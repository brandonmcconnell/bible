<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 16:18–19; テモテへの手紙第一 5:21; ネヘミヤ記 7:2"> サムエルが年老いた時、彼は自分の息子たちをイスラエルをさばく者とした。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代誌上 6:38; 創世記 22:19; 歴代誌上 6:28"> 彼の長子の名はヨエル、次子の名はアビヤといった。彼らはベエル・シェバでさばいていた。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 16:19; 詩篇 15:5; テモテへの手紙第一 6:10"> 彼の息子たちは彼の道を歩まず、不正な利益を求めてそれて行き、賄賂を取り、さばきを曲げた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="サムエル記第一 7:17; サムエル記第二 5:3; 出エジプト記 3:16"> そこでイスラエルの長老たちは皆集まり、ラマにいるサムエルのところに来た。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 17:14–15; ホセア書 13:10–11; サムエル記第一 8:6–8"> 彼らは彼に言った。「見よ、あなたは年老い、あなたの息子たちはあなたの道を歩んでいない。今、すべての国々のように、私たちをさばく王を私たちのために立ててほしい。」</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記第一 15:11; ヤコブの手紙 1:5; サムエル記第一 12:17"> しかし彼らが、「私たちをさばく王を与えよ」と言った時、サムエルはその言葉を不快に思った。サムエルは主に祈った。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカ 10:16; サムエル記第一 10:19; 出エジプト記 16:8"> 主はサムエルに言われた。「民があなたに言うすべてのことについて、彼らの声に聞き従いなさい。彼らが退けたのはあなたではない。わたしが彼らの上に王として治めることを退けたのである。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 106:34–40; 出エジプト記 32:1; 士師記 13:1"> わたしが彼らをエジプトから導き上げた日から今日に至るまで、彼らが行ってきたすべての行いのとおりである。彼らはわたしを捨てて他の神々に仕えたように、あなたにもそのようにしている。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記第一 10:25; サムエル記第一 8:11–18; エゼキエル書 46:18"> それゆえ今、彼らの声に聞き従いなさい。しかし、彼らに厳しく警告し、彼らを治める王のやり方を彼らに示しなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> サムエルは、王を求めた民に主のすべての言葉を語った。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記第一 14:52; 申命記 17:14–20; サムエル記第一 10:25"> 彼は言った。「あなたがたを治める王のやり方はこうである。彼はあなたがたの息子たちを取り、自分の戦車隊や騎兵に任じる。彼らは王の戦車の前を走るであろう。</span>
<span className="v" id="v12" data-v="12" data-xref="サムエル記第一 22:7; 列王記第一 4:7; 歴代誌上 27:1–22"> また彼は自分に千人隊の長、五十人隊の長を任命する。また一部の者を、自分の地を耕させ、自分の収穫を刈り取らせ、自分の戦いの武器や戦車の装備を作らせるために置く。</span>
<span className="v" id="v13" data-v="13"> 彼はあなたがたの娘たちを取り、香料を作る者、料理人、パンを焼く者とする。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 46:18; 列王記第一 21:7; 列王記第一 21:19"> 彼はあなたがたの畑、ぶどう畑、オリーブ畑の最も良いものを取り、自分の家来たちに与える。</span>
<span className="v" id="v15" data-v="15" data-xref="ダニエル書 1:3; イザヤ書 39:7; 創世記 37:36"> 彼はあなたがたの穀物とぶどう畑の収穫の十分の一を取り、自分の役人や家来たちに与える。</span>
<span className="v" id="v16" data-v="16"> 彼はあなたがたの男奴隷、女奴隷、あなたがたの最も良い若者たち、またあなたがたのろばを取り、自分の仕事に使わせる。</span>
<span className="v" id="v17" data-v="17"> 彼はあなたがたの羊の群れの十分の一を取り、あなたがたは彼の奴隷となる。</span>
<span className="v" id="v18" data-v="18" data-xref="ミカ書 3:4; イザヤ書 1:15; 箴言 1:25–28"> その日、あなたがたは自分たちのために選んだ王のゆえに叫び求めるであろうが、主はその日、あなたがたに答えられないであろう。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 44:16; エレミヤ書 7:13; イザヤ書 66:4"> しかし民はサムエルの声に聞き入れることを拒み、こう言った。「いいえ、どうしても私たちの上に王がいなければならない。</span>
<span className="v" id="v20" data-v="20" data-xref="サムエル記第一 8:5; 詩篇 106:35; 申命記 7:6"> 私たちも他のすべての国々のようになり、私たちの王が私たちをさばき、私たちの前に出て行って私たちの戦いを担うためだ。」</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 11:11"> サムエルは民のすべての言葉を聞き、それを主の耳に入れた。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記第一 8:7; ホセア書 13:11"> 主はサムエルに言われた。「彼らの声に聞き従い、彼らのために王を立てよ。」サムエルはイスラエルの男たちに言った。「それぞれ自分の町に帰りなさい。」</span>
</div>

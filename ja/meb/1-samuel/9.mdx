<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記第一 14:51; 使徒の働き 13:21; 歴代誌上 9:36–39"> ベニヤミン人の中にキシュという名の男がいた。彼はアビエルの子、ツェロルの子、ベコラテの子、アフィアの子で、ベニヤミン人であり、力ある勇士であった。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 6:2; 民数記 13:33; サムエル記第一 16:7"> 彼にはサウルという名の息子がおり、立派な若者で、イスラエルの人々の中で彼ほど容姿の優れた者はいなかった。彼の肩から上は、どの民よりも背が高かった。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="士師記 5:10; サムエル記第一 10:2; 士師記 10:4"> サウルの父キシュのろばが迷い出た。キシュは息子のサウルに言った。「今、若者の一人を連れて立ち上がり、行ってろばを探しなさい。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王記第二 4:42; ヨシュア記 24:33; ヨハネ 3:23"> サウルはエフライムの山地を通り抜け、シャリシャの地を通り抜けたが、彼らはろばを見つけられなかった。それからシャアリムの地を通り抜けたが、そこにもいなかった。さらにベニヤミン人の地を通り抜けたが、彼らは見つけられなかった。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="サムエル記第一 10:2; サムエル記第一 1:1; ルカ 12:11"> 彼らがツフの地に来た時、サウルはともにいた若者に言った。「さあ、引き返そう。父がろばのことよりも私たちのことを心配し始めないように。」</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第一 13:1; 申命記 33:1; テモテへの手紙第一 6:11"> 若者は彼に言った。「見よ、この町には神の人がいます。彼は誉れ高い人で、彼の言うことはすべて必ずその通りになります。今、そこへ行きましょう。もしかすると、彼が私たちの行くべき道について教えてくれるかもしれません。」</span>
<span className="v" id="v7" data-v="7" data-xref="列王記第一 14:3; 列王記第二 8:8; 列王記第二 4:42"> そこでサウルは若者に言った。「しかし、見よ、もし私たちが行くなら、その人に何を持って行こうか。私たちの袋のパンは尽きており、神の人に持って行く贈り物はない。私たちには何があるだろうか。」</span>
<span className="v" id="v8" data-v="8"> 若者は再びサウルに答えた。「見よ、わたしの手に銀一シェケルの四分の一<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一シェケルは約10グラム、あるいは約0.35オンスである。四分の一シェケルは約2.5グラムである。">a</a></sup>があります。わたしはこれを神の人に与え、私たちの道を教えてもらいましょう。」</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 30:10; 列王記第二 17:13; アモス書 7:12"> （昔、イスラエルで人が神に伺うために行く時、このように言った。「さあ、先見者のところへ行こう。」今日預言者と呼ばれている者は、以前は先見者と呼ばれていたからである。）</span>
<span className="v" id="v10" data-v="10" data-xref="列王記第二 5:13–14"> サウルは若者に言った。「良い考えだ。さあ、行こう。」こうして彼らは神の人がいる町へ行った。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="創世記 24:11; 出エジプト記 2:16; 創世記 24:18–20"> 彼らが町へ上る坂道を上って行くと、水を汲みに出て来る若い娘たちに出会い、彼女たちに「先見者はここにいますか」と尋ねた。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 31:54; サムエル記第一 16:2; サムエル記第一 10:5"> 彼女たちは答えた。「います。ほら、その方はあなたがたの前におられます。急ぎなさい。民が今日、高き所でいけにえを献げるので、その方は町に来られたのです。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネ 6:11; マタイ 26:26; ルカ 24:30"> 町に入れば、高き所へ食事に上る前にその方を見つけられるでしょう。その方がいけにえを祝福するので、その方が来られるまで民は食事をしません。その後で、招かれた者たちが食事をします。それゆえ今、上って行きなさい。今ならその方に会えるでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 彼らは町に上って行った。彼らが町の中に入ると、見よ、サムエルが高き所へ上るために、彼らに向かって出て来た。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 13:21; サムエル記第一 15:1; ヨブ記 33:16"> サウルが来る前日、主はサムエルに啓示して言われていた。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記第一 10:1; 詩篇 106:44; 出エジプト記 3:7–9"> 「明日の今ごろ、わたしはベニヤミンの地から一人の男をあなたのところに遣わす。あなたは彼に油を注いで、わたしの民イスラエルの君主としなさい。彼はわたしの民をペリシテ人の手から救い出すであろう。彼らの叫びがわたしに届き、わたしがわたしの民を顧みたからである。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ホセア書 13:11; サムエル記第一 16:6–12; ネヘミヤ記 13:25"> サムエルがサウルを見た時、主は彼に言われた。「見よ、わたしがあなたに話した男だ。この者がわたしの民を治める。」</span>
<span className="v" id="v18" data-v="18"> その時サウルは門の中でサムエルに近づいて言った。「どうか、先見者の家がどこにあるか教えてください。」</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第一の手紙 14:25; ヨハネ 4:29"> サムエルはサウルに答えた。「わたしが先見者である。わたしの先に高き所へ上りなさい。あなたがたは今日わたしとともに食事をするからである。朝にはあなたを送り出し、あなたの心にあることをすべて教えよう。</span>
<span className="v" id="v20" data-v="20" data-xref="サムエル記第一 8:5; サムエル記第一 12:13; サムエル記第一 9:3"> 三日前に迷い出たあなたのろばについては、気にかけるな。すでに見つかっているからだ。イスラエルの望むものはすべて、だれのものになるのか。あなたと、あなたの父の全家のものではないか。」</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記第一 15:17; 士師記 20:46–48; 詩篇 68:27"> サウルは答えた。「わたしはイスラエルの部族の中で最も小さいベニヤミン人ではありませんか。わたしの氏族はベニヤミン部族のすべての氏族の中で最も小さなものではありませんか。それなのに、なぜあなたはそのようなことをわたしに言われるのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="創世記 43:32; ルカ 14:10"> サムエルはサウルとその若者を連れて客間に入り、招かれたおよそ三十人の人々のうちの最も良い席に彼らを座らせた。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記第一 1:5; 創世記 43:34"> サムエルは料理人に言った。「わたしがあなたに渡し、『取っておくように』と言ったあの分を持って来なさい。」</span>
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 24:4; レビ記 7:32–33; 出エジプト記 29:22"> 料理人はもも肉とその上の部分を持ち上げ、サウルの前に置いた。サムエルは言った。「見よ、取り分けておいたものがあなたの前に置かれている。食べなさい。わたしが『民を招いた』と言った時から、この時のためにあなたのために取っておかれたものだからだ。」こうしてサウルはその日、サムエルとともに食事をした。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 10:9; 申命記 22:8; サムエル記第二 11:2"> 彼らが高き所から町に下って来た時、サムエルは屋上でサウルと語り合った。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 44:4; ヨシュア記 7:13; 士師記 19:28"> 彼らは朝早く起きた。夜明けごろ、サムエルは屋上でサウルを呼んで、「起きなさい、あなたを送り出そう」と言った。サウルは起き上がり、彼とサムエルの二人は外へ出て行った。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネ 15:14–15; サムエル記第一 20:38–39; 列王記第二 9:5–6"> 彼らが町の外れまで下って行った時、サムエルはサウルに言った。「若者に、私たちの先を行くように言いなさい。」若者は先に行った。「しかし、あなたはしばらく立ち止まりなさい。わたしがあなたに神の言葉を聞かせるためである。」</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記第一 28:3; 民数記 20:29; 申命記 34:8"> サムエルが死んだ。全イスラエルはともに集まって彼のために嘆き悲しみ、ラマにある彼の家に彼を葬った。ダビデは立ち上がり、パランの荒野へ下って行った。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 38:13; サムエル記第一 23:24; ヨシュア記 15:55"> マオンに一人の男がいた。その財産はカルメルにあり、その男は非常に裕福であった。彼には三千匹の羊と一千頭のやぎがおり、彼はカルメルで羊の毛を刈っていた。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 14:1; 箴言 31:10; イザヤ書 32:5–7"> さて、その男の名はナバル、その妻の名はアビガイルといった。その女は分別があり、顔立ちも美しかった。しかしその男は、粗暴で、行いの悪い男だった。彼はカレブの家系の者であった。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 38:13; サムエル記第二 13:23"> ダビデは、ナバルが羊の毛を刈っていると荒野で聞いた。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 43:23; サムエル記第一 17:22"> ダビデは十人の若者を遣わし、彼らに言った。「カルメルへ上って行き、ナバルのところへ行き、わたしの名で彼に挨拶しなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカ 10:5; 歴代誌上 12:18; 詩篇 122:7"> 彼にこう言いなさい。『ご繁栄を。あなたに平安があるように。あなたの家に平安があるように。あなたのすべての持ち物に平安があるように。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記第一 25:21; サムエル記第一 25:15–16; サムエル記第一 22:2"> 今、あなたが毛を刈る者たちを抱えていると聞きました。あなたの羊飼いたちは今まで私たちと一緒にいましたが、私たちは彼らに何の害も加えず、彼らがカルメルにいた間ずっと、彼らから何かがなくなることもありませんでした。</span>
<span className="v" id="v8" data-v="8" data-xref="エステル記 9:19; ネヘミヤ記 8:10–12; ルカ 14:12–14"> あなたの若者たちに尋ねてみてください。そうすれば彼らがあなたに教えてくれるでしょう。それゆえ、この若者たちがあなたの目に恵みを得ますように。私たちは祝いの日に来たからです。どうか、あなたの手にあるものを何でも、あなたのしもべたちと、あなたの息子ダビデに与えてください。』」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王記第二 2:15; 歴代誌 第二 14:7; 創世記 8:4"> ダビデの若者たちが来て、ダビデの名でこれらすべての言葉をナバルに告げ、そして返事を待った。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 9:28; イザヤ書 32:7; サムエル記第一 22:7–8"> ナバルはダビデのしもべたちに答えた。「ダビデとは何者か。エッサイの息子とは何者か。近頃、それぞれの主人から逃げ出す奴隷が多くなっている。</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 8:6; ガラテヤ人への手紙 6:10; コリント人への第二の手紙 6:9"> それなのに、わたしがわたしのパンとわたしの水と、わたしの毛を刈る者たちのために屠った肉を取って、どこから来たのか分からないような者たちに与えなければならないのか。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 36:21–22; サムエル記第二 24:13; ヘブル人への手紙 13:17"> そこでダビデの若者たちは道を引き返し、戻って来て、これらすべての言葉を彼に告げた。</span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記第一 23:13; 箴言 25:8; サムエル記第一 24:5–6"> ダビデは自分の人々に言った。「それぞれ自分の剣を帯びよ。」彼らはそれぞれ自分の剣を帯び、ダビデも自分の剣を帯びた。約四百人がダビデの後について上って行き、二百人は荷物のところに留まった。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="サムエル記第一 13:10; マルコ 15:29"> しかし若者たちの一人がナバルの妻アビガイルに告げて言った。「見よ、ダビデが荒野から私たちの主人に挨拶するために使者たちを送ったのに、彼は彼らをののしりました。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記第一 25:7; サムエル記第一 25:21; ピリピ人への手紙 2:15"> しかしその人たちは、私たちに対して非常に良くしてくれました。私たちが野にいて彼らと一緒にいた間ずっと、私たちは害を受けることもなく、何かがなくなることもありませんでした。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨブ記 1:10; 出エジプト記 14:22; ゼカリヤ書 2:5"> 私たちが羊を飼いながら彼らと一緒にいた間ずっと、彼らは夜も昼も私たちにとって城壁となってくれました。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記第一 20:7; 申命記 13:13; サムエル記第一 20:9"> それゆえ今、あなたが何をすべきかを知り、よく考えなさい。私たちの主人とその全家には、災いが避けられません。彼はどうしようもないならず者なので、だれも彼に話しかけることができません。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="サムエル記第二 16:1; マタイ 5:25; 箴言 6:4–5"> そこでアビガイルは急いで、二百個のパン、二つのぶどう酒の皮袋、調理された五匹の羊、五セア<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一セアは約7リットル、または1.9ガロン、あるいは0.8ペックである。">a</a></sup>の炒り麦、百房の干しぶどう、および二百個の干しいちじくの菓子を取り、それらをろばに載せた。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 32:20; 創世記 32:16; 箴言 31:11–12"> 彼女は若者たちに言った。「わたしの先に行きなさい。見よ、わたしはあなたがたの後について行く。」しかし彼女は夫のナバルには告げなかった。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王記第二 4:24"> 彼女がろばに乗って山の隠れた所を下って来た時、見よ、ダビデと彼の人々が彼女の方へ下って来たので、彼女は彼らに出会った。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 17:13; エペソ人への手紙 4:31; ローマ人への手紙 12:21"> さて、ダビデは言っていた。「わたしが荒野でこの男に属するすべてのものを守り、彼に属するものが何一つなくならないようにしたのは、全くの無駄であった。彼は善の代わりに悪をわたしに報いた。</span>
<span className="v" id="v22" data-v="22" data-xref="列王記第一 14:10; サムエル記第一 20:13; サムエル記第一 3:17"> もしわたしが朝の光がさすまでに、彼に属するすべての者のうち、男<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="直訳「壁に向かって放尿する者」。男性を指す表現。">b</a></sup>を一人でも残しておくなら、神がダビデの敵たちにそうされ、さらにそれ以上のことをされるように。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="サムエル記第一 20:41; 士師記 1:14; ヨシュア記 15:18"> アビガイルがダビデを見た時、彼女は急いでろばから降り、ダビデの前に顔を伏せ、地にひれ伏した。</span>
<span className="v" id="v24" data-v="24" data-xref="エステル記 8:3; サムエル記第一 25:28; サムエル記第二 14:9"> 彼女は彼の足元にひれ伏して言った。「わが主よ。この責めはわたしが負います。どうかあなたのはしためにあなたの耳に語らせ、あなたのはしための言葉を聞いてください。</span>
<span className="v" id="v25" data-v="25" data-xref="サムエル記第一 25:17; マラキ書 2:2; サムエル記第二 13:33"> どうか、わが主がこのならず者であるナバルを気に留められませんように。彼はその名の通りの者だからです。彼がナバル<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「ナバル」は「愚か者」を意味する。">c</a></sup>という名であるように、愚かさが彼とともにあります。しかし、あなたのはしためであるわたしは、わが主が遣わされた若者たちを見ませんでした。</span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記第二 18:32; ローマ人への手紙 12:19–20; 創世記 20:6"> それゆえ今、わが主よ、主が生きておられ、あなたが生きているのと同じほど確かに、主はあなたが血を流す罪を犯し、自らの手で復讐することを思いとどまらせてくださったのですから、今、あなたの敵たちとわが主に悪をたくらむ者たちがナバルのようになりますように。</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 33:11; サムエル記第一 30:26; 列王記第二 5:15"> 今、あなたのはしためがわが主のもとに持って来たこの贈り物を、わが主の後について行く若者たちに与えてください。</span>
<span className="v" id="v28" data-v="28" data-xref="サムエル記第一 18:17; サムエル記第二 7:11; サムエル記第一 24:11"> どうか、あなたのはしための背きをお赦しください。主は必ずわが主のために確かな家を建てられるからです。わが主が主の戦いを戦っておられ、あなたの生涯にわたってあなたに悪が見出されないからです。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネ 17:21; マタイ 10:29–30; マラキ書 3:17"> 人があなたを追撃し、あなたの命を狙って立ち上がっても、わが主の命は、あなたの神、主のもとで、命の包みに大切に包まれています。そしてあなたの敵たちの命は、石投げひものくぼみから投げるように、主が投げ捨てられるでしょう。</span>
<span className="v" id="v30" data-v="30" data-xref="サムエル記第一 13:14; 詩篇 89:20; サムエル記第一 23:17"> 主がわが主について語られたすべての良いことに従って、あなたに行い、あなたをイスラエルの君主として任命された時、</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 40:14; ローマ人への手紙 12:19; ルカ 23:42"> わが主が理由なく血を流したことや、わが主が自ら復讐したことが、わが主にとって良心の痛みや、心のつまずきとなりませんように。主がわが主に良くしてくださった時、あなたのはしためを思い出してください。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="ルカ 1:68; 出エジプト記 18:10; 詩篇 72:18"> ダビデはアビガイルに言った。「今日あなたを遣わしてわたしに会わせてくださったイスラエルの神、主がほめたたえられるように。</span>
<span className="v" id="v33" data-v="33" data-xref="サムエル記第一 25:26; 箴言 28:23; 箴言 9:9"> あなたの分別の良さが祝福されるように。そして、わたしが今日血を流す罪を犯し、自分の手で復讐することを思いとどまらせてくれたあなたが祝福されるように。</span>
<span className="v" id="v34" data-v="34" data-xref="サムエル記第一 11:11; サムエル記第一 25:26; ヨシュア記 10:6"> しかし、わたしがあなたに害を加えることを思いとどまらせてくださったイスラエルの神、生ける主にかけて、もしあなたが急いでわたしに会いに来なかったなら、朝の光がさすまでに、ナバルには確かに男<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="直訳「壁に向かって放尿する者」。男性を指す表現。">d</a></sup>が一人も残されていなかったであろう。」</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 19:21; サムエル記第一 20:42; 列王記第二 5:19"> こうしてダビデは、彼女が彼のために持って来たものを彼女の手から受け取り、彼女に言った。「平安のうちにあなたの家へ上って行きなさい。見よ、わたしはあなたの声に聞き入れ、あなたの願いを受け入れた。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="サムエル記第一 25:19; サムエル記第二 13:23; サムエル記第二 13:28"> アビガイルがナバルのところに来ると、見よ、彼は王の宴会のような宴会を家で催していた。ナバルはひどく酔っており、その心は陽気であった。それゆえ、彼女は朝の光がさすまで、大小にかかわらず彼に何も告げなかった。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 28:28; サムエル記第一 25:34; サムエル記第一 25:22"> 朝になって、ナバルの酔いが覚めた時、彼の妻は彼にこれらの事柄を告げた。すると彼の心は麻痺し、石のようになった。</span>
<span className="v" id="v38" data-v="38" data-xref="サムエル記第一 26:10; 列王記第二 15:5; サムエル記第一 6:9"> そして約十日後、主がナバルを打たれたため、彼は死んだ。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="サムエル記第一 25:26; サムエル記第一 25:34; 箴言 22:23"> ナバルが死んだと聞いた時、ダビデは言った。「ナバルが浴びせた侮辱の訴えを取り上げ、そのしもべを悪から引き止めてくださった主がほめたたえられるように。主はナバルの悪行を彼自身の頭上に返された。」そしてダビデは、アビガイルを自分の妻に迎えるため、彼女に人を遣わして申し入れた。</span>
<span className="v" id="v40" data-v="40" data-xref="創世記 24:51; 創世記 24:37–38"> ダビデのしもべたちがカルメルのアビガイルのところに来て、彼女に語って言った。「ダビデはあなたを自分の妻とするために、私たちをあなたのところに遣わしました。」</span>
<span className="v" id="v41" data-v="41" data-xref="テモテへの手紙第一 5:10; ヨハネ 13:3–5; ルツ記 2:10"> 彼女は立ち上がり、顔を地に向けてひれ伏し、「見よ、あなたのはしためは、わが主のしもべたちの足を洗う仕え女です」と言った。</span>
<span className="v" id="v42" data-v="42" data-xref="創世記 24:61–67; 詩篇 45:10–11"> アビガイルは急いで立ち上がり、五人の侍女を連れてろばに乗り、ダビデの使者たちの後について行き、彼の妻となった。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="サムエル記第一 30:5; ヨシュア記 15:56; サムエル記第一 27:3"> ダビデはまたエズレルのアヒノアムをめとり、彼女たち二人は彼の妻となった。</span>
<span className="v" id="v44" data-v="44" data-xref="サムエル記第二 3:14; サムエル記第一 18:27; サムエル記第一 18:20"> サウルは、自分の娘でありダビデの妻であるミカルを、ガリムの出身であるライシュの子パルティに与えていた。</span>
</div>
</div>

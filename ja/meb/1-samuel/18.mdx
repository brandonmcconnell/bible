<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記第一 20:17; 箴言 18:24; サムエル記第一 18:3"> ダビデがサウルに語り終えた時、ヨナタンの心はダビデの心と深く結ばれ、ヨナタンは自分自身のようにダビデを愛した。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記第一 17:15; サムエル記第一 16:21–23"> サウルはその日彼を召し抱え、もはや父の家に帰ることを許さなかった。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記第一 20:8–17; サムエル記第一 20:42; サムエル記第二 21:7"> ヨナタンはダビデを自分自身のように愛したため、彼と契約を結んだ。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 41:42; ルカ 15:22; エステル記 6:8–9"> ヨナタンは自分の着ていた上着を脱いでダビデに与え、また自分の衣服、さらには自分の剣、弓、および帯までも彼に与えた。</span>
<span className="v" id="v5" data-v="5" data-xref="サムエル記第一 18:30; サムエル記第一 18:14–15; コロサイ人への手紙 4:5"> ダビデはサウルが彼を遣わすところはどこへでも出て行き、成功を収めた。サウルは彼を戦士たちの上に立てた。それはすべての民の目に、またサウルの家来たちの目にも良いことであった。</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 15:20; 士師記 11:34; 詩篇 68:25"> 彼らが帰って来た時、すなわちダビデがそのペリシテ人を殺して戻って来た時、女たちはイスラエルのすべての町々から、タンバリンを鳴らし、喜びをもって、またさまざまな楽器を携えて、サウル王を迎えるために歌い踊りながら出て来た。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記第一 21:11; サムエル記第一 29:5; 出エジプト記 15:21"> 女たちは遊び戯れながら互いに歌い交わして言った。<br /><span className="pl pl-1">「サウルは千を打ち、</span><br /><span className="pl pl-2">ダビデは万を打った。」</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="サムエル記第一 15:28; 箴言 13:10; ヤコブの手紙 4:5"> サウルは非常に怒り、この言葉は彼の心を悪くさせた。彼は言った。「彼らはダビデに万を割り当てたが、わたしには千しか割り当てなかった。あとは王位を手にするだけではないか。」</span>
<span className="v" id="v9" data-v="9" data-xref="マルコ 7:22; 創世記 31:2; マタイ 20:15"> その日以来、サウルはダビデに疑いの目を向けた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="サムエル記第一 19:9; テサロニケ人への第二の手紙 2:11; 列王記第一 18:29"> 翌日、神からの悪霊がサウルの上に激しく臨み、彼は家の中で預言した。ダビデは他の時のように彼の手で竪琴を弾いた。サウルの手には槍があった。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記第一 20:33; イザヤ書 54:17; ルカ 4:30"> サウルは「ダビデを壁に突き刺してやる」と言って槍を投げた。ダビデは彼の前から二度身をかわした。</span>
<span className="v" id="v12" data-v="12" data-xref="サムエル記第一 18:15; サムエル記第一 18:29; サムエル記第一 16:13–14"> 主がダビデとともにおられ、サウルから去られたため、サウルはダビデを恐れた。</span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記第二 5:2; 詩篇 121:8; サムエル記第一 18:16–17"> それゆえサウルは彼を自分のそばから遠ざけ、彼を自分の千人隊の長とした。彼は民の前を出入りした。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="創世記 39:23; マタイ 28:20; サムエル記第一 16:18"> ダビデはそのすべての道において賢く振る舞い、主は彼とともにおられた。</span>
<span className="v" id="v15" data-v="15" data-xref="ヤコブの手紙 3:17; コロサイ人への手紙 4:5; ヤコブの手紙 1:5"> サウルは彼が非常に賢く振る舞うのを見た時、彼を恐れおののいた。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記第一 18:5; 民数記 27:17; 列王記第一 3:7"> しかし、彼が民を率いて出入りしていたので、全イスラエルとユダはダビデを愛した。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="サムエル記第一 17:25; サムエル記第一 25:28; サムエル記第一 18:25"> サウルはダビデに言った。「見よ、わたしの長女メラブを、あなたに妻として与えよう。ただ、わたしのために勇敢に働き、主の戦いを戦いなさい。」サウルは「わたしの手が彼に下るのではなく、ペリシテ人の手が彼に下るようにしよう」と考えていたからである。</span>
<span className="v" id="v18" data-v="18" data-xref="サムエル記第二 7:18; サムエル記第一 9:21; サムエル記第一 18:23"> ダビデはサウルに言った。「わたしは何者でしょうか。わたしの命、あるいはイスラエルにおけるわたしの父の家系が何だというので、わたしが王の婿になれるのでしょうか。」</span>
<span className="v" id="v19" data-v="19" data-xref="士師記 7:22; サムエル記第二 21:8; 士師記 14:20"> しかし、サウルの娘メラブがダビデに与えられる時になって、彼女はメホラ人アドリエルに妻として与えられた。</span>
<span className="v" id="v20" data-v="20" data-xref="サムエル記第一 18:28"> サウルの娘ミカルはダビデを愛していた。人々がそれをサウルに告げると、その事は彼を喜ばせた。</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記第一 18:17; 出エジプト記 10:7; エレミヤ書 9:8"> サウルは言った。「わたしは彼女を彼に与えよう。彼女が彼にとって罠となり、ペリシテ人の手が彼に下るためである。」それゆえサウルはダビデに「今日、あなたはもう一度、わたしの婿となるのだ」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="詩篇 36:1–3; 詩篇 55:21; サムエル記第二 13:28–29"> サウルは家来たちに命じた。「ダビデにひそかに語って、『見よ、王はあなたを喜んでおり、その家来たちも皆あなたを愛している。それゆえ今、王の婿になりなさい』と言いなさい。」</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 119:141; 箴言 14:20; 伝道者の書 9:15–16"> サウルの家来たちはこれらの言葉をダビデの耳に語った。ダビデは「わたしが貧しく、軽く見られている者であるのに、王の婿になることがあなたがたにとって軽いことと思われるのですか」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> サウルの家来たちは彼に告げて、「ダビデはこれこれの事を語りました」と言った。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 34:12; サムエル記第一 18:17; サムエル記第一 14:24"> サウルは言った。「あなたがたはダビデにこう言いなさい。『王は、王の敵に復讐するために、百人のペリシテ人の包皮のほかには、結納金を望んでおられない。』」しかしサウルは、ダビデをペリシテ人の手によって倒そうとたくらんでいたのである。</span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記第一 18:21"> 家来たちがこれらの言葉をダビデに告げると、ダビデは王の婿になることを大いに喜んだ。その期日がまだ満ちないうちに、</span>
<span className="v" id="v27" data-v="27" data-xref="サムエル記第二 3:14; 士師記 14:19; サムエル記第一 18:13"> ダビデは立ち上がり、彼と彼の人々とともに行って、ペリシテ人のうち二百人の男を殺した。そしてダビデは彼らの包皮を持って来て、彼が王の婿となるために、その数をそろえて王に差し出した。そこでサウルは娘ミカルを彼に妻として与えた。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="サムエル記第一 24:20; サムエル記第一 26:25; 創世記 37:8–11"> サウルは、主がダビデとともにおられるのを見、また知った。そしてサウルの娘ミカルは彼を愛していた。</span>
<span className="v" id="v29" data-v="29" data-xref="伝道者の書 4:4; ヨハネ 11:53; ヤコブの手紙 2:19"> サウルはダビデをますます恐れ、サウルは生涯ダビデの敵となった。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="サムエル記第一 18:5; サムエル記第二 11:1; ペテロの手紙第一 2:4"> それからペリシテ人の君主たちが出て来て戦った。彼らが出て来るたびに、ダビデはサウルのすべての家来たちよりも賢く振る舞ったので、彼の名は高く尊ばれた。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記第一 9:16; サムエル記第一 12:14; 詩篇 2:10–11"> サムエルはサウルに言った。「主はわたしを遣わし、あなたに油を注いでご自分の民イスラエルの王とされた。それゆえ今、主の言葉に聞き従いなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 25:17–19; 出エジプト記 17:8–16; 民数記 24:20"> 万軍の主はこう言われる。『わたしはアマレクがイスラエルにしたこと、すなわちイスラエルがエジプトから上って来た時、彼が道でイスラエルに敵対したことを覚えている。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 20:16–18; 民数記 24:20; 民数記 31:17"> 今、行ってアマレクを打ち、彼らが持っているすべてのものを滅ぼし尽くしなさい。彼らを惜しんではならない。男も女も、幼子も乳飲み子も、牛も羊も、らくだもろばも殺しなさい。』」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ヨシュア記 15:24; サムエル記第一 11:8; サムエル記第一 13:15"> サウルは民を呼び集め、テライムで彼らを数えた。歩兵二十万人とユダの男一万人であった。</span>
<span className="v" id="v5" data-v="5"> サウルはアマレクの町に来て、谷で待ち伏せした。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 1:16; 民数記 10:29–32; 出エジプト記 18:19"> サウルはケニ人に言った。「行け、立ち去れ、アマレク人の中から下って行け。わたしがあなたがたを彼らと一緒に滅ぼさないためだ。あなたがたは、イスラエルのすべての子らがエジプトから上って来た時、彼らに慈しみを示したからである。」そこでケニ人はアマレク人の中から立ち去った。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="創世記 16:7; 創世記 25:18; サムエル記第一 14:48"> サウルはハビラからエジプトの前にあるシュルに至るまで、アマレク人を打った。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記第一 30:1; エステル記 3:1; 民数記 24:7"> 彼はアマレクの王アガグを生け捕りにし、すべての民を剣の刃で滅ぼし尽くした。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記第一 15:15; サムエル記第一 15:19; サムエル記第一 15:3"> しかしサウルと民は、アガグ、および羊と牛の最も良いもの、肥えた子牛、子羊、そしてすべての良いものを惜しみ、それらを滅ぼし尽くそうとはせず、ただ価値のないつまらないものだけを滅ぼし尽くした。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> その時、主の言葉がサムエルに臨んで言われた。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記第一 13:13; 創世記 6:6; サムエル記第二 24:16"> 「サウルを王に立てたことを、わたしは悲しく思う。彼はわたしに従うことから背き、わたしの命令を実行しなかったからである。」サムエルは怒り、夜通し主に向かって叫び求めた。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 15:55; サムエル記第二 18:18; サムエル記第一 25:2"> サムエルはサウルに会うために朝早く起きた。するとサムエルに、「サウルはカルメルに行き、自分のために記念碑を立て、そこを離れて進み、ギルガルへ下った」という知らせがあった。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="士師記 17:2; ルツ記 3:10; 箴言 31:31"> サムエルがサウルのところに来ると、サウルは彼に言った。「あなたが主に祝福されますように。わたしは主の命令を実行しました。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マラキ書 3:13–15; エレミヤ書 2:18–19; エレミヤ書 2:34–37"> サムエルは言った。「では、わたしの耳に入るこの羊の鳴き声と、わたしに聞こえる牛の鳴き声は何なのか。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="サムエル記第一 15:21; サムエル記第一 15:9; 出エジプト記 32:22–23"> サウルは言った。「彼らがアマレク人から持って来たのです。民が羊と牛の最も良いものをあなたの神、主にいけにえとして献げるために惜しみ、残りのものは私たちが滅ぼし尽くしました。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="サムエル記第一 9:27; 列王記第一 22:16; サムエル記第一 12:7"> サムエルはサウルに言った。「もうよい。昨夜、主がわたしに語られたことをあなたに告げよう。」<br />サウルは彼に言った。「お話しください。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="サムエル記第一 10:22; サムエル記第一 9:21; サムエル記第一 15:1–3"> サムエルは言った。「あなたは自分の目には小さな者であったが、イスラエルの部族のかしらとされたのではないか。主はあなたに油を注いでイスラエルの王とされた。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:29; 創世記 13:13; 創世記 15:16"> 主はあなたを旅に遣わして、『行き、あの罪人たち、アマレク人を滅ぼし尽くし、彼らが滅びるまで彼らと戦え』と言われた。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記第一 14:32; 歴代誌 第二 33:6; 歴代誌 第二 36:12"> それなのに、なぜあなたは主の声に聞き従わなかったのか。なぜ分捕り品に飛びかかり、主の目に悪であるとされることを行ったのか。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="サムエル記第一 15:13; マタイ 19:20; ローマ人への手紙 10:3"> サウルはサムエルに言った。「わたしは確かに主の声に聞き従い、主がわたしを遣わされた道を行き、アマレクの王アガグを連れて来て、アマレク人を滅ぼし尽くしました。</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記第一 15:15; 出エジプト記 32:22–23; 創世記 3:13"> しかし民は、滅ぼし尽くすべきものの中で最も良い羊と牛を、ギルガルであなたの神、主にいけにえとして献げるために、分捕り品の中から取りました。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="ホセア書 6:6; 詩篇 51:16–17; 箴言 21:3"> サムエルは言った。<br /><span className="pl pl-1">「主は、主の声に聞き従うことと同じほど、全焼のささげ物やいけにえを喜ばれるだろうか。</span><br /><span className="pl pl-2">見よ、聞き従うことはいけにえにまさり、耳を傾けることは雄羊の脂肪にまさる。</span></span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 28:16; サムエル記第一 13:14; レビ記 20:6"> <span className="pl pl-1">反逆は占いの罪に等しく、</span><br /><span className="pl pl-2">強情は偶像礼拝とテラフィム</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="テラフィムは家の偶像であり、家の財産を受け継ぐ権利と関係していた可能性がある。">a</a></sup><br /><span className="pl pl-2">と同じである。</span><br /><span className="pl pl-1">あなたが主の言葉を退けたので、</span><br /><span className="pl pl-2">主もまた、あなたが王であることを退けられた。」</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="サムエル記第二 12:13; イザヤ書 51:12–13; 民数記 22:34"> サウルはサムエルに言った。「わたしは罪を犯しました。民を恐れ、彼らの声に聞き従ったため、主の命令とあなたの言葉を破りました。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 10:17"> それゆえ今、どうかわたしの罪を赦し、わたしと一緒に帰って、わたしが主を礼拝できるようにしてください。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ホセア書 4:6; サムエル記第一 13:14; サムエル記第一 16:1"> サムエルはサウルに言った。「わたしはあなたと一緒に帰らない。あなたが主の言葉を退けたので、主もまた、あなたがイスラエルを治める王であることを退けられたからだ。」</span>
<span className="v" id="v27" data-v="27" data-xref="列王記第一 11:30–31"> サムエルが去ろうとして背を向けた時、サウルはサムエルの上着の裾をつかみ、それは引き裂かれた。</span>
<span className="v" id="v28" data-v="28" data-xref="サムエル記第一 28:17–18; 使徒の働き 13:22; ダニエル書 4:32"> サムエルは彼に言った。「主は今日、イスラエルの王位をあなたから引き裂き、それをあなたより優れたあなたの隣人に与えられた。</span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 24:14; 民数記 23:19; テトス 1:2"> イスラエルの力である方は偽ることも、思いを変えることもない。主は人間ではないので、思いを変えることはない。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ヨハネ 5:44; ヨハネ 12:43; イザヤ書 29:13"> サウルは言った。「わたしは罪を犯しました。しかし今、どうかわたしの民の長老たちの前で、またイスラエルの前でわたしを重んじ、わたしと一緒に帰って、わたしがあなたの神、主を礼拝できるようにしてください。」</span>
<span className="v" id="v31" data-v="31"> そこでサムエルはサウルの後に付いて帰り、サウルは主を礼拝した。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="ヨハネの黙示録 18:7; テサロニケ人への手紙第一 5:3; エレミヤ書 48:44"> それからサムエルは言った。「アマレクの王アガグをわたしのところに連れて来なさい。」アガグは悠然と彼のもとにやって来た。アガグは言った。「確かに死の苦しみは過ぎ去った。」</span>
<span className="v" id="v33" data-v="33" data-xref="士師記 1:7; 創世記 9:6; マタイ 7:2"> サムエルは言った。「おまえの剣が女たちを子なしにしたように、おまえの母も女たちの中で子なしとなる。」そしてサムエルはギルガルで、主の御前でアガグを切り刻んだ。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="サムエル記第一 11:4; サムエル記第一 7:17"> それからサムエルはラマへ行き、サウルはサウルのギベアにある自分の家へ上って行った。</span>
<span className="v" id="v35" data-v="35" data-xref="サムエル記第一 15:11; サムエル記第一 19:24; サムエル記第一 16:1"> サムエルは死ぬ日まで二度とサウルに会わなかったが、サムエルはサウルのために悲しんだ。主はサウルをイスラエルの王としたことを悲しまれた。</span>
</div>
</div>

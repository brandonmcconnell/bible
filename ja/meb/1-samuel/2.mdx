</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="詩篇 76:3; 詩篇 37:15; 詩篇 46:9"> <span className="pl pl-1">勇士たちの弓は折られ、</span><br /><span className="pl pl-2">つまずく者は力を帯びる。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 15:9; ルカ 1:53; 詩篇 113:9"> <span className="pl pl-1">満ち足りていた者はパンのために身を雇い、</span><br /><span className="pl pl-2">飢えていた者はもはや飢えない。</span><br /><span className="pl pl-1">不妊の女は七人の子を産み、</span><br /><span className="pl pl-2">多くの子を持つ女は衰える。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="申命記 32:39; イザヤ書 26:19; ヨハネの黙示録 1:18"> <span className="pl pl-1">主は殺し、また生かす。</span><br /><span className="pl pl-2">よみ</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「よみ」は死者の場所を指す。">a</a></sup><br /><span className="pl pl-2">に下らせ、また引き上げる。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="詩篇 75:7; ヨブ記 5:11; 申命記 8:17–18"> <span className="pl pl-1">主は貧しくし、また富ませる。</span><br /><span className="pl pl-2">低くし、また高く上げる。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="詩篇 113:7–8; ダニエル書 2:48; ヤコブの手紙 2:5"> <span className="pl pl-1">主は貧しい者をちりから起こし、</span><br /><span className="pl pl-2">乏しい者をごみの山から引き上げる。</span><br /><span className="pl pl-1">彼らを君主たちとともに座らせ、</span><br /><span className="pl pl-2">栄光の座を受け継がせる。</span><br /><span className="pl pl-1">地の柱は主のもの。</span><br /><span className="pl pl-2">主はその上に世界を据えられた。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="詩篇 121:3; 詩篇 91:11–12; 詩篇 33:16–17"> <span className="pl pl-1">主は聖なる者たちの足を守る。</span><br /><span className="pl pl-2">しかし悪者は暗闇の中で沈黙する。</span><br /><span className="pl pl-2">人は力によって勝つのではない。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="詩篇 2:9; 詩篇 89:24; 詩篇 18:13–14"> <span className="pl pl-1">主と争う者は打ち砕かれる。</span><br /><span className="pl pl-2">主は天から彼らに雷をとどろかす。</span><br /><span className="pl pl-1">主は地の果てをさばき、</span><br /><span className="pl pl-2">その王に力を与え、</span><br /><span className="pl pl-2">油注がれた者の角を高く上げる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="サムエル記第一 3:1; サムエル記第一 2:18; サムエル記第一 1:28"> エルカナはラマにある自分の家へ行った。その子どもは祭司エリの前で主に仕えた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 1:28–30; エレミヤ書 2:8; 士師記 2:10"> さて、エリの息子たちはならず者であった。彼らは主を知らなかった。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 7:29–34"> 祭司たちが民に対して行っていた慣習はこうであった。だれかがいけにえを献げ、肉を煮ている時、祭司のしもべが三つ又の肉刺しを手に持って来て、</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 29:27–28; イザヤ書 56:11; サムエル記第一 2:29"> それを鉢、釜、大釜、鍋に突き入れた。肉刺しが引き上げたものはすべて、祭司が自分のために取った。彼らはシロに来るすべてのイスラエル人にそのように行った。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 3:16; レビ記 3:3–5; ローマ人への手紙 16:18"> それだけでなく、彼らが脂肪を焼く前にも、祭司のしもべが来て、いけにえを献げる人に言った。「祭司に焼くための肉を渡しなさい。祭司はあなたから煮た肉ではなく、生の肉を受け取るからだ。」</span>
<span className="v" id="v16" data-v="16" data-xref="レビ記 7:23–25; レビ記 3:16; ペテロの手紙第一 5:2–3"> もしその人が彼に、「まず脂肪を焼かせてください。その後で、あなたが望むだけ取りなさい」と言えば、彼は「いや、今すぐ渡さなければならない。もしそうしないなら、力ずくで奪い取る」と言った。</span>
<span className="v" id="v17" data-v="17" data-xref="マラキ書 2:7–9; 創世記 13:13; マラキ書 2:13"> それゆえ、その若者たちの罪は主の御前で非常に大きかった。人々が主のささげ物を侮ったからである。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="サムエル記第一 3:1; 出エジプト記 28:4; サムエル記第一 2:11"> しかしサムエルは、まだ子どもであったが、亜麻布のエポデを身に着けて主の御前で仕えていた。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記第一 1:3; サムエル記第一 1:21; 出エジプト記 23:14"> 彼の母は彼のために小さな上着を作り、年ごとのいけにえを献げるために夫とともに上って行くたびに、それを彼に持って行った。</span>
<span className="v" id="v20" data-v="20" data-xref="サムエル記第一 1:27–28; ルカ 2:34; ルツ記 4:11"> エリはエルカナとその妻を祝福して言った。「主に願い求めてささげたこの子の代わりに、主がこの女によってあなたに子ども<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または「種」。">b</a></sup>を与えてくださるように。」そして彼らは自分の家に帰って行った。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカ 2:40; サムエル記第一 3:19; 創世記 21:1"> 主がハンナを顧みられたので、彼女は身ごもり、三人の息子と二人の娘を産んだ。子どものサムエルは主の御前で成長した。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 38:8; サムエル記第一 2:13–17; エレミヤ書 7:9–10"> さて、エリは非常に年をとっていた。彼は自分の息子たちが全イスラエルに対して行っているすべてのことや、会見の天幕の入り口で奉仕する女たちと寝ていることを聞いた。</span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 8:12; ピリピ人への手紙 3:19; 使徒の働き 9:4"> 彼は彼らに言った。「なぜおまえたちはこのようなことをするのか。わたしはこれらすべての民から、おまえたちの悪行を聞いている。</span>
<span className="v" id="v24" data-v="24" data-xref="マラキ書 2:8; テモテへの手紙第一 3:7; 使徒の働き 6:3"> わたしの息子たちよ、それはいけない。わたしが聞くうわさは良いものではない。おまえたちは主の民を罪に陥れている。</span>
<span className="v" id="v25" data-v="25" data-xref="サムエル記第一 3:14; ヨシュア記 11:20; ヘブル人への手紙 10:26"> もし人が人に対して罪を犯したなら、神がその人をさばかれるだろう。しかし、もし人が主に対して罪を犯したなら、だれがその人のために執り成しをするだろうか。」それにもかかわらず、彼らは父の声に聞き入れなかった。主が彼らを死に定めておられたからである。</span>
<span className="v" id="v26" data-v="26" data-xref="ルカ 2:52; ルカ 2:40; 使徒の働き 2:47"> 子どものサムエルはますます成長し、主にも人々にもますます恵みを得ていった。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="申命記 33:1; 出エジプト記 4:27; 出エジプト記 4:14–16"> ある神の人がエリのもとに来て彼に言った。「主はこう言われる。『あなたの父の家がエジプトでファラオの家の奴隷であった時、わたしは確かに彼らに自分を現したではないか。</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 28:1; レビ記 8:7–8; 民数記 18:19"> わたしは彼をイスラエルのすべての部族の中から選んでわたしの祭司とし、わたしの祭壇に上り、香をたき、わたしの前でエポデを身に着けるようにしたではないか。わたしはあなたの父の家に、イスラエルの人々が火で献げるすべてのささげ物を与えたではないか。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイ 10:37; 申命記 32:15; サムエル記第一 2:13–17"> なぜおまえたちは、わたしがわたしの住まいで命じたいけにえとささげ物を足で踏みつけ、わたしよりも自分の息子たちを重んじて、わたしの民イスラエルのすべてのささげ物のうち最も良い部分で自分たちを肥え太らせるのか。』</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネ 12:26; エレミヤ書 18:9–10; 箴言 3:9–10"> それゆえ、イスラエルの神、主は言われる。『わたしは確かに、あなたの家とあなたの父の家が、いつまでもわたしの前を歩むと言った。』しかし今、主は言われる。『断じてそうではない。わたしをあがめる者をわたしはあがめ、わたしを侮る者は軽んじられるからである。</span>
<span className="v" id="v31" data-v="31" data-xref="サムエル記第一 22:17–20; 列王記第一 2:26–27; 詩篇 37:17"> 見よ、わたしがあなたの腕とあなたの父の家の腕を切り落とし、あなたの家には老人がいなくなる日が来る。</span>
<span className="v" id="v32" data-v="32" data-xref="ゼカリヤ書 8:4; サムエル記第一 4:11; 詩篇 78:59–64"> あなたは、わたしがイスラエルに与えるあらゆる幸いのただ中で、わたしの住まいに臨む苦難を見る。あなたの家にはいつまでも老人がいないであろう。</span>
<span className="v" id="v33" data-v="33" data-xref="列王記第一 2:26–27; 列王記第一 1:7; サムエル記第一 22:21–23"> わたしがわたしの祭壇から断ち切らずに残すあなたの家の者は、あなたの目を衰えさせ<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="または「あなたの目を涙で見えなくさせ」">c</a></sup>、あなたの心を悲しませる。あなたの家に生まれる者は皆、若盛りのうちに死ぬ。</span>
<span className="v" id="v34" data-v="34" data-xref="サムエル記第一 4:11; 列王記第一 13:3; サムエル記第一 4:17"> あなたの二人の息子、ホフニとピネハスに臨むことが、あなたに対するしるしとなる。彼らは一日のうちに二人とも死ぬであろう。</span>
<span className="v" id="v35" data-v="35" data-xref="サムエル記第二 7:27; サムエル記第二 7:11; 列王記第一 11:38"> わたしは自分のために忠実な祭司を起こす。彼はわたしの心と思いにあるとおりに行う。わたしは彼のために確かな家を建て、彼はわたしが油注いだ者の前をいつまでも歩む。</span>
<span className="v" id="v36" data-v="36" data-xref="列王記第一 2:27; マラキ書 1:13; エゼキエル書 44:10–12"> あなたの家に残された者は皆、来て銀の一枚とパンの一塊のために彼にひれ伏し、「どうか、わたしがパンの一切れを食べられるように、わたしを祭司の職務の一つに就かせてください」と言うであろう。』」</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 15:44; ミカ書 6:15; ネヘミヤ記 3:17–18"> 人々がダビデに告げて言った。「見よ、ペリシテ人がケイラと戦い、打ち場を略奪しています。」</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記第一 23:4; サムエル記第二 5:19; サムエル記第二 5:23"> それゆえダビデは主に尋ねて、「わたしは行って、これらペリシテ人を打つべきでしょうか」と言った。<br />主はダビデに言われた。「行ってペリシテ人を打ち、ケイラを救いなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 12:5; 詩篇 11:1; サムエル記第一 23:15"> ダビデの人々は彼に言った。「見よ、私たちはここユダで恐れています。ましてケイラへ行き、ペリシテ人の軍勢に向かうなら、なおさらではありませんか。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士師記 7:7; ヨシュア記 8:7; 列王記第二 3:18"> そこでダビデは再び主に尋ねた。主は彼に答えて言われた。「立ち上がり、ケイラへ下って行きなさい。わたしはペリシテ人をあなたの手に渡すからである。」</span>
<span className="v" id="v5" data-v="5"> ダビデと彼の人々はケイラへ行ってペリシテ人と戦い、彼らの家畜を奪い取り、彼らに大打撃を与えた。こうしてダビデはケイラの住民を救った。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記第一 22:20; サムエル記第一 14:3; サムエル記第一 14:18"> アヒメレクの子アビアタルがケイラにいるダビデのもとへ逃げて来た時、彼は手にエポデを持って下って来た。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="サムエル記第一 24:4–6; ヨブ記 20:5; サムエル記第一 26:8–9"> サウルは、ダビデがケイラに来たことを告げられた。サウルは言った。「神が彼をわたしの手に渡されたのだ。彼は扉と門の貫の木がある町に入って、閉じ込められたからだ。」</span>
<span className="v" id="v8" data-v="8"> サウルは戦いのためにすべての民を呼び集め、ダビデと彼の人々を包囲するためにケイラへ下って行こうとした。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="サムエル記第一 30:7; サムエル記第一 23:6; 民数記 27:21"> ダビデは、サウルが自分に対して悪をたくらんでいるのを知り、祭司アビアタルに言った。「ここにエポデを持って来なさい。」</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 3:15–16; サムエル記第一 23:8; 創世記 18:24"> それからダビデは言った。「ああ、イスラエルの神、主よ。サウルがわたしのゆえに町を滅ぼそうと、ケイラに来ようとしていることを、あなたのしもべは確かに聞きました。</span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 33:3; 詩篇 50:15; マタイ 7:7–8"> ケイラの人々は、わたしを彼の手に引き渡すでしょうか。あなたのしもべが聞いたように、サウルは下って来るでしょうか。ああ、イスラエルの神、主よ。どうか、あなたのしもべに教えてください。」<br />主は言われた。「彼は下って来る。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="サムエル記第一 23:20; 詩篇 31:8; 詩篇 62:1"> それからダビデは言った。「ケイラの人々は、わたしとわたしの人々をサウルの手に引き渡すでしょうか。」<br />主は言われた。「彼らはあなたがたを引き渡すであろう。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="サムエル記第一 22:2; サムエル記第一 25:13; サムエル記第一 30:9–10"> そこでダビデと彼の人々、約六百人は立ち上がり、ケイラを出発し、行ける所へ行った。サウルはダビデがケイラから逃げたことを告げられ、そこへ行くのをやめた。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 54:3–4; 詩篇 32:7; ヨシュア記 15:24"> ダビデは荒野の要害に留まり、ジフの荒野の山地に留まった。サウルは毎日彼を探したが、神は彼をサウルの手に渡されなかった。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> ダビデは、サウルが自分の命を狙って出て来たのを見た。ダビデはジフの荒野の森にいた。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 35:3–4; ヘブル人への手紙 12:12–13; ヨブ記 4:3–4"> サウルの子ヨナタンは立ち上がり、森にいるダビデのところへ行き、神にあって彼を力づけた。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記第一 20:31; サムエル記第一 24:20; 使徒の働き 28:16"> 彼は彼に言った。「恐れることはない。わたしの父サウルの手があなたを見つけることはない。あなたはイスラエルの王となり、わたしはあなたの次に立つ。わたしの父サウルもまた、そのことを知っている。」</span>
<span className="v" id="v18" data-v="18" data-xref="サムエル記第二 21:7; サムエル記第一 20:42; サムエル記第一 18:3"> 二人は主の御前で契約を結んだ。ダビデは森に留まり、ヨナタンは自分の家へ帰った。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="サムエル記第一 26:1; サムエル記第一 26:3; 詩篇 54:1–7"> その時、ジフ人たちがギベアのサウルのところに上って来て言った。「ダビデは荒野の南にあるハキラの丘の森の要害で、私たちと一緒に身を隠しているではありませんか。</span>
<span className="v" id="v20" data-v="20" data-xref="サムエル記第一 23:12; 箴言 29:26; 箴言 11:23"> それゆえ今、王よ。王が心から望まれるとおり下って来てください。彼を王の手に引き渡すのは私たちの務めです。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="サムエル記第一 22:8; イザヤ書 66:5; ミカ書 3:11"> サウルは言った。「あなたがたが主に祝福されるように。あなたがたはわたしをあわれんでくれたからだ。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨブ記 5:13"> どうか行って、さらに確かめ、彼のいる場所と、そこで彼を見た者を知り、見定めなさい。彼は非常に狡猾であると聞いているからだ。</span>
<span className="v" id="v23" data-v="23" data-xref="ローマ人への手紙 3:15–16; マルコ 14:1; 民数記 10:36"> したがって、彼が身を隠しているすべての潜伏場所を見定めて、確かな情報を持ってわたしのところに戻って来なさい。そうすればわたしはあなたがたと一緒に行く。もし彼がその地にいるなら、わたしはユダのすべての氏族の中から彼を探し出すであろう。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="サムエル記第一 25:2; ヨシュア記 15:55"> 彼らは立ち上がり、サウルより先にジフへ行った。しかしダビデと彼の人々は、荒野の南の、アラバにあるマオンの荒野にいた。</span>
<span className="v" id="v25" data-v="25" data-xref="士師記 15:8; サムエル記第一 23:28"> サウルと彼の人々は彼を探しに行った。それがダビデに告げられると、彼は岩へ下って行き、マオンの荒野に留まった。サウルはそれを聞くと、マオンの荒野でダビデを追撃した。</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 17:9; コリント人への第二の手紙 1:8; 詩篇 140:1–9"> サウルは山のこちら側を行き、ダビデと彼の人々は山のあちら側を行った。ダビデは急いでサウルから逃れようとした。サウルと彼の人々が、ダビデと彼の人々を捕らえようと包囲していたからである。</span>
<span className="v" id="v27" data-v="27" data-xref="列王記第二 19:9; 詩篇 116:3; 申命記 32:36"> しかし、使者がサウルのところに来て言った。「急いで来てください。ペリシテ人がこの地に襲撃をかけました。」</span>
<span className="v" id="v28" data-v="28"> そこでサウルはダビデの追撃から引き返し、ペリシテ人を迎え撃ちに行った。それゆえ人々はその場所をセラ・ハマレコテ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「セラ・ハマレコテ」は「分かれの岩」を意味する。">a</a></sup>と呼んだ。</span>
<span className="v" id="v29" data-v="29" data-xref="歴代誌 第二 20:2; ヨシュア記 15:62; エゼキエル書 47:10"> ダビデはそこから上って行き、エン・ゲディの要害に住んだ。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 12:5; ミカ書 6:6"> サウルは王となった時、三十歳であり、イスラエルを四十二年治めた。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="伝統的なヘブル語本文では「三十」と「四十」が欠けている。ここでは七十人訳のいくつかの写本に基づいて空所を補っている。">a</a></sup></span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記第一 10:26; サムエル記第一 13:5; サムエル記第一 14:31"> サウルは自分のためにイスラエルのうちから三千人を選んだ。そのうち二千人はミクマスとベテルの山地でサウルとともにおり、一千人はベニヤミンのギベアでヨナタンとともにおり、残りの民はそれぞれ自分の天幕に帰らせた。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記第一 10:5; 士師記 3:27; 士師記 6:34"> ヨナタンはゲバにいたペリシテ人の守備隊を打ったので、ペリシテ人はそれを聞いた。サウルは全地に角笛を吹き鳴らして、「ヘブル人よ、聞け」と言った。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 34:30; 出エジプト記 5:21; ゼカリヤ書 11:8"> 全イスラエルは、サウルがペリシテ人の守備隊を打ったこと、またイスラエルがペリシテ人に憎まれるようになったことを聞いた。民はサウルの後に従ってギルガルに集められた。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="サムエル記第一 14:23; ヨシュア記 11:4; ヨシュア記 18:12"> ペリシテ人はイスラエルと戦うために集まった。戦車三万両、騎兵六千人、また民は海辺にある砂のように大群であった。彼らは上って来て、ベテ・アベンの東にあるミクマスに陣を敷いた。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 6:2; ヘブル人への手紙 11:38; 士師記 10:9"> イスラエルの男たちは、自分たちが窮地にあり、民が追い詰められているのを見て、ほら穴、やぶ、岩、墓、そして穴の中に隠れた。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 20:8; レビ記 26:17; 民数記 32:1–5"> また何人かのヘブル人はヨルダン川を渡ってガドとギレアデの地へ行った。しかしサウルはまだギルガルにおり、すべての民は震えながら彼の後に従った。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="サムエル記第一 10:8"> 彼はサムエルが定めた日時に従って七日の間待ったが、サムエルはギルガルに来なかった。そして民は彼から離れて散って行った。</span>
<span className="v" id="v9" data-v="9" data-xref="列王記第一 3:4; 箴言 21:27; 箴言 15:8"> サウルは言った。「全焼のささげ物と和解のいけにえをわたしのところに持って来なさい。」そして彼は全焼のささげ物を献げた。</span>
<span className="v" id="v10" data-v="10" data-xref="サムエル記第一 15:13; ルツ記 2:4; 詩篇 129:8"> 彼が全焼のささげ物を献げ終えるとすぐに、見よ、サムエルが来た。サウルは彼を迎えに出て、彼に挨拶した。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="サムエル記第一 13:23; サムエル記第一 13:5; サムエル記第一 13:16"> サムエルは言った。「あなたは何ということをしたのか。」<br />サウルは言った。「民がわたしから離れて散って行き、あなたが定められた日時のうちに来ず、ペリシテ人がミクマスに集まっていたのを見たので、</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 66:3; アモス書 8:5; コリント人への第二の手紙 9:7"> わたしは『今、ペリシテ人はギルガルのわたしのところに下って来るのに、わたしはまだ主の恵みを求めていない』と考えたからです。それゆえ、わたしは自らを強いて、全焼のささげ物を献げました。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="サムエル記第一 15:22; 歴代誌 第二 16:9; サムエル記第一 15:28"> サムエルはサウルに言った。「あなたは愚かなことをした。あなたはあなたの神、主があなたに命じられた命令を守らなかった。もし守っていたなら、主は今、イスラエルにおけるあなたの王権を永遠に堅く立てられたであろうに。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 13:22; サムエル記第一 15:28; 詩篇 89:19–37"> しかし今、あなたの王権は続かない。主はご自分の心にかなう人を求め、主は彼をその民の君主として立てられた。あなたが主が命じられたことを守らなかったからである。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="サムエル記第一 14:2; サムエル記第一 13:2; サムエル記第一 13:6–7"> サムエルは立ち上がり、ギルガルからベニヤミンのギベアへ上って行った。サウルは自分と一緒にいる民を数えたところ、約六百人であった。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記第一 13:3"> サウルと、その子ヨナタンと、彼らと一緒にいる民はベニヤミンのゲバに留まっていたが、ペリシテ人はミクマスに陣を敷いていた。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨシュア記 18:23; サムエル記第一 14:15; ヨシュア記 19:3"> 略奪隊がペリシテ人の陣営から三つの部隊に分かれて出て来た。一つの部隊はシュアルの地にあるオフラへの道に向かい、</span>
<span className="v" id="v18" data-v="18" data-xref="ネヘミヤ記 11:34; ヨシュア記 18:13–14; ヨシュア記 16:3"> 一つの部隊はベテ・ホロンへの道に向かい、もう一つの部隊は荒野に向かうツェボイムの谷を見下ろす境界への道に向かった。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王記第二 24:14; 士師記 5:8; エレミヤ書 24:1"> その頃、イスラエルの全地には鍛冶屋がいなかった。ペリシテ人が「ヘブル人が剣や槍を作るかもしれない」と言ったからである。</span>
<span className="v" id="v20" data-v="20"> すべてのイスラエル人は、それぞれのすき先の刃、くわ、斧、およびかまを研ぐためにペリシテ人のところへ下って行った。</span>
<span className="v" id="v21" data-v="21"> すき先、くわ、三つ又の農具、斧を研ぎ、牛追い棒を直す料金は、それぞれ一パイム<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一パイムは銀三分の二シェケルで、約7.6グラム、または0.26オンスである。">b</a></sup>であった。</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 5:8; ゼカリヤ書 4:6; サムエル記第一 17:50"> それゆえ、戦いの日には、サウルおよびヨナタンと一緒にいるすべての民の手には剣も槍も見当たらず、ただサウルとその子ヨナタンにのみ見られた。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 10:28; サムエル記第一 14:1; サムエル記第一 14:4–5"> ペリシテ人の守備隊はミクマスの道へ出て行った。</span>
</div>
</div>

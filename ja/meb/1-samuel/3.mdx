<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="アモス書 8:11–12; 詩篇 74:9; サムエル記第一 3:21"> 子どものサムエルはエリの前で主に仕えていた。その頃、主の言葉はまれで、幻もほとんどなかった。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記第一 4:15; 詩篇 90:10; 創世記 27:1"> その頃、エリは自分の場所で横になっていた。彼の目はかすみ始め、見ることができなかった。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 27:4; レビ記 24:2–4; 出エジプト記 27:20–21"> 神のともしびはまだ消えておらず、サムエルは神の箱がある主の神殿で横になっていた。</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 6:8; コリント人への第一の手紙 12:6–11; 出エジプト記 3:4"> その時、主はサムエルを呼ばれた。彼は「はい、ここにおります」と言った。</span>
<span className="v" id="v5" data-v="5"> 彼はエリのところに走って行き、「はい、ここにおります。あなたがわたしを呼ばれたからです」と言った。<br />エリは「わたしは呼んでいない。戻って寝なさい」と言った。そこで彼は行って横になった。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="マタイ 9:2; サムエル記第一 4:16; サムエル記第二 18:22"> 主は再び「サムエルよ」と呼ばれた。<br />サムエルは起きてエリのところに行き、「はい、ここにおります。あなたがわたしを呼ばれたからです」と言った。<br />彼は答えた。「わたしは呼んでいない、わたしの子よ。戻って寝なさい。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 19:2; エレミヤ書 9:24"> サムエルはまだ主を知らず、主の言葉もまだ彼に啓示されていなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨブ記 33:14–15; コリント人への第一の手紙 13:11–12"> 主は三度目に再びサムエルを呼ばれた。彼は起きてエリのところに行き、「はい、ここにおります。あなたがわたしを呼ばれたからです」と言った。<br />エリはその時、主がその子を呼んでおられることを悟った。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 20:19; イザヤ書 6:8; 詩篇 85:8"> そこでエリはサムエルに言った。「行って横になりなさい。もし主があなたを呼ばれたら、あなたは『主よ、お話しください。しもべは聞いております』と言いなさい。」こうしてサムエルは行って自分の場所で横になった。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="サムエル記第一 3:8; サムエル記第一 3:4–6"> 主が来て立たれ、他の時のように「サムエルよ、サムエルよ」と呼ばれた。<br />するとサムエルは言った。「お話しください。しもべは聞いております。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ハバクク書 1:5; エレミヤ書 19:3; 列王記第二 21:12"> 主はサムエルに言われた。「見よ、わたしはイスラエルにおいて一つのことを行う。それを聞く者は皆、両耳が鳴るであろう。</span>
<span className="v" id="v12" data-v="12" data-xref="サムエル記第一 2:27–36; ゼカリヤ書 1:6; ヨシュア記 23:15"> その日、わたしはエリの家についてわたしが語ったすべてのことを、初めから終わりまでエリに対して実行する。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 19:18; マタイ 10:37; サムエル記第一 2:12"> わたしは彼に、彼の家を永遠にさばくことを告げた。それは彼が知っている咎のためである。彼の息子たちが自分たちの上にのろいを招いたのに、彼が彼らを戒めなかったからである。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 22:14; サムエル記第一 2:25; エレミヤ書 15:1"> それゆえ、わたしはエリの家について誓った。エリの家の咎は、いけにえやささげ物によって永遠に取り除かれることはない。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 1:6–8; マラキ書 1:10; サムエル記第一 1:9"> サムエルは朝まで横たわり、主の家の戸を開けた。サムエルはその幻をエリに告げることを恐れた。</span>
<span className="v" id="v16" data-v="16"> しかしエリはサムエルを呼んで言った。「サムエル、わたしの子よ。」<br />彼は「はい、ここにおります」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="サムエル記第二 3:35; ルツ記 1:17; 詩篇 141:5"> エリは言った。「主があなたに語られた言葉は何であったか。どうか、わたしに隠さないでほしい。もし主があなたに語られたすべての言葉のうち、一つでもわたしに隠すなら、神があなたにそうされ、さらにそれ以上のことをされるように。」</span>
<span className="v" id="v18" data-v="18" data-xref="ヨブ記 2:10; イザヤ書 39:8; 士師記 10:15"> サムエルは彼にすべてを告げ、彼に何も隠さなかった。<br />彼は言った。「主である。主のよいと思われることを、主がなさるがよい。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 39:2; サムエル記第一 9:6; 列王記第一 8:56"> サムエルは成長し、主は彼とともにおられ、彼のどの言葉も地に落ちることはなかった。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 20:1; サムエル記第二 3:10; テモテへの手紙第一 1:12"> ダンからベエル・シェバに至るまでの全イスラエルは、サムエルが主の預言者として立てられたことを知った。</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記第一 3:1; 創世記 12:7; サムエル記第一 3:4"> 主は再びシロに現れられた。主はシロで、主の言葉によってご自身をサムエルに現された。</span>
</div>
</div>

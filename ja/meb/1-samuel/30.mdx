<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記第一 15:7; サムエル記第一 29:11; サムエル記第一 27:8–10"> 三日目に、ダビデとその人々がツィクラグに来た時、アマレク人は南とツィクラグに襲撃をかけていた。彼らはツィクラグを打ち、火で燃やし、</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記第一 27:11; ヨブ記 38:11; 詩篇 76:10"> その中にいた女たちと、小さい者から大きい者まで、すべての人を捕虜にしていた。彼らは一人も殺さず、人々を連れ去って自分たちの道を行っていた。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 34:19; ペテロの手紙第一 1:6–7; ヨハネの黙示録 3:9"> ダビデとその人々が町に来ると、見よ、町は火で燃やされ、彼らの妻、息子、娘たちは捕虜となっていた。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記第一 11:4; 民数記 14:1; 士師記 21:2"> そこでダビデと彼とともにいた民は、もはや泣く力がなくなるまで声を上げて泣いた。</span>
<span className="v" id="v5" data-v="5" data-xref="サムエル記第一 25:42–43; サムエル記第二 2:2; サムエル記第一 1:2"> ダビデの二人の妻、エズレル人アヒノアムと、カルメル人ナバルの妻であったアビガイルも捕虜となっていた。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 56:3–4; 詩篇 56:11; 詩篇 62:5"> 民が皆、それぞれ自分の息子と娘のことで悲しみに苦しみ、ダビデを石で打とうと言ったため、ダビデは非常に苦しんだ。しかしダビデは、彼の神、主にあって自らを強めた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王記第一 2:26; サムエル記第一 22:20–21; サムエル記第一 23:2–9"> ダビデはアヒメレクの子である祭司アビアタルに言った。「どうか、エポデをわたしのところに持って来てください。」アビアタルはエポデをダビデのところに持って来た。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記第一 30:18; 箴言 3:5–6; サムエル記第一 23:2"> ダビデは主に尋ねて言った。「わたしはこの略奪隊を追撃すべきでしょうか。彼らに追いつけるでしょうか。」<br />主は彼に答えられた。「追撃せよ。あなたは必ず彼らに追いつき、間違いなくすべてを取り戻す。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="サムエル記第一 27:2"> そこでダビデは、彼とともにいた六百人とともに出発し、ベソル川に来た。疲れて後に残った者たちは、そこにとどまった。</span>
<span className="v" id="v10" data-v="10" data-xref="サムエル記第一 30:9; サムエル記第一 30:21; サムエル記第一 14:31"> しかしダビデは、彼と四百人で追撃を続けた。二百人は、疲れ果ててベソル川を渡ることができず、後に留まったからである。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 12:20–21; 申命記 23:7; マタイ 25:35"> 彼らは野で一人のエジプト人を見つけ、彼をダビデのところに連れて来た。彼らがパンを与えると、彼は食べ、彼らは彼に水を飲ませた。</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 15:19; サムエル記第一 14:27; サムエル記第一 30:13"> また、いちじくの菓子の一切れと、干しぶどう二房を与えた。彼がそれを食べると、彼は元気を取り戻した。彼は三日三晩、パンも食べず、水も飲んでいなかったからである。</span>
<span className="v" id="v13" data-v="13" data-xref="ヤコブの手紙 2:13; 箴言 12:10; ヨブ記 31:13–15"> ダビデは彼に言った。「あなたはだれのものか。どこから来たのか。」<br />彼は言った。「わたしはエジプト人の若者で、アマレク人の奴隷です。三日前に病気になったため、主人はわたしを置き去りにしました。</span>
<span className="v" id="v14" data-v="14" data-xref="列王記第一 1:38; サムエル記第二 8:18; 列王記第一 1:44"> 私たちはケレテ人の南と、ユダに属する地と、カレブの南に襲撃をかけ、ツィクラグを火で燃やしました。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 2:12; ヨシュア記 9:19–20; エゼキエル書 17:16"> ダビデは彼に言った。「わたしをその略奪隊のところへ連れて下ってくれるか。」<br />彼は言った。「わたしを殺さず、また主人の手に引き渡さないと、神にかけてわたしに誓ってください。そうすれば、あなたをこの略奪隊のところへ連れて下りましょう。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 11:10–13; サムエル記第二 13:28; 士師記 16:23–30"> 彼がダビデを連れて下ると、見よ、彼らは地一面に広がって、飲み食いし、踊っていた。ペリシテ人の地とユダの地から奪い取った非常に多くの分捕り品のためであった。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記第一 11:11; 詩篇 18:42; サムエル記第一 15:3"> ダビデは夕暮れから翌日の夕方まで彼らを打った。彼らのうち、らくだに乗って逃げた四百人の若者たちのほかには、一人も逃れなかった。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 14:16"> ダビデはアマレク人が奪い去ったすべてのものを取り戻した。ダビデは二人の妻も救い出した。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 91:9–10; サムエル記第一 30:8; ヨブ記 1:10"> 小さい者から大きい者まで、息子も娘も、分捕り品も、彼らが奪い去ったものも、何一つ欠けるものはなかった。ダビデはすべてを取り戻した。</span>
<span className="v" id="v20" data-v="20" data-xref="サムエル記第一 30:26; 民数記 31:9–12; 歴代誌 第二 20:25"> ダビデはすべての羊と牛を取った。人々はそれらの家畜をほかの家畜の前で追い立て、「これはダビデの分捕り品だ」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ヘブル人への手紙 13:1; サムエル記第一 30:10; 士師記 8:15"> ダビデは、疲れ果ててダビデについて行くことができず、ベソル川に留まらせておいた二百人のところに来た。彼らはダビデを迎え、また彼とともにいる民を迎えるために出て来た。ダビデが彼らに近づくと、彼らに挨拶した。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイ 7:12; 申命記 13:13; 列王記第一 21:10"> すると、ダビデとともに行った者たちのうちの悪意あるならず者たちが答えた。「彼らは私たちとともに行かなかったのだから、私たちが取り戻した分捕り品は彼らに与えない。ただ、それぞれが自分の妻と子どもたちを連れて去るのはよい。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="申命記 8:18; 詩篇 44:2–7; 使徒の働き 7:2"> しかしダビデは言った。「わたしの兄弟たちよ、主が私たちに与えてくださったものについて、あなたがたはそのようにしてはならない。主は私たちを守り、私たちに向かって来た略奪隊を私たちの手に渡されたのだ。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨシュア記 22:8; 民数記 31:27; 詩篇 68:12"> この事について、だれがあなたがたの言うことに聞き従うだろうか。戦いに下って行った者の分は、荷物のそばに留まった者の分と同じである。彼らは同じように分け合わなければならない。」</span>
<span className="v" id="v25" data-v="25" data-xref="サムエル記第一 16:13"> その日以来、ダビデはそれをイスラエルのための掟と定めとしたので、今日に至るまでそうなっている。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="サムエル記第一 25:27; 創世記 33:11; イザヤ書 32:8"> ダビデはツィクラグに来ると、分捕り品の一部を彼の友人であるユダの長老たちに送って言った。「見よ、主の敵からの分捕り品の一部を、あなたがたへの贈り物とします。」</span>
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 15:48; ヨシュア記 19:8; 士師記 1:22–23"> それは、ベテルにいる人々、南のラモテにいる人々、ヤティルにいる人々、</span>
<span className="v" id="v28" data-v="28" data-xref="ヨシュア記 13:16; ヨシュア記 15:50; ヨシュア記 21:14"> アロエルにいる人々、シフモテにいる人々、エシュテモアにいる人々、</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 1:16; サムエル記第一 27:10; サムエル記第一 15:6"> ラカルにいる人々、エラフメル人の町々にいる人々、ケニ人の町々にいる人々、</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 1:17; ヨシュア記 19:4; ヨシュア記 15:42"> ホルマにいる人々、ボラシャンにいる人々、アタクにいる人々、</span>
<span className="v" id="v31" data-v="31" data-xref="サムエル記第二 2:1; サムエル記第二 15:10; サムエル記第二 4:1"> ヘブロンにいる人々、そしてダビデとその人々がかつて留まっていたすべての場所にいる人々に送られた。</span>
</div>

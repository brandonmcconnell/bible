<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="NUM" data-book-slug="numbers" data-book-name="民数記" data-chapter="10" data-verses="36">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 1:13; ヨエル書 1:14; 詩篇 81:3"> 「銀のラッパを二本、打ち出し細工で作りなさい。会衆を呼び集め、宿営を出発させるために用いる。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 4:5; ヨエル書 2:15–16"> 両方が吹き鳴らされると、全会衆は会見の天幕の入口にあるあなたのもとに集まる。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 7:2; 出エジプト記 18:21; 民数記 1:4–16"> もし一つだけ吹き鳴らされたなら、イスラエルの千人の部隊の長である指導者たちがあなたのもとに集まる。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 2:3–9; 民数記 10:14; イザヤ書 58:1"> 進軍の合図を吹き鳴らすと、東側に宿営している陣営が出発する。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 10:18; 民数記 2:10–16"> 二度目に進軍の合図を吹き鳴らすと、南側に宿営している陣営が出発する。陣営を出発させるときには、進軍の合図を吹き鳴らす。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨエル書 2:1; 民数記 10:3–4"> 会衆を集めるときにはラッパを吹き鳴らす。ただし、進軍の合図を鳴らしてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 6:4–16; 民数記 31:6; 歴代誌上 15:24"> 祭司であるアロンの子らがラッパを吹く。これは代々にわたる永遠の掟となる。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記第一 10:18; 士師記 2:18; 創世記 8:1"> あなたがたの地で、圧迫する敵と戦うときには、ラッパで進軍の合図を吹き鳴らす。そうすれば、あなたがたの神、主の前で覚えられ、敵から救われる。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="詩篇 81:3; テサロニケ人への手紙第一 4:16; コリント人への第一の手紙 11:24–26"> また、喜びの日、定められた祭り、月の初めに、全焼のささげ物と和解のいけにえをささげるとき、ラッパを吹き鳴らす。それは神の前であなたがたを覚えていただくためである。わたしはあなたがたの神、主である。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 40:17; 民数記 1:1; 民数記 9:11"> 第二年の第二の月の二十日に、証しの幕屋の上から雲が昇った。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 21:21; 民数記 12:16; 民数記 9:5"> イスラエルの子らはシナイの荒野を出て、行程を進めた。雲はパランの荒野にとどまった。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 1:6; 民数記 9:23"> 彼らは主がモーセを通して命じられたとおり、初めの行程に出た。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数記 2:3–9; 民数記 1:7; 民数記 7:12"> 先頭には、ユダの子らの宿営が旗を掲げ、部隊ごとに進んだ。その部隊を率いたのは、アミナダブの子ナフションであった。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 7:18; 民数記 1:8"> イッサカルの子らの部族の部隊の長は、ツアルの子ネタネルであった。</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 7:24; 民数記 1:9"> ゼブルンの子らの部族の部隊の長は、ヘロンの子エリアブであった。</span>
<span className="v" id="v17" data-v="17" data-xref="民数記 7:6–8; 民数記 1:51; ヘブル人への手紙 12:28"> 幕屋が取り外されると、それを担うゲルションの子らとメラリの子らが出発した。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 2:10–16; 民数記 1:5; 民数記 26:5–18"> 次に、ルベンの宿営が旗を掲げ、部隊ごとに出発した。その部隊を率いたのは、シェデウルの子エリツルであった。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 1:6; 民数記 7:36"> シメオンの子らの部族の部隊の長は、ツリシャダイの子シェルミエルであった。</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 1:14; 民数記 2:14; 民数記 7:42"> ガドの子らの部族の部隊の長は、デウエルの子エリアサフであった。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数記 10:17; 民数記 7:9; 民数記 4:4–16"> 次にケハテ人が聖なるものを担いで出発した。彼らが着く前に、幕屋は組み立てられた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数記 2:18–24; 民数記 1:10; 民数記 26:23–41"> 次に、エフライムの子らの宿営が旗を掲げ、部隊ごとに出発した。その部隊を率いたのは、アミフデの子エリシャマであった。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 1:10; 民数記 7:54"> マナセの子らの部族の部隊の長は、ペダツルの子ガマリエルであった。</span>
<span className="v" id="v24" data-v="24" data-xref="民数記 1:11; 民数記 7:60"> ベニヤミンの子らの部族の部隊の長は、ギデオニの子アビダンであった。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 6:9; 民数記 1:12; 創世記 49:16–17"> 最後に、すべての宿営のしんがりとして、ダンの子らの宿営が旗を掲げ、部隊ごとに出発した。その部隊を率いたのは、アミシャダイの子アヒエゼルであった。</span>
<span className="v" id="v26" data-v="26" data-xref="民数記 1:13; 民数記 7:72"> アシェルの子らの部族の部隊の長は、オクランの子パギエルであった。</span>
<span className="v" id="v27" data-v="27" data-xref="民数記 1:15; 民数記 7:78"> ナフタリの子らの部族の部隊の長は、エナンの子アヒラであった。</span>
<span className="v" id="v28" data-v="28" data-xref="民数記 2:34; 民数記 24:4–5; コリント人への第一の手紙 14:33"> 以上がイスラエルの子らの部隊ごとの行進順序であり、このようにして彼らは出発した。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="創世記 12:7; 士師記 4:11; 出エジプト記 3:1"> モーセは、しゅうとであるミディアン人レウエルの子ホバブに言った。「私たちは、主が『あなたがたに与える』と言われた場所へ向かっています。私たちと一緒に来てください。あなたによくします。主がイスラエルに幸いを約束しておられるからです。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ルツ記 1:15–17; 詩篇 45:10; マタイ 21:29"> 彼はモーセに言った。「私は行きません。自分の土地、私の親族のところへ帰ります。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ヨブ記 29:15; ガラテヤ人への手紙 6:2; コリント人への第一の手紙 12:14–21"> モーセは言った。「どうか私たちを離れないでください。あなたは荒野でどこに宿営すべきかを知っており、私たちの目となってくださるからです。</span>
<span className="v" id="v32" data-v="32" data-xref="士師記 1:16; 申命記 10:18; ヨハネの手紙第一 1:3"> もし私たちと一緒に来てくださるなら、主が私たちになさるどんな良いことも、私たちは同じようにあなたにいたします。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="申命記 1:33; 出エジプト記 3:1; 詩篇 95:11"> 彼らは主の山から三日の道のりを進んだ。主の契約の箱は、彼らの休む場所を探すため、三日の道のりを先頭に立って進んだ。</span>
<span className="v" id="v34" data-v="34" data-xref="ネヘミヤ記 9:12; ネヘミヤ記 9:19; 詩篇 105:39"> 彼らが宿営を出発するとき、昼は主の雲が彼らの上にあった。</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 68:1–2; イザヤ書 17:12–14; 詩篇 132:8"> 契約の箱が出発するとき、モーセは言った。「主よ、立ち上がってください。あなたの敵を散らし、あなたを憎む者を御前から逃れさせてください。」</span>
<span className="v" id="v36" data-v="36" data-xref="申命記 1:10; 詩篇 90:13–17; イザヤ書 63:17"> 箱がとどまるとき、モーセは言った。「主よ、イスラエルの幾万、幾千の民のもとへ戻ってください。」</span>
</div>
</div>

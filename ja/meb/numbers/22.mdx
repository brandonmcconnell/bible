<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="NUM" data-book-slug="numbers" data-book-name="民数記" data-chapter="22" data-verses="41">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 34:1; 申命記 3:8; 民数記 21:20"> イスラエルの子らは旅立ち、エリコの向かい、ヨルダン川の向こうにあるモアブの平野に宿営した。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 11:25; 民数記 21:20–35; 民数記 21:3"> ツィポルの子バラクは、イスラエルがアモリ人に行ったすべてのことを見た。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 15:15; イザヤ書 23:5; ヨシュア記 9:24"> モアブは、民の数が多いのを見て非常に恐れ、イスラエルの子らを前にしておびえた。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 25:15–18; 民数記 31:8; 民数記 24:17"> モアブはミディアンの長老たちに言った。「今にこの群衆は、牛が野の草をなめ尽くすように、私たちの周囲をすべてなめ尽くすだろう。」<br />ツィポルの子バラクは、そのころモアブの王であった。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 23:4; ヨシュア記 24:9; ミカ書 6:5"> 彼は、川のほとりのペトルにいるベオルの子バラムを呼ぶため、その同族の地へ使者を遣わした。「見よ、一つの民がエジプトから出て来て、地の面を覆い、私の向かいに住み着いている。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 24:9; 民数記 23:7–8; 使徒の働き 16:16"> どうか来て、私のためにこの民を呪ってほしい。彼らは私より強い。そうすれば、私は彼らを打ち、この地から追い出せるかもしれない。あなたが祝福する者は祝福され、呪う者は呪われると知っているからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="サムエル記第一 9:7–8; ミカ書 3:11; ローマ人への手紙 16:18"> モアブとミディアンの長老たちは、占いの報酬を手にして出発した。彼らはバラムのもとへ来て、バラクの言葉を伝えた。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="民数記 23:12; 民数記 22:19–20; エレミヤ書 12:2"> バラムは彼らに言った。「今夜はここに泊まりなさい。主が私に語られることを、あなたがたに知らせよう。」そこでモアブの指導者たちはバラムのもとにとどまった。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 20:3; 民数記 22:20; 創世記 16:8"> 神はバラムのもとに来て言われた。「あなたと一緒にいるこの者たちはだれか。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> バラムは神に答えた。「モアブの王、ツィポルの子バラクが、私にこう言ってきました。</span>
<span className="v" id="v11" data-v="11"> 『見よ、エジプトから出て来た民が地の面を覆っている。今来て、私のために彼らを呪ってほしい。そうすれば、私は彼らと戦い、追い出せるかもしれない。』」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 23:5; エペソ人への手紙 1:3; 創世記 12:2"> 神はバラムに言われた。「彼らと一緒に行ってはならない。その民を呪ってはならない。彼らは祝福されている。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命記 23:5; 民数記 22:14"> 朝、バラムは起きて、バラクの指導者たちに言った。「あなたがたの国へ帰りなさい。主は、私があなたがたと一緒に行くことをお許しにならない。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数記 22:37; 民数記 22:13"> モアブの指導者たちは起きてバラクのもとへ帰り、言った。「バラムは私たちと一緒に来ることを拒みました。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 10:7–8; 民数記 22:7–8"> バラクは再び、先の者たちより数も多く、身分も高い指導者たちを遣わした。</span>
<span className="v" id="v16" data-v="16"> 彼らはバラムのもとへ来て言った。「ツィポルの子バラクはこう申します。『どうか、何ものにも妨げられず、私のもとへ来てください。</span>
<span className="v" id="v17" data-v="17" data-xref="民数記 24:11; エステル記 5:11; マタイ 4:8–9"> 私はあなたをこの上なく厚くもてなし、あなたの言うことは何でも行います。どうか来て、私のためにこの民を呪ってください。』」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民数記 24:13; 列王記第一 22:14; 歴代誌 第二 18:13"> バラムはバラクの家来たちに答えた。「たとえバラクが、銀と金で満ちた彼の家を私に与えても、私の神、主の命令を越えて、小さなことも大きなことも行うことはできない。</span>
<span className="v" id="v19" data-v="19" data-xref="ユダ 1:11; ペテロの第二の手紙 2:3; テモテへの手紙第一 6:9–10"> それでも、あなたがたも今夜ここにとどまってください。主がさらに何を語られるか確かめましょう。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数記 23:12; 民数記 24:13; 民数記 23:26"> 夜、神はバラムのもとに来て言われた。「この者たちがあなたを呼びに来たのなら、立って一緒に行きなさい。ただし、わたしがあなたに告げることだけを行いなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="箴言 1:15–16"> バラムは朝起きて、ろばに鞍を置き、モアブの指導者たちと出発した。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 4:24; 哀歌 2:4; 民数記 22:32"> しかし、彼が出発したので神の怒りが燃え、主の使いが敵対する者として道に立った。バラムはろばに乗り、二人の従者も一緒にいた。</span>
<span className="v" id="v23" data-v="23" data-xref="ユダ 1:11; ペテロの第二の手紙 2:16; コリント人への第一の手紙 1:27–29"> ろばは、主の使いが抜き身の剣を手にして道に立っているのを見た。ろばは道をそれて畑に入ったので、バラムは道へ戻そうとして打った。</span>
<span className="v" id="v24" data-v="24"> すると、主の使いはぶどう園の間の狭い道に立った。両側には石垣があった。</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 47:12; ヨブ記 5:13–15"> ろばは主の使いを見ると、石垣に身を寄せ、バラムの足を石垣に押しつけた。バラムはまたろばを打った。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ホセア書 2:6; イザヤ書 26:11"> 主の使いはさらに進み、右にも左にも曲がる余地のない狭い場所に立った。</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 14:16; ヤコブの手紙 1:19; 箴言 27:3–4"> ろばは主の使いを見ると、バラムを乗せたまま伏した。バラムは怒りに燃え、杖でろばを打った。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ペテロの第二の手紙 2:16; ルカ 1:37; 出エジプト記 4:11"> すると主がろばの口を開かれた。ろばはバラムに言った。「私が何をしたというのですか。三度も私を打つとは。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="箴言 12:10; マタイ 15:19; 箴言 12:16"> バラムはろばに言った。「おまえが私を愚弄したからだ。手に剣があれば、今すぐおまえを殺していた。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ペテロの第二の手紙 2:16; コリント人への第一の手紙 1:27–28"> ろばはバラムに言った。「私は、あなたが今日まで一生乗ってきたろばではありませんか。これまで、あなたにこんなことをしたでしょうか。」<br />バラムは答えた。「いや。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="創世記 21:19; ルカ 24:31; 使徒の働き 26:18"> そのとき主はバラムの目を開かれた。彼は主の使いが抜き身の剣を手にして道に立っているのを見て、身をかがめ、顔を地につけてひれ伏した。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 28:18; 使徒の働き 13:10; 民数記 22:22"> 主の使いは言った。「なぜろばを三度も打ったのか。見よ、あなたの道がわたしの前でよこしまであるため、わたしは敵対する者として出て来た。</span>
<span className="v" id="v33" data-v="33" data-xref="民数記 16:33–35; 民数記 14:37; 列王記第一 13:24–28"> ろばはわたしを見て、三度身をかわした。もし身をかわしていなければ、今ごろあなたを殺し、ろばを生かしていただろう。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ヨブ記 34:31–32; サムエル記第二 12:13; サムエル記第一 15:24"> バラムは主の使いに言った。「私は罪を犯しました。あなたが道に立ちはだかっておられるとは知りませんでした。これがあなたの意に反するなら、引き返します。」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="テサロニケ人への第二の手紙 2:9–12; イザヤ書 37:26–29; 民数記 22:20–21"> 主の使いはバラムに言った。「この者たちと一緒に行きなさい。ただし、わたしがあなたに語る言葉だけを語りなさい。」<br />こうしてバラムはバラクの指導者たちと行った。</span>
<span className="v" id="v36" data-v="36" data-xref="イザヤ書 16:2; 使徒の働き 28:15; エレミヤ書 48:20"> バラクはバラムが来たと聞き、アルノン川の境、領土の最果てにあるモアブの町まで迎えに出た。</span>
<span className="v" id="v37" data-v="37" data-xref="民数記 24:11; ヨハネ 5:44; マタイ 4:8–9"> バラクはバラムに言った。「私は何度も使者を遣わしてあなたを呼んだではないか。なぜ来なかったのか。私にはあなたを厚くもてなす力がないとでもいうのか。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="民数記 22:18; 箴言 19:21; 民数記 23:16"> バラムはバラクに答えた。「ご覧ください。私はあなたのもとに参りました。しかし、私に何かを自由に語る力があるでしょうか。神が私の口に置かれる言葉を、私は語ります。」</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39"> バラムはバラクとともに行き、キルヤテ・フゾトに着いた。</span>
<span className="v" id="v40" data-v="40" data-xref="民数記 23:14; 箴言 1:16; 民数記 23:2"> バラクは牛と羊をいけにえとしてささげ、その一部をバラムと彼に同行していた指導者たちに送った。</span>
<span className="v" id="v41" data-v="41" data-xref="民数記 23:13; 民数記 25:2–3; 歴代誌 第二 11:15"> 朝になると、バラクはバラムを連れてバモテ・バアルに上った。そこからバラムは民の一部を見渡した。</span>
</div>
</div>

</div>

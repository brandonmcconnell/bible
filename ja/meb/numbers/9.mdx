<span className="v" id="v1" data-v="1" data-xref="民数記 1:1; 出エジプト記 40:2"> イスラエルの子らがエジプトの地を出て第二年、第一の月に、主はシナイの荒野でモーセに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 16:1–2; コリント人への第一の手紙 5:7–8; 歴代誌 第二 35:1"> 「イスラエルの子らに、その定められた時に過越の祭りを守らせなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 12:6–11; レビ記 23:5; 歴代誌 第二 30:2"> この月の十四日の夕暮れ、定められた時に、すべての掟と定めに従ってそれを守りなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> モーセはイスラエルの子らに、過越の祭りを守るように語った。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 5:10; マタイ 28:20; 出エジプト記 12:1–13"> 彼らは第一の月の十四日の夕暮れに、シナイの荒野で過越の祭りを守った。主がモーセに命じられたすべてのことを、そのとおりに行った。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 27:2; 出エジプト記 18:15; 民数記 5:2"> さて、人間の死体によって汚れ、その日に過越の祭りを守ることができない人たちがいた。彼らはその日、モーセとアロンの前に進み出た。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 16:2; コリント人への第一の手紙 5:7–8; 出エジプト記 12:27"> 彼らは言った。「私たちは死体によって汚れています。なぜ、定められた時にイスラエルの子らとともに主へのささげ物をささげられないのでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="詩篇 85:8; 民数記 27:5; コリント人への第一の手紙 4:4"> モーセは彼らに言った。「待っていなさい。主があなたがたについて何を命じられるかを聞いてみよう。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 主はモーセに告げられた。</span>
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 2:1–2; エペソ人への手紙 2:12–13; コリント人への第一の手紙 11:28"> 「イスラエルの子らにこう告げなさい。『あなたがた、またはあなたがたの子孫のうち、だれかが死体によって汚れている場合、あるいは遠い旅に出ている場合でも、その人は主の過越を守る。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代誌 第二 30:2–15; 出エジプト記 12:43–49; ヨハネ 19:36"> 彼らは第二の月の十四日の夕暮れにそれを守り、種なしパンと苦菜とともにそれを食べる。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネ 19:36; 出エジプト記 12:46; 出エジプト記 12:10"> 朝までそれを少しでも残しておいてはならず、その骨を一本でも折ってはならない。過越の祭りのすべての掟に従って、それを守る。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 17:14; 出エジプト記 12:15; 民数記 9:7"> しかし、清く、旅にも出ていないのに過越を守らない者は、民の中から断たれる。その人は定められた時に主へのささげ物をささげなかったので、自分の罪を負う。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 12:48–49; レビ記 24:22; イザヤ書 56:3–7"> 寄留者があなたがたの間に住み、主の過越を守ろうとするなら、過越の掟と定めに従って行う。寄留者にも、その地に生まれた者にも、同じ一つの掟がある。』」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 13:21; 出エジプト記 40:34; ネヘミヤ記 9:19"> 幕屋が建てられた日、雲が幕屋、すなわち証しの天幕を覆った。夕暮れから朝まで、幕屋の上には火のようなものが現れた。</span>
<span className="v" id="v16" data-v="16" data-xref="ネヘミヤ記 9:12; 出エジプト記 40:38; コリント人への第一の手紙 10:1"> 常にそのようであった。昼は雲が幕屋を覆い、夜は火のようなものが現れた。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 40:36–38; 詩篇 32:8; ヨハネ 10:9"> 雲が幕屋の上から上がると、イスラエルの子らは旅立ち、雲がとどまる場所に宿営した。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 10:1; ヨハネの手紙第二 1:6; 出エジプト記 17:1"> イスラエルの子らは主の命令によって旅立ち、主の命令によって宿営した。雲が幕屋の上にとどまっている間、彼らは宿営し続けた。</span>
<span className="v" id="v19" data-v="19" data-xref="ゼカリヤ書 3:7; 民数記 1:52–53; 民数記 3:8"> 雲が幕屋の上に長くとどまるとき、イスラエルの子らは主の命令を守り、旅立たなかった。</span>
<span className="v" id="v20" data-v="20"> 雲が数日しか幕屋の上にないこともあった。そのときも主の命令に従って彼らは宿営し、主の命令に従って旅立った。</span>
<span className="v" id="v21" data-v="21" data-xref="ネヘミヤ記 9:19; ネヘミヤ記 9:12"> 雲が夕暮れから朝までしかないこともあった。朝になって雲が昇ると、彼らは旅立った。昼であれ夜であれ、雲が昇ると彼らは旅立った。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 32:8; 出エジプト記 40:36–37; 出エジプト記 40:16"> 二日であれ、一か月であれ、一年であれ、雲が幕屋の上にとどまっている間は、イスラエルの子らは宿営し続け、旅立たなかった。しかし、それが昇ると彼らは旅立った。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨシュア記 22:3; 民数記 9:19; 創世記 26:5"> 主の命令によって宿営し、主の命令によって旅立った。主がモーセを通して命じられたとおり、その命令を守った。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 25:37; 出エジプト記 40:25; レビ記 24:1–2"> 「アロンにこう告げなさい。『ともしびをともすとき、七つのともしびが燭台の前方を照らすようにしなさい。』」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3"> アロンはそのとおりに行い、主がモーセに命じられたとおり、七つのともしびを燭台の前方に向けてともした。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 25:31–40; 出エジプト記 25:9; 出エジプト記 25:18"> 燭台は金の打ち出し細工で、その台座から花に至るまで打ち出して作られていた。主がモーセに示された型どおりに作られた。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 主はモーセに告げられた。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第二の手紙 7:1; ヤコブの手紙 4:8; 出エジプト記 19:15"> 「イスラエルの子らの中からレビ人を取り、彼らを清めなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 19:13; 民数記 19:7–10; レビ記 8:6"> 彼らを清めるには、次のようにしなさい。清めの水を振りかけ、全身の毛を剃らせ、衣服を洗わせて、身を清めさせる。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 2:1; 出エジプト記 29:1; レビ記 16:3"> それから、彼らに若い牛一頭と、それに伴う穀物のささげ物、すなわち油を混ぜた上質の小麦粉を取らせなさい。またあなたは、贖罪のささげ物として、もう一頭の若い牛を取りなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 40:12; レビ記 8:3; 出エジプト記 29:4–37"> レビ人を会見の天幕の前に連れて来て、イスラエルの子らの全会衆を集める。</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 1:4; 使徒の働き 6:6; テモテへの手紙第一 4:14"> レビ人を主の前に進み出させ、イスラエルの子らにレビ人の上へ手を置かせる。</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 7:30; レビ記 8:29; 民数記 1:49–53"> アロンはイスラエルの子らを代表し、レビ人を揺り動かすささげ物として主の前にささげる。こうして彼らは主への奉仕に就く。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 10:4–10; 出エジプト記 29:10; レビ記 1:4"> レビ人は二頭の牛の頭に手を置く。あなたは一頭を贖罪のささげ物、もう一頭を全焼のささげ物として主にささげ、レビ人のために贖いを行う。</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 8:21; 民数記 8:11; ローマ人への手紙 15:16"> レビ人をアロンとその子らの前に立たせ、揺り動かすささげ物として主にささげる。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 3:45; マラキ書 3:17; 民数記 18:6"> このようにして、あなたはイスラエルの子らの中からレビ人をえり分けなさい。レビ人はわたしのものとなる。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数記 8:11; 民数記 8:13; 民数記 3:23–37"> その後、レビ人は会見の天幕に入り、奉仕に就く。あなたは彼らを清め、揺り動かすささげ物としてささげる。</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 3:12; 民数記 3:45; 民数記 3:9"> 彼らはイスラエルの子らの中から、完全にわたしに与えられているからである。わたしは、胎を開くすべての者、すなわちイスラエルの子らのすべての長子の代わりに、彼らをわたしのものとして取った。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 13:2; ルカ 2:23; 出エジプト記 13:12–15"> イスラエルの子らの長子はみな、人であれ動物であれ、わたしのものだからである。わたしがエジプトの地で長子をすべて打ち殺した日に、わたしは彼らをわたしのために聖別した。</span>
<span className="v" id="v18" data-v="18"> わたしは、イスラエルの子らの中のすべての長子の代わりにレビ人を取った。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 1:53; 民数記 16:46; 歴代誌 第二 26:16–20"> わたしはイスラエルの子らの中からレビ人を選び、アロンとその子らへの贈り物とした。彼らは会見の天幕でイスラエルの子らに代わって奉仕し、そのために贖いを行う。こうして、イスラエルの子らが聖所に近づくとき、彼らの中に疫病が起こらないようにする。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> モーセとアロン、およびイスラエルの子らの全会衆は、レビ人にそのとおりに行った。主がレビ人についてモーセに命じられたすべてのことを、そのとおりに行った。</span>
<span className="v" id="v21" data-v="21" data-xref="民数記 8:7; 民数記 19:19; 民数記 8:15"> レビ人は罪を清める儀式を行い、衣服を洗った。アロンは彼らを主の前で揺り動かすささげ物としてささげ、彼らを清めるために贖いを行った。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代誌 第二 31:2; 歴代誌 第二 35:8–15; 民数記 8:15"> その後、レビ人は会見の天幕に入り、アロンとその子らの前で奉仕した。主がレビ人についてモーセに命じられたとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 主はモーセに告げられた。</span>
<span className="v" id="v24" data-v="24" data-xref="民数記 4:3; 歴代誌上 23:3; 民数記 4:23"> 「レビ人についての定めは次のとおりである。二十五歳以上の者は会見の天幕の務めに就き、奉仕する。</span>
<span className="v" id="v25" data-v="25" data-xref="民数記 4:23; テモテへの第二の手紙 4:7"> 五十歳からは、彼らは働きの奉仕から退き、もはや奉仕してはならない。</span>
<span className="v" id="v26" data-v="26" data-xref="民数記 1:53; 民数記 3:32; テモテへの手紙第一 4:15"> ただし、会見の天幕で兄弟たちを助け、務めを果たすことはできるが、奉仕そのものには就かない。レビ人の務めについて、このように定めなさい。」</span>
</div>

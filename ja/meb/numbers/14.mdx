<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="NUM" data-book-slug="numbers" data-book-name="民数記" data-chapter="14" data-verses="45">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 1:45; 民数記 11:1–4"> 全会衆は声を上げて叫び、民はその夜、泣いた。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 15:24; 出エジプト記 17:3; 民数記 16:41"> イスラエルの子らは皆、モーセとアロンに向かってつぶやいた。全会衆は彼らに言った。「私たちはエジプトの地で死んでいればよかったのに！ それとも、この荒野で死んでいればよかったのに！</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 14:31–32; エレミヤ書 9:3; 詩篇 78:40"> なぜ主は私たちをこの地に導き入れて、剣に倒れさせようとされるのか。私たちの妻や幼子たちは捕らえられ、あるいは殺されてしまう。私たちにとって、エジプトに帰るほうが良いではないか。」</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 7:39; ネヘミヤ記 9:16–17; 申命記 17:16"> 彼らは互いに言った。「指導者を立てて、エジプトに帰ろう。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民数記 16:4; 民数記 16:22; 民数記 16:45"> モーセとアロンは、イスラエルの子らの全会衆の前でひれ伏した。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数記 14:30; 民数記 13:30; 民数記 14:38"> その地を偵察した者たちのうち、ヌンの子ヨシュアとエフネの子カレブは自分たちの衣を引き裂いた。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 13:27; 申命記 1:25; 申命記 8:7–9"> そしてイスラエルの子らの全会衆に言った。「私たちが偵察して通り巡った地は、非常に良い地です。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記第二 22:20; イザヤ書 62:4; 民数記 13:27"> 主が私たちを喜びとされるなら、この地に導き入れ、与えてくださいます。そこは乳と蜜の流れる地です。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 7:18; ローマ人への手紙 8:31; 申命記 31:6"> ただ、主に背いてはなりません。また、その地の民を恐れてはなりません。彼らは私たちのパンだからです。彼らの守りは彼らの上から取り去られており、主が私たちとともにおられます。彼らを恐れてはなりません。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 17:4; サムエル記第一 30:6; レビ記 9:23"> しかし、全会衆は彼らを石で打ち殺そうとした。<br />主の栄光が会見の天幕でイスラエルのすべての子らに現れた。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 78:32; 詩篇 106:24; 詩篇 78:22"> 主はモーセに言われた。「この民はいつまでわたしを侮るのか。わたしが彼らの間で行ったすべてのしるしにもかかわらず、いつまでわたしを信じないのか。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 32:10; 民数記 25:9; サムエル記第二 24:12–15"> わたしは疫病で彼らを打ち、滅ぼす。そして彼らよりも大きく、力強い国民をあなたから起こそう。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 106:23; エゼキエル書 20:9; 申命記 32:27"> モーセは主に言った。「それではエジプト人が聞くでしょう。あなたは御力によって、彼らの間からこの民を導き上られたからです。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 15:14; 出エジプト記 33:11; 申命記 5:4"> エジプト人はこの地の住民に告げるでしょう。彼らは、主であるあなたがこの民のただ中におられ、この民に御姿を現されることを聞いています。あなたの雲は彼らの上にとどまり、あなたは昼は雲の柱、夜は火の柱の中で彼らの前を進まれるからです。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 6:16"> もしこの民を一人残らず殺されるなら、あなたの名声を聞いた国々はこう言うでしょう。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 9:28; ヨシュア記 7:9; ヨシュア記 7:7"> 『主はこの民を、彼らに誓った地に導き入れることができなかったので、彼らを荒野で殺したのだ』と。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイ 9:6; マタイ 9:8; ミカ書 3:8"> 今、あなたが語られたとおり、どうか主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「主」と訳された言葉は「アドナイ」である。">a</a></sup>の御力を現してください。あなたはこう言われました。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 34:6–7; 詩篇 145:8; 出エジプト記 20:5"> 『主は怒るのに遅く、慈しみに富み、咎と背きを赦す。しかし、罪ある者を決して無罪とはされず、父の咎を子に報い、三代、四代にまで及ぼす』と。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 34:9; 詩篇 78:38; 詩篇 106:45"> どうか、あなたの慈しみの大きさに従い、エジプトから今に至るまでこの民を赦してこられたように、この民の咎を赦してください。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ミカ書 7:18–20; ヤコブの手紙 5:16; 詩篇 106:23"> 主は言われた。「あなたの言葉どおりに、わたしは赦した。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 72:19; ハバクク書 2:14; イザヤ書 6:3"> しかし、わたしが生きていること、そして全地が主の栄光で満たされることにかけて言う。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨブ記 19:3; 創世記 31:7; 出エジプト記 32:1"> エジプトや荒野でわたしが行った栄光やしるしを見ながら、このように十度もわたしを試み、わたしの声に聞き従わなかった者たちは皆、</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 32:11; 民数記 26:64; エゼキエル書 20:15"> わたしが彼らの父祖たちに誓った地を確かに見ることはない。わたしを侮った者たちも、だれ一人それを見ることはない。</span>
<span className="v" id="v24" data-v="24" data-xref="民数記 14:6–9; ヨシュア記 14:6–14; エペソ人への手紙 6:6"> しかし、わたしのしもべカレブには異なる霊があり、わたしに従い通したので、彼が行った地に彼を導き入れる。彼の子孫はそこを所有する。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 1:40; 民数記 13:29; 詩篇 81:11–13"> アマレク人とカナン人は谷に住んでいる。明日、向きを変えて、紅海への道を通って荒野へ出発しなさい。」</span>
<span className="v" id="v26" data-v="26"> 主はモーセとアロンに告げられた。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 16:12; コリント人への第一の手紙 10:10; 出エジプト記 16:28"> 「わたしに逆らってつぶやくこの邪悪な会衆を、いつまで耐え忍ばなければならないのか。イスラエルの子らがわたしに逆らってつぶやくのを、わたしは聞いた。</span>
<span className="v" id="v28" data-v="28" data-xref="民数記 14:21; ヘブル人への手紙 3:17; 民数記 14:2"> 彼らに言いなさい。『わたしは生きている、と主は言われる。あなたがたがわたしの耳に聞こえるように語ったとおり、わたしはあなたがたに行う。</span>
<span className="v" id="v29" data-v="29" data-xref="民数記 1:45; コリント人への第一の手紙 10:5; ヘブル人への手紙 3:17"> あなたがたの死体はこの荒野に倒れる。あなたがたの総数に従って数えられた者のうち、二十歳以上でわたしに向かってつぶやいた者は皆、倒れる。</span>
<span className="v" id="v30" data-v="30" data-xref="民数記 26:65; 民数記 14:38; 申命記 1:36–38"> エフネの子カレブとヌンの子ヨシュアを除いて、あなたがたを住まわせるとわたしが誓った地に、あなたがたは決して入らない。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 1:39; 詩篇 106:24; 民数記 26:64"> しかし、捕らえられ、あるいは殺されるとあなたがたが言った幼子たちを、わたしは導き入れる。彼らはあなたがたが拒んだ地を知るようになる。</span>
<span className="v" id="v32" data-v="32" data-xref="コリント人への第一の手紙 10:5; 民数記 14:29; ヘブル人への手紙 3:17"> しかし、あなたがたについては、あなたがたの死体はこの荒野に倒れる。</span>
<span className="v" id="v33" data-v="33" data-xref="エゼキエル書 23:35; 民数記 32:13; 申命記 2:14"> あなたがたの子どもたちは、あなたがたの死体が荒野で朽ち果てるまで四十年間、荒野をさまよい、あなたがたの不貞の報いを負う。</span>
<span className="v" id="v34" data-v="34" data-xref="エゼキエル書 4:6; 民数記 13:25; エレミヤ書 18:9–10"> あなたがたがその地を偵察した四十日、その一日を一年として、四十年間、自分の咎を負う。そして、わたしが敵となることを知る。』</span>
<span className="v" id="v35" data-v="35" data-xref="民数記 23:19; コリント人への第一の手紙 10:5; ヘブル人への手紙 3:19"> 主であるわたしは語った。わたしに逆らって集まったこの邪悪な全会衆に、わたしは必ずこれを行う。この荒野で彼らは朽ち果て、そこで死ぬ。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="民数記 13:31–33; 民数記 13:4–16"> モーセがその地を偵察するために遣わした男たちで、帰って来てその地について悪い報告をもたらし、全会衆をモーセに向かってつぶやかせるようにした者たち、</span>
<span className="v" id="v37" data-v="37" data-xref="コリント人への第一の手紙 10:10; 民数記 16:49; ヘブル人への手紙 3:17"> その地について悪評を広めた男たちは、主の前で疫病によって死んだ。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨシュア記 14:6–10; 民数記 26:65"> しかし、その地を偵察に行った男たちのうち、ヌンの子ヨシュアとエフネの子カレブは生き残った。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出エジプト記 33:4; マタイ 8:12; ヘブル人への手紙 12:17"> モーセがこれらの言葉をイスラエルのすべての子らに告げると、民は非常に悲しんだ。</span>
<span className="v" id="v40" data-v="40" data-xref="申命記 1:41; マタイ 7:21–23; ルカ 13:25"> 彼らは朝早く起き、山頂に上って言った。「見よ、私たちはここにいます。主が約束された場所へ上って行きましょう。私たちは罪を犯したからです。」</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="歴代誌 第二 24:20; ヨブ記 4:9; エレミヤ書 2:37"> モーセは言った。「なぜ今、主の命令に背くのか。それは成功しない。</span>
<span className="v" id="v42" data-v="42" data-xref="申命記 1:42; ヨシュア記 7:8; ヨシュア記 7:12"> 上って行ってはならない。主はあなたがたのただ中におられず、敵に打ち倒されるだけだ。</span>
<span className="v" id="v43" data-v="43" data-xref="民数記 13:29; 民数記 14:25; 歴代誌 第二 15:2"> そこにはアマレク人とカナン人があなたがたの前にいて、あなたがたは剣に倒れるからだ。あなたがたが主に従うことから退いたので、主はあなたがたとともにおられない。」</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="申命記 1:43; サムエル記第一 4:3–11; 民数記 31:6"> しかし、彼らはあえて山頂に上って行った。それでも、主の契約の箱とモーセは宿営の中から離れなかった。</span>
<span className="v" id="v45" data-v="45" data-xref="民数記 21:3; 士師記 1:17; 申命記 1:44"> すると、その山に住んでいたアマレク人とカナン人が下って来て、彼らを打ち、ホルマにまで彼らを打ち砕いた。</span>
</div>
</div>

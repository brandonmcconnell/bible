<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 23:10; 民数記 15:18; レビ記 25:2"> 「イスラエルの子らにこう告げなさい。『わたしがあなたがたに与える住まいの地に入り、</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 29:18; 創世記 8:21; ピリピ人への手紙 4:18"> 主への火によるささげ物、すなわち全焼のささげ物、いけにえ、誓願を果たすためのもの、自発的なささげ物、あるいはあなたがたの定められた祭りに、牛の群れまたは羊の群れから、主への芳ばしい香りとしてささげ物をささげるとき、</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 29:40; レビ記 23:13; レビ記 6:14"> そのささげ物をささげる者は、十分の一エパ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="1エパは約22リットル、または約3分の2ブッシェルである。">a</a></sup>の上質の小麦粉に四分の一ヒン<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="1ヒンは約6.5リットル、または1.7ガロンである。">b</a></sup>の油を混ぜた穀物のささげ物を主にささげる。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 28:7; 民数記 28:14; 士師記 9:13"> 子羊一頭ごとに、全焼のささげ物またはいけにえとともに、注ぎのささげ物としてぶどう酒四分の一ヒンを準備する。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数記 28:12–14; 民数記 15:4"> 雄羊の場合は、穀物のささげ物として、三分の一ヒンの油を混ぜた十分の二エパ<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="1エパは約22リットル、または約3分の2ブッシェルである。">c</a></sup>の上質の小麦粉を準備する。</span>
<span className="v" id="v7" data-v="7"> 注ぎのささげ物としてぶどう酒三分の一ヒンをささげる。これは主への芳ばしい香りとなる。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 3:1; レビ記 7:11–18; レビ記 1:3"> 全焼のささげ物、いけにえ、誓願を果たすためのもの、あるいは主への和解のいけにえとして若い雄牛を準備するときは、</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 28:14; 民数記 28:12; レビ記 6:14"> その若い雄牛とともに、二分の一ヒンの油を混ぜた十分の三エパ<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="1エパは約22リットル、または約3分の2ブッシェルである。">d</a></sup>の上質の小麦粉の穀物のささげ物をささげる。</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 15:5; 民数記 6:15"> 注ぎのささげ物としてぶどう酒二分の一ヒンをささげる。これは主への芳ばしい香りとなる火によるささげ物である。</span>
<span className="v" id="v11" data-v="11"> 牛一頭ごと、雄羊一頭ごと、あるいは雄の子羊や若い山羊一頭ごとに、このように行う。</span>
<span className="v" id="v12" data-v="12"> 準備する数に応じて、それぞれについてこのように行う。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> その地で生まれた者は皆、主への芳ばしい香りとなる火によるささげ物をささげるとき、これらのことをこのように行う。</span>
<span className="v" id="v14" data-v="14"> 寄留者、または代々あなたがたの間に住む者が、主への芳ばしい香りとなる火によるささげ物をささげるときは、あなたがたと同じように行う。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 9:14; 民数記 15:29; 出エジプト記 12:49"> 会衆には一つの掟があり、あなたがたにも、寄留者にも同じである。これは代々にわたる永遠の掟である。主の前では、あなたがたも寄留者も同じである。</span>
<span className="v" id="v16" data-v="16"> あなたがたにも、あなたがたとともに住む寄留者にも、同じ一つの律法と定めがある。』」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 主はモーセに告げられた。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 15:2; 申命記 26:1–15"> 「イスラエルの子らにこう告げなさい。『わたしがあなたがたを導き入れる地に入るとき、</span>
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 5:11–12"> その地のパンを食べるときには、主への揺り動かすささげ物をささげる。</span>
<span className="v" id="v20" data-v="20" data-xref="レビ記 2:14; 出エジプト記 34:26; 申命記 26:2–10"> 初めの練り粉から菓子一つを揺り動かすささげ物としてささげる。打ち場からの奉納物と同じように奉納する。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 29:28; 民数記 18:26"> あなたがたは代々にわたって、初めの練り粉から主への揺り動かすささげ物を与える。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="レビ記 4:2; レビ記 4:27; レビ記 5:15–17"> もし過って、主がモーセに語られたこれらすべての命令、</span>
<span className="v" id="v23" data-v="23"> すなわち、主がモーセを通して命じられたすべてのことを、命じられた日から後の代々にわたって守らなかった場合、</span>
<span className="v" id="v24" data-v="24" data-xref="レビ記 4:23; レビ記 4:13–21; レビ記 5:15"> それが会衆の知らないうちに、意図せずに行われたなら、全会衆は定めに従い、主への芳ばしい香りとなる全焼のささげ物として若い雄牛一頭を、穀物のささげ物と注ぎのささげ物とともにささげ、贖罪のささげ物として雄山羊一頭をささげる。</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 4:20; ローマ人への手紙 3:25; ヘブル人への手紙 2:17"> 祭司はイスラエルの子らの全会衆のために贖いを行う。そうすれば彼らは赦される。これは過失であり、彼らはその過失のために、主への火によるささげ物と贖罪のささげ物を主の前に携えて来たからである。</span>
<span className="v" id="v26" data-v="26" data-xref="民数記 15:24"> イスラエルの子らの全会衆も、彼らの間に外国人として住む寄留者も赦される。すべての民に関して、それは意図せずに行われたことだからである。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="レビ記 4:27–28; 使徒の働き 17:30; 使徒の働き 3:17"> もし一人の人が意図せずに罪を犯したなら、その人は贖罪のささげ物として一歳の雌山羊をささげる。</span>
<span className="v" id="v28" data-v="28" data-xref="レビ記 4:35"> 祭司は、意図せずに罪を犯した者のために主の前で贖いを行う。贖いが行われると、その人は赦される。</span>
<span className="v" id="v29" data-v="29" data-xref="民数記 15:15; レビ記 16:29; レビ記 17:15"> イスラエルの子らの中で生まれた者にも、彼らの間に外国人として住む寄留者にも、意図せずに事を行う者については、一つの律法がある。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ヘブル人への手紙 10:26; 詩篇 19:13; 申命記 1:43"> しかし、その地に生まれた者であれ寄留者であれ、故意に罪を犯す者は主を冒涜する。その者は民の中から断たれる。</span>
<span className="v" id="v31" data-v="31" data-xref="サムエル記第二 12:9; 箴言 13:13; エゼキエル書 18:20"> 主の言葉を侮り、その命令を破ったので、その者は必ず断たれ、自分の咎を負う。』」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 35:2–3; 出エジプト記 31:14–15; 出エジプト記 20:8–10"> イスラエルの子らが荒野にいたとき、ある男が安息日に薪を集めているのを見つけた。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネ 8:3–20"> 薪を集めているのを見つけた者たちは、彼をモーセとアロン、および全会衆のもとに連れて来た。</span>
<span className="v" id="v34" data-v="34" data-xref="レビ記 24:12; 民数記 9:8"> どう処置すべきか示されていなかったので、彼らはその男を留置した。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="使徒の働き 7:58; 出エジプト記 31:14–15; 列王記第一 21:13"> 主はモーセに言われた。「その男は必ず死刑に処される。全会衆は宿営の外で彼を石で打ち殺しなさい。」</span>
<span className="v" id="v36" data-v="36" data-xref="ヨシュア記 7:25"> 全会衆は彼を宿営の外に連れ出し、主がモーセに命じられたとおりに、石で打ち殺した。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37"> 主はモーセに告げられた。</span>
<span className="v" id="v38" data-v="38" data-xref="マタイ 23:5; 申命記 22:12; マタイ 9:20"> 「イスラエルの子らにこう告げなさい。『代々にわたって、衣服の裾に房<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="または、房飾り（ヘブル語 צִיצִ֛ת）。">e</a></sup>を作り、それぞれの裾の房<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="または、房飾り。">f</a></sup>に青いひもをつけなさい。</span>
<span className="v" id="v39" data-v="39" data-xref="詩篇 106:39; 箴言 28:26; 詩篇 73:27"> その房<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="または、房飾り。">g</a></sup>を見て主のすべての命令を思い起こし、それを行いなさい。自分の心や目の欲に従って不実に走ってはならない。</span>
<span className="v" id="v40" data-v="40" data-xref="ローマ人への手紙 12:1; テサロニケ人への手紙第一 4:7; レビ記 11:44–45"> そうしてあなたがたがわたしのすべての命令を思い起こしてそれを行い、あなたがたの神に対して聖なる者となるためである。</span>
<span className="v" id="v41" data-v="41" data-xref="ペテロの手紙第一 2:9–10; エゼキエル書 36:25–27; ヘブル人への手紙 11:16"> わたしは、あなたがたの神となるためにエジプトの地からあなたがたを導き出した、あなたがたの神、主である。わたしはあなたがたの神、主である。』」</span>
</div>
</div>

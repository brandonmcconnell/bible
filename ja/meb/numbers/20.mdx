<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 13:21; 出エジプト記 15:20; 民数記 33:36"> イスラエルの子ら、すなわち全会衆は第一の月にツィンの荒野に着き、民はカデシュにとどまった。ミリアムはそこで死に、そこに葬られた。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 16:19; 民数記 16:42; 出エジプト記 15:23–24"> 会衆には水がなかった。そこで彼らはモーセとアロンに逆らって集まった。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 17:2; 民数記 14:1–2; 民数記 16:31–35"> 民はモーセと争って言った。「私たちの兄弟たちが主の前で死んだとき、私たちも死んでいればよかった！</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 17:3; 詩篇 106:21; 民数記 16:13–14"> なぜ主の集会をこの荒野に連れて来て、私たちも家畜もここで死なせようとするのか。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 16:14; エレミヤ書 2:2; エレミヤ書 2:6"> なぜ私たちをエジプトから上らせて、こんなひどい場所に連れて来たのか。ここには穀物も、いちじくも、ぶどうも、ざくろもない。そのうえ、飲み水さえない。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数記 14:5; 民数記 16:4; 民数記 16:19"> モーセとアロンは集会の前から会見の天幕の入口に行き、ひれ伏した。すると、主の栄光が彼らに現れた。</span>
<span className="v" id="v7" data-v="7"> 主はモーセに告げられた。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 4:17; 使徒の働き 2:1–4; ヨハネの黙示録 22:17"> 「杖を取りなさい。あなたと兄弟アロンは会衆を集め、彼らの前で岩に語りかけ、水を出させなさい。こうして岩から水を出し、会衆とその家畜に飲ませなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数記 17:10"> モーセは命じられたとおり、主の前から杖を取った。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 106:32–33; 使徒の働き 14:9–15; ルカ 9:54–55"> モーセとアロンは会衆を岩の前に集めた。モーセは言った。「反逆する者たちよ、聞け。この岩から、私たちがあなたがたのために水を出せというのか。」</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 10:4; 出エジプト記 17:6; 申命記 8:15"> モーセは手を上げ、杖で岩を二度打った。すると水が豊かに湧き出し、会衆も家畜も飲んだ。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 1:37; 民数記 27:14; エゼキエル書 36:23"> 主はモーセとアロンに言われた。「あなたがたはわたしを信じず、イスラエルの子らの前でわたしを聖なる者として示さなかった。それゆえ、あなたがたがこの集会を、わたしが彼らに与える地へ導き入れることはない。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 17:7; 詩篇 95:8; 申命記 33:8"> これがメリバ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「メリバ」は「争い」を意味する。">a</a></sup>の水である。イスラエルの子らが主と争い、主が彼らの間で御自分を聖なる者として示されたからである。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="士師記 11:16–17; 申命記 23:7; オバデヤ書 1:10–12"> モーセはカデシュからエドムの王に使者を遣わして言った。<br />「あなたの兄弟イスラエルはこう申します。『あなたは、私たちが経験したすべての苦難をご存じです。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 12:40; 申命記 26:6; 創世記 46:6"> 私たちの父祖はエジプトに下り、私たちは長い間そこに住みました。エジプト人は私たちと父祖を虐げました。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 14:19; 出エジプト記 23:20; 出エジプト記 33:2"> 私たちが主に叫び求めると、主は声を聞き、御使いを遣わして、エジプトから導き出してくださいました。今、私たちはあなたの領土の境にある町カデシュにおります。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="申命記 2:27; 申命記 2:29; 民数記 21:22–24"> どうか、あなたの国を通らせてください。畑やぶどう園には入らず、井戸の水も飲みません。あなたの領土を通り過ぎるまで、王の道を進み、右にも左にもそれません。』」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> エドムは答えた。「私の国を通ってはならない。さもないと、剣をもって迎え撃つ。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命記 2:28; 申命記 2:6; 出エジプト記 12:38"> イスラエルの子らは言った。「大通りを進みます。私たちや家畜があなたの水を飲むなら、その代価を払います。ただ歩いて通らせていただくだけです。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="士師記 11:17; アモス書 1:11; 創世記 32:6"> 彼は言った。「通ってはならない。」そしてエドムは大軍と強力な軍勢を率いて、迎え撃つために出て来た。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 11:18; 申命記 2:29; 申命記 2:4–8"> こうしてエドムが領土を通ることを拒んだので、イスラエルはそこから離れた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数記 20:1; 民数記 20:14; 民数記 21:4"> イスラエルの子ら、すなわち全会衆はカデシュから旅立ち、ホル山に着いた。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 33:37"> 主はエドムの地の境にあるホル山で、モーセとアロンに告げられた。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 25:8; 申命記 32:50; 民数記 31:2"> 「アロンはその民に加えられる。メリバの水であなたがたがわたしの言葉に背いたので、彼はわたしがイスラエルの子らに与える地に入ることはない。</span>
<span className="v" id="v25" data-v="25" data-xref="民数記 33:38–39"> アロンとその子エルアザルを連れて、ホル山に登りなさい。</span>
<span className="v" id="v26" data-v="26" data-xref="民数記 20:24; イザヤ書 22:21–22; ヘブル人への手紙 7:11"> アロンの衣を脱がせ、その子エルアザルに着せなさい。アロンはそこでその民に加えられ、死ぬ。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> モーセは主が命じられたとおりに行った。彼らは全会衆の前でホル山に登った。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 10:6; 出エジプト記 29:29–30; 申命記 34:9"> モーセはアロンの衣を脱がせ、それを彼の子エルアザルに着せた。アロンはそこで、山の頂で死んだ。そしてモーセとエルアザルは山から下りた。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 34:8; 歴代誌 第二 35:24–25; 創世記 1:10"> 全会衆はアロンが死んだのを見たとき、イスラエルの全家はアロンのために三十日間泣き悲しんだ。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 1:16; 民数記 33:40; ヨシュア記 12:14"> 南部地方に住むカナン人、アラドの王は、イスラエルがアタリムの道を進んで来たと聞き、イスラエルと戦って、そのうち何人かを捕虜にした。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 11:30; 創世記 28:20; サムエル記第一 1:11"> イスラエルは主に誓願を立てた。「この民を私の手に渡してくださるなら、彼らの町々を聖絶します。」</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 14:45; 申命記 1:44; 詩篇 10:17"> 主はイスラエルの願いを聞き、カナン人を彼らの手に渡された。イスラエルは彼らとその町々を聖絶した。それで、その場所はホルマ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「ホルマ」は「滅び」を意味する。">a</a></sup>と呼ばれた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 6:9; 士師記 11:18; 民数記 32:7"> 彼らはエドムの地を迂回するため、ホル山から紅海への道を進んだ。しかし民は旅のために気力を失った。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 78:19; 民数記 16:13–14; 出エジプト記 17:2–3"> 民は神とモーセに逆らって言った。「なぜ私たちをエジプトから上らせ、この荒野で死なせようとするのか。パンも水もない。私たちはこの粗末な食物にうんざりしている。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="コリント人への第一の手紙 10:9; エレミヤ書 8:17; 申命記 8:15"> 主は民の中に毒蛇を送られた。蛇は民をかみ、イスラエルの多くの者が死んだ。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 8:24; 民数記 11:2; 詩篇 78:34"> 民はモーセのもとに来て言った。「私たちは主とあなたに逆らって語り、罪を犯しました。蛇を取り去ってくださるよう主に祈ってください。」そこでモーセは民のために祈った。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨハネ 3:14; 詩篇 106:43–45; 詩篇 145:8"> 主はモーセに言われた。「毒蛇を作り、旗竿の上に掲げなさい。かまれた者は、それを見れば生きる。」</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネ 3:14–15; ヘブル人への手紙 12:2; ヨハネ 6:40"> モーセは青銅の蛇を作り、旗竿の上に掲げた。蛇にかまれた者も、青銅の蛇を仰ぎ見ると生きた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民数記 33:43–45"> イスラエルの子らは旅立ち、オボテに宿営した。</span>
<span className="v" id="v11" data-v="11"> 彼らはオボテから旅立ち、モアブの東、日の出る方角の荒野にあるイエ・アバリムに宿営した。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 2:13–14"> そこから旅立ち、ゼレドの谷に宿営した。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 11:18; 民数記 22:36; イザヤ書 16:2"> そこから旅立ち、アモリ人の領域から延びる荒野のアルノン川の向こう側に宿営した。アルノン川は、モアブとアモリ人の間を隔てるモアブの境界である。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 10:13; サムエル記第二 1:18"> それゆえ、主の戦いの書 にはこう記されている。「スファのワヘブ、アルノンの谷々、</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 21:28; 申命記 2:18; 申命記 2:9"> 谷々の斜面はアルの住まいへ傾き、モアブの境に寄りかかる。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数記 20:8; イザヤ書 12:3; イザヤ書 41:17–18"> そこから彼らはベエルへ向かった。そこは、主がモーセに「民を集めなさい。わたしは彼らに水を与える」と言われた井戸である。</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="ヤコブの手紙 5:13; 出エジプト記 15:1–2; 詩篇 106:12"> そのとき、イスラエルはこの歌を歌った。<br /><span className="pl pl-1">「湧き上がれ、井戸よ。これに向かって歌え。</span></span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 33:22; テモテへの手紙第一 6:17–18; ヤコブの手紙 4:12"> <span className="pl pl-2">指導者たちが掘った井戸、</span><br /><span className="pl pl-2">民の高貴な者たちが掘った井戸、</span><br /><span className="pl pl-2">王笏と杖をもって掘った井戸。」</span><br />荒野から彼らはマタナへ進み、</span>
<span className="v" id="v19" data-v="19"> マタナからナハリエルへ、ナハリエルからバモテへ、</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 23:28; 民数記 23:14; 申命記 1:5"> バモテから、モアブの野にある谷へ、荒れ地を見下ろすピスガの頂へ進んだ。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 2:26–28; 民数記 20:14–19; 士師記 11:19–21"> イスラエルはアモリ人の王シホンに使者を遣わして言った。</span>
<span className="v" id="v22" data-v="22" data-xref="民数記 20:17"> 「あなたの国を通らせてください。畑やぶどう園には入らず、井戸の水も飲みません。あなたの領土を通り過ぎるまで、王の道を進みます。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="士師記 11:20; 申命記 29:7–8; イザヤ書 15:4"> しかしシホンは、イスラエルが自分の領土を通ることを許さなかった。彼は全軍を集めて荒野へ出てイスラエルを迎え撃ち、ヤハツで戦った。</span>
<span className="v" id="v24" data-v="24" data-xref="アモス書 2:9; ヨシュア記 24:8; 創世記 32:22"> イスラエルは彼を剣の刃で打ち、アルノン川からヤボク川まで、アンモン人の領域に至る地を占領した。アンモン人の境界は堅固だった。</span>
<span className="v" id="v25" data-v="25" data-xref="民数記 32:33–42; イザヤ書 16:8–9; エレミヤ書 48:2"> イスラエルはこれらの町々をすべて取り、アモリ人のすべての町、すなわちヘシュボンと周辺の村々に住んだ。</span>
<span className="v" id="v26" data-v="26"> ヘシュボンはアモリ人の王シホンの町であった。シホンは先のモアブの王と戦い、アルノン川に至るまで、その領土をすべて奪っていた。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 14:4; 民数記 21:14; ハバクク書 2:6"> それゆえ、歌を詠む者たちは言う。<br /><span className="pl pl-1">「ヘシュボンへ来よ。</span><br /><span className="pl pl-2">シホンの町を建て、堅くせよ。</span></span>
<span className="v" id="v28" data-v="28" data-xref="民数記 21:15; エレミヤ書 48:45–46; イザヤ書 15:1–2"> <span className="pl pl-1">火がヘシュボンから、</span><br /><span className="pl pl-2">炎がシホンの町から出た。</span><br /><span className="pl pl-1">それはモアブのアルを、</span><br /><span className="pl pl-2">アルノンの高き所の支配者たちを焼き尽くした。</span></span>
<span className="v" id="v29" data-v="29" data-xref="士師記 11:24; 列王記第二 23:13; エレミヤ書 48:46"> <span className="pl pl-1">モアブよ、災いだ。</span><br /><span className="pl pl-2">ケモシュの民よ、おまえは滅びる。</span><br /><span className="pl pl-1">ケモシュは息子たちを逃亡者とし、</span><br /><span className="pl pl-2">娘たちを捕虜とし、</span><br /><span className="pl pl-2">アモリ人の王シホンに渡した。</span></span>
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 48:18; イザヤ書 15:2; エレミヤ書 48:22"> <span className="pl pl-1">私たちは彼らを射倒した。</span><br /><span className="pl pl-2">ヘシュボンはディボンまで滅び、</span><br /><span className="pl pl-1">私たちはノファまで荒廃させ、</span><br /><span className="pl pl-2">メデバにまで攻め及んだ。」</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ヨシュア記 13:8–12; 民数記 32:33–42; 申命記 3:16–17"> こうしてイスラエルはアモリ人の地に住んだ。</span>
<span className="v" id="v32" data-v="32" data-xref="エレミヤ書 48:32; 民数記 32:1; 民数記 32:35"> モーセはヤゼルを偵察させた。イスラエルはその周辺の村々を取り、そこにいたアモリ人を追い出した。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨシュア記 13:12; 申命記 1:4; 申命記 29:7"> 彼らは向きを変え、バシャンへの道を上った。バシャンの王オグは全軍を率いて迎え撃つために出て来て、エドレイで戦った。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="詩篇 135:10–11; ヨシュア記 8:7; 申命記 3:2–3"> 主はモーセに言われた。「彼を恐れてはならない。わたしは彼と全軍、その地をあなたの手に渡した。ヘシュボンに住んでいたアモリ人の王シホンにしたのと同じように、彼にも行いなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="申命記 29:7–8; ヨシュア記 13:12; 申命記 3:3–17"> 彼らはオグとその息子たち、全軍を、一人も残さず打ち倒し、その地を占領した。</span>
</div>
</div>

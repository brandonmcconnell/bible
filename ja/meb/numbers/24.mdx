<span className="v" id="v1" data-v="1" data-xref="民数記 23:3; 民数記 23:23; 民数記 23:28"> バラムは、イスラエルを祝福することが主の御心にかなうと知り、これまでのように占いを求めて行かず、荒野の方へ顔を向けた。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記第一 19:20; 歴代誌 第二 15:1; サムエル記第一 19:23"> バラムが目を上げると、イスラエルが部族ごとに宿営しているのが見えた。そのとき神の霊が彼の上に臨んだ。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 22:31; 民数記 24:16; 民数記 23:7"> 彼は託宣を述べた。<br /><span className="pl pl-1">「ベオルの子バラムの言葉、</span><br /><span className="pl pl-2">目を開かれた男の言葉。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 1:17; ヨハネの黙示録 1:10; 民数記 12:6"> <span className="pl pl-1">神の言葉を聞く者、</span><br /><span className="pl pl-2">全能者の幻を見る者、</span><br /><span className="pl pl-2">倒れ伏しながらも、目を開かれている者の言葉。</span></span>
<span className="v" id="v5" data-v="5"> <span className="pl pl-1">ヤコブよ、なんと美しいことか、あなたの天幕は。</span><br /><span className="pl pl-2">イスラエルよ、あなたの住まいは。</span></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 1:3; イザヤ書 58:11; 詩篇 104:16"> <span className="pl pl-1">広がる谷のように、</span><br /><span className="pl pl-2">川辺の園のように、</span><br /><span className="pl pl-2">主が植えられたアロエのように、</span><br /><span className="pl pl-2">水のほとりの杉のように。</span></span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記第二 5:12; 歴代誌上 14:2; ヨハネの黙示録 17:1"> <span className="pl pl-1">水はその桶からあふれ、</span><br /><span className="pl pl-2">その種は豊かな水に潤される。</span><br /><span className="pl pl-1">その王はアガグより高く、</span><br /><span className="pl pl-2">その王国は高く上げられる。</span></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 45:5; 詩篇 2:9; 民数記 14:9"> <span className="pl pl-1">神は彼をエジプトから導き出された。</span><br /><span className="pl pl-2">彼には野牛のような力がある。</span><br /><span className="pl pl-1">彼は敵対する国々を食い尽くし、</span><br /><span className="pl pl-2">その骨を砕き、</span><br /><span className="pl pl-2">矢で射抜く。</span></span>
<span className="v" id="v9" data-v="9" data-xref="創世記 12:3; 創世記 27:29; 創世記 49:9"> <span className="pl pl-1">彼は身をかがめ、獅子のように伏す。</span><br /><span className="pl pl-2">雌獅子のように。</span><br /><span className="pl pl-2">だれが彼を起こせよう。</span><br /><span className="pl pl-1">あなたを祝福する者は祝福され、</span><br /><span className="pl pl-2">あなたを呪う者は呪われる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民数記 23:11; エゼキエル書 21:14; エゼキエル書 21:17"> バラクはバラムに向かって怒りに燃え、両手を打ち鳴らした。「私は敵を呪わせるためにあなたを呼んだのに、あなたは三度も彼らを祝福した。</span>
<span className="v" id="v11" data-v="11" data-xref="民数記 22:17; 民数記 22:37; ヘブル人への手紙 11:24–26"> 今すぐ自分の所へ逃げ帰れ。私はあなたを大いに厚くもてなすつもりだったが、主がその栄誉をあなたから取り上げられたのだ。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数記 22:18; 民数記 22:38"> バラムはバラクに言った。「あなたが遣わした使者たちにも、こう申したではありませんか。</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 16:28; 民数記 22:18; 民数記 22:20"> 『たとえバラクが銀と金で満ちた家を私に与えても、主の命令を越えて、自分の思いで良いことも悪いことも行うことはできない。私は主が語られることを語る』と。</span>
<span className="v" id="v14" data-v="14" data-xref="ミカ書 6:5; ヨハネの黙示録 2:14; 創世記 49:1"> さあ、私は自分の民のもとへ帰ります。しかしその前に、後の日にこの民があなたの民に何をするか、あなたに知らせましょう。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="民数記 24:3–4; 民数記 23:7; マタイ 13:35"> 彼は託宣を述べた。<br /><span className="pl pl-1">「ベオルの子バラムの言葉、</span><br /><span className="pl pl-2">目を開かれた男の言葉。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="民数記 24:4; コリント人への第一の手紙 8:1; サムエル記第二 23:1–2"> <span className="pl pl-2">神の言葉を聞き、</span><br /><span className="pl pl-2">いと高き方の知識を持つ者、</span><br /><span className="pl pl-2">全能者の幻を見、</span><br /><span className="pl pl-2">倒れ伏しながらも目を開かれている者の言葉。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの黙示録 22:16; ルカ 1:32–33; 創世記 49:10"> <span className="pl pl-1">私は彼を見る。しかし今ではない。</span><br /><span className="pl pl-2">彼を見つめる。しかし近くではない。</span><br /><span className="pl pl-1">ヤコブから一つの星が進み出て、</span><br /><span className="pl pl-2">イスラエルから一つの王笏が立ち上がる。</span><br /><span className="pl pl-1">それはモアブのこめかみを打ち砕き、</span><br /><span className="pl pl-2">シェトの子らをことごとく打ち倒す。</span></span>
<span className="v" id="v18" data-v="18" data-xref="アモス書 9:12; 創世記 27:29; サムエル記第二 8:14"> <span className="pl pl-1">エドムはその所有となり、</span><br /><span className="pl pl-2">敵セイルもその所有となる。</span><br /><span className="pl pl-2">イスラエルは力を現す。</span></span>
<span className="v" id="v19" data-v="19" data-xref="創世記 49:10; ミカ書 5:2; 詩篇 2:1–12"> <span className="pl pl-1">ヤコブから支配する者が出て、</span><br /><span className="pl pl-2">町に残る者を滅ぼす。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 17:14; 士師記 6:3; 歴代誌上 4:43"> 彼はアマレクを見渡し、託宣を述べた。<br /><span className="pl pl-1">「アマレクは国々の初め。</span><br /><span className="pl pl-2">しかし、その終わりは滅びに至る。」</span></span>

<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="創世記 15:19; 士師記 1:16; ヨブ記 29:18"> 彼はケニ人を見渡し、託宣を述べた。<br /><span className="pl pl-1">「あなたの住まいは堅固で、</span><br /><span className="pl pl-2">巣は岩の上に置かれている。</span></span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 83:8; 創世記 10:22; エズラ記 4:2"> <span className="pl pl-1">しかし、カインは焼き尽くされる。</span><br /><span className="pl pl-2">ついにはアッシュルがおまえを捕らえる。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="民数記 23:23; マラキ書 3:2; 列王記第二 5:1"> 彼は託宣を述べた。<br /><span className="pl pl-1">「ああ、神がこれを行われるとき、だれが生き延びられよう。</span></span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 17:8; 詩篇 105:11; 申命記 1:7–8"> 「イスラエルの子らに命じて、こう告げなさい。『あなたがたがカナンの地に入るとき、相続地として与えられるカナンの地の境界は次のとおりである。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 14:3; エゼキエル書 47:13; ヨシュア記 3:16"> 南側は、エドムに接するツィンの荒野から始まり、南の境界は塩の海の東端から始まる。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 32:8; ヨシュア記 15:3–4; 民数記 13:26"> 境界はアクラビムの坂の南を回ってツィンを通り、カデシュ・バルネアの南へ出る。そこからハツァル・アダルへ進み、アツモンを通る。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 15:4; 創世記 15:18; 列王記第一 8:65"> さらにアツモンからエジプト川へ曲がり、海に至る。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 1:4; エゼキエル書 47:20; エゼキエル書 47:15"> 西の境界は大海とその海岸である。これが西の境界となる。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="民数記 33:37; 民数記 34:6; 民数記 34:3"> 北の境界は次のとおりである。大海からホル山へ境界線を引き、</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 13:21; 列王記第二 14:25; ヨシュア記 13:5–6"> ホル山からハマトの入口へ線を引く。境界はツェダデへ進み、</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 47:17"> ツィフロンを経てハツァル・エナンに至る。これが北の境界となる。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 東の境界は、ハツァル・エナンからシェファムへ線を引く。</span>
<span className="v" id="v11" data-v="11" data-xref="列王記第二 23:33; 申命記 3:17; ヨシュア記 11:2"> 境界はシェファムからアインの東にあるリブラへ下り、さらにキネレテ湖の東岸に達する。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 34:3; 創世記 13:10; 創世記 19:24–26"> そこからヨルダン川を下り、塩の海に至る。これが周囲の境界によって定められる、あなたがたの地である。』」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数記 34:1; ヨシュア記 14:1–5"> モーセはイスラエルの子らに命じた。「これは、くじによって相続地として受け継ぐ地である。主はこれを九部族と半部族に与えるよう命じられた。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 32:33; 民数記 32:23; ヨシュア記 14:2–3"> ルベン族とガド族は父祖の家ごとに、またマナセの半部族も、すでに相続地を受け取っている。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 32:32"> 二部族と半部族は、エリコの向かい、ヨルダン川の東側、日の出る方角に相続地を受け取った。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 主はモーセに告げられた。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨシュア記 14:1; ヨシュア記 19:51; 民数記 13:8"> 「あなたがたのために地を相続地として分ける者は、祭司エルアザルとヌンの子ヨシュアである。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 1:4–16"> また、地を分けるため、各部族から指導者を一人ずつ選びなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 26:65; 民数記 13:30; 民数記 14:24"> その男たちの名は次のとおりである。ユダの部族からは、エフネの子カレブ。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 49:5"> シメオンの子らの部族からは、アミフデの子シェムエル。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 49:27; 詩篇 68:27"> ベニヤミンの部族からは、キスロンの子エリダデ。</span>
<span className="v" id="v22" data-v="22"> ダンの子らの部族の指導者として、ヨグリの子ブキ。</span>
<span className="v" id="v23" data-v="23"> ヨセフの子らのうち、マナセの子らの部族の指導者として、エフォデの子ハニエル。</span>
<span className="v" id="v24" data-v="24"> エフライムの子らの部族の指導者として、シフタンの子ケムエル。</span>
<span className="v" id="v25" data-v="25"> ゼブルンの子らの部族の指導者として、パルナクの子エリツァファン。</span>
<span className="v" id="v26" data-v="26"> イッサカルの子らの部族の指導者として、アザンの子パルティエル。</span>
<span className="v" id="v27" data-v="27"> アシェルの子らの部族の指導者として、シェロミの子アヒフデ。</span>
<span className="v" id="v28" data-v="28"> ナフタリの子らの部族の指導者として、アミフデの子ペダヘル。」</span>
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 19:51; 民数記 34:18"> これらが、カナンの地でイスラエルの子らに相続地を分けるよう、主が命じられた者たちである。</span>
</div>

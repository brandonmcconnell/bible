<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 3:11; 創世記 8:21; 民数記 9:2–3"> 「イスラエルの子らに命じて、こう告げなさい。『わたしへのささげ物、すなわち芳ばしい香りとなる火によるささげ物、わたしの食物を、定められた時にささげるよう注意しなさい。』</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 6:9; ダニエル書 11:31; ヨハネ 1:29"> また、こう告げなさい。『主にささげる火によるささげ物は次のとおりである。絶えずささげる全焼のささげ物として、一歳の傷のない雄の子羊を毎日二頭ささげる。</span>
<span className="v" id="v4" data-v="4" data-xref="ダニエル書 9:21; 列王記第一 18:36; 出エジプト記 12:6"> 一頭の子羊は朝にささげ、もう一頭の子羊は夕方にささげなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 2:1; 出エジプト記 16:36; 出エジプト記 29:38–42"> 穀物のささげ物として十分の一エパ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一エパは約22リットル、または約3分の2ブッシェルである。">a</a></sup>の上質の小麦粉に、打って搾った四分の一ヒン<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一ヒンは約6.5リットル、または1.7ガロンである。">b</a></sup>の油を混ぜたものをささげなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="アモス書 5:25; レビ記 6:9; 詩篇 50:8"> これはシナイ山で定められた、絶えずささげる全焼のささげ物であり、主への芳ばしい香りとなる火によるささげ物である。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 29:42; 民数記 28:14; イザヤ書 57:6"> 子羊一頭につき四分の一ヒン<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一ヒンは約6.5リットルなので、四分の一ヒンは約1.6リットル、または1.7クォートである。">c</a></sup>の注ぎのささげ物を添える。聖所で、強い酒を主への注ぎのささげ物として注ぐ。</span>
<span className="v" id="v8" data-v="8"> もう一頭の子羊は夕方にささげる。朝の穀物のささげ物と注ぎのささげ物と同じように、主への芳ばしい香りとなる火によるささげ物としてささげる。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 58:13; 詩篇 92:1–4; ヨハネの黙示録 1:10"> 安息日には、一歳の傷のない雄の子羊二頭と、穀物のささげ物として油を混ぜた十分の二エパ<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一エパは約22リットル、または約3分の2ブッシェルである。">d</a></sup>の上質の小麦粉、および注ぎのささげ物をささげる。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 46:4–5; 民数記 29:22; 民数記 29:31"> これは、絶えずささげる全焼のささげ物と注ぎのささげ物に加える、毎安息日の全焼のささげ物である。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民数記 10:10; エゼキエル書 46:6; エズラ記 3:5"> 月の初めには、主への全焼のささげ物として、若い雄牛二頭、雄羊一頭、一歳の傷のない雄の子羊七頭をささげる。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 15:4–12; エゼキエル書 46:5–7; 民数記 29:10"> 牛一頭につき、穀物のささげ物として油を混ぜた十分の三エパ<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一エパは約22リットル、または約3分の2ブッシェルである。">e</a></sup>の上質の小麦粉を、雄羊一頭につき、穀物のささげ物として油を混ぜた十分の二エパの上質の小麦粉をささげなさい。</span>
<span className="v" id="v13" data-v="13"> 子羊一頭ごとに、穀物のささげ物として油を混ぜた十分の一エパの上質の小麦粉をささげる。これは主への芳ばしい香りとなる、火による全焼のささげ物である。</span>
<span className="v" id="v14" data-v="14"> 注ぎのささげ物は、雄牛一頭につきぶどう酒二分の一ヒン、雄羊には三分の一ヒン、子羊には四分の一ヒンとする。これは一年を通じて毎月ささげる全焼のささげ物である。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 28:3; 民数記 28:22; 民数記 15:24"> また、主への贖罪のささげ物として雄山羊一頭を、絶えずささげる全焼のささげ物と注ぎのささげ物に加えてささげる。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 16:1–8; 出エジプト記 12:18; レビ記 23:5–8"> 第一の月の十四日は、主の過越である。</span>
<span className="v" id="v17" data-v="17" data-xref="レビ記 23:6; 出エジプト記 23:15; 出エジプト記 13:6"> この月の十五日は祭りである。七日間、種なしパンを食べる。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 12:16; レビ記 23:7–8"> 最初の日には聖なる集会を開き、通常の仕事をしてはならない。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 15:21; エゼキエル書 45:21–25; 民数記 29:8"> しかし、あなたがたは主への火によるささげ物、全焼のささげ物をささげなさい。若い牛二頭、雄羊一頭、一歳の雄の子羊七頭である。それらは傷のないものである。</span>
<span className="v" id="v20" data-v="20"> それらに伴う穀物のささげ物は、油を混ぜた上質の小麦粉とする。牛一頭につき十分の三エパを、雄羊につき十分の二エパをささげなさい。</span>
<span className="v" id="v21" data-v="21"> 七頭の子羊のそれぞれ一頭につき、十分の一エパをささげなさい。</span>
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 8:3"> また、あなたがたのために贖罪を行うため、贖罪のささげ物として雄山羊一頭をささげなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 28:3; 民数記 28:10"> あなたがたはこれらを、朝の全焼のささげ物、すなわち絶えずささげる全焼のささげ物に加えてささげなさい。</span>
<span className="v" id="v24" data-v="24"> このように七日間、毎日、主への芳ばしい香りとなる火によるささげ物の食物をささげる。これは、絶えずささげる全焼のささげ物と注ぎのささげ物に加えてささげる。</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 23:8; 民数記 28:18; 出エジプト記 13:6"> 七日目には、あなたがたは聖なる集会を開きなさい。通常のいかなる仕事もしてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 23:16; 出エジプト記 34:22; レビ記 23:10"> また初穂の日、すなわち七週の祭りに、主へ新しい穀物のささげ物をささげるとき、聖なる集会を開き、通常の仕事をしてはならない。</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 23:18–19; 民数記 28:11; 民数記 28:19"> あなたがたは主への芳ばしい香りとなる全焼のささげ物をささげなさい。若い牛二頭、雄羊一頭、一歳の雄の子羊七頭である。</span>
<span className="v" id="v28" data-v="28"> それらに伴う穀物のささげ物は油を混ぜた上質の小麦粉とし、牛一頭につき十分の三エパ、雄羊一頭につき十分の二エパ、</span>
<span className="v" id="v29" data-v="29"> 七頭の子羊のそれぞれ一頭につき十分の一エパとする。</span>
<span className="v" id="v30" data-v="30" data-xref="民数記 28:15; 民数記 28:22; ペテロの手紙第一 2:24"> また、あなたがたのために贖罪を行うため、雄山羊一頭をささげなさい。</span>
<span className="v" id="v31" data-v="31" data-xref="民数記 28:19; 民数記 28:3; マラキ書 1:13–14"> 絶えずささげる全焼のささげ物と穀物のささげ物に加えて、これらと注ぎのささげ物をささげる。それらは傷のないものとする。』」</span>
</div>

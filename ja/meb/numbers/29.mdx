<span className="v" id="v2" data-v="2" data-xref="民数記 28:27; 民数記 28:19; 民数記 29:36"> 主への芳ばしい香りとなる全焼のささげ物として、若い雄牛一頭、雄羊一頭、一歳の傷のない雄の子羊七頭をささげる。</span>
<span className="v" id="v3" data-v="3"> その穀物のささげ物は油を混ぜた上質の小麦粉とし、牛には十分の三エパ、雄羊には十分の二エパ、</span>
<span className="v" id="v4" data-v="4"> 七頭の子羊のそれぞれ一頭には十分の一エパをささげなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 28:30; 民数記 28:15; 民数記 28:22"> また、あなたがたのために贖罪を行うため、贖罪のささげ物として雄山羊一頭をささげなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 28:3–8; 民数記 28:11–15; 民数記 29:18"> これは、新月の全焼のささげ物と穀物のささげ物、絶えずささげる全焼のささげ物と穀物のささげ物、および定めに従った注ぎのささげ物に加える、主への芳ばしい香りとなる火によるささげ物である。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マタイ 5:4; レビ記 16:29–31; ゼカリヤ書 12:10"> この第七の月の十日には聖なる集会を開き、身を戒め、いかなる仕事もしてはならない。</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 28:19; 民数記 29:13; 民数記 29:2"> 主への芳ばしい香りとなる全焼のささげ物として、若い雄牛一頭、雄羊一頭、一歳の雄の子羊七頭をささげる。それらは傷のないものとする。</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 15:3–12"> その穀物のささげ物は油を混ぜた上質の小麦粉とし、牛には十分の三エパ、一頭の雄羊には十分の二エパ、</span>
<span className="v" id="v10" data-v="10"> 七頭の子羊のそれぞれ一頭には十分の一エパをささげなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 16:3; レビ記 16:5; 民数記 28:3–8"> 贖罪のささげ物として雄山羊一頭をささげる。これは贖罪日の贖罪のささげ物、絶えずささげる全焼のささげ物、穀物のささげ物、および注ぎのささげ物に加えるものである。</span>
</div>
<div className="bp">

<span className="v" id="v13" data-v="13" data-xref="民数記 28:11; エズラ記 3:4; 民数記 29:2"> 主への芳ばしい香りとなる火による全焼のささげ物として、若い雄牛十三頭、雄羊二頭、一歳の雄の子羊十四頭をささげる。それらは傷のないものとする。</span>
<span className="v" id="v14" data-v="14"> その穀物のささげ物は油を混ぜた上質の小麦粉とし、十三頭の牛のそれぞれ一頭に十分の三エパ、二頭の雄羊のそれぞれ一頭に十分の二エパ、</span>
<span className="v" id="v15" data-v="15"> 十四頭の子羊のそれぞれ一頭に十分の一エパをささげなさい。</span>
<span className="v" id="v16" data-v="16"> また、絶えずささげる全焼のささげ物、穀物のささげ物、注ぎのささげ物に加えて、贖罪のささげ物として雄山羊一頭をささげる。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 8:13; 詩篇 50:8–9; 詩篇 69:31"> 二日目には、若い雄牛十二頭、雄羊二頭、一歳の傷のない雄の子羊十四頭をささげる。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 28:7; 民数記 15:4–12; 民数記 28:14"> 雄牛、雄羊、子羊に添える穀物のささげ物と注ぎのささげ物は、定めに従い、その数に応じてささげる。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 29:11; 民数記 29:25; 民数記 29:22"> また、絶えずささげる全焼のささげ物と穀物のささげ物、注ぎのささげ物に加えて、贖罪のささげ物として雄山羊一頭をささげる。</span>
</div>

<span className="v" id="v21" data-v="21"> 雄牛、雄羊、子羊に添える穀物のささげ物と注ぎのささげ物は、定めに従い、その数に応じてささげる。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨエル書 1:13; 詩篇 16:4; ヨエル書 2:14"> また、絶えずささげる全焼のささげ物と穀物のささげ物、注ぎのささげ物に加えて、贖罪のささげ物として雄山羊一頭をささげる。</span>

<span className="v" id="v23" data-v="23"> 四日目には、雄牛十頭、雄羊二頭、一歳の傷のない雄の子羊十四頭をささげる。</span>
<span className="v" id="v24" data-v="24"> 雄牛、雄羊、子羊に添える穀物のささげ物と注ぎのささげ物は、定めに従い、その数に応じてささげる。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ユダ 1:11; 申命記 11:6; 出エジプト記 6:21"> レビの子ケハテの子イツハルの子コラは、ルベン族のエリアブの子ダタンとアビラム、ペレトの子オンと組み、</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 26:9; エゼキエル書 23:10; 創世記 6:4"> イスラエルの子らの中から二百五十人を率いてモーセに逆らって立った。彼らは会衆の指導者、集会に召された名のある人々であった。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 106:16; 民数記 14:14; 出エジプト記 19:6"> 彼らはモーセとアロンに逆らって集まり、言った。「あなたがたは行き過ぎている。全会衆は一人残らず聖なる者であり、主がそのただ中におられる。それなのに、なぜ主の集会の上に立とうとするのか。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="民数記 14:5; 民数記 20:6; ヨシュア記 7:6"> モーセはこれを聞くと、ひれ伏した。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 65:4; 民数記 17:5; テモテへの第二の手紙 2:19"> コラとその仲間すべてに言った。「朝になれば、主はだれがご自分のものか、だれが聖なる者かを示し、その者をみもとに近づけられる。主が選ばれる者を、みもとに近づけられる。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 10:1; 民数記 16:46–48; 列王記第一 18:21–23"> コラとその全仲間よ、このようにしなさい。あなたがたは香炉を取りなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 16:3; エペソ人への手紙 1:4; 列王記第一 18:17–18"> 明日、主の前でその中に火を入れ、その上に香を置きなさい。主が選ばれるその人こそが聖なる者となる。レビの子らよ、あなたがたは行き過ぎている！」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> モーセはコラに言った。「レビの子らよ、今聞きなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 7:13; 申命記 10:8; エゼキエル書 44:10–11"> イスラエルの神があなたがたを会衆から分け、みもとに近づけ、主の幕屋で奉仕させ、会衆の前に立って仕えさせてくださったことは、小さなことなのか。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 13:10; ヨハネの手紙第三 1:9; 民数記 18:7"> 主はあなたと、兄弟であるレビの子らすべてをみもとに近づけられた。それなのに、祭司の務めまでも求めるのか。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 16:7–8; 出エジプト記 17:2; 民数記 16:3"> それゆえ、あなたとあなたの全仲間は主に逆らって集まったのだ！ アロンが何者だから、あなたがたは彼に向かってつぶやくのか。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ペテロの手紙第一 2:13–14; ユダ 1:8; 箴言 29:9"> モーセはエリアブの子ダタンとアビラムを呼びに人を遣わしたが、彼らは言った。「私たちは上って行かない！</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 7:35; 出エジプト記 2:14; 民数記 11:5"> あなたが私たちを乳と蜜の流れる地から導き上って、この荒野で殺そうとしていることは、小さなことなのか。そのうえ、あなたは私たちの上で支配者として振る舞おうとするのか。</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 20:24; 民数記 36:8–10; 民数記 20:5"> しかも、あなたは私たちを乳と蜜の流れる地に導き入れず、畑とぶどう園を相続地として与えてもいない。あなたはこの人たちの目をえぐり出すつもりか。私たちは上って行かない。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 4:4–5; コリント人への第二の手紙 7:2; テサロニケ人への手紙第一 2:10"> モーセは非常に怒り、主に言った。「彼らのささげ物を顧みないでください。私は彼らからろば一頭も取っておらず、彼らのうちのだれにも害を与えていません。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="サムエル記第一 12:3; サムエル記第一 12:7; テモテへの第二の手紙 2:14"> モーセはコラに言った。「明日、あなたとあなたの全仲間は、あなたと彼ら、そしてアロンとともに、主の前に出なさい。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記第一 12:7"> それぞれ香炉を取り、その上に香を置き、主の前に携えて来なさい。香炉は二百五十ある。あなたもアロンも、それぞれ自分の香炉を持って来なさい。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 彼らは各自自分の香炉を取り、その中に火を入れ、その上に香を置き、モーセとアロンとともに会見の天幕の入口に立った。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 14:10; 民数記 16:42; 出エジプト記 16:7"> コラは、会見の天幕の入口で彼らに向かい合うように、全会衆を集めた。<br />主の栄光が全会衆に現れた。</span>
<span className="v" id="v20" data-v="20"> 主はモーセとアロンに告げられた。</span>
<span className="v" id="v21" data-v="21" data-xref="民数記 16:45; 出エジプト記 32:10; 詩篇 73:19"> 「この会衆の間から離れなさい。わたしが一瞬のうちに彼らを滅ぼし尽くすためである！」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数記 27:16; ゼカリヤ書 12:1; ヨブ記 12:10"> 彼らはひれ伏して言った。「神よ、すべての肉なるものの霊の神よ。一人の人が罪を犯したからといって、あなたは全会衆に向かって怒られるのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 主はモーセに告げられた。</span>
<span className="v" id="v24" data-v="24" data-xref="民数記 16:21"> 「会衆にこう告げなさい。『コラ、ダタン、アビラムの天幕の周りから離れなさい！』」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="民数記 11:16–17; 民数記 11:25; 民数記 11:30"> モーセは立ち上がり、ダタンとアビラムのところに行った。イスラエルの長老たちも彼に従った。</span>
<span className="v" id="v26" data-v="26" data-xref="イザヤ書 52:11; コリント人への第二の手紙 6:17; ヨハネの黙示録 18:4"> 彼は会衆に言った。「どうか、この邪悪な男たちの天幕から離れ、彼らのものにはいっさい触れないでください。彼らのすべての罪に巻き込まれて滅ぼされないためです！」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ヨブ記 9:4; イザヤ書 28:14; ヨブ記 40:10–11"> そこで彼らは、四方からコラ、ダタン、アビラムの天幕から離れた。ダタンとアビラムは出て来て、妻、息子、幼子たちとともに自分たちの天幕の入口に立った。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヨハネ 6:38; 出エジプト記 3:12; ヨハネ 14:11"> モーセは言った。「これによって、主がこれらすべてを行わせるために私を遣わされたこと、私自身の考えによるものではないことがわかる。</span>
<span className="v" id="v29" data-v="29" data-xref="哀歌 4:22; 列王記第一 22:28; 出エジプト記 32:34"> もしこの者たちがすべての人の普通の死に方で死ぬか、すべての人が経験することを経験するなら、主は私を遣わされたのではない。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 55:15; 民数記 16:33; ヨブ記 31:3"> しかし、もし主が新しい事をなされ、地面がその口を開いて彼らとそのすべての持ち物を飲み込み、彼らが生きたままよみ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="よみは死者の場所である。">a</a></sup>に下るなら、この者たちが主を侮ったことをあなたがたは理解するであろう。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="詩篇 106:17–18; 民数記 27:3; 申命記 11:6"> 彼がこれらすべての言葉を語り終えると、彼らの下にある地面が裂けた。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 106:17; 民数記 26:11; ヨハネの黙示録 12:16"> 地はその口を開き、彼らとその家族、コラに属するすべての人々、そしてすべての財産を飲み込んだ。</span>
<span className="v" id="v33" data-v="33" data-xref="エゼキエル書 32:18; イザヤ書 14:9; 詩篇 9:15"> 彼らとそのすべての持ち物は生きたままよみ<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="よみは死者の場所である。">b</a></sup>に下った。地は彼らの上を閉じ、彼らは集会の中から滅び去った。</span>
<span className="v" id="v34" data-v="34" data-xref="ゼカリヤ書 14:5; イザヤ書 33:3; ヨハネの黙示録 6:15–17"> 周りにいたイスラエルの人々は皆、その叫び声を聞いて逃げた。「地が私たちまで飲み込むぞ！」と言ったのである。</span>
<span className="v" id="v35" data-v="35" data-xref="民数記 26:10; レビ記 10:2; 詩篇 106:18"> 主のもとから火が出て、香をささげた二百五十人を焼き尽くした。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36"> 主はモーセに告げられた。</span>
<span className="v" id="v37" data-v="37" data-xref="レビ記 27:28; 民数記 16:18; 民数記 16:7"> 「祭司アロンの子エルアザルに、焼け残った中から香炉を取り上げ、その火を宿営から離れた所にまき散らすように言いなさい。それらは聖なるものだからである。</span>
<span className="v" id="v38" data-v="38" data-xref="民数記 26:10; エゼキエル書 14:8; ペテロの第二の手紙 2:6"> 自らの命を失う罪を犯した者たちの香炉を、打ち延ばして祭壇を覆う板にしなさい。彼らが主の前にささげたので、それらは聖なるものとなった。イスラエルの子らへのしるしとする。」</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39"> 祭司エルアザルは、焼かれた者たちがささげた青銅の香炉を取った。人々はそれらを祭壇を覆うために打ち延ばした。</span>
<span className="v" id="v40" data-v="40" data-xref="民数記 3:10; 民数記 18:4–7; 歴代誌 第二 26:16–21"> これは、アロンの子孫ではない者が主の前で香をたくために近づき、コラとその仲間のようにならないため、イスラエルの子らへの記念となった。主がモーセを通してエルアザルに告げられたとおりである。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数記 16:1–7; 詩篇 106:23; 民数記 14:2"> しかし翌日、イスラエルの子らの全会衆はモーセとアロンに向かってつぶやいて言った。「あなたがたが主の民を殺したのだ！」</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="民数記 16:19; レビ記 9:23; 民数記 20:6"> 会衆がモーセとアロンに逆らって集まり、彼らが会見の天幕の方を見たとき、見よ、雲がそれを覆い、主の栄光が現れた。</span>
<span className="v" id="v43" data-v="43"> モーセとアロンは会見の天幕の前に来た。</span>
<span className="v" id="v44" data-v="44"> 主はモーセに告げられた。</span>
<span className="v" id="v45" data-v="45" data-xref="民数記 16:21–22; 民数記 16:24; 民数記 20:6"> 「この会衆の間から離れなさい。わたしが一瞬のうちに彼らを滅ぼし尽くすためである！」彼らはひれ伏した。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="民数記 8:19; 歴代誌上 27:24; レビ記 10:6"> モーセはアロンに言った。「香炉を取り、祭壇の火を入れ、香を置き、急いで会衆のところへ行って贖いを行いなさい。主のもとから御怒りが出て、疫病が始まった。」</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="マタイ 5:44; 申命記 33:10–11; 詩篇 106:29"> アロンはモーセが言ったとおりに、集会のただ中へ走って行った。疫病はすでに民の間で始まっていた。彼は香をたき、民のために贖いを行った。</span>
<span className="v" id="v48" data-v="48" data-xref="サムエル記第二 24:25; ヘブル人への手紙 7:24–25; 民数記 16:18"> アロンは死者と生きている者との間に立ち、疫病はとどまった。</span>
<span className="v" id="v49" data-v="49" data-xref="民数記 25:9; 民数記 16:32–35; ヘブル人への手紙 2:1–3"> コラの件で死んだ者たちのほかに、この疫病で死んだ者は一万四千七百人であった。</span>
<span className="v" id="v50" data-v="50" data-xref="歴代誌上 21:26–30; 民数記 16:43"> 疫病がとどまると、アロンは会見の天幕の入口にいるモーセのもとへ戻った。</span>
</div>

<span className="v" id="v2" data-v="2" data-xref="レビ記 21:1; レビ記 13:46; 民数記 12:14"> 「イスラエルの子らに命じて、重い皮膚病を患う者、漏出のある者、死体によって汚れた者を、すべて宿営の外に出させなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 23:14; レビ記 26:11–12; 詩篇 68:18"> 男も女も宿営の外に出す。わたしがそのただ中に住む宿営を、彼らが汚さないためである。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> イスラエルの子らはそのとおりに行い、彼らを宿営の外に出した。主がモーセに告げられたとおりに行った。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 主はモーセに告げられた。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 5:1–4; レビ記 5:14–7"> 「イスラエルの子らにこう告げなさい。『男であれ女であれ、人に対して罪を犯し、主に背いて罪責を負ったなら、</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 5:5; レビ記 26:40; ヨシュア記 7:19"> その者は犯した罪を告白する。損害を全額償い、さらにその五分の一を加えて、損害を与えた相手に渡す。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 6:6–7; レビ記 7:7; レビ記 25:25–26"> しかし、償いを受け取る近親者がその人にいないなら、その償いは主のものとして祭司に渡される。これは、その人のために贖いを行う雄羊とは別である。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 18:3–4; レビ記 7:6–14; レビ記 6:17–18"> イスラエルの子らが祭司のもとに携えて来る聖なるささげ物のうち、すべての奉納物は祭司のものとなる。</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 10:13"> 人がささげる聖なるものは祭司のものとなり、だれであれ祭司に与えたものは、その祭司のものとなる。』」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 主はモーセに告げられた。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 5:19–20; 箴言 2:16–17"> 「イスラエルの子らにこう告げなさい。『ある人の妻が道を外れ、夫に不実を働き、</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 18:20; レビ記 20:10; 箴言 7:18–19"> 別の男が彼女と関係を持ったが、それが夫の目から隠され、事実が知られないまま彼女が身を汚しても、証人がなく、現場で捕らえられなかった場合、</span>
<span className="v" id="v14" data-v="14" data-xref="雅歌 8:6; 箴言 6:34; ゼパニヤ書 3:8"> 夫にねたみの思いが起こり、妻が実際に身を汚していたために彼女を疑う場合、または、妻は身を汚していないのに、夫にねたみの思いが起こって彼女を疑う場合、</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 29:16; 列王記第一 17:18; レビ記 5:11"> 夫は妻を祭司のもとに連れて行き、彼女のためのささげ物として、大麦の粉十分の一エパ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一エパは約22リットル、または約3分の2ブッシェルである。">a</a></sup>を携えて行く。その上に油を注いだり、乳香を添えたりしてはならない。これは、ねたみのための穀物のささげ物、咎を思い起こさせる記念のささげ物である。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 2:22–23; エレミヤ書 17:10; ヘブル人への手紙 13:4"> 祭司は女を近づけ、主の前に立たせる。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 30:18; ヨハネ 8:6; 民数記 19:2–9"> 祭司は土の器に聖なる水を取り、幕屋の床のちりを少し取って水に入れる。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 5:4; 民数記 5:22; ヨハネの黙示録 10:9–10"> 祭司は女を主の前に立たせ、髪をほどき、記念の穀物のささげ物、すなわちねたみのための穀物のささげ物を両手に持たせる。祭司は、呪いをもたらす苦い水を手に持つ。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 7:2; 民数記 5:12; マタイ 26:63"> 祭司は女に誓わせ、こう言う。『もしほかの男があなたと関係を持たず、あなたが夫のもとにありながら道を外れて身を汚したことがないなら、呪いをもたらすこの苦い水によって害を受けることはない。</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 5:12"> しかし、あなたが夫のもとにありながら道を外れて身を汚し、夫以外の男があなたと関係を持ったのなら——』</span>
<span className="v" id="v21" data-v="21" data-xref="ヨシュア記 6:26; ネヘミヤ記 10:29; サムエル記第一 14:24"> 祭司は女に呪いの誓いを立てさせ、こう言う。『主があなたのももを衰えさせ、腹を膨れさせるとき、主があなたを民の中で呪いと誓いの的とされるように。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 109:18; 詩篇 89:52; ヨブ記 31:39–40"> 呪いをもたらすこの水があなたの腹に入り、腹を膨れさせ、ももを衰えさせるように。』女は『アーメン、アーメン』と答える。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 3:19; 詩篇 51:1; 詩篇 51:9"> 祭司はこれらの呪いを巻物に書き、それを苦い水の中に洗い落とす。</span>
<span className="v" id="v24" data-v="24" data-xref="ゼカリヤ書 5:3–4; マラキ書 3:5"> 女に呪いをもたらす苦い水を飲ませる。その水は女の内に入り、苦い結果をもたらす。</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 8:27; 民数記 5:18; 民数記 5:15"> 祭司は女の手からねたみのための穀物のささげ物を取り、主の前で揺り動かし、祭壇に運ぶ。</span>
<span className="v" id="v26" data-v="26" data-xref="レビ記 2:2; レビ記 2:9; レビ記 5:12"> その穀物のささげ物から記念の分として一握りを取り、祭壇の上で焼く。その後、女に水を飲ませる。</span>
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 42:18; ゼカリヤ書 8:13; エレミヤ書 29:18"> 水を飲ませた後、もし女が身を汚し、夫に不実を働いていたなら、呪いをもたらす水が内に入り、苦い結果をもたらす。腹は膨れ、ももは衰え、その女は民の中で呪いの的となる。</span>
<span className="v" id="v28" data-v="28" data-xref="ミカ書 7:7–10; コリント人への第二の手紙 4:17; 詩篇 113:9"> しかし、女が身を汚しておらず、清いなら、害を受けず、子を宿す。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または「種」。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数記 5:19; 民数記 5:12; 民数記 5:15"> これがねたみについての律法である。妻が夫のもとにありながら道を外れ、身を汚した場合、</span>
<span className="v" id="v30" data-v="30"> または男にねたみの思いが起こって妻を疑った場合、男は女を主の前に立たせ、祭司はこの律法をすべて彼女に行う。</span>
<span className="v" id="v31" data-v="31" data-xref="レビ記 20:10; ローマ人への手紙 2:8–9; エゼキエル書 18:4"> 夫は咎を負わず、女は自分の咎を負う。』」</span>
</div>
</div>

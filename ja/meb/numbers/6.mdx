<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 13:5; アモス書 2:11–12; ローマ人への手紙 1:1"> 「イスラエルの子らにこう告げなさい。『男であれ女であれ、主に身をささげる特別な誓願、すなわちナジル人の誓願を立てる場合、</span>
<span className="v" id="v3" data-v="3" data-xref="ルカ 1:15; テモテへの手紙第一 5:23; アモス書 2:12"> その人はぶどう酒と強い酒を断つ。ぶどう酒から作った酢も、強い酒から作った酢も飲まず、ぶどうの汁を飲んではならない。生のぶどうも干しぶどうも食べてはならない。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 6:5; 民数記 6:21; 民数記 6:8–9"> 身をささげている全期間、種から皮に至るまで、ぶどうの木からできるものは何も食べてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="サムエル記第一 1:11; 士師記 16:17; 士師記 13:5"> 身をささげる誓願の全期間、主に身をささげる日々が満ちるまで、頭に剃刀を当ててはならない。その人は聖なる者であり、髪を長く伸ばす。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="レビ記 21:11; レビ記 19:28; レビ記 21:1–3"> 主に身をささげている全期間、死体に近づいてはならない。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 9:6; レビ記 21:1–2; レビ記 21:10–12"> 父、母、兄弟、姉妹が死んだときであっても、そのために身を汚してはならない。神<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「神」と訳されているヘブル語は「אֱלֹהִים」（エロヒム）である。">a</a></sup>に身をささげているしるしが、その頭にあるからである。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第二の手紙 6:17–18"> 身をささげている全期間、その人は主にとって聖なる者である。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数記 6:18; 使徒の働き 18:18; レビ記 14:9"> もしだれかがその人のそばで突然死に、ナジル人として聖別された頭を汚したなら、清めの日、すなわち第七の日に頭を剃る。</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 15:29; レビ記 1:14; レビ記 15:14"> 第八の日に、山鳩二羽、または家鳩の雛二羽を、会見の天幕の入口にいる祭司のもとに携えて行く。</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 14:30–31; レビ記 5:8–10"> 祭司は一羽を贖罪のささげ物、もう一羽を全焼のささげ物としてささげ、死体によって罪を負ったその人のために贖いを行う。その日に、その人の頭を改めて聖別する。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 5:6; マタイ 24:13; レビ記 14:24"> その人は、主に身をささげる日々を改めて始め、償いのささげ物として一歳の雄の子羊を携えて行く。聖別が汚されたため、以前の日々は無効となる。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 21:26"> ナジル人についての律法は次のとおりである。身をささげる日々が満ちたとき、その人は会見の天幕の入口に出て、</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 3:6; レビ記 4:32; レビ記 4:2–3"> 主へのささげ物として、全焼のささげ物に傷のない一歳の雄の子羊一頭、贖罪のささげ物に傷のない一歳の雌の子羊一頭、和解のいけにえに傷のない雄羊一頭、</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 2:4; 出エジプト記 29:2; 民数記 15:10"> また、油を混ぜた上質の小麦粉で作った種なしの菓子と、油を塗った種なしの薄焼きパンを入れた籠を、それらに伴う穀物のささげ物と注ぎのささげ物とともに携えて来る。</span>
<span className="v" id="v16" data-v="16"> 祭司はこれらを主の前にささげ、その人の贖罪のささげ物と全焼のささげ物をささげる。</span>
<span className="v" id="v17" data-v="17"> 雄羊を、種なしパンの籠とともに、主への和解のいけにえとしてささげる。祭司は、それに伴う穀物のささげ物と注ぎのささげ物もささげる。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 21:24; 民数記 6:9; 使徒の働き 18:18"> ナジル人は会見の天幕の入口で、聖別された頭を剃り、その髪を取って、和解のいけにえの下にある火にくべる。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記第一 2:15; レビ記 7:30; 出エジプト記 29:23–28"> 祭司は雄羊の煮た肩肉と、籠から種なしの菓子一つ、種なしの薄焼きパン一つを取り、ナジル人が頭を剃った後、それらをその人の手に置く。</span>
<span className="v" id="v20" data-v="20" data-xref="伝道者の書 9:7; 出エジプト記 29:27–28; 民数記 5:25"> 祭司はそれらを主の前で揺り動かすささげ物としてささげる。これらは、揺り動かした胸肉と奉納したもも肉とともに、祭司に属する聖なるものである。その後、ナジル人はぶどう酒を飲むことができる。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ヘブル人への手紙 13:16; エズラ記 2:69; 民数記 5:29"> 以上が、誓願を立てたナジル人と、その聖別のために主にささげるものについての律法である。そのほか、力に応じたささげ物を加えることができる。立てた誓願に従い、ナジル人についての律法どおりに行う。』」</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22"> 主はモーセに告げられた。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 21:5; 歴代誌上 23:13; 創世記 48:20"> 「アロンとその子らに告げなさい。イスラエルの子らを祝福するとき、こう言いなさい。</span>
<span className="v" id="v24" data-v="24" data-xref="テサロニケ人への手紙第一 5:23; 詩篇 121:4–7; ピリピ人への手紙 4:7"> <span className="pl pl-1">『主があなたを祝福し、あなたを守られるように。</span></span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 80:19; 詩篇 119:135; 詩篇 31:16"> <span className="pl pl-2">主が御顔をあなたの上に輝かせ、</span><br /><span className="pl pl-2">あなたを恵まれるように。</span></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 4:6; 詩篇 29:11; テサロニケ人への第二の手紙 3:16"> <span className="pl pl-1">主が御顔をあなたに向け、</span><br /><span className="pl pl-2">あなたに平安を与えられるように。』</span></span>
</div>
<div className="bp">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセとアロンに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 22:20–25; 申命記 21:3; サムエル記第一 6:7"> 「主が命じられた律法の掟は次のとおりである。イスラエルの子らに、傷も欠陥もなく、まだくびきを負ったことのない赤い雌牛を連れて来るよう告げなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 4:12; レビ記 4:21; レビ記 16:27"> それを祭司エルアザルに渡す。彼は宿営の外へ引き出し、自分の前で屠らせる。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 4:17; レビ記 4:6; レビ記 16:14"> 祭司エルアザルはその血を指に取り、会見の天幕の正面に向かって七度振りかける。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 29:14; レビ記 4:11–12; 詩篇 22:14"> 雌牛は彼の前で焼かれる。その皮、肉、血を、糞とともに焼く。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 14:4; レビ記 14:49; 詩篇 51:7"> 祭司は杉の木、ヒソプ、緋色の糸を取り、燃えている雌牛の中に投げ入れる。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 11:25; レビ記 11:40; 民数記 19:8"> その後、祭司は衣服を洗い、体を水で洗う。それから宿営に入ることができるが、夕方まで汚れている。</span>
<span className="v" id="v8" data-v="8"> 雌牛を焼いた者も衣服を水で洗い、体を水で洗う。彼は夕方まで汚れている。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヘブル人への手紙 9:13; 民数記 19:13; 民数記 19:20–21"> 清い人が雌牛の灰を集め、宿営の外の清い場所に置く。それはイスラエルの子らの会衆のため、汚れを清める水に用いるものとして保管する。これは贖罪のささげ物である。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 12:49; 民数記 19:7–8; コロサイ人への手紙 3:11"> 雌牛の灰を集めた者は衣服を洗い、夕方まで汚れている。これはイスラエルの子らにも、彼らの間に住む寄留者にも、永遠の掟となる。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民数記 5:2; 民数記 31:19; レビ記 21:1"> 人の死体に触れた者は七日間汚れる。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 31:19; ヨハネの黙示録 7:14; レビ記 7:17"> その者は三日目と七日目にその水で身を清め、七日目に清くなる。しかし、三日目と七日目に身を清めなければ、清くならない。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 15:31; レビ記 22:3; レビ記 7:20"> 死んだ人の体に触れながら身を清めない者は、主の幕屋を汚す。その者はイスラエルから断たれる。汚れを清める水を振りかけられなかったので、その人は汚れており、汚れはなおその身にある。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 人が天幕の中で死んだ場合の律法は次のとおりである。その天幕に入る者も、中にいる者も、みな七日間汚れる。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 14:36; レビ記 11:32; 民数記 31:20"> ふたをして封じていない開いた器は、すべて汚れる。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数記 31:19; マタイ 23:27; ルカ 11:44"> 野外で、剣で殺された者、死体、人の骨、あるいは墓に触れた者は、七日間汚れる。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヨハネ 7:38; 創世記 26:19; ヨハネの黙示録 7:17"> 汚れた者のために、贖罪のささげ物を焼いた灰を取り、器の中でその上に流水を注ぐ。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 36:25–27; ヘブル人への手紙 9:14; 民数記 19:9"> 清い人がヒソプを取り、その水に浸して、天幕、すべての器、そこにいた人々、また骨、殺された者、死体、あるいは墓に触れた者に振りかける。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの手紙第一 1:7; ヘブル人への手紙 10:22; エゼキエル書 36:25"> 清い人は三日目と七日目に、汚れた者に振りかける。七日目にその人を清める。その人は衣服を洗い、体を水で洗い、夕方には清くなる。</span>
<span className="v" id="v20" data-v="20" data-xref="マルコ 16:16; 創世記 17:14; 民数記 19:13"> しかし、汚れていながら身を清めない者は、集会の中から断たれる。主の聖所を汚したからである。汚れを清める水を振りかけられなかったので、その人は汚れている。</span>
<span className="v" id="v21" data-v="21" data-xref="ヘブル人への手紙 9:13–14; ヘブル人への手紙 10:4; ヘブル人への手紙 9:10"> これは彼らにとって永遠の掟となる。汚れを清める水を振りかけた者は衣服を洗い、その水に触れた者は夕方まで汚れている。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ハガイ書 2:13; レビ記 7:19; マタイ 15:19–20"> 汚れた者が触れるものはすべて汚れ、それに触れた者も夕方まで汚れている。」</span>
</div>

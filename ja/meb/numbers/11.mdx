<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 21:5; 民数記 16:35; 列王記第二 1:12"> 民は主の耳に不平を漏らした。主がそれを聞かれると御怒りが燃え上がり、主の火が彼らの間で燃えて、宿営の外れを焼き尽くした。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 21:7; ヤコブの手紙 5:16; 民数記 16:45–48"> 民がモーセに叫び求めると、モーセは主に祈り、火は鎮まった。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 9:22"> 主の火が彼らの間で燃えたため、その場所はタベラ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="タベラは「燃えること」を意味する。">a</a></sup>と呼ばれた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 10:6; 出エジプト記 12:38; 詩篇 106:14"> 彼らの中にいた寄り集まりの者たちは激しい欲望に駆られ、イスラエルの子らも再び泣き出して言った。「だれが私たちに肉を食べさせてくれるのか。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 16:3; 詩篇 17:14; ピリピ人への手紙 3:19"> 私たちはエジプトでただで食べていた魚、きゅうり、すいか、にら、玉ねぎ、にんにくを思い出す。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 21:5; サムエル記第二 13:4"> しかし今、食欲はすっかり失せてしまった。目に入るのは、このマナだけだ。」</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 16:31; 創世記 2:12; 出エジプト記 16:14–15"> マナはコリアンダーの種のようで、その色はブデリウム<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ブデリウムは、アフリカなどの樹木から採れる芳香性の樹脂である。">b</a></sup>のようであった。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 16:31; 出エジプト記 16:16–18; 出エジプト記 16:23"> 民は歩き回ってそれを集め、ひき臼でひくか、鉢でつき、鍋で煮て、平たい菓子を作った。その味は新鮮な油のようであった。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 16:13–14; 詩篇 78:23–25; 申命記 32:2"> 夜、宿営に露が降りるとき、マナもその上に降った。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="詩篇 78:21; 民数記 16:27; 民数記 14:1–2"> モーセは、民が氏族ごとに、それぞれ天幕の入口で泣いているのを聞いた。主の御怒りは激しく燃え上がり、モーセも心を痛めた。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 1:12; 出エジプト記 5:22; エレミヤ書 15:10"> モーセは主に言った。「なぜ、しもべをこれほど苦しめられるのですか。なぜ私を顧みず、この民すべての重荷を負わせられるのですか。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 49:23; イザヤ書 40:11; テサロニケ人への手紙第一 2:7"> 私がこの民すべてを身ごもり、産んだのでしょうか。それなのに、あなたは私に、『乳母が乳飲み子を抱くように、彼らを胸に抱き、父祖たちに誓った地へ連れて行け』と言われるのですか。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイ 15:33; マルコ 8:4; ヨハネ 6:5–9"> どこから、この民すべてに与える肉を得られるでしょう。彼らは私の前で泣き、『肉を与えて食べさせてくれ』と言うのです。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 18:18; 申命記 1:9–12; コリント人への第二の手紙 2:16"> 私一人では、このすべての民を背負うことはできません。私には重すぎるからです。</span>
<span className="v" id="v15" data-v="15" data-xref="ピリピ人への手紙 1:20–24; 列王記第一 19:4; ヨナ書 4:3"> このように扱われるのなら、どうか今すぐ私を殺してください。私を顧みてくださるなら、これ以上、私の惨めさを見せないでください。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 24:1; 出エジプト記 24:9; 申命記 16:18"> 主はモーセに言われた。「イスラエルの長老たちの中から、民の長老、役人であるとあなたが認める者を七十人集めなさい。会見の天幕に連れて来て、そこであなたとともに立たせなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="民数記 11:25; サムエル記第一 10:6; コリント人への第一の手紙 12:4–11"> わたしはそこに降り、あなたと語る。あなたにある霊を分けて彼らに与える。彼らはあなたとともに民の重荷を担い、あなたが一人で担わなくてもよいようにする。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 19:10; 使徒の働き 7:39; 出エジプト記 16:3–7"> 民に言いなさい。『明日に備えて身を聖別しなさい。あなたがたは肉を食べる。あなたがたが主の耳に泣き声を届かせ、「だれが肉を食べさせてくれるのか。エジプトにいたときは良かった」と言ったからである。主はあなたがたに肉を与え、あなたがたは食べる。</span>
<span className="v" id="v19" data-v="19"> あなたがたは一日、二日、五日、十日、あるいは二十日だけ食べるのではない。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 106:15; 民数記 21:5; 詩篇 78:27–30"> 丸一か月の間、それがあなたがたの鼻からあふれ出て、嫌になるまで食べる。あなたがたが、自分たちの間にいる主を拒み、主の御前で泣いて、「なぜ私たちはエジプトから出てきたのだろうか」と言ったからである。』」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 12:37; 民数記 1:46; 創世記 12:2"> モーセは言った。「私と一緒にいる民は、徒歩の男だけで六十万人です。それなのに、あなたは『彼らに肉を与え、丸一か月の間食べさせる』と言われます。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイ 15:33; 列王記第二 7:2; ヨハネ 6:9"> 彼らに十分なように、羊や牛の群れを屠るというのでしょうか。あるいは、彼らに十分なように、海の魚をすべて集めるというのでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 59:1; イザヤ書 50:2; 創世記 18:14"> 主はモーセに言われた。「主の手が短いとでもいうのか。わたしの言葉が実現するかどうか、今にわかる。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数記 11:16; 民数記 11:26"> モーセは外に出て、主の言葉を民に告げた。彼は民の長老たちの中から七十人を集め、彼らを天幕の周りに立たせた。</span>
<span className="v" id="v25" data-v="25" data-xref="民数記 11:17; ヨエル書 2:28–29; サムエル記第一 10:10"> 主は雲の中に降り、モーセに語られた。そしてモーセにある霊を分けて、七十人の長老たちに与えた。霊が彼らの上にとどまると、彼らは預言した。しかし、その後は預言しなかった。</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 36:5; サムエル記第一 20:26; サムエル記第一 10:22"> しかし、二人の者が宿営に残っていた。一人の名はエルダド、もう一人の名はメダドであった。霊が彼らの上にとどまった。彼らも登録された者たちであったが、天幕には出て行かず、宿営の中で預言した。</span>
<span className="v" id="v27" data-v="27"> 若者が走って来てモーセに告げた。「エルダドとメダドが宿営の中で預言しています！」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="マルコ 9:38–40; ルカ 9:49–50; ヨハネ 3:26"> モーセの従者で、若いころから仕えていたヌンの子ヨシュアが言った。「わが主モーセよ、彼らをやめさせてください！」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="コリント人への第一の手紙 14:5; マタイ 9:37–38; ルカ 10:2"> モーセは答えた。「あなたは私のためにねたんでいるのか。主の民がみな預言者となり、主が霊を彼らの上に置いてくださればよいのに！」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> そしてモーセとイスラエルの長老たちは宿営に戻った。</span>
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 16:13; 詩篇 105:40; 詩篇 78:26–29"> さて、主のもとから風が起こり、海からうずらを運んで来て宿営の周りに落とした。それは宿営のこちら側にも向こう側にも一日の道のりほど広がり、地面から約二キュビト<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一キュビトは、ひじから中指の先までの長さで、約46センチである。">c</a></sup>の高さに及んだ。</span>
<span className="v" id="v32" data-v="32" data-xref="エゼキエル書 45:11; 出エジプト記 16:36"> 民はその日一日中、またその夜も、そして次の日も一日中起き出して、うずらを集めた。最も少なく集めた者でも十ホメル<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="1ホメルは約220リットル、または6ブッシェルである。">d</a></sup>を集めた。彼らはそれを自分たちのために宿営の周り一面に広げた。</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 78:30–31; 詩篇 106:14–15; 民数記 25:9"> 肉がまだ彼らの歯の間にあり、噛み砕かれる前に、主の怒りが民に向かって燃え上がり、主は非常に大きな疫病で民を打たれた。</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 9:22; コリント人への第一の手紙 10:6; 民数記 33:16"> その場所の名はキブロト・ハタアワ<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="キブロト・ハタアワは「欲望の墓」を意味する。">e</a></sup>と呼ばれた。そこで彼らは欲望に駆られた民を葬ったからである。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="民数記 33:17; 民数記 12:16; 申命記 1:1"> 民はキブロト・ハタアワからハツェロトへ旅立ち、ハツェロトにとどまった。</span>
</div>
</div>

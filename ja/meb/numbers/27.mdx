<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 26:33; ガラテヤ人への手紙 3:28; 歴代誌上 7:15"> ヨセフの子マナセの氏族に属する、マナセの子マキルの子ギルアデの子ヘフェルの子ゼロフェハデの娘たちが近づいて来た。娘たちの名はマフラ、ノア、ホグラ、ミルカ、ティルツァであった。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 15:33–34; 申命記 17:8–10; 出エジプト記 18:19–26"> 彼女たちは会見の天幕の入口で、モーセ、祭司エルアザル、指導者たち、および全会衆の前に立って言った。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 26:64–65; エゼキエル書 18:4; 民数記 14:35"> 「私たちの父は荒野で死にました。コラの仲間として主に逆らって集まった者たちの中にはおらず、自分の罪のために死んだのです。父には息子がいませんでした。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨシュア記 17:4; 詩篇 109:13; 出エジプト記 32:11"> 息子がいないために、なぜ父の名がその氏族から消されるのでしょう。父の兄弟たちの間で、私たちにも相続地を与えてください。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="レビ記 24:12–13; ヨブ記 23:4; 箴言 3:5–6"> モーセは彼女たちの訴えを主の前に差し出した。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 3:28; 詩篇 68:5–6"> 主はモーセに告げられた。</span>
<span className="v" id="v7" data-v="7" data-xref="ガラテヤ人への手紙 3:28; エレミヤ書 49:11; ヨシュア記 17:4"> 「ゼロフェハデの娘たちの言うことは正しい。彼女たちの父の兄弟たちの間に、必ず相続地を与え、父の相続地を娘たちに受け継がせなさい。</span>
<span className="v" id="v8" data-v="8"> イスラエルの子らにこう告げなさい。『人が死んで息子がいない場合、その相続地を娘に受け継がせる。</span>
<span className="v" id="v9" data-v="9"> もし娘もいないなら、その所有地を彼の兄弟たちに与える。</span>
<span className="v" id="v10" data-v="10"> もし兄弟たちもいないなら、その所有地を彼の父の兄弟たちに与える。</span>
<span className="v" id="v11" data-v="11" data-xref="民数記 35:29; ルツ記 4:3–6; エレミヤ書 32:8"> 父に兄弟もいない場合、その相続地を氏族の中で最も近い親族に与え、その人が受け継ぐ。これは、主がモーセに命じられたとおり、イスラエルの子らのための法令となる。』」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数記 33:47–48; 申命記 34:1–4; 申命記 3:23–27"> 主はモーセに言われた。「このアバリムの山に登り、わたしがイスラエルの子らに与える地を見なさい。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 10:6; 民数記 31:2; 民数記 20:24–28"> それを見た後、兄弟アロンと同じように、あなたもその民に加えられる。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 1:37; 民数記 20:8–13; 出エジプト記 17:7"> 会衆が争ったとき、あなたがたはツィンの荒野でわたしの命令に背き、水のことで彼らの前にわたしを聖なる者として示さなかったからである。」これはツィンの荒野、カデシュにあるメリバの水のことである。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> モーセは主に言った。</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 16:22; エレミヤ書 3:15; ヘブル人への手紙 12:9"> 「すべての肉なるものの霊を治める神、主よ、どうか会衆の上に一人の人を任命してください。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 34:5; マルコ 6:34; 列王記第一 22:17"> 彼らの先に立って出入りし、彼らを導き出し、導き入れる人です。主の会衆が、羊飼いのいない羊のようにならないためです。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命記 34:9; 民数記 27:23; 創世記 41:38"> 主はモーセに言われた。「ヌンの子ヨシュア、内に霊のある人を取り、彼の上に手を置きなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 3:28; 申命記 31:7–8; 申命記 31:23"> 彼を祭司エルアザルと全会衆の前に立たせ、彼らの前で任命しなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨシュア記 1:16–18; サムエル記第一 10:9; 列王記第二 2:9–10"> あなたの権威の一部を彼に与え、イスラエルの子らの全会衆が彼に従うようにしなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨシュア記 9:14; サムエル記第一 28:6; 出エジプト記 28:30"> 彼は祭司エルアザルの前に立ち、エルアザルは主の前で、ウリムの判断によって彼のために伺いを立てる。その命令によって、ヨシュアも、彼とともにいるイスラエルの子らも、全会衆も、出入りする。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> モーセは主が命じられたとおりに行った。彼はヨシュアを取り、彼を祭司エルアザルと全会衆の前に立たせた。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 3:28; 民数記 27:19; 申命記 31:7–8"> モーセは彼の上に手を置き、主がモーセを通して語られたとおり、彼を任命した。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 22:1; 民数記 31:12; 民数記 33:50"> 主はエリコの向かい側にあるヨルダン川のほとりのモアブの平野でモーセに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 14:3–4; エゼキエル書 48:8; ヨシュア記 21:2–42"> 「イスラエルの子らに命じ、受け継ぐ相続地から、レビ人に住むための町々を与えさせなさい。また、町々の周囲の放牧地もレビ人に与えなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代誌 第二 11:14; ヨシュア記 21:11; エゼキエル書 45:2"> 町々は彼らの住まいとなり、放牧地は家畜と財産、すべての動物のためとなる。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> レビ人に与える町々の放牧地は、町の城壁から外側へ、周囲一千キュビト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一キュビトは人の中指の先から肘までの長さで、約46センチメートル、または18インチである。">a</a></sup>とする。</span>
<span className="v" id="v5" data-v="5"> あなたがたは町を真ん中にして、町の外側の東側に二千キュビト、南側に二千キュビト、西側に二千キュビト、北側に二千キュビトを測る。これが彼らにとって町々の放牧地となる。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 21:13; ヨシュア記 21:3; 詩篇 9:9"> レビ人に与える町々のうち、六つを逃れの町とし、過失で人を死なせた者がそこへ逃れられるようにする。そのほかに四十二の町を与える。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 21:3–42; 歴代誌上 6:54–81"> あなたがたがレビ人に与えるすべての町は四十八の町となり、それらを放牧地とともに与える。</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 26:54; 民数記 33:54; ヨシュア記 21:1–42"> イスラエルの子らの所有地から町々を与えるときは、大きな部族から多く、小さな部族から少なく取る。各部族は、受け継いだ相続地に応じて町々をレビ人に与える。」</span>
<span className="v" id="v9" data-v="9"> 主はモーセに告げられた。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 12:9; 申命記 19:1–2; レビ記 14:34"> 「イスラエルの子らにこう告げなさい。『ヨルダン川を渡ってカナンの地に入るとき、</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 21:13; ヨシュア記 20:2; 民数記 35:6"> 逃れの町を定め、過失で人を死なせた者がそこへ逃れられるようにしなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 20:3–6; 申命記 19:6; ヨシュア記 20:9"> その町々は血の復讐者から逃れる場所となる。人を死なせた者は、会衆の前に立って裁きを受けるまでは死刑に処されない。</span>
<span className="v" id="v13" data-v="13"> あなたがたが与える町々は、あなたがたのための六つの逃れの町となる。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 19:8–10; 申命記 4:41–43; ヨシュア記 20:7–9"> あなたがたはヨルダン川の向こう側に三つの町を与え、カナンの地に三つの町を与える。これらは逃れの町となる。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 15:16; ガラテヤ人への手紙 3:28; ローマ人への手紙 3:29"> これら六つの町は、イスラエルの子らにも、寄留者にも、彼らの間に住む者にも逃れの場所となり、過失で人を死なせた者はだれでも、そこへ逃れることができる。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="レビ記 24:17; 創世記 9:5–6; 申命記 19:11–13"> しかし、鉄の道具で人を打って死なせたなら、その者は殺人者である。殺人者は必ず死刑に処される。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 21:18"> 人を死なせるほどの石を手にして打ち、その人が死んだなら、その者は殺人者である。殺人者は必ず死刑に処される。</span>
<span className="v" id="v18" data-v="18"> 人を死なせるほどの木の道具を手にして打ち、その人が死んだなら、その者は殺人者である。殺人者は必ず死刑に処される。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 20:3; 申命記 19:6; 申命記 19:12"> 血の復讐者が殺人者を死刑に処す。出会ったときに、その者を殺す。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 21:14; 申命記 19:11; サムエル記第二 3:27"> 憎しみから人を突き飛ばし、あるいは待ち伏せして物を投げつけ、その人が死んだ場合、</span>
<span className="v" id="v21" data-v="21"> また、敵意をもって手で打ち、その人が死んだ場合、打った者は必ず死刑に処される。その者は殺人者である。血の復讐者は出会ったときに殺人者を殺す。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数記 35:11; 出エジプト記 21:13; ヨシュア記 20:3"> しかし、敵意なく、突然人を突き飛ばした場合、または待ち伏せせずに物を投げつけた場合、</span>
<span className="v" id="v23" data-v="23"> あるいは人を死なせるほどの石を、相手に気づかず落として死なせた場合で、その人の敵ではなく、危害を加えようともしていなかったなら、</span>
<span className="v" id="v24" data-v="24" data-xref="ヨシュア記 20:6; 民数記 35:12"> 会衆はこれらの定めに従って、人を死なせた者と血の復讐者との間を裁く。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 29:7; レビ記 4:3; ローマ人への手紙 3:24–26"> 会衆はその者を血の復讐者の手から救い、逃げ込んだ逃れの町へ戻す。その者は、聖なる油を注がれた大祭司が死ぬまで、そこに住む。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> しかし、その者が逃げ込んだ逃れの町の境界を越え、</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 22:2; 申命記 19:10; 申命記 19:6"> 血の復讐者が町の境界の外で見つけて殺しても、血を流した罪はない。</span>
<span className="v" id="v28" data-v="28" data-xref="ヘブル人への手紙 3:14; ヘブル人への手紙 10:26–30; ヘブル人への手紙 6:4–8"> その者は大祭司が死ぬまで逃れの町にとどまるべきだったからである。大祭司が死んだ後は、自分の相続地に戻ることができる。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数記 27:11; 民数記 27:1"> これらは、あなたがたのすべての住まいで、代々にわたる法令となる。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ヘブル人への手紙 10:28; 申命記 19:15; マタイ 18:16"> 人を殺した者を死刑に処すには、複数の証人の証言による。一人の証人だけの証言で人を死刑に処してはならない。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="申命記 19:11–13; 創世記 9:5–6; 詩篇 51:14"> 死刑に当たる殺人者の命のために、身代金を受け取ってはならない。その者は必ず死刑に処される。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 4:12; ガラテヤ人への手紙 3:10–13; ガラテヤ人への手紙 2:21"> 逃れの町に逃げ込んだ者のために身代金を受け取り、祭司が死ぬ前にその地へ戻って住むことを許してはならない。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="ルカ 11:50–51; 詩篇 106:38; ホセア書 4:2–3"> あなたがたの住む地を汚してはならない。血は地を汚すからである。地に流された血を贖うものは、それを流した者の血以外にはない。</span>
<span className="v" id="v34" data-v="34" data-xref="民数記 5:3; 詩篇 135:21; ヨハネの黙示録 21:27"> あなたがたが住み、わたしも住む地を汚してはならない。主であるわたしは、イスラエルの子らの間に住む。』」</span>
</div>
</div>

<span className="v" id="v1" data-v="1" data-xref="民数記 23:29; ユダ 1:11; 出エジプト記 27:1–8"> バラムはバラクに言った。「ここに七つの祭壇を築き、七頭の雄牛と七頭の雄羊を用意してください。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="民数記 23:14; 民数記 23:30"> バラクはバラムの言うとおりにし、二人はそれぞれの祭壇に雄牛一頭と雄羊一頭をささげた。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 23:15; 創世記 8:20; 創世記 22:2"> バラムはバラクに言った。「あなたは全焼のささげ物のそばに立っていてください。私は行ってきます。もしかすると、主が私に会ってくださるかもしれません。示されたことをあなたに告げましょう。」<br />そして彼は何もない高台へ行った。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 23:16; エペソ人への手紙 2:9; ルカ 18:12"> 神はバラムに会われた。バラムは言った。「私は七つの祭壇を整え、それぞれに雄牛一頭と雄羊一頭をささげました。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="申命記 18:18; エレミヤ書 1:9; イザヤ書 59:21"> 主はバラムの口に言葉を置いて言われた。「バラクのもとへ戻り、このように語りなさい。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6"> バラムが戻ると、バラクはモアブのすべての指導者とともに、全焼のささげ物のそばに立っていた。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 23:4; 民数記 24:3; 民数記 22:5–6"> バラムは託宣を述べた。<br /><span className="pl pl-1">「バラクは私をアラムから、</span><br /><span className="pl pl-2">モアブの王は東の山々から連れて来た。</span><br /><span className="pl pl-1">『来て、私のためにヤコブを呪え。</span><br /><span className="pl pl-2">来て、イスラエルを責めよ。』</span></span>
<span className="v" id="v8" data-v="8" data-xref="民数記 23:23; イザヤ書 44:25; 民数記 23:20"> <span className="pl pl-1">神が呪わない者を、どうして私が呪えよう。</span><br /><span className="pl pl-2">主が責めない者を、どうして私が責められよう。</span></span>
<span className="v" id="v9" data-v="9" data-xref="申命記 33:28; 申命記 32:8; 出エジプト記 33:16"> <span className="pl pl-1">岩の頂から私は彼を見る。</span><br /><span className="pl pl-2">丘の上から彼を見渡す。</span><br /><span className="pl pl-1">見よ、ひとり離れて住み、</span><br /><span className="pl pl-2">国々の一つには数えられない民。</span></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 37:37; 創世記 13:16; 詩篇 116:15"> <span className="pl pl-1">だれがヤコブのちりを数え、</span><br /><span className="pl pl-2">イスラエルの四分の一を数えられよう。</span><br /><span className="pl pl-1">私も正しい者たちの死を遂げたい。</span><br /><span className="pl pl-2">私の終わりも彼らのようであれ。」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ネヘミヤ記 13:2; 民数記 24:10; 民数記 22:17"> バラクはバラムに言った。「あなたは私に何ということをしたのか。敵を呪わせるために連れて来たのに、彼らを祝福してしまったではないか。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数記 22:38; 民数記 23:20; 民数記 23:26"> バラムは答えた。「主が私の口に置かれる言葉を、忠実に語るべきではありませんか。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 109:17; ヤコブの手紙 3:9–10; 民数記 22:41"> バラクは言った。「どうか私と別の場所へ行ってください。そこからなら民の一部は見えますが、全体は見えません。そこから私のために彼らを呪ってください。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 46:6; 民数記 23:29; イザヤ書 1:10–11"> バラクは彼をツォフィムの野、ピスガの頂へ連れて行き、七つの祭壇を築き、それぞれの祭壇に牛一頭と雄羊一頭をささげた。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 23:3; 民数記 22:8"> バラムはバラクに言った。「私が向こうで神に会っている間、あなたはここで全焼のささげ物のそばに立っていてください。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数記 23:5; 民数記 24:1; 民数記 22:35"> 主はバラムに会い、その口に言葉を置いて言われた。「バラクのもとへ戻り、このように語りなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民数記 23:26; サムエル記第一 3:17; エレミヤ書 37:17"> バラムが戻ると、バラクはモアブの指導者たちとともに、全焼のささげ物のそばに立っていた。バラクは尋ねた。「主は何と語られたか。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="士師記 3:20"> バラムは託宣を述べた。<br /><span className="pl pl-1">「バラクよ、立って聞け。</span><br /><span className="pl pl-2">ツィポルの子よ、私に耳を傾けよ。</span></span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記第一 15:29; ヤコブの手紙 1:17; マラキ書 3:6"> <span className="pl pl-1">神は人ではなく、偽ることがない。</span><br /><span className="pl pl-2">人の子ではなく、悔いることがない。</span><br /><span className="pl pl-1">神が言われて、行わないことがあろうか。</span><br /><span className="pl pl-2">語られて、成し遂げないことがあろうか。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネ 10:27–29; 民数記 22:12; 創世記 12:2"> <span className="pl pl-1">見よ、私は祝福せよとの命を受けた。</span><br /><span className="pl pl-2">神が祝福された。私はそれを覆せない。</span></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 23:4; マタイ 1:23; エレミヤ書 50:20"> <span className="pl pl-1">ヤコブの中に咎を見ず、</span><br /><span className="pl pl-2">イスラエルの中に不正を認めない。</span><br /><span className="pl pl-1">彼らの神、主がともにおられ、</span><br /><span className="pl pl-2">王を迎える歓声がその中に響く。</span></span>
<span className="v" id="v22" data-v="22" data-xref="民数記 24:8; 申命記 33:17; ヨブ記 39:9–11"> <span className="pl pl-1">神は彼らをエジプトから導き出された。</span><br /><span className="pl pl-2">彼らには野牛のような力がある。</span></span>
<span className="v" id="v23" data-v="23" data-xref="ルカ 10:18–19; ヨシュア記 13:22; ガラテヤ人への手紙 1:23–24"> <span className="pl pl-1">ヤコブに対する呪術はなく、</span><br /><span className="pl pl-2">イスラエルに対する占いもない。</span><br /><span className="pl pl-1">今、ヤコブとイスラエルについて言われる。</span><br /><span className="pl pl-2">『神は何を成し遂げられたことか。』</span></span>
<span className="v" id="v24" data-v="24" data-xref="創世記 49:27; 創世記 49:9; 民数記 24:17"> <span className="pl pl-1">見よ、その民は雌獅子のように立ち上がり、</span><br /><span className="pl pl-2">獅子のように身を起こす。</span><br /><span className="pl pl-1">獲物を食らい、</span><br /><span className="pl pl-2">殺された者の血を飲むまで横たわらない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="詩篇 2:1–3"> バラクはバラムに言った。「彼らを呪うことも、祝福することもやめてくれ。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 5:29; 民数記 22:18; 使徒の働き 4:19–20"> バラムは答えた。「『主が語られることはすべて行う』と、あなたに申したではありませんか。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ローマ人への手紙 11:29; 箴言 21:30; 民数記 23:19–20"> バラクはバラムに言った。「さあ、別の場所へ連れて行こう。そこから彼らを呪うことを、神がよしとされるかもしれない。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="民数記 21:20; 詩篇 106:28"> バラクはバラムを、荒れ地を見下ろすペオルの頂へ連れて行った。</span>
<span className="v" id="v29" data-v="29" data-xref="民数記 23:1–2"> バラムはバラクに言った。「ここに七つの祭壇を築き、七頭の雄牛と七頭の雄羊を用意してください。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> バラクはバラムの言うとおりにし、それぞれの祭壇に雄牛一頭と雄羊一頭をささげた。</span>
</div>

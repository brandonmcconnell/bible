<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 21:32; 民数記 32:3; 創世記 13:10–11"> ルベンの子らとガドの子らは、非常に多くの家畜を持っていた。彼らがヤゼルとギルアデの地を見ると、そこは家畜に適した場所であった。</span>
<span className="v" id="v2" data-v="2"> そこでガドの子らとルベンの子らは来て、モーセと祭司エルアザル、および会衆の指導者たちに言った。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 48:34; イザヤ書 16:8–9; 民数記 32:34–38"> 「アタロト、ディボン、ヤゼル、ニムラ、ヘシュボン、エルアレ、セバム、ネボ、ベオン、</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 21:34; 申命記 2:24–35; 民数記 21:24"> 主がイスラエルの会衆の前で打たれたこの地は、家畜に適しています。そして、しもべどもには家畜があります。」</span>
<span className="v" id="v5" data-v="5" data-xref="ルツ記 2:10; ヨシュア記 7:7; エレミヤ書 31:2"> さらに言った。「私たちをお認めくださるなら、この地をしもべどもの所有地として与え、ヨルダン川の向こうへ渡らせないでください。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="コリント人への第一の手紙 13:5; サムエル記第二 11:11; ピリピ人への手紙 2:4"> モーセはガドの子らとルベンの子らに言った。「あなたがたの兄弟たちが戦いに行くのに、あなたがたはここに座っているつもりか。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 13:27–4; 民数記 32:9; 申命記 1:28"> なぜ、主が与えられた地へ渡ろうとするイスラエルの子らの心をくじくのか。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 1:19–25; 民数記 14:2; 民数記 13:2–26"> 私がその地を見るためにカデシュ・バルネアから彼らを遣わしたとき、あなたがたの父祖たちもそうした。</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 13:23–10; 申命記 1:24–28"> 彼らはエシュコルの谷へ上り、その地を見た後、イスラエルの子らの心をくじき、主が与えられた地へ入らせまいとした。</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 14:11; 詩篇 95:11; エゼキエル書 20:15"> その日、主の怒りが燃え上がり、誓って言われた。</span>
<span className="v" id="v11" data-v="11" data-xref="民数記 14:28–30; 民数記 14:24; 民数記 26:2"> 『エジプトから上って来た者たちのうち、二十歳以上の者はだれも、わたしがアブラハム、イサク、ヤコブに誓った地を見ることはない。彼らがわたしに完全に従わなかったからである。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 1:36; 民数記 14:30; 民数記 14:24"> ただし、ケナズ人エフネの子カレブと、ヌンの子ヨシュアは例外である。彼らは主に完全に従ったからである。』</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 10:5; 民数記 14:33–35; ヘブル人への手紙 3:16–19"> 主の怒りはイスラエルに向かって燃え、主の前で悪を行った世代が滅びるまで、四十年間、彼らを荒野でさまよわせた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ルカ 11:48; 詩篇 78:57; マタイ 23:31–33"> 見よ、あなたがたは父祖に代わる罪人の一団として立ち上がり、イスラエルに対する主の激しい怒りをさらに増そうとしている。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 8:11–12; 歴代誌 第二 15:2; 歴代誌 第二 7:19–22"> もし主に従うことから背を向けるなら、主は再びこの民を荒野に取り残される。こうして、あなたがたはこの民全体を滅ぼすことになる。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="創世記 33:17; 民数記 34:22"> 彼らはモーセに近づいて言った。「私たちはここに家畜のために羊の囲いを建て、幼子たちのために町々を建てます。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨシュア記 4:12–13; 民数記 32:29–32; 申命記 3:18–20"> 私たちは武装してイスラエルの子らの先頭に立ち、彼らをそれぞれの場所へ導き入れます。幼子たちは、この地の住民から守られるよう、城壁のある町々に住ませます。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 22:1–5"> イスラエルの子らが皆、それぞれ自分の所有地を受け継ぐまで、私たちは自分の家に帰りません。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 13:8; ヨシュア記 12:1–6; 民数記 34:15"> 私たちの相続地は、ヨルダン川のこちら側、東に与えられたので、川の向こう側で彼らとともに相続地を受けることはありません。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヨシュア記 4:12–13; 申命記 3:18–20; ヨシュア記 1:13–15"> モーセは彼らに言った。「この約束を果たし、主の前で戦うために武装し、</span>
<span className="v" id="v21" data-v="21"> 武装した者がみな、主が敵を御前から追い払われるまで、主の前でヨルダン川を渡り、</span>
<span className="v" id="v22" data-v="22" data-xref="ヨシュア記 22:9; ヨシュア記 22:4; 申命記 3:20"> その地が主の前で征服されたなら、その後、帰ることができる。主に対してもイスラエルに対しても責任を果たしたことになり、この地は主の前であなたがたの所有地となる。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 59:12; 箴言 13:21; 創世記 44:16"> しかし、そうしないなら、あなたがたは主に罪を犯す。あなたがたの罪は必ず追いつくと知りなさい。</span>
<span className="v" id="v24" data-v="24" data-xref="民数記 32:16; 民数記 30:2; 民数記 32:34–42"> 幼子たちのために町々を建て、羊のために囲いを建てなさい。そして、あなたがたの口から出たことを実行しなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 1:13–14"> ガドの子らとルベンの子らはモーセに答えた。「しもべどもは、わが主が命じられるとおりに行います。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨシュア記 1:14"> 私たちの幼子たち、妻たち、群れ、そしてすべての家畜は、そこのギルアデの町々にとどまります。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 4:12; 民数記 32:17; 民数記 12:11"> しかしあなたのしもべたち、すなわち戦いのために武装したすべての者は、わが主が言われるように、主の前で戦いのために渡って行きます。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヨシュア記 1:13"> そこでモーセは、彼らについて、祭司エルアザル、ヌンの子ヨシュア、イスラエルの子らの部族の父祖の家の長たちに命じた。</span>
<span className="v" id="v29" data-v="29"> モーセは言った。「ガドの子らとルベンの子らのうち、武装した者がみな、主の前であなたがたとともにヨルダン川を渡り、その地が征服されたなら、ギルアデの地を彼らの所有地として与えなさい。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨシュア記 22:19"> しかし、武装してともに渡らないなら、カナンの地であなたがたの間に所有地を与えなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31"> ガドの子らとルベンの子らは答えた。「主があなたのしもべたちに言われたとおりに、私たちは行います。</span>
<span className="v" id="v32" data-v="32"> 私たちは武装して主の前でカナンの地に渡って行きますが、私たちの受け継ぐ所有地はヨルダン川のこちら側にとどまります。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="ヨシュア記 12:6; 申命記 29:8; 申命記 3:12–17"> モーセはガドの子ら、ルベンの子ら、ヨセフの子マナセの半部族に、アモリ人の王シホンの王国とバシャンの王オグの王国、すなわち境界内の町々と周辺の地を与えた。</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 2:36; 民数記 32:3; イザヤ書 17:2"> ガドの子らはディボン、アタロト、アロエル、</span>
<span className="v" id="v35" data-v="35" data-xref="民数記 32:1; 民数記 32:3"> アトロテ・ショファン、ヤゼル、ヨグボハ、</span>
<span className="v" id="v36" data-v="36" data-xref="民数記 32:3"> ベテ・ニムラ、ベテ・ハランを城壁のある町として建て、羊のための囲いを建てた。</span>
<span className="v" id="v37" data-v="37" data-xref="民数記 21:27; 民数記 32:3; イザヤ書 15:4"> ルベンの子らはヘシュボン、エルアレ、キルヤタイム、</span>
<span className="v" id="v38" data-v="38" data-xref="イザヤ書 46:1; 民数記 32:3; ヨシュア記 23:7"> ネボ、バアル・メオン（これらの名は変更された）、およびシブマを建てた。彼らは自分たちが建てた町々に別の名を与えた。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 50:23; ヨシュア記 17:1; 民数記 26:29"> マナセの子マキルの子らはギルアデに行ってこれを取り、そこにいたアモリ人を追い出した。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨシュア記 17:1; ヨシュア記 13:29–31; 申命記 3:13–15"> モーセはギルアデをマナセの子マキルに与えた。彼はそこに住んだ。</span>
<span className="v" id="v41" data-v="41" data-xref="申命記 3:14; 士師記 10:4; ヨシュア記 13:30"> マナセの子ヤイルは行ってその村々を取り、それらをハボテ・ヤイルと呼んだ。</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 49:11; サムエル記第二 18:18"> ノバは行ってケナテとその村々を取り、自分の名にちなんでそれをノバと呼んだ。</span>
</div>
</div>

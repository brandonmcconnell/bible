<span className="v" id="v1" data-v="1" data-xref="民数記 25:9"> 疫病の後、主はモーセと祭司アロンの子エルアザルに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 38:25–26; 民数記 1:2–3; 出エジプト記 30:11–16"> 「イスラエルの子らの全会衆のうち、二十歳以上で、イスラエルの軍務に就くことのできる者を、父祖の家ごとに数えなさい。」</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 22:1; 民数記 33:48; 民数記 35:1"> モーセと祭司エルアザルは、エリコの向かい、ヨルダン川のほとりのモアブの平野で、民に告げた。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 1:1; 歴代誌上 21:1"> 「主がモーセに命じられたとおり、二十歳以上の者を数えなさい。」<br />エジプトの地から出たイスラエルの子らは次のとおりである。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代誌上 5:3; 創世記 46:8–9; 出エジプト記 6:14"> イスラエルの長子であるルベン。ルベンの子らは、ハノクからハノク人の氏族、パルからパル人の氏族、</span>
<span className="v" id="v6" data-v="6"> ヘツロンからヘツロン人の氏族、カルミからカルミ人の氏族が出た。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 46:9; 民数記 26:21; 民数記 2:11"> これらがルベン人の氏族であり、数えられた者は四万三千七百三十人であった。</span>
<span className="v" id="v8" data-v="8"> パルの子はエリアブであった。</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 1:16; 民数記 16:1–35; 詩篇 106:17"> エリアブの子らはネムエル、ダタン、アビラムであった。このダタンとアビラムは会衆から選ばれた者であったが、コラの仲間とともにモーセとアロンに逆らい、主に逆らった。</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 16:38; ペテロの第二の手紙 2:6; 民数記 16:31–35"> 地が口を開いて、コラとともに彼らをのみ込んだ。また火が二百五十人を焼き尽くし、その仲間は死んで、警告のしるしとなった。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 6:24; 詩篇 42:1; 民数記 16:33"> しかし、コラの子らは死ななかった。</span>
<span className="v" id="v12" data-v="12" data-xref="歴代誌上 4:24; 創世記 46:10; 出エジプト記 6:15"> シメオンの子らの氏族は次のとおりである。ネムエルからネムエル人の氏族、ヤミンからヤミン人の氏族、ヤキンからヤキン人の氏族、</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 46:10"> ゼラからゼラ人の氏族、シャウルからシャウル人の氏族が出た。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 1:22–23; 民数記 2:12–13"> これらがシメオン人の氏族であり、二万二千二百人であった。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 46:16; 民数記 2:14"> ガドの子らの氏族は次のとおりである。ツェフォンからツェフォン人の氏族、ハギからハギ人の氏族、シュニからシュニ人の氏族、</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 46:16"> オズニからオズニ人の氏族、エリからエリ人の氏族、</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 46:16"> アロドからアロド人の氏族、アレリからアレリ人の氏族が出た。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 1:24–25; 民数記 2:14–15"> これらがガドの子らの氏族であり、数えられた者は四万五百人であった。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 46:12; 創世記 38:1–10; 歴代誌上 2:3–8"> ユダの子らはエルとオナンであった。エルとオナンはカナンの地で死んだ。</span>
<span className="v" id="v20" data-v="20" data-xref="ネヘミヤ記 11:24; 創世記 46:12; ルカ 3:33"> ユダの子らの氏族は次のとおりである。シェラからシェラ人の氏族、ペレツからペレツ人の氏族、ゼラからゼラ人の氏族が出た。</span>
<span className="v" id="v21" data-v="21"> ペレツの子らは、ヘツロンからヘツロン人の氏族、ハムルからハムル人の氏族が出た。</span>
<span className="v" id="v22" data-v="22" data-xref="民数記 1:26–27; 民数記 2:3–4; 創世記 49:8"> これらがユダの氏族であり、数えられた者は七万六千五百人であった。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 46:13; 歴代誌上 7:1; 創世記 30:17–18"> イッサカルの子らの氏族は次のとおりである。トラからトラ人の氏族、プワからプワ人の氏族、</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 46:13"> ヤシュブからヤシュブ人の氏族、シムロンからシムロン人の氏族が出た。</span>
<span className="v" id="v25" data-v="25" data-xref="民数記 2:5–6; 民数記 1:28–29"> これらがイッサカルの氏族であり、数えられた者は六万四千三百人であった。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 46:14; 創世記 30:19–20"> ゼブルンの子らの氏族は次のとおりである。セレドからセレド人の氏族、エロンからエロン人の氏族、ヤフレエルからヤフレエル人の氏族が出た。</span>
<span className="v" id="v27" data-v="27" data-xref="民数記 1:30–31; 民数記 2:7–8"> これらがゼブルン人の氏族であり、数えられた者は六万五百人であった。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 46:20; 創世記 48:5; 創世記 41:51–52"> ヨセフの子らの氏族は、マナセとエフライムであった。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 17:1; 民数記 36:1; 歴代誌上 7:14–19"> マナセの子らは、マキルからマキル人の氏族が出た。マキルはギルアデの父となった。ギルアデからギルアデ人の氏族が出た。</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 6:11; 士師記 6:34; 士師記 6:24"> ギルアデの子らは次のとおりである。イエゼルからイエゼル人の氏族、ヘレクからヘレク人の氏族、</span>
<span className="v" id="v31" data-v="31"> アスリエルからアスリエル人の氏族、シェケムからシェケム人の氏族、</span>
<span className="v" id="v32" data-v="32"> シェミダからシェミダ人の氏族、ヘフェルからヘフェル人の氏族が出た。</span>
<span className="v" id="v33" data-v="33" data-xref="民数記 27:1; 民数記 36:10–12"> ヘフェルの子ゼロフェハデには息子がなく、娘だけであった。ゼロフェハデの娘たちの名は、マフラ、ノア、ホグラ、ミルカ、ティルツァであった。</span>
<span className="v" id="v34" data-v="34" data-xref="民数記 1:34–35; 民数記 2:20–21"> これらがマナセの氏族であり、数えられた者は五万二千七百人であった。</span>
<span className="v" id="v35" data-v="35" data-xref="歴代誌上 7:20–21"> エフライムの子らの氏族は次のとおりである。シュテラからシュテラ人の氏族、ベケルからベケル人の氏族、タハンからタハン人の氏族が出た。</span>
<span className="v" id="v36" data-v="36"> シュテラの子らは次のとおりである。エランからエラン人の氏族が出た。</span>
<span className="v" id="v37" data-v="37" data-xref="民数記 1:32–33; 民数記 2:18–19"> これらがエフライムの子らの氏族であり、数えられた者は三万二千五百人であった。これらがヨセフの子らの氏族である。</span>
<span className="v" id="v38" data-v="38" data-xref="歴代誌上 8:1; 歴代誌上 7:6–12; 創世記 46:2"> ベニヤミンの子らの氏族は次のとおりである。ベラからベラ人の氏族、アシュベルからアシュベル人の氏族、アヒラムからアヒラム人の氏族、</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 46:21"> シュファムからシュファム人の氏族、フファムからフファム人の氏族が出た。</span>
<span className="v" id="v40" data-v="40" data-xref="歴代誌上 8:3"> ベラの子らはアルドとナアマンであり、アルドからアルド人の氏族、ナアマンからナアマン人の氏族が出た。</span>
<span className="v" id="v41" data-v="41" data-xref="民数記 2:22–23; 創世記 46:21; 民数記 1:36–37"> これらがベニヤミンの子らの氏族であり、数えられた者は四万五千六百人であった。</span>
<span className="v" id="v42" data-v="42" data-xref="創世記 46:23"> ダンの子らの氏族は次のとおりである。シュハムからシュハム人の氏族が出た。これらがダンの氏族である。</span>
<span className="v" id="v43" data-v="43" data-xref="民数記 1:38–39; 民数記 2:25–26"> シュハム人のすべての氏族で、数えられた者は六万四千四百人であった。</span>
<span className="v" id="v44" data-v="44" data-xref="創世記 46:17; 歴代誌上 7:30"> アシェルの子らの氏族は次のとおりである。イムナからイムナ人の氏族、イシュビからイシュビ人の氏族、ベリアからベリア人の氏族が出た。</span>
<span className="v" id="v45" data-v="45"> ベリアの子らは、ヘベルからヘベル人の氏族、マルキエルからマルキエル人の氏族が出た。</span>
<span className="v" id="v46" data-v="46" data-xref="創世記 46:17"> アシェルの娘の名はセラといった。</span>
<span className="v" id="v47" data-v="47" data-xref="民数記 2:27–28; 民数記 1:40–41"> これらがアシェルの子らの氏族であり、数えられた者は五万三千四百人であった。</span>
<span className="v" id="v48" data-v="48" data-xref="創世記 46:24; 歴代誌上 7:13"> ナフタリの子らの氏族は次のとおりである。ヤフツェエルからヤフツェエル人の氏族、グニからグニ人の氏族、</span>
<span className="v" id="v49" data-v="49" data-xref="歴代誌上 7:13"> イエツェルからイエツェル人の氏族、シレムからシレム人の氏族が出た。</span>
<span className="v" id="v50" data-v="50" data-xref="民数記 1:42–43; 民数記 2:29–30"> これらがナフタリの氏族であり、数えられた者は四万五千四百人であった。</span>
<span className="v" id="v51" data-v="51" data-xref="民数記 1:46; 民数記 2:32; 出エジプト記 12:37"> イスラエルの子らのうち数えられた者は、六十万一千七百三十人であった。</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52"> 主はモーセに告げられた。</span>
<span className="v" id="v53" data-v="53" data-xref="ヨシュア記 11:23; ヨシュア記 14:1; 詩篇 105:44"> 「これらの者に、人数に応じて地を相続地として割り当てなさい。</span>
<span className="v" id="v54" data-v="54" data-xref="民数記 33:54; 民数記 32:3; 民数記 32:5"> 人数の多い部族には相続地を多く、少ない部族には少なく与える。それぞれ、数えられた人数に応じて相続地を与える。</span>
<span className="v" id="v55" data-v="55" data-xref="民数記 34:13; 民数記 33:54; ヨシュア記 14:2"> ただし、地はくじによって割り当てる。彼らは父祖の部族の名に従って受け継ぐ。</span>
<span className="v" id="v56" data-v="56" data-xref="コリント人への第一の手紙 12:4; ローマ人への手紙 11:7"> 人数の多い部族と少ない部族の間で、くじによって相続地を割り当てる。」</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="創世記 46:11; 歴代誌上 6:1; 出エジプト記 6:16–19"> 氏族ごとに数えられたレビ人は次のとおりである。ゲルションからゲルション人の氏族、ケハテからケハテ人の氏族、メラリからメラリ人の氏族が出た。</span>
<span className="v" id="v58" data-v="58" data-xref="民数記 16:1; 民数記 3:17–21; 出エジプト記 6:20"> レビの氏族は次のとおりである。リブニ人の氏族、ヘブロン人の氏族、マフリ人の氏族、ムシ人の氏族、コラ人の氏族である。ケハテはアムラムの父となった。</span>
<span className="v" id="v59" data-v="59" data-xref="出エジプト記 6:20; 出エジプト記 2:1–2; レビ記 18:12"> アムラムの妻の名は、エジプトでレビに生まれたレビの娘ヨケベデであった。彼女はアムラムにアロンとモーセ、およびその姉妹ミリアムを産んだ。</span>
<span className="v" id="v60" data-v="60" data-xref="民数記 3:2; 民数記 3:8"> アロンにはナダブとアビフ、エルアザルとイタマルが生まれた。</span>
<span className="v" id="v61" data-v="61" data-xref="民数記 3:4; レビ記 10:1–2; 歴代誌上 24:1–2"> ナダブとアビフは、主の前に異なる火をささげたときに死んだ。</span>
<span className="v" id="v62" data-v="62" data-xref="申命記 10:9; 民数記 35:2–8; 民数記 3:39"> 生後一か月以上の男子で、数えられた者は二万三千人であった。彼らはイスラエルの子らとともには数えられなかった。イスラエルの中に相続地を与えられなかったからである。</span>
<span className="v" id="v63" data-v="63" data-xref="民数記 26:3"> これらは、エリコの向かい、ヨルダン川のほとりのモアブの平野で、モーセと祭司エルアザルが数えたイスラエルの子らである。</span>
<span className="v" id="v64" data-v="64" data-xref="申命記 2:14–15; 申命記 4:3–4; コリント人への第一の手紙 10:5"> その中には、シナイの荒野でモーセと祭司アロンが数えた者は一人もいなかった。</span>
<span className="v" id="v65" data-v="65" data-xref="コリント人への第一の手紙 10:5–6; 民数記 14:38; ローマ人への手紙 11:22"> 主が彼らについて、「彼らは必ず荒野で死ぬ」と言われたからである。エフネの子カレブとヌンの子ヨシュアのほかには、一人も残らなかった。</span>

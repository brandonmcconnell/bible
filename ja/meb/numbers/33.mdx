<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 77:20; ミカ書 6:4; 出エジプト記 12:51"> モーセとアロンに率いられ、部隊ごとにエジプトの地から出たイスラエルの子らの旅程は次のとおりである。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 9:17–23; 申命記 10:11; 民数記 10:6"> モーセは主の命令によって、旅の出発地を書き記した。出発地ごとの旅程は次のとおりである。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 14:8; 出エジプト記 12:37; 出エジプト記 13:4"> 彼らは第一の月の十五日にラメセスを旅立った。過越の翌日、イスラエルの子らはすべてのエジプト人が見ている前を、堂々と出て行った。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 12:12; イザヤ書 19:1; 出エジプト記 18:11"> エジプト人は、主が彼らの間で打たれた長子を葬っていた。主はまた、彼らの神々に裁きを下された。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 12:37"> イスラエルの子らはラメセスを旅立ち、スコテに宿営した。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 13:20"> 彼らはスコテを旅立ち、荒野の端にあるエタムに宿営した。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 14:2; 出エジプト記 14:9; 民数記 33:8"> 彼らはエタムを旅立ち、バアル・ツェフォンの前にあるピ・ハヒロトに引き返し、ミグドルの前に宿営した。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 15:22–26; 出エジプト記 14:21–31"> 彼らはハヒロトの前を旅立ち、海の中を通って荒野へ出た。そしてエタムの荒野を三日間の道のりで進み、マラに宿営した。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 15:27"> 彼らはマラを旅立ち、エリムに着いた。エリムには十二の水の泉と七十本のなつめやしの木があり、彼らはそこに宿営した。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 16:1; 出エジプト記 17:1"> 彼らはエリムを旅立ち、紅海のほとりに宿営した。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 16:1"> 彼らは紅海を旅立ち、シンの荒野に宿営した。</span>
<span className="v" id="v12" data-v="12"> 彼らはシンの荒野を旅立ち、ドフカに宿営した。</span>
<span className="v" id="v13" data-v="13"> 彼らはドフカを旅立ち、アルシュに宿営した。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 17:1–8; 出エジプト記 19:2"> 彼らはアルシュを旅立ち、レフィディムに宿営したが、そこには民が飲むための水がなかった。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 19:1–2; 出エジプト記 16:1"> 彼らはレフィディムを旅立ち、シナイの荒野に宿営した。</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 11:34; 民数記 10:11–13; 民数記 10:33"> 彼らはシナイの荒野を旅立ち、キブロト・ハタアワに宿営した。</span>
<span className="v" id="v17" data-v="17" data-xref="民数記 11:35"> 彼らはキブロト・ハタアワを旅立ち、ハツェロトに宿営した。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 12:16"> 彼らはハツェロトを旅立ち、リトマに宿営した。</span>
<span className="v" id="v19" data-v="19"> 彼らはリトマを旅立ち、リモン・ペレツに宿営した。</span>
<span className="v" id="v20" data-v="20"> 彼らはリモン・ペレツを旅立ち、リブナに宿営した。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 1:1"> 彼らはリブナを旅立ち、リサに宿営した。</span>
<span className="v" id="v22" data-v="22"> 彼らはリサを旅立ち、ケヘラタに宿営した。</span>
<span className="v" id="v23" data-v="23"> 彼らはケヘラタを旅立ち、シェフェル山に宿営した。</span>
<span className="v" id="v24" data-v="24"> 彼らはシェフェル山を旅立ち、ハラダに宿営した。</span>
<span className="v" id="v25" data-v="25"> 彼らはハラダを旅立ち、マクヘロトに宿営した。</span>
<span className="v" id="v26" data-v="26"> 彼らはマクヘロトを旅立ち、タハトに宿営した。</span>
<span className="v" id="v27" data-v="27"> 彼らはタハトを旅立ち、テラに宿営した。</span>
<span className="v" id="v28" data-v="28"> 彼らはテラを旅立ち、ミトカに宿営した。</span>
<span className="v" id="v29" data-v="29"> 彼らはミトカを旅立ち、ハシュモナに宿営した。</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 10:5–6"> 彼らはハシュモナを旅立ち、モセロトに宿営した。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 10:6; 創世記 36:27; 歴代誌上 1:43"> 彼らはモセロトを旅立ち、ベネ・ヤアカンに宿営した。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 10:7"> 彼らはベネ・ヤアカンを旅立ち、ホル・ハギデガドに宿営した。</span>
<span className="v" id="v33" data-v="33" data-xref="申命記 10:7"> 彼らはホル・ハギデガドを旅立ち、ヨトバタに宿営した。</span>
<span className="v" id="v34" data-v="34"> 彼らはヨトバタを旅立ち、アブロナに宿営した。</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 2:8; 列王記第一 9:26; 列王記第一 22:48"> 彼らはアブロナを旅立ち、エツヨン・ゲベルに宿営した。</span>
<span className="v" id="v36" data-v="36" data-xref="民数記 20:1; 民数記 27:14; 申命記 32:51"> 彼らはエツヨン・ゲベルを旅立ち、ツィンの荒野、すなわちカデシュに宿営した。</span>
<span className="v" id="v37" data-v="37" data-xref="民数記 21:4; 民数記 20:22–23; 民数記 20:16"> 彼らはカデシュを旅立ち、エドムの地の端にあるホル山に宿営した。</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 10:6; 申命記 32:50; 民数記 20:24–28"> 祭司アロンは主の命令によってホル山に登り、そこで死んだ。それはイスラエルの子らがエジプトの地から出た後の第四十年目の、第五の月の最初の日のことであった。</span>
<span className="v" id="v39" data-v="39"> アロンがホル山で死んだとき、彼は百二十三歳であった。</span>
<span className="v" id="v40" data-v="40" data-xref="民数記 21:1–9"> カナンの地の南部に住むカナン人、アラドの王は、イスラエルの子らが来ると聞いた。</span>
<span className="v" id="v41" data-v="41" data-xref="民数記 21:4"> 彼らはホル山を旅立ち、ツァルモナに宿営した。</span>
<span className="v" id="v42" data-v="42"> 彼らはツァルモナを旅立ち、プノンに宿営した。</span>
<span className="v" id="v43" data-v="43" data-xref="民数記 21:10"> 彼らはプノンを旅立ち、オボテに宿営した。</span>
<span className="v" id="v44" data-v="44" data-xref="民数記 21:11"> 彼らはオボテを旅立ち、モアブの境界にあるイエ・アバリムに宿営した。</span>
<span className="v" id="v45" data-v="45"> 彼らはイイムを旅立ち、ディボン・ガドに宿営した。</span>
<span className="v" id="v46" data-v="46" data-xref="エレミヤ書 48:18; エゼキエル書 6:14; イザヤ書 15:2"> 彼らはディボン・ガドを旅立ち、アルモン・ディブラタイムに宿営した。</span>
<span className="v" id="v47" data-v="47" data-xref="申命記 32:49; 申命記 34:1; 民数記 27:12"> 彼らはアルモン・ディブラタイムを旅立ち、ネボの前にあるアバリムの山々に宿営した。</span>
<span className="v" id="v48" data-v="48" data-xref="民数記 22:1"> 彼らはアバリムの山々を旅立ち、エリコの向かい側にあるヨルダン川のほとりのモアブの平野に宿営した。</span>
<span className="v" id="v49" data-v="49" data-xref="ヨシュア記 2:1; ヨシュア記 13:20; 民数記 25:1–9"> 彼らはモアブの平野にあるベテ・エシモトからアベル・シティムに至るまでの、ヨルダン川のほとりに宿営した。</span>
<span className="v" id="v50" data-v="50" data-xref="民数記 33:48–49"> 主はエリコの向かい、ヨルダン川のほとりのモアブの平野で、モーセに告げられた。</span>
<span className="v" id="v51" data-v="51" data-xref="ヨシュア記 3:17; 申命記 9:1; 申命記 7:1"> 「イスラエルの子らにこう告げなさい。『ヨルダン川を渡ってカナンの地に入るとき、</span>
<span className="v" id="v52" data-v="52" data-xref="出エジプト記 23:24; レビ記 26:1; 申命記 20:16–18"> その地の住民をすべて追い出し、彫刻した石像をすべて壊し、鋳造した像をすべて壊し、高き所をことごとく破壊しなさい。</span>
<span className="v" id="v53" data-v="53" data-xref="申命記 11:31; 詩篇 115:16; 申命記 32:8"> その地を占領し、そこに住みなさい。わたしがその地を、所有するためにあなたがたに与えたからである。</span>
<span className="v" id="v54" data-v="54" data-xref="民数記 26:53–56; ヨシュア記 18:11–48; ヨシュア記 15:1–12"> 氏族ごとにくじを引いて、その地を相続地として受け継ぎなさい。人数の多い部族には多く、少ない部族には少なく与える。くじが当たった所が、その者の相続地となる。父祖の部族に従って受け継ぎなさい。</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="士師記 2:3; 詩篇 106:34–36; 申命記 7:16"> しかし、その地の住民を追い出さないなら、残した者たちは目のとげ、脇腹のいばらとなり、あなたがたの住む地で苦しめる。</span>
<span className="v" id="v56" data-v="56" data-xref="ルカ 21:23–24; 申命記 28:63; レビ記 20:23"> そして、わたしが彼らに行おうとしたことを、あなたがたに行う。』」</span>
</div>

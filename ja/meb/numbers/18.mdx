<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 28:38; ヘブル人への手紙 13:17; ペテロの手紙第一 2:24"> 主はアロンに言われた。「あなたとあなたの子ら、父祖の家は、聖所に関する咎の責任を負う。あなたとあなたの子らは、祭司職に関する咎の責任を負う。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 29:34; 民数記 18:4; エゼキエル書 44:15"> 父の部族であるレビ人の兄弟たちも近づけなさい。彼らはあなたに加わり、あなたに仕える。ただし、あなたとあなたの子らは証しの天幕の前に立つ。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 4:15; 民数記 16:40; 民数記 4:19–20"> 彼らはあなたの務めと天幕全体の務めを担う。ただし、彼らもあなたがたも死なないよう、聖所の器具や祭壇に近づいてはならない。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記第一 6:19; 民数記 1:51; 民数記 3:10"> 彼らはあなたに加わり、会見の天幕のすべての奉仕と管理を担う。部外者はあなたがたに近づいてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 27:21; レビ記 24:3; 民数記 16:46"> あなたがたは聖所と祭壇の務めを担う。イスラエルの子らに再び御怒りが下らないためである。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 3:9; 民数記 3:12; 民数記 3:45"> 見よ、わたしはイスラエルの子らの中から、兄弟であるレビ人を選んだ。彼らは主に属する者としてあなたがたに与えられ、会見の天幕で奉仕する。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 15:15–16; ヨハネ 3:27; 民数記 3:10"> あなたとあなたの子らは、祭壇に関するすべてのことと垂れ幕の内側のことについて、祭司の務めを担う。祭司職を贈り物としてあなたがたに与える。近づく部外者は死刑に処される。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="レビ記 6:16; レビ記 7:6; 出エジプト記 29:29"> 主はアロンに言われた。「見よ、イスラエルの子らがささげるすべての聖なる奉納物を、わたしはあなたの管理に委ねる。油注がれた者の受ける分として、あなたとあなたの子らに永遠に与える。</span>
<span className="v" id="v9" data-v="9" data-xref="レビ記 7:7; レビ記 14:13; レビ記 6:25–26"> 火で焼かれない最も聖なるささげ物のうち、穀物のささげ物、贖罪のささげ物、償いのささげ物など、人々がわたしにささげるものは、あなたとあなたの子らのものとなり、最も聖なるものである。</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 7:6; レビ記 6:29; レビ記 6:16"> 男子はみな、最も聖なる場所でそれを食べる。それはあなたにとって聖なるものである。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="申命記 18:3; 出エジプト記 29:27–28; レビ記 10:14"> また、イスラエルの子らのすべての揺り動かすささげ物もあなたのものとなる。これを永遠の割り当てとして、あなたと息子、娘たちに与える。家の中で清い者はだれでも食べることができる。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 18:4; 出エジプト記 23:19; 出エジプト記 34:26"> 最良の油、新しいぶどう酒、穀物、すなわち彼らが主にささげる初物をすべてあなたに与える。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 22:29; 出エジプト記 23:19; ミカ書 7:1"> 彼らの地の初熟の実で、主のもとに持って来るものはすべてあなたのものとなる。家の中で清い者はだれでも食べることができる。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="レビ記 27:28; エゼキエル書 44:29"> イスラエルで聖絶されたものはすべてあなたのものとなる。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 34:20; 出エジプト記 13:2; 出エジプト記 13:12–13"> 人であれ動物であれ、主にささげられる胎を開くものはすべてあなたのものとなる。ただし、人の長子と汚れた動物の初子は必ず贖う。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 30:13; 民数記 3:47; レビ記 27:2–7"> 生後一か月以上の者は、あなたの評価に従い、聖所のシェケルによる銀五シェケル<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一シェケルは約10グラム、または約0.35オンスである。">a</a></sup>で贖う。一シェケルは二十ゲラ<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一ゲラは約0.5グラム、または約7.7グレーンである。">b</a></sup>である。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 29:16; 申命記 15:19–22; レビ記 3:2–5"> しかし、牛、羊、山羊の初子は贖ってはならない。それらは聖なるものである。その血を祭壇に振りかけ、脂肪を主への芳ばしい香りとなる火によるささげ物として焼く。</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 7:31–34; 出エジプト記 29:26–28"> その肉はあなたのものとなる。揺り動かした胸や右のももと同じく、あなたのものとなる。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代誌 第二 13:5; レビ記 2:13; 民数記 18:11"> イスラエルの子らが主にささげる聖なる揺り動かすささげ物をすべて、永遠の割り当てとして、あなたと息子、娘たちに与える。これは、あなたとあなたの子孫のための、主の前における永遠の塩の契約である。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 44:28; 申命記 10:9; ヨシュア記 13:33"> 主はアロンに言われた。「あなたは彼らの地に相続地を持たず、彼らの間に受ける分を持たない。イスラエルの子らの中で、わたしがあなたの受ける分、相続地である。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ネヘミヤ記 12:44; 申命記 14:22–29; ネヘミヤ記 10:37"> 見よ、わたしはレビの子らに、イスラエルのすべての十分の一を相続分として与える。それは彼らが行う会見の天幕の奉仕への報酬である。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 22:9; 民数記 1:51–52; 民数記 3:38"> 今後、イスラエルの子らは会見の天幕に近づいてはならない。罪を負って死ぬことのないためである。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 3:7; 民数記 18:20; 民数記 18:1"> レビ人が会見の天幕の奉仕を行い、その務めに伴う責任を負う。これは代々にわたる永遠の掟である。彼らはイスラエルの子らの中に相続地を持たない。</span>
<span className="v" id="v24" data-v="24" data-xref="民数記 18:26; マラキ書 3:8–10"> イスラエルの子らが主への揺り動かすささげ物としてささげる十分の一を、レビ人の相続分として与えたからである。それゆえ、彼らについて『イスラエルの子らの中に相続地を持たない』と言ったのである。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 主はモーセに告げられた。</span>
<span className="v" id="v26" data-v="26" data-xref="ネヘミヤ記 10:38; 民数記 18:21"> 「さらにレビ人にこう告げなさい。『わたしがイスラエルの子らからあなたがたの相続分として与えた十分の一を受け取るとき、その十分の一からさらに十分の一を、主への奉納物としてささげる。</span>
<span className="v" id="v27" data-v="27" data-xref="民数記 18:30; 申命記 15:14; 列王記第二 6:27"> その奉納物は、打ち場の穀物や、ぶどう搾り場からの産物と同じように、あなたがたのものとみなされる。</span>
<span className="v" id="v28" data-v="28" data-xref="ヘブル人への手紙 6:20–10; 創世記 14:18"> このように、イスラエルの子らから受け取るすべての十分の一から、あなたがたも主への奉納物をささげ、その中から主への奉納物を祭司アロンに与える。</span>
<span className="v" id="v29" data-v="29"> 受け取るすべての贈り物から、その最上の部分、聖なる部分を、主への奉納物としてささげる。』</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="箴言 3:9–10; 創世記 43:11; マタイ 6:33"> 彼らにこう告げなさい。『その最上の部分をささげるとき、残りはレビ人にとって、打ち場やぶどう搾り場からの産物と同じものとみなされる。</span>
<span className="v" id="v31" data-v="31" data-xref="コリント人への第一の手紙 9:10–14; テモテへの手紙第一 5:17–18; ルカ 10:7"> あなたがたも家族も、どこででもそれを食べることができる。それは会見の天幕における奉仕の報酬だからである。</span>
<span className="v" id="v32" data-v="32" data-xref="レビ記 19:8; レビ記 22:2; マラキ書 1:7"> その最上の部分をささげるなら、そのことで罪を負うことはない。イスラエルの子らの聖なるものを汚してはならない。死なないためである。』」</span>
</div>
</div>

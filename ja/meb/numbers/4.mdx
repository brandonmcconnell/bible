<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセとアロンに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 3:27; 民数記 3:19"> 「レビの子らの中から、ケハテの子らを氏族ごと、父祖の家ごとに数え上げなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 4:23; 歴代誌上 23:3–5; 列王記第二 11:4–12"> 三十歳以上五十歳までで、会見の天幕の務めに就き、奉仕するすべての者を数えなさい。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="民数記 4:19; マルコ 13:34; 民数記 4:30"> 会見の天幕におけるケハテの子らの奉仕、すなわち最も聖なるものに関する務めは次のとおりである。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイ 27:51; ヘブル人への手紙 9:3; 出エジプト記 40:3"> 宿営を移すとき、アロンとその子らは中に入り、仕切りの垂れ幕を取り外して、証しの箱をそれで覆う。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 25:13–15; 出エジプト記 35:19; 民数記 4:7–8"> その上にアザラシの皮の覆いを掛け、さらに青い布を広げ、担ぎ棒を通す。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="レビ記 24:5–8; 出エジプト記 37:10–16; 出エジプト記 25:23–30"> 臨在のパンの机の上に青い布を広げ、その上に皿、さじ、鉢、注ぎのささげ物に用いる杯を置く。絶えず供えるパンもその上に置く。</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 4:6–7; 民数記 4:11–13; 民数記 4:9"> その上に緋色の布を広げ、アザラシの皮の覆いを掛け、担ぎ棒を通す。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 25:31–39; 出エジプト記 37:17–24; ヨハネの黙示録 1:20–1"> 青い布を取り、明かりの燭台とそのともしび、芯切りばさみ、芯取り皿、および奉仕に用いるすべての油の器を覆う。</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 4:12; 民数記 4:6"> それとすべての器具をアザラシの皮の覆いに包み、担ぎ台の上に載せる。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 40:5; 出エジプト記 30:1–19; 出エジプト記 40:26–27"> 金の祭壇の上に青い布を広げ、アザラシの皮の覆いを掛け、担ぎ棒を通す。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歴代誌上 9:29; 出エジプト記 25:9; 歴代誌 第二 4:22"> 聖所で奉仕するために用いるすべての器具を取り、青い布に包み、アザラシの皮の覆いを掛け、担ぎ台の上に載せる。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="レビ記 6:12–13; 出エジプト記 39:1; 出エジプト記 39:41"> 祭壇から灰を取り除き、その上に紫の布を広げる。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代誌 第二 4:19; 出エジプト記 38:1–7"> その上に、祭壇の奉仕に用いるすべての器具、すなわち火皿、肉刺し、シャベル、鉢など、祭壇のすべての器具を置く。さらにアザラシの皮の覆いを広げ、担ぎ棒を通す。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="サムエル記第二 6:6–7; 民数記 7:9; 申命記 31:9"> 宿営を移すとき、アロンとその子らが聖所とそのすべての器具を覆い終えた後で、ケハテの子らが来てこれらを担ぐ。ただし、死ぬことのないよう、聖なるものに触れてはならない。以上が、会見の天幕に属するもののうち、ケハテの子らが担う荷である。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 25:6; レビ記 24:2; 出エジプト記 30:23–38"> 祭司アロンの子エルアザルは、明かりの油、香り高い香、絶えずささげる穀物のささげ物、注ぎ油を受け持ち、幕屋全体とその中にあるすべてのもの、すなわち聖所とその器具を管理する。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 主はモーセとアロンに告げられた。</span>
<span className="v" id="v18" data-v="18" data-xref="サムエル記第二 6:6–7; 民数記 17:10; 民数記 18:5"> 「ケハテ人の諸氏族を、レビ人の中から絶やしてはならない。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 4:15"> 彼らが最も聖なるものに近づくとき、死なずに生きられるよう、次のようにしなさい。アロンとその子らが中に入り、それぞれに奉仕と荷を割り当てる。</span>
<span className="v" id="v20" data-v="20" data-xref="サムエル記第一 6:19; 出エジプト記 19:21; 民数記 4:15"> 彼らは中に入って、聖なるものを一目でも見てはならない。死ぬことのないためである。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 主はモーセに告げられた。</span>
<span className="v" id="v22" data-v="22" data-xref="民数記 3:18; 民数記 3:21; 民数記 3:24"> 「ゲルションの子らについても、父祖の家ごと、氏族ごとに数え上げなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 4:3; テモテへの手紙第一 1:18; コリント人への第一の手紙 9:7"> 三十歳以上五十歳までで、会見の天幕の務めに就き、奉仕するすべての者を数えなさい。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数記 4:19; 民数記 4:31–32; 民数記 4:47"> ゲルション人の諸氏族が奉仕し、荷を担う務めは次のとおりである。</span>
<span className="v" id="v25" data-v="25" data-xref="民数記 3:25–26; 出エジプト記 26:14; 民数記 7:5–7"> 彼らは幕屋の幕、会見の天幕とその覆い、その上にあるアザラシの皮の覆い、会見の天幕の入口の垂れ幕、</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 35:18; 出エジプト記 27:9"> 庭の掛け幕、幕屋と祭壇を囲む庭の入口の垂れ幕、そのひも、奉仕に用いるすべての器具を運び、これらに関するすべての務めを果たす。</span>
<span className="v" id="v27" data-v="27" data-xref="ルカ 1:70; コリント人への第一の手紙 11:2"> ゲルションの子らのすべての荷と奉仕は、アロンとその子らの指示に従う。あなたがたは、彼らが担うすべての務めを割り当てなさい。</span>
<span className="v" id="v28" data-v="28" data-xref="民数記 4:33; コリント人への第一の手紙 12:5–6"> 以上が、会見の天幕におけるゲルション人の諸氏族の奉仕である。彼らの務めは祭司アロンの子イタマルの監督のもとに置かれる。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数記 3:33–35"> メラリの子らについては、氏族ごと、父祖の家ごとに彼らを数えなさい。</span>
<span className="v" id="v30" data-v="30" data-xref="民数記 4:3; 民数記 4:23; テモテへの第二の手紙 2:4"> 三十歳以上五十歳までで、会見の天幕の務めに就き、奉仕するすべての者を数えなさい。</span>
<span className="v" id="v31" data-v="31" data-xref="民数記 3:36–37; 出エジプト記 26:15; 民数記 7:8–9"> 会見の天幕で彼らが担う荷は、幕屋の板、横木、柱、台座、</span>
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 38:21; 歴代誌上 9:29; 民数記 3:8"> 庭を囲む柱、その台座、杭、ひも、およびこれらのすべての器具である。担う器具を一つずつ名を挙げて割り当てなさい。</span>
<span className="v" id="v33" data-v="33" data-xref="民数記 4:28; ヨシュア記 3:6; イザヤ書 3:6"> 以上が、会見の天幕におけるメラリの子らの諸氏族の奉仕であり、祭司アロンの子イタマルの監督のもとで行われる。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> モーセとアロン、および会衆の指導者たちは、ケハテの子らを氏族ごと、父祖の家ごとに数えた。</span>
<span className="v" id="v35" data-v="35" data-xref="歴代誌上 23:24; 民数記 4:23; 歴代誌上 23:3"> 三十歳以上五十歳までで、会見の天幕の務めに就いて奉仕するすべての者である。</span>
<span className="v" id="v36" data-v="36"> 氏族ごとに数えられた者は、二千七百五十人であった。</span>
<span className="v" id="v37" data-v="37"> 以上が、会見の天幕で奉仕するケハテ人の諸氏族から数えられた者たちであり、主がモーセを通して命じられたとおり、モーセとアロンが数えた。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> ゲルションの子らのうち、氏族ごと、父祖の家ごとに数えられた者は、</span>
<span className="v" id="v39" data-v="39"> 三十歳以上五十歳までで、会見の天幕の務めに就いて奉仕するすべての者、</span>
<span className="v" id="v40" data-v="40" data-xref="民数記 3:32"> すなわち、氏族ごと、父祖の家ごとに数えられた者は、二千六百三十人であった。</span>
<span className="v" id="v41" data-v="41"> 以上が、会見の天幕で奉仕するゲルションの子らの諸氏族から数えられた者たちであり、主の命令に従って、モーセとアロンが数えた。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> メラリの子らの諸氏族から、氏族ごと、父祖の家ごとに数えられた者は、</span>
<span className="v" id="v43" data-v="43"> 三十歳以上五十歳までで、会見の天幕の務めに就いて奉仕するすべての者、</span>
<span className="v" id="v44" data-v="44" data-xref="コリント人への第一の手紙 10:13; コリント人への第二の手紙 12:9–10; コリント人への第一の手紙 12:8–12"> すなわち、氏族ごとに数えられた者は、三千二百人であった。</span>
<span className="v" id="v45" data-v="45" data-xref="民数記 4:29"> 以上が、主がモーセを通して命じられたとおり、モーセとアロンが数えたメラリの子らの諸氏族の者たちである。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46"> モーセとアロン、およびイスラエルの指導者たちは、レビ人を氏族ごと、父祖の家ごとに数えた。</span>
<span className="v" id="v47" data-v="47" data-xref="コリント人への第一の手紙 12:4–31; ローマ人への手紙 12:6–8; 民数記 4:3"> 三十歳以上五十歳までで、会見の天幕における奉仕と荷を担う務めに就くすべての者である。</span>
<span className="v" id="v48" data-v="48" data-xref="民数記 3:39; マタイ 20:16; マタイ 22:15"> すなわち数えられた者は、八千五百八十人であった。</span>
<span className="v" id="v49" data-v="49" data-xref="民数記 1:54; 民数記 4:31; 民数記 4:15"> 主の命令に従い、モーセはそれぞれを奉仕と荷に応じて数えた。主がモーセに命じられたとおりである。</span>
</div>

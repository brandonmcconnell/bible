<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 25:22; 出エジプト記 19:1; 民数記 10:11–12"> 主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="すべて大文字の「主」または「神」は、神の固有名であるヘブル語「יהוה」（通常「ヤハウェ」と発音される）の訳である。">a</a></sup>は、イスラエルの子らがエジプトの地を出て第二年、第二の月の一日に、シナイの荒野の会見の天幕でモーセに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 38:26; 出エジプト記 30:12; 民数記 1:18"> 「イスラエルの子らの全会衆を、氏族ごと、父祖の家ごとに調べ、名簿に従ってすべての男子を一人ずつ数えなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 30:14; 民数記 14:29; 民数記 33:1"> 二十歳以上で、イスラエルの戦いに出ることのできるすべての者を、あなたとアロンが部隊ごとに数えなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 1:16; 出エジプト記 18:25; 民数記 13:2–15"> あなたがたとともに、各部族から一人ずつ、その父祖の家の長である者を立ち会わせなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 7:30; 創世記 30:5–20; 創世記 49:1–33"> あなたがたとともに立つ者たちの名は次のとおりである。<br />ルベンからは、シェデウルの子エリツル。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数記 7:36; 民数記 2:12"> シメオンからは、ツリシャダイの子シェルミエル。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ルカ 3:32; 民数記 10:14; マタイ 1:2–5"> ユダからは、アミナダブの子ナフション。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="民数記 7:18; 民数記 10:15; 民数記 2:5"> イッサカルからは、ツアルの子ネタネル。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数記 7:24; 民数記 10:16; 民数記 2:7"> ゼブルンからは、ヘロンの子エリアブ。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民数記 7:54; 民数記 7:48; 歴代誌上 7:26–27"> ヨセフの子らのうち、エフライムからは、アミフデの子エリシャマ。マナセからは、ペダツルの子ガマリエル。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民数記 7:60; 民数記 10:24; 民数記 2:22"> ベニヤミンからは、ギデオニの子アビダン。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数記 7:66; 民数記 2:25; 民数記 10:25"> ダンからは、アミシャダイの子アヒエゼル。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数記 7:72; 民数記 10:26; 民数記 2:27"> アシェルからは、オクランの子パギエル。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数記 2:14; 民数記 7:42; 民数記 10:20"> ガドからは、デウエルの子エリアサフ。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数記 7:78; 民数記 10:27; 民数記 2:29"> ナフタリからは、エナンの子アヒラ。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数記 7:2; 出エジプト記 18:21; 出エジプト記 18:25"> これらは会衆の中から召し出された者たちであり、彼らの父祖の部族の指導者たち<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または、首長たち、長たち。">b</a></sup>であった。彼らはイスラエルの千人の部隊の長たちであった。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネ 10:3; ヨハネの黙示録 7:4–17; 民数記 1:5–15"> モーセとアロンは、名を挙げられたこれらの者たちを選び、</span>
<span className="v" id="v18" data-v="18" data-xref="エズラ記 2:59; ネヘミヤ記 7:61; ヘブル人への手紙 7:3"> 第二の月の一日に全会衆を集めた。人々は氏族ごと、父祖の家ごとに自分の系統を登録し、二十歳以上の者は名簿に従って一人ずつ数えられた。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 1:2; 民数記 26:1–2; サムエル記第二 24:1–10"> 主がモーセに命じられたとおり、モーセはシナイの荒野で彼らを数えた。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数記 26:5–7; 民数記 2:10–11; 創世記 46:9"> イスラエルの長子ルベンの子らは、その系統、氏族、父祖の家ごとに、名簿に従って一人ずつ登録された。二十歳以上で、戦いに出ることのできるすべての男子である。</span>
<span className="v" id="v21" data-v="21" data-xref="民数記 26:7; 民数記 2:10–11"> ルベンの部族から数えられた者は、四万六千五百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数記 26:12–14; 創世記 34:25–30; 民数記 2:12–13"> シメオンの子らは、その系統、氏族、父祖の家ごとに、名簿に従って一人ずつ登録された。二十歳以上で、戦いに出ることのできるすべての男子である。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 26:14; 民数記 2:13; 民数記 25:8–9"> シメオンの部族から数えられた者は、五万九千三百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数記 26:15–18; 創世記 46:16; 民数記 2:14–15"> ガドの子らは、その系統、氏族、父祖の家ごとに、名簿に従って登録された。二十歳以上で、戦いに出ることのできるすべての者である。</span>
<span className="v" id="v25" data-v="25" data-xref="民数記 26:18; 民数記 2:15"> ガドの部族から数えられた者は、四万五千六百五十人であった。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="創世記 29:35; 民数記 26:19–22; サムエル記第二 24:9"> ユダの子らは、その系統、氏族、父祖の家ごとに、名簿に従って登録された。二十歳以上で、戦いに出ることのできるすべての者である。</span>
<span className="v" id="v27" data-v="27" data-xref="サムエル記第二 24:9; 民数記 26:22; 歴代誌 第二 17:14–16"> ユダの部族から数えられた者は、七万四千六百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 46:13; 創世記 49:14–15; 創世記 30:18"> イッサカルの子らは、その系統、氏族、父祖の家ごとに、名簿に従って登録された。二十歳以上で、戦いに出ることのできるすべての者である。</span>
<span className="v" id="v29" data-v="29" data-xref="民数記 26:25; 民数記 2:6"> イッサカルの部族から数えられた者は、五万四千四百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="民数記 26:26–27; 創世記 49:13; 創世記 30:20"> ゼブルンの子らは、その系統、氏族、父祖の家ごとに、名簿に従って登録された。二十歳以上で、戦いに出ることのできるすべての者である。</span>
<span className="v" id="v31" data-v="31" data-xref="民数記 26:27; 民数記 2:8"> ゼブルンの部族から数えられた者は、五万七千四百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="民数記 26:35–37; 申命記 33:17; 創世記 46:20"> ヨセフの子らのうち、エフライムの子らは、その系統、氏族、父祖の家ごとに、名簿に従って登録された。二十歳以上で、戦いに出ることのできるすべての者である。</span>
<span className="v" id="v33" data-v="33" data-xref="民数記 26:37; 申命記 33:17; 民数記 2:19"> エフライムの部族から数えられた者は、四万五百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="民数記 26:28–34"> マナセの子らは、その系統、氏族、父祖の家ごとに、名簿に従って登録された。二十歳以上で、戦いに出ることのできるすべての者である。</span>
<span className="v" id="v35" data-v="35" data-xref="民数記 26:34; 創世記 48:19–20; 民数記 2:21"> マナセの部族から数えられた者は、三万二千二百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="創世記 49:27; 創世記 44:20; ヨハネの黙示録 7:8"> ベニヤミンの子らは、その系統、氏族、父祖の家ごとに、名簿に従って登録された。二十歳以上で、戦いに出ることのできるすべての者である。</span>
<span className="v" id="v37" data-v="37" data-xref="民数記 26:41; 士師記 20:44–46; 歴代誌 第二 17:17"> ベニヤミンの部族から数えられた者は、三万五千四百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="創世記 46:23; 創世記 30:5–6; 創世記 49:16–17"> ダンの子らは、その系統、氏族、父祖の家ごとに、名簿に従って登録された。二十歳以上で、戦いに出ることのできるすべての者である。</span>
<span className="v" id="v39" data-v="39" data-xref="民数記 26:43; 民数記 2:26"> ダンの部族から数えられた者は、六万二千七百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="創世記 30:12–13; 創世記 46:27; 創世記 49:20"> アシェルの子らは、その系統、氏族、父祖の家ごとに、名簿に従って登録された。二十歳以上で、戦いに出ることのできるすべての者である。</span>
<span className="v" id="v41" data-v="41" data-xref="民数記 26:47; 民数記 2:28"> アシェルの部族から数えられた者は、四万一千五百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="創世記 49:21; 民数記 26:48–50; 創世記 46:24"> ナフタリの子らは、その系統、氏族、父祖の家ごとに、名簿に従って登録された。二十歳以上で、戦いに出ることのできるすべての者である。</span>
<span className="v" id="v43" data-v="43" data-xref="民数記 26:50; 民数記 2:30"> ナフタリの部族から数えられた者は、五万三千四百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="民数記 26:64; 民数記 1:2–16"> 以上が、モーセとアロン、およびイスラエルの十二人の指導者によって数えられた者たちである。指導者たちは、それぞれ父祖の家を代表していた。</span>
<span className="v" id="v45" data-v="45"> こうしてイスラエルの子らのうち、二十歳以上で、イスラエルの戦いに出ることのできるすべての者が、父祖の家ごとに数えられた。</span>
<span className="v" id="v46" data-v="46" data-xref="出エジプト記 12:37; 民数記 26:51; 出エジプト記 38:26"> その数えられた者の総数は、六十万三千五百五十人であった。</span>
<span className="v" id="v47" data-v="47" data-xref="民数記 2:33; 民数記 3:1–49; 民数記 26:57–62"> しかし、レビ人は彼らの父祖の部族に従って、彼らの中に数えられなかった。</span>
<span className="v" id="v48" data-v="48"> 主がモーセにこう告げておられたからである。</span>
<span className="v" id="v49" data-v="49" data-xref="民数記 26:62; 民数記 2:33"> 「レビの部族だけは数えてはならず、イスラエルの子らの中で彼らの人口調査を行ってはならない。</span>
<span className="v" id="v50" data-v="50" data-xref="出エジプト記 38:21; 出エジプト記 31:18; 民数記 4:15"> ただし、レビ人を証しの幕屋とそのすべての器具、およびそれに属するすべてのものの管理に任じなさい。彼らは幕屋とそのすべての器具を運び、その務めを果たし、幕屋の周りに宿営する。</span>
<span className="v" id="v51" data-v="51" data-xref="民数記 3:38; 民数記 3:10; サムエル記第一 6:19"> 幕屋を移すときにはレビ人がそれを取り外し、設営するときにはレビ人が組み立てる。近づく部外者は死刑に処される。</span>
<span className="v" id="v52" data-v="52" data-xref="民数記 2:2; 民数記 2:34; 民数記 10:1–36"> イスラエルの子らは、それぞれ自分の宿営、それぞれ自分の旗印のもとに、部隊ごとに天幕を張る。</span>
<span className="v" id="v53" data-v="53" data-xref="民数記 16:46; 歴代誌上 23:32; レビ記 10:6"> しかし、イスラエルの子らの会衆に御怒りが下らないよう、レビ人は証しの幕屋の周りに宿営し、その務めを担う。」</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="申命記 12:32; 出エジプト記 40:16; 出エジプト記 39:32"> イスラエルの子らはそのとおりに行った。主がモーセに命じられたすべてのことを、そのとおりに行った。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 27:13; 民数記 25:14–18; ヨハネの黙示録 6:10"> 「ミディアン人に対するイスラエルの子らの復讐を遂げなさい。その後、あなたはその民に加えられる。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="レビ記 26:25; 民数記 25:11; 列王記第二 10:30"> モーセは民に言った。「あなたがたの中から戦いに出る者を武装させ、ミディアンを攻めて、主の復讐を遂げさせなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 26:8; サムエル記第一 14:6; 士師記 7:2"> イスラエルのすべての部族から、各部族千人ずつを戦いに遣わしなさい。」</span>
<span className="v" id="v5" data-v="5"> こうしてイスラエルの部隊から、各部族千人ずつ、合わせて一万二千人が戦いのために召集された。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 14:44; 民数記 10:8–9; 歴代誌 第二 13:12–15"> モーセは各部族から千人ずつを戦いに遣わした。祭司エルアザルの子ピネハスも、聖所の器具と合図のラッパを手にして彼らとともに出陣した。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 21:11; 列王記第一 11:15–16; サムエル記第一 27:9"> 彼らは主がモーセに命じられたとおりにミディアンと戦い、すべての男子を殺した。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 13:21–22; 民数記 25:15; ヨハネの黙示録 2:14"> 彼らは殺された者たちとともにミディアンの王たち、すなわちエヴィ、レケム、ツル、フル、レバというミディアンの五人の王を殺した。彼らはまた、ベオルの子バラムを剣で殺した。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 20:14; 歴代誌 第二 28:8–10; 歴代誌 第二 28:5"> イスラエルの子らはミディアンの女たちと幼子を捕虜にし、家畜、羊の群れ、財産をすべて戦利品として奪った。</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 1:7; サムエル記第一 30:1; ヨシュア記 6:24"> 彼らは、彼らが住んでいたすべての町々と、すべての宿営を火で燃やした。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 20:14; ヨシュア記 8:2"> 彼らは人も家畜も、捕虜と戦利品をすべて取った。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 22:1"> そして捕虜と戦利品を、エリコの向かい、ヨルダン川のほとりのモアブの平野にある宿営へ持ち帰り、モーセ、祭司エルアザル、イスラエルの子らの会衆のもとへ届けた。</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 5:2; サムエル記第一 30:21; 民数記 31:12"> モーセ、祭司エルアザル、および会衆のすべての指導者たちは、彼らを出迎えるために宿営の外に出た。</span>
<span className="v" id="v14" data-v="14" data-xref="列王記第二 13:19; サムエル記第一 15:13–14; 民数記 31:48"> モーセは、戦いから帰って来た軍の指揮官、千人隊長、百人隊長に怒った。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記第一 15:3; エレミヤ書 48:10; 申命記 2:34"> モーセは言った。「女たちをみな生かしておいたのか。</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 25:1–9; ペテロの第二の手紙 2:15; ヨハネの黙示録 2:14"> この女たちは、バラムの助言によって、ペオルの事件でイスラエルの子らを主に背かせた者たちではないか。そのため、主の会衆に疫病が起こった。</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 21:11–12; 申命記 20:16–18; 申命記 7:2"> 今、幼子のうち男子をみな殺し、男と寝たことのある女をみな殺しなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 21:10–14; 歴代誌 第二 28:8–10; 申命記 20:14"> しかし、男と寝たことのない若い女はみな生かしておきなさい。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="民数記 19:11–22; 民数記 5:2; 歴代誌上 22:8"> あなたがたは七日間、宿営の外にとどまりなさい。人を殺した者、殺された者に触れた者は、三日目と七日目に、自分と捕虜を清める。</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 19:22; 創世記 35:2; 出エジプト記 19:10"> あなたがたはすべての衣服、すべての革製品、山羊の毛で作られたすべてのもの、およびすべての木製品を清めなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数記 30:16"> 祭司エルアザルは、戦いに行った軍人たちに言った。「これが主がモーセに命じられた律法の掟である。</span>
<span className="v" id="v22" data-v="22"> 金、銀、青銅、鉄、すず、鉛、</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 19:9; 民数記 19:17; コリント人への第一の手紙 3:13"> 火に耐えるものはすべて火の中を通せば清くなる。ただし、汚れを清める水でも清める。火に耐えないものはすべて水の中を通す。</span>
<span className="v" id="v24" data-v="24" data-xref="レビ記 11:25; レビ記 15:13; レビ記 14:9"> 七日目に衣服を洗えば清くなり、その後、宿営に入ることができる。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 主はモーセに告げられた。</span>
<span className="v" id="v26" data-v="26"> 「あなたと祭司エルアザル、会衆の父祖の家の長たちは、奪った戦利品のうち、人と家畜の総数を数えなさい。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 22:8; 詩篇 68:12; サムエル記第一 30:24–25"> 戦利品を、戦いに出た兵士と全会衆との間で二等分しなさい。</span>
<span className="v" id="v28" data-v="28" data-xref="民数記 18:26; 民数記 31:30; 民数記 31:47"> 戦いに出た兵士の分から、主への貢ぎ物を取りなさい。人、牛、ろば、羊、それぞれ五百につき一つである。</span>
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 29:27; 申命記 12:19; 申命記 12:12"> 彼らの半分からそれを取り、主への奉納物として祭司エルアザルに与えなさい。</span>
<span className="v" id="v30" data-v="30" data-xref="民数記 3:31; 民数記 3:7–8; 民数記 3:25"> イスラエルの子らの半分からは、人、牛、ろば、羊、その他の家畜を、五十につき一つ取り、主の幕屋の務めを担うレビ人に与えなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31"> モーセと祭司エルアザルは、主がモーセに命じられたとおりに行った。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 軍人たちが奪った獲物の残りのぶんどり物は、羊六十七万五千頭、</span>
<span className="v" id="v33" data-v="33"> 牛七万二千頭、</span>
<span className="v" id="v34" data-v="34"> ろば六万一千頭、</span>
<span className="v" id="v35" data-v="35"> また、男と寝たことのない女が、合わせて三万二千人であった。</span>
<span className="v" id="v36" data-v="36"> その半分、すなわち戦いに出た者たちの割り当ては、羊三十三万七千五百頭であった。</span>
<span className="v" id="v37" data-v="37"> その羊からの主への貢ぎ物は六百七十五頭であった。</span>
<span className="v" id="v38" data-v="38"> 牛は三万六千頭であり、その中からの主への貢ぎ物は七十二頭であった。</span>
<span className="v" id="v39" data-v="39"> ろばは三万五百頭であり、その中からの主への貢ぎ物は六十一頭であった。</span>
<span className="v" id="v40" data-v="40"> 人は一万六千人であり、その中からの主への貢ぎ物は三十二人であった。</span>
<span className="v" id="v41" data-v="41" data-xref="民数記 18:8; 民数記 18:19; ヘブル人への手紙 7:9–12"> モーセは主が命じられたとおり、主への奉納物である貢ぎ物を祭司エルアザルに与えた。</span>
<span className="v" id="v42" data-v="42"> モーセが戦った男たちから分けた、イスラエルの子らの半分については、</span>
<span className="v" id="v43" data-v="43"> （会衆の半分は、羊三十三万七千五百頭、</span>
<span className="v" id="v44" data-v="44"> 牛三万六千頭、</span>
<span className="v" id="v45" data-v="45"> ろば三万五百頭、</span>
<span className="v" id="v46" data-v="46"> および人一万六千人であった。）</span>
<span className="v" id="v47" data-v="47" data-xref="民数記 31:30; ルカ 10:1–8; イザヤ書 56:10–11"> モーセはそのイスラエルの子らの半分から、人であれ動物であれ、五十につき一つを取り出し、主がモーセに命じられたとおり、主の幕屋の任務を果たすレビ人に与えた。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48"> 軍の部隊を指揮する千人隊長と百人隊長が、モーセのもとに来た。</span>
<span className="v" id="v49" data-v="49" data-xref="ヨハネ 18:9; サムエル記第一 30:18–19; 詩篇 72:14"> 彼らはモーセに言った。「しもべどもが指揮下の兵士を数えましたが、私たちのうち一人も欠けていません。</span>
<span className="v" id="v50" data-v="50" data-xref="出エジプト記 30:12; 出エジプト記 30:15–16; 詩篇 116:12"> そこで私たちは、各自が手に入れた金の装飾品、腕輪、腕飾り、指輪、耳輪、首飾りを、主へのささげ物として持って来ました。主の前で私たちの命のために贖いを行うためです。」</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="民数記 7:2–6"> モーセと祭司エルアザルは、彼らから金、すなわちすべての細工物を受け取った。</span>
<span className="v" id="v52" data-v="52"> 千人隊長と百人隊長が主にささげた奉納物の金は、合わせて一万六千七百五十シェケル<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一シェケルは約10グラム、または約0.35オンスなので、16,750シェケルは約167.5キログラム、または約368.5ポンドである。">a</a></sup>であった。</span>
<span className="v" id="v53" data-v="53" data-xref="申命記 20:14; 民数記 31:32"> 軍人たちはめいめい自分のために獲物を奪っていた。</span>
<span className="v" id="v54" data-v="54" data-xref="出エジプト記 30:16; ゼカリヤ書 6:14; 使徒の働き 10:4"> モーセと祭司エルアザルは千人の長たちや百人の長たちから金を受け取り、イスラエルの子らのための主の前での記念として、それを会見の天幕に持って行った。</span>
</div>
</div>

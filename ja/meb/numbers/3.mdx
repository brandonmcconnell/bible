<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 6:20; 創世記 10:1; 出エジプト記 6:16"> 主がシナイ山でモーセに語られたころの、アロンとモーセの系譜は次のとおりである。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 6:23; 民数記 26:60; 出エジプト記 28:1"> アロンの子らの名は次のとおりである。長子はナダブ、次にアビフ、エルアザル、イタマルである。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 28:41; レビ記 8:30; レビ記 8:12"> これらがアロンの子ら、すなわち油を注がれ、祭司として仕えるために任職された祭司たちの名である。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 10:1–2; 民数記 26:61"> ナダブとアビフは、シナイの荒野で主の前に異なる火をささげたとき、主の前で死んだ。二人には子がなかった。エルアザルとイタマルは、父アロンのもとで祭司として仕えた。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 主はモーセに告げられた。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 10:8; 民数記 2:33; 民数記 1:49–53"> 「レビの部族を近づけ、祭司アロンの前に立たせて、彼に仕えさせなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 1:50; 民数記 8:15; 民数記 8:11"> 彼らは会見の天幕の前で、アロンに対する務めと全会衆に対する務めを果たし、幕屋の奉仕を担う。</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 4:33; 民数記 10:17; イザヤ書 52:11"> 会見の天幕のすべての器具を管理し、イスラエルの子らに代わって幕屋の奉仕を担う。</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 8:19; 民数記 18:6–7; エペソ人への手紙 4:8"> レビ人をアロンとその子らに与えなさい。彼らはイスラエルの子らに代わって、アロンに全面的に与えられた者たちである。</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 1:51; 民数記 3:38; ローマ人への手紙 12:7"> アロンとその子らを任命し、祭司の務めを担わせなさい。近づく部外者は死刑に処される。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 主はモーセに告げられた。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 3:41; 民数記 8:16; 民数記 18:6"> 「見よ、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「見よ」はヘブル語「הִנֵּה」に由来し、「見なさい」「注目せよ」などの意味を持つ間投詞である。">a</a></sup>わたしは、イスラエルの子らのうち胎を開くすべての長子に代えて、イスラエルの子らの中からレビ人を取った。レビ人はわたしのものとなる。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカ 2:23; 出エジプト記 13:12; 出エジプト記 13:2"> すべての長子はわたしのものだからである。わたしがエジプトの地で長子をすべて打ち殺した日に、人間であれ動物であれ、イスラエルのすべての長子をわたしのために聖別した。彼らはわたしのものとなる。わたしは主である。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 主はシナイの荒野でモーセに告げられた。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 26:62; マルコ 10:14; テモテへの第二の手紙 3:15"> 「レビの子らを、父祖の家ごと、氏族ごとに数えなさい。一か月以上のすべての男子を数えなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数記 3:39; 民数記 4:37; 民数記 4:49"> モーセは命じられたとおり、主の言葉に従って彼らを数えた。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 46:11; 出エジプト記 6:16–19; 民数記 15:5–23"> レビの子らの名は、ゲルション、ケハテ、メラリである。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歴代誌上 6:17; 歴代誌上 26:1–32; 出エジプト記 6:17–19"> ゲルションの子らを氏族別に挙げると、リブニとシムイ。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 6:18; 歴代誌上 6:18; 歴代誌上 15:17–21"> ケハテの子らを氏族別に挙げると、アムラム、イツハル、ヘブロン、ウジエル。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 6:19; 歴代誌上 6:19; 民数記 3:33"> メラリの子らを氏族別に挙げると、マフリとムシである。<br />これらが、父祖の家によるレビ人の氏族である。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> ゲルションからはリブニ人の氏族とシムイ人の氏族が出た。これらがゲルション人の氏族である。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数記 4:38–40"> 一か月以上の男子を数えると、七千五百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="民数記 1:53; 民数記 2:17"> ゲルション人の氏族は、幕屋の後ろ、すなわち西側に宿営する。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> ゲルション人の父祖の家の長は、ラエルの子エルヤサフであった。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 25:9; 歴代誌上 23:32; 歴代誌上 9:14–33"> 会見の天幕におけるゲルションの子らの任務は、幕屋と天幕、その覆い、会見の天幕の入口の垂れ幕、</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 35:18; 出エジプト記 38:9–16; 出エジプト記 27:9–16"> 庭の掛け幕、幕屋と祭壇を囲む庭の入口の垂れ幕、およびこれらの奉仕に用いるすべてのひもを管理することであった。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歴代誌上 26:23; 民数記 3:19; 歴代誌上 23:12"> ケハテからはアムラム人の氏族、イツハル人の氏族、ヘブロン人の氏族、ウジエル人の氏族が出た。これらがケハテ人の氏族である。</span>
<span className="v" id="v28" data-v="28" data-xref="民数記 3:31; 民数記 4:35–36; 民数記 3:7"> 一か月以上の男子は八千六百人であり、聖所の務めを担った。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数記 1:53; 民数記 3:23; 民数記 2:10"> ケハテの子らの氏族は、幕屋の南側に宿営する。</span>
<span className="v" id="v30" data-v="30"> ケハテ人の氏族の父祖の家の長は、ウジエルの子エリツァファンであった。</span>
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 36:35–36; 出エジプト記 27:1–8; 出エジプト記 26:31–33"> 彼らの任務は、契約の箱、机、燭台、祭壇、奉仕に用いる聖所の器具、垂れ幕、およびこれらに関するすべての務めであった。</span>
<span className="v" id="v32" data-v="32" data-xref="民数記 4:27; 民数記 4:16; 民数記 20:25–28"> 祭司アロンの子エルアザルはレビ人の指導者たちを統括し、聖所の務めを担う者たちを監督した。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="民数記 3:20; 歴代誌上 6:19; 歴代誌上 23:21"> メラリからはマフリ人の氏族とムシ人の氏族が出た。これらがメラリの氏族である。</span>
<span className="v" id="v34" data-v="34" data-xref="民数記 2:9; 民数記 2:11; 民数記 1:21"> 彼らのうち数えられた一か月以上の男子は、六千二百人であった。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="22,000は有効数字2桁に丸められた合計である。上記で挙げられたゲルション人、ケハテ人、メラリ人の合計は22,300であるが、伝統的なヘブル語本文では、その数は有効数字3桁ではなく有効数字2桁に丸められている。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="民数記 1:53; 民数記 2:25; 民数記 3:28–29"> メラリの氏族の父祖の家の長は、アビハイルの子ツリエルであった。彼らは幕屋の北側に宿営する。</span>
<span className="v" id="v36" data-v="36" data-xref="出エジプト記 26:32; 出エジプト記 26:37; 出エジプト記 26:15–29"> メラリの子らの割り当てられた任務は、幕屋の板、その横木、その柱、その台座、そのすべての器具、そのすべての奉仕、</span>
<span className="v" id="v37" data-v="37"> 庭の周囲の柱、その台座、その釘、そのひもであった。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="民数記 3:10; 民数記 1:53; 民数記 2:3"> 幕屋の前、すなわち東側、会見の天幕の正面の日の出る方角には、モーセとアロン、その子らが宿営した。彼らはイスラエルの子らに代わって聖所の務めを担った。近づく部外者は死刑に処される。</span>
<span className="v" id="v39" data-v="39" data-xref="民数記 26:62; マタイ 7:14; 民数記 4:47–48"> 主の命令によってモーセとアロンが氏族ごとに数えたレビ人のうち、数えられたすべての者、すなわち一か月以上のすべての男子は、二万二千人であった。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="民数記 3:15; ルカ 10:20; 詩篇 87:6"> 主はモーセに言われた。「イスラエルの子らの長子であるすべての男子を、一か月以上の者から数え、その名を一人ずつ記録しなさい。</span>
<span className="v" id="v41" data-v="41" data-xref="民数記 3:12; 民数記 3:45; 民数記 8:16"> あなたはイスラエルの子らの中のすべての長子の代わりに、わたしのためにレビ人を――わたしは主である――取りなさい。また、イスラエルの子らの家畜のすべての初子の代わりに、レビ人の家畜を取りなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> モーセは、主が命じられたとおりに、イスラエルの子らの中のすべての長子を数えた。</span>
<span className="v" id="v43" data-v="43" data-xref="民数記 3:39"> 一か月以上で、名を数えられた長子の男子は、二万二千二百七十三人であった。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44"> 主はモーセに告げられた。</span>
<span className="v" id="v45" data-v="45" data-xref="民数記 3:12; 民数記 3:40–41"> 「イスラエルの子らの中のすべての長子の代わりにレビ人を、彼らの家畜の代わりにレビ人の家畜を取りなさい。レビ人はわたしのものとなる。わたしは主である。</span>
<span className="v" id="v46" data-v="46" data-xref="出エジプト記 13:13; 民数記 18:15–16"> レビ人の数を超えた、イスラエルの子らの長子二百七十三人を贖うために、</span>
<span className="v" id="v47" data-v="47" data-xref="出エジプト記 30:13; レビ記 27:6; 民数記 18:16"> あなたは一人につき五シェケルずつ取りなさい。聖所のシェケル<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="1シェケルは約10グラム、または約0.35オンスである。">c</a></sup>に従ってこれらを取りなさい（一シェケルは二十ゲラ<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="1ゲラは約0.5グラム、または約7.7グレーンである。">d</a></sup>である）。</span>
<span className="v" id="v48" data-v="48"> 数を超えた者たちの贖いの銀を、アロンとその子らに渡しなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49"> モーセは、レビ人の数を超えた長子たちから贖いの銀を取った。</span>
<span className="v" id="v50" data-v="50" data-xref="民数記 3:46–47; ペテロの手紙第一 3:18; マタイ 20:28"> 彼はイスラエルの子らの長子からその銀、すなわち聖所のシェケルに従って千三百六十五シェケル<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="1シェケルは約10グラム、または約0.35オンスであるため、1365シェケルは約13.65キログラム、または約30ポンドである。">e</a></sup>を取った。</span>
<span className="v" id="v51" data-v="51" data-xref="民数記 3:48; 民数記 16:15; サムエル記第一 12:3–4"> モーセは主の言葉に従い、主が命じられたとおり、その贖いの銀をアロンとその子らに渡した。</span>
</div>
</div>

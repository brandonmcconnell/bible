<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセとアロンに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第一の手紙 14:40; 民数記 10:22; 民数記 1:50"> 「イスラエルの子らは、それぞれ自分の旗のもと、父祖の家の旗印のもとに宿営する。会見の天幕を囲み、少し離れて宿営する。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="歴代誌上 2:10; ルツ記 4:20; ルカ 3:32–33"> 東側、日の出る方角には、ユダの宿営の旗に属する者たちが部隊ごとに宿営する。ユダの子らの指導者は、アミナダブの子ナフションである。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 26:22; 民数記 1:27"> その部隊で数えられた者は、七万四千六百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民数記 1:8; 民数記 7:18; 民数記 7:23"> その隣にはイッサカルの部族が宿営する。イッサカルの子らの指導者は、ツアルの子ネタネルである。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 26:25; 民数記 1:29"> その部隊で数えられた者は、五万四千四百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="民数記 1:9; 民数記 7:24; 民数記 10:16"> ゼブルンの部族。ゼブルンの子らの指導者は、ヘロンの子エリアブである。</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 26:26–27; 民数記 1:31"> その部隊で数えられた者は、五万七千四百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数記 10:14"> ユダの宿営で数えられた者の総数は、部隊ごとに十八万六千四百人であった。彼らは先頭に立って出発する。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民数記 1:5; 創世記 49:3–4; 民数記 7:35"> 南側には、ルベンの宿営の旗に属する者たちが部隊ごとに宿営する。ルベンの子らの指導者は、シェデウルの子エリツルである。</span>
<span className="v" id="v11" data-v="11" data-xref="民数記 26:7; 民数記 1:21"> その部隊で数えられた者は、四万六千五百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数記 1:6; 民数記 10:19; 民数記 7:41"> その隣にはシメオンの部族が宿営する。シメオンの子らの指導者は、ツリシャダイの子シェルミエルである。</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 26:14; 民数記 1:23"> その部隊で数えられた者は、五万九千三百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数記 1:14; 民数記 7:42; 民数記 7:47"> ガドの部族。ガドの子らの指導者は、レウエルの子エリアサフである。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 26:18; 民数記 1:25"> その部隊で数えられた者は、四万五千六百五十人であった。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数記 10:18; 民数記 2:9; 民数記 2:24"> ルベンの宿営で数えられた者の総数は、部隊ごとに十五万一千四百五十人であった。彼らは二番目に出発する。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民数記 10:21; 民数記 10:17; 民数記 3:38"> 次に、レビ人の宿営とともに会見の天幕が、各宿営の中央を進む。宿営した順に出発し、それぞれ自分の位置を守って、旗印ごとに進む。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民数記 1:10; 民数記 10:22; 創世記 48:14–20"> 西側には、エフライムの宿営の旗に属する者たちが部隊ごとに宿営する。エフライムの子らの指導者は、アミフデの子エリシャマである。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 1:33; 民数記 26:37"> その部隊で数えられた者は、四万五百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数記 1:10; 民数記 7:54; 民数記 10:23"> その隣にはマナセの部族が宿営する。マナセの子らの指導者は、ペダツルの子ガマリエルである。</span>
<span className="v" id="v21" data-v="21" data-xref="民数記 26:34; 民数記 1:35"> その部隊で数えられた者は、三万二千二百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数記 1:11; 民数記 7:60; 民数記 10:24"> ベニヤミンの部族。ベニヤミンの子らの指導者は、ギデオニの子アビダンである。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 1:37; 民数記 26:41"> その部隊で数えられた者は、三万五千四百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数記 10:22; 民数記 2:31; 詩篇 80:2"> エフライムの宿営で数えられた者の総数は、部隊ごとに十万八千百人であった。彼らは三番目に出発する。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="民数記 1:12; 民数記 7:66; 民数記 10:25"> 北側には、ダンの宿営の旗に属する者たちが部隊ごとに宿営する。ダンの子らの指導者は、アミシャダイの子アヒエゼルである。</span>
<span className="v" id="v26" data-v="26" data-xref="民数記 26:43; 民数記 1:39"> その部隊で数えられた者は、六万二千七百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="民数記 1:13; 民数記 7:77; 民数記 7:72"> その隣にはアシェルの部族が宿営する。アシェルの子らの指導者は、オクランの子パギエルである。</span>
<span className="v" id="v28" data-v="28" data-xref="民数記 1:41; 民数記 26:47"> その部隊で数えられた者は、四万一千五百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数記 1:15; 民数記 10:27; 民数記 26:48–50"> ナフタリの部族。ナフタリの子らの指導者は、エナンの子アヒラである。</span>
<span className="v" id="v30" data-v="30" data-xref="民数記 1:42–43; 民数記 26:50"> その部隊で数えられた者は、五万三千四百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="民数記 10:25; 民数記 2:16; 民数記 2:9"> ダンの宿営で数えられた者の総数は、十五万七千六百人であった。彼らはその旗に従って、最後に出発する。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="民数記 1:46; 出エジプト記 38:26; 民数記 2:9"> これらが、父祖の家ごとに数えられたイスラエルの子らである。部隊ごとに宿営で数えられた者の総数は、六十万三千五百五十人であった。</span>
<span className="v" id="v33" data-v="33" data-xref="民数記 26:57–62; 民数記 1:47–49"> しかし、主がモーセに命じられたとおり、レビ人はイスラエルの子らの中には数えられなかった。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="詩篇 119:6; 民数記 24:2; 民数記 24:5–6"> イスラエルの子らはそのとおりに行った。主がモーセに命じられたとおり、旗印ごとに宿営し、それぞれの氏族、父祖の家ごとに出発した。</span>
</div>
</div>

<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="NUM" data-book-slug="numbers" data-book-name="民数記" data-chapter="13" data-verses="33">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 1:22–25; 民数記 32:8; 民数記 34:18"> 「イスラエルの子らにわたしが与えるカナンの地を偵察させるため、人々を遣わしなさい。父祖の各部族から一人ずつ、その部族の指導者を遣わしなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="民数記 12:16; 民数記 32:8; 申命記 1:19"> モーセは主の命令に従い、パランの荒野から彼らを遣わした。彼らは皆、イスラエルの子らの指導者であった。</span>
<span className="v" id="v4" data-v="4"> 彼らの名は次のとおりである。<br />ルベンの部族からは、ザクルの子シャムア。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> シメオンの部族からは、ホリの子シャファト。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数記 34:19; 民数記 14:6; 民数記 13:30"> ユダの部族からは、エフネの子カレブ。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> イッサカルの部族からは、ヨセフの子イグアル。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 24:13; 民数記 11:28; 民数記 13:16"> エフライムの部族からは、ヌンの子ホシェア。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> ベニヤミンの部族からは、ラフの子パルティ。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> ゼブルンの部族からは、ソディの子ガディエル。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> ヨセフの部族、すなわちマナセの部族からは、スシの子ガディ。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> ダンの部族からは、ゲマリの子アミエル。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> アシェルの部族からは、ミカエルの子セトル。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> ナフタリの部族からは、ウォフシの子ナフビ。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> ガドの部族からは、マキの子ゲウエル。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数記 13:8; 出エジプト記 17:9; 民数記 14:6"> これらは、モーセがその地を偵察させるために遣わした男たちの名である。モーセはヌンの子ホシェアをヨシュアと呼んだ。</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 1:9; 創世記 12:9; 士師記 1:19"> モーセはカナンの地を偵察させるために彼らを遣わし、言った。「ここからネゲブへ上り、さらに山地へ上りなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 34:14; 出エジプト記 3:8"> その地がどのようなものか、そこに住む民が強いか弱いか、少ないか多いかを見なさい。</span>
<span className="v" id="v19" data-v="19"> 彼らの住む地が良いか悪いか、町々が無防備か城壁で守られているかを見なさい。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 31:23; 申命記 31:6–8; エゼキエル書 34:14"> その地がどのようなものか、肥えているか痩せているか、そこに木があるかないかを見なさい。勇気を出し、その地の果実をいくらか持って来なさい。」さて、その時期はぶどうの初なりの季節であった。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数記 20:1; 民数記 33:36; 民数記 27:14"> 彼らは上って行き、ツィンの荒野からハマトの入口にあるレホブまで、その地を偵察した。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 78:12; 詩篇 78:43; イザヤ書 19:11"> 彼らは南の地を通って上り、ヘブロンに来た。そこにはアナクの子らであるアヒマン、シェシャイ、タルマイがいた。（ヘブロンはエジプトのツォアンより七年前に建てられていた。）</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 13:24; 民数記 32:9; 申命記 1:24–25"> 彼らはエシュコルの谷に来て、そこからぶどうの一房のついた枝を切り取り、二人で棒にかけてそれを担いだ。彼らはざくろといちじくもいくらか持って来た。</span>
<span className="v" id="v24" data-v="24"> イスラエルの子らがそこで切り取ったぶどうの房にちなみ、その場所はエシュコルの谷と呼ばれた。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 34:28; 出エジプト記 24:18; 民数記 14:33–34"> 四十日後、彼らはその地の偵察から帰って来た。</span>
<span className="v" id="v26" data-v="26" data-xref="民数記 32:8; 民数記 20:1; 申命記 1:19"> 彼らはパランの荒野のカデシュにいるモーセとアロン、およびイスラエルの子らの全会衆のもとに戻り、全会衆に報告して、その地の果実を見せた。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 3:8; 出エジプト記 3:17; 出エジプト記 13:5"> 彼らはモーセに告げた。「私たちは、あなたが遣わされた地へ行きました。そこは確かに乳と蜜が流れており、これがその果実です。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 9:1–2; 申命記 1:28; 民数記 13:33"> しかし、その地に住む民は強く、町々は城壁で囲まれて非常に大きく、さらにそこでアナクの子らを見ました。</span>
<span className="v" id="v29" data-v="29" data-xref="民数記 14:43; 士師記 6:3; 創世記 15:19–21"> アマレク人は南の地に住み、ヘト人、エブス人、アモリ人は山地に住み、カナン人は海辺とヨルダン川沿いに住んでいます。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="民数記 14:24; ローマ人への手紙 8:31; ピリピ人への手紙 4:13"> カレブはモーセの前で民を静めて言った。「すぐに上って行き、そこを占領しましょう。私たちは必ず勝てます。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="申命記 1:28; ヨシュア記 14:8; ヘブル人への手紙 3:19"> しかし、彼とともに上って行った男たちは言った。「私たちはあの民に向かって上って行くことはできません。彼らは私たちよりも強いからです。」</span>
<span className="v" id="v32" data-v="32" data-xref="アモス書 2:9; 民数記 14:36–37; エゼキエル書 36:13–14"> 彼らは偵察した地についてイスラエルの子らの間に悪評を広め、言った。「私たちが偵察して通り巡った地は、住民を食い尽くす地です。そこで見た民は皆、並外れて大きな者たちでした。</span>
<span className="v" id="v33" data-v="33" data-xref="申命記 1:28; イザヤ書 40:22; 創世記 6:4"> そこでネフィリム<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または、巨人。">a</a></sup>、すなわちネフィリム<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または、巨人。">b</a></sup>の子孫であるアナクの子らを見ました。自分たちがいなごのように見え、彼らの目にもそう見えました。」</span>
</div>
</div>

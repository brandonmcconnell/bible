<span className="v" id="v3" data-v="3" data-xref="コロサイ人への手紙 2:11; 申命記 30:6; ローマ人への手紙 7:6"> 聖霊によって神を礼拝し、キリスト・イエスにあって誇り、肉に頼らない私たちこそ、割礼を受けた者だからです。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第二の手紙 11:18–22"> もっとも、私自身には肉に頼る根拠もあります。ほかのだれかが肉に頼れると思うなら、私はなおさらです。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 11:22; ローマ人への手紙 11:1; 使徒の働き 23:6"> 私は生後八日目に割礼を受け、イスラエル民族に属し、ベニヤミン族の出身で、ヘブル人の中のヘブル人です。律法についてはファリサイ人、</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 1:13–14; 使徒の働き 8:3; 使徒の働き 26:9–10"> 熱心さについては教会を迫害する者、律法による義については非難されるところのない者でした。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ルカ 14:33; マタイ 16:26; マタイ 13:44–46"> しかし、私にとって益であったものを、私はキリストのために損失と数えるようになりました。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 9:23–24; ローマ人への手紙 8:18; ピリピ人への手紙 3:7"> それどころか、私の主キリスト・イエスを知ることの比類ない尊さのゆえに、私はすべてのものを損失と数えています。キリストのためにすべてを失い、それらをくずと見なしています。それは、私がキリストを得て、</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第二の手紙 5:21; コリント人への第一の手紙 1:30; ガラテヤ人への手紙 2:16"> キリストのうちにある者と認められるためです。私が持つ義は、律法による自分自身の義ではなく、キリストへの信仰による義、すなわち、信仰に基づいて神から与えられる義です。</span>
<span className="v" id="v10" data-v="10" data-xref="ガラテヤ人への手紙 2:20; ローマ人への手紙 8:17; ペテロの手紙第一 4:1–2"> 私はキリストと、その復活の力を知り、その苦しみにあずかり、キリストの死と同じ姿にされたいのです。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカ 20:35–36; ヨハネの黙示録 20:5; 使徒の働き 23:6"> そうして、何とかして死者の中からの復活に達したいと願っています。</span>
<span className="v" id="v12" data-v="12" data-xref="テモテへの手紙第一 6:11–12; ペテロの第二の手紙 1:5–8; 詩篇 138:8"> 私は、すでにそれを得たわけでも、すでに完全な者にされたわけでもありません。しかし、キリスト・イエスに捕らえられた私も、それを捕らえようとして、ひたすら追い求めています。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカ 9:62; ヘブル人への手紙 12:1–2; ピリピ人への手紙 3:12"> 兄弟たち、私はまだ捕らえたとは考えていません。ただ一つ、後ろのものを忘れ、前のものに向かって身を伸ばし、</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 9:24; ペテロの手紙第一 5:10; ヨハネの黙示録 3:21"> キリスト・イエスにあって神から上へと召されて受ける賞を得るため、目標に向かって進んでいます。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネ 7:17; ヤコブの手紙 1:4–5; 箴言 2:3–6"> ですから、成熟した者は皆、このように考えましょう。もし何かについて違う考えを持っているなら、そのことも神があなたがたに明らかにしてくださいます。</span>
<span className="v" id="v16" data-v="16" data-xref="コロサイ人への手紙 2:6; ヨハネの黙示録 3:3; ヨハネの黙示録 2:4–5"> ただ、私たちがすでに到達したところに従い、同じ基準によって歩み、同じ思いを保ちましょう。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ピリピ人への手紙 4:9; コリント人への第一の手紙 4:16; ペテロの手紙第一 5:3"> 兄弟たち、皆で私に倣う者となりなさい。また、私たちを模範として、このように歩んでいる人たちに目を留めなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 4:17; イザヤ書 8:11; ガラテヤ人への手紙 6:12"> 多くの人がキリストの十字架の敵として歩んでいるからです。私は彼らのことを何度もあなたがたに話し、今も涙を流しながら話しています。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 16:18; ローマ人への手紙 8:5–7; ペテロの第二の手紙 2:3"> 彼らの行き着く先は滅びであり、彼らの神は腹です。彼らは自分たちの恥を誇り、地上のことばかり考えています。</span>
<span className="v" id="v20" data-v="20" data-xref="エペソ人への手紙 2:19; コロサイ人への手紙 3:1–3; コリント人への第二の手紙 4:18–1"> しかし、私たちの国籍は天にあります。私たちはそこから救い主、主イエス・キリストが来られるのを待ち望んでいます。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの手紙第一 3:2; コロサイ人への手紙 3:4; コリント人への第一の手紙 15:42–56"> キリストは、万物をご自分に従わせることのできる力によって、私たちの卑しい体を変え、ご自分の栄光の体と同じ姿にしてくださいます。</span>

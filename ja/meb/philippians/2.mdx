<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 3:12; ヨハネの手紙第一 4:12; ヨハネの手紙第一 4:7–8"> こういうわけで、キリストにある励まし、愛による慰め、聖霊との交わり、深い愛情とあわれみが少しでもあるなら、</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 12:16; ペテロの手紙第一 3:8–9; コリント人への第一の手紙 1:10"> 同じ思いを持ち、同じ愛を抱き、心を合わせ、一つの思いを抱いて、私の喜びを満たしてください。</span>
<span className="v" id="v3" data-v="3" data-xref="ローマ人への手紙 12:10; ガラテヤ人への手紙 5:26; エペソ人への手紙 5:21"> 利己的な野心や虚栄からは何もせず、へりくだって、それぞれ相手を自分より優れた者と考えなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 10:24; ローマ人への手紙 15:1; ヤコブの手紙 2:8"> それぞれ、自分のことだけでなく、ほかの人のことにも目を配りなさい。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ヨハネの手紙第一 2:6; マタイ 11:29; ペテロの手紙第一 2:21"> キリスト・イエスにあったこの思いを、あなたがたの間でも抱きなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 5:18; コリント人への第二の手紙 4:4; ヘブル人への手紙 1:3"> キリストは神のかたちで存在しておられましたが、神と等しくあることを、固守すべきものとは考えず、</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第二の手紙 8:9; マタイ 20:28; ヨハネ 1:14"> かえってご自分をむなしくし、しもべのかたちを取り、人間と同じ姿になられました。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネ 10:18; ヘブル人への手紙 12:2; ローマ人への手紙 5:19"> 人としての姿をもって現れ、ご自分を低くし、死に至るまで、それも十字架の死に至るまで従順になられました。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 19:16; マタイ 28:18; ペテロの手紙第一 3:22"> それゆえ神は、キリストをこの上なく高く上げ、あらゆる名にまさる名をお与えになりました。</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 45:23–25; マタイ 28:18; ヨハネの黙示録 5:13–14"> それは、イエスの名の前に、天上のもの、地上のもの、地下のものが皆ひざをかがめ、</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの手紙第一 4:15; ローマ人への手紙 14:11; ヨハネ 13:13"> すべての舌が「イエス・キリストは主である」と告白して、父なる神に栄光を帰すためです。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ペテロの第二の手紙 1:5–10; ルカ 13:23–24; コリント人への第一の手紙 15:58"> こういうわけで、私の愛する人たち、あなたがたはいつも従順でしたが、私がいる時だけでなく、今、私がいない時にはなおさら、恐れおののきながら自分の救いを全うしなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 13:21; コリント人への第二の手紙 3:5; テモテへの第二の手紙 1:9"> あなたがたのうちに働き、御心のままに、志を与え、それを実行させてくださるのは神だからです。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ペテロの手紙第一 4:9; コリント人への第一の手紙 10:10; ピリピ人への手紙 2:3"> 何事も、不平を言ったり言い争ったりせずに行いなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイ 5:14–16; ペテロの手紙第一 2:12; マタイ 5:45"> それは、曲がったよこしまな世代のただ中で、非難されるところのない純真な者、傷のない神の子どもとなるためです。あなたがたは、その中で世の光として輝き、</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への第一の手紙 9:26; ガラテヤ人への手紙 2:2; ヨハネの手紙第一 1:1"> いのちの言葉を掲げなさい。そうすればキリストの日に、私が走ったことも労苦したことも無駄ではなかったと誇ることができます。</span>
<span className="v" id="v17" data-v="17" data-xref="テモテへの第二の手紙 4:6; ローマ人への手紙 15:16; ヘブル人への手紙 13:15–16"> たとえ私が、あなたがたの信仰といういけにえと奉仕の上に注ぎ出されるとしても、私は喜び、あなたがたすべてとともに喜びます。</span>
<span className="v" id="v18" data-v="18" data-xref="ヤコブの手紙 1:2–4; ピリピ人への手紙 4:4; ピリピ人への手紙 3:1"> 同じように、あなたがたも喜び、私とともに喜びなさい。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="コリント人への第一の手紙 4:17; テサロニケ人への手紙第一 3:6–8; テサロニケ人への手紙第一 3:2"> あなたがたの様子を知って私も心強くなるように、主イエスにあって、近いうちにテモテをあなたがたのもとへ遣わしたいと願っています。</span>
<span className="v" id="v20" data-v="20" data-xref="ピリピ人への手紙 2:2; コリント人への第一の手紙 16:10; ピリピ人への手紙 2:22"> 彼のように私と心を同じくし、あなたがたのことを真心から気遣う者は、ほかにだれもいないからです。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第一の手紙 10:24; マタイ 16:24; ピリピ人への手紙 2:4"> ほかの人たちは皆、イエス・キリストのことではなく、自分自身のことを求めています。</span>
<span className="v" id="v22" data-v="22" data-xref="コリント人への第一の手紙 4:17; コリント人への第二の手紙 2:9; テモテへの第二の手紙 1:2"> しかし、テモテが確かな人物であることを、あなたがたは知っています。子が父に仕えるように、彼は私とともに福音のために仕えてきました。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記第一 22:3; ピリピ人への手紙 2:19"> ですから、私のことがどうなるか分かりしだい、すぐに彼を遣わしたいと思っています。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの手紙第三 1:14; フィレモンへの手紙 1:22; ピリピ人への手紙 1:25–26"> また、私自身も間もなく行けると、主にあって確信しています。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ピリピ人への手紙 4:18; フィレモンへの手紙 1:1–2; ピリピ人への手紙 4:3"> しかし私は、私の兄弟、同労者、戦友であり、またあなたがたの使者として、私の必要に仕えてくれたエパフロディトを、あなたがたのもとへ遣わす必要があると考えました。</span>
<span className="v" id="v26" data-v="26" data-xref="ローマ人への手紙 12:15; 箴言 12:25; エペソ人への手紙 3:13"> 彼はあなたがたすべてを慕い、自分が病気であったことがあなたがたに伝わったと知って、ひどく心を痛めていたからです。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 34:19; ピリピ人への手紙 2:30; 詩篇 103:3–4"> 実際、彼は死ぬほどの病気にかかりました。しかし神は彼をあわれんでくださいました。彼だけでなく私をもあわれみ、私が悲しみに悲しみを重ねずにすむようにしてくださいました。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネ 16:22; テモテへの第二の手紙 1:4; ピリピ人への手紙 2:26–27"> そこで私は、なおさら急いで彼を遣わしました。あなたがたが彼に再会して喜び、私も憂いが軽くなるためです。</span>
<span className="v" id="v29" data-v="29" data-xref="テサロニケ人への手紙第一 5:12; コリント人への第一の手紙 16:18; テモテへの手紙第一 5:17"> ですから、大きな喜びをもって主にあって彼を迎え、このような人たちを尊びなさい。</span>
<span className="v" id="v30" data-v="30" data-xref="コリント人への第一の手紙 16:17; 使徒の働き 20:24; ピリピ人への手紙 4:10"> 彼はキリストの働きのために死ぬところまで行き、あなたがたに代わって私に仕え、その不足を補うために、いのちを危険にさらしたからです。</span>
</div>

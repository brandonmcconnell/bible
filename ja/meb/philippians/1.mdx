<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第二の手紙 1:1; 使徒の働き 16:12–15; ローマ人への手紙 1:1"> キリスト・イエス<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「キリスト」は「油を注がれた者」という意味である。">a</a></sup>のしもべであるパウロとテモテから、ピリピにいるキリスト・イエスにあるすべての聖徒たち、ならびに監督者たち<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または、管理者たち、あるいは司教たち">b</a></sup>と奉仕者たち<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="または、執事たち">c</a></sup>へ。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 1:7; コリント人への第二の手紙 1:2; ペテロの手紙第一 1:2"> 私たちの父なる神と主イエス・キリストから、恵みと平安があなたがたにありますように。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="コリント人への第一の手紙 1:4; テサロニケ人への手紙第一 1:2–3; フィレモンへの手紙 1:4–5"> 私は、あなたがたを思うたびに、私の神に感謝しています。</span>
<span className="v" id="v4" data-v="4" data-xref="テサロニケ人への手紙第一 1:2; ローマ人への手紙 1:9; ヨハネの手紙第二 1:4"> あなたがたすべてのために祈るたび、いつも喜びをもって祈っています。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 4:14–15; ピリピ人への手紙 1:7; ヘブル人への手紙 3:14"> それは、あなたがたが最初の日から今日まで、福音の働きにあずかって<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="「あずかる」と訳された言葉（κοινωνίᾳ）には、「交わり」や「分かち合い」という意味もある。">d</a></sup>きたからです。</span>
<span className="v" id="v6" data-v="6" data-xref="テサロニケ人への手紙第一 5:23–24; ピリピ人への手紙 2:13; エペソ人への手紙 4:12"> あなたがたのうちに良い働きを始めてくださった方は、キリスト・イエスの日までに、それを完成してくださると確信しています。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第二の手紙 7:3; ピリピ人への手紙 1:5; コロサイ人への手紙 4:18"> あなたがたすべてについて、このように考えるのは当然です。私はあなたがたを心に留めているからです。私が鎖につながれている時も、福音を弁明し、確証している時も、あなたがたは皆、私とともに恵みにあずかっています。</span>
<span className="v" id="v8" data-v="8" data-xref="ピリピ人への手紙 4:1; ローマ人への手紙 1:9; テモテへの第二の手紙 1:4"> 私がキリスト・イエスの深い愛情をもって、あなたがたすべてをどれほど慕っているか、神が証人です。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への手紙第一 3:12; コロサイ人への手紙 1:9; ペテロの第二の手紙 1:5–6"> 私はこう祈っています。あなたがたの愛が、知識とあらゆる識別力を伴って、ますます豊かになり、</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 12:2; テサロニケ人への手紙第一 3:13; テサロニケ人への手紙第一 5:23"> 何が最も優れているかを見分けられるように。また、キリストの日まで純真で、つまずきのない者となり、</span>
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 12:11; ヨハネ 15:8; ヨハネ 15:4–5"> イエス・キリストによる義の実に満たされて、神の栄光と賛美を現すように。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="テモテへの第二の手紙 2:9; ローマ人への手紙 8:28; 使徒の働き 11:19–21"> 兄弟たち、<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="ここや、文脈上可能な箇所で「兄弟たち」と訳された言葉は、「兄弟姉妹」または「きょうだいたち」と訳すこともできる。">e</a></sup>私の身に起こったことが、かえって福音の前進に役立ったと知ってほしいのです。</span>
<span className="v" id="v13" data-v="13" data-xref="テモテへの第二の手紙 2:9; エペソ人への手紙 3:1; ピリピ人への手紙 1:7"> 私がキリストのために鎖につながれていることは、宮廷の衛兵<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="または、親衛隊">f</a></sup>全体をはじめ、ほかのすべての人に明らかになりました。</span>
<span className="v" id="v14" data-v="14" data-xref="エペソ人への手紙 6:19–20; テサロニケ人への手紙第一 2:2; ルカ 1:74"> また、主にある兄弟たちの多くは、私が鎖につながれていることによって主への確信を深め、恐れることなく神の言葉を語る勇気を、ますます得るようになりました。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 16:17–18; ピリピ人への手紙 2:3; コリント人への第二の手紙 11:13"> ある人たちはねたみや争いからキリストを宣べ伝え、ほかの人たちは善意から宣べ伝えています。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への第二の手紙 2:17; コリント人への第二の手紙 4:1–2; 詩篇 69:26"> 前者は、私の鎖に苦しみを加えようと考え、利己的な野心から、純粋でない動機でキリストを宣べ伝えています。</span>
<span className="v" id="v17" data-v="17" data-xref="テモテへの第二の手紙 1:11–12; ピリピ人への手紙 2:3; ピリピ人への手紙 1:7"> 後者は、私が福音を弁明するために立てられていると知り、愛から宣べ伝えています。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ルカ 9:50; マルコ 9:38–40; コリント人への第一の手紙 15:11"> それなら、どうだというのでしょう。見せかけであれ真実であれ、どのような仕方であっても、キリストが宣べ伝えられています。私はそのことを喜んでいます。いや、これからも喜びます。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 8:28; 使徒の働き 16:7; コリント人への第二の手紙 1:11"> あなたがたの祈りと、イエス・キリストの霊の助けによって、このことが私の救いに至ると知っているからです。</span>
<span className="v" id="v20" data-v="20" data-xref="ペテロの手紙第一 4:16; コリント人への第一の手紙 6:20; イザヤ書 54:4"> 私が切に待ち望み、希望しているのは、何一つ恥じることなく、いつものように今も大胆に、生きるにしても死ぬにしても、私の体を通してキリストがあがめられることです。</span>
<span className="v" id="v21" data-v="21" data-xref="ガラテヤ人への手紙 2:20; コリント人への第二の手紙 5:8; コリント人への第二の手紙 5:1"> 私にとって、生きることはキリストであり、死ぬことは益です。</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの手紙第一 4:2; ガラテヤ人への手紙 2:20; ピリピ人への手紙 1:24"> しかし、肉体をもって生きることが実りある働きとなるなら、どちらを選ぶべきか、私には分かりません。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への第二の手紙 5:8; 詩篇 17:15; ヨハネの黙示録 14:13"> 私はこの二つの間で板挟みになっています。世を去ってキリストとともにいたいと願っています。そのほうが、はるかに良いのです。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネ 16:7; ピリピ人への手紙 1:22; ピリピ人への手紙 1:25–26"> けれども、肉体にとどまることは、あなたがたのためにいっそう必要です。</span>
<span className="v" id="v25" data-v="25" data-xref="ピリピ人への手紙 2:24; コリント人への第二の手紙 1:24; エペソ人への手紙 4:11–13"> こう確信しているので、私はとどまり、あなたがたの信仰の進歩と喜びのために、あなたがたすべてとともにいることになると知っています。</span>
<span className="v" id="v26" data-v="26" data-xref="コリント人への第二の手紙 1:14; コリント人への第二の手紙 5:12; ピリピ人への手紙 3:3"> そうすれば、私が再びあなたがたのもとに行くことによって、私のことでキリスト・イエスにあるあなたがたの誇り<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="または、喜び">g</a></sup>がますます大きくなるでしょう。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="エペソ人への手紙 4:1; コリント人への第一の手紙 16:13–14; コリント人への第一の手紙 1:10"> ただ、キリストの福音にふさわしく歩みなさい。そうすれば、私が行ってあなたがたに会うにしても、離れているにしても、あなたがたが一つの霊にあって堅く立ち、心を一つにして福音の信仰のためにともに戦っている、と聞くことができます。</span>
<span className="v" id="v28" data-v="28" data-xref="テモテへの第二の手紙 1:7–8; テサロニケ人への第二の手紙 1:5–6; マタイ 10:28"> どんなことがあっても、敵対する者たちにおびえてはなりません。そのことは、彼らには滅びのしるし、あなたがたには救いのしるしであり、しかも神から出たものです。</span>
<span className="v" id="v29" data-v="29" data-xref="ヤコブの手紙 1:2; ペテロの手紙第一 4:13; 使徒の働き 5:41"> あなたがたはキリストのために、キリストを信じることだけでなく、キリストのために苦しむことも恵みとして与えられたからです。</span>
<span className="v" id="v30" data-v="30" data-xref="テサロニケ人への手紙第一 2:2; 使徒の働き 16:19–40; テモテへの第二の手紙 4:7"> あなたがたは、かつて私のうちに見、今も私について聞いているのと同じ戦いをしています。</span>
</div>

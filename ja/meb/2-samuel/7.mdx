<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 16:7; ルカ 1:74–75; 列王記第一 5:4"> 王が自分の家に住み、主が周囲のすべての敵から彼を休ませられたとき、</span>
<span className="v" id="v2" data-v="2" data-xref="歴代誌上 16:1; サムエル記第二 5:11; ハガイ書 1:4"> 王は預言者ナタンに言った。「わたしは杉の家に住んでいるが、神の箱は幕の内にある。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="歴代誌上 22:7; 列王記第一 8:17–18; 列王記第二 4:27"> ナタンは王に言った。「行って、あなたの心にあることをすべて行いなさい。主があなたとともにおられるからです。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="歴代誌上 17:3; 民数記 12:6; アモス書 3:7"> その夜、主のことばがナタンに臨んで言った。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代誌上 23:3–32; 列王記第一 5:3–4; 列王記第一 8:16–19"> 「行って、わたしのしもべダビデに言え。『主はこう言われる。「わたしが住むための家を、あなたが建てるというのか。</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第一 8:16; ヨシュア記 18:1; 出エジプト記 40:18–19"> わたしはイスラエルの民をエジプトから導き上げた日から今日に至るまで、家に住んだことはなく、天幕や幕屋の中を移動してきた。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌上 17:6; サムエル記第二 5:2; レビ記 26:11–12"> わたしがイスラエルのすべての民とともに歩んできたすべての場所で、わたしの民イスラエルの牧者となるよう命じたイスラエルの部族のだれかに、『なぜわたしのために杉の家を建てなかったのか』と、ひと言でも言ったことがあるだろうか。」』</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 78:70–71; サムエル記第二 6:21; サムエル記第二 12:7"> 今、わたしのしもべダビデにこう言え。『万軍の主はこう言われる。「わたしはあなたを羊の囲いから、羊の群れの後ろから取って、わたしの民イスラエルの上の君主とした。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記第二 5:10; 歴代誌上 17:8; サムエル記第一 18:14"> あなたがどこへ行くにも、わたしはあなたとともにおり、あなたの前からすべての敵を断ち切った。わたしは地上の偉大な者たちの名のような、大いなる名をあなたに与える。</span>
<span className="v" id="v10" data-v="10" data-xref="アモス書 9:15; 歴代誌上 17:9; エレミヤ書 24:6"> わたしはわたしの民イスラエルのために一つの場所を定め、彼らを植え付ける。彼らは自分たちの場所に住み、もはや動かされることはない。悪しき者たちが、初めのころのように、またわたしが民イスラエルの上に士師たちを立てた時代のように、彼らを苦しめることはもはやない。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記第二 7:27; サムエル記第二 7:1; 歴代誌上 17:10"> わたしはあなたをすべての敵から休ませる。さらに主はあなたに告げる。主があなたのために一つの家を建てると。</span>
<span className="v" id="v12" data-v="12" data-xref="列王記第一 8:20; 使徒の働き 2:30; 使徒の働き 13:36"> あなたの日々が満ち、あなたが父祖たちとともに眠りにつくとき、わたしはあなたから生まれる子孫を、あなたの後に立て、彼の王国を確立する。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカ 1:31–33; 列王記第一 8:19; サムエル記第二 7:16"> 彼はわたしの名のために家を建て、わたしは彼の王国の王座をとこしえに確立する。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 1:5; ヨハネの黙示録 3:19; 歴代誌上 17:13"> わたしは彼の父となり、彼はわたしの息子となる。彼が不義を犯すなら、わたしは人の杖と人の子らの鞭をもって彼を懲らしめる。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記第一 15:23; サムエル記第一 15:28; 詩篇 89:28"> しかし、わたしの慈しみは彼から離れ去ることはない。わたしがあなたの前から退けたサウルから、それを取り去ったようにはならない。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカ 1:32–33; 詩篇 89:36–37; サムエル記第二 7:13"> あなたの家とあなたの王国は、あなたの前にとこしえに確かなものとされる。あなたの王座はとこしえに確立される。」』」</span>
<span className="v" id="v17" data-v="17" data-xref="歴代誌上 17:15; 使徒の働き 20:27; コリント人への第一の手紙 15:3"> ナタンはこれらのすべての言葉を、またこのすべての幻のとおりに、ダビデに語った。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="詩篇 8:4; 歴代誌上 17:16; サムエル記第一 18:18"> そこでダビデ王は中に入って主の御前に座り、こう言った。「主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「主」と訳された言葉は「アドナイ」である。">a</a></sup>なる神よ。わたしは何者でしょう。わたしの家が何だというので、あなたはここまで導いてくださったのでしょうか。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 55:8–9; 歴代誌上 17:17; 詩篇 36:7"> 主なる神よ、これはあなたの御目にはまだ小さなことでした。あなたはしもべの家について、はるか先のことまで語ってくださいました。主なる神よ、しかもあなたはこれを人への定めとして語られました。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネ 21:17; サムエル記第一 16:7; 詩篇 139:1"> ダビデはこれ以上、あなたに何を言えるでしょうか。主なる神よ、あなたはあなたのしもべをご存じだからです。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 115:1; 詩篇 138:2; エペソ人への手紙 1:9"> あなたの言葉のゆえに、またあなた自身の御心にしたがって、あなたはあなたのしもべに知らせるために、このすべての偉大なことを行われました。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 86:10; 出エジプト記 15:11; 詩篇 86:8"> それゆえ、主なる神よ、あなたは大いなる方です。わたしたちの耳で聞いたすべてのことによれば、あなたのような方はほかになく、あなたのほかに神はいないからです。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 9:26; 申命記 10:21; 申命記 15:15"> あなたがエジプトから贖い出してご自分の民とされたイスラエル、この地上の一つの国民のような者が、ほかにあるでしょうか。あなたはご自身のために名を上げ、彼らのために偉大なことを行い、その地に恐るべきみわざを示されました。あなたがエジプトから、国々とその神々のもとから贖い出された民の前で、これを行われたのです。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 26:18; ペテロの手紙第一 2:10; 創世記 17:7"> あなたはご自分の民イスラエルを、とこしえにあなたの民として確立されました。そして主よ、あなたが彼らの神となられました。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="詩篇 119:49; エゼキエル書 36:37; 創世記 32:12"> 今、主なる神よ、あなたがしもべとその家について語られた言葉を、とこしえに確かなものとし、あなたが語られたとおりに行ってください。</span>
<span className="v" id="v26" data-v="26" data-xref="歴代誌上 17:23–24; 詩篇 72:18–19; マタイ 6:9"> そうして、『万軍の主はイスラエルを治める神である』と言われて、あなたの御名がとこしえにあがめられますように。そして、あなたのしもべダビデの家が、あなたの御前に確立されますように。</span>
<span className="v" id="v27" data-v="27" data-xref="歴代誌上 17:25–26; 詩篇 10:17; ルツ記 4:4"> 万軍の主、イスラエルの神であるあなたは、あなたのしもべに『わたしがあなたのために一つの家を建てる』と言って啓示されました。それゆえ、あなたのしもべはこの祈りをあなたにささげる勇気を得たのです。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヨハネ 17:17; 出エジプト記 34:6; 民数記 23:19"> 今、主なる神よ、あなたこそ神であり、あなたの言葉は真理です。そして、あなたはこの良いことをしもべに約束してくださいました。</span>
<span className="v" id="v29" data-v="29" data-xref="民数記 6:24–26; 歴代誌上 17:27; 詩篇 115:12–15"> ですから今、あなたのしもべの家を祝福し、それがあなたの御前にとこしえに続くようにしてください。主なる神よ、あなたがそう語られたからです。あなたの祝福によって、あなたのしもべの家がとこしえに祝福されますように。」</span>
</div>
</div>

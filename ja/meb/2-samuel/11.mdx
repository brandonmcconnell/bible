<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌上 20:1; 列王記第一 20:26; 列王記第一 20:22"> 年が巡り、王たちが出陣する時期になると、ダビデはヨアブとその部下たち、および全イスラエルを遣わした。彼らはアンモン人を打ち破り、ラバを包囲した。しかしダビデはエルサレムにとどまっていた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 5:28; 詩篇 119:37; ヨブ記 31:1"> 夕暮れ時、ダビデは寝台から起き上がり、王の家の屋上を歩いていた。屋上から一人の女が水浴びをしているのが見えた。その女は非常に美しかった。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記第二 23:39; 歴代誌上 3:5; ヤコブの手紙 1:14–15"> ダビデは人を遣わして、その女について尋ねさせた。ある者が、「あれはエリアムの娘で、ヘテ人ウリヤの妻バテ・シェバではありませんか」と言った。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 18:19; ヤコブの手紙 1:14–15; 詩篇 51:1–19"> ダビデは使者たちを遣わし、彼女を連れて来た。彼女が彼のもとに来ると、彼は彼女と寝た（彼女は汚れから身をきよめていたからである）。その後、彼女は自分の家に帰った。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 22:22; 箴言 6:34"> 女は身ごもったので、人を遣わしてダビデに告げて、「わたしは身ごもりました」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="箴言 28:13; 創世記 4:7; サムエル記第一 15:30"> ダビデはヨアブに、「ヘテ人ウリヤをわたしのもとに遣わしなさい」と言って人を遣わした。そこでヨアブはウリヤをダビデのもとに遣わした。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 37:14; サムエル記第一 17:22; 創世記 29:6"> ウリヤが彼のもとに来たとき、ダビデはヨアブの様子や民の様子、そして戦いの状況がどうであるかを尋ねた。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 18:4; 創世記 43:34; イザヤ書 29:15"> ダビデはウリヤに言った。「自分の家に下って行き、足を洗いなさい。」ウリヤが王の家から出て行くと、王からの贈り物が彼の後から届けられた。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 21:30; ヨブ記 5:12–14"> しかしウリヤは、自分の家に下って行かず、主君のすべてのしもべたちとともに王の家の入り口で寝た。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 人々がダビデに、「ウリヤは自分の家に下って行きませんでした」と告げたとき、ダビデはウリヤに言った。「あなたは旅から帰って来たのではないか。なぜ自分の家に下って行かなかったのか。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="サムエル記第二 7:2; サムエル記第二 20:6; サムエル記第二 7:6"> ウリヤはダビデに言った。「箱も、イスラエルも、ユダも天幕にとどまり、わたしの主君ヨアブも、わたしの主君のしもべたちも野に宿営しています。それなのに、わたしだけが自分の家に行って食べたり飲んだりし、妻と寝ることができるでしょうか。あなたの命にかけて、わたしはそのようなことはいたしません。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 2:37; エレミヤ書 2:22–23"> ダビデはウリヤに言った。「今日もここにとどまりなさい。明日、あなたを送り出そう。」こうしてウリヤは、その日と次の日、エルサレムにとどまった。</span>
<span className="v" id="v13" data-v="13" data-xref="ハバクク書 2:15; 創世記 19:32–35; 箴言 20:1"> ダビデが彼を招いたので、彼はダビデの前で飲み食いし、ダビデは彼を酔わせた。しかし夕暮れになると、彼は出て行って主君のしもべたちとともに寝台で寝て、自分の家には下って行かなかった。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 17:9; 列王記第一 21:8–10; 詩篇 19:13"> 朝になると、ダビデはヨアブに手紙を書き、ウリヤの手に託して送った。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記第二 12:9; 詩篇 51:4; エレミヤ書 20:13"> 彼は手紙にこう書いた。「ウリヤを最も激しい戦いの最前線に出し、彼が打たれて死ぬように、彼から退け。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="箴言 29:12; サムエル記第一 22:17–19; 使徒の働き 5:29"> ヨアブは町を包囲して見張っていたとき、勇敢な者たちがいると知っていた場所にウリヤを配置した。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記第二 12:9; 詩篇 51:14"> 町の者たちが出て来てヨアブと戦った。ダビデのしもべである民のうちの数人が倒れ、ヘテ人ウリヤもまた死んだ。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> そこでヨアブは人を遣わし、戦いに関するすべての事をダビデに告げさせた。</span>
<span className="v" id="v19" data-v="19"> 彼は使者に命じて言った。「戦いに関するすべての事を王に話し終えたとき、</span>
<span className="v" id="v20" data-v="20"> もし王の怒りが燃え上がり、あなたにこう言ったなら。『なぜ戦うために、それほど町に近づいたのか。彼らが城壁の上から射かけてくることを知らなかったのか。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 7:1; 士師記 9:50–54; サムエル記第二 3:27"> エルベシェテの息子アビメレクを打ったのは誰か。一人の女が城壁の上から彼の上にひき臼の上石を投げ落とし、彼がテベツで死んだのではなかったか。なぜそれほど城壁に近づいたのか。』そのとき、あなたは、『あなたのしもべであるヘテ人ウリヤも死にました』と言いなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> そこで使者は行き、ダビデのもとに来て、ヨアブが彼を遣わして伝えさせたすべてのことを報告した。</span>
<span className="v" id="v23" data-v="23"> 使者はダビデに言った。「あの者たちはわれわれに対して優勢になり、野にいるわれわれのところへ出て来ました。そこでわれわれは門の入り口まで彼らを追い詰めました。</span>
<span className="v" id="v24" data-v="24"> 射手たちが城壁の上からあなたのしもべたちに向かって射かけ、王のしもべたちのうち数人が死にました。あなたのしもべであるヘテ人ウリヤもまた死にました。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="サムエル記第二 12:26; ヨシュア記 7:8–9; 伝道者の書 9:1–3"> するとダビデは使者に言った。「あなたはヨアブにこう言いなさい。『この事を気に病むな。剣はこの者もあの者も同じように食い尽くす。町に対する戦いをさらに強め、それを打ち倒せ。』彼を励ましなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="サムエル記第二 14:2; 創世記 27:41; サムエル記第二 3:31"> ウリヤの妻は、夫ウリヤが死んだことを聞くと、夫のために泣き悲しんだ。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 51:4–5; サムエル記第二 12:9; 申命記 22:29"> 喪の期間が過ぎると、ダビデは人を遣わして彼女を自分の家に引き取った。彼女は彼の妻となり、彼に男の子を産んだ。しかし、ダビデが行ったこの事は、主の御目には悪であった。</span>
</div>
</div>

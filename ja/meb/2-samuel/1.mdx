</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ヨブ記 1:15–19; 列王記第二 5:25"> ダビデが彼に、「あなたはどこから来たのか」と言うと、<br />彼は、「イスラエルの陣営から逃れて来ました」と答えた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="サムエル記第一 4:16; サムエル記第一 31:1–6; 歴代誌上 10:1–6"> ダビデは彼に言った。「どうなったのか。どうか、わたしに告げなさい。」<br />彼は答えた。「民は戦いから逃げ去り、民の多くが倒れて死にました。サウルとその息子ヨナタンも死にました。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="箴言 25:2; 箴言 14:15"> ダビデは、その知らせを告げた若者に言った。「サウルとその息子ヨナタンが死んだと、どうして分かるのか。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="サムエル記第一 28:4; サムエル記第二 1:21; 歴代誌上 10:4–6"> その知らせを告げた若者は言った。「わたしがたまたまギルボア山にいたとき、サウルは自分の槍に寄りかかり、戦車と騎兵が彼に迫っていました。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記第一 22:12; サムエル記第二 9:6; 士師記 9:54"> 彼が後ろを振り向いてわたしを見つけ、わたしを呼びました。わたしは『ここにおります』と答えました。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記第一 30:17; サムエル記第一 30:13; サムエル記第一 30:1"> 彼が『あなたは何者か』と言うので、わたしは『アマレク人です』と答えました。</span>
<span className="v" id="v9" data-v="9"> すると彼はわたしに、『どうか、わたしのそばに立って、わたしを殺してくれ。命はまだあるが、苦痛がわたしを捕らえているからだ』と言いました。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイ 7:2; 士師記 9:54; 列王記第二 11:12"> そこでわたしは彼のそばに立ち、彼を殺しました。彼が倒れた後は生き延びられないと確信したからです。わたしは彼の頭にあった王冠と、腕にあった腕輪を取り、ここに、わが君のもとに持って来ました。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="サムエル記第二 13:31; 創世記 37:29; サムエル記第二 3:31"> するとダビデは自分の服をつかんで引き裂いた。彼とともにいたすべての男たちも同じようにした。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 24:17; 詩篇 35:13–14; マタイ 5:44"> 彼らは、サウルとその息子ヨナタンのため、主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="すべて大文字の「主」または「神」はヘブル語のיהוה（ヤハウェ）から来ている。ただし、短い形のיה（ヤハ）から来ていると記されている場合を除く。">a</a></sup>の民のため、そしてイスラエルの家のために、夕暮れまで悼み、泣き、断食した。彼らが剣に倒れたからである。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="サムエル記第二 1:8"> ダビデは、その知らせを告げた若者に言った。「あなたはどこの出身か。」<br />彼は答えた。「わたしは在留外国人の息子、アマレク人です。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="サムエル記第一 26:9; サムエル記第一 31:4; ペテロの第二の手紙 2:10"> ダビデは彼に言った。「なぜあなたは、主に油を注がれた者を滅ぼすために手を伸ばすことを恐れなかったのか。」</span>
<span className="v" id="v15" data-v="15" data-xref="列王記第一 2:34; 士師記 8:20; サムエル記第二 4:10–12"> ダビデは若者の一人を呼んで言った。「近寄って、彼を切り倒せ。」その若者が彼を打つと、彼は死んだ。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイ 27:25; ルカ 19:22; レビ記 20:9"> ダビデは彼に言った。「あなたの血の責任は、あなた自身にある。あなたの口が、『わたしは主に油を注がれた者を殺した』と言って、あなた自身に不利な証言をしたからである。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="歴代誌 第二 35:25; サムエル記第二 1:19; 創世記 50:11"> ダビデは、サウルとその息子ヨナタンについて、この哀歌を歌って悼んだ。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 10:13; 創世記 49:8; 申命記 4:10"> 彼はユダの人々にこの「弓の歌」を教えるよう命じた。それはヤシャルの書に記されている。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記第二 1:27; サムエル記第二 1:25; 申命記 4:7–8"> <span className="pl pl-1">「イスラエルよ、あなたの栄光が高き所で刺し殺された。</span><br /><span className="pl pl-2">ああ、勇士たちは倒れた。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ミカ書 1:10; サムエル記第一 18:6; 士師記 11:34"> <span className="pl pl-1">ガテで告げるな。</span><br /><span className="pl pl-2">アシュケロンの通りで知らせるな。</span><br /><span className="pl pl-1">ペリシテ人の娘たちが喜び、</span><br /><span className="pl pl-2">無割礼の者たちの娘が勝ち誇らないために。</span></span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記第一 31:1; イザヤ書 21:5; サムエル記第一 10:1"> <span className="pl pl-1">ギルボアの山々よ、</span><br /><span className="pl pl-2">おまえたちの上には露も雨も降るな。ささげ物を産する畑もなくなれ。</span><br /><span className="pl pl-2">そこで勇士の盾は汚され、投げ捨てられた。</span><br /><span className="pl pl-2">サウルの盾は、もはや油を塗られることもない。</span></span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記第一 18:4; イザヤ書 34:6–7; サムエル記第一 14:6–14"> <span className="pl pl-1">殺された者の血を浴び、</span><br /><span className="pl pl-2">勇士の脂を貫いても、</span><br /><span className="pl pl-2">ヨナタンの弓は退かず、</span><br /><span className="pl pl-2">サウルの剣はむなしく帰らなかった。</span></span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 4:13; 士師記 14:18; 哀歌 4:19"> <span className="pl pl-1">サウルとヨナタンは、生前には愛され、麗しく、</span><br /><span className="pl pl-2">死にも別たれなかった。</span><br /><span className="pl pl-1">鷲より速く、</span><br /><span className="pl pl-2">獅子より強かった。</span></span>
<span className="v" id="v24" data-v="24" data-xref="ペテロの手紙第一 3:3–5; エレミヤ書 2:32; 士師記 5:30"> <span className="pl pl-1">イスラエルの娘たちよ、サウルのために泣け。</span><br /><span className="pl pl-2">彼はおまえたちに緋の衣をまとわせ、</span><br /><span className="pl pl-2">その衣に金の飾りを添えた。</span></span>
<span className="v" id="v25" data-v="25" data-xref="サムエル記第二 1:19; サムエル記第二 1:27; 士師記 5:18"> <span className="pl pl-1">ああ、勇士たちは戦いのただ中で倒れた。</span><br /><span className="pl pl-2">ヨナタンよ、あなたは高き所で刺し殺された。</span></span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記第一 20:17; サムエル記第一 23:16; サムエル記第一 20:41"> <span className="pl pl-1">わが兄弟ヨナタンよ、わたしはあなたを思って苦しむ。</span><br /><span className="pl pl-2">あなたはわたしにこよなく慕わしかった。</span><br /><span className="pl pl-2">あなたの愛は驚くべきもの、</span><br /><span className="pl pl-2">女の愛にもまさっていた。</span></span>
<span className="v" id="v27" data-v="27" data-xref="サムエル記第二 1:25; サムエル記第二 1:19; エゼキエル書 39:9–10"> <span className="pl pl-1">ああ、勇士たちは倒れ、</span><br /><span className="pl pl-2">戦いの武具は滅び失せた。」</span></span>

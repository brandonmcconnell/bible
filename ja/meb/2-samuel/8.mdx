<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌上 18:1–17; サムエル記第二 7:9; サムエル記第二 21:15–22"> この後、ダビデはペリシテ人を打って彼らを従わせた。そしてダビデは、ペリシテ人の手から、その中心都市の支配権を奪い取った。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 24:17; サムエル記第一 10:27; サムエル記第二 8:6"> 彼はモアブを打ち破り、彼らを地面に寝かせて縄で測った。すなわち、二本の縄で測った者たちを死に渡し、一本の縄いっぱいで測った者たちを生かしておいた。モアブ人はダビデのしもべとなり、貢ぎ物を持って来た。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="サムエル記第一 14:47; サムエル記第二 10:16; サムエル記第二 10:19"> ダビデはまた、レホブの息子であるツォバの王ハダデゼルが、大河のほとりで自らの支配を取り戻そうとしたとき、彼を打ち破った。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨシュア記 11:6; ヨシュア記 11:9; 歴代誌上 18:4"> ダビデは彼から騎兵千七百人、歩兵二万人を奪い取った。ダビデは戦車用の馬の足の筋をすべて切ったが、百台の戦車に足りる馬は残しておいた。</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第一 11:23–25; イザヤ書 7:8; ヨブ記 9:13"> ダマスコのアラム人たちがツォバの王ハダデゼルを助けに来たとき、ダビデはアラム人二万二千人を打った。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記第二 8:14; サムエル記第二 7:9; 詩篇 18:34–46"> それからダビデはダマスコのアラムに守備隊を置いた。アラム人はダビデのしもべとなり、貢ぎ物を持って来た。主はダビデが行くところどこででも、彼に勝利をお与えになった。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌 第二 9:15–16; 列王記第一 14:26–27; 列王記第一 10:16–17"> ダビデはハダデゼルのしもべたちが持っていた金の盾を奪い、それらをエルサレムに持って来た。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代誌上 18:8; 歴代誌上 22:16; エゼキエル書 47:16"> またダビデ王は、ハダデゼルの町々であるベタとベロタイから、非常に多くの青銅を奪い取った。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王記第一 8:65; 歴代誌 第二 8:4; 歴代誌上 18:9"> ハマテの王トイは、ダビデがハダデゼルの全軍勢を打ち破ったことを聞いた。</span>
<span className="v" id="v10" data-v="10" data-xref="サムエル記第一 13:10; 歴代誌上 18:10; 詩篇 129:8"> そこでトイは、息子ヨラムをダビデ王のもとに遣わし、あいさつさせ、祝福させた。ダビデがハダデゼルと戦い、彼を打ち破ったからである。ハダデゼルはトイと何度も戦っていた。ヨラムは銀の器、金の器、青銅の器を持って来た。</span>
<span className="v" id="v11" data-v="11" data-xref="列王記第一 7:51; 歴代誌上 29:2; 歴代誌上 22:14–16"> ダビデ王はこれらをも、彼が従わせたすべての国々から得てささげた銀や金とともに、主にささげた。</span>
<span className="v" id="v12" data-v="12" data-xref="サムエル記第二 10:14; サムエル記第二 8:2; 歴代誌上 18:11"> すなわちアラム、モアブ、アンモン人、ペリシテ人、アマレク、またレホブの息子であるツォバの王ハダデゼルからの戦利品である。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王記第二 14:7; サムエル記第二 7:9; 歴代誌上 18:12"> ダビデが塩の谷でアラム人一万八千人を打って帰って来たとき、彼は名を上げた。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 27:29; 創世記 25:23; サムエル記第二 8:6"> 彼はエドムに守備隊を置き、エドム全土に守備隊を置いた。すべてのエドム人はダビデのしもべとなった。主はダビデが行くところどこででも、彼に勝利をお与えになった。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="アモス書 5:15; 詩篇 89:14; 詩篇 72:2"> ダビデは全イスラエルを治めた。ダビデは自分のすべての民に対して公正と義を行った。</span>
<span className="v" id="v16" data-v="16" data-xref="列王記第一 4:3; 歴代誌上 11:6; サムエル記第二 19:13"> ツェルヤの息子ヨアブが軍の長であり、アヒルデの息子ヨシャファテが記録官であった。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代誌上 6:8; 歴代誌上 18:16; 歴代誌上 24:3–4"> アヒトブの息子ツァドクとアビアタルの息子アヒメレクが祭司であり、セラヤが書記官であった。</span>
<span className="v" id="v18" data-v="18" data-xref="サムエル記第一 30:14; サムエル記第二 20:7; サムエル記第二 20:23"> エホヤダの息子ベナヤはケレテ人とペレテ人の長であり、ダビデの息子たちは高官であった。</span>
</div>
</div>

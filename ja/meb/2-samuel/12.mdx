<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王記第一 20:35–41; 詩篇 51:1–19; サムエル記第二 11:10–17"> 主はナタンをダビデのもとに遣わされた。彼はダビデのところに来て、彼に言った。「ある町に二人の男がいました。一人は富んでおり、もう一人は貧しい者でした。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記第二 15:16; ヨブ記 1:3; サムエル記第二 5:13–16"> 富んでいる男には、非常に多くの羊や牛の群れがいましたが、</span>
<span className="v" id="v3" data-v="3" data-xref="ミカ書 7:5; サムエル記第二 11:3; 箴言 5:18–19"> 貧しい男には、自分で買って育てていた一匹の小さな雌の小羊のほかには、何もありませんでした。その小羊は彼と子どもたちと一緒に育ち、彼の食べ物を分けてもらい、彼の杯から飲み、胸に抱かれて眠り、彼にとって娘のようでした。</span>
<span className="v" id="v4" data-v="4" data-xref="ヤコブの手紙 1:14; サムエル記第二 11:3–4; 創世記 18:2–7"> 一人の旅人が富んでいる男のところにやって来ました。彼は自分のもとに来た旅人のために食事を用意するのに、自分の羊や牛の群れから取ることを惜しみ、その貧しい男の小羊を取って、自分のところに来た男のために調理しました。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 38:24; ローマ人への手紙 2:1; サムエル記第一 26:16"> ダビデの怒りはその男に対して激しく燃え上がり、ナタンに言った。「主は生きておられる。このようなことをした男は死に値する。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 22:1; ルカ 19:8; 箴言 6:31"> 彼はこのようなことを行い、あわれみを持たなかったので、その小羊を四倍にして償わなければならない。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マタイ 14:14; サムエル記第一 16:13; サムエル記第二 22:1"> ナタンはダビデに言った。「あなたがその男です。イスラエルの神、主はこう言われます。『わたしはあなたに油を注いでイスラエルの王とし、サウルの手からあなたを救い出した。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 84:11; ローマ人への手紙 8:32; サムエル記第二 9:7"> わたしはあなたの主君の家をあなたに与え、あなたの主君の妻たちをあなたの胸に与え、イスラエルとユダの家をあなたに与えた。もしそれが少なすぎたのなら、わたしはあなたにさらに多くのものを加えたであろう。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記第一 15:19; 詩篇 139:1–2; サムエル記第一 15:23"> なぜ、あなたは主の言葉を軽んじ、その御目に悪であることを行ったのか。あなたはヘテ人ウリヤを剣で打ち、彼の妻を奪って自分の妻とし、アンモン人の剣で彼を殺した。</span>
<span className="v" id="v10" data-v="10" data-xref="サムエル記第二 18:14–15; マタイ 26:52; ローマ人への手紙 2:4"> あなたがわたしを軽んじ、ヘテ人ウリヤの妻を奪って自分の妻としたので、今や剣はとこしえにあなたの家から離れない。』</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記第二 16:21–22; 申命記 28:30; サムエル記第二 15:10"> 主はこう言われます。『わたしはあなた自身の家から、あなたに対して悪を起こす。わたしはあなたの目の前であなたの妻たちを取り、あなたの隣人に与える。彼はこの太陽の光の中で、あなたの妻たちと寝るであろう。</span>
<span className="v" id="v12" data-v="12" data-xref="サムエル記第二 16:22; サムエル記第二 11:4–15; 伝道者の書 12:14"> あなたはそれを密かに行ったが、わたしはこの事を全イスラエルの前で、そして太陽の前で行う。』」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 51:4; サムエル記第二 24:10; 箴言 28:13"> ダビデはナタンに言った。「わたしは主に対して罪を犯しました。」<br />ナタンはダビデに言った。「主もまた、あなたの罪を取り除かれました。あなたは死ぬことはありません。</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 2:24; イザヤ書 52:5; 詩篇 89:31–33"> しかし、あなたはこの行いによって、主の敵どもに主を冒涜する大きな機会を与えた。それゆえ、あなたに生まれた子は必ず死ぬ。」</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記第一 25:38; 詩篇 104:29; 歴代誌 第二 13:20"> ナタンは自分の家に帰って行った。<br />主は、ウリヤの妻がダビデに産んだ子を打たれたので、その子は重い病気になった。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記第二 13:31; 使徒の働き 9:9; 詩篇 69:10"> それゆえ、ダビデはその子のために神に懇願した。ダビデは断食し、中に入って、夜通し地面に横たわっていた。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記第二 3:35; サムエル記第一 28:23"> 彼の家の長老たちは、彼を地面から起き上がらせようとして彼のそばに立ったが、彼はそうしようとはせず、彼らと一緒にパンを食べることもしなかった。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民数記 20:15"> 七日目に、その子は死んだ。ダビデのしもべたちは、子が死んだことを彼に告げるのを恐れた。彼らはこう言ったからである。「子がまだ生きていたとき、われわれが彼に話しかけても、彼はわれわれの声に耳を傾けなかった。子が死んだと告げたら、彼はどれほど自分を傷つけることだろう。」</span>
<span className="v" id="v19" data-v="19"> しかしダビデは、しもべたちがささやき合っているのを見て、子が死んだことを悟った。ダビデはしもべたちに言った。「子は死んだのか。」<br />彼らは言った。「死にました。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヨブ記 1:20; ルツ記 3:3; 哀歌 3:39–41"> そこでダビデは地面から起き上がり、体を洗い、油を塗り、衣服を着替えた。そして主の家に入って礼拝した。それから自分の家に帰り、彼が求めると、彼らは彼の前にパンを出し、彼は食べた。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第一の手紙 2:15"> すると、しもべたちは彼に言った。「あなたがされたこの事は何ですか。子が生きている間は、あなたはその子のために断食して泣かれましたが、子が死ぬと、あなたは起き上がってパンを食べられました。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 38:1–3; イザヤ書 38:5; ヨナ書 3:9–10"> 彼は言った。「子がまだ生きていた間、わたしが断食して泣いたのは、『もしかすると主がわたしをあわれみ、子を生かしてくださるかもしれない』と思ったからだ。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 37:35; ヨブ記 30:23; ルカ 23:43"> しかし今、子は死んでしまった。なぜわたしは断食しなければならないのか。わたしはあの子を再び連れ戻すことができるだろうか。わたしはあの子のところへ行くが、あの子がわたしのところに戻って来ることはない。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="マタイ 1:6; 歴代誌上 28:5–6; 歴代誌上 22:9–10"> ダビデは妻バテ・シェバを慰め、彼女のところに入って、彼女と寝た。彼女は男の子を産み、彼はその名をソロモンと呼んだ。主は彼を愛され、</span>
<span className="v" id="v25" data-v="25" data-xref="サムエル記第二 7:4; ネヘミヤ記 13:26; 列王記第一 1:11"> 主は預言者ナタンを遣わし、主のゆえに、その子をエディデヤ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「エディデヤ」は「主に愛された者」を意味する。">a</a></sup>と名づけさせた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歴代誌上 20:1–3; 申命記 3:11; サムエル記第二 11:25"> さて、ヨアブはアンモン人のラバと戦い、王の町を攻め取った。</span>
<span className="v" id="v27" data-v="27" data-xref="エゼキエル書 21:20; サムエル記第二 11:1; 申命記 3:11"> ヨアブはダビデに使者たちを遣わして言った。「わたしはラバと戦いました。わたしは水の町を攻め取りました。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネ 7:18"> ですから今、残りの民を集めて町の向かいに陣を敷き、そこを攻め取ってください。そうしなければ、わたしが町を攻め取り、わたしの名で呼ばれることになってしまいます。」</span>
<span className="v" id="v29" data-v="29"> ダビデはすべての民を集め、ラバへ行ってそれと戦い、そこを攻め取った。</span>
<span className="v" id="v30" data-v="30" data-xref="歴代誌上 20:2"> 彼は彼らの王の頭から王冠を奪い取った。その重さは一タラント<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一タラントは約30キログラム、または約66ポンドである。">b</a></sup>の金であり、そこには宝石がはめ込まれていた。それはダビデの頭に置かれた。彼は町から非常に多くの戦利品を持ち出した。</span>
<span className="v" id="v31" data-v="31" data-xref="歴代誌上 20:3; 詩篇 21:8–9; アモス書 1:3"> 彼はその中にいた民を引き出し、彼らをのこぎり、鉄の鶴嘴、鉄の斧を用いる労働に就かせ、れんが窯で働かせた。彼はアンモン人のすべての町々にこのようにした。それからダビデとすべての民はエルサレムに帰った。</span>
</div>

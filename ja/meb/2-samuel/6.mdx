<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="2SA" data-book-slug="2-samuel" data-book-name="サムエル記第二" data-chapter="6" data-verses="23">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌上 13:1–4; 列王記第一 8:1; 歴代誌上 13:6–14"> ダビデは再びイスラエルの精鋭三万人をすべて集めた。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記第一 4:4; サムエル記第一 7:1; 詩篇 80:1"> ダビデは立ち上がり、自分とともにいたすべての民を連れてユダのバアレから出発した。ケルビムの上に座しておられる万軍の主、その御名によって呼ばれる神の箱を、そこから運び上るためであった。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記第一 6:7; 民数記 7:4–9; 民数記 4:5–12"> 彼らは神の箱を新しい車に載せ、丘の上にあるアビナダブの家から運び出した。アビナダブの息子であるウザとアヒオが、その新しい車を御していた。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌上 13:7; サムエル記第一 7:1–2"> 彼らが丘の上にあるアビナダブの家から、神の箱とともにそれを運び出したとき、アヒオは箱の前を歩いていた。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代誌上 13:8; 詩篇 150:3–5; アモス書 5:23"> ダビデとイスラエルの全家は、糸杉の木で作られたあらゆる楽器、竪琴、弦楽器、タンバリン、カスタネット、シンバルを鳴らして、主の御前で演奏していた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歴代誌上 13:9; 民数記 4:15; 民数記 4:19–20"> 彼らがナコンの打ち場に着いたとき、牛がつまずいたので、ウザは神の箱に手を伸ばし、それをつかんだ。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記第一 6:19; 歴代誌上 15:13; 歴代誌上 13:10"> するとウザに対して主の怒りが燃え上がり、神はその過ちのゆえに、その場で彼を打たれた。彼はそこで神の箱の傍らで死んだ。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨナ書 4:1; 歴代誌上 13:11–12; ヨナ書 4:9"> 主がウザを打ち破られたので、ダビデは怒った。そして彼はその場所をペレツ・ウザ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「ペレツ・ウザ」は「ウザに対する打ち破り」を意味する。">a</a></sup>と呼び、今日に至っている。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 119:120; 歴代誌上 13:11–12; 民数記 17:12–13"> その日、ダビデは主を恐れて言った。「どうして主の箱をわたしのところへ迎えられようか。」</span>
<span className="v" id="v10" data-v="10" data-xref="歴代誌上 26:4–8; サムエル記第二 15:19; 歴代誌上 15:18"> そのためダビデは、主の箱をダビデの町にある自分のところへ移そうとはせず、それをガテ人オベデ・エドムの家に運び入れた。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 39:5; 創世記 30:27; 箴言 3:9–10"> 主の箱はガテ人オベデ・エドムの家に三か月とどまった。主はオベデ・エドムとその全家を祝福された。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歴代誌上 15:25–3; 列王記第一 8:1; マタイ 10:42"> 「主は神の箱のゆえに、オベデ・エドムの家と彼に属するすべてのものを祝福された」とダビデ王に告げられた。ダビデは行って、神の箱をオベデ・エドムの家からダビデの町へ、喜びをもって運び上った。</span>
<span className="v" id="v13" data-v="13" data-xref="列王記第一 8:5; 歴代誌上 15:15; 民数記 4:15"> 主の箱を担ぐ者たちが六歩進んだとき、彼は牛と肥えた子牛をいけにえとしてささげた。</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記第一 2:18; 出エジプト記 15:20; 詩篇 150:4"> ダビデは力の限り主の御前で踊った。ダビデは亜麻布のエポデを身に着けていた。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 68:24–27; 歴代誌上 15:28; 歴代誌上 15:25"> こうしてダビデとイスラエルの全家は、歓声を上げ、角笛を吹き鳴らして、主の箱を運び上った。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="コリント人への第一の手紙 2:14; 歴代誌上 15:29; 詩篇 69:7"> 主の箱がダビデの町に入って来たとき、サウルの娘ミカルは窓から見下ろし、ダビデ王が主の御前で跳ねたり踊ったりしているのを見て、心の中で彼をさげすんだ。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代誌上 15:1; 歴代誌 第二 1:4; 列王記第一 8:5"> 彼らは主の箱を運び入れ、ダビデがそのために張った天幕の中の定めの場所に安置した。ダビデは主の御前に全焼のささげ物と和解のいけにえをささげた。</span>
<span className="v" id="v18" data-v="18" data-xref="列王記第一 8:55; 歴代誌上 16:2; 創世記 14:19"> ダビデは全焼のささげ物と和解のいけにえをささげ終えると、万軍の主の御名によって民を祝福した。</span>
<span className="v" id="v19" data-v="19" data-xref="ネヘミヤ記 8:10; 歴代誌 第二 35:7–8; 歴代誌上 16:3"> 彼はすべての民、すなわちイスラエルの全群衆の男女一人ひとりに、パン一切れ、なつめやし、干しぶどうを分け与えた。そして民は皆、それぞれ自分の家に帰って行った。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="サムエル記第二 6:16; サムエル記第二 6:14; 士師記 9:4"> それからダビデは自分の家族を祝福するために戻って来た。サウルの娘ミカルはダビデを出迎えに出て来て言った。「今日のイスラエルの王は、なんとご立派だったことでしょう。ならず者が恥じることもなく自分をさらけ出すように、ご自分の家来たちのはしためたちの目の前で、今日ご自分をさらけ出されるとは。」</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 13:22; 詩篇 89:19–20; サムエル記第一 13:14"> ダビデはミカルに言った。「それは主の御前でのことだ。主はあなたの父よりも、またその全家よりもわたしを選び、主の民イスラエルの君主に任命してくださった。それゆえ、わたしは主の御前で喜び祝う。</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの手紙第一 4:14; ヘブル人への手紙 12:2; イザヤ書 51:7"> わたしはこれよりもさらに身を低くし、自分を卑しい者と見なそう。しかし、あなたが話したそのはしためたちからは、わたしは敬われるだろう。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="マタイ 1:25; イザヤ書 22:14; イザヤ書 4:1"> サウルの娘ミカルには、死ぬ日まで子どもがなかった。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記第一 25:18; サムエル記第二 15:32; サムエル記第二 9:2–13"> ダビデが坂の頂を少し過ぎたとき、メフィボシェテのしもべツィバが、鞍を置いた一対のろばと、その上に二百個のパン、干しぶどうの房百個、夏の果物百個、そして皮袋一つのぶどう酒を載せて、彼を出迎えた。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記第二 17:29; 士師記 10:4; 士師記 5:10"> 王はツィバに言った。「これらは何のためか。」ツィバは言った。「ろばは王の家族が乗るため、パンと夏の果物は若者たちが食べるため、ぶどう酒は荒野で気を失いそうな者が飲むためです。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="サムエル記第二 9:9–10; 詩篇 15:3; サムエル記第二 19:24–30"> 王は言った。「そして、あなたの主人の息子はどこにいるのか。」ツィバは王に言った。「彼はエルサレムにとどまっています。彼は『今日、イスラエルの家はわたしの父の王国をわたしに回復してくれるだろう』と言ったからです。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="箴言 18:13; 箴言 18:17; 箴言 19:2"> そこで王はツィバに言った。「メフィボシェテに属するものはすべてあなたのものだ。」ツィバは言った。「わたしはひれ伏します。わが君、王よ、これからもどうかご好意をお示しください。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="サムエル記第二 3:16; サムエル記第一 17:43; 出エジプト記 22:28"> ダビデ王がバフリムに来たとき、サウルの家の氏族の男が出て来た。その名はゲラの息子シメイといった。彼は呪いの言葉を吐きながら近づいて来た。</span>
<span className="v" id="v6" data-v="6"> 彼はダビデと、ダビデ王のすべてのしもべたちに石を投げつけた。すべての民とすべての勇士たちは、王の右と左にいた。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 13:13; サムエル記第一 25:17; 列王記第一 21:10"> シメイは呪いながら言った。「失せろ、失せろ。血を流す男、ならず者よ。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記第二 1:16; サムエル記第二 3:28–29; 列王記第一 2:32–33"> 主はサウルの家のすべての血をあなたに報いられた。あなたはその代わりとして王となったのだ。主は王国をあなたの息子アブサロムの手に渡された。あなたは自分の災いに陥った。あなたが血を流す男だからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 22:28; サムエル記第二 9:8; サムエル記第一 24:14"> するとツェルヤの息子アビシャイは王に言った。「なぜこの死んだ犬が、わが君、王を呪うのでしょうか。どうか、わたしを向こうへ行かせて、彼の首をはねさせてください。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="サムエル記第二 19:22; ローマ人への手紙 9:20; ヨハネ 18:11"> 王は言った。「ツェルヤの息子たちよ、わたしがあなたがたと何のかかわりがあるだろうか。彼が呪っているのは、主が彼に『ダビデを呪え』と言われたからだ。それならだれが『なぜあなたはそのようにしたのか』と言えるだろうか。」</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記第二 17:1–4; 創世記 45:5; サムエル記第二 12:11–12"> ダビデはアビシャイとすべてのしもべたちに言った。「実の息子でさえ、わたしの命を狙っている。まして、このベニヤミン人はなおさらだ。彼をそのままにしておき、彼に呪わせよ。主が彼にお命じになったのだから。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 23:5; ヘブル人への手紙 12:10; 詩篇 25:18"> もしかすると、主がわたしの受ける不当な扱いをご覧になり、今日わたしが受けているこの呪いの代わりに、主がわたしに良いことを報いてくださるかもしれない。」</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 23:23; サムエル記第二 16:5–6"> こうしてダビデとその部下たちは道を進んだ。シメイは彼の向かいの山腹を歩きながら呪い続け、彼に向かって石を投げ、ちりを投げつけた。</span>
<span className="v" id="v14" data-v="14"> 王と彼とともにいたすべての民は疲れ果てて着き、そこで息を休めた。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="サムエル記第二 15:37; サムエル記第二 15:12"> アブサロムとすべての民、イスラエルの男たちはエルサレムに到着し、アヒトフェルも彼とともにいた。</span>
<span className="v" id="v16" data-v="16" data-xref="列王記第二 11:12; サムエル記第一 10:24; 列王記第一 1:25"> ダビデの友人であるアルキ人フシャイがアブサロムのところに来たとき、フシャイはアブサロムに言った。「王万歳。王万歳。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="サムエル記第二 19:25; サムエル記第二 15:32–37; 申命記 32:6"> アブサロムはフシャイに言った。「これがあなたの友人への慈しみなのか。なぜあなたは友人とともにいかなかったのか。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="サムエル記第一 16:13; サムエル記第二 5:1–3"> フシャイはアブサロムに言った。「いいえ、主と、この民と、すべてのイスラエルの男たちが選んだ方、わたしはその方のものとなり、その方とともにとどまります。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記第二 15:34; 詩篇 55:21; サムエル記第一 28:2"> さらに、わたしはだれに仕えるべきでしょうか。その息子さんの御前で仕えるべきではないでしょうか。わたしがあなたのお父上の御前で仕えたように、あなたの御前でもそのようにいたします。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 8:10; 詩篇 37:12–13; イザヤ書 29:15"> それからアブサロムはアヒトフェルに言った。「われわれは何をすべきか、あなたの助言を与えよ。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="サムエル記第二 20:3; サムエル記第二 15:16; ゼカリヤ書 8:13"> アヒトフェルはアブサロムに言った。「あなたの父が家を守らせるために残した、彼のそばめたちのところに入りなさい。そうすれば、全イスラエルはあなたが父に忌み嫌われていることを聞くでしょう。そして、あなたとともにいるすべての者の手は強くなるでしょう。」</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記第二 12:11–12; サムエル記第二 15:16; サムエル記第二 20:3"> そこで人々は、家の屋上にアブサロムのために天幕を張り、アブサロムは全イスラエルの目の前で父のそばめたちのところに入った。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記第二 15:12; サムエル記第二 17:14; サムエル記第二 17:23"> その当時にアヒトフェルが与えた助言は、人が神の託宣を伺うかのようであった。アヒトフェルのすべての助言は、ダビデにとってもアブサロムにとってもそのようであった。</span>
</div>
</div>

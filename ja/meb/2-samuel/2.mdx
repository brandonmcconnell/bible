<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記第一 30:31; サムエル記第一 23:4; 創世記 32:2"> この後、ダビデは主に伺って言った。「ユダの町々のどれかに上って行くべきでしょうか。」主は彼に言われた。「上って行きなさい。」ダビデは言った。「どこへ上って行くべきでしょうか。」主は言われた。「ヘブロンへ。」</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記第一 25:42–43; サムエル記第一 30:5; ルカ 22:28–29"> そこでダビデはそこへ上って行った。彼の二人の妻、エズレル人アヒノアムと、カルメル人ナバルの妻であったアビガイルも一緒であった。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記第一 30:1; 歴代誌上 12:1–7; サムエル記第一 27:2–3"> ダビデは自分とともにいた部下たちも、それぞれの家族とともに連れ上った。彼らはヘブロンの町々に住んだ。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記第二 5:5; サムエル記第一 31:11–13; サムエル記第二 5:3"> ユダの人々が来て、そこでダビデに油を注ぎ、ユダの家の王とした。人々はダビデに、「サウルを葬ったのはヤベシュ・ギレアデの人々です」と告げた。</span>
<span className="v" id="v5" data-v="5" data-xref="サムエル記第一 23:21; 詩篇 115:15; ルツ記 2:20"> ダビデはヤベシュ・ギレアデの人々に使者を遣わして言った。「あなたがたは、自分たちの主君サウルにこの慈しみを示し、彼を葬りました。あなたがたが主によって祝福されますように。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 14:22; 出エジプト記 34:6; マタイ 5:44"> 今、主があなたがたに慈しみと真実を示してくださいますように。あなたがたがこのことを行ったので、わたしもまた、この慈しみに報います。</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 6:10; サムエル記第二 10:12; 創世記 15:1"> だから今、心を強くし、勇気を出しなさい。あなたがたの主君サウルは死に、ユダの家はわたしに油を注いで彼らの王としたからです。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="サムエル記第一 14:50; 創世記 32:2; サムエル記第二 3:7–8"> さて、サウルの軍の長であるネルの息子アブネルは、サウルの息子イシュボシェテを連れてマハナイムへ渡っていた。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 19:18; ヨシュア記 13:8–11; 民数記 1:40"> 彼はイシュボシェテを、ギレアデ、アシュル人、エズレル、エフライム、ベニヤミン、そして全イスラエルの王とした。</span>
<span className="v" id="v10" data-v="10"> サウルの息子イシュボシェテがイスラエルを治め始めたとき、彼は四十歳で、二年間統治した。しかし、ユダの家はダビデに従った。</span>
<span className="v" id="v11" data-v="11" data-xref="列王記第一 2:11; サムエル記第二 5:4–5; 歴代誌上 3:4"> ダビデがヘブロンでユダの家を治めた期間は、七年六か月であった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 18:25; ヨシュア記 10:2; ヨシュア記 9:3"> ネルの息子アブネルと、サウルの息子イシュボシェテの家来たちは、マハナイムからギベオンへ出て行った。</span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記第二 8:16; 歴代誌上 2:16; サムエル記第二 20:23"> ツェルヤの息子ヨアブとダビデの家来たちも出て行き、ギベオンの池のそばで彼らと出会った。一方は池のこちら側に、他方は池の向こう側に座った。</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記第二 2:17; 箴言 10:23; 箴言 17:14"> アブネルはヨアブに言った。「若者たちを立たせ、われわれの前で戦わせてみよう。」ヨアブは言った。「立たせよう。」</span>
<span className="v" id="v15" data-v="15"> そこで双方から十二人ずつが進み出た。ベニヤミンとサウルの息子イシュボシェテの側から十二人、ダビデの家来たちから十二人であった。</span>
<span className="v" id="v16" data-v="16"> 彼らはそれぞれ相手の頭をつかみ、剣を相手のわき腹に突き刺したので、ともに倒れた。それゆえ、ギベオンにあるその場所はヘルカテ・ハツリム<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「ヘルカテ・ハツリム」は「短剣の野」を意味する。">a</a></sup>と呼ばれた。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記第二 3:1"> その日の戦いは非常に激しく、アブネルとイスラエル勢は、ダビデの家来たちに打ち負かされた。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歴代誌上 12:8; ハバクク書 3:19; 雅歌 8:14"> そこにはツェルヤの三人の息子、ヨアブ、アビシャイ、アサエルがいた。アサエルは野のガゼルのように足が速かった。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記第二 2:21; ヨシュア記 1:7; 箴言 4:27"> アサエルは右にも左にもそれず、アブネルを追い続けた。</span>
<span className="v" id="v20" data-v="20"> するとアブネルは後ろを振り向いて言った。「それはあなたか、アサエル。」彼は答えた。「わたしです。」</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 14:19"> アブネルは彼に言った。「右か左にそれて、若者の一人に向かい、その武具を奪え。」しかし、アサエルは彼を追うことからそれようとはしなかった。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記第二 3:27; 箴言 29:1; 列王記第二 14:10–12"> アブネルは再びアサエルに言った。「わたしを追うのをやめて、引き返せ。なぜ、わたしがあなたを地面に打ち倒さなければならないのか。そうなれば、どうしてあなたの兄弟ヨアブに顔向けできようか。」</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記第二 3:27; サムエル記第二 4:6; サムエル記第二 5:6"> しかし、彼はそれることを拒んだ。そのため、アブネルは槍の石突きで彼の腹を刺し、槍は背中に突き抜けた。彼はそこで倒れ、その場で死んだ。アサエルが倒れて死んだ場所に来た者は皆、立ち止まった。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> しかし、ヨアブとアビシャイはアブネルを追った。彼らがギベオンの荒野へ向かう道沿いの、ギアの前にあるアンマの丘に来たとき、太陽が沈んだ。</span>
<span className="v" id="v25" data-v="25"> ベニヤミン人はアブネルの後ろに集まって一つの隊となり、丘の頂に立った。</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 46:14; エレミヤ書 46:10; 使徒の働き 7:26"> その時、アブネルはヨアブに呼びかけて言った。「剣はいつまでも食い尽くすのか。最後には苦い結末になることを、あなたは知らないのか。民に、自分たちの兄弟を追うのをやめて戻るよう命じるまで、どれほどかかるのか。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="箴言 17:14; サムエル記第二 2:14; 箴言 15:1"> ヨアブは言った。「神<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「神」と訳されたヘブル語は「אֱלֹהִים」（エロヒム）である。">b</a></sup>は生きておられる。もしあなたが語っていなかったなら、民は朝には去って、それぞれ兄弟を追うことはなかっただろう。」</span>
<span className="v" id="v28" data-v="28"> そこでヨアブは角笛を吹き鳴らした。すると民は皆立ち止まり、もはやイスラエルを追わず、戦うこともしなかった。</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記第二 2:8; 雅歌 2:17"> アブネルとその部下たちはその夜通しアラバを進み、ヨルダン川を渡り、ビトロン全域を通ってマハナイムに着いた。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> ヨアブはアブネルを追うことから戻った。彼が民をすべて集めると、ダビデの部下十九人とアサエルが欠けていた。</span>
<span className="v" id="v31" data-v="31" data-xref="サムエル記第二 3:1; 列王記第一 20:11"> しかし、ダビデの家来たちはベニヤミン人とアブネルの部下たちを打ち、三百六十人が死んだ。</span>
<span className="v" id="v32" data-v="32" data-xref="歴代誌上 2:13–16; サムエル記第一 17:58; 歴代誌 第二 21:1"> 彼らはアサエルを引き取り、ベツレヘムにある彼の父の墓に葬った。ヨアブとその部下たちは夜通し歩き、夜明けにヘブロンに着いた。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 59:7–8; 詩篇 109:2–4; 詩篇 3:3–5"> さらに、アヒトフェルはアブサロムに言った。「どうか、わたしに一万二千人の男たちを選ばせてください。わたしは立ち上がり、今夜ダビデを追跡します。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記第二 16:14; 列王記第一 22:31; ゼカリヤ書 13:7"> 彼が疲れて弱っているときに、わたしは彼を襲い、彼を恐れさせます。彼とともにいるすべての民は逃げ去るでしょう。わたしは王だけを打ちます。</span>
<span className="v" id="v3" data-v="3" data-xref="テサロニケ人への手紙第一 5:3; イザヤ書 48:22; イザヤ書 57:21"> そして、すべての民をあなたのもとに連れ戻します。あなたが求めるその一人を倒せば、民は皆あなたのもとに戻り、すべての民は平安になります。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="サムエル記第一 18:20–21; ローマ人への手紙 1:32; 歴代誌 第二 30:4"> この言葉はアブサロムと、イスラエルのすべての長老たちに良いとされた。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="サムエル記第二 15:32–37; サムエル記第二 16:16–19"> そこでアブサロムは言った。「今、アルキ人フシャイも呼びなさい。彼も何と言うか聞いてみよう。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> フシャイがアブサロムのもとに来ると、アブサロムは彼に言った。「アヒトフェルはこのように語った。われわれは彼の言うとおりにすべきか。そうでないなら、話しなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="箴言 31:8"> フシャイはアブサロムに言った。「アヒトフェルが今回与えた助言は良くありません。」</span>
<span className="v" id="v8" data-v="8" data-xref="ホセア書 13:8; サムエル記第一 16:18; ヘブル人への手紙 11:32–34"> フシャイはさらに言った。「あなたは自分の父とその部下たちをご存じです。彼らは勇士であり、野で子を奪われた熊のように気が立っています。あなたの父は戦いの熟練者であり、民と一緒に夜を過ごすことはありません。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記第一 24:3; サムエル記第一 14:14–15; 士師記 20:32–33"> 彼は今、どこかの穴か、あるいはどこか別の場所に隠れています。初めに彼らのうちの何人かが倒れたとき、それを聞く者はだれでも、『アブサロムに従う民の間に殺戮があった』と言うでしょう。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨシュア記 2:9–11; 出エジプト記 15:15; 創世記 49:9"> たとえ獅子の心のような心を持つ勇敢な者であっても、すっかりくじけてしまいます。全イスラエルは、あなたの父が勇士であり、彼とともにいる者たちが勇敢な男たちであることを知っているからです。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 22:17; 士師記 20:1; 詩篇 9:16"> ですから、わたしはこう助言します。ダンからベエルシェバに至るまで、海辺の砂のように数多い全イスラエルをあなたのもとに集め、あなたご自身が戦いに出て行くのです。</span>
<span className="v" id="v12" data-v="12" data-xref="サムエル記第一 23:23; オバデヤ書 1:3; 列王記第一 20:10"> そうして、われわれは彼が見つかるどこかの場所で彼を襲い、露が地を覆うように彼の上に降りかかります。彼も、彼とともにいるすべての男たちも、われわれは一人も残しません。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイ 24:2; ミカ書 1:6"> さらに、もし彼が町に退き込んだなら、全イスラエルはその町に縄をかけ、われわれはそこを川へ引きずり込み、一つの小石さえ残らないようにします。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="サムエル記第二 15:34; コリント人への第一の手紙 1:19–20; 箴言 19:21"> アブサロムとイスラエルのすべての男たちは言った。「アルキ人フシャイの助言は、アヒトフェルの助言よりも良い。」主がアブサロムに災いをもたらすため、アヒトフェルの優れた助言を打ち破ろうと定めておられたからである。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="サムエル記第二 15:35–36"> それからフシャイは、祭司ツァドクとアビアタルに言った。「アヒトフェルはアブサロムとイスラエルの長老たちにこのように助言し、わたしはこのように助言しました。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記第二 15:28; コリント人への第一の手紙 15:54; コリント人への第二の手紙 5:4"> ですから今すぐ人を遣わして、ダビデに告げて言いなさい。『今夜は荒野の浅瀬で夜を過ごしてはなりません。どうしても渡らなければなりません。王と、彼とともにいるすべての民が飲み込まれてしまわないようにするためです。』」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="サムエル記第二 15:36; ヨシュア記 18:16; サムエル記第二 15:27"> さて、ヨナタンとアヒマアツはエン・ロゲルのそばにとどまっていた。はしためが行って彼らに告げ、彼らは行ってダビデ王に告げることになっていた。彼らは町に入るのを見られてはならなかったからである。</span>
<span className="v" id="v18" data-v="18" data-xref="サムエル記第二 3:16; サムエル記第二 16:5; サムエル記第二 19:16"> しかし一人の若者が彼らを見て、アブサロムに告げた。そこで二人は急いで立ち去り、バフリムのある男の家に来た。その男の庭には井戸があり、彼らはそこに下って行った。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 1:19; ヨシュア記 2:4–24"> その女は覆いを取って井戸の口の上に広げ、その上に砕いた穀物を広げたので、だれにも気づかれなかった。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 1:19; ヨシュア記 2:22–23; サムエル記第一 19:12–17"> アブサロムのしもべたちがその家へ女のところに来て、「アヒマアツとヨナタンはどこにいるのか」と言った。<br />女は彼らに言った。「彼らは水の流れを渡って行きました。」<br />彼らは捜したが、見つけることができなかったので、エルサレムに帰った。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="サムエル記第二 17:15–16"> 彼らが去った後、二人は井戸から上がり、行ってダビデ王に告げた。彼らはダビデに言った。「起きて、急いで水を渡ってください。アヒトフェルがあなたに対してこのように助言したからです。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="マタイ 10:16; ヨハネ 18:9; 箴言 27:12"> そこでダビデと、彼とともにいたすべての民は起き上がり、ヨルダン川を渡った。朝の光が射すころには、ヨルダン川を渡っていない者は一人も残っていなかった。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="マタイ 27:5; 列王記第二 20:1; サムエル記第二 15:12"> アヒトフェルは自分の助言が受け入れられなかったのを見ると、自分のろばに鞍を置き、立ち上がって自分の町の家に帰り、家のことを整えた後、首をつって死んだ。そして彼は自分の父の墓に葬られた。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="創世記 32:2; サムエル記第二 2:8; ヨシュア記 13:26"> それからダビデはマハナイムに来た。アブサロムは、彼と、彼とともにいたイスラエルのすべての男たちと一緒にヨルダン川を渡った。</span>
<span className="v" id="v25" data-v="25" data-xref="歴代誌上 2:13; サムエル記第二 19:13; サムエル記第二 20:9–12"> アブサロムはヨアブの代わりにアマサを軍の長とした。さて、アマサはイスラエル人イトラという名の男の息子であり、イトラはナハシュの娘でヨアブの母ツェルヤの姉妹であるアビガイルのところに入った者であった。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨシュア記 17:1; 申命記 3:15; 民数記 32:1–42"> イスラエルとアブサロムはギレアデの地に陣を敷いた。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="列王記第一 2:7; サムエル記第二 10:1–2; サムエル記第二 9:4"> ダビデがマハナイムに来たとき、アンモン人のラバから来たナハシュの息子ショビと、ロ・デバルから来たアミエルの息子マキルと、ロゲリムから来たギレアデ人バルジライが、</span>
<span className="v" id="v28" data-v="28" data-xref="サムエル記第一 25:18; オバデヤ書 1:3; サムエル記第二 16:1–2"> 寝台、鉢、土の器、小麦、大麦、麦粉、炒り麦、豆、レンズ豆、炒り豆、</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記第二 16:2; イザヤ書 21:14; サムエル記第二 16:14"> はちみつ、凝乳、羊、牛乳のチーズを、ダビデと彼とともにいた民が食べるために持って来た。彼らが、「民は荒野で飢え、疲れ、渇いている」と言ったからである。</span>
</div>
</div>

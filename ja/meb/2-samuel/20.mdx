<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王記第一 12:16; 歴代誌 第二 10:16; 申命記 13:13"> そこにたまたま一人のならず者がおり、その名はベニヤミン人ビクリの息子シェバといった。彼は角笛を吹き鳴らして言った。「ダビデには、われわれの分はない。エッサイの息子には、われわれの相続分はない。イスラエルよ、それぞれ自分の天幕へ帰れ！」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ヨハネ 6:66–68; 使徒の働き 11:23; サムエル記第二 19:15"> そこでイスラエルのすべての男たちはダビデに従うのをやめて上り、ビクリの息子シェバに従った。しかしユダの男たちは、ヨルダン川からエルサレムに至るまで、自分たちの王にしっかりとついて行った。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="サムエル記第二 16:21–22; サムエル記第二 15:16; 創世記 40:3"> ダビデはエルサレムの自分の家に来た。王は家を守らせるために残しておいた自分のそばめである十人の女を取り、彼女たちを監禁して養ったが、彼女たちのところには入らなかった。こうして彼女たちは死ぬ日まで閉じ込められ、やもめとして生きた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="サムエル記第二 19:13; サムエル記第二 17:25; 歴代誌上 2:17"> それから王はアマサに言った。「三日以内にユダの男たちをわたしのところに呼び集め、あなた自身もここにいなさい。」</span>
<span className="v" id="v5" data-v="5" data-xref="サムエル記第二 19:13; サムエル記第一 13:8"> そこでアマサはユダの男たちを呼び集めるために出かけて行った。しかし、王が彼に定めた期限よりも遅れた。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記第二 21:17; サムエル記第二 11:11; 列王記第一 1:33"> ダビデはアビシャイに言った。「今やビクリの息子シェバは、アブサロムよりもわれわれに多くの悪を行うだろう。あなたの主君のしもべたちを連れて、彼を追跡せよ。彼が防備の町々を得て、われわれの目から逃れ去ることのないように。」</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記第二 8:18; 列王記第一 1:38; サムエル記第二 20:23"> ヨアブの部下たちは、ケレテ人、ペレテ人、そしてすべての勇士たちとともに彼の後を追って出て行った。彼らはビクリの息子シェバを追跡するために、エルサレムから出て行った。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="サムエル記第二 3:30; サムエル記第二 2:13; サムエル記第二 20:4–5"> 彼らがギベオンにある大きな石のところに来たとき、アマサが彼らを迎えに来た。ヨアブは戦いの装束をまとい、その上から、剣を鞘に収めて帯で腰に結んでいた。彼が進み出たとき、剣が抜け落ちた。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカ 22:47–48; マタイ 26:48–49; ミカ書 7:2"> ヨアブはアマサに、「わたしの兄弟よ、平安か」と言った。ヨアブは右手でアマサのひげをつかみ、彼に口づけしようとした。</span>
<span className="v" id="v10" data-v="10" data-xref="サムエル記第二 2:23; サムエル記第二 3:27; 士師記 3:21"> しかしアマサは、ヨアブの手にある剣に注意を払わなかった。そこでヨアブはそれで彼の腹を打ち、彼のはらわたを地面に流し出させた。彼を二度打つことはなかった。そして彼は死んだ。<br />ヨアブとその兄弟アビシャイは、ビクリの息子シェバを追跡した。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記第二 20:13; サムエル記第二 20:21; 列王記第二 9:32"> ヨアブの若者の一人が彼のそばに立って言った。「ヨアブに好意を持つ者、ダビデに味方する者は、ヨアブに従え！」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="箴言 24:21–22; 詩篇 9:16; サムエル記第二 17:25"> アマサは大路の真ん中で血だまりの中をもがいていた。その男は、すべての民が立ち止まるのを見ると、アマサを大路から野へ運び出し、彼の上に服を投げかけた。彼のそばを通る者が皆、立ち止まるのを見たからである。</span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記第一 6:12; イザヤ書 7:3; 列王記第二 18:17"> 彼が大路から除かれると、すべての民はヨアブの後に続いて進み、ビクリの息子シェバを追跡した。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王記第二 15:29; 列王記第一 15:20; 歴代誌 第二 16:4"> シェバはイスラエルのすべての部族を通って、アベル、ベテ・マアカ、そしてすべてのベリ人のところへ行った。彼らは呼び集められ、彼らもまた彼の後について行った。</span>
<span className="v" id="v15" data-v="15" data-xref="列王記第二 19:32; エレミヤ書 32:24; 列王記第一 15:20"> 彼らはやって来て、ベテ・マアカのアベルで彼を包囲し、町に向かって土塁を築き上げた。それは外塁に達して立った。そしてヨアブとともにいたすべての民は、城壁を打ち倒そうと攻撃した。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="サムエル記第二 14:2; 伝道者の書 9:14–18; サムエル記第一 25:32–33"> そのとき、町の中から一人の知恵のある女が大声で叫んだ。「聞いてください、聞いてください！どうかヨアブに、『ここに近づいてください。わたしがあなたとお話しできるよう』と言ってください。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="サムエル記第二 14:12; サムエル記第一 25:24"> 彼は彼女に近づいた。女は、「あなたはヨアブですか」と言った。<br />彼は「そうだ」と答えた。<br />それから彼女は彼に言った。「あなたのはしための言葉を聞いてください。」<br />彼は「聞いている」と答えた。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命記 20:10–11"> それから彼女は言った。「昔から、『必ずアベルで尋ねよ』と言われ、そのようにして事は決着したものです。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記第一 26:19; サムエル記第二 21:3; サムエル記第二 17:16"> わたしはイスラエルにおいて平和で忠実な者の一人です。あなたはイスラエルの母なる町を滅ぼそうとしておられます。なぜあなたは主の相続地を飲み込もうとされるのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ルカ 10:29; 箴言 28:13; エレミヤ書 17:9"> ヨアブは答えた。「決して、そのようなことはない。わたしが飲み込んだり滅ぼしたりすることは、決してない。</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記第一 26:9; 士師記 2:9; サムエル記第二 17:2–3"> 事はそうではない。エフライムの山地出身の、ビクリの息子シェバという名の男が、王に対して、すなわちダビデに対して手を上げたのだ。彼だけを引き渡せ。そうすればわたしは町から去ろう。」<br />女はヨアブに言った。「彼の首を城壁越しにあなたへ投げましょう。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="サムエル記第二 20:1; 伝道者の書 7:19; サムエル記第二 11:6–21"> それから女は自分の知恵をもってすべての民のところへ行った。彼らはビクリの息子シェバの首をはね、それを外のヨアブに投げた。彼は角笛を吹き鳴らし、彼らは町から散って、それぞれ自分の天幕へ帰った。それからヨアブはエルサレムの王のもとに帰った。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="サムエル記第二 8:16–18; 歴代誌上 18:15–17; 列王記第一 4:3–6"> さて、ヨアブはイスラエルの全軍の長であった。エホヤダの息子ベナヤはケレテ人とペレテ人の長であり、</span>
<span className="v" id="v24" data-v="24" data-xref="列王記第一 4:3; 列王記第一 12:18; 列王記第一 4:6"> アドラムは強制労働に服する者たちの長であり、アヒルデの息子ヨシャファテは記録官であった。</span>
<span className="v" id="v25" data-v="25" data-xref="列王記第一 4:4; サムエル記第二 8:17; 歴代誌上 18:16"> シェワは書記官であり、ツァドクとアビアタルは祭司であった。</span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記第二 23:38; 出エジプト記 2:14; 創世記 41:45"> そしてヤイル人イラもまたダビデの主要な大臣であった。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記第二 13:39; サムエル記第二 2:18; サムエル記第二 18:33"> さて、ツェルヤの息子ヨアブは、王の心がアブサロムに向いていることに気づいた。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代誌 第二 11:6; アモス書 1:1; ルツ記 3:3"> ヨアブはテコアに人を遣わし、そこから一人の知恵のある女を連れて来て、彼女に言った。「どうか、喪に服しているふりをして、喪服を着てください。油を塗らず、死者のために長く喪に服している女のようになってください。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記第二 14:19; 出エジプト記 4:15; イザヤ書 51:16"> そして王のところに行き、このように話しなさい。」こうしてヨアブは彼女の口に言葉を入れた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="サムエル記第二 1:2; 列王記第二 6:26–28; サムエル記第一 25:23"> テコアの女が王に話しかけたとき、彼女は地にひれ伏して敬意を表し、「王よ、お助けください」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="士師記 9:8–15; サムエル記第二 12:1–3"> 王は彼女に言った。「どうしたのか。」<br />彼女は答えた。「本当にわたしはやもめで、夫は死にました。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 4:8; 申命記 22:26–27; 出エジプト記 2:13"> あなたのはしためには二人の息子がいましたが、彼らは野で争いました。彼らを引き離す者は誰もいなかったので、一人がもう一人を打って殺してしまいました。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 35:19; マタイ 21:38; サムエル記第二 12:17"> 一族全体があなたのはしために立ち向かって、こう言っています。『兄弟を打った者を引き渡せ。彼が殺した兄弟の命の代わりに、われわれが彼を殺し、跡継ぎをも滅ぼすためだ。』こうして彼らは、わたしに残されたただ一つの炭火を消し、わたしの夫の名も跡継ぎも、この地上に残さないようにしようとしているのです。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="箴言 18:13; イザヤ書 11:3–4; ヨブ記 29:16"> 王は女に言った。「あなたの家に帰りなさい。わたしがあなたについて命令を出そう。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="サムエル記第一 25:24; 列王記第一 2:33; マタイ 27:25"> テコアの女は王に言った。「わが君、王よ。その咎はわたしと、わたしの父の家にありますように。王とその王座は無罪です。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 王は言った。「だれでもあなたに何かを言う者がいれば、その者をわたしのところに連れて来なさい。彼が二度とあなたを煩わせることはない。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="サムエル記第一 14:45; マタイ 10:30; 民数記 35:19"> すると彼女は言った。「どうか王が、あなたの神、主を覚えていてくださいますように。血の復讐をする者がこれ以上滅びをもたらし、彼らがわたしの息子を滅ぼすことのないようにしてください。」<br />彼は言った。「主は生きておられる。あなたの息子の髪の毛一本も地に落ちることはない。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 18:27; サムエル記第一 25:24; 使徒の働き 26:1"> それから女は言った。「どうか、あなたのはしために、わが君、王へひと言話させてください。」<br />彼は言った。「話しなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="サムエル記第二 13:37–38; サムエル記第二 12:7; 士師記 20:2"> 女は言った。「ではなぜ、あなたは神の民に対してこのようなことをなさるのですか。王はこの判決を下しながら、ご自分が追放した者を連れ戻そうとせず、自ら罪ある者となっておられます。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨブ記 30:23; 民数記 35:28; ヘブル人への手紙 9:27"> われわれは必ず死ぬ者であり、地にこぼれて再び集めることのできない水のようです。しかし神は命をむやみに取り去らず、追放された者がご自身から永久に追いやられないよう、帰る道を備えられます。</span>
<span className="v" id="v15" data-v="15"> ですから今、わたしがわが君、王にこの言葉を話すために来たのは、民がわたしを脅したからです。あなたのはしためは言いました。『わたしは今、王に話そう。もしかすると、王はしもべの願いをかなえてくださるかもしれない。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記第一 26:19"> 王は聞いてくださり、神の相続地から、わたしと息子をともに滅ぼそうとする男の手から、しもべを救い出してくださるだろう。』</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記第一 29:9; サムエル記第二 19:27; サムエル記第二 14:20"> それであなたのはしためは言いました。『どうか、わが君、王の言葉が安らぎをもたらしますように。わが君、王は神の使いのように、善と悪を見分けることができるからです。あなたの神、主があなたとともにおられますように。』」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 38:25; サムエル記第一 3:17–18; エレミヤ書 38:14"> そこで王は女に答えた。「わたしが尋ねることを、どうか隠さないでくれ。」<br />女は言った。「わが君、王よ、今お話しください。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="サムエル記第二 14:3; サムエル記第一 1:26; サムエル記第一 20:3"> 王は言った。「このすべてのことにおいて、ヨアブの手があなたとともにあったのか。」<br />女は答えた。「わが君、王よ、あなたの命にかけて誓います。わが君、王が語られたことから、だれも右にも左にも逸れることはできません。あなたのしもべヨアブがわたしに求め、彼がこのすべての言葉をあなたのはしための口に入れたからです。</span>
<span className="v" id="v20" data-v="20" data-xref="サムエル記第二 14:17; サムエル記第二 19:27; ヨブ記 32:21–22"> 事の成り行きを変えるために、あなたのしもべヨアブはこの事を行いました。わが君は、地にあるすべてのことを知る神の使いの知恵のように賢くあられます。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="サムエル記第二 14:11; サムエル記第一 14:39; マルコ 6:26"> 王はヨアブに言った。「よし、今わたしはこの事を行おう。だから行って、若者アブサロムを連れ戻しなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ルツ記 2:2; ヨブ記 31:20; ヨブ記 29:11"> ヨアブは地にひれ伏して敬意を表し、王を祝福した。ヨアブは言った。「今日、あなたのしもべは、わたしがわが君、王の御目に恵みを得たことを知りました。王がしもべの願いをかなえてくださったからです。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="サムエル記第二 3:3; サムエル記第二 13:37–38"> そこでヨアブは立ち上がってゲシュルへ行き、アブサロムをエルサレムに連れて来た。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの黙示録 22:4; 創世記 43:3; サムエル記第二 3:13"> 王は言った。「彼を自分の家へ帰らせよ。だが、わたしの顔を見てはならない。」こうしてアブサロムは自分の家へ帰り、王の顔を見ることはなかった。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 1:6; 申命記 28:35; ヨブ記 2:7"> さて、全イスラエルの中で、アブサロムほどその美しさをたたえられた者はいなかった。足の裏から頭の頂まで、彼には欠点がなかった。</span>
<span className="v" id="v26" data-v="26" data-xref="エゼキエル書 44:20; コリント人への第一の手紙 11:14; サムエル記第二 18:9"> 彼が頭の毛を刈る時（それが重くなったので、彼は毎年、年末にそれを刈っていた）、王の重り石にしたがって、その頭の毛を量ると二百シェケル<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一シェケルは約10グラム、あるいは約0.35オンスである。二百シェケルは約2キログラム、または約4.4ポンドである。">a</a></sup>あった。</span>
<span className="v" id="v27" data-v="27" data-xref="サムエル記第二 18:18; サムエル記第二 13:1; イザヤ書 14:22"> アブサロムには三人の息子と一人の娘が生まれた。娘の名はタマルといい、美しい顔立ちの女であった。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> アブサロムはエルサレムに丸二年間住んだが、王の顔を見ることはなかった。</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記第二 14:30–31; エステル記 1:12; マタイ 22:3"> そこでアブサロムは、王への取り次ぎを頼もうとヨアブを呼んだが、彼は来ようとはしなかった。彼が再び二度目に人を遣わしたが、それでも彼は来ようとはしなかった。</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 15:4–5; 列王記第二 10:6–7; 列王記第二 9:33"> そこで彼は自分のしもべたちに言った。「ヨアブの畑がわたしの畑の近くにあり、そこに大麦がある。行ってそれに火を放て。」アブサロムのしもべたちはその畑に火を放った。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31"> そこでヨアブは立ち上がって、アブサロムの家に来て、彼に言った。「なぜあなたのしもべたちは、わたしの畑に火を放ったのか。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="サムエル記第一 20:8; 出エジプト記 14:12; 箴言 28:13"> アブサロムはヨアブに答えた。「わたしはあなたのところに人を遣わして言った。『ここに来てくれ。あなたを王のもとに遣わし、「なぜわたしはゲシュルから帰って来たのですか。まだあそこにいた方が、わたしにとっては良かったのです。ですから今、わたしに王の顔を見せてください。もしわたしに咎があるなら、わたしを殺させてください」と言わせるためだ。』」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="創世記 33:4; ルカ 15:20; 創世記 27:26"> そこでヨアブは王のところに来て、彼に告げた。王がアブサロムを呼ぶと、彼は王のところに来て、王の御前で地にひれ伏した。そして王はアブサロムに口づけした。</span>
</div>
</div>

<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="2SA" data-book-slug="2-samuel" data-book-name="サムエル記第二" data-chapter="13" data-verses="39">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌上 3:9; サムエル記第二 3:2–3; サムエル記第二 13:15"> この後、ダビデの息子アブサロムにはタマルという名の美しい妹がいた。ダビデの息子アムノンは彼女を愛した。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第二の手紙 7:10; 列王記第一 21:4; 雅歌 5:8"> アムノンは妹タマルのゆえに思い悩み、病気になるほどであった。彼女は処女であり、アムノンには彼女に近づくことさえ難しく思われたからである。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記第一 16:9; コリント人への第一の手紙 3:19; ヤコブの手紙 3:15"> しかしアムノンには一人の友人がおり、その名はヨナダブといった。彼はダビデの兄弟シメアの息子であった。ヨナダブは非常に悪賢い男であった。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 20:17; レビ記 18:9; エステル記 5:13–14"> 彼はアムノンに言った。「王の息子よ、なぜあなたは日ごとにそのように沈んでいるのか。わたしに話してくれないか。」<br />アムノンは彼に言った。「わたしは兄弟アブサロムの妹タマルを愛している。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="マルコ 6:24–25; 箴言 19:27; 使徒の働き 23:15"> ヨナダブは彼に言った。「寝台に横になり、病気のふりをしなさい。あなたの父があなたを見舞いに来たなら、彼に言いなさい。『どうか、妹のタマルを来させて、わたしに食べ物を与え、わたしの目の前で料理をさせてください。わたしがそれを見て、彼女の手から食べられるように。』」</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 18:6; マタイ 13:33"> そこでアムノンは横になり、病気のふりをした。王が彼を見舞いに来たとき、アムノンは王に言った。「どうか、妹のタマルを来させて、わたしの目の前で二つの菓子を作らせてください。わたしが彼女の手から食べられるように。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> そこでダビデはタマルの家に人を遣わして言った。「今すぐあなたの兄弟アムノンの家に行き、彼のために食べ物を用意しなさい。」</span>
<span className="v" id="v8" data-v="8"> そこでタマルは兄弟アムノンの家に行った。彼は横になっていた。彼女はパン生地を取り、それをこねて、彼の目の前で菓子を作り、その菓子を焼いた。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 45:1; ヨハネ 3:20; 士師記 3:19"> 彼女は鍋を取り、彼の前に料理をよそったが、彼は食べることを拒んだ。アムノンは言った。「すべての者をわたしのところから退出させよ。」すると、すべての者が彼から退出した。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> アムノンはタマルに言った。「その食べ物を寝室に持ってきなさい。わたしがあなたの手から食べるように。」タマルは自分が作った菓子を取り、兄弟アムノンのいる寝室に持って行った。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 39:11–12"> 彼女が彼に食べさせようとそれを近づけたとき、彼は彼女を捕らえて言った。「妹よ、来てわたしと寝なさい。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="士師記 19:23; レビ記 20:17; 士師記 20:6"> 彼女は彼に答えた。「いいえ、兄弟よ、わたしに無理強いしないでください。イスラエルにおいてそのようなことは行われるべきではありません。この愚行をしてはなりません。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 19:24; 創世記 20:12; 創世記 19:8"> わたしは、自分の恥をどこへ持って行けばよいのでしょうか。それにあなたも、イスラエルにおける愚か者の一人のようになってしまいます。ですから今、どうか王に話してください。王はわたしをあなたに与えることを惜しまれないでしょう。」</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記第二 12:11; エステル記 7:8; 士師記 20:5"> しかし、彼は彼女の声に耳を傾けようとはしなかった。彼は彼女よりも力が強かったので、彼女に無理強いし、彼女と寝た。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 23:17"> その後、アムノンは彼女を激しく憎んだ。その憎しみは、かつての愛よりも大きかった。アムノンは彼女に言った。「起きて、出て行け。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 彼女は彼に言った。「いけません。わたしを追い出すこの仕打ちは、あなたが先ほどわたしにしたことよりも、さらに悪いことです。」<br />しかし、彼は彼女に耳を傾けようとはしなかった。</span>
<span className="v" id="v17" data-v="17"> それから彼は自分に仕えている若者を呼んで言った。「今すぐこの女をわたしのところから外に出し、彼女のうしろで戸のかんぬきをかけよ。」</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 5:30; 創世記 37:3; 詩篇 45:13–14"> 彼女はいろいろな色の長衣を着ていた。王の処女である娘たちは、そのような上着を着ていたからである。そこで彼のしもべは彼女を外に出し、彼女のうしろで戸のかんぬきをかけた。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 7:6; エレミヤ書 2:37; サムエル記第二 1:11"> タマルは頭に灰をかぶり、着ていたいろいろな色の長衣を引き裂き、頭に手を当てて、大声で泣きながら歩いて行った。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 12:19; 創世記 46:15; 創世記 34:2"> 彼女の兄弟アブサロムは彼女に言った。「あなたの兄弟アムノンがあなたと一緒にいたのか。しかし妹よ、今は黙っていなさい。彼はあなたの兄弟だ。この事を思い詰めてはならない。」こうしてタマルは、兄弟アブサロムの家で孤独のうちに暮らした。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 34:7; サムエル記第二 3:28–29; サムエル記第一 2:29"> ダビデ王はこれらすべての事を聞くと、非常に怒った。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 19:17–18; 創世記 31:24; 創世記 24:50"> アブサロムはアムノンに、良いことも悪いことも何も言わなかった。アブサロムは、アムノンが自分の妹タマルに無理強いしたため、彼を憎んでいたからである。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="創世記 38:12–13; サムエル記第一 25:4; 歴代誌 第二 26:10"> 丸二年が経った後、アブサロムはエフライムのそばにあるバアル・ハツォルで羊の毛刈りを行い、王の息子たちをすべて招いた。</span>
<span className="v" id="v24" data-v="24" data-xref="サムエル記第二 11:8–15; エレミヤ書 41:6–7; 詩篇 55:21"> アブサロムは王のところに来て言った。「今ご覧のように、あなたのしもべは羊の毛刈りを行っております。どうか、王とそのしもべたちも、あなたのしもべと一緒に行ってください。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ルカ 14:23; 士師記 19:7–10; サムエル記第二 14:22"> 王はアブサロムに言った。「いや、わが息子よ、われわれ全員が行くのはやめておこう。あなたに負担をかけてはならないから。」アブサロムは王に強く勧めたが、王は行こうとはせず、彼を祝福した。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="サムエル記第二 20:9; サムエル記第二 3:27; サムエル記第二 11:13–15"> そこでアブサロムは言った。「それなら、どうか兄弟のアムノンをわれわれと一緒に行かせてください。」<br />王は彼に言った。「なぜ彼があなたと一緒に行く必要があるのか。」</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 26:24–26"> しかしアブサロムが強く勧めたので、王はアムノンとすべての王の息子たちを彼とともに行かせた。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="士師記 19:6; 士師記 19:22; 士師記 19:9"> アブサロムは自分のしもべたちに命じて言った。「よく見ておけ。アムノンの心がぶどう酒で陽気になったとき、わたしが『アムノンを打て』とあなたがたに言ったら、彼を殺せ。恐れてはならない。わたしがあなたがたに命じたのではないか。勇気を出し、勇敢であれ。」</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記第二 18:9; 列王記第一 1:33; 列王記第二 1:9–12"> アブサロムのしもべたちは、アブサロムが命じたとおりにアムノンに対して行った。すると王の息子たちは皆起き上がり、それぞれ自分の騾馬に乗って逃げた。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 彼らが道中にいたとき、ダビデに知らせが届き、「アブサロムが王の息子たちをすべて殺し、一人も残っていません」と告げられた。</span>
<span className="v" id="v31" data-v="31" data-xref="サムエル記第二 1:11; サムエル記第二 12:16; ヨブ記 1:20"> すると王は立ち上がり、自分の服を引き裂いて、地面に横たわった。彼のしもべたちも皆、服を引き裂いてそばに立っていた。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="サムエル記第一 16:9; サムエル記第二 13:3; 創世記 27:41"> ダビデの兄弟シメアの息子ヨナダブは答えた。「わが主君が、王の息子である若者たちが皆殺されたと考えてはなりません。死んだのはアムノンだけです。彼が妹タマルに無理強いした日から、アブサロムがそう決意していたからです。</span>
<span className="v" id="v33" data-v="33" data-xref="サムエル記第二 19:19"> ですから今、わが主君、王は、王の息子たちが皆死んだと考えて、この事を思い詰めないでください。死んだのはアムノンだけなのですから。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="創世記 4:8–14; 箴言 28:17; アモス書 5:19"> しかしアブサロムは逃げた。見張りをしていた若者が目を上げると、多くの人々が、彼の背後の丘の中腹の道からやって来るのが見えた。</span>
<span className="v" id="v35" data-v="35"> ヨナダブは王に言った。「王の息子たちが来ます。あなたのしもべが言ったとおりです。」</span>
<span className="v" id="v36" data-v="36" data-xref="サムエル記第二 18:33; サムエル記第二 12:21; サムエル記第二 13:15"> 彼が話し終えるやいなや、王の息子たちがやって来て、声を上げて泣いた。王もそのしもべたちも皆、激しく泣いた。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="サムエル記第二 3:3; サムエル記第二 14:32; サムエル記第二 13:34"> しかしアブサロムは逃げて、ゲシュルの王、アミフドの息子タルマイのところへ行った。ダビデは毎日、自分の息子のために悲しんだ。</span>
<span className="v" id="v38" data-v="38" data-xref="サムエル記第二 15:8; サムエル記第二 14:23; サムエル記第二 14:32"> アブサロムはゲシュルに逃げて行き、そこで三年間を過ごした。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 24:67; 創世記 38:12; 創世記 37:35"> ダビデ王はアブサロムのところに出て行きたいと切に願うようになった。アムノンについては、彼が死んだことで慰めを得ていたからである。</span>
</div>
</div>

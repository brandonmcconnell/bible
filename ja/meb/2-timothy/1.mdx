<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヘブル人への手紙 9:15; ヨハネ 17:3; ヨハネ 10:28"> キリスト・イエスにある命の約束に基づき、神の御心によってキリスト・イエス<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「キリスト」は「油を注がれた者」という意味である。">a</a></sup>の使徒とされたパウロから。</span>
<span className="v" id="v2" data-v="2" data-xref="テモテへの第二の手紙 2:1; テモテへの手紙第一 1:2; 使徒の働き 16:1"> 愛する子テモテへ。父なる神と、私たちの主キリスト・イエスから、恵みとあわれみと平和がありますように。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ローマ人への手紙 1:8–9; ヘブル人への手紙 13:8; 使徒の働き 23:1"> 私は先祖たちにならい、清い良心をもって仕えている神に感謝しています。昼も夜も祈るたびに、絶えずあなたを覚え、</span>
<span className="v" id="v4" data-v="4" data-xref="テモテへの第二の手紙 4:9; ピリピ人への手紙 1:8; テサロニケ人への手紙第一 2:17–1"> あなたの涙を思い出しては、あなたに会い、喜びに満たされたいと切に願っています。</span>
<span className="v" id="v5" data-v="5" data-xref="テモテへの手紙第一 1:5; 使徒の働き 16:1; テモテへの第二の手紙 3:15"> あなたに宿る偽りのない信仰を思い起こしています。その信仰は、まず祖母ロイスと母ユニケのうちに宿り、あなたのうちにも宿っていると私は確信しています。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="テモテへの手紙第一 4:14; ペテロの手紙第一 4:10–11; ローマ人への手紙 12:6–8"> ですから、私が手を置いたことによってあなたのうちにある神の賜物を、再び燃え立たせなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 8:15; ヨハネの手紙第一 4:18; ガラテヤ人への手紙 5:22"> 神が私たちに与えてくださったのは、臆病の霊ではなく、力と愛と自制の霊だからです。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 1:16; マルコ 8:38; ペテロの手紙第一 4:13–15"> ですから、私たちの主についての証しも、主の囚人である私のことも恥じてはなりません。むしろ、神の力に支えられて、福音のために苦しみを担いなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="エペソ人への手紙 2:8–9; テトス 3:4–5; エペソ人への手紙 1:3–4"> 神は私たちを救い、聖なる召しをもって召してくださいました。それは私たちの行いによるのではなく、神ご自身のご計画と恵みによるものです。この恵みは、永遠の時より前にキリスト・イエスにあって私たちに与えられていましたが、</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの手紙第一 1:2; ローマ人への手紙 16:26; ペテロの第二の手紙 3:18"> 今や、私たちの救い主キリスト・イエスの現れによって明らかにされました。キリストは死を滅ぼし、福音によって命と不滅とを光の中に現してくださいました。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテへの手紙第一 2:7; エペソ人への手紙 3:7–8; 使徒の働き 9:15"> 私はこの福音のために、宣教者、使徒、そして異邦人の教師として任命されました。</span>
<span className="v" id="v12" data-v="12" data-xref="テモテへの第二の手紙 1:8; ユダ 1:24; ペテロの手紙第一 4:19"> そのために、私はこのような苦しみも受けています。<br />しかし、私は恥じてはいません。自分が信じている方を知っており、私がその方に委ねたものを、かの日まで守ることがおできになると確信しているからです。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="テトス 1:9; テモテへの第二の手紙 3:14; ピリピ人への手紙 4:9"> 私から聞いた健全な言葉を規範として、キリスト・イエスにある信仰と愛のうちに守りなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネ 14:17; ローマ人への手紙 8:13; テモテへの手紙第一 6:20"> あなたに託された良いものを、私たちのうちに住まわれる聖霊によって守りなさい。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="テモテへの第二の手紙 4:16; ピリピ人への手紙 2:21; 使徒の働き 19:10"> あなたも知っているとおり、アジアにいる者たちは皆、私から離れて行きました。その中にはフィゲロとヘルモゲネもいます。</span>
<span className="v" id="v16" data-v="16" data-xref="テモテへの第二の手紙 4:19; フィレモンへの手紙 1:20; フィレモンへの手紙 1:7"> 主がオネシフォロの家にあわれみを与えてくださいますように。彼は何度も私を力づけ、私が鎖につながれていることを恥じませんでした。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 28:30–31"> それどころか、ローマに来ると熱心に私を捜し、見つけてくれました。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 6:10; テモテへの第二の手紙 1:12; テモテへの手紙第一 1:3"> かの日に、主が彼をあわれんでくださいますように。彼がエフェソでどれほどよく仕えてくれたかは、あなたがよく知っています。</span>
</div>

<span className="v" id="v2" data-v="2" data-xref="テサロニケ人への手紙第一 5:14; テモテへの手紙第一 4:15–16; テトス 2:15"> 御言葉を宣べ伝えなさい。時が良くても悪くても、たゆまず務めなさい。あらゆる忍耐と教えを尽くして、誤りを指摘し、戒め、励ましなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="ペテロの第二の手紙 2:1–3; テモテへの第二の手紙 3:1–6; テモテへの手紙第一 4:1–3"> 人々が健全な教えに耳を傾けなくなる時が来るからです。彼らは耳を楽しませる話を聞きたがり、自分の欲望に従って教師を次々と集め、</span>
<span className="v" id="v4" data-v="4" data-xref="ゼカリヤ書 7:11; テモテへの手紙第一 1:4; 使徒の働き 7:57"> 真理から耳を背け、作り話へと心を向けます。</span>
<span className="v" id="v5" data-v="5" data-xref="テモテへの第二の手紙 1:8; ペテロの手紙第一 1:13; テモテへの第二の手紙 2:3"> しかしあなたは、どんな場合にも冷静さを保ち、苦しみに耐え、福音を伝える者の働きをし、自分の務めを十分に果たしなさい。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ピリピ人への手紙 1:23; ピリピ人への手紙 2:17; ペテロの第二の手紙 1:14–15"> 私はすでに注ぎの供え物とされつつあり、旅立つ時が来ました。</span>
<span className="v" id="v7" data-v="7" data-xref="テモテへの手紙第一 6:12; コリント人への第一の手紙 9:24–27; ヘブル人への手紙 12:1–2"> 私は立派に戦い抜き、走るべき道のりを走り終え、信仰を守りました。</span>
<span className="v" id="v8" data-v="8" data-xref="ヤコブの手紙 1:12; ヨハネの黙示録 2:10; ペテロの手紙第一 5:4"> 今や、義の冠が私のために蓄えられています。正しい裁き主である主が、かの日にそれを私に授けてくださいます。私だけでなく、主の現れを愛してきたすべての人にも授けてくださいます。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="テモテへの第二の手紙 1:4; テモテへの第二の手紙 4:21"> できるだけ早く私のもとに来てください。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの手紙第一 2:15–16; テモテへの第二の手紙 1:15; コロサイ人への手紙 4:14–15"> デマスは今の世を愛し、私を見捨ててテサロニケへ行きました。クレスケンスはガラテヤへ、テトスはダルマティアへ行きました。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 12:12; フィレモンへの手紙 1:24; 使徒の働き 12:25"> 私と一緒にいるのはルカだけです。マルコを連れて来てください。彼は務めのために私の役に立つからです。</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 6:21; 使徒の働き 20:4; テトス 3:12"> テキコはエフェソに遣わしました。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 4:11; コリント人への第二の手紙 11:27; 使徒の働き 16:11"> 来る時には、私がトロアスのカルポの所に置いてきた外套を持って来てください。書物も、特に羊皮紙も持って来てください。</span>
<span className="v" id="v14" data-v="14" data-xref="テモテへの手紙第一 1:20; テサロニケ人への第二の手紙 1:6; 詩篇 28:4"> 銅細工人アレクサンデルは、私に多くの害を加えました。主が彼の行いに応じて報われるでしょう。</span>
<span className="v" id="v15" data-v="15" data-xref="テモテへの第二の手紙 3:8; ピリピ人への手紙 3:2; マタイ 10:16–17"> あなたも彼を警戒してください。彼は私たちの言葉に激しく逆らったからです。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 7:60; ヨハネ 16:32; マルコ 14:50"> 私の最初の弁明の時、だれも私を支えてくれず、皆が私を見捨てました。どうか、それが彼らの罪とされませんように。</span>
<span className="v" id="v17" data-v="17" data-xref="ペテロの手紙第一 5:8; ピリピ人への手紙 1:12–14; サムエル記第一 17:37"> しかし、主は私のそばに立って、私を強めてくださいました。それは、私を通して福音の知らせが余すところなく告げられ、すべての異邦人が聞くためでした。こうして私は獅子の口から救い出されました。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 121:7; テサロニケ人への第二の手紙 3:3; ユダ 1:24–25"> 主は私をあらゆる悪い行いから救い出し、天の御国に至るまで守ってくださいます。主に栄光が世々限りなくありますように。アーメン。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 18:2; コリント人への第一の手紙 16:19; ローマ人への手紙 16:3–4"> プリスカとアキラ、そしてオネシフォロの家の人々によろしく伝えてください。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 20:4; 使徒の働き 19:22; ピリピ人への手紙 2:26–27"> エラストはコリントに残りました。トロフィモは病気だったので、ミレトに残してきました。</span>
<span className="v" id="v21" data-v="21" data-xref="テモテへの第二の手紙 4:9; ピリピ人への手紙 4:22; ヨハネの手紙第三 1:14"> 冬になる前に来られるよう急いでください。エウブロ、プデス、リノス、クラウディア、そしてすべての兄弟たちが、あなたによろしくと言っています。</span>
</div>

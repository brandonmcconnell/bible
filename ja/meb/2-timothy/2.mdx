<span className="v" id="v2" data-v="2" data-xref="テモテへの第二の手紙 1:13–14; テモテへの手紙第一 4:6; テモテへの手紙第一 6:12"> 多くの証人の前で私から聞いたことを、ほかの人々にも教えることのできる忠実な人たちに委ねなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 12:2–3; ヤコブの手紙 1:12; テモテへの第二の手紙 4:5"> あなたも、キリスト・イエスの良い兵士として苦しみに耐えなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="テサロニケ人への手紙第一 2:4; ルカ 8:14; ペテロの第二の手紙 2:20"> 兵役に就いている者は、日々の生活の事柄に巻き込まれません。自分を兵士として召した方を喜ばせるためです。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第一の手紙 9:24–27; ヨハネの黙示録 3:11; テモテへの第二の手紙 4:7–8"> また、競技をする人も、規則に従って競技をしなければ栄冠を受けることはできません。</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 10:36; コリント人への第一の手紙 9:7–11; コリント人への第一の手紙 3:6–9"> まず収穫の分け前にあずかるべきなのは、労苦した農夫です。</span>
<span className="v" id="v7" data-v="7" data-xref="ヤコブの手紙 1:5; ヨハネの手紙第一 5:20; ルカ 24:45"> 私の言うことをよく考えなさい。主がすべてのことを悟らせてくださいますように。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 2:24; ローマ人への手紙 2:16; コリント人への第一の手紙 15:11–20"> 私の福音によれば、死者の中からよみがえられた、ダビデの子孫<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「種」。">a</a></sup>であるイエス・キリストを思い起こしなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="ピリピ人への手紙 1:7; 使徒の働き 28:31; テモテへの第二の手紙 1:8"> 私はこの福音のために、犯罪者のように鎖につながれるほど苦しんでいます。しかし、神の言葉はつながれていません。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの手紙第一 5:10; コロサイ人への手紙 1:24; テモテへの第二の手紙 2:3"> ですから私は、選ばれた者たちのために、すべてのことを耐え忍んでいます。彼らもまた、キリスト・イエスにある救いを、永遠の栄光と共に得るためです。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 6:8; コロサイ人への手紙 3:3–4; ローマ人への手紙 6:5"> この言葉は信頼できます。<br /><span className="pl pl-1">「私たちがキリストと共に死んだのなら、</span><br /><span className="pl pl-2">共に生きるようにもなる。</span></span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 8:17; マタイ 10:33; ヨハネの黙示録 20:4"> <span className="pl pl-1">耐え忍ぶなら、</span><br /><span className="pl pl-2">共に治めるようにもなる。</span><br /><span className="pl pl-1">この方を否むなら、</span><br /><span className="pl pl-2">この方も私たちを否まれる。</span></span>
<span className="v" id="v13" data-v="13" data-xref="民数記 23:19; ローマ人への手紙 3:3; テサロニケ人への第二の手紙 3:3"> <span className="pl pl-1">私たちが不真実であっても、</span><br /><span className="pl pl-2">この方は真実であり続けられる。</span><br /><span className="pl pl-2">ご自分を否むことはできないからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="テトス 3:9–11; テモテへの第二の手紙 2:23; テモテへの第二の手紙 4:1"> これらのことを人々に思い起こさせなさい。そして、言葉を巡って争わないよう、主の前で厳かに命じなさい。そのような争いは何の益もなく、聞く人々を損なうだけです。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="テサロニケ人への手紙第一 2:4; ペテロの第二の手紙 1:10; テモテへの手紙第一 4:6"> 神に認められる者として自分を示せるよう努めなさい。恥じるところのない働き人として、真理の言葉を正しく扱いなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="テトス 3:9; テモテへの手紙第一 6:20; テモテへの第二の手紙 2:14"> 空しいおしゃべりを避けなさい。そのような言葉は、人をますます不敬虔へと進ませるからです。</span>
<span className="v" id="v17" data-v="17" data-xref="テモテへの手紙第一 1:20; ナホム書 3:15; ヤコブの手紙 5:3"> 彼らの言葉は壊疽のように広がっていきます。その中にヒメナイとフィレトがいます。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 15:12; テモテへの手紙第一 1:19; ヘブル人への手紙 3:10"> 彼らは真理から外れ、復活はすでに起こったと言って、ある人々の信仰を覆しています。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネ 10:14; コリント人への第一の手紙 8:3; ナホム書 1:7"> しかし、神の堅固な土台は立ち続けており、次の言葉が印として刻まれています。「主はご自分に属する者を知っておられる。」 また、「主<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="公認本文では「主」の代わりに「キリスト」となっている。">b</a></sup>の名を口にする者は皆、不義から離れよ。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 9:21–23; ペテロの手紙第一 2:5; テモテへの手紙第一 3:15"> 大きな家には、金や銀の器だけでなく、木や土の器もあります。尊い用途に使われるものもあれば、卑しい用途に使われるものもあります。</span>
<span className="v" id="v21" data-v="21" data-xref="テモテへの第二の手紙 3:17; エペソ人への手紙 2:10; コリント人への第二の手紙 7:1"> ですから、こうしたものから自分を清める人は、尊い用途に用いられる器となります。聖なるものとされ、主人に役立ち、あらゆる良い働きのために備えられた器です。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ペテロの手紙第一 2:11; ペテロの手紙第一 3:11; コリント人への第一の手紙 6:18"> 若者の欲望から逃れなさい。そして、清い心で主を呼び求める人々と共に、義と信仰と愛と平和を追い求めなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="テモテへの第二の手紙 2:14; テトス 3:9; テモテへの手紙第一 4:7"> 愚かで無知な論争は退けなさい。それが争いを生むことを知っているからです。</span>
<span className="v" id="v24" data-v="24" data-xref="テトス 3:2; ヤコブの手紙 1:19–20; テモテへの手紙第一 3:2–3"> 主の僕は争ってはなりません。すべての人に優しく、よく教えることができ、忍耐強くあるべきです。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 11:18; ガラテヤ人への手紙 6:1; テモテへの手紙第一 2:4"> 反対する者たちを柔和な心で正しなさい。ひょっとすると神が彼らに悔い改めを与え、真理を十分に知るようにしてくださるかもしれません。</span>
<span className="v" id="v26" data-v="26" data-xref="テモテへの手紙第一 3:7; イザヤ書 49:25–26; 詩篇 124:7"> そうすれば彼らは正気に返り、悪魔の罠から逃れられるでしょう。彼らは悪魔に生け捕りにされ、その意志を行っていたのです。</span>

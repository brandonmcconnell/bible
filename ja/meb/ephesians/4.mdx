<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 1:10; ピリピ人への手紙 1:27; テサロニケ人への手紙第一 2:12"> そこで、主にあって囚人となっている私は、あなたがたにお願いします。あなたがたが受けた召しにふさわしく歩みなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="コロサイ人への手紙 3:12–13; コリント人への第一の手紙 13:7; コリント人への第一の手紙 13:4–5"> どこまでも謙遜に、柔和に、忍耐をもって、愛のうちに互いに耐え忍び、</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第一の手紙 1:10; コロサイ人への手紙 3:13–15; コリント人への第一の手紙 12:12–13"> 平和のきずなによって、聖霊による一致を熱心に保ちなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="エペソ人への手紙 2:18; ローマ人への手紙 12:4–5; コリント人への第一の手紙 12:4–13"> 体は一つ、聖霊は一つです。あなたがたが召されたときに与えられた望みも一つです。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第一の手紙 8:6; コリント人への第一の手紙 12:13; ペテロの手紙第一 3:21"> 主は一人、信仰は一つ、バプテスマは一つ、</span>
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 11:36; マラキ書 2:10; コリント人への第一の手紙 8:6"> すべてのものの父なる神はお一人です。この方はすべてのものの上にあり、すべてを貫き、私たちすべてのうちにおられます。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの手紙第一 4:10; ローマ人への手紙 12:3; コリント人への第一の手紙 12:7–11"> しかし、私たち一人一人には、キリストの賜物の量りに応じて恵みが与えられました。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 68:18; コロサイ人への手紙 2:15; サムエル記第一 30:26"> そのため、聖書はこう言っています。<br /><span className="pl pl-1">「高い所に上られたとき、</span><br /><span className="pl pl-2">捕らわれの者たちを引き連れ、</span><br /><span className="pl pl-2">人々に賜物をお与えになった。」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヨハネ 3:13; マタイ 12:40; 箴言 30:4"> さて、「上られた」ということは、まず地の低い所へ下られたことにほかなりません。</span>
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 7:26; ヘブル人への手紙 4:14; エペソ人への手紙 1:20–23"> 下られた方ご自身が、すべてのものを満たすために、あらゆる天よりもはるか高く上られた方なのです。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 3:15; コリント人への第一の手紙 12:28–29; エペソ人への手紙 2:20"> キリストは、ある人を使徒、ある人を預言者、ある人を福音を伝える者、またある人を牧者<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「牧師」。">a</a></sup>や教師としてお与えになりました。</span>
<span className="v" id="v12" data-v="12" data-xref="テサロニケ人への手紙第一 5:11–14; エペソ人への手紙 4:16; コリント人への第一の手紙 12:27"> それは、聖徒たちを整えて奉仕の働きに就かせ、キリストの体を築き上げるためです。</span>
<span className="v" id="v13" data-v="13" data-xref="コロサイ人への手紙 1:28; ヨハネ 17:21; エペソ人への手紙 4:5"> こうして私たちは皆、信仰と神の御子を知る知識との一致に達し、成熟した一人の人となり、キリストの満ち満ちた姿にまで成長するのです。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 13:9; ローマ人への手紙 16:17–18; コリント人への第一の手紙 14:20"> それは、私たちがもはや子どものままで、人の欺きや、誤りへと巧みに誘い込む策略によって、教えのあらゆる風に吹き回され、波にもてあそばれることがないためです。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの手紙第一 3:18; エペソ人への手紙 4:25; ゼカリヤ書 8:16"> むしろ、愛のうちに真理を語り、すべての点で、かしらであるキリストへと成長していきます。</span>
<span className="v" id="v16" data-v="16" data-xref="コロサイ人への手紙 2:19; ヨハネ 15:5; コロサイ人への手紙 2:2"> キリストから、体全体は、すべての節々の支えによって組み合わされ、結び合わされます。そして、それぞれの部分がその力量に応じて働くとき、体は成長し、愛のうちに自らを築き上げていくのです。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 1:21; ペテロの手紙第一 4:3–4; テサロニケ人への手紙第一 4:1–2"> ですから私は、主にあってこう言い、厳かに告げます。あなたがたはもはや、ほかの異邦人たちのように、むなしい思いに従って歩んではなりません。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイ 13:15; エペソ人への手紙 2:12; ローマ人への手紙 1:21–23"> 彼らは理解が暗くなり、内にある無知と心のかたくなさのために、神のいのちから遠く離れています。</span>
<span className="v" id="v19" data-v="19" data-xref="コロサイ人への手紙 3:5; ローマ人への手紙 1:24–26; テモテへの手紙第一 4:2"> 彼らは感覚を失い、放縦に身を任せ、貪欲のままにあらゆる汚れた行いにふけっています。</span>
<span className="v" id="v20" data-v="20" data-xref="テトス 2:11–14; ヨハネ 6:45; マタイ 11:29"> しかし、あなたがたが学んだキリストは、そのような方ではありません。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの手紙第一 5:20; エペソ人への手紙 1:13; ヘブル人への手紙 3:7–8"> もし実際にキリストに聞き、イエスにある真理に従って、キリストにあって教えられたのなら、</span>
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 6:6; ヘブル人への手紙 12:1; ヤコブの手紙 1:21"> 以前の生き方に属する古い人を脱ぎ捨てなさい。その古い人は、欺く欲望によって滅びへと向かっています。</span>
<span className="v" id="v23" data-v="23" data-xref="ローマ人への手紙 12:2; ローマ人への手紙 8:6; 詩篇 51:10"> そして、心の内なる霊において新しくされ、</span>
<span className="v" id="v24" data-v="24" data-xref="コロサイ人への手紙 3:10–14; コリント人への第二の手紙 5:17; エペソ人への手紙 2:10"> 神に似せて、真理から生まれる義と聖さのうちに造られた新しい人を身に着けなさい。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="コロサイ人への手紙 3:9; ゼカリヤ書 8:16; 箴言 12:22"> ですから、偽りを捨て、それぞれ隣人に真実を語りなさい。私たちは互いに一つの体を成す部分だからです。</span>
<span className="v" id="v26" data-v="26" data-xref="ヤコブの手紙 1:19; 詩篇 4:4; 詩篇 37:8"> 「怒っても、罪を犯してはならない。」 怒ったまま日を沈ませてはならず、</span>
<span className="v" id="v27" data-v="27" data-xref="ヤコブの手紙 4:7; ペテロの手紙第一 5:8; エペソ人への手紙 6:16"> 悪魔につけ入る隙<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または「機会」。">b</a></sup>を与えてはなりません。</span>
<span className="v" id="v28" data-v="28" data-xref="テモテへの手紙第一 6:18; テサロニケ人への手紙第一 4:11–12; ガラテヤ人への手紙 6:10"> 盗みをしていた者は、もう盗んではなりません。むしろ、必要な人に分け与えられるよう、自分の手で正当な仕事をし、働きなさい。</span>
<span className="v" id="v29" data-v="29" data-xref="コロサイ人への手紙 4:6; テサロニケ人への手紙第一 5:11; 伝道者の書 10:12"> 悪い言葉を口から出してはなりません。必要に応じて人を築き上げ、聞く人に恵みを与える良い言葉だけを語りなさい。</span>
<span className="v" id="v30" data-v="30" data-xref="テサロニケ人への手紙第一 5:19; イザヤ書 63:10; エペソ人への手紙 1:13–14"> 神の聖霊を悲しませてはなりません。あなたがたは贖いの日のために、聖霊によって証印を押されたのです。</span>
<span className="v" id="v31" data-v="31" data-xref="コロサイ人への手紙 3:8; 伝道者の書 7:9; テトス 3:2–3"> あらゆる苦々しさ、憤り、怒り、わめき、悪口を、すべての悪意とともに捨て去りなさい。</span>
<span className="v" id="v32" data-v="32" data-xref="コロサイ人への手紙 3:12–13; マタイ 6:14–15; マルコ 11:25"> 互いに親切にし、心優しく接し、神がキリストにあってあなたがたを赦してくださったように、互いに赦し合いなさい。</span>
</div>

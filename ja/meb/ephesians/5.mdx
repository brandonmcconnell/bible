<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの手紙第一 4:11; ペテロの手紙第一 1:15–16; エペソ人への手紙 4:32"> ですから、愛されている子どもとして、神にならう者となりなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネ 13:34; ガラテヤ人への手紙 2:20; コロサイ人への手紙 3:14"> キリストが私たちを愛し、私たちのためにご自分を、芳しい香りとなる神への供え物といけにえとして献げられたように、あなたがたも愛のうちに歩みなさい。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="コロサイ人への手紙 3:5; エペソ人への手紙 5:5; ガラテヤ人への手紙 5:19–21"> 性的不品行、あらゆる汚れ、また貪欲は、聖徒にふさわしく、あなたがたの間にその名さえ挙がらないようにしなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="コロサイ人への手紙 3:8; エペソ人への手紙 4:29; テサロニケ人への手紙第一 5:18"> 恥ずべきこと、愚かな話、下品な冗談もふさわしくありません。むしろ、感謝の言葉を語りなさい。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ガラテヤ人への手紙 5:21; コリント人への第一の手紙 6:9–10; エペソ人への手紙 5:3"> このことを確かに知っておきなさい。性的不品行を行う者、汚れた者、貪欲な者、すなわち偶像を礼拝する者はだれも、キリストと神の王国には何の相続分も持っていません。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 1:18; コロサイ人への手紙 2:8; マタイ 24:4"> むなしい言葉でだれにも欺かれてはなりません。このようなことのために、神の怒りは不従順の子らの上に下るからです。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの黙示録 18:4; エペソ人への手紙 5:11; テモテへの手紙第一 5:22"> ですから、彼らと行いをともにしてはなりません。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネ 8:12; ヨハネの手紙第一 1:7; 使徒の働き 26:18"> あなたがたは以前は闇そのものでしたが、今は主にあって光です。光の子どもとして歩みなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの手紙第一 3:9–10; ガラテヤ人への手紙 5:22–23; ヨハネの手紙第三 1:11"> 聖霊の実は、あらゆる善と義と真理のうちに現れるからです。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 12:1–2; ヘブル人への手紙 12:28; 詩篇 19:14"> 何が主に喜ばれるかを見極めなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 13:12; テモテへの手紙第一 5:20; テサロニケ人への第二の手紙 3:6"> 実を結ばない闇の行いに加わらず、むしろそれを責めて明るみに出しなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 5:3; エレミヤ書 23:24; 伝道者の書 12:14"> 彼らが隠れて行っていることは、口にすることさえ恥ずべきことだからです。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネ 3:20–21; コリント人への第一の手紙 4:5; ホセア書 2:10"> しかし、すべてのものは光に照らされると明るみに出され、その正体が現れます。すべてを明るみに出すのは光だからです。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 60:1; ローマ人への手紙 13:11–12; イザヤ書 26:19"> そのため、こう言われています。「眠っている者よ、目を覚ませ。死者の中から立ち上がれ。そうすれば、キリストがあなたを照らす。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="コロサイ人への手紙 4:5; ヤコブの手紙 3:13; ピリピ人への手紙 1:27"> ですから、自分がどのように歩んでいるかに細心の注意を払いなさい。知恵のない者としてではなく、知恵のある者として歩み、</span>
<span className="v" id="v16" data-v="16" data-xref="コロサイ人への手紙 4:5; アモス書 5:13; ヨハネ 12:35"> 時を有効に使いなさい。今は悪い時代だからです。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 12:2; テサロニケ人への手紙第一 5:18; コロサイ人への手紙 1:9"> ですから、愚かな者にならず、主の御心が何であるかを理解しなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 20:1; ルカ 1:15; ローマ人への手紙 13:13"> 酒に酔ってはなりません。それは放蕩につながるからです。むしろ、聖霊に満たされなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="コロサイ人への手紙 3:16; コリント人への第一の手紙 14:26; 詩篇 95:2"> 詩篇と賛美歌と霊の歌をもって互いに語り合い、心から主に歌い、賛美を奏でなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="コロサイ人への手紙 3:17; テサロニケ人への手紙第一 5:18; ヘブル人への手紙 13:15"> いつでも、すべてのことについて、私たちの主イエス・キリストの名によって、父なる神に感謝しなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="ピリピ人への手紙 2:3; エペソ人への手紙 5:24; エペソ人への手紙 5:22"> キリストを恐れ敬う心で、互いに従い合いなさい。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="コロサイ人への手紙 3:18–1; ペテロの手紙第一 3:1–6; テトス 2:5"> 妻たちよ、主に従うように、自分の夫に従いなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への第一の手紙 11:3–10; コロサイ人への手紙 1:18; エペソ人への手紙 1:22–23"> 夫は妻のかしらだからです。それは、キリストが教会のかしらであり、ご自身がその体の救い主であるのと同じです。</span>
<span className="v" id="v24" data-v="24" data-xref="エペソ人への手紙 5:33; コロサイ人への手紙 3:20; テトス 2:7"> 教会がキリストに従っているように、妻もすべてのことにおいて自分の夫に従いなさい。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ペテロの手紙第一 3:7; コロサイ人への手紙 3:19; エペソ人への手紙 5:28"> 夫たちよ、キリストが教会を愛し、教会のためにご自分を献げられたように、妻を愛しなさい。</span>
<span className="v" id="v26" data-v="26" data-xref="ヘブル人への手紙 10:22; ヨハネ 15:3; エゼキエル書 36:25"> キリストがご自分を献げられたのは、言葉による水の洗いをもって教会を清め、聖なるものとするため、</span>
<span className="v" id="v27" data-v="27" data-xref="コロサイ人への手紙 1:22; ヘブル人への手紙 9:14; ペテロの手紙第一 1:19"> また、しみやしわ、そのほかそのようなものが何もなく、聖なる、傷のない、栄光に輝く教会として、ご自分の前に立たせるためでした。</span>
<span className="v" id="v28" data-v="28" data-xref="エペソ人への手紙 5:25; マタイ 19:5; 創世記 2:21–24"> 同じように、夫も自分の体を愛するように妻を愛すべきです。自分の妻を愛する人は、自分自身を愛しているのです。</span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 34:14–15; エペソ人への手紙 5:31; 伝道者の書 4:5"> 自分の肉体を憎んだ人は一人もいません。むしろ、それを養い、いたわります。主が教会に対してなさるのも同じです。</span>
<span className="v" id="v30" data-v="30" data-xref="コリント人への第一の手紙 6:15; コリント人への第一の手紙 12:12–27; ローマ人への手紙 12:5"> 私たちはキリストの体の一部、すなわち、その肉と骨だからです。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 2:24; マタイ 19:5; マルコ 10:7–8"> 「このため、男は父と母を離れて妻と結ばれ、二人は一つの肉体となる。」</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネの黙示録 21:2; コリント人への第二の手紙 11:2; イザヤ書 54:5"> この奥義は偉大です。私はキリストと教会について語っています。</span>
<span className="v" id="v33" data-v="33" data-xref="ペテロの手紙第一 3:2–7; エステル記 1:20; エペソ人への手紙 5:25"> いずれにしても、あなたがたも一人一人、自分自身を愛するように妻を愛しなさい。また、妻は夫を敬うようにしなさい。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 1:24; テモテへの第二の手紙 1:8; ピリピ人への手紙 1:13–16"> こういうわけで、あなたがた異邦人のためにキリスト・イエスの囚人となっている、この私パウロは――</span>
<span className="v" id="v2" data-v="2" data-xref="コロサイ人への手紙 1:25–27; テモテへの手紙第一 1:11; テモテへの第二の手紙 1:11"> あなたがたのために私に委ねられた神の恵みの務めについて、きっと聞いていることでしょう。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 1:12; ローマ人への手紙 16:25; エペソ人への手紙 1:9–11"> 先に手短に書いたとおり、啓示によって奥義が私に知らされました。</span>
<span className="v" id="v4" data-v="4" data-xref="コロサイ人への手紙 4:3; コリント人への第一の手紙 4:1; コリント人への第二の手紙 11:6"> それを読めば、私がキリストの奥義をどのように理解しているかが分かります。</span>
<span className="v" id="v5" data-v="5" data-xref="ペテロの手紙第一 1:10–12; ペテロの第二の手紙 3:2; テトス 1:1–3"> この奥義は、以前の世代には人々に知らされませんでしたが、今は聖霊によって、神の聖なる使徒たちと預言者たちに啓示されています。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 3:26–29; ヨハネの手紙第一 1:3; ヨハネの手紙第一 2:25"> その奥義とは、異邦人も福音を通してキリスト・イエスにあって、ともに相続を受け、ともに一つの体に属し、ともに神の約束にあずかる者となることです。</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 1:19; エペソ人への手紙 3:20; エペソ人への手紙 3:2"> 私は、神の力の働きに従って与えられた恵みの賜物により、この福音に仕える者とされました。</span>
<span className="v" id="v8" data-v="8" data-xref="コロサイ人への手紙 1:27; コリント人への第一の手紙 15:9; エペソ人への手紙 2:7"> すべての聖徒の中で最も小さい者にも及ばない私に、この恵みが与えられました。それは、計り知ることのできないキリストの豊かさを異邦人に福音として告げ知らせ、</span>
<span className="v" id="v9" data-v="9" data-xref="コロサイ人への手紙 1:26; マタイ 13:35; テモテへの第二の手紙 1:9"> また、イエス・キリストによってすべてを創造された神のうちに、長い時代にわたって隠されてきた奥義にかかわるご計画がどのようなものか<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="公認本文では「奥義にかかわるご計画」の代わりに「奥義の交わり」としている。">a</a></sup>を、すべての人に明らかにするためです。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの手紙第一 1:12; エペソ人への手紙 6:12; コリント人への第一の手紙 2:7"> それは今、教会を通して、神の多種多様な知恵が、天上にいる支配者たちと権威ある者たちに知らされるためでした。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテへの第二の手紙 1:9; エペソ人への手紙 1:11; エペソ人への手紙 1:4"> これは、神が私たちの主キリスト・イエスにあって成し遂げられた、永遠の目的に沿うものです。</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 2:18; ローマ人への手紙 5:2; ヘブル人への手紙 4:14–16"> 私たちはキリストにあって、キリストへの信仰により、大胆に、確信をもって神に近づくことができます。</span>
<span className="v" id="v13" data-v="13" data-xref="コロサイ人への手紙 1:24; テサロニケ人への第二の手紙 3:13; コリント人への第二の手紙 1:6"> ですから、私があなたがたのために受けている苦難によって、気落ちしないよう願います。この苦難はあなたがたの栄光なのです。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="詩篇 95:6; エペソ人への手紙 1:16–19; ピリピ人への手紙 2:10"> こういうわけで私は、私たちの主イエス・キリストの父の前にひざをかがめます。</span>
<span className="v" id="v15" data-v="15" data-xref="エペソ人への手紙 1:10; ヨハネの黙示録 5:8–14; エペソ人への手紙 1:21"> 天と地にあるすべての家族は、この方に由来してその名を与えられています。</span>
<span className="v" id="v16" data-v="16" data-xref="コロサイ人への手紙 1:11; ピリピ人への手紙 4:13; イザヤ書 40:29–31"> どうか父が、その栄光の豊かさにふさわしく、聖霊によって、あなたがたの内なる人を力強くしてくださいますように。</span>
<span className="v" id="v17" data-v="17" data-xref="コロサイ人への手紙 2:7; ヨハネの手紙第一 4:16; ヨハネ 14:23"> また、信仰によってキリストがあなたがたの心に住んでくださいますように。そして、あなたがたが愛に根を下ろし、愛を土台として、</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 103:11–12; ヨブ記 11:7–9; エペソ人への手紙 1:18–23"> すべての聖徒とともに、その広さ、長さ、高さ、深さがどれほどであるかを理解する力を与えられ、</span>
<span className="v" id="v19" data-v="19" data-xref="エペソ人への手紙 1:23; コロサイ人への手紙 2:9–10; コロサイ人への手紙 1:10"> 人の知識をはるかに超えるキリストの愛を知ることができますように。こうして、神の満ち満ちた豊かさのすべてにまで、あなたがたが満たされますように。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="コリント人への第二の手紙 9:8; ローマ人への手紙 4:21; エレミヤ書 32:27"> 私たちのうちに働く力によって、私たちが願うこと、思うことのすべてをはるかに超えて、限りなく豊かに実現することのできる方に、</span>
<span className="v" id="v21" data-v="21" data-xref="ユダ 1:25; ローマ人への手紙 11:36; ペテロの第二の手紙 3:18"> 教会とキリスト・イエスにおいて、すべての世代にわたり、世々限りなく栄光がありますように。アーメン。</span>
</div>

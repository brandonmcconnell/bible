<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 1:2; コリント人への第二の手紙 1:1; コリント人への第一の手紙 1:1–2"> 神の御心によってキリスト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「キリスト」は「油を注がれた者」という意味である。">a</a></sup>・イエスの使徒とされたパウロから、エペソにいる聖徒たち、すなわちキリスト・イエスにあって忠実な人々へ。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 1:7; ガラテヤ人への手紙 1:3; テトス 1:4"> 私たちの父なる神と主イエス・キリストから、恵みと平安があなたがたにありますように。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ペテロの手紙第一 1:3; コリント人への第二の手紙 1:3; エペソ人への手紙 2:6"> 私たちの主イエス・キリストの父なる神が、ほめたたえられますように。神は、キリストにあって、天上にあるあらゆる霊的な祝福をもって私たちを祝福してくださいました。</span>
<span className="v" id="v4" data-v="4" data-xref="テモテへの第二の手紙 1:9; ローマ人への手紙 8:28–30; エペソ人への手紙 2:10"> 神は世界の基が据えられる前から、御前で聖なる、傷のない者となるよう、愛のうちにキリストにあって私たちを選ばれました。</span>
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 8:29–30; エペソ人への手紙 1:11; ガラテヤ人への手紙 4:5–6"> そして御心の喜びに従い、イエス・キリストを通して私たちをご自分の子として迎えることを、あらかじめ定めてくださいました。</span>
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 3:22–26; エペソ人への手紙 1:12; コロサイ人への手紙 1:13"> それは、愛する御子にあって私たちに惜しみなく注いでくださった、栄光に満ちた恵みがほめたたえられるためです。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの手紙第一 2:24; ローマ人への手紙 3:24; ヨハネの手紙第一 1:7–9"> 私たちは御子にあって、その血による贖い、すなわち背きの赦しを受けています。これは神の豊かな恵みによるものです。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの黙示録 5:12; エペソ人への手紙 3:10; ローマ人への手紙 5:15"> 神はあらゆる知恵と分別をもって、この恵みを私たちにあふれるほど注ぎ、</span>
<span className="v" id="v9" data-v="9" data-xref="コロサイ人への手紙 1:26–28; ローマ人への手紙 16:25–27; エペソ人への手紙 3:3–9"> 御心の奥義を知らせてくださいました。それは、神が御心の喜びに従って、キリストにあってあらかじめ定めておられたものです。</span>
<span className="v" id="v10" data-v="10" data-xref="コロサイ人への手紙 1:20; ピリピ人への手紙 2:9–10; ガラテヤ人への手紙 4:4"> 時が満ちるに及んで実現されるそのご計画とは、天にあるものも地にあるものも、すべてをキリストにあって一つにまとめることです。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 8:28; ペテロの手紙第一 1:4; イザヤ書 46:10–11"> 私たちはキリストにあって相続を受ける者とされました。ご自分の御心の計画に従ってすべてを行われる方の目的により、あらかじめ定められていたのです。</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 1:6; エレミヤ書 17:5–7; エペソ人への手紙 1:13–14"> それは、先にキリストに望みを置いていた私たちが、神の栄光をほめたたえる者となるためです。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第二の手紙 1:22; エペソ人への手紙 4:30; テモテへの第二の手紙 2:19"> あなたがたもキリストにあって、真理の言葉、すなわち救いの福音を聞き、信じたとき、約束された聖霊によって証印を押されました。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第二の手紙 1:22; コリント人への第二の手紙 5:5; エペソ人への手紙 4:30"> 聖霊は、神の所有とされた民が贖われる日まで、私たちの相続を保証する手付です。それは、神の栄光がほめたたえられるためです。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="フィレモンへの手紙 1:5; コロサイ人への手紙 1:3–4; テサロニケ人への第二の手紙 1:3"> こういうわけで私も、主イエスに対するあなたがたの信仰と、すべての聖徒への愛を聞き、</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 1:8–9; コロサイ人への手紙 1:9; コロサイ人への手紙 1:3"> 絶えずあなたがたのために感謝し、祈りの中であなたがたを覚えています。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 11:2; ヤコブの手紙 3:17–18; コロサイ人への手紙 1:9–10"> どうか、私たちの主イエス・キリストの神、栄光の父が、ご自分を深く知るための知恵と啓示の霊を、あなたがたに与えてくださいますように。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 26:18; コリント人への第二の手紙 4:6; ルカ 24:45"> また、あなたがたの心の目<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="公認本文では「心」の代わりに「理解力」としている。">b</a></sup>が照らされ、神に召された者の望みがどのようなものか、聖徒たちのうちにある神の相続財産の栄光がどれほど豊かであるかを、知ることができますように。</span>
<span className="v" id="v19" data-v="19" data-xref="ピリピ人への手紙 2:13; エペソ人への手紙 3:20; コロサイ人への手紙 2:12"> また、信じる私たちに向けられた神の力が、どれほど計り知れず偉大であるかを知ることができますように。その力は、神の強大な御力の働きによるものです。</span>
<span className="v" id="v20" data-v="20" data-xref="ヘブル人への手紙 10:12; マルコ 16:19; 詩篇 110:1"> 神はその力をキリストに働かせ、キリストを死者の中からよみがえらせ、天上でご自分の右に座らせました。</span>
<span className="v" id="v21" data-v="21" data-xref="ピリピ人への手紙 2:9–11; コロサイ人への手紙 2:10; コロサイ人への手紙 1:15–16"> キリストは、あらゆる支配、権威、力、主権のはるか上に置かれ、この時代だけでなく来るべき時代においても、呼ばれるあらゆる名の上におられます。</span>
<span className="v" id="v22" data-v="22" data-xref="コロサイ人への手紙 1:18; コロサイ人への手紙 2:10; コリント人への第一の手紙 15:25–27"> 神はすべてをキリストの足の下に従わせ、教会のために、キリストをすべてのものの上に立つかしらとしてお与えになりました。</span>
<span className="v" id="v23" data-v="23" data-xref="コロサイ人への手紙 1:18–19; ヨハネ 1:16; コロサイ人への手紙 2:9–10"> 教会はキリストの体であり、すべてのものをあらゆるところに満たしておられる方が、満ち満ちておられるところです。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 2:13; エペソ人への手紙 2:5–6; コロサイ人への手紙 3:1–4"> 背きと罪のうちに死んでいたあなたがたを、神は生かしてくださいました。</span>
<span className="v" id="v2" data-v="2" data-xref="エペソ人への手紙 6:12; ヨハネの手紙第一 5:19; エペソ人への手紙 2:3"> かつてあなたがたは、その背きと罪の中を、この世の時代の流れに従い、空中の権力を握る支配者、すなわち今も不従順の子らのうちに働く霊に従って歩んでいました。</span>
<span className="v" id="v3" data-v="3" data-xref="テトス 3:3; エペソ人への手紙 4:22; ガラテヤ人への手紙 5:16–24"> 私たちも皆、かつては彼らの中にあって、肉の欲望のままに生き、肉と心の望むことを行っていました。そして、ほかの人々と同じように、生まれながら神の怒りを受けるべき者でした。</span>
<span className="v" id="v4" data-v="4" data-xref="ペテロの手紙第一 1:3; エペソ人への手紙 1:7; 詩篇 86:15"> しかし、あわれみに富む神は、私たちを愛してくださったその大きな愛のゆえに、</span>
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 3:24; エペソ人への手紙 2:8; ローマ人への手紙 5:10"> 背きのうちに死んでいた私たちを、キリストとともに生かしてくださいました。あなたがたが救われたのは、恵みによるのです。</span>
<span className="v" id="v6" data-v="6" data-xref="コロサイ人への手紙 3:1–3; エペソ人への手紙 1:3; ローマ人への手紙 6:4–5"> また、神は私たちをキリストとともによみがえらせ、キリスト・イエスにあって、ともに天上の領域に座らせてくださいました。</span>
<span className="v" id="v7" data-v="7" data-xref="テモテへの手紙第一 1:16–17; テトス 3:4; エペソ人への手紙 2:4"> それは、来るべき世々に、キリスト・イエスにあって私たちに示された慈しみにより、神の恵みの計り知れない豊かさを明らかにするためです。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 3:22–26; エペソ人への手紙 2:5; ローマ人への手紙 4:16"> あなたがたは、恵みにより、信仰を通して救われたのです。この救いはあなたがた自身から出たものではなく、神からの賜物です。</span>
<span className="v" id="v9" data-v="9" data-xref="テモテへの第二の手紙 1:9; ローマ人への手紙 11:6; テトス 3:3–5"> 行いによるのではありません。だれも誇ることがないためです。</span>
<span className="v" id="v10" data-v="10" data-xref="ピリピ人への手紙 2:13; コロサイ人への手紙 1:10; ヘブル人への手紙 13:21"> 私たちは神の作品であり、良い行いをするためにキリスト・イエスにあって造られました。その良い行いは、私たちがそれを行って生きるように、神が前もって備えてくださったものです。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="コロサイ人への手紙 2:11; コロサイ人への手紙 2:13; コロサイ人への手紙 3:11"> ですから、以前のことを覚えていなさい。肉によれば異邦人であるあなたがたは、肉体に人の手で施された、いわゆる「割礼」を受けた人々から「無割礼」と呼ばれていました。</span>
<span className="v" id="v12" data-v="12" data-xref="ガラテヤ人への手紙 4:8; コロサイ人への手紙 1:21; エレミヤ書 31:31–34"> そのころ、あなたがたはキリストから離れ、イスラエルの民の共同体から締め出され、約束にかかわる契約とは無縁のよそ者でした。この世で望みもなく、神もなく生きていたのです。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 2:39; コロサイ人への手紙 1:20–22; コロサイ人への手紙 1:13–14"> しかし今、キリスト・イエスにあって、以前は遠く離れていたあなたがたが、キリストの血によって近い者とされました。</span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 3:28; コロサイ人への手紙 3:11; コロサイ人への手紙 3:15"> キリストこそ私たちの平和です。キリストは両者を一つにし、隔てていた壁を打ち壊し、</span>
<span className="v" id="v15" data-v="15" data-xref="コロサイ人への手紙 2:14; ガラテヤ人への手紙 3:10; コロサイ人への手紙 1:21–22"> 敵意を生み出していた、さまざまな規定から成る戒めの律法を、ご自分の肉によって廃止されました。それは、両者をご自分にあって一人の新しい人に造り、平和を実現するため、</span>
<span className="v" id="v16" data-v="16" data-xref="コロサイ人への手紙 1:20–22; ローマ人への手紙 5:10; コリント人への第二の手紙 5:18–21"> また、十字架によって敵意を滅ぼし、両者を一つの体として神と和解させるためでした。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 57:19–21; 使徒の働き 10:36; ローマ人への手紙 5:1"> キリストは来られ、遠く離れていたあなたがたにも、近くにいた人々にも、平和の福音を告げ知らせました。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 12:13; エペソ人への手紙 3:12; ローマ人への手紙 5:2"> 私たちは両者とも、キリストを通して、一つの聖霊によって父に近づくことができるからです。</span>
<span className="v" id="v19" data-v="19" data-xref="ピリピ人への手紙 3:20; ヨハネの手紙第一 3:1; ガラテヤ人への手紙 6:10"> ですから、あなたがたはもはやよそ者でも外国人でもありません。聖徒たちと同じ国の民であり、神の家族なのです。</span>
<span className="v" id="v20" data-v="20" data-xref="ペテロの手紙第一 2:4–5; イザヤ書 28:16; ペテロの手紙第一 2:7–8"> あなたがたは、使徒たちと預言者たちを土台として建てられています。そして、キリスト・イエスご自身が隅のかしら石です。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第一の手紙 3:16–17; コリント人への第一の手紙 3:9; コリント人への第二の手紙 6:16"> キリストにあって建物全体が組み合わされ、成長して、主にある聖なる神殿となります。</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの手紙第一 2:4–5; コリント人への第一の手紙 3:16; ヨハネの手紙第一 4:16"> あなたがたもキリストにあってともに建て上げられ、聖霊によって神の住まいとなるのです。</span>

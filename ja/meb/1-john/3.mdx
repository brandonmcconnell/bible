<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネ 1:12; ガラテヤ人への手紙 3:26; コリント人への第二の手紙 6:18"> 父が私たちにどれほど大きな愛を与えてくださったか、考えてみなさい。私たちは神の子どもと呼ばれるのです。このため、世は私たちを知りません。世は父を知らなかったからです。</span>
<span className="v" id="v2" data-v="2" data-xref="ピリピ人への手紙 3:21; コロサイ人への手紙 3:4; コリント人への第一の手紙 13:12"> 愛する者たち、私たちは今、神の子どもです。私たちがどのようになるかは、まだ明らかにされていません。しかし、この方が現れるとき、私たちはこの方に似た者になると分かっています。ありのままのこの方を見るからです。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 7:1; ヨハネの手紙第一 2:6; ペテロの第二の手紙 3:14"> この望みをこの方に置く人は皆、この方が清いように、自分を清くします。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ヨハネの手紙第一 5:17; ローマ人への手紙 3:20; ローマ人への手紙 4:15"> 罪を犯す人は皆、不法を行っています。罪とは不法です。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 5:21; ヘブル人への手紙 9:28; ペテロの手紙第一 3:18"> あなたがたが知っているとおり、この方が現れたのは私たちの罪を取り除くためであり、この方のうちに罪はありません。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの手紙第三 1:11; ヨハネの手紙第一 2:4; ヨハネの手紙第一 3:9"> この方のうちにとどまる人はだれも、罪を犯しません。罪を犯す人はだれも、この方を見たことも、知ったこともありません。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨハネの手紙第一 2:29; ペテロの手紙第一 1:15–16; ローマ人への手紙 2:13"> 子どもたちよ、だれにも惑わされてはいけません。この方が正しいように、義を行う人も正しい者です。</span>
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 2:14; ヨハネ 8:44; コロサイ人への手紙 2:15"> 罪を犯す人は悪魔から出た者です。悪魔は初めから罪を犯しているからです。神の御子が現れたのは、悪魔のわざを滅ぼすためです。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの手紙第一 5:18; ペテロの手紙第一 1:23; ヨハネ 1:13"> 神から生まれた人はだれも、罪を犯しません。神の種がその人のうちにとどまっているからです。その人は神から生まれているので、罪を犯すことができません。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの手紙第一 4:8; ヨハネの手紙第三 1:11; ルカ 6:35"> 神の子どもと悪魔の子どもは、このことによって明らかになります。義を行わない人は神から出た者ではありません。自分の兄弟を愛さない人も同じです。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネ 15:12; ヨハネの手紙第二 1:5; ヨハネの手紙第一 4:7"> 私たちが互いに愛し合うべきだということ――これが、あなたがたが初めから聞いていた知らせです。</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 11:4; 創世記 4:4–15; 箴言 29:27"> 悪い者から出たカインのようであってはいけません。カインは自分の兄弟を殺しました。なぜ殺したのでしょうか。自分の行いが悪く、兄弟の行いが正しかったからです。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨハネ 15:18–19; ヨハネ 17:14; ルカ 21:17"> 私の兄弟たち、世があなたがたを憎んでも、驚いてはいけません。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネ 13:35; ヨハネの手紙第一 5:2; ヨハネの手紙第一 4:20–21"> 私たちは、死から命へ移ったことを知っています。兄弟たちを愛しているからです。兄弟を愛さない人は、死のうちにとどまっています。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイ 5:21–22; 箴言 26:24–26; ヨハネの黙示録 21:8"> 自分の兄弟を憎む人は皆、人殺しです。人殺しのうちには永遠の命がとどまっていないことを、あなたがたは知っています。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヨハネの手紙第一 4:9–11; エペソ人への手紙 5:2; ヨハネ 13:34"> この方が私たちのために命を捨ててくださったことによって、私たちは愛とは何かを知りました。ですから、私たちも兄弟たちのために命を捨てるべきです。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 13:16; イザヤ書 58:7–10; 申命記 15:7–11"> しかし、この世の財産を持ちながら、困っている兄弟を見ても、その人に対してあわれみの心を閉ざすなら、どうして神の愛がその人のうちにとどまるでしょうか。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヤコブの手紙 2:15–16; ローマ人への手紙 12:9; ペテロの手紙第一 1:22"> 私の子どもたちよ、ことばや口先だけではなく、行いと真実をもって愛しましょう。</span>
<span className="v" id="v19" data-v="19" data-xref="ヘブル人への手紙 10:22; ヨハネの手紙第一 3:21; ヘブル人への手紙 6:10–11"> それによって、私たちが真理から出た者であることが分かり、神の御前で自分の心を納得させることができます。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 139:1–4; エレミヤ書 17:10; ヘブル人への手紙 4:13"> たとえ自分の心が私たちを責めても、神は私たちの心よりも大きく、すべてのことをご存じだからです。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの手紙第一 2:28; ヘブル人への手紙 4:16; コリント人への第二の手紙 1:12"> 愛する者たち、自分の心が私たちを責めないなら、私たちは神に対して確信を持てます。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネ 15:7; ヨハネ 9:31; ヨハネの手紙第一 5:14"> そして、願い求めるものは何でも神から受けます。私たちが神の戒めを守り、御前で喜ばれることを行っているからです。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネ 6:29; ヨハネ 13:34; ペテロの手紙第一 1:22"> 神の戒めとは、その御子イエス・キリストの御名を信じ、神が命じられたとおり、互いに愛し合うことです。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第一の手紙 3:16; ヨハネの手紙第一 4:15–16; ヨハネの手紙第一 4:12–13"> 神の戒めを守る人は神のうちにとどまり、神もその人のうちにとどまります。神が私たちに与えてくださった聖霊によって、神が私たちのうちにとどまっておられることが分かります。</span>
</div>

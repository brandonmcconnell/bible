<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テモテへの手紙第一 2:5; ローマ人への手紙 8:34; ヨハネ 14:6"> 私の子どもたちよ、あなたがたが罪を犯さないように、私はこれらのことを書きます。しかし、だれかが罪を犯しても、私たちには父のもとに弁護者<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="ギリシャ語のπαρακλητονは、「助言者」「助け主」「仲裁者」「弁護者」「慰め主」という意味を持つ。">a</a></sup>がおられます。義なる方、イエス・キリストです。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの手紙第一 4:14; ペテロの手紙第一 3:18; ヨハネの手紙第一 4:10"> この方こそ、私たちの罪を贖ういけにえ<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「罪を贖ういけにえ」はギリシャ語のιλασμοςから来ており、神の怒りをなだめるもの、またはその手段、すなわち私たちの罪のために神の怒りを取り去るいけにえを意味する。">b</a></sup>です。私たちの罪だけでなく、全世界の罪のためのいけにえです。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネ 14:15; ヨハネ 15:10; ルカ 6:46"> その戒めを守っているなら、それによって私たちは、この方を知っていると分かります。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの手紙第一 1:6; テトス 1:16; ヤコブの手紙 2:14–16"> 「私はこの方を知っている」と言いながら、その戒めを守らない人は偽り者であり、その人のうちに真理はありません。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネ 14:23; ヨハネ 14:21; ヨハネの手紙第一 4:12–13"> しかし、この方のことばを守る人のうちでは、神の愛がまことに全うされています。それによって、私たちがこの方のうちにいることが分かります。</span>
<span className="v" id="v6" data-v="6" data-xref="ペテロの手紙第一 2:21; ヨハネ 13:15; コリント人への第一の手紙 11:1"> この方のうちにとどまっていると言う人は、この方が歩まれたように、自らも歩むべきです。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨハネの手紙第一 3:11; レビ記 19:18; マルコ 12:29–34"> 兄弟たち、私があなたがたに書いているのは、新しい戒めではなく、あなたがたが初めから持っていた古い戒めです。その古い戒めとは、あなたがたが初めから聞いていたことばです。</span>
<span className="v" id="v8" data-v="8" data-xref="エペソ人への手紙 5:8; ローマ人への手紙 13:12; ヨハネ 13:34"> また、私はあなたがたに新しい戒めを書いています。この戒めは、この方においても、あなたがたにおいても真実です。闇は過ぎ去りつつあり、まことの光がすでに輝いているからです。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの手紙第一 4:20; ヨハネの手紙第一 2:11; ヨハネの手紙第一 3:13–17"> 光の中にいると言いながら自分の兄弟を憎む人は、今もなお闇の中にいます。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの手紙第一 3:14; ローマ人への手紙 9:32–33; ローマ人への手紙 14:13"> 自分の兄弟を愛する人は光の中にとどまり、その人には、つまずきとなるものがありません。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネ 12:35; テトス 3:3; ヨハネの手紙第一 1:6"> しかし、自分の兄弟を憎む人は闇の中にいて、闇の中を歩み、自分がどこへ行くのか分かりません。闇がその目をくらませたからです。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 10:43; 使徒の働き 13:38; エペソ人への手紙 1:7"> 子どもたちよ、私があなたがたに書くのは、その御名のゆえに、あなたがたの罪が赦されているからです。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨハネ 14:7; ヨハネの手紙第一 2:14; ルカ 10:22"> 父たちよ、私があなたがたに書くのは、初めからおられる方をあなたがたが知っているからです。<br />若者たちよ、私があなたがたに書くのは、あなたがたが悪い者に打ち勝ったからです。<br />子どもたちよ、私があなたがたに書くのは、あなたがたが父を知っているからです。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="詩篇 119:11; ヨハネの手紙第一 2:13; コロサイ人への手紙 3:16"> 父たちよ、私があなたがたに書いたのは、初めからおられる方をあなたがたが知っているからです。<br />若者たちよ、私があなたがたに書いたのは、あなたがたが強く、神のことばがあなたがたのうちにとどまり、あなたがたが悪い者に打ち勝ったからです。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヤコブの手紙 4:4; ローマ人への手紙 12:2; マタイ 6:24"> 世も、世にあるものも愛してはいけません。世を愛する人のうちには、父の愛がありません。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 13:14; ガラテヤ人への手紙 5:17; 詩篇 119:36–37"> 世にあるすべてのもの、すなわち肉の欲、目の欲、この世のものを誇る心は、父から出たものではなく、世から出たものだからです。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイ 24:35; ローマ人への手紙 12:2; コリント人への第一の手紙 7:31"> 世とその欲は過ぎ去ります。しかし、神のみこころを行う人は永遠にとどまります。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨハネの手紙第一 4:3; ヨハネの手紙第二 1:7; マタイ 24:24"> 子どもたちよ、今は終わりの時です。反キリストが来るとあなたがたが聞いていたとおり、今や多くの反キリストが現れています。このことによって、今が最後の時だと分かります。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 20:30; コリント人への第一の手紙 11:19; ルカ 8:13"> 彼らは私たちのもとから出て行きましたが、私たちに属してはいませんでした。もし属していたなら、私たちとともにとどまっていたはずです。しかし彼らが出て行ったのは、そのだれも私たちに属していないことが明らかになるためでした。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネ 14:26; ヨハネの手紙第一 2:27; コリント人への第二の手紙 1:21–22"> しかし、あなたがたは聖なる方から油を注がれており、皆、知識を持っています。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="別訳「真実なことを知っています」、または「すべてのことを知っています」。">c</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの第二の手紙 1:12; ユダ 1:5; 箴言 1:5"> 私があなたがたに書いたのは、真理を知らないからではありません。あなたがたが真理を知り、また、どんな偽りも真理から出るものではないと知っているからです。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの手紙第二 1:7; ヨハネの手紙第一 4:3; ヨハネの手紙第一 2:18"> 偽り者とは、イエスがキリストであることを否定する者のほかに、だれでしょう。この者こそ反キリスト、父と御子を否定する者です。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの手紙第一 4:15; ヨハネ 8:19; ヨハネ 5:23"> 御子を否定する者は、父を持っていません。御子を告白する者は、父をも持っています。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="多数本文は「御子を告白する者は、父をも持っています」を省いている。">d</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヨハネ 14:23; ヨハネ 15:9–10; ヨハネの手紙第一 4:13"> ですから、あなたがたは、初めから聞いたことを自分のうちにとどめなさい。それがあなたがたのうちにとどまるなら、あなたがたも御子と父のうちにとどまります。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネ 10:28; テトス 3:7; ユダ 1:21"> これこそ、この方が私たちに約束してくださったもの、永遠の命です。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ペテロの第二の手紙 2:1–3; ヨハネの手紙第二 1:7; 使徒の働き 20:29–30"> あなたがたを惑わそうとする者たちについて、私はこれらのことを書きました。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネ 14:26; ヨハネの手紙第一 2:20–21; コリント人への第一の手紙 2:13"> あなたがたについて言えば、この方から受けた油注ぎがあなたがたのうちにとどまっているので、だれかに教えてもらう必要はありません。その油注ぎが、すべてのことについてあなたがたを教えます。それは真実であって、偽りではありません。それが教えたとおり、あなたがたはこの方のうちにとどまるでしょう。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヨハネの手紙第一 4:17; マルコ 8:38; ヨハネの手紙第一 3:2"> さあ、子どもたちよ、この方のうちにとどまりなさい。そうすれば、この方が現れるとき、私たちは確信を持ち、その来臨の時にも御前で恥じることがありません。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネ 3:3–5; ヨハネの手紙第一 3:7; ヨハネの手紙第一 5:1"> この方が正しいと知っているなら、義を行う者は皆、この方から生まれたことも分かります。</span>
</div>

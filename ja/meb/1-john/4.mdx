<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への手紙第一 5:21; ペテロの第二の手紙 2:1; テモテへの手紙第一 4:1"> 愛する者たち、すべての霊を信じてはいけません。その霊が神から出たものかどうかを吟味しなさい。多くの偽預言者が世に出て来ているからです。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネ 1:14; コリント人への第一の手紙 12:3; テモテへの手紙第一 3:16"> 神の霊は、こうして見分けられます。イエス・キリストが肉体をもって来られたと告白する霊は皆、神から出ています。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの手紙第一 2:22; ヨハネの手紙第二 1:7; ヨハネの手紙第一 2:18"> イエス・キリストが肉体をもって来られたと告白しない霊は皆、神から出たものではありません。それは反キリストの霊です。あなたがたは、それが来ると聞いていましたが、今すでに世に来ています。</span>
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 8:31; ヨハネの手紙第一 5:4; ローマ人への手紙 8:37"> 子どもたちよ、あなたがたは神から出た者であり、彼らに打ち勝っています。あなたがたのうちにおられる方は、世にいる者よりも偉大だからです。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネ 8:23; ペテロの第二の手紙 2:2–3; ヨハネ 17:14"> 彼らは世から出た者です。そのため、世のことを語り、世も彼らの言うことを聞きます。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 14:17; ヨハネ 10:27; コリント人への第一の手紙 2:12–14"> 私たちは神から出た者です。神を知る人は私たちの言うことを聞きます。神から出ていない人は聞きません。このことによって、真理の霊と迷いの霊を見分けることができます。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨハネの手紙第一 4:20–1; ヨハネの手紙第一 4:8; ペテロの手紙第一 1:22"> 愛する者たち、互いに愛し合いましょう。愛は神から出ているからです。愛する人は皆、神から生まれ、神を知っています。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの手紙第一 4:16; 詩篇 86:15; コリント人への第二の手紙 13:11"> 愛さない人は神を知りません。神は愛だからです。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネ 3:16; ヨハネの手紙第一 5:11; ローマ人への手紙 8:32"> 神は、ただひとりの御子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="直訳では「ただひとり生まれた」。この表現は、ギリシャ語のμονογενηから来ており、「ひとり子」または「ただひとりの者」と訳されることもある。">a</a></sup>を世に遣わしてくださいました。その方によって私たちが生きるためです。このことによって、神の愛が私たちのうちに現されました。</span>
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 2:4–5; ローマ人への手紙 5:8–10; ヨハネの手紙第一 4:19"> 愛とは、私たちが神を愛したことではなく、神が私たちを愛し、私たちの罪を贖ういけにえ<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「罪を贖ういけにえ」はギリシャ語のιλασμοςから来ており、神の怒りをなだめるもの、またはその手段、すなわち私たちの罪のために神の怒りを取り去るいけにえを意味する。">b</a></sup>として御子を遣わしてくださったことです。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネ 15:12–13; コロサイ人への手紙 3:13; ヨハネ 13:34"> 愛する者たち、神がこのように私たちを愛してくださったのなら、私たちも互いに愛し合うべきです。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネ 1:18; ヨハネの手紙第一 2:5; ヨハネの手紙第一 4:17–18"> いまだかつて、神を見た人はいません。私たちが互いに愛し合うなら、神は私たちのうちにとどまり、その愛が私たちのうちで全うされます。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="エペソ人への手紙 2:20–22; ヨハネの手紙第一 3:24; コリント人への第一の手紙 3:16–17"> 神がご自分の聖霊を私たちに分け与えてくださったことによって、私たちが神のうちにとどまり、神も私たちのうちにとどまっておられることが分かります。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの手紙第一 4:10; ヨハネ 3:16–17; ヨハネ 4:42"> 私たちは、父が御子を世の救い主として遣わされたのを見て、あかししています。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 10:9; ヨハネの手紙第一 5:5; マタイ 10:32"> イエスが神の御子であると告白する人はだれでも、神がその人のうちにとどまり、その人も神のうちにとどまります。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの手紙第一 3:24; 詩篇 36:7–9; ヨハネの手紙第一 3:1"> 私たちは、神が私たちに抱いておられる愛を知り、信じています。神は愛です。愛のうちにとどまる人は神のうちにとどまり、神もその人のうちにとどまります。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの手紙第一 4:12; ヨハネの手紙第一 2:28; ローマ人への手紙 8:29"> このように、愛は私たちの間で全うされ、裁きの日にも私たちは確信を持てます。この方がそうであるように、私たちもこの世にあって、この方のような者だからです。</span>
<span className="v" id="v18" data-v="18" data-xref="テモテへの第二の手紙 1:7; ローマ人への手紙 8:15; ヨハネの手紙第一 4:12"> 愛には恐れがありません。全うされた愛は恐れを締め出します。恐れは罰を伴うからです。恐れる人は、愛において全うされていません。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの手紙第一 4:10; ヨハネ 3:16; ヨハネ 15:16"> 神がまず私たちを愛してくださったので、私たちは神を愛します。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="ネストレ・アーラント／聖書協会共同本文は「神を」を省いている。">c</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの手紙第一 3:17; ヨハネの手紙第一 2:9; ヨハネの手紙第一 4:12"> 「私は神を愛している」と言いながら自分の兄弟を憎む人がいるなら、その人は偽り者です。目に見える兄弟を愛さない人が、目に見えない神を愛することはできないからです。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイ 22:37–39; レビ記 19:18; ヨハネの手紙第一 3:11"> 神を愛する人は自分の兄弟をも愛するべきです。これが、私たちが神から受けている戒めです。</span>

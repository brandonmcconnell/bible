<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ダニエル書 6:25; ペテロの手紙第一 1:2; ダニエル書 3:4"> ネブカドネザル王から、<br />全地に住む諸民族、諸国民、諸言語の者たちへ。<br />あなたがたに平安が豊かにあるように。</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="ダニエル書 3:26; 詩篇 66:16; 詩篇 71:18"> いと高き神が私になさったしるしと不思議を、私は告げ知らせようと思う。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 145:13; イザヤ書 25:1; ダニエル書 2:44"> <span className="pl pl-1">神のしるしは何と偉大であり、</span><br /><span className="pl pl-2">神の不思議は何と力強いことか。</span><br /><span className="pl pl-1">神の王国は永遠の王国、</span><br /><span className="pl pl-2">その支配は代々に及ぶ。</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 47:7–8; テサロニケ人への手紙第一 5:2–3; 詩篇 30:6–7"> 私ネブカドネザルは、自分の家で安らかに過ごし、宮殿で栄えていた。</span>
<span className="v" id="v5" data-v="5" data-xref="ダニエル書 2:1; ヨブ記 7:13–14; ダニエル書 2:28–29"> 私は一つの夢を見て恐れた。寝床での思いと、頭に浮かぶ幻が私をおびえさせた。</span>
<span className="v" id="v6" data-v="6" data-xref="ダニエル書 2:2; 創世記 41:7–8; イザヤ書 8:19"> そこで私は、夢の解き明かしを知らせさせるため、バビロンのすべての知者を私の前に連れて来るよう命令を出した。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 44:25; ダニエル書 2:7; 創世記 41:8"> 呪術師、まじない師、カルデア人、占い師たちが来たので、私は夢を彼らに話した。しかし彼らはその解き明かしを私に知らせることができなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="ダニエル書 1:7; ダニエル書 5:14; ダニエル書 4:18"> 最後にダニエルが私の前に来た。彼は私の神の名にちなんでベルテシャツァルと名づけられ、その内には聖なる神々の霊が宿っている。私は彼に夢を語って言った。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ダニエル書 2:48; ダニエル書 5:11; ダニエル書 4:8"> 「呪術師たちの長ベルテシャツァルよ、私は、聖なる神々の霊があなたの内にあり、どんな秘密もあなたには難しくないことを知っている。私が見た夢の幻と、その解き明かしを私に告げよ。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 12:2; ダニエル書 4:5; 詩篇 37:35–36"> 寝床で私の頭に浮かんだ幻はこうであった。見ていると、見よ、地の中央に一本の木があった。その木は非常に高かった。</span>
<span className="v" id="v11" data-v="11" data-xref="ダニエル書 4:21–22; 申命記 9:1; マタイ 11:23"> その木は成長して強くなり、高さは天に達し、地の果てからも見えた。</span>
<span className="v" id="v12" data-v="12" data-xref="ルカ 13:19; 哀歌 4:20; エゼキエル書 31:6–7"> 葉は美しく、実は豊かで、すべてのものを養う食物があった。野の獣はその下で陰を得、空の鳥はその枝に住み、すべての生き物がその木から養われた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命記 33:2; ダニエル書 8:13; ダニエル書 7:1"> 寝床で私の頭に浮かんだ幻の中で見ていると、見よ、一人の聖なる見張りの者が天から降りて来た。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイ 3:10; ダニエル書 4:23; エゼキエル書 31:12–13"> 彼は大声で叫んで言った。『その木を切り倒し、枝を切り落とせ。葉を振り落とし、実をまき散らせ。その下から獣を、枝から鳥を追い払え。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨブ記 14:7–9; ダニエル書 4:25–27; エゼキエル書 29:14–15"> ただし、根の切り株は地に残し、鉄と青銅の帯をかけて、野の若草の中に置け。天の露にぬれさせ、その者の分け前を地の草の中で獣とともにさせよ。</span>
<span className="v" id="v16" data-v="16" data-xref="ダニエル書 4:23; ヨハネの黙示録 12:14; ダニエル書 4:25"> その者の心を人の心から変え、獣の心を与えよ。こうして七つの時をその上に過ぎさせよ。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ダニエル書 4:25; ダニエル書 2:21; 詩篇 75:6–7"> この決定は見張りの者たちの定めによる。これは聖なる者たちの宣告である。生きている者たちが、いと高き方は人間の王国を支配し、御心にかなう者にそれを与え、人の中で最も低い者をその上に立てられることを知るためだ。』</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ダニエル書 5:15; 創世記 41:8; ダニエル書 5:8"> 私ネブカドネザル王が見た夢はこれである。ベルテシャツァルよ、その解き明かしを告げよ。私の王国の知者たちはだれも、その解き明かしを私に知らせることができない。しかし、あなたにはできる。聖なる神々の霊があなたの内にあるからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ダニエル書 8:27; ダニエル書 7:28; ダニエル書 4:24"> その時、ベルテシャツァルという名のダニエルは、しばらく呆然となり、その思いにおびえた。王は言った。「ベルテシャツァルよ、夢とその解き明かしにおびえるな。」<br />ベルテシャツァルは答えた。「わが主よ、その夢があなたを憎む者たちに、その解き明かしがあなたの敵たちに当てはまりますように。</span>
<span className="v" id="v20" data-v="20" data-xref="ダニエル書 4:10–12; エゼキエル書 31:3; エゼキエル書 31:16"> あなたがご覧になった木は成長して強くなり、その高さは天に達し、地の果てからも見えました。</span>
<span className="v" id="v21" data-v="21"> 葉は美しく、実は豊かで、すべてのものを養う食物がありました。その下には野の獣が住み、枝には空の鳥が住んでいました。</span>
<span className="v" id="v22" data-v="22" data-xref="ダニエル書 2:37–38; サムエル記第二 12:7; エレミヤ書 27:6–8"> 王よ、それはあなたです。あなたは成長して強くなられました。あなたの偉大さは増して天に達し、その支配は地の果てにまで及んでいます。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ダニエル書 5:21; ダニエル書 4:13–16"> 王は、一人の聖なる見張りの者が天から降りて来て、こう言うのをご覧になりました。『その木を切り倒して滅ぼせ。ただし、根の切り株は地に残し、鉄と青銅の帯をかけて、野の若草の中に置け。天の露にぬれさせ、七つの時がその上を過ぎるまで、その者の分け前を野の獣とともにさせよ。』</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="詩篇 107:40; ヨブ記 40:11–12; イザヤ書 46:10–11"> 王よ、その解き明かしはこうです。これは、わが主である王に下った、いと高き方の定めです。</span>
<span className="v" id="v25" data-v="25" data-xref="ダニエル書 4:17; エレミヤ書 27:5; 詩篇 83:18"> あなたは人々の中から追い出され、野の獣とともに住むことになります。牛のように草を食べさせられ、天の露にぬれます。そして七つの時があなたの上を過ぎます。ついにあなたは、いと高き方が人間の王国を支配し、御心にかなう者にそれをお与えになることを知るようになります。</span>
<span className="v" id="v26" data-v="26" data-xref="ダニエル書 4:15; マタイ 5:34; マタイ 21:20"> 木の根の切り株を残すよう命じられたのは、あなたが天の支配を認めた後、王国が再びあなたのものとして確立されるということです。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 55:6–7; ヨナ書 3:9; 使徒の働き 8:22"> ですから王よ、どうか私の勧めを受け入れてください。義を行って罪を捨て、貧しい者をあわれんで不義を離れてください。そうすれば、あなたの平穏が長く続くかもしれません。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="民数記 23:19; ゼカリヤ書 1:6; 箴言 10:24"> これらすべてのことがネブカドネザル王の身に起こった。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの黙示録 2:21; 伝道者の書 8:11; ペテロの手紙第一 3:20"> 十二か月後、王がバビロンの王宮の屋上を歩いていた時、</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 16:18; ヨハネの黙示録 18:10; ルカ 14:11"> 王は言った。「この大いなるバビロンは、私の力によって王の住まいとして建て、私の威光を示したものではないか。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="使徒の働き 9:3–5; ヨハネの黙示録 16:7; ルカ 12:20"> その言葉がまだ王の口にあるうちに、天から声があった。「ネブカドネザル王よ、あなたに告げる。王国はあなたから取り去られた。</span>
<span className="v" id="v32" data-v="32" data-xref="エレミヤ書 27:5; ダニエル書 5:21; 箴言 8:15–16"> あなたは人々の中から追い出され、野の獣とともに住むことになる。牛のように草を食べさせられ、七つの時があなたの上を過ぎる。ついにあなたは、いと高き方が人間の王国を支配し、御心にかなう者にそれをお与えになることを知る。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="ダニエル書 4:32; ダニエル書 4:25; ダニエル書 5:5"> その時すぐに、この言葉はネブカドネザルの身に実現した。彼は人々の中から追い出され、牛のように草を食べ、その体は天の露にぬれた。ついには、髪の毛は鷲の羽のように伸び、爪は鳥の爪のようになった。</span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="ヨハネの黙示録 4:10; エレミヤ書 10:10; ダニエル書 12:7"> その期間が終わると、私ネブカドネザルは目を天に上げ、理性が私に戻った。私はいと高き方をほめたたえ、永遠に生きておられる方を賛美し、あがめた。<br /><span className="pl pl-1">その支配は永遠の支配、</span><br /><span className="pl pl-2">その王国は代々に及ぶ。</span></span>
<span className="v" id="v35" data-v="35" data-xref="ヨブ記 42:2; 詩篇 135:6; 詩篇 115:3"> <span className="pl pl-1">地に住むすべての者は、無きに等しいものとみなされる。</span><br /><span className="pl pl-2">神は天の軍勢の中でも、</span><br /><span className="pl pl-2">地に住む者たちの間でも、御心のままに行われる。</span><br /><span className="pl pl-1">その手を押しとどめる者はなく、</span><br /><span className="pl pl-2">「何をしているのか」と問う者もいない。</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="ダニエル書 4:34; 箴言 22:4; ダニエル書 4:15–16"> その時、私の理性が戻った。王国の栄光とともに、威厳と輝きも私に戻った。顧問官と貴族たちは私を求め、私は再び王国に立てられ、以前にも増す偉大さが私に加えられた。</span>
<span className="v" id="v37" data-v="37" data-xref="ヤコブの手紙 4:6–7; 詩篇 33:4–5; ペテロの手紙第一 5:5–6"> 今、私ネブカドネザルは天の王を賛美し、あがめ、ほめたたえる。そのみわざはすべて真実、その道はすべて公正。高ぶって歩む者を低くすることがおできになる。</span>
</div>

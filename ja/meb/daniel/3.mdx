<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ハバクク書 2:19; エレミヤ書 16:20; イザヤ書 46:6"> ネブカドネザル王は金の像を造った。その高さは六十キュビト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一キュビトは、人の腕の中指の先から肘までの長さで、約十八インチ、または四十六センチメートルである。">a</a></sup>、幅は六キュビトであった。彼はそれをバビロン州のドラの平野に立てた。</span>
<span className="v" id="v2" data-v="2" data-xref="ダニエル書 3:27; 箴言 29:12; 列王記第一 12:32"> それからネブカドネザル王は、王が立てた像の奉献式に来させるため、地方総督、長官、総督、裁判官、財務官、顧問官、行政官、そして州のすべての支配者を召集するよう使いを送った。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 17:17; ヨハネの黙示録 17:13; ヨハネの黙示録 13:13–16"> そこで地方総督、長官、総督、裁判官、財務官、顧問官、行政官、そして州のすべての支配者が、ネブカドネザル王の立てた像の奉献式に集まり、その像の前に立った。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ダニエル書 4:1; ダニエル書 6:25; ミカ書 6:16"> その時、伝令が大声で叫んだ。「諸民族、諸国民、諸言語の者たちよ、あなたがたに命じる。</span>
<span className="v" id="v5" data-v="5" data-xref="ダニエル書 3:15; ダニエル書 3:10; ダニエル書 3:7"> 角笛、笛、ツィター、竪琴、ハープ、管楽器、そしてあらゆる楽器の音を聞いた時、ひれ伏して、ネブカドネザル王が立てた金の像を拝め。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイ 13:50; マタイ 13:42; エレミヤ書 29:22"> ひれ伏して拝まない者はだれでも、直ちに燃え盛る火の炉の中に投げ込まれる。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨハネの黙示録 17:8; ヨハネの黙示録 13:3; ヨハネの黙示録 13:8"> そこでその時、すべての民が角笛、笛、ツィター、竪琴、ハープ、管楽器、そしてあらゆる楽器の音を聞くと、諸民族、諸国民、諸言語の者たちは皆ひれ伏し、ネブカドネザル王が立てた金の像を拝んだ。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="エズラ記 4:12–16; ダニエル書 6:12–13; エステル記 3:8–9"> その時、あるカルデア人たちが進み出て、ユダヤ人たちを訴えた。</span>
<span className="v" id="v9" data-v="9" data-xref="ダニエル書 5:10; ダニエル書 6:6; ダニエル書 6:21"> 彼らはネブカドネザル王に言った。「王よ、永遠に生きられますように。</span>
<span className="v" id="v10" data-v="10" data-xref="ダニエル書 3:4–7; ダニエル書 6:12; エステル記 3:12–14"> 王よ、あなたは、角笛、笛、ツィター、竪琴、ハープ、管楽器、そしてあらゆる楽器の音を聞く者は皆、ひれ伏して金の像を拝まなければならない、</span>
<span className="v" id="v11" data-v="11"> ひれ伏して拝まない者は、燃え盛る火の炉の中に投げ込まれる、と命令を出されました。</span>
<span className="v" id="v12" data-v="12" data-xref="ダニエル書 6:13; ダニエル書 2:49; 使徒の働き 17:7"> ところが、あなたがバビロン州の行政に任命されたユダヤ人、シャデラク、メシャク、アベデ・ネゴがいます。王よ、この者たちはあなたを重んじず、あなたの神々に仕えず、あなたが立てた金の像を拝んでいません。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ダニエル書 3:19; ダニエル書 2:12; エステル記 3:5–6"> そこでネブカドネザルは怒りに燃え、激しく憤って、シャデラク、メシャク、アベデ・ネゴを連れて来るよう命じた。すると、この三人は王の前に連れて来られた。</span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 50:2; ダニエル書 3:1; イザヤ書 46:1"> ネブカドネザルは彼らに言った。「シャデラク、メシャク、アベデ・ネゴよ、あなたがたが私の神々に仕えず、私が立てた金の像を拝まないというのは本当か。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 5:29; 歴代誌 第二 32:15–17; 出エジプト記 5:2"> 今、角笛、笛、ツィター、竪琴、ハープ、管楽器、そしてあらゆる楽器の音を聞いた時、ひれ伏して私が造った像を拝むなら、それでよい。しかし拝まないなら、直ちに燃え盛る火の炉の中に投げ込まれる。私の手からあなたがたを救い出せる神がいるのか。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ダニエル書 1:7; ダニエル書 3:12"> シャデラク、メシャク、アベデ・ネゴは王に答えた。「ネブカドネザルよ、このことについて、私たちは弁明する必要はありません。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 8:31; ルカ 1:37; ヘブル人への手紙 7:25"> たとえ私たちが炉に投げ込まれても、私たちの仕える神は、燃え盛る火の炉から私たちを救い出すことがおできになります。王よ、神はあなたの手からも私たちを救い出してくださいます。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 5:29–32; マタイ 10:39; ヨハネの黙示録 2:10–11"> たとえそうでなくても、王よ、知っておいてください。私たちはあなたの神々には仕えず、あなたが立てた金の像も拝みません。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ダニエル書 3:13; レビ記 26:24; 箴言 21:24"> するとネブカドネザルは憤りに満ち、シャデラク、メシャク、アベデ・ネゴに対する顔つきが変わった。そして炉をいつもより七倍熱くするよう命じた。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 16:23; 使徒の働き 16:25; ダニエル書 3:15"> また軍隊の中の力の強い者たちに、シャデラク、メシャク、アベデ・ネゴを縛り、燃え盛る火の炉の中に投げ込むよう命じた。</span>
<span className="v" id="v21" data-v="21"> そこでこの三人は、下衣、上着、外套、そのほかの衣服を着たまま縛られ、燃え盛る火の炉の中に投げ込まれた。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 12:33; 箴言 21:18; 箴言 11:8"> 王の命令が厳しく、炉が非常に熱かったので、シャデラク、メシャク、アベデ・ネゴを引き立てて行った者たちは、火炎に焼き殺された。</span>
<span className="v" id="v23" data-v="23" data-xref="ダニエル書 6:16–17; エレミヤ書 38:6; 詩篇 34:19"> シャデラク、メシャク、アベデ・ネゴの三人は、縛られたまま燃え盛る火の炉の中に落ちた。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ダニエル書 6:7; ダニエル書 6:22; ダニエル書 3:9–10"> その時、ネブカドネザル王は驚いて急いで立ち上がり、顧問官たちに言った。「われわれは三人を縛って火の中に投げ込んだのではなかったか。」<br />彼らは王に答えた。「王よ、そのとおりです。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 43:2; 使徒の働き 28:5; マルコ 16:18"> 王は言った。「見よ、四人の者が縄を解かれ、火の中を歩いている。しかも何の害も受けていない。第四の者の姿は神々の子のようだ。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または「神の子」">b</a></sup>」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ダニエル書 3:17; イザヤ書 52:12; ヨハネの黙示録 19:5"> それからネブカドネザルは燃え盛る火の炉の口に近づき、言った。「いと高き神のしもべ、シャデラク、メシャク、アベデ・ネゴよ、出て来て、ここへ来なさい。」<br />するとシャデラク、メシャク、アベデ・ネゴは火の中から出て来た。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 43:2; ヘブル人への手紙 11:34; イザヤ書 26:11"> 地方総督、長官、総督、王の顧問官たちが集まり、この三人を見た。火は彼らの体に何の力も及ぼしていなかった。頭の毛一本も焦げず、衣服も損なわれず、火のにおいさえ付いていなかった。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ローマ人への手紙 14:7–8; 詩篇 34:7–8; 詩篇 84:11–12"> ネブカドネザルは言った。「シャデラク、メシャク、アベデ・ネゴの神はほめたたえられるように。神は御使いを遣わして、ご自分に信頼したしもべたちを救い出された。彼らは王の命令に背き、自分たちの神のほかには、どの神にも仕えず、拝まないために、その身を差し出した。</span>
<span className="v" id="v29" data-v="29" data-xref="ダニエル書 2:5; 詩篇 76:10; 申命記 32:31"> それゆえ私は命令を出す。どの民族、国民、言語の者であっても、シャデラク、メシャク、アベデ・ネゴの神を冒瀆する者は、手足を切り刻まれ、その家は汚物の山にされる。このように救い出すことのできる神は、ほかにいないからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ダニエル書 2:49; サムエル記第一 2:30; ダニエル書 3:12"> それから王は、シャデラク、メシャク、アベデ・ネゴをバビロン州でさらに高い地位に上げた。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ダニエル書 1:17; アモス書 3:7; ダニエル書 5:1"> バビロンの王ベルシャツァルの第一年に、ダニエルは寝床で夢を見、心に浮かぶ幻を見た。それから彼はその夢を書き記し、事の要点を語った。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 7:1; ヨハネの黙示録 17:15"> ダニエルは言った。「私は夜の幻の中で見ていた。見よ、天の四方の風が大海をかき立てていた。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 13:1; ダニエル書 7:17; ダニエル書 2:32–33"> すると、互いに異なる四頭の大きな獣が海から上って来た。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 4:7; イザヤ書 14:13–17; エゼキエル書 17:3"> 第一の獣は獅子のようで、鷲の翼を持っていた。私が見ていると、その翼は引き抜かれ、その獣は地から持ち上げられ、人のように二本の足で立たされた。そして人の心が与えられた。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ダニエル書 2:39; イザヤ書 13:17–18; 箴言 17:12"> 見よ、熊のような第二の獣が現れた。それは体の片側を持ち上げ、口の歯の間に三本の肋骨をくわえていた。その獣にこう告げる声があった。『立ち上がり、多くの肉を食らえ。』</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 13:2; ダニエル書 8:20–22; ダニエル書 8:5–8"> その後、私が見ていると、見よ、豹のような別の獣が現れた。その背には鳥の翼が四つあり、頭も四つあった。そしてその獣に支配権が与えられた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨハネの黙示録 13:1; ヨハネの黙示録 12:3; ヨハネの黙示録 17:12"> その後、夜の幻の中で私が見ていると、見よ、第四の獣が現れた。それは恐ろしく、力強く、非常に強かった。大きな鉄の歯を持ち、食らい、かみ砕き、残ったものを足で踏みつけた。それまでのすべての獣とは異なり、十本の角を持っていた。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="ヨハネの黙示録 13:5–6; ヨハネの黙示録 13:1; 詩篇 12:3"> 私がその角をよく見ていると、見よ、その間からもう一本の小さな角が出て来た。その前で、最初の角のうち三本が根こそぎ抜かれた。見よ、その角には人の目のような目があり、傲慢なことを語る口があった。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 1:14; マルコ 9:3; ダニエル書 7:13"> <span className="pl pl-1">私が見ていると、幾つもの王座が据えられ、</span><br /><span className="pl pl-2">年を経た方が座られた。</span><br /><span className="pl pl-1">その衣は雪のように白く、</span><br /><span className="pl pl-2">頭の毛は純粋な羊毛のようであった。</span><br /><span className="pl pl-1">その王座は燃える炎であり、</span><br /><span className="pl pl-2">その車輪は燃え盛る火であった。</span></span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 30:27; 申命記 33:2; ヨハネの黙示録 20:11–15"> <span className="pl pl-1">火の川が流れ出て、</span><br /><span className="pl pl-2">その方の前から進み出た。</span><br /><span className="pl pl-1">幾千もの者がその方に仕え、</span><br /><span className="pl pl-2">幾万もの者がその前に立っていた。</span><br /><span className="pl pl-1">法廷が開かれ、</span><br /><span className="pl pl-2">数々の書物が開かれた。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 19:20; ヨハネの黙示録 20:10; テサロニケ人への第二の手紙 2:8"> その時、私は角が語る傲慢な言葉の声を聞きながら見続けた。ついにその獣は殺され、その体は滅ぼされ、燃える火に投げ込まれた。</span>
<span className="v" id="v12" data-v="12" data-xref="ダニエル書 8:7; ダニエル書 7:4–6"> ほかの獣たちからも支配権は取り去られた。しかし、その命は定められた時と期間だけ延ばされた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マタイ 26:64; ヨハネの黙示録 1:7; ルカ 21:27"> 私が夜の幻の中で見ていると、見よ、人の子のような者が天の雲とともに来た。その方は年を経た方のもとに進み、その前に導かれた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの黙示録 11:15; ダニエル書 7:27; ヨハネ 3:35"> その方には支配と栄光と王国が与えられ、すべての民族、国民、言語の者たちがその方に仕えることになった。その支配は過ぎ去ることのない永遠の支配であり、その王国は滅ぼされることがない。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ダニエル書 7:28; エレミヤ書 17:16; 創世記 40:7–8"> 私ダニエルは、霊が内で苦しみ、心に浮かぶ幻に悩まされた。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 7:13–14; ゼカリヤ書 2:3; ヨハネの黙示録 5:5"> 私は、そばに立っていた者の一人に近づき、これらすべてのことの真相を尋ねた。<br />すると彼は私に告げ、その意味を知らせた。</span>
<span className="v" id="v17" data-v="17" data-xref="ダニエル書 8:19–22; ダニエル書 2:37–40; ヨハネ 18:36"> 『この四頭の大きな獣は、地から起こる四人の王である。</span>
<span className="v" id="v18" data-v="18" data-xref="ダニエル書 7:27; イザヤ書 60:12–14; ヨハネの黙示録 5:10"> しかし、いと高き方の聖なる者たちが王国を受け、永遠に、まさに世々限りなく、その王国を所有する。』</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ダニエル書 7:7; ダニエル書 2:40–43"> それから私は、ほかのすべての獣とは異なり、非常に恐ろしかった第四の獣について真実を知りたいと願った。その歯は鉄、爪は青銅で、食らい、かみ砕き、残ったものを足で踏みつけていた。</span>
<span className="v" id="v20" data-v="20" data-xref="ダニエル書 7:23; ダニエル書 7:8; ダニエル書 7:11"> また、その頭にあった十本の角と、後から出て来て、その前で三本の角が倒れた、もう一本の角についても知りたいと願った。その角には目と、傲慢なことを語る口があり、その姿はほかの角よりも大きかった。</span>
<span className="v" id="v21" data-v="21" data-xref="ダニエル書 12:7; ヨハネの黙示録 17:14; ダニエル書 8:24"> 私が見ていると、その角は聖なる者たちと戦い、彼らに打ち勝った。</span>
<span className="v" id="v22" data-v="22" data-xref="ダニエル書 7:18; ヨハネの黙示録 20:4; ヨハネの黙示録 5:10"> しかし、年を経た方が来られ、いと高き方の聖なる者たちのために裁きが下された。そして聖なる者たちが王国を所有する時が来た。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ダニエル書 2:40; ダニエル書 7:7; ルカ 2:1"> 彼はこう言った。『第四の獣は、地上に起こる第四の王国である。それはほかのすべての王国とは異なり、全地を食らい、踏みにじり、打ち砕く。</span>
<span className="v" id="v24" data-v="24" data-xref="ダニエル書 7:20; ダニエル書 11:36; ヨハネの黙示録 13:1"> 十本の角は、この王国から起こる十人の王である。その後にもう一人の王が起こる。彼は前の王たちとは異なり、三人の王を屈服させる。</span>
<span className="v" id="v25" data-v="25" data-xref="ダニエル書 12:7; ヨハネの黙示録 12:14; テサロニケ人への第二の手紙 2:4"> 彼はいと高き方に逆らう言葉を語り、いと高き方の聖なる者たちを苦しめ、疲れ果てさせる。彼は時と律法を変えようと企てる。聖なる者たちは、一つの時、二つの時、そして半分の時の間、彼の手に渡される。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ヨハネの黙示録 20:10–11; テサロニケ人への第二の手紙 2:8; ヨハネの黙示録 11:13"> しかし、法廷が開かれ、彼の支配は取り去られ、ついには完全に消し去られ、滅ぼされる。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 72:11; ルカ 1:33; ヨハネの黙示録 11:15"> 王国と支配と、全天下の王国の偉大さは、いと高き方の聖なる者たちの民に与えられる。その方の王国は永遠の王国であり、すべての支配者はその方に仕え、従う。』</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ルカ 2:19; ルカ 2:51; ダニエル書 10:8"> この事はここで終わった。私ダニエルは、自分の思いにひどく悩まされ、顔色が変わった。しかし、この事を心に留めておいた。」</span>
</div>

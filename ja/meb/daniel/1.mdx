<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌 第二 36:5–7; 列王記第二 24:1–2; 列王記第二 24:13"> ユダの王エホヤキムの治世の第三年に、バビロンの王ネブカドネザルがエルサレムに攻めて来て、これを包囲した。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代誌 第二 36:7; ゼカリヤ書 5:11; エレミヤ書 27:19–20"> 主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「主」と訳された言葉は「アドナイ」である。">a</a></sup>は、ユダの王エホヤキムと、神<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「神」と訳されたヘブル語は「אֱלֹהִים」（エロヒム）である。">b</a></sup>の宮の器の一部を、ネブカドネザルの手に渡された。ネブカドネザルはそれらをシンアルの地にある自分の神の宮へ運び、その神の宝物庫に納めた。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 39:7; 列王記第二 20:17–18; 列王記第二 24:15"> 王は宦官の長アシュペナズに命じ、イスラエルの子らの中から、王族<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="または「子孫」">c</a></sup>と貴族に属する者たちを連れて来させた。</span>
<span className="v" id="v4" data-v="4" data-xref="ダニエル書 5:11; 使徒の働き 7:22; 箴言 22:29"> それは、体に何の欠陥もなく、容姿が良く、あらゆる知恵に通じ、知識と学識を備え、王宮に仕える能力のある若者たちであった。アシュペナズは彼らにカルデア人の学問と言語を教えることになった。</span>
<span className="v" id="v5" data-v="5" data-xref="ダニエル書 1:19; 列王記第一 10:8; ダニエル書 1:8"> 王は、王のごちそうと王が飲むぶどう酒から、彼らの毎日の分を定めた。彼らを三年間養い、その期間が終わると王の前に立たせるためであった。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 14:14; マタイ 24:15; ダニエル書 2:17"> 彼らの中には、ユダの子らであるダニエル、ハナニヤ、ミシャエル、アザリヤがいた。</span>
<span className="v" id="v7" data-v="7" data-xref="ダニエル書 5:12; ダニエル書 4:8; ダニエル書 2:49"> 宦官の長は彼らに新しい名を与えた。ダニエルにはベルテシャツァル、ハナニヤにはシャデラク、ミシャエルにはメシャク、アザリヤにはアベデ・ネゴという名を与えた。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="詩篇 141:4; エゼキエル書 4:13–14; レビ記 11:45–47"> しかしダニエルは、王のごちそうや王が飲むぶどう酒によって自分を汚すまいと心に決めた。それで、自分を汚さずに済むよう、宦官の長に願い出た。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 39:21; 箴言 16:7; 詩篇 106:46"> 神はダニエルが宦官の長から好意とあわれみを受けるようにされた。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイ 6:16–18; ヨハネ 12:42–43; 箴言 29:25"> 宦官の長はダニエルに言った。「私は、あなたがたの食べ物と飲み物を定めた、わが主である王を恐れている。王が、あなたがたの顔色が同じ年ごろの若者たちよりも悪いのをご覧になれば、あなたがたのせいで私の首が危うくなる。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> そこでダニエルは、宦官の長がダニエル、ハナニヤ、ミシャエル、アザリヤの世話係として任命した者に言った。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 14:2; ダニエル書 1:16; 創世記 1:29–30"> 「どうか、十日間あなたのしもべたちを試してください。私たちには野菜を食べさせ、水を飲ませてください。</span>
<span className="v" id="v13" data-v="13"> その後、私たちの顔色と、王のごちそうを食べている若者たちの顔色とを、あなたの前で比べてください。そして、あなたがご覧になったとおりに、しもべたちを扱ってください。」</span>
<span className="v" id="v14" data-v="14"> 監督はこの件について彼らの言うことを聞き、十日間彼らを試した。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 23:25; 箴言 10:22; 列王記第二 4:42–44"> 十日が終わると、彼らの顔色は、王のごちそうを食べていたどの若者よりも良く、肉付きもよかった。</span>
<span className="v" id="v16" data-v="16" data-xref="ダニエル書 1:12"> そこで世話係は、彼らに与えられていたごちそうとぶどう酒を取り上げ、代わりに野菜を与えた。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王記第一 3:12; ヤコブの手紙 1:5; ダニエル書 2:21"> 神はこの四人の若者に、あらゆる学問と知恵についての知識と理解力を与えられた。またダニエルには、あらゆる幻と夢を悟る力があった。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ダニエル書 1:5"> 王が彼らを連れて来るよう定めた期間が終わると、宦官の長は彼らをネブカドネザルの前に連れて来た。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 22:29; 創世記 41:46; ダニエル書 1:5"> 王が彼らと話してみると、そのすべての者の中で、ダニエル、ハナニヤ、ミシャエル、アザリヤに並ぶ者は一人もいなかった。それで彼らは王の前に仕えることになった。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 8:19; イザヤ書 47:12–14; 列王記第一 4:29–34"> 王が彼らに尋ねた知恵と理解に関するあらゆる事柄において、王は、彼らが王国全土のすべての呪術師やまじない師より十倍も優れていることを認めた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ダニエル書 6:28; ダニエル書 10:1"> ダニエルはキュロス王の第一年まで仕え続けた。</span>
</div>
</div>

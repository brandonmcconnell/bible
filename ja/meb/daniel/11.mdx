<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ダニエル書 9:1; ダニエル書 5:31; ダニエル書 10:18"> 私も、メディア人ダリヨスの第一年に、彼を支え、力づけるために立ち上がった。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="エズラ記 4:5–6; ダニエル書 8:26; ヨハネの黙示録 21:5"> 今、私はあなたに真実を告げる。見よ、さらに三人の王がペルシアに起こる。第四の王は、彼らすべてよりもはるかに富む。彼はその富によって強くなると、すべての者を奮い立たせてギリシア王国に立ち向かわせる。</span>
<span className="v" id="v3" data-v="3" data-xref="ダニエル書 11:16; ダニエル書 11:36; ダニエル書 8:21"> 一人の力ある王が起こり、大きな支配権をもって治め、思いのままに行う。</span>
<span className="v" id="v4" data-v="4" data-xref="ダニエル書 8:22; ダニエル書 8:8; エレミヤ書 12:17"> しかし、彼が立ち上がると、その王国は砕かれ、天の四方に分けられる。それは彼の子孫には継がれず、彼が治めた時の支配権を保つこともない。彼の王国は根こそぎにされ、彼ら以外の者たちに与えられるからである。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ダニエル書 11:14; ダニエル書 11:11; ダニエル書 11:25"> 南の王は強くなる。しかし、その将軍の一人が彼よりも強くなって支配し、その支配は大きな支配となる。</span>
<span className="v" id="v6" data-v="6" data-xref="ダニエル書 11:13; ダニエル書 11:40; ダニエル書 11:7"> 数年の後、両者は同盟を結ぶ。南の王の娘が和解を図って北の王のもとへ行く。しかし彼女は腕の力を保てず、王もその力を保てない。彼女は、自分を連れて来た者たち、自分を生んだ者、その時に彼女を支えた者とともに引き渡される。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ダニエル書 11:38–39; ダニエル書 11:19–20; イザヤ書 9:14"> しかし、彼女の根から出た一人が、彼女に代わって立つ。彼は軍隊を率いて進み、北の王の要塞に入り、彼らに立ち向かって勝利する。</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 37:19; イザヤ書 46:1–2; エレミヤ書 43:12–13"> 彼らの神々、鋳造された像、銀と金の美しい器をも捕らえてエジプトへ運び去る。そして数年の間、北の王に手を出さない。</span>
<span className="v" id="v9" data-v="9"> 北の王は南の王の国に攻め入るが、自分の国へ帰る。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 51:42; ダニエル書 11:7; ダニエル書 11:26"> その息子たちは戦いを起こし、大軍を集める。その軍勢は押し寄せ、あふれて通り過ぎる。さらに進んで、北の王の要塞にまで戦いを及ぼす。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ダニエル書 8:7; ダニエル書 11:5; 詩篇 33:16–17"> 南の王は怒りに駆られて出陣し、北の王と戦う。北の王は大軍を繰り出すが、その大軍は南の王の手に渡される。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 12:22–23; 列王記第二 14:10; イザヤ書 10:7–12"> その大軍が連れ去られると、南の王の心は高ぶる。彼は幾万もの者を倒すが、勝利を保つことはできない。</span>
<span className="v" id="v13" data-v="13" data-xref="ダニエル書 4:16; ダニエル書 12:7; ダニエル書 11:6–7"> 北の王は再び戻り、以前よりも大きな軍勢を繰り出す。数年の時が過ぎた後、大軍と豊富な物資を携えて進軍する。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ヨハネの黙示録 17:17; 使徒の働き 4:25–28"> その時、多くの者が南の王に立ち向かう。あなたの民の中の暴虐な者たちも、幻を実現しようとして立ち上がるが、倒れる。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 6:6; エゼキエル書 17:17; エゼキエル書 4:2"> 北の王は進軍して土塁を築き、堅固な町を攻め取る。南の軍勢は持ちこたえられず、精鋭部隊にも立ち向かう力はない。</span>
<span className="v" id="v16" data-v="16" data-xref="ダニエル書 8:9; ダニエル書 11:36; ダニエル書 11:3"> 北の王に攻めかかる者は思いのままに行い、彼の前に立ちはだかる者はいない。彼は麗しい地に立ち、滅びがその手にある。</span>
<span className="v" id="v17" data-v="17" data-xref="列王記第二 12:17; エゼキエル書 4:3; エゼキエル書 4:7"> 彼は王国全体の力をもって進もうと決意し、和解の条件を携えて来る。王国を滅ぼそうとして、自分の娘を妻として相手に与える。しかし彼女は彼のために立たず、彼のものにもならない。</span>
<span className="v" id="v18" data-v="18" data-xref="ホセア書 12:14; エレミヤ書 31:10; ゼパニヤ書 2:11"> その後、彼は島々に向かい、多くを攻め取る。しかし一人の司令官が、彼から受けたそしりをやめさせ、それを彼自身に返す。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 26:21; 詩篇 37:36; ヨブ記 20:8"> それから彼は自国の要塞に顔を向けるが、つまずいて倒れ、姿を消す。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 60:17; ダニエル書 11:7; 申命記 15:2–3"> 彼の地位には、王国の栄光ある地に徴税官を行き巡らせる者が立つ。しかし数日のうちに彼は滅ぼされる。それは怒りによるのでも、戦いによるのでもない。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ダニエル書 11:34; ダニエル書 8:25; 士師記 9:1–20"> 彼の地位には、王位の尊厳を与えられていなかった卑しむべき者が立つ。彼は人々が安心している時に来て、へつらいによって王国を手に入れる。</span>
<span className="v" id="v22" data-v="22" data-xref="ダニエル書 8:10–11; ダニエル書 11:10; ダニエル書 9:26"> あふれるような軍勢は彼の前から押し流され、打ち砕かれる。契約の君もまた打ち砕かれる。</span>
<span className="v" id="v23" data-v="23" data-xref="ダニエル書 8:25; テサロニケ人への第二の手紙 2:9; 詩篇 52:2"> 彼は同盟を結んだ後も欺きを行い、わずかな民を率いて上り、力を増す。</span>
<span className="v" id="v24" data-v="24" data-xref="ダニエル書 7:25; 箴言 23:7; マタイ 9:4"> 人々が安心している時、彼は州の最も豊かな所にまで入り込む。彼は父祖たちも、そのまた父祖たちも行わなかったことを行う。獲物、略奪品、財宝を人々に分け与える。また要塞に対して策略を巡らすが、それは定められた時までである。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="箴言 15:18; ダニエル書 11:2; 箴言 28:25"> 彼は力と勇気を奮い起こし、大軍を率いて南の王に立ち向かう。南の王も非常に大きく強い軍勢を率いて戦うが、持ちこたえることができない。人々が彼に対して策略を巡らすからである。</span>
<span className="v" id="v26" data-v="26" data-xref="ダニエル書 11:10; ダニエル書 11:40; サムエル記第二 4:2–12"> 彼のごちそうを食べる者たちが彼を滅ぼし、その軍勢は押し流され、多くの者が殺されて倒れる。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 12:2; エレミヤ書 9:3–5; ハバクク書 2:3"> この二人の王は、どちらも心に悪を抱き、同じ食卓で偽りを語り合う。しかし成功しない。終わりはなお、定められた時に来るからである。</span>
<span className="v" id="v28" data-v="28" data-xref="ダニエル書 11:30–32; ダニエル書 8:24; 使徒の働き 3:25"> それから北の王は多くの財宝を携えて自国へ帰る。その心は聖なる契約に逆らい、思うままに行った後、自国へ帰る。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 17:26; イザヤ書 14:31; ダニエル書 11:25"> 定められた時に、彼は再び南へ攻め入る。しかし今度は、以前の時のようにはならない。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 10:4; 民数記 24:24; エレミヤ書 2:10"> キティムの船が彼に立ち向かうので、彼は落胆して引き返す。そして聖なる契約に憤りを抱き、思うままに行う。彼は引き返し、聖なる契約を捨てる者たちに目を留める。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ダニエル書 12:11; ダニエル書 9:27; マタイ 24:15"> 彼から出た軍勢が、要塞である聖所を汚し、絶えずささげられる全焼のささげ物を取り去る。そして荒廃をもたらす忌まわしいものを立てる。</span>
<span className="v" id="v32" data-v="32" data-xref="歴代誌上 28:9; 詩篇 9:10; ヨハネ 17:3"> 彼は、契約に背いて悪を行う者たちをへつらいによって堕落させる。しかし、自分たちの神を知る民は堅く立ち、事を行う。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="マタイ 24:9; ヨハネ 16:2; マラキ書 2:7"> 民の中の悟りある者たちは、多くの者に理解を与える。しかし彼らは長い間、剣と炎、捕囚と略奪によって倒れる。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイ 7:15; ローマ人への手紙 16:18; 使徒の働き 20:29–30"> 彼らが倒れる時、わずかな助けを受ける。しかし多くの者が、偽りをもって彼らに加わる。</span>
<span className="v" id="v35" data-v="35" data-xref="ゼカリヤ書 13:9; マラキ書 3:2–4; ヨハネの黙示録 2:10"> 悟りある者たちの中にも倒れる者がいる。それは彼らが練られ、清められ、白くされるためであり、終わりの時まで続く。その時はなお、定められた時に来るからである。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="ヨハネの黙示録 13:5–6; テサロニケ人への第二の手紙 2:4; 申命記 10:17"> その王は思いのままに行う。自らを高くし、あらゆる神よりも自分を大いなるものとし、神々の神に逆らって驚くべきことを語る。彼は憤りが成し遂げられるまで成功する。定められたことが行われるからである。</span>
<span className="v" id="v37" data-v="37" data-xref="テサロニケ人への第二の手紙 2:4; イザヤ書 14:13; テモテへの手紙第一 4:3"> 彼は父祖たちの神々にも、女たちが慕うものにも、どの神にも心を留めない。自らをすべてのものよりも大いなるものとするからである。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネの黙示録 17:1–5; イザヤ書 44:9; ヨハネの黙示録 13:12–17"> その代わりに、彼は要塞の神をあがめる。父祖たちの知らなかった神を、金、銀、宝石、貴重な品々をもってあがめる。</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネの黙示録 18:9–13"> 彼は異国の神を頼みとして、最も堅固な要塞を攻める。彼を認める者には大きな栄誉を与え、多くの者を治めさせ、報酬として土地を分配する。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="ダニエル書 11:35; ダニエル書 11:10; イザヤ書 5:28"> 終わりの時に、南の王が彼と争う。北の王は戦車、騎兵、多くの船を率い、つむじ風のように彼に攻めかかる。彼は国々に侵入し、あふれて通り過ぎる。</span>
<span className="v" id="v41" data-v="41" data-xref="エレミヤ書 48:47; エレミヤ書 49:6; イザヤ書 11:13–15"> 彼は麗しい地にも侵入し、多くの国々が倒される。しかしエドム、モアブ、アンモンの子らの主だった者たちは、彼の手から逃れる。</span>
<span className="v" id="v42" data-v="42" data-xref="ゼカリヤ書 10:10–11; エゼキエル書 29:14; ヨハネの黙示録 11:8"> 彼は諸国に手を伸ばし、エジプトの地も逃れられない。</span>
<span className="v" id="v43" data-v="43" data-xref="歴代誌 第二 12:3; ナホム書 3:9; エゼキエル書 30:4–5"> 彼はエジプトの金銀の財宝と、すべての貴重な品々を支配する。リビア人とエチオピア人も彼の後に従う。</span>
<span className="v" id="v44" data-v="44" data-xref="ヨハネの黙示録 19:19–21; ヨハネの黙示録 16:12; ヨハネの黙示録 17:13"> しかし東と北からの知らせが彼を悩ませる。彼は激しい怒りをもって出て行き、多くの者を滅ぼし尽くそうとする。</span>
<span className="v" id="v45" data-v="45" data-xref="テサロニケ人への第二の手紙 2:4; ダニエル書 8:25; ヨハネの黙示録 19:19–21"> 彼は海と麗しい聖なる山との間に王の天幕を張る。しかし、ついに終わりを迎え、彼を助ける者はいない。</span>
</div>

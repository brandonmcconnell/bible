<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ダニエル書 11:4; ダニエル書 9:2; ダニエル書 7:28"> ベルシャツァル王の治世の第三年に、私ダニエルに幻が現れた。それは初めに現れた幻の後のことであった。</span>
<span className="v" id="v2" data-v="2" data-xref="エステル記 1:2; ネヘミヤ記 1:1; 創世記 10:22"> 私は幻を見た。幻の中で、私はエラム州にあるスサの城塞にいた。そして私はウライ川のほとりにいた。</span>
<span className="v" id="v3" data-v="3" data-xref="ダニエル書 8:20; ダニエル書 10:5; ゼカリヤ書 6:1"> 私が目を上げて見ると、見よ、二本の角を持つ一頭の雄羊が川辺に立っていた。二本の角は高かったが、一方は他方より高く、その高い角は後から伸びた。</span>
<span className="v" id="v4" data-v="4" data-xref="ダニエル書 11:16; ダニエル書 11:36; ダニエル書 8:7"> 私は、その雄羊が西、北、南に向かって突き進むのを見た。どの獣もその前に立つことができず、その手から救い出せる者もいなかった。雄羊は思いのままに振る舞い、自らを大いなるものとした。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ダニエル書 8:21; ダニエル書 11:3; ダニエル書 8:8"> なお見つめていると、見よ、一頭の雄やぎが西から全地の表を進んで来たが、地面には触れなかった。その雄やぎには、両目の間に目立つ一本の角があった。</span>
<span className="v" id="v6" data-v="6"> 雄やぎは、二本の角を持ち川辺に立っていた雄羊のところへ来て、激しい勢いで突進した。</span>
<span className="v" id="v7" data-v="7" data-xref="ダニエル書 7:7; ダニエル書 11:11; ヨシュア記 8:20"> 私が見ていると、雄やぎは雄羊に近づき、激しい怒りを燃やして雄羊を打ち、その二本の角を折った。雄羊にはその前に立つ力がなく、雄やぎは雄羊を地に投げ倒して踏みつけた。雄羊をその手から救い出せる者はいなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="ダニエル書 7:2; ヨハネの黙示録 7:1; ダニエル書 5:20"> 雄やぎは自らを非常に大いなるものとした。しかし、強くなった時、その大きな角は折れ、その代わりに目立つ四本の角が天の四方に向かって伸びた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ダニエル書 11:16; エゼキエル書 20:6; エゼキエル書 20:15"> そのうちの一本から小さな角が出て、南と東と麗しい地に向かって非常に大きく成長した。</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 14:13; ヨハネの黙示録 12:4; ダニエル書 8:7"> それは天の軍勢にまで達するほど大きくなり、軍勢の一部と星の一部を地に投げ落とし、踏みつけた。</span>
<span className="v" id="v11" data-v="11" data-xref="ダニエル書 12:11; ヨハネの黙示録 13:5–7; ダニエル書 8:25"> それは軍勢の君にまで向かって自らを大いなるものとし、君から絶えずささげられる全焼のささげ物を取り去り、その聖所を打ち倒した。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 12:1; イザヤ書 59:14; ダニエル書 11:31–36"> 背きのゆえに、軍勢は、絶えずささげられる全焼のささげ物とともに、その角に引き渡された。その角は真理を地に投げ捨て、思いのままに行って成功した。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 11:2; ヨハネの黙示録 6:10; ルカ 21:24"> その時、私は一人の聖なる者が語るのを聞いた。すると、もう一人の聖なる者が、その話していた者に言った。「絶えずささげられる全焼のささげ物と、荒廃をもたらす背きについてのこの幻、すなわち聖所と軍勢が踏みにじられることは、いつまで続くのか。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ダニエル書 12:7; ダニエル書 7:25; ヨハネの黙示録 11:2–3"> 彼は私に言った。「二千三百の夕と朝までである。その時、聖所は清められる。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ダニエル書 10:16; ヨハネの黙示録 1:13; ペテロの手紙第一 1:10–11"> 私ダニエルは、この幻を見て、その意味を理解しようとした。すると見よ、人のような姿をした者が私の前に立った。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカ 1:19; ルカ 1:26; ダニエル書 8:2"> その時、ウライ川の両岸の間から人の声が聞こえ、こう呼びかけた。「ガブリエルよ、この者に幻を理解させよ。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ダニエル書 8:19; ダニエル書 12:4; ハバクク書 2:3"> そこで彼は、私が立っている所に近づいて来た。彼が来ると、私は恐れてひれ伏した。しかし彼は私に言った。「人の子よ、悟れ。この幻は終わりの時に関するものだ。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ダニエル書 10:18; エゼキエル書 2:2; ダニエル書 10:16"> 彼が私に語っている間に、私は顔を地に伏せたまま深い眠りに陥った。しかし彼は私に触れ、私を立たせた。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ハバクク書 2:3; ダニエル書 11:27; ヨハネの黙示録 17:17"> 彼は言った。「見よ、憤りの終わりの時に起こることを、あなたに知らせよう。これは定められた終わりの時に関するものだからだ。</span>
<span className="v" id="v20" data-v="20" data-xref="ダニエル書 8:3; ダニエル書 11:1–2"> あなたが見た二本の角を持つ雄羊は、メディアとペルシアの王たちである。</span>
<span className="v" id="v21" data-v="21" data-xref="ダニエル書 10:20; ダニエル書 11:3; ダニエル書 8:5–8"> 毛深い雄やぎはギリシアの王であり、その両目の間にある大きな角は最初の王である。</span>
<span className="v" id="v22" data-v="22" data-xref="ダニエル書 11:4; ダニエル書 8:3; ダニエル書 8:8"> その角が折れ、代わりに四本の角が立ったように、その国から四つの王国が起こる。しかし、それらは最初の王の力には及ばない。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ヨハネの黙示録 13:11–14; テサロニケ人への第二の手紙 2:9–11; ヨハネの黙示録 19:20"> 彼らの王国の終わりの時、背く者たちの罪が満ちた時、険しい顔つきで謎に通じた一人の王が起こる。</span>
<span className="v" id="v24" data-v="24" data-xref="ダニエル書 8:12; ダニエル書 11:31–36; ダニエル書 7:25"> 彼の力は強大になるが、それは彼自身の力によるのではない。彼は驚くほどの破壊を行い、その行うことに成功する。彼は力ある者たちと聖なる民を滅ぼす。</span>
<span className="v" id="v25" data-v="25" data-xref="ダニエル書 8:11; ヨハネの黙示録 17:14; ヨブ記 34:20"> 彼は巧みな策略によって、その手の中で欺きを栄えさせる。心の中で自らを大いなるものとし、油断している多くの者を滅ぼす。また、君たちの君に立ち向かうが、人の手によらずに打ち砕かれる。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ダニエル書 10:1; ダニエル書 12:9; ダニエル書 12:4"> 告げられた夕と朝についての幻は真実である。しかし、この幻を封じておけ。それは遠い日のことだからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ダニエル書 7:28; ハバクク書 3:16; ダニエル書 8:7"> 私ダニエルは力を失い、数日間病気になった。その後、起き上がって王の仕事を行った。私はその幻に驚き惑ったが、だれもそれを悟らなかった。</span>
</div>

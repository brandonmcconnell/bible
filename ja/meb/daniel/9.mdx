<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ダニエル書 11:1; ダニエル書 1:21; ダニエル書 5:31–1"> カルデア人の王国の王とされた、メディア人の一族に属するアハシュエロスの子ダリヨスの第一年、</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 29:10; エレミヤ書 25:11–12; 歴代誌 第二 36:21"> その治世の第一年に、私ダニエルは書物によって年数を悟った。それは、エルサレムの荒廃の期間が七十年であると、主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="すべて大文字の「主」または「神」はヘブル語のיהוה（ヤハウェ）から来ている。ただし、短い形のיה（ヤハ）から来ていると記されている場合を除く。">a</a></sup>の言葉が預言者エレミヤに臨んだ、その年数である。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 33:3; エレミヤ書 29:10–13; ヤコブの手紙 5:16–18"> 私は主なる神に顔を向け、断食し、粗布をまとい、灰をかぶって、祈りと願いをもって求めた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 8:28; 出エジプト記 20:6; 申命記 5:10"> 私は私の神、主に祈り、罪を告白した。<br />「ああ、主よ。偉大で畏るべき神。あなたを愛し、あなたの戒めを守る者たちには、契約と慈しみを守られる方。</span>
<span className="v" id="v5" data-v="5" data-xref="マラキ書 3:7; ダニエル書 9:11; ダニエル書 9:15"> 私たちは罪を犯し、よこしまなことを行い、悪をなし、背いた。あなたの命令と定めから離れた。</span>
<span className="v" id="v6" data-v="6" data-xref="ダニエル書 9:10; 歴代誌 第二 36:15–16; ルカ 20:10–12"> あなたのしもべである預言者たちに聞き従わなかった。彼らはあなたの御名によって、私たちの王たち、君主たち、父祖たち、この地のすべての民に語った。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="詩篇 44:15; エレミヤ書 3:25; エレミヤ書 2:26–27"> 主よ、義はあなたにある。しかし私たちには、今日このとおり、顔を覆う恥がある。ユダの人々、エルサレムの住民、すべてのイスラエル、近くにいる者も遠くにいる者も、あなたが追い散らされたあらゆる国々で恥を負っている。私たちがあなたに背いたゆえに。</span>
<span className="v" id="v8" data-v="8" data-xref="ダニエル書 9:6–7; 哀歌 1:7–8; 哀歌 1:18"> 主よ、私たちには顔を覆う恥がある。私たちの王たち、君主たち、父祖たちにも。私たちはあなたに罪を犯した。</span>
<span className="v" id="v9" data-v="9" data-xref="エペソ人への手紙 1:6–8; ダニエル書 9:7; ダニエル書 9:5"> あわれみと赦しは、私たちの神、主のもの。私たちは主に背いた。</span>
<span className="v" id="v10" data-v="10" data-xref="ダニエル書 9:6; 列王記第二 18:12; ネヘミヤ記 9:13–17"> 私たちの神、主の御声に聞き従わず、主がしもべである預言者たちを通して私たちの前に置かれた律法に歩まなかった。</span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 8:5–10; イザヤ書 1:4–6; 申命記 28:15–68"> まことに、全イスラエルはあなたの律法を犯し、背を向け、あなたの御声に聞き従わなかった。<br />それゆえ、神のしもべモーセの律法に記された呪いと誓いが、私たちの上に注がれた。私たちは神に罪を犯した。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 5:9; 哀歌 1:12; ヨブ記 12:17"> 神は、私たちと、私たちを治めた裁き人たちに対して語られた言葉を成し遂げ、私たちの上に大きな災いをもたらされた。エルサレムに行われたようなことは、天下のどこにも行われたことがない。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 28:15–68; イザヤ書 9:13; ダニエル書 9:11"> モーセの律法に記されているとおり、このすべての災いが私たちの上に臨んだ。それでも私たちは、不義から立ち返り、あなたの真理を悟るために、私たちの神、主の恵みを求めなかった。</span>
<span className="v" id="v14" data-v="14" data-xref="ダニエル書 9:7; ネヘミヤ記 9:33; 詩篇 51:14"> それゆえ主は、この災いを心に留め、私たちの上にもたらされた。私たちの神、主は、なされるすべてのみわざにおいて義である。だが私たちは、その御声に聞き従わなかった。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ネヘミヤ記 9:10; 出エジプト記 32:11; ネヘミヤ記 1:10"> 今、私たちの神、主よ。あなたは力強い御手によって、ご自分の民をエジプトの地から導き出し、今日に至るまで御名を知らしめられた。私たちは罪を犯し、悪を行った。</span>
<span className="v" id="v16" data-v="16" data-xref="ゼカリヤ書 8:3; ヨエル書 3:17; 詩篇 87:1–3"> 主よ、あなたのすべての義に従って、どうかあなたの怒りと憤りを、あなたの町エルサレム、あなたの聖なる山からそらしてください。私たちの罪と父祖たちの不義のために、エルサレムとあなたの民は、周囲のすべての者からそしられています。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="詩篇 80:19; 哀歌 5:18; コリント人への第二の手紙 1:20"> 今、私たちの神よ、あなたのしもべの祈りと願いを聞いてください。主よ、ご自身のために、荒れ果てた聖所の上に御顔を輝かせてください。</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 37:17; エレミヤ書 36:7; 列王記第二 19:16"> 私の神よ、耳を傾けて聞いてください。目を開いて、私たちの荒廃と、あなたの御名をもって呼ばれている町をご覧ください。私たちは自分たちの義によって願いをささげるのではなく、ただあなたの大いなるあわれみによって願うのです。</span>
<span className="v" id="v19" data-v="19" data-xref="ダニエル書 9:18; エペソ人への手紙 1:12; アモス書 7:2"> 主よ、聞いてください。主よ、赦してください。主よ、耳を傾け、事を行ってください。私の神よ、ご自身のために遅らせないでください。あなたの町とあなたの民は、あなたの御名をもって呼ばれているからです。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="詩篇 145:18; ダニエル書 9:3–4; ローマ人への手紙 3:23"> 私が語り、祈り、自分の罪と自分の民イスラエルの罪を告白し、私の神の聖なる山のために、私の神、主の前に願いをささげていた時、</span>
<span className="v" id="v21" data-v="21" data-xref="ルカ 1:19; ダニエル書 8:16; 列王記第一 18:36"> そうして私が祈りの言葉を語っている間に、初めの幻で見たあの人ガブリエルが速く飛んで来て、夕方のささげ物の時刻ごろ、私に触れた。</span>
<span className="v" id="v22" data-v="22" data-xref="ダニエル書 9:24–27; ダニエル書 10:21; ダニエル書 8:16"> 彼は私に教え、私と話して言った。「ダニエルよ、私は今、あなたに知恵と悟りを与えるために来た。</span>
<span className="v" id="v23" data-v="23" data-xref="ダニエル書 10:19; マタイ 24:15; ダニエル書 10:11–12"> あなたが願い始めた時、命令が出された。あなたは深く愛されているので、私はそれを告げるために来た。だから、この事をよく考え、幻を悟れ。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヘブル人への手紙 9:11–14; ローマ人への手紙 5:10; エレミヤ書 23:5–6"> あなたの民とあなたの聖なる町について、七十週が定められている。それは、背きを終わらせ、罪に終止符を打ち、不義を贖い、永遠の義をもたらし、幻と預言を封じ、最も聖なるものに油を注ぐためである。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="エズラ記 4:24; イザヤ書 9:6; イザヤ書 55:4"> だから知り、悟れ。エルサレムを回復して建て直せという命令が出てから、油注がれた者である君<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「油注がれた者」は「メシア」（「キリスト」と同じ意味）とも訳せる。">b</a></sup>が現れるまで、七週と六十二週がある。エルサレムは広場と堀を備えて再建されるが、それは苦難の時代に行われる。</span>
<span className="v" id="v26" data-v="26" data-xref="イザヤ書 53:8; ナホム書 1:8; マルコ 13:2"> 六十二週の後、油注がれた者<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「油注がれた者」は「メシア」（「キリスト」と同じ意味）とも訳せる。">c</a></sup>は断たれ、彼には何も残らない。やがて来る君の民が、町と聖所を滅ぼす。その終わりは洪水のように来る。終わりまで戦いが続き、荒廃が定められている。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイ 24:15; ルカ 21:20; ダニエル書 12:11"> 彼は一週の間、多くの者と堅い契約を結ぶ。その週の半ばに、いけにえとささげ物をやめさせる。忌まわしいものの翼には、荒廃させる者が現れる。そして定められた終局が、荒廃をもたらす者の上に注がれる。」</span>
</div>

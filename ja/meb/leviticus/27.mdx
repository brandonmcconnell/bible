<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 6:2; サムエル記第一 1:28; 士師記 11:30–31"> 「イスラエルの子らに告げなさい。『人が誓願によって、ある人を主にささげる場合、その人の価値は定められた評価額による。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 30:13; レビ記 27:25; 民数記 18:16"> 二十歳から六十歳までの男性の評価は、聖所のシェケル<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一シェケルは約10グラム、または約0.35オンスである。">a</a></sup>による銀五十シェケルとする。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイ 27:9–10; ゼカリヤ書 11:12–13; マタイ 26:15"> 女性であれば、あなたの評価は三十シェケルとする。</span>
<span className="v" id="v5" data-v="5"> 五歳から二十歳までであれば、あなたの評価は、男性なら二十シェケル、女性なら十シェケルとする。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 3:40–43; 民数記 18:14–16"> 一か月から五歳までであれば、あなたの評価は、男性なら銀五シェケル、女性なら銀三シェケルとする。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 90:10"> 六十歳以上であれば、男性ならあなたの評価は十五シェケル、女性なら十シェケルとする。</span>
<span className="v" id="v8" data-v="8" data-xref="マルコ 14:7; レビ記 14:21–22; ルカ 21:1–4"> しかし、もし彼があなたの評価額を払えないほど貧しいなら、彼は祭司の前に立たされ、祭司が彼に評価額を定める。祭司は誓願を立てる者の支払う能力に応じて評価額を定める。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 『もしそれが、人々が主へのささげ物としてささげる動物であるなら、だれかがそのようなものを主に与える場合、それはすべて聖なるものとなる。</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 27:15–33; ヤコブの手紙 1:8"> 彼はそれを変えたり、良いものを悪いものと、悪いものを良いものと交換したりしてはならない。もし少しでも動物を他の動物と交換するなら、それと交換されたものの両方が聖なるものとなる。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 23:18; マラキ書 1:14"> もしそれが汚れた動物で、主へのささげ物としてささげられないものであるなら、彼はその動物を祭司の前に立たせる。</span>
<span className="v" id="v12" data-v="12"> 祭司がその良し悪しを評価する。祭司が評価したとおりに定まる。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 27:19; レビ記 27:15; レビ記 22:14"> しかし、もし彼がそれを買い戻すなら、彼はその評価額にその五分の一を加算する。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数記 18:14; レビ記 25:29–31; レビ記 27:21"> 『人が自分の家を主への聖なるものとして聖別する場合、祭司がその良し悪しを評価する。祭司が評価したとおりに定まる。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 27:13"> 家を聖別した者がそれを買い戻すなら、評価額にその五分の一を加える。そうすれば、その家は再び彼のものとなる。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 45:11–14; ホセア書 3:2; 使徒の働き 4:34–37"> 『もし人が自分の所有地である畑の一部を主に聖別するなら、あなたの評価はそれに蒔く種に応じたものとする。一ホメル<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一ホメルは約220リットル、または6ブッシェルである。">b</a></sup>の大麦の種まきは銀五十シェケル<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一シェケルは約10グラム、または約0.35オンスである。">c</a></sup>と評価される。</span>
<span className="v" id="v17" data-v="17"> もし彼がヨベルの年から自分の畑を聖別するなら、あなたの評価のまま確定する。</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 25:15–16; レビ記 25:51–52; レビ記 25:27"> ヨベルの年より後に畑を聖別するなら、祭司は次のヨベルの年まで残る年数に応じて金額を計算し、評価額から減額する。</span>
<span className="v" id="v19" data-v="19" data-xref="レビ記 27:13"> 畑を聖別した者がそれを買い戻すなら、評価額にその五分の一を加える。そうすれば、その畑は彼のものとして残る。</span>
<span className="v" id="v20" data-v="20"> もし彼が畑を買い戻さない場合、あるいは彼が畑を他の人に売っていた場合は、それはもはや買い戻すことはできない。</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 44:29; 民数記 18:14; レビ記 25:31"> その畑がヨベルの年に手放されるとき、それは永久にささげられた畑として、主にとって聖なるものとなる。それは祭司の所有地となる。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="レビ記 25:10; レビ記 25:25"> 『もし彼が、自分の所有地ではない、自分で買った畑を主に聖別するなら、</span>
<span className="v" id="v23" data-v="23" data-xref="レビ記 27:18; レビ記 27:12"> 祭司はヨベルの年までの年数に応じて評価額を計算する。その人はその日に、主への聖なるものとして評価額を納める。</span>
<span className="v" id="v24" data-v="24" data-xref="レビ記 25:28; レビ記 27:20"> ヨベルの年には、その畑は彼がそれを買った相手、すなわちその土地の所有権を持つ者に返される。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 30:13; 民数記 18:16; 民数記 3:47"> すべての評価額は聖所のシェケル<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一シェケルは約10グラム、または約0.35オンスである。">d</a></sup>による。一シェケルは二十ゲラ<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一ゲラは約0.5グラム、または約7.7グレーンである。">e</a></sup>である。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 13:2; 出エジプト記 13:12–13; 民数記 18:17"> 『しかし、動物の初子については、初子として主のものであるから、牛であれ羊であれ、だれも聖別してはならない。それは主のものである。</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 27:11"> もしそれが汚れた動物であるなら、あなたの評価に従ってそれを買い戻し、それにその五分の一を加算する。あるいは買い戻されないなら、あなたの評価に従って売る。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヨシュア記 6:17–19; レビ記 27:21; 出エジプト記 22:20"> 『とはいえ、人が自分が持っているすべてのもののうち、人であれ動物であれ、自分の所有する畑であれ、主に永久にささげるどんなものも、売ったり買い戻したりしてはならない。永久にささげられるすべてのものは、主にとって最も聖なるものである。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="サムエル記第一 15:18–23; 民数記 21:2–3"> 『人のうち、滅びのためにささげられた者はだれも、贖い出されてはならない。彼は必ず死刑に処される。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="マタイ 23:23; ネヘミヤ記 13:12; 創世記 28:22"> 『土地の種であれ、木の実であれ、土地の十分の一はすべて主のものである。それは主にとって聖なるものである。</span>
<span className="v" id="v31" data-v="31"> もし人が自分の十分の一のいくらかを買い戻すなら、彼はそれにその五分の一を加算する。</span>
<span className="v" id="v32" data-v="32" data-xref="エレミヤ書 33:13; エゼキエル書 20:37; ミカ書 7:14"> 牛や羊の群れのすべての十分の一、すなわち杖の下を通るすべてのもののうち、十番目のものは主にとって聖なるものとなる。</span>
<span className="v" id="v33" data-v="33" data-xref="レビ記 27:10"> それが良いか悪いかを調べてはならず、それを交換してもならない。もし少しでもそれを交換するなら、それと交換されたものの両方が聖なるものとなる。それは買い戻されてはならない。』」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="レビ記 26:46; 民数記 1:1; ヘブル人への手紙 12:18–25"> これらが、シナイ山でイスラエルの子らのために、主がモーセに命じられた命令である。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 26:61; 申命記 12:32; レビ記 16:12"> アロンの子ナダブとアビフは、それぞれ香炉を取り、火を入れ、その上に香を置き、主が命じられなかった火を主の前にささげた。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 26:61; 民数記 16:35; レビ記 9:24"> すると、主の前から火が出て彼らを焼き尽くし、彼らは主の前で死んだ。</span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 19:22; レビ記 21:6; イザヤ書 49:3"> そこでモーセはアロンに言った。「主が語られたのはこのことである。<br /><span className="pl pl-1">『わたしに近づく者たちの間で、わたしは聖なる者とされ、</span><br /><span className="pl pl-2">すべての民の前で、わたしは栄光を現す。』」</span><br />アロンは黙っていた。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 6:22; 出エジプト記 6:18; 使徒の働き 5:6"> モーセはアロンの叔父ウジエルの子ら、ミシャエルとエルツァファンを呼び寄せ、彼らに言った。「近づきなさい。そしてあなたがたの兄弟たちを聖所の前から宿営の外へ運び出しなさい。」</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 8:13"> 彼らは近づき、モーセが言ったように、長服を着せたまま彼らを宿営の外へ運び出した。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 22:18; ヨシュア記 7:1; 民数記 16:22"> モーセはアロンと、その子エルアザル、イタマルに言った。「頭髪を乱してはならず、衣を引き裂いてはならない。あなたがたが死なず、また主の怒りが全会衆に及ばないためである。しかし、あなたがたの兄弟であるイスラエルの全家は、主が燃え上がらせたこの火を嘆き悲しむがよい。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 21:12; レビ記 8:30; 使徒の働き 10:38"> あなたがたが死なないために、会見の天幕の入り口から出てはならない。主の注ぎ油があなたがたの上にあるからである。」彼らはモーセの言葉の通りにした。</span>
<span className="v" id="v8" data-v="8"> そして主はアロンに言われた。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカ 1:15; テモテへの手紙第一 3:3; エペソ人への手紙 5:18"> 「あなたも、あなたの子らも、会見の天幕に入るときには、ぶどう酒や強い酒を飲んではならない。死なないためである。これは代々にわたる永遠の掟である。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 22:26; ペテロの手紙第一 1:14–16; レビ記 11:47"> あなたがたは聖なるものと俗なるもの、汚れたものと清いものを区別する。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイ 28:20; マラキ書 2:7; ネヘミヤ記 8:8"> また、あなたがたは、主がモーセを通してイスラエルの子らに語られたすべての掟を、彼らに教える。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="レビ記 21:22; 民数記 18:9–10; レビ記 7:9"> モーセはアロンと、残された子であるエルアザルとイタマルに言った。「主への火によるささげ物のうち、残っている穀物のささげ物を取り、祭壇のそばでパン種を入れずに食べなさい。それは最も聖なるものだからである。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 2:3; レビ記 6:16; 民数記 18:10"> あなたがたはそれを聖なる場所で食べる。それは主への火によるささげ物の中からの、あなたとあなたの子らの分だからである。私はそのように命じられている。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 18:11; レビ記 7:29–34; 出エジプト記 29:24–28"> また揺り動かされた胸と持ち上げられたももは、清い場所で食べる。あなたと、あなたと共にいる息子たちと娘たちも食べることができる。これらは、イスラエルの子らの和解のいけにえから、あなたとあなたの子らの分として与えられているからである。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 7:34; 創世記 17:13; レビ記 7:29–30"> 彼らは、火によるささげ物である脂肪とともに、持ち上げられたももと揺り動かされた胸を持って来て、主の前で揺り動かすささげ物として揺り動かす。主が命じられた通り、それはあなたとあなたの子らの永遠の分となる。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="レビ記 9:3; レビ記 9:15; レビ記 6:26"> モーセは贖罪のささげ物の山羊について念入りに尋ねたが、それはすでに焼かれていた。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「見よ」と訳されるヘブル語は、注意を促す間投詞として用いられる。">a</a></sup>彼はアロンの残された子エルアザルとイタマルに怒って言った。</span>
<span className="v" id="v17" data-v="17" data-xref="レビ記 7:6–7; 民数記 18:1; レビ記 6:24–30"> 「なぜあなたがたは聖所の場所で、贖罪のささげ物を食べなかったのか。それは最も聖なるものであり、会衆の咎を負うため、また主の前で彼らのために贖いを行うために、あなたがたに与えられたものではないか。</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 6:30; レビ記 6:26"> その血は聖所の内側に持ち込まれなかった。私が命じた通りに、あなたがたは必ずそれを聖所で食べるべきであった。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="レビ記 9:12; レビ記 9:8; エレミヤ書 14:12"> アロンはモーセに言った。「今日、彼らは主の前に贖罪のささげ物と全焼のささげ物をささげた。しかし、このようなことが私の身に起こった。もし今日、私が贖罪のささげ物を食べていたなら、主の目にかなっただろうか。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ゼカリヤ書 7:8–9; マタイ 12:20; 歴代誌 第二 30:18–20"> モーセはそれを聞いて、それをよしとした。</span>
</div>
</div>

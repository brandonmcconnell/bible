<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 1:1; ガラテヤ人への手紙 4:24–25; 出エジプト記 19:1"> 主はシナイ山でモーセに言われた。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代誌 第二 36:21; レビ記 26:34–35; 出エジプト記 23:10"> 「イスラエルの子らに告げなさい。『わたしが与える地に入ったとき、その地にも主のための安息を与えなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 23:10"> 六年間は畑に種を蒔き、六年間はぶどう園の手入れをして、その産物を収穫しなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌 第二 36:21; レビ記 25:20–23; 出エジプト記 23:10–11"> しかし、七年目は地にとって厳かな安息の安息日、すなわち主への安息日となる。畑に種を蒔いたり、ぶどう園の手入れをしたりしてはならない。</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第二 19:29; イザヤ書 37:30"> あなたの収穫の後に自然に生えたものを刈り取ってはならず、手入れをしなかったぶどうの木のぶどうを収穫してはならない。地にとって厳かな安息の年となるからである。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 2:44; 出エジプト記 23:11; 使徒の働き 4:34–35"> 地の安息の年の産物は、あなたがたの食物となる。すなわち、あなた、あなたの男奴隷、女奴隷、雇い人、あなたと共に住む寄留者のためである。</span>
<span className="v" id="v7" data-v="7"> あなたの家畜や、あなたの地にいる動物のためにも、そのすべての産物が食物となる。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="レビ記 23:15; 創世記 2:2"> 『七年を七回、すなわち七回の安息の年を数えなさい。その年数は四十九年となる。</span>
<span className="v" id="v9" data-v="9" data-xref="レビ記 23:24; レビ記 23:27; テサロニケ人への手紙第一 1:8"> 第七の月の十日には、角笛を高らかに吹き鳴らしなさい。贖罪の日に、あなたがたの全土に角笛を響き渡らせなさい。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 34:8; イザヤ書 63:4; ペテロの手紙第一 2:16"> 第五十年目を聖別し、その地のすべての住民に解放を布告しなさい。これはあなたがたにとってヨベルの年である。あなたがたはそれぞれ自分の所有地に帰り、それぞれ自分の家族のもとに帰る。</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 27:17; レビ記 25:4–5"> その第五十年目はあなたがたにとってヨベルの年となる。種を蒔いてはならず、自然に生えたものを刈り取ってはならず、手入れをしなかったぶどうの木から収穫してもならない。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 25:6–7"> それはヨベルの年であり、あなたがたにとって聖なる年である。畑に自然に生えたものを食べなさい。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="レビ記 25:10; レビ記 27:17–24; 民数記 36:4"> 『このヨベルの年には、あなたがたはそれぞれ自分の所有地に帰る。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="レビ記 19:13; レビ記 25:17; サムエル記第一 12:3–4"> 『隣人に何かを売る場合、あるいは隣人から買う場合、互いに不当な扱いをしてはならない。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 27:18–23; ピリピ人への手紙 4:5"> ヨベルの年からの年数に応じて、あなたは隣人から買い、収穫の年数に応じて、彼はあなたに売る。</span>
<span className="v" id="v16" data-v="16" data-xref="レビ記 25:27; レビ記 25:51"> 年数が多いほどあなたはその価格を上げ、年数が少ないほどあなたはその価格を下げなさい。彼は収穫の回数をあなたに売るからである。</span>
<span className="v" id="v17" data-v="17" data-xref="レビ記 19:14; レビ記 19:32; レビ記 25:43"> 互いに不当な扱いをしてはならず、あなたの神を恐れなさい。わたしはあなたがたの神、主である。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 23:6; 申命記 12:10; 箴言 1:33"> 『わたしの掟を行い、わたしの法を守りなさい。そうすれば、あなたがたはその地に安らかに住む。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨエル書 2:26; 詩篇 85:12; レビ記 26:5"> その地は実を結び、あなたがたは十分に食べ、そこで安全に住むことができる。</span>
<span className="v" id="v20" data-v="20" data-xref="レビ記 25:4; ルカ 12:29; 民数記 11:4"> もしあなたがたが、『七年目には何を食べればよいのか。私たちは種を蒔くことも、産物を集めることもできないではないか』と言うなら、</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 28:8; 箴言 10:22; コリント人への第二の手紙 9:10"> わたしは六年目にあなたがたに祝福を命じる。その地は三年分の実りをもたらす。</span>
<span className="v" id="v22" data-v="22" data-xref="列王記第二 19:29; レビ記 26:10; イザヤ書 37:30"> 八年目に種を蒔き、九年目まで古い蓄えの産物を食べなさい。その産物が入るまで、あなたがたは古い蓄えを食べなさい。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ペテロの手紙第一 2:11; 詩篇 39:12; エゼキエル書 48:14"> 『土地を永久に売り渡してはならない。土地はわたしのものだからである。あなたがたは、わたしのもとに身を寄せる寄留者であり滞在者である。</span>
<span className="v" id="v24" data-v="24" data-xref="エペソ人への手紙 1:7; レビ記 25:51–53; レビ記 25:27"> あなたがたの所有地全土において、土地を買い戻す権利を認める。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ルツ記 2:20; エレミヤ書 32:7–8; ルツ記 3:12"> 『あなたの兄弟が貧しくなり、自分の所有地の一部を売ったなら、彼に最も近い親族が来て、兄弟が売ったものを買い戻す。</span>
<span className="v" id="v26" data-v="26" data-xref="レビ記 5:7"> もし買い戻す者がおらず、自ら資力を得て、それを買い戻す十分な手段を得たなら、</span>
<span className="v" id="v27" data-v="27"> 売却してからの年数を計算し、残りの代金を買い手に返す。そうすれば、自分の所有地に戻ることができる。</span>
<span className="v" id="v28" data-v="28" data-xref="イザヤ書 35:9–10; レビ記 25:10; ペテロの手紙第一 1:4–5"> しかし、もし自ら買い戻すことができないなら、売ったものはヨベルの年まで買った者の手に残る。ヨベルの年にはそれは手放され、彼は自分の所有地に戻ることができる。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 『もし城壁のある町にある住居を売ったなら、売却後まる一年の間は買い戻すことができる。まる一年の間は買い戻す権利がある。</span>
<span className="v" id="v30" data-v="30"> もしまる一年の間に買い戻されなければ、城壁のある町にあるその家は、それを買った者に代々にわたって永久に確定される。それはヨベルの年にも手放されない。</span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 49:7–8"> しかし、周囲に城壁のない村々の家は、その国の畑と同じとみなされる。それらは買い戻すことができ、ヨベルの年には手放される。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="ヨシュア記 21:1–45; 民数記 35:1–8"> 『ただし、レビ人の町、すなわち彼らの所有地である町々の家については、レビ人はいつでも買い戻すことができる。</span>
<span className="v" id="v33" data-v="33" data-xref="民数記 18:20–24; 申命記 18:1–2"> レビ人が売った家、すなわちその所有する町は買い戻すことができ、それはヨベルの年に手放される。レビ人の町々の家は、イスラエルの子らの中における彼らの所有地だからである。</span>
<span className="v" id="v34" data-v="34" data-xref="レビ記 25:23; 使徒の働き 4:36–37; 民数記 35:2–5"> しかし、彼らの町々の放牧地の畑は売ってはならない。それは彼らの永久の所有地だからである。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="申命記 15:7–8; 使徒の働き 11:29; レビ記 25:25"> 『兄弟が貧しくなり、あなたのもとで生活を支えられなくなったなら、彼を支えなさい。寄留者や滞在者のように、あなたと共に生きられるようにしなさい。</span>
<span className="v" id="v36" data-v="36" data-xref="出エジプト記 22:25; 申命記 23:19–20; エゼキエル書 18:8"> 彼から利息や利益を取ってはならない。あなたの神を恐れ、あなたの兄弟があなたとともに生きられるようにしなさい。</span>
<span className="v" id="v37" data-v="37"> あなたのお金を利息をとって貸したり、利益のためにあなたの食物を与えたりしてはならない。</span>
<span className="v" id="v38" data-v="38" data-xref="レビ記 11:45; 民数記 15:41; 出エジプト記 20:2"> わたしはあなたがたの神、主であり、カナンの地をあなたがたに与え、あなたがたの神となるために、エジプトの地からあなたがたを導き出した。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出エジプト記 21:2; 列王記第一 9:22; 列王記第二 4:1"> 『もしあなたの兄弟が貧しくなり、自身をあなたに売ったなら、あなたは彼を奴隷として働かせてはならない。</span>
<span className="v" id="v40" data-v="40" data-xref="出エジプト記 21:2–3"> 彼は雇い人や滞在者のようにあなたのもとにおり、ヨベルの年まであなたのもとで働く。</span>
<span className="v" id="v41" data-v="41" data-xref="レビ記 25:28; 出エジプト記 21:3; ヨハネ 8:32"> その後、彼と彼の子らはあなたのもとを去り、自分の家族のもとに帰り、父祖の所有地に戻る。</span>
<span className="v" id="v42" data-v="42" data-xref="レビ記 25:55; ローマ人への手紙 6:22; コリント人への第一の手紙 7:21–23"> 彼らはわたしがエジプトの地から導き出した、わたしのしもべだからである。彼らは奴隷として売られてはならない。</span>
<span className="v" id="v43" data-v="43" data-xref="コロサイ人への手紙 4:1; レビ記 25:46; 出エジプト記 1:13–14"> あなたは彼を過酷に支配してはならない。あなたの神を恐れなさい。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="出エジプト記 12:44; 詩篇 2:8–9; イザヤ書 14:1–2"> 『あなたが所有してもよい男奴隷と女奴隷については、あなたがたの周囲の国々から、男奴隷と女奴隷を買うことができる。</span>
<span className="v" id="v45" data-v="45" data-xref="イザヤ書 56:3–6"> さらに、あなたがたの間に住む異国人の子らや、彼らの家族のうち、あなたがたの地で生まれた者から買うことができる。彼らはあなたがたの所有物となる。</span>
<span className="v" id="v46" data-v="46" data-xref="イザヤ書 14:2; レビ記 25:43"> あなたがたは彼らを自分の後の子らに遺産として譲り、所有物として受け継がせることができる。あなたがたは彼らを永久に奴隷とすることができる。しかし、あなたがたの兄弟であるイスラエルの子らに対しては、互いに過酷に支配してはならない。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="ヤコブの手紙 2:5; レビ記 25:26; サムエル記第一 2:7–8"> 『もしあなたのもとにいる異国人や一時滞在者が豊かになり、そのそばにいるあなたの兄弟が貧しくなって、あなたのもとに住む異国人や寄留者、あるいはその異国人の家族の者に自分を売った場合、</span>
<span className="v" id="v48" data-v="48" data-xref="ネヘミヤ記 5:5; ヘブル人への手紙 2:11–13; レビ記 25:35"> 売られた後、彼は買い戻される権利がある。彼の兄弟の一人が彼を買い戻すことができる。</span>
<span className="v" id="v49" data-v="49" data-xref="レビ記 25:26"> あるいは彼の叔父、叔父の息子が彼を買い戻すことができ、彼の家族の近しい親族のだれもが彼を買い戻すことができる。または、もし彼自身が豊かになったなら、自らを買い戻すことができる。</span>
<span className="v" id="v50" data-v="50" data-xref="イザヤ書 16:14; イザヤ書 21:16; レビ記 25:53"> その人は、自分を買った者と、自分を売った年からヨベルの年までを計算する。売却の価格は年数に応じ、雇い人の期間に基づいて定める。</span>
<span className="v" id="v51" data-v="51"> もしまだ多くの年数が残っているなら、それに従って、自分が買われた金額の中から買い戻しの価格を返す。</span>
<span className="v" id="v52" data-v="52"> ヨベルの年まで数年しか残っていないなら、彼とともに計算し、その労働の年数に応じて買い戻しの価格を返す。</span>
<span className="v" id="v53" data-v="53" data-xref="レビ記 25:46; レビ記 25:43"> その人は年ごとに雇われる雇い人のように主人のもとにいる。主人があなたの目の前で彼を過酷に支配してはならない。</span>
<span className="v" id="v54" data-v="54" data-xref="出エジプト記 21:2–3; レビ記 25:40–41; イザヤ書 49:9"> もしこれらの方法で買い戻されない場合でも、ヨベルの年には、彼とその子どもたちはともに手放される。</span>
<span className="v" id="v55" data-v="55" data-xref="レビ記 25:42; イザヤ書 43:3; 出エジプト記 13:3"> イスラエルの子らはわたしにとってしもべだからである。彼らはわたしがエジプトの地から導き出したわたしのしもべである。わたしはあなたがたの神、主である。』」</span>
</div>

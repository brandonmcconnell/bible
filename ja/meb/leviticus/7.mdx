<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="レビ記 6:17; レビ記 5:14–7; レビ記 6:25"> 『償いのささげ物についての律法は次の通りである。これは最も聖なるものである。</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 1:5; レビ記 6:25; レビ記 1:11"> 全焼のささげ物を屠る場所で、償いのささげ物を屠る。その血は祭壇の周囲に振りかける。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 29:13; レビ記 3:15–16; 詩篇 51:6"> 彼はそのすべての脂肪をささげる。すなわち、脂尾、内臓を覆う脂肪、</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 3:4"> 二つの腎臓と、腰のあたりにあるそれらの上の脂肪、および腎臓と一緒に取り外す肝臓の覆いである。</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 1:13; ガラテヤ人への手紙 5:24; ペテロの手紙第一 4:1–2"> 祭司はそれらを、主への火によるささげ物として祭壇の上で燃やす。これは償いのささげ物である。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 6:29; 民数記 18:9–10; レビ記 2:3"> 祭司の男子は皆、これを食べてもよい。それは聖なる場所で食べる。これは最も聖なるものである。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="レビ記 6:25–26; レビ記 14:13; コリント人への第一の手紙 9:13"> 『贖罪のささげ物も償いのささげ物も同じである。これらには一つの律法がある。それで贖いを行う祭司がそれを受ける。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 4:11; 出エジプト記 29:14; ローマ人への手紙 13:14"> 人のために全焼のささげ物をささげる祭司は、自らささげた全焼のささげ物の皮を自分のものとする。</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 18:9; エゼキエル書 44:29; レビ記 2:10"> かまどで焼かれたすべての穀物のささげ物と、鍋や平鍋で準備されたすべてのものは、それをささげる祭司のものとなる。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第二の手紙 8:14; 出エジプト記 16:18"> すべての穀物のささげ物は、油を混ぜたものでも乾いたものでも、等しくアロンのすべての子らのものとなる。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="レビ記 22:18–21; エゼキエル書 45:15; レビ記 3:1–17"> 『人が主にささげる和解のいけにえについての律法は次の通りである。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 2:4; 民数記 6:15; ペテロの手紙第一 2:5"> もし感謝のためにそれをささげるなら、感謝のいけにえとともに、油を混ぜた種なしの菓子、油を塗った種なしの薄焼きパン、油を混ぜた菓子をささげる。</span>
<span className="v" id="v13" data-v="13" data-xref="アモス書 4:5; レビ記 23:17; マタイ 13:33"> 感謝のための和解のいけにえとともに、パン種を入れたパンの菓子をささげ物としてささげる。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 18:19; 出エジプト記 29:27–28; 民数記 18:24–32"> その中から、それぞれのささげ物の一つを、主への持ち上げるささげ物としてささげる。それは和解のいけにえの血を振りかける祭司のものとなる。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 22:29–30"> 感謝のための和解のいけにえの肉は、それをささげたその日に食べる。その一部でも朝まで残しておいてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="レビ記 19:5–8; 申命記 12:6; 詩篇 116:14"> 『しかし、もしそのささげ物のいけにえが誓願、または自発的なささげ物であるなら、それは彼がいけにえをささげたその日に食べる。次の日にもその残りを食べてもよい。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 12:10; ホセア書 6:2; コリント人への第一の手紙 15:4"> しかし、三日目に残っているいけにえの肉は、火で焼く。</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 19:7–8; レビ記 11:41; 民数記 18:27"> 和解のいけにえの肉が三日目に少しでも食べられたなら、そのいけにえは受け入れられず、ささげた者のものとは数えられない。それは忌むべきものとなり、それを食べた者は自分の咎を負う。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ルカ 11:41; テトス 1:15; 使徒の働き 10:15–16"> 『汚れたものに触れた肉は食べてはならない。それは火で焼く。肉については、清い者は皆それを食べてもよい。</span>
<span className="v" id="v20" data-v="20" data-xref="レビ記 15:2–33; 創世記 17:14; レビ記 22:3–7"> しかし、自分の汚れを身に帯びたままで、主に属する和解のいけにえの肉を食べる者は、その民から断たれる。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 12:1–59; レビ記 11:20; エゼキエル書 4:14"> もしだれかが汚れたもの、すなわち人の汚れ、あるいは汚れた動物、あるいはどんな汚れた忌むべきものにでも触れ、主に属する和解のいけにえの肉をいくらかでも食べるなら、その者は自分の民から断たれる。』」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 主はモーセに告げられた。</span>
<span className="v" id="v23" data-v="23" data-xref="レビ記 3:16–17; レビ記 17:6; サムエル記第一 2:15–17"> 「イスラエルの子らに告げなさい。『牛、羊、山羊の脂肪は一切食べてはならない。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 22:31; レビ記 17:15; レビ記 22:8"> 自然に死んだ動物の脂肪や、野獣に引き裂かれた動物の脂肪は、他のどんな用途に使ってもよいが、決して食べてはならない。</span>
<span className="v" id="v25" data-v="25"> 人が主への火によるささげ物としてささげる動物の脂肪を食べる者はだれでも、それを食べるその者は自分の民から断たれるからである。</span>
<span className="v" id="v26" data-v="26" data-xref="創世記 9:4; レビ記 3:17; 使徒の働き 15:20"> あなたがたはどの住まいにおいても、鳥であれ動物であれ、いっさいの血を食べてはならない。</span>
<span className="v" id="v27" data-v="27" data-xref="ヘブル人への手紙 10:29; レビ記 7:20–21; レビ記 7:25"> 血を食べる者はだれでも、その者は自分の民から断たれる。』」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 主はモーセに告げられた。</span>
<span className="v" id="v29" data-v="29" data-xref="コロサイ人への手紙 1:20; ヨハネの手紙第一 1:7; レビ記 3:1–17"> 「イスラエルの子らに告げなさい。『主に和解のいけにえをささげる者は、その和解のいけにえの中から主へのささげ物を持って来る。</span>
<span className="v" id="v30" data-v="30" data-xref="民数記 6:20; レビ記 3:9; レビ記 3:14"> 彼は自分の手で、主への火によるささげ物を持って来る。胸を主の前で揺り動かすささげ物として揺り動かすために、その胸と一緒に脂肪を持って来る。</span>
<span className="v" id="v31" data-v="31" data-xref="レビ記 3:5; レビ記 3:11; レビ記 3:16"> 祭司はその脂肪を祭壇の上で燃やす。しかしその胸はアロンとその子らのものとなる。</span>
<span className="v" id="v32" data-v="32" data-xref="民数記 6:20; レビ記 7:34; レビ記 9:21"> あなたがたは和解のいけにえの中から、右のももを持ち上げるささげ物として祭司に与える。</span>
<span className="v" id="v33" data-v="33" data-xref="レビ記 26:1–46; レビ記 6:1–30; レビ記 7:3"> アロンの子らのうち、和解のいけにえの血と脂肪をささげる者が、右のももを自分の分として受け取る。</span>
<span className="v" id="v34" data-v="34" data-xref="民数記 18:18–19; レビ記 10:14–15; 出エジプト記 29:9"> わたしはイスラエルの子らの和解のいけにえの中から、揺り動かされた胸と持ち上げられたももを取り、それを永遠の分として、イスラエルの子らから祭司アロンとその子らに与えたからである。』」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="ヨハネの手紙第一 2:20; ヨハネの手紙第一 2:27; 民数記 18:7–19"> これは、彼らを主に祭司として仕えさせるために差し出した日に、主への火によるささげ物の中からアロンに聖別された分と、その子らに聖別された分である。</span>
<span className="v" id="v36" data-v="36" data-xref="レビ記 8:12; レビ記 8:30; 出エジプト記 40:13–15"> それは、主が彼らに油を注がれた日に、イスラエルの子らから彼らに与えるよう主が命じられたものである。これは代々にわたって彼らの永遠の分である。</span>
<span className="v" id="v37" data-v="37" data-xref="出エジプト記 29:1; レビ記 1:1–6; レビ記 6:9–18"> 以上が、全焼のささげ物、穀物のささげ物、贖罪のささげ物、償いのささげ物、任職、そして和解のいけにえについての律法である。</span>
<span className="v" id="v38" data-v="38" data-xref="レビ記 1:1–2"> これは、シナイの荒野でイスラエルの子らに主へのささげ物をささげるよう命じられた日に、主がシナイ山でモーセに命じられたものである。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセとアロンに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 24:8; レビ記 14:56; レビ記 14:3"> 「人が自分の体の皮膚に腫れ物、かさぶた、あるいは光る斑点ができ、それが体の皮膚で規定の病の患部となったなら、その人を祭司アロンか、その子らである祭司の一人のところに連れて来る。</span>
<span className="v" id="v3" data-v="3" data-xref="ローマ人への手紙 3:19–20; 使徒の働き 20:28; マラキ書 2:7"> 祭司は体の皮膚にある患部を調べる。患部の毛が白く変わり、患部が皮膚より深く見えるなら、それは規定の病の患部である。祭司はその人を調べ、汚れていると宣告する。</span>
<span className="v" id="v4" data-v="4" data-xref="民数記 12:15; コリント人への第一の手紙 4:5; テモテへの手紙第一 5:24"> もし彼の体の皮膚にある光る斑点が白く、皮膚より深く見えず、その毛が白く変わっていないなら、祭司は患部のあるその人を七日間隔離する。</span>
<span className="v" id="v5" data-v="5"> 祭司は七日目にその人を調べる。祭司の目に患部がとどまり、皮膚に広がっていないなら、さらに七日間隔離する。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 11:25; レビ記 14:8; 申命記 32:5"> 祭司は七日目に再び調べる。患部が薄くなり、皮膚に広がっていないなら、祭司はその人を清いと宣告する。それはかさぶたである。その人は衣服を洗えば清くなる。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 38:3; レビ記 13:35–36; テモテへの第二の手紙 2:16–17"> しかし、清めのために祭司に自分を見せた後で、そのかさぶたが皮膚に広がるなら、彼は再び祭司に自分を見せる。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイ 15:7–8; ピリピ人への手紙 3:18–19; 使徒の働き 8:21"> 祭司は彼を調べる。もしそのかさぶたが皮膚に広がっているなら、祭司は彼を汚れていると宣告する。それは規定の病である。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 規定の病の患部が人にある場合、その人を祭司のところに連れて来る。</span>
<span className="v" id="v10" data-v="10" data-xref="列王記第二 5:27; 歴代誌 第二 26:19–20; レビ記 13:14–15"> 祭司は彼を調べる。皮膚に白い腫れ物があり、それが毛を白く変え、腫れ物の中に生肉ができているなら、</span>
<span className="v" id="v11" data-v="11"> それは彼の体の皮膚にある慢性の規定の病である。祭司は彼を汚れていると宣告する。彼を隔離してはならない。彼はすでに汚れているからである。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨハネの手紙第一 1:8–10; ヨブ記 42:6; ローマ人への手紙 7:14"> もし規定の病が皮膚の至るところに広がり、祭司が見る限り、規定の病が患部のあるその人の頭から足に至るまで皮膚の全面を覆っているなら、</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネ 9:41; イザヤ書 64:6"> 祭司は彼を調べる。規定の病が彼の全身を覆っているなら、祭司はその患部について彼を清いと宣告する。それはすべて白く変わっているので、彼は清い。</span>
<span className="v" id="v14" data-v="14"> しかし、生肉が彼に現れたときはいつでも、彼は汚れる。</span>
<span className="v" id="v15" data-v="15"> 祭司はその生肉を調べ、彼を汚れていると宣告する。生肉は汚れている。それは規定の病である。</span>
<span className="v" id="v16" data-v="16" data-xref="ガラテヤ人への手紙 1:14–16; ローマ人への手紙 7:14–24; ピリピ人への手紙 3:6–8"> あるいは、生肉が再び変化して白く変わったなら、彼は祭司のところに来る。</span>
<span className="v" id="v17" data-v="17"> 祭司は彼を調べる。患部が白く変わっているなら、祭司はその患部について彼を清いと宣告する。彼は清い。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 9:9; イザヤ書 38:21; 詩篇 38:3–7"> 体の皮膚に腫れ物ができ、それが癒え、</span>
<span className="v" id="v19" data-v="19" data-xref="レビ記 13:24"> 腫れ物があった場所に白い腫れ物、あるいは赤みがかった白い光る斑点ができたなら、それを祭司に見せる。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネ 5:14; レビ記 13:3; ペテロの第二の手紙 2:20"> 祭司はそれを調べる。皮膚より深く見え、その毛が白く変わっているなら、祭司は彼を汚れていると宣告する。それは規定の病の患部である。それは腫れ物の中に発生したのである。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第一の手紙 5:5"> しかし、祭司がそれを調べ、そこに白い毛がなく、皮膚より深くなく薄くなっているなら、祭司は彼を七日間隔離する。</span>
<span className="v" id="v22" data-v="22"> もしそれが皮膚に広がっているなら、祭司は彼を汚れていると宣告する。それは患部である。</span>
<span className="v" id="v23" data-v="23" data-xref="ガラテヤ人への手紙 6:1; ヨブ記 34:31–32; マタイ 26:75"> しかし、その光る斑点がそこにとどまり、広がっていないなら、それは腫れ物の跡である。祭司は彼を清いと宣告する。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 3:24"> あるいは、体の皮膚に火によるやけどがあり、やけどの生肉が赤みがかった白い、あるいは白い光る斑点になったなら、</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 13:18–20; レビ記 13:4"> 祭司はそれを調べる。光る斑点の毛が白く変わり、皮膚より深く見えるなら、それは規定の病である。それはやけどの中に発生したのである。祭司は彼を汚れていると宣告する。それは規定の病の患部である。</span>
<span className="v" id="v26" data-v="26" data-xref="レビ記 13:23; レビ記 13:4–5"> しかし、祭司がそれを調べ、光る斑点の中に白い毛がなく、皮膚より深くなく薄くなっているなら、祭司は彼を七日間隔離する。</span>
<span className="v" id="v27" data-v="27"> 祭司は七日目に彼を調べる。もしそれが皮膚に広がっているなら、祭司は彼を汚れていると宣告する。それは規定の病の患部である。</span>
<span className="v" id="v28" data-v="28"> もし光る斑点がそこにとどまり、皮膚に広がっておらず、薄くなっているなら、それはやけどによる腫れ物である。祭司は彼を清いと宣告する。それはやけどの跡だからである。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 9:15; マタイ 13:14–15; コリント人への第二の手紙 4:3–4"> 男または女の頭あるいはひげに患部がある場合、</span>
<span className="v" id="v30" data-v="30" data-xref="レビ記 13:34–37; レビ記 14:54"> 祭司はその患部を調べる。患部が皮膚より深く見え、そこに黄色く細い毛があるなら、祭司はその人を汚れていると宣告する。それは白癬、すなわち頭またはひげに生じる規定の病である。</span>
<span className="v" id="v31" data-v="31"> 祭司がその白癬の患部を調べ、皮膚より深く見えず、そこに黒い毛がないなら、祭司は白癬の患部があるその者を七日間隔離する。</span>
<span className="v" id="v32" data-v="32" data-xref="レビ記 13:30; マタイ 23:5; ルカ 18:9–12"> 七日目に祭司は患部を調べる。白癬が広がっておらず、そこに黄色い毛がなく、白癬が皮膚より深くないなら、</span>
<span className="v" id="v33" data-v="33"> その者は毛を剃る。ただし、白癬のところを剃ってはならない。それから祭司は白癬のある者をさらに七日間隔離する。</span>
<span className="v" id="v34" data-v="34" data-xref="ユダ 1:22; ヨハネの手紙第一 4:1; ヨハネの黙示録 2:2"> 七日目に、祭司は白癬を調べる。白癬が皮膚に広がっておらず、皮膚より深く見えないなら、祭司は彼を清いと宣告する。彼は自分の衣服を洗う。そうすれば清くなる。</span>
<span className="v" id="v35" data-v="35" data-xref="レビ記 13:27; テモテへの第二の手紙 2:16–17; レビ記 13:7"> しかし、彼が清くされた後に白癬が皮膚に広がるなら、</span>
<span className="v" id="v36" data-v="36"> 祭司は彼を調べる。白癬が皮膚に広がっているなら、祭司は黄色い毛を探す必要はない。彼は汚れている。</span>
<span className="v" id="v37" data-v="37"> しかし、祭司の目に白癬がとどまっており、そこに黒い毛が生えているなら、白癬は癒えている。彼は清い。祭司は彼を清いと宣告する。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> 男または女の体の皮膚に光る斑点、すなわち白い光る斑点がある場合、</span>
<span className="v" id="v39" data-v="39" data-xref="ローマ人への手紙 7:22–25; ヤコブの手紙 3:2; 伝道者の書 7:20"> 祭司はそれらを調べる。彼らの体の皮膚にある光る斑点が鈍い白色であるなら、それは無害な発疹である。それは皮膚に発生したのである。その者は清い。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="ガラテヤ人への手紙 4:13; ローマ人への手紙 8:10; 雅歌 5:11"> 男の頭の毛が抜け落ちたなら、彼ははげである。彼は清い。</span>
<span className="v" id="v41" data-v="41"> もしその毛が頭の前部から抜け落ちたなら、彼は前頭はげである。彼は清い。</span>
<span className="v" id="v42" data-v="42"> しかし、はげ頭、あるいは前頭はげのところに赤みがかった白い患部があるなら、それは彼のはげ頭、あるいは前頭はげに発生した規定の病である。</span>
<span className="v" id="v43" data-v="43"> 祭司は彼を調べる。彼のはげ頭、あるいは前頭はげにある患部の腫れ物が赤みがかった白色で、体の皮膚にある規定の病のような見た目であるなら、</span>
<span className="v" id="v44" data-v="44" data-xref="ペテロの第二の手紙 2:1–2; マタイ 6:23; イザヤ書 1:5"> 彼は規定の病の者である。彼は汚れている。祭司は彼を確かに汚れていると宣告する。彼の患部は頭にある。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="ミカ書 3:7; レビ記 10:6; エゼキエル書 24:17"> 患部のある規定の病の者は、衣服を裂き、頭髪を乱したままにし、口元を覆って、「汚れている、汚れている」と叫ぶ。</span>
<span className="v" id="v46" data-v="46" data-xref="列王記第二 7:3; 列王記第二 15:5; 歴代誌 第二 26:21"> その患部が彼にある間、彼は汚れている。彼は汚れている。彼は一人で住む。彼の住まいは宿営の外である。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="ユダ 1:23; ローマ人への手紙 13:12; エゼキエル書 16:16"> また、規定の病の患部がある衣服、それが羊毛の衣服であれ、亜麻布の衣服であれ、</span>
<span className="v" id="v48" data-v="48" data-xref="レビ記 13:51; ヨハネの黙示録 3:4; 申命記 8:11"> それが亜麻布または羊毛の縦糸であれ横糸<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="縦糸と横糸は織物の縦と横の糸である。">a</a></sup>であれ、革であれ、革で作られたどんなものであれ、</span>
<span className="v" id="v49" data-v="49"> もし衣服、革、縦糸、横糸、あるいは革で作られたどんなものにおいても、その患部が緑がかった色、あるいは赤みがかった色であるなら、それは規定の病の患部であり、祭司に見せる。</span>
<span className="v" id="v50" data-v="50" data-xref="エゼキエル書 44:23"> 祭司はその患部を調べ、その患部を七日間隔離する。</span>
<span className="v" id="v51" data-v="51" data-xref="レビ記 14:44"> 彼は七日目にその患部を調べる。もしその患部が、衣服、縦糸、横糸、あるいは革、その革がどのような用途に使われるものであれ、そこに広がっているなら、その患部は悪性のカビである。それは汚れている。</span>
<span className="v" id="v52" data-v="52" data-xref="レビ記 11:35; レビ記 11:33; レビ記 14:44–45"> 患部がある衣服、すなわち羊毛あるいは亜麻布の縦糸であれ横糸であれ、またはどんな革製品であれ、彼はそれを燃やす。それは悪性のカビだからである。それは火で燃やす。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53"> もし祭司がそれを調べ、患部が衣服、縦糸、横糸、あるいはどんな革製品においても広がっていないなら、</span>
<span className="v" id="v54" data-v="54"> 祭司は患部があるものを洗うように命じる。そして彼はそれをさらに七日間隔離する。</span>
<span className="v" id="v55" data-v="55" data-xref="エゼキエル書 24:13; ヘブル人への手紙 6:4–8; ペテロの第二の手紙 2:20–22"> 患部が洗われた後、祭司はそれを調べる。患部の色が変わっておらず、患部が広がっていなくても、それは汚れている。あなたはそれを火で燃やす。内側であれ外側であれ、それはカビの侵食である。</span>
<span className="v" id="v56" data-v="56"> もし祭司が見て、それが洗われた後に患部が薄くなっているなら、彼は衣服、あるいは革、あるいは縦糸、あるいは横糸からそれを引き裂く。</span>
<span className="v" id="v57" data-v="57" data-xref="マタイ 22:7; ヨハネの黙示録 21:8; マタイ 3:12"> そしてもしそれが衣服、縦糸、横糸、あるいはどんな革製品に再び現れるなら、それは広がっている。あなたは患部があるものを火で燃やす。</span>
<span className="v" id="v58" data-v="58" data-xref="列王記第二 5:14; ヨハネの黙示録 1:5; 詩篇 51:2"> あなたが洗った衣服、縦糸、横糸、あるいはいかなる革製品であれ、そこから患部が消え去ったなら、それを二度目に洗う。そうすればそれは清くなる。」</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59"> これが、羊毛あるいは亜麻布の衣服、縦糸、横糸、あるいはどんな革製品におけるカビの患部について、それが清いか汚れているかを宣告するための律法である。</span>
</div>
</div>

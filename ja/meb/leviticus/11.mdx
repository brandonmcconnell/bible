<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセとアロンに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 15:11; レビ記 11:11; ヘブル人への手紙 9:10"> 「イスラエルの子らに告げなさい。『地上のすべての動物のうち、あなたがたが食べてもよい生き物は次のとおりである。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 2:10; コリント人への第二の手紙 6:17; 申命記 6:6–7"> 動物のうち、ひづめが完全に二つに分かれ、反すうするものはすべて食べてもよい。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 『ただし、反すうするもの、あるいはひづめが分かれているもののうち、これらは食べてはならない。ラクダは反すうするが、ひづめが分かれていないため、あなたがたには汚れたものである。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 104:18; 箴言 30:26; マタイ 7:26"> ハイラックス<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または岩アナグマ、またはコニー。">a</a></sup>は反すうするが、ひづめが分かれていないため、あなたがたには汚れたものである。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 14:7"> 野うさぎは反すうするが、ひづめが分かれていないため、あなたがたには汚れたものである。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 66:17; イザヤ書 65:4; イザヤ書 66:3"> 豚は、ひづめが分かれ、完全に割れているが、反すうしないため、あなたがたには汚れたものである。</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 52:11; コロサイ人への手紙 2:16; ヘブル人への手紙 9:10"> あなたがたはこれらの肉を食べてはならない。その死骸に触れてはならない。これらはあなたがたには汚れたものである。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ガラテヤ人への手紙 5:6; ヤコブの手紙 2:18; 使徒の働き 20:21"> 『水の中にいるすべてのもののうち、これらは食べてもよい。水の中、すなわち海や川にいるもののうち、ひれとうろこがあるものはすべて食べてもよい。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 29:27; レビ記 7:18; 詩篇 139:21–22"> 海や川にいて、ひれとうろこがないもの、すなわち水の中で動くすべてのもの、水の中にいるすべての生き物は、あなたがたには忌まわしいものである。</span>
<span className="v" id="v11" data-v="11"> あなたがたはそれらを忌み嫌う。その肉を食べてはならない。その死骸を忌み嫌う。</span>
<span className="v" id="v12" data-v="12"> 水の中にいて、ひれとうろこがないものはすべて、あなたがたには忌まわしいものである。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨブ記 39:27–30; エレミヤ書 4:22; テトス 3:3"> 『鳥のうち、これらを忌み嫌う。これらは忌まわしいものなので食べてはならない。すなわち、鷲、はげわし、黒はげわし、</span>
<span className="v" id="v14" data-v="14"> 赤とび、あらゆる種類の黒とび、</span>
<span className="v" id="v15" data-v="15" data-xref="ルカ 12:24; 列王記第一 17:6; 箴言 30:17"> あらゆる種類のからす、</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 34:11–15; エペソ人への手紙 5:7–11; エペソ人への手紙 2:2–3"> ワシミミズク、コノハズク、かもめ、あらゆる種類の鷹、</span>
<span className="v" id="v17" data-v="17"> 小ふくろう、鵜、大ふくろう、</span>
<span className="v" id="v18" data-v="18"> 白ふくろう、荒野のふくろう、みさご、</span>
<span className="v" id="v19" data-v="19"> こうのとり、あらゆる種類のさぎ、やつがしら、こうもりである。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="テモテへの第二の手紙 4:10; ピリピ人への手紙 3:18–19; レビ記 11:23"> 『羽があり、四つ足で歩く群がるものはすべて、あなたがたには忌まわしい。</span>
<span className="v" id="v21" data-v="21"> ただし、羽があり四つ足で歩く群がるもののうち、地上を跳ねるための関節のある脚を持つものは食べてもよい。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイ 3:4; マルコ 1:6; 出エジプト記 10:4–5"> これらのうち、食べてもよいものは次のとおりである。あらゆる種類のいなご、あらゆる種類のキリギリス、あらゆる種類のこおろぎ、あらゆる種類のばったである。</span>
<span className="v" id="v23" data-v="23"> しかし、四つの足を持つその他の羽のある這うものはすべて、あなたがたには忌まわしいものである。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="コリント人への第一の手紙 15:33; エペソ人への手紙 2:1–3; コリント人への第二の手紙 6:17"> 『以下のものによって、あなたがたは汚れる。これらの死骸に触れる者はだれでも、夕方まで汚れる。</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 15:5; レビ記 14:8; 民数記 31:24"> これらの死骸の一部でも運ぶ者は、自分の衣服を洗う。その者は夕方まで汚れる。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 『ひづめが分かれているが完全に割れていない動物、または反すうしないすべての動物は、あなたがたには汚れたものである。これらに触れる者はだれでも汚れる。</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 11:23; レビ記 11:20"> 四つ足で歩くすべての動物のうち、足の裏で歩くものはすべて、あなたがたには汚れたものである。その死骸に触れる者はだれでも、夕方まで汚れる。</span>
<span className="v" id="v28" data-v="28" data-xref="レビ記 11:24–25"> その死骸を運ぶ者は、自分の衣服を洗う。その者は夕方まで汚れる。これらはあなたがたには汚れたものである。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="レビ記 11:41–42; テモテへの第二の手紙 3:2–5; 詩篇 10:3"> 『地上を這うもののうち、あなたがたに汚れたものは次のとおりである。いたち、ねずみ、あらゆる種類の大きなとかげ、</span>
<span className="v" id="v30" data-v="30"> やもり、おおとかげ、壁とかげ、すきんく、カメレオンである。</span>
<span className="v" id="v31" data-v="31" data-xref="レビ記 11:24–25; レビ記 11:8"> 這うすべてのもののうち、これらはあなたがたには汚れたものである。これらが死んだときに触れる者はだれでも、夕方まで汚れる。</span>
<span className="v" id="v32" data-v="32" data-xref="レビ記 15:12; テトス 3:5; テトス 2:14"> それらが死んで何かの上に落ちたなら、その物は汚れる。木の器、衣服、皮、袋など、何かに用いる器はすべて水に入れる。それは夕方まで汚れ、その後は清くなる。</span>
<span className="v" id="v33" data-v="33" data-xref="レビ記 6:28; レビ記 15:12; レビ記 14:45"> これらのいずれかが土の器の中に落ちたなら、その中にあるものはすべて汚れる。あなたがたはその器を砕く。</span>
<span className="v" id="v34" data-v="34" data-xref="テトス 1:15; 箴言 21:4; 箴言 21:27"> 食べることのできる食物で、水に浸されたものはすべて汚れる。そのような器の中で飲むことのできる飲み物もすべて汚れる。</span>
<span className="v" id="v35" data-v="35" data-xref="レビ記 15:12; レビ記 6:28; レビ記 11:33"> これらの死骸の一部が落ちたものはすべて汚れる。それがかまどであれ、鍋を置く台であれ、打ち砕く。これらは汚れたものであり、あなたがたにとっても汚れたものとなる。</span>
<span className="v" id="v36" data-v="36" data-xref="ゼカリヤ書 13:1; ヨハネ 4:14"> しかし、泉や水をためる貯水池は清いままである。ただし、その死骸に触れたものは汚れる。</span>
<span className="v" id="v37" data-v="37" data-xref="コリント人への第一の手紙 15:37; ペテロの手紙第一 1:23; ヨハネの手紙第一 5:18"> これらの死骸の一部が、これから蒔かれる種の上に落ちても、それは清い。</span>
<span className="v" id="v38" data-v="38"> しかし、水が種にかけられており、その上にこれらの死骸の一部が落ちたなら、それはあなたがたには汚れたものである。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="レビ記 11:40; レビ記 11:24; レビ記 15:7"> 『あなたがたが食べてもよい動物が死んだ場合、その死骸に触れる者は夕方まで汚れる。</span>
<span className="v" id="v40" data-v="40" data-xref="レビ記 22:8; エゼキエル書 44:31; 申命記 14:21"> その死骸を食べる者は自分の衣服を洗う。その者は夕方まで汚れる。その死骸を運ぶ者も自分の衣服を洗う。その者は夕方まで汚れる。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="レビ記 11:29; レビ記 11:20; レビ記 11:23"> 『地上を這うすべてのものは忌まわしい。それは食べてはならない。</span>
<span className="v" id="v42" data-v="42" data-xref="テトス 1:12; イザヤ書 65:25; コリント人への第二の手紙 11:3"> 腹ばいで進むもの、四つ足で歩くもの、多くの足を持つものなど、地上を這うすべてのものを食べてはならない。それらは忌まわしいからである。</span>
<span className="v" id="v43" data-v="43" data-xref="レビ記 20:25; レビ記 11:41–42"> 這うどんな生き物によっても、自分を忌まわしいものにしてはならない。それらによって身を汚してはならない。</span>
<span className="v" id="v44" data-v="44" data-xref="出エジプト記 20:2; ペテロの手紙第一 1:15–16; レビ記 19:2"> わたしはあなたがたの神、主だからである。それゆえ、自らを聖別し、聖なる者となりなさい。わたしは聖なる者だからである。地上を動くどんな這うものによっても、身を汚してはならない。</span>
<span className="v" id="v45" data-v="45" data-xref="レビ記 11:44; 出エジプト記 20:2; 出エジプト記 6:7"> わたしはあなたがたの神となるために、エジプトの地からあなたがたを導き上った主である。それゆえ、あなたがたは聖なる者となりなさい。わたしは聖なる者だからである。』</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="レビ記 14:54; レビ記 15:32; エゼキエル書 43:12"> これが、動物、鳥、水の中を動くすべての生き物、そして地上を這うすべての生き物についての律法であり、</span>
<span className="v" id="v47" data-v="47" data-xref="レビ記 10:10; エゼキエル書 44:23; ローマ人への手紙 14:13–23"> 汚れたものと清いもの、食べられる生き物と食べられない生き物を区別するためのものである。」</span>
</div>
</div>

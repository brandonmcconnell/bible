<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 23:4; レビ記 23:37; 民数記 29:39"> 「イスラエルの子らに告げなさい。『あなたがたが聖なる集会として布告すべき主の定められた祭り、これらがわたしの定められた祭りである。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="レビ記 19:3; 出エジプト記 23:12; 出エジプト記 35:2–3"> 『六日間は仕事をしてもよいが、七日目は厳かな安息日であり、聖なる集会の日である。いかなる仕事もしてはならない。これはあなたがたのすべての住まいにおける主への安息日である。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="レビ記 23:2; 出エジプト記 23:14; レビ記 23:37"> 『主の定められた祭り、すなわちあなたがたがその定められた時に布告すべき聖なる集会は次のとおりである。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 5:10; 申命記 16:1–8; 民数記 28:16–17"> 第一の月の十四日の夕暮れには主の過越の祭りがある。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 34:18; 申命記 16:8; 出エジプト記 12:15–16"> 同じ月の十五日は主への種なしパンの祭りである。七日間、種なしパンを食べる。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 28:18–25; レビ記 23:8; レビ記 23:21"> 最初の日に、あなたがたは聖なる集会を開きなさい。通常の仕事をしてはならない。</span>
<span className="v" id="v8" data-v="8"> 七日間、主への火によるささげ物をささげなさい。七日目は聖なる集会である。通常の仕事をしてはならない。』」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 主はモーセに告げられた。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 34:26; 出エジプト記 23:19; 申命記 16:9"> 「イスラエルの子らに告げなさい。『わたしがあなたがたに与える地に入り、その収穫を刈り入れるとき、あなたがたの収穫の初穂の束を祭司のところに持って来る。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 29:24; レビ記 10:14; レビ記 9:21"> 祭司は、あなたがたが受け入れられるように、主の前でその束を揺り動かす。安息日の翌日にそれを揺り動かす。</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 10:10–12; ペテロの手紙第一 1:19; レビ記 1:10"> その束を揺り動かす日に、あなたがたは一歳の傷のない雄の子羊を、主への全焼のささげ物としてささげなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 2:14–16; ヨエル書 1:9; 民数記 28:10"> それに伴う穀物のささげ物は、油を混ぜた十分の二エパ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一エパは約22リットル、または約3分の2ブッシェルである。">a</a></sup>の上質の小麦粉であり、芳ばしい香りのための主への火によるささげ物とする。それに伴う飲み物のささげ物は、四分の一ヒン<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一ヒンは約6.5リットル、または1.7ガロンである。">b</a></sup>のぶどう酒とする。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 34:26; 創世記 4:4–5; レビ記 3:17"> あなたがたは自分の神へのささげ物を持って来るこの日までは、パンも、炒った穀物も、新しい穀物も食べてはならない。これは、あなたがたのすべての住まいで、代々にわたっての永遠の掟である。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="レビ記 23:10–11; レビ記 25:8; 申命記 16:9–10"> 『あなたがたは、揺り動かすささげ物の束を持って来た日、すなわち安息日の翌日から数えなさい。七回の安息日を満了する。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 2:1; 民数記 28:26"> 七回目の安息日の翌日まで数えて五十日とし、主への新しい穀物のささげ物をささげなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="レビ記 23:10; 出エジプト記 34:26; 出エジプト記 34:22"> あなたがたは揺り動かすささげ物として、自分の住まいから二つのパンを持って来なさい。それは十分の二エパ<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一エパは約22リットル、または約3分の2ブッシェルである。">c</a></sup>の上質の小麦粉で作られ、パン種を入れて焼かれたもので、主への初穂とする。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 28:27–31; レビ記 23:12–13; マラキ書 1:13–14"> そのパンとともに、一歳の傷のない七頭の子羊と、若い雄牛一頭と、雄羊二頭をささげなさい。これらは主への全焼のささげ物となり、それに伴う穀物のささげ物と飲み物のささげ物とともに、主への芳ばしい香りのための、火によるささげ物となる。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 28:30; レビ記 4:23–28; レビ記 7:11–18"> 贖罪のささげ物として雄山羊一頭を、和解のいけにえのささげ物として一歳の雄の子羊二頭をささげなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 18:4; エペソ人への手紙 2:14; 民数記 18:8–12"> 祭司はそれらを、初穂のパンおよび二頭の子羊とともに、主の前で揺り動かすささげ物として揺り動かす。これらは主に対する聖なるものとなり、祭司のものとなる。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 23:2; レビ記 23:4; 民数記 18:23"> あなたがたは同じ日に布告しなさい。それはあなたがたにとって聖なる集会となる。通常のいかなる仕事もしてはならない。これは、あなたがたのすべての住まいで、代々にわたっての永遠の掟である。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命記 24:19–21; レビ記 19:9–10; イザヤ書 58:10"> 『あなたがたの土地の収穫を刈り入れるとき、畑の隅々まで刈り尽くしてはならない。収穫の落ち穂を拾い集めてはならない。貧しい者と寄留者のためにそれらを残しておく。わたしはあなたがたの神、主である。』」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 主はモーセに告げられた。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第一の手紙 15:52; テサロニケ人への手紙第一 4:16; レビ記 25:9"> 「イスラエルの子らに告げなさい。『第七の月の最初の日に、あなたがたは厳かな安息を守り、ラッパを吹き鳴らす記念とし、聖なる集会を開きなさい。</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 23:21"> 通常のいかなる仕事もしてはならない。主への火によるささげ物をささげなさい。』」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 主はモーセに告げられた。</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 16:29–31; 出エジプト記 30:10; レビ記 16:24"> 「ただし、この第七の月の十日は贖罪の日である。それはあなたがたにとって聖なる集会となる。あなたがたは身を慎み、主への火によるささげ物をささげなさい。</span>
<span className="v" id="v28" data-v="28" data-xref="ゼカリヤ書 3:9; レビ記 16:34; ヘブル人への手紙 10:10"> その日にはいかなる仕事もしてはならない。これは贖罪の日であり、あなたがたの神、主の前であなたがたのために贖いを行うためである。</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 17:14; 民数記 5:2; レビ記 23:27"> その日に身を慎まない者はだれでも、自分の民の中から断たれる。</span>
<span className="v" id="v30" data-v="30" data-xref="レビ記 20:3; ゼパニヤ書 2:5; エレミヤ書 15:7"> その日にいかなる仕事をする者も、わたしはその人をその民の中から滅ぼす。</span>
<span className="v" id="v31" data-v="31"> いかなる仕事もしてはならない。これは、あなたがたのすべての住まいで、代々にわたっての永遠の掟である。</span>
<span className="v" id="v32" data-v="32" data-xref="レビ記 16:31; マタイ 11:28–30; 詩篇 69:10–11"> これはあなたがたにとって厳かな安息の安息日であり、身を慎む。その月の九日の夕暮れから翌日の夕暮れまで、安息日を守りなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 主はモーセに告げられた。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネ 7:2; ネヘミヤ記 8:14; エズラ記 3:4"> 「イスラエルの子らに告げなさい。『この第七の月の十五日は、主のための七日間にわたる仮庵の祭り<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="あるいは、天幕の祭り、またはスコット。">d</a></sup>である。</span>
<span className="v" id="v35" data-v="35" data-xref="レビ記 23:24–25; レビ記 23:7–8"> 最初の日は聖なる集会とする。通常のいかなる仕事もしてはならない。</span>
<span className="v" id="v36" data-v="36" data-xref="ネヘミヤ記 8:18; ヨハネ 7:37; 歴代誌 第二 7:8–11"> 七日間、主への火によるささげ物をささげなさい。八日目には、あなたがたのための聖なる集会を開きなさい。主への火によるささげ物をささげなさい。これは厳粛な集会である。通常の仕事をしてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="レビ記 23:2; レビ記 23:4; 伝道者の書 3:1"> 『これらが主の定められた祭りであり、あなたがたが聖なる集会として布告し、主への火によるささげ物、全焼のささげ物、穀物のささげ物、いけにえ、飲み物のささげ物を、それぞれその日にささげるためのものである。</span>
<span className="v" id="v38" data-v="38" data-xref="民数記 29:39; レビ記 19:3; エズラ記 2:68–69"> これは主の安息日に加えて、また、あなたがたが主に与えるささげ物に加えて、またすべての誓願に加えて、またすべての自発的なささげ物に加えて行われる。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出エジプト記 23:16; 申命記 16:13; レビ記 23:34"> 『それで、第七の月の十五日、あなたがたがその土地の産物を収穫し終えたとき、七日間にわたって主の祭りを守りなさい。最初の日は厳かな安息の日であり、八日目も厳かな安息の日である。</span>
<span className="v" id="v40" data-v="40" data-xref="ピリピ人への手紙 4:4; ヨハネの黙示録 7:9; 申命記 16:14–15"> 最初の日に、あなたがたは立派な木の実、なつめやしの葉、茂った木の枝、川の柳の枝を取り、七日間、あなたがたの神、主の前で喜び楽しみなさい。</span>
<span className="v" id="v41" data-v="41" data-xref="民数記 29:12; ネヘミヤ記 8:18"> 一年のうち七日間、主への祭りとしてこれを守りなさい。これはあなたがたの代々にわたっての永遠の掟である。第七の月にこれを守る。</span>
<span className="v" id="v42" data-v="42" data-xref="ネヘミヤ記 8:14–17; 創世記 33:17; 民数記 24:5"> あなたがたは七日間、仮庵<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="あるいは、仮小屋。">e</a></sup>に住む。イスラエルで生まれた者は皆、仮庵<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="あるいは、仮小屋。">f</a></sup>に住む。</span>
<span className="v" id="v43" data-v="43" data-xref="申命記 31:10–13; 詩篇 78:5–6; 出エジプト記 13:14"> それは、わたしがエジプトの地からイスラエルの子らを導き出したとき、彼らを仮庵<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="あるいは、仮小屋。">g</a></sup>に住まわせたことを、あなたがたの代々の人々が知るためである。わたしはあなたがたの神、主である。』」</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="レビ記 23:1–2; マタイ 18:20; レビ記 21:24"> こうしてモーセはイスラエルの子らに、主の定められた祭りについて告げた。</span>
</div>

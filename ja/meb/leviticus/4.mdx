<span className="v" id="v1" data-v="1"> 主はモーセに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 19:12; ヘブル人への手紙 9:7; レビ記 4:27"> 「イスラエルの子らに告げなさい。『もしだれかが、主がしてはならないと命じられたことのどれかを行って、意図せずに罪を犯したなら、</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 7:27–28; レビ記 4:14; レビ記 9:2"> もし油注がれた祭司が罪を犯して民に罪過をもたらしたなら、自分が犯した罪のために、傷のない若い牛を贖罪のささげ物として主にささげる。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 1:3–4; ダニエル書 9:26; イザヤ書 53:6"> 彼はその牛を主の前、会見の天幕の入り口に連れて来て、牛の頭に手を置き、主の前でその牛を屠る。</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 16:14; 民数記 19:4; レビ記 4:16–17"> 油注がれた祭司はその牛の血の一部を取り、会見の天幕の中に持って行く。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 16:14; レビ記 14:18; レビ記 26:28"> 祭司は指を血に浸し、主の前、すなわち聖所の垂れ幕の前で、血の一部を七度振りかける。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 8:15; レビ記 9:9; レビ記 16:18"> 祭司はその血の一部を、会見の天幕の中にある主の前の香りのよい香の祭壇の角に塗る。そして牛の残りの血をすべて、会見の天幕の入り口にある全焼のささげ物の祭壇の土台に注ぎ出す。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 3:3–5; レビ記 4:26; レビ記 4:31"> 彼は贖罪のささげ物である牛からすべての脂肪を取り外す。すなわち、内臓を覆う脂肪と、内臓についているすべての脂肪、</span>
<span className="v" id="v9" data-v="9" data-xref="レビ記 3:4"> 二つの腎臓と、腰のあたりにあるそれらの上の脂肪、および腎臓と一緒に取り外す肝臓の覆いである。</span>
<span className="v" id="v10" data-v="10"> 和解のいけにえの牛から取り外されるのと同じように、これらを取り外す。祭司はそれらを全焼のささげ物の祭壇の上で燃やす。</span>
<span className="v" id="v11" data-v="11" data-xref="民数記 19:5; 出エジプト記 29:14; レビ記 9:8–11"> その牛の皮、すべての肉、頭、足、内臓、糞、</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 13:11; 出エジプト記 29:14; レビ記 16:27"> すなわち牛の残りのすべての部分は、宿営の外の清い場所、灰を捨てる場所に運び出し、薪の上の火で燃やす。それは灰を捨てる場所で燃やされる。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="レビ記 5:17; レビ記 5:2–5; ホセア書 5:15"> 『もしイスラエルの全会衆が罪を犯し、そのことが集会の目から隠されており、主がしてはならないと命じられたことのどれかを行って罪過がある場合、</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 4:23; レビ記 4:3; レビ記 4:28"> 彼らが犯した罪が知られるようになったとき、集会は贖罪のささげ物として若い牛をささげ、それを会見の天幕の前に連れて来る。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 1:4; レビ記 16:21; レビ記 8:14"> 会衆の長老たちは、主の前でその牛の頭に手を置く。そしてその牛は主の前で屠られる。</span>
<span className="v" id="v16" data-v="16" data-xref="レビ記 4:5–12; ヘブル人への手紙 9:12–14"> 油注がれた祭司はその牛の血の一部を、会見の天幕の中に持って行く。</span>
<span className="v" id="v17" data-v="17" data-xref="レビ記 4:6–7"> 祭司は指を血に浸し、主の前、垂れ幕の前で、それを七度振りかける。</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 4:7"> 彼はその血の一部を、会見の天幕の中にある主の前の祭壇の角に塗る。そして残りの血をすべて、会見の天幕の入り口にある全焼のささげ物の祭壇の土台に注ぎ出す。</span>
<span className="v" id="v19" data-v="19" data-xref="レビ記 5:6; レビ記 4:26; 民数記 15:25"> 彼はそこからすべての脂肪を取り外し、祭壇の上で燃やす。</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 15:25; ヘブル人への手紙 10:10–12; レビ記 12:8"> 最初の贖罪のささげ物の牛にしたのと同じように、この牛にも行う。祭司が彼らのために贖いを行えば、彼らは赦される。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 16:15; マタイ 20:28; コリント人への第二の手紙 5:21"> 彼はその牛を宿営の外に運び出し、最初の牛を燃やしたようにそれを燃やす。これは集会のための贖罪のささげ物である。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="レビ記 4:2; レビ記 4:13; 民数記 31:13"> 『指導者が罪を犯し、彼の神、主がしてはならないと命じられたすべてのことのどれかを意図せずに行って罪過がある場合、</span>
<span className="v" id="v23" data-v="23" data-xref="レビ記 4:14; ローマ人への手紙 8:3; 民数記 7:22"> 自分が犯した罪を知らされたなら、彼は自分のささげ物として、傷のない雄山羊を持って来る。</span>
<span className="v" id="v24" data-v="24" data-xref="レビ記 3:13; レビ記 7:2; レビ記 4:3–35"> 彼はその山羊の頭に手を置き、主の前で全焼のささげ物を屠る場所でそれを屠る。これは贖罪のささげ物である。</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 4:7; レビ記 4:18; レビ記 4:30"> 祭司は贖罪のささげ物の血の一部を指に取り、全焼のささげ物の祭壇の角に塗る。残りの血は全焼のささげ物の祭壇の土台に注ぎ出す。</span>
<span className="v" id="v26" data-v="26" data-xref="レビ記 4:20; レビ記 4:31; レビ記 4:35"> そのすべての脂肪は、和解のいけにえの脂肪のように、祭壇の上で燃やす。祭司が彼の罪について彼のために贖いを行うなら、彼は赦される。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="レビ記 4:2; 民数記 15:27; レビ記 4:13"> 『もし一般の民のだれかが、主がしてはならないと命じられたことのどれかを行って、意図せずに罪を犯し、罪過があり、</span>
<span className="v" id="v28" data-v="28" data-xref="レビ記 4:23; レビ記 4:3; レビ記 4:32"> 自分が犯した罪を知らされたなら、彼は自分が犯した罪のために、自分のささげ物として傷のない雌山羊を持って来る。</span>
<span className="v" id="v29" data-v="29" data-xref="レビ記 4:4; レビ記 4:24; レビ記 1:4"> 彼はその贖罪のささげ物の頭に手を置き、全焼のささげ物をささげる場所でその贖罪のささげ物を屠る。</span>
<span className="v" id="v30" data-v="30" data-xref="レビ記 4:7; レビ記 4:25; レビ記 4:34"> 祭司はその血の一部を指に取り、全焼のささげ物の祭壇の角に塗る。そして残りの血をすべて祭壇の土台に注ぎ出す。</span>
<span className="v" id="v31" data-v="31" data-xref="レビ記 4:26; レビ記 4:35; レビ記 1:9"> そのすべての脂肪は、和解のいけにえから脂肪が取り外されるように取り外す。祭司はそれを主への芳ばしい香りとして祭壇の上で燃やす。祭司が彼のために贖いを行うなら、彼は赦される。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="レビ記 4:28; ペテロの手紙第一 3:18; ペテロの手紙第一 2:22"> 『もし彼が贖罪のささげ物として子羊を持って来るなら、傷のない雌を持って来る。</span>
<span className="v" id="v33" data-v="33" data-xref="レビ記 4:29–31; レビ記 4:4"> 彼はその贖罪のささげ物の頭に手を置き、全焼のささげ物を屠る場所で、それを贖罪のささげ物として屠る。</span>
<span className="v" id="v34" data-v="34" data-xref="レビ記 4:30; レビ記 4:25; レビ記 4:7"> 祭司は贖罪のささげ物の血の一部を指に取り、全焼のささげ物の祭壇の角に塗る。残りの血はすべて祭壇の土台に注ぎ出す。</span>
<span className="v" id="v35" data-v="35" data-xref="レビ記 4:26; レビ記 4:20; レビ記 14:18"> 和解のいけにえから子羊の脂肪が取り外されるように、そのすべての脂肪を取り外す。祭司は主への火によるささげ物の上で、それらを祭壇の上で燃やす。祭司が彼の犯した罪について彼のために贖いを行うなら、彼は赦される。』」</span>
</div>

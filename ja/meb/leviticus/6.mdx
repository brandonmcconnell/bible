<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="コロサイ人への手紙 3:9; 使徒の働き 5:4; レビ記 5:15"> 「もしだれかが主に背き、預かり物、取引、強奪に関して隣人を欺き、あるいは隣人をしいたげ、</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 23:4; レビ記 19:12; 出エジプト記 22:9–11"> または失くした物を見つけたのにそれについて嘘をつき、偽って誓うなど、人が行って罪となるこれらのことのいずれかを行ったなら、</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 18:18; アモス書 3:10; レビ記 5:3–4"> そのように罪を犯して有罪となったなら、彼は強奪したもの、しいたげて得たもの、預けられたもの、または彼が見つけた失くした物を返還する。</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 5:16; ルカ 19:8; 民数記 5:7–8"> あるいは、偽って誓ったものすべてについて、その全額を返還し、さらにその五分の一を加える。有罪とされる日に、それを本来の持ち主に返還する。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 5:15; レビ記 5:18; イザヤ書 53:10–11"> 彼は主への償いのささげ物を祭司のもとに持って来る。すなわち、羊の群れから、あなたの評価額に従う傷のない雄羊を、償いのささげ物として持って来る。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 4:26; ヨハネの手紙第一 1:9; ヨハネの手紙第一 2:1–2"> 祭司が主の前で彼のために贖いを行うなら、彼が有罪となったどんなことについても赦される。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 主はモーセに告げられた。</span>
<span className="v" id="v9" data-v="9" data-xref="レビ記 6:12–13; 民数記 28:3; 出エジプト記 29:38–42"> 「アロンとその子らに命じなさい。『全焼のささげ物についての律法は次のとおりである。全焼のささげ物は朝まで一晩中、祭壇の炉床の上に置き、祭壇の火を絶やしてはならない。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 28:39–43; レビ記 16:4; レビ記 1:13"> 祭司は亜麻布の衣を身に着け、その身に亜麻布のももひきを着ける。そして祭壇の上で火が全焼のささげ物を焼き尽くした後の灰を取り除き、それを祭壇のそばに置く。</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 4:12; エゼキエル書 44:19; ヘブル人への手紙 13:11–13"> 彼はその衣を脱ぎ、別の衣を着て、その灰を宿営の外の清い場所に運び出す。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 9:24; 出エジプト記 29:38–42; ネヘミヤ記 13:31"> 祭壇の上の火はその上で燃え続けていなければならず、消してはならない。祭司は毎朝その上で薪を燃やし、その上に全焼のささげ物を整えて並べ、その上で和解のいけにえの脂肪を燃やす。</span>
<span className="v" id="v13" data-v="13"> 祭壇の火は絶えず燃やし続け、決して消してはならない。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数記 15:4; レビ記 2:1–2; ヨハネ 6:32"> 『穀物のささげ物についての律法は次の通りである。アロンの子らはそれを、主の前、祭壇の前にささげる。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 2:2; レビ記 2:9"> 祭司はそこから、穀物のささげ物の上質の小麦粉と油をひとつかみ、また穀物のささげ物の上にあるすべての乳香を取り、その記念の部分として、主への芳ばしい香りとして祭壇の上で燃やす。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 44:29; レビ記 2:3; レビ記 10:12–13"> その残りはアロンとその子らが食べる。それはパン種を入れずに、聖なる場所で食べる。彼らは会見の天幕の庭でそれを食べる。</span>
<span className="v" id="v17" data-v="17" data-xref="レビ記 2:3; レビ記 2:11; 民数記 18:9–10"> それはパン種を入れて焼いてはならない。わたしはそれを、わたしの火によるささげ物の中から彼らへの分として与えた。それは、贖罪のささげ物や償いのささげ物と同様に、最も聖なるものである。</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 6:29; 民数記 18:10; ハガイ書 2:12–14"> アロンの子らのうちの男子は皆、これを食べる。これは、主への火によるささげ物の中から、あなたがたの代々にわたって永遠に彼らの分となる。それらに触れるものはすべて聖なるものとなる。』」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 主はモーセに告げられた。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 29:2; 出エジプト記 16:36; レビ記 2:1–16"> 「アロンとその子らが、アロンの油注ぎの日に主にささげるものは次のとおりである。日ごとの穀物のささげ物として、十分の一エパ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一エパは約22リットル、または約3分の2ブッシェルである。">a</a></sup>の上質の小麦粉を、半分は朝に、半分は夕方にささげる。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 2:5; レビ記 7:9; 歴代誌上 9:31"> それを油でよく練り、平鍋で焼いて携えて来る。焼いたものを細かくして穀物のささげ物とし、主への芳ばしい香りとしてささげる。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 29:22–25; イザヤ書 53:10; レビ記 8:21"> 彼の子らの中から、彼の代わりに油注がれる祭司が、これをささげる。これは永遠の掟であり、それは主のために完全に焼き尽くされる。</span>
<span className="v" id="v23" data-v="23" data-xref="レビ記 2:10; レビ記 6:16–17"> 祭司の穀物のささげ物はすべて、完全に焼き尽くされる。食べてはならない。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 主はモーセに告げられた。</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 4:24; レビ記 1:11; レビ記 1:3"> 「アロンとその子らに告げなさい。『贖罪のささげ物についての律法は次の通りである。全焼のささげ物を屠る場所で、贖罪のささげ物を主の前で屠る。これは最も聖なるものである。</span>
<span className="v" id="v26" data-v="26" data-xref="レビ記 10:17–18; エゼキエル書 44:28–29; ホセア書 4:8"> 罪のためにそれをささげる祭司が、それを食べる。それは聖なる場所、会見の天幕の庭で食べる。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 29:37; ハガイ書 2:12; コリント人への第二の手紙 7:1"> その肉に触れるものはすべて聖なるものとなる。その血が衣服に少しでも振りかけられたなら、あなたはその振りかけられた部分を聖なる場所で洗う。</span>
<span className="v" id="v28" data-v="28" data-xref="レビ記 11:33; レビ記 15:12; ヘブル人への手紙 9:9–10"> それを煮た土の器は砕く。もしそれが青銅の器で煮られたなら、その器は磨き、水ですすぐ。</span>
<span className="v" id="v29" data-v="29" data-xref="レビ記 6:25; レビ記 6:17–18; 民数記 18:10"> 祭司の男子は皆、これを食べる。これは最も聖なるものである。</span>
<span className="v" id="v30" data-v="30" data-xref="レビ記 10:18; レビ記 16:27–28; ヘブル人への手紙 13:11"> しかし、聖所で贖いを行うために、その血のいくらかが会見の天幕の中に持ち込まれた贖罪のささげ物は、いっさい食べてはならない。それは火で焼く。</span>
</div>

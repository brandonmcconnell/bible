<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="レビ記 19:4; 申命記 27:15; 民数記 33:52"> 『あなたがたは自分たちのために偶像を造ってはならない。また、彫像や石柱を立ててはならず、あなたがたの地に模様のある石を置いて、それにひれ伏してはならない。わたしはあなたがたの神、主だからである。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="レビ記 19:30"> 『わたしの安息日を守り、わたしの聖所を敬いなさい。わたしは主である。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 1:19; 申命記 11:13–15; 申命記 28:1–14"> 『もしあなたがたがわたしの掟に従って歩み、わたしの命令を守り、それらを行うなら、</span>
<span className="v" id="v4" data-v="4" data-xref="ゼカリヤ書 8:12; 詩篇 67:6; レビ記 25:21"> わたしは季節に応じてあなたがたに雨を与える。地はその産物をもたらし、野の木はその実を結ぶ。</span>
<span className="v" id="v5" data-v="5" data-xref="アモス書 9:13; ヨエル書 2:26; ヨエル書 2:19"> あなたがたの脱穀はぶどうの収穫まで続き、ぶどうの収穫は種まきの時期まで続く。あなたがたはパンを十分に食べ、あなたがたの地で安全に住むことができる。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 35:9; ゼパニヤ書 3:13; 詩篇 147:14"> 『わたしはその地に平和を与える。あなたがたは安らかに伏し、だれにも脅かされない。わたしは凶暴な獣をその地から取り除き、剣があなたがたの地を通ることもない。</span>
<span className="v" id="v7" data-v="7"> あなたがたは敵を追い散らし、彼らはあなたがたの前で剣によって倒れる。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 23:10; 申命記 28:7; 申命記 32:30"> あなたがたの五人が百人を追い散らし、百人が一万人を追い散らす。あなたがたの敵はあなたがたの前で剣によって倒れる。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 17:6–7; ネヘミヤ記 9:23; エゼキエル書 16:62"> 『わたしはあなたがたに目を留め、あなたがたを実り豊かにし、あなたがたを増し加え、あなたがたとのわたしの契約を確立する。</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 25:22; 列王記第二 19:29; ルカ 12:17"> あなたがたは長く保存された古い蓄えを食べ、新しいもののために古い蓄えを運び出すことになる。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 25:8; ヨハネの黙示録 21:3; 出エジプト記 29:45"> わたしはあなたがたの間に幕屋を置き、あなたがたを忌み嫌わない。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第二の手紙 6:16; エレミヤ書 30:22; エレミヤ書 7:23"> わたしはあなたがたの間を歩み、あなたがたの神となり、あなたがたはわたしの民となる。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 34:27; レビ記 25:38; 詩篇 116:16"> わたしはあなたがたの神、主である。あなたがたがエジプト人の奴隷でなくなるよう、エジプトの地から導き出した。わたしはあなたがたのくびきの横木を砕き、胸を張って歩かせた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命記 28:15–68; レビ記 26:18; エレミヤ書 17:27"> 『しかし、もしあなたがたがわたしに聞き従わず、これらすべての命令を行わないなら、</span>
<span className="v" id="v15" data-v="15" data-xref="列王記第二 17:15; 申命記 31:16; ゼカリヤ書 7:11–13"> わたしの掟を退け、わたしの法を忌み嫌い、わたしのすべての命令を行わず、わたしの契約を破るなら、</span>
<span className="v" id="v16" data-v="16" data-xref="ヨブ記 31:8; エレミヤ書 5:17; ミカ書 6:15"> わたしもあなたがたにこうする。恐怖を臨ませ、目を衰えさせ、命をすり減らす消耗病と熱病を送る。あなたがたが種を蒔いてもむなしい。敵がそれを食べるからである。</span>
<span className="v" id="v17" data-v="17" data-xref="レビ記 17:10; 箴言 28:1; 詩篇 53:5"> わたしはあなたがたに顔を向け、あなたがたは敵の前に打たれる。あなたがたを憎む者があなたがたを支配し、あなたがたはだれも追っていないのに逃げることになる。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="レビ記 26:21; レビ記 26:28; レビ記 26:24"> 『もしこれらのことがあってもなお、わたしに聞き従わないなら、わたしはあなたがたの罪のために、さらに七倍の懲らしめを与える。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 28:23; 列王記第一 17:1; ダニエル書 4:37"> わたしはあなたがたの力の高ぶりを砕き、あなたがたの空を鉄のようにし、あなたがたの土を青銅のようにする。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 127:1; 申命記 11:17; イザヤ書 49:4"> あなたがたの力はむなしく費やされる。あなたがたの地はその産物をもたらさず、地の木々もその実を結ばないからである。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="レビ記 26:18; レビ記 26:27"> 『それでもわたしに背いて歩み、聞き従わないなら、あなたがたの罪に応じて、さらに七倍の災いを加える。</span>
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 14:15; 申命記 32:24; 士師記 5:6"> わたしはあなたがたの間に野の獣を送り込む。それらはあなたがたの子どもを奪い、あなたがたの家畜を滅ぼし、あなたがたの数を減らす。あなたがたの道は荒れ果てる。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 5:3; エレミヤ書 2:30; アモス書 4:6–12"> 『これらによってもわたしに立ち返らず、なおわたしに背いて歩むなら、</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 18:26; サムエル記第二 22:27; ヨブ記 9:4"> わたしもあなたがたに敵対して歩み、あなたがたの罪のため、わたし自身が七倍も打つ。</span>
<span className="v" id="v25" data-v="25" data-xref="民数記 14:12; エゼキエル書 5:17; エレミヤ書 29:17–18"> わたしは契約の復讐を遂行する剣をあなたがたにもたらす。あなたがたが自分たちの町々に集まるとき、わたしはあなたがたの間に疫病を送り込む。あなたがたは敵の手に引き渡される。</span>
<span className="v" id="v26" data-v="26" data-xref="ミカ書 6:14; イザヤ書 3:1; 詩篇 105:16"> わたしがあなたがたのパンの杖を砕くとき、十人の女が一つのかまどであなたがたのパンを焼き、量ってあなたがたのパンを返す。あなたがたは食べても、満足することはない。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="レビ記 26:24; レビ記 26:21"> 『これでもわたしに聞き従わず、なおわたしに背いて歩むなら、</span>
<span className="v" id="v28" data-v="28" data-xref="イザヤ書 59:18; エレミヤ書 21:5; イザヤ書 66:15"> わたしも憤りをもってあなたがたに敵対し、罪のために七倍の懲らしめを加える。</span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 5:10; 哀歌 4:10; マタイ 24:19"> あなたがたは自分たちの息子の肉を食べ、自分たちの娘の肉を食べることになる。</span>
<span className="v" id="v30" data-v="30" data-xref="列王記第二 23:20; イザヤ書 27:9; エゼキエル書 6:13"> わたしはあなたがたの高き所を滅ぼし、香の祭壇を切り倒し、死体を偶像の死体の上に投げ捨てる。わたしはあなたがたを忌み嫌う。</span>
<span className="v" id="v31" data-v="31" data-xref="ネヘミヤ記 2:3; 哀歌 1:10; ヘブル人への手紙 10:26"> わたしはあなたがたの町々を荒廃させ、あなたがたの聖所を荒れ果てさせる。わたしはあなたがたのささげ物の芳ばしい香りを楽しむことはない。</span>
<span className="v" id="v32" data-v="32" data-xref="エレミヤ書 9:11; エレミヤ書 19:8; エレミヤ書 18:16"> わたしはその地を荒れ果てさせる。そこに住む敵さえ、その有様に呆然とする。</span>
<span className="v" id="v33" data-v="33" data-xref="ゼカリヤ書 7:14; エゼキエル書 20:23; 申命記 28:64–66"> わたしはあなたがたを国々の間に散らし、あなたがたのうしろから剣を抜く。あなたがたの地は荒れ果て、あなたがたの町々は荒廃する。</span>
<span className="v" id="v34" data-v="34" data-xref="歴代誌 第二 36:21; レビ記 26:43; レビ記 25:2–4"> そのとき、その地が荒れ果て、あなたがたが敵の地にいる間、その地は安息日を楽しむ。そのとき初めて地は休み、その安息日を楽しむ。</span>
<span className="v" id="v35" data-v="35" data-xref="イザヤ書 24:5–6; ローマ人への手紙 8:22"> その地は、荒れ果てている間ずっと休みを得る。あなたがたがそこに住んでいたときの安息日には得られなかった休みを得るのである。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="エゼキエル書 21:7; イザヤ書 30:17; レビ記 26:17"> 『あなたがたのうち残された者たちについては、わたしは彼らの敵の地で彼らの心におびえを送り込む。風に追われる葉の音さえも彼らを逃げ走らせる。彼らは剣から逃げるように逃げる。だれも追っていないのに彼らは倒れる。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨシュア記 7:12–13; 士師記 2:14; エレミヤ書 37:10"> だれも追っていないのに、彼らは剣の前を逃げるようにお互いにつまずく。あなたがたには敵の前に立つ力はない。</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 28:48; イザヤ書 27:13; エレミヤ書 42:17–18"> あなたがたは国々の間で滅びる。あなたがたの敵の地があなたがたを食い尽くす。</span>
<span className="v" id="v39" data-v="39" data-xref="エゼキエル書 4:17; エゼキエル書 24:23; エゼキエル書 33:10"> あなたがたのうち残された者たちは、敵の地で自分たちの咎のゆえにやつれ果てる。彼らはまた、自分たちの父祖の咎のゆえにもやつれ果てる。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="箴言 28:13; ネヘミヤ記 9:2–5; ヨハネの手紙第一 1:8–10"> 『もし彼らが、自分たちの咎と父祖の咎を告白し、わたしに背いて不実を行い、わたしに逆らって歩んだこと、</span>
<span className="v" id="v41" data-v="41" data-xref="エゼキエル書 44:7; 歴代誌 第二 32:26; 歴代誌 第二 12:6–7"> そのためにわたしも彼らに敵対し、敵の地へ追いやったことを認め、その無割礼の心がへりくだって、自分たちの咎の罰を受け入れるなら、</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 106:45; 出エジプト記 6:5; エゼキエル書 16:60"> わたしはヤコブとのわたしの契約を思い起こし、イサクとのわたしの契約、そしてアブラハムとのわたしの契約を思い起こす。そしてわたしはその地を思い起こす。</span>
<span className="v" id="v43" data-v="43" data-xref="ローマ人への手紙 8:7; レビ記 26:15; ヨハネ 7:7"> その地は彼らに捨てられ、彼らがいない間、荒れ果てて安息日を楽しむ。彼らは、わたしの法を退け、わたしの掟を忌み嫌ったため、自分たちの咎の罰を受ける。</span>
<span className="v" id="v44" data-v="44" data-xref="ローマ人への手紙 11:2; ネヘミヤ記 9:31; 申命記 4:29–31"> それにもかかわらず、彼らが敵の地にいるとき、わたしは彼らを拒まず、彼らを完全に滅ぼして彼らとのわたしの契約を破るほど彼らを忌み嫌うこともない。わたしは彼らの神、主だからである。</span>
<span className="v" id="v45" data-v="45" data-xref="レビ記 25:38; エゼキエル書 20:22; エゼキエル書 20:9"> わたしは彼らの神となるために、国々の目の前でエジプトの地から導き出した彼らの父祖たちとの契約を、彼らのために思い起こす。わたしは主である。』」</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="レビ記 27:34; 申命記 12:1; 申命記 6:1"> これらは、シナイ山でモーセを通して、主とイスラエルの子らとの間に主が設けられた掟、法、そして律法である。</span>
</div>

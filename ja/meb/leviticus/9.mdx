<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 28:1; エゼキエル書 43:26–27; レビ記 15:14"> 八日目に、モーセはアロンとその子ら、そしてイスラエルの長老たちを呼び寄せた。</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 4:3; ヘブル人への手紙 10:10–14; レビ記 8:14"> そしてアロンに言った。「贖罪のささげ物として牛の群れから子牛を、全焼のささげ物として雄羊を、傷のないものとして取り、主の前にささげなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="エズラ記 6:17; ヨハネの黙示録 5:9; テトス 2:14"> またイスラエルの子らに告げなさい。『贖罪のささげ物として雄山羊を一頭、全焼のささげ物として、いずれも一歳の傷のない子牛と子羊を取りなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 29:43; エゼキエル書 43:2; レビ記 9:23"> また和解のいけにえとして、主の前でいけにえをささげるために雄牛と雄羊を、そして油を混ぜた穀物のささげ物を取りなさい。今日、主があなたがたに現れるからである。』」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歴代誌 第二 5:2–3; 出エジプト記 19:17; ネヘミヤ記 8:1"> 彼らはモーセが命じたものを会見の天幕の前に持って来た。全会衆が近づき、主の前に立った。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 9:23; エゼキエル書 43:2; 出エジプト記 24:16"> モーセは言った。「これは、あなたがたが行うように主が命じられたことである。そうすれば、主の栄光があなたがたに現れる。」</span>
<span className="v" id="v7" data-v="7" data-xref="ヘブル人への手紙 5:3; ヘブル人への手紙 5:1; レビ記 4:3"> モーセはアロンに言った。「祭壇に近づき、あなたの贖罪のささげ物と全焼のささげ物をささげて、あなた自身と民のために贖いを行いなさい。そして、主が命じられた通りに、民のささげ物をささげて、彼らのために贖いを行いなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="レビ記 4:1–12; レビ記 1:4–5; レビ記 4:29"> そこでアロンは祭壇に近づき、自分のための贖罪のささげ物である子牛を屠った。</span>
<span className="v" id="v9" data-v="9" data-xref="レビ記 4:6–7; レビ記 8:15; レビ記 4:25"> アロンの子らは彼に血を差し出した。彼は指を血に浸し、それを祭壇の角に塗り、残りの血を祭壇の土台に注ぎ出した。</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 8:16–17; 箴言 23:26; レビ記 3:9–11"> しかし、贖罪のささげ物の脂肪と、腎臓と、肝臓の覆いは、主がモーセに命じられた通りに祭壇の上で燃やした。</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 8:17; レビ記 4:11–12; レビ記 16:27–28"> 肉と皮は宿営の外で火で焼いた。</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 5:2; エペソ人への手紙 5:25–27; レビ記 1:1–17"> 彼は全焼のささげ物を屠った。アロンの子らは彼に血を渡し、彼はそれを祭壇の周囲に振りかけた。</span>
<span className="v" id="v13" data-v="13"> 彼らは全焼のささげ物を、切り分けた部分ごとに、また頭を彼に渡した。彼はそれらを祭壇の上で燃やした。</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 8:21"> 彼は内臓と足を洗い、祭壇の上の全焼のささげ物の上でそれらを燃やした。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 4:27–31; ヘブル人への手紙 5:3; レビ記 9:3"> 彼は民のささげ物をささげた。民のための贖罪のささげ物の山羊を取り、それを屠り、最初のものと同じように罪のためにそれをささげた。</span>
<span className="v" id="v16" data-v="16" data-xref="レビ記 9:12–14; レビ記 8:18–21; ヘブル人への手紙 10:1–22"> 彼は全焼のささげ物をささげ、定めに従ってそれをささげた。</span>
<span className="v" id="v17" data-v="17" data-xref="レビ記 2:1–2; ヨハネ 6:53; レビ記 9:1"> 彼は穀物のささげ物をささげ、そこから手いっぱいに取り、朝の全焼のささげ物に加えて祭壇の上でそれを燃やした。</span>
<span className="v" id="v18" data-v="18" data-xref="コロサイ人への手紙 1:20; ローマ人への手紙 5:1; エペソ人への手紙 2:14–17"> 彼はまた、民のための和解のいけにえである雄牛と雄羊を屠った。アロンの子らは彼に血を渡し、彼はそれを祭壇の周囲に振りかけた。</span>
<span className="v" id="v19" data-v="19" data-xref="レビ記 3:16; レビ記 9:10; レビ記 3:9"> 雄牛と雄羊の脂肪、すなわち脂尾、内臓を覆うもの、腎臓、そして肝臓の覆い、</span>
<span className="v" id="v20" data-v="20" data-xref="レビ記 3:14–17; レビ記 7:29–34"> 彼らはその脂肪を胸の上に置き、彼はその脂肪を祭壇の上で燃やした。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 7:30–34; レビ記 7:24; 出エジプト記 29:24"> モーセが命じた通り、アロンは胸と右のももを主の前で揺り動かすささげ物として揺り動かした。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 21:5; ルカ 24:50; 民数記 6:23–27"> アロンは民に向かって両手を上げて彼らを祝福した。そして贖罪のささげ物、全焼のささげ物、和解のいけにえをささげ終えて降りて来た。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="レビ記 9:6; 民数記 16:19; ルカ 1:21–22"> モーセとアロンは会見の天幕に入り、そして出て来て民を祝福した。すると主の栄光がすべての民に現れた。</span>
<span className="v" id="v24" data-v="24" data-xref="士師記 6:21; 列王記第一 18:38–39; 歴代誌上 21:26"> 主の前から火が出て、祭壇の上の全焼のささげ物と脂肪を焼き尽くした。すべての民はこれを見て叫び声を上げ、ひれ伏した。</span>
</div>

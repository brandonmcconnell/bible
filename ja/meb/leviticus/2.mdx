<span className="v" id="v1" data-v="1" data-xref="レビ記 6:14–18; レビ記 9:17; イザヤ書 66:20"> 『だれかが主に穀物のささげ物をささげるときは、そのささげ物は上質の小麦粉である。その上に油を注ぎ、乳香を添える。</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 5:12; レビ記 6:15; 使徒の働き 10:4"> 彼はそれを祭司であるアロンの子らのところに持って行く。祭司はそこから上質の小麦粉と油をひとつかみ取り、すべての乳香とともに、記念の部分として祭壇の上で燃やす。これは火によるささげ物であり、主への芳ばしい香りである。</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 10:12–13; 民数記 18:9; レビ記 21:22"> 穀物のささげ物の残りは、アロンとその子らのものとなる。これは主への火によるささげ物の中で最も聖なる部分である。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 29:2; コリント人への第一の手紙 5:7–8; 詩篇 22:14"> 『かまどで焼いた穀物のささげ物をする場合は、油を混ぜた上質の小麦粉で作る種なしの輪形パン、または油を塗った種なしの薄焼きパンとする。</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 6:21; レビ記 7:9"> 平鍋で作る穀物のささげ物の場合は、油を混ぜた上質の小麦粉で作り、パン種を入れてはならない。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 18:1–19; 詩篇 22:1–21; マルコ 14:1–15"> あなたはそれを切り分け、その上に油を注ぐ。これは穀物のささげ物である。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 2:1–2; レビ記 7:9"> もしあなたのささげ物が鍋で作られた穀物のささげ物であるなら、それは上質の小麦粉と油で作られる。</span>
<span className="v" id="v8" data-v="8"> これらのものから作られた穀物のささげ物を主のもとに持って行く。それは祭司に差し出され、祭司はそれを祭壇に持って行く。</span>
<span className="v" id="v9" data-v="9" data-xref="レビ記 2:2; ピリピ人への手紙 4:18; レビ記 6:15"> 祭司はその穀物のささげ物から記念の部分を取り、祭壇の上で燃やす。これは火によるささげ物であり、主への芳ばしい香りである。</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 2:3"> 穀物のささげ物の残りは、アロンとその子らのものとなる。これは主への火によるささげ物の中で最も聖なる部分である。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ガラテヤ人への手紙 5:9; ルカ 12:1; 出エジプト記 23:18"> 『主にささげる穀物のささげ物には、パン種を入れてはならない。パン種も蜜も、主への火によるささげ物として燃やしてはならない。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 23:19; 創世記 23:10–11; 出エジプト記 22:29"> 初穂のささげ物としては、それらを主にささげてもよいが、祭壇の上に芳ばしい香りとして上らせてはならない。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 43:24; マタイ 5:13; コロサイ人への手紙 4:6"> あなたの穀物のささげ物にはすべて、塩で味付けをする。あなたの穀物のささげ物に、あなたの神<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「神」と訳されたヘブル語は「אֱלֹהִים」（エロヒム）である。">a</a></sup>の契約の塩を欠かしてはならない。あなたのすべてのささげ物とともに、塩をささげる。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="レビ記 23:10; マラキ書 1:11; 民数記 28:2"> 『もしあなたが初穂の穀物のささげ物を主にささげるなら、あなたの初穂の穀物のささげ物として、火で炒った新穀の穂を砕いたものをささげる。</span>
<span className="v" id="v15" data-v="15"> その上に油をかけ、乳香を添える。これは穀物のささげ物である。</span>
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 5:7; ローマ人への手紙 8:26–27; イザヤ書 61:1"> 祭司は記念の部分として、砕いた穀物の一部と油の一部を、すべての乳香とともに燃やす。これは主への火によるささげ物である。』」</span>
</div>

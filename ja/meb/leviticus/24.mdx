<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第二の手紙 4:6; エペソ人への手紙 5:8–14; 出エジプト記 27:20–21"> 「イスラエルの子らに命じて、ともしびのために打って搾った純粋なオリーブ油をあなたのもとに持って来させ、ともしびが絶えずともるようにしなさい。</span>
<span className="v" id="v3" data-v="3"> 会見の天幕の中、あかしの垂れ幕の外側で、アロンは夕暮れから朝まで、主の前で絶えずそれを整える。これは代々にわたっての永遠の掟である。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 31:8; 出エジプト記 37:17–24; 出エジプト記 39:37"> 彼は主の前で、純金の燭台の上のともしびを絶えず整える。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 25:30; 列王記第一 18:31; 出エジプト記 40:23"> 「上質の小麦粉を取り、それで十二のパンを焼きなさい。一つのパンには十分の二エパ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一エパは約22リットル、または約3分の2ブッシェルである。">a</a></sup>を用いる。</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第一 7:48; 出エジプト記 25:23–24; 歴代誌 第二 4:19"> それらを主の前の純金の机の上に、一列に六つずつ、二列に並べなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 2:2; ヨハネの黙示録 8:3–4; 創世記 9:16"> 各列の上に純粋な乳香を置きなさい。それがパンのための記念の部分となり、主への火によるささげ物となるためである。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代誌 第二 2:4; 民数記 4:7; 歴代誌上 9:32"> 彼は安息日ごとに、絶えずそれを主の前に整える。これはイスラエルの子らのための永遠の契約である。</span>
<span className="v" id="v9" data-v="9" data-xref="レビ記 8:31; ルカ 6:4; マルコ 2:26"> それはアロンとその子らのものとなる。彼らは聖なる場所でそれを食べる。永遠の掟により、主への火によるささげ物の中から彼らに与えられる、最も聖なるものだからである。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民数記 11:4; 出エジプト記 12:38"> 父がエジプト人であるイスラエル人の女の息子が宿営に出て来た。そのイスラエル人の女の息子と、イスラエル人の男が宿営の中で争った。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 20:7; レビ記 24:15–16; 出エジプト記 3:15"> このイスラエル人の女の息子は御名を冒涜して呪った。そこで人々は彼をモーセのところに連れて来た。彼の母親の名はスロミテといい、ダン部族のディブリの娘であった。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 18:15–16; 民数記 15:34; 民数記 27:5"> 主の命令が明らかにされるまで、人々はその者を留置した。</span>
<span className="v" id="v13" data-v="13"> 主はモーセに告げられた。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 17:7; レビ記 20:27; 申命記 21:21"> 「呪った者を宿営の外に引き出しなさい。それを聞いた者はみな彼の頭に手を置き、全会衆で彼を石で打ち殺しなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 9:13; 出エジプト記 22:28; レビ記 5:1"> イスラエルの子らに告げなさい。『自分の神を呪う者はだれでも、その罪を負う。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイ 12:31; ヤコブの手紙 2:7; ヨハネ 10:33–36"> 主の御名を冒涜する者は、必ず死刑に処される。全会衆は必ず彼を石で打ち殺す。寄留者であれ、その地に生まれた者であれ、御名を冒涜したときは死刑に処される。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 9:5–6; 申命記 19:11–12; 申命記 27:24"> 『人を打ち殺した者は、必ず死刑に処される。</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 24:21; 出エジプト記 21:34–36"> 動物を打ち殺した者は、同じ価値の動物をもって償う。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイ 5:38; マタイ 7:2; 申命記 19:21"> 隣人に傷を負わせたなら、彼がしたのと同じように彼にもされる。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 19:21; マタイ 5:38; 出エジプト記 21:23–25"> 骨折には骨折を、目には目を、歯には歯を。彼が人に傷を負わせたように、彼にもそのようにされる。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 24:17–18; 出エジプト記 21:33"> 動物を殺した者は償いをしなければならず、人を殺した者は死刑に処される。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 12:49; 民数記 15:15–16; 民数記 9:14"> 寄留者にもその地に生まれた者にも、あなたがたは一つの同じ法を持つ。わたしはあなたがたの神、主だからである。』」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ヘブル人への手紙 10:28–29; ヘブル人への手紙 2:2–3; 民数記 15:35–36"> モーセがイスラエルの子らに語ると、彼らは呪った者を宿営の外に引き出し、石で打ち殺した。イスラエルの子らは主がモーセに命じられたとおりに行った。</span>
</div>

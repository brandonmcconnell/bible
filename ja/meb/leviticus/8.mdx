<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 28:2–4; 出エジプト記 39:41; ヘブル人への手紙 7:27"> 「アロンと、その子ら、衣服、注ぎ油、贖罪のささげ物となる牛、二頭の雄羊、種なしパンの籠を取りなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代誌 第二 30:13; 使徒の働き 2:1; ネヘミヤ記 8:1"> そして全会衆を会見の天幕の入り口に集めなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 39:26; 出エジプト記 39:7; 出エジプト記 39:5"> モーセは主が彼に命じられた通りに行った。そして会衆は会見の天幕の入り口に集められた。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 29:4–37"> モーセは会衆に言った。「これが、行うように主が命じられたことである。」</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第一の手紙 6:11; エペソ人への手紙 5:26; 出エジプト記 29:4"> モーセはアロンとその子らを連れて来て、水で彼らを洗った。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 28:4; イザヤ書 61:10; ガラテヤ人への手紙 3:27"> モーセはアロンに長服を着せ、飾り帯を締め、上着をまとわせ、エポデを着け、その巧みに織られた帯を締めて、エポデを体に結びつけた。</span>
<span className="v" id="v8" data-v="8" data-xref="エズラ記 2:63; テサロニケ人への手紙第一 5:8; イザヤ書 59:17"> 彼はその上に胸当てを置き、その胸当ての中にウリムとトンミムを入れた。</span>
<span className="v" id="v9" data-v="9" data-xref="ピリピ人への手紙 2:9–11; ゼカリヤ書 6:11–14; 出エジプト記 28:36–38"> 彼はその頭にターバンをかぶらせた。主がモーセに命じられた通りに、ターバンの前面に金の札、すなわち聖なる冠を付けた。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 40:9–11; レビ記 8:2; 出エジプト記 30:23–29"> モーセは注ぎ油を取り、幕屋とその中にあるすべてのものに油を注いで、それらを聖別した。</span>
<span className="v" id="v11" data-v="11" data-xref="テトス 3:6; 出エジプト記 30:29; 出エジプト記 16:19"> 彼はそれを祭壇に七度振りかけ、祭壇とそのすべての器具、また洗盤とその台に油を注いで、それらを聖別した。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 30:30; 詩篇 133:2; 出エジプト記 29:7"> 彼は注ぎ油の一部をアロンの頭に注ぎ、彼に油を注いで、彼を聖別した。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 29:8–9; ヨハネの黙示録 5:10; ヨハネの黙示録 1:6"> モーセは主がモーセに命じられた通りに、アロンの子らを連れて来て、長服を着せ、飾り帯を締め、頭帯をかぶらせた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 43:19; 詩篇 66:15; ペテロの手紙第一 3:18"> 彼は贖罪のささげ物の牛を連れて来た。アロンとその子らは、贖罪のささげ物の牛の頭に手を置いた。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 4:7; ヘブル人への手紙 9:18–23; エゼキエル書 43:19–27"> 彼はそれを屠った。モーセはその血を取り、指で祭壇の角の周囲にそれを塗って祭壇を清め、その血を祭壇の土台に注ぎ出して、それを聖別し、そのために贖いを行った。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 29:13; レビ記 3:3–5; レビ記 4:8–9"> 彼は内臓についているすべての脂肪と、肝臓の覆い、二つの腎臓とその脂肪を取り、モーセはそれを祭壇の上で燃やした。</span>
<span className="v" id="v17" data-v="17" data-xref="レビ記 4:11–12; 出エジプト記 29:14; レビ記 6:30"> しかし、その牛、すなわちその皮、肉、そして糞は、主がモーセに命じられた通りに、宿営の外で火で焼いた。</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 8:2; レビ記 1:4–13; 出エジプト記 29:15–18"> 彼は全焼のささげ物の雄羊をささげた。アロンとその子らはその雄羊の頭に手を置いた。</span>
<span className="v" id="v19" data-v="19"> 彼はそれを屠り、モーセはその血を祭壇の周囲に振りかけた。</span>
<span className="v" id="v20" data-v="20" data-xref="レビ記 1:8"> 彼は雄羊を切り分け、モーセは頭と切り分けた肉と脂肪を燃やした。</span>
<span className="v" id="v21" data-v="21" data-xref="エペソ人への手紙 5:2; 出エジプト記 29:18; レビ記 1:17"> 彼は内臓と足を水で洗った。そしてモーセは雄羊全体を祭壇の上で燃やした。これは芳ばしい香りのための全焼のささげ物であり、主への火によるささげ物であった。主がモーセに命じられた通りである。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 8:2; レビ記 8:29; 出エジプト記 29:19–31"> 彼はもう一頭の雄羊、すなわち任職の雄羊をささげた。アロンとその子らはその雄羊の頭に手を置いた。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 29:20; レビ記 14:14; ローマ人への手紙 12:1"> 彼はそれを屠り、モーセはその血の一部を取って、アロンの右の耳たぶと、右手の親指と、右足の親指に塗った。</span>
<span className="v" id="v24" data-v="24" data-xref="ヘブル人への手紙 9:18–22"> 彼はアロンの子らを連れて来た。モーセはその血の一部を彼らの右の耳たぶと、右手の親指と、右足の親指に塗った。そしてモーセはその血を祭壇の周囲に振りかけた。</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 3:9; レビ記 3:3–5; イザヤ書 53:10"> 彼は脂肪、脂尾、内臓についているすべての脂肪、肝臓の覆い、二つの腎臓とその脂肪、および右のももを取った。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 29:23; テモテへの手紙第一 2:5; 使徒の働き 5:12"> また、主の前にある種なしパンの籠から、種なしの菓子を一つ、油を塗ったパンの菓子を一つ、薄焼きパンを一つ取り出し、それらを脂肪と右のももの上に置いた。</span>
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 30:21; ヘブル人への手紙 9:14; 出エジプト記 29:24–37"> 彼はこれらすべてをアロンの手に、そしてその子らの手に渡し、主の前で揺り動かすささげ物として揺り動かした。</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 29:25; 詩篇 22:13–14; ヘブル人への手紙 10:14–22"> モーセは彼らの手からそれらを受け取り、祭壇の上の全焼のささげ物の上で燃やした。これらは芳ばしい香りのための任職のささげ物であった。それは主への火によるささげ物であった。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第一の手紙 10:31; ペテロの手紙第一 4:11; レビ記 7:30–34"> モーセは胸を取り、主の前で揺り動かすささげ物として揺り動かした。主がモーセに命じられた通り、それは任職の雄羊からのモーセの分であった。</span>
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 29:21; 民数記 3:3; 出エジプト記 30:30"> モーセは注ぎ油の一部と、祭壇の上にある血の一部を取り、アロンとその衣服、またその子らとその衣服に振りかけ、アロンとその衣服、その子らとその衣服を聖別した。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 29:31–32; ガラテヤ人への手紙 2:20; サムエル記第一 2:13–17"> モーセはアロンとその子らに言った。「会見の天幕の入り口で肉を煮、そこでその肉と任職の籠にあるパンを食べなさい。『アロンとその子らがそれを食べる』と私が命じたとおりである。</span>
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 29:34; 出エジプト記 12:10; ヘブル人への手紙 3:13–14"> 肉とパンの残りは火で焼く。</span>
<span className="v" id="v33" data-v="33" data-xref="出エジプト記 29:35; 民数記 19:12; エゼキエル書 43:25–27"> あなたがたの任職の日々が満ちるまで、七日間、会見の天幕の入り口から出てはならない。あなたがたの任職は七日間かけて行われるからである。</span>
<span className="v" id="v34" data-v="34" data-xref="ヘブル人への手紙 7:27; ヘブル人への手紙 7:16; ヘブル人への手紙 10:11–12"> 今日行われたことは、あなたがたのために贖いを行うよう主が命じられたことである。</span>
<span className="v" id="v35" data-v="35" data-xref="民数記 3:7; 申命記 11:1; 列王記第一 2:3"> あなたがたは七日間、昼も夜も会見の天幕の入り口にとどまり、死なないように主の命令を守りなさい。私はそのように命じられている。」</span>
<span className="v" id="v36" data-v="36" data-xref="申命記 12:32; 申命記 4:2; 出エジプト記 40:16"> アロンとその子らは、主がモーセを通して命じられたすべてのことを行った。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="民数記 6:14; レビ記 1:3; ローマ人への手紙 5:1–2"> 『もし彼のささげ物が和解のいけにえであり、牛の群れからささげるなら、雄でも雌でも、傷のないものを主の前にささげる。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 29:10; レビ記 1:4–5; 使徒の働き 2:36–38"> 彼はそのささげ物の頭に手を置き、会見の天幕の入り口でそれを屠る。祭司であるアロンの子らは、その血を祭壇の周囲に振りかける。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 29:13; レビ記 4:8–9; 出エジプト記 29:22"> 彼はその和解のいけにえから、主への火によるささげ物をささげる。すなわち、内臓を覆う脂肪と、内臓についているすべての脂肪、</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 3:10; レビ記 8:25; 出エジプト記 29:22"> 二つの腎臓と、腰のあたりにあるそれらの上の脂肪、および腎臓と一緒に取り外す肝臓の覆いである。</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 6:12; 出エジプト記 29:13; ペテロの手紙第一 2:5"> アロンの子らは、祭壇の上の全焼のささげ物の上で、すなわち火にある薪の上で、それを燃やす。これは火によるささげ物であり、主への芳ばしい香りである。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="テトス 2:11–12; ガラテヤ人への手紙 3:28; レビ記 1:2"> 『もし彼の主への和解のいけにえのささげ物が羊の群れからであるなら、雄でも雌でも、傷のないものをささげる。</span>
<span className="v" id="v7" data-v="7" data-xref="列王記第一 8:62; エペソ人への手紙 5:12; レビ記 17:8–9"> もし彼がささげ物として子羊をささげるなら、主の前にそれをささげる。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 1:5; エペソ人への手紙 3:12; レビ記 3:13"> 彼はそのささげ物の頭に手を置き、会見の天幕の前でそれを屠る。アロンの子らはその血を祭壇の周囲に振りかける。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 29:22; レビ記 9:19; レビ記 8:25"> 彼はその和解のいけにえから、主への火によるささげ物をささげる。その脂肪、すなわち背骨の近くで取り外す脂尾全体と、内臓を覆う脂肪、および内臓についているすべての脂肪、</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 3:4"> 二つの腎臓と、腰のあたりにあるそれらの上の脂肪、および腎臓と一緒に取り外す肝臓の覆いである。</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 21:17; レビ記 21:6; レビ記 3:16"> 祭司はそれを祭壇の上で燃やす。これは主への火によるささげ物の食物である。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="レビ記 9:15; イザヤ書 53:2; コリント人への第二の手紙 5:21"> 『もし彼のささげ物が山羊であるなら、主の前にそれをささげる。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 3:8; ローマ人への手紙 5:15–21; コリント人への第二の手紙 5:21"> 彼はその頭に手を置き、会見の天幕の前でそれを屠る。アロンの子らはその血を祭壇の周囲に振りかける。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイ 26:38; マタイ 22:37; レビ記 3:9–11"> 彼はそこから自分のささげ物として、主への火によるささげ物をささげる。すなわち、内臓を覆う脂肪と、内臓についているすべての脂肪、</span>
<span className="v" id="v15" data-v="15"> 二つの腎臓と、腰のあたりにあるそれらの上の脂肪、および腎臓と一緒に取り外す肝臓の覆いである。</span>
<span className="v" id="v16" data-v="16" data-xref="レビ記 7:23–25; マタイ 22:37; イザヤ書 53:10"> 祭司はそれらを祭壇の上で燃やす。これは芳ばしい香りのための、火によるささげ物の食物である。脂肪はすべて主のものである。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 9:4; マタイ 26:28; 申命記 15:23"> 『あなたがたは脂肪も血も一切食べてはならない。これは、あなたがたのすべての住まいで、代々にわたっての永遠の掟である。』」</span>

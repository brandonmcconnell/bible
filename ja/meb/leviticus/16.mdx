<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="レビ記 10:1–2"> アロンの二人の子が主の前に近づいて死んだ後、主はモーセに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 30:10; 列王記第一 8:10–12; ヘブル人への手紙 10:19–20"> 主はモーセに言われた。「あなたの兄弟アロンに告げなさい。箱の上にある贖いの座の前、すなわち垂れ幕の内側の至聖所に、いつでも入って来てはならない。彼が死なないためである。わたしは贖いの座の上の雲の中に現れるからである。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="レビ記 4:3; ヘブル人への手紙 9:24–25; ヘブル人への手紙 9:7"> 「アロンは、贖罪のささげ物として若い牛を、全焼のささげ物として雄羊を携えて、聖所に入る。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 28:39–43; エゼキエル書 44:17–18; 出エジプト記 30:20"> 彼は聖なる亜麻布の長服を着る。亜麻布のももひきを身に着け、亜麻布の飾り帯を締め、亜麻布のターバンをかぶる。これらは聖なる衣である。彼は水で体を洗い、それらを着る。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代誌 第二 29:21; レビ記 8:2; エズラ記 6:17"> 彼はイスラエルの子らの会衆から、贖罪のささげ物として二頭の雄山羊を、全焼のささげ物として一頭の雄羊を取る。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="レビ記 9:7; ヘブル人への手紙 9:7; ヘブル人への手紙 7:27"> 「アロンは自分のための贖罪のささげ物の牛をささげ、自分と自分の家のために贖いを行う。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 12:1; レビ記 4:4; マタイ 16:21"> 彼は二頭の山羊を取り、会見の天幕の入り口で主の前に立たせる。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 1:23–26; ヨナ書 1:7; 箴言 16:33"> アロンは二頭の山羊のためにくじを引く。一つのくじは主のため、もう一つは荒野に放つ山羊のためである。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 4:27–28; 使徒の働き 2:23"> アロンは主のためのくじが当たった山羊をささげ、それを贖罪のささげ物としてささげる。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの手紙第一 2:2; レビ記 16:21–22; ヘブル人への手紙 9:23–24"> 荒野に放つ山羊のくじが当たった山羊は、主の前に生かしたまま立たせ、それによって贖いを行い、荒野へ送り出す。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="レビ記 16:6; ヘブル人への手紙 7:27; ヘブル人への手紙 9:7"> 「アロンは自分のための贖罪のささげ物の牛をささげ、自分と自分の家のために贖いを行い、自分のための贖罪のささげ物の牛を屠る。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 10:1; 出エジプト記 30:34–38; ヨハネの黙示録 8:3–4"> 彼は主の前にある祭壇から、火のついた炭を満たした香炉と、細かく砕いた香りのよい香を両手いっぱいに取り、垂れ幕の内側に持って入る。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 25:21; 出エジプト記 30:1; 出エジプト記 30:7–8"> 彼は主の前でその香を火の上に置く。それは、香の雲があかしの上にある贖いの座を覆い、彼が死なないためである。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 9:25; レビ記 4:5–6; ヘブル人への手紙 9:13"> 彼は牛の血の一部を取り、指で贖いの座の東側に振りかける。また贖いの座の前で、その血の一部を指で七度振りかける。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 9:7; ヘブル人への手紙 2:17; ヘブル人への手紙 9:3"> 「その後、彼は民のための贖罪のささげ物の山羊を屠り、その血を垂れ幕の内側に持って入り、牛の血にしたようにその血を扱い、贖いの座の上と贖いの座の前にそれを振りかける。</span>
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 9:22–23; レビ記 16:18; エゼキエル書 45:18–19"> 彼はイスラエルの子らの汚れと、その背き、すなわち彼らのすべての罪のために、聖所のために贖いを行う。また、彼らの汚れのただ中で彼らと共に住む会見の天幕のためにも、同じように行う。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 53:6; ルカ 1:10; 出エジプト記 34:3"> 彼が聖所で贖いを行うために入り、彼自身と彼の家、そしてイスラエルの全会衆のために贖いを行って出て来るまで、会見の天幕にはだれもいてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="レビ記 4:7; ヘブル人への手紙 5:7–8; レビ記 16:16"> 「彼は主の前にある祭壇のところに出て行き、そのために贖いを行う。牛の血の一部と山羊の血の一部を取り、祭壇の角の周囲に塗る。</span>
<span className="v" id="v19" data-v="19" data-xref="ゼカリヤ書 13:1; エゼキエル書 43:18–22"> 彼はその血の一部を指で祭壇に七度振りかけ、イスラエルの子らの汚れからそれを清め、聖なるものとする。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="レビ記 16:16; エゼキエル書 45:20; コロサイ人への手紙 1:20"> 「聖所、会見の天幕、および祭壇のための贖罪を終えたとき、彼は生きた山羊をささげる。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 53:6; コリント人への第二の手紙 5:21; エズラ記 10:1"> アロンは生きた山羊の頭に両手を置き、その上でイスラエルの子らのすべての咎と、すべての背き、すなわち彼らのすべての罪を告白する。彼はそれらを山羊の頭に置き、用意された人の手によって荒野に送り出す。</span>
<span className="v" id="v22" data-v="22" data-xref="ヘブル人への手紙 9:28; イザヤ書 53:11–12; ヨハネ 1:29"> 山羊は彼らのすべての咎を負って、人里離れた地へ運んで行く。係の者はその山羊を荒野に放つ。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 44:19; エゼキエル書 42:14; レビ記 16:4"> 「アロンは会見の天幕に入り、聖所に入った時に着た亜麻布の衣を脱ぎ、そこに残しておく。</span>
<span className="v" id="v24" data-v="24" data-xref="レビ記 16:3–5; ヘブル人への手紙 10:19–22; 出エジプト記 28:4–14"> それから彼は聖なる場所で水で体を洗い、自分の衣服を着て外に出る。そして彼自身の全焼のささげ物と民の全焼のささげ物をささげ、自分と民のために贖いを行う。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 29:13; レビ記 4:8–10; レビ記 16:6"> 彼は贖罪のささげ物の脂肪を祭壇の上で燃やす。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="レビ記 16:10; ヘブル人への手紙 7:19; 民数記 19:21"> 山羊を荒野に放った者は、衣服を洗い、水で体を洗う。その後、宿営に入ることができる。</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 4:21; レビ記 6:30; レビ記 4:11–12"> 聖所で贖いを行うために血が持ち込まれた贖罪のささげ物の牛と、贖罪のささげ物の山羊は、宿営の外に運び出される。人々はその皮、肉、および糞を火で焼く。</span>
<span className="v" id="v28" data-v="28"> それらを焼く者は、自分の衣服を洗い、水で体を洗う。その後、彼は宿営に入ることができる。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 58:3; 民数記 29:7; 出エジプト記 20:10"> 「これはあなたがたにとって永遠の掟となる。第七の月の十日には、あなたがたは身を慎み、いかなる仕事もしてはならない。その地に生まれた者であれ、あなたがたの間に住む寄留者であれ、同様である。</span>
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 33:8; 詩篇 51:2; エペソ人への手紙 5:26"> この日に、あなたがたを清めるために贖いが行われるからである。あなたがたは主の前で、すべての罪から清くなる。</span>
<span className="v" id="v31" data-v="31" data-xref="レビ記 23:32; イザヤ書 58:5; レビ記 25:4"> これはあなたがたにとって全き休みの安息日であり、あなたがたは身を慎む。これは永遠の掟である。</span>
<span className="v" id="v32" data-v="32" data-xref="レビ記 16:4; 出エジプト記 29:29–30; レビ記 4:5"> 油注がれ、父に代わって祭司となるように任職された祭司が、贖いを行う。彼は亜麻布の衣、すなわち聖なる衣を着る。</span>
<span className="v" id="v33" data-v="33" data-xref="レビ記 16:16; レビ記 16:24; レビ記 16:6"> 彼は聖なる聖所のために贖いを行い、会見の天幕と祭壇のために贖いを行う。また、祭司たちと会衆のすべての民のために贖いを行う。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ヘブル人への手紙 9:7; ヘブル人への手紙 9:25; 出エジプト記 30:10"> 「これはあなたがたにとって永遠の掟となり、イスラエルの子らのすべての罪のために年に一度、贖いを行うためのものである。」<br />主がモーセに命じられた通りに事が行われた。</span>
</div>

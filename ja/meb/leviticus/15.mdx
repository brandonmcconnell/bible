<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="アモス書 3:7; レビ記 13:1; レビ記 11:1"> 主はモーセとアロンに告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 5:2; サムエル記第二 3:29; レビ記 22:4"> 「イスラエルの子らに告げなさい。『どんな男であれ、その体から漏出がある場合、その漏出のゆえに彼は汚れている。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 23:20; エゼキエル書 16:26; レビ記 12:3"> 漏出による汚れは次のとおりである。分泌物が体から流れ続けていても、詰まっていても、その人は汚れている。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="テトス 1:15; エペソ人への手紙 5:11; コリント人への第一の手紙 15:33"> 漏出のある者が横たわるすべての寝床は汚れ、彼が座るすべてのものも汚れる。</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 11:25; レビ記 16:26; レビ記 17:15"> 彼の寝床に触れる者はだれでも、自分の衣服を洗い、水で体を洗う。その者は夕方まで汚れる。</span>
<span className="v" id="v6" data-v="6" data-xref="ヤコブの手紙 4:8; イザヤ書 1:16"> 漏出のある男が座っていたものに座る者は、自分の衣服を洗い、水で体を洗う。その者は夕方まで汚れる。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 漏出のある者の体に触れる者は、自分の衣服を洗い、水で体を洗う。その者は夕方まで汚れる。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ユダ 1:4; ペテロの第二の手紙 2:1–3; イザヤ書 1:16"> もし漏出のある者が、清い人に唾を吐きかけたなら、その人は自分の衣服を洗い、水で体を洗う。その人は夕方まで汚れる。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 31:34"> 漏出のある者が乗るどんな鞍も汚れる。</span>
<span className="v" id="v10" data-v="10" data-xref="ヤコブの手紙 4:8; 詩篇 26:6; レビ記 15:8"> 彼の下にあったものに触れる者はだれでも、夕方まで汚れる。それらのものを運ぶ者は、自分の衣服を洗い、水で体を洗う。その者は夕方まで汚れる。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 漏出のある者が水で手をすすがずにだれかに触れたなら、触れられた者は自分の衣服を洗い、水で体を洗う。その者は夕方まで汚れる。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="レビ記 6:28; レビ記 11:32–33; コリント人への第二の手紙 5:1"> 漏出のある者が触れた土の器は砕く。また、すべての木の器は水ですすぐ。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="レビ記 14:8; レビ記 8:33; レビ記 15:28"> 漏出のある者がその漏出から清められるとき、彼は清めのために七日間を数え、自分の衣服を洗う。彼は流水で自分の体を洗う。そうすれば彼は清くなる。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="レビ記 12:8; レビ記 12:6; ヘブル人への手紙 10:10"> 八日目に彼は二羽の山鳩、あるいは二羽の家鳩の雛を取り、会見の天幕の入り口で主の前に来て、それらを祭司に渡す。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 14:30–31; レビ記 4:26; マタイ 3:17"> 祭司は一羽を贖罪のささげ物として、もう一羽を全焼のささげ物としてささげる。祭司は彼の漏出について、主の前で彼のために贖いを行う。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 23:10–11; レビ記 22:4; レビ記 15:5"> どんな男であれ、精液の漏出があったなら、彼は水で全身を洗う。彼は夕方まで汚れる。</span>
<span className="v" id="v17" data-v="17"> 精液がついたすべての衣服や革は、水で洗う。それは夕方まで汚れる。</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 15:5; テサロニケ人への手紙第一 4:3–5; コリント人への第一の手紙 6:12"> 男と女が交わり、精液が出たなら、二人とも水で体を洗い、夕方まで汚れる。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="レビ記 12:2; マタイ 15:19; マルコ 5:25"> 女に漏出があり、その体からの漏出が血であるなら、彼女は七日間その月経の汚れにとどまる。彼女に触れる者はだれでも、夕方まで汚れる。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="レビ記 15:4–9; 箴言 2:16–19; 箴言 6:35"> 彼女がその汚れの期間中に横たわるものはすべて汚れる。彼女が座るものもすべて汚れる。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの黙示録 7:14; コリント人への第二の手紙 7:1; イザヤ書 22:14"> 彼女の寝床に触れる者はだれでも、自分の衣服を洗い、水で体を洗う。その者は夕方まで汚れる。</span>
<span className="v" id="v22" data-v="22"> 彼女が座るものに触れる者はだれでも、自分の衣服を洗い、水で体を洗う。その者は夕方まで汚れる。</span>
<span className="v" id="v23" data-v="23"> それが寝床の上であれ、彼女が座っているものの上であれ、彼がそれに触れたなら、夕方まで汚れる。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="レビ記 20:18; ペテロの手紙第一 2:11; レビ記 18:19"> もし男が彼女と寝て、彼女の月経の血が彼についたなら、彼は七日間汚れる。彼が横たわるすべての寝床は汚れる。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="マルコ 5:25; マタイ 9:20; ルカ 8:43"> もし女が月経の期間ではないのに何日も血の漏出がある場合、あるいは月経の期間を過ぎても漏出がある場合、彼女の汚れの漏出の期間中はすべて、月経の期間のようである。彼女は汚れている。</span>
<span className="v" id="v26" data-v="26"> その漏出のすべての日に彼女が横たわるすべての寝床は、月経の時の寝床のように彼女にとって汚れたものである。彼女が座るすべてのものは、月経の汚れのように汚れる。</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 15:21; ヘブル人への手紙 10:22; レビ記 17:15–16"> これらのものに触れる者はだれでも汚れる。その者は自分の衣服を洗い、水で体を洗う。その者は夕方まで汚れる。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="レビ記 15:13–15; ガラテヤ人への手紙 3:13; エペソ人への手紙 1:6–7"> しかし、彼女がその漏出から清められたなら、彼女は七日間を数え、その後清くなる。</span>
<span className="v" id="v29" data-v="29"> 八日目に彼女は二羽の山鳩、あるいは二羽の家鳩の雛を取り、それらを会見の天幕の入り口の祭司のもとに持って来る。</span>
<span className="v" id="v30" data-v="30"> 祭司は一羽を贖罪のささげ物として、もう一羽を全焼のささげ物としてささげる。そして祭司は彼女の漏出の汚れについて、主の前で彼女のために贖いを行う。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="民数記 19:20; 民数記 19:13; エゼキエル書 5:11"> このようにして、イスラエルの子らをその汚れから離れさせなさい。彼らの間にあるわたしの幕屋を汚し、その汚れの中で死ぬことのないためである。』」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="レビ記 11:46; レビ記 13:59; 民数記 6:13"> これが、漏出のある者、および精液の漏出によって汚れた者、</span>
<span className="v" id="v33" data-v="33" data-xref="レビ記 15:19; レビ記 20:18; レビ記 15:24–25"> 月経中の女、および漏出のある男女、そして汚れている女と寝る男についての律法である。</span>
</div>
</div>

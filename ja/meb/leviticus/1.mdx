<span className="v" id="v1" data-v="1" data-xref="出エジプト記 19:3; 出エジプト記 25:22; 出エジプト記 29:42"> 主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="すべて大文字の「主」または「神」はヘブル語のיהוה（ヤハウェ）から来ている。ただし、短い形のיה（ヤハ）から来ていると記されている場合を除く。">a</a></sup>はモーセを呼び、会見の天幕から彼に告げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 22:18–19; ローマ人への手紙 12:6; 歴代誌上 16:29"> 「イスラエルの子らに告げなさい。『あなたがたのうち、だれかが主にささげ物を携えて来るときは、牛または羊の群れからささげなさい。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命記 15:21; ヘブル人への手紙 9:14; レビ記 22:19–24"> 『牛の群れから全焼のささげ物をする場合は、傷のない雄をささげる。その人は主に受け入れられるよう、会見の天幕の入り口でそれを差し出す。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 29:10; 出エジプト記 29:15; レビ記 4:20"> その人が全焼のささげ物の頭に手を置くと、それは彼のための贖いとして受け入れられる。</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 1:11; レビ記 3:8; レビ記 3:2"> 彼は主の前でその若い牛を屠る。祭司であるアロンの子らはその血を差し出し、会見の天幕の入り口にある祭壇の周囲にその血を振りかける。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 7:8; 創世記 3:21"> 彼は全焼のささげ物の皮を剥ぎ、それを切り分ける。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 6:12–13; 創世記 22:9; 歴代誌上 21:26"> 祭司アロンの子らは祭壇の上に火を置き、火の上に薪を整えて並べる。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 9:13–14; レビ記 1:12; 列王記第一 18:33"> 祭司であるアロンの子らは、切り分けた肉、頭、脂肪を、祭壇の上の火にある薪の上に整えて並べる。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 8:21; レビ記 1:13; エペソ人への手紙 5:2"> ただし、その内臓と足は水で洗う。祭司はそのすべてを祭壇の上で全焼のささげ物として燃やす。これは火によるささげ物であり、主への芳ばしい香りである。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 53:6–7; レビ記 1:2–3; 創世記 8:20"> 『もし彼のささげ物が羊の群れ、すなわち羊または山羊からの全焼のささげ物であるなら、傷のない雄をささげる。</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 1:5; 出エジプト記 40:22; レビ記 7:2"> 彼は祭壇の北側で、主の前にそれを屠る。祭司であるアロンの子らは、その血を祭壇の周囲に振りかける。</span>
<span className="v" id="v12" data-v="12"> 彼はそれを、その頭と脂肪とともに切り分ける。祭司はそれらを、祭壇の上の火にある薪の上に整えて並べる。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 1:9"> ただし、内臓と足は水で洗う。祭司はその全体をささげ、祭壇の上で燃やす。これは全焼のささげ物、火によるささげ物であり、主への芳ばしい香りである。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="レビ記 5:7; ルカ 2:24; レビ記 12:8"> 『もし彼の主へのささげ物が鳥の全焼のささげ物であるなら、山鳩または家鳩の雛の中から、彼のささげ物をささげる。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 5:8–9; 詩篇 22:21; ヨハネの手紙第一 2:27"> 祭司はそれを祭壇に持って行き、その頭をねじり切り、祭壇の上で燃やす。その血は祭壇の側面に絞り出される。</span>
<span className="v" id="v16" data-v="16" data-xref="ペテロの手紙第一 1:2; ルカ 1:35; レビ記 16:27"> 彼はその餌袋を羽毛とともに取り除き、祭壇の東側にある灰の場所に投げ捨てる。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 15:10; ヨハネ 19:30; レビ記 1:9–10"> 彼はその翼のところでそれを引き裂く。ただし、二つに切り離してはならない。祭司はそれを祭壇の上、火にある薪の上で燃やす。これは全焼のささげ物、火によるささげ物であり、主への芳ばしい香りである。』」</span>
</div>

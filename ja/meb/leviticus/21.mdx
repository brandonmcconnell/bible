<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 44:25; レビ記 21:11; レビ記 10:6–7"> 主はモーセに言われた。「アロンの子らである祭司たちに告げなさい。『祭司は、自分の民の中の死者のために自分を汚してはならない。</span>
<span className="v" id="v2" data-v="2" data-xref="テサロニケ人への手紙第一 4:13; レビ記 18:6"> ただし、自分に近い親族、すなわち自分の母、父、息子、娘、兄弟のため、</span>
<span className="v" id="v3" data-v="3"> また、自分に近く、まだ夫を持ったことのない処女の姉妹のためには、自分を汚してもよい。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 24:16–17"> 彼は自分の民の中の長である者として、自分を汚して自らを俗なるものにしてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="申命記 14:1; エゼキエル書 44:20; レビ記 19:27–28"> 『彼らは頭を剃ったり、ひげの端を剃り落としたり、肉体に切り傷をつけたりしてはならない。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 3:11; レビ記 18:21; ペテロの手紙第一 2:9"> 彼らは自分たちの神に対して聖なる者でなければならず、自分たちの神の御名を汚してはならない。彼らは主への火によるささげ物、すなわち自分たちの神のパンをささげるからである。それゆえ、彼らは聖なる者である。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="レビ記 21:13–14; エゼキエル書 44:22; レビ記 21:8"> 『祭司は遊女や身を汚した女を妻にめとってはならない。また、夫から離縁された女をめとってはならない。祭司は自分の神に対して聖なる者だからである。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 20:7–8; レビ記 19:2; レビ記 11:44–45"> それゆえ、あなたは彼を聖別しなさい。彼はあなたの神のパンをささげるからである。彼はあなたにとって聖なる者である。あなたがたを聖別する主であるわたしが聖なる者だからである。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 38:24; レビ記 19:29; エゼキエル書 9:6"> 『祭司の娘が遊女となって自分を汚すなら、彼女は自分の父を汚すことになる。彼女は火で燃やされる。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="レビ記 10:6–7; レビ記 16:32; マタイ 26:65"> 『兄弟たちの中で大祭司であり、その頭に注ぎ油が注がれ、衣服を着るために聖別された者は、頭の毛を乱したままにしたり、自分の衣服を引き裂いたりしてはならない。</span>
<span className="v" id="v11" data-v="11" data-xref="民数記 19:14; レビ記 21:1–2; 民数記 6:7"> 彼はどんな死体にも近づいてはならず、自分の父や母のためであっても自身を汚してはならない。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 10:7; 出エジプト記 29:6–7; レビ記 8:9–12"> 彼は聖所から出てはならず、自分の神の聖所を汚してはならない。彼の神の注ぎ油の冠が彼の上にあるからである。わたしは主である。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="レビ記 21:7; コリント人への第二の手紙 11:2; ヨハネの黙示録 14:4"> 『彼は処女を妻にめとる。</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 21:7; エゼキエル書 44:22"> やもめ、離縁された女、汚された女、遊女をめとってはならない。彼は自分の民の中から処女を妻にめとる。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 11:16; コリント人への第一の手紙 7:14; ネヘミヤ記 13:23–29"> 彼は自分の民の中で自分の子孫を汚してはならない。わたしは彼を聖別する主だからである。』」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 主はモーセに告げられた。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 65:4; 民数記 16:5; レビ記 10:3"> 「アロンに告げなさい。『あなたの代々の子孫のうち、体に欠陥のある者は、その神のパンをささげるために近づいてはならない。</span>
<span className="v" id="v18" data-v="18" data-xref="テモテへの手紙第一 3:2–3; レビ記 22:19–25; テトス 1:7"> 欠陥のある者はだれでも近づいてはならない。すなわち、目の見えない者、足の不自由な者、鼻のつぶれた者、または体に変形のある者、</span>
<span className="v" id="v19" data-v="19"> 足や手に骨折がある者、</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 23:1; イザヤ書 56:3"> 背中の曲がった者、小人の者、目に欠陥のある者、白癬のある病やかさぶたのある者、睾丸が損なわれている者である。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 21:6; レビ記 21:8; レビ記 21:17"> 祭司アロンの子孫で体に欠陥のある者は、主への火によるささげ物をささげるために近づいてはならない。彼には欠陥があるので、その神のパンをささげるために近づいてはならない。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 2:3; 民数記 18:19; レビ記 24:8–9"> 彼は自分の神のパンを、最も聖なるものも聖なるものも食べることができる。</span>
<span className="v" id="v23" data-v="23" data-xref="レビ記 21:12; エゼキエル書 44:9–14; 出エジプト記 30:6–8"> しかし、彼には欠陥があるので、垂れ幕に近づいたり、祭壇に近づいたりしてはならない。わたしの聖所を汚さないためである。わたしは彼らを聖別する主だからである。』」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="テモテへの手紙第一 1:18; マラキ書 2:1–7; テモテへの第二の手紙 2:2"> こうしてモーセは、アロンとその子ら、およびイスラエルのすべての子らに語った。</span>
</div>

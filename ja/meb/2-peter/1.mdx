<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テトス 2:13; ローマ人への手紙 3:21–26; テトス 1:4"> イエス・キリスト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「キリスト」は「油を注がれた者」という意味である。">a</a></sup>のしもべであり使徒であるシモン・ペテロから、私たちの神であり救い主であるイエス・キリストの義によって、私たちと同じ尊い信仰を得た人々へ。</span>
<span className="v" id="v2" data-v="2" data-xref="ペテロの第二の手紙 3:18; ヨハネ 17:3; ピリピ人への手紙 3:8"> 神と、私たちの主イエスとを知ることによって、恵みと平安があなたがたにますます豊かに与えられますように。</span>
<span className="v" id="v3" data-v="3" data-xref="ペテロの手紙第一 5:10; テモテへの第二の手紙 1:9; ローマ人への手紙 8:28–30"> ご自身の栄光と徳によって私たちを召してくださった方を知ることにより、私たちは、その神の力によって、命と敬虔に必要なすべてを与えられました。</span>
<span className="v" id="v4" data-v="4" data-xref="エペソ人への手紙 4:23–24; エゼキエル書 36:25–27; コリント人への第二の手紙 3:18"> この栄光と徳によって、神は尊く、この上なく偉大な約束を私たちに与えてくださいました。それは、あなたがたが欲望によって世に生じる腐敗から逃れ、これらの約束を通して神の性質にあずかる者となるためです。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 4:8; 箴言 4:23; ペテロの第二の手紙 3:18"> だからこそ、あなたがたもあらゆる熱意を傾け、信仰に徳を、徳に知識を、</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 10:36; ローマ人への手紙 5:3–4; ルカ 21:19"> 知識に自制を、自制に忍耐を、忍耐に敬虔を、</span>
<span className="v" id="v7" data-v="7" data-xref="ヘブル人への手紙 13:1; ローマ人への手紙 12:10; テサロニケ人への手紙第一 3:12"> 敬虔に兄弟愛を、兄弟愛に愛を加えなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="テトス 3:14; ヨハネ 15:2; ヘブル人への手紙 6:12"> これらがあなたがたに備わり、ますます豊かになるなら、私たちの主イエス・キリストを知ることにおいて、怠惰な者にも、実を結ばない者にもなりません。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの第二の手紙 2:18–20; エペソ人への手紙 5:26; テトス 2:14"> しかし、これらを備えていない人は目が見えず、近くのものしか見えません。自分が過去の罪から清められたことを忘れているのです。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの第二の手紙 3:17; ルカ 6:47–49; ヘブル人への手紙 6:11"> ですから、兄弟たち、<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ここで「兄弟たち」と訳された言葉は、文脈によっては「兄弟姉妹」または「きょうだいたち」と訳すこともできる。">b</a></sup>自分たちへの召しと選びを確かなものとするため、いっそう熱心に努めなさい。これらのことを行っていれば、決してつまずくことはありません。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 5:10; マタイ 25:34; ヨハネの黙示録 3:21"> こうして、私たちの主であり救い主であるイエス・キリストの永遠の王国へ入る道が、あなたがたのために豊かに備えられるのです。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨハネの手紙第一 2:21; ローマ人への手紙 15:14–15; ピリピ人への手紙 3:1"> ですから、あなたがたがこれらのことを知り、今受けている真理に堅く立っているとはいえ、私はいつもそれを思い起こさせることを怠りません。</span>
<span className="v" id="v13" data-v="13" data-xref="ペテロの第二の手紙 3:1; ペテロの第二の手紙 1:14; ヘブル人への手紙 13:3"> 私がこの幕屋に身を置いている間は、これらを思い起こさせ、あなたがたを奮い立たせるのが当然だと考えています。</span>
<span className="v" id="v14" data-v="14" data-xref="テモテへの第二の手紙 4:6; ヨハネ 21:18–19; 申命記 31:14"> 私たちの主イエス・キリストが明らかにしてくださったとおり、私がこの幕屋を脱ぎ捨てる時が迫っていることを知っているからです。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 31:19–29; 詩篇 71:18; ヨシュア記 24:24–29"> それだけでなく、私が世を去った後にも、あなたがたがいつでもこれらのことを思い出せるよう、力を尽くします。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヨハネの手紙第一 4:14; ヨハネ 1:14; テモテへの手紙第一 1:4"> 私たちが、私たちの主イエス・キリストの力と来臨をあなたがたに知らせたとき、巧妙に作り上げられた作り話をよりどころにしたのではありません。私たちは、その方の威光を自分の目で見たのです。</span>
<span className="v" id="v17" data-v="17" data-xref="マルコ 9:7; マタイ 17:5; マタイ 3:17"> イエスが父なる神から誉れと栄光をお受けになったとき、荘厳な栄光から、「これはわたしの愛する子、わたしの心にかなう者である」という声がイエスのもとに響きました。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイ 17:6; ヨシュア記 5:15; 出エジプト記 3:5"> 私たちはイエスとともに聖なる山にいたとき、天から響くこの声を聞きました。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨハネの黙示録 22:16; イザヤ書 9:2; 詩篇 119:105"> 私たちには、さらに確かな預言の言葉があります。夜が明け、明けの明星があなたがたの心に昇るまで、暗い所で輝くともしびとして、その言葉に心を留めるのは良いことです。</span>
<span className="v" id="v20" data-v="20" data-xref="ペテロの第二の手紙 3:3; ローマ人への手紙 12:6; ローマ人への手紙 6:6"> 何よりもまず、聖書のどの預言も、個人的な解釈から生じるものではないことを知っておきなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="テモテへの第二の手紙 3:15–17; ペテロの手紙第一 1:11; サムエル記第二 23:2"> 預言は決して人間の意志によってもたらされたのではなく、神に属する聖なる人々が聖霊に動かされて語ったものだからです。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 24:7; エステル記 5:11; ダニエル書 6:2"> これらのことの後、アハシュエロス王はアガグ人ハメダタの子ハマンを昇進させ、重用し、王とともにいるすべての高官より高い地位に就かせた。</span>
<span className="v" id="v2" data-v="2" data-xref="エステル記 3:5; 詩篇 15:4; エステル記 5:9"> 王の門にいた王の家臣たちは皆、ハマンの前にひざまずき、ひれ伏して敬意を表した。王が彼についてそう命じていたからである。しかしモルデカイは、ひざまずくことも、ひれ伏すこともしなかった。</span>
<span className="v" id="v3" data-v="3" data-xref="エステル記 3:2; 出エジプト記 1:17; エステル記 2:19"> そこで王の門にいた家臣たちはモルデカイに言った。「なぜ王の命令に背くのか。」</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 39:10; ヨナ書 1:9; ダニエル書 6:20–28"> 彼らは毎日語りかけたが、モルデカイは耳を貸さなかった。そこで彼らは、その言い分が通るかどうかを見るため、ハマンに告げた。モルデカイが自分はユダヤ人だと明かしていたからである。</span>
<span className="v" id="v5" data-v="5" data-xref="ダニエル書 3:19; エステル記 5:9; 箴言 21:24"> ハマンは、モルデカイが自分の前にひざまずかず、ひれ伏しもしないのを見て、激しい怒りに満たされた。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 83:4; ヨハネの黙示録 12:12"> だがモルデカイ一人に手を下すだけでは足りないと考えた。モルデカイの民族を知らされていたので、ハマンはアハシュエロスの全王国にいるすべてのユダヤ人、すなわちモルデカイの民を滅ぼそうと企てた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エズラ記 6:15; エゼキエル書 21:21–22; エステル記 9:24–26"> アハシュエロス王の治世第十二年、第一の月、すなわちニサンの月に、ハマンの前でプル、すなわちくじが日ごと、月ごとに投げられ、第十二の月、すなわちアダルの月が選ばれた。</span>
<span className="v" id="v8" data-v="8" data-xref="エズラ記 4:12–15; 使徒の働き 16:20–21; 申命記 4:27"> ハマンはアハシュエロス王に言った。「王国の全州で、諸民族の間に散らされ、離れ離れに暮らしている一つの民族がいます。その法はどの民の法とも異なり、王の法令にも従いません。この民を放置することは、王の利益になりません。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 23:16; マタイ 18:24"> 王がよしとされるなら、彼らを滅ぼす勅令をお書きください。私は一万タラント<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一タラントは約30キログラム、約66ポンド、または約965トロイオンスである。">a</a></sup>の銀を、王の事務をつかさどる者たちに量り渡し、王の宝物庫に納めさせます。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="創世記 41:42; エステル記 8:2; エステル記 7:6"> 王は手から印章の指輪を外し、ユダヤ人の敵であるアガグ人ハメダタの子ハマンに渡した。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカ 23:25; エレミヤ書 40:4; エレミヤ書 26:14"> 王はハマンに言った。「その銀も、その民も、あなたに任せる。あなたのよいと思うようにせよ。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王記第一 21:8; エステル記 1:22; ダニエル書 6:12"> 第一の月の十三日に王の書記官たちが召集され、ハマンの命じたことがすべて、王の総督、各州の長官、各民族の高官に宛てて、それぞれの州の文字、それぞれの民の言語で書かれた。書状はアハシュエロス王の名で記され、王の印章の指輪で封印された。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代誌 第二 30:6; エステル記 9:10; エステル記 8:10–14"> 書状は急使によって王の全州に送られた。それは、第十二の月、すなわちアダルの月の十三日という一日のうちに、若者も老人も、子どもも女も、すべてのユダヤ人を滅ぼし、殺し、絶やし、その財産を略奪せよというものだった。</span>
<span className="v" id="v14" data-v="14" data-xref="エステル記 8:13–14"> この文書の写しは、すべての民がその日に備えるよう、各州で法令として公示された。</span>
<span className="v" id="v15" data-v="15" data-xref="エステル記 8:15; ヨハネ 16:20; 箴言 29:2"> 急使たちは王命によって急ぎ出発し、法令はスサの宮殿でも発布された。王とハマンは座って酒を飲んでいたが、スサの町は混乱に包まれた。</span>
</div>
</div>

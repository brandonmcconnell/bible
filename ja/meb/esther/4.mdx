<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ダニエル書 9:3; エゼキエル書 27:30–31; サムエル記第二 13:19"> モルデカイは起こったことをすべて知ると、衣を裂き、荒布をまとい、灰をかぶった。そして町の中へ出て行き、大声で激しく嘆き叫んだ。</span>
<span className="v" id="v2" data-v="2"> 彼は王の門の前まで来た。荒布をまとったまま王の門に入ることは、誰にも許されていなかったからである。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 22:12; ダニエル書 9:3; イザヤ書 58:5"> 王の命令と法令が届いたどの州でも、ユダヤ人の間に激しい悲しみが起こり、断食と泣き声と嘆きが広がった。多くの者が荒布と灰の中に身を伏せた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="詩篇 77:2; エレミヤ書 31:15; エステル記 1:12"> エステルの侍女たちと宦官たちが来てこのことを告げると、王妃は深く心を痛めた。彼女はモルデカイに衣服を送り、荒布を脱がせようとしたが、彼は受け取らなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第一の手紙 12:26; ローマ人への手紙 12:15; エステル記 1:10"> そこでエステルは、自分に仕えるよう王が任命した宦官の一人ハタクを呼び、何が起こり、なぜそうなったのかをモルデカイから聞くよう命じた。</span>
<span className="v" id="v6" data-v="6" data-xref="エステル記 4:3; エステル記 7:2; エステル記 9:12"> ハタクは、王の門の前にある町の広場へ出て、モルデカイのもとへ行った。</span>
<span className="v" id="v7" data-v="7" data-xref="エステル記 3:2–15"> モルデカイは、自分に起こったことをすべて、またハマンがユダヤ人を滅ぼすため王の宝物庫に納めると約束した銀の正確な額を彼に話した。</span>
<span className="v" id="v8" data-v="8" data-xref="伝道者の書 10:4; ヨブ記 9:15; テモテへの手紙第一 6:13"> さらに、ユダヤ人を滅ぼすためスサで発布された法令の写しを渡し、エステルに見せて事情を説明するよう頼んだ。そして王のもとへ行き、民のために王の憐れみを求め、願い出るよう強く求めた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> ハタクは戻って、モルデカイの言葉をエステルに伝えた。</span>
<span className="v" id="v10" data-v="10"> エステルはハタクに、モルデカイへこう伝えるよう命じた。</span>
<span className="v" id="v11" data-v="11" data-xref="エステル記 5:1–2; エステル記 8:4; ダニエル書 2:9"> 「王の家臣も、王の諸州の民も皆知っています。男であれ女であれ、召されずに内庭の王のもとへ入る者には、死刑という一つの法しかありません。ただし、王が金の笏を差し伸べれば、その者は生きることができます。私はもう三十日も、王のもとへ召されていません。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> エステルの言葉がモルデカイに伝えられた。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 24:10–12; ピリピ人への手紙 2:30; ヨハネ 12:25"> するとモルデカイは、エステルにこう返すよう命じた。「自分は王宮にいるから、ほかのユダヤ人が滅びても自分だけは逃れられるなどと考えてはならない。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 45:4–8; サムエル記第一 12:22; 申命記 32:36"> この時にあなたが黙っているなら、ユダヤ人には別の所から助けと救いが起こる。しかし、あなたと父の家は滅びる。あなたが王妃の位に就いたのは、まさにこの時のためかもしれない。だれがそれを知ろう。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> エステルはモルデカイに、こう返事をするよう命じた。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 20:24; 歴代誌 第二 20:3; ヨエル書 2:12–17"> 「行って、スサにいるすべてのユダヤ人を集め、私のために断食してください。三日三晩、食べることも飲むこともしないでください。私も侍女たちと同じように断食します。その後、法に背くことになりますが、王のもとへ行きます。滅びるなら、滅びよう。」</span>
<span className="v" id="v17" data-v="17"> モルデカイは去り、エステルが命じたことをすべて行った。</span>
</div>

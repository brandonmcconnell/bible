<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ダニエル書 6:14–18; エステル記 7:10; エステル記 1:12–21"> これらのことの後、アハシュエロス王の怒りが静まると、王はワシュティのこと、彼女がしたこと、そして彼女について定められたことを思い起こした。</span>
<span className="v" id="v2" data-v="2" data-xref="列王記第一 1:2; 創世記 12:14; エステル記 6:14"> そこで王に仕える侍臣たちは言った。「王のために、容姿の美しい若い処女たちを捜させましょう。</span>
<span className="v" id="v3" data-v="3" data-xref="エステル記 2:12–15; エステル記 2:8–9; エステル記 1:1–2"> 王国の全州に役人を任命し、美しい若い処女たちをスサの宮殿の後宮に集め、女たちを預かる王の宦官ヘガイの管理下に置かせてください。また、彼女たちに身支度の品を与えさせてください。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイ 14:6; マタイ 20:16; エステル記 1:21"> そして王の心にかなう娘を、ワシュティに代わる王妃としてください。」この提案は王の心にかない、王はそのようにした。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="サムエル記第二 16:5; サムエル記第一 9:1; エステル記 10:3"> さて、スサの宮殿にモルデカイというユダヤ人がいた。彼はベニヤミン人キシュの子シムイの子ヤイルの子であった。</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第二 24:14–15; 歴代誌 第二 36:20; エレミヤ書 24:1"> このキシュは、バビロンの王ネブカデネザルがユダの王エコニヤとともに捕らえ移した捕囚の民とともに、エルサレムから連れ去られた者であった。</span>
<span className="v" id="v7" data-v="7" data-xref="エステル記 2:15; エステル記 1:11; コリント人への第二の手紙 6:18"> モルデカイは、叔父の娘ハダサ、すなわちエステルを育てていた。彼女には父も母もなかった。この娘は姿も顔立ちも美しかった。父母の死後、モルデカイは彼女を自分の娘として引き取ったのである。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="エステル記 2:3; エステル記 2:15"> 王の命令と法令が布告され、多くの娘たちがスサの宮殿に集められてヘガイの管理下に置かれたとき、エステルも王宮に連れて来られ、女たちを預かるヘガイの管理下に置かれた。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 39:21; 箴言 16:7; エステル記 2:12"> この娘はヘガイの心にかない、その好意を得た。彼はすぐに身支度の品と特別な食事を彼女に与え、王宮から選ばれた七人の侍女も付けた。そして彼女と侍女たちを後宮の最良の場所に移した。</span>
<span className="v" id="v10" data-v="10" data-xref="エステル記 2:20; マタイ 10:16; エステル記 3:8"> エステルは自分の民族も親族も明かさなかった。モルデカイが、明かしてはならないと命じていたからである。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 37:14; サムエル記第一 17:18; 使徒の働き 15:36"> モルデカイは毎日、エステルが無事でいるか、これからどうなるかを知ろうとして、後宮の中庭の前を行き来した。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="テサロニケ人への手紙第一 4:4–5; 箴言 7:17; イザヤ書 57:9"> それぞれの娘がアハシュエロス王のもとへ行く番は、十二か月に及ぶ身を清める期間を終えた後に来た。その期間は、六か月を没薬の油で、さらに六か月を香料や女の身支度の品で整えるものだった。</span>
<span className="v" id="v13" data-v="13"> 娘が王のもとへ行くときには、後宮から王宮へ携えて行きたいものは何でも与えられた。</span>
<span className="v" id="v14" data-v="14" data-xref="エステル記 4:11; 創世記 34:19; イザヤ書 62:4–5"> 夕方に王のもとへ入り、翌朝には、側女たちを預かる王の宦官シャアシュガズの管理する第二の後宮へ移された。王が彼女を気に入り、名を呼んで召さない限り、二度と王のもとへ行くことはなかった。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="雅歌 6:9; エステル記 2:3; エステル記 9:29"> モルデカイが娘として引き取った、叔父アビハイルの娘エステルの番が来たとき、彼女は女たちを預かる王の宦官ヘガイが勧めたもの以外、何も求めなかった。エステルは見る者すべてから好意を受けた。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="エステル記 8:9; エステル記 2:3; エステル記 2:1"> エステルがアハシュエロス王の王宮へ迎え入れられたのは、王の治世第七年、第十の月、すなわちテベテの月であった。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 113:7–8; ルカ 1:48–52; エゼキエル書 17:24"> 王はどの女よりもエステルを愛した。彼女はほかのすべての処女にまさって王の好意と慈しみを受けたので、王はその頭に王冠を置き、ワシュティに代わる王妃とした。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="雅歌 3:11; ルカ 14:8; 士師記 14:10–17"> 王はすべての高官と家臣のために、エステルの祝宴と呼ばれる盛大な宴を催した。また諸州に休日を布告し、王の気前のよさにふさわしく贈り物を配った。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="エステル記 2:21; エステル記 2:3–4; エステル記 5:13"> 処女たちが二度目に集められたとき、モルデカイは王の門に座っていた。</span>
<span className="v" id="v20" data-v="20" data-xref="エペソ人への手紙 6:1–3; エステル記 2:10; エステル記 2:7"> エステルはモルデカイに命じられたとおり、まだ自分の親族も民族も明かしていなかった。彼女は養育されていたころと同じように、モルデカイの言いつけに従っていた。</span>
<span className="v" id="v21" data-v="21" data-xref="エステル記 6:2; 列王記第一 16:9; 列王記第二 21:23"> そのころ、モルデカイが王の門に座っていると、入口を守る王の宦官ビッグタンとテレシュの二人が怒りを抱き、アハシュエロス王に手を下そうと企てた。</span>
<span className="v" id="v22" data-v="22" data-xref="エステル記 6:1–2; ローマ人への手紙 11:33; 伝道者の書 10:20"> この企てを知ったモルデカイは王妃エステルに知らせ、エステルはモルデカイの名によって王に報告した。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 40:22; 創世記 40:19; エステル記 10:2"> この件は調査され、事実であると判明したので、二人は木に掛けられた。このことは王の前で年代記に記された。</span>
</div>

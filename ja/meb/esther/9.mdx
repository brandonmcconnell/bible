<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エステル記 3:13; エステル記 8:12; 詩篇 30:11"> 第十二の月、すなわちアダルの月の十三日、王の命令と法令が実行される日が来た。ユダヤ人の敵は彼らを打ち負かそうと望んでいたが、事態は逆転し、ユダヤ人が自分たちを憎む者を打ち負かした。</span>
<span className="v" id="v2" data-v="2" data-xref="エステル記 8:17; エステル記 8:11; 詩篇 71:13"> ユダヤ人はアハシュエロス王の全州にある自分たちの町々に集まり、害を加えようとする者たちに手を下した。誰も彼らの前に立つことができなかった。ユダヤ人への恐れがすべての民をとらえたからである。</span>
<span className="v" id="v3" data-v="3" data-xref="エズラ記 8:36; エステル記 8:5; ダニエル書 6:1–2"> 諸州の高官、総督、長官、王の事務をつかさどる者たちは皆、ユダヤ人を助けた。モルデカイへの恐れが彼らをとらえたからである。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記第二 3:1; 歴代誌上 11:9; サムエル記第一 2:30"> モルデカイは王宮で重んじられ、その名声は全州に広まった。このモルデカイという人は、ますます勢力を増していった。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 18:34–40; 詩篇 20:7–8; 詩篇 149:6–9"> ユダヤ人は剣で敵をことごとく打ち、殺し、滅ぼし、自分たちを憎む者を思うままにした。</span>
<span className="v" id="v6" data-v="6" data-xref="エステル記 3:15"> スサの宮殿で、ユダヤ人は五百人を殺して滅ぼした。</span>
<span className="v" id="v7" data-v="7"> パルシャンダタ、ダルフォン、アスパタ、</span>
<span className="v" id="v8" data-v="8"> ポラタ、アダルヤ、アリダタ、</span>
<span className="v" id="v9" data-v="9"> パルマシュタ、アリサイ、アリダイ、ワエザタ、</span>
<span className="v" id="v10" data-v="10" data-xref="エステル記 5:11; エステル記 8:11; 創世記 14:23"> すなわち、ユダヤ人の敵ハメダタの子ハマンの十人の息子を殺した。しかし略奪品には手を伸ばさなかった。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> その日、スサの宮殿で殺された者の数が王に報告された。</span>
<span className="v" id="v12" data-v="12" data-xref="エステル記 7:2; エステル記 5:6"> 王は王妃エステルに言った。「ユダヤ人はスサの宮殿で五百人を殺して滅ぼし、ハマンの十人の息子も殺した。王のほかの州では、どれほどのことをしただろう。さて、あなたの願いは何か。かなえてやろう。さらに何を求めるのか。そのとおりにしよう。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="エステル記 8:11; 申命記 21:23; エステル記 9:15"> エステルは答えた。「王がよしとされるなら、スサのユダヤ人に、明日も今日の法令どおりに行うことをお許しください。また、ハマンの十人の息子を木柱に掛けさせてください。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 王はそのようにせよと命じた。法令がスサで発布され、ハマンの十人の息子は木に掛けられた。</span>
<span className="v" id="v15" data-v="15" data-xref="エステル記 8:11; エステル記 9:10; エステル記 9:16"> スサのユダヤ人はアダルの月の十四日にも集まり、スサで三百人を殺した。しかし略奪品には手を伸ばさなかった。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="エステル記 8:11; エステル記 9:2; レビ記 26:7–8"> 王の諸州にいたほかのユダヤ人も集まり、命を守り、敵を退けて安息を得た。彼らを憎む者七万五千人を殺したが、略奪品には手を伸ばさなかった。</span>
<span className="v" id="v17" data-v="17" data-xref="エステル記 9:21; エステル記 9:1; エステル記 8:9"> これはアダルの月の十三日のことである。十四日には休み、その日を祝宴と喜びの日とした。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エステル記 9:21; エステル記 9:1; エステル記 9:15"> しかしスサのユダヤ人は十三日と十四日に集まり、十五日に休んで、その日を祝宴と喜びの日とした。</span>
<span className="v" id="v19" data-v="19" data-xref="エステル記 8:17; ヨハネの黙示録 11:10; ネヘミヤ記 8:10–12"> それゆえ、城壁のない町々に住む地方のユダヤ人は、アダルの月の十四日を喜びと祝宴の祝いの日とし、互いに食べ物を贈り合う日としている。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 31:19–22; コリント人への第二の手紙 1:10–11; 詩篇 145:4–12"> モルデカイはこれらの出来事を書き記し、近くにも遠くにも、アハシュエロス王の全州にいるすべてのユダヤ人へ書状を送った。</span>
<span className="v" id="v21" data-v="21"> そして毎年、アダルの月の十四日と十五日を守るよう定めた。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 30:11; イザヤ書 14:3; エステル記 9:19"> それはユダヤ人が敵を退けて安息を得た日々であり、悲しみが喜びに、嘆きが祝いの日に変わった月であった。彼らはその日々を祝宴と喜びの日とし、互いに食べ物を贈り合い、貧しい者に贈り物をする日とした。</span>
<span className="v" id="v23" data-v="23"> ユダヤ人は、自分たちが始めたこの習慣と、モルデカイが書き送ったことを受け入れた。</span>
<span className="v" id="v24" data-v="24" data-xref="エステル記 3:5–13; エステル記 9:10"> すべてのユダヤ人の敵であるアガグ人ハメダタの子ハマンが、ユダヤ人を滅ぼそうと企て、彼らを打ち砕き、絶やすためにプル、すなわちくじを投げたからである。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 7:16; 詩篇 140:9; 詩篇 141:10"> しかしこのことが王に知られると、王は書状によって、ハマンがユダヤ人に対して企てた悪い計略を彼自身の頭上に返し、彼と息子たちを木に掛けるよう命じた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="エステル記 9:20; 民数記 16:40; エゼキエル書 39:11"> このため、プルという言葉にちなんで、これらの日はプリム<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="プリムは、ヘブル語で「くじ」を意味するプルの複数形である。">a</a></sup>と呼ばれた。この書状に記されたすべてのこと、彼らがこの件について見たこと、そして彼らの身に起こったことに基づき、</span>
<span className="v" id="v27" data-v="27" data-xref="ゼカリヤ書 2:11; イザヤ書 56:6; エステル記 8:17"> ユダヤ人は自分たちと子孫、また彼らに加わるすべての者のために、毎年この二日を、記されたとおり、定められた時に必ず守ることを定め、義務として引き受けた。</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 13:8–9; ヨシュア記 4:7; 詩篇 103:2"> これらの日は、すべての世代、すべての家族、すべての州、すべての町で覚えられ、守られなければならない。プリムの日がユダヤ人の間から廃れることなく、その記憶が子孫<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または「種」。">b</a></sup>から消え去ることのないためである。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="エステル記 9:20; エステル記 2:15; エステル記 8:10"> アビハイルの娘である王妃エステルとユダヤ人モルデカイは、プリムについてのこの第二の書状を確定するため、全権をもって書き送った。</span>
<span className="v" id="v30" data-v="30" data-xref="エステル記 1:1; エステル記 8:9; ゼカリヤ書 8:19"> モルデカイは、アハシュエロスの王国百二十七州のすべてのユダヤ人に、平和と真実の言葉を記した書状を送った。</span>
<span className="v" id="v31" data-v="31" data-xref="エステル記 4:3; エステル記 4:16; ヨナ書 3:2–9"> そして、ユダヤ人モルデカイと王妃エステルが定めたとおり、またユダヤ人が自分たちと子孫のため、断食と嘆きについて定めたとおり、プリムの日々をその定められた時に守ることを確定した。</span>
<span className="v" id="v32" data-v="32" data-xref="エステル記 9:26"> エステルの命令によってプリムに関するこれらの事柄は確定され、書物に記された。</span>
</div>
</div>

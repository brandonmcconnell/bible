<span className="v" id="v3" data-v="3" data-xref="箴言 2:1–9; ヨブ記 22:22; 箴言 8:10–11"> <span className="pl pl-1">賢く行動するための教訓を受け、</span><br /><span className="pl pl-2">義と公正と公平を身につけるため。</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 8:5; 箴言 8:17; 詩篇 119:9"> <span className="pl pl-1">浅はかな者に思慮を与え、</span><br /><span className="pl pl-2">若者に知識と慎重さを与えるため。</span></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 12:1; 箴言 9:9; コリント人への第一の手紙 10:15"> <span className="pl pl-1">知恵のある者がこれを聞いて学びを増し、</span><br /><span className="pl pl-2">悟りのある者が確かな助言を得るため。</span></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 78:2; マルコ 4:11; 詩篇 49:4"> <span className="pl pl-1">箴言とたとえ、</span><br /><span className="pl pl-2">知恵のある者の言葉と謎を理解するため。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="ヨブ記 28:28; 詩篇 111:10–1; 伝道者の書 12:13"> <span className="pl pl-1">主</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「主」は、神の固有名であるヘブライ語「יהוה」（一般にヤハウェと発音される）の訳である。">a</a></sup><br /><span className="pl pl-1">を恐れることは知識の初めである。</span><br /><span className="pl pl-2">しかし、愚かな者は知恵と教訓を侮る。</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 6:20; 箴言 30:17; 箴言 5:1–2"> <span className="pl pl-1">わが子よ、父の教訓を聞き、</span><br /><span className="pl pl-2">母の教えを捨ててはならない。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ダニエル書 5:29; 箴言 4:9; 創世記 41:42"> <span className="pl pl-1">それらはあなたの頭を飾る優美な花輪となり、</span><br /><span className="pl pl-2">首を飾る鎖となる。</span></span>
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 5:11; 箴言 16:29; 詩篇 1:1"> <span className="pl pl-1">わが子よ、罪人たちがあなたを誘っても、</span><br /><span className="pl pl-2">同意してはならない。</span></span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 5:26; 箴言 1:18; 箴言 12:6"> <span className="pl pl-1">彼らがこう言っても、「われわれと一緒に来い。</span><br /><span className="pl pl-2">血を流すために待ち伏せしよう。</span><br /><span className="pl pl-2">罪のない者を、理由もなくひそかに狙おう。</span></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 124:3; 詩篇 28:1; ローマ人への手紙 3:13"> <span className="pl pl-1">よみ</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="よみ（シェオル）は死者の場所である。">b</a></sup><br /><span className="pl pl-1">のように、彼らを生きたままのみ込もう。</span><br /><span className="pl pl-2">穴に下る者のように、彼らを丸ごとのみ込もう。</span></span>
<span className="v" id="v13" data-v="13" data-xref="テモテへの手紙第一 6:9–10; ルカ 12:15; ヨブ記 24:2–3"> <span className="pl pl-1">あらゆる貴重な財宝を見つけ、</span><br /><span className="pl pl-2">略奪品で家々を満たそう。</span></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">おまえもわれわれと一緒にくじを引け。</span><br /><span className="pl pl-2">財布は皆で一つにしよう」</span></span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 119:101; 詩篇 1:1; 箴言 4:14–15"> <span className="pl pl-1">わが子よ、彼らと同じ道を歩んではならない。</span><br /><span className="pl pl-2">彼らの道に足を踏み入れてはならない。</span></span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 59:7; 箴言 6:18; 箴言 4:16"> <span className="pl pl-1">彼らの足は悪へと走り、</span><br /><span className="pl pl-2">血を流すことへと急ぐ。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ヨブ記 35:11; 箴言 7:23; エレミヤ書 8:7"> <span className="pl pl-1">どんな鳥の目の前で網を張っても、むだである。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 9:16; エステル記 7:10; 箴言 5:22–23"> <span className="pl pl-1">しかし彼らは、自分の血を流すために待ち伏せし、</span><br /><span className="pl pl-2">自分の命を狙ってひそむ。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 15:27; ペテロの第二の手紙 2:3; ヤコブの手紙 5:1–4"> <span className="pl pl-1">利益をむさぼる者は皆、このような道をたどる。</span><br /><span className="pl pl-2">その利益は、持ち主の命を奪う。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="箴言 9:3; コロサイ人への手紙 2:3; ルカ 11:49"> <span className="pl pl-1">知恵は通りで声高く呼び、</span><br /><span className="pl pl-2">広場で声を上げる。</span></span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 5:20; 箴言 9:3; マタイ 13:2"> <span className="pl pl-1">人の行き交う通りのかどで呼びかけ、</span><br /><span className="pl pl-2">町の門の入り口でこう語る。</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 1:29; 詩篇 1:1; 箴言 5:12"> <span className="pl pl-1">「浅はかな者たちよ、いつまで浅はかさを愛するのか。</span><br /><span className="pl pl-2">あざける者たちは、いつまであざけりを喜び、</span><br /><span className="pl pl-2">愚かな者たちは知識を憎むのか。</span></span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 3:19; エゼキエル書 33:11; エゼキエル書 18:27–30"> <span className="pl pl-1">私の叱責を受けて立ち返れ。</span><br /><span className="pl pl-2">見よ、</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「見よ」は注意を促す間投詞で、「よく見よ」「心に留めよ」という意味を持つ。">c</a></sup><br /><span className="pl pl-2">私はあなたがたに私の霊を注ぐ。</span><br /><span className="pl pl-2">私の言葉をあなたがたに知らせよう。</span></span>
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 65:12; ローマ人への手紙 10:21; エレミヤ書 7:13"> <span className="pl pl-1">私が呼びかけても、あなたがたは拒み、</span><br /><span className="pl pl-2">手を伸ばしても、誰も注意を払わなかった。</span></span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 81:11; ルカ 7:30; 箴言 1:30"> <span className="pl pl-1">あなたがたは私の助言をすべて無視し、</span><br /><span className="pl pl-2">私の叱責を少しも受け入れようとしなかった。</span></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 2:4; 箴言 10:24; 詩篇 37:13"> <span className="pl pl-1">だから私も、あなたがたの災難を笑い、</span><br /><span className="pl pl-2">災いが襲うとき、あざ笑う。</span></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 3:25–26; ルカ 21:34–35; 詩篇 58:9"> <span className="pl pl-1">災いが嵐のように襲い、</span><br /><span className="pl pl-2">災難がつむじ風のように来て、</span><br /><span className="pl pl-2">苦難と苦悩があなたがたに臨むとき。</span></span>
<span className="v" id="v28" data-v="28" data-xref="ミカ書 3:4; ヤコブの手紙 4:3; エレミヤ書 11:11"> <span className="pl pl-1">そのとき彼らは私を呼ぶが、私は答えない。</span><br /><span className="pl pl-2">熱心に私を捜すが、見つけられない。</span></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 1:22; ヨブ記 21:14–15; 箴言 6:23"> <span className="pl pl-1">彼らは知識を憎み、</span><br /><span className="pl pl-2">主を恐れることを選ばなかった。</span></span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 81:11; 箴言 1:25; ルカ 14:18–20"> <span className="pl pl-1">彼らは私の助言を望まず、</span><br /><span className="pl pl-2">私の叱責をことごとく侮った。</span></span>
<span className="v" id="v31" data-v="31" data-xref="箴言 14:14; エレミヤ書 6:19; 箴言 22:8"> <span className="pl pl-1">それゆえ彼らは自分の道の実を食べ、</span><br /><span className="pl pl-2">自分の企みに飽きるほど満たされる。</span></span>
<span className="v" id="v32" data-v="32" data-xref="箴言 8:36; エレミヤ書 2:19; ヨハネ 3:36"> <span className="pl pl-1">浅はかな者の背きは彼らを殺し、</span><br /><span className="pl pl-2">愚かな者の安逸は彼らを滅ぼす。</span></span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 25:12–13; 詩篇 112:7–8; イザヤ書 26:3"> <span className="pl pl-1">しかし、私に聞き従う者は安全に住み、</span><br /><span className="pl pl-2">災いを恐れず、安らかに暮らす。」</span></span>

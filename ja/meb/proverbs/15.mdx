<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 4:13; エレミヤ書 16:17; エレミヤ書 23:24"> <span className="pl pl-1">主の目は至る所にあり、</span><br /><span className="pl pl-2">悪い者も良い者も見ておられる。</span></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 12:18; 箴言 16:24; 箴言 18:8"> <span className="pl pl-1">穏やかな舌は命の木であるが、</span><br /><span className="pl pl-2">よこしまな舌は心を打ち砕く。</span></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 15:31–32; 箴言 13:1; 箴言 13:18"> <span className="pl pl-1">愚かな者は父の教訓を侮るが、</span><br /><span className="pl pl-2">叱責に心を留める者は慎重に行動する。</span></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 8:21; 箴言 21:20; 箴言 10:22"> <span className="pl pl-1">義人の家には多くの宝があるが、</span><br /><span className="pl pl-2">悪しき者の収入には悩みが伴う。</span></span>
<span className="v" id="v7" data-v="7" data-xref="マタイ 12:34; ヤコブの手紙 3:6; エペソ人への手紙 4:29"> <span className="pl pl-1">知恵のある者の唇は知識を広めるが、</span><br /><span className="pl pl-2">愚かな者の心に知識はない。</span></span>

<span className="v" id="v9" data-v="9" data-xref="テモテへの手紙第一 6:11; 箴言 21:21; マタイ 7:13"> <span className="pl pl-1">悪しき者の道は主に忌み嫌われるが、</span><br /><span className="pl pl-2">主は義を追い求める者を愛する。</span></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 12:1; ヨハネ 3:20; 箴言 13:1"> <span className="pl pl-1">道を捨てる者には厳しい訓練があり、</span><br /><span className="pl pl-2">叱責を憎む者は死ぬ。</span></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 44:21; ヘブル人への手紙 4:13; 詩篇 139:8"> <span className="pl pl-1">よみ</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="よみ（シェオル）は死者の場所である。">a</a></sup><br /><span className="pl pl-1">とアバドンは主の前にある。</span><br /><span className="pl pl-2">まして人の子らの心は、なおさらではないか。</span></span>

<span className="v" id="v13" data-v="13" data-xref="箴言 17:22; ヨハネ 14:1; 箴言 18:14"> <span className="pl pl-1">喜びに満ちた心は顔を明るくするが、</span><br /><span className="pl pl-2">心が痛むと気力はくじかれる。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 9:9; イザヤ書 30:10; 箴言 18:15"> <span className="pl pl-1">悟りのある者の心は知識を求めるが、</span><br /><span className="pl pl-2">愚かな者の口は愚かさを食べる。</span></span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第二の手紙 6:10; ローマ人への手紙 12:12; 箴言 15:13"> <span className="pl pl-1">苦しむ者の日々はすべてつらいが、</span><br /><span className="pl pl-2">心の明るい者には絶え間ない宴がある。</span></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 16:8; 詩篇 37:16; 伝道者の書 5:10–12"> <span className="pl pl-1">わずかな物しかなくても主を恐れるほうが、</span><br /><span className="pl pl-2">多くの宝があって悩みを抱えるより良い。</span></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 17:1; 箴言 21:19; ヨハネの手紙第一 4:16"> <span className="pl pl-1">愛のある所で野菜だけを食べるほうが、</span><br /><span className="pl pl-2">憎しみのある所で肥えた子牛を食べるより良い。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 15:1; 箴言 26:21; 箴言 29:22"> <span className="pl pl-1">憤る者は争いを引き起こすが、</span><br /><span className="pl pl-2">怒ることの遅い者は争いを静める。</span></span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 35:8; 箴言 22:5; イザヤ書 30:21"> <span className="pl pl-1">怠け者の道はいばらの生け垣のようだが、</span><br /><span className="pl pl-2">正しい者の道は大路である。</span></span>
<span className="v" id="v20" data-v="20" data-xref="箴言 29:3; 箴言 10:1; 箴言 23:15–16"> <span className="pl pl-1">知恵のある息子は父を喜ばせるが、</span><br /><span className="pl pl-2">愚かな者は母を侮る。</span></span>
<span className="v" id="v21" data-v="21" data-xref="エペソ人への手紙 5:15; 箴言 10:23; 箴言 14:16"> <span className="pl pl-1">愚かさは知恵のない者の喜びだが、</span><br /><span className="pl pl-2">悟りのある人はまっすぐに歩む。</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 11:14; 箴言 20:18; 伝道者の書 8:6"> <span className="pl pl-1">助言がなければ計画は失敗するが、</span><br /><span className="pl pl-2">助言者が多ければ計画は確かなものとなる。</span></span>

<span className="v" id="v25" data-v="25" data-xref="詩篇 146:9; 詩篇 68:5–6; 箴言 14:11"> <span className="pl pl-1">主は高慢な者の家を根こそぎにするが、</span><br /><span className="pl pl-2">やもめの境界を確かなものにされる。</span></span>
<span className="v" id="v26" data-v="26" data-xref="箴言 6:16–19; エレミヤ書 4:14; 箴言 15:23"> <span className="pl pl-1">悪しき者の思いは主に忌み嫌われるが、</span><br /><span className="pl pl-2">純粋な者の思いは喜ばれる。</span></span>

<span className="v" id="v1" data-v="1" data-xref="申命記 28:7; 詩篇 53:5; イザヤ書 26:3–4"> <span className="pl pl-1">悪しき者は追う者がいなくても逃げるが、</span><br /><span className="pl pl-2">義人は獅子のように大胆である。</span></span>
<span className="v" id="v2" data-v="2" data-xref="列王記第一 15:28; 列王記第一 16:8–29; 列王記第二 15:8–31"> <span className="pl pl-1">国に反逆が起こると支配者が多くなるが、</span><br /><span className="pl pl-2">悟りと知識のある人によって秩序は保たれる。</span></span>
<span className="v" id="v3" data-v="3" data-xref="マタイ 18:28–30"> <span className="pl pl-1">貧しい身で貧しい者を虐げる者は、</span><br /><span className="pl pl-2">作物を何も残さない激しい雨のようである。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 1:32; エペソ人への手紙 5:11; マタイ 14:4"> <span className="pl pl-1">律法を捨てる者たちは悪しき者を称賛するが、</span><br /><span className="pl pl-2">律法を守る者たちは彼らと争う。</span></span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 92:6; ヤコブの手紙 1:5; ヨハネの手紙第一 2:27"> <span className="pl pl-1">悪い者たちは公正を理解しないが、</span><br /><span className="pl pl-2">主を求める者たちはそれを完全に理解する。</span></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 19:1; 箴言 28:18; ルカ 16:19–23"> <span className="pl pl-1">潔白に歩む貧しい者は、</span><br /><span className="pl pl-2">道が曲がっていて富む者にまさる。</span></span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの手紙第一 4:3–4; 箴言 29:3; 箴言 3:1–35"> <span className="pl pl-1">律法を守る者は知恵のある息子だが、</span><br /><span className="pl pl-2">大食する者たちの仲間は父に恥をもたらす。</span></span>
<span className="v" id="v8" data-v="8" data-xref="ヨブ記 27:16–17; 箴言 13:22; 伝道者の書 2:26"> <span className="pl pl-1">法外な利息によって財産を増やす者は、</span><br /><span className="pl pl-2">貧しい者をあわれむ人のためにそれを蓄える。</span></span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 66:18; テモテへの第二の手紙 4:3–4; ゼカリヤ書 7:11–13"> <span className="pl pl-1">律法を聞くことから耳をそむける者は、</span><br /><span className="pl pl-2">その祈りさえ忌み嫌われる。</span></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 26:27; 詩篇 37:25–26; ガラテヤ人への手紙 2:4"> <span className="pl pl-1">正しい者を悪い道へ迷わせる者は、</span><br /><span className="pl pl-2">自分のわなに落ちる。</span><br /><span className="pl pl-2">しかし、潔白な者たちは良いものを受け継ぐ。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 18:17; 伝道者の書 9:15–17; 箴言 26:16"> <span className="pl pl-1">富む者は自分の目には知恵があるが、</span><br /><span className="pl pl-2">悟りのある貧しい者は彼を見抜く。</span></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 29:2; 箴言 11:10; 箴言 28:28"> <span className="pl pl-1">義人たちが勝利を得ると、大きな栄光があるが、</span><br /><span className="pl pl-2">悪しき者たちが立ち上がると、人々は身を隠す。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの手紙第一 1:8–10; 詩篇 32:3–5; ヨブ記 31:33"> <span className="pl pl-1">自分の罪を隠す者は栄えないが、</span><br /><span className="pl pl-2">それを告白して捨てる者はあわれみを受ける。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 23:17; 詩篇 2:11; イザヤ書 66:2"> <span className="pl pl-1">常に恐れ慎む人は幸いである。</span><br /><span className="pl pl-2">しかし、心をかたくなにする者は災いに陥る。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ペテロの手紙第一 5:8; マタイ 2:16; 箴言 19:12"> <span className="pl pl-1">ほえる獅子、襲いかかる熊のように、</span><br /><span className="pl pl-2">無力な民を治める悪しき支配者もそうである。</span></span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 18:21; エレミヤ書 22:15–17; 伝道者の書 4:1"> <span className="pl pl-1">圧政を行う支配者には悟りがない。</span><br /><span className="pl pl-2">不正な利益を憎む者は長く生きる。</span></span>
<span className="v" id="v17" data-v="17" data-xref="創世記 9:6; 列王記第一 21:19; 出エジプト記 21:14"> <span className="pl pl-1">人の血を流した罪に責めさいなまれる者は、</span><br /><span className="pl pl-2">死ぬまで逃亡者となる。誰も彼を支えない。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:9; 箴言 28:6; ヨハネの黙示録 3:3"> <span className="pl pl-1">潔白に歩む者は安全に守られるが、</span><br /><span className="pl pl-2">道の曲がった者は突然倒れる。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 12:11; 士師記 9:4; 箴言 27:23–27"> <span className="pl pl-1">自分の土地を耕す者は食物に満ち足りるが、</span><br /><span className="pl pl-2">むなしいものを追い求める者は貧しさに満たされる。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ルカ 16:10–12; 箴言 13:11; ヨハネの黙示録 2:10"> <span className="pl pl-1">忠実な人は祝福に満ちるが、</span><br /><span className="pl pl-2">急いで富もうとする者は罰を免れない。</span></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 24:23; 箴言 18:5; エゼキエル書 13:19"> <span className="pl pl-1">えこひいきすることは良くない。</span><br /><span className="pl pl-2">しかし人は、一切れのパンのためにさえ不正を行う。</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 23:6; テモテへの手紙第一 6:9; 箴言 28:20"> <span className="pl pl-1">物惜しみする者は富を得ようと急ぐが、</span><br /><span className="pl pl-2">貧しさが自分を待っていることを知らない。</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 27:5–6; マタイ 18:15; 詩篇 141:5"> <span className="pl pl-1">人を叱る者は、後になって、</span><br /><span className="pl pl-2">舌でへつらう者よりも多くの好意を得る。</span></span>
<span className="v" id="v24" data-v="24" data-xref="マタイ 15:4–6; 箴言 18:9; 箴言 19:26"> <span className="pl pl-1">父や母から奪いながら、「これは悪いことではない」と言う者は、</span><br /><span className="pl pl-2">滅ぼす者の仲間である。</span></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 11:25; テモテへの手紙第一 6:6; 箴言 13:10"> <span className="pl pl-1">貪欲な者は争いを引き起こすが、</span><br /><span className="pl pl-2">主に信頼する者は豊かにされる。</span></span>
<span className="v" id="v26" data-v="26" data-xref="箴言 3:5; エレミヤ書 17:9; ヨブ記 28:28"> <span className="pl pl-1">自分の心に頼る者は愚かな者だが、</span><br /><span className="pl pl-2">知恵をもって歩む者は安全に守られる。</span></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 19:17; 申命記 15:7; 詩篇 41:1–3"> <span className="pl pl-1">貧しい者に与える者は乏しくならないが、</span><br /><span className="pl pl-2">目をそむける者は多くの呪いを受ける。</span></span>
<span className="v" id="v28" data-v="28" data-xref="箴言 29:2; ヨブ記 24:4; 使徒の働き 12:23–24"> <span className="pl pl-1">悪しき者たちが立ち上がると、人々は身を隠すが、</span><br /><span className="pl pl-2">彼らが滅びると、義人たちは栄える。</span></span>

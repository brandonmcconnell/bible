<span className="v" id="v4" data-v="4" data-xref="ルカ 2:52; サムエル記第一 2:26; ローマ人への手紙 14:18"> <span className="pl pl-1">そうすれば、神と人の目に、</span><br /><span className="pl pl-2">好意と良い評判を得る。</span></span>

<span className="v" id="v7" data-v="7" data-xref="ヨブ記 28:28; ローマ人への手紙 12:16; 箴言 26:12"> <span className="pl pl-1">自分を知恵のある者と思ってはならない。</span><br /><span className="pl pl-2">主を恐れ、悪から離れよ。</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 4:22; 詩篇 147:3; 箴言 16:24"> <span className="pl pl-1">それはあなたの体の健康となり、</span><br /><span className="pl pl-2">骨を潤すものとなる。</span></span>
<span className="v" id="v9" data-v="9" data-xref="申命記 26:2–15; コリント人への第一の手紙 16:2; 出エジプト記 23:19"> <span className="pl pl-1">あなたの財産と、</span><br /><span className="pl pl-2">すべての収穫の初物をもって主をあがめよ。</span></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 19:17; 申命記 28:8; 箴言 22:9"> <span className="pl pl-1">そうすれば、あなたの倉は豊かに満たされ、</span><br /><span className="pl pl-2">搾り場は新しいぶどう酒であふれる。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ヨブ記 5:17; ヨハネの黙示録 3:19; ヘブル人への手紙 12:5–12"> <span className="pl pl-1">わが子よ、主の訓練を侮ってはならない。</span><br /><span className="pl pl-2">その叱責を嫌ってはならない。</span></span>
<span className="v" id="v12" data-v="12" data-xref="申命記 8:5; ヨハネの黙示録 3:19; 箴言 29:17"> <span className="pl pl-1">主は愛する者を正す。</span><br /><span className="pl pl-2">父が喜びとする息子を叱るように。</span></span>
</div>
<div className="bp poetry">

<span className="v" id="v14" data-v="14" data-xref="箴言 16:16; 箴言 8:19; ヨブ記 28:13–19"> <span className="pl pl-1">知恵から得る利益は銀を得ることにまさり、</span><br /><span className="pl pl-2">その収益は純金にまさる。</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 8:11; ヨブ記 28:18; 詩篇 73:25–26"> <span className="pl pl-1">知恵はルビーよりも貴い。</span><br /><span className="pl pl-2">あなたが望むものは何一つ、知恵と比べることができない。</span></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 3:2; コリント人への第二の手紙 6:10; 箴言 22:4"> <span className="pl pl-1">その右の手には長い命があり、</span><br /><span className="pl pl-2">左の手には富と誉れがある。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ルカ 1:79; イザヤ書 26:3; ピリピ人への手紙 4:8–9"> <span className="pl pl-1">その道は喜びに満ちた道であり、</span><br /><span className="pl pl-2">その通り道はすべて平安である。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 11:30; ヨハネの黙示録 2:7; 箴言 15:4"> <span className="pl pl-1">知恵は、それをつかむ者にとって命の木である。</span><br /><span className="pl pl-2">それをしっかり保つ者は皆、幸いである。</span></span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 104:24; エレミヤ書 10:12; ヨハネ 1:3"> <span className="pl pl-1">主は知恵によって地の基を据え、</span><br /><span className="pl pl-2">悟りによって天を堅く立てられた。</span></span>
<span className="v" id="v20" data-v="20" data-xref="創世記 7:11; 詩篇 65:9–12; ヨブ記 36:27–28"> <span className="pl pl-1">その知識によって深淵は裂け、</span><br /><span className="pl pl-2">空は露を滴らせる。</span></span>
<span className="v" id="v21" data-v="21" data-xref="ヨシュア記 1:8; 申命記 6:6–9; 申命記 32:46–47"> <span className="pl pl-1">わが子よ、確かな知恵と思慮を目から離さず、</span><br /><span className="pl pl-2">それらを守れ。</span></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 4:22; 箴言 1:9; イザヤ書 38:16"> <span className="pl pl-1">それらはあなたに命を与え、</span><br /><span className="pl pl-2">あなたの首を飾る優美さとなる。</span></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 4:12; 箴言 10:9; 詩篇 121:3"> <span className="pl pl-1">そのとき、あなたは自分の道を安全に歩み、</span><br /><span className="pl pl-2">あなたの足はつまずかない。</span></span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 3:5; 詩篇 4:8; 箴言 6:22"> <span className="pl pl-1">横になるときも、恐れることはない。</span><br /><span className="pl pl-2">横になれば、あなたの眠りは心地よい。</span></span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 41:10–14; 詩篇 112:7; ペテロの手紙第一 3:14"> <span className="pl pl-1">突然の恐怖におびえてはならない。</span><br /><span className="pl pl-2">悪しき者に滅びが襲うときも、恐れてはならない。</span></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 91:3; サムエル記第一 2:9; 箴言 14:26"> <span className="pl pl-1">主があなたの拠り所となり、</span><br /><span className="pl pl-2">あなたの足をわなから守る。</span></span>
</div>
<div className="bp poetry">

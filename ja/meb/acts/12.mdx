<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 24:9; ヨハネ 15:20; マタイ 10:17–18"> そのころ、ヘロデ王は教会の何人かを迫害しようとし、</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 11:37; マタイ 20:23; マタイ 4:21–22"> ヨハネの兄弟ヤコブを剣で殺しました。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 23:15; ヨハネ 12:43; 使徒の働き 24:27"> それがユダヤ人たちを喜ばせるのを見ると、さらにペテロも捕らえました。それは種なしパンの祭りの期間でした。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 19:21; ルカ 22:33; ルカ 21:12"> ヘロデはペテロを逮捕して牢に入れ、四人一組の兵士四組に引き渡して監視させました。過越の祭りの後、民の前に引き出すつもりだったのです。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第一の手紙 12:26; テサロニケ人への手紙第一 5:17; ヤコブの手紙 5:16"> こうしてペテロは牢に入れられていましたが、教会は彼のために、絶えず神に祈っていました。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 21:33; ヘブル人への手紙 13:6; ピリピ人への手紙 4:6–7"> ヘロデがペテロを引き出そうとしていた前夜、ペテロは二本の鎖につながれ、二人の兵士の間で眠っていました。戸口の前では番兵たちが牢を見張っていました。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 5:19; 使徒の働き 16:26; 詩篇 146:7"> すると見よ、主の使いがそばに立ち、光が牢の中を照らしました。使いはペテロの脇腹をたたいて起こし、「早く立ちなさい」と言いました。すると鎖が彼の両手から外れました。</span>
<span className="v" id="v8" data-v="8"> 使いは彼に言いました。「帯を締め、履物を履きなさい。」ペテロはそのとおりにしました。さらに使いは、「上着を着て、私について来なさい」と言いました。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 126:1; ヘブル人への手紙 11:8; 創世記 45:26"> ペテロは外へ出て、使いについて行きました。しかし、使いがしていることが現実だとは分からず、幻を見ているのだと思っていました。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 5:19; 使徒の働き 16:26; イザヤ書 45:1–2"> 二人は第一、第二の見張り所を通り過ぎ、町へ通じる鉄の門まで来ました。門はひとりでに開きました。二人は外へ出て一つの通りを進むと、すぐに使いはペテロから離れました。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ダニエル書 6:22; ダニエル書 3:28; ペテロの第二の手紙 2:9"> ペテロは我に返って言いました。「今、はっきり分かった。主は御使いを遣わし、ヘロデの手と、ユダヤの民が期待していたすべてのことから、私を救い出してくださったのだ。」</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの手紙第一 5:14–15; 使徒の働き 12:5; マタイ 18:19–20"> そうと分かると、ペテロはマルコと呼ばれるヨハネの母マリアの家へ行きました。そこには大勢の人が集まって祈っていました。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 12:16; ルカ 13:25; ヨハネ 18:16–17"> ペテロが門の戸をたたくと、ロデという女中が応対に出ました。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカ 24:41; マタイ 28:8"> 彼女はペテロの声だと分かると、喜びのあまり門を開けもせずに中へ駆け込み、ペテロが門の前に立っていると知らせました。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="マタイ 18:10; ルカ 24:11; マルコ 16:14"> 人々は彼女に、「気が狂ったのだ」と言いました。しかし彼女は、本当にそうだと言い張りました。そこで人々は、「それは彼の天使だ」と言いました。</span>
<span className="v" id="v16" data-v="16"> しかしペテロは戸をたたき続けました。彼らは戸を開けてペテロを見ると、驚きました。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 21:40; 使徒の働き 13:16; 使徒の働き 19:33"> ペテロは手で合図をして静かにさせ、主がどのように自分を牢から連れ出されたかを話しました。そして、「このことをヤコブと兄弟たちに知らせてください」と言い、そこを出て別の場所へ行きました。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 5:22–25; 使徒の働き 16:27; 使徒の働き 19:23"> 夜が明けると、ペテロがどうなったのかと、兵士たちの間に大変な騒ぎが起こりました。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 16:27; 詩篇 37:32–33; ヨハネ 12:10–11"> ヘロデは彼を捜しましたが、見つけられませんでした。そこで番兵たちを取り調べ、処刑するよう命じました。その後、ヘロデはユダヤからカイサリアへ下り、そこに滞在しました。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="エズラ記 3:7; マタイ 11:21–22; エゼキエル書 27:17"> さて、ヘロデはティルスとシドンの人々に激しく怒っていました。彼らは心を一つにしてヘロデのもとへ行き、王の侍従ブラストを味方につけて、和解を求めました。彼らの地方は王の領地から食糧を得ていたからです。</span>
<span className="v" id="v21" data-v="21"> 定められた日に、ヘロデは王の衣をまとい、王座に着いて彼らに演説しました。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 14:10–13; ヨハネの黙示録 13:4; ユダ 1:16"> 民は「神の声だ。人の声ではない」と叫びました。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 115:1; 使徒の働き 10:25–26; テサロニケ人への第二の手紙 2:4"> するとたちまち主の使いがヘロデを打ちました。彼が神に栄光を帰さなかったからです。彼は虫に食われて死にました。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 6:7; 使徒の働き 19:20; テサロニケ人への第二の手紙 3:1"> しかし、神の言葉はますます広まり、信じる人が増えていきました。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 12:12; ペテロの手紙第一 5:13; 使徒の働き 15:37"> バルナバとサウロは務めを果たすと、エルサレムへ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TRは「へ」の代わりに「から」としている。">a</a></sup>帰りました。そのとき、マルコと呼ばれるヨハネも連れて行きました。</span>
</div>

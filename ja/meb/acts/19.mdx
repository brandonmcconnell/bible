<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 18:23–28; コリント人への第一の手紙 16:12; コリント人への第一の手紙 1:12"> アポロがコリントにいたころ、パウロは内陸地方を通ってエフェソに着き、何人かの弟子に会いました。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネ 7:39; 使徒の働き 11:15–17; ガラテヤ人への手紙 3:5"> 彼らに「信じたとき、聖霊を受けましたか」と尋ねました。<br />彼らは「いいえ、聖霊がおられることさえ聞いたことがありません」と答えました。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 18:25; コリント人への第一の手紙 12:13; 使徒の働き 8:16"> パウロは「それでは、何のためのバプテスマを受けたのですか」と尋ねました。<br />彼らは「ヨハネのバプテスマです」と答えました。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ヨハネ 1:29–34; 使徒の働き 11:16; 使徒の働き 1:5"> パウロは言いました。「ヨハネは悔い改めのバプテスマを授け、自分の後から来られる方、すなわちキリスト・イエスを信じるよう、民に告げました。」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NUは「キリスト」を省いている。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 8:12; 使徒の働き 8:16; ローマ人への手紙 6:3–4"> これを聞いた彼らは、主イエスの名によってバプテスマを受けました。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 6:6; 使徒の働き 2:4; マルコ 16:17"> パウロが彼らの上に手を置くと、聖霊が彼らに臨み、彼らはほかの言語で話し、預言しました。</span>
<span className="v" id="v7" data-v="7"> 彼らは全部で十二人ほどでした。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 28:23; 使徒の働き 1:3; 使徒の働き 9:20–22"> パウロは会堂に入り、三か月にわたって大胆に語り、神の国について論じ、人々を説得しました。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 19:23; 使徒の働き 9:2; 使徒の働き 18:6–8"> しかし、心をかたくなにして従おうとせず、群衆の前で「この道」を悪く言う者たちがいたので、パウロは彼らから離れ、弟子たちを別にして、毎日ティラノの講堂で論じました。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 20:31; テモテへの第二の手紙 1:15; 使徒の働き 16:6"> このことが二年間続いたので、アジアに住む人は皆、ユダヤ人もギリシャ人も、主イエスの言葉を聞きました。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="マルコ 16:17–20; 使徒の働き 5:12; ローマ人への手紙 15:18–19"> 神はパウロの手によって並外れた奇跡を行われました。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 5:15; 列王記第二 13:20–21; マルコ 16:17"> パウロの体に触れた手ぬぐいや前掛けを病人のところへ持って行くだけで、病気が去り、悪霊も出て行くほどでした。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイ 12:27; マルコ 9:38; ルカ 11:19"> ところが、各地を巡り歩くユダヤ人の祈祷師たちの中にも、悪霊につかれた人に主イエスの名を唱え、「パウロが宣べ伝えているイエスによって、おまえたちに命じる」と言う者がいました。</span>
<span className="v" id="v14" data-v="14"> ユダヤ人の祭司長スケワの七人の息子たちが、このことをしていました。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 16:17–18; ルカ 4:33–35; マルコ 1:34"> すると悪霊は答えました。「イエスなら知っている。パウロも知っている。だが、おまえたちは何者だ。」</span>
<span className="v" id="v16" data-v="16" data-xref="ルカ 8:29; マルコ 5:3–4; マルコ 5:15"> 悪霊につかれた男は彼らに飛びかかり、全員を押さえつけて打ち負かしました。彼らは裸にされ、傷を負って、その家から逃げ出しました。</span>
<span className="v" id="v17" data-v="17" data-xref="テサロニケ人への第二の手紙 1:12; 使徒の働き 5:5; ピリピ人への手紙 2:9–11"> このことはエフェソに住むすべてのユダヤ人とギリシャ人に知れ渡りました。皆に恐れが生じ、主イエスの名があがめられました。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 10:10; 詩篇 32:5; マタイ 3:6"> 信じた人々も大勢やって来て、自分の行いを告白し、明らかにしました。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 13:8; 出エジプト記 32:20; 創世記 35:4"> 魔術を行っていた者たちも大勢、書物を持って来て、すべての人の前で焼きました。その値段を計算すると、銀貨五万枚になりました。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ここでいう銀貨五万枚は、おそらく五万ドラクマを指す。その場合、焼かれた書物の価値は、農業労働者およそ百六十人分の年収に相当した。">b</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 12:24; 使徒の働き 6:7; イザヤ書 55:11"> このようにして、主の言葉は力強く広まり、勢いを増していきました。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 20:22; 使徒の働き 20:16; 使徒の働き 23:11"> これらのことが終わると、パウロはマケドニアとアカイアを通ってエルサレムへ行こうと、霊のうちに決意しました。そして、「そこへ行った後、ローマも見なければならない」と言いました。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 16:23; テモテへの第二の手紙 4:20; 使徒の働き 16:3"> そこで、自分に仕えていた者のうち二人、テモテとエラストをマケドニアへ送り、自分はしばらくアジアにとどまりました。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 19:9; 使徒の働き 24:22; コリント人への第二の手紙 1:8–10"> そのころ、「この道」をめぐって大変な騒動が起こりました。</span>
<span className="v" id="v24" data-v="24" data-xref="テモテへの手紙第一 6:9–10; 使徒の働き 16:16; 使徒の働き 16:19"> デメテリオという銀細工人が、アルテミスの銀製の神殿模型を作り、職人たちにかなりの収入を得させていました。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 16:19; ホセア書 12:7–8; ヨハネの黙示録 18:11–19"> 彼は職人たちと同業の仕事をする人々を集めて言いました。「皆さん。この仕事によって、われわれが富を得ていることはご存じのとおりです。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 17:29; コリント人への第一の手紙 8:4; イザヤ書 44:10–20"> ところが、あなたがたが見聞きしているように、あのパウロはエフェソだけでなく、アジアのほぼ全域で、手で造った物は神ではないと言って、大勢の人を説き伏せ、背を向けさせています。</span>
<span className="v" id="v27" data-v="27" data-xref="ゼパニヤ書 2:11; テモテへの手紙第一 6:5; マタイ 23:13"> そのため、われわれの商売の評判が悪くなる危険があるだけではありません。アジア全土と世界が礼拝している偉大な女神アルテミスの神殿も、何の価値もないものと見なされ、女神の威光さえ失われる危険があります。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 13:4; ヨハネの黙示録 17:13; 使徒の働き 16:19–24"> これを聞いた人々は怒りに満たされ、「偉大なのはエフェソ人のアルテミスだ」と叫び始めました。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 20:4; コロサイ人への手紙 4:10; 使徒の働き 27:2"> 町全体が混乱に陥りました。人々はパウロの旅の同行者であるマケドニア人ガイオとアリスタルコを捕らえ、一斉に劇場へなだれ込みました。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 21:39; サムエル記第二 18:2–3; 使徒の働き 17:22–31"> パウロは民衆の中へ入ろうとしましたが、弟子たちが許しませんでした。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒の働き 19:10; 使徒の働き 21:12; 使徒の働き 16:6"> 彼の友人であったアジア州の高官たちも何人か人を送り、劇場へ入るような危険を冒さないでほしいと懇願しました。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 21:34; 使徒の働き 19:40; マタイ 11:7–9"> さて、集会は混乱し、ある者はあることを、別の者は別のことを叫んでいました。大多数の者は、何のために集まったのかさえ分かっていませんでした。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒の働き 12:17; テモテへの第二の手紙 4:14; テモテへの手紙第一 1:20"> ユダヤ人たちは群衆の中からアレクサンデルを前へ押し出しました。アレクサンデルは手で合図をし、民衆に弁明しようとしました。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒の働き 19:28; マタイ 6:7; ヨハネの黙示録 13:4"> しかし、彼がユダヤ人だと分かると、全員が声をそろえ、二時間ほども「偉大なのはエフェソ人のアルテミスだ」と叫び続けました。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="テサロニケ人への第二の手紙 2:10–11; テモテへの手紙第一 4:2; エペソ人への手紙 2:12"> 町の書記官は群衆を静めて言いました。「エフェソの皆さん。エフェソの町が、偉大な女神アルテミスとゼウスから降って来た像の守護者であることを知らない者がいるでしょうか。</span>
<span className="v" id="v36" data-v="36" data-xref="箴言 14:29; 使徒の働き 5:35–39; 箴言 25:8"> これは否定できない事実なのですから、あなたがたは静かにし、軽率なことをしてはなりません。</span>
<span className="v" id="v37" data-v="37" data-xref="コリント人への第二の手紙 6:3; ローマ人への手紙 2:22; 使徒の働き 25:8"> あなたがたはこの者たちをここへ連れて来ましたが、彼らは神殿から物を盗んだわけでも、あなたがたの女神を冒瀆したわけでもありません。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒の働き 13:7; コリント人への第一の手紙 6:1; 使徒の働き 18:14"> ですから、デメテリオとその仲間の職人たちが、だれかに対する訴えを持っているのなら、法廷は開かれており、地方総督たちもいます。互いに告訴すればよいのです。</span>
<span className="v" id="v39" data-v="39"> しかし、それ以外のことについて何か求めるのなら、正式な集会で解決すべきです。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒の働き 17:5–8; マタイ 26:5; 使徒の働き 20:1"> 今日の騒動について、われわれが暴動の罪に問われる危険さえあります。この騒ぎには何の理由もなく、釈明することができないからです。」</span>
<span className="v" id="v41" data-v="41" data-xref="伝道者の書 9:17; 詩篇 65:7; コリント人への第二の手紙 1:8–10"> こう言って、彼は集会を解散させました。</span>
</div>

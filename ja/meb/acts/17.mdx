<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="ACT" data-book-slug="acts" data-book-name="使徒の働き" data-chapter="17" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への手紙第一 1:1; ピリピ人への手紙 4:16; 使徒の働き 20:4"> 一行はアンフィポリスとアポロニアを通って、ユダヤ人の会堂があるテサロニケへ来ました。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 9:20; 使徒の働き 17:17; 使徒の働き 18:4"> パウロはいつものように会堂に入り、三回の安息日にわたって、聖書に基づいて人々と論じ、</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 18:28; 使徒の働き 9:22; ルカ 24:32"> キリストは苦しみを受け、死者の中から復活しなければならなかったことを説明し、証明しました。そして、「私があなたがたに宣べ伝えているこのイエスこそ、キリストです」と語りました。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 17:12; 使徒の働き 13:43; 使徒の働き 14:4"> 彼らのうち何人かは説得され、パウロとシラスの仲間に加わりました。また、敬虔なギリシャ人も大勢、有力な女たちも少なからず加わりました。</span>
<span className="v" id="v5" data-v="5" data-xref="ガラテヤ人への手紙 5:26; 使徒の働き 17:13; ローマ人への手紙 16:21"> しかし、説得されなかったユダヤ人たちは、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TRは「しかし、説得されなかったユダヤ人たちは」の代わりに「しかし、説得されなかったユダヤ人たちは、ねたみに駆られ」としている。">a</a></sup>市場にたむろするならず者を何人か引き入れ、群衆を集めて町に騒動を起こしました。そしてヤソンの家を襲い、パウロたちを民衆の前に引き出そうとしました。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 24:5; 使徒の働き 16:19–21; 使徒の働き 28:22"> しかし見つからなかったので、ヤソンと何人かの兄弟たちを<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ここおよび文脈上可能な箇所で「兄弟」と訳された言葉は、「兄弟姉妹」または「きょうだい」と訳すこともできる。">b</a></sup>町の役人たちのところへ引きずって行き、叫びました。「世界中を騒がせた者たちが、ここにも来ています。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカ 23:2; 使徒の働き 16:21; ヨハネ 19:12"> ヤソンは彼らを迎え入れました。この者たちは皆、イエスという別の王がいると言って、カエサルの布告に逆らっています。」</span>
<span className="v" id="v8" data-v="8" data-xref="マタイ 2:3; ヨハネ 11:48"> 群衆と町の役人たちは、これを聞いて動揺しました。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 17:5"> そしてヤソンとほかの者たちから保証金を取ったうえで、彼らを釈放しました。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 17:2; テサロニケ人への手紙第一 2:2; 使徒の働き 17:13–14"> 兄弟たちはすぐに、夜のうちにパウロとシラスをベレアへ送り出しました。二人は到着すると、ユダヤ人の会堂に入りました。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 34:16; 箴言 2:1–5; ヨハネ 5:39"> ベレアの人々はテサロニケの人々より素直な心を持っていて、非常に熱心に御言葉を受け入れ、果たしてそのとおりかどうか、毎日聖書を調べました。</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 5:14; 使徒の働き 14:1; 使徒の働き 13:50"> それで彼らの多くが信じました。有力なギリシャ人女性や男たちも少なからず信じました。</span>
<span className="v" id="v13" data-v="13" data-xref="テサロニケ人への手紙第一 2:14–16; 箴言 28:25; 使徒の働き 6:12"> しかしテサロニケのユダヤ人たちは、ベレアでもパウロによって神の言葉が宣べ伝えられていると知ると、そこにも来て群衆を扇動しました。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 17:10; マタイ 10:23; 使徒の働き 9:25"> そこで兄弟たちはすぐにパウロを海辺まで送り出しましたが、シラスとテモテはそこに残りました。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 18:5; テサロニケ人への手紙第一 3:1; 使徒の働き 18:1"> パウロを案内した人たちは彼をアテネまで連れて行きました。そして、シラスとテモテはできるだけ早く自分のところへ来るようにというパウロの指示を受けて、帰って行きました。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="詩篇 119:158; ペテロの第二の手紙 2:7; 詩篇 119:136"> さて、パウロはアテネで二人を待っている間、町が偶像で満ちているのを見て、心に激しい憤りを感じました。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 13:16; 使徒の働き 14:1–4; 使徒の働き 17:2–4"> それで会堂ではユダヤ人や敬虔な人々と論じ、広場では毎日、そこに居合わせた人々と論じました。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 1:20–21; コロサイ人への手紙 2:8; ルカ 11:53"> エピクロス派とストア派の哲学者たちも<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="TRは「も」を省いている。">c</a></sup>何人か彼と議論しました。ある者たちは、「このおしゃべりは何を言いたいのだろう」と言いました。<br />ほかの者たちは、パウロがイエスと復活について福音を宣べ伝えていたので、「外国の神々を宣伝しているらしい」と言いました。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="マルコ 1:27; 使徒の働き 17:22; 使徒の働き 24:24"> そこで彼らはパウロをつかまえてアレオパゴスへ連れて行き、言いました。「あなたが語っているその新しい教えがどんなものか、教えてもらえませんか。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 1:23; ホセア書 8:12; コリント人への第一の手紙 2:14"> あなたは私たちの耳に、聞き慣れないことを伝えています。それがどういう意味なのか知りたいのです。」</span>
<span className="v" id="v21" data-v="21" data-xref="テモテへの第二の手紙 2:16–17; コロサイ人への手紙 4:5; エペソ人への手紙 5:16"> アテネ人も、そこに住む外国人も皆、何か新しいことを話したり聞いたりすることだけで時を過ごしていたのです。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 25:19; 使徒の働き 19:35; 使徒の働き 17:16"> パウロはアレオパゴスの中央に立って言いました。「アテネの皆さん。あなたがたは、あらゆる点で非常に信心深いと見受けます。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネ 4:22; ガラテヤ人への手紙 4:8–9; ヨハネ 17:3"> 私が歩きながら、あなたがたの礼拝する物をよく見ていると、『未知の神に』と刻まれた祭壇も見つけました。それで、あなたがたが知らずに礼拝している方を、私はあなたがたに知らせます。</span>
<span className="v" id="v24" data-v="24" data-xref="列王記第一 8:27; 申命記 10:14; 使徒の働き 7:48"> 世界とその中のすべてのものを造られた神は、天地の主ですから、人の手で造った神殿には住まわれません。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 50:8–13; 創世記 2:7; イザヤ書 42:5"> また、何かを必要としているかのように、人の手によって仕えてもらうこともありません。神ご自身が、すべての人に命と息と、すべてのものを与えておられるからです。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 32:7–8; 創世記 3:20; ローマ人への手紙 5:12–19"> 神は、一つの血から人類のすべての国民を造り、地の全面に住まわせました。そして、定められた時期と、その住まいの境界をお決めになりました。</span>
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 23:23–24; 申命記 4:7; 使徒の働き 14:17"> それは、人々が主を求め、手探りでも見つけるためです。もっとも、神は私たち一人一人から遠く離れてはおられません。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨブ記 12:10; コロサイ人への手紙 1:17; ヘブル人への手紙 1:3"> 『私たちは神のうちに生き、動き、存在している』からです。あなたがたの詩人の中にも、『私たちもまた、神の子孫である』と言った人たちがいます。</span>
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 40:25; 出エジプト記 20:4; 詩篇 115:4–8"> 私たちは神の子孫なのですから、神を、人間の技術や考案によって彫られた金や銀や石の像のように考えるべきではありません。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 14:16; テトス 2:11–12; ルカ 24:47"> 神はこれまでの無知の時代を見過ごしてこられました。しかし今は、どこにいる人にも皆、悔い改めるよう命じておられます。</span>
<span className="v" id="v31" data-v="31" data-xref="マタイ 25:31–46; ペテロの第二の手紙 3:7; ローマ人への手紙 2:16"> 神が、ご自分の定めた一人の人によって、義をもって世界を裁く日をお決めになったからです。そして、その方を死者の中から復活させることにより、すべての人に確かな証拠をお与えになりました。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 17:18; 使徒の働き 26:8; 使徒の働き 25:19"> 人々は死者の復活について聞くと、ある者たちはあざ笑い、ほかの者たちは「このことについては、もう一度あなたの話を聞きたい」と言いました。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> こうしてパウロは彼らの中から出て行きました。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒の働き 17:19; ローマ人への手紙 11:5–6; 使徒の働き 13:48"> しかし、彼について行って信じた人たちもいました。その中には、アレオパゴスの議員ディオニシオ、ダマリスという女、またほかの人々もいました。</span>
</div>
</div>

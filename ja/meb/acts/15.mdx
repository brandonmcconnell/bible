<span className="v" id="v1" data-v="1" data-xref="ガラテヤ人への手紙 5:6; 使徒の働き 15:5; レビ記 12:3"> さて、ある人々がユダヤから下って来て、兄弟たちに<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="ここおよび文脈上可能な箇所で「兄弟」と訳された言葉は、「兄弟姉妹」または「きょうだい」と訳すこともできる。">a</a></sup>「モーセの慣習に従って割礼を受けなければ、あなたがたは救われない」と教えました。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 15:22–23; 使徒の働き 15:6–7; ガラテヤ人への手紙 2:1–2"> そのため、パウロとバルナバは彼らと激しく対立し、議論しました。そこで教会は、この問題について使徒たちと長老たちに相談するため、パウロとバルナバ、また仲間の数人をエルサレムへ上らせることにしました。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 14:27; 使徒の働き 21:5; コリント人への第一の手紙 16:11"> 教会の人々に見送られた彼らはフェニキアとサマリアを通り、異邦人が回心したことを詳しく伝えて、すべての兄弟たちに大きな喜びをもたらしました。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 14:27; 使徒の働き 15:12; 使徒の働き 15:3"> エルサレムに着くと、教会と使徒たちと長老たちに迎えられ、神が自分たちを通して行われたすべてのことを報告しました。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ガラテヤ人への手紙 5:1–3; ピリピ人への手紙 3:5–8; 使徒の働き 15:1"> ところが、信者になったパリサイ派の人々の中から数人が立ち上がり、「異邦人にも割礼を施し、モーセの律法を守るよう命じなければならない」と言いました。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="箴言 15:22; ヘブル人への手紙 13:7; ヘブル人への手紙 13:17"> そこで使徒たちと長老たちは、この問題を検討するために集まりました。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 10:17–18; ガラテヤ人への手紙 2:7–9; 歴代誌上 28:4–5"> 多くの議論がなされた後、ペテロが立って彼らに言いました。「兄弟たち。ずっと以前に、神があなたがたの中で私を選び、私の口から異邦人が福音の言葉を聞いて信じるようにされたことを、あなたがたは知っています。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 1:24; 使徒の働き 10:47; 使徒の働き 14:3"> 人の心をご存じである神は、私たちと同じように彼らにも聖霊を与え、彼らを受け入れられたことを証しされました。</span>
<span className="v" id="v9" data-v="9" data-xref="エペソ人への手紙 3:6; ガラテヤ人への手紙 5:6; 使徒の働き 10:28"> また、私たちと彼らの間に何の差別もなさらず、信仰によって彼らの心を清められました。</span>
<span className="v" id="v10" data-v="10" data-xref="ガラテヤ人への手紙 5:1; マタイ 23:4; ガラテヤ人への手紙 4:9"> それなのに今、なぜあなたがたは神を試み、私たちの父祖も私たちも負いきれなかったくびきを、弟子たちの首にかけようとするのですか。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 3:24; テトス 3:4–7; テトス 2:11"> 私たちは、彼らと同じように、主イエスの恵みによって<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TRは「キリスト」を加えている。">b</a></sup>救われると信じています。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 14:27; 使徒の働き 15:4; 使徒の働き 21:19"> すると全員が静かになり、バルナバとパウロが、神が二人を通して異邦人の間で行われたしるしと不思議について語るのに耳を傾けました。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 12:17; ガラテヤ人への手紙 2:12; ヤコブの手紙 1:1"> 二人が語り終えると、ヤコブが答えました。「兄弟たち、私の話を聞いてください。</span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの第二の手紙 1:1; 使徒の働き 15:7–9; ルカ 2:31–32"> シメオンは、神が初めに異邦人を顧み、その中からご自分の名のために一つの民を選び出された次第を話してくれました。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 15:8–12; 使徒の働き 13:47"> これは預言者たちの言葉と一致しています。こう書かれています。</span>
<span className="v" id="v16" data-v="16" data-xref="アモス書 9:11–12; 詩篇 89:35–49; ルカ 1:31–33"> <span className="pl pl-1">『その後、私は戻って来る。</span><br /><span className="pl pl-1">倒れたダビデの幕屋を再び建てる。</span><br /><span className="pl pl-1">その廃墟を再び建て、</span><br /><span className="pl pl-1">それを立て直す。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ゼカリヤ書 2:11; ゼカリヤ書 8:20–23; イザヤ書 65:1"> <br /><span className="pl pl-1">それは、残りの人々が主を求めるため、</span><br /><span className="pl pl-1">私の名で呼ばれるすべての異邦人が主を求めるためである。</span><br /><span className="pl pl-1">これらのことをすべて行う主が、こう言われる。』</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 1:4; エペソ人への手紙 3:9; イザヤ書 46:9–10"> 神のすべてのわざは、永遠の昔から神に知られています。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 15:28; ガラテヤ人への手紙 1:7–10; 使徒の働き 15:24"> ですから私の判断では、異邦人の中から神に立ち返る人々を悩ませてはなりません。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 15:29; ヨハネの黙示録 2:20; レビ記 3:17"> ただし、偶像によって汚された物、性的不品行、絞め殺した動物、血を避けるようにと、彼らに書き送るべきです。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 13:15; 使徒の働き 13:27; コリント人への第二の手紙 3:14–15"> モーセの律法は昔から、町ごとに宣べ伝える人がおり、安息日ごとに諸会堂で朗読されているからです。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 15:27; 使徒の働き 15:40; テサロニケ人への手紙第一 1:1"> そこで使徒たちと長老たちは、教会全体と共に、自分たちの中から人を選び、パウロとバルナバに同行させてアンティオキアへ送るのがよいと考えました。選ばれたのは、兄弟たちの中で指導的な人である、バルサバと呼ばれるユダとシラスでした。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="ここおよび文脈上可能な箇所で「兄弟」と訳された言葉は、「兄弟姉妹」または「きょうだい」と訳すこともできる。">c</a></sup></span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 23:26; ヤコブの手紙 1:1; ガラテヤ人への手紙 1:21"> そして彼らの手に、次の手紙を託しました。<br />「使徒と長老と兄弟たちから、アンティオキア、シリア、キリキアにいる異邦人の兄弟たちへ。ごあいさつ申し上げます。</span>
<span className="v" id="v24" data-v="24" data-xref="ガラテヤ人への手紙 5:12; ガラテヤ人への手紙 5:10; 使徒の働き 15:1"> 私たちの中から出て行ったある者たちが、私たちの命令もないのに、『割礼を受けて律法を守らなければならない』と言葉であなたがたを悩ませ、心をかき乱したと聞きました。</span>
<span className="v" id="v25" data-v="25" data-xref="ペテロの第二の手紙 3:15; 使徒の働き 1:14; 使徒の働き 15:2"> そこで私たちは心を一つにし、人を選んで、愛するバルナバとパウロと共にあなたがたのもとへ送るのがよいと考えました。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 14:19; 使徒の働き 9:23–25; ピリピ人への手紙 2:29–30"> この二人は、私たちの主イエス・キリストの名のために命を危険にさらしてきた人たちです。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 15:22; 使徒の働き 15:32; ヨハネの手紙第三 1:13"> それでユダとシラスを遣わしました。二人も同じことを自分の口で伝えます。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネ 16:13; ヨハネの黙示録 2:24; マタイ 11:30"> 聖霊と私たちは、次の必要なことのほかは、あなたがたにこれ以上の重荷を負わせないのがよいと考えました。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 15:20; 使徒の働き 21:25; ヨハネの黙示録 2:14"> すなわち、偶像にささげた物、血、絞め殺した動物、性的不品行を避けることです。これらを慎んでいれば、よいでしょう。お元気で。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 16:4; 使徒の働き 6:2; 使徒の働き 23:33"> こうして一行は送り出され、アンティオキアへ行きました。そして大勢の人を集め、手紙を手渡しました。</span>
<span className="v" id="v31" data-v="31" data-xref="ガラテヤ人への手紙 2:4–5; ピリピ人への手紙 3:3; ガラテヤ人への手紙 5:1"> 人々はそれを読むと、その励ましを喜びました。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 11:23; 使徒の働き 14:22; 使徒の働き 13:1"> ユダとシラスも預言者だったので、多くの言葉をもって兄弟たちを励まし、力づけました。</span>
<span className="v" id="v33" data-v="33" data-xref="コリント人への第一の手紙 16:11; 使徒の働き 16:36; ヘブル人への手紙 11:31"> 二人はしばらく滞在した後、兄弟たちから平安のうちに送り出され、使徒たちのもとへ帰りました。</span>
<span className="v" id="v34" data-v="34"> <sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="写本によっては次の文を加えている。しかしシラスは、そこにとどまるのがよいと考えた。">d</a></sup></span>
<span className="v" id="v35" data-v="35" data-xref="テモテへの第二の手紙 4:2; コロサイ人への手紙 1:28; 使徒の働き 13:1"> 一方、パウロとバルナバはアンティオキアにとどまり、ほかの多くの人々と共に主の言葉を教え、福音を宣べ伝えました。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒の働き 14:6; 使徒の働き 13:4; 使徒の働き 13:51"> 何日かたって、パウロはバルナバに言いました。「さあ、主の言葉を宣べ伝えた町を一つ一つ再び訪ね、兄弟たちがどうしているか見て来ましょう。」</span>
<span className="v" id="v37" data-v="37" data-xref="使徒の働き 12:12; フィレモンへの手紙 1:24; 使徒の働き 13:5"> バルナバは、マルコと呼ばれるヨハネも連れて行くつもりでした。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒の働き 13:13; 箴言 25:19; ルカ 14:27–34"> しかしパウロは、パンフィリアで自分たちから離れ、働きに同行しなかった者を連れて行くのはよくないと考えました。</span>
<span className="v" id="v39" data-v="39" data-xref="コロサイ人への手紙 4:10; 伝道者の書 7:20; 使徒の働き 4:36"> そのため激しい衝突が起こり、二人は別々に行くことになりました。バルナバはマルコを連れ、船でキプロスへ渡りました。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒の働き 15:22; 使徒の働き 14:26; 使徒の働き 11:23"> 一方パウロはシラスを選び、兄弟たちから神の恵みに委ねられて出発しました。</span>
<span className="v" id="v41" data-v="41" data-xref="使徒の働き 15:23; ガラテヤ人への手紙 1:21; 使徒の働き 15:32"> そしてシリアとキリキアを巡り、諸教会を力づけました。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への手紙第一 2:17; ルカ 5:4; サムエル記第一 20:41–42"> 私たちは彼らと別れて船出し、コスへ直航しました。翌日はロドスへ、そこからパタラへ行きました。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨナ書 1:3; 使徒の働き 11:19; 使徒の働き 15:3"> フェニキアへ渡る船を見つけたので、それに乗って出航しました。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 21:16; 使徒の働き 4:36; マタイ 4:24"> キプロスが見える所まで来ると、その島を左にしてシリアへ向かい、ティルスに上陸しました。船がそこで積み荷を降ろすことになっていたからです。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 20:22–23; 使徒の働き 21:10–12; 使徒の働き 20:6–7"> 私たちは弟子たちを見つけ、そこに七日間滞在しました。彼らは霊によって、エルサレムへ上らないようパウロに告げました。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 20:36; 使徒の働き 9:40; 詩篇 95:6"> 滞在の日数が終わると、私たちは出発して旅を続けました。彼らは妻や子どもも含めて皆、町の外まで見送りに来ました。そして海岸でひざまずいて祈りました。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 19:27; ヨハネ 1:11; コリント人への第二の手紙 2:13"> 互いに別れを告げた後、私たちは船に乗り、彼らは家へ帰りました。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヘブル人への手紙 13:24; サムエル記第一 10:4; 使徒の働き 28:12"> 私たちはティルスからの航海を終えてプトレマイスに着きました。兄弟たちにあいさつし、彼らのもとに一日滞在しました。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 6:5; 使徒の働き 8:26–40; エペソ人への手紙 4:11"> 翌日、パウロの同行者である私たちは出発し、カイサリアへ行きました。<br />そして七人の一人である伝道者ピリポの家に入り、彼のもとに滞在しました。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 2:17; ヨハネの黙示録 2:20; ヨエル書 2:28"> この人には、預言をする未婚の娘が四人いました。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 11:28; 使徒の働き 21:4; 使徒の働き 20:16"> 私たちがそこに何日か滞在していると、アガボという預言者がユダヤから下って来ました。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 21:33; エレミヤ書 13:1–11; サムエル記第一 15:27–28"> 彼は私たちのところへ来ると、パウロの帯を取り、それで自分の手足を縛って言いました。「聖霊はこう言われます。『エルサレムのユダヤ人たちは、この帯の持ち主をこのように縛り、異邦人の手に引き渡す。』」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マタイ 16:21–23; 使徒の働き 20:22; 使徒の働き 21:4"> 私たちはこれを聞くと、その土地の人々と共に、エルサレムへ上らないようパウロに懇願しました。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 20:24; ピリピ人への手紙 2:17; ピリピ人への手紙 1:20–21"> しかしパウロは答えました。「なぜ泣いて、私の心をくじくのですか。私は主イエスの名のためなら、縛られるだけでなく、エルサレムで死ぬ覚悟もできています。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ルカ 22:42; マタイ 26:42; マタイ 26:39"> パウロが聞き入れようとしないので、私たちは「主の御心が行われますように」と言って、口をつぐみました。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 25:1; 使徒の働き 25:6; 使徒の働き 25:9"> 数日後、私たちは荷物をまとめ、エルサレムへ上りました。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 16:31; 使徒の働き 21:8; 詩篇 92:14"> カイサリアの弟子たちも何人か同行し、私たちが泊めてもらうことになっていたキプロス人ムナソンのところへ案内しました。彼は初期からの弟子でした。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 15:4; ローマ人への手紙 15:7; ヘブル人への手紙 13:1–2"> 私たちがエルサレムに着くと、兄弟たちは喜んで迎えてくれました。</span>
<span className="v" id="v18" data-v="18" data-xref="ガラテヤ人への手紙 1:19; ガラテヤ人への手紙 2:9; 使徒の働き 15:13"> 翌日、パウロは私たちと一緒にヤコブを訪ねました。長老たちも全員そこにいました。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 14:27; 使徒の働き 1:17; ローマ人への手紙 15:18–19"> パウロは彼らにあいさつした後、自分の務めを通して神が異邦人の間で行われたことを、一つ一つ報告しました。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 10:2; ガラテヤ人への手紙 1:14; 使徒の働き 22:3"> 彼らはそれを聞いて神をあがめ、パウロに言いました。「兄弟よ、ご覧なさい。ユダヤ人の中で信じた者は何万人もいて、皆が律法に熱心です。</span>
<span className="v" id="v21" data-v="21" data-xref="ガラテヤ人への手紙 6:12–15; コリント人への第一の手紙 9:19–21; ガラテヤ人への手紙 5:1–6"> ところが彼らは、あなたが異邦人の中にいるすべてのユダヤ人にモーセを捨てるよう教え、子どもに割礼を施さず、慣習に従って歩まないよう告げていると聞かされています。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 15:12; 使徒の働き 15:22; 使徒の働き 19:32"> では、どうすればよいでしょう。あなたが来たことを彼らは必ず聞きつけ、人々が集まって来るでしょう。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 18:18; 民数記 6:2–7"> ですから、私たちの言うとおりにしてください。ここに誓願を立てている男が四人います。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 21:26; 使徒の働き 24:18; 使徒の働き 18:18"> この人たちを連れて行って一緒に身を清め、彼らが髪をそるための費用を負担してください。そうすれば、あなたについて聞かされていることには何の真実もなく、あなた自身も律法を守って歩んでいることが、皆に分かります。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 15:29; 使徒の働き 15:19–20"> しかし、信者になった異邦人については、偶像にささげた食べ物、血、絞め殺した動物、性的不品行を避けること以外、何も守る必要はないと決定し、書き送っておきました。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 24:18; 使徒の働き 21:24; 民数記 6:13–20"> そこでパウロはその男たちを連れ、翌日、彼らと一緒に身を清めて神殿に入りました。そして、彼ら一人一人のために供え物がささげられる、清めの期間が終わる日を届け出ました。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 26:21; 使徒の働き 24:18; 使徒の働き 13:50"> 七日間が終わろうとしていたとき、アジアから来たユダヤ人たちが神殿でパウロを見つけ、群衆全体を扇動して彼を捕らえ、</span>
<span className="v" id="v28" data-v="28" data-xref="使徒の働き 24:5–6; 使徒の働き 21:21; 使徒の働き 26:20–21"> 叫びました。「イスラエルの人たち、手を貸してくれ。この男は至る所で、すべての人に、われわれの民と律法とこの場所に逆らうことを教えている。そのうえ、ギリシャ人を神殿に連れ込み、この聖なる場所を汚した。」</span>
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 20:4; テモテへの第二の手紙 4:20; 使徒の働き 18:19"> 彼らは以前、エフェソ人トロフィモが町でパウロと一緒にいるのを見て、パウロが彼を神殿に連れ込んだものと思ったのです。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 26:21; コリント人への第二の手紙 11:26; 使徒の働き 16:19–22"> 町全体が騒然となり、人々が一斉に駆けつけました。そしてパウロを捕らえて神殿の外へ引きずり出すと、すぐに門が閉じられました。</span>
<span className="v" id="v31" data-v="31" data-xref="コリント人への第二の手紙 11:23–33; 使徒の働き 17:5; 使徒の働き 26:9–10"> 彼らがパウロを殺そうとしていると、エルサレム中が混乱に陥っているとの知らせが、部隊の千人隊長に届きました。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 23:27; イザヤ書 3:15; 使徒の働き 5:40"> 千人隊長はすぐに兵士と百人隊長たちを率い、群衆のところへ駆け下りました。人々は千人隊長と兵士たちを見ると、パウロを殴るのをやめました。</span>
<span className="v" id="v33" data-v="33" data-xref="エペソ人への手紙 6:20; 使徒の働き 21:11; 使徒の働き 20:23"> そこで千人隊長は近づいてパウロを逮捕し、二本の鎖で縛るよう命じてから、彼が何者で、何をしたのかと尋ねました。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒の働き 19:32; 使徒の働き 23:10; 使徒の働き 22:24"> しかし群衆の中では、ある者はあることを、別の者は別のことを叫びました。騒がしくて確かなことが分からなかったので、千人隊長はパウロを兵営へ連れて行くよう命じました。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="ハバクク書 1:2–3; 詩篇 55:9; 詩篇 58:2"> パウロが階段に差しかかると、群衆の暴力が激しかったため、兵士たちが彼を担がなければなりませんでした。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネ 19:15; 使徒の働き 22:22; ルカ 23:18"> 大勢の民が後について来て、「そんな男は除いてしまえ」と叫んでいたからです。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒の働き 21:34; ルカ 21:15; 使徒の働き 19:30"> 兵営へ連れ込まれようとしたとき、パウロは千人隊長に「少しお話ししてもよいでしょうか」と尋ねました。<br />千人隊長は言いました。「おまえはギリシャ語を話せるのか。</span>
<span className="v" id="v38" data-v="38" data-xref="マタイ 24:26; 使徒の働き 5:36–37; マタイ 5:11"> それなら、少し前に反乱を起こし、四千人の暗殺者を率いて荒野へ出た、あのエジプト人ではないのか。」</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒の働き 22:3; 使徒の働き 9:11; 使徒の働き 23:27"> しかしパウロは言いました。「私はキリキアのタルソ出身のユダヤ人で、名もない町ではないタルソの市民です。どうか民に話すことをお許しください。」</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="使徒の働き 12:17; 使徒の働き 22:2; ヨハネ 5:2"> 千人隊長が許可すると、パウロは階段の上に立ち、民に手で合図をしました。すっかり静かになると、ヘブル語で彼らに語り始めました。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 18:4; 使徒の働き 13:51; 使徒の働き 13:46"> イコニオムでも、二人は一緒にユダヤ人の会堂へ入りました。そして語ると、ユダヤ人とギリシャ人の非常に多くの人が信じました。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 13:50; 使徒の働き 21:27–30; 使徒の働き 14:19"> しかし、信じない<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「従わない」。">a</a></sup>ユダヤ人たちは異邦人を扇動し、兄弟たちに対して悪意を抱かせました。</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 2:4; エペソ人への手紙 6:18–20; 使徒の働き 20:32"> それでも二人は長い間そこに滞在し、主にあって大胆に語りました。主は二人の手によってしるしと不思議を行わせ、ご自分の恵みの言葉を証しされました。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 28:24; 使徒の働き 14:14; ルカ 11:21–23"> 町の群衆は二つに分かれ、一方はユダヤ人たちに、もう一方は使徒たちに味方しました。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 14:19; テモテへの第二の手紙 3:11; 使徒の働き 17:5"> 異邦人とユダヤ人がその指導者たちと共に、二人を虐待し、石で打とうと襲いかかったとき、</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 14:20–21; マタイ 10:23; テモテへの第二の手紙 3:11"> 二人はそれに気づき、リカオニアの町々、リステラとデルベ、およびその周辺へ逃れました。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 14:21; 使徒の働き 16:10; テサロニケ人への手紙第一 2:2"> そして、そこで福音を宣べ伝えました。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 3:2; ヨハネ 9:1–2; ヨハネ 5:3–5"> リステラに、生まれつき足が不自由で、一度も歩いたことのない男が座っていました。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 3:4; マタイ 15:28; マタイ 9:28–29"> 彼はパウロの話に耳を傾けていました。パウロは彼をじっと見つめ、癒やされる信仰があるのを見て、</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 35:6; ヨハネ 5:8–9; ヨハネ 14:12"> 大声で「自分の足で、まっすぐに立ちなさい」と言いました。すると男は跳び上がり、歩き始めました。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 28:6; 使徒の働き 8:10; 使徒の働き 12:22"> 群衆はパウロのしたことを見ると、声を張り上げ、リカオニアの言葉で言いました。「神々が人間の姿になって、われわれのところへ下って来た。」</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 19:35"> そして、バルナバを「ゼウス」、パウロを、主に話す人だったので「ヘルメス」と呼びました。</span>
<span className="v" id="v13" data-v="13" data-xref="ダニエル書 2:46; 使徒の働き 10:25"> 町の前にあるゼウス神殿の祭司は、雄牛と花輪を門のところへ運んで来て、群衆と共にいけにえをささげようとしました。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マタイ 26:65; コリント人への第一の手紙 9:5–6; 列王記第二 5:7"> しかし使徒たち、すなわちバルナバとパウロはこれを聞くと、衣を引き裂いて群衆の中へ飛び込み、叫びました。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 10:26; コリント人への第一の手紙 8:4; ヤコブの手紙 5:17"> 「皆さん、なぜこんなことをするのですか。私たちもあなたがたと同じ人間です。あなたがたがこのようなむなしい物から離れ、天と地と海、またその中のすべてのものを造られた生ける神に立ち返るよう、福音を伝えているのです。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 17:30; 詩篇 81:12; ローマ人への手紙 1:28"> 神は過ぎ去った時代には、すべての国民がそれぞれ自分の道を歩むままにされました。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 1:19–20; ヨエル書 2:23; ヨブ記 5:10"> それでも、ご自分についての証しを残さずにおかれたのではありません。良いことを行い、天からあなたがたに<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TRは「あなたがた」の代わりに「私たち」としている。">b</a></sup>雨を降らせ、実りの季節を与え、食べ物と喜びで私たちの心を満たしてくださったのです。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 44:16–17; 創世記 19:9; 創世記 11:6"> こう言って、二人はようやく、群衆が自分たちにいけにえをささげるのをやめさせました。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第二の手紙 11:25; テモテへの第二の手紙 3:11; 使徒の働き 13:50–51"> ところが、アンティオキアとイコニオムからユダヤ人たちが来て、群衆を説き伏せました。そしてパウロを石で打ち、死んだものと思って町の外へ引きずり出しました。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="コリント人への第二の手紙 1:9–10; コリント人への第二の手紙 6:9; 使徒の働き 14:6"> しかし弟子たちが周りを取り囲むと、パウロは立ち上がって町に入りました。翌日、彼はバルナバと共にデルベへ出発しました。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 14:19; 使徒の働き 14:1; 使徒の働き 13:51"> 二人はその町で福音を宣べ伝え、多くの人を弟子にしてから、リステラ、イコニオム、アンティオキアへ引き返し、</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの手紙第一 5:10; テモテへの第二の手紙 3:12; ヨハネ 16:33"> 弟子たちの心を強め、信仰にとどまるよう励ましました。そして、「私たちは多くの苦難を通って神の国に入らなければならない」と語りました。</span>
<span className="v" id="v23" data-v="23" data-xref="テトス 1:5; 使徒の働き 11:30; ヤコブの手紙 5:14"> また、教会ごとに長老たちを任命し、断食して祈った後、彼らが信じた主に彼らを委ねました。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 13:13–14; 使徒の働き 15:38"> それから二人はピシディアを通り、パンフィリアへ来ました。</span>
<span className="v" id="v25" data-v="25"> ペルガで御言葉を語った後、アタリアへ下りました。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 15:40; 使徒の働き 11:19; コリント人への第二の手紙 1:12"> そこから船でアンティオキアへ戻りました。そこは、二人が今成し遂げた働きのために神の恵みに委ねられ、送り出された所でした。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への第一の手紙 16:9; 使徒の働き 15:12; コロサイ人への手紙 4:3"> 到着すると教会を集め、神が自分たちを通して行われたすべてのこと、また、異邦人に信仰の扉を開かれたことを報告しました。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒の働き 11:26; 使徒の働き 15:35"> そして弟子たちと共に、そこに長く滞在しました。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネ 18:19–21; マタイ 26:61–62; 使徒の働き 6:13–14"> 大祭司が「そのとおりなのか」と尋ねました。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 22:1; 創世記 11:31; 詩篇 29:3"> ステファノは言いました。「兄弟たち、父たち、聞いてください。私たちの父アブラハムがハランに住む前、メソポタミアにいたとき、栄光の神が彼に現れて、</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 12:1; ヘブル人への手紙 11:8; ヨシュア記 24:3"> 『あなたの土地と親族を離れ、私が示す土地へ行きなさい』と言われました。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 12:4–5; 創世記 11:31–32; イザヤ書 41:9"> そこでアブラハムはカルデア人の土地を出て、ハランに住みました。彼の父が死んだ後、神は彼をそこから、今あなたがたが住んでいるこの土地に移されました。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 17:8; 創世記 12:7; 創世記 13:15"> しかし神は、この土地では足を置く場所ほどの相続地さえ彼にお与えになりませんでした。それでも、まだ子どものいなかった彼に、この土地を彼とその後の子孫の所有として与えると約束されました。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 15:13; 出エジプト記 12:40–41; ガラテヤ人への手紙 3:17"> 神はこのように語られました。『彼の子孫はよその土地に寄留し、四百年の間、奴隷にされて虐げられる。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 3:12; 詩篇 105:27–36; ネヘミヤ記 9:9–11"> しかし、彼らを奴隷にする国民を私は裁く。その後、彼らはそこから出て、この場所で私に仕える。』</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 35:23–26; 創世記 17:9–14; 創世記 21:1–4"> それから神はアブラハムに割礼の契約をお与えになりました。こうしてアブラハムにイサクが生まれ、八日目に割礼を施しました。イサクにヤコブが生まれ、ヤコブに十二人の族長が生まれました。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 39:2; 詩篇 105:17; イザヤ書 43:2"> 族長たちはヨセフをねたんでエジプトへ売りました。しかし神はヨセフと共におられ、</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 3:4; テモテへの第二の手紙 4:18; 箴言 2:6"> あらゆる苦難から彼を救い出し、エジプト王ファラオの前で好意と知恵をお与えになりました。ファラオは彼をエジプトとその全家の支配者にしました。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 41:54–57; 創世記 45:11; 創世記 42:5"> さて、エジプトとカナンの全土に飢饉が起こり、大きな苦難が訪れました。私たちの父祖は食べ物を見つけられませんでした。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 42:1–24; 創世記 43:2"> しかし、ヤコブはエジプトに穀物があると聞き、私たちの父祖を初めてそこへ送りました。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 45:1–18; 創世記 46:31–10"> 二度目のとき、ヨセフは兄弟たちに自分の身を明かし、ヨセフの一族のことがファラオに知らされました。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 46:26–27; 申命記 10:22; 出エジプト記 1:5"> ヨセフは人を送り、父ヤコブと親族全員、合わせて七十五人を呼び寄せました。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 49:33; 出エジプト記 1:6; 創世記 46:3–7"> こうしてヤコブはエジプトに下り、そこで彼も私たちの父祖も死にました。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨシュア記 24:32; 創世記 23:16; 出エジプト記 13:19"> 彼らはシェケムに運び戻され、アブラハムがシェケムのハモルの子らから銀を払って買った墓に納められました。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 1:7–12; 使徒の働き 7:6; 使徒の働き 13:17"> しかし、神がアブラハムに誓われた約束の時が近づくにつれ、民はエジプトで成長し、数を増していきました。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 1:8"> やがて、ヨセフを知らない別の王が現れました。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 105:25; 出エジプト記 1:9–22; ヨハネの黙示録 12:4–5"> この王は私たちの民を欺いて父祖たちを虐げ、赤ん坊を生き延びさせないよう捨てさせました。</span>
<span className="v" id="v20" data-v="20" data-xref="ヘブル人への手紙 11:23; 出エジプト記 2:2–10; サムエル記第一 16:12"> そのころモーセが生まれました。彼は神の目に非常に美しく、三か月の間、父の家で育てられました。</span>
<span className="v" id="v21" data-v="21" data-xref="ヘブル人への手紙 11:24; 出エジプト記 2:2–10; 申命記 32:26"> 彼が捨てられると、ファラオの娘が拾い上げ、自分の息子として育てました。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 19:11; ダニエル書 1:17–20; 歴代誌 第二 9:22"> モーセはエジプト人のあらゆる知恵を教え込まれ、その言葉にも行いにも力がありました。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 2:11–12; 箴言 21:1; ヘブル人への手紙 11:24–26"> 四十歳になったとき、彼は自分の兄弟である<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="ここおよび文脈上可能な箇所で「兄弟」と訳された言葉は、「兄弟姉妹」または「きょうだい」と訳すこともできる。">a</a></sup>イスラエルの子らを訪ねようと思い立ちました。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネ 18:10–11; 使徒の働き 7:28; ヨハネ 18:25–27"> そして、その一人が不当な扱いを受けているのを見て彼を守り、虐げられていた人のためにエジプト人を打ち倒して報復しました。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 15:7; マルコ 9:32; 列王記第二 5:1"> モーセは、自分の手によって神が彼らを救おうとしておられることを、兄弟たちも理解していると思っていました。しかし、彼らは理解しませんでした。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 2:13–15; 箴言 18:19; ヨハネの手紙第一 3:11–15"> 翌日、モーセは彼らが争っているところに現れ、仲直りさせようとして言いました。『あなたがた、同じ兄弟ではありませんか。なぜ互いに傷つけ合うのですか。』</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 7:35; ルカ 12:14; 使徒の働き 7:54"> しかし、隣人を傷つけていた者はモーセを押しのけて言いました。『だれがおまえをわれわれの支配者や裁判官にしたのか。</span>
<span className="v" id="v28" data-v="28"> 昨日エジプト人を殺したように、私も殺すつもりか。』</span>
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 18:2–4; 出エジプト記 2:14–22; 出エジプト記 4:19–20"> モーセはこの言葉を聞いて逃げ、ミディアンの地で寄留者となり、そこで二人の息子の父となりました。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 3:1–2; 使徒の働き 7:35; イザヤ書 43:2"> 四十年がたったとき、シナイ山の荒野で、燃える茂みの炎の中に主の使いがモーセに現れました。</span>
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 3:3–4"> モーセはこれを見て、その光景を不思議に思いました。よく見ようとして近づくと、主の声が聞こえました。</span>
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 3:6; マタイ 22:32; ヨブ記 4:14"> 『私はあなたの父祖の神、アブラハムの神、イサクの神、ヤコブの神である。』モーセは震え上がり、あえて見ようとはしませんでした。</span>
<span className="v" id="v33" data-v="33" data-xref="出エジプト記 3:5; ヨシュア記 5:15; 伝道者の書 5:1"> 主は彼に言われました。『履物を脱ぎなさい。あなたが立っている場所は聖なる地だからである。</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 3:7–10; 出エジプト記 4:31; 詩篇 106:44"> 私はエジプトにいる私の民の苦しみを確かに見、そのうめきを聞いた。それで、彼らを救い出すために下って来た。さあ、私はあなたをエジプトへ遣わす。』</span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="詩篇 118:22–23; ルカ 19:14; 詩篇 113:7–8"> 『だれがおまえを支配者や裁判官にしたのか』と言って彼らが拒んだこのモーセを、神は、茂みの中で彼に現れた使いの手によって、支配者また解放者として遣わされました。</span>
<span className="v" id="v36" data-v="36" data-xref="出エジプト記 12:41; 出エジプト記 14:21; 出エジプト記 33:1"> この人が彼らを導き出し、エジプトの地と紅海と荒野で、四十年にわたって不思議としるしを行いました。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 18:15–19; 使徒の働き 3:22–23; ヨハネ 18:37"> このモーセこそ、イスラエルの子らに、『主なる私たちの神は、私のような預言者を、あなたがたの兄弟たちの中から一人起こしてくださる』と言った人です。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TRは「あなたがたは彼に聞き従わなければならない」を加えている。">b</a></sup></span>
<span className="v" id="v38" data-v="38" data-xref="ローマ人への手紙 3:2; ヘブル人への手紙 5:12; ペテロの手紙第一 4:11"> この人が、荒野の集会で、シナイ山において彼に語った使いと私たちの父祖と共にいて、私たちに与えるための生ける言葉を受けたのです。</span>
<span className="v" id="v39" data-v="39" data-xref="民数記 14:3–4; 民数記 11:5; ネヘミヤ記 9:16–17"> ところが、私たちの父祖は彼に従おうとせず、彼を退け、心ではエジプトへ引き返して、</span>
<span className="v" id="v40" data-v="40" data-xref="出エジプト記 32:1; 出エジプト記 32:23"> アロンに言いました。『われわれの先に立って進む神々を造ってくれ。われわれをエジプトの地から導き出した、あのモーセがどうなったのか分からないからだ。』</span>
<span className="v" id="v41" data-v="41" data-xref="詩篇 106:19–21; ネヘミヤ記 9:18; ヨハネの黙示録 9:20"> 彼らはそのころ子牛を造り、その偶像にいけにえをささげ、自分たちの手で造った物を喜びました。</span>
<span className="v" id="v42" data-v="42" data-xref="アモス書 5:25–26; エゼキエル書 20:39; エレミヤ書 19:13"> そこで神は背を向け、彼らを天の軍勢<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="この慣用句は「天の万軍」「天使たち」または「天体」と訳すこともできる。">c</a></sup>に仕えるままにされました。預言者たちの書にこう記されているとおりです。<br /><span className="pl pl-1">『イスラエルの家よ、荒野でほふった動物といけにえを、</span><br /><span className="pl pl-2">四十年の間、あなたがたは私にささげたのか。</span></span>
<span className="v" id="v43" data-v="43" data-xref="アモス書 5:26–27; 出エジプト記 20:4–5; 申命記 5:8–9"> <span className="pl pl-1">あなたがたはモロクの幕屋と、</span><br /><span className="pl pl-2">あなたがたの神レファンの星を担いだ。</span><br /><span className="pl pl-1">それは、拝むために自分たちで造った像である。</span><br /><span className="pl pl-2">それゆえ、私はあなたがたをバビロンの向こうへ連れ去る。』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v44" data-v="44" data-xref="出エジプト記 25:40; 出エジプト記 38:21; ヘブル人への手紙 8:5"> 私たちの父祖は荒野で、あかしの幕屋を持っていました。それは、モーセに語られた方が、彼の見た型に従って造るよう命じられたものです。</span>
<span className="v" id="v45" data-v="45" data-xref="詩篇 44:2; ヨシュア記 18:1; ヨシュア記 23:9"> 私たちの父祖はそれを受け継ぎ、ヨシュアと共にこの地へ運び入れました。そのとき、神は父祖たちの前から異邦の民を追い出されました。あかしの幕屋はダビデの時代までありました。</span>
<span className="v" id="v46" data-v="46" data-xref="詩篇 132:1–5; 使徒の働き 13:22; サムエル記第二 7:1–5"> ダビデは神の御前で恵みを受け、ヤコブの神のために住まいを見つけたいと願いました。</span>
<span className="v" id="v47" data-v="47" data-xref="列王記第一 8:20; 列王記第一 6:37–38; サムエル記第二 7:13"> しかし、神のために家を建てたのはソロモンでした。</span>
<span className="v" id="v48" data-v="48" data-xref="使徒の働き 17:24–25; イザヤ書 66:1–2; 列王記第一 8:27"> とはいえ、いと高き方は人の手で造った神殿には住まわれません。預言者がこう言っているとおりです。</span>
<span className="v" id="v49" data-v="49" data-xref="イザヤ書 66:1; 詩篇 11:4; ヨハネ 4:21"> <span className="pl pl-1">『天は私の王座、</span><br /><span className="pl pl-2">地は私の足台である。</span><br /><span className="pl pl-1">あなたがたは私のために、どのような家を建てようというのか、と主は言われる。</span><br /><span className="pl pl-2">私が休む場所はどこにあるのか。</span></span>
<span className="v" id="v50" data-v="50" data-xref="エレミヤ書 32:17; 詩篇 33:6–9; 使徒の働き 14:15"> <span className="pl pl-1">これらすべてを造ったのは、私の手ではないか。』</span></span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="申命記 10:16; エペソ人への手紙 4:30; イザヤ書 63:10"> かたくなで、心と耳に割礼を受けていない者たち。あなたがたはいつも聖霊に逆らっています。父祖たちがしたとおり、あなたがたもしているのです。</span>
<span className="v" id="v52" data-v="52" data-xref="マタイ 5:12; 歴代誌 第二 36:16; 列王記第一 19:10"> あなたがたの父祖が迫害しなかった預言者が一人でもいましたか。彼らは正しい方が来られることを前もって告げた人々を殺しました。そして今や、あなたがたがその正しい方を裏切り、殺す者となったのです。</span>
<span className="v" id="v53" data-v="53" data-xref="ヘブル人への手紙 2:2; ガラテヤ人への手紙 3:19; 使徒の働き 7:38"> あなたがたは、天使たちによって定められた律法を受けたのに、それを守りませんでした。」</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="使徒の働き 5:33; 詩篇 35:16; マタイ 25:30"> 人々はこれを聞くと心を切り裂かれるように感じ、ステファノに向かって歯ぎしりしました。</span>
<span className="v" id="v55" data-v="55" data-xref="マルコ 16:19; ヘブル人への手紙 1:3; コリント人への第二の手紙 4:6"> しかし、ステファノは聖霊に満たされ、じっと天を見つめて、神の栄光と、神の右に立っておられるイエスを見ました。</span>
<span className="v" id="v56" data-v="56" data-xref="マタイ 26:64–65; 使徒の働き 10:11; ヨハネの黙示録 11:19"> そして言いました。「見よ、天が開けて、人の子が神の右に立っておられるのが見えます。」</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="ゼカリヤ書 7:11; 詩篇 58:4; 使徒の働き 23:27"> すると人々は大声で叫び、耳をふさぎ、一斉に彼へ襲いかかりました。</span>
<span className="v" id="v58" data-v="58" data-xref="使徒の働き 22:20; 使徒の働き 8:1; 使徒の働き 6:13"> そしてステファノを町の外へ追い出し、石を投げつけました。証人たちは、自分たちの上着をサウロという若者の足もとに置きました。</span>
<span className="v" id="v59" data-v="59" data-xref="ルカ 23:46; 詩篇 31:5; 使徒の働き 22:16"> 人々が石を投げつける間、ステファノは呼び求めて言いました。「主イエスよ、私の霊をお受けください。」</span>
<span className="v" id="v60" data-v="60" data-xref="マタイ 5:44; ルカ 23:34; コリント人への第一の手紙 15:20"> そしてひざまずき、大声で叫びました。「主よ、この罪を彼らに負わせないでください。」こう言って、彼は眠りにつきました。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="レビ記 10:1–3; テモテへの第二の手紙 2:20; マタイ 13:47–48"> ところが、アナニアという男が、妻サッピラと共に財産を売り、</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 4:37; ペテロの第二の手紙 2:14–15; マタイ 23:5"> 妻も承知のうえで、その代金の一部を自分たちのために取っておき、残りの一部を持って来て使徒たちの足もとに置きました。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 23:24; イザヤ書 29:15; ヨハネ 13:2"> そこでペテロは言いました。「アナニア。なぜサタンに心を満たされて聖霊に偽りを言い、土地の代金の一部を取っておいたのですか。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 5:3; ヨシュア記 7:25–26; 列王記第二 5:25–27"> 売らずにおけば、あなたのものだったではありませんか。売った後も、代金はあなたが自由にできたではありませんか。どうしてこんなことを心に抱いたのですか。あなたが偽った相手は人ではなく、神です。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 5:10–11; 使徒の働き 2:43; 使徒の働き 5:13"> アナニアはこの言葉を聞くと倒れ、息絶えました。これを聞いたすべての人に、大きな恐れが生じました。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 19:40; サムエル記第二 18:17; 申命記 21:23"> 若者たちは立ち上がって彼を布で包み、運び出して葬りました。</span>
<span className="v" id="v7" data-v="7"> それから三時間ほどたって、何が起こったかを知らない彼の妻が入って来ました。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 5:2"> ペテロは彼女に尋ねました。「土地を売った代金は、この金額だったのですか。」<br />彼女は「はい、その金額です」と言いました。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="コリント人への第一の手紙 10:9; 使徒の働き 5:3–4; 詩篇 95:8–11"> そこでペテロは彼女に言いました。「どうして二人で申し合わせて主の霊を試したのですか。見よ、あなたの夫を葬った人たちの足が戸口まで来ています。彼らはあなたも運び出します。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 5:5"> すると彼女はたちまちペテロの足もとに倒れ、息絶えました。若者たちが入って来ると、彼女が死んでいるのを見つけ、運び出して夫のそばに葬りました。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 5:5; コリント人への第一の手紙 10:11–12; 使徒の働き 19:17"> 教会全体と、これらのことを聞いたすべての人に、大きな恐れが生じました。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 19:11; コリント人への第二の手紙 12:12; ヘブル人への手紙 2:4"> 使徒たちの手によって、民の間で多くのしるしと不思議が行われました。皆は心を一つにしてソロモンの柱廊に集まっていました。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 2:47; 使徒の働き 4:21; ヨハネ 12:42"> ほかの者はだれも、あえて彼らの仲間に加わろうとはしませんでしたが、民は彼らを高く評価していました。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 2:47; 使徒の働き 4:4; イザヤ書 55:11–13"> そして、主を信じる男も女も、ますます大勢加えられました。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイ 14:36; 使徒の働き 19:11–12; ヨハネ 14:12"> ついには、ペテロが通りかかるとき、せめてその影だけでも病人のだれかにかかるようにと、人々は病人を通りに運び出し、簡易寝台や敷物の上に寝かせるほどでした。</span>
<span className="v" id="v16" data-v="16" data-xref="マルコ 16:17–18; マルコ 2:3–4; マタイ 15:30–31"> また、エルサレム周辺の町々からも大勢の人が集まり、病人や汚れた霊に苦しめられている人々を連れて来ました。そして全員が癒やされました。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 13:45; 使徒の働き 7:9; 使徒の働き 17:5"> ところが、大祭司とその仲間、すなわちサドカイ派の人々は立ち上がり、ねたみに満たされて、</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 4:3; ルカ 21:12; コリント人への第二の手紙 11:23"> 使徒たちを捕らえ、公の留置場に入れました。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 16:26; 詩篇 34:7; 使徒の働き 12:7–11"> しかし、夜になると主の使いが牢の戸を開け、彼らを外へ連れ出して言いました。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネ 6:63; ヨハネ 6:68; ヨハネの手紙第一 5:11–12"> 「行って神殿に立ち、この命についての言葉をすべて民に語りなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ヨハネ 8:2; 使徒の働き 22:15; 使徒の働き 12:18–19"> 彼らはこれを聞くと、夜明けごろ神殿に入り、教え始めました。一方、大祭司とその仲間たちは到着すると、最高法院とイスラエルの子らの長老会全体を招集し、使徒たちを連れて来させようと牢へ人を送りました。</span>
<span className="v" id="v22" data-v="22"> ところが、役人たちが行ってみると、使徒たちは牢の中にいませんでした。そこで戻って報告しました。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 2:4; 詩篇 33:10; ダニエル書 6:22–24"> 「牢はしっかり閉ざされ、戸の前には番人たちが立っていました。しかし開けてみると、中にはだれもいませんでした。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 4:1; 使徒の働き 5:26; ヨハネ 12:19"> 大祭司、神殿の警備隊長、祭司長たちはこの報告を聞くと、これはいったいどうなるのかと、ひどく困惑しました。</span>
<span className="v" id="v25" data-v="25"> そのとき、ある人が来て告げました。「見よ、あなたがたが牢に入れた者たちが、神殿に立って民を教えています。」</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 5:13; 使徒の働き 4:21; マタイ 26:5"> そこで警備隊長は役人たちと一緒に行き、使徒たちを連れて来ました。ただし、民に石で打たれるのを恐れ、乱暴には扱いませんでした。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="マタイ 5:22; 使徒の働き 4:7; ルカ 22:66"> 彼らが使徒たちを連れて来て最高法院の前に立たせると、大祭司は問いただして、</span>
<span className="v" id="v28" data-v="28" data-xref="マタイ 27:25; 使徒の働き 7:52; 使徒の働き 4:10–11"> 言いました。「この名によって教えてはならないと、厳しく命じておいたではないか。見よ、おまえたちは自分たちの教えをエルサレム中に広め、あの男の血の責任をわれわれに負わせようとしている。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 4:19; サムエル記第一 15:24; マルコ 7:7–9"> しかし、ペテロと使徒たちは答えました。「人にではなく、神に従わなければなりません。</span>
<span className="v" id="v30" data-v="30" data-xref="ガラテヤ人への手紙 3:13; ペテロの手紙第一 2:24; 使徒の働き 10:39"> 私たちの父祖の神は、あなたがたが木にかけて殺したイエスを復活させられました。</span>
<span className="v" id="v31" data-v="31" data-xref="ルカ 24:47; 使徒の働き 2:33; ヘブル人への手紙 2:10"> 神はイスラエルに悔い改めと罪の赦しを与えるため、この方を君また救い主として、ご自分の右に上げられました。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネ 15:26–27; ヘブル人への手紙 2:3–4; 使徒の働き 1:8"> 私たちはこれらのことの証人です。また、神に従う人々に神が与えられた聖霊も証人です。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="使徒の働き 7:54; 使徒の働き 2:37; ルカ 4:28–29"> これを聞いた者たちは心を切り裂かれるように感じ、使徒たちを殺そうと決意しました。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒の働き 22:3; ルカ 2:46; ルカ 5:17"> ところが、民全体から尊敬されている律法の教師で、ガマリエルという名のパリサイ人が最高法院の中に立ち、使徒たちをしばらく外へ出すよう命じました。</span>
<span className="v" id="v35" data-v="35" data-xref="使徒の働き 22:26; エレミヤ書 26:19; マタイ 27:19"> そして彼らに言いました。「イスラエルの人たち。この者たちをどう扱おうとしているのか、よく注意しなさい。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒の働き 8:9; ペテロの第二の手紙 2:2; ガラテヤ人への手紙 6:3"> 以前、テウダが立ち上がって、自分を何者かであるように見せ、およそ四百人の男が彼に加わりました。しかし彼は殺され、従っていた者たちは皆散らされて、何も残りませんでした。</span>
<span className="v" id="v37" data-v="37" data-xref="ルカ 2:1–2; 詩篇 7:14–15; マタイ 26:52"> その後、住民登録のころにガリラヤのユダが立ち上がり、民の一部を引き連れて行きました。しかし彼も滅び、従っていた者たちは皆散らされました。</span>
<span className="v" id="v38" data-v="38" data-xref="マタイ 15:13; 哀歌 3:37; イザヤ書 8:9–10"> そこで今、あなたがたに言います。この者たちから手を引き、放っておきなさい。この計画や働きが人から出たものなら、打ち壊されるでしょう。</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 21:30; イザヤ書 46:10; マタイ 16:18"> しかし、それが神から出たものなら、あなたがたには打ち壊すことができません。それどころか、神に敵対して戦う者となりかねません。」</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="マタイ 10:17; 使徒の働き 5:28; 使徒の働き 4:17–21"> 彼らはガマリエルの意見に同意しました。使徒たちを呼び入れてむちで打ち、イエスの名によって語らないよう命じてから釈放しました。</span>
<span className="v" id="v41" data-v="41" data-xref="ヤコブの手紙 1:2; ペテロの手紙第一 4:13–16; ルカ 6:22"> 使徒たちは、イエスの名のために辱めを受けるに値する者とされたことを喜びながら、最高法院の前を立ち去りました。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="使徒の働き 2:46; 使徒の働き 20:20; ルカ 21:37"> そして毎日、神殿でも家々でも、イエスがキリストであると教え、福音を宣べ伝えることをやめませんでした。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 9:15; 箴言 1:24; 使徒の働き 26:2"> アグリッパはパウロに言いました。「自分の弁明をしてよい。」<br />そこでパウロは手を差し伸べ、弁明しました。</span>
<span className="v" id="v2" data-v="2"> 「アグリッパ王。ユダヤ人たちに訴えられているすべてのことについて、今日、王の前で弁明できることを幸いに思います。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 6:14; 使徒の働き 26:26; 使徒の働き 26:7"> とりわけ王は、ユダヤ人のあらゆる慣習や論争に精通しておられます。ですから、どうか忍耐をもって私の話をお聞きください。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ガラテヤ人への手紙 1:13; テモテへの第二の手紙 3:10; ピリピ人への手紙 3:5"> 私が若いころからどのように生活してきたかは、すべてのユダヤ人が知っています。初めから自分の国民の間で、またエルサレムで暮らしてきたからです。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 23:6; 使徒の働き 22:3; 使徒の働き 24:5"> 彼らは以前から私を知っており、証言する気があるなら、私が私たちの宗教で最も厳格な一派に従い、パリサイ人として生活していたことを証言できます。</span>
<span className="v" id="v6" data-v="6" data-xref="テトス 2:13; 使徒の働き 24:15; 使徒の働き 28:20"> 今、私がここに立って裁かれているのは、神が私たちの父祖に与えられた約束の望みのためです。</span>
<span className="v" id="v7" data-v="7" data-xref="ヤコブの手紙 1:1; ピリピ人への手紙 3:11; テモテへの手紙第一 5:5"> 私たちの十二部族は、夜も昼も熱心に神に仕えながら、その約束の実現にあずかることを望んでいます。王よ、私はこの望みのことでユダヤ人たちに訴えられているのです。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 15:12–20; 使徒の働き 4:2; 使徒の働き 17:31–32"> 神が死者を復活させられることを、なぜあなたがたは信じ難いと判断するのでしょうか。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="テモテへの手紙第一 1:13; 使徒の働き 22:8; ピリピ人への手紙 3:6"> 実際、私自身も、ナザレのイエスの名に逆らって多くのことをすべきだと、固く考えていました。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 8:3; 使徒の働き 9:13–14; 使徒の働き 9:21"> そして、エルサレムでそれを実行しました。祭司長たちから権限を受け、聖徒たちを大勢牢に入れ、彼らが死刑にされるときには賛成票を投じました。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 22:19; マタイ 10:17; 使徒の働き 13:45"> また、すべての会堂でたびたび彼らを罰し、神を冒瀆させようとしました。彼らに対して激しい怒りに駆られ、外国の町々にまで迫害の手を伸ばしました。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 26:10; 使徒の働き 22:5–11; 使徒の働き 9:1–8"> こうして私は祭司長たちから権限と委任を受け、ダマスコへ向かっていました。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイ 17:2; ヨハネの黙示録 21:23; ヨハネの黙示録 1:16"> 王よ、正午ごろ、その道中で、太陽よりも明るい光が天から私と同行者たちの周りを照らすのを見ました。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 21:40; 使徒の働き 22:2; 使徒の働き 9:7"> 私たちが皆地に倒れると、ヘブル語で私にこう言う声を聞きました。<span className="woj">『サウロ、サウロ、なぜ私を迫害するのか。突き棒を蹴るのは、あなたにはつらいことだ。』</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨハネ 15:20–21; マタイ 25:45; 出エジプト記 16:8"> 私は『主よ、あなたはどなたですか』と言いました。<br />主は言われました。<span className="woj">『私は、あなたが迫害しているイエスである。</span></span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 22:14–15; エゼキエル書 2:1; ダニエル書 10:11"> <span className="woj">しかし立ち上がって、自分の足で立ちなさい。私があなたに現れたのは、あなたが見たことと、これから私があなたに示すことについて、あなたをしもべ、また証人に任命するためである。</span></span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 9:15; テモテへの手紙第一 2:7; エレミヤ書 1:19"> <span className="woj">私はあなたを、この民と異邦人から救い出す。私があなたを彼らのもとへ遣わすのは、</span></span>
<span className="v" id="v18" data-v="18" data-xref="ペテロの手紙第一 2:9; エペソ人への手紙 1:18; エペソ人への手紙 5:8"> <span className="woj">彼らの目を開き、暗闇から光へ、サタンの支配から神へ立ち返らせるためである。それは彼らが罪の赦しを受け、私に対する信仰によって聖別された人々の中で、相続財産を受けるためである。』</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 50:5; ガラテヤ人への手紙 1:16; エゼキエル書 2:7–8"> ですからアグリッパ王、私は天からの幻に背きませんでした。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイ 3:8; 使徒の働き 3:19; 使徒の働き 2:38"> まずダマスコの人々に、次にエルサレム、さらにユダヤ全土の人々と異邦人に、悔い改めて神に立ち返り、悔い改めにふさわしい行いをするよう告げました。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 21:30–31; 使徒の働き 21:27; 使徒の働き 25:3"> そのため、ユダヤ人たちは神殿で私を捕らえ、殺そうとしました。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 24:14; ヨハネ 5:46; ローマ人への手紙 3:21"> しかし私は神からの助けを得て、今日まで立ち、小さな者にも大きな者にも証ししています。そして預言者たちとモーセが、これから起こると語ったこと以外は、何も話していません。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 53:1–12; ルカ 24:26; コロサイ人への手紙 1:18"> すなわち、キリストが苦しみを受け、死者の中から復活し、この民にも異邦人にも光を宣べ伝える最初の者となる、ということです。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="コリント人への第一の手紙 2:13–14; コリント人への第一の手紙 1:23; コリント人への第一の手紙 4:10"> パウロがこのように弁明していると、フェストは大声で言いました。「パウロ、おまえは気が狂っている。学問のしすぎで狂ってしまったのだ。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 23:26; テトス 1:9; テトス 2:7–8"> しかしパウロは言いました。「フェスト閣下、私は気が狂ってはいません。真実で筋の通った言葉を大胆に語っているのです。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 26:2–3; 使徒の働き 2:1–12; イザヤ書 30:20"> 王はこれらのことをご存じですので、私も王に率直に申し上げています。これらのことは一つも王に隠されていないと確信しています。片隅で行われたことではないからです。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 26:22–23"> アグリッパ王、預言者たちを信じておられますか。信じておられることを私は知っています。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="使徒の働き 11:26; マタイ 10:18; 使徒の働き 26:29"> アグリッパはパウロに言いました。「わずかな説得で、私をキリスト者にしようというのか。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="エペソ人への手紙 6:20; コロサイ人への手紙 1:28; ローマ人への手紙 10:1"> パウロは言いました。「わずかであろうと、多くであろうと、王だけでなく、今日、私の話を聞いているすべての方が、この鎖につながれることを除いて、私のようになってくださるよう神に祈ります。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 18:15; 使徒の働き 28:22; 使徒の働き 25:23"> 王は総督とベルニケ、および同席していた人々と共に立ち上がりました。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒の働き 23:29; 使徒の働き 23:9; 使徒の働き 28:18"> 彼らは退出すると、互いに話し合って言いました。「この男は、死刑や投獄に値することを何もしていない。」</span>
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 28:18; 使徒の働き 25:11–12; 使徒の働き 25:25"> アグリッパはフェストに言いました。「この男は、カエサルに上訴していなければ釈放できただろう。」</span>
</div>

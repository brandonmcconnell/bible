<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="ACT" data-book-slug="acts" data-book-name="使徒の働き" data-chapter="23" data-verses="35">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 24:16; テモテへの第二の手紙 1:3; コリント人への第二の手紙 1:12"> パウロは最高法院をじっと見つめて言いました。「兄弟たち。私は今日まで、あらゆる点で良心に恥じることなく、神の御前で生きてきました。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ヨハネ 18:22; 使徒の働き 24:1; ミカ書 5:1"> すると大祭司アナニアは、そばに立っている者たちに、パウロの口を打つよう命じました。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命記 25:1–2; ヨハネ 7:51; マタイ 23:27–28"> そこでパウロは彼に言いました。「白く塗った壁よ、神があなたを打たれる。あなたは律法に従って私を裁くために座っていながら、律法に反して私を打つよう命じるのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> そばに立っていた者たちは言いました。「神の大祭司を侮辱するのか。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 22:28; 伝道者の書 10:20; ユダ 1:8–9"> パウロは言いました。「兄弟たち、私はこの方が大祭司だとは知りませんでした。『あなたの民の支配者を悪く言ってはならない』と書かれているからです。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 24:15; 使徒の働き 24:21; 使徒の働き 26:5–8"> パウロは、一方がサドカイ人で、もう一方がパリサイ人であることに気づくと、最高法院で叫びました。「兄弟たち。私はパリサイ人で、パリサイ人の子です。私は死者の復活という望みのことで裁かれているのです。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="詩篇 55:9; ヨハネ 7:40–43; マタイ 10:34"> パウロがこう言うと、パリサイ人とサドカイ人の間に論争が起こり、集まった人々は二つに分かれました。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカ 20:27; マタイ 22:23; マルコ 12:18"> サドカイ人は、復活も天使も霊もないと言い、パリサイ人はそのすべてがあると認めているからです。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 22:7; 使徒の働き 22:17–18; ヨハネ 12:29"> 激しい叫び声が上がりました。パリサイ派の律法学者が何人か立って強く主張しました。「この男には何の悪も見つからない。もし霊か天使が彼に語ったのなら、神に逆らって戦うのはやめよう。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ヤコブの手紙 1:19; ヤコブの手紙 3:14–2; 使徒の働き 22:24"> 論争がさらに激しくなると、千人隊長はパウロが彼らに引き裂かれるのを恐れ、兵士たちに、下りて行って彼らの中からパウロを力ずくで取り出し、兵営へ連れて来るよう命じました。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 18:9; 使徒の働き 19:21; テモテへの第二の手紙 4:17"> その夜、主がパウロのそばに立って言われました。<span className="woj">「勇気を出しなさい、パウロ。あなたはエルサレムで私について証ししたように、ローマでも証ししなければならない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 23:30; イザヤ書 8:9–10; 使徒の働き 23:21"> 夜が明けると、ユダヤ人たちの一部が徒党を組み、パウロを殺すまでは何も食べず、何も飲まないと誓って、自分たちに呪いをかけました。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネ 16:2; サムエル記第二 15:31; サムエル記第二 15:12"> この陰謀に加わった者は四十人を超えていました。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 23:12; エレミヤ書 8:12; イザヤ書 3:9"> 彼らは祭司長たちと長老たちのところへ行って言いました。「われわれはパウロを殺すまでは何も口にしないと、厳しい呪いをかけて誓いました。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 59:7; 詩篇 37:32–33; 箴言 1:16"> そこで今、あなたがたは最高法院と共に、パウロの件をもっと詳しく調べるという口実で、明日、彼を自分たちのところへ連れて下るよう、千人隊長に申し入れてください。われわれは彼がここへ近づく前に殺す準備ができています。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 23:10; コリント人への第一の手紙 3:19; 使徒の働き 23:32"> しかし、パウロの姉妹の息子が待ち伏せのことを聞きつけ、兵営に入ってパウロに知らせました。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 22:3; マタイ 8:8–9; マタイ 10:16"> そこでパウロは百人隊長の一人を呼んで言いました。「この若者を千人隊長のところへ連れて行ってください。お伝えしたいことがあるそうです。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 3:1; エペソ人への手紙 4:1; 使徒の働き 28:17"> 百人隊長は彼を千人隊長のところへ連れて行って言いました。「囚人パウロが私を呼び、この若者をあなたのところへ連れて行ってほしいと頼みました。お伝えしたいことがあるそうです。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 31:32; エステル記 9:12; エステル記 7:2"> 千人隊長は若者の手を取り、人のいない所へ連れて行って、「私に伝えたいこととは何か」とひそかに尋ねました。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 23:14–15; 使徒の働き 23:1; 詩篇 12:2"> 若者は言いました。「ユダヤ人たちはパウロのことをもっと詳しく調べるふりをして、明日、彼を最高法院へ連れて下るよう、あなたに願い出ることで合意しています。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 23:12–14; 使徒の働き 14:5–6; コリント人への第二の手紙 11:26"> しかし、彼らの願いを聞き入れないでください。四十人を超える者たちが彼を待ち伏せしています。彼らはパウロを殺すまでは何も食べず、何も飲まないと誓い、自分たちに呪いをかけています。今は準備を整え、あなたの承諾を待っています。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="マルコ 1:44; ヨシュア記 2:14"> 千人隊長は「このことを私に知らせたと、だれにも言ってはならない」と若者に命じて帰しました。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="マタイ 14:25; 使徒の働き 23:33; ルカ 12:38"> それから百人隊長を二人呼んで言いました。「午後九時に、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="午後九時ごろ。">a</a></sup>カイサリアへ向けて出発できるよう、兵士二百人、騎兵七十人、槍兵二百人を用意しなさい。」</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 25:14; 使徒の働き 23:26; 使徒の働き 24:10"> また、パウロを乗せて総督フェリクスのもとへ無事に送り届けるため、馬も用意するよう命じました。</span>
<span className="v" id="v25" data-v="25"> そして、次のような手紙を書きました。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 15:23; 使徒の働き 26:25; ルカ 1:3"> 「クラウディオ・リシアから、フェリクス閣下へ。ごあいさつ申し上げます。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 22:25–29; 使徒の働き 21:31–33; 使徒の働き 24:6"> この男がユダヤ人たちに捕らえられ、殺されようとしていたところ、彼がローマ市民であると知ったので、私は兵士を率いて行って救出しました。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒の働き 22:30"> また、彼らがこの男を訴えた理由を知りたいと思い、彼らの最高法院へ連れて下りました。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 26:31; 使徒の働き 25:25; 使徒の働き 18:15"> すると、彼らの律法に関する問題で訴えられているだけで、死刑や投獄に値する罪には問われていないことが分かりました。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 23:35; 使徒の働き 25:16; 使徒の働き 25:5–6"> しかし、この男に対するユダヤ人たちの待ち伏せがあると知らされたので、ただちにあなたのもとへ送りました。また、訴える者たちには、彼に対する告発をあなたの前で申し立てるよう命じてあります。お元気で。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="テモテへの第二の手紙 2:3–4; ルカ 7:8; 使徒の働き 23:23–24"> そこで兵士たちは命令どおりパウロを引き取り、夜のうちにアンティパトリスまで連れて行きました。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 23:23; 使徒の働き 23:10"> 翌日、騎兵たちにパウロの護送を任せ、自分たちは兵営へ帰りました。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒の働き 23:26; 使徒の働き 23:23–24; 使徒の働き 28:16"> 騎兵たちはカイサリアに着くと、総督に手紙を渡し、パウロも引き渡しました。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒の働き 21:39; 使徒の働き 25:1; ダニエル書 2:49"> 総督は手紙を読むと、パウロがどの属州の出身かと尋ねました。キリキア出身だと分かると、</span>
<span className="v" id="v35" data-v="35" data-xref="使徒の働き 23:30; 使徒の働き 25:16; マタイ 27:27"> 「おまえを訴える者たちも到着したら、詳しく事情を聞こう」と言い、ヘロデの官邸で監禁するよう命じました。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 27:1; マタイ 8:5–13; マタイ 27:27"> さて、カイサリアにコルネリオという人がいました。「イタリア隊」と呼ばれる部隊の百人隊長で、</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 7:7–8; 使徒の働き 10:4; 使徒の働き 10:22"> 敬虔な人でした。家族全員と共に神を恐れ、民に惜しみなく施しをし、いつも神に祈っていました。</span>
<span className="v" id="v3" data-v="3" data-xref="ダニエル書 9:20–21; 使徒の働き 3:1; 使徒の働き 5:19"> ある日の午後三時ごろ、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="午後三時。">a</a></sup>幻の中で、神の使いが自分のところに来て、「コルネリオ」と言うのをはっきり見ました。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ピリピ人への手紙 4:6; ヘブル人への手紙 6:10; 使徒の働き 10:31"> 彼はその使いをじっと見つめ、恐ろしくなって言いました。「主よ、何でしょうか。」<br />使いは言いました。「あなたの祈りと施しは神の御前に上り、覚えられています。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 16:9; 使徒の働き 9:38; 使徒の働き 15:7"> さあ、ヨッパへ人を遣わし、ペテロとも呼ばれるシモンを招きなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 9:43; 使徒の働き 11:13–14; ローマ人への手紙 10:14–17"> 彼は、海辺に家を持つ皮なめし職人シモンのところに滞在しています。」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TRは「この人が、あなたのなすべきことを告げる」を加えている。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="フィレモンへの手紙 1:16; サムエル記第一 14:6–7; マタイ 8:9–10"> 語りかけた使いが去ると、コルネリオは家のしもべ二人と、いつも身近に仕えている敬虔な兵士一人を呼び、</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 9:36; 詩篇 119:59–60; 使徒の働き 10:33"> すべてを説明してからヨッパへ遣わしました。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ゼパニヤ書 1:5; 詩篇 55:17; サムエル記第一 9:25"> 翌日、彼らが旅を続けて町に近づいたころ、ペテロは正午ごろ祈るために屋上へ上りました。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 22:17; ヨハネの黙示録 4:2–3; コリント人への第二の手紙 12:2–4"> 彼は空腹になり、何か食べたいと思いました。人々が食事を用意している間に、恍惚状態に入りました。</span>
<span className="v" id="v11" data-v="11" data-xref="エペソ人への手紙 3:6; ヨハネ 1:51; ローマ人への手紙 16:25–26"> そして天が開き、大きな布のようなものが四隅をつるされて地上に降りて来るのを見ました。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 7:8–9; ヨハネ 7:37; コリント人への第一の手紙 6:9–11"> その中には、地上のあらゆる種類の四つ足の動物、野獣、地をはう生き物、空の鳥が入っていました。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネ 4:31–34; エレミヤ書 35:2–5; 使徒の働き 10:10"> すると声が聞こえました。<span className="woj">「ペテロ、立ちなさい。ほふって食べなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="レビ記 20:25; エゼキエル書 4:14; ダニエル書 1:8"> しかしペテロは言いました。「主よ、とんでもありません。私は清くない物や汚れた物を一度も食べたことがありません。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 10:25; マタイ 15:11; テトス 1:15"> すると二度目に、また声が聞こえました。<span className="woj">「神が清めた物を、汚れていると言ってはならない。」</span></span>
<span className="v" id="v16" data-v="16" data-xref="創世記 41:32; ヨハネ 21:17; コリント人への第二の手紙 13:1"> このことが三度あり、それはすぐに天へ引き上げられました。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヨハネ 13:12; 使徒の働き 10:7–19; 使徒の働き 5:24"> ペテロが、見た幻にはどんな意味があるのかと、ひどく思い悩んでいると、見よ、コルネリオから遣わされた人々がシモンの家を尋ね当て、門の前に立って、</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 10:5–6; 使徒の働き 11:11"> 声をかけ、ペテロとも呼ばれるシモンがここに泊まっているかと尋ねました。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 8:29; 使徒の働き 11:12; 使徒の働き 21:4"> ペテロが幻について考え続けていると、霊が彼に言いました。「見よ、三人の<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="TRとNUによる。MTは「三人の」を省いている。">c</a></sup>男があなたを捜している。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 15:7–9; ゼカリヤ書 2:9–11; イザヤ書 48:16"> さあ、立って下へ降りなさい。ためらわずに彼らと一緒に行きなさい。私が彼らを遣わしたからである。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ヨハネ 1:38–39; マルコ 10:51; 使徒の働き 10:29"> そこでペテロは男たちのところへ降りて行って言いました。「見よ、あなたがたが捜しているのは私です。何のために来たのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 11:14; 使徒の働き 10:2; 使徒の働き 22:12"> 彼らは答えました。「百人隊長コルネリオは正しい人で神を恐れ、ユダヤ人の国民全体から評判の良い人です。あなたを家に招いて、あなたの話を聞くようにと、聖なる天使から指示を受けました。」</span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 10:45; 使徒の働き 11:12; ペテロの手紙第一 4:9"> そこでペテロは彼らを中に招き入れ、泊めました。<br />翌日、ペテロは立って彼らと一緒に出発し、ヨッパの兄弟たちも何人か同行しました。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 8:40; ゼカリヤ書 8:20–23; ゼカリヤ書 3:10"> その翌日、一行はカイサリアに入りました。コルネリオは親族や親しい友人たちを呼び集め、彼らを待っていました。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの黙示録 19:10; ヨハネの黙示録 22:8–9; ダニエル書 2:46"> ペテロが入って来ると、コルネリオは迎えに出て、その足もとにひれ伏して拝みました。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの黙示録 19:10; ヨハネの黙示録 22:8–9; 使徒の働き 14:14–15"> しかしペテロは彼を起こして言いました。「立ってください。私自身も人間です。」</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への第二の手紙 2:12; ヨハネ 4:35; 使徒の働き 10:24"> そしてコルネリオと話しながら中に入ると、大勢の人が集まっているのを見ました。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネ 4:9; エペソ人への手紙 3:6–7; ガラテヤ人への手紙 2:12–14"> ペテロは彼らに言いました。「ユダヤ人が異邦人と交わったり、訪ねたりすることが律法に反するのは、あなたがたも知っています。しかし神は私に、どんな人も清くない者や汚れた者と呼んではならないことを示されました。</span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 119:60; ペテロの手紙第一 3:15; 使徒の働き 10:19–20"> それで、呼ばれたときも異議を唱えずに来ました。そこで伺いますが、どういう理由で私を呼んだのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 10:3; ダニエル書 9:20–21; ネヘミヤ記 9:1–3"> コルネリオは言いました。「四日前、私は今の時刻まで断食し、午後三時に<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="午後三時。">d</a></sup>家で祈っていました。すると見よ、輝く衣を着た人が私の前に立ち、</span>
<span className="v" id="v31" data-v="31" data-xref="使徒の働き 10:4; ダニエル書 9:23; ルカ 1:13"> 言いました。『コルネリオ。あなたの祈りは聞かれ、施しは神の御前で覚えられている。</span>
<span className="v" id="v32" data-v="32"> だからヨッパへ人を遣わし、ペテロとも呼ばれるシモンを招きなさい。彼は海辺にある皮なめし職人シモンの家に泊まっている。彼が来れば、あなたに語るだろう。』</span>
<span className="v" id="v33" data-v="33" data-xref="ヤコブの手紙 1:19; ガラテヤ人への手紙 4:14; 歴代誌 第二 30:12"> それですぐに、あなたをお招きしました。よく来てくださいました。今、私たちは皆、神があなたに命じられたことをすべて聞くため、神の御前に集まっています。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ローマ人への手紙 2:11; 歴代誌 第二 19:7; 申命記 10:17"> そこでペテロは口を開いて言いました。「今、はっきり分かりました。神はえこひいきをなさいません。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの手紙第一 2:29; 使徒の働き 10:2; ローマ人への手紙 10:12–13"> どの国民の中でも、神を恐れて義を行う人は、神に受け入れられるのです。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイ 28:18; 使徒の働き 2:36; ヨハネの黙示録 17:14"> 神はイスラエルの子らに御言葉を送り、イエス・キリストによる平和の福音を宣べ伝えられました。この方はすべての人の主です。</span>
<span className="v" id="v37" data-v="37" data-xref="ルカ 4:14; 使徒の働き 2:22; 使徒の働き 28:22"> ヨハネが宣べ伝えたバプテスマの後、ガリラヤから始まってユダヤ全土に告げ知らされた出来事を、あなたがた自身も知っています。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカ 4:18; 使徒の働き 2:22; イザヤ書 61:1–3"> それは、神がナザレのイエスに聖霊と力を注がれたことです。神がこの方と共におられたので、イエスは巡り歩いて良いことを行い、悪魔に虐げられていた人々をすべて癒やされました。</span>
<span className="v" id="v39" data-v="39" data-xref="ルカ 24:48; 使徒の働き 1:8; 使徒の働き 10:41"> 私たちは、イエスがユダヤ人の地方とエルサレムで行われたすべてのことの証人です。人々はこの方を木にかけて<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="TRは「も」を省いている。">e</a></sup>殺しました。</span>
<span className="v" id="v40" data-v="40" data-xref="ペテロの手紙第一 1:21; 使徒の働き 13:30–31; コリント人への第一の手紙 15:3–4"> しかし神は三日目にこの方を復活させ、人々の前に現れるようにされました。</span>
<span className="v" id="v41" data-v="41" data-xref="ヨハネ 14:22; 使徒の働き 10:39; ヨハネ 21:13"> ただし、民全体にではなく、神によってあらかじめ選ばれた証人たち、すなわち、イエスが死者の中から復活された後、この方と共に食べたり飲んだりした私たちに現れるようにされたのです。</span>
<span className="v" id="v42" data-v="42" data-xref="コリント人への第二の手紙 5:10; テモテへの第二の手紙 4:1; ペテロの手紙第一 4:5"> そしてイエスは、この方こそ神が生きている者と死んだ者の裁判官として定められた方だと、民に宣べ伝え、証しするよう私たちに命じられました。</span>
<span className="v" id="v43" data-v="43" data-xref="ゼカリヤ書 13:1; 使徒の働き 2:38; イザヤ書 53:11"> すべての預言者もこの方について、この方を信じる者はだれでも、その名によって罪の赦しを受けると証ししています。」</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="使徒の働き 11:15; 使徒の働き 19:6; 使徒の働き 15:8"> ペテロがまだこの言葉を話しているうちに、御言葉を聞いていたすべての人に聖霊が臨みました。</span>
<span className="v" id="v45" data-v="45" data-xref="使徒の働き 10:23; 使徒の働き 2:38; ガラテヤ人への手紙 3:13–14"> ペテロと一緒に来た割礼を受けた信者たちは、聖霊の賜物が異邦人にも注がれたことに驚きました。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒の働き 19:6; 使徒の働き 2:4; マルコ 16:17"> 彼らがほかの言語で話し、神をあがめるのを聞いたからです。<br />そこでペテロは言いました。</span>
<span className="v" id="v47" data-v="47" data-xref="使徒の働き 8:36; ローマ人への手紙 10:12; 使徒の働き 11:15–17"> 「私たちと同じように聖霊を受けたこの人たちが、水でバプテスマを受けるのを、だれが禁じることができるでしょうか。」</span>
<span className="v" id="v48" data-v="48" data-xref="使徒の働き 2:38; 使徒の働き 8:16; ガラテヤ人への手紙 3:27"> そして彼らに、イエス・キリストの名によってバプテスマを受けるよう命じました。それから人々はペテロに、数日滞在するよう頼みました。</span>
</div>

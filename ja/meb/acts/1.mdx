<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカ 1:3; ルカ 24:19; マタイ 4:23–24"> テオフィロよ。私は先の書で、イエスが行い、また教え始められたすべてのことを記しました。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 1:9; ヨハネ 20:21; イザヤ書 59:20–21"> それは、イエスが選ばれた使徒たちに聖霊によって命じた後、天に上げられた日までのことです。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第一の手紙 15:5–7; 使徒の働き 13:31; ヨハネ 20:26"> イエスは苦しみを受けた後、数多くの確かな証拠によって、ご自分が生きていることを使徒たちに示されました。四十日にわたって彼らに現れ、神の国について語られたのです。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカ 24:49; ヨハネ 14:16; ヨハネ 15:26"> イエスは彼らと集まっていたとき、こう命じられました。<span className="woj">「エルサレムを離れず、あなたがたが私から聞いた父の約束を待ちなさい。</span></span>
<span className="v" id="v5" data-v="5" data-xref="マタイ 3:11; 使徒の働き 11:15–16; ルカ 3:16"> <span className="woj">ヨハネは水でバプテスマを授けましたが、あなたがたは間もなく聖霊によってバプテスマを授けられます。」</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ルカ 19:11; ルカ 17:20; ダニエル書 7:27"> そこで、一緒に集まった人々はイエスに尋ねました。「主よ、今こそイスラエルに王国を回復なさるのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マタイ 24:36; テサロニケ人への手紙第一 5:1–2; マルコ 13:32"> イエスは彼らに言われました。<span className="woj">「父がご自分の権威によって定められた時や時期は、あなたがたの知るべきことではありません。</span></span>
<span className="v" id="v8" data-v="8" data-xref="マタイ 28:19; マルコ 16:15; ローマ人への手紙 15:19"> <span className="woj">しかし、聖霊があなたがたの上に臨むとき、あなたがたは力を受けます。そしてエルサレム、ユダヤとサマリアの全土、さらに地の果てにまで、私の証人となります。」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ダニエル書 7:13; ルカ 24:50–51; マルコ 16:19"> こう言われると、彼らが見ているうちにイエスは上げられ、雲に包まれて見えなくなりました。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカ 24:4; ヨハネ 20:12; ヨハネの黙示録 7:14"> イエスが上って行かれる間、彼らがじっと空を見つめていると、見よ、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「見よ」と訳された「ἰδοὺ」には、見る、注意を向ける、よく観察する、目を留めるという意味がある。しばしば間投詞として用いられる。">a</a></sup>白い衣を着た二人の人が彼らのそばに立ち、</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 1:7; テサロニケ人への手紙第一 4:16; マルコ 13:26"> 言いました。「ガリラヤの人たち、なぜ立ったまま空を見つめているのですか。あなたがたを離れて天に上げられたこのイエスは、天に上って行くのをあなたがたが見たのと同じ有様で、再び来られます。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ルカ 24:52; マタイ 21:1; ルカ 24:50"> それから彼らは、オリーブ山と呼ばれる山からエルサレムに帰りました。その山はエルサレムに近く、安息日に歩くことが許される距離にありました。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 20:8; ルカ 22:12; マルコ 14:15"> 町に入ると、彼らは滞在していた階上の部屋に上がりました。そこにいたのは、ペテロ、ヨハネ、ヤコブ、アンデレ、ピリポ、トマス、バルトロマイ、マタイ、アルパヨの子ヤコブ、熱心党のシモン、ヤコブの子ユダでした。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 6:4; エペソ人への手紙 6:18; コロサイ人への手紙 4:2"> 彼らは皆、女たちやイエスの母マリア、イエスの兄弟たちと心を一つにし、ひたすら祈りと願いをささげていました。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 15:6; 使徒の働き 21:20; ヨハネの黙示録 3:4"> そのころ、ペテロは弟子たちの中に立って言いました。集まっていた人々はおよそ百二十人でした。</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 41:9; ヨハネ 13:18; 詩篇 55:12–15"> 「兄弟たち。イエスを捕らえた者たちの手引きをしたユダについて、聖霊がダビデの口を通して前もって語られた聖書の言葉は、成就しなければなりませんでした。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 1:25; マルコ 3:19; ヨハネ 17:12"> ユダは私たちの一人に数えられ、この務めを分け与えられていたからです。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイ 27:3–10; マタイ 26:14–15; 詩篇 55:23"> ところが、この男は不正の報酬で土地を手に入れ、真っ逆さまに落ちて体が裂け、はらわたがすべて流れ出ました。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 2:22; マタイ 28:15; 使徒の働き 21:40"> このことはエルサレムの住民全体に知れ渡り、その土地は彼らの言葉で『アケルダマ』、すなわち『血の土地』と呼ばれるようになりました。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 69:25; 詩篇 109:8–15; 使徒の働き 1:25"> 詩篇にこう書かれています。<br /><span className="pl pl-1">『彼の住まいは荒れ果て、</span><br /><span className="pl pl-2">そこに住む者がいなくなるように。』</span><br />また、<br /><span className="pl pl-1">『その職をほかの者に引き継がせよ。』</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ヨハネ 15:27; ルカ 10:1–2; 民数記 27:17"> ですから、主イエスが私たちの間を行き来された間、いつも私たちと行動を共にしていた人たち、</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 1:2; 使徒の働き 4:33; 使徒の働き 1:8–9"> すなわち、ヨハネのバプテスマの時から、イエスが私たちを離れて天に上げられた日まで共にいた人たちの中から、だれか一人が私たちと共にイエスの復活の証人とならなければなりません。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 15:22; 使徒の働き 1:26"> そこで人々は、バルサバと呼ばれ、ユストとも呼ばれていたヨセフと、マッティアの二人を立てました。</span>
<span className="v" id="v24" data-v="24" data-xref="サムエル記第一 16:7; 使徒の働き 15:8; ヘブル人への手紙 4:13"> そして祈って言いました。「すべての人の心をご存じである主よ、この二人のうち、あなたがどちらを選ばれたかをお示しください。</span>
<span className="v" id="v25" data-v="25" data-xref="コリント人への第一の手紙 9:2; ヨハネ 6:70–71; ヨハネ 17:12"> ユダが自分の行くべき所へ行くために離れた、この務めと使徒職を引き継ぐ者をお示しください。」</span>
<span className="v" id="v26" data-v="26" data-xref="レビ記 16:8; ヨシュア記 18:10; サムエル記第一 14:41–42"> それから二人のためにくじを引くと、くじはマッティアに当たりました。こうして彼は十一人の使徒に加えられました。</span>
</div>
</div>

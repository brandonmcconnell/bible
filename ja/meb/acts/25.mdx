<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 23:34; 使徒の働き 25:5; 使徒の働き 8:40"> さてフェストは州に着任して三日後、カイサリアからエルサレムへ上りました。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 25:15; 箴言 4:16; 使徒の働き 24:1"> すると大祭司とユダヤ人の主だった人々がパウロを訴え、フェストに願い出ました。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 9:24; 使徒の働き 23:12–15; サムエル記第一 23:19–21"> 彼らはパウロを途中で殺そうとたくらみ、自分たちへの好意として、彼をエルサレムへ呼び出してほしいと求めたのです。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 24:23"> しかしフェストは、パウロをカイサリアで拘留しておくべきであり、自分も間もなくそこへ出発すると答えました。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 25:25; ヨハネ 18:29–30; 使徒の働き 25:18–19"> そして言いました。「だから、あなたがたの中で権限のある者たちが私と一緒に下り、あの男に何か不正があるなら、彼を訴えなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 25:17; 使徒の働き 25:10; マタイ 27:19"> フェストは彼らの間に十日以上滞在してからカイサリアへ下り、翌日、裁判の席に着いて、パウロを連れて来るよう命じました。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 24:13; ルカ 23:10; 使徒の働き 25:24"> パウロが入って来ると、エルサレムから下って来たユダヤ人たちが彼を取り囲み、数多くの重大な罪を訴えましたが、それを証明することはできませんでした。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 24:12; 使徒の働き 28:17; コリント人への第二の手紙 1:12"> パウロは弁明して言いました。「私はユダヤ人の律法にも、神殿にも、カエサルにも、何一つ罪を犯していません。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 24:27; 使徒の働き 12:3; 使徒の働き 25:20"> しかしフェストは、ユダヤ人たちの好意を得ようとして、パウロに尋ねました。「おまえはエルサレムへ上り、これらの件について、そこで私の裁判を受けたいか。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="マタイ 27:18; コリント人への第二の手紙 4:2; 使徒の働き 28:18"> しかしパウロは言いました。「私はカエサルの裁判の席の前に立っています。ここで裁判を受けるべきです。閣下もよくご存じのとおり、私はユダヤ人に何の悪事も働いていません。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 28:19; 使徒の働き 26:32; 使徒の働き 25:25"> もし私が悪を行い、死刑に値することをしたのなら、死を拒むつもりはありません。しかし、彼らが私を訴えていることに何の真実もないのなら、だれも私を彼らに引き渡すことはできません。私はカエサルに上訴します。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 19:21; ピリピ人への手紙 1:12–14; ピリピ人への手紙 1:20"> そこでフェストは陪席者たちと相談したうえで答えました。「おまえはカエサルに上訴した。カエサルのもとへ行くことになる。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 8:40; 使徒の働き 26:1; 使徒の働き 26:27–28"> 何日かたって、アグリッパ王とベルニケがカイサリアに到着し、フェストを表敬訪問しました。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 24:27"> 二人がそこに何日も滞在していたので、フェストはパウロの件を王に説明して言いました。「フェリクスが囚人のまま残していった男が一人います。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 25:1–3; エステル記 3:9; ルカ 18:3–5"> 私がエルサレムにいたとき、祭司長たちとユダヤ人の長老たちがこの男を訴え、有罪判決を下すよう求めました。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネ 7:51; 申命記 19:17–18; 使徒の働き 23:30"> しかし私は、訴えられた者が訴えた者たちと面と向かい、告発された件について弁明する機会を得る前に、処罰のために引き渡すのはローマ人の慣習ではないと答えました。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 25:6; 使徒の働き 25:10"> そこで彼らがここに集まったとき、私は遅らせることなく、翌日には裁判の席に着き、その男を連れて来るよう命じました。</span>
<span className="v" id="v18" data-v="18"> 訴える者たちは立ち上がりましたが、私が予想していたような悪事は何一つ告発しませんでした。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 23:29; 使徒の働き 18:15; コリント人への第一の手紙 15:3–4"> ただ、自分たちの宗教と、死んだのにパウロが生きていると主張する、イエスという人物について、いくつかの論争があるだけでした。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 25:9"> 私はこのような問題をどう調べればよいか分からなかったので、エルサレムへ行き、そこでこれらの件について裁判を受けたいかと尋ねました。</span>
<span className="v" id="v21" data-v="21" data-xref="テモテへの第二の手紙 4:16; ルカ 2:1; 使徒の働き 25:10–11"> ところがパウロが皇帝の裁定を受けるために拘留しておくよう上訴したので、カエサルのもとへ送るまで拘留しておくよう命じました。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 9:15; マタイ 10:18; イザヤ書 52:15"> アグリッパはフェストに言いました。「私も自分で、その男の話を聞いてみたい。」<br />フェストは「明日、お聞きになれます」と答えました。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 26:30; 使徒の働き 25:13; ヨハネの手紙第一 2:16"> 翌日、アグリッパとベルニケは盛大な威儀を整えてやって来て、千人隊長たちや町の主だった人々と共に謁見の間へ入りました。そしてフェストの命令によって、パウロが連れて来られました。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 22:22; 使徒の働き 25:7; 使徒の働き 25:2–3"> フェストは言いました。「アグリッパ王、ならびにご同席の皆さん。この男をご覧ください。エルサレムでもここでも、ユダヤ人の群衆全体が私に訴え、もう生かしておくべきではないと叫んだ人物です。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 23:29; 使徒の働き 25:11–12; ルカ 23:4"> しかし私は、彼が死刑に値することを何もしていないと分かりました。また、彼自身が皇帝に上訴したので、彼を送ることに決めました。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 26:2–3"> ところが、この男について皇帝陛下に書き送る確かなことが何もありません。そのため、取り調べた後で何か書き送るべき内容を得るため、彼を皆さんの前、とりわけアグリッパ王よ、あなたの前に連れ出しました。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネ 7:51; 箴言 18:13"> 囚人を送るのに、その告発内容も示さないのは、不合理なことに思えるからです。」</span>
</div>

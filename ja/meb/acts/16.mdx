<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テモテへの第二の手紙 1:5; テモテへの第二の手紙 1:2; コリント人への第一の手紙 4:17"> パウロはデルベとリステラへも行きました。すると見よ、そこにテモテという弟子がいました。信者であるユダヤ人女性の息子で、父親はギリシャ人でした。</span>
<span className="v" id="v2" data-v="2" data-xref="テモテへの手紙第一 5:10; テモテへの第二の手紙 3:15; 使徒の働き 14:21"> 彼はリステラとイコニオムの兄弟たちから評判の良い人でした。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 2:3; コリント人への第一の手紙 9:20; ガラテヤ人への手紙 5:6"> パウロはテモテを連れて行きたいと思い、その地方にいるユダヤ人たちのために、彼に割礼を施しました。彼の父親がギリシャ人であることを、皆が知っていたからです。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 15:28–29; 使徒の働き 15:2; 使徒の働き 11:30"> 一行は町々を巡りながら、エルサレムの使徒たちと長老たちが定めた規定を守るよう、人々に伝えました。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 9:31; 使徒の働き 2:47; 使徒の働き 6:7"> こうして諸教会は信仰において強められ、日ごとに人数を増していきました。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 18:23; 使徒の働き 16:7; 使徒の働き 13:2–4"> 一行はフリギアとガラテヤ地方を通りましたが、アジアで御言葉を語ることを聖霊に禁じられました。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 8:9; ピリピ人への手紙 1:19; ガラテヤ人への手紙 4:6"> ミシアの近くまで来ると、ビティニアへ行こうとしましたが、霊がそれを許しませんでした。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第二の手紙 2:12; テモテへの第二の手紙 4:13; 使徒の働き 16:11"> そこでミシアを通り過ぎて、トロアスへ下りました。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 9:10–12; 使徒の働き 19:21; 使徒の働き 18:5"> 夜、パウロは幻を見ました。マケドニア人の男が立って、「マケドニアへ渡って来て、私たちを助けてください」と懇願していました。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第二の手紙 2:12–13; 使徒の働き 14:7; 使徒の働き 16:10–17"> パウロがこの幻を見ると、私たちはすぐにマケドニアへ出発しようとしました。彼らに福音を宣べ伝えるため、主が私たちを召されたのだと判断したからです。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 21:1; 使徒の働き 16:8"> こうしてトロアスから船出し、サモトラケへ直航し、翌日はネアポリスへ行きました。</span>
<span className="v" id="v12" data-v="12" data-xref="テサロニケ人への手紙第一 2:2; ピリピ人への手紙 1:1; 使徒の働き 20:6"> そこから、この地域の主要都市でローマの植民都市である、マケドニアの町ピリピへ行きました。私たちはこの町に数日滞在しました。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 13:14; コロサイ人への手紙 1:23; 使徒の働き 17:2"> 安息日に、私たちは祈り場があると思われる町の門の外の川岸へ行きました。そして腰を下ろし、集まって来た女たちに話しました。</span>
<span className="v" id="v14" data-v="14" data-xref="エペソ人への手紙 1:17–18; ルカ 24:45; イザヤ書 50:5"> ティアティラの町の紫布商人で、神を礼拝するリディアという女が話を聞いていました。主は彼女の心を開き、パウロの語ることに耳を傾けさせました。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 11:14; ヘブル人への手紙 13:2; 使徒の働き 16:33"> 彼女とその家の者たちがバプテスマを受けると、彼女は私たちに懇願しました。「私が主に忠実な者だとお考えでしたら、私の家に来て泊まってください。」こうして私たちは、彼女の願いを受け入れました。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="レビ記 19:31; 申命記 18:9–11; イザヤ書 8:19"> あるとき、私たちが祈り場へ行く途中、占いの霊につかれた女奴隷に出会いました。彼女は占いによって主人たちに多くの利益を得させていました。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネ 14:6; ペテロの手紙第一 2:16; マルコ 5:7"> 彼女はパウロと私たちの後について来て、こう叫び続けました。「この人たちは、いと高き神のしもべで、私たちに救いの道を宣べ伝えています。」</span>
<span className="v" id="v18" data-v="18" data-xref="マルコ 16:17; ルカ 10:17–19; 使徒の働き 3:6"> 彼女は何日も同じことを続けました。<br />しかしパウロはひどく困り、振り向いてその霊に言いました。「イエス・キリストの名によって命じる。この女から出て行け。」すると霊は、ただちに出て行きました。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 17:6; 使徒の働き 21:30; 使徒の働き 8:3"> 彼女の主人たちは、利益を得る望みがなくなったことに気づくと、パウロとシラスを捕らえ、広場にいる役人たちのところへ引きずって行きました。</span>
<span className="v" id="v20" data-v="20" data-xref="ヤコブの手紙 4:4; ヨハネ 15:18–20; 使徒の働き 28:22"> そして二人を長官たちの前に連れて行って言いました。「この者たちはユダヤ人で、われわれの町を騒がせ、</span>
<span className="v" id="v21" data-v="21" data-xref="エステル記 3:8; 使徒の働き 26:3; エレミヤ書 10:3"> ローマ人であるわれわれが受け入れることも実行することも許されない慣習を広めています。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="テサロニケ人への手紙第一 2:2; コリント人への第二の手紙 6:5; コリント人への第二の手紙 11:23–25"> 群衆も一緒になって二人に襲いかかりました。長官たちは二人の衣をはぎ取り、棒で打つよう命じました。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの黙示録 2:10; テモテへの第二の手紙 2:9; サムエル記第一 23:22–23"> そして何度も打たせてから牢に入れ、厳重に見張るよう看守に命じました。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨブ記 13:27; ヨブ記 33:11; エレミヤ書 29:26"> 看守はこの命令を受け、二人を奥の牢に入れ、両足を足かせにしっかり固定しました。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="テサロニケ人への手紙第一 5:16–18; 詩篇 119:62; ヤコブの手紙 1:2"> 真夜中ごろ、パウロとシラスは祈りながら神を賛美する歌を歌っており、囚人たちはそれに聞き入っていました。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 4:31; 使徒の働き 5:19; 使徒の働き 12:10"> すると突然、大地震が起こり、牢の土台が揺れ動きました。たちまちすべての戸が開き、全員の鎖が解けました。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 12:19; マタイ 27:5; 士師記 9:54"> 看守は眠りから覚め、牢の戸が開いているのを見ると、囚人たちが逃げたものと思い、剣を抜いて自害しようとしました。</span>
<span className="v" id="v28" data-v="28" data-xref="テサロニケ人への手紙第一 5:15; ルカ 23:34; ルカ 6:27–28"> しかしパウロは大声で叫びました。「自分を傷つけてはいけない。私たちは皆ここにいる。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ヨハネの黙示録 3:9; 使徒の働き 24:25; イザヤ書 60:14"> 看守は明かりを持って来させ、牢の中へ駆け込み、震えながらパウロとシラスの前にひれ伏しました。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 2:37; ヨハネ 6:27–29; イザヤ書 58:9"> そして二人を外へ連れ出して言いました。「先生方、救われるためには何をしなければなりませんか。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ヨハネ 1:12; 使徒の働き 2:38–39; ヨハネ 3:36"> 二人は言いました。「主イエス・キリストを信じなさい。そうすれば、あなたもあなたの家族も救われます。」</span>
<span className="v" id="v32" data-v="32" data-xref="ローマ人への手紙 1:16; コロサイ人への手紙 1:27–28; テモテへの手紙第一 1:13–16"> そして彼と、その家にいた全員に主の言葉を語りました。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="コリント人への第一の手紙 1:16; 使徒の働き 16:15; 使徒の働き 16:25"> 看守はその夜、同じ時刻に二人を引き取り、その傷を洗いました。そして彼も家の者も全員、すぐにバプテスマを受けました。</span>
<span className="v" id="v34" data-v="34" data-xref="ローマ人への手紙 15:13; 使徒の働き 2:46; ローマ人への手紙 5:11"> それから二人を自分の家に案内して食事を出し、家族全員と共に神を信じたことを心から喜びました。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="エレミヤ書 5:22; 詩篇 76:10; 使徒の働き 5:40"> 夜が明けると、長官たちは警吏を遣わし、「あの者たちを釈放せよ」と伝えました。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒の働き 15:33; ヨハネ 14:27; サムエル記第一 1:17"> 看守はその言葉をパウロに伝えました。「長官たちが、あなたがたを釈放するよう人をよこしました。ですから、出て来て、安心してお帰りください。」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒の働き 22:25–29; 詩篇 58:1–2; マタイ 10:16"> しかしパウロは警吏たちに言いました。「長官たちは、ローマ市民である私たちを裁判にもかけず、公衆の面前で打って牢に入れた。それなのに今、ひそかに私たちを釈放するのか。いや、断じてそうはさせない。彼ら自身がここへ来て、私たちを連れ出すべきだ。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="使徒の働き 22:29; マタイ 21:46; マタイ 14:5"> 警吏たちはこの言葉を長官たちに報告しました。長官たちは、二人がローマ市民だと聞いて恐れ、</span>
<span className="v" id="v39" data-v="39" data-xref="マタイ 8:34; マルコ 5:17; ダニエル書 6:23"> 自ら来て二人に謝りました。そして牢から連れ出し、町から去ってほしいと頼みました。</span>
<span className="v" id="v40" data-v="40" data-xref="テサロニケ人への手紙第一 3:2–3; 使徒の働き 16:14; 使徒の働き 14:22"> 二人は牢を出てリディアの家へ行き、兄弟たちに会って励ました後、そこを出発しました。</span>
</div>
</div>

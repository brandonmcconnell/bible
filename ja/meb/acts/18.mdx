<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第一の手紙 1:2; テモテへの第二の手紙 4:20; コリント人への第二の手紙 1:1"> その後、パウロはアテネを去ってコリントへ行きました。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 16:3–4; コリント人への第一の手紙 16:19; テモテへの第二の手紙 4:19"> そこで、ポントス出身のアクラというユダヤ人に会いました。クラウディオがすべてのユダヤ人にローマから退去するよう命じたため、彼は妻プリスキラと共に、少し前にイタリアから来たばかりでした。パウロは二人を訪ね、</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第一の手紙 4:12; テサロニケ人への手紙第一 2:9; コリント人への第二の手紙 11:9"> 同じ職業だったので、彼らの家に住んで一緒に働きました。彼らは天幕作りを職業としていたのです。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第二の手紙 5:11; 使徒の働き 17:17; 使徒の働き 28:23"> パウロは安息日ごとに会堂で論じ、ユダヤ人とギリシャ人を説得しました。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 5:14; 使徒の働き 18:28; 使徒の働き 20:21"> シラスとテモテがマケドニアから下って来ると、パウロは霊に促され、イエスがキリストであることをユダヤ人たちに証ししました。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 33:4; サムエル記第二 1:16; エゼキエル書 33:8–9"> しかし彼らが反対して冒瀆の言葉を吐いたので、パウロは衣のちりを払い落として言いました。「あなたがたの血は、あなたがた自身の頭に降りかかれ。私には責任がない。これから私は異邦人のところへ行く。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 16:14; コロサイ人への手紙 4:11; 使徒の働き 10:2"> 彼はそこを去り、神を礼拝するユストという人の家へ行きました。その家は会堂の隣にありました。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 1:13–17; ローマ人への手紙 10:14–17; マルコ 16:15–16"> 会堂司クリスポは、家族全員と共に主を信じました。また、コリント人の多くが御言葉を聞いて信じ、バプテスマを受けました。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 23:11; エペソ人への手紙 6:19–20; 使徒の働き 27:23–25"> ある夜、主は幻の中でパウロに言われました。<span className="woj">「恐れずに語り続け、黙っていてはならない。</span></span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第二の手紙 12:9; 出エジプト記 4:12; イザヤ書 41:10"> <span className="woj">私があなたと共にいるからである。だれもあなたを襲って危害を加えることはない。この町には、私の民が大勢いる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 14:3; 使徒の働き 19:10; 使徒の働き 20:31"> パウロは一年六か月そこに住み、彼らの間で神の言葉を教えました。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 13:50; 使徒の働き 18:27; 使徒の働き 13:7"> しかし、ガリオがアカイアの地方総督だったとき、ユダヤ人たちは心を一つにしてパウロに逆らい、彼を裁判の席へ引いて行き、</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 25:8; 使徒の働き 24:5–6; 使徒の働き 6:13"> 「この男は律法に反する仕方で神を礼拝するよう、人々をそそのかしています」と言いました。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ペテロの手紙第一 3:14–15; 使徒の働き 25:11; マルコ 9:19"> パウロが口を開こうとすると、ガリオはユダヤ人たちに言いました。「もし何かの不正や悪質な犯罪の問題なら、ユダヤ人諸君、あなたがたの訴えを取り上げるのも当然だろう。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 23:29; 使徒の働き 25:19; テモテへの手紙第一 6:4"> しかし、言葉や名称、あなたがた自身の律法に関する論争なら、自分たちで処理しなさい。私はそのような事柄の裁判官になるつもりはない。」</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 12:16; 詩篇 76:10; ローマ人への手紙 13:3–4"> そして彼らを裁判の席から追い出しました。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 1:1; アモス書 6:6; 使徒の働き 17:32"> するとギリシャ人たちは皆、会堂司ソステネを捕らえ、裁判の席の前で殴りました。しかしガリオは、そのようなことを一切気にかけませんでした。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 21:24; 民数記 6:18; 民数記 6:5–9"> パウロはその後もかなり長く滞在しました。それから兄弟たちに<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="ここおよび文脈上可能な箇所で「兄弟」と訳された言葉は、「兄弟姉妹」または「きょうだい」と訳すこともできる。">a</a></sup>別れを告げ、プリスキラとアクラを伴って、そこから船でシリアへ向かいました。彼は誓願を立てていたので、ケンクレアで髪をそりました。</span>
<span className="v" id="v19" data-v="19" data-xref="エペソ人への手紙 1:1; テモテへの手紙第一 1:3; テモテへの第二の手紙 1:18"> 一行はエフェソに着きました。パウロは二人をそこに残し、自分は会堂へ入ってユダヤ人たちと論じました。</span>
<span className="v" id="v20" data-v="20" data-xref="マルコ 1:37–38; コリント人への第一の手紙 16:12; 使徒の働き 20:16"> 人々はもっと長く滞在してほしいと頼みましたが、彼は承知せず、</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第一の手紙 4:19; ヤコブの手紙 4:15; ローマ人への手紙 15:32"> 彼らに別れを告げて言いました。「私は何としても、今度の祭りをエルサレムで守らなければなりません。しかし、神の御心なら、またあなたがたのところへ戻って来ます。」それからエフェソを船で出発しました。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 8:40; 使徒の働き 15:4; 使徒の働き 23:23"> カイサリアに上陸すると、エルサレムへ上って教会にあいさつし、それからアンティオキアへ下りました。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 14:22; 使徒の働き 16:6; 使徒の働き 15:41"> そこでしばらく過ごした後に出発し、ガラテヤとフリギアの地方を順に巡って、すべての弟子たちを力づけました。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第一の手紙 4:6; テトス 3:13; コリント人への第一の手紙 3:5–6"> さて、アレクサンドリア出身のアポロというユダヤ人がエフェソに来ました。雄弁な人で、聖書に精通していました。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 19:3; ローマ人への手紙 12:11; ホセア書 14:9"> この人は主の道について教えを受けており、霊に燃えて、イエスについて正確に語り、教えていました。ただし、ヨハネのバプテスマしか知りませんでした。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 18:25; 使徒の働き 14:3; コリント人への第一の手紙 12:21"> 彼は会堂で大胆に語り始めました。プリスキラとアクラは彼の話を聞くと、彼を自分たちのところに招き、神の道をさらに正確に説明しました。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="テサロニケ人への第二の手紙 2:13–14; ヤコブの手紙 1:16–18; ペテロの手紙第一 1:2–3"> アポロがアカイアへ渡ろうと決めたとき、兄弟たちは彼を励まし、弟子たちに彼を迎え入れるよう手紙を書きました。彼は到着すると、恵みによって信者となった人々に大きな助けを与えました。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒の働き 18:5; コリント人への第一の手紙 15:3–4; 使徒の働き 9:22"> 聖書に基づいてイエスがキリストであることを公に示し、力強くユダヤ人たちを論破したからです。</span>
</div>

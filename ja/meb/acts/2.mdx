<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 15:6; ピリピ人への手紙 2:2; 使徒の働き 1:13–15"> 五旬節の日が来たとき、彼らは皆、心を一つにして同じ場所に集まっていました。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 4:31; 列王記第一 19:11; 詩篇 18:10"> すると突然、激しい風が吹きつけるような音が天から起こり、彼らが座っていた家全体に響き渡りました。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイ 3:11; ヨハネ 1:32–33; エレミヤ書 23:29"> また、炎のような舌が現れて分かれ、一人一人の上にとどまりました。</span>
<span className="v" id="v4" data-v="4" data-xref="マルコ 16:17; 使徒の働き 13:52; 使徒の働き 4:31"> 皆が聖霊に満たされ、聖霊が語らせるままに、ほかの言語で話し始めました。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ルカ 2:25; 使徒の働き 8:2; コロサイ人への手紙 1:23"> さて、エルサレムには、天下のあらゆる国から来た敬虔なユダヤ人たちが住んでいました。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイ 2:3; コリント人への第一の手紙 16:9; 使徒の働き 2:2"> この音が聞こえると大勢の人が集まって来ましたが、だれもが自分の言語で弟子たちが話すのを聞いたので、戸惑いました。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 2:12; 使徒の働き 1:11; ヨハネ 7:52"> 人々は皆、驚き、不思議に思って互いに言いました。「見よ、話しているこの人たちは皆、ガリラヤ人ではないか。</span>
<span className="v" id="v8" data-v="8"> それなのに、私たち一人一人が、生まれ故郷の言語で聞いているのはどうしてだろう。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの手紙第一 1:1; 使徒の働き 18:2; ヨハネの黙示録 1:4"> 私たちの中には、パルティア人、メディア人、エラム人がおり、メソポタミア、ユダヤ、カパドキア、ポントス、アジア、</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 16:6; ゼカリヤ書 8:23; ゼカリヤ書 8:20"> フリギア、パンフィリア、エジプト、キレネに近いリビア地方から来た者もいる。また、ローマからの滞在者であるユダヤ人と改宗者、</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 12:10; 出エジプト記 15:11; 詩篇 78:4"> クレタ人やアラビア人もいる。それなのに、あの人たちが神の偉大なみわざを私たちの言語で語るのを聞いているのだ。」</span>
<span className="v" id="v12" data-v="12" data-xref="ルカ 15:26; 使徒の働き 17:20; ルカ 18:36"> 人々は皆、驚いて途方に暮れ、「これはいったいどういうことだろう」と互いに言いました。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 14:23; 使徒の働き 2:15; サムエル記第一 1:14"> しかし、ほかの者たちはあざけって、「あの者たちは新しいぶどう酒に酔っているのだ」と言いました。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 51:7; イザヤ書 51:1; 申命記 27:9"> そこでペテロは十一人と共に立ち上がり、声を張り上げて人々に語りかけました。「ユダヤの人たち、またエルサレムに住むすべての方々、このことを知り、私の言葉に耳を傾けてください。</span>
<span className="v" id="v15" data-v="15" data-xref="テサロニケ人への手紙第一 5:5–8; サムエル記第一 1:15; マタイ 20:3"> 今はまだ午前九時ですから、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="午前九時ごろ。">a</a></sup>この人たちは、あなたがたが思っているように酔っているのではありません。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨエル書 2:28–32"> これは預言者ヨエルを通して語られたことです。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨエル書 2:28–32; イザヤ書 44:3; テトス 3:4–6"> <span className="pl pl-1">『終わりの日々に、こうなると神は言われる。</span><br /><span className="pl pl-2">私はすべての人に私の霊を注ぐ。</span><br /><span className="pl pl-1">あなたがたの息子や娘は預言し、</span><br /><span className="pl pl-2">若者は幻を見、</span><br /><span className="pl pl-2">老人は夢を見る。</span></span>
<span className="v" id="v18" data-v="18" data-xref="ガラテヤ人への手紙 3:28; コロサイ人への手紙 3:11; コリント人への第一の手紙 7:21–22"> <span className="pl pl-1">その日々には、私のしもべにも、はしためにも、</span><br /><span className="pl pl-2">私の霊を注ぐ。すると彼らは預言する。</span></span>
<span className="v" id="v19" data-v="19" data-xref="ヨエル書 2:30–31; ゼパニヤ書 1:14–18; マラキ書 4:1–6"> <span className="pl pl-1">私は上では空に不思議なことを、</span><br /><span className="pl pl-2">下では地にしるしを示す。</span><br /><span className="pl pl-2">血と火と、立ち上る煙である。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ペテロの第二の手紙 3:10; アモス書 8:9; マタイ 24:29"> <span className="pl pl-1">主の大いなる輝かしい日が来る前に、</span><br /><span className="pl pl-2">太陽は闇に、</span><br /><span className="pl pl-2">月は血に変わる。</span></span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 10:12–13; ヨエル書 2:32; 詩篇 86:5"> <span className="pl pl-1">そのとき、主の名を呼び求める者は、だれでも救われる。』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="ヨハネ 3:2; ヨハネ 14:10–11; マタイ 12:28"> イスラエルの人たち、この言葉を聞いてください。ナザレのイエスは、神によってあなたがたに示された方です。神がこの方を通してあなたがたの間で行われた力あるわざ、不思議、しるしが、その証しです。これはあなたがた自身が知っているとおりです。</span>
<span className="v" id="v23" data-v="23" data-xref="ルカ 22:22; 使徒の働き 4:28; 使徒の働き 3:18"> このイエスが、神の定められた計画と予知によって引き渡されたとき、あなたがたは律法を持たない者たちの手を借りて十字架につけ、殺しました。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第一の手紙 6:14; ペテロの手紙第一 1:21; 使徒の働き 2:32"> しかし神は、イエスを死の苦しみから解き放って復活させられました。イエスが死に捕らわれたままでいることはあり得なかったからです。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 16:8–11; イザヤ書 41:13; 詩篇 62:6"> ダビデはこの方についてこう言っています。<br /><span className="pl pl-1">『私はいつも目の前に主を見ていた。</span><br /><span className="pl pl-2">主が私の右におられるので、私は揺るがない。</span></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 16:9; 詩篇 63:5; 詩篇 71:23"> <span className="pl pl-1">それゆえ、私の心は喜び、舌は歓声を上げた。</span><br /><span className="pl pl-2">さらに、私の肉体も希望のうちに住む。</span></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 16:10; 使徒の働き 2:31; ヨハネの黙示録 1:18"> <span className="pl pl-1">あなたは私の魂をハデスに置き去りにせず、</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または「地獄」。">b</a></sup><br /><span className="pl pl-2">あなたの聖なる方が朽ちるのをお許しにならないからだ。</span></span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 16:11; 詩篇 25:4; 詩篇 21:6"> <span className="pl pl-1">あなたは私に命の道を知らせてくださった。</span><br /><span className="pl pl-2">あなたの御前で、私を喜びに満たしてくださる。』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 13:36; 列王記第一 2:10; 使徒の働き 7:8–9"> 兄弟たち。族長ダビデについては、はっきり申し上げることができます。彼は死んで葬られ、その墓は今日まで私たちのもとにあります。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 132:11–18; 詩篇 89:3–4; エレミヤ書 33:14–15"> ダビデは預言者であり、神が彼に、肉による彼の子孫からキリストを起こして王座に着かせると誓われたことを知っていました。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「キリスト」は「油を注がれた者」という意味である。">c</a></sup></span>
<span className="v" id="v31" data-v="31" data-xref="使徒の働き 2:27; 詩篇 16:10; 使徒の働き 13:35"> それで彼は先を見通し、キリストの復活について、キリストの魂はハデスに置き去りにされず、<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="または「地獄」。">d</a></sup>その肉体は朽ちなかった、と語ったのです。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 3:15; 使徒の働き 1:8; 使徒の働き 1:22"> 神はこのイエスを復活させられました。私たちは皆、その証人です。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒の働き 1:4; 使徒の働き 5:31; 使徒の働き 2:17"> それでイエスは神の右に上げられ、約束の聖霊を父から受けて、今あなたがたが見聞きしているものを注いでくださったのです。</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 110:1; マタイ 22:42–45; ヘブル人への手紙 1:13"> ダビデは天に上ったのではありません。それでも彼自身がこう言っています。<br /><span className="pl pl-1">『主は私の主に言われた。「私の右に座っていなさい。</span></span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの黙示録 19:19–3; ローマ人への手紙 16:20; イザヤ書 60:14"> <span className="pl pl-2">私があなたの敵を、あなたの足台とするまで。」』</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒の働き 5:30–31; ローマ人への手紙 14:8–12; コリント人への第二の手紙 5:10"> ですから、イスラエルの全家よ、はっきり知ってください。あなたがたが十字架につけたこのイエスを、神は主ともキリストともされたのです。」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="ルカ 3:10; 使徒の働き 22:10; ヘブル人への手紙 4:12–13"> 人々はこれを聞くと心を刺され、ペテロとほかの使徒たちに言いました。「兄弟たち、私たちはどうすればよいのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="使徒の働き 22:16; マルコ 16:16; 使徒の働き 8:12"> ペテロは彼らに言いました。「悔い改めなさい。そして罪が赦されるために、一人一人、イエス・キリストの名によってバプテスマを受けなさい。そうすれば、聖霊という賜物を受けます。</span>
<span className="v" id="v39" data-v="39" data-xref="イザヤ書 44:3; 創世記 17:7–8; ローマ人への手紙 8:30"> この約束は、あなたがたと、その子どもたち、また遠くにいるすべての人、すなわち、私たちの神である主がご自分のもとに召されるすべての人に与えられているからです。」</span>
<span className="v" id="v40" data-v="40" data-xref="ピリピ人への手紙 2:15; 申命記 32:5; マタイ 17:17"> ペテロはほかにも多くの言葉で証しし、「この曲がった世代から救われなさい」と勧めました。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="使徒の働き 4:4; 使徒の働き 2:47; 使徒の働き 16:31–34"> そこで、喜んで彼の言葉を受け入れた人々はバプテスマを受け、その日、およそ三千人が仲間に加えられました。</span>
<span className="v" id="v42" data-v="42" data-xref="ヘブル人への手紙 10:25; 使徒の働き 1:14; ヨハネの手紙第一 1:3"> 彼らは使徒たちの教えと交わり、パンを裂くことと祈りを、ひたすら続けました。</span>
<span className="v" id="v43" data-v="43" data-xref="ルカ 7:16; ヨハネ 14:12; ルカ 8:37"> すべての人の心に恐れが生じ、使徒たちを通して多くの不思議としるしが行われました。</span>
<span className="v" id="v44" data-v="44" data-xref="使徒の働き 4:32; ヨハネの手紙第一 3:16–18; コリント人への第二の手紙 8:14–15"> 信じた人たちは皆一緒にいて、すべての物を共有していました。</span>
<span className="v" id="v45" data-v="45" data-xref="ヨハネの手紙第一 3:17; テモテへの手紙第一 6:18–19; ヤコブの手紙 2:14–16"> そして財産や持ち物を売り、それぞれの必要に応じて皆に分け与えました。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒の働き 5:42; 使徒の働き 20:7; 使徒の働き 2:42"> 彼らは毎日、心を一つにして神殿に集まり続け、家々でパンを裂き、喜びと真心をもって食事を共にし、</span>
<span className="v" id="v47" data-v="47" data-xref="使徒の働き 16:5; 使徒の働き 5:13–14; 使徒の働き 2:41"> 神を賛美し、民全体から好意を持たれていました。主は救われる人々を毎日、集会に加えてくださいました。</span>
</div>

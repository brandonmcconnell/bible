<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第二の手紙 7:5; 使徒の働き 19:21; テモテへの手紙第一 1:3"> 騒動が収まると、パウロは弟子たちを呼び寄せ、別れを告げてから、マケドニアへ向けて出発しました。</span>
<span className="v" id="v2" data-v="2" data-xref="テサロニケ人への手紙第一 2:3; テサロニケ人への手紙第一 4:1; コロサイ人への手紙 1:28"> 彼はその地方を巡り、多くの言葉で人々を励ましてから、ギリシャに来ました。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 20:19; コリント人への第二の手紙 11:26; 使徒の働き 9:23–24"> そこで三か月過ごしましたが、シリアへ向けて船出しようとしたとき、ユダヤ人たちが彼に対して陰謀を企てたので、マケドニアを通って帰ることに決めました。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 19:29; エペソ人への手紙 6:21; テモテへの第二の手紙 4:20"> 彼に同行してアジアまで行ったのは、ベレア人ソパテロ、テサロニケ人アリスタルコとセクンド、デルベ人ガイオ、テモテ、またアジア出身のティキコとトロフィモでした。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 16:8; 使徒の働き 16:10–11; テモテへの第二の手紙 4:13"> この人たちは先に出発し、トロアスで私たちを待っていました。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 12:3; 使徒の働き 16:12; 出エジプト記 23:15"> 私たちは種なしパンの祭りの後、ピリピから船出し、五日かかってトロアスの彼らのもとに着き、そこに七日間滞在しました。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="コリント人への第一の手紙 16:2; 使徒の働き 2:42; ヨハネ 20:19"> 週の初めの日、弟子たちがパンを裂くために集まったとき、パウロは翌日出発する予定だったので、人々に語り、話を真夜中まで続けました。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 1:13; ルカ 22:12"> 私たちが<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TRは「私たち」の代わりに「彼ら」としている。">a</a></sup>集まっていた階上の部屋には、多くの明かりがともっていました。</span>
<span className="v" id="v9" data-v="9" data-xref="マルコ 13:36; マタイ 26:40–41; ヨナ書 1:5–6"> ユティコという青年が窓辺に座っていましたが、深い眠りに沈みかけていました。パウロがなおも長く語り続けるうちに、眠りに負けて三階から下へ落ち、抱き起こされたときには死んでいました。</span>
<span className="v" id="v10" data-v="10" data-xref="マルコ 5:39; マタイ 9:23–24; 列王記第一 17:21–22"> パウロは下へ降り、彼の上に身をかがめて抱きしめ、言いました。「騒がないでください。彼には命があります。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 20:7; 使徒の働き 20:9"> それから上へ戻ってパンを裂いて食べ、夜明けまで長く語り合ってから出発しました。</span>
<span className="v" id="v12" data-v="12" data-xref="テサロニケ人への第二の手紙 2:16; テサロニケ人への手紙第一 5:14; コリント人への第二の手紙 1:4"> 人々は生き返った青年を連れて帰り、大いに慰められました。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マルコ 6:46; マルコ 1:35; マルコ 6:31–33"> 一方、私たちは先に船へ行き、アソスへ向けて船出しました。そこでパウロを乗せる予定でした。彼自身は陸路を行くことにして、そのように手配していたからです。</span>
<span className="v" id="v14" data-v="14"> パウロがアソスで私たちと合流すると、彼を船に乗せてミティレネへ行きました。</span>
<span className="v" id="v15" data-v="15" data-xref="テモテへの第二の手紙 4:20; 使徒の働き 20:17"> そこから船出し、翌日はキオスの向かい側に着き、その翌日はサモスに寄ってトロギリオンに滞在し、さらに翌日、ミレトスに着きました。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への第一の手紙 16:8; 使徒の働き 2:1; 使徒の働き 19:21"> パウロは、アジアで時間を費やさないため、エフェソには寄らずに船で通り過ぎることに決めていました。できれば五旬節の日にはエルサレムに着こうと急いでいたのです。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="テトス 1:5; 使徒の働き 11:30; テモテへの手紙第一 5:17"> パウロはミレトスからエフェソへ人を遣わし、教会の長老たちを呼び寄せました。</span>
<span className="v" id="v18" data-v="18" data-xref="テサロニケ人への手紙第一 1:5–6; 使徒の働き 18:19; 使徒の働き 19:1"> 長老たちが来ると、彼はこう言いました。「私がアジアに足を踏み入れた最初の日から、いつもあなたがたと共にどのように過ごしたか、あなたがた自身が知っています。</span>
<span className="v" id="v19" data-v="19" data-xref="コロサイ人への手紙 3:24; コリント人への第二の手紙 2:4; ローマ人への手紙 12:11"> 私は謙遜の限りを尽くし、多くの涙を流し、ユダヤ人たちの陰謀によって降りかかった数々の試練に遭いながら、主に仕えてきました。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 20:27; テモテへの第二の手紙 4:2; 使徒の働き 5:42"> また、あなたがたのためになることは何一つためらわずに伝え、公の場でも家々でも、あなたがたを教えてきました。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 2:38; 使徒の働き 11:18; ヨハネの手紙第一 5:11–13"> そしてユダヤ人にもギリシャ人にも、神に対する悔い改めと、私たちの主イエスに対する信仰を証ししました。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TRは「キリスト」を加えている。">b</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="ヤコブの手紙 4:14; コリント人への第二の手紙 5:14; ペテロの第二の手紙 1:14"> 今、見よ、私は霊に縛られてエルサレムへ行きます。そこで何が身に起こるかは分かりません。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 9:16; テサロニケ人への手紙第一 3:3; 使徒の働き 21:4"> ただ、聖霊がどの町でも、投獄と苦難が私を待ち受けていると証ししておられます。</span>
<span className="v" id="v24" data-v="24" data-xref="テモテへの第二の手紙 4:6–8; コリント人への第二の手紙 4:1; コリント人への第二の手紙 12:10"> しかし私は、そのようなことを意に介しません。また、自分の命を惜しいとも思いません。それは、自分の走るべき道のりを喜びのうちに走り終え、主イエスから受けた務め、すなわち、神の恵みの福音を十分に証しする務めを果たすためです。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 28:31; 使徒の働き 20:38; マタイ 4:23"> さて見よ、私は神の国を宣べ伝えながら、あなたがた全員の間を巡りましたが、あなたがたがもう二度と私の顔を見ないことを知っています。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 18:6; エゼキエル書 3:18–21; エゼキエル書 33:2–9"> ですから今日、私はあなたがたに証言します。すべての人の血について、私には責任がありません。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 20:20; テサロニケ人への手紙第一 2:4; ガラテヤ人への手紙 1:7–10"> 神の御計画のすべてを、ためらわずあなたがたに伝えたからです。</span>
<span className="v" id="v28" data-v="28" data-xref="ペテロの手紙第一 5:2–3; テモテへの手紙第一 4:16; イザヤ書 40:11"> ですから、自分自身と群れ全体に気を配りなさい。聖霊はあなたがたをその群れの監督者にされました。それは、主と<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="TRとNUは「主と」を省いている。">c</a></sup>神がご自分の血によって買い取られた教会を牧するためです。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイ 7:15; ペテロの第二の手紙 2:1; ヨハネ 10:12"> 私が去った後、凶暴な狼たちがあなたがたの中に入り込み、群れを容赦しないことを、私は知っています。</span>
<span className="v" id="v30" data-v="30" data-xref="テモテへの手紙第一 1:19–20; テモテへの第二の手紙 4:3–4; 箴言 23:33"> また、あなたがた自身の中からも、曲がったことを語って弟子たちを自分の後に引き込もうとする者たちが現れます。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒の働き 19:8; 使徒の働き 20:19; 使徒の働き 19:10"> ですから目を覚ましていなさい。私が三年の間、夜も昼も涙を流しながら、一人一人を絶えず戒めたことを覚えていなさい。</span>
<span className="v" id="v32" data-v="32" data-xref="コロサイ人への手紙 1:12; エペソ人への手紙 1:14; コロサイ人への手紙 3:24"> さて兄弟たち、<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="ここおよび文脈上可能な箇所で「兄弟」と訳された言葉は、「兄弟姉妹」または「きょうだい」と訳すこともできる。">d</a></sup>私はあなたがたを神と、その恵みの言葉に委ねます。この言葉には、あなたがたを築き上げ、聖別されたすべての人々と共に相続財産を受けさせる力があります。</span>
<span className="v" id="v33" data-v="33" data-xref="コリント人への第二の手紙 11:9; コリント人への第一の手紙 9:12; コリント人への第一の手紙 9:18"> 私は、だれの銀も金も衣服も欲しがりませんでした。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒の働き 18:3; コリント人への第一の手紙 4:12; テサロニケ人への第二の手紙 3:8–9"> 私のこの両手が、自分の必要と、仲間たちの必要のために働いたことは、あなたがた自身が知っています。</span>
<span className="v" id="v35" data-v="35" data-xref="ヘブル人への手紙 13:16; 箴言 19:17; コリント人への第二の手紙 9:6–12"> 私はあらゆる点で模範を示しました。このように働いて弱い人々を助け、主イエスご自身が、<span className="woj">『受けるより与えるほうが幸いである』</span>と言われた言葉を覚えていなければなりません。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒の働き 21:5; ルカ 22:41; ピリピ人への手紙 4:6"> こう言ってから、パウロはひざまずき、皆と一緒に祈りました。</span>
<span className="v" id="v37" data-v="37" data-xref="テモテへの第二の手紙 1:4; コリント人への第一の手紙 16:20; テサロニケ人への手紙第一 5:26"> 皆は激しく泣き、パウロの首を抱いて口づけしました。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒の働き 15:3; コリント人への第一の手紙 16:11; 使徒の働き 20:25"> 彼らは、もう二度と自分の顔を見ることはない、とパウロが言った言葉を何よりも悲しみました。そして彼を船まで見送りました。</span>
</div>

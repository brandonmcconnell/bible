<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 27:26; 使徒の働き 27:44; 使徒の働き 27:39"> 無事に逃れた後、人々は<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NUは「私たちは」としている。">a</a></sup>その島がマルタと呼ばれていることを知りました。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 1:14; ヘブル人への手紙 13:2; コロサイ人への手紙 3:11"> 島の人々は、私たちに並々ならぬ親切を示してくれました。雨が降って寒かったので、火をたいて、私たち全員を迎えてくれたのです。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイ 23:33; マタイ 12:34; 使徒の働き 28:4"> パウロが一束の枯れ枝を集めて火にくべると、熱のために一匹の毒蛇が出て来て、彼の手にかみつきました。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカ 13:2; ルカ 13:4; ヨハネ 7:24"> 島の人々は、その生き物がパウロの手からぶら下がっているのを見て、互いに言いました。「この男はきっと人殺しだ。海からは逃れたものの、正義の女神は彼を生かしておかなかった。」</span>
<span className="v" id="v5" data-v="5" data-xref="ルカ 10:19; マルコ 16:18; 詩篇 91:13"> しかしパウロは、その生き物を火の中に振り落とし、何の害も受けませんでした。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 12:22; 使徒の働き 14:11–13; マタイ 21:9"> 人々は、彼の体が腫れ上がるか、突然倒れて死ぬだろうと待っていました。しかし長い間見ていても何の異変も起こらなかったので、考えを変え、彼は神だと言いました。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マタイ 10:40–41; ルカ 19:6–9; 使徒の働き 28:2"> さて、その場所の近くに、島の長官でプブリオという人の土地がありました。彼は私たちを迎え、三日間、心を込めてもてなしてくれました。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 9:40; マルコ 6:5; ヤコブの手紙 5:14–16"> そのとき、プブリオの父が熱病と赤痢を患い、床についていました。パウロは彼のところに入って祈り、手を置いて癒やしました。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 5:12; マルコ 6:54–56; 使徒の働き 5:15"> このことがあってから、島で病気を患っていたほかの人々もやって来て、治してもらいました。</span>
<span className="v" id="v10" data-v="10" data-xref="テサロニケ人への手紙第一 2:6; ピリピ人への手紙 4:11–12; マタイ 6:31–34"> 人々は私たちに数々の敬意を示し、船出するときには必要な物を船に積んでくれました。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 27:6; コリント人への第一の手紙 8:4; イザヤ書 45:20"> 三か月後、私たちはその島で冬を越したアレクサンドリアの船で出航しました。その船の船首像は「双子の兄弟」でした。</span>
<span className="v" id="v12" data-v="12"> シラクサに寄港し、そこに三日間滞在しました。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 27:13"> そこから回り込んでレギオンに着きました。一日たつと南風が吹き始め、二日目にはポテオリに着きました。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 21:4; 使徒の働き 20:6; 使徒の働き 19:1"> そこで兄弟たちに会い、<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ここおよび文脈上可能な箇所で「兄弟」と訳された言葉は、「兄弟姉妹」または「きょうだい」と訳すこともできる。">b</a></sup>七日間滞在するよう頼まれました。こうして私たちはローマに着きました。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 13:3; ローマ人への手紙 15:24; 出エジプト記 4:14"> ローマの兄弟たちは私たちのことを聞き、アピオの市場と三軒宿まで迎えに来てくれました。パウロは彼らを見ると神に感謝し、勇気づけられました。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 27:3; 使徒の働き 24:23; 使徒の働き 28:30–31"> 私たちがローマに入ると、百人隊長は囚人たちを近衛隊長に引き渡しました。しかしパウロは、自分を見張る兵士一人と共に、別に暮らすことを許されました。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 25:8; 使徒の働き 6:14; 使徒の働き 25:10"> 三日後、パウロはユダヤ人の主だった人々を呼び集めました。彼らが集まると、パウロは言いました。「兄弟たち。私は、民にも父祖たちの慣習にも何一つ逆らうことをしていないのに、エルサレムで囚人としてローマ人の手に引き渡されました。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 26:31–32; 使徒の働き 23:29; 使徒の働き 22:24–25"> ローマ人は私を取り調べた後、私に死刑の理由がないので釈放しようとしました。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 26:32; 使徒の働き 25:21; 使徒の働き 25:10–12"> しかしユダヤ人たちが反対したため、私はカエサルに上訴せざるを得ませんでした。自分の国民を訴える理由があったわけではありません。</span>
<span className="v" id="v20" data-v="20" data-xref="エペソ人への手紙 6:20; テモテへの第二の手紙 2:9; 使徒の働き 26:6–7"> そのようなわけで、あなたがたに会って話をしたいと願いました。私はイスラエルの望みのために、この鎖につながれているのです。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 54:17; イザヤ書 41:11; イザヤ書 50:8"> 彼らはパウロに言いました。「私たちは、あなたについての手紙をユダヤから受け取っていません。また、兄弟たちのだれもここへ来て、あなたについて悪いことを報告したり、話したりしてはいません。</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの手紙第一 2:12; 使徒の働き 24:14; ペテロの手紙第一 3:16"> ただ、あなたがどのように考えているのか、直接聞きたいと思います。この一派については、至る所で反対されていると承知しています。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 17:2–3; 使徒の働き 19:8; 使徒の働き 18:28"> そこで彼らは日を決め、その日にはさらに大勢の人がパウロの宿に来ました。パウロは朝から晩まで、神の国について説明して証しし、モーセの律法と預言者たちの書から、イエスについて彼らを説得しようとしました。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 14:4; 使徒の働き 17:4–5; 使徒の働き 19:8–9"> 語られたことを信じる人もいれば、信じない人もいました。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイ 15:7; ペテロの第二の手紙 1:21; マルコ 7:6"> 互いに意見が一致しなかったので、彼らは帰り始めました。そのときパウロは一言、こう述べました。「聖霊は預言者イザヤを通して、私たちの父祖に正しく語られました。</span>
<span className="v" id="v26" data-v="26" data-xref="イザヤ書 6:9–10; エゼキエル書 12:2; イザヤ書 42:19–20"> こう言っておられます。<br /><span className="pl pl-1">『この民のところへ行って言いなさい。</span><br /><span className="pl pl-1">あなたがたは聞くには聞くが、</span><br /><span className="pl pl-2">決して理解しない。</span><br /><span className="pl pl-1">見るには見るが、</span><br /><span className="pl pl-2">決して悟らない。</span></span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 6:10"> <span className="pl pl-1">この民の心は鈍くなり、</span><br /><span className="pl pl-2">耳は聞こえにくくなり、</span><br /><span className="pl pl-2">目は閉じてしまった。</span><br /><span className="pl pl-1">そうでなければ、彼らは目で見、</span><br /><span className="pl pl-2">耳で聞き、</span><br /><span className="pl pl-2">心で理解し、</span><br /><span className="pl pl-2">立ち返るだろう。</span><br /><span className="pl pl-2">そうすれば、私は彼らを癒やすのに。』</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ルカ 2:30–32; 使徒の働き 26:17–18; ローマ人への手紙 3:29–30"> ですから、神のこの救いが異邦人に送られたことを知ってください。彼らは耳を傾けます。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> パウロがこの言葉を語り終えると、ユダヤ人たちは互いに激しく論じ合いながら立ち去りました。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="NUは29節を省いている。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> パウロは自分で借りた家に丸二年間住み、訪ねて来るすべての人を迎え入れ、</span>
<span className="v" id="v31" data-v="31" data-xref="使徒の働き 4:29; エペソ人への手紙 6:19–20; マタイ 4:23"> 少しも妨げられることなく、あらん限りの大胆さをもって神の国を宣べ伝え、主イエス・キリストについて教えました。</span>
</div>

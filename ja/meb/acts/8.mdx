<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 22:20; ダニエル書 3:16–18; 使徒の働き 5:40"> サウロはステファノが殺されることに賛成していました。その日、エルサレムにある教会に対する激しい迫害が起こり、使徒たち以外の人々は皆、ユダヤとサマリアの各地へ散らされました。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 50:10–11; 創世記 23:2; エレミヤ書 22:18"> 敬虔な人々はステファノを葬り、彼のために激しく嘆き悲しみました。</span>
<span className="v" id="v3" data-v="3" data-xref="テモテへの手紙第一 1:13; ガラテヤ人への手紙 1:13; コリント人への第一の手紙 15:9"> しかしサウロは教会を荒らし、家々に押し入って男も女も引きずり出し、牢に入れました。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイ 10:23; 使徒の働き 11:19; 使徒の働き 8:1"> 一方、散らされた人々は各地を巡りながら、御言葉を宣べ伝えました。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 6:5; 使徒の働き 21:8; 使徒の働き 8:35–36"> ピリポはサマリアの町へ下って行き、人々にキリストを宣べ伝えました。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 4:41–42; 歴代誌 第二 30:12; マタイ 20:15–16"> 群衆は、ピリポが行うしるしを見聞きすると、彼が語ることに心を一つにして耳を傾けました。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイ 10:1; 使徒の働き 14:8–10; マルコ 16:17–18"> 汚れた霊が取りついていた多くの人から、大声で叫びながら出て行きました。また、体の麻痺した人や足の不自由な人が大勢癒やされました。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 13:52; 使徒の働き 13:48; 使徒の働き 8:39"> それで、その町には大きな喜びがありました。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 13:6; 使徒の働き 5:36; ヨハネ 7:18"> さて、その町にはシモンという男がいました。以前から魔術を使ってサマリアの人々を驚かせ、自分を偉大な者であるかのように見せていました。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 31:34; ペテロの第二の手紙 2:2; ヨハネの黙示録 13:3"> 小さな者から大きな者まで、皆が彼に耳を傾け、「この人こそ、『神の偉大な力』と呼ばれる方だ」と言っていました。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 8:9; ガラテヤ人への手紙 3:1; イザヤ書 44:25"> 人々が彼に耳を傾けたのは、長い間、その魔術によって驚かされていたからです。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 2:38; 使徒の働き 1:3; マタイ 28:19"> しかし、ピリポが神の国とイエス・キリストの名について福音を宣べ伝えると、人々はそれを信じ、男も女もバプテスマを受けました。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 8:6–7; ヨハネ 5:20; 使徒の働き 19:11"> シモン自身も信じてバプテスマを受け、その後はいつもピリポと行動を共にしました。そして、しるしや大きな奇跡が起こるのを見て驚きました。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への手紙第一 2:13; テサロニケ人への手紙第一 3:2; ガラテヤ人への手紙 2:9"> エルサレムにいた使徒たちは、サマリアが神の言葉を受け入れたと聞き、ペテロとヨハネを彼らのもとへ遣わしました。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 2:38; ヨハネ 16:23–24; ヨハネ 14:13–14"> 二人はそこへ下って行き、人々が聖霊を受けるようにと祈りました。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 2:38; 使徒の働き 19:2; マタイ 28:19"> 彼らはキリスト・イエスの名によってバプテスマを受けただけで、聖霊はまだそのうちのだれにも臨んでいなかったからです。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 19:6; 使徒の働き 6:6; テモテへの第二の手紙 1:6"> そこで二人が彼らの上に手を置くと、彼らは聖霊を受けました。</span>
<span className="v" id="v18" data-v="18" data-xref="テモテへの手紙第一 6:5; マタイ 10:8; 列王記第二 8:9"> シモンは、使徒たちが手を置くことによって聖霊が与えられるのを見ると、二人に金を差し出し、</span>
<span className="v" id="v19" data-v="19" data-xref="ルカ 14:7–11; ヨハネの手紙第三 1:9; ヨハネ 5:44"> 言いました。「私にもその力を与えてください。私が手を置く人が、だれでも聖霊を受けられるようにしてください。」</span>
<span className="v" id="v20" data-v="20" data-xref="ダニエル書 5:17; マタイ 10:8; 使徒の働き 2:38"> しかしペテロは彼に言いました。「神の賜物を金で手に入れられると考えたあなたは、その銀と共に滅びてしまいなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="ヘブル人への手紙 4:13; 詩篇 36:1; マタイ 6:22–24"> このことについて、あなたには何の分け前も権利もありません。あなたの心は神の御前に正しくないからです。</span>
<span className="v" id="v22" data-v="22" data-xref="テモテへの第二の手紙 2:25–26; ダニエル書 4:27; ヘブル人への手紙 4:12"> ですから、この悪を悔い改め、神に願いなさい。そうすれば、もしかすると心に抱いたその考えが赦されるかもしれません。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 58:6; 箴言 5:22; ヨハネ 8:34"> あなたが苦い毒に満ち、不義に縛られていることが、私には分かるからです。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 8:8; 民数記 21:7; ヨブ記 42:8"> シモンは答えました。「あなたがたの言ったことが何一つ私の身に起こらないよう、私のために主に祈ってください。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 20:21; 使徒の働き 26:22–23; 使徒の働き 1:8"> 二人は主の言葉を証しして語った後、エルサレムへ帰りました。その途中、サマリア人の多くの村で福音を宣べ伝えました。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 5:19; ヘブル人への手紙 1:14; 列王記第二 1:3"> さて、主の使いがピリポに語りかけました。「立って南へ向かい、エルサレムからガザへ下る道に行きなさい。その道は寂しい所を通っている。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ゼパニヤ書 3:10; 詩篇 68:31; イザヤ書 56:3–8"> そこでピリポは立って出かけました。すると見よ、エチオピア人の男がいました。彼は宦官で、エチオピア人の女王カンダケに仕える高官であり、女王の全財産を管理していました。礼拝のためエルサレムに来ていたのです。</span>
<span className="v" id="v28" data-v="28" data-xref="コロサイ人への手紙 3:16; イザヤ書 1:1; 使徒の働き 28:25"> 彼は帰る途中で、馬車に座って預言者イザヤの書を読んでいました。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 10:19; 使徒の働き 11:12; 使徒の働き 20:22–23"> 霊がピリポに言いました。「近寄って、あの馬車と一緒に進みなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ルカ 24:44–45; ヨハネ 5:39; エペソ人への手紙 5:17"> ピリポが駆け寄ると、その人が預言者イザヤの書を読んでいるのが聞こえたので、「読んでいることが分かりますか」と尋ねました。</span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="ローマ人への手紙 10:14; 詩篇 73:16–17; イザヤ書 29:18–19"> その人は言いました。「だれかが説明してくれなければ、どうして分かるでしょう。」そしてピリポに、馬車に乗って自分の隣に座るよう頼みました。</span>
<span className="v" id="v32" data-v="32" data-xref="イザヤ書 53:7–8; ペテロの手紙第一 2:21–24; エレミヤ書 51:40"> 彼が読んでいた聖書の箇所は、次のとおりです。<br /><span className="pl pl-1">「彼は羊のように、ほふり場へ引かれて行った。</span><br /><span className="pl pl-2">毛を刈る者の前で黙っている子羊のように、</span><br /><span className="pl pl-2">彼は口を開かない。</span></span>
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 53:12; イザヤ書 53:8; ゼカリヤ書 13:7"> <span className="pl pl-1">彼は辱めを受け、公正な裁きを奪われた。</span><br /><span className="pl pl-2">だれが彼の時代のことを語れるだろう。</span><br /><span className="pl pl-2">彼の命は地上から取り去られるからだ。」</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="マタイ 15:15; マタイ 13:36; マタイ 2:2–4"> 宦官はピリポに尋ねました。「教えてください。預言者はだれについてこう語っているのですか。自分自身についてですか、それともほかのだれかについてですか。」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="ルカ 24:27; 使徒の働き 18:28; 使徒の働き 28:23"> そこでピリポは口を開き、この聖書の箇所から始めて、イエスについての福音を彼に伝えました。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒の働き 10:47; ヨハネ 3:5; テトス 3:5–6"> 二人が道を進んで行くと、水のある所に着きました。宦官は言いました。「見よ、ここに水があります。私がバプテスマを受けるのを妨げるものが何かあるでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37"> <sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TRは次の文を加えている。ピリポは言った。「あなたが心のすべてをもって信じるなら、受けてもよい。」彼は答えた。「私はイエス・キリストが神の子であると信じます。」">a</a></sup></span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネ 4:1; ヨハネ 3:22–23"> 宦官は馬車を止めるよう命じました。そしてピリポと宦官は二人とも水の中に下り、ピリポが彼にバプテスマを授けました。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="列王記第一 18:12; 列王記第二 2:16; エゼキエル書 8:3"> 二人が水から上がると、主の霊がピリポを連れ去りました。宦官はもう彼を見ることがありませんでしたが、喜びながら旅を続けました。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒の働き 21:8; 使徒の働き 23:23; 使徒の働き 23:33"> 一方、ピリポはアゾトに現れました。そしてそこからカイサリアに着くまで、町々を通りながら福音を宣べ伝えました。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカ 22:4; 使徒の働き 6:12; 使徒の働き 23:6–9"> 二人が民に話していると、祭司たち、神殿の警備隊長、サドカイ人たちが近づいて来ました。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 17:18; テサロニケ人への手紙第一 4:13–14; 使徒の働き 24:14–15"> 彼らは、二人が民を教え、イエスにおける死者の復活を宣べ伝えていることに腹を立てていました。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 5:18; マタイ 10:16–17; 使徒の働き 16:19–24"> そこで二人を捕らえ、すでに夕方だったので、翌日まで拘留しました。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 2:41; コリント人への第二の手紙 2:14–17; テモテへの第二の手紙 2:9–10"> しかし、言葉を聞いた人々の多くが信じ、男の数はおよそ五千人になりました。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 4:8; マタイ 27:1–2; ルカ 20:1"> 翌朝、民の指導者、長老、律法学者たちがエルサレムに集まりました。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカ 3:2; ヨハネ 18:24; マタイ 26:3"> 大祭司アンナスのほか、カヤパ、ヨハネ、アレクサンデル、また大祭司の親族が皆そこにいました。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイ 21:23; マルコ 11:28; 使徒の働き 5:40"> 彼らはペテロとヨハネを中央に立たせ、「おまえたちは、何の力によって、まただれの名によって、このことをしたのか」と尋ねました。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ルカ 12:11–12; マタイ 10:19–20; 使徒の働き 2:4"> そのとき、ペテロは聖霊に満たされて彼らに言いました。「民の指導者たち、イスラエルの長老たち。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの手紙第一 3:15–17; 使徒の働き 3:7; ヨハネ 10:32"> 私たちが今日、足の不自由な人に行った善い行いと、その人が何によって癒やされたかについて取り調べを受けているのであれば、</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 5:29–32; 使徒の働き 3:6; 使徒の働き 2:36"> あなたがた全員、またイスラエルの民全体は、はっきり知ってください。この人が治って、あなたがたの前に立っているのは、あなたがたが十字架につけ、神が死者の中から復活させられたナザレのイエス・キリストの名によるのです。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 118:22–23; イザヤ書 28:16; マルコ 12:10–12"> この方こそ、『あなたがた建築家に退けられた石であり、隅のかしらとなった石』です。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネ 14:6; コリント人への第一の手紙 3:11; ヨハネ 3:36"> ほかのだれにも救いはありません。私たちが救われるための名は、天下にこの名のほか、人々に与えられていないからです。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 1:27; ヨハネ 7:15; マタイ 11:25"> 人々はペテロとヨハネの大胆さを見、二人が教育を受けていない普通の人だと知って驚きました。そして、二人がイエスと共にいた者だと気づきました。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 19:36; 使徒の働き 3:8–12; 使徒の働き 4:21"> また、癒やされた人が二人と一緒に立っているのを見て、何も言い返すことができませんでした。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 26:30–32; 使徒の働き 5:34–42; マタイ 5:22"> そこで二人に最高法院から退出するよう命じ、互いに相談して、</span>
<span className="v" id="v16" data-v="16" data-xref="ルカ 21:15; 使徒の働き 6:10; ヨハネ 12:18"> 言いました。「あの者たちをどうすればよいだろう。確かに彼らを通して著しい奇跡が行われたことは、エルサレムの住民全体に明らかであり、否定することはできない。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 5:28; ローマ人への手紙 15:18–22; 使徒の働き 5:24"> しかし、これ以上民の間に広まらないよう、今後はこの名によってだれにも語ってはならないと脅しておこう。」</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 5:40; ルカ 24:46–48; 使徒の働き 5:20"> それから二人を呼び戻し、イエスの名によっては決して語ることも教えることもないよう命じました。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 5:29; 出エジプト記 1:17; コリント人への第一の手紙 10:15"> しかし、ペテロとヨハネは彼らに答えました。「神に聞き従うより、あなたがたに聞き従うほうが神の御前に正しいかどうか、自分たちで判断してください。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 22:15; エレミヤ書 20:9; コリント人への第一の手紙 9:16–17"> 私たちは、自分たちが見聞きしたことを話さずにはいられません。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 5:26; マタイ 21:46; ルカ 22:2"> 彼らは二人をさらに脅したうえで、釈放しました。人々のために、二人を罰する方法が見つからなかったからです。起こったことのゆえに、だれもが神をたたえていました。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネ 5:5; 使徒の働き 9:33; ルカ 13:11"> この癒やしの奇跡が行われた人は、四十歳を超えていました。</span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="コリント人への第二の手紙 6:14–17; 使徒の働き 12:11–12; 詩篇 119:63"> 釈放された二人は仲間のところへ行き、祭司長たちと長老たちに言われたことをすべて報告しました。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 20:11; エレミヤ書 32:17; ネヘミヤ記 9:6"> 仲間たちはこれを聞くと、心を一つにして神に向かって声を上げ、言いました。「主よ。あなたは天と地と海、またその中のすべてのものを造られた神です。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 2:1–6; 使徒の働き 1:16; 使徒の働き 2:30"> あなたは、しもべである私たちの父ダビデの口を通して、こう言われました。<br /><span className="pl pl-1">『なぜ異邦の民は荒れ狂い、</span><br /><span className="pl pl-2">もろもろの民はむなしいことを企むのか。</span></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 2:2; ヨハネの黙示録 17:12–14; ダニエル書 9:24"> <span className="pl pl-1">地の王たちは立ち上がり、</span><br /><span className="pl pl-2">支配者たちは共に集まって、</span><br /><span className="pl pl-2">主と、そのキリストに逆らう。』</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="キリスト（ギリシャ語）とメシア（ヘブル語）は、どちらも「油を注がれた者」という意味である。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="マタイ 27:2; 使徒の働き 4:30; ルカ 9:22"> 実に、<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NUは「この町で」を加えている。">b</a></sup>ヘロデとポンテオ・ピラトは、異邦人やイスラエルの民と共に、あなたが油を注がれた聖なるしもべイエスに逆らって集まりました。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒の働き 2:23; イザヤ書 46:10; 創世記 50:20"> それは、あなたの御手と御計画によって、起こるようにとあらかじめ定められていたことを行うためでした。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 4:13; 使徒の働き 14:3; ピリピ人への手紙 1:14"> 主よ。今、彼らの脅しをご覧になり、あなたのしもべたちが、あらん限りの大胆さをもって、あなたの言葉を語れるようにしてください。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 4:27; 使徒の働き 3:6; 使徒の働き 5:12"> また、癒やしのために御手を伸ばし、あなたの聖なるしもべイエスの名によって、しるしと不思議が行われるようにしてください。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="マタイ 21:22; 使徒の働き 2:2; 使徒の働き 2:4"> 祈り終えると、彼らが集まっていた場所が揺れ動きました。皆が聖霊に満たされ、大胆に神の言葉を語りました。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="コリント人への第一の手紙 1:10; エペソ人への手紙 4:2–6; ペテロの手紙第一 3:8"> 信じた大勢の人々は心も魂も一つでした。持っている物を自分だけのものだと主張する者は一人もなく、すべての物を共有していました。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネ 1:16; 使徒の働き 1:22; 使徒の働き 1:8"> 使徒たちは大きな力をもって主イエスの復活を証しし、一同の上には豊かな恵みがありました。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒の働き 2:45; ルカ 12:33; ルカ 16:9"> 彼らの中には、乏しい者が一人もいませんでした。土地や家を持っている人々がそれを売り、売った物の代金を持って来て、</span>
<span className="v" id="v35" data-v="35" data-xref="使徒の働き 5:2; 使徒の働き 2:45; コリント人への第二の手紙 8:20–21"> 使徒たちの足もとに置き、それぞれの必要に応じて一人一人に分け与えられたからです。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="ガラテヤ人への手紙 2:9; ガラテヤ人への手紙 2:13; ガラテヤ人への手紙 2:1"> ヨセは、使徒たちからバルナバ、訳せば「励ましの子」と呼ばれていました。キプロス生まれのレビ人で、</span>
<span className="v" id="v37" data-v="37" data-xref="使徒の働き 5:1–2; 使徒の働き 4:34–35; マタイ 19:29"> 畑を持っていましたが、それを売り、その代金を持って来て使徒たちの足もとに置きました。</span>
</div>
</div>

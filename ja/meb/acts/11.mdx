<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 22:27; マラキ書 1:11; イザヤ書 32:15"> さて、ユダヤにいる使徒たちと兄弟たちは、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="ここおよび文脈上可能な箇所で「兄弟」と訳された言葉は、「兄弟姉妹」または「きょうだい」と訳すこともできる。">a</a></sup>異邦人も神の言葉を受け入れたと聞きました。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 10:45; 使徒の働き 10:9; 使徒の働き 15:1"> ペテロがエルサレムへ上って来ると、割礼を受けた者たちは彼を非難して、</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 10:28; ガラテヤ人への手紙 2:12; ルカ 15:2"> 言いました。「あなたは割礼を受けていない者たちのところへ入って、一緒に食事をした。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ルカ 1:3; 使徒の働き 14:27; ヨシュア記 22:21–31"> そこでペテロは、事の次第を初めから順序立てて彼らに説明しました。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 10:9–32; 使徒の働き 9:10; 使徒の働き 22:17"> 「私はヨッパの町で祈っていました。すると恍惚状態に入り、幻を見ました。大きな布のようなものが四隅をつるされて天から降り、私のところまで来ました。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカ 4:20; 使徒の働き 3:4"> 私がそれをじっと見て調べると、中には地上の四つ足の動物、野獣、地をはう生き物、空の鳥が見えました。</span>
<span className="v" id="v7" data-v="7"> また、私にこう言う声を聞きました。<span className="woj">『ペテロ、立ちなさい。ほふって食べなさい。』</span></span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 14:14; ホセア書 9:3; コリント人への第一の手紙 7:14"> しかし私は言いました。『主よ、とんでもありません。清くない物や汚れた物が私の口に入ったことは、一度もありません。』</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 15:9; ヘブル人への手紙 9:13–14; 使徒の働き 10:34–35"> すると天からの声が二度目に答えました。<span className="woj">『神が清めた物を、汚れていると言ってはならない。』</span></span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネ 21:17; 民数記 24:10; コリント人への第二の手紙 12:8"> このことが三度あり、そのすべてが再び天へ引き上げられました。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 4:27; 使徒の働き 9:10–12; 出エジプト記 4:14"> すると見よ、ちょうどそのとき、カイサリアから私のもとへ遣わされた三人の男が、私のいた家の前に立ちました。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 8:29; ローマ人への手紙 3:22; テサロニケ人への第二の手紙 2:2"> 霊は私に、分け隔てせず彼らと一緒に行くよう告げました。ここにいる六人の兄弟たちも同行し、私たちはその人の家に入りました。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 10:30–32; 使徒の働き 10:3–6; 使徒の働き 9:43"> その人は、天使が自分の家に立って、こう言うのを見たと話してくれました。『ヨッパへ人を遣わし、ペテロと呼ばれるシモンを招きなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 16:15; 使徒の働き 10:22; 使徒の働き 16:31–34"> その人が、あなたとあなたの全家が救われるための言葉を語ってくれる。』</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 19:6; 使徒の働き 10:34–46; 使徒の働き 2:2–12"> 私が話し始めると、初めに私たちに臨んだのと同じように、聖霊が彼らに臨みました。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 1:5; マルコ 1:8; 箴言 1:23"> そのとき私は、主がこう言われた言葉を思い出しました。<span className="woj">『ヨハネは水でバプテスマを授けたが、あなたがたは聖霊によってバプテスマを授けられる。』</span></span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 10:47; ローマ人への手紙 9:20–26; ダニエル書 4:35"> ですから、私たちが主イエス・キリストを信じたときと同じ賜物を、神が彼らにも与えられたのなら、神を妨げることのできる私は、いったい何者でしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 10:12–13; コリント人への第二の手紙 7:10; エゼキエル書 36:26"> 人々はこれを聞くと黙り、神をあがめて言いました。「それでは神は、異邦人にも命に至る悔い改めをお与えになったのだ。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 4:36; 使徒の働き 21:2; 使徒の働き 15:3"> さて、ステファノのことで起こった迫害によって散らされた人々は、フェニキア、キプロス、アンティオキアまで進んで行きましたが、ユダヤ人以外のだれにも御言葉を語りませんでした。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイ 27:32; 使徒の働き 13:1; コリント人への第一の手紙 1:23–24"> しかし、その中にキプロスやキレネ出身の人たちがいて、アンティオキアへ行くと、ギリシャ文化を受け入れていた人々<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ここでいう人々とは、ギリシャの慣習と文化に従っていた人々である。">b</a></sup>にも主イエスの福音を宣べ伝えました。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカ 1:66; 使徒の働き 2:47; 使徒の働き 5:14"> 主の御手が彼らと共にあったので、大勢の人が信じて主に立ち返りました。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 9:27; 使徒の働き 8:14; 使徒の働き 13:1–3"> 彼らについての知らせがエルサレムの教会に届くと、教会はバルナバをアンティオキアまで遣わしました。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への第一の手紙 15:58; 使徒の働き 14:22; 使徒の働き 13:43"> 彼は到着して神の恵みを見ると喜び、心を定めて主にとどまるよう、皆を励ましました。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 11:21; 使徒の働き 5:14; 使徒の働き 9:31"> バルナバは良い人で、聖霊と信仰に満ちていました。こうして多くの人が主に加えられました。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 9:11; 使徒の働き 9:27; 使徒の働き 9:30"> それからバルナバは、サウロを捜しにタルソへ出かけました。</span>
<span className="v" id="v26" data-v="26" data-xref="ペテロの手紙第一 4:16; 使徒の働き 26:28; ペテロの手紙第一 4:14"> 彼を見つけると、アンティオキアへ連れて来ました。二人は丸一年、教会と共に集まり、大勢の人を教えました。弟子たちが初めて「キリスト者」と呼ばれたのは、アンティオキアでした。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 13:1; コリント人への第一の手紙 12:28; エペソ人への手紙 4:11"> そのころ、預言者たちがエルサレムからアンティオキアへ下って来ました。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒の働き 21:10; 使徒の働き 18:2; ルカ 3:1"> その一人でアガボという人が立ち、世界中に大飢饉が起こることを霊によって示しました。それはクラウディオの時代に実際に起こりました。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第二の手紙 8:12–14; ガラテヤ人への手紙 2:10; コリント人への第二の手紙 8:2–4"> そこで弟子たちは、それぞれの暮らし向きに応じて、ユダヤに住む兄弟たちに援助を送ることに決めました。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 14:23; 使徒の働き 12:25; 使徒の働き 15:4"> 彼らはそれを実行し、バルナバとサウロの手によって長老たちへ送りました。</span>
</div>

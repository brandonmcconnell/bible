<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 25:25; 使徒の働き 25:12; 使徒の働き 10:1"> 私たちが船でイタリアへ向かうことが決まると、人々はパウロとほかの囚人たちを、皇帝直属部隊のユリオという百人隊長に引き渡しました。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 19:29; フィレモンへの手紙 1:24; コロサイ人への手紙 4:10"> 私たちは、アジア沿岸の各地へ向かう予定のアドラミティオンの船に乗り込み、出航しました。テサロニケ出身のマケドニア人アリスタルコも一緒でした。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 24:23; 使徒の働き 28:16; 使徒の働き 27:43"> 翌日、私たちはシドンに寄港しました。ユリオはパウロを親切に扱い、友人たちのところへ行って世話を受けることを許しました。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 4:36; 使徒の働き 15:39; 使徒の働き 13:4"> そこから船出しましたが、向かい風だったので、キプロスの風下を航行しました。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 6:9; 使徒の働き 13:13; 使徒の働き 15:41"> そしてキリキアとパンフィリア沖の海を渡り、リキアの町ミラに着きました。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 28:11; 使徒の働き 27:1; 使徒の働き 6:9"> そこで百人隊長は、イタリアへ向かうアレクサンドリアの船を見つけ、私たちをそれに乗せました。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 27:21; テトス 1:5; テトス 1:12"> 何日もの間ゆっくり進み、ようやくクニドスの沖まで来ましたが、風に阻まれて先へ進めなかったので、サルモネ沖を通り、クレタ島の風下を航行しました。</span>
<span className="v" id="v8" data-v="8"> そして島の岸に沿って苦労しながら進み、ラサヤの町に近い「良い港」と呼ばれる所に着きました。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数記 29:7; レビ記 23:27–29; レビ記 16:29–31"> かなりの日数が過ぎ、すでに断食の日も過ぎて、航海が危険な季節になっていたので、パウロは人々に忠告して、</span>
<span className="v" id="v10" data-v="10" data-xref="ダニエル書 2:30; 使徒の働き 27:20–26; 使徒の働き 27:41–44"> 言いました。「皆さん、この航海では積み荷や船だけでなく、私たちの命までも損なう、大きな被害が出ると私は見ています。」</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 33:4; ヘブル人への手紙 11:7; エゼキエル書 3:17–18"> しかし百人隊長は、パウロの言葉よりも、船長や船主の言うことを信用しました。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 107:30; 使徒の働き 27:8"> この港は冬を越すのに適していなかったので、大多数の者は、できればそこから船出し、フェニクスへ行って冬を越すことを勧めました。フェニクスは南西と北西に面したクレタ島の港です。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカ 12:55; 雅歌 4:16; ヨブ記 37:17"> 南風が穏やかに吹いてきたので、人々は計画どおりに行けると思い、錨を上げてクレタ島の海岸近くを航行しました。</span>
<span className="v" id="v14" data-v="14" data-xref="マルコ 4:37; 詩篇 107:25–27; 出エジプト記 14:21–27"> しかし間もなく、島から「ユーロクリドン」と呼ばれる暴風が吹き下ろして来ました。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「北東風」。">a</a></sup></span>
<span className="v" id="v15" data-v="15" data-xref="ヤコブの手紙 3:4; 使徒の働き 27:27"> 船は巻き込まれ、風に向かって進めなくなったので、私たちは流されるままにしました。</span>
<span className="v" id="v16" data-v="16"> クラウダという小さな島の風下を通り、ようやく小舟を確保することができました。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 27:29; 使徒の働き 27:26; 使徒の働き 27:41"> 船員たちは小舟を引き上げると、綱で船体を巻いて補強しました。また、スルティスの砂州に乗り上げるのを恐れ、海錨を降ろして流されるままにしました。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨナ書 1:5; 使徒の働き 27:38; マタイ 16:26"> 暴風にひどく苦しめられたので、翌日、人々は積み荷を海へ捨て始めました。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨブ記 2:4; ルカ 9:24–25; マルコ 8:35–37"> 三日目には、自分たちの手で船具を投げ捨てました。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイ 24:29; マタイ 8:24–25; エレミヤ書 2:25"> 何日もの間、太陽も星も見えず、激しい暴風が吹き荒れたので、ついには助かる望みがすべて失われました。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="創世記 42:22; 詩篇 107:5–6; 使徒の働き 27:7"> 長い間だれも食事を取らなかったので、パウロは人々の中に立って言いました。「皆さん、私の忠告に従ってクレタ島から出航しなければ、この被害と損失は避けられたのです。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 27:25; 使徒の働き 27:36; コリント人への第二の手紙 4:8–9"> しかし今、元気を出すよう勧めます。あなたがたのうち命を失う者は一人もいません。失われるのは船だけです。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 23:11; ローマ人への手紙 1:9; テモテへの第二の手紙 4:17"> 昨夜、私が属し、仕えている神の使いが私のそばに立ち、</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 23:11; テモテへの第二の手紙 4:16–17; マタイ 10:28"> こう言いました。『恐れることはない、パウロ。あなたはカエサルの前に立たなければならない。見よ、神はあなたと共に航海している人々を皆、あなたに与えてくださった。』</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 4:20–21; ルカ 1:45; 民数記 23:19"> ですから皆さん、元気を出してください。私は神を信じています。私に告げられたとおりになるからです。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 28:1; 使徒の働き 27:17; 使徒の働き 27:29"> ただし、私たちはどこかの島に乗り上げなければなりません。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ヨナ書 1:6; 使徒の働き 27:30; ヨハネの黙示録 18:17"> 十四日目の夜になり、私たちがアドリア海を漂流していた真夜中ごろ、船員たちはどこかの陸地に近づいていると感じました。</span>
<span className="v" id="v28" data-v="28"> 水深を測ると二十ファゾムでした。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="二十ファゾムは百二十フィート、すなわち36.6メートルである。">b</a></sup>少し進んでもう一度測ると、十五ファゾムでした。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="十五ファゾムは九十フィート、すなわち27.4メートルである。">c</a></sup></span>
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 27:17; ヘブル人への手紙 6:19; 申命記 28:67"> 岩礁に乗り上げることを恐れ、船尾から四つの錨を下ろし、夜が明けるのを待ち望みました。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 27:16; 使徒の働き 27:32"> ところが船員たちは、船首から錨を降ろすふりをして小舟を海へ下ろし、船から逃げようとしました。</span>
<span className="v" id="v31" data-v="31" data-xref="テサロニケ人への第二の手紙 2:13–14; 詩篇 91:11–12; エレミヤ書 29:11–13"> そこでパウロは百人隊長と兵士たちに言いました。「この人たちが船に残らなければ、あなたがたは助かりません。」</span>
<span className="v" id="v32" data-v="32" data-xref="ピリピ人への手紙 3:7–9; ルカ 16:8"> すると兵士たちは小舟の綱を切り、流れるに任せました。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 夜が明けかけたころ、パウロは皆に食事を取るよう勧めて言いました。「あなたがたは今日まで十四日間、何も食べずに待ち続けています。</span>
<span className="v" id="v34" data-v="34" data-xref="マタイ 10:30; 列王記第一 1:52; ルカ 21:18"> ですから、どうか食事を取ってください。それがあなたがたの無事のためになります。あなたがたの頭から髪の毛一本さえ失われないからです。」</span>
<span className="v" id="v35" data-v="35" data-xref="マタイ 15:36; コリント人への第一の手紙 10:30–31; テモテへの手紙第一 4:3–4"> こう言ってパンを取り、皆の前で神に感謝をささげ、それを裂いて食べ始めました。</span>
<span className="v" id="v36" data-v="36" data-xref="コリント人への第二の手紙 1:4–6; 使徒の働き 27:22; 詩篇 27:14"> そこで全員が元気を取り戻し、自分たちも食事を取りました。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒の働き 2:41; ローマ人への手紙 13:1; ペテロの手紙第一 3:20"> 船にいたのは、私たち全員で二百七十六人でした。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨナ書 1:5; マタイ 6:25; 使徒の働き 27:18–19"> 十分に食べると、小麦を海へ投げ捨て、船を軽くしました。</span>
<span className="v" id="v39" data-v="39" data-xref="使徒の働き 28:1"> 夜が明けても、どこの陸地か分かりませんでしたが、砂浜のある入り江を見つけました。そこで、できるなら船をそこに乗り上げようと決めました。</span>
<span className="v" id="v40" data-v="40" data-xref="イザヤ書 33:23; 使徒の働き 27:29–30"> 錨を切り離して海に捨て、同時に舵を縛っていた綱を解き、前帆を風に上げて砂浜へ向かいました。</span>
<span className="v" id="v41" data-v="41" data-xref="コリント人への第二の手紙 11:25–26; エゼキエル書 27:26; 使徒の働き 27:26–29"> しかし二つの潮流がぶつかる所に入り込み、船を浅瀬に乗り上げてしまいました。船首はめり込んで動かなくなり、船尾は激しい波によって壊れ始めました。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="マルコ 15:15–20; 伝道者の書 9:3; 詩篇 74:20"> 兵士たちは、囚人が泳いで逃げることのないよう、彼らを殺そうと相談しました。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒の働き 27:3; 箴言 16:7; 使徒の働き 27:11"> しかし百人隊長は、パウロを助けたいと思って彼らの計画を止めました。そして、泳げる者はまず海に飛び込み、陸へ向かうよう命じました。</span>
<span className="v" id="v44" data-v="44" data-xref="使徒の働き 27:22; 詩篇 107:28–30; ヨハネ 6:39–40"> 残りの者は、ある者は板に、ある者は船のほかの物につかまって続きました。こうして全員が無事に陸へ逃れました。</span>
</div>
</div>

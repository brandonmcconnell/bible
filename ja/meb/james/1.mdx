<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 12:15; ペテロの手紙第一 1:1; ヨハネ 7:35"> 神と主イエス・キリストに仕える者ヤコブから、離散している十二部族へ。あいさつを送ります。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「キリスト」は「油を注がれた者」という意味である。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ペテロの手紙第一 1:6–8; ヤコブの手紙 1:12; コリント人への第二の手紙 12:9–10"> 私の兄弟たち、さまざまな試練に直面するときは、それをこの上ない喜びと考えなさい。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ここや、文脈上可能な箇所で「兄弟たち」と訳される言葉は、「兄弟姉妹」または「きょうだいたち」と訳すこともできる。">b</a></sup></span>
<span className="v" id="v3" data-v="3" data-xref="ローマ人への手紙 5:3–4; ヘブル人への手紙 10:36; コロサイ人への手紙 1:11"> あなたがたの信仰が試されると忍耐が生み出されることを知っているからです。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカ 21:19; ペテロの手紙第一 5:10; マタイ 5:48"> 忍耐がその働きを全うするようにしなさい。そうすれば、あなたがたは成熟して完全な者となり、何一つ欠けることがありません。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="箴言 2:3–6; ヨハネ 15:7; 箴言 3:5–7"> あなたがたのうちに知恵に欠ける人がいるなら、すべての人に惜しみなく、責めることなく与えてくださる神に願い求めなさい。そうすれば、その人に知恵が与えられます。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイ 21:21–22; ヘブル人への手紙 11:6; マルコ 11:22–24"> ただ、少しも疑わず、信仰をもって願い求めなさい。疑う人は、風に吹かれ、揺れ動く海の波のようです。</span>
<span className="v" id="v7" data-v="7" data-xref="ヤコブの手紙 4:3; イザヤ書 58:3–4; 箴言 21:27"> そのような人は、主から何かをいただけると思ってはなりません。</span>
<span className="v" id="v8" data-v="8" data-xref="列王記第一 18:21; マタイ 6:24; ヤコブの手紙 4:8"> その人は二心のある人で、何をするにも定まりがありません。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 9:23–24; ヤコブの手紙 2:5–6; 箴言 19:1"> 低い境遇にある兄弟は、自分が高くされたことを誇りなさい。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの手紙第一 1:24; ヨハネの手紙第一 2:17; ヨブ記 14:2"> 富む人は、自分が低くされたことを誇りなさい。その人は草の花のように過ぎ去るからです。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 40:7–8; 詩篇 37:35–36; 詩篇 49:6–14"> 太陽が焼けつく風とともに昇ると、草は枯れ、花は落ち、その美しい姿も失われます。同じように、富む人も自分の営みの途中で消え去るのです。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ペテロの手紙第一 5:10; ペテロの手紙第一 1:6–8; ヨハネの黙示録 2:10"> 試練に耐える人は幸いです。その人は試練を経て認められた後、主がご自分を愛する人々に約束された、いのちの冠を受けるからです。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ハバクク書 2:12–13; ヤコブの手紙 1:12; ローマ人への手紙 9:19–20"> 誘惑を受けるとき、だれも「神に誘惑されている」と言ってはなりません。神は悪に誘惑されることがなく、またご自身がだれをも誘惑なさらないからです。</span>
<span className="v" id="v14" data-v="14" data-xref="マルコ 7:21–22; エペソ人への手紙 4:22; マタイ 15:18"> 人はそれぞれ、自分の欲望に引かれ、おびき寄せられるとき、誘惑を受けるのです。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 7:14; ヨブ記 15:35; ローマ人への手紙 5:12–21"> そして欲望がはらむと罪を産み、罪が成長しきると死を生みます。</span>
<span className="v" id="v16" data-v="16" data-xref="ガラテヤ人への手紙 6:7; ヤコブの手紙 1:19; ピリピ人への手紙 2:12"> 私の愛する兄弟たち、思い違いをしてはなりません。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネ 3:27; マタイ 7:11; ヘブル人への手紙 13:8"> 良い贈り物も完全な賜物も、すべて上から来るものであり、光の父から下って来ます。父には変化することも、移り変わる影もありません。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 8:29–31; ペテロの手紙第一 1:23; ヨハネ 3:3–5"> 神はご自分の御心によって、真理の言葉を通して私たちを生んでくださいました。それは、私たちが神の被造物の初穂のようになるためです。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="箴言 17:27; 箴言 21:23; 箴言 14:29"> ですから、私の愛する兄弟たち、一人一人、聞くには早く、語るには遅く、怒るにも遅くありなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="テモテへの第二の手紙 2:24–25; エペソ人への手紙 4:26; ヤコブの手紙 3:17–18"> 人の怒りは神の義をもたらさないからです。</span>
<span className="v" id="v21" data-v="21" data-xref="エペソ人への手紙 4:22; エペソ人への手紙 1:13; ペテロの手紙第一 2:11"> それゆえ、あらゆる汚れとはびこる悪を捨て去り、心に植えつけられた言葉を謙虚に受け入れなさい。その言葉には、あなたがたの魂を救う力があります。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="または、「あなたがたのいのちを守ることができます」。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 2:13; ルカ 6:46–48; ヨハネ 13:17"> 言葉を行う者となりなさい。ただ聞くだけで、自分を欺いてはなりません。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイ 7:26–27; エゼキエル書 33:31–32; ヤコブの手紙 2:14–26"> 言葉を聞いても行わない人は、鏡に映る自分の顔を眺める人に似ています。</span>
<span className="v" id="v24" data-v="24" data-xref="ペテロの第二の手紙 3:11; ルカ 1:66; ルカ 7:39"> 自分の姿を眺めても、そこを離れると、自分がどんな顔だったかをすぐに忘れてしまいます。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカ 11:28; ヨハネ 13:17; コリント人への第二の手紙 3:17–18"> しかし、自由をもたらす完全な律法を注意深く見つめ、そこにとどまる人は、聞いて忘れる者ではなく、実際に行う者です。その人は、その行いによって幸いになります。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="エペソ人への手紙 4:29; 詩篇 141:3; ペテロの手紙第一 3:10"> 自分は信心深いと思いながら舌を制御せず、自分の心を欺いている人がいるなら、その人の信心はむなしいものです。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 1:16–17; ヨハネの手紙第一 3:17–19; ガラテヤ人への手紙 6:9–10"> 私たちの父なる神の前で、純粋で汚れのない信心とは、苦しみの中にいる孤児ややもめを顧み、自分を世の汚れに染まらないよう守ることです。</span>
</div>

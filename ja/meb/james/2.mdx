<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 24:23; ヤコブの手紙 2:9; レビ記 19:15"> 私の兄弟たち、私たちの栄光の主イエス・キリストを信じる者として、人をえこひいきしてはなりません。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカ 15:22; エステル記 3:10; エステル記 8:2"> たとえば、あなたがたの会堂<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または、「集会」。">a</a></sup>に、金の指輪をはめ、立派な服を着た人が入って来て、汚れた服を着た貧しい人も入って来たとします。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 8:9; ヤコブの手紙 2:6; ルカ 7:44–46"> あなたがたが立派な服を着た人には特別に目を留めて、「こちらの良い席にお座りください」と言い、貧しい人には、「そこに立っていなさい」とか、「私の足台のそばに座りなさい」と言うなら、</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネ 7:24; ヨブ記 34:19; マタイ 7:1–5"> あなたがたは人を分け隔てし、悪い考えをもつ裁き手となっているのではありませんか。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイ 5:3; ルカ 6:20; ヨハネの黙示録 2:9"> 私の愛する兄弟たち、よく聞きなさい。神は、この世の貧しい人々を選んで信仰に富む者とし、ご自分を愛する人々に約束された王国の相続人とされたのではありませんか。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 17:5; コリント人への第一の手紙 11:22; 箴言 14:31"> それなのに、あなたがたは貧しい人を辱めています。あなたがたを虐げ、裁判所へ引きずって行くのは、富んでいる人たちではありませんか。</span>
<span className="v" id="v7" data-v="7" data-xref="ピリピ人への手紙 2:9–11; ヨハネの黙示録 13:5–6; テモテへの手紙第一 1:13"> あなたがたに与えられた尊い御名を冒瀆するのも、彼らではありませんか。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="レビ記 19:18; ガラテヤ人への手紙 5:14; マタイ 22:39"> それでも、聖書に従い、「あなたの隣人を自分自身のように愛しなさい」という王の律法を実行しているなら、あなたがたは正しく行っています。</span>
<span className="v" id="v9" data-v="9" data-xref="レビ記 19:15; ヤコブの手紙 2:1–4; ヨハネの手紙第一 3:4"> しかし、人をえこひいきするなら、あなたがたは罪を犯し、律法によって違反者と定められます。</span>
<span className="v" id="v10" data-v="10" data-xref="ガラテヤ人への手紙 3:10; マタイ 5:18–19; 申命記 27:26"> 律法全体を守っていても、その一つの点でつまずくなら、律法全体に違反した者となるからです。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 20:13–14; マタイ 5:21–28; 申命記 5:17–18"> 「姦淫してはならない」と言われた方は、「殺してはならない」とも言われました。ですから、姦淫しなくても人を殺すなら、あなたは律法の違反者となります。</span>
<span className="v" id="v12" data-v="12" data-xref="ヤコブの手紙 1:25; ヤコブの手紙 2:8; ペテロの第二の手紙 1:4–8"> 自由をもたらす律法によって裁かれる者らしく、語り、また行いなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイ 5:7; マタイ 6:15; 箴言 21:13"> あわれみを示さなかった者は、あわれみのない裁きを受けるからです。あわれみは裁きに打ち勝つのです。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マタイ 7:26–27; マタイ 7:21–23; ヤコブの手紙 1:22–25"> 私の兄弟たち、ある人が信仰を持っていると言っても、行いがないなら、何の役に立つでしょうか。その信仰がその人を救えるでしょうか。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカ 3:11; マタイ 25:35–40; イザヤ書 58:7"> 兄弟や姉妹が着る物もなく、日々の食べ物にも事欠いているのに、</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 3:27–28; ヨハネの手紙第一 3:16–18; マタイ 25:42–45"> あなたがたの一人が、「安心して行きなさい。暖かくして、十分に食べなさい」と言うだけで、体に必要な物を与えないなら、何の役に立つでしょうか。</span>
<span className="v" id="v17" data-v="17" data-xref="ヤコブの手紙 2:26; ペテロの第二の手紙 1:5–9; ヤコブの手紙 2:19–20"> それと同じように、信仰も行いがなければ、それ自体で死んでいます。</span>
<span className="v" id="v18" data-v="18" data-xref="ヤコブの手紙 3:13; ヤコブの手紙 2:14; ガラテヤ人への手紙 5:6"> しかし、ある人はこう言うでしょう。「あなたには信仰があり、私には行いがあります。」行いを抜きにして、あなたの信仰を私に見せてください。私は自分の行いによって、私の信仰をあなたに示しましょう。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ルカ 4:34; マルコ 1:24; マタイ 8:29"> あなたは、神はお一人だと信じています。それはよいことです。悪霊たちも信じて、震えています。</span>
<span className="v" id="v20" data-v="20" data-xref="ヤコブの手紙 2:17; ヤコブの手紙 2:26; 箴言 12:11"> 思慮のない人よ、行いを伴わない信仰が死んだものであることを知りたいのか。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 22:16–18; 創世記 22:9–12; ヨハネ 8:39"> 私たちの父祖アブラハムは、その子イサクを祭壇にささげたとき、行いによって義と認められたのではありませんか。</span>
<span className="v" id="v22" data-v="22" data-xref="テサロニケ人への手紙第一 1:3; ヘブル人への手紙 11:17–19; ガラテヤ人への手紙 5:6"> 分かるでしょう。信仰は彼の行いとともに働き、行いによって信仰は完成されたのです。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 15:6; イザヤ書 41:8; 歴代誌 第二 20:7"> こうして、「アブラハムは神を信じ、それが彼の義とみなされた」という聖書の言葉が成就し、彼は神の友と呼ばれました。</span>
<span className="v" id="v24" data-v="24" data-xref="ヤコブの手紙 2:21–22; ヤコブの手紙 2:15–18; 詩篇 60:12"> このように、人は行いによって義と認められるのであって、信仰だけによるのではないことが分かります。</span>
<span className="v" id="v25" data-v="25" data-xref="ヘブル人への手紙 11:31; ヨシュア記 6:22–25; ヨシュア記 2:19–21"> 同じように、遊女ラハブも使者たちを迎え入れ、別の道から送り出したとき、行いによって義と認められたのではありませんか。</span>
<span className="v" id="v26" data-v="26" data-xref="ヤコブの手紙 2:20; ヤコブの手紙 2:17; ヤコブの手紙 2:14"> 霊のない体が死んでいるように、行いを伴わない信仰も死んでいるのです。</span>
</div>

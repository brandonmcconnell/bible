<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヤコブの手紙 1:1; 使徒の働き 2:5–11; ヘブル人への手紙 11:13"> イエス・キリスト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「キリスト」は「油を注がれた者」という意味である。">a</a></sup>の使徒ペテロから、ポント、ガラテヤ、カパドキア、アジア、ビティニアに離散し、寄留者として暮らす選ばれた人々へ。</span>
<span className="v" id="v2" data-v="2" data-xref="テサロニケ人への第二の手紙 2:13; エペソ人への手紙 1:4–5; ヘブル人への手紙 12:24"> あなたがたは、父なる神の予知に基づき、御霊による聖別を受け、イエス・キリストに従い、その血を振りかけられるために選ばれました。恵みと平安が、あなたがたにますます豊かにありますように。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ペテロの手紙第一 1:23; ヨハネの手紙第一 5:4; ローマ人への手紙 15:13"> 私たちの主イエス・キリストの父なる神が、ほめたたえられますように。神はその豊かなあわれみにより、イエス・キリストが死者の中から復活されたことによって、私たちを新しく生まれさせ、生ける望みを与えてくださいました。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 21:27; ヘブル人への手紙 9:15; ペテロの手紙第一 5:4"> また、朽ちず、汚れず、色あせることのないものを受け継ぐようにしてくださいました。それは、あなたがたのために天に蓄えられています。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 1:6; エペソ人への手紙 2:8; テサロニケ人への第二の手紙 2:13–14"> あなたがたは、終わりの時に現されるために用意されている救いを受けるよう、信仰を通して神の力に守られています。</span>
<span className="v" id="v6" data-v="6" data-xref="ヤコブの手紙 1:2; ペテロの手紙第一 5:10; ローマ人への手紙 12:12"> あなたがたは、この救いを大いに喜んでいます。今しばらくの間、必要があって、さまざまな試練によって悲しまなければならないとしても、</span>
<span className="v" id="v7" data-v="7" data-xref="ヨブ記 23:10; イザヤ書 48:10; ペテロの手紙第一 4:12"> 火で精錬されても朽ちる金よりはるかに尊いあなたがたの信仰が、試練を経て真実であると認められ、イエス・キリストが現れる時に、称賛と栄光と誉れをもたらすためです。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネ 20:29; コリント人への第二の手紙 5:7; ローマ人への手紙 15:13"> あなたがたは、この方に直接お会いしたことがなくても愛しています。今は見ていなくても信じ、言葉では言い表せない、栄光に満ちた喜びにあふれています。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 6:22; ヤコブの手紙 1:21; ヘブル人への手紙 11:13"> 信仰の結末である、魂の救いを受けているからです。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="マタイ 13:17; ルカ 10:24; ルカ 24:25–27"> この救いについて、預言者たちは熱心に探り、詳しく調べました。彼らは、あなたがたに与えられる恵みについて預言し、</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 52:13–14; ペテロの第二の手紙 1:21; ルカ 24:25–27"> 自分たちのうちにおられるキリストの霊が、キリストの苦難と、それに続く栄光とを前もって示された時、それがだれを、またどのような時を指しているのかを調べました。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネ 15:26; コリント人への第一の手紙 2:10; エペソ人への手紙 3:10"> 彼らがこれらのことによって仕えていたのは、自分たちのためではなく、あなたがたのためであることが示されました。そして今、それらのことは、天から遣わされた聖霊によって福音を宣べ伝えた人々を通して、あなたがたに告げ知らされました。御使いたちも、これらのことをのぞき込みたいと願っています。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ペテロの手紙第一 5:8; ルカ 12:35; ペテロの手紙第一 4:7"> ですから、心を引き締めて行動に備えなさい。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="直訳では、「心の腰に帯を締めなさい」または「心の腰の帯を着けなさい」。">b</a></sup>身を慎み、イエス・キリストが現れる時にもたらされるその恵みに、すべての望みを置きなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 12:2; テトス 3:3–5; ペテロの手紙第一 4:2–3"> 従順な子どもとして、無知であったころに抱いていた欲望に、自分を合わせてはなりません。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイ 5:48; コリント人への第二の手紙 7:1; ヘブル人への手紙 12:14"> むしろ、あなたがたを召された方が聖なる方であるように、あなたがた自身も、あらゆる行いにおいて聖なる者となりなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="レビ記 11:44; レビ記 19:2; レビ記 20:7"> 「あなたがたは聖なる者でありなさい。わたしが聖なる者だからである」と書かれているからです。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 10:34–35; 歴代誌 第二 19:7; マタイ 6:9"> 一人ひとりの行いに応じて、分け隔てなく裁かれる方を父と呼ぶのであれば、寄留者として過ごす間を、畏れをもって過ごしなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 6:20; テトス 2:14; 詩篇 49:7–8"> あなたがたが先祖から受け継いだむなしい生き方から贖われたのは、銀や金のような朽ちるものによったのではありません。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの手紙第一 1:7; ペテロの手紙第一 2:22–24; ヨハネ 1:29"> 傷も汚れもない子羊の血のような、キリストの尊い血によったのです。</span>
<span className="v" id="v20" data-v="20" data-xref="エペソ人への手紙 1:4; テモテへの第二の手紙 1:9–10; ヘブル人への手紙 9:26"> キリストは、世界の基が据えられる前からあらかじめ知られていましたが、この終わりの時代に、あなたがたのために現されました。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 2:24; ヘブル人への手紙 2:9; ヨハネ 12:44"> あなたがたは、この方を通して、この方を死者の中から復活させ、栄光をお与えになった神を信じています。こうして、あなたがたの信仰と望みは神に置かれているのです。</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="テモテへの手紙第一 1:5; ヘブル人への手紙 13:1; ローマ人への手紙 12:9–10"> あなたがたは、聖霊によって真理に従い、自分の魂を清め、偽りのない兄弟愛を抱くようになったのですから、心から熱く互いに愛し合いなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="ペテロの手紙第一 1:3; ヘブル人への手紙 4:12; ヨハネ 1:13"> あなたがたは、朽ちる種からではなく、朽ちない種から、すなわち、いつまでも生きて残る神の言葉によって、新しく生まれたのです。</span>
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 40:6–8; 詩篇 103:15; ヤコブの手紙 4:14"> 聖書にこうあります。<br /><span className="pl pl-1">「すべての肉なる者は草のようであり、</span><br /><span className="pl pl-2">人の栄光はすべて草の花のようである。</span><br /><span className="pl pl-1">草は枯れ、花は散る。</span></span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 40:8; マタイ 5:18; 詩篇 119:89"> <span className="pl pl-2">しかし、主の言葉は永遠に残る。」</span><br />これが、あなたがたに福音として宣べ伝えられた言葉です。</span>
</div>

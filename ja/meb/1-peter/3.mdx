<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 3:18; エペソ人への手紙 5:33; エペソ人への手紙 5:22–24"> 同じように、妻たちよ、自分の夫に従いなさい。そうすれば、御言葉に従わない夫がいても、妻の振る舞いによって、言葉によらずとも心を動かされるでしょう。</span>
<span className="v" id="v2" data-v="2" data-xref="ペテロの手紙第一 2:12; ペテロの手紙第一 1:15; ピリピ人への手紙 1:27"> 彼らは、神を畏れるあなたがたの清い振る舞いを目にするからです。</span>
<span className="v" id="v3" data-v="3" data-xref="テモテへの手紙第一 2:9–10; ローマ人への手紙 12:2; イザヤ書 3:18–24"> あなたがたの美しさは、髪を編むこと、金の飾りを身に着けること、美しい服を着ることといった外面的な装いにあるのではありません。</span>
<span className="v" id="v4" data-v="4" data-xref="コロサイ人への手紙 3:12; サムエル記第一 16:7; ローマ人への手紙 2:29"> むしろ、心の内なる人を、柔和で穏やかな霊という朽ちることのないもので飾りなさい。これは、神の目に非常に尊いものです。</span>
<span className="v" id="v5" data-v="5" data-xref="テトス 2:3–4; テモテへの手紙第一 5:5; ルカ 2:37"> 昔、神に望みを置いた聖なる女性たちも、このように自分を飾り、自分の夫に従いました。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 18:12; ローマ人への手紙 9:7–9; イザヤ書 57:11"> サラもアブラハムに従い、彼を「主人」と呼びました。あなたがたも、良いことを行い、何を恐れることもないなら、サラの子どもたちなのです。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="コロサイ人への手紙 3:19; 創世記 2:23–24; マタイ 19:3–9"> 同じように、夫たちよ、理解をもって妻と共に暮らしなさい。妻はより弱い器であり、また命の恵みを共に受け継ぐ者なのですから、妻を尊びなさい。それは、あなたがたの祈りが妨げられないためです。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 12:10; エペソ人への手紙 4:31–2; ペテロの手紙第一 1:22"> 最後に、あなたがたは皆、心を一つにし、互いに思いやり、兄弟として愛し合い、心を優しくし、礼節を重んじなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 20:22; ローマ人への手紙 12:17; ローマ人への手紙 12:14"> 悪に悪を返したり、侮辱に侮辱を返したりせず、かえって祝福しなさい。あなたがたは、祝福を受け継ぐために召されたのだと知っているからです。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 34:12–16; ヤコブの手紙 1:26; ペテロの手紙第一 2:1"> というのも、こう書かれているからです。<br /><span className="pl pl-1">「命を愛し、</span><br /><span className="pl pl-2">良い日々を見たいと願う者は、</span><br /><span className="pl pl-1">舌を悪から守り、</span><br /><span className="pl pl-2">唇で欺きを語ってはならない。</span></span>
<span className="v" id="v11" data-v="11" data-xref="マタイ 5:9; 詩篇 34:14; ヘブル人への手紙 12:14"> <span className="pl pl-1">悪を離れて善を行い、</span><br /><span className="pl pl-2">平和を求めて追い求めよ。</span></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 34:15–16; ヨハネ 9:31; 箴言 15:29"> <span className="pl pl-1">主の目は義人たちに注がれ、</span><br /><span className="pl pl-2">その耳は彼らの祈りに傾けられる。</span><br /><span className="pl pl-2">しかし、主の御顔は悪を行う者たちに敵対する。」</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 16:7; ローマ人への手紙 8:28; テサロニケ人への手紙第一 5:15"> あなたがたが善に倣う者となるなら、だれがあなたがたに害を加えるでしょうか。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイ 10:28; ペテロの手紙第一 2:19–20; マタイ 5:10–12"> たとえ義のために苦しむことがあっても、あなたがたは幸いです。「彼らが恐れるものを恐れず、心を乱してはならない」。</span>
<span className="v" id="v15" data-v="15" data-xref="コロサイ人への手紙 4:6; テモテへの第二の手紙 2:25–26; ルカ 21:14–15"> むしろ、心の中で主なる神を聖なる方としなさい。あなたがたのうちにある望みの理由を尋ねる人には、いつでも答えられる用意をしていなさい。ただし、柔和さと畏れをもって答えなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="ペテロの手紙第一 2:12; ヘブル人への手紙 13:18; ペテロの手紙第一 2:15"> また、良い良心を保ちなさい。そうすれば、あなたがたが悪人であるかのように非難されても、キリストにあるあなたがたの良い生き方を侮辱する人々は恥じ入ることになります。</span>
<span className="v" id="v17" data-v="17" data-xref="ペテロの手紙第一 3:14; ペテロの手紙第一 4:19; マタイ 26:39"> 神の御心であるなら、悪を行って苦しむよりも、正しいことを行って苦しむほうがよいのです。</span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 9:28; ヘブル人への手紙 9:26; コリント人への第二の手紙 5:21"> キリストもまた、罪のためにただ一度苦しまれました。正しい方が正しくない者たちのために苦しまれたのは、あなたがたを神のもとへ導くためでした。キリストは肉において殺されましたが、霊において生かされ、</span>
<span className="v" id="v19" data-v="19" data-xref="ペテロの手紙第一 4:6; イザヤ書 61:1; イザヤ書 42:7"> こうして、牢獄にいる霊たちのもとへも行き、宣べ伝えられました。</span>
<span className="v" id="v20" data-v="20" data-xref="ヘブル人への手紙 11:7; ペテロの第二の手紙 2:5; 創世記 6:3"> 彼らは、かつてノアの時代に箱舟が造られていた間、神が忍耐して待っておられた時に従わなかった者たちです。その箱舟の中では、わずかな人々、すなわち八人だけが、水を通って救われました。</span>
<span className="v" id="v21" data-v="21" data-xref="マルコ 16:16; エゼキエル書 36:25–26; 使徒の働き 2:38"> この水に対応するバプテスマが、今あなたがたを救います。それは肉体の汚れを取り除くことではなく、イエス・キリストの復活を通して、神に対する良い良心からの応答です。</span>
<span className="v" id="v22" data-v="22" data-xref="ヘブル人への手紙 9:24; ヘブル人への手紙 12:2; ヘブル人への手紙 10:12"> キリストは天に上り、神の右におられます。御使いたちも、権威も、力も、この方に従っています。</span>

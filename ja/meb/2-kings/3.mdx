<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王記第二 1:17; 列王記第一 22:51; 列王記第二 8:16"> ユダの王ヨシャファテの第十八年に、アハブの息子エホラムがサマリアでイスラエルの王となり、十二年間治めた。</span>
<span className="v" id="v2" data-v="2" data-xref="列王記第二 10:18; 列王記第二 10:26–28; 列王記第一 21:25"> 彼は主の目に悪とされることを行ったが、彼の父や彼の母のようではなかった。彼は父が造ったバアルの柱を取り除いたからである。</span>
<span className="v" id="v3" data-v="3" data-xref="列王記第一 14:16; 列王記第一 15:34; 列王記第二 15:18"> それでも彼は、イスラエルに罪を犯させたネバテの子ヤロブアムの罪に固執し、そこから離れなかった。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="サムエル記第二 8:2; 創世記 26:13–14; ヨブ記 1:3"> さて、モアブの王メシャは羊を飼う者であった。彼はイスラエルの王に、十万匹の子羊と十万頭の雄羊の羊毛を納めていた。</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第二 1:1; 列王記第二 8:20; 歴代誌 第二 21:8–10"> しかしアハブが死ぬと、モアブの王はイスラエルの王に背いた。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記第二 24:1–25; サムエル記第一 11:8; サムエル記第一 15:4"> その時、エホラム王はサマリアから出て行き、全イスラエルを召集した。</span>
<span className="v" id="v7" data-v="7" data-xref="列王記第一 22:4; 歴代誌 第二 22:10–12; 歴代誌 第二 18:3"> 彼は行ってユダの王ヨシャファテのところに人を遣わして言った。「モアブの王がわたしに背いた。あなたはわたしと一緒にモアブへ戦いに行くか。」<br />ヨシャファテは答えた。「行こう。わたしとあなた、わたしの民とあなたの民、わたしの馬とあなたの馬は一つだ。」</span>
<span className="v" id="v8" data-v="8" data-xref="マラキ書 1:2–3; 民数記 21:4"> 彼は言った。「どの道を上って行こうか。」<br />彼は答えた。「エドムの荒野の道である。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王記第一 22:47; 民数記 20:2; 出エジプト記 17:1"> こうしてイスラエルの王、ユダの王、そしてエドムの王は出発した。彼らは七日間の道のりを回り道して行った。その軍勢のためにも、彼らに従う家畜のためにも水がなかった。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 78:34–36; イザヤ書 51:20; イザヤ書 8:21"> イスラエルの王は言った。「ああ、主はこの三人の王を呼び集めて、彼らをモアブの手に引き渡されるのか。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王記第一 22:7; 列王記第一 19:21; 列王記第二 3:3"> しかしヨシャファテは言った。「ここには、われわれが彼を通して主に伺いを立てることができるような主の預言者がいないのか。」<br />イスラエルの王のしもべの一人が答えた。「ここには、エリヤの手に水を注いだ、シャファテの息子エリシャがいます。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王記第二 5:15; 列王記第二 2:21; イザヤ書 60:14"> ヨシャファテは「主の言葉は彼とともにある」と言った。そこでイスラエルの王とヨシャファテ、およびエドムの王は彼のところへ下って行った。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王記第一 22:6; 列王記第一 18:19; 列王記第一 22:10–11"> エリシャはイスラエルの王に言った。「わたしがあなたと何のかかわりがあるのか。あなたの父の預言者たちと、あなたの母の預言者たちのところへ行きなさい。」<br />イスラエルの王は彼に言った。「いや、主はこの三人の王を呼び集めて、彼らをモアブの手に引き渡されるからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王記第二 5:16; 列王記第一 17:1; 歴代誌 第二 19:3–4"> エリシャは言った。「わたしが仕える万軍の主は生きておられる。もしユダの王ヨシャファテへの敬意がなければ、わたしはあなたを顧みることも、目を向けることもなかった。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記第一 16:23; エペソ人への手紙 5:18–19; エゼキエル書 1:3"> しかし今、楽人をわたしのところに連れて来なさい。」<br />楽人が奏でたとき、主の御手が彼の上に臨んだ。</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 2:16–18; 列王記第二 4:3"> 彼は言った。「主はこう言われる。『この谷に溝をいくつも掘れ。』</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 107:35; イザヤ書 41:17–18; イザヤ書 48:21"> 主はこう言われる。『風も見ず、雨も見ないのに、この谷は水で満たされる。あなたがたも、家畜も、荷を負う動物も飲むことができる。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 32:27; ルカ 1:37; エレミヤ書 32:17"> これは主にとって小さなことだ。主はモアブ人をもあなたがたの手に渡される。</span>
<span className="v" id="v19" data-v="19" data-xref="列王記第二 13:17; 申命記 20:19–20; 士師記 6:16"> あなたがたはすべての防備の町と良い町を打ち、良い木を切り倒し、泉をふさぎ、肥沃な土地を石で荒らす。』」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 29:39–40; ダニエル書 9:21; 列王記第一 18:36"> 翌朝、ささげ物を献げるころ、エドムの方から水が流れて来て、その地は水で満たされた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="エペソ人への手紙 6:14; 列王記第一 20:11"> さて、すべてのモアブ人は王たちが自分たちと戦うために上って来たことを聞き、武具を身に着けられる者を若い者から年長者まで皆集め、国境に立った。</span>
<span className="v" id="v22" data-v="22"> 彼らが朝早く起きると、太陽が水の上に輝いており、モアブ人は向かいにある水が血のように赤いのに気づいた。</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 5:30; 出エジプト記 15:9; イザヤ書 10:14"> 彼らは言った。「これは血だ。王たちは確かに滅ぼされ、互いに打ち合ったのだ。それなら今、モアブよ、略奪だ！」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="テサロニケ人への手紙第一 5:3–4; ヨシュア記 8:20–22; 士師記 20:40–46"> 彼らがイスラエルの陣営に来ると、イスラエル人は立ち上がってモアブ人を打ったので、彼らは彼らの前から逃げた。彼らはさらに進んでモアブ人を打ちながらその地に入った。</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 16:7; エレミヤ書 48:36; エレミヤ書 48:31"> 彼らは町々を破壊し、肥沃な畑には一人一つずつ石を投げ込んで覆い尽くした。また、すべての泉をふさぎ、良い木を切り倒した。キル・ハレセテには石造りの町だけが残ったが、石投げの兵たちが取り囲んで攻めた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王記第二 3:9; アモス書 2:1"> モアブの王は戦いが自分にとって激しすぎるのを見ると、エドムの王のところへ突破するために、剣を抜く七百人の男たちを自分とともに引き連れたが、彼らはできなかった。</span>
<span className="v" id="v27" data-v="27" data-xref="ミカ書 6:7; 申命記 12:31; 士師記 11:31"> それから彼は自分の代わりに王となるはずであった長男を取り、城壁の上で彼を全焼のささげ物としてささげた。イスラエルに対して激しい怒りが起こり、彼らは彼から離れ去り、自分たちの地へ帰った。</span>
</div>
</div>

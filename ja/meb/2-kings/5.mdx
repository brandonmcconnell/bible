<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="2KI" data-book-slug="2-kings" data-book-name="列王記第二" data-chapter="5" data-verses="27">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカ 4:27; ローマ人への手紙 15:18; 箴言 21:31"> アラムの王の軍の長ナアマンは、主君から重く用いられ、尊敬を受けていた。主が彼を通してアラムに勝利を与えられたからである。彼は力ある勇士であったが、規定の病に冒されていた。</span>
<span className="v" id="v2" data-v="2" data-xref="列王記第二 6:23; 列王記第二 13:20; サムエル記第一 13:17–18"> アラム人は略奪隊として出て行き、イスラエルの地から一人の若い娘を捕らえてきていた。彼女はナアマンの妻に仕えていた。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 26:29; ルカ 17:12–14; 民数記 11:29"> 彼女は女主人に言った。「わたしの主人がサマリアにいる預言者のところに行けたらよいのに。そうすれば、彼は主人の規定の病をいやしてくれるでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 1:26–27; ヨハネ 4:28–29; ヨハネ 1:42–46"> ある者が主君のもとに行き、「イスラエルの地から来た娘が、このように申しております」と告げた。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="士師記 14:12; 列王記第二 8:8–9; 民数記 22:17–18"> アラムの王は言った。「行きなさい。わたしもイスラエルの王に手紙を送ろう。」彼は銀十タラント<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一タラントは約30キログラム、または約66ポンドである。">a</a></sup>、金六千枚、それに十着の着替えを持って出発した。</span>
<span className="v" id="v6" data-v="6"> ナアマンがイスラエルの王に届けた手紙には、こう記されていた。「この手紙とともに、わたしのしもべナアマンをあなたのもとに遣わす。彼の規定の病をいやしていただきたい。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="サムエル記第一 2:6; 列王記第一 20:7; 創世記 30:2"> イスラエルの王はその手紙を読むと、自分の服を引き裂いて言った。「わたしは、人を殺したり生かしたりする神なのか。あの王は、人の規定の病をいやすようにと、わたしのところに人を遣わしてきた。どうか、彼がわたしに言いがかりをつけようとしていることを、よく考え、見極めてほしい。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王記第一 18:36–37; ホセア書 12:13; エゼキエル書 2:5"> 神の人エリシャは、イスラエルの王が服を引き裂いたことを聞くと、王に人を遣わして言った。「なぜあなたは服を引き裂いたのですか。彼をわたしのところに来させてください。そうすれば、彼はイスラエルに預言者がいることを知るでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 16:37–39; 列王記第二 6:32; イザヤ書 60:14"> そこでナアマンは馬と戦車とともに来て、エリシャの家の戸口に立った。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネ 9:7; コリント人への第一の手紙 6:11; レビ記 14:7"> エリシャは彼に使者を遣わして言った。「行って、ヨルダン川で七回身を洗いなさい。そうすれば、あなたの肉は元通りになり、あなたはきよくなる。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="マタイ 15:27; ルカ 14:11; マタイ 8:8"> しかしナアマンは怒って立ち去り、言った。「わたしは、あの人がきっと出て来て立ち、その神、主の名を呼び、患部の上で手を動かして、この病をいやすものと思っていた。</span>
<span className="v" id="v12" data-v="12" data-xref="マルコ 1:9; 列王記第二 5:17; 列王記第二 2:14"> ダマスコの川であるアバナやパルパルは、イスラエルのすべての水よりも良いではないか。わたしはそれらの中で身を洗い、きよくなることができないというのか。」こうして彼は向きを変え、怒って去って行った。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王記第二 6:21; 列王記第二 13:14; 列王記第二 2:12"> 彼のしもべたちは近づいて彼に語った。「わが父よ。もし預言者があなたに何か大きなことを命じたなら、あなたはなさったのではありませんか。まして彼があなたに、『身を洗え。そうすればきよくなる』と言っただけなら、なおさらではありませんか。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ヨブ記 33:25; ルカ 4:27; ルカ 5:13"> そこで彼は下って行き、神の人の言葉にしたがって、ヨルダン川に七回身を浸した。すると彼の肉は幼い子どもの肉のように元通りになり、彼はきよくなった。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ダニエル書 2:47; ダニエル書 6:26–27; ヨシュア記 2:9–11"> ナアマンは供の者を皆連れて神の人のもとに戻り、その前に立って言った。「今、イスラエルのほか、全地のどこにも神がおられないことが分かりました。どうか、あなたのしもべから贈り物を受け取ってください。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王記第二 5:26; 列王記第二 5:20; 列王記第二 3:14"> しかし彼は言った。「わたしがその御前に立っている主は生きておられる。わたしは受け取らない。」彼は彼に受け取るようにと強く勧めたが、彼は拒んだ。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 26:18; 列王記第二 5:12; ローマ人への手紙 14:1"> ナアマンは言った。「そうされないのでしたら、どうかあなたのしもべに、ろば二頭分の土を与えてください。あなたのしもべは今後、主以外の他の神々に全焼のささげ物やいけにえをささげることはしないからです。</span>
<span className="v" id="v18" data-v="18" data-xref="列王記第二 7:2; 列王記第二 7:17; 列王記第二 17:35"> ただ、この一事については、主があなたのしもべを赦してくださいますように。わたしの主君が礼拝のためリモンの神殿に入り、わたしの腕に寄りかかるので、わたしもそこで身をかがめなければなりません。わたしがリモンの神殿で身をかがめることを、どうか主が赦してくださいますように。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="サムエル記第一 1:17; マルコ 5:34; 出エジプト記 4:18"> 彼は彼に、「平安のうちに行きなさい」と言った。こうして彼は彼から少しの道のりを去って行った。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王記第二 4:12; 列王記第二 4:31; 列王記第二 6:31"> しかし神の人エリシャのしもべゲハジは考えた。「主人は、あのアラム人ナアマンが持って来たものを受け取らず、ただで帰してしまった。主は生きておられる。彼の後を追い、何かをもらってこよう。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ルカ 7:6–7; 列王記第二 9:17–22; 列王記第二 4:26"> そこでゲハジはナアマンの後を追った。ナアマンは彼が自分の後を走って来るのを見ると、戦車から下りて彼を迎え、「無事か」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="列王記第二 5:5; イザヤ書 59:3; 使徒の働き 5:3–4"> ゲハジは答えた。「無事です。主人がわたしを遣わして申しました。『たった今、エフライムの山地から預言者の子らの若者が二人訪ねて来た。どうか彼らに、銀一タラント<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一タラントは約30キログラム、または約66ポンドである。">b</a></sup>と着替え二着を与えてほしい。』」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王記第二 12:10; 列王記第一 20:7; 列王記第二 2:17"> ナアマンは、「どうか、二タラントを受け取ってくれ」と言った。彼は彼に強く勧め、二タラントの銀を二つの袋に縛り入れ、二着の着替えとともに二人のしもべに載せた。彼らはゲハジの前でそれらを運んだ。</span>
<span className="v" id="v24" data-v="24" data-xref="列王記第一 21:16; ヨシュア記 7:11–12; ヨシュア記 7:1"> ゲハジが丘に着くと、彼は彼らの手からそれらを取り、家の中にしまい込んだ。そして彼は男たちを去らせ、彼らは去って行った。</span>
<span className="v" id="v25" data-v="25" data-xref="列王記第二 5:22; 創世記 16:8; 箴言 30:20"> それから彼は入って行き、主人の前に立った。エリシャは彼に言った。「ゲハジ、どこから来たのか。」<br />彼は「あなたのしもべはどこへも行きませんでした」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="コロサイ人への手紙 2:5; コリント人への第一の手紙 5:3; 列王記第二 6:12"> エリシャは言った。「あの男が戦車から降りてあなたを迎えたとき、わたしの心もそこに行っていたではないか。今は銀や衣服、オリーブ畑、ぶどう畑、羊、牛、男女の奴隷を受け取る時なのか。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 4:6; 民数記 12:10; 列王記第二 15:5"> それゆえ、ナアマンの規定の病は、あなたとあなたの子孫<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="または「種」。">c</a></sup>に永久にまといつく。」ゲハジは、雪のように白く病に冒されて、エリシャの前から出て行った。</span>
</div>
</div>

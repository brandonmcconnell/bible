<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王記第一 21:27; 列王記第二 18:37; 歴代誌 第二 32:20–22"> ヒゼキヤ王はそれを聞いたとき、自分の服を引き裂き、粗布を体にまとって、主の家に入った。</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 1:1; イザヤ書 2:1; マタイ 4:14"> 彼は家を管理するエリアキム、書記官シェブナ、および祭司の長老たちに粗布をまとわせて、アモツの息子である預言者イザヤのもとに遣わした。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 30:5–7; イザヤ書 66:9; ホセア書 13:13"> 彼らはイザヤに言った。「ヒゼキヤはこう申しております。『今日は苦難と懲らしめと辱めの日です。子どもが産道まで来ているのに、産み出す力がありません。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記第二 16:12; ローマ人への手紙 9:27; ヨシュア記 14:12"> あなたの神、主が、生ける神をそしるためにその主君であるアッシリアの王が遣わしたラブシャケのすべての言葉を聞き、あなたの神、主が聞かれたその言葉を責めてくださるかもしれない。それゆえ、生き残っている者たちのために祈ってほしい。』」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> こうして、ヒゼキヤ王のしもべたちはイザヤのところに来た。</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第二 18:35; 列王記第二 18:17; イザヤ書 37:6–38"> イザヤは彼らに言った。「あなたがたの主君にこう言いなさい。『主はこう言われる。「アッシリアの王のしもべたちがわたしを冒涜した、あなたが聞いた言葉を恐れてはならない。</span>
<span className="v" id="v7" data-v="7" data-xref="オバデヤ書 1:1; 列王記第二 7:6; 詩篇 18:14–15"> わたしは彼のうちに一つの思いを起こす。彼はある知らせを聞いて自分の国へ帰る。わたしは彼を、その国で剣に倒れさせる。」』」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王記第二 18:14; ヨシュア記 10:29; ヨシュア記 12:11"> ラブシャケが帰って行くと、アッシリアの王がリブナと戦っているのを見つけた。彼がラキシュから去ったと聞いたからである。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記第一 23:27; イザヤ書 37:9; 列王記第二 18:17"> セナケリブは、「エチオピアの王ティルハカがあなたと戦うために出て来た」との知らせを聞き、再び使者をヒゼキヤに遣わして言った。</span>
<span className="v" id="v10" data-v="10" data-xref="列王記第二 18:5; 列王記第二 18:29–30; 歴代誌 第二 32:15–19"> 「あなたがたはユダの王ヒゼキヤにこう言え。『あなたが頼みとしているあなたの神が、「エルサレムはアッシリアの王の手に引き渡されることはない」と言ってあなたを欺かせてはならない。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 10:8–11; 歴代誌 第二 32:13–14; 列王記第二 19:17–18"> あなたは、アッシリアの王たちが諸国を完全に滅ぼしたことを聞いているはずだ。それでも自分だけは救われると思うのか。</span>
<span className="v" id="v12" data-v="12" data-xref="列王記第二 17:6; 創世記 11:31; エゼキエル書 27:23"> わたしの先祖が滅ぼした諸国の神々は、彼らを救い出しただろうか。ゴザン、ハラン、レツェフ、そしてテラサルにいたエデンの子らを。</span>
<span className="v" id="v13" data-v="13" data-xref="列王記第二 18:34; 列王記第二 17:24; イザヤ書 11:11"> ハマテの王、アルパドの王、セファルワイムの町の王、ヘナの王、イワの王はどこにいるか。』」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 37:14; 詩篇 91:1–2; 詩篇 123:1–4"> ヒゼキヤは使者たちの手から手紙を受け取り、それを読んだ。それからヒゼキヤは主の家へ上って行き、それを主の前に広げた。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 44:6; 列王記第二 5:15; ダニエル書 4:34–35"> ヒゼキヤは主の御前で祈って言った。「ケルビムの上に座しておられるイスラエルの神、主よ。あなたこそ、ただあなただけが、地上のすべての王国の神です。あなたが天と地を造られました。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代誌 第二 6:40; 詩篇 31:2; 列王記第二 19:4"> 主よ、耳を傾けて聞いてください。主よ、目を開いて見てください。生ける神をそしるために彼が送ったセナケリブの言葉を聞いてください。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代誌上 5:26; ヨブ記 9:2; コリント人への第一の手紙 14:25"> 主よ、確かにアッシリアの王たちは諸国とその地を荒れ廃れさせ、</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 17:29; イザヤ書 44:9–20; エレミヤ書 10:3–9"> 彼らの神々を火に投げ込みました。それらは神々ではなく、人の手のわざ、木や石にすぎなかったからです。それゆえ、彼らはそれらを滅ぼしたのです。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 83:18; 列王記第一 8:43; 詩篇 67:1–2"> 今、われわれの神、主よ、どうか彼の手から救ってください。そうすれば、地上のすべての王国は、主よ、あなただけが神であると知るでしょう。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="列王記第二 20:5; 歴代誌 第二 32:20–21; エレミヤ書 33:3"> アモツの息子イザヤはヒゼキヤに人を遣わして言った。「イスラエルの神、主はこう言われる。『あなたがアッシリアの王セナケリブについてわたしに祈ったことを、わたしは聞いた。』</span>
<span className="v" id="v21" data-v="21" data-xref="哀歌 2:13; ヨブ記 16:4; エレミヤ書 14:17"> これが、主が彼について語られた言葉である。<br /><span className="pl pl-1">『処女であるシオンの娘は、あなたをさげすみ、あなたをあざ笑った。</span><br /><span className="pl pl-2">エルサレムの娘は、あなたの後ろで頭を振った。</span></span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 5:24; 詩篇 71:22; イザヤ書 30:11–12"> <span className="pl pl-1">あなたはだれをそしり、冒涜したのか。</span><br /><span className="pl pl-2">あなたはだれに向かって声を上げ、目を高く上げたのか。</span><br /><span className="pl pl-2">イスラエルの聖なる方に向かってではないか。</span></span>
<span className="v" id="v23" data-v="23" data-xref="列王記第二 18:17; 詩篇 20:7; イザヤ書 10:18"> <span className="pl pl-1">あなたは自分の使者たちによって主をそしり、そして言った。</span><br /><span className="pl pl-2">「数多くの戦車を率いて、わたしは山々の頂、レバノンの奥深くまで上った。</span><br /><span className="pl pl-2">わたしはその高い杉の木と、選び抜かれた糸杉の木を切り倒し、</span><br /><span className="pl pl-2">その果ての高み、その豊かな森に入る。</span></span>
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 19:6; 出エジプト記 15:9; サムエル記第二 17:13"> <span className="pl pl-1">わたしは井戸を掘り、異国の水を飲んだ。</span><br /><span className="pl pl-2">わたしの足の裏でエジプトのすべての川を干上がらせる。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 45:7; イザヤ書 10:5–6; イザヤ書 37:26–27"> <span className="pl pl-1">わたしが昔からこれを計画し、</span><br /><span className="pl pl-2">いにしえの日から定めていたことを、あなたは聞かなかったのか。</span><br /><span className="pl pl-2">今、わたしはそれを実現させ、</span><br /><span className="pl pl-2">あなたが防備の町々を廃墟の山とするようにした。</span></span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 51:30; 詩篇 102:11; エレミヤ書 51:32"> <span className="pl pl-1">それゆえ、そこの住民は力が弱く、</span><br /><span className="pl pl-2">恐れおののき、恥じ入った。</span><br /><span className="pl pl-2">彼らは野の草や青々とした草のようになり、</span><br /><span className="pl pl-2">屋上の草、育つ前に枯れる穀物のようになった。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 37:28–29; エレミヤ書 23:23–24; 詩篇 139:1–11"> <span className="pl pl-1">しかし、わたしはあなたが座る時も、</span><br /><span className="pl pl-2">出る時も、入る時も、</span><br /><span className="pl pl-2">わたしに向かって激しく怒ることも知っている。</span></span>
<span className="v" id="v28" data-v="28" data-xref="エゼキエル書 29:4; エゼキエル書 38:4; 列王記第二 19:33"> <span className="pl pl-1">あなたがわたしに向かって激しく怒り、あなたの傲慢さがわたしの耳に届いたため、</span><br /><span className="pl pl-2">わたしはあなたの鼻にわたしの鉤をかけ、あなたの唇にわたしのくつわをはめ、</span><br /><span className="pl pl-2">あなたが来た道からあなたを引き返させる。』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="レビ記 25:20–22; 列王記第二 20:8–9; 出エジプト記 3:12"> <span className="pl pl-1">『これがあなたへのしるしとなる。</span><br /><span className="pl pl-2">今年は自然に生えたものを食べ、</span><br /><span className="pl pl-2">二年目にはそこから伸びたものを食べる。</span><br /><span className="pl pl-2">そして三年目には種を蒔いて刈り入れ、ぶどう畑を作ってその実を食べよ。</span></span>
<span className="v" id="v30" data-v="30" data-xref="列王記第二 19:4; イザヤ書 27:6; 歴代誌 第二 32:22–23"> <span className="pl pl-1">ユダの家の生き残った者たちは、再び下に根を張り、上に実を結ぶ。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="イザヤ書 9:7; ローマ人への手紙 11:5; ローマ人への手紙 9:27"> <span className="pl pl-1">残りの者がエルサレムから出て行き、逃れた者がシオンの山から出て行くからである。</span><br /><span className="pl pl-2">万軍の主の熱心がこれを行う。』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="イザヤ書 8:7–10; サムエル記第二 20:15; イザヤ書 37:33–35"> それゆえ、アッシリアの王について主はこう言われる。<br /><span className="pl pl-1">『彼がこの町に入ることはなく、</span><br /><span className="pl pl-2">ここに矢を射ることもなく、</span><br /><span className="pl pl-2">盾をもってその前に来ることもなく、</span><br /><span className="pl pl-2">これに対して土塁を築くこともない。</span></span>
<span className="v" id="v33" data-v="33" data-xref="列王記第二 19:28; 列王記第二 19:36"> <span className="pl pl-1">彼は自分が来た道を帰り、</span><br /><span className="pl pl-2">この町に入ることはない』と主は言われる。</span></span>
<span className="v" id="v34" data-v="34" data-xref="列王記第一 11:12–13; 列王記第二 20:6; 列王記第一 15:4"> <span className="pl pl-1">『わたしはこの町を守ってこれを救う。</span><br /><span className="pl pl-2">わたし自身のため、またわたしのしもべダビデのために。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="歴代誌 第二 32:21–22; サムエル記第二 24:16; 出エジプト記 12:29–30"> その夜、主の使いが出て行き、アッシリアの陣営で十八万五千人を打った。朝早く起きてみると、皆、死体となっていた。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨナ書 1:2; 列王記第二 19:7; 列王記第二 19:33"> そこでアッシリアの王セナケリブは立ち去り、帰って行ってニネベに住んだ。</span>
<span className="v" id="v37" data-v="37" data-xref="エズラ記 4:2; 創世記 8:4; 列王記第二 19:7"> 彼がその神ニスロクの家で拝んでいたとき、彼の子であるアドラメレクとシャレツェルが剣で彼を打ち、アララテの地へ逃げた。そして彼の息子エサル・ハドンが代わって王となった。</span>
</div>

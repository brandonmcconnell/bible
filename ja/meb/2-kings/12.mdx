<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌上 3:11; 列王記第二 11:21; 列王記第二 11:1–4"> イエフの第七年にエホアシュがユダの王となり、エルサレムで四十年間治めた。母の名はベエルシェバ出身のツィビヤであった。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代誌 第二 24:17–22; 歴代誌 第二 26:4; 歴代誌 第二 25:2"> エホアシュは、祭司エホヤダが教え導いていた間、主の目にかなうことを行った。</span>
<span className="v" id="v3" data-v="3" data-xref="列王記第二 14:4; 列王記第一 22:43; 列王記第一 15:14"> しかし高き所は取り除かれず、民はまだ高き所でいけにえをささげ、香をたいていた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王記第二 22:4; 出エジプト記 35:5; 歴代誌上 29:3–9"> エホアシュは祭司たちに言った。「主の家に持ち込まれる聖なる銀、すなわち通用する銀、各人に課された評価額の銀 、また人が進んで主の家に持って来るすべての銀を、</span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 58:12; 列王記第一 11:27; 列王記第二 22:5–6"> 祭司たちはそれぞれ寄進者から受け取り、神殿の破損が見つかったところはどこでも修理させよ。」</span>
<span className="v" id="v6" data-v="6" data-xref="歴代誌 第二 29:34; ペテロの手紙第一 5:2; イザヤ書 56:10–12"> しかし、エホアシュ王の第二十三年になっても、祭司たちは家の破れを修理していなかった。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌 第二 24:16; 歴代誌 第二 24:5–14; 列王記第二 11:4"> そこでエホアシュ王は祭司エホヤダと他の祭司たちを呼び、「なぜ神殿の破損を修理しないのか。これからは寄進者から銀を受け取らず、修理のために引き渡せ」と命じた。</span>
<span className="v" id="v8" data-v="8"> 祭司たちは、民からこれ以上銀を受け取らず、神殿修理の責任も負わないことに同意した。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="マルコ 12:41; 詩篇 84:10; エレミヤ書 35:4"> しかし祭司エホヤダは一つの箱を取り、その蓋に穴を開け、主の家に入って来る者の右側、祭壇のそばにそれを置いた。門を守る祭司たちは、主の家に持ち込まれたすべての銀をその中に入れた。</span>
<span className="v" id="v10" data-v="10" data-xref="サムエル記第二 8:17; 列王記第二 22:12; 列王記第二 19:2"> 箱に銀が多くたまると、王の書記官と大祭司が来て、主の家に集まった銀を袋に入れて数えた。</span>
<span className="v" id="v11" data-v="11" data-xref="列王記第二 22:5–6; 歴代誌 第二 24:11–12; 歴代誌 第二 34:9–11"> 彼らは量られた銀を、仕事をする者たち、すなわち主の家を監督する者たちの手に渡し、彼らはそれを主の家で働く大工や建築者たち、</span>
<span className="v" id="v12" data-v="12" data-xref="列王記第二 22:5–6; 列王記第一 5:17–18; エズラ記 3:7"> 石工、石を切り出す者たちに支払い、また主の家の破れを修理するための木材と切り石を買うため、そして家を修理するために費やされるすべてのために支払った。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代誌 第二 24:14; 列王記第一 7:48–50; エズラ記 1:9–11"> しかし、主の家に持ち込まれた銀から、主の家のための銀の杯、芯切りばさみ、鉢、ラッパ、金の器や銀の器は何も造られなかった。</span>
<span className="v" id="v14" data-v="14"> 彼らはそれを仕事をする者たちに与え、それで主の家を修理したからである。</span>
<span className="v" id="v15" data-v="15" data-xref="列王記第二 22:7; ヨハネの手紙第三 1:5; コリント人への第一の手紙 4:2–3"> また、工事をする者たちに支払う銀を託された人々には、会計報告を求めなかった。彼らが誠実に働いていたからである。</span>
<span className="v" id="v16" data-v="16" data-xref="レビ記 7:7; レビ記 5:15–18; レビ記 4:24"> 咎のささげ物の銀と罪のささげ物の銀は、主の家には持ち込まれなかった。それは祭司たちのものであった。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歴代誌 第二 24:23–24; ルカ 9:53; エレミヤ書 42:15"> そのころ、アラムの王ハザエルはガテに攻め上ってこれを奪い、さらにエルサレムへ攻め上る決意をした。</span>
<span className="v" id="v18" data-v="18" data-xref="列王記第一 15:18; 列王記第二 18:15–16; 列王記第二 12:4"> ユダの王エホアシュは、彼の先祖であるユダの王たち、ヨシャファテ、エホラム、アハズヤが聖別したすべての聖なるもの、彼自身の聖なるもの、および主の家の宝物庫と王の家で見つかったすべての金を取り、それをアラムの王ハザエルに送った。すると彼はエルサレムから去って行った。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王記第一 14:29; 列王記第一 14:19; 列王記第一 11:41"> ヨアシュのその他の事績と、彼が行ったすべてのことは、ユダの王たちの年代記の書に記されているではないか。</span>
<span className="v" id="v20" data-v="20" data-xref="歴代誌 第二 24:24–27; 列王記第二 14:5; サムエル記第二 5:9"> 彼のしもべたちは立ち上がって陰謀を企て、シラへ下るミロの家でヨアシュを打ち殺した。</span>
<span className="v" id="v21" data-v="21" data-xref="列王記第二 14:1; 歴代誌 第二 24:26–27"> シメアテの息子ヨザカルと、ショメルの息子エホザバド、すなわち彼のしもべたちが彼を打ったので、彼は死んだ。そして彼らは彼をダビデの町で先祖とともに葬り、その息子アマツヤが代わって王となった。</span>
</div>

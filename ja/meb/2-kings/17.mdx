<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王記第二 15:30"> ユダの王アハズの第十二年に、エラの息子ホセアがサマリアでイスラエルの王となり、九年間治めた。</span>
<span className="v" id="v2" data-v="2" data-xref="列王記第二 3:2; 列王記第二 13:11; 歴代誌 第二 30:5–11"> 彼は主の目に悪とされることを行ったが、彼より前にいたイスラエルの王たちのようではなかった。</span>
<span className="v" id="v3" data-v="3" data-xref="ホセア書 10:14; 列王記第二 15:19; 列王記第二 19:36–37"> アッシリアの王シャルマネセルが彼に攻め上って来た。ホセアは彼のしもべとなり、彼に貢ぎ物を持って来た。</span>
<span className="v" id="v4" data-v="4" data-xref="列王記第二 18:21; 列王記第二 24:20; エゼキエル書 17:13–19"> しかしアッシリアの王はホセアの謀反を知った。ホセアがエジプトの王ソに使者を遣わし、例年のように貢ぎ物を納めなかったからである。そこで彼を捕らえ、牢獄につないだ。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ホセア書 13:16; 列王記第二 25:1–3; 列王記第二 18:9"> それからアッシリアの王はその全地に攻め上り、サマリアに上って来て、三年間それを包囲した。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代誌上 5:26; ホセア書 13:16; 申命記 28:64"> ホセアの第九年に、アッシリアの王はサマリアを攻め取り、イスラエルをアッシリアへ捕らえ移した。そして彼らをハラと、ゴザンの川のハボルと、メディア人の町々に住まわせた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 23:16; 詩篇 106:35–41; ネヘミヤ記 9:26"> イスラエルの子らが、自分たちをエジプトの地から、エジプトの王ファラオの手の下から導き上られた彼らの神、主に対して罪を犯し、他の神々を恐れ、</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 18:3; 列王記第二 16:3; 申命記 18:9"> 主がイスラエルの子らの前から追い払われた国々の定めや、イスラエルの王たちが作った定めの中を歩んだので、この事が起こった。</span>
<span className="v" id="v9" data-v="9" data-xref="列王記第二 18:8; ヨブ記 31:27; 申命記 13:6"> イスラエルの子らは、彼らの神、主に逆らうことをひそかに行い、見張りのやぐらから防備の町に至るまで、すべての町に高き所を築いた。</span>
<span className="v" id="v10" data-v="10" data-xref="列王記第一 14:23; ミカ書 5:14; 出エジプト記 34:13"> 彼らはすべての高い丘の上と、すべての青々とした木の下に、石の柱とアシェラ像を立て、</span>
<span className="v" id="v11" data-v="11" data-xref="歴代誌 第二 28:25; 列王記第二 21:6; エレミヤ書 44:17"> 主が彼らの前から捕らえ移された国々がしたように、すべての高き所で香をたいた。彼らは悪事を行って主を怒らせた。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 12:4; 出エジプト記 20:3–5; 申命記 4:23–25"> 彼らは、主が彼らに「あなたがたはこの事を行ってはならない」と言われていた偶像に仕えた。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 35:15; サムエル記第一 9:9; エレミヤ書 18:11"> それでも主は、すべての預言者とすべての先見者を通してイスラエルとユダに警告して言われた。「あなたがたの悪い道から立ち返り、わたしがあなたがたの先祖に命じ、またわたしのしもべである預言者たちを通してあなたがたに送ったすべての律法に従って、わたしの戒めとわたしの定めを守りなさい。」</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 31:27; 使徒の働き 7:51; 詩篇 106:24"> しかし彼らは聞き入れようとはせず、彼らの神、主を信じなかった彼らの先祖のうなじのように、自分たちのうなじを固くした。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 12:30–31; 申命記 32:21; ローマ人への手紙 1:21–23"> 彼らは主の定め、先祖と結ばれた契約、彼らに与えられたあかしを退けた。むなしいものを追って自らもむなしくなり、主が「彼らのように行ってはならない」と命じられた周囲の国々に倣った。</span>
<span className="v" id="v16" data-v="16" data-xref="列王記第一 14:23; 列王記第一 16:31; 列王記第一 14:15"> 彼らは彼らの神、主のすべての戒めを捨て、自分のために鋳造の像、すなわち二頭の子牛を造り、アシェラ像を造り、天のすべての軍勢を拝み、バアルに仕えた。</span>
<span className="v" id="v17" data-v="17" data-xref="列王記第二 21:6; 列王記第二 16:3; 申命記 18:10–12"> 彼らは息子や娘を火の中を通らせ、占いとまじないを行い、主の目に悪とされることに身を売って、主を怒らせた。</span>
<span className="v" id="v18" data-v="18" data-xref="列王記第一 12:20; 列王記第一 11:13; ホセア書 11:12"> それゆえ、主はイスラエルに向かって非常に怒られ、彼らを御前から取り除かれた。ユダの部族のほかには何も残らなかった。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王記第二 16:3; 列王記第一 14:22–23; エゼキエル書 16:51–52"> ユダもまた、彼らの神、主の戒めを守らず、イスラエルが作った定めの中を歩んだ。</span>
<span className="v" id="v20" data-v="20" data-xref="列王記第二 15:29; エレミヤ書 6:30; 列王記第二 13:3"> 主はイスラエルのすべての子孫を退け、彼らを苦しめ、彼らを略奪者たちの手に引き渡された。ついに彼はご自分の前から彼らを投げ捨てられた。</span>
<span className="v" id="v21" data-v="21" data-xref="列王記第一 11:11; 列王記第一 11:31; 列王記第一 14:16"> 彼がイスラエルをダビデの家から引き裂かれたとき、彼らはネバテの息子ヤロブアムを王とした。ヤロブアムはイスラエルを主に従うことからそらせて、彼らに大いなる罪を犯させた。</span>
<span className="v" id="v22" data-v="22" data-xref="列王記第二 3:3; 列王記第二 13:6; 列王記第二 13:11"> イスラエルの子らはヤロブアムが犯したすべての罪の中を歩んだ。彼らはそこから離れず、</span>
<span className="v" id="v23" data-v="23" data-xref="列王記第二 17:6; 列王記第二 17:13; 列王記第二 17:20"> ついに主は、そのすべてのしもべである預言者たちを通して語られたとおりに、ご自分の前からイスラエルを取り除かれた。こうしてイスラエルは自分たちの地からアッシリアへ捕らえ移され、今日に至っている。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王記第二 18:34; 列王記第二 17:30–31; マタイ 10:5"> アッシリアの王はバビロン、クタ、アワ、ハマテ、セファルワイムから人々を連れて来て、イスラエルの子らの代わりにサマリアの町々に住まわせた。彼らはサマリアを所有し、その町々に住んだ。</span>
<span className="v" id="v25" data-v="25" data-xref="列王記第二 17:32; 列王記第二 17:34; 列王記第二 17:41"> 彼らがそこに住み始めたころ、彼らは主を恐れていなかったので、主は彼らの中に獅子を送られ、獅子は彼らの中の何人かを殺した。</span>
<span className="v" id="v26" data-v="26" data-xref="列王記第二 17:27; サムエル記第一 8:9; アモス書 8:14"> そこで人々はアッシリアの王に訴えた。「あなたが移住させ、サマリアの町々に住まわせた諸国の民は、この地の神の定めを知りません。そのため神が獅子を送り、彼らを殺しています。この地の神の定めを知らないからです。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="士師記 17:13; 列王記第一 12:31; 列王記第一 13:2"> そこでアッシリアの王は命じて言った。「あなたがたがそこから捕らえ移した祭司の一人をそこに連れて行け。彼に<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="ヘブル語では「彼らに」（複数形）である。">a</a></sup>行ってそこに住まわせ、その地の神の定めを彼らに教えさせよ。」</span>
<span className="v" id="v28" data-v="28" data-xref="列王記第一 12:29–32; イザヤ書 29:13; マタイ 15:14"> そこで、彼らがサマリアから捕らえ移した祭司の一人が来てベテルに住み、どのように主を恐れるべきかを彼らに教えた。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王記第一 12:31; ミカ書 4:5; 列王記第一 13:32"> しかし、それぞれの国が自分たちの神々を造り、サマリア人が造った高き所の家々にそれらを置いた。それぞれの国が自分たちの住んでいる町々でそのようにした。</span>
<span className="v" id="v30" data-v="30" data-xref="列王記第二 17:24"> バビロンの人々はスコテ・ベノテを造り、クタの人々はネルガルを造り、ハマテの人々はアシマを造り、</span>
<span className="v" id="v31" data-v="31" data-xref="列王記第二 17:24; 列王記第二 17:17; 列王記第二 19:37"> アワ人はニブハズとタルタクを造り、セファルワイム人はセファルワイムの神々であるアドラメレクとアナメレクのために自分たちの子らを火で焼いた。</span>
<span className="v" id="v32" data-v="32" data-xref="列王記第一 12:31; 列王記第二 17:29; 列王記第一 13:33"> 彼らは主を恐れながらも、自分たちの中から高き所の祭司たちを作り、その祭司たちは彼らのために高き所の家々でいけにえをささげた。</span>
<span className="v" id="v33" data-v="33" data-xref="列王記第二 17:41; ルカ 16:13; マタイ 6:24"> 彼らは主を恐れながらも、彼らが捕らえ移されてきた国々の習慣に従って、自分たちの神々に仕えた。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="創世記 32:28; 創世記 35:10; 列王記第二 17:27–28"> 今日まで、彼らは以前の習慣に従っている。彼らは主を恐れず、自分たちの掟や定めにも、主がイスラエルと名づけられたヤコブの子らに、主が命じられた律法や戒めにも従って行わない。</span>
<span className="v" id="v35" data-v="35" data-xref="士師記 6:10; ヨシュア記 23:16; ヨシュア記 23:7"> 主は彼らと契約を結び、彼らに命じて言われた。「あなたがたは他の神々を恐れてはならない。またそれらを拝んではならないし、それらに仕えてはならないし、それらにいけにえをささげてはならない。</span>
<span className="v" id="v36" data-v="36" data-xref="出エジプト記 6:6; 申命記 6:13; レビ記 19:32"> しかし、大いなる力と伸ばされた腕をもってあなたがたをエジプトの地から導き上られた主、彼をあなたがたは恐れ、彼を拝み、彼にいけにえをささげなければならない。</span>
<span className="v" id="v37" data-v="37" data-xref="レビ記 19:37; 申命記 5:31–2; 申命記 4:44–45"> 彼があなたがたのために書き記された掟、定め、律法、戒めを、あなたがたはいつまでも守って行わなければならない。他の神々を恐れてはならない。</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 4:23; 申命記 6:12; 申命記 8:14–18"> わたしがあなたがたに結んだ契約を忘れてはならない。また他の神々を恐れてはならない。</span>
<span className="v" id="v39" data-v="39" data-xref="ルカ 1:74–75; サムエル記第一 12:24; マタイ 10:28"> しかし、あなたがたの神、主を恐れなさい。そうすれば、彼はあなたがたをすべての敵の手から救い出される。」</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="申命記 4:28; 列王記第二 17:8; エレミヤ書 13:23"> しかし彼らは聞き入れようとはせず、以前の習慣に従って行った。</span>
<span className="v" id="v41" data-v="41" data-xref="マタイ 6:24; ゼパニヤ書 1:5; 列王記第一 18:21"> こうしてこれらの国々は主を恐れながらも、その刻まれた像に仕えた。彼らの子らも、その子らの子らも同じである。彼らの先祖が行ったように、彼らも行い、今日に至っている。</span>
</div>

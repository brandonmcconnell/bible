<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 8:30; 列王記第一 13:32; 列王記第一 21:8–14"> さて、アハブにはサマリアに七十人の息子がいた。イエフは手紙を書き、サマリアへ、イズレエルの支配者たち、すなわち長老たちと、アハブの子らを育てた者たちのところに送って言った。</span>
<span className="v" id="v2" data-v="2" data-xref="列王記第二 5:6"> 「今、この手紙があなたがたに届き次第、あなたがたの主君の息子たちはあなたがたのところにおり、あなたがたには戦車と馬、防備の町と武具もあるのだから、</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記第二 2:8–9; 列王記第一 12:20–21; サムエル記第二 2:12–17"> あなたがたの主君の息子たちの中から最も優れ、ふさわしい者を選び、彼を父の王座に就かせ、あなたがたの主君の家のために戦え。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王記第二 9:24; 列王記第二 9:27; イザヤ書 27:4"> 彼らは非常に恐れた。「二人の王でさえ彼に立ち向かえなかった。まして、どうしてわれわれが立ち向かえよう。」</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第一 20:32; 列王記第一 20:4; ヨシュア記 9:11"> そこで、王宮の管理者、町の長、長老たち、王子たちの養育係は、イエフに人を遣わして言った。「われわれはあなたのしもべです。何でもお命じどおりにいたします。だれも王には立てません。あなたがよいと思われるようになさってください。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 2:20–23; 申命記 5:9; 民数記 25:4"> すると彼は彼らに二度目の手紙を書いて言った。「もしあなたがたがわたしの味方であり、わたしの声に聞き従うなら、あなたがたの主君の息子たちの首を取り、明日の今ごろ、イズレエルのわたしのところに来なさい。」さて、王の息子たちである七十人は、彼らを育てた町の有力者たちと一緒にいた。</span>
<span className="v" id="v7" data-v="7" data-xref="列王記第一 21:21; 列王記第二 11:1; 列王記第二 10:9"> 手紙が彼らに届くと、彼らは王の息子たちを捕らえ、その七十人を殺し、彼らの首をかごに入れ、イズレエルの彼のもとに送った。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="申命記 21:23; サムエル記第二 11:18–21; マルコ 6:28"> 使者が来て彼に告げて言った。「彼らが王の息子たちの首を持って来ました。」彼は言った。「朝まで、門の入り口に二つの山にして置いておけ。」</span>
<span className="v" id="v9" data-v="9" data-xref="列王記第二 9:14–24; イザヤ書 5:3; ホセア書 1:4"> 朝になると、イエフは外に出て立ち、すべての民に言った。「あなたがたに罪はない。主君に謀反を起こして殺したのは、このわたしだ。しかし、この者たちを皆殺したのはだれか。</span>
<span className="v" id="v10" data-v="10" data-xref="列王記第一 21:29; 列王記第一 21:19; 列王記第二 9:7–10"> アハブの家について主が語られた言葉は、一つも成就せずに地に落ちることはないと知れ。主は、そのしもべエリヤを通して語られたことを行われたのだ。」</span>
<span className="v" id="v11" data-v="11" data-xref="ヨブ記 18:19; 列王記第一 18:19; 列王記第一 22:6"> こうしてイエフは、イズレエルにいるアハブの家に残っていたすべての者、彼のすべての有力者、彼の親しい友人たち、彼の祭司たちを、彼に一人も残る者がいなくなるまで打った。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 彼は立ち上がって出発し、サマリアへ行った。彼が途中の羊飼いたちの毛刈り場にいたとき、</span>
<span className="v" id="v13" data-v="13" data-xref="列王記第二 8:29; 列王記第二 8:24; 歴代誌 第二 21:17"> イエフはユダの王アハズヤの兄弟たちに出会い、言った。「あなたがたはだれか。」彼らは答えた。「われわれはアハズヤの兄弟です。王の子らと王妃の子らに挨拶するために下って行くところです。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歴代誌 第二 22:10; 列王記第二 10:6; 列王記第二 10:10–11"> 彼は「彼らを生け捕りにせよ！」と言った。彼らは彼らを生け捕りにし、毛刈りの家の穴で彼ら四十二人を殺した。彼は彼らのうち一人も残さなかった。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 35:14–19; エズラ記 10:19; エゼキエル書 17:18"> 彼がそこから出発すると、レカブの息子エホナダブが彼を迎えに来た。エフーは彼に挨拶して言った。「わたしがあなたに誠意を尽くしているように、あなたもわたしに誠実か。」<br />エホナダブは答えた。「誠実です。」<br />「それなら、手を差し出せ。」エホナダブが手を差し出すと、イエフは彼を戦車に引き上げた。</span>
<span className="v" id="v16" data-v="16" data-xref="列王記第一 19:10; マタイ 6:5; 列王記第二 10:31"> イエフは言った。「わたしと一緒に来て、主への熱心を見届けよ。」こうしてエホナダブを戦車に乗せた。</span>
<span className="v" id="v17" data-v="17" data-xref="列王記第二 9:8; 歴代誌 第二 22:8; マラキ書 4:1"> サマリアに着くと、主がエリヤに語られた言葉のとおり、イエフはそこに残っていたアハブの家の者をことごとく打ち、アハブの家を滅ぼし尽くした。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王記第一 16:31–32; 列王記第二 3:2; ローマ人への手紙 3:8"> イエフはすべての民を一つに集め、彼らに言った。「アハブは少しだけバアルに仕えたが、イエフは大いに彼に仕えるであろう。</span>
<span className="v" id="v19" data-v="19" data-xref="列王記第一 22:6; 列王記第一 18:19; コリント人への第二の手紙 11:3"> だから今、バアルのすべての預言者、礼拝者、祭司をわたしのもとに呼び集めよ。一人も欠けてはならない。わたしはバアルに盛大ないけにえを献げる。来ない者は生かしておかない。」しかしイエフは、バアルの礼拝者たちを滅ぼすため、策略を用いていたのである。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヨエル書 1:14; 出エジプト記 32:5; 列王記第一 18:19–20"> イエフは「バアルのために厳かな集会を聖別せよ！」と言った。彼らはそれを布告した。</span>
<span className="v" id="v21" data-v="21" data-xref="列王記第一 16:32; 列王記第二 11:18; ヨエル書 3:2"> イエフは全イスラエルに人を遣わした。そしてバアルのすべての礼拝者たちが来て、来ない者は一人もいなかった。彼らはバアルの家に入り、バアルの家は端から端までいっぱいになった。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 28:2; マタイ 22:11–12"> 彼は衣装部屋を管理する者に言った。「バアルのすべての礼拝者たちのために長服を出して来い！」彼は彼らのために長服を出して来た。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="マタイ 13:30; マタイ 25:32–33; マタイ 13:41"> イエフはレカブの子エホナダブとともにバアルの神殿に入り、礼拝者たちに言った。「よく調べ、ここに主のしもべが一人もおらず、バアルの礼拝者だけであることを確かめよ。」</span>
<span className="v" id="v24" data-v="24" data-xref="列王記第一 20:30–42"> 彼らはいけにえと全焼のささげ物をささげるために入った。さて、イエフは自分のために外に八十人の男たちを配置し、こう言っていた。「わたしがあなたがたの手に引き渡す男たちのうち、だれかを逃がしたなら、彼を逃がした者の命は彼の命の代わりとなる。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ヨハネの黙示録 16:6–7; エゼキエル書 22:21–22; 列王記第一 18:40"> 全焼のささげ物をささげ終えるやいなや、イエフは護衛兵と隊長たちに言った。「入って彼らを殺せ！だれも逃がすな。」彼らは剣の刃で彼らを打った。護衛兵と隊長たちは彼らを投げ捨て、バアルの家の奥の聖所に入った。</span>
<span className="v" id="v26" data-v="26" data-xref="列王記第一 14:23; 列王記第二 3:2; 列王記第二 19:18"> 彼らはバアルの家にあった柱を持ち出し、それらを焼いた。</span>
<span className="v" id="v27" data-v="27" data-xref="ダニエル書 3:29; エズラ記 6:11; ダニエル書 2:5"> 彼らはバアルの柱を打ち壊し、バアルの家を打ち壊し、それを便所にして今日に至っている。</span>
<span className="v" id="v28" data-v="28"> このようにして、イエフはバアルをイスラエルから滅ぼした。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王記第一 12:28–30; 列王記第一 14:16; 列王記第一 13:33–34"> しかしイエフは、ネバテの息子ヤロブアムの罪、すなわち彼がイスラエルに罪を犯させた罪である、ベテルとダンにある二頭の金の子牛から離れなかった。</span>
<span className="v" id="v30" data-v="30" data-xref="列王記第二 10:35; 列王記第二 13:1; 列王記第二 13:10"> 主はイエフに言われた。「あなたは、わたしの目に正しいことをよく行い、わたしの心にあったとおりにアハブの家を処断した。それゆえ、あなたの子孫は四代目までイスラエルの王座に着く。」</span>
<span className="v" id="v31" data-v="31" data-xref="列王記第二 10:29; 箴言 4:23; ヘブル人への手紙 2:1"> しかし、イエフは心を尽くしてイスラエルの神、主の律法に歩むよう注意を払わなかった。彼はヤロブアムがイスラエルに罪を犯させたその罪から離れなかった。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="列王記第二 8:12; 列王記第一 19:17; 列王記第二 13:22"> そのころ、主はイスラエルの領土を削り始められた。ハザエルがイスラエルの国境一帯を攻めたのである。</span>
<span className="v" id="v33" data-v="33" data-xref="アモス書 1:3–4; 申命記 2:36; ヨシュア記 13:9–12"> ヨルダン川から東の方、ギレアデの全地、ガド人、ルベン人、マナセ人、アルノン谷のそばにあるアロエルから、ギレアデとバシャンに至るまでであった。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="列王記第一 11:41; 列王記第一 14:29; 列王記第一 14:19"> イエフのその他の事績、彼が行ったすべてのこと、彼のすべての力は、イスラエルの王たちの年代記の書に記されているではないか。</span>
<span className="v" id="v35" data-v="35" data-xref="列王記第一 14:20; 列王記第一 14:31; 列王記第一 1:21"> イエフは先祖とともに眠りにつき、人々は彼をサマリアに葬った。その息子エホアハズが代わって王となった。</span>
<span className="v" id="v36" data-v="36"> イエフがサマリアでイスラエルを治めた期間は二十八年間であった。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 18:25; 列王記第二 2:3; ネヘミヤ記 5:2–5"> 預言者の子らの妻の一人がエリシャに叫んで言った。「あなたのしもべであるわたしの夫は死にました。あなたのしもべが主を恐れる者であったことは、あなたがご存じです。しかし債権者が来て、わたしの二人の子どもを自分の奴隷にしようとしています。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="列王記第一 17:12; ヤコブの手紙 2:5; 列王記第二 6:26–27"> エリシャは彼女に言った。「わたしはあなたのために何をしようか。あなたの家に何があるか、わたしに告げなさい。」<br />彼女は言った。「あなたのはしための家には、油の壺一つのほか、何もありません。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ヨハネ 2:7; 詩篇 81:10; ヨハネ 16:24"> 彼は言った。「外に出て、すべての隣人から空の器を借りなさい。少しだけにしてはならない。</span>
<span className="v" id="v4" data-v="4" data-xref="マルコ 8:5–9; マタイ 6:6; エペソ人への手紙 3:20"> あなたは中に入り、あなたと息子たちの後ろで戸を閉め、それらすべての器に油を注ぎ入れなさい。そして、いっぱいになったものはわきに置きなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王記第二 5:11; ヘブル人への手紙 11:7–8; 列王記第一 17:15–16"> そこで彼女は彼から去り、自分と息子たちの後ろで戸を閉めた。彼らが彼女に器を持ってくると、彼女は注ぎ入れた。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイ 14:20; 列王記第二 13:19; ルカ 6:19"> 器がいっぱいになったとき、彼女は息子に言った。「器をもう一つ持ってきなさい。」<br />彼は彼女に、「器はもうありません」と言った。すると、油は止まった。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="テサロニケ人への第二の手紙 3:7–12; 列王記第一 12:22; ローマ人への手紙 12:17"> それから彼女は来て、神の人に告げた。彼は言った。「行って、油を売り、あなたの負債を払いなさい。そして、あなたとあなたの息子たちは、残ったもので生活しなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 19:18; 創世記 19:3; 列王記第二 4:11–12"> ある日、エリシャはシュネムへ渡って行った。そこには有力な女がいて、彼に食事をするよう強く勧めた。それで、彼はそこを通り過ぎるたびに、食事をするためにそこに立ち寄った。</span>
<span className="v" id="v9" data-v="9" data-xref="列王記第一 17:24; 箴言 31:10–11; 列王記第二 4:7"> 彼女は夫に言った。「いつもわたしたちのところを通るあの方は、聖なる神の人に違いありません。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 12:13; マタイ 10:41–42; マタイ 25:40"> どうか、屋上に壁のある小さな部屋を造りましょう。そこに彼のために寝台、机、椅子、ともしび台を置きましょう。そうすれば、彼がわたしたちのところに来たとき、そこに泊まることができます。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> ある日、彼はそこに来て、その部屋に入り、そこで横になった。</span>
<span className="v" id="v12" data-v="12" data-xref="列王記第二 8:4–5; 列王記第二 3:11; 列王記第二 4:29–31"> 彼はしもべゲハジに言った。「このシュネムの女を呼んでくれ。」彼が彼女を呼ぶと、彼女は彼の前に立った。</span>
<span className="v" id="v13" data-v="13" data-xref="テモテへの第二の手紙 1:16–18; ピリピ人への手紙 4:18–19; ヘブル人への手紙 6:10"> エリシャはゲハジに言った。「彼女にこう言いなさい。『あなたはこれほど心を尽くして、わたしたちの世話をしてくれた。何かしてほしいことはあるか。王や軍の長に取り次いでもらいたいことがあるか。』」<br />彼女は答えた。「わたしは自分の民の間に住んでいます。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ルカ 1:7; 創世記 15:2–3; サムエル記第一 1:8"> 彼は言った。「それでは、彼女のために何をすべきか。」<br />ゲハジは答えた。「確かに、彼女には息子がなく、夫は年老いています。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 彼は言った。「彼女を呼んでくれ。」彼が彼女を呼ぶと、彼女は戸口に立った。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 18:10; ルカ 1:13; 列王記第二 4:28"> エリシャは言った。「来年の今ごろ、あなたは息子を抱いている。」<br />彼女は言った。「いいえ、わが主君、神の人よ。あなたのはしためを欺かないでください。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="詩篇 113:9; ルカ 1:36; 創世記 21:1"> 女は身ごもり、エリシャが彼女に言ったとおり、次の年のその時期に息子を産んだ。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ルツ記 2:4"> 子どもが大きくなったある日、彼は刈り入れをする者たちのところにいる父のもとへ出て行った。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨブ記 14:1–2; エレミヤ書 4:19"> その子は父に、「頭が痛い！頭が痛い！」と叫んだ。<br />父はしもべに、「彼を母親のところに連れて行け」と言った。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカ 7:12; ヨハネ 11:3; ヨハネ 11:14"> しもべがその子を母親のもとへ連れて来ると、子どもは昼まで母のひざに抱かれていたが、やがて死んだ。</span>
<span className="v" id="v21" data-v="21" data-xref="列王記第二 4:32; 列王記第二 4:10; 列王記第二 4:7"> 彼女は上って行き、彼を神の人の寝台の上に寝かせ、彼の後ろで戸を閉めて出て行った。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 9:38; 列王記第二 4:26; ヨハネ 11:3"> 彼女は夫を呼んで言った。「どうか、しもべ一人と、ろば一頭をわたしのところに送ってください。わたしが神の人のところへ急いで行き、また戻って来られるように。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="民数記 10:10; 民数記 28:11; 歴代誌上 23:31"> 彼は言った。「なぜ今日、彼のところへ行くのか。新月でも安息日でもないのに。」<br />彼女は言った。「大丈夫です。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 4:20; 列王記第一 13:13; サムエル記第一 25:19–20"> 彼女はろばに鞍を置き、しもべに命じた。「ろばを駆って進め。わたしが命じないかぎり、速さを緩めるな。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王記第二 2:25; イザヤ書 35:2; 列王記第一 18:19"> 彼女は出発し、カルメル山にいる神の人のもとへ向かった。神の人は遠くから彼女を見つけ、しもべゲハジに言った。「あのシュネムの女だ。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 15:36; 列王記第二 4:23; サムエル記第一 17:18"> 今、走って彼女を迎えに行き、彼女に『あなたは無事か。あなたの夫は無事か。子どもは無事か』と言いなさい。」<br />彼女は答えた。「無事です。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="サムエル記第二 7:3; 創世記 18:17; アモス書 3:7"> 彼女は山にいる神の人のところまで来ると、その足にすがりついた。ゲハジが引き離そうとしたが、神の人は言った。「そのままにしておけ。彼女の心は深い悲しみに沈んでいる。主はそのことをわたしに隠し、告げられなかった。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 30:1; 列王記第二 4:16"> すると彼女は言った。「わたしがわが主君に息子を求めたでしょうか。『わたしを欺かないでください』とわたしは言わなかったでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王記第二 2:14; 列王記第一 18:46; 出エジプト記 14:16"> そこで彼はゲハジに言った。「裾を帯にはさみ、わたしの杖を手に持って行きなさい。だれかに会っても挨拶をしてはならない。だれかがあなたに挨拶をしても答えてはならない。そしてわたしの杖を子どもの顔の上に置きなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ルツ記 1:16–18; 列王記第二 2:2; 出エジプト記 33:12–16"> 子どもの母は言った。「主は生きておられ、あなたの命にかけても誓います。わたしはあなたから離れません。」そこで彼は立ち上がり、彼女の後に従った。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ヨハネ 11:11; マルコ 5:39; マルコ 9:19–29"> ゲハジは二人より先に行き、杖を子どもの顔の上に置いた。しかし声もなく、何の反応もなかった。そこで引き返してエリシャを迎え、「子どもは目を覚ましません」と告げた。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="ルカ 8:52–53; ヨハネ 11:17; 列王記第一 17:17"> エリシャが家に入ると、子どもは死んで彼の寝台に横たわっていた。</span>
<span className="v" id="v33" data-v="33" data-xref="マタイ 6:6; 列王記第二 4:4; 使徒の働き 9:40"> 彼は中に入り、二人だけになるように戸を閉め、主に祈った。</span>
<span className="v" id="v34" data-v="34" data-xref="列王記第一 17:21; 使徒の働き 20:10"> 彼は上って子どもの上に横たわり、自分の口を彼の口の上に、自分の目を彼の目の上に、自分の手を彼の手の上に置き、彼の上に身を伸ばした。すると子どもの肉は温かくなった。</span>
<span className="v" id="v35" data-v="35" data-xref="列王記第二 8:5; 列王記第二 13:21; 列王記第一 17:22"> それから彼は戻って、家の中を一度あちらこちらへと歩き、上って行って彼の上に身を伸ばした。すると子どもは七回くしゃみをし、子どもは目を開いた。</span>
<span className="v" id="v36" data-v="36" data-xref="ヘブル人への手紙 11:35; 列王記第一 17:23; ルカ 7:15"> 彼はゲハジを呼んで、「あのシュネムの女を呼んでくれ」と言った。そこで彼は彼女を呼んだ。彼女が彼のもとに来たとき、彼は「あなたの息子を取りなさい」と言った。</span>
<span className="v" id="v37" data-v="37" data-xref="ヘブル人への手紙 11:35; 列王記第二 2:15; 列王記第一 17:24"> そこで彼女は入り、彼の足もとにひれ伏し、地に身をかがめた。そして彼女は息子を取り、出て行った。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="列王記第二 8:1; 列王記第二 2:3; 列王記第二 2:1"> エリシャはギルガルに戻った。その地にはききんがあった。預言者の子らが彼の前に座っていた。彼は自分のしもべに「大きな鍋を火にかけ、預言者の子らのために煮物を作りなさい」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="エレミヤ書 2:21; イザヤ書 5:4; マタイ 15:13"> 一人が野草を摘むために野に出て行き、野生のつる草を見つけ、それから野生のひょうたんを自分の上着いっぱいに集めた。彼は戻って来て、それらを切り刻んで煮物の鍋に入れた。彼らはそれが何であるか知らなかったからである。</span>
<span className="v" id="v40" data-v="40" data-xref="マルコ 16:18; 出エジプト記 15:23; 出エジプト記 10:17"> 人々に盛り分け、彼らが食べ始めると、皆は叫んだ。「神の人よ、鍋に死が入っています！」彼らは食べることができなかった。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="列王記第二 2:21; 出エジプト記 15:25; コリント人への第一の手紙 1:25"> しかし彼は、「麦粉を持ってきなさい」と言った。彼はそれを鍋の中に投げ入れ、「民が食べるために注ぎ出しなさい」と言った。そして鍋の中には有害なものは何もなくなった。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="サムエル記第一 9:7; ヨハネ 6:9; マタイ 14:16–21"> ある男がバアル・シャリシャから来て、初穂のパンとして大麦のパン二十個と、袋に入った新鮮な穀物の穂を添えて神の人のもとに持って来た。彼は、「民が食べるために与えなさい」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="ルカ 9:13; マタイ 14:20; ヨハネ 6:9"> 彼のしもべは言った。「どうしてこれを百人の男の前に出せましょうか。」<br />しかし彼は言った。「民が食べるために与えなさい。主はこう言われるからである。『彼らは食べ、しかも残すであろう。』」</span>
<span className="v" id="v44" data-v="44"> そこで彼は彼らの前にそれを出し、主の言葉のとおりに彼らは食べ、しかも残した。</span>
</div>
</div>

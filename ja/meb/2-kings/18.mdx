<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌 第二 28:27–1; マタイ 1:9–10; 歴代誌上 3:13"> イスラエルの王、エラの息子ホセアの第三年に、ユダの王アハズの息子ヒゼキヤが王となった。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代誌 第二 29:1–2"> 彼が王となったときは二十五歳で、エルサレムで二十九年間治めた。彼の母の名はアビといい、ゼカリヤの娘であった。</span>
<span className="v" id="v3" data-v="3" data-xref="列王記第二 20:3; 列王記第一 11:4; 歴代誌 第二 31:20–21"> 彼は先祖ダビデが行ったすべてのことに従って、主の目にかなうことを行った。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌 第二 31:1; 民数記 21:8–9; 列王記第二 18:22"> 彼は高き所を取り除き、石の柱を打ち砕き、アシェラ像を切り倒した。彼はまた、モーセが造った青銅の蛇を粉々に打ち砕いた。そのころまでイスラエルの子らはそれに香をたいていたからである。彼はそれをネフシュタンと呼んだ。</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第二 23:25; 列王記第二 19:10; マタイ 27:43"> ヒゼキヤはイスラエルの神、主に信頼した。ユダのすべての王の中で、彼の後にも前にも、彼ほどの者はいなかった。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 23:8; 申命記 10:20; ヨハネ 14:15"> 彼は主にすがり、主に従うことから離れず、主がモーセに命じられた戒めを守った。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 8:31; 創世記 39:2–3; 列王記第二 16:7"> 主は彼とともにおられた。彼はどこへ行っても成功した。彼はアッシリアの王に背き、彼に仕えなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 14:29; 列王記第二 17:9; 歴代誌 第二 28:18"> 彼は見張りのやぐらから防備の町に至るまで、ペリシテ人をガザとその国境まで打った。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ホセア書 10:14; 列王記第二 17:3–23; 列王記第二 18:1"> ヒゼキヤ王の第四年、すなわちイスラエルの王、エラの息子ホセアの第七年に、アッシリアの王シャルマネセルがサマリアに攻め上って来て、これを包囲した。</span>
<span className="v" id="v10" data-v="10" data-xref="アモス書 6:7; アモス書 9:1–4; ミカ書 1:6–9"> 三年の終わりに彼らはそれを攻め取った。ヒゼキヤの第六年、すなわちイスラエルの王ホセアの第九年に、サマリアは攻め取られた。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代誌上 5:26; 列王記第二 17:6; イザヤ書 37:12"> アッシリアの王はイスラエルをアッシリアへ捕らえ移し、彼らをハラと、ゴザンの川のハボルと、メディア人の町々に置いた。</span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの手紙第一 4:17; ペテロの手紙第一 2:8; ミカ書 3:4"> 彼らが彼らの神、主の声に聞き従わず、その契約、すなわち主のしもべモーセが命じたすべてのことに背き、それを聞こうとも行おうともしなかったからである。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 36:1–22; 歴代誌 第二 32:1–23; イザヤ書 7:17–25"> ヒゼキヤ王の第十四年に、アッシリアの王セナケリブがユダのすべての防備の町々に攻め上って来て、それらを攻め取った。</span>
<span className="v" id="v14" data-v="14" data-xref="列王記第二 18:7; ルカ 14:32; 列王記第一 20:4"> ユダの王ヒゼキヤはラキシュにいるアッシリアの王に人を遣わして言った。「わたしはあなたに背きました。わたしから引き返してください。あなたがわたしに課すものは何でも負います。」アッシリアの王はユダの王ヒゼキヤに、銀三百タラント<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一タラントは約30キログラム、66ポンド、または965トロイオンスである。">a</a></sup>と金三十タラントを課した。</span>
<span className="v" id="v15" data-v="15" data-xref="列王記第二 16:8; 列王記第一 15:18–19; 列王記第二 12:18"> ヒゼキヤは主の家と王の家の宝物庫で見つかったすべての銀を彼に与えた。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代誌 第二 29:3; 列王記第一 6:31–35"> その時、ヒゼキヤは主の神殿の扉と、ユダの王ヒゼキヤが金をかぶせた柱から金を切り取り、それをアッシリアの王に与えた。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 20:1; 列王記第二 20:20; イザヤ書 7:3"> アッシリアの王は、タルタン、ラブサリス、ラブシャケをラキシュからヒゼキヤ王のもとへ、大軍勢を率いてエルサレムに遣わした。彼らは上って行ってエルサレムに来た。彼らが上って来たとき、彼らは来て、布さらしの野の大通りにある上の池の水道のそばに立った。</span>
<span className="v" id="v18" data-v="18" data-xref="列王記第二 19:2; イザヤ書 36:3; サムエル記第二 8:16–17"> 彼らが王を呼ぶと、家を管理するヒルキヤの息子エリアキム、書記官シェブナ、記録官であるアサフの息子ヨアが彼らのところに出て来た。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 36:4; 列王記第二 19:10; イザヤ書 10:8–14"> ラブシャケは彼らに言った。「さあ、ヒゼキヤに言え。『大王、アッシリアの王はこう言われる。「あなたが頼みとしているこの頼みは何なのか。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 21:30–31"> あなたは『戦いのための策と力がある』と言うが、それは口先だけの言葉にすぎない。いったい何を頼みとして、わたしに背いたのか。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 30:7; エゼキエル書 29:6–7; イザヤ書 30:2–3"> 今、あなたはこの傷ついた葦の杖、すなわちエジプトを頼みとしている。人がそれに寄りかかれば、折れてその手を刺し貫く。エジプトの王ファラオは、彼を頼みとするすべての者にとってそのようである。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代誌 第二 31:1; 列王記第二 18:4–5; マタイ 27:43"> しかし、もしあなたがたがわたしに、『われわれはわれわれの神、主に頼む』と言うなら、ヒゼキヤがその高き所と祭壇を取り除き、ユダとエルサレムに『あなたがたはエルサレムにあるこの祭壇の前で拝まなければならない』と言った、その方ではないか。」</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記第一 17:42; 列王記第一 20:10; ネヘミヤ記 4:2–5"> さあ、わたしの主君、アッシリアの王と賭けをしてみよ。あなたが乗り手をそろえられるなら、二千頭の馬を与えよう。</span>
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 10:8; 申命記 17:16; イザヤ書 36:6"> それなら、どうしてあなたはわたしの主君のしもべたちのうち最も小さな隊長一人さえ退けることができようか。まして、戦車と騎兵のためにエジプトを頼みとするとは。</span>
<span className="v" id="v25" data-v="25" data-xref="列王記第二 19:6; イザヤ書 10:5–6; 列王記第二 19:22–37"> わたしが今、この場所を滅ぼすために主によらずに上って来たであろうか。主はわたしに、「この地に上って行き、それを滅ぼせ」と言われたのだ。』」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="エズラ記 4:7; ダニエル書 2:4; イザヤ書 36:11–12"> ヒルキヤの息子エリアキムとシェブナとヨアは、ラブシャケに言った。「どうか、あなたのしもべたちにアラム語で話してください。われわれはそれを理解できるからです。城壁の上にいる民が聞いているところで、ユダの言葉でわれわれと話さないでください。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="詩篇 73:8; 哀歌 4:5; エゼキエル書 4:15"> しかしラブシャケは彼らに言った。「わたしの主君はあなたの主君とあなたにこれらの言葉を語るためにわたしを遣わしたのだろうか。彼は、あなたがたとともに自分たちの糞を食い、自分たちの尿を飲むために城壁の上に座っている男たちに、わたしを遣わしたのではないか。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="イザヤ書 36:13–18; イザヤ書 10:8–13; エゼキエル書 29:3"> それからラブシャケは立ち、ユダの言葉で大声で叫び、語った。「大王、アッシリアの王の言葉を聞け。</span>
<span className="v" id="v29" data-v="29" data-xref="歴代誌 第二 32:15; テサロニケ人への第二の手紙 2:8; 歴代誌 第二 32:11"> 王はこう言われる。『ヒゼキヤに欺かれてはならない。彼は彼の手からあなたがたを救い出すことはできないからだ。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 125:1–2; ルカ 23:35; 列王記第二 19:32–34"> ヒゼキヤが「主は必ずわれわれを救い出され、この町はアッシリアの王の手に引き渡されることはない」と言って、あなたがたに主を頼みとさせてはならない。</span>
<span className="v" id="v31" data-v="31" data-xref="列王記第一 4:25; 列王記第一 4:20; ゼカリヤ書 3:10"> ヒゼキヤに聞き従うな。』アッシリアの王はこう言われる。『わたしと和を結び、わたしのもとに出て来い。そうすれば、それぞれ自分のぶどうの木といちじくの木の実を食べ、自分の井戸の水を飲める。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 8:7–9; 出エジプト記 3:8; 申命記 11:12"> わたしが来て、あなたがたをあなたがた自身の地のような地、穀物と新しいぶどう酒の地、パンとぶどう畑の地、オリーブの木とはちみつの地へ連れ去るまでである。そうして、あなたがたは生きて死なない。ヒゼキヤが「主はわれわれを救い出される」と言ってあなたがたを説き伏せようとするとき、彼に聞き入れてはならない。</span>
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 10:10–11; 列王記第二 19:12–13; 歴代誌 第二 32:19"> 諸国の神々のうち、その地をアッシリアの王の手から救い出した者が、かつていただろうか。</span>
<span className="v" id="v34" data-v="34" data-xref="イザヤ書 10:9; 列王記第二 17:23–33; エレミヤ書 49:23"> ハマテとアルパドの神々はどこにいるか。セファルワイム、ヘナ、イワの神々はどこにいるか。彼らはサマリアをわたしの手から救い出したか。</span>
<span className="v" id="v35" data-v="35" data-xref="ダニエル書 3:15; イザヤ書 10:15; 出エジプト記 5:2"> これらの国々のすべての神々のうち、だれが自分の国をわたしの手から救い出したので、主がエルサレムをわたしの手から救い出せるというのか。』」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="アモス書 5:13; 箴言 9:7; マタイ 7:6"> しかし民は黙っており、彼にひと言も答えなかった。王の命令が、「彼に答えてはならない」というものだったからである。</span>
<span className="v" id="v37" data-v="37" data-xref="列王記第二 22:11; 創世記 37:29; 列王記第二 5:7"> それから、家を管理するヒルキヤの息子エリアキム、書記官シェブナ、および記録官であるアサフの息子ヨアは、服を引き裂いてヒゼキヤのところに来て、ラブシャケの言葉を彼に告げた。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ハガイ書 1:11; 列王記第二 4:31–35; ルツ記 1:1"> さて、エリシャはその息子を生き返らせた女に語った。「起きて、あなたの家族とともに行き、滞在できるところならどこにでもしばらく滞在しなさい。主がききんを呼び寄せられたからである。それはまた、七年間この地に臨むであろう。」</span>
<span className="v" id="v2" data-v="2" data-xref="テモテへの手紙第一 5:8; 士師記 3:3; サムエル記第一 27:1–3"> 女は起き上がり、神の人の言葉にしたがって出て行った。彼女は家族とともに行き、ペリシテ人の地に七年間住んだ。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 22:16; ルカ 18:3–5; 列王記第二 4:13"> 七年の終わりに、女はペリシテ人の地から帰って来た。それから彼女は、自分の家と自分の土地のために王に訴え出た。</span>
<span className="v" id="v4" data-v="4" data-xref="列王記第二 5:20–27; 列王記第二 2:14; 列王記第二 6:32"> さて、王は神の人のしもべであるゲハジと話しており、「どうか、エリシャがしたすべての偉大なことをわたしに話してくれ」と言っていた。</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第二 4:35; マタイ 10:29–30; 列王記第二 6:26"> ゲハジが、エリシャが死者を生き返らせた出来事を王に話していると、ちょうどその時、息子を生き返らせてもらった女が、自分の家と土地を返してもらおうと王に訴え出た。ゲハジは言った。「わが君、王よ、この女です。これがエリシャの生き返らせた息子です。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="箴言 16:7; 箴言 21:1; サムエル記第二 9:7"> 王が女に尋ねると、彼女は彼に語った。そこで王は彼女のために一人の役人を任命し、言った。「彼女のものだったすべてと、彼女がこの地を去った日から今に至るまでの、畑のすべての産物を返しなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王記第一 11:24; 列王記第二 6:24; 列王記第一 20:1"> エリシャはダマスコに来た。アラムの王ベン・ハダドは病気であった。彼は「神の人がここに来ました」と告げられた。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王記第一 19:15; 列王記第二 1:2; サムエル記第一 9:7"> 王はハザエルに言った。「手に贈り物を取り、行って神の人を迎えなさい。そして彼を通して主に伺いを立て、『わたしはこの病気から回復するだろうか』と言いなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王記第二 5:13; 列王記第二 13:14; 列王記第一 19:15"> そこでハザエルは彼を迎えに行き、ダマスコのあらゆる良いものを贈り物として携えた。それは四十頭のらくだの荷となるほどであった。彼はエリシャの前に立って言った。「あなたの息子であるアラムの王ベン・ハダドがわたしをあなたに遣わし、『わたしはこの病気から回復するだろうか』と言っています。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="アモス書 7:7; 創世記 2:17; アモス書 7:1"> エリシャは彼に言った。「行って、彼に『あなたは必ず回復する』と言いなさい。しかし主は、彼が必ず死ぬことをわたしに示された。」</span>
<span className="v" id="v11" data-v="11" data-xref="ルカ 19:41; ローマ人への手紙 9:2; エレミヤ書 9:18"> エリシャはハザエルが耐えられなくなるほど、じっと彼を見つめた。やがて神の人は泣き出した。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ホセア書 13:16; ナホム書 3:10; 列王記第二 15:16"> ハザエルは言った。「なぜわが主君は泣くのですか。」<br />彼は答えた。「あなたがイスラエルの子らに対して行う悪を、わたしが知っているからだ。あなたは彼らの要害に火を放ち、彼らの若者たちを剣で殺し、彼らの幼い子どもたちを粉々に打ち砕き、彼らの身重の女たちを切り裂くであろう。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="サムエル記第一 17:43; 列王記第一 19:15; サムエル記第二 9:8"> ハザエルは言った。「犬にすぎないこのしもべに、どうしてそのような大それたことができましょう。」<br />エリシャは答えた。「主はあなたがアラムの王となることを、わたしに示された。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王記第二 8:10; マタイ 26:16; 列王記第二 5:25"> それから彼はエリシャから去り、自分の主人のところへ帰った。主人は彼に、「エリシャはあなたに何と言ったか」と言った。<br />彼は答えた。「彼はわたしに、あなたが必ず回復すると言いました。」</span>
<span className="v" id="v15" data-v="15" data-xref="列王記第二 8:13; 列王記第一 15:28; 列王記第一 11:26–37"> 翌日、ハザエルは厚い布を水に浸して王の顔にかぶせ、王を死なせた。そしてハザエルが代わって王となった。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王記第二 1:17; 列王記第二 3:1; 歴代誌 第二 21:1–20"> イスラエルの王、アハブの子ヨラムの第五年、ヨシャファテがなおユダの王であった時に、その子エホラムがユダの王となった。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代誌 第二 21:5–10"> 彼が王となったときは三十二歳であった。彼はエルサレムで八年間治めた。</span>
<span className="v" id="v18" data-v="18" data-xref="列王記第二 8:26; 列王記第一 11:1–5; 歴代誌 第二 21:13"> アハブの家がしたように、彼はイスラエルの王たちの道を歩んだ。彼はアハブの娘を妻としていたからである。彼は主の目に悪とされることを行った。</span>
<span className="v" id="v19" data-v="19" data-xref="列王記第一 11:36; サムエル記第二 7:12–13; ルカ 1:32–33"> しかし主は、そのしもべダビデのゆえに、ユダを滅ぼそうとはされなかった。それは彼とその子孫にいつもともしびを与えるために、彼に約束されたからである。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王記第一 22:47; 列王記第二 3:9; 列王記第二 8:22"> 彼の時代に、エドムはユダの手の下から背き、自分たちの上に王を立てた。</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記第二 18:17"> そこでヨラムは全戦車隊を率いてツァイルへ渡った。夜のうちに立ち上がり、自分を包囲していたエドム人と戦車隊の長たちを打ち破ったが、兵たちはそれぞれ自分の天幕へ逃げ帰った。</span>
<span className="v" id="v22" data-v="22" data-xref="列王記第二 19:8; ヨシュア記 21:13; 創世記 27:40"> こうしてエドムはユダの手の下から背き、今日に至っている。それからリブナも同じ時に背いた。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王記第二 15:36; 列王記第一 11:41; 歴代誌 第二 21:11–20"> ヨラムのその他の事績と、彼が行ったすべてのことは、ユダの王たちの年代記の書に記されているではないか。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代誌 第二 22:6; 歴代誌 第二 25:23; 歴代誌 第二 21:1"> ヨラムは先祖とともに眠りにつき、ダビデの町で先祖とともに葬られた。そしてその息子アハズヤが代わって王となった。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王記第二 9:29; 列王記第二 8:16–17; 歴代誌 第二 21:20–6"> イスラエルの王、アハブの息子ヨラムの第十二年に、ユダの王エホラムの息子アハズヤが王となった。</span>
<span className="v" id="v26" data-v="26" data-xref="歴代誌 第二 22:2; 列王記第二 9:21–27; 列王記第二 11:1"> アハズヤが王となったときは二十二歳であり、エルサレムで一年間治めた。彼の母の名はアタルヤといい、イスラエルの王オムリの娘であった。</span>
<span className="v" id="v27" data-v="27" data-xref="歴代誌 第二 22:3–4; コリント人への第二の手紙 6:14–17; 伝道者の書 7:26"> 彼はアハブの家の道を歩み、アハブの家がしたように、主の目に悪とされることを行った。彼はアハブの家の婿であったからである。</span>
<span className="v" id="v28" data-v="28" data-xref="歴代誌 第二 22:5; 列王記第一 4:13; 歴代誌 第二 19:2"> 彼はアハブの息子ヨラムとともに、ラモテ・ギレアデでアラムの王ハザエルと戦うために行き、アラム人はヨラムを傷つけた。</span>
<span className="v" id="v29" data-v="29" data-xref="列王記第二 9:15–16; 列王記第二 8:28; 歴代誌 第二 22:5–7"> ヨラム王は、アラムの王ハザエルと戦ったときにラマでアラム人が彼に負わせた傷をいやすために、イズレエルへ帰った。ユダの王エホラムの息子アハズヤは、アハブの息子ヨラムが病気であったため、彼を見舞うためにイズレエルへ下って行った。</span>
</div>
</div>

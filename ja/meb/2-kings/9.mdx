<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記第一 10:1; 列王記第二 4:29; 列王記第一 1:39"> 預言者エリシャは預言者の子らの一人を呼んで、彼に言った。「あなたの腰に帯を締め、この油の壺を手に持って、ラモテ・ギレアデへ行きなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="列王記第二 9:5; 列王記第一 19:16–17; 列王記第二 9:11"> そこに着いたなら、そこでニムシの子ヨシャファテの息子イエフを探し、中に入り、彼を仲間たちの中から立たせて、奥の部屋へ連れて行きなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="列王記第一 19:16; 出エジプト記 29:7; サムエル記第一 16:2"> それから油の壺を取り、彼の頭に注いで、『主はこう言われる。「わたしはあなたに油を注いでイスラエルの上の王とする」』と言いなさい。それから戸を開け、逃げなさい。待っていてはならない。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> そこで若い預言者はラモテ・ギレアデへ行った。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 3:19"> 彼が着くと、軍の長たちが座っていた。若者は言った。「隊長、あなたにお伝えすることがあります。」<br />イエフは言った。「われわれのうち、だれにだ。」<br />彼は言った。「隊長、あなたです。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歴代誌 第二 22:7; 列王記第一 19:16; 列王記第二 9:3"> 彼は立ち上がって、家の中に入った。すると若者は彼の頭に油を注いで彼に言った。「イスラエルの神、主はこう言われる。『わたしはあなたに油を注いで主の民、すなわちイスラエルの上の王とする。</span>
<span className="v" id="v7" data-v="7" data-xref="列王記第一 21:15; 列王記第一 18:4; 申命記 32:43"> あなたは主君アハブの家を打たなければならない。こうしてわたしは、イゼベルの手にかかった、わたしのしもべである預言者たちと、主のすべてのしもべたちの血に報いる。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記第一 25:22; 申命記 32:36; 列王記第二 14:26"> アハブの全家は滅びる。わたしはイスラエルで、壁に放尿するすべての者<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「男子」。">a</a></sup>を、閉じ込められている者も自由な者も、アハブの家から断ち切る。</span>
<span className="v" id="v9" data-v="9" data-xref="列王記第一 15:29; 列王記第一 21:22; 列王記第一 14:10–11"> わたしはアハブの家をネバテの息子ヤロブアムの家のようにし、アヒヤの息子バシャの家のようにする。</span>
<span className="v" id="v10" data-v="10" data-xref="列王記第一 21:23; 列王記第二 9:35–36; 列王記第二 9:3"> 犬がイズレエルの地所でイゼベルを食うであろう。彼女を葬る者はだれもいない。』」それから彼は戸を開け、逃げた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 29:26; 使徒の働き 26:24; ホセア書 9:7"> それからイエフは主君のしもべたちのところに出て来た。ある者が彼に言った。「無事か。なぜあの気の触れた男があなたのところに来たのか。」<br />イエフは答えた。「あの男がどんな者で、何を言いそうか、あなたがたも知っているだろう。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 彼らは言った。「ごまかすな。さあ、話してくれ。」<br />彼は言った。「彼はわたしにこのように語り、『主はこう言われる。「わたしはあなたに油を注いでイスラエルの上の王とする」』と言った。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マルコ 11:7–8; 列王記第一 1:39; 列王記第一 1:34"> すると彼らは急ぎ、各自が自分の上着を取り、階段の頂にある彼の下に置き、角笛を吹き鳴らして、「イエフが王だ」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王記第二 8:28; 列王記第一 22:3; 列王記第一 16:16"> こうしてニムシの子ヨシャファテの息子イエフは、ヨラムに対して陰謀を企てた。（さて、ヨラムと全イスラエルは、アラムの王ハザエルのゆえにラモテ・ギレアデを守っていた。</span>
<span className="v" id="v15" data-v="15" data-xref="列王記第二 8:29; サムエル記第一 27:9–11; 歴代誌 第二 22:6"> しかし、ヨラム王はアラムの王ハザエルと戦ったときにアラム人が彼に負わせた傷をいやすため、イズレエルへ帰っていた。）<br />イエフは言った。「あなたがたも同じ考えなら、だれ一人この町から逃がしてはならない。イズレエルへ知らせに行かせるな。」</span>
<span className="v" id="v16" data-v="16" data-xref="歴代誌 第二 22:6–7; 列王記第二 8:28–29"> そこでイエフは戦車に乗り、イズレエルへ行った。ヨラムがそこに横たわっていたからである。ユダの王アハズヤはヨラムを見舞うために下って来ていた。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="サムエル記第一 16:4; エゼキエル書 33:2–9; 列王記第二 7:14"> イズレエルのやぐらに立っていた見張りは、近づいて来るイエフの一隊を見て、「一隊が見えます」と報告した。<br />ヨラムは言った。「騎兵を一人選んで、彼らを迎えに遣わし、『平和か』と言わせよ。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王記第二 9:19; 列王記第二 9:22; エレミヤ書 16:5"> そこで馬に乗った男が彼を迎えに行き、「王が『平和か』と言っておられます」と言った。<br />イエフは言った。「あなたに平和と何のかかわりがあるのか。わたしの後ろに従え！」<br />見張りは、「使者は彼らのところに行きましたが、戻って来ません」と告げた。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> そこで彼は二人目の馬に乗った者を遣わした。彼は彼らのところに来て言った。「王が『平和か』と言っておられます。」<br />イエフは答えた。「あなたに平和と何のかかわりがあるのか。わたしの後ろに従え！」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="サムエル記第二 18:27; 列王記第一 19:17; 伝道者の書 9:10"> 見張りは報告した。「彼も一隊のところまで行きましたが、戻って来ません。戦車の駆り方はニムシの子イエフのようです。猛烈に駆っています。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王記第一 21:1–7; 歴代誌 第二 22:7; ミカ書 1:13"> ヨラムは言った。「準備せよ！」彼らは彼の戦車を準備した。イスラエルの王ヨラムとユダの王アハズヤは、それぞれ自分の戦車で出て行き、イエフを迎えに出た。彼らはイズレエル人ナボテの地所で彼を見つけた。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代誌 第二 21:13; ナホム書 3:4; 列王記第一 16:30–33"> ヨラムはイエフを見たとき、言った。「平和か、イエフよ。」<br />イエフは答えた。「あなたの母イゼベルの淫行と呪術がこれほどはびこっているのに、何の平和があるか。」</span>
<span className="v" id="v23" data-v="23" data-xref="列王記第二 11:14; 歴代誌 第二 23:13"> ヨラムは手綱を返して逃げ、アハズヤに叫んだ。「謀反だ、アハズヤ！」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王記第一 22:34; 箴言 21:30; テサロニケ人への手紙第一 5:3"> イエフは力いっぱい弓を引き、ヨラムの両腕の間を射た。矢は彼の心臓を貫き抜け、彼は戦車の中に崩れ落ちた。</span>
<span className="v" id="v25" data-v="25" data-xref="列王記第一 21:19; 列王記第一 21:24–29; イザヤ書 13:1"> イエフは副官ビデカルに言った。「彼を持ち上げ、イズレエル人ナボテの畑に投げ捨てよ。あなたとわたしが並んで彼の父アハブの後に従っていた時、主が彼にこの宣告を下されたことを思い出せ。</span>
<span className="v" id="v26" data-v="26" data-xref="列王記第一 21:19; 申命記 5:9; 歴代誌 第二 25:4"> 『確かにわたしは昨日、ナボテの血と彼の息子たちの血を見た』と主は言われる。『わたしはこの地所であなたに報いる』と主は言われる。だから今、主の言葉のとおりに、彼を取ってその地所に投げ捨てよ。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="士師記 1:27; ヨシュア記 17:11; 列王記第二 8:29"> ユダの王アハズヤはこれを見ると、園の家の道を通って逃げた。イエフは彼の後を追い、「彼も戦車の中で打て！」と言った。彼らはイブレアムのそばにあるグルの上り坂で彼を打った。彼はメギドへ逃げ、そこで死んだ。</span>
<span className="v" id="v28" data-v="28" data-xref="歴代誌 第二 35:24; 列王記第二 23:30; 列王記第二 12:21"> 彼のしもべたちは彼を戦車でエルサレムに運び、ダビデの町にある彼の墓に、彼の先祖とともに彼を葬った。</span>
<span className="v" id="v29" data-v="29" data-xref="歴代誌 第二 21:18–19; 歴代誌 第二 22:1–2; 列王記第二 8:24–25"> アハブの息子ヨラムの第十一年に、アハズヤはユダの王となっていた。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 4:30; エゼキエル書 23:40; エゼキエル書 24:17"> イエフがイズレエルに来たとき、イゼベルはそれを聞いた。彼女は目に化粧を施し、頭を飾り、窓から見下ろした。</span>
<span className="v" id="v31" data-v="31" data-xref="列王記第一 16:9–20"> イエフが門に入ると、彼女は言った。「ジムリよ、主君殺しよ。無事か。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="エステル記 2:15; 出エジプト記 32:26; 歴代誌 第二 11:12"> 彼は窓に顔を上げ、そして言った。「だれがわたしの味方か。だれか。」二、三人の宦官が彼を見下ろした。</span>
<span className="v" id="v33" data-v="33" data-xref="ミカ書 7:10; 哀歌 1:15; イザヤ書 25:10"> イエフが「彼女を突き落とせ！」と命じると、彼らはイゼベルを突き落とした。血が壁と馬に飛び散り、イエフは彼女を踏みつけた。</span>
<span className="v" id="v34" data-v="34" data-xref="列王記第一 16:31; 列王記第一 21:25; イザヤ書 65:15"> 彼が中に入り、飲み食いした後、彼は言った。「さあ、この呪われた女の始末をして、彼女を葬れ。彼女は王の娘だからだ。」</span>
<span className="v" id="v35" data-v="35" data-xref="使徒の働き 12:23; イザヤ書 14:18–20; ヨブ記 31:3"> 彼らは彼女を葬りに行ったが、頭蓋骨と両足と手のひらのほかには何も見つからなかった。</span>
<span className="v" id="v36" data-v="36" data-xref="列王記第一 21:23; レビ記 8:36; 列王記第二 14:25"> それゆえ彼らは戻って来て、彼に告げた。彼は言った。「これは主の言葉だ。主がそのしもべであるティシュベ人エリヤを通して語られた。『犬がイズレエルの地所でイゼベルの肉を食うであろう。</span>
<span className="v" id="v37" data-v="37" data-xref="エレミヤ書 8:2; 詩篇 83:10; エレミヤ書 16:4"> イゼベルの死体は、イズレエルの地所で野の肥やしのようになる。だれも『これがイゼベルだ』と見分けることはできない。』」</span>
</div>
</div>

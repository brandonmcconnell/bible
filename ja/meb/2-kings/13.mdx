<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王記第二 11:21; 列王記第二 8:26; 列王記第二 11:4"> ユダの王、アハズヤの息子ヨアシュの第二十三年に、イエフの息子エホアハズがサマリアでイスラエルの王となり、十七年間治めた。</span>
<span className="v" id="v2" data-v="2" data-xref="列王記第一 12:26–33; 列王記第一 14:16; 列王記第二 10:29"> 彼は主の目に悪とされることを行い、イスラエルに罪を犯させたネバテの子ヤロブアムの罪に従い、そこから離れなかった。</span>
<span className="v" id="v3" data-v="3" data-xref="列王記第一 19:17; 列王記第二 13:24–25; 士師記 2:14"> 主の怒りがイスラエルに対して燃え上がり、主はエホアハズの生涯、彼らをアラムの王ハザエルと、その子ベン・ハダドの手に渡された。</span>
<span className="v" id="v4" data-v="4" data-xref="列王記第二 14:26; 出エジプト記 3:7; 詩篇 78:34"> エホアハズが主に願い求めると、主はその願いを聞き入れられた。アラムの王がイスラエルを圧迫しているのをご覧になったからである。</span>
<span className="v" id="v5" data-v="5" data-xref="ネヘミヤ記 9:27; 列王記第二 14:25; 列王記第二 14:27"> （主はイスラエルに一人の救い主を与えられたので、彼らはアラム人の手の下から逃れ出た。そしてイスラエルの子らは以前のように自分たちの天幕に住んだ。</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第一 16:33; 列王記第二 13:2; 申命記 7:5"> それにもかかわらず、彼らはイスラエルに罪を犯させたヤロブアムの家の罪から離れず、その中を歩んだ。アシェラ像もまたサマリアに残っていた。）</span>
<span className="v" id="v7" data-v="7" data-xref="アモス書 1:3; 列王記第二 10:32; 列王記第一 20:15"> アラムの王はエホアハズに、騎兵五十人、戦車十台、歩兵一万人しか残さなかった。彼らを滅ぼし、脱穀場のちりのようにしたのである。</span>
<span className="v" id="v8" data-v="8" data-xref="列王記第一 11:4; 列王記第一 14:29; 列王記第一 14:31"> エホアハズのその他の事績、彼が行ったすべてのこと、および彼の力は、イスラエルの王たちの年代記の書に記されているではないか。</span>
<span className="v" id="v9" data-v="9" data-xref="列王記第二 10:35; 列王記第二 13:13; 列王記第二 14:8"> エホアハズは先祖とともに眠りにつき、彼らは彼をサマリアに葬った。そしてその息子ヨアシュが代わって王となった。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> ユダの王ヨアシュの第三十七年に、エホアハズの息子エホアシュがサマリアでイスラエルの王となり、十六年間治めた。</span>
<span className="v" id="v11" data-v="11" data-xref="列王記第二 13:2; 列王記第二 10:29; 列王記第二 3:3"> 彼は主の目に悪とされることを行った。彼はイスラエルに罪を犯させたネバテの息子ヤロブアムのすべての罪から離れず、その中を歩んだ。</span>
<span className="v" id="v12" data-v="12" data-xref="列王記第二 13:14–25; 列王記第二 14:8–16; 歴代誌 第二 25:17–24"> ヨアシュのその他の事績、彼が行ったすべてのこと、彼がユダの王アマツヤと戦ったときの彼の力は、イスラエルの王たちの年代記の書に記されているではないか。</span>
<span className="v" id="v13" data-v="13" data-xref="列王記第一 1:21; 列王記第二 14:28–29; 列王記第一 2:10"> ヨアシュは先祖とともに眠りにつき、ヤロブアムが彼の王座に座った。ヨアシュはイスラエルの王たちとともにサマリアに葬られた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王記第二 2:12; ピリピ人への手紙 2:26; 創世記 48:1"> さて、エリシャは死に至る病にかかった。イスラエルの王ヨアシュは彼のもとへ下り、すがって泣いた。「わが父よ、わが父よ。イスラエルの戦車と騎兵よ！」</span>
<span className="v" id="v15" data-v="15"> エリシャは彼に言った。「弓と矢を取りなさい。」そこで彼は弓と矢を取った。</span>
<span className="v" id="v16" data-v="16" data-xref="列王記第二 4:34; 創世記 49:24; 詩篇 144:1"> エリシャはイスラエルの王に言った。「あなたの手を弓に置きなさい。」彼が手を置くと、エリシャは王の手の上に自分の手を置いた。</span>
<span className="v" id="v17" data-v="17" data-xref="列王記第一 20:26; 列王記第二 5:10–14; コリント人への第一の手紙 1:18"> そして彼は言った。「東の窓を開けなさい。」彼がそれを開けると、エリシャは「射なさい」と言った。彼が射ると、彼は言った。「主の救いの矢、アラムからの救いの矢。あなたはアフェクでアラム人を打ち、ついに彼らを滅ぼすであろう。」</span>
<span className="v" id="v18" data-v="18" data-xref="列王記第二 4:6; 出エジプト記 17:11; イザヤ書 20:2–4"> 彼はまた、「矢を取りなさい」と言った。彼がそれを取ると、エリシャはイスラエルの王に、「地面を打ちなさい」と言った。彼は三度打って、やめた。</span>
<span className="v" id="v19" data-v="19" data-xref="列王記第二 13:25; 民数記 16:15; 列王記第二 4:40"> 神の人は王に腹を立てて言った。「五度か六度打つべきだった。そうすれば、アラムを完全に打ち滅ぼせたものを。今となっては、アラムを打つのは三度だけだ。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王記第二 24:2; 列王記第二 3:7; 列王記第二 6:23"> エリシャは死に、彼らは彼を葬った。さて、年が改まるころ、モアブ人の略奪隊がその地に侵入してきた。</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 37:1–10; 使徒の働き 19:12; ヨハネ 5:28–29"> 人々がある男を葬っていたとき、彼らは略奪隊を見つけた。そこで彼らはその男をエリシャの墓に投げ込んだ。男が下ろされてエリシャの骨に触れると、彼は生き返り、自分の足で立ち上がった。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="列王記第二 8:12; 列王記第二 13:3–7; 詩篇 106:40–42"> アラムの王ハザエルは、エホアハズの生涯イスラエルを苦しめた。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 105:8; 列王記第二 14:27; ミカ書 7:18–20"> しかし主は、アブラハム、イサク、ヤコブとの契約のゆえに彼らを恵み、あわれみ、顧みられた。彼らを滅ぼすことを望まず、今に至るまで御前から捨て去られなかった。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 125:3; ルカ 18:7"> アラムの王ハザエルは死に、その息子ベン・ハダドが代わって王となった。</span>
<span className="v" id="v25" data-v="25" data-xref="列王記第二 13:18–19; 列王記第二 10:32; 列王記第二 14:25"> エホアハズの息子エホアシュは、ハザエルの息子ベン・ハダドの手から、彼が戦いによって父エホアハズの手から奪った町々を再び奪い返した。ヨアシュは三度彼を打ち負かし、イスラエルの町々を回復した。</span>
</div>

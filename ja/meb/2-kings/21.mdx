<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 62:4; 歴代誌 第二 32:33–9; マタイ 1:10"> マナセが王となったときは十二歳で、エルサレムで五十五年間治めた。彼の母の名はヘフジバといった。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 12:31; 歴代誌 第二 36:14; 歴代誌 第二 33:2–4"> 彼は、主がイスラエルの子らの前から追い払われた国々の忌むべきことの通りに、主の目に悪とされることを行った。</span>
<span className="v" id="v3" data-v="3" data-xref="列王記第二 18:4; 列王記第二 17:16; 申命記 17:3"> 彼は父ヒゼキヤが打ち壊した高き所を再び建て、アハブがイスラエルの王として行ったように、バアルのために祭壇を築き、アシェラ像を造り、天のすべての軍勢を拝み、これらに仕えた。</span>
<span className="v" id="v4" data-v="4" data-xref="列王記第一 8:29; サムエル記第二 7:13; エレミヤ書 32:34"> 彼は、主が「エルサレムにわたしの名を置く」と言われた主の家に祭壇を築いた。</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第一 7:12; 列王記第二 23:4; 列王記第二 23:12"> 彼は主の家の二つの庭に、天のすべての軍勢のために祭壇を築いた。</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第二 17:17; レビ記 19:31; レビ記 18:21"> 彼は自分の息子を火の中を通らせ、まじないと占いを行い、霊媒や口寄せに伺いを立てた。主の目に悪とされることを重ね、主を怒らせた。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌 第二 7:16; 列王記第一 9:3; サムエル記第二 7:13"> 彼は自分が造ったアシェラの刻まれた像を家に置いた。この家については、主がダビデとその息子ソロモンに言われていた。「わたしがイスラエルのすべての部族の中から選んだこの家とエルサレムに、わたしの名をとこしえに置く。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記第二 7:10; 申命記 5:28–29; 詩篇 81:11–16"> もし彼らが、わたしが彼らに命じたすべてのこと、およびわたしのしもべモーセが彼らに命じたすべての律法に従って注意深く行うなら、わたしはイスラエルの足を、わたしが彼らの先祖に与えた地から二度とさまよい出させることはしない。」</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 29:12; ネヘミヤ記 9:26; 列王記第一 14:16"> しかし彼らは聞き入れなかった。マナセは彼らを惑わし、主がイスラエルの子らの前から滅ぼされた国々よりもさらに多くの悪を行わせた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="マタイ 23:34–37; 歴代誌 第二 33:10; 歴代誌 第二 36:15"> 主はそのしもべである預言者たちを通して語られた。</span>
<span className="v" id="v11" data-v="11" data-xref="列王記第二 24:3–4; 列王記第一 21:26; 列王記第二 21:9"> 「ユダの王マナセがこれらの忌むべきことを行い、彼より前にいたアモリ人が行ったすべてのことよりも悪を行い、彼が造った偶像によってユダにも罪を犯させたので、</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 19:3; サムエル記第一 3:11; ダニエル書 9:12"> それゆえ、イスラエルの神、主はこう言われる。『見よ、わたしはエルサレムとユダにわざわいをもたらす。それを聞く者は皆、両耳が鳴るであろう。</span>
<span className="v" id="v13" data-v="13" data-xref="アモス書 7:7–8; 哀歌 2:8; イザヤ書 34:11"> わたしはエルサレムの上に、サマリアの測り縄とアハブの家の下げ振りを伸ばす。人が皿をぬぐい、ぬぐってそれを伏せるように、わたしはエルサレムをぬぐい去る。</span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 23:33; 列王記第二 19:4; 詩篇 89:38–45"> わたしは、わたしの所有の民の残りを捨て、敵の手に渡す。彼らはすべての敵のえじきとなり、略奪される。</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 20:30; 申命記 31:27; エゼキエル書 20:21"> 彼らがわたしの目に悪とされることを行い、先祖がエジプトから出た日から今日まで、わたしを怒らせ続けてきたからである。』」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数記 35:33; 歴代誌 第二 33:9; 列王記第二 21:11"> マナセは、ユダに罪を犯させて主の目に悪を行ったばかりでなく、罪のない者の血をおびただしく流し、エルサレムを端から端まで血で満たした。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王記第二 20:20–21; 歴代誌 第二 33:1–20"> マナセのその他の事績、彼が行ったすべてのこと、彼が犯した罪は、ユダの王たちの年代記の書に記されているではないか。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代誌 第二 33:20; 列王記第二 21:26; 歴代誌 第二 32:33"> マナセは先祖とともに眠りにつき、彼自身の家の園、すなわちウザの園に葬られた。そしてその息子アモンが代わって王となった。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="歴代誌 第二 33:21–23; 列王記第一 22:51; 歴代誌上 3:14"> アモンが王となったときは二十二歳で、エルサレムで二年間治めた。彼の母の名はメシュレメテといい、ヨトバのハルツの娘であった。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイ 23:32; 列王記第二 21:11; 使徒の働き 7:51"> 彼は父マナセが行ったように、主の目に悪とされることを行った。</span>
<span className="v" id="v21" data-v="21"> 彼は父が歩んだすべての道を歩み、父が仕えた偶像に仕え、これらを拝んだ。</span>
<span className="v" id="v22" data-v="22" data-xref="列王記第二 22:17; 列王記第一 11:33; 歴代誌上 28:9"> 彼は彼の先祖の神、主を捨て、主の道を歩まなかった。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王記第二 12:20; 列王記第二 14:19; 歴代誌 第二 33:24–25"> アモンのしもべたちは彼に対して陰謀を企て、王を彼自身の家で殺した。</span>
<span className="v" id="v24" data-v="24" data-xref="列王記第二 14:5; 列王記第二 11:17; 列王記第二 14:21"> その地の民は、アモン王に対して陰謀を企てた者たちをすべて打ち殺し、その地の民はその息子ヨシヤを彼の代わりに王とした。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王記第二 20:20; 列王記第二 21:17"> アモンが行ったその他の事績は、ユダの王たちの年代記の書に記されているではないか。</span>
<span className="v" id="v26" data-v="26" data-xref="列王記第二 21:18; マタイ 1:10; 列王記第一 13:5"> 彼はウザの園にある彼自身の墓に葬られた。そしてその息子ヨシヤが代わって王となった。</span>
</div>
</div>

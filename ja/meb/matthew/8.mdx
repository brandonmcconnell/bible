<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="MAT" data-book-slug="matthew" data-book-name="マタイ" data-chapter="8" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 8:18; マタイ 4:25–1; ルカ 5:15"> イエスが山を下りられると、大勢の群衆が従った。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 15:25; ルカ 17:12–19; マタイ 18:26"> 見よ、重い皮膚病を患う人が近づいて来て、イエスを拝み、言った。「主よ、お望みになれば、私を清くすることがおできになります。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ルカ 5:13; 詩篇 33:9; 列王記第二 5:14"> イエスは手を伸ばして彼に触れ、<span className="woj">「そうしよう。清くなりなさい。」</span>と言われた。すると、彼の重い皮膚病はすぐに清められた。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 14:2–32; ルカ 5:14; ルカ 17:14"> イエスは彼に言われた。<span className="woj">「だれにも話さないように気をつけなさい。ただ行って、自分の体を祭司に見せ、彼らへのあかしとして、モーセが命じた供え物をささげなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ルカ 7:1–10; 使徒の働き 27:43; 使徒の働き 10:1–33"> イエスがカペナウムに入られると、一人の百人隊長が近づいて来て、助けを求め、</span>
<span className="v" id="v6" data-v="6" data-xref="コロサイ人への手紙 4:1; マタイ 4:24; 使徒の働き 9:33"> 言った。「主よ、私の僕が家で麻痺して寝たきりになり、ひどく苦しんでいます。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マタイ 9:18–19; ルカ 7:6; マルコ 5:23–24"> イエスは彼に言われた。<span className="woj">「私が行って、彼を癒そう。」</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="詩篇 107:20; ルカ 7:6–7; 詩篇 33:9"> 百人隊長は答えた。「主よ、あなたを私の屋根の下にお迎えする資格は、私にはありません。ただ、お言葉をください。そうすれば、私の僕は癒されます。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカ 4:35–36; テトス 2:9; コロサイ人への手紙 3:22"> 私も権威の下にある者ですが、私の下にも兵士たちがいます。私が一人に『行け』と言えば行き、別の者に『来い』と言えば来ます。また、私の僕に『これをせよ』と言えば、そのとおりにします。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="マタイ 15:28; ルカ 7:9; マルコ 6:6"> イエスはこれを聞いて驚き、ついて来た人々に言われた。<span className="woj">「まことに、あなたがたに言う。イスラエルの中でさえ、これほど大きな信仰を見いだしたことはない。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ルカ 13:28–29; エペソ人への手紙 3:6; ガラテヤ人への手紙 3:28–29"> <span className="woj">あなたがたに言う。多くの人が東から西から来て、天の御国でアブラハム、イサク、ヤコブと共に食卓に着く。</span></span>
<span className="v" id="v12" data-v="12" data-xref="マタイ 25:30; ルカ 13:28; マタイ 21:43"> <span className="woj">しかし、御国の子らは外の闇に投げ出される。そこで泣き叫び、歯ぎしりする。」</span></span>
<span className="v" id="v13" data-v="13" data-xref="マタイ 9:29–30; マルコ 9:23; ヨハネ 4:50"> イエスは百人隊長に言われた。<span className="woj">「行きなさい。あなたが信じたとおりになるように。」</span>すると、ちょうどその時、僕は癒された。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ルカ 4:38–41; マルコ 1:29–34; コリント人への第一の手紙 9:5"> イエスがペテロの家に入られると、彼のしゅうとめが熱を出して寝込んでいるのをご覧になった。</span>
<span className="v" id="v15" data-v="15" data-xref="列王記第二 13:21; ルカ 4:38–39; ルカ 8:54"> イエスが彼女の手に触れると、熱が引いた。彼女は起き上がり、イエスに仕えた。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR本文では「イエスに」の代わりに「彼らに」となっている。">a</a></sup></span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 15:26; マタイ 14:14; マルコ 1:32–34"> 夕方になると、人々は悪霊につかれた者を大勢、イエスのもとに連れて来た。イエスは言葉によって霊を追い出し、病んでいる人をすべて癒された。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 53:4; ペテロの手紙第一 2:24; マタイ 1:22"> これは、預言者イザヤを通して、「彼は私たちの弱さを引き受け、私たちの病を担った」と語られたことが成就するためであった。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ルカ 4:42–43; ルカ 8:22; マルコ 4:35"> さて、イエスはご自分の周りに大勢の群衆がいるのを見ると、向こう岸へ渡るよう命じられた。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ルカ 22:33–34; ヨハネ 13:36–38; ルカ 14:25–27"> 一人の律法学者が近づいて来て言った。「先生、どこへ行かれても、私はあなたについて行きます。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="詩篇 84:3; ルカ 2:7; イザヤ書 53:2–3"> イエスは彼に言われた。<span className="woj">「狐には穴があり、空の鳥には巣がある。しかし、人の子には頭を横たえる場所もない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ルカ 9:59–62; レビ記 21:11–12; 民数記 6:6–7"> 弟子の一人がイエスに言った。「主よ、まず行って父を葬ることをお許しください。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="コロサイ人への手紙 2:13; ルカ 15:32; エペソ人への手紙 5:14"> しかしイエスは彼に言われた。<span className="woj">「私について来なさい。死者たちには、自分たちの死者を葬らせなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ルカ 8:22–25; マルコ 4:36–41; マタイ 9:1"> イエスが舟に乗られると、弟子たちも従った。</span>
<span className="v" id="v24" data-v="24" data-xref="ルカ 8:23; 詩篇 107:23–27; マルコ 4:37–38"> すると見よ、湖に激しい嵐が起こり、舟が波に覆われるほどになった。しかし、イエスは眠っておられた。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨナ書 1:6; 歴代誌 第二 14:11; マルコ 4:38–39"> 弟子たちは近寄ってイエスを起こし、言った。「主よ、私たちをお救いください。死んでしまいます。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="イザヤ書 41:10–14; 詩篇 65:7; 詩篇 107:28–30"> イエスは彼らに言われた。<span className="woj">「なぜ怖がるのか、信仰の薄い者たちよ。」</span>それから起き上がり、風と湖を叱りつけられると、すっかり凪になった。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="マルコ 7:37; マルコ 6:51; マタイ 14:33"> 人々は驚いて言った。「この方は、いったいどういう方なのだろう。風も湖も従うとは。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ルカ 8:26–39; マルコ 5:1–20; 使徒の働き 10:38"> イエスが向こう岸のゲルゲサ人の地方に着かれると、<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NU本文では「ガダラ人」となっている。">b</a></sup>悪霊につかれた二人の男が墓場から出て来て、イエスに出会った。彼らは非常に凶暴で、だれもその道を通れないほどだった。</span>
<span className="v" id="v29" data-v="29" data-xref="マルコ 1:24; ルカ 4:34; ヤコブの手紙 2:19"> 見よ、彼らは叫んで言った。「神の子イエスよ、私たちと何の関係があるのですか。定められた時より前に、私たちを苦しめるためにここへ来られたのですか。」</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 14:8; レビ記 11:7; マルコ 5:11"> 彼らから遠く離れた所で、多くの豚の群れが飼われていた。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの黙示録 20:1–2; ルカ 8:30–33; マルコ 5:12"> 悪霊たちはイエスに願って言った。「私たちを追い出すのなら、あの豚の群れに行かせてください。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="マルコ 5:13; 使徒の働き 2:23; ヨハネの黙示録 20:7"> イエスは彼らに、<span className="woj">「行け。」</span>と言われた。<br />すると悪霊たちは出て行き、豚の群れに入った。見よ、豚の群れはみな崖を駆け下りて湖に飛び込み、水の中で死んだ。</span>
<span className="v" id="v33" data-v="33" data-xref="ルカ 8:34–36; マルコ 5:14–16; 使徒の働き 19:15–17"> 豚を飼っていた者たちは逃げて町へ行き、悪霊につかれていた人々に起こったことを含め、すべてを知らせた。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒の働き 16:39; ルカ 8:37–39; ルカ 5:8"> 見よ、町中の人々がイエスに会うため出て来た。そしてイエスを見ると、自分たちの地域から立ち去ってくださるよう願った。</span>
</div>
</div>

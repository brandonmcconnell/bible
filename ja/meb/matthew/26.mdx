<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 7:28; マタイ 19:1"> イエスはこれらすべての言葉を語り終えると、弟子たちに言われた。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカ 22:1–2; マルコ 14:1–2; ヨハネ 13:1–2"> <span className="woj">「あなたがたも知っているように、二日後には過越の祭りが来る。そして人の子は、十字架につけられるために引き渡される。」</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ヨハネ 11:47–53; ヨハネ 18:24; マルコ 14:54"> そのころ、祭司長たち、律法学者たち、民の長老たちは、カヤパという大祭司の屋敷の中庭に集まった。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイ 12:14; 詩篇 2:2; 使徒の働き 13:10"> そして策略を用いてイエスを捕らえ、殺そうと相談した。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイ 27:24; マタイ 21:26; マタイ 14:5"> しかし彼らは、「祭りの間はいけない。民の間に騒ぎが起こるかもしれない」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="マルコ 14:3–9; ルカ 7:37–39; ヨハネ 12:1–8"> さて、イエスがベタニアで、重い皮膚病のシモンの家におられたとき、</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネ 12:2–3; ルカ 7:46; ルカ 7:37–38"> 一人の女が、非常に高価な香油の入った雪花石膏の壺を持って近づいて来た。そして、食卓に着いておられるイエスの頭に香油を注いだ。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネ 12:4–6; マルコ 14:4; 出エジプト記 5:17"> 弟子たちはこれを見て憤り、言った。「なぜ、こんな無駄なことをするのか。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネ 12:5–6; マルコ 14:5; ヨシュア記 7:20–21"> この香油なら高く売って、貧しい人々に施すことができたのに。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="テトス 3:8; ヘブル人への手紙 13:21; テモテへの手紙第一 5:10"> イエスはそれを知って、彼らに言われた。<span className="woj">「なぜこの女を困らせるのか。彼女は私に良いことをしてくれた。</span></span>
<span className="v" id="v11" data-v="11" data-xref="申命記 15:11; マルコ 14:7; ヨハネ 12:8"> <span className="woj">貧しい人々はいつもあなたがたと一緒にいるが、私はいつも一緒にいるわけではない。</span></span>
<span className="v" id="v12" data-v="12" data-xref="マルコ 14:8; ヨハネ 12:7; マルコ 16:1"> <span className="woj">彼女がこの香油を私の体に注いだのは、私の葬りの備えをするためである。</span></span>
<span className="v" id="v13" data-v="13" data-xref="マルコ 14:9; マタイ 24:14; 詩篇 112:6"> <span className="woj">まことに、あなたがたに言う。世界中どこででもこの福音が宣べ伝えられる所では、彼女のしたことも、彼女を記念するために語られる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ルカ 22:3–6; マタイ 10:4; マルコ 14:10–11"> そのとき、十二人の一人で、イスカリオテのユダと呼ばれる者が、祭司長たちのところへ行き、</span>
<span className="v" id="v15" data-v="15" data-xref="ゼカリヤ書 11:12–13; 創世記 37:26–28; 出エジプト記 21:32"> 言った。「あの人をあなたがたに引き渡せば、私に何をくれますか。」そこで彼らは、銀貨三十枚を量ってユダに渡した。</span>
<span className="v" id="v16" data-v="16" data-xref="マルコ 14:11; ルカ 22:6"> その時から、ユダはイエスを裏切る機会をうかがっていた。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ルカ 22:7–13; マルコ 14:12–16; 出エジプト記 12:18–20"> さて、種なしパンの祭りの初日に、弟子たちはイエスのもとに来て言った。「過越の食事をなさるために、どこで用意をしましょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="マルコ 14:13–16; ヨハネ 7:6; ヨハネ 17:1"> イエスは言われた。<span className="woj">「町に入り、ある人のところへ行って、こう言いなさい。『先生が、「私の時が近づいた。あなたの家で弟子たちと共に過越の祭りを守る」と言っています。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨハネ 2:5; ヨハネ 15:14; マタイ 21:6"> 弟子たちはイエスが命じられたとおりにして、過越の食事を用意した。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="マルコ 14:17–21; ヨハネ 13:21; ルカ 22:14–16"> 夕方になると、イエスは十二人の弟子たちと共に食卓に着かれた。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネ 13:21; ヘブル人への手紙 4:13; ヨハネ 6:70–71"> 一同が食事をしていると、イエスは言われた。<span className="woj">「まことに、あなたがたに言う。あなたがたのうちの一人が私を裏切る。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨハネ 13:22–25; ルカ 22:23; マルコ 14:19–20"> 弟子たちは非常に悲しみ、一人ひとりイエスに、「主よ、まさか私ではないでしょう」と尋ね始めた。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ヨハネ 13:18; 詩篇 41:9; ヨハネ 13:26–28"> イエスは答えられた。<span className="woj">「私と一緒に鉢に手を浸した者が、私を裏切る。</span></span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 26:22–23; ルカ 24:46; マタイ 18:7"> <span className="woj">人の子は、自分について書かれているとおりに去って行く。しかし、人の子を裏切るその人は災いである。その人は生まれなかったほうがよかった。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="マタイ 26:64; マタイ 27:11; ルカ 22:70"> イエスを裏切ろうとしていたユダが答えた。「先生、まさか私ではないでしょう。」<br />イエスは彼に言われた。<span className="woj">「あなたがそう言った。」</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="コリント人への第一の手紙 11:23–29; ルカ 22:18–20; コリント人への第一の手紙 10:16–17"> 一同が食事をしていると、イエスはパンを取り、それに感謝をささげ、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR本文では「感謝をささげた」の代わりに「祝福した」となっている。">a</a></sup>それを裂いて弟子たちに与え、言われた。<span className="woj">「取って食べなさい。これは私の体である。」</span></span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 25:6; コリント人への第一の手紙 10:16; 詩篇 116:13"> また杯を取り、感謝をささげて彼らに与え、言われた。<span className="woj">「みな、この杯から飲みなさい。</span></span>
<span className="v" id="v28" data-v="28" data-xref="ヘブル人への手紙 10:4–14; ヘブル人への手紙 9:14–22; レビ記 17:11"> <span className="woj">これは、罪の赦しのために多くの人のために流される、私の新しい契約の血である。</span></span>
<span className="v" id="v29" data-v="29" data-xref="ヘブル人への手紙 12:2; ヨハネの黙示録 7:17; マルコ 14:25"> <span className="woj">あなたがたに言う。今から、父の御国であなたがたと共に新しく飲むその日まで、私はこのぶどうの実から造ったものを決して飲まない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="マタイ 21:1; エペソ人への手紙 5:19–20; ルカ 22:39"> 一同は賛美の歌を歌ってから、オリーブ山へ出かけた。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ゼカリヤ書 13:7; マルコ 14:27–28; ヨハネ 16:32"> そのとき、イエスは彼らに言われた。<span className="woj">「今夜、あなたがたはみな、私のためにつまずく。『私は羊飼いを打つ。すると、群れの羊は散らされる』と書かれているからである。</span></span>
<span className="v" id="v32" data-v="32" data-xref="マタイ 28:10; ルカ 18:33–34; マタイ 28:16"> <span className="woj">しかし私は、よみがえった後、あなたがたより先にガリラヤへ行く。」</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="ルカ 22:33; ヨハネ 13:36–38; 箴言 28:25–26"> しかし、ペテロはイエスに答えた。「たとえみながあなたのためにつまずいても、私は決してつまずきません。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ヨハネ 13:38; ルカ 22:34; マタイ 26:75"> イエスは彼に言われた。<span className="woj">「まことに、あなたに言う。今夜、鶏が鳴く前に、あなたは三度、私を否む。」</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="ローマ人への手紙 11:20; ヨハネ 13:37; 箴言 29:23"> ペテロは言った。「たとえあなたと一緒に死ななければならなくても、決してあなたを否みません。」弟子たちもみな、同じように言った。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="マルコ 14:32–42; マタイ 26:42; ルカ 22:39–46"> それからイエスは弟子たちと共に、ゲツセマネという所に来て、彼らに言われた。<span className="woj">「私が向こうへ行って祈っている間、ここに座っていなさい。」</span></span>
<span className="v" id="v37" data-v="37" data-xref="マタイ 4:21; マタイ 17:1; マルコ 5:37"> そしてペテロとゼベダイの二人の息子を連れて行き、深く悲しみ、激しく苦悩し始められた。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネ 12:27; ペテロの手紙第一 3:18; ペテロの手紙第一 2:24"> そのとき、イエスは彼らに言われた。<span className="woj">「私の心は、死ぬほど深く悲しんでいる。ここにとどまり、私と共に目を覚ましていなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="ヨハネ 6:38; ピリピ人への手紙 2:8; ルカ 22:41–42"> イエスは少し先へ進み、ひれ伏して祈り、言われた。<span className="woj">「わが父よ、できることなら、この杯を私から過ぎ去らせてください。しかし、私が望むようにではなく、あなたがお望みになるようになさってください。」</span></span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="マルコ 14:37; ルカ 22:45; マタイ 26:43"> それから弟子たちのところへ戻ると、彼らが眠っているのを見て、ペテロに言われた。<span className="woj">「あなたがたは、一時間でも私と共に目を覚ましていられなかったのか。</span></span>
<span className="v" id="v41" data-v="41" data-xref="マルコ 14:38; ルカ 22:46; エペソ人への手紙 6:18"> <span className="woj">誘惑に陥らないよう、目を覚まして祈っていなさい。心はそうしたいと願っていても、肉体は弱い。」</span></span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="マタイ 26:39; マルコ 14:39–40; ヘブル人への手紙 4:15"> イエスは再び二度目に離れて行き、祈って言われた。<span className="woj">「わが父よ、私が飲まなければこの杯が過ぎ去らないのでしたら、あなたの御心が行われますように。」</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="ルカ 9:32; ローマ人への手紙 13:1; 箴言 23:34"> イエスが再び戻ると、弟子たちは眠っていた。まぶたが重くなっていたのである。</span>
<span className="v" id="v44" data-v="44" data-xref="コリント人への第二の手紙 12:8; ルカ 18:1; マタイ 6:7"> イエスはまた彼らを残して離れて行き、三度目も同じ言葉で祈られた。</span>
<span className="v" id="v45" data-v="45" data-xref="ヨハネ 13:1; ヨハネ 12:27; マルコ 14:41–42"> それから弟子たちのところへ戻って言われた。<span className="woj">「まだ眠って休んでいるのか。見よ、時が近づいた。人の子は罪人たちの手に引き渡される。</span></span>
<span className="v" id="v46" data-v="46" data-xref="ルカ 9:51; ヨハネ 14:31; サムエル記第一 17:48"> <span className="woj">立ちなさい。行こう。見よ、私を裏切る者が近づいて来た。」</span></span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="使徒の働き 1:16; マタイ 26:55; マルコ 14:43–50"> イエスがまだ話しておられるうちに、見よ、十二人の一人であるユダがやって来た。祭司長たちと民の長老たちから遣わされた大勢の群衆も、剣や棍棒を手にして一緒に来た。</span>
<span className="v" id="v48" data-v="48" data-xref="詩篇 55:20–21; 詩篇 28:3; サムエル記第二 3:27"> イエスを裏切る者は、「私が口づけするのがその人だ。その人を捕らえよ」と、彼らに合図を決めていた。</span>
<span className="v" id="v49" data-v="49" data-xref="マタイ 26:25; テサロニケ人への手紙第一 5:26; 箴言 27:6"> ユダはすぐにイエスに近づき、「先生、ごきげんよう」と言って、口づけした。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="マタイ 20:13; マタイ 22:12; 詩篇 41:9"> イエスは彼に言われた。<span className="woj">「友よ、何のために来たのか。」</span><br />すると人々は近寄り、イエスに手をかけて捕らえた。</span>
<span className="v" id="v51" data-v="51" data-xref="ヨハネ 18:36; マルコ 14:47; コリント人への第二の手紙 10:4"> 見よ、イエスと一緒にいた者の一人が手を伸ばして剣を抜き、大祭司の僕に打ちかかり、その耳を切り落とした。</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="ヨハネの黙示録 13:10; 創世記 9:6; ローマ人への手紙 12:19"> そのとき、イエスは彼に言われた。<span className="woj">「剣を元の所に納めなさい。剣を取る者はみな、剣によって滅びるからである。</span></span>
<span className="v" id="v53" data-v="53" data-xref="列王記第二 6:17; マタイ 4:11; ダニエル書 7:10"> <span className="woj">それとも、私が父に願えば、父は今すぐ十二軍団を超える御使いを私のもとに送ってくださらないとでも思うのか。</span></span>
<span className="v" id="v54" data-v="54" data-xref="ゼカリヤ書 13:7; マタイ 26:24; 使徒の働き 1:16"> <span className="woj">しかし、それでは、こうならなければならないという聖書の言葉が、どうして成就するだろうか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="マルコ 12:35; ヨハネ 8:2; ルカ 22:52–53"> その時、イエスは群衆に言われた。<span className="woj">「まるで強盗にでも向かうように、剣や棍棒を持って私を捕らえに来たのか。私は毎日、神殿に座って教えていたが、あなたがたは私を捕らえなかった。</span></span>
<span className="v" id="v56" data-v="56" data-xref="ゼカリヤ書 13:7; ヨハネ 16:32; マルコ 14:50–52"> <span className="woj">しかし、これらすべてのことが起こったのは、預言者たちの聖書の言葉が成就するためである。」</span><br />そのとき、弟子たちはみなイエスを見捨てて逃げた。</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="マタイ 26:3; マルコ 14:53–65; 詩篇 56:5–6"> イエスを捕らえた者たちは、イエスを大祭司カヤパのもとへ連れて行った。そこには律法学者たちと長老たちが集まっていた。</span>
<span className="v" id="v58" data-v="58" data-xref="ヨハネ 7:32; ヨハネ 18:15–16; ヨハネ 18:25"> ペテロは遠くからイエスについて行き、大祭司の屋敷の中庭まで来た。そして中に入り、事の成り行きを見届けようと、役人たちと一緒に座った。</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="使徒の働き 6:11–13; 申命記 19:16–21; マルコ 14:55–56"> さて、祭司長たち、長老たち、そして最高法院全体は、イエスを死刑にするため、イエスに不利な偽証を探した。</span>
<span className="v" id="v60" data-v="60" data-xref="申命記 19:15; 詩篇 35:11; 詩篇 27:12"> しかし、見つからなかった。多くの偽証人が出て来たが、それでも見つからなかった。最後に、二人の偽証人が進み出て、</span>
<span className="v" id="v61" data-v="61" data-xref="ヨハネ 2:19–21; マタイ 27:40; マルコ 15:29"> 言った。「この男は、『私は神の神殿を壊し、三日で建て直すことができる』と言いました。」</span>
</div>
<div className="bp">
<span className="v" id="v62" data-v="62" data-xref="ヨハネ 19:9–11; ヨハネ 18:19–24; マルコ 14:60"> 大祭司は立ち上がり、イエスに言った。「何も答えないのか。この者たちがあなたに不利な証言をしているが、これはどういうことか。」</span>
<span className="v" id="v63" data-v="63" data-xref="レビ記 5:1; マタイ 16:16; イザヤ書 53:7"> しかし、イエスは黙っておられた。大祭司は言った。「生ける神にかけて、あなたに命じる。あなたはキリスト、神の子なのか、私たちに答えよ。」</span>
</div>
<div className="bp">
<span className="v" id="v64" data-v="64" data-xref="ダニエル書 7:13; マルコ 14:62; 詩篇 110:1"> イエスは彼に言われた。<span className="woj">「あなたがそう言った。しかし、あなたがたに言う。これから後、あなたがたは、人の子が力ある方の右に座り、空の雲に乗って来るのを見る。」</span></span>
</div>
<div className="bp">
<span className="v" id="v65" data-v="65" data-xref="エレミヤ書 36:24; ヨハネ 10:33; マタイ 9:3"> すると大祭司は自分の衣を引き裂いて言った。「この男は神を冒涜した。これ以上、証人が必要だろうか。見よ、今あなたがたは、この者の冒涜を聞いた。</span>
<span className="v" id="v66" data-v="66" data-xref="ヨハネ 19:7; 使徒の働き 7:52; レビ記 24:11–16"> どう思うか。」<br />彼らは答えた。「彼は死刑に値する。」</span>
<span className="v" id="v67" data-v="67" data-xref="イザヤ書 50:6; イザヤ書 53:3; マタイ 27:30"> それから彼らはイエスの顔につばを吐き、拳で殴った。また、平手で打つ者もいて、</span>
<span className="v" id="v68" data-v="68" data-xref="ルカ 22:63–65; マルコ 14:65; ペテロの手紙第一 2:4–8"> 言った。「キリストよ、預言してみろ。おまえを打ったのはだれだ。」</span>

<div className="bp">
<span className="v" id="v69" data-v="69" data-xref="列王記第一 19:13; マタイ 26:71; 使徒の働き 5:37"> さて、ペテロが外の中庭に座っていると、一人の女中が近づいて来て言った。「あなたもガリラヤ人イエスと一緒にいましたね。」</span>
</div>
<div className="bp">
<span className="v" id="v70" data-v="70" data-xref="コリント人への第一の手紙 10:12; ヨハネの黙示録 21:8; マタイ 26:40–43"> しかし、ペテロは皆の前でそれを否み、「何を言っているのか、私には分からない」と言った。</span>

<span className="v" id="v71" data-v="71" data-xref="マルコ 14:68–69; ヨハネ 18:25–27; ルカ 22:58"> ペテロが門口へ出て行くと、別の女中が彼を見て、そこにいる人々に言った。「この人もナザレのイエスと一緒にいました。」</span>
</div>

<span className="v" id="v72" data-v="72" data-xref="マタイ 26:74; イザヤ書 48:1; ゼカリヤ書 8:17"> ペテロは再びそれを否み、「私はそんな人を知らない」と誓った。</span>

<span className="v" id="v73" data-v="73" data-xref="士師記 12:6; ヨハネ 18:26–27; ネヘミヤ記 13:24"> しばらくすると、そばに立っていた人々が近寄り、ペテロに言った。「確かに、あなたも彼らの仲間だ。話し方で分かる。」</span>

<span className="v" id="v74" data-v="74" data-xref="ヨハネの黙示録 3:19; コリント人への第一の手紙 16:22; マルコ 14:71–72"> するとペテロは、「私はそんな人を知らない」と言って、呪いをかけて誓い始めた。<br />その時すぐ、鶏が鳴いた。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 61:1–3; 使徒の働き 10:38; ルカ 8:1"> イエスは十二人の弟子に指示を与え終えると、彼らの町々で教え、宣べ伝えるため、そこを立ち去られた。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="マルコ 6:17; マタイ 14:3; マタイ 9:14"> さて、ヨハネは牢獄の中でキリストのわざについて聞き、弟子を二人遣わして、</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネ 11:27; マラキ書 3:1; 申命記 18:15–18"> イエスに尋ねさせた。「来るべき方はあなたですか。それとも、ほかの方を待つべきでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> イエスは彼らに答えられた。<span className="woj">「行って、あなたがたが聞き、見ていることをヨハネに知らせなさい。</span></span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 35:4–6; イザヤ書 61:1–3; ルカ 4:18"> <span className="woj">目の見えない人は見えるようになり、足の不自由な人は歩き、重い皮膚病の人は清められ、耳の聞こえない人は聞こえるようになり、</span><span className="woj">死者は生き返り、貧しい人々には福音が宣べ伝えられている。</span></span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 8:14–15; コリント人への第一の手紙 2:14; マタイ 26:31"> <span className="woj">私につまずかない者は幸いである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヤコブの手紙 1:6; ヨハネ 5:35; マルコ 1:3–5"> 彼らが帰って行くと、イエスはヨハネについて群衆に語り始められた。<span className="woj">「あなたがたは何を見るために荒野へ出て行ったのか。風に揺られる葦か。</span></span>
<span className="v" id="v8" data-v="8" data-xref="マタイ 3:4; 列王記第二 1:8; ゼカリヤ書 13:4"> <span className="woj">では、何を見るために出て行ったのか。柔らかな衣を着た人か。見よ、柔らかな衣を着る人々は王宮にいる。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ルカ 1:76; マタイ 14:5; マタイ 21:24–26"> <span className="woj">では、なぜ出て行ったのか。預言者を見るためか。そうだ。あなたがたに言う。預言者以上の者である。</span></span>
<span className="v" id="v10" data-v="10" data-xref="マラキ書 3:1; イザヤ書 40:3; マラキ書 4:5"> <span className="woj">この人こそ、『見よ、私はあなたの前に私の使者を遣わす。彼はあなたの前に道を整える』と書かれている人である。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ルカ 7:28; エペソ人への手紙 3:8; マタイ 3:11"> <span className="woj">まことに、あなたがたに言う。女から生まれた者の中で、バプテスマのヨハネより偉大な者は現れたことがない。しかし、天の御国で最も小さい者でさえ、彼より偉大である。</span></span>
<span className="v" id="v12" data-v="12" data-xref="ルカ 16:16; ルカ 13:24; エペソ人への手紙 6:11–13"> <span className="woj">バプテスマのヨハネの時から今に至るまで、天の御国は激しく攻められ、激しく攻める者たちが力ずくで奪っている。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「それを略奪している」。">a</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="マタイ 5:17–18; ローマ人への手紙 3:21; 使徒の働き 13:27"> <span className="woj">すべての預言者と律法は、ヨハネの時まで預言した。</span></span>
<span className="v" id="v14" data-v="14" data-xref="マラキ書 4:5; マタイ 17:10–13; マルコ 9:11–13"> <span className="woj">あなたがたが受け入れるつもりなら、この人こそ、来るべきエリヤである。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ルカ 8:8; マタイ 13:9; マルコ 4:23"> <span className="woj">聞く耳のある者は聞きなさい。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ルカ 7:31–35; マタイ 12:34; マタイ 23:36"> <span className="woj">ところで、この時代を何にたとえればよいだろうか。市場に座って、仲間たちに呼びかける子どもたちのようである。</span></span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 28:9–13; イザヤ書 30:29; エレミヤ書 9:17–20"> <span className="woj">彼らはこう言う。『笛を吹いたのに、踊ってくれなかった。弔いの歌を歌ったのに、悲しんでくれなかった。』</span></span>
<span className="v" id="v18" data-v="18" data-xref="ルカ 1:15; マタイ 3:4; ヨハネ 10:20"> <span className="woj">ヨハネが来て、食べも飲みもしないと、人々は『彼は悪霊につかれている』と言う。</span></span>
<span className="v" id="v19" data-v="19" data-xref="マタイ 9:10–11; ルカ 15:1–2; ルカ 19:7"> <span className="woj">人の子が来て、食べたり飲んだりすると、人々は言う。『見よ、大食いで大酒飲みの男、徴税人や罪人の友だ。』しかし、知恵の正しさは、その子どもたちによって証明される。」</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NU本文では「子どもたち」の代わりに「行い」となっている。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ルカ 10:13–15; エレミヤ書 8:6; テモテへの第二の手紙 2:25–26"> それからイエスは、力あるわざを最も多く行われた町々が悔い改めなかったので、これを責め始められた。</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 3:6–7; 使徒の働き 12:20; ルカ 9:10"> <span className="woj">「コラジンよ、災いだ。ベツサイダよ、災いだ。あなたがたの中で行われた力あるわざが、もしツロとシドンで行われていたなら、彼らはとうの昔に粗布をまとい、灰をかぶって悔い改めていただろう。</span></span>
<span className="v" id="v22" data-v="22" data-xref="マタイ 11:24; マタイ 10:15; ヘブル人への手紙 10:26–31"> <span className="woj">しかし、あなたがたに言う。裁きの日には、あなたがたよりもツロとシドンのほうが耐えやすい。</span></span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 14:13–15; ヨハネ 4:46–54; 創世記 13:13"> <span className="woj">カペナウムよ、天にまで高く上げられたおまえは、ハデスにまで下る。</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="または「地獄」。">c</a></sup><span className="woj">おまえの中で行われた力あるわざが、もしソドムで行われていたなら、ソドムは今日まで残っていただろう。</span></span>
<span className="v" id="v24" data-v="24" data-xref="マタイ 10:15; マタイ 11:22; マルコ 6:11"> <span className="woj">しかし、あなたがたに言う。裁きの日には、おまえよりもソドムの地のほうが耐えやすい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="マタイ 21:16; 詩篇 8:2; マタイ 16:17"> その時、イエスは言われた。<span className="woj">「天地の主である父よ、あなたをほめたたえます。あなたはこれらのことを知恵ある者や理解力のある者には隠し、幼子たちに現してくださいました。</span></span>
<span className="v" id="v26" data-v="26" data-xref="テモテへの第二の手紙 1:9; エペソ人への手紙 1:11; ヨブ記 33:13"> <span className="woj">そうです、父よ。これはあなたの御心にかなうことでした。</span></span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネ 14:6–9; マタイ 28:18; ルカ 10:22"> <span className="woj">すべてのものは、父から私に委ねられている。父のほかに子を知る者はなく、子と、子が父を現そうと望む者のほかに、父を知る者はいない。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="マタイ 11:29; ヨハネ 7:37; ヨハネ 6:37"> <span className="woj">疲れ果て、重荷を負っている人はみな、私のもとに来なさい。私があなたがたを休ませよう。</span></span>
<span className="v" id="v29" data-v="29" data-xref="エレミヤ書 6:16; ヨハネの手紙第一 2:6; ピリピ人への手紙 2:7–8"> <span className="woj">私は柔和で心のへりくだった者だから、私のくびきを負い、私から学びなさい。そうすれば、あなたがたの魂に安らぎを得る。</span></span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの手紙第一 5:3; ヨハネ 16:33; ピリピ人への手紙 4:13"> <span className="woj">私のくびきは負いやすく、私の荷は軽いからである。」</span></span>
</div>
</div>

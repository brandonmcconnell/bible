<span className="v" id="v3" data-v="3" data-xref="テモテへの手紙第一 5:13; 使徒の働き 2:15; マタイ 20:6–7"> <span className="woj">また、第三時ごろ</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="時刻は日の出から日没までを基準に数えたので、第三時は午前九時ごろに当たる。">b</a></sup><span className="woj">に出て行き、ほかの人たちが何もせずに市場に立っているのを見た。</span></span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 6:11; ペテロの手紙第一 4:2–3; ルカ 19:7–10"> <span className="woj">そこで彼らに、『あなたがたもぶどう園へ行きなさい。ふさわしい賃金を支払おう』と言った。彼らはぶどう園へ行った。</span></span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 11:24–26; 使徒の働き 10:3; マルコ 15:33–34"> <span className="woj">主人は第六時と第九時ごろ</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="正午と午後三時ごろ。">c</a></sup><span className="woj">にも出て行き、同じようにした。</span></span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 6:12; ヨハネ 9:4; 使徒の働き 17:21"> <span className="woj">第十一時ごろ</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="午後五時ごろ。">d</a></sup><span className="woj">にも出て行き、ほかの人たちが何もせずに立っているのを見つけた。主人は彼らに、『なぜ一日中、何もせずにここに立っているのか』と尋ねた。</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 2:11–12; ヘブル人への手紙 6:10; ヨハネ 9:4"> <span className="woj">彼らは答えた。『だれも私たちを雇ってくれなかったからです。』</span><br /><span className="woj">主人は彼らに言った。『あなたがたもぶどう園へ行きなさい。ふさわしい賃金を受け取るだろう。』</span></span>

<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="申命記 24:15; ペテロの手紙第一 4:10; ローマ人への手紙 2:6–10"> <span className="woj">夕方になると、ぶどう園の主人は管理人に言った。『労働者たちを呼び、最後に来た者から始めて、最初に来た者まで賃金を支払いなさい。』</span></span>
<span className="v" id="v9" data-v="9" data-xref="マタイ 20:6–7; ルカ 23:40–43; マタイ 20:2"> <span className="woj">第十一時ごろに雇われた者たちが来て、それぞれ一デナリを受け取った。</span></span>
<span className="v" id="v10" data-v="10"> <span className="woj">最初に雇われた者たちは、自分たちはもっと多く受け取れると思った。しかし、彼らもそれぞれ一デナリを受け取った。</span></span>
<span className="v" id="v11" data-v="11" data-xref="テサロニケ人への手紙第一 2:16; ルカ 19:7; 使徒の働き 22:21–22"> <span className="woj">彼らはそれを受け取ると、家の主人に不平を言い、</span></span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 11:5–6; コリント人への第二の手紙 11:23–28; ルカ 12:55"> <span className="woj">『最後に来たこの者たちは、一時間しか働いていません。それなのに、一日の重荷と焼けつく暑さに耐えた私たちと同じ扱いをなさいました』と言った。</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マタイ 26:50; マタイ 22:12; ローマ人への手紙 9:14–15"> <span className="woj">しかし、主人はその一人に答えた。『友よ、私はあなたに不当なことをしていない。あなたは一デナリで私と合意したではないか。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネ 17:2; ルカ 15:31; マタイ 6:6"> <span className="woj">自分の賃金を受け取って帰りなさい。私は最後に来たこの者にも、あなたと同じだけ与えたいのだ。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 9:15–24; 申命記 15:9; ヨナ書 4:1–4"> <span className="woj">自分のものを自分の思いどおりにすることは許されているではないか。それとも、私が良い者なので、あなたはねたみの目で見るのか。』</span></span>
<span className="v" id="v16" data-v="16" data-xref="マタイ 19:30; マルコ 10:31; マタイ 22:14"> <span className="woj">このように、後にいる者が先になり、先にいる者が後になる。招かれる者は多いが、選ばれる者は少ない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="マルコ 10:32–34; ルカ 18:31–34; マタイ 16:13"> イエスはエルサレムへ上って行く途中、十二人の弟子だけを脇へ呼び、道すがら彼らに言われた。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイ 16:21; 使徒の働き 2:23; マタイ 27:1"> <span className="woj">「見よ、私たちはエルサレムへ上って行く。人の子は祭司長たちと律法学者たちに引き渡され、彼らは人の子を死刑に定める。</span></span>
<span className="v" id="v19" data-v="19" data-xref="マタイ 16:21; マルコ 15:16–20; マタイ 27:27–31"> <span className="woj">そして、あざけり、むち打ち、十字架につけるために、異邦人に引き渡す。しかし、彼は三日目によみがえる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="マタイ 4:21; マルコ 10:35–45; マタイ 8:2"> そのとき、ゼベダイの息子たちの母が二人の息子と共にイエスのもとに来て、ひざまずき、あることを願った。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイ 19:28; マルコ 10:36–37; エステル記 5:3"> イエスは彼女に言われた。<span className="woj">「何を望んでいるのか。」</span><br />彼女はイエスに言った。「私のこの二人の息子が、あなたの御国で、一人はあなたの右に、もう一人は左に座れるよう、お命じください。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="マタイ 26:42; ルカ 22:42; マタイ 26:39"> しかし、イエスは答えられた。<span className="woj">「あなたがたは、自分が何を願っているのか分かっていない。私が飲もうとしている杯を飲み、私が受けようとしているバプテスマを受けることができるか。」</span><br />二人はイエスに答えた。「できます。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ヨハネの黙示録 1:9; マタイ 25:34; 使徒の働き 12:2"> イエスは彼らに言われた。<span className="woj">「確かに、あなたがたは私の杯を飲み、私が受けようとしているバプテスマを受ける。しかし、私の右と左に座ることは、私が与えるものではない。それは、私の父によって備えられた人たちのためのものである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ペテロの手紙第一 5:5; ピリピ人への手紙 2:3; マルコ 10:41"> ほかの十人はこれを聞いて、二人の兄弟に腹を立てた。</span>

<span className="v" id="v25" data-v="25" data-xref="ルカ 22:25–27; マタイ 20:25–28; ヨハネ 13:12–17"> そこでイエスは彼らを呼び寄せて言われた。<span className="woj">「あなたがたが知っているように、諸国民の支配者たちは人々の上に君臨し、偉い者たちは人々に権力を振るっている。</span></span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコ 3:22; マタイ 23:2; ルカ 5:21"> その時、パリサイ人と律法学者たちがエルサレムからイエスのもとに来て言った。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカ 11:38; マルコ 7:2; コロサイ人への手紙 2:20–23"> 「なぜあなたの弟子たちは、長老たちの言い伝えに背くのですか。彼らはパンを食べるとき、手を洗っていません。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="コロサイ人への手紙 2:23; テトス 1:14; コロサイ人への手紙 2:8"> イエスは彼らに答えられた。<span className="woj">「なぜあなたがたも、自分たちの言い伝えのために神の戒めに背くのか。</span></span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 20:12; レビ記 20:9; 出エジプト記 21:17"> <span className="woj">神は、『父と母を敬いなさい』、</span><span className="woj">また、『父または母をののしる者は、必ず死刑に処せられる』と命じられた。</span></span>
<span className="v" id="v5" data-v="5" data-xref="マルコ 7:10–13; 使徒の働き 5:29; マタイ 23:16–18"> <span className="woj">ところが、あなたがたは言う。『父や母に、「私から受けるはずだった助けは、神に献げた供え物です」と言う者は、</span></span>
<span className="v" id="v6" data-v="6" data-xref="テモテへの手紙第一 5:8; エレミヤ書 8:8; マルコ 7:13"> <span className="woj">父や母を敬わなくてもよい。』こうしてあなたがたは、自分たちの言い伝えのために神の戒めを無効にしている。</span></span>
<span className="v" id="v7" data-v="7" data-xref="マルコ 7:6; マタイ 23:23–29; 使徒の働き 28:25–27"> <span className="woj">偽善者たちよ。イザヤはあなたがたについて、まさにそのとおり預言した。</span></span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 29:13; エゼキエル書 33:31; 使徒の働き 8:21"> <span className="pl pl-1 woj">『この民は口で私に近づき、</span><br /><span className="pl pl-2 woj">唇で私を敬う。</span><br /><span className="pl pl-2 woj">しかし、その心は私から遠く離れている。</span></span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 29:13; マルコ 7:7; テモテへの手紙第一 1:4"> <span className="pl pl-1 woj">彼らが私を礼拝してもむなしい。</span><br /><span className="pl pl-2 woj">人の戒めを教えとして教えているからである。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="マルコ 7:14–15; ルカ 20:45–47; ルカ 24:45"> イエスは群衆を呼び寄せて言われた。<span className="woj">「聞いて、理解しなさい。</span></span>
<span className="v" id="v11" data-v="11" data-xref="マルコ 7:15; マタイ 15:18–20; ヤコブの手紙 3:5–8"> <span className="woj">口に入るものが人を汚すのではない。口から出るものが人を汚すのである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王記第一 22:13–14; コリント人への第一の手紙 10:32–33; ガラテヤ人への手紙 2:5"> その時、弟子たちは近寄って来て、イエスに言った。「パリサイ人たちがこの言葉を聞いて腹を立てたことをご存じですか。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨハネ 15:2; イザヤ書 60:21; ヨハネ 15:6"> しかし、イエスは答えられた。<span className="woj">「天におられる私の父が植えられなかったものは、すべて根こそぎにされる。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ルカ 6:39; イザヤ書 56:10; マタイ 23:16–24"> <span className="woj">彼らのことは放っておきなさい。彼らは目の見えない人を導く、目の見えない案内人である。目の見えない人が目の見えない人を導けば、二人とも穴に落ちる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="マタイ 13:36; マルコ 4:34; ヨハネ 16:29"> ペテロはイエスに答えた。「そのたとえを私たちに説明してください。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="マタイ 16:9; マルコ 7:18; マルコ 9:32"> そこでイエスは言われた。<span className="woj">「あなたがたも、まだ理解できないのか。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ルカ 6:45; コリント人への第一の手紙 6:13; マタイ 7:19–20"> <span className="woj">口に入るものは何でも腹に入り、やがて体の外に出されることが分からないのか。</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 15:28; マタイ 12:34; ヤコブの手紙 3:6–10"> <span className="woj">しかし、口から出るものは心から出て来る。それが人を汚す。</span></span>
<span className="v" id="v19" data-v="19" data-xref="マルコ 7:21–23; ガラテヤ人への手紙 5:19–21; エレミヤ書 17:9"> <span className="woj">心から、悪い思い、殺人、姦淫、性的不品行、盗み、偽証、冒涜が出て来るからである。</span></span>
<span className="v" id="v20" data-v="20" data-xref="マルコ 7:3–4; エペソ人への手紙 5:3–6; コリント人への第一の手紙 6:18–20"> <span className="woj">これらが人を汚すのである。しかし、洗っていない手で食べることは、人を汚さない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="マルコ 7:24–30; マタイ 11:21–23; 士師記 1:31"> イエスはそこを去り、ツロとシドンの地方へ退かれた。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイ 9:27; マルコ 7:25–26; マタイ 17:15"> 見よ、その地方から一人のカナン人の女が出て来て、叫んで言った。「主よ、ダビデの子よ、私をあわれんでください。娘が悪霊にひどく取りつかれています。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="マタイ 14:15; マルコ 10:47–48; 哀歌 3:8"> しかし、イエスは一言もお答えにならなかった。<br />弟子たちは近寄って来て、「彼女を帰してください。私たちの後について来て、叫び続けています」と願った。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="マタイ 10:5–6; ローマ人への手紙 15:8; エレミヤ書 50:6–7"> しかし、イエスは答えられた。<span className="woj">「私はイスラエルの家の失われた羊たちのほかには、だれのところにも遣わされていない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="創世記 32:26; マタイ 20:31; マタイ 14:33"> しかし、女は来てイエスを拝み、「主よ、私をお助けください」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="マルコ 7:27–28; マタイ 7:6; ピリピ人への手紙 3:2"> しかし、イエスは答えられた。<span className="woj">「子どもたちのパンを取って、犬に投げてやるのはよくない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="エペソ人への手紙 3:8; ルカ 16:21; ヨブ記 40:4–5"> しかし、女は言った。「そうです、主よ。それでも犬は、主人の食卓から落ちるパンくずを食べます。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="マルコ 9:23–24; マタイ 8:13; 詩篇 145:19"> その時、イエスは彼女に答えられた。<span className="woj">「女よ、あなたの信仰は大きい。あなたが願うとおりになるように。」</span>すると、ちょうどその時、娘は癒された。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="マタイ 4:18; ヨハネ 6:1; マタイ 5:1"> イエスはそこを去り、ガリラヤ湖の近くに来られた。そして山に登り、そこに座られた。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカ 6:17–19; 使徒の働き 5:15–16; マタイ 14:35–36"> すると、大勢の群衆が、足の不自由な人、目の見えない人、口の利けない人、手足の不自由な人、そのほか多くの人々を連れて来て、イエスの足元に置いた。イエスは彼らを癒された。</span>
<span className="v" id="v31" data-v="31" data-xref="マタイ 9:8; ルカ 18:43; ルカ 17:15–18"> 群衆は、口の利けない人が話し、傷ついた人が癒され、足の不自由な人が歩き、目の見えない人が見えるようになったのを見て驚き、イスラエルの神をあがめた。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 27:33; ルカ 12:29–30; マタイ 9:36"> イエスは弟子たちを呼び寄せて言われた。<span className="woj">「群衆を深くあわれんでいる。彼らはもう三日間も私と一緒にいて、食べるものがない。空腹のまま帰らせたくない。途中で力尽きるかもしれないからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="マルコ 6:37; マタイ 14:15; マルコ 8:4–5"> 弟子たちはイエスに言った。「この人里離れた所で、これほど大勢の群衆を満腹させるだけのパンを、どこから手に入れられるでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="マタイ 16:9–10; ルカ 24:41–42; ヨハネ 21:9–10"> イエスは彼らに言われた。<span className="woj">「パンはいくつあるのか。」</span><br />彼らは答えた。「七つです。それに、小さな魚が少しあります。」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="ルカ 9:14–16; マルコ 6:39–40; ヨハネ 6:10"> イエスは群衆に、地面に座るよう命じられた。</span>
<span className="v" id="v36" data-v="36" data-xref="ルカ 22:19; ローマ人への手紙 14:6; ヨハネ 6:11"> そして七つのパンと魚を取り、感謝をささげてから裂き、弟子たちに渡された。弟子たちはそれを群衆に配った。</span>
<span className="v" id="v37" data-v="37" data-xref="マルコ 8:19–21; マタイ 16:9–10; マタイ 15:33"> 人々はみな食べて満腹した。弟子たちが残ったパン切れを拾い集めると、七つのかごがいっぱいになった。</span>
<span className="v" id="v38" data-v="38"> 食べた者は、女と子どもを除いて、男が四千人であった。</span>
<span className="v" id="v39" data-v="39" data-xref="マルコ 8:10; マタイ 14:22"> それからイエスは群衆を解散させ、舟に乗り、マグダラ地方に来られた。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコ 9:33–37; ルカ 9:46–48; マタイ 20:20–28"> その時、弟子たちがイエスのもとに来て尋ねた。「いったい、天の御国ではだれが一番偉いのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="マタイ 19:13–14; マルコ 9:36–37; 列王記第一 3:7"> イエスは一人の幼い子どもを呼び寄せ、彼らの真ん中に立たせ、</span>
<span className="v" id="v3" data-v="3" data-xref="マルコ 10:14–15; ペテロの手紙第一 2:2; マタイ 19:14"> 言われた。<span className="woj">「まことに、あなたがたに言う。心を改めて幼い子どものようにならなければ、決して天の御国に入ることはできない。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ヤコブの手紙 4:10; ルカ 14:11; マルコ 10:43"> <span className="woj">だから、この幼い子どものように自分を低くする者が、天の御国で一番偉いのである。</span></span>
<span className="v" id="v5" data-v="5" data-xref="マタイ 25:40; マルコ 9:37; ヨハネ 13:20"> <span className="woj">また、私の名のゆえに、このような幼い子どもの一人を受け入れる者は、私を受け入れるのである。</span></span>
<span className="v" id="v6" data-v="6" data-xref="マルコ 9:42; ルカ 17:1–2; マタイ 18:10"> <span className="woj">しかし、私を信じるこの小さい者たちの一人をつまずかせる者は、大きな石臼を首に掛けられ、深い海に沈められるほうがよい。</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ルカ 17:1; コリント人への第一の手紙 11:19; マタイ 26:24"> <span className="woj">つまずきをもたらすもののゆえに、世は災いである。つまずきが起こることは避けられないが、つまずきをもたらすその人は災いである。</span></span>
<span className="v" id="v8" data-v="8" data-xref="マタイ 5:29–30; ピリピ人への手紙 3:8–9; ローマ人への手紙 13:12"> <span className="woj">もし、あなたの手や足があなたをつまずかせるなら、それを切り落として捨てなさい。両手、両足がそろったまま永遠の火に投げ込まれるより、片手や片足を失っていのちに入るほうがよい。</span></span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 14:22; マタイ 18:8; マタイ 5:29"> <span className="woj">もし、あなたの目があなたをつまずかせるなら、それをえぐり出して捨てなさい。両目がそろったまま火の燃えるゲヘナ</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「地獄」。">a</a></sup><span className="woj">に投げ込まれるより、片目でいのちに入るほうがよい。</span></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 91:11; 詩篇 34:7; ヘブル人への手紙 1:14"> <span className="woj">この小さい者たちの一人をも軽んじないように気をつけなさい。あなたがたに言う。彼らの御使いたちは、天におられる私の父の御顔をいつも見ているからである。</span></span>
<span className="v" id="v11" data-v="11"> <span className="woj">人の子は、失われた者を救うために来たのである。</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NU本文では11節が省かれている。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 34:12; ルカ 15:4–7; エゼキエル書 34:16"> <span className="woj">あなたがたはどう思うか。ある人が百匹の羊を持っていて、そのうちの一匹が迷い出たなら、九十九匹を残して山へ行き、迷い出た一匹を捜さないだろうか。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ゼパニヤ書 3:17; ルカ 15:5–10; ヤコブの手紙 2:13"> <span className="woj">もしそれを見つけたなら、まことに、あなたがたに言う。その人は、迷わなかった九十九匹以上に、その一匹のことを喜ぶ。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネ 17:12; ヨハネ 6:39–40; ペテロの第二の手紙 3:9"> <span className="woj">このように、この小さい者たちの一人が滅びることは、天におられるあなたがたの父の御心ではない。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="レビ記 19:17; ルカ 17:3–4; ガラテヤ人への手紙 6:1"> <span className="woj">もし、あなたの兄弟があなたに対して罪を犯したなら、行って、二人だけの間でその過ちを指摘しなさい。兄弟があなたの言うことを聞くなら、あなたは兄弟を取り戻したのである。</span></span>
<span className="v" id="v16" data-v="16" data-xref="申命記 19:15; コリント人への第二の手紙 13:1; ヨハネ 8:17"> <span className="woj">しかし、聞かなければ、ほかに一人か二人を連れて行きなさい。それは、『二人または三人の証人の証言によって、すべての事実が確かめられる』ためである。</span></span>
<span className="v" id="v17" data-v="17" data-xref="テサロニケ人への第二の手紙 3:6; コリント人への第一の手紙 5:9–7; テサロニケ人への第二の手紙 3:14–15"> <span className="woj">それでも彼らの言うことを聞かなければ、教会に知らせなさい。教会の言うことも聞かなければ、その人を異邦人や徴税人と同じように扱いなさい。</span></span>
<span className="v" id="v18" data-v="18" data-xref="マタイ 16:19; コリント人への第二の手紙 2:10; ヨハネ 20:23"> <span className="woj">まことに、あなたがたに言う。あなたがたが地上で縛るものは何でも、天ですでに縛られており、あなたがたが地上で解くものは何でも、天ですでに解かれている。</span></span>
<span className="v" id="v19" data-v="19" data-xref="マタイ 7:7; ヨハネの手紙第一 5:14–16; マルコ 11:24"> <span className="woj">また、まことに、あなたがたに言う。あなたがたのうち二人が、願い求めるどんなことについても地上で心を合わせるなら、天におられる私の父がそれをかなえてくださる。</span></span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 5:4; ヨハネの黙示録 21:3; マタイ 28:20"> <span className="woj">二人または三人が私の名によって集まるところには、私もその真ん中にいるからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ルカ 17:3–4; マタイ 18:15"> そのときペテロがイエスのもとに来て尋ねた。「主よ、兄弟が私に対して罪を犯したら、何度赦せばよいのでしょうか。七回までですか。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="コロサイ人への手紙 3:13; マルコ 11:25; マタイ 6:14–15"> イエスは彼に言われた。<span className="woj">「七回までとは言わない。七十倍の七回までである。</span></span>
<span className="v" id="v23" data-v="23" data-xref="マタイ 13:24; ローマ人への手紙 14:12; マタイ 3:2"> <span className="woj">だから、天の御国は、家来たちと勘定を清算しようとした、ある王にたとえられる。</span></span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 38:4; 詩篇 130:3–4; ルカ 16:5"> <span className="woj">清算を始めると、一万タラントの借金がある者が王のもとに連れて来られた。</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一万タラント（銀約300トン）は途方もない金額である。農作業の一日分の賃金に相当する一デナリを基準にすると、約六千万デナリに相当する。">c</a></sup></span>
<span className="v" id="v25" data-v="25" data-xref="列王記第二 4:1; ネヘミヤ記 5:5; ルカ 7:42"> <span className="woj">しかし、その者には返済することができなかったので、主人は彼自身と妻と子どもたち、また全財産を売って、返済するよう命じた。</span></span>
<span className="v" id="v26" data-v="26" data-xref="マタイ 18:29; ルカ 7:43; マタイ 8:2"> <span className="woj">そこで家来はひれ伏し、主人にひざまずいて言った。『どうか私を待ってください。すべてお返しします。』</span></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 145:8; ネヘミヤ記 9:17; 詩篇 86:15"> <span className="woj">その家来の主人は深くあわれみ、彼を解放し、借金を免じてやった。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="マタイ 20:2; エゼキエル書 45:9; 申命記 15:2"> <span className="woj">ところが、その家来は出て行き、自分に百デナリの借金がある仲間の家来に出会った。</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="百デナリは一タラントの約六十分の一、すなわち銀約500グラム、または1.1ポンドに相当した。">d</a></sup><span className="woj">彼はその仲間を捕まえて首を絞め、『借りたものを返せ』と言った。</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="マタイ 18:26; マタイ 6:12; フィレモンへの手紙 1:18–19"> <span className="woj">そこで仲間の家来は彼の足元にひれ伏し、『どうか待ってくれ。必ず返すから』と懇願した。</span></span>
<span className="v" id="v30" data-v="30" data-xref="列王記第一 22:27; 列王記第一 21:27–29"> <span className="woj">しかし、彼は承知せず、その仲間を連れて行き、借金を返すまで牢獄に入れた。</span></span>
<span className="v" id="v31" data-v="31" data-xref="ローマ人への手紙 12:15; ヘブル人への手紙 13:3; マルコ 3:5"> <span className="woj">仲間の家来たちは、起こったことを見て非常に悲しみ、主人のところへ行って、事の一部始終を知らせた。</span></span>
<span className="v" id="v32" data-v="32" data-xref="ルカ 19:22; マタイ 25:26; ローマ人への手紙 3:19"> <span className="woj">そこで主人は彼を呼び寄せて言った。『悪い家来だ。おまえが懇願したので、私はあの借金をすべて免じてやった。</span></span>
<span className="v" id="v33" data-v="33" data-xref="コロサイ人への手紙 3:13; マタイ 6:12; エペソ人への手紙 4:32–2"> <span className="woj">私がおまえをあわれんだように、おまえも仲間の家来をあわれむべきではなかったか。』</span></span>
<span className="v" id="v34" data-v="34" data-xref="マタイ 5:25–26; ヤコブの手紙 2:13; ルカ 12:58–59"> <span className="woj">主人は怒って、借金をすべて返すまで、彼を責めさいなむ者たちに引き渡した。</span></span>
<span className="v" id="v35" data-v="35" data-xref="マタイ 6:14–15; ヤコブの手紙 2:13; ルカ 6:37–38"> <span className="woj">あなたがたも、それぞれ心から兄弟の過ちを赦さないなら、天におられる私の父も同じようになさる。」</span></span>
</div>

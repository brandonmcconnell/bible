<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 40:3–6; ヨハネ 1:6–8; ルカ 1:76"> そのころ、バプテスマを授けるヨハネが現れ、ユダヤの荒野で宣べ伝え、こう言った。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 4:17; マルコ 1:15; ダニエル書 2:44"> 「悔い改めなさい。天の御国が近づいたからだ。」</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 40:3; マラキ書 3:1; ヨハネ 1:23"> このヨハネこそ、預言者イザヤによって、次のように語られた人である。<br /><span className="pl pl-1">「荒野で叫ぶ者の声がする。</span><br /><span className="pl pl-2">『主の道を整えよ。</span><br /><span className="pl pl-2">その道筋をまっすぐにせよ。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王記第二 1:8; ゼカリヤ書 13:4; マルコ 1:6"> ヨハネはらくだの毛でできた衣をまとい、腰に革の帯を締めていた。食べ物はいなごと野生の蜂蜜だった。</span>
<span className="v" id="v5" data-v="5" data-xref="マルコ 1:5; ルカ 3:7; ヨハネ 3:23"> すると、エルサレム、ユダヤ全土、ヨルダン川周辺一帯から、人々が彼のもとに出て来た。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 19:18; マタイ 3:13–16; 使徒の働き 2:38–41"> そして自分たちの罪を告白し、ヨルダン川でヨハネからバプテスマを受けた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マタイ 12:34; テサロニケ人への手紙第一 1:10; ローマ人への手紙 5:9"> しかし、多くのパリサイ人とサドカイ人がバプテスマを受けに来るのを見て、ヨハネは彼らに言った。「まむしの子らよ。迫り来る御怒りから逃れるようにと、だれがあなたがたに警告したのか。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカ 3:8; 使徒の働き 26:20; ペテロの第二の手紙 1:4–8"> それなら、悔い改めにふさわしい実を結びなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカ 3:8; ローマ人への手紙 9:7–8; ガラテヤ人への手紙 3:27–29"> 『われわれの父はアブラハムだ』と心の中で思ってはならない。あなたがたに言っておく。神はこれらの石からでも、アブラハムの子らを起こすことがおできになる。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネ 15:6; ルカ 3:9; マタイ 7:19"> 斧はすでに木々の根元に置かれている。だから、良い実を結ばない木はすべて切り倒され、火に投げ込まれる。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 4:4; ルカ 3:16; 使徒の働き 1:5"> 私は悔い改めのために、あなたがたに水でバプテスマを授けている。しかし、私の後から来られる方は私より力があり、私はその方の履物を運ぶ資格さえない。その方は聖霊によって、あなたがたにバプテスマを授ける。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TRおよびNU本文は「そして火で」を加えている。">a</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="マラキ書 4:1; マタイ 13:30; ルカ 3:17"> その方は麦をふるい分ける箕を手に持ち、脱穀場をすっかり清める。そして麦を倉に納めるが、もみ殻は消えることのない火で焼き尽くす。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨハネ 1:32–34; マタイ 2:22; マルコ 1:9–11"> そのとき、イエスはヨハネからバプテスマを受けるため、ガリラヤからヨルダン<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="すなわち、ヨルダン川。">b</a></sup>へ来られた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネ 3:3–7; 使徒の働き 1:5–8; ヨハネ 13:6–8"> しかしヨハネは、「私こそあなたからバプテスマを受ける必要があるのに、あなたが私のところへ来られるのですか」と言って、イエスを思いとどまらせようとした。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨハネ 4:34; ヨハネ 15:10; 詩篇 40:7–8"> しかしイエスは答えられた。<span className="woj">「今はそうさせてほしい。このようにして、すべての義を成し遂げることが私たちにはふさわしいからだ。」</span>そこでヨハネは、そのとおりにした。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 11:2; マルコ 1:10; ルカ 3:21–22"> イエスはバプテスマを受けると、すぐに水から上がられた。すると見よ、天が開けた。イエスは、神の霊が鳩のように下り、ご自分の上に来るのをご覧になった。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 42:1; 詩篇 2:7; マタイ 17:5"> 見よ、天から声がして言った。「これはわたしの愛する子。わたしはこの子を心から喜んでいる。」</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 20:1–16; マタイ 12:43–45; ルカ 14:16"> イエスは再び、たとえをもって彼らに語られた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 19:7–9; マタイ 13:24; エペソ人への手紙 5:24–32"> <span className="woj">「天の御国は、自分の息子のために婚宴を催した、ある王のようなものである。</span></span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 22:17; ヨハネ 5:40; ルカ 14:15–17"> <span className="woj">王は、婚宴に招いておいた人々を呼ぶために僕たちを遣わしたが、彼らは来ようとしなかった。</span></span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 13:46; マタイ 21:36; ヨハネ 6:50–57"> <span className="woj">そこで王は再び、ほかの僕たちを遣わして言った。『招いておいた人々にこう告げなさい。「見よ、食事の用意ができた。私の雄牛も肥えた家畜もほふられ、すべてが整っている。婚宴に来なさい。」』</span></span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 2:3; ルカ 14:18–20; ヨハネの手紙第一 2:15–16"> <span className="woj">しかし彼らは気にも留めず、一人は自分の畑へ、もう一人は商売へ出かけて行った。</span></span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 15:19–20; ヨハネ 16:2–3; 使徒の働き 7:51–57"> <span className="woj">残りの者たちは王の僕たちを捕らえ、辱めたうえで殺した。</span></span>
<span className="v" id="v7" data-v="7" data-xref="ルカ 19:27; ペテロの手紙第一 4:17–18; ルカ 21:24"> <span className="woj">王はこれを聞いて怒り、軍隊を送り、その人殺しどもを滅ぼして、彼らの町を焼き払った。</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="テサロニケ人への第二の手紙 1:5; 使徒の働き 13:46; ヨハネの黙示録 3:4"> <span className="woj">それから王は僕たちに言った。『婚宴の用意はできているが、招いておいた人々はふさわしくなかった。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ルカ 14:21–24; 箴言 1:20–23; マルコ 16:15–16"> <span className="woj">だから、大通りの交差する所へ行き、見つけた人をみな婚宴に招きなさい。』</span></span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 6:9–11; ヨハネの黙示録 19:6–9; コリント人への第二の手紙 12:21"> <span className="woj">僕たちは大通りへ出て行き、悪い人も良い人も、見つけた者をみな集めた。こうして婚宴の席は客でいっぱいになった。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 3:4–5; ヨハネの黙示録 19:8; ヘブル人への手紙 4:12–13"> <span className="woj">王が客を見ようと入って来ると、婚礼の礼服を着ていない人が一人いるのを見つけた。</span></span>
<span className="v" id="v12" data-v="12" data-xref="サムエル記第一 2:9; ヨブ記 5:16; マタイ 20:13"> <span className="woj">そこで王はその人に、『友よ、婚礼の礼服を着ないで、どうしてここに入って来たのか』と尋ねた。その人は何も答えられなかった。</span></span>
<span className="v" id="v13" data-v="13" data-xref="マタイ 8:12; マタイ 25:30; マタイ 24:51"> <span className="woj">すると王は僕たちに言った。『この者の手足を縛って連れ出し、外の闇に投げ込みなさい。そこで泣き叫び、歯ぎしりすることになる。』</span></span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの第二の手紙 1:10; ルカ 13:23–24; マタイ 7:13–14"> <span className="woj">招かれる者は多いが、選ばれる者は少ない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ルカ 20:20–26; マルコ 12:13–17; 詩篇 2:2"> それからパリサイ人たちは出て行き、イエスの言葉尻を捕らえるにはどうすればよいか、相談した。</span>
<span className="v" id="v16" data-v="16" data-xref="マルコ 3:6; マルコ 8:15; マルコ 12:14"> そして自分たちの弟子をヘロデ党の者たちと共にイエスのもとへ遣わして言わせた。「先生、私たちは、あなたが誠実な方で、真理に基づいて神の道を教え、だれにも左右されないことを知っています。人を分け隔てなさらないからです。</span>
<span className="v" id="v17" data-v="17" data-xref="ルカ 2:1; ローマ人への手紙 13:6–7; マタイ 17:25"> それでは、どう思われるか、お聞かせください。カエサルに税を納めることは、律法にかなっているでしょうか。それとも、かなっていないでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨハネ 8:6; ルカ 5:22; ヨハネ 2:25"> しかし、イエスは彼らの悪意を見抜いて言われた。<span className="woj">「偽善者たちよ。なぜ私を試すのか。</span></span>
<span className="v" id="v19" data-v="19" data-xref="マタイ 20:2; ヨハネの黙示録 6:6; マタイ 18:28"> <span className="woj">税として納める貨幣を見せなさい。」</span><br />彼らは一デナリを持って来た。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ルカ 20:24"> イエスは彼らに尋ねられた。<span className="woj">「これはだれの肖像と銘か。」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 13:7; 箴言 24:21; 使徒の働き 4:19"> 彼らは、「カエサルのものです」と答えた。<br />するとイエスは彼らに言われた。<span className="woj">「それなら、カエサルのものはカエサルに、神のものは神に返しなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="マルコ 12:12; マタイ 22:46; ルカ 20:25–26"> 彼らはこれを聞いて驚き、イエスを残して立ち去った。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 4:1; マルコ 12:18–27; 使徒の働き 23:6–8"> その日、復活はないと言っているサドカイ人たちが、イエスのもとに来て尋ねた。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 25:5–10; ルカ 20:28; ルツ記 1:11"> 「先生、モーセは、『ある人が子どもを残さずに死んだなら、その人の兄弟がその妻と結婚し、兄弟のために子孫をもうけなければならない』と言いました。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「種」。">a</a></sup></span>
<span className="v" id="v25" data-v="25" data-xref="ルカ 20:29–33; マルコ 12:19–23; ヘブル人への手紙 9:27"> ところで、私たちのところに七人の兄弟がいました。長男は結婚しましたが、子孫を残さずに死に、妻を弟に残しました。</span>
<span className="v" id="v26" data-v="26"> 次男も三男も同じようになり、ついには七人ともそうなりました。</span>
<span className="v" id="v27" data-v="27"> 最後に、その女も死にました。</span>
<span className="v" id="v28" data-v="28"> では、復活の時、その女は七人のうちだれの妻になるのでしょうか。七人とも彼女を妻にしたのです。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ヨハネ 20:9; ローマ人への手紙 15:4; ルカ 1:37"> イエスは彼らに答えられた。<span className="woj">「あなたがたは聖書も神の力も知らないので、思い違いをしている。</span></span>
<span className="v" id="v30" data-v="30" data-xref="ルカ 20:34–36; マルコ 12:24–25; マタイ 24:38"> <span className="woj">復活の時には、めとることも嫁ぐこともなく、天にいる神の御使いたちのようになるからである。</span></span>
<span className="v" id="v31" data-v="31" data-xref="マタイ 12:3; マタイ 21:16; マタイ 21:42"> <span className="woj">死者の復活について、神があなたがたに語られた次の言葉を読んだことがないのか。</span></span>
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 3:6; マルコ 12:26–27; ルカ 20:37–38"> <span className="woj">『私はアブラハムの神、イサクの神、ヤコブの神である。』</span><span className="woj">神は死者の神ではなく、生きている者の神である。」</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="マルコ 12:17; マルコ 6:2; ヨハネ 7:46"> 群衆はこれを聞いて、イエスの教えに驚いた。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="マルコ 12:28–31; マタイ 25:3–5; マタイ 12:14"> パリサイ人たちは、イエスがサドカイ人たちを黙らせたと聞いて、一緒に集まった。</span>
<span className="v" id="v35" data-v="35" data-xref="ルカ 7:30; ルカ 10:25–37; ルカ 11:52"> そのうちの一人の律法の専門家が、イエスを試そうとして尋ねた。</span>
<span className="v" id="v36" data-v="36" data-xref="マルコ 12:28–33; マタイ 5:19–20; ルカ 11:42"> 「先生、律法の中で最も大切な戒めはどれですか。」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="マルコ 12:29–30; ルカ 10:27; 申命記 6:5"> イエスは彼に言われた。<span className="woj">「『心を尽くし、魂を尽くし、思いを尽くして、あなたの神である主を愛しなさい。』</span></span>
<span className="v" id="v38" data-v="38"> <span className="woj">これが第一の、最も大切な戒めである。</span></span>
<span className="v" id="v39" data-v="39" data-xref="マルコ 12:31; ルカ 10:27–37; レビ記 19:18"> <span className="woj">第二もこれと同じように大切である。『隣人を自分自身のように愛しなさい。』</span></span>
<span className="v" id="v40" data-v="40" data-xref="ローマ人への手紙 13:9; マタイ 7:12; ヨハネの手紙第一 4:19–21"> <span className="woj">律法全体と預言者たちは、この二つの戒めにかかっている。」</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="ルカ 20:41–44; マルコ 12:35–37; マタイ 22:34"> さて、パリサイ人たちが集まっていたとき、イエスは彼らに尋ねられた。</span>
<span className="v" id="v42" data-v="42" data-xref="エレミヤ書 23:5–6; ヨハネ 6:68–69; マタイ 16:13–17"> <span className="woj">「あなたがたはキリストについてどう思うか。彼はだれの子か。」</span><br />彼らはイエスに、「ダビデの子です」と答えた。</span>
</div>
<div className="bp poetry">
<span className="v" id="v43" data-v="43" data-xref="サムエル記第二 23:2; ヨハネの黙示録 4:2; マルコ 12:36"> イエスは彼らに言われた。<span className="woj">「それでは、どうしてダビデは聖霊によって彼を主と呼び、こう言っているのか。</span></span>
<span className="v" id="v44" data-v="44" data-xref="詩篇 110:1; ヘブル人への手紙 1:13; 使徒の働き 2:34–35"> <span className="pl pl-1 woj">『主は私の主に言われた。</span><br /><span className="pl pl-2 woj">「私の右に座っていなさい。</span><br /><span className="pl pl-2 woj">私があなたの敵をあなたの足台とするまで。」』</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="ローマ人への手紙 1:3–4; ヨハネの黙示録 22:16; ヨハネ 8:58"> <span className="woj">ダビデが彼を主と呼んでいるのなら、どうして彼はダビデの子なのか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="マルコ 12:34; ルカ 20:40; ルカ 14:6"> だれも一言も答えることができず、その日からは、あえてイエスに質問する者は一人もいなかった。</span>
</div>

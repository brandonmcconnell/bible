<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 23:25; マルコ 2:23–28; ルカ 6:1–5"> そのころ、イエスは安息日に麦畑を通られた。弟子たちは空腹だったので、麦の穂を摘んで食べ始めた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 12:10; ヨハネ 7:21–24; ルカ 14:3"> パリサイ人たちはそれを見て、イエスに言った。「見よ、あなたの弟子たちは、安息日にしてはならないことをしています。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="サムエル記第一 21:3–6; ルカ 6:3; マルコ 2:25–26"> しかし、イエスは彼らに言われた。<span className="woj">「ダビデとその供の者たちが空腹だったとき、ダビデが何をしたか、読んだことがないのか。</span></span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 24:5–9; 出エジプト記 25:30; レビ記 8:31"> <span className="woj">彼は神の家に入り、祭司のほかは、自分も供の者たちも食べることを許されていない供えのパンを食べた。</span></span>
<span className="v" id="v5" data-v="5" data-xref="民数記 28:9–10; ヨハネ 7:22–23; ネヘミヤ記 13:17"> <span className="woj">また、安息日に神殿の祭司たちが安息日を破っても罪に問われないことを、律法で読んだことがないのか。</span></span>
<span className="v" id="v6" data-v="6" data-xref="マタイ 12:41–42; 歴代誌 第二 6:18; ペテロの手紙第一 2:4–5"> <span className="woj">しかし、あなたがたに言う。神殿よりも偉大なものがここにある。</span></span>
<span className="v" id="v7" data-v="7" data-xref="ホセア書 6:6; マタイ 9:13; ミカ書 6:6–8"> <span className="woj">『私が望むのはあわれみであって、いけにえではない』とはどういう意味かを知っていたなら、</span><span className="woj">あなたがたは罪のない者たちを罪に定めなかっただろう。</span></span>
<span className="v" id="v8" data-v="8" data-xref="マルコ 2:28; ルカ 6:5; ヨハネ 5:17–23"> <span className="woj">人の子は安息日の主だからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="マルコ 3:1–6; ルカ 6:6–11"> イエスはそこを去り、彼らの会堂に入られた。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカ 13:14; ヨハネ 9:16; ヨハネ 8:6"> 見よ、そこに片手の萎えた人がいた。彼らはイエスを訴えるため、「安息日に癒すことは許されていますか」と尋ねた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="申命記 22:4; ルカ 14:5; ルカ 13:15–17"> イエスは彼らに言われた。<span className="woj">「あなたがたのうち、羊を一匹持っている人がいて、その羊が安息日に穴に落ちたなら、つかんで引き上げないだろうか。</span></span>
<span className="v" id="v12" data-v="12" data-xref="マタイ 6:26; ルカ 6:9; マルコ 3:4"> <span className="woj">人は羊より、どれほど価値があることか。だから、安息日に良いことをするのは許されている。」</span></span>
<span className="v" id="v13" data-v="13" data-xref="ルカ 13:13; 使徒の働き 3:7–8"> それから、その人に<span className="woj">「手を伸ばしなさい」</span>と言われた。彼が手を伸ばすと、もう一方の手と同じように元どおりになった。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネ 11:53; ヨハネ 10:39; マルコ 3:6"> しかし、パリサイ人たちは出て行き、どうすればイエスを殺せるかと相談した。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="マルコ 3:7–12; マタイ 10:23; マタイ 19:2"> イエスはそれを知って、そこから退かれた。大勢の群衆がイエスに従い、イエスは彼らをみな癒された。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイ 8:4; マタイ 9:30; マタイ 17:9"> そして、ご自分のことを人々に知らせないよう、彼らに命じられた。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 42:1–4; イザヤ書 42:9; マタイ 13:35"> これは、預言者イザヤを通して語られたことが成就するためであった。</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 42:1; ルカ 4:18; 使徒の働き 10:38"> <span className="pl pl-1">「見よ、私が選んだ私の僕、</span><br /><span className="pl pl-2">私の心が喜ぶ、私の愛する者。</span><br /><span className="pl pl-1">私は彼の上に私の霊を置く。</span><br /><span className="pl pl-2">彼は諸国民に公正を告げ知らせる。</span></span>
<span className="v" id="v19" data-v="19" data-xref="マタイ 11:29; ヨハネ 18:36–38; テモテへの第二の手紙 2:24–25"> <span className="pl pl-1">彼は争わず、叫ばず、</span><br /><span className="pl pl-2">通りでその声を聞く者もない。</span></span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 42:3–4; エゼキエル書 34:16; イザヤ書 61:1–3"> <span className="pl pl-1">傷ついた葦を折らず、</span><br /><span className="pl pl-2">くすぶる灯芯を消さない。</span><br /><span className="pl pl-1">公正を勝利へと導くまで。</span></span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 11:10; ローマ人への手紙 15:12–13; イザヤ書 42:4"> <span className="pl pl-2">諸国民は彼の名に望みを置く。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ルカ 11:14–15; マルコ 7:35–37; イザヤ書 29:18"> その時、悪霊につかれ、目が見えず、口も利けない人が、イエスのもとに連れて来られた。イエスが彼を癒すと、その人は話し、見えるようになった。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイ 9:27; ヨハネ 4:29; マタイ 22:42–43"> 群衆はみな驚いて、「この方がダビデの子ではないだろうか」と言った。</span>
<span className="v" id="v24" data-v="24" data-xref="マルコ 3:22; マタイ 9:34; ルカ 11:15"> しかし、パリサイ人たちはこれを聞いて言った。「この男が悪霊どもを追い出すのは、悪霊どもの支配者ベルゼブルによるほかはない。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ガラテヤ人への手紙 5:15; エレミヤ書 17:10; マタイ 9:4"> イエスは彼らの考えを知って、言われた。<span className="woj">「内輪で分裂した国はすべて荒れ果て、内輪で分裂した町や家は立ち行かない。</span></span>
<span className="v" id="v26" data-v="26" data-xref="コロサイ人への手紙 1:13; ヨハネの黙示録 20:2–3; ヨハネの手紙第一 5:19"> <span className="woj">もしサタンがサタンを追い出すなら、彼は内輪で分裂している。それでは、どうして彼の国が立ち行くだろうか。</span></span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 19:13–16; マルコ 9:38–39; ルカ 9:49–50"> <span className="woj">もし私がベルゼブルによって悪霊どもを追い出しているのなら、あなたがたの子らはだれによって追い出すのか。だから、彼らがあなたがたを裁く者となる。</span></span>
<span className="v" id="v28" data-v="28" data-xref="ルカ 11:20; ダニエル書 7:14; マタイ 6:33"> <span className="woj">しかし、私が神の霊によって悪霊どもを追い出しているのなら、神の御国はすでにあなたがたのところに来ている。</span></span>
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 49:24; マルコ 3:27; ルカ 11:21–22"> <span className="woj">また、まず強い者を縛らなければ、どうしてその家に入って家財を奪うことができるだろうか。縛ってから、その家を略奪するのである。</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="マルコ 9:40; ルカ 11:23; ヨシュア記 24:15"> <span className="woj">私と共にいない者は私に敵対している。私と共に集めない者は散らしている。</span></span>
<span className="v" id="v31" data-v="31" data-xref="ルカ 12:10; マルコ 3:28–30; ヘブル人への手紙 10:29"> <span className="woj">だから、あなたがたに言う。人のあらゆる罪と冒涜は赦される。しかし、聖霊に対する冒涜は赦されない。</span></span>
<span className="v" id="v32" data-v="32" data-xref="マルコ 3:29; ヘブル人への手紙 10:26–29; ヘブル人への手紙 6:4–6"> <span className="woj">人の子に逆らう言葉を語る者は赦される。しかし、聖霊に逆らう言葉を語る者は、この時代でも、来るべき時代でも赦されない。</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="ルカ 6:43–44; マタイ 7:16–20; ヤコブの手紙 4:8"> <span className="woj">木を良いとするなら、その実も良いとしなさい。木を悪いとするなら、その実も悪いとしなさい。木はその実によって分かるからである。</span></span>
<span className="v" id="v34" data-v="34" data-xref="ルカ 6:45; マタイ 15:18; エペソ人への手紙 4:29"> <span className="woj">まむしの子らよ。悪い者であるあなたがたに、どうして良いことを語れるだろうか。心に満ちていることを口が語るからである。</span></span>
<span className="v" id="v35" data-v="35" data-xref="箴言 15:4; コロサイ人への手紙 4:6; 箴言 15:28"> <span className="woj">良い人は、その良い蓄えから良いものを取り出し、</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR本文は「心の」を加えている。">a</a></sup><span className="woj">悪い人は、その悪い蓄えから悪いものを取り出す。</span></span>
<span className="v" id="v36" data-v="36" data-xref="伝道者の書 12:14; ローマ人への手紙 2:16; ヨハネの黙示録 20:12"> <span className="woj">あなたがたに言う。人々が口にする無益な言葉はすべて、裁きの日に申し開きをしなければならない。</span></span>
<span className="v" id="v37" data-v="37" data-xref="箴言 13:3; ヤコブの手紙 2:21–25"> <span className="woj">あなたは自分の言葉によって義とされ、自分の言葉によって罪に定められるからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="コリント人への第一の手紙 1:22; マルコ 8:11–12; ルカ 11:16"> すると、律法学者とパリサイ人の何人かが答えた。「先生、あなたからしるしを見せていただきたいのです。」</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="マタイ 16:4; ルカ 11:29–32; マルコ 8:38"> しかし、イエスは彼らに答えられた。<span className="woj">「邪悪で不実な時代はしるしを求めるが、預言者ヨナのしるしのほかには、しるしは与えられない。</span></span>
<span className="v" id="v40" data-v="40" data-xref="ヨナ書 1:17; マタイ 27:63–64; マタイ 16:21"> <span className="woj">ヨナが三日三晩、巨大な魚の腹の中にいたように、人の子も三日三晩、地の中心にいるからである。</span></span>
<span className="v" id="v41" data-v="41" data-xref="マタイ 12:42; ヘブル人への手紙 11:7; マタイ 12:6"> <span className="woj">ニネベの人々は、裁きの時にこの時代の人々と共に立ち上がり、彼らを罪に定める。ニネベの人々はヨナの宣教を聞いて悔い改めたからである。見よ、ヨナよりも偉大な者がここにいる。</span></span>
<span className="v" id="v42" data-v="42" data-xref="列王記第一 10:1–13; 歴代誌 第二 9:1–12; ヘブル人への手紙 1:2–4"> <span className="woj">南の女王は、裁きの時にこの時代の人々と共によみがえり、彼らを罪に定める。彼女はソロモンの知恵を聞くために、地の果てから来たからである。見よ、ソロモンよりも偉大な者がここにいる。</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="ルカ 11:24–26; ルカ 8:28–32; マタイ 8:29"> <span className="woj">汚れた霊が人から出て行くと、休み場を求めて水のない所を通り歩くが、見つからない。</span></span>
<span className="v" id="v44" data-v="44" data-xref="ヨハネの手紙第一 4:4; ヨハネの黙示録 13:8–9; ユダ 1:4–5"> <span className="woj">そこで、『出て来た自分の家に帰ろう』と言う。帰ってみると、家は空いていて、掃除され、整えられている。</span></span>
<span className="v" id="v45" data-v="45" data-xref="ルカ 11:26; マルコ 5:9; ヘブル人への手紙 6:4–8"> <span className="woj">そこで出かけて行き、自分より悪いほかの七つの霊を連れて来る。彼らは中に入って住みつく。その人の後の状態は、初めよりも悪くなる。この悪い時代も同じようになる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="マタイ 13:55; ヨハネ 2:12; ヨハネ 7:3"> イエスがまだ群衆に話しておられると、見よ、母と兄弟たちがイエスに話そうとして外に立っていた。</span>
<span className="v" id="v47" data-v="47"> ある人がイエスに言った。「見よ、あなたのお母様と兄弟たちが、あなたに話そうとして外に立っています。」</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="マルコ 3:32–33; マタイ 10:37; ルカ 2:52"> しかし、イエスはそう告げた人に答えられた。<span className="woj">「私の母とはだれか。私の兄弟たちとはだれか。」</span></span>
<span className="v" id="v49" data-v="49" data-xref="マルコ 3:34; ヨハネ 17:8–9; ヨハネ 20:17–20"> そして弟子たちのほうに手を伸ばして、言われた。<span className="woj">「見よ、私の母、私の兄弟たちである。</span></span>
<span className="v" id="v50" data-v="50" data-xref="ルカ 8:21; マルコ 3:35; ヨハネ 15:14"> <span className="woj">天におられる私の父の御心を行う者はだれでも、私の兄弟、姉妹、また母だからである。」</span></span>
</div>

<span className="v" id="v1" data-v="1" data-xref="マルコ 13:1–37; ルカ 21:5–36; エゼキエル書 8:6"> イエスが神殿を出て立ち去ろうとされると、弟子たちが近づいて来て、神殿の建物を指し示した。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカ 19:44; エレミヤ書 26:18; ミカ書 3:12"> しかし、イエスは彼らに答えられた。<span className="woj">「あなたがたは、これらすべてを見ているだろう。まことに、あなたがたに言う。ここでは、石が一つとしてほかの石の上に残されることなく、すべて崩される。」</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="マルコ 13:3–4; 使徒の働き 1:7; テサロニケ人への手紙第一 5:1–11"> イエスがオリーブ山に座っておられると、弟子たちがひそかに近づいて来て尋ねた。「お聞かせください。それらのことはいつ起こるのでしょうか。また、あなたの来臨と時代の終わりには、どんなしるしがあるのでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ヨハネの手紙第一 4:1; エレミヤ書 29:8; テサロニケ人への第二の手紙 2:3"> イエスは彼らに答えられた。<span className="woj">「だれにも惑わされないように気をつけなさい。</span></span>
<span className="v" id="v5" data-v="5" data-xref="マタイ 24:11; マタイ 24:24; エレミヤ書 14:14"> <span className="woj">多くの者が私の名によって来て、『私がキリストだ』と言い、多くの人を惑わすからである。</span></span>
<span className="v" id="v6" data-v="6" data-xref="マルコ 13:7–8; ルカ 21:9; ペテロの手紙第一 3:14–15"> <span className="woj">あなたがたは戦争と戦争のうわさを聞く。慌てないようにしなさい。これらすべては起こらなければならないが、まだ終わりではない。</span></span>
<span className="v" id="v7" data-v="7" data-xref="ルカ 21:11; ヨハネの黙示録 6:8; イザヤ書 19:2"> <span className="woj">民族は民族に、国は国に敵対して立ち上がり、各地に飢饉、疫病、地震が起こる。</span></span>
<span className="v" id="v8" data-v="8" data-xref="テサロニケ人への手紙第一 5:3; ペテロの手紙第一 4:17–18; 申命記 28:59"> <span className="woj">しかし、これらすべては産みの苦しみの始まりにすぎない。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヨハネ 16:2; ヨハネ 15:19–20; ルカ 21:16–17"> <span className="woj">そのとき、人々はあなたがたを苦難に引き渡して殺す。あなたがたは私の名のために、すべての国民から憎まれる。</span></span>
<span className="v" id="v10" data-v="10" data-xref="ミカ書 7:5–6; ルカ 21:16; マタイ 11:6"> <span className="woj">そのとき、多くの者がつまずき、互いに裏切り、憎み合う。</span></span>
<span className="v" id="v11" data-v="11" data-xref="マタイ 24:24; マタイ 7:15; マタイ 24:5"> <span className="woj">多くの偽預言者が現れ、多くの人を惑わす。</span></span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 2:4–5; ヤコブの手紙 4:1–4; ヨハネの黙示録 3:15"> <span className="woj">不法が増すため、多くの人の愛が冷える。</span></span>
<span className="v" id="v13" data-v="13" data-xref="マタイ 10:22; マルコ 13:13; ヨハネの黙示録 2:10"> <span className="woj">しかし、最後まで耐え忍ぶ者は救われる。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの黙示録 14:6; ローマ人への手紙 10:18; ローマ人への手紙 16:25–26"> <span className="woj">この御国の福音は、すべての国民へのあかしとして全世界で宣べ伝えられる。それから終わりが来る。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ダニエル書 9:27; ダニエル書 12:11; マルコ 13:14"> <span className="woj">だから、預言者ダニエルを通して語られた『荒廃をもたらす忌まわしいもの』が、</span><span className="woj">聖なる場所に立っているのを見たなら――読者は悟りなさい――、</span></span>
<span className="v" id="v16" data-v="16" data-xref="創世記 19:15–17; ルカ 21:21–22; ヘブル人への手紙 11:7"> <span className="woj">ユダヤにいる人々は山へ逃げなさい。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ルカ 17:31–33; マルコ 13:15–16; マタイ 10:27"> <span className="woj">屋上にいる人は、家から物を持ち出そうとして下りてはならない。</span></span>
<span className="v" id="v18" data-v="18"> <span className="woj">畑にいる人は、上着を取りに戻ってはならない。</span></span>
<span className="v" id="v19" data-v="19" data-xref="ルカ 23:29–30; 申命記 28:53–56; ルカ 21:23"> <span className="woj">その日には、身重の女と乳飲み子に乳を飲ませている女は災いである。</span></span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 16:29; 使徒の働き 1:12"> <span className="woj">あなたがたが逃げるのが冬や安息日にならないように祈りなさい。</span></span>
<span className="v" id="v21" data-v="21" data-xref="ダニエル書 12:1; ヨエル書 2:2; マラキ書 4:1"> <span className="woj">そのとき、大きな苦難が起こるからである。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「圧迫」。">a</a></sup><span className="woj">それは世界の初めから今に至るまでなく、今後も決してないほどのものである。</span></span>
<span className="v" id="v22" data-v="22" data-xref="マルコ 13:20; テモテへの第二の手紙 2:10; マタイ 24:31"> <span className="woj">もしその日数が短くされなければ、だれ一人生き残れない。しかし、選ばれた者たちのために、その日数は短くされる。</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ルカ 21:8; ルカ 17:23–24; 申命記 13:1–3"> <span className="woj">そのとき、だれかがあなたがたに、『見よ、キリストはここにいる』、または『あそこにいる』と言っても、信じてはならない。</span></span>
<span className="v" id="v24" data-v="24" data-xref="テサロニケ人への第二の手紙 2:9–11; マルコ 13:22; ヨハネの黙示録 13:13–14"> <span className="woj">偽キリストや偽預言者たちが現れ、大きなしるしと不思議なわざを行い、できることなら、選ばれた者たちさえ惑わそうとするからである。</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ヨハネ 16:1; ルカ 21:13; イザヤ書 48:5–6"> <span className="woj">見よ、私は前もってあなたがたに告げた。</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ルカ 3:2–3; イザヤ書 40:3; マタイ 3:1"> <span className="woj">だから、人々があなたがたに、『見よ、彼は荒野にいる』と言っても、出て行ってはならない。また、『見よ、奥の部屋にいる』と言っても、信じてはならない。</span></span>
<span className="v" id="v27" data-v="27" data-xref="ルカ 17:24–37; ゼカリヤ書 9:14; ヨブ記 37:3"> <span className="woj">稲妻が東からひらめき、西にまで見えるように、人の子の来臨もそのようになるからである。</span></span>
<span className="v" id="v28" data-v="28" data-xref="ルカ 17:37; ヨブ記 39:27–30; 申命記 28:49"> <span className="woj">死骸のある所には、はげわし</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または「わし」。">b</a></sup><span className="woj">が集まる。</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="アモス書 8:9; ヨエル書 3:15; イザヤ書 13:10"> <span className="woj">しかし、その日の苦難の直後、</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="または「圧迫」。">c</a></sup><span className="woj">太陽は暗くなり、月は光を放たず、星は空から落ち、天の力は揺り動かされる。</span></span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの黙示録 1:7; ダニエル書 7:13; ルカ 21:27"> <span className="woj">そのとき、人の子のしるしが空に現れる。地上のすべての部族は嘆き、人の子が力と大いなる栄光をもって、空の雲に乗って来るのを見る。</span></span>
<span className="v" id="v31" data-v="31" data-xref="テサロニケ人への手紙第一 4:16; マルコ 13:27; イザヤ書 27:13"> <span className="woj">人の子は、大きなラッパの音と共に御使いたちを遣わす。彼らは四方から、空の果てから果てまで、選ばれた者たちを集める。</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="マルコ 13:28–29; ルカ 21:29–30"> <span className="woj">いちじくの木から、このたとえを学びなさい。枝が柔らかくなり、葉が出ると、夏が近いことが分かる。</span></span>
<span className="v" id="v33" data-v="33" data-xref="ヤコブの手紙 5:9; ヘブル人への手紙 10:37; エゼキエル書 7:2–14"> <span className="woj">同じように、あなたがたもこれらすべてを見たなら、人の子が近く、戸口まで来ていることを知りなさい。</span></span>
<span className="v" id="v34" data-v="34" data-xref="マルコ 13:30–31; ルカ 21:32–33; マタイ 16:28"> <span className="woj">まことに、あなたがたに言う。この時代</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="「時代」と訳された言葉（ゲネア）は、「民族」とも訳すことができる。">d</a></sup><span className="woj">は、これらすべてのことが起こるまで決して過ぎ去らない。</span></span>
<span className="v" id="v35" data-v="35" data-xref="イザヤ書 40:8; ペテロの手紙第一 1:25; 民数記 23:19"> <span className="woj">天と地は過ぎ去るが、私の言葉は決して過ぎ去らない。</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="マルコ 13:32; 使徒の働き 1:7; マタイ 24:44"> <span className="woj">しかし、その日と時刻についてはだれも知らない。天の御使いたちも知らず、</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="NU本文は「子も知らず」を加えている。">e</a></sup><span className="woj">ただ私の父だけが知っておられる。</span></span>
<span className="v" id="v37" data-v="37" data-xref="ルカ 17:26–27; 創世記 6:1–7; ペテロの第二の手紙 2:5"> <span className="woj">ノアの日々と同じように、人の子の来臨もそうなる。</span></span>
<span className="v" id="v38" data-v="38" data-xref="ルカ 17:26–28; ローマ人への手紙 13:13–14; ルカ 14:18–20"> <span className="woj">洪水前の人々は、ノアが箱舟に入るその日まで、食べたり飲んだり、めとったり嫁いだりしていた。</span></span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネ 3:20; マタイ 24:37; 使徒の働き 13:41"> <span className="woj">そして洪水が来て、彼らをみなさらって行くまで、何も気づかなかった。人の子の来臨もそのようになる。</span></span>
<span className="v" id="v40" data-v="40" data-xref="ルカ 17:34–37; ペテロの第二の手紙 2:7–9; ペテロの第二の手紙 2:5"> <span className="woj">そのとき、二人の男が畑にいる。一人は連れて行かれ、一人は残される。</span></span>
<span className="v" id="v41" data-v="41" data-xref="出エジプト記 11:5; イザヤ書 47:2; ルカ 17:35"> <span className="woj">二人の女がひき臼を回している。一人は連れて行かれ、一人は残される。</span></span>
<span className="v" id="v42" data-v="42" data-xref="ルカ 21:36; テサロニケ人への手紙第一 5:6; マタイ 25:13"> <span className="woj">だから、目を覚ましていなさい。あなたがたの主が何時に来られるか、知らないからである。</span></span>
<span className="v" id="v43" data-v="43" data-xref="ルカ 12:39; マタイ 24:44; テサロニケ人への手紙第一 5:2–6"> <span className="woj">しかし、このことを知っておきなさい。家の主人は、盗人が夜のどの時刻に来るか分かっていたなら、目を覚ましていて、家に押し入らせなかっただろう。</span></span>
<span className="v" id="v44" data-v="44" data-xref="マタイ 25:10; マタイ 24:42; マタイ 25:13"> <span className="woj">だから、あなたがたも用意していなさい。人の子は、あなたがたが思いもしない時に来るからである。</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="マタイ 25:21; マタイ 25:23; コリント人への第一の手紙 4:1–2"> <span className="woj">それでは、主人から家の者たちを任され、定められた時に食事を与える、忠実で賢い僕とはだれか。</span></span>
<span className="v" id="v46" data-v="46" data-xref="ヨハネの黙示録 16:15; ルカ 12:43; ルカ 12:37"> <span className="woj">主人が帰って来たとき、そのようにしているのを見られる僕は幸いである。</span></span>
<span className="v" id="v47" data-v="47" data-xref="マタイ 25:23; マタイ 25:21; ルカ 12:37"> <span className="woj">まことに、あなたがたに言う。主人はその僕に、自分の全財産を任せる。</span></span>
<span className="v" id="v48" data-v="48" data-xref="マタイ 18:32; イザヤ書 32:6; ルカ 12:45"> <span className="woj">しかし、その僕が悪い者で、心の中で、『主人の帰りは遅れている』と言い、</span></span>
<span className="v" id="v49" data-v="49" data-xref="ヨハネの黙示録 17:6; ヨハネの黙示録 16:6; ミカ書 3:5"> <span className="woj">仲間の僕たちを打ちたたき始め、酔っ払いたちと一緒に食べたり飲んだりするなら、</span></span>
<span className="v" id="v50" data-v="50" data-xref="テサロニケ人への手紙第一 5:2–3; ヨハネの黙示録 3:3; マタイ 24:42–44"> <span className="woj">その僕の主人は、彼が予想していない日、知らない時刻に帰って来る。</span></span>
<span className="v" id="v51" data-v="51" data-xref="マタイ 8:12; マタイ 22:13; ルカ 12:46"> <span className="woj">そして彼を切り裂き、偽善者たちと同じ運命に定める。そこで泣き叫び、歯ぎしりすることになる。</span></span>

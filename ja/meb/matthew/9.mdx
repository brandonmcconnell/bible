<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 4:13; ルカ 8:37; マタイ 8:18"> イエスは舟に乗って向こう岸へ渡り、ご自分の町に来られた。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコ 2:1–12; ルカ 5:18–26; エレミヤ書 31:33–34"> 見よ、人々が体の麻痺した人を寝床に載せて、イエスのもとに運んで来た。イエスは彼らの信仰を見て、その人に言われた。<span className="woj">「子よ、元気を出しなさい。あなたの罪は赦されている。」</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="マタイ 26:65; ルカ 5:21; レビ記 24:16"> 見よ、律法学者たちの何人かが心の中で、「この男は神を冒涜している」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ルカ 6:8; マタイ 12:25; ヨハネの黙示録 2:23"> イエスは彼らの思いを知って言われた。<span className="woj">「なぜ心の中で悪いことを考えているのか。</span></span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネ 5:8–14; マルコ 2:9–12; 使徒の働き 3:16"> <span className="woj">『あなたの罪は赦されている』と言うのと、『起きて歩きなさい』と言うのと、どちらが易しいか。</span></span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 43:25; マタイ 9:5; ヨハネ 20:21–23"> <span className="woj">しかし、人の子が地上で罪を赦す権威を持っていることを、あなたがたが知るために――」</span>それから、体の麻痺した人に言われた。<span className="woj">「起きて寝床を取り上げ、自分の家に帰りなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> その人は起き上がり、自分の家に帰って行った。</span>
<span className="v" id="v8" data-v="8" data-xref="ルカ 7:16; マタイ 15:31; 使徒の働き 4:21"> 群衆はこれを見て驚き、このような権威を人々にお与えになった神をあがめた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ルカ 5:27–38; マルコ 2:14–22; ルカ 19:2–10"> イエスはそこから進んで行き、マタイという人が収税所に座っているのをご覧になった。そして、<span className="woj">「私について来なさい」</span>と言われた。するとマタイは立ち上がり、イエスに従った。</span>
<span className="v" id="v10" data-v="10" data-xref="テモテへの手紙第一 1:13–16; ルカ 5:29–32; マルコ 2:15–17"> イエスが家で食卓に着いておられると、見よ、大勢の徴税人や罪人が来て、イエスや弟子たちと一緒に食卓に着いた。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイ 11:19; ルカ 5:30; マルコ 2:16"> パリサイ人たちはこれを見て、弟子たちに言った。「なぜあなたがたの先生は、徴税人や罪人と一緒に食事をするのか。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ルカ 5:31; ヨハネの黙示録 3:17–18; マルコ 2:17"> イエスはこれを聞いて、彼らに言われた。<span className="woj">「健康な人に医者は必要ない。必要なのは病人である。</span></span>
<span className="v" id="v13" data-v="13" data-xref="マルコ 2:17; ルカ 19:10; ホセア書 6:6"> <span className="woj">『私が望むのはあわれみであって、いけにえではない』とはどういう意味か、行って学びなさい。</span><span className="woj">私が来たのは義人を招くためではなく、罪人を悔い改めに招くためである。」</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NU本文では「悔い改めに」が省かれている。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ルカ 5:33–39; マルコ 2:18–22; マタイ 6:16"> それから、ヨハネの弟子たちがイエスのもとに来て言った。「私たちとパリサイ人はたびたび断食するのに、なぜあなたの弟子たちは断食しないのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨハネの黙示録 19:9; ヨハネ 3:29; ヨハネの黙示録 21:2"> イエスは彼らに言われた。<span className="woj">「花婿が一緒にいる間、花婿の友人たちは悲しむことができるだろうか。しかし、花婿が彼らから取り去られる日が来る。そのとき、彼らは断食する。</span></span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への第一の手紙 3:1–2; ヨハネ 16:12; 詩篇 125:3"> <span className="woj">だれも、縮んでいない布切れを古い衣服に当てることはしない。その継ぎ切れが衣服を引き裂き、破れがもっとひどくなるからである。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ヨシュア記 9:4; ヨブ記 32:19; 詩篇 119:83"> <span className="woj">また、新しいぶどう酒を古い革袋に入れる人はいない。そんなことをすれば、革袋は裂け、ぶどう酒は流れ出て、革袋も使えなくなる。新しいぶどう酒は新しい革袋に入れる。そうすれば、どちらも保たれる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ルカ 8:41–56; マルコ 5:22–43; マタイ 8:2"> イエスが彼らにこれらのことを話しておられると、見よ、一人の指導者が来て、イエスを拝み、言った。「私の娘がたった今、死にました。けれども、おいでになって娘の上に手を置いてください。そうすれば生き返ります。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 10:38; ガラテヤ人への手紙 6:9–10; マタイ 8:7"> イエスは立ち上がり、弟子たちと共に彼について行かれた。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカ 8:43–56; マタイ 14:36; マルコ 6:56"> 見よ、十二年間、出血が続いていた女が後ろから近づき、イエスの衣の裾<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または「房」。">b</a></sup>に触れた。</span>
<span className="v" id="v21" data-v="21" data-xref="マルコ 5:26–33; ルカ 8:45–47; 使徒の働き 19:12"> 彼女は、「あの方の衣に触れるだけで、私は癒される」と心の中で言っていたからである。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ルカ 7:50; マタイ 15:28; マタイ 9:2"> イエスは振り向いて彼女を見て、言われた。<span className="woj">「娘よ、元気を出しなさい。あなたの信仰があなたを癒した。」</span>その時から、女は癒された。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="歴代誌 第二 35:25; マルコ 5:35–40; ルカ 8:49–51"> イエスは指導者の家に入り、笛を吹く者たちと騒いでいる群衆をご覧になった。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 20:10; ヨハネ 11:11–13; マタイ 27:39–43"> そして彼らに言われた。<span className="woj">「そこを空けなさい。少女は死んだのではなく、眠っているのだから。」</span><br />人々はイエスをあざ笑った。</span>
<span className="v" id="v25" data-v="25" data-xref="マルコ 9:27; マルコ 5:41; ルカ 8:54"> しかし、群衆が外に出されると、イエスは中に入り、少女の手を取られた。すると少女は起き上がった。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイ 4:24; マタイ 14:1–2; マルコ 1:45"> この知らせは、その地方全体に広まった。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="マタイ 15:22; マタイ 20:30–31; マルコ 10:46–48"> イエスがそこから進んで行かれると、二人の目の見えない人が、「ダビデの子よ、私たちをあわれんでください」と叫びながら、ついて来た。</span>
<span className="v" id="v28" data-v="28" data-xref="マルコ 9:23–24; マタイ 13:58; マタイ 8:2"> イエスが家に入られると、目の見えない人たちが近づいて来た。イエスは彼らに言われた。<span className="woj">「私にこれができると信じるか。」</span><br />彼らは答えた。「はい、主よ。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="マタイ 15:28; マルコ 10:52; マタイ 8:13"> そこでイエスは彼らの目に触れ、言われた。<span className="woj">「あなたがたの信仰のとおりになるように。」</span></span>
<span className="v" id="v30" data-v="30" data-xref="マタイ 8:4; ルカ 5:14; マタイ 17:9"> すると、彼らの目は開かれた。イエスは彼らを厳しく戒めて、<span className="woj">「だれにもこのことを知られないようにしなさい」</span>と言われた。</span>
<span className="v" id="v31" data-v="31" data-xref="マルコ 7:36; マタイ 9:26; マルコ 1:44–45"> しかし彼らは出て行き、その地方全体にイエスの評判を広めた。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="マタイ 4:24; マタイ 12:22–24; ルカ 11:14"> 彼らが出て行くと、見よ、悪霊につかれて口の利けない人が、イエスのもとに連れて来られた。</span>
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 35:6; マルコ 7:32–37; 出エジプト記 4:11–12"> 悪霊が追い出されると、口の利けなかった人が話し始めた。群衆は驚いて言った。「イスラエルで、このようなことが見られたことは一度もない。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ルカ 11:15; マルコ 3:22; マタイ 12:23–24"> しかし、パリサイ人たちは言った。「彼は悪霊どもの支配者によって、悪霊を追い出しているのだ。」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="マタイ 4:23–24; 使徒の働き 10:38; マルコ 6:56"> イエスはすべての町や村を巡り、諸会堂で教え、御国の福音を宣べ伝え、民のあらゆる病気とあらゆる患いを癒された。</span>
<span className="v" id="v36" data-v="36" data-xref="マルコ 6:34; 民数記 27:17; エレミヤ書 50:6"> イエスは群衆を見ると、深くあわれまれた。彼らが苦しめられ、<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="TR本文では「苦しめられ」の代わりに「疲れ果て」となっている。">c</a></sup>羊飼いのいない羊のように散らされていたからである。</span>
<span className="v" id="v37" data-v="37" data-xref="ルカ 10:2; マルコ 16:15; コリント人への第一の手紙 3:9"> そこで弟子たちに言われた。<span className="woj">「収穫は多いが、働き手が少ない。</span></span>
<span className="v" id="v38" data-v="38" data-xref="ルカ 10:1–2; エレミヤ書 3:15; テサロニケ人への第二の手紙 3:1"> <span className="woj">だから、収穫の主に、収穫の場へ働き手を送り出してくださるよう祈りなさい。」</span></span>
</div>
</div>

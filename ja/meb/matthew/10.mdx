<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカ 9:1–6; マルコ 3:13–15; マルコ 6:7–13"> イエスは十二人の弟子を呼び寄せ、汚れた霊を追い出し、あらゆる病気とあらゆる患いを癒す権威を彼らにお与えになった。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 4:21; 使徒の働き 1:13; ルカ 5:10"> 十二使徒の名は次のとおりである。まず、ペテロと呼ばれるシモンと、その兄弟アンデレ。ゼベダイの子ヤコブと、その兄弟ヨハネ。</span>
<span className="v" id="v3" data-v="3" data-xref="マルコ 3:18; 使徒の働き 1:13; マルコ 2:14"> フィリポとバルトロマイ。トマスと徴税人マタイ。アルパヨの子ヤコブと、レバイ、またの名を<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NU本文では「レバイ、またの名を」が省かれている。">a</a></sup>タダイ。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイ 26:14; マタイ 26:47; ヨハネ 13:2"> 熱心党員シモンと、イエスを裏切ったイスカリオテのユダである。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ヨハネ 4:9; 使徒の働き 22:21–23; 列王記第二 17:24–41"> イエスはこの十二人を遣わし、命じて言われた。<span className="woj">「異邦人の道へ行ってはならない。また、サマリア人の町に入ってはならない。</span></span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 50:6; エゼキエル書 34:6; イザヤ書 53:6"> <span className="woj">むしろ、イスラエルの家の失われた羊たちのところへ行きなさい。</span></span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 28:31; マタイ 3:2; ルカ 9:60"> <span className="woj">行って、『天の御国が近づいた』と宣べ伝えなさい。</span></span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 3:6; ルカ 10:9; 使徒の働き 4:30"> <span className="woj">病人を癒し、重い皮膚病の人々を清め、</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TR本文は「死者を生き返らせ」を加えている。">b</a></sup><span className="woj">悪霊を追い出しなさい。ただで受けたのだから、ただで与えなさい。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ルカ 22:35; ルカ 9:3–5; ルカ 10:4–12"> <span className="woj">帯の中に金貨も銀貨も銅貨も入れてはならない。</span></span>
<span className="v" id="v10" data-v="10" data-xref="ルカ 10:7–12; テモテへの手紙第一 5:17–18; コリント人への第一の手紙 9:4–14"> <span className="woj">旅のための袋も、二枚の上着も、履物も、杖も持って行ってはならない。働く者が食べ物を受けるのは当然だからである。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ルカ 10:7–8; ヨブ記 31:32; 士師記 19:16–21"> <span className="woj">どの町や村に入っても、そこにふさわしい人がいるか調べ、出て行くまでその人のところにとどまりなさい。</span></span>
<span className="v" id="v12" data-v="12" data-xref="サムエル記第一 25:6; ルカ 10:5–6; 使徒の働き 10:36"> <span className="woj">その家に入るときは、挨拶をしなさい。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ルカ 10:6; 詩篇 35:13; コリント人への第二の手紙 2:16"> <span className="woj">その家がふさわしければ、あなたがたの平安がその家に臨むようにしなさい。しかし、ふさわしくなければ、その平安をあなたがたのもとに戻しなさい。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ルカ 10:10–11; 使徒の働き 18:6; ネヘミヤ記 5:13"> <span className="woj">あなたがたを受け入れず、あなたがたの言葉を聞かない者がいるなら、その家や町を出るとき、足のちりを払い落としなさい。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ペテロの第二の手紙 2:6; ヨハネの手紙第一 4:17; ヨハネ 15:22–24"> <span className="woj">まことに、あなたがたに言う。裁きの日には、その町よりもソドムとゴモラの地のほうが耐えやすい。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ルカ 10:3; ピリピ人への手紙 2:15; コリント人への第一の手紙 14:20"> <span className="woj">見よ、私はあなたがたを狼の中にいる羊のように遣わす。だから、蛇のように賢く、鳩のように純真でありなさい。</span></span>
<span className="v" id="v17" data-v="17" data-xref="マルコ 13:9; マタイ 23:34; 使徒の働き 26:11"> <span className="woj">人々に用心しなさい。彼らはあなたがたを議会に引き渡し、会堂でむち打つ。</span></span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 5:25–27; マタイ 8:4; 詩篇 2:1–6"> <span className="woj">また、私のために総督や王たちの前に連れて行かれる。それは彼らと諸国民へのあかしとなるためである。</span></span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 4:12; マルコ 13:11–13; テモテへの第二の手紙 4:17"> <span className="woj">しかし、彼らがあなたがたを引き渡すとき、どのように、何を話そうかと思い悩んではならない。話すべきことは、その時に与えられるからである。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ルカ 21:15; 使徒の働き 6:10; ルカ 12:12"> <span className="woj">語るのはあなたがたではなく、あなたがたを通して語る、あなたがたの父の御霊だからである。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ルカ 21:16–17; ミカ書 7:5–6; マルコ 13:12–13"> <span className="woj">兄弟は兄弟を、父は子を、死に引き渡す。子どもたちは両親に逆らって立ち上がり、彼らを死なせる。</span></span>
<span className="v" id="v22" data-v="22" data-xref="マタイ 24:13; ヤコブの手紙 1:12; ヨハネの黙示録 2:10"> <span className="woj">あなたがたは、私の名のためにすべての人から憎まれる。しかし、最後まで耐え忍ぶ者は救われる。</span></span>
<span className="v" id="v23" data-v="23" data-xref="マタイ 16:28; 使徒の働き 8:1; マルコ 13:26"> <span className="woj">この町で迫害されたなら、次の町へ逃げなさい。まことに、あなたがたに言う。人の子が来るまでに、あなたがたがイスラエルの町々を巡り尽くすことは決してない。</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヨハネ 15:20; ルカ 6:40; ヨハネ 13:16"> <span className="woj">弟子は先生より上ではなく、僕は主人より上ではない。</span></span>
<span className="v" id="v25" data-v="25" data-xref="ルカ 11:15; マタイ 12:24; マタイ 9:34"> <span className="woj">弟子は先生のように、僕は主人のようになれば十分である。家の主人がベルゼブルと呼ばれたのなら、</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="文字どおりには「ハエの主」、または悪魔。">c</a></sup><span className="woj">その家の者たちは、なおさらそう呼ばれるだろう。</span></span>
<span className="v" id="v26" data-v="26" data-xref="ルカ 8:17; マルコ 4:22; エレミヤ書 1:8"> <span className="woj">だから、彼らを恐れてはならない。覆われているものは必ず明らかにされ、隠されているものは必ず知られるようになるからである。</span></span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 5:20; ヨハネ 16:13; ヨハネ 16:1"> <span className="woj">私が暗闇であなたがたに語ることを、明るいところで話しなさい。耳元で聞くことを、屋上から宣べ伝えなさい。</span></span>
<span className="v" id="v28" data-v="28" data-xref="ルカ 12:4–5; イザヤ書 8:12–13; ヨハネの黙示録 2:10"> <span className="woj">体を殺しても、魂を殺すことのできない者たちを恐れてはならない。むしろ、魂も体もゲヘナで滅ぼすことのできる方を恐れなさい。</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="または「地獄」。">d</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ルカ 12:6–7; 詩篇 104:27–30"> <span className="woj">二羽の雀は一アサリオンで売られているではないか。</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一アサリオンは一ドラクマの十分の一、または一デナリの十六分の一に相当する小さな硬貨である。一アサリオンは農作業の約三十分の賃金に相当する。">e</a></sup><span className="woj">しかし、あなたがたの父の御心によらずに、その一羽でさえ地に落ちることはない。</span></span>
<span className="v" id="v30" data-v="30" data-xref="ルカ 12:7; サムエル記第一 14:45; 使徒の働き 27:34"> <span className="woj">あなたがたの髪の毛さえ、すべて数えられている。</span></span>
<span className="v" id="v31" data-v="31" data-xref="ルカ 12:24; 詩篇 8:5; マタイ 6:26"> <span className="woj">だから、恐れてはならない。あなたがたは多くの雀よりも価値がある。</span></span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネの黙示録 3:5; ローマ人への手紙 10:9–10; ルカ 12:8–9"> <span className="woj">だから、だれでも人々の前で私を認める者を、私も天におられる私の父の前で認める。</span></span>
<span className="v" id="v33" data-v="33" data-xref="テモテへの第二の手紙 2:12; ルカ 9:26; ルカ 12:9"> <span className="woj">しかし、だれでも人々の前で私を否む者を、私も天におられる私の父の前で否む。</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ルカ 12:49–53; 使徒の働き 14:4; 使徒の働き 13:45–50"> <span className="woj">私が地上に平和をもたらすために来たと思ってはならない。平和ではなく、剣をもたらすために来たのである。</span></span>
<span className="v" id="v35" data-v="35" data-xref="ミカ書 7:5–6; マタイ 10:21; ルカ 21:16"> <span className="woj">私は、人をその父に、娘をその母に、嫁をそのしゅうとめに逆らわせるために来た。</span></span>
<span className="v" id="v36" data-v="36" data-xref="ミカ書 7:6; エレミヤ書 12:6; 詩篇 41:9"> <span className="woj">人の敵は、その家の者たちである。</span></span>
<span className="v" id="v37" data-v="37" data-xref="ルカ 14:26; マタイ 22:37; ピリピ人への手紙 3:7–9"> <span className="woj">私よりも父や母を愛する者は、私にふさわしくない。私よりも息子や娘を愛する者も、私にふさわしくない。</span></span>
<span className="v" id="v38" data-v="38" data-xref="ルカ 14:27; マルコ 8:34; マタイ 16:24"> <span className="woj">自分の十字架を負って私の後について来ない者は、私にふさわしくない。</span></span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネ 12:25; マルコ 8:35–36; ルカ 17:33"> <span className="woj">自分のいのちを得ようとする者はそれを失い、私のために自分のいのちを失う者はそれを見いだす。</span></span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="ヨハネ 13:20; ルカ 9:48; ルカ 10:16"> <span className="woj">あなたがたを受け入れる者は私を受け入れ、私を受け入れる者は私を遣わされた方を受け入れる。</span></span>
<span className="v" id="v41" data-v="41" data-xref="ヨハネの手紙第三 1:5–8; ヘブル人への手紙 6:10; 列王記第二 4:16–17"> <span className="woj">預言者であるという理由で預言者を受け入れる者は、預言者の報いを受ける。義人であるという理由で義人を受け入れる者は、義人の報いを受ける。</span></span>
<span className="v" id="v42" data-v="42" data-xref="ヘブル人への手紙 6:10; マタイ 25:40; マルコ 9:41–42"> <span className="woj">弟子であるという理由で、この小さい者たちの一人に冷たい水を一杯でも飲ませる者は、決してその報いを失うことはない。まことに、あなたがたに言う。」</span></span>
</div>

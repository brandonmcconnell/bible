<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ゼカリヤ書 14:4; マルコ 11:1–10; ルカ 21:37"> 一行がエルサレムに近づき、オリーブ山にあるベトスファゲに来たとき、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR本文とNU本文では「ベトスファゲ」の代わりに「ベトファゲ」となっている。">a</a></sup>イエスは二人の弟子を遣わして、</span>
<span className="v" id="v2" data-v="2" data-xref="ルカ 19:30–32; マルコ 11:2–3; ヨハネ 2:5–8"> 彼らに言われた。<span className="woj">「向こうの村へ行きなさい。すぐに、ろばがつながれ、そのそばに子ろばがいるのを見つける。つないである綱を解いて、私のところに連れて来なさい。</span></span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 8:1–2; 使徒の働き 17:25; コリント人への第二の手紙 8:9"> <span className="woj">もしだれかが何か言ったら、『主がお入り用なのです』と言いなさい。そうすれば、その人はすぐに行かせてくれる。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="ゼカリヤ書 9:9; ヨハネ 12:15; マタイ 1:22"> これらすべてのことが起こったのは、預言者を通して語られたことが成就するためであった。</span>
<span className="v" id="v5" data-v="5" data-xref="ゼカリヤ書 9:9–10; イザヤ書 62:11; イザヤ書 12:6"> <span className="pl pl-1">「シオンの娘に告げよ。</span><br /><span className="pl pl-2">見よ、あなたの王があなたのところに来られる。</span><br /><span className="pl pl-2">柔和で、ろばに乗り、</span><br /><span className="pl pl-2">ろばの子である子ろばに乗って。」</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 39:43; ヨハネ 15:14; 出エジプト記 40:16"> 弟子たちは出かけて行き、イエスが命じられたとおりにした。</span>
<span className="v" id="v7" data-v="7" data-xref="列王記第二 9:13; マルコ 11:4–8; ルカ 19:32–35"> そして、ろばと子ろばを連れて来て、その上に自分たちの上着を掛けると、イエスはその上に座られた。</span>
<span className="v" id="v8" data-v="8" data-xref="列王記第二 9:13; ヨハネ 12:13; レビ記 23:40"> 非常に大勢の群衆が、自分たちの上着を道に敷いた。また、木の枝を切って道に敷く者たちもいた。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 118:24–26; ルカ 2:14; ヨハネ 12:13–15"> イエスの前を行く群衆も、後に従う群衆も叫び続けた。「ダビデの子にホサナ！<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「ホサナ」は「私たちをお救いください」または「どうか私たちをお助けください」という意味である。">b</a></sup>主の名によって来られる方は幸いである！ いと高き所にホサナ！」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 9:5; ルツ記 1:19; ヨハネ 12:16–19"> イエスがエルサレムに入られると、町中が騒ぎ立ち、「この方はだれなのか」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヨハネ 6:14; ルカ 7:16; ヨハネ 7:40"> 群衆は、「この方は、ガリラヤのナザレから来た預言者イエスだ」と答えた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨハネ 2:14–17; ルカ 19:45–47; マルコ 11:15–18"> イエスは神殿に入ると、神殿で売り買いしていた者たちをみな追い出し、両替人の台と、鳩を売る者たちの腰掛けを倒された。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 7:11; イザヤ書 56:7; ルカ 19:46"> そして彼らに言われた。<span className="woj">「『私の家は祈りの家と呼ばれる』と書かれている。</span><span className="woj">それなのに、あなたがたはそれを強盗の巣にしている！」</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 3:1–9; 使徒の働き 10:38; マタイ 11:4–5"> 神殿で、足の不自由な人や目の見えない人がイエスのもとに来たので、イエスは彼らを癒された。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイ 21:9; ルカ 19:39–40; イザヤ書 26:11"> しかし祭司長たちと律法学者たちは、イエスが行われた驚くべきわざを見、また子どもたちが神殿で「ダビデの子にホサナ」と叫んでいるのを見て、憤り、</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 8:2; マタイ 11:25; ルカ 19:39–40"> イエスに言った。「この者たちが何と言っているか、聞こえるか。」<br />イエスは彼らに言われた。<span className="woj">「聞こえている。あなたがたは、『幼子と乳飲み子の口から、あなたは賛美を完成された』とあるのを、一度も読んだことがないのか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヨハネ 11:18; マルコ 11:11; ルカ 24:50"> イエスは彼らを残し、町を出てベタニアへ行き、そこで夜を過ごされた。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="マタイ 4:2; ヘブル人への手紙 4:15; マタイ 12:1"> 朝早く、町へ戻る途中、イエスは空腹を覚えられた。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネ 15:6; マルコ 11:14; テトス 1:16"> 道端にいちじくの木があるのを見て、そばに行かれたが、葉のほかには何も見つからなかった。そこで木に、<span className="woj">「今後いつまでも、おまえが実を結ぶことはない」</span>と言われた。<br />すると、いちじくの木はたちまち枯れた。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 40:6–8; マルコ 11:20–21; ヤコブの手紙 1:10–11"> 弟子たちはこれを見て驚き、「どうして、いちじくの木がたちまち枯れたのでしょうか」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ヤコブの手紙 1:6; マタイ 17:20; マルコ 11:22–23"> イエスは彼らに答えられた。<span className="woj">「まことに、あなたがたに言う。もしあなたがたに信仰があり、疑わないなら、このいちじくの木にしたのと同じことができるだけでなく、この山に、『持ち上がって海に投げ込まれよ』と言っても、そのとおりになる。</span></span>
<span className="v" id="v22" data-v="22" data-xref="マタイ 7:7; ヨハネの手紙第一 5:14–15; マルコ 11:24"> <span className="woj">信じて祈り求めるものは、何でも受ける。」</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 4:7; マルコ 11:27–33; 歴代誌上 24:1–19"> イエスが神殿に入り、教えておられると、祭司長たちと民の長老たちが近づいて来て言った。「何の権威によって、これらのことをしているのか。だれがその権威をあなたに与えたのか。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ルカ 6:9; コロサイ人への手紙 4:6; マタイ 10:16"> イエスは彼らに答えられた。<span className="woj">「私もあなたがたに一つ尋ねよう。それに答えるなら、私も何の権威によってこれらのことをするのか、あなたがたに答えよう。</span></span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの手紙第一 3:20; マルコ 1:1–11; ヨハネ 3:18"> <span className="woj">ヨハネのバプテスマはどこから来たのか。天からか、それとも人からか。」</span><br />彼らは互いに論じ合った。「もし『天から』と言えば、彼は『それなら、なぜヨハネを信じなかったのか』と言うだろう。</span>
<span className="v" id="v26" data-v="26" data-xref="マルコ 6:20; マタイ 14:5; ヨハネ 5:35"> しかし、『人から』と言えば、群衆が怖い。みながヨハネを預言者だと思っているからだ。」</span>
<span className="v" id="v27" data-v="27" data-xref="ローマ人への手紙 1:18–22; テサロニケ人への第二の手紙 2:9–10; ルカ 20:7–8"> そこで彼らはイエスに、「分かりません」と答えた。<br />イエスも彼らに言われた。<span className="woj">「それなら私も、何の権威によってこれらのことをするのか、あなたがたに言わない。</span></span>
<span className="v" id="v28" data-v="28" data-xref="コリント人への第一の手紙 15:58; マタイ 20:1; コリント人への第一の手紙 10:15"> <span className="woj">あなたがたはどう思うか。ある人に二人の息子がいた。彼は兄のところへ行って、『子よ、今日、私のぶどう園へ行って働きなさい』と言った。</span></span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 18:28–32; マタイ 3:2–8; イザヤ書 55:6–7"> <span className="woj">息子は『行きません』と答えたが、後で思い直して出かけた。</span></span>
<span className="v" id="v30" data-v="30" data-xref="テトス 1:16; エゼキエル書 33:31; マタイ 23:3"> <span className="woj">父は弟のところへ行き、同じことを言った。息子は『はい、行きます』と答えたが、行かなかった。</span></span>
<span className="v" id="v31" data-v="31" data-xref="ルカ 7:29; ルカ 7:37–50; マタイ 7:21"> <span className="woj">二人のうち、どちらが父の望みどおりにしたか。」</span><br />彼らはイエスに、「兄です」と答えた。<br />イエスは彼らに言われた。<span className="woj">「まことに、あなたがたに言う。徴税人や娼婦たちのほうが、あなたがたより先に神の御国に入る。</span></span>
<span className="v" id="v32" data-v="32" data-xref="ルカ 7:37–50; ゼカリヤ書 7:11–12; ルカ 7:29–30"> <span className="woj">ヨハネが義の道を示すためにあなたがたのところへ来たのに、あなたがたは彼を信じなかった。しかし、徴税人や娼婦たちは彼を信じた。あなたがたはそれを見ても、後になって悔い改め、彼を信じようとはしなかった。</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 5:1–4; マルコ 12:1–12; ルカ 20:9–19"> <span className="woj">もう一つのたとえを聞きなさい。ある家の主人がいた。彼はぶどう園を造り、その周りに垣根を巡らし、中にぶどうの搾り場を掘り、見張りの塔を建てた。そして、それを農夫たちに貸して、外国へ旅立った。</span></span>
<span className="v" id="v34" data-v="34" data-xref="ルカ 20:10–19; イザヤ書 5:4; ゼカリヤ書 1:3–6"> <span className="woj">収穫の時期が近づくと、ぶどう園の収穫を受け取るために、僕たちを農夫たちのところへ遣わした。</span></span>
<span className="v" id="v35" data-v="35" data-xref="歴代誌 第二 36:15–16; マタイ 5:12; ヘブル人への手紙 11:36–37"> <span className="woj">ところが農夫たちはその僕たちを捕らえ、一人を打ちたたき、一人を殺し、もう一人を石で打ち殺した。</span></span>
<span className="v" id="v36" data-v="36" data-xref="マタイ 22:4"> <span className="woj">主人は再び、最初より多くの僕たちを遣わしたが、農夫たちは彼らにも同じようにした。</span></span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネ 3:16; ヨハネ 3:35–36; ゼパニヤ書 3:7"> <span className="woj">その後、主人は『私の息子なら敬うだろう』と言って、自分の息子を彼らのところへ遣わした。</span></span>
<span className="v" id="v38" data-v="38" data-xref="ルカ 20:14; 創世記 37:18–20; マルコ 12:7–8"> <span className="woj">しかし農夫たちはその息子を見ると、互いに言った。『こいつは跡取りだ。さあ、殺して、その相続財産を奪おう。』</span></span>
<span className="v" id="v39" data-v="39" data-xref="使徒の働き 2:23; ヤコブの手紙 5:6; ルカ 22:52–54"> <span className="woj">そして彼を捕らえ、ぶどう園の外に投げ出して殺した。</span></span>
<span className="v" id="v40" data-v="40" data-xref="ヘブル人への手紙 10:29; マルコ 12:9; ルカ 20:15–16"> <span className="woj">では、ぶどう園の主人が帰って来たら、この農夫たちをどうするだろうか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="使徒の働き 18:6; マタイ 21:43; 使徒の働き 28:28"> 彼らはイエスに答えた。「その悪人どもを容赦なく滅ぼし、季節ごとに収穫を納めるほかの農夫たちに、ぶどう園を貸すでしょう。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v42" data-v="42" data-xref="詩篇 118:22–23; イザヤ書 28:16; 使徒の働き 4:11"> イエスは彼らに言われた。<span className="woj">「あなたがたは聖書で、次のようにあるのを一度も読んだことがないのか。</span><br /><span className="pl pl-1 woj">『家を建てる者たちが退けた石が、</span><br /><span className="pl pl-2 woj">隅のかしら石となった。</span><br /><span className="pl pl-1 woj">これは主によってなされた。</span><br /><span className="pl pl-2 woj">私たちの目には驚くべきことである。』</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="マタイ 21:41; マタイ 8:11–12; ペテロの手紙第一 2:9"> <span className="woj">だから、あなたがたに言う。神の御国はあなたがたから取り上げられ、その実を結ぶ民に与えられる。</span></span>
<span className="v" id="v44" data-v="44" data-xref="イザヤ書 8:14–15; ペテロの手紙第一 2:8; ダニエル書 2:34–35"> <span className="woj">この石の上に落ちる者は粉々に砕かれ、この石がその人の上に落ちれば、彼をちりのように散らす。」</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="ルカ 20:19; ルカ 11:45; マタイ 12:12"> 祭司長たちとパリサイ人たちは、イエスのたとえを聞いて、自分たちのことを話しておられるのだと悟った。</span>
<span className="v" id="v46" data-v="46" data-xref="マタイ 21:11; マタイ 21:26; ルカ 7:16"> そこでイエスを捕らえようとしたが、群衆を恐れた。群衆がイエスを預言者だと思っていたからである。</span>
</div>

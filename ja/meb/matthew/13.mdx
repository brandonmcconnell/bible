<span className="v" id="v3" data-v="3" data-xref="マルコ 4:2–9; マルコ 4:13; 詩篇 78:2"> イエスは、たとえによって多くのことを彼らに語られた。<span className="woj">「見よ、種を蒔く人が種蒔きに出かけた。</span></span>
<span className="v" id="v4" data-v="4" data-xref="マタイ 13:18–19"> <span className="woj">蒔いていると、ある種は道端に落ち、鳥が来て食べてしまった。</span></span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 11:19; エゼキエル書 36:26; ゼカリヤ書 7:12"> <span className="woj">ほかの種は、土の少ない岩地に落ちた。土が深くなかったので、すぐに芽を出した。</span></span>
<span className="v" id="v6" data-v="6" data-xref="マタイ 13:21; ヤコブの手紙 1:11–12; コロサイ人への手紙 1:23"> <span className="woj">しかし、日が昇ると焼け、根がなかったので枯れてしまった。</span></span>
<span className="v" id="v7" data-v="7" data-xref="マルコ 4:18–19; エレミヤ書 4:3–4; 創世記 3:18"> <span className="woj">ほかの種は茨の中に落ちた。茨が伸びて、それをふさいだ。</span></span>
<span className="v" id="v8" data-v="8" data-xref="マタイ 13:23; ルカ 8:15; 創世記 26:12"> <span className="woj">ほかの種は良い地に落ち、実を結んだ。あるものは百倍、あるものは六十倍、あるものは三十倍になった。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 2:11; マタイ 11:15; ヨハネの黙示録 2:7"> <span className="woj">聞く耳のある者は聞きなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="マルコ 4:33–34; マルコ 4:10"> 弟子たちは近寄って、イエスに尋ねた。「なぜ、たとえで彼らに話されるのですか。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 2:9–10; コリント人への第一の手紙 2:14; マタイ 19:11"> イエスは彼らに答えられた。<span className="woj">「あなたがたには天の御国の奥義を知ることが与えられているが、彼らには与えられていない。</span></span>
<span className="v" id="v12" data-v="12" data-xref="マタイ 25:29; マルコ 4:24–25; ルカ 8:18"> <span className="woj">持っている者にはさらに与えられ、豊かになる。しかし、持っていない者は、持っているものまで取り上げられるからである。</span></span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 12:2; エレミヤ書 5:21; イザヤ書 42:18–20"> <span className="woj">だから、私はたとえで彼らに話す。彼らは見ても見ず、聞いても聞かず、理解もしないからである。</span></span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 6:9–10; エゼキエル書 12:2; コリント人への第二の手紙 3:14"> <span className="woj">彼らにおいて、次のように語るイザヤの預言が成就している。</span><br /><span className="pl pl-1 woj">『あなたがたは聞くには聞くが、</span><br /><span className="pl pl-2 woj">決して理解しない。</span><br /><span className="pl pl-1 woj">見るには見るが、</span><br /><span className="pl pl-2 woj">決して悟らない。</span></span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 6:10; マルコ 4:12; ゼカリヤ書 7:11"> <span className="pl pl-1 woj">この民の心は鈍くなり、</span><br /><span className="pl pl-2 woj">耳は聞こえにくくなり、</span><br /><span className="pl pl-2 woj">目を閉じてしまったからである。</span><br /><span className="pl pl-1 woj">そうでなければ、彼らは目で見、</span><br /><span className="pl pl-2 woj">耳で聞き、</span><br /><span className="pl pl-2 woj">心で理解し、</span><br /><span className="pl pl-1 woj">立ち返って、</span><br /><span className="pl pl-2 woj">私が彼らを癒すだろう。』</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ルカ 10:23–24; エペソ人への手紙 1:17–18; マタイ 16:17"> <span className="woj">しかし、あなたがたの目は見ているので幸いであり、あなたがたの耳は聞いているので幸いである。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネ 8:56; ヘブル人への手紙 11:13; ペテロの手紙第一 1:10–12"> <span className="woj">まことに、あなたがたに言う。多くの預言者や義人が、あなたがたの見ているものを見たいと願ったが、見られず、あなたがたの聞いているものを聞きたいと願ったが、聞けなかった。</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="マタイ 13:11–12; ルカ 8:11–15; マルコ 4:13–20"> <span className="woj">だから、種を蒔く人のたとえを聞きなさい。</span></span>
<span className="v" id="v19" data-v="19" data-xref="ルカ 8:11–15; マタイ 13:38; ヘブル人への手紙 2:1"> <span className="woj">だれでも御国の言葉を聞いて理解しないと、悪い者が来て、その人の心に蒔かれたものを奪い取る。これが道端に蒔かれたものである。</span></span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 33:31–32; 詩篇 106:12–13; ヨハネ 5:35"> <span className="woj">岩地に蒔かれたものとは、御言葉を聞くと、すぐに喜んで受け入れる人のことである。</span></span>
<span className="v" id="v21" data-v="21" data-xref="マタイ 11:6; ペテロの第二の手紙 1:8–9; エペソ人への手紙 3:17"> <span className="woj">しかし、自分の内に根がなく、しばらく続くだけである。御言葉のために苦難や迫害が起こると、すぐにつまずく。</span></span>
<span className="v" id="v22" data-v="22" data-xref="テモテへの手紙第一 6:17; ルカ 8:14; テモテへの手紙第一 6:9–10"> <span className="woj">茨の中に蒔かれたものとは、御言葉を聞くが、この時代の思い煩いや富の惑わしが御言葉をふさぎ、実を結ばなくなる人のことである。</span></span>
<span className="v" id="v23" data-v="23" data-xref="ピリピ人への手紙 1:11; マタイ 12:33; ヨハネ 15:16"> <span className="woj">良い地に蒔かれたものとは、御言葉を聞いて理解する人のことである。その人は必ず実を結び、ある人は百倍、ある人は六十倍、ある人は三十倍を生み出す。」</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="マタイ 25:1; マタイ 13:47; マタイ 20:1"> イエスは別のたとえを彼らに示して言われた。<span className="woj">「天の御国は、自分の畑に良い種を蒔いた人のようである。</span></span>
<span className="v" id="v25" data-v="25" data-xref="ペテロの手紙第一 5:8; ペテロの第二の手紙 2:1; 使徒の働き 20:30–31"> <span className="woj">人々が眠っている間に、敵が来て麦の中に毒麦を</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="毒麦は、成熟するまでは小麦によく似ているイネ科の雑草である（おそらくノゲナガドクムギ、またはドクムギ）。成熟すると違いがはっきり現れる。">a</a></sup><span className="woj">蒔き、去って行った。</span></span>
<span className="v" id="v26" data-v="26" data-xref="マルコ 4:26–29"> <span className="woj">やがて芽が出て穂が実ると、毒麦も現れた。</span></span>
<span className="v" id="v27" data-v="27" data-xref="ローマ人への手紙 16:17; コリント人への第二の手紙 6:1; コリント人への第二の手紙 5:18–20"> <span className="woj">家の主人の僕たちが来て言った。『ご主人様、畑には良い種を蒔かれたのではありませんか。それなのに、毒麦はどこから来たのでしょう。』</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="コリント人への第一の手紙 5:3–7; テサロニケ人への手紙第一 5:14; ルカ 9:49–54"> <span className="woj">主人は彼らに言った。『敵の仕業だ。』</span><br /><span className="woj">僕たちは尋ねた。『では、行って毒麦を抜き集めましょうか。』</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> <span className="woj">しかし、主人は言った。『いや、毒麦を抜き集めるとき、小麦まで一緒に引き抜くかもしれない。</span></span>
<span className="v" id="v30" data-v="30" data-xref="マタイ 3:12; テモテへの手紙第一 5:24; コリント人への第一の手紙 4:5"> <span className="woj">収穫まで両方とも一緒に育たせておきなさい。収穫の時になったら、刈り取る者たちにこう言おう。「まず毒麦を抜き集め、焼くために束にしなさい。しかし、小麦は私の倉に集めなさい。」』」</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ルカ 13:18–19; マタイ 17:20; マルコ 4:30–32"> イエスは別のたとえを彼らに示して言われた。<span className="woj">「天の御国は、人が取って自分の畑に蒔いた一粒のからし種のようである。</span></span>
<span className="v" id="v32" data-v="32" data-xref="エゼキエル書 31:6; ダニエル書 4:12; エゼキエル書 17:23–24"> <span className="woj">それは確かに、どの種よりも小さい。しかし、育つと野菜よりも大きくなり、木となるので、空の鳥が来て、その枝に巣を作る。」</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="ガラテヤ人への手紙 5:9; コリント人への第一の手紙 5:6–7; ルカ 13:21"> イエスはもう一つのたとえを彼らに語られた。<span className="woj">「天の御国は、女がパン種を取って、三サタ</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="文字どおりには「三サタ」。三サタは約39リットル、または一ブッシェルより少し多い量である。">b</a></sup><span className="woj">の小麦粉に混ぜ、全体が発酵するまで置いたようなものである。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="マルコ 4:33–34; ヨハネ 16:25; マタイ 13:13"> イエスはこれらのことをすべて、たとえで群衆に語られた。たとえを使わずに語ることはなかった。</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 78:2; エペソ人への手紙 3:9; ペテロの手紙第一 1:20–21"> これは、預言者を通して語られたことが成就するためであった。<br /><span className="pl pl-1">「私はたとえをもって口を開き、</span><br /><span className="pl pl-2">世界の基が据えられた時から隠されていたことを語ろう。」</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="ヨハネ 16:17–20; マタイ 13:11; マタイ 9:28"> それからイエスは群衆を帰らせ、家に入られた。弟子たちはイエスのもとに来て言った。「畑の毒麦のたとえを、私たちに説明してください。」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="コリント人への第一の手紙 3:5–7; マタイ 13:41; ルカ 10:16"> イエスは彼らに答えられた。<span className="woj">「良い種を蒔く者は人の子である。</span></span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネ 8:44; ピリピ人への手紙 3:18–19; 使徒の働き 13:10"> <span className="woj">畑は世界であり、良い種は御国の子ら、毒麦は悪い者の子らである。</span></span>
<span className="v" id="v39" data-v="39" data-xref="マタイ 13:49; ヨハネの黙示録 14:15–19; マタイ 25:31"> <span className="woj">毒麦を蒔いた敵は悪魔である。収穫はこの時代の終わりであり、刈り取る者たちは御使いたちである。</span></span>
<span className="v" id="v40" data-v="40" data-xref="マタイ 13:39"> <span className="woj">だから、毒麦が抜き集められて火で焼かれるように、この時代の終わりにも同じことが起こる。</span></span>
<span className="v" id="v41" data-v="41" data-xref="マタイ 24:31; マタイ 18:7; ペテロの第二の手紙 2:1–2"> <span className="woj">人の子は御使いたちを遣わし、つまずきのもととなるすべてのものと、不法を行う者たちを、その御国から集め出す。</span></span>
<span className="v" id="v42" data-v="42" data-xref="マタイ 13:50; ルカ 16:23–24; マタイ 8:12"> <span className="woj">そして彼らを火の燃える炉に投げ込む。そこで人々は泣き叫び、歯ぎしりする。</span></span>
<span className="v" id="v43" data-v="43" data-xref="ダニエル書 12:3; マタイ 11:15; ルカ 12:32"> <span className="woj">その時、義人たちは父の御国で太陽のように輝く。聞く耳のある者は聞きなさい。</span></span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="箴言 2:2–5; コロサイ人への手紙 2:3; ピリピ人への手紙 3:7–9"> <span className="woj">また、天の御国は畑に隠された宝のようである。人がそれを見つけて隠しておき、喜びのあまり出かけて行って、持っているものをすべて売り、その畑を買う。</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="箴言 3:13–18; マタイ 16:26; マタイ 13:24"> <span className="woj">また、天の御国は良い真珠を捜している商人のようである。</span></span>
<span className="v" id="v46" data-v="46" data-xref="エペソ人への手紙 3:8; ルカ 18:28–30; 箴言 2:4"> <span className="woj">その人は非常に高価な真珠を一つ見つけると、出かけて行って、持っているものをすべて売り、それを買った。</span></span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="ヨハネ 15:6; テモテへの第二の手紙 3:2–5; マタイ 22:9–10"> <span className="woj">また、天の御国は海に投げ入れられ、あらゆる種類の魚を集める引き網のようである。</span></span>
<span className="v" id="v48" data-v="48" data-xref="マタイ 13:30; マタイ 13:40–43; マタイ 3:12"> <span className="woj">網がいっぱいになると、漁師たちは岸に引き上げて座り、良いものは入れ物に集め、悪いものは捨てた。</span></span>
<span className="v" id="v49" data-v="49" data-xref="ヨハネの黙示録 20:12–15; マタイ 24:31; マタイ 13:39"> <span className="woj">この世の終わりにも同じようになる。</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="または「この時代の終わり」。">c</a></sup><span className="woj">御使いたちが来て、義人たちの中から悪人たちを分け、</span></span>
<span className="v" id="v50" data-v="50" data-xref="マタイ 13:42; マタイ 8:12; ヨハネの黙示録 14:10–11"> <span className="woj">火の燃える炉に投げ込む。そこで人々は泣き叫び、歯ぎしりする。」</span></span>
<span className="v" id="v51" data-v="51" data-xref="マタイ 13:19; マタイ 13:11; マルコ 4:34"> イエスは彼らに言われた。<span className="woj">「これらのことをすべて理解したか。」</span><br />彼らは答えた。「はい、主よ。」</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="ヨハネの手紙第一 2:7–8; テモテへの第二の手紙 3:16–17; テトス 1:9"> イエスは彼らに言われた。<span className="woj">「だから、天の御国の弟子となった律法学者はみな、自分の倉から新しいものと古いものを取り出す家の主人のようである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="マタイ 7:28; マルコ 4:33–35"> イエスはこれらのたとえを語り終えると、そこを立ち去られた。</span>
<span className="v" id="v54" data-v="54" data-xref="マタイ 7:28; ヨハネ 7:15–16; マルコ 6:1–6"> そして、ご自分の郷里に来て、会堂で人々を教えられた。人々は驚いて言った。「この人は、どこからこの知恵と力あるわざを得たのだろう。</span>
<span className="v" id="v55" data-v="55" data-xref="ヨハネ 6:42; マルコ 6:3; ルカ 3:23"> この人は大工の息子ではないか。母はマリアと呼ばれ、兄弟たちはヤコブ、ヨセ、シモン、ユダではないか。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="または「ユダ」。">d</a></sup></span>
<span className="v" id="v56" data-v="56"> 姉妹たちもみな、われわれと一緒にいるではないか。それなのに、この人はどこからこれらすべてを得たのだろう。」</span>
<span className="v" id="v57" data-v="57" data-xref="ヨハネ 4:44; マタイ 11:6; ルカ 4:24"> こうして、彼らはイエスにつまずいた。<br />しかし、イエスは彼らに言われた。<span className="woj">「預言者が敬われないのは、自分の郷里と自分の家のほかにはない。」</span></span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネ 10:40; マタイ 19:1–9; マタイ 7:28"> イエスはこれらの言葉を語り終えると、ガリラヤを去り、ヨルダン川の向こう側にあるユダヤ地方に来られた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 12:15; マルコ 6:55–56; マタイ 15:30–31"> 大勢の群衆がイエスに従い、イエスはそこで彼らを癒された。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="マルコ 10:2; ヘブル人への手紙 3:9; マタイ 16:1"> パリサイ人たちがイエスのもとに来て、試そうとして尋ねた。「どんな理由であっても、男が妻を離縁することは律法にかなっていますか。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="創世記 2:23; 創世記 1:27; 創世記 5:2"> イエスは彼らに答えられた。<span className="woj">「あなたがたは読んだことがないのか。初めに人を造られた方は、彼らを男と女に造り、</span></span>
<span className="v" id="v5" data-v="5" data-xref="創世記 2:21–24; コリント人への第一の手紙 7:4; コリント人への第一の手紙 7:2"> <span className="woj">『それゆえ、男は父と母を離れ、妻と結ばれ、二人は一つの肉体となる』と言われた。</span></span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 13:4; マルコ 10:9; コリント人への第一の手紙 7:10–14"> <span className="woj">こうして、二人はもはや別々ではなく、一つの肉体である。だから、神が結び合わせたものを、人が引き離してはならない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命記 24:1–4; マタイ 5:31; マルコ 10:4"> 彼らはイエスに尋ねた。「それでは、なぜモーセは、離縁状を渡して妻を離縁するよう命じたのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="マラキ書 2:13–14; 創世記 2:24; マルコ 10:5"> イエスは彼らに言われた。<span className="woj">「モーセがあなたがたに妻を離縁することを許したのは、あなたがたの心がかたくなだったからである。しかし、初めからそうだったのではない。</span></span>
<span className="v" id="v9" data-v="9" data-xref="マタイ 5:32; ルカ 16:18; コリント人への第一の手紙 7:39"> <span className="woj">あなたがたに言う。性的不品行以外の理由で妻を離縁して別の女と結婚する者は、姦淫を犯す。また、離縁された女と結婚する者も姦淫を犯す。」</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 7:32–35; 箴言 19:13–14; 箴言 21:19"> 弟子たちはイエスに言った。「夫と妻の関係がそのようなものなら、結婚しないほうがよいことになります。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 7:17; コリント人への第一の手紙 7:35; コリント人への第一の手紙 7:7–9"> しかし、イエスは彼らに言われた。<span className="woj">「すべての人がこの言葉を受け入れられるわけではなく、それを与えられた人だけが受け入れられる。</span></span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 7:32–38; コリント人への第一の手紙 9:5; イザヤ書 56:3–4"> <span className="woj">母の胎内からそのように生まれた宦官もいれば、人によって宦官にされた者もいる。また、天の御国のために自ら宦官となった者もいる。受け入れることのできる者は、受け入れなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マルコ 10:13–16; ルカ 18:15–17; マタイ 18:2–5"> それから、イエスに手を置いて祈っていただこうと、人々が幼い子どもたちを連れて来た。しかし、弟子たちは彼らを叱った。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイ 18:3; ルカ 18:16–17; コリント人への第一の手紙 14:20"> するとイエスは言われた。<span className="woj">「幼い子どもたちをそのまま来させなさい。私のところに来るのを妨げてはならない。天の御国は、このような者たちのものだからである。」</span></span>
<span className="v" id="v15" data-v="15" data-xref="マルコ 10:16; テモテへの第二の手紙 3:15; コリント人への第一の手紙 7:14"> そして彼らに手を置いてから、そこを去られた。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="マルコ 10:17–30; ヨハネ 3:15; ユダ 1:21"> 見よ、一人の人がイエスのもとに来て尋ねた。「良い先生、永遠のいのちを得るためには、どんな良いことをすればよいのでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="レビ記 18:5; ルカ 10:26–28; ガラテヤ人への手紙 3:11–13"> イエスは彼に言われた。<span className="woj">「なぜ私を良いと呼ぶのか。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="MT本文とTR本文ではこのようになっている。NU本文では「なぜ良いことについて私に尋ねるのか」となっている。">a</a></sup><span className="woj">良い方はただ一人、神だけである。しかし、いのちに入りたいなら、戒めを守りなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命記 5:16–21; 出エジプト記 20:12–17; マルコ 10:19"> 彼はイエスに尋ねた。「どの戒めですか。」<br />イエスは言われた。<span className="woj">「『殺してはならない』『姦淫してはならない』『盗んではならない』『偽りの証言をしてはならない』、</span></span>
<span className="v" id="v19" data-v="19" data-xref="レビ記 19:18; 出エジプト記 20:12; マタイ 22:39"> <span className="woj">『父と母を敬いなさい』。</span><span className="woj">また、『隣人を自分自身のように愛しなさい』である。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ガラテヤ人への手紙 3:24; マルコ 10:20–21; ピリピ人への手紙 3:6"> 青年はイエスに言った。「私はこれらすべてを幼いころから守ってきました。まだ何が欠けているのでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="マルコ 10:21; ルカ 18:22; ルカ 12:33"> イエスは彼に言われた。<span className="woj">「完全な者になりたいなら、行って、持っているものを売り、貧しい人々に与えなさい。そうすれば、天に宝を持つことになる。それから来て、私に従いなさい。」</span></span>
<span className="v" id="v22" data-v="22" data-xref="マタイ 6:24; エゼキエル書 33:31; マタイ 13:22"> しかし、青年はこの言葉を聞くと、悲しみながら立ち去った。多くの財産を持っていたからである。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="テモテへの手紙第一 6:9–10; マタイ 13:22; マルコ 10:23"> イエスは弟子たちに言われた。<span className="woj">「まことに、あなたがたに言う。富む者が天の御国に入るのは難しい。</span></span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネ 5:44; ルカ 18:25; マルコ 10:24–25"> <span className="woj">もう一度、あなたがたに言う。富む者が神の御国に入るより、らくだが針の穴を通るほうが易しい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 10:13; マタイ 24:22; ローマ人への手紙 11:5–7"> 弟子たちはこれを聞くと、非常に驚いて言った。「それでは、いったいだれが救われるのでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 32:27; ルカ 1:37; ヨブ記 42:2"> イエスは彼らを見つめて言われた。<span className="woj">「人には不可能だが、神にはすべてのことが可能である。」</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ピリピ人への手紙 3:8; ルカ 18:28; ルカ 5:11"> するとペテロが答えた。「見よ、私たちはすべてを捨てて、あなたに従って来ました。それでは、私たちは何をいただけるのでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ルカ 22:28–30; コリント人への第一の手紙 6:2–3; マタイ 25:31"> イエスは彼らに言われた。<span className="woj">「まことに、あなたがたに言う。世が新しくされ、人の子が栄光の座に着くとき、私に従って来たあなたがたも十二の座に着き、イスラエルの十二部族を裁く。</span></span>
<span className="v" id="v29" data-v="29" data-xref="ルカ 18:29–30; マルコ 10:29–30; ピリピ人への手紙 3:8"> <span className="woj">私の名のために、家、兄弟、姉妹、父、母、妻、子ども、または土地を離れた者はみな、その百倍を受け、永遠のいのちを受け継ぐ。</span></span>
<span className="v" id="v30" data-v="30" data-xref="マタイ 20:16; ルカ 13:30; マルコ 10:31"> <span className="woj">しかし、先にいる多くの者が後になり、後にいる者が先になる。</span></span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 23:5; ヨハネ 12:43; ヘブル人への手紙 6:10"> <span className="woj">人に見てもらうために、人前で施しをしないように気をつけなさい。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NU本文では「施し」の代わりに「義の行い」となっている。">a</a></sup><span className="woj">そうでなければ、天におられるあなたがたの父から報いを受けることはない。</span></span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 6:5; マタイ 6:16; コリント人への第二の手紙 9:6–15"> <span className="woj">だから、施しをするとき、偽善者たちが人々から称賛を受けようとして、会堂や通りでするように、自分の前でラッパを吹き鳴らしてはならない。まことに、あなたがたに言う。彼らはすでに自分の報いを受けている。</span></span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネ 7:4; マタイ 9:30; マルコ 1:44"> <span className="woj">しかし、あなたが施しをするときは、右の手がしていることを左の手に知らせてはならない。</span></span>
<span className="v" id="v4" data-v="4" data-xref="マタイ 6:18; マタイ 6:6; エレミヤ書 17:10"> <span className="woj">あなたの施しが隠れたところでなされるためである。そうすれば、隠れたところで見ておられるあなたの父が、公に報いてくださる。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="ルカ 18:10–11; マタイ 6:2; ルカ 18:13"> <span className="woj">また、祈るとき、偽善者たちのようであってはならない。彼らは人々に見てもらおうとして、会堂や通りの角に立って祈ることを好む。まことに、あなたがたに言う。彼らはすでに自分の報いを受けている。</span></span>
<span className="v" id="v6" data-v="6" data-xref="列王記第二 4:33; マタイ 14:23; イザヤ書 65:24"> <span className="woj">しかし、あなたが祈るときは、自分の奥の部屋に入り、戸を閉めて、隠れたところにおられるあなたの父に祈りなさい。そうすれば、隠れたところで見ておられるあなたの父が、公に報いてくださる。</span></span>
<span className="v" id="v7" data-v="7" data-xref="伝道者の書 5:2–3; 伝道者の書 5:7; 列王記第一 18:26–29"> <span className="woj">祈るとき、異邦人のように、むなしい言葉を繰り返してはならない。彼らは、言葉数が多ければ聞き入れられると思っている。</span></span>
<span className="v" id="v8" data-v="8" data-xref="マタイ 6:32; ルカ 12:30; ピリピ人への手紙 4:6"> <span className="woj">だから、彼らのようになってはならない。あなたがたの父は、あなたがたが求める前から、必要なものを知っておられるからである。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ルカ 11:1–4; ヨハネの黙示録 4:11; ローマ人への手紙 8:15"> <span className="woj">だから、このように祈りなさい。</span><br /><span className="pl pl-1 woj">『天におられる私たちの父よ、御名が聖なるものとされますように。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 10:36; マタイ 26:42; マタイ 12:50"> <span className="pl pl-1 woj">あなたの御国が来ますように。</span><br /><span className="pl pl-2 woj">あなたの御心が、天で行われているように、地でも行われますように。</span></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 30:8; ルカ 11:3; マタイ 4:4"> <span className="pl pl-1 woj">私たちの日ごとのパンを、今日もお与えください。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 4:32; マルコ 11:25; エペソ人への手紙 1:7"> <span className="pl pl-1 woj">私たちの負い目をお赦しください。</span><br /><span className="pl pl-2 woj">私たちも、私たちに負い目のある者を赦すのと同じように。</span></span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 10:13; ヨハネの黙示録 7:14–17; マタイ 26:41"> <span className="pl pl-1 woj">私たちを誘惑に陥らせず、</span><br /><span className="pl pl-2 woj">悪い者からお救いください。</span><br /><span className="pl pl-1 woj">御国と力と栄光は、永遠にあなたのものだからです。アーメン。』</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NU本文では「御国と力と栄光は、永遠にあなたのものだからです。アーメン」が省かれている。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="エペソ人への手紙 4:32; マルコ 11:25; コロサイ人への手紙 3:13"> <span className="woj">人々の過ちを赦すなら、天におられるあなたがたの父も、あなたがたを赦してくださる。</span></span>
<span className="v" id="v15" data-v="15" data-xref="マタイ 18:35"> <span className="woj">しかし、人々の過ちを赦さないなら、あなたがたの父も、あなたがたの過ちを赦してくださらない。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 58:3–5; マタイ 9:14–15; ダニエル書 9:3"> <span className="woj">また、断食するとき、偽善者たちのように暗い顔をしてはならない。彼らは断食していることを人々に見せようとして、顔をやつれさせる。まことに、あなたがたに言う。彼らはすでに自分の報いを受けている。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ルツ記 3:3; 伝道者の書 9:8; サムエル記第二 12:20"> <span className="woj">しかし、あなたが断食するときは、頭に油を塗り、顔を洗いなさい。</span></span>
<span className="v" id="v18" data-v="18" data-xref="マタイ 6:6; マタイ 6:4; コリント人への第二の手紙 10:18"> <span className="woj">それは、断食していることが人には見えず、隠れたところにおられるあなたの父にだけ見えるためである。そうすれば、隠れたところで見ておられるあなたの父が、あなたに報いてくださる。</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヘブル人への手紙 13:5; ヨハネの手紙第一 2:15–16; ルカ 12:21"> <span className="woj">自分のために地上に宝を蓄えてはならない。そこでは、蛾やさびが食い尽くし、盗人が押し入って盗む。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ルカ 12:33; マタイ 19:21; ヤコブの手紙 2:5"> <span className="woj">むしろ、自分のために天に宝を蓄えなさい。そこでは、蛾もさびも食い尽くさず、盗人も押し入って盗まない。</span></span>
<span className="v" id="v21" data-v="21" data-xref="コロサイ人への手紙 3:1–3; ルカ 12:34; コリント人への第二の手紙 4:18"> <span className="woj">あなたの宝があるところに、あなたの心もあるからである。</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ルカ 11:34–36; コリント人への第二の手紙 11:3; コロサイ人への手紙 3:22"> <span className="woj">体のランプは目である。だから、目が健全なら、全身が明るい。</span></span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの手紙第一 2:11; マタイ 6:22; イザヤ書 5:20–21"> <span className="woj">しかし、目が悪ければ、全身が暗い。もし、あなたの内にある光が闇なら、その闇はどれほど深いことか。</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヨハネの手紙第一 2:15–16; ルカ 16:13; ヤコブの手紙 4:4"> <span className="woj">だれも二人の主人に仕えることはできない。一方を憎んで他方を愛するか、一方を重んじて他方を軽んじることになるからである。神とマモンの両方に仕えることはできない。</span></span>
<span className="v" id="v25" data-v="25" data-xref="ピリピ人への手紙 4:6; ペテロの手紙第一 5:7; ローマ人への手紙 8:32"> <span className="woj">だから、あなたがたに言う。何を食べ、何を飲もうかと、自分のいのちのことで思い悩んではならない。また、何を着ようかと、自分の体のことで思い悩んではならない。いのちは食べ物よりも、体は衣服よりも大切ではないか。</span></span>
<span className="v" id="v26" data-v="26" data-xref="マタイ 10:29–31; 詩篇 147:9; ルカ 12:24–32"> <span className="woj">空の鳥を見なさい。種を蒔くことも、刈り取ることも、倉に集めることもしない。それでも、天におられるあなたがたの父は鳥を養っておられる。あなたがたは鳥よりも、はるかに価値があるではないか。</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ルカ 12:25–26; 伝道者の書 3:14; 詩篇 39:5–6"> <span className="woj">あなたがたのうち、思い悩んだからといって、寿命をわずかでも</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="文字どおりには「一キュビト」。">c</a></sup><span className="woj">延ばせる者がいるだろうか。</span></span>
<span className="v" id="v28" data-v="28" data-xref="マタイ 6:25; ピリピ人への手紙 4:6; ルカ 12:27"> <span className="woj">なぜ衣服のことで思い悩むのか。野のゆりがどのように育つか、よく考えなさい。働くことも、糸を紡ぐこともしない。</span></span>
<span className="v" id="v29" data-v="29" data-xref="歴代誌 第二 9:20–22; 歴代誌 第二 9:4–6; ペテロの手紙第一 3:2–5"> <span className="woj">しかし、あなたがたに言う。栄華を極めたソロモンでさえ、この花の一つほどにも着飾ってはいなかった。</span></span>
<span className="v" id="v30" data-v="30" data-xref="マタイ 14:31; ルカ 12:28; ペテロの手紙第一 1:24"> <span className="woj">今日生えていて、明日は炉に投げ込まれる野の草でさえ、神がこのように装ってくださるのなら、信仰の薄い者たちよ、あなたがたには、なおさら着せてくださるではないか。</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ペテロの手紙第一 5:7; ルカ 12:29; マタイ 4:4"> <span className="woj">だから、『何を食べようか』『何を飲もうか』『何を着ようか』と言って、思い悩んではならない。</span></span>
<span className="v" id="v32" data-v="32" data-xref="マタイ 6:8; ルカ 12:30; エペソ人への手紙 4:17"> <span className="woj">これらはすべて、異邦人が追い求めているものだからである。天におられるあなたがたの父は、これらすべてがあなたがたに必要であることを知っておられる。</span></span>
<span className="v" id="v33" data-v="33" data-xref="ルカ 12:31; マタイ 5:6; ヨハネ 6:27"> <span className="woj">まず神の御国と神の義を求めなさい。そうすれば、これらすべてのものも与えられる。</span></span>
<span className="v" id="v34" data-v="34" data-xref="マタイ 6:25; ヨハネ 14:27; ヘブル人への手紙 13:5–6"> <span className="woj">だから、明日のことで思い悩んではならない。明日のことは明日が思い悩む。その日の苦労は、その日だけで十分である。</span></span>
</div>

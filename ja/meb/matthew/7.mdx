<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカ 6:37; ローマ人への手紙 2:1–2; ヤコブの手紙 4:11–12"> <span className="woj">裁いてはならない。あなたがたが裁かれないためである。</span></span>
<span className="v" id="v2" data-v="2" data-xref="ヤコブの手紙 2:13; マルコ 4:24; ルカ 6:38"> <span className="woj">あなたがたが裁くその裁きで、あなたがたも裁かれ、あなたがたが量るその尺度で、あなたがたも量り返されるからである。</span></span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネ 8:7–9; ガラテヤ人への手紙 6:1; ルカ 6:41–42"> <span className="woj">なぜ、兄弟の目にあるちりは見えるのに、自分の目にある梁には気づかないのか。</span></span>
<span className="v" id="v4" data-v="4"> <span className="woj">見よ、自分の目には梁があるのに、どうして兄弟に、『あなたの目からちりを取ってあげよう』と言えるのか。</span></span>
<span className="v" id="v5" data-v="5" data-xref="ルカ 6:42; 詩篇 51:9–13; マタイ 23:13–28"> <span className="woj">偽善者よ。まず自分の目から梁を取り除きなさい。そうすれば、兄弟の目からちりを取り除くために、はっきり見えるようになる。</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="箴言 9:7–8; 箴言 23:9; マタイ 10:14–15"> <span className="woj">聖なるものを犬に与えてはならない。また、真珠を豚の前に投げてはならない。豚がそれを足で踏みつけ、向き直ってあなたがたを引き裂くかもしれない。</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マタイ 21:22; ヨハネの手紙第一 3:22; ヨハネ 15:7"> <span className="woj">求めなさい。そうすれば与えられる。捜しなさい。そうすれば見つかる。たたきなさい。そうすれば開かれる。</span></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 81:10; 詩篇 81:16; ルカ 23:42–43"> <span className="woj">だれでも求める者は受け、捜す者は見つけ、たたく者には開かれるからである。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ルカ 11:11–13"> <span className="woj">あなたがたのうち、自分の子がパンを求めているのに、石を与える者がいるだろうか。</span></span>
<span className="v" id="v10" data-v="10"> <span className="woj">また、魚を求めているのに、蛇を与える者がいるだろうか。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ルカ 11:11–13; ヤコブの手紙 1:17; ローマ人への手紙 8:32"> <span className="woj">このように、悪い者であっても、あなたがたは自分の子どもに良い贈り物を与えることを知っている。それなら、天におられるあなたがたの父は、ご自分に求める者たちに、なおさら良いものを与えてくださらないだろうか。</span></span>
<span className="v" id="v12" data-v="12" data-xref="ルカ 6:31; ローマ人への手紙 13:8–10; ガラテヤ人への手紙 5:13–14"> <span className="woj">だから、人々にしてもらいたいことは何でも、あなたがたも同じように人々にしなさい。これこそ律法と預言者だからである。</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカ 13:24–25; 箴言 16:25; ヨハネ 14:6"> <span className="woj">狭い門から入りなさい。滅びに至る門は広く、その道は広々としていて、その門から入る者は多い。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ルカ 13:23–30; マタイ 22:14; マタイ 16:24–25"> <span className="woj">いのちに至る門はなんと</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR本文では「なんと」の代わりに「なぜなら」となっている。">a</a></sup><span className="woj">狭く、その道はなんと細いことか。それを見つける者は少ない。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨハネの手紙第一 4:1; ペテロの第二の手紙 2:1–3; マタイ 24:11"> <span className="woj">偽預言者たちに用心しなさい。彼らは羊の皮をかぶってあなたがたのところに来るが、内側は貪欲な狼である。</span></span>
<span className="v" id="v16" data-v="16" data-xref="ルカ 6:43–45; マタイ 12:33; ヤコブの手紙 3:12"> <span className="woj">あなたがたは、その実によって彼らを見分ける。茨からぶどうを、あざみからいちじくを集めることがあるだろうか。</span></span>
<span className="v" id="v17" data-v="17" data-xref="マタイ 12:33–35; ガラテヤ人への手紙 5:22–24; エペソ人への手紙 5:9"> <span className="woj">このように、良い木はみな良い実を結び、悪い木は悪い実を結ぶ。</span></span>
<span className="v" id="v18" data-v="18" data-xref="ガラテヤ人への手紙 5:17; ヨハネの手紙第一 3:9–10"> <span className="woj">良い木が悪い実を結ぶことはできず、悪い木が良い実を結ぶこともできない。</span></span>
<span className="v" id="v19" data-v="19" data-xref="マタイ 3:10; ヘブル人への手紙 6:8; ヨハネ 15:2–6"> <span className="woj">良い実を結ばない木はすべて切り倒され、火に投げ込まれる。</span></span>
<span className="v" id="v20" data-v="20" data-xref="マタイ 7:16; 使徒の働き 5:38"> <span className="woj">だから、あなたがたは、その実によって彼らを見分ける。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 2:13; ルカ 6:46; ヤコブの手紙 1:22"> <span className="woj">私に向かって、『主よ、主よ』と言う者がみな天の御国に入るのではない。天におられる私の父の御心を行う者が入るのである。</span></span>
<span className="v" id="v22" data-v="22" data-xref="ルカ 13:25–27; コリント人への第一の手紙 13:1–2; マラキ書 3:17–18"> <span className="woj">その日には、多くの者が私に言うだろう。『主よ、主よ、私たちはあなたの名によって預言し、あなたの名によって悪霊を追い出し、あなたの名によって多くの力あるわざを行ったではありませんか。』</span></span>
<span className="v" id="v23" data-v="23" data-xref="マタイ 25:41; 詩篇 6:8; ルカ 13:25"> <span className="woj">そのとき、私は彼らにはっきり告げる。『私はあなたがたを一度も知らなかった。不法を行う者たちよ、私から離れ去れ。』</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ルカ 6:47–49; ヨハネ 13:17; コリント人への第一の手紙 3:10–11"> <span className="woj">だから、私のこれらの言葉を聞いて行う者を、私は岩の上に家を建てた賢い人にたとえよう。</span></span>
<span className="v" id="v25" data-v="25" data-xref="ヤコブの手紙 1:12; 詩篇 125:1–2; ペテロの手紙第一 1:7"> <span className="woj">雨が降り、洪水が押し寄せ、風が吹きつけてその家を打った。しかし、家は倒れなかった。岩の上に土台が据えられていたからである。</span></span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 8:9; ルカ 6:49; ヤコブの手紙 2:20"> <span className="woj">私のこれらの言葉を聞いても行わない者は、砂の上に家を建てた愚かな人のようである。</span></span>
<span className="v" id="v27" data-v="27" data-xref="マタイ 13:19–22; ペテロの第二の手紙 2:20–22; コリント人への第一の手紙 3:13"> <span className="woj">雨が降り、洪水が押し寄せ、風が吹きつけてその家を打った。すると家は倒れ、その倒れ方はひどかった。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ルカ 4:32; マルコ 1:22; ヨハネ 7:46"> イエスがこれらの言葉を語り終えられると、群衆はその教えに驚いた。</span>
<span className="v" id="v29" data-v="29" data-xref="ヘブル人への手紙 4:12–13; ルカ 20:8; 申命記 18:18–19"> イエスが律法学者たちのようにではなく、権威ある者として教えられたからである。</span>
</div>

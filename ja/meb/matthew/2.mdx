<span className="v" id="v1" data-v="1" data-xref="ミカ書 5:2; ヨハネ 7:42; ルカ 2:4–7"> ヘロデ王の時代に、イエスがユダヤのベツレヘムでお生まれになると、見よ、東方から博士たち<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「博士たち」に当たる言葉（マゴイ）は、教師、科学者、医師、占星術師、予見者、夢を解き明かす者、魔術師を意味することもある。">a</a></sup>がエルサレムに来て言った。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 24:17; エレミヤ書 23:5; ヨハネの黙示録 22:16"> 「ユダヤ人の王としてお生まれになった方は、どこにおられますか。私たちは東方でその方の星を見たので、拝むために来ました。」</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 17:6–7; ヨハネ 11:47–48; マタイ 23:37"> ヘロデ王はこれを聞いて動揺し、エルサレム中も王と共に不安に包まれた。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイ 21:23; マタイ 7:29; 使徒の働き 6:12"> 王は民の祭司長たちと律法学者たちを全員集め、キリストがどこで生まれることになっているのかと尋ねた。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネ 7:42; ルツ記 1:1; サムエル記第一 16:1"> 彼らは王に答えた。「ユダヤのベツレヘムです。預言者を通して、こう書かれています。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 34:23–25; ミカ書 5:2; イザヤ書 9:6–7"> <span className="pl pl-1">『ユダの地にあるベツレヘムよ、</span><br /><span className="pl pl-2">あなたはユダの君主たちの中で、決して最も小さいものではない。</span><br /><span className="pl pl-1">あなたから一人の支配者が出て、</span><br /><span className="pl pl-2">わたしの民イスラエルを牧するからである。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 1:10; サムエル記第一 18:21; 詩篇 55:21"> そこでヘロデは博士たちをひそかに呼び寄せ、星が現れた時期を正確に聞き出した。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 3:19–20; エレミヤ書 41:5–7; ルカ 20:20–21"> そして彼らをベツレヘムへ送り出して言った。「行って、幼子を注意深く捜しなさい。見つけたら私に知らせてくれ。私も行って、その方を拝みたい。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="マタイ 2:2; 箴言 8:17; 詩篇 25:12"> 彼らは王の言葉を聞いて出かけた。すると見よ、東方で見た星が彼らの先を進み、幼子のいる場所の上まで来ると、そこで止まった。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 105:3; ルカ 2:20; ルカ 2:10"> 彼らはその星を見て、この上ない喜びにあふれた。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 60:6; 詩篇 72:10; ルカ 2:16"> 家に入ると、母マリアと共にいる幼子を見た。彼らはひれ伏して幼子を拝み、宝の箱を開け、黄金、乳香、没薬を贈り物としてささげた。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイ 2:22; マタイ 2:19; マタイ 2:13"> そして、ヘロデのもとへ戻らないよう夢で警告を受けたので、別の道を通って自分たちの国へ帰った。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 10:7; 使徒の働き 5:19; マタイ 1:20"> 彼らが立ち去ると、見よ、主の使いが夢の中でヨセフに現れて言った。「起きて、幼子とその母を連れ、エジプトへ逃げなさい。そして、私が知らせるまでそこにいなさい。ヘロデが幼子を殺そうとして捜し回るからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マタイ 2:20–21; 使徒の働き 26:21; マタイ 1:24"> そこでヨセフは起き、夜のうちに幼子とその母を連れて、エジプトへ立ち去った。</span>
<span className="v" id="v15" data-v="15" data-xref="ホセア書 11:1; 出エジプト記 4:22; 民数記 24:8"> そして、ヘロデが死ぬまでそこにいた。これは、主が預言者を通して語られたことが成就するためであった。「エジプトから、わたしの子を呼び出した。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 59:7; 箴言 28:15; 士師記 16:10"> その後ヘロデは、自分が博士たちに欺かれたと知ると、激しく怒った。そして人を遣わし、博士たちから正確に聞き出した時期に基づいて、ベツレヘムとその周辺一帯にいた二歳以下の男の子をすべて殺させた。</span>
<span className="v" id="v17" data-v="17"> こうして、預言者エレミヤを通して語られたことが成就した。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 31:15; エレミヤ書 9:17–21; エレミヤ書 4:31"> <span className="pl pl-1">「ラマで声が聞こえた。</span><br /><span className="pl pl-2">嘆きと泣き声、大いなる悲しみ。</span><br /><span className="pl pl-1">ラケルが自分の子どもたちのために泣いている。</span><br /><span className="pl pl-2">子どもたちはもういないので、</span><br /><span className="pl pl-2">彼女は慰めを受けようとしなかった。」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="マタイ 1:20; ダニエル書 8:25; マタイ 2:12–13"> ヘロデが死ぬと、見よ、主の使いがエジプトにいたヨセフの夢に現れて言った。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 4:19; 列王記第一 12:1–3; マタイ 2:13"> 「起きて、幼子とその母を連れ、イスラエルの地へ行きなさい。幼子のいのちを狙っていた者たちは死んだからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ヘブル人への手紙 11:8; 創世記 6:22"> そこでヨセフは起き、幼子とその母を連れて、イスラエルの地へ戻った。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 48:17–18; ルカ 2:39; ヨハネ 7:52"> しかし、アルケラオが父ヘロデに代わってユダヤを治めていると聞き、そこへ行くことを恐れた。そして夢で警告を受け、ガリラヤ地方へ退いた。</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 13:5; ヨハネ 1:45–46; マルコ 1:24"> そこで、ナザレという町に行って住んだ。これは、預言者たちを通して「彼はナザレ人と呼ばれる」と語られたことが成就するためであった。</span>

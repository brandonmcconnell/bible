<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカ 11:16; マタイ 16:6; 使徒の働き 4:1"> パリサイ人たちとサドカイ人たちが来て、イエスを試そうとし、天からのしるしを見せてほしいと求めた。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカ 12:54–56"> しかし、イエスは彼らに答えられた。<span className="woj">「夕方になると、あなたがたは、『空が赤いから、晴れるだろう』と言う。</span></span>
<span className="v" id="v3" data-v="3" data-xref="ルカ 12:56; 歴代誌上 12:32; マタイ 11:5"> <span className="woj">また朝には、『空が赤く、どんよりしているから、今日は荒れ模様だろう』と言う。偽善者たちよ。あなたがたは空模様を見分けることができるのに、時代のしるしを見分けることができない。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ルカ 11:29–30; マタイ 12:39–40; ヨナ書 1:17"> <span className="woj">邪悪で不実な時代はしるしを求めるが、預言者ヨナのしるしのほかには、何のしるしも与えられない。」</span><br />イエスは彼らを残して立ち去られた。</span>
<span className="v" id="v5" data-v="5" data-xref="マルコ 8:13–14; マタイ 15:39"> 弟子たちは向こう岸に着いたが、パンを持って来るのを忘れていた。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカ 12:1; ガラテヤ人への手紙 5:9; マタイ 16:12"> イエスは彼らに言われた。<span className="woj">「パリサイ人とサドカイ人のパン種に注意し、用心しなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マルコ 8:16–18; マタイ 15:16–18; 使徒の働き 10:14"> 弟子たちは、「私たちはパンを持って来なかった」と互いに論じ合った。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="マタイ 6:30; マタイ 14:31; マタイ 8:26"> イエスはそれに気づいて言われた。<span className="woj">「信仰の薄い者たちよ。なぜ、パンを持って来なかったことを論じ合っているのか。</span></span>
<span className="v" id="v9" data-v="9" data-xref="マタイ 14:17–21; ヨハネ 6:9–13; ルカ 9:13–17"> <span className="woj">まだ分からないのか。五千人に五つのパンを分けたとき、幾つのかごいっぱいに拾い集めたか、覚えていないのか。</span></span>
<span className="v" id="v10" data-v="10" data-xref="マタイ 15:34–38; マルコ 8:17–21; マルコ 8:5–9"> <span className="woj">また、四千人に七つのパンを分けたとき、幾つのかごいっぱいに拾い集めたか、覚えていないのか。</span></span>
<span className="v" id="v11" data-v="11" data-xref="マタイ 16:6; ルカ 12:56; マルコ 8:21"> <span className="woj">私がパンについて話したのではないことが、どうして分からないのか。パリサイ人とサドカイ人のパン種に用心しなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マタイ 5:20; 使徒の働き 23:8; マタイ 15:4–9"> そのとき弟子たちは、イエスが用心するように言われたのはパンに入れるパン種のことではなく、パリサイ人とサドカイ人の教えのことだと理解した。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカ 9:18–20; マルコ 8:27–29; ダニエル書 7:13"> さて、イエスはカイサリア・ピリポ地方に来られたとき、弟子たちに尋ねられた。<span className="woj">「人々は、人の子である私をだれだと言っているか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マルコ 6:15; マタイ 14:2; マラキ書 4:5"> 弟子たちは答えた。「バプテスマのヨハネだと言う人もいれば、エリヤだと言う人もいます。また、エレミヤ、あるいは預言者の一人だと言う人もいます。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ルカ 9:20; マタイ 13:11; マルコ 8:29"> イエスは彼らに言われた。<span className="woj">「では、あなたがたは私をだれだと言うのか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="マタイ 14:33; ヨハネ 11:27; ヨハネの手紙第一 4:15"> シモン・ペテロが答えた。「あなたはキリスト、生ける神の子です。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヨハネ 6:45; エペソ人への手紙 1:17–18; マタイ 11:25–27"> イエスは彼に答えられた。<span className="woj">「バルヨナ・シモン、あなたは幸いである。このことをあなたに示したのは、肉と血ではなく、天におられる私の父だからである。</span></span>
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 2:19–22; コリント人への第一の手紙 3:9–11; イザヤ書 28:16"> <span className="woj">私もあなたに言う。あなたはペテロである。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="ペテロという名は、ギリシャ語ではペトロスで、特定の岩または石を指す言葉である。">a</a></sup><span className="woj">私はこの岩の上に</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ギリシャ語ではペトラで、岩塊または岩盤を意味する。">b</a></sup><span className="woj">私の教会を建てる。ハデス</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="または「地獄」。">c</a></sup><span className="woj">の門も、それに打ち勝つことはない。</span></span>
<span className="v" id="v19" data-v="19" data-xref="マタイ 18:18; イザヤ書 22:22; ヨハネの黙示録 1:18"> <span className="woj">私はあなたに天の御国の鍵を与える。あなたが地上で縛るものは何でも、天ですでに縛られており、あなたが地上で解くものは何でも、天ですでに解かれている。」</span></span>
<span className="v" id="v20" data-v="20" data-xref="マルコ 8:30; ルカ 9:21; ヨハネ 1:41"> それからイエスは、ご自分がキリストであることをだれにも言わないよう、弟子たちに命じられた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ルカ 24:6–7; マタイ 20:17–19; マタイ 17:22–23"> その時から、イエスはご自分がエルサレムへ行き、長老たち、祭司長たち、律法学者たちから多くの苦しみを受け、殺され、三日目によみがえらなければならないことを、弟子たちに示し始められた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="マルコ 8:32; ヨハネ 13:6–8; マタイ 16:16–17"> するとペテロはイエスを脇へお連れし、いさめ始めた。「主よ、どうかそんなことがありませんように。そんなことがあなたに起こるはずはありません。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ローマ人への手紙 8:5–8; コロサイ人への手紙 3:2; ピリピ人への手紙 3:19"> しかし、イエスは振り向いてペテロに言われた。<span className="woj">「サタンよ、私の後ろに退け。あなたは私をつまずかせる者だ。神のことを思わず、人のことを思っているからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="マタイ 10:38; ルカ 14:27; ペテロの手紙第一 4:1–2"> それからイエスは弟子たちに言われた。<span className="woj">「だれでも私について来たいと思うなら、自分を捨て、自分の十字架を負って、私に従いなさい。</span></span>
<span className="v" id="v25" data-v="25" data-xref="マタイ 10:39; マルコ 8:35; ヨハネの黙示録 12:11"> <span className="woj">自分のいのちを救おうとする者はそれを失い、私のために自分のいのちを失う者はそれを見いだすからである。</span></span>
<span className="v" id="v26" data-v="26" data-xref="マルコ 8:36–37; ヨブ記 27:8; ルカ 9:25"> <span className="woj">たとえ全世界を手に入れても、自分のいのちを失うなら、何の益があるだろうか。また、人は自分のいのちと引き換えに何を差し出せるだろうか。</span></span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への第二の手紙 5:10; 詩篇 62:12; ローマ人への手紙 2:6"> <span className="woj">人の子は、御使いたちと共に父の栄光のうちに来る。そのとき、一人ひとりにその行いに応じて報いる。</span></span>
<span className="v" id="v28" data-v="28" data-xref="ルカ 9:27; マルコ 9:1; ヨハネ 8:52"> <span className="woj">まことに、あなたがたに言う。ここに立っている者の中には、人の子が御国のうちに来るのを見るまでは、決して死を味わわない者がいる。」</span></span>
</div>
</div>

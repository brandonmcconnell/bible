<span className="v" id="v1" data-v="1" data-xref="創世記 22:18; ローマ人への手紙 1:3; ガラテヤ人への手紙 3:16"> ダビデの子、アブラハムの子であるイエス・キリスト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="メシア（ヘブル語）とキリスト（ギリシャ語）は、どちらも「油を注がれた者」という意味である。">a</a></sup>の系図。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 7:8; ヘブル人への手紙 11:17–18; 創世記 46:8–27"> アブラハムにイサクが生まれ、イサクにヤコブが生まれ、ヤコブにユダとその兄弟たちが生まれた。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 46:12; 創世記 38:29–30; 歴代誌上 4:1"> ユダとタマルの間にペレツとゼラが生まれ、ペレツにヘツロンが生まれ、ヘツロンにラムが生まれた。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌上 2:10–12; 民数記 7:12; 民数記 2:3"> ラムにアミナダブが生まれ、アミナダブにナフションが生まれ、ナフションにサルモンが生まれた。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 11:31; ルツ記 1:16–17; ヤコブの手紙 2:25"> サルモンとラハブの間にボアズが生まれ、ボアズとルツの間にオベデが生まれ、オベデにエッサイが生まれた。</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第一 15:5; サムエル記第一 17:12; サムエル記第二 12:24–25"> エッサイにダビデ王が生まれた。ダビデ王<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NU本文では「王」が省かれている。">b</a></sup>と、ウリヤの妻との間にソロモンが生まれた。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌 第二 14:1–15; 列王記第一 14:31; 列王記第一 11:43–24"> ソロモンにレハブアムが生まれ、レハブアムにアビヤが生まれ、アビヤにアサが生まれた。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代誌上 3:11; 歴代誌 第二 26:1–23; 列王記第二 8:16"> アサにヨシャファトが生まれ、ヨシャファトにヨラムが生まれ、ヨラムにウジヤが生まれた。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 7:1–13; 歴代誌 第二 26:21; 歴代誌 第二 27:1–32"> ウジヤにヨタムが生まれ、ヨタムにアハズが生まれ、アハズにヒゼキヤが生まれた。</span>
<span className="v" id="v10" data-v="10" data-xref="歴代誌 第二 32:33–27; 列王記第一 13:2; 歴代誌上 3:13–15"> ヒゼキヤにマナセが生まれ、マナセにアモンが生まれ、アモンにヨシヤが生まれた。</span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 27:20; エレミヤ書 52:28–30; ダニエル書 1:2"> バビロン捕囚のころ、ヨシヤにエコニヤとその兄弟たちが生まれた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歴代誌上 3:17; エズラ記 3:2; ルカ 3:27"> バビロン捕囚の後、エコニヤにシェアルティエルが生まれ、シェアルティエルにゼルバベルが生まれた。</span>
<span className="v" id="v13" data-v="13"> ゼルバベルにアビウドが生まれ、アビウドにエリアキムが生まれ、エリアキムにアゾルが生まれた。</span>
<span className="v" id="v14" data-v="14"> アゾルにツァドクが生まれ、ツァドクにアキムが生まれ、アキムにエリウドが生まれた。</span>
<span className="v" id="v15" data-v="15"> エリウドにエレアザルが生まれ、エレアザルにマタンが生まれ、マタンにヤコブが生まれた。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイ 27:17; ヨハネ 4:25; ルカ 3:23"> ヤコブに、マリアの夫ヨセフが生まれた。このマリアから、キリストと呼ばれるイエス<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「イエス」は「救い」という意味である。">c</a></sup>が生まれた。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="マタイ 1:11–12; 列王記第二 24:14; マタイ 11:2"> こうして、アブラハムからダビデまでが全部で十四代、ダビデからバビロン捕囚までが十四代、バビロン捕囚からキリストまでが十四代である。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ガラテヤ人への手紙 4:4–5; ルカ 1:27–38; ヨブ記 14:4"> さて、イエス・キリストの誕生は次のようであった。母マリアはヨセフと婚約していたが、二人が一緒になる前に、聖霊によって身ごもっていることが分かった。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 22:21–24; 申命記 24:1–4; ヨハネ 8:4–5"> 夫ヨセフは義人で、彼女をさらし者にしたくなかったので、ひそかに離縁しようと考えた。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 3:5–6; ルカ 1:19; マタイ 1:18"> 彼がこのことを思い巡らしていると、見よ、<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="「見よ」はギリシャ語の「ἰδοὺ」に由来し、「見る、注意を向ける、観察する、目を留める」という意味で、しばしば間投詞として用いられる。">d</a></sup>主の使いが夢に現れて言った。「ダビデの子ヨセフよ、恐れずにマリアを妻として迎えなさい。彼女に宿っている子は聖霊によるものだからだ。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 13:23; 使徒の働き 4:12; ヨハネ 1:29"> 彼女は男の子を産む。その名をイエス<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="「イエス」は「救い」という意味である。">e</a></sup>とつけなさい。この方こそ、ご自分の民をその罪から救う方だからだ。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="ルカ 24:44; マタイ 2:23; 列王記第一 8:15"> このすべてのことが起こったのは、主が預言者を通して語られたことが成就するためである。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 7:14; イザヤ書 9:6–7; 詩篇 46:11"> <span className="pl pl-1">「見よ、処女が身ごもり、</span><br /><span className="pl pl-2">男の子を産む。</span><br /><span className="pl pl-1">人々はその名をインマヌエルと呼ぶ。」</span><br /><span className="pl pl-2">これは訳すと、「神はわれわれと共におられる」という意味である。</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヨハネ 15:14; ヤコブの手紙 2:21–26; ヨハネ 2:5–8"> ヨセフは眠りから覚めると、主の使いに命じられたとおりにして、妻を迎え入れた。</span>
<span className="v" id="v25" data-v="25" data-xref="ルカ 2:21; 出エジプト記 13:2; マタイ 1:21"> しかし、彼女が初子となる男の子を産むまでは、彼女と性的な関係を持たなかった。そして、その子をイエスと名づけた。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカ 3:1; マルコ 8:15; ルカ 9:7–9"> そのころ、四分領主ヘロデはイエスの評判を聞き、</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 16:14; ヨハネ 10:41; マルコ 8:28"> 家来たちに言った。「この人はバプテスマのヨハネだ。死者の中からよみがえったのだ。だから、あのような力あるわざが彼を通して行われるのだ。」</span>
<span className="v" id="v3" data-v="3" data-xref="マルコ 6:17; ルカ 3:19–20; マタイ 4:12"> ヘロデは、自分の兄弟フィリポの妻ヘロディアのために、ヨハネを捕らえて縛り、牢獄に入れていた。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 20:21; レビ記 18:16; マルコ 6:18"> ヨハネがヘロデに、「彼女を妻とすることは、律法で許されていない」と言っていたからである。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイ 21:26; マタイ 11:9; マルコ 6:19–20"> ヘロデはヨハネを殺そうと思っていたが、群衆を恐れていた。人々がヨハネを預言者と認めていたからである。</span>
<span className="v" id="v6" data-v="6" data-xref="マルコ 6:21–23; 創世記 40:20; ホセア書 1:5–6"> ところが、ヘロデの誕生日に、ヘロディアの娘が人々の前で踊り、ヘロデを喜ばせた。</span>
<span className="v" id="v7" data-v="7" data-xref="エステル記 5:3; エステル記 5:6; エステル記 7:2"> そこでヘロデは誓いを立て、娘が求めるものは何でも与えると約束した。</span>
<span className="v" id="v8" data-v="8" data-xref="マルコ 6:24; 箴言 29:10; 箴言 1:16"> 娘は母に促されて言った。「バプテスマのヨハネの首を、盆に載せて、ここで私にください。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヨハネ 19:12–16; サムエル記第一 14:28; マルコ 6:26"> 王は心を痛めたが、自分の誓いと同席している者たちのために、娘の願いどおりにするよう命じた。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイ 17:12; マタイ 21:35–36; ルカ 9:9"> そして人を遣わし、牢獄でヨハネの首をはねさせた。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 16:6; 創世記 49:7; エゼキエル書 16:3–4"> その首は盆に載せて運ばれ、少女に渡された。少女はそれを母のところに持って行った。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 8:2; マタイ 27:58–61"> ヨハネの弟子たちは来て遺体を引き取り、葬った。それからイエスのもとに行って知らせた。</span>
<span className="v" id="v13" data-v="13" data-xref="ルカ 9:10–17; マタイ 14:1–2; マルコ 6:30–44"> イエスはこれを聞くと、舟でそこを去り、人里離れた所へ退かれた。しかし、群衆はそれを聞き、町々から歩いてイエスの後を追った。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 4:15; マタイ 9:36; ヘブル人への手紙 2:17"> イエスは舟から出て大勢の群衆をご覧になると、彼らを深くあわれみ、その中の病人たちを癒された。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイ 15:23; マルコ 8:3; マルコ 6:35–36"> 夕方になり、弟子たちがイエスのもとに来て言った。「ここは人里離れた所で、もう時刻も遅くなっています。群衆を解散させて、村々へ行き、自分たちで食べ物を買わせてください。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王記第二 4:42–44; コリント人への第二の手紙 8:2–3; 伝道者の書 11:2"> しかし、イエスは彼らに言われた。<span className="woj">「彼らが行く必要はない。あなたがたが何か食べるものを与えなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="マタイ 15:33–34; マルコ 6:37–38; ルカ 9:13"> 弟子たちは言った。「ここにはパン五つと魚二匹しかありません。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> イエスは言われた。<span className="woj">「それをここに、私のところへ持って来なさい。」</span></span>
<span className="v" id="v19" data-v="19" data-xref="マルコ 8:6–7; ルカ 24:30; サムエル記第一 9:13"> そして群衆に命じて草の上に座らせ、五つのパンと二匹の魚を取り、天を見上げて祝福し、パンを裂いて弟子たちに渡された。弟子たちはそれを群衆に配った。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 16:12; マルコ 6:42–44; マタイ 16:8–10"> 人々はみな食べて満腹した。弟子たちが残ったパン切れを拾い集めると、十二のかごがいっぱいになった。</span>
<span className="v" id="v21" data-v="21" data-xref="ピリピ人への手紙 4:19; コリント人への第二の手紙 9:8–11; 使徒の働き 4:4"> 食べた者は、女と子どもを除いて、男が約五千人であった。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="マルコ 6:45–51; ヨハネ 6:15–21; マタイ 15:39"> それからすぐ、イエスは弟子たちを舟に乗せ、ご自分が群衆を解散させている間に、先に向こう岸へ行かせられた。</span>
<span className="v" id="v23" data-v="23" data-xref="ルカ 6:12; マルコ 6:46; マタイ 26:36"> 群衆を解散させると、祈るために一人で山に登られた。夕方になっても、そこに一人でおられた。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネ 6:18; マルコ 6:48; マタイ 8:24"> そのころ、舟はすでに湖の真ん中にあり、向かい風だったため、波に悩まされていた。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨブ記 9:8; ヨハネ 6:19; マルコ 6:48"> 夜の第四の見張り時に、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="夜は四つの見張り時に等分されていたので、第四の見張り時は、およそ午前三時から日の出までである。">a</a></sup>イエスは湖の上を歩いて、彼らのところに来られた。</span>
<span className="v" id="v26" data-v="26" data-xref="マルコ 6:49–50; ヨハネの黙示録 1:17; ルカ 1:11–12"> 弟子たちはイエスが湖の上を歩いておられるのを見て取り乱し、「幽霊だ」と言って、恐怖のあまり叫び声を上げた。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 23:11; ヨハネの黙示録 1:17–18; ヨハネ 16:33"> しかし、イエスはすぐに彼らに語りかけられた。<span className="woj">「元気を出しなさい。私だ。</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または「私はある」。">b</a></sup><span className="woj">恐れてはならない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヨハネ 6:68; ローマ人への手紙 12:3; マタイ 26:33–35"> ペテロはイエスに答えた。「主よ、あなたでしたら、水の上を歩いてあなたのところに行くよう、私にお命じください。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ピリピ人への手紙 4:13; マルコ 9:23; 使徒の働き 3:16"> イエスは<span className="woj">「来なさい」</span>と言われた。<br />ペテロは舟から降り、水の上を歩いてイエスのところへ向かった。</span>
<span className="v" id="v30" data-v="30" data-xref="哀歌 3:54–57; テモテへの第二の手紙 4:16–17; マルコ 14:38"> しかし、風が強いのを見て怖くなり、沈み始めたので、「主よ、私をお救いください」と叫んだ。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ヤコブの手紙 1:6–8; 詩篇 138:7; 創世記 22:14"> イエスはすぐに手を伸ばして彼をつかみ、言われた。<span className="woj">「信仰の薄い者よ、なぜ疑ったのか。」</span></span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 107:29–30; マルコ 4:41; ヨハネ 6:21"> 二人が舟に乗り込むと、風はやんだ。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネ 11:27; 詩篇 2:7; ローマ人への手紙 1:4"> 舟にいた者たちはイエスを拝み、「まことに、あなたは神の子です」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="マルコ 6:53–56; ルカ 5:1; ヨハネ 6:24–25"> 彼らは湖を渡り、ゲネサレの地に着いた。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイ 4:24–25; マルコ 6:55; マルコ 1:28–34"> その土地の人々はイエスだと気づくと、周辺の地方全体に人を遣わし、病んでいる人々をみなイエスのもとに連れて来た。</span>
<span className="v" id="v36" data-v="36" data-xref="ルカ 6:19; マルコ 3:10; 出エジプト記 28:33–43"> そして、せめて衣の裾<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="または「房」。">c</a></sup>に触れさせていただきたいと願った。触れた者はみな癒された。</span>
</div>

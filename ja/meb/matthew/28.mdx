<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコ 16:1–8; ヨハネ 20:1–10; マタイ 27:56"> さて、安息日が終わり、週の初めの日の夜明けごろ、マグダラのマリアともう一人のマリアが墓を見に来た。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 16:26; ヨハネ 20:12–13; マルコ 16:3–5"> 見よ、大きな地震が起こった。主の使いが天から降りて来て、墓の入り口から石を転がし、その上に座ったからである。</span>
<span className="v" id="v3" data-v="3" data-xref="マルコ 9:3; 使徒の働き 1:10; マルコ 16:5"> その姿は稲妻のようで、衣は雪のように白かった。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 1:17; ダニエル書 10:7; マタイ 27:65–66"> 番兵たちは御使いを恐れて震え上がり、死人のようになった。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 1:17–18; ヘブル人への手紙 1:14; イザヤ書 41:10"> 御使いは女たちに言った。「恐れてはならない。あなたがたが十字架につけられたイエスを捜していることは分かっている。</span>
<span className="v" id="v6" data-v="6" data-xref="マルコ 16:6; マタイ 12:40; ルカ 24:6–8"> イエスはここにはおられない。言われたとおり、よみがえられたからである。来て、主が横たわっておられた場所を見なさい。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイ 26:32; ルカ 24:22–24; マタイ 28:10"> そして急いで行き、弟子たちに、『イエスは死者の中からよみがえられた。見よ、あなたがたより先にガリラヤへ行かれる。そこでお会いできる』と告げなさい。見よ、私はあなたがたに伝えた。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="詩篇 2:11; マルコ 16:8; ルカ 24:36–41"> 女たちは恐れと大きな喜びを抱き、急いで墓を離れ、弟子たちに知らせるために走って行った。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイ 28:17; ヨハネ 20:14–17; マタイ 14:33"> 弟子たちに知らせに行く途中、見よ、イエスが彼女たちに出会い、<span className="woj">「喜びなさい」</span>と言われた。<br />彼女たちは近寄ってイエスの足を抱き、礼拝した。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 8:29; ヨハネ 20:17; マタイ 28:7"> そのとき、イエスは彼女たちに言われた。<span className="woj">「恐れてはならない。行って、私の兄弟たち</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="ここで「兄弟」と訳された言葉は、「兄弟姉妹」または「きょうだい」と訳すこともできる。">a</a></sup><span className="woj">に、ガリラヤへ行くよう伝えなさい。そこで彼らは私に会う。」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="マタイ 27:65–66; マタイ 28:4"> 女たちが行く途中、見よ、番兵の何人かが町に入り、起こったことをすべて祭司長たちに報告した。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイ 26:3–4; 使徒の働き 4:5–22; マタイ 27:1–2"> 祭司長たちは長老たちと集まって相談し、兵士たちに多額の銀貨を与えて、</span>
<span className="v" id="v13" data-v="13" data-xref="マタイ 26:64"> 言った。「『夜中に弟子たちが来て、われわれが眠っている間に彼を盗んで行った』と言え。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイ 27:2; 使徒の働き 12:19"> もしこのことが総督の耳に入っても、われわれが説得し、おまえたちが心配しなくてよいようにしよう。」</span>
<span className="v" id="v15" data-v="15" data-xref="テモテへの手紙第一 6:10; マタイ 27:8; マタイ 26:15"> そこで兵士たちは銀貨を受け取り、教えられたとおりにした。この話はユダヤ人の間に広まり、今日まで伝わっている。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="マタイ 26:32; マタイ 28:10; マタイ 28:7"> さて、十一人の弟子たちはガリラヤへ行き、イエスが指定された山に登った。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 45:11; 詩篇 2:12; ヨハネ 5:23"> そしてイエスを見ると礼拝した。しかし、疑う者もいた。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネ 3:35; ペテロの手紙第一 3:22; マタイ 11:27"> イエスは近づいて来て、彼らに言われた。<span className="woj">「天と地におけるすべての権威が、私に与えられている。</span></span>
<span className="v" id="v19" data-v="19" data-xref="マルコ 16:15–16; 使徒の働き 2:38–39; 使徒の働き 1:8"> <span className="woj">行って</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TR本文とNU本文は「だから」を加えている。">b</a></sup><span className="woj">、すべての国民を弟子とし、父と子と聖霊の名によって彼らにバプテスマを授けなさい。</span></span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 41:10; ヨシュア記 1:5; 使徒の働き 18:9–10"> <span className="woj">また、私があなたがたに命じたすべてのことを守るように教えなさい。見よ、私は世の終わりまで、いつもあなたがたと共にいる。」</span>アーメン。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ネヘミヤ記 2:1; 歴代誌上 6:4–14; エズラ記 7:21"> これらのことの後、ペルシア王アルタクセルクセスの治世に、セラヤの子エズラがいた。セラヤはアザルヤの子、アザルヤはヒルキヤの子、</span>
<span className="v" id="v2" data-v="2" data-xref="列王記第一 2:35; サムエル記第二 8:17"> ヒルキヤはシャルムの子、シャルムはツァドクの子、ツァドクはアヒトブの子、</span>
<span className="v" id="v3" data-v="3"> アヒトブはアマルヤの子、アマルヤはアザルヤの子、アザルヤはメラヨテの子、</span>
<span className="v" id="v4" data-v="4"> メラヨテはゼラフヤの子、ゼラフヤはウジの子、ウジはブキの子、</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 6:25; 歴代誌 第二 26:20; 歴代誌上 6:4"> ブキはアビシュアの子、アビシュアはピネハスの子、ピネハスはエルアザルの子、エルアザルは祭司長アロンの子であった。</span>
<span className="v" id="v6" data-v="6" data-xref="エズラ記 8:22; エズラ記 7:28; エズラ記 8:31"> このエズラがバビロンから上って来た。彼はイスラエルの神、主が与えられたモーセの律法に精通した書記であった。彼の神、主の御手が彼の上にあったので、王は彼の願いをすべてかなえた。</span>
<span className="v" id="v7" data-v="7" data-xref="エズラ記 8:1–20; 歴代誌上 6:31–48; 歴代誌上 9:17–27"> アルタクセルクセス王の第七年に、イスラエルの子らの一部、また祭司、レビ人、歌うたいたち、門衛たち、宮のしもべたちの一部がエルサレムに上って来た。</span>
<span className="v" id="v8" data-v="8"> 彼は王の第七年の第五の月にエルサレムに着いた。</span>
<span className="v" id="v9" data-v="9" data-xref="エズラ記 7:6; ネヘミヤ記 2:8; ネヘミヤ記 2:18"> 彼は第一の月の一日にバビロンを出発し、第五の月の一日にエルサレムへ着いた。彼の神の恵み深い御手が彼の上にあったからである。</span>
<span className="v" id="v10" data-v="10" data-xref="マラキ書 2:7; テモテへの第二の手紙 4:2; マタイ 7:24"> エズラは主の律法を探究し、それを行い、イスラエルに掟と定めを教えることに心を定めていた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エズラ記 5:6; エズラ記 7:6; マタイ 23:2"> これは、祭司であり書記であって、主の命令のことばと、イスラエルに与えられた主の掟に通じていたエズラに、アルタクセルクセス王が与えた手紙の写しである。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ダニエル書 2:37; エゼキエル書 26:7; エズラ記 4:17"> 「王の王アルタクセルクセスから、<br />完全な天の神の律法に通じた書記、祭司エズラへ。<br />さて、</span>
<span className="v" id="v13" data-v="13" data-xref="エズラ記 6:1; 詩篇 148:6; 歴代誌 第二 30:5"> 私は命令する。私の領土内にいるイスラエルの民、その祭司とレビ人のうち、自ら進んでエルサレムへ行こうとする者は皆、あなたとともに行くように。</span>
<span className="v" id="v14" data-v="14" data-xref="エステル記 1:14; エズラ記 7:25–26; エズラ記 7:28"> あなたは、あなたの手にある神の律法に従ってユダとエルサレムの事情を調査するため、王と七人の顧問によって遣わされる。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 135:21; 歴代誌 第二 6:2; エズラ記 6:12"> また、王と顧問たちが、その住まいがエルサレムにあるイスラエルの神に、自発のささげ物として献げた銀と金を携えよ。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代誌上 29:6; エズラ記 1:4; 歴代誌上 29:9"> さらに、バビロン州全域で得られるすべての銀と金を、エルサレムにある彼らの神の家のため、民と祭司たちが進んで献げる自発のささげ物とともに携えて行け。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 12:5–11; 民数記 15:4–13; エズラ記 6:9–10"> それゆえ、この金で雄牛、雄羊、子羊、またそれに伴う穀物のささげ物と注ぎのささげ物を必ず買い、エルサレムにあるあなたがたの神の家の祭壇でささげよ。</span>
<span className="v" id="v18" data-v="18" data-xref="列王記第二 22:7; エペソ人への手紙 5:17; 列王記第二 12:15"> 残った銀と金については、あなたとあなたの同胞がよいと思うことを、あなたがたの神の御心に従って行え。</span>
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 3:17; エズラ記 8:33–34; 歴代誌 第二 32:19"> あなたの神の家の奉仕のために託された器は、エルサレムにおられる神の前に納めよ。</span>
<span className="v" id="v20" data-v="20" data-xref="エズラ記 6:4; エズラ記 6:8–18"> あなたの神の家のためにそのほかの必要が生じ、あなたが支払うべきものがあれば、王の宝物倉から支出せよ。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="エズラ記 4:16; エズラ記 7:6; エズラ記 7:10–13"> 私、アルタクセルクセス王は、川の向こう側にいるすべての宝物倉の管理者に命じる。祭司であり天の神の律法の書記であるエズラが求めるものは、何であれ滞りなく与えよ。</span>
<span className="v" id="v22" data-v="22" data-xref="ルカ 16:6–7; レビ記 2:13; エゼキエル書 45:14"> 銀は百タラント<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一タラントは約30キログラム、66ポンド、または965トロイオンスである。">a</a></sup>まで、小麦は百コル<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一コルは一ホメルと同じで、約55.9米ガロン、211リットル、または6ブッシェルである。">b</a></sup>まで、ぶどう酒は百バテ<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一バテは一コルの十分の一で、約5.6米ガロン、21リットル、または2.4ペックである。百バテは約2,100リットルになる。">c</a></sup>まで、油は百バテまで、塩は量を定めずに与えよ。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 119:4; エズラ記 7:18; エズラ記 6:10–12"> 天の神が命じられることは何であれ、天の神の家のために正確に行え。王とその子らの王国に御怒りが下るようなことが、どうしてあってよいだろうか。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="エズラ記 7:7; エズラ記 4:13; エズラ記 2:36–55"> さらに知らせる。祭司、レビ人、歌うたいたち、門衛たち、宮のしもべたち、またこの神の家に仕える者たちには、貢ぎ物、関税、通行料を課してはならない。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="エズラ記 7:10; 申命記 16:18; ヤコブの手紙 1:5"> エズラよ。あなたの手にある神の知恵に従い、川の向こう側にいる民、すなわちあなたの神の律法を知るすべての者を治める役人と裁判官を任命せよ。また、それを知らない者には教えよ。</span>
<span className="v" id="v26" data-v="26" data-xref="エズラ記 6:11; 申命記 13:1–18; レビ記 20:1–27"> あなたの神の律法と王の法律を守らない者には、死刑、追放、財産の没収、投獄のいずれであれ、厳正に裁きを執行せよ。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="エズラ記 6:22; ヨハネの黙示録 17:17; イザヤ書 60:13"> 私たちの父祖の神、主はほめたたえられよ。主はエルサレムにある主の家を美しくするため、このような思いを王の心に置いてくださった。</span>
<span className="v" id="v28" data-v="28" data-xref="テモテへの第二の手紙 4:17–18; エズラ記 5:5; 創世記 32:28"> また王とその顧問たち、王のすべての有力な君たちの前で、私に慈しみを示してくださった。私の神、主の御手が私の上にあったので、私は力づけられ、ともに上る指導者たちをイスラエルの中から集めた。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ダニエル書 9:20; 詩篇 119:136; ローマ人への手紙 9:2"> エズラが祈り、罪を告白し、泣きながら神の家の前にひれ伏していると、イスラエルから男、女、子どもの非常に大きな会衆が彼のもとに集まった。民は激しく泣いていた。</span>
<span className="v" id="v2" data-v="2" data-xref="ネヘミヤ記 13:27; エズラ記 9:2; エレミヤ書 3:12–13"> エラムの子らの一人、エヒエルの子シェカニヤがエズラに言った。「私たちは神に背き、その地の諸国の民から異国の女たちを妻に迎えました。それでも今、このことについてイスラエルには希望があります。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 7:2–3; エズラ記 9:4; ヨシュア記 23:12–13"> それゆえ今、わが主の助言と、私たちの神の命令に震える者たちの助言に従い、すべての妻と、その妻たちから生まれた子どもたちを去らせる契約を、私たちの神と結びましょう。律法に従って行いましょう。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌上 28:10; 伝道者の書 9:10; ヘブル人への手紙 12:12–13"> 立ち上がってください。このことはあなたにかかっています。私たちもあなたとともにいます。勇気を出して実行してください。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ネヘミヤ記 13:25; ネヘミヤ記 5:12; 箴言 9:9"> そこでエズラは立ち上がり、祭司の長たち、レビ人たち、全イスラエルに、このことばどおりに行うと誓わせた。彼らは誓った。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 9:18; ネヘミヤ記 3:1; ネヘミヤ記 12:22"> それからエズラは神の家の前を去り、エルヤシブの子エホハナンの部屋に入った。彼はそこにいる間、パンを食べず、水も飲まなかった。捕囚から帰った者たちの背信を嘆いていたからである。</span>
<span className="v" id="v7" data-v="7" data-xref="エズラ記 1:1; 歴代誌 第二 30:5"> そしてユダとエルサレム全土に、捕囚から帰った者たちは皆エルサレムに集まるようにとの布告が出された。</span>
<span className="v" id="v8" data-v="8" data-xref="エズラ記 7:26; ヨハネ 9:22; 士師記 21:5"> 君たちと長老たちの決定により、三日以内に来ない者は、その全財産を没収され、本人も捕囚から帰った者たちの会衆から追放されることになった。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="サムエル記第一 12:17–18; エレミヤ書 10:13; エズラ記 7:8–9"> そこでユダとベニヤミンのすべての男たちは、三日以内にエルサレムへ集まった。それは第九の月の二十日であった。民は皆、神の家の前の広場に座り、この問題と大雨のために震えていた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エズラ記 9:6; 民数記 32:14; マタイ 23:32"> 祭司エズラは立ち上がって言った。「あなたがたは神に背き、異国の女たちを妻に迎えて、イスラエルの罪責を増し加えた。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 12:2; エズラ記 10:3; イザヤ書 1:16–18"> それゆえ今、あなたがたの父祖の神、主の前に罪を告白し、その御心を行え。その地の民と、異国の女たちから離れよ。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ネヘミヤ記 13:23; 詩篇 78:57; エズラ記 10:3–4"> すると全会衆は大声で答えた。「あなたの言われたとおりに、私たちは行います。</span>
<span className="v" id="v13" data-v="13" data-xref="エズラ記 10:18–44; マタイ 7:13–14"> しかし民は多く、今は大雨の時期なので、外に立ち続けることはできません。また、これは一日や二日で済む仕事ではありません。私たちはこの件で大きな罪を犯したからです。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代誌 第二 29:10; 歴代誌 第二 30:8; 民数記 25:4"> 全会衆を代表する君たちを任命してください。私たちの町々で異国の女を妻に迎えた者は皆、定められた時に、それぞれの町の長老と裁判官を伴って来るようにしてください。この件が解決し、私たちに向けられた神の激しい怒りが去るまで、そのようにしましょう。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ネヘミヤ記 11:16; ネヘミヤ記 10:20; ネヘミヤ記 12:33"> ただアサエルの子ヨナタンとティクワの子ヤフゼヤはこの案に反対し、メシュラムとレビ人シャベタイが彼らを支持した。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヨブ記 29:16; 申命記 13:14; ヨハネ 7:51"> 捕囚から帰った者たちは、そのとおりにした。祭司エズラと、父祖の家ごとに選ばれた家長たちが、それぞれ名を挙げて任命された。彼らは第十の月の一日に、この件を調べるため席に着いた。</span>
<span className="v" id="v17" data-v="17"> そして第一の月の一日までに、異国の女を妻に迎えたすべての男について調査を終えた。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エズラ記 5:2; エズラ記 3:2; ゼカリヤ書 3:1"> 祭司の子らのうち、異国の女を妻に迎えていた者は次のとおりである。 エホツァダクの子エシュアの子らとその兄弟たちのうち、マアセヤ、エリエゼル、ヤリブ、ゲダルヤ。</span>
<span className="v" id="v19" data-v="19" data-xref="レビ記 6:6; 列王記第二 10:15; 歴代誌 第二 30:8"> 彼らは妻を去らせることを誓約し、罪責を負う者として、その罪過のために羊の群れから雄羊一頭をささげた。</span>
<span className="v" id="v20" data-v="20" data-xref="エズラ記 2:37; 歴代誌上 24:14; ネヘミヤ記 7:40"> イメルの子らのうち、ハナニとゼバデヤ。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代誌上 24:8; エズラ記 2:39; ネヘミヤ記 7:42"> ハリムの子らのうち、マアセヤ、エリヤ、シェマヤ、エヒエル、ウジヤ。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代誌上 9:12; ネヘミヤ記 7:41; エズラ記 2:38"> パシュフルの子らのうち、エリオエナイ、マアセヤ、イシュマエル、ネタンエル、ヨザバド、エラサ。</span>
<span className="v" id="v23" data-v="23" data-xref="ネヘミヤ記 10:10; ネヘミヤ記 11:16; エズラ記 8:33"> レビ人のうち、ヨザバド、シムイ、ケラヤ（別名ケリタ）、ペタフヤ、ユダ、エリエゼル。</span>
<span className="v" id="v24" data-v="24"> 歌うたいたちのうち、エルヤシブ。 門衛たちのうち、シャルム、テレム、ウリ。</span>
<span className="v" id="v25" data-v="25" data-xref="エズラ記 2:3; ネヘミヤ記 7:8"> イスラエルのうち、パロシュの子らでは、ラミヤ、イズヤ、マルキヤ、ミヤミン、エルアザル、マルキヤ、ベナヤ。</span>
<span className="v" id="v26" data-v="26" data-xref="エズラ記 10:2; エズラ記 2:31; ネヘミヤ記 7:12"> エラムの子らでは、マタヌヤ、ゼカリヤ、エヒエル、アブディ、エレモテ、エリヤ。</span>
<span className="v" id="v27" data-v="27" data-xref="ネヘミヤ記 7:13; エズラ記 2:8"> ザトの子らでは、エリオエナイ、エルヤシブ、マタヌヤ、エレモテ、ザバド、アジザ。</span>
<span className="v" id="v28" data-v="28" data-xref="エズラ記 8:11; エズラ記 2:11; ネヘミヤ記 7:16"> ベバイの子らでは、エホハナン、ハナニヤ、ザバイ、アテライ。</span>
<span className="v" id="v29" data-v="29" data-xref="ネヘミヤ記 7:15; ネヘミヤ記 10:4; エズラ記 2:10"> バニの子らでは、メシュラム、マルク、アダヤ、ヤシュブ、シェアル、エレモテ。</span>
<span className="v" id="v30" data-v="30" data-xref="エズラ記 8:4; ネヘミヤ記 7:11; エズラ記 2:6"> パハテ・モアブの子らでは、アドナ、ケラル、ベナヤ、マアセヤ、マタヌヤ、ベツァルエル、ビンヌイ、マナセ。</span>
<span className="v" id="v31" data-v="31" data-xref="ネヘミヤ記 3:11; ネヘミヤ記 7:35; エズラ記 2:32"> ハリムの子らでは、エリエゼル、イシヤ、マルキヤ、シェマヤ、シメオン、</span>
<span className="v" id="v32" data-v="32"> ベニヤミン、マルク、シェマルヤ。</span>
<span className="v" id="v33" data-v="33" data-xref="エズラ記 2:19; ネヘミヤ記 7:22"> ハシュムの子らでは、マテナイ、マタタ、ザバド、エリフェレテ、エレマイ、マナセ、シムイ。</span>
<span className="v" id="v34" data-v="34"> バニの子らでは、マアダイ、アムラム、ウエル、</span>
<span className="v" id="v35" data-v="35"> ベナヤ、ベデヤ、ケルヒ、</span>
<span className="v" id="v36" data-v="36"> ワヌヤ、メレモテ、エルヤシブ、</span>
<span className="v" id="v37" data-v="37"> マタヌヤ、マテナイ、ヤアス、</span>
<span className="v" id="v38" data-v="38"> バニ、ビンヌイ、シムイ、</span>
<span className="v" id="v39" data-v="39"> シェレミヤ、ナタン、アダヤ、</span>
<span className="v" id="v40" data-v="40"> マクナデバイ、シャシャイ、シャライ、</span>
<span className="v" id="v41" data-v="41"> アザレル、シェレミヤ、シェマルヤ、</span>
<span className="v" id="v42" data-v="42"> シャルム、アマルヤ、ヨセフ。</span>
<span className="v" id="v43" data-v="43" data-xref="エズラ記 2:29; ネヘミヤ記 7:33"> ネボの子らでは、エイエル、マティティヤ、ザバド、ゼビナ、イド、ヨエル、ベナヤ。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="箴言 5:20; エズラ記 10:3; 箴言 2:16"> これらの者は皆、異国の妻を迎えていた。その妻との間に子どもがいた者もあった。</span>
</div>

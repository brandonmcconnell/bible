<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌上 22:9–10; エズラ記 1:11; エズラ記 10:16"> ユダとベニヤミンの敵たちは、捕囚から帰った者たちがイスラエルの神、主のために神殿を建てていると聞いた。</span>
<span className="v" id="v2" data-v="2" data-xref="列王記第二 19:37; 列王記第二 17:24; ガラテヤ人への手紙 2:4"> 彼らはゼルバベルと父祖の家の長たちに近づいて言った。「私たちにも、あなたがたとともに建てさせてほしい。私たちもあなたがたと同じように、あなたがたの神を求めている。私たちをここへ移したアッシリア王エサルハドンの時代から、この神にいけにえをささげてきた。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ネヘミヤ記 2:20; マタイ 10:16; 歴代誌 第二 36:22–3"> しかしゼルバベル、エシュア、そのほかのイスラエルの父祖の家の長たちは答えた。「私たちの神のために家を建てることについて、あなたがたは私たちと何のかかわりもない。ペルシア王クロスが命じたとおり、私たちだけで、ともにイスラエルの神、主のために建てる。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="エズラ記 3:3; ネヘミヤ記 6:9; エレミヤ書 38:4"> そこでその地の民はユダの民の気力をくじき、彼らを脅して建築を妨げた。</span>
<span className="v" id="v5" data-v="5" data-xref="ナホム書 1:11; エズラ記 5:5–18; 詩篇 2:1–2"> 彼らはペルシア王クロスの時代からペルシア王ダレイオスの治世に至るまで、ユダの民の計画を挫くため、反対工作をする者たちを雇った。</span>
<span className="v" id="v6" data-v="6" data-xref="エステル記 1:1; ダニエル書 9:1; 使徒の働き 24:5–9"> アハシュエロスの治世、すなわちその治世の初めに、彼らはユダとエルサレムの住民に対する告発状を書いた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王記第二 18:26; ダニエル書 2:4; イザヤ書 36:11"> またアルタクセルクセスの時代には、ビシュラム、ミトレダテ、タベエル、そのほかの同僚たちが、ペルシア王アルタクセルクセスに手紙を書いた。その手紙はアラム文字で記され、アラム語で書かれていた。</span>
<span className="v" id="v8" data-v="8" data-xref="エズラ記 4:9; サムエル記第二 8:17; サムエル記第二 20:25"> 長官レフムと書記シムシャイは、エルサレムを告発する次の手紙をアルタクセルクセス王に書いた。</span>
<span className="v" id="v9" data-v="9" data-xref="エズラ記 5:6; エズラ記 6:6; 列王記第二 17:24"> 手紙を送ったのは、長官レフム、書記シムシャイ、そのほかの同僚たち、すなわちディナ人、アファルサテク人、タルペル人、アファル人、アルケブ人、バビロニア人、シュシャン人、デハ人、エラム人、</span>
<span className="v" id="v10" data-v="10" data-xref="エズラ記 4:17; エズラ記 4:11; エズラ記 7:12"> さらに、偉大で高貴なオセナパルが移住させ、サマリアの町と川の向こう側のその他の地方に住まわせた諸国の民であった。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> これは彼らがアルタクセルクセス王に送った手紙の写しである。<br />「アルタクセルクセス王へ。川の向こう側に住む王のしもべたちより。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="エズラ記 5:9; 歴代誌 第二 36:13; エズラ記 5:3"> 王にお知らせします。王のもとから私たちのところへ上って来たユダヤ人は、エルサレムに入り、あの反逆的で邪悪な町を再建しています。彼らは城壁を完成させ、土台を修復しています。</span>
<span className="v" id="v13" data-v="13" data-xref="エズラ記 7:24; ローマ人への手紙 13:6–7; ネヘミヤ記 5:4"> 今、王にお知らせします。この町が再建され、城壁が完成すれば、彼らは貢ぎ物も関税も通行料も納めなくなり、ついには王たちの損失となるでしょう。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネ 19:12–15; エゼキエル書 33:31; ヨハネ 12:5–6"> 私たちは王宮の塩をいただいており、王が辱められるのを見過ごすことはできません。それゆえ、人を遣わして王にお知らせします。</span>
<span className="v" id="v15" data-v="15" data-xref="エズラ記 4:12; エステル記 3:5–8; 列王記第二 24:20–1"> 王の父祖たちの記録の書をお調べください。記録の書の中に、この町が反逆の町であり、王たちと諸州に損害を与え、昔からその中で反乱が企てられてきたことを見いだされるでしょう。この町が滅ぼされたのも、そのためです。</span>
<span className="v" id="v16" data-v="16" data-xref="エズラ記 4:20; 列王記第一 4:24; サムエル記第二 8:3"> 私たちは王にお知らせします。この町が再建され、城壁が完成すれば、王は川の向こう側に何の領地も持てなくなるでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 1:7; エズラ記 5:7; エズラ記 4:9–11"> そこで王は、長官レフム、書記シムシャイ、サマリアと川の向こう側のその他の地方に住む同僚たちに返書を送った。<br />「平安を告げる。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ネヘミヤ記 8:8"> あなたがたが私たちに送った手紙は、私の前で明瞭に読み上げられた。</span>
<span className="v" id="v19" data-v="19" data-xref="列王記第二 18:7; 箴言 25:2; 申命記 13:14"> 私が命じて調査させたところ、この町は昔から王たちに反乱を起こし、その中で反逆と暴動が行われてきたことが判明した。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 15:18; 列王記第一 4:21; 歴代誌上 18:3"> またエルサレムには力ある王たちがいて、川の向こう側のすべての地方を治め、貢ぎ物、関税、通行料が彼らに支払われていた。</span>
<span className="v" id="v21" data-v="21"> 今、命令を出してこの者たちの工事を中止させ、私が命令を下すまで、この町を再建させてはならない。</span>
<span className="v" id="v22" data-v="22" data-xref="エステル記 7:3–4; エステル記 3:8–9; エズラ記 4:13"> この命令を怠らぬよう、くれぐれも注意せよ。王たちに損害を与える害悪を、どうして増大させてよいだろうか。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ローマ人への手紙 3:15; ミカ書 2:1; エズラ記 4:17"> アルタクセルクセス王の手紙の写しが、レフム、書記シムシャイ、その同僚たちの前で読み上げられると、彼らは急いでエルサレムのユダヤ人のもとへ行き、武力をもって工事を中止させた。</span>
<span className="v" id="v24" data-v="24" data-xref="ハガイ書 1:15; ネヘミヤ記 6:9; エズラ記 5:5"> こうしてエルサレムにある神の家の工事は止まり、ペルシア王ダレイオスの治世の第二年まで中断した。</span>
</div>
</div>

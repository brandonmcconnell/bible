<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エズラ記 7:7; エズラ記 2:62; 歴代誌上 9:1"> アルタクセルクセス王の治世に、バビロンから私とともに上って来た者たちの父祖の家の長たちと、その系図は次のとおりである。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代誌上 3:22; 歴代誌上 3:1; 歴代誌上 6:3–15"> ピネハスの子らのうちからはゲルショム。 イタマルの子らのうちからはダニエル。 ダビデの子らのうちからはハトシュ。</span>
<span className="v" id="v3" data-v="3" data-xref="エズラ記 2:3; ネヘミヤ記 10:14; ネヘミヤ記 7:8"> シェカニヤの子ら、すなわちパロシュの子らのうちからはゼカリヤ。彼とともに男子百五十人が系図に登録されていた。</span>
<span className="v" id="v4" data-v="4" data-xref="エズラ記 2:6; ネヘミヤ記 10:14; ネヘミヤ記 7:11"> パハテ・モアブの子らのうちからはゼラフヤの子エリオエナイ。彼とともに男子二百人。</span>
<span className="v" id="v5" data-v="5"> シェカニヤの子らのうちからはヤハジエルの子。彼とともに男子三百人。</span>
<span className="v" id="v6" data-v="6" data-xref="エズラ記 2:15; ネヘミヤ記 10:16; ネヘミヤ記 7:20"> アディンの子らのうちからはヨナタンの子エベド。彼とともに男子五十人。</span>
<span className="v" id="v7" data-v="7" data-xref="エズラ記 2:31; ネヘミヤ記 7:34; エズラ記 2:7"> エラムの子らのうちからはアタルヤの子エシャヤ。彼とともに男子七十人。</span>
<span className="v" id="v8" data-v="8" data-xref="ネヘミヤ記 11:4; エズラ記 2:4; ネヘミヤ記 7:9"> シェファティヤの子らのうちからはミカエルの子ゼバデヤ。彼とともに男子八十人。</span>
<span className="v" id="v9" data-v="9" data-xref="ネヘミヤ記 7:11; エズラ記 2:6"> ヨアブの子らのうちからはエヒエルの子オバデヤ。彼とともに男子二百十八人。</span>
<span className="v" id="v10" data-v="10"> シェロミテの子らのうちからはヨシフヤの子。彼とともに男子百六十人。</span>
<span className="v" id="v11" data-v="11" data-xref="エズラ記 10:28; ネヘミヤ記 7:16; エズラ記 2:11"> ベバイの子らのうちからはベバイの子ゼカリヤ。彼とともに男子二十八人。</span>
<span className="v" id="v12" data-v="12" data-xref="エズラ記 2:12; ネヘミヤ記 7:17"> アズガドの子らのうちからはハカタンの子ヨハナン。彼とともに男子百十人。</span>
<span className="v" id="v13" data-v="13" data-xref="エズラ記 2:13; ネヘミヤ記 7:18"> アドニカムの子らのうち、最後に来た者たちはエリフェレテ、エウエル、シェマヤ。彼らとともに男子六十人。</span>
<span className="v" id="v14" data-v="14" data-xref="ネヘミヤ記 10:12; エズラ記 2:14; ネヘミヤ記 7:19"> ビグワイの子らのうちからはウタイとザブド。彼らとともに男子七十人。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エズラ記 8:21; エズラ記 8:31; エズラ記 7:7"> 私は彼らをアハワへ流れる川のほとりに集め、そこに三日間宿営した。民と祭司たちを調べたところ、レビの子らが一人もいなかった。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 2:6; エズラ記 8:18; エズラ記 10:39"> そこで私は、指導者であるエリエゼル、アリエル、シェマヤ、エルナタン、ヤリブ、エルナタン、ナタン、ゼカリヤ、メシュラムを呼び、また教師であるヨヤリブとエルナタンを呼んだ。</span>
<span className="v" id="v17" data-v="17" data-xref="エズラ記 2:43; 出エジプト記 4:15; 民数記 8:22–26"> 私は彼らをカシフヤという場所の長イドのもとへ遣わし、イドと、カシフヤにいるその同族の宮のしもべたちに伝えるべきことばを授けた。私たちの神の家に仕える者たちを連れて来させるためであった。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 3:15; エズラ記 7:28; ネヘミヤ記 2:8"> 私たちの神の恵み深い御手が私たちの上にあったので、彼らはイスラエルの子レビ、その子マフリの子孫から、思慮ある人シェレブヤと、その子らや兄弟たち十八人を連れて来た。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代誌上 6:1; 歴代誌上 6:16; ネヘミヤ記 10:11"> またハシャブヤと、彼とともにメラリの子らのうちからエシャヤ、その兄弟たちとその子ら二十人、</span>
<span className="v" id="v20" data-v="20" data-xref="エズラ記 2:43; エズラ記 7:7; 歴代誌上 9:2"> さらに、ダビデと君たちがレビ人の奉仕のために任命した宮のしもべたちの中から、二百二十人を連れて来た。全員が名指しで選ばれた者であった。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歴代誌 第二 20:3; ヨエル書 1:14; サムエル記第一 7:6"> そのとき私はアハワ川のほとりで断食を布告した。私たちが神の御前にへりくだり、自分たちと幼い子どもたち、すべての財産のために、まっすぐな道を神に願い求めるためであった。</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの手紙第一 3:12; 詩篇 33:18–19; 歴代誌 第二 16:9"> 道中の敵から私たちを守る歩兵と騎兵の部隊を王に求めることを、私は恥じた。私たちは王に、「私たちの神の御手は、神を求めるすべての者に恵みを施す。しかし、その力と怒りは神を捨てるすべての者に向けられる」と語っていたからである。</span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 29:12–13; マタイ 7:7–8; エズラ記 8:31"> そこで私たちは断食し、このことを神に願い求めた。すると神は私たちの願いを聞き入れてくださった。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="エズラ記 8:18–19"> その後、私は祭司の長たちのうちから十二人、すなわちシェレブヤ、ハシャブヤと、その兄弟たち十人を選び分け、</span>
<span className="v" id="v25" data-v="25" data-xref="エズラ記 8:33; エズラ記 7:14–16; エズラ記 1:8"> 王、その顧問たち、君たち、またそこにいた全イスラエルが私たちの神の家のために献げた銀、金、器を量って彼らに渡した。</span>
<span className="v" id="v26" data-v="26" data-xref="エズラ記 1:9–11"> 私は彼らの手に、銀六百五十タラント<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一タラントは約30キログラム、66ポンド、または965トロイオンスである。">a</a></sup>、重さ百タラントの銀の器、金百タラントを量って渡し、</span>
<span className="v" id="v27" data-v="27" data-xref="哀歌 4:2"> また重さ千ダリク<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ダリクはペルシア王が発行した金貨で、一枚は約8.4グラム、または約0.27トロイオンスである。">b</a></sup>の金の鉢二十個と、金のように高価な、精錬されて輝く青銅の器二つを渡した。</span>
<span className="v" id="v28" data-v="28" data-xref="レビ記 22:2–3; レビ記 21:6–8; 歴代誌上 23:28"> 私は彼らに言った。「あなたがたは主に聖なる者であり、これらの器も聖なるものである。銀と金は、あなたがたの父祖の神、主への自発のささげ物である。</span>
<span className="v" id="v29" data-v="29" data-xref="エズラ記 8:33–34; マルコ 13:34–35; 歴代誌上 26:20–26"> エルサレムにある主の家の部屋で、祭司とレビ人の長たち、イスラエルの父祖の家の長たちの前で量るまで、注意深く守り保て。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="エズラ記 8:22; 歴代誌上 29:2–3; イザヤ書 60:13"> こうして祭司たちとレビ人たちは、エルサレムにある私たちの神の家へ運ぶため、量り渡された銀、金、器を受け取った。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="エズラ記 8:21–22; エズラ記 7:9; エズラ記 8:15"> 私たちは第一の月の十二日にアハワ川を出発し、エルサレムへ向かった。私たちの神の御手が私たちの上にあり、神は道中の敵と待ち伏せする者の手から私たちを救い出された。</span>
<span className="v" id="v32" data-v="32" data-xref="ネヘミヤ記 2:11; エズラ記 7:8–9"> 私たちはエルサレムに着き、そこに三日間滞在した。</span>
<span className="v" id="v33" data-v="33" data-xref="ネヘミヤ記 3:4; ネヘミヤ記 3:21; エズラ記 8:30"> 四日目に、私たちの神の家で銀、金、器を量り、祭司ウリヤの子メレモテの手に渡した。彼とともにピネハスの子エルアザルが、また彼らとともにレビ人であるエシュアの子ヨザバドとビンヌイの子ノアデヤがいた。</span>
<span className="v" id="v34" data-v="34"> すべてを数え、量り、その総重量をその時に書き記した。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="エズラ記 6:17; 歴代誌 第二 29:31–32; 詩篇 66:10–15"> 捕囚から帰った者たちは、全イスラエルのために雄牛十二頭、雄羊九十六頭、子羊七十七匹、また罪のきよめのささげ物として雄ヤギ十二頭をイスラエルの神にささげた。これらはすべて主への全焼のいけにえであった。</span>
<span className="v" id="v36" data-v="36" data-xref="エズラ記 7:21–24; エズラ記 4:7–23; エズラ記 6:13"> 彼らは王の命令書を、王の太守たちと川の向こう側の総督たちに渡した。すると彼らは民と神の家を支援した。</span>
</div>

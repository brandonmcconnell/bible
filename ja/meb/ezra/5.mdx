<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ゼカリヤ書 4:6–10; ハガイ書 1:1; ゼカリヤ書 1:1–21"> 預言者ハガイとイドの子である預言者ゼカリヤは、ユダとエルサレムにいたユダヤ人たちに、イスラエルの神の名によって預言した。</span>
<span className="v" id="v2" data-v="2" data-xref="エズラ記 3:2; エズラ記 6:14; ゼカリヤ書 3:1–4"> そこでシェアルティエルの子ゼルバベルと、エホツァダクの子エシュアが立ち上がり、エルサレムにある神の家を建て始めた。彼らとともに神の預言者たちがいて、彼らを助けた。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="エズラ記 6:6; エズラ記 6:13; エズラ記 5:9"> そのころ、川の向こう側の総督タテナイが、シェタル・ボゼナイとその同僚たちを伴って来て、彼らに尋ねた。「だれがあなたがたに、この家を建て、この城壁を完成させる許可を与えたのか。」</span>
<span className="v" id="v4" data-v="4"> 彼らはまた、この建物を建てている者たちの名を尋ねた。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 33:18; エズラ記 7:6; エズラ記 7:28"> しかし、彼らの神の目がユダヤ人の長老たちに注がれていたので、総督たちは工事を中止させなかった。事がダレイオスに報告され、この件について書面の返答が届くのを待ったのである。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エズラ記 4:9; エズラ記 4:11; エズラ記 6:6"> これは、川の向こう側の総督タテナイ、シェタル・ボゼナイ、川の向こう側にいたその同僚であるアファルサク人たちが、ダレイオス王に送った手紙の写しである。</span>
<span className="v" id="v7" data-v="7" data-xref="エズラ記 4:17; ダニエル書 6:21; テサロニケ人への第二の手紙 3:16"> 彼らが王に送った手紙には、次のように記されていた。<br />「ダレイオス王へ。どうかすべての平安がありますように。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ネヘミヤ記 7:6; マルコ 13:1–2; ダニエル書 3:26"> 王にお知らせします。私たちはユダ州に入り、大いなる神の家へ行きました。その家は大石で建てられ、壁には木材が組み込まれています。工事は熱心に進められ、順調に進展しています。</span>
<span className="v" id="v9" data-v="9" data-xref="エズラ記 5:3–4"> そこで私たちは長老たちに、『だれがあなたがたに、この家を建て、この城壁を完成させる許可を与えたのか』と尋ねました。</span>
<span className="v" id="v10" data-v="10"> また、その指導者たちの名を書いて王にお知らせするため、彼らの名も尋ねました。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 6:16; ヨナ書 1:9; 使徒の働き 27:23"> すると彼らは、こう答えました。『私たちは天と地の神のしもべであり、はるか昔に建てられた家を建て直しています。それはイスラエルの偉大な王が建て、完成させた家です。</span>
<span className="v" id="v12" data-v="12" data-xref="歴代誌 第二 36:16–17; ダニエル書 9:5; 列王記第二 24:2"> しかし、私たちの父祖たちが天の神の御怒りを招いたため、神は彼らをカルデア人であるバビロン王ネブカドネザルの手に渡されました。王はこの家を破壊し、民を捕虜としてバビロンへ連れ去りました。</span>
<span className="v" id="v13" data-v="13" data-xref="エズラ記 6:3–5; イザヤ書 44:28–1; エズラ記 1:1–8"> しかし、バビロンの王クロスの第一年に、クロス王はこの神の家を建てるための認可を与えました。</span>
<span className="v" id="v14" data-v="14" data-xref="エズラ記 6:5; ダニエル書 5:2–3; エズラ記 5:16"> さらに、ネブカドネザルがエルサレムにあった神殿から取り出してバビロンの神殿に持ち込んだ神の家の金と銀の器も、クロス王がバビロンの神殿から取り出し、彼が総督に任じたシェシュバツァルという名の人に引き渡されました。</span>
<span className="v" id="v15" data-v="15" data-xref="エズラ記 6:3; エズラ記 1:2; エズラ記 3:3"> クロス王は彼に、「これらの器を携えて行き、エルサレムの神殿に納めよ。神の家を元の場所に建てよ」と命じました。</span>
<span className="v" id="v16" data-v="16" data-xref="エズラ記 3:10; エズラ記 6:15; エズラ記 3:8"> そこでシェシュバツァルは来て、エルサレムにある神の家の土台を据えました。建築はその時から今まで続いていますが、まだ完成していません。』</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="エズラ記 4:15; 箴言 25:2; エズラ記 6:1–5"> それゆえ今、もし王がよしとされるなら、バビロンにある王の宝物倉を調べさせ、エルサレムにこの神の家を建てる許可が本当にクロス王から出されたかどうかをご確認ください。そして、この件について王のご意向をお知らせください。」</span>
</div>
</div>

<span className="v" id="v2" data-v="2" data-xref="ハガイ書 1:14; ネヘミヤ記 7:7; ハガイ書 2:4"> 彼らはゼルバベル、エシュア、ネヘミヤ、セラヤ、レエラヤ、モルデカイ、ビルシャン、ミスパル、ビグワイ、レフム、バアナとともに来た。<br />イスラエルの民の男子の数は次のとおりである。</span>
<span className="v" id="v3" data-v="3" data-xref="エズラ記 8:3; エズラ記 10:25; ネヘミヤ記 7:8"> パロシュの子らは二千百七十二人。</span>
<span className="v" id="v4" data-v="4" data-xref="ネヘミヤ記 7:9; エズラ記 8:8"> シェファティヤの子らは三百七十二人。</span>
<span className="v" id="v5" data-v="5" data-xref="ネヘミヤ記 7:10; ネヘミヤ記 6:18"> アラの子らは七百七十五人。</span>
<span className="v" id="v6" data-v="6" data-xref="ネヘミヤ記 7:11; エズラ記 10:30; エズラ記 8:9"> パハテ・モアブの子ら、すなわちエシュアとヨアブの子らは二千八百十二人。</span>
<span className="v" id="v7" data-v="7" data-xref="エズラ記 10:26; エズラ記 2:31; ネヘミヤ記 7:12"> エラムの子らは千二百五十四人。</span>
<span className="v" id="v8" data-v="8" data-xref="ネヘミヤ記 7:13; エズラ記 10:27"> ザトの子らは九百四十五人。</span>
<span className="v" id="v9" data-v="9" data-xref="ネヘミヤ記 7:14"> ザカイの子らは七百六十人。</span>

<span className="v" id="v11" data-v="11" data-xref="エズラ記 10:28; ネヘミヤ記 7:16; エズラ記 8:11"> ベバイの子らは六百二十三人。</span>
<span className="v" id="v12" data-v="12" data-xref="ネヘミヤ記 7:17; エズラ記 8:12"> アズガドの子らは千二百二十二人。</span>
<span className="v" id="v13" data-v="13" data-xref="エズラ記 8:13; ネヘミヤ記 7:18"> アドニカムの子らは六百六十六人。</span>
<span className="v" id="v14" data-v="14" data-xref="エズラ記 8:14; ネヘミヤ記 7:19"> ビグワイの子らは二千五十六人。</span>
<span className="v" id="v15" data-v="15" data-xref="ネヘミヤ記 7:20; エズラ記 8:6"> アディンの子らは四百五十四人。</span>
<span className="v" id="v16" data-v="16" data-xref="ネヘミヤ記 7:21"> ヒゼキヤに属するアテルの子らは九十八人。</span>

<span className="v" id="v18" data-v="18" data-xref="ネヘミヤ記 7:24"> ヨラの子らは百十二人。</span>
<span className="v" id="v19" data-v="19" data-xref="ネヘミヤ記 7:22; エズラ記 10:33"> ハシュムの子らは二百二十三人。</span>
<span className="v" id="v20" data-v="20" data-xref="ネヘミヤ記 7:25"> ギバルの子らは九十五人。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代誌上 2:50–52"> ベツレヘムの子らは百二十三人。</span>
<span className="v" id="v22" data-v="22" data-xref="ネヘミヤ記 7:26; サムエル記第二 23:28; エレミヤ書 40:8"> ネトファの人々は五十六人。</span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 1:1; ヨシュア記 21:18; エレミヤ書 11:21"> アナトテの人々は百二十八人。</span>
<span className="v" id="v24" data-v="24" data-xref="ネヘミヤ記 7:28"> アズマベテの子らは四十二人。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 9:17; ネヘミヤ記 7:29"> キルヤテ・エアリム、ケフィラ、ベエロテの子らは七百四十三人。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨシュア記 18:24–25; ネヘミヤ記 7:30"> ラマとゲバの子らは六百二十一人。</span>
<span className="v" id="v27" data-v="27" data-xref="サムエル記第一 13:23; サムエル記第一 13:5; イザヤ書 10:28"> ミクマスの人々は百二十二人。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 12:8; ネヘミヤ記 7:33; ヨシュア記 8:9"> ベテルとアイの人々は二百二十三人。</span>
<span className="v" id="v29" data-v="29" data-xref="エレミヤ書 48:1; 申命記 32:49; ネヘミヤ記 7:33"> ネボの子らは五十二人。</span>
<span className="v" id="v30" data-v="30"> マグビシュの子らは百五十六人。</span>
<span className="v" id="v31" data-v="31" data-xref="エズラ記 2:7; ネヘミヤ記 7:34"> もう一方のエラムの子らは千二百五十四人。</span>
<span className="v" id="v32" data-v="32" data-xref="エズラ記 10:31; ネヘミヤ記 7:35"> ハリムの子らは三百二十人。</span>
<span className="v" id="v33" data-v="33" data-xref="ネヘミヤ記 11:34–35; ネヘミヤ記 6:2; 歴代誌上 8:12"> ロド、ハディド、オノの子らは七百二十五人。</span>
<span className="v" id="v34" data-v="34" data-xref="列王記第一 16:34; 歴代誌 第二 28:15; ネヘミヤ記 7:36"> エリコの子らは三百四十五人。</span>
<span className="v" id="v35" data-v="35" data-xref="ネヘミヤ記 7:38"> セナアの子らは三千六百三十人。</span>
</div>

<span className="v" id="v37" data-v="37" data-xref="歴代誌上 24:14; エズラ記 10:20; ネヘミヤ記 7:40"> イメルの子らは千五十二人。</span>
<span className="v" id="v38" data-v="38" data-xref="歴代誌上 9:12; ネヘミヤ記 7:41; エズラ記 10:22"> パシュフルの子らは千二百四十七人。</span>
<span className="v" id="v39" data-v="39" data-xref="歴代誌上 24:8; エズラ記 10:21; ネヘミヤ記 7:42"> ハリムの子らは千十七人。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="エズラ記 3:9; ネヘミヤ記 7:43"> レビ人は次のとおりである。ホダブヤの子らのうち、エシュアとカドミエルの子らは七十四人。</span>
<span className="v" id="v41" data-v="41" data-xref="歴代誌上 6:39; 歴代誌上 15:17; 歴代誌上 25:1–2"> 歌うたいたちは次のとおりである。アサフの子らは百二十八人。</span>
<span className="v" id="v42" data-v="42" data-xref="ネヘミヤ記 7:45; 歴代誌上 9:17; 歴代誌上 26:1–19"> 門衛の子らは次のとおりである。シャルムの子ら、アテルの子ら、タルモンの子ら、アクブの子ら、ハティタの子ら、ショバイの子ら。すべてで百三十九人。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="歴代誌上 9:2; ネヘミヤ記 10:28; ネヘミヤ記 7:46–56"> 宮のしもべたちは次のとおりである。ツィハの子ら、ハスファの子ら、タバオテの子ら、</span>
<span className="v" id="v44" data-v="44" data-xref="ネヘミヤ記 7:47"> ケロスの子ら、シアハの子ら、パドンの子ら、</span>
<span className="v" id="v45" data-v="45" data-xref="ネヘミヤ記 7:48"> レバナの子ら、ハガバの子ら、アクブの子ら、</span>
<span className="v" id="v46" data-v="46"> ハガブの子ら、シャムライの子ら、ハナンの子ら、</span>
<span className="v" id="v47" data-v="47"> ギデルの子ら、ガハルの子ら、レアヤの子ら、</span>
<span className="v" id="v48" data-v="48"> レツィンの子ら、ネコダの子ら、ガザムの子ら、</span>
<span className="v" id="v49" data-v="49" data-xref="ネヘミヤ記 7:51"> ウザの子ら、パセアの子ら、ベツァイの子ら、</span>
<span className="v" id="v50" data-v="50" data-xref="ネヘミヤ記 7:52"> アスナの子ら、メウニムの子ら、ネフィシムの子ら、</span>
<span className="v" id="v51" data-v="51"> バクブクの子ら、ハクファの子ら、ハルフルの子ら、</span>
<span className="v" id="v52" data-v="52" data-xref="ネヘミヤ記 7:54"> バツルテの子ら、メヒダの子ら、ハルシャの子ら、</span>
<span className="v" id="v53" data-v="53" data-xref="ネヘミヤ記 7:55"> バルコスの子ら、シセラの子ら、テマの子ら、</span>
<span className="v" id="v54" data-v="54"> ネツィアの子ら、ハティファの子ら。</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="列王記第一 9:21; ネヘミヤ記 7:57"> ソロモンのしもべたちの子らは次のとおりである。ソタイの子ら、ハソフェレテの子ら、ペルダの子ら、</span>
<span className="v" id="v56" data-v="56" data-xref="ネヘミヤ記 7:58"> ヤアラの子ら、ダルコンの子ら、ギデルの子ら、</span>
<span className="v" id="v57" data-v="57" data-xref="ネヘミヤ記 7:59"> シェファティヤの子ら、ハティルの子ら、ポケレテ・ハツェバイムの子ら、アミの子ら。</span>
<span className="v" id="v58" data-v="58" data-xref="歴代誌上 9:2; 列王記第一 9:21; ヨシュア記 9:23"> すべての宮のしもべたち、およびソロモンのしもべたちの子らは、合わせて三百九十二人であった。</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="ネヘミヤ記 7:61"> テル・メラ、テル・ハルシャ、ケルブ、アダン、イメルから上って来た者たちのうち、父祖の家や血筋<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「種」。">a</a></sup>がイスラエルに属することを証明できなかった者は次のとおりである。</span>
<span className="v" id="v60" data-v="60" data-xref="ネヘミヤ記 7:62"> デラヤの子ら、トビヤの子ら、ネコダの子らは六百五十二人。</span>
<span className="v" id="v61" data-v="61" data-xref="サムエル記第二 17:27; 列王記第一 2:7; サムエル記第二 19:31–39"> 祭司の子らのうちでは、ハバヤの子ら、ハコツの子ら、バルジライの子ら。このバルジライはギルアデ人バルジライの娘を妻に迎え、その妻の家名で呼ばれていた。</span>
<span className="v" id="v62" data-v="62" data-xref="民数記 3:10; 民数記 16:39–40; レビ記 21:21–23"> 彼らは系図に登録された者たちの中から自分たちの記録を捜したが、見つからなかった。そのため祭司として不適格とされ、祭司職から退けられた。</span>
<span className="v" id="v63" data-v="63" data-xref="レビ記 2:10; レビ記 2:3; 出エジプト記 28:30"> 総督は彼らに、ウリムとトンミムを用いる祭司が立つまでは、最も聖なるものを食べてはならないと告げた。</span>
</div>
<div className="bp">
<span className="v" id="v64" data-v="64" data-xref="エレミヤ書 23:3; エズラ記 9:8; ネヘミヤ記 7:66–69"> 会衆はみな合わせて四万二千三百六十人であった。</span>
<span className="v" id="v65" data-v="65" data-xref="サムエル記第二 19:35; ネヘミヤ記 7:67; マタイ 9:23"> このほかに、彼らの男女の奴隷が七千三百三十七人おり、また歌うたいの男女が二百人いた。</span>
<span className="v" id="v66" data-v="66"> 彼らの馬は七百三十六頭、騾馬は二百四十五頭、</span>
<span className="v" id="v67" data-v="67"> らくだは四百三十五頭、ろばは六千七百二十頭であった。</span>
</div>
<div className="bp">
<span className="v" id="v68" data-v="68" data-xref="コリント人への第二の手紙 9:7; コリント人への第二の手紙 8:3; 出エジプト記 35:29"> 父祖の家の長たちのうち何人かは、エルサレムにある主の家に着くと、神の家を元の場所に建てるため、自発のささげ物をした。</span>
<span className="v" id="v69" data-v="69" data-xref="エズラ記 8:25–34; ネヘミヤ記 7:71–72; 歴代誌上 22:14"> 彼らはそれぞれの力に応じて、工事のための宝物庫に、金六万一千ダリク<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ダリクはペルシア王が発行した金貨で、一枚は約8.4グラム、または約0.27トロイオンスである。">b</a></sup>、銀五千ミナ<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一ミナは約600グラム、または約1.3米ポンドである。五千ミナは約3メートルトンになる。">c</a></sup>、祭司の衣百着を納めた。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ペテロの手紙第一 2:8; マタイ 13:21; マタイ 26:31–33"> <span className="woj">「私がこれらのことをあなたがたに話したのは、あなたがたがつまずかないためです。</span></span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネ 9:22; 使徒の働き 26:9–11; ローマ人への手紙 10:2–3"> <span className="woj">人々はあなたがたを会堂から追放します。実際、あなたがたを殺す者が皆、それによって神に奉仕していると思う時が来ます。</span></span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネ 15:21; ヨハネ 17:25; ヨハネ 8:55"> <span className="woj">人々がこれらのことをするのは、</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TRは「あなたがたに」を加えている。">a</a></sup><span className="woj">父も私も知らなかったからです。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネ 14:29; マルコ 13:23; ヨハネ 17:12–13"> <span className="woj">しかし、私がこれらのことをあなたがたに話したのは、その時が来た時、私が話しておいたことをあなたがたが思い出すためです。初めからこれらのことを話さなかったのは、私があなたがたとともにいたからです。</span></span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネ 13:36; ヨハネ 7:33; ヨハネ 16:28"> <span className="woj">しかし今、私は私を遣わされた方のもとへ行きます。それでも、あなたがたのうちだれも『どこへ行くのですか』とは尋ねません。</span></span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 14:1; ヨハネ 16:20–22; ルカ 24:17"> <span className="woj">むしろ、私がこれらのことを話したために、あなたがたの心は悲しみで満たされています。</span></span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネ 14:26; ヨハネ 14:16–17; ヨハネ 15:26"> <span className="woj">しかし、私はあなたがたに真実を告げます。私が去って行くことは、あなたがたのためになるのです。私が去って行かなければ、助け主はあなたがたのところに来ません。しかし、私が行けば、その方をあなたがたに遣わします。</span></span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 2:37; ユダ 1:15; ゼカリヤ書 12:10"> <span className="woj">その方が来ると、罪について、義について、裁きについて、世にその誤りを悟らせます。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネ 15:22–25; ヨハネ 8:23–24; ヨハネ 12:47–48"> <span className="woj">罪についてとは、彼らが私を信じないからです。</span></span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第二の手紙 5:21; ペテロの手紙第一 3:18; ローマ人への手紙 10:3–4"> <span className="woj">義についてとは、私が父のもとへ行き、あなたがたがもはや私を見なくなるからです。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネ 12:31; ヨハネの手紙第一 3:8; ヘブル人への手紙 2:14"> <span className="woj">裁きについてとは、この世の支配者が裁かれたからです。」</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マルコ 4:33; ヨハネ 15:15; コリント人への第一の手紙 3:1–2"> <span className="woj">「私にはまだ、あなたがたに話すことがたくさんありますが、あなたがたは今、それに耐えることができません。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネ 14:26; コリント人への第一の手紙 2:10–13; ヨハネ 14:17"> <span className="woj">しかし、真理の霊であるその方が来ると、あなたがたをすべての真理へと導きます。その方は自分から語るのではなく、聞いたことを語り、これから起こることをあなたがたに告げるからです。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの手紙第一 4:13–14; コリント人への第二の手紙 3:14–18; ヨハネ 15:26"> <span className="woj">その方は私に栄光を与えます。私のものを受けて、あなたがたに告げるからです。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネ 17:10; マタイ 11:27; ヨハネ 3:35"> <span className="woj">父が持っておられるものはすべて私のものです。それで、その方が私のものを受けて</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TRは「受ける」の代わりに「受けるであろう」としている。">b</a></sup><span className="woj">あなたがたに告げると、私は言ったのです。」</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヨハネ 7:33; 使徒の働き 1:3; ヨハネ 14:18–24"> <span className="woj">「もうしばらくすると、あなたがたは私を見なくなります。そして、さらにしばらくすると、私を見ます。」</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヨハネ 16:16; マルコ 9:32; ヨハネ 16:5"> そこで弟子たちの何人かが互いに言った。「私たちに、<span className="woj">『もうしばらくすると、あなたがたは私を見なくなる。そして、さらにしばらくすると、私を見る』</span>、また<span className="woj">『私が父のもとへ行くからだ』</span>と言われるが、これはどういうことだろう。」</span>
<span className="v" id="v18" data-v="18" data-xref="ルカ 24:25; マタイ 16:9–11; ヘブル人への手紙 5:12"> 彼らは言った。「<span className="woj">『もうしばらくすると』</span>と言われるのは、どういうことだろう。何を言っておられるのか分からない。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨハネ 16:30; ヨハネ 16:16; ヨハネ 14:19"> イエスは、彼らが尋ねたがっていることに気づいて、彼らに言われた。<span className="woj">「私が『もうしばらくすると、あなたがたは私を見なくなり、さらにしばらくすると、私を見る』と言ったことについて、互いに尋ね合っているのですか。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ヤコブの手紙 1:2; マタイ 5:4; 詩篇 126:5–6"> <span className="woj">まことに、まことに、あなたがたに告げます。あなたがたは泣き悲しみますが、世は喜びます。あなたがたは悲しみますが、その悲しみは喜びに変わります。</span></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 113:9; イザヤ書 13:8; テサロニケ人への手紙第一 5:3"> <span className="woj">女は出産する時、その時が来たので苦しみます。しかし子どもを産むと、人がこの世に生まれた喜びのために、その苦痛をもう覚えていません。</span></span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの手紙第一 1:8; 使徒の働き 13:52; ヨハネ 16:6"> <span className="woj">ですから、あなたがたも今は悲しんでいます。しかし、私は再びあなたがたに会います。そうすれば、あなたがたの心は喜び、だれもその喜びをあなたがたから奪いません。」</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ヨハネ 15:7; ヨハネ 14:13–14; マタイ 21:22"> <span className="woj">「その日には、あなたがたは私に何も尋ねません。まことに、まことに、あなたがたに告げます。あなたがたが私の名によって父に求めるものは何でも、父は与えてくださいます。</span></span>
<span className="v" id="v24" data-v="24" data-xref="マタイ 7:7–8; ヤコブの手紙 4:2–3; ヨハネ 15:11"> <span className="woj">今まで、あなたがたは私の名によって何も求めませんでした。求めなさい。そうすれば受けます。あなたがたの喜びが満ちあふれるためです。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ヨハネ 16:12; マルコ 4:13; マタイ 13:34–35"> <span className="woj">「私はこれらのことを比喩であなたがたに話しました。しかし、もはや比喩では話さず、父についてはっきり告げる時が来ます。</span></span>
<span className="v" id="v26" data-v="26" data-xref="ローマ人への手紙 8:34; ヨハネ 17:24; ヨハネ 17:19"> <span className="woj">その日には、あなたがたは私の名によって求めます。私があなたがたのために父にお願いするとは言いません。</span></span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネ 14:21; ヨハネ 14:23; ヨハネ 17:23"> <span className="woj">父ご自身があなたがたを愛しておられるからです。それは、あなたがたが私を愛し、私が神から来たと信じたからです。</span></span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネ 13:1; ヨハネ 13:3; ヨハネ 8:14"> <span className="woj">私は父から出て、この世に来ました。そして再び世を去り、父のもとへ行きます。」</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ヨハネ 16:25"> 弟子たちはイエスに言った。「見よ、今ははっきりと話し、比喩を使っておられません。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネ 21:17; ヨハネ 17:8; ヨハネ 16:17"> 今、私たちは、あなたがすべてをご存じで、だれかに尋ねてもらう必要がないことを知っています。それによって、あなたが神から来られたと信じます。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ルカ 9:44–45; ヨハネ 13:38"> イエスは彼らに答えられた。<span className="woj">「今、信じているのですか。</span></span>
<span className="v" id="v32" data-v="32" data-xref="ゼカリヤ書 13:7; マタイ 26:31; ヨハネ 8:29"> <span className="woj">見よ、あなたがたがそれぞれ自分の所へ散らされ、私を一人残す時が来ます。いや、すでに来ています。しかし私は一人ではありません。父が私とともにおられるからです。</span></span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネ 14:27; ヨハネの手紙第一 5:4; テサロニケ人への第二の手紙 3:16"> <span className="woj">私がこれらのことをあなたがたに話したのは、あなたがたが私にあって平安を得るためです。世にあって、あなたがたには苦難があります。しかし、勇気を出しなさい。私は世に勝ったのです。」</span></span>
</div>

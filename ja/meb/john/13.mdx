<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネ 12:23; ヨハネの手紙第一 4:19; ヨハネ 13:34"> さて、過越の祭りの前、イエスはこの世を去って父のもとへ行くご自分の時が来たことを知り、世にいるご自分の者たちを愛して、最後まで彼らを愛し抜かれた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヤコブの手紙 1:13–17; 使徒の働き 5:3; ヨハネ 13:26–27"> 夕食の最中、悪魔はすでに、シモンの子ユダ・イスカリオテの心に、イエスを裏切る思いを植えつけていた。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネ 3:35; マタイ 11:27; ヘブル人への手紙 1:2"> イエスは、父がすべてのものをご自分の手に与えられたこと、ご自分が神から来て神のもとへ行くことを知って、</span>
<span className="v" id="v4" data-v="4" data-xref="ルカ 22:27; コリント人への第二の手紙 8:9; ルカ 12:37"> 夕食の席から立ち上がり、上着を脱がれた。そして手ぬぐいを取り、腰に巻かれた。</span>
<span className="v" id="v5" data-v="5" data-xref="ルカ 7:44; 詩篇 51:2; 創世記 18:4"> それから、たらいに水を注ぎ、弟子たちの足を洗い、腰に巻いた手ぬぐいで拭き始められた。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイ 3:11–14; ヨハネ 1:27; ルカ 5:8"> こうしてシモン・ペテロのところに来られた。ペテロはイエスに言った。「主よ、あなたが私の足を洗われるのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ダニエル書 12:8; ヨハネ 12:16; ヨハネ 14:26"> イエスは彼に答えられた。<span className="woj">「私がしていることは、今はあなたには分かりませんが、後で分かるようになります。」</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 36:25; 使徒の働き 22:16; テトス 3:5"> ペテロはイエスに言った。「決して私の足をお洗いにならないでください。」<br />イエスは彼に答えられた。<span className="woj">「私があなたを洗わなければ、あなたは私と何の関わりもありません。」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="詩篇 51:7; 詩篇 51:2; ペテロの手紙第一 3:21"> シモン・ペテロはイエスに言った。「主よ、足だけでなく、手も頭も洗ってください。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ヨハネ 15:3; コリント人への第二の手紙 7:1; コリント人への第二の手紙 5:17"> イエスは彼に言われた。<span className="woj">「すでに体を洗った者は、足を洗うだけでよく、全身が清いのです。あなたがたは清いのですが、全員が清いわけではありません。」</span></span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネ 13:26; ヨハネ 13:2; ヨハネ 13:21"> イエスは、ご自分を裏切ろうとしている者を知っておられた。それで、<span className="woj">「あなたがた全員が清いわけではありません」</span>と言われたのである。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネ 13:7; ヨハネ 13:4; エゼキエル書 24:24"> イエスは弟子たちの足を洗い、上着を着て、再び席に着くと、彼らに言われた。<span className="woj">「私があなたがたにしたことが分かりますか。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ルカ 6:46; コリント人への第一の手紙 12:3; ヨハネ 11:28"> <span className="woj">あなたがたは私を『先生』また『主』と呼びます。そう言うのは正しい。私はそのとおりだからです。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ペテロの手紙第一 5:5; 使徒の働き 20:35; ローマ人への手紙 12:16"> <span className="woj">主であり先生である私があなたがたの足を洗ったのですから、あなたがたも互いに足を洗い合うべきです。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの手紙第一 2:6; マタイ 11:29; ペテロの手紙第一 3:17–18"> <span className="woj">私があなたがたにしたとおり、あなたがたもするようにと、私は模範を示したのです。</span></span>
<span className="v" id="v16" data-v="16" data-xref="ルカ 6:40; ヨハネ 15:20; マタイ 10:24–25"> <span className="woj">まことに、まことに、あなたがたに告げます。僕はその主人より偉大ではなく、遣わされた者は遣わした者より偉大ではありません。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ルカ 11:28; ヤコブの手紙 4:17; ヤコブの手紙 1:25"> <span className="woj">これらのことを知り、それを行うなら、あなたがたは幸いです。</span></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 41:9; マタイ 26:23; ヨハネ 17:12"> <span className="woj">私はあなたがた全員について言っているのではありません。私は自分が選んだ者たちを知っています。しかし、それは『私とともにパンを食べる者が、私に向かってかかとを上げた』という聖書の言葉が実現するためです。</span></span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 43:10; ヨハネ 14:29; ヨハネ 16:4"> <span className="woj">今、そのことが起こる前に、あなたがたに告げておきます。それが起こった時、私がその者であるとあなたがたが信じるためです。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ルカ 10:16; ルカ 9:48; マタイ 25:40"> <span className="woj">まことに、まことに、あなたがたに告げます。私が遣わす者を受け入れる者は、私を受け入れます。私を受け入れる者は、私を遣わされた方を受け入れるのです。」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ヨハネ 13:18; マタイ 26:21; マルコ 14:18"> イエスはこう言われると、霊の内に心を騒がせ、はっきりと言われた。<span className="woj">「まことに、まことに、あなたがたに告げます。あなたがたのうちの一人が私を裏切ります。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ルカ 22:23; マタイ 26:22; マルコ 14:19"> 弟子たちは、だれのことを言われたのか分からず、戸惑いながら互いに顔を見合わせた。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネ 19:26; ヨハネ 21:7; ヨハネ 21:20"> 弟子の一人で、イエスが愛しておられた者が、食卓でイエスの胸もとに寄りかかっていた。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 12:17; ルカ 1:22; 使徒の働き 13:16"> そこでシモン・ペテロは彼に合図をして、「だれのことを言っておられるのか、尋ねてくれ」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ヨハネ 21:20; 創世記 44:4–12; エステル記 7:5"> 彼はそのままイエスの胸もとに寄りかかり、「主よ、それはだれですか」と尋ねた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="マタイ 26:23; ヨハネ 13:30; マルコ 14:19–20"> そこでイエスは答えられた。<span className="woj">「私がパン切れを浸して与える者が、その人です。」</span>そしてパン切れを浸すと、シモン・イスカリオテの子ユダに与えられた。</span>
<span className="v" id="v27" data-v="27" data-xref="ルカ 22:3; ヨハネ 13:2; 伝道者の書 9:3"> ユダがそのパン切れを受け取ると、サタンが彼の中に入った。<br />そこでイエスは彼に言われた。<span className="woj">「しようとしていることを、早くしなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> しかし、食卓に着いていた者のうち、なぜイエスが彼にそう言われたのか分かる者は一人もいなかった。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネ 12:5–6; ヨハネ 13:1; エペソ人への手紙 4:28"> ある者たちは、ユダが金入れを預かっていたので、イエスが「祭りに必要なものを買いなさい」と言われたか、貧しい人々に何か施すように言われたのだと思った。</span>
<span className="v" id="v30" data-v="30" data-xref="イザヤ書 59:7; ヨブ記 24:13–15; 箴言 4:16"> そこでユダはそのパン切れを受け取ると、すぐに出て行った。夜であった。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ヨハネ 14:13; ペテロの手紙第一 4:11; ヨハネ 7:39"> ユダが出て行くと、イエスは言われた。<span className="woj">「今、人の子は栄光を受け、神も人の子によって栄光を受けられました。</span></span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネの黙示録 22:1; イザヤ書 53:10–12; ヨハネ 17:4–6"> <span className="woj">神が人の子によって栄光を受けられたのなら、神もご自身によって人の子に栄光を与え、しかもすぐにお与えになります。</span></span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネ 7:33–34; ヨハネ 8:21–24; ヨハネ 16:16–22"> <span className="woj">子どもたちよ、私はもうしばらくあなたがたとともにいます。あなたがたは私を捜すでしょう。私はユダヤ人たちに、『私が行く所に、あなたがたは来ることができない』と言いましたが、今、あなたがたにも同じことを言います。</span></span>
<span className="v" id="v34" data-v="34" data-xref="エペソ人への手紙 5:2; レビ記 19:18; ヨハネ 15:17"> <span className="woj">私はあなたがたに新しい戒めを与えます。互いに愛し合いなさい。私があなたがたを愛したように、あなたがたも互いに愛し合いなさい。</span></span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの手紙第一 4:20–21; ヨハネの手紙第一 3:10–14; ヨハネの手紙第一 2:10"> <span className="woj">あなたがたが互いに愛し合うなら、それによって、すべての人はあなたがたが私の弟子であることを知ります。」</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="ペテロの第二の手紙 1:14; ヨハネ 13:33; ヨハネ 21:21–22"> シモン・ペテロがイエスに言った。「主よ、どこへ行かれるのですか。」<br />イエスは答えられた。<span className="woj">「私が行く所に、あなたは今ついて来ることはできません。しかし、後にはついて来ます。」</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒の働き 21:13; 使徒の働き 20:24; マルコ 14:27–31"> ペテロはイエスに言った。「主よ、なぜ今はついて行けないのですか。私はあなたのためなら命を捨てます。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="ルカ 22:34; マタイ 26:34; マルコ 14:30"> イエスは彼に答えられた。<span className="woj">「私のために命を捨てるのですか。まことに、まことに、あなたに告げます。あなたが三度私を否むまで、鶏は鳴きません。」</span></span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネ 4:46; 箴言 31:10–12; ヨハネ 21:2"> 三日目、ガリラヤのカナで婚礼があり、イエスの母もそこにいた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネ 1:40–49; マタイ 10:40–42; コリント人への第一の手紙 7:39"> イエスも弟子たちとともに婚礼に招かれていた。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 104:15; ピリピ人への手紙 4:6; イザヤ書 24:11"> ぶどう酒がなくなった時、イエスの母は「ぶどう酒がありません」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ヨハネ 7:6; ヨハネ 13:1; ヨハネ 7:30"> イエスは母に言われた。<span className="woj">「婦人よ、それはあなたと私に何の関わりがありますか。私の時はまだ来ていません。」</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ヨハネ 15:14; 創世記 6:22; ヘブル人への手紙 11:8"> 母は召使いたちに、「この方が言うことは何でもしてください」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 3:25; ヘブル人への手紙 9:10; エペソ人への手紙 5:26"> そこには、ユダヤ人の清めの習慣のために、二、三メトレテス<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="二から三メトレテスは、約20から30米ガロン、または75から115リットルである。">a</a></sup>ずつ入る石の水がめが六つ置かれていた。</span>
<span className="v" id="v7" data-v="7" data-xref="列王記第二 4:2–6; ヨハネ 2:5; ヨハネ 2:3"> イエスが彼らに<span className="woj">「水がめを水で満たしなさい」</span>と言われると、彼らは縁までいっぱいにした。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネ 2:9; 箴言 3:5–6; ローマ人への手紙 13:7"> イエスは<span className="woj">「さあ、くんで、宴会の世話役のところへ持って行きなさい」</span>と言われた。そこで彼らは持って行った。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネ 4:46; ヨハネ 7:17; 詩篇 119:100"> 宴会の世話役は、ぶどう酒になった水を味わったが、それがどこから来たのか知らなかった。しかし、水をくんだ召使いたちは知っていた。そこで世話役は花婿を呼び、</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 7:16–17; 箴言 9:1–6; ルカ 16:25"> 言った。「だれでも初めに良いぶどう酒を出し、客が十分飲んだころに質の劣るものを出します。それなのに、あなたは良いぶどう酒を今まで取っておきました。」</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネ 20:30–31; ヨハネ 1:14; ヨハネ 3:2"> イエスはガリラヤのカナでこの最初のしるしを行い、ご自分の栄光を現された。弟子たちはイエスを信じた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マタイ 12:46; マタイ 13:55–56; マルコ 6:3"> この後、イエスは母、兄弟たち、弟子たちとともにカペナウムへ下り、そこに数日滞在された。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカ 2:41; ヨハネ 11:55; ヨハネ 2:23"> ユダヤ人の過越祭が近づいたので、イエスはエルサレムへ上られた。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカ 19:45–46; マルコ 11:15; マルコ 11:17"> そして神殿で、牛、羊、鳩を売る者たちや、座っている両替人たちをご覧になった。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネ 18:6; ゼカリヤ書 4:6; コリント人への第二の手紙 10:4"> イエスは縄でむちを作り、羊も牛もすべて神殿から追い出された。また両替人の金をまき散らし、その台を倒された。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイ 21:13; エレミヤ書 7:11; マルコ 11:17"> 鳩を売る者たちには、<span className="woj">「これらをここから運び出しなさい。私の父の家を市場にしてはなりません」</span>と言われた。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 69:9; 詩篇 119:139"> 弟子たちは、「あなたの家を思う熱心が私を食い尽くす」と書かれていることを思い出した。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="マタイ 21:23; マルコ 8:11; マルコ 11:27–28"> そこでユダヤ人たちはイエスに言った。「こうしたことをするからには、私たちにどんなしるしを見せるのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="マルコ 14:58; マルコ 15:29; マタイ 27:40"> イエスは答えられた。<span className="woj">「この神殿を壊しなさい。私は三日でこれを建て直します。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> ユダヤ人たちは言った。「この神殿を建てるのに四十六年かかりました。それを三日で起こすのですか。」</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第一の手紙 6:19; コリント人への第一の手紙 3:16; エペソ人への手紙 2:20–22"> しかし、イエスはご自分の体という神殿について語っておられたのである。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネ 12:16; ヨハネ 16:4; ルカ 24:7–8"> それで、イエスが死者の中からよみがえられた時、弟子たちはイエスがこう言われたことを思い出し、聖書とイエスの言葉を信じた。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ヨハネ 7:31; ルカ 8:13; ヨハネ 6:14"> イエスが過越祭の祝いの間エルサレムにおられた時、多くの人が、その行われたしるしを見て、イエスの名を信じた。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネ 6:64; ヘブル人への手紙 4:13; 使徒の働き 1:24"> しかし、イエスはご自分を彼らにお任せにならなかった。すべての人を知っておられ、</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネ 13:11; マタイ 9:4; ヨハネ 6:64"> 人についてだれかにあかししてもらう必要はなかった。イエスご自身、人の内に何があるかを知っておられたからである。</span>
</div>
</div>

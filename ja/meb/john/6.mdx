<span className="v" id="v1" data-v="1" data-xref="マルコ 6:31–44; ヨハネ 6:23; ルカ 5:1"> これらのことの後、イエスはガリラヤの湖、すなわちティベリアス湖の向こう岸へ行かれた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 4:24–25; マタイ 12:15; マタイ 15:30–31"> 大勢の群衆がイエスについて行った。イエスが病人たちに行われたしるしを見たからである。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネ 6:15; ルカ 9:28; ルカ 6:12–13"> イエスは山に上り、弟子たちとともにそこに座られた。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネ 2:13; ヨハネ 11:55; ヨハネ 5:1"> さて、ユダヤ人の祭りである過越の祭りが近づいていた。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイ 15:33; ルカ 9:12–13; マタイ 14:14–15"> イエスは目を上げ、大勢の群衆がご自分のもとに来るのを見て、フィリポに<span className="woj">「この人たちに食べさせるパンを、どこで買いましょうか」</span>と言われた。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 22:1; 申命記 13:3; 歴代誌 第二 32:31"> イエスがこう言われたのは、フィリポを試すためであった。ご自分では、何をしようとしているか分かっておられたからである。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="民数記 11:21–22; マルコ 6:37; ヨハネ 12:5"> フィリポは答えた。「一人ひとりが少しずつ取るとしても、二百デナリ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一デナリは農業労働者のほぼ一日分の賃金に相当する銀貨であった。したがって、二百デナリは六か月から七か月分の賃金に相当する。">a</a></sup>のパンでは足りません。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨハネ 1:40–44; マタイ 4:18"> 弟子の一人で、シモン・ペテロの兄弟アンデレがイエスに言った。</span>
<span className="v" id="v9" data-v="9" data-xref="列王記第二 4:42–44; マタイ 14:17; マルコ 6:38"> 「ここに、大麦のパン五つと魚二匹を持っている少年がいます。しかし、これほど大勢の人に、それが何になるでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ルカ 9:14–16; マタイ 15:35–36; マルコ 6:39–41"> イエスは<span className="woj">「人々を座らせなさい」</span>と言われた。その場所には草がたくさん生えていた。そこで人々は座った。男の数はおよそ五千人であった。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネ 6:23; テサロニケ人への手紙第一 5:18; マタイ 15:36"> イエスはパンを取り、感謝をささげてから弟子たちに分け、弟子たちは座っている人々に分けた。魚も同じように、彼らが望むだけ分け与えた。</span>
<span className="v" id="v12" data-v="12" data-xref="ルカ 1:53; ネヘミヤ記 9:25; ネヘミヤ記 8:10"> 人々が満腹になると、イエスは弟子たちに<span className="woj">「何も無駄にならないように、残ったパン切れを集めなさい」</span>と言われた。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 11:24–25; 列王記第二 4:2–7; コリント人への第二の手紙 9:8–9"> そこで彼らが集めると、人々が食べた後に残った五つの大麦のパンの切れ端で、十二の籠がいっぱいになった。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 18:15–18; マタイ 21:11; 使徒の働き 7:37"> 人々はイエスが行われたしるしを見て、「この方こそ、まことに世に来るあの預言者だ」と言った。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネ 18:36; ヨハネ 6:15–21; ヨハネ 7:3–4"> イエスは、人々が来てご自分を無理やり王にしようとしていることを察し、再びただ一人で山へ退かれた。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 夕方になると、弟子たちは湖へ下りた。</span>
<span className="v" id="v17" data-v="17" data-xref="マルコ 6:45; ヨハネ 6:24–25; ヨハネ 2:12"> そして舟に乗り、湖を渡ってカペナウムへ向かった。すでに暗くなっていたが、イエスはまだ彼らのところに来ておられなかった。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 107:25; 詩篇 135:7; マタイ 14:24"> 激しい風が吹き、湖は荒れていた。</span>
<span className="v" id="v19" data-v="19" data-xref="マルコ 6:47–49; マタイ 14:25–26; ヨブ記 9:8"> 弟子たちが二十五ないし三十スタディオン<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="二十五ないし三十スタディオンは約5キロメートルから6キロメートル、または約3マイルから4マイルである。">b</a></sup>ほどこぎ出した時、イエスが湖の上を歩き、舟に近づいて来られるのを見て、恐れた。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイ 14:27–31; イザヤ書 43:1–2; イザヤ書 44:8"> しかし、イエスは彼らに<span className="woj">「私です。</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="または、「わたしはある」。">c</a></sup><span className="woj">恐れてはなりません」</span>と言われた。</span>
<span className="v" id="v21" data-v="21" data-xref="マルコ 6:51; マタイ 14:32–33; ヨハネの黙示録 3:20"> そこで彼らは喜んでイエスを舟に迎え入れた。すると舟はすぐに、彼らが目指していた岸に着いた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="マルコ 6:45; マタイ 14:22; ヨハネ 6:2"> 翌日、湖の向こう岸にとどまっていた群衆は、そこには弟子たちが乗った一そうの舟のほかに舟がなかったこと、またイエスが弟子たちと一緒に舟に乗らず、弟子たちだけで出発したことに気づいた。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネ 6:1; ヨハネ 6:11–12"> ところが、主が感謝をささげられた後、人々がパンを食べた場所の近くに、ティベリアスから来た舟が何そうか着いた。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネ 6:17; ルカ 8:40; マルコ 6:53"> 群衆は、そこにイエスも弟子たちもいないことを知ると、自分たちも舟に乗り、イエスを捜してカペナウムへ行った。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネ 1:38–39; マタイ 23:7"> そして湖の向こう岸でイエスを見つけると、「ラビ、いつここに来られたのですか」と尋ねた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ヤコブの手紙 4:3–4; ピリピ人への手紙 3:19; ピリピ人への手紙 2:21"> イエスは彼らに答えられた。<span className="woj">「まことに、まことに、あなたがたに告げます。あなたがたが私を捜しているのは、しるしを見たからではなく、パンを食べて満腹したからです。</span></span>
<span className="v" id="v27" data-v="27" data-xref="コロサイ人への手紙 3:2; イザヤ書 55:2; ヨハネ 6:54"> <span className="woj">朽ちる食物のためではなく、永遠の命に至るまで残る食物のために働きなさい。それは人の子があなたがたに与えるものです。父なる神が、人の子に証印を押されたからです。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="使徒の働き 16:30; 使徒の働き 9:6; マタイ 19:16"> そこで彼らは尋ねた。「神の業を行うために、私たちは何をしなければなりませんか。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ヨハネの手紙第一 3:23; 使徒の働き 16:31; ヨハネ 3:36"> イエスは答えられた。<span className="woj">「神の業とは、神が遣わされた者をあなたがたが信じることです。」</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ヨハネ 12:37; ヨハネ 10:38; コリント人への第一の手紙 1:22"> そこで彼らは言った。「それでは、私たちが見てあなたを信じられるように、どんなしるしを行うのですか。どのような業をするのですか。</span>
<span className="v" id="v31" data-v="31" data-xref="ネヘミヤ記 9:15; 詩篇 105:40; 詩篇 78:24–25"> 私たちの先祖は荒野でマナを食べました。『彼は天からパンを与えて彼らに食べさせた』<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="ギリシャ語とヘブル語では、「天」「もろもろの天」「空」「大気」に同じ言葉が使われている。">d</a></sup>と書かれているとおりです。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="ヨハネ 15:1; ヨハネ 6:58; 出エジプト記 16:4"> そこでイエスは彼らに言われた。<span className="woj">「まことに、まことに、あなたがたに告げます。天からのパンをあなたがたに与えたのはモーセではありません。私の父が、天からのまことのパンをあなたがたに与えておられるのです。</span></span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネ 8:42; ヨハネ 17:8; ヨハネ 3:13"> <span className="woj">神のパンとは、天から下って来て、世に命を与えるものです。」</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ヨハネ 4:15; ヨハネ 6:26; 詩篇 4:6"> そこで彼らは言った。「主よ、そのパンをいつも私たちに与えてください。」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="ヨハネ 6:48–58; ヨハネの黙示録 22:17; ヨハネ 6:41"> イエスは彼らに言われた。<span className="woj">「私が命のパンです。私のもとに来る者は決して飢えず、私を信じる者は決して渇きません。</span></span>
<span className="v" id="v36" data-v="36" data-xref="ペテロの手紙第一 1:8–9; ルカ 16:31; ヨハネ 12:37"> <span className="woj">しかし、私はあなたがたに言いました。あなたがたは私を見たのに、それでも信じません。</span></span>
<span className="v" id="v37" data-v="37" data-xref="マタイ 11:28; ヨハネ 6:39; ヨハネ 17:24"> <span className="woj">父が私に与えてくださる者は皆、私のもとに来ます。そして、私のもとに来る者を、私は決して追い出しません。</span></span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネ 5:30; ヨハネ 4:34; ヨハネ 3:31"> <span className="woj">私が天から下って来たのは、自分の意志を行うためではなく、私を遣わされた方の御心を行うためだからです。</span></span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネ 17:12; ヨハネ 6:40; ヨハネ 18:9"> <span className="woj">私を遣わされた父の御心は、父が私に与えてくださったすべての者を一人も失わず、終わりの日によみがえらせることです。</span></span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネ 6:54; ヨハネ 5:24; ローマ人への手紙 6:23"> <span className="woj">私を遣わされた方の御心は、御子を見て信じる者が皆、永遠の命を持つことです。私はその人を終わりの日によみがえらせます。」</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="ヨハネ 6:51–52; ヨハネ 6:48; ヨハネ 6:33"> ユダヤ人たちは、イエスが<span className="woj">「私は天から下って来たパンです」</span>と言われたので、イエスについて不平を言った。</span>
<span className="v" id="v42" data-v="42" data-xref="ルカ 4:22; マルコ 6:3; マタイ 13:55–56"> 彼らは言った。「これはヨセフの子イエスではないか。われわれはその父も母も知っている。それなのに、どうして今、<span className="woj">『私は天から下って来た』</span>と言うのか。」</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="ヘブル人への手紙 4:13; ヨハネ 6:64; マルコ 9:33"> そこでイエスは彼らに答えられた。<span className="woj">「互いに不平を言うのはやめなさい。</span></span>
<span className="v" id="v44" data-v="44" data-xref="ヨハネ 6:65; ヨハネ 6:39–40; マタイ 11:25–27"> <span className="woj">私を遣わされた父が引き寄せてくださらなければ、だれも私のもとに来ることはできません。そして私は、その人を終わりの日によみがえらせます。</span></span>
<span className="v" id="v45" data-v="45" data-xref="イザヤ書 54:13; エレミヤ書 31:33–34; ヘブル人への手紙 10:16"> <span className="woj">預言者たちの書に、『彼らは皆、神に教えられる』と書かれています。ですから、父から聞いて学んだ者は皆、私のもとに来ます。</span></span>
<span className="v" id="v46" data-v="46" data-xref="ヨハネ 1:18; ヨハネ 7:29; マタイ 11:27"> <span className="woj">神から来た者のほかに、父を見た者がいるということではありません。その方は父を見ました。</span></span>
<span className="v" id="v47" data-v="47" data-xref="ヨハネ 3:36; コロサイ人への手紙 3:3–4; ローマ人への手紙 5:9–10"> <span className="woj">まことに、まことに、あなたがたに告げます。私を信じる者には永遠の命があります。</span></span>
<span className="v" id="v48" data-v="48" data-xref="ヨハネ 6:51; コリント人への第一の手紙 11:24–25; コリント人への第一の手紙 10:16–17"> <span className="woj">私が命のパンです。</span></span>
<span className="v" id="v49" data-v="49" data-xref="コリント人への第一の手紙 10:3–5; ユダ 1:5; ゼカリヤ書 1:5"> <span className="woj">あなたがたの先祖は荒野でマナを食べましたが、死にました。</span></span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネ 6:33; ヨハネ 6:51; ローマ人への手紙 8:10"> <span className="woj">しかし、これは天から下って来るパンであり、だれでもこれを食べる者は死にません。</span></span>
<span className="v" id="v51" data-v="51" data-xref="ルカ 22:19; ヨハネ 6:33; ヘブル人への手紙 10:5–12"> <span className="woj">私は天から下って来た生けるパンです。だれでもこのパンを食べるなら、永遠に生きます。私が世の命のために与えるパンは、私の肉です。」</span></span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="ヨハネ 9:16; ヨハネ 10:19; ヨハネ 6:41"> そこでユダヤ人たちは、「この人は、どうして自分の肉をわれわれに与えて食べさせることができるのか」と互いに激しく議論した。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="ヨハネの手紙第一 5:12; マタイ 26:26–28; ヨハネ 6:55"> そこでイエスは彼らに言われた。<span className="woj">「まことに、まことに、あなたがたに告げます。人の子の肉を食べ、その血を飲まなければ、あなたがたのうちに命はありません。</span></span>
<span className="v" id="v54" data-v="54" data-xref="ヨハネ 6:39–40; ヨハネ 6:27; ピリピ人への手紙 3:7–10"> <span className="woj">私の肉を食べ、私の血を飲む者には永遠の命があります。私はその人を終わりの日によみがえらせます。</span></span>
<span className="v" id="v55" data-v="55" data-xref="ヨハネ 15:1; ヨハネ 8:31; ヨハネ 6:32"> <span className="woj">私の肉はまことの食物であり、私の血はまことの飲み物だからです。</span></span>
<span className="v" id="v56" data-v="56" data-xref="ヨハネの手紙第一 3:24; ヨハネ 15:4–5; ヨハネ 14:20"> <span className="woj">私の肉を食べ、私の血を飲む者は私のうちにとどまり、私もその人のうちにとどまります。</span></span>
<span className="v" id="v57" data-v="57" data-xref="ガラテヤ人への手紙 2:20; ヨハネ 5:26; ヨハネ 17:21"> <span className="woj">生ける父が私を遣わされ、私が父によって生きているように、私を食べる者も私によって生きます。</span></span>
<span className="v" id="v58" data-v="58" data-xref="ヨハネ 3:36; ヨハネ 6:47–51; ヨハネ 6:41"> <span className="woj">これは天から下って来たパンです。私たちの先祖がマナを食べて死んだのとは違います。このパンを食べる者は永遠に生きます。」</span></span>
<span className="v" id="v59" data-v="59" data-xref="ヨハネ 6:24; 箴言 8:1–3; ルカ 4:31"> イエスはカペナウムの会堂で教えておられた時、これらのことを言われた。</span>
</div>
<div className="bp">
<span className="v" id="v60" data-v="60" data-xref="ヨハネ 6:66; ヨハネ 8:43; ヨハネ 8:31"> そこで弟子たちの多くは、これを聞いて言った。「これは厳しい言葉だ。だれが聞いていられるだろう。」</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61" data-xref="ヨハネ 2:24–25; ヨハネ 6:64; ヨハネ 21:17"> しかしイエスは、弟子たちがこのことで不平を言っているのをご自分のうちで知り、彼らに言われた。<span className="woj">「このことがあなたがたをつまずかせるのですか。</span></span>
<span className="v" id="v62" data-v="62" data-xref="マルコ 16:19; ヨハネ 3:13; ヨハネ 17:4–5"> <span className="woj">それでは、人の子が以前いた所へ上って行くのを見たら、どうでしょう。</span></span>

<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="JHN" data-book-slug="john" data-book-name="ヨハネ" data-chapter="7" data-verses="53">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネ 5:16–18; ヨハネ 4:3; マタイ 21:38"> これらのことの後、イエスはガリラヤを巡っておられた。ユダヤ人たちがイエスを殺そうとしていたので、ユダヤを巡ろうとはされなかったのである。</span>
<span className="v" id="v2" data-v="2" data-xref="ゼカリヤ書 14:16–19; 申命記 16:13–16; 出エジプト記 23:16–17"> さて、ユダヤ人の祭りである仮庵の祭りが近づいていた。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイ 12:46; ヨハネ 7:5; ルカ 8:19"> そこでイエスの兄弟たちは言った。「ここを去ってユダヤへ行き、あなたが行っている業を弟子たちにも見せたらどうですか。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネ 18:20; 箴言 18:1–2; マタイ 23:5"> 公に知られようとしながら、ひそかに事を行う人はいません。このようなことを行うのなら、自分を世に示しなさい。」</span>
<span className="v" id="v5" data-v="5" data-xref="マルコ 3:21; ヨハネ 1:11–13; ミカ書 7:5–6"> 兄弟たちさえ、イエスを信じていなかったからである。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 7:8; ヨハネ 2:4; ヨハネ 7:30"> そこでイエスは彼らに言われた。<span className="woj">「私の時はまだ来ていません。しかし、あなたがたの時はいつでも整っています。</span></span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネ 15:18–19; ヨハネ 3:19; ガラテヤ人への手紙 4:16"> <span className="woj">世はあなたがたを憎むことができません。しかし、私を憎みます。私が世について、その行いが悪いとあかしするからです。</span></span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネ 7:6; ヨハネ 8:20; ヨハネ 7:30"> <span className="woj">あなたがたは祭りに上って行きなさい。私はまだこの祭りには上りません。私の時はまだ満ちていないからです。」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> こう言って、イエスはガリラヤにとどまられた。</span>
<span className="v" id="v10" data-v="10" data-xref="アモス書 5:13; マタイ 10:16; イザヤ書 42:2–3"> しかし兄弟たちが祭りに上って行った後、イエスご自身も、人目につくようにではなく、いわばひそかに上って行かれた。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネ 11:56"> そこでユダヤ人たちは祭りでイエスを捜し、「あの人はどこにいるのか」と言っていた。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネ 7:40–43; ヨハネ 9:16; ヨハネ 7:32"> 群衆の間では、イエスについて盛んにささやかれていた。ある者は「良い人だ」と言い、ほかの者は「いや、群衆を惑わしている」と言った。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネ 9:22; ヨハネ 19:38; ヨハネ 20:19"> しかし、ユダヤ人たちを恐れて、イエスについて公然と語る者はいなかった。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネ 7:28; ルカ 19:47; ヨハネ 7:37"> 祭りも半ばになったころ、イエスは宮に上って教えられた。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカ 4:22; マタイ 7:28–29; マタイ 13:54"> そこでユダヤ人たちは驚いて言った。「この人は正式に学んだこともないのに、どうしてこれほど学識があるのか。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヨハネ 14:10; ヨハネ 14:24; ヨハネ 17:8"> イエスは彼らに答えられた。<span className="woj">「私の教えは私のものではなく、私を遣わされた方のものです。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネ 8:31–32; ヨハネ 8:43; エレミヤ書 31:33–34"> <span className="woj">だれでもその方の御心を行おうと望むなら、この教えが神から出たものか、それとも私が自分から語っているのかが分かります。</span></span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネ 5:41; コリント人への第一の手紙 10:31–33; ヨハネ 13:31–32"> <span className="woj">自分から語る者は自分の栄誉を求めます。しかし、自分を遣わした方の栄誉を求める者は真実であり、その人のうちに不義はありません。</span></span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネ 1:17; ヨハネ 11:53; マタイ 12:14"> <span className="woj">モーセはあなたがたに律法を与えたのではありませんか。それなのに、あなたがたのうち、だれ一人として律法を守っていません。なぜ私を殺そうとするのですか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヨハネ 10:20; ヨハネ 8:48; ヨハネ 8:52"> 群衆は答えた。「あなたは悪霊に取りつかれている。だれがあなたを殺そうとしているのか。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ヨハネ 7:23; ヨハネ 5:2–11"> イエスは彼らに答えられた。<span className="woj">「私が一つの業を行ったので、あなたがたは皆、そのことで驚いています。</span></span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 12:3; 創世記 17:10–14; ローマ人への手紙 4:9–11"> <span className="woj">モーセはあなたがたに割礼を与えました。もっとも、割礼はモーセからではなく、父祖たちから始まったものです。そのため、あなたがたは安息日にも男の子に割礼を施します。</span></span>
<span className="v" id="v23" data-v="23" data-xref="マタイ 12:5; ヨハネ 5:14–16; マタイ 12:2"> <span className="woj">モーセの律法が破られないように安息日にも男の子が割礼を受けるのなら、私が安息日に一人の人を完全に健康にしたからといって、私に腹を立てるのですか。</span></span>
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 11:3–4; ヤコブの手紙 2:9; ヨハネ 8:15"> <span className="woj">うわべによって裁かず、正しい裁きをしなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ヨハネ 7:10–11"> そこでエルサレムの人々の中には、こう言う者がいた。「この人は、彼らが殺そうとしている者ではないか。</span>
<span className="v" id="v26" data-v="26" data-xref="テモテへの第二の手紙 1:7–8; ヨハネ 7:48; ヨハネ 12:42"> 見よ、彼は公然と話しているのに、彼らは何も言わない。もしかすると、指導者たちは、この人が本当にキリストだと知っているのだろうか。</span>
<span className="v" id="v27" data-v="27" data-xref="ミカ書 5:2; ヨハネ 7:41–42; ヨハネ 6:42"> しかし、われわれはこの人がどこから来たか知っている。キリストが来る時には、どこから来たかを知る者はいないはずだ。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヨハネ 8:42; ヨハネ 8:19; ヨハネ 8:26"> そこでイエスは、宮で教えながら大声で言われた。<span className="woj">「あなたがたは私を知っており、私がどこから来たかも知っています。しかし、私は自分から来たのではありません。私を遣わされた方は真実ですが、あなたがたはその方を知りません。</span></span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネ 8:55; マタイ 11:27; ヨハネ 17:18"> <span className="woj">私はその方を知っています。私はその方から来た者であり、その方が私を遣わされたからです。」</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ヨハネ 8:20; ヨハネ 10:39; ヨハネ 7:6"> そこで彼らはイエスを捕らえようとした。しかし、だれもイエスに手をかけなかった。イエスの時がまだ来ていなかったからである。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネ 12:42; マタイ 12:23; ヨハネ 10:41–42"> しかし、群衆の中の多くの人がイエスを信じて言った。「キリストが来られても、この方が行ったより多くのしるしを行うことはないだろう。」</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネ 18:3; ルカ 22:52–53; ヨハネ 11:47–48"> パリサイ人たちは、群衆がイエスについてこのようにささやいているのを聞いた。そこで祭司長たちとパリサイ人たちは、イエスを捕らえるために役人たちを遣わした。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="ヨハネ 16:5; ヨハネ 13:33; マルコ 16:19"> そこでイエスは言われた。<span className="woj">「私はもうしばらくあなたがたとともにいて、それから私を遣わされた方のもとへ行きます。</span></span>
<span className="v" id="v34" data-v="34" data-xref="箴言 1:24–31; ヨハネ 13:33–36; ヨハネ 14:6"> <span className="woj">あなたがたは私を捜しても見つけられません。また、私がいる所に、あなたがたは来ることができません。」</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="ヤコブの手紙 1:1; イザヤ書 11:12; ゼパニヤ書 3:10"> そこでユダヤ人たちは互いに言った。「この人はどこへ行こうとしているので、われわれには見つけられないというのか。ギリシャ人の間に離散している人々のところへ行って、ギリシャ人を教えようというのか。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネ 3:9; ヨハネ 7:34; ヨハネ 12:34"> 彼が言った、<span className="woj">『あなたがたは私を捜しても見つけられない』</span>、また<span className="woj">『私がいる所に、あなたがたは来ることができない』</span>という言葉は、どういう意味なのか。」</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="イザヤ書 55:1; ヨハネ 4:14; ヨハネ 6:35"> 祭りの最後の大いなる日に、イエスは立って大声で言われた。<span className="woj">「だれでも渇いているなら、私のもとに来て飲みなさい。</span></span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネ 4:14; イザヤ書 44:3; イザヤ書 58:11"> <span className="woj">私を信じる者は、聖書が言っているとおり、その人の内から生ける水の川が流れ出ます。」</span></span>
<span className="v" id="v39" data-v="39" data-xref="使徒の働き 2:17; ヨエル書 2:28; ヨハネ 14:16–17"> イエスは、ご自分を信じる者たちが受けようとしていた聖霊について、こう言われたのである。イエスがまだ栄光を受けておられなかったので、聖霊はまだ与えられていなかった。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="マタイ 21:11; ヨハネ 1:21; ヨハネ 6:14"> 群衆の多くはこれらの言葉を聞いて、「この方こそ、まことにあの預言者だ」と言った。</span>
<span className="v" id="v41" data-v="41" data-xref="ヨハネ 7:52; ヨハネ 1:46; ヨハネ 1:49"> ほかの者たちは「この方はキリストだ」と言った。しかし、ある者たちは言った。「まさか、キリストがガリラヤから出ることはないだろう。</span>
<span className="v" id="v42" data-v="42" data-xref="ミカ書 5:2; マタイ 2:5; ルカ 2:4"> 聖書には、キリストはダビデの子孫<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または、「種」。">a</a></sup>から出て、ダビデの村ベツレヘムから来ると書かれているではないか。」</span>
<span className="v" id="v43" data-v="43" data-xref="ヨハネ 9:16; ヨハネ 10:19; ヨハネ 7:12"> こうして、イエスのことで群衆の間に分裂が生じた。</span>
<span className="v" id="v44" data-v="44" data-xref="ヨハネ 7:30; 使徒の働き 23:11; ヨハネ 8:20"> 彼らの中にはイエスを捕らえようとする者もいたが、だれもイエスに手をかけなかった。</span>
<span className="v" id="v45" data-v="45" data-xref="ヨハネ 7:32; 使徒の働き 5:21–27"> 役人たちは祭司長たちとパリサイ人たちのもとへ戻った。彼らは役人たちに「なぜあの人を連れて来なかったのか」と尋ねた。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="マタイ 7:28–29; ルカ 4:22; ヨハネ 7:26"> 役人たちは答えた。「あの人のように語った人は、これまで一人もいません。」</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="ヨハネ 7:12; コリント人への第二の手紙 6:8; 列王記第二 18:32"> そこでパリサイ人たちは彼らに答えた。「あなたがたまで惑わされたのか。</span>
<span className="v" id="v48" data-v="48" data-xref="ヨハネ 12:42; コリント人への第一の手紙 1:20; コリント人への第一の手紙 2:8"> 指導者たちやパリサイ人たちの中に、あの男を信じた者がいるか。</span>
<span className="v" id="v49" data-v="49" data-xref="コリント人への第一の手紙 1:20–21; ヨハネ 9:40; ヨハネ 9:34"> だが、律法を知らないこの群衆は呪われている。」</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="ヨハネ 19:39; ヨハネ 3:1–2"> 彼らの一人であり、以前、夜にイエスのもとへ来たニコデモが言った。</span>
<span className="v" id="v51" data-v="51" data-xref="箴言 18:13; 申命記 1:17; 申命記 19:15–19"> 「われわれの律法は、まず本人から話を聞き、その人が何をしているかを知る前に、その人を裁くだろうか。」</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="ヨハネ 7:41; ヨハネ 1:46; イザヤ書 9:1–2"> 彼らは答えた。「あなたもガリラヤ出身なのか。調べてみなさい。ガリラヤから預言者が起こったことはないと分かるだろう。」</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="詩篇 33:10; ヨブ記 5:12–13; 詩篇 76:10"> 人々はそれぞれ自分の家へ帰って行った。</span>
</div>
</div>

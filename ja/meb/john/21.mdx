<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネ 6:1; ヨハネ 6:23; マタイ 28:16"> これらのことの後、イエスはティベリアス湖畔で、再び弟子たちにご自分を現された。その現れ方はこうであった。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 4:21–22; ヨハネ 1:45–1; ヨハネ 4:46"> シモン・ペテロ、ディディモ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「双子」。">a</a></sup>と呼ばれるトマス、ガリラヤのカナ出身のナタナエル、ゼベダイの息子たち、それにほかの二人の弟子が一緒にいた。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカ 5:5; マタイ 4:18–20; テサロニケ人への第二の手紙 3:7–9"> シモン・ペテロが彼らに「私は漁に行く」と言った。<br />彼らは「私たちも一緒に行こう」と言った。彼らはすぐに出て行って舟に乗り込んだ。しかし、その夜は何も捕れなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネ 20:14; ルカ 24:15–16; ルカ 24:31"> すでに夜が明けたころ、イエスが岸辺に立っておられた。しかし弟子たちには、それがイエスだと分からなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 4:19; ピリピ人への手紙 4:11–13; ヨハネの手紙第一 2:13"> そこでイエスは彼らに言われた。<span className="woj">「子どもたちよ、何か食べる物がありますか。」</span><br />彼らは「ありません」と答えた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ルカ 5:4–7; 使徒の働き 2:41; ヨハネ 2:5"> イエスは彼らに言われた。<span className="woj">「舟の右側に網を投げなさい。そうすれば見つかります。」</span><br />そこで彼らは網を投げた。すると魚があまりに多く、網を引き上げることができなかった。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネ 13:23; ヨハネ 20:2; マタイ 14:28–29"> そこで、イエスが愛しておられた弟子がペテロに言った。「主だ。」<br />シモン・ペテロは主だと聞くと、裸だったので上着を身にまとい、湖に飛び込んだ。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 3:11"> ほかの弟子たちは小舟でやって来た。陸から二百キュビト<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="二百キュビトは約百ヤード、または約91メートルである。">b</a></sup>ほどしか離れていなかったので、魚でいっぱいの網を引いて来たのである。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネ 21:13; 列王記第一 19:5–6; ヨハネ 21:10"> 彼らが陸に上がると、そこに炭火があり、その上に魚とパンが置いてあるのが見えた。</span>
<span className="v" id="v10" data-v="10"> イエスは彼らに言われた。<span className="woj">「今捕った魚を何匹か持って来なさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ルカ 5:6–8; 使徒の働き 2:41"> シモン・ペテロは舟に上がり、百五十三匹もの大きな魚でいっぱいの網を陸へ引き上げた。それほど多かったのに、網は破れなかった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 10:41; ルカ 9:45; ヨハネ 16:19"> イエスは彼らに言われた。<span className="woj">「さあ、朝食を取りなさい。」</span><br />弟子たちは、主であることが分かっていたので、「あなたはどなたですか」とあえて尋ねる者はいなかった。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨハネ 21:9; 使徒の働き 10:41; ルカ 24:42–43"> イエスは来てパンを取り、彼らに与えられた。魚も同じようにされた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネ 20:26; ヨハネ 20:19"> イエスが死者の中からよみがえった後、弟子たちに現れたのは、これで三度目であった。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 40:11; ヨハネの手紙第一 4:19; ローマ人への手紙 15:1"> 彼らが朝食を終えると、イエスはシモン・ペテロに言われた。<span className="woj">「ヨナの子シモン、あなたは、これら以上に私を愛していますか。」</span><br />ペテロはイエスに言った。「はい、主よ。私があなたを慕っていることは、あなたがご存じです。」<br />イエスは彼に言われた。<span className="woj">「私の子羊を養いなさい。」</span></span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 20:28; ペテロの手紙第一 5:2; ペテロの手紙第一 2:25"> イエスは再び二度目に彼に言われた。<span className="woj">「ヨナの子シモン、私を愛していますか。」</span><br />ペテロはイエスに言った。「はい、主よ。私があなたを慕っていることは、あなたがご存じです。」<br />イエスは彼に言われた。<span className="woj">「私の羊を世話しなさい。」</span></span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネ 13:38; ヨハネ 16:30; マルコ 14:72"> イエスは三度目に彼に言われた。<span className="woj">「ヨナの子シモン、私を愛していますか。」</span><br />ペテロは、イエスが三度目に<span className="woj">「私を慕っていますか」</span>と尋ねられたので、悲しくなった。そしてイエスに言った。「主よ、あなたはすべてをご存じです。私があなたを慕っていることを、あなたはご存じです。」<br />イエスは彼に言われた。<span className="woj">「私の羊を養いなさい。</span></span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネ 13:36; 使徒の働き 12:3–4; 使徒の働き 21:11"> <span className="woj">まことに、まことに、あなたに告げます。あなたは若かった時、自分で帯を締め、行きたい所を歩きました。しかし年を取ると、あなたは両手を伸ばし、ほかの人があなたに帯を締め、行きたくない所へ連れて行きます。」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ペテロの第二の手紙 1:14; ヨハネ 21:22; マタイ 10:38"> イエスは、ペテロがどのような死に方で神に栄光を与えるかを示すために、こう言われたのである。そして、こう言ってから彼に言われた。<span className="woj">「私に従いなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヨハネ 21:7; ヨハネ 20:2; ヨハネ 21:24"> ペテロが振り向くと、一人の弟子がついて来るのが見えた。それはイエスが愛しておられた弟子で、夕食の時にもイエスの胸もとに寄りかかり、「主よ、あなたを裏切ろうとしているのはだれですか」と尋ねた者であった。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカ 13:23–24; 使徒の働き 1:6–7; マタイ 24:3–4"> ペテロは彼を見て、イエスに言った。「主よ、この人はどうなるのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨハネの黙示録 2:25; ヨハネの黙示録 3:11; マルコ 9:1"> イエスは彼に言われた。<span className="woj">「私が来るまで彼がとどまることを私が望んだとしても、それがあなたに何の関わりがありますか。あなたは私に従いなさい。」</span></span>
<span className="v" id="v23" data-v="23" data-xref="申命記 29:29; ヨブ記 33:13; ダニエル書 4:35"> そこで、この弟子は死なないという言葉が兄弟たち<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="ここで「兄弟たち」と訳された言葉は、「兄弟姉妹」または「きょうだいたち」と訳すこともできる。">c</a></sup>の間に広まった。しかしイエスは、彼が死なないと言われたのではなく、<span className="woj">「私が来るまで彼がとどまることを私が望んだとしても、それがあなたに何の関わりがありますか」</span>と言われたのである。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヨハネ 19:35; ヨハネ 15:27; ヨハネの手紙第一 5:6"> これらのことについてあかしし、これらのことを書いたのは、この弟子である。われわれは、彼のあかしが真実であることを知っている。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 40:5; ヨハネ 20:30–31; 詩篇 71:15"> イエスが行われたことは、ほかにもたくさんある。それを一つ一つ書き記したなら、この世界さえ、書かれる書物を収めきれないだろうと私は思う。</span>
</div>

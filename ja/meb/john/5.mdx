<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 16:16; 出エジプト記 23:14–17; 出エジプト記 34:23"> これらのことの後、ユダヤ人の祭りがあり、イエスはエルサレムへ上られた。</span>
<span className="v" id="v2" data-v="2" data-xref="ネヘミヤ記 12:39; ネヘミヤ記 3:1; ネヘミヤ記 3:32"> エルサレムの羊の門のそばに、ヘブル語で「ベテスダ」と呼ばれる池があり、五つの回廊があった。</span>
<span className="v" id="v3" data-v="3" data-xref="マルコ 3:1–4; ルカ 7:22; マタイ 15:30"> その回廊には、病人、目の見えない人、足の不自由な人、体の麻痺した人が大勢横たわり、水が動くのを待っていた。</span>
<span className="v" id="v4" data-v="4"> それは、ある時になると御使いが池に降りて水をかき動かし、水が動いた後、最初に入った者は、どんな病気にかかっていても癒やされたからである。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NUは、3節の「待っていた」から4節の終わりまでを省いている。">a</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 3:2; ルカ 8:43; マルコ 9:21"> そこに、三十八年間病気に苦しんでいる人がいた。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカ 18:41; ヘブル人への手紙 4:15; ヘブル人への手紙 4:13"> イエスはその人が横たわっているのを見て、すでに長い間病んでいることを知り、<span className="woj">「治りたいですか」</span>と尋ねられた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="詩篇 72:12; 申命記 32:36; コリント人への第一の手紙 9:24"> 病人は答えた。「先生、水がかき動かされた時、私を池に入れてくれる人がいません。私が行こうとしている間に、ほかの人が先に入ってしまうのです。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ルカ 5:24; マタイ 9:6; マルコ 2:11"> イエスは彼に<span className="woj">「起き上がり、敷物を取り上げて歩きなさい」</span>と言われた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 3:7–8; ヨハネ 9:14; マルコ 3:2–4"> すると、その人はすぐに良くなり、敷物を取り上げて歩き始めた。<br />その日は安息日であった。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 17:21; ルカ 6:2; ヨハネ 9:16"> そこでユダヤ人たちは、癒やされた人に言った。「今日は安息日だ。敷物を運ぶことは律法で許されていない。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="マルコ 2:9–11; ヨハネ 9:16"> 彼は答えた。「私を良くしてくださった方が、<span className="woj">『敷物を取り上げて歩きなさい』</span>と言われたのです。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マタイ 21:23; 士師記 6:29; ローマ人への手紙 10:2"> 彼らは尋ねた。「あなたに<span className="woj">『敷物を取り上げて歩きなさい』</span>と言ったのは、だれだ。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカ 4:30; ルカ 24:31; ヨハネ 8:59"> しかし、癒やされた人は、それがだれか知らなかった。その場所には群衆がいて、イエスは人々の間から立ち去っておられたからである。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ヨハネ 8:11; レビ記 26:23–24; 詩篇 118:18"> その後、イエスは宮で彼を見つけて言われた。<span className="woj">「見なさい。あなたはもう治りました。これからは罪を犯してはなりません。さもないと、もっと悪いことがあなたの身に起こるでしょう。」</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨハネ 9:11–12; ヨハネ 4:29; ヨハネ 9:25"> その人は立ち去り、自分を良くしてくださったのはイエスだとユダヤ人たちに告げた。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネ 10:39; ヨハネ 7:19–20; マルコ 3:6"> そのためユダヤ人たちはイエスを迫害し、殺そうとした。イエスが安息日にこのようなことを行われたからである。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネ 9:4; ヨハネ 14:10; コロサイ人への手紙 1:16"> しかし、イエスは彼らに答えられた。<span className="woj">「私の父は今も働いておられます。ですから、私も働いています。」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨハネ 10:30; ヨハネ 10:33; ヨハネ 19:7"> このためユダヤ人たちは、ますますイエスを殺そうとした。イエスが安息日を破っただけでなく、神をご自分の父と呼び、ご自分を神と等しい者とされたからである。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネ 12:49; ヨハネ 8:28; ヨハネ 14:10"> そこでイエスは彼らに答えられた。<span className="woj">「まことに、まことに、あなたがたに告げます。御子は自分からは何もできず、ただ父がなさるのを見るとおりに行います。父がなさることは何でも、御子も同じように行うからです。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネ 3:35; マタイ 3:17; ヨハネ 17:26"> <span className="woj">父は御子を愛し、ご自分がなさるすべてのことを御子に示されます。そして、あなたがたが驚くように、これらよりもさらに大きな業を御子に示されます。</span></span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 8:11; 申命記 32:39; ヨハネ 11:25"> <span className="woj">父が死者をよみがえらせて命を与えられるように、御子もまた、ご自分が望む者に命を与えます。</span></span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネ 5:27; 使徒の働き 17:31; コリント人への第二の手紙 5:10"> <span className="woj">父はだれをも裁かず、すべての裁きを御子に委ねられました。</span></span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの手紙第一 2:23; ルカ 10:16; マタイ 11:27"> <span className="woj">それは、すべての人が父を敬うのと同じように、御子をも敬うためです。御子を敬わない者は、御子を遣わされた父をも敬っていません。</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヨハネ 3:36; ヨハネ 6:40; ヨハネの手紙第一 5:11–13"> <span className="woj">まことに、まことに、あなたがたに告げます。私の言葉を聞いて、私を遣わされた方を信じる者には永遠の命があり、裁きを受けることがなく、すでに死から命へ移っています。</span></span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネ 5:28; エペソ人への手紙 5:14; エペソ人への手紙 2:5"> <span className="woj">まことに、まことに、あなたがたに告げます。死者が神の子の声を聞く時が来ます。今がその時です。そして、聞く者は生きます。</span></span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネ 11:26; ヨハネ 1:4; 出エジプト記 3:14"> <span className="woj">父がご自分のうちに命を持っておられるように、御子にもご自分のうちに命を持つことをお与えになりました。</span></span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 10:42; ヨハネ 5:22; 使徒の働き 17:31"> <span className="woj">また、人の子であるため、裁きを行う権威を御子にお与えになりました。</span></span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 20:12; テサロニケ人への手紙第一 4:14–17; イザヤ書 26:19"> <span className="woj">このことに驚いてはなりません。墓の中にいるすべての者が御子の声を聞く時が来るからです。</span></span>
<span className="v" id="v29" data-v="29" data-xref="ダニエル書 12:2–3; ローマ人への手紙 2:6–10; 使徒の働き 24:15"> <span className="woj">彼らは墓から出て来ます。良いことを行った者は命の復活へ、悪いことを行った者は裁きの復活へと出て来るのです。</span></span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネ 6:38; ヨハネ 5:19; ヨハネ 4:34"> <span className="woj">私は自分からは何もできません。私は聞いたとおりに裁きます。そして私の裁きは正しいのです。自分の意志ではなく、私を遣わされた父の御心を求めるからです。</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="箴言 27:2; ヨハネ 8:54; ヨハネの黙示録 3:14"> <span className="woj">もし私が自分についてあかしするなら、私のあかしは真実とは認められません。</span></span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネ 1:33; ヨハネ 12:28–30; ヨハネ 5:36–37"> <span className="woj">私についてあかしする別の方がおられます。私は、その方が私についてなさるあかしが真実であることを知っています。</span></span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネ 1:29–34; ヨハネ 3:26–36; ヨハネ 1:15–27"> <span className="woj">あなたがたはヨハネのもとに人を遣わし、彼は真理についてあかししました。</span></span>
<span className="v" id="v34" data-v="34" data-xref="ルカ 19:41–42; ヨハネ 20:31; ヨハネの手紙第一 5:9"> <span className="woj">しかし、私が受けるあかしは人からのものではありません。それでも、あなたがたが救われるために、私はこれらのことを言うのです。</span></span>
<span className="v" id="v35" data-v="35" data-xref="ペテロの第二の手紙 1:19; ヨハネ 1:7–8; マタイ 11:11"> <span className="woj">ヨハネは燃えて輝くともしびでした。あなたがたは、しばらくの間、その光の中で喜ぶことを望みました。</span></span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネ 10:25; ヨハネ 10:37–38; ヨハネ 15:24"> <span className="woj">しかし、私にはヨハネのあかしよりも偉大なあかしがあります。父が私に成し遂げるように与えられた業、すなわち私が行っているその業自体が、父が私を遣わされたことをあかししているからです。</span></span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネ 8:18; ヨハネ 1:18; マタイ 3:17"> <span className="woj">また、私を遣わされた父ご自身が、私についてあかしされました。あなたがたは、これまで一度もその声を聞いたことも、その姿を見たこともありません。</span></span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネの手紙第一 2:14; 申命記 6:6–9; ヨハネ 12:44–48"> <span className="woj">また、父の言葉があなたがたのうちにとどまっていません。父が遣わされた方を、あなたがたは信じていないからです。</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="ルカ 24:27; ルカ 24:44; ペテロの第二の手紙 1:19–21"> <span className="woj">あなたがたは、聖書の中に永遠の命があると考えて、聖書を調べています。その聖書こそ、私についてあかしするものです。</span></span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネ 3:19; ヨハネ 1:11; 詩篇 81:11"> <span className="woj">それなのに、あなたがたは命を得るために私のもとへ来ようとしません。</span></span>
<span className="v" id="v41" data-v="41" data-xref="ヨハネ 7:18; ヨハネ 5:34; テサロニケ人への手紙第一 2:6"> <span className="woj">私は人からの栄誉を受けません。</span></span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネの手紙第一 4:20; ヨハネの手紙第一 3:17; ヨハネ 2:25"> <span className="woj">しかし、私はあなたがたを知っています。あなたがたのうちには神の愛がありません。</span></span>
<span className="v" id="v43" data-v="43" data-xref="ヨハネ 10:25; マタイ 24:5; ヨハネ 17:4–6"> <span className="woj">私は父の名によって来たのに、あなたがたは私を受け入れません。ほかの者が自分の名によって来れば、あなたがたはその者を受け入れるでしょう。</span></span>
<span className="v" id="v44" data-v="44" data-xref="ヨハネ 12:43; ローマ人への手紙 2:29; ピリピ人への手紙 2:3"> <span className="woj">互いに栄誉を受けながら、唯一の神から来る栄誉を求めないあなたがたが、どうして信じることができるでしょうか。</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="ローマ人への手紙 3:19–20; ガラテヤ人への手紙 3:10; コリント人への第二の手紙 3:7–11"> <span className="woj">私が父の前であなたがたを訴えると思ってはなりません。あなたがたを訴える者がいます。あなたがたが望みを置いているモーセです。</span></span>
<span className="v" id="v46" data-v="46" data-xref="申命記 18:15; 申命記 18:18–19; ヨハネ 1:45"> <span className="woj">もしあなたがたがモーセを信じていたなら、私をも信じたでしょう。モーセは私について書いたからです。</span></span>
<span className="v" id="v47" data-v="47" data-xref="ルカ 16:31; ルカ 16:29"> <span className="woj">しかし、モーセの書いたものを信じないなら、どうして私の言葉を信じるでしょうか。」</span></span>
</div>

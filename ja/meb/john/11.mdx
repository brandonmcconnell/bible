<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカ 10:38–42; ヨハネ 12:17; 列王記第二 20:1–12"> さて、ある人が病気にかかっていた。マリアとその姉妹マルタの村ベタニアに住むラザロであった。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネ 12:3; マルコ 14:3; マタイ 26:6–7"> このマリアは、主に香油を塗り、自分の髪でその足をぬぐった人である。病気になったラザロは彼女の兄弟であった。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネ 11:5; ヨハネの黙示録 3:19; テモテへの第二の手紙 4:20"> そこで姉妹たちは、イエスのもとに人を遣わし、「主よ、見よ、あなたが深く愛しておられる者が病気です」と伝えた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ヨハネ 11:40; ヨハネ 9:3; ペテロの手紙第一 4:14"> しかしイエスはそれを聞いて言われた。<span className="woj">「この病気は死に至るものではなく、神の栄光のためのものです。それによって神の子が栄光を受けるためです。」</span></span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネ 15:9–13; ヨハネ 16:27; ヨハネ 17:26"> イエスはマルタとその姉妹とラザロを愛しておられた。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 30:18; イザヤ書 55:8–9; 創世記 45:1–5"> それで、ラザロが病気だと聞いても、イエスはおられた場所にさらに二日とどまられた。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネ 10:40–42; ルカ 9:51; 使徒の働き 20:22–24"> その後、弟子たちに<span className="woj">「もう一度ユダヤへ行きましょう」</span>と言われた。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨハネ 10:31; ヨハネ 8:59; 使徒の働き 21:12–13"> 弟子たちは尋ねた。「ラビ、つい先ほどユダヤ人たちがあなたを石打ちにしようとしたのに、またそこへ行かれるのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヨハネ 9:4; ヨハネ 12:35; エレミヤ書 31:9"> イエスは答えられた。<span className="woj">「昼は十二時間ではありませんか。昼間に歩く人は、この世の光を見るので、つまずきません。</span></span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの手紙第一 2:10–11; 箴言 4:18–19; エレミヤ書 13:16"> <span className="woj">しかし、夜に歩く人は、その人のうちに光がないので、つまずきます。」</span></span>
<span className="v" id="v11" data-v="11" data-xref="ダニエル書 12:2; ヨハネ 11:13; ヨハネ 11:43–44"> こう言った後、さらに彼らに言われた。<span className="woj">「私たちの友ラザロは眠っています。しかし、私は彼を眠りから起こすために行きます。」</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> そこで弟子たちは言った。「主よ、眠っているのなら、良くなるでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マタイ 9:24"> イエスはラザロの死について語られたのだが、弟子たちは眠って休んでいることを語られたと思ったのである。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネ 16:25; ヨハネ 16:29; ヨハネ 10:24"> そこでイエスは、彼らにはっきりと言われた。<span className="woj">「ラザロは死にました。</span></span>
<span className="v" id="v15" data-v="15" data-xref="テモテへの第二の手紙 2:10; ヨハネ 14:10–11; イザヤ書 54:15"> <span className="woj">私がそこにいなかったことを、あなたがたのために喜んでいます。それは、あなたがたが信じるためです。さあ、彼のところへ行きましょう。」</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヨハネ 13:37; マタイ 10:3; ヨハネ 21:2"> そこで、ディディモ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「ディディモ」は「双子」という意味である。">a</a></sup>と呼ばれるトマスが、仲間の弟子たちに言った。「私たちも行って、イエスと一緒に死のう。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヨハネ 11:39; ホセア書 6:2; 使徒の働き 2:27–31"> イエスが着くと、ラザロはすでに四日間、墓の中にいた。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 14:20; ヨハネの黙示録 21:16; ヨハネ 6:19"> ベタニアはエルサレムに近く、約十五スタディオン<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="十五スタディオンは約2.8キロメートル、または1.7マイルである。">b</a></sup>離れていた。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨブ記 2:11; ヨハネ 11:31; テサロニケ人への手紙第一 5:11"> 多くのユダヤ人が、兄弟を亡くしたマルタとマリアを慰めるため、二人のもとに来ていた。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカ 10:38–42; テサロニケ人への手紙第一 4:17; マタイ 25:1"> マルタは、イエスが来られると聞くと迎えに出たが、マリアは家に座っていた。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネ 11:32; 列王記第一 17:18; マタイ 9:18"> そこでマルタはイエスに言った。「主よ、もしここにいてくださったなら、私の兄弟は死ななかったでしょう。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネ 9:31; ヨハネ 11:41–42; マタイ 28:18"> しかし今でも、あなたが神に求めることは何でも、神があなたに与えてくださると知っています。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ヨハネ 11:43–44"> イエスは彼女に<span className="woj">「あなたの兄弟はよみがえります」</span>と言われた。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ダニエル書 12:2–3; 使徒の働き 24:15; ヨハネ 5:28–29"> マルタは言った。「終わりの日の復活の時に、彼がよみがえることは知っています。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="テサロニケ人への手紙第一 4:14; ヨハネ 3:36; ヨハネの手紙第一 5:11–12"> イエスは彼女に言われた。<span className="woj">「私が復活であり、命です。私を信じる者は、たとえ死んでも生きます。</span></span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネ 10:28; ヨハネ 5:24; ローマ人への手紙 8:13"> <span className="woj">生きていて私を信じる者は皆、決して死にません。あなたはこのことを信じますか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="マタイ 16:16; ヨハネ 6:69; ヨハネ 6:14"> 彼女は言った。「はい、主よ。あなたがキリスト、神の子、世に来られる方であると、私は信じています。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヨハネ 11:20; ヨハネ 13:13; マルコ 10:49"> こう言うと、マルタは帰って行き、姉妹マリアをひそかに呼んで、「先生が来て、あなたを呼んでおられます」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="箴言 15:23; 詩篇 27:8; 雅歌 3:1–4"> マリアはそれを聞くと、すぐに立ち上がり、イエスのもとへ向かった。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネ 11:20"> イエスはまだ村に入らず、マルタが出迎えた場所におられた。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネ 11:19; 創世記 37:35; サムエル記第二 12:16–18"> 家でマリアと一緒にいて彼女を慰めていたユダヤ人たちは、マリアが急いで立ち上がって出て行くのを見ると、「墓へ泣きに行くのだろう」と思い、彼女について行った。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="ヨハネ 11:21; ルカ 17:16; ルカ 5:8"> マリアはイエスのおられる所に来て、イエスを見ると、その足もとにひれ伏して言った。「主よ、もしここにいてくださったなら、私の兄弟は死ななかったでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="ヨハネ 11:38; ヨハネ 12:27; マルコ 3:5"> イエスは、マリアが泣き、一緒に来たユダヤ人たちも泣いているのを見て、霊の内に深くうめき、心を揺さぶられ、</span>
<span className="v" id="v34" data-v="34" data-xref="マルコ 15:47; マタイ 28:6; ヨハネ 1:39"> <span className="woj">「彼をどこに置きましたか」</span>と言われた。<br />彼らは「主よ、来て、ご覧ください」と答えた。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="ルカ 19:41; ヘブル人への手紙 4:15; ヨハネ 11:33"> イエスは涙を流された。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="ヨハネ 11:3; ヨハネの手紙第一 3:1; ヨハネの手紙第一 4:9–10"> そこでユダヤ人たちは言った。「見なさい。どれほどラザロを深く愛しておられたことか。」</span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネ 9:6–7; ヨハネ 11:32; ルカ 23:39"> しかし、彼らの中にはこう言う者もいた。「目の見えなかった人の目を開いたこの人が、ラザロを死なせないようにすることはできなかったのか。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="ヨハネ 11:33; ルカ 24:2; マタイ 27:60"> イエスは再び深くうめきながら、墓へ来られた。それは洞穴で、入り口には石が置かれていた。</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネ 11:17; マルコ 16:3; 詩篇 49:7"> イエスは<span className="woj">「石を取りのけなさい」</span>と言われた。<br />死んだ人の姉妹マルタは、「主よ、もう臭くなっています。死んで四日になりますから」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="ヨハネ 11:4; ヨハネ 11:23–26; ローマ人への手紙 4:17–25"> イエスは彼女に言われた。<span className="woj">「信じるなら神の栄光を見ると、あなたに言ったではありませんか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="マタイ 11:25; ヨハネ 17:1; 詩篇 123:1"> そこで人々は、死んだ人が横たわっていた場所から石を取りのけた。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="NUは「死んだ人が横たわっていた場所から」を省いている。">c</a></sup>イエスは目を上げて言われた。<span className="woj">「父よ、私の願いを聞いてくださったことを感謝します。</span></span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネ 3:17; ヨハネ 17:21; ヨハネの手紙第一 4:14"> <span className="woj">あなたがいつも私の願いを聞いてくださることを、私は知っています。しかし、周りに立っている群衆のために、私はこう言いました。あなたが私を遣わされたことを、彼らが信じるためです。」</span></span>
<span className="v" id="v43" data-v="43" data-xref="列王記第二 4:33–36; 使徒の働き 9:40; 使徒の働き 9:34"> こう言うと、イエスは大声で叫ばれた。<span className="woj">「ラザロ、出て来なさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="ヨハネ 5:25; ヨハネ 20:7; ヨハネ 11:25–26"> 死んでいた人が出て来た。その手足は布で巻かれ、顔も布で包まれていた。<br />イエスは人々に<span className="woj">「彼をほどいて、行かせなさい」</span>と言われた。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="ヨハネ 2:23; ヨハネ 11:19; ヨハネ 10:41"> そこで、マリアのもとに来て、イエスが行われたことを見たユダヤ人の多くが、イエスを信じた。</span>
<span className="v" id="v46" data-v="46" data-xref="ヨハネ 9:13; 使徒の働き 5:25; ヨハネ 12:37"> しかし、彼らの中にはパリサイ人たちのところへ行き、イエスが行われたことを知らせる者もいた。</span>
<span className="v" id="v47" data-v="47" data-xref="マタイ 26:3; ヨハネ 12:19; 使徒の働き 4:5–6"> そこで祭司長たちとパリサイ人たちは最高法院を招集して言った。「われわれは何をしているのか。この人は多くのしるしを行っている。</span>
<span className="v" id="v48" data-v="48" data-xref="テサロニケ人への手紙第一 2:15–16; マタイ 23:35–38; マタイ 27:25"> このままにしておけば、皆が彼を信じるだろう。そうなればローマ人が来て、われわれの場所も国民も奪うだろう。」</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="マタイ 26:3; ヨハネ 11:51; ヨハネ 18:13–14"> しかし、その年の大祭司であったカヤパという一人が、彼らに言った。「あなたがたは何も分かっていない。</span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネ 18:14; ルカ 24:46; ローマ人への手紙 3:8"> 一人の人が民のために死に、国民全体が滅びない方が、われわれにとって有益だということを考えてもいない。」</span>
<span className="v" id="v51" data-v="51" data-xref="ダニエル書 9:26; コリント人への第二の手紙 5:21; 出エジプト記 28:30"> 彼はこれを自分から言ったのではない。その年の大祭司であったので、イエスが国民のために死ぬことを預言したのである。</span>
<span className="v" id="v52" data-v="52" data-xref="ヨハネ 10:16; イザヤ書 49:6; ヨハネの手紙第一 2:2"> しかも国民のためだけではなく、各地に散らされている神の子どもたちを一つに集めるためでもあった。</span>
<span className="v" id="v53" data-v="53" data-xref="使徒の働き 5:33; 使徒の働き 9:23; マルコ 14:1"> そこで彼らは、その日からイエスを殺そうと相談した。</span>
<span className="v" id="v54" data-v="54" data-xref="ヨハネ 7:1; ヨハネ 7:4; 歴代誌 第二 13:19"> そのためイエスは、もはやユダヤ人たちの間を公然とは歩かず、そこを去って荒野に近い地方へ行き、エフライムという町で弟子たちとともに滞在された。</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="歴代誌 第二 30:17–20; ヘブル人への手紙 9:13–14; ヨハネ 6:4"> さて、ユダヤ人の過越の祭りが近づいていた。多くの人が自分を清めるため、過越の祭りの前に地方からエルサレムへ上った。</span>
<span className="v" id="v56" data-v="56" data-xref="ヨハネ 7:11; ヨハネ 11:7–8"> 彼らはイエスを捜し、宮に立ちながら互いに言った。「どう思うか。あの人は祭りに全く来ないのだろうか。」</span>
<span className="v" id="v57" data-v="57" data-xref="ヨハネ 9:22; ヨハネ 8:59; ヨハネ 5:16–18"> 祭司長たちとパリサイ人たちは、イエスがどこにいるか知っている者は届け出るようにと命じていた。イエスを捕らえるためであった。</span>
</div>

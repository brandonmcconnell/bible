<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコ 14:3–8; ヨハネ 11:1; ルカ 24:50"> 過越の祭りの六日前、イエスはベタニアに来られた。そこには、死んでいたのをイエスが死者の中からよみがえらせたラザロがいた。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカ 22:27; ルカ 10:38–42; ヨハネの黙示録 3:20"> 人々はそこでイエスのために夕食を用意した。マルタが給仕し、ラザロはイエスとともに食卓に着いている人々の一人であった。</span>
<span className="v" id="v3" data-v="3" data-xref="マルコ 14:3–9; ヨハネ 11:2; ルカ 10:38–39"> そこでマリアは、非常に高価な純粋なナルドの香油一ローマ・ポンド<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="ローマの一ポンドは12オンス、または約340グラムである。">a</a></sup>を取り、イエスの足に塗り、自分の髪でその足をぬぐった。家は香油の香りでいっぱいになった。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="マタイ 10:4; サムエル記第一 17:28–29; ヨハネ 13:2"> すると、弟子の一人で、イエスを裏切ろうとしていたシモンの子ユダ・イスカリオテが言った。</span>
<span className="v" id="v5" data-v="5" data-xref="ルカ 18:22; ルカ 12:33; マルコ 14:4–5"> 「なぜこの香油を三百デナリ<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="三百デナリは農業労働者のほぼ一年分の賃金であった。">b</a></sup>で売って、貧しい人々に施さなかったのか。」</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 13:29; 詩篇 50:16–20; ヤコブの手紙 2:6"> 彼がこう言ったのは、貧しい人々を心にかけていたからではなく、彼が盗人だったからである。彼は金入れを預かり、その中に入れられたものを盗んでいた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マタイ 26:12; マルコ 14:6; マタイ 27:57–60"> しかしイエスは言われた。<span className="woj">「彼女をそのままにしておきなさい。彼女は私の埋葬の日のために、これを取っておいたのです。</span></span>
<span className="v" id="v8" data-v="8" data-xref="申命記 15:11; マルコ 14:7; マタイ 26:11"> <span className="woj">貧しい人々はいつもあなたがたとともにいますが、私はいつもあなたがたとともにいるわけではありません。」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 4:14; ヨハネ 11:43–45; 使徒の働き 3:10–11"> さて、大勢のユダヤ人が、イエスがそこにおられることを知ってやって来た。イエスのためだけではなく、イエスが死者の中からよみがえらせたラザロを見るためでもあった。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカ 16:31; マタイ 2:16; ヨハネ 11:47–53"> ところが祭司長たちは、ラザロも殺そうと相談した。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネ 11:45; ヨハネ 12:18; 使徒の働き 13:45"> ラザロのために、多くのユダヤ人が去ってイエスを信じたからである。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マルコ 11:7–10; マタイ 21:4–9; ルカ 19:35–38"> 翌日、祭りに来ていた大勢の群衆は、イエスがエルサレムに来られると聞いて、</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 118:25–26; ヨハネの黙示録 15:3; マタイ 21:9–11"> なつめやしの枝を手に取り、イエスを迎えに出て叫んだ。「ホサナ。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「ホサナ」は「私たちを救ってください」または「どうか私たちを助けてください」という意味である。">c</a></sup>主の名によって来られる方、イスラエルの王は幸いである。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ゼカリヤ書 9:9; マルコ 11:1–7; マタイ 21:1–7"> イエスは一頭の若いろばを見つけ、それに乗られた。こう書かれているとおりである。</span>
<span className="v" id="v15" data-v="15" data-xref="ゼカリヤ書 9:9; イザヤ書 62:11; ゼパニヤ書 3:16–17"> 「シオンの娘よ、恐れてはならない。見よ、あなたの王が、ろばの子に乗って来られる。」</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネ 2:22; ヨハネ 14:26; ヨハネ 7:39"> 弟子たちは初め、これらのことを理解しなかった。しかし、イエスが栄光を受けられた時、これらのことがイエスについて書かれていたこと、また人々がイエスにこのようにしたことを思い出した。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの黙示録 1:2; ヨハネの手紙第一 5:9–12; ヨハネ 19:35"> イエスがラザロを墓から呼び出し、死者の中からよみがえらせた時に一緒にいた群衆は、そのことをあかししていた。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネ 12:11"> 群衆がイエスを迎えに出たのも、イエスがこのしるしを行われたと聞いたからである。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 17:6; 詩篇 22:27; ヨハネの手紙第一 2:2"> そこでパリサイ人たちは互いに言った。「見なさい。何をしても無駄だ。見よ、世全体が彼について行った。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヨハネ 7:35; イザヤ書 11:10; 使徒の働き 17:4"> さて、祭りで礼拝するために上って来た人々の中に、何人かのギリシャ人がいた。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイ 2:2; ルカ 19:2–4; ヨハネ 6:40"> 彼らはガリラヤのベツサイダ出身のフィリポのところへ来て、「先生、イエスにお会いしたいのです」と頼んだ。</span>
<span className="v" id="v22" data-v="22" data-xref="マルコ 10:13–14; ルカ 9:49–50; ヨハネ 1:40–41"> フィリポはアンデレのところへ行って伝えた。それからアンデレとフィリポはイエスのところへ行って伝えた。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ヨハネ 13:31–32; ヨハネ 17:1–5; イザヤ書 60:9"> イエスは彼らに答えられた。<span className="woj">「人の子が栄光を受ける時が来ました。</span></span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第一の手紙 15:36–38; イザヤ書 53:10–12; ヘブル人への手紙 2:9–10"> <span className="woj">まことに、まことに、あなたがたに告げます。一粒の麦が地に落ちて死ななければ、それはただ一粒のままです。しかし、死ぬなら、多くの実を結びます。</span></span>
<span className="v" id="v25" data-v="25" data-xref="マタイ 10:39; ルカ 9:23–24; マルコ 8:35"> <span className="woj">自分の命を愛する者は、それを失います。この世で自分の命を憎む者は、それを保って永遠の命に至ります。</span></span>
<span className="v" id="v26" data-v="26" data-xref="コロサイ人への手紙 3:24; ガラテヤ人への手紙 1:10; サムエル記第一 2:30"> <span className="woj">私に仕える者は、私に従いなさい。私がいる所に、私に仕える者もいます。だれでも私に仕えるなら、父はその人を重んじてくださいます。</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ヨハネ 12:23; ヘブル人への手紙 5:7; マタイ 26:42"> <span className="woj">今、私の心は騒いでいます。私は何と言えばよいのでしょう。『父よ、この時から私を救ってください』と言うべきでしょうか。しかし、私はこのために、この時に来たのです。</span></span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネ 13:31–32; マタイ 26:42; ヨハネの黙示録 5:9–14"> <span className="woj">父よ、あなたの御名の栄光を現してください。」</span><br />すると天から、「私はすでに御名の栄光を現した。再び現す」という声がした。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ヨブ記 37:2–5; ヨハネの黙示録 6:1; ヨハネの黙示録 14:2"> そばに立っていてその声を聞いた群衆は、「雷が鳴ったのだ」と言った。ほかの者たちは「御使いがイエスに話しかけたのだ」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ヨハネ 11:42; ヨハネ 11:15; ヨハネ 5:34"> イエスは答えられた。<span className="woj">「この声がしたのは、私のためではなく、あなたがたのためです。</span></span>
<span className="v" id="v31" data-v="31" data-xref="コリント人への第二の手紙 4:4; ヨハネの手紙第一 5:19; ヨハネの手紙第一 3:8"> <span className="woj">今、この世が裁かれます。今、この世の支配者が追い出されます。</span></span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネ 3:14; ヨハネ 8:28; ペテロの手紙第一 2:24"> <span className="woj">そして私は、地から上げられる時、すべての人を自分のもとに引き寄せます。」</span></span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネ 18:32; ヨハネ 21:19"> イエスは、ご自分がどのような死に方で死ぬかを示すために、こう言われたのである。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="エゼキエル書 37:24–25; イザヤ書 9:7; ダニエル書 7:14"> 群衆はイエスに答えた。「私たちは、キリストは永遠にとどまると律法から聞いている。それなのに、どうしてあなたは<span className="woj">『人の子は上げられなければならない』</span>と言うのか。その人の子とはだれなのか。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="ヨハネ 12:46; ヨハネ 16:16; エペソ人への手紙 5:8"> そこでイエスは彼らに言われた。<span className="woj">「光はもうしばらく、あなたがたとともにあります。闇に追いつかれないよう、光がある間に歩きなさい。闇の中を歩く者は、自分がどこへ行くのか分かりません。</span></span>
<span className="v" id="v36" data-v="36" data-xref="エペソ人への手紙 5:8; ヨハネ 8:59; 使徒の働き 13:47–48"> <span className="woj">光がある間に光を信じ、光の子どもとなりなさい。」</span>イエスはこう言うと、立ち去って彼らから身を隠された。</span>
<span className="v" id="v37" data-v="37" data-xref="ルカ 16:31; ヨハネ 1:11; ヨハネ 15:24"> イエスが彼らの前でこれほど多くのしるしを行われたのに、彼らはイエスを信じなかった。</span>
<span className="v" id="v38" data-v="38" data-xref="イザヤ書 53:1; ローマ人への手紙 10:16; ローマ人への手紙 10:20"> それは、預言者イザヤが語った言葉が実現するためであった。<br /><span className="pl pl-1">「主よ、だれがわれわれの知らせを信じたのか。</span><br /><span className="pl pl-2">主の御腕はだれに現されたのか。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v39" data-v="39" data-xref="ヨハネ 10:38; ヨハネ 5:44; ペテロの第二の手紙 2:14"> 彼らが信じることができなかったのは、イザヤがさらにこう言っているからである。</span>
<span className="v" id="v40" data-v="40" data-xref="イザヤ書 6:10; マタイ 13:13–15; ルカ 8:10"> <span className="pl pl-1">「神は彼らの目を見えなくし、彼らの心をかたくなにされた。</span><br /><span className="pl pl-2">それは、彼らが目で見ることも、</span><br /><span className="pl pl-2">心で悟ることも、</span><br /><span className="pl pl-2">立ち返ることもなく、</span><br /><span className="pl pl-2">私が彼らを癒やすこともないためである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="イザヤ書 6:1–5; イザヤ書 6:9–10; ヨハネ 1:14"> イザヤがこれらのことを言ったのは、イエスの栄光を見て、イエスについて語ったからである。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネ 9:22; ヨハネ 7:13; イザヤ書 51:7"> それでも、指導者たちの中でさえ多くの者がイエスを信じた。しかし、会堂から追放されないように、パリサイ人たちを恐れて告白しなかった。</span>
<span className="v" id="v43" data-v="43" data-xref="ヨハネ 5:44; マタイ 23:5–7; ヨハネ 5:41"> 彼らは神からの称賛よりも、人からの称賛を愛したからである。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="マタイ 10:40; ヨハネ 13:20; ヨハネ 5:24"> イエスは大声で言われた。<span className="woj">「私を信じる者は、私だけでなく、私を遣わされた方を信じるのです。</span></span>
<span className="v" id="v45" data-v="45" data-xref="ヨハネ 14:9–10; コリント人への第二の手紙 4:6; コロサイ人への手紙 1:15"> <span className="woj">私を見る者は、私を遣わされた方を見ます。</span></span>
<span className="v" id="v46" data-v="46" data-xref="ヨハネ 8:12; 詩篇 36:9; ヨハネ 9:5"> <span className="woj">私は光として世に来ました。それは、私を信じる者がだれも闇の中にとどまらないためです。</span></span>
<span className="v" id="v47" data-v="47" data-xref="ヨハネ 3:17; ヨハネ 8:15–16; ヨハネ 12:48"> <span className="woj">だれかが私の言葉を聞いて信じなくても、私はその人を裁きません。私は世を裁くためではなく、世を救うために来たからです。</span></span>
<span className="v" id="v48" data-v="48" data-xref="ルカ 10:16; ヘブル人への手紙 9:27–28; ローマ人への手紙 2:16"> <span className="woj">私を拒み、私の言葉を受け入れない者には、その人を裁くものがあります。私が語った言葉が、終わりの日にその人を裁きます。</span></span>
<span className="v" id="v49" data-v="49" data-xref="ヨハネ 14:10; ヨハネ 8:26; ヨハネ 5:30"> <span className="woj">私は自分から語ったのではありません。私を遣わされた父が、何を言い、何を語るべきかを私に命じられました。</span></span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネ 17:3; ヨハネ 6:68; ヨハネの手紙第一 5:20"> <span className="woj">私は、父の命令が永遠の命であることを知っています。ですから私は、父が私に言われたとおりに語るのです。」</span></span>
</div>

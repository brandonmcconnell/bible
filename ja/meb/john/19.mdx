<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="JHN" data-book-slug="john" data-book-name="ヨハネ" data-chapter="19" data-verses="42">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 53:5; イザヤ書 50:6; マタイ 20:19"> そこでピラトはイエスを引き取り、むちで打たせた。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコ 15:16–20; ルカ 23:11; マタイ 27:27–31"> 兵士たちは茨を編んで冠を作り、イエスの頭にかぶせ、紫の衣を着せた。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイ 27:29; マタイ 26:49; ルカ 1:28"> そして「ユダヤ人の王、万歳」と繰り返し言いながら、イエスを平手で打ち続けた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ヨハネ 18:38; ヨハネ 19:6; ルカ 23:4"> ピラトは再び外へ出て行き、彼らに言った。「見よ、私はこの男をあなたがたの前に連れ出す。私がこの男に何の罪状も認めないことを、あなたがたに知らせるためだ。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ヨハネ 19:2; ヘブル人への手紙 12:2; イザヤ書 7:14"> そこでイエスは、茨の冠をかぶり、紫の衣を着て、外へ出て来られた。ピラトは彼らに言った。「見よ、この人だ。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 18:31; ヨハネ 19:4; 使徒の働き 2:23"> 祭司長たちと下役たちはイエスを見ると、「十字架につけろ。十字架につけろ」と叫んだ。<br />ピラトは彼らに言った。「あなたがたがこの男を引き取り、十字架につけなさい。私はこの男に何の罪状も認めない。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="レビ記 24:16; ヨハネ 5:18; マタイ 26:63–66"> ユダヤ人たちは彼に答えた。「私たちには律法があり、私たちの律法によれば、この男は死ななければなりません。自分を神の子としたからです。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨハネ 19:13; 使徒の働き 14:11–19"> ピラトはこの言葉を聞くと、ますます恐れた。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネ 18:33; 詩篇 38:13–15; ピリピ人への手紙 1:28"> そして再び総督官邸に入り、イエスに「あなたはどこから来たのか」と言った。しかし、イエスは何もお答えにならなかった。</span>
<span className="v" id="v10" data-v="10" data-xref="ダニエル書 5:19; ヨハネ 18:39; ダニエル書 3:14–15"> そこでピラトはイエスに言った。「私に答えないのか。私にはあなたを釈放する権力も、十字架につける権力もあることを知らないのか。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 13:1; ヨハネ 3:27; 使徒の働き 2:23"> イエスは答えられた。<span className="woj">「上から与えられていなければ、あなたには私に対する何の権限もないでしょう。ですから、私をあなたに引き渡した者には、より大きな罪があります。」</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 17:6–7; ヨハネ 18:33–36; マルコ 6:16–26"> これを聞いて、ピラトはイエスを釈放しようと努めた。しかしユダヤ人たちは叫んだ。「この男を釈放するなら、あなたはカエサルの友ではない。自分を王とする者は皆、カエサルに逆らう者だ。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 82:5–7; マタイ 27:19; アモス書 4:7"> そこでピラトはこれらの言葉を聞くと、イエスを外へ連れ出し、「敷石」と呼ばれ、ヘブル語では「ガバタ」と呼ばれる場所で、裁判の席に着いた。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイ 27:62; ヨハネ 19:5; マルコ 15:25"> その日は過越の祭りの備えの日で、時刻は第六時ごろであった。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「第六時」は、ローマ式の時刻の数え方では午前六時、当時使われていたユダヤ式では正午であった。">a</a></sup>ピラトはユダヤ人たちに言った。「見よ、あなたがたの王だ。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ルカ 23:18; 使徒の働き 21:36; ヨハネ 19:6"> 彼らは叫んだ。「連れて行け。連れて行け。十字架につけろ。」<br />ピラトは彼らに言った。「あなたがたの王を十字架につけるのか。」<br />祭司長たちは答えた。「私たちにはカエサルのほかに王はいません。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ルカ 23:24–25; マタイ 27:26–31; マルコ 15:15–20"> そこでピラトは、イエスを十字架につけさせるために彼らに引き渡した。彼らはイエスを引き取り、連れて行った。</span>
<span className="v" id="v17" data-v="17" data-xref="ルカ 23:33; ルカ 14:27; ルカ 23:26"> イエスはご自分で十字架を背負い、「どくろの場所」と呼ばれ、ヘブル語で「ゴルゴタ」と呼ばれる所へ出て行かれた。</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 53:12; マルコ 15:24–27; ガラテヤ人への手紙 3:13"> そこで彼らはイエスを十字架につけ、イエスとともにほかの二人を、一人ずつ両側に、イエスを真ん中にして十字架につけた。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイ 27:37; ルカ 23:38; マルコ 15:26"> ピラトは罪状書きも書いて、十字架の上に掲げた。そこには「ナザレのイエス、ユダヤ人の王」と書かれていた。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 26:14; ヨハネの黙示録 16:16; 使徒の働き 22:2"> 多くのユダヤ人がこの罪状書きを読んだ。イエスが十字架につけられた場所は都に近く、それがヘブル語、ラテン語、ギリシャ語で書かれていたからである。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネ 19:14; ヨハネ 19:19"> そこでユダヤ人の祭司長たちはピラトに言った。「『ユダヤ人の王』と書かず、『この男は「私はユダヤ人の王だ」と言った』と書いてください。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="詩篇 76:10; 詩篇 65:7; 箴言 8:29"> ピラトは答えた。「私が書いたことは、書いたままにしておく。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="ルカ 23:34; マルコ 15:24; マタイ 27:35"> 兵士たちはイエスを十字架につけると、その衣を取って四つに分け、それぞれの兵士に一つずつ与えた。下着も取ったが、その下着には縫い目がなく、上から下まで一枚織りであった。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 22:18; ヨハネ 19:28; ヨハネ 19:36–37"> そこで彼らは互いに言った。「これは裂かずに、だれのものになるか、くじを引いて決めよう。」これは、次の聖書の言葉が実現するためであった。<br /><span className="pl pl-1">「彼らは私の衣を分け合い、</span><br /><span className="pl pl-2">私の服をくじ引きにした。」</span><br />兵士たちはこのように行った。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ルカ 23:49; マタイ 27:55–56; ヨハネ 20:1"> イエスの十字架のそばには、イエスの母、その母の姉妹、クロパの妻マリア、マグダラのマリアが立っていた。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネ 21:24; ヨハネ 20:2; ヨハネ 2:4"> イエスは母と、ご自分が愛しておられた弟子がそばに立っているのを見て、母に言われた。<span className="woj">「婦人よ、見よ、あなたの息子です。」</span></span>
<span className="v" id="v27" data-v="27" data-xref="マタイ 12:48–50; ヨハネ 16:32; テモテへの手紙第一 5:2–4"> それから、その弟子に言われた。<span className="woj">「見よ、あなたの母です。」</span>その時から、その弟子は彼女を自分の家に迎えた。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="詩篇 69:21; 詩篇 22:15; ヨハネ 19:30"> この後、イエスはすべてのことがすでに終わったのを見て、<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NUとTRは「見て」の代わりに「知って」としている。">b</a></sup>聖書の言葉が実現するために、<span className="woj">「渇く。」</span>と言われた。</span>
<span className="v" id="v29" data-v="29" data-xref="民数記 19:18; ルカ 23:36; マルコ 15:36"> そこには酸いぶどう酒をいっぱい入れた器が置いてあった。そこで人々は、そのぶどう酒をたっぷり含ませた海綿をヒソプにつけ、イエスの口もとに差し出した。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネ 17:4; ピリピ人への手紙 2:8; コロサイ人への手紙 2:14–17"> イエスはその酸いぶどう酒を受けると、<span className="woj">「成し遂げられた。」</span>と言われた。そして頭を垂れ、ご自分の霊をお渡しになった。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ヨハネ 19:14; ヨハネ 19:42; マルコ 15:42"> その日は備えの日であった。その安息日は特別な日だったので、ユダヤ人たちは安息日に遺体を十字架に残しておかないため、彼らの脚を折って、遺体を取り降ろすようピラトに願った。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネ 19:18; ルカ 23:39–43"> そこで兵士たちが来て、イエスとともに十字架につけられた最初の者と、もう一人の者の脚を折った。</span>
<span className="v" id="v33" data-v="33"> しかしイエスのところに来て、すでに死んでおられるのを見ると、その脚は折らなかった。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネの手紙第一 5:6; ゼカリヤ書 12:10; ゼカリヤ書 13:1"> けれども、兵士の一人が槍でイエスの脇腹を突き刺すと、すぐに血と水が流れ出た。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネ 21:24; ヘブル人への手紙 2:3–4; ヨハネの手紙第一 1:1–3"> それを見た者があかしした。そのあかしは真実である。彼は自分が真実を語っていることを知っている。それは、あなたがたも信じるためである。</span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 34:20; 民数記 9:12; 出エジプト記 12:46"> これらのことが起こったのは、「その骨は一本も折られない」という聖書の言葉が実現するためであった。</span>
<span className="v" id="v37" data-v="37" data-xref="ゼカリヤ書 12:10; ヨハネの黙示録 1:7; 詩篇 22:16–17"> また別の聖書の言葉には、「彼らは自分たちが突き刺した者を見上げる」とある。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="マルコ 15:42–47; マタイ 27:57–61; 箴言 29:25"> これらのことの後、アリマタヤのヨセフが、イエスの体を引き取らせてほしいとピラトに願った。彼はイエスの弟子であったが、ユダヤ人たちを恐れて、そのことを隠していた。ピラトは許可した。そこで彼は来て、イエスの体を引き取った。</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネ 7:50–52; 雅歌 4:14; ヨハネ 3:1–21"> 初め夜にイエスのもとへ来たニコデモも、没薬とアロエを混ぜたものを百ローマ・ポンドほど持って来た。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一ローマ・ポンドは12オンスであり、百ローマ・ポンドは約72ポンド、または33キログラムである。">c</a></sup></span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネ 11:44; ヨハネ 20:5–7; 使徒の働き 5:6"> そこで彼らはイエスの体を取り、ユダヤ人の埋葬の習慣に従って、香料とともに亜麻布で包んだ。</span>
<span className="v" id="v41" data-v="41" data-xref="ルカ 23:53; マタイ 27:60; ヨハネ 20:15"> イエスが十字架につけられた場所には園があり、その園には、まだだれも葬られたことのない新しい墓があった。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネ 19:31; ヨハネ 19:14; イザヤ書 53:9"> その日はユダヤ人の備えの日であり、その墓が近かったので、彼らはそこにイエスを納めた。</span>
</div>

</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 5:17; ヨハネ 3:5–6; ペテロの手紙第一 1:23–25"> イエスは答えられた。<span className="woj">「まことに、まことに、あなたに告げます。人は新しく生まれなければ、</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="ここ、およびヨハネ3:7で「新しく」と訳された言葉（ἄνωθεν）には、「再び」または「上から」という意味もある。">a</a></sup><span className="woj">神の国を見ることはできません。」</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 2:14; コリント人への第一の手紙 1:18; ヨハネ 3:3"> ニコデモは言った。「人は年を取ってから、どうして生まれることができるでしょう。もう一度母の胎内に入って生まれることができるでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 36:25–27; エペソ人への手紙 5:26; 使徒の働き 2:38"> イエスは答えられた。<span className="woj">「まことに、まことに、あなたに告げます。人は水と霊から生まれなければ、神の国に入ることはできません。</span></span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 5:16–21; エゼキエル書 36:26–27; ローマ人への手紙 8:4–9"> <span className="woj">肉から生まれるものは肉であり、霊から生まれるものは霊です。</span></span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネ 3:3; エペソ人への手紙 4:22–24; ローマ人への手紙 12:1–2"> <span className="woj">『あなたがたは新しく生まれなければならない』と私が言ったことを、不思議に思ってはなりません。</span></span>
<span className="v" id="v8" data-v="8" data-xref="伝道者の書 11:4–5; コリント人への第一の手紙 2:11; 使徒の働き 2:2"> <span className="woj">風</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="同じギリシャ語（πνεῦμα）は、風、息、霊を意味する。">b</a></sup><span className="woj">は思いのままに吹きます。あなたはその音を聞いても、どこから来てどこへ行くのか知りません。霊から生まれる者も皆、そのようです。」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヨハネ 6:60; ルカ 1:34; イザヤ書 42:16"> ニコデモは「どうしてそのようなことがあり得るのですか」と尋ねた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="マタイ 22:29; エレミヤ書 8:8–9; エゼキエル書 11:19"> イエスは答えられた。<span className="woj">「あなたはイスラエルの教師なのに、これらのことが分からないのですか。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネ 8:38; ヨハネの手紙第一 5:6–12; ヨハネ 12:49"> <span className="woj">まことに、まことに、あなたに告げます。われわれは知っていることを語り、見たことをあかししているのに、あなたがたはわれわれのあかしを受け入れません。</span></span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 3:1–2; コリント人への第一の手紙 2:7–9; ヘブル人への手紙 5:11"> <span className="woj">私が地上のことを話してもあなたがたが信じないなら、天上のことを話した時、どうして信じるでしょう。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 30:4; ヨハネ 6:38; 使徒の働き 2:34"> <span className="woj">天から下って来た者、すなわち天にいる人の子のほかには、だれも天に上ったことはありません。</span></span>
<span className="v" id="v14" data-v="14" data-xref="民数記 21:7–9; ヨハネ 8:28; ヨハネ 12:32–34"> <span className="woj">モーセが荒野で蛇を上げたように、人の子も上げられなければなりません。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネ 3:16; ヨハネ 6:40; ヨハネ 12:44–46"> <span className="woj">それは、この方を信じる者がだれも滅びることなく、永遠の命を持つためです。</span></span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 5:8; ヨハネの手紙第一 4:9–10; ヨハネ 3:15"> <span className="woj">神は世をこれほどまでに愛し、そのひとり子</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「ひとり子」という表現は、ギリシャ語の「μονογενη」から来ており、「ただ一人、生まれた者」または「唯一の者」と訳されることもある。">c</a></sup><span className="woj">をお与えになりました。それは、この方を信じる者がだれも滅びることなく、永遠の命を持つためです。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの手紙第一 4:14; ルカ 19:10; ヨハネ 12:47–48"> <span className="woj">神が御子を世に遣わされたのは、世を裁くためではなく、御子を通して世が救われるためです。</span></span>
<span className="v" id="v18" data-v="18" data-xref="マルコ 16:16; ヨハネの手紙第一 5:10; ローマ人への手紙 8:1"> <span className="woj">御子を信じる者は裁かれません。信じない者はすでに裁かれています。神のひとり子の名を信じていないからです。</span></span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネ 8:12; テサロニケ人への第二の手紙 2:12; ヨハネ 9:39–41"> <span className="woj">その裁きとは、光が世に来たのに、人々が光よりも闇を愛したということです。彼らの行いが悪かったからです。</span></span>
<span className="v" id="v20" data-v="20" data-xref="エペソ人への手紙 5:11–13; ヨハネ 7:7; ヨブ記 24:13–17"> <span className="woj">悪を行う者は皆、光を憎み、自分の行いが明るみに出されないように、光のもとへ来ません。</span></span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの手紙第一 1:6; 詩篇 139:23–24; ヨハネの手紙第三 1:11"> <span className="woj">しかし、真理を行う者は、自分の行いが神にあってなされたことが明らかになるように、光のもとへ来ます。」</span></span>
</div>

<span className="v" id="v23" data-v="23" data-xref="マルコ 1:4–5; エゼキエル書 43:2; マタイ 3:5–6"> ヨハネもサリムに近いアイノンでバプテスマを授けていた。そこには水が豊かにあったからである。人々は来てバプテスマを受けた。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイ 4:12; マタイ 14:3; マルコ 6:17"> ヨハネはまだ投獄されていなかった。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネ 2:6; マタイ 3:11; ヘブル人への手紙 6:2"> ところが、ヨハネの弟子たちとあるユダヤ人たちとの間で、清めについての議論が起こった。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネ 1:7; ヨハネ 1:15; ヨハネ 12:19"> 彼らはヨハネのもとに来て言った。「ラビ、見よ、ヨルダン川の向こうであなたと一緒にいて、あなたがあかしされた方が、バプテスマを授けています。皆がその方のところへ行っています。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ヤコブの手紙 1:17; コリント人への第一の手紙 4:7; コリント人への第一の手紙 15:10"> ヨハネは答えた。「人は、天から与えられなければ、何も受けることができない。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネ 1:20; ヨハネ 1:23; マタイ 3:11–12"> 『私はキリストではなく、その方より先に遣わされた者である』と私が言ったことについて、あなたがた自身が私の証人である。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイ 9:15; ホセア書 2:19; イザヤ書 54:5"> 花嫁を持つ者が花婿である。花婿の友人はそばに立ってその声を聞き、花婿の声を聞いて大いに喜ぶ。こうして、私の喜びは満ちた。</span>
<span className="v" id="v30" data-v="30" data-xref="コロサイ人への手紙 1:18; 詩篇 72:17–19; ヘブル人への手紙 3:2–6"> あの方はますます栄え、私は衰えなければならない。</span>
</div>

<span className="v" id="v32" data-v="32" data-xref="ヨハネ 3:11; ヨハネ 15:15; ヨハネ 1:11"> この方は見聞きしたことをあかしされるが、だれもそのあかしを受け入れない。</span>
<span className="v" id="v33" data-v="33" data-xref="ヘブル人への手紙 6:17; エペソ人への手紙 1:13; テトス 1:1–2"> そのあかしを受け入れた者は、神が真実であることに、自ら証印を押したのである。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒の働き 10:38; マタイ 12:18; ヨハネ 15:26"> 神が遣わされた方は神の言葉を語られる。神は限りなく聖霊をお与えになるからである。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイ 28:18; ヨハネ 5:22; ヨハネ 5:20"> 父は御子を愛し、すべてのものをその手に委ねられた。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネ 5:24; ヨハネ 1:12; テサロニケ人への手紙第一 5:9"> 御子を信じる者には永遠の命がある。しかし、御子に従わない<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="この文脈では、同じ言葉を「従わない」とも「信じない」とも訳すことができる。">d</a></sup>者は命を見ることがなく、神の怒りがその上にとどまる。」</span>

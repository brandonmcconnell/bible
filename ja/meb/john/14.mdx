<span className="v" id="v3" data-v="3" data-xref="テサロニケ人への手紙第一 4:16–17; ヨハネ 12:26; テモテへの第二の手紙 2:12"> <span className="woj">私が行ってあなたがたのために場所を備えたなら、再び来て、あなたがたを私のもとに迎えます。私がいる所に、あなたがたもいるためです。</span></span>

<div className="bp">

<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 4:12; ヨハネ 10:9; エペソ人への手紙 2:18"> イエスは彼に言われた。<span className="woj">「私は道であり、真理であり、命です。私を通してでなければ、だれも父のもとに来ることはありません。</span></span>
<span className="v" id="v7" data-v="7" data-xref="コロサイ人への手紙 1:15–17; ヨハネ 8:19; ルカ 10:22"> <span className="woj">あなたがたが私を知っていたなら、私の父をも知っていたでしょう。今からあなたがたは父を知り、すでに父を見たのです。」</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 33:18–23; ヨハネの黙示録 22:3–5; ヨハネ 1:43–46"> フィリポがイエスに言った。「主よ、私たちに父をお示しください。そうすれば十分です。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="コロサイ人への手紙 1:15; ヨハネ 12:45; ヨハネ 14:7"> イエスは彼に言われた。<span className="woj">「フィリポ、こんなに長い間あなたがたとともにいるのに、あなたは私を知らないのですか。私を見た者は父を見たのです。どうして『私たちに父を示してください』と言うのですか。</span></span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネ 5:19; ヨハネ 10:38; ヨハネ 10:30"> <span className="woj">私が父のうちにいて、父が私のうちにおられることを信じないのですか。私があなたがたに告げる言葉は、自分から語っているのではありません。私のうちに住んでおられる父が、ご自分の業を行っておられるのです。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネ 10:38; ヨハネ 10:25; ヨハネ 5:36"> <span className="woj">私が父のうちにいて、父が私のうちにおられると信じなさい。そうでなければ、業そのもののゆえに信じなさい。</span></span>
<span className="v" id="v12" data-v="12" data-xref="マタイ 21:21; マルコ 16:17; ルカ 10:17–19"> <span className="woj">まことに、まことに、あなたがたに告げます。私を信じる者は、私が行う業をその人も行い、これらよりもさらに大きな業を行います。私が父のもとへ行くからです。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネ 15:7; マルコ 11:24; マタイ 7:7"> <span className="woj">あなたがたが私の名によって求めることは何でも、私はそれを行います。父が子によって栄光を受けられるためです。</span></span>
<span className="v" id="v14" data-v="14"> <span className="woj">あなたがたが私の名によって何かを求めるなら、私はそれを行います。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの手紙第一 2:3–5; ヨハネの手紙第一 5:2–3; ヨハネ 14:21–24"> <span className="woj">あなたがたが私を愛するなら、私の戒めを守りなさい。</span></span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネ 14:26; ヨハネ 15:26; ヨハネ 16:7–15"> <span className="woj">私は父にお願いします。父はもう一人の助け主をあなたがたに与えてくださいます。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="ギリシャ語のπαρακλητονには、助言者、助け主、執り成す者、弁護者、慰め主という意味がある。">a</a></sup><span className="woj">その方が永遠にあなたがたとともにいるためです。</span></span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 36:27; ヨハネ 16:13; ヨハネの手紙第一 2:27"> <span className="woj">その方は真理の霊です。世はその方を見ることも知ることもないので、受け入れることができません。あなたがたはその方を知っています。その方はあなたがたとともに住み、あなたがたのうちにおられるようになるからです。</span></span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネ 14:3; 詩篇 23:4; マタイ 18:20"> <span className="woj">私はあなたがたを孤児のままにはしておきません。あなたがたのところに来ます。</span></span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネ 16:16; ヨハネ 7:33; ヘブル人への手紙 7:25"> <span className="woj">もうしばらくすると、世はもはや私を見なくなります。しかし、あなたがたは私を見ます。私が生きているので、あなたがたも生きるのです。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネ 15:5–7; ガラテヤ人への手紙 2:20; ヨハネ 17:21–23"> <span className="woj">その日には、私が父のうちにいて、あなたがたが私のうちに、私があなたがたのうちにいることが分かります。</span></span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネ 14:15; ヨハネの手紙第一 5:3; ヨハネの手紙第一 2:5"> <span className="woj">私の戒めを持って、それを守る人こそ、私を愛する人です。私を愛する人は私の父に愛され、私もその人を愛し、私自身をその人に現します。」</span></span>
</div>

<span className="v" id="v24" data-v="24" data-xref="ヨハネ 7:16; ヨハネ 14:10; ヨハネ 8:42"> <span className="woj">私を愛さない者は、私の言葉を守りません。あなたがたが聞いている言葉は私のものではなく、私を遣わされた父のものです。」</span></span>

<span className="v" id="v26" data-v="26" data-xref="ヨハネ 15:26; ヨハネ 14:16; ヨハネの手紙第一 2:27"> <span className="woj">しかし、助け主、すなわち父が私の名によって遣わされる聖霊は、あなたがたにすべてのことを教え、私があなたがたに話したすべてのことを思い起こさせてくださいます。</span></span>
<span className="v" id="v27" data-v="27" data-xref="ピリピ人への手紙 4:7; ヨハネ 16:33; イザヤ書 41:10"> <span className="woj">私はあなたがたに平安を残します。私の平安をあなたがたに与えます。世が与えるように、私は与えるのではありません。心を騒がせてはなりません。恐れてもなりません。</span></span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネ 10:29–30; コリント人への第一の手紙 15:24–28; コリント人への第一の手紙 11:3"> <span className="woj">『私は去って行きますが、あなたがたのところに戻って来ます』と私が言ったのを、あなたがたは聞きました。私を愛しているなら、私が『父のもとへ行く』と言ったことを喜んだでしょう。父は私より偉大だからです。</span></span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネ 13:19; ヨハネ 16:4–31; マタイ 24:24–25"> <span className="woj">今、私はそれが起こる前に、あなたがたに告げました。それが起こった時、あなたがたが信じるためです。</span></span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの手紙第一 5:19; ヨハネの手紙第一 4:4; ヨハネの黙示録 12:9"> <span className="woj">私はもう、あなたがたと多くは語りません。この世の支配者が来るからです。彼は私に対して何の権利も持っていません。</span></span>

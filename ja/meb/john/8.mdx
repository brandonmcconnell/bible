<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 21:1; マルコ 11:1; ルカ 19:37"> しかし、イエスはオリーブ山へ行かれた。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="マタイ 26:55; ルカ 4:20; ルカ 21:37"> 朝早く、イエスは再び宮に来られた。民は皆、イエスのもとに来た。イエスは座って、彼らを教えられた。</span>
<span className="v" id="v3" data-v="3"> 律法学者たちとパリサイ人たちは、姦淫の現場で捕らえられた一人の女を連れて来た。そして彼女を真ん中に立たせ、</span>
<span className="v" id="v4" data-v="4"> イエスに言った。「先生、この女は姦淫をしている現場で捕らえられました。</span>
<span className="v" id="v5" data-v="5" data-xref="レビ記 20:10; 申命記 22:21–24; エゼキエル書 16:38–40"> 律法の中で、モーセはこのような女を石打ちにするよう、われわれに命じています。それでは、あなたは彼女について何と言いますか。」</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 17:13; ルカ 10:25; 伝道者の書 3:7"> 彼らがこう言ったのは、イエスを試し、訴える口実を得るためであった。<br />しかし、イエスは身をかがめ、指で地面に書いておられた。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイ 7:1–5; ローマ人への手紙 2:21–25; ローマ人への手紙 2:1–3"> それでも彼らが問い続けたので、イエスは身を起こして言われた。<span className="woj">「あなたがたの中で罪のない者が、まずこの女に石を投げなさい。」</span></span>
<span className="v" id="v8" data-v="8"> そして再び身をかがめ、指で地面に書かれた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="伝道者の書 7:22; ローマ人への手紙 2:15; ヨハネの手紙第一 3:20"> 彼らはそれを聞くと、良心に責められ、年長者から始めて最後の者に至るまで、一人また一人と出て行った。イエスだけが残され、女はその場の真ん中に残っていた。</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 41:11–12"> イエスは立ち上がって彼女を見て、<span className="woj">「婦人よ、あなたを訴えた人たちはどこにいますか。だれもあなたを罪に定めなかったのですか」</span>と言われた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヨハネ 3:17; ヨハネ 5:14; イザヤ書 1:16–18"> 彼女は「主よ、だれも」と答えた。<br />イエスは言われた。<span className="woj">「私もあなたを罪に定めません。行きなさい。これからは、もう罪を犯してはなりません。」</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NUはヨハネ7:53からヨハネ8:11までを含めているが、本文が原文にあったことについて本文批評家の確信が低いことを示すため、角括弧で囲んでいる。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨハネ 12:46; ヨハネ 9:5; ヨハネ 12:35"> そこでイエスは再び人々に語られた。<span className="woj">「私は世の光です。私に従う者は闇の中を歩むことがなく、命の光を持ちます。」</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨハネ 5:31–47"> そこでパリサイ人たちはイエスに言った。「あなたは自分についてあかししている。あなたのあかしは有効ではない。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ヨハネ 16:28; ヨハネ 13:3; ヨハネ 8:42"> イエスは彼らに答えられた。<span className="woj">「たとえ私が自分についてあかししても、私のあかしは真実です。私はどこから来て、どこへ行くのかを知っています。しかし、あなたがたは私がどこから来て、どこへ行くのかを知りません。</span></span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記第一 16:7; ヨハネ 7:24; ヨハネ 12:47"> <span className="woj">あなたがたは肉に従って裁きます。私はだれも裁きません。</span></span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 17:31; ヨハネ 8:29; ヨハネ 16:32"> <span className="woj">しかし、たとえ私が裁いても、私の裁きは真実です。私だけではなく、私を遣わされた父がともにおられるからです。</span></span>
<span className="v" id="v17" data-v="17" data-xref="申命記 19:15; 申命記 17:6; ヘブル人への手紙 10:28"> <span className="woj">あなたがたの律法にも、二人の人のあかしは有効であると書かれています。</span></span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネ 8:38; ヨハネ 8:58; ヨハネ 8:25"> <span className="woj">私は自分についてあかしする者であり、私を遣わされた父も私についてあかしされます。」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨハネ 16:3; ヨハネ 8:54–55; ヨハネ 14:6–9"> そこで彼らはイエスに「あなたの父はどこにいるのか」と尋ねた。<br />イエスは答えられた。<span className="woj">「あなたがたは私も、私の父も知りません。もし私を知っていたなら、私の父をも知っていたでしょう。」</span></span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネ 7:30; ヨハネ 7:8; マルコ 12:41"> イエスは宮で教えておられた時、宝物庫でこれらの言葉を語られた。それでも、だれもイエスを捕らえなかった。イエスの時がまだ来ていなかったからである。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネ 7:34; ヨハネ 8:24; コリント人への第一の手紙 15:17–18"> そこでイエスは再び彼らに言われた。<span className="woj">「私は去って行きます。あなたがたは私を捜しますが、自分の罪のうちに死にます。私が行く所に、あなたがたは来ることができません。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨハネ 8:52; 詩篇 22:6; ヨハネ 8:48"> そこでユダヤ人たちは言った。「彼は<span className="woj">『私が行く所に、あなたがたは来ることができない』</span>と言っている。自殺するつもりなのか。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ヨハネ 3:31; ヨハネ 17:14; ヨハネ 17:16"> イエスは彼らに言われた。<span className="woj">「あなたがたは下から来た者です。私は上から来た者です。あなたがたはこの世に属しています。私はこの世に属していません。</span></span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネ 3:36; マルコ 16:16; ヨハネ 3:18"> <span className="woj">ですから私は、あなたがたは自分の罪のうちに死ぬと言ったのです。私がその者であると信じなければ、</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または、「わたしはある」。">b</a></sup><span className="woj">あなたがたは自分の罪のうちに死ぬからです。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ヨハネ 5:17–29; ルカ 22:67; ヨハネ 1:22"> そこで彼らはイエスに「あなたはだれなのか」と尋ねた。<br />イエスは彼らに言われた。<span className="woj">「初めからあなたがたに言っているとおりの者です。</span></span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネ 15:15; ヨハネ 12:47–50; ヨハネ 8:40"> <span className="woj">私には、あなたがたについて語り、裁くべきことが多くあります。しかし、私を遣わされた方は真実です。私はその方から聞いたことを世に語ります。」</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 6:9; ヨハネ 8:43; コリント人への第二の手紙 4:3–4"> 彼らは、イエスが父について語っておられることを理解しなかった。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネ 5:19; ヨハネ 5:30; ヨハネ 6:38"> そこでイエスは彼らに言われた。<span className="woj">「あなたがたが人の子を上げた時、私がその者であること、また私が自分からは何もせず、父が私に教えられたとおりにこれらのことを語っていることが分かります。</span></span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネ 6:38; ヨハネ 16:32; ヨハネ 4:34"> <span className="woj">私を遣わされた方は私とともにおられます。父は私を一人にされません。私はいつも父に喜ばれることを行うからです。」</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ヨハネ 7:31; ヨハネ 2:23; ヨハネ 11:45"> イエスがこれらのことを語られると、多くの人がイエスを信じた。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの手紙第二 1:9; ヨハネ 15:4–9; テモテへの第二の手紙 3:14"> そこでイエスは、ご自分を信じたユダヤ人たちに言われた。<span className="woj">「あなたがたが私の言葉にとどまるなら、本当に私の弟子です。</span></span>
<span className="v" id="v32" data-v="32" data-xref="ローマ人への手紙 8:2; ヨハネ 8:36; ヨハネ 17:17"> <span className="woj">あなたがたは真理を知り、真理はあなたがたを自由にします。」</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="マタイ 3:9; ヨハネ 8:39; 創世記 15:13"> 彼らはイエスに答えた。「われわれはアブラハムの子孫であり、これまでだれの奴隷になったこともない。それなのに、どうしてあなたは<span className="woj">『あなたがたは自由にされる』</span>と言うのか。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ローマ人への手紙 6:16; ペテロの第二の手紙 2:19; 箴言 5:22"> イエスは彼らに答えられた。<span className="woj">「まことに、まことに、あなたがたに告げます。罪を犯す者は皆、罪の奴隷です。</span></span>
<span className="v" id="v35" data-v="35" data-xref="ガラテヤ人への手紙 4:4–7; ルカ 15:31; ローマ人への手紙 8:15–17"> <span className="woj">奴隷はいつまでも家にいるわけではありません。しかし、子はいつまでもいます。</span></span>
<span className="v" id="v36" data-v="36" data-xref="コリント人への第二の手紙 3:17; ガラテヤ人への手紙 5:1; ローマ人への手紙 8:2"> <span className="woj">ですから、御子があなたがたを自由にするなら、あなたがたは本当に自由になります。</span></span>
<span className="v" id="v37" data-v="37" data-xref="コリント人への第一の手紙 2:14; ヨハネ 8:45–47; ヨハネ 7:1"> <span className="woj">あなたがたがアブラハムの子孫であることは知っています。それでもあなたがたは私を殺そうとしています。私の言葉があなたがたのうちに入る余地がないからです。</span></span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネ 5:19; ヨハネ 8:44; ヨハネ 8:41"> <span className="woj">私は父のもとで見たことを語っています。あなたがたも、自分の父のもとで見たことを行っています。」</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="ガラテヤ人への手紙 3:7; ヨハネ 8:37; ローマ人への手紙 9:7"> 彼らはイエスに「われわれの父はアブラハムだ」と答えた。<br />イエスは彼らに言われた。<span className="woj">「もしあなたがたがアブラハムの子どもなら、アブラハムの行いをするはずです。</span></span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネ 8:26; ガラテヤ人への手紙 4:29; ガラテヤ人への手紙 4:16"> <span className="woj">ところが今、あなたがたは、神から聞いた真理をあなたがたに告げた者である私を殺そうとしています。アブラハムはそのようなことをしませんでした。</span></span>
<span className="v" id="v41" data-v="41" data-xref="イザヤ書 64:8; ヨハネ 8:38; イザヤ書 63:16"> <span className="woj">あなたがたは、自分の父の行いをしているのです。」</span><br />彼らはイエスに言った。「われわれは淫らな関係から生まれたのではない。われわれにはただ一人の父、神がおられる。」</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="ヨハネ 12:49; ヨハネ 14:10; ヨハネ 17:8"> そこでイエスは彼らに言われた。<span className="woj">「もし神があなたがたの父であったなら、あなたがたは私を愛したでしょう。私は神から出て、ここに来たからです。私は自分から来たのではなく、神が私を遣わされたのです。</span></span>
<span className="v" id="v43" data-v="43" data-xref="ヨハネ 12:39–40; ローマ人への手紙 8:7–8; ヨハネ 7:17"> <span className="woj">なぜあなたがたは私の話すことを理解しないのですか。それは、私の言葉を聞き入れることができないからです。</span></span>
<span className="v" id="v44" data-v="44" data-xref="使徒の働き 13:10; ヨハネの手紙第一 3:12; ヨハネの手紙第一 3:8–10"> <span className="woj">あなたがたは、あなたがたの父である悪魔から出た者であり、自分の父の欲望を行いたいのです。悪魔は初めから人殺しであり、真理のうちに立っていません。彼のうちに真理がないからです。彼が偽りを語る時、自分の本性から語ります。彼は偽り者であり、偽りの父だからです。</span></span>
<span className="v" id="v45" data-v="45" data-xref="テモテへの第二の手紙 4:3–4; ガラテヤ人への手紙 4:16; ヨハネ 18:37"> <span className="woj">しかし、私が真理を語るので、あなたがたは私を信じません。</span></span>
<span className="v" id="v46" data-v="46" data-xref="ヘブル人への手紙 4:15; ヨハネ 16:8; ペテロの手紙第一 2:22"> <span className="woj">あなたがたのうち、だれが私に罪があると証明できますか。私が真理を語っているなら、なぜ私を信じないのですか。</span></span>
<span className="v" id="v47" data-v="47" data-xref="ヨハネ 10:26–27; ヨハネの手紙第二 1:9; ヨハネ 18:37"> <span className="woj">神から出た者は神の言葉を聞きます。あなたがたが聞かないのは、神から出た者ではないからです。」</span></span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="ヨハネ 7:20; ヨハネ 8:52; マタイ 10:5"> そこでユダヤ人たちはイエスに答えた。「あなたはサマリア人で、悪霊に取りつかれていると、われわれが言うのは正しいではないか。」</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="ペテロの手紙第一 2:23; イザヤ書 49:3; ヨハネ 13:31–32"> イエスは答えられた。<span className="woj">「私は悪霊に取りつかれてはいません。私は父を敬っていますが、あなたがたは私を辱めています。</span></span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネ 5:41; ヨハネ 8:54; ヨハネ 7:18"> <span className="woj">しかし、私は自分の栄光を求めません。それを求め、裁く方がおられます。</span></span>
<span className="v" id="v51" data-v="51" data-xref="ヨハネ 11:25–26; ヨハネ 5:24; ヨハネ 3:15–16"> <span className="woj">まことに、まことに、あなたがたに告げます。だれでも私の言葉を守るなら、その人は決して死を見ることがありません。」</span></span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="ヨハネ 9:24; ヨハネ 8:48; ヘブル人への手紙 2:9"> そこでユダヤ人たちはイエスに言った。「今、あなたが悪霊に取りつかれていることが分かった。アブラハムも預言者たちも死んだ。それなのにあなたは、<span className="woj">『だれでも私の言葉を守るなら、その人は決して死を味わうことがない』</span>と言う。</span>
<span className="v" id="v53" data-v="53" data-xref="ヨハネ 4:12; ローマ人への手紙 9:5; ヘブル人への手紙 7:1–7"> あなたは、死んだわれわれの父アブラハムより偉いのか。預言者たちも死んだ。あなたは自分を何者だと言うのか。」</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="ヨハネ 8:50; 箴言 25:27; ペテロの第二の手紙 1:17"> イエスは答えられた。<span className="woj">「もし私が自分に栄光を与えるなら、私の栄光には何の意味もありません。私に栄光を与えてくださるのは私の父です。あなたがたが『われわれの神だ』と言っている方です。</span></span>
<span className="v" id="v55" data-v="55" data-xref="ヨハネ 8:19; ヨハネ 8:44; ヨハネ 7:28–29"> <span className="woj">あなたがたはその方を知りませんが、私は知っています。もし『その方を知らない』と言えば、私もあなたがたと同じく偽り者になるでしょう。しかし、私はその方を知り、その言葉を守っています。</span></span>
<span className="v" id="v56" data-v="56" data-xref="ヘブル人への手紙 11:13; 創世記 22:18; ガラテヤ人への手紙 3:7–9"> <span className="woj">あなたがたの父アブラハムは、私の日を見ることを喜びました。彼はそれを見て喜んだのです。」</span></span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57"> そこでユダヤ人たちはイエスに言った。「あなたはまだ五十歳にもなっていない。それなのに、アブラハムを見たのか。」</span>
</div>
<div className="bp">
<span className="v" id="v58" data-v="58" data-xref="出エジプト記 3:14; コロサイ人への手紙 1:17; ヨハネ 17:5"> イエスは彼らに言われた。<span className="woj">「まことに、まことに、あなたがたに告げます。アブラハムが存在する前から、私はある。」</span></span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="ヨハネ 11:8; ヨハネ 10:30–33; ヨハネ 10:39–40"> そこで彼らは、イエスに投げつけようと石を拾った。しかし、イエスは身を隠し、彼らの真ん中を通り抜けて宮から出て行き、そのまま立ち去られた。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 7:15; ヨハネ 10:8–10; ローマ人への手紙 16:18"> <span className="woj">「まことに、まことに、あなたがたに告げます。羊の囲いに戸口から入らず、ほかの所を乗り越えて入る者は、盗人であり強盗です。</span></span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネ 10:14; 使徒の働き 20:28; ペテロの手紙第一 5:4"> <span className="woj">しかし、戸口から入る者は羊の牧者です。</span></span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 34:11–16; テモテへの第二の手紙 2:19; ヨハネ 10:4"> <span className="woj">門番は牧者のために門を開き、羊はその声を聞きます。牧者は自分の羊を一匹ずつ名を呼んで連れ出します。</span></span>
<span className="v" id="v4" data-v="4" data-xref="申命記 1:30; ヨハネ 10:16; ヨハネ 12:26"> <span className="woj">自分の羊をすべて外に出すと、その先頭に立って進みます。羊はその声を知っているので、牧者について行きます。</span></span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの手紙第一 4:5–6; コロサイ人への手紙 2:6–10; マルコ 4:24"> <span className="woj">しかし、知らない者には決してついて行かず、かえって逃げます。知らない者たちの声を知らないからです。」</span></span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 56:11; 詩篇 82:5; 箴言 28:5"> イエスはこのたとえを彼らに話されたが、彼らはイエスが何を言っておられるのか理解しなかった。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨハネ 14:6; エペソ人への手紙 2:18; ヨハネ 10:1"> そこでイエスは再び彼らに言われた。<span className="woj">「まことに、まことに、あなたがたに告げます。私が羊の戸口です。</span></span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 34:2; エレミヤ書 23:1; ヨハネ 10:1"> <span className="woj">私より前に来た者は皆、盗人であり強盗です。しかし、羊は彼らの言うことを聞きませんでした。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネ 14:6; エペソ人への手紙 2:18; ヨハネ 10:7"> <span className="woj">私が戸口です。だれでも私を通って入るなら救われ、出入りして牧草を見つけます。</span></span>
<span className="v" id="v10" data-v="10" data-xref="ルカ 19:10; ヨハネ 6:51; ヨハネ 12:47"> <span className="woj">盗人が来るのは、盗み、殺し、滅ぼすためにほかなりません。私が来たのは、羊たちが命を得、しかも豊かに得るためです。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヨハネ 10:14–15; 詩篇 23:1; ヨハネ 15:13"> <span className="woj">私は良い牧者です。良い牧者は羊のために自分の命を捨てます。</span></span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 20:29; ゼカリヤ書 11:16–17; エゼキエル書 34:2–6"> <span className="woj">雇われ人は牧者ではなく、羊も自分のものではありません。そのため、狼が来るのを見ると、羊を残して逃げてしまいます。狼は羊を奪い、散らします。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ピリピ人への手紙 2:20; ヨハネ 12:6; 使徒の働き 18:17"> <span className="woj">雇われ人が逃げるのは、雇われ人であって、羊のことを心にかけていないからです。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネ 10:27; ヨハネ 10:11; テモテへの第二の手紙 2:19"> <span className="woj">私は良い牧者です。私は自分の羊を知っており、私の羊も私を知っています。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ガラテヤ人への手紙 1:4; ヨハネ 10:11; イザヤ書 53:10"> <span className="woj">それは、父が私を知り、私が父を知っているのと同じです。私は羊のために自分の命を捨てます。</span></span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 56:8; ヨハネ 11:52; ペテロの手紙第一 2:25"> <span className="woj">私には、この囲いに属していないほかの羊もいます。私はその羊たちをも連れて来なければなりません。彼らは私の声を聞き、一つの群れ、一人の牧者となります。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネ 10:18; ヨハネ 10:11; ヘブル人への手紙 2:9"> <span className="woj">父が私を愛してくださるのは、私が自分の命を捨てるからです。それは、私が再び命を得るためです。</span></span>
<span className="v" id="v18" data-v="18" data-xref="ヘブル人への手紙 2:9; テトス 2:14; ヨハネ 2:19–21"> <span className="woj">だれも私から命を奪うのではありません。私が自分から命を捨てるのです。私にはそれを捨てる権威があり、再び得る権威もあります。私はこの命令を父から受けました。」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨハネ 9:16; コリント人への第一の手紙 3:3; ヨハネ 7:40–43"> これらの言葉のため、ユダヤ人たちの間に再び分裂が生じた。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネ 7:20; マルコ 3:21; ヨハネ 8:47–48"> 彼らの多くは言った。「彼は悪霊に取りつかれ、気が狂っている。なぜ彼の言うことを聞くのか。」</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 4:11; イザヤ書 35:5–6; 詩篇 94:9"> ほかの者たちは言った。「これは悪霊に取りつかれた者の言葉ではない。悪霊に目の見えない人の目を開くことができるだろうか。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> そのころ、エルサレムでは宮きよめの祭り<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「宮きよめの祭り」は、神殿が再び奉献されたことを祝う「ハヌカ」のギリシャ語名である。">a</a></sup>が行われた。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒の働き 5:12; 使徒の働き 3:11"> 冬であった。イエスは宮の中のソロモンの回廊を歩いておられた。</span>
<span className="v" id="v24" data-v="24" data-xref="ルカ 22:67–70; ヨハネ 1:19; ヨハネ 8:25"> するとユダヤ人たちがイエスを取り囲み、言った。「いつまでわれわれを迷わせておくのか。あなたがキリストなら、はっきり言ってくれ。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ヨハネ 10:38; ヨハネ 8:58; ヨハネ 14:11"> イエスは彼らに答えられた。<span className="woj">「私はあなたがたに言いましたが、あなたがたは信じません。私が父の名によって行う業が、私についてあかししています。</span></span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネ 8:47; コリント人への第二の手紙 4:3–4; ヨハネ 12:37–40"> <span className="woj">しかし、私が言ったように、あなたがたは私の羊ではないので信じません。</span></span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネ 10:16; ヨハネ 10:14; ヨハネの黙示録 3:20"> <span className="woj">私の羊は私の声を聞きます。私は彼らを知っており、彼らは私に従います。</span></span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネ 6:39–40; ヨハネ 6:37; ヨハネ 3:15–16"> <span className="woj">私は彼らに永遠の命を与えます。彼らは決して滅びず、だれも彼らを私の手から奪い去ることはできません。</span></span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネ 6:37; ヨハネ 17:2; ヨハネ 17:9"> <span className="woj">彼らを私に与えてくださった私の父は、すべてのものより偉大です。だれも彼らを父の手から奪い去ることはできません。</span></span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネ 1:1–2; ヨハネ 14:9; ヨハネ 17:21–23"> <span className="woj">私と父とは一つです。」</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ヨハネ 5:18; ヨハネ 8:59; サムエル記第一 30:6"> そこでユダヤ人たちは、イエスを石打ちにしようとして、再び石を拾った。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネの手紙第一 3:12; ヨハネ 5:36; 詩篇 35:12"> イエスは彼らに答えられた。<span className="woj">「私は父から出た多くの良い業をあなたがたに示しました。そのうちのどの業のために、私を石打ちにするのですか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="ヨハネ 5:18; レビ記 24:16; ヨハネ 10:30"> ユダヤ人たちは答えた。「良い業のために石打ちにするのではない。冒涜のためだ。あなたは人間でありながら、自分を神としているからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="詩篇 82:6–7; 出エジプト記 7:1; 詩篇 82:1"> イエスは彼らに答えられた。<span className="woj">「あなたがたの律法に、『私は言った。あなたがたは神々である』と書かれているではありませんか。</span></span>
<span className="v" id="v35" data-v="35" data-xref="マタイ 24:35; ローマ人への手紙 13:1; ルカ 16:17"> <span className="woj">神の言葉を受けた人々を神々と呼んだのであれば、そして聖書が無効にされることはないのですから、</span></span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネ 5:17–18; ヨハネ 3:17; エレミヤ書 1:5"> <span className="woj">父が聖別して世に遣わされた者が『私は神の子です』と言ったからといって、あなたがたは『神を冒涜している』と言うのですか。</span></span>
<span className="v" id="v37" data-v="37" data-xref="ヨハネ 15:24; ヨハネ 10:25; ヨハネ 12:37–40"> <span className="woj">もし私が父の業を行っていないなら、私を信じてはなりません。</span></span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネ 14:20; ヨハネ 10:25; ヨハネ 10:30"> <span className="woj">しかし、行っているなら、たとえ私を信じなくても、その業を信じなさい。それは、父が私のうちにおられ、私が父のうちにいることを、あなたがたが知って信じるためです。」</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="ヨハネ 7:30; ヨハネ 8:59; ヨハネ 7:44"> そこで彼らは再びイエスを捕らえようとした。しかし、イエスは彼らの手を逃れられた。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネ 1:28; ヨハネ 11:54; ヨハネ 7:1"> イエスは再びヨルダン川の向こう側へ行き、ヨハネが初めにバプテスマを授けていた場所に滞在された。</span>
<span className="v" id="v41" data-v="41" data-xref="ヨハネ 1:33–34; ヨハネ 1:29–30; マルコ 1:37"> 多くの人がイエスのもとに来て言った。「ヨハネは一つもしるしを行わなかったが、この方についてヨハネが言ったことはすべて真実だった。」</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネ 4:41; ヨハネ 2:23; ヨハネ 7:31"> そこで多くの人がイエスを信じた。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 12:6–23; マタイ 26:2–5; ヨハネ 11:55–57"> さて、過越と呼ばれる種なしパンの祭りが近づいていた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネ 11:47–53; マタイ 12:14; ルカ 20:19"> 祭司長たちと律法学者たちは、どうすればイエスを殺せるかと考えていた。民を恐れていたからである。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ヨハネ 13:2; マルコ 14:10–11; ヨハネ 13:26–27"> その時、十二人の一人に数えられていた、イスカリオテと呼ばれるユダにサタンが入った。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 4:1; 使徒の働き 5:24; ルカ 22:52"> ユダは出かけて行き、祭司長たちや神殿の警備隊長たちと、どうすればイエスを引き渡せるか相談した。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイ 26:15–16; 使徒の働き 1:18; マタイ 27:3–5"> 彼らは喜び、ユダに金を与えることに同意した。</span>
<span className="v" id="v6" data-v="6" data-xref="マルコ 14:2; マタイ 26:5"> ユダも承知し、群衆のいない時にイエスを引き渡す機会をうかがった。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 12:18; マルコ 14:12–16; コリント人への第一の手紙 5:7"> 過越のいけにえをほふらなければならない、種なしパンの日が来た。</span>
<span className="v" id="v8" data-v="8" data-xref="マルコ 14:13–16; 使徒の働き 4:19; 使徒の働き 4:13"> イエスはペテロとヨハネを遣わして言った。<span className="woj">「行って、私たちが食べる過越の食事を用意しなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 二人はイエスに言った。「どこに用意することをお望みですか。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ヨハネ 16:4; マタイ 26:18–19; 使徒の働き 8:26–29"> イエスは彼らに言った。<span className="woj">「見よ、あなたがたが都に入ると、水がめを運んでいる男に出会う。その人が入って行く家までついて行きなさい。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネ 11:28; ヨハネの黙示録 3:20; ルカ 19:34"> <span className="woj">そして、その家の主人にこう言いなさい。『先生があなたに、「弟子たちと一緒に過越の食事をする客間はどこですか」と言っています。』</span></span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 16:14–15; 使徒の働き 1:13; ヨハネ 2:25"> <span className="woj">すると主人は、家具の整った広い二階の部屋を見せてくれる。そこで用意しなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカ 21:33; ルカ 19:32; ヨハネ 2:5"> 二人が行ってみると、イエスが言ったとおりだったので、過越の食事を用意した。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マタイ 26:20; マルコ 14:17; 申命記 16:6–7"> 時刻になると、イエスは十二使徒とともに食卓に着いた。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカ 12:50; ヨハネ 4:34; ヨハネ 17:1"> そして彼らに言った。<span className="woj">「私は苦しみを受ける前に、あなたがたと一緒にこの過越の食事をしたいと、心から願っていた。</span></span>
<span className="v" id="v16" data-v="16" data-xref="ルカ 14:15; ヨハネの黙示録 19:9; ルカ 22:30"> <span className="woj">あなたがたに言う。過越が神の王国で成就するまでは、私は二度とこれを食べない。」</span></span>
<span className="v" id="v17" data-v="17" data-xref="ルカ 22:19; 詩篇 116:13; 申命記 8:10"> イエスは杯を受け取り、感謝をささげてから言った。<span className="woj">「これを受け取り、互いに分けなさい。</span></span>
<span className="v" id="v18" data-v="18" data-xref="マタイ 26:29; ルカ 22:16; マルコ 14:25"> <span className="woj">あなたがたに言う。神の王国が来るまでは、私は今から後、ぶどうの実からできたものを決して飲まない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="コリント人への第一の手紙 11:23–29; コリント人への第一の手紙 10:16; マルコ 14:22–24"> また、パンを取り、感謝をささげてから裂き、弟子たちに与えて言った。<span className="woj">「これは、あなたがたのために与えられる私の体である。私を覚えるために、これを行いなさい。」</span></span>
<span className="v" id="v20" data-v="20" data-xref="マタイ 26:28; コリント人への第一の手紙 11:25; ゼカリヤ書 9:11"> 食事の後、同じように杯を取り、言った。<span className="woj">「この杯は、あなたがたのために注ぎ出される私の血による新しい契約である。</span></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 41:9; ヨハネ 13:26; ヨハネ 13:21–22"> <span className="woj">しかし見よ、私を裏切る者の手が、私とともに食卓の上にある。</span></span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 2:23; 詩篇 109:6–15; 詩篇 55:12–15"> <span className="woj">人の子は定められたとおりに去って行く。しかし、人の子を裏切るその者には災いがある。」</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ヨハネ 13:22–25; マルコ 14:19; マタイ 26:22"> 弟子たちは、このようなことをする者は自分たちのうちのだれかと、互いに問い始めた。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ルカ 9:46; マルコ 9:34; マルコ 10:37–41"> また、自分たちのうちでだれが一番偉いと見なされるかをめぐって、弟子たちの間に争いが起こった。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイ 20:25–28; マルコ 10:41–45"> イエスは彼らに言った。<span className="woj">「異邦人の王たちは民を支配し、民の上に権力を振るう者たちは『恩人』と呼ばれている。</span></span>
<span className="v" id="v26" data-v="26" data-xref="ペテロの手紙第一 5:5; ルカ 9:48; マタイ 18:3–5"> <span className="woj">しかし、あなたがたはそうであってはならない。あなたがたの中で一番偉い者は一番若い者のように、治める者は仕える者のようになりなさい。</span></span>
<span className="v" id="v27" data-v="27" data-xref="マタイ 20:28; ルカ 12:37; ヨハネ 13:5–16"> <span className="woj">食卓に着く者と給仕する者では、どちらが偉いか。食卓に着く者ではないか。しかし私は、仕える者としてあなたがたの中にいる。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ヘブル人への手紙 2:18; ヘブル人への手紙 4:15; 使徒の働き 1:25"> <span className="woj">「あなたがたは、私が試練に遭っている間も、ともに歩み続けてくれた者たちである。</span></span>
<span className="v" id="v29" data-v="29" data-xref="マタイ 25:34; テモテへの第二の手紙 2:12; ヤコブの手紙 2:5"> <span className="woj">私の父が私に王国を授けてくださったように、私もあなたがたに王国を授ける。</span></span>
<span className="v" id="v30" data-v="30" data-xref="マタイ 19:28; マタイ 8:11; ヨハネの黙示録 2:26–27"> <span className="woj">それは、あなたがたが私の王国で私の食卓に着いて食べたり飲んだりし、王座に座ってイスラエルの十二部族を裁くためである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ペテロの手紙第一 5:8; ゼカリヤ書 3:1; ヨブ記 1:6–12"> 主は言った。<span className="woj">「シモン、シモン、見よ、サタンはあなたがたを麦のようにふるいにかけようと、自分の手に渡すよう求めた。</span></span>
<span className="v" id="v32" data-v="32" data-xref="ペテロの手紙第一 5:8–10; ヨハネ 21:15–17; ヨハネ 17:9–11"> <span className="woj">しかし私は、あなたの信仰がなくならないように、あなたのために祈った。あなたは立ち直ったら、兄弟たちを力づけなさい。」</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="ここで「兄弟たち」と訳された言葉は、「兄弟姉妹」または「きょうだいたち」と訳すこともできる。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="マルコ 14:31; マタイ 26:33–35; マルコ 14:29"> シモンはイエスに言った。「主よ、私はあなたと一緒なら、牢獄にも死にも行く覚悟ができています。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ヨハネ 13:38; マタイ 26:34; マルコ 14:30"> イエスは言った。<span className="woj">「ペテロ、あなたに言う。今日、あなたが私を知っていることを三度否むまで、鶏は決して鳴かない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="マタイ 10:9–10; ルカ 10:4; 詩篇 23:1"> また彼らに言った。<span className="woj">「私が財布も袋も履物も持たせずにあなたがたを遣わした時、何か不足したものがあったか。」</span><br />彼らは言った。「何もありませんでした。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="マタイ 10:22–25; テサロニケ人への手紙第一 3:4; テサロニケ人への手紙第一 2:14–15"> そこでイエスは彼らに言った。<span className="woj">「しかし今は、財布のある者はそれを持ち、袋も同じように持ちなさい。剣を持っていない者は、上着を売って剣を買いなさい。</span></span>
<span className="v" id="v37" data-v="37" data-xref="イザヤ書 53:12; ルカ 23:32; コリント人への第二の手紙 5:21"> <span className="woj">あなたがたに言う。『彼は律法に背く者たちとともに数えられた』と書かれていることは、なお私において成就しなければならない。</span><span className="woj">私に関することは、今まさに成就しようとしているからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="ルカ 22:49; マタイ 26:52–54; ヨハネ 18:36"> 彼らは言った。「主よ、見よ、ここに剣が二振りあります。」<br />イエスは彼らに言った。<span className="woj">「それで十分だ。」</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="ルカ 21:37; ヨハネ 18:1–2; マタイ 21:1"> イエスは外へ出て、いつものようにオリーブ山へ行った。弟子たちもついて行った。</span>
<span className="v" id="v40" data-v="40" data-xref="マタイ 6:13; マタイ 26:36–46; ルカ 22:46"> その場所に着くと、彼らに言った。<span className="woj">「誘惑に陥らないように祈りなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="マタイ 26:39; マルコ 14:35; ルカ 18:11"> そして弟子たちから石を投げれば届くほどの所まで離れ、ひざまずいて祈り、</span>
<span className="v" id="v42" data-v="42" data-xref="ヨハネ 12:27–28; マタイ 26:39; マタイ 26:42"> 言った。<span className="woj">「父よ、もし御心なら、この杯を私から取り除いてください。しかし、私の望むことではなく、あなたの御心が行われますように。」</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="マタイ 4:11; マタイ 26:53; 詩篇 91:11–12"> すると、天から御使いが現れ、イエスを力づけた。</span>
<span className="v" id="v44" data-v="44" data-xref="哀歌 1:12; ヘブル人への手紙 5:7; 詩篇 22:12–21"> イエスは苦悶の中で、いっそう切に祈った。その汗は、地面に落ちる大きな血の滴のようになった。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="マルコ 14:40–41; マタイ 26:43; マタイ 26:40"> イエスは祈りを終えて立ち上がり、弟子たちの所へ来ると、彼らが悲しみのために眠り込んでいるのを見た。</span>
<span className="v" id="v46" data-v="46" data-xref="ルカ 22:40; ヨナ書 1:6; ルカ 21:34–36"> そして彼らに言った。<span className="woj">「なぜ眠っているのか。起きて、誘惑に陥らないように祈りなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="マルコ 14:41–50; ヨハネ 18:2–11; ルカ 22:3–6"> イエスがまだ話しているうちに、群衆が現れた。十二人の一人でユダと呼ばれる者が先頭に立ち、イエスに口づけしようと近づいた。</span>
<span className="v" id="v48" data-v="48" data-xref="マルコ 14:44–46; サムエル記第二 20:9–10; 箴言 27:6"> しかしイエスは彼に言った。<span className="woj">「ユダ、口づけで人の子を裏切るのか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="ルカ 22:38"> イエスの周りにいた者たちは、事態を見て言った。「主よ、剣で切りつけましょうか。」</span>
<span className="v" id="v50" data-v="50" data-xref="ヨハネ 18:10–11; マルコ 14:47; ローマ人への手紙 12:19"> そのうちの一人が大祭司のしもべに切りつけ、右の耳を切り落とした。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="ローマ人への手紙 12:21; コリント人への第二の手紙 10:1; ペテロの手紙第一 2:21–23"> しかしイエスは答えた。<span className="woj">「これだけはさせなさい。」</span>そして、その耳に触れて癒やした。</span>
<span className="v" id="v52" data-v="52" data-xref="ルカ 22:4; マルコ 14:48–49; ヨハネ 17:12"> それから、自分を捕らえに来た祭司長たち、神殿の警備隊長たち、長老たちに言った。<span className="woj">「強盗に向かうように、剣やこん棒を持って出て来たのか。</span></span>
<span className="v" id="v53" data-v="53" data-xref="ヨハネ 12:27; エペソ人への手紙 6:12; 使徒の働き 26:18"> <span className="woj">私は毎日あなたがたとともに神殿にいたのに、あなたがたは私に手をかけなかった。しかし今は、あなたがたの時、闇の力の時である。」</span></span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="マルコ 14:53–54; マタイ 26:57–58; ヨハネ 18:12–17"> 彼らはイエスを捕らえて連れ去り、大祭司の家に引いて行った。ペテロは遠く離れてついて行った。</span>
<span className="v" id="v55" data-v="55" data-xref="詩篇 26:4–5; コリント人への第二の手紙 6:15–17; マルコ 14:66–72"> 人々が中庭の中央に火をたいて一緒に座ると、ペテロもその中に座った。</span>
<span className="v" id="v56" data-v="56" data-xref="ヨハネ 18:17; マルコ 14:6; マルコ 14:17"> ある女中が、ペテロが火明かりの中に座っているのを見て、じっと見つめて言った。「この人もイエスと一緒にいました。」</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="ヨハネの手紙第一 1:9; ヨハネ 18:25; マタイ 26:70"> しかしペテロはイエスを否定して言った。「女の人、私はあの人を知らない。」</span>
</div>
<div className="bp">
<span className="v" id="v58" data-v="58" data-xref="ヨハネ 18:25; マタイ 26:71–72; マルコ 14:69–70"> しばらくして、別の人がペテロを見て言った。「あなたもあの人たちの仲間だ。」<br />しかしペテロは答えた。「いや、私は違う。」</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="ヨハネ 18:26–27; マルコ 14:69–70; マタイ 26:73–74"> 一時間ほどたつと、ほかの人が強く主張して言った。「確かにこの人も一緒にいた。この人はガリラヤ人だからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v60" data-v="60" data-xref="マタイ 26:74–75; ルカ 22:34; マルコ 14:71–72"> しかしペテロは言った。「あなたが何を言っているのか、私には分からない。」彼がまだ話しているうちに、すぐに鶏が鳴いた。</span>
<span className="v" id="v61" data-v="61" data-xref="ルカ 22:34; イザヤ書 57:15–18; エレミヤ書 31:18–20"> 主は振り向いてペテロを見つめた。ペテロは、主が自分に、<span className="woj">「鶏が鳴く前に、あなたは三度私を否定する」</span>と言われた言葉を思い出した。</span>
<span className="v" id="v62" data-v="62" data-xref="マタイ 26:75; コリント人への第一の手紙 10:12; マルコ 14:72"> そして外へ出て、激しく泣いた。</span>
</div>
<div className="bp">
<span className="v" id="v63" data-v="63" data-xref="ヨハネ 18:22; マルコ 14:55–65; ヨブ記 16:9–10"> イエスを拘束していた男たちは、イエスをあざけり、殴った。</span>
<span className="v" id="v64" data-v="64" data-xref="士師記 16:25; 士師記 16:21"> 目隠しをして顔を打ち、「預言してみろ。おまえを打ったのはだれか」と尋ねた。</span>
<span className="v" id="v65" data-v="65" data-xref="ルカ 12:10; マタイ 12:31–32; マタイ 27:39"> そのほかにも多くの侮辱の言葉を浴びせた。</span>
</div>
<div className="bp">
<span className="v" id="v66" data-v="66" data-xref="マタイ 27:1; マルコ 15:1; 使徒の働き 22:5"> 夜が明けると、民の長老たち、祭司長たち、律法学者たちが集まり、イエスを議会に連れて行って言った。</span>

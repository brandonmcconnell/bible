<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="ルカ 23:24; 創世記 49:10; ルカ 9:7"> 皇帝ティベリウスの治世の第十五年、ポンテオ・ピラトがユダヤの総督、ヘロデがガリラヤの領主、その兄弟フィリポがイトラヤとトラコニティス地方の領主、リサニアがアビレネの領主であり、</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 4:6; ヨハネ 18:24; ルカ 1:80"> アンナスとカヤパが大祭司であった時、荒野でザカリヤの子ヨハネに神の言葉が臨んだ。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカ 1:77; マタイ 3:5–6; 使徒の働き 13:24"> 彼はヨルダン川周辺の全地域に行き、罪の赦しに至る悔い改めのバプテスマを宣べ伝えた。</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 40:3–5; ヨハネ 1:23; ルカ 1:76–79"> 預言者イザヤの言葉の書に、こう書かれている。<br /><span className="pl pl-1">「荒野で叫ぶ者の声。</span><br /><span className="pl pl-2">『主の道を備えよ。</span><br /><span className="pl pl-1">その道筋をまっすぐにせよ。</span></span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 40:4; イザヤ書 42:16; イザヤ書 45:2"> <span className="pl pl-2">すべての谷は埋められ、</span><br /><span className="pl pl-1">すべての山と丘は低くされる。</span><br /><span className="pl pl-2">曲がった道はまっすぐに、</span><br /><span className="pl pl-2">険しい道は平らになる。</span></span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 52:10; イザヤ書 40:5; 詩篇 98:2–3"> <span className="pl pl-1">すべての肉なる者は神の救いを見る。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マタイ 23:33; マタイ 12:34; テサロニケ人への手紙第一 1:10"> そこでヨハネは、自分からバプテスマを受けようと出て来た群衆に言った。「まむしの子孫よ、来ようとしている御怒りから逃れるようにと、だれがあなたがたに教えたのか。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 18:27–31; 使徒の働き 26:20; イザヤ書 1:16–18"> それなら、悔い改めにふさわしい実を結びなさい。心の中で『われわれの父はアブラハムだ』と言い始めてはならない。あなたがたに言うが、神はこれらの石からでも、アブラハムの子どもたちを起こすことがおできになる。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイ 7:19; ヨハネ 15:6; ルカ 13:9"> 斧はすでに木々の根元に置かれている。だから、良い実を結ばない木はすべて切り倒され、火に投げ込まれる。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 2:37; ルカ 3:14; 使徒の働き 16:30"> 群衆は彼に尋ねた。「では、私たちは何をすべきでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 58:7–11; ヨハネの手紙第一 3:17; テモテへの手紙第一 6:18"> 彼は答えた。「上着を二枚持っている者は、一枚も持たない者に分け与えなさい。食べ物を持っている者も同じようにしなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ルカ 7:29; ルカ 15:1–2; ルカ 18:13"> 徴税人たちもバプテスマを受けに来て、彼に言った。「先生、私たちは何をすべきでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカ 19:8; エペソ人への手紙 4:28; コリント人への第一の手紙 6:10"> 彼は言った。「定められた額以上に取り立ててはならない。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 13:5–6; 出エジプト記 20:16; 出エジプト記 23:1"> 兵士たちも尋ねた。「私たちはどうでしょうか。何をすべきでしょうか。」<br />彼は言った。「だれからも力ずくで金を取らず、偽りの告発もしてはならない。自分の給料で満足しなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨハネ 10:24; ヨハネ 3:28–29; ヨハネ 1:19–28"> 民は期待を抱き、皆がヨハネについて、もしかすると彼がキリストではないかと心の中で考えていた。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイ 3:11; 使徒の働き 1:5; 使徒の働き 11:15–16"> ヨハネは皆に答えた。「私は水であなたがたにバプテスマを授けている。しかし、私より力ある方が来られる。私はその方の履物のひもを解く資格もない。その方は聖霊と火によって、あなたがたにバプテスマを授ける。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 15:7; マタイ 13:30; ミカ書 4:12"> その方は手に箕を持ち、脱穀場をすっかり清め、麦を倉に集める。しかし、もみ殻は消えることのない火で焼き尽くす。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨハネ 3:29–36; ヨハネ 1:34; ヨハネ 1:29"> ヨハネはこのほかにも多くの勧めをもって、民に福音を宣べ伝えた。</span>
<span className="v" id="v19" data-v="19" data-xref="ルカ 3:1; マタイ 11:2; マルコ 6:17–18"> ところが領主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="領主とは、一つの州を四分して治める四人の統治者の一人である。">a</a></sup>ヘロデは、兄弟の妻<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TRは「兄弟」の代わりに「兄弟フィリポ」としている。">b</a></sup>ヘロディアのことや、自分が行ったすべての悪事についてヨハネから責められ、</span>
<span className="v" id="v20" data-v="20" data-xref="歴代誌 第二 24:17–22; ヨハネ 3:24; テサロニケ人への手紙第一 2:15–16"> それらすべてに加えて、ヨハネを牢に閉じ込めた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ヨハネ 1:32–34; マタイ 3:13–17; ヨハネ 12:27–28"> さて、民が皆バプテスマを受けた時、イエスもバプテスマを受けて祈っておられた。すると天が開き、</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 2:7; ペテロの第二の手紙 1:17–18; ヨハネ 1:32"> 聖霊が鳩のような目に見える姿でイエスの上に降られた。そして天から声がした。「あなたは私の愛する子。私はあなたを喜びとする。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ルカ 4:22; マタイ 13:55; 民数記 4:3"> イエスは教え始めた時、およそ三十歳で、人々にはヨセフの子と思われていた。ヨセフはヘリの子、</span>
<span className="v" id="v24" data-v="24"> ヘリはマタテの子、マタテはレビの子、レビはメルキの子、メルキはヤナイの子、ヤナイはヨセフの子、</span>
<span className="v" id="v25" data-v="25"> ヨセフはマタティアの子、マタティアはアモスの子、アモスはナホムの子、ナホムはエスリの子、エスリはナガイの子、</span>
<span className="v" id="v26" data-v="26"> ナガイはマハテの子、マハテはマタティアの子、マタティアはセメインの子、セメインはヨセフの子、ヨセフはユダの子、</span>
<span className="v" id="v27" data-v="27" data-xref="マタイ 1:12"> ユダはヨアナンの子、ヨアナンはレサの子、レサはゼルバベルの子、ゼルバベルはシェアルティエルの子、シェアルティエルはネリの子、</span>
<span className="v" id="v28" data-v="28"> ネリはメルキの子、メルキはアディの子、アディはコサムの子、コサムはエルモダムの子、エルモダムはエルの子、</span>
<span className="v" id="v29" data-v="29"> エルはヨセの子、ヨセはエリエゼルの子、エリエゼルはヨリムの子、ヨリムはマタテの子、マタテはレビの子、</span>
<span className="v" id="v30" data-v="30"> レビはシメオンの子、シメオンはユダの子、ユダはヨセフの子、ヨセフはヨナンの子、ヨナンはエリアキムの子、</span>
<span className="v" id="v31" data-v="31" data-xref="歴代誌上 3:5; サムエル記第二 5:14; ゼカリヤ書 12:12"> エリアキムはメレアの子、メレアはメナンの子、メナンはマタタの子、マタタはナタンの子、ナタンはダビデの子、</span>
<span className="v" id="v32" data-v="32" data-xref="ルツ記 4:18–22; マタイ 1:3–6; イザヤ書 11:1–2"> ダビデはエッサイの子、エッサイはオベデの子、オベデはボアズの子、ボアズはサルモンの子、サルモンはナフションの子、</span>
<span className="v" id="v33" data-v="33" data-xref="ルツ記 4:19–20; 創世記 49:8; 創世記 38:29"> ナフションはアミナダブの子、アミナダブはアラムの子、<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="NUは「アラム」の代わりに「アドミンの子、アドミンはアルニの子」としている。">c</a></sup>アラムはヘツロンの子、ヘツロンはペレツの子、ペレツはユダの子、</span>
<span className="v" id="v34" data-v="34" data-xref="創世記 21:3; ヨシュア記 24:2; 歴代誌上 1:24–28"> ユダはヤコブの子、ヤコブはイサクの子、イサクはアブラハムの子、アブラハムはテラの子、テラはナホルの子、</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 11:12–21; 創世記 10:24–25"> ナホルはセルグの子、セルグはレウの子、レウはペレグの子、ペレグはエベルの子、エベルはシェラの子、</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 5:28–32; 創世記 10:21–22; 創世記 9:1"> シェラはカイナンの子、カイナンはアルパクシャデの子、アルパクシャデはセムの子、セムはノアの子、ノアはレメクの子、</span>
<span className="v" id="v37" data-v="37" data-xref="歴代誌上 1:1–3; 創世記 5:6–28"> レメクはメトシェラの子、メトシェラはエノクの子、エノクはヤレドの子、ヤレドはマハラルエルの子、マハラルエルはカイナンの子、</span>
<span className="v" id="v38" data-v="38" data-xref="創世記 2:7; イザヤ書 64:8; コリント人への第一の手紙 15:45"> カイナンはエノシュの子、エノシュはセツの子、セツはアダムの子、アダムは神の子であった。</span>
</div>

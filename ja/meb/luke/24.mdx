<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネ 20:1–2; マルコ 16:1–8; マタイ 28:1–8"> 週の初めの日、夜明け早く、女たちは用意しておいた香料を持ち、ほかの何人かとともに墓へ行った。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコ 16:3–4; マタイ 27:60–66; マルコ 15:46–47"> すると、墓から石が転がしてあるのを見つけた。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカ 24:23; ヨハネ 20:6–7; マタイ 16:5"> 中に入ったが、主イエスの体が見当たらなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="マルコ 16:5; ヨハネ 20:11–12; 使徒の働き 1:10"> このことで途方に暮れていると、見よ、まばゆい衣を着た二人の人がそばに立った。</span>
<span className="v" id="v5" data-v="5" data-xref="マルコ 16:5–6; マタイ 28:3–5; ヨハネの黙示録 1:18"> 女たちは恐ろしくなり、顔を地に伏せた。<br />二人は女たちに言った。「なぜ、生きている方を死人の中に捜すのですか。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイ 17:22–23; ルカ 9:22; マルコ 8:31"> ここにはおられません。よみがえられました。まだガリラヤにおられた時、あなたがたに何と言われたかを思い出しなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイ 16:21"> 人の子は罪人たちの手に引き渡され、十字架につけられ、三日目によみがえらなければならない、と言われたでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨハネ 12:16; ヨハネ 14:26; ヨハネ 2:19–22"> 女たちはイエスの言葉を思い出し、</span>
<span className="v" id="v9" data-v="9" data-xref="ルカ 24:22–24; マルコ 16:7–8; マタイ 28:7–8"> 墓から帰って、十一人とほかのすべての人にこれらのことを告げた。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイ 27:56; ヨハネ 20:11–18; ルカ 8:2–3"> その女たちは、マグダラのマリア、ヨハンナ、ヤコブの母マリアであった。彼女たちと一緒にいたほかの女たちも、これらのことを使徒たちに告げた。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨブ記 9:16; マルコ 16:11; 創世記 19:14"> しかし、この話は使徒たちにはたわごとのように思われ、彼女たちを信じなかった。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネ 20:3–10"> しかしペテロは立ち上がって墓へ走った。身をかがめて中をのぞくと、亜麻布だけが置いてあるのが見えた。それで、起こったことを不思議に思いながら家へ帰った。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ルカ 24:18; マルコ 16:12–13"> 見よ、ちょうどその日、弟子たちのうち二人が、エルサレムから六十スタディア<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="六十スタディアは約十一キロメートル、または約七マイルである。">a</a></sup>離れたエマオという村へ向かっていた。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカ 6:45; 申命記 6:7; マラキ書 3:6"> 二人は、起こったこれらすべての出来事について互いに話していた。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイ 18:20; ヨハネ 14:18–19; ルカ 24:36"> 彼らが話し合い、論じ合っていると、イエスご自身が近づいて来て、一緒に歩き始めた。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネ 20:14; ヨハネ 21:4; ルカ 24:31"> しかし、二人の目は遮られていて、イエスだと気づかなかった。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネ 16:20–22; ヨハネ 16:6; エゼキエル書 9:4–6"> イエスは彼らに言った。<span className="woj">「歩きながら話し合っている、その話は何ですか。なぜ悲しんでいるのですか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨハネ 19:25"> クレオパという名の一人が答えた。「エルサレムに滞在していながら、この数日の間にそこで起こったことを知らないのは、あなただけなのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="マタイ 21:11; 使徒の働き 7:22; ヨハネ 4:19"> イエスは彼らに言った。<span className="woj">「どんなことですか。」</span><br />二人は答えた。「ナザレ人イエスのことです。この方は、神と民全体の前で、行いにも言葉にも力ある預言者でした。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 3:13–15; 使徒の働き 4:8–10; ルカ 23:13"> ところが祭司長たちやわれわれの指導者たちは、この方を死刑に定めるために引き渡し、十字架につけたのです。</span>
<span className="v" id="v21" data-v="21" data-xref="ルカ 1:68; ペテロの手紙第一 1:18–19; ルカ 2:38"> 私たちは、この方こそイスラエルを贖ってくださる方だと望みをかけていました。しかも、そのすべてが起こってから、今日でもう三日目になります。</span>
<span className="v" id="v22" data-v="22" data-xref="マルコ 16:9–10; マタイ 28:7–8; ヨハネ 20:1–2"> そのうえ、仲間の女たちが何人か、私たちを驚かせました。朝早く墓へ行ったのですが、</span>
<span className="v" id="v23" data-v="23"> イエスの体が見つからず、戻って来て、御使いたちの幻まで見たと言うのです。御使いたちは、イエスは生きておられると告げたそうです。</span>
<span className="v" id="v24" data-v="24" data-xref="ルカ 24:12; ヨハネ 20:1–10"> 仲間の何人かが墓へ行ってみると、女たちの言ったとおりでしたが、イエスは見ませんでした。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="マルコ 7:18; マルコ 9:19; ヘブル人への手紙 5:11–12"> イエスは彼らに言った。<span className="woj">「ああ、愚かな人たち。預言者たちが語ったすべてのことを信じるのに、心の鈍い人たち。</span></span>
<span className="v" id="v26" data-v="26" data-xref="ペテロの手紙第一 1:11; イザヤ書 53:1–12; ゼカリヤ書 13:7"> <span className="woj">キリストはこれらの苦しみを受けて、その栄光に入らなければならなかったのではないか。」</span></span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 7:14; ルカ 24:44; 申命記 18:15"> そしてモーセとすべての預言者から始めて、聖書全体の中から、ご自分について書かれていることを彼らに解き明かした。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="マルコ 6:48; 創世記 19:2; 創世記 32:26"> 三人は、目指していた村に近づいた。イエスはさらに先へ行く様子を見せた。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王記第二 4:8; ルカ 14:23; 創世記 19:3"> 二人は強く引き止めて言った。「私たちと一緒にお泊まりください。もう夕方になり、日も暮れかけています。」<br />それでイエスは、彼らとともに泊まるために中へ入った。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイ 14:19; ルカ 24:35; マタイ 15:36"> イエスが彼らと食卓に着いた時、パンを取って感謝をささげ、それを裂いて彼らに渡した。</span>
<span className="v" id="v31" data-v="31" data-xref="ルカ 24:16; ヨハネ 8:59; ルカ 4:30"> すると二人の目が開かれ、イエスだと分かった。その時、イエスの姿は見えなくなった。</span>
<span className="v" id="v32" data-v="32" data-xref="ルカ 24:45; エレミヤ書 23:29; ヘブル人への手紙 4:12"> 二人は互いに言った。「道を歩きながら、あの方が話してくださり、聖書を解き明かしてくださった時、私たちの心は内で燃えていたではないか。」</span>
<span className="v" id="v33" data-v="33" data-xref="マルコ 16:13; ヨハネ 20:19–26; 使徒の働き 1:14"> 二人はすぐに立ってエルサレムへ戻り、十一人と、その仲間たちが集まっているのを見つけた。</span>
<span className="v" id="v34" data-v="34" data-xref="コリント人への第一の手紙 15:5; マルコ 16:7; ルカ 22:54–62"> 集まっていた人々は、「主は本当によみがえり、シモンに現れた」と言っていた。</span>
<span className="v" id="v35" data-v="35" data-xref="マルコ 16:12–13; 使徒の働き 2:42; ルカ 24:30–31"> そこで二人も、道で起こったことや、パンを裂いた時にイエスだと分かったことを話した。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="テサロニケ人への第二の手紙 3:16; イザヤ書 57:18; マルコ 16:14"> 彼らがこれらのことを話していると、イエスご自身が彼らのただ中に立って言った。<span className="woj">「あなたがたに平和があるように。」</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="サムエル記第一 28:13; マタイ 14:26–27; ヨブ記 4:14–16"> 彼らはおびえ、恐れに満たされ、霊を見ているのだと思った。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="エレミヤ書 4:14; ヘブル人への手紙 4:13; ダニエル書 4:19"> イエスは彼らに言った。<span className="woj">「なぜ取り乱しているのか。なぜ心に疑いが起こるのか。</span></span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネ 20:27; ヨハネの手紙第一 1:1; 伝道者の書 12:7"> <span className="woj">私の手と足を見なさい。確かに私自身である。触って見なさい。霊には肉や骨はないが、見てのとおり、私にはある。」</span></span>
<span className="v" id="v40" data-v="40"> こう言って、手と足を彼らに見せた。</span>
<span className="v" id="v41" data-v="41" data-xref="ヨハネ 21:5; 詩篇 126:1–2; 創世記 45:26–28"> 彼らが喜びのあまりまだ信じられず、不思議に思っていると、イエスは言った。<span className="woj">「ここに何か食べ物がありますか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> 彼らは焼いた魚一切れと、蜂の巣を少し差し出した。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒の働き 10:41"> イエスはそれを受け取り、彼らの前で食べた。</span>
<span className="v" id="v44" data-v="44" data-xref="ゼカリヤ書 12:10; ルカ 24:26–27; ゼカリヤ書 9:9"> そして彼らに言った。<span className="woj">「私がまだあなたがたと一緒にいた時に話していたのは、このことである。モーセの律法、預言者たち、詩篇に私について書かれていることは、すべて成就しなければならない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="使徒の働き 16:14; ヨハネの手紙第一 5:20; 詩篇 119:18"> それからイエスは、聖書を理解できるように、彼らの心を開いた。</span>
<span className="v" id="v46" data-v="46" data-xref="イザヤ書 53:2–12; イザヤ書 50:6; ルカ 24:44"> そして彼らに言った。<span className="woj">「このように書かれている。キリストは苦しみを受け、三日目に死人の中からよみがえらなければならなかった。</span></span>
<span className="v" id="v47" data-v="47" data-xref="使徒の働き 5:31; イザヤ書 49:6; 使徒の働き 2:38"> <span className="woj">また、悔い改めと罪の赦しが、その名によって、エルサレムから始まり、すべての国々に宣べ伝えられる。</span></span>
<span className="v" id="v48" data-v="48" data-xref="使徒の働き 1:8; 使徒の働き 2:32; 使徒の働き 13:31"> <span className="woj">あなたがたは、これらのことの証人である。</span></span>
<span className="v" id="v49" data-v="49" data-xref="使徒の働き 1:8; 使徒の働き 1:4; ヨエル書 2:28–32"> <span className="woj">見よ、私は父が約束されたものをあなたがたの上に送る。しかし、いと高き所からの力を身にまとうまでは、エルサレムの都にとどまっていなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="使徒の働き 1:12; マタイ 21:17; マルコ 11:1"> それからイエスは彼らをベタニアの近くまで連れて行き、両手を上げて祝福した。</span>
<span className="v" id="v51" data-v="51" data-xref="使徒の働き 1:9; マルコ 16:19; 列王記第二 2:11"> 祝福している間に彼らから離れ、天に上げられた。</span>
<span className="v" id="v52" data-v="52" data-xref="マタイ 28:9; ヨハネ 16:22; 詩篇 30:11"> 彼らはイエスを礼拝し、大きな喜びに満たされてエルサレムへ帰った。</span>
<span className="v" id="v53" data-v="53" data-xref="マルコ 16:20; 使徒の働き 2:46–47; 使徒の働き 5:41–42"> そして絶えず神殿にいて、神を賛美し、ほめたたえていた。アーメン。</span>
</div>
</div>

<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="LUK" data-book-slug="luke" data-book-name="ルカ" data-chapter="23" data-verses="56">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 27:1–2; マタイ 27:11–14; ルカ 22:66"> 彼らは全員立ち上がり、イエスをピラトの前に連れて行った。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 17:6–7; ヨハネ 19:12; ルカ 23:14"> そしてイエスを訴え始めて言った。「この男は国民を惑わし、カエサルに税を納めることを禁じ、自分こそ王なるキリストだと言っていることが分かりました。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ヨハネ 1:49; テモテへの手紙第一 6:13; ルカ 22:70"> ピラトはイエスに尋ねた。「おまえはユダヤ人の王なのか。」<br />イエスは答えた。<span className="woj">「あなたがそう言っている。」</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ヨハネ 18:38; ルカ 23:14–15; ルカ 23:22"> ピラトは祭司長たちと群衆に言った。「私はこの男に何の罪状も見いださない。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="マルコ 1:14; ヨハネ 1:43; ヨハネ 2:11"> しかし彼らは言い張った。「この男はガリラヤから始めて、この場所に至るまで、ユダヤ全土で教え、民を扇動しています。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 5:37; ルカ 13:1"> ピラトはガリラヤと聞くと、この人はガリラヤ人なのかと尋ねた。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカ 3:1; ルカ 13:31; マタイ 14:1"> そして、イエスがヘロデの管轄に属すると知ると、ヘロデのもとへ送った。ヘロデもそのころエルサレムにいたのである。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ルカ 9:7–9; マタイ 14:1; マルコ 6:14"> ヘロデはイエスを見ると非常に喜んだ。イエスについて多くのことを聞いていたので、長い間会いたいと思っており、イエスが何か奇跡を行うのを見たいと願っていたからである。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイ 27:14; マタイ 7:6; ペテロの手紙第一 2:23"> ヘロデは多くの言葉でイエスに質問したが、イエスは何も答えなかった。</span>
<span className="v" id="v10" data-v="10" data-xref="ルカ 11:53; ルカ 23:14–15; ルカ 23:5"> 祭司長たちと律法学者たちは立って、激しくイエスを訴え続けた。</span>
<span className="v" id="v11" data-v="11" data-xref="マルコ 15:16–20; マタイ 27:27–30; 詩篇 69:19–20"> ヘロデは兵士たちとともにイエスを侮辱し、あざけった。そして華やかな衣を着せて、ピラトのもとへ送り返した。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 4:27; ヨハネの黙示録 17:13–14; 詩篇 83:4–6"> その日、ヘロデとピラトは互いに友となった。それ以前は互いに敵対していたのである。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マルコ 15:14; マタイ 27:21–23; ヨハネ 18:38"> ピラトは祭司長たち、指導者たち、民を呼び集め、</span>
<span className="v" id="v14" data-v="14" data-xref="ダニエル書 6:4; ヘブル人への手紙 7:26; ルカ 23:1–2"> 彼らに言った。「あなたがたは、この男が民を惑わす者だとして、私の所に連れて来た。見よ、私はあなたがたの前で取り調べたが、あなたがたが訴えていることについて、この男に何の罪状も見いださなかった。</span>
<span className="v" id="v15" data-v="15"> ヘロデも同じだ。私はあなたがたを彼のもとへ送ったが、見よ、この男は死に値するようなことを何もしていない。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイ 27:26; ルカ 23:22; マルコ 15:15"> だから、むちで懲らしめてから釈放する。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 祭りのたびに、ピラトは囚人を一人、彼らのために釈放しなければならなかった。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NUは十七節を省いている。">a</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 21:36; 使徒の働き 3:14; 使徒の働き 22:22"> しかし彼らは一斉に叫んだ。「この男を除け。バラバを釈放しろ。」</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 3:14; ルカ 23:5; ルカ 23:2"> バラバは、都で起こった暴動と殺人のために投獄されていた者である。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="マルコ 15:15; マタイ 14:8–9; マタイ 27:19"> ピラトはイエスを釈放したいと思い、再び彼らに呼びかけた。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイ 27:22–25; マルコ 15:13; ヨハネ 19:15"> しかし彼らは叫び続けた。「十字架につけろ。十字架につけろ。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ルカ 23:14; ルカ 23:20; ペテロの手紙第一 3:18"> ピラトは三度目に彼らに言った。「なぜだ。この男がどんな悪事をしたというのか。私はこの男に死刑に当たる罪を何も見いださなかった。だから、むちで懲らしめてから釈放する。」</span>
<span className="v" id="v23" data-v="23" data-xref="ゼカリヤ書 11:8; 詩篇 57:4; 詩篇 22:12–13"> しかし彼らは大声で迫り、イエスを十字架につけるよう要求し続けた。彼らと祭司長たちの声が勝った。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイ 27:26; 出エジプト記 23:2; 箴言 17:15"> ピラトは、彼らの要求どおりにすることを決定した。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 3:14; マルコ 15:6–7; マルコ 15:15"> そして彼らが求めた、暴動と殺人のために投獄されていた者を釈放し、イエスを彼らの思いに委ねた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="マタイ 27:32–44; マルコ 15:21–32; 使徒の働き 6:9"> 兵士たちはイエスを引いて行く途中、田舎から来たキレネ人シモンを捕らえ、十字架を背負わせてイエスの後から運ばせた。</span>
<span className="v" id="v27" data-v="27" data-xref="ルカ 8:52; ルカ 8:2; マルコ 15:40"> 民の大群衆がイエスについて行った。その中には、イエスのために胸を打ち、嘆き悲しむ女たちもいた。</span>
<span className="v" id="v28" data-v="28" data-xref="雅歌 8:4; 雅歌 5:8; 雅歌 1:5"> イエスは女たちのほうを向いて言った。<span className="woj">「エルサレムの娘たち、私のために泣いてはならない。むしろ、自分自身と自分の子どもたちのために泣きなさい。</span></span>
<span className="v" id="v29" data-v="29" data-xref="マタイ 24:19; ルカ 21:23–24; マルコ 13:17–19"> <span className="woj">見よ、『不妊の女、子を産んだことのない胎、乳を飲ませたことのない乳房は幸いだ』と言う日が来る。</span></span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの黙示録 6:16; ホセア書 10:8; イザヤ書 2:19"> <span className="woj">その時、人々は山々に『われわれの上に倒れかかれ』と言い、丘々に『われわれを覆ってくれ』と言い始める。</span></span>
<span className="v" id="v31" data-v="31" data-xref="ペテロの手紙第一 4:17–18; ヨハネ 15:6; 箴言 11:31"> <span className="woj">生木にこのようなことをするなら、枯れ木には何が起こるだろうか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="マルコ 15:27; イザヤ書 53:12; マタイ 27:38"> ほかにも二人の犯罪人が、処刑されるためにイエスとともに引かれて行った。</span>
<span className="v" id="v33" data-v="33" data-xref="マルコ 15:22–23; ヨハネ 19:17–18; ヨハネ 18:32"> 「どくろ」と呼ばれる場所に着くと、そこでイエスを十字架につけ、犯罪人たちも一人を右に、もう一人を左にして十字架につけた。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="マタイ 5:44; 使徒の働き 7:60; ペテロの手紙第一 3:9"> イエスは言った。<span className="woj">「父よ、彼らをお赦しください。自分たちが何をしているのか、分かっていないのです。」</span><br />人々はくじを引いて、イエスの衣を分け合った。</span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 22:17; イザヤ書 42:1; ペテロの手紙第一 2:4"> 民は立って見ていた。指導者たちも一緒になってイエスをあざ笑い、言った。「あの男はほかの人を救った。もし神のキリスト、選ばれた者なら、自分を救ってみろ。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="詩篇 69:21; マタイ 27:48; マタイ 27:34"> 兵士たちもイエスをあざけり、近寄って酸いぶどう酒を差し出し、</span>
<span className="v" id="v37" data-v="37"> 言った。「おまえがユダヤ人の王なら、自分を救ってみろ。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="マルコ 15:26; マタイ 27:37; ヨハネ 19:19–22"> イエスの上には、ギリシャ語、ラテン語、ヘブル語で、「これはユダヤ人の王」と書かれた札も掲げられていた。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="マタイ 27:44; マルコ 15:32; ルカ 23:35"> 十字架にかけられた犯罪人の一人が、イエスを侮辱して言った。「おまえがキリストなら、自分とわれわれを救え。」</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="エペソ人への手紙 5:11; ルカ 12:5; ヨハネの黙示録 15:4"> しかし、もう一人は彼を戒めて言った。「おまえは同じ刑罰を受けているのに、神を恐れないのか。</span>
<span className="v" id="v41" data-v="41" data-xref="レビ記 26:40–41; エズラ記 9:13; ペテロの手紙第一 1:19"> われわれが罰を受けるのは当然だ。自分のしたことに見合う報いを受けているのだから。しかし、この方は何も悪いことをしていない。」</span>
<span className="v" id="v42" data-v="42" data-xref="ローマ人への手紙 10:9–14; 使徒の働き 16:31; ヨハネの手紙第一 5:11–13"> そしてイエスに言った。「主よ、あなたの王国に入られる時、私を思い出してください。」</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="ヨハネの黙示録 2:7; 詩篇 50:15; テモテへの手紙第一 1:15–16"> イエスは彼に言った。<span className="woj">「まことに、あなたに言う。あなたは今日、私とともにパラダイスにいる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="マタイ 27:45; マルコ 15:33–34; アモス書 8:9"> すでに第六時<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="時刻は日の出から数えたので、第六時は正午ごろである。">b</a></sup>ごろであった。全地が暗くなり、第九時<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="午後三時。">c</a></sup>まで続いた。</span>
<span className="v" id="v45" data-v="45" data-xref="ヘブル人への手紙 10:19–22; マタイ 27:51; ヘブル人への手紙 9:3–8"> 太陽は暗くなり、神殿の垂れ幕が真ん中から裂けた。</span>
<span className="v" id="v46" data-v="46" data-xref="詩篇 31:5; 使徒の働き 7:59; ヨハネ 19:30"> イエスは大声で叫んで言った。<span className="woj">「父よ、私の霊をあなたの御手に委ねます。」</span>こう言って、息を引き取った。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="マタイ 27:54; マルコ 15:39; ルカ 23:41"> 百人隊長は起こったことを見ると、神に栄光を帰して言った。「確かに、この人は義人だった。」</span>
<span className="v" id="v48" data-v="48" data-xref="ルカ 18:13; 使徒の働き 2:37; エレミヤ書 31:19"> この光景を見るために集まっていた群衆は皆、起こったことを見ると、胸をたたきながら帰って行った。</span>
<span className="v" id="v49" data-v="49" data-xref="ルカ 8:2; 詩篇 38:11; ルカ 23:55"> イエスを知る人々と、ガリラヤからイエスについて来た女たちは皆、遠く離れて立ち、これらのことを見ていた。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="ヨハネ 19:38–42; 使徒の働き 11:24; 使徒の働き 10:22"> 見よ、ヨセフという人がいた。議員で、善良で正しい人であった。</span>
<span className="v" id="v51" data-v="51" data-xref="ルカ 2:25; ルカ 2:38; イザヤ書 8:12"> この人は議会の決議と行動に同意しなかった。ユダヤ人の町アリマタヤの出身で、彼も神の王国を待ち望んでいた。</span>
<span className="v" id="v52" data-v="52" data-xref="ヨハネ 19:38–42"> 彼はピラトの所へ行き、イエスの体を引き取らせてほしいと願い出た。</span>
<span className="v" id="v53" data-v="53" data-xref="マタイ 27:59–60; イザヤ書 53:9; マルコ 15:46"> そして体を取り降ろして亜麻布で包み、岩を掘って造った、まだだれも葬られたことのない墓に納めた。</span>
<span className="v" id="v54" data-v="54" data-xref="マタイ 27:62; ヨハネ 19:31; マルコ 15:42"> その日は準備の日で、安息日が近づいていた。</span>
<span className="v" id="v55" data-v="55" data-xref="ルカ 23:49; マタイ 27:61; マルコ 15:47"> ガリラヤからイエスとともに来ていた女たちは後について行き、墓と、イエスの体がどのように納められたかを見届けた。</span>
<span className="v" id="v56" data-v="56" data-xref="ルカ 24:1; マルコ 16:1; 申命記 5:14"> それから帰って、香料と香油を用意した。安息日には、戒めに従って休んだ。</span>
</div>

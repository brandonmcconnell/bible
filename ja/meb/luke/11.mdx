<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 19:14; ルカ 22:39–45; ローマ人への手紙 8:26–27"> イエスがある場所で祈り終えると、弟子の一人が言った。「主よ、ヨハネが弟子たちに教えたように、私たちにも祈りを教えてください。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="マタイ 6:6–15; 伝道者の書 5:2; 詩篇 72:18–19"> イエスは彼らに言った。<span className="woj">「祈る時は、こう言いなさい。</span><br /><span className="pl pl-1 woj">『天におられるわれわれの父よ、</span><br /><span className="pl pl-2 woj">あなたの御名が聖なるものとされますように。</span><br /><span className="pl pl-1 woj">あなたの王国が来ますように。</span><br /><span className="pl pl-2 woj">あなたのみこころが、天で行われるように地でも行われますように。</span></span>
<span className="v" id="v3" data-v="3" data-xref="マタイ 6:11; マタイ 6:34; 箴言 30:8"> <span className="pl pl-1 woj">日ごとのパンを、日々われわれにお与えください。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="マタイ 6:12–15; マタイ 26:41; イザヤ書 43:25–26"> <span className="pl pl-1 woj">われわれの罪をお赦しください。</span><br /><span className="pl pl-2 woj">われわれも、自分に負い目のある者を皆、赦します。</span><br /><span className="pl pl-1 woj">われわれを誘惑に遭わせず、</span><br /><span className="pl pl-2 woj">悪い者からお救いください。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ルカ 18:1–8"> また彼らに言った。<span className="woj">「あなたがたのうち、真夜中に友人の所へ行って、『友よ、パンを三つ貸してください。</span></span>
<span className="v" id="v6" data-v="6"> <span className="woj">旅をしていた友人が私の所に来たのですが、出す物が何もないのです』と言う人がいたとする。</span></span>
<span className="v" id="v7" data-v="7" data-xref="ルカ 13:25; ガラテヤ人への手紙 6:17; ルカ 7:6"> <span className="woj">すると中から、『面倒をかけないでくれ。もう戸は閉めたし、子どもたちも私と一緒に寝床にいる。起きて何かを渡すことはできない』と答えるだろうか。</span></span>
<span className="v" id="v8" data-v="8" data-xref="創世記 32:26; コロサイ人への手紙 4:12; ローマ人への手紙 15:30"> <span className="woj">あなたがたに告げる。その人は友人だからという理由では起きて与えなくても、相手がしつこく頼むため、起きて必要なだけ与えるだろう。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="マルコ 11:24; ヨハネ 16:23–24; マタイ 21:22"> <span className="woj">「だから、あなたがたに言う。求め続けなさい。そうすれば与えられる。捜し続けなさい。そうすれば見つかる。たたき続けなさい。そうすれば開かれる。</span></span>
<span className="v" id="v10" data-v="10" data-xref="ヤコブの手紙 4:3; 哀歌 3:54–58; 詩篇 31:22"> <span className="woj">求める者は皆受け、捜す者は見つけ、たたく者には開かれるからである。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="マタイ 7:9; イザヤ書 49:15"> <span className="woj">「あなたがたのうち父親で、息子がパンを求めるのに石を与える者がいるだろうか。魚を求めるのに、魚の代わりに蛇を与えるだろうか。</span></span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 9:10; ルカ 10:19; エゼキエル書 2:6"> <span className="woj">卵を求めるのに、さそりを与えるだろうか。</span></span>
<span className="v" id="v13" data-v="13" data-xref="マタイ 7:11; イザヤ書 44:3–4; ローマ人への手紙 8:32"> <span className="woj">このように、悪い者であるあなたがたでさえ、自分の子どもに良い贈り物を与えることを知っている。まして天の父は、求める者に聖霊を与えてくださる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マタイ 12:22–24; マタイ 9:32–34; マルコ 7:32–37"> イエスは口を利けなくする悪霊を追い出していた。悪霊が出て行くと、口の利けなかった人が話し始め、群衆は驚いた。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイ 9:34; マタイ 12:24–30; ヨハネ 8:48"> しかし彼らのある者たちは言った。「彼は悪霊どもの頭ベルゼブルによって、悪霊を追い出しているのだ。」</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネ 6:30; コリント人への第一の手紙 1:22; マルコ 8:11–12"> またほかの者たちはイエスを試そうとして、天からのしるしを求めた。</span>
<span className="v" id="v17" data-v="17" data-xref="マルコ 3:23–27; マタイ 12:25–29; イザヤ書 19:2–3"> しかしイエスは彼らの考えを知って言った。<span className="woj">「内輪で分裂する王国はすべて荒れ果て、内輪で分裂する家は倒れる。</span></span>
<span className="v" id="v18" data-v="18" data-xref="マタイ 12:26; マタイ 12:31–34; ルカ 11:15"> <span className="woj">サタンも内輪で分裂しているなら、どうしてその王国が立ち続けられるだろう。あなたがたは、私がベルゼブルによって悪霊を追い出していると言っている。</span></span>
<span className="v" id="v19" data-v="19" data-xref="ルカ 9:49; ヨブ記 15:6; ローマ人への手紙 3:19"> <span className="woj">私がベルゼブルによって悪霊を追い出すなら、あなたがたの子らはだれによって追い出すのか。だから彼らがあなたがたを裁く者となる。</span></span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 8:19; マタイ 12:28; ルカ 10:9"> <span className="woj">しかし、私が神の指によって悪霊を追い出しているのなら、神の王国はあなたがたのもとに来ている。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="マルコ 3:27; マタイ 12:29"> <span className="woj">「強い者が武装して自分の家を守っている時、その財産は安全である。</span></span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 49:24–25; イザヤ書 53:12; ヨハネの手紙第一 3:8"> <span className="woj">しかし、彼より強い者が襲って打ち負かすと、頼みにしていた武具をすべて奪い、戦利品を分ける。</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="マタイ 12:30; ルカ 9:50; マルコ 9:40"> <span className="woj">「私とともにいない者は私に反対し、私とともに集めない者は散らす。</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="マタイ 12:43–45; ペテロの手紙第一 5:8; ヨブ記 2:2"> <span className="woj">汚れた霊は人から出ると、休み場を求めて乾いた所を通り巡る。しかし見つからないので、『出て来た自分の家に戻ろう』と言う。</span></span>
<span className="v" id="v25" data-v="25" data-xref="テサロニケ人への第二の手紙 2:9–12; ペテロの第二の手紙 2:10–19; ユダ 1:8–13"> <span className="woj">戻ってみると、家は掃除され、整えられている。</span></span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネ 5:14; マタイ 12:45; ペテロの第二の手紙 2:20–22"> <span className="woj">そこで出て行き、自分より悪いほかの七つの霊を連れて来る。そして中に入って住みつく。その人の後の状態は、初めより悪くなる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ルカ 1:42; ルカ 1:48; ルカ 23:29"> イエスがこれらのことを話していると、群衆の中から一人の女が声を上げて言った。「あなたを宿した胎と、あなたが乳を飲んだ乳房は幸いです。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ルカ 6:47–48; ルカ 8:21; 詩篇 112:1"> しかしイエスは言った。<span className="woj">「むしろ、神の言葉を聞いて守る人たちこそ幸いである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ルカ 11:16; マルコ 8:11–12; コリント人への第一の手紙 1:22"> 群衆がさらに集まって来ると、イエスは語り始めた。<span className="woj">「この世代は悪い世代である。しるしを求めるが、預言者ヨナのしるしのほかには、何のしるしも与えられない。</span></span>
<span className="v" id="v30" data-v="30" data-xref="マタイ 12:40–42; ヨナ書 1:17; ヨナ書 3:2–10"> <span className="woj">ヨナがニネベの人々へのしるしとなったように、人の子もこの世代へのしるしとなる。</span></span>
<span className="v" id="v31" data-v="31" data-xref="歴代誌 第二 9:1; 列王記第一 10:1–13; ローマ人への手紙 2:27"> <span className="woj">南の女王が裁きの時、この世代の人々とともに立ち上がり、彼らを罪に定める。彼女はソロモンの知恵を聞くために地の果てから来たからである。見よ、ここにソロモンより偉大なものがある。</span></span>
<span className="v" id="v32" data-v="32" data-xref="ヘブル人への手紙 7:26; ルカ 11:31; ヨナ書 3:5–4"> <span className="woj">ニネベの人々が裁きの時、この世代とともに立ち上がり、この世代を罪に定める。彼らはヨナの宣教によって悔い改めたからである。見よ、ここにヨナより偉大なものがある。</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="ルカ 8:16–17; マルコ 4:21–22; マタイ 5:15–16"> <span className="woj">「明かりをともしてから、地下室やかごの下に置く人はいない。入って来る人に光が見えるよう、燭台の上に置く。</span></span>
<span className="v" id="v34" data-v="34" data-xref="マタイ 6:22–23; 使徒の働き 26:18; エレミヤ書 5:21"> <span className="woj">体の明かりは目である。目が健全なら、全身も光に満ちる。しかし目が悪ければ、体も闇に満ちる。</span></span>
<span className="v" id="v35" data-v="35" data-xref="箴言 16:25; ペテロの第二の手紙 1:9; ヤコブの手紙 3:13–17"> <span className="woj">だから、自分のうちにある光が闇でないか注意しなさい。</span></span>
<span className="v" id="v36" data-v="36" data-xref="箴言 20:27; 箴言 6:23; 箴言 4:18–19"> <span className="woj">もし全身が光に満ち、暗い部分が少しもなければ、明かりが輝いて照らす時のように、全身が明るくなる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="ルカ 7:36; コリント人への第一の手紙 9:19–23; ルカ 14:1"> イエスが話していると、あるパリサイ人が食事に招いた。イエスは家に入って食卓についた。</span>
<span className="v" id="v38" data-v="38" data-xref="マタイ 15:2–3; マルコ 7:2–5; ヨハネ 3:25"> パリサイ人は、イエスが食事の前にまず身を洗わなかったのを見て驚いた。</span>
<span className="v" id="v39" data-v="39" data-xref="テトス 1:15; 箴言 30:12; 創世記 6:5"> 主は彼に言った。<span className="woj">「あなたがたパリサイ人は、杯と皿の外側はきれいにするが、内側は強奪と邪悪に満ちている。</span></span>
<span className="v" id="v40" data-v="40" data-xref="ルカ 12:20; コリント人への第一の手紙 15:36; マタイ 23:26"> <span className="woj">愚かな者たちよ、外側を造られた方は、内側も造られたのではないか。</span></span>
<span className="v" id="v41" data-v="41" data-xref="ルカ 12:33; ヤコブの手紙 1:27; テトス 1:15"> <span className="woj">しかし、内にあるものを貧しい人々への施しとして与えなさい。見よ、そうすれば、すべてがあなたがたにとって清くなる。</span></span>
<span className="v" id="v42" data-v="42" data-xref="マタイ 23:23; ルカ 18:12; 箴言 21:3"> <span className="woj">しかし、パリサイ人よ、あなたがたは災いだ。はっか、うん香、あらゆる野菜の十分の一は納めるのに、正義と神への愛をなおざりにしている。これらを行い、十分の一も怠らないようにすべきだった。</span></span>
<span className="v" id="v43" data-v="43" data-xref="ルカ 20:46; マルコ 12:38–39; ルカ 14:7–11"> <span className="woj">パリサイ人よ、あなたがたは災いだ。会堂の上席や広場でのあいさつを好むからである。</span></span>
<span className="v" id="v44" data-v="44" data-xref="マタイ 23:27–28; 詩篇 5:9; 使徒の働き 23:3"> <span className="woj">律法学者、パリサイ人、偽善者よ、あなたがたは災いだ。人に気づかれず、その上を歩かれる墓のようなものだからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="ヨハネ 9:40; マタイ 22:35; エレミヤ書 6:10"> 律法の専門家の一人が答えた。「先生、そんなことを言われると、私たちまで侮辱することになります。」</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="ルカ 11:52; イザヤ書 10:1; マタイ 23:2–4"> イエスは言った。<span className="woj">「律法の専門家よ、あなたがたも災いだ。人々には背負いきれない重荷を負わせながら、自分では指一本、その重荷に触れようともしない。</span></span>
<span className="v" id="v47" data-v="47" data-xref="テサロニケ人への手紙第一 2:15; 使徒の働き 7:51; マタイ 23:29–33"> <span className="woj">あなたがたは災いだ。預言者たちの墓を建てているが、彼らを殺したのはあなたがたの父祖である。</span></span>
<span className="v" id="v48" data-v="48" data-xref="ヤコブの手紙 5:10; マタイ 23:31; 歴代誌 第二 36:16"> <span className="woj">こうしてあなたがたは、父祖の行いを証言し、同意している。彼らが預言者を殺し、あなたがたがその墓を建てるからである。</span></span>
<span className="v" id="v49" data-v="49" data-xref="コリント人への第一の手紙 1:30; コロサイ人への手紙 2:3; エペソ人への手紙 4:11"> <span className="woj">それゆえ神の知恵も言った。『私は彼らに預言者や使徒たちを遣わす。彼らはそのうちのある者を殺し、ある者を迫害する。</span></span>
<span className="v" id="v50" data-v="50" data-xref="創世記 9:5–6; ヨハネの黙示録 18:20–24; 列王記第二 24:4"> <span className="woj">それは、世界の基が据えられて以来流された、すべての預言者の血の責任を、この世代に問うためである。</span></span>
<span className="v" id="v51" data-v="51" data-xref="歴代誌 第二 24:20–22; マタイ 23:35; ヘブル人への手紙 11:4"> <span className="woj">アベルの血から、祭壇と聖所の間で殺されたザカリヤの血に至るまで。』そうだ。あなたがたに告げる。その責任はこの世代に問われる。</span></span>
<span className="v" id="v52" data-v="52" data-xref="マタイ 23:13; マラキ書 2:7; ルカ 11:45–46"> <span className="woj">律法の専門家よ、あなたがたは災いだ。知識の鍵を取り上げたからである。自分たちも入らず、入ろうとする人々をも妨げた。」</span></span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="コリント人への第一の手紙 13:5; エレミヤ書 20:10; ルカ 20:20"> イエスがこれらのことを彼らに言うと、律法学者たちとパリサイ人たちは激しく怒り始め、多くのことを問い詰め、</span>
<span className="v" id="v54" data-v="54" data-xref="マルコ 12:13; マタイ 22:15; マタイ 22:35"> イエスの言葉尻を捕らえて訴えようと、待ち構えていた。</span>
</div>

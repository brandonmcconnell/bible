<span className="v" id="v1" data-v="1" data-xref="申命記 23:25; マルコ 2:23–28; マタイ 12:1–8"> さて、最初の安息日の次に来る第二の安息日に、イエスが麦畑を通っていると、弟子たちは麦の穂を摘み、手でもんで食べた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 12:2; ヨハネ 5:16; ヨハネ 5:9–11"> パリサイ人のある者たちは言った。「なぜあなたがたは、安息日にしてはならないことをするのか。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="サムエル記第一 21:3–6; マルコ 2:25–26; マタイ 12:3–5"> イエスは彼らに答えた。<span className="woj">「ダビデとその供の者たちが空腹だった時、ダビデが何をしたか、読んだことがないのか。</span></span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 24:5–9"> <span className="woj">彼は神の家に入り、祭司以外は食べてはならない供えのパンを取って食べ、供の者たちにも与えたではないか。」</span></span>
<span className="v" id="v5" data-v="5" data-xref="マルコ 2:27; ヨハネの黙示録 1:10; マルコ 9:7"> また彼らに言った。<span className="woj">「人の子は安息日の主である。」</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="マルコ 3:1–6; マタイ 12:9–14; ルカ 4:31"> 別の安息日に、イエスは会堂に入って教えた。そこに右手の萎えた人がいた。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカ 20:20; 詩篇 38:12; ルカ 13:14"> 律法学者たちとパリサイ人たちは、イエスを訴える口実を見つけようと、安息日に癒やすかどうかを見張っていた。</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 42:4; マタイ 9:4; ルカ 5:22"> しかしイエスは彼らの考えを知って、手の萎えた人に言った。<span className="woj">「立って、真ん中に出なさい。」</span>その人は立ち上がってそこに立った。</span>
<span className="v" id="v9" data-v="9" data-xref="マルコ 3:4; マタイ 12:12–13; ルカ 14:3"> イエスは彼らに言った。<span className="woj">「あなたがたに尋ねる。安息日に許されているのは、良いことをすることか、害を加えることか。命を救うことか、殺すことか。」</span></span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 4:6–7; マルコ 3:5; ヨハネ 5:8"> イエスは彼ら一同を見回してから、その人に言った。<span className="woj">「手を伸ばしなさい。」</span>彼がそうすると、その手はもう一方の手と同じように元どおりになった。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 2:1–2; 使徒の働き 5:33; 伝道者の書 9:3"> しかし彼らは激しい怒りに満たされ、イエスをどうしようかと互いに話し合った。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 5:7; マルコ 6:46; マルコ 1:35"> そのころ、イエスは祈るために山へ行き、夜通し神に祈り続けた。</span>
<span className="v" id="v13" data-v="13" data-xref="マルコ 3:13–19; マタイ 9:36–4; ヨハネの黙示録 21:14"> 夜が明けると弟子たちを呼び、その中から十二人を選び、使徒と名づけた。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 1:13; マタイ 4:21; マタイ 4:18"> ペテロと名づけたシモン、その兄弟アンデレ、ヤコブ、ヨハネ、フィリポ、バルトロマイ、</span>
<span className="v" id="v15" data-v="15" data-xref="マタイ 9:9; マルコ 3:18; 使徒の働き 1:13"> マタイ、トマス、アルパヨの子ヤコブ、熱心党と呼ばれたシモン、</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネ 14:22; ヨハネ 6:70–71; マルコ 3:18"> ヤコブの子ユダ、そして裏切り者となったイスカリオテのユダである。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="マタイ 11:21; マタイ 4:23–25; 詩篇 107:17–20"> イエスは彼らとともに下り、平らな所に立った。そこには大勢の弟子たちと、イエスの教えを聞き、病気を癒やしてもらおうと、ユダヤ全土、エルサレム、またツロとシドンの海岸地方から来た、おびただしい数の人々がいた。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイ 17:15; マタイ 15:22; 使徒の働き 5:16"> 汚れた霊に苦しめられていた人々も癒やされた。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイ 14:36; マルコ 3:10; 使徒の働き 5:15–16"> 群衆は皆、イエスに触れようとした。イエスから力が出て、すべての人を癒やしていたからである。</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="ヤコブの手紙 2:5; ルカ 6:20–24; コリント人への第二の手紙 8:9"> イエスは弟子たちに目を向けて言った。<br /><span className="pl pl-1 woj">「貧しいあなたがたは幸いである。</span><br /><span className="pl pl-2 woj">神の王国はあなたがたのものだからである。</span></span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネ 6:35; マタイ 5:6; ヤコブの手紙 1:12"> <span className="pl pl-1 woj">今、飢えているあなたがたは幸いである。</span><br /><span className="pl pl-2 woj">満たされるからである。</span><br /><span className="pl pl-1 woj">今、泣いているあなたがたは幸いである。</span><br /><span className="pl pl-2 woj">笑うようになるからである。</span></span>

<span className="v" id="v23" data-v="23" data-xref="使徒の働き 5:41; ヨハネの黙示録 21:7; ヨハネの黙示録 3:12"> <span className="pl pl-2 woj">その日には喜び、躍り上がりなさい。見よ、天でのあなたがたの報いは大きい。彼らの父祖たちも預言者たちに同じことをしたからである。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="マタイ 6:2; ヤコブの手紙 5:1–6; 詩篇 49:6–7"> <span className="pl pl-1 woj">しかし、富んでいるあなたがたは災いである。</span><br /><span className="pl pl-2 woj">すでに慰めを受けているからである。</span></span>

<span className="v" id="v26" data-v="26" data-xref="ヨハネ 15:19; ヤコブの手紙 4:4; マタイ 7:15"> <span className="pl pl-1 woj">人々が</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TRは「すべての」を加えている。">a</a></sup><br /><span className="pl pl-1 woj">あなたがたをほめる時、</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TRは「あなたがたは」を加えている。">b</a></sup><br /><span className="pl pl-1 woj">災いだ。</span><br /><span className="pl pl-2 woj">彼らの父祖たちも偽預言者たちに同じことをしたからである。</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="テサロニケ人への手紙第一 5:15; ルカ 6:35; ローマ人への手紙 12:17–21"> <span className="woj">「しかし、聞いているあなたがたに言う。敵を愛し、あなたがたを憎む者に良いことをしなさい。</span></span>
<span className="v" id="v28" data-v="28" data-xref="ペテロの手紙第一 3:9; コリント人への第一の手紙 4:12; ローマ人への手紙 12:14"> <span className="woj">あなたがたを呪う者を祝福し、虐待する者のために祈りなさい。</span></span>
<span className="v" id="v29" data-v="29" data-xref="ヘブル人への手紙 10:34; マタイ 5:39–42; コリント人への第二の手紙 11:20"> <span className="woj">あなたの頬を打つ者には、もう一方の頬も差し出しなさい。上着を奪う者には、下着も拒んではならない。</span></span>
<span className="v" id="v30" data-v="30" data-xref="申命記 15:7–10; コリント人への第二の手紙 9:6–14; マタイ 6:12"> <span className="woj">求める者にはだれにでも与え、あなたの物を奪う者から取り戻そうとしてはならない。</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="マタイ 7:12; ガラテヤ人への手紙 5:14; マタイ 22:39"> <span className="woj">「人にしてもらいたいと思うとおりに、あなたがたも人にしなさい。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="マタイ 5:46–47; ペテロの手紙第一 2:19–20"> <span className="woj">「自分を愛する者を愛したからといって、何の誉れになるだろう。罪人たちでさえ、自分を愛する者を愛する。</span></span>
<span className="v" id="v33" data-v="33"> <span className="woj">自分に良いことをする者に良いことをしたからといって、何の誉れになるだろう。罪人たちでさえ同じことをする。</span></span>
<span className="v" id="v34" data-v="34" data-xref="マタイ 5:42; ルカ 14:12–14; ルカ 6:35"> <span className="woj">返してもらえると期待して貸したからといって、何の誉れになるだろう。罪人たちでさえ、同じだけ返してもらうために罪人たちに貸す。</span></span>
<span className="v" id="v35" data-v="35" data-xref="マタイ 5:44–45; ヨハネ 13:35; 箴言 19:17"> <span className="woj">しかし、敵を愛し、良いことをし、何も返してもらおうとせずに貸しなさい。そうすれば、あなたがたの報いは大きく、いと高き方の子らとなる。いと高き方は、感謝しない者にも悪人にも情け深いからである。</span></span>
<span className="v" id="v36" data-v="36" data-xref="エペソ人への手紙 5:1–2; マタイ 5:48; ペテロの手紙第一 1:15–16"> <span className="pl pl-1 woj">「だから、あわれみ深い者となりなさい。</span><br /><span className="pl pl-2 woj">あなたがたの父もあわれみ深い方だからである。</span></span>
<span className="v" id="v37" data-v="37" data-xref="エペソ人への手紙 4:32; ヤコブの手紙 5:9; マタイ 7:1–5"> <span className="pl pl-1 woj">人を裁いてはならない。</span><br /><span className="pl pl-2 woj">そうすれば、あなたがたも裁かれない。</span><br /><span className="pl pl-1 woj">人を罪に定めてはならない。</span><br /><span className="pl pl-2 woj">そうすれば、あなたがたも罪に定められない。</span><br /><span className="pl pl-1 woj">人を解放しなさい。</span><br /><span className="pl pl-2 woj">そうすれば、あなたがたも解放される。</span></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="コリント人への第二の手紙 9:6–8; 申命記 15:10; マルコ 4:24"> <span className="woj">「与えなさい。そうすれば、あなたがたにも与えられる。十分に量り、押し込み、揺すって詰め、あふれるほどにして与えられる。</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="直訳すると「あなたがたの懐に」である。">c</a></sup><span className="woj">あなたがたが量るその量りで、あなたがたにも量り返されるからである。」</span></span>
</div>
<div className="bp">

<span className="v" id="v43" data-v="43" data-xref="エレミヤ書 2:21; マタイ 12:33; マタイ 7:16–20"> <span className="woj">「悪い実を結ぶ良い木はなく、良い実を結ぶ悪い木もない。</span></span>

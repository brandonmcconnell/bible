<span className="v" id="v1" data-v="1" data-xref="ペテロの手紙第一 4:17–18; 哀歌 2:20; エゼキエル書 9:5–7"> ちょうどその時、ピラトがガリラヤ人たちの血を彼らのいけにえに混ぜたことを、イエスに知らせた人々がいた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネ 9:2; 使徒の働き 28:4; ヨブ記 22:5–16"> イエスは答えた。<span className="woj">「そのガリラヤ人たちはこのような目に遭ったから、ほかのすべてのガリラヤ人より罪深かったと思うのか。</span></span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 3:19; マタイ 3:2; 使徒の働き 2:38–40"> <span className="woj">そうではない。あなたがたに言う。悔い改めなければ、あなたがたも皆、同じように滅びる。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ネヘミヤ記 3:15; ヨブ記 1:19; ヨハネ 9:11"> <span className="woj">また、シロアムの塔が倒れて死んだ十八人は、エルサレムに住むほかのすべての人より罪深かったと思うのか。</span></span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 18:30; ルカ 13:3; イザヤ書 28:10–13"> <span className="woj">そうではない。あなたがたに言う。悔い改めなければ、あなたがたも皆、同じように滅びる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 15:16; イザヤ書 5:1–4; ガラテヤ人への手紙 5:22"> イエスはこのたとえを語った。<span className="woj">「ある人が、ぶどう園にいちじくの木を植えていた。実を捜しに来たが、一つも見つからなかった。</span></span>
<span className="v" id="v7" data-v="7" data-xref="マタイ 7:19; ルカ 3:9; ヨハネ 15:6"> <span className="woj">そこで園の番人に言った。『見よ、三年間、この木に実を捜しに来たが、一つも見つからない。切り倒しなさい。なぜ土地を無駄にしておくのか。』</span></span>
<span className="v" id="v8" data-v="8" data-xref="ペテロの第二の手紙 3:9; ヨエル書 2:17; ローマ人への手紙 10:1"> <span className="woj">番人は答えた。『ご主人様、今年もこのままにしてください。周りを掘って肥料をやります。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネ 15:2; テサロニケ人への手紙第一 2:15; ヘブル人への手紙 6:8"> <span className="woj">実を結べばよし、結ばなければ、その後で切り倒してください。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="マタイ 4:23; ルカ 4:44; ルカ 4:15–16"> イエスは安息日に、ある会堂で教えていた。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカ 8:2; ルカ 8:27; ルカ 13:16"> 見よ、十八年間、病の霊に取りつかれている女がいた。腰が曲がり、まったく伸ばすことができなかった。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 107:20; マタイ 8:16; ルカ 6:8–10"> イエスは彼女を見ると呼び寄せて言った。<span className="woj">「女よ、あなたは病から解放された。」</span></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 107:20–22; マルコ 16:18; マルコ 5:23"> そして手を置くと、彼女はただちにまっすぐになり、神に栄光を帰した。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 20:9; マタイ 12:2; ヨハネ 9:14–16"> 会堂の長は、イエスが安息日に癒やしたことに腹を立て、群衆に言った。「働くべき日は六日ある。その日に来て癒やしてもらいなさい。安息日にはいけない。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ルカ 14:5; ヨハネ 7:21–24; 使徒の働き 13:9–10"> 主は彼に答えた。<span className="woj">「偽善者たちよ。あなたがたは皆、安息日にも牛やろばを小屋から解き、水を飲ませに連れて行くではないか。</span></span>
<span className="v" id="v16" data-v="16" data-xref="マルコ 2:27; テモテへの第二の手紙 2:26; ルカ 19:9"> <span className="woj">それなら、サタンに十八年も縛られていたアブラハムの娘であるこの女が、安息日に束縛から解放されるべきではないか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ペテロの手紙第一 3:16; 詩篇 132:18; イザヤ書 45:24"> イエスがこう言うと、反対する者たちは皆恥じ入り、群衆は皆、イエスが行った栄光あるすべてのわざを喜んだ。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="マルコ 4:30–34; ルカ 17:21; マタイ 13:31–32"> イエスは言った。<span className="woj">「神の王国は何に似ているか。何にたとえよう。</span></span>
<span className="v" id="v19" data-v="19" data-xref="ダニエル書 4:12; ダニエル書 4:21; ダニエル書 2:44–45"> <span className="woj">一粒のからし種のようなものである。ある人がそれを取って自分の庭にまくと、育って大きな木になり、空の鳥がその枝に巣を作った。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> また言った。<span className="woj">「神の王国を何にたとえよう。</span></span>
<span className="v" id="v21" data-v="21" data-xref="マタイ 13:33; コリント人への第一の手紙 5:6; テサロニケ人への手紙第一 5:23–24"> <span className="woj">パン種のようなものである。女がそれを取って三サタ</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="直訳すると「三サタ」。三サタは約39リットル、または一ブッシェルを少し超える量である。">a</a></sup><span className="woj">の小麦粉に混ぜると、全体が膨らんだ。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ルカ 9:51; マタイ 9:35; マルコ 10:32–34"> イエスは町や村を通って教えながら、エルサレムへの旅を続けた。</span>
<span className="v" id="v23" data-v="23" data-xref="マタイ 7:14; マタイ 22:14; ヨハネ 21:21–22"> ある人が尋ねた。「主よ、救われる人は少ないのですか。」<br />イエスは人々に言った。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイ 7:13–14; ペテロの第二の手紙 1:10; コリント人への第一の手紙 9:24–27"> <span className="woj">「狭い戸口から入るよう力を尽くしなさい。あなたがたに言うが、多くの人が入ろうとしても、入れなくなるからである。</span></span>
<span className="v" id="v25" data-v="25" data-xref="マタイ 25:10–12; ルカ 13:27; マタイ 7:21–23"> <span className="woj">家の主人が立ち上がって戸を閉めた後、あなたがたは外に立って戸をたたき、『主よ、主よ、開けてください』と言い始める。しかし主人は、『おまえたちがどこの者か知らない』と答える。</span></span>
<span className="v" id="v26" data-v="26" data-xref="イザヤ書 58:2; テトス 1:16; テモテへの第二の手紙 3:5"> <span className="woj">するとあなたがたは、『私たちはあなたの前で食べたり飲んだりし、あなたは私たちの大通りで教えてくださいました』と言い始める。</span></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 6:8; マタイ 25:41; マタイ 7:22–23"> <span className="woj">しかし主人は言う。『おまえたちがどこの者か知らない。不正を行う者たちよ、皆、私から離れよ。』</span></span>
<span className="v" id="v28" data-v="28" data-xref="マタイ 8:11–12; マタイ 22:13; マタイ 25:30"> <span className="woj">アブラハム、イサク、ヤコブとすべての預言者が神の王国にいるのに、自分たちは外へ投げ出されているのを見る時、そこで泣きわめき、歯ぎしりする。</span></span>
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 43:6; イザヤ書 66:18–20; イザヤ書 49:6"> <span className="woj">人々が東西南北から来て、神の王国で食卓につく。</span></span>
<span className="v" id="v30" data-v="30" data-xref="マタイ 19:30; マルコ 10:31; マタイ 20:16"> <span className="woj">見よ、後の者で先になる者がおり、先の者で後になる者がいる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ネヘミヤ記 6:9–11; 詩篇 11:1–2; マタイ 14:1"> その日に、何人かのパリサイ人が来て言った。「ここを出て、立ち去りなさい。ヘロデがあなたを殺そうとしています。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="ヘブル人への手紙 2:10; ヘブル人への手紙 5:9; ヨハネ 17:4–5"> イエスは彼らに言った。<span className="woj">「行って、あの狐に伝えなさい。『見よ、私は今日と明日、悪霊を追い出し、病を治し、三日目に使命を終える。</span></span>
<span className="v" id="v33" data-v="33" data-xref="ルカ 9:53; マタイ 21:11; 使徒の働き 13:27"> <span className="woj">それでも今日、明日、その次の日と旅を続けなければならない。預言者がエルサレムの外で死ぬことはあり得ないからである。』</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="マタイ 23:37–39; 申命記 32:11–12; 使徒の働き 7:52"> <span className="woj">「エルサレム、エルサレム。預言者たちを殺し、遣わされた人々を石で打つ者よ。めんどりがひなを翼の下に集めるように、私は何度あなたの子らを集めようとしたことか。それなのに、あなたがたは応じなかった。</span></span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 118:26; マルコ 11:9–10; マタイ 21:9"> <span className="woj">見よ、あなたがたの家は荒れ果てたまま残される。あなたがたに言う。『主の名によって来る方は祝福されている』と言う時まで、あなたがたは私を見ることがない。」</span></span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 4:1–11; 使徒の働き 10:38; マルコ 1:12–13"> イエスは聖霊に満たされてヨルダン川から帰り、御霊によって荒野へ導かれ、</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 34:28; ヘブル人への手紙 4:15; 申命記 9:9"> 四十日間、悪魔の誘惑を受けた。その間、何も食べず、その期間が終わると空腹を覚えた。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="マタイ 4:3; ルカ 3:22"> 悪魔はイエスに言った。「あなたが神の子なら、この石にパンになれと命じなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="申命記 8:3; マタイ 4:4; マタイ 6:31"> イエスは答えた。<span className="woj">「『人はパンだけで生きるのではなく、神の一つ一つの言葉によって生きる』と書かれている。」</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ヨハネの手紙第一 2:15–16; コリント人への第一の手紙 15:52; マタイ 4:8"> 悪魔はイエスを高い山へ連れて行き、一瞬のうちに世界のすべての国々を見せた。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 12:31; ヨハネの手紙第一 5:19; ヨハネ 14:30"> そして言った。「このすべての権威と栄華をあなたに与えよう。これは私に渡されており、私は望む者に与えることができる。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカ 8:28; 詩篇 72:11; イザヤ書 45:14"> だから、あなたが私の前にひれ伏すなら、すべてはあなたのものになる。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="申命記 6:13; 申命記 10:20; マタイ 4:10"> イエスは答えた。<span className="woj">「私の後ろに退け、サタン。『あなたの神である主を礼拝し、ただ主にのみ仕えなければならない』と書かれている。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="マタイ 4:5–6; ルカ 4:3; マタイ 8:29"> 悪魔はイエスをエルサレムへ連れて行き、神殿の屋根の端に立たせて言った。「あなたが神の子なら、ここから飛び降りなさい。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 91:11–12; ヘブル人への手紙 1:14; コリント人への第二の手紙 11:14"> こう書かれているからだ。<br /><span className="pl pl-1">『神はあなたのために御使いたちに命じ、あなたを守らせる。』</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="詩篇 91:12"> また、<br /><span className="pl pl-1">『彼らはその手であなたを支え、</span><br /><span className="pl pl-2">あなたの足が石に打ち当たることのないようにする。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 6:16; ヘブル人への手紙 3:8–9; コリント人への第一の手紙 10:9"> イエスは答えた。<span className="woj">「『あなたの神である主を試してはならない』と言われている。」</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 4:15; ヤコブの手紙 4:7; マタイ 4:11"> 悪魔はあらゆる誘惑を終えると、次の機会までイエスから離れた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マタイ 4:23–25; 使徒の働き 10:37; マタイ 4:12"> イエスは御霊の力に満ちてガリラヤへ帰り、その評判は周辺一帯に広まった。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイ 4:23; マタイ 9:8; マタイ 9:35"> イエスは彼らの会堂で教え、すべての人から称賛された。</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 17:2; 使徒の働き 13:14–16; マタイ 2:23"> イエスは育った町ナザレへ行き、いつものように安息日に会堂に入り、朗読するために立ち上がった。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 61:1–3; 使徒の働き 13:15; 使徒の働き 7:42"> 預言者イザヤの書が手渡された。イエスは巻物を開き、こう書かれている箇所を見つけた。</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 61:1; マタイ 11:5; 詩篇 146:7–8"> <span className="pl pl-1 woj">「主の霊が私の上におられる。</span><br /><span className="pl pl-2 woj">貧しい人々に福音を宣べ伝えるため、主が私に油を注がれたからである。</span><br /><span className="pl pl-1 woj">主は、心の打ち砕かれた者を癒やし、</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NUは「心の打ち砕かれた者を癒やし」を省いている。">a</a></sup><br /><span className="pl pl-2 woj">捕らわれた者に解放を、</span><br /><span className="pl pl-2 woj">目の見えない者に視力の回復を告げ、</span><br /><span className="pl pl-2 woj">打ちひしがれた者を自由にし、</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 61:2; イザヤ書 63:4; コリント人への第二の手紙 6:1"> <span className="pl pl-2 woj">主の恵みの年を告げるために、私を遣わされた。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ルカ 4:17; ヨハネ 8:2; ルカ 19:48"> イエスは巻物を閉じ、係の者に返して座った。会堂にいたすべての人の目が、イエスに注がれていた。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネ 4:25–26; 使徒の働き 3:18; 使徒の働き 2:16–18"> イエスは彼らに語り始めた。<span className="woj">「今日、この聖書の言葉が、あなたがたの聞いているところで実現した。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="マタイ 13:54–56; 詩篇 45:2; 使徒の働き 6:10"> 人々は皆、イエスについて証言し、その口から出る恵みに満ちた言葉に驚いて言った。「この人はヨセフの子ではないか。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ヨハネ 4:46–53; マタイ 11:23–24; マルコ 2:1–12"> イエスは彼らに言った。<span className="woj">「きっとあなたがたは、『医者よ、自分を治せ』ということわざを私に言うだろう。『カペナウムで行ったと聞いていることを、ここ、あなたの故郷でも行え』と。</span></span>
<span className="v" id="v24" data-v="24" data-xref="マタイ 13:57; ヨハネ 4:44; マルコ 6:4–5"> イエスは言った。<span className="woj">「まことに、あなたがたに告げる。預言者はだれも、自分の故郷では受け入れられない。</span></span>
<span className="v" id="v25" data-v="25" data-xref="ヤコブの手紙 5:17; 列王記第一 17:1; マタイ 20:15"> <span className="woj">まことに、あなたがたに告げる。エリヤの時代、三年六か月の間、天が閉ざされ、全地に大飢饉が起こった時、イスラエルには多くのやもめがいた。</span></span>
<span className="v" id="v26" data-v="26" data-xref="列王記第一 17:9–24; マタイ 11:21; オバデヤ書 1:20"> <span className="woj">しかしエリヤが遣わされたのは、そのうちのだれでもなく、シドンの地のツァレファテにいた一人のやもめの女のところだけだった。</span></span>
<span className="v" id="v27" data-v="27" data-xref="列王記第二 5:1–27; ヨハネ 17:12; マタイ 12:4"> <span className="woj">また、預言者エリシャの時代、イスラエルには多くのらい病人がいたが、清められたのはシリア人ナアマンだけであった。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="使徒の働き 5:33; 歴代誌 第二 24:20–21; エレミヤ書 38:6"> 会堂にいた人々はこれを聞くと、皆、激しい怒りに満たされた。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネ 8:59; 使徒の働き 21:28–32; 民数記 15:35"> 彼らは立ち上がってイエスを町の外に追い出し、町が建っている丘の崖まで連れて行き、そこから突き落とそうとした。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネ 10:39; ヨハネ 8:59; ヨハネ 18:6–7"> しかしイエスは彼らの真ん中を通り抜け、立ち去った。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="マルコ 1:21–28; マタイ 4:13; 使徒の働き 13:50–2"> イエスはガリラヤの町カペナウムへ下り、安息日に人々を教えていた。</span>
<span className="v" id="v32" data-v="32" data-xref="ルカ 4:36; マタイ 7:28–29; ヨハネ 6:63"> 人々はその教えに驚いた。その言葉には権威があったからである。</span>
<span className="v" id="v33" data-v="33" data-xref="マルコ 1:23"> 会堂に、汚れた悪霊につかれた人がいて、大声で叫んだ。</span>
<span className="v" id="v34" data-v="34" data-xref="マルコ 1:24; ヤコブの手紙 2:19; マタイ 8:29"> 「ああ、ナザレのイエスよ、私たちとあなたに何の関わりがあるのですか。私たちを滅ぼしに来たのですか。私はあなたがどなたか知っています。神の聖なる方です。」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="ルカ 4:41; ルカ 4:39; マタイ 8:26"> イエスは叱りつけて言った。<span className="woj">「黙れ。この人から出て行け。」</span>悪霊はその人を人々の真ん中に投げ倒したが、傷つけることなく出て行った。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="ルカ 4:32; ペテロの手紙第一 3:22; マタイ 12:22–23"> 人々は皆、驚きに包まれ、互いに言った。「これは何という言葉だろう。権威と力をもって汚れた霊に命じると、出て行くではないか。」</span>
<span className="v" id="v37" data-v="37" data-xref="マルコ 1:45; ルカ 4:14; イザヤ書 52:13"> イエスの評判は、周辺地方のあらゆる所に広まった。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="マタイ 8:14–15; マルコ 1:29–31; ヨハネ 11:22"> イエスは会堂を出て、シモンの家に入った。シモンのしゅうとめが高熱で苦しんでいたので、人々は彼女のためにイエスに願った。</span>
<span className="v" id="v39" data-v="39" data-xref="ルカ 4:41; ルカ 4:35; ルカ 8:24"> イエスが彼女のそばに立って熱を叱ると、熱は去った。彼女はすぐに起き上がり、彼らをもてなした。</span>
<span className="v" id="v40" data-v="40" data-xref="マルコ 1:32–34; マタイ 8:16–17; マルコ 5:23"> 日が沈むころ、さまざまな病気で苦しむ者を抱えていた人々は皆、彼らをイエスのもとに連れて来た。イエスは一人一人に手を置いて癒やした。</span>
<span className="v" id="v41" data-v="41" data-xref="マルコ 1:34; ヤコブの手紙 2:19; ルカ 4:34–35"> 多くの人から悪霊も出て行き、「あなたはキリスト、神の子です」と叫んだ。イエスは悪霊を叱り、話すことを許さなかった。彼らがイエスをキリストだと知っていたからである。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="ルカ 6:12; マルコ 1:35–38; ヨハネ 4:34"> 夜が明けると、イエスは出て行き、人里離れた所へ行った。群衆はイエスを捜し、そばまで来ると、自分たちから離れて行かないように引き止めた。</span>
<span className="v" id="v43" data-v="43" data-xref="マルコ 1:38–39; テモテへの第二の手紙 4:2; ヨハネ 9:4"> しかしイエスは彼らに言った。<span className="woj">「私はほかの町々にも神の王国の福音を宣べ伝えなければならない。そのために遣わされたからである。」</span></span>
<span className="v" id="v44" data-v="44" data-xref="マタイ 4:23; マルコ 1:39; ルカ 4:15"> イエスはガリラヤの諸会堂で宣べ伝えていた。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 6:1–27; ルカ 18:35; 列王記第二 2:18–22"> イエスはエリコに入り、町を通っていた。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカ 18:24–27; 歴代誌 第二 17:5–6"> ザアカイという人がいた。彼は徴税人の長で、金持ちであった。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカ 23:8; ルカ 9:7–9; ヨハネ 12:21"> イエスがどのような方か見ようとしたが、背が低かったので、群衆のために見ることができなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 9:10; ルカ 5:19; 列王記第一 10:27"> それで先へ走って行き、イエスを見るためにいちじく桑の木に登った。イエスがそこを通ろうとしておられたからである。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 3:20; ヨハネ 14:23; ヘブル人への手紙 13:2"> イエスはその場所に来ると、見上げて彼を見て言った。<span className="woj">「ザアカイ、急いで下りて来なさい。今日はあなたの家に泊まらなければならない。」</span></span>
<span className="v" id="v6" data-v="6" data-xref="ルカ 5:29; 使徒の働き 16:34; 使徒の働き 16:15"> ザアカイは急いで下りて来て、喜んでイエスを迎えた。</span>
<span className="v" id="v7" data-v="7" data-xref="ルカ 15:2; ルカ 7:39; ルカ 7:34"> 人々は皆それを見て、「あの人は罪人の所に入って客となった」とつぶやいた。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="サムエル記第二 12:6; 民数記 5:7; ルカ 18:22–23"> ザアカイは立って主に言った。「見よ、主よ。私は財産の半分を貧しい人たちに与えます。だれかから不正に取り立てたものがあれば、四倍にして返します。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ガラテヤ人への手紙 3:7; ルカ 13:16; ローマ人への手紙 4:16"> イエスは彼に言った。<span className="woj">「今日、この家に救いが来た。この人もアブラハムの子なのだから。</span></span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 34:16; マタイ 1:21; テモテへの手紙第一 1:13–16"> <span className="woj">人の子は、失われたものを捜して救うために来たのである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ルカ 17:20; 使徒の働き 1:6; テサロニケ人への第二の手紙 2:1–3"> 人々がこれらのことを聞いていると、イエスはさらに一つのたとえを語った。エルサレムの近くに来ており、人々は神の王国がすぐにも現れると思っていたからである。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイ 25:14–30; ルカ 19:12–27; ルカ 20:9"> それでイエスは言った。<span className="woj">「ある身分の高い人が、王位を受けて戻るために遠い国へ出かけた。</span></span>
<span className="v" id="v13" data-v="13" data-xref="マタイ 25:14–15; ヨハネ 12:26; コリント人への第一の手紙 12:7–11"> <span className="woj">彼は十人のしもべを呼び、十ミナ硬貨を与え、</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十ミナは農業労働者の三年分を超える賃金に相当した。">a</a></sup><span className="woj">『私が帰るまで商売をしなさい』と言った。</span></span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記第一 8:7; 使徒の働き 7:51–52; 使徒の働き 3:14–15"> <span className="woj">しかし国民は彼を憎み、その後から使節を送って、『われわれは、この人に王となってもらいたくない』と言わせた。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 4:1–5; ローマ人への手紙 14:10–12; 詩篇 2:4–6"> <span className="woj">「彼は王位を受けて帰って来ると、金を与えておいたしもべたちを呼び寄せるよう命じた。商売によってどれだけもうけたかを知るためであった。</span></span>
<span className="v" id="v16" data-v="16" data-xref="ヤコブの手紙 2:18–26; テモテへの第二の手紙 4:7–8; コリント人への第一の手紙 15:10"> <span className="woj">最初の者が進み出て言った。『ご主人様、あなたの一ミナが十ミナをもうけました。』</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ルカ 16:10; マタイ 25:21; ヨハネの黙示録 2:26–29"> <span className="woj">「主人は彼に言った。『よくやった、良いしもべだ。ごく小さなことに忠実だったから、十の町を治めなさい。』</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="マルコ 4:20; マタイ 13:23; コリント人への第二の手紙 8:12"> <span className="woj">「二番目の者が来て言った。『ご主人様、あなたの一ミナが五ミナをもうけました。』</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="コリント人への第一の手紙 15:58; コリント人への第一の手紙 15:41–42; コリント人への第一の手紙 3:8"> <span className="woj">「主人は彼にも言った。『あなたは五つの町を治めなさい。』</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="マタイ 25:24; 箴言 26:13–16; ヤコブの手紙 4:17"> <span className="woj">「また別の者が来て言った。『ご主人様、見よ、あなたの一ミナです。布に包んでしまっておきました。</span></span>
<span className="v" id="v21" data-v="21" data-xref="マタイ 25:24–25; ローマ人への手紙 8:7; ヨハネの手紙第一 4:18"> <span className="woj">あなたは厳しい方なので、恐ろしかったのです。預けなかったものを取り立て、蒔かなかったものを刈り取る方だからです。』</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="サムエル記第二 1:16; マタイ 12:37; ヨブ記 15:5–6"> <span className="woj">「主人は彼に言った。『悪いしもべよ、あなた自身の言葉によって裁こう。私が厳しい人間で、預けなかったものを取り立て、蒔かなかったものを刈り取ると知っていたのか。</span></span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 22:25–27; ローマ人への手紙 2:4–5; 申命記 23:19–20"> <span className="woj">それなら、なぜ私の金を銀行に預けなかったのか。そうしておけば、帰って来た時に利息とともに受け取れたのに。』</span></span>
<span className="v" id="v24" data-v="24" data-xref="ルカ 16:2; ルカ 12:20"> <span className="woj">そして、そばに立っていた人々に言った。『この者から一ミナを取り上げ、十ミナ持っている者に与えなさい。』</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ルカ 16:2; サムエル記第二 7:19; イザヤ書 55:8–9"> <span className="woj">「彼らは言った。『ご主人様、あの人はすでに十ミナ持っています。』</span></span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの手紙第二 1:8; ルカ 8:18; マタイ 21:43"> <span className="woj">『あなたがたに言う。持っている者にはさらに与えられ、持っていない者からは、持っているものまで取り上げられる。</span></span>
<span className="v" id="v27" data-v="27" data-xref="ルカ 19:14; 詩篇 21:8–9; マタイ 22:7"> <span className="woj">だが、私が王になることを望まなかったあの敵どもをここに連れて来て、私の前で殺せ。』」</span></span>
<span className="v" id="v28" data-v="28" data-xref="ルカ 9:51; ヘブル人への手紙 12:2; ペテロの手紙第一 4:1"> イエスはこう語ると、先頭に立ってエルサレムへ上って行った。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 1:12; マタイ 21:17; マタイ 21:1–11"> オリーブ山のふもとのベツファゲ<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TRとNUは「ベツファゲ」の代わりに「ベテパゲ」としている。">b</a></sup>とベタニアに近づいた時、イエスは二人の弟子を遣わし、</span>
<span className="v" id="v30" data-v="30" data-xref="ルカ 22:8–13; ルカ 19:32; サムエル記第一 10:2–9"> 言った。<span className="woj">「向こうの村へ行きなさい。村に入ると、まだだれも乗ったことのない子ろばがつながれているのを見つける。それを解いて連れて来なさい。</span></span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 24:1; 詩篇 50:10–12; マルコ 11:3–6"> <span className="woj">もしだれかが『なぜ解くのか』と尋ねたら、『主がお入り用なのです』と言いなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="ルカ 22:13"> 遣わされた二人が行ってみると、イエスが言ったとおりであった。</span>
<span className="v" id="v33" data-v="33"> 彼らが子ろばを解いていると、持ち主たちが言った。「なぜ子ろばを解くのか。」</span>
<span className="v" id="v34" data-v="34" data-xref="ゼカリヤ書 9:9; ヨハネ 10:35; コリント人への第二の手紙 8:9"> 二人は答えた。「主がお入り用なのです。」</span>
<span className="v" id="v35" data-v="35" data-xref="マルコ 11:7–8; マタイ 21:7; ヨハネ 12:14"> そして子ろばをイエスのもとに連れて来た。自分たちの上着を子ろばの上にかけ、イエスをその上に乗せた。</span>
<span className="v" id="v36" data-v="36" data-xref="列王記第二 9:13; マタイ 21:8"> イエスが進んで行くと、人々は道に上着を敷いた。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="ヨハネ 12:12–13; エズラ記 3:10–13; マタイ 21:1"> イエスがオリーブ山の下り坂に近づいた時、弟子たちの群衆は皆、これまで見たすべての力あるわざのために喜び、大声で神を賛美し始め、</span>
<span className="v" id="v38" data-v="38" data-xref="ゼカリヤ書 9:9; ルカ 13:35; 詩篇 118:22–26"> こう言った。「主の御名によって来られる王は幸いである。天には平和、いと高き所には栄光。」</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒の働き 4:1–2; マタイ 23:13; 使徒の働き 4:16–18"> 群衆の中にいたパリサイ人の何人かがイエスに言った。「先生、あなたの弟子たちを叱ってください。」</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="ハバクク書 2:11; イザヤ書 55:12; マタイ 3:9"> イエスは答えた。<span className="woj">「あなたがたに言う。もし彼らが黙れば、石が叫び出す。」</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="ルカ 13:34–35; ヨハネ 11:35; 詩篇 119:136"> イエスは近づいて都を見ると、そのために泣き、</span>
<span className="v" id="v42" data-v="42" data-xref="申命記 32:29; ヘブル人への手紙 10:26–29; イザヤ書 48:18"> 言った。<span className="woj">「おまえも、せめて今日、平和への道を知っていたなら。しかし今、それはおまえの目から隠されている。</span></span>
<span className="v" id="v43" data-v="43" data-xref="ルカ 21:20–24; イザヤ書 29:1–4; エゼキエル書 4:2"> <span className="woj">おまえの敵が周囲に防壁を築き、おまえを取り囲み、四方から包囲する日が来る。</span></span>
<span className="v" id="v44" data-v="44" data-xref="ルカ 21:6; ルカ 13:34–35; ヨハネ 3:18–21"> <span className="woj">彼らはおまえと、おまえの中にいる子どもたちを地面にたたきつけ、おまえの中で石を一つもほかの石の上に残さない。神が訪れてくださった時を、おまえが知らなかったからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="マタイ 21:12–13; マルコ 11:15–17; ヨハネ 2:13–17"> イエスは神殿に入り、そこで売り買いしている者たちを追い出し始め、</span>
<span className="v" id="v46" data-v="46" data-xref="イザヤ書 56:7; エレミヤ書 7:11; 詩篇 93:5"> 彼らに言った。<span className="woj">「『私の家は祈りの家である』と書かれている。</span><span className="woj">それなのに、あなたがたはそれを『強盗の巣』にした。」</span></span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="マルコ 11:18; マタイ 26:55; マルコ 11:27–33"> イエスは毎日、神殿で教えていた。しかし祭司長たち、律法学者たち、民の指導者たちは、イエスを滅ぼそうとしていた。</span>
<span className="v" id="v48" data-v="48" data-xref="ネヘミヤ記 8:3; 使徒の働き 16:14; ヨハネ 7:46–49"> けれども、どうすればよいか分からなかった。民が皆、その一言一言に聞き入っていたからである。</span>
</div>

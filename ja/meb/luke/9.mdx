<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネ 14:12; ルカ 10:19; マタイ 16:19"> イエスは十二人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TRは「十二人」の代わりに「十二人の弟子たち」としている。">a</a></sup>を呼び集め、すべての悪霊を制し、病気を治す力と権威を授けた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 10:7–8; ルカ 10:9; マタイ 3:2"> そして神の王国を宣べ伝え、病人を癒やすために彼らを遣わした。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカ 22:35; 詩篇 37:3; ルカ 10:4–12"> 彼らに言った。<span className="woj">「旅には何も持って行ってはならない。杖も袋もパンも金も持たず、衣も二枚持ってはならない。</span></span>
<span className="v" id="v4" data-v="4" data-xref="マタイ 10:11; マルコ 6:10; ルカ 10:5–8"> <span className="woj">どの家に入っても、そこにとどまり、そこから出発しなさい。</span></span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 13:51; 使徒の働き 18:6; マルコ 6:11"> <span className="woj">あなたがたを受け入れない者がいれば、その町を出る時、彼らへのあかしとして、足のちりまでも払い落としなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 4:30; マルコ 16:20; 使徒の働き 5:15"> 十二人は出て行き、村々を巡りながら、至る所で福音を宣べ伝え、病人を癒やした。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マルコ 6:14–28; マタイ 14:1–12; ルカ 3:1"> 領主ヘロデは、イエスが行ったすべてのことを聞き、ひどく当惑した。ヨハネが死人の中から生き返ったと言う人もいれば、</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネ 1:21; ルカ 9:19; マルコ 6:15"> エリヤが現れたと言う人、昔の預言者の一人が生き返ったと言う人もいたからである。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカ 23:8; ルカ 13:31–32"> ヘロデは言った。「ヨハネなら私が首をはねた。それでは、こんなことを聞くこの人はだれなのか。」そしてイエスに会おうとした。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="マタイ 11:21; ヘブル人への手紙 13:17; マタイ 14:13–21"> 使徒たちは帰って来ると、自分たちが行ったことをイエスに報告した。<br />イエスは彼らを連れ、ベツサイダという町の<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NUは「人のいない地方」を省いている。">b</a></sup>人のいない地方へひそかに退いた。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカ 9:2; ルカ 5:31; ヘブル人への手紙 4:16"> しかし群衆はそれに気づいて後を追った。イエスは彼らを迎え、神の王国について語り、癒やしを必要とする人々を治した。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネ 6:1; ヨハネ 6:5–15; ホセア書 13:5"> 日が傾き始めると、十二人が来て言った。「群衆を解散させ、周辺の村や集落へ行って宿と食べ物を得させてください。ここは人里離れた所ですから。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 11:24–25; ヨハネ 6:5–9; 列王記第二 4:42–43"> しかしイエスは言った。<span className="woj">「あなたがたが食べ物を与えなさい。」</span><br />彼らは言った。「私たちにはパン五つと魚二匹しかありません。この人々全員のために食べ物を買いに行くのでなければ、足りません。」</span>
<span className="v" id="v14" data-v="14" data-xref="マルコ 8:6; コリント人への第一の手紙 14:40; マルコ 6:39–40"> 男だけで五千人ほどいたのである。<br />イエスは弟子たちに言った。<span className="woj">「五十人ほどずつ組にして座らせなさい。」</span></span>
<span className="v" id="v15" data-v="15"> 弟子たちはそのとおりにして、皆を座らせた。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイ 14:19; テモテへの手紙第一 4:4–5; マタイ 15:36"> イエスは五つのパンと二匹の魚を取り、天を見上げて祝福し、それらを裂いて弟子たちに渡し、群衆の前に置かせた。</span>
<span className="v" id="v17" data-v="17" data-xref="列王記第二 4:44; マタイ 15:37–38; ヨハネ 6:11–13"> 人々は皆、食べて満腹した。残ったパン切れを集めると、十二のかごにいっぱいになった。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="マタイ 16:13–16; ルカ 11:1; マタイ 26:36"> イエスが人々から離れて祈っておられ、弟子たちだけがそばにいた時、イエスは彼らに尋ねた。<span className="woj">「群衆は、私をだれだと言っているか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="マラキ書 4:5; ルカ 9:7–8; マタイ 14:2"> 彼らは答えた。「『バプテスマを授けるヨハネ』と言う人も、『エリヤ』と言う人も、『昔の預言者の一人が生き返った』と言う人もいます。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="マタイ 16:15–17; ヨハネ 4:29; ヨハネ 7:41"> イエスは彼らに言った。<span className="woj">「では、あなたがたは私をだれだと言うのか。」</span><br />ペテロが答えた。「神のキリストです。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="マタイ 16:20; マタイ 17:9; マルコ 8:30–31"> イエスは、このことをだれにも話さないよう彼らを厳しく戒めた。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 53:1–12; ルカ 24:7; ルカ 18:31–34"> そして言った。<span className="woj">「人の子は多くの苦しみを受け、長老、祭司長、律法学者たちに退けられ、殺され、三日目に生き返らなければならない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="マタイ 10:38–39; ルカ 14:26–27; ローマ人への手紙 8:13"> また皆に言った。<span className="woj">「だれでも私について来たいなら、自分を捨て、自分の十字架を負い、</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="TRとNUは「日々」を加えている。">c</a></sup><span className="woj">私に従いなさい。</span></span>
<span className="v" id="v24" data-v="24" data-xref="ルカ 17:33; ヨハネ 12:25; 使徒の働き 20:23–24"> <span className="woj">自分の命を救おうとする者はそれを失い、私のために命を失う者はそれを救うからである。</span></span>
<span className="v" id="v25" data-v="25" data-xref="マルコ 8:36; マタイ 16:26; 詩篇 49:6–8"> <span className="woj">全世界を手に入れても、自分自身を失い、または損なうなら、何の益があるだろう。</span></span>
<span className="v" id="v26" data-v="26" data-xref="マタイ 10:32–33; テモテへの第二の手紙 2:12; ルカ 12:8–9"> <span className="woj">私と私の言葉を恥じる者を、人の子も、自分と父と聖なる御使いたちの栄光を帯びて来る時に恥じる。</span></span>
<span className="v" id="v27" data-v="27" data-xref="マタイ 16:28; マルコ 9:1; ヨハネ 21:22–23"> <span className="woj">まことに、あなたがたに告げる。ここに立っている者の中には、神の王国を見るまでは決して死を味わわない者がいる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="マタイ 17:1–13; マタイ 26:37–39; マルコ 14:33–36"> これらの言葉から八日ほど後、イエスはペテロ、ヨハネ、ヤコブを連れ、祈るために山へ登った。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイ 17:2; マルコ 9:2–3; 出エジプト記 34:29–35"> 祈っておられるうちに、顔の様子が変わり、衣は白くまばゆく輝いた。</span>
<span className="v" id="v30" data-v="30" data-xref="ヘブル人への手紙 3:3–6; コリント人への第二の手紙 3:7–11; ルカ 1:17"> 見よ、二人の人がイエスと語り合っていた。それはモーセとエリヤで、</span>
<span className="v" id="v31" data-v="31" data-xref="ピリピ人への手紙 3:21; ペテロの手紙第一 1:11–12; ペテロの手紙第一 5:10"> 栄光のうちに現れ、イエスがエルサレムで成し遂げようとしている旅立ち<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="直訳すると「出エジプト」である。">d</a></sup>について話していた。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="ダニエル書 8:18; ヨハネ 1:14; ダニエル書 10:9"> ペテロと仲間たちは眠気に押しつぶされそうだったが、目がすっかり覚めると、イエスの栄光と、ともに立つ二人を見た。</span>
<span className="v" id="v33" data-v="33" data-xref="マルコ 9:5–6; マルコ 10:38; 詩篇 4:6–7"> 二人がイエスから離れようとした時、ペテロは言った。「先生、私たちがここにいるのは良いことです。幕屋を三つ建てましょう。一つはあなたに、一つはモーセに、一つはエリヤに。」自分が何を言っているのか分かっていなかった。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 40:34–38; マタイ 17:5–7; 士師記 13:22"> 彼がこう言っていると、雲が現れて彼らを覆った。彼らは雲の中に入る時、恐れた。</span>
<span className="v" id="v35" data-v="35" data-xref="ルカ 3:22; 使徒の働き 3:22–23; マタイ 3:17"> 雲の中から声がした。「これは私の愛する子。彼に聞きなさい。」</span>
<span className="v" id="v36" data-v="36" data-xref="マタイ 17:9; マルコ 9:9–10; マルコ 9:6"> 声がした時、そこにいたのはイエスだけだった。弟子たちは沈黙し、そのころは見たことを何一つ、だれにも話さなかった。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="マタイ 17:14–20; マルコ 9:14–29"> 翌日、彼らが山から下りると、大勢の群衆がイエスを迎えた。</span>
<span className="v" id="v38" data-v="38" data-xref="ゼカリヤ書 12:10; ヨハネ 4:47; ルカ 7:12"> 見よ、群衆の中から一人の男が叫んだ。「先生、お願いします。私の息子を見てください。私の一人息子<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="「一人息子」という表現はギリシャ語の「μονογενη」に由来し、「ただ一人の子」または「独り子」と訳されることもある。">e</a></sup>です。</span>
<span className="v" id="v39" data-v="39" data-xref="マルコ 9:20; ルカ 8:29; ルカ 4:35"> 見よ、霊が息子を捕らえると、突然叫び、泡を吹くほどけいれんさせ、ひどく傷つけて、なかなか離れません。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカ 9:1; 使徒の働き 19:13–16; ルカ 10:17–19"> あなたの弟子たちに追い出してくださるよう願いましたが、できませんでした。」</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="申命記 32:5; ローマ人への手紙 2:4; ヨハネ 20:27"> イエスは答えた。<span className="woj">「信仰のない曲がった世代よ、いつまで私はあなたがたとともにいて、耐えなければならないのか。あなたの息子をここへ連れて来なさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="マルコ 9:26–27; ルカ 7:15; ヨハネの黙示録 12:12"> 息子が近づいて来る途中にも、悪霊は彼を投げ倒し、激しくけいれんさせた。しかしイエスは汚れた霊を叱り、少年を癒やして父親に返した。</span>
<span className="v" id="v43" data-v="43" data-xref="ルカ 9:43–45; ルカ 5:26; マタイ 17:22"> 人々は皆、神の威光に驚いた。<br />しかし皆がイエスの行うすべてのことに驚いている間に、イエスは弟子たちに言った。</span>
<span className="v" id="v44" data-v="44" data-xref="ルカ 9:22; 使徒の働き 2:23; ルカ 2:19"> <span className="woj">「この言葉をしっかり耳に入れておきなさい。人の子は人々の手に引き渡される。」</span></span>
<span className="v" id="v45" data-v="45" data-xref="ルカ 18:34; ルカ 2:50; ヨハネ 12:16"> しかし弟子たちはこの言葉を理解できなかった。悟ることのないよう彼らには隠されていたのである。また、この言葉について尋ねることを恐れていた。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="マタイ 18:1–5; マルコ 9:33–37; マタイ 20:20–22"> 弟子たちの間で、自分たちのうちだれが一番偉いかという議論が起こった。</span>
<span className="v" id="v47" data-v="47" data-xref="詩篇 139:23; ヨハネ 16:30; ルカ 5:22"> イエスは彼らの心の思いを見抜き、一人の幼い子どもを連れて来て自分のそばに立たせ、</span>
<span className="v" id="v48" data-v="48" data-xref="ペテロの手紙第一 5:6; ルカ 14:11; マルコ 9:37"> 言った。<span className="woj">「私の名によってこの幼い子どもを受け入れる者は私を受け入れ、私を受け入れる者は私を遣わされた方を受け入れる。あなたがたすべての中で最も小さい者こそ、偉大だからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="マルコ 9:38–40; 民数記 11:27–29; マルコ 10:13–14"> ヨハネが答えた。「先生、あなたの名によって悪霊を追い出している人を見ましたが、私たちと行動をともにしていないので、やめさせました。」</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="マタイ 12:30; ルカ 11:23; コリント人への第一の手紙 12:3"> イエスは彼に言った。<span className="woj">「やめさせてはならない。われわれに反対しない者は、われわれの味方だからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="イザヤ書 50:5–9; マルコ 16:19; ルカ 13:22"> イエスが天に上げられる日が近づくと、エルサレムへ行こうと固く決意し、</span>
<span className="v" id="v52" data-v="52" data-xref="マタイ 10:5; ルカ 17:16; ルカ 10:1"> 自分に先立って使者たちを遣わした。彼らはイエスのために準備しようと、サマリア人の村に入った。</span>
<span className="v" id="v53" data-v="53" data-xref="ヨハネ 4:9; ヨハネ 4:40–42; ルカ 9:48"> しかし村人たちはイエスを受け入れなかった。イエスがエルサレムへ向かっていたからである。</span>
<span className="v" id="v54" data-v="54" data-xref="列王記第二 1:10–14; ヤコブの手紙 3:14–18; ヤコブの手紙 1:19–20"> 弟子のヤコブとヨハネはこれを見て言った。「主よ、エリヤがしたように、天から火を下して彼らを滅ぼすよう、私たちが命じましょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="ヨハネの黙示録 3:19; ペテロの手紙第一 3:9; エレミヤ書 17:9"> しかしイエスは振り向いて彼らを叱った。<span className="woj">「あなたがたは、自分がどのような霊に属しているか分かっていない。</span></span>
<span className="v" id="v56" data-v="56" data-xref="マタイ 20:28; ローマ人への手紙 12:21; ヨハネ 3:17"> <span className="woj">人の子は、人の命を滅ぼすためではなく、救うために来たのである。」</span><br />そして一行は別の村へ行った。</span>
<span className="v" id="v57" data-v="57" data-xref="マタイ 8:19–22; ヨハネ 13:37; ルカ 9:57–60"> 道を進んでいると、ある人がイエスに言った。「主よ、どこへ行かれても、私はあなたに従います。」</span>
</div>
<div className="bp">
<span className="v" id="v58" data-v="58" data-xref="マタイ 8:20; ルカ 14:26–33; ヤコブの手紙 2:5"> イエスは彼に言った。<span className="woj">「狐には穴があり、空の鳥には巣がある。しかし人の子には、頭を横たえる所もない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="マタイ 16:24; マタイ 6:33; 列王記第一 19:20"> 別の人には、<span className="woj">「私に従いなさい」</span>と言った。<br />しかしその人は言った。「主よ、まず父を葬りに行かせてください。」</span>
</div>
<div className="bp">
<span className="v" id="v60" data-v="60" data-xref="テモテへの第二の手紙 2:3–4; テモテへの手紙第一 5:6; ヨハネ 21:15–17"> イエスは彼に言った。<span className="woj">「死者には、自分たちの死者を葬らせなさい。あなたは行って、神の王国を告げ知らせなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61" data-xref="ルカ 14:26; ルカ 14:18–20; 列王記第一 19:20"> また別の人が言った。「主よ、あなたに従います。しかしまず、家にいる者たちに別れを告げさせてください。」</span>
</div>
<div className="bp">
<span className="v" id="v62" data-v="62" data-xref="ピリピ人への手紙 3:13; ヘブル人への手紙 10:38; ペテロの第二の手紙 2:20–22"> イエスは彼に言った。<span className="woj">「鋤に手をかけてから後ろを見る者は、神の王国にふさわしくない。」</span></span>
</div>

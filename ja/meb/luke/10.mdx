<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコ 6:7–13; ルカ 9:52; 民数記 11:24–26"> その後、主はほかに七十人を任命し、ご自分が行こうとしていたすべての町や場所へ、二人ずつ先に<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="直訳すると「顔の前に」である。">a</a></sup>遣わした。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 9:36–38; ヨハネ 4:35–38; コリント人への第一の手紙 3:6–9"> そして彼らに言った。<span className="woj">「収穫は確かに多いが、働き手が少ない。だから、収穫の主に、収穫のために働き手を送り出してくださるよう願いなさい。</span></span>
<span className="v" id="v3" data-v="3" data-xref="マタイ 10:16; 使徒の働き 20:29; エゼキエル書 2:3–6"> <span className="woj">行きなさい。見よ、私はあなたがたを、狼の中にいる子羊のように遣わす。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ルカ 22:35; 列王記第二 4:29; ルカ 10:4–12"> <span className="woj">財布も袋も履物も持って行ってはならない。道中でだれにもあいさつしてはならない。</span></span>
<span className="v" id="v5" data-v="5" data-xref="サムエル記第一 25:6; マタイ 10:12–13; イザヤ書 57:19"> <span className="woj">どの家に入っても、まず『この家に平和があるように』と言いなさい。</span></span>
<span className="v" id="v6" data-v="6" data-xref="テサロニケ人への第二の手紙 3:16; コリント人への第二の手紙 2:15–16; エペソ人への手紙 5:6"> <span className="woj">そこに平和の子がいれば、あなたがたの平和はその人の上にとどまる。いなければ、その平和はあなたがたに戻って来る。</span></span>
<span className="v" id="v7" data-v="7" data-xref="テモテへの手紙第一 5:17–18; マタイ 10:10–11; ガラテヤ人への手紙 6:6"> <span className="woj">同じ家にとどまり、出される物を食べたり飲んだりしなさい。働き手が報酬を受けるのは当然だからである。家から家へ移ってはならない。</span></span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 10:27; マタイ 10:40; ルカ 10:10"> <span className="woj">どの町に入っても、人々が受け入れてくれたら、出される物を食べなさい。</span></span>
<span className="v" id="v9" data-v="9" data-xref="マタイ 3:2; ヨハネ 3:5; ルカ 10:11"> <span className="woj">そこにいる病人を癒やし、『神の王国があなたがたに近づいた』と告げなさい。</span></span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 18:6; マタイ 10:14; 使徒の働き 13:51"> <span className="woj">しかし、どの町に入っても、人々が受け入れなければ、大通りに出て言いなさい。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ルカ 10:9; 使徒の働き 13:51; 使徒の働き 13:26"> <span className="woj">『足についたあなたがたの町のちりさえ、あなたがたに対して払い落とす。しかし、神の王国があなたがたに近づいたことは知っておきなさい。』</span></span>
<span className="v" id="v12" data-v="12" data-xref="マタイ 10:15; マタイ 11:24; 哀歌 4:6"> <span className="woj">あなたがたに告げる。その日には、その町よりソドムのほうが耐えやすい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 23:1–18; ヨエル書 3:4–8; エゼキエル書 26:1–26"> <span className="woj">「コラジンよ、災いだ。ベツサイダよ、災いだ。あなたがたの中で行われた力あるわざがツロやシドンで行われていたなら、彼らはとうの昔に粗布をまとい、灰の中に座って悔い改めていただろう。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネ 15:22–25; ローマ人への手紙 2:1; ルカ 12:47–48"> <span className="woj">しかし裁きの時には、あなたがたよりツロとシドンのほうが耐えやすい。</span></span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 14:13–15; マタイ 4:13; ルカ 13:28"> <span className="woj">カペナウムよ、天にまで上げられたおまえは、ハデスにまで引き下ろされる。</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ハデスは死者のいる地下の領域、または地獄である。">b</a></sup></span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネ 13:20; マタイ 10:40; テサロニケ人への手紙第一 4:8"> <span className="woj">あなたがたに聞く者は私に聞き、あなたがたを退ける者は私を退ける。私を退ける者は、私を遣わされた方を退ける。」</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 16:20; マルコ 16:17; ルカ 9:1"> 七十人は喜んで帰り、「主よ、あなたの名によって、悪霊たちさえ私たちに従います」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 12:7–9; イザヤ書 14:12; ヨハネの黙示録 9:1"> イエスは彼らに言った。<span className="woj">「サタンが稲妻のように天から落ちたのを、私は見ていた。</span></span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 91:13; マルコ 16:18; ローマ人への手紙 16:20"> <span className="woj">見よ、私はあなたがたに、蛇やさそりを踏みつけ、敵のあらゆる力を制する権威を与える。何ものも決してあなたがたを害することはない。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの黙示録 20:15; ヨハネの黙示録 20:12; ヘブル人への手紙 12:23"> <span className="woj">しかし、霊たちが従うことを喜ぶのではなく、あなたがたの名が天に記されていることを喜びなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="コリント人への第二の手紙 4:3; マタイ 13:11–16; マタイ 11:25–27"> その時、イエスは聖霊によって喜びにあふれて言った。<span className="woj">「天地の主である父よ、あなたに感謝します。これらのことを知恵ある者や賢い者には隠し、幼い子どもたちに現してくださいました。そうです、父よ。これはあなたの御前に喜ばしいことでした。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="マタイ 11:27; ヨハネ 1:18; ヨハネ 6:44–46"> 弟子たちのほうを向いて言った。<span className="woj">「すべてのものが父から私に渡されている。子がだれかを知る者は父のほかになく、父がだれかを知る者は子と、子が父を現そうと望む者のほかにいない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="マタイ 13:16–17"> それから弟子たちのほうを向き、彼らだけに言った。<span className="woj">「あなたがたが見ているものを見る目は幸いである。</span></span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネ 8:56; ヘブル人への手紙 11:13; ペテロの手紙第一 1:10–12"> <span className="woj">あなたがたに告げる。多くの預言者や王たちが、あなたがたの見ているものを見たいと望んだが、見られず、あなたがたの聞いていることを聞きたいと望んだが、聞けなかった。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="マタイ 22:34–39; ルカ 18:18; マタイ 19:16–19"> 見よ、ある律法の専門家が立ち上がり、イエスを試して言った。「先生、永遠の命を受け継ぐには、何をすればよいでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ローマ人への手紙 10:5; イザヤ書 8:20; ガラテヤ人への手紙 3:21–22"> イエスは彼に言った。<span className="woj">「律法には何と書かれているか。あなたはどう読んでいるか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="マルコ 12:30–31; マタイ 22:37–40; 申命記 6:5"> 彼は答えた。「『心を尽くし、魂を尽くし、力を尽くし、思いを尽くして、あなたの神である主を愛しなさい。 また、隣人を自分自身のように愛しなさい。』」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="エゼキエル書 20:11; レビ記 18:5; マタイ 19:17"> イエスは言った。<span className="woj">「正しく答えた。それを行いなさい。そうすれば生きる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ルカ 16:15; ローマ人への手紙 4:2; レビ記 19:34"> しかし彼は、自分を正当化しようとしてイエスに尋ねた。「私の隣人とはだれですか。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="詩篇 88:4; ルカ 18:31; 哀歌 2:12"> イエスは答えた。<span className="woj">「ある人がエルサレムからエリコへ下って行く途中、強盗たちに襲われた。彼らはその人の衣服をはぎ取り、殴りつけ、半死半生にして立ち去った。</span></span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネの手紙第一 3:16–18; 詩篇 69:20; エレミヤ書 5:31"> <span className="woj">たまたま、ある祭司がその道を下って来たが、その人を見ると反対側を通り過ぎた。</span></span>
<span className="v" id="v32" data-v="32" data-xref="箴言 27:10; 使徒の働き 18:17; 詩篇 109:25"> <span className="woj">同じようにレビ人も、その場所に来て彼を見ると、反対側を通り過ぎた。</span></span>
<span className="v" id="v33" data-v="33" data-xref="列王記第一 8:50; エレミヤ書 38:7–13; ルカ 7:13"> <span className="woj">しかし旅をしていたあるサマリア人は、彼の所まで来て、見ると深くあわれんだ。</span></span>
<span className="v" id="v34" data-v="34" data-xref="ローマ人への手紙 12:20; 詩篇 147:3; テサロニケ人への手紙第一 5:15"> <span className="woj">近寄って傷に油とぶどう酒を注ぎ、包帯を巻いた。そして自分の家畜に乗せ、宿屋へ連れて行って介抱した。</span></span>
<span className="v" id="v35" data-v="35" data-xref="箴言 19:17; ルカ 14:13; ローマ人への手紙 16:23"> <span className="woj">翌日、出発する時に二デナリを取り出して宿屋の主人に渡し、言った。『この人を介抱してください。これ以上費用がかかったら、帰りに払います。』</span></span>
<span className="v" id="v36" data-v="36" data-xref="ルカ 7:42; マタイ 21:28–31; マタイ 17:25"> <span className="woj">この三人のうち、強盗に襲われた人の隣人になったのは、だれだと思うか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="ヨハネの手紙第一 3:16–18; ミカ書 6:8; ペテロの手紙第一 2:21"> 彼は言った。「その人にあわれみを示した者です。」<br />イエスは言った。<span className="woj">「行って、あなたも同じようにしなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="ヨハネ 11:19–20; ヨハネ 11:1–5; ヨハネ 12:1–3"> 一行が道を進んでいると、イエスはある村に入った。するとマルタという女が、イエスを家に迎えた。</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 8:34; ルカ 8:35; ヨハネ 12:3"> 彼女にはマリアという姉妹がいて、イエスの足もとに座り、その言葉を聞いていた。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨハネ 6:27; ルカ 12:29; マタイ 14:15"> しかしマルタは、もてなしのことで忙しくしていた。彼女はイエスのそばに来て言った。「主よ、姉妹が私一人にもてなしをさせているのを、何とも思われないのですか。手伝うように言ってください。」</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="ピリピ人への手紙 4:6; ルカ 21:34; マタイ 6:25–34"> イエスは答えた。<span className="woj">「マルタ、マルタ。あなたは多くのことを心配し、気を乱している。</span></span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 27:4; 詩篇 16:5–6; ヨハネ 10:27–28"> <span className="woj">しかし必要なものは一つである。マリアは良いほうを選んだ。それが彼女から取り去られることはない。」</span></span>
</div>
</div>

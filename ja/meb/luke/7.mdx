<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 8:5–13; ルカ 7:1–10; マタイ 7:28–29"> イエスは民に聞かせていた話をすべて終えると、カペナウムに入った。</span>
<span className="v" id="v2" data-v="2" data-xref="列王記第二 5:2–3; 創世記 24:27; ヨハネ 4:46–47"> ある百人隊長に、重んじていたしもべがいた。そのしもべは病気で、死にかけていた。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイ 8:5; ヨハネ 4:47; ルカ 9:38"> 百人隊長はイエスのことを聞き、ユダヤ人の長老たちを遣わして、来てしもべを救ってくださるよう頼んだ。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 3:4; マタイ 10:11; ルカ 7:6–7"> 彼らはイエスのところに来て熱心に願った。「あの人は、あなたにそうしていただくにふさわしい人です。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代誌 第二 2:11–12; 歴代誌上 29:3–9; 列王記第一 5:1"> 私たちの国民を愛し、私たちのために会堂を建ててくれたからです。」</span>
<span className="v" id="v6" data-v="6" data-xref="マルコ 5:24; 創世記 32:10; ヤコブの手紙 4:6"> そこでイエスは彼らとともに行った。家からもう遠くない所まで来た時、百人隊長は友人たちを遣わして言わせた。「主よ、お手を煩わせないでください。私は、あなたを屋根の下にお迎えできるような者ではありません。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 107:20; 詩篇 33:9; ルカ 4:36"> それで、自分から伺うことさえ、ふさわしくないと思いました。ただお言葉をください。そうすれば、私のしもべは癒やされます。</span>
<span className="v" id="v8" data-v="8" data-xref="コロサイ人への手紙 3:22; 使徒の働き 23:17; 使徒の働き 22:25–26"> 私も権威の下に置かれた者で、私の下にも兵士たちがいます。この者に『行け』と言えば行き、別の者に『来い』と言えば来ます。しもべに『これをせよ』と言えば、そのとおりにします。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="マタイ 15:28; ローマ人への手紙 3:1–3; マタイ 8:10"> イエスはこれを聞いて彼に驚き、振り向いて、ついて来た群衆に言った。<span className="woj">「あなたがたに告げる。イスラエルの中でさえ、これほど大きな信仰を見たことがない。」</span></span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネ 4:50–53; マタイ 8:13; マタイ 15:28"> 遣わされた者たちが家に帰ると、病んでいたしもべは元気になっていた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 10:38"> それから間もなく、イエスはナインという町へ行った。大勢の弟子たちと多くの群衆も一緒に行った。</span>
<span className="v" id="v12" data-v="12" data-xref="ルカ 8:42; ルカ 8:52; 列王記第一 17:9"> 町の門に近づいた時、見よ、死んだ人が運び出されるところだった。その母の一人息子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「一人息子」という表現はギリシャ語の「μονογενη」に由来し、「ただ一人の子」または「独り子」と訳されることもある。">a</a></sup>で、母はやもめだった。町の人々も大勢、彼女に付き添っていた。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 103:13; イザヤ書 63:9; 詩篇 86:15"> 主は彼女を見ると、深くあわれんで言った。<span className="woj">「泣かなくてよい。」</span></span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネ 5:25; ヨハネ 11:43–44; 使徒の働き 9:40–41"> そして近寄って棺に触れると、担いでいた人たちは立ち止まった。イエスは言った。<span className="woj">「青年よ、あなたに言う。起きなさい。」</span></span>
<span className="v" id="v15" data-v="15" data-xref="列王記第二 13:21; 列王記第二 4:32–37; 列王記第一 17:23–24"> すると死人は起き上がり、話し始めた。イエスは彼を母親に渡した。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="マタイ 9:8; ルカ 7:39; ルカ 1:68"> 人々は皆、恐れに捕らえられ、神に栄光を帰して言った。「偉大な預言者がわれわれの間に現れた」「神がその民を訪れてくださった。」</span>
<span className="v" id="v17" data-v="17" data-xref="マタイ 4:24; マルコ 6:14; マタイ 9:26"> イエスについてのこの知らせは、ユダヤ全土と周辺一帯に広まった。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨハネ 3:26; マタイ 11:2–19"> ヨハネの弟子たちは、これらのことをすべて彼に報告した。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 9:6–7; ヨハネ 4:25; 創世記 22:18"> ヨハネは弟子のうち二人を呼び、「来るべき方はあなたですか。それとも、ほかの方を待つべきでしょうか」とイエスに尋ねさせた。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカ 7:19"> 二人はイエスのところに来て言った。「バプテスマを授けるヨハネから遣わされました。『来るべき方はあなたですか。それとも、ほかの方を待つべきでしょうか』と申しております。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="マルコ 3:10; 詩篇 90:7–9; ヘブル人への手紙 12:6"> ちょうどその時、イエスは多くの人を病気や苦痛や悪霊から癒やし、目の見えない多くの人に視力を与えた。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 35:5–6; イザヤ書 61:1–3; ルカ 4:18"> イエスは二人に答えた。<span className="woj">「行って、見聞きしたことをヨハネに伝えなさい。目の見えない人が見えるようになり、足の不自由な人が歩き、らい病人が清められ、耳の聞こえない人が聞こえるようになり、死人が生き返り、貧しい人々に福音が宣べ伝えられている。</span></span>
<span className="v" id="v23" data-v="23" data-xref="マタイ 11:6; ペテロの手紙第一 2:7–8; ローマ人への手紙 9:32–33"> <span className="woj">私につまずかない人は幸いである。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="エペソ人への手紙 4:14; ヨハネ 1:23; ルカ 1:80"> ヨハネの使者たちが去ると、イエスは群衆にヨハネのことを語り始めた。<span className="woj">「あなたがたは何を見るために荒野へ出て行ったのか。風に揺れる葦か。</span></span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 59:17; エステル記 8:15; エステル記 1:3"> <span className="woj">では、何を見るために出て行ったのか。柔らかな衣をまとった人か。見よ、華やかに装い、ぜいたくに暮らす人々なら王宮にいる。</span></span>
<span className="v" id="v26" data-v="26" data-xref="ルカ 1:76; ヨハネ 5:35; ルカ 20:6"> <span className="woj">では、何を見るために出て行ったのか。預言者か。そのとおり。あなたがたに言う。預言者をはるかに超える者である。</span></span>
<span className="v" id="v27" data-v="27" data-xref="マラキ書 3:1; ルカ 1:76; マルコ 1:2"> <span className="woj">この人について、こう書かれている。</span><br /><span className="pl pl-1 woj">『見よ、私はあなたの前に使者を遣わす。</span><br /><span className="pl pl-2 woj">彼はあなたの前に道を備える。』</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="マタイ 13:16–17; マタイ 11:11; コロサイ人への手紙 1:25–27"> <span className="woj">「あなたがたに告げる。女から生まれた者の中で、バプテスマを授けるヨハネより偉大な預言者はいない。しかし、神の王国で最も小さい者も、彼より偉大である。」</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ルカ 3:12; ルカ 7:35; 使徒の働き 18:25"> 民は皆、徴税人たちも、これを聞いて神が正しい方であることを認めた。彼らはヨハネのバプテスマを受けていたからである。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカ 13:34; コリント人への第二の手紙 6:1; マタイ 22:35"> しかし、パリサイ人たちと律法の専門家たちは、ヨハネからバプテスマを受けず、自分たちに対する神の計画を退けた。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="マタイ 11:16–19; 哀歌 2:13; マルコ 4:30"> <sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TRは「しかし主は言われた」を加えている。">b</a></sup><span className="woj">「では、この世代の人々を何にたとえよう。彼らは何に似ているだろう。</span></span>
<span className="v" id="v32" data-v="32" data-xref="マタイ 11:16–19; エレミヤ書 5:3–5; 箴言 17:16"> <span className="woj">広場に座り、互いに呼びかける子どもたちに似ている。『笛を吹いたのに、あなたがたは踊らなかった。弔いの歌を歌ったのに、泣かなかった。』</span></span>
<span className="v" id="v33" data-v="33" data-xref="ルカ 1:15; マルコ 1:6; ヨハネ 8:52"> <span className="woj">バプテスマを授けるヨハネが来て、パンを食べず、ぶどう酒も飲まないと、あなたがたは『悪霊につかれている』と言う。</span></span>
<span className="v" id="v34" data-v="34" data-xref="ルカ 15:2; ルカ 7:36; ヨハネ 12:2"> <span className="woj">人の子が来て食べたり飲んだりすると、『見よ、大食いで大酒飲み、徴税人や罪人たちの友だ』と言う。</span></span>
<span className="v" id="v35" data-v="35" data-xref="箴言 8:32–36; マタイ 11:19; ホセア書 14:9"> <span className="woj">しかし、知恵が正しいことは、そのすべての子どもたちによって証明される。」</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="マルコ 14:3–9; マタイ 26:5–6; ルカ 14:1"> あるパリサイ人が、イエスに一緒に食事をしてほしいと招いた。イエスはその家に入り、食卓についた。</span>
<span className="v" id="v37" data-v="37" data-xref="マルコ 14:3–9; マタイ 26:6–13; マタイ 21:31"> 見よ、その町に罪深い女がいた。彼女は、イエスがパリサイ人の家で食卓についていると知り、香油の入った雪花石膏の壺を持って来た。</span>
<span className="v" id="v38" data-v="38" data-xref="詩篇 126:5–6; 詩篇 51:17; 創世記 18:4"> 泣きながらイエスの後ろ、足もとに立ち、涙でその足をぬらし始めた。そして自分の髪で拭い、その足に口づけして香油を塗った。</span>
<span className="v" id="v39" data-v="39" data-xref="ルカ 7:16; ルカ 15:2; マルコ 7:21"> イエスを招いたパリサイ人はこれを見て、心の中で言った。「この人が預言者なら、自分に触れている女がだれで、どんな女か分かるはずだ。罪人なのだから。」</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="ヨハネ 16:19; ルカ 5:31; エゼキエル書 33:31"> イエスは彼に答えた。<span className="woj">「シモン、あなたに言いたいことがある。」</span><br />彼は言った。「先生、お話しください。」</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="ルカ 7:47; ローマ人への手紙 5:20; マタイ 18:28"> <span className="woj">「ある金貸しに二人の債務者がいた。一人は五百デナリ、もう一人は五十デナリを借りていた。</span></span>
<span className="v" id="v42" data-v="42" data-xref="ダニエル書 9:18–19; コロサイ人への手紙 3:13; ローマ人への手紙 3:24"> <span className="woj">二人とも返すことができなかったので、金貸しは二人の負債を免除した。では、二人のうち、どちらが彼をより愛するだろうか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="詩篇 116:16–18; テモテへの手紙第一 1:13–16; ルカ 7:47"> シモンは答えた。「より多く免除してもらったほうだと思います。」<br />イエスは言った。<span className="woj">「あなたの判断は正しい。」</span></span>
<span className="v" id="v44" data-v="44" data-xref="テモテへの手紙第一 5:10; 士師記 19:21; 創世記 18:4"> それから女のほうを向き、シモンに言った。<span className="woj">「この女を見ているか。私があなたの家に入った時、あなたは足を洗う水をくれなかった。しかし彼女は涙で私の足をぬらし、自分の髪で拭ってくれた。</span></span>
<span className="v" id="v45" data-v="45" data-xref="サムエル記第二 15:5; サムエル記第二 19:39; ローマ人への手紙 16:16"> <span className="woj">あなたは私に口づけしなかった。しかし彼女は、私が入って来てから私の足に口づけするのをやめなかった。</span></span>
<span className="v" id="v46" data-v="46" data-xref="詩篇 23:5; 伝道者の書 9:8; マタイ 6:17"> <span className="woj">あなたは私の頭に油を塗らなかった。しかし彼女は私の足に香油を塗ってくれた。</span></span>
<span className="v" id="v47" data-v="47" data-xref="ヨハネの手紙第一 4:19; ヨハネの手紙第一 3:18; イザヤ書 1:18"> <span className="woj">だから、あなたに言う。彼女の多くの罪は赦されている。彼女が多く愛したからである。しかし、赦されることの少ない者は、愛することも少ない。」</span></span>
<span className="v" id="v48" data-v="48" data-xref="マタイ 9:2; マルコ 2:5; ルカ 5:20"> そして彼女に言った。<span className="woj">「あなたの罪は赦された。」</span></span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="ルカ 5:20–21; マタイ 9:3; マルコ 2:7"> 一緒に食卓についていた人々は、心の中で言い始めた。「罪さえ赦すこの人は何者だろう。」</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="マルコ 5:34; ルカ 8:48; ルカ 18:42"> イエスは女に言った。<span className="woj">「あなたの信仰があなたを救った。安心して行きなさい。」</span></span>
</div>

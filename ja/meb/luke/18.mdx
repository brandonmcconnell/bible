<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 4:2; ローマ人への手紙 12:12; テサロニケ人への手紙第一 5:17"> イエスは、いつも祈り、あきらめてはならないことを教えるために、彼らにたとえを語った。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 29:7; 詩篇 8:1–4; ルカ 18:4"> <span className="woj">「ある町に、神を恐れず、人を人とも思わない裁判官がいた。</span></span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 1:17; エレミヤ書 5:28; 申命記 27:19"> <span className="woj">その町に一人のやもめがいて、たびたび彼のもとへ来ては、『私を訴える相手から守って、正しい裁きをしてください』と言っていた。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 4:12–13; ルカ 16:3; ルカ 12:17"> <span className="woj">裁判官はしばらく応じようとしなかった。しかし後になって、心の中で言った。『私は神を恐れず、人を人とも思わないが、</span></span>
<span className="v" id="v5" data-v="5" data-xref="ルカ 11:8; ルカ 18:39; 士師記 16:16"> <span className="woj">このやもめが私を煩わせるので、正しい裁きをしてやろう。そうしなければ、絶えずやって来て私を疲れ果てさせるだろう。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ルカ 7:13"> 主は言った。<span className="woj">「この不正な裁判官の言うことを聞きなさい。</span></span>
<span className="v" id="v7" data-v="7" data-xref="ヘブル人への手紙 10:35–37; ペテロの第二の手紙 3:9; ルカ 11:13"> <span className="woj">まして神は、昼も夜もご自分に叫び求める選ばれた者たちのために正しい裁きを行わず、いつまでも待たせておかれるだろうか。</span></span>
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 10:23–26; ペテロの第二の手紙 3:8–9; マタイ 24:9–13"> <span className="woj">あなたがたに言う。神は彼らのために速やかに正しい裁きを行われる。しかし、人の子が来る時、地上に信仰を見いだすだろうか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ルカ 16:15; 箴言 30:12; イザヤ書 65:5"> また、自分は義であると確信し、ほかのすべての人を見下している者たちに、このたとえを語った。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイ 21:31–32; 列王記第一 8:30; 列王記第二 20:5"> <span className="woj">「二人の人が祈るために神殿へ上った。一人はパリサイ人で、もう一人は徴税人であった。</span></span>
<span className="v" id="v11" data-v="11" data-xref="マタイ 6:5; イザヤ書 65:5; ヨハネの黙示録 3:17"> <span className="woj">パリサイ人は立って、自分だけでこのように祈った。『神よ、私はほかの人たちのように、ゆすり取る者、不正な者、姦淫する者ではなく、この徴税人のようでもないことを感謝します。</span></span>
<span className="v" id="v12" data-v="12" data-xref="ルカ 11:42; マタイ 23:23–24; マタイ 9:14"> <span className="woj">私は週に二度断食し、得るものすべての十分の一をささげています。』</span></span>
<span className="v" id="v13" data-v="13" data-xref="エズラ記 9:6; ヨハネの手紙第一 1:8–10; テモテへの手紙第一 1:15"> <span className="woj">しかし徴税人は遠く離れて立ち、目を天に上げようともせず、胸をたたいて言った。『神よ、罪人の私をあわれんでください。』</span></span>
<span className="v" id="v14" data-v="14" data-xref="ルカ 14:11; ルカ 16:15; ヤコブの手紙 4:10"> <span className="woj">あなたがたに言う。義とされて家に帰ったのは、あの人ではなく、この人である。自分を高くする者は皆低くされ、自分を低くする者は高くされるからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="マルコ 10:13–16; マタイ 19:13–15; サムエル記第一 1:24"> 人々は、イエスに触れていただこうとして、乳飲み子たちまで連れて来た。しかし弟子たちはそれを見て、人々を叱った。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイ 18:3–4; コリント人への第一の手紙 14:20; コリント人への第一の手紙 7:14"> けれどもイエスは彼らを呼び寄せて言った。<span className="woj">「幼い子どもたちを私のもとに来させなさい。妨げてはならない。神の王国はこのような者たちのものだからである。</span></span>
<span className="v" id="v17" data-v="17" data-xref="マタイ 18:3; マルコ 10:15; 詩篇 131:1–2"> <span className="woj">まことに、あなたがたに告げる。幼い子どものように神の王国を受け入れない者は、決してそこに入ることができない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="マルコ 10:17–31; 使徒の働き 16:30; マタイ 19:16–30"> ある指導者がイエスに尋ねた。「良い先生、永遠の命を受け継ぐためには、何をすればよいでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨブ記 15:14–16; ヤコブの手紙 1:17; ヘブル人への手紙 7:26"> イエスは彼に言った。<span className="woj">「なぜ私を良いと言うのか。神おひとりのほかに、良い者はいない。</span></span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 20:12–17; 申命記 5:16–21; ローマ人への手紙 13:9"> <span className="woj">戒めは知っているはずだ。『姦淫してはならない』『殺してはならない』『盗んではならない』『偽りの証言をしてはならない』『父と母を敬いなさい。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ピリピ人への手紙 3:6; ローマ人への手紙 10:2–3; マルコ 10:20–21"> その人は言った。「そのすべてを若い時から守ってきました。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ルカ 12:33; テモテへの手紙第一 6:18–19; マタイ 19:21"> イエスはこれを聞いて彼に言った。<span className="woj">「あなたには、まだ一つ欠けている。持っているものをすべて売り、貧しい人たちに分け与えなさい。そうすれば、天に宝を持つことになる。それから来て、私について来なさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 33:31; ヨハネの手紙第一 2:15; ヨブ記 31:24–25"> しかし、その人はこれを聞くと非常に悲しんだ。たいへんな金持ちだったからである。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="箴言 30:9; ヤコブの手紙 2:5–7; マルコ 10:23–27"> イエスは彼が非常に悲しむのを見て言った。<span className="woj">「富を持つ者が神の王国に入るのは、なんと難しいことか。</span></span>
<span className="v" id="v25" data-v="25" data-xref="マタイ 23:24"> <span className="woj">金持ちが神の王国に入るより、らくだが針の穴を通るほうが易しい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ルカ 13:23"> これを聞いた人々は言った。「それでは、だれが救われることができるでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 32:17; マタイ 19:26; ルカ 1:37"> イエスは言った。<span className="woj">「人には不可能なことも、神には可能である。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="マルコ 10:28; ピリピ人への手紙 3:7; マタイ 19:27"> ペテロは言った。「見てください。私たちはすべてを捨てて、あなたについて来ました。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="マルコ 10:29–31; マタイ 10:37–39; ルカ 14:26–28"> イエスは彼らに言った。<span className="woj">「まことに、あなたがたに告げる。神の王国のために、家、妻、兄弟、両親、子どもを離れた者で、</span></span>
<span className="v" id="v30" data-v="30" data-xref="ヘブル人への手紙 13:5–6; ヨブ記 42:10; ヨハネの黙示録 2:17"> <span className="woj">この時代に何倍も多くを受け、来るべき世で永遠の命を受けない者はいない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="マタイ 20:17–19; イザヤ書 53:1–12; 詩篇 22:1–31"> イエスは十二人をそばに連れて行き、彼らに言った。<span className="woj">「見よ、私たちはエルサレムへ上って行く。人の子について預言者たちを通して書かれたことは、すべて成就する。</span></span>
<span className="v" id="v32" data-v="32" data-xref="ルカ 23:11; イザヤ書 50:6; イザヤ書 53:3"> <span className="woj">人の子は異邦人に引き渡され、あざけられ、辱められ、つばをかけられる。</span></span>
<span className="v" id="v33" data-v="33" data-xref="コリント人への第一の手紙 15:3–4; ルカ 24:7; マタイ 27:63"> <span className="woj">彼らは人の子をむち打ち、殺す。そして人の子は三日目によみがえる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ルカ 9:45; マルコ 9:32; ルカ 24:25"> 弟子たちには、これらのことが何一つ分からなかった。この言葉は彼らから隠されていて、語られたことを理解できなかったのである。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="マタイ 20:29–34; マルコ 10:46–52; ルカ 16:20–21"> イエスがエリコに近づいた時、ある目の見えない人が道端に座って物乞いをしていた。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイ 21:10–11; ルカ 15:26"> 群衆が通って行く音を聞き、これは何事かと尋ねた。</span>
<span className="v" id="v37" data-v="37" data-xref="マタイ 2:23; ヨハネ 19:19; ヨハネ 12:35–36"> 人々は、ナザレのイエスがお通りになるのだと知らせた。</span>
<span className="v" id="v38" data-v="38" data-xref="マタイ 9:27; ルカ 18:39; マタイ 15:22"> 彼は叫んだ。「ダビデの子イエスよ、私をあわれんでください。」</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 32:26–28; 詩篇 141:1; ルカ 18:15"> 先を行く人々は、黙るようにと彼を叱った。しかし彼はますます激しく叫んだ。「ダビデの子よ、私をあわれんでください。」</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="マタイ 20:31–34; マルコ 10:48–52"> イエスは立ち止まり、その人を連れて来るよう命じた。彼が近くに来ると、イエスは尋ねた。</span>
<span className="v" id="v41" data-v="41" data-xref="列王記第一 3:5–15; マタイ 20:21–22; ピリピ人への手紙 4:6"> <span className="woj">「私に何をしてほしいのか。」</span><br />彼は言った。「主よ、再び見えるようにしてください。」</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="マタイ 8:3; ルカ 8:48; ルカ 17:19"> イエスは彼に言った。<span className="woj">「見えるようになりなさい。あなたの信仰があなたを癒やした。」</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="詩篇 146:8; テサロニケ人への第二の手紙 1:10–12; イザヤ書 43:21"> すると、たちまち見えるようになり、神に栄光を帰しながらイエスについて行った。民は皆、これを見て神を賛美した。</span>
</div>

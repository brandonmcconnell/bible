<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 21:23–27; ルカ 19:47–48; 使徒の働き 6:12"> ある日、イエスが神殿で民を教え、福音を宣べ伝えていると、祭司たち<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TRは「祭司長たち」としている。">a</a></sup>と律法学者たちが長老たちとともに近寄って来た。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 2:14; マルコ 11:28–33; ヨハネ 2:18"> 彼らはイエスに尋ねた。「何の権威によって、これらのことをしているのか、私たちに言いなさい。また、この権威をあなたに与えたのはだれか。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="マタイ 15:2–3; ルカ 22:68; コロサイ人への手紙 4:6"> イエスは彼らに答えた。<span className="woj">「私もあなたがたに一つ尋ねよう。答えなさい。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ルカ 15:18; マタイ 11:7–19; マタイ 17:11–12"> <span className="woj">ヨハネのバプテスマは天からのものだったのか、それとも人からのものだったのか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ヨハネ 1:34; ヨハネ 1:15–18; ヨハネ 1:30"> 彼らは互いに論じ合って言った。「もし『天から』と言えば、『では、なぜ彼を信じなかったのか』と言うだろう。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイ 21:26; マタイ 11:9; ヨハネ 10:41"> しかし『人から』と言えば、民は皆、われわれを石で打ち殺すだろう。民はヨハネを預言者だと確信しているからだ。」</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 29:14; ペテロの第二の手紙 3:3; イザヤ書 41:28"> そこで彼らは、どこからのものか分からないと答えた。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="箴言 26:4–5; マタイ 21:27; マルコ 11:33"> イエスは彼らに言った。<span className="woj">「私も、何の権威によってこれらのことをするのか、あなたがたには言わない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="マタイ 21:33–46; マルコ 12:1–12; イザヤ書 5:1–7"> イエスは民にこのたとえを語り始めた。<span className="woj">「ある</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NU（角括弧内）とTRは「ある」を加えている。">b</a></sup><span className="woj">人がぶどう園を造り、農夫たちに貸して、長い間ほかの国へ出かけた。</span></span>
<span className="v" id="v10" data-v="10" data-xref="歴代誌 第二 36:15–16; ネヘミヤ記 9:26; マタイ 21:34–36"> <span className="woj">収穫の季節になると、ぶどう園の実の分け前を受け取るために、しもべを農夫たちの所へ遣わした。しかし農夫たちは彼を殴り、何も持たせずに帰らせた。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ホセア書 10:1; ヘブル人への手紙 11:36–37; テサロニケ人への手紙第一 2:2"> <span className="woj">主人はさらに別のしもべを遣わしたが、農夫たちはそのしもべも殴って辱め、何も持たせずに帰らせた。</span></span>
<span className="v" id="v12" data-v="12"> <span className="woj">さらに三人目を遣わしたが、彼らはこのしもべにも傷を負わせ、外へ投げ出した。</span></span>
<span className="v" id="v13" data-v="13" data-xref="マタイ 3:17; ヨハネ 3:16–17; エレミヤ書 36:7"> <span className="woj">ぶどう園の主人は言った。『どうしようか。愛する息子を遣わそう。彼を見れば、敬ってくれるかもしれない。』</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 8:17; ヘブル人への手紙 1:2; 使徒の働き 2:23"> <span className="woj">「ところが農夫たちは息子を見ると、互いに相談して言った。『これは跡取りだ。さあ、殺してしまおう。そうすれば、相続財産はわれわれのものになる。』</span></span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 13:12; マルコ 12:6–9; マタイ 21:37–40"> <span className="woj">そして息子をぶどう園の外に投げ出して殺した。では、ぶどう園の主人は彼らをどうするだろうか。</span></span>
<span className="v" id="v16" data-v="16" data-xref="ルカ 19:27; 使徒の働き 13:46; マタイ 21:41"> <span className="woj">主人は来て、この農夫たちを滅ぼし、ぶどう園をほかの人々に与える。」</span><br />人々はこれを聞いて言った。「決してそのようなことがありませんように。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="詩篇 118:22; イザヤ書 28:16; 使徒の働き 4:11"> しかしイエスは彼らを見つめて言った。<span className="woj">「それでは、こう書かれているのはどういう意味か。</span><br /><span className="pl pl-1 woj">『家を建てる者たちが退けた石、</span><br /><span className="pl pl-2 woj">それが主要な隅石となった。』</span></span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 8:14–15; ゼカリヤ書 12:3; ダニエル書 2:44–45"> <span className="pl pl-1 woj">この石の上に落ちる者は皆、粉々に砕かれ、</span><br /><span className="pl pl-2 woj">この石がその上に落ちる者は、押しつぶされて粉になる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ルカ 19:47–48; ルカ 20:14; マタイ 21:45–46"> 祭司長たちと律法学者たちは、その時すぐにイエスを捕らえようとしたが、民を恐れた。イエスが自分たちに対してこのたとえを語ったと分かっていたからである。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカ 11:54; マタイ 22:15–22; マタイ 27:2"> 彼らはイエスを見張り、正しい人のふりをする回し者たちを送り込んだ。イエスの言葉じりを捕らえ、総督の支配権と権威に引き渡そうとしたのである。</span>
<span className="v" id="v21" data-v="21" data-xref="テサロニケ人への手紙第一 2:4–5; マタイ 26:49–50; マタイ 22:16"> 彼らはイエスに尋ねた。「先生、私たちは、あなたが正しいことを語り、教えておられ、人を分け隔てせず、真理に基づいて神の道を教えておられることを知っています。</span>
<span className="v" id="v22" data-v="22" data-xref="ネヘミヤ記 9:37; マルコ 12:14–17; 使徒の働き 5:37"> われわれがカエサルに税を納めることは、律法にかなっているでしょうか、いないでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="マタイ 22:18; コリント人への第一の手紙 3:19; ルカ 5:22"> しかしイエスは彼らの悪巧みを見抜いて言った。<span className="woj">「なぜ私を試すのか。</span></span>
<span className="v" id="v24" data-v="24" data-xref="マタイ 18:28; 使徒の働き 11:28; 使徒の働き 26:32"> <span className="woj">一デナリ硬貨を見せなさい。そこにある肖像と銘はだれのものか。」</span><br />彼らは答えた。「カエサルのものです。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 13:6–7; マルコ 12:17; ペテロの手紙第一 2:13–17"> イエスは彼らに言った。<span className="woj">「それなら、カエサルのものはカエサルに、神のものは神に返しなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ルカ 20:20; 箴言 26:4–5; テトス 1:10"> 彼らは民の前で、イエスの言葉じりを捕らえることができなかった。その答えに驚き、黙り込んだ。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒の働き 4:1–2; コリント人への第一の手紙 15:12; マルコ 12:18–27"> 復活はないと否定するサドカイ人の何人かがイエスのもとに来た。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 25:5–10; 創世記 38:8; 創世記 38:11"> 彼らは尋ねた。「先生、モーセは私たちのためにこう書きました。ある人の兄弟が妻を残して死に、子がいない場合、その人が兄弟の妻を迎え、兄弟のために子孫を残さなければならない、と。</span>
<span className="v" id="v29" data-v="29" data-xref="レビ記 20:20; エレミヤ書 22:30"> ところで、七人の兄弟がいました。長男が妻を迎えましたが、子を残さずに死にました。</span>
<span className="v" id="v30" data-v="30"> 次男が彼女を妻に迎えましたが、子を残さずに死に、</span>
<span className="v" id="v31" data-v="31"> 三男も彼女を迎えました。同じように、七人とも子を残さずに死にました。</span>
<span className="v" id="v32" data-v="32" data-xref="伝道者の書 1:4; 伝道者の書 9:5; ヘブル人への手紙 9:27"> 最後に、その女も死にました。</span>
<span className="v" id="v33" data-v="33" data-xref="マタイ 22:24–28; マルコ 12:19–23"> では復活の時、彼女はだれの妻になるのでしょうか。七人とも彼女を妻にしたのです。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ルカ 16:8; ルカ 17:27; ヘブル人への手紙 13:4"> イエスは彼らに言った。<span className="woj">「この時代の子らは、めとったり嫁いだりする。</span></span>
<span className="v" id="v35" data-v="35" data-xref="テサロニケ人への第二の手紙 1:5; ヨハネ 5:29; ダニエル書 12:2–3"> <span className="woj">しかし、かの時代と死人の中からの復活にあずかるのにふさわしいとされる者たちは、めとることも嫁ぐこともない。</span></span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネの黙示録 21:4; ピリピ人への手紙 3:21; マタイ 22:30"> <span className="woj">彼らはもはや死ぬことができない。御使いたちのようであり、復活の子として神の子だからである。</span></span>
<span className="v" id="v37" data-v="37" data-xref="出エジプト記 3:2–6; マルコ 12:26–27; 使徒の働き 7:30–32"> <span className="woj">死人がよみがえることは、モーセも柴の箇所で示している。彼は主を『アブラハムの神、イサクの神、ヤコブの神』と呼んでいる。</span></span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネ 11:25–26; コロサイ人への手紙 3:3–4; ローマ人への手紙 6:10–11"> <span className="woj">神は死んだ者の神ではなく、生きている者の神である。神にとっては、すべての者が生きているからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒の働き 23:9; マルコ 12:28–34; マタイ 22:34–40"> 律法学者の何人かが答えた。「先生、立派なお答えです。」</span>
<span className="v" id="v40" data-v="40" data-xref="マタイ 22:46; マルコ 12:34; 箴言 26:5"> 彼らはそれ以上、何も尋ねようとはしなかった。</span>
</div>
<div className="bp poetry">
<span className="v" id="v41" data-v="41" data-xref="マルコ 12:35–37; マタイ 1:1; マタイ 22:41–45"> イエスは彼らに言った。<span className="woj">「どうして人々は、キリストをダビデの子だと言うのか。</span></span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 110:1; 使徒の働き 2:34–35; ヘブル人への手紙 1:13"> <span className="woj">ダビデ自身が詩篇の書でこう言っている。</span><br /><span className="pl pl-1 woj">『主は私の主に言われた。</span><br /><span className="pl pl-2 woj">「私の右に座っていなさい。</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="ルカ 19:27; 詩篇 110:1; ヨハネの黙示録 19:14–21"> <span className="pl pl-2 woj">私があなたの敵を、あなたの足台とするまで。」』</span></span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="ヨハネの黙示録 22:16; ルカ 1:31–35; マタイ 1:23"> <span className="woj">ダビデがキリストを主と呼んでいる。それなら、どうしてキリストはダビデの子なのか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="マタイ 15:10; マルコ 12:38–39; マルコ 8:34"> 民が皆聞いているところで、イエスは弟子たちに言った。</span>
<span className="v" id="v46" data-v="46" data-xref="ルカ 11:43; マルコ 12:38–39; ルカ 14:7"> <span className="woj">「律法学者たちに気をつけなさい。彼らは長い衣を着て歩き回ることを好み、市場であいさつされること、会堂の上席、宴会の上座を愛している。</span></span>
<span className="v" id="v47" data-v="47" data-xref="マルコ 12:40; ヤコブの手紙 3:1; テトス 1:16"> <span className="woj">また、やもめたちの家を食い尽くし、見せかけに長い祈りをする。このような者たちは、いっそう厳しい裁きを受ける。」</span></span>
</div>

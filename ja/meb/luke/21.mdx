<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコ 12:41–44; ヨハネ 8:20; マタイ 27:6"> イエスは目を上げ、金持ちたちが献金箱に献金を入れているのを見た。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコ 12:42"> また、ある貧しいやもめが小さな青銅貨二枚を投げ入れるのを見て、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="直訳すると「二レプタ」。二レプタは農業労働者の一日分の賃金のおよそ一パーセントに相当した。">a</a></sup></span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 8:12; 使徒の働き 10:34; コリント人への第二の手紙 8:2–3"> 言った。<span className="woj">「まことにあなたがたに言う。この貧しいやもめは、だれよりも多く入れた。</span></span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 2:44–45; ルカ 15:12; 使徒の働き 4:34"> <span className="woj">あの人たちは皆、あり余る中から神への献金を入れたが、この女は乏しい中から、暮らしのために持っていたものをすべて入れたからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ヨハネ 2:20; マタイ 24:1–51; マルコ 13:1–37"> ある人たちが、神殿は美しい石や奉納物で飾られていると話していると、イエスは言った。</span>
<span className="v" id="v6" data-v="6" data-xref="マタイ 24:2; マルコ 13:2; 哀歌 5:18"> <span className="woj">「あなたがたが見ているこれらのものについては、一つの石もほかの石の上に残らず、すべて崩される日が来る。」</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 1:6–7; マルコ 13:14; マルコ 13:3–4"> 彼らはイエスに尋ねた。「先生、それでは、これらのことはいつ起こるのでしょうか。また、これらのことが起ころうとする時には、どんなしるしがあるのでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨハネの手紙第一 4:1; マルコ 13:5–6; エペソ人への手紙 5:6"> イエスは言った。<span className="woj">「惑わされないように気をつけなさい。多くの者が私の名によって来て、『私がそれだ</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または「私はある」">b</a></sup><span className="woj">』『時は近づいた』と言うからである。彼らについて行ってはならない。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ルカ 21:28; マタイ 24:6–8; マルコ 13:7–8"> <span className="woj">戦争や騒乱のことを聞いても、おびえてはならない。これらのことがまず起こらなければならないが、終わりはすぐには来ないからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 2:19–20; マルコ 13:8; 歴代誌 第二 15:5–6"> それから彼らに言った。<span className="woj">「民族は民族に、王国は王国に敵対して立ち上がる。</span></span>
<span className="v" id="v11" data-v="11" data-xref="マタイ 24:29–30; ルカ 21:25–27"> <span className="woj">あちらこちらで大地震、飢饉、疫病が起こる。また、恐ろしい出来事と、天からの大きなしるしがある。</span></span>
<span className="v" id="v12" data-v="12" data-xref="ペテロの手紙第一 4:12–14; 使徒の働き 5:40; 使徒の働き 22:30"> <span className="woj">しかし、これらすべてに先立って、人々はあなたがたに手をかけて迫害し、会堂や牢獄に引き渡し、私の名のために王や総督の前に連れて行く。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ピリピ人への手紙 1:12; ピリピ人への手紙 1:28; テサロニケ人への第二の手紙 1:5"> <span className="woj">それはあなたがたにとって、あかしをする機会となる。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ルカ 12:11–12; マルコ 13:11; マタイ 10:19–20"> <span className="woj">だから、弁明の仕方を前もって考えないよう、心に決めておきなさい。</span></span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 1:9; エペソ人への手紙 6:19; ルカ 12:12"> <span className="woj">あなたがたに言葉と知恵を与えるのは私であり、敵対する者はだれも、それに抵抗することも反論することもできないからである。</span></span>
<span className="v" id="v16" data-v="16" data-xref="ルカ 12:53; ヨハネの黙示録 6:9; ミカ書 7:5–6"> <span className="woj">あなたがたは、両親、兄弟、親族、友人にさえ引き渡される。あなたがたの中には殺される者もいる。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネ 15:19; ルカ 6:22; ヨハネ 15:21"> <span className="woj">あなたがたは私の名のために、すべての人から憎まれる。</span></span>
<span className="v" id="v18" data-v="18" data-xref="マタイ 10:30; サムエル記第一 14:45; ルカ 12:7"> <span className="woj">しかし、あなたがたの髪の毛一本さえ失われない。</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヘブル人への手紙 10:36; マタイ 10:22; ヤコブの手紙 1:3"> <span className="woj">「忍耐によって、自分の命を勝ち取りなさい。</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ルカ 19:43; ダニエル書 9:27; マルコ 13:14"> <span className="woj">「エルサレムが軍隊に囲まれるのを見たなら、その荒廃が近づいたことを知りなさい。</span></span>
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 6:1; 創世記 19:17; ルカ 17:31–33"> <span className="woj">その時、ユダヤにいる者は山へ逃げなさい。都の中にいる者はそこから出なさい。地方にいる者は都に入ってはならない。</span></span>
<span className="v" id="v22" data-v="22" data-xref="ホセア書 9:7; イザヤ書 65:12–16; イザヤ書 63:4"> <span className="woj">書かれていることがすべて成就する、報復の日々だからである。</span></span>
<span className="v" id="v23" data-v="23" data-xref="マルコ 13:17; マタイ 24:19; ルカ 23:29"> <span className="woj">その日、身重の女と乳を飲ませている女には災いがある。この地には大きな苦難が臨み、この民には御怒りが下るからである。</span></span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 11:25; ヨハネの黙示録 11:2; イザヤ書 63:18"> <span className="woj">人々は剣の刃に倒れ、捕虜としてあらゆる国々へ引かれて行く。異邦人の時が満ちるまで、エルサレムは異邦人に踏みにじられる。</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 13:10; ヨエル書 2:30–31; ヨハネの黙示録 6:12–14"> <span className="woj">「太陽、月、星にしるしが現れる。地上では、海と波のとどろきに、諸国の民が不安に陥り、途方に暮れる。</span></span>
<span className="v" id="v26" data-v="26" data-xref="マタイ 24:29; 申命記 28:65–67; ペテロの第二の手紙 3:10–12"> <span className="woj">人々は、世界に臨もうとしていることへの恐れと予感のために気を失う。天の力が揺り動かされるからである。</span></span>
<span className="v" id="v27" data-v="27" data-xref="マタイ 24:30; ヨハネの黙示録 1:7; マルコ 13:26"> <span className="woj">その時、人々は、人の子が力と大きな栄光を帯びて雲に乗って来るのを見る。</span></span>
<span className="v" id="v28" data-v="28" data-xref="ローマ人への手紙 8:23; イザヤ書 60:1–2; エペソ人への手紙 4:30"> <span className="woj">これらのことが起こり始めたら、身を起こして頭を上げなさい。あなたがたの贖いが近づいているからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="マタイ 24:32–35; マルコ 13:28–30"> それからイエスは彼らにたとえを語った。<span className="woj">「いちじくの木と、すべての木を見なさい。</span></span>
<span className="v" id="v30" data-v="30" data-xref="ルカ 12:57"> <span className="woj">木々が芽を出すと、それを見て、夏がすでに近いことを自分で知る。</span></span>
<span className="v" id="v31" data-v="31" data-xref="ヤコブの手紙 5:9; ヘブル人への手紙 10:37; ペテロの手紙第一 4:7"> <span className="woj">同じように、これらのことが起こるのを見たなら、神の王国が近いことを知りなさい。</span></span>
<span className="v" id="v32" data-v="32" data-xref="マルコ 13:30; マタイ 24:34; マタイ 23:36"> <span className="woj">まことに、あなたがたに告げる。すべてのことが成し遂げられるまで、この世代は決して過ぎ去らない。</span></span>
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 40:8; マルコ 13:31; マタイ 24:35"> <span className="woj">天と地は過ぎ去るが、私の言葉は決して過ぎ去らない。</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="マルコ 4:19; ルカ 12:45–46; ルカ 12:40"> <span className="woj">「放縦、酩酊、生活の思い煩いによって心が鈍くなり、その日が突然あなたがたに臨むことのないよう、自分に気をつけなさい。</span></span>
<span className="v" id="v35" data-v="35" data-xref="ヨハネの黙示録 16:15; 詩篇 11:6; エレミヤ書 48:43–44"> <span className="woj">その日は、全地の表に住むすべての人に、わなのように臨むからである。</span></span>
<span className="v" id="v36" data-v="36" data-xref="ヨハネの手紙第一 2:28; マタイ 25:13; ペテロの手紙第一 5:8"> <span className="woj">だから、いつも目を覚まして祈りなさい。起ころうとしているこれらすべてのことを逃れ、人の子の前に立つのにふさわしいとされるためである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="ルカ 22:39; マルコ 11:19; マタイ 21:17"> イエスは毎日、神殿で教え、夜になると外へ出て、オリーブ山と呼ばれる山で夜を過ごした。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネ 8:1–2"> 民は皆、イエスの話を聞くために、朝早くから神殿のイエスのもとにやって来た。</span>
</div>

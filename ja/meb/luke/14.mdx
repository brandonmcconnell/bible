<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコ 3:2; ルカ 20:20; 詩篇 62:4"> 安息日に、イエスが食事をするためパリサイ人の指導者の家に入ると、人々はイエスを見張っていた。</span>
<span className="v" id="v2" data-v="2"> 見よ、イエスの前に水腫を患う人がいた。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイ 12:10; マルコ 3:4; ルカ 13:14–16"> イエスは律法の専門家たちとパリサイ人たちに言った。<span className="woj">「安息日に癒やすことは許されているか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="マタイ 22:46; マタイ 21:25–27"> 彼らは黙っていた。<br />イエスはその人を抱き、癒やして帰した。</span>
<span className="v" id="v5" data-v="5" data-xref="ルカ 13:15; 出エジプト記 23:4–5; マタイ 12:11–12"> そして彼らに言った。<span className="woj">「あなたがたのうち、息子</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TRは「息子」の代わりに「ろば」としている。">a</a></sup><span className="woj">や牛が井戸に落ちたら、安息日でもすぐに引き上げない者がいるだろうか。」</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ルカ 20:40; ルカ 21:15; 使徒の働き 6:10"> 彼らはこれに答えることができなかった。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ピリピ人への手紙 2:3; ルカ 11:43; マタイ 23:6"> イエスは招かれた人々が上席を選ぶ様子を見て、たとえを語った。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 25:6–7"> <span className="woj">「婚礼の宴に招かれた時、上席についてはならない。あなたより身分の高い人が招かれているかもしれない。</span></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 16:18; 箴言 11:2; 箴言 3:35"> <span className="woj">二人を招いた人が来て、『この方に席を譲ってください』と言えば、あなたは恥をかきながら末席につくことになる。</span></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 25:6–7; 箴言 15:33; サムエル記第一 15:17"> <span className="woj">招かれたら末席に座りなさい。そうすれば、招いた人が来て、『友よ、もっと上の席へどうぞ』と言ってくれる。その時、同席するすべての人の前で誉れを受ける。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ルカ 18:14; マタイ 23:12; 箴言 29:23"> <span className="woj">自分を高くする者は皆低くされ、自分を低くする者は高くされるからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マタイ 5:46; ヤコブの手紙 2:1–6; ルカ 6:32–36"> また招いた人にも言った。<span className="woj">「昼食や夕食を設ける時、友人、兄弟、親族、裕福な隣人を呼んではならない。彼らもあなたを招き返し、返礼するかもしれないからである。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ルカ 14:21; イザヤ書 58:10; 箴言 14:31"> <span className="woj">宴会を開く時は、貧しい人、手足を損なった人、足の不自由な人、目の見えない人を招きなさい。</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 19:17; 使徒の働き 24:15; ヨハネ 5:29"> <span className="woj">そうすれば幸いである。彼らには返礼する力がないからである。義人の復活の時に、あなたは報いを受ける。」</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨハネの黙示録 19:9; ルカ 22:30; ルカ 13:29"> 同席していた一人がこれを聞いて言った。「神の王国で食事をする人は幸いです。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="マタイ 22:2–14; ヨハネの黙示録 22:17; イザヤ書 55:1–7"> イエスは言った。<span className="woj">「ある人が盛大な夕食を設け、大勢を招いた。</span></span>
<span className="v" id="v17" data-v="17" data-xref="マタイ 11:27–29; マタイ 10:1–4; マタイ 22:3–4"> <span className="woj">夕食の時刻にしもべを遣わし、招いていた人々に、『来てください。もうすべて整いました』と言わせた。</span></span>
<span className="v" id="v18" data-v="18" data-xref="テモテへの手紙第一 6:9–10; ルカ 17:26–31; ルカ 18:24"> <span className="woj">すると皆が一様に断り始めた。</span><br /><span className="woj">「最初の人は言った。『畑を買ったので、見に行かなければなりません。どうかご容赦ください。』</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> <span className="woj">「別の人は言った。『牛を五くびき買ったので、試しに行くところです。どうかご容赦ください。』</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 24:5; コリント人への第一の手紙 7:33; ルカ 14:26–28"> <span className="woj">「また別の人は言った。『妻を迎えたので、行けません。』</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ルカ 14:13; マタイ 11:5; ルカ 14:24"> <span className="woj">「しもべは帰って来て、主人にこれらのことを報告した。家の主人は怒り、しもべに言った。『急いで町の大通りや路地へ出て行き、貧しい人、手足の不自由な人、目の見えない人、足の不自由な人をここへ連れて来なさい。』</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨハネ 14:2; エペソ人への手紙 3:8; テモテへの手紙第一 2:5–6"> <span className="woj">「しもべは言った。『ご主人様、ご命令どおりにしましたが、まだ席があります。』</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="マタイ 22:9–10; コロサイ人への手紙 1:28; 使徒の働き 13:47–48"> <span className="woj">「主人はしもべに言った。『街道や垣根の所へ出て行き、人々を促して入らせ、私の家をいっぱいにしなさい。</span></span>
<span className="v" id="v24" data-v="24" data-xref="マタイ 21:43; 使徒の働き 13:46; ヨハネ 8:24"> <span className="woj">あなたがたに言う。初めに招かれた者は一人も、私の夕食を味わうことがない。招かれる者は多いが、選ばれる者は少ないからである。</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="RPとMTは最後の文を含む。TR、NU、FH MTは「招かれる者は多いが、選ばれる者は少ないからである」を省いている。">b</a></sup><span className="woj">』」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ヨハネ 6:24–27; ルカ 12:1"> 大勢の群衆がイエスとともに歩いていた。イエスは振り向いて彼らに言った。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイ 10:37; ヨハネ 12:25; ピリピ人への手紙 3:8"> <span className="woj">「私のもとに来る者が、自分の父、母、妻、子ども、兄弟、姉妹、さらに自分の命さえ後回しに</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="または「憎む」">c</a></sup><span className="woj">しないなら、私の弟子になることはできない。</span></span>
<span className="v" id="v27" data-v="27" data-xref="マタイ 10:38; ルカ 9:23–25; マルコ 8:34–37"> <span className="woj">自分の十字架を負って私について来ない者は、私の弟子になることができない。</span></span>
<span className="v" id="v28" data-v="28" data-xref="箴言 24:27; マタイ 10:22; ヨシュア記 24:19–24"> <span className="woj">塔を建てようとする時、まず座って費用を計算し、完成させるだけのものがあるか確かめない人がいるだろうか。</span></span>
<span className="v" id="v29" data-v="29"> <span className="woj">土台を据えても完成できなければ、見る人は皆、その人をあざ笑い始め、</span></span>
<span className="v" id="v30" data-v="30" data-xref="ヘブル人への手紙 6:11; ヨハネの手紙第二 1:8; コリント人への第一の手紙 3:11–14"> <span className="woj">『この人は建て始めたが、完成できなかった』と言うだろう。</span></span>
<span className="v" id="v31" data-v="31" data-xref="箴言 20:18; 箴言 25:8; 列王記第二 18:20–22"> <span className="woj">また、別の王と戦おうとする王は、まず座って、一万人で二万人を率いて向かって来る相手に立ち向かえるか考えるではないか。</span></span>
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 12:20; ヤコブの手紙 4:6–10; ルカ 12:58"> <span className="woj">できなければ、相手がまだ遠くにいる間に使者を送り、和平の条件を求める。</span></span>
<span className="v" id="v33" data-v="33" data-xref="ピリピ人への手紙 3:7–8; ヨハネの手紙第一 2:15–16; ルカ 5:28"> <span className="woj">同じように、自分の持つすべてを捨てない者は、私の弟子になることができない。</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="マタイ 5:13; コロサイ人への手紙 4:6; マルコ 9:49–50"> <span className="woj">「塩は良いものだ。しかし塩が味を失えば、何によって味をつけるのか。</span></span>
<span className="v" id="v35" data-v="35" data-xref="マタイ 11:15; ルカ 9:44; ヨハネの黙示録 2:11"> <span className="woj">土地にも肥料の山にも役立たず、外へ投げ捨てられる。聞く耳のある者は聞きなさい。」</span></span>
</div>

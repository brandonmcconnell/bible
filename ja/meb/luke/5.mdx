<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="LUK" data-book-slug="luke" data-book-name="ルカ" data-chapter="5" data-verses="39">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マルコ 1:16–20; マタイ 4:18–22; マルコ 3:9"> さて、イエスがゲネサレ湖のほとりに立っておられると、群衆が神の言葉を聞こうとして押し寄せて来た。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコ 1:19; マタイ 4:21"> イエスは岸辺に二そうの舟があるのを見た。漁師たちは舟から降りて網を洗っていた。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイ 4:18; マタイ 13:1–2; ヨハネ 1:41–42"> イエスはその一そう、シモンの舟に乗り、陸から少し離すように頼んだ。そして座って、舟から群衆を教えた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ヨハネ 21:6; マタイ 17:27"> 話し終えると、シモンに言った。<span className="woj">「深みに漕ぎ出し、網を下ろして魚を捕りなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ヨハネ 2:5; ヨハネ 15:14; ルカ 6:46–48"> シモンは答えた。「先生、私たちは夜通し働きましたが、何も捕れませんでした。しかし、お言葉ですから網を下ろしましょう。」</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第一の手紙 15:58; ヨハネ 21:6–11; 伝道者の書 11:6"> そのとおりにすると、非常に多くの魚がかかり、網が破れそうになった。</span>
<span className="v" id="v7" data-v="7" data-xref="ガラテヤ人への手紙 6:2; ピリピ人への手紙 4:3; 使徒の働き 11:25"> そこで、もう一そうの舟にいる仲間に合図して、助けに来てもらった。彼らが来て、二そうの舟をいっぱいにしたため、舟は沈みかけた。</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 6:5; ヨブ記 42:5–6; ヨハネの黙示録 1:17"> シモン・ペテロはこれを見て、イエスの膝もとにひれ伏して言った。「主よ、私から離れてください。私は罪深い者です。」</span>
<span className="v" id="v9" data-v="9" data-xref="ルカ 4:32; 詩篇 8:8; マルコ 9:6"> 捕れた魚の多さに、彼も一緒にいた者も皆、驚いたのである。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイ 4:19; マタイ 13:47; エゼキエル書 47:9–10"> シモンの仲間であったゼベダイの子ヤコブとヨハネも同じだった。<br />イエスはシモンに言った。<span className="woj">「恐れることはない。今からあなたは、人を生け捕る者になる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="マタイ 4:20; ルカ 5:28; マタイ 19:27"> 彼らは舟を陸に引き上げると、すべてを捨ててイエスに従った。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="詩篇 50:15; ルカ 17:16; マタイ 8:2–4"> イエスがある町におられた時、見よ、全身らい病の人がいた。彼はイエスを見ると、ひれ伏して願った。「主よ、お望みなら、私を清くすることがおできになります。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マタイ 9:29–30; ヨハネ 4:50–53; ホセア書 14:4"> イエスは手を伸ばして彼に触れ、言った。<span className="woj">「そうしよう。清くなれ。」</span><br />すると、らい病はただちに彼から去った。</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 14:2–32; ルカ 17:14; マルコ 1:44"> イエスは、だれにも話さないよう命じて言った。<span className="woj">「ただ行って、自分を祭司に見せなさい。そして、人々へのあかしとして、モーセが命じたとおり、清めのための供え物をささげなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="マタイ 15:30–31; ルカ 12:1; マルコ 1:45–2"> しかし、イエスについての評判はいっそう広まり、大勢の群衆が教えを聞き、病気を癒やしてもらうために集まって来た。</span>
<span className="v" id="v16" data-v="16" data-xref="ルカ 6:12; マルコ 1:35–36; マタイ 14:23"> だがイエスは人里離れた所に退いて祈っていた。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ルカ 6:19; ルカ 8:46; マタイ 11:5"> ある日のこと、イエスが教えていると、ガリラヤとユダヤのすべての村やエルサレムから来たパリサイ人と律法の教師たちがそこに座っていた。主の力が働き、イエスは人々を癒やしていた。</span>
<span className="v" id="v18" data-v="18" data-xref="マルコ 2:3–12; マタイ 9:2–8; ヨハネ 5:5–6"> 見よ、人々が寝台に載せた麻痺した人を運んで来て、中に入れてイエスの前に置こうとした。</span>
<span className="v" id="v19" data-v="19" data-xref="マルコ 2:4; マタイ 10:27; マタイ 24:17"> しかし群衆のために運び込む道が見つからなかったので、屋根に上り、瓦の間から寝台ごと人々の真ん中、イエスの前につり下ろした。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 14:9; マタイ 9:2; マルコ 2:5"> イエスは彼らの信仰を見て、その人に言った。<span className="woj">「人よ、あなたの罪は赦された。」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 43:25; マルコ 2:6–7; ルカ 7:49"> 律法学者たちとパリサイ人たちは論じ始めた。「神を冒涜することを言うこの人は何者だ。神お一人のほかに、だれが罪を赦せるのか。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ルカ 24:38; イザヤ書 66:18; 詩篇 139:2"> イエスは彼らの考えを見抜いて答えた。<span className="woj">「なぜ心の中でそのように論じているのか。</span></span>
<span className="v" id="v23" data-v="23" data-xref="マルコ 2:9; マタイ 9:5"> <span className="woj">『あなたの罪は赦された』と言うのと、『起きて歩け』と言うのと、どちらがたやすいか。</span></span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの黙示録 1:13; イザヤ書 53:11; ルカ 8:54"> <span className="woj">しかし、人の子が地上で罪を赦す権威を持っていることを、あなたがたが知るために。」</span>そして麻痺した人に言った。<span className="woj">「あなたに言う。起きて寝台を担ぎ、家に帰りなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ヨハネ 9:24; ルカ 5:13; 詩篇 107:20–22"> その人はたちまち皆の前で立ち上がり、寝ていた寝台を担いで、神に栄光を帰しながら家に帰った。</span>
<span className="v" id="v26" data-v="26" data-xref="マタイ 9:8; マタイ 12:23; ルカ 7:16"> 人々は皆、驚嘆して神に栄光を帰した。そして恐れに満たされて言った。「今日、私たちは驚くべきことを見た。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="マルコ 2:13–22; マタイ 9:9–17; ヨハネ 1:43"> その後、イエスは外に出て、レビという徴税人が収税所に座っているのを見て言った。<span className="woj">「私に従いなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ルカ 5:11; マタイ 19:22–27; 列王記第一 19:19–21"> レビはすべてを捨てて立ち上がり、イエスに従った。</span>
<span className="v" id="v29" data-v="29" data-xref="マルコ 2:15; ルカ 15:1; コリント人への第一の手紙 10:27"> レビは自分の家でイエスのために盛大な宴会を開いた。徴税人やほかの人々が大勢、イエスとその一行とともに食卓についていた。</span>
<span className="v" id="v30" data-v="30" data-xref="マタイ 21:28–32; ルカ 5:17; マルコ 7:3"> 律法学者たちとパリサイ人たちは、イエスの弟子たちに不平を言った。「なぜあなたがたは、徴税人や罪人たちと一緒に食べたり飲んだりするのか。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="マルコ 2:17; マタイ 9:12–13; エレミヤ書 8:22"> イエスは彼らに答えた。<span className="woj">「健康な人に医者はいらない。医者を必要とするのは病人である。</span></span>
<span className="v" id="v32" data-v="32" data-xref="ルカ 19:10; ルカ 15:10; テモテへの手紙第一 1:15–16"> <span className="woj">私は義人を招くためではなく、罪人を悔い改めに招くために来た。」</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="マタイ 9:14–17; マルコ 2:18–22; ヨハネ 3:25"> 彼らはイエスに言った。「ヨハネの弟子たちはたびたび断食して祈り、パリサイ人の弟子たちも同じようにしています。それなのに、あなたの弟子たちは食べたり飲んだりしています。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ヨハネ 3:29; コリント人への第二の手紙 11:2; イザヤ書 54:5"> イエスは彼らに言った。<span className="woj">「花婿が一緒にいる間、花婿の友人たちを断食させることができるだろうか。</span></span>
<span className="v" id="v35" data-v="35" data-xref="ルカ 17:22; 使徒の働き 14:23; 使徒の働き 3:21"> <span className="woj">しかし、花婿が彼らから取り去られる日が来る。その日には断食する。」</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="マタイ 9:16–17; マルコ 2:21–22; コリント人への第二の手紙 6:16"> イエスはまた、彼らにたとえを語った。<span className="woj">「新しい衣から布を切り取って、古い衣に継ぎ当てる人はいない。そんなことをすれば、新しい衣を裂くことになり、新しい衣から取った布も古い衣には合わない。</span></span>
<span className="v" id="v37" data-v="37" data-xref="ヨシュア記 9:13; 詩篇 119:83; ヨシュア記 9:4"> <span className="woj">また、新しいぶどう酒を古い革袋に入れる人はいない。そんなことをすれば、新しいぶどう酒が革袋を破り、酒はこぼれ、革袋もだめになる。</span></span>
<span className="v" id="v38" data-v="38" data-xref="ヘブル人への手紙 8:8–13; コリント人への第二の手紙 5:17; エゼキエル書 36:26"> <span className="woj">新しいぶどう酒は新しい革袋に入れなければならない。そうすれば、どちらも保たれる。</span></span>
<span className="v" id="v39" data-v="39" data-xref="ヘブル人への手紙 11:39; マルコ 7:7–13; エレミヤ書 6:16"> <span className="woj">古いぶどう酒を飲んだ人は、すぐに新しいものを欲しがることはない。『古いもののほうが良い』と言うからである。」</span></span>
</div>
</div>

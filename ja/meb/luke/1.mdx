<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 1:1–3; ペテロの第二の手紙 1:16–19; ヨハネ 20:31"> われわれの間で成就した出来事について、多くの人が物語を順序立てて書こうと試みました。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネ 15:27; 使徒の働き 26:16; ヘブル人への手紙 2:3"> それは、初めから目撃者であり、みことばに仕える者であった人々が、われわれに伝えたとおりのものです。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 1:1; 使徒の働き 26:25; 使徒の働き 11:4"> そこで私も、すべてのことを初めから綿密に調べましたので、テオフィロ閣下、あなたのために順序立てて書くのがよいと思いました。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネ 20:31; 使徒の働き 18:25; コリント人への第一の手紙 14:19"> それは、あなたが教えを受けた事柄が確かなものであることを知っていただくためです。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歴代誌上 24:10; マタイ 2:1; ネヘミヤ記 12:4"> ユダヤの王ヘロデの時代に、アビヤの祭司組に属するザカリヤという祭司がいた。彼の妻はアロンの子孫で、名をエリサベツといった。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 7:1; 創世記 17:1; ピリピ人への手紙 2:15"> 二人はともに神の前に正しい人で、主のすべての戒めと定めを落ち度なく守っていた。</span>
<span className="v" id="v7" data-v="7" data-xref="ヘブル人への手紙 11:11; 創世記 18:11; サムエル記第一 1:2"> しかし、エリサベツは不妊であったため、二人には子がなく、二人ともすでに年を取っていた。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歴代誌 第二 8:14; 歴代誌上 24:19; 歴代誌 第二 31:2"> さて、ザカリヤが自分の組の順番に従って、神の前で祭司の務めを果たしていたとき、</span>
<span className="v" id="v9" data-v="9" data-xref="歴代誌 第二 29:11; 出エジプト記 30:7–8; 歴代誌上 23:13"> 祭司職の慣例によってくじを引いたところ、主の神殿に入って香をたく役に当たった。</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 16:17; ヨハネの黙示録 8:3; ヘブル人への手紙 4:14"> 香をたく時刻には、民の群衆が皆、外で祈っていた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 40:26–27; 使徒の働き 10:3–4; 士師記 13:3"> すると、主の使いが彼に現れ、香の祭壇の右側に立った。</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 13:22; 士師記 6:22; ルカ 2:9–10"> ザカリヤはそれを見て動揺し、恐れに襲われた。</span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記第一 2:21; 使徒の働き 10:31; 創世記 25:21"> しかし、御使いは彼に言った。「恐れることはない、ザカリヤ。あなたの願いは聞き入れられた。妻エリサベツは男の子を産む。その子をヨハネと名づけなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="ルカ 1:58; 箴言 23:24; 創世記 21:6"> あなたは喜びにあふれ、多くの人もその誕生を喜ぶ。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 1:5; 民数記 6:2–4; ルカ 7:33"> 彼は主の前に偉大な者となり、ぶどう酒も強い酒も決して飲まない。母の胎内にいる時から聖霊に満たされる。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 40:3–5; マタイ 21:32; マラキ書 3:1"> そして、イスラエルの子らの多くを、彼らの神である主に立ち返らせる。</span>
<span className="v" id="v17" data-v="17" data-xref="マラキ書 4:5–6; マタイ 11:14; ルカ 1:76"> 彼はエリヤの霊と力をもって主に先立って行き、『父たちの心を子どもたちに向けさせ』、従わない者を義人の知恵に立ち返らせ、主のために備えられた民を用意する。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 38:22; 創世記 17:17; ルカ 1:7"> ザカリヤは御使いに言った。「どうすれば、それが確かだと分かるでしょうか。私は老人ですし、妻もかなり年を取っています。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ルカ 1:26; マタイ 18:10; ダニエル書 9:21–23"> 御使いは答えた。「私は神の御前に立つガブリエルである。あなたに語り、この良い知らせを伝えるために遣わされた。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 3:26; エゼキエル書 24:27; ルカ 1:22"> 見よ、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「見よ」はギリシャ語の「ἰδοὺ」に由来し、見る、注意を向ける、観察する、目を留めるという意味がある。しばしば間投詞として用いられる。">a</a></sup>これらのことが起こる日まで、あなたは口が利けず、話すこともできなくなる。定められた時に実現する私の言葉を、あなたが信じなかったからである。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数記 6:23–27"> 民はザカリヤを待っていて、彼が神殿の中で手間取っているのを不思議に思っていた。</span>
<span className="v" id="v22" data-v="22" data-xref="ルカ 1:62; ヨハネ 13:24; 使徒の働き 21:40"> 彼は外に出て来たが、彼らに話すことができなかった。それで人々は、彼が神殿の中で幻を見たのだと悟った。彼は身振りを続けるばかりで、口が利けないままだった。</span>
<span className="v" id="v23" data-v="23" data-xref="歴代誌上 9:25; 列王記第二 11:5–7"> 奉仕の日々が終わると、彼は家に帰った。</span>
<span className="v" id="v24" data-v="24"> その後、妻エリサベツは身ごもり、五か月の間、人目を避けて言った。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 30:22–23; イザヤ書 54:1–4; 創世記 21:1–2"> 「主は今、私を顧みて、人々の間での恥を取り除いてくださった。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="マタイ 2:23; ルカ 1:19; ヨハネ 7:41"> 六か月目に、御使いガブリエルが神から遣わされ、ガリラヤのナザレという町に行った。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイ 1:18; イザヤ書 7:14; マタイ 1:16"> それは、ダビデの家に属するヨセフという人と婚約している処女のもとへであった。その処女の名はマリアといった。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 6:12; ダニエル書 10:19; ルカ 1:30"> 御使いは中に入って来て、彼女に言った。「喜びなさい、大いに恵まれた人。主があなたとともにおられる。あなたは女たちの中で祝福されている。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 10:17; ルカ 1:12; 使徒の働き 10:4"> しかし、彼女はその言葉にひどく戸惑い、これはいったい何のあいさつだろうかと考え込んだ。</span>
<span className="v" id="v30" data-v="30" data-xref="ルカ 1:13; ローマ人への手紙 8:31; ルカ 12:32"> 御使いは言った。「恐れることはない、マリア。あなたは神から恵みを受けた。</span>
<span className="v" id="v31" data-v="31" data-xref="イザヤ書 7:14; マタイ 1:21; マタイ 1:25"> 見よ、あなたは胎内に子を宿し、男の子を産む。その子を『イエス』と名づけなさい。</span>
<span className="v" id="v32" data-v="32" data-xref="イザヤ書 9:6–7; イザヤ書 16:5; サムエル記第二 7:11–13"> 彼は偉大な者となり、いと高き方の子と呼ばれる。主なる神は彼に、その父ダビデの王座をお与えになる。</span>
<span className="v" id="v33" data-v="33" data-xref="ダニエル書 2:44; ヘブル人への手紙 1:8; ダニエル書 7:13–14"> 彼は永遠にヤコブの家を治め、その王国に終わりはない。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="士師記 13:8–12; 使徒の働き 9:6"> マリアは御使いに言った。「私はまだ男の人を知りません。どうしてそのようなことが起こるのでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="マタイ 1:18; ヨハネ 1:49; マタイ 1:20"> 御使いは答えた。「聖霊があなたの上に臨み、いと高き方の力があなたを覆う。それゆえ、あなたから生まれる聖なる者は神の子と呼ばれる。</span>
<span className="v" id="v36" data-v="36"> 見よ、あなたの親族エリサベツも、年を取ってから男の子を身ごもっている。不妊と呼ばれていた彼女が、今や六か月目である。</span>
<span className="v" id="v37" data-v="37" data-xref="マタイ 19:26; エレミヤ書 32:27; マルコ 10:27"> 神が語られたことは、何一つ実現不可能ではない。」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または「神によって語られたことは、すべて実現できる。」">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="ローマ人への手紙 4:20–21; 詩篇 119:38; 詩篇 116:16"> マリアは言った。「見よ、私は主のしもべです。あなたの言葉どおり、この身になりますように。」<br />それから御使いは彼女のもとを去った。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="ルカ 1:65; ヨシュア記 15:48–59; ヨシュア記 10:40"> そのころ、マリアは立って急いで山地へ向かい、ユダの町に行った。</span>
<span className="v" id="v40" data-v="40"> そしてザカリヤの家に入り、エリサベツにあいさつした。</span>
<span className="v" id="v41" data-v="41" data-xref="ルカ 1:67; 使徒の働き 4:8; ルカ 1:44"> エリサベツがマリアのあいさつを聞いたとき、胎内の子が跳ねた。そしてエリサベツは聖霊に満たされた。</span>
<span className="v" id="v42" data-v="42" data-xref="ルカ 1:28; 士師記 5:24; 創世記 22:18"> 彼女は声高らかに叫んで言った。「あなたは女たちの中で祝福され、あなたの胎の実も祝福されています。</span>
<span className="v" id="v43" data-v="43" data-xref="ヨハネ 20:28; ヨハネ 13:13; ルカ 2:11"> 私の主の母が私のところに来てくださるとは、私はなんと恵まれていることでしょう。</span>
<span className="v" id="v44" data-v="44"> 見よ、あなたのあいさつの声が私の耳に届いたとき、胎内の子が喜んで跳ねました。</span>
<span className="v" id="v45" data-v="45" data-xref="ヨハネ 20:29; ヨハネ 11:40; ルカ 11:27–28"> 主から語られたことは実現すると信じた人は、幸いです。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v46" data-v="46" data-xref="サムエル記第一 2:1–10; 詩篇 34:2–3; 詩篇 35:9"> マリアは言った。<br /><span className="pl pl-1">「私の魂は主をあがめ、</span></span>
<span className="v" id="v47" data-v="47" data-xref="詩篇 35:9; テモテへの手紙第一 2:3; ハバクク書 3:18"> <span className="pl pl-2">私の霊は救い主である神を喜びたたえる。</span><br /></span>
<span className="v" id="v48" data-v="48" data-xref="詩篇 138:6; マラキ書 3:12; コリント人への第一の手紙 1:26–28"> <span className="pl pl-2">神が、しもべである私の卑しい身に目を留めてくださったから。</span><br /><span className="pl pl-1">見よ、今から後、すべての世代が私を幸いな者と呼ぶ。</span></span>
<span className="v" id="v49" data-v="49" data-xref="詩篇 126:2–3; 詩篇 111:9; エペソ人への手紙 3:20"> <span className="pl pl-2">力ある方が、私のために大いなることをしてくださった。</span><br /><span className="pl pl-2">その御名は聖なるもの。</span><br /></span>
<span className="v" id="v50" data-v="50" data-xref="詩篇 103:17–18; 出エジプト記 20:6; 創世記 17:7"> <span className="pl pl-2">そのあわれみは、主を恐れる者に代々限りなく及ぶ。</span></span>
<span className="v" id="v51" data-v="51" data-xref="詩篇 98:1; イザヤ書 52:10; サムエル記第一 2:3–4"> <span className="pl pl-1">主はその御腕で力を現し、</span><br /><span className="pl pl-2">心の思いにおごる者たちを散らされた。</span></span>
<span className="v" id="v52" data-v="52" data-xref="エゼキエル書 17:24; ヤコブの手紙 4:10; 詩篇 107:40–41"> <span className="pl pl-1">権力者たちを王座から引き降ろし、</span><br /><span className="pl pl-2">低い者たちを高く上げられた。</span></span>
<span className="v" id="v53" data-v="53" data-xref="詩篇 107:8–9; ルカ 6:21; 詩篇 34:10"> <span className="pl pl-1">飢えた者たちを良いもので満たし、</span><br /><span className="pl pl-2">富む者たちを何も持たせずに帰された。</span></span>
<span className="v" id="v54" data-v="54" data-xref="詩篇 98:3; ミカ書 7:20; イザヤ書 44:21"> <span className="pl pl-1">あわれみを忘れず、しもべイスラエルを助けられた。</span></span>
<span className="v" id="v55" data-v="55" data-xref="詩篇 105:6–10; 創世記 17:19; 詩篇 132:11–17"> <span className="pl pl-2">父祖たちに語られたとおり、</span><br /><span className="pl pl-2">アブラハムとその子孫</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="または「種」">c</a></sup><br /><span className="pl pl-2">に、永遠にあわれみを示された。」</span></span>
</div>
<div className="bp">
<span className="v" id="v56" data-v="56"> マリアはエリサベツと三か月ほど過ごしてから、自分の家に帰った。</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="ルカ 1:13; 創世記 21:2–3; ルカ 2:6–7"> さて、エリサベツは出産の時が満ちて、男の子を産んだ。</span>
<span className="v" id="v58" data-v="58" data-xref="ルカ 1:25; ルカ 1:14; ローマ人への手紙 12:15"> 近所の人々や親族は、主が彼女に大きなあわれみを示されたと聞き、ともに喜んだ。</span>
<span className="v" id="v59" data-v="59" data-xref="創世記 17:12; レビ記 12:3; ピリピ人への手紙 3:5"> 八日目に、人々はその子に割礼を施すために来て、父の名にちなんでザカリヤと名づけようとした。</span>
<span className="v" id="v60" data-v="60" data-xref="ルカ 1:13; サムエル記第二 12:25; ルカ 1:63"> しかし母親は答えた。「いいえ、この子はヨハネと呼ばれます。」</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61"> 人々は彼女に言った。「あなたの親族の中に、その名で呼ばれている人は一人もいません。」</span>
<span className="v" id="v62" data-v="62" data-xref="ルカ 1:22"> そして父親に、何という名にしたいのかと身振りで尋ねた。</span>
</div>
<div className="bp">
<span className="v" id="v63" data-v="63" data-xref="ルカ 1:60; イザヤ書 30:8; ルカ 1:13"> 彼は書き板を求め、「その名はヨハネ」と書いた。<br />人々は皆、驚いた。</span>
<span className="v" id="v64" data-v="64" data-xref="ルカ 1:20; 出エジプト記 4:15–16; エゼキエル書 33:22"> するとたちまち彼の口が開き、舌が自由になった。そして彼は語り出し、神をほめたたえた。</span>
<span className="v" id="v65" data-v="65" data-xref="ルカ 1:39; 使徒の働き 5:11; ルカ 7:16"> 近所に住む人々は皆、恐れに包まれ、これらの出来事はユダヤの山地全体で語り合われた。</span>
<span className="v" id="v66" data-v="66" data-xref="使徒の働き 11:21; ルカ 2:19; ルカ 2:51"> それを聞いた人々は皆、心に留めて言った。「いったい、この子はどのようになるのだろう。」主の御手が彼とともにあった。</span>
</div>
<div className="bp poetry">
<span className="v" id="v67" data-v="67" data-xref="ヨエル書 2:28; ルカ 1:41; ルカ 1:15"> 父ザカリヤは聖霊に満たされ、預言して言った。</span>
<span className="v" id="v68" data-v="68" data-xref="詩篇 106:48; ルカ 7:16; 詩篇 41:13"> <span className="pl pl-1">「イスラエルの神である主は、ほめたたえられよ。</span><br /><span className="pl pl-2">主はその民を訪れ、贖ってくださった。</span></span>
<span className="v" id="v69" data-v="69" data-xref="詩篇 18:2; エゼキエル書 29:21; サムエル記第二 22:3"> <span className="pl pl-1">仕える者ダビデの家に、われわれのために救いの角を立てられた。</span></span>
<span className="v" id="v70" data-v="70" data-xref="使徒の働き 3:21–24; ローマ人への手紙 1:2; ペテロの第二の手紙 1:21"> <span className="pl pl-2">昔からの聖なる預言者たちの口を通して語られたとおり、</span><br /></span>
<span className="v" id="v71" data-v="71" data-xref="詩篇 106:10; エレミヤ書 23:6; ゼパニヤ書 3:15–20"> <span className="pl pl-2">われわれを敵から、憎む者すべての手から救ってくださる。</span></span>
<span className="v" id="v72" data-v="72" data-xref="ヘブル人への手紙 6:13–18; ミカ書 7:20; 詩篇 106:45"> <span className="pl pl-1">これは父祖たちにあわれみを示し、</span><br /><span className="pl pl-2">主の聖なる契約を覚えておられるため、</span></span>

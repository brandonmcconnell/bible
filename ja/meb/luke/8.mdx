<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 4:23; ローマ人への手紙 10:15; マタイ 9:35"> それから間もなく、イエスは町や村を巡りながら、神の王国を宣べ伝え、その福音を告げ知らせた。十二人も一緒にいた。</span>
<span className="v" id="v2" data-v="2" data-xref="マルコ 16:9; マタイ 27:55–56; マルコ 15:40–41"> 悪霊や病気を癒やされた何人かの女たちもいた。七つの悪霊が出て行ったマグダラと呼ばれるマリア、</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネ 4:46–53; コリント人への第二の手紙 8:9; 使徒の働き 9:36–39"> ヘロデの家令クーザの妻ヨハンナ、スザンナ、そして自分の財産を使って彼らに<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TRは「彼ら」の代わりに「彼」としている。">a</a></sup>仕える多くの女たちである。</span>
<span className="v" id="v4" data-v="4" data-xref="マルコ 4:1–9; マタイ 13:2–9"> 大勢の群衆が集まり、町々から人々がイエスのもとに来ると、イエスはたとえで語った。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 2:1; ヤコブの手紙 1:23–24; マルコ 4:15"> <span className="woj">「種をまく人が種をまきに出て行った。まいていると、ある種は道端に落ち、踏みつけられ、空の鳥に食べられた。</span></span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 3:7–8; ルカ 8:13; マルコ 4:5–6"> <span className="woj">ある種は岩の上に落ち、芽を出したが、水分がないため枯れてしまった。</span></span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 4:3; ルカ 8:14; ルカ 21:34"> <span className="woj">ある種はいばらの間に落ち、いばらも一緒に伸びて、それをふさいでしまった。</span></span>
<span className="v" id="v8" data-v="8" data-xref="マタイ 11:15; ヨハネの黙示録 2:11; ヨハネの黙示録 2:7"> <span className="woj">ある種は良い地に落ち、芽を出して百倍の実を結んだ。」</span>こう語ると、声を上げた。<span className="woj">「聞く耳のある者は聞きなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="マルコ 4:10; マタイ 13:10; マタイ 13:18"> 弟子たちは、「このたとえはどういう意味ですか」と尋ねた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 6:9; マルコ 4:11; マタイ 11:25"> イエスは言った。<span className="woj">「あなたがたには神の王国の奥義を知ることが与えられている。しかし、ほかの人々にはたとえで語られる。それは、『見ても見えず、聞いても理解しない』ためである。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="マタイ 13:19; マルコ 4:14–20; ヤコブの手紙 1:21"> <span className="woj">「このたとえの意味はこうである。種は神の言葉である。</span></span>
<span className="v" id="v12" data-v="12" data-xref="テサロニケ人への第二の手紙 2:9–14; ヨハネの黙示録 12:9; ヤコブの手紙 1:23–24"> <span className="woj">道端のものとは、みことばを聞く人々である。その後、悪魔が来て、彼らが信じて救われることのないよう、心からみことばを取り去る。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ホセア書 6:4; ヨハネ 5:35; 箴言 12:12"> <span className="woj">岩の上のものとは、聞くと喜んでみことばを受け入れる人々である。しかし彼らには根がない。しばらくは信じるが、誘惑の時になると離れてしまう。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの手紙第一 2:15–17; テモテへの手紙第一 6:9–10; テモテへの手紙第一 6:17"> <span className="woj">いばらの中に落ちたものとは、みことばを聞いた人々である。しかし歩んで行くうちに、この世の心配や富や快楽にふさがれ、実を熟させることがない。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 10:36; ガラテヤ人への手紙 5:22–26; コロサイ人への手紙 1:10"> <span className="woj">良い地のものとは、誠実で良い心でみことばを聞き、しっかり保ち、忍耐して実を結ぶ人々である。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ルカ 11:33; マタイ 5:15–16; マルコ 4:21–22"> <span className="woj">「明かりをともしてから、器で覆ったり寝台の下に置いたりする人はいない。入って来る人に光が見えるよう、燭台の上に置く。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ルカ 12:2–3; マタイ 10:26; マルコ 4:22"> <span className="woj">隠されていて明らかにならないものはなく、秘密にされていて知られず、明るみに出ないものもない。</span></span>
<span className="v" id="v18" data-v="18" data-xref="マタイ 13:12; ルカ 19:26; マルコ 4:23–25"> <span className="woj">だから、どのように聞くかに注意しなさい。持っている者にはさらに与えられ、持っていない者からは、持っていると思っているものまで取り去られるからである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="マタイ 12:46–50; マルコ 3:31–35; マルコ 3:21"> イエスの母と兄弟たちが来たが、群衆のために近づくことができなかった。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 1:14; マルコ 6:3; マタイ 13:55–56"> 人々がイエスに告げた。「あなたのお母様と兄弟たちが、あなたに会いたいと外に立っています。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ルカ 11:27–28; ヤコブの手紙 1:22; ヨハネ 13:17"> しかしイエスは彼らに答えた。<span className="woj">「神の言葉を聞いて行う人たちこそ、私の母、私の兄弟である。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="マタイ 8:23–27; マルコ 4:35–41; マルコ 6:45"> ある日のこと、イエスは弟子たちと舟に乗り、彼らに言った。<span className="woj">「湖の向こう岸へ渡ろう。」</span>そこで彼らは舟を出した。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 93:3–4; 詩篇 124:2–4; 詩篇 148:8"> 舟で進んでいる間に、イエスは眠ってしまった。湖に暴風が吹き下ろし、舟に水がたまって危険になった。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 107:25–29; ルカ 4:39; 詩篇 104:6–9"> 弟子たちは近寄ってイエスを起こし、「先生、先生、死んでしまいます」と言った。イエスは起き上がり、風と荒れ狂う水を叱った。するとそれらは静まり、凪になった。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイ 8:26; 箴言 30:4; マルコ 4:40–41"> イエスは彼らに言った。<span className="woj">「あなたがたの信仰はどこにあるのか。」</span>彼らは恐れ、驚いて互いに言った。「この方はいったいだれなのだろう。風や水にさえ命じると、従うではないか。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="マルコ 5:1–20; マタイ 8:28–34"> 彼らはガリラヤの向かい側にある、ガダラ人の地方に着いた。</span>
<span className="v" id="v27" data-v="27" data-xref="マルコ 5:2–5; サムエル記第一 19:24; 民数記 19:16"> イエスが陸に上がると、その町から来た一人の男が出会った。彼は長い間悪霊につかれ、服を着ず、家にも住まず、墓場に住んでいた。</span>
<span className="v" id="v28" data-v="28" data-xref="マタイ 8:29; ペテロの第二の手紙 2:4; マルコ 5:6–8"> 彼はイエスを見ると叫び、その前にひれ伏して大声で言った。「いと高き神の子イエスよ、私とあなたに何の関わりがあるのですか。お願いします。私を苦しめないでください。」</span>
<span className="v" id="v29" data-v="29" data-xref="マルコ 5:3–5; ルカ 9:39; テモテへの第二の手紙 2:25–26"> イエスが汚れた霊に、その人から出て行くよう命じておられたからである。汚れた霊はたびたび彼を捕らえていた。人々が番をし、鎖と足かせでつないでも、彼はそれを引きちぎり、悪霊に追い立てられて荒野へ行った。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="マタイ 26:53; ルカ 8:2; マタイ 8:29"> イエスは彼に尋ねた。<span className="woj">「名は何というのか。」</span><br />彼は「レギオンです」と答えた。多くの悪霊が彼の中に入っていたからである。</span>
<span className="v" id="v31" data-v="31" data-xref="マタイ 25:41; ピリピ人への手紙 2:10–11; ヨブ記 2:5"> 悪霊たちは、底知れぬ所へ行けと命じないでほしいとイエスに願った。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="イザヤ書 65:4; イザヤ書 66:3; ヨハネの黙示録 20:7"> そこでは、多くの豚の群れが山で草を食べていた。悪霊たちは、その豚に入ることを許してほしいと願った。そこでイエスは許した。</span>
<span className="v" id="v33" data-v="33" data-xref="ペテロの手紙第一 5:8; ヨハネ 8:44; ルカ 8:22–23"> 悪霊たちはその人から出て豚に入った。すると群れは急な崖を駆け下り、湖に飛び込んで溺れ死んだ。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="マルコ 5:14; マタイ 8:33; マタイ 28:11"> 飼っていた者たちは起こったことを見ると逃げ、町や地方で知らせた。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="ルカ 10:39; 使徒の働き 22:3; ヨハネの手紙第一 3:8"> 人々は起こったことを見ようと出て来た。イエスのところに来ると、悪霊の出て行った人が服を着て正気になり、イエスの足もとに座っているのを見て恐れた。</span>
<span className="v" id="v36" data-v="36" data-xref="マタイ 4:24"> 目撃した者たちは、悪霊につかれていた人がどのように癒やされたかを人々に伝えた。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒の働き 16:39; ルカ 8:28; ルカ 10:10–11"> ガダラ人の周辺地方の民は皆、非常に恐れて、ここから去ってほしいとイエスに頼んだ。そこでイエスは舟に乗って帰った。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒の働き 9:13–16; マルコ 5:18–20; 詩篇 145:3–12"> 悪霊を追い出してもらった人は、一緒に行かせてほしいと願った。しかしイエスは彼を帰らせて言った。</span>
<span className="v" id="v39" data-v="39" data-xref="ルカ 17:15–18; テモテへの手紙第一 5:8; 申命記 10:21"> <span className="woj">「自分の家に帰り、神があなたのためにどれほど大きなことをしてくださったかを語りなさい。」</span>彼は帰り、イエスが自分のためにどれほど大きなことをしてくださったかを町中に宣べ伝えた。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="マタイ 9:1; マルコ 5:21; マルコ 6:20"> イエスが戻ると、群衆は歓迎した。皆がイエスを待っていたのである。</span>
<span className="v" id="v41" data-v="41" data-xref="マルコ 5:22–43; ルカ 13:14; 使徒の働き 18:8"> 見よ、ヤイロという人が来た。会堂の長であった。彼はイエスの足もとにひれ伏し、自分の家に来てほしいと願った。</span>
<span className="v" id="v42" data-v="42" data-xref="ルカ 7:12; ルカ 8:45; ヨブ記 1:18–19"> 十二歳くらいになる一人娘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「一人娘」という表現はギリシャ語の「μονογενη」に由来し、「ただ一人の子」または「独り子」と訳されることもある。">b</a></sup>がいて、死にかけていたからである。イエスが行く途中、群衆が周りに押し寄せていた。</span>
<span className="v" id="v43" data-v="43" data-xref="マルコ 5:25–26; マタイ 9:20–22; レビ記 15:25–33"> そこに、十二年間も出血が続き、医者たちに全財産を使い果たしたが、だれにも治してもらえなかった女がいた。</span>
<span className="v" id="v44" data-v="44" data-xref="マルコ 5:27–28; 申命記 22:12; 使徒の働き 19:12"> 彼女は後ろから近づき、イエスの上着の房<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="または「飾り房」">c</a></sup>に触れた。すると、出血がたちまち止まった。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="マルコ 5:30–32; ルカ 9:13; ルカ 5:5"> イエスは言った。<span className="woj">「私に触れたのはだれか。」</span><br />皆が否定すると、ペテロと一緒にいた者たちが言った。「先生、群衆が取り囲んで押し合っているのに、<span className="woj">『私に触れたのはだれか』</span>とおっしゃるのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="ルカ 6:19; ルカ 5:17; ペテロの手紙第一 2:9"> しかしイエスは言った。<span className="woj">「だれかが私に触れた。私から力が出て行ったのが分かったからである。」</span></span>
<span className="v" id="v47" data-v="47" data-xref="マルコ 5:33; ルカ 17:15–16; コリント人への第一の手紙 2:3"> 女は隠しきれないと悟り、震えながら進み出て、イエスの前にひれ伏した。そして触れた理由と、たちまち癒やされたことを、民すべての前で話した。</span>
<span className="v" id="v48" data-v="48" data-xref="ルカ 7:50; マタイ 9:22; ヘブル人への手紙 4:2"> イエスは彼女に言った。<span className="woj">「娘よ、元気を出しなさい。あなたの信仰があなたを癒やした。安心して行きなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="マルコ 5:35–43; イザヤ書 7:12; ルカ 7:6"> イエスがまだ話していると、会堂の長の家から人が来て言った。「お嬢さんは亡くなりました。先生を煩わせることはありません。」</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="ヨハネ 11:40; ヨハネ 11:25; マルコ 5:36"> しかしイエスはこれを聞き、彼に答えた。<span className="woj">「恐れることはない。ただ信じなさい。そうすれば、娘は癒やされる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="マルコ 14:33; マタイ 6:5–6; 列王記第一 17:19–23"> 家に着くと、ペテロ、ヨハネ、ヤコブ、子どもの父と母のほかは、だれも中に入ることを許さなかった。</span>
<span className="v" id="v52" data-v="52" data-xref="ルカ 23:27; ヨハネ 11:4; ゼカリヤ書 12:10"> 人々は皆、娘のために泣き悲しんでいた。しかしイエスは言った。<span className="woj">「泣かなくてよい。死んだのではなく、眠っているのだ。」</span></span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="ルカ 16:14; イザヤ書 53:3; ヨハネ 11:39"> 人々は娘が死んだことを知っていたので、イエスをあざ笑った。</span>
<span className="v" id="v54" data-v="54" data-xref="エレミヤ書 31:32; ヨハネ 11:43; マルコ 1:31"> しかしイエスは皆を外に出し、娘の手を取って呼びかけた。<span className="woj">「子よ、起きなさい。」</span></span>
<span className="v" id="v55" data-v="55" data-xref="ヨハネ 11:44; 列王記第一 17:21–23; マルコ 5:43"> すると娘の霊が戻り、ただちに起き上がった。イエスは食べ物を与えるよう命じた。</span>
<span className="v" id="v56" data-v="56" data-xref="マタイ 8:4; マタイ 9:30; ルカ 5:14"> 両親は驚いたが、イエスは起こったことをだれにも話さないよう命じた。</span>
</div>

<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="テサロニケ人への手紙第一 5:5; エペソ人への手紙 5:8; 箴言 6:6–8"> <span className="woj">「主人は、不正な管理人が賢く行動したので、彼をほめた。この世の子らは、自分たちの世代の中では、光の子らより賢いからである。</span></span>
<span className="v" id="v9" data-v="9" data-xref="マタイ 19:21; テモテへの手紙第一 6:17–19; ダニエル書 4:27"> <span className="woj">あなたがたに言う。不正の富を用いて自分のために友人を作りなさい。そうすれば、それが尽きた時、彼らはあなたがたを永遠の住まいに迎えてくれる。</span></span>
<span className="v" id="v10" data-v="10" data-xref="ルカ 16:11–12; マタイ 25:21; ルカ 19:17"> <span className="woj">ごく小さなことに忠実な者は、大きなことにも忠実であり、ごく小さなことに不正な者は、大きなことにも不正である。</span></span>

<span className="v" id="v12" data-v="12" data-xref="ルカ 19:13–26; マタイ 25:14–29; ヨブ記 1:21"> <span className="woj">他人のものに忠実でなかったなら、だれがあなたがた自身のものを与えるだろう。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの手紙第一 2:15–16; マタイ 6:24; ヤコブの手紙 4:4"> <span className="woj">どんなしもべも二人の主人に仕えることはできない。一方を憎んで他方を愛するか、一方に忠実で他方を軽んじるからである。神とマモンの両方に仕えることはできない。」</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「マモン」は富、または富を神格化した偽りの神を指す。">c</a></sup></span>

<span className="v" id="v15" data-v="15" data-xref="サムエル記第一 16:7; 箴言 21:2; コリント人への第一の手紙 4:5"> イエスは彼らに言った。<span className="woj">「あなたがたは人々の前で自分を正しいとする者だが、神は心を知っておられる。人々の間で尊ばれるものは、神の前では忌まわしいからである。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="マタイ 11:9–14; マタイ 21:32; 使徒の働き 3:24–25"> <span className="woj">「律法と預言者はヨハネまでである。それ以来、神の王国の福音が宣べ伝えられ、だれもが力ずくでそこに入ろうとしている。</span></span>
<span className="v" id="v17" data-v="17" data-xref="マタイ 5:18; ルカ 21:33; ペテロの手紙第一 1:25"> <span className="woj">しかし、律法の一画が落ちるより、天地が過ぎ去るほうがたやすい。</span></span>

<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="マタイ 19:9; マルコ 10:11–12; マタイ 5:31–32"> <span className="woj">「妻と離婚して別の女と結婚する者は皆、姦淫を犯す。夫と離婚した女と結婚する者も姦淫を犯す。</span></span>
</div>
<div className="bp">

<span className="v" id="v21" data-v="21" data-xref="マタイ 15:27; マルコ 7:28; ヨハネ 6:12"> <span className="woj">金持ちの食卓から落ちるパンくずで腹を満たしたいと願っていた。そのうえ犬まで来て、できものをなめていた。</span></span>

<span className="v" id="v23" data-v="23" data-xref="ペテロの第二の手紙 2:4; ルカ 16:28; マタイ 18:9"> <span className="woj">金持ちはハデスで</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="または「地獄」">d</a></sup><span className="woj">苦しみながら目を上げると、遠くにアブラハムと、その懐にいるラザロが見えた。</span></span>

</div>
<div className="bp">

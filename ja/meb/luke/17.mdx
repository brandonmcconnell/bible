<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 18:7; ローマ人への手紙 14:13; コリント人への第一の手紙 11:19"> イエスは弟子たちに言った。<span className="woj">「つまずきが起こるのは避けられない。しかし、それをもたらす者には災いがある。</span></span>
<span className="v" id="v2" data-v="2" data-xref="マルコ 9:42; マタイ 18:14; マタイ 18:3–6"> <span className="woj">この小さな者たちの一人をつまずかせるよりは、ひき臼を首にかけられて海に投げ込まれるほうが、その者にとってよい。</span></span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 19:17; マタイ 18:21; マタイ 18:15–17"> <span className="woj">自分自身に気をつけなさい。兄弟があなたに対して罪を犯したなら、戒めなさい。悔い改めたなら、赦しなさい。</span></span>
<span className="v" id="v4" data-v="4" data-xref="コロサイ人への手紙 3:12–13; マタイ 18:21–22; ローマ人への手紙 12:20"> <span className="woj">一日に七度あなたに対して罪を犯し、七度戻って来て、『悔い改めます』と言うなら、赦しなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="マルコ 9:24; ヘブル人への手紙 12:2; ピリピ人への手紙 4:13"> 使徒たちは主に言った。「私たちの信仰を増してください。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="マタイ 17:20; マタイ 21:21; マルコ 9:23"> 主は言った。<span className="woj">「もしあなたがたに、からし種一粒ほどの信仰があれば、この桑の木に『根こそぎ抜けて、海に植われ』と言えば、あなたがたに従うだろう。</span></span>
<span className="v" id="v7" data-v="7" data-xref="マタイ 12:11; ルカ 13:15; ルカ 14:5"> <span className="woj">あなたがたのうち、畑を耕すか羊を飼うしもべを持つ人が、しもべが畑から帰って来た時、『すぐに来て、食卓に着きなさい』と言うだろうか。</span></span>
<span className="v" id="v8" data-v="8" data-xref="ルカ 12:37; 創世記 43:16; サムエル記第二 12:20"> <span className="woj">むしろ、『私の夕食を用意し、きちんと身支度をして、私が食べたり飲んだりする間、給仕しなさい。その後で、あなたも食べたり飲んだりしなさい』と言うのではないか。</span></span>
<span className="v" id="v9" data-v="9"> <span className="woj">命じられたことをしたからといって、そのしもべに感謝するだろうか。そうは思わない。</span></span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 9:16–17; ヨブ記 22:2–3; ペテロの手紙第一 5:5–6"> <span className="woj">同じように、あなたがたも命じられたことをすべて行った時には、『私たちは取るに足りないしもべです。なすべきことをしただけです』と言いなさい。」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ルカ 9:51–52; ヨハネ 4:3–4"> イエスはエルサレムへ向かう途中、サマリアとガリラヤの境を通っていた。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 13:45–46; ルカ 5:12; 列王記第二 7:3"> ある村に入ると、十人の重い皮膚病の人がイエスを迎えた。彼らは遠く離れて立ち、</span>
<span className="v" id="v13" data-v="13" data-xref="マタイ 15:22; マタイ 20:30–31; マタイ 9:27"> 声を張り上げて言った。「イエス様、先生、私たちをあわれんでください。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ルカ 5:14; レビ記 13:1–46; 列王記第二 5:14"> イエスは彼らを見て言った。<span className="woj">「行って、自分の体を祭司たちに見せなさい。」</span>彼らは行く途中で清められた。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 30:11–12; 詩篇 103:1–4; 詩篇 118:18–19"> そのうちの一人は、自分が癒やされたのを見ると、大声で神に栄光を帰しながら戻って来た。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 8:5–25; マタイ 10:5; ヨハネの黙示録 19:10"> そしてイエスの足もとにひれ伏して感謝した。彼はサマリア人であった。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 1:21; 詩篇 106:13; 創世記 3:9"> イエスは答えた。<span className="woj">「清められたのは十人ではなかったか。九人はどこにいるのか。</span></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 50:23; マタイ 15:24–28; 詩篇 106:13"> <span className="woj">この外国人のほかに、神に栄光を帰すために戻って来た者はいなかったのか。」</span></span>
<span className="v" id="v19" data-v="19" data-xref="ルカ 7:50; ルカ 8:48; マルコ 10:52"> それから彼に言った。<span className="woj">「立って行きなさい。あなたの信仰があなたを癒やした。」</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヨハネ 18:36; ルカ 19:11; ダニエル書 2:44"> 神の王国はいつ来るのかとパリサイ人たちに尋ねられた時、イエスは答えた。<span className="woj">「神の王国は、人の目に明らかな形で来るのではない。</span></span>
<span className="v" id="v21" data-v="21" data-xref="マタイ 12:28; ローマ人への手紙 14:17; マルコ 13:21"> <span className="woj">『見よ、ここにある』とか、『見よ、あそこにある』とも言わない。見よ、神の王国はあなたがたのただ中にある。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ルカ 5:35; マタイ 9:15; ヨハネ 8:21–24"> また弟子たちに言った。<span className="woj">「人の子の日を一日でも見たいと願う日が来る。しかし、見ることはできない。</span></span>
<span className="v" id="v23" data-v="23" data-xref="ルカ 21:8; マタイ 24:23–26; ルカ 17:21"> <span className="woj">人々はあなたがたに、『見よ、ここだ』とか、『見よ、あそこだ』と言うだろう。しかし、出て行って彼らについて行ってはならない。</span></span>
<span className="v" id="v24" data-v="24" data-xref="マタイ 24:27; マタイ 24:30; マラキ書 4:1–2"> <span className="woj">稲妻がひらめくと、空の一方からもう一方まで照らすように、人の子もその日にはそのようになるからである。</span></span>
<span className="v" id="v25" data-v="25" data-xref="マタイ 16:21; ルカ 9:22; マルコ 8:31"> <span className="woj">しかし、まず人の子は多くの苦しみを受け、この世代から退けられなければならない。</span></span>
<span className="v" id="v26" data-v="26" data-xref="マタイ 24:37–39; ルカ 17:24; 創世記 7:7–23"> <span className="woj">ノアの日々に起こったように、人の子の日々にも同じことが起こる。</span></span>
<span className="v" id="v27" data-v="27" data-xref="ルカ 12:19–20; テサロニケ人への手紙第一 5:1–3; ルカ 16:19–23"> <span className="woj">ノアが箱舟に入るその日まで、人々は食べ、飲み、めとり、嫁いでいた。そこへ洪水が来て、彼らをことごとく滅ぼした。</span></span>
<span className="v" id="v28" data-v="28" data-xref="エゼキエル書 16:49–50; 創世記 18:20–21; ヤコブの手紙 5:1–5"> <span className="woj">ロトの日々にも同じことが起こった。人々は食べ、飲み、買い、売り、植え、建てていた。</span></span>
<span className="v" id="v29" data-v="29" data-xref="ペテロの第二の手紙 2:6; ゼパニヤ書 2:9; ユダ 1:7"> <span className="woj">しかし、ロトがソドムから出た日に、天から火と硫黄が降って来て、彼らをことごとく滅ぼした。</span></span>
<span className="v" id="v30" data-v="30" data-xref="コリント人への第一の手紙 1:7; テサロニケ人への第二の手紙 1:7; ヨハネの黙示録 1:7"> <span className="woj">人の子が現れる日にも、同じようになる。</span></span>
<span className="v" id="v31" data-v="31" data-xref="ルカ 21:21; マルコ 13:14–16; エレミヤ書 45:5"> <span className="woj">その日、屋上にいる者は、家の中に家財があっても、それを取り出すために下りてはならない。同じように、畑にいる者も後ろを振り返ってはならない。</span></span>
<span className="v" id="v32" data-v="32" data-xref="創世記 19:26; ヘブル人への手紙 10:38–39; ペテロの第二の手紙 2:18–22"> <span className="woj">ロトの妻を思い出しなさい。</span></span>
<span className="v" id="v33" data-v="33" data-xref="マルコ 8:35–37; マタイ 10:39; ヨハネ 12:25"> <span className="woj">自分の命を救おうとする者はそれを失い、自分の命を失う者はそれを保つ。</span></span>
<span className="v" id="v34" data-v="34" data-xref="マタイ 24:40–41; ペテロの第二の手紙 2:9; マラキ書 3:16–18"> <span className="woj">あなたがたに言う。その夜、一つの寝床に二人がいる。一人は取られ、もう一人は残される。</span></span>
<span className="v" id="v35" data-v="35" data-xref="マタイ 24:41; 出エジプト記 11:5; 士師記 16:21"> <span className="woj">二人の女が一緒にひき臼をひいている。一人は取られ、もう一人は残される。」</span></span>
<span className="v" id="v36" data-v="36"> <sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="いくつかのギリシャ語写本には、「二人が畑にいる。一人は取られ、もう一人は残される」が加えられている。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="マタイ 24:28; ヨブ記 39:29–30; ヨハネの黙示録 19:17–18"> 弟子たちは答えて尋ねた。「主よ、どこでですか。」<br />イエスは彼らに言った。<span className="woj">「死体のある所には、はげわしも集まる。」</span></span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカ 3:1; マタイ 24:14; 使徒の働き 25:21"> そのころ、皇帝アウグストゥスから、全世界の住民登録をせよとの勅令が出た。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカ 3:1; マタイ 4:24; 使徒の働き 26:30"> これは、キリニウスがシリアの総督であった時に行われた最初の住民登録である。</span>
<span className="v" id="v3" data-v="3"> 人々は皆、登録するため、それぞれ自分の町へ向かった。</span>
<span className="v" id="v4" data-v="4" data-xref="ミカ書 5:2; ヨハネ 7:42; サムエル記第一 16:1"> ヨセフもガリラヤの町ナザレを出て、ユダヤにあるダビデの町、ベツレヘムへ上って行った。彼がダビデの家系に属していたからである。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 22:22–27; マタイ 1:18–19"> 身ごもっていた婚約者のマリアとともに登録するためであった。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="詩篇 33:11; ヨハネの黙示録 12:1–5; ミカ書 5:2"> 二人がそこにいる間に、彼女の出産の日が来た。</span>
<span className="v" id="v7" data-v="7" data-xref="ガラテヤ人への手紙 4:4; コリント人への第二の手紙 8:9; イザヤ書 53:2–3"> 彼女は初子の男の子を産み、布にくるんで飼い葉桶に寝かせた。宿屋には彼らの泊まる場所がなかったからである。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="創世記 31:39–40; 詩篇 78:70–71; サムエル記第一 17:34–35"> その地方では、羊飼いたちが野宿をしながら、夜通し羊の群れの番をしていた。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 60:1; コリント人への第二の手紙 3:18; 列王記第一 8:11"> 見よ、主の使いが彼らのそばに立ち、主の栄光が周囲を照らしたので、彼らは非常に恐れた。</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 40:9; イザヤ書 61:1; イザヤ書 52:7"> 御使いは彼らに言った。「恐れることはない。見よ、私は民全体に大きな喜びをもたらす良い知らせを、あなたがたに伝える。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 9:6; マタイ 1:21; 使徒の働き 2:36"> 今日、ダビデの町で、あなたがたのために救い主がお生まれになった。この方こそ主であるキリスト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「キリスト」は「油を注がれた者」という意味である。">a</a></sup>である。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 7:14; イザヤ書 53:1–2; イザヤ書 7:11"> あなたがたへのしるしはこれである。布にくるまれ、飼い葉桶に寝かされている乳飲み子を見つける。」</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 103:20–21; ヨハネの黙示録 5:11; 詩篇 148:2"> すると突然、その御使いとともに天の軍勢が大勢現れ、神を賛美して言った。</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 5:1; ルカ 19:38; コロサイ人への手紙 1:20"> <span className="pl pl-1">「いと高き所では神に栄光、</span><br /><span className="pl pl-2">地には平和、人々には好意。」</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ペテロの手紙第一 3:22; マタイ 2:1–2; マタイ 2:9–11"> 御使いたちが彼らを離れて天へ去ると、羊飼いたちは互いに言った。「さあ、ベツレヘムへ行って、主が知らせてくださったこの出来事を見よう。」</span>
<span className="v" id="v16" data-v="16" data-xref="ルカ 19:32; ルカ 2:12; ルカ 2:7"> 彼らは急いで行き、マリアとヨセフ、そして飼い葉桶に寝ている乳飲み子を見つけた。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 66:16; ルカ 8:39; 詩篇 71:17–18"> それを見ると、この幼子について自分たちに告げられた言葉を広く知らせた。</span>
<span className="v" id="v18" data-v="18" data-xref="ルカ 2:47; ルカ 4:36; ルカ 1:65–66"> それを聞いた人々は皆、羊飼いたちが語ったことを不思議に思った。</span>
<span className="v" id="v19" data-v="19" data-xref="ルカ 2:51; ルカ 1:66; 箴言 4:4"> しかしマリアは、これらの言葉をすべて心に納め、思い巡らしていた。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 106:48; イザヤ書 29:19; 使徒の働き 11:18"> 羊飼いたちは、聞いたり見たりしたことがすべて告げられたとおりだったので、神に栄光を帰し、賛美しながら帰って行った。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ルカ 1:31; 創世記 17:12; ガラテヤ人への手紙 4:4–5"> 幼子に割礼を施す八日目が満ちると、その子はイエスと名づけられた。それは、胎内に宿る前に御使いがつけた名であった。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="レビ記 12:1–8"> モーセの律法による彼らの清めの日々が満ちると、両親は幼子を主にささげるため、エルサレムに連れて行った。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 13:2; 出エジプト記 22:29; 民数記 3:13"> 主の律法に「胎を初めに開く男子は皆、主のために聖なる者と呼ばれる」と書かれているとおりである。</span>
<span className="v" id="v24" data-v="24" data-xref="レビ記 12:6–8; レビ記 12:2; コリント人への第二の手紙 8:9"> また、主の律法に言われているとおり、「山鳩一つがい、または家鳩のひな二羽」をいけにえとしてささげるためであった。</span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 25:9; ルカ 2:38; ルカ 1:6"> 見よ、エルサレムにシメオンという人がいた。この人は正しく敬虔で、イスラエルの慰めを待ち望んでいた。聖霊が彼の上におられた。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネ 8:51; ヘブル人への手紙 11:5; ルカ 9:27"> 彼は、主のキリストを見るまでは死ぬことはないと、聖霊から示されていた。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「キリスト」（ギリシャ語）と「メシア」（ヘブル語）は、ともに「油を注がれた者」という意味である。">b</a></sup></span>
<span className="v" id="v27" data-v="27" data-xref="マタイ 4:1; ルカ 2:41; ルカ 2:51"> 彼は聖霊に導かれて神殿に入った。両親が、律法の慣習に従って幼子イエスのために行うべきことをしようと、幼子を連れて来ると、</span>
<span className="v" id="v28" data-v="28" data-xref="ルカ 1:64; ルカ 2:20; ルカ 2:13–14"> シメオンは幼子を腕に抱き、神をほめたたえて言った。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの黙示録 14:13; 創世記 15:15; ピリピ人への手紙 1:23"> <span className="pl pl-1">「主よ、今こそ、あなたの言葉どおり、</span><br /><span className="pl pl-2">仕える者を安らかに去らせてくださいます。</span></span>
<span className="v" id="v30" data-v="30" data-xref="イザヤ書 49:6; ルカ 2:10–11; ルカ 3:6"> <span className="pl pl-1">私の目が、あなたの救いを見たからです。</span></span>
<span className="v" id="v31" data-v="31" data-xref="イザヤ書 62:1–2; イザヤ書 42:1–4; 詩篇 98:2–3"> <span className="pl pl-2">これはあなたが、すべての民の前に備えられたもの、</span></span>
<span className="v" id="v32" data-v="32" data-xref="イザヤ書 60:1–3; イザヤ書 49:6; 使徒の働き 26:23"> <span className="pl pl-1">異邦人を照らす啓示の光、</span><br /><span className="pl pl-2">あなたの民イスラエルの栄光です。」</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="ルカ 1:65–66; イザヤ書 8:18; ルカ 2:48"> ヨセフとその母は、幼子について語られたことに驚いていた。</span>
<span className="v" id="v34" data-v="34" data-xref="コリント人への第一の手紙 1:23; ペテロの手紙第一 2:7–8; イザヤ書 8:14–15"> シメオンは彼らを祝福し、母マリアに言った。「見よ、この子は、イスラエルの多くの人を倒れさせ、また立ち上がらせるために定められ、反対を受けるしるしとなる。</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 8:2; コリント人への第一の手紙 11:19; マタイ 12:24–35"> そして剣があなた自身の心をも刺し貫く。それは、多くの人の心の思いが明らかにされるためである。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="出エジプト記 15:20; 創世記 30:13; 使徒の働き 21:9"> また、アシェル族のファヌエルの娘で、アンナという女預言者がいた。彼女は非常に年を取っており、処女の時から七年間、夫と暮らした後、</span>
<span className="v" id="v37" data-v="37" data-xref="テモテへの手紙第一 5:5; 詩篇 23:6; 使徒の働き 14:23"> 約八十四年間、やもめであった。彼女は神殿を離れず、断食と祈願をもって夜も昼も礼拝していた。</span>
<span className="v" id="v38" data-v="38" data-xref="ルカ 2:25; コリント人への第二の手紙 9:15; マルコ 15:43"> ちょうどその時、彼女も近寄って来て主に感謝をささげ、エルサレムの贖いを待ち望んでいたすべての人に、この幼子のことを語った。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="ルカ 2:4; ガラテヤ人への手紙 4:4–5; 申命記 12:32"> 両親は主の律法に従ってすべてを行い終えると、ガリラヤの自分たちの町ナザレへ帰った。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカ 2:52; ルカ 1:80; イザヤ書 11:1–5"> 幼子は成長し、霊において強くなり、知恵に満たされていった。神の恵みがその上にあった。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="出エジプト記 12:14; 民数記 28:16; 申命記 12:18"> 両親は毎年、過越の祭りにエルサレムへ行っていた。</span>
<span className="v" id="v42" data-v="42"> イエスが十二歳になった時も、祭りの慣習に従ってエルサレムへ上った。</span>
<span className="v" id="v43" data-v="43" data-xref="歴代誌 第二 30:21–23; 出エジプト記 12:15; 歴代誌 第二 25:17"> 祭りの日々を終えて帰る途中、少年イエスはエルサレムに残っていたが、ヨセフとその母はそれに気づかなかった。</span>
<span className="v" id="v44" data-v="44" data-xref="詩篇 122:1–4; イザヤ書 2:3; 詩篇 42:4"> 一行の中にいるものと思い、一日分の道のりを進んでから、親族や知人の間を捜した。</span>
<span className="v" id="v45" data-v="45"> しかし見つからなかったので、捜しながらエルサレムへ引き返した。</span>
<span className="v" id="v46" data-v="46" data-xref="ルカ 5:17; イザヤ書 49:1–2; イザヤ書 50:4"> 三日後、二人は神殿でイエスを見つけた。イエスは教師たちの真ん中に座り、彼らの話を聞いたり質問したりしていた。</span>
<span className="v" id="v47" data-v="47" data-xref="マタイ 7:28; ルカ 4:32; 詩篇 119:99"> 聞いていた人々は皆、その理解力と答えに驚いていた。</span>
<span className="v" id="v48" data-v="48" data-xref="ルカ 2:49; マタイ 12:46; ルカ 3:23"> 両親はイエスを見て驚き、母は言った。「息子よ、どうして私たちにこんなことをしたのですか。見よ、お父さんと私は心配してあなたを捜していたのです。」</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="ヨハネ 6:38; ヨハネ 8:29; マラキ書 3:1"> イエスは二人に言った。<span className="woj">「どうして私を捜したのですか。私が父の家にいなければならないことを、知らなかったのですか。」</span></span>
<span className="v" id="v50" data-v="50" data-xref="ルカ 18:34; ルカ 9:45; マルコ 9:32"> しかし二人には、イエスの語った言葉が理解できなかった。</span>
<span className="v" id="v51" data-v="51" data-xref="ルカ 2:19; ダニエル書 7:28; 創世記 37:11"> イエスは二人とともに下ってナザレへ行き、彼らに従って暮らした。母はこれらの言葉をすべて心に納めていた。</span>
<span className="v" id="v52" data-v="52" data-xref="ルカ 2:40; 箴言 3:3–4; サムエル記第一 2:26"> イエスは知恵と背丈を増し、神と人々からますます好意を受けていった。</span>
</div>

<div className="bp poetry">
<span className="v" id="v1" data-v="1"> そこでヨブは主に答えた。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 19:26; マルコ 10:27; 創世記 18:14"> <span className="pl pl-1">私は、あなたがすべてのことをなし得ること、</span><br /><span className="pl pl-2">あなたの計画は一つも妨げられないことを知った。</span></span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 131:1; 詩篇 139:6; ヨブ記 38:2"> <span className="pl pl-1">あなたは尋ねられた。『知識もないのに計り事を暗くするこの者は誰か』</span><br /><span className="pl pl-2">それゆえ私は、自分の理解できないこと、</span><br /><span className="pl pl-2">私にはあまりに驚くべき、知らないことを語った。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ヨブ記 40:7; ヨブ記 38:3; 創世記 18:30–32"> <span className="pl pl-1">あなたは言われた。『さあ聞け、私が語ろう。</span><br /><span className="pl pl-2">私があなたに尋ねるから、私に答えよ。』</span></span>
<span className="v" id="v5" data-v="5" data-xref="エペソ人への手紙 1:17–18; ローマ人への手紙 10:17; ヨハネ 12:45"> <span className="pl pl-1">私はあなたのことを耳で聞いていた。</span><br /><span className="pl pl-2">しかし今、この目があなたを見た。</span></span>
<span className="v" id="v6" data-v="6" data-xref="エズラ記 9:6; テモテへの手紙第一 1:13–16; ヤコブの手紙 4:7–10"> <span className="pl pl-1">それゆえ私は自分を忌み、</span><br /><span className="pl pl-2">ちりと灰の中で悔い改める。</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨブ記 11:5–6; ヨブ記 32:2–3; ヨブ記 32:5"> さて、主がこれらの言葉をヨブに語られた後、主はテマン人エリファズに言った。「私の怒りは、あなたと二人の友に向かって燃えている。あなたがたが私のしもべヨブのように、私について正しく語らなかったからだ。</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 23:1; ヤコブの手紙 5:16; 詩篇 103:10"> だから今、七頭の雄牛と七頭の雄羊を取って私のしもべヨブのところに行き、自分たちのために全焼のささげ物をささげよ。そして、私のしもべヨブがあなたがたのために祈る。私は彼を受け入れる。そうすれば、あなたがたを愚かさに応じて扱わない。あなたがたが私のしもべヨブのように、私について正しく語らなかったからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヘブル人への手紙 11:8; 使徒の働き 9:6; 使徒の働き 10:33"> そこでテマン人エリファズ、シュア人ビルダデ、ナアマ人ツォファルは行って、主が彼らに命じられたとおりにした。そして主はヨブを受け入れた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命記 30:3; ヨブ記 8:6–7; 箴言 22:4"> ヨブが友たちのために祈ったとき、主はヨブの境遇を回復された。主はヨブに、以前の二倍のものを与えられた。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨブ記 2:11; ヨブ記 19:13–14; 箴言 16:7"> それから、彼のすべての兄弟、すべての姉妹、以前から彼を知っていたすべての人々が彼のもとに来て、彼の家でともにパンを食べた。彼らは、主が彼にもたらしたすべての災いについて、彼をいたわり、慰めた。また彼らは皆、彼に一枚の貨幣<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="文字通りには「ケシタ」。おそらく銀の貨幣単位である。">a</a></sup>と、一つの金の指輪を与えた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨブ記 8:7; 伝道者の書 7:8; 箴言 10:22"> こうして主は、ヨブの後半の生涯を初めよりも豊かに祝福された。彼は一万四千頭の羊、六千頭のらくだ、千くびきの牛、千頭の雌ろばを持った。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨブ記 1:2; 詩篇 107:41; 詩篇 127:3"> 彼にはまた、七人の息子と三人の娘がいた。</span>
<span className="v" id="v14" data-v="14"> 彼は第一の娘をエミマ、第二の娘をケツィア、第三の娘をケレン・ハプクと名付けた。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 27:7; 詩篇 144:12; 使徒の働き 7:20"> その地のどこにも、ヨブの娘たちほど美しい女は見当たらなかった。父は兄弟たちと同じように、彼女たちにも相続地を与えた。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 17:6; 詩篇 128:6; 創世記 50:23"> この後、ヨブは百四十年生き、息子たちとその子孫を四代にわたって見た。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 25:8; 創世記 15:15; ヨブ記 5:26"> こうしてヨブは年老い、長寿を全うして死んだ。</span>
</div>

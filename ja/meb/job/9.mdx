<span className="v" id="v1" data-v="1"> そこでヨブは答えた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨブ記 4:17; ローマ人への手紙 3:20; ヨブ記 25:4"> <span className="pl pl-1">まことに、私はそれがその通りであることを知っている。</span><br /><span className="pl pl-2">しかし、人がどうして神の前で義とされようか。</span></span>
<span className="v" id="v3" data-v="3" data-xref="ヨブ記 10:2; ヨブ記 40:2; イザヤ書 57:15–16"> <span className="pl pl-1">もし人が神と争うことを望んでも、</span><br /><span className="pl pl-2">千に一つも神に答えることはできない。</span></span>

<span className="v" id="v5" data-v="5" data-xref="マタイ 27:51; ルカ 21:11; ハバクク書 3:10"> <span className="pl pl-1">神は山々を移されるが、山々はそれを知らない。</span><br /><span className="pl pl-2">怒りのうちにそれらを覆す。</span></span>
<span className="v" id="v6" data-v="6" data-xref="ハガイ書 2:6; ヘブル人への手紙 12:26; 詩篇 75:3"> <span className="pl pl-1">神は地をその場所から揺り動かされる。</span><br /><span className="pl pl-2">その柱は震える。</span></span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 13:10; アモス書 8:9; ルカ 21:25–26"> <span className="pl pl-1">神が太陽に命じられると、それは昇らず、</span><br /><span className="pl pl-2">星々を封じられる。</span></span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 44:24; イザヤ書 40:22; 詩篇 104:2–3"> <span className="pl pl-1">神はただ独りで天を広げ、</span><br /><span className="pl pl-2">海の大波の上を歩かれる。</span></span>
<span className="v" id="v9" data-v="9" data-xref="アモス書 5:8; 創世記 1:16; ヨブ記 38:31–41"> <span className="pl pl-1">神は北斗七星、オリオン、プレアデス、</span><br /><span className="pl pl-2">そして南の星座の部屋を造られる。</span></span>
<span className="v" id="v10" data-v="10" data-xref="ヨブ記 5:9; 詩篇 72:18; エペソ人への手紙 3:20"> <span className="pl pl-1">神は測り知れない大いなることを行い、</span><br /><span className="pl pl-2">まことに数え切れない不思議なことを行われる。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ヨブ記 23:8–9; ヨブ記 35:14; 詩篇 77:19"> <span className="pl pl-1">見よ、神は私のそばを通られるが、私は神を見ない。</span><br /><span className="pl pl-2">神はまた通り過ぎて行かれるが、私は神に気づかない。</span></span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 45:9; ヨブ記 11:10; ヨブ記 23:13"> <span className="pl pl-1">見よ、神は奪い去られる。</span><br /><span className="pl pl-2">誰が神を妨げることができようか。</span><br /><span className="pl pl-2">誰が神に『何をなさるのか』と問えよう。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="詩篇 89:10; ヨブ記 26:12; イザヤ書 30:7"> <span className="pl pl-1">神はその怒りを収めない。</span><br /><span className="pl pl-2">ラハブの助け手たちは神の下に身をかがめる。</span></span>
<span className="v" id="v14" data-v="14" data-xref="列王記第一 8:27; ヨブ記 9:3; ヨブ記 4:19"> <span className="pl pl-1">まして、私がどうして神に答え、</span><br /><span className="pl pl-2">神と論じ合うために言葉を選べるだろうか。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ヨブ記 10:15; ヨブ記 8:5; ヨブ記 10:2"> <span className="pl pl-1">たとえ私が義であったとしても、私は神に答えないだろう。</span><br /><span className="pl pl-2">私は私の裁き主に願い求めるのみである。</span></span>
<span className="v" id="v16" data-v="16" data-xref="ヨブ記 29:24; 出エジプト記 6:9; 詩篇 66:18–20"> <span className="pl pl-1">もし私が呼びかけて、神が私に答えられたとしても、</span><br /><span className="pl pl-2">神が私の声に耳を傾けられたとは私は信じない。</span></span>
<span className="v" id="v17" data-v="17" data-xref="ヨブ記 16:14; ヨブ記 2:3; ヨブ記 34:6"> <span className="pl pl-1">神は嵐で私を打ち砕き、</span><br /><span className="pl pl-2">理由もなく私の傷を増し加えられるからだ。</span></span>
<span className="v" id="v18" data-v="18" data-xref="ヨブ記 7:19; 哀歌 3:15; 詩篇 88:15–18"> <span className="pl pl-1">神は私に息をつかせず、</span><br /><span className="pl pl-2">苦しみで満たす。</span></span>
<span className="v" id="v19" data-v="19" data-xref="ヨブ記 9:32–33; ヨブ記 9:4; コリント人への第一の手紙 1:25"> <span className="pl pl-1">もし力のことなら、見よ、神は力強い。</span><br /><span className="pl pl-2">もし裁きのことなら、『誰が私を呼び出すのか』と神は言われる。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ヨブ記 15:5–6; ピリピ人への手紙 3:12–15; 詩篇 143:2"> <span className="pl pl-1">たとえ私が義であったとしても、私自身の口が私を罪に定める。</span><br /><span className="pl pl-2">たとえ私が咎のない者であっても、私の口は私を曲がった者とする。</span></span>
<span className="v" id="v21" data-v="21" data-xref="ヨブ記 1:1; 詩篇 139:23–24; 箴言 28:26"> <span className="pl pl-1">私は咎のない者だ。</span><br /><span className="pl pl-2">私は自分自身を顧みない。</span><br /><span className="pl pl-2">私は自分の命を忌み嫌う。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="伝道者の書 9:1–3; ルカ 13:2–4; ヨブ記 10:8"> <span className="pl pl-1">それはみな同じだ。</span><br /><span className="pl pl-2">だから私は言う。神は咎のない者も悪者も滅ぼされると。</span></span>
<span className="v" id="v23" data-v="23" data-xref="ヨブ記 24:12; ヨブ記 1:13–19; ヨブ記 4:7"> <span className="pl pl-1">むちが突然殺すとき、</span><br /><span className="pl pl-2">神は罪のない者の絶望をあざ笑う。</span></span>
<span className="v" id="v24" data-v="24" data-xref="ヨブ記 10:3; エレミヤ書 12:1–2; 詩篇 73:3–7"> <span className="pl pl-1">地は悪者の手に渡されている。</span><br /><span className="pl pl-2">神はその地の裁き司たちの顔を覆う。</span><br /><span className="pl pl-2">もし神ではないなら、一体誰なのか。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="ヨブ記 7:6–7; ヤコブの手紙 4:14; 詩篇 90:9–10"> <span className="pl pl-1">今、私の日々は走る者よりも速い。</span><br /><span className="pl pl-2">それらは逃げ去り、良いことを見ない。</span></span>
<span className="v" id="v26" data-v="26" data-xref="ハバクク書 1:8; イザヤ書 18:2; ヨブ記 39:27–30"> <span className="pl pl-1">それらは葦の小舟のように過ぎ去った。</span><br /><span className="pl pl-2">獲物に飛びかかる鷲のように。</span></span>
<span className="v" id="v27" data-v="27" data-xref="ヨブ記 7:13; エレミヤ書 8:18; ヨブ記 7:11"> <span className="pl pl-1">もし私が、『自分の不平を忘れよう。</span><br /><span className="pl pl-2">悲しい顔を捨てて、明るくしよう』と言っても、</span></span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 119:120; 詩篇 88:15–16; ヨブ記 21:6"> <span className="pl pl-1">私はすべての悲しみを恐れる。</span><br /><span className="pl pl-2">私は、あなたが私を罪のない者とはされないことを知っている。</span></span>
<span className="v" id="v29" data-v="29" data-xref="ヨブ記 10:7; ヨブ記 21:27; ヨブ記 10:14–17"> <span className="pl pl-1">私は罪に定められる。</span><br /><span className="pl pl-2">それならなぜ、私はむなしく労苦するのか。</span></span>
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 2:22; 詩篇 26:6; ヨハネの手紙第一 1:8"> <span className="pl pl-1">たとえ私が雪の水で身を洗い、</span><br /><span className="pl pl-2">灰汁で手をきよめたとしても、</span></span>

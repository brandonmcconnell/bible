<span className="v" id="v2" data-v="2" data-xref="ピリピ人への手紙 2:29; ピリピ人への手紙 1:27; マタイ 10:40–42"> どうか聖徒にふさわしく、主にあって彼女を迎え、あなたがたの助けを必要とすることがあれば、何でも助けてください。彼女自身、多くの人を助け、私をも助けてくれたからです。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="コリント人への第一の手紙 16:19; テモテへの第二の手紙 4:19; 使徒の働き 18:26"> キリスト・イエスにあって私の同労者であるプリスカとアキラに、よろしく伝えてください。</span>
<span className="v" id="v4" data-v="4" data-xref="ピリピ人への手紙 2:30; ヨハネの手紙第一 3:16; コリント人への第一の手紙 16:1"> 二人は私の命のために、自分の首を差し出すほどの危険を冒してくれました。二人に感謝しているのは私だけでなく、異邦人のすべての教会も同じです。</span>
<span className="v" id="v5" data-v="5" data-xref="コロサイ人への手紙 4:15; フィレモンへの手紙 1:2; コリント人への第一の手紙 16:19"> また、二人の家にある教会にも、よろしく伝えてください。私の愛するエパイネトにも、よろしく伝えてください。彼はアカイアでキリストに献げられた初穂です。</span>
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 16:12; マタイ 27:55; テモテへの手紙第一 5:10"> 私たちのために大いに労苦したマリアに、よろしく伝えてください。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 16:11; ローマ人への手紙 16:21; フィレモンへの手紙 1:23"> 私の同族であり、共に投獄されたアンドロニコとユニアに、よろしく伝えてください。二人は使徒たちの間で名高い人々であり、<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または「使徒たちによく知られており」">b</a></sup>私より先にキリストにある者となりました。</span>
<span className="v" id="v8" data-v="8" data-xref="ピリピ人への手紙 4:1; ヨハネの手紙第一 3:14; ローマ人への手紙 16:5"> 主にあって私の愛するアンプリアスに、よろしく伝えてください。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 16:2–3; ローマ人への手紙 16:21"> キリストにあって私たちの同労者であるウルバノと、私の愛するスタキスに、よろしく伝えてください。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 14:18; ペテロの手紙第一 1:7; 申命記 8:2"> キリストにあって認められているアペレスに、よろしく伝えてください。アリストブロの家の人々にも、よろしく伝えてください。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 16:21; ローマ人への手紙 16:7"> 私の同族ヘロディオンに、よろしく伝えてください。ナルキソの家のうち、主にある人々にも、よろしく伝えてください。</span>
<span className="v" id="v12" data-v="12" data-xref="テサロニケ人への手紙第一 5:12–13; ヘブル人への手紙 6:10–11; コリント人への第一の手紙 15:58"> 主にあって労苦しているトリファイナとトリフォサに、よろしく伝えてください。主にあって大いに労苦した、愛するペルシスに、よろしく伝えてください。</span>
<span className="v" id="v13" data-v="13" data-xref="マルコ 15:21; テモテへの手紙第一 5:2; ヨハネの手紙第二 1:1"> 主にあって選ばれたルフォスと、その母によろしく伝えてください。彼女は私にとっても母です。</span>
<span className="v" id="v14" data-v="14" data-xref="コロサイ人への手紙 1:2; ローマ人への手紙 8:29; ヘブル人への手紙 3:1"> アシンクリト、フレゴン、ヘルメス、パトロバ、ヘルマス、および彼らと共にいる兄弟たち<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="ここや、文脈上可能な箇所で「兄弟たち」と訳された言葉は、「兄弟姉妹」または「きょうだいたち」と訳すこともできる。">c</a></sup>に、よろしく伝えてください。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 16:2; ローマ人への手紙 1:7; ローマ人への手紙 16:14"> フィロロゴとユリア、ネレウスとその姉妹、オリンパス、および彼らと共にいるすべての聖徒たちに、よろしく伝えてください。</span>
<span className="v" id="v16" data-v="16" data-xref="テサロニケ人への手紙第一 5:26; コリント人への第一の手紙 16:20; コリント人への第二の手紙 13:12"> 聖なる口づけをもって、互いにあいさつを交わしなさい。キリストの諸教会からも、あなたがたによろしくとのあいさつがあります。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ユダ 1:19; テサロニケ人への第二の手紙 3:6; テモテへの手紙第一 6:3–5"> 兄弟たち、お願いします。あなたがたが学んだ教えに反して分裂やつまずきを引き起こす人々を警戒し、その人たちから離れなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="コロサイ人への手紙 2:4; マタイ 7:15; テモテへの手紙第一 6:5"> そのような人々は、私たちの主イエス・キリストではなく、自分の腹に仕えています。そして、なめらかな言葉とへつらいによって、純真な人々の心を欺いています。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイ 10:16; コリント人への第一の手紙 14:20; ピリピ人への手紙 2:15"> あなたがたの従順は、すべての人に知られています。ですから、私はあなたがたのことを喜んでいます。しかし、あなたがたには善について賢く、悪について無垢であってほしいのです。</span>
<span className="v" id="v20" data-v="20" data-xref="ルカ 10:19; ヨハネの手紙第一 3:8; 創世記 3:15"> 平和の神は、間もなくサタンをあなたがたの足の下で打ち砕かれます。<br />私たちの主イエス・キリストの恵みが、あなたがたと共にありますように。</span>
</div>

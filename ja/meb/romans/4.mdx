<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 51:2; ローマ人への手紙 4:16; コリント人への第二の手紙 11:22"> では、私たちの先祖アブラハムは、肉によって何を得たと言うべきでしょうか。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第一の手紙 1:31; コリント人への第二の手紙 11:30; ピリピ人への手紙 3:9"> もしアブラハムが行いによって義とされたのなら、彼には誇る理由があります。しかし、神の前ではそうではありません。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 15:6; ヤコブの手紙 2:23; ガラテヤ人への手紙 3:6–8"> 聖書は何と言っていますか。「アブラハムは神を信じ、それが彼の義とみなされた。」</span>
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 11:6; ローマ人への手紙 9:32; ローマ人への手紙 11:35"> 働く人に支払われる報酬は、恵みではなく、当然受けるべきものとみなされます。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 3:9; ローマ人への手紙 3:22; テトス 3:3–7"> しかし、行いによらず、不敬虔な者を義と認める方を信じる人は、その信仰が義とみなされます。</span>
<span className="v" id="v6" data-v="6" data-xref="テモテへの第二の手紙 1:9; ピリピ人への手紙 3:9; コリント人への第一の手紙 1:30"> 同じようにダビデも、行いとは別に神から義とみなされる人の幸いを、こう語っています。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 32:1–2; 詩篇 130:3–4; ルカ 7:47–50"> <span className="pl pl-1">「不法を赦され、</span><br /><span className="pl pl-2">罪を覆われた人たちは幸いである。</span></span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 32:2; ペテロの手紙第一 2:24; コリント人への第二の手紙 5:19–20"> <span className="pl pl-1">主から決して罪を負わされない人は幸いである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ガラテヤ人への手紙 3:14; コロサイ人への手紙 3:11; ガラテヤ人への手紙 3:26–28"> では、この幸いは割礼を受けた者だけのものでしょうか。それとも、割礼を受けていない者のものでもあるのでしょうか。私たちは、「信仰がアブラハムの義とみなされた」と言っています。</span>
<span className="v" id="v10" data-v="10" data-xref="ガラテヤ人への手紙 6:15; ガラテヤ人への手紙 5:6; 創世記 17:10"> では、どのようなときに、そうみなされたのでしょう。割礼を受けていたときですか、それとも、受けていなかったときですか。割礼を受けた後ではなく、受ける前です。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 3:22; ルカ 19:9; コリント人への第二の手紙 1:22"> 彼は割礼を受けていなかったときに持っていた信仰による義の証印として、割礼のしるしを受けました。それは、割礼を受けていなくても信じるすべての人の父となり、その人たちも義とみなされるためでした。</span>
<span className="v" id="v12" data-v="12" data-xref="雅歌 1:8; ヨハネ 8:39–40; 箴言 2:20"> また彼は、割礼を受けているだけでなく、私たちの父アブラハムが割礼を受ける前に持っていた信仰の足跡をたどる人々にとっても、割礼ある者の父です。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ガラテヤ人への手紙 3:29; 創世記 22:17–18; 創世記 28:14"> アブラハムとその子孫が世界を受け継ぐという約束は、律法によるのではなく、信仰の義によるものでした。</span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 3:18–24; ピリピ人への手紙 3:9; ローマ人への手紙 4:16"> もし律法による者が相続人なら、信仰はむなしくなり、約束は無効になります。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 5:13; ガラテヤ人への手紙 3:10; ローマ人への手紙 3:19–20"> 律法は怒りをもたらします。律法のないところには、違反もないからです。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 3:24–26; エペソ人への手紙 2:8; ガラテヤ人への手紙 3:22"> ですから、約束は信仰によります。それは恵みに基づくためであり、すべての子孫に約束が保証されるためです。律法による者だけでなく、アブラハムの信仰による者にもです。アブラハムは私たちすべての父です。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 1:28; 創世記 17:4–5; ヨハネ 5:21"> 「私はあなたを多くの国民の父とした」と書かれているとおりです。彼が信じた神、すなわち、死者に命を与え、存在しないものを存在するものとして呼び出す方の前で、アブラハムは私たちすべての父なのです。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 8:24; 創世記 15:5–6; 使徒の働き 27:25"> 望み得ない状況にあっても、アブラハムはなお望みを抱いて信じました。それは、「あなたの子孫もこのようになる」と語られたとおり、多くの国民の父となるためでした。</span>
<span className="v" id="v19" data-v="19" data-xref="ヘブル人への手紙 11:11–19; ローマ人への手紙 4:20–21; 創世記 17:17"> 彼は信仰が弱ることなく、百歳ほどになってすでに衰えた自分の体にも、サラの胎が死んだも同然であることにも目を向けず、</span>
<span className="v" id="v20" data-v="20" data-xref="ルカ 1:45; コリント人への第一の手紙 16:13; ダニエル書 10:19"> 神の約束を前にして、不信仰によって揺らぐことはありませんでした。むしろ信仰によって強められ、神に栄光を帰し、</span>
<span className="v" id="v21" data-v="21" data-xref="ルカ 1:37; エレミヤ書 32:27; 創世記 18:14"> 神には約束されたことを実現する力もあると確信していました。</span>
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 4:6; ローマ人への手紙 4:3"> そのため、「それが彼の義とみなされた」のです。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への第一の手紙 10:11; ローマ人への手紙 15:4; コリント人への第一の手紙 10:6"> 「彼の義とみなされた」と書かれたのは、彼だけのためではなく、</span>
<span className="v" id="v24" data-v="24" data-xref="使徒の働き 2:24; ペテロの手紙第一 1:21; 使徒の働き 13:30"> 私たちのためでもあります。私たちの主イエスを死者の中からよみがえらせた方を信じる私たちも、義とみなされるのです。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの手紙第一 4:9–10; イザヤ書 53:5–6; コリント人への第二の手紙 5:21"> イエスは私たちの背きのために引き渡され、私たちを義とするためによみがえらされました。</span>
</div>

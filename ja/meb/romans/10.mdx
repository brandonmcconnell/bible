<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第一の手紙 9:20–22; ローマ人への手紙 9:1–3; ヨハネ 5:34"> 兄弟たち、私が心から願い、神に祈っているのは、イスラエルが救われることです。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 21:20; ローマ人への手紙 9:31–32; 箴言 19:2"> 私は、彼らが神に対して熱心であることをあかしします。しかし、その熱心さは知識に基づくものではありません。</span>
<span className="v" id="v3" data-v="3" data-xref="ピリピ人への手紙 3:9; ルカ 16:15; コリント人への第二の手紙 5:21"> 彼らは神の義を知らず、自分自身の義を打ち立てようとして、神の義に従いませんでした。</span>
<span className="v" id="v4" data-v="4" data-xref="ガラテヤ人への手紙 3:24; ローマ人への手紙 8:3–4; マタイ 5:17–18"> キリストは律法の成就<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「完成」あるいは「終わり」">a</a></sup>であり、信じるすべての人に義をもたらす方だからです。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="レビ記 18:5; エゼキエル書 20:11; ネヘミヤ記 9:29"> モーセは律法による義について、「これらを行う人は、これらによって生きる」と書いています。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 30:11–14; 箴言 30:4; エペソ人への手紙 4:8–10"> しかし、信仰による義はこう言います。「心の中で、『だれが天に上るだろうか』と言ってはならない。」それは、キリストを引き降ろすことです。</span>
<span className="v" id="v7" data-v="7" data-xref="ヘブル人への手紙 13:20; ヨハネの黙示録 1:18; ローマ人への手紙 4:25"> また、「『だれが底知れぬ所に下るだろうか』と言ってはならない。」それは、キリストを死者の中から引き上げることです。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 30:14; ローマ人への手紙 1:16–17; テモテへの手紙第一 4:6"> では、何と言っていますか。「言葉はあなたの近くにあり、あなたの口にあり、あなたの心にある。」これは、私たちが宣べ伝えている信仰の言葉です。</span>
<span className="v" id="v9" data-v="9" data-xref="ルカ 12:8; 使徒の働き 16:31; ピリピ人への手紙 2:11"> すなわち、自分の口でイエスを主と告白し、神がイエスを死者の中からよみがえらせたと心で信じるなら、あなたは救われます。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの手紙第一 4:15; ローマ人への手紙 10:9; ガラテヤ人への手紙 2:16"> 人は心で信じて義に至り、口で告白して救いに至るからです。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 28:16; ローマ人への手紙 9:33; ペテロの手紙第一 2:6"> 聖書は、「この方を信じる者は、だれも失望に終わることがない」と言っています。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="ピリピ人への手紙 4:19; ヨハネの黙示録 17:14; ガラテヤ人への手紙 3:28"> ユダヤ人とギリシャ人の間に区別はありません。同じ主がすべての人の主であり、ご自分を呼び求めるすべての人に豊かな恵みを与えてくださるからです。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 2:21; ヨエル書 2:32"> 「主の名を呼び求める者は、だれでも救われる」のです。</span>
<span className="v" id="v14" data-v="14" data-xref="マルコ 16:15–16; 使徒の働き 26:17–18; テトス 1:3"> しかし、信じていない方を、どうして呼び求められるでしょう。聞いたことのない方を、どうして信じられるでしょう。宣べ伝える人がいなければ、どうして聞けるでしょう。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 52:7; ナホム書 1:15; エペソ人への手紙 2:17"> 遣わされなければ、どうして宣べ伝えられるでしょう。こう書かれています。<br /><span className="pl pl-1">「平和の福音を宣べ伝える人々の足は、何と美しいことか。</span><br /><span className="pl pl-2">良い知らせを伝える人々の足は、何と美しいことか。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 53:1; ローマ人への手紙 3:3; ヨハネ 12:38–40"> しかし、すべての人が福音に聞き従ったわけではありません。イザヤは、「主よ、だれが私たちの知らせを信じたでしょうか」と言っています。</span>
<span className="v" id="v17" data-v="17" data-xref="ガラテヤ人への手紙 3:2; ガラテヤ人への手紙 3:5; テサロニケ人への手紙第一 2:13"> ですから、信仰は聞くことから生まれ、聞くことは神の言葉によります。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 19:4; ローマ人への手紙 1:8; マタイ 24:14"> しかし、私は尋ねます。彼らは聞かなかったのでしょうか。いいえ、確かに聞きました。<br /><span className="pl pl-1">「その声は全地に響き渡り、</span><br /><span className="pl pl-2">その言葉は世界の果てにまで届いた。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="申命記 32:21; ローマ人への手紙 11:11; ローマ人への手紙 11:14"> さらに私は尋ねます。イスラエルは知らなかったのでしょうか。まずモーセがこう言っています。<br /><span className="pl pl-1">「私は、国民でない者によって、あなたがたにねたみを起こさせる。</span><br /><span className="pl pl-2">悟りのない国民によって、あなたがたを怒らせる。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 65:1–2; ローマ人への手紙 9:30; イザヤ書 55:4–5"> また、イザヤは大胆にこう言っています。<br /><span className="pl pl-1">「私を捜さなかった者たちに、私は見いだされ、</span><br /><span className="pl pl-2">私を求めなかった者たちに、私は現れた。」</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 65:2–5; ペテロの手紙第一 2:8; エレミヤ書 35:15"> しかし、イスラエルについては、「私は一日中、従わず逆らう民に手を差し伸べた」と言っています。</span>
</div>

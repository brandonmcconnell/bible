<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 2:25–29; 創世記 25:32; 伝道者の書 6:11"> では、ユダヤ人にはどんな優位性がありますか。割礼にはどんな益がありますか。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 9:4; 使徒の働き 7:38; コリント人への第一の手紙 9:17"> あらゆる点で大いにあります。何よりもまず、彼らは神の言葉を委ねられました。</span>
<span className="v" id="v3" data-v="3" data-xref="テモテへの第二の手紙 2:13; ヘブル人への手紙 4:2; ローマ人への手紙 9:6"> では、ある者たちが信じなかったとしても、それがどうしたというのでしょう。彼らの不信仰が神の真実を無にするのでしょうか。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 51:4; 詩篇 116:11; ガラテヤ人への手紙 2:17"> 決してそうではありません。たとえすべての人が偽り者であっても、神は真実であるとされるべきです。こう書かれています。<br /><span className="pl pl-1">「あなたが語る言葉によって義とされ、</span><br /><span className="pl pl-2">裁きを受けるとき、勝利を得るためです。」</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 6:19; ガラテヤ人への手紙 3:15; ローマ人への手紙 9:18–20"> しかし、私たちの不義が神の義を明らかにするのなら、何と言えばよいでしょう。怒りを下す神は不義なのでしょうか。私は人間的な言い方をしています。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 18:25; 使徒の働き 17:31; ヨブ記 8:3"> 決してそうではありません。もしそうなら、神はどうして世界を裁けるでしょうか。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 3:4; ローマ人への手紙 9:19–20; 使徒の働き 13:27–29"> しかし、私の偽りによって神の真実がますます明らかになり、神の栄光となるのなら、なぜ私もなお罪人として裁かれるのでしょうか。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 6:1; ローマ人への手紙 6:15; ローマ人への手紙 5:20"> それなら、「善をもたらすために悪を行おう」ということになるのでしょうか。私たちがそう言っていると中傷し、実際そう主張する者もいますが、そのような者が罪に定められるのは当然です。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="ガラテヤ人への手紙 3:22; ローマ人への手紙 6:15; イザヤ書 65:5"> では、どうでしょう。私たちは彼らより優れているのでしょうか。決してそうではありません。すでに私たちが指摘したように、ユダヤ人もギリシャ人も皆、罪のもとにあります。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 53:1–3; 詩篇 14:1–3; ローマ人への手紙 3:23"> こう書かれています。<br /><span className="pl pl-1">「義人はいない。</span><br /><span className="pl pl-2">一人もいない。</span></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 14:2–4; 詩篇 53:2; テトス 3:3"> <span className="pl pl-1">悟る者はいない。</span><br /><span className="pl pl-2">神を求める者はいない。</span></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 14:3; 伝道者の書 7:20; イザヤ書 64:6"> <span className="pl pl-1">皆が道を外れ、</span><br /><span className="pl pl-2">そろって役に立たない者となった。</span><br /><span className="pl pl-1">善を行う者はいない。</span><br /><span className="pl pl-2">一人としていない。」</span></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 5:9; 詩篇 140:3; マタイ 23:27–28"> <span className="pl pl-1">「彼らの喉は開いた墓。</span><br /><span className="pl pl-2">その舌で人を欺く。」</span><br /><span className="pl pl-1">「まむしの毒が彼らの唇の下にある。」</span></span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 10:7; 詩篇 109:17–18; 詩篇 59:12"> <span className="pl pl-2">「彼らの口は呪いと苦々しさで満ちている。」</span></span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 59:7–8; 箴言 1:16; 箴言 6:18"> <span className="pl pl-1">「彼らの足は血を流すことに速く、</span></span>
<span className="v" id="v16" data-v="16"> <span className="pl pl-2">その道には破滅と悲惨がある。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 59:8; ローマ人への手紙 5:1; ルカ 1:79"> <span className="pl pl-2">彼らは平和の道を知らない。」</span></span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 36:1; 箴言 23:17; 箴言 16:6"> <span className="pl pl-1">「彼らの目の前に神への恐れはない。」</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ガラテヤ人への手紙 3:10; ガラテヤ人への手紙 3:22–23; ローマ人への手紙 2:12–18"> さて、律法が語ることはすべて、律法のもとにいる人々に語られていると私たちは知っています。それは、すべての口が閉ざされ、全世界が神の裁きのもとに置かれるためです。</span>
<span className="v" id="v20" data-v="20" data-xref="ガラテヤ人への手紙 2:16; 使徒の働き 13:39; ローマ人への手紙 3:28"> 律法の行いによっては、だれ一人、神の前で義とされません。律法によって罪が自覚されるからです。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 10:43; エレミヤ書 33:16; ピリピ人への手紙 3:9"> しかし今、律法とは別に神の義が現されました。律法と預言者たちも、それをあかししています。</span>
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 10:12; ガラテヤ人への手紙 3:28; ローマ人への手紙 8:1"> すなわち、イエス・キリストを信じる信仰による神の義が、信じるすべての人に与えられ、そのすべての人の上に及ぶのです。そこに区別はありません。</span>
<span className="v" id="v23" data-v="23" data-xref="伝道者の書 7:20; ヨハネの手紙第一 1:8–10; ローマ人への手紙 3:9"> すべての人が罪を犯し、神の栄光に達していないからです。</span>
<span className="v" id="v24" data-v="24" data-xref="ペテロの手紙第一 1:18–19; テトス 3:5–7; コロサイ人への手紙 1:14"> しかし、キリスト・イエスによる贖いを通し、神の恵みによって無償で義とされます。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 3:23–24; ペテロの手紙第一 1:18–20; ヨハネの手紙第一 4:10"> 神はキリストを、その血に対する信仰によって受ける贖罪の供え物<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「なだめの供え物」">a</a></sup>として公に示されました。それは、神が寛容のうちに以前の罪を見過ごしてこられた間にも、ご自分の義を示すためでした。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 32:4; ローマ人への手紙 4:5; ローマ人への手紙 3:30"> こうして今この時にご自分の義を示し、ご自身が義であり、イエスを信じる者を義と認める方であることを明らかにされたのです。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ローマ人への手紙 4:2; ローマ人への手紙 2:23; コリント人への第一の手紙 1:29–31"> では、誇る余地はどこにありますか。まったくありません。どのような律法によってでしょう。行いの律法によってですか。いいえ、信仰の律法によってです。</span>
<span className="v" id="v28" data-v="28" data-xref="ガラテヤ人への手紙 2:16; ガラテヤ人への手紙 3:8; テトス 3:7"> 私たちは、人は律法の行いとは別に、信仰によって義とされると結論づけます。</span>
<span className="v" id="v29" data-v="29" data-xref="コロサイ人への手紙 3:11; エペソ人への手紙 3:6; ゼカリヤ書 2:11"> それとも、神はユダヤ人だけの神でしょうか。異邦人の神でもあるのではありませんか。確かに、異邦人の神でもあります。</span>
<span className="v" id="v30" data-v="30" data-xref="ガラテヤ人への手紙 3:8; ガラテヤ人への手紙 3:20; ピリピ人への手紙 3:3"> 神はただ一人であり、割礼を受けた者を信仰によって、割礼を受けていない者を信仰を通して義と認める方だからです。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ガラテヤ人への手紙 2:21; マタイ 5:17; ローマ人への手紙 13:8–10"> では、私たちは信仰によって律法を無効にするのでしょうか。決してそうではありません。むしろ、律法を確立するのです。</span>
</div>

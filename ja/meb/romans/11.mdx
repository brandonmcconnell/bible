<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第二の手紙 11:22; サムエル記第一 12:22; ピリピ人への手紙 3:5"> では、私は尋ねます。神はご自分の民を退けられたのでしょうか。決してそうではありません。私もイスラエル人であり、アブラハムの子孫、ベニヤミン族の者です。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 94:14; ローマ人への手紙 8:29–30; 出エジプト記 32:1"> 神は、前もって知っておられたご自分の民を退けられませんでした。それとも、聖書がエリヤについて何と言っているか知らないのですか。彼はイスラエルを神に訴えて、こう言っています。</span>
<span className="v" id="v3" data-v="3" data-xref="列王記第一 19:10–18; 列王記第一 18:13; ネヘミヤ記 9:26"> 「主よ、彼らはあなたの預言者たちを殺し、あなたの祭壇を打ち壊しました。私だけが残りましたが、彼らは私の命も狙っています。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王記第一 19:18; 民数記 25:3; ゼパニヤ書 1:4"> しかし、神は彼に何と答えておられますか。「私は、バアルに膝をかがめなかった七千人を、自分のために残しておいた。」</span>
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 9:27; エペソ人への手紙 1:5–6; ローマ人への手紙 9:11"> それと同じように、今この時にも、恵みの選びによって残された者たちがいます。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 2:21; ローマ人への手紙 4:4–5; テモテへの第二の手紙 1:9"> もし恵みによるのであれば、もはや行いによるのではありません。そうでなければ、恵みはもはや恵みではありません。しかし、もし行いによるのであれば、もはや恵みによるのではありません。そうでなければ、行いはもはや行いではありません。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 9:18; ローマ人への手紙 11:5; コリント人への第二の手紙 4:4"> では、どうでしょう。イスラエルは求めていたものを得られませんでしたが、選ばれた者たちはそれを得ました。ほかの者たちはかたくなにされました。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 29:4; イザヤ書 29:10; エゼキエル書 12:2"> こう書かれているとおりです。「神は彼らに鈍い心を与え、今日に至るまで、見ることのできない目と、聞くことのできない耳を与えられた。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="詩篇 69:22–23; ルカ 12:20; 詩篇 28:4"> ダビデはこう言っています。<br /><span className="pl pl-1">「彼らの食卓が罠となり、落とし穴となり、</span><br /><span className="pl pl-2">つまずきとなり、彼らへの報いとなるように。</span></span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 69:23; 申命記 28:64–68; ペテロの第二の手紙 2:4"> <span className="pl pl-1">彼らの目が暗くなって、見えなくなるように。</span><br /><span className="pl pl-2">彼らの背をいつまでも曲げたままにしてください。」</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 13:46–48; ローマ人への手紙 11:31; ローマ人への手紙 10:19"> では、私は尋ねます。彼らがつまずいたのは、倒れてしまうためだったのでしょうか。決してそうではありません。むしろ、彼らの違反によって救いが異邦人に及び、イスラエルにねたみを起こさせることになったのです。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 11:25; コロサイ人への手紙 1:27; ローマ人への手紙 11:15"> もし彼らの違反が世界の富となり、彼らの損失が異邦人の富となったのなら、彼らが満ちることは、どれほど大きな富をもたらすでしょう。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 9:15; テモテへの第二の手紙 1:11–12; エペソ人への手紙 3:8"> 私は異邦人であるあなたがたに語っています。私は異邦人への使徒なので、この務めを誇りとしています。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 7:16; テモテへの手紙第一 4:16; ローマ人への手紙 9:3"> それによって、何とか私の同胞にねたみを起こさせ、その中の幾人かを救いたいのです。</span>
<span className="v" id="v15" data-v="15" data-xref="エペソ人への手紙 1:10; ローマ人への手紙 5:10–11; コロサイ人への手紙 1:20–21"> 彼らが退けられたことが世界の和解となったのなら、彼らが受け入れられることは、死者の中からの命にほかなりません。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 44:30; ヤコブの手紙 1:18; 箴言 3:9"> 初物が聖であるなら、こねた粉全体も聖です。根が聖であるなら、枝も聖です。</span>
<span className="v" id="v17" data-v="17" data-xref="エペソ人への手紙 2:11–13; エペソ人への手紙 3:6; マタイ 21:43"> しかし、枝の一部が折り取られ、野生のオリーブであるあなたがその間に接ぎ木され、ほかの枝と共にオリーブの木の根と豊かな樹液にあずかる者となったのなら、</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 10:12; ローマ人への手紙 11:20; エペソ人への手紙 2:19–20"> その枝々に対して誇ってはなりません。もし誇るとしても、あなたが根を支えているのではなく、根があなたを支えていることを覚えなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 11:17; ローマ人への手紙 11:11–12; ローマ人への手紙 11:23–24"> するとあなたは、「私が接ぎ木されるために、枝が折り取られた」と言うでしょう。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 12:16; コリント人への第二の手紙 1:24; コリント人への第一の手紙 10:12"> そのとおりです。彼らは不信仰によって折り取られ、あなたは信仰によって立っています。高慢にならず、恐れなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの第二の手紙 2:4–9; エレミヤ書 25:29; エレミヤ書 49:12"> 神が本来の枝を惜しまれなかったのなら、あなたを惜しまれることもありません。</span>
<span className="v" id="v22" data-v="22" data-xref="ヘブル人への手紙 3:14; ヘブル人への手紙 3:6; コリント人への第一の手紙 15:2"> ですから、神の慈しみと厳しさを見なさい。倒れた者たちには厳しさがありますが、あなたには神の慈しみがあります。ただし、あなたがその慈しみにとどまるならです。そうでなければ、あなたも切り取られます。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への第二の手紙 3:16; ゼカリヤ書 12:10; マタイ 23:39"> 彼らも不信仰にとどまらなければ、接ぎ木されます。神には、彼らを再び接ぎ木することができるからです。</span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 11:17–18; ローマ人への手紙 11:30"> あなたが本来は野生のオリーブの木から切り取られ、自然に反して栽培されたオリーブの木に接ぎ木されたのなら、本来の枝である彼らは、なおさら自分のオリーブの木に接ぎ木されるはずです。</span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="ルカ 21:24; コリント人への第二の手紙 3:14–16; ローマ人への手紙 16:25"> 兄弟たち、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="ここや、文脈上可能な箇所で「兄弟たち」と訳された言葉は、「兄弟姉妹」または「きょうだいたち」と訳すこともできる。">a</a></sup>あなたがたが自分を賢いと思わないために、この秘められた真理を知っておいてほしいのです。イスラエルの一部がかたくなにされた状態は、異邦人の全数が神の民に加わるまで続きます。</span>
<span className="v" id="v26" data-v="26" data-xref="イザヤ書 59:20; エレミヤ書 31:31–37; 詩篇 14:7"> こうして、イスラエルは皆、救われます。こう書かれているとおりです。<br /><span className="pl pl-1">「救い出す方がシオンから来て、</span><br /><span className="pl pl-2">ヤコブから不敬虔を取り除く。</span></span>
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 31:31–34; イザヤ書 59:21; エゼキエル書 36:25–29"> <span className="pl pl-1">これが彼らと結ぶ私の契約である。</span><br /><span className="pl pl-2">私が彼らの罪を取り除くときに。」</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命記 10:15; 申命記 7:7–8; マタイ 21:43"> 福音に関しては、彼らはあなたがたのために敵となっています。しかし、選びに関しては、父祖たちのために愛されています。</span>
<span className="v" id="v29" data-v="29" data-xref="ヘブル人への手紙 7:21; 民数記 23:19; マラキ書 3:6"> 神の賜物と召しは取り消されることがないからです。</span>
<span className="v" id="v30" data-v="30" data-xref="コロサイ人への手紙 3:7; エペソ人への手紙 2:1–2; コリント人への第一の手紙 7:25"> あなたがたは以前、神に従わない者でしたが、今は彼らの不従順によってあわれみを受けています。</span>
<span className="v" id="v31" data-v="31" data-xref="ローマ人への手紙 11:15; ローマ人への手紙 10:16; ローマ人への手紙 11:25"> それと同じように、彼らも今は従わない者となっていますが、それは、あなたがたに示されたあわれみによって、彼ら自身もあわれみを受けるためです。</span>
<span className="v" id="v32" data-v="32" data-xref="ガラテヤ人への手紙 3:22; ローマ人への手紙 3:9; テモテへの手紙第一 2:4–6"> 神はすべての人を不従順のうちに閉じ込められました。それは、すべての人をあわれむためです。</span>
</div>
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="ヨブ記 5:9; ヨブ記 11:7–9; 詩篇 92:5"> ああ、神の知恵と知識の富は、何と深いことでしょう。神の裁きは何と探り尽くしがたく、その道は何とたどりがたいことでしょう。</span>
<span className="v" id="v34" data-v="34" data-xref="イザヤ書 40:13; コリント人への第一の手紙 2:16; ヨブ記 15:8"> <span className="pl pl-1">「だれが主の思いを知っていたでしょう。</span><br /><span className="pl pl-2">だれが主の助言者となったでしょう。」</span></span>
<span className="v" id="v35" data-v="35" data-xref="ヨブ記 41:11; ヨブ記 35:7; コリント人への第一の手紙 4:7"> <span className="pl pl-1">「だれがまず神に与えて、</span><br /><span className="pl pl-2">神からその報いを受けられるでしょう。」</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="コロサイ人への手紙 1:15–17; コリント人への第一の手紙 8:6; ヘブル人への手紙 2:10"> すべてのものは神から出て、神によって存在し、神へと至るからです。栄光が永遠に神にありますように。アーメン。</span>
</div>

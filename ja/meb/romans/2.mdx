<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカ 6:37; ローマ人への手紙 2:3; ヨハネ 8:7–9"> ですから、人を裁く者よ、あなたがだれであっても弁解の余地はありません。他人を裁くことで、自分自身を罪に定めているからです。裁くあなたも同じことを行っています。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 9:7–8; ゼパニヤ書 3:5; 詩篇 145:17"> 私たちは、そのようなことを行う者に対する神の裁きが、真理に基づくことを知っています。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 16:5; ルカ 12:14; ローマ人への手紙 1:32–1"> そのようなことを行う者を裁きながら、自分も同じことを行う人よ。あなたは神の裁きを逃れられると思うのですか。</span>
<span className="v" id="v4" data-v="4" data-xref="ペテロの第二の手紙 3:9; イザヤ書 30:18; 出エジプト記 34:6"> それとも、神の慈しみがあなたを悔い改めに導くことを知らず、その豊かな慈しみと寛容と忍耐を軽んじるのですか。</span>
<span className="v" id="v5" data-v="5" data-xref="伝道者の書 12:14; ローマ人への手紙 1:18; ローマ人への手紙 2:2–3"> あなたは、かたくなで悔い改めようとしない心のために、神の怒りと正しい裁きが現される怒りの日に向けて、自分のために怒りを蓄えています。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 62:12; エレミヤ書 32:19; マタイ 16:27"> 神は「一人ひとりに、その行いに応じて報いる」方です。</span>
<span className="v" id="v7" data-v="7" data-xref="テモテへの第二の手紙 4:7–8; ルカ 8:15; テモテへの第二の手紙 1:10"> 忍耐強く善を行い、栄光と誉れと不滅を求める者には、永遠の命を与え、</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネ 3:18–21; テサロニケ人への第二の手紙 1:8; テモテへの手紙第一 6:3–4"> 利己心から真理に従わず、不義に従う者には、怒りと憤りを下されます。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの手紙第一 4:17; エゼキエル書 18:4; ローマ人への手紙 1:16"> 悪を行うすべての人には、苦難と苦悩が臨みます。まずユダヤ人に、そしてギリシャ人にもです。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 32:17; イザヤ書 26:12; 民数記 6:26"> しかし、善を行うすべての人には、栄光と誉れと平和が与えられます。まずユダヤ人に、そしてギリシャ人にもです。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 10:17; 使徒の働き 10:34; 歴代誌 第二 19:7"> 神にはえこひいきがないからです。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 9:21; ガラテヤ人への手紙 3:10; ガラテヤ人への手紙 2:16–19"> 律法を持たずに罪を犯した者は皆、律法によらずに滅びます。律法のもとで罪を犯した者は皆、律法によって裁かれます。</span>
<span className="v" id="v13" data-v="13" data-xref="ヤコブの手紙 1:22–25; ヨハネの手紙第一 3:7; ヤコブの手紙 2:21–25"> 神の前で義とされるのは、律法を聞く者ではなく、律法を行う者だからです。</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 2:12; ローマ人への手紙 1:19–20; ローマ人への手紙 2:27"> 律法を持たない異邦人が、生まれつき律法の求めることを行うなら、律法を持たなくても、自分自身が律法となります。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第二の手紙 5:11; コリント人への第二の手紙 1:12; ローマ人への手紙 1:18–19"> 彼らは、律法の求める働きが自分たちの心に書かれていることを示しています。彼らの良心もそのことを証言し、その思いも、ある時は彼らを責め、ある時は弁明しています。</span>
<span className="v" id="v16" data-v="16" data-xref="伝道者の書 12:14; コリント人への第一の手紙 4:5; 使徒の働き 17:31"> これは、私の福音によれば、神がイエス・キリストによって人々の隠れた事柄を裁かれる日に明らかになります。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 2:23; ミカ書 3:11; イザヤ書 48:1–2"> ところで、あなたはユダヤ人と名乗り、律法を頼みとし、神を誇り、</span>
<span className="v" id="v18" data-v="18" data-xref="テサロニケ人への手紙第一 5:21; 申命記 4:8; ヤコブの手紙 4:17"> 律法から教えられて神のみこころを知り、何が優れているかを見分け、</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの黙示録 3:17–18; マタイ 15:14; イザヤ書 49:6"> 自分は目の見えない人の案内人、闇の中にいる人の光、</span>
<span className="v" id="v20" data-v="20" data-xref="テモテへの第二の手紙 3:5; テトス 1:16; テモテへの第二の手紙 1:13"> 愚かな者を正す者、未熟な者を教える者であり、律法の中に知識と真理の形を持っていると確信しています。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第一の手紙 9:27; マタイ 23:3–28; ルカ 12:47"> それなら、他人を教えるあなたが、自分を教えないのですか。盗んではならないと説くあなたが、盗むのですか。</span>
<span className="v" id="v22" data-v="22" data-xref="マラキ書 3:8; マタイ 12:39; マルコ 11:17"> 姦淫してはならないと言うあなたが、姦淫するのですか。偶像を忌み嫌うあなたが、神殿のものを盗むのですか。</span>
<span className="v" id="v23" data-v="23" data-xref="ヤコブの手紙 4:16–17; ローマ人への手紙 2:17; ローマ人への手紙 3:2"> 律法を誇るあなたが、律法に背いて神を辱めるのですか。</span>
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 36:20–23; イザヤ書 52:5; ペテロの第二の手紙 2:2"> 「神の名は、あなたがたのために異邦人の間で冒涜されている」と書かれているとおりです。</span>
<span className="v" id="v25" data-v="25" data-xref="エレミヤ書 4:4; ガラテヤ人への手紙 5:3–6; 使徒の働き 7:51"> あなたが律法を行うなら、割礼には確かに価値があります。しかし、律法に背くなら、あなたの割礼は無割礼となります。</span>
<span className="v" id="v26" data-v="26" data-xref="コロサイ人への手紙 2:11; コリント人への第一の手紙 7:18–19; ローマ人への手紙 8:4"> ですから、割礼を受けていない人が律法の定めを守るなら、その人の無割礼は割礼とみなされるのではありませんか。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイ 12:41–42; ローマ人への手紙 2:29; コリント人への第二の手紙 3:6"> 生まれながら割礼を受けていなくても律法を全うする人は、律法の文字と割礼を持ちながら律法に背くあなたを裁くことになります。</span>
<span className="v" id="v28" data-v="28" data-xref="ガラテヤ人への手紙 6:15; マタイ 3:9; ローマ人への手紙 9:6–8"> 外見だけのユダヤ人が真のユダヤ人なのではなく、肉体に施された外見だけの割礼が真の割礼なのでもありません。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 30:6; ピリピ人への手紙 3:3; 申命記 10:16"> 内面がユダヤ人である人こそ真のユダヤ人であり、割礼とは、文字によるものではなく、霊による心の割礼です。その人への称賛は、人からではなく神から来ます。</span>

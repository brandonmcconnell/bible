<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への手紙第一 5:14; ローマ人への手紙 14:1; ガラテヤ人への手紙 6:1–2"> 私たち強い者は、弱い人たちの弱さを担うべきであって、自分を喜ばせるべきではありません。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 14:19; コリント人への第一の手紙 10:24; ピリピ人への手紙 2:4–5"> 私たちは一人ひとり、隣人の益を求め、その人を築き上げるように努めましょう。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 69:9; ピリピ人への手紙 2:8; ヨハネ 4:34"> キリストでさえ、ご自分を喜ばせることはなさいませんでした。むしろ、「あなたを非難する者たちの非難が、私の上に降りかかった」と書かれているとおりです。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 10:11; テモテへの第二の手紙 3:16–17; ローマ人への手紙 4:23–24"> 以前に書かれたことはすべて、私たちを教えるために書かれました。それは、忍耐と聖書から来る励ましによって、私たちが希望を持つためです。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 2:4–5; ペテロの手紙第一 3:8; ローマ人への手紙 12:16"> どうか忍耐と励ましを与えてくださる神が、キリスト・イエスに倣い、あなたがたに互いに同じ思いを持たせてくださいますように。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 10:29–30; ヨハネの黙示録 1:6; エペソ人への手紙 1:3"> それは、あなたがたが心を一つにし、声を合わせて、私たちの主イエス・キリストの父なる神をあがめるためです。</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="マタイ 10:40; ヨハネ 13:34; ローマ人への手紙 5:2"> ですから、神の栄光のために、キリストがあなたがたを受け入れてくださったように、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TRでは「あなたがた」ではなく「私たち」となっている。">a</a></sup>あなたがたも互いに受け入れなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="ガラテヤ人への手紙 4:4–5; マタイ 15:24; ヨハネ 1:11"> 私はこう言います。キリストは神の真実を示すために、割礼を受けた者たちに仕える者となられました。それは、父祖たちに与えられた約束を確かなものとし、</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記第二 22:50; 詩篇 18:49; ローマ人への手紙 3:29"> 異邦人が神のあわれみのゆえに神をあがめるためです。こう書かれています。<br /><span className="pl pl-1">「それゆえ、私は異邦人の間であなたをたたえ、</span><br /><span className="pl pl-2">あなたの名をほめ歌う。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="詩篇 67:3–4; 申命記 32:43; イザヤ書 42:10–12"> また、こう言われています。<br /><span className="pl pl-1">「異邦人よ、主の民と共に喜べ。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="詩篇 117:1"> さらに、<br /><span className="pl pl-1">「すべての異邦人よ、主をほめたたえよ。</span><br /><span className="pl pl-2">すべての民よ、主をたたえよ。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 11:10; イザヤ書 11:1; マタイ 12:21"> さらに、イザヤはこう言っています。<br /><span className="pl pl-1">「エッサイの根が現れる。</span><br /><span className="pl pl-2">異邦人を治めるために立ち上がる方。</span><br /><span className="pl pl-2">異邦人はこの方に望みを置く。」</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="テサロニケ人への第二の手紙 2:16–17; ローマ人への手紙 12:12; コリント人への第二の手紙 9:8"> どうか希望の神が、信じるあなたがたをあらゆる喜びと平和で満たし、聖霊の力によって希望にあふれさせてくださいますように。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="コロサイ人への手紙 3:16; ペテロの第二の手紙 1:12; ヨハネの手紙第一 2:21"> 私の兄弟たち、<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ここや、文脈上可能な箇所で「兄弟たち」と訳された言葉は、「兄弟姉妹」または「きょうだいたち」と訳すこともできる。">b</a></sup>あなたがた自身が善に満ち、あらゆる知識に満たされ、互いに戒めることもできると、私自身も確信しています。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 12:3; コリント人への第一の手紙 15:10; ローマ人への手紙 1:5"> しかし、神から私に与えられた恵みによって、いくつかの点を思い起こしてもらうため、私はあなたがたにいっそう大胆に書きました。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 11:13; ローマ人への手紙 1:1; 使徒の働き 9:15"> その恵みによって、私は異邦人のためにキリスト・イエスに仕える者となり、神の福音に祭司として仕えています。それは、異邦人という供え物が聖霊によって聖なるものとされ、神に受け入れられるものとなるためです。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第二の手紙 2:14–16; コリント人への第二の手紙 12:11–21; ヘブル人への手紙 5:1"> ですから、神に仕える働きについて、私はキリスト・イエスにあって誇ることがあります。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 15:12; ローマ人への手紙 1:5; 使徒の働き 21:19"> 私は、異邦人を従順へ導くためにキリストが私を通して行われたこと以外は、何一つあえて語ろうとはしません。キリストは言葉と行い、</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第二の手紙 12:12; ヘブル人への手紙 2:4; 使徒の働き 19:11–12"> しるしと不思議の力、神の霊の力によって働かれました。こうして私は、エルサレムからその周辺を巡り、イリリコに至るまで、キリストの福音を余すところなく宣べ伝えました。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第二の手紙 10:13–16; コリント人への第一の手紙 3:9–15; エペソ人への手紙 2:20–22"> しかも私は、ほかの人の土台の上に建てることがないように、キリストの御名がまだ知られていない所で福音を宣べ伝えることを目標としてきました。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 52:15; イザヤ書 65:1"> こう書かれているとおりです。<br /><span className="pl pl-1">「この方について知らされなかった人々が見、</span><br /><span className="pl pl-2">聞いたことのなかった人々が悟る。」</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 1:13; テサロニケ人への手紙第一 2:17–18"> そのため、私は何度もあなたがたのところへ行くことを妨げられてきました。</span>
<span className="v" id="v23" data-v="23" data-xref="ローマ人への手紙 15:32; ローマ人への手紙 1:10–12; ローマ人への手紙 15:29"> しかし今、この地方にはもう働く場所がなく、また何年も前からあなたがたのところへ行きたいと願っているので、</span>
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 15:28; ローマ人への手紙 1:12; 使徒の働き 15:3"> スペインへ旅をするときには、あなたがたのところへ行きます。その旅の途中であなたがたに会い、まずしばらく共に過ごして喜びを味わってから、スペインへ送り出してもらいたいと願っています。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 24:17; 使徒の働き 19:21; 使徒の働き 20:22"> しかし今、私は聖徒たちに仕えるためにエルサレムへ行くところです。</span>
<span className="v" id="v26" data-v="26" data-xref="コリント人への第二の手紙 8:1–9; 使徒の働き 11:27–30; コリント人への第二の手紙 9:2"> マケドニアとアカイアの人々は、エルサレムにいる聖徒たちのうち、貧しい人々のために喜んで献金することにしたからです。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への第一の手紙 9:11; ガラテヤ人への手紙 6:6; フィレモンへの手紙 1:19"> 彼らは喜んで決めましたが、同時にその人々に対して義務を負っています。異邦人がユダヤ人の霊的なものにあずかったのなら、物質的なものをもってユダヤ人に仕える義務があるからです。</span>
<span className="v" id="v28" data-v="28" data-xref="ローマ人への手紙 15:24; ピリピ人への手紙 4:17; コロサイ人への手紙 1:6"> ですから、この務めを果たし、この実を確実に彼らへ届け終えたら、あなたがたのところを通ってスペインへ向かいます。</span>
<span className="v" id="v29" data-v="29" data-xref="エペソ人への手紙 4:13; ローマ人への手紙 1:10–12; 詩篇 16:11"> あなたがたのところへ行くときには、キリストの福音の祝福に満ちあふれて行くことになると知っています。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="コロサイ人への手紙 4:12; コリント人への第二の手紙 1:11; コリント人への第二の手紙 4:11"> 兄弟たち、私たちの主イエス・キリストと聖霊の愛によってお願いします。私のために神に祈り、私と共に力を尽くしてください。</span>
<span className="v" id="v31" data-v="31" data-xref="テサロニケ人への第二の手紙 3:2; コリント人への第二の手紙 8:4; コリント人への第二の手紙 9:1"> 私がユダヤにいる不従順な者たちから救い出され、エルサレムのために行う私の奉仕が聖徒たちに受け入れられるように、</span>
<span className="v" id="v32" data-v="32" data-xref="コリント人への第一の手紙 16:18; フィレモンへの手紙 1:20; フィレモンへの手紙 1:7"> そして、神のみこころによって喜びのうちにあなたがたのところへ行き、共に安らぎを得られるように祈ってください。</span>
<span className="v" id="v33" data-v="33" data-xref="コリント人への第二の手紙 13:11; ピリピ人への手紙 4:9; テサロニケ人への手紙第一 5:23"> どうか平和の神が、あなたがたすべてと共におられますように。アーメン。</span>
</div>

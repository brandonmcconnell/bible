<span className="v" id="v1" data-v="1" data-xref="イザヤ書 32:17; ローマ人への手紙 15:13; ヨハネ 16:33"> こうして、私たちは信仰によって義とされたのですから、私たちの主イエス・キリストを通して、神との間に平和を得ています。</span>
<span className="v" id="v2" data-v="2" data-xref="エペソ人への手紙 2:18; エペソ人への手紙 3:12; ローマ人への手紙 12:12"> また、この方によって、信仰を通して、今立っているこの恵みに入る道が開かれました。そして、神の栄光にあずかる希望を喜びとしています。</span>
<span className="v" id="v3" data-v="3" data-xref="ヤコブの手紙 1:2–3; ヤコブの手紙 1:12; ペテロの手紙第一 3:14"> それだけでなく、苦難をも喜んでいます。苦難が忍耐を生み、</span>
<span className="v" id="v4" data-v="4" data-xref="ペテロの手紙第一 5:10; ヤコブの手紙 1:12; コリント人への第二の手紙 4:8–12"> 忍耐が練られた品性を、練られた品性が希望を生むと知っているからです。</span>
<span className="v" id="v5" data-v="5" data-xref="ガラテヤ人への手紙 4:6; エペソ人への手紙 3:16–19; ピリピ人への手紙 1:20"> この希望は私たちを失望させません。私たちに与えられた聖霊によって、神の愛が私たちの心に注がれているからです。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エペソ人への手紙 2:1–5; ローマ人への手紙 5:8; コロサイ人への手紙 2:13"> 私たちがまだ弱かったとき、定められた時に、キリストは不敬虔な者たちのために死んでくださいました。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネ 15:13; ヨハネの手紙第一 3:16; ローマ人への手紙 16:4"> 義人のために死ぬ人は、ほとんどいません。善良な人のためなら、あえて死のうとする人がいるかもしれません。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネ 15:13; ヨハネ 3:16; ローマ人への手紙 5:6"> しかし、私たちがまだ罪人であったとき、キリストが私たちのために死んでくださったことによって、神は私たちに対するご自分の愛を示されました。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への手紙第一 1:10; ローマ人への手紙 8:1; エペソ人への手紙 2:13"> まして今、私たちはキリストの血によって義とされたのですから、この方を通して神の怒りから救われます。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第二の手紙 5:18–19; コリント人への第二の手紙 4:10–11; ローマ人への手紙 8:32"> 私たちが敵であったときでさえ、御子の死によって神と和解させられたのなら、和解した今はなおさら、御子の命によって救われます。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="コリント人への第二の手紙 5:18–19; ローマ人への手紙 5:10; イザヤ書 61:10"> それだけではありません。今や私たちの主イエス・キリストによって和解を受けた私たちは、この方を通して神をも喜んでいます。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 15:21–22; ローマ人への手紙 5:19; ローマ人への手紙 6:23"> ですから、一人の人を通して罪が世界に入り、罪を通して死が入りました。こうして、すべての人が罪を犯したため、死がすべての人に及びました。</span>
<span className="v" id="v13" data-v="13" data-xref="ローマ人への手紙 4:15; コリント人への第一の手紙 15:56; ヨハネの手紙第一 3:4"> 律法が与えられる前にも、罪は世界にありました。しかし、律法がなければ、罪は罪として数えられません。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 15:45; ローマ人への手紙 5:17; ヘブル人への手紙 9:27"> それでも、アダムからモーセまで、アダムの違反と同じような罪を犯さなかった人々に対してさえ、死は支配しました。アダムは、後に来る方の予型です。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 6:23; エペソ人への手紙 2:8; ローマ人への手紙 5:12"> しかし、恵みの賜物は違反と同じではありません。一人の違反によって多くの人が死んだのであれば、なおさら、神の恵みと、一人の人イエス・キリストの恵みによる賜物は、多くの人に豊かに注がれました。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 13:38–39; イザヤ書 1:18; イザヤ書 44:22"> また、この賜物は、一人が罪を犯した結果とは異なります。一人の罪から裁きが下って有罪となりましたが、恵みの賜物は多くの違反を越えて、人を義とするものとなったからです。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 15:21–22; コリント人への第一の手紙 15:49; ローマ人への手紙 5:12"> 一人の違反によって、その一人を通して死が支配したのであれば、なおさら、豊かな恵みと義の賜物を受ける人々は、一人の方イエス・キリストを通して、命のうちに王として支配します。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 15:22; ローマ人への手紙 5:12; ローマ人への手紙 5:15"> したがって、一つの違反によってすべての人に有罪判決が及んだように、一つの義の行為によって、すべての人が義とされて命を得るに至りました。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 5:18; コリント人への第二の手紙 5:21; ピリピ人への手紙 2:8"> 一人の人の不従順によって多くの人が罪人とされたように、一人の方の従順によって多くの人が義人とされます。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 6:1; テトス 3:3–7; ローマ人への手紙 6:14"> 律法が入って来たのは、違反が増し加わるためでした。しかし、罪が増し加わったところには、恵みがさらにあふれました。</span>
<span className="v" id="v21" data-v="21" data-xref="テトス 2:11; ローマ人への手紙 5:14; ローマ人への手紙 8:10"> それは、罪が死によって支配したように、恵みが義を通して支配し、私たちの主イエス・キリストによる永遠の命をもたらすためです。</span>
</div>

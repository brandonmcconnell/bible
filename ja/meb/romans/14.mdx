<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 15:1; コリント人への第一の手紙 8:7–13; コリント人への第一の手紙 9:22"> 信仰の弱い人を受け入れなさい。ただし、意見をめぐって言い争うためではありません。</span>
<span className="v" id="v2" data-v="2" data-xref="テモテへの手紙第一 4:4; ローマ人への手紙 14:22–23; ローマ人への手紙 14:14"> ある人は何でも食べられるという信仰を持っていますが、弱い人は野菜だけを食べます。</span>
<span className="v" id="v3" data-v="3" data-xref="ローマ人への手紙 14:10; コロサイ人への手紙 2:16–17; ルカ 18:9"> 食べる人は食べない人を軽蔑してはならず、食べない人は食べる人を裁いてはなりません。神がその人を受け入れてくださったからです。</span>
<span className="v" id="v4" data-v="4" data-xref="ヤコブの手紙 4:11–12; ローマ人への手紙 9:20; ローマ人への手紙 8:31–39"> 他人のしもべを裁くあなたは何者ですか。その人が立つのも倒れるのも、その主人の前でのことです。しかし、その人は立つのです。神には、その人を立たせる力があるからです。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="コロサイ人への手紙 2:16–17; ローマ人への手紙 14:23; ガラテヤ人への手紙 4:9–10"> ある人は、ある日をほかの日より大切に考え、別の人は、どの日も同じだと考えます。それぞれが自分の心の中で確信を持ちなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第一の手紙 10:30–31; テモテへの手紙第一 4:3–5; マタイ 14:19"> 特定の日を大切にする人は、主のために大切にします。その日を大切にしない人は、主のためにそうしません。食べる人は神に感謝して、主のために食べます。食べない人も主のために食べず、神に感謝します。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの手紙第一 4:2; コリント人への第二の手紙 5:15; コリント人への第一の手紙 6:19–20"> 私たちのうち、だれ一人、自分のために生きる人はおらず、自分のために死ぬ人もいません。</span>
<span className="v" id="v8" data-v="8" data-xref="ピリピ人への手紙 1:20; テサロニケ人への手紙第一 5:10; コリント人への第一の手紙 15:23"> 私たちは生きるなら主のために生き、死ぬなら主のために死にます。ですから、生きるにしても死ぬにしても、私たちは主のものです。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 1:18; ルカ 24:26; ヘブル人への手紙 12:2"> キリストが死んで復活し、再び生きられたのは、死者と生きている者の両方の主となるためです。</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="コリント人への第二の手紙 5:10; コリント人への第一の手紙 4:5; 伝道者の書 12:14"> それなのに、なぜあなたは自分の兄弟を裁くのですか。また、なぜあなたは自分の兄弟を軽蔑するのですか。私たちは皆、キリストの裁きの座の前に立つことになるのです。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 45:22–25; ピリピ人への手紙 2:10–11; 詩篇 72:11"> こう書かれています。<br /><span className="pl pl-1">「『私は生きている』と主は言われる。『すべての膝が私の前にかがみ、</span><br /><span className="pl pl-2">すべての舌が神に告白する。』」</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ペテロの手紙第一 4:5; マタイ 12:36; マタイ 16:27"> ですから、私たちは一人ひとり、自分のことを神に申し開くことになります。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="コリント人への第二の手紙 6:3; ヤコブの手紙 4:11; コリント人への第一の手紙 8:9–13"> それゆえ、もう互いに裁き合わないようにしましょう。むしろ、兄弟の前につまずきや妨げを置かないことを心に決めなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="テトス 1:15; ローマ人への手紙 14:2; テモテへの手紙第一 4:4"> 私は、主イエスにあって知り、確信しています。それ自体で汚れているものは何もありません。ただし、何かを汚れていると考える人にとっては、それは汚れたものです。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 8:11–12; ピリピ人への手紙 2:2–4; ガラテヤ人への手紙 5:13"> 食べ物のためにあなたの兄弟を悲しませるなら、あなたはもはや愛に従って歩んではいません。キリストがその人のために死んでくださったのですから、あなたの食べ物によってその人を滅ぼしてはなりません。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 12:17; テサロニケ人への手紙第一 5:22; コリント人への第一の手紙 10:29–30"> ですから、あなたがたが良いとすることが、悪く言われないようにしなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイ 6:33; ローマ人への手紙 15:13; コリント人への第一の手紙 4:20"> 神の国は食べることや飲むことではなく、義と平和と聖霊による喜びだからです。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第二の手紙 8:21; コリント人への第二の手紙 5:11; ペテロの手紙第一 2:20"> このようにキリストに仕える人は、神に喜ばれ、人々にも認められます。</span>
<span className="v" id="v19" data-v="19" data-xref="エペソ人への手紙 4:29; ローマ人への手紙 12:18; 詩篇 34:14"> ですから、平和に役立つことと、互いを築き上げることを追い求めましょう。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 14:14–15; マタイ 18:6; テトス 1:15"> 食べ物のために神の働きを壊してはなりません。確かに、すべてのものは清いのですが、食べることで人をつまずかせるなら、それは悪いことです。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第一の手紙 8:13; ローマ人への手紙 14:13; ローマ人への手紙 15:1–2"> 肉を食べず、ぶどう酒を飲まず、そのほか兄弟をつまずかせ、妨げとなり、弱らせるようなことを何もしないのが良いのです。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨハネの手紙第一 3:21; ローマ人への手紙 14:5; ヤコブの手紙 3:13"> あなたには信仰がありますか。それは神の前で、自分のうちに保ちなさい。自分が良いと認めたことについて、良心に責められない人は幸いです。</span>
<span className="v" id="v23" data-v="23" data-xref="ヘブル人への手紙 11:6; テトス 1:15; コリント人への第一の手紙 11:29–31"> しかし、疑いながら食べる人は罪に定められます。それが信仰によるものではないからです。信仰によらないことはすべて罪です。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 私の福音、すなわちイエス・キリストについての宣教と、長い時代にわたって隠されていた秘められた真理の啓示とに従って、あなたがたを堅く立たせることのできる方に。</span>
<span className="v" id="v25" data-v="25"> この真理は今や明らかにされ、永遠の神の命令に従って、預言者たちの書を通してすべての国々に知らされ、信仰の従順へと導いています。</span>
<span className="v" id="v26" data-v="26"> その唯一の知恵ある神に、イエス・キリストを通して、永遠に栄光がありますように。アーメン。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TRは24-26節を、ローマ人への手紙16:24の後に25-27節として置いている。">a</a></sup></span>

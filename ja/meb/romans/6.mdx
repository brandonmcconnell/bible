<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ペテロの手紙第一 2:16; ガラテヤ人への手紙 5:13; ローマ人への手紙 6:15"> では、何と言えばよいでしょう。恵みが増し加わるために、罪の中にとどまるべきでしょうか。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの手紙第一 3:9; コロサイ人への手紙 3:3; ローマ人への手紙 7:4"> 決してそうではありません。罪に対して死んだ私たちが、どうしてなおも罪の中に生きられるでしょうか。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 3:27; ガラテヤ人への手紙 2:20–21; ローマ人への手紙 6:8"> それとも、キリスト・イエスへのバプテスマを受けた私たちは皆、キリストの死へのバプテスマを受けたことを知らないのですか。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第二の手紙 5:17; コロサイ人への手紙 3:10; エペソ人への手紙 4:22–24"> ですから、私たちは死へのバプテスマによって、キリストと共に葬られました。それは、キリストが御父の栄光によって死者の中からよみがえらされたように、私たちも新しい命に歩むためです。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 3:10–11; コリント人への第二の手紙 4:10; コロサイ人への手紙 2:12"> 私たちがキリストの死と同じ姿になって、この方と一つにされたのなら、その復活とも同じ姿にされるでしょう。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 2:20; エペソ人への手紙 4:22; ガラテヤ人への手紙 5:24"> 私たちは知っています。私たちの古い自分はキリストと共に十字架につけられました。それは、罪の体が無力にされ、私たちがもはや罪の奴隷とならないためです。</span>
<span className="v" id="v7" data-v="7" data-xref="ペテロの手紙第一 4:1; コロサイ人への手紙 3:1–3; ローマ人への手紙 7:4"> 死んだ者は罪から解放されているからです。</span>
<span className="v" id="v8" data-v="8" data-xref="テモテへの第二の手紙 2:11–12; コロサイ人への手紙 3:3–4; コリント人への第二の手紙 4:10–14"> 私たちがキリストと共に死んだのなら、キリストと共に生きると信じます。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 6:14; ヨハネの黙示録 1:18; 使徒の働き 2:24–28"> 私たちは、死者の中からよみがえらされたキリストが、もはや死ぬことはないと知っています。死はもはや、この方を支配しません。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第二の手紙 5:21; ペテロの手紙第一 4:6; ペテロの手紙第一 3:18"> キリストが死なれたのは、ただ一度、罪に対して死なれたのであり、今生きておられるのは、神に対して生きておられるのです。</span>
<span className="v" id="v11" data-v="11" data-xref="コロサイ人への手紙 3:3–5; コリント人への第一の手紙 6:20; ローマ人への手紙 6:2"> 同じようにあなたがたも、自分は罪に対して死んだ者であり、私たちの主キリスト・イエスにあって神に対して生きている者だと考えなさい。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ガラテヤ人への手紙 5:16; ローマ人への手紙 6:16; ローマ人への手紙 8:13"> ですから、罪にあなたがたの死ぬべき体を支配させ、その欲望に従ってはなりません。</span>
<span className="v" id="v13" data-v="13" data-xref="ローマ人への手紙 12:1; ローマ人への手紙 6:16; コロサイ人への手紙 3:5"> また、自分の体の各部分を不義の道具として罪に差し出してはなりません。むしろ、死者の中から生かされた者として自分自身を神に差し出し、体の各部分を義の道具として神に差し出しなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 5:18; ローマ人への手紙 8:2; ローマ人への手紙 7:4–11"> 罪があなたがたを支配することはありません。あなたがたは律法のもとではなく、恵みのもとにいるからです。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="テトス 2:11–14; エペソ人への手紙 2:8–10; ローマ人への手紙 6:1–2"> では、どうでしょう。私たちは律法のもとではなく、恵みのもとにいるのだから、罪を犯してもよいのでしょうか。決してそうではありません。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネ 8:34; マタイ 6:24; ヨシュア記 24:15"> あなたがたは知らないのですか。自分自身をしもべとしてだれかに差し出して従うなら、あなたがたはその従う相手のしもべです。罪に従って死に至るか、従順によって義に至るかのどちらかです。</span>
<span className="v" id="v17" data-v="17" data-xref="ペテロの手紙第一 2:9; テモテへの第二の手紙 1:13; ローマ人への手紙 1:8"> しかし、神に感謝します。あなたがたはかつて罪の奴隷でしたが、あなたがたに伝えられた教えの規範に心から従い、</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 6:22; ローマ人への手紙 8:2; ガラテヤ人への手紙 5:1"> 罪から解放されて、義のしもべとなりました。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 6:13; ペテロの手紙第一 4:2–4; コロサイ人への手紙 3:5–7"> あなたがたの肉の弱さのために、私は人間的な言い方をしています。以前、あなたがたは自分の体の各部分を汚れと不法の奴隷として差し出し、ますます不法に陥っていました。それと同じように今は、体の各部分を義のしもべとして差し出し、聖なる者となりなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 6:16–17; ヨハネ 8:34"> あなたがたが罪の奴隷であったとき、義に対しては自由でした。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 1:32; ローマ人への手紙 7:5; ローマ人への手紙 6:23"> では、今は恥じていることから、当時どんな実を得たのでしょう。それらの行き着く先は死です。</span>
<span className="v" id="v22" data-v="22" data-xref="ペテロの手紙第一 2:16; ローマ人への手紙 6:18; ローマ人への手紙 8:2"> しかし今、罪から解放されて神のしもべとなったあなたがたは、その実として聖なる者とされ、その行き着く先に永遠の命があります。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネ 3:36; ローマ人への手紙 5:12; ヤコブの手紙 1:15"> 罪が支払う報酬は死です。しかし、神の恵みの賜物は、私たちの主キリスト・イエスにある永遠の命です。</span>
</div>

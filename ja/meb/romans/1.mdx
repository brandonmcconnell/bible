<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 9:15; ローマ人への手紙 15:16; コリント人への第一の手紙 1:1"> イエス・キリスト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「キリスト」は「油を注がれた者」という意味である。">a</a></sup>のしもべであり、使徒として召され、神の福音のために選び分けられたパウロから。</span>
<span className="v" id="v2" data-v="2" data-xref="テトス 1:2; ルカ 1:70; ローマ人への手紙 3:21"> この福音は、神が聖書の中で預言者たちを通して前もって約束されたもので、</span>
<span className="v" id="v3" data-v="3" data-xref="マタイ 1:1; ガラテヤ人への手紙 4:4; エレミヤ書 23:5–6"> 御子に関するものです。御子は肉によればダビデの子孫<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または「種」">b</a></sup>として生まれ、</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 9:14; ヘブル人への手紙 5:5–6; エペソ人への手紙 1:19–23"> 聖なる霊によれば、死者の中からの復活によって、力ある神の子と定められた方、すなわち、私たちの主イエス・キリストです。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 9:15; ローマ人への手紙 16:26; 使徒の働き 6:7"> 私たちはこの方を通して、御名のために、すべての国々の人々を信仰から生まれる従順へと導く恵みと使徒の務めを受けました。</span>
<span className="v" id="v6" data-v="6" data-xref="ペテロの手紙第一 2:9; ヨハネの黙示録 17:14; ペテロの第二の手紙 1:10"> あなたがたもその人々の中にいて、イエス・キリストのものとなるよう召されています。</span>
<span className="v" id="v7" data-v="7" data-xref="コロサイ人への手紙 1:2; ユダ 1:1–2; エペソ人への手紙 1:2"> ローマにいるすべての人、神に愛され、聖徒として召された人々へ。私たちの父なる神と主イエス・キリストから、恵みと平和があなたがたにありますように。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 16:19; コリント人への第一の手紙 1:4; テサロニケ人への手紙第一 1:8–9"> まず、あなたがた一同のことを、イエス・キリストを通して私の神に感謝します。あなたがたの信仰が全世界で語り伝えられているからです。</span>
<span className="v" id="v9" data-v="9" data-xref="エペソ人への手紙 6:18; テモテへの第二の手紙 1:3; エペソ人への手紙 1:16–19"> 御子の福音を宣べ伝えつつ、私が心から仕えている神が、私の証人です。私は祈るたびに、絶えずあなたがたのことを覚え、</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 15:30–32; 使徒の働き 18:21; フィレモンへの手紙 1:22"> 何とかして今度こそ、神のみこころによってあなたがたのところへ行く道が開かれるようにと、いつも願っています。</span>
<span className="v" id="v11" data-v="11" data-xref="ペテロの第二の手紙 1:12; ローマ人への手紙 16:25; ローマ人への手紙 15:29"> 私はあなたがたに会うことを切に望んでいます。それは、あなたがたを強めるために、何らかの霊の賜物を分け与えたいからです。</span>
<span className="v" id="v12" data-v="12" data-xref="テサロニケ人への手紙第一 3:7–10; ヨハネの手紙第三 1:3–4; コリント人への第二の手紙 7:13"> つまり、あなたがたと私が、互いの信仰によって共に励まされたいのです。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 19:21; ピリピ人への手紙 4:17; テモテへの第二の手紙 4:17"> 兄弟たち、次のことを知っておいてほしいのです。私はほかの異邦人の間で得たように、あなたがたの間でも実を得たいと思い、何度もそちらへ行こうと計画しましたが、今まで妨げられてきました。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 9:16–23; 使徒の働き 9:15; コロサイ人への手紙 3:11"> 私はギリシャ人にも異民族の人々にも、知恵ある者にも愚かな者にも、福音を伝える責任を負っています。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 15:20; イザヤ書 6:8; コリント人への第一の手紙 9:17"> ですから、私としては、ローマにいるあなたがたにもぜひ福音を伝えたいのです。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="マルコ 8:38; テモテへの第二の手紙 1:8; ペテロの手紙第一 4:16"> 私はキリストの福音を恥とは思いません。それは、信じるすべての人を救う神の力だからです。まずユダヤ人に、そしてギリシャ人にもです。</span>
<span className="v" id="v17" data-v="17" data-xref="ハバクク書 2:4; ガラテヤ人への手紙 3:11; ヘブル人への手紙 10:38"> 福音には、信仰に始まり信仰に至る神の義が示されています。「義人は信仰によって生きる」と書かれているとおりです。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 5:6; テモテへの手紙第一 4:1–2; ローマ人への手紙 1:32"> 神の怒りは、不義によって真理を押さえつける人々のあらゆる不敬虔と不義に対して、天から現されています。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 14:16–17; 詩篇 19:1–6; ローマ人への手紙 1:20"> 神について知りうることは彼らのうちに明らかだからです。神がそれを彼らに明らかにされたのです。</span>
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 1:19; イザヤ書 40:26; 詩篇 19:1–6"> 神の目に見えない性質、すなわち永遠の力と神性は、世界の創造以来、造られたものを通して理解され、はっきり認められます。ですから、彼らには弁解の余地がありません。</span>
<span className="v" id="v21" data-v="21" data-xref="エペソ人への手紙 4:17–18; 列王記第二 17:15; エレミヤ書 2:5"> 彼らは神を知っていながら、神としてあがめることも感謝することもせず、考えることがむなしくなり、悟りのない心は暗くなりました。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="コリント人への第一の手紙 1:19–21; ローマ人への手紙 11:25; 箴言 26:12"> 自分では知恵ある者だと言いながら愚かになり、</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 106:20; エレミヤ書 2:11; 使徒の働き 17:29"> 滅びることのない神の栄光を、滅びる人間や鳥、四つ足の動物、地を這うものに似せた像と取り替えました。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 81:11–12; 使徒の働き 7:42; 使徒の働き 14:16"> そこで神は、彼らを心の欲望のままに汚れへと引き渡し、彼らが互いに自分の体を辱めるに任せられました。</span>
<span className="v" id="v25" data-v="25" data-xref="ハバクク書 2:18; エレミヤ書 13:25; ヨハネの手紙第一 2:15–16"> 彼らは神の真理を偽りと取り替え、創造者ではなく造られたものを拝み、それに仕えました。創造者こそ、永遠にほめたたえられる方です。アーメン。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ユダ 1:7; テモテへの手紙第一 1:10; ローマ人への手紙 1:24"> そのため、神は彼らを恥ずべき情欲に引き渡されました。女たちは自然な営みを、自然に反するものへと変え、</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 20:13; レビ記 18:22; ローマ人への手紙 1:23–24"> 同じように男たちも、女との自然な関係を捨てて互いに情欲を燃やし、男どうしで恥ずべきことを行い、その迷いにふさわしい報いを自分の身に受けました。</span>
<span className="v" id="v28" data-v="28" data-xref="テサロニケ人への第二の手紙 2:10–12; ローマ人への手紙 1:21; テトス 1:16"> 彼らは神を心に留めることをよしとしなかったので、神も彼らを堕落した思いに引き渡し、してはならないことをするに任せられました。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第二の手紙 12:20; 箴言 16:28; 詩篇 41:7"> 彼らは、あらゆる不義、性的不品行、邪悪、貪欲、悪意に満ち、ねたみ、殺意、争い、欺き、悪癖にあふれ、陰口をたたき、</span>
<span className="v" id="v30" data-v="30" data-xref="テモテへの第二の手紙 3:2; ユダ 1:16; ペテロの第二の手紙 2:18"> 人を中傷し、神を憎み、人を侮り、高ぶり、大言壮語し、悪事を考え出し、親に従わず、</span>
<span className="v" id="v31" data-v="31" data-xref="テモテへの第二の手紙 3:3; 箴言 18:2; ローマ人への手紙 3:11"> 悟りがなく、約束を破り、情愛がなく、人を赦さず、あわれみもありません。</span>
<span className="v" id="v32" data-v="32" data-xref="ローマ人への手紙 2:1–5; ローマ人への手紙 1:21; ローマ人への手紙 6:21"> 彼らは、このようなことを行う者は死に値するという神の定めを知っていながら、自ら行うだけでなく、それを行う者たちに賛同しています。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テモテへの手紙第一 2:7; ローマ人への手紙 1:9; ガラテヤ人への手紙 1:20"> 私はキリストにあって真実を語り、偽りを言いません。私の良心も聖霊によって共にあかししています。</span>
<span className="v" id="v2" data-v="2" data-xref="ピリピ人への手紙 3:18; 詩篇 119:136; エレミヤ書 13:17"> 私には大きな悲しみがあり、心には絶え間ない痛みがあります。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 32:32; エステル記 8:6; ローマ人への手紙 11:14"> 私の兄弟たち、肉による同胞のためなら、私自身がキリストから引き離され、呪われた者となってもよいとさえ願うほどです。</span>
<span className="v" id="v4" data-v="4" data-xref="エペソ人への手紙 2:12; 詩篇 147:19; ローマ人への手紙 9:6"> 彼らはイスラエル人です。子とされることも、栄光も、数々の契約も、律法を授けられたことも、礼拝も、数々の約束も、彼らのものです。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネ 10:30; ヨハネ 1:1–3; コロサイ人への手紙 1:16–19"> 父祖たちも彼らのものであり、肉によればキリストも彼らから出られました。キリストはすべてのものの上におられる神、永遠にほめたたえられる方です。アーメン。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ローマ人への手紙 2:28–29; ガラテヤ人への手紙 6:16; ローマ人への手紙 11:1–2"> しかし、神の言葉が無効になったわけではありません。イスラエルから出た者が皆、イスラエルなのではないからです。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 21:12; ヘブル人への手紙 11:18; ヨハネ 8:37–39"> また、アブラハムの子孫だからといって、皆が子どもなのでもありません。むしろ、「イサクから生まれる者が、あなたの子孫と呼ばれる」とあります。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネ 1:13; ローマ人への手紙 4:11–16; ガラテヤ人への手紙 3:26–29"> つまり、肉による子どもが神の子どもなのではなく、約束の子どもが子孫とみなされるのです。</span>
<span className="v" id="v9" data-v="9" data-xref="創世記 18:10; 創世記 18:14; 創世記 17:21"> 約束の言葉はこうです。「定められた時に私は来る。そのとき、サラに男の子が生まれる。」</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 25:21–23; ルカ 16:26; ローマ人への手紙 5:11"> それだけではありません。リベカもまた、ただ一人の人、私たちの父イサクによって身ごもりました。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテへの第二の手紙 1:9; エペソ人への手紙 1:4–5; ペテロの第二の手紙 1:10"> その子どもたちがまだ生まれず、善も悪も何も行っていないうちに、行いによらず、召す方によって、神の選びに基づく目的が揺るがず成り立つため、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NUは「行いによらず、召す方によって」という句を、11節の終わりではなく12節の初めに置いている。">a</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="創世記 25:22–23; サムエル記第二 8:14; 列王記第一 22:47"> 「兄は弟に仕える」と彼女に告げられました。</span>
<span className="v" id="v13" data-v="13" data-xref="マラキ書 1:2–3; 申命記 21:15; 創世記 29:33"> 「私はヤコブを愛し、エサウを憎んだ」と書かれているとおりです。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歴代誌 第二 19:7; 詩篇 145:17; 申命記 32:4"> では、何と言えばよいでしょう。神に不義があるのでしょうか。決してそうではありません。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 33:19; ローマ人への手紙 9:16; ミカ書 7:18"> 神はモーセにこう言われました。「私は、あわれもうとする者をあわれみ、慈しもうとする者を慈しむ。」</span>
<span className="v" id="v16" data-v="16" data-xref="エペソ人への手紙 2:8; マタイ 11:25–26; ペテロの手紙第一 2:9–10"> ですから、それは人の意志や努力によるのではなく、あわれんでくださる神によるのです。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 9:16; 箴言 16:4; 出エジプト記 14:17–18"> 聖書はファラオにこう言っています。「私があなたを立てたのは、まさにこの目的のためである。あなたによって私の力を示し、私の名が全地に告げ知らされるためである。」</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 11:20; 出エジプト記 4:21; ローマ人への手紙 9:15–16"> このように、神は望む者をあわれみ、望む者をかたくなにされます。</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="ダニエル書 4:35; 歴代誌 第二 20:6; コリント人への第一の手紙 15:12"> すると、あなたは私にこう言うでしょう。「それなら、なぜ神はなお人を責めるのですか。だれが神の意志に逆らえるでしょう。」</span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 29:16; イザヤ書 45:9–11; イザヤ書 64:8"> しかし、人よ、神に言い返すあなたは、いったい何者ですか。形造られたものが、形造った方に「なぜ私をこのように造ったのですか」と言うでしょうか。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 64:8; 箴言 16:4; テモテへの第二の手紙 2:20–21"> 陶器師には、同じ一塊の粘土から、一つを尊いことに用いる器に、もう一つを卑しいことに用いる器に造る権利があるのではありませんか。</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 16:4; ユダ 1:4; ローマ人への手紙 9:21"> では、神がご自分の怒りを示し、その力を知らせようとされながら、滅びのために備えられた怒りの器を深い忍耐をもって耐え忍ばれ、</span>
<span className="v" id="v23" data-v="23" data-xref="ローマ人への手紙 2:4; ペテロの手紙第一 1:2–5; コロサイ人への手紙 1:27"> また、栄光のために前もって備えられたあわれみの器に、ご自分の豊かな栄光を知らせようとされたとしても、何が言えるでしょう。</span>
<span className="v" id="v24" data-v="24" data-xref="コロサイ人への手紙 3:11; 使徒の働き 13:47–48; エペソ人への手紙 3:6–8"> その器とは、ユダヤ人だけでなく異邦人の中からも神に召された私たちのことです。</span>
<span className="v" id="v25" data-v="25" data-xref="ホセア書 2:23; ペテロの手紙第一 2:10; ヨハネ 16:27"> 神はホセア書でもこう言われます。<br /><span className="pl pl-1">「私の民でなかった者を『私の民』と呼び、</span><br /><span className="pl pl-2">愛されなかった女を『愛する者』と呼ぶ。」</span></span>
<span className="v" id="v26" data-v="26" data-xref="ホセア書 1:9–10; ヨハネの手紙第一 3:1–3; ガラテヤ人への手紙 3:26"> <span className="pl pl-1">「『あなたがたは私の民ではない』と言われたその場所で、</span><br /><span className="pl pl-2">彼らは『生ける神の子どもたち』と呼ばれる。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 10:20–23; ローマ人への手紙 11:4–6; イザヤ書 1:9"> また、イザヤはイスラエルについて叫んでいます。<br /><span className="pl pl-1">「イスラエルの子らの数が海の砂のようであっても、</span><br /><span className="pl pl-2">救われるのは残された者である。</span></span>
<span className="v" id="v28" data-v="28" data-xref="イザヤ書 10:23; ヨハネの黙示録 19:11; 使徒の働き 17:31"> <span className="pl pl-1">主は義をもってその働きを成し遂げ、速やかに終えられる。</span><br /><span className="pl pl-2">主は地上で、その働きを速やかに行われるからである。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 1:9; イザヤ書 13:19; アモス書 4:11"> さらに、イザヤが前もって言ったとおりです。<br /><span className="pl pl-1">「もし万軍の主</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ギリシャ語では「サバオト」、またはヘブル語では「ツェヴァオト」">b</a></sup><br /><span className="pl pl-1">が、私たちに子孫を残してくださらなかったなら、</span><br /><span className="pl pl-2">私たちはソドムのようになり、</span><br /><span className="pl pl-2">ゴモラと同じにされていただろう。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="ピリピ人への手紙 3:9; ヘブル人への手紙 11:7; ガラテヤ人への手紙 2:16"> では、何と言えばよいでしょう。義を追い求めなかった異邦人が義、すなわち信仰による義を得ました。</span>
<span className="v" id="v31" data-v="31" data-xref="ローマ人への手紙 11:7; ローマ人への手紙 3:20; ヤコブの手紙 2:10–11"> しかし、義の律法を追い求めたイスラエルは、その義の律法に到達しませんでした。</span>
<span className="v" id="v32" data-v="32" data-xref="コリント人への第一の手紙 1:23; ペテロの手紙第一 2:8; ルカ 7:23"> なぜでしょうか。信仰によってではなく、律法の行いによるかのように追い求めたからです。彼らは、つまずきの石につまずきました。</span>
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 28:16; イザヤ書 8:14–15; ローマ人への手紙 10:11"> こう書かれています。<br /><span className="pl pl-1">「見よ、</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「見よ」はギリシャ語「ἰδοὺ」に由来し、「見る」「注意を向ける」「よく見る」という意味で、しばしば間投詞として用いられる。">c</a></sup><br /><span className="pl pl-1">私はシオンにつまずきの石、妨げの岩を置く。</span><br /><span className="pl pl-2">この方を信じる者は、だれも失望に終わることがない。」</span></span>

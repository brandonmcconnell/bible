<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネ 3:18–19; コリント人への第二の手紙 5:17; ガラテヤ人への手紙 3:13"> ですから今、キリスト・イエスにある者、すなわち肉に従って歩まず、霊に従って歩む者には、有罪判決がありません。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NUは「肉に従って歩まず、霊に従って歩む者」を省いている。">a</a></sup></span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 6:14; コリント人への第二の手紙 3:17; ローマ人への手紙 6:18"> キリスト・イエスにある命の霊の法則が、私を罪と死の法則から解放したからです。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 13:39; ガラテヤ人への手紙 4:4–5; ヘブル人への手紙 7:18–19"> 肉によって弱くなったために律法にはできなかったことを、神は成し遂げられました。ご自分の御子を罪ある肉と似た姿で、罪のために遣わし、その肉において罪を罪に定められたのです。</span>
<span className="v" id="v4" data-v="4" data-xref="ガラテヤ人への手紙 5:16; ガラテヤ人への手紙 5:22–25; コロサイ人への手紙 1:22"> それは、肉に従わず、霊に従って歩む私たちのうちに、律法の要求が満たされるためでした。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第一の手紙 2:14; ガラテヤ人への手紙 5:19–25; ヨハネ 3:6"> 肉に従って生きる者は肉のことを思い、霊に従って生きる者は霊のことを思います。</span>
<span className="v" id="v6" data-v="6" data-xref="ガラテヤ人への手紙 6:8; ローマ人への手紙 8:7; ローマ人への手紙 8:13"> 肉の思いは死ですが、霊の思いは命と平和です。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第一の手紙 2:14; ヨハネの手紙第一 2:15–16; ヤコブの手紙 4:4"> 肉の思いは神に敵対します。神の律法に従わず、従うこともできないからです。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネ 3:5–6; ヘブル人への手紙 11:5–6; ローマ人への手紙 8:9"> 肉のうちにいる者は、神を喜ばせることができません。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ガラテヤ人への手紙 4:6; コリント人への第一の手紙 3:16; テモテへの第二の手紙 1:14"> しかし、神の霊があなたがたのうちに住んでいるなら、あなたがたは肉のうちではなく、霊のうちにいます。キリストの霊を持たない人は、キリストのものではありません。</span>
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 3:17; ガラテヤ人への手紙 2:20; コリント人への第二の手紙 5:21"> キリストがあなたがたのうちにおられるなら、体は罪のゆえに死んでいても、霊は義のゆえに生きています。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第二の手紙 4:14; ローマ人への手紙 6:4–5; コリント人への第二の手紙 4:11"> イエスを死者の中からよみがえらせた方の霊があなたがたのうちに住んでいるなら、キリスト・イエスを死者の中からよみがえらせた方は、あなたがたのうちに住むご自分の霊によって、あなたがたの死ぬべき体にも命を与えてくださいます。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 6:2–15; コリント人への第一の手紙 6:19–20; ペテロの手紙第一 4:2–3"> ですから兄弟たち、私たちは肉に対して、肉に従って生きる義務を負っているのではありません。</span>
<span className="v" id="v13" data-v="13" data-xref="ガラテヤ人への手紙 6:8; ペテロの手紙第一 2:11; コリント人への第一の手紙 9:27"> 肉に従って生きるなら、あなたがたは死ななければなりません。しかし、霊によって体の行いを殺すなら、あなたがたは生きます。</span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 5:18; ヨハネ 1:12; ガラテヤ人への手紙 3:26"> 神の霊に導かれる者は皆、神の子どもだからです。</span>
<span className="v" id="v15" data-v="15" data-xref="ガラテヤ人への手紙 4:5–7; テモテへの第二の手紙 1:7; コリント人への第一の手紙 2:12"> あなたがたは、再び恐れに陥れる奴隷の霊を受けたのではなく、子とする霊を受けました。この霊によって、私たちは「アバ！<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「アバ」は「父」または「お父さん」を意味するアラム語で、天の父に祈るとき、親愛と敬意を込めて用いることができる。">b</a></sup>父よ！」と叫びます。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヨハネの手紙第一 4:13; コリント人への第二の手紙 1:22; コリント人への第二の手紙 5:5"> 聖霊ご自身が、私たちの霊と共に、私たちが神の子どもであることをあかししてくださいます。</span>
<span className="v" id="v17" data-v="17" data-xref="ガラテヤ人への手紙 4:7; ガラテヤ人への手紙 3:29; エペソ人への手紙 3:6"> 子どもであるなら相続人でもあります。神の相続人であり、キリストと共同の相続人です。キリストと共に苦しむなら、共に栄光を受けることにもなるのです。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="コリント人への第二の手紙 4:17–18; ペテロの手紙第一 4:13; ペテロの手紙第一 1:5–7"> 今の時の苦しみは、私たちに現されようとしている栄光と比べるに値しないと、私は考えます。</span>
<span className="v" id="v19" data-v="19" data-xref="マラキ書 3:17–18; ローマ人への手紙 8:23; ヨハネの手紙第一 3:2"> 被造物は、神の子どもたちが現されるのを、切なる期待をもって待ち望んでいます。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 3:17–19; 創世記 5:29; ローマ人への手紙 8:22"> 被造物がむなしさに服従させられたのは、自ら望んだからではなく、服従させた方によるものでした。しかし、そこには希望があります。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの黙示録 22:3–5; 使徒の働き 3:21; ペテロの第二の手紙 3:13"> 被造物そのものも、朽ちることへの束縛から解放され、神の子どもたちの栄光に満ちた自由にあずかるからです。</span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 12:4; エレミヤ書 12:11; ヨハネ 16:21"> 被造物全体が今に至るまで、共にうめき、産みの苦しみを味わっていることを、私たちは知っています。</span>
<span className="v" id="v23" data-v="23" data-xref="ピリピ人への手紙 3:20–21; コリント人への第二の手紙 5:2–5; ヘブル人への手紙 9:28"> それだけではありません。聖霊の初穂を持つ私たち自身も、心の中でうめきながら、子とされること、すなわち自分の体が贖われることを待ち望んでいます。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第二の手紙 5:7; ヘブル人への手紙 11:1; コリント人への第二の手紙 4:18"> 私たちは、この希望のうちに救われました。目に見える希望は希望ではありません。目に見えているものを、だれがなお望むでしょうか。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 12:12; ヘブル人への手紙 10:36; 詩篇 27:14"> しかし、まだ見ていないものを望むなら、私たちは忍耐して待ち望みます。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="マタイ 10:20; エペソ人への手紙 6:18; ガラテヤ人への手紙 4:6"> 同じように、聖霊も私たちの弱さを助けてくださいます。私たちは、何をどのように祈るべきかを知りません。しかし聖霊ご自身が、言葉にできないうめきをもって私たちのために執り成してくださいます。</span>
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 17:10; ヨハネの手紙第一 5:14–15; エペソ人への手紙 2:18"> 人の心を探る方は、聖霊の思いが何であるかをご存じです。聖霊が神のみこころに従って、聖徒たちのために執り成してくださるからです。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ペテロの手紙第一 5:10; ヤコブの手紙 1:12; 創世記 50:20"> 神を愛する人々、すなわち、神の目的に従って召された人々のためには、すべてのことが共に働いて益となることを、私たちは知っています。</span>
<span className="v" id="v29" data-v="29" data-xref="エペソ人への手紙 1:4–5; エレミヤ書 1:5; エペソ人への手紙 1:11"> 神は前もって知っておられた人々を、御子のかたちに似た者となるようにあらかじめ定められました。それは、御子が多くの兄弟たち<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="ここや、文脈上可能な箇所で「兄弟たち」と訳された言葉は、「兄弟姉妹」または「きょうだいたち」と訳すこともできる。">c</a></sup>の中で長子となるためです。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの黙示録 17:14; ローマ人への手紙 8:28; エペソ人への手紙 1:11"> 神はあらかじめ定めた人々を召し、召した人々を義とし、義とした人々に栄光をお与えになりました。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="詩篇 118:6; エレミヤ書 1:19; 詩篇 56:11"> では、これらのことについて何と言えばよいでしょう。神が私たちの味方なら、だれが私たちに敵対できるでしょうか。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨハネ 3:16; ローマ人への手紙 8:28; 詩篇 84:11"> ご自分の御子さえ惜しまず、私たちすべてのために引き渡された方が、どうして御子と共に、すべてのものを私たちに無償で与えてくださらないことがあるでしょうか。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨハネの黙示録 12:10–11; イザヤ書 50:8–9; イザヤ書 54:17"> だれが、神に選ばれた者たちを訴えることができるでしょう。義と認めるのは神です。</span>
<span className="v" id="v34" data-v="34" data-xref="ヘブル人への手紙 7:25; ローマ人への手紙 8:27; ヘブル人への手紙 9:24"> 罪に定める者がいるでしょうか。キリストは、死んでくださった方、いや、それ以上に、死者の中からよみがえらされ、神の右におられ、私たちのために執り成してくださる方です。</span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="ヨハネ 10:28; 詩篇 103:17; ヨハネ 16:33"> だれが私たちをキリストの愛から引き離すことができるでしょう。苦難でしょうか、苦悩でしょうか、迫害でしょうか、飢えでしょうか、裸でしょうか、危険でしょうか、剣でしょうか。</span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 44:22; イザヤ書 53:7; コリント人への第一の手紙 15:30"> こう書かれています。<br /><span className="pl pl-1">「あなたのために、私たちは一日中殺され続け、</span><br /><span className="pl pl-2">屠られる羊のようにみなされています。」</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="コリント人への第一の手紙 15:57; ヨハネの手紙第一 4:4; コリント人への第二の手紙 2:14"> いいえ、これらすべての中にあっても、私たちは、私たちを愛してくださった方によって、圧倒的な勝利を収めています。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨハネ 10:28; ローマ人への手紙 14:8; テモテへの第二の手紙 1:12"> 私は確信しています。死も命も、御使いたちも支配者たちも、今あるものも後に来るものも、力あるものも、</span>
<span className="v" id="v39" data-v="39" data-xref="ヨハネ 10:28–30; ローマ人への手紙 8:35; ローマ人への手紙 5:8"> 高いところにあるものも深いところにあるものも、そのほかどんな被造物も、私たちの主キリスト・イエスにある神の愛から、私たちを引き離すことはできません。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王記第一 12:32–33; 列王記第二 23:17; テサロニケ人への手紙第一 4:15"> ヤロブアムが香をたくために祭壇のそばに立っていたとき、神の人が主のことばによってユダからベテルにやって来た。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 36:1; 列王記第二 23:15–18; 列王記第二 22:1–2"> 彼は祭壇に向かって主のことばによって叫んで言った。「祭壇よ、祭壇よ、主はこう言われる。『見よ、ダビデの家にヨシヤという名の子が生まれる。彼はあなたの上で香をたく高き所の祭司たちをあなたの上でいけにえとし、人の骨があなたの上で焼かれる。』」</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第一の手紙 1:22; 出エジプト記 4:3–5; 士師記 6:17"> 彼はその日、一つのしるしを与えて言った。「これは主が語られたしるしである。見よ、祭壇は裂け、その上の灰は注ぎ出される。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 11:5; 歴代誌 第二 18:25–27; ルカ 6:10"> ヤロブアム王は、神の人がベテルの祭壇に向かって叫ぶのを聞くと、祭壇から手を伸ばして、「彼を捕らえよ！」と言った。すると、彼に向かって伸ばした手が動かなくなり、引き戻すことができなくなった。</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第一 13:3; エレミヤ書 28:16–17; 申命記 18:22"> 神の人が主のことばによって与えたしるしにしたがって、祭壇は裂け、灰は祭壇から注ぎ出された。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 9:28; 使徒の働き 8:24; 出エジプト記 10:17"> 王は神の人に言った。「どうか、あなたの神、主に取りなし、わたしの手が元どおりになるよう祈ってくれ。」神の人が主に祈ると、王の手は元どおりになり、以前のようになった。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王記第二 5:15; サムエル記第一 9:7–8; 士師記 13:15"> 王は神の人に言った。「わたしと一緒に家に来て、食事をして力をつけてくれ。あなたに贈り物をしよう。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="民数記 24:13; 民数記 22:18; マルコ 6:23"> 神の人は王に言った。「たとえあなたがあなたの家の半分をわたしに与えても、わたしはあなたと一緒には行きません。わたしはこの場所でパンを食べず、水を飲むこともしません。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネ 13:17; 申命記 13:13–18; ローマ人への手紙 16:17"> 『パンを食べず、水を飲まず、来た道を帰ってはならない』と、主のことばによってわたしに命じられたからです。」</span>
<span className="v" id="v10" data-v="10"> そこで彼は別の道から行き、ベテルに来た道を帰らなかった。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王記第二 23:18; 列王記第一 13:20–21; 民数記 24:2"> さて、ベテルには一人の年老いた預言者が住んでいた。その息子たちの一人が来て、神の人がその日ベテルで行ったすべてのことを彼に告げた。神の人が王に語った言葉も、彼らは父に告げた。</span>
<span className="v" id="v12" data-v="12"> 父は彼らに言った。「その人はどの道を行ったのか。」息子たちは、ユダから来た神の人が行った道を見ていた。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 10:4; サムエル記第二 19:26; 士師記 5:10"> 彼は息子たちに言った。「わたしのためにろばに鞍を置いてくれ。」彼らが彼のためにろばに鞍を置くと、彼はそれに乗り、</span>
<span className="v" id="v14" data-v="14" data-xref="ピリピ人への手紙 4:12–13; コリント人への第二の手紙 11:27; コリント人への第一の手紙 4:11–12"> 預言者は神の人の後を追い、彼が樫の木の下に座っているのを見つけて言った。「あなたがユダから来た神の人ですか。」<br />彼は「わたしです」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 預言者は言った。「わたしと一緒に家に来て、パンを食べてください。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王記第一 13:8–9; マタイ 16:23; 民数記 22:19"> 彼は言った。「わたしはあなたとともに引き返し、あなたと一緒に行くことはできません。またわたしはこの場所であなたとともにパンを食べず、水を飲むこともしません。</span>
<span className="v" id="v17" data-v="17" data-xref="列王記第一 20:35; テサロニケ人への手紙第一 4:15; 列王記第一 13:1"> 主のことばによってわたしに言われたからです。『あなたはそこでパンを食べず、水を飲んではならない。来た道を引き返してはならない。』」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨハネの手紙第一 4:1; マタイ 7:15; 民数記 22:35"> 彼は言った。「わたしもあなたと同じ預言者です。そして御使いが主のことばによってわたしに語り、『彼をあなたの家に連れ帰り、パンを食べ、水を飲ませよ』と言いました。」しかし、彼はその人に嘘をついていた。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命記 13:1; 創世記 3:6; 使徒の働き 4:19"> そこで神の人は預言者とともに引き返し、その家でパンを食べ、水を飲んだ。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="マタイ 7:22; 民数記 24:4; 民数記 24:16–24"> 彼らが食卓に座っていたとき、彼を連れ帰った預言者に主のことばが臨んだ。</span>
<span className="v" id="v21" data-v="21" data-xref="列王記第一 13:17; サムエル記第一 13:13–14; サムエル記第一 4:18"> 彼はユダから来た神の人に向かって叫んだ。「主はこう言われる。『あなたは主のことばに背き、あなたの神、主が命じられた戒めを守らず、</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 14:18–20; 列王記第一 14:13; エレミヤ書 22:18–19"> 引き返して、「パンを食べず、水を飲んではならない」と彼があなたに言われた場所でパンを食べ、水を飲んだので、あなたの死体はあなたの父祖たちの墓に入らない。』」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 彼がパンを食べ、水を飲んだ後、彼を連れ帰った預言者は、その人のためにろばに鞍を置いた。</span>
<span className="v" id="v24" data-v="24" data-xref="列王記第一 20:36; 列王記第二 2:24; 箴言 26:13"> 神の人が立ち去ると、道で獅子に出会い、殺された。その死体は道に倒れ、ろばはそのそばに立ち、獅子も死体のそばに立っていた。</span>
<span className="v" id="v25" data-v="25" data-xref="列王記第一 13:11"> 通りかかった人々は、道に倒れている死体と、そのそばに立つ獅子を見て、年老いた預言者の住む町へ行き、それを告げた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="エゼキエル書 9:6; 箴言 11:31; 詩篇 119:120"> 彼を道から連れ帰った預言者はそれを聞いて言った。「それは主のことばに背いた神の人だ。主は語られたことばどおり、彼を獅子に渡された。獅子が彼を襲い、殺したのだ。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 彼は息子たちに語って、「わたしのためにろばに鞍を置いてくれ」と言った。彼らは鞍を置いた。</span>
<span className="v" id="v28" data-v="28" data-xref="列王記第一 17:6; 詩篇 148:7–8; ダニエル書 6:22–24"> 彼が行ってみると、死体は道に倒れ、ろばと獅子がそのそばに立っていた。獅子は死体を食べず、ろばにも襲いかかっていなかった。</span>
<span className="v" id="v29" data-v="29"> 預言者は神の人の死体を取り上げ、それをろばに載せて持ち帰った。年老いた預言者は彼のために泣き悲しみ、彼を葬るために町に来た。</span>
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 22:18; 使徒の働き 8:2; 列王記第一 14:13"> 彼はその死体を自分の墓に納めた。人々は彼のために、「ああ、わたしの兄弟よ！」と言って泣き悲しんだ。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王記第二 23:17–18; 民数記 23:10; ルカ 16:22–23"> 彼を葬った後、彼は息子たちに言った。「わたしが死んだら、神の人が葬られた墓にわたしを葬り、わたしの骨を彼の骨のそばに置いてくれ。</span>
<span className="v" id="v32" data-v="32" data-xref="列王記第一 16:24; 列王記第一 13:2; 列王記第一 12:31"> 彼が主のことばによって、ベテルの祭壇と、サマリアの町々にある高き所のすべての神殿に向かって叫んだことばは、必ず実現するからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="歴代誌 第二 11:15; 歴代誌 第二 13:9; 民数記 17:12–13"> このことの後にも、ヤロブアムはその悪い道から立ち返らず、再びすべての民の中から高き所の祭司たちを任命した。彼はだれでも望む者を聖別し、その者が高き所の祭司たちの一人となるようにした。</span>
<span className="v" id="v34" data-v="34" data-xref="列王記第一 14:10; 列王記第一 15:29–30; 列王記第一 12:30"> このことはヤロブアムの家にとって罪となり、それを地の面から絶ち、滅ぼすことになった。</span>
</div>
</div>

<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="1KI" data-book-slug="1-kings" data-book-name="列王記第一" data-chapter="16" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌 第二 20:34; 歴代誌 第二 19:2; 列王記第一 16:7"> 主のことばが、バシャに対してハナニの息子イエフに臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="列王記第一 15:34; 列王記第一 14:7; サムエル記第一 2:8"> 「わたしはあなたをちりの中から引き上げ、わたしの民イスラエルの君主とした。しかし、あなたはヤロブアムの道を歩み、わたしの民イスラエルに罪を犯させ、その罪によってわたしの怒りを引き起こした。</span>
<span className="v" id="v3" data-v="3" data-xref="列王記第一 14:10; 列王記第一 15:29–30; イザヤ書 66:24"> 見よ、わたしはバシャとその家を完全に一掃し、あなたの家をネバテの息子ヤロブアムの家のようにする。</span>
<span className="v" id="v4" data-v="4" data-xref="列王記第一 14:11; 列王記第一 21:24"> バシャに属する者で町で死ぬ者は犬が食い、野で死ぬ者は空の鳥が食う。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王記第一 14:19; 列王記第一 15:31; 歴代誌 第二 16:1–6"> バシャのその他の事績、彼が行ったこと、および彼の力は、イスラエルの王たちの年代記の書に記されているではないか。</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第一 14:17; 列王記第一 15:21; 列王記第一 16:13–14"> バシャは父祖たちとともに眠りにつき、ティルツァに葬られた。そしてその息子エラが彼に代わって王となった。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王記第一 14:14; ホセア書 1:4; 詩篇 115:4"> さらに、預言者ハナニの息子イエフを通して、主のことばがバシャとその家に臨んだ。彼が主の目に悪とされることをことごとく行い、手のわざによって主の怒りを引き起こしてヤロブアムの家のようになったこと、またヤロブアムの家を打ち滅ぼしたことのためであった。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> ユダの王アサの第二十六年に、バシャの息子エラがティルツァでイスラエルを治め始め、二年間統治した。</span>
<span className="v" id="v9" data-v="9" data-xref="列王記第一 18:3; 創世記 39:4; ダニエル書 5:1–4"> 戦車隊の半数を率いる隊長であった家臣ジムリは、彼に対して陰謀を企てた。エラはティルツァで、宮廷を管理するアルツァの家におり、飲んで酔っていた。</span>
<span className="v" id="v10" data-v="10" data-xref="列王記第二 9:31"> ユダの王アサの第二十七年に、ジムリは入って来て彼を打ち殺し、彼に代わって王となった。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="サムエル記第一 25:22; 列王記第一 16:3; 列王記第一 15:29"> 彼は王となって王座に座るやいなや、バシャの全家を打ち、バシャ家の男子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="直訳では「壁に向かって放尿する者」。男子を指すヘブル語の慣用表現。">a</a></sup>を一人も残さなかった。親族も友人も残さなかった。</span>
<span className="v" id="v12" data-v="12" data-xref="列王記第一 16:1; 列王記第一 16:7; 歴代誌 第二 10:15"> このようにして、主が預言者イエフを通してバシャに対して語られた言葉のとおりに、ジムリはバシャの全家を滅ぼした。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 32:21; 列王記第一 15:30; イザヤ書 41:29"> これはバシャとその息子エラが犯し、イスラエルに犯させたすべての罪のためであった。彼らはむなしい偶像によって、イスラエルの神、主の怒りを引き起こした。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> エラのその他の事績と、彼が行ったすべてのことは、イスラエルの王たちの年代記の書に記されているではないか。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王記第一 15:27; ヨシュア記 19:44; ヨブ記 20:5"> ユダの王アサの第二十七年に、ジムリはティルツァで七日間統治した。さて、民はペリシテ人に属するギベトンに対して陣を敷いていた。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代誌 第二 22:2; 列王記第二 8:26; ミカ書 6:16"> 陣を敷いていた民は、「ジムリが陰謀を企て、また王を打った」ということを聞いた。それゆえ、全イスラエルはその日、陣営の中で軍の長オムリをイスラエルの王とした。</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 9:50; ルカ 19:43–44; 列王記第二 18:9–12"> オムリと彼とともにいた全イスラエルはギベトンから上って行き、ティルツァを包囲した。</span>
<span className="v" id="v18" data-v="18" data-xref="サムエル記第二 17:23; サムエル記第一 31:4–5; ヨブ記 2:9–10"> ジムリは町が攻め取られたのを見ると、王宮の城郭に入り、自分もろとも王宮に火を放って死んだ。</span>
<span className="v" id="v19" data-v="19" data-xref="列王記第一 15:26; 列王記第一 14:16; 列王記第一 12:28"> これは、彼が主の目に悪とされることを行い、ヤロブアムの道を歩み、彼が行った罪によってイスラエルに罪を犯させた、彼の罪のためであった。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王記第一 16:14; 列王記第一 16:5; 列王記第一 16:27"> ジムリのその他の事績と、彼が企てた反逆は、イスラエルの王たちの年代記の書に記されているではないか。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="マタイ 12:25; エペソ人への手紙 4:3–5; 箴言 28:2"> その時、イスラエルの民は二つに分かれた。民の半分はギナテの息子ティブニに従って彼を王としようとし、半分はオムリに従った。</span>
<span className="v" id="v22" data-v="22"> しかし、オムリに従った民は、ギナテの息子ティブニに従った民に打ち勝った。こうしてティブニは死に、オムリが王となった。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王記第一 16:8; 列王記第一 16:29; 歴代誌 第二 22:2"> ユダの王アサの第三十一年に、オムリはイスラエルを治め始め、十二年間統治した。彼はティルツァで六年間治めた。</span>
<span className="v" id="v24" data-v="24" data-xref="列王記第一 13:32; 列王記第一 16:32; 使徒の働き 8:5–8"> 彼はシェメルからサマリアの丘を銀二タラント<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一タラントは約30キログラム、または66ポンドである。">b</a></sup>で買い取った。彼はその丘の上に町を建て、丘の所有者シェメルの名にちなんで、その建てた町の名をサマリアと呼んだ。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ミカ書 6:16; 列王記第一 16:30–31; 列王記第一 14:9"> オムリは主の目に悪とされることを行い、それまでのだれよりも悪を行った。</span>
<span className="v" id="v26" data-v="26" data-xref="列王記第一 16:19; 列王記第一 16:13; 列王記第一 12:26–33"> 彼はネバテの息子ヤロブアムの道と、ヤロブアムがイスラエルに犯させた罪の道をことごとく歩み、むなしい偶像によってイスラエルの神、主の怒りを引き起こした。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="列王記第一 16:20; 列王記第一 16:14; 列王記第一 16:5"> オムリが行ったその他の事績と、彼が示した力は、イスラエルの王たちの年代記の書に記されているではないか。</span>
<span className="v" id="v28" data-v="28"> オムリは父祖たちとともに眠りにつき、サマリアに葬られた。そしてその息子アハブが彼に代わって王となった。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> ユダの王アサの第三十八年に、オムリの息子アハブがイスラエルを治め始めた。オムリの息子アハブはサマリアで二十二年間イスラエルを治めた。</span>
<span className="v" id="v30" data-v="30" data-xref="列王記第一 16:25; 列王記第一 21:25; 列王記第一 14:9"> オムリの息子アハブは、それまでのだれよりも主の目に悪とされることを行った。</span>
<span className="v" id="v31" data-v="31" data-xref="列王記第二 17:16; 列王記第二 10:18; 士師記 18:7"> ネバテの息子ヤロブアムの罪を行うだけでは足りないかのように、彼はシドン人の王エトバアルの娘イゼベルを妻に迎え、バアルに仕えてこれを拝んだ。</span>
<span className="v" id="v32" data-v="32" data-xref="列王記第二 10:21; 列王記第二 10:26–27"> 彼はサマリアに建てたバアルの家の中に、バアルのための祭壇を築いた。</span>
<span className="v" id="v33" data-v="33" data-xref="列王記第二 13:6; 列王記第一 21:25; 列王記第二 21:3"> アハブはアシェラ像も造った。彼は、それまでのイスラエルのすべての王にも増して、イスラエルの神、主の怒りを引き起こした。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ヨシュア記 6:26; ヨシュア記 23:14–15; マタイ 24:35"> 彼の時代に、ベテル人ヒエルがエリコを建てた。彼は長子アビラムを失ってその基を据え、末の子セグブを失ってその門を立てた。これは主がヌンの子ヨシュアを通して語られた言葉のとおりであった。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 20:5; 列王記第一 13:33–34; サムエル記第一 31:2"> そのころ、ヤロブアムの息子アビヤが病気になった。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記第一 28:8; 列王記第一 11:29–38; サムエル記第二 14:2"> ヤロブアムは妻に言った。「起きて変装し、ヤロブアムの妻だと知られないようにして、シロへ行きなさい。そこには預言者アヒヤがいる。彼は、わたしがこの民の王になると語った者だ。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記第一 9:7–8; 列王記第一 13:7; 列王記第二 4:42"> パン十個と、菓子と、はちみつの入った壺を手に持って、彼のところに行きなさい。彼はこの子どもに何が起こるかをあなたに告げるだろう。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王記第一 11:29; サムエル記第一 3:2; サムエル記第一 4:15"> ヤロブアムの妻はそのようにして、立ち上がってシロへ行き、アヒヤの家に来た。さてアヒヤは、年老いて目がかすんでいたため、見ることができなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第二 6:8–12; 箴言 21:30; 列王記第二 4:27"> 主はアヒヤに言われた。「見よ、ヤロブアムの妻が、病気の息子について尋ねるために来る。彼女には次のように告げなさい。彼女は入って来るとき、別の女を装う。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ダニエル書 5:17–28; 使徒の働き 5:9–10; ルカ 20:20–23"> アヒヤは彼女が戸口から入る足音を聞くと、言った。「入りなさい、ヤロブアムの妻よ。なぜ別の女を装うのか。わたしは厳しい知らせを携えて、あなたのもとに遣わされている。</span>
<span className="v" id="v7" data-v="7" data-xref="列王記第一 16:2; サムエル記第二 12:7–8; サムエル記第一 15:16"> 行って、ヤロブアムに告げよ。『イスラエルの神、主はこう言われる。「わたしはあなたを民の中から引き上げ、わたしの民イスラエルの上の君主とした。</span>
<span className="v" id="v8" data-v="8" data-xref="列王記第一 15:5; 列王記第一 11:33–38; 歴代誌 第二 28:1"> わたしはダビデの家から王国を裂いてあなたに与えたが、あなたは、わたしの戒めを守り、心を尽くしてわたしに従い、わたしの目にかなうことだけを行ったわたしのしもべダビデのようではなかった。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 23:35; ネヘミヤ記 9:26; 詩篇 50:17"> あなたは自分よりも前にいたすべての者よりも悪いことを行った。あなたは自分のために他の神々や鋳造の像を造って、わたしを怒らせ、わたしをあなたの背後に投げ捨てた。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 32:36; 列王記第一 21:21; 列王記第二 14:26"> それゆえ見よ、わたしはヤロブアムの家に災いをもたらし、ヤロブアム家の男子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="直訳では「壁に向かって放尿する者」。男子を指すヘブル語の慣用表現。">a</a></sup>をことごとく断ち切る。奴隷であれ自由人であれ断ち切り、糞を掃き尽くすように、ヤロブアムの家を跡形もなく一掃する。</span>
<span className="v" id="v11" data-v="11" data-xref="列王記第一 16:4; エレミヤ書 15:3; 列王記第一 21:23–24"> ヤロブアムに属する者で町で死ぬ者は犬が食い、野で死ぬ者は空の鳥が食う。主がそう語られたからである。」』</span>
<span className="v" id="v12" data-v="12" data-xref="列王記第一 14:3; 列王記第一 14:16–17; 列王記第二 1:6"> だから、起きて自分の家へ帰りなさい。あなたの足が町に入るとき、その子は死ぬ。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代誌 第二 19:3; 歴代誌 第二 12:12; ヨブ記 19:28"> 全イスラエルは彼のために嘆き、彼を葬る。ヤロブアムの家で墓に入るのは彼だけである。ヤロブアムの家の中で、イスラエルの神、主に喜ばれるものが、彼のうちに見いだされたからだ。</span>
<span className="v" id="v14" data-v="14" data-xref="列王記第一 15:27–29; エゼキエル書 7:2–7; エゼキエル書 12:22–28"> 主はイスラエルの上に一人の王を起こされる。その王はヤロブアムの家を断ち切る。その日は来る。いや、今すでに来ている。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 23:15–16; 詩篇 52:5; 列王記第二 15:29"> 主は、水の中で葦が揺れるようにイスラエルを打ち、父祖たちに与えたこの良い地からイスラエルを根こぎにして、大河<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="すなわち、ユーフラテス川。">b</a></sup>の向こうへ散らす。彼らがアシェラ像を造り、主を怒らせたからである。</span>
<span className="v" id="v16" data-v="16" data-xref="列王記第一 15:34; 列王記第一 16:2; 列王記第一 13:34"> 彼はヤロブアムが犯した罪、またイスラエルに犯させた罪のゆえにイスラエルを引き渡される。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王記第一 15:33; 列王記第一 16:15; 列王記第一 16:23"> ヤロブアムの妻は立ち上がって去り、ティルツァに来た。彼女が家の敷居をまたぐと、子どもは死んだ。</span>
<span className="v" id="v18" data-v="18" data-xref="列王記第一 14:13"> 全イスラエルは、主がそのしもべである預言者アヒヤを通して語られた言葉のとおりに、彼を葬り、彼のために泣き悲しんだ。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="歴代誌 第二 13:2–20; 歴代誌上 27:24; 列王記第一 16:20"> ヤロブアムのその他の事績、彼がどのように戦い、どのように治めたかは、イスラエルの王たちの年代記の書に記されている。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨブ記 14:12; 詩篇 3:5; 列王記第一 11:43"> ヤロブアムが治めた日数は二十二年であった。彼は父祖たちとともに眠りにつき、その息子ナダブが彼に代わって王となった。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歴代誌 第二 12:13; 列王記第一 11:36; 列王記第一 14:31"> ソロモンの息子レハブアムはユダを治めた。王となったとき四十一歳で、主がご自分の御名を置くためにイスラエルの全部族から選ばれた町エルサレムで、十七年間治めた。母の名はナアマといい、アンモン人であった。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代誌 第二 12:1; コリント人への第一の手紙 10:22; 詩篇 78:58"> ユダは主の目に悪とされることを行い、その罪によって、父祖たちがした以上に主のねたみを引き起こした。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 12:2; イザヤ書 57:5; 列王記第二 17:9–10"> 彼らもまた、すべての高い丘の上と、すべての青々とした木の下に、自分たちのために高き所、石の柱、アシェラ像を建てたからである。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 23:17; コリント人への第一の手紙 6:9; 列王記第一 15:12"> また、その地には神殿男娼もいた。人々は、主がイスラエルの子らの前から追い払われた国々の忌むべきことのすべてにしたがって行った。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王記第一 11:40; 歴代誌 第二 12:2–4; 歴代誌 第二 12:9"> レハブアム王の第五年に、エジプトの王シシャクがエルサレムに攻め上って来た。</span>
<span className="v" id="v26" data-v="26" data-xref="列王記第一 15:18; 歴代誌 第二 9:15–16; 列王記第一 7:51"> 彼は主の家の財宝と、王の家の財宝を奪い去った。彼はすべてを奪い去り、ソロモンが造った金の盾もすべて奪い去った。</span>
<span className="v" id="v27" data-v="27" data-xref="サムエル記第一 8:11; サムエル記第一 22:17; 列王記第一 18:46"> レハブアム王はその代わりに青銅の盾を造り、王の家の戸口を守る護衛兵の長たちの手に委ねた。</span>
<span className="v" id="v28" data-v="28" data-xref="歴代誌 第二 12:11"> 王が主の家へ行くたびに、護衛兵がそれらを持ち、その後、彼らはそれらを護衛兵の部屋に戻した。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王記第一 22:45; 列王記第一 15:23; 列王記第一 14:19"> レハブアムのその他の事績と、彼が行ったすべてのことは、ユダの王たちの年代記の書に記されているではないか。</span>
<span className="v" id="v30" data-v="30" data-xref="列王記第一 12:24; 列王記第一 12:21; 列王記第一 15:6–7"> レハブアムとヤロブアムの間には常に戦いがあった。</span>
<span className="v" id="v31" data-v="31" data-xref="歴代誌 第二 12:16; マタイ 1:7; 列王記第一 15:3"> レハブアムは父祖たちとともに眠りにつき、ダビデの町で父祖たちとともに葬られた。彼の母の名はナアマといい、アンモン人であった。その息子アビヤムが彼に代わって王となった。</span>
</div>
</div>

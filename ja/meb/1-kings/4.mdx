<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="伝道者の書 1:12; 歴代誌 第二 9:30; 列王記第一 12:19–20"> ソロモン王は全イスラエルを治めていた。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 18:21; コリント人への第一の手紙 12:28; サムエル記第二 8:15–18"> 彼の高官たちは次のとおりである。祭司、ツァドクの息子アザルヤ、</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記第二 8:16; イザヤ書 62:6; 歴代誌上 18:15"> 書記官、シシャの息子たちであるエリホレフとアヒヤ、記録官、アヒルデの息子ヨシャファテ、</span>
<span className="v" id="v4" data-v="4" data-xref="列王記第一 2:35; 列王記第一 2:26–27"> 軍の長、エホヤダの息子ベナヤ、祭司、ツァドクとアビアタル、</span>
<span className="v" id="v5" data-v="5" data-xref="歴代誌上 27:33; サムエル記第二 15:37; サムエル記第二 16:16"> 代官たちの長、ナタンの息子アザルヤ、主要な大臣であり、王の友である、ナタンの息子ザブデ、</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第一 9:15; サムエル記第二 20:24; 列王記第一 12:18"> 宮内長、アヒシャル、強制労働に服する者たちの長、アブダの息子アドニラム。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歴代誌上 27:1–15"> ソロモンは全イスラエルの上に十二人の役人を置いており、彼らが王とその家族のために食糧を供給した。それぞれが年に一か月、食糧を供給することになっていた。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 24:33; 士師記 19:1; 士師記 17:1"> 彼らの名は次のとおりである。エフライムの山地のベン・フル、</span>
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 21:16; サムエル記第一 6:20; サムエル記第一 6:12"> マカツ、シャアルビム、ベテ・シェメシュ、エロン・ベテ・ハナンのベン・デケル、</span>
<span className="v" id="v10" data-v="10" data-xref="ヨシュア記 15:35; ヨシュア記 12:17; ヨシュア記 17:2"> アルボテのベン・ヘセド（彼にはソコとヘフェルの全地が属していた）、</span>
<span className="v" id="v11" data-v="11" data-xref="ヨシュア記 11:2; ヨシュア記 12:23; ヨシュア記 17:11"> ドルの全高地のベン・アビナダブ（彼はソロモンの娘タファテを妻としていた）、</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 17:11; 士師記 5:19; ヨシュア記 3:16"> タアナク、メギド、そしてエズレルの下にあるツァレタンのそばの全ベテ・シャン、すなわちベテ・シャンからアベル・メホラ、さらにヨクメアムの向こうに至るまでのアヒルデの息子バアナ、</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 3:4; 民数記 32:41; 列王記第一 22:3"> ラモテ・ギレアデのベン・ゲベル（彼にはギレアデにあるマナセの息子ヤイルの町々が属していた。また彼には、城壁と青銅のかんぬきを持つ六十の大きな町々があるバシャンのアルゴブの地方が属していた）、</span>
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 13:26; サムエル記第二 17:24; サムエル記第二 2:8"> マハナイムのイドの息子アヒナダブ、</span>
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 19:32–39; サムエル記第二 15:27; サムエル記第一 18:18"> ナフタリのアヒマアツ（彼もソロモンの娘バセマトを妻としてめとっていた）、</span>
<span className="v" id="v16" data-v="16" data-xref="ヨシュア記 19:24–31; サムエル記第二 15:32"> アシェルとベアロテのフシャイの息子バアナ、</span>
<span className="v" id="v17" data-v="17" data-xref="ヨシュア記 19:17–23"> イッサカルのパルアの息子ヨシャファテ、</span>
<span className="v" id="v18" data-v="18" data-xref="列王記第一 1:8; ヨシュア記 18:20–28; ゼカリヤ書 12:13"> ベニヤミンのエラの息子シメイ、</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 2:26–17; ヨシュア記 13:9–12; 民数記 21:21–35"> ウリの息子ゲベルは、ギレアデの地、すなわちアモリ人の王シホンの国とバシャンの王オグの国を担当した。この地には彼一人だけが役人として置かれていた。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="創世記 22:17; 列王記第一 3:8; 創世記 32:12"> ユダとイスラエルは海辺の砂のように数が多く、食べたり飲んだりして喜んでいた。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 15:18; ヨシュア記 1:4; 詩篇 68:29"> ソロモンは、大河からペリシテ人の地、さらにエジプトの国境に至るまでのすべての王国を治めた。彼らは貢ぎ物を携え、ソロモンの生涯を通じて彼に仕えた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> ソロモンの一日分の食糧は、上等の小麦粉三十コル<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一コルは一ホメルと同じで、約211リットル、または6ブッシェルである。">a</a></sup>、粗挽きの小麦粉六十コル、</span>
<span className="v" id="v23" data-v="23" data-xref="ネヘミヤ記 5:17–18"> 肥えた牛十頭、牧草地の牛二十頭、羊百頭であり、このほかに鹿、ガゼル、ノロジカ、肥えた鳥もあった。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代誌上 22:9; 詩篇 72:11; 詩篇 72:3"> 彼は大河の西側の全地方、ティフサからガザに至るまで、大河の西側のすべての王を支配し、四方に平和を得ていた。</span>
<span className="v" id="v25" data-v="25" data-xref="ミカ書 4:4; ゼカリヤ書 3:10; 士師記 20:1"> ユダとイスラエルは、ソロモンの生涯にわたり、ダンからベエルシェバに至るまで、それぞれ自分のぶどうの木の下と、いちじくの木の下で安全に住んでいた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歴代誌 第二 1:14; 歴代誌 第二 9:25; サムエル記第二 8:4"> ソロモンには戦車用の馬の厩舎が四万と、騎兵が一万二千人いた。</span>
<span className="v" id="v27" data-v="27"> 十二人の役人は、それぞれ担当の月に、ソロモン王と王の食卓に連なるすべての者の食糧を供給し、何一つ不足させなかった。</span>
<span className="v" id="v28" data-v="28" data-xref="エステル記 8:10; エステル記 8:14; ミカ書 1:13"> 彼らはまた、それぞれが命じられたとおりに、馬や早馬のための大麦とわらを役人たちがいる場所に持って来た。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王記第一 3:12; ヤコブの手紙 3:17; 列王記第一 4:20"> 神はソロモンに、非常に豊かな知恵と悟り、海辺の砂のように広い心をお与えになった。</span>
<span className="v" id="v30" data-v="30" data-xref="ダニエル書 5:11–12; 創世記 25:6; ダニエル書 1:20"> ソロモンの知恵は、東のすべての子らの知恵と、エジプトのすべての知恵に勝っていた。</span>
<span className="v" id="v31" data-v="31" data-xref="歴代誌上 2:6; 歴代誌上 15:19; 列王記第一 3:12"> 彼はすべての人よりも賢く、エズラ人エタン、マホルの息子たちであるヘマン、カルコル、ダルダよりも賢かった。彼の名声は周囲のすべての国々に広まった。</span>
<span className="v" id="v32" data-v="32" data-xref="雅歌 1:1–17; マタイ 13:35; 箴言 1:1–31"> 彼は三千の箴言を語り、彼の歌は千五であった。</span>
<span className="v" id="v33" data-v="33" data-xref="列王記第二 19:23; 詩篇 51:7; 詩篇 92:12"> 彼はレバノンにある杉から、城壁に生えるヒソプに至るまで、木々について語った。彼はまた、獣、鳥、這うもの、魚についても語った。</span>
<span className="v" id="v34" data-v="34" data-xref="歴代誌 第二 9:23; 列王記第一 10:1; 歴代誌 第二 9:1"> あらゆる民の中から人々がソロモンの知恵を聞きに来た。彼の知恵を聞き及んだ地上のすべての王たちからも、人々が遣わされて来た。</span>
</div>

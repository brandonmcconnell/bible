<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 6:33; 歴代誌 第二 28:22; ヨシュア記 19:18"> これらのことの後、イズレエル人ナボテがイズレエルにぶどう畑を持っていた。それはイスラエルの王アハブの宮殿のそばにあった。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記第一 8:14; ヤコブの手紙 1:14–15; テモテへの手紙第一 6:9"> アハブはナボテに言った。「あなたのぶどう畑を譲ってほしい。わたしの家のすぐそばにあるので、野菜畑にしたい。その代わり、もっと良いぶどう畑を与えよう。望むなら、代価を銀で払おう。」</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 36:7; レビ記 25:23; エゼキエル書 46:18"> ナボテはアハブに言った。「主にかけて、父祖の相続地をあなたにお渡しすることはできません。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王記第一 20:43; ヤコブの手紙 1:14; ヨナ書 4:9"> アハブは、イズレエル人ナボテが「父祖の相続地をあなたには渡さない」と言ったため、不機嫌になり、腹を立てて家に帰った。寝台に横たわって顔を背け、食事を取ろうとしなかった。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王記第一 16:31; 創世記 3:6; 列王記第一 19:2"> 妻イゼベルが来て尋ねた。「なぜそんなに不機嫌で、食事も取らないのですか。」</span>
<span className="v" id="v6" data-v="6" data-xref="エステル記 5:9–14; ヤコブの手紙 4:2–7; テモテへの手紙第一 6:9–10"> 彼は彼女に言った。「わたしがイズレエル人ナボテに、『あなたのぶどう畑を金で譲ってくれ。あるいは、もし望むなら、その代わりに別のぶどう畑をやろう』と言ったからだ。しかし彼は、『わたしのぶどう畑をあなたには与えない』と言った。」</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記第一 8:14; ミカ書 7:3; サムエル記第二 13:4"> 妻イゼベルは言った。「それでもあなたはイスラエルの王ですか。起きて食事をし、元気を出しなさい。イズレエル人ナボテのぶどう畑は、わたしがあなたに差し上げます。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ネヘミヤ記 6:5; 列王記第二 10:11; エズラ記 4:7–8"> そこで彼女はアハブの名で手紙を書き、彼の印を押して封をし、ナボテの町に住む長老たちと貴族たちにその手紙を送った。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 58:4; マタイ 23:13; ルカ 20:47"> 手紙にはこう書いた。「断食を布告し、ナボテを民の上席に座らせよ。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 22:28; 使徒の働き 6:11; レビ記 24:15–16"> そして二人のならず者を彼の前に座らせ、彼らにこう証言させよ。『あなたは神と王を呪った。』それから彼を外に連れ出し、石で打って殺せ。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒の働き 4:19; レビ記 19:15; 列王記第二 10:6–7"> ナボテの町の人々、すなわち町に住む長老と貴族たちは、イゼベルが送った手紙に書かれていたとおりに行った。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 58:4; 列王記第一 21:8–10"> 彼らは断食を布告し、ナボテを民の頭に座らせた。</span>
<span className="v" id="v13" data-v="13" data-xref="列王記第二 9:26; 申命記 22:24; 伝道者の書 10:20"> 二人のならず者が入って来て、彼の前に座った。ならず者たちは民の前でナボテに対して証言し、「ナボテは神と王を呪った」と言った。そこで彼らは彼を町の外に連れ出し、石で打って殺した。</span>
<span className="v" id="v14" data-v="14" data-xref="伝道者の書 8:14; サムエル記第二 11:14–24; 伝道者の書 5:8"> それから彼らはイゼベルに人を遣わして、「ナボテは石で打たれて死にました」と告げた。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="箴言 1:10–16; 箴言 4:17; 列王記第一 21:7"> イゼベルはナボテが石で打たれて死んだと聞くと、アハブに言った。「起きて、イズレエル人ナボテが銀で売ることを拒んだぶどう畑を自分のものにしなさい。ナボテはもう生きていません。死んだのです。」</span>
<span className="v" id="v16" data-v="16" data-xref="オバデヤ書 1:12–14; ローマ人への手紙 1:32; サムエル記第二 11:25–27"> アハブはナボテが死んだと聞くと、イズレエル人ナボテのぶどう畑を自分のものにするため、立ってそこへ下って行った。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="詩篇 9:12; イザヤ書 26:21; 列王記第二 5:26"> 主のことばがティシュベ人エリヤに臨んだ。</span>
<span className="v" id="v18" data-v="18" data-xref="列王記第一 13:32; 歴代誌 第二 22:9"> 「立って、サマリアに住むイスラエルの王アハブに会いに行きなさい。見よ、彼はナボテのぶどう畑を自分のものにするため、そこへ下っている。</span>
<span className="v" id="v19" data-v="19" data-xref="列王記第一 22:38; サムエル記第二 12:9; ハバクク書 2:9"> あなたは彼にこう語りなさい。『主はこう言われる。「あなたは殺したうえに、所有までしようとするのか。」』また彼にこう言いなさい。『主はこう言われる。「犬がナボテの血をなめたその場所で、犬はあなたの血、あなた自身の血をもなめる。」』」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王記第二 17:17; ローマ人への手紙 7:14; 列王記第一 21:25"> アハブはエリヤに言った。「わが敵よ、とうとうわたしを見つけたか。」エリヤは答えた。「見つけました。あなたが主の目に悪とされることを行うため、自分を売り渡したからです。</span>
<span className="v" id="v21" data-v="21" data-xref="列王記第一 14:10; サムエル記第一 25:34; 列王記第二 10:1–7"> 見よ、わたしはあなたに災いをもたらし、あなたを一掃する。アハブ家の男子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="直訳では「壁に向かって放尿する者」。男子を指すヘブル語の慣用表現。">a</a></sup>をことごとく断ち切る。イスラエルにいる奴隷も自由人も断ち切る。</span>
<span className="v" id="v22" data-v="22" data-xref="列王記第一 16:3; 列王記第一 14:16; 列王記第一 16:11"> あなたの家をネバテの息子ヤロブアムの家のようにし、アヒヤの息子バシャの家のようにする。あなたがわたしの怒りを引き起こし、イスラエルに罪を犯させたからである。</span>
<span className="v" id="v23" data-v="23" data-xref="列王記第二 9:10; 列王記第二 9:30–37; 列王記第一 21:25"> 主はイゼベルについても言われた。『犬がイズレエルの城壁のそばでイゼベルを食うであろう。』</span>
<span className="v" id="v24" data-v="24" data-xref="列王記第一 16:4; 列王記第一 14:11; エレミヤ書 15:3"> アハブに属する者で町で死ぬ者は犬が食い、野で死ぬ者は空の鳥が食う。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="箴言 22:14; 列王記第一 21:20; 列王記第一 16:30–33"> （実際、妻イゼベルにそそのかされて、主の目に悪とされることを行うために自分を売ったアハブのような者は一人もいなかった。</span>
<span className="v" id="v26" data-v="26" data-xref="列王記第二 21:11; 創世記 15:16; レビ記 18:25–30"> 彼は主がイスラエルの子らの前から追い払ったアモリ人が行ったすべてのことと同じように、偶像に従って非常に忌むべきことを行った。）</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="列王記第二 6:30; 創世記 37:34; サムエル記第二 3:31"> アハブはこれらのことばを聞くと、服を引き裂き、粗布を身にまとって断食した。粗布をまとったまま横になり、うなだれて歩いた。</span>
<span className="v" id="v28" data-v="28"> 主のことばがティシュベ人エリヤに臨んだ。</span>
<span className="v" id="v29" data-v="29" data-xref="ペテロの第二の手紙 3:9; ミカ書 7:18; 詩篇 86:15"> 「アハブがわたしの前にへりくだったのを見たか。彼がわたしの前にへりくだったので、彼の生涯には災いをもたらさない。その息子の時代に、彼の家へ災いをもたらす。」</span>
</div>
</div>

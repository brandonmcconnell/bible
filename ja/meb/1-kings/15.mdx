<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王記第一 14:31; 歴代誌 第二 13:1–22"> ネバテの息子ヤロブアム王の第十八年に、アビヤムはユダを治め始めた。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代誌 第二 13:2; 歴代誌 第二 11:20–22; 列王記第一 15:13"> 彼はエルサレムで三年間統治した。彼の母の名はマアカといい、アビシャロムの娘であった。</span>
<span className="v" id="v3" data-v="3" data-xref="列王記第一 11:4; 詩篇 119:80; 列王記第一 3:14"> 彼は父が先に歩んだ罪の道をことごとく歩んだ。彼の心は、父ダビデの心のようには、彼の神、主に対して全きものではなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="列王記第一 11:36; 歴代誌 第二 21:7; イザヤ書 37:35"> それでもダビデのゆえに、彼の神、主はエルサレムで彼に一つのともしびを与え、彼の後に息子を立ててエルサレムを堅くされた。</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第一 14:8; サムエル記第二 11:15–17; 列王記第一 15:3"> ダビデは主の目にかなうことを行い、その生涯のすべての日々において、ヘテ人ウリヤの事のほかは、主が彼に命じられたすべてのことから逸れなかったからである。</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第一 14:30"> レハブアムとヤロブアムの間には、彼の生涯のすべての日々において戦いがあった。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌 第二 13:2–22; 列王記第一 14:29"> アビヤムのその他の事績と、彼が行ったすべてのことは、ユダの王たちの年代記の書に記されているではないか。アビヤムとヤロブアムの間には戦いがあった。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代誌 第二 14:1; 列王記第一 14:31; マタイ 1:7–8"> アビヤムは父祖たちとともに眠りにつき、彼らは彼をダビデの町に葬った。そしてその息子アサが彼に代わって王となった。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> イスラエルの王ヤロブアムの第二十年に、アサはユダを治め始めた。</span>
<span className="v" id="v10" data-v="10" data-xref="列王記第一 15:2; 列王記第一 15:13; 歴代誌 第二 13:2"> 彼はエルサレムで四十一年間統治した。彼の母の名はマアカといい、アビシャロムの娘であった。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代誌 第二 14:2; 歴代誌 第二 15:17; 列王記第一 15:3"> アサは、彼の父ダビデが行ったように、主の目にかなうことを行った。</span>
<span className="v" id="v12" data-v="12" data-xref="列王記第一 22:46; 列王記第一 14:23–24; 歴代誌 第二 14:2–5"> 彼はその地から神殿男娼を取り除き、父祖たちが造ったすべての偶像を取り除いた。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 32:20; 申命記 7:5; ゼカリヤ書 13:3"> 彼はまた、彼の母マアカがアシェラのために忌むべき像を造ったので、彼女を王母の位から退けた。アサは彼女の像を切り倒し、キデロンの川でそれを焼いた。</span>
<span className="v" id="v14" data-v="14" data-xref="列王記第一 22:43; 列王記第一 8:61; 列王記第一 15:3"> しかし高き所は取り除かれなかった。それにもかかわらず、アサの心はその生涯の間、主に対して全きものであった。</span>
<span className="v" id="v15" data-v="15" data-xref="列王記第一 7:51; 歴代誌 第二 14:13; 歴代誌 第二 15:18"> 彼は彼の父が聖別したものと、彼自身が聖別したもの、すなわち銀、金、器を主の家に運び入れた。</span>
<span className="v" id="v16" data-v="16" data-xref="列王記第一 15:32; 列王記第一 14:30; 歴代誌 第二 16:1–6"> アサとイスラエルの王バシャの間には、彼らの日々のすべてにおいて戦いがあった。</span>
<span className="v" id="v17" data-v="17" data-xref="列王記第一 12:27; 歴代誌 第二 16:1–6; ヨシュア記 18:25"> イスラエルの王バシャはユダに攻め上り、ユダの王アサのもとへだれも出入りできないよう、ラマを築いた。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王記第一 14:26; 列王記第二 12:18; 列王記第一 11:23–24"> そこでアサは、主の家の宝物庫と王の家の宝物庫に残されていたすべての銀と金を取り、それらを自分のしもべたちの手に委ねた。そしてアサ王は彼らを、ダマスコに住むアラムの王、ヘジオンの息子タブリモンの息子ベン・ハダドに遣わして言った。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 1:31; 歴代誌 第二 16:7; ローマ人への手紙 3:8"> 「わたしとあなた、わたしの父とあなたの父の間には契約があります。わたしはあなたに銀と金の贈り物をお送りします。行って、イスラエルの王バシャとの契約を破棄してください。彼がわたしから去って行くためです。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王記第二 15:29; 士師記 18:29; ヨシュア記 11:2"> ベン・ハダドはアサ王に聞き従い、自分の軍の長たちをイスラエルの町々に遣わした。彼らはイヨン、ダン、アベル・ベテ・マアカ、およびナフタリの全地とともにキネロテのすべてを打った。</span>
<span className="v" id="v21" data-v="21" data-xref="列王記第一 14:17; 列王記第一 16:15–18; 歴代誌 第二 16:5"> バシャはそれを聞くと、ラマを建てるのをやめて、ティルツァに住んだ。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨシュア記 21:17; ヨシュア記 18:24; ヨシュア記 18:26"> そこでアサ王は全ユダに布告を出した。免除される者はだれもいなかった。彼らはバシャが建てていたラマの石と木材を運び去り、アサ王はそれらでベニヤミンのゲバとミツパを建てた。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="歴代誌 第二 16:11–14; 列王記第一 14:29–31; 列王記第一 15:7–8"> アサのその他のすべての事績、その力、行ったすべてのこと、建てた町々は、ユダの王たちの年代記の書に記されている。彼は年老いたとき、足を病んだ。</span>
<span className="v" id="v24" data-v="24" data-xref="マタイ 1:8; 列王記第一 22:41–43; 歴代誌 第二 17:1–9"> アサは父祖たちとともに眠りにつき、父ダビデの町に父祖たちとともに葬られた。そしてその息子ヨシャファテが彼に代わって王となった。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王記第一 14:20; 列王記第一 14:12"> ユダの王アサの第二年に、ヤロブアムの息子ナダブがイスラエルを治め始めた。彼は二年間イスラエルを治めた。</span>
<span className="v" id="v26" data-v="26" data-xref="列王記第一 14:16; 列王記第一 15:34; 列王記第一 15:30"> 彼は主の目に悪とされることを行い、父の道、すなわち父がイスラエルに犯させた罪の道を歩んだ。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 19:44; ヨシュア記 21:23; 列王記第一 14:14"> イッサカルの家の、アヒヤの息子バシャは彼に対して陰謀を企てた。ナダブと全イスラエルはギベトンを包囲していたので、バシャはペリシテ人に属するギベトンで彼を打った。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 32:35"> ユダの王アサの第三年に、バシャは彼を殺し、彼に代わって王となった。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王記第一 14:9–16; 列王記第二 19:25; 列王記第二 10:10–11"> 彼が王となるやいなや、彼はヤロブアムの全家を打った。主がそのしもべであるシロ人アヒヤを通して語られた言葉のとおりに、彼はヤロブアムに息のある者を一人も残さず、ついに彼を滅ぼした。</span>
<span className="v" id="v30" data-v="30" data-xref="列王記第一 15:26; 列王記第一 14:22; 列王記第一 14:9–16"> それはヤロブアムが犯した罪と、イスラエルに犯させた罪のためであり、彼がイスラエルの神、主の怒りを引き起こしたためであった。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王記第一 14:19; 列王記第一 16:20; 列王記第一 16:14"> ナダブのその他の事績と、彼が行ったすべてのことは、イスラエルの王たちの年代記の書に記されているではないか。</span>
<span className="v" id="v32" data-v="32" data-xref="列王記第一 15:16"> アサとイスラエルの王バシャの間には、彼らの日々のすべてにおいて戦いがあった。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="列王記第一 16:8"> ユダの王アサの第三年に、アヒヤの息子バシャはティルツァで全イスラエルを治め始め、二十四年間統治した。</span>
<span className="v" id="v34" data-v="34" data-xref="列王記第一 15:26; 列王記第一 14:16; 列王記第一 12:28–29"> 彼は主の目に悪とされることを行い、ヤロブアムの道、すなわちヤロブアムがイスラエルに犯させた罪の道を歩んだ。</span>
</div>

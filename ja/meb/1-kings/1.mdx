<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨシュア記 23:1–2; 歴代誌上 29:27–28; 歴代誌上 23:1"> ダビデ王は年を重ね、非常に老いていた。人々は彼に衣を掛けたが、王は温まらなかった。</span>
<span className="v" id="v2" data-v="2" data-xref="伝道者の書 4:11; 創世記 16:5; ミカ書 7:5"> そこで家臣たちは王に言った。「わが君、王のために若い処女を探させましょう。彼女を王のおそばに仕えさせ、王の世話をさせます。そして、わが君、王が温まるように、王のふところに寝かせましょう。」</span>
<span className="v" id="v3" data-v="3" data-xref="ヨシュア記 19:18; エステル記 2:4; エステル記 2:2"> そこで彼らはイスラエルの全土で美しい若い女を探し、シュネム人アビシャグを見つけて、彼女を王のもとに連れて来た。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイ 1:25"> その若い女は非常に美しかった。彼女は王の世話をし、彼に仕えた。しかし、王は彼女と床を共にすることはなかった。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="サムエル記第二 15:1; サムエル記第二 3:4; 申命記 17:15–16"> そのころ、ハギテの息子アドニヤは、「わたしが王になる」と言って自らを高く上げた。彼は戦車と騎兵、それに自分の前を走る五十人の男を用意した。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記第二 3:3–4; サムエル記第一 3:13; ヘブル人への手紙 12:5–6"> 父はこれまで一度も、「なぜこのようなことをしたのか」と言って彼をたしなめたことがなかった。アドニヤは非常に容姿の良い男で、アブサロムの次に生まれた者であった。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記第二 20:25; 列王記第一 2:22; サムエル記第一 22:20–23"> 彼はツェルヤの息子ヨアブ、および祭司アビアタルと協議した。彼らはアドニヤに従い、彼を支持した。</span>
<span className="v" id="v8" data-v="8" data-xref="列王記第一 4:18; サムエル記第二 23:8–39; サムエル記第二 20:25"> しかし祭司ツァドク、エホヤダの息子ベナヤ、預言者ナタン、シメイ、レイ、そしてダビデに属する勇士たちは、アドニヤに味方しなかった。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記第二 17:17; サムエル記第二 13:23–27; サムエル記第二 15:11–12"> アドニヤはエン・ロゲルのそばにあるツォヘレテの石の傍らで、羊、牛、肥えた家畜をいけにえとしてささげ、王の息子たちであるすべての兄弟たちと、王のしもべであるユダのすべての男たちを招いた。</span>
<span className="v" id="v10" data-v="10" data-xref="サムエル記第二 12:24; 列王記第一 1:19; サムエル記第二 12:1–15"> しかし彼は、預言者ナタン、ベナヤ、勇士たち、そして兄弟のソロモンは招かなかった。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="サムエル記第二 3:4; サムエル記第二 7:12–17; サムエル記第二 12:24–25"> そこでナタンはソロモンの母バテ・シェバに言った。「ハギテの息子アドニヤが王となり、われわれの主君ダビデがそれをご存じないことを、あなたは聞いていないのですか。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 11:14; 使徒の働き 27:31; 創世記 19:17"> さあ、助言をお聞きください。あなた自身のいのちと、息子ソロモンのいのちを救うためです。</span>
<span className="v" id="v13" data-v="13" data-xref="列王記第一 1:30; 列王記第一 1:17; 詩篇 132:11–12"> ダビデ王のところに入って行き、彼に言いなさい。『わが君、王よ。あなたはしもべに誓って、「確かにあなたの息子ソロモンがわたしの後に王となり、わたしの王座に座る」と言われたではありませんか。それなら、なぜアドニヤが王となっているのですか。』</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第二の手紙 13:1; 列王記第一 1:17–27"> 見よ、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「見よ」はヘブル語「הִנֵּה」に由来し、「見る」「注意を向ける」「よく観察する」などの意味を持ち、しばしば間投詞として用いられる。">a</a></sup>あなたがそこで王と話している間に、わたしもあなたの後から入って行き、あなたの言葉を確かなものとします。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王記第一 1:1"> バテ・シェバは部屋にいる王のところに入って行った。王は非常に年老いており、シュネム人アビシャグが王に仕えていた。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記第一 25:23; サムエル記第一 24:8; サムエル記第一 20:41"> バテ・シェバは身をかがめ、王に敬意を表した。<br />王は、「何が望みか」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王記第一 1:13; 列王記第一 1:30; ペテロの手紙第一 3:6"> 彼女は彼に言った。「わが君。あなたはあなたの神<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「神」と訳されたヘブル語は「אֱלֹהִים」（エロヒム）である。">b</a></sup>、主<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="すべて大文字の「主」または「神」はヘブル語のיהוה（ヤハウェ）から来ている。ただし、短い形のיה（ヤハ）から来ていると記されている場合を除く。">c</a></sup>にかけて、あなたのしもべに『確かにあなたの息子ソロモンがわたしの後に王となり、彼はわたしの王座に座る』と誓われました。</span>
<span className="v" id="v18" data-v="18" data-xref="列王記第一 1:24; 列王記第一 1:11; 使徒の働き 3:17"> 今、アドニヤが王となっています。そして、わが君、王はそれを知っておられません。</span>
<span className="v" id="v19" data-v="19" data-xref="列王記第一 1:25; 列王記第一 1:7–10"> 彼は牛、肥えた家畜、羊を豊かにいけにえとしてささげ、王のすべての息子たち、祭司アビアタル、軍の長ヨアブを招きました。しかし、あなたのしもべソロモンは招いていません。</span>
<span className="v" id="v20" data-v="20" data-xref="歴代誌上 29:1; 詩篇 123:2; 歴代誌上 22:8–10"> わが君、王よ。全イスラエルの目はあなたに注がれています。わが君、王の後にだれが王座に座るのかを、あなたが告げてくださるのを待っているのです。</span>
<span className="v" id="v21" data-v="21" data-xref="列王記第一 2:10; 申命記 31:16; 創世記 15:15"> そうでなければ、わが君、王が父祖たちとともに眠りにつかれるとき、わたしと息子ソロモンは罪人として扱われることになります。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨブ記 1:16–18; 創世記 24:15; ダニエル書 9:20"> 彼女がまだ王と話している間に、預言者ナタンが入って来た。</span>
<span className="v" id="v23" data-v="23" data-xref="列王記第一 1:16; ペテロの手紙第一 2:17; ローマ人への手紙 13:7"> 人々は王に、「預言者ナタンがお見えです」と告げた。<br />彼が王の前に入って来たとき、彼は地に顔を伏せて王の前に身をかがめた。</span>
<span className="v" id="v24" data-v="24" data-xref="列王記第一 1:17–18; 列王記第一 1:5; 列王記第一 1:13–14"> ナタンは言った。「わが君、王よ。あなたは『アドニヤがわたしの後に王となり、わたしの王座に座る』と言われたのですか。</span>
<span className="v" id="v25" data-v="25" data-xref="サムエル記第一 10:24; 列王記第一 1:19; 列王記第一 1:9"> 彼は今日下って行き、牛、肥えた家畜、羊を豊かにいけにえとしてささげ、王のすべての息子たち、軍の長たち、祭司アビアタルを招きました。彼らは今、彼の前で食べたり飲んだりし、『アドニヤ王、万歳！』と言っています。</span>
<span className="v" id="v26" data-v="26" data-xref="列王記第一 1:8; 列王記第一 1:10; サムエル記第二 7:2"> しかし彼は、あなたのしもべであるわたし、祭司ツァドク、エホヤダの息子ベナヤ、そしてあなたのしもべソロモンを招きませんでした。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネ 15:15; 列王記第一 1:24; 列王記第二 4:27"> これはわが君、王によってなされたことですか。そしてあなたは、わが君、王の後にだれがその王座に座るかを、あなたのしもべたちに示されなかったのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> そこでダビデ王は答えて、「バテ・シェバをわたしのところに呼べ」と言った。彼女は王の御前に来て、王の前に立った。</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記第二 4:9; 詩篇 136:24; サムエル記第一 14:45"> 王は誓って言った。「あらゆる苦難からわたしのいのちを救い出してくださった主は生きておられる。</span>
<span className="v" id="v30" data-v="30" data-xref="列王記第一 1:13; 列王記第一 1:17"> 『確かにあなたの息子ソロモンがわたしの後に王となり、彼はわたしに代わってわたしの王座に座る』と言って、わたしがイスラエルの神、主にかけてあなたに誓ったとおりに、わたしは今日そのように行う。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ダニエル書 2:4; ダニエル書 5:10; ダニエル書 3:9"> そこでバテ・シェバは地に顔を伏せて身をかがめ、王に敬意を表して、「わが君、ダビデ王がとこしえに生きられますように」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="列王記第一 1:8; 列王記第一 1:38; 列王記第一 1:26"> ダビデ王は、「祭司ツァドク、預言者ナタン、エホヤダの息子ベナヤをわたしのところに呼べ」と言った。彼らは王の前に来た。</span>
<span className="v" id="v33" data-v="33" data-xref="歴代誌 第二 32:30; 列王記第一 1:38; 歴代誌 第二 33:14"> 王は彼らに言った。「あなたがたの主君のしもべたちを連れて行き、わたしの息子ソロモンをわたし自身の騾馬に乗せ、彼をギホンへ連れて下りなさい。</span>
<span className="v" id="v34" data-v="34" data-xref="列王記第一 1:25; サムエル記第二 15:10; サムエル記第一 10:1"> そこで祭司ツァドクと預言者ナタンは、彼に油を注いでイスラエルの王としなさい。角笛を吹き鳴らし、『ソロモン王、万歳！』と言いなさい。</span>
<span className="v" id="v35" data-v="35" data-xref="列王記第一 1:17; 詩篇 72:1–2; 列王記第一 1:13"> それから彼の後について上って来なさい。彼は来て、わたしの王座に座る。彼がわたしに代わって王となるからだ。わたしは彼をイスラエルとユダの君主に任命した。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="エレミヤ書 28:6; コリント人への第一の手紙 14:16; 詩篇 72:19"> エホヤダの息子ベナヤは王に答えた。「アーメン。わが君、王の神である主が、そのように言われますように。</span>
<span className="v" id="v37" data-v="37" data-xref="サムエル記第一 20:13; 列王記第一 1:47; ヨシュア記 1:17"> 主がわが君、王とともにおられたように、ソロモンとともにおられ、彼の王座を、わが君ダビデ王の王座よりも大いなるものとされますように。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="サムエル記第二 8:18; 列王記第一 1:8; 列王記第一 1:33"> そこで祭司ツァドク、預言者ナタン、エホヤダの息子ベナヤ、およびケレテ人とペレテ人は下って行き、ソロモンをダビデ王の騾馬に乗せ、彼をギホンへ連れて行った。</span>
<span className="v" id="v39" data-v="39" data-xref="詩篇 89:20; 列王記第一 1:34; 歴代誌上 29:22"> 祭司ツァドクは天幕から油の角を取り出し、ソロモンに油を注いだ。彼らは角笛を吹き鳴らし、すべての民は「ソロモン王、万歳！」と言った。</span>
<span className="v" id="v40" data-v="40" data-xref="列王記第二 11:14; ゼカリヤ書 9:9; 列王記第二 11:20"> すべての民は彼の後について上り、笛を吹き、大いに喜んだ。その歓声で地が裂けるほどであった。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="ヨブ記 15:21–22; ルカ 17:26–29; 使徒の働き 21:31"> アドニヤと彼とともにいたすべての客は、食事を終えたときにこれを聞いた。ヨアブは角笛の音を聞くと、「なぜ町はあのように騒がしいのか」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="サムエル記第二 15:36; サムエル記第二 17:17; サムエル記第二 18:27"> 彼がまだ話している間に、祭司アビアタルの息子ヨナタンがやって来た。アドニヤは、「入れ。あなたは立派な人だから、良い知らせを持って来たのだ」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43"> ヨナタンはアドニヤに答えた。「いいえ。われわれの主君ダビデ王は、ソロモンを王とされました。</span>
<span className="v" id="v44" data-v="44"> 王は祭司ツァドク、預言者ナタン、エホヤダの息子ベナヤ、それにケレテ人とペレテ人を彼とともに遣わされました。彼らは彼を王の騾馬に乗せました。</span>
<span className="v" id="v45" data-v="45" data-xref="列王記第一 1:40; ダニエル書 5:26–28; サムエル記第一 4:5"> 祭司ツァドクと預言者ナタンは、ギホンで彼に油を注いで王としました。彼らはそこから喜びながら上って来たので、町は響き渡りました。あなたがたが聞いたのはその音です。</span>
<span className="v" id="v46" data-v="46" data-xref="歴代誌上 29:23; 詩篇 132:11; 列王記第一 1:13"> さらに、ソロモンは王座に着いています。</span>
<span className="v" id="v47" data-v="47" data-xref="創世記 47:31; 列王記第一 1:37; エズラ記 6:10"> その上、王のしもべたちはわれわれの主君ダビデ王を祝福しに来て、『あなたの神が、ソロモンの名をあなたの名よりも良くし、彼の王座をあなたの王座よりも大いなるものとされますように』と言いました。すると王は寝台の上で身をかがめられました。</span>
<span className="v" id="v48" data-v="48" data-xref="列王記第一 3:6; 詩篇 132:11–12; 詩篇 145:2"> さらに王はこう言われました。『イスラエルの神、主はほめたたえられるように。主は今日、わたしの王座に座る者を与えられ、わたしの目もそれを見ている。』」</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="イザヤ書 21:4–5; 箴言 28:1; ダニエル書 5:4–6"> アドニヤの客たちは皆恐れ、立ち上がって、それぞれ自分の道へ行った。</span>
<span className="v" id="v50" data-v="50" data-xref="列王記第一 2:28; 出エジプト記 21:14; 出エジプト記 27:2"> アドニヤはソロモンを恐れ、立ち上がって行き、祭壇の角をつかんだ。</span>
<span className="v" id="v51" data-v="51"> ソロモンに告げる者がいた。「アドニヤはソロモン王を恐れています。彼は祭壇の角をつかんで、『ソロモン王がそのしもべを剣で殺さないと、まずわたしに誓ってくださるように』と言っています。」</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="サムエル記第一 14:45; サムエル記第二 14:11; 箴言 13:6"> ソロモンは言った。「彼が忠実な者であることを示すなら、その髪の毛一本も地に落ちることはない。しかし、彼のうちに悪が見つかれば、彼は死ぬ。」</span>
<span className="v" id="v53" data-v="53" data-xref="列王記第一 1:16; サムエル記第二 14:24; サムエル記第二 1:2"> こうしてソロモン王は人を遣わし、彼らは彼を祭壇から連れて下った。彼は来てソロモン王に身をかがめた。ソロモンは彼に、「あなたの家へ帰りなさい」と言った。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王記第一 9:10; 歴代誌 第二 8:1; 伝道者の書 2:4–5"> ソロモンは自分の家を十三年かけて建て、その家のすべてを完成させた。</span>
<span className="v" id="v2" data-v="2" data-xref="列王記第一 10:17; 歴代誌 第二 9:16; 列王記第一 10:21"> 彼はレバノンの森の家を建てた。その長さは百キュビト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一キュビトは肘から中指の先までの長さで、約46センチメートル、または18インチである。">a</a></sup>、幅は五十キュビト、高さは三十キュビトで、四列の杉の柱の上にあり、柱の上には杉の梁があった。</span>
<span className="v" id="v3" data-v="3" data-xref="列王記第一 6:5"> 柱の上に渡した四十五本の梁の上は杉で覆われ、一列に十五本ずつ並んでいた。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 40:22; エゼキエル書 40:16; 列王記第一 6:4"> 梁は三列あり、窓は三つの層で互いに向かい合っていた。</span>
<span className="v" id="v5" data-v="5"> すべての入り口と門柱は梁で四角く造られていた。そして窓は三つの層で互いに向かい合っていた。</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第一 7:12; エゼキエル書 41:25–26"> 彼は柱の広間を造った。長さ五十キュビト、幅三十キュビトで、その前には柱のある玄関とひさしがあった。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 20:8; 詩篇 122:5; イザヤ書 9:7"> 彼はまた、さばきを行う王座の広間、すなわち裁きの広間を造り、床から天井まで杉で覆った。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代誌 第二 8:11; 列王記第一 3:1; 列王記第一 9:24"> 玄関の内側のもう一つの庭にある、彼が住むための家も、同じような造りであった。ソロモンはまた、（彼が妻としてめとった）ファラオの娘のためにも、この玄関のような家を造った。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王記第一 7:10–11; 列王記第一 5:17"> これらはすべて、内側も外側も、基から笠石に至るまで、また外側から大庭に至るまで、寸法に従ってのこぎりで切られた、高価な石、すなわち切り石でできていた。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 21:19–20; コリント人への第一の手紙 3:10–11; イザヤ書 54:11"> その基は高価な石、すなわち大きな石であった。十キュビトの石と、八キュビトの石である。</span>
<span className="v" id="v11" data-v="11" data-xref="エペソ人への手紙 2:20–22; ペテロの手紙第一 2:5"> その上には、寸法に従って切られた高価な切り石と、杉があった。</span>
<span className="v" id="v12" data-v="12" data-xref="列王記第一 6:36; 列王記第一 7:6; ヨハネ 10:23"> 大庭の周囲には、主の家の内庭と家の玄関のように、切り石の三つの層と杉の梁の一つの層があった。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歴代誌 第二 4:11; 歴代誌 第二 2:13–14; 列王記第一 7:40"> ソロモン王は人を遣わして、ツロからヒラムを呼び寄せた。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代誌 第二 2:14; 歴代誌 第二 4:16; 出エジプト記 31:2–6"> 彼はナフタリの部族のやもめの息子であり、彼の父はツロの人で青銅の細工師であった。彼は青銅のあらゆる仕事を行うための知恵と理解と技術に満ちていた。彼はソロモン王のもとに来て、そのすべての仕事を行った。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 52:21; 歴代誌 第二 3:15–17; 列王記第一 7:21"> 彼は青銅の二本の柱を鋳造した。それぞれ高さ十八キュビト、周囲は十二キュビトの糸で測ることができた。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 38:19; 歴代誌 第二 4:12–13; 出エジプト記 38:17"> 彼は柱の頂に置くために、青銅を溶かして二つの柱頭を造った。一つの柱頭の高さは五キュビト、もう一つの柱頭の高さも五キュビトであった。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 28:14; 出エジプト記 28:24–25; 出エジプト記 28:22"> 柱の頂にある柱頭のために、編み目細工の網、鎖の細工の花綱があった。一つの柱頭に七つ、もう一つの柱頭に七つであった。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 28:14; 出エジプト記 39:15–18; 出エジプト記 28:22"> こうして彼は柱を造った。柱の頂にある柱頭を覆うために、一つの網の上に二列のざくろが周囲にあった。もう一つの柱頭にもそのようにした。</span>
<span className="v" id="v19" data-v="19" data-xref="列王記第一 7:22; 列王記第一 6:32–35; 列王記第一 6:18"> 玄関の柱の頂にある柱頭は、ゆりの花の形をしており、四キュビトであった。</span>
<span className="v" id="v20" data-v="20" data-xref="歴代誌 第二 3:16; 歴代誌 第二 4:13; エレミヤ書 52:22–23"> 二本の柱の柱頭には、網細工に接する丸いふくらみの周囲にもざくろがあり、それぞれの柱頭を二百個のざくろが列をなして取り巻いていた。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代誌 第二 3:17; 列王記第一 6:3; 列王記第一 7:12"> 彼は神殿の玄関に柱を立てた。彼は右の柱を立ててその名をヤキンと呼び、左の柱を立ててその名をボアズと呼んだ。</span>
<span className="v" id="v22" data-v="22"> 柱の頂にはゆりの花の細工があった。こうして柱の仕事は完了した。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="歴代誌 第二 4:2; 列王記第二 25:13; エレミヤ書 52:17"> 彼は鋳造の海を造った。端から端まで十キュビトの円形で、高さは五キュビト、周囲は三十キュビトの糸で測ることができた。</span>
<span className="v" id="v24" data-v="24" data-xref="列王記第一 6:18; 歴代誌 第二 4:3; 出エジプト記 37:17–22"> その端の下には周囲にひょうたんの飾りがそれを取り囲んでおり、一キュビトにつき十個ずつ、海の周囲を取り囲んでいた。そのひょうたんの飾りは、それが鋳造されたときに二列に鋳造されたものであった。</span>
<span className="v" id="v25" data-v="25" data-xref="エレミヤ書 52:20; 歴代誌 第二 4:4–5; マタイ 28:19"> それは十二頭の牛の上に載っていた。三頭は北を向き、三頭は西を向き、三頭は南を向き、三頭は東を向いていた。海はそれらの上に載っており、それらの後ろの体はすべて内側に向いていた。</span>
<span className="v" id="v26" data-v="26" data-xref="歴代誌 第二 4:5; 列王記第一 7:38; 列王記第一 6:18"> その厚さは手幅であり、その縁は杯の縁のように、ゆりの花のように造られていた。それには二千バテが入った。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歴代誌 第二 4:14; 列王記第二 25:13; エレミヤ書 52:17"> 彼は青銅の十個の台座を造った。一つの台座の長さは四キュビト、幅は四キュビト、高さは三キュビトであった。</span>
<span className="v" id="v28" data-v="28"> 台座の造りは次のとおりである。それらには鏡板があり、鏡板は枠の間にあった。</span>
<span className="v" id="v29" data-v="29" data-xref="ホセア書 5:14; エゼキエル書 10:14; 出エジプト記 37:7"> 枠の間の鏡板には、獅子、牛、ケルビムが刻まれ、枠の上には台があった。獅子と牛の下には、垂れ下がる花綱の細工があった。</span>
<span className="v" id="v30" data-v="30" data-xref="エゼキエル書 10:10–13; エゼキエル書 3:13; エゼキエル書 1:15–21"> 各台座には青銅の車輪が四つと、青銅の車軸があり、四隅には洗盤を支える支柱があった。その支柱は鋳造され、それぞれの側面には花綱が付いていた。</span>
<span className="v" id="v31" data-v="31"> その口は柱頭の内側から上へ一キュビトであった。その口は台座の細工のように円形で、一キュビト半であった。またその口の上には彫刻があり、その鏡板は丸くなく四角であった。</span>
<span className="v" id="v32" data-v="32"> 鏡板の下には四つの車輪があり、車輪の軸は台座にあった。一つの車輪の高さは一キュビト半であった。</span>
<span className="v" id="v33" data-v="33" data-xref="エゼキエル書 1:18; エゼキエル書 1:16"> 車輪の造りは戦車の車輪の造りのようであった。その軸、縁、輻、こしきは、すべて鋳造されたものであった。</span>
<span className="v" id="v34" data-v="34"> 各台座の四隅には四つの支柱があり、支柱は台座と一体に造られていた。</span>
<span className="v" id="v35" data-v="35"> 台座の上部には高さ半キュビトの丸い帯があり、その上の支柱と鏡板は台座と一体であった。</span>
<span className="v" id="v36" data-v="36" data-xref="列王記第一 7:29; 列王記第一 6:29; エゼキエル書 41:18–20"> 彼は支柱の板と鏡板に、空いた場所に応じてケルビム、獅子、なつめやしの木を彫り、その周囲に花綱を施した。</span>
<span className="v" id="v37" data-v="37"> 彼はこのようにして十個の台座を造った。それらはみな同じ鋳型、同じ寸法、同じ形であった。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="出エジプト記 40:11–12; ゼカリヤ書 13:1; ヨハネの手紙第一 1:7"> 彼は青銅の十個の洗盤を造った。一つの洗盤には四十バテ<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一バテは一コルの十分の一で、約21リットルである。したがって四十バテは約840リットルである。">b</a></sup>が入り、一つの洗盤は四キュビトであった。十個の台座のそれぞれの上に一つの洗盤があった。</span>
<span className="v" id="v39" data-v="39" data-xref="歴代誌 第二 4:10; 歴代誌 第二 4:6"> 彼は台座の五つを家の右側に、五つを家の左側に置いた。彼は海を家の右側、東の方、南に向かって置いた。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="歴代誌 第二 4:11–16; 出エジプト記 24:6; 出エジプト記 39:32–43"> ヒラムは鍋、十能、鉢を造った。こうしてヒラムは、ソロモン王のために主の家で行うすべての仕事を終えた。</span>
<span className="v" id="v41" data-v="41" data-xref="列王記第一 7:15–22; 歴代誌 第二 4:12"> すなわち、二本の柱と、柱の頂にある柱頭の二つの鉢と、柱の頂にある柱頭の二つの鉢を覆う二つの網と、</span>
<span className="v" id="v42" data-v="42" data-xref="列王記第一 7:20"> 二つの網のための四百個のざくろ（一つの網につき二列のざくろがあり、柱の上にある柱頭の二つの鉢を覆っていた）と、</span>
<span className="v" id="v43" data-v="43"> 十個の台座と台座の上の十個の洗盤と、</span>
<span className="v" id="v44" data-v="44" data-xref="列王記第一 7:23; 列王記第一 7:25"> 一つの海と海の下の十二頭の牛と、</span>
<span className="v" id="v45" data-v="45" data-xref="出エジプト記 27:3; 出エジプト記 38:3; 歴代誌 第二 4:16"> 鍋、十能、鉢である。ヒラムがソロモン王のために主の家に造ったこれらの器は、すべて磨き上げた青銅であった。</span>
<span className="v" id="v46" data-v="46" data-xref="ヨシュア記 3:16; 歴代誌 第二 4:17; 創世記 33:17"> 王はヨルダンの平野で、スコテとツァレタンの間の粘土の地でこれらを鋳造した。</span>
<span className="v" id="v47" data-v="47" data-xref="歴代誌上 22:14; 歴代誌上 22:3; 歴代誌 第二 4:18"> 器は非常に多かったので、ソロモンはそれらをすべて量らないでおいた。青銅の重さは量りきれなかった。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="出エジプト記 37:10–16; 歴代誌 第二 4:8; 出エジプト記 39:36"> ソロモンは主の家にあるすべての器を造った。金の祭壇と、供えのパンを載せる金の机と、</span>
<span className="v" id="v49" data-v="49" data-xref="歴代誌 第二 4:7; 歴代誌 第二 4:20; ゼカリヤ書 4:11–14"> 純金の燭台（内側の聖所の前に右に五つ、左に五つ）と、金の花、ともしび、芯切りばさみと、</span>
<span className="v" id="v50" data-v="50" data-xref="出エジプト記 25:29; 歴代誌 第二 4:21–22; 出エジプト記 27:3"> 純金の杯、芯切りばさみ、鉢、さじ、火皿と、内側の家、すなわち至聖所の扉と、神殿の家の扉のための金の蝶番である。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="歴代誌 第二 5:1; サムエル記第二 8:7–11; 歴代誌上 28:11–18"> こうして、ソロモン王が主の家のために行ったすべての仕事は終わった。ソロモンは父ダビデが聖別したもの、すなわち銀、金、器を運び入れ、それらを主の家の宝物庫に納めた。</span>
</div>
</div>

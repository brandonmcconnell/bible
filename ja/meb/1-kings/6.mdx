<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌 第二 3:1–2; 使徒の働き 7:47; 歴代誌上 29:19"> イスラエルの子らがエジプトの地を出てから四百八十年目、ソロモンがイスラエルを治めて四年目のジブの月、すなわち第二の月に、彼は主の家を建て始めた。</span>
<span className="v" id="v2" data-v="2" data-xref="エゼキエル書 40:1–41; エゼキエル書 41:1–15; ヨハネの黙示録 21:16–17"> ソロモン王が主のために建てた家は、長さが六十キュビト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一キュビトは肘から中指の先までの長さで、約46センチメートル、または18インチである。">a</a></sup>、幅が二十キュビト、高さが三十キュビトであった。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代誌上 28:11; 歴代誌 第二 3:3–4; エゼキエル書 41:15"> 神殿本体の前にある玄関は、長さが神殿の幅と同じ二十キュビト、神殿の正面から張り出す幅が十キュビトであった。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 40:16; エゼキエル書 41:26; エゼキエル書 41:16"> 彼は家のために、格子のはめ込まれた窓を造った。</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第一 6:16; 列王記第一 6:19–21; 列王記第一 6:31"> 彼は神殿の壁に沿って、その周囲に脇屋を建てた。それは神殿本体と内陣の壁を取り巻き、周囲に脇部屋が設けられていた。</span>
<span className="v" id="v6" data-v="6"> 脇屋の一階は幅五キュビト、二階は六キュビト、三階は七キュビトであった。梁を神殿の壁に差し込まずにすむよう、外壁の周囲に段を設けたからである。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 27:5–6; ペテロの手紙第一 2:5; 出エジプト記 20:25"> 神殿は、石切り場で仕上げられた石を用いて建てられた。建築中、神殿の中では槌も斧も、いかなる鉄の道具の音も聞こえなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 41:6–7"> 中階の脇部屋への入り口は、神殿の右側にあった。らせん階段で中階へ上り、中階から三階へ上った。</span>
<span className="v" id="v9" data-v="9" data-xref="列王記第一 6:14; 列王記第一 6:38"> こうして彼は家を建て、それを完成させた。そして杉の梁と板で家を覆った。</span>
<span className="v" id="v10" data-v="10"> 彼は神殿全体に沿って、高さ五キュビトの脇屋を建て、杉の材木で神殿本体に取り付けた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 主のことばがソロモンに臨んだ。</span>
<span className="v" id="v12" data-v="12" data-xref="歴代誌上 22:10; コロサイ人への手紙 1:23; 列王記第一 3:14"> 「あなたが建てているこの家について言う。もしあなたがわたしの定めに歩み、わたしの掟を行い、わたしの戒めをことごとく守って歩むなら、わたしはあなたの父ダビデに語った約束を、あなたに対して果たす。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 31:6; 出エジプト記 25:8; レビ記 26:11"> わたしはイスラエルの子らの間に住み、わたしの民イスラエルを見捨てることはない。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王記第一 6:9; 列王記第一 6:38; 使徒の働き 7:47–48"> こうしてソロモンは家を建て、それを完成させた。</span>
<span className="v" id="v15" data-v="15" data-xref="列王記第一 7:7"> 彼は家の内側の壁を杉の板で造った。家の床から天井に至るまで、内側を木で覆い、家の床を糸杉の板で覆った。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代誌 第二 3:8; 列王記第一 8:6; ヘブル人への手紙 9:3"> 彼は家の奥二十キュビトを、床から天井まで杉の板で仕切り、内陣、すなわち至聖所とした。</span>
<span className="v" id="v17" data-v="17"> 内陣の前にある神殿本体は、長さ四十キュビトであった。</span>
<span className="v" id="v18" data-v="18" data-xref="列王記第一 7:24"> 内側の家の杉の木には、つぼみと開いた花の彫刻が施されていた。すべてが杉であり、石は一つも見えなかった。</span>
<span className="v" id="v19" data-v="19" data-xref="列王記第一 8:6–10; 詩篇 28:2; 列王記第一 6:5"> 彼は主の契約の箱をそこに置くために、家の内側の奥に内側の聖所を準備した。</span>
<span className="v" id="v20" data-v="20" data-xref="列王記第一 6:2–3; 列王記第一 6:22; 列王記第一 7:48"> 内陣の内部は、長さ二十キュビト、幅二十キュビト、高さ二十キュビトであった。彼はそこを純金で覆い、杉で覆われた祭壇にも金をかぶせた。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代誌 第二 3:7–9; 歴代誌 第二 3:14–16; 列王記第一 6:5"> こうしてソロモンは家の内側を純金で覆った。彼は内側の聖所の前に金の鎖を渡し、それを金で覆った。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 30:1; 出エジプト記 30:3; 歴代誌 第二 3:7–14"> 彼は家全体が完成するまで、家全体を金で覆った。彼はまた、内側の聖所に属する祭壇の全体を金で覆った。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 37:7–9; 創世記 3:24; ペテロの手紙第一 1:12"> 彼は内側の聖所に、高さ十キュビトのオリーブの木で二つのケルビム<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「ケルビム」は「ケルブ」の複数形で、御使いのような存在である。">b</a></sup>を造った。</span>
<span className="v" id="v24" data-v="24"> ケルブの一つの翼は五キュビト、ケルブのもう一つの翼も五キュビトで、一方の翼の端からもう一方の翼の端までは十キュビトであった。</span>
<span className="v" id="v25" data-v="25"> もう一つのケルブも十キュビトであった。両方のケルビムは同じ寸法、同じ形であった。</span>
<span className="v" id="v26" data-v="26"> 一つのケルブの高さは十キュビトであり、もう一つのケルブも同様であった。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 37:9; 出エジプト記 25:20; 歴代誌 第二 5:8"> 彼はケルビムを内陣に置いた。ケルビムは翼を広げ、一方のケルブの翼は一方の壁に、もう一方のケルブの翼は反対側の壁に触れ、中央では互いの翼が触れ合っていた。</span>
<span className="v" id="v28" data-v="28"> 彼はケルビムを金で覆った。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王記第一 6:32; 詩篇 92:12–15; 歴代誌 第二 4:2–5"> 彼は家の周囲のすべての壁に、内側も外側も、ケルビム、なつめやしの木、開いた花の彫刻を施した。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの黙示録 21:18–21; イザヤ書 60:17; イザヤ書 54:11–12"> 彼は家の床を、内側も外側も金で覆った。</span>
<span className="v" id="v31" data-v="31" data-xref="ヘブル人への手紙 10:19–20; エペソ人への手紙 3:18; ヨハネ 14:6"> 内陣の入り口にはオリーブ材の扉を造った。まぐさと門柱は五角形であった。</span>
<span className="v" id="v32" data-v="32" data-xref="列王記第一 6:18; 列王記第一 6:29"> 彼はオリーブの木で二つの扉を造り、そこにケルビム、なつめやしの木、開いた花の彫刻を施し、それらを金で覆った。彼はケルビムとなつめやしの木の上に金を延べた。</span>
<span className="v" id="v33" data-v="33"> 神殿本体の入り口にも、オリーブ材で四角形の門柱を造り、</span>
<span className="v" id="v34" data-v="34" data-xref="エゼキエル書 41:23–25; 列王記第一 5:8"> 糸杉の木で二つの扉を造った。一方の扉の二つの戸板は折りたたみ式であり、もう一方の扉の二つの戸板も折りたたみ式であった。</span>
<span className="v" id="v35" data-v="35"> 彼はケルビム、なつめやしの木、開いた花を彫り、彫刻された細工にぴったりと合うように金を覆った。</span>
<span className="v" id="v36" data-v="36" data-xref="列王記第一 7:12; 歴代誌 第二 7:7; 出エジプト記 27:9–19"> 彼は内庭を、切り石の三つの層と、杉の梁の一つの層で造った。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="列王記第一 6:1; 歴代誌 第二 3:2"> 四年目のジブの月に主の家の基が据えられた。</span>
<span className="v" id="v38" data-v="38" data-xref="エズラ記 6:14–15; 列王記第一 7:1; ゼカリヤ書 4:9"> 十一年目のブルの月、すなわち第八の月に、神殿はすべての部分にわたり、その仕様どおりに完成した。こうして彼は七年をかけて神殿を建てた。</span>
</div>
</div>

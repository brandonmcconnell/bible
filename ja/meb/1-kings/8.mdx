<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌 第二 5:2–10; 歴代誌上 15:25; サムエル記第二 6:12–17"> その時、ソロモンはイスラエルの長老たち、全部族のかしらたち、すなわちイスラエルの父祖の家の長たちを、エルサレムのソロモン王のもとに集めた。主の契約の箱をダビデの町、すなわちシオンから運び上るためであった。</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 23:34; 歴代誌 第二 7:8–10; ゼカリヤ書 14:16–19"> エタニムの月、すなわち第七の月の祭りに、イスラエルのすべての男たちがソロモン王のもとに集まった。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 31:9; ヨシュア記 3:6; 民数記 4:15"> イスラエルのすべての長老たちが来て、祭司たちは箱を担ぎ上げた。</span>
<span className="v" id="v4" data-v="4" data-xref="列王記第一 3:4; 歴代誌 第二 1:3; 出エジプト記 40:2–33"> 彼らは主の箱、会見の天幕、および天幕の中にあったすべての聖なる器を運び上った。祭司たちとレビ人たちがこれらを運び上った。</span>
<span className="v" id="v5" data-v="5" data-xref="サムエル記第二 6:13; 歴代誌上 16:1; 列王記第一 8:62–63"> ソロモン王と、彼のもとに集まったイスラエルの全会衆は、箱の前にいて、数えることも量ることもできないほど多くの羊や牛をいけにえとしてささげた。</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第一 6:19; サムエル記第二 6:17; 列王記第一 6:27"> 祭司たちは主の契約の箱をその定めの場所、すなわち家の内側の聖所である至聖所に、ケルビムの翼の下に運び入れた。</span>
<span className="v" id="v7" data-v="7"> ケルビムは箱の置かれた場所の上に両翼を広げ、上から箱とその担ぎ棒を覆っていた。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 25:13–15; 出エジプト記 37:4–5; ヨシュア記 4:9"> 担ぎ棒は長く、その端は内陣の前の聖所から見えたが、外からは見えなかった。それらは今日に至るまでそこにある。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 25:21; ヘブル人への手紙 9:4; 出エジプト記 40:20"> イスラエルの子らがエジプトの地を出たとき、主が彼らと契約を結ばれたホレブで、モーセがそこに置いた二枚の石の板のほかには、箱の中には何もなかった。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 40:34–35; 歴代誌 第二 7:1–2"> 祭司たちが聖所から出て来たとき、雲が主の家に満ちた。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 43:4–5; エゼキエル書 44:4; コリント人への第二の手紙 3:18"> 祭司たちは雲のために立って仕えることができなかった。主の栄光が主の家に満ちたからである。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="詩篇 97:2; 歴代誌 第二 6:1–11; レビ記 16:2"> その時、ソロモンは言った。「主は、ご自分が暗やみの中に住むと言われました。</span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記第二 7:13; 詩篇 132:13–14; ヘブル人への手紙 9:24"> わたしは確かにあなたのために住まいの家を、あなたがとこしえに住むための場所を建てました。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="サムエル記第二 6:18; 列王記第一 8:55–56; 歴代誌 第二 30:18–20"> 王は振り向いて、イスラエルの全会衆を祝福した。イスラエルの全会衆は立っていた。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカ 1:68; 歴代誌上 29:20; 歴代誌上 29:10"> 彼は言った。「イスラエルの神、主はほめたたえられるように。主はご自分の口でわたしの父ダビデに語られ、ご自分の手でそれを成し遂げて言われました。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記第一 16:1; 列王記第一 8:29; サムエル記第二 7:4–8"> 『わたしの民イスラエルをエジプトから導き出した日以来、わたしの名を置く家を建てるために、イスラエルのどの部族からも町を選ばなかった。しかし、わたしの民イスラエルを治める者としてダビデを選んだ。』</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記第二 7:2–3; 歴代誌上 22:7; 歴代誌上 28:2"> わたしの父ダビデの心には、イスラエルの神、主の御名のために家を建てる思いがありました。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代誌 第二 6:7–9; コリント人への第二の手紙 8:12"> しかし主は父ダビデに言われました。『わたしの名のために家を建てたいとの思いを心に抱いたことは良い。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記第二 7:5; 歴代誌上 22:8–10; 歴代誌上 28:6"> だが、あなたがその家を建てるのではない。あなたの身から出る息子が、わたしの名のために家を建てる。』</span>
<span className="v" id="v20" data-v="20" data-xref="歴代誌上 28:5–6; ピリピ人への手紙 1:6; 列王記第一 8:15"> 主はご自分が語られた言葉を果たされました。主が約束されたとおりに、わたしは父ダビデに代わって立ち、イスラエルの王座に座り、イスラエルの神、主の御名のために家を建てました。</span>
<span className="v" id="v21" data-v="21" data-xref="列王記第一 8:9; 申命記 31:26; 列王記第一 8:5–6"> わたしはそこに、主がわれわれの父祖たちをエジプトの地から導き出されたときに彼らと結ばれた、主の契約を納めた箱のための場所を設けました。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="エズラ記 9:5; 列王記第一 8:54; 出エジプト記 9:33"> ソロモンはイスラエルの全会衆の前で主の祭壇の前に立ち、天に向かって両手を広げて、</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記第二 7:22; 申命記 7:9; ダニエル書 9:4"> 言った。「イスラエルの神、主よ。上は天にも、下は地にも、あなたのような神はいません。あなたは、心を尽くしてあなたの前を歩むあなたのしもべたちに対して、契約と慈しみを守られます。</span>
<span className="v" id="v24" data-v="24" data-xref="サムエル記第二 7:16; 列王記第一 8:15; サムエル記第二 7:12"> あなたはご自分のしもべであるわたしの父ダビデに約束したことを守られました。はい、あなたはご自分の口で語り、今日あるように、ご自分の手でそれを成し遂げられました。</span>
<span className="v" id="v25" data-v="25" data-xref="列王記第一 2:4; 列王記第一 9:4–6; エレミヤ書 33:17–26"> ですから今、イスラエルの神、主よ、しもべである父ダビデに約束して、『あなたの子らが自分の道に心を配り、あなたがわたしの前を歩んだように歩むなら、イスラエルの王座に座る者があなたから絶えることはない』と言われたことを、どうかお守りください。</span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記第二 7:25–29; イザヤ書 41:17; サムエル記第一 1:17"> 今、イスラエルの神よ、どうか、しもべである父ダビデに語られたことばを確かなものとしてください。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歴代誌 第二 2:6; イザヤ書 66:1; エレミヤ書 23:24"> しかし、神は果たして地上に住まわれるでしょうか。天も、天の天も、あなたをお納めすることはできません。まして、わたしが建てたこの家にはなおさらです。</span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 88:1–2; 詩篇 5:1; ルカ 18:1"> それでも、しもべの祈りと願いを顧みてください。わたしの神、主よ、しもべが今日あなたの前で上げる叫びと祈りを聞いてください。</span>
<span className="v" id="v29" data-v="29" data-xref="歴代誌 第二 6:20; 列王記第一 8:16; 歴代誌 第二 7:15–16"> 「わたしの名をそこに置く」と言われたこの家に、昼も夜も御目を注いでください。しもべがこの場所に向かってささげる祈りを聞いてください。</span>
<span className="v" id="v30" data-v="30" data-xref="列王記第一 8:39; 列王記第一 8:34; 列王記第一 8:36"> しもべと、あなたの民イスラエルがこの場所に向かってささげる願いを聞いてください。あなたの住まいである天で聞き、聞いてお赦しください。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 22:8–11; 歴代誌 第二 6:22–23; レビ記 5:1"> もし人が隣人に罪を犯し、彼に誓いを立てさせるために誓いが課せられ、彼が来てこの家にあるあなたの祭壇の前で誓うなら、</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 25:1; イザヤ書 3:10–11; ローマ人への手紙 2:6–10"> あなたは天で聞いて行い、あなたのしもべたちをさばいてください。悪者には有罪を宣告してその行いを彼の頭に帰らせ、義人には義を宣告してその義にしたがって彼に報いてください。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="レビ記 26:17; 申命記 28:25; ヨナ書 3:10"> あなたの民イスラエルがあなたに対して罪を犯したため、敵の前で打ち負かされたとき、彼らがあなたに立ち返ってあなたの御名を告白し、この家であなたに祈り求めるなら、</span>
<span className="v" id="v34" data-v="34" data-xref="エレミヤ書 31:4–9; ダニエル書 9:12; 創世記 13:15"> あなたは天で聞いて、あなたの民イスラエルの罪を赦し、あなたが彼らの父祖たちに与えた地へ彼らを連れ戻してください。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="レビ記 26:19; 申命記 11:17; 列王記第一 8:33"> 彼らがあなたに対して罪を犯したため、天が閉ざされて雨が降らないとき、もし彼らがこの場所に向けて祈り、あなたの御名を告白し、あなたが彼らを苦しめられたときにその罪から立ち返るなら、</span>
<span className="v" id="v36" data-v="36" data-xref="詩篇 27:11; サムエル記第一 12:23; エレミヤ書 6:16"> あなたは天で聞いて、あなたのしもべたちとあなたの民イスラエルの罪を赦してください。あなたが彼らに歩むべき良い道を教えられ、あなたの民にゆずりの地として与えられたあなたの地に雨を降らせてください。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="申命記 28:21–22; レビ記 26:16; 歴代誌 第二 20:9"> もしこの地にききんが起きたとき、疫病が起こったとき、胴枯れ病、黒穂病、いなご、青虫が発生したとき、敵が彼らの地の町々で彼らを包囲したとき、どんな災厄、どんな病気であっても、</span>
<span className="v" id="v38" data-v="38" data-xref="詩篇 73:21–22; 列王記第一 8:22; ピリピ人への手紙 4:6"> どのような祈りや願いであれ、一人の人、あるいはあなたの民イスラエル全体が、それぞれ自分の心の痛みを知って、この家に向かって両手を広げるなら、</span>
<span className="v" id="v39" data-v="39" data-xref="歴代誌上 28:9; エレミヤ書 17:10; 使徒の働き 1:24"> あなたの住まいである天で聞き、赦し、行ってください。各人のすべての歩みに応じて報いてください。あなたはその心をご存じです。すべての人の心をご存じなのは、あなただけです。</span>
<span className="v" id="v40" data-v="40" data-xref="詩篇 130:4; ヨハネの黙示録 19:5; 申命記 6:2"> それは、あなたがわれわれの父祖たちに与えられた地の面で彼らが生きるすべての日々、彼らがあなたを恐れるためです。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="列王記第一 10:1–2; 使徒の働き 8:27–40; 出エジプト記 18:8–12"> さらに、あなたの民イスラエルに属さない外国人についても、彼があなたの御名のために遠い国から来たとき</span>
<span className="v" id="v42" data-v="42" data-xref="申命記 3:24; 列王記第二 17:36; 出エジプト記 3:13–16"> （彼らはあなたの大いなる御名と、力強い御手と、伸ばされた腕について聞くからです）、彼が来てこの家に向けて祈るなら、</span>
<span className="v" id="v43" data-v="43" data-xref="詩篇 102:15; サムエル記第一 17:46; 詩篇 22:27"> あなたはあなたの住まいである天で聞いて、その外国人があなたに呼び求めるすべてのことにしたがって行ってください。地上のすべての民があなたの御名を知り、あなたの民イスラエルと同じようにあなたを恐れ、わたしが建てたこの家があなたの御名によって呼ばれていることを知るためです。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="歴代誌 第二 6:34; 詩篇 78:67–69; 列王記第一 8:16"> あなたが遣わされる道で、あなたの民が敵と戦うために出て行くとき、彼らが主のお選びになった町と、わたしがあなたの御名のために建てた家に向けて主に祈るなら、</span>
<span className="v" id="v45" data-v="45" data-xref="創世記 18:25; 詩篇 9:4; エレミヤ書 5:28"> あなたは天で彼らの祈りと願いを聞き、彼らの正しい訴えを取り上げてください。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="伝道者の書 7:20; 箴言 20:9; ヨハネの手紙第一 1:8–10"> 彼らがあなたに対して罪を犯し（罪を犯さない人はいないからです）、あなたが彼らに向かって怒り、彼らを敵に引き渡し、彼らが遠くであれ近くであれ、敵の地に捕らえられて行ったとき、</span>
<span className="v" id="v47" data-v="47" data-xref="詩篇 106:6; ネヘミヤ記 1:6–11; ネヘミヤ記 9:26–30"> もし彼らが捕らえ移された地で我に返り、悔い改め、捕らえ移した者たちの地であなたに願って、「われわれは罪を犯し、よこしまなことを行い、悪を行いました」と言い、</span>
<span className="v" id="v48" data-v="48" data-xref="ダニエル書 6:10; エレミヤ書 29:12–14; 申命記 4:29"> 彼らを捕らえて行った敵の地で、心を尽くし、いのちを尽くしてあなたに立ち返り、あなたが彼らの父祖たちに与えられた彼らの地、あなたがお選びになった町、そしてわたしがあなたの御名のために建てた家に向けてあなたに祈るなら、</span>
<span className="v" id="v49" data-v="49" data-xref="列王記第二 19:19; 列王記第一 8:45; ゼカリヤ書 1:15–16"> あなたの住まいである天で彼らの祈りと願いを聞き、彼らの正しい訴えを取り上げてください。</span>
<span className="v" id="v50" data-v="50" data-xref="詩篇 106:46; 歴代誌 第二 30:9; 使徒の働き 7:10"> あなたに対して罪を犯したあなたの民を赦し、彼らがあなたに背いたすべての背きを赦してください。彼らを捕らえ移した者たちの前であわれみを得させ、その者たちが彼らをあわれむようにしてください。</span>
<span className="v" id="v51" data-v="51" data-xref="ネヘミヤ記 1:10; エレミヤ書 11:4; 申命記 4:20"> 彼らは、エジプトの鉄の炉の中からあなたが導き出された、あなたの民、ご自分の所有の民だからです。</span>
<span className="v" id="v52" data-v="52" data-xref="詩篇 145:18; 列王記第一 8:29; 詩篇 86:5"> あなたの目があなたのしもべの願いと、あなたの民イスラエルの願いに向かって開かれ、彼らがあなたに呼び求めるときにはいつでも、彼らの声を聞いてくださいますように。</span>
<span className="v" id="v53" data-v="53" data-xref="出エジプト記 19:5–6; 申命記 14:2; 申命記 32:9"> 主なる神よ、あなたが父祖たちをエジプトから導き出されたとき、しもべモーセを通して語られたように、あなたは彼らを地上のあらゆる民の中から、ご自分の所有の民として取り分けられたからです。」</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="歴代誌 第二 7:1; 歴代誌 第二 6:12–13; ルカ 22:45"> ソロモンは主にこのすべての祈りと願いをささげ終えると、天に向かって両手を広げ、ひざまずいていた主の祭壇の前から立ち上がった。</span>
<span className="v" id="v55" data-v="55" data-xref="列王記第一 8:14; サムエル記第二 6:18; 民数記 6:23–26"> 彼は立ち上がり、大声でイスラエルの全会衆を祝福して言った。</span>
<span className="v" id="v56" data-v="56" data-xref="ヨシュア記 23:14–15; ヨシュア記 21:44–45; ルカ 21:33"> 「約束されたすべてのことにしたがって、ご自分の民イスラエルに安息を与えられた主はほめたたえられるように。主がしもべモーセを通して語られた良い約束は、一言もたがわなかった。</span>
<span className="v" id="v57" data-v="57" data-xref="ヨシュア記 1:5; 申命記 31:6; 申命記 31:8"> われわれの神、主が、われわれの父祖たちとともにおられたように、われわれとともにおられますように。主がわれわれを見放すことも、見捨てることもありませんように。</span>
<span className="v" id="v58" data-v="58" data-xref="詩篇 119:36; エゼキエル書 36:26–27; エレミヤ書 31:33"> 主がわれわれの心をご自分に向けさせ、われわれが主のすべての道を歩み、主がわれわれの父祖たちに命じられた戒め、定め、掟を守るようにしてくださいますように。</span>
<span className="v" id="v59" data-v="59" data-xref="詩篇 141:2; ヨハネ 17:9; ヨハネ 17:20–24"> わたしが主の前で願ったこれらのことばが、昼も夜もわれわれの神、主の御前にあり、主がしもべの訴えと、民イスラエルの訴えを、日々必要に応じて取り上げてくださいますように。</span>
<span className="v" id="v60" data-v="60" data-xref="申命記 4:35; エレミヤ書 10:10–12; 列王記第一 18:39"> 地上のすべての民が、主こそ神であり、ほかに神はいないことを知るためです。</span>

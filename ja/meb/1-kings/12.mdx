<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 9:6; 歴代誌 第二 10:1–19; 士師記 9:1"> レハブアムはシケムへ行った。全イスラエルが彼を王とするためにシケムに来ていたからである。</span>
<span className="v" id="v2" data-v="2" data-xref="列王記第一 11:40; 歴代誌 第二 10:2–3; 列王記第一 11:26–31"> ネバテの息子ヤロブアムがこれを聞いたとき（彼はソロモン王の前から逃げてまだエジプトにおり、エジプトに住んでいたが、</span>
<span className="v" id="v3" data-v="3"> 人々は人を遣わして彼を呼んだ）、ヤロブアムとイスラエルの全会衆はレハブアムのもとに来て、彼に言った。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記第一 8:11–18; 列王記第一 4:7; マタイ 11:29–30"> 「あなたの父はわれわれのくびきを重くしました。ですから今、あなたの父の過酷な奉仕と、彼がわれわれに負わせた重いくびきを軽くしてください。そうすれば、われわれはあなたに仕えます。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王記第一 12:12"> 彼は彼らに言った。「いったん去り、三日後にわたしのところへ戻って来なさい。」そこで民は去った。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨブ記 12:12; ヨブ記 32:7; サムエル記第二 16:20"> レハブアム王は、父ソロモンが生きている間に彼の前に立っていた長老たちと協議して、「この民にどう答えるべきか、あなたがたはどのように助言するのか」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="箴言 15:1; 歴代誌 第二 10:6–7; 列王記第一 12:13"> 彼らは答えた。「もし今日、あなたがこの民に仕える者となって彼らに仕え、親切なことばで答えるなら、彼らはいつまでもあなたのしもべとなるでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="箴言 19:20; 伝道者の書 10:2–3; 歴代誌 第二 10:8"> しかし、彼は長老たちが与えた助言を退け、彼とともに育ち、彼の前に立っている若者たちと協議した。</span>
<span className="v" id="v9" data-v="9" data-xref="列王記第一 22:6–8; サムエル記第二 17:5–6; 歴代誌 第二 10:9"> 彼は彼らに言った。「『あなたの父がわれわれに負わせたくびきを軽くしてくれ』とわたしに語ったこの民に答えるために、あなたがたはどのような助言を与えるのか。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歴代誌 第二 10:10–11; 箴言 10:14; イザヤ書 47:6"> 彼とともに育った若者たちは答えた。「『あなたの父はわれわれのくびきを重くした。あなたはそれを軽くしてほしい』と言った民には、こう答えなさい。『わたしの小指は父の腰よりも太い。</span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 27:11; エゼキエル書 2:6; エレミヤ書 28:13–14"> 今、わたしの父はあなたがたに重いくびきを負わせたが、わたしはあなたがたのくびきをさらに重くする。わたしの父は鞭であなたがたを懲らしめたが、わたしはさそりであなたがたを懲らしめる。』」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王記第一 12:5; 歴代誌 第二 10:12–14"> 王が「三日目にわたしのところに戻って来なさい」と命じたとおりに、ヤロブアムとすべての民は三日目にレハブアムのところに来た。</span>
<span className="v" id="v13" data-v="13" data-xref="ヤコブの手紙 3:17; 箴言 13:20; 伝道者の書 10:12"> 王は長老たちが与えた助言を退け、民に荒々しく答えた。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 5:16–18; 列王記第一 12:10–11; 出エジプト記 5:5–9"> 若者たちの助言にしたがって言った。「父はあなたがたに重いくびきを負わせたが、わたしはさらに重くする。父は鞭であなたがたを懲らしめたが、わたしはさそりで懲らしめる。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王記第一 12:24; 申命記 2:30; 士師記 14:4"> 王は民の訴えを聞き入れなかった。これは主から出たことであり、主がシロ人アヒヤを通してネバテの息子ヤロブアムに語られたことばを成就するためであった。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="サムエル記第二 20:1; エレミヤ書 23:5–6; 歴代誌 第二 10:16"> 全イスラエルは、王が自分たちの訴えを聞き入れないのを見て、王に答えた。「ダビデにわれわれの何の分け前があるか。エッサイの子にわれわれの相続はない。イスラエルよ、自分の天幕へ帰れ！ ダビデよ、今、自分の家を顧みよ。」こうしてイスラエルは自分たちの天幕へ帰った。</span>
<span className="v" id="v17" data-v="17" data-xref="列王記第一 11:36; 列王記第一 11:13; 歴代誌 第二 11:13–17"> しかし、ユダの町々に住んでいたイスラエルの子らについて言えば、レハブアムが彼らを治めた。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王記第一 4:6; サムエル記第二 20:24; 列王記第一 5:14"> レハブアム王は強制労働を監督するアドラムを遣わしたが、全イスラエルは彼を石で打ち殺した。レハブアム王は急いで戦車に乗り、エルサレムへ逃げた。</span>
<span className="v" id="v19" data-v="19" data-xref="列王記第二 17:21; 歴代誌 第二 10:19; ヨシュア記 4:9"> こうしてイスラエルはダビデの家に背き、今日に至っている。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王記第一 11:13; 列王記第一 11:32; ホセア書 8:4"> 全イスラエルはヤロブアムが帰って来たことを聞き、人を遣わして彼を会衆に呼び寄せ、彼を全イスラエルの王とした。ユダの部族のほかには、ダビデの家に従う者はなかった。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歴代誌 第二 11:1–3; 歴代誌上 21:5; 歴代誌 第二 14:8"> レハブアムはエルサレムに着くと、ユダの全家とベニヤミン族から、選り抜きの戦士十八万人を集めた。イスラエルの家と戦い、ソロモンの息子レハブアムに王国を取り戻すためであった。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歴代誌 第二 11:2; 歴代誌 第二 12:5–7; 列王記第一 13:1"> しかし、神のことばが神の人シェマヤに臨んで言った。</span>
<span className="v" id="v23" data-v="23" data-xref="列王記第一 12:17"> 「ユダの王、ソロモンの息子レハブアム、およびユダとベニヤミンの全家、また残りの民に語って言え。</span>
<span className="v" id="v24" data-v="24" data-xref="列王記第一 12:15; 歴代誌 第二 25:7–8; ホセア書 8:4"> 『主はこう言われる。「上って行ってはならない。あなたがたの兄弟であるイスラエルの子らと戦ってはならない。それぞれ自分の家へ帰れ。このことはわたしによるものだからである。」』」そこで彼らは主のことばに聞き従い、主のことばにしたがって帰って行った。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="士師記 8:17; 士師記 8:8; 士師記 9:45–49"> それからヤロブアムはエフライムの山地にシケムを建ててそこに住んだ。彼はそこから出て行き、ペヌエルを建てた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 38:18–21; イザヤ書 7:9; マルコ 2:6–8"> ヤロブアムは心の中で言った。「今、王国はダビデの家に帰るかもしれない。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 12:5–7; 箴言 29:25; 申命記 12:14"> もしこの民がエルサレムにある主の家でいけにえをささげるために上って行くなら、この民の心は彼らの主君、ユダの王レハブアムに再び向くであろう。彼らはわたしを殺し、ユダの王レハブアムのところに帰るであろう。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王記第二 10:29; 出エジプト記 32:8; 列王記第二 17:16"> 王は相談のうえ、金の子牛を二頭造り、民に言った。「もうエルサレムに上る必要はない。イスラエルよ、見よ、あなたをエジプトの地から導き上った、あなたの神々だ。」</span>
<span className="v" id="v29" data-v="29" data-xref="創世記 28:19; 士師記 18:27–31; ホセア書 4:15"> 彼は一頭をベテルに置き、もう一頭をダンに置いた。</span>
<span className="v" id="v30" data-v="30" data-xref="列王記第二 17:21; 列王記第一 13:34; 列王記第二 10:31"> このことは罪となった。民がその一頭を礼拝するために、遠くダンまで行ったからである。</span>
<span className="v" id="v31" data-v="31" data-xref="歴代誌 第二 13:9; 列王記第二 17:32; 列王記第一 13:32–33"> 彼は高き所のための神殿を造り、レビの子孫ではない一般の民の中から祭司を任命した。</span>
<span className="v" id="v32" data-v="32" data-xref="列王記第一 8:5; 列王記第一 8:2; アモス書 7:10–13"> ヤロブアムは、第八の月の十五日に、ユダでの祭りのような祭りを定め、祭壇に上った。彼はベテルでそのように行い、自分が造った子牛にいけにえをささげ、自分が造った高き所の祭司たちをベテルに置いた。</span>
<span className="v" id="v33" data-v="33" data-xref="列王記第一 13:1; 民数記 15:39; マタイ 15:6"> 彼は第八の月の十五日、自分の心で定めた月日に、ベテルに造った祭壇に上った。イスラエルの子らのために祭りを定め、香をたくため祭壇に上ったのである。</span>
</div>
</div>

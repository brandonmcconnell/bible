<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 47:29; 申命記 31:14; テモテへの手紙第一 1:18"> さて、ダビデが死ぬ日が近づいたとき、彼は息子のソロモンに命じて言った。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 1:6–7; ヨシュア記 23:14; エペソ人への手紙 6:10"> 「わたしは地上のすべての者が行く道を行こうとしている。それゆえ、あなたは強くあり、男らしくありなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 29:9; 申命記 17:18–20; 箴言 3:1–4"> あなたの神、主の務めを守り、主の道を歩みなさい。モーセの律法に書かれているとおり、主の掟、戒め、定め、あかしを守りなさい。そうすれば、あなたは何をしても、どこへ向かっても栄える。</span>
<span className="v" id="v4" data-v="4" data-xref="列王記第二 20:3; サムエル記第二 7:25; 列王記第一 8:25"> そうすれば主は、わたしについて語られたことばを果たしてくださる。主はこう言われた。『もしあなたの子らが自分の道に心を配り、心を尽くし、いのちを尽くして、真実をもってわたしの前を歩むなら、イスラエルの王座に座る者があなたから絶えることはない。』</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="サムエル記第二 3:27; サムエル記第二 20:10; サムエル記第二 18:5"> また、ツェルヤの息子ヨアブがわたしにしたことを、あなたは知っている。彼はイスラエルの二人の軍の長、ネルの息子アブネルとエテルの息子アマサを殺し、平和な時に戦いの血を流した。その戦いの血を、腰の帯と足の履物に負わせた。</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第一 2:9; イザヤ書 57:21; 詩篇 37:37"> それゆえ、あなたの知恵にしたがって行い、彼の白髪頭を安らかによみ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="よみ（シェオル）は死者の場所である。">a</a></sup>へ下らせてはならない。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記第二 17:27–29; サムエル記第二 9:7; サムエル記第二 19:31–40"> しかし、ギレアデ人バルジライの息子たちには恵みを示し、あなたの食卓で食べる者たちに加えなさい。わたしがあなたの兄弟アブサロムから逃げたとき、彼らはわたしを迎えてくれたからだ。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="サムエル記第二 16:5–8; 列王記第一 2:36–46; サムエル記第二 19:16–23"> また、バフリム出身のベニヤミン人、ゲラの息子シメイがあなたとともにいる。わたしがマハナイムへ行った日、彼はひどい呪いでわたしを呪った。しかし彼はヨルダン川でわたしを迎えに下って来たので、わたしは主にかけて彼に誓い、『わたしはあなたを剣で殺すことはしない』と言った。</span>
<span className="v" id="v9" data-v="9" data-xref="列王記第一 2:6; 創世記 42:38; 創世記 44:31"> 今、彼を無罪のままでいさせてはならない。あなたは知恵のある男だから、彼に何をすべきかを知っているはずだ。あなたは彼の白髪頭を血とともによみ<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="よみ（シェオル）は死者の場所である。">b</a></sup>へ下らせなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 2:29; 使徒の働き 13:36; 列王記第一 1:21"> ダビデは父祖たちとともに眠りにつき、ダビデの町に葬られた。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記第二 5:4–5; 歴代誌上 29:26–27"> ダビデがイスラエルを治めた日数は四十年であった。彼はヘブロンで七年治め、エルサレムで三十三年治めた。</span>
<span className="v" id="v12" data-v="12" data-xref="歴代誌 第二 1:1; 歴代誌上 29:23–25; 詩篇 132:12"> ソロモンは父ダビデの王座に座り、その王権は堅く確立された。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="サムエル記第一 16:4–5; 列王記第一 1:5–10; ルカ 10:5–6"> その後、ハギテの息子アドニヤがソロモンの母バテ・シェバのところに来た。彼女は「平和な用件で来たのですか」と尋ねた。<br />彼は「平和な用件です」と答えた。</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記第二 14:12; ルカ 7:40"> 彼はさらに、「あなたにお話ししたいことがあります」と言った。<br />彼女は「話しなさい」と言った。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代誌上 22:9–10; 歴代誌上 28:5–7; 列王記第一 1:25"> 彼は言った。「王位は本来わたしのもので、全イスラエルもわたしが王になるものと期待していたことを、あなたはご存じです。しかし王位は転じて、わたしの兄弟のものとなりました。主によって彼のものとされたからです。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 30:7; 詩篇 132:10"> 今、わたしはあなたに一つの願い事があります。わたしの願いを退けないでください。」<br />彼女は彼に、「話しなさい」と言った。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記第二 12:8; 列王記第一 1:2–4; サムエル記第二 3:7"> 彼は言った。「どうか、ソロモン王に話して――彼はあなたの願いを退けないでしょうから――シュネム人アビシャグをわたしの妻として与えるようにしてください。」</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 14:15"> バテ・シェバは、「わかりました。あなたのために王に話しましょう」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="詩篇 45:9; 列王記第一 15:13; レビ記 19:32"> そこでバテ・シェバはアドニヤのために話をするために、ソロモン王のところへ行った。王は彼女を迎えるために立ち上がり、彼女に身をかがめた。それから自分の王座に座り、王の母のために王座を置かせたので、彼女は王の右に座った。</span>
<span className="v" id="v20" data-v="20" data-xref="マタイ 7:7–11; マタイ 11:24; ヨハネ 2:3–4"> すると彼女は、「あなたに一つ小さな願い事があります。わたしを拒まないでください」と言った。<br />王は彼女に、「母上、願ってください。わたしはあなたを拒みません」と言った。</span>
<span className="v" id="v21" data-v="21" data-xref="列王記第一 1:3; サムエル記第二 16:21–22"> 彼女は言った。「シュネム人アビシャグを、あなたの兄弟アドニヤに妻として与えてください。」</span>
<span className="v" id="v22" data-v="22" data-xref="歴代誌上 3:2; 歴代誌上 3:5; マタイ 20:22"> ソロモン王は母に答えた。「なぜアドニヤのためにシュネム人アビシャグを願うのですか。彼のために王国をも願ったらよいでしょう。彼はわたしの兄であり、祭司アビアタルとツェルヤの息子ヨアブも彼の側についているのですから。」</span>
<span className="v" id="v23" data-v="23" data-xref="ルツ記 1:17; 詩篇 140:9; 詩篇 64:8"> そこでソロモン王は主にかけて誓った。「アドニヤは、このことばによって自らのいのちを失うことになる。そうでなければ、神がわたしを幾重にも罰せられるように。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代誌上 22:10; 歴代誌上 17:10; 歴代誌上 17:17"> ですから今、わたしを堅く立て、父ダビデの王座に着かせ、約束されたとおりにわたしのために家を造ってくださった主は生きておられる。確かにアドニヤは今日殺される。」</span>
<span className="v" id="v25" data-v="25" data-xref="サムエル記第二 8:18; 列王記第一 2:46; 士師記 8:20–21"> ソロモン王はエホヤダの息子ベナヤを遣わした。ベナヤはアドニヤを討ち、彼は死んだ。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ヨシュア記 21:18; サムエル記第一 22:20–23; エレミヤ書 1:1"> 王は祭司アビアタルに言った。「アナトテにある自分の畑へ行きなさい。あなたは死に値する者である。しかし、今日はあなたを殺さない。あなたはわたしの父ダビデの前で主<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「主」と訳された言葉は「アドナイ」である。">c</a></sup>なる神の箱を担ぎ、またわたしの父が苦しめられたすべてのことにおいて、あなたも苦しめられたからだ。」</span>
<span className="v" id="v27" data-v="27" data-xref="サムエル記第一 2:27–36; サムエル記第一 3:12–14; エレミヤ書 7:12–14"> こうしてソロモンは、アビアタルを主の祭司から追放した。これは主がシロでエリの家について語られた言葉を成就するためであった。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王記第一 1:50; 列王記第一 1:7; サムエル記第二 18:2"> その知らせはヨアブに届いた。ヨアブはアブサロムには従わなかったが、アドニヤには従っていたからである。ヨアブは主の天幕に逃げ込み、祭壇の角をつかんだ。</span>
<span className="v" id="v29" data-v="29" data-xref="列王記第一 2:25; 出エジプト記 21:14; 列王記第一 2:46"> ソロモン王に、「ヨアブは主の天幕に逃げ込み、祭壇のそばにいます」と告げられた。そこでソロモンはエホヤダの息子ベナヤを遣わして、「行って、彼を討て」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> ベナヤは主の天幕に来て彼に、「王が『出て来い！』と言っておられる」と言った。<br />彼は「いや、わたしはここで死ぬ」と言った。<br />ベナヤは、「ヨアブはこのように言い、わたしにこのように答えた」と言って王に再び言葉を持ち帰った。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="申命記 21:8–9; 民数記 35:33; 出エジプト記 21:14"> 王は彼に言った。「彼が言ったとおりにせよ。彼を討って葬り、ヨアブが理由なく流した血の責任を、わたしと父の家から取り除け。</span>
<span className="v" id="v32" data-v="32" data-xref="士師記 9:24; 士師記 9:57; 詩篇 7:16"> 主は彼自身の血を彼自身の頭に帰らせるであろう。彼が、自分よりも義であり善良である二人の男を襲い、剣で殺し、わたしの父ダビデがそれを知らなかったからである。すなわち、イスラエルの軍の長であるネルの息子アブネルと、ユダの軍の長であるエテルの息子アマサである。</span>
<span className="v" id="v33" data-v="33" data-xref="マタイ 27:25; 列王記第一 2:32; ルカ 2:14"> 彼らの血はヨアブの頭と、その子孫<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="または、種">d</a></sup>の頭にとこしえに帰る。しかしダビデとその子孫、その家と王座には、主からの平安がとこしえにある。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="マタイ 3:1; ヨシュア記 15:61; 列王記第一 2:25"> そこでエホヤダの息子ベナヤは上って行き、彼を討って殺した。そして彼は荒野にある自分の家に葬られた。</span>
<span className="v" id="v35" data-v="35" data-xref="列王記第一 2:27; 歴代誌上 24:3; 歴代誌上 29:22"> 王は軍においてエホヤダの息子ベナヤを彼の代わりに就かせ、王はアビアタルの代わりに祭司ツァドクを就かせた。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="サムエル記第二 16:5–9; 列王記第一 2:8–9; 箴言 20:26"> 王は人を遣わしてシメイを呼び、彼に言った。「エルサレムに自分のための家を建ててそこに住み、そこからどこへも出て行ってはならない。</span>
<span className="v" id="v37" data-v="37" data-xref="サムエル記第二 1:16; サムエル記第二 15:23; ヨシュア記 2:19"> あなたが出て行き、キデロンの川を渡る日には、あなたが必ず死ぬことを確かに知っておけ。あなたの血はあなた自身の頭に帰る。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="列王記第一 20:4; 列王記第二 20:19"> シメイは王に言った。「その言葉は良いものです。わが君、王が言われたとおりに、あなたのしもべは行います。」シメイは多くの日々をエルサレムに住んだ。</span>
<span className="v" id="v39" data-v="39" data-xref="サムエル記第一 21:10; サムエル記第一 27:2–3"> 三年の終わりに、シメイの二人の奴隷がガテの王、マアカの息子アキシュのところへ逃げた。人々がシメイに告げて、「あなたの奴隷たちはガテにいます」と言った。</span>
<span className="v" id="v40" data-v="40" data-xref="ルカ 12:15; 箴言 15:27; テモテへの手紙第一 6:10"> シメイは起き上がり、自分のろばに鞍を置き、自分の奴隷たちを探すためにガテのアキシュのところへ行った。そしてシメイは行き、自分の奴隷たちをガテから連れ帰った。</span>
<span className="v" id="v41" data-v="41"> シメイがエルサレムからガテに行き、また帰って来たことがソロモンに告げられた。</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 15:4; 列王記第一 2:36–38; ルカ 15:22"> 王は人を遣わしてシメイを呼び、彼に言った。「わたしはあなたに主にかけて誓わせ、『あなたが出て行き、どこかほかのところへ歩いて行く日には、必ず死ぬことを確かに知っておけ』と言って、厳しく警告したではないか。あなたはわたしに『わたしが聞いた言葉は良いものです』と言った。</span>
<span className="v" id="v43" data-v="43" data-xref="ローマ人への手紙 13:5; 歴代誌 第二 30:12; 伝道者の書 8:2"> それならなぜ、あなたは主の誓いと、わたしがあなたに命じた戒めを守らなかったのか。」</span>
<span className="v" id="v44" data-v="44" data-xref="サムエル記第二 16:5–13; 詩篇 7:16; エゼキエル書 17:19"> 王はさらにシメイに言った。「あなたは、自分がわたしの父ダビデにしたすべての悪を心で知っている。それゆえ、主はあなたの悪をあなた自身の頭に帰らせるであろう。</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 25:5; 列王記第一 2:24; イザヤ書 9:6–7"> しかし、ソロモン王は祝福され、ダビデの王座は主の御前でとこしえに堅く立つ。」</span>
<span className="v" id="v46" data-v="46" data-xref="歴代誌 第二 1:1; 列王記第一 2:12; 列王記第一 2:45"> そこで王はエホヤダの息子ベナヤに命じた。ベナヤは出て行ってシメイを討ち、彼は死んだ。こうして王国はソロモンの手に堅く確立された。</span>
</div>

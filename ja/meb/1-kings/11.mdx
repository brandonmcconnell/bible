<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 17:17; 箴言 6:24; ネヘミヤ記 13:23–27"> さて、ソロモン王はファラオの娘とともに、モアブ人、アンモン人、エドム人、シドン人、ヘテ人の多くの外国の女たちを愛した。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 34:16; 申命記 7:3–4; ヨシュア記 23:12–13"> これらの国々について、主はイスラエルの子らに、「あなたがたは彼らの中に入って行ってはならない。彼らもあなたがたの中に入って来てはならない。彼らは必ず、あなたがたの心を自分たちの神々へとそらす」と言われていた。それでもソロモンは彼女たちを深く愛し、離れなかった。</span>
<span className="v" id="v3" data-v="3" data-xref="伝道者の書 7:28; サムエル記第二 5:13–16; 歴代誌 第二 11:21"> 彼には妻である七百人の王女と、三百人のそばめがいた。そして彼の妻たちは彼の心をそらした。</span>
<span className="v" id="v4" data-v="4" data-xref="列王記第一 9:4; 列王記第一 8:61; 列王記第一 11:6"> ソロモンが年老いたとき、妻たちは彼の心を他の神々へとそらした。彼の心は、父ダビデの心のようには、彼の神、主に対して全きものではなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 2:13; 列王記第一 11:7; 列王記第二 23:13"> ソロモンはシドン人の女神アシュトレテと、アンモン人の忌まわしい神ミルコムに従った。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 14:24; ヨシュア記 14:8; ヨシュア記 14:14"> ソロモンは主の目に悪とされることを行い、父ダビデのように主に従い通さなかった。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 21:29; 士師記 11:24; 使徒の働き 7:43"> そのころソロモンは、エルサレムの東にある山に、モアブの忌まわしい神ケモシュと、アンモン人の忌まわしい神モレクのために高き所を築いた。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 10:11–12; 列王記第一 11:1; エゼキエル書 16:22–29"> 彼は外国人の妻たちすべてのためにも同じようにし、彼女たちは自分たちの神々に香をたき、いけにえをささげた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王記第一 9:2; 列王記第一 3:5; 申命記 7:4"> 主はソロモンに怒りを発せられた。二度も彼に現れたイスラエルの神、主から、彼の心がそれたからである。</span>
<span className="v" id="v10" data-v="10" data-xref="列王記第一 6:12–13; 歴代誌 第二 7:17–22; 列王記第一 9:4–7"> 主はこのことについて、他の神々に従って行ってはならないと彼に命じられていたが、彼は主が命じられたことを守らなかった。</span>
<span className="v" id="v11" data-v="11" data-xref="列王記第一 12:15–16; 列王記第一 11:31; 列王記第二 17:21"> 主はソロモンに言われた。「あなたがこのように行い、わたしが命じた契約と定めを守らなかったので、わたしは必ず王国をあなたから裂き取り、あなたの家臣に与える。</span>
<span className="v" id="v12" data-v="12" data-xref="列王記第二 20:19; サムエル記第一 9:4–5; 列王記第二 22:19–20"> しかし、あなたの父ダビデのゆえに、あなたの生きている間はそれを行わない。あなたの息子の手からそれを裂くのである。</span>
<span className="v" id="v13" data-v="13" data-xref="列王記第一 12:20; 申命記 12:11; 列王記第一 11:32"> とはいえ、王国全体を裂くことはしない。わたしのしもべダビデのゆえに、またわたしが選んだエルサレムのゆえに、一つの部族をあなたの息子に与える。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歴代誌上 5:26; 詩篇 89:30–34; イザヤ書 13:17"> 主はソロモンに対して敵を起こされた。エドム人ハダドである。彼はエドムにいる王の子孫であった。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記第二 8:14; 歴代誌上 18:12–13; 申命記 20:13"> かつてダビデがエドムにいたとき、軍の長ヨアブは戦死者を葬るために上って行き、エドムの男子をことごとく打ち殺した。</span>
<span className="v" id="v16" data-v="16"> ヨアブと全イスラエルは、エドムの男子をことごとく断ち切るまで、六か月そこにとどまっていた。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイ 2:13–14; 出エジプト記 2:1–10; 列王記第二 11:2"> その時まだ幼かったハダドは、父の家臣である数人のエドム人とともに逃げ、エジプトへ向かった。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 10:12; 申命記 33:2; 申命記 1:1"> 彼らはミディアンから旅立ってパランに来た。彼らはパランから男たちを連れてエジプトへ行き、エジプトの王ファラオのところへ来た。ファラオは彼に家を与え、食物をあてがい、土地を与えた。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 39:4; エレミヤ書 43:7–9; 創世記 39:21"> ハダドはファラオに大いに気に入られ、ファラオは自分の妻、王妃タフペネスの妹を彼の妻として与えた。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 21:7; サムエル記第一 1:24"> タフペネスの姉妹は彼に息子ゲヌバテを産み、タフペネスはファラオの家で彼を乳離れさせた。ゲヌバテはファラオの家でファラオの息子たちの中にいた。</span>
<span className="v" id="v21" data-v="21" data-xref="列王記第一 2:10; 出エジプト記 4:19; マタイ 2:20"> ハダドはエジプトで、ダビデが父祖たちとともに眠りにつき、軍の長ヨアブも死んだと聞くと、ファラオに「どうか、わたしを自分の国へ帰らせてください」と言った。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記第二 18:22–23; ルカ 22:35; マルコ 14:31"> ファラオは彼に言った。「わたしのもとで何が不足しているので、自分の国へ帰ろうとするのか。」彼は答えた。「何もありません。それでも、どうか帰らせてください。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王記第一 11:14; サムエル記第二 8:3; サムエル記第二 10:15–18"> 神は彼に対しても、もう一人の敵、エリアダの息子レゾンを起こされた。彼はその主君であるツォバの王ハダデゼルから逃げてきた者であった。</span>
<span className="v" id="v24" data-v="24" data-xref="サムエル記第二 10:8; サムエル記第二 10:18; 列王記第一 20:34"> ダビデがツォバの者たちを殺したとき、彼は自分のところに男たちを集め、部隊の長となった。彼らはダマスコへ行ってそこに住み、ダマスコで治めた。</span>
<span className="v" id="v25" data-v="25" data-xref="歴代誌 第二 15:2; 詩篇 106:40; 列王記第一 5:4"> 彼はソロモンの生涯を通じてイスラエルの敵となり、ハダドのもたらした災いに加えて害を及ぼした。彼はイスラエルを憎み、アラムを治めた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歴代誌 第二 13:6; 列王記第一 12:2; 列王記第一 11:28"> ツェレダ出身のエフライム人でソロモンのしもべである、ネバテの息子ヤロブアムも王に対して手を上げた。彼の母の名はツェルアといい、やもめであった。</span>
<span className="v" id="v27" data-v="27" data-xref="列王記第一 9:24; 列王記第一 9:15; 箴言 30:32"> 彼が王に対して手を上げた理由はこれである。ソロモンはミロを建て、父ダビデの町の破れを修復していた。</span>
<span className="v" id="v28" data-v="28" data-xref="箴言 22:29; サムエル記第二 19:20; 士師記 1:22–23"> このヤロブアムという男は有能な勇士であった。ソロモンはこの若者が勤勉であるのを見て、彼をヨセフの家のすべての労働の監督に任じた。</span>
<span className="v" id="v29" data-v="29" data-xref="列王記第一 12:15; 列王記第一 14:2; 歴代誌 第二 9:29"> そのころ、ヤロブアムがエルサレムから出て行ったとき、シロ人である預言者アヒヤが道で彼に出会った。アヒヤは新しい外套を身にまとっており、野には二人だけであった。</span>
<span className="v" id="v30" data-v="30" data-xref="サムエル記第一 15:27–28; サムエル記第一 24:4–5"> アヒヤは自分が着ていた新しい外套をつかみ、それを十二切れに引き裂いた。</span>
<span className="v" id="v31" data-v="31" data-xref="列王記第一 11:11–12"> 彼はヤロブアムに言った。「十切れを取りなさい。イスラエルの神、主はこう言われる。『見よ、わたしはソロモンの手から王国を裂き取り、十部族をあなたに与える。</span>
<span className="v" id="v32" data-v="32" data-xref="列王記第一 11:13; 列王記第一 12:20–21; 列王記第一 14:21"> （しかし、わたしのしもべダビデのゆえに、またわたしがイスラエルのすべての部族の中から選んだ町エルサレムのゆえに、彼には一つの部族が残る）。</span>
<span className="v" id="v33" data-v="33" data-xref="列王記第一 11:9; 列王記第一 11:5–7; 列王記第一 9:5–7"> これは、彼らがわたしを捨て、シドン人の女神アシュトレテ、モアブの神ケモシュ、アンモン人の神ミルコムを拝んだからである。彼らは父ダビデのように、わたしの道を歩まず、わたしの目にかなうことを行わず、わたしの定めと掟を守らなかった。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="列王記第一 11:12–13; 列王記第一 11:31; ヨブ記 11:6"> しかし、わたしは彼の手から王国全体を取り上げない。わたしが選び、わたしの戒めと定めを守ったしもべダビデのゆえに、ソロモンの生涯の間は彼を君主としておく。</span>
<span className="v" id="v35" data-v="35" data-xref="列王記第一 12:20; 列王記第一 11:12; 出エジプト記 20:5–6"> しかし、わたしは彼の息子の手から王国を取り上げ、それをあなたに、すなわち十部族を与える。</span>
<span className="v" id="v36" data-v="36" data-xref="列王記第二 8:19; 列王記第一 11:13; 列王記第一 15:4"> 彼の息子には一つの部族を与える。それは、わたしの名を置くために選んだ町エルサレムで、しもべダビデのともしびが、いつもわたしの前にあるためである。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 14:26; 列王記第一 11:26; サムエル記第二 3:21"> わたしはあなたを選び取る。あなたは心の望むままに治め、イスラエルの王となる。</span>
<span className="v" id="v38" data-v="38" data-xref="サムエル記第二 7:11; ヨシュア記 1:5; 申命記 31:8"> もしあなたが、わたしの命じるすべてのことに聞き従い、わたしの道を歩み、しもべダビデのように、わたしの定めと戒めを守って、わたしの目にかなうことを行うなら、わたしはあなたとともにいる。ダビデに建てたように、あなたにも確かな家を建て、イスラエルをあなたに与える。</span>
<span className="v" id="v39" data-v="39" data-xref="ルカ 1:32–33; ルカ 2:11; イザヤ書 11:1–10"> わたしはこのことのためにダビデの子孫を苦しめるが、とこしえにではない。』」</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="歴代誌 第二 12:2–9; イザヤ書 14:24–27; 哀歌 3:37"> そのためソロモンはヤロブアムを殺そうとした。ヤロブアムは立ち上がってエジプトへ逃げ、エジプトの王シシャクのもとに身を寄せ、ソロモンが死ぬまでエジプトにいた。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="歴代誌 第二 9:29–31"> ソロモンのその他の事績、彼が行ったすべてのこと、および彼の知恵は、ソロモンの事績の書に記されているではないか。</span>
<span className="v" id="v42" data-v="42" data-xref="列王記第一 2:11"> ソロモンがエルサレムで全イスラエルを治めた期間は四十年であった。</span>
<span className="v" id="v43" data-v="43" data-xref="列王記第二 21:18; 列王記第一 2:10; マタイ 1:7"> ソロモンは父祖たちとともに眠りにつき、父ダビデの町に葬られた。そして彼の息子レハブアムが彼に代わって王となった。</span>
</div>
</div>

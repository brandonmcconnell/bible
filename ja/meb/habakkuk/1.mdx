<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ナホム書 1:1; イザヤ書 22:1"> 預言者ハバククが見た啓示。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 22:1–2; エレミヤ書 14:9; 詩篇 13:1–2"> 主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="すべて大文字の「主」または「神」はヘブル語のיהוה（ヤハウェ）から来ている。ただし、短い形のיה（ヤハ）から来ていると記されている場合を除く。">a</a></sup>よ、いつまで私が叫んでも、あなたはお聞きにならないのか。私が「暴虐だ」と叫んでも、救ってくださらないのか。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 55:9–11; エレミヤ書 9:2–6; エレミヤ書 20:8"> なぜ私に不義を見せ、よこしまを黙って見ておられるのか。破壊と暴虐が私の前にあり、争いが起こり、いさかいが湧き上がる。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 119:126; イザヤ書 1:21–23; ヨブ記 21:7"> それゆえ、律法は力を失い、公正は決して行き渡らない。悪者が義人を取り囲み、公正はねじ曲げられる。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 13:40–41; 哀歌 4:12; イザヤ書 29:14"> 「諸国民の間を見渡し、よく見よ。驚き、驚け。私はあなたがたの時代に、驚くべきみわざを行う。たとえ告げられても、あなたがたは信じない。</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第二 24:2; エレミヤ書 5:15; イザヤ書 23:13"> 見よ、<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「見よ」と訳されたヘブル語は、見る、注意を向ける、よく観察するという意味を持ち、しばしば強い呼びかけとして用いられる。">b</a></sup>私はカルデア人を起こす。彼らは激しく性急な国民で、地の果てまで駆け巡り、自分たちのものではない住まいを奪い取る。</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 39:5–9; エレミヤ書 52:9–11; 申命記 5:27"> 彼らは恐ろしく、畏怖を起こす。その裁きも威厳も、自らを源とする。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 4:13; ゼパニヤ書 3:3; ホセア書 8:1"> その馬は豹より速く、夕暮れの狼より獰猛だ。その騎兵は猛然と駆け進む。騎兵は遠くから来て、獲物を食らおうと急ぐ鷲のように飛ぶ。</span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 25:9; ホセア書 13:15; ホセア書 1:10"> 彼らは皆、暴虐を行うために来る。その大軍はひたすら前へ進み、捕虜を砂のように集める。</span>
<span className="v" id="v10" data-v="10" data-xref="歴代誌 第二 36:6; エレミヤ書 32:24; イザヤ書 14:16"> 彼らは王たちをあざけり、君主たちを物笑いにする。どんな要塞をも笑い、土塁を築いて攻め取る。</span>
<span className="v" id="v11" data-v="11" data-xref="ダニエル書 5:20; ダニエル書 4:30–34; エレミヤ書 4:11–12"> そして風のように一気に吹き過ぎ、進み去る。自分の力を神とする彼らは、まことに罪ある者だ。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 32:4; エレミヤ書 30:11; エレミヤ書 46:28"> 主よ、私の神<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「神」と訳されたヘブル語は「אֱלֹהִים」（エロヒム）である。">c</a></sup>、私の聖なる方よ、あなたは永遠の昔からおられる方ではないか。われわれは死なない。主よ、あなたは裁きのために彼らを立てられた。岩なる方よ、懲らしめるためにこの者を据えられた。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 5:4–5; 詩篇 34:15–16; エレミヤ書 12:1–2"> あなたの目は清く、悪を見るに耐えず、よこしまを黙って見過ごされない。それなのに、なぜ裏切る者たちを容認し、悪者が自分より正しい者をのみ込む時、沈黙しておられるのか。</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 6:7"> なぜ人を海の魚のように、治める者のない這うもののようにされるのか。</span>
<span className="v" id="v15" data-v="15" data-xref="アモス書 4:2; エレミヤ書 16:16; 詩篇 10:9"> 彼は人々を皆、釣り針で釣り上げ、網で捕らえ、引き網で集める。それゆえ彼は喜び、楽しむ。</span>
<span className="v" id="v16" data-v="16" data-xref="ハバクク書 1:11; 申命記 8:17; ダニエル書 4:30"> そのため彼は自分の網にいけにえをささげ、引き網に香をたく。それらによってぜいたくに暮らし、豊かな食物を得るからだ。</span>
<span className="v" id="v17" data-v="17" data-xref="ハバクク書 2:5–8; エゼキエル書 25:1–17; エレミヤ書 25:9–26"> それでは彼は絶えず網を空にし、あわれみもなく諸国民を殺し続けるのか。</span>
</div>

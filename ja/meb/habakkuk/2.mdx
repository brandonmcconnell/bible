<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 21:8; イザヤ書 62:6; サムエル記第二 18:24"> 私は見張り所に立ち、城壁の上に身を置こう。主が私に何を語られるか、この訴えに対して私が何と答えるべきか、見張って待とう。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 30:8; ヨハネの黙示録 14:13; ヨハネの黙示録 1:18–19"> 主は私に答えられた。「幻を書き記し、板の上にはっきりと記せ。走りながらでも読めるように。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 27:14; ヘブル人への手紙 10:36–37; エゼキエル書 12:25"> この幻はなお、定められた時のためにある。終わりに向かって急ぎ、偽ることはない。たとえ遅れても待て。必ず来る。遅れることはない。</span>
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 1:17; ヘブル人への手紙 10:38; ガラテヤ人への手紙 3:11–12"> 見よ、高ぶる者。その心はまっすぐではない。しかし義人は、その信仰によって生きる。</span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 5:11–12; 箴言 27:20; 箴言 20:1"> まことに、ぶどう酒は人を欺く。高慢な者は家にとどまることを知らない。彼はよみ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="よみ（シェオル）は死者の場所である。">a</a></sup>のように欲望を広げ、死のように満足することがない。すべての国々を自分のもとに集め、すべての民をかき集める。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数記 23:7; ミカ書 2:4; エレミヤ書 50:13"> これらの民は皆、彼についてたとえを語り、あざけりのことわざを唱えて、こう言うではないか。『自分のものでないものを増し加え、不当な取り立てで身を肥やす者には災いがある。いつまで続くのか。』</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 29:1; イザヤ書 47:11; エレミヤ書 8:17"> あなたに返済を迫る者たちが突然立ち上がり、あなたを震え上がらせる者たちが目を覚まし、あなたが彼らの餌食となるのではないか。</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 33:1; ハバクク書 2:17; エレミヤ書 27:7"> あなたは多くの国々を略奪した。それゆえ、諸民族の残りの者が皆、あなたを略奪する。人の血を流し、地と町と、そこに住むすべての者に暴虐を行ったからだ。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 49:16; エレミヤ書 22:13–19; イザヤ書 28:15"> 自分の家のために不正な利益を得て、災いの手の届かない高みに巣を設けようとする者には災いがある。</span>
<span className="v" id="v10" data-v="10" data-xref="ナホム書 1:14; 列王記第二 9:26; エレミヤ書 36:31"> あなたは多くの民を断ち滅ぼそうと企て、自分の家に恥をもたらし、自らに罪を負わせた。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカ 19:40; ヨシュア記 24:27; ヨブ記 31:38–40"> 壁の石が叫び、木組みの梁がそれに答えるからだ。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ミカ書 3:10; ダニエル書 4:27–31; ナホム書 3:1"> 血によって町を築き、不義によって都を建てる者には災いがある。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 51:58; イザヤ書 50:11; 箴言 21:30"> 見よ、民が火に焼かれるもののために働き、国々がむなしいもののために疲れ果てるのは、万軍の主によることではないか。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 11:9; 詩篇 22:27; 詩篇 72:19"> 水が海を覆うように、主の栄光を知ることが地に満ちるからだ。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 51:7; 創世記 9:22; ヨハネの黙示録 18:3"> 隣人に酒を飲ませ、激しい酔いに陥るまで酒を注ぎ、その裸を見ようとする者には災いがある。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 47:3; ナホム書 3:5–6; イザヤ書 51:21–23"> あなたは栄光ではなく、恥に満たされている。あなたも飲み、裸をさらせ。主の右の御手にある杯があなたのもとに巡って来て、恥辱があなたの栄光を覆う。</span>
<span className="v" id="v17" data-v="17" data-xref="ハバクク書 2:8; 詩篇 55:23; ゼカリヤ書 11:1"> あなたがレバノンに加えた暴虐があなたを覆い、獣に加えた破壊があなたをおびえさせる。人の血を流し、地とすべての町と、そこに住む者たちに暴虐を行ったからだ。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 10:8; コリント人への第一の手紙 12:2; イザヤ書 44:9–10"> 刻んだ像に何の価値があるのか。造り手がそれを刻んでも、何になるのか。鋳造された像、偽りを教えるものに何の価値があるのか。形造った者が、自分の造った口のきけない偶像に信頼している。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 135:17; エレミヤ書 10:4; 列王記第一 18:26–29"> 木に『目を覚ませ』と言い、口のきけない石に『起きよ』と言う者には災いがある。それが教えられるというのか。見よ、それは金と銀で覆われているが、その内には息が全くない。</span>
<span className="v" id="v20" data-v="20" data-xref="ゼカリヤ書 2:13; ゼパニヤ書 1:7; 詩篇 46:10"> しかし主は、その聖なる宮におられる。全地よ、御前に静まれ。」</span>
</div>

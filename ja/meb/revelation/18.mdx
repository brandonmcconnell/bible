<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 43:2; ルカ 17:24; テサロニケ人への第二の手紙 2:8"> その後、別の御使いが大きな権威を持って天から下って来るのを見た。地はその栄光によって照らされた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 14:8; エレミヤ書 51:8; エレミヤ書 51:37"> 御使いは力強い声で叫んだ。「倒れた。大バビロンは倒れた。悪霊の住みか、あらゆる汚れた霊の牢獄、あらゆる汚れた憎むべき鳥の牢獄となった。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 14:8; ヨハネの黙示録 17:2; ヨハネの黙示録 18:9"> すべての国民が、彼女の淫行に対する怒りのぶどう酒を飲み、地上の王たちは彼女と淫行を行い、地上の商人たちは彼女のあふれるぜいたくによって富んだからである。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 52:11; コリント人への第二の手紙 6:17; エレミヤ書 51:6"> また、天から別の声がこう言うのを聞いた。「わたしの民よ、彼女から出て来なさい。彼女の罪をともにせず、彼女の災害を受けないためである。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 18:20–21; エズラ記 9:6; ヨハネの黙示録 16:19"> 彼女の罪は天にまで達し、神は彼女の不義を覚えられた。</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 50:29; 詩篇 137:8; エレミヤ書 51:24"> 彼女が報いたとおりに彼女に報い、その行いに応じて二倍にして返しなさい。彼女が混ぜた杯には、二倍の量を混ぜて返しなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 47:7–9; ゼパニヤ書 2:15; 哀歌 1:1"> 彼女が自らを誇り、放縦に暮らした分だけ、苦しみと悲しみを与えなさい。彼女は心の中で、『私は女王として座っている。やもめではない。決して悲しみを見ることはない』と言っているからである。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 50:34; エレミヤ書 50:31; ヨハネの黙示録 17:16"> それゆえ、一日のうちに、死と悲しみと飢饉という災害が彼女を襲い、彼女は火で完全に焼き尽くされる。彼女を裁かれる主なる神は力強い方だからである。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 19:3; ヨハネの黙示録 18:3; ヨハネの黙示録 17:2"> 彼女と淫行を行い、放縦に暮らした地上の王たちは、彼女が焼かれる煙を見ると、彼女のために泣き、嘆き悲しむ。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 18:19; ヨハネの黙示録 18:8; ヨハネの黙示録 18:15–17"> 彼女の苦しみを恐れて遠く離れて立ち、こう言う。『災いだ。災いだ。大きな都、力ある都バビロンよ。あなたへの裁きは、わずか一時間で来た。』</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 18:3; ヨハネの黙示録 18:23; エゼキエル書 27:27–36"> 地上の商人たちも彼女のために泣き、悲しむ。もはや彼らの商品を買う者がいないからである。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 17:4; エゼキエル書 27:5–25; 箴言 8:10–11"> その商品とは、金、銀、宝石、真珠、上質の亜麻布、紫布、絹、緋色の布、あらゆる高価な木材、象牙で作ったあらゆる器、最も高価な木材や青銅、鉄、大理石で作ったあらゆる器、</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 27:13; アモス書 2:6; ペテロの第二の手紙 2:3"> また、肉桂、香、香料、乳香、ぶどう酒、オリーブ油、上等な小麦粉、小麦、牛、羊、馬、馬車、人の体、さらに人の命である。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 10:6; 詩篇 106:14; ルカ 16:25"> 『あなたが心から欲しがった果実は、あなたから失われた。美しく豪華なものはすべて、あなたから消え去り、もはや決して見いだせない。』</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの黙示録 18:3; 使徒の働き 19:24–27; エゼキエル書 27:31"> これらの品を商い、彼女によって富んだ商人たちは、彼女の苦しみを恐れて遠く離れて立ち、泣き悲しみながら、</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 17:4; ルカ 16:19–31; ヨハネの黙示録 18:10–11"> こう言う。『災いだ。災いだ。上質の亜麻布と紫と緋色の衣をまとい、金と宝石と真珠で身を飾っていた大きな都よ。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 27:27–36; ヨハネの黙示録 17:16; イザヤ書 23:14"> これほどの富が、わずか一時間で荒れ果ててしまった。』すべての船長、各地を航海するすべての者、船乗り、海で生計を立てるすべての者は、遠く離れて立ち、</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 13:4; エゼキエル書 27:30–32; ヨハネの黙示録 18:9–10"> 彼女が焼かれる煙を見て叫んだ。『この大きな都に並ぶものがあるだろうか。』</span>
<span className="v" id="v19" data-v="19" data-xref="ヨハネの黙示録 18:10; ヨシュア記 7:6; エゼキエル書 27:30"> 彼らは頭にちりをかぶり、泣き悲しみながら叫んだ。『災いだ。災いだ。海に船を持つすべての者が、その莫大な富によって豊かになった大きな都よ。わずか一時間で荒れ果ててしまった。』</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヨハネの黙示録 6:10; ヨハネの黙示録 19:1–3; ルカ 18:7–8"> 「天よ、聖徒たち、使徒たち、預言者たちよ、彼女のことで喜べ。神が、あなたがたのために彼女を裁かれたからである。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 51:63–64; エゼキエル書 26:21; ヨハネの黙示録 5:2"> すると、一人の力強い御使いが、大きな石臼のような石を持ち上げ、海に投げ込んで言った。「大きな都バビロンは、このように激しく投げ倒され、もはや決して見いだされない。</span>
<span className="v" id="v22" data-v="22" data-xref="エゼキエル書 26:13; エレミヤ書 25:10; エレミヤ書 7:34"> 竪琴を弾く者、歌う者、笛を吹く者、ラッパを吹く者の声は、もはやあなたのうちに決して聞かれない。どのような技術を持つ職人も、もはやあなたのうちに決して見いだされない。石臼の音も、もはやあなたのうちに決して聞かれない。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの黙示録 18:3; イザヤ書 23:8; ナホム書 3:4"> ともしびの光も、もはやあなたのうちに決して輝かない。花婿と花嫁の声も、もはやあなたのうちに決して聞かれない。あなたの商人たちは地上の有力者であり、あなたの魔術によってすべての国民が惑わされたからである。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの黙示録 17:6; ヨハネの黙示録 16:6; エレミヤ書 51:49"> この都のうちに、預言者たちと聖徒たちの血、また地上で殺されたすべての者の血が見いだされた。」</span>
</div>

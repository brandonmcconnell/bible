<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 65:17–19; ペテロの第二の手紙 3:13; イザヤ書 66:22"> また、新しい天と新しい地を見た。初めの天と初めの地は過ぎ去り、もはや海もなかった。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 11:10; ヨハネの黙示録 3:12; ヨハネの黙示録 21:10"> また、聖なる都、新しいエルサレムが、夫のために着飾った花嫁のように整えられ、神のもとから天より下って来るのを見た。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 37:27; コリント人への第二の手紙 6:16; ヨハネ 14:23"> そして、天から大きな声がこう言うのを聞いた。「見よ、神の住まいは人々とともにある。神は彼らとともに住み、彼らは神の民となる。神ご自身が彼らとともにいて、彼らの神となられる。</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 25:8; ヨハネの黙示録 7:17; コリント人への第一の手紙 15:26"> 神は彼らの目から涙をことごとくぬぐい取られる。もはや死はなく、悲しみも叫びも苦痛もない。初めのものは過ぎ去ったからである。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 5:17; イザヤ書 42:9; イザヤ書 43:19"> 王座に座っておられる方が、<span className="woj">「見よ、わたしはすべてのものを新しくする」</span>と言われた。また、<span className="woj">「書き記しなさい。これらの言葉は信頼でき、真実である」</span>と言われた。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 7:37–38; ヨハネ 4:10; ヨハネの黙示録 7:17"> また私に言われた。<span className="woj">「わたしはアルファであり、オメガである。初めであり、終わりである。渇いている者には、命の水の泉から無償で飲ませよう。</span></span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第二の手紙 6:18; ヘブル人への手紙 8:10; ヨハネの黙示録 2:11"> <span className="woj">勝利を得る者には、これらのものを与えよう。わたしはその者の神となり、その者はわたしの子となる。</span></span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 6:9–10; ヨハネの黙示録 2:11; エペソ人への手紙 5:5–6"> <span className="woj">しかし、臆病な者、不信仰な者、罪人、</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TRとNUは「罪人」を省いている。">a</a></sup><span className="woj">忌まわしい者、殺人者、淫行を行う者、魔術を行う者、</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ここで「魔術を行う者」と訳された言葉には、調合薬や薬物を使う者も含まれる。">b</a></sup><span className="woj">偶像を礼拝する者、すべての偽り者が受ける分は、火と硫黄の燃える池の中にある。これが第二の死である。」</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 21:2; ヨハネの黙示録 19:7; ヨハネの黙示録 16:1–17"> 最後の七つの災害で満たされた七つの鉢を持つ七人の御使いの一人が来て、私に語りかけた。「ここに来なさい。花嫁である小羊の妻を見せよう。」</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 21:2; エゼキエル書 11:24; エゼキエル書 40:1–49"> 御使いは御霊によって、私を大きな高い山へ連れて行き、聖なる都エルサレムが神のもとから天より下って来るのを見せた。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 4:6; ヨハネの黙示録 22:5; ヨハネの黙示録 22:1"> 都は神の栄光に包まれていた。その輝きはこの上なく貴い宝石のようであり、水晶のように澄んだ碧玉に似ていた。</span>
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 48:31–34; ヨハネの黙示録 7:4–8; ヨハネの黙示録 21:17–21"> 都には大きな高い城壁があり、十二の門があった。門には十二人の御使いがいて、イスラエルの子らの十二部族の名が書かれていた。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 48:31–34"> 東に三つの門、北に三つの門、南に三つの門、西に三つの門があった。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 11:10; エペソ人への手紙 2:20; イザヤ書 54:11"> 都の城壁には十二の土台があり、その上には小羊の十二使徒の十二の名が記されていた。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ゼカリヤ書 2:1; ヨハネの黙示録 11:1–2; エゼキエル書 41:1–5"> 私に語りかけた御使いは、都とその門と城壁を測るため、測り竿として金の葦を持っていた。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 48:35; エゼキエル書 48:8–20"> 都は四角形で、その長さは幅と同じであった。御使いが葦で都を測ると、一万二千十二スタディオン<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一万二千十二スタディオンは、二千二百二十一キロメートル、または千三百八十マイルである。TRは一万二千十二スタディオンの代わりに一万二千スタディオンとしている。">c</a></sup>あった。長さも幅も高さも同じであった。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネの黙示録 7:4; 申命記 3:11; ヨハネの黙示録 13:18"> また、城壁を測ると百四十四キュビト<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="百四十四キュビトは約六十五・八メートル、または二百十六フィートである。">d</a></sup>あった。これは人間の尺度、すなわち御使いの用いた尺度である。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 21:11; ヨハネの黙示録 21:21; ヨハネの黙示録 21:19"> 城壁は碧玉で造られ、都は澄んだガラスのような純金でできていた。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 54:11–12; 出エジプト記 28:17–21; ヨブ記 28:16–19"> 都の城壁の土台は、あらゆる宝石で飾られていた。第一の土台は碧玉、第二はサファイア、<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="または「ラピスラズリ」">e</a></sup>第三は玉髄、第四はエメラルド、</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの黙示録 4:3"> 第五は紅縞めのう、第六は赤めのう、第七は貴かんらん石、第八は緑柱石、第九はトパーズ、第十は緑玉髄、第十一は青玉、第十二は紫水晶であった。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの黙示録 21:18; ヨハネの黙示録 17:4; ヨハネの黙示録 22:2"> 十二の門は十二の真珠で、それぞれの門が一個の真珠でできていた。都の大通りは、透き通ったガラスのような純金であった。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨハネ 4:23; 列王記第一 8:27; 歴代誌 第二 2:6"> 私は都の中に神殿を見なかった。主なる神、全能者と小羊が、都の神殿だからである。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 60:19–20; ヨハネの黙示録 22:5; ヨハネの黙示録 21:11"> 都には、照らすための太陽も月も必要ない。神ご自身の栄光が都を照らし、小羊がそのともしびだからである。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨハネの黙示録 21:26; ヨハネの黙示録 22:2; ゼカリヤ書 8:22–23"> 諸国民は都の光の中を歩み、地上の王たちは諸国民の栄光と誉れを都に携えて来る。</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 60:11; ゼカリヤ書 14:7; ヨハネの黙示録 22:5"> 都の門は昼の間、決して閉じられない。そこには夜がないからである。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの黙示録 21:24"> 人々は、都に入るため、諸国民の栄光と誉れをその中に携えて来る。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネの黙示録 22:14–15; イザヤ書 52:1; ヨハネの黙示録 20:15"> 汚れたもの、忌まわしいことや偽りを行う者は、決して都に入れない。入れるのは、小羊の命の書に名が記されている者だけである。</span>
</div>

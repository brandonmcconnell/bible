<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの黙示録 1:18; ペテロの第二の手紙 2:4; ユダ 1:6"> また、一人の御使いが底知れぬ所の鍵と大きな鎖を手に持ち、天から下って来るのを見た。</span>
<span className="v" id="v2" data-v="2" data-xref="ペテロの第二の手紙 2:4; ヨハネの黙示録 12:9; イザヤ書 27:1"> 御使いは、竜、すなわち、全世界を惑わす者<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TRとNUは「全世界を惑わす者」を省いている。">a</a></sup>で、悪魔またサタンである、あの古い蛇を捕らえ、千年の間つないだ。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 20:1; ヨハネの黙示録 17:8; テサロニケ人への第二の手紙 2:9–11"> そして竜を底知れぬ所に投げ込み、その入口を閉じ、その上に封印をした。千年が終わるまで、竜がこれ以上諸国民を惑わさないようにするためである。その後、竜はしばらくの間、解き放たれなければならない。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ダニエル書 7:27; ダニエル書 7:18; マタイ 19:28"> また、いくつもの王座を見た。そこには人々が座り、彼らには裁きを行う権威が与えられた。また、イエスのあかしと神の言葉のために首をはねられた人々の魂を見た。彼らは獣もその像も礼拝せず、額にも手にもその印を受けなかった。彼らは生き返り、キリストとともに千年の間治めた。</span>
<span className="v" id="v5" data-v="5" data-xref="ピリピ人への手紙 3:11; ヨハネの黙示録 11:15; ルカ 14:14"> 残りの死者は、千年が終わるまで生き返らなかった。これが第一の復活である。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 2:11; ヨハネの黙示録 1:6; テモテへの第二の手紙 2:12"> 第一の復活にあずかる者は、幸いであり、聖なる者である。この人々に対して、第二の死は何の力も持たない。彼らは神とキリストの祭司となり、キリストとともに千年の間治める。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨハネの黙示録 20:2"> 千年が終わると、サタンは牢獄から解き放たれる。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの黙示録 16:14; エゼキエル書 38:1; ヨハネの黙示録 20:10"> そして、地の四隅にいる諸国民、すなわちゴグとマゴグを惑わすために出て行き、彼らを戦いのために集める。その数は海の砂のように多い。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 38:16; エゼキエル書 39:6; エゼキエル書 38:9"> 彼らは地の広がりを進み、聖徒たちの陣営と愛された都を取り囲んだ。しかし、神のもとから火が天より下り、彼らを焼き尽くした。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイ 25:41; ヨハネの黙示録 19:20; マタイ 25:46"> 彼らを惑わした悪魔は、獣と偽預言者のいる火と硫黄の池に投げ込まれた。彼らは昼も夜も永遠に苦しめられる。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 21:1; ペテロの第二の手紙 3:7; マタイ 25:31"> また、大きな白い王座と、そこに座っておられる方を見た。その御顔の前から地と空は逃げ去り、その居場所は見つからなかった。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第二の手紙 5:10; マタイ 16:27; ダニエル書 7:10"> また、死者たちが、大きい者も小さい者も王座の前に立っているのを見た。そして、いくつもの書物が開かれた。さらに、もう一つの書物が開かれた。それは命の書である。死者たちは、書物に書かれていることに基づき、自分たちの行いに応じて裁かれた。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネ 5:28–29; ヨハネの黙示録 6:8; ホセア書 13:14"> 海はその中にいる死者を出し、死とハデス<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または「地獄」">b</a></sup>も、その中にいる死者を出した。彼らは一人ひとり、その行いに応じて裁かれた。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 15:26; ヨハネの黙示録 20:6; ヨハネの黙示録 21:8"> それから、死とハデス<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="または「地獄」">c</a></sup>は火の池に投げ込まれた。この火の池が第二の死である。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネ 3:36; マタイ 13:50; マタイ 25:41"> 命の書に名が記されていない者は、火の池に投げ込まれた。</span>
</div>

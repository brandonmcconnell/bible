<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="ヨハネの手紙第一 4:1; ペテロの第二の手紙 2:1–3; テサロニケ人への手紙第一 5:21"> <span className="woj">わたしは、あなたの行いと労苦と忍耐を知っている。また、あなたが悪人たちを容認せず、使徒と自称しながら実はそうでない者たちを試し、彼らが偽り者であることを見抜いたのも知っている。</span></span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 10:36; ガラテヤ人への手紙 6:9; ヤコブの手紙 5:7–11"> <span className="woj">あなたは忍耐し、わたしの名のために耐え忍び、</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TRは「労苦し、」を加えている。">a</a></sup><span className="woj">くじけることがなかった。</span></span>
<span className="v" id="v4" data-v="4" data-xref="マタイ 24:12–13; エレミヤ書 2:2–5; ヘブル人への手紙 6:10–11"> <span className="woj">しかし、あなたには責めるべきことがある。あなたは初めの愛を捨ててしまった。</span></span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 3:2–3; ヨハネの黙示録 3:19; ヨハネの黙示録 2:16"> <span className="woj">だから、どこから落ちたのかを思い出し、悔い改めて、初めの行いをしなさい。さもなければ、わたしはすぐにあなたのところへ行き、あなたが悔い改めないなら、あなたの燭台をその場所から移す。</span></span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 101:3; ヨハネの手紙第二 1:9–10; 詩篇 26:5"> <span className="woj">しかし、あなたにはこの点がある。あなたはニコライ派の人々の行いを憎んでいる。わたしもそれを憎んでいる。</span></span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの黙示録 2:17; ヨハネの黙示録 2:11; マタイ 11:15"> <span className="woj">耳のある者は、聖霊が諸教会に語ることを聞きなさい。勝利を得る者には、わたしの神の楽園にある命の木の実を食べさせよう。』</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨハネの黙示録 1:17–18; ヨハネの黙示録 1:8; ヨハネの黙示録 1:11"> <span className="woj">「スミルナにある教会の御使いに書き送りなさい。</span><br /><span className="woj">『最初であり最後である方、死んだが生き返った方が、こう言われる。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 3:9; コリント人への第二の手紙 8:9; ヤコブの手紙 2:5–6"> <span className="woj">わたしは、あなたの行いと苦難と貧しさを知っている。しかし、あなたは豊かである。また、自分はユダヤ人だと言いながら実はそうではなく、サタンの会堂に属する者たちの中傷も知っている。</span></span>
<span className="v" id="v10" data-v="10" data-xref="ヤコブの手紙 1:12; マタイ 10:22; ヨハネの黙示録 3:10–11"> <span className="woj">これから受けようとしている苦しみを恐れてはならない。見よ、悪魔はあなたがたを試すために、そのうちの何人かを牢獄に投げ込もうとしている。あなたがたは十日の間、苦難を受ける。死に至るまで忠実でありなさい。そうすれば、命の冠を与えよう。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 20:6; ヨハネの黙示録 20:14; ヨハネの黙示録 21:8"> <span className="woj">耳のある者は、聖霊が諸教会に語ることを聞きなさい。勝利を得る者は、決して第二の死によって害を受けない。』</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 2:16; ヘブル人への手紙 4:12; ヨハネの黙示録 1:16"> <span className="woj">「ペルガモンにある教会の御使いに書き送りなさい。</span><br /><span className="woj">『鋭い両刃の剣を持つ方が、こう言われる。</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 2:9–10; テモテへの手紙第一 5:8; ヨハネの黙示録 3:8–9"> <span className="woj">わたしは、あなたの行いと、あなたがどこに住んでいるかを知っている。そこにはサタンの王座がある。それでもあなたは、わたしの名を堅く守り、わたしの忠実な証人アンティパスが、サタンの住むあなたがたのところで殺された日々にも、わたしの信仰を否定しなかった。</span></span>
<span className="v" id="v14" data-v="14" data-xref="民数記 31:16; ペテロの第二の手紙 2:15; ヨハネの黙示録 2:20"> <span className="woj">しかし、あなたには少しばかり責めるべきことがある。あなたのところには、バラムの教えに従う者たちがいる。バラムはバラクに、イスラエルの子らの前につまずきの石を置き、偶像に供えた物を食べさせ、淫行を行わせるよう教えた。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの黙示録 2:6"> <span className="woj">同じように、あなたのところにもニコライ派の教えに従う者たちがいる。</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TRは「同じように」の代わりに「わたしが憎む」としている。">b</a></sup></span>
<span className="v" id="v16" data-v="16" data-xref="テサロニケ人への第二の手紙 2:8; ヨハネの黙示録 1:16; ヨハネの黙示録 2:5"> <span className="woj">だから悔い改めなさい。さもなければ、わたしはすぐにあなたのところへ行き、口の剣で彼らと戦う。</span></span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 62:2; イザヤ書 65:15; ヨハネの黙示録 19:12–13"> <span className="woj">耳のある者は、聖霊が諸教会に語ることを聞きなさい。勝利を得る者には、隠されたマナを与え、</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="マナは超自然的な食物で、その名はヘブル語の「これは何か」に由来する。出エジプト記11:7–9参照。">c</a></sup><span className="woj">白い石を与えよう。その石には、受け取る者のほかはだれも知らない新しい名が書かれている。』</span></span>

</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="テモテへの手紙第一 1:5; ペテロの第二の手紙 1:7; ヨハネ 15:2"> <span className="woj">わたしは、あなたの行い、愛、信仰、奉仕、忍耐を知っている。また、あなたの最近の行いが初めの行いよりも多いことも知っている。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの黙示録 2:14; 列王記第一 16:31; コリント人への第一の手紙 10:18–21"> <span className="woj">しかし、あなたには責めるべきことがある。あなたは、自ら女預言者と称する、あなたの</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="TRとNUは「あなたの」の代わりに「その」としている。">d</a></sup><span className="woj">もとにいるイゼベルという女を容認している。彼女はわたしの僕たちを教えて惑わし、淫行を行わせ、偶像に供えた物を食べさせている。</span></span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの第二の手紙 3:9; ローマ人への手紙 2:4–5; ヨハネの黙示録 9:20–21"> <span className="woj">わたしは彼女に悔い改める時間を与えたが、彼女は自分の淫行を悔い改めようとしない。</span></span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの黙示録 17:2; ルカ 13:5; エゼキエル書 16:37–41"> <span className="woj">見よ、わたしは彼女を病の床に投げ込み、彼女と姦淫する者たちを大きな苦難に投げ込む。彼女の行いを悔い改めないかぎり、そうする。</span></span>
<span className="v" id="v23" data-v="23" data-xref="マタイ 16:27; ローマ人への手紙 8:27; 詩篇 7:9"> <span className="woj">また、彼女の子どもたちを死で打つ。そうすれば、すべての教会は、わたしが思いと心を探る者であることを知る。わたしはあなたがた一人ひとりに、その行いに応じて報いる。</span></span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第二の手紙 2:11; ヨハネの黙示録 12:9; コリント人への第二の手紙 11:3"> <span className="woj">しかし、テアティラにいる残りの人々、この教えを持たず、ある人々が『サタンの深み』と呼ぶものを知らないすべての人に、わたしは言う。あなたがたには、ほかの重荷を負わせない。</span></span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの黙示録 3:11; ヨハネの黙示録 3:3; ヘブル人への手紙 10:23"> <span className="woj">ただし、わたしが来るまで、あなたがたの持っているものを堅く守りなさい。</span></span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの黙示録 3:21; ダニエル書 7:27; ヨハネの黙示録 2:7"> <span className="woj">勝利を得て、最後までわたしの行いを守る者には、諸国民を治める権威を与えよう。</span></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 2:8–9; ヨハネの黙示録 12:5; ヨハネの黙示録 19:15"> <span className="woj">彼は鉄の杖で彼らを治め、土の器のように粉々にする。わたしが父から受けたのと同じ権威である。</span></span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 22:16; ペテロの第二の手紙 1:19; ルカ 1:78–79"> <span className="woj">また、彼に明けの明星を与えよう。</span></span>
<span className="v" id="v29" data-v="29" data-xref="ヨハネの黙示録 2:7"> <span className="woj">耳のある者は、聖霊が諸教会に語ることを聞きなさい。』</span></span>

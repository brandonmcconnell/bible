<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 14:8; エレミヤ書 51:7; ヨハネの黙示録 18:3"> 地上の王たちは彼女と淫行を行い、地上に住む者たちは彼女の淫行のぶどう酒に酔わされた。」</span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 12:3; ヨハネの黙示録 13:1–6; ヨハネの黙示録 12:6"> 御使いは、御霊によって私を荒野へ連れて行った。そこで私は、神を冒涜する名で覆われ、七つの頭と十本の角を持つ緋色の獣に、一人の女が乗っているのを見た。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 18:16; エレミヤ書 51:7; ヨハネの黙示録 19:2"> 女は紫と緋色の衣をまとい、金、宝石、真珠で身を飾っていた。その手には、忌まわしいものと、その淫行の汚れとで満ちた金の杯を持っていた。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 14:8; ヨハネの黙示録 18:2; ヨハネの黙示録 17:7"> その額には、名がこう書かれていた。「奥義、大バビロン、淫婦たちと地の忌まわしいものの母。」</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 16:6; ヨハネの黙示録 13:15; ヨハネの黙示録 2:13"> 私は、その女が聖徒たちの血と、イエスの殉教者たちの血に酔っているのを見た。彼女を見て、私は驚きに打たれた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨハネの黙示録 17:1–6; ヨハネの黙示録 17:8"> すると御使いが私に言った。「なぜ驚くのか。女の奥義と、彼女を乗せている、七つの頭と十本の角を持つ獣の奥義を、あなたに教えよう。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの黙示録 17:11; ヨハネの黙示録 11:7; ヨハネの黙示録 3:10"> あなたが見た獣は、かつてはいたが、今はいない。しかし、底知れぬ所から上って来て、滅びへ向かう。世の初めから命の書に名が記されていない地上の住民は、獣が、かつてはいたが、今はいないのに、やがて現れる<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TRは「やがて現れる」の代わりに「なおいる」としている。">a</a></sup>のを見て驚く。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 13:18; ヨハネの黙示録 17:7; マタイ 13:11"> ここに、知恵ある理解が必要である。七つの頭は、女がその上に座っている七つの山である。</span>
<span className="v" id="v10" data-v="10"> また、七人の王でもある。五人は倒れ、一人は今おり、もう一人はまだ来ていない。しかし、彼が来れば、しばらくとどまらなければならない。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 17:8"> かつてはいたが、今はいない獣は、それ自身が第八の王であり、七人のうちの一人でもある。そして滅びへ向かう。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 12:3; ヨハネの黙示録 13:1; ダニエル書 7:24"> あなたが見た十本の角は、まだ王国を受けていない十人の王である。彼らは獣とともに、一時の間、王としての権威を受ける。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 17:17; エゼキエル書 38:10; イザヤ書 10:5–7"> 彼らは一つの思いを持ち、自分たちの力と権威を獣に与える。</span>
<span className="v" id="v14" data-v="14" data-xref="ローマ人への手紙 8:30; テモテへの手紙第一 6:15; マタイ 22:14"> 彼らは小羊と戦うが、小羊は彼らに打ち勝つ。小羊は主の主、王の王だからである。また、小羊とともにいる者たちは、召され、選ばれ、忠実な者たちである。」</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの黙示録 17:1; エレミヤ書 51:13; エレミヤ書 51:55"> 御使いはまた私に言った。「あなたが見た水、大淫婦が座っている所は、諸民族、群衆、国民、言語である。</span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 18:8; エゼキエル書 16:37–44; レビ記 21:9"> あなたが見た十本の角と獣は大淫婦を憎み、彼女を荒れ果てさせ、裸にし、その肉を食らい、火で焼き尽くす。</span>
<span className="v" id="v17" data-v="17" data-xref="テサロニケ人への第二の手紙 2:10–12; 箴言 21:1; ヨハネの黙示録 10:7"> 神がご自分の御心を実現させるため、彼らの心に一つの思いを持たせ、神の言葉が成就するまで、自分たちの王国を獣に与えさせたからである。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 16:19; ヨハネの黙示録 18:2; ダニエル書 7:23"> あなたが見た女は、地上の王たちを治める大きな都である。」</span>

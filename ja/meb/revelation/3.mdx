<span className="v" id="v2" data-v="2" data-xref="ペテロの手紙第一 5:8; テモテへの第二の手紙 4:1–4; ヨハネの黙示録 16:15"> <span className="woj">目を覚ましなさい。そして、残されたもののうち、捨て去ろうとしていたものを力づけなさい。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NUとTRは「あなたが捨てようとしていた」の代わりに「死にかけていた」としている。">a</a></sup><span className="woj">わたしの神の前で、あなたの行いが完成されたものとは認められなかったからである。</span></span>
<span className="v" id="v3" data-v="3" data-xref="ヨハネの黙示録 2:5; ペテロの第二の手紙 3:10; テサロニケ人への手紙第一 5:2"> <span className="woj">だから、どのように受け、聞いたかを思い出し、それを守って悔い改めなさい。もし目を覚ましていなければ、わたしは盗人のように来る。わたしがいつあなたのところに来るか、あなたには分からない。</span></span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 3:5; ヨハネの黙示録 7:9; 伝道者の書 9:8"> <span className="woj">しかし、サルディスには、自分の衣を汚さなかった者が、わずかだがいる。彼らはそれにふさわしいので、白い衣を着て、わたしとともに歩む。</span></span>
<span className="v" id="v5" data-v="5" data-xref="マタイ 10:32; ルカ 12:8; ヨハネの黙示録 21:27"> <span className="woj">勝利を得る者は白い衣を着せられる。わたしはその名を命の書から決して消さず、わたしの父と御使いたちの前で、その名を公に認める。</span></span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 2:7"> <span className="woj">耳のある者は、聖霊が諸教会に語ることを聞きなさい。』</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 22:22; マタイ 16:19; ヨハネの黙示録 1:18"> <span className="woj">「フィラデルフィアにある教会の御使いに書き送りなさい。</span><br /><span className="woj">『聖なる方、真実な方、ダビデの鍵を持つ方、開けばだれも閉じることができず、閉じればだれも開くことができない方が、こう言われる。</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 16:9; コロサイ人への手紙 4:3; ヨハネの黙示録 3:7"> <span className="woj">わたしはあなたの行いを知っている。見よ、わたしはあなたの前に、だれも閉じることのできない開かれた扉を置いた。あなたの力はわずかでも、わたしの言葉を守り、わたしの名を否まなかった。</span></span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 60:14; ヨハネの黙示録 2:9; イザヤ書 49:23"> <span className="woj">見よ、自分はユダヤ人だと言いながら実はそうではなく、偽っているサタンの会堂の者たちを、あなたの足もとに来てひれ伏させよう。そして、わたしがあなたを愛したことを彼らに知らせよう。</span></span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの第二の手紙 2:9; ヨハネの黙示録 14:12; ゼカリヤ書 13:9"> <span className="woj">忍耐せよというわたしの命令を守ったので、わたしも、地上に住む者たちを試すため全世界に臨もうとしている試練の時から、あなたを守る。</span></span>
<span className="v" id="v11" data-v="11" data-xref="ヤコブの手紙 1:12; ヨハネの黙示録 22:12; ヨハネの黙示録 2:10"> <span className="woj">わたしはすぐに来る。だれにもあなたの冠を奪われないように、持っているものを堅く守りなさい。</span></span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 22:4; ヨハネの黙示録 21:2; ヨハネの黙示録 14:1"> <span className="woj">勝利を得る者を、わたしの神の神殿の柱にしよう。彼はもう決してそこから出ることはない。わたしは彼の上に、わたしの神の名と、わたしの神の都、すなわち、わたしの神のもとから天より下って来る新しいエルサレムの名と、わたし自身の新しい名を書き記す。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 2:7"> <span className="woj">耳のある者は、聖霊が諸教会に語ることを聞きなさい。』</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="コロサイ人への手紙 1:15; ヨハネの黙示録 1:5; コリント人への第二の手紙 1:20"> <span className="woj">「ラオディキアにある教会の御使いに書き送りなさい。</span><br /><span className="woj">『アーメンである方、忠実で真実な証人、神の創造の初め</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または「源」、または「かしら」">b</a></sup><span className="woj">である方が、こう言われる。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 12:11; マタイ 6:24; 列王記第一 18:21"> <span className="woj">わたしはあなたの行いを知っている。あなたは冷たくも熱くもない。冷たいか熱いか、どちらかであってほしい。</span></span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 2:5; ゼカリヤ書 11:8–9; エレミヤ書 14:19"> <span className="woj">しかし、あなたは生ぬるく、熱くも冷たくもないので、わたしはあなたを口から吐き出そう。</span></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 13:7; ホセア書 12:8; ローマ人への手紙 7:24"> <span className="woj">あなたは、『私は豊かで、富を得た。何も必要なものはない』と言っているが、自分が惨めで、哀れで、貧しく、盲目で、裸であることを知らない。</span></span>
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 16:15; ペテロの手紙第一 1:7; イザヤ書 55:1"> <span className="woj">そこで、火で精錬された金をわたしから買って豊かになりなさい。白い衣を買って身にまとい、裸の恥をさらさないようにしなさい。また、目薬を買って目に塗り、見えるようになりなさい。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 3:11–12; コリント人への第一の手紙 11:32; ヘブル人への手紙 12:5–11"> <span className="woj">わたしは愛する者をみな叱り、懲らしめる。だから熱心になり、悔い改めなさい。</span></span>
<span className="v" id="v20" data-v="20" data-xref="ルカ 12:36–37; ヨハネの黙示録 19:9; ヨハネ 14:21–23"> <span className="woj">見よ、わたしは戸口に立ってたたいている。だれでも、わたしの声を聞いて戸を開けるなら、わたしはその人のところに入り、その人と食事をともにしよう。</span></span>
<span className="v" id="v21" data-v="21" data-xref="テモテへの第二の手紙 2:12; マタイ 19:28; ヨハネの黙示録 2:26–27"> <span className="woj">勝利を得る者には、わたしとともにわたしの王座に座ることを許そう。わたしも勝利を得て、父とともにその王座に座ったのと同じである。</span></span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの黙示録 2:7; ヨハネの黙示録 2:11; ヨハネの黙示録 2:17"> <span className="woj">耳のある者は、聖霊が諸教会に語ることを聞きなさい。』」</span></span>

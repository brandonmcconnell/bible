<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの黙示録 7:17; ヨハネ 4:14; 詩篇 36:8–9"> 御使いはまた、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TRは「清い」を加えている。">a</a></sup>水晶のように澄んだ命の水の川を私に見せた。その川は、神と小羊の王座から流れ出て、</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 22:1; ペテロの手紙第一 2:24; ヨハネの黙示録 2:7"> 都の大通りの中央を流れていた。川の両岸には命の木があり、十二種類の実を結び、毎月その実を実らせていた。その木の葉は諸国民を癒やすためのものであった。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイ 25:21; ヨハネの黙示録 21:3–4; ヨハネ 12:26"> もはや、のろいはない。神と小羊の王座が都の中にあり、その僕たちはその方に仕える。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイ 5:8; ヨハネの黙示録 14:1; ヨハネの黙示録 3:12"> 彼らはその御顔を仰ぎ見て、その額にはその名が記される。</span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 60:19–20; ダニエル書 7:18; ヨハネの黙示録 20:4"> そこには、もはや夜がない。ともしびの光も太陽の光も必要ない。主なる神が彼らを照らされるからである。彼らは永遠に王として治める。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 1:1; ヨハネの黙示録 21:5; ヨハネの黙示録 19:9"> 御使いは私に言った。「これらの言葉は忠実で真実である。預言者たちの霊を司る神である主は、間もなく起こるべきことを僕たちに示すため、ご自分の御使いを遣わされた。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨハネの黙示録 1:3; ヨハネの黙示録 3:11; ヨハネの黙示録 22:20"> <span className="woj">「見よ、わたしはすぐに来る。この書の預言の言葉を守る者は幸いである。」</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨハネの黙示録 19:10; ヨハネの黙示録 1:1; ヨハネの黙示録 19:19"> これらのことを聞き、また見たのは、私ヨハネである。私が聞き、また見たとき、これらのことを見せてくれた御使いを礼拝しようとして、その足もとにひれ伏した。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 19:10; コロサイ人への手紙 2:18–19; ヨハネの黙示録 14:7"> しかし、御使いは私に言った。「そうしてはならない。私は、あなたや、あなたの兄弟である預言者たち、またこの書の言葉を守る人々と同じ僕である。神を礼拝しなさい。」</span>
<span className="v" id="v10" data-v="10" data-xref="ダニエル書 8:26; ヨハネの黙示録 1:3; ペテロの手紙第一 4:7"> また私に言った。「この書の預言の言葉を封じてはならない。時が近いからである。</span>
<span className="v" id="v11" data-v="11" data-xref="ダニエル書 12:10; 箴言 4:18; エゼキエル書 3:27"> 不義を行う者は、なお不義を行うがよい。汚れた者は、なお汚れたままでいるがよい。義人は、なお義を行うがよい。聖なる者は、なお聖なる者であり続けるがよい。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マタイ 16:27; イザヤ書 62:11; イザヤ書 40:10"> <span className="woj">「見よ、わたしはすぐに来る。わたしは報いを携えて来て、一人ひとりにその行いに応じて報いる。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 1:8; ヨハネの黙示録 21:6; イザヤ書 44:6"> <span className="woj">わたしはアルファであり、オメガである。最初であり、最後である。初めであり、終わりである。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの黙示録 21:27; ヨハネの手紙第一 5:3; ヨハネの黙示録 22:7"> <span className="woj">その方の戒めを行う者たちは幸いである。</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NUは「その方の戒めを行う」の代わりに「自分の衣を洗う」としている。">b</a></sup><span className="woj">彼らは命の木にあずかる権利を得て、門を通って都に入ることができる。</span></span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネの黙示録 21:8; ガラテヤ人への手紙 5:19–21; ピリピ人への手紙 3:2"> <span className="woj">外にいるのは、犬ども、魔術を行う者、淫行を行う者、殺人者、偶像を礼拝する者、偽りを愛して行うすべての者である。</span></span>
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 5:5; ペテロの第二の手紙 1:19; イザヤ書 11:1"> <span className="woj">わたしイエスは、諸教会のためにこれらのことをあなたがたに証言させるため、わたしの御使いを遣わした。わたしはダビデの根であり、その子孫であり、輝く明けの明星である。」</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヨハネ 4:14; ヨハネの黙示録 21:6; イザヤ書 55:1–3"> 聖霊と花嫁が言う。「来てください。」これを聞く者も、「来てください」と言いなさい。渇いている者は来なさい。望む者は、命の水を無償で受けなさい。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命記 12:32; 申命記 4:2; 箴言 30:6"> 私は、この書の預言の言葉を聞くすべての人に証言する。これらの言葉に付け加える者がいれば、神はこの書に書かれている災害をその者に加えられる。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 4:2; ルカ 11:52; ヨハネの黙示録 22:2"> また、この預言の書の言葉から取り去る者がいれば、神は、この書に書かれている命の木<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="TRは「木」の代わりに「書」としている。">c</a></sup>と聖なる都にあずかるその者の分を取り去られる。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの黙示録 22:7; ヘブル人への手紙 9:28; ヨハネの黙示録 22:12"> これらのことを証言する方が言われる。<span className="woj">「そのとおりである。わたしはすぐに来る。」</span><br />アーメン。主イエスよ、来てください。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="テサロニケ人への第二の手紙 3:18; ローマ人への手紙 16:20; コリント人への第二の手紙 13:14"> 主イエス・キリストの恵みが、すべての聖徒たちとともにあるように。アーメン。</span>

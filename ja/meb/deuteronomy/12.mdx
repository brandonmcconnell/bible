<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王記第一 8:40; ヨブ記 7:1; 申命記 4:19"> あなたがたの父祖の神、主があなたに与えて所有させてくださる地において、あなたがたが地上に生きるすべての日の間、注意して行うべき掟と法はこれである。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 7:5; 列王記第二 16:4; 民数記 33:51–52"> あなたがたが追い払う国々の民がその神々に仕えたすべての場所、すなわち高い山の上、丘の上、すべての青々とした木の下を、あなたがたは完全に滅ぼせ。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 2:2; ゼカリヤ書 13:2; 民数記 33:52"> 彼らの祭壇を打ち壊し、石柱を砕き、アシェラ柱を火で焼き、神々の彫像を切り倒せ。その名をその場所から消し去れ。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="レビ記 20:23; 申命記 20:18; 申命記 16:21–22"> あなたがたの神、主に対して、そのように行ってはならない。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 12:11; 申命記 26:2; 歴代誌 第二 7:12"> そうではなく、あなたの神、主がご自分の名を置くため、すべての部族の中から選ばれる場所、主の住まいを求め、そこへ行け。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 15:19–20; マラキ書 3:10; レビ記 27:32–33"> そこへ、全焼のささげ物、いけにえ、十分の一のささげ物、手の揺り動かすささげ物、誓願のささげ物、自発的なささげ物、牛や羊の群れの初子を持って行け。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 12:18; レビ記 23:40; 申命記 14:26"> そこであなたがたは、あなたの神、主の前で食べなさい。あなたとあなたの家族は、あなたの神、主があなたを祝福してくださったあなたの手のすべての働きを喜び楽しみなさい。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="士師記 21:25; 士師記 17:6; 箴言 21:2"> わたしたちが今日ここでしているように、それぞれが自分の目に正しいと見えることを行ってはならない。</span>
<span className="v" id="v9" data-v="9" data-xref="列王記第一 8:56; 詩篇 95:11; 申命記 25:19"> あなたの神、主があなたに与えようとしておられる安息の場所と所有地に、あなたがたはまだ入っていないからである。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 33:11; エゼキエル書 34:28; 申命記 3:27"> しかし、あなたがたがヨルダン川を渡り、あなたの神、主が受け継がせてくださるその地に住み、主が周囲のすべての敵からあなたがたに安息を与えられ、あなたがたが安全に住むようになったとき、</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 12:5; 申命記 15:20; 申命記 17:8"> あなたの神、主がご自分の名を住まわせるために選ばれる場所がある。そこへ、わたしがあなたに命じるすべてのもの、すなわちあなたの全焼のささげ物、いけにえ、十分の一のささげ物、あなたの手の揺り動かすささげ物、そしてあなたが主に誓うすべてのえり抜きの誓願のささげ物を持って行け。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 12:7; 申命記 10:9; 申命記 26:12"> あなたがたは、あなたの神、主の前で喜び楽しみなさい。あなたと、あなたの息子たち、娘たち、男奴隷、女奴隷、そしてあなたの町に住むレビ人も同様である。彼にはあなたとともに持つ割り当ても所有地もないからである。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王記第一 12:28–32; 列王記第一 15:34; 歴代誌 第二 15:17"> あなたが見るどの場所でも全焼のささげ物をささげないように気をつけなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 12:11; コリント人への第二の手紙 5:19; 申命記 12:5"> ただ、主があなたの部族の一つの中に選ばれる場所で全焼のささげ物を献げ、そこでわたしが命じるすべてのことを行え。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命記 14:5; 申命記 15:22–23; 申命記 14:26"> ただし、あなたの神、主が与えられた祝福に応じ、どの町でも望むままに家畜を屠って肉を食べてよい。汚れた者もきよい者も、かもしかや鹿の肉と同じように食べてよい。</span>
<span className="v" id="v16" data-v="16" data-xref="創世記 9:4; 申命記 15:23; 申命記 12:23–24"> ただし、血を食べてはならない。水のように地面に注ぎ出せ。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 26:14; 申命記 12:6; 申命記 14:22–29"> あなたは、あなたの穀物、新しいぶどう酒、油の十分の一、牛や羊の群れの初子、あなたが誓うすべての誓願のささげ物、自発的なささげ物、あなたの手の揺り動かすささげ物を、自分の町で食べてはならない。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 12:7; 申命記 14:23; 申命記 12:5"> ただ、あなたの神、主が選ばれる場所で、あなたの神、主の前でそれを食べよ。あなたも、あなたの息子、娘、男奴隷、女奴隷、そしてあなたの町に住むレビ人も同様である。あなたは、あなたの手のすべての働きについて、あなたの神、主の前で喜び楽しみなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代誌 第二 31:4–21; ネヘミヤ記 10:34–39; 申命記 14:27–29"> あなたが自分の地に生きている間、レビ人を見捨てないように気をつけなさい。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 19:8; 申命記 11:24; 出エジプト記 34:24"> あなたの神、主が約束どおり領土を広げられ、あなたが肉を食べたいと思うときは、望むままに肉を食べてよい。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 12:5; 列王記第一 14:21; 申命記 16:11"> あなたの神、主がご自分の名を置くために選ばれる場所が遠いなら、主が与えられた牛や羊を、わたしが命じたとおりに屠り、町の中で望むままに食べてよい。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 12:15–16"> ガゼルや鹿が食べられるように、あなたはそれを食べてもよい。汚れた者もきよい者も等しくそれを食べてもよい。</span>
<span className="v" id="v23" data-v="23" data-xref="レビ記 17:11; 創世記 9:4; レビ記 17:13–14"> ただ、血を食べないように十分気をつけなさい。血は命だからである。肉と一緒に命を食べてはならない。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 12:16; 申命記 15:23"> それを食べてはならない。水のように地面に注ぎ出せ。</span>
<span className="v" id="v25" data-v="25" data-xref="列王記第一 11:38; 申命記 4:40; イザヤ書 3:10"> それを食べてはならない。それは、あなたが主の目に正しいことを行い、あなたとあなたの後の子供たちが幸いを得るためである。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="民数記 18:19; 民数記 5:9–10; 申命記 12:11"> ただ、あなたの持つ聖なるもの、およびあなたの誓願のささげ物は、主が選ばれる場所へ持って行け。</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 1:13; レビ記 17:11; レビ記 1:9"> あなたは全焼のささげ物の肉と血を、あなたの神、主の祭壇の上にささげなさい。あなたのいけにえの血はあなたの神、主の祭壇に注ぎ出せが、肉はあなたが食べてもよい。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命記 4:40; ヨハネ 15:14; ヨハネ 15:10"> あなたの神、主の御目に良くて正しいことを行い、あなたとあなたの後の子供たちが永遠に幸いを得るために、わたしがあなたに命じるこれらのすべての言葉に注意して聞き従いなさい。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 23:4; 申命記 19:1; 申命記 9:3"> あなたが所有するために入って行く地の国々の民を、あなたの神、主があなたの前から断ち滅ぼし、あなたが彼らを所有して彼らの地に住むとき、</span>
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 10:2; エゼキエル書 20:32; 申命記 7:16"> 彼らがあなたの前から滅ぼされた後で、彼らに倣って罠にかからないように、また彼らの神々を探し求めて、「これらの国々の民はどのようにしてその神々に仕えたのだろうか。私も同じようにしよう」と言わないように気をつけなさい。</span>
<span className="v" id="v31" data-v="31" data-xref="エレミヤ書 32:35; 申命記 18:9–10; 列王記第二 17:15–17"> あなたはあなたの神、主に対して、そのように行ってはならない。彼らは主が憎まれるあらゆる忌まわしいことをその神々に対して行ったからである。彼らは自分たちの神々に、息子や娘たちさえも火で燃やしてささげるのである。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="申命記 4:2; ヨハネの黙示録 22:18–19; ヨシュア記 1:7"> わたしが命じるすべてのことを注意して行え。それに付け加えてはならず、そこから減らしてもならない。</span>
</div>

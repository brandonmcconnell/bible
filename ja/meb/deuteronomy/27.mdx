<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネ 15:14; ルカ 11:28; ヤコブの手紙 2:10"> モーセとイスラエルの長老たちは民に命じて言った。「わたしが今日あなたに命じるすべての命令を守りなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 8:31; エゼキエル書 36:26; エゼキエル書 11:19"> ヨルダン川を渡って、あなたの神、主が与えられる地に入る日に、大きな石を立て、漆喰を塗れ。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨシュア記 8:32; 申命記 26:9; コリント人への第二の手紙 3:2–3"> あなたが渡ったとき、その上にこの律法のすべての言葉を書き記せ。それは、あなたの父祖の神、主があなたに約束されたとおり、あなたの神、主があなたに与えられる地、乳と蜜の流れる地にあなたが入るためである。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 11:29–30; ヨシュア記 8:30–33"> ヨルダン川を渡ったとき、わたしが今日命じるとおり、エバル山にこれらの石を立て、漆喰を塗れ。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 20:25; 出エジプト記 24:4; ヨシュア記 8:30–31"> そこで、あなたの神、主のために石の祭壇を築け。石に鉄の道具を用いてはならない。</span>
<span className="v" id="v6" data-v="6" data-xref="エペソ人への手紙 5:2; レビ記 1:1–17"> 切り出していない石で、あなたの神、主の祭壇を築け。その上で、あなたの神、主に全焼のささげ物を献げよ。</span>
<span className="v" id="v7" data-v="7" data-xref="レビ記 3:1–17; イザヤ書 12:3; 詩篇 100:1–2"> また、和解のいけにえをささげ、そこで食べなさい。あなたはあなたの神、主の前で喜び楽しみなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="ハバクク書 2:2; ヨハネ 16:25; コリント人への第二の手紙 3:12"> 石の上に、この律法のすべての言葉を明瞭に書き記せ。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ペテロの手紙第一 2:10–11; 申命記 26:16–18; エペソ人への手紙 5:8–9"> モーセとレビ人の祭司たちは全イスラエルに語って言った。「静かにして、聞きなさい、イスラエルよ。今日、あなたはあなたの神、主の民となった。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 11:1; ペテロの手紙第一 1:14–16; マタイ 5:48"> それゆえ、あなたの神、主の御声に聞き従い、わたしが今日あなたに命じる主の命令と掟を行え。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> モーセは同じ日に民に命じて言った。</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 9:7; 創世記 30:24; 創世記 35:18"> 「あなたがたがヨルダン川を渡ったとき、民を祝福するためにゲリジム山に立つ者は次のとおりである。シメオン、レビ、ユダ、イッサカル、ヨセフ、ベニヤミンである。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 27:4; 創世記 29:32; 創世記 30:20"> また、呪いのためにエバル山に立つ者は次のとおりである。ルベン、ガド、アシェル、ゼブルン、ダン、ナフタリである。</span>
<span className="v" id="v14" data-v="14" data-xref="ダニエル書 9:11; 申命記 33:9–10; ヨシュア記 8:33"> レビ人は声を大にして、イスラエルのすべての者に宣言する。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 34:17; 出エジプト記 20:4; 申命記 5:8"> 『主にとって忌まわしいもの、職人の手の業である彫像や鋳造した偶像を造り、それをひそかに安置する者は呪われる。』すべての民は答えて、『アーメン』と言う。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="レビ記 19:3; 出エジプト記 21:17; 申命記 21:18–21"> 『自分の父や母を軽んじる者は呪われる。』すべての民は、『アーメン』と言う。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="申命記 19:14; 箴言 22:28; 箴言 23:10–11"> 『隣人の境界標を移す者は呪われる。』すべての民は、『アーメン』と言う。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="レビ記 19:14; マタイ 15:14; 箴言 28:10"> 『目の見えない者を道から迷わせる者は呪われる。』すべての民は、『アーメン』と言う。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命記 10:18; 申命記 24:17; 箴言 17:23"> 『寄留者、孤児、やもめの裁きを曲げる者は呪われる。』すべての民は、『アーメン』と言う。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 22:30; レビ記 18:8; コリント人への第一の手紙 5:1"> 『父の妻と寝る<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="すなわち、性的関係を持つ。">a</a></sup>者は呪われる。彼は父の寝床を辱めたからである。』すべての民は、『アーメン』と言う。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="レビ記 18:23; 出エジプト記 22:19; レビ記 20:15"> 『いかなる動物と寝る者も呪われる。』すべての民は、『アーメン』と言う。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="レビ記 20:17; レビ記 18:9; エゼキエル書 22:11"> 『自分の姉妹、すなわち父の娘、または母の娘と寝る者は呪われる。』すべての民は、『アーメン』と言う。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="レビ記 20:14; レビ記 18:17"> 『自分のしゅうとめと寝る者は呪われる。』すべての民は、『アーメン』と言う。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数記 35:31; レビ記 24:17; サムエル記第二 11:15–17"> 『ひそかに隣人を殺す者は呪われる。』すべての民は、『アーメン』と言う。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="申命記 10:17; 出エジプト記 23:7–8; 詩篇 15:5"> 『賄賂を受け取って罪のない人を殺す者は呪われる。』すべての民は、『アーメン』と言う。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ガラテヤ人への手紙 3:10; 申命記 28:15–68; ローマ人への手紙 10:5"> 『この律法の言葉を行うことによってそれを堅く守らない者は呪われる。』すべての民は、『アーメン』と言う。」</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 23:25–28; ヨハネの手紙第一 4:1; エレミヤ書 29:8"> もしあなたがたの中に預言者や夢見る者が現れ、しるしや不思議をあなたに示し、</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 13:6; マタイ 7:22–23; ヨハネの黙示録 13:13–14"> 彼があなたに語ったしるしや不思議が実現して、「あなたの知らなかった他の神々に従い、それらに仕えよう」と言うなら、</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 8:2; コリント人への第一の手紙 11:19; 詩篇 66:10"> あなたはその預言者や夢見る者の言葉に聞き従ってはならない。あなたの神、主は、あなたがたが心を尽くし、魂を尽くしてあなたの神、主を愛しているかどうかを知るために、あなたがたを試みておられるからである。</span>
<span className="v" id="v4" data-v="4" data-xref="コロサイ人への手紙 1:10; 申命記 10:20; コリント人への第一の手紙 6:17"> あなたがたの神、主に従って歩み、主を恐れ、主の命令を守り、その御声に聞き従え。主に仕え、主にすがれ。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第一の手紙 5:13; 申命記 18:20; エレミヤ書 14:15"> その預言者、または夢見る者は死刑に処せられる。彼は、あなたがたをエジプトの地から導き出し、奴隷の家から贖い出されたあなたがたの神、主に対する反逆を語り、主が歩むよう命じられた道からあなたを迷い出させようとした。こうして、あなたがたの中から悪を取り除け。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="申命記 17:2–7; ペテロの第二の手紙 2:1; エペソ人への手紙 4:14"> もしあなたの同じ母から生まれた兄弟、息子、娘、あなたの懐にいる妻、あるいは自分自身のような親しい友が、ひそかにあなたをそそのかして、「さあ、ほかの神々に仕えよう」と言うなら（それはあなたも父祖たちも知らなかった神々であり、</span>
<span className="v" id="v7" data-v="7"> 地の果てから果てに至るまで、あなたの近くにいるか遠くにいるかを問わず、あなたの周りにいる国々の民の神々のうちのどれかである）、</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 19:13; 箴言 1:10; 申命記 7:16"> 彼に同意してはならず、彼に聞き従ってはならない。彼をあわれみの目で見てはならず、彼を惜しんではならず、彼をかばってもならない。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 7:58; ルカ 14:26; マタイ 10:37"> 必ず彼を殺せ。彼を死刑にするため、まずあなたが手を下し、その後、民が皆手を下す。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨシュア記 7:25; レビ記 24:14–16; 出エジプト記 20:2"> 彼を石で打ち殺せ。彼は、エジプトの地、奴隷の家からあなたを導き出されたあなたの神、主から、あなたを遠ざけようとしたからである。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 19:20; 申命記 17:13; テモテへの手紙第一 5:20"> 全イスラエルはこれを聞いて恐れ、二度とこのような悪があなたのただ中で行われることはない。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="士師記 20:1–17; ヨシュア記 22:11–34"> もし、あなたの神、主があなたに住むために与えられた町々の一つについて、あなたがこう聞くなら、</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの手紙第一 2:19; 申命記 13:2; コリント人への第二の手紙 6:15"> 「あなたの中からならず者たちが出て行き、その町の住民を惑わして、『さあ行って、あなたがたの知らなかった他の神々に仕えよう』と言っている」と。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 17:4; イザヤ書 11:3–4; ヨハネ 7:24"> よく調べ、探り、念入りに問いただせ。もしそれが真実で、そのような忌まわしいことがあなたがたの中で行われたことが確かなら、</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 22:20; レビ記 27:28; 申命記 7:2"> あなたは必ずその町の住民を剣の刃で打ち、町とそこにあるすべてのもの、そしてその家畜を剣の刃で完全に滅ぼせ。</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 49:2; ヨシュア記 8:28; イザヤ書 25:2"> ぶんどり物をすべて広場の中央に集め、町とそのぶんどり物をあなたの神、主のために火で焼き尽くせ。その町は永久に廃墟となり、二度と建て直されてはならない。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 26:4; 申命記 7:26; ヨシュア記 7:26"> 完全に滅ぼされるべきものは、何一つあなたの手についていてはならない。それは、主がその激しい怒りから離れてあなたにあわれみを示し、あなたをあわれみ、あなたの父祖たちに誓われたようにあなたを増やされるためである。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 12:28; マタイ 7:21; 申命記 12:25"> それは、あなたがあなたの神、主の御声に聞き従い、わたしが今日あなたに命じる主のすべての命令を守り、あなたの神、主の目に正しいことを行うからである。</span>
</div>

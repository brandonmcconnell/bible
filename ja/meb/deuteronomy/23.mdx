<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ガラテヤ人への手紙 3:28; イザヤ書 56:3–4; レビ記 21:17–21"> 睾丸が砕かれたり、陰茎が切り取られたりした者は、主の集会に入ってはならない。</span>
<span className="v" id="v2" data-v="2" data-xref="ゼカリヤ書 9:6; イザヤ書 57:3; ヘブル人への手紙 12:8"> 禁じられた結合から生まれた者は主の集会に入ってはならない。十代目に至るまで、その子孫はだれも主の集会に入ってはならない。</span>
<span className="v" id="v3" data-v="3" data-xref="ネヘミヤ記 13:1–2; ネヘミヤ記 13:23; ルツ記 4:6"> アンモン人やモアブ人は主の集会に入ってはならない。十代目に至るまで、彼らのうちの誰も、永遠に主の集会に入ってはならない。</span>
<span className="v" id="v4" data-v="4" data-xref="ネヘミヤ記 13:2; ペテロの第二の手紙 2:15; 列王記第一 18:4"> あなたがたがエジプトから出て来たとき、彼らが道でパンと水をもってあなたがたを出迎えなかったからである。また、彼らがメソポタミアのペトルからベオルの子バラムを雇い、あなたを呪わせようとしたからである。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 7:7–8; ローマ人への手紙 8:31; エペソ人への手紙 2:4–5"> しかし、あなたの神、主はバラムに聞き従おうとはされなかった。あなたの神、主はあなたを愛しておられたので、あなたの神、主はその呪いをあなたへの祝福に変えられた。</span>
<span className="v" id="v6" data-v="6" data-xref="エズラ記 9:12; サムエル記第二 12:31; ネヘミヤ記 13:23–25"> あなたは生涯、永遠に彼らの平安や繁栄を求めてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命記 10:19; 出エジプト記 22:21; 出エジプト記 23:9"> エドム人を忌み嫌ってはならない。彼はあなたの兄弟だからである。エジプト人を忌み嫌ってはならない。あなたは彼の地で寄留者だったからである。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 20:5–6; エペソ人への手紙 2:12–13; 申命記 23:1–3"> 彼らに生まれた三代目の子供たちは、主の集会に入ることができる。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 6:18; 士師記 20:26; ヨハネの黙示録 19:11–14"> あなたが敵との戦いのために宿営に出るときは、あらゆる悪事から身を守れ。</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 15:16; 民数記 5:2–3; コリント人への第一の手紙 5:11–13"> 夜に起こることのために汚れた男がいるなら、その者は宿営の外へ出る。宿営の中に入ってはならない。</span>
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 10:22; エペソ人への手紙 5:26–27; レビ記 14:9"> 夕暮れになったら水で身を洗い、日が沈んでから宿営の中へ戻る。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 宿営の外に用を足す場所を設けよ。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 24:6–8"> 道具の中に小さなへらを持ち、外で用を足すときは、それで穴を掘り、排泄物を覆え。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 17:1; レビ記 26:12; コリント人への第二の手紙 6:16"> あなたの神、主は、あなたを救い出し、敵をあなたの前に引き渡すため、宿営のただ中を歩まれる。それゆえ、宿営を聖く保て。主があなたの中に汚れたものを見て、離れ去ることのないためである。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="サムエル記第一 30:15; オバデヤ書 1:14"> 主人から逃れてあなたのもとに来た奴隷を、その主人に引き渡してはならない。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 22:21; ゼカリヤ書 7:10; エレミヤ書 7:6"> その奴隷は、あなたがたの町の一つ、自分が選ぶ住みよい場所に、あなたとともに住む。彼を虐げてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王記第二 23:7; 列王記第一 14:24; レビ記 19:29"> イスラエルの娘の中に遊女がいてはならない。また、イスラエルの息子の中に男娼がいてはならない。</span>
<span className="v" id="v18" data-v="18" data-xref="ピリピ人への手紙 3:2; マタイ 7:6; ヨハネの黙示録 22:15"> 遊女の稼ぎや犬<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="文字通りには「犬」。">a</a></sup>の代金を、いかなる誓願のためにもあなたの神、主の家に持って来てはならない。これら二つのものは、あなたの神、主にとって忌まわしいものだからである。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 22:25; レビ記 25:35–37; 詩篇 15:5"> あなたの兄弟に利息をとって貸してはならない。金の利息、食べ物の利息、その他利息をとって貸すいかなるものもである。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 15:10; 申命記 15:3; コリント人への第一の手紙 15:58"> 外国人には利息をとって貸してもよいが、あなたの兄弟には利息をとって貸してはならない。それは、あなたが所有するために行く地において、あなたが手をつけるすべてのことにおいて、あなたの神、主があなたを祝福されるためである。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="伝道者の書 5:4–5; 詩篇 66:13–14; 詩篇 116:18"> あなたの神、主に誓願を立てるときは、その支払いを遅らせてはならない。あなたの神、主は必ずそれをあなたに求められ、それはあなたの罪となるからである。</span>
<span className="v" id="v22" data-v="22"> しかし、誓願を立てることを控えるなら、それはあなたの罪にはならない。</span>
<span className="v" id="v23" data-v="23" data-xref="箴言 20:25; 士師記 11:30–31; サムエル記第一 1:11"> 自分の口から出たことを守り行え。あなたの神、主に誓い、自分の口で約束した自発的なささげ物だからである。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="コリント人への第一の手紙 10:26; ローマ人への手紙 12:13; ヘブル人への手紙 13:5"> 隣人のぶどう園に入ったときは、心の望むままにぶどうを飽きるまで食べてもよいが、自分の器に入れてはならない。</span>
<span className="v" id="v25" data-v="25" data-xref="マタイ 12:1–2; マルコ 2:23; ルカ 6:1–2"> 隣人の立ち穂の畑に入ったときは、手で穂を摘んでもよいが、隣人の立ち穂に鎌を入れてはならない。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="レビ記 21:5; ローマ人への手紙 9:8; ガラテヤ人への手紙 3:26"> あなたがたはあなたの神、主の子供である。死者のために自分の身に傷をつけたり、目の間の毛を剃り落としたりしてはならない。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 7:6; レビ記 20:26; 出エジプト記 19:5–6"> あなたはあなたの神、主にとって聖なる民だからである。主は地の面にいるすべての民の中から、ご自身の所有の民とするためにあなたを選ばれた。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 4:14; ローマ人への手紙 14:14; レビ記 20:25"> あなたは忌まわしいものをいっさい食べてはならない。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 11:2–45; 使徒の働き 10:14; 列王記第一 4:23"> あなたがたが食べてもよい動物は次のとおりである。牛、羊、山羊、</span>
<span className="v" id="v5" data-v="5"> 鹿、ガゼル、ノロジカ、野山羊、アイベックス、アンテロープ、シャモアである。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 18:1; コリント人への第二の手紙 6:17; 詩篇 1:1–2"> 動物のうち、ひづめが分かれ、ひづめが完全に二つに割れており、反すうするものはすべて食べてもよい。</span>
<span className="v" id="v7" data-v="7" data-xref="マタイ 7:22–23; テトス 1:16; テモテへの第二の手紙 3:5"> ただし、反すうするもの、あるいは完全にひづめが分かれているもののうち、これらは食べてはならない。らくだ、野うさぎ、うさぎである。これらは反すうするがひづめが分かれていないため、あなたがたには汚れたものである。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 11:26–27; イザヤ書 66:3; ペテロの第二の手紙 2:22"> 豚は、ひづめが分かれているが反すうしないため、あなたがたには汚れたものである。あなたがたはこれらの肉を食べてはならず、その死骸に触れてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="レビ記 11:9–12"> 水の中にいるすべてのもののうち、これらは食べてもよい。ひれとうろこがあるものはすべて食べてもよい。</span>
<span className="v" id="v10" data-v="10"> ひれとうろこがないものはすべて食べてはならない。それはあなたがたには汚れたものである。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> きよい鳥はすべて食べてもよい。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 11:13–19"> しかし、これらは食べてはならない鳥である。鷲、はげわし、黒はげわし、</span>
<span className="v" id="v13" data-v="13"> 赤とび、隼、あらゆる種類のとび、</span>
<span className="v" id="v14" data-v="14"> あらゆる種類のからす、</span>
<span className="v" id="v15" data-v="15" data-xref="ヨブ記 30:29"> だちょう、ふくろう、かもめ、あらゆる種類の鷹、</span>
<span className="v" id="v16" data-v="16"> 小ふくろう、大ふくろう、みみずく、</span>
<span className="v" id="v17" data-v="17"> ペリカン、はげ鷹、鵜、</span>
<span className="v" id="v18" data-v="18"> こうのとり、あらゆる種類のさぎ、やつがしら、こうもりである。</span>
<span className="v" id="v19" data-v="19" data-xref="ピリピ人への手紙 3:19; レビ記 11:20–23"> 羽のある昆虫はすべて、あなたがたには汚れたものである。それらは食べてはならない。</span>
<span className="v" id="v20" data-v="20"> きよい鳥はすべて食べてもよい。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 23:19; 出エジプト記 34:26; レビ記 22:8"> 自然に死んだものは一切食べてはならない。あなたはそれを、あなたの町に住む寄留者に与えて食べさせてもよいし、外国人に売ってもよい。あなたはあなたの神、主にとって聖なる民だからである。<br />子山羊をその母の乳で煮てはならない。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ネヘミヤ記 10:37; 申命記 12:17; 申命記 26:12–15"> あなたは毎年、畑から得られるあなたの種のすべての収穫の十分の一を、必ず取り分けよ。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 12:5–7; 申命記 4:10; 申命記 12:17–18"> あなたはあなたの神、主の前、主がご自分の名を住まわせるために選ばれる場所で、あなたの穀物、新しいぶどう酒、油の十分の一、および牛や羊の群れの初子を食べよ。それは、あなたがあなたの神、主を常に恐れることを学ぶためである。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 12:21; 申命記 12:5; 申命記 11:24"> あなたの神、主があなたを祝福されたとき、もしその道が遠すぎてそれを運ぶことができず、あなたの神、主がご自分の名を置くために選ばれる場所があなたから遠すぎるなら、</span>
<span className="v" id="v25" data-v="25"> あなたはそれを金に換え、その金を手に握って、あなたの神、主が選ばれる場所へ行きなさい。</span>
<span className="v" id="v26" data-v="26" data-xref="伝道者の書 9:7; 申命記 12:7; マタイ 21:12"> その銀で、牛でも羊でも、ぶどう酒でも強い酒でも、あなたが望むものを何でも買い、そこであなたの神、主の前で食べ、家族とともに喜び楽しめ。</span>
<span className="v" id="v27" data-v="27" data-xref="民数記 18:20; 申命記 14:29; 申命記 12:12"> あなたの町に住むレビ人を見捨ててはならない。彼にはあなたとともに持つ割り当ても所有地もないからである。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命記 14:22; アモス書 4:4; 申命記 26:12–15"> 三年の終わりごとに、その年の産物の十分の一をすべて持ち出し、町の中に蓄えておけ。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 15:10; 申命記 14:27; 箴言 19:17"> レビ人はあなたとともに持つ割り当ても所有地もないので、彼と、あなたの町に住む寄留者、孤児、やもめが来て、食べて満ち足りるようにしなさい。そうすれば、あなたの神、主は、あなたの手が行うすべての業においてあなたを祝福される。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 23:4–5; エゼキエル書 34:16; イザヤ書 58:7"> あなたの兄弟の牛や羊が迷い出ているのを見て、それを見ないふりをしてはならない。あなたは必ずそれらをあなたの兄弟のところに連れ戻せ。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 7:12; テサロニケ人への手紙第一 4:6"> 兄弟が近くにおらず、だれのものか分からないなら、自分の家に連れて帰り、兄弟が捜しに来るまで手もとに置き、返せ。</span>
<span className="v" id="v3" data-v="3"> ろばについても、衣服についても、兄弟が失い、あなたが見つけたどのような物についても同じようにせよ。見ないふりをしてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ガラテヤ人への手紙 6:1–2; ヘブル人への手紙 12:12–13; マタイ 5:44"> あなたの兄弟のろばや牛が道で倒れているのを見て、それを見ないふりをしてはならない。あなたは彼がそれらを再び立たせるのを必ず手伝え。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="コリント人への第一の手紙 11:4–15; 申命記 18:12"> 女は男の着物を着てはならず、男は女の着物を着てはならない。これらのことを行う者は皆、あなたの神、主にとって忌まわしいからである。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="レビ記 22:28; 箴言 12:10; 創世記 8:17"> もし道を行くとき、木の上や地面に鳥の巣があり、そこに雛や卵があって、母鳥が雛や卵を抱いているのを見つけたなら、母鳥を雛と一緒に取ってはならない。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 4:40; 箴言 22:4"> あなたは必ず母鳥を逃がせ。しかし、雛は自分のために取ってもよい。それはあなたが幸いを得て、あなたの日々が長く続くためである。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="サムエル記第二 11:2; イザヤ書 22:1; 出エジプト記 21:28–36"> あなたが新しい家を建てるときは、屋上に欄干を作れ。だれかがそこから落ちて、あなたの家に血を流した罪をもたらすことがないためである。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="レビ記 19:19; コリント人への第二の手紙 11:3; マタイ 9:16"> あなたのぶどう園に二種類の種を蒔いてはならない。あなたが蒔いた種とぶどう園の産物、そのすべてが汚されないためである。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="コリント人への第二の手紙 6:14–16"> 牛とろばを一緒に組にして耕してはならない。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="レビ記 19:19"> 羊毛と亜麻布を一緒に混ぜて織った着物を着てはならない。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="マタイ 23:5; 民数記 15:37–41"> あなたが身を覆う上着の四つの裾に、自分のために房<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または、房飾り">a</a></sup>を作れ。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 29:21; 創世記 29:31; エペソ人への手紙 5:28–29"> もしある男が妻をめとり、彼女のところに入って行った後で彼女を憎み、</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 22:19; 箴言 18:21; 箴言 18:8"> 彼女に恥ずべきことを言い立て、彼女に悪評を立てて、「私はこの女をめとったが、彼女に近づいたとき、彼女に処女の証拠を見いだせなかった」と言うなら、</span>
<span className="v" id="v15" data-v="15"> 若い女の父と母は、その若い女の処女の証拠を取り、門にいる町の長老たちのところへ持って行く。</span>
<span className="v" id="v16" data-v="16"> 若い女の父は長老たちに言う。「私は娘をこの男に妻として与えましたが、彼は娘を憎み、</span>
<span className="v" id="v17" data-v="17"> 『あなたの娘に処女の証拠が見つからなかった』と、娘に恥ずべきことを言い立てています。しかし、これが娘の処女の証拠です。」そして両親はその布を町の長老たちの前に広げる。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 18:21"> その町の長老たちはその男を捕らえて彼を懲らしめ、</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 22:29; マタイ 19:8–9; 申命記 24:1–4"> イスラエルの処女に悪評を立てたので、彼から銀百シェケル<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一シェケルは約10グラム、または約0.35オンスであるため、百シェケルは約1キログラム、または2.2ポンドである。">b</a></sup>の罰金を取り、若い女の父に与える。彼女はその男の妻となり、彼は生涯彼女を離縁できない。</span>
<span className="v" id="v20" data-v="20"> しかし、もしこの事が真実であり、若い女に処女の証拠が見いだされなかったなら、</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 13:5; 創世記 34:7; 士師記 20:6"> 若い女を父の家の戸口へ連れ出し、その町の男たちは彼女を石で打ち殺す。彼女は父の家で淫行を働き、イスラエルの中で恥ずべきことをしたからである。こうして、あなたがたの中から悪を取り除け。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="レビ記 20:10; エゼキエル書 23:45–47; ヨハネ 8:4–5"> 男が夫のある女と寝ているところを見つけられたなら、女と寝た男も女も、二人とも死刑に処せられる。こうして、イスラエルから悪を取り除け。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="マタイ 1:18–19; 申命記 20:7"> 夫となる人と婚約している処女の若い女がいて、ある男が町の中で彼女を見つけ、彼女と寝た場合、</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 22:21–22; 申命記 21:14; コリント人への第一の手紙 5:13"> 二人をその町の門へ連れ出し、石で打ち殺せ。若い女は町の中にいながら叫ばなかったからであり、男は隣人の妻を辱めたからである。こうして、あなたがたの中から悪を取り除け。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="サムエル記第二 13:14"> しかし、男が婚約している若い女を野原で見つけ、力ずくで捕らえて寝たなら、その男だけが死刑に処せられる。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 21:22"> 若い女には何もしてはならない。若い女には死刑に値する罪はない。これは、人が隣人に向かって立ち上がり、彼を殺すようなものだからである。</span>
<span className="v" id="v27" data-v="27" data-xref="コリント人への第一の手紙 13:7"> 彼は野原で彼女を見つけ、婚約していた若い女は大声で叫んだが、彼女を救う者はだれもいなかったのである。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 22:16–17"> もし男が婚約していない処女の若い女を見つけ、彼女を捕まえて彼女と寝て、彼らが見つかったなら、</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 22:19; 申命記 22:24; 申命記 21:14"> 彼女と寝た男は、若い女の父に銀五十シェケル<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一シェケルは約10グラム、または約0.35オンスである。">c</a></sup>を与える。彼が彼女を辱めたので、彼女はその男の妻となる。彼は生涯彼女を離縁できない。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="申命記 27:20; コリント人への第一の手紙 5:1; レビ記 18:8"> 男は自分の父の妻をめとってはならず、自分の父の衣の裾をめくってはならない。</span>
</div>

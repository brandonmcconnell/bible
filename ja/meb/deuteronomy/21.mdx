<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 26:21; 詩篇 5:6; 箴言 28:17"> あなたの神、主があなたに与えて所有させてくださる地において、野原に倒れて殺されている者が見つかり、だれが彼を打ち殺したのか分からない場合、</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 13:3–4; 申命記 16:18–19"> 長老たちと裁き人たちは出て行き、殺された者から周囲の町々までの距離を測る。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 19:2; マタイ 11:28–30; エレミヤ書 31:18"> 殺された者に最も近い町の長老たちは、まだ仕事に使われず、くびきを負ったことのない若い雌牛を取る。</span>
<span className="v" id="v4" data-v="4" data-xref="ペテロの手紙第一 2:21–24; ペテロの手紙第一 3:18"> その町の長老たちは、その雌牛を、耕されたことも種を蒔かれたこともない、絶えず水の流れる谷へ引いて行き、そこで首を折る。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代誌上 23:13; マラキ書 2:7; 申命記 10:8"> レビの子らである祭司たちが進み出る。あなたの神、主は彼らを選び、ご自分に仕え、主の御名によって祝福させられた。すべての争いと傷害は、彼らの言葉によって裁定される。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 73:13; 詩篇 26:6; 詩篇 51:7"> 殺された者に最も近い町の長老たちは皆、谷で首を折られた雌牛の上で手を洗い、</span>
<span className="v" id="v7" data-v="7" data-xref="ヨブ記 21:21–23; ヨブ記 21:31–34; サムエル記第二 16:8"> こう宣言する。「私たちの手はこの血を流していません。私たちの目もそれを見ていません。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨナ書 1:14; 列王記第二 24:4; エゼキエル書 23:24–25"> 主よ、あなたが贖い出されたあなたの民イスラエルを赦してください。あなたの民イスラエルのただ中に、罪のない者の血をとどめないでください。」そうすればその血は彼らに赦される。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 19:12–13; 列王記第二 10:30–31; 申命記 13:18"> こうして、主の目に正しいことを行い、あなたがたの中から罪のない者の血を取り除け。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命記 20:10–16; ヨシュア記 21:44"> あなたが敵との戦いに出て行き、あなたの神、主が彼らをあなたの手に引き渡し、あなたが彼らを捕虜として連れ去るとき、</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 31:10; 創世記 34:3; 創世記 12:14–15"> あなたが捕虜の中に美しい女を見て彼女に心を惹かれ、自分の妻にしたいと望むなら、</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 14:9; 民数記 6:9; エペソ人への手紙 4:22"> 彼女を自分の家に連れて帰りなさい。彼女は頭を剃り、爪を切り、</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 45:10–11; ルカ 14:26–27"> 捕虜の衣服を脱いで、あなたの家に住み、丸一か月、父と母のために泣き悲しむ。その後、あなたは彼女のところに入り、夫となり、彼女はあなたの妻となる。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 22:29; 創世記 34:2; 申命記 22:19"> もし彼女を喜ばなくなったなら、望むところへ行かせよ。決して金で売ってはならず、奴隷として扱ってもならない。あなたが彼女を辱めたからである。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 29:33; 創世記 29:20; 創世記 29:18"> もしある男に二人の妻がいて、一人は愛され、もう一人は憎まれており、愛されている妻も憎まれている妻も彼に子供を産み、その長子が憎まれている妻の息子である場合、</span>
<span className="v" id="v16" data-v="16" data-xref="歴代誌上 26:10; 歴代誌上 5:2; 歴代誌 第二 21:3"> 彼が自分の所有するものを息子たちに受け継がせる日に、長子である憎まれている妻の息子を差し置いて、愛されている妻の息子を長子とすることはできない。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 49:3; 創世記 25:31–34; 詩篇 105:36"> 憎まれている妻の息子を長子として認め、全財産から二倍の分け前を与える。彼はその人の力の初めであり、長子の権利は彼のものだからである。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="レビ記 19:3; 出エジプト記 20:12; アモス書 4:11–12"> もしある男に頑固で反抗的な息子がいて、父の声にも母の声にも聞き従わず、彼らが懲らしめても彼らに耳を傾けない場合、</span>
<span className="v" id="v19" data-v="19" data-xref="ゼカリヤ書 13:3; 申命記 21:2; 申命記 16:18"> 父と母は彼を捕らえ、その町の長老たちのもと、その町の門へ連れ出す。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 23:29–35; 箴言 20:1; 箴言 23:19–21"> そして町の長老たちに言う。「私たちのこの息子は頑固で反抗的で、私たちの声に聞き従いません。大食漢で、大酒飲みです。」</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 19:19–20; 申命記 13:10–11; レビ記 24:16"> その町の男たちは皆、彼を石で打ち殺す。こうして、あなたがたの中から悪を取り除け。全イスラエルはこれを聞いて恐れる。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨハネ 19:31–38; 使徒の働き 26:31; ルカ 23:33"> もし人が死刑に値する罪を犯し、彼が死刑に処されてあなたが彼を木にかける場合、</span>
<span className="v" id="v23" data-v="23" data-xref="ガラテヤ人への手紙 3:13; ヨハネ 19:31; コリント人への第二の手紙 5:21"> 死体を夜通し木に残してはならない。その日のうちに必ず葬れ。木にかけられた者は神に呪われた者だからである。あなたの神、主が所有地として与えられる地を汚してはならない。</span>
</div>

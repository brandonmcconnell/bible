<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 1:19; 出エジプト記 23:22; レビ記 26:3–13"> 「もしあなたが、あなたの神、主の御声に熱心に聞き従い、わたしが今日あなたに命じる主のすべての命令を注意して行うなら、あなたの神、主は、あなたを地上のすべての国々の上に高く上げられる。</span>
<span className="v" id="v2" data-v="2" data-xref="ゼカリヤ書 1:6; 申命記 28:15; テモテへの手紙第一 4:8"> あなたがあなたの神、主の御声に聞き従うなら、これらのすべての祝福があなたに臨み、あなたに追いつく。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 144:12–15; 創世記 39:5; ハガイ書 2:19"> あなたは町でも祝福され、野でも祝福される。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 10:22; 創世記 49:25; 申命記 7:13"> あなたの胎の実、あなたの地の産物、あなたの動物の産物、すなわちあなたの牛の群れの増加や、あなたの羊の群れの幼いものは祝福される。</span>
<span className="v" id="v5" data-v="5"> あなたの籠とあなたのこね鉢は祝福される。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 121:8; 民数記 27:17; 歴代誌 第二 1:10"> あなたは入るときにも祝福され、出るときにも祝福される。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="サムエル記第二 22:38–41; レビ記 26:7–8; 詩篇 89:23"> 主は、あなたに立ち向かってくる敵を、あなたの前で打ち負かされる。彼らは一つの道からあなたに向かって攻め寄せて来るが、あなたの前から七つの道に逃げ去る。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 15:10; レビ記 26:10; 箴言 3:9–10"> 主は、あなたの倉と、あなたが手をつけるすべてのことにおいて、あなたに祝福を命じられる。あなたの神、主は、主があなたに与えられる地であなたを祝福される。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 19:5–6; 申命記 7:6; 申命記 26:18–19"> もしあなたが、あなたの神、主の命令を守り、主の道を歩むなら、主があなたに誓われたとおり、主はあなたをご自身の聖なる民として堅く立てられる。</span>
<span className="v" id="v10" data-v="10" data-xref="歴代誌 第二 7:14; 申命記 11:25; エレミヤ書 33:9"> 地上のすべての民は、あなたが主の御名によって呼ばれているのを見て、あなたを恐れるであろう。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 30:9; 箴言 10:22; レビ記 26:9"> 主があなたに与えるとあなたの父祖たちに誓われたその地で、主はあなたの胎の実、あなたの家畜の産物、そしてあなたの地の産物において、あなたを大いに栄えさせられる。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 15:6; ヨエル書 2:23–24; 申命記 15:10"> 主は天にあるその良い宝物倉を開き、季節ごとにあなたの地に雨を与え、あなたの手のすべての働きを祝福される。あなたは多くの国々に貸し与えるが、借りることはない。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 28:1; 申命記 4:6–9; ピリピ人への手紙 1:27"> あなたの神、主はあなたを頭とし、尾とはされない。あなたが、わたしが今日あなたに命じるあなたの神、主の命令に聞き従い、それを注意して行うなら、あなたはただ上になり、下になることはない。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 30:21; 申命記 5:32; 申命記 11:16"> わたしが今日あなたに命じるどの言葉からも、右にも左にもそれてはならず、他の神々に従ってそれに仕えてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="マラキ書 2:2; 申命記 28:2; 申命記 29:20"> しかし、もしあなたが、あなたの神、主の御声に聞き従わず、わたしが今日あなたに命じる主のすべての命令と掟を注意して行わないなら、これらのすべての呪いがあなたに臨み、あなたに追いつく。</span>
<span className="v" id="v16" data-v="16" data-xref="マラキ書 3:9–12; 箴言 3:33; ヨエル書 1:4"> あなたは町でも呪われ、野でも呪われる。</span>
<span className="v" id="v17" data-v="17" data-xref="ハガイ書 1:6; 申命記 28:5; 詩篇 69:22"> あなたの籠とあなたのこね鉢は呪われる。</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 26:26; レビ記 26:19–20; ヨブ記 18:16–19"> あなたの胎の実、あなたの地の産物、あなたの牛の群れの増加、あなたの羊の群れの幼いものは呪われる。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 28:6; 士師記 5:6–7; 歴代誌 第二 15:5"> あなたは入るときにも呪われ、出るときにも呪われる。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 66:15; マラキ書 2:2; 申命記 4:26"> わたしを捨てたあなたの悪行のゆえに、あなたが完全に滅ぼされ、速やかに滅び去るまで、主はあなたが手をつけるすべてのことにおいて、呪い、混乱、懲らしめをあなたに送られる。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 26:25; エレミヤ書 24:10; エレミヤ書 16:4"> あなたが所有するために入って行くその地から、主があなたを絶ち滅ぼされるまで、主は疫病をあなたにまといつかせられる。</span>
<span className="v" id="v22" data-v="22" data-xref="アモス書 4:9; レビ記 26:16; ハガイ書 2:17"> 主は結核、熱病、炎症、激しい熱、剣、立ち枯れ、そして胴枯れ病であなたを打たれる。これらはあなたが滅びるまであなたを追いかける。</span>
<span className="v" id="v23" data-v="23" data-xref="レビ記 26:19; エレミヤ書 14:1–6; 列王記第一 18:2"> あなたの頭上の空は青銅となり、あなたの下にある地は鉄となる。</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 28:12; イザヤ書 5:24; アモス書 4:11"> 主はあなたの地の雨を細かいちりとほこりにされる。あなたが完全に滅ぼされるまで、それは天からあなたの上に降ってくる。</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 30:17; エゼキエル書 23:46; エレミヤ書 24:9"> 主は、あなたが敵の前で打ち破られるようにされる。あなたは一つの道から彼らに向かって出て行き、七つの道に分かれて逃げる。あなたは地のすべての王国の恐怖の的となる。</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 34:20; エレミヤ書 16:4; エレミヤ書 7:33"> あなたの死体は空のすべての鳥と地の動物の食べ物となる。それらを追い払う者はだれもいない。</span>
<span className="v" id="v27" data-v="27" data-xref="サムエル記第一 5:6; 申命記 28:35; レビ記 21:20"> 主は、あなたが癒やされることのできない、エジプトの腫れ物、腫瘍、壊血病、そしてかゆみであなたを打たれる。</span>
<span className="v" id="v28" data-v="28" data-xref="テサロニケ人への第二の手紙 2:9–11; イザヤ書 19:11–17; イザヤ書 6:9–10"> 主は狂気、失明、そして心の混乱であなたを打たれる。</span>
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 59:10; ヨブ記 5:14; 士師記 6:1–6"> 目の見えない者が暗闇の中で手探りするように、あなたは真昼に手探りする。あなたは自分の道で栄えることはない。あなたは常にしいたげられ、奪われるだけであり、あなたを救う者はだれもいない。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="アモス書 5:11; エレミヤ書 8:10; ヨブ記 31:10"> あなたが妻を婚約しても、別の男が彼女と寝る。あなたが家を建てても、そこに住むことはない。あなたがぶどう園を植えても、その実を使うことはない。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨブ記 1:14–15; 士師記 6:1"> あなたの牛はあなたの目の前で屠られるが、あなたはそれを食べない。あなたのろばはあなたの目の前から力ずくで奪われ、あなたに返されることはない。あなたの羊は敵に与えられ、あなたを救う者はだれもいない。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨエル書 3:6; 申命記 28:41; ヨブ記 17:5"> あなたの息子たちと娘たちは他の民に与えられる。あなたの目は一日中彼らを慕って見つめ、衰え果てるが、あなたの手には何の力もない。</span>
<span className="v" id="v33" data-v="33" data-xref="エレミヤ書 5:17; 申命記 28:29–30; イザヤ書 1:7"> あなたの知らなかった国が、あなたの地の産物とあなたのすべての労苦の実を食べる。あなたは常にしいたげられ、打ち砕かれるだけである。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネの黙示録 16:10–11; 申命記 28:68; イザヤ書 33:14"> あなたは、自分の目が見る光景のゆえに、狂気に追いやられる。</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 28:27; イザヤ書 3:24; イザヤ書 3:17"> 主はあなたの膝と足を、足の裏から頭の頂に至るまで、あなたが癒やされることのできないひどい腫れ物で打たれる。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="エレミヤ書 16:13; 申命記 4:28; 列王記第二 25:11"> 主はあなたと、あなたが自分の上に立てた王とを、あなたもあなたの父祖たちも知らなかった国へ連れて行かれる。そこであなたは、木や石の他の神々に仕えることになる。</span>
<span className="v" id="v37" data-v="37" data-xref="エレミヤ書 25:9; 列王記第一 9:7–8; エレミヤ書 24:9"> 主があなたを連れ去られるすべての民の中で、あなたは驚きとなり、ことわざとなり、笑いぐさとなる。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="ハガイ書 1:6; ミカ書 6:15; ヨエル書 1:4"> あなたは畑に多くの種を持って出て行くが、わずかしか取り入れない。いなごがそれを食い尽くすからである。</span>
<span className="v" id="v39" data-v="39" data-xref="イザヤ書 17:10–11; ヨエル書 2:2–4; ヨナ書 4:7"> あなたはぶどう園を植えて手入れをするが、そのぶどう酒を飲むことも、集めることもない。虫がそれを食べるからである。</span>
<span className="v" id="v40" data-v="40" data-xref="ミカ書 6:15; 詩篇 23:5; 詩篇 104:15"> あなたのすべての境界内にオリーブの木があるようになるが、あなたは油を体に塗ることはない。あなたのオリーブは落ちてしまうからである。</span>
<span className="v" id="v41" data-v="41" data-xref="申命記 28:32; 哀歌 1:5; 列王記第二 24:14"> あなたは息子や娘をもうけるが、彼らはあなたのものとはならない。彼らは捕虜として連れ去られるからである。</span>
<span className="v" id="v42" data-v="42" data-xref="アモス書 7:1–2; 申命記 28:38–39"> あなたのすべての木と地の産物は、いなごが所有する。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="申命記 28:13; サムエル記第一 13:19–23; 列王記第二 17:20"> あなたの間にいる寄留者は、あなたの上にますます高く上り、あなたはますます低く下る。</span>
<span className="v" id="v44" data-v="44" data-xref="申命記 28:12–13; 哀歌 1:5"> 彼はあなたに貸し与えるが、あなたは彼に貸し与えることはない。彼は頭となり、あなたは尾となる。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="申命記 28:15; イザヤ書 1:20; エレミヤ書 24:9–10"> あなたがあなたの神、主の御声に聞き従わず、主があなたに命じられた命令と掟を守らなかったため、これらのすべての呪いがあなたに臨み、あなたを追いかけ、あなたに追いつき、ついにあなたは完全に滅ぼされる。</span>
<span className="v" id="v46" data-v="46" data-xref="イザヤ書 8:18; 申命記 28:37; エゼキエル書 14:8"> これらはあなたとあなたの子孫に対して、永遠にしるしとなり、不思議となる。</span>
<span className="v" id="v47" data-v="47" data-xref="申命記 16:11; 申命記 12:7–12; ネヘミヤ記 9:35–37"> すべてのものが豊かであったのに、あなたが喜びと心からの喜びをもってあなたの神、主に仕えなかったため、</span>
<span className="v" id="v48" data-v="48" data-xref="エレミヤ書 28:13–14; 哀歌 5:2–6; エゼキエル書 4:16–17"> あなたは、主があなたに差し向けられる敵に、飢え、渇き、裸、そしてすべてのものに欠乏する中で仕えることになる。主はあなたが完全に滅ぼされるまで、あなたの首に鉄のくびきを置かれる。</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="哀歌 4:19; エレミヤ書 49:22; エレミヤ書 48:40"> 主は遠くから、地の果てから、鷲が飛ぶように一つの国をあなたに差し向けられる。それはあなたが言葉を理解できない国であり、</span>
<span className="v" id="v50" data-v="50" data-xref="イザヤ書 47:6; 歴代誌 第二 36:17; ルカ 21:23–24"> その国民は険しい顔つきで、老人を敬わず、若者をあわれまない。</span>
<span className="v" id="v51" data-v="51" data-xref="申命記 28:33; イザヤ書 62:8; レビ記 26:26"> 彼らは、あなたが完全に滅ぼされるまで、あなたの家畜の産物と、あなたの地の産物を食べる。また、彼らがあなたを滅ぼすまで、穀物、新しいぶどう酒、油、あなたの牛の群れの増加、羊の群れの幼いものをあなたに残さない。</span>
<span className="v" id="v52" data-v="52" data-xref="エレミヤ書 52:4–7; エゼキエル書 4:1–8; マタイ 24:15–16"> 彼らはあなたのすべての門であなたを包囲し、ついにあなたの全土において、あなたが頼みとしていた高く堅固な城壁は崩れ落ちる。彼らはあなたの神、主があなたに与えられた全土のすべての門であなたを包囲する。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="哀歌 4:10; エレミヤ書 19:9; レビ記 26:29"> 敵があなたを苦しめる包囲と苦難の中で、あなたは自分の胎の実、すなわちあなたの神、主があなたに与えられたあなたの息子たちや娘たちの肉を食べる。</span>
<span className="v" id="v54" data-v="54" data-xref="申命記 15:9; マタイ 20:15; 申命記 13:6"> あなたがたの中で優しく、非常に上品な男でさえ、その目は自分の兄弟、自分の愛する妻、そして残された子供たちに対して悪意を抱く。</span>
<span className="v" id="v55" data-v="55" data-xref="エレミヤ書 34:2; エレミヤ書 52:6; エレミヤ書 5:10"> 敵があなたのすべての門であなたを苦しめる包囲と苦難の中で、彼には何も残されていないため、自分が食べる子供の肉をそのだれにも与えようとはしない。</span>
<span className="v" id="v56" data-v="56" data-xref="申命記 28:54; イザヤ書 3:16; 哀歌 4:3–6"> あなたがたの中で上品で優しく、上品さと優しさのゆえに足の裏を地面につけようともしなかった女でさえ、その目は自分の愛する夫、自分の息子、自分の娘、</span>
<span className="v" id="v57" data-v="57" data-xref="イザヤ書 49:15; 創世記 49:10"> 自分の足の間から出る幼子、および自分が産む子供たちに対して悪意を抱く。敵があなたの門であなたを苦しめる包囲と苦難の中で、すべてのものが欠乏しているため、彼女は彼らをひそかに食べるのである。</span>
</div>
<div className="bp">
<span className="v" id="v58" data-v="58" data-xref="イザヤ書 42:8; エレミヤ書 7:9–10; マラキ書 1:14"> もしあなたが、この輝かしく恐るべき御名、すなわちあなたの神、主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="すべて大文字の「主」または「神」はヘブル語のיהוה（ヤハウェ）から来ている。ただし、短い形のיה（ヤハ）から来ていると記されている場合を除く。">a</a></sup>を恐れるために、この書物に書き記されているこの律法のすべての言葉を注意して行わないなら、</span>
<span className="v" id="v59" data-v="59" data-xref="マルコ 13:19; 申命記 28:46; ダニエル書 9:12"> 主はあなたの疫病とあなたの子孫の疫病を驚くべきものとされる。それは大いなる疫病で長く続き、重い病気で長く続くものである。</span>
<span className="v" id="v60" data-v="60" data-xref="申命記 7:15; 出エジプト記 15:26; 申命記 28:27"> 主はあなたが恐れていたエジプトのすべての病気を再びあなたにもたらし、それらはあなたにまといつく。</span>
<span className="v" id="v61" data-v="61" data-xref="申命記 4:25–26"> また、この律法の書に書き記されていないあらゆる病気やあらゆる疫病も、あなたが完全に滅ぼされるまで主はあなたに下される。</span>
<span className="v" id="v62" data-v="62" data-xref="申命記 10:22; ネヘミヤ記 9:23; 申命記 4:27"> あなたがたは空の星のように数が多かったが、あなたがたの神、主の御声に聞き従わなかったため、わずかな人数しか残されない。</span>
<span className="v" id="v63" data-v="63" data-xref="箴言 1:26; エレミヤ書 32:41; 申命記 30:9"> 主があなたがたに良いことを行い、あなたがたを増やすことを喜ばれたように、主はあなたがたを滅ぼし、あなたがたを断ち滅ぼすことを喜ばれる。あなたがたは、所有するために入って行くその地から引き抜かれる。</span>

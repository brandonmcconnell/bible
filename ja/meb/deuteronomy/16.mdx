<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 34:18; 出エジプト記 12:2–20; 出エジプト記 13:4"> アビブの月を守り、あなたの神、主に過越の祭りを守りなさい。アビブの月に、あなたの神、主が夜、あなたをエジプトから導き出されたからである。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 12:5; 申命記 12:26; ルカ 22:15"> あなたは、主がご自分の名を住まわせるために選ばれる場所で、羊と牛の群れから、あなたの神、主に過越のいけにえをささげよ。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 12:39; 出エジプト記 34:18; 出エジプト記 12:19–20"> あなたはそれにパン種を入れたパンを添えて食べてはならない。七日間、それに種なしパン、すなわち苦悩のパンを添えて食べよ。あなたがエジプトの地から急いで出て来たからである。それは、あなたがエジプトの地から出て来た日を、あなたの生涯のすべての日の間思い起こすためである。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 34:25; 出エジプト記 12:10; 出エジプト記 13:7"> 七日間、あなたのすべての領土内でパン種が見られてはならない。また、あなたが最初の日の夕方にささげたいけにえの肉のいっさいを、朝まで夜通し残しておいてはならない。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 16:2; 申命記 12:5–6"> あなたは、あなたの神、主があなたに与えられるどの門のうちでも、過越のいけにえをささげることはできない。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 12:5; 出エジプト記 12:6–9; 民数記 9:11"> しかし、あなたの神、主がご自分の名を住まわせるために選ばれるその場所で、夕方、日の沈むころ、あなたがエジプトから出て来たその時期に、過越のいけにえをささげよ。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌 第二 35:13; 出エジプト記 12:8–9; ヨハネ 2:23"> あなたは、あなたの神、主が選ばれる場所でそれを焼いて食べなさい。そして朝になったら、向きを変えてあなたの天幕へ帰りなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 13:6–8; レビ記 23:6–8; レビ記 23:36"> 六日間は種なしパンを食べよ。七日目はあなたの神、主への厳かな集会である。いかなる仕事もしてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 34:22; 出エジプト記 23:16; 使徒の働き 2:1"> あなたは七週間を数えなさい。立ち穂に鎌を入れ始める時から七週間を数え始めなさい。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 16:2; レビ記 12:8; マラキ書 3:10–11"> そして、あなたの神、主があなたを祝福されるのに従って、あなたが自ら手でささげる自発的なささげ物の貢ぎ物をもって、あなたの神、主に七週の祭りを守りなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 12:7; 申命記 12:12; 申命記 12:18"> あなたはあなたの神、主の前で喜び楽しみなさい。あなたも、あなたの息子、娘、男奴隷、女奴隷、あなたの町に住むレビ人、そしてあなたのただ中にいる寄留者、孤児、やもめも、あなたの神、主がご自分の名を住まわせるために選ばれるその場所で喜び楽しみなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 15:15; 哀歌 3:19–20; ローマ人への手紙 6:17–18"> あなたはエジプトで奴隷であったことを思い起こしなさい。あなたはこれらの掟を注意して行え。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 23:16; ヨハネ 7:2; 歴代誌 第二 5:3"> あなたが自分の打ち場とぶどう搾り場から取り入れた後、七日間にわたって仮庵の祭りを守れ。</span>
<span className="v" id="v14" data-v="14" data-xref="ネヘミヤ記 8:9–12; 申命記 16:11; イザヤ書 30:29"> あなたの祭りに際して、あなたも、あなたの息子、娘、男奴隷、女奴隷、レビ人、そしてあなたの町に住む寄留者、孤児、やもめも喜び楽しみなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="レビ記 23:36–42; 申命記 30:16; 申命記 16:10"> 七日間、あなたの神、主が選ばれる場所で、あなたの神、主に祭りを守りなさい。あなたの神、主があなたのすべての収穫と、あなたの手のすべての業を祝福されるので、あなたはひたすら喜び楽しみなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 3:9–10; 詩篇 96:8; ハガイ書 1:9"> 一年に三度、すべての男子は、あなたの神、主が選ばれる場所で主の前に出る。種なしパンの祭り、七週の祭り、仮庵の祭りの時である。空手で主の前に出てはならない。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第二の手紙 9:6–7; コリント人への第二の手紙 8:12; 申命記 16:10"> それぞれ、あなたの神、主から受けた祝福に応じ、自分の力にかなうささげ物を携えよ。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歴代誌上 23:4; 出エジプト記 18:25–26; ローマ人への手紙 13:1–6"> あなたの神、主が与えられるすべての町に、部族ごとに裁き人と役人を立てよ。彼らは義をもって民を裁く。</span>
<span className="v" id="v19" data-v="19" data-xref="レビ記 19:15; 出エジプト記 23:2; 箴言 17:23"> あなたは裁きを曲げてはならない。人をえこひいきしてはならない。賄賂を受け取ってはならない。賄賂は知恵のある者の目をくらませ、正しい者の言葉をゆがめるからである。</span>
<span className="v" id="v20" data-v="20" data-xref="ピリピ人への手紙 4:8; エゼキエル書 18:9; エゼキエル書 18:5"> ただ正義だけを追い求めよ。そうすれば、あなたは生き、あなたの神、主が与えられる地を受け継ぐことができる。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="歴代誌 第二 33:3; 列王記第二 17:16; 出エジプト記 34:13"> あなたが自分のために造るあなたの神、主の祭壇のそばに、どんな木であれアシェラを植えてはならない。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 26:1; 出エジプト記 20:4; ゼカリヤ書 8:17"> あなたの神、主が憎まれる聖なる石柱を立ててもならない。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="エゼキエル書 40:2; 申命記 32:49; ヨシュア記 19:47"> モーセはモアブの平野からネボ山、すなわちエリコの向かいにあるピスガの頂に登った。主は彼に、ダンに至る全ギルアデ、</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 11:24; 民数記 34:6; 出エジプト記 23:31"> 全ナフタリ、エフライムとマナセの地、西の海に至るユダの全土、</span>
<span className="v" id="v3" data-v="3" data-xref="歴代誌 第二 28:15; 士師記 1:16; 士師記 3:13"> 南<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または、ネゲブ。">a</a></sup>、およびツォアルに至るやしの木の町エリコの谷の平野をお見せになった。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 32:52; 創世記 12:7; 創世記 28:13"> 主は彼に言われた。「これが、わたしがアブラハム、イサク、ヤコブに誓って、『わたしはこれをあなたの子孫に与える』と言った地である。わたしはあなたの目でそれを見させたが、あなたはそこに渡って行くことはない。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="申命記 32:50; ヨシュア記 1:1–2; ヘブル人への手紙 3:3–6"> こうして主のしもべモーセは、主の言葉のとおりにモアブの地で死んだ。</span>
<span className="v" id="v6" data-v="6" data-xref="ユダ 1:9; 申命記 3:29"> 主は彼をベテ・ペオルの向かいのモアブの地の谷に葬られたが、今日に至るまでだれも彼の墓を知らない。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 31:2; ヨシュア記 14:10–11; 創世記 27:1"> モーセは死んだ時、百二十歳であった。その目はかすまず、力も衰えていなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 50:3; 民数記 20:29; 創世記 50:10"> イスラエルの子らはモアブの平野で三十日間、モーセのために泣き悲しんだ。こうしてモーセのために泣き悲しむ喪の日々は終わった。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 11:2; ダニエル書 6:3; 使徒の働き 6:6"> ヌンの子ヨシュアは知恵の霊に満たされていた。モーセが彼の上に手を置いていたからである。イスラエルの子らは彼に聞き従い、主がモーセに命じられたとおりに行った。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 33:11; 民数記 12:6–8; 申命記 18:15–18"> それ以来、イスラエルにはモーセのような預言者は起こらなかった。主は顔と顔を合わせて彼を知られ、</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 7:19; 申命記 4:34; 詩篇 105:26–38"> 主が彼を遣わして、エジプトの地でファラオとそのすべての家来たち、およびその全土に行わせたすべてのしるしと不思議において、</span>
<span className="v" id="v12" data-v="12"> また、モーセが全イスラエルの目の前で行った、あのすべての力強い御手と、あのすべての恐るべき大いなるわざにおいて、彼に並ぶ者はいなかった。</span>

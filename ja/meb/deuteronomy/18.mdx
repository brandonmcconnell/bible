<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 18:8–9; 申命記 10:9; コリント人への第一の手紙 9:13–14"> レビ人の祭司たち、すなわちレビの全部族は、イスラエルとともに持つ割り当ても所有地もない。彼らは主への火によるささげ物と、主の分を食べる。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 1:5–6; 詩篇 84:11; ペテロの手紙第一 2:5"> 彼らは兄弟たちの中で所有地を持たない。主が彼らに語られたとおり、主が彼らの所有地である。</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 7:30–34; 申命記 12:27"> 牛であれ羊であれ、いけにえを献げる民から祭司が受ける分は、肩、両頬、胃袋である。</span>
<span className="v" id="v4" data-v="4" data-xref="ネヘミヤ記 12:44–47; 民数記 18:12–24; 歴代誌 第二 31:4–10"> あなたの穀物、新しいぶどう酒、油の初穂と、あなたの羊の最初の羊毛を彼に与えよ。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 10:8; 民数記 3:10; 出エジプト記 28:1–14"> あなたの神、主があなたのすべての部族の中から彼を選び、彼とその息子たちが永遠に主の御名によって立って仕えるようにされたからである。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数記 35:2–3; 申命記 12:5; 申命記 16:2"> 一人のレビ人が、全イスラエルのどこであれ自分の住む町から、心から望んで主の選ばれる場所へ来るなら、</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌 第二 31:2–4"> 彼はそこに主の前に立っているすべての彼の兄弟であるレビ人と同じように、彼の神、主の御名によって仕えることができる。</span>
<span className="v" id="v8" data-v="8" data-xref="ネヘミヤ記 12:44; ネヘミヤ記 12:47; 歴代誌 第二 31:4"> 彼は家族の財産を売って得たものとは別に、ほかのレビ人と同じ分を食べる。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命記 12:29–31; レビ記 18:26–27; レビ記 18:30"> あなたの神、主があなたに与えられる地に入ったとき、あなたはそれらの国々の忌まわしいことに従って行うことを学んではならない。</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 19:31; 出エジプト記 22:18; レビ記 19:26"> あなたがたの中に、自分の息子や娘に火の中を通らせる者、占いをする者、魔術を行う者、まじない師、呪術者、</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 19:31; サムエル記第一 28:11–14"> 呪文を唱える者、霊媒師に相談する者、魔法使い、死者に伺いを立てる者がいてはならない。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 18:24; 申命記 9:4; レビ記 18:27"> これらのことを行う者は皆、主にとって忌まわしいからである。これらの忌まわしいことのゆえに、あなたの神、主はあなたの前から彼らを追い出されるのである。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイ 5:48; 創世記 17:1; 創世記 6:9"> あなたの神、主にひたすら従え。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 14:16; 申命記 18:10; 創世記 20:6"> あなたが追い出すこれらの国々は、魔術を行う者や占い師に聞き従うが、あなたについては、あなたの神、主はあなたがそのようにすることを許されなかった。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 3:22–23; 使徒の働き 7:37; ヨハネ 1:45"> あなたの神、主は、あなたのただ中、兄弟たちの中から、わたしのような預言者をあなたのために起こされる。彼に聞き従え。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 20:19; 申命記 5:23–28; 申命記 9:10"> これは、集まりの日にホレブで、あなたがあなたの神、主に求めたすべてのことに従っている。あなたは言った。「私の神、主の御声を二度と聞かせないでください。また、私が死なないために、この大いなる火を二度と見せないでください。」</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 5:28"> すると主はわたしに言われた。「彼らが語ったことはもっともである。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 18:15; ヨハネ 8:28; ヨハネ 12:49–50"> わたしは彼らの兄弟たちの中から、あなたのような一人の預言者を彼らのために起こす。わたしは彼の口にわたしの言葉を置き、彼はわたしが命じるすべてのことを彼らに語る。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 3:22–23; ヘブル人への手紙 2:3; ヘブル人への手紙 10:26"> わたしがわたしの名によって語るわたしの言葉に聞き従わない者があれば、わたし自身が彼に責任を問う。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 13:1–5; エレミヤ書 27:15; エレミヤ書 23:13–15"> しかし、わたしが命じていない言葉をわたしの名によって不遜に語る預言者、またはほかの神々の名によって語る預言者は死刑に処せられる。」</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの手紙第一 4:1–3; テサロニケ人への手紙第一 5:24; ヨハネの黙示録 2:2"> あなたは心の中で、「主が語られなかった言葉を、私たちはどのようにして知ることができるだろうか」と言うかもしれない。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 18:20; 列王記第二 20:1; エレミヤ書 28:1–17"> 預言者が主の御名によって語っても、そのことが起こらず、実現しないなら、それは主が語られなかった言葉である。その預言者は不遜にもそれを語ったのである。あなたは彼を恐れてはならない。</span>

<span className="v" id="v1" data-v="1" data-xref="出エジプト記 34:1–2; 出エジプト記 25:10–15; 申命記 10:3–4"> その時、主はわたしに言われた。「最初のような二枚の石の板を切り出し、山に登ってわたしのところに来なさい。また、木で箱を作りなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="列王記第一 8:9; 申命記 10:5; 申命記 4:13"> あなたが砕いた最初の板にあった言葉を、わたしはその板に書き記す。あなたはそれを箱の中に納めなさい。」</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 34:4; 出エジプト記 37:1–9; 出エジプト記 25:10"> そこでわたしはアカシアの木で箱を作り、最初のような二枚の石の板を切り出し、その二枚の板を手に持って山に登った。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 9:10; 出エジプト記 34:28; ヘブル人への手紙 12:18–19"> 主は最初の書き記しと同じように、集まりの日に山で火のただ中から主があなたがたに語られた十戒を、その板に書き記された。そして主はそれをわたしに与えられた。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 34:29; 出エジプト記 40:20; 申命記 10:2"> わたしは向きを変えて山から下り、わたしが作った箱の中にその板を納めた。主がわたしに命じられたように、それはそこにある。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数記 33:38; 民数記 20:23–28; 民数記 33:30–33"> （イスラエルの子らはベエロト・ベネ・ヤアカンからモセラへ旅立った。アロンはそこで死に、そこに葬られた。彼の子エルアザルが彼に代わって祭司の務めを果たした。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 33:32–34"> そこから彼らはグドゴダへ旅立ち、グドゴダから水路の地であるヨトバタへ旅立った。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 21:5; 申命記 18:5; 民数記 6:23–26"> その時、主は主の契約の箱を担ぎ、主の前に立って主に仕え、主の御名によって祝福するために、レビの部族をえり分けられた。それは今日に至っている。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 44:28; 民数記 18:20–24; 申命記 18:1–2"> それゆえ、レビには彼の兄弟たちとともに持つ割り当ても所有地もない。あなたの神、主が彼に語られたとおり、主が彼の所有地である。）</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命記 9:18–19; 申命記 9:25; 出エジプト記 34:28"> わたしは最初の時と同じように、四十日四十夜、山にとどまった。主はその時もわたしの願いを聞き入れられた。主はあなたを滅ぼすことはされなかった。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 33:1; 出エジプト記 32:34"> 主はわたしに言われた。「立ち上がり、民の先頭に立って旅立ちなさい。彼らが入って行き、わたしが彼らの父祖たちに与えると誓ったその地を所有するためである。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ミカ書 6:8; 申命記 6:5; ルカ 10:27"> 今、イスラエルよ。あなたの神、主があなたに求めておられることは何か。ただ、あなたの神、主を恐れ、そのすべての道を歩み、主を愛し、心を尽くし、魂を尽くして、あなたの神、主に仕えること、</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 32:39; 申命記 6:24; ヤコブの手紙 1:25"> あなたの幸せのために、わたしが今日あなたに命じる主の命令と掟を守ることではないか。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 19:5; 詩篇 24:1; 詩篇 115:16"> 見よ、天と天の天、地とそこにあるすべてのものは、あなたの神、主のものである。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 4:37; 申命記 7:7–8; ローマ人への手紙 9:13–23"> ただ主はあなたの父祖たちを喜んで愛された。そして今日あるように、すべての民に勝って彼らの後の子孫、すなわちあなたがたを選ばれた。</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 4:4; 申命記 30:6; レビ記 26:41"> 心の包皮に割礼を施せ。もう、うなじを固くしてはならない。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 10:34; ローマ人への手紙 2:11; ダニエル書 2:47"> あなたがたの神、主は神々の神、主の主であり、人をえこひいきせず、賄賂を受け取らない、大いなる、力強い、恐るべき神だからである。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 146:9; 詩篇 68:5; エレミヤ書 49:11"> 主は孤児ややもめのために裁きを行い、寄留者を愛して彼に食べ物と着物を与えられる。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 22:21; レビ記 19:33–34; ルカ 17:18"> それゆえ、寄留者を愛しなさい。あなたがたもエジプトの地で寄留者であったからである。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 6:13; 申命記 13:4; ルカ 4:8"> あなたの神、主を恐れ、主に仕え、主にすがり、主の御名によって誓え。</span>
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 17:14; 詩篇 106:21–22; 出エジプト記 15:2"> 主はあなたの賛美であり、あなたの目が見たこれらの大いなる恐るべきことをあなたのために行われた、あなたの神である。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 46:27; 出エジプト記 1:5; 創世記 15:5"> あなたの父祖たちは七十人でエジプトに下ったが、今やあなたの神、主は、あなたを天の星のように多くされた。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 4:1; マタイ 23:3; 申命記 29:10"> モーセは全イスラエルを呼び寄せて言った。「イスラエルよ、わたしが今日あなたがたの耳に語る掟と法を聞きなさい。あなたがたはそれらを学び、注意して行いなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 4:23; 出エジプト記 19:5–8; 出エジプト記 24:8"> わたしたちの神、主はホレブでわたしたちと契約を結ばれた。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 29:10–15; 創世記 17:21; 創世記 17:7"> 主はこの契約をわたしたちの父祖たちと結ばれたのではなく、わたしたち、すなわち今日ここに生きているわたしたち全員と結ばれたのである。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 19:18–19; 申命記 34:10; 出エジプト記 19:9"> 主は山の上で、火のただ中から顔と顔を合わせてあなたがたと語られた。</span>
<span className="v" id="v5" data-v="5" data-xref="ガラテヤ人への手紙 3:19; 出エジプト記 19:16; 出エジプト記 20:18–21"> （その時、わたしは主とあなたがたの間に立って、主の言葉をあなたがたに告げ知らせた。あなたがたは火のゆえに恐れて、山に登らなかったからである。）主は言われた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 20:2–17; 詩篇 81:5–10; レビ記 26:1–2"> 『わたしはあなたの神、主であり、あなたをエジプトの地から、奴隷の家から導き出した。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 20:3; マタイ 4:10; ヨハネの手紙第一 5:21"> 『あなたには、わたしのほかに他の神々があってはならない。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 20:4; 申命記 4:15–19"> 『自分のために彫像を造ってはならない。上は天にあるもの、下は地にあるもの、地の下の水の中にあるものの、いかなる似姿も造ってはならない。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 20:4–6; 出エジプト記 34:7; ダニエル書 9:4–9"> それらを拝んではならず、それらに仕えてはならない。あなたの神、主であるわたしはねたむ神であり、わたしを憎む者には父の咎を子供たち、さらに三代、四代にまで報いるが、</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 8:28; ヨハネの手紙第一 1:7; エレミヤ書 32:18"> わたしを愛し、わたしの命令を守る者には、幾千代にまで恵みを示すからである。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 20:7; レビ記 19:12; 申命記 6:13"> 『あなたの神、主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="すべて大文字の「主」または「神」はヘブル語のיהוה（ヤハウェ）から来ている。ただし、短い形のיה（ヤハ）から来ていると記されている場合を除く。">a</a></sup>の御名をみだりに用いてはならない。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または、あなたの神、主の御名をむなしく取り上げてはならない。">b</a></sup>主は、ご自分の御名をみだりに用いる者を罰せずにはおかれないからである。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 20:8–11; イザヤ書 58:13; イザヤ書 56:6"> 『あなたの神、主が命じられたように、安息日を守り、それを聖なる日としなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 20:12; ルカ 13:14–16; 出エジプト記 23:12"> 六日間働き、あなたのすべての仕事をせよ。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 4:4; 創世記 2:2; 出エジプト記 23:12"> しかし七日目はあなたの神、主の安息日である。その日にはいかなる仕事もしてはならない。あなたも、息子も、娘も、男奴隷も、女奴隷も、牛も、ろばも、いかなる家畜も、あなたの町に住む寄留者も同様である。それは、あなたの男奴隷も女奴隷も、あなたと同じように休むためである。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 5:6; 申命記 15:15; 申命記 16:12"> あなたはエジプトの地で奴隷であったこと、そしてあなたの神、主が力強い御手と伸ばされた腕によって、そこからあなたを導き出されたことを思い起こせ。それゆえ、あなたの神、主は安息日を守るようにあなたに命じられたのである。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 20:12; エペソ人への手紙 6:1–3; コロサイ人への手紙 3:20"> 『あなたの神、主が命じられたように、あなたの父と母を敬いなさい。それはあなたの日々が長く続き、あなたの神、主があなたに与えられる地で、あなたが幸いを得るためである。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 20:13; ローマ人への手紙 13:9; マタイ 5:21–22"> 『殺人を犯してはならない。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 20:14; ルカ 18:20; レビ記 20:10"> 『姦淫してはならない。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 20:15; ローマ人への手紙 13:9; エペソ人への手紙 4:28"> 『盗んではならない。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 20:16; 出エジプト記 23:1; 箴言 19:9"> 『隣人に対して偽りの証言をしてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 20:17; ローマ人への手紙 13:9; ルカ 12:15"> 『隣人の妻をむさぼってはならない。隣人の家、畑、男奴隷、女奴隷、牛、ろば、また隣人のいかなるものも欲しがってはならない。』</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 24:12; 出エジプト記 31:18; 申命記 4:12–15"> これらの言葉を、主は山で、火と雲と濃い暗闇のただ中から、大いなる御声であなたがたの全集会に語られ、それ以上は付け加えられなかった。主はそれを二枚の石の板に書き記し、わたしに与えられた。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 20:18–19; ヘブル人への手紙 12:18–21"> 山が火で燃え上がっている中、あなたがたが暗闇のただ中から御声を聞いたとき、あなたがたの部族のすべての頭たち、および長老たちは皆、わたしのところに近づいて来て、</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 4:33; 出エジプト記 19:19; 出エジプト記 33:20"> あなたがたは言った。「見よ、私たちの神、主は、ご自分の栄光と偉大さを私たちに示されました。私たちは火の中から御声を聞きました。今日、神が人に語られても、人が生きていられることを知りました。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 18:16; ガラテヤ人への手紙 3:10; コリント人への第二の手紙 3:7–9"> しかし今、どうして私たちは死ななければならないのでしょう。この大いなる火は私たちを焼き尽くします。これ以上、私たちの神、主の御声を聞けば、私たちは死んでしまいます。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 4:33; ローマ人への手紙 3:20; マタイ 26:63"> 生ける神が火のただ中から語られる御声を聞いて、わたしたちのように生きている肉なる者が、ほかにだれかいるでしょうか。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 20:19; ヘブル人への手紙 12:19"> あなたが近づいて、わたしたちの神、主が言われるすべてのことを聞いてください。そして、わたしたちの神、主があなたに語られるすべてのことをわたしたちに告げてください。わたしたちはそれを聞いて、実行します。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命記 18:17; 民数記 36:5; 民数記 27:7"> あなたがたがわたしに語ったとき、主はあなたがたの語った言葉を聞かれ、主はわたしに言われた。「この民があなたに語った語った言葉を聞いた。彼らが語ったことはすべて正しい。</span>
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 48:18; エゼキエル書 33:31–32; 申命記 11:1"> 彼らにこのような心があって、常にわたしを恐れ、わたしのすべての命令を守るなら、彼らもその子供たちも永遠に幸いを得るであろうに。</span>
<span className="v" id="v30" data-v="30"> 行って彼らに、『自分の天幕に帰りなさい』と言いなさい。</span>
<span className="v" id="v31" data-v="31" data-xref="ガラテヤ人への手紙 3:19; エゼキエル書 20:11; 申命記 5:1"> しかしあなたはここに、わたしのそばに立っていなさい。わたしはあなたにすべての命令、掟、および法を語る。あなたはそれを彼らに教えなさい。わたしが彼らに所有地として与えるその地で、彼らがそれを行うためである。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="ヨシュア記 23:6; 箴言 4:27; ヨシュア記 1:7"> それゆえ、あなたがたの神、主が命じられたとおり、注意して行え。右にも左にもそれてはならない。</span>
<span className="v" id="v33" data-v="33" data-xref="エレミヤ書 7:23; 申命記 4:40; ルカ 1:6"> あなたがたの神、主が命じられた道をどこまでも歩め。そうすれば、あなたがたは生き、幸いを得て、所有する地で長く生きることができる。</span>
</div>

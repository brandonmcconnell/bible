<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> モーセは行って、これらの言葉を全イスラエルに語った。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 34:7; 民数記 27:17; 列王記第一 3:7"> 彼は彼らに言った。「私は今日、百二十歳である。私はもはや出入りすることができない。主は私に、『あなたはこのヨルダン川を渡ることはない』と言われた。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 9:3; 申命記 31:23; 申命記 3:28"> あなたの神、主ご自身があなたの先頭に立って渡って行かれる。主はあなたの前からこれらの国々を滅ぼし、あなたは彼らの地を所有する。主が語られたとおりに、ヨシュアがあなたの先頭に立って渡って行く。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 23:28–31; 申命記 2:33; 申命記 3:3–11"> 主は、アモリ人の王シホンとオグ、および彼らを滅ぼされた時に彼らの地になされたのと同じように、彼らにもなされる。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 7:2; 申命記 20:16–17; 出エジプト記 23:32–33"> 主は彼らをあなたがたの前に引き渡される。わたしが命じたすべてのことに従って、彼らにせよ。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 1:9; エペソ人への手紙 6:10; 詩篇 27:14"> 強く、また雄々しくありなさい。彼らのゆえに恐れてはならず、おののいてはならない。あなたの神、主ご自身があなたとともに行かれるからである。主はあなたを見放すことも、あなたを見捨てることもない。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命記 3:28; 申命記 31:6; 申命記 1:38"> モーセはヨシュアを呼び、全イスラエルの目の前で言った。「強く、雄々しくあれ。主が父祖たちに与えると誓われた地へ、この民とともに入って行き、彼らにそれを受け継がせるのはあなただ。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 33:14; 申命記 31:6; ヨシュア記 1:9"> あなたの先頭に立って行かれるのは主である。主はあなたとともにおられる。主はあなたを見放すことも、あなたを見捨てることもない。恐れてはならない。また、おじけづいてはならない。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数記 4:15; ヨシュア記 3:3; 申命記 17:18"> モーセはこの律法を書き記し、それを主の契約の箱を担ぐレビの子らである祭司たちと、イスラエルのすべての長老たちに渡した。</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 23:34–43; 申命記 15:1–2"> モーセは彼らに命じて言った。「七年の終わりごとに、免除の年の定められた時に、仮庵の祭りに、</span>
<span className="v" id="v11" data-v="11" data-xref="列王記第二 23:2; ヨシュア記 8:34–35; 申命記 16:16–17"> 全イスラエルが、主の選ばれる場所であなたの神、主の前に出るとき、この律法を全イスラエルの前で読み上げ、聞かせよ。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 4:10; 詩篇 34:11–14; 申命記 6:6–7"> 民を、すなわち男、女、幼子、およびあなたの町に住む寄留者を集めなさい。彼らが聞いて学び、あなたがたの神、主を恐れ、この律法のすべての言葉を注意して行うためである。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 11:2; 申命記 6:7; 箴言 22:6"> また、それをまだ知らない彼らの子どもたちが聞いて、あなたがたが所有するためにヨルダン川を渡って行くその地で、あなたがたが生きるすべての日の間、あなたがたの神、主を恐れることを学ぶためである。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数記 27:13; 申命記 31:23; ヨブ記 2:1"> 主はモーセに言われた。「見よ、あなたの死ぬ日が近づいた。ヨシュアを呼び、二人で会見の天幕に立ちなさい。わたしが彼を任命する。」モーセとヨシュアは行き、会見の天幕に立った。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 40:38; 詩篇 99:7; 出エジプト記 33:9–10"> 主は天幕の中で雲の柱の内に現れ、雲の柱は天幕の入口の上にとどまった。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 10:6; 士師記 10:13; 士師記 2:12"> 主はモーセに言われた。「見よ、あなたは父祖たちとともに眠りにつく。そしてこの民は立ち上がり、彼らが入って行くその地のただ中で、その地の異国の神々に従って淫行を働き、わたしを見捨て、わたしが彼らと結んだ契約を破るであろう。</span>
<span className="v" id="v17" data-v="17" data-xref="民数記 14:42; イザヤ書 8:17; 詩篇 104:29"> その日、わたしの怒りが彼らに向かって燃え上がり、わたしは彼らを見捨て、彼らからわたしの顔を隠す。彼らは食い尽くされ、多くの災いと苦難が彼らに降りかかる。その日、彼らは『これらの災いが私たちに降りかかったのは、私たちの神が私たちのただ中におられないからではないか』と言うであろう。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 31:16–17"> 彼らが他の神々に向きを変え、行ってきたすべての悪のゆえに、わたしはその日、わたしの顔を完全に隠す。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命記 6:7; 申命記 31:21–22; 申命記 31:26"> 「それゆえ今、この歌を書き記し、イスラエルの子らに教え、その口に置け。この歌がイスラエルの子らに対する、わたしの証人となるためである。</span>
<span className="v" id="v20" data-v="20" data-xref="ホセア書 13:6; 申命記 6:10–12; ネヘミヤ記 9:25–26"> わたしが彼らの父祖たちに誓った、乳と蜜の流れる地にわたしが彼らを導き入れ、彼らが食べて満ち足り、太ったとき、彼らは他の神々に向きを変えてそれらに仕え、わたしを侮り、わたしの契約を破るであろう。</span>
<span className="v" id="v21" data-v="21" data-xref="ホセア書 5:3; 詩篇 139:2; ヨハネ 2:24–25"> 多くの災いと苦難が彼らに臨むとき、この歌が彼らに対する証言となる。子孫の口から忘れ去られることはない。わたしが彼らを約束の地へ導き入れる前から、彼らが今日抱いている思いを知っているからである。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命記 31:19; 申命記 31:9"> そこでモーセはその日にこの歌を書き記し、それをイスラエルの子らに教えた。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="申命記 31:7–8; 申命記 31:14; 使徒の働き 7:45"> 主はヌンの子ヨシュアに任務をゆだねて、言われた。「強く、また雄々しくありなさい。わたしがイスラエルの子らに誓った地に、あなたが彼らを導き入れるからである。わたしはあなたとともにいる。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="申命記 31:9; 申命記 17:18"> モーセがこの律法の言葉を書物に書き記し、それを最後まで終わらせたとき、</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 31:9"> モーセは主の契約の箱を担ぐレビ人に命じて言った。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 31:19; 列王記第二 22:8–11; ガラテヤ人への手紙 2:19"> 「この律法の書を取り、それをあなたがたの神、主の契約の箱のそばに置きなさい。それがそこであなたに対する証人となるためである。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 32:20; 申命記 9:24; 使徒の働き 7:51"> わたしはあなたの反逆とあなたのうなじの強さを知っているからである。見よ、今日わたしがまだあなたがたとともに生きている間にも、あなたがたは主に対して反逆してきた。ましてや、わたしの死後はなおさらであろう！</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 32:1; 申命記 4:26; 申命記 30:19"> あなたがたの部族のすべての長老たちとあなたがたの役人たちを、わたしのところに集めなさい。わたしが彼らの耳にこれらの言葉を語り、彼らに対して天と地を証人に呼ぶためである。</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 2:19; 申命記 32:5; ルカ 21:24"> わたしの死後、あなたがたが完全に自らを堕落させ、わたしがあなたがたに命じた道からそれることを、わたしは知っているからである。そして後の日に、災いがあなたがたに降りかかる。あなたがたが主の目に悪であることを行い、あなたがたの手の業によって主を怒らせるからである。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ヘブル人への手紙 3:2; 申命記 4:5; ヨハネ 12:49"> そこでモーセはイスラエルの全集会の耳に、この歌の言葉を最後まで語り終えた。</span>
</div>

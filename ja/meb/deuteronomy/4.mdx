<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 10:5; エゼキエル書 20:11; レビ記 18:5"> 今、イスラエルよ。わたしが教える掟と法を聞き、それを行え。そうすれば、あなたがたは生き、父祖の神、主が与えられる地に入って、それを所有することができる。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 12:32; 箴言 30:6; ヨハネの黙示録 22:18–19"> わたしがあなたがたに命じる言葉に付け加えてはならず、またそこから減らしてはならない。わたしがあなたがたに命じるあなたがたの神、主の命令を守るためである。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 25:1–9; 詩篇 106:28–29; ヨシュア記 22:17"> あなたがたの目は、主がバアル・ペオルのゆえに行われたことを見た。バアル・ペオルに従ったすべての者を、あなたの神、主はあなたのただ中から滅ぼされた。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 10:20; ヨシュア記 23:8; ヨハネ 6:67–69"> しかし、あなたがたの神、主に忠実であったあなたがたは皆、今日生きている。</span>
<span className="v" id="v5" data-v="5" data-xref="マタイ 28:20; テサロニケ人への手紙第一 4:1–2; ヘブル人への手紙 3:5"> 見よ、わたしの神、主がわたしに命じられたように、わたしはあなたがたに掟と法を教えた。あなたがたが、所有するために入って行くその地のただ中で、そのように行うためである。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨブ記 28:28; 詩篇 111:10; テモテへの第二の手紙 3:15"> それゆえ、それらを守り行いなさい。これは、これらのすべての掟を聞いて、「確かにこの大いなる国民は、知恵と理解力のある民である」と言う国々の民の前に、あなたがたの知恵と理解力を示すものだからである。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 145:18; サムエル記第二 7:23; 詩篇 34:18"> わたしたちが呼ぶときはいつでも、わたしたちの神、主がわたしたちの近くにおられるように、そのように神が近くにおられる大いなる国民が、ほかにどこにあるだろうか。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 147:19–20; ローマ人への手紙 7:12–14; 詩篇 119:127–128"> 今日わたしがあなたがたの前に置くこのすべての律法のように、義にかなった掟と法を持つ大いなる国民が、ほかにどこにあるだろうか。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 6:7; 申命記 11:19; 詩篇 78:3–8"> ただ、十分に気をつけ、自分自身をよく守れ。あなたの目が見たことを忘れず、生涯それを心から離してはならない。それを子供たちと孫たちに知らせよ。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 19:9; ヘブル人への手紙 12:18–19; 出エジプト記 19:16"> あなたがホレブであなたの神、主の前に立った日のこと、主がわたしに、「民をわたしの前に集めよ。わたしは彼らにわたしの言葉を聞かせよう。彼らが地上に生きるすべての日の間、わたしを恐れることを学び、またそれを彼らの子供たちに教えることができるようにするためである」と言われた。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 5:23; 出エジプト記 19:16–18; ヘブル人への手紙 12:18–19"> あなたがたは近づき、山のふもとに立った。山は火で空の中心にまで燃え上がり、暗黒の雲と濃い暗闇に覆われていた。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 4:15; 申命記 5:4; 申命記 5:22"> 主は火のただ中からあなたがたに語られた。あなたがたは語った言葉を聞いたが、いかなる姿も見ず、ただ声だけを聞いた。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 34:28; 出エジプト記 31:18; 申命記 9:9–11"> 主はご自身の契約、すなわちあなたがたに行うように命じられた十戒をあなたがたに告げ知らされた。そして、主はそれを二枚の石の板に書き記された。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 105:44–45; エゼキエル書 21:1–23"> その時、主はわたしに掟と法をあなたがたに教えるように命じられた。それはあなたがたが所有するために渡って行くその地で、あなたがたがそれを行うためである。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 4:12; イザヤ書 40:18; コリント人への第二の手紙 4:4–6"> 主がホレブで火のただ中からあなたがたに語られた日、あなたがたはいかなる姿も見なかったのであるから、自分自身を深く注意して守りなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 17:29; 申命記 5:8; 出エジプト記 20:4–5"> あなたがたが自分たちを堕落させ、いかなる形、すなわち男や女の似姿の彫像を自分たちのために造らないようにするためである。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 1:23"> また、地上のいかなる動物の似姿も、空を飛ぶいかなる翼のある鳥の似姿も、</span>
<span className="v" id="v18" data-v="18"> 地面を這ういかなるものの似姿も、地の下の水の中にいるいかなる魚の似姿も造らないようにするためである。</span>
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 1:25; 申命記 17:3; 列王記第二 21:3"> また、あなたが目を空に向け、太陽、月、星々、すなわち天のすべての万象を見たとき、あなたがたの神、主が全天の下にいるすべての民に割り当てられたそれらに引き寄せられ、それらを拝み、それに仕えないようにするためである。</span>
<span className="v" id="v20" data-v="20" data-xref="列王記第一 8:51; エレミヤ書 11:4; 出エジプト記 19:5–6"> しかし主は、今日あるように、ご自身の受け継ぐ民とするために、あなたがたを取り、鉄の炉、すなわちエジプトから導き出された。</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 1:37; 民数記 20:12; 詩篇 106:32–33"> さらに主はあなたがたのゆえにわたしに対して怒り、わたしがヨルダン川を渡らず、あなたの神、主があなたに所有地として与えられるあの良い地に入らないと誓われた。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 3:25; 申命記 3:27; ペテロの第二の手紙 1:13–15"> わたしはこの地で死に、ヨルダン川を渡ることはできない。しかし、あなたがたは渡って行き、あの良い地を所有する。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 4:9; ヘブル人への手紙 3:12; ヨシュア記 23:16"> あなたがたの神、主があなたがたと結ばれた契約を忘れ、あなたの神、主があなたに禁じられたいかなる形の彫像も、自分たちのために造らないように気をつけなさい。</span>
<span className="v" id="v24" data-v="24" data-xref="ヘブル人への手紙 12:29; ナホム書 1:6; 申命記 9:3"> あなたの神、主は焼き尽くす火であり、ねたむ神だからである。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 4:16; ホセア書 9:9; コリント人への第一の手紙 10:22"> あなたに子供が生まれ、子供たちの子供が生まれ、あなたがたがその地に長く住んで、自らを堕落させ、いかなる形の彫像を造り、あなたの神、主の御目に悪であることを行って、主を怒らせるなら、</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 32:1; ミカ書 6:2; エレミヤ書 22:29"> 今日わたしはあなたがたに対して天と地を証人に呼ぶ。あなたがたは、所有するためにヨルダン川を渡って行くその地から、すぐに完全に滅び去る。あなたがたはその地で長く日々を過ごすことはできず、完全に滅ぼされる。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 28:62–64; レビ記 26:33; エゼキエル書 12:15"> 主はあなたがたを国々の民の間に散らし、主があなたがたを追いやる国々の間で、あなたがたは少ない人数として残される。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 28:64; エレミヤ書 16:13; 申命記 28:36"> そこであなたがたは、人の手の業である木や石の神々、すなわち見ることも、聞くことも、食べることも、嗅ぐこともできない神々に仕えることになる。</span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 119:2; エレミヤ書 29:12–14; 歴代誌 第二 15:4"> しかし、そこからあなたの神、主を求めるなら、心を尽くし、魂を尽くして尋ね求めるなら、あなたは主を見いだす。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨエル書 2:12–13; エレミヤ書 23:20; ホセア書 3:5"> あなたが苦難の中にあり、これらのすべてのことがあなたに臨むとき、終わりの日に、あなたはあなたの神、主に立ち返り、その御声に聞き従う。</span>
<span className="v" id="v31" data-v="31" data-xref="申命記 31:8; 詩篇 116:5; ネヘミヤ記 9:31"> あなたの神、主はあわれみ深い神だからである。主はあなたを見捨てることも、あなたを滅ぼすこともなく、あなたの父祖たちに誓われた彼らとの契約を忘れることもない。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨブ記 8:8; マタイ 24:31; 詩篇 44:1"> 神が地上に人を創造された日から、また天の果てから果てに至るまで、あなたより前にあった過ぎ去った日々に、今尋ねてみなさい。このような大いなる事があっただろうか。あるいは、これに似た事が聞かれただろうか。</span>
<span className="v" id="v33" data-v="33" data-xref="士師記 6:22; 申命記 5:24; 出エジプト記 33:20"> あなたが聞いたように、火のただ中から語られる神の声を聞いて、なお生きている民があっただろうか。</span>
<span className="v" id="v34" data-v="34" data-xref="申命記 26:8; 申命記 5:15; 出エジプト記 6:6"> あるいは神が、あなたの神、主がエジプトにおいてあなたの目の前であなたのために行われたすべてのことのように、試み、しるし、不思議、戦い、力強い御手、伸ばされた腕、そして大いなる恐れによって、一つの国民を別の国民の中からご自分のために取り出そうとされたことがあっただろうか。</span>
<span className="v" id="v35" data-v="35" data-xref="イザヤ書 45:18; サムエル記第一 2:2; イザヤ書 45:5"> それがあなたに示されたのは、主こそが神であることをあなたが知るためであった。主のほかに神はいない。</span>
<span className="v" id="v36" data-v="36" data-xref="出エジプト記 19:9; 出エジプト記 19:19; 申命記 4:33"> 主はあなたを教え導くために、天から主の御声をあなたに聞かせられた。地上では主の大いなる火をあなたに見せられ、あなたは火のただ中から主の言葉を聞いた。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 10:15; イザヤ書 63:9; 出エジプト記 13:9"> 主はあなたの父祖たちを愛されたので、彼らの後の子孫を選び、主の臨在と大いなる力をもって、あなたをエジプトから導き出された。</span>
<span className="v" id="v38" data-v="38" data-xref="申命記 7:1; 申命記 9:1–5; 出エジプト記 23:27–28"> それは、あなたよりも大きく力強い国々をあなたの前から追い払い、今日あるように、あなたを導き入れて、彼らの地を所有地としてあなたに与えるためであった。</span>
<span className="v" id="v39" data-v="39" data-xref="ヨシュア記 2:11; 申命記 4:35; 歴代誌上 29:11"> それゆえ今日、上は天において、下は地において、主こそ神であり、ほかに神はいないことを知り、心に留めなさい。</span>
<span className="v" id="v40" data-v="40" data-xref="申命記 6:3; エペソ人への手紙 6:3; 申命記 12:28"> 今日わたしが命じる主の掟と命令を守れ。そうすれば、あなたも後の子供たちも幸いを得て、あなたの神、主がいつまでも与えられる地で長く生きることができる。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数記 35:6; 民数記 35:14–15; ヨシュア記 20:2–9"> その時、モーセは日の出る方角であるヨルダン川の向こう側に、三つの町をえり分けた。</span>
<span className="v" id="v42" data-v="42" data-xref="ヘブル人への手紙 6:18; 申命記 19:1–10; 民数記 35:15–28"> 過去において憎しみがなく、過って隣人を殺した者がそこに逃れ、これらの町の一つに逃げ込んで生き延びることができるようにするためである。</span>
<span className="v" id="v43" data-v="43" data-xref="ヨシュア記 20:8; 列王記第一 4:13; ヨシュア記 21:27"> すなわち、ルベン人のための平原の荒野にあるベツェル、ガド人のためのギルアデのラモト、およびマナセ人のためのバシャンのゴランである。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="申命記 27:3; レビ記 27:34; マラキ書 4:4"> これはモーセがイスラエルの子らの前に置いた律法である。</span>
<span className="v" id="v45" data-v="45" data-xref="列王記第一 2:3; 申命記 4:1; 詩篇 119:7"> これらは、イスラエルの子らがエジプトから出て来たとき、モーセがイスラエルの子らに語った証し、掟、および法である。</span>
<span className="v" id="v46" data-v="46" data-xref="申命記 3:29; 申命記 4:47; 申命記 1:4–5"> それはヨルダン川の向こう側、ベテ・ペオルの向かいの谷、ヘシュボンに住んでいたアモリ人の王シホンの地であった。モーセとイスラエルの子らはエジプトから出て来たときに彼を打ち倒した。</span>
<span className="v" id="v47" data-v="47" data-xref="申命記 3:1–14; 民数記 21:33–35; 申命記 29:7–8"> 彼らは彼の地と、バシャンの王オグの地、すなわち日の出る方角のヨルダン川の向こう側にいたアモリ人の二人の王の地を所有した。</span>
<span className="v" id="v48" data-v="48" data-xref="申命記 3:9; 申命記 2:36; 申命記 3:12"> それはアルノン川の谷の端にあるアロエルから、シオン山、すなわちヘルモン山に至るまで、</span>
<span className="v" id="v49" data-v="49" data-xref="申命記 3:17; ヨシュア記 13:20; 申命記 34:1"> また、ヨルダン川の向こう側の東にある全アラバ、ピスガの斜面の下にあるアラバの海に至るまでであった。</span>

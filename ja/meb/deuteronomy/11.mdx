<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 6:5; 申命記 10:12; ルカ 1:74–75"> それゆえ、あなたはあなたの神、主を愛し、主の訓戒、掟、法、および命令を常に守れ。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 8:2–5; 申命記 29:10; 使徒の働き 26:22"> 今日、あなたがたは知れ。わたしが語っているのは、あなたがたの神、主の懲らしめ、その偉大さ、力強い御手、伸ばされた腕を知らず、見たこともない子供たちにではない。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 7:19; 申命記 4:34; 詩篇 105:27–45"> また、主がエジプトのただ中で、エジプトの王ファラオとその全土に行われたしるしと御業、</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 106:11; 出エジプト記 14:23–31; 出エジプト記 15:19"> 主がエジプトの軍隊、その馬と戦車に行われたこと、彼らがあなたがたを追いかけてきたとき、主が紅海の水を彼らの上に溢れさせ、今日に至るまで主が彼らを滅ぼされたこと、</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 77:20; 詩篇 106:12–48; 詩篇 78:14–72"> あなたがたがこの場所に来るまで、主が荒野であなたがたに行われたこと、</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 26:9–10; 詩篇 106:17; 民数記 16:1–35"> ルベンの子エリアブの子であるダタンとアビラムに行われたこと、すなわち全イスラエルのただ中で、地がその口を開き、彼らとその家族、天幕、そして彼らに従っていたすべての生き物を飲み込んだことを見たのは、あなたがたの子供たちではない。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 145:4–6; 詩篇 145:12; 詩篇 150:2"> しかし、主が行われたすべての大いなる御業を見たのは、あなたがたの目である。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="エペソ人への手紙 6:10; ヨシュア記 1:6–7; エペソ人への手紙 3:16"> それゆえ、あなたがたは今日わたしが命じるすべての命令を守れ。それはあなたがたが強くなり、渡って行って所有しようとしているその地に入ってそれを所有するため、</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 3:8; 申命記 4:40; 申命記 6:2"> また、主があなたがたの父祖たちに、彼らとその後の子孫に与えると誓われたその地、乳と蜜の流れる地で、あなたがたの日々が長く続くためである。</span>
<span className="v" id="v10" data-v="10" data-xref="ゼカリヤ書 14:18"> あなたが所有するために入って行くその地は、あなたがたが出てきたエジプトの地とは異なる。そこではあなたがたは種を蒔き、野菜畑のように足で水を引いていた。</span>
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 6:7; 申命記 8:7–9; 詩篇 65:12–13"> しかし、あなたがたが渡って行って所有しようとしている地は、山と谷のある地であり、天の雨の水を飲む。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 24:6; 詩篇 33:18; 列王記第一 9:3"> それはあなたの神、主が顧みてくださる地であり、年の初めから終わりまで、あなたの神、主の目が常にそこにある。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命記 10:12; 申命記 4:29; 申命記 6:17"> もしあなたがたが、わたしが今日命じる命令に熱心に聞き従い、あなたがたの神、主を愛し、心を尽くし、魂を尽くして主に仕えるなら、</span>
<span className="v" id="v14" data-v="14" data-xref="ヤコブの手紙 5:7; レビ記 26:4; エゼキエル書 34:26"> わたしはあなたがたの地に季節ごとの雨、すなわち秋の雨と春の雨を与える。あなたは穀物、新しいぶどう酒、油を集めることができる。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 104:14; 申命記 6:11; ヨエル書 2:19"> わたしはあなたの家畜のために野に草を与える。あなたは食べて満ち足りる。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヨブ記 31:27; ヘブル人への手紙 3:12; ヘブル人への手紙 2:1"> あなたがたは心を惑わされて横道にそれ、他の神々に仕えて、それらを拝むことのないように気をつけなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="列王記第一 8:35; 申命記 6:15; 歴代誌 第二 6:26"> さもないと、主の怒りがあなたがたに向かって燃え上がり、主が天を閉ざして雨が降らなくなり、地がその産物をもたらさなくなる。そして、主があなたがたに与えられるあの良い地から、あなたがたは速やかに滅び去る。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="コロサイ人への手紙 3:16; 申命記 6:6–9; 箴言 3:1"> それゆえ、わたしのこれらの言葉を心と魂に刻め。しるしとして手に結び、額飾りとして目の間につけよ。</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 6:7; イザヤ書 38:19; 申命記 4:9–10"> これを子供たちに教えよ。家に座っているときも、道を歩くときも、寝るときも、起きるときも、これを語れ。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 6:9"> これを家の戸口の柱と門に書き記せ。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 4:10; 箴言 3:2; 箴言 9:11"> それは、主があなたがたの父祖たちに与えると誓われたその地において、天が地の上にある限り、あなたがたの日々と、あなたがたの子供たちの日々が多くなるためである。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命記 6:17; 申命記 11:13; 申命記 10:20"> あなたがたの神、主を愛し、主のすべての道を歩み、主にすがりつくために、わたしがあなたがたに行うように命じるこのすべての命令を、あなたがたが熱心に守るなら、</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 4:38; 申命記 9:1; 申命記 7:1–2"> 主はこれらのすべての国々の民をあなたがたの前から追い払われる。あなたがたは、自分たちよりも大きくて力強い国々の民の地を所有する。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨシュア記 14:9; 出エジプト記 23:31; 創世記 15:18–21"> あなたがたの足の裏が踏むあらゆる場所は、あなたがたのものとなる。荒野とレバノンから、大河ユーフラテス川から西の海に至るまでが、あなたがたの境界となる。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 7:24; 出エジプト記 23:27; ヨシュア記 1:5"> だれ一人としてあなたがたの前に立つことはできない。あなたの神、主は、あなたに語られたとおり、あなたが踏む全地に、あなたに対する恐れと恐怖を置かれる。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="申命記 30:1; 申命記 30:15–20; ガラテヤ人への手紙 3:10"> 見よ、わたしは今日、あなたがたの前に祝福と呪いを置く。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 1:19; 申命記 28:1–14; イザヤ書 3:10"> わたしが今日あなたがたに命じる、あなたの神、主の命令に聞き従うなら、祝福がある。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 28:15–68; ローマ人への手紙 2:8–9; ガラテヤ人への手紙 3:10"> もしあなたの神、主の命令に聞き従わず、わたしが今日あなたがたに命じる道からそれて、あなたがたの知らなかった他の神々に従うなら、呪いがある。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="申命記 27:12–26; ヨシュア記 8:30–35"> あなたの神、主が、所有しようとしている地にあなたを導き入れられたとき、ゲリジム山には祝福を、エバル山には呪いを置け。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 12:6; 士師記 7:1; ヨシュア記 4:19"> それらはヨルダン川の向こう側、日の沈む道の背後、ギルガルの近く、モレの樫の木のそばにある、アラバに住むカナン人の地にあるではないか。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨシュア記 1:11; 申命記 9:1; ヨシュア記 3:13–17"> あなたがたはヨルダン川を渡り、あなたの神、主が与えられる地に入ってそれを所有しようとしている。あなたがたはそれを所有し、そこに住む。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイ 28:20; 申命記 12:32; テサロニケ人への手紙第一 4:1–2"> わたしが今日あなたがたの前に置く、すべての掟と法を注意して行え。</span>
</div>

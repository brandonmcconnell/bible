<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 17:14; 申命記 13:9; 申命記 6:1–10"> あなたの神、主が所有地としてあなたに与えられる地に入り、それを所有してそこに住むようになったとき、</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 23:19; 出エジプト記 23:16; エゼキエル書 44:30"> あなたは、あなたの神、主があなたに与えられる地から取り入れる、地のすべての産物の初穂の一部を取りなさい。あなたはそれを籠に入れ、あなたの神、主がご自分の名を住まわせるために選ばれる場所へ行きなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 105:9–10; 申命記 19:17; 創世記 26:3"> その時代の祭司のところへ行き、こう言いなさい。「私は今日、あなたの神、主に宣言します。主が私たちに与えると父祖たちに誓われた地に、私は入りました。」</span>
<span className="v" id="v4" data-v="4" data-xref="マタイ 23:19; マタイ 5:23–24; ヘブル人への手紙 13:10–12"> 祭司はあなたの手から籠を受け取り、あなたの神、主の祭壇の前に置く。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 10:22; 創世記 46:27; 創世記 31:20"> そして、あなたの神、主の前でこう告白しなさい。「私の父祖<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または、「父」。">a</a></sup>は、滅びかけたアラム人でした。わずかな人数でエジプトへ下り、そこに寄留しましたが、そこで大きく、強く、数の多い国民となりました。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 1:11; 出エジプト記 1:14; 出エジプト記 5:23"> エジプト人は私たちをひどく扱い、私たちを苦しめ、過酷な奴隷労働を私たちに課しました。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 2:23–4; エペソ人への手紙 3:20–21; 出エジプト記 3:9"> 私たちが私たちの父祖の神、主に叫び求めたとき、主は私たちの声を聞き、私たちの苦しみ、私たちの労苦、私たちのしいたげを見られました。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 4:34; 申命記 5:15; 詩篇 78:12–13"> そして主は、力強い御手、伸ばされた腕、大いなる恐れ、しるし、そして不思議によって、私たちをエジプトから導き出されました。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 3:8; 詩篇 105:44; 詩篇 107:7–8"> 主は私たちをこの場所に導き入れ、この地、乳と蜜の流れる地を私たちに与えられました。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 26:2; 申命記 18:4; ヨハネの黙示録 22:9"> 主よ、見よ、今私は、あなたが私に与えてくださった地の産物の初穂を持って来ました。」あなたはそれをあなたの神、主の前に置き、あなたの神、主の前で伏し拝みなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 16:11; 申命記 12:7; ピリピ人への手紙 4:4"> そして、あなたの神、主があなたとあなたの家に与えられたすべての良いものを喜び楽しみなさい。あなたも、レビ人も、あなたのただ中にいる寄留者も同様である。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="レビ記 27:30; 民数記 18:24; ピリピ人への手紙 4:18–19"> 第三の年、すなわち十分の一の年に、あなたの全収穫の十分の一を納め終えたとき、あなたはそれをレビ人、寄留者、孤児、およびやもめに与え、彼らがあなたの町で食べて満ち足りるようにしなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 119:176; 詩篇 119:153; 詩篇 119:141"> あなたはあなたの神、主の前で言いなさい。「私は聖なるものを家から取り出し、あなたが私に命じられたすべての命令に従って、それをレビ人、寄留者、孤児、およびやもめに与えました。私はあなたのいかなる命令にも背かず、それらを忘れませんでした。</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 7:20; レビ記 21:11; ホセア書 9:4"> 私は喪に服しているときにそれを食べず、汚れているときにそれを取り出さず、死者のためにそれを提供することもありませんでした。私は私の神、主の御声に聞き従いました。私はあなたが命じられたすべてのことに従って行いました。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 63:15; ゼカリヤ書 2:13; エレミヤ書 31:23"> あなたの聖なる住まいである天から見下ろし、あなたの民イスラエルと、あなたが私たちの父祖たちに誓われたとおりに私たちに与えてくださった地、乳と蜜の流れる地を祝福してください。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 12:1; ヨハネ 14:15; ヨハネの手紙第一 5:2–3"> 今日、あなたの神、主は、これらの掟と法を行うようにあなたに命じられる。それゆえ、あなたは心を尽くし、魂を尽くして、それらを守り行え。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 24:7; イザヤ書 12:2; コリント人への第一の手紙 6:19–20"> あなたは今日、主をあなたの神とし、主の道を歩み、主の掟、命令、および法を守り、主の御声に聞き従うことを宣言した。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 7:6; 申命記 14:2; 申命記 28:9"> そして主は今日、約束されたとおり、あなたが主ご自身の宝の民であること、そしてあなたが主のすべての命令を守るべきことを宣言された。</span>
<span className="v" id="v19" data-v="19" data-xref="ペテロの手紙第一 2:9; 申命記 7:6; 申命記 28:1"> また、主が造られたすべての国々の上に、あなたを賛美、名声、栄誉において高く上げること、そして語られたとおり、あなたがあなたの神、主にとって聖なる民となることを宣言された。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王記第二 24:18; ヨシュア記 10:29; 歴代誌 第二 36:11"> ゼデキヤは二十一歳で王となり、エルサレムで十一年間治めた。彼の母の名はハムタルといい、リブナ出身のエレミヤの娘であった。</span>
<span className="v" id="v2" data-v="2" data-xref="列王記第一 14:22; 列王記第二 24:19–20; エゼキエル書 17:16–20"> 彼はエホヤキムが行ったすべてのことに倣い、主の目に悪いことを行った。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 3:4–5; 歴代誌 第二 36:13; イザヤ書 3:1"> エルサレムとユダにこのことが起こったのは主の怒りによるもので、ついに主は彼らを御前から投げ捨てられた。<br />ゼデキヤはバビロンの王に反逆した。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 39:1; ゼカリヤ書 8:19; エゼキエル書 24:1–2"> ゼデキヤの治世第九年、第十の月の十日に、バビロンの王ネブカドネザルは全軍を率いてエルサレムに攻めて来た。彼らはその周囲に陣を張り、四方に包囲の塁を築いた。</span>
<span className="v" id="v5" data-v="5"> こうして町は、ゼデキヤ王の治世第十一年まで包囲された。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 39:2; イザヤ書 3:1; 列王記第二 25:3"> 第四の月の九日、町の飢饉は激しくなり、この地の民には食べ物がなくなった。</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 39:4–7; エレミヤ書 51:32; 列王記第二 25:4"> その時、町の城壁が破られ、兵士たちは皆、夜のうちに逃げ出した。彼らは王の庭のそばにある二重の城壁の間の門を通って、町を出た。カルデア人は町を四方から取り囲んでいた。兵士たちはアラバの方へ向かった。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 34:21; エレミヤ書 32:4; エレミヤ書 38:23"> しかし、カルデア人の軍隊は王を追い、エリコの平地でゼデキヤに追いついた。その全軍は彼のもとから散らされた。</span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 39:5; 民数記 13:21; 列王記第二 25:6"> 彼らは王を捕らえ、ハマテの地リブラにいるバビロンの王のもとへ連れて行った。王はゼデキヤに判決を下した。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 22:30; 列王記第二 25:7; 創世記 21:16"> バビロンの王はゼデキヤの息子たちを彼の目の前で殺した。また、リブラでユダのすべての高官たちを殺した。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 12:13; エレミヤ書 34:3–5"> さらにゼデキヤの両目をえぐった。バビロンの王は彼を足かせにつなぎ、バビロンへ連れて行き、死ぬ日まで牢獄に入れておいた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王記第二 25:8; エレミヤ書 39:9; エレミヤ書 52:29"> 第五の月の十日、すなわちバビロンの王ネブカドネザルの治世第十九年に、バビロンの王に仕える親衛隊長ネブザラダンがエルサレムに来た。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 79:1; ミカ書 3:12; 歴代誌 第二 36:19"> 彼は主の家、王宮、エルサレムのすべての家々を火で焼いた。大きな家はすべて火で焼いた。</span>
<span className="v" id="v14" data-v="14" data-xref="ネヘミヤ記 1:3; 列王記第二 25:10"> 親衛隊長とともにいたカルデア人の全軍は、エルサレムを囲むすべての城壁を打ち壊した。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 15:1–2; ゼカリヤ書 14:2"> 親衛隊長ネブザラダンは、民の中の貧しい者の一部、町に残っていた民、バビロンの王に投降した者たち、残っていた群衆を捕囚として連れ去った。</span>
<span className="v" id="v16" data-v="16" data-xref="列王記第二 25:12; エレミヤ書 39:9–10; エレミヤ書 40:5–7"> しかし、親衛隊長ネブザラダンは、この地の最も貧しい者の一部を、ぶどう畑を手入れする者と農夫として残した。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 27:19–22; エレミヤ書 52:21–23; 歴代誌 第二 4:12–15"> カルデア人は主の家にあった青銅の柱、台、青銅の海を砕き、その青銅をすべてバビロンへ運んだ。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 27:3; 民数記 4:14; 列王記第一 7:45"> また、鍋、灰取り、芯切りばさみ、鉢、さじ、礼拝に用いるすべての青銅の器を持ち去った。</span>
<span className="v" id="v19" data-v="19" data-xref="列王記第一 7:49–50; 歴代誌 第二 4:6–22; レビ記 26:12"> 親衛隊長は、杯、火皿、鉢、鍋、燭台、さじ、注ぎの器を持ち去った。金でできたものは金として、銀でできたものは銀として持ち去った。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王記第一 7:47; 列王記第二 25:16; 歴代誌 第二 4:18"> ソロモン王が主の家のために造った二本の柱、一つの海、台の下にあった十二頭の青銅の雄牛も持ち去った。これらすべての器の青銅は、量ることができないほどであった。</span>
<span className="v" id="v21" data-v="21" data-xref="列王記第二 25:17; 列王記第一 7:15–21; 歴代誌 第二 3:15–17"> 一本の柱の高さは十八キュビトで、周囲の長さは十二キュビトであった。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一キュビトは、男性の腕の中指の先から肘までの長さで、約46センチメートル、または18インチである。">a</a></sup>その厚さは指四本分で、中は空洞であった。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 28:25; 列王記第二 25:17; 歴代誌 第二 3:15"> その上には青銅の柱頭があり、一つの柱頭の高さは五キュビトであった。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一キュビトは、男性の腕の中指の先から肘までの長さで、約46センチメートル、または18インチである。">b</a></sup>柱頭の周囲には、すべて青銅でできた網細工とざくろがあった。もう一方の柱も同じで、ざくろがついていた。</span>
<span className="v" id="v23" data-v="23" data-xref="列王記第一 7:20"> 外側には九十六個のざくろがあり、網細工の周囲全体では百個のざくろがあった。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王記第二 25:18; エレミヤ書 29:25; エレミヤ書 35:4"> 親衛隊長は祭司長セラヤ、第二の祭司ゼパニヤ、三人の門衛を捕らえた。</span>
<span className="v" id="v25" data-v="25" data-xref="列王記第二 25:19; エステル記 1:14; マタイ 18:10"> また、町から、兵士たちを指揮していた一人の高官、町にいた王に謁見する七人の者、民を召集していた軍の長の書記、この地の民のうち町の中にいた六十人を捕らえた。</span>
<span className="v" id="v26" data-v="26"> 親衛隊長ネブザラダンは彼らを捕らえ、リブラにいるバビロンの王のもとへ連れて行った。</span>
<span className="v" id="v27" data-v="27" data-xref="エゼキエル書 33:28; イザヤ書 32:13–14; イザヤ書 6:11–12"> バビロンの王はハマテの地リブラで彼らを打ち殺した。<br />こうしてユダは自分の地から捕囚として連れ去られた。</span>
<span className="v" id="v28" data-v="28" data-xref="列王記第二 24:12–16; 列王記第二 24:2–3; ダニエル書 1:1–3"> ネブカドネザルが捕囚として連れ去った民の数は、次のとおりである。<br />第七年に、ユダヤ人三千二十三人。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="エレミヤ書 52:12; 創世記 12:5; 列王記第二 25:11"> ネブカドネザルの治世第十八年に、エルサレムから八百三十二人を捕囚として連れ去った。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 52:15; エレミヤ書 6:9"> ネブカドネザルの治世第二十三年に、親衛隊長ネブザラダンがユダヤ人七百四十五人を捕囚として連れ去った。<br />全員で四千六百人であった。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王記第二 25:27–30; 詩篇 3:3; 創世記 40:13"> ユダの王エホヤキンが捕囚となってから第三十七年、第十二の月の二十五日に、バビロンの王エビル・メロダクは、その治世第一年に、ユダの王エホヤキンに恩赦を与え、牢獄から出した。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 12:25; ダニエル書 5:18–19; ダニエル書 2:37"> 彼に親切に語り、バビロンで彼とともにいた王たちの王座よりも高い王座を与えた。</span>
<span className="v" id="v33" data-v="33" data-xref="サムエル記第二 9:7; 列王記第一 2:7; 創世記 41:14"> エホヤキンは囚人の服を着替え、生涯いつも王の前で食事をした。</span>
<span className="v" id="v34" data-v="34" data-xref="サムエル記第二 9:10; ルカ 11:3; マタイ 6:11"> 彼にはバビロンの王から、日々の必要に応じた一定の食料が、死ぬ日まで、生涯にわたって毎日与えられた。</span>
</div>
</div>

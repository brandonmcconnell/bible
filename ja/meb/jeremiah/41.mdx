<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 40:8; エレミヤ書 40:6; 詩篇 41:9"> 第七の月に、エリシャマの孫でネタヌヤの子であるイシュマエルが、十人の者とともに、ミツパにいるアヒカムの子ゲダルヤのもとへ来た。イシュマエルは王族で、王の高官の一人であった。彼らはミツパでともに食事をした。</span>
<span className="v" id="v2" data-v="2" data-xref="列王記第二 25:25; エレミヤ書 40:5; 詩篇 109:5"> その時、ネタヌヤの子イシュマエルと、彼とともにいた十人の者は立ち上がり、シャファンの孫でアヒカムの子であるゲダルヤを剣で打ち殺した。ゲダルヤは、バビロンの王がこの地の総督に任命した者であった。</span>
<span className="v" id="v3" data-v="3" data-xref="列王記第二 25:25; 哀歌 1:2; エレミヤ書 41:11–12"> イシュマエルはまた、ミツパでゲダルヤとともにいたすべてのユダヤ人と、そこにいたカルデア人の兵士たちも殺した。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="サムエル記第一 27:11; 詩篇 52:1–2"> 彼がゲダルヤを殺した翌日、まだだれもそのことを知らない時、</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第一 16:24; 申命記 14:1; ヨシュア記 18:1"> シェケム、シロ、サマリアから八十人の男たちがやって来た。彼らはひげをそり、衣を引き裂き、身を傷つけ、主の家に献げる穀物のささげ物と乳香を手にしていた。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記第二 3:16; エレミヤ書 50:4; サムエル記第二 1:2–16"> ネタヌヤの子イシュマエルは、彼らを迎えるためにミツパから出て行き、歩きながら泣き続けた。彼らに会うと、「アヒカムの子ゲダルヤのところへ来てください」と言った。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 59:7; 詩篇 55:23; エゼキエル書 22:27"> 彼らが町の中央まで来ると、ネタヌヤの子イシュマエルは、彼とともにいた者たちと彼らを殺し、穴の中に投げ込んだ。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨブ記 2:4; 箴言 13:8; ピリピ人への手紙 3:7–9"> しかし、その中の十人がイシュマエルに言った。「私たちを殺さないでください。畑に小麦、大麦、油、蜜を隠してあります。」<br />そこで彼は手を止め、彼らを仲間たちとともに殺さなかった。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 6:2; 列王記第一 15:17–22; サムエル記第一 13:6"> イシュマエルが、ゲダルヤとともに殺した人々の死体を投げ込んだ穴は、かつてアサ王がイスラエルの王バシャを恐れて造ったものであった。ネタヌヤの子イシュマエルは、それを殺された者たちで満たした。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 40:14; エレミヤ書 40:7; ネヘミヤ記 2:10"> それからイシュマエルは、ミツパに残っていたすべての民、すなわち王の娘たちと、親衛隊長ネブザラダンがアヒカムの子ゲダルヤに委ねていた、ミツパに残るすべての民を捕らえた。ネタヌヤの子イシュマエルは彼らを捕虜として連れ去り、アンモン人の地へ渡ろうと出発した。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 40:13–16; エレミヤ書 40:7–8; エレミヤ書 42:1"> カレアの子ヨハナンと、彼とともにいた軍隊のすべての隊長たちは、ネタヌヤの子イシュマエルが行ったすべての悪を聞くと、</span>
<span className="v" id="v12" data-v="12" data-xref="サムエル記第二 2:13; 創世記 14:14–16; サムエル記第一 30:1–8"> すべての部下を率いて、ネタヌヤの子イシュマエルと戦うために出て行き、ギブオンにある大きな池のそばで彼を見つけた。</span>
<span className="v" id="v13" data-v="13"> イシュマエルとともにいたすべての民は、カレアの子ヨハナンと、彼とともにいた軍隊のすべての隊長たちを見ると喜んだ。</span>
<span className="v" id="v14" data-v="14"> イシュマエルがミツパから捕らえて連れ去ったすべての民は向きを変えて戻り、カレアの子ヨハナンのもとへ行った。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨブ記 21:30; 箴言 28:17; 列王記第一 20:20"> しかし、ネタヌヤの子イシュマエルは八人の者とともにヨハナンから逃れ、アンモン人のもとへ行った。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 43:4–7; エレミヤ書 42:8; エレミヤ書 41:10"> そこでカレアの子ヨハナンと、彼とともにいた軍隊のすべての隊長たちは、ネタヌヤの子イシュマエルがアヒカムの子ゲダルヤを殺した後、ミツパから捕らえて連れ去った民の残りの者を、彼の手から取り戻した。ヨハナンがギブオンから連れ戻したのは、兵士たち、女たち、子どもたち、宦官たちであった。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記第二 19:37–38; エレミヤ書 42:14; エレミヤ書 43:7"> 彼らは出発し、ベツレヘムの近くにあるゲルテ・キムハムに滞在して、エジプトへ入ろうとした。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 40:5; ルカ 12:4–5; エレミヤ書 42:16"> 彼らがカルデア人を恐れたからである。ネタヌヤの子イシュマエルが、バビロンの王によってこの地の総督に任命されたアヒカムの子ゲダルヤを殺したためであった。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 1:2; エレミヤ書 2:1; エレミヤ書 1:4"> 主の言葉が私に臨んで言われた。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第一の手紙 7:26–27; ルカ 23:29; 創世記 19:14"> 「あなたはこの場所で妻をめとってはならない。息子や娘を持ってもならない。」</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 16:9; エレミヤ書 16:5; エレミヤ書 6:21"> この場所で生まれる息子や娘、彼らを産む母親、この地で彼らをもうける父親について、主はこう言われる。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 25:33; 詩篇 83:10; エレミヤ書 9:22"> 「彼らは悲惨な死を遂げる。嘆かれることも、葬られることもない。地の表の糞のようになる。剣と飢饉によって滅ぼし尽くされ、その死体は空の鳥と地の動物の餌となる。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 24:16–23; イザヤ書 27:11; エレミヤ書 15:1–4"> 主はこう言われる。「喪の家に入ってはならない。嘆きに行ってはならず、彼らのために悲しんではならない。わたしはこの民から、わたしの平和を取り去ったからだ」と、主は言われる。「慈しみとあわれみも取り去った。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 14:1; エレミヤ書 41:5; エレミヤ書 47:5"> この地では、大きい者も小さい者も死ぬ。彼らは葬られず、だれも彼らのために嘆かない。彼らのために身を傷つける者も、頭をそる者もいない。</span>
<span className="v" id="v7" data-v="7" data-xref="ホセア書 9:4; エゼキエル書 24:17; 申命記 26:14"> 死者を悼む者のためにパンを裂いて慰める者はいない。父や母を失った者に、慰めの杯を飲ませる者もいない。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 15:17; 伝道者の書 7:2–4; イザヤ書 22:12–14"> 「あなたは祝宴の家に入り、彼らとともに座って食べたり飲んだりしてはならない。」</span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 25:10; エレミヤ書 7:34; エゼキエル書 26:13"> イスラエルの神、万軍の主はこう言われる。「見よ、わたしはあなたの目の前で、あなたの生きている間に、この場所から喜びの声と楽しみの声、花婿の声と花嫁の声を絶えさせる。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 5:19; 列王記第一 9:8–9; 申命記 29:24–25"> あなたがこの民にこれらすべての言葉を告げると、彼らはあなたに、『なぜ、主はこの大きな災いをすべて私たちに告げられたのか』『私たちの咎は何か』『私たちの神、主に対して犯した罪は何か』と尋ねるだろう。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 106:35–41; 申命記 29:25–26; エレミヤ書 22:9"> その時、あなたは彼らにこう言え。『あなたがたの父祖がわたしを捨てたからだ』と、主は言われる。『彼らはほかの神々に従って歩み、それらに仕え、それらを拝み、わたしを捨て、わたしの律法を守らなかった。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 13:10; エレミヤ書 7:26; 伝道者の書 9:3"> あなたがたは父祖たちよりもさらに悪いことを行った。見よ、あなたがたはそれぞれ、自分の悪い心のかたくなさに従って歩み、わたしに聞き従わない。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 28:36; 申命記 4:26–28; エレミヤ書 15:14"> それゆえ、わたしはあなたがたをこの地から、あなたがたも父祖たちも知らなかった地へ投げ出す。そこであなたがたは昼も夜も、ほかの神々に仕える。わたしはあなたがたに恵みを示さない。』」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 23:7–8; 申命記 15:15; 出エジプト記 20:2"> 「それゆえ、見よ、『イスラエルの子らをエジプトの地から連れ上った主は生きておられる』とは、もはや言われなくなる日々が来る」と、主は言われる。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 3:18; エレミヤ書 24:6; エレミヤ書 32:37"> かえって、『イスラエルの子らを北の地から、また主が彼らを追いやったすべての国々から連れ上った主は生きておられる』と言われる。わたしは彼らを、父祖たちに与えた彼らの地へ再び連れ帰る。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ハバクク書 1:14–15; アモス書 4:2; ミカ書 7:2"> 「見よ、わたしは多くの漁師を呼び寄せる」と、主は言われる。「彼らは民を釣り上げる。その後、わたしは多くの狩人を呼び寄せる。彼らはあらゆる山、あらゆる丘、岩の裂け目から民を狩り出す。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 15:3; エレミヤ書 23:24; 箴言 5:21"> わたしの目は彼らのすべての道に注がれている。それらはわたしの顔から隠されず、彼らの咎もわたしの目から隠されない。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 35:33–34; イザヤ書 40:2; ヨハネの黙示録 18:6"> まず、わたしは彼らの咎と罪に二倍の報いを返す。彼らが忌まわしいものの死骸でわたしの地を汚し、忌むべきものでわたしの相続地を満たしたからだ。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 25:4; エレミヤ書 17:17; ナホム書 1:7"> <span className="pl pl-1">主よ、私の力、私のとりで、</span><br /><span className="pl pl-2">苦難の日の私の逃れ場よ、</span><br /><span className="pl pl-1">諸国民は地の果てからあなたのもとに来て、</span><br /><span className="pl pl-2">こう言う。</span><br /><span className="pl pl-1">「私たちの父祖が受け継いだものは、偽り、</span><br /><span className="pl pl-2">空しいもの、何の益もないものだけでした。</span></span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 37:19; 詩篇 115:4–8; ガラテヤ人への手紙 4:8"> <span className="pl pl-1">人は自分のために神々を造るでしょうか。</span><br /><span className="pl pl-2">それらは神ではない。」</span></span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 1:15; ダニエル書 2:37–38; 列王記第二 25:1–9"> バビロンの王ネブカドネザルが、その全軍、彼の支配下にある地のすべての王国、すべての民とともに、エルサレムとそのすべての町々を攻めていた時、主の言葉がエレミヤに臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 21:10; エレミヤ書 34:22; エレミヤ書 37:8–10"> 「イスラエルの神、主はこう言われる。『行って、ユダの王ゼデキヤに語り、こう告げよ。主はこう言われる。「見よ、わたしはこの町をバビロンの王の手に渡す。彼はこれを火で焼く。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 32:4; エレミヤ書 21:7; 列王記第二 25:4–7"> あなたは彼の手から逃れられず、必ず捕らえられ、その手に渡される。あなたはバビロンの王と顔を合わせ、彼はあなたと直接語る。あなたはバビロンへ行く。」』</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> しかし、ユダの王ゼデキヤよ、主の言葉を聞け。主はあなたについてこう言われる。『あなたは剣で死ぬことはない。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 22:18; 歴代誌 第二 16:14; 列王記第二 22:20"> あなたは平安のうちに死ぬ。あなたより前にいた先代の王である父祖たちのために火をたいたように、人々はあなたのためにも火をたく。そして、「ああ、主君よ」と、あなたのために嘆く。わたしがこの言葉を語ったからだ』と、主は言われる。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="サムエル記第一 15:16–24; サムエル記第一 3:18; 列王記第一 21:19"> 預言者エレミヤは、エルサレムでユダの王ゼデキヤにこれらすべての言葉を語った。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 10:3; エレミヤ書 4:5; 列王記第二 18:13–14"> その時、バビロンの王の軍隊は、エルサレムと、残っていたユダのすべての町々、すなわちラキシュとアゼカを攻めていた。ユダの町々のうち、城壁のある町として残っていたのは、この二つだけであった。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="レビ記 25:10; 列王記第二 23:2–3; 列王記第二 11:17"> ゼデキヤ王がエルサレムにいるすべての民と契約を結び、彼らに解放を宣言した後、主からエレミヤに言葉が臨んだ。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 15:12; レビ記 25:39–46; 出エジプト記 3:18"> それは、各自がヘブル人である男奴隷と女奴隷を自由にし、だれもユダヤ人である兄弟を奴隷として使ってはならないというものであった。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 26:16; エレミヤ書 26:10; エレミヤ書 38:4"> この契約に加わったすべての高官とすべての民は、各自が男奴隷と女奴隷を自由にし、もはや彼らを奴隷として使わないという契約に従い、奴隷たちを自由にした。</span>
<span className="v" id="v11" data-v="11" data-xref="ペテロの第二の手紙 2:20–22; 箴言 26:11; マタイ 12:43–45"> しかし、その後、彼らは心を変え、自由にした男奴隷と女奴隷を連れ戻し、再び奴隷として働かせた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> そこで、主の言葉がエレミヤに臨んだ。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 6:8; ヨシュア記 24:17; 申命記 5:27"> 「イスラエルの神、主はこう言われる。『わたしは、あなたがたの父祖をエジプトの地、奴隷の家から連れ出した日に、彼らと契約を結び、こう言った。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 15:12; 列王記第一 9:22; 列王記第二 17:13–14"> 「七年の終わりに、あなたがたはそれぞれ、あなたに身を売り、六年間仕えたヘブル人の兄弟を解放しなければならない。彼をあなたのもとから自由に去らせよ。」しかし、あなたがたの父祖はわたしに聞き従わず、耳を傾けなかった。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 34:8; 列王記第二 23:3; ネヘミヤ記 10:29"> あなたがたは今、立ち返って、各自が隣人に解放を宣言し、わたしの目に正しいことを行った。そして、わたしの名で呼ばれる家で、わたしの前に契約を結んだ。</span>
<span className="v" id="v16" data-v="16" data-xref="レビ記 19:12; 出エジプト記 20:7; エレミヤ書 34:11"> しかし、あなたがたは再び心を変えて、わたしの名を汚した。各自が、自由に去らせた男奴隷と女奴隷を連れ戻し、再び自分たちの奴隷として働かせた。』」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="マタイ 7:2; 申命記 28:25; ガラテヤ人への手紙 6:7"> それゆえ、主はこう言われる。「あなたがたはわたしに聞き従わず、各自が兄弟と隣人に解放を宣言しなかった。見よ、わたしはあなたがたに自由を宣言する」と、主は言われる。「剣と疫病と飢饉に渡される自由を。わたしはあなたがたを地のすべての王国の間をさまよう者とする。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 15:10; 創世記 15:17–18; ホセア書 6:7"> わたしの契約に背き、わたしの前で結んだ契約の言葉を果たさなかった者たちを、わたしは引き渡す。彼らは子牛を二つに切り、その二つの部分の間を通った。</span>
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 34:10; ゼパニヤ書 3:3–4; ダニエル書 9:6"> ユダの高官たち、エルサレムの高官たち、宦官たち、祭司たち、この地のすべての民が、その子牛の二つの部分の間を通った。</span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 7:33; エレミヤ書 16:4; エレミヤ書 19:7"> わたしは彼らを敵の手と、彼らの命を狙う者たちの手に渡す。彼らの死体は空の鳥と地の動物の餌となる。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 52:24–27; エレミヤ書 39:6; エレミヤ書 52:10"> わたしはユダの王ゼデキヤとその高官たちを、敵の手、彼らの命を狙う者たちの手、また、あなたがたのところから退いたバビロンの王の軍隊の手に渡す。</span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 9:11; エレミヤ書 39:8; エレミヤ書 39:1–2"> 見よ、わたしは命じる」と、主は言われる。「彼らをこの町に戻らせる。彼らはこの町を攻め、占領し、火で焼く。わたしはユダの町々を荒れ果てさせ、住む者のない所とする。」</span>
</div>

<span className="v" id="v3" data-v="3" data-xref="アモス書 9:14–15; エレミヤ書 32:37; イザヤ書 43:5–6"> 「わたしは、自分が追いやったすべての国々から、わたしの群れの残りの者を集め、再びその囲いに連れ戻す。彼らは実を結び、数を増す。</span>

<span className="v" id="v5" data-v="5" data-xref="ルカ 1:32–33; イザヤ書 4:2; イザヤ書 9:7"> <span className="pl pl-1">「見よ、その日々が来る」と、主は言われる。</span><br /><span className="pl pl-2">「その時、わたしはダビデのために義の若枝を起こす。</span><br /><span className="pl pl-1">彼は王として治め、知恵をもって行い、</span><br /><span className="pl pl-2">この地に公正と義を行う。</span></span>

<span className="v" id="v8" data-v="8" data-xref="イザヤ書 43:5–6; アモス書 9:14–15; エゼキエル書 34:13"> かえって、『イスラエルの家の子孫を北の地から、また、わたしが彼らを追いやったすべての国々から連れ上り、導いた主は生きておられる』と言われる。彼らは自分たちの地に住む。」</span>
</div>

<div className="bp poetry">

<span className="v" id="v14" data-v="14" data-xref="イザヤ書 1:9–10; エレミヤ書 29:23; エゼキエル書 22:25"> <span className="pl pl-1">エルサレムの預言者たちの中にも、恐ろしいことを見た。</span><br /><span className="pl pl-2">彼らは姦淫し、偽りのうちを歩む。</span><br /><span className="pl pl-1">悪を行う者たちの手を強め、</span><br /><span className="pl pl-2">だれも自分の悪から立ち返らないようにしている。</span><br /><span className="pl pl-1">彼らは皆、わたしにとってソドムのようになり、</span><br /><span className="pl pl-2">その住民はゴモラのようになった。」</span></span>

<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 23:22; イザヤ書 40:13–14; アモス書 3:7"> <span className="pl pl-1">だれが主の会議に立ち、</span><br /><span className="pl pl-2">その言葉を悟り、聞いたのか。</span><br /><span className="pl pl-2">だれがわたしの言葉に耳を傾けて聞いたのか。</span></span>
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 30:23; エレミヤ書 25:32; アモス書 1:14"> <span className="pl pl-1">見よ、主の嵐、主の憤りが出て行く。</span><br /><span className="pl pl-2">まさに、渦巻く嵐が、</span><br /><span className="pl pl-2">悪者の頭上に激しく襲いかかる。</span></span>

<span className="v" id="v27" data-v="27" data-xref="士師記 8:33–34; 士師記 3:7; 使徒の働き 13:8"> 彼らは、互いに語り合う夢によって、わたしの民にわたしの名を忘れさせようとしている。彼らの父祖がバアルのためにわたしの名を忘れたように。</span>
<span className="v" id="v28" data-v="28" data-xref="コリント人への第二の手紙 2:17; テモテへの手紙第一 1:12; コリント人への第一の手紙 3:12–13"> 夢を見た預言者は夢を語れ。わたしの言葉を持つ者は、わたしの言葉を忠実に語れ。わらと小麦に何の関わりがあるのか」と、主は言われる。</span>
<span className="v" id="v29" data-v="29" data-xref="ヘブル人への手紙 4:12; エレミヤ書 5:14; ルカ 24:32"> 「わたしの言葉は火のようではないか」と、主は言われる。「岩を打ち砕く金槌のようではないか。」</span>
</div>
<div className="bp">

<span className="v" id="v34" data-v="34" data-xref="ゼカリヤ書 13:3; 哀歌 2:14"> 預言者でも祭司でも民でも、『主からの託宣』と言う者を、わたしはその人とその家族とともに罰する。</span>
<span className="v" id="v35" data-v="35" data-xref="エレミヤ書 31:34; エレミヤ書 42:4; エレミヤ書 33:3"> あなたがたは、それぞれ隣人や兄弟に、『主は何と答えられたか』『主は何と語られたか』と言いなさい。</span>
<span className="v" id="v36" data-v="36" data-xref="エレミヤ書 10:10; ペテロの第二の手紙 3:16; イザヤ書 3:8"> もう『主からの託宣』と言ってはならない。人はそれぞれ自分の言葉を託宣としているからだ。あなたがたは、生ける神、万軍の主、私たちの神の言葉を曲げている。</span>

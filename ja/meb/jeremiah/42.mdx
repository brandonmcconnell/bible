<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 41:11; エレミヤ書 40:13; エレミヤ書 6:13"> その時、軍隊のすべての隊長たち、カレアの子ヨハナン、ホシャヤの子エザヌヤ、および小さい者から大きい者まで、すべての民が近づいて来て、</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 36:7; レビ記 26:22; 使徒の働き 8:24"> 預言者エレミヤに言った。「どうか、私たちの願いを受け入れ、あなたの神、主に、残された私たちすべてのために祈ってください。ご覧のとおり、多くの者の中から、私たちはわずかしか残っていません。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 86:11; 箴言 3:6; 詩篇 25:4–5"> あなたの神、主が、私たちの歩むべき道と、行うべきことを示してくださるようにしてください。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="サムエル記第一 12:23; サムエル記第一 3:17–18; 出エジプト記 8:29"> 預言者エレミヤは彼らに言った。「分かりました。私はあなたがたの言葉どおり、あなたがたの神、主に祈ります。主があなたがたに答えられることは、何であってもあなたがたに告げます。何一つ隠しません。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 31:50; 士師記 11:10; マラキ書 3:5"> すると彼らはエレミヤに言った。「もし私たちが、あなたの神、主があなたを遣わして私たちに告げられるすべての言葉のとおりに行わないなら、主が私たちに対する真実で忠実な証人となられますように。</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 7:23; 申命記 5:29; ローマ人への手紙 8:7"> 良くても悪くても、私たちは、私たちがあなたを遣わして尋ねる神、主の声に聞き従います。私たちの神、主の声に聞き従うなら、私たちは幸いを得るからです。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="詩篇 27:14; イザヤ書 28:16; ハバクク書 2:3"> 十日後、主の言葉がエレミヤに臨んだ。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 42:1; エレミヤ書 41:11–16; エレミヤ書 43:2–5"> そこで彼はカレアの子ヨハナン、彼とともにいた軍隊のすべての隊長たち、および小さい者から大きい者まで、すべての民を呼び、</span>
<span className="v" id="v9" data-v="9" data-xref="列王記第二 19:4; エレミヤ書 42:2; 列王記第二 19:6"> 彼らに言った。「あなたがたが、願いを御前に申し上げるために私を遣わした、イスラエルの神、主はこう言われる。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 31:28; エゼキエル書 36:36; エレミヤ書 24:6"> 『あなたがたがこの地にとどまって住むなら、わたしはあなたがたを建てて、打ち壊さず、植えて、引き抜かない。わたしがあなたがたにもたらした災いのために心を痛めているからだ。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 8:31; エレミヤ書 1:19; エレミヤ書 1:8"> あなたがたが恐れているバビロンの王を恐れてはならない。彼を恐れてはならない』と、主は言われる。『わたしがあなたがたとともにいて、あなたがたを救い、彼の手から救い出すからだ。</span>
<span className="v" id="v12" data-v="12" data-xref="ネヘミヤ記 1:11; 詩篇 106:45–46; 箴言 16:7"> わたしはあなたがたにあわれみを与える。彼はあなたがたをあわれみ、あなたがた自身の地に帰らせる。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 44:16; 出エジプト記 5:2; エレミヤ書 42:10"> しかし、あなたがたが自分たちの神、主の声に聞き従わず、「私たちはこの地に住まない」と言い、</span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 41:17; エレミヤ書 4:19; イザヤ書 31:1"> 「いや、私たちはエジプトの地へ行こう。そこでは戦争を見ることも、ラッパの音を聞くことも、パンに飢えることもない。私たちはそこに住もう」と言うなら』、</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 17:16; エレミヤ書 44:12–14; エレミヤ書 42:17"> ユダの残りの者よ、今、主の言葉を聞け。イスラエルの神、万軍の主はこう言われる。『あなたがたがどうしてもエジプトへ入ろうと顔を向け、そこへ行って寄留するなら、</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 44:27; エゼキエル書 11:8; アモス書 9:1–4"> あなたがたが恐れている剣は、エジプトの地であなたがたに追いつく。あなたがたが心配している飢饉も、エジプトであなたがたの後を追う。あなたがたはそこで死ぬ。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 42:22; エレミヤ書 44:28; エレミヤ書 44:13–14"> エジプトへ行って寄留しようと顔を向ける者は皆、剣と飢饉と疫病によって死ぬ。わたしが彼らにもたらす災いから、一人も残らず、だれも逃れることはない。』</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 7:20; エレミヤ書 18:16; エレミヤ書 29:18"> イスラエルの神、万軍の主はこう言われる。『わたしの怒りと憤りがエルサレムの住民に注がれたように、あなたがたがエジプトへ入る時、わたしの憤りはあなたがたに注がれる。あなたがたは恐怖の的、驚きの的、呪いの的、そしりの的となり、二度とこの場所を見ることはない。』</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命記 17:16; イザヤ書 30:1–7; ネヘミヤ記 9:26"> ユダの残りの者よ、主はあなたがたについて、『エジプトへ行ってはならない』と語られた。私が今日、あなたがたに厳しく警告したことを確かに知りなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 14:3–4; エゼキエル書 33:31; マタイ 22:15–18"> あなたがたは自分自身を欺いた。あなたがたは私を自分たちの神、主のもとへ遣わし、『私たちのために、私たちの神、主に祈ってください。私たちの神、主が言われることをすべて私たちに告げてください。私たちはそれを行います』と言った。</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 2:7; ゼカリヤ書 7:11–12; 使徒の働き 20:26–27"> 私は今日、あなたがたに告げた。しかし、あなたがたは、あなたがたの神、主が私を遣わして告げさせたことに、何一つ聞き従わなかった。</span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 42:17; エゼキエル書 6:11; ホセア書 9:6"> それゆえ今、あなたがたが行って寄留したいと願っている場所で、剣と飢饉と疫病によって死ぬことを確かに知りなさい。」</span>
</div>

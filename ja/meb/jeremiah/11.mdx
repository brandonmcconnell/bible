<span className="v" id="v1" data-v="1"> 主からエレミヤに臨んだ言葉。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 11:6; 出エジプト記 19:5; 歴代誌 第二 29:10"> 「この契約の言葉を聞き、ユダの人々とエルサレムの住民に語れ。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 27:26; 申命記 28:15–68; 申命記 29:19–20"> 彼らにこう言え。『イスラエルの神、主はこう言われる。この契約の言葉を聞かない者は呪われる。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 26:12; エレミヤ書 7:22–23; 申命記 4:20"> この契約は、わたしがあなたがたの父祖をエジプトの地、鉄の炉から連れ出した日に、彼らに命じたものである。その時、わたしはこう言った。「わたしの声に聞き従い、わたしがあなたがたに命じるすべてのことを行え。そうすれば、あなたがたはわたしの民となり、わたしはあなたがたの神となる。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 7:12–13; 詩篇 105:9–11; エレミヤ書 28:6"> こうして、乳と蜜の流れる地を彼らに与えると、わたしがあなたがたの父祖に誓った誓いを果たす。」今日あるとおりである。』」<br />そこで私は答えた。「アーメン、主よ。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヤコブの手紙 1:22; ローマ人への手紙 2:13; エレミヤ書 7:2"> 主は私に言われた。「これらの言葉をすべてユダの町々とエルサレムの通りで告げ知らせ、こう言え。『この契約の言葉を聞き、それを行え。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌 第二 36:15; エペソ人への手紙 4:17; サムエル記第一 8:9"> わたしは、あなたがたの父祖をエジプトの地から連れ上った日から今日に至るまで、朝早くから繰り返し彼らに警告し、「わたしの声に聞き従え」と言い続けた。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 7:24; エレミヤ書 7:26; エレミヤ書 35:15"> しかし、彼らは聞かず、耳を傾けず、それぞれ自分の悪い心のかたくなさに従って歩んだ。それゆえ、わたしはこの契約の言葉をすべて彼らの上にもたらした。わたしが行うように命じたのに、彼らは行わなかったからだ。』」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ホセア書 6:9; マタイ 26:3–4; ミカ書 3:11"> 主は私に言われた。「ユダの人々とエルサレムの住民の間に、陰謀が見つかった。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 31:16; エゼキエル書 16:59; 詩篇 78:8–10"> 彼らは、わたしの言葉を聞くことを拒んだ先祖たちの不義に立ち返った。ほかの神々に従って行き、これらに仕えた。イスラエルの家とユダの家は、わたしが彼らの父祖と結んだ契約を破った。</span>
<span className="v" id="v11" data-v="11" data-xref="エゼキエル書 8:18; 箴言 1:28; イザヤ書 1:15"> それゆえ、主はこう言われる。『見よ、わたしは彼らの上に災いをもたらす。彼らはそこから逃れることができない。彼らがわたしに叫んでも、わたしは彼らの願いを聞かない。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 2:28; 申命記 32:37; 歴代誌 第二 28:22"> その時、ユダの町々とエルサレムの住民は、自分たちが香をたいている神々のもとへ行って叫ぶ。しかし、それらは彼らの苦難の時に、決して彼らを救うことができない。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 2:28; 列王記第二 23:13; イザヤ書 2:8"> ユダよ、あなたの神々は、あなたの町々と同じ数だけいる。あなたがたはエルサレムの通りと同じ数だけ、恥ずべきもののために祭壇、すなわちバアルに香をたく祭壇を築いた。』」</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 7:16; エレミヤ書 11:11; ヨハネの手紙第一 5:16"> 「それゆえ、この民のために祈ってはならない。彼らのために叫びや祈りを上げてはならない。彼らが災いのためにわたしに叫ぶ時、わたしは彼らの願いを聞かない。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 2:14; テトス 1:15; エレミヤ書 3:1–2"> <span className="pl pl-1">わたしの愛する者が、</span><br /><span className="pl pl-2">多くの者とみだらなことを行いながら、わたしの家で何をしているのか。</span><br /><span className="pl pl-2">聖なる肉はあなたから取り去られた。</span><br /><span className="pl pl-1">あなたは悪を行いながら、</span><br /><span className="pl pl-2">それを喜んでいる。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 11:17–24; イザヤ書 27:11; 詩篇 52:8"> <span className="pl pl-1">主はあなたを、</span><br /><span className="pl pl-2">「美しく、良い実を結ぶ、青々としたオリーブの木」と名づけられた。</span><br /><span className="pl pl-1">しかし、大きなとどろきとともに、その木に火をつけられ、</span><br /><span className="pl pl-2">その枝々は折られた。</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 5:2; エレミヤ書 2:21; エレミヤ書 12:2"> あなたを植えた万軍の主は、あなたに災いを告げられた。イスラエルの家とユダの家が、自らに災いを招く悪を行い、バアルに香をたいて、わたしを怒らせたからだ。</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="サムエル記第一 23:11–12; 列王記第二 6:9–10; エゼキエル書 8:6–18"> 主が私に知らせてくださったので、私はそれを知った。その時、あなたは彼らの行いを私に示された。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 53:7–8; エレミヤ書 20:10; 詩篇 83:4"> しかし、私は屠り場に引かれて行くおとなしい子羊のようであった。彼らが私に対して計略を巡らせていたことを、私は知らなかった。彼らは言っていた。<br /><span className="pl pl-1">「木をその実とともに滅ぼそう。</span><br /><span className="pl pl-2">彼を生ける者の地から断ち、</span><br /><span className="pl pl-2">その名が二度と思い出されないようにしよう。」</span></span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 20:12; エレミヤ書 17:10; サムエル記第一 16:7"> <span className="pl pl-1">しかし、正しく裁き、</span><br /><span className="pl pl-2">心と思いを試される万軍の主よ、</span><br /><span className="pl pl-1">あなたが彼らに報復されるのを、私は見る。</span><br /><span className="pl pl-2">私の訴えをあなたに委ねたのだから。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 20:10; アモス書 2:12; ルカ 13:33–34"> それゆえ、あなたの命を狙い、「主の名によって預言してはならない。そうしなければ、私たちの手で死ぬことになる」と言うアナトテの人々について、主はこう言われる。</span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 18:21; 歴代誌 第二 36:17; エレミヤ書 9:21"> それゆえ、万軍の主はこう言われる。「見よ、わたしは彼らを罰する。若者たちは剣で死に、息子たちと娘たちは飢饉で死ぬ。</span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 23:12; ミカ書 7:4; ホセア書 9:7"> 彼らには一人の残りの者もいなくなる。わたしがアナトテの人々に、彼らを罰する年に災いをもたらすからだ。」</span>
</div>

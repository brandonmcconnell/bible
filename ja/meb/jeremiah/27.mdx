<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 27:3; エレミヤ書 28:1; エレミヤ書 27:12"> ユダの王ヨシヤの子エホヤキムの治世の初めに、主からエレミヤにこの言葉が臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="アモス書 7:1; アモス書 7:4; エレミヤ書 27:12"> 主は私にこう言われる。「縄とくびきの横木を作り、自分の首につけよ。</span>
<span className="v" id="v3" data-v="3" data-xref="アモス書 1:9–3; エゼキエル書 25:1–17; エゼキエル書 17:15–21"> それらを、ユダの王ゼデキヤのもとへエルサレムに来た使者たちの手によって、エドムの王、モアブの王、アンモンの子らの王、ツロの王、シドンの王に送れ。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 51:19; エレミヤ書 10:10; エレミヤ書 25:27"> 彼らの主人たちにこう命じよ。『イスラエルの神、万軍の主はこう言われる。あなたがたの主人たちにこう伝えよ。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 32:17; エレミヤ書 51:15; 詩篇 115:15–16"> 「わたしは大いなる力と伸ばした腕によって、地と、地の表にいる人と動物を造った。わたしは、自分の目に良いと思う者にそれを与える。</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 28:14; エレミヤ書 25:9; ダニエル書 2:37–38"> 今、わたしはこれらすべての国々を、わたしのしもべであるバビロンの王ネブカドネザルの手に与えた。野の動物も彼に仕えさせるために与えた。</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 52:31; ヨハネの黙示録 13:5–10; ダニエル書 5:25–31"> すべての国々は、彼とその子とその孫に仕える。やがて彼の国の時も来る。その時、多くの国々と大いなる王たちが彼を奴隷として使う。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 14:21; エゼキエル書 17:19–21; エレミヤ書 38:17–19"> バビロンの王ネブカドネザルに仕えず、その首をバビロンの王のくびきの下に置かない国と王国を、わたしは剣と飢饉と疫病で罰する」と、主は言われる。「ついには彼の手によって彼らを滅ぼし尽くす。</span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 14:14; マラキ書 3:5; エレミヤ書 29:8"> あなたがたは、自分たちの預言者、占い師、夢、兆しを解く者、呪術師の言葉を聞いてはならない。彼らは、『あなたがたはバビロンの王に仕えることはない』と語る。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 32:31; エレミヤ書 28:16; エレミヤ書 23:25"> 彼らはあなたがたに偽りを預言して、あなたがたを自分たちの地から遠く離れさせようとしている。そのため、わたしはあなたがたを追い出し、あなたがたは滅びる。</span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 27:8; エレミヤ書 27:2; エレミヤ書 38:2"> しかし、首をバビロンの王のくびきの下に置いて彼に仕える国は、その地にとどまらせる」と、主は言われる。「彼らはそこで耕し、そこに住む。」』」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 28:1; エレミヤ書 38:17; 歴代誌 第二 36:11–13"> 私はユダの王ゼデキヤにも、これらすべての言葉に従って語った。「あなたがたの首をバビロンの王のくびきの下に置き、彼とその民に仕えて生きなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 18:31; エレミヤ書 27:8; 箴言 8:36"> なぜ、あなたとあなたの民は、バビロンの王に仕えない国について主が語られたとおり、剣と飢饉と疫病によって死ななければならないのですか。</span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 14:14; コリント人への第二の手紙 11:13–15; エレミヤ書 29:8–9"> 『あなたがたはバビロンの王に仕えることはない』と語る預言者たちの言葉を聞いてはなりません。彼らはあなたがたに偽りを預言しているからです。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 27:10; 歴代誌 第二 25:16; エレミヤ書 6:13–15"> 『わたしは彼らを遣わしていない』と、主は言われます。『それなのに、彼らはわたしの名によって偽って預言している。そのため、わたしはあなたがたを追い出し、あなたがたも、あなたがたに預言する預言者たちも滅びる。』」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王記第二 24:13; エレミヤ書 28:3; ダニエル書 1:2"> 私は祭司たちとこのすべての民にも語った。「主はこう言われる。『「見よ、主の家の器は間もなくバビロンから持ち帰られる」と、あなたがたに預言する預言者たちの言葉を聞いてはならない。彼らはあなたがたに偽りを預言しているからだ。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 38:17; エレミヤ書 38:23; エレミヤ書 7:34"> 彼らに聞いてはならない。バビロンの王に仕えて生きよ。なぜ、この町を荒れ果てた所としなければならないのか。</span>
<span className="v" id="v18" data-v="18" data-xref="サムエル記第一 7:8; エレミヤ書 18:20; サムエル記第一 12:19"> もし彼らが預言者であり、主の言葉が彼らとともにあるなら、主の家、ユダの王の家、エルサレムに残っている器がバビロンへ運ばれないよう、今、万軍の主に執り成すがよい。</span>
<span className="v" id="v19" data-v="19" data-xref="列王記第二 25:13; エレミヤ書 52:17–23; 列王記第二 25:17"> 万軍の主は、柱、海、台、またこの町に残っているその他の器について、こう言われる。</span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 24:1; 歴代誌 第二 36:10; 列王記第二 24:14–16"> バビロンの王ネブカドネザルは、ユダの王エホヤキムの子エコニヤと、ユダとエルサレムのすべての高貴な者たちを、エルサレムからバビロンへ捕らえて行った時、それらを持ち去らなかった。</span>
<span className="v" id="v21" data-v="21"> そうだ。イスラエルの神、万軍の主は、主の家、ユダの王の家、エルサレムに残っている器について、こう言われる。</span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 29:10; エズラ記 7:19; エレミヤ書 32:5"> 「それらはバビロンへ運ばれ、わたしがそれらを顧みる日まで、そこに置かれる」と、主は言われる。「その後、わたしはそれらを運び上げ、この場所に戻す。」』」</span>
</div>

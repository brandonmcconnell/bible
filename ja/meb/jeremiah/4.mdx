<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨエル書 2:12; エレミヤ書 3:22; エレミヤ書 3:12"> 「イスラエルよ、あなたが帰るのなら」と、主は言われる。「わたしのもとに帰れ。あなたが忌まわしいものをわたしの前から取り除くなら、あなたは追い払われることはない。</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 65:16; エレミヤ書 9:24; 創世記 22:18"> また、真実と公正と義をもって、『主は生きておられる』と誓うなら、諸国民は主によって自らを祝福し、主を誇る。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ホセア書 10:12; ルカ 8:7; ルカ 8:14"> 主はユダの人々とエルサレムにこう言われる。「耕されていない土地を耕せ。茨の中に種を蒔いてはならない。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 10:16; 申命記 30:6; ローマ人への手紙 2:28–29"> ユダの人々とエルサレムの住民よ、主のために割礼を受け、心の包皮を取り除け。そうしなければ、あなたがたの行いが悪いために、わたしの憤りが火のように燃え上がり、だれにも消せなくなる。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 8:14; エレミヤ書 6:1; ヨシュア記 10:20"> ユダで告げ、エルサレムで知らせよ。こう言え。『この地でラッパを吹け』と。大声で叫び、こう言え。『集まれ。城壁のある町々に入ろう』と。</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 50:2; エレミヤ書 1:13–15; エレミヤ書 51:27"> シオンに向けて旗印を掲げよ。安全な所へ逃げよ。立ち止まってはならない。わたしが北から災いと大いなる破滅をもたらすからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 1:7; エレミヤ書 5:6; イザヤ書 6:11"> 獅子が茂みから上って来た。国々を滅ぼす者が進み出た。彼は自分の場所を出て、あなたの地を荒れ果てさせようとしている。あなたの町々は廃墟となり、住む者はいなくなる。</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 22:12; エレミヤ書 6:26; イザヤ書 10:4"> このために、粗布をまとい、嘆き、泣き叫べ。主の燃える怒りが、私たちから離れていないからだ。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 13:9–16; イザヤ書 29:9–10; イザヤ書 22:3–5"> 「その日には」と、主は言われる。「王も高官たちも勇気を失う。祭司たちは驚き、預言者たちは驚き惑う。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 5:12; テサロニケ人への第二の手紙 2:9–12; イザヤ書 37:35"> そこで私は言った。「ああ、主なる神よ。あなたはこの民とエルサレムをまことに欺き、『あなたがたには平和がある』と言われた。しかし、剣は命にまで迫っている。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ホセア書 13:15; エゼキエル書 17:10; エレミヤ書 23:19"> その時、この民とエルサレムにこう言われる。「荒野の裸の高台から、娘なるわたしの民に向かって熱風が吹いて来る。穀物をふるい分けるためでも、清めるためでもない。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 1:16; エゼキエル書 5:8; エゼキエル書 6:11–13"> これらの高台から、さらに激しい風が、わたしのために吹いて来る。今、わたしも彼らに裁きを言い渡す。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 19:1; イザヤ書 66:15; ハバクク書 1:8"> 見よ、彼は雲のように上って来る。その戦車はつむじ風のようだ。その馬は鷲よりも速い。ああ、私たちは滅ぼされる。</span>
<span className="v" id="v14" data-v="14" data-xref="ヤコブの手紙 4:8; イザヤ書 55:7; 使徒の働き 8:22"> エルサレムよ、救われるために、悪から心を洗い清めよ。いつまで、悪い思いを自分の内に宿しておくのか。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 8:16; ヨシュア記 17:15; 士師記 18:29"> ダンから声が告げ、エフライムの丘々から災いを知らせている。</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 5:15; エゼキエル書 21:22; イザヤ書 39:3"> 「諸国民に告げよ。見よ、エルサレムに向かって知らせよ。『遠い国から見張る者たちが来て、ユダの町々に向かって声を上げる。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 5:23; 列王記第二 25:1–4; ネヘミヤ記 9:30"> 畑を守る者たちのように、彼らはエルサレムを四方から取り囲む。彼女がわたしに逆らったからだ』」と、主は言われる。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 2:19; 詩篇 107:17; 箴言 1:31"> 「あなたの道と行いが、これらのことをあなたにもたらした。これがあなたの悪である。それは苦く、あなたの心にまで達している。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ハバクク書 3:16; イザヤ書 16:11; イザヤ書 22:4"> 私の苦しみよ、私の苦しみよ。胸の奥が痛む。胸が激しく鳴る。黙ってはいられない。私はラッパの音を、戦いの警報を聞いてしまった。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 42:7; マタイ 10:28; ヨエル書 1:15"> 破滅に次ぐ破滅が告げられ、全地が荒らされる。突然、私の天幕は破壊され、一瞬のうちに幕が失われる。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代誌 第二 36:10; 歴代誌 第二 36:3; 歴代誌 第二 36:6–7"> いつまで私は旗印を見、ラッパの音を聞かなければならないのか。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="コリント人への第一の手紙 14:20; ローマ人への手紙 16:19; エレミヤ書 5:21"> 「わたしの民は愚かで、わたしを知らない。彼らは愚かな子らで、悟りがない。悪を行うことには熟練しているが、良いことを行うことを知らない。」</span>
<span className="v" id="v23" data-v="23" data-xref="マタイ 24:29; マルコ 13:24–25; イザヤ書 13:10"> 私が地を見ると、見よ、それは荒れ果て、むなしかった。天を見ても、そこに光はなかった。</span>
<span className="v" id="v24" data-v="24" data-xref="エゼキエル書 38:20; イザヤ書 5:25; ナホム書 1:5–6"> 私が山々を見ると、見よ、それらは震え、すべての丘が揺れ動いていた。</span>
<span className="v" id="v25" data-v="25" data-xref="ゼパニヤ書 1:2–3; エレミヤ書 12:4; エレミヤ書 9:10"> 私が見ると、見よ、人は一人もおらず、空の鳥も皆、逃げ去っていた。</span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 107:34; エレミヤ書 12:4; エレミヤ書 14:2–6"> 私が見ると、見よ、実り豊かな地は荒野となり、そのすべての町は主の御前で、その燃える怒りによって打ち壊されていた。</span>
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 46:28; エレミヤ書 5:10; エレミヤ書 5:18"> 主はこう言われる。「全地は荒れ果てる。しかし、わたしは完全には滅ぼさない。</span>
<span className="v" id="v28" data-v="28" data-xref="民数記 23:19; イザヤ書 50:3; ホセア書 4:3"> このために、地は嘆き、上の天は暗くなる。わたしがこれを語り、計画したからだ。わたしは思い直さず、これを取りやめない。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 2:19–21; エレミヤ書 4:7; エレミヤ書 52:7"> 騎兵と弓を射る者たちの物音を聞いて、どの町も逃げ去る。人々は茂みに入り、岩の上に登る。すべての町は見捨てられ、そこに住む者は一人もいない。</span>
<span className="v" id="v30" data-v="30" data-xref="列王記第二 9:30; 哀歌 1:2; 哀歌 1:19"> 荒らされた者よ、あなたはどうするのか。緋色の服をまとい、金の飾りで身を飾り、化粧で目を大きく見せても、美しく装うのは無駄である。あなたの愛人たちはあなたをさげすみ、あなたの命を狙っている。</span>
<span className="v" id="v31" data-v="31" data-xref="哀歌 1:17; イザヤ書 1:15; エレミヤ書 13:21"> 私は、産みの苦しみにある女のような声、初めての子を産む女のような苦悶の声を聞いた。息を切らし、両手を広げる娘なるシオンの声である。彼女は言う。「ああ、私は何と災いなことか。殺す者たちの前で、私は力尽きる。」</span>
</div>

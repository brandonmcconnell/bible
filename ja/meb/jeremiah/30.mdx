<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 26:15; エレミヤ書 1:1–2"> 主からエレミヤに臨んだ言葉。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 36:32; イザヤ書 30:8; ハバクク書 2:2–3"> 「イスラエルの神、主はこう言われる。『わたしがあなたに語ったすべての言葉を、一冊の書に書き記せ。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 29:14; エレミヤ書 16:15; エレミヤ書 30:18"> 見よ、その日々が来る』と、主は言われる。『その時、わたしはわたしの民イスラエルとユダを捕囚から帰らせる』と、主は言われる。『わたしが彼らの父祖に与えた地へ彼らを帰らせ、彼らはそれを所有する。』」</span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4"> 主がイスラエルとユダについて語られた言葉は、次のとおりである。</span>
<span className="v" id="v5" data-v="5" data-xref="ゼパニヤ書 1:10–11; アモス書 8:10; イザヤ書 5:30"> 主はこう言われる。<br /><span className="pl pl-1">「私たちは震えの声を聞いた。</span><br /><span className="pl pl-2">それは恐怖の声であり、平和の声ではない。</span></span>
<span className="v" id="v6" data-v="6" data-xref="ナホム書 2:10; ヨエル書 2:6; エレミヤ書 4:31"> <span className="pl pl-1">尋ねて、見よ。男が産みの苦しみをするだろうか。</span><br /><span className="pl pl-2">それなのに、なぜわたしは、すべての男が産みの苦しみにある女のように、両手を腰に当て、</span><br /><span className="pl pl-2">どの顔も青ざめているのを見るのか。</span></span>
<span className="v" id="v7" data-v="7" data-xref="ダニエル書 12:1; ゼカリヤ書 14:1–2; マラキ書 4:1"> <span className="pl pl-1">ああ、その日は大いなる日で、これに比べられる日はない。</span><br /><span className="pl pl-2">それはヤコブの苦難の時である。</span><br /><span className="pl pl-2">しかし、彼はそこから救われる。</span></span>
<span className="v" id="v8" data-v="8" data-xref="ナホム書 1:13; エゼキエル書 34:27; イザヤ書 9:4"> <span className="pl pl-1">その日には」と、万軍の主は言われる。「わたしはそのくびきをあなたの首から砕き、</span><br /><span className="pl pl-2">あなたの束縛を断ち切る。</span><br /><span className="pl pl-2">異国人が二度と彼らを奴隷にすることはない。</span></span>
<span className="v" id="v9" data-v="9" data-xref="ホセア書 3:5; イザヤ書 55:3–5; ルカ 1:69"> <span className="pl pl-1">彼らは自分たちの神、主に仕え、</span><br /><span className="pl pl-2">彼らの王ダビデにも仕える。</span><br /><span className="pl pl-2">わたしが彼を彼らのために起こす。</span></span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 46:27–28; イザヤ書 43:5; エレミヤ書 29:14"> <span className="pl pl-1">それゆえ、わたしのしもべヤコブよ、恐れてはならない」と、主は言われる。</span><br /><span className="pl pl-2">「イスラエルよ、うろたえてはならない。</span><br /><span className="pl pl-1">見よ、わたしは遠くからあなたを救い、</span><br /><span className="pl pl-2">あなたの子孫を捕囚の地から救う。</span><br /><span className="pl pl-1">ヤコブは帰り、</span><br /><span className="pl pl-2">静かに安らかに暮らす。</span><br /><span className="pl pl-2">彼を恐れさせる者はいない。</span></span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 10:24; エレミヤ書 1:19; イザヤ書 8:10"> <span className="pl pl-1">わたしはあなたとともにいて、あなたを救うからだ」と、主は言われる。</span><br /><span className="pl pl-2">「わたしがあなたを散らしたすべての国々を完全に滅ぼしても、</span><br /><span className="pl pl-2">あなたを完全には滅ぼさない。</span><br /><span className="pl pl-1">しかし、あなたを正しく懲らしめ、</span><br /><span className="pl pl-2">決して罰せずに済ませることはしない。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 15:18; エレミヤ書 30:15; エレミヤ書 14:17"> 主はこう言われる。<br /><span className="pl pl-1">「あなたの打ち傷は癒やしがたく、</span><br /><span className="pl pl-2">あなたの傷は重い。</span></span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 46:11; エレミヤ書 8:22; エレミヤ書 30:17"> <span className="pl pl-1">あなたの訴えを弁護する者はおらず、</span><br /><span className="pl pl-2">傷に包帯を巻く者もいない。</span><br /><span className="pl pl-2">あなたには癒やす薬がない。</span></span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 5:6; ヨブ記 30:21; 哀歌 1:2"> <span className="pl pl-1">あなたの愛人たちは皆、あなたを忘れ、</span><br /><span className="pl pl-2">あなたを求めない。</span><br /><span className="pl pl-1">あなたの咎が大きく、</span><br /><span className="pl pl-2">罪が増し加わったために、</span><br /><span className="pl pl-1">わたしは敵が打つようにあなたを打ち、</span><br /><span className="pl pl-2">残酷な者が懲らしめるようにあなたを懲らしめた。</span></span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 30:14; エレミヤ書 30:12; エレミヤ書 6:6–7"> <span className="pl pl-1">なぜ、自分の傷のために叫ぶのか。</span><br /><span className="pl pl-2">あなたの痛みは癒やしがたい。</span><br /><span className="pl pl-1">あなたの咎が大きく、</span><br /><span className="pl pl-2">罪が増し加わったために、</span><br /><span className="pl pl-2">わたしはこれらのことをあなたに行った。</span></span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 10:25; イザヤ書 33:1; 出エジプト記 23:22"> <span className="pl pl-1">それゆえ、あなたを食い尽くす者は皆、食い尽くされる。</span><br /><span className="pl pl-2">あなたの敵は一人残らず捕囚となる。</span><br /><span className="pl pl-1">あなたを略奪する者は略奪され、</span><br /><span className="pl pl-2">あなたを餌食にする者を、わたしは餌食とする。</span></span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 107:20; エレミヤ書 33:6; ペテロの手紙第一 2:24"> <span className="pl pl-1">わたしはあなたの健康を回復させ、</span><br /><span className="pl pl-2">あなたの傷を癒やすからだ」と、主は言われる。</span><br /><span className="pl pl-1">「人々はあなたを追い出された者と呼び、</span><br /><span className="pl pl-2">『これはシオンだ。だれも彼女を求めない』と言ったからだ。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="ハガイ書 2:7–9; 詩篇 102:13; エレミヤ書 30:3"> 主はこう言われる。<br /><span className="pl pl-1">「見よ、わたしはヤコブの天幕を元どおりにし、</span><br /><span className="pl pl-2">その住まいをあわれむ。</span><br /><span className="pl pl-1">町は元の丘の上に建てられ、</span><br /><span className="pl pl-2">宮殿には元の場所で再び人が住む。</span></span>
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 33:22; イザヤ書 51:11; イザヤ書 60:22"> <span className="pl pl-1">そこから感謝の歌と、</span><br /><span className="pl pl-2">喜び楽しむ者たちの声が聞こえる。</span><br /><span className="pl pl-1">わたしは彼らを増やし、</span><br /><span className="pl pl-2">彼らは少なくならない。</span><br /><span className="pl pl-1">わたしは彼らに栄誉を与え、</span><br /><span className="pl pl-2">彼らは軽んじられない。</span></span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 32:39; エレミヤ書 2:3; エレミヤ書 50:33–34"> <span className="pl pl-1">彼らの子らは昔のようになり、</span><br /><span className="pl pl-2">その会衆はわたしの前に堅く立つ。</span><br /><span className="pl pl-2">わたしは彼らを虐げる者を皆、罰する。</span></span>
<span className="v" id="v21" data-v="21" data-xref="民数記 16:5; エゼキエル書 34:23–24; 使徒の働き 5:31"> <span className="pl pl-1">彼らの君主は彼らの中から出て、</span><br /><span className="pl pl-2">その支配者は彼らのうちから現れる。</span><br /><span className="pl pl-1">わたしは彼を近づかせ、</span><br /><span className="pl pl-2">彼はわたしに近づく。</span><br /><span className="pl pl-2">だれが自ら進んで、わたしに近づこうとするだろうか」と、主は言われる。</span></span>
<span className="v" id="v22" data-v="22" data-xref="ヨハネの黙示録 21:3; エゼキエル書 36:28; エレミヤ書 31:33"> <span className="pl pl-1">「あなたがたはわたしの民となり、</span><br /><span className="pl pl-2">わたしはあなたがたの神となる。</span></span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 23:19–20; ゼカリヤ書 9:14; エレミヤ書 25:32"> <span className="pl pl-1">見よ、主の嵐、その憤りが出て行く。</span><br /><span className="pl pl-2">吹き荒れる嵐が、</span><br /><span className="pl pl-2">悪者の頭上に激しく襲いかかる。</span></span>
<span className="v" id="v24" data-v="24" data-xref="エレミヤ書 23:20; ホセア書 3:5; ミカ書 4:1"> <span className="pl pl-1">主の燃える怒りは、その心の計画を実行し、</span><br /><span className="pl pl-2">成し遂げるまで戻らない。</span><br /><span className="pl pl-2">後の日々に、あなたがたはそれを悟る。」</span></span>

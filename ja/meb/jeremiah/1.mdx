<span className="v" id="v1" data-v="1" data-xref="歴代誌上 6:60; エレミヤ書 11:21; 歴代誌 第二 36:21"> ベニヤミンの地アナトテにいた祭司の一人、ヒルキヤの子であるエレミヤの言葉。</span>
<span className="v" id="v2" data-v="2" data-xref="列王記第一 13:20; ヨナ書 1:1; エレミヤ書 1:11"> アモンの子であるユダの王ヨシヤの治世の第十三年に、主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="すべて大文字の「主」または「神」はヘブル語のיהוה（ヤハウェ）から来ている。ただし、短い形のיה（ヤハ）から来ていると記されている場合を除く。">a</a></sup>の言葉が彼に臨んだ。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 39:2; 歴代誌 第二 36:5–8; 列王記第二 23:34"> 主の言葉はまた、ヨシヤの子であるユダの王エホヤキムの時代にも彼に臨み、ヨシヤの子であるユダの王ゼデキヤの治世第十一年の終わり、すなわちエルサレムが捕囚として連れ去られた第五の月まで続いた。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 3:16; エゼキエル書 1:3; エレミヤ書 1:2"> 主の言葉が私に臨み、こう告げられた。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 139:16; イザヤ書 49:1; ガラテヤ人への手紙 1:15–16"> <span className="pl pl-1">「わたしはあなたを胎内で形造る前から、あなたを知っていた。</span><br /><span className="pl pl-2">あなたが生まれる前から、あなたを聖別した。</span><br /><span className="pl pl-2">あなたを諸国民への預言者として任命した。」</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 6:12; 出エジプト記 4:10–16; 列王記第一 3:7–9"> そこで私は言った。「ああ、主<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「主」と訳された言葉は「アドナイ」である。">b</a></sup>なる神よ。見よ、<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「見よ」はヘブル語のהִנֵּהに由来し、「見なさい」「注目しなさい」などの意味を持つ間投詞である。">c</a></sup>私はどう語ればよいか分からない。まだ若者にすぎない。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マルコ 16:15–16; エゼキエル書 3:27; 民数記 22:20"> しかし、主は私に言われた。「『私はまだ子どもです』と言ってはならない。わたしがあなたを遣わす者のところへ行き、わたしが命じることをすべて語りなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 1:5; ヨシュア記 1:9; イザヤ書 51:7"> 彼らを恐れてはならない。わたしがあなたとともにいて、あなたを救い出すからだ」と、主は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ルカ 21:15; 出エジプト記 4:11–12; ルカ 12:12"> その時、主は手を伸ばして私の口に触れた。そして主は私に言われた。「見よ、わたしの言葉をあなたの口に置いた。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 31:28; コリント人への第二の手紙 10:4–5; イザヤ書 44:26–28"> 見よ、今日、わたしはあなたを諸国民と王国の上に立てた。引き抜き、打ち壊し、滅ぼし、覆し、建て、植えるためである。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="アモス書 7:8; アモス書 8:2; ゼカリヤ書 5:2"> さらに、主の言葉が私に臨み、こう告げられた。「エレミヤ、何が見えるか。」<br />私は言った。「アーモンドの木の枝が見えます。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="エゼキエル書 12:28; エゼキエル書 12:25; エゼキエル書 12:22–23"> すると主は私に言われた。「あなたはよく見た。わたしは自分の言葉を成し遂げるため、それを見守っているからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 11:3; エゼキエル書 11:7; ゼカリヤ書 4:2"> 主の言葉が再び私に臨み、こう告げられた。「何が見えるか。」<br />私は言った。「煮え立つ大釜が見えます。その口は北からこちらへ傾いています。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 41:25; エレミヤ書 4:6; エレミヤ書 10:22"> すると主は私に言われた。「北から災いが起こり、この地のすべての住民に襲いかかる。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 43:10; エレミヤ書 25:9; エレミヤ書 9:11"> 見よ、わたしは北の王国のすべての諸族を呼び寄せる」と、主は言われる。<br /><span className="pl pl-1">「彼らはやって来て、それぞれ自分の王座をエルサレムの門の入口に据え、</span><br /><span className="pl pl-2">周囲のすべての城壁と、ユダのすべての町に攻めかかる。</span></span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 7:9; エレミヤ書 19:4; 使徒の働き 7:41"> <span className="pl pl-1">わたしは彼らのすべての悪について、彼らに対する裁きを言い渡す。</span><br /><span className="pl pl-2">彼らはわたしを捨て、</span><br /><span className="pl pl-2">ほかの神々に香をたき、</span><br /><span className="pl pl-2">自分たちの手で造ったものを拝んだからだ。</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 1:7–8; 列王記第一 18:46; ペテロの手紙第一 1:13"> だから、あなたは腰に帯を締め、立ち上がり、わたしが命じることをすべて彼らに語りなさい。彼らの前でうろたえてはならない。さもなければ、わたしが彼らの前であなたをうろたえさせる。</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 50:7; エゼキエル書 3:8–9; エレミヤ書 15:20"> 見よ、今日、わたしはあなたをこの国全体に立ち向かう城塞都市、鉄の柱、青銅の城壁とした。ユダの王たち、その高官たち、その祭司たち、この地の民に立ち向かわせるためである。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 1:9; エレミヤ書 1:8; エレミヤ書 20:11"> 彼らはあなたと戦うが、あなたに勝つことはできない。わたしがあなたとともにいて、あなたを救い出すからだ」と、主は言われる。</span>

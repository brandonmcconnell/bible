<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 18:23–32; 歴代誌 第二 16:9; エゼキエル書 22:30"> 「エルサレムの通りを行き巡り、見て、知れ。その広場で捜してみよ。公正を行い、真実を求める者が一人でも見つかるなら、わたしはこの町を赦そう。</span>
<span className="v" id="v2" data-v="2" data-xref="テトス 1:16; エレミヤ書 4:2; ホセア書 4:1–2"> 彼らは『主は生きておられる』と言っても、偽って誓っている。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 2:30; エレミヤ書 7:28; イザヤ書 9:13"> 主よ、あなたの目は真実に向けられているのではありませんか。あなたは彼らを打たれましたが、彼らは痛みを覚えませんでした。彼らを打ち尽くされましたが、彼らは懲らしめを受け入れませんでした。彼らは顔を岩よりも堅くし、帰ることを拒みました。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 8:7; ホセア書 4:6; イザヤ書 28:9–13"> そこで私は言った。「確かに、彼らは貧しい者たちで、愚かなのだ。主の道も、自分たちの神の律法も知らないからだ。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 2:20; ヤコブの手紙 2:5–7; マタイ 19:23–26"> 私は身分の高い者たちのところへ行き、彼らに語ろう。彼らなら、主の道も、自分たちの神の律法も知っているはずだ。」しかし、彼らも皆そろってくびきを砕き、束縛を断ち切っていた。</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 4:7; ハバクク書 1:8; ゼパニヤ書 3:3"> それゆえ、森から出て来る獅子が彼らを殺し、夕暮れの狼が彼らを滅ぼす。豹が彼らの町々を狙って待ち伏せする。そこから出る者は皆、引き裂かれる。彼らの背きは多く、その背信は増し加わったからだ。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ガラテヤ人への手紙 4:8; ヨシュア記 23:7; エレミヤ書 2:11"> 「どうして、わたしはあなたを赦せるだろうか。あなたの子らはわたしを捨て、神々ではないものによって誓った。わたしが彼らを満ち足らせると、彼らは姦淫し、群れをなして遊女の家に押しかけた。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 13:27; 申命記 5:18; サムエル記第二 11:2–4"> 彼らはよく肥えた放し飼いの馬のようになり、それぞれ隣人の妻を求めていなないた。</span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 9:9; エレミヤ書 5:29; イザヤ書 1:24"> これらのことのために、わたしが彼らを罰しないだろうか」と、主は言われる。「このような国に、わたし自身が復讐しないだろうか。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 4:27; マタイ 22:7; アモス書 9:8"> 「その城壁に上って破壊せよ。しかし、完全に滅ぼしてはならない。その枝を取り除け。それらは主のものではないからだ。</span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 3:20; イザヤ書 48:8; ホセア書 6:7"> イスラエルの家もユダの家も、わたしをひどく裏切ったからだ」と、主は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歴代誌 第二 36:16; エゼキエル書 12:22–28; エレミヤ書 23:14–17"> 彼らは主を否み、こう言った。「主がそんなことをなさるはずはない。災いが私たちに臨むことはない。剣も飢饉も見ることはない。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 14:15; ヨブ記 8:2; エレミヤ書 14:13"> 預言者たちは風となり、彼らの内には言葉がない。そのようなことは、彼ら自身に起こればよい。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 23:29; エレミヤ書 1:9; ホセア書 6:5"> それゆえ、万軍の主はこう言われる。「あなたがたがこの言葉を語ったので、見よ、わたしはあなたの口にあるわたしの言葉を火とし、この民を薪とする。その火が彼らを焼き尽くす。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 28:49; エレミヤ書 4:16; イザヤ書 33:19"> イスラエルの家よ、見よ、わたしは遠くから一つの国をあなたがたに攻め来させる」と、主は言われる。「それは強い国、昔からの国である。その言葉をあなたがたは知らず、彼らが何を話しているか理解できない。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 5:28; 詩篇 5:9; ローマ人への手紙 3:13"> 彼らの矢筒は開いた墓のようで、彼らは皆、勇士である。</span>
<span className="v" id="v17" data-v="17" data-xref="レビ記 26:16; 申命記 28:33; ホセア書 8:14"> 彼らは、あなたの息子や娘が食べるはずの収穫とパンを食い尽くす。あなたの羊の群れと牛の群れを食い尽くし、ぶどうの木といちじくの木を食い尽くす。あなたが信頼している城壁のある町々を、剣で打ち壊す。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 5:10; ローマ人への手紙 11:1–5; エレミヤ書 4:27"> 「しかし、その日々にも、わたしはあなたがたを完全には滅ぼさない」と、主は言われる。</span>
<span className="v" id="v19" data-v="19" data-xref="列王記第一 9:8–9; 申命記 28:47–48; エレミヤ書 22:8–9"> 「あなたがたが、『なぜ、私たちの神、主は、これらすべてのことを私たちにされたのか』と尋ねる時、あなたは彼らにこう言え。『あなたがたがわたしを捨て、自分たちの国で外国の神々に仕えたように、自分たちのものではない国で、外国人に仕えることになる』と。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 「ヤコブの家にこれを告げ、ユダに知らせて言え。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 28:26; エゼキエル書 12:2; イザヤ書 6:9–10"> 『今、このことを聞け。悟りのない愚かな民よ。目があっても見ず、耳があっても聞かない民よ。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨブ記 38:10–11; 詩篇 104:9; ヨブ記 26:10"> あなたがたはわたしを恐れないのか』と、主は言われる。『わたしの前で震えないのか。わたしは砂を海の境とし、越えることのできない永遠の定めとした。その波が逆巻いても勝つことはできず、鳴りとどろいても、それを越えることはできない。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 6:28; 申命記 21:18; 詩篇 95:10"> しかし、この民には背き逆らう心がある。彼らは背いて去って行った。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 147:8; ヨエル書 2:23; 創世記 8:22"> 彼らは心の中でこう言わない。「さあ、私たちの神、主を恐れよう。主は季節に従って先の雨と後の雨を与え、刈り入れのために定められた週を守ってくださる」と。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 59:2; 詩篇 107:17; 詩篇 107:34"> あなたがたの咎がこれらを遠ざけ、あなたがたの罪が良いものをあなたがたから差し止めた。</span>
<span className="v" id="v26" data-v="26" data-xref="箴言 1:11; 詩篇 64:5; エゼキエル書 22:2–12"> わたしの民の中には悪者がいる。彼らは鳥を捕る者が待ち伏せするように身を潜め、罠を仕掛けて人々を捕らえる。</span>
<span className="v" id="v27" data-v="27" data-xref="ミカ書 1:12; エレミヤ書 9:6; ホセア書 12:7–8"> 鳥かごが鳥で満ちているように、彼らの家は欺きで満ちている。それゆえ、彼らは勢力を増し、富んだ。</span>
<span className="v" id="v28" data-v="28" data-xref="イザヤ書 1:23; 申命記 32:15; エレミヤ書 7:6"> 彼らは肥え太り、つややかになった。しかも、悪事においては度を越えている。彼らはみなしごが栄えるように、その訴えを取り上げることもなく、貧しい者たちの権利も擁護しない。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="エレミヤ書 5:9; マラキ書 3:5; エレミヤ書 9:9"> これらのことのために、わたしが彼らを罰しないだろうか』と、主は言われる。『このような国に、わたし自身が復讐しないだろうか。』」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ホセア書 6:10; エレミヤ書 23:14; イザヤ書 1:2"> 「驚くべき恐ろしいことが、この地に起こっている。</span>
<span className="v" id="v31" data-v="31" data-xref="エゼキエル書 13:6; エレミヤ書 14:14; ミカ書 2:11"> 預言者たちは偽りを預言し、祭司たちは自分たちの権力で支配し、わたしの民はそれを愛している。しかし、その終わりには、あなたがたはどうするのか。」</span>
</div>

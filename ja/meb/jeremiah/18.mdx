<span className="v" id="v1" data-v="1"> 主からエレミヤに臨んだ言葉。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 1:1; 使徒の働き 9:6; エレミヤ書 19:1–2"> 「立って、陶器師の家へ下って行け。そこで、わたしの言葉をあなたに聞かせよう。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ヨハネ 15:14; ヨナ書 1:3; 使徒の働き 26:19"> そこで私は陶器師の家へ下って行った。見よ、彼はろくろを使って仕事をしていた。</span>
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 9:20–23; エレミヤ書 18:6; イザヤ書 45:9"> 陶器師が粘土で作っていた器がその手の中で損なわれると、彼は自分の目に良いと思う別の器に作り直した。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> その時、主の言葉が私に臨んで言われた。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 64:8; ローマ人への手紙 9:20–21; エレミヤ書 18:4"> 「イスラエルの家よ、わたしはこの陶器師がしたように、あなたがたにできないだろうか」と、主は言われる。「見よ、粘土が陶器師の手の中にあるように、イスラエルの家よ、あなたがたもわたしの手の中にある。</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 1:10; エレミヤ書 12:14–17; エレミヤ書 45:4"> わたしがある国、ある王国について、引き抜き、打ち壊し、滅ぼすと語ったその時、</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 18:21; エレミヤ書 26:13; ヨナ書 3:9–10"> わたしが語ったその国が悪から立ち返るなら、わたしは彼らに行おうと考えた災いを思い直す。</span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 31:28; アモス書 9:11–15; エレミヤ書 1:10"> また、わたしがある国、ある王国について、建て、植えると語ったその時、</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 33:18; サムエル記第一 2:30; エゼキエル書 18:24"> 彼らがわたしの目に悪いことを行い、わたしの声に聞き従わないなら、彼らに与えると言った幸いを思い直す。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王記第二 17:13; イザヤ書 55:6–7; エレミヤ書 35:15"> 「それゆえ今、ユダの人々とエルサレムの住民に語って言え。『主はこう言われる。「見よ、わたしはあなたがたに災いをもたらそうとし、あなたがたに対して計画を立てている。今、それぞれ悪い道から立ち返り、自分たちの道と行いを改めよ。」』</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 2:25; エレミヤ書 7:24; 申命記 29:19"> しかし、彼らは言う。『無駄だ。私たちは自分たちの計画に従って歩み、それぞれ自分の悪い心のかたくなさに従う』と。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 5:30; ホセア書 6:10; エレミヤ書 23:14"> それゆえ、主はこう言われる。<br /><span className="pl pl-1">「さあ、諸国民の間で尋ねよ。</span><br /><span className="pl pl-2">『だれがこのようなことを聞いたことがあるか』と。</span><br /><span className="pl pl-2">イスラエルのおとめは、実に恐ろしいことを行った。</span></span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネ 6:68"> <span className="pl pl-1">レバノンの雪が野の岩から消えるだろうか。</span><br /><span className="pl pl-2">遠くから流れ下る冷たい水が干上がるだろうか。</span></span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 6:16; エレミヤ書 2:32; ホセア書 11:2"> <span className="pl pl-1">しかし、わたしの民はわたしを忘れ、</span><br /><span className="pl pl-2">偽りの神々に香をたいた。</span><br /><span className="pl pl-1">彼らは自分たちの道、</span><br /><span className="pl pl-2">昔からの道でつまずかされ、</span><br /><span className="pl pl-2">整えられていない脇道を歩いた。</span></span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 22:7; エレミヤ書 25:9; エレミヤ書 19:8"> <span className="pl pl-1">そのため、自分たちの地を驚きの的、</span><br /><span className="pl pl-2">永遠にあざけられる所とした。</span><br /><span className="pl pl-1">そこを通る者は皆、驚き、</span><br /><span className="pl pl-2">頭を振る。</span></span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 13:24; エレミヤ書 2:27; ヨブ記 27:21"> <span className="pl pl-1">わたしは東風で吹き散らすように、</span><br /><span className="pl pl-2">彼らを敵の前に散らす。</span><br /><span className="pl pl-1">彼らの災いの日に、</span><br /><span className="pl pl-2">わたしは顔ではなく、背を彼らに見せる。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="詩篇 52:2; エレミヤ書 11:19; マラキ書 2:7"> すると彼らは言った。「さあ、エレミヤに対して計略を巡らそう。祭司から律法が、知恵ある者から助言が、預言者から言葉が失われることはない。さあ、舌で彼を打ち、彼の言葉には何一つ耳を傾けないようにしよう。」</span>
<span className="v" id="v19" data-v="19" data-xref="ネヘミヤ記 6:9; エレミヤ書 20:12; 詩篇 55:16–17"> <span className="pl pl-1">主よ、私に心を留め、</span><br /><span className="pl pl-2">私と争う者たちの声を聞いてください。</span></span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 35:7; 詩篇 57:6; 詩篇 106:23"> <span className="pl pl-1">善に悪を返してよいのか。</span><br /><span className="pl pl-2">彼らは私の命を奪うために穴を掘った。</span><br /><span className="pl pl-1">私があなたの御前に立って彼らのために良いことを語り、</span><br /><span className="pl pl-2">あなたの憤りを彼らからそらそうとしたことを覚えてください。</span></span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 109:9–20; 哀歌 5:3; アモス書 4:10"> <span className="pl pl-1">それゆえ、彼らの子どもたちを飢饉に渡し、</span><br /><span className="pl pl-2">彼らを剣の力に引き渡してください。</span><br /><span className="pl pl-1">彼らの妻たちを子のないやもめとし、</span><br /><span className="pl pl-2">男たちを死に渡し、</span><br /><span className="pl pl-2">若者たちを戦いの剣に打たせてください。</span></span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 6:26; 詩篇 140:5; ゼパニヤ書 1:10–11"> <span className="pl pl-1">あなたが突然、軍勢を彼らに襲わせる時、</span><br /><span className="pl pl-2">彼らの家から叫び声が上がりますように。</span><br /><span className="pl pl-1">彼らは私を捕らえるために穴を掘り、</span><br /><span className="pl pl-2">私の足に罠を隠したからだ。</span></span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 35:4; 詩篇 69:22–28; ネヘミヤ記 4:4–5"> <span className="pl pl-1">しかし、主よ、あなたは私を殺そうとする</span><br /><span className="pl pl-2">彼らの計略をすべてご存じだ。</span><br /><span className="pl pl-1">彼らの咎を赦さず、</span><br /><span className="pl pl-2">その罪をあなたの御前から消し去らないでください。</span><br /><span className="pl pl-1">彼らをあなたの御前で倒し、</span><br /><span className="pl pl-2">あなたの怒りの時に彼らを罰してください。</span></span>
</div>

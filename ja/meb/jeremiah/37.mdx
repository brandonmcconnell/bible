<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 22:24; 列王記第二 24:17; 列王記第二 24:12"> ヨシヤの子ゼデキヤは、バビロンの王ネブカドネザルがユダの地の王としたエホヤキムの子コニヤに代わって王となった。</span>
<span className="v" id="v2" data-v="2" data-xref="列王記第二 24:19–20; 箴言 29:12; 歴代誌 第二 36:12–16"> しかし、彼も、その家来たちも、この地の民も、主が預言者エレミヤを通して語られた言葉に聞き従わなかった。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 21:1–2; エレミヤ書 29:25; エレミヤ書 42:20"> ゼデキヤ王は、シェレムヤの子エフカルと祭司マアセヤの子ゼパニヤを預言者エレミヤのもとに遣わして言わせた。「どうか、私たちのために、私たちの神、主に祈ってください。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 37:15; エレミヤ書 32:2–3"> その時、エレミヤは民の間を自由に出入りしていた。人々はまだ彼を牢獄に入れていなかったからである。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 17:15; エレミヤ書 37:11; エレミヤ書 34:21"> ファラオの軍隊がエジプトから出て来た。エルサレムを包囲していたカルデア人は、その知らせを聞くと、エルサレムから退いた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> その時、主の言葉が預言者エレミヤに臨んで言われた。</span>
<span className="v" id="v7" data-v="7" data-xref="哀歌 4:17; 列王記第二 22:18; エゼキエル書 17:17"> 「イスラエルの神、主はこう言われる。『わたしに尋ねるためにあなたがたを遣わしたユダの王に、こう告げよ。「見よ、あなたがたを助けるために出て来たファラオの軍隊は、自分たちの国エジプトへ帰る。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 39:2–8; エレミヤ書 38:23; エレミヤ書 34:21–22"> カルデア人は再び来て、この町と戦い、これを占領し、火で焼く。」』</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="オバデヤ書 1:3; エレミヤ書 29:8; ガラテヤ人への手紙 6:3"> 主はこう言われる。『「カルデア人は必ず私たちから去って行く」と言って、自分たちを欺いてはならない。彼らは去って行かないからだ。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 50:45; イザヤ書 30:17; ヨエル書 2:11"> たとえ、あなたがたと戦うカルデア人の全軍を打ち破り、その中に負傷者しか残らなかったとしても、彼らはそれぞれ自分の天幕から立ち上がり、この町を火で焼く。』」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 37:5"> カルデア人の軍隊がファラオの軍隊を恐れてエルサレムから退いた時、</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 1:1; ネヘミヤ記 6:11; 列王記第一 19:3"> エレミヤは自分の分け前を受け取るため、民の間を通ってベニヤミンの地へ行こうと、エルサレムを出た。</span>
<span className="v" id="v13" data-v="13" data-xref="ゼカリヤ書 14:10; エレミヤ書 38:7; ルカ 23:2"> 彼がベニヤミンの門に来ると、そこにハナンヤの孫で、シェレムヤの子であるイリヤという衛兵の隊長がいた。彼は預言者エレミヤを捕らえて言った。「おまえはカルデア人のもとへ脱走しようとしている。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="詩篇 52:1–2; エレミヤ書 40:4–6; 詩篇 27:12"> エレミヤは言った。「それは偽りです。私はカルデア人のもとへ脱走しようとしているのではありません。」<br />しかし、イリヤは彼の言うことを聞かず、エレミヤを捕らえて高官たちのもとへ連れて行った。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 38:26; エレミヤ書 20:1–3; エレミヤ書 26:16"> 高官たちはエレミヤに怒り、彼を打ち、書記ヨナタンの家にある牢獄に入れた。その家を牢獄にしていたからである。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 38:6; エレミヤ書 38:10–13; 哀歌 3:53"> エレミヤは地下牢の中の独房に入り、そこに長い間とどまった。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 21:7; エレミヤ書 24:8; 列王記第一 14:1–4"> その後、ゼデキヤ王は人を遣わして彼を連れ出させ、王宮でひそかに尋ねた。「主からの言葉が何かあるか。」<br />エレミヤは答えた。「あります。あなたはバビロンの王の手に渡されます。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 25:8; ヨハネ 10:32; ダニエル書 6:22"> また、エレミヤはゼデキヤ王に言った。「私があなたや、あなたの家来たちや、この民に対して、どのような罪を犯したので、あなたがたは私を牢獄に入れたのですか。</span>
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 2:28; エレミヤ書 28:10–17; エレミヤ書 6:14"> 『バビロンの王は、あなたにもこの地にも攻めて来ない』と預言した、あなたの預言者たちは今どこにいるのですか。</span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 36:7; エレミヤ書 38:6–9; 使徒の働き 28:18–19"> わが主である王よ、今どうかお聞きください。私の願いを受け入れてください。私を再び書記ヨナタンの家へ戻さないでください。そこで死ぬことのないようにしてください。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 38:13; エレミヤ書 38:28; エレミヤ書 38:9"> そこでゼデキヤ王は命じ、エレミヤを衛兵の庭に置かせた。町のパンがすべてなくなるまで、パン職人の通りから毎日パン一個が彼に与えられた。こうしてエレミヤは衛兵の庭にとどまった。</span>
</div>

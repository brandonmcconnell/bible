<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 36:1; 列王記第二 24:1–2; ダニエル書 1:1"> ユダの王ヨシヤの子エホヤキムの治世第四年、すなわちバビロンの王ネブカドネザルの治世第一年に、ユダのすべての民についてエレミヤに臨んだ言葉。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 18:11; エレミヤ書 19:14–15; マルコ 7:14–15"> 預言者エレミヤはそれをユダのすべての民とエルサレムのすべての住民に語った。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 11:7; エレミヤ書 26:5; エレミヤ書 1:2"> ユダの王アモンの子ヨシヤの治世第十三年から今日まで、この二十三年間、主の言葉が私に臨んだ。私は朝早くから繰り返しあなたがたに語ったが、あなたがたは聞かなかった。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 25:3; エレミヤ書 26:5; エレミヤ書 13:10–11"> 主はそのしもべであるすべての預言者たちを、朝早くから繰り返しあなたがたに遣わされた。しかし、あなたがたは聞かず、耳を傾けようともしなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 7:7; 創世記 17:8; イザヤ書 55:6–7"> 彼らはこう言った。「今、それぞれ悪い道と悪い行いから立ち返れ。そうすれば、主が昔からとこしえまで、あなたがたと父祖たちに与えられた地に住むことができる。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 8:19; エレミヤ書 7:6; エレミヤ書 35:15"> ほかの神々に従って行き、これらに仕えたり、拝んだりしてはならない。自分たちの手で造ったものによって、わたしを怒らせてはならない。そうすれば、わたしはあなたがたに災いを行わない。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王記第二 21:15; 箴言 8:36; 申命記 32:21"> 「それでも、あなたがたはわたしに聞き従わなかった」と、主は言われる。「自分たちの手で造ったものによってわたしを怒らせ、自らに災いを招いた。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> それゆえ、万軍の主はこう言われる。「あなたがたがわたしの言葉を聞かなかったので、</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 13:3; エレミヤ書 18:16; エレミヤ書 1:15"> 見よ、わたしは北のすべての氏族を呼び寄せる」と、主は言われる。「また、わたしのしもべであるバビロンの王ネブカドネザルを呼び寄せ、この地とその住民、また周囲のすべての国々を攻めさせる。わたしは彼らを完全に滅ぼし、驚きの的、あざけりの的、永遠の廃墟とする。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 7:34; ヨハネの黙示録 18:22–23; エゼキエル書 26:13"> また、彼らの中から喜びの声と楽しみの声、花婿の声と花嫁の声、ひき臼の音、灯火の光を絶えさせる。</span>
<span className="v" id="v11" data-v="11" data-xref="ダニエル書 9:2; ゼカリヤ書 1:12; 歴代誌 第二 36:21–22"> この全地は荒れ果て、驚きの的となる。これらの国々は七十年間、バビロンの王に仕える。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ダニエル書 9:2; イザヤ書 13:19; エレミヤ書 29:10"> 「七十年が満ちると、わたしはバビロンの王とその国を、その咎のために罰する」と、主は言われる。「わたしはカルデア人の地を永遠に荒れ果てた地とする。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 1:10; エレミヤ書 1:5; ダニエル書 5:31"> わたしはその地に対して語ったすべての言葉、すなわちエレミヤがすべての国々に対して預言し、この書に記されているすべてのことを、その地にもたらす。</span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 51:6; エレミヤ書 27:7; エレミヤ書 50:9"> 彼らもまた、多くの国々と大いなる王たちに奴隷として使われる。わたしは彼らの行いと、その手の業に従って報いる。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="詩篇 75:8; イザヤ書 51:17; ヨハネの黙示録 14:10"> イスラエルの神、主は私にこう言われた。「わたしの手から、この憤りのぶどう酒の杯を取り、わたしがあなたを遣わすすべての国々に飲ませよ。</span>
<span className="v" id="v16" data-v="16" data-xref="ナホム書 3:11; エレミヤ書 51:7; エレミヤ書 51:39"> 彼らはそれを飲み、よろめき、正気を失う。わたしが彼らの間に送る剣のためである。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 1:10; エレミヤ書 25:28; エゼキエル書 43:3"> そこで私は主の手から杯を取り、主が私を遣わされたすべての国々に飲ませた。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 24:9; 詩篇 60:3; エレミヤ書 44:22"> エルサレムとユダの町々、その王たちと高官たちに飲ませ、それらを荒れ果てた地、驚きの的、あざけりの的、呪いの的とした。今日あるとおりである。</span>
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 46:13–26; ナホム書 3:8–10; エレミヤ書 46:2"> エジプトの王ファラオと、その家来たち、高官たち、すべての民、</span>
<span className="v" id="v20" data-v="20" data-xref="ヨブ記 1:1; エゼキエル書 30:5; イザヤ書 20:1"> すべての入り混じった民、ウツの地のすべての王、ペリシテ人の地のすべての王、アシュケロン、ガザ、エクロン、アシュドドの残りの者、</span>
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 48:1–22; 詩篇 137:7; エレミヤ書 9:26"> エドム、モアブ、アンモンの子ら、</span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 47:4; アモス書 1:9–10; エゼキエル書 28:22–23"> ツロのすべての王、シドンのすべての王、海の向こうの島の王たち、</span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 9:26; エレミヤ書 49:32; エレミヤ書 49:8"> デダン、テマ、ブズ、ひげの端を切り落としているすべての者、</span>
<span className="v" id="v24" data-v="24" data-xref="歴代誌 第二 9:14; エレミヤ書 25:20; エゼキエル書 30:5"> アラビアのすべての王、荒野に住む入り混じった民のすべての王、</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 11:11; 創世記 10:22; イザヤ書 13:17"> ジムリのすべての王、エラムのすべての王、メディア人のすべての王、</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 51:41; エレミヤ書 25:9; エレミヤ書 50:1–46"> 近くにも遠くにもいる北のすべての王を、順々に飲ませた。また、地の表にある世界のすべての王国にも飲ませた。彼らの後で、シェシャクの王も飲む。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 25:16; ハバクク書 2:16; エゼキエル書 21:4–5"> 「あなたは彼らにこう言え。『イスラエルの神、万軍の主はこう言われる。「飲んで酔い、吐き、倒れて、二度と起き上がるな。わたしがあなたがたの間に送る剣のためだ。」』</span>
<span className="v" id="v28" data-v="28" data-xref="ヨブ記 34:33; エレミヤ書 51:29; イザヤ書 14:24–27"> もし彼らがあなたの手から杯を取って飲むことを拒むなら、彼らにこう言え。『万軍の主はこう言われる。「あなたがたは必ず飲まなければならない。</span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 38:21; 箴言 11:31; ペテロの手紙第一 4:17"> 見よ、わたしの名で呼ばれる町にさえ、わたしは災いをもたらし始める。それなのに、あなたがたが罰を免れられるだろうか。あなたがたは決して罰を免れない。わたしが地のすべての住民に剣を呼び寄せるからだ」と、万軍の主は言われる。』」</span>
</div>
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="アモス書 1:2; ヨエル書 3:16; イザヤ書 42:13"> 「それゆえ、これらすべての言葉を彼らに対して預言し、こう言え。<br /><span className="pl pl-1">『主は高い所からほえ、</span><br /><span className="pl pl-2">その聖なる住まいから声を発せられる。</span><br /><span className="pl pl-2">ご自分の牧場に向かって激しくほえ、</span><br /><span className="pl pl-1">ぶどうを踏む者たちのように、</span><br /><span className="pl pl-2">地のすべての住民に向かって叫び声を上げられる。</span></span>
<span className="v" id="v31" data-v="31" data-xref="ホセア書 4:1; ヨエル書 3:2; イザヤ書 66:16"> <span className="pl pl-1">騒音は地の果てにまで及ぶ。</span><br /><span className="pl pl-2">主が諸国民と争われるからだ。</span><br /><span className="pl pl-1">主はすべての人を裁き、</span><br /><span className="pl pl-2">悪者たちを剣に渡される』と、主は言われる。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="エレミヤ書 23:19; イザヤ書 34:2; 歴代誌 第二 15:6"> 万軍の主はこう言われる。<br /><span className="pl pl-1">「見よ、災いが国から国へと広がり、</span><br /><span className="pl pl-2">大きな嵐が地の果てから巻き起こる。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 66:16; エレミヤ書 8:2; 詩篇 79:3"> その日、主に殺された者たちは、地の一方の果てから他方の果てにまで及ぶ。彼らは嘆かれず、集められず、葬られない。地の表の糞となる。</span>
<span className="v" id="v34" data-v="34" data-xref="エレミヤ書 6:26; エレミヤ書 50:27; 詩篇 2:9"> <span className="pl pl-1">牧者たちよ、泣き叫べ。</span><br /><span className="pl pl-2">群れの指導者たちよ、ちりの中を転げ回れ。</span><br /><span className="pl pl-1">あなたがたが屠られ、散らされる日が来たからだ。</span><br /><span className="pl pl-2">あなたがたは上質な陶器のように落ちて砕ける。</span></span>
<span className="v" id="v35" data-v="35" data-xref="ヨブ記 11:20; アモス書 2:14; エレミヤ書 52:8–11"> <span className="pl pl-1">牧者たちには逃げ道がなく、</span><br /><span className="pl pl-2">群れの指導者たちには逃れる道がない。</span></span>
<span className="v" id="v36" data-v="36" data-xref="エレミヤ書 4:8; エレミヤ書 25:34"> <span className="pl pl-1">牧者たちの叫び声と、</span><br /><span className="pl pl-2">群れの指導者たちの嘆き声が聞こえる。</span><br /><span className="pl pl-2">主が彼らの牧場を滅ぼされるからだ。</span></span>
<span className="v" id="v37" data-v="37" data-xref="イザヤ書 27:10–11; イザヤ書 32:14"> <span className="pl pl-1">平穏な羊の囲いは静まり返る。</span><br /><span className="pl pl-2">主の燃える怒りのために。</span></span>
<span className="v" id="v38" data-v="38" data-xref="エレミヤ書 4:7; エレミヤ書 5:6; ホセア書 13:7–8"> <span className="pl pl-1">主は獅子のように、その隠れ場を出られた。</span><br /><span className="pl pl-2">激しい虐げと、</span><br /><span className="pl pl-2">主の燃える怒りのために、彼らの地は驚きの的となった。</span></span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ネヘミヤ記 7:9; エズラ記 2:3; 使徒の働き 4:6–10"> マタンの子シェファテヤ、パシュフルの子ゲダルヤ、シェレムヤの子ユカル、マルキヤの子パシュフルは、エレミヤがすべての民に語っていた次の言葉を聞いた。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 39:18; エレミヤ書 34:17; エレミヤ書 45:5"> 「主はこう言われる。『この町にとどまる者は、剣と飢饉と疫病によって死ぬ。しかし、カルデア人のもとへ出て行く者は生きる。その人は命だけは助かって生きる。』</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 21:10; エレミヤ書 32:3–5"> 主はこう言われる。『この町は必ずバビロンの王の軍隊の手に渡され、彼はこれを占領する。』」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 26:11; 使徒の働き 16:20; ネヘミヤ記 6:9"> そこで高官たちは王に言った。「どうか、この男を死刑にしてください。彼はこのような言葉を人々に語り、この町に残っている兵士たちと、すべての民の戦意をくじいています。この男はこの民の益ではなく、災いを求めているのです。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ヨハネ 19:12–16; サムエル記第二 3:39; サムエル記第二 19:22"> ゼデキヤ王は言った。「見よ、彼はあなたがたの手の中にいる。王には、あなたがたに逆らって何もできない。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 37:21; エレミヤ書 38:22; エレミヤ書 37:16"> そこで彼らはエレミヤを捕らえ、衛兵の庭にある王の子マルキヤの地下牢に投げ込んだ。彼らは縄でエレミヤを下ろした。地下牢には水はなく、泥があったので、エレミヤは泥の中に沈んだ。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命記 21:19; アモス書 5:10; エレミヤ書 29:2"> 王宮にいた宦官で、エチオピア人のエベデ・メレクは、彼らがエレミヤを地下牢に入れたことを聞いた。その時、王はベニヤミンの門に座っていた。</span>
<span className="v" id="v8" data-v="8"> エベデ・メレクは王宮を出て、王に語って言った。</span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 37:21–6; エステル記 7:4–6; 箴言 31:8–9"> 「わが主である王よ、この人々が預言者エレミヤにしたことは、すべて悪いことです。彼らは彼を地下牢に投げ込みました。町にはもうパンがないので、彼はそこにいたまま飢えて死ぬでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="箴言 21:1; エステル記 8:7; エステル記 5:2"> そこで王はエチオピア人エベデ・メレクに命じた。「ここから三十人を連れて行き、預言者エレミヤが死ぬ前に、地下牢から引き上げよ。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> エベデ・メレクは人々を連れて王宮に行き、宝物倉の下の部屋から古いぼろ布と擦り切れた衣を取り、それらを縄で地下牢のエレミヤのもとへ下ろした。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 12:10; エペソ人への手紙 4:32; ローマ人への手紙 12:15"> エチオピア人エベデ・メレクはエレミヤに言った。「このぼろ布と擦り切れた衣を、縄が当たる脇の下に入れてください。」<br />エレミヤはそのとおりにした。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 37:21; 使徒の働き 28:16; 使徒の働き 23:35"> 彼らは縄でエレミヤを引き上げ、地下牢から出した。エレミヤは衛兵の庭にとどまった。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 37:17; 列王記第一 22:16; エレミヤ書 21:1–2"> その後、ゼデキヤ王は人を遣わし、預言者エレミヤを主の家の第三の入口へ連れて来させた。王はエレミヤに言った。「私はあなたに一つのことを尋ねる。私に何も隠してはならない。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ルカ 22:67–68"> エレミヤはゼデキヤに言った。「私があなたに告げれば、あなたは必ず私を殺すのではありませんか。また、私があなたに助言しても、あなたは私の言うことを聞かないでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 37:17; エレミヤ書 38:1–6; イザヤ書 57:16"> そこでゼデキヤ王は、ひそかにエレミヤに誓って言った。「私たちの命を造られた主は生きておられる。私はあなたを殺さない。また、あなたの命を狙うこの人々の手に、あなたを渡さない。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 27:12; エレミヤ書 27:17; エレミヤ書 38:2"> そこでエレミヤはゼデキヤに言った。「イスラエルの神、万軍の主はこう言われます。『あなたがバビロンの王の高官たちのもとへ出て行くなら、あなたの命は助かり、この町は火で焼かれない。あなたも、あなたの家も生きる。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 38:3; エレミヤ書 24:8–10; 列王記第二 25:4–10"> しかし、あなたがバビロンの王の高官たちのもとへ出て行かないなら、この町はカルデア人の手に渡される。彼らはこれを火で焼き、あなたも彼らの手から逃れられない。』」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨハネ 12:42; エレミヤ書 38:22; ヨハネ 19:12–13"> ゼデキヤ王はエレミヤに言った。「私は、カルデア人のもとへ脱走したユダヤ人たちを恐れている。カルデア人が私を彼らの手に渡し、彼らが私を辱めるのではないかと。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="ダニエル書 4:27; イザヤ書 55:3; エレミヤ書 26:13"> しかし、エレミヤは言った。「彼らはあなたを渡しません。どうか、私があなたに語る主の声に聞き従ってください。そうすれば、あなたは幸いを得て、あなたの命は助かります。</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 2:7; エゼキエル書 2:4–5; エレミヤ書 26:15"> しかし、あなたが出て行くことを拒むなら、主が私に示された言葉はこれです。</span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 43:6; 哀歌 1:2; 哀歌 5:11"> 『見よ、ユダの王の家に残っているすべての女たちは、バビロンの王の高官たちのもとへ連れ出される。女たちはこう言う。<br /><span className="pl pl-1">「あなたの親しい友たちがあなたをそそのかし、</span><br /><span className="pl pl-2">あなたに勝った。</span><br /><span className="pl pl-1">あなたの足が泥に沈むと、</span><br /><span className="pl pl-2">彼らはあなたを見捨てた。」</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 41:10; エレミヤ書 39:6; エレミヤ書 38:18"> あなたのすべての妻と子どもたちはカルデア人のもとへ連れ出される。あなたは彼らの手から逃れられず、バビロンの王の手に捕らえられる。そして、あなたはこの町を火で焼かせることになる。』」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> するとゼデキヤはエレミヤに言った。「これらの言葉をだれにも知らせてはならない。そうすれば、あなたは死なない。</span>
<span className="v" id="v25" data-v="25" data-xref="エレミヤ書 38:27; エレミヤ書 38:4–6"> 高官たちが、私があなたと話したことを聞き、あなたのところへ来て、『あなたが王に何を語ったのか、今、私たちに話せ。私たちに隠すな。そうすれば、あなたを殺さない。王があなたに何を語ったのかも話せ』と言うなら、</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 37:20; エレミヤ書 37:15; エステル記 4:8"> あなたは彼らに、『私は王の前に願いを申し上げ、死ぬことのないように、私をヨナタンの家へ戻さないでくださいと頼みました』と言いなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="サムエル記第一 10:15–16; 列王記第二 6:19; 使徒の働き 23:6"> その後、すべての高官たちがエレミヤのところへ来て、彼に尋ねた。エレミヤは、王が命じたこれらすべての言葉のとおりに彼らに答えた。話の内容が知られなかったので、彼らはそれ以上彼に話さなかった。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="エレミヤ書 37:21; エレミヤ書 39:14; 詩篇 23:4"> エレミヤは、エルサレムが占領された日まで衛兵の庭にとどまった。</span>
</div>
</div>

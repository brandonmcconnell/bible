<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 38:28; エレミヤ書 37:21; エレミヤ書 32:2–3"> エレミヤがなお衛兵の庭に閉じ込められていた時、主の言葉が二度目に彼に臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 6:3; 出エジプト記 15:3; イザヤ書 37:26"> 「これを行い、形造って確立する主、その名を主という方は、こう言われる。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 29:12; イザヤ書 65:24; エペソ人への手紙 3:20"> 『わたしを呼べ。そうすれば、わたしはあなたに答え、あなたの知らない、大いなる、理解しがたいことをあなたに示す。』</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 32:24; ハバクク書 1:10; エゼキエル書 4:2"> イスラエルの神、主は、この町の家々とユダの王たちの家々、すなわち包囲の塁と剣に対する防備のために取り壊された家々について、こう言われる。</span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 8:17; エレミヤ書 21:10; エレミヤ書 21:4–7"> 『人々はカルデア人と戦うために来るが、その家々は、わたしが怒りと憤りのうちに打ち殺した者たちの死体で満たされる。彼らのすべての悪のために、わたしはこの町から顔を隠した。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 10:10; イザヤ書 30:26; テトス 3:5–6"> 見よ、わたしはこの町に回復と癒やしをもたらし、彼らを癒やす。わたしは豊かな平和と真実を彼らに示す。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 1:26; エレミヤ書 30:3; アモス書 9:14–15"> わたしはユダとイスラエルを捕囚から帰らせ、初めの時のように彼らを建てる。</span>
<span className="v" id="v8" data-v="8" data-xref="ゼカリヤ書 13:1; ミカ書 7:18–19; 詩篇 51:2"> わたしは、彼らがわたしに対して罪を犯したすべての咎から彼らを清める。彼らがわたしに対して罪を犯し、背いたすべての咎を赦す。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 126:2–3; イザヤ書 60:5; ゼパニヤ書 3:17–20"> この町は、地のすべての国々の前で、わたしにとって喜びの名、賛美、栄光となる。国々は、わたしが彼らに行うすべての良いことを聞き、わたしがこの町に与えるすべての良いことと平和のために、恐れ震える。』」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 32:43; エレミヤ書 32:36; エゼキエル書 37:11"> 主はこう言われる。「あなたがたが、『ここは荒れ果て、人も動物もいない』と言っているこの場所、すなわち人も住民も動物もいない荒れ果てたユダの町々とエルサレムの通りで、再び声が聞こえるようになる。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代誌上 16:34; 詩篇 106:1; 詩篇 107:22"> 喜びの声と楽しみの声、花婿の声と花嫁の声、また、『万軍の主に感謝せよ。主は良い方であり、その慈しみは永遠に続く』と言う者たちの声が聞こえる。彼らは感謝のささげ物を主の家に携えて来る。わたしがこの地を捕囚から帰らせ、初めの時のようにするからだ」と、主は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 65:10; エゼキエル書 34:12–15; エレミヤ書 36:29"> 万軍の主はこう言われる。「人も動物もいない荒れ果てたこの場所と、そのすべての町々に、再び羊飼いたちの住まいができ、彼らは群れを伏させる。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 27:32; ルカ 15:4; エレミヤ書 17:26"> 山地の町々、低地の町々、南部の町々、ベニヤミンの地、エルサレムの周辺、ユダの町々で、群れは再び数える者の手の下を通る」と、主は言われる。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="ハガイ書 2:6–9; エレミヤ書 23:5; 歴代誌上 17:13–14"> 「見よ、その日々が来る」と、主は言われる。「その時、わたしはイスラエルの家とユダの家について語った良い言葉を実現する。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 11:1–5; エレミヤ書 23:5–6; イザヤ書 4:2"> <span className="pl pl-1">その日、その時、</span><br /><span className="pl pl-2">わたしはダビデのために義なる若枝を生えさせる。</span><br /><span className="pl pl-2">彼はこの地に公正と義を行う。</span></span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 23:6; コリント人への第一の手紙 1:30; イザヤ書 45:17"> <span className="pl pl-1">その日々にユダは救われ、</span><br /><span className="pl pl-2">エルサレムは安らかに住む。</span><br /><span className="pl pl-1">この町は、</span><br /><span className="pl pl-2">『主は私たちの義』という名で呼ばれる。」</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王記第一 2:4; 詩篇 89:29–37; ルカ 1:32–33"> 主はこう言われる。「ダビデには、イスラエルの家の王座に座る者が絶えることはない。</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 56:7; ヨハネの黙示録 1:6; 申命記 18:1"> レビ人の祭司たちにも、全焼のささげ物を献げ、穀物のささげ物を焼き、絶えずいけにえを献げる者が、わたしの前から絶えることはない。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 主の言葉がエレミヤに臨んだ。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 8:22; 詩篇 89:37; イザヤ書 54:9–10"> 「主はこう言われる。『もし、あなたがたが昼とのわたしの契約と、夜とのわたしの契約を破り、昼と夜が定められた時に来ないようにできるなら、</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 89:34; 歴代誌 第二 7:18; サムエル記第二 23:5"> わたしのしもべダビデとの契約も破られ、彼の王座に座って治める息子がいなくなる。また、わたしに仕えるレビ人の祭司たちとの契約も破られる。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 15:5; 創世記 22:17; ヘブル人への手紙 11:12"> 天の軍勢が数えられず、海の砂が量れないように、わたしはしもべダビデの子孫と、わたしに仕えるレビ人を増やす。』」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 主の言葉がエレミヤに臨んだ。</span>
<span className="v" id="v24" data-v="24" data-xref="ネヘミヤ記 4:2–4; 詩篇 83:4; 詩篇 44:13–14"> 「この民が、『主はご自分で選ばれた二つの家を退けられた』と言っているのを、あなたは見ていないのか。こうして彼らはわたしの民を侮り、もはや一つの国とはみなしていない。」</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 74:16–17; エレミヤ書 31:35–36; 詩篇 104:19"> 主はこう言われる。「もし、昼と夜とのわたしの契約がなく、わたしが天と地の定めを設けなかったのなら、</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 31:37; イザヤ書 14:1; ホセア書 2:23"> わたしはヤコブの子孫と、わたしのしもべダビデの子孫を退け、彼の子孫からアブラハム、イサク、ヤコブの子孫を治める者を立てることもないだろう。しかし、わたしは彼らを捕囚から帰らせ、彼らをあわれむ。」</span>
</div>

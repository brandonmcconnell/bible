<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 25:1; 歴代誌 第二 36:5; エレミヤ書 45:1"> ユダの王ヨシヤの子エホヤキムの治世第四年に、主からエレミヤにこの言葉が臨んで言われた。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 30:2; エレミヤ書 25:3; エレミヤ書 1:10"> 「一巻の巻物を取り、わたしがあなたに語ったすべての言葉をそこに書き記せ。ヨシヤの時代にわたしがあなたに語り始めた日から今日まで、イスラエル、ユダ、すべての国々に対して語った言葉を。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 18:8; 使徒の働き 3:19; エレミヤ書 26:3"> ユダの家が、わたしが彼らに行おうと考えているすべての災いを聞き、それぞれ悪い道から立ち返るかもしれない。そうすれば、わたしは彼らの咎と罪を赦す。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 32:12; エレミヤ書 36:32; エゼキエル書 2:9"> そこでエレミヤはネリヤの子バルクを呼んだ。バルクは、主がエレミヤに語られたすべての言葉を、エレミヤの口から聞いて巻物に書き記した。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 32:2; エレミヤ書 33:1; コリント人への第二の手紙 11:23"> エレミヤはバルクに命じて言った。「私は行動を制限されていて、主の家に入ることができない。</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 36:8–9; エレミヤ書 26:2; エレミヤ書 22:2"> それゆえ、あなたが行って、断食の日に、私の口から聞いて書いた巻物から主の言葉を、主の家で民の耳に読んで聞かせなさい。町々から来るユダのすべての人々の耳にも、それを読んで聞かせなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 36:3; エレミヤ書 21:5; 歴代誌 第二 33:12–13"> もしかすると、彼らは主の前に願いを申し上げ、それぞれ悪い道から立ち返るかもしれない。主がこの民に対して告げられた怒りと憤りは大きいからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 1:17; コリント人への第一の手紙 16:10; ルカ 4:16–30"> ネリヤの子バルクは、預言者エレミヤが命じたすべてのことに従い、主の家で巻物から主の言葉を読んだ。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代誌 第二 20:3; ヨナ書 3:5; エステル記 4:16"> ユダの王ヨシヤの子エホヤキムの治世第五年、第九の月に、エルサレムのすべての民と、ユダの町々からエルサレムに来たすべての民は、主の前に断食を布告した。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 36:11; エレミヤ書 26:10; エレミヤ書 52:25"> その時、バルクは主の家で、書記シャファンの子ゲマルヤの部屋から、巻物に記されたエレミヤの言葉をすべての民の耳に読んで聞かせた。その部屋は上の庭にあり、主の家の新しい門の入口にあった。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 36:10; 歴代誌 第二 34:20; 列王記第二 25:22"> シャファンの孫で、ゲマルヤの子であるミカヤは、巻物から主のすべての言葉を聞くと、</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 26:22; 列王記第二 22:12; エレミヤ書 36:25"> 王の家にある書記の部屋へ下って行った。見よ、そこにはすべての高官たち、すなわち書記エリシャマ、シェマヤの子デラヤ、アクボルの子エルナタン、シャファンの子ゲマルヤ、ハナンヤの子ゼデキヤ、そのほかのすべての高官たちが座っていた。</span>
<span className="v" id="v13" data-v="13" data-xref="列王記第二 22:10; 歴代誌 第二 34:24; 歴代誌 第二 34:16–18"> ミカヤは、バルクが民の耳に巻物を読んで聞かせた時に自分が聞いたすべての言葉を、彼らに告げた。</span>
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 36:2; エレミヤ書 41:18; エレミヤ書 41:1–2"> そこで、すべての高官たちは、クシのひ孫で、シェレムヤの孫、ネタヌヤの子であるエフディをバルクのもとへ遣わして言わせた。「あなたが民の耳に読んで聞かせた巻物を手に取り、来なさい。」<br />そこで、ネリヤの子バルクは巻物を手に取って、彼らのもとへ来た。</span>
<span className="v" id="v15" data-v="15"> 彼らはバルクに言った。「さあ、座って、私たちにそれを読んで聞かせなさい。」<br />そこでバルクは、彼らに読んで聞かせた。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 13:18; エレミヤ書 36:24; アモス書 7:10–11"> 彼らはそのすべての言葉を聞くと、恐れに打たれて互いに顔を見合わせ、バルクに言った。「私たちはこれらすべての言葉を、必ず王に告げなければならない。」</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネ 9:15; ヨハネ 9:10–11; ヨハネ 9:26–27"> 彼らはバルクに尋ねた。「さあ、私たちに教えてほしい。あなたはどのようにして、彼の口からこれらすべての言葉を書いたのか。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 36:4; エレミヤ書 36:2; 箴言 26:4–5"> バルクは彼らに答えた。「彼がその口で、これらすべての言葉を私に語り、私はそれを墨で巻物に書きました。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王記第一 17:3; 列王記第一 18:10; エレミヤ書 26:20–24"> すると高官たちはバルクに言った。「あなたとエレミヤは行って身を隠しなさい。あなたがたがどこにいるか、だれにも知られてはならない。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 36:12; エレミヤ書 36:21"> 彼らは巻物を書記エリシャマの部屋に保管してから、王のいる中庭へ入って行き、王の耳にすべての言葉を告げた。</span>
<span className="v" id="v21" data-v="21" data-xref="列王記第二 22:10; 歴代誌 第二 34:18; エゼキエル書 2:4–5"> そこで王はエフディを遣わして巻物を取りに行かせた。彼は書記エリシャマの部屋からそれを取り出し、王と、王のそばに立っていたすべての高官たちの耳に読んで聞かせた。</span>
<span className="v" id="v22" data-v="22" data-xref="アモス書 3:15; エレミヤ書 22:14–16; エレミヤ書 36:9"> 第九の月で、王は冬の家に座っており、その前では火鉢の火が燃えていた。</span>
<span className="v" id="v23" data-v="23" data-xref="列王記第一 22:8; 箴言 21:30; 列王記第一 22:27"> エフディが三、四欄を読み終えるたびに、王は書記の小刀でそれを切り取り、火鉢の火の中に投げ入れた。ついには、巻物全体が火鉢の火で焼き尽くされた。</span>
<span className="v" id="v24" data-v="24" data-xref="エレミヤ書 36:16; 詩篇 36:1; ヨナ書 3:6"> 王も、これらすべての言葉を聞いた家来たちも恐れず、衣を引き裂かなかった。</span>
<span className="v" id="v25" data-v="25" data-xref="創世記 37:22; エレミヤ書 36:12; 使徒の働き 5:34–39"> エルナタン、デラヤ、ゲマルヤは、巻物を焼かないよう王に願ったが、王は彼らの言うことを聞かなかった。</span>
<span className="v" id="v26" data-v="26" data-xref="列王記第一 17:3; 列王記第一 19:1–3; 列王記第一 19:14"> 王は、王の子エラフメエル、アズリエルの子セラヤ、アブデルの子シェレムヤに、書記バルクと預言者エレミヤを捕らえるよう命じた。しかし、主は彼らを隠された。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 36:4"> 王が巻物と、バルクがエレミヤの口から聞いて書いた言葉を焼いた後、主の言葉がエレミヤに臨んで言われた。</span>
<span className="v" id="v28" data-v="28" data-xref="ゼカリヤ書 1:5–6; ヨブ記 23:13; エレミヤ書 44:28"> 「もう一度、別の巻物を取り、ユダの王エホヤキムが焼いた最初の巻物に記されていた、以前のすべての言葉を書き記せ。</span>
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 30:10; エレミヤ書 26:9; 申命記 29:19"> ユダの王エホヤキムについては、こう言え。『主はこう言われる。あなたはこの巻物を焼き、「なぜ、この中に『バビロンの王は必ず来て、この地を滅ぼし、そこから人も動物も絶えさせる』と書いたのか」と言った。</span>
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 22:30; 列王記第二 24:12–15; 創世記 31:40"> それゆえ、主はユダの王エホヤキムについてこう言われる。彼にはダビデの王座に座る者がいなくなる。その死体は、昼は暑さに、夜は霜にさらされる。</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 29:1; エレミヤ書 19:15; エレミヤ書 35:17"> わたしは彼とその子孫と家来たちを、その咎のために罰する。わたしは彼らとエルサレムの住民とユダの人々に、わたしが彼らに対して告げたすべての災いをもたらす。彼らが聞こうとしなかったからだ。』」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="エレミヤ書 36:4; エレミヤ書 36:18; 出エジプト記 4:15–16"> そこでエレミヤは別の巻物を取り、ネリヤの子である書記バルクに渡した。バルクは、ユダの王エホヤキムが火で焼いた巻物のすべての言葉を、エレミヤの口から聞いてそこに書き記した。さらに、それと同じような言葉が多く加えられた。</span>
</div>

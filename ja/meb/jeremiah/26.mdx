<span className="v" id="v1" data-v="1" data-xref="歴代誌 第二 36:4–5; エレミヤ書 27:1; 列王記第二 23:34–36"> ユダの王ヨシヤの子エホヤキムの治世の初めに、主からこの言葉が臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 4:2; 使徒の働き 20:27; マタイ 28:20"> 「主はこう言われる。『主の家の庭に立ち、主の家に礼拝しに来るユダのすべての町の人々に、わたしが語るよう命じるすべての言葉を語れ。一言も省いてはならない。</span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 36:3; イザヤ書 1:16–19; エレミヤ書 18:7–10"> もしかすると、彼らは聞き、それぞれ悪い道から立ち返るかもしれない。そうすれば、わたしは彼らの悪い行いのために行おうと考えている災いを思い直す。』」</span>
<span className="v" id="v4" data-v="4" data-xref="列王記第一 9:6; エレミヤ書 44:10; イザヤ書 1:20"> 「あなたは彼らにこう言え。『主はこう言われる。「もしあなたがたがわたしに聞き従わず、わたしがあなたがたの前に置いた律法に従って歩まず、</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 11:7; 列王記第二 9:7; エレミヤ書 7:13"> わたしが朝早くから繰り返し遣わしている、わたしのしもべである預言者たちの言葉に聞き従わないなら――あなたがたはこれまで聞き従わなかった――</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 24:9; 列王記第二 22:19; エレミヤ書 25:18"> わたしはこの家をシロのようにし、この町を地のすべての国々にとって呪いの的とする。」』」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 5:31; ミカ書 3:11; 使徒の働き 5:17"> 祭司たち、預言者たち、すべての民は、エレミヤが主の家でこれらの言葉を語るのを聞いた。</span>
<span className="v" id="v8" data-v="8" data-xref="哀歌 4:13–14; 使徒の働き 7:52; エレミヤ書 18:18"> エレミヤが、主からすべての民に語るよう命じられたことをすべて語り終えると、祭司たち、預言者たち、すべての民は彼を捕らえて言った。「おまえは必ず死ななければならない。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 4:17–19; 使徒の働き 19:24–32; ミカ書 2:6"> なぜ、おまえは主の名によって、『この家はシロのようになり、この町は荒れ果て、住む者がいなくなる』と預言したのか。」すべての民は主の家でエレミヤの周りに押し寄せた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 36:10; エレミヤ書 38:4–6; エレミヤ書 37:14–16"> ユダの高官たちはこれらのことを聞くと、王の家から主の家へ上って来て、主の家の新しい門の入口に座った。</span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 38:4; マタイ 26:66; 申命記 18:20"> 祭司たちと預言者たちは、高官たちとすべての民に言った。「この男は死刑に値する。あなたがたが自分の耳で聞いたとおり、この町に対して預言したからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 5:29; エレミヤ書 26:15; 使徒の働き 4:19"> そこでエレミヤは、すべての高官たちとすべての民に言った。「主が私を遣わし、この家とこの町に対して、あなたがたの聞いたこれらすべての言葉を預言するよう命じられたのです。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨナ書 3:9; ヨナ書 4:2; イザヤ書 1:19"> それゆえ今、あなたがたの道と行いを改め、あなたがたの神、主の声に聞き従ってください。そうすれば、主はあなたがたに告げられた災いを思い直されます。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 9:25; サムエル記第二 15:26; エレミヤ書 38:5"> 見よ、私はあなたがたの手の中にいます。あなたがたの目に良く正しいと思うことを、私に行ってください。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 35:33; 箴言 6:17; マタイ 26:25"> ただし、よく知っておいてください。もし私を殺すなら、あなたがた自身と、この町とその住民の上に、罪のない者の血をもたらすことになります。主が本当に私をあなたがたのもとに遣わし、これらすべての言葉をあなたがたの耳に語らせたからです。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 5:34–39; 使徒の働き 23:29; 使徒の働き 25:25"> すると、高官たちとすべての民は、祭司たちと預言者たちに言った。「この男は死刑に値しない。私たちの神、主の名によって私たちに語ったからだ。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 5:34; ミカ書 1:1"> その時、この地の長老たちの何人かが立ち上がり、民の全会衆に語った。</span>
<span className="v" id="v18" data-v="18" data-xref="ミカ書 1:1; ネヘミヤ記 4:2; ゼカリヤ書 8:3"> 「モレシェト人ミカは、ユダの王ヒゼキヤの時代に預言し、ユダのすべての民にこう語った。『万軍の主はこう言われる。<br /><span className="pl pl-1">「シオンは畑のように耕され、</span><br /><span className="pl pl-2">エルサレムは石の山となり、</span><br /><span className="pl pl-2">主の家の山は森に覆われた高台のようになる。」』</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 32:14; サムエル記第二 24:16; イザヤ書 37:15–20"> ユダの王ヒゼキヤとユダのすべての民は、彼を殺しただろうか。ヒゼキヤは主を恐れ、主に願い求めたので、主は彼らに告げられた災いを思い直されたではないか。もし私たちが彼を殺せば、自分たちに大きな災いを招くことになる。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="サムエル記第一 7:2; ヨシュア記 9:17; ヨシュア記 15:60"> また、キルヤテ・エアリム出身のシェマヤの子ウリヤという人も、主の名によって預言した。彼はエレミヤのすべての言葉と同じように、この町とこの地に対して預言した。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイ 10:23; マタイ 14:5; エレミヤ書 36:26"> エホヤキム王と、そのすべての勇士たち、高官たちが彼の言葉を聞くと、王は彼を殺そうとした。ウリヤはそれを聞いて恐れ、エジプトへ逃げて行った。</span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 36:12; 列王記第二 22:12; 列王記第二 22:14"> そこでエホヤキム王は、アクボルの子エルナタンと、彼に同行する何人かの者をエジプトへ遣わした。</span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 2:30; ヨハネの黙示録 11:7; エゼキエル書 19:6"> 彼らはウリヤをエジプトから連れ出し、エホヤキム王のもとへ連れて来た。王は彼を剣で殺し、その死体を一般の民の墓に投げ込んだ。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="エレミヤ書 40:5–7; エレミヤ書 39:14; エレミヤ書 1:18–19"> しかし、シャファンの子アヒカムがエレミヤを守ったので、彼は殺されるために民の手に渡されなかった。</span>
</div>

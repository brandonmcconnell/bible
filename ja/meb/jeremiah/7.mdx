<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="JER" data-book-slug="jeremiah" data-book-name="エレミヤ書" data-chapter="7" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主からエレミヤに臨んだ言葉。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 26:2; ヨハネの黙示録 3:22; アモス書 7:16"> 「主の家の門に立ち、そこでこの言葉を告げて言え。『主を礼拝するために、これらの門から入るユダのすべての人々よ、主の言葉を聞け。』」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 18:11; エレミヤ書 26:13; イザヤ書 1:16–19"> イスラエルの神、万軍の主はこう言われる。「あなたがたの道と行いを改めよ。そうすれば、わたしはあなたがたをこの場所に住み続けさせる。</span>
<span className="v" id="v4" data-v="4" data-xref="ミカ書 3:11; マタイ 3:9–10; ゼパニヤ書 3:11"> 『これこそ主の神殿、主の神殿、主の神殿だ』という偽りの言葉に頼ってはならない。</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第一 6:12–13; イザヤ書 1:19; エレミヤ書 7:3"> あなたがたが自分たちの道と行いを本当に改め、人とその隣人との間に公正な裁きを本当に行い、</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 22:21–24; ゼカリヤ書 7:9–12; エレミヤ書 13:10"> 寄留者、みなしご、やもめを虐げず、この場所で罪のない者の血を流さず、自分たちを害するほかの神々に従って歩まないなら、</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 4:40; エレミヤ書 25:5; エレミヤ書 3:18"> わたしは、昔からとこしえまで、あなたがたの父祖に与えたこの地、この場所に、あなたがたを住み続けさせる。</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 28:15; エゼキエル書 13:6–16; エレミヤ書 23:14–16"> 見よ、あなたがたは何の益にもならない偽りの言葉に頼っている。</span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 7:6; 出エジプト記 20:3; ヤコブの手紙 4:1–4"> あなたがたは盗み、殺し、姦淫し、偽って誓い、バアルに香をたき、自分たちの知らなかったほかの神々に従って歩み、</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 32:34; エゼキエル書 23:37; エゼキエル書 23:39"> それから、わたしの名で呼ばれるこの家に来て、わたしの前に立ち、『私たちは救われた』と言いながら、これらすべての忌まわしいことを行うのか。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカ 19:45–46; イザヤ書 56:7; マタイ 21:13"> わたしの名で呼ばれるこの家は、あなたがたの目には強盗の巣となったのか。見よ、わたし自身がそれを見た」と、主は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 18:1; エレミヤ書 26:6; サムエル記第一 4:10–11"> 「さあ、初めにわたしの名を住まわせたシロにある、わたしの場所へ行き、わたしの民イスラエルの悪のために、わたしがそこに何をしたかを見よ。</span>
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 65:12; 歴代誌 第二 36:15–16; エレミヤ書 7:25"> 今、あなたがたがこれらすべての行いをしたので」と、主は言われる。「わたしは朝早くから繰り返しあなたがたに語ったが、あなたがたは聞かなかった。わたしが呼んでも、あなたがたは答えなかった。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 78:60; 列王記第二 25:9; エレミヤ書 7:4"> それゆえ、わたしの名で呼ばれ、あなたがたが信頼しているこの家と、わたしがあなたがたと父祖たちに与えたこの場所に、シロにしたのと同じことをする。</span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 15:1; 列王記第二 17:23; エレミヤ書 52:3"> わたしは、あなたがたのすべての兄弟、すなわちエフライムの全子孫<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「種」。">a</a></sup>を追い出したように、あなたがたをわたしの前から追い出す。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 11:14; エレミヤ書 14:11–12; エレミヤ書 15:1"> それゆえ、この民のために祈ってはならない。彼らのために叫びや祈りを上げてはならず、わたしに執り成してもならない。わたしはあなたの願いを聞かないからだ。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 8:6–18; エゼキエル書 14:23; エレミヤ書 6:27"> 彼らがユダの町々とエルサレムの通りでしていることを、あなたは見ていないのか。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 19:13; エレミヤ書 44:17–19; コリント人への第一の手紙 10:22"> 子どもたちは薪を集め、父親たちは火をつけ、女たちは粉をこね、天の女王のために菓子を作る。また、ほかの神々に注ぎのささげ物を注いで、わたしを怒らせている。</span>
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 20:11; エレミヤ書 2:19; ダニエル書 9:7–8"> 彼らが怒らせているのは、わたしなのか」と、主は言われる。「彼ら自身ではないのか。自ら恥を受けることになる。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 42:18; 哀歌 2:3–5; イザヤ書 42:25"> それゆえ、主なる神はこう言われる。「見よ、わたしの怒りと憤りはこの場所に注がれる。人にも動物にも、野の木々にも地の実にも注がれる。それは燃え、消されることはない。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ホセア書 8:13; エレミヤ書 6:20; アモス書 5:21–23"> イスラエルの神、万軍の主はこう言われる。「あなたがたの全焼のささげ物を、ほかのいけにえに加え、その肉を食べよ。</span>
<span className="v" id="v22" data-v="22" data-xref="ホセア書 6:6; サムエル記第一 15:22; 詩篇 51:16–17"> わたしがあなたがたの父祖をエジプトの地から連れ出した日に、全焼のささげ物やいけにえについて、彼らに語りも命じもしなかった。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 15:26; 申命記 5:33; 出エジプト記 19:5–6"> ただ、わたしは彼らにこう命じた。『わたしの声に聞き従え。そうすれば、わたしはあなたがたの神となり、あなたがたはわたしの民となる。わたしが命じるすべての道を歩め。そうすれば、あなたがたにとって幸いとなる。』</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 81:11–12; エレミヤ書 8:5; エレミヤ書 7:26"> しかし、彼らは聞かず、耳を傾けず、自分たちの考えと悪い心のかたくなさに従って歩み、前に進まず、後ろへ退いた。</span>
<span className="v" id="v25" data-v="25" data-xref="歴代誌 第二 36:15; エレミヤ書 25:4; ネヘミヤ記 9:26"> あなたがたの父祖がエジプトの地から出た日から今日まで、わたしはわたしのしもべであるすべての預言者を、日ごとに朝早くからあなたがたに遣わしてきた。</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 16:12; 歴代誌 第二 30:8; エレミヤ書 7:24"> それでも、彼らはわたしに聞かず、耳を傾けず、うなじを堅くした。彼らは父祖たちよりもさらに悪いことを行った。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 26:2; エレミヤ書 1:7; イザヤ書 65:12"> あなたはこれらすべての言葉を彼らに語るが、彼らはあなたに聞かない。あなたが彼らに呼びかけても、彼らは答えない。</span>
<span className="v" id="v28" data-v="28" data-xref="イザヤ書 59:14–15; 箴言 1:7; イザヤ書 1:4–5"> あなたは彼らにこう言え。『これは、自分たちの神、主の声に聞き従わず、懲らしめを受け入れなかった国である。真実は滅び、彼らの口から断たれた。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨブ記 1:20; ミカ書 1:16; エレミヤ書 6:30"> 髪を切り落として捨て、裸の高台で哀歌を歌え。主が、その怒りを受ける世代を退け、見捨てられたからだ。』</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 32:34; エゼキエル書 7:20; ダニエル書 9:27"> 「ユダの子らは、わたしの目に悪いことを行った」と、主は言われる。「彼らは、わたしの名で呼ばれる家に忌まわしいものを置き、これを汚した。</span>
<span className="v" id="v31" data-v="31" data-xref="列王記第二 23:10; エレミヤ書 32:35; レビ記 18:21"> 彼らはベン・ヒノムの谷にあるトフェテの高き所を築き、そこで自分たちの息子や娘を火で焼いた。それは、わたしが命じたことではなく、わたしの心に思い浮かびもしなかった。</span>
<span className="v" id="v32" data-v="32" data-xref="エレミヤ書 19:11; エレミヤ書 19:6; 列王記第二 23:10"> それゆえ、見よ、その場所がもはや『トフェテ』とも『ベン・ヒノムの谷』とも呼ばれず、『虐殺の谷』と呼ばれる日々が来る」と、主は言われる。「彼らは場所がなくなるまで、トフェテに死者を葬る。</span>
<span className="v" id="v33" data-v="33" data-xref="エレミヤ書 12:9; 申命記 28:26; ヨハネの黙示録 19:17–18"> この民の死体は、空の鳥と地の動物の餌となり、それらを追い払う者はいない。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨハネの黙示録 18:23; ホセア書 2:11; エゼキエル書 26:13"> わたしはユダの町々とエルサレムの通りから、喜びの声と楽しみの声、花婿の声と花嫁の声を絶えさせる。この地は荒れ果てるからだ。」</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 39:1–2; 列王記第二 25:1–2; エレミヤ書 25:1"> ユダの王ゼデキヤの治世第十年、すなわちネブカドネザルの治世第十八年に、主からエレミヤに臨んだ言葉。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 37:21; ネヘミヤ記 3:25; エレミヤ書 33:1"> その時、バビロンの王の軍隊はエルサレムを包囲していた。預言者エレミヤは、ユダの王の家にある衛兵の庭に閉じ込められていた。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 34:2–3; エレミヤ書 21:4–7; エレミヤ書 26:8–9"> ユダの王ゼデキヤが彼を閉じ込めて、こう言ったからである。「なぜ、あなたは預言して言うのか。『主はこう言われる。「見よ、わたしはこの町をバビロンの王の手に渡し、彼はこれを占領する。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 39:4–7; 列王記第二 25:4–7; エレミヤ書 37:17"> ユダの王ゼデキヤはカルデア人の手から逃れられず、必ずバビロンの王の手に渡される。彼はバビロンの王と面と向かって語り、自分の目で王を見る。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 39:7; エゼキエル書 17:9–10; エゼキエル書 17:15"> 王はゼデキヤをバビロンへ連れて行く。ゼデキヤは、わたしが彼を顧みる時までそこにいる」と、主は言われる。「あなたがたがカルデア人と戦っても、勝つことはない。」』」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> エレミヤは言った。「主の言葉が私に臨んだ。</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 1:1; エレミヤ書 11:21; レビ記 25:25"> 『見よ、あなたのおじシャルムの子ハナムエルがあなたのところに来て、「アナトテにある私の畑を買ってください。それを贖って買う権利はあなたにあるからです」と言う。』」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 32:7; エレミヤ書 32:2; エレミヤ書 33:1"> すると、主の言葉のとおり、私のおじの子ハナムエルが衛兵の庭にいる私のところに来て言った。「どうか、ベニヤミンの地アナトテにある私の畑を買ってください。相続する権利も、贖う権利もあなたにあります。あなたのものとして買ってください。」<br />そこで私は、これが主の言葉であると知った。</span>
<span className="v" id="v9" data-v="9" data-xref="ゼカリヤ書 11:12–13; エステル記 3:9; 列王記第一 20:39"> 私は、おじの子ハナムエルからアナトテにある畑を買い、銀十七シェケル<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一シェケルは約10グラム、あるいは約0.35オンスである。">a</a></sup>を量って彼に渡した。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 32:44; エレミヤ書 32:12; エレミヤ書 32:25"> 私は証書に署名して封印し、証人を立て、秤で銀を量って彼に渡した。</span>
<span className="v" id="v11" data-v="11" data-xref="ルカ 2:27; コリント人への第一の手紙 11:16; 使徒の働き 26:3"> そして、封印され、規定と条件を含む購入証書と、封印されていない証書を受け取った。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 32:16; エレミヤ書 51:59; エレミヤ書 36:4–5"> 私は、おじの子ハナムエルと、購入証書に署名した証人たちの前で、また衛兵の庭に座っていたすべてのユダヤ人の前で、その購入証書をネリヤの子で、マフセヤの孫であるバルクに渡した。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 私は彼らの前でバルクに命じて言った。</span>
<span className="v" id="v14" data-v="14"> 「イスラエルの神、万軍の主はこう言われる。『これらの証書、すなわち封印された購入証書と、封印されていない証書を取り、土の器に入れよ。長い間保存できるようにするためだ。』</span>
<span className="v" id="v15" data-v="15" data-xref="ゼカリヤ書 3:10; アモス書 9:14–15; エレミヤ書 30:18"> イスラエルの神、万軍の主はこう言われる。『この地では、家や畑やぶどう畑が再び買われるようになる。』」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 12:1; 創世記 32:9–12; ピリピ人への手紙 4:6–7"> 私は購入証書をネリヤの子バルクに渡した後、主に祈って言った。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ルカ 1:37; エレミヤ書 32:27; 創世記 18:14"> 「ああ、主なる神よ。見よ、あなたは大いなる力と伸ばした腕によって、天と地を造られた。あなたにとって不可能なことは何一つない。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 10:16; 申命記 5:9–10; 出エジプト記 34:7"> あなたは幾千の者に慈しみを示し、父祖の咎を、その後の子らの懐に報いられる。偉大で力ある神よ、あなたの名は万軍の主。</span>
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 17:10; マタイ 16:27; 詩篇 62:12"> あなたの計画は偉大で、御業には力がある。あなたの目はすべての人の道に開かれ、一人一人にその道と、その行いの実に従って報いられる。</span>
<span className="v" id="v20" data-v="20" data-xref="ネヘミヤ記 9:10; サムエル記第二 7:23; 出エジプト記 10:2"> あなたはエジプトの地でしるしと不思議を行い、今日に至るまで、イスラエルの中でも、ほかの人々の間でも御業を行って、ご自分の名を今日のように高くされた。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 6:6; 申命記 26:8; 詩篇 105:43"> あなたは、しるしと不思議、強い手と伸ばした腕、大いなる恐怖をもって、あなたの民イスラエルをエジプトの地から連れ出された。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 3:8; 出エジプト記 13:5; エレミヤ書 11:5"> そして、父祖たちに与えると誓われたこの地、乳と蜜の流れる地を彼らに与えられた。</span>
<span className="v" id="v23" data-v="23" data-xref="エズラ記 9:7; 詩篇 78:54–55; ダニエル書 9:10–14"> 彼らは入って来てこの地を所有したが、あなたの声に聞き従わず、あなたの律法に従って歩まなかった。あなたが彼らに行うよう命じられたことを、彼らは何一つ行わなかった。それゆえ、あなたはこのすべての災いを彼らの上にもたらされた。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="エレミヤ書 32:36; 申命記 4:26; ヨシュア記 23:15–16"> 見よ、町を攻め取るために包囲の塁が築かれている。剣と飢饉と疫病のために、町はこれを攻めるカルデア人の手に渡されている。あなたが語られたことが起こった。見よ、あなたはそれをご覧になっている。</span>
<span className="v" id="v25" data-v="25" data-xref="エレミヤ書 32:24; 詩篇 97:2; 詩篇 77:19"> 主なる神よ、町がカルデア人の手に渡されているのに、あなたは私に、『代金を払って畑を買い、証人を立てよ』と言われた。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> その時、主の言葉がエレミヤに臨んだ。</span>
<span className="v" id="v27" data-v="27" data-xref="マタイ 19:26; エレミヤ書 32:17; イザヤ書 64:8"> 「見よ、わたしは主、すべての肉なるものの神である。わたしにとって難しすぎることがあるだろうか。</span>
<span className="v" id="v28" data-v="28" data-xref="エレミヤ書 32:3; エレミヤ書 32:24; エレミヤ書 19:7–12"> それゆえ、主はこう言われる。見よ、わたしはこの町をカルデア人の手と、バビロンの王ネブカドネザルの手に渡す。彼はこれを占領する。</span>
<span className="v" id="v29" data-v="29" data-xref="エレミヤ書 21:10; エレミヤ書 19:13; エレミヤ書 52:13"> この町と戦っているカルデア人は来て、この町に火をつけて焼く。その屋上でバアルに香をたき、ほかの神々に注ぎのささげ物を注いで、わたしを怒らせた家々も焼く。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="エレミヤ書 7:22–26; 申命記 9:7–12; エレミヤ書 25:7"> イスラエルの子らとユダの子らは、若いころから、わたしの目に悪いことだけを行ってきた。イスラエルの子らは、自分たちの手で造ったものによって、ただわたしを怒らせてきた」と、主は言われる。</span>
<span className="v" id="v31" data-v="31" data-xref="列王記第二 23:27; エレミヤ書 27:10; 列王記第二 21:4–7"> 「この町は、建てられた日から今日に至るまで、わたしの怒りと憤りを引き起こしてきた。それゆえ、わたしはこれをわたしの前から取り除く。</span>
<span className="v" id="v32" data-v="32" data-xref="ダニエル書 9:8; エレミヤ書 2:26; イザヤ書 1:4–6"> イスラエルの子らとユダの子らが、わたしを怒らせるために行ったすべての悪のためである。彼ら、その王たち、高官たち、祭司たち、預言者たち、ユダの人々、エルサレムの住民が悪を行った。</span>
<span className="v" id="v33" data-v="33" data-xref="エレミヤ書 7:13; エレミヤ書 2:27; エゼキエル書 8:16"> 彼らは顔ではなく、背をわたしに向けた。わたしは朝早くから繰り返し彼らを教えたが、彼らは聞かず、懲らしめを受け入れなかった。</span>
<span className="v" id="v34" data-v="34" data-xref="エレミヤ書 7:30; エゼキエル書 8:5–16; 列王記第二 21:4–7"> 彼らは、わたしの名で呼ばれる家に忌まわしいものを置き、これを汚した。</span>
<span className="v" id="v35" data-v="35" data-xref="エレミヤ書 7:31; 歴代誌 第二 33:6; レビ記 18:21"> 彼らはベン・ヒノムの谷にバアルの高き所を築き、息子や娘をモレクのために火の中を通らせた。わたしはそのようなことを彼らに命じなかった。彼らがこの忌まわしいことを行ってユダに罪を犯させることは、わたしの心に思い浮かびもしなかった。」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="エレミヤ書 32:24; エレミヤ書 32:3; エレミヤ書 32:28"> それゆえ今、イスラエルの神、主は、あなたがたが「この町は剣と飢饉と疫病によってバビロンの王の手に渡された」と言っているこの町について、こう言われる。</span>
<span className="v" id="v37" data-v="37" data-xref="エレミヤ書 23:3; エレミヤ書 23:6; エゼキエル書 34:12–14"> 「見よ、わたしは怒りと憤りと大いなる激怒によって彼らを追いやったすべての国々から、彼らを集める。彼らを再びこの場所に連れ戻し、安全に住まわせる。</span>
<span className="v" id="v38" data-v="38" data-xref="エレミヤ書 24:7; エゼキエル書 11:19–20; ヘブル人への手紙 8:10"> 彼らはわたしの民となり、わたしは彼らの神となる。</span>
<span className="v" id="v39" data-v="39" data-xref="エゼキエル書 11:19–20; 使徒の働き 4:32; ヨハネ 17:21"> わたしは彼らに一つの心と一つの道を与え、彼ら自身と、その後の子らの幸いのために、いつまでもわたしを恐れさせる。</span>
<span className="v" id="v40" data-v="40" data-xref="エレミヤ書 31:31–33; エゼキエル書 36:26; エレミヤ書 24:7"> わたしは彼らと永遠の契約を結ぶ。わたしは彼らから離れず、彼らに良いことをし続ける。また、彼らがわたしから離れないように、わたしへの恐れを彼らの心に置く。</span>
<span className="v" id="v41" data-v="41" data-xref="エレミヤ書 24:6; ゼパニヤ書 3:17; イザヤ書 62:5"> わたしは彼らに良いことをすることを喜び、心を尽くし、全身全霊をもって、確かにこの地に彼らを植える。」</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="エレミヤ書 31:28; ヨシュア記 23:14–15; エレミヤ書 33:10–11"> 主はこう言われる。「わたしがこの民にこのすべての大きな災いをもたらしたように、わたしが彼らに約束したすべての良いことをもたらす。</span>
<span className="v" id="v43" data-v="43" data-xref="エゼキエル書 37:11–14; エレミヤ書 32:15; エレミヤ書 32:36"> あなたがたが、『この地は荒れ果て、人も動物もいない。カルデア人の手に渡された』と言っているこの地で、再び畑が買われる。</span>
<span className="v" id="v44" data-v="44" data-xref="エレミヤ書 17:26; エレミヤ書 33:26; エレミヤ書 33:11"> ベニヤミンの地、エルサレムの周辺、ユダの町々、山地の町々、低地の町々、南部の町々で、人々は代金を払って畑を買い、証書に署名し、封印し、証人を立てる。わたしが彼らを捕囚から帰らせるからだ」と、主は言われる。</span>
</div>

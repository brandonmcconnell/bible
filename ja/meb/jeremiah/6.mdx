<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 4:31; イザヤ書 1:8; イザヤ書 3:16–17"> わたしは、美しく繊細な娘なるシオンを滅ぼす。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカ 19:43; エレミヤ書 39:1–3; 列王記第二 24:10–12"> 羊飼いたちがその群れを連れて彼女のもとに来る。彼女を取り囲んで天幕を張り、それぞれ自分の場所で群れに草を食べさせる。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 15:8; ゼパニヤ書 2:4; ヨエル書 3:9"> 「彼女に対する戦いの準備をせよ。立ち上がれ。真昼に攻め上ろう。ああ、災いだ。日は傾き、夕暮れの影が長くなっている。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 52:13; イザヤ書 32:14; 歴代誌 第二 36:19"> 立ち上がれ。夜のうちに攻め上り、彼女の宮殿を破壊しよう。」</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 20:19–20; エレミヤ書 32:24"> 万軍の主はこう言われる。「木を切り倒し、エルサレムに向かって塁を築け。この町は罰せられるべき町であり、その中は虐げで満ちている。</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 20:8; エゼキエル書 7:23; エゼキエル書 7:11"> 井戸が水を湧き出させるように、彼女は悪を湧き出させる。その中では暴虐と破壊の音が聞こえ、病と傷が絶えずわたしの前にある。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 23:18; ホセア書 9:12; エレミヤ書 17:23"> エルサレムよ、警告を受け入れよ。そうしなければ、わたしの心はあなたから離れ、あなたを荒れ果てた、人の住まない地とする。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 49:9; エレミヤ書 16:16; オバデヤ書 1:5–6"> 万軍の主はこう言われる。「彼らは、ぶどうの木を摘み尽くすように、イスラエルの残りの者を徹底して刈り取る。ぶどうを摘む者のように、もう一度かごへ手を伸ばせ。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 7:51; エレミヤ書 7:26; ヨハネ 7:7"> 私はだれに語り、警告すれば、彼らは聞くのだろうか。見よ、彼らの耳には割礼がなく、聞くことができない。見よ、主の言葉は彼らのそしりの的となり、彼らはそれを喜ばない。</span>
<span className="v" id="v11" data-v="11" data-xref="エレミヤ書 9:21; エレミヤ書 20:9; ミカ書 3:8"> それゆえ、私は主の憤りで満たされ、それを抑えていることに疲れた。<br /><span className="pl pl-1">「それを通りにいる子どもたちの上に注げ。</span><br /><span className="pl pl-2">若者たちの集まりにも注げ。</span><br /><span className="pl pl-1">夫も妻とともに捕らえられ、</span><br /><span className="pl pl-2">年老いた者も、長く生きた者とともに捕らえられる。</span></span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 8:10; イザヤ書 5:25; 申命記 28:39–43"> <span className="pl pl-1">彼らの家は他人のものとなり、</span><br /><span className="pl pl-2">畑も妻もともに奪われる。</span><br /><span className="pl pl-1">わたしがこの地の住民に向かって</span><br /><span className="pl pl-2">手を伸ばすからだ」と、主は言われる。</span></span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 23:11; エレミヤ書 8:10; ミカ書 3:11"> <span className="pl pl-1">「彼らは小さい者から大きい者まで、</span><br /><span className="pl pl-2">皆、利得をむさぼっている。</span><br /><span className="pl pl-1">預言者から祭司に至るまで、</span><br /><span className="pl pl-2">皆、偽りを行っている。</span></span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 13:10; エレミヤ書 23:17; エレミヤ書 4:10"> <span className="pl pl-1">彼らはわたしの民の傷を上辺だけで癒やし、</span><br /><span className="pl pl-2">平和がないのに、『平和だ、平和だ』と言う。</span></span>
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 8:12; マタイ 15:14; エレミヤ書 3:3"> <span className="pl pl-1">彼らは忌まわしいことを行った時、恥じただろうか。</span><br /><span className="pl pl-2">いや、少しも恥じず、</span><br /><span className="pl pl-2">顔を赤らめることさえできなかった。</span><br /><span className="pl pl-1">それゆえ、彼らは倒れる者たちの中で倒れる。</span><br /><span className="pl pl-2">わたしが彼らを罰する時、彼らは倒される」と、主は言われる。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 30:21; 申命記 32:7; エレミヤ書 18:15"> 主はこう言われる。「道に立って見よ。昔からの道について、『良い道はどこにあるのか』と尋ね、その道を歩め。そうすれば、心に安らぎを見いだす。しかし、彼らは『私たちはその道を歩まない』と言った。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 25:4; イザヤ書 58:1; ゼカリヤ書 7:11"> わたしはあなたがたの上に見張り人を立て、『ラッパの音に耳を傾けよ』と言った。しかし、彼らは『私たちは耳を傾けない』と言った。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 4:10; エレミヤ書 31:10; ミカ書 6:5"> それゆえ、諸国民よ、聞け。会衆よ、彼らの中に何があるかを知れ。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 1:2; エレミヤ書 8:9; エレミヤ書 17:10"> 地よ、聞け。見よ、わたしはこの民に災いをもたらす。それは彼らの思いが結んだ実である。彼らはわたしの言葉に耳を傾けず、わたしの律法を退けたからだ。</span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 1:11; アモス書 5:21–22; イザヤ書 60:6"> シェバから乳香が、遠い国から香りの良い葦が、わたしのもとに来ても何になるのか。あなたがたの全焼のささげ物は受け入れられず、いけにえもわたしを喜ばせない。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 8:14; エゼキエル書 3:20; エレミヤ書 13:16"> それゆえ、主はこう言われる。「見よ、わたしはこの民の前につまずきとなるものを置く。父も子もともにそれにつまずき、隣人もその友も滅びる。」</span>
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 50:41–43; エレミヤ書 10:22; エレミヤ書 6:1"> 主はこう言われる。「見よ、北の国から一つの民が来る。地の果てから大いなる国が奮い立つ。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 13:18; エレミヤ書 50:42; ルカ 21:25–26"> 彼らは弓と槍を手に取る。残酷で、あわれみがない。その声は海のようにとどろき、馬に乗って進む。娘なるシオンよ、彼らは戦士のように隊列を整え、あなたに向かって来る。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="エレミヤ書 4:31; エレミヤ書 50:43; エレミヤ書 49:24"> 私たちはその知らせを聞き、手から力が抜けた。苦しみが私たちを捕らえ、産みの苦しみにある女のような痛みが襲った。</span>
<span className="v" id="v25" data-v="25" data-xref="エレミヤ書 49:29; エレミヤ書 20:10; 詩篇 31:13"> 野に出てはならない。道を歩いてもならない。敵の剣と恐怖が四方にあるからだ。</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 4:8; ゼカリヤ書 12:10; イザヤ書 32:11"> 娘なるわたしの民よ、粗布をまとい、灰の中を転げ回れ。一人息子を失った時のように、激しく嘆き悲しめ。破壊する者が突然、私たちに襲いかかるからだ。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 1:18; エレミヤ書 15:20; エゼキエル書 3:8–10"> 「わたしはあなたを、わたしの民の中で金属を試す者として、また、とりでとして立てた。彼らの道を知り、試すためである。</span>
<span className="v" id="v28" data-v="28" data-xref="エレミヤ書 9:4; エレミヤ書 5:23; エレミヤ書 18:18"> 彼らは皆、頑迷な反逆者で、歩き回って人をそしる。彼らは青銅と鉄であり、皆、堕落している。</span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 24:13; エレミヤ書 9:7; ペテロの手紙第一 4:12"> ふいごは激しく吹き、鉛は火で焼き尽くされる。精錬はむなしく続けられるが、悪者は取り除かれない。</span>
<span className="v" id="v30" data-v="30" data-xref="ホセア書 9:17; 詩篇 119:119; イザヤ書 1:22"> 人々は彼らを『捨てられた銀』と呼ぶ。主が彼らを退けられたからだ。」</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エステル記 9:20; 使徒の働き 15:23; ヘブル人への手紙 13:22"> これは、預言者エレミヤがエルサレムから、捕囚となった長老たちのうち生き残っていた者、祭司たち、預言者たち、またネブカドネザルがエルサレムからバビロンへ捕らえ移したすべての民に送った手紙の言葉である。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 22:24–28; エレミヤ書 27:20; 歴代誌 第二 36:9–10"> これは、エコニヤ王、王母、宦官たち、ユダとエルサレムの高官たち、職人たち、鍛冶職人たちがエルサレムを去った後のことであった。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 8:11; 歴代誌 第二 34:20; エレミヤ書 39:14"> エレミヤは、ユダの王ゼデキヤがバビロンの王ネブカドネザルのもとへ遣わした、シャファンの子エルアサとヒルキヤの子ゲマルヤに手紙を託した。そこにはこう記されていた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 24:5; イザヤ書 10:5–6; イザヤ書 45:7"> イスラエルの神、万軍の主は、わたしがエルサレムからバビロンへ捕らえ移させたすべての捕囚の民にこう言われる。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 29:28; エレミヤ書 29:10; エゼキエル書 28:26"> 「家を建てて住み、園を造ってその実を食べよ。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 24:3–4; 創世記 24:51; 創世記 28:1–4"> 妻をめとり、息子や娘をもうけよ。息子たちには妻をめとらせ、娘たちは夫に嫁がせて、息子や娘を産ませよ。そこで数を増し、減ってはならない。</span>
<span className="v" id="v7" data-v="7" data-xref="テモテへの手紙第一 2:1–2; エズラ記 6:10; ペテロの手紙第一 2:13–17"> わたしがあなたがたを捕らえ移させた町の平和を求め、その町のために主に祈れ。その町の平和によって、あなたがたも平和を得るからだ。」</span>
<span className="v" id="v8" data-v="8" data-xref="エペソ人への手紙 5:6; エレミヤ書 5:31; テサロニケ人への第二の手紙 2:9–11"> イスラエルの神、万軍の主はこう言われる。「あなたがたの間にいる預言者や占い師に欺かれてはならない。あなたがたが見させている夢にも耳を傾けてはならない。</span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 27:15; エレミヤ書 29:31; エレミヤ書 29:23"> 彼らはわたしの名によって、あなたがたに偽りを預言している。わたしは彼らを遣わしていない」と、主は言われる。</span>
<span className="v" id="v10" data-v="10" data-xref="ダニエル書 9:2; ゼカリヤ書 7:5; エレミヤ書 24:6–7"> 主はこう言われる。「バビロンに定められた七十年が満ちた後、わたしはあなたがたを顧み、あなたがたについて語った良い言葉を実現して、この場所に帰らせる。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 55:8–12; 詩篇 33:11; ミカ書 4:12"> わたしがあなたがたのために抱いている計画を、わたしは知っている」と、主は言われる。「それは平和の計画であって、災いの計画ではない。あなたがたに将来と希望を与えるためのものだ。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイ 7:7–8; エレミヤ書 33:3; 詩篇 50:15"> あなたがたはわたしを呼び求め、わたしのもとに来て祈る。わたしはあなたがたの願いを聞く。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 4:29–31; 詩篇 119:2; マタイ 7:7"> あなたがたが心を尽くしてわたしを捜し求めるなら、わたしを見つける。</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 36:1–38; エレミヤ書 30:3; 歴代誌上 28:9"> わたしはあなたがたに見いだされる」と、主は言われる。「わたしはあなたがたを捕囚から帰らせる。わたしがあなたがたを追いやったすべての国々、すべての場所からあなたがたを集める」と、主は言われる。「わたしがあなたがたを捕らえ移させた場所から、再び連れ戻す。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 29:8–9; エレミヤ書 28:1–17; エゼキエル書 1:3"> あなたがたは、「主はバビロンで私たちのために預言者たちを起こされた」と言った。</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 38:2–3; エレミヤ書 38:17–23; エゼキエル書 17:12–21"> それゆえ、主はダビデの王座に着く王と、この町に住むすべての民、すなわちあなたがたとともに捕囚にならなかった兄弟たちについて、こう言われる。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 24:8–10; エレミヤ書 29:18; エレミヤ書 24:1–3"> 万軍の主はこう言われる。「見よ、わたしは彼らに剣と飢饉と疫病を送り、彼らを、あまりにも悪くて食べられない腐ったいちじくのようにする。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代誌 第二 29:8; エレミヤ書 15:4; エレミヤ書 42:18"> わたしは剣と飢饉と疫病をもって彼らを追い、地のすべての王国の間であちこちに追い回される者とする。また、わたしが彼らを追いやるすべての国々で、恐怖の的、驚きの的、あざけりの的、そしりの的とする。</span>
<span className="v" id="v19" data-v="19" data-xref="エレミヤ書 6:19; エレミヤ書 26:5; エレミヤ書 7:24–26"> 彼らがわたしの言葉に聞き従わなかったからだ」と、主は言われる。「わたしは、わたしのしもべである預言者たちを、朝早くから繰り返し彼らに遣わした。しかし、あなたがたは聞こうとしなかった」と、主は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 24:5; ミカ書 4:10; エゼキエル書 3:15"> それゆえ、わたしがエルサレムからバビロンへ送り出したすべての捕囚の民よ、主の言葉を聞け。</span>
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 14:14–15; 哀歌 2:14; エレミヤ書 29:8–9"> イスラエルの神、万軍の主は、わたしの名によってあなたがたに偽りを預言する、コラヤの子アハブとマアセヤの子ゼデキヤについて、こう言われる。「見よ、わたしは彼らをバビロンの王ネブカドネザルの手に渡す。彼はあなたがたの目の前で彼らを殺す。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 65:15; ダニエル書 3:6; ダニエル書 3:21"> バビロンにいるユダのすべての捕囚の民は、彼らの名を用いて、『主があなたを、バビロンの王が火で焼き殺したゼデキヤとアハブのようにされるように』と呪うようになる。</span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 23:14; ヘブル人への手紙 4:13; マラキ書 3:5"> 彼らはイスラエルで愚かなことを行い、隣人の妻たちと姦淫し、わたしが命じていない偽りの言葉を、わたしの名によって語ったからだ。わたしはそれを知っており、その証人である」と、主は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="エレミヤ書 29:31–32"> ネヘラム人シェマヤについては、こう語れ。</span>
<span className="v" id="v25" data-v="25" data-xref="エレミヤ書 37:3; エレミヤ書 29:29; エレミヤ書 52:24"> 「イスラエルの神、万軍の主はこう言われる。『あなたは自分の名で、エルサレムにいるすべての民、祭司マアセヤの子ゼパニヤ、またすべての祭司たちに手紙を送り、こう書いた。</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 20:1–2; 列王記第二 9:11; ヨハネ 10:20"> 「主は祭司エホヤダに代えて、あなたを祭司とされた。それは、主の家に監督者を置き、狂って預言者を自称する者を皆、足かせと首かせにつなぐためである。</span>
<span className="v" id="v27" data-v="27" data-xref="歴代誌 第二 25:16; エレミヤ書 43:2–3; エレミヤ書 29:26"> それなのに、なぜあなたは、あなたがたに対して預言者を自称しているアナトテのエレミヤを責めなかったのか。</span>
<span className="v" id="v28" data-v="28" data-xref="エレミヤ書 29:5; エレミヤ書 29:1; エレミヤ書 29:10"> 彼はバビロンにいる私たちのもとへ、『捕囚は長く続く。家を建てて住み、園を造ってその実を食べよ』と書き送ってきたではないか。」』」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="エレミヤ書 29:25"> 祭司ゼパニヤは、この手紙を預言者エレミヤの耳に読んで聞かせた。</span>
<span className="v" id="v30" data-v="30"> その時、主の言葉がエレミヤに臨んだ。</span>
<span className="v" id="v31" data-v="31" data-xref="エレミヤ書 29:9; エレミヤ書 29:23–24; エレミヤ書 14:14–15"> 「すべての捕囚の民にこう書き送れ。『主はネヘラム人シェマヤについてこう言われる。「シェマヤは、わたしが彼を遣わしていないのに、あなたがたに預言し、偽りを信じさせた。」</span>
<span className="v" id="v32" data-v="32" data-xref="エレミヤ書 28:16; 列王記第二 7:19–20; エレミヤ書 17:6"> それゆえ、主はこう言われる。「見よ、わたしはネヘラム人シェマヤとその子孫を罰する。彼の子孫には、この民の中に住む者が一人もいなくなる。わたしがわたしの民に行う良いことを、彼は見ることがない」と、主は言われる。「彼が主に逆らうことを語ったからだ。」』」</span>
</div>

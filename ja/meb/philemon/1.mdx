<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 1:1; エペソ人への手紙 3:1; フィレモンへの手紙 1:9"> キリスト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「キリスト」は「油を注がれた者」という意味である。">a</a></sup>・イエスの囚人であるパウロと、私たちの兄弟テモテから、愛する同労者フィレモンへ。</span>
<span className="v" id="v2" data-v="2" data-xref="ピリピ人への手紙 2:25; コロサイ人への手紙 4:17; ローマ人への手紙 16:5"> また、愛するアフィア、私たちの戦友アルキポ、そしてあなたの家に集う教会へ。</span>
<span className="v" id="v3" data-v="3" data-xref="ローマ人への手紙 1:7; エペソ人への手紙 1:2; コリント人への第二の手紙 13:14"> 私たちの父なる神と主イエス・キリストから、あなたがたに恵みと平和がありますように。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 1:8; エペソ人への手紙 1:16; テサロニケ人への第二の手紙 1:3"> 私は祈りの中であなたのことを覚え、いつも私の神に感謝しています。</span>
<span className="v" id="v5" data-v="5" data-xref="コロサイ人への手紙 1:4; エペソ人への手紙 1:15; コリント人への第一の手紙 16:1"> 主イエスに対するあなたの信仰と、すべての聖徒に対するあなたの愛について聞いているからです。</span>
<span className="v" id="v6" data-v="6" data-xref="ピリピ人への手紙 1:9–11; ペテロの第二の手紙 1:8; コロサイ人への手紙 1:9"> あなたと私たちが分かち合う信仰が、キリスト・イエスにあって私たちに与えられているすべての良いものを深く知ることによって、力強く働くようにと祈っています。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第二の手紙 7:13; テサロニケ人への手紙第一 3:9; コリント人への第二の手紙 7:4"> 兄弟よ、あなたの愛によって私たちは大きな喜びと慰めを得ました。聖徒たちの心が、あなたによって安らぎを得たからです。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="テサロニケ人への手紙第一 2:6; コリント人への第二の手紙 10:8; コリント人への第二の手紙 3:12"> それゆえ、私はキリストにあって、あなたがなすべきことを大胆に命じることもできますが、</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第二の手紙 5:20; エペソ人への手紙 4:1; ローマ人への手紙 12:1"> 愛のゆえに、むしろお願いします。年老いたこのパウロ、しかも今はイエス・キリストの囚人でもある私が、</span>
<span className="v" id="v10" data-v="10" data-xref="コロサイ人への手紙 4:9; コリント人への第一の手紙 4:15; テモテへの手紙第一 1:2"> 鎖につながれた身で父となった、わが子オネシモのことで、あなたにお願いします。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="オネシモは「役に立つ」という意味である。">b</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="テモテへの第二の手紙 4:11; ヨブ記 30:1–2; ペテロの手紙第一 2:10"> 彼は以前、あなたにとって役に立たない者でしたが、今ではあなたにも私にも役に立つ者です。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイ 6:14–15; エレミヤ書 31:20; マルコ 11:25"> 彼をあなたのもとに送り返します。彼こそ、私の心そのものです。どうか彼を受け入れてください。</span>
<span className="v" id="v13" data-v="13" data-xref="ピリピ人への手紙 1:7; エペソ人への手紙 3:1; コリント人への第一の手紙 16:17"> 福音のために鎖につながれている私に、あなたの代わりに仕えてもらおうと、彼をそばに置いておきたいと思いました。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第二の手紙 9:7; 歴代誌上 29:17; ペテロの手紙第一 5:2–3"> しかし、あなたの同意なしには何もしたくありませんでした。あなたの善意が強いられたものではなく、自発的なものとなるためです。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 50:20; 創世記 45:5–8; イザヤ書 20:6"> 彼がしばらくの間あなたから引き離されたのは、おそらく、あなたが彼といつまでも共にいられるためだったのでしょう。</span>
<span className="v" id="v16" data-v="16" data-xref="コロサイ人への手紙 3:22; マタイ 23:8; コリント人への第一の手紙 7:22"> もはや奴隷としてではなく、奴隷以上の者、愛する兄弟としてです。彼は私にとってとりわけ愛する兄弟ですが、あなたにとっては、肉においても主にあっても、なおさらでしょう。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="コリント人への第二の手紙 8:23; マタイ 10:40; フィレモンへの手紙 1:12"> ですから、あなたが私を共に働く者と認めているなら、私を迎えるように彼を迎えてください。</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 53:4–7"> もし彼があなたに何か損害を与えたか、何か借りがあるなら、それを私の勘定につけてください。</span>
<span className="v" id="v19" data-v="19" data-xref="ガラテヤ人への手紙 6:11; ガラテヤ人への手紙 5:2; コリント人への第一の手紙 4:15"> 私パウロが自分の手で書きます。私が返済します。もっとも、あなた自身までも私に負っていることは、言うまでもありませんが。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの手紙第三 1:4; フィレモンへの手紙 1:7; フィレモンへの手紙 1:12"> そうです、兄弟よ。主にあって、どうか私を喜ばせてください。主にあって、私の心を安らがせてください。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="テサロニケ人への第二の手紙 3:4; コリント人への第二の手紙 2:3; コリント人への第二の手紙 7:16"> あなたが聞き従ってくれることを確信して、私はこう書いています。私が言う以上のことまでしてくれると分かっているからです。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="コリント人への第二の手紙 1:11; ピリピ人への手紙 2:24; ヨハネの手紙第二 1:12"> それと同時に、私のために宿を用意しておいてください。あなたがたの祈りによって、再びあなたがたのもとへ行けるようになることを望んでいます。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="コロサイ人への手紙 1:7; ローマ人への手紙 16:7; コロサイ人への手紙 4:12"> キリスト・イエスにあって私と共に囚人となっているエパフラスが、あなたによろしくと言っています。</span>
<span className="v" id="v24" data-v="24" data-xref="テモテへの第二の手紙 4:10–11; コロサイ人への手紙 4:14; コロサイ人への手紙 4:10"> 私の同労者マルコ、アリスタルコ、デマス、ルカからもよろしく。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="テモテへの第二の手紙 4:22; ローマ人への手紙 16:23; ローマ人への手紙 16:20"> 私たちの主イエス・キリストの恵みが、あなたがたの霊とともにありますように。アーメン。</span>
</div>

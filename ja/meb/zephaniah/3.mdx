<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 6:6; イザヤ書 30:12; イザヤ書 59:13"> 反逆し、汚れ、虐げを行う町には災いがある。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 5:3; エレミヤ書 22:21; エレミヤ書 7:23–28"> 彼女は御声に従わず、戒めを受け入れなかった。主に信頼せず、自分の神に近づかなかった。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ハバクク書 1:8; エゼキエル書 22:25–27; エレミヤ書 5:6"> その中にいる君主たちは、ほえる獅子である。その裁き人たちは夕暮れの狼であり、朝まで何一つ残さない。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 22:26; ホセア書 9:7; マラキ書 2:8"> その預言者たちは高慢で、裏切る者たちである。その祭司たちは聖所を汚し、律法を踏みにじった。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 32:4; 詩篇 145:17; 哀歌 3:23"> その中におられる主は義なる方であり、不正を行われない。朝ごとにご自分の公正を明るみに出し、決して欠かすことがない。しかし不義な者は恥を知らない。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="コリント人への第一の手紙 10:6; ゼパニヤ書 2:5; コリント人への第一の手紙 10:11"> 「私は国々を断ち滅ぼした。その胸壁は荒れ果てた。私はその通りを荒れ地とし、通る者がいなくなった。その町々は滅ぼされ、人も住民もいなくなった。</span>
<span className="v" id="v7" data-v="7" data-xref="ホセア書 9:9; エレミヤ書 36:3; ミカ書 2:1–2"> 私は言った。『ただ私を恐れ、戒めを受けよ。そうすれば、その住まいは断ち滅ぼされず、彼女について定めたすべての罰を免れる。』しかし彼らは、いち早くそのすべての行いを腐敗させた。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨエル書 3:2; ゼパニヤ書 1:18; ミカ書 7:7"> 「それゆえ、私を待て」と主は言われる。「私が立ち上がって獲物を取る日まで。私は国々を集め、諸王国を召集し、その上に私の憤り、燃える怒りのすべてを注ぐことを定めた。全地は私のねたみの火で焼き尽くされる。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="創世記 11:1; 詩篇 22:27; イザヤ書 19:18"> その時、私は諸民族の唇を清める。彼らが皆、主の御名を呼び求め、肩を並べて主に仕えるためである。</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 11:11; 詩篇 68:31; イザヤ書 18:1"> クシュの川々の彼方から、散らされた私の民、私を礼拝する者たちが、私へのささげ物を携えて来る。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 54:4; ヨエル書 2:26–27; イザヤ書 11:9"> その日、あなたは、私に背いて行ったすべての行いのために恥じることはない。その時、私はあなたの中から、高慢に勝ち誇る者たちを取り除く。あなたは私の聖なる山で、もう高ぶることはない。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 14:32; ナホム書 1:7; ゼカリヤ書 13:8–9"> 私はあなたの中に、苦しめられた貧しい民を残す。彼らは主の御名を避け所とする。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨハネの黙示録 14:5; ゼパニヤ書 2:7; ミカ書 4:7"> イスラエルの残りの者は不義を行わず、偽りを語らない。その口に欺く舌はない。彼らは食べ、身を横たえる。彼らを恐れさせる者は一人もいない。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 12:6; ゼカリヤ書 2:10–11; ミカ書 4:8"> シオンの娘よ、歌え。イスラエルよ、喜び叫べ。エルサレムの娘よ、心を尽くして喜び、楽しめ。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 51:22; ゼパニヤ書 3:5; イザヤ書 33:22"> 主はあなたへの裁きを取り除き、あなたの敵を追い払われた。イスラエルの王である主があなたの中におられる。あなたはもう災いを恐れない。</span>
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 12:12; イザヤ書 35:3–4; イザヤ書 41:10"> その日、エルサレムにはこう言われる。「恐れるな、シオンよ。手を垂れるな。」</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 149:4; 詩篇 147:11; エレミヤ書 32:41"> あなたの神、主はあなたの中におられる。救いをもたらす勇士である。主は喜びに満ちてあなたを楽しみ、その愛のうちにあなたを静め、歌声を上げてあなたのゆえに喜ばれる。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 42:2–4; エゼキエル書 36:24; 哀歌 2:6–7"> 「例祭のために嘆く者たちを、私はあなたから取り除く。彼らはあなたの重荷、あなたのそしりであった。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 49:25–26; イザヤ書 60:14; エレミヤ書 30:16"> 見よ、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「見よ」と訳されたヘブル語הִנֵּהは、「見なさい」「注意を向けなさい」「よく見なさい」という意味を持ち、しばしば間投詞として用いられる。">a</a></sup>その時、私はあなたを苦しめるすべての者を処罰する。歩けない者を救い、追い散らされた者を集める。全地で恥を受けていた者たちに、称賛と誉れを与える。</span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 29:14; マラキ書 3:12; イザヤ書 56:5"> その時、私はあなたがたを連れて来る。その時、あなたがたを集める。あなたがたの目の前で繁栄を回復する時、地のすべての民の間で、あなたがたに誉れと称賛を与える」と主は言われる。</span>
</div>

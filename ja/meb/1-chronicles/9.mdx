<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ネヘミヤ記 7:64; 歴代誌上 5:25–26; エレミヤ書 52:14–15"> こうして全イスラエルが系図に記された。見よ、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「見よ」はヘブル語「הִנֵּה」に由来し、「見なさい」「注目しなさい」「よく見よ」などの意味を持つ間投詞である。">a</a></sup>それらはイスラエルの王たちの書に記されている。ユダの民は、その背信のゆえにバビロンへ捕囚として連れ去られた。</span>
<span className="v" id="v2" data-v="2" data-xref="ネヘミヤ記 7:73; エズラ記 2:58; エズラ記 2:70"> さて、彼らの町々にある自分たちの所有地に最初に住んだ住民は、イスラエル人、祭司たち、レビ人、および宮のしもべたちであった。</span>
<span className="v" id="v3" data-v="3" data-xref="ネヘミヤ記 11:1; 歴代誌 第二 11:16; ネヘミヤ記 11:4–9"> エルサレムにはユダの子ら、ベニヤミンの子ら、エフライムとマナセの子らの一部が住んでいた。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌上 2:5; 創世記 46:12; 民数記 26:20"> ユダの子ペレツの子らのうちでは、バニの子インリの子オムリの子アミフドの子ウタイ。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 26:20; ネヘミヤ記 11:5"> シロ人の中では、長子アサヤとその子ら。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 26:20; 歴代誌上 2:6; 創世記 38:30"> ゼラの子らのうちでは、エウエルとその兄弟たち、六百九十人。</span>
<span className="v" id="v7" data-v="7" data-xref="ネヘミヤ記 10:20; ネヘミヤ記 11:7; ネヘミヤ記 8:4"> ベニヤミンの子らのうちでは、ハセヌアの子ホダブヤの子メシュラムの子サル、</span>
<span className="v" id="v8" data-v="8"> エロハムの子イブネヤ、ミクリの子ウジの子エラ、イブニヤの子レウエルの子シェファティヤの子メシュラム。</span>
<span className="v" id="v9" data-v="9" data-xref="ネヘミヤ記 11:8"> およびその世代に基づく彼らの兄弟たちで、九百五十六人。これらの人々は皆、それぞれの父祖の家のかしらであった。</span>
<span className="v" id="v10" data-v="10" data-xref="ネヘミヤ記 12:19; ネヘミヤ記 11:10–24"> 祭司たちの中では、エダヤ、エホヤリブ、ヤキン、</span>
<span className="v" id="v11" data-v="11" data-xref="ネヘミヤ記 11:11; 列王記第二 25:18; 民数記 4:33"> および神の家のつかさである、アヒトブの子メラヨテの子ツァドクの子メシュラムの子ヒルキヤの子アザルヤ、</span>
<span className="v" id="v12" data-v="12" data-xref="ネヘミヤ記 7:40; エズラ記 2:37; ネヘミヤ記 11:12–13"> マルキヤの子パシュフルの子エロハムの子アダヤ、およびイメルの子メシレミテの子メシュラムの子ヤフゼラの子アディエルの子マアサイ、</span>
<span className="v" id="v13" data-v="13" data-xref="ネヘミヤ記 11:14; 歴代誌上 26:30; 歴代誌上 26:32"> さらに彼らの兄弟たちで、父祖の家の長である千七百六十人。彼らは神の家の奉仕のわざを行う有能な人々であった。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 26:57; ネヘミヤ記 10:11; 歴代誌上 6:29"> レビ人の中では、メラリの子らのうち、ハシャブヤの子アズリカムの子ハシュブの子シェマヤ、</span>
<span className="v" id="v15" data-v="15" data-xref="ネヘミヤ記 11:22; ネヘミヤ記 11:17; 歴代誌上 11:17"> バクバカル、ヘレシュ、ガラル、およびアサフの子ジクリの子ミカの子マタヌヤ、</span>
<span className="v" id="v16" data-v="16" data-xref="歴代誌上 25:1; 歴代誌 第二 35:15; 歴代誌上 12:25"> エドゥトンの子ガラルの子シェマヤの子オバデヤ、およびネトファ人の村々に住んだエルカナの子アサの子ベレクヤ。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代誌上 26:1–32; 歴代誌上 23:5; ネヘミヤ記 11:19"> 門衛たちは、シャルム、アクブ、タルモン、アヒマン、および彼らの兄弟たち。シャルムが長であった。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 46:1–2; エゼキエル書 44:2–3; 列王記第一 10:5"> 彼らは以前、東のほうにある王の門で仕えていた。これらがレビの子らの宿営の門衛であった。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 26:9–11; 詩篇 44:1; 列王記第二 11:15"> コラの子エビアサフの子コルの子シャルムと、その父祖の家に属する兄弟であるコラ人たちは、奉仕の務めに携わり、天幕の敷居を守る者であった。彼らの父祖たちは主の宿営を管理し、入り口を守る者であった。</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 31:6; 民数記 3:32; 民数記 4:33"> かつてはエルアザルの子ピネハスが彼らを治める長であり、主は彼とともにおられた。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代誌上 26:14; 歴代誌上 26:2"> メシェレミヤの子ゼカリヤは、会見の天幕の入り口の門衛であった。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記第一 9:9; 歴代誌上 28:13; 歴代誌上 23:1–32"> 敷居の門衛として選ばれたこれらの者は、皆で二百十二人であった。彼らはその村々で系図に記された。ダビデと先見者サムエルが、この信任の務めに彼らを任じていた。</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 44:14; 歴代誌 第二 23:19; エゼキエル書 44:10–11"> そこで彼らとその子らは、主の家の門、すなわち天幕である主の家の門を、組ごとに管理して見張った。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代誌上 26:14–18"> 門衛は東西南北の四方にいた。</span>
<span className="v" id="v25" data-v="25" data-xref="列王記第二 11:5; 歴代誌 第二 23:8; 列王記第二 11:7"> 村々にいる彼らの兄弟たちは、七日ごとに交代して彼らとともにいるために来なければならなかった。</span>
<span className="v" id="v26" data-v="26" data-xref="ネヘミヤ記 13:5; ネヘミヤ記 10:38–39; 歴代誌上 26:20–27"> レビ人である四人の門衛長は信任の務めを担い、神の家の部屋と宝物庫を管理していた。</span>
<span className="v" id="v27" data-v="27" data-xref="歴代誌上 23:30–32; マラキ書 1:10; サムエル記第一 3:15"> 彼らは神の家の周囲で宿直した。警備を担い、朝ごとに戸を開ける責任があったからである。</span>
<span className="v" id="v28" data-v="28" data-xref="ネヘミヤ記 13:4–5; ネヘミヤ記 12:44; 歴代誌上 26:22–26"> 彼らのうちのある者は奉仕の器具を任され、それらを数えて運び入れ、また数えて運び出していた。</span>
<span className="v" id="v29" data-v="29" data-xref="歴代誌上 23:29; 出エジプト記 30:23–38; 出エジプト記 27:20"> 彼らのうちのある者は、器具、聖所のすべての器、上質の小麦粉、ぶどう酒、油、乳香、および香料を管理するように任命されていた。</span>
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 30:23–25; 出エジプト記 37:29; 出エジプト記 30:35–38"> 祭司の子らのうち何人かが香料を調合した。</span>
<span className="v" id="v31" data-v="31" data-xref="歴代誌上 9:19; 歴代誌上 9:22; レビ記 6:21"> レビ人の一人であり、コラ人シャルムの長子であるマティティヤには、平鍋で焼く物を管理する信任の務めがあった。</span>
<span className="v" id="v32" data-v="32" data-xref="レビ記 24:5–8; 歴代誌上 6:33–48; 出エジプト記 25:30"> 彼らの兄弟であるケハテの子らのうちの何人かは、安息日ごとに備えのパンを整える役割を任されていた。</span>
<span className="v" id="v33" data-v="33" data-xref="歴代誌上 6:31–33; 詩篇 134:1–2; 歴代誌上 16:4–6"> これらは歌い手で、レビ人の父祖の家の長であった。彼らは神の家の部屋に住み、ほかの務めを免除されていた。昼も夜も歌の務めに携わっていたからである。</span>
<span className="v" id="v34" data-v="34" data-xref="ネヘミヤ記 11:1–15; 歴代誌上 9:13"> これらは代々、レビ人の父祖の家のかしらを務めた有力者たちであった。彼らはエルサレムに住んでいた。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="歴代誌上 2:23–24; 歴代誌上 2:50–52; 歴代誌上 8:29–40"> ギベオンにはギベオンの父エイエルが住んでいた。その妻の名はマアカといった。</span>
<span className="v" id="v36" data-v="36" data-xref="歴代誌上 9:39; 歴代誌上 8:33"> その長子はアブドン、次にツル、キシュ、バアル、ネル、ナダブ、</span>
<span className="v" id="v37" data-v="37" data-xref="歴代誌上 8:31"> ゲドル、アヒオ、ゼカリヤ、ミクロテ。</span>
<span className="v" id="v38" data-v="38" data-xref="歴代誌上 8:32"> ミクロテはシムアムの父となった。彼らもまた親族とともにエルサレムに住み、同族の者たちの近くにいた。</span>
<span className="v" id="v39" data-v="39" data-xref="サムエル記第一 13:22; 歴代誌上 8:33–38; 歴代誌上 10:2"> ネルはキシュの父となり、キシュはサウルの父となり、サウルはヨナタン、マルキ・シュア、アビナダブ、エシュバアルの父となった。</span>
<span className="v" id="v40" data-v="40" data-xref="サムエル記第二 4:4; 歴代誌上 8:34–36"> ヨナタンの子はメリブ・バアルであった。メリブ・バアルはミカの父となった。</span>
<span className="v" id="v41" data-v="41" data-xref="歴代誌上 8:35"> ミカの子らは、ピトン、メレク、タフレア、およびアハズ。</span>
<span className="v" id="v42" data-v="42" data-xref="歴代誌上 8:36"> アハズはヤラの父となり、ヤラはアレメテ、アズマベテ、ジムリの父となり、ジムリはモツァの父となった。</span>
<span className="v" id="v43" data-v="43" data-xref="歴代誌上 8:37"> モツァはビネアの父となり、その子はレファヤ、その子はエルアサ、その子はアツェルであった。</span>
<span className="v" id="v44" data-v="44"> アツェルには六人の子がおり、その名は次のとおりである。アズリカム、ボケル、イシュマエル、シェアルヤ、オバデヤ、ハナン。これらがアツェルの子らである。</span>
</div>

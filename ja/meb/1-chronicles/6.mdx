<span className="v" id="v3" data-v="3" data-xref="出エジプト記 6:20; レビ記 10:1; レビ記 10:12"> アムラムの子らは、アロン、モーセ、ミリヤム。アロンの子らは、ナダブ、アビフ、エルアザル、イタマル。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌上 6:50; 出エジプト記 6:25; エズラ記 7:1–5"> エルアザルはピネハスの父となり、ピネハスはアビシュアの父となり、</span>

<span className="v" id="v11" data-v="11" data-xref="エズラ記 7:3"> アザルヤはアマルヤの父となり、アマルヤはアヒトブの父となり、</span>
<span className="v" id="v12" data-v="12" data-xref="ネヘミヤ記 11:11; 歴代誌上 9:11"> アヒトブはツァドクの父となり、ツァドクはシャルムの父となり、</span>
<span className="v" id="v13" data-v="13" data-xref="歴代誌 第二 35:8; 列王記第二 22:12–14; 列王記第二 22:4"> シャルムはヒルキヤの父となり、ヒルキヤはアザルヤの父となり、</span>
<span className="v" id="v14" data-v="14" data-xref="列王記第二 25:18; ネヘミヤ記 11:11; ゼカリヤ書 6:11"> アザルヤはセラヤの父となり、セラヤはエホツァダクの父となった。</span>
<span className="v" id="v15" data-v="15" data-xref="ハガイ書 2:2; 列王記第二 25:18; ハガイ書 1:1"> 主がネブカドネザルの手によってユダとエルサレムを捕囚にされたとき、エホツァダクも捕らえられて行った。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 6:16; 歴代誌上 6:1"> レビの子らは、ゲルショム、ケハテ、メラリ。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代誌上 23:7; 民数記 3:18; 民数記 3:21"> ゲルショムの子らの名は次のとおりである。リブニとシムイ。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代誌上 23:12; 歴代誌上 6:2–3"> ケハテの子らは、アムラム、イツハル、ヘブロン、ウジエルであった。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代誌上 23:21; 歴代誌上 24:26; 出エジプト記 6:19"> メラリの子らは、マフリとムシ。以上が、父祖の家ごとのレビ人の諸氏族である。</span>
<span className="v" id="v20" data-v="20" data-xref="歴代誌上 6:43"> ゲルショムからは、その子リブニ、その子ヤハテ、その子ジムマ、</span>
<span className="v" id="v21" data-v="21"> その子ヨア、その子イド、その子ゼラ、その子エアテライ。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 6:24; 歴代誌上 6:18; 歴代誌上 6:2"> ケハテの子らは、その子アミナダブ、その子コラ、その子アシル、</span>
<span className="v" id="v23" data-v="23"> その子エルカナ、その子エビアサフ、その子アシル、</span>
<span className="v" id="v24" data-v="24"> その子タハテ、その子ウリエル、その子ウジヤ、その子シャウル。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 6:24; 歴代誌上 6:35–36"> エルカナの子らは、アマサイとアヒモテ。</span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記第一 1:1; 歴代誌上 6:35"> エルカナの系譜は、その子ツォファイ、その子ナハテ、</span>
<span className="v" id="v27" data-v="27" data-xref="サムエル記第一 1:1; サムエル記第一 1:19–20"> その子エリアブ、その子エロハム、その子エルカナ。</span>
<span className="v" id="v28" data-v="28" data-xref="歴代誌上 6:33; サムエル記第一 8:2"> サムエルの子らは、長子ヨエル、次男アビヤ。</span>
<span className="v" id="v29" data-v="29" data-xref="歴代誌上 6:19; 民数記 3:33"> メラリの子らは、マフリ、その子リブニ、その子シムイ、その子ウザ、</span>
<span className="v" id="v30" data-v="30"> その子シメア、その子ハギヤ、その子アサヤ。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="サムエル記第二 6:17; 歴代誌上 15:25–1; 歴代誌上 15:16–22"> 箱がそこに安置された後、ダビデが主の家での歌の務めのために任命した者たちは次のとおりである。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 135:1–3; 列王記第一 8:6–13; エズラ記 6:18"> 彼らは、ソロモンがエルサレムに主の家を建てるまで、会見の天幕である幕屋の前で歌をもって仕えた。彼らはその定めに従って自分たちの務めを果たした。</span>
<span className="v" id="v33" data-v="33" data-xref="歴代誌上 6:28; 歴代誌上 15:17; 歴代誌上 25:1–5"> 仕えた者たちとその子らは次のとおりである。ケハテ人の子らからは、歌い手ヘマン。彼はサムエルの子ヨエルの子、</span>
<span className="v" id="v34" data-v="34"> エルカナの子、エロハムの子、エリエルの子、トアの子、</span>
<span className="v" id="v35" data-v="35"> ツフの子、エルカナの子、マハテの子、アマサイの子、</span>
<span className="v" id="v36" data-v="36"> エルカナの子、ヨエルの子、アザルヤの子、ゼパニヤの子、</span>
<span className="v" id="v37" data-v="37" data-xref="詩篇 45:1; 民数記 26:10–11; 出エジプト記 6:21–24"> タハテの子、アシルの子、エビアサフの子、コラの子、</span>
<span className="v" id="v38" data-v="38" data-xref="民数記 3:19; 歴代誌上 16:1"> イツハルの子、ケハテの子、レビの子、イスラエルの子である。</span>
<span className="v" id="v39" data-v="39" data-xref="ネヘミヤ記 7:44; エズラ記 2:41; 詩篇 75:1"> 彼の兄弟アサフは彼の右手に立った。すなわち、シメアの子ベレクヤの子アサフ。彼は、</span>
<span className="v" id="v40" data-v="40"> ミカエルの子、バアセヤの子、マルキヤの子、</span>
<span className="v" id="v41" data-v="41"> エテニの子、ゼラの子、アダヤの子、</span>
<span className="v" id="v42" data-v="42"> エタンの子、ジムマの子、シムイの子、</span>
<span className="v" id="v43" data-v="43" data-xref="出エジプト記 6:16; 歴代誌上 6:16–17; 創世記 46:11"> ヤハテの子、ゲルショムの子、レビの子である。</span>
<span className="v" id="v44" data-v="44" data-xref="詩篇 89:1; 歴代誌上 15:17; 歴代誌上 25:1"> 左手には彼らの兄弟であるメラリの子らがいた。マルクの子アブディの子キシの子エタン。彼は、</span>
<span className="v" id="v45" data-v="45"> ハシャブヤの子、アマツヤの子、ヒルキヤの子、</span>
<span className="v" id="v46" data-v="46"> アムジの子、バニの子、シェメルの子、</span>
<span className="v" id="v47" data-v="47" data-xref="ヨシュア記 21:7; 出エジプト記 6:19; 歴代誌上 23:21"> マフリの子、ムシの子、メラリの子、レビの子である。</span>
<span className="v" id="v48" data-v="48" data-xref="歴代誌上 23:2; 民数記 3:1–4; 民数記 18:1–32"> 彼らの兄弟であるレビ人は、神の家である幕屋のすべての務めのために任命された。</span>
<span className="v" id="v49" data-v="49" data-xref="レビ記 4:20; 出エジプト記 27:1–8; 出エジプト記 30:1–7"> しかし、アロンとその子らは、全焼のいけにえの祭壇と香の祭壇の上でささげ物をし、至聖所のすべての働きを行い、神のしもべモーセが命じたすべてのことに従って、イスラエルのために贖罪をした。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="レビ記 10:16; 歴代誌上 24:1; 民数記 20:26–28"> アロンの子らは次のとおりである。その子エルアザル、その子ピネハス、その子アビシュア、</span>
<span className="v" id="v51" data-v="51"> その子ブキ、その子ウジ、その子ゼラフヤ、</span>
<span className="v" id="v52" data-v="52"> その子メラヨテ、その子アマルヤ、その子アヒトブ、</span>
<span className="v" id="v53" data-v="53" data-xref="サムエル記第二 8:17; エゼキエル書 44:15; サムエル記第二 15:35–36"> その子ツァドク、その子アヒマアツ。</span>
<span className="v" id="v54" data-v="54" data-xref="創世記 25:16; ヨシュア記 21:10; ヨシュア記 21:3–8"> 彼らの領地内に設けられた居住地は次のとおりである。アロンの子ら、すなわちケハテ人の諸氏族（彼らのために最初のくじが引かれた）には、</span>
<span className="v" id="v55" data-v="55" data-xref="ヨシュア記 14:13; ヨシュア記 21:11–13; ヨシュア記 15:13"> ユダの地にあるヘブロンと、その周囲の牧草地が与えられた。</span>
<span className="v" id="v56" data-v="56" data-xref="ヨシュア記 15:13; ヨシュア記 14:13"> しかし、その町の畑と村々は、エフネの子カレブに与えられた。</span>
<span className="v" id="v57" data-v="57" data-xref="ヨシュア記 21:13–14; ヨシュア記 15:48; ヨシュア記 10:29"> アロンの子らには、逃れの町であるヘブロン、および牧草地を持つリブナ、ヤティル、牧草地を持つエシュテモア、</span>
<span className="v" id="v58" data-v="58" data-xref="ヨシュア記 10:3; ヨシュア記 15:49; ヨシュア記 12:13"> 牧草地を持つヒレン、牧草地を持つデビル、</span>
<span className="v" id="v59" data-v="59" data-xref="ヨシュア記 21:16; ヨシュア記 15:42; サムエル記第一 6:12–19"> 牧草地を持つアシャン、牧草地を持つベテ・シェメシュが与えられ、</span>
<span className="v" id="v60" data-v="60" data-xref="エレミヤ書 1:1; 列王記第一 2:26; エレミヤ書 11:23"> さらにベニヤミンの部族からは、牧草地を持つゲバ、牧草地を持つアレメテ、牧草地を持つアナトテが与えられた。彼らの諸氏族に属する町は全部で十三であった。</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61" data-xref="ヨシュア記 21:4–5; 歴代誌上 6:18; ヨシュア記 21:20–26"> ケハテの残りの子らには、マナセの半部族の氏族から、くじによって十の町が与えられた。</span>
<span className="v" id="v62" data-v="62" data-xref="ヨシュア記 21:27–33; 歴代誌上 6:71–76; 出エジプト記 2:22"> ゲルショムの子らには、その諸氏族に従って、イッサカルの部族、アシェルの部族、ナフタリの部族、およびバシャンにいるマナセの部族から、十三の町が与えられた。</span>
<span className="v" id="v63" data-v="63" data-xref="ヨシュア記 21:7; ヨシュア記 21:34–40; 民数記 3:20"> メラリの子らには、その諸氏族に従って、ルベンの部族、ガドの部族、ゼブルンの部族から、くじによって十二の町が与えられた。</span>
<span className="v" id="v64" data-v="64" data-xref="ヨシュア記 21:41–42; ヨシュア記 21:3; 民数記 35:1–8"> イスラエルの子らはこれらの町とその牧草地をレビ人に与えた。</span>
<span className="v" id="v65" data-v="65" data-xref="歴代誌上 6:57–60"> 彼らは、ユダの子らの部族、シメオンの子らの部族、ベニヤミンの子らの部族から、名前を挙げられたこれらの町をくじによって与えた。</span>
</div>
<div className="bp">
<span className="v" id="v66" data-v="66" data-xref="ヨシュア記 21:20–26"> ケハテの子らの諸氏族のうちのいくつかは、エフライムの部族から領地として町々を与えられた。</span>
<span className="v" id="v67" data-v="67" data-xref="ヨシュア記 21:21; 創世記 33:18; 創世記 35:4"> 彼らには、エフライムの山地にある逃れの町シェケムとその牧草地、牧草地を持つゲゼル、</span>
<span className="v" id="v68" data-v="68" data-xref="ヨシュア記 21:22; ヨシュア記 16:5; サムエル記第一 13:18"> 牧草地を持つヨクメアム、牧草地を持つベテ・ホロン、</span>
<span className="v" id="v69" data-v="69" data-xref="ヨシュア記 10:12; ヨシュア記 21:24–25"> 牧草地を持つアヤロン、牧草地を持つガテ・リモンが与えられ、</span>

<span className="v" id="v72" data-v="72" data-xref="ヨシュア記 21:28–29; ヨシュア記 21:32; ヨシュア記 19:37"> イッサカルの部族からは、牧草地を持つケデシュ、牧草地を持つダベラテ、</span>

</div>
<div className="bp">
<span className="v" id="v77" data-v="77" data-xref="ヨシュア記 21:34–35"> 残りのレビ人、すなわちメラリの子らには、ゼブルンの部族から、牧草地を持つリモノ、牧草地を持つタボルが与えられ、</span>

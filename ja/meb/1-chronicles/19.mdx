<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記第一 11:1–2; サムエル記第二 10:1–19; サムエル記第一 12:12"> その後、アンモン人の王ナハシュが死に、その子が代わって王となった。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 23:3–6; サムエル記第一 30:26; 創世記 19:37–38"> ダビデは言った。「ナハシュの子ハヌンに真実の愛を示そう。彼の父も私に真実の愛を示してくれたからだ。」<br />そこでダビデは、父を亡くしたハヌンを慰めるため、使者を遣わした。ダビデの家臣たちはハヌンを慰めるため、アンモン人の国に入った。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 1:23–24; コリント人への第一の手紙 13:5–7; 列王記第一 12:8–11"> ところがアンモン人の高官たちはハヌンに言った。「ダビデが弔問の使者を送ったのは、あなたの父を敬っているからだとお考えですか。彼の家臣たちは、この国を探り、滅ぼし、偵察するために来たのではありませんか。」</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記第二 10:4–5; イザヤ書 15:2; マルコ 12:4"> そこでハヌンはダビデの家臣たちを捕らえ、ひげをそり落とし、衣を尻の辺りまで半分に切り取って送り返した。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨシュア記 6:24–26; マタイ 18:31; 列王記第一 16:34"> 人々が来て、その者たちの受けた仕打ちをダビデに知らせたので、ダビデは彼らを迎えに人を遣わした。彼らがひどく辱められていたからである。王は言った。「ひげが伸びるまでエリコにとどまり、それから帰って来なさい。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歴代誌上 18:5; 創世記 34:30; 歴代誌上 18:9"> アンモン人は、自分たちがダビデに憎まれるようになったことを悟った。そこでハヌンとアンモン人は、メソポタミア、アラム・マアカ、ツォバから戦車と騎兵を雇うため、銀千タラント<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一タラントは約三十キログラム、または六十六ポンド。千タラントは約三十メートルトンに相当する。">a</a></sup>を送った。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 21:30; ヨシュア記 13:9; ヨシュア記 13:16"> 彼らは戦車三万二千台と、マアカの王およびその軍勢を雇った。彼らはやって来て、メデバの近くに陣を敷いた。アンモン人も自分たちの町々から集まり、戦いに出た。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代誌上 11:6; 歴代誌上 11:10–47; サムエル記第二 23:8–39"> ダビデはこれを聞くと、ヨアブと勇士たちの全軍を送り出した。</span>
<span className="v" id="v9" data-v="9" data-xref="列王記第一 20:1; 列王記第一 20:24; イザヤ書 28:6"> アンモン人は出て来て、町の門の前に戦列を整えた。一方、援軍として来た王たちは、離れた野に陣取った。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="サムエル記第二 10:9–14; 士師記 20:42–43; ヨシュア記 8:22"> ヨアブは、自分の前後に戦線が築かれているのを見ると、イスラエルの精鋭の中から兵を選び、アラム人に向かって戦列を整えた。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代誌上 18:12; 歴代誌上 11:20; 歴代誌上 19:9"> 残りの兵は弟アビシャイに委ね、彼らをアンモン人に向かって配置した。</span>
<span className="v" id="v12" data-v="12" data-xref="ピリピ人への手紙 1:27–28; ネヘミヤ記 4:20; 伝道者の書 4:9–12"> そして言った。「もしアラム人が私より強ければ、あなたが私を助けてくれ。もしアンモン人があなたより強ければ、私があなたを助ける。</span>
<span className="v" id="v13" data-v="13" data-xref="ネヘミヤ記 4:14; 詩篇 27:14; サムエル記第二 10:12"> 勇気を出そう。私たちの民と、私たちの神の町々のために、力を尽くそう。主が御心にかなうことを行われるように。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王記第一 20:19–21; 歴代誌 第二 13:5–16; エレミヤ書 46:15–16"> ヨアブと彼に従う兵がアラム人に近づいて戦いを挑むと、アラム人は彼の前から逃げた。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 8:31; レビ記 26:7"> アンモン人もアラム人が逃げるのを見ると、ヨアブの弟アビシャイの前から逃げ、町の中に入った。そこでヨアブはエルサレムへ帰った。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="サムエル記第二 10:16; ゼカリヤ書 14:1–3; ミカ書 4:11–12"> アラム人は、自分たちがイスラエルに打ち破られたことを知ると、使者を遣わして川の向こう側<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または「ユーフラテス川の向こう側」。">b</a></sup>のアラム人を呼び寄せた。ハダドエゼルの軍の司令官ショファクが彼らを率いていた。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 22:6–7; 歴代誌上 19:9"> この知らせを受けたダビデは、全イスラエルを集めてヨルダン川を渡り、彼らのもとへ進み、戦列を整えた。ダビデがアラム人に向かって戦列を整えると、彼らはダビデと戦った。</span>
<span className="v" id="v18" data-v="18" data-xref="サムエル記第二 10:18; 詩篇 33:16; 詩篇 18:32"> しかしアラム人はイスラエルの前から逃げた。ダビデはアラム人の戦車兵七千人と歩兵四万人を討ち、軍の司令官ショファクも殺した。</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記第二 10:19; ヨシュア記 9:9–11; 列王記第一 20:1"> ハダドエゼルの家臣たちは、自分たちがイスラエルに打ち破られたのを見ると、ダビデと和を結び、彼に仕えた。その後アラム人は、二度とアンモン人を助けようとはしなかった。</span>
</div>

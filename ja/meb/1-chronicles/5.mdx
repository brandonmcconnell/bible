<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 35:22; 創世記 29:32; 創世記 48:15–22"> イスラエルの長子ルベンの子ら。（彼は長子であったが、父の寝床を汚したため、その長子の権利はイスラエルの子ヨセフの子らに与えられた。それゆえ、長子の権利に従って系図が記されることはない。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 2:6; ミカ書 5:2; ヘブル人への手紙 7:14"> ユダは兄弟たちの中で力があり、彼から君が出たが、長子の権利はヨセフのものであった。）</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 46:9; 出エジプト記 6:14; 民数記 26:5–9"> イスラエルの長子ルベンの子らは、エノク、パル、ヘツロン、カルミ。</span>
<span className="v" id="v4" data-v="4"> ヨエルの子らは、その子シェマヤ、その子ゴグ、その子シムイ、</span>
<span className="v" id="v5" data-v="5"> その子ミカ、その子レアヤ、その子バアル、</span>
<span className="v" id="v6" data-v="6" data-xref="歴代誌上 5:26; 列王記第二 15:29; 歴代誌 第二 28:20"> その子ベエラ。彼はアッシリアの王ティルガテ・ピルネセルに捕囚として連れ去られた。彼はルベン人の君であった。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌上 5:17"> 氏族ごとの彼の兄弟たちが、その世代の系図に記されたとき、長はエイエル、次にゼカリヤ、</span>
<span className="v" id="v8" data-v="8" data-xref="歴代誌上 5:4; 民数記 32:34; 民数記 32:38"> そしてヨエルの子であるシェマの子アザズの子ベラ。彼はアロエルに住み、ネボとバアル・メオンにまで及んだ。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 22:8–9"> 彼は東のほうユーフラテス川から荒野の入り口に至るまで住んだ。彼らの家畜がギルアドの地で増え広がったからである。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="創世記 21:9; 歴代誌上 5:18–21; 詩篇 83:6"> サウルの時代に、彼らはハガル人と戦い、ハガル人は彼らの手によって倒れた。彼らはギルアドの東全域にわたって天幕に住んだ。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヨシュア記 13:11; ヨシュア記 13:24–28; 申命記 3:10–17"> ガドの子らはバシャンの地で彼らと並んでサルカに至るまで住んだ。</span>
<span className="v" id="v12" data-v="12"> バシャンでは長のヨエル、二番目のシャファム、ヤナイ、シャファテ。</span>
<span className="v" id="v13" data-v="13"> 彼らの父祖の家に属する兄弟たちは、ミカエル、メシュラム、シェバ、ヨライ、ヤカン、ジア、エベルの七人。</span>
<span className="v" id="v14" data-v="14"> これらはアビハイルの子らである。アビハイルはブズの子、ヤフドの子、エシシャイの子、ミカエルの子、ギルアドの子、ヤロアの子、フリの子である。</span>
<span className="v" id="v15" data-v="15"> グニの子であるアブディエルの子アヒが彼らの父祖の家の長であった。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代誌上 27:29; 雅歌 2:1; イザヤ書 35:2"> 彼らはバシャンのギルアドとその町々、そしてシャロンのすべての放牧地をその境界まで住処とした。</span>
<span className="v" id="v17" data-v="17" data-xref="列王記第二 14:16; 列王記第二 14:28; 列王記第二 15:32"> これらは皆、ユダの王ヨタムの時代とイスラエルの王ヤロブアムの時代に系図に記された。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民数記 1:3; ヨシュア記 4:12–13"> ルベンの子ら、ガド人、およびマナセの半部族の勇士たち、すなわち盾と剣を携え、弓を射ることができ、戦いに熟練した者たちのうち、出陣できる者は四万四千七百六十人であった。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 25:15; 歴代誌上 1:31; 歴代誌上 5:10"> 彼らはハガル人、エツル、ナフィシュ、ノダブと戦った。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 22:4–5; 詩篇 9:10; 歴代誌 第二 18:31"> 彼らは戦いで神の助けを受け、ハガル人とその同盟軍は彼らの手に渡された。彼らが戦いのただ中で神に叫び求め、神に信頼したので、神がその願いに答えられたからである。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの黙示録 18:13; 民数記 31:35"> 彼らは敵の家畜を奪い取った。そのらくだ五万頭、羊二十五万匹、ろば二千頭、また十万人を捕虜とした。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代誌 第二 32:8; ローマ人への手紙 8:31; ヨシュア記 23:10"> 多くの者が殺されて倒れた。この戦いは神によるものだったからである。彼らは捕囚の時までその地に住んだ。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="申命記 3:8–9; 雅歌 4:8; 詩篇 133:3"> マナセの半部族の子らもその地に住んだ。彼らはバシャンからバアル・ヘルモン、セニル、そしてヘルモン山に至るまで増え広がった。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代誌上 4:38"> 彼らの父祖の家の長たちは次のとおりである。エフェル、イシ、エリエル、アズリエル、エレミヤ、ホダブヤ、ヤフディエル。彼らは力ある勇士であり、名のある人々であって、彼らの父祖の家の長であった。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨハネの黙示録 17:5; 詩篇 106:34–39; 出エジプト記 34:15"> しかし、彼らは彼らの父祖の神に対して罪を犯し、神が彼らの前から滅ぼされたその地の民の神々を追い求め、淫行にふけった。</span>
<span className="v" id="v26" data-v="26" data-xref="列王記第二 15:19; 列王記第二 17:6; 列王記第二 15:29"> そのため、イスラエルの神はアッシリアの王プルの霊とアッシリアの王ティルガテ・ピルネセルの霊を奮い立たせられた。その王はルベン人、ガド人、マナセの半部族を捕囚として連れ去り、ハラ、ハボル、ハラ、およびゴザン川へと連れて行き、今日に至っている。</span>

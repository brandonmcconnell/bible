<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 46:12; 創世記 38:29; 民数記 26:20–21"> ユダの子らは、ペレツ、ヘツロン、カルミ、フル、ショバル。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 13:25; 歴代誌上 2:52–54; ヨシュア記 15:33"> ショバルの子レアヤはヤハテの父となり、ヤハテはアフマイとラハドの父となった。これらはツォラ人の諸氏族である。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 15:11; 歴代誌 第二 11:6"> エタムの父の子らは次のとおりである。エズレル、イシュマ、イドバシュ。彼らの妹の名はハツェレルポニといった。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌上 4:18; 歴代誌上 2:50; 歴代誌上 4:39"> ペヌエルはゲドルの父、エゼルはフシャの父。これらはベツレヘムの父であるエフラタの長子フルの子らである。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代誌上 2:24"> テコアの父アシュフルには、ヘラとナアラという二人の妻がいた。</span>
<span className="v" id="v6" data-v="6"> ナアラは彼にアフザム、ヘフェル、テメニ、ハアハシュタリを産んだ。これらがナアラの子らである。</span>
<span className="v" id="v7" data-v="7"> ヘラの子らは、ツェレテ、イツハル、エトナン。</span>
<span className="v" id="v8" data-v="8"> ハコツはアヌブ、ツォベバ、およびハルムの子アハルヘルの諸氏族の父となった。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="サムエル記第一 4:21; 歴代誌上 7:23; 創世記 35:18"> ヤベツはその兄弟たちよりも尊ばれた。彼の母は、「わたしが苦しんでこの子を産んだからだ」と言って、彼をヤベツ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「ヤベツ」は、ヘブル語で「苦しみ」を表す言葉と音が似ている。">a</a></sup>と名付けた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="マタイ 7:7–11; 詩篇 116:1–4; 箴言 10:22"> ヤベツはイスラエルの神<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「神」と訳されたヘブル語は「אֱלֹהִים」（エロヒム）である。">b</a></sup>に呼び求めて言った。「どうか、私を大いに祝福し、私の領地を広げてください。御手が私とともにあり、私を悪から守り、私が苦しみを引き起こすことのないようにしてください。」<br />神は彼の願いをかなえられた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> シュアの兄弟ケルブはメヒルの父となった。メヒルはエシュトンの父である。</span>
<span className="v" id="v12" data-v="12"> エシュトンはベテ・ラファ、パセア、およびイル・ナハシュの父テヒナの父となった。これらはレカの人々である。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨシュア記 15:17; 士師記 1:13; 士師記 3:9–11"> ケナズの子らは、オテニエルとセラヤ。オテニエルの子らは、ハタテ<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="ギリシア語訳とウルガタ訳には「とメオノタイ」が加えられている。">c</a></sup>。</span>
<span className="v" id="v14" data-v="14" data-xref="ネヘミヤ記 11:35; 列王記第二 24:14"> メオノタイはオフラの父となり、セラヤはゲ・ハラシムの父ヨアブの父となった。彼らは職人だったからである。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 13:6; 民数記 14:6–10; ヨシュア記 15:13–20"> エフネの子カレブの子らは、イル、エラ、ナアム。エラの子は、ケナズ。</span>
<span className="v" id="v16" data-v="16"> エハレレルの子らは、ジフ、ジファ、ティルヤ、アサレル。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代誌上 4:19; 歴代誌上 6:57; ヨシュア記 15:50"> エズラの子らは、エテル、メレド、エフェル、ヤロン。メレドの妻はミリヤム、シャマイ、およびエシュテモアの父イシュバを産んだ。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代誌上 2:42; 歴代誌上 4:39; ヨシュア記 15:58"> 彼のユダ人の妻は、ゲドルの父エレド、ソコの父ヘベル、ザノアの父エクティエルを産んだ。これらはメレドがめとったファラオの娘ビテヤの子らである。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 15:44; サムエル記第一 23:1–13"> ナハムの妹であるホディヤの妻の子らは、ガルミ人ケイラの父、およびマアカ人エシュテモアの父である。</span>
<span className="v" id="v20" data-v="20"> シモンの子らは、アムノン、リンナ、ベン・ハナン、ティロン。イシの子らは、ゾヘテ、ベン・ゾヘテ。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 38:5; 歴代誌上 2:3; 民数記 26:20"> ユダの子シェラの子らは、レカの父エル、マレシャの父ラダ、および上質の亜麻布を織る職人であるアシュベアの家の諸氏族、</span>
<span className="v" id="v22" data-v="22"> さらにヨキム、コゼバの人々、モアブを支配したヨアシュとサラフ、そしてヤシュビ・レヘムである。これらの記録は古いものである。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 81:6; 歴代誌上 4:14"> 彼らは陶器職人であり、ネタイムとゲデラに住む者たちであった。彼らは王の仕事のために王とともにそこに住んだ。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="創世記 46:10; 出エジプト記 6:15; 民数記 26:12–14"> シメオンの子らは、ネムエル、ヤミン、ヤリブ、ゼラ、シャウル。</span>
<span className="v" id="v25" data-v="25"> その子はシャルム、その子はミブサム、その子はミシュマ。</span>
<span className="v" id="v26" data-v="26"> ミシュマの子らは、その子ハムエル、その子ザクル、その子シムイ。</span>
<span className="v" id="v27" data-v="27" data-xref="民数記 26:14; 民数記 26:22; 民数記 2:13"> シムイには十六人の息子と六人の娘がいた。しかし彼の兄弟たちには子どもが多くなく、彼らの氏族はすべてユダの子らのようには増えなかった。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨシュア記 19:2–3; ヨシュア記 15:28–29; ヨシュア記 19:9"> 彼らはベエル・シェバ、モラダ、ハツァル・シュアル、</span>
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 19:3–4"> ビルハ、エツェム、トラド、</span>
<span className="v" id="v30" data-v="30" data-xref="ネヘミヤ記 11:28; ヨシュア記 19:4–5; サムエル記第一 30:1"> ベトエル、ホルマ、ツィクラグ、</span>
<span className="v" id="v31" data-v="31" data-xref="ヨシュア記 19:5–6"> ベテ・マルカボテ、ハツァル・スシム、ベテ・ビルイ、シャアライムに住んでいた。これらはダビデの治世まで彼らの町であった。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨシュア記 19:7"> 彼らの村々は、エタム、アイン、リモン、トケン、アシャンの五つの町であり、</span>
<span className="v" id="v33" data-v="33" data-xref="ヨシュア記 19:8"> またバアルに至るまで、それらの町の周辺にあるすべての村々であった。以上が彼らの居住地であり、彼らは系図を記録していた。</span>
<span className="v" id="v34" data-v="34"> メショバブ、ヤムレク、アマツヤの子ヨシャ、</span>
<span className="v" id="v35" data-v="35"> ヨエル、アシエルの子であるセラヤの子ヨシブヤの子イエフ、</span>
<span className="v" id="v36" data-v="36"> エリオエナイ、ヤアコバ、エショハヤ、アサヤ、アディエル、エシミエル、ベナヤ、</span>
<span className="v" id="v37" data-v="37"> そしてシェマヤの子であるシムリの子エダヤの子アロンの子シフィの子ジザ――</span>
<span className="v" id="v38" data-v="38" data-xref="歴代誌上 5:24; 創世記 6:4"> 名前を挙げられたこれらの者は、その氏族の首長たちであった。彼らの父祖の家は大いに増え広がった。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="歴代誌上 4:4; 歴代誌上 4:18; ヨシュア記 15:58"> 彼らは自分たちの羊の群れのために牧草地を求めて、ゲドルの入り口、谷の東側にまで行った。</span>
<span className="v" id="v40" data-v="40" data-xref="士師記 18:7–10; 詩篇 105:23; 詩篇 78:51"> 彼らは豊かで良い牧草地を見つけた。その地は広々として静かで平和であった。以前そこに住んでいた者たちはハムの子孫だったからである。</span>
<span className="v" id="v41" data-v="41" data-xref="イザヤ書 14:28–32; 列王記第二 18:8–12; 歴代誌上 4:34–38"> 名を記されたこれらの者は、ユダの王ヒゼキヤの時代に来て、彼らの天幕を打ち壊し、そこにいたメウニムを討ち、今日に至るまで完全に滅ぼして、その地に住んだ。そこには彼らの羊の群れのための牧草地があったからである。</span>
<span className="v" id="v42" data-v="42" data-xref="創世記 36:8–9; 申命記 1:2"> 彼らの一部、すなわちシメオンの子らの中から五百人がセイル山へ行った。イシの子であるペラテヤ、ネアルヤ、レファヤ、ウジエルを長としていた。</span>
<span className="v" id="v43" data-v="43" data-xref="サムエル記第一 30:17; サムエル記第一 15:7–8; サムエル記第二 8:12"> 彼らは生き残っていたアマレク人の残党を討ち、今日に至るまでそこに住んでいる。</span>
</div>

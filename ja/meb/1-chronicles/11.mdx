<span className="v" id="v1" data-v="1" data-xref="サムエル記第二 5:1–16; 歴代誌上 12:23–40; 士師記 9:2"> その後、全イスラエルはヘブロンのダビデのもとに集まって言った。「見よ、私たちはあなたの骨であり、肉です。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記第二 5:2; ヨハネ 10:4; 詩篇 78:71"> 以前、サウルが王であったときにも、イスラエルを率いて出陣し、帰還させたのはあなたでした。あなたの神、主はあなたに言われました。『あなたが私の民イスラエルを牧し、あなたが私の民イスラエルの君となる』と。」</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記第一 16:12–13; サムエル記第一 16:1; サムエル記第二 5:3"> こうしてイスラエルのすべての長老たちがヘブロンの王のもとに来た。ダビデはヘブロンで主の御前に彼らと契約を結んだ。彼らはサムエルを通して語られた主の言葉に従って、ダビデに油を注いでイスラエルの王とした。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 1:21; 創世記 15:21; ヨシュア記 15:8"> ダビデと全イスラエルはエルサレム、すなわちエブスへ行った。その地の住民であるエブス人はそこにいた。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代誌 第二 5:2; 列王記第一 8:1; 詩篇 87:2"> エブスの住民はダビデに言った。「あなたはここに入ることはできない。」しかしダビデはシオンの要害を攻め取った。それがダビデの町である。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記第二 8:16; サムエル記第二 20:23; サムエル記第二 3:27"> ダビデは言った。「エブス人を最初に打つ者は誰でも、長となり、指揮官となる。」ツェルヤの子ヨアブが最初に上って行ったので、彼が長となった。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌上 11:5; サムエル記第二 5:7; 詩篇 2:6"> ダビデはその要害に住んだ。それゆえ、彼らはそこをダビデの町と呼んだ。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 9:6; 列王記第一 11:27; 列王記第二 12:20"> 彼はミロからその周囲に至るまで、町の周囲を建て直した。ヨアブは町の残りの部分を修復した。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記第二 3:1; イザヤ書 41:10; 歴代誌上 9:20"> ダビデはますます大いなる者となった。万軍の主が彼とともにおられたからである。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歴代誌上 11:3; サムエル記第一 16:1; 歴代誌上 12:38"> ダビデに仕えた勇士たちの長は次のとおりである。彼らは全イスラエルとともにダビデの王権を力強く支え、主がイスラエルについて語られた言葉どおり、彼を王とした。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記第二 23:8; 歴代誌上 27:2; 歴代誌上 12:18"> ダビデに属していた勇士たちの数は次のとおりである。ハクモニ人の子ヤショブアムは、三十人の長であった。彼は槍を振るって一度に三百人を刺し殺した。</span>
<span className="v" id="v12" data-v="12" data-xref="歴代誌上 27:4; サムエル記第二 23:17–19; サムエル記第二 23:23"> 彼に次いで、アホア人ドドの子エルアザルがいた。彼は三勇士の一人であった。</span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記第二 23:11–12; サムエル記第一 17:1"> 彼はパス・ダミムでダビデとともにいた。ペリシテ人はそこに戦いのために集まっていた。そこには大麦がいっぱいに実った畑の一部があり、民はペリシテ人の前から逃げていた。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 144:10; 列王記第二 5:1; サムエル記第一 14:23"> 彼らはその畑の真ん中に立ってそこを守り、ペリシテ人を打ち倒した。そして主は大いなる勝利によって彼らを救われた。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代誌上 14:9; サムエル記第二 5:18; イザヤ書 17:5"> 三十人の長のうち三人が、岩場を下り、アドラムの洞窟にいるダビデのもとへ行った。ペリシテ人の軍勢はレファイムの谷に陣を敷いていた。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記第一 10:5; サムエル記第一 13:4; サムエル記第一 13:23"> その時、ダビデは要害におり、ペリシテ人の守備隊はベツレヘムにあった。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨハネ 4:14; イザヤ書 12:3; サムエル記第二 23:15–16"> ダビデは水を飲みたいと切に願って言った。「誰か、ベツレヘムの門のそばにある井戸の水を私に飲ませてくれないか。」</span>
<span className="v" id="v18" data-v="18" data-xref="使徒の働き 21:13; サムエル記第一 19:5; 使徒の働き 20:24"> するとこの三人がペリシテ人の宿営を突破し、ベツレヘムの門のそばにある井戸から水を汲み、それを携えてダビデのもとに持って来た。しかしダビデはそれを飲もうとせず、主の御前に注ぎ出して、</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記第二 23:17; 詩篇 72:14; 士師記 9:17"> 言った。「このようなことをするなど、わが神が許されるはずがない。命を懸けて行ったこの人々の血を、どうして私が飲めようか。彼らは命がけでこれを持ち帰ったのだ。」それゆえ彼はそれを飲もうとはしなかった。これら三人の勇士はこのようなことを行った。</span>
<span className="v" id="v20" data-v="20" data-xref="サムエル記第一 26:6; 歴代誌上 2:16; サムエル記第二 20:6"> ヨアブの兄弟アビシャイは、その三人の長であった。彼は三百人に向かって槍を振るい、彼らを討った。彼にはあの三人と同じような名声があった。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第一の手紙 15:41; マタイ 13:8"> この三人の中でも、彼はほかの二人より尊ばれ、その長となった。しかし、最初の三人には及ばなかった。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記第二 23:20–23; サムエル記第二 8:18; ヨシュア記 15:21"> カブツェエルの勇士の子であるエホヤダの子ベナヤは、数々の功績をあげ、モアブのアリエルの二人の息子を討った。また、雪の日に穴の中へ下り、獅子を仕留めた。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記第一 17:7; サムエル記第一 17:4; 申命記 3:11"> 彼はまた、身の丈が五キュビト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一キュビトは肘から中指の先までの長さで、約46センチメートル、または18インチである。したがって、このエジプト人の身長は約2.3メートル、または7フィート6インチであった。">a</a></sup>もある巨漢のエジプト人を討った。エジプト人の手には機織りの巻き棒のような槍があったが、彼は一本の杖を持ってその者に下って行き、エジプト人の手から槍を奪い取り、その者の槍で彼を殺した。</span>
<span className="v" id="v24" data-v="24"> エホヤダの子ベナヤがこれらのことを行い、三勇士の間にその名を知られた。</span>
<span className="v" id="v25" data-v="25" data-xref="サムエル記第二 20:23"> 彼は確かに三十人のだれよりも尊ばれたが、最初の三人には及ばなかった。ダビデは彼を自分の護衛の長とした。</span>
<span className="v" id="v26" data-v="26" data-xref="歴代誌上 27:7; サムエル記第二 21:19; サムエル記第二 2:18–23"> また、軍隊の勇士たちは次のとおりである。ヨアブの兄弟アサエル、ベツレヘムのドドの子エルハナン、</span>
<span className="v" id="v27" data-v="27" data-xref="サムエル記第二 23:25–26"> ハロル人シャモテ、ペロン人ヘレツ、</span>
<span className="v" id="v28" data-v="28" data-xref="歴代誌上 27:12; 歴代誌上 27:9; サムエル記第二 23:27"> テコア人イケシュの子イラ、アナトテ人アビエゼル、</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記第二 23:27–28; 歴代誌上 27:11"> フシャ人シベカイ、アホア人イライ、</span>
<span className="v" id="v30" data-v="30" data-xref="歴代誌上 27:13; 歴代誌上 27:15; サムエル記第二 23:29"> ネトファ人マハライ、ネトファ人バアナの子ヘレド、</span>
<span className="v" id="v31" data-v="31" data-xref="サムエル記第二 23:29"> ベニヤミン人のギブア出身であるリバイの子イタイ、ピルアトン人ベナヤ、</span>
<span className="v" id="v32" data-v="32" data-xref="サムエル記第二 23:30–31"> ガアシュの谷から来たフライ、アルバテ人アビエル、</span>
<span className="v" id="v33" data-v="33"> バハルミ人アズマベテ、シャアルボン人エルヤフバ、</span>
<span className="v" id="v34" data-v="34" data-xref="サムエル記第二 23:32–33"> ギゾン人ハシェムの子ら、ハラル人シャゲの子ヨナタン、</span>
<span className="v" id="v35" data-v="35" data-xref="サムエル記第二 23:33–34"> ハラル人サカルの子アヒアム、ウルの子エリファル、</span>
<span className="v" id="v36" data-v="36"> メケラ人ヘフェル、ペロン人アヒヤ、</span>
<span className="v" id="v37" data-v="37" data-xref="サムエル記第二 23:35"> カルメル人ヘツロ、エズバイの子ナアライ、</span>
<span className="v" id="v38" data-v="38" data-xref="サムエル記第二 23:36"> ナタンの兄弟ヨエル、ハグリの子ミブハル、</span>
<span className="v" id="v39" data-v="39"> アモン人ツェレク、ツェルヤの子ヨアブの武具持ちであるベロテ人ナハライ、</span>
<span className="v" id="v40" data-v="40" data-xref="サムエル記第二 20:26"> イテル人イラ、イテル人ガレブ、</span>
<span className="v" id="v41" data-v="41" data-xref="歴代誌上 2:36; サムエル記第二 23:39; サムエル記第二 11:6–27"> ヒッタイト人ウリヤ、アフライの子ザバド、</span>
<span className="v" id="v42" data-v="42"> ルベン人の長である、ルベン人シザの子アディナ。彼とともに三十人がいた。</span>
<span className="v" id="v43" data-v="43"> マアカの子ハナン、ミテネ人ヨシャファテ、</span>
<span className="v" id="v44" data-v="44"> アシュテラテ人ウジヤ、アロエル人ホタンの子であるシャマとエイエル、</span>
<span className="v" id="v45" data-v="45"> シムリの子エディアエル、その兄弟であるティツ人ヨハ、</span>
<span className="v" id="v46" data-v="46"> マハビ人エリエル、エルナアムの子であるエリバイとヨシャブヤ、モアブ人イトマ、</span>
<span className="v" id="v47" data-v="47"> エリエル、オベド、およびメツォバ人ヤアシエル。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌上 29:28; 歴代誌上 28:5; 列王記第一 1:33–39"> ダビデは年老いて、その生涯を全うしようとしていた。そこで息子ソロモンをイスラエルの王とした。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 24:1; 歴代誌 第二 34:29–30; 歴代誌上 13:1"> 彼はイスラエルのすべての指導者、祭司、レビ人を集めた。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代誌上 23:24; 民数記 4:2–49"> 三十歳以上のレビ人が数えられ、一人ひとり数えた総数は三万八千人であった。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌 第二 19:8; 申命記 16:18; 歴代誌上 26:29–31"> ダビデは言った。「このうち二万四千人は主の家の仕事を監督し、六千人は役人と裁判官になり、</span>
<span className="v" id="v5" data-v="5" data-xref="歴代誌 第二 29:25–26; 歴代誌 第二 8:14; 詩篇 87:7"> 四千人は門衛となり、四千人は、私が賛美のために造った楽器を用いて主を賛美する。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歴代誌 第二 8:14; 歴代誌上 6:1; 歴代誌上 6:16"> ダビデはレビの子ら、ゲルション、ケハテ、メラリに従って、彼らを組に分けた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歴代誌上 26:21; 出エジプト記 6:17; 歴代誌上 6:17–20"> ゲルション人はラダンとシムイ。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代誌上 6:33–34; 歴代誌上 15:20–21; 歴代誌上 15:7"> ラダンの子らは、長男エヒエル、ゼタム、ヨエルの三人。</span>
<span className="v" id="v9" data-v="9"> シムイの子らは、シェロミテ、ハジエル、ハランの三人。これらはラダンの父祖の家のかしらであった。</span>
<span className="v" id="v10" data-v="10"> シムイの子らは、ヤハテ、ジナ、エウシュ、ベリヤ。この四人がシムイの子らであった。</span>
<span className="v" id="v11" data-v="11"> ヤハテが長男で、ジザが次男であった。エウシュとベリヤには多くの息子がいなかったので、二人を合わせて一つの父祖の家として数えた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 6:18; 民数記 3:27; 民数記 26:58"> ケハテの子らは、アムラム、イツハル、ヘブロン、ウジエルの四人。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 21:5; 出エジプト記 6:20; サムエル記第一 2:28"> アムラムの子らはアロンとモーセ。アロンは、その子らとともに、とこしえに最も聖なるものを聖別し、主の前で香をたき、主に仕え、御名によって祝福するために取り分けられた。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 33:1; 詩篇 90:1; 歴代誌上 26:23–25"> しかし神の人モーセの子らは、レビの部族の中に数えられた。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 18:3–4; 出エジプト記 2:22; 出エジプト記 4:20"> モーセの子らはゲルショムとエリエゼル。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代誌上 26:24; 歴代誌上 25:20; 歴代誌上 24:20"> ゲルショムの子らでは、シェブエルがかしらであった。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代誌上 26:25"> エリエゼルの子では、レハブヤがかしらであった。エリエゼルにはほかに息子がいなかったが、レハブヤの子らは非常に多かった。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代誌上 26:26; 歴代誌上 24:22"> イツハルの子では、シェロミテがかしらであった。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代誌上 24:23; 歴代誌上 15:9; 歴代誌上 23:12"> ヘブロンの子らは、長男エリヤ、次男アマルヤ、三男ヤハジエル、四男エカムアム。</span>
<span className="v" id="v20" data-v="20"> ウジエルの子らは、長男ミカ、次男イシヤ。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 6:19; 歴代誌上 6:20; 歴代誌上 24:26–30"> メラリの子らはマフリとムシ。マフリの子らはエルアザルとキシュ。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代誌上 24:28; 民数記 36:6–8"> エルアザルは息子を残さず、娘だけを残して死んだ。彼女たちは親族であるキシュの子らと結婚した。</span>
<span className="v" id="v23" data-v="23" data-xref="歴代誌上 24:30"> ムシの子らは、マフリ、エデル、エレモテの三人。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数記 10:17; 民数記 10:21; 歴代誌上 23:3"> 以上が父祖の家ごとに数えられたレビの子らである。彼らは父祖の家のかしらであり、一人ひとり名を挙げて登録された二十歳以上の者で、主の家の奉仕の仕事を行った。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 132:13–14; 歴代誌上 22:18; サムエル記第二 7:11"> ダビデがこう言ったからである。「イスラエルの神、主は御自分の民に安息を与え、とこしえにエルサレムに住まわれる。</span>
<span className="v" id="v26" data-v="26" data-xref="民数記 4:5; 民数記 7:9; 民数記 4:15"> したがって、レビ人はもはや幕屋と、その奉仕に用いるすべての器を運ぶ必要がない。」</span>
<span className="v" id="v27" data-v="27" data-xref="歴代誌上 23:24; 詩篇 72:20; サムエル記第二 23:1"> ダビデの最後の言葉に従って、レビの子らは二十歳以上の者が数えられた。</span>
<span className="v" id="v28" data-v="28" data-xref="歴代誌 第二 35:3–6; 歴代誌 第二 31:11; 歴代誌 第二 35:11–14"> 彼らの務めは、主の家の奉仕においてアロンの子らを助けることであった。すなわち、庭、部屋、すべての聖なるものの清め、および神の家の奉仕にかかわる仕事である。</span>
<span className="v" id="v29" data-v="29" data-xref="レビ記 19:35–36; 出エジプト記 25:30; レビ記 6:20–23"> また、供えのパン、穀物のささげ物に用いる上質の小麦粉、種なしの薄焼きパン、平鍋で焼くもの、練ったもの、およびすべての容量と寸法を量ることも彼らの務めであった。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 92:1–3; エズラ記 3:10–11; 歴代誌上 9:33"> さらに、毎朝立って主に感謝し、主を賛美し、夕方にも同じようにした。</span>
<span className="v" id="v31" data-v="31" data-xref="イザヤ書 1:13–14; 民数記 28:1–29; 民数記 10:10"> 安息日、新月の祭り、定められた祭りには、定められた数に従って主に全焼のいけにえをささげ、絶えず主の前に仕えた。</span>
<span className="v" id="v32" data-v="32" data-xref="民数記 1:53; 民数記 3:38; 民数記 3:6–9"> こうして彼らは、主の家の奉仕のため、会見の天幕の務め、聖所の務め、同族であるアロンの子らを助ける務めを守った。</span>
</div>

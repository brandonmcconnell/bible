<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌上 22:5; 列王記第一 3:7; 歴代誌 第二 13:7"> ダビデ王は全会衆に言った。「神がただ一人選ばれたわが子ソロモンは、まだ若く、経験も浅い。しかし、この事業は大きい。この宮は人のためではなく、主なる神のためだからである。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代誌上 22:3–5; コリント人への第二の手紙 8:3; イザヤ書 54:11–12"> 私は力の限り、わが神の家のために準備をしてきた。金の物のために金を、銀の物のために銀を、青銅の物のために青銅を、鉄の物のために鉄を、木の物のために木を、さらに縞めのう、はめ込み用の石、色とりどりの象眼用の石、あらゆる宝石、大理石を大量に用意した。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代誌上 21:24; 詩篇 27:4; 詩篇 26:8"> そのうえ私は、わが神の家を愛しているので、聖なる家のためにすでに用意したすべてのものに加え、自分の所有する金銀の財宝も、わが神の家にささげる。</span>
<span className="v" id="v4" data-v="4" data-xref="列王記第一 9:28; 歴代誌上 22:14; ヨブ記 28:16"> すなわち、建物の壁を覆うため、オフィルの金三千タラント<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一タラントは約三十キログラム、六十六ポンド、または九百六十五トロイオンス。三千タラントは約九十メートルトンに相当する。">a</a></sup>と、精錬された銀七千タラント<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="約二百十メートルトン。">b</a></sup>をささげる。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 7:2–3; 出エジプト記 35:5–9; エズラ記 7:15–16"> 金の物のために金を、銀の物のために銀を、職人の手で造られるあらゆる物のためにこれを用いる。では今日、だれが自ら進んで主に身をささげるだろうか。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="コリント人への第二の手紙 9:7; 歴代誌上 27:25–1; イザヤ書 60:3–10"> すると父祖の家のかしらたち、イスラエルの各部族の長、千人隊と百人隊の長、王の事業を管理する者たちが、進んでささげた。</span>
<span className="v" id="v7" data-v="7" data-xref="ネヘミヤ記 7:70–71; エズラ記 2:69"> 彼らは神の家の奉仕のために、金五千タラント<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一タラントは約三十キログラム、六十六ポンド、または九百六十五トロイオンス。五千タラントは約百五十メートルトンに相当する。">c</a></sup>と一万ダリク<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="ダリクはペルシア王が発行した金貨で、一枚は約八・四グラム、または約〇・二七トロイオンス。">d</a></sup>、銀一万タラント、青銅一万八千タラント、鉄十万タラントをささげた。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代誌上 23:8; 歴代誌上 26:21–22"> 宝石を持っていた者たちは、ゲルション人エヒエルの管理する主の家の宝物庫にそれを納めた。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第二の手紙 9:7–8; コリント人への第二の手紙 8:3; 列王記第一 8:61"> 民は、全き心で進んで主にささげたことを喜んだ。ダビデ王も大いに喜んだ。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 1:3; ペテロの手紙第一 1:3; ローマ人への手紙 1:7"> そこでダビデは全会衆の前で主をほめたたえ、こう言った。「私たちの父イスラエルの神、主よ。あなたはとこしえからとこしえまで、ほめたたえられる方です。</span>
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 1:3; ダニエル書 4:34–35; テモテへの手紙第一 1:17"> 主よ、偉大さ、力、栄光、勝利、威厳はあなたのものです。天と地にあるすべてのものはあなたのものだからです。主よ、王国はあなたのものです。あなたはすべてのものの上に、かしらとして高く上げられています。</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 3:16; 歴代誌 第二 20:6; 申命記 8:18"> 富と誉れはあなたから出ます。あなたはすべてを治めておられます。力と勢いはあなたの御手のうちにあり、すべてのものを大いなる者とし、強くするのもあなたの御手にあります。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 106:1; コリント人への第二の手紙 9:15; コリント人への第二の手紙 8:16"> それゆえ今、私たちの神よ、私たちはあなたに感謝し、栄光に満ちた御名を賛美します。</span>
<span className="v" id="v14" data-v="14" data-xref="ヤコブの手紙 1:17; コリント人への第二の手紙 3:5; ローマ人への手紙 11:36"> しかし、私は何者でしょう。私の民は何者でしょう。このように進んでささげる力が、私たちにあるというのでしょうか。すべてはあなたから出たものであり、私たちはあなたの御手から受けたものを、あなたにお返ししたにすぎません。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 144:4; レビ記 25:23; 詩篇 102:11"> 私たちは父祖たちと同じように、あなたの前では寄留者であり、旅人です。地上にある私たちの日々は影のようで、長くとどまることはありません。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代誌上 29:14; 詩篇 24:1; 歴代誌 第二 31:10"> 私たちの神、主よ。あなたの聖なる御名のために家を建てようと準備したこのすべての豊かな物は、あなたの御手から出たものであり、すべてあなたのものです。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 17:10; 箴言 11:20; 歴代誌上 28:9"> わが神よ。あなたは心を試し、まっすぐなことを喜ばれると、私は知っています。私はまっすぐな心で、これらすべてを進んでささげました。今ここにいるあなたの民も、進んであなたにささげるのを見て、私は喜んでいます。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 32:39; エレミヤ書 10:23; ヘブル人への手紙 13:21"> 私たちの父祖アブラハム、イサク、イスラエルの神、主よ。この願いと志を、あなたの民の心の思いのうちにとこしえに保ち、彼らの心をあなたへ向けさせてください。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 72:1; 歴代誌上 28:9; ヤコブの手紙 1:17"> わが子ソロモンに全き心を与え、あなたの命令、証し、掟を守り、これらすべてを行い、私が準備を整えた宮を建てさせてください。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="詩篇 95:6; 出エジプト記 4:31; 詩篇 135:19–21"> それからダビデは全会衆に言った。「今、あなたがたの神、主をほめたたえよ。」<br />全会衆は父祖の神、主をほめたたえ、頭を垂れ、主と王の前にひれ伏した。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代誌 第二 7:4–9; 民数記 15:7; エズラ記 6:17"> その翌日、彼らは主にいけにえをささげ、主に全焼のいけにえをささげた。雄牛千頭、雄羊千匹、子羊千匹と、それに伴う注ぎのささげ物、さらに全イスラエルのために多くのいけにえをささげた。</span>
<span className="v" id="v22" data-v="22" data-xref="列王記第一 2:35; 歴代誌上 23:1; 出エジプト記 24:11"> その日、彼らは主の前で食べて飲み、大いに喜んだ。そしてダビデの子ソロモンを再び王とし、主の前で油を注いで君とした。またツァドクにも油を注いで祭司とした。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王記第一 2:12; 歴代誌上 28:5; ローマ人への手紙 13:1"> こうしてソロモンは父ダビデに代わって、主の王座に着き、王として栄えた。全イスラエルは彼に従った。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代誌上 2:3–9; エゼキエル書 17:18; 創世記 24:2"> すべての指導者、勇士、さらにダビデ王のすべての息子も、ソロモン王に服従した。</span>
<span className="v" id="v25" data-v="25" data-xref="歴代誌 第二 1:12; 歴代誌 第二 1:1; 伝道者の書 2:9"> 主は全イスラエルの目の前でソロモンをこの上なく大いなる者とし、彼より前のイスラエルのどの王にもなかった王の威厳を彼に与えられた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歴代誌上 18:14; 詩篇 78:71–72"> エッサイの子ダビデは全イスラエルを治めた。</span>
<span className="v" id="v27" data-v="27" data-xref="列王記第一 2:11; サムエル記第二 5:4–5; 歴代誌上 3:4"> 彼がイスラエルを治めた期間は四十年であった。ヘブロンで七年、エルサレムで三十三年治めた。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 15:15; 使徒の働き 13:36; 歴代誌上 23:1"> 彼は長寿、富、誉れに満ち、幸いな老年を迎えて死んだ。その子ソロモンが代わって王となった。</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記第一 9:9; サムエル記第二 12:1–7; 歴代誌上 21:9–11"> ダビデ王の最初から最後までの事績は、先見者サムエルの記録、預言者ナタンの記録、先見者ガドの記録に書かれている。</span>
<span className="v" id="v30" data-v="30" data-xref="ダニエル書 4:25; ダニエル書 4:23; ダニエル書 2:21"> そこには彼の統治と力、彼とイスラエル、および諸国のすべての王国に起こった出来事が記されている。</span>
</div>

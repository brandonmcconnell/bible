<span className="v" id="v2" data-v="2" data-xref="ルカ 3:37; 創世記 5:12–20; 創世記 5:9"> カイナン、マハラレル、ヤレド、</span>
<span className="v" id="v3" data-v="3" data-xref="ユダ 1:14; 創世記 5:21–31; ルカ 3:36–37"> エノク、メトセラ、レメク、</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 5:32; 創世記 9:18; ルカ 17:26"> ノア、セム、ハム、ヤペテ。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 10:1–5; エゼキエル書 38:6; エゼキエル書 27:13"> ヤペテの子らは、ゴメル、マゴグ、マダイ、ヤワン、トバル、メシェク、ティラス。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 10:3"> ゴメルの子らは、アシュケナズ、ディパテ、トガルマ。</span>
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 2:10; 民数記 24:24; イザヤ書 66:19"> ヤワンの子らは、エリシャ、タルシシュ、キティム、ロダニム。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="創世記 10:6–7"> ハムの子らは、クシュ、ミツライム、プテ、カナン。</span>
<span className="v" id="v9" data-v="9"> クシュの子らは、セバ、ハビラ、サブタ、ラアマ、サブテカ。ラアマの子らは、シェバとデダン。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 10:8–12; ミカ書 5:6"> クシュはニムロドをもうけた。ニムロドは地上で勇士となり始めた。</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 10:13–18"> ミツライムは、ルディム、アナミム、レハビム、ナフトヒム、</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 2:23; エレミヤ書 47:4; アモス書 9:7"> パトルシム、カスルヒム（ペリシテ人はここから出た）、カフトリムの父となった。</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 9:22; 創世記 23:20; 創世記 10:15–19"> カナンは、その長子シドン、ヘテ、</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 15:21; ヨシュア記 3:10; 出エジプト記 33:2"> エブス人、アモリ人、ギルガシ人、</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 3:8; 列王記第一 9:20; 出エジプト記 13:5"> ヒビ人、アルキ人、シニ人、</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 34:8; 列王記第一 8:65"> アルワド人、ツェマリ人、ハマテ人の父となった。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="創世記 10:22–32; エズラ記 4:2; エゼキエル書 32:24"> セムの子らは、エラム、アシュル、アルパクシャド、ルド、アラム、ウツ、フル、ゲテル、メシェク。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 11:12–15; 創世記 10:24"> アルパクシャドはシェラの父となり、シェラはエベルの父となった。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 10:21; 創世記 11:16–17; 創世記 10:25"> エベルには二人の息子が生まれた。一人の名はペレグであった。彼の時代に地が分けられたからである。その兄弟の名はヨクタンであった。</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 10:26–27"> ヨクタンは、アルモダド、シェレフ、ハツァルマベテ、エラ、</span>
<span className="v" id="v21" data-v="21"> ハドラム、ウザル、ディクラ、</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 10:28"> エバル、アビマエル、シェバ、</span>
<span className="v" id="v23" data-v="23" data-xref="列王記第一 10:11; 創世記 25:18; サムエル記第一 15:7"> オフィル、ハビラ、ヨバブの父となった。これらは皆ヨクタンの子らである。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 11:10–26; ルカ 3:34–36"> セム、アルパクシャド、シェラ、</span>
<span className="v" id="v25" data-v="25" data-xref="ルカ 3:35"> エベル、ペレグ、レウ、</span>
<span className="v" id="v26" data-v="26" data-xref="ルカ 3:34–35"> セルグ、ナホル、テラ、</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 11:27–32; ネヘミヤ記 9:7; ヨシュア記 24:2"> アブラム（別名アブラハム）。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="創世記 17:19–21; 創世記 21:2–5; 創世記 21:9–10"> アブラハムの子らは、イサクとイシュマエル。</span>
<span className="v" id="v29" data-v="29" data-xref="イザヤ書 60:7; 創世記 25:12–16; 雅歌 1:5"> 彼らの系図は次のとおりである。イシュマエルの長子ネバヨト、次にケダル、アドベエル、ミブサム、</span>
<span className="v" id="v30" data-v="30" data-xref="イザヤ書 21:11; 創世記 25:15"> ミシュマ、ドゥマ、マサ、ハダド、テマ、</span>
<span className="v" id="v31" data-v="31"> エツル、ナフィシュ、ケデマ。以上がイシュマエルの子らである。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="創世記 25:1–4; エレミヤ書 25:23; 士師記 6:1–6"> アブラハムのそばめケトラの子ら。彼女はジムラン、ヨクシャン、メダン、ミディアン、イシュバク、シュアを産んだ。ヨクシャンの子らは、シェバとデダン。</span>
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 60:6"> ミディアンの子らは、エパ、エフェル、エノク、アビダ、エルダア。これらは皆ケトラの子らである。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="創世記 32:28; 使徒の働き 7:8; マタイ 1:2"> アブラハムはイサクをもうけた。イサクの子らは、エサウとイスラエル。</span>
<span className="v" id="v35" data-v="35" data-xref="創世記 36:9–10; 創世記 36:4–5"> エサウの子らは、エリファズ、レウエル、エウシュ、ヤラム、コラ。</span>
<span className="v" id="v36" data-v="36" data-xref="エレミヤ書 49:20; アモス書 1:12; オバデヤ書 1:9"> エリファズの子らは、テマン、オマル、ツェフィ、ガタム、ケナズ、ティムナ、アマレク。</span>
<span className="v" id="v37" data-v="37"> レウエルの子らは、ナハテ、ゼラ、シャマ、ミザ。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="創世記 36:20–30"> セイルの子らは、ロタン、ショバル、ツィベオン、アナ、ディション、エツェル、ディシャン。</span>
<span className="v" id="v39" data-v="39" data-xref="申命記 2:12; 創世記 36:22; 申命記 2:22"> ロタンの子らは、ホリとホマム。ティムナはロタンの妹であった。</span>
<span className="v" id="v40" data-v="40" data-xref="創世記 36:23–24"> ショバルの子らは、アルヤン、マナハテ、エバル、シェフィ、オナム。ツィベオンの子らは、アヤとアナ。</span>
<span className="v" id="v41" data-v="41" data-xref="創世記 36:25–26"> アナの子はディション。ディションの子らは、ハムラン、エシュバン、イトラン、ケラン。</span>
<span className="v" id="v42" data-v="42" data-xref="哀歌 4:21; 創世記 36:27–28"> エツェルの子らは、ビルハン、ザアバン、ヤアカン。ディシャンの子らは、ウツとアラン。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="創世記 36:31–43; 民数記 24:17–19; 創世記 49:10"> イスラエルの子らを治める王がまだだれもいなかったころ、エドムの地で治めていた王たちは次のとおりである。ベオルの子ベラ、その町の名はディンハバであった。</span>
<span className="v" id="v44" data-v="44" data-xref="イザヤ書 34:6; イザヤ書 63:1; アモス書 1:12"> ベラが死ぬと、ボツラのゼラの子ヨバブが代わって王となった。</span>
<span className="v" id="v45" data-v="45" data-xref="創世記 36:11; ヨブ記 2:11"> ヨバブが死ぬと、テマン人の地のフシャムが代わって王となった。</span>
<span className="v" id="v46" data-v="46"> フシャムが死ぬと、ベダドの子ハダドが代わって王となった。彼はモアブの野でミディアンを打ち破った。彼の町の名はアビテであった。</span>
<span className="v" id="v47" data-v="47" data-xref="創世記 36:36"> ハダドが死ぬと、マスレカのサムラが代わって王となった。</span>
<span className="v" id="v48" data-v="48" data-xref="創世記 36:37"> サムラが死ぬと、川のほとりのレホボトのシャウルが代わって王となった。</span>
<span className="v" id="v49" data-v="49"> シャウルが死ぬと、アクボルの子バアル・ハナンが代わって王となった。</span>
<span className="v" id="v50" data-v="50" data-xref="創世記 36:39"> バアル・ハナンが死ぬと、ハダドが代わって王となった。彼の町の名はパイであった。彼の妻の名はメヘタベルといい、マトレドの娘であってメ・ザハブの孫娘であった。</span>
<span className="v" id="v51" data-v="51" data-xref="創世記 36:40"> その後、ハダドは死んだ。エドムの首長たちは次のとおりであった。首長ティムナ、首長アルヤ、首長エテテ、</span>
<span className="v" id="v52" data-v="52"> 首長オホリバマ、首長エラ、首長ピノン、</span>
<span className="v" id="v53" data-v="53"> 首長ケナズ、首長テマン、首長ミブツァル、</span>
<span className="v" id="v54" data-v="54" data-xref="創世記 36:41–43"> 首長マグディエル、首長イラム。以上がエドムの首長たちである。</span>

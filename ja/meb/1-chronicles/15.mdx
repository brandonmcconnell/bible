<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌上 16:1; 歴代誌上 17:1–5; 詩篇 132:5"> ダビデはダビデの町に自分のために家々を建てた。また、神の箱のために場所を整え、そのために天幕を張った。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 10:8; 申命記 31:9; 民数記 18:1–8"> そのとき、ダビデは言った。「レビ人以外はだれも神の箱を担いではならない。主が神の箱を担ぎ、とこしえに主に仕えるために彼らを選ばれたからである。」</span>
<span className="v" id="v3" data-v="3" data-xref="列王記第一 8:1; 歴代誌上 13:5; 歴代誌上 15:1"> ダビデは、主の箱を彼が整えたその場所に運び上るために、全イスラエルをエルサレムに集めた。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 6:16–22; 歴代誌上 12:26–28; 歴代誌上 6:16–30"> ダビデはアロンの子らとレビ人を集めた。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代誌上 6:22–24"> ケハテの子らのうちからは、長であるウリエルと、その兄弟たち百二十人。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代誌上 6:29–30"> メラリの子らのうちからは、長であるアサヤと、その兄弟たち二百二十人。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌上 15:11; 歴代誌上 23:8"> ゲルショムの子らのうちからは、長であるヨエルと、その兄弟たち百三十人。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 6:22"> エリツァファンの子らのうちからは、長であるシェマヤと、その兄弟たち二百人。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 6:18; 歴代誌上 23:19; 歴代誌上 26:30–31"> ヘブロンの子らのうちからは、長であるエリエルと、その兄弟たち八十人。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 6:18; 歴代誌上 6:18; 歴代誌上 23:12"> ウジエルの子らのうちからは、長であるアミナダブと、その兄弟たち百十二人。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="歴代誌上 12:28; 列王記第一 2:35; サムエル記第一 22:20–23"> ダビデは祭司ツァドクとアビアタルを呼び、またレビ人であるウリエル、アサヤ、ヨエル、シェマヤ、エリエル、アミナダブを呼んで、</span>
<span className="v" id="v12" data-v="12" data-xref="歴代誌 第二 35:6; 出エジプト記 19:14–15; 歴代誌上 15:14"> 彼らに言った。「あなたがたはレビ人の父祖の家の長である。あなたがたとその兄弟たちは自らを聖別し、イスラエルの神、主の箱を、私が整えた場所に運び上りなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記第二 6:3; コリント人への第一の手紙 14:40; ヨハネの手紙第一 1:8–10"> 初めはあなたがたがそれを担がなかったので、私たちの神、主は怒りをもって私たちを打たれた。私たちが掟に従って主に尋ね求めなかったからである。」</span>
<span className="v" id="v14" data-v="14" data-xref="歴代誌 第二 29:15; ヨエル書 2:16–17; 歴代誌 第二 29:34"> そこで祭司たちとレビ人たちは、イスラエルの神、主の箱を運び上るために自らを聖別した。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 4:15; 民数記 7:9; 歴代誌 第二 5:9"> レビ人の子らは、主の言葉に従ってモーセが命じたとおりに、神の箱の棒を肩に載せて担いだ。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歴代誌上 13:8; 歴代誌 第二 5:13; 歴代誌上 16:42"> ダビデはレビ人の長たちに命じて、彼らの同族を歌い手として任命し、楽器、すなわち琴、竪琴、シンバルを高らかに鳴らして、喜びの声を上げさせた。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代誌上 6:39; 歴代誌上 6:44; 歴代誌上 6:33"> そこでレビ人たちはヨエルの子ヘマンを任命した。またその兄弟たちのうちからはベレクヤの子アサフを、彼らの兄弟であるメラリの子らのうちからはクシャヤの子エタンを任命し、</span>
<span className="v" id="v18" data-v="18" data-xref="歴代誌上 26:4; 歴代誌上 26:8; 歴代誌上 13:14"> さらに彼らとともに、第二の組に属する同族の者たちであるゼカリヤ、ベン、ヤアジエル、シェミラモテ、エヒエル、ウニ、エリアブ、ベナヤ、マアセヤ、マティティヤ、エリフェレフ、ミクネヤ、および門衛であるオベド・エドムとエイエルを任命した。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代誌上 25:6; 歴代誌上 16:5; 歴代誌上 13:8"> 歌い手ヘマン、アサフ、エタンは、青銅のシンバルを高らかに鳴らすために任命された。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 46:1–11"> ゼカリヤ、アジエル、シェミラモテ、エヒエル、ウニ、エリアブ、マアセヤ、ベナヤは、アラモテの調べに合わせて琴を奏でるため、</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記第一 10:5; 歴代誌上 25:6–7; 詩篇 81:1–2"> マティティヤ、エリフェレフ、ミクネヤ、オベド・エドム、エイエル、アザズヤは、八弦の竪琴に合わせて指揮をするために任命された。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代誌上 15:27; 歴代誌上 15:16; 歴代誌上 25:7–8"> レビ人の長ケナニヤは歌の指揮を執った。彼が熟練者だったからである。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 84:10; 列王記第二 22:4; 歴代誌上 9:21–23"> ベレクヤとエルカナは箱の門衛であった。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代誌上 16:6; 民数記 10:8; 歴代誌上 15:28"> 祭司であるシェバヌヤ、ヨシャファテ、ネタンエル、アマサイ、ゼカリヤ、ベナヤ、エリエゼルは、神の箱の前でラッパを吹き鳴らした。またオベド・エドムとエヒヤは箱の門衛であった。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="サムエル記第二 6:12–23; ミカ書 5:2; ピリピ人への手紙 3:3"> こうして、ダビデとイスラエルの長老たち、および千人隊の長たちは行って、主の契約の箱をオベド・エドムの家から喜びをもって運び上った。</span>
<span className="v" id="v26" data-v="26" data-xref="民数記 23:29; 歴代誌上 29:14; 詩篇 66:13–15"> 神が主の契約の箱を担ぐレビ人たちを助けられたので、彼らは七頭の雄牛と七頭の雄羊をいけにえとしてささげた。</span>
<span className="v" id="v27" data-v="27" data-xref="サムエル記第一 2:18; サムエル記第二 6:14"> ダビデ、箱を担ぐすべてのレビ人、歌い手、また歌い手を指揮するケナニヤは、上質の亜麻布の衣を着ていた。ダビデはまた亜麻布のエポデを身に着けていた。</span>
<span className="v" id="v28" data-v="28" data-xref="歴代誌上 13:8; 歴代誌上 15:16; 歴代誌 第二 5:12–13"> こうして、全イスラエルは喜びの叫びと、角笛の音、ラッパ、シンバルを伴い、琴と竪琴を高らかに鳴らして、主の契約の箱を運び上った。</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記第二 6:20–23; サムエル記第二 6:16; 申命記 31:26"> 主の契約の箱がダビデの町に入ったとき、サウルの娘ミカルは窓から見下ろし、ダビデ王が踊り、楽器を奏でているのを見て、心の中で彼をさげすんだ。</span>
</div>

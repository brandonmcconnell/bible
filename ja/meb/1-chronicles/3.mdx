<span className="v" id="v2" data-v="2" data-xref="サムエル記第二 19:4–10; サムエル記第二 3:4; 列王記第一 2:24–25"> 三男アブサロムはゲシュルの王タルマイの娘マアカの子。四男アドニヤはハギテの子。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記第二 3:5"> 五男シェファティヤはアビタルの子。六男イトレアムはその妻エグラによる。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記第二 2:11; サムエル記第二 5:4–5; 列王記第一 2:11"> この六人がヘブロンで彼に生まれた。彼はそこで七年六か月治めた。また、エルサレムで三十三年治めた。</span>
<span className="v" id="v5" data-v="5" data-xref="サムエル記第二 11:3; サムエル記第二 12:24–25; サムエル記第二 12:1–15"> エルサレムで彼に生まれたのは次のとおりである。アミエルの娘バテ・シュアによるシメア、ショバブ、ナタン、ソロモンの四人。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記第二 5:15; 歴代誌上 14:5; サムエル記第一 14:5"> さらに、イブハル、エリシャマ、エリフェレテ、</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記第二 5:15–16"> ノガ、ネフェグ、ヤフィア、</span>
<span className="v" id="v8" data-v="8" data-xref="歴代誌上 14:7; サムエル記第二 5:14–16"> エリシャマ、エルヤダ、エリフェレテの九人。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記第二 13:1–20; サムエル記第二 5:13"> これらは皆ダビデの子らであり、このほかにそばめたちの子らがいた。また、タマルは彼らの妹であった。</span>

<span className="v" id="v11" data-v="11" data-xref="列王記第二 8:24; 歴代誌 第二 21:17; 列王記第二 11:21"> その子はヨラム、その子はアハズヤ、その子はヨアシュ、</span>
<span className="v" id="v12" data-v="12" data-xref="歴代誌 第二 25:1; 列王記第二 14:21; 列王記第二 14:1"> その子はアマツヤ、その子はアザルヤ、その子はヨタム、</span>
<span className="v" id="v13" data-v="13" data-xref="列王記第二 18:1; 列王記第二 16:1; 歴代誌 第二 29:1"> その子はアハズ、その子はヒゼキヤ、その子はマナセ、</span>
<span className="v" id="v14" data-v="14" data-xref="列王記第二 23:30; 歴代誌 第二 34:1; 列王記第二 21:19"> その子はアモン、その子はヨシヤ。</span>
<span className="v" id="v15" data-v="15" data-xref="列王記第二 23:34"> ヨシヤの子らは、長子ヨハナン、次男エホヤキム、三男ゼデキヤ、四男シャルム。</span>
<span className="v" id="v16" data-v="16" data-xref="列王記第二 24:6; マタイ 1:11; 列王記第二 24:17"> エホヤキムの子らは、その子エコニヤ、その子ゼデキヤ。</span>
<span className="v" id="v17" data-v="17" data-xref="エズラ記 3:2; エズラ記 5:2; マタイ 1:12"> 捕囚となったエコニヤの子らは、その子シェアルティエル、</span>

<span className="v" id="v20" data-v="20"> さらにハシュバ、オヘル、ベレクヤ、ハサデヤ、ユシャブ・ヘセドの五人。</span>

<span className="v" id="v22" data-v="22" data-xref="エズラ記 8:2"> シェカニヤの子は、シェマヤ。シェマヤの子らは、ハトシュ、イガル、バリア、ネアルヤ、シャファテの六人。</span>
<span className="v" id="v23" data-v="23"> ネアルヤの子らは、エリオエナイ、ヒズキヤ、アズリカムの三人。</span>
<span className="v" id="v24" data-v="24"> エリオエナイの子らは、ホダブヤ、エルヤシブ、ペラヤ、アクブ、ヨハナン、デラヤ、アナニの七人。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 46:13; 民数記 26:23–24"> イッサカルの子らは、トラ、プア、ヤシュブ、シムロンの四人。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記第二 24:1–9; 歴代誌上 27:23–24; 歴代誌上 27:1"> トラの子らは、ウジ、レファヤ、エリエル、ヤフマイ、イブサム、シェムエルであり、トラの父祖の家の長であった。彼らはその世代において力ある勇士であった。ダビデの時代の彼らの数は二万二千六百人であった。</span>
<span className="v" id="v3" data-v="3"> ウジの子は、イズラフヤ。イズラフヤの子らは、ミカエル、オバデヤ、ヨエル、イシヤの五人。彼らは皆、長の者であった。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌上 12:32"> 彼らとともに、彼らの世代に従って、父祖の家ごとに、戦いのための軍隊の部隊が三万六千人いた。彼らには多くの妻と子らがいたからである。</span>
<span className="v" id="v5" data-v="5"> イッサカルのすべての諸氏族の中での彼らの兄弟たちは力ある勇士であり、すべて系図に記された数は八万七千人であった。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="創世記 46:21; 歴代誌上 8:1–40; 歴代誌上 7:10–11"> ベニヤミンの子らは、ベラ、ベケル、エディアエルの三人。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌 第二 17:17–18; 歴代誌上 21:1–5"> ベラの子らは、エツボン、ウジ、ウジエル、エリモテ、イリの五人で、父祖の家の長であり、力ある勇士であった。彼らの系図に記された数は二万二千三十四人であった。</span>
<span className="v" id="v8" data-v="8"> ベケルの子らは、ゼミラ、ヨアシュ、エリエゼル、エリオエナイ、オムリ、エレモテ、アビヤ、アナトテ、アレメテ。これらはすべてベケルの子らであった。</span>
<span className="v" id="v9" data-v="9"> 彼らの系図には、彼らの世代に従って、父祖の家の長であり、力ある勇士である二万二百人が記されていた。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 3:15–30"> エディアエルの子は、ビルハン。ビルハンの子らは、エウシュ、ベニヤミン、エフデ、ケナアナ、ゼタン、タルシシュ、アヒシャハル。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代誌 第二 17:13–19"> これらは皆エディアエルの子らで、父祖の家のかしらである力ある勇士だった。軍に加わって戦いに出られる者は一万七千二百人であった。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 26:38–39; 創世記 46:21; 歴代誌上 7:15"> イルの子であるシュピムとフピム、およびアヘルの子であるフシムもそうであった。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数記 26:48–49; 創世記 30:3–8; 創世記 35:22"> ナフタリの子らは、ヤフジエル、グニ、エツェル、シャルム、そしてビルハの子らであった。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数記 32:30–42; 士師記 5:14; 申命記 3:13–15"> マナセの子らは次のとおりである。アラム人のそばめが産んだアスリエル。彼女はギルアドの父マキルを産んだ。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 26:33; 民数記 36:1–12; 民数記 27:1–11"> マキルはフピムとシュピムの姉妹を妻に迎えた。その名はマアカであった。二番目の者の名はツェロフハデであった。ツェロフハデには娘たちがいた。</span>
<span className="v" id="v16" data-v="16"> マキルの妻マアカは息子を産み、彼をペレシュと名付けた。彼の兄弟の名はシェレシュであり、彼の子らはウラムとレケムであった。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記第一 12:11"> ウラムの子は、ベダン。これらはマナセの子マキルの子ギルアドの子らであった。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 6:24; 士師記 6:11; 士師記 8:2"> 彼の妹ハムレケテはイシュホド、アビエゼル、マフラを産んだ。</span>
<span className="v" id="v19" data-v="19"> シュミダの子らは、アヒヤン、シェケム、リクヒ、アニアムであった。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数記 26:35–36"> エフライムの子らは、シュテラ、その子ベレド、その子タハテ、その子エルアダ、その子タハテ、</span>
<span className="v" id="v21" data-v="21"> その子ザバド、その子シュテラ、そしてエゼル、エレアドであった。彼らが家畜を奪い取ろうと下って行ったため、その地に生まれたガテの人々が彼らを殺した。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨブ記 2:11; 創世記 37:34"> 彼らの父エフライムは幾日も喪に服し、彼の兄弟たちは彼を慰めに来た。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記第二 23:5"> 彼が妻と交わると、彼女は身ごもって息子を産んだ。彼はその子をベリア<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「ベリア」は、ヘブル語で「災い」を表す言葉と音が似ている。">a</a></sup>と名付けた。彼の家に災いがあったからである。</span>
<span className="v" id="v24" data-v="24" data-xref="ヨシュア記 16:3; ヨシュア記 16:5; 歴代誌 第二 8:5"> 彼の娘はシェエラであった。彼女は下と上のベテ・ホロン、およびウゼン・シェエラを建てた。</span>
<span className="v" id="v25" data-v="25"> その子レファ、その子レシェフ、その子テラ、その子タハン、</span>
<span className="v" id="v26" data-v="26"> その子ラダン、その子アミフド、その子エリシャマ、</span>
<span className="v" id="v27" data-v="27" data-xref="民数記 13:8; 民数記 13:16; 出エジプト記 17:9–14"> その子ヌン、その子ヨシュア。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 28:19; ヨシュア記 16:2–3; 歴代誌上 6:66–67"> 彼らの所有地と居住地は、ベテルとその町々、東のほうはナアラン、西のほうはゲゼルとその町々、またシェケムとその町々、アザとその町々にまで及んだ。</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 1:22–29; ゼカリヤ書 12:11; 列王記第二 9:27"> また、マナセの子らの境界のそばには、ベテ・シャンとその町々、タアナクとその町々、メギドとその町々、ドルとその町々があった。イスラエルの子ヨセフの子らはこれらに住んだ。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="創世記 46:17; 民数記 26:44–46"> アシェルの子らは、イムナ、イシュワ、イシュビ、ベリア。セラは彼らの妹であった。</span>
<span className="v" id="v31" data-v="31"> ベリアの子らは、ヘベルと、ビルザイテの父であるマルキエル。</span>
<span className="v" id="v32" data-v="32"> ヘベルはヤフレテ、ショメル、ホタム、および彼らの妹シュアの父となった。</span>
<span className="v" id="v33" data-v="33"> ヤフレテの子らは、パサク、ビムハル、アシュバテ。これらがヤフレテの子らである。</span>
<span className="v" id="v34" data-v="34"> シェメルの子らは、アヒ、ロフガ、エフバ、アラム。</span>
<span className="v" id="v35" data-v="35"> 彼の兄弟ヘレムの子らは、ツォファ、イムナ、シェレシュ、アマル。</span>
<span className="v" id="v36" data-v="36"> ツォファの子らは、スア、ハルネフェル、シュアル、ベリ、イムラ、</span>
<span className="v" id="v37" data-v="37"> ベツェル、ホド、シャマ、シルシャ、イトラン、ベエラ。</span>
<span className="v" id="v38" data-v="38"> エテルの子らは、エフネ、ピスパ、アラ。</span>
<span className="v" id="v39" data-v="39"> ウラの子らは、アラ、ハニエル、リツヤ。</span>
<span className="v" id="v40" data-v="40" data-xref="歴代誌上 21:1–5; サムエル記第二 24:1–9"> これらは皆アシェルの子らであり、父祖の家の長、選り抜きの力ある勇士、諸侯の長であった。戦いの務めのために系図に記された彼らの数は二万六千人であった。</span>
</div>

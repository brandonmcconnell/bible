<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌 第二 3:1; 歴代誌上 21:18–28; 創世記 28:17"> そこでダビデは言った。「こここそ主なる神の家となる場所であり、ここがイスラエルのための全焼のいけにえの祭壇となる。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="歴代誌 第二 2:17; 列王記第一 9:20–21; 列王記第一 5:17–18"> ダビデはイスラエルの地に住む寄留者たちを集めるよう命じ、神の家を建てるために切り石を整える石工を任命した。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代誌上 22:14; 歴代誌上 29:2; 列王記第一 7:47"> また、門の扉の釘や継ぎ金具に用いる鉄を大量に準備し、量りきれないほどの青銅も備えた。</span>
<span className="v" id="v4" data-v="4" data-xref="列王記第一 5:6–10; エズラ記 3:7; 歴代誌 第二 2:3"> 香柏の材木も数えきれないほど用意した。シドン人とツロ人が大量の香柏をダビデのもとに運んで来たからである。</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第一 3:7; 歴代誌上 29:1; ヨハネ 3:30"> ダビデは言った。「わが子ソロモンはまだ若く、経験も浅い。主のために建てる家は、あらゆる国で名声と栄光を得るほど壮麗なものでなければならない。だから私がその準備をしておこう。」こうしてダビデは、死ぬ前に多くのものを準備した。</span>
<span className="v" id="v6" data-v="6" data-xref="民数記 27:23; 使徒の働き 20:25–31; 使徒の働き 1:2"> それから息子ソロモンを呼び、イスラエルの神、主のために家を建てるよう命じた。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 132:5; 列王記第一 8:16–20; 歴代誌 第二 6:7–9"> ダビデは息子ソロモンに言った。「私は、わが神、主の御名のために家を建てたいと心に願っていた。</span>
<span className="v" id="v8" data-v="8" data-xref="列王記第一 5:3; 歴代誌上 28:3; 歴代誌上 17:4–10"> しかし主の言葉が私に臨んだ。『あなたは多くの血を流し、大きな戦いを重ねてきた。わたしの目の前で地上に多くの血を流したので、わたしの名のために家を建ててはならない。</span>
<span className="v" id="v9" data-v="9" data-xref="列王記第一 4:25; 列王記第一 5:4; 列王記第一 4:20"> 見よ、あなたに一人の子が生まれる。彼は平安の人となる。わたしは彼を周囲のすべての敵から守り、安息を与える。彼の名はソロモンとなり、彼の時代にイスラエルへ平和と平穏を与える。</span>
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 1:5; サムエル記第二 7:13–14; 歴代誌上 17:12–14"> 彼がわたしの名のために家を建てる。彼はわたしの子となり、わたしは彼の父となる。わたしは彼の王国の王座をイスラエルの上にとこしえに堅く立てる。』</span>
<span className="v" id="v11" data-v="11" data-xref="歴代誌上 22:16; 歴代誌上 28:20; テモテへの第二の手紙 4:22"> わが子よ、どうか主があなたとともにおられますように。主があなたについて語られたとおり、あなたが栄え、あなたの神、主の家を建てることができるように。</span>
<span className="v" id="v12" data-v="12" data-xref="ヤコブの手紙 1:5; 箴言 14:8; 列王記第一 3:9–12"> ただ、主があなたに思慮と理解を与え、イスラエルを治めさせてくださるように。そうして、あなたの神、主の律法を守ることができるように。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨシュア記 1:6–9; 歴代誌上 28:20; 歴代誌上 28:7"> 主がイスラエルについてモーセに命じられた掟と定めを注意深く行うなら、あなたは栄える。強く、雄々しくあれ。恐れてはならない。おじけてはならない。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代誌上 22:3; 列王記第二 25:16; 歴代誌上 29:4–7"> 見よ、私は苦労を重ねながら、主の家のために金十万タラント<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一タラントは約三十キログラム、六十六ポンド、または九百六十五トロイオンス。十万タラントは約三千メートルトンに相当する。">a</a></sup>、銀百万タラント<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="約三万メートルトン。">b</a></sup>を準備した。青銅と鉄はあまりにも多く、量ることができない。材木と石も用意したが、あなたはさらに加えることができる。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 28:6; 出エジプト記 35:32; 列王記第一 7:14"> あなたのもとには多くの職人がいる。石を切る者、石工、木工、あらゆる仕事に熟練した者たちである。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代誌上 22:11; ピリピ人への手紙 4:13; エペソ人への手紙 5:14"> 金、銀、青銅、鉄は数えきれない。さあ、立って仕事に取りかかれ。主があなたとともにおられるように。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歴代誌上 28:1–6; ヨハネの手紙第三 1:8; 歴代誌上 29:6"> ダビデはまた、イスラエルのすべての指導者に、息子ソロモンを助けるよう命じて言った。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代誌上 22:9; 歴代誌上 23:25; サムエル記第二 7:1"> 「あなたがたの神、主はあなたがたとともにおられるではないか。主は四方に安息を与えてくださったではないか。主はこの地の住民を私の手に渡され、この地は主とその民の前に服している。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代誌上 28:9; 申命記 4:29; 歴代誌上 16:11"> 今、心と思いを尽くして、あなたがたの神、主を求めよ。立って主なる神の聖所を建て、主の契約の箱と神の聖なる器を、主の御名のために建てる家へ運び入れよ。」</span>
</div>

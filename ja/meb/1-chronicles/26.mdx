<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌 第二 23:19; 民数記 26:9–11; 詩篇 44:1"> 門衛の組分けは次のとおりである。コラ人では、アサフの子孫であるコレの子メシェレムヤ。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代誌上 9:21"> メシェレムヤの子らは、長男ゼカリヤ、次男エディアエル、三男ゼバドヤ、四男ヤテニエル、</span>
<span className="v" id="v3" data-v="3"> 五男エラム、六男エホハナン、七男エルエホエナイ。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌上 16:38; 歴代誌上 15:24; 歴代誌上 15:18"> オベド・エドムの子らは、長男シェマヤ、次男エホザバド、三男ヨア、四男サカル、五男ネタヌエル、</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 128:1"> 六男アミエル、七男イッサカル、八男ペウレタイ。神がオベド・エドムを祝福されたからである。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代誌上 12:28; テモテへの手紙第一 6:12; 士師記 6:12"> その子シェマヤにも息子たちが生まれ、父祖の家を治めた。彼らは勇敢な力ある者だったからである。</span>
<span className="v" id="v7" data-v="7"> シェマヤの子らは、オテニ、レファエル、オベド、エルザバド。また彼らの親族エリフとセマクヤも勇士であった。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第二の手紙 3:6; ペテロの手紙第一 4:11; コリント人への第一の手紙 12:4–11"> これらは皆オベド・エドムの子孫であり、彼らとその息子および兄弟たちは、奉仕に必要な力を備えた有能な者であった。オベド・エドムの子孫は六十二人。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代誌上 26:14; 歴代誌上 26:1"> メシェレムヤには、勇士である息子と兄弟が十八人いた。</span>
<span className="v" id="v10" data-v="10" data-xref="歴代誌上 16:38; 歴代誌上 5:1–2"> メラリの子孫ホサにも息子たちがいた。長はシムリであった。彼は長男ではなかったが、父が彼を長に任じたのである。</span>
<span className="v" id="v11" data-v="11"> 次男はヒルキヤ、三男はテバルヤ、四男はゼカリヤ。ホサの息子と兄弟は全部で十三人であった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="歴代誌上 25:8"> 以上が門衛の組分けである。これらの長たちも、兄弟たちと同じように、主の家で奉仕する務めを担った。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代誌上 25:8; 歴代誌上 24:31; 歴代誌上 24:5"> 彼らは父祖の家ごとに、年少者も年長者も同じように、各門の担当を決めるためくじを引いた。</span>
<span className="v" id="v14" data-v="14"> 東の門のくじはシェレムヤに当たった。次に、賢明な助言者であった息子ゼカリヤのためにくじを引くと、北の門が当たった。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代誌 第二 25:24; 歴代誌上 26:17"> オベド・エドムには南の門が、その息子たちには倉が当たった。</span>
<span className="v" id="v16" data-v="16" data-xref="ネヘミヤ記 12:24; 歴代誌上 26:10–12; 列王記第一 10:5"> シュピムとホサには、西の門と、上り坂にあるシャレケテの門が当たった。番所は互いに向かい合っていた。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代誌 第二 8:14; 歴代誌上 9:24"> 東にはレビ人が一日六人、北には一日四人、南には一日四人、倉には二人ずつ配置された。</span>
<span className="v" id="v18" data-v="18" data-xref="列王記第二 23:11"> 西側のパルバルでは、上り坂に四人、パルバルに二人が配置された。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 16:11"> 以上が、コラの子らとメラリの子らに属する門衛の組分けである。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="歴代誌上 26:22; 歴代誌上 28:12–19; 歴代誌上 22:14–16"> レビ人のうち、アヒヤは神の家の宝物庫と聖別された物の宝物庫を管理した。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代誌上 23:7; 歴代誌上 6:17; 歴代誌上 29:8"> ゲルション人ラダンの子ら、すなわちラダンに属する父祖の家のかしらは、エヒエリ人であった。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代誌上 23:8; ネヘミヤ記 10:38; 歴代誌上 26:20"> エヒエリの子らゼタムと、その兄弟ヨエルは、主の家の宝物庫を管理した。</span>
<span className="v" id="v23" data-v="23" data-xref="民数記 3:27; 歴代誌上 23:12; 民数記 3:19"> アムラム人、イツハル人、ヘブロン人、ウジエル人については、</span>
<span className="v" id="v24" data-v="24" data-xref="歴代誌上 24:20; 歴代誌上 23:15–16"> モーセの子ゲルショムの子シェブエルが、宝物庫の責任者であった。</span>
<span className="v" id="v25" data-v="25" data-xref="歴代誌上 23:17–18; 歴代誌上 23:15; 出エジプト記 18:4"> その親族は、エリエゼルから、その子レハブヤ、その子エシャヤ、その子ヨラム、その子ジクリ、その子シェロモテと続いた。</span>
<span className="v" id="v26" data-v="26" data-xref="サムエル記第二 8:11; 歴代誌上 29:2–9; 歴代誌上 22:14"> このシェロモテとその兄弟たちは、聖別された物のすべての宝物庫を管理した。それらはダビデ王、父祖の家のかしらたち、千人隊と百人隊の長たち、および軍の指揮官たちが聖別してささげたものであった。</span>
<span className="v" id="v27" data-v="27" data-xref="列王記第二 12:14; ヨシュア記 6:19; ネヘミヤ記 10:32–34"> 彼らは戦いで得た略奪品の一部を、主の家の修理のために聖別した。</span>
<span className="v" id="v28" data-v="28" data-xref="サムエル記第一 9:9; サムエル記第一 17:55; サムエル記第二 10:9–14"> また、先見者サムエル、キシュの子サウル、ネルの子アブネル、ツェルヤの子ヨアブが聖別したすべてのものも含まれていた。だれが何を聖別した場合でも、それはシェロモテとその兄弟たちの管理下に置かれた。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="歴代誌上 23:4; ネヘミヤ記 11:16; 歴代誌 第二 34:13"> イツハル人では、ケナンヤとその息子たちが、神殿の外におけるイスラエルの行政を担当し、役人と裁判官を務めた。</span>
<span className="v" id="v30" data-v="30" data-xref="歴代誌上 27:17; 歴代誌上 23:19; 歴代誌上 23:12"> ヘブロン人では、ハシャブヤとその兄弟たち、勇士千七百人が、ヨルダン川の西側にいるイスラエルを監督し、主に関するすべての務めと王の奉仕を担当した。</span>
<span className="v" id="v31" data-v="31" data-xref="歴代誌上 23:19; ヨシュア記 21:39; 歴代誌上 29:27"> ヘブロン人では、エリヤが父祖の家の系譜に従ってヘブロン人の長であった。ダビデの治世第四十年に彼らが調査され、ギルアデのヤゼルで勇士たちが見つかった。</span>
<span className="v" id="v32" data-v="32" data-xref="歴代誌 第二 19:11; 歴代誌上 12:37; 歴代誌上 23:24"> エリヤの親族である勇士二千七百人は父祖の家のかしらであった。ダビデ王は彼らを、ルベン人、ガド人、マナセの半部族の監督者とし、神に関するすべての事柄と王に関する事務を担当させた。</span>
</div>

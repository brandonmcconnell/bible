<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 32:28; 創世記 35:22–26; ヨハネの黙示録 7:5–8"> イスラエルの子らは次のとおりである。ルベン、シメオン、レビ、ユダ、イッサカル、ゼブルン、</span>
<span className="v" id="v2" data-v="2"> ダン、ヨセフ、ベニヤミン、ナフタリ、ガド、アシェル。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="創世記 38:2–10; 創世記 46:12; 民数記 26:19"> ユダの子らは、エル、オナン、シェラ。この三人は、カナン人の女であるシュアの娘が彼に産んだ。ユダの長子エルは主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="すべて大文字の「主」または「神」は、神の固有名（ヘブル語「יהוה」、通常「ヤハウェ」と発音される）の訳である。">a</a></sup>の目に悪しき者であったので、主は彼を殺された。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイ 1:3; 創世記 38:13–30; ネヘミヤ記 11:4"> 彼の嫁タマルは彼にペレツとゼラを産んだ。ユダの子は全部で五人であった。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 46:12; ルツ記 4:18; 民数記 26:21"> ペレツの子らは、ヘツロンとハムル。</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第一 4:31; ヨシュア記 7:17–18; ヨシュア記 7:1"> ゼラの子らは、ジムリ、エタン、ヘマン、カルコル、ダラ。全員で五人であった。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 6:18; 申命記 7:26; ヨシュア記 7:25"> カルミの子は、イスラエルを煩わせたアカルであった。彼は聖絶のものに関して罪を犯した。</span>
<span className="v" id="v8" data-v="8"> エタンの子は、アザルヤ。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歴代誌上 2:42; マタイ 1:3; ルツ記 4:19"> ヘツロンに生まれた子らは、エラフメエル、ラム、ケルバイ。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイ 1:4; 民数記 1:7; 民数記 2:3"> ラムはアミナダブをもうけ、アミナダブはユダの子らの君ナフションをもうけ、</span>
<span className="v" id="v11" data-v="11" data-xref="ルツ記 4:21; マタイ 1:4–5; ルカ 3:32"> ナフションはサルマをもうけ、サルマはボアズをもうけ、</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 15:12; 歴代誌上 10:14; イザヤ書 11:10"> ボアズはオベデをもうけ、オベデはエッサイをもうけた。</span>
<span className="v" id="v13" data-v="13" data-xref="サムエル記第一 17:13; サムエル記第一 17:28; 歴代誌上 20:7"> エッサイの子らは、長子エリアブ、次男アビナダブ、三男シメア、</span>
<span className="v" id="v14" data-v="14"> 四男ネタンエル、五男ラダイ、</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記第一 16:10–11; サムエル記第一 17:12–14"> 六男オツェム、七男ダビデ。</span>
<span className="v" id="v16" data-v="16" data-xref="サムエル記第一 26:6; サムエル記第二 3:39; サムエル記第二 2:18–23"> 彼らの姉妹はツェルヤとアビガイルであった。ツェルヤの子らは、アビシャイ、ヨアブ、アサエルの三人。</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記第二 17:25; 列王記第一 2:32; サムエル記第二 20:4–12"> アビガイルはアマサを産んだ。アマサの父はイシュマエル人エテルであった。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> ヘツロンの子カレブは、その妻アズバとエリオテによって子らをもうけた。アズバの子らは次のとおりである。エシェル、ショバブ、アルドン。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代誌上 2:50; 歴代誌上 2:24; 歴代誌上 4:4"> アズバが死ぬと、カレブはエフラテをめとった。彼女は彼にフルを産んだ。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 31:2; 出エジプト記 36:1–2; 出エジプト記 37:1"> フルはウリの父となり、ウリはベツァルエルの父となった。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数記 27:1; 申命記 3:15; 民数記 26:29"> その後、ヘツロンはギルアドの父マキルの娘を妻に迎えた。彼が彼女をめとったのは六十歳のときで、彼女はセグブを産んだ。</span>
<span className="v" id="v22" data-v="22" data-xref="ヨシュア記 13:30; 申命記 3:14; 民数記 32:41"> セグブはヤイルの父となった。ヤイルはギルアドの地に二十三の町を持っていた。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨシュア記 13:30; 申命記 3:14; 民数記 32:41–42"> しかしゲシュルとアラムが、彼らからヤイルの町々を、ケナテとその村々を含む六十の町を奪い取った。これらは皆、ギルアドの父マキルの子孫であった。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代誌上 4:5; 歴代誌上 2:9; サムエル記第一 30:14"> ヘツロンがカレブ・エフラタで死んだ後、妻アビヤは彼の子アシュフルを産んだ。アシュフルはテコアの父となった。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> ヘツロンの長子エラフメエルの子らは、長子ラム、ブナ、オレン、オツェム、アヒヤであった。</span>
<span className="v" id="v26" data-v="26"> エラフメエルにはもう一人の妻がおり、その名をアタラといった。彼女はオナムの母であった。</span>
<span className="v" id="v27" data-v="27"> エラフメエルの長子ラムの子らは、マアツ、ヤミン、エケルであった。</span>
<span className="v" id="v28" data-v="28"> オナムの子らは、シャマイとヤダ。シャマイの子らは、ナダブとアビシュル。</span>
<span className="v" id="v29" data-v="29"> アビシュルの妻の名はアビハイルといい、彼女は彼にアフバンとモリドを産んだ。</span>
<span className="v" id="v30" data-v="30"> ナダブの子らは、セレドとアパイム。セレドは子を持たずに死んだ。</span>
<span className="v" id="v31" data-v="31" data-xref="歴代誌上 2:34–35"> アパイムの子は、イシ。イシの子は、シェシャン。シェシャンの子は、アフライ。</span>
<span className="v" id="v32" data-v="32"> シャマイの兄弟ヤダの子らは、エテルとヨナタン。エテルは子を持たずに死んだ。</span>
<span className="v" id="v33" data-v="33"> ヨナタンの子らは、ペレテとザザ。以上がエラフメエルの子らである。</span>
<span className="v" id="v34" data-v="34"> シェシャンには息子がなく、娘だけがいた。シェシャンにはエジプト人のしもべがおり、その名をヤルハといった。</span>
<span className="v" id="v35" data-v="35"> シェシャンはその娘をしもべヤルハに妻として与えた。彼女は彼にアタイを産んだ。</span>
<span className="v" id="v36" data-v="36" data-xref="歴代誌上 11:41"> アタイはナタンの父となり、ナタンはザバドの父となり、</span>
<span className="v" id="v37" data-v="37"> ザバドはエフラルの父となり、エフラルはオベデの父となり、</span>
<span className="v" id="v38" data-v="38"> オベデはイエフの父となり、イエフはアザルヤの父となり、</span>
<span className="v" id="v39" data-v="39"> アザルヤはヘレツの父となり、ヘレツはエルアサの父となり、</span>
<span className="v" id="v40" data-v="40"> エルアサはシスマイの父となり、シスマイはシャルムの父となり、</span>
<span className="v" id="v41" data-v="41"> シャルムはエカムヤの父となり、エカムヤはエリシャマの父となった。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="歴代誌上 2:23–24; ヘブル人への手紙 12:23; ローマ人への手紙 8:29"> エラフメエルの兄弟カレブの子らは、長子でジフの父となったメシャと、ヘブロンの父マレシャの子らであった。</span>
<span className="v" id="v43" data-v="43"> ヘブロンの子らは、コラ、タプア、レケム、シェマ。</span>
<span className="v" id="v44" data-v="44"> シェマはヨルケアムの父ラハムの父となった。レケムはシャマイの父となった。</span>
<span className="v" id="v45" data-v="45" data-xref="ヨシュア記 15:58"> シャマイの子はマオンであった。マオンはベテ・ツルの父となった。</span>
<span className="v" id="v46" data-v="46" data-xref="歴代誌上 2:18–19; 歴代誌上 2:48"> カレブのそばめエパは、ハラン、モツァ、ガゼツを産んだ。ハランはガゼツの父となった。</span>
<span className="v" id="v47" data-v="47"> ヤフダイの子らは、レゲム、ヨタム、ゲシャン、ペレテ、エパ、シャアフ。</span>
<span className="v" id="v48" data-v="48" data-xref="創世記 25:5–6; 歴代誌上 2:46"> カレブのそばめマアカは、シェベルとティルハナを産んだ。</span>
<span className="v" id="v49" data-v="49" data-xref="ヨシュア記 15:31; 歴代誌上 2:42; イザヤ書 10:31"> 彼女はまた、マドマナの父シャアフ、マクベナの父でありギベアの父であるシェバを産んだ。カレブの娘はアクサであった。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="サムエル記第一 7:1; ヨシュア記 15:60; 歴代誌上 2:53"> 以上がカレブの子らである。エフラタの長子フルの子は、キルヤテ・エアルィムの父ショバル、</span>
<span className="v" id="v51" data-v="51" data-xref="歴代誌上 4:4; ヨハネ 7:42; マタイ 2:6"> ベツレヘムの父サルマ、ベテ・ガデルの父ハレフ。</span>
<span className="v" id="v52" data-v="52" data-xref="歴代誌上 4:2"> キルヤテ・エアルィムの父ショバルの子らは、ハロエとメヌホテ人の半数であった。</span>
<span className="v" id="v53" data-v="53" data-xref="サムエル記第二 23:38; 士師記 13:25; 士師記 13:2"> キルヤテ・エアルィムの諸氏族は、エテル人、プテ人、シュマテ人、ミシュラ人であった。ツォラ人とエシュタオル人は彼らから出た。</span>
<span className="v" id="v54" data-v="54" data-xref="ネヘミヤ記 7:26; エズラ記 2:22; ネヘミヤ記 12:28"> サルマの子らは、ベツレヘム、ネトファ人、アトロテ・ベテ・ヨアブ、そしてマナハテ人の半ばであるツォル人。</span>
<span className="v" id="v55" data-v="55" data-xref="列王記第二 10:15; 士師記 1:16; エレミヤ書 35:19"> ヤベツに住んでいた書記の諸氏族は、ティルアテ人、シムアテ人、スカテ人であった。これらはレカブの家の父であるハマトから出たケニ人である。</span>
</div>

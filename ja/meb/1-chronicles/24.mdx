<span className="v" id="v1" data-v="1" data-xref="歴代誌上 23:6; 出エジプト記 6:23; 民数記 26:60"> アロンの子らの組分けは次のとおりである。アロンの子らはナダブ、アビフ、エルアザル、イタマル。</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 10:2; 民数記 3:4; 民数記 26:61"> ナダブとアビフは父より先に、子を残さずに死んだので、エルアザルとイタマルが祭司として仕えた。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記第二 8:17; 歴代誌上 24:31; サムエル記第一 21:1"> ダビデは、エルアザルの子孫ツァドクおよびイタマルの子孫アヒメレクとともに、彼らを奉仕の任務に従って組に分けた。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌上 23:24; 民数記 25:11–13; 歴代誌上 15:6–12"> エルアザルの子らには、イタマルの子らよりも多くの父祖の家のかしらがいたので、次のように分けた。エルアザルの子らには父祖の家のかしらが十六人、イタマルの子らには父祖の家に従って八人いた。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代誌上 24:31; ヨシュア記 18:10; 使徒の働き 4:1"> 両者の中に聖所の長と神の長がいたので、くじを引き、分け隔てなく組に分けた。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代誌上 18:16; マタイ 8:19; ネヘミヤ記 8:1"> レビ人である書記、ネタヌエルの子シェマヤが、王、指導者たち、祭司ツァドク、アビヤタルの子アヒメレク、および祭司とレビ人の父祖の家のかしらたちの前で、その名を書き留めた。エルアザルのために一つの父祖の家を取り、次にイタマルのために一つを取った。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エズラ記 2:36; ネヘミヤ記 11:10; ネヘミヤ記 12:19"> 第一のくじはエホヤリブに、第二はエダヤに、</span>
<span className="v" id="v8" data-v="8" data-xref="エズラ記 2:39; ネヘミヤ記 7:35; ネヘミヤ記 12:15"> 第三はハリムに、第四はセオリムに、</span>
<span className="v" id="v9" data-v="9" data-xref="ネヘミヤ記 12:17"> 第五はマルキヤに、第六はミヤミンに、</span>
<span className="v" id="v10" data-v="10" data-xref="ルカ 1:5; ネヘミヤ記 12:4; ネヘミヤ記 12:17"> 第七はハコツに、第八はアビヤに、</span>
<span className="v" id="v11" data-v="11" data-xref="エズラ記 2:36; ネヘミヤ記 12:10; ネヘミヤ記 7:39"> 第九はエシュアに、第十はシェカンヤに、</span>
<span className="v" id="v12" data-v="12" data-xref="ネヘミヤ記 12:10"> 第十一はエルヤシブに、第十二はヤキムに、</span>
<span className="v" id="v13" data-v="13"> 第十三はフパに、第十四はエシェブアブに、</span>
<span className="v" id="v14" data-v="14" data-xref="ネヘミヤ記 7:40; エズラ記 2:37; エズラ記 10:20"> 第十五はビルガに、第十六はイメルに、</span>
<span className="v" id="v15" data-v="15"> 第十七はヘジルに、第十八はハピツェツに、</span>
<span className="v" id="v16" data-v="16"> 第十九はペタフヤに、第二十はエヘズケルに、</span>
<span className="v" id="v17" data-v="17"> 第二十一はヤキンに、第二十二はガムルに、</span>
<span className="v" id="v18" data-v="18"> 第二十三はデラヤに、第二十四はマアズヤに当たった。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代誌上 9:25; コリント人への第一の手紙 14:40; ヘブル人への手紙 7:11"> これが彼らの奉仕の順序であった。彼らの父祖アロンに与えられた定めに従い、イスラエルの神、主がアロンに命じられたとおり、主の家に入って仕えた。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="歴代誌上 26:24; 歴代誌上 23:16; 歴代誌上 6:18"> 残りのレビの子らについては、アムラムの子らではシュバエル、シュバエルの子らではエフデヤ。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代誌上 23:17; 歴代誌上 26:25"> レハブヤについては、レハブヤの子らのうちイシヤがかしらであった。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代誌上 23:18; 民数記 3:27; 民数記 3:19"> イツハル人ではシェロモテ、シェロモテの子らではヤハテ。</span>
<span className="v" id="v23" data-v="23" data-xref="歴代誌上 23:19; 歴代誌上 26:31"> ヘブロンの子らは、エリヤ、次男アマルヤ、三男ヤハジエル、四男エカムアム。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代誌上 23:20"> ウジエルの子はミカ、ミカの子らではシャミル。</span>
<span className="v" id="v25" data-v="25" data-xref="歴代誌上 15:20; 歴代誌上 15:18; 歴代誌上 23:20"> ミカの兄弟はイシヤ、イシヤの子らではゼカリヤ。</span>
<span className="v" id="v26" data-v="26" data-xref="歴代誌上 23:21"> メラリの子らはマフリとムシ。ヤアズヤの子はベノ。</span>
<span className="v" id="v27" data-v="27" data-xref="民数記 3:20; 歴代誌上 23:21; 歴代誌上 6:19"> ヤアズヤを通して生まれたメラリの子らは、ベノ、ショハム、ザクル、イブリ。</span>
<span className="v" id="v28" data-v="28" data-xref="歴代誌上 23:22"> マフリからはエルアザル。彼には息子がいなかった。</span>
<span className="v" id="v29" data-v="29"> キシュについては、キシュの子エラフメエル。</span>
<span className="v" id="v30" data-v="30" data-xref="歴代誌上 23:23; 歴代誌上 6:47"> ムシの子らはマフリ、エデル、エリモテ。以上が父祖の家ごとのレビの子らである。</span>
<span className="v" id="v31" data-v="31" data-xref="歴代誌上 24:5–6; 歴代誌上 26:13; 歴代誌上 25:8"> 彼らもまた、兄弟であるアロンの子らと同じように、ダビデ王、ツァドク、アヒメレク、および祭司とレビ人の父祖の家のかしらたちの前でくじを引いた。かしらの父祖の家も、その弟の父祖の家も同じように扱われた。</span>

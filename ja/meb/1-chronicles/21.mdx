<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="1CH" data-book-slug="1-chronicles" data-book-name="歴代誌上" data-chapter="21" data-verses="30">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記第二 24:1–25; ゼカリヤ書 3:1; ヨブ記 2:4–6"> サタンがイスラエルに立ち向かい、イスラエルの人口を数えるようダビデをそそのかした。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代誌上 27:23–24; サムエル記第二 3:10; サムエル記第二 24:15"> ダビデはヨアブと民の指導者たちに言った。「行って、ベエル・シェバからダンに至るまでイスラエルを数え、その数を私に報告せよ。私がそれを知るためだ。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命記 1:11; イザヤ書 26:15; 歴代誌上 19:13"> ヨアブは言った。「主が御自分の民を今の百倍にも増してくださいますように。王、わが主よ、彼らは皆、わが主のしもべではありませんか。なぜわが主はこのことをお求めになるのですか。なぜイスラエルに罪責を負わせるのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 5:29; 出エジプト記 1:17; ダニエル書 3:18"> それでも王の命令がヨアブを押し切った。ヨアブは出て行き、全イスラエルを巡ってからエルサレムに戻った。</span>
<span className="v" id="v5" data-v="5" data-xref="サムエル記第二 24:9; 歴代誌上 27:23"> ヨアブは民の登録人数をダビデに報告した。イスラエル全体で剣を扱える者が百十万人、ユダには剣を扱える者が四十七万人いた。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代誌上 27:24; 民数記 1:47–49; サムエル記第二 20:9–10"> しかしレビとベニヤミンはその中に数えなかった。王の命令がヨアブには忌まわしいものだったからである。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王記第一 15:5; ヨシュア記 7:5; サムエル記第二 21:14"> 神はこのことを悪と見られ、イスラエルを打たれた。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記第二 12:13; ヨハネの手紙第一 1:9; 創世記 34:7"> ダビデは神に言った。「私はこのことをして、大きな罪を犯しました。どうか今、あなたのしもべの咎を取り除いてください。私は非常に愚かなことをしました。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="サムエル記第一 9:9; サムエル記第二 24:11; 歴代誌上 29:29"> 主はダビデの先見者ガドに告げられた。</span>
<span className="v" id="v10" data-v="10" data-xref="列王記第一 13:21–22; ヨハネの黙示録 3:19; 箴言 1:29–31"> 「行ってダビデに告げよ。『主はこう言われる。わたしは三つのことをあなたに示す。その一つを選べ。わたしはそれをあなたに行う。』」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="箴言 19:20"> ガドはダビデのもとに来て言った。「主はこう言われます。『あなたが選びなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="申命記 28:27; 使徒の働き 12:23; エゼキエル書 14:19–21"> 三年間の飢饉か、三か月間、敵の前で敗れ続けて敵の剣に追い迫られることか、あるいは三日間、主の剣、すなわち国中に疫病が臨み、主の使いがイスラエルの全領域で滅ぼすことか。今、私を遣わされた方に何と答えるべきか、よく考えてください。』」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 130:7; イザヤ書 55:7; ピリピ人への手紙 1:23"> ダビデはガドに言った。「私は深い苦しみの中にいる。どうか主の御手に陥らせてほしい。主の憐れみは非常に大きいからだ。人の手には陥らせないでほしい。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 12:30; 歴代誌上 27:24; 列王記第二 19:35"> そこで主はイスラエルに疫病を送り、イスラエル人七万人が倒れた。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 6:6; 出エジプト記 32:14; エレミヤ書 26:18"> 神はエルサレムを滅ぼすために御使いを遣わされた。しかし御使いが滅ぼそうとしていたとき、主はそれを御覧になり、災いを思い直して、滅ぼす御使いに言われた。「もう十分だ。今、手を引け。」主の使いはエブス人オルナンの打ち場のそばに立っていた。</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 14:5; 列王記第一 21:27; 列王記第二 6:17"> ダビデが目を上げると、主の使いが地と天の間に立ち、抜いた剣を手にしてエルサレムの上に差し伸べているのが見えた。<br />ダビデと長老たちは粗布をまとい、ひれ伏した。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 16:63; サムエル記第二 24:17; ヨハネ 10:11–12"> ダビデは神に言った。「民を数えるよう命じたのは私ではありませんか。罪を犯し、大きな悪を行ったのはこの私です。しかし、この羊たちが何をしたというのでしょう。主、わが神よ、どうか御手を私と私の父の家に下してください。あなたの民を疫病に渡さないでください。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歴代誌 第二 3:1; サムエル記第二 24:18; 歴代誌上 21:11"> そのとき主の使いはガドに命じ、ダビデが上って行き、エブス人オルナンの打ち場に主のための祭壇を築くよう告げさせた。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒の働き 9:6; ヨハネ 2:5; 列王記第二 5:10–14"> ダビデは、ガドが主の御名によって語った言葉に従って上って行った。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="士師記 6:11"> オルナンが振り返ると、御使いが見えた。彼と一緒にいた四人の息子は身を隠した。オルナンは小麦を打っているところであった。</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記第一 25:23; サムエル記第二 24:18–20"> ダビデがオルナンのところへ来ると、オルナンはダビデを見て打ち場から出て行き、地に顔を伏せてダビデに礼をした。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="サムエル記第二 24:21; 列王記第一 21:2; 民数記 25:8"> ダビデはオルナンに言った。「この打ち場の場所を私に譲ってほしい。ここに主のための祭壇を築き、民に臨んだ災いを止めたい。十分な代価を払うから、私に譲ってほしい。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="サムエル記第二 24:22–23; サムエル記第一 6:14; 創世記 23:4–6"> オルナンはダビデに言った。「どうぞお取りください。王、わが主が御心にかなうことをなさいますように。御覧ください。全焼のいけにえには牛を、薪には脱穀用の道具を、穀物のささげ物には小麦を差し上げます。すべて差し上げます。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="申命記 16:16–17; 創世記 14:23; 創世記 23:13"> しかしダビデ王はオルナンに言った。「いや、私は必ず十分な代価を払って買う。あなたのものを主のために取ったり、代価を払わずに全焼のいけにえをささげたりはしない。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="サムエル記第二 24:24–25"> そこでダビデは、その場所の代価として、重さ六百シェケル<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一シェケルは約十グラム、または約〇・三二トロイオンス。六百シェケルは約六キログラム、または約百九十二トロイオンスに相当する。">a</a></sup>の金をオルナンに渡した。</span>
<span className="v" id="v26" data-v="26" data-xref="レビ記 9:24; 士師記 6:21; 箴言 15:8"> ダビデはそこに主のための祭壇を築き、全焼のいけにえと和解のいけにえをささげ、主を呼び求めた。すると主は天から火を下し、全焼のいけにえの祭壇の上で彼に答えられた。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ヨハネ 18:11; 詩篇 103:20; 歴代誌上 21:15–16"> 主が御使いに命じられると、御使いは剣をさやに納めた。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> そのときダビデは、主がエブス人オルナンの打ち場で自分に答えられたのを見て、そこでいけにえをささげた。</span>
<span className="v" id="v29" data-v="29" data-xref="歴代誌上 16:39; 歴代誌 第二 1:3; 歴代誌 第二 1:13"> モーセが荒野で造った主の幕屋と全焼のいけにえの祭壇は、そのころギベオンの高き所にあった。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨハネの黙示録 1:17; ヘブル人への手紙 12:28–29; ヨハネの黙示録 15:4"> しかしダビデは、主の使いの剣を恐れていたので、神を求めるためにその前へ行くことができなかった。</span>
</div>
</div>

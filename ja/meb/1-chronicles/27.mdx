<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王記第一 4:27; 歴代誌 第二 26:11–13; 申命記 1:15"> イスラエルの子らのうち、父祖の家のかしら、千人隊と百人隊の長、および彼らに属する役人たちは、年間を通じて月ごとに交替し、各組に分かれて王に仕えた。各組は二万四千人であった。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="歴代誌上 11:11; サムエル記第二 23:8"> 第一の月の第一組を率いたのは、ザブディエルの子ヤショブアムで、その組は二万四千人であった。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 26:20; 民数記 10:14; 創世記 49:8–10"> 彼はペレツの子孫で、第一の月に仕える軍のすべての隊長の長であった。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記第二 23:9; 歴代誌上 11:12"> 第二の月の組を率いたのはアホア人ドダイで、その組には指揮官ミクロテがいた。その組は二万四千人であった。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代誌上 18:17; 列王記第一 4:4–5"> 第三の月の第三の軍団長は、大祭司エホヤダの子ベナヤで、その組は二万四千人であった。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記第二 23:20–23; 歴代誌上 11:22–25; サムエル記第二 22:20–23"> このベナヤは三十人の勇士の一人で、その三十人を率いた者である。彼の子アミザバドがその組に属していた。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌上 11:26; サムエル記第二 23:24; サムエル記第二 2:18–23"> 第四の月の第四の隊長はヨアブの兄弟アサエルで、後にはその子ゼバドヤが務めた。その組は二万四千人であった。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代誌上 11:27; サムエル記第二 23:25; 歴代誌上 26:29"> 第五の月の第五の隊長はイズラ人シャムフテで、その組は二万四千人であった。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代誌上 11:28; サムエル記第二 23:26"> 第六の月の第六の隊長はテコア人イケシュの子イラで、その組は二万四千人であった。</span>
<span className="v" id="v10" data-v="10" data-xref="歴代誌上 11:27; サムエル記第二 23:26"> 第七の月の第七の隊長はエフライムの子孫であるペロニ人ヘレツで、その組は二万四千人であった。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記第二 21:18; 歴代誌上 11:29; 民数記 26:20"> 第八の月の第八の隊長はゼラ人に属するフシャ人シブカイで、その組は二万四千人であった。</span>
<span className="v" id="v12" data-v="12" data-xref="歴代誌上 11:28; サムエル記第二 23:27"> 第九の月の第九の隊長はベニヤミン人に属するアナトテ人アビエゼルで、その組は二万四千人であった。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代誌上 11:30; サムエル記第二 23:28"> 第十の月の第十の隊長はゼラ人に属するネトファ人マハライで、その組は二万四千人であった。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代誌上 11:31; サムエル記第二 23:30"> 第十一の月の第十一の隊長はエフライムの子孫であるピルアトン人ベナヤで、その組は二万四千人であった。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記第二 23:29; 歴代誌上 4:13; 士師記 3:9"> 第十二の月の第十二の隊長はオテニエルの子孫であるネトファ人ヘルダイで、その組は二万四千人であった。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> イスラエルの各部族を治めた者は次のとおりである。ルベン人ではジクリの子エリエゼル、シメオン人ではマアカの子シェファテヤ、</span>
<span className="v" id="v17" data-v="17" data-xref="歴代誌上 26:30; 歴代誌上 24:31; 歴代誌上 12:27–28"> レビではケムエルの子ハシャブヤ、アロンの家ではツァドク、</span>
<span className="v" id="v18" data-v="18" data-xref="サムエル記第一 16:6; サムエル記第一 17:29; サムエル記第一 17:13"> ユダではダビデの兄弟の一人エリフ、イッサカルではミカエルの子オムリ、</span>
<span className="v" id="v19" data-v="19"> ゼブルンではオバデヤの子イシュマヤ、ナフタリではアズリエルの子エリモテ、</span>
<span className="v" id="v20" data-v="20"> エフライムの子らではアザズヤの子ホシェア、マナセの半部族ではペダヤの子ヨエル、</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記第二 3:27; サムエル記第一 14:50–51; サムエル記第二 3:37"> ギルアデにいるマナセの半部族ではゼカリヤの子イド、ベニヤミンではアブネルの子ヤアシエル、</span>
<span className="v" id="v22" data-v="22" data-xref="歴代誌上 28:1"> ダンではエロハムの子アザルエル。以上がイスラエルの部族の長たちであった。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 15:5; 歴代誌上 21:2–5; ヘブル人への手紙 11:12"> ダビデは二十歳以下の者を数に入れなかった。主がイスラエルを天の星のように増やすと語られたからである。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代誌上 21:1–17; サムエル記第二 24:1–15"> ツェルヤの子ヨアブは人口を数え始めたが、終えることができなかった。この人口調査のために御怒りがイスラエルに臨んだからである。その数はダビデ王の年代記の記録には載せられなかった。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="歴代誌 第二 16:2; 出エジプト記 1:11; 歴代誌 第二 26:10"> 王の宝物庫を管理したのはアディエルの子アズマベテ。野、町、村、塔にある倉を管理したのはウジヤの子ヨナタン。</span>
<span className="v" id="v26" data-v="26"> 土地を耕す農夫たちを管理したのはケルブの子エズリ。</span>
<span className="v" id="v27" data-v="27"> ぶどう畑を管理したのはラマ人シムイ。ぶどう畑の収穫をぶどう酒の倉に納める責任者はシフム人ザブディ。</span>
<span className="v" id="v28" data-v="28" data-xref="列王記第一 10:27; 歴代誌 第二 1:15; 列王記第一 4:7"> 低地にあるオリーブといちじく桑を管理したのはゲデル人バアル・ハナン。油の倉を管理したのはヨアシュ。</span>
<span className="v" id="v29" data-v="29" data-xref="歴代誌上 5:16; イザヤ書 65:10"> シャロンで草を食む牛の群れを管理したのはシャロン人シトライ。谷にいる牛の群れを管理したのはアドライの子シャファテ。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 47:6; ヨブ記 1:3"> らくだを管理したのはイシュマエル人オビル。ろばを管理したのはメロノテ人エフデヤ。羊の群れを管理したのはハガル人ヤジズ。</span>
<span className="v" id="v31" data-v="31" data-xref="歴代誌上 5:10"> 以上がダビデ王の財産を管理した者たちであった。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="サムエル記第二 21:21; サムエル記第二 13:3; 歴代誌上 11:11"> ダビデのおじヨナタンは助言者で、理解力のある書記官であった。ハクモニの子エヒエルは王の子らの世話をした。</span>
<span className="v" id="v33" data-v="33" data-xref="サムエル記第二 15:12; サムエル記第二 15:37; サムエル記第二 15:32"> アヒトフェルは王の助言者、アルキ人フシャイは王の友であった。</span>
<span className="v" id="v34" data-v="34" data-xref="歴代誌上 11:6; 列王記第一 1:7; 歴代誌上 27:5"> アヒトフェルの後にはベナヤの子エホヤダとアビヤタルが助言者となった。ヨアブは王の軍の司令官であった。</span>
</div>

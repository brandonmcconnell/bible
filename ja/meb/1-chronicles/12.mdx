<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記第一 27:2–6; 歴代誌上 11:24–25; 歴代誌上 8:33"> ダビデがキシュの子サウルを避けて身を隠していたころ、ツィクラグで彼のもとに加わった者たちは次のとおりである。彼らは戦いで彼を助けた勇士たちの中にいた。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 3:15; 士師記 20:16; サムエル記第一 17:49"> 彼らは弓で武装し、石を投げるにも弓で矢を射るにも、右手も左手も使うことができた。彼らはベニヤミン出身で、サウルの同族であった。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代誌上 11:28; サムエル記第二 21:6; 歴代誌上 11:33"> 長はアヒエゼル。次にギブア人シェマアの子ヨアシュ、アズマベテの子エジエルとペレテ、ベラカ、アナトテ人イエフ、</span>
<span className="v" id="v4" data-v="4" data-xref="ヨシュア記 9:3; ヨシュア記 15:36; 歴代誌上 11:15"> 三十人の中の勇士であり三十人を率いていたギベオン人イシュマヤ、エレミヤ、ヤハジエル、ヨハナン、ゲデラ人ヨザバド、</span>
<span className="v" id="v5" data-v="5"> エルザイ、エリモテ、ベアルヤ、シェマルヤ、ハルフ人シェファティヤ、</span>
<span className="v" id="v6" data-v="6"> コラ人であるエルカナ、イシヤ、アザレル、ヨエゼル、ヤショブアム、</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 15:58; 歴代誌上 4:18; 歴代誌上 4:39"> ゲドルのエロハムの子であるヨエラとゼバデヤ。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記第二 2:18; サムエル記第二 17:10; サムエル記第二 23:20"> ガド人の中からも、勇士で戦いの訓練を受け、盾と槍を扱う軍人たちが、荒野の要害にいるダビデのもとへ加わった。その顔は獅子のようで、山を駆けるかもしかのように素早かった。</span>
<span className="v" id="v9" data-v="9"> 長はエツェル、二番目はオバデヤ、三番目はエリアブ、</span>
<span className="v" id="v10" data-v="10"> 四番目はミシュマナ、五番目はエレミヤ、</span>
<span className="v" id="v11" data-v="11"> 六番目はアタイ、七番目はエリエル、</span>
<span className="v" id="v12" data-v="12"> 八番目はヨハナン、九番目はエルザバド、</span>
<span className="v" id="v13" data-v="13"> 十番目はエレミヤ、十一番目はマクバナイ。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 32:30; レビ記 26:8"> これらはガドの子らで、軍隊の長であった。最も弱い者でも百人に匹敵し、最も強い者は千人に匹敵した。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 3:15; ヨシュア記 4:18; エレミヤ書 49:19"> これらは、第一の月にヨルダン川がすべての岸に溢れていたとき、それを渡り、谷に住むすべての人々を東にも西にも敗走させた者たちである。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> ベニヤミンの子らとユダの子らの中からも、要害にいるダビデのところに来る者たちがいた。</span>
<span className="v" id="v17" data-v="17" data-xref="ペテロの手紙第一 2:23; ユダ 1:9; コリント人への第二の手紙 13:11"> ダビデは彼らを迎えるために出て行き、彼らに答えて言った。「もしあなたがたが、私を助けるために平和な思いで私のもとに来たのなら、私の心はあなたがたと一つに結ばれる。しかし、私の手に不法なことがないのに、あなたがたが私を敵に裏切るために来たのなら、私たちの父祖の神がそれを見て、お叱りになるように。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="士師記 6:34; 士師記 3:10; サムエル記第二 17:25"> そのとき、三十人の長であるアマサイに霊が臨み、彼は言った。<br /><span className="pl pl-1">「ダビデよ、私たちはあなたのもの。</span><br /><span className="pl pl-2">エッサイの子よ、私たちはあなたとともにいる。</span><br /><span className="pl pl-1">平安あれ、平安あれ、あなたに。</span><br /><span className="pl pl-2">あなたを助ける者にも平安あれ。</span><br /><span className="pl pl-2">あなたの神があなたを助けておられる。」</span><br />そこでダビデは彼らを受け入れ、彼らを軍隊の長たちとした。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="サムエル記第一 29:2–9"> マナセの中からも、ダビデのもとに加わる者たちがいた。それは、彼がペリシテ人とともにサウルと戦うために行ったときである。しかし彼らはペリシテ人を助けなかった。ペリシテ人の領主たちが協議の末、「彼は私たちの首を代償にして、主人サウルのもとへ寝返るだろう」と言って、彼を送り去ったからである。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 33:17; 申命記 1:15; サムエル記第一 29:11"> 彼がツィクラグへ行ったとき、マナセから彼のもとに加わった者たちは、マナセの千人の長であったアドナフ、ヨザバド、エディアエル、ミカエル、ヨザバド、エリフ、ツィルタイであった。</span>
<span className="v" id="v21" data-v="21" data-xref="サムエル記第一 30:1–17; 歴代誌上 12:20; 歴代誌上 5:24"> 彼らはダビデを助けて略奪隊に立ち向かった。彼らは皆、力ある勇士であり、軍隊の長となったからである。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記第二 3:1; ヨブ記 17:9; 創世記 32:2"> そのころ、日々ダビデを助けるために人々が彼のもとに来たので、神の軍隊のような大軍団となった。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="サムエル記第二 2:3–4; 歴代誌上 11:10; サムエル記第一 16:1"> 主の言葉に従って、サウルの王権をダビデに移すため、ヘブロンにいるダビデのもとに来た、戦いの装備をした部隊の長たちの数は次のとおりである。</span>
<span className="v" id="v24" data-v="24"> ユダの子らで盾と槍を携えていた者は、戦いの装備をした者が六千八百人。</span>
<span className="v" id="v25" data-v="25"> シメオンの子らのうち、戦いのための力ある勇士が七千百人。</span>
<span className="v" id="v26" data-v="26"> レビの子らのうち、四千六百人。</span>
<span className="v" id="v27" data-v="27" data-xref="列王記第二 11:9; 列王記第二 25:18; 歴代誌上 6:49–57"> エホヤダはアロンの家の君であり、彼とともに三千七百人がいた。</span>
<span className="v" id="v28" data-v="28" data-xref="サムエル記第二 8:17; 歴代誌上 6:8; 歴代誌上 6:53"> 若い力ある勇士ツァドクと、その父祖の家の長たち二十二人。</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記第二 2:8–9; 歴代誌上 12:2; 創世記 31:23"> ベニヤミンの子らでサウルの同族は、三千人。それまで彼らの大部分はサウルの家に忠誠を尽くしていたからである。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 6:4"> エフライムの子らのうち、力ある勇士であり、その父祖の家で名のある者が二万八百人。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨシュア記 17:1–18"> マナセの半部族のうち、名前を指定されて、ダビデを王とするために来た者が一万八千人。</span>
<span className="v" id="v32" data-v="32" data-xref="エペソ人への手紙 5:17; ルカ 12:56–57; エステル記 1:13"> イッサカルの子らのうち、時勢をわきまえ、イスラエルが何をすべきかを知っていた者たち。その長は二百人であり、すべての兄弟たちは彼らの命令に従った。</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 12:2; ヨハネ 1:47"> ゼブルンのうち、軍隊として出陣でき、あらゆる戦いの武器を身に着けて隊列を組むことができ、忠誠に二心のない者が五万人。</span>
<span className="v" id="v34" data-v="34"> ナフタリのうち、千人の長たちと、彼らとともに盾と槍を携えた者が三万七千人。</span>
<span className="v" id="v35" data-v="35"> ダン人のうち、戦いのために隊列を組むことができる者が二万八千六百人。</span>
<span className="v" id="v36" data-v="36" data-xref="歴代誌上 12:33; ヨエル書 2:7"> アシェルのうち、軍隊として出陣して隊列を組むことができる者が四万人。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨシュア記 14:3; 申命記 3:12–16; ヨシュア記 13:7–32"> ヨルダン川の向こう側にあるルベン人、ガド人、およびマナセの半部族のうち、あらゆる戦いのためのすべての武器を身に着けていた者が十二万人。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="創世記 49:8–10; 列王記第一 8:61; 詩篇 101:2"> 隊列を組むことができるこれらすべての戦士たちは、ダビデを全イスラエルの王とするために、全き心をもってヘブロンにやって来た。イスラエルの残りの者も皆、ダビデを王とすることで心を一つにしていた。</span>
<span className="v" id="v39" data-v="39" data-xref="創世記 31:54; サムエル記第二 19:42; 創世記 26:30"> 彼らはそこでダビデとともに三日間過ごし、食べたり飲んだりした。彼らの兄弟たちが彼らのために備えていたからである。</span>
<span className="v" id="v40" data-v="40" data-xref="サムエル記第一 25:18; サムエル記第二 16:1; エレミヤ書 23:5–6"> さらに、彼らに近い者たちから、イッサカル、ゼブルン、ナフタリに至るまでもが、ろば、らくだ、騾馬、牛に食物を載せて持って来た。すなわち、小麦粉、いちじくの菓子、干しぶどう、ぶどう酒、油、それに牛と羊を豊かに持って来た。イスラエルの中に喜びがあったからである。</span>
</div>

<span className="v" id="v2" data-v="2" data-xref="創世記 47:10; 創世記 14:19; レビ記 1:3"> ダビデは全焼のいけにえと和解のいけにえをささげ終えると、主の御名によって民を祝福した。</span>
<span className="v" id="v3" data-v="3" data-xref="ネヘミヤ記 8:10; エゼキエル書 45:17; 歴代誌 第二 35:7–8"> 彼はイスラエルのすべての人に、男にも女にも、それぞれパンの塊、肉の切れ、干しぶどうの菓子を分け与えた。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌上 23:27–32; 詩篇 72:18; 詩篇 103:2"> 彼はレビ人のうちのある者を任命して、主の箱の前で仕えさせ、イスラエルの神、主を覚え、感謝し、賛美するようにした。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代誌上 6:39; 歴代誌 第二 29:25; 歴代誌上 15:16–24"> 長はアサフ、二番目はゼカリヤ、次にエイエル、シェミラモテ、エヒエル、マティティヤ、エリアブ、ベナヤ、オベド・エドム、エイエルであり、彼らは琴と竪琴を奏でた。アサフはシンバルを高らかに鳴らした。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代誌 第二 13:12; 歴代誌 第二 29:26–28; 歴代誌 第二 5:12–13"> 祭司ベナヤとヤハジエルは、神の契約の箱の前で絶えずラッパを吹き鳴らした。</span>

<span className="v" id="v9" data-v="9" data-xref="コロサイ人への手紙 3:16; 詩篇 96:1–3; 詩篇 98:1–4"> <span className="pl pl-1">主に向かって歌え。主に向かってほめ歌を歌え。</span><br /><span className="pl pl-2">そのすべての驚くべきみわざを語り伝えよ。</span></span>
<span className="v" id="v10" data-v="10" data-xref="マタイ 7:7–8; エレミヤ書 29:13; 詩篇 34:2"> <span className="pl pl-1">その聖なる御名を誇りとせよ。</span><br /><span className="pl pl-2">主を尋ね求める者たちの心は喜べ。</span></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 27:8–9; ゼパニヤ書 2:2–3; 詩篇 68:35"> <span className="pl pl-1">主とその御力を尋ね求めよ。</span><br /><span className="pl pl-2">絶えずその御顔を慕い求めよ。</span></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 111:4; 詩篇 119:20; 詩篇 103:2"> <span className="pl pl-1">主が行われた驚くべきみわざを思い起こせ。</span><br /><span className="pl pl-2">その奇跡と、御口のさばきを。</span></span>
<span className="v" id="v13" data-v="13" data-xref="ペテロの手紙第一 2:9; 出エジプト記 19:5–6; 詩篇 135:4"> <span className="pl pl-1">主のしもべイスラエルの子孫</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「種」。">a</a></sup><br /><span className="pl pl-1">よ、</span><br /><span className="pl pl-2">選ばれた者、ヤコブの子らよ。</span></span>

<div className="bp poetry">

<span className="v" id="v15" data-v="15" data-xref="詩篇 105:8; マラキ書 4:4; 申命記 7:9"> <span className="pl pl-1">主の契約をとこしえに思い起こせ。</span><br /><span className="pl pl-2">千代にわたって命じられた御言葉を。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="創世記 26:3; 創世記 17:2; 創世記 35:11"> <span className="pl pl-2">それはアブラハムと結ばれた契約、</span><br /><span className="pl pl-2">イサクへの誓い。</span></span>
<span className="v" id="v17" data-v="17" data-xref="創世記 17:7–8; 創世記 35:11–12; ヨシュア記 24:11–13"> <span className="pl pl-1">主はそれをヤコブのための掟とし、</span><br /><span className="pl pl-2">イスラエルへの永遠の契約とされた。</span></span>
<span className="v" id="v18" data-v="18" data-xref="創世記 13:15; ミカ書 2:5; 創世記 17:8"> <span className="pl pl-1">こう言われた。「私はあなたにカナンの地を与える。</span><br /><span className="pl pl-2">それはあなたがたが受け継ぐ割り当ての地である。」</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="創世記 34:30; 申命記 7:7; 使徒の働き 7:5"> <span className="pl pl-2">そのとき、あなたがたの人数は少なく、</span><br /><span className="pl pl-2">実にわずかで、そこでは寄留者であった。</span></span>
<span className="v" id="v20" data-v="20" data-xref="創世記 46:6; 創世記 20:1; 創世記 46:3"> <span className="pl pl-1">彼らは国から国へ、</span><br /><span className="pl pl-2">一つの王国から別の民へと渡り歩いた。</span></span>
<span className="v" id="v21" data-v="21" data-xref="創世記 12:17; 創世記 20:3; 出エジプト記 7:15–18"> <span className="pl pl-1">主はだれにも彼らをしいたげることを許さず、</span><br /><span className="pl pl-2">彼らのために王たちを戒められた。</span></span>
<span className="v" id="v22" data-v="22" data-xref="創世記 20:7; 詩篇 105:15; 創世記 49:8–10"> <span className="pl pl-1">「私に油注がれた者たちに触れるな。</span><br /><span className="pl pl-2">私の預言者たちに危害を加えるな。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="詩篇 96:1–13; 詩篇 71:15; イザヤ書 51:6–8"> <span className="pl pl-1">全地よ、主に向かって歌え。</span><br /><span className="pl pl-2">日から日へと、その救いを告げ知らせよ。</span></span>
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 12:2–6; ダニエル書 4:1–3; 詩篇 22:27"> <span className="pl pl-1">国々の間でその栄光を語り伝え、</span><br /><span className="pl pl-2">すべての民の間でその驚くべきみわざを語り伝えよ。</span></span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 89:7; 詩篇 76:7; 詩篇 66:3–5"> <span className="pl pl-1">主は大いなる方、大いに賛美されるべき方。</span><br /><span className="pl pl-2">すべての神々にまさって畏れられる方。</span></span>
<span className="v" id="v26" data-v="26" data-xref="詩篇 102:25; レビ記 19:4; イザヤ書 42:5"> <span className="pl pl-1">国々の民の神々はすべて偶像であるが、</span><br /><span className="pl pl-2">主は天を造られた。</span></span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 16:11; 詩篇 96:6; 詩篇 28:7–8"> <span className="pl pl-1">誉れと威厳はその御前にあり、</span><br /><span className="pl pl-2">力と喜びはその御住まいにある。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="コリント人への第一の手紙 15:10; ピリピ人への手紙 4:13; 詩篇 100:1–2"> <span className="pl pl-1">国々の民の諸氏族よ、主に帰せよ。</span><br /><span className="pl pl-2">栄光と力を主に帰せよ。</span></span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 100:4; 詩篇 96:9; イザヤ書 6:3"> <span className="pl pl-1">御名にふさわしい栄光を主に帰せよ。</span><br /><span className="pl pl-2">ささげ物を携えて、その御前に進み出よ。</span><br /><span className="pl pl-2">聖なる装いをして、主を礼拝せよ。</span></span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 33:9; 詩篇 148:5–6; ヘブル人への手紙 1:3"> <span className="pl pl-1">全地よ、その御前に打ち震えよ。</span><br /><span className="pl pl-2">世界は堅く据えられ、揺らぐことはない。</span></span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 96:10; ヨハネの黙示録 19:6; 詩篇 97:1"> <span className="pl pl-1">天は喜び、</span><br /><span className="pl pl-2">地は楽しめ。</span><br /><span className="pl pl-2">国々の間で言え。「主は王として治める」と。</span></span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 148:9–10; イザヤ書 44:23; 詩篇 98:7–8"> <span className="pl pl-1">海とそれに満ちているものは鳴り轟け。</span><br /><span className="pl pl-2">野とそこにあるすべてのものは喜び勇め。</span></span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 98:9; 詩篇 96:12–13; ヨハネの黙示録 11:17–18"> <span className="pl pl-1">そのとき、森の木々も主の御前で喜び歌う。</span><br /><span className="pl pl-2">主が地をさばくために来られるからだ。</span></span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 106:1; 歴代誌 第二 7:3; 詩篇 107:1"> <span className="pl pl-1">主に感謝せよ。主はいつくしみ深く、</span><br /><span className="pl pl-2">その慈しみはとこしえまで続く。</span></span>
<span className="v" id="v35" data-v="35" data-xref="詩篇 106:47–48; ペテロの手紙第一 2:9; 詩篇 14:7"> <span className="pl pl-1">こう言え。「私たちの救いの神よ、私たちを救い出してください。</span><br /><span className="pl pl-2">国々から私たちを集め、救い出してください。</span><br /><span className="pl pl-2">あなたの聖なる御名に感謝し、あなたを賛美して喜び誇るために。」</span></span>
<span className="v" id="v36" data-v="36" data-xref="列王記第一 8:15; 詩篇 72:18–19; 列王記第一 8:56"> <span className="pl pl-1">イスラエルの神、主がほめたたえられるように。</span><br /><span className="pl pl-2">とこしえからとこしえまで。</span><br />すべての民は「アーメン」と言って、主を賛美した。</span>
</div>

<span className="v" id="v38" data-v="38" data-xref="歴代誌上 26:10; 歴代誌上 13:14; 歴代誌上 25:3"> またオベド・エドムとその同族六十八人を残した。エドゥトンの子オベド・エドムとホサは門衛であった。</span>
<span className="v" id="v39" data-v="39" data-xref="列王記第一 3:4; 歴代誌上 15:11; 歴代誌 第二 1:3–4"> また、ギベオンにあった高き所で、主の幕屋の前に祭司ツァドクと、その兄弟である祭司たちを残した。</span>

<span className="v" id="v43" data-v="43" data-xref="サムエル記第二 6:19–20; 創世記 18:19; 詩篇 101:2"> すべての民はそれぞれ自分の家へ去って行き、ダビデも自分の家族を祝福するために帰って行った。</span>

<span className="v" id="v1" data-v="1" data-xref="創世記 46:21; 歴代誌上 7:6–12; 民数記 26:38"> ベニヤミンは長子ベラ、次男アシュベル、三男アハラ、</span>
<span className="v" id="v2" data-v="2"> 四男ノハ、五男ラファの父となった。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 46:21; 民数記 26:40"> ベラの子らは、アダル、ゲラ、アビフド、</span>
<span className="v" id="v4" data-v="4"> アビシュア、ナアマン、アホア、</span>
<span className="v" id="v5" data-v="5" data-xref="歴代誌上 7:12; 民数記 26:39; 士師記 3:15"> ゲラ、シェフファン、フラムであった。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代誌上 2:54; 士師記 3:20–30; 歴代誌上 7:10"> これらはエフドの子らである。これらはゲバの住民の父祖の家の長であり、マナハテに捕囚として連れ去られた者たちである。</span>
<span className="v" id="v7" data-v="7"> すなわち、ナアマン、アヒヤ、そして彼らを連れ去ったゲラである。彼はウザとアヒフドの父となった。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ルツ記 1:1; 創世記 25:6"> シャハライムは、妻たちを離縁した後、モアブの野で子らの父となった。フシムとバアラが彼の妻であった。</span>
<span className="v" id="v9" data-v="9"> 妻ホデシュによって、彼はヨバブ、ツィブヤ、メシャ、マルカム、</span>
<span className="v" id="v10" data-v="10"> エウツ、サキヤ、ミルマの父となった。これらが彼の子らであり、父祖の家の長であった。</span>
<span className="v" id="v11" data-v="11"> フシムによって、彼はアビトブとエルパアルの父となった。</span>
<span className="v" id="v12" data-v="12" data-xref="エズラ記 2:33; ネヘミヤ記 7:37; ネヘミヤ記 6:2"> エルパアルの子らは、エベル、ミシャム、シェメド。彼はオノとロド、およびその町々を建てた。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代誌上 2:52; ヨシュア記 19:42; 歴代誌上 4:4"> そしてアヤロンの住民の父祖の家の長であるベリアとシェマ。彼らはガテの住民を敗走させた。</span>
<span className="v" id="v14" data-v="14"> さらにアヒオ、シャシャク、エレモテ、</span>
<span className="v" id="v15" data-v="15"> ゼバデヤ、アラド、エデル、</span>
<span className="v" id="v16" data-v="16"> ミカエル、イシュパ、ヨハはベリアの子らであった。</span>
<span className="v" id="v17" data-v="17"> またゼバデヤ、メシュラム、ヒズキ、ヘベル、</span>
<span className="v" id="v18" data-v="18"> イシュメライ、イズリヤ、ヨバブはエルパアルの子らであった。</span>
<span className="v" id="v19" data-v="19"> またヤキム、ジクリ、ザブディ、</span>
<span className="v" id="v20" data-v="20"> エリエナイ、ツィルタイ、エリエル、</span>
<span className="v" id="v21" data-v="21"> アダヤ、ベラヤ、シムラテはシムイの子らであった。</span>
<span className="v" id="v22" data-v="22"> またイシュパン、エベル、エリエル、</span>
<span className="v" id="v23" data-v="23"> アブドン、ジクリ、ハナン、</span>
<span className="v" id="v24" data-v="24"> ハナニヤ、エラム、アントテヤ、</span>
<span className="v" id="v25" data-v="25"> イフデヤ、ペヌエルはシャシャクの子らであった。</span>
<span className="v" id="v26" data-v="26"> またシャムシェライ、シェハルヤ、アタルヤ、</span>
<span className="v" id="v27" data-v="27"> ヤアレシュヤ、エリヤ、ジクリ、およびエロハムの子ら。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 1:21; ヨシュア記 15:63; ネヘミヤ記 11:1"> これらは代々、父祖の家の長を務めた有力者たちであった。彼らはエルサレムに住んでいた。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="歴代誌上 9:35–38"> ギベオンの父はギベオンに住んでいた。その妻の名はマアカであった。</span>
<span className="v" id="v30" data-v="30" data-xref="歴代誌上 9:36–37"> その長子はアブドン、次にツル、キシュ、バアル、ナダブ、</span>
<span className="v" id="v31" data-v="31" data-xref="歴代誌上 9:37"> ゲドル、アヒオ、ゼケル、</span>
<span className="v" id="v32" data-v="32" data-xref="歴代誌上 9:38"> そしてシメアの父となったミクロテ。彼らもまた親族とともにエルサレムに住み、同族の者たちの近くにいた。</span>
<span className="v" id="v33" data-v="33" data-xref="サムエル記第一 9:1; サムエル記第二 2:8; サムエル記第一 31:2"> ネルはキシュの父となった。キシュはサウルの父となった。サウルはヨナタン、マルキ・シュア、アビナダブ、エシュバアルの父となった。</span>
<span className="v" id="v34" data-v="34" data-xref="サムエル記第二 4:4; サムエル記第二 9:12; サムエル記第二 9:10"> ヨナタンの子はメリブ・バアルであった。メリブ・バアルはミカの父となった。</span>
<span className="v" id="v35" data-v="35" data-xref="歴代誌上 9:41"> ミカの子らは、ピトン、メレク、タレア、アハズ。</span>
<span className="v" id="v36" data-v="36" data-xref="歴代誌上 9:42"> アハズはエホアッダの父となった。エホアッダはアレメテ、アズマベテ、ジムリの父となった。ジムリはモツァの父となった。</span>
<span className="v" id="v37" data-v="37" data-xref="歴代誌上 9:43"> モツァはビネアの父となった。その子ラファ、その子エルアサ、その子アツェル。</span>
<span className="v" id="v38" data-v="38"> アツェルには六人の子がおり、その名は次のとおりである。アズリカム、ボケル、イシュマエル、シェアルヤ、オバデヤ、ハナン。これらは皆アツェルの子らである。</span>
<span className="v" id="v39" data-v="39"> 彼の兄弟エシェクの子らは、長子ウラム、次男エウシュ、三男エリフェレテ。</span>
<span className="v" id="v40" data-v="40" data-xref="詩篇 128:3–6; 歴代誌 第二 14:8; 歴代誌上 12:2"> ウラムの子らは力ある勇士であり、弓を射る者たちで、多くの子と孫を持ち、百五十人であった。これらは皆ベニヤミンの子らである。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テトス 1:3; コロサイ人への手紙 1:27; 使徒の働き 9:15"> 私たちの救い主である神と、私たちの望みである主イエス・キリスト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NU本文ではキリスト・イエスと読み、「主」は省略されている。">a</a></sup>の命令によって、キリスト・イエスの使徒とされたパウロから、</span>
<span className="v" id="v2" data-v="2" data-xref="テトス 1:4; テモテへの第二の手紙 1:2; コリント人への第一の手紙 4:14–17"> 信仰による真の子テモテへ。私たちの父である神と、私たちの主キリスト・イエスから、恵みとあわれみと平安がありますように。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="テモテへの手紙第一 6:3; ガラテヤ人への手紙 1:6–7; ヨハネの手紙第二 1:9–10"> 私がマケドニアへ向かう際に勧めたように、エフェソにとどまり、ある人々に異なる教えを説かないよう命じなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="テモテへの手紙第一 4:7; テトス 1:14; テトス 3:9"> また、作り話や果てしのない系図に心を奪われないよう命じなさい。それらは、信仰に基づく神のご計画を進めるどころか、論争を引き起こします。</span>
<span className="v" id="v5" data-v="5" data-xref="テモテへの手紙第一 1:19; ガラテヤ人への手紙 5:22; テモテへの第二の手紙 2:22"> この命令が目指すものは、清い心、正しい良心、偽りのない信仰から生まれる愛です。</span>
<span className="v" id="v6" data-v="6" data-xref="テトス 1:10; テモテへの第二の手紙 2:23–24; テトス 3:9"> ある人々はこれらからそれ、むなしい話へと迷い込んでしまいました。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 1:22; テモテへの手紙第一 6:4; ペテロの第二の手紙 2:12"> 彼らは律法の教師になりたがっていますが、自分の言っていることも、強く断言していることも理解していません。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 7:12–13; 詩篇 19:7–10; ローマ人への手紙 7:16"> しかし、律法を正しく用いるなら、それが良いものであることを私たちは知っています。</span>
<span className="v" id="v9" data-v="9" data-xref="ガラテヤ人への手紙 3:19; ペテロの手紙第一 4:18; ローマ人への手紙 5:20"> 私たちが知っているとおり、律法は義人のために設けられたのではなく、律法に背く者と反抗する者、不敬虔な者と罪人、聖さを顧みない者と神聖なものを汚す者、父を殺す者、母を殺す者、人を殺す者、</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 6:9–10; レビ記 18:22; テモテへの第二の手紙 4:3"> 淫らな行いをする者、男色を行う者、人をさらって売る者、偽りを言う者、偽りの誓いを立てる者、また健全な教えに反するそのほかのあらゆるもののためです。</span>
<span className="v" id="v11" data-v="11" data-xref="ガラテヤ人への手紙 2:7; テトス 1:3; テモテへの手紙第一 6:15"> それは、私に託された、幸いなる神の栄光の福音にかなう教えです。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ピリピ人への手紙 4:13; テモテへの第二の手紙 4:17; コリント人への第二の手紙 12:9–10"> 私を強くしてくださった私たちの主キリスト・イエスに感謝します。主は私を忠実な者と認め、奉仕の務めに就かせてくださいました。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 8:3; ペテロの手紙第一 2:10; ヘブル人への手紙 6:4–8"> 私はかつて、神を冒涜し、迫害し、暴虐を働く者でした。それでも、信じないまま無知によって行ったことなので、あわれみを受けました。</span>
<span className="v" id="v14" data-v="14" data-xref="テモテへの第二の手紙 1:13; エペソ人への手紙 1:7–8; コリント人への第一の手紙 15:10"> 私たちの主の恵みは、キリスト・イエスにある信仰と愛とともに、あふれるばかりに注がれました。</span>
<span className="v" id="v15" data-v="15" data-xref="マルコ 2:17; ルカ 19:10; ヨハネ 3:16–17"> 「キリスト・イエスは罪人を救うために世に来られた」という言葉は信頼でき、すべての人が受け入れるに値します。私はその罪人の中でも最たる者です。</span>
<span className="v" id="v16" data-v="16" data-xref="テモテへの手紙第一 1:13; エペソ人への手紙 2:7; ルカ 7:47"> しかし、私があわれみを受けたのは、まさにこのためです。罪人の最たる私に、イエス・キリストが限りない忍耐を示し、これから永遠のいのちを得るために主を信じる人々の模範として私を置くためでした。</span>
<span className="v" id="v17" data-v="17" data-xref="エペソ人への手紙 3:20–21; ユダ 1:25; テモテへの手紙第一 6:15–16"> 永遠の王、不滅で目に見えない、ただひとり知恵ある神に、誉れと栄光が世々限りなくありますように。アーメン。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="テモテへの手紙第一 4:14; テモテへの手紙第一 6:20; テモテへの第二の手紙 4:1–3"> わが子テモテよ、以前あなたに与えられた預言に従って、この命令を託します。それらによって、立派に戦い抜きなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="テモテへの手紙第一 3:9; ペテロの手紙第一 3:15–16; ヨハネの黙示録 3:10"> 信仰と正しい良心を保ちなさい。ある人々は良心を押しのけたため、信仰の船を難破させてしまいました。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第一の手紙 5:4–5; テモテへの第二の手紙 2:17; コリント人への第一の手紙 11:32"> その中にはヒメナイとアレクサンドロがいます。私は、神を冒涜してはならないことを学ばせるため、彼らをサタンに引き渡しました。</span>
</div>

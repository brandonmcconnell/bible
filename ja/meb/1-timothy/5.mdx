<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="レビ記 19:32; ペテロの手紙第一 5:5–6; テトス 2:2"> 年配の男性を厳しく叱ってはなりません。父親に対するように勧め、若い男性には兄弟に対するように、</span>
<span className="v" id="v2" data-v="2" data-xref="テモテへの手紙第一 4:12; マタイ 12:50; ピリピ人への手紙 4:8"> 年配の女性には母親に対するように、若い女性には、あらゆる純潔をもって姉妹に対するように接しなさい。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命記 27:19; 使徒の働き 6:1; 申命記 10:18"> 真にやもめである女性を敬いなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="エペソ人への手紙 6:1–3; ヨハネ 19:26–27; マタイ 15:4–6"> しかし、やもめに子どもや孫がいるなら、まず彼らに、自分の家族を大切にし、親に恩を返すことを学ばせなさい。これは<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR本文は「良いことであり」を加えている。">a</a></sup>神に喜ばれることだからです。</span>
<span className="v" id="v5" data-v="5" data-xref="テモテへの手紙第一 5:3; ルカ 2:37; コリント人への第一の手紙 7:32"> 真にやもめであり身寄りのない女性は、神に望みを置き、夜も昼も願いと祈りを絶やしません。</span>
<span className="v" id="v6" data-v="6" data-xref="ヤコブの手紙 5:5; ヨハネの黙示録 18:7; ルカ 15:24"> しかし、快楽にふける女性は、生きていても死んでいるのです。</span>
<span className="v" id="v7" data-v="7" data-xref="テモテへの手紙第一 4:11; テトス 2:15; テモテへの第二の手紙 4:1"> 彼女たちが非難されるところのない者となるよう、これらのことも命じなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="ガラテヤ人への手紙 6:10; コリント人への第二の手紙 12:14; ルカ 11:11–13"> だれであれ、自分の身内、とりわけ自分の家族を養わない人は、信仰を否定したのであり、信じない人よりも悪い者です。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="テモテへの手紙第一 3:2; テモテへの手紙第一 5:11; ルカ 2:36–37"> やもめとして名簿に載せるのは、六十歳以上で、一人の夫の妻であった女性に限りなさい。</span>
<span className="v" id="v10" data-v="10" data-xref="テモテへの手紙第一 6:18; テトス 3:8; 使徒の働き 9:36"> また、良い行いによって認められている人、すなわち子どもを育て、旅人をもてなし、聖徒たちの足を洗い、苦しむ人々を助け、あらゆる良い行いに励んできた人でなければなりません。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="テモテへの手紙第一 5:14; ホセア書 13:6; ヤコブの手紙 5:5"> しかし、若いやもめは名簿に載せないようにしなさい。彼女たちはキリストに背いて情欲に駆られると、結婚したいと望むようになり、</span>
<span className="v" id="v12" data-v="12" data-xref="ガラテヤ人への手紙 1:6; ヤコブの手紙 3:1; コリント人への第一の手紙 11:34"> 最初の誓約を捨てたために、裁きを受けることになるからです。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 20:19; テサロニケ人への第二の手紙 3:6–11; 使徒の働き 20:30"> そのうえ、彼女たちは怠け癖がつき、家々を歩き回ります。怠けるだけでなく、うわさ話をし、人のことに口を出し、話すべきでないことまで話します。</span>
<span className="v" id="v14" data-v="14" data-xref="テトス 2:5; テモテへの手紙第一 6:1; テトス 2:8"> ですから私は、若いやもめには結婚し、子どもを産み、家庭を治め、敵対する者に悪口を言う機会を少しも与えないでほしいのです。</span>
<span className="v" id="v15" data-v="15" data-xref="ペテロの第二の手紙 2:2; ユダ 1:4–5; ペテロの第二の手紙 2:20–22"> すでに何人かは道をそれ、サタンについて行きました。</span>
<span className="v" id="v16" data-v="16" data-xref="テモテへの手紙第一 5:3–5; テモテへの手紙第一 5:8"> 信者である男性または女性の身内にやもめがいるなら、その人が彼女たちを助け、教会に負担をかけてはなりません。そうすれば教会は、真にやもめである女性たちを助けることができます。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 13:17; テサロニケ人への手紙第一 5:12–13; ガラテヤ人への手紙 6:6"> よく治めている長老たちを、格別の敬意を受けるにふさわしい者としなさい。特に、御言葉と教えのために労苦している長老たちはそうです。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 25:4; コリント人への第一の手紙 9:14; コリント人への第一の手紙 9:7–10"> 聖書は、「脱穀している牛に口籠をはめてはならない」と言い、また、<span className="woj">「働く者が報酬を受けるのは当然である」</span>と言っています。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="マタイ 18:16; 申命記 19:15; コリント人への第二の手紙 13:1"> 二人か三人の証人の言葉によるのでなければ、長老に対する訴えを受理してはなりません。</span>
<span className="v" id="v20" data-v="20" data-xref="テモテへの第二の手紙 4:2; テトス 1:13; テモテへの手紙第一 1:20"> 罪を犯している者たちを、すべての人の前で戒めなさい。ほかの人々も恐れを抱くようになるためです。</span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの第二の手紙 2:4; テモテへの第二の手紙 4:1; テモテへの手紙第一 6:13"> 神と主イエス・キリストと選ばれた御使いたちの前で、私は厳かに命じます。偏見なくこれらのことを守り、何事もえこひいきしてはなりません。</span>
<span className="v" id="v22" data-v="22" data-xref="エペソ人への手紙 5:11; テモテへの手紙第一 3:10; テモテへの手紙第一 3:6"> だれにも性急に手を置いてはなりません。他人の罪に加わってはなりません。自分を清く保ちなさい。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="詩篇 104:15; 箴言 31:4–7; テモテへの手紙第一 4:4"> これからは水ばかり飲まず、胃と、たびたび患う病気のために、少量のぶどう酒も飲みなさい。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="テモテへの第二の手紙 4:10; 使徒の働き 8:18; ガラテヤ人への手紙 5:19–21"> ある人々の罪は明白で、本人に先立って裁きの場に現れます。しかし、ほかの人々の罪は後から明らかになります。</span>
<span className="v" id="v25" data-v="25" data-xref="箴言 10:9; ルカ 11:33; 詩篇 37:5–6"> 同じように、良い行いにも明らかなものがあり、そうでないものも隠れたままではいられません。</span>
</div>

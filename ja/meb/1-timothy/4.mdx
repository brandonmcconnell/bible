<span className="v" id="v2" data-v="2" data-xref="エペソ人への手紙 4:19; 使徒の働き 20:30; ローマ人への手紙 16:18"> それは、良心に焼き印を押された偽りを語る者たちの偽善によるものです。</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 13:4; テモテへの手紙第一 4:4; ローマ人への手紙 14:6"> 彼らは結婚を禁じ、食物を断つよう命じます。しかし食物は、信じて真理を知る人々が感謝して受けるよう、神が造られたものです。</span>
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 14:20; コリント人への第一の手紙 10:25; ローマ人への手紙 14:14"> 神が造られたものはすべて良いものであり、感謝して受けるなら、捨てるべきものは何もありません。</span>
<span className="v" id="v5" data-v="5" data-xref="テモテへの手紙第一 4:3; コリント人への第一の手紙 7:14; ルカ 4:4"> それは、神の言葉と祈りによって聖なるものとされるからです。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="テトス 2:7–10; コロサイ人への手紙 3:16; マタイ 13:52"> これらのことを兄弟たちに示すなら、あなたはキリスト・イエスの良い奉仕者となります。あなた自身、信仰の言葉と、これまで従ってきた良い教えによって養われてきたのです。</span>
<span className="v" id="v7" data-v="7" data-xref="テモテへの第二の手紙 2:16; テトス 2:12; テモテへの手紙第一 1:4"> しかし、世俗的で、老女の作り話のようなものは退けなさい。敬虔を目指して自分を鍛えなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="マタイ 6:33; テモテへの手紙第一 6:6; 詩篇 37:3–4"> 体の鍛錬にもいくらか益がありますが、敬虔はすべてのことに益があります。今のいのちと来るべきいのちの約束を持っているからです。</span>
<span className="v" id="v9" data-v="9" data-xref="テモテへの手紙第一 1:15"> この言葉は信頼でき、すべての人が受け入れるに値します。</span>
<span className="v" id="v10" data-v="10" data-xref="テモテへの手紙第一 2:4; ヨハネの手紙第一 2:2; テモテへの手紙第一 2:6"> 私たちがこの目標のために労苦し、非難にも耐えているのは、生ける神に望みを置いているからです。神はすべての人の救い主、特に信じる人々の救い主です。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテへの手紙第一 6:2; テモテへの第二の手紙 4:2; テトス 2:15"> これらのことを命じ、教えなさい。</span>
</div>
<div className="bp">

<span className="v" id="v13" data-v="13" data-xref="使徒の働き 6:4; テトス 2:15; テモテへの第二の手紙 4:2"> 私が行くまで、朗読すること、勧めること、教えることに専念しなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="テモテへの第二の手紙 1:6; ペテロの手紙第一 4:9–11; テモテへの手紙第一 1:18"> あなたのうちにある賜物をおろそかにせず、用いなさい。その賜物は、預言を通して、長老たちがあなたに手を置いたときに与えられたものです。</span>
<span className="v" id="v15" data-v="15" data-xref="マタイ 5:16; ピリピ人への手紙 2:15–16; 詩篇 143:5"> これらのことに心を注ぎ、ひたすら励みなさい。あなたの進歩がすべての人に明らかになるようにしなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="テトス 1:9; テトス 2:7; ヨハネの手紙第二 1:8–9"> 自分自身と教えに注意を払い、これらのことを続けなさい。そうすることによって、自分自身とあなたの言葉を聞く人々の両方を救うことになるからです。</span>

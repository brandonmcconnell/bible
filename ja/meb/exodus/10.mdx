<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 4:21; 出エジプト記 7:13–14; 出エジプト記 3:20"> 主はモーセに言われた。「ファラオのもとへ行きなさい。わたしが彼と家臣たちの心をかたくなにしたのは、これらのしるしを彼らの中で行うため、</span>
<span className="v" id="v2" data-v="2" data-xref="ヨエル書 1:3; 申命記 4:9; 申命記 6:20–22"> また、わたしがエジプトをどのように扱い、どのようなしるしを彼らの中で行ったかを、あなたが子や孫に語り聞かせるためである。こうして、あなたがたはわたしが主であることを知る。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ペテロの手紙第一 5:6; 列王記第一 21:29; ヤコブの手紙 4:10"> モーセとアロンはファラオのところに行き、彼に言った。「ヘブル人の神、主はこう言われる。『あなたはいつまで、わたしの前にへりくだることを拒むのか。わたしの民を行かせ、わたしに仕えさせなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 9:3; ヨエル書 2:25; 出エジプト記 11:4–5"> わたしの民を行かせることを拒むなら、見よ、明日いなごをあなたの国に送り込む。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨエル書 1:4; 出エジプト記 9:32; ヨエル書 2:25"> いなごは地面が見えないほど地を覆い、雹を免れて残ったものを食べ、野に生える木をすべて食い尽くす。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 8:21; 出エジプト記 8:3; 出エジプト記 11:6"> あなたの家、すべての家臣の家、すべてのエジプト人の家は、いなごで満ちる。あなたの父祖も、そのまた父祖も、地上に生きた日から今日まで見たことのないものだ。』」モーセは身を翻し、ファラオのもとを去った。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="サムエル記第一 18:21; 出エジプト記 23:33; ヨシュア記 23:13"> ファラオの家臣たちは言った。「いつまでこの男は私たちの罠となるのでしょう。男たちを行かせ、彼らの神、主に仕えさせてください。エジプトが滅びたことが、まだお分かりにならないのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 10:24; 出エジプト記 12:31; 出エジプト記 8:8"> モーセとアロンは再びファラオのもとに連れ戻された。彼は彼らに言った。「行って、あなたがたの神、主に仕えなさい。しかし、行くのは誰か。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 5:1; コリント人への第一の手紙 5:7–8; 申命記 31:12–13"> モーセは言った。「若者も老人も、息子も娘も、羊も牛も連れて行きます。私たちは主の祭りを祝うのです。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 13:21; 歴代誌 第二 32:15; 出エジプト記 12:30–31"> ファラオは言った。「私がおまえたちを子どもと一緒に行かせるなら、主がおまえたちと共におられるだろうよ。見ろ、おまえたちの悪い企みは明らかだ。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 10:28; 詩篇 119:69; 出エジプト記 5:4"> そうはいかない。男たちだけ行って、主に仕えよ。おまえたちが求めていたのはそれだろう。」こうして二人はファラオの前から追い出された。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 7:19; 出エジプト記 10:4–5"> 主はモーセに言われた。「いなごを呼ぶため、エジプトの地の上に手を伸ばしなさい。いなごは地に群がり、雹が残した草をすべて食べる。」</span>
<span className="v" id="v13" data-v="13" data-xref="ヨナ書 1:4; 詩篇 78:26; 詩篇 148:8"> モーセがエジプトの地の上に杖を伸ばすと、主はその日一日中、そして一晩中、地の上に東風を吹かせた。朝になると、東風がいなごを運んで来た。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 78:46; ヨエル書 1:2–4; 詩篇 105:34–35"> いなごはエジプト全土に群がり、国中にとどまった。これほど激しいいなごはかつてなく、二度と起こらないほどであった。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 10:5; 詩篇 78:46; ヨエル書 1:6–7"> それらは地の面全体を覆ったので、地は暗くなった。それらは地のすべての草と、雹が残した木のすべての実を食べた。エジプトの地全体を通して、木にも野の草にも、緑のものは何も残らなかった。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 9:27; サムエル記第二 19:20; サムエル記第一 15:30"> そこでファラオは急いでモーセとアロンを呼び寄せて言った。「私はあなたがたの神、主に対して、またあなたがたに対して罪を犯した。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 8:8; 出エジプト記 9:28; 列王記第一 13:6"> どうか今、もう一度だけ私の罪を赦し、あなたがたの神、主に祈って、この死を私から取り除いてくれ。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ルカ 6:28; 出エジプト記 8:28–30; 出エジプト記 8:9"> モーセはファラオのところから出て行き、主に祈った。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨエル書 2:20; 出エジプト記 13:18; 出エジプト記 15:4"> 主は非常に強い西風を送り、それがいなごを巻き上げ、紅海<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「紅海」はヘブル語の「ヤム・スフ」の翻訳であり、文字通りには「葦の海」または「ガマの海」と訳される。これは現在紅海として知られている水域、またはそれに接続する、あるいはその近くにある水域のいずれかを指している。">a</a></sup>に追い払った。エジプトの全領土に一匹のいなごも残らなかった。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 4:21; 出エジプト記 11:10; 申命記 2:30"> しかし、主はファラオの心をかたくなにされ、彼はイスラエルの子らを行かせなかった。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ヨハネの黙示録 16:10–11; ユダ 1:6; ルカ 23:44"> 主はモーセに言われた。「手を天に向けて伸ばしなさい。エジプトの地を、手で触れられるほど濃い暗闇が覆う。」</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 105:28; ヨハネの黙示録 16:10; 出エジプト記 20:21"> モーセが天に向けて手を伸ばすと、三日間、エジプトの地全体が濃い暗闇に覆われた。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 8:22; イザヤ書 42:16; ペテロの手紙第一 2:9"> 三日間、人々は互いを見ることも、誰も自分の場所から動くこともなかった。しかし、イスラエルの子らが住む所にはすべて光があった。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 10:8–10; 出エジプト記 8:28; 創世記 34:23"> ファラオはモーセを呼び寄せて言った。「行って、主に仕えなさい。ただ、あなたがたの羊の群れと牛の群れは残しておけ。子どもたちも一緒に連れて行くがよい。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="レビ記 9:22; レビ記 16:9; 出エジプト記 29:1–46"> モーセは言った。「私たちの神、主に献げる犠牲と全焼のいけにえも、あなたが私たちに渡さなければなりません。</span>
<span className="v" id="v26" data-v="26" data-xref="イザヤ書 23:18; 使徒の働き 2:44–45; 箴言 3:9"> 家畜も一緒に連れて行きます。ひづめ一つ残しません。私たちはその中から選んで、私たちの神、主に仕えなければなりません。そこへ着くまで、何をもって主に仕えるべきか分からないのです。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 10:20; 出エジプト記 4:21; 出エジプト記 14:8"> しかし主はファラオの心をかたくなにされ、彼は彼らを行かせようとはしなかった。</span>
<span className="v" id="v28" data-v="28" data-xref="歴代誌 第二 25:16; 歴代誌 第二 16:10; アモス書 7:13"> ファラオは言った。「私の前から立ち去れ。二度と私の顔を見ないよう気をつけろ。私の顔を見る日、おまえは死ぬ。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ヘブル人への手紙 11:27; 出エジプト記 12:30–31; 出エジプト記 11:4–8"> モーセは言った。「お言葉通りです。私は二度とあなたの顔を見ません。」</span>
</div>
</div>

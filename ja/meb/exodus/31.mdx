<span className="v" id="v1" data-v="1"> 主はモーセに言われた。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 36:1; 出エジプト記 35:30; ヨハネ 3:27"> 「見よ、わたしはユダ部族のフルの子であるウリの子ベツァルエルを名指しで呼んだ。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 35:31; イザヤ書 28:26; 列王記第一 7:14"> わたしは彼を神の霊で満たし、知恵と英知と知識とあらゆる種類の職人の技を与えた。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 26:1; 出エジプト記 25:32–35; 歴代誌 第二 2:13–14"> それは、巧みな意匠を考案し、金、銀、青銅で細工をし、</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 28:9–21"> 宝石を切ってはめ込み、木を彫り、あらゆる職人の仕事をするためである。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 35:10; 出エジプト記 35:34–1; 出エジプト記 28:3"> 見よ、わたしはダン部族のアヒサマクの子オホリアブを、彼と共に任命した。また、心に知恵のある者たちに知恵を授けた。彼らは、わたしが命じたすべてのものを造る。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 36:8–9; 出エジプト記 25:10–22; 出エジプト記 26:1–37"> すなわち、会見の天幕、あかしの箱、その上にある贖いの座、天幕のすべての器具、</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 37:10–28; 出エジプト記 30:1–10; 出エジプト記 25:23–40"> 机とその器具、純金の燭台とそのすべての器具、香の祭壇、</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 38:1–8; 出エジプト記 27:1–8; 出エジプト記 40:11"> 全焼のいけにえの祭壇とそのすべての器具、洗盤とその台、</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 4:5–14; 出エジプト記 28:1–43; 出エジプト記 39:1–43"> 精巧に織られた衣服、すなわち祭司アロンのための聖なる衣服と、その子らが祭司として仕えるための衣服、</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 37:29; 出エジプト記 30:23–38"> 注ぎ油と、聖所のための香りのよい香である。わたしがあなたに命じた通りに、彼らは造る。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 主はモーセに言われた。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 20:12; エゼキエル書 20:20; レビ記 19:30"> 「イスラエルの子らに告げなさい。『わたしの安息日を必ず守りなさい。これは、わたしとあなたがたとの間の代々にわたるしるしであり、わたしがあなたがたを聖別する主であることを知らせるものである。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 35:2–3; 民数記 15:32–36; エゼキエル書 20:21"> 安息日を守りなさい。それはあなたがたにとって聖なる日である。これを汚す者は必ず死刑に処せられる。その日に仕事をする者はみな、民の中から断ち切られる。</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 2:2; 出エジプト記 16:23; レビ記 23:3"> 六日間は仕事をする。しかし七日目は完全な休みの安息日、主に対して聖なる日である。安息日に仕事をする者は必ず死刑に処せられる。</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 50:5; 創世記 9:13; 創世記 17:11"> イスラエルの子らは安息日を守り、代々にわたる永遠の契約として守り続ける。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 1:31; 出エジプト記 31:13; 創世記 2:2–3"> これは、わたしとイスラエルの子らとの間の永遠のしるしである。主は六日間で天と地を造り、七日目に休み、息をつかれた。』」</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 33:10–12; 出エジプト記 15:27; 出エジプト記 17:1"> 彼らはエリムを旅立った。イスラエルの子らの全会衆は、エジプトの地を出て第二の月の十五日に、エリムとシナイの間にあるシンの荒野へ来た。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第一の手紙 10:10; 出エジプト記 15:24; 詩篇 106:25"> イスラエルの子らの全会衆は、荒野でモーセとアロンにつぶやいた。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 11:4–5; 民数記 20:3–5; 出エジプト記 17:3"> イスラエルの子らは二人に言った。「エジプトの地で肉の鍋の傍らに座り、パンを腹いっぱい食べていた時、主の手にかかって死んでいた方がよかった。あなたがたは、この全会衆を飢え死にさせるため、私たちを荒野へ連れ出した。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 10:3; 詩篇 78:24–25; 申命記 8:2"> 主はモーセに言われた。「見よ、わたしはあなたがたのために天からパンを降らせる。民は出て行き、一日分を毎日集める。こうして、彼らがわたしの教えに従って歩むかどうかを試す。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 16:22–23; 出エジプト記 35:2–3; レビ記 25:21–22"> 六日目には、彼らが持ち帰ったものを用意すると、それは毎日集める分の二倍となる。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 6:7; 民数記 16:28; 出エジプト記 16:12–13"> モーセとアロンはイスラエルのすべての子らに言った。「夕方になると、あなたがたはエジプトの地からあなたがたを導き出されたのが主であることを知る。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 40:5; 民数記 16:11; ヨハネ 11:40"> 朝には主の栄光を見る。主は、あなたがたが主に向かってつぶやくのを聞かれた。私たちは何者なのか。あなたがたは私たちに向かってつぶやいているのではない。」</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 13:2; サムエル記第一 8:7; テサロニケ人への手紙第一 4:8"> モーセは言った。「主は夕方には肉を、朝には満ち足りるほどのパンを与えられる。主は、あなたがたが主に向かってつぶやくのを聞かれた。私たちは何者なのか。あなたがたのつぶやきは、私たちではなく主に向けられている。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数記 16:16; 出エジプト記 16:2; 出エジプト記 16:8"> モーセはアロンに言った。「イスラエルの子らの全会衆に告げなさい。『主の前に近づきなさい。主はあなたがたのつぶやきを聞かれた。』」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 16:7; 民数記 16:19; 民数記 16:42"> アロンがイスラエルの子らの全会衆に語っていると、彼らは荒野の方を見た。すると、主の栄光が雲の中に現れた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 主はモーセに言われた。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨエル書 3:17; エゼキエル書 39:22; 出エジプト記 6:7"> 「わたしはイスラエルの子らのつぶやきを聞いた。彼らに告げなさい。『夕方には肉を食べ、朝にはパンで満ち足りる。こうして、わたしがあなたがたの神、主であることを知る。』」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数記 11:9; 詩篇 105:40; 詩篇 78:27–28"> 夕方になると、うずらが飛んで来て陣営を覆った。朝になると、陣営の周囲に露が降りていた。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 11:7–9; 詩篇 105:40; 詩篇 78:24"> 降りていた露が上がると、見よ、荒野の面に、地の上の霜のような、小さく丸いものがあった。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 16:4; ヨハネ 6:58; 出エジプト記 16:31"> イスラエルの子らはそれを見て、互いに「これは何だ」と言った。何であるか分からなかったのである。モーセは言った。「これは主が食物として与えられたパンである。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 16:36; 出エジプト記 16:18; 出エジプト記 16:32–33"> 主が命じられたことはこうである。『各人は食べる分だけ、一人につき一オメル<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一オメルは約二・二リットルである。">a</a></sup>ずつ、自分の天幕にいる人数に応じて集めなさい。』」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> イスラエルの子らはそのようにした。ある者は多く、ある者は少なく集めた。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第二の手紙 8:14–15"> 彼らがオメルで量ると、多く集めた者も余らず、少なく集めた者も不足しなかった。各人は食べる分だけ集めた。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 12:10; 出エジプト記 23:18; マタイ 6:34"> モーセは彼らに言った。「だれも朝までそれを残してはならない。」</span>
<span className="v" id="v20" data-v="20" data-xref="マルコ 10:14; 民数記 16:15; エペソ人への手紙 4:26"> しかし彼らはモーセに聞き従わなかった。ある者たちが朝までそれを残しておくと、虫がわき、臭くなった。モーセは彼らに怒った。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 6:6–11; 伝道者の書 12:1; コリント人への第二の手紙 6:2"> 彼らは毎朝、各人が食べる分だけを集めた。日が熱くなると、それは溶けた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 16:5; レビ記 25:22; 出エジプト記 16:16"> 六日目になると、彼らは二倍のパン、すなわち一人につき二オメルずつ集めた。会衆の長は皆来て、モーセに告げた。</span>
<span className="v" id="v23" data-v="23" data-xref="レビ記 23:3; 出エジプト記 31:15; 出エジプト記 20:8–11"> モーセは言った。「主が語られたのはこうである。『明日は完全な休み、主への聖なる安息日である。焼くものは焼き、煮るものは煮なさい。残ったものはすべて朝まで取っておく。』」</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 16:20; 出エジプト記 16:33"> 彼らはモーセが命じた通り、朝までそれを取っておいたが、臭くもならず、虫もわかなかった。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 16:23; 出エジプト記 16:29; ネヘミヤ記 9:14"> モーセは言った。「今日はそれを食べなさい。今日は主への安息である。今日、野でそれを見つけることはないであろう。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 5:13; 出エジプト記 20:9–11; エゼキエル書 46:1"> 六日間は集める。しかし七日目は安息日なので、その日には何もない。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="箴言 20:4"> 七日目になると、民のうちのある者たちが集めに出て行ったが、何も見つからなかった。</span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 78:10; 詩篇 106:13; 民数記 14:11"> 主はモーセに言われた。「あなたがたはいつまで、わたしの戒めとわたしの律法を守ることを拒むのか。</span>
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 31:13; イザヤ書 58:13–14; エゼキエル書 20:12"> 主が安息日を与えられたので、六日目には二日分のパンを与えられる。七日目はそれぞれ自分の場所にとどまり、そこから出てはならない。」</span>
<span className="v" id="v30" data-v="30" data-xref="申命記 5:12–14; レビ記 23:3; ヘブル人への手紙 4:9"> こうして民は七日目に休んだ。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="雅歌 2:3; 民数記 11:6–9; 出エジプト記 16:15"> イスラエルの家はそれをマナ<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「マナ」は、ヘブライ語の「これは何か」という問いに響きが似ている。">b</a></sup>と名づけた。それは白いコリアンダーの種のようで、味は蜂蜜を入れた薄焼き菓子のようであった。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 105:5; ルカ 22:19; 詩篇 111:4–5"> モーセは言った。「主が命じられたのはこうである。『一オメル分を代々にわたって保存しなさい。後の世代が、わたしがあなたがたをエジプトから導き出した時、荒野で食べさせたパンを見るためである。』」</span>
<span className="v" id="v33" data-v="33" data-xref="ヘブル人への手紙 9:4"> モーセはアロンに言った。「壺を取り、その中に一オメル分のマナを入れ、それを主の前に置いて、あなたがたの代々にわたり保管しなさい。」</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 27:21; 出エジプト記 25:21; 出エジプト記 25:16"> 主がモーセに命じられた通り、アロンはそれを保管のためにあかしの前に置いた。</span>
<span className="v" id="v35" data-v="35" data-xref="ネヘミヤ記 9:20–21; ヨシュア記 5:12; 申命記 8:2–3"> イスラエルの子らは、人が住む地に着くまで、四十年間マナを食べた。彼らはカナンの地の境に着くまでマナを食べた。</span>
<span className="v" id="v36" data-v="36" data-xref="出エジプト記 16:16; 出エジプト記 16:32–33"> オメルはエファの十分の一である。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一エファは約二十二リットルである。">c</a></sup></span>
</div>
</div>

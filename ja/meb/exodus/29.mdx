<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="レビ記 4:3; マラキ書 1:13–14; 出エジプト記 12:5"> 彼らが祭司としてわたしに仕えるために、彼らを聖なるものとするため、あなたが彼らになすべき事は次の通りである。若い雄牛一頭と、傷のない雄羊二匹を取りなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 6:15; レビ記 2:15; レビ記 7:12"> 種なしパン、油を混ぜた種なしの菓子、油を塗った種なしの薄焼きパンを、上質な小麦粉で造りなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="民数記 6:17; レビ記 8:26; レビ記 8:2"> それらを一つの籠に入れ、その籠に入れて、雄牛と二匹の雄羊と共に持って来なさい。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 40:12; ヘブル人への手紙 10:22; 出エジプト記 26:36"> アロンとその子らを会見の天幕の入り口へ連れて来て、水で洗いなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 28:2–8; レビ記 8:7–8"> 衣服を取り、アロンに長衣、エポデの上着、エポデ、胸当てを着せ、エポデの織り帯を締めなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 8:9; 出エジプト記 28:36–39"> 彼の頭にターバンをかぶせ、ターバンの上に聖なる冠を置きなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 35:25; レビ記 21:10; ヨハネ 3:34"> そして注ぎ油を取り、彼の頭に注いで、彼に油を注ぎなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 8:13; 出エジプト記 28:40"> 息子たちを連れて来て、長衣を着せなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 18:7; レビ記 8:22–28; 申命記 18:5"> アロンとその子らに飾り帯を締め、頭帯を結びなさい。祭司職は永遠の掟によって彼らのものとなる。こうしてアロンとその子らを任職する。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="レビ記 1:4; レビ記 8:14; 出エジプト記 29:15"> 雄牛を会見の天幕の前へ連れて来て、アロンとその子らに、その頭へ手を置かせなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 9:8; レビ記 9:12; 出エジプト記 29:4"> 会見の天幕の入り口、主の前で雄牛を屠りなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 27:2; レビ記 9:9; レビ記 8:15"> 雄牛の血を指で祭壇の角に塗り、残りの血を祭壇の土台に注ぎなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 3:3–4; サムエル記第一 2:16; レビ記 9:10"> 内臓を覆う脂肪、肝臓の覆い、二つの腎臓とその脂肪を取り、祭壇の上で焼きなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 4:11–12; レビ記 4:21; 出エジプト記 30:10"> 雄牛の肉、皮、糞は陣営の外で火に焼く。これは罪のいけにえである。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 29:19; 出エジプト記 29:3; レビ記 8:18–21"> 一匹の雄羊を取り、アロンとその子らに、その頭へ手を置かせなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 29:11–12"> 雄羊を屠り、その血を祭壇の周囲に振りかけなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 4:14; レビ記 1:13; レビ記 1:9"> その雄羊を切り分け、その内臓と足を洗い、切り分けた肉や頭と一緒に置きなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 8:21; ピリピ人への手紙 4:18; 創世記 22:7"> 雄羊を全部、祭壇の上で焼きなさい。これは主への全焼のいけにえ、心地よい香り、主への火によるささげ物である。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 29:3; レビ記 8:22–29"> もう一匹の雄羊を取り、アロンとその子らに、その頭へ手を置かせなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 50:5; ヘブル人への手紙 10:22; レビ記 14:16"> 雄羊を屠り、その血をアロンとその子らの右の耳たぶ、右手の親指、右足の親指に塗り、残りを祭壇の周囲に振りかけなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="ヘブル人への手紙 9:22; 出エジプト記 29:7; 出エジプト記 29:1"> 祭壇の上にある血と注ぎ油の一部を取って、アロンとその衣服、および彼と共にいるその子らとその衣服に振りかけなさい。そうすれば彼とその衣服、および彼と共にいるその子らとその衣服は聖なるものとなる。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 29:13; レビ記 9:21; レビ記 9:19"> また、その雄羊の脂肪、脂尾、内臓を覆う脂肪、肝臓の覆い、二つの腎臓、それについている脂肪、右のももを取りなさい（それは任職の雄羊だからである）。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 29:2–3; レビ記 8:26"> さらに、主の前にある種なしパンの籠から、パンの塊一つ、油を塗ったパンの菓子一つ、薄焼きパン一つを取りなさい。</span>
<span className="v" id="v24" data-v="24" data-xref="レビ記 7:30; レビ記 8:27; レビ記 9:21"> これらをすべてアロンとその子らの手に載せ、揺り動かすささげ物として主の前で揺り動かしなさい。</span>
<span className="v" id="v25" data-v="25" data-xref="レビ記 8:28; 出エジプト記 29:41; レビ記 3:16"> あなたはそれらを彼らの手から取り、祭壇の上で全焼のいけにえの上で焼きなさい。これは主の前の心地よい香り、主への火によるささげ物である。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="レビ記 8:29; レビ記 7:31; レビ記 7:34"> アロンの任職の雄羊の胸を取り、揺り動かすささげ物として主の前で揺り動かしなさい。これはあなたの分となる。</span>
<span className="v" id="v27" data-v="27" data-xref="レビ記 10:15; 民数記 18:11; 申命記 18:3"> 任職の雄羊から取った、揺り動かすささげ物の胸と、持ち上げるささげ物のももを聖別しなさい。これはアロンとその子らの分である。</span>
<span className="v" id="v28" data-v="28" data-xref="民数記 15:19–20; レビ記 7:11–38; レビ記 10:14–15"> これはイスラエルの子らからアロンとその子らに与えられる永遠の分である。和解のいけにえから取り分けて主に献げる、持ち上げるささげ物である。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数記 18:8; 出エジプト記 28:3–4; 出エジプト記 30:30"> アロンの聖なる衣服は、彼の後の子らのためのものとなり、彼らがそれを着て油を注がれ、それを着て任職される。</span>
<span className="v" id="v30" data-v="30" data-xref="民数記 20:28; レビ記 13:5; 使徒の働き 20:6–7"> 彼に代わって祭司となる息子は、聖所で仕えるため会見の天幕に入る時、七日間その衣服を着る。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="レビ記 8:31; サムエル記第一 2:13; エゼキエル書 46:20–24"> 任職の雄羊を取り、その肉を聖なる場所で煮なさい。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイ 12:4; 出エジプト記 29:23; 出エジプト記 29:2–3"> アロンとその子らは、会見の天幕の入り口で、雄羊の肉と籠のパンを食べる。</span>
<span className="v" id="v33" data-v="33" data-xref="民数記 18:4; レビ記 10:13–18; 詩篇 22:26"> 彼らを任職し聖別する贖いのために用いられたものを、彼らが食べる。ほかの者は食べてはならない。これは聖なるものである。</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 12:10; レビ記 8:32; 出エジプト記 29:22"> 任職の肉やパンが朝まで残ったなら、火で焼き尽くしなさい。聖なるものなので、食べてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="出エジプト記 29:30; レビ記 14:8–11; レビ記 8:4–36"> わたしが命じたすべての通りに、アロンとその子らに行いなさい。七日間にわたって任職する。</span>
<span className="v" id="v36" data-v="36" data-xref="ヘブル人への手紙 10:11; ヘブル人への手紙 9:22–23; 出エジプト記 30:28–29"> 毎日、贖いのために罪のいけにえの雄牛を献げなさい。祭壇のために贖いを行ってこれをきよめ、油を注いで聖別する。</span>
<span className="v" id="v37" data-v="37" data-xref="出エジプト記 40:10; マタイ 23:19; 出エジプト記 30:28–29"> 七日間、祭壇のために贖罪をし、それを聖別しなさい。そうすれば祭壇は最も聖なるものとなる。祭壇に触れるものはみな聖なるものとなる。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="歴代誌 第二 2:4; 歴代誌上 16:40; 民数記 28:3–8"> あなたが祭壇の上にささげるべきものは次の通りである。一歳の小羊二匹を、毎日絶えずささげる。</span>
<span className="v" id="v39" data-v="39" data-xref="エゼキエル書 46:13–15; 列王記第二 16:15; 詩篇 5:3"> 一匹を朝に、もう一匹を夕暮れに献げる。</span>
<span className="v" id="v40" data-v="40" data-xref="ピリピ人への手紙 2:17; エゼキエル書 46:14; ヨエル書 2:14"> 一匹の小羊と共に、一エファ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="1エファは約22リットル、あるいは約3分の2ブッシェルである。">a</a></sup>の十分の一の上質な小麦粉に、一ヒン<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="1ヒンは約6.5リットル、すなわち1.7ガロンである。したがって、1ヒンの四分の一は約1.6リットルである。">b</a></sup>の四分の一のついて搾った油を混ぜたものと、注ぎのささげ物として一ヒンの四分の一のぶどう酒をささげる。</span>
<span className="v" id="v41" data-v="41" data-xref="エゼキエル書 46:13–15; 列王記第一 18:29; 詩篇 141:2"> もう一匹の小羊は夕暮れにささげ、朝の穀物のささげ物と注ぎのささげ物と同様にしなさい。心地よい香り、主への火によるささげ物である。</span>
<span className="v" id="v42" data-v="42" data-xref="出エジプト記 25:22"> これが、あなたがたの代々にわたり、会見の天幕の入り口、主の前で絶えずささげられる全焼のいけにえとなる。そこでわたしはあなたがたと会い、そこであなたに語る。</span>
<span className="v" id="v43" data-v="43" data-xref="列王記第一 8:11; 歴代誌 第二 7:1–3; マラキ書 3:1"> そこでわたしはイスラエルの子らと会う。その場所はわたしの栄光によって聖別される。</span>
<span className="v" id="v44" data-v="44" data-xref="レビ記 21:15; レビ記 22:9; レビ記 22:16"> わたしは会見の天幕と祭壇を聖別する。わたしはまた、アロンとその子らを聖別し、祭司としてわたしに仕えさせる。</span>
<span className="v" id="v45" data-v="45" data-xref="レビ記 26:12; コリント人への第二の手紙 6:16; 出エジプト記 25:8"> わたしはイスラエルの子らの間に住み、彼らの神となる。</span>
<span className="v" id="v46" data-v="46" data-xref="出エジプト記 20:2; エレミヤ書 31:33; エゼキエル書 20:5"> 彼らは、わたしが彼らの間に住むために、エジプトの地から彼らを導き出した、彼らの神、主であることを知るであろう。わたしは彼らの神、主である。</span>
</div>

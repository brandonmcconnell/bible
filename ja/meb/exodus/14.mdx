<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 12:1; 出エジプト記 13:1"> 主はモーセに言われた。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 33:7–8; エレミヤ書 44:1; 出エジプト記 13:17–18"> 「イスラエルの子らに、引き返して、ミグドルと海の間にあるピハヒロテの前、バアル・ツェフォンの向かいに宿営するよう告げなさい。海辺に宿営せよ。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒の働き 4:28; サムエル記第一 23:23; 詩篇 71:11"> ファラオはイスラエルの子らについて、『彼らはあの地で迷っており、荒野が彼らを閉じ込めた』と言うであろう。</span>
<span className="v" id="v4" data-v="4" data-xref="ローマ人への手紙 9:22–23; 出エジプト記 7:5; ローマ人への手紙 9:17"> わたしはファラオの心をかたくなにし、彼に後を追わせる。わたしはファラオとその全軍を通して栄光を現す。エジプト人は、わたしが主であることを知る。」彼らはそのようにした。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="詩篇 105:25; 出エジプト記 12:33; ルカ 11:24–26"> 民が逃げたことがエジプトの王に告げられると、ファラオと家臣たちは民に対して心を変えた。彼らは言った。「私たちは何ということをしたのか。イスラエルを解放し、仕えさせることをやめてしまった。」</span>
<span className="v" id="v6" data-v="6"> 彼は戦車を整え、自分の軍勢を連れて行った。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 15:4; 士師記 4:3; 詩篇 68:17"> 彼は選りすぐりの戦車六百台、およびエジプトのすべての戦車、それらすべての上の指揮官を連れて行った。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 13:17; 民数記 33:3; 申命記 26:8"> 主はエジプトの王ファラオの心をかたくなにされたので、彼はイスラエルの子らを追跡した。イスラエルの子らは堂々と出て行った<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="直訳は「高く上げた手をもって」。反抗的に、あるいは大胆に進み出る様子を表す。">a</a></sup>。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 15:9; ヨシュア記 24:6; 出エジプト記 14:2"> エジプト人は彼らを追跡した。ファラオのすべての馬、戦車、騎兵、軍勢が、海沿いのピハヒロテのそば、バアル・ツェフォンの前で宿営していた彼らに追いついた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ヨシュア記 24:7; 詩篇 34:17; ネヘミヤ記 9:9"> ファラオが近づくと、イスラエルの子らは目を上げた。エジプト人が後ろから迫っていた。彼らはひどく恐れ、主に叫んだ。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 106:7–8; 民数記 14:1–4; 出エジプト記 15:23–24"> 彼らはモーセに言った。「エジプトに墓がないからといって、あなたは私たちを荒野で死なせるために連れて来たのですか。私たちをエジプトから連れ出して、あなたは私たちに何ということをしたのですか。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨナ書 4:3; 出エジプト記 6:9; ヨナ書 4:8"> 私たちがエジプトであなたに言った言葉は、これではありませんでしたか。『私たちを放っておいて、エジプト人に仕えさせなさい』と。エジプト人に仕える方が、荒野で死ぬよりも私たちには良かったのです。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歴代誌 第二 20:17; 歴代誌 第二 20:15; 出エジプト記 14:30"> モーセは民に言った。「恐れてはならない。しっかり立って、主が今日あなたがたのために働かれる救いを見なさい。今日見るエジプト人を、あなたがたは二度と見ることがない。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 3:22; 申命記 20:4; 歴代誌 第二 20:17"> 主があなたがたのために戦われる。あなたがたは静かにしていなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 7:10; エズラ記 10:4–5; ネヘミヤ記 9:9"> 主はモーセに言われた。「なぜわたしに叫ぶのか。イスラエルの子らに前進するように言いなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 7:19; 出エジプト記 4:20; 出エジプト記 4:2"> あなたは杖を上げ、手を海の上に向けて伸ばし、海を分けなさい。イスラエルの子らは海の真ん中を乾いた地として通るであろう。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 14:8; 出エジプト記 14:4; エゼキエル書 34:11"> 見よ、わたしはエジプト人の心をかたくなにし、彼らを後から入らせる。わたしはファラオとその全軍、その戦車と騎兵を通して栄光を現す。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 7:5; 出エジプト記 14:4; 出エジプト記 7:17"> わたしがファラオとその戦車と騎兵を通して栄光を現す時、エジプト人はわたしが主であることを知る。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 63:9; 出エジプト記 32:34; 出エジプト記 23:20–21"> イスラエルの陣営の前を進んでいた神の使いは移動し、彼らの後ろに行った。雲の柱も彼らの前を離れ、彼らの後ろに立った。</span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 8:14; コリント人への第二の手紙 2:15–16; 箴言 4:18–19"> 雲の柱はエジプトの陣営とイスラエルの陣営の間に入り、一方には闇をもたらし、他方には夜を照らした。夜通し、両者が近づくことはなかった。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 63:12; 出エジプト記 15:8; 詩篇 66:6"> モーセが手を海の上に向けて伸ばすと、主は一晩中、強い東風で海を後退させ、海を乾いた地とし、水は分かれた。</span>
<span className="v" id="v22" data-v="22" data-xref="ヘブル人への手紙 11:29; 詩篇 66:6; 出エジプト記 15:19"> イスラエルの子らは海の真ん中を乾いた地として通り、水は彼らの右と左で壁となった。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 15:19; 出エジプト記 14:17; 出エジプト記 15:9"> エジプト人は追跡し、ファラオのすべての馬、戦車、騎兵が彼らの後を追って海の中に入って来た。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 13:21; 詩篇 77:16–19; 出エジプト記 14:25"> 朝の見張り時に、主は火と雲の柱の中からエジプト人の軍勢を見下ろし、エジプト人の軍勢を混乱に陥れられた。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 14:14; 申命記 3:22; ヨブ記 20:24"> 主は戦車の車輪を外し、進みにくくされた。エジプト人は言った。「イスラエルの前から逃げよう。主が彼らのためにエジプトと戦っておられる。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 14:16; 出エジプト記 8:5; ヤコブの手紙 2:13"> 主はモーセに言われた。「手を海の上に向けて伸ばし、水がエジプト人、戦車、騎兵の上に返るようにしなさい。」</span>
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 4:18; 詩篇 78:53; ヘブル人への手紙 11:29"> モーセが手を海の上に伸ばすと、明け方、海は元の勢いに戻った。エジプト人は押し寄せる水に向かって逃げたが、主は彼らを海のただ中に投げ込まれた。</span>
<span className="v" id="v28" data-v="28" data-xref="詩篇 78:53; 詩篇 106:9–11; ハバクク書 3:13"> 水は戻り、彼らの後を追って海に入ったファラオの全軍勢の戦車と騎兵を覆った。一人も残らなかった。</span>
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 14:22; 詩篇 77:19–20; イザヤ書 43:2"> しかしイスラエルの子らは海の真ん中を乾いた地として歩いた。水は彼らの右と左で壁となった。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 106:8; 詩篇 106:10; 詩篇 92:9–11"> こうして、主はその日、イスラエルをエジプト人の手から救われた。イスラエルは海辺にエジプト人の死体を見た。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨハネ 2:11; ヨハネ 11:45; ヨハネ 2:23–25"> イスラエルは、主がエジプト人に行われた大いなる御業を見た。民は主を恐れ、主とそのしもべモーセを信じた。</span>
</div>

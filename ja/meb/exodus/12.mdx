<div className="bp">
<span className="v" id="v1" data-v="1"> 主はエジプトの地でモーセとアロンに言われた。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 13:4; 申命記 16:1; 出エジプト記 34:18"> 「この月を、あなたがたの月々の始まりとしなさい。あなたがたにとって一年の第一の月とする。</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 1:2; コリント人への第一の手紙 5:7; ヨハネ 1:29"> イスラエルの全会衆に告げなさい。『この月の十日に、各人は父祖の家ごとに一匹の小羊を取り、一家族に一匹とする。</span>
<span className="v" id="v4" data-v="4"> 一家族が一匹を食べきれないほど少人数なら、隣家と人数に応じて分けなさい。小羊は、それぞれが食べる量を考えて割り当てる。</span>
<span className="v" id="v5" data-v="5" data-xref="ペテロの手紙第一 1:18–19; ヘブル人への手紙 9:13–14; マラキ書 1:14"> 小羊は傷のない一歳の雄とし、羊か山羊の群れから取る。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 23:5; 歴代誌 第二 30:15–18; 民数記 28:16"> この月の十四日まで取っておき、イスラエルの全会衆が夕暮れにそれを屠る。</span>
<span className="v" id="v7" data-v="7" data-xref="ヘブル人への手紙 11:28; 出エジプト記 12:22–23; ヘブル人への手紙 9:22"> その血を取り、それを食べる家の二本の門柱と鴨居に塗る。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 34:25; 申命記 16:7; 出エジプト記 13:3"> その夜、肉を火で焼き、種なしパンと苦菜を添えて食べる。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 12:8; 申命記 16:7; 哀歌 1:13"> 生のまま、または水で煮て食べてはならない。頭も足も内臓も一緒に、火で焼く。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 23:18; 出エジプト記 34:25; 出エジプト記 29:34"> 朝まで少しも残してはならない。朝まで残ったものは火で焼き尽くす。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 12:27; エペソ人への手紙 6:15; コリント人への第一の手紙 5:7"> 腰に帯を締め、足に履き物を履き、手に杖を持ち、急いで食べなさい。これは主の過越である。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 33:4; 出エジプト記 12:23; 詩篇 82:6"> その夜、わたしはエジプトの地を巡り、人から家畜に至るまで、すべての長子を打つ。エジプトのすべての神々に裁きを下す。わたしは主である。</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 11:28; 出エジプト記 12:23; ヨハネの手紙第一 1:7"> その血は、あなたがたがいる家々において、あなたがたのためのしるしとなる。わたしがその血を見る時、わたしはあなたがたを過ぎ越す。わたしがエジプトの地を打つ時、あなたがたを滅ぼす災いはあなたがたの上に臨まない。</span>
<span className="v" id="v14" data-v="14" data-xref="列王記第二 23:21; 出エジプト記 12:24; 出エジプト記 13:9–10"> この日をあなたがたの記念の日とし、主への祭りとして祝いなさい。代々にわたり、永遠の掟として祝う。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 17:14; 申命記 16:3; 出エジプト記 23:15"> 七日間、種なしパンを食べなさい。初日には家からパン種を取り除く。初日から七日目までの間に種入りパンを食べる者は、イスラエルから断たれる。</span>
<span className="v" id="v16" data-v="16" data-xref="レビ記 23:7–8; 民数記 28:18; 出エジプト記 16:23"> 初日と七日目には聖なる集会を開く。これらの日には、各人が食べる物を用意するほか、どんな仕事もしてはならない。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 7:5; 出エジプト記 13:3; 出エジプト記 12:41"> 種なしパンの祭りを守りなさい。まさにこの日に、わたしはあなたがたの軍団をエジプトの地から導き出した。代々にわたり、永遠の掟としてこの日を守る。</span>
<span className="v" id="v18" data-v="18" data-xref="レビ記 23:5–8; 出エジプト記 12:15; 出エジプト記 12:1–2"> 第一の月の十四日の夕暮れから、二十一日の夕暮れまで、種なしパンを食べる。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 12:15; 出エジプト記 23:15; 申命記 16:3"> 七日間、家にパン種が見つかってはならない。種の入ったものを食べる者は、寄留者であれ、その地で生まれた者であれ、イスラエルの会衆から断たれる。</span>
<span className="v" id="v20" data-v="20"> 種の入ったものは一切食べてはならない。どこに住んでいても、種なしパンを食べなさい。』」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 12:3; ルカ 22:7–13; 歴代誌 第二 35:5–6"> そこでモーセはイスラエルのすべての長老たちを呼び寄せて、彼らに言った。「あなたがたの家族のために小羊を選び取って、過越のいけにえを屠りなさい。</span>
<span className="v" id="v22" data-v="22" data-xref="ヘブル人への手紙 11:28; 民数記 19:18; 詩篇 51:7"> ヒソプの束を取り、それを鉢の中の血に浸し、鉢の中の血を鴨居と二つの門柱に付けなさい。あなたがたは誰一人、朝まで自分の家の戸口から出てはならない。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの黙示録 7:3; ヨハネの黙示録 9:4; ヘブル人への手紙 11:28"> 主はエジプト人を打つために通り過ぎられる。鴨居と二本の門柱にある血をご覧になると、その戸口を過ぎ越し、滅ぼす者が家に入ってあなたがたを打つことを許されない。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 12:14; 創世記 17:8–10"> このことを、あなたとあなたの子らのための掟として永遠に守りなさい。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 3:17; 出エジプト記 3:8; 申命記 12:8–9"> 主が約束された地へ導き入れられた時にも、この儀式を守りなさい。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 13:14–15; 申命記 32:7; 詩篇 145:4"> そして、あなたがたの子どもたちがあなたがたに『この儀式にはどのような意味があるのですか』と尋ねる時、</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 4:31; 出エジプト記 12:11; コリント人への第一の手紙 5:7"> 『これは主への過越のいけにえである。主はエジプト人を打たれた時、エジプトにいたイスラエルの子らの家を過ぎ越し、私たちの家を守られた』と答えなさい。」<br />民は頭を下げて礼拝した。</span>
<span className="v" id="v28" data-v="28" data-xref="ヘブル人への手紙 11:28"> イスラエルの子らは行って、そのようにした。主がモーセとアロンに命じられた通りに、彼らは行った。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="詩篇 78:51; 出エジプト記 4:23; 詩篇 105:36"> 真夜中に、主はエジプトの地のすべての長子を打たれた。それは王座に座るファラオの長子から、地下牢にいる捕虜の長子に至るまで、また家畜のすべての初子に及んだ。</span>
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 11:6; アモス書 5:17; 箴言 21:13"> ファラオは夜中に起き上がった。彼も家臣たちも、すべてのエジプト人も起きた。エジプトには大きな叫びが起こった。死人のいない家は一つもなかった。</span>
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 6:1; 出エジプト記 10:9; 出エジプト記 3:19–20"> 彼は夜のうちにモーセとアロンを呼び寄せて言った。「起き上がり、私の民の中から出て行け。おまえたちもイスラエルの子らもだ。行って、おまえたちが言ったように主に仕えよ。</span>
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 10:26; 創世記 27:34; 創世記 27:38"> おまえたちが言ったように、羊の群れも牛の群れも連れて去れ。そして私のことも祝福してくれ。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="詩篇 105:38; 出エジプト記 11:1; 創世記 20:3"> エジプト人は民を急き立て、急いでその地から送り出そうとした。「さもなければ、私たちはみな死んでしまう」と言ったのである。</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 8:3"> 民はパン種が入る前のパン生地を取り、こね鉢を衣服に包んで肩に担いだ。</span>
<span className="v" id="v35" data-v="35" data-xref="出エジプト記 3:21–22; 出エジプト記 11:2–3; 創世記 15:14"> イスラエルの子らはモーセの言葉通りに行い、エジプト人から銀の飾り、金の飾り、衣服を求めた。</span>
<span className="v" id="v36" data-v="36" data-xref="創世記 15:14; 使徒の働き 7:10; 出エジプト記 3:21–22"> 主が、民がエジプト人の目に好意を得るようにされたので、彼らは民の求めるものを与えた。こうして彼らはエジプト人から奪い取った。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="民数記 1:46; 出エジプト記 38:26; 民数記 33:3"> イスラエルの子らはラメセスからスコテへと旅立った。子どもたちを除いて、徒歩の男たちは約六十万人であった。</span>
<span className="v" id="v38" data-v="38" data-xref="民数記 11:4; ゼカリヤ書 8:23"> 多くの入り混じった群衆も彼らと共に上り、羊の群れ、牛の群れ、さらに非常に多くの家畜も共に行った。</span>
<span className="v" id="v39" data-v="39" data-xref="出エジプト記 11:1; 出エジプト記 6:1; 出エジプト記 12:31–33"> 彼らはエジプトから持ち出した生地で、種なしのパン菓子を焼いた。追い出されて待つことができず、自分たちの食料を準備する暇もなかったので、生地にはパン種が入っていなかった。</span>
<span className="v" id="v40" data-v="40" data-xref="創世記 15:13; 使徒の働き 7:6; 使徒の働き 13:17"> イスラエルの子らがエジプトに住んでいた期間は四百三十年であった。</span>
<span className="v" id="v41" data-v="41" data-xref="ハバクク書 2:3; ヨハネ 7:8; 使徒の働き 1:7"> 四百三十年が終わったまさにその日に、主のすべての軍団はエジプトの地から出て行った。</span>
<span className="v" id="v42" data-v="42" data-xref="申命記 16:1–6; 出エジプト記 12:14; 出エジプト記 13:10"> その夜は、主が彼らをエジプトの地から導き出されたことを覚えて守る夜であった。これはイスラエルの子らが代々にわたり守る、主の夜である。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="出エジプト記 12:48; 民数記 9:14; 出エジプト記 12:11"> 主はモーセとアロンに言われた。「過越についての掟は次の通りである。外国人は誰もこれを食べてはならない。</span>
<span className="v" id="v44" data-v="44" data-xref="創世記 17:12–13; 創世記 17:23"> 金で買った奴隷は、割礼を施した後で食べることができる。</span>
<span className="v" id="v45" data-v="45" data-xref="レビ記 22:10; エペソ人への手紙 2:12"> 滞在している外国人や雇い人は、これを食べてはならない。</span>
<span className="v" id="v46" data-v="46" data-xref="民数記 9:12; ヨハネ 19:36; ヨハネ 19:33"> 一つの家の中で食べなさい。肉を家の外へ持ち出してはならない。骨を一本も折ってはならない。</span>
<span className="v" id="v47" data-v="47" data-xref="出エジプト記 12:6; 民数記 9:13; 出エジプト記 12:3"> イスラエルの全会衆がこれを守る。</span>
<span className="v" id="v48" data-v="48" data-xref="民数記 9:14; コロサイ人への手紙 3:11; ガラテヤ人への手紙 3:28"> 寄留者があなたと共に住み、主への過越を守りたいと願うなら、その家の男子はみな割礼を受けなければならない。その後で近づいて守ることができ、その地で生まれた者と同じになる。割礼を受けていない者は誰も食べてはならない。</span>
<span className="v" id="v49" data-v="49" data-xref="民数記 15:15–16; 民数記 15:29; レビ記 24:22"> その地で生まれた者にも、あなたがたの間に寄留する者にも、同じ一つの律法がある。」</span>
<span className="v" id="v50" data-v="50" data-xref="マタイ 7:24–25; 出エジプト記 6:26; 出エジプト記 7:4"> イスラエルの子らは皆、そのようにした。主がモーセとアロンに命じられた通りに彼らは行った。</span>
<span className="v" id="v51" data-v="51" data-xref="出エジプト記 12:41; 出エジプト記 6:26"> まさにその日、主はイスラエルの子らをその軍団ごとにエジプトの地から導き出された。</span>
</div>

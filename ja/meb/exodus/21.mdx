<span className="v" id="v1" data-v="1" data-xref="申命記 4:14; 申命記 6:20; 出エジプト記 24:3–4"> 「あなたが彼らの前に示す定めは、次の通りである。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 15:12–15; 出エジプト記 12:44; 申命記 15:18"> あなたがヘブル人の奴隷を買う場合、彼は六年間仕え、七年目には無償で自由の身となって出て行く。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 15:12–14"> もし彼がひとりで来たなら、ひとりで出て行く。もし彼が妻帯者であれば、妻は彼と共に出て行く。</span>
<span className="v" id="v4" data-v="4"> もし主人が彼に妻を与え、彼女が彼に息子や娘を産んだ場合、その妻と子どもたちは主人のものとなり、彼はひとりで出て行く。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 5:14–15; 申命記 15:16–17; イザヤ書 26:13"> しかし、もしその奴隷がはっきりと『私は主人と、妻と、子どもたちを愛している。自由の身となって出て行くことはしない』と言うなら、</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 15:17; レビ記 25:40; 申命記 19:17–18"> 主人は彼を神のもとに連れて行き、戸口か門柱に連れて行く。そして主人はきりで彼の耳を突き通し、彼は永遠に主人に仕える。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ネヘミヤ記 5:5; 出エジプト記 21:2–3"> 人が娘を女奴隷として売った場合、彼女は男奴隷のように出て行くことはない。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 28:8; 申命記 20:7; マラキ書 2:11–15"> 自分の妻と定めた主人が彼女を気に入らないなら、彼女が贖い出されることを認めなさい。主人は彼女を裏切ったので、外国の民に売る権利はない。</span>
<span className="v" id="v9" data-v="9"> 主人が彼女を自分の息子の妻とするなら、娘として扱う。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 7:1–6"> 主人が別の妻をめとっても、彼女の食物、衣服、夫婦としての権利を減らしてはならない。</span>
<span className="v" id="v11" data-v="11"> これら三つを与えないなら、彼女は金を払わず、自由の身となって出て行く。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 9:6; マタイ 26:52; レビ記 24:17"> 人を打って死なせた者は、必ず死刑に処せられる。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨシュア記 20:2–9; サムエル記第一 24:18; 申命記 4:41–43"> しかし故意でなく、神がそのことの起こるのを許されたのであれば、わたしは彼が逃れる場所を定める。</span>
<span className="v" id="v14" data-v="14" data-xref="列王記第一 2:28–34; ヘブル人への手紙 10:26; 民数記 15:30–31"> 人が悪意をもって隣人を襲い、故意に殺したなら、わたしの祭壇からでも連れ出して死刑に処しなさい。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命記 21:18–21; 箴言 30:17; テモテへの手紙第一 1:9"> 自分の父や母を打つ者は、必ず死刑に処せられる。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 24:7; テモテへの手紙第一 1:10; 出エジプト記 22:4"> 人を誘拐し、彼を売る者、あるいは彼を自分の手元に置いているのが見つかった者は、必ず死刑に処せられる。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="箴言 20:20; マルコ 7:10–11; 申命記 27:16"> 自分の父や母をのろう者は、必ず死刑に処せられる。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 21:20; 申命記 25:11; サムエル記第二 14:6"> 男たちが争い、一方が他方を石かこぶしで打ち、その人が死なずに床に伏せ、</span>
<span className="v" id="v19" data-v="19" data-xref="サムエル記第二 3:29; ゼカリヤ書 8:4"> その人が起き上がり、杖をついて外を歩けるようになれば、打った者は罰を免れる。ただし、働けなかった期間の損失を償い、完全に治るまで治療の費用を負担する。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="箴言 29:19; 申命記 19:21; 民数記 35:19"> 人が自分の男奴隷や女奴隷を杖で打ち、その者が彼の手の下で死んだ場合、彼は必ず罰せられる。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 25:44–46"> しかし、その奴隷が一日か二日後まで生きているなら、主人は罰せられない。その奴隷は主人の財産だからである。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命記 22:18–19; 出エジプト記 21:30; 申命記 16:18"> 男たちが争って身重の女を傷つけ、子を早く産ませたが、ほかに害がなければ、加害者は女の夫が要求し、裁判官が認める罰金を払う。</span>
<span className="v" id="v23" data-v="23" data-xref="申命記 19:21; 民数記 35:31; レビ記 24:19"> しかし、害が生じたなら、命には命、</span>
<span className="v" id="v24" data-v="24" data-xref="申命記 19:21; マタイ 5:38–40; マタイ 7:2"> 目には目、歯には歯、手には手、足には足、</span>
<span className="v" id="v25" data-v="25"> やけどにはやけど、傷には傷、打ち身には打ち身をもって償う。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 21:20; ヨブ記 31:13–15; 詩篇 72:12–14"> 人が男奴隷または女奴隷の目を打ってつぶしたなら、その目の償いとして奴隷を自由にしなさい。</span>
<span className="v" id="v27" data-v="27"> 男奴隷または女奴隷の歯を打ち折ったなら、その歯の償いとして奴隷を自由にしなさい。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 21:32; レビ記 20:15–16; 創世記 9:5–6"> 牛が男や女を角で突いて死なせた場合、その牛は必ず石で打ち殺され、その肉は食べてはならない。しかし牛の持ち主は責任を問われない。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 21:1–9"> しかし、もしその牛に以前から角で突く癖があり、その持ち主が警告されていたにもかかわらず、それをつないでおかず、それが男や女を殺したなら、その牛は石で打ち殺され、その持ち主も死刑に処せられる。</span>
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 21:22; 出エジプト記 30:12; 民数記 35:31–33"> 持ち主に身代金が課せられたなら、自分の命の贖いとして、課せられた額をすべて支払う。</span>
<span className="v" id="v31" data-v="31"> それが息子を突いた場合でも、娘を突いた場合でも、この定めに従って彼に行われる。</span>
<span className="v" id="v32" data-v="32" data-xref="マタイ 26:15; ゼカリヤ書 11:12–13; マタイ 27:3–9"> 牛が男奴隷または女奴隷を突いたなら、牛の持ち主は奴隷の主人に銀三十シェケル<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一シェケルは約十グラム、すなわち約〇・三五オンスである。したがって三十シェケルは約三百グラム、すなわち約一〇・六オンスである。">a</a></sup>を払い、牛は石で打ち殺す。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="箴言 28:10; エレミヤ書 18:20; 伝道者の書 10:8"> 人が穴を開けるか、あるいは穴を掘ってそれに覆いをせず、そこに牛やろばが落ちた場合、</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 22:6; 出エジプト記 21:29–30; 出エジプト記 22:14"> 穴の持ち主は損害を償い、動物の持ち主に代金を払う。死んだ動物は穴の持ち主のものとなる。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35"> ある人の牛が他の人の牛を傷つけ、それが死んだ場合、彼らは生きている牛を売り、その代金を分け合う。また、死んだ動物も分け合う。</span>
<span className="v" id="v36" data-v="36"> その牛に以前から人を突く癖があり、持ち主がつないでおかなかったことが知られているなら、生きた牛をもって死んだ牛を償う。死んだ牛は彼のものとなる。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに言われた。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 26:30; 出エジプト記 13:4; 民数記 7:1"> 「第一の月の一日に、会見の天幕である幕屋を建てなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 35:12; 民数記 4:5; ヨハネの黙示録 11:19"> あなたはその中にあかしの箱を置き、垂れ幕でその箱を覆いなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 24:8; 出エジプト記 40:22–25; 出エジプト記 37:10–24"> あなたは机を運び入れ、その上のものを整えなさい。燭台を運び入れ、そのともしびに火をともしなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 10:19–22; ヘブル人への手紙 9:24; ヨハネの手紙第一 2:1–2"> あなたは香をたく金の祭壇をあかしの箱の前に置き、幕屋の入り口の幕を掛けなさい。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 40:29; ヨハネの手紙第一 4:9–10; ヘブル人への手紙 13:10"> あなたは全焼のいけにえの祭壇を、会見の天幕である幕屋の入り口の前に置きなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="ゼカリヤ書 13:1; ヨハネの手紙第一 1:7; 詩篇 26:6"> あなたは洗盤を会見の天幕と祭壇の間に置き、その中に水を入れなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 40:33; エペソ人への手紙 4:11–12; マタイ 16:18"> あなたはその周囲に庭を設け、庭の入り口に幕を掛けなさい。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="レビ記 8:10; 民数記 7:1; マタイ 3:16"> あなたは注ぎ油を取り、幕屋とその中にあるすべてのものに油を注いで聖別しなさい。そのすべての器具も聖別しなさい。そうすれば、それは聖なるものとなる。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 29:36–37; ルカ 1:35; イザヤ書 61:1"> あなたは全焼のいけにえの祭壇と、そのすべての器具に油を注ぎ、その祭壇を聖別しなさい。そうすれば、祭壇は最も聖なるものとなる。</span>
<span className="v" id="v11" data-v="11"> あなたは洗盤とその台に油を注ぎ、それを聖別しなさい。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="レビ記 8:1–13; レビ記 9:1–24; 出エジプト記 29:1–35"> アロンとその子らを会見の天幕の入り口へ連れて来て、水で洗いなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 28:41; ヨハネの手紙第一 2:20; ヨハネの手紙第一 2:27"> あなたはアロンに聖なる衣服を着せなさい。そして彼に油を注いで聖別し、彼が祭司としてわたしに仕えることができるようにしなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 61:10; ローマ人への手紙 8:30; コリント人への第一の手紙 1:30"> その子らを連れて来て、長衣を着せなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 25:13; ヘブル人への手紙 5:1–14; ヘブル人への手紙 8:1–10"> あなたが彼らの父に油を注いだように、彼らにも油を注ぎなさい。彼らが祭司としてわたしに仕えるためである。その注ぎの油は、彼らの代々にわたる永遠の祭司職のためとなる。」</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 4:1; 出エジプト記 40:17–32; 申命記 12:32"> モーセはそのようにした。主が命じられた通り、すべてを行った。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民数記 7:1; 出エジプト記 40:1–2; 民数記 9:1"> 第二年の第一の月、その月の最初の日に、幕屋は建てられた。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 37:27–28; ペテロの手紙第一 1:5; レビ記 26:11"> モーセは幕屋を建て、その台座を置き、その板を立て、その横木を通し、その柱を立てた。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 26:1–14; 出エジプト記 36:8–19"> 主がモーセに命じられた通りに、彼は天幕の上に覆いを広げ、その上に幕屋の屋根を掛けた。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 16:34; 申命記 10:5; ヘブル人への手紙 10:19–21"> あかしを箱に納め、担ぎ棒を付け、箱の上に贖いの座を置いた。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 26:33; 出エジプト記 40:3; 出エジプト記 35:12"> 主がモーセに命じられた通りに、彼は箱を幕屋に運び入れ、仕切りの垂れ幕を掛け、あかしの箱を覆った。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 26:35; ヨハネ 6:53–57; エペソ人への手紙 3:8"> 彼は会見の天幕の、幕屋の北側、垂れ幕の外側に机を置いた。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 25:30; 出エジプト記 40:4; ヘブル人への手紙 9:2"> 主がモーセに命じられた通りに、彼は主の前の机の上にパンを整えた。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 26:35; ヨハネの黙示録 2:5; ヨハネ 1:1"> 彼は会見の天幕の、幕屋の南側、机の向かい側に燭台を置いた。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 40:4; 出エジプト記 25:37; ヨハネの黙示録 4:5"> 主がモーセに命じられた通り、主の前でともしびをともした。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 40:5; ヘブル人への手紙 7:25; ヨハネ 11:42"> 彼は会見の天幕の、垂れ幕の前に金の祭壇を置き、</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 30:7"> 主がモーセに命じられた通りに、その上で香りのよい香をたいた。</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 40:5; ヘブル人への手紙 10:19–20; エペソ人への手紙 2:18"> 彼は幕屋の入り口に幕を掛けた。</span>
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 40:6; ヘブル人への手紙 13:5–6; ヘブル人への手紙 13:10"> 主がモーセに命じられた通りに、彼は全焼のいけにえの祭壇を、会見の天幕である幕屋の入り口の前に置き、その上で全焼のいけにえと穀物のささげ物をささげた。</span>
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 40:7; 出エジプト記 38:8; エゼキエル書 36:25"> 彼は会見の天幕と祭壇の間に洗盤を置き、洗うためにその中に水を入れた。</span>
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 30:19–20; 詩篇 26:6; ヨハネ 13:10"> モーセ、アロン、およびその子らは、そこで手と足を洗った。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 73:19; 出エジプト記 30:19–20; 出エジプト記 40:19"> 主がモーセに命じられた通りに、彼らが会見の天幕に入る時、また祭壇に近づく時に、彼らは洗った。</span>
<span className="v" id="v33" data-v="33" data-xref="出エジプト記 40:8; 出エジプト記 27:9–16; ヨハネ 17:4"> 彼は幕屋と祭壇の周囲に庭を設け、庭の入り口の幕を掛けた。こうしてモーセはその仕事を終えた。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="ヨハネの黙示録 15:8; 民数記 9:15–23; 歴代誌 第二 7:2"> その時、雲が会見の天幕を覆い、主の栄光が幕屋に満ちた。</span>
<span className="v" id="v35" data-v="35" data-xref="列王記第一 8:11; レビ記 16:2; 歴代誌 第二 7:2"> 雲がその上にとどまり、主の栄光が幕屋に満ちていたので、モーセは会見の天幕に入ることができなかった。</span>
<span className="v" id="v36" data-v="36" data-xref="ネヘミヤ記 9:19; 民数記 9:17; 出エジプト記 13:21–22"> 雲が幕屋の上から取り上げられる時、イスラエルの子らはいつも旅立った。</span>
<span className="v" id="v37" data-v="37" data-xref="民数記 9:19–22; 詩篇 31:15"> しかし、雲が取り上げられない時は、それが取り上げられる日まで彼らは旅立たなかった。</span>
<span className="v" id="v38" data-v="38" data-xref="詩篇 78:14; 民数記 9:15; 出エジプト記 13:21"> 昼は主の雲が幕屋の上にあり、夜は雲の中に火があった。イスラエルの全家は、すべての旅路でこれを目の当たりにした。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 34:32; 出エジプト記 31:1–11; ローマ人への手紙 2:13"> モーセはイスラエルの子らの全会衆を集め、言った。「主が行うよう命じられたことは、次の通りである。</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 23:3; ルカ 13:14–15; 出エジプト記 20:9–10"> 六日間は仕事をしてもよいが、七日目はあなたがたにとって聖なる日であり、主への全き休みの安息日である。この日に仕事をする者はみな死刑に処せられる。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 16:23; 民数記 15:32–36; 出エジプト記 12:16"> 安息日には、あなたがたのどの住まいでも火をたいてはならない。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 25:1–2"> モーセはイスラエルの子らの全会衆に告げた。「主が命じられたことは、次の通りである。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 9:7; 詩篇 110:3; 出エジプト記 25:2–7"> あなたがたの中から主へのささげ物を取りなさい。心から進んで献げる者は、主へのささげ物として金、銀、青銅、</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 26:7–14; 出エジプト記 26:31; 出エジプト記 28:15"> 青色、紫色、緋色の糸、撚り糸で織った亜麻布、山羊の毛、</span>
<span className="v" id="v7" data-v="7"> 赤く染めた雄羊の皮、ジュゴンの皮、アカシアの木、</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 27:20; 出エジプト記 25:1–40; 出エジプト記 30:23"> 灯火のための油、注ぎ油と香りのよい香のための香料、</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 39:6–14; 出エジプト記 28:9; 出エジプト記 25:5"> 縞めのう、そしてエポデや胸当てにはめ込むための宝石である。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 31:1–6; 出エジプト記 36:1–4"> あなたがたのうち心に知恵のある者はみな来て、主が命じられたものをすべて造りなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 26:1–37; 出エジプト記 36:8–34; 出エジプト記 31:7–9"> 幕屋、その天幕、その覆い、その留め金、その板、その横木、その柱、その台座、</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 25:10–22; 出エジプト記 26:31–33; 出エジプト記 37:1–9"> 箱とその担ぎ棒、贖いの座、仕切りの垂れ幕、</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 25:23–30; レビ記 24:5–6; 出エジプト記 37:10–16"> 机とその担ぎ棒、そのすべての器具、供えのパン、</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 25:31–39; マタイ 5:14–15; 出エジプト記 37:17–24"> 灯火のための燭台とその器具、そのともしび、灯火のための油、</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 30:1–10; 出エジプト記 30:22–38; 出エジプト記 37:25–28"> 香の祭壇とその担ぎ棒、注ぎ油、香りのよい香、幕屋の入り口の幕、</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 27:1–8; 出エジプト記 30:18–21; 出エジプト記 38:1–8"> 全焼のいけにえの祭壇と青銅の格子、その担ぎ棒、そのすべての器具、洗盤とその台、</span>
<span className="v" id="v17" data-v="17" data-xref="サムエル記第二 7:2; 出エジプト記 38:9–20; 出エジプト記 27:9–19"> 庭の幕、その柱、その台座、庭の入り口の幕、</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 27:19"> 幕屋の釘、庭の釘とそれらのひも、</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 31:10; 民数記 4:5–15; 出エジプト記 28:1–43"> 聖所で仕えるための精巧に織られた衣服、すなわち祭司アロンのための聖なる衣服と、その子らが祭司として仕えるための衣服である。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> イスラエルの子らの全会衆は、モーセの前から退出した。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 25:2; 出エジプト記 35:26; 歴代誌上 29:14"> 心を動かされ、霊に促された者はみな来て、会見の天幕の仕事、そのすべての奉仕、聖なる衣服のために、主へのささげ物を持って来た。</span>
<span className="v" id="v22" data-v="22" data-xref="ネヘミヤ記 7:70–72; マタイ 2:11; エズラ記 2:68–69"> 男も女も、心から進んで献げる者はみな、留め金、耳輪、指輪、腕輪など、あらゆる金の飾り物を持って来た。金を主へのささげ物として献げる者は、みな持って来た。</span>
<span className="v" id="v23" data-v="23" data-xref="歴代誌上 29:8; 出エジプト記 25:2–7; 出エジプト記 35:6–10"> 青色、紫色、緋色の糸、撚り糸で織った亜麻布、山羊の毛、赤く染めた雄羊の皮、ジュゴンの皮を持っている者もみな、それらを持って来た。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第二の手紙 8:12"> 銀や青銅のささげ物をささげる者はみな、それを主へのささげ物として持って来た。奉仕のあらゆる仕事に用いるアカシアの木を持っている者もみな、それを持って来た。</span>
<span className="v" id="v25" data-v="25" data-xref="ローマ人への手紙 16:12; ルカ 8:2–3; 箴言 14:1"> 心に知恵のある女たちはみな手で糸を紡ぎ、青色、紫色、緋色の糸と、撚り糸で織った亜麻布を持って来た。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 35:21; 出エジプト記 36:8; 出エジプト記 35:29"> 知恵に心を動かされた女たちは、山羊の毛を紡いだ。</span>
<span className="v" id="v27" data-v="27" data-xref="エズラ記 2:68; 歴代誌上 29:6; 出エジプト記 35:9"> 指導者たちは、縞めのうと、エポデや胸当てにはめ込むための宝石を持って来た。</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 30:23–38; 出エジプト記 35:8"> また、香料と、灯火のため、注ぎ油のため、香りのよい香のための油も持って来た。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第二の手紙 9:7; 出エジプト記 35:21–22; 出エジプト記 35:4"> イスラエルの子らは、男も女も、主がモーセを通して命じられた仕事のため、心から進んで持って来ようとする者がみな、主への自発のささげ物を持って来た。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 31:1–6; ヤコブの手紙 1:17; コリント人への第一の手紙 12:11"> モーセはイスラエルの子らに言った。「見よ、主はユダ部族のフルの子であるウリの子ベツァルエルを名指しで呼ばれた。</span>
<span className="v" id="v31" data-v="31" data-xref="ヤコブの手紙 1:17; イザヤ書 11:2–5; イザヤ書 61:1–3"> 彼を神の霊で満たし、知恵、英知、知識、あらゆる職人の技を授けられた。</span>
<span className="v" id="v32" data-v="32"> それは巧みな意匠を考案し、金、銀、青銅で細工をし、</span>
<span className="v" id="v33" data-v="33"> はめ込み用の石を切り、木を彫り、あらゆる種類の巧みな職人の技で仕事をするためである。</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 31:6; 歴代誌 第二 2:14; エズラ記 7:27"> 主は、彼とダン部族のアヒサマクの子オホリアブに、人を教える力も授けられた。</span>
<span className="v" id="v35" data-v="35" data-xref="出エジプト記 35:31; 列王記第一 7:14; イザヤ書 28:26"> 主は二人を知恵で満たし、彫刻師、熟練した職人、青色、紫色、緋色の糸と亜麻布を用いる刺繍師、機織りなど、あらゆる仕事を行い、巧みな意匠を考案できるようにされた。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨハネの黙示録 8:3; 出エジプト記 37:25–28; 出エジプト記 40:5"> 香をたく祭壇をアカシアの木で造りなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 27:2"> 長さと幅は一キュビト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一キュビトは、大人の腕の中指の先から肘までの長さで、約十八インチ、すなわち約四十六センチメートルである。">a</a></sup>の正方形、高さは二キュビトとし、角は祭壇と一体にする。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 25:11; 出エジプト記 25:24"> その上面、周囲の側面、およびその角に純金をかぶせなさい。そしてその周囲に金の飾り縁を造りなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 25:27; 出エジプト記 26:29; 出エジプト記 27:7"> 飾り縁の下、両側の側面に二つの金の環を造り、祭壇を担ぐ棒を通す場所としなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 25:13; 出エジプト記 25:27"> アカシアの木で担ぎ棒を造り、金をかぶせなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 25:21–22; 出エジプト記 30:36; レビ記 16:13"> あかしの箱のそばにある垂れ幕の手前、わたしがあなたと会うあかしの上にある贖いの座の前にそれを置きなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記第一 2:28; 歴代誌上 23:13; 出エジプト記 27:20–21"> アロンは毎朝、ともしびを整える時、その上で香りのよい香をたく。</span>
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 9:24; テサロニケ人への手紙第一 5:17; ヘブル人への手紙 7:25"> 夕暮れにともしびをともす時にも香をたく。これは代々にわたり、主の前で絶えずたく香である。</span>
<span className="v" id="v9" data-v="9" data-xref="レビ記 10:1"> あなたがたは、その上で異なった香をたいたり、全焼のいけにえや穀物のささげ物をささげたりしてはならない。また、その上に注ぎのささげ物を注いではならない。</span>
<span className="v" id="v10" data-v="10" data-xref="レビ記 16:18; ヘブル人への手紙 9:22–23; レビ記 16:29–30"> アロンは年に一度、その角の上で贖いを行う。贖いのための罪のいけにえの血を用い、代々にわたり年に一度、祭壇の贖いを行う。これは主にとって最も聖なるものである。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 主はモーセに言われた。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 31:50; 歴代誌上 27:24; 出エジプト記 38:25–26"> 「イスラエルの子らの人口を数える時、数えられる者はそれぞれ、自分の命の贖い金を主に納めなければならない。彼らを数える時、彼らの間に災いが起こらないためである。</span>
<span className="v" id="v13" data-v="13" data-xref="レビ記 27:25; 民数記 3:47; エゼキエル書 45:12"> 数えられる者はみな、聖所のシェケル<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一シェケルは約十グラム、すなわち約〇・三五オンスである。">b</a></sup>で半シェケルを納める。一シェケルは二十ゲラ<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一ゲラは約〇・五グラム、すなわち約七・七グレーンである。">c</a></sup>である。半シェケルを主へのささげ物とする。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 1:20; 民数記 1:18; 民数記 1:3"> 数えられる二十歳以上の者はみな、主へのささげ物を納める。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 31:50; レビ記 17:11; 出エジプト記 30:12"> あなたがたの命を贖うため、主へのささげ物を納める時、富む者も半シェケル<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一シェケルは約十グラム、すなわち約〇・三五オンスである。">d</a></sup>より多く納めてはならず、貧しい者もそれより少なく納めてはならない。</span>
<span className="v" id="v16" data-v="16" data-xref="ネヘミヤ記 10:32–33; 民数記 16:40; 出エジプト記 38:25–31"> イスラエルの子らから贖いの銀を受け取り、会見の天幕の奉仕に用いなさい。それは主の前でイスラエルの子らの記念となり、あなたがたの命を贖うものとなる。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 主はモーセに言われた。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 40:7; 出エジプト記 38:8; 列王記第一 7:23"> 「洗うための青銅の洗盤と、青銅のその台を造りなさい。それを会見の天幕と祭壇の間に置き、その中に水を入れなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 52:11; 出エジプト記 40:31–32; 詩篇 26:6"> アロンとその子らは、そこで手と足を洗う。</span>
<span className="v" id="v20" data-v="20" data-xref="レビ記 10:1–3; ヘブル人への手紙 12:28–29; 歴代誌上 13:10"> 会見の天幕に入る時、また祭壇に近づいて主への火によるささげ物を焼く時、水で洗い、死ぬことのないようにする。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 28:43; 出エジプト記 27:21"> 手と足を洗い、死ぬことのないようにする。これはアロンとその子孫に対する、代々にわたる永遠の掟である。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> さらに主はモーセに言われた。</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 27:19; 雅歌 4:14; エゼキエル書 27:22"> 「また、最上の香料を取りなさい。液体の没薬を五百シェケル<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一シェケルは約10グラム、すなわち約0.35オンスである。したがって500シェケルは約5キログラム、すなわち約11ポンドである。">e</a></sup>、香りのよい肉桂をその半分の二百五十、香りのよい菖蒲を二百五十、</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 45:8; 出エジプト記 29:40; 民数記 3:47"> 桂皮を聖所のシェケルに従って五百、そしてオリーブ油を一ヒン<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="1ヒンは約6.5リットル、あるいは1.7ガロンである。">f</a></sup>取りなさい。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 37:29; 歴代誌上 9:30; 出エジプト記 40:9"> 香料作りの技法によって調合し、聖なる注ぎ油を造りなさい。</span>
<span className="v" id="v26" data-v="26" data-xref="民数記 7:1; ヨハネの手紙第一 2:20; イザヤ書 61:1"> これを用いて、会見の天幕、あかしの箱、</span>
<span className="v" id="v27" data-v="27"> 机とそのすべての器具、燭台とその付属物、香の祭壇、</span>
<span className="v" id="v28" data-v="28"> 全焼のいけにえの祭壇とそのすべての器具、洗盤とその台に油を注ぎなさい。</span>
<span className="v" id="v29" data-v="29" data-xref="マタイ 23:19; 出エジプト記 29:37; レビ記 6:18"> それらを聖別し、最も聖なるものとしなさい。それに触れるものはみな聖なるものとなる。</span>
<span className="v" id="v30" data-v="30" data-xref="レビ記 8:12; 出エジプト記 28:3; レビ記 8:30"> アロンとその子らに油を注いで聖別し、祭司としてわたしに仕えさせなさい。</span>
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 37:29; レビ記 21:10; 詩篇 89:20"> イスラエルの子らに告げなさい。『これは代々にわたり、わたしのための聖なる注ぎ油である。</span>
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 30:25; 出エジプト記 30:37–38; レビ記 21:10"> 人の体に注いではならず、同じ配合のものを造ってはならない。これは聖なるものであり、あなたがたも聖なるものとして扱う。</span>
<span className="v" id="v33" data-v="33" data-xref="出エジプト記 30:38; 創世記 17:14; 出エジプト記 12:15"> これに似たものを調合する者、あるいはこれを一般の人に塗る者はみな、その民から断ち切られる。』」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 37:29; 出エジプト記 25:6; 出エジプト記 30:23"> 主はモーセに言われた。「香料を取りなさい。樹脂、オニカ、ガルバヌム、これらの香料と純粋な乳香である。それぞれ同量とする。</span>
<span className="v" id="v35" data-v="35" data-xref="レビ記 2:13; 出エジプト記 30:25; ヨハネ 12:3"> 香料作りの技法に従って、塩を混ぜた、純粋で聖なる香を造りなさい。</span>
<span className="v" id="v36" data-v="36" data-xref="出エジプト記 25:22; 出エジプト記 30:6; 出エジプト記 16:34"> その一部を細かく砕き、それを会見の天幕の中の契約の前に置きなさい。そこでわたしはあなたと会う。それはあなたがたにとって最も聖なるものとなる。</span>
<span className="v" id="v37" data-v="37" data-xref="レビ記 2:3; 出エジプト記 29:37; 出エジプト記 30:32–33"> この配合の香を自分たちのために造ってはならない。主のための聖なるものとしなさい。</span>
<span className="v" id="v38" data-v="38" data-xref="出エジプト記 30:33"> 香りを楽しむためにこれに似たものを造る者はみな、その民から断ち切られる。」</span>
</div>

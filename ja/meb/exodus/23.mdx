<span className="v" id="v1" data-v="1" data-xref="詩篇 101:5; 箴言 19:5; 申命記 19:16–21"> 偽りのうわさを広めてはならない。悪者に手を貸し、悪意ある証人となってはならない。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 1:10–11; 箴言 1:15; ルカ 23:23–24"> 群衆に従って悪を行ってはならない。裁判で群衆に同調して証言し、正義を曲げてはならない。</span>
<span className="v" id="v3" data-v="3" data-xref="ヤコブの手紙 3:17; レビ記 19:15; 詩篇 82:2–3"> 貧しい者だからといって、訴訟で不当に肩入れしてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="申命記 22:1–4; テサロニケ人への手紙第一 5:15; マタイ 5:44"> 敵の牛やろばが迷っているのに出会ったなら、必ずその人のもとへ連れ戻しなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 22:4"> あなたを憎む者のろばが荷の下に倒れているのを見たなら、見捨ててはならない。その人と共に、必ず助け起こしなさい。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="マラキ書 3:5; エレミヤ書 5:28; レビ記 19:15"> 貧しい者の訴訟で、正義を曲げてはならない。</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 4:25; 出エジプト記 34:7; 出エジプト記 23:1"> 偽りの訴えから遠ざかり、罪のない正しい者を殺してはならない。わたしは悪者を義とはしない。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 16:19; 箴言 17:23; イザヤ書 5:23"> 賄賂を受け取ってはならない。賄賂は目の見える者を盲目にし、正しい者の言葉を曲げる。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命記 27:19; 出エジプト記 22:21; 申命記 24:14–18"> 寄留者をしいたげてはならない。あなたがたもエジプトの地で寄留者であったので、寄留者の心を知っている。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="レビ記 25:3–4"> 六年間、土地に種をまき、その収穫を集めなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="レビ記 26:34–35; レビ記 25:2–7; レビ記 25:11–12"> 七年目には耕作をやめ、土地を休ませなさい。あなたの民の貧しい者がそこから食べ、残りを野の動物が食べる。ぶどう園とオリーブ畑についても同じようにする。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ルカ 13:14; 出エジプト記 34:21; 出エジプト記 35:3"> 六日間は仕事をし、七日目には休みなさい。牛とろばが休み、女奴隷の子と寄留者も息をつくことができるためである。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨシュア記 23:7; ゼカリヤ書 13:2; テモテへの手紙第一 4:16"> わたしがあなたがたに言ったすべてのことに注意を払いなさい。他の神々の名を呼び求めてはならない。それがあなたの口から聞かれるようにしてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命記 16:16; 出エジプト記 34:22–24; レビ記 23:34"> 年に三度、わたしのために祭りを祝いなさい。</span>
<span className="v" id="v15" data-v="15" data-xref="ルカ 22:7; 出エジプト記 34:20; 民数記 28:16–25"> 種なしパンの祭りを守りなさい。命じた通り、アビブの月の定められた時に七日間、種なしパンを食べる。この月にあなたはエジプトから出た。誰も手ぶらでわたしの前に出てはならない。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 34:22; 出エジプト記 22:29; レビ記 23:9–21"> 畑にまいた労働の初穂をもって刈り入れの祭りを祝い、年の終わりには、畑から労働の実りを集めて取り入れの祭りを祝いなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 16:16; 出エジプト記 34:23; 出エジプト記 23:14"> 年に三度、男子はみな主なる神の前に出る。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 34:25; レビ記 2:11; 申命記 16:4"> あなたはわたしのいけにえの血を、種入りパンと共に献げてはならない。わたしの祭りの脂肪を、朝まで夜通し残しておいてはならない。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 34:26; 申命記 14:21; 申命記 26:10"> 土地の初穂の最上のものを、あなたの神、主の家へ持って来なさい。子山羊をその母の乳で煮てはならない。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 33:14; 詩篇 91:11; 出エジプト記 32:34"> 見よ、わたしはあなたの前に使いを遣わし、道中であなたを守り、わたしが備えた場所にあなたを導き入れる。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 78:56; 詩篇 78:40; ヘブル人への手紙 12:25"> 彼に心を留め、その声に聞き従いなさい。逆らってはならない。彼はあなたがたの背きを赦さない。わたしの名が彼の内にある。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 12:3; 申命記 30:7; ゼカリヤ書 2:8"> しかし、もしあなたが確かに彼の声に聞き従い、わたしが語るすべてのことを行うなら、わたしはあなたの敵の敵となり、あなたの仇の仇となる。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 23:20; イザヤ書 5:13; 創世記 15:19–21"> わたしの使いはあなたの前を行き、アモリ人、ヘト人、ペリジ人、カナン人、ヒビ人、エブス人の地へ導き入れる。わたしは彼らを断ち切る。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 20:5; 申命記 12:30–31; 民数記 33:52"> 彼らの神々にひれ伏したり、仕えたりしてはならない。その習わしにならってはならない。かえって、それらを徹底して打ち倒し、石の柱を打ち砕きなさい。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 7:15; 出エジプト記 15:26; ヨシュア記 22:5"> あなたがたの神、主に仕えなさい。主はパンと水を祝福される。わたしはあなたがたの中から病を取り除く。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 7:14; ヨブ記 5:26; 申命記 28:4"> あなたの地には流産する者も、不妊の者もいなくなる。わたしはあなたの日数を満たす。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 2:25; 創世記 35:5; 申命記 11:25"> わたしはあなたの前に恐怖を送り、あなたが行く先のすべての民を混乱させる。敵はみな、あなたに背を向けて逃げる。</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 7:20; ヨシュア記 24:11–12"> わたしはあなたの前にスズメバチを送り、ヒビ人、カナン人、ヘト人をあなたの前から追い出させる。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 7:22; ヨシュア記 17:12–13; 士師記 3:1–4"> わたしは一年で彼らをあなたの前から追い出すことはしない。地が荒れ果て、野の動物があなたに対して増えすぎないためである。</span>
<span className="v" id="v30" data-v="30"> あなたがたが増え、その地を受け継ぐまで、わたしは少しずつ彼らをあなたの前から追い出す。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 15:18; 申命記 11:24; ヨシュア記 21:44"> あなたの境界を紅海からペリシテ人の海まで、荒野から大河までとする。わたしはその地の住民をあなたの手に渡す。あなたは彼らを前から追い出しなさい。</span>
<span className="v" id="v32" data-v="32" data-xref="申命記 7:2; 出エジプト記 34:12; 出エジプト記 34:15"> あなたは彼らや彼らの神々と契約を結んではならない。</span>
<span className="v" id="v33" data-v="33" data-xref="詩篇 106:36; 申命記 7:16; 出エジプト記 34:12"> 彼らをあなたの地に住ませてはならない。彼らがあなたに、わたしに対して罪を犯させないためである。もしあなたが彼らの神々に仕えるなら、それは必ずあなたにとって罠となる。」</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 31:10; 出エジプト記 35:23; 出エジプト記 35:19"> 主がモーセに命じられた通り、彼らは青色、紫色、緋色の糸で、聖所の奉仕に用いる精巧な衣服と、アロンの聖なる衣服を造った。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 28:6–12; レビ記 8:7; 出エジプト記 25:7"> 彼は金、青色、紫色、緋色の糸、撚り糸で織った亜麻布でエポデを作った。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 36:8; 出エジプト記 26:1"> 彼らは金をたたいて薄い板にし、それを切り分けて糸にし、熟練した職人の細工として、青色、紫色、緋色の糸、および亜麻布の中に織り込んだ。</span>
<span className="v" id="v4" data-v="4"> 彼らは互いにつながる肩ひもを作り、それは両端でつながれていた。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 1:13; マタイ 28:20; イザヤ書 11:5"> 主がモーセに命じられた通りに、それを結びつけるための、エポデの上にある巧みに織られた帯は、それと同じような細工で、それと一体であった。すなわち、金、青色、紫色、緋色の糸、撚り糸で織った亜麻布で作られた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 28:9; エゼキエル書 28:13; ヨブ記 28:16"> 彼らは縞めのうを金の枠にはめ込み、イスラエルの子らの名前に従って、印章を彫るようにしてそれを彫った。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 4:7; 出エジプト記 28:12; 出エジプト記 28:29"> 主がモーセに命じられた通りに、彼はそれらをエポデの肩ひもに付け、イスラエルの子らのための記念の石とした。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 28:4; レビ記 8:8–9; イザヤ書 59:17"> 彼は熟練した職人の細工として、エポデの細工と同じように胸当てを作った。すなわち、金、青色、紫色、緋色の糸、撚り糸で織った亜麻布で作った。</span>
<span className="v" id="v9" data-v="9"> 胸当ては正方形で、二つ折りにした。長さも幅も一スパン<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一スパンは、大人が手を広げた時の親指の先から小指の先までの長さで、約半キュビト、すなわち約二十二・八センチメートルである。">a</a></sup>であった。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 28:21; 出エジプト記 28:16–17; ヨハネの黙示録 21:19–21"> 彼らはその中に四列の石をはめ込んだ。第一列はルビー、トパーズ、緑柱石の列であった。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 28:18; エゼキエル書 28:13"> 第二列はトルコ石、サファイア<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="あるいは、ラピスラズリ。">b</a></sup>、エメラルドであった。</span>
<span className="v" id="v12" data-v="12"> 第三列はヒヤシンス石、めのう、紫水晶であった。</span>
<span className="v" id="v13" data-v="13"> 第四列はクリソライト、縞めのう、碧玉であった。これらは金の枠にはめ込まれていた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネの黙示録 21:12"> 石はイスラエルの子らの名前に従って十二あり、彼らの名前に従うものであった。印章を彫るように、十二部族のために、それぞれ名前に従って彫られていた。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨハネ 10:28; ヨハネ 17:12; ペテロの手紙第一 1:5"> 彼らは胸当ての上に、純金で撚り合わせた編んだひものような鎖を作った。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 25:12"> 彼らは二つの金の枠と二つの金の環を作り、その二つの環を胸当ての両端に取り付けた。</span>
<span className="v" id="v17" data-v="17"> 彼らはその二つの金の編んだ鎖を、胸当ての端にある二つの環に通した。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 28:14; 雅歌 1:10"> 二つの編んだ鎖の他の二つの端を、彼らは二つの枠に取り付け、それをエポデの前面の肩ひもに取り付けた。</span>
<span className="v" id="v19" data-v="19"> 彼らは二つの金の環を作り、胸当ての両端、すなわち内側のエポデに向いている側の縁にそれを取り付けた。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 26:3"> 彼らはさらに二つの金の環を作り、それをエポデの二つの肩ひもの下部、前面のつなぎ目の近く、エポデの巧みに織られた帯の上に取り付けた。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイ 16:24; コリント人への第一の手紙 1:25; コリント人への第一の手紙 1:27"> 主がモーセに命じられた通りに、彼らは胸当ての環とエポデの環を青いひもで結びつけ、それがエポデの巧みに織られた帯の上にあり、胸当てがエポデからずれないようにした。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 28:31–35"> 彼はエポデの上着を織物細工で、すべて青色で作った。</span>
<span className="v" id="v23" data-v="23"> その真ん中にある上着の穴は、よろいの穴のようであり、それが裂けないように穴の周囲に縁取りがあった。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 28:33; ガラテヤ人への手紙 5:22"> 彼らは上着の裾に、青色、紫色、緋色の糸、および撚り糸で織った亜麻布でざくろを作った。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 28:33–34; 雅歌 4:13; 詩篇 89:15"> 彼らは純金の鈴を作り、その鈴を上着の裾の周囲にあるざくろとざくろの間に置いた。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 28:34; 雅歌 4:13; 雅歌 6:7"> 主がモーセに命じられた通りに、奉仕のために着る上着の裾の周囲に、鈴とざくろ、鈴とざくろを交互に配置した。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="エゼキエル書 44:18; ペテロの手紙第一 1:13; イザヤ書 61:10"> 彼らはアロンとその子らのために、亜麻布の織物細工で長衣を作った。</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 28:4; エゼキエル書 44:18; 出エジプト記 28:39"> 亜麻布のターバン、亜麻布の頭帯、撚り糸で織った亜麻布の下衣、</span>
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 28:39"> 主がモーセに命じられた通りに、撚り糸で織った亜麻布、青色、紫色、緋色の糸を用いた、刺繍をする者の細工による飾り帯を作った。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ヨハネの黙示録 5:10; ヘブル人への手紙 7:26; ヘブル人への手紙 1:3"> 彼らは純金で聖なる冠の札を造り、印章を彫るように、「主に聖なるもの」と刻んだ。</span>
<span className="v" id="v31" data-v="31"> 主がモーセに命じられた通りに、それに青いひもを結びつけ、上のターバンに取り付けた。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 39:42–43; マタイ 28:20; 出エジプト記 25:40"> こうして、会見の天幕である幕屋のすべての仕事が完成した。イスラエルの子らは、主がモーセに命じられた通り、すべてを行った。</span>
<span className="v" id="v33" data-v="33" data-xref="出エジプト記 35:11–19; 出エジプト記 31:7–11; 出エジプト記 36:1–38"> 彼らは幕屋をモーセのもとに持って来た。天幕とそのすべての器具、その留め金、その板、その横木、その柱、その台座、</span>
<span className="v" id="v34" data-v="34"> 赤く染めた雄羊の皮の覆い、ジュゴンの皮の覆い、仕切りの垂れ幕、</span>
<span className="v" id="v35" data-v="35" data-xref="ヘブル人への手紙 9:5; 出エジプト記 25:17; ヘブル人への手紙 9:8"> 担ぎ棒の付いたあかしの箱、贖いの座、</span>
<span className="v" id="v36" data-v="36" data-xref="出エジプト記 25:30; 列王記第一 7:48"> 机、そのすべての器具、供えのパン、</span>
<span className="v" id="v37" data-v="37" data-xref="ピリピ人への手紙 2:15; 出エジプト記 27:21; マタイ 5:14–16"> 純金の燭台、そのともしび、整えられるべきともしび、そのすべての器具、灯火のための油、</span>
<span className="v" id="v38" data-v="38" data-xref="出エジプト記 30:7; 出エジプト記 37:29; 出エジプト記 30:3"> 金の祭壇、注ぎ油、香りのよい香、天幕の入り口の幕、</span>
<span className="v" id="v39" data-v="39" data-xref="列王記第一 8:64; 出エジプト記 38:30"> 青銅の祭壇、その青銅の格子、担ぎ棒、そのすべての器具、洗盤とその台、</span>
<span className="v" id="v40" data-v="40" data-xref="出エジプト記 27:9–16"> 庭の幕、その柱、その台座、庭の入り口の幕、そのひも、その釘、会見の天幕のための幕屋の奉仕に用いるすべての器具、</span>
<span className="v" id="v41" data-v="41" data-xref="出エジプト記 28:2; 出エジプト記 31:10; 出エジプト記 39:1"> 聖所で仕えるための精巧に織られた衣服、すなわち祭司アロンのための聖なる衣服と、その子らが祭司として仕えるための衣服である。</span>
<span className="v" id="v42" data-v="42" data-xref="出エジプト記 35:10; 出エジプト記 23:21–22; テモテへの第二の手紙 2:15"> 主がモーセに命じられたすべてに従って、イスラエルの子らはそのすべての仕事を行った。</span>
<span className="v" id="v43" data-v="43" data-xref="民数記 6:23–27; レビ記 9:22–23; サムエル記第二 6:18"> モーセがすべての仕事を見ると、彼らは主が命じられた通りに完成させていた。そこでモーセは彼らを祝福した。</span>
</div>

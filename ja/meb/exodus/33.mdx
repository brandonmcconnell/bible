<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="創世記 12:7; 出エジプト記 32:13; 出エジプト記 32:7"> 主はモーセに言われた。「ここを立ち、あなたと、あなたがエジプトの地から導き上った民は、わたしがアブラハム、イサク、ヤコブに『あなたの子孫に与える』と誓った地へ上って行きなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 32:34; ヨシュア記 24:11; 出エジプト記 23:27–31"> わたしはあなたの前に使いを遣わし、カナン人、アモリ人、ヘト人、ペリジ人、ヒビ人、エブス人を追い出す。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 32:9–10; 出エジプト記 3:8; 使徒の働き 7:51"> 乳と蜜の流れる地へ行きなさい。しかし、わたしはあなたがたのただ中を共に上らない。あなたがたはうなじの固い民なので、途中で滅ぼしてしまうかもしれない。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="民数記 14:39; 民数記 14:1; エゼキエル書 26:16"> 民はこの悪い知らせを聞いて嘆き悲しみ、だれも飾り物を身に着けなかった。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民数記 16:21; 民数記 16:45–46; 出エジプト記 33:3–4"> 主はモーセに言われた。「イスラエルの子らに告げなさい。『あなたがたはうなじの固い民である。わたしが一瞬でもただ中を共に上れば、あなたがたを滅ぼすだろう。今、飾り物を外しなさい。それから、あなたがたをどうするか決めよう。』」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 33:4; 出エジプト記 32:3; エレミヤ書 2:19"> それでイスラエルの子らは、ホレブ山を出てから飾り物を身に着けなかった。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 55:6–7; 出エジプト記 29:42–43; 箴言 15:29"> モーセは天幕を取り、陣営の外、陣営から遠く離れた所に張り、「会見の天幕」と呼んだ。主を求める者はみな、陣営の外にある会見の天幕へ出て行った。</span>
<span className="v" id="v8" data-v="8" data-xref="民数記 16:27"> モーセが天幕へ出て行く時は、民は皆立ち上がり、それぞれ自分の天幕の入り口に立って、モーセが天幕に入るまで彼を見送った。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 99:7; 出エジプト記 31:18; 出エジプト記 13:21–22"> モーセが天幕に入ると、雲の柱が降りて天幕の入り口に立ち、主はモーセと語られた。</span>
<span className="v" id="v10" data-v="10" data-xref="列王記第一 8:22; 列王記第一 8:14; 出エジプト記 4:31"> 民は皆、雲の柱が天幕の入り口に立っているのを見た。民は皆立ち上がり、それぞれ自分の天幕の入り口で礼拝した。</span>
<span className="v" id="v11" data-v="11" data-xref="民数記 12:8; 申命記 34:10; 出エジプト記 24:13"> 人が友と語るように、主はモーセと顔を合わせて語られた。モーセは陣営へ戻ったが、従者であるヌンの子ヨシュアという若者は、天幕から離れなかった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 33:17; エレミヤ書 1:5; ヨハネ 10:14–15"> モーセは主に言った。「あなたは私に『この民を導き上れ』と言われますが、誰を共に遣わすのか知らせておられません。それでも、『わたしはあなたを名指しで知り、あなたはわたしの目に恵みを得た』と言われました。</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 119:33; 詩篇 25:4; 詩篇 27:11"> 今、もし私があなたの目に恵みを得ているなら、どうかあなたの道を示してください。私があなたを知り、なお恵みを得るためです。また、この国民があなたの民であることを心に留めてください。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 21:44; マタイ 11:28; ヨシュア記 1:5"> 主は言われた。「わたしの臨在が共に行く。わたしはあなたに安息を与える。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 34:9; 詩篇 4:6; 出エジプト記 33:3"> モーセは言った。「あなたの臨在が共に行かれないなら、私たちをここから上らせないでください。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 4:7; 民数記 14:14; 列王記第一 8:53"> 私とあなたの民が、あなたの目に恵みを得ていることは、何によって知られるのでしょう。あなたが私たちと共に行かれることによってではありませんか。こうして私とあなたの民は、地の面にいるすべての民と区別されるのです。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 65:24; ヨハネの手紙第一 5:14–15; 出エジプト記 33:12"> 主はモーセに言われた。「あなたが語ったこの事も、わたしは行おう。あなたがわたしの目に好意を得ており、わたしがあなたを名指しで知っているからである。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨハネの黙示録 21:23; 出エジプト記 33:20; テトス 2:13"> モーセは言った。「どうか、あなたの栄光を私に見せてください。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 9:15–18; エペソ人への手紙 1:6–8; エレミヤ書 31:14"> 主は言われた。「わたしのすべての良きものをあなたの前に通らせ、あなたの前で主の名を宣言する。わたしは恵もうとする者を恵み、あわれもうとする者をあわれむ。」</span>
<span className="v" id="v20" data-v="20" data-xref="創世記 32:30; ヨハネ 1:18; テモテへの手紙第一 6:16"> また言われた。「あなたはわたしの顔を見ることができない。人はわたしを見て、なお生きることはできない。」</span>
<span className="v" id="v21" data-v="21" data-xref="申命記 5:31; ゼカリヤ書 3:7; ヨシュア記 20:4"> 主はさらに言われた。「見よ、わたしの傍らに一つの場所がある。あなたはその岩の上に立ちなさい。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 91:1; イザヤ書 2:21; 詩篇 91:4"> わたしの栄光が通り過ぎる時、わたしはあなたを岩の裂け目に入れ、わたしが通り過ぎるまでわたしの手であなたを覆う。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 33:20; ヨハネ 1:18; テモテへの手紙第一 6:16"> その後、手をのけるので、あなたはわたしの後ろを見る。しかし、わたしの顔は見られない。」</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 36:8–19; 出エジプト記 26:36; 出エジプト記 26:31"> 撚り糸で織った亜麻布と、青色、紫色、緋色の糸で十枚の幕を造り、幕屋としなさい。熟練した職人がケルビムを織り出す。</span>
<span className="v" id="v2" data-v="2" data-xref="サムエル記第二 7:2; 民数記 4:25; 歴代誌上 17:1"> 一枚の幕の長さは二十八キュビト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一キュビトは、大人の腕の中指の先から肘までの長さで、約十八インチ、すなわち約四十六センチメートルである。">a</a></sup>、幅は四キュビトとし、すべて同じ寸法にする。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 36:10; コロサイ人への手紙 2:2; エペソ人への手紙 2:21–22"> 五枚の幕を互いにつなぎ合わせ、もう五枚の幕も互いにつなぎ合わせる。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 36:11–12; 出エジプト記 36:17; 出エジプト記 26:10–11"> つなぎ合わせた一方の幕の端に青い糸で輪を作り、もう一つのつなぎ合わせた幕の外側の端にも同じようにする。</span>
<span className="v" id="v5" data-v="5"> 一方の幕に五十の輪を作り、もう一つのつなぎ合わせた幕の端にも五十の輪を作る。輪は互いに向かい合うようにする。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 36:13; 出エジプト記 26:11; 出エジプト記 26:33"> 五十の金の留め金を造り、その留め金で幕を互いにつなぎ合わせる。こうして幕屋は一つとなる。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 26:14; 詩篇 45:13; 出エジプト記 26:9"> 幕屋の上を覆う天幕として、山羊の毛で十一枚の幕を造りなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 26:13; 出エジプト記 26:2"> 一枚の幕の長さは三十キュビト、幅は四キュビトとし、十一枚をすべて同じ寸法にする。</span>
<span className="v" id="v9" data-v="9"> 五枚の幕を一つにつなぎ合わせ、六枚の幕を一つにつなぎ合わせる。そして六枚目の幕を天幕の前面で折り返す。</span>
<span className="v" id="v10" data-v="10"> つなぎ合わせた一方の外側の幕の端に五十の輪を作り、もう一つのつなぎ合わせた幕の外側の端にも五十の輪を作る。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 26:3; 出エジプト記 26:6"> 五十の青銅の留め金を造り、その留め金を輪にはめ込んで、天幕を一つにつなぎ合わせる。</span>
<span className="v" id="v12" data-v="12"> 天幕の幕の余った垂れ下がった部分、すなわち余った半分の幕は、幕屋の背面に垂れ下がるようにする。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 26:2; 出エジプト記 26:8"> 天幕の幕の長さに余る部分は、一方の側で一キュビト、もう一方の側で一キュビト、幕屋の両側に垂れ下がるようにして、それを覆う。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 36:19; 出エジプト記 25:5; 出エジプト記 35:23"> 天幕のために、赤く染めた雄羊の皮の覆いを造り、その上にジュゴンの皮の覆いを造りなさい。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 36:20–33; 民数記 4:31–32; 出エジプト記 40:17–18"> 幕屋のためにアカシアの木で板を造り、直立させなさい。</span>
<span className="v" id="v16" data-v="16"> 板の長さは十キュビト、それぞれの板の幅は一・五キュビトとする。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 36:22; 出エジプト記 26:19; 出エジプト記 36:24"> 一枚の板には互いに対応する二つのほぞを設ける。幕屋のすべての板を同じように造りなさい。</span>
<span className="v" id="v18" data-v="18"> 南側に向かう幕屋のために二十枚の板を造りなさい。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 38:27; 出エジプト記 38:30–31; 出エジプト記 26:37"> その二十枚の板の下に四十の銀の台座を造る。すなわち、一枚の板の二つのほぞの下に二つの台座、もう一枚の板の二つのほぞの下にも二つの台座を置く。</span>
<span className="v" id="v20" data-v="20"> 幕屋のもう一方の側、すなわち北側にも二十枚の板を造り、</span>
<span className="v" id="v21" data-v="21"> それらの四十の銀の台座を造る。すなわち、一枚の板の下に二つの台座、もう一枚の板の下にも二つの台座を置く。</span>
<span className="v" id="v22" data-v="22"> 幕屋の奥、すなわち西側のために六枚の板を造りなさい。</span>
<span className="v" id="v23" data-v="23"> 幕屋の奥の両隅のために二枚の板を造りなさい。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 36:29–30; 詩篇 133:1–3; コリント人への第一の手紙 1:10"> 二枚とも下端で二重にし、上端でも一つの環で結び合わせる。これを二つの隅の板とする。</span>
<span className="v" id="v25" data-v="25"> 八枚の板と、その銀の台座は十六の台座となる。一枚の板の下に二つの台座、もう一枚の板の下にも二つの台座を置く。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="ローマ人への手紙 15:1; 民数記 4:31; ガラテヤ人への手紙 6:1–2"> アカシアの木で横木を造りなさい。幕屋の一方の側の板のために五本、</span>
<span className="v" id="v27" data-v="27"> 幕屋のもう一方の側の板のために五本の横木、そして幕屋の奥、すなわち西側の板のために五本の横木を造る。</span>
<span className="v" id="v28" data-v="28"> 板の真ん中を通る中央の横木は、端から端まで通るようにする。</span>
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 25:11–12"> 板には金をかぶせ、横木を通す場所として金の環を造りなさい。横木にも金をかぶせなさい。</span>
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 25:40; ヘブル人への手紙 8:5; 出エジプト記 25:9"> 山で示された通りに幕屋を建てなさい。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="マタイ 27:51; 歴代誌 第二 3:14; 出エジプト記 36:35"> 青色、紫色、緋色の糸と、撚り糸で織った亜麻布で垂れ幕を造り、熟練した職人がケルビムを織り出す。</span>
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 26:37; 出エジプト記 36:38; エステル記 1:6"> 金をかぶせたアカシアの木の四本の柱にそれを掛けなさい。その掛け釘は金とし、四つの銀の台座の上に立てる。</span>
<span className="v" id="v33" data-v="33" data-xref="ヘブル人への手紙 9:2–3; レビ記 16:2; 出エジプト記 40:21"> その垂れ幕を留め金の下に掛け、そこに、垂れ幕の内側にあかしの箱を運び入れなさい。垂れ幕はあなたがたのために聖所と至聖所とを分けるものとなる。</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 40:20; 出エジプト記 25:21; ヘブル人への手紙 9:5"> 至聖所にあるあかしの箱の上に贖いの座を置きなさい。</span>
<span className="v" id="v35" data-v="35" data-xref="出エジプト記 40:24; 出エジプト記 40:22; ヘブル人への手紙 9:2"> 垂れ幕の外側に机を置き、その向かい、幕屋の南側に燭台を置く。机は北側に置きなさい。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="出エジプト記 36:37; 民数記 9:15; 出エジプト記 26:31"> 天幕の入り口のために、青色、紫色、緋色の糸、撚り糸で織った亜麻布で、刺繍をする者の細工による幕を造りなさい。</span>
<span className="v" id="v37" data-v="37" data-xref="出エジプト記 36:38"> その幕のためにアカシアの木で五本の柱を造り、それに金をかぶせる。その掛け釘は金とする。柱のために五つの青銅の台座を鋳造しなさい。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 28:3; 出エジプト記 35:30–35; 出エジプト記 31:1–6"> ベツァルエル、オホリアブ、および主から知恵と英知を授けられ、聖所の奉仕の仕事を行うすべを知る者たちはみな、主が命じられた通りに仕事をする。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="コロサイ人への手紙 4:17; ヘブル人への手紙 5:4; 出エジプト記 31:6"> モーセはベツァルエルとオホリアブ、また主から知恵を授けられ、心を動かされて仕事に携わろうとする者たちをみな呼び寄せた。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 35:29; 出エジプト記 35:27; 出エジプト記 35:5–21"> 彼らは、イスラエルの子らが聖所の奉仕の仕事のために持って来たささげ物を、すべてモーセから受け取った。民はなおも毎朝、自発のささげ物を持って来た。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 3:10; ルカ 12:42; マタイ 24:45"> 聖所のすべての仕事を行っていた知恵のある人々はみな、各自が行っていた仕事から離れて来て、</span>
<span className="v" id="v5" data-v="5" data-xref="歴代誌 第二 31:6–10; コリント人への第二の手紙 8:2–3; 歴代誌 第二 24:14"> 彼らはモーセに言った。「民は、主が命じられた仕事に必要な量を、はるかに超えて持って来ています。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> そこでモーセは命じ、陣営中にこう布告させた。「男も女も、聖所へのささげ物のため、もう何も作ってはならない。」こうして民は、持って来ることを止められた。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌 第二 31:10"> 材料はすべての仕事を行うのに十分であり、なお余りがあった。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王記第一 6:23; 出エジプト記 26:1–37; エゼキエル書 1:5–28"> 仕事をする者たちのうち、心に知恵のある人々はみな、撚り糸で織った亜麻布、青色、紫色、緋色の糸で十枚の幕を造り、幕屋を造った。彼らはケルビムを熟練した職人の細工としてこれらに織り出した。</span>
<span className="v" id="v9" data-v="9"> それぞれの幕の長さは二十八キュビト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一キュビトは、大人の腕の中指の先から肘までの長さで、約18インチ、すなわち約46センチメートルである。">a</a></sup>、幅は四キュビトとした。すべての幕は同じ寸法であった。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 12:27; 出エジプト記 26:3; 詩篇 122:3"> 彼は五枚の幕を互いにつなぎ合わせ、もう五枚の幕も互いにつなぎ合わせた。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 26:4"> 彼はつなぎ合わせた一方の幕の端に青い糸で輪を作った。もう一つのつなぎ合わせた幕の外側の端にも同じようにした。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 26:5; 出エジプト記 26:10"> 一方の幕に五十の輪を作り、もう一つのつなぎ合わせた幕の端にも五十の輪を作った。輪は互いに向かい合うようにした。</span>
<span className="v" id="v13" data-v="13" data-xref="ペテロの手紙第一 2:4–5; エペソ人への手紙 2:20–22; コリント人への第一の手紙 12:20"> 彼は五十の金の留め金を造り、その留め金で幕を互いにつなぎ合わせた。こうして幕屋は一つとなった。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 26:7–13"> 彼は幕屋の上に掛ける天幕として、山羊の毛で幕を造った。十一枚の幕を造った。</span>
<span className="v" id="v15" data-v="15"> それぞれの幕の長さは三十キュビト、幅は四キュビトとした。十一枚の幕は同じ寸法であった。</span>
<span className="v" id="v16" data-v="16"> 彼は五枚の幕を一つにつなぎ合わせ、六枚の幕を一つにつなぎ合わせた。</span>
<span className="v" id="v17" data-v="17"> 彼はつなぎ合わせた一方の外側の幕の端に五十の輪を作り、もう一つのつなぎ合わせた幕の外側の端にも五十の輪を作った。</span>
<span className="v" id="v18" data-v="18"> 彼は五十の青銅の留め金を造り、天幕を一つにつなぎ合わせた。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 26:14"> 彼は天幕のために赤く染めた雄羊の皮の覆いを造り、その上にジュゴンの皮の覆いを造った。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 25:5; 民数記 25:1; 出エジプト記 40:18–19"> 彼は幕屋のためにアカシアの木で板を造り、直立させた。</span>
<span className="v" id="v21" data-v="21"> 板の長さは十キュビト、それぞれの板の幅は一・五キュビトであった。</span>
<span className="v" id="v22" data-v="22"> それぞれの板には、互いに合うように二つのほぞがあった。彼は幕屋のすべての板をこのように造った。</span>
<span className="v" id="v23" data-v="23"> 彼は幕屋の南側に向かう側に、二十枚の板を造った。</span>
<span className="v" id="v24" data-v="24"> 彼はその二十枚の板の下に四十の銀の台座を造った。すなわち、一枚の板の二つのほぞの下に二つの台座、もう一枚の板の二つのほぞの下にも二つの台座を置いた。</span>
<span className="v" id="v25" data-v="25"> 幕屋のもう一方の側、すなわち北側にも二十枚の板を造り、</span>
<span className="v" id="v26" data-v="26"> それらの四十の銀の台座を造った。すなわち、一枚の板の下に二つの台座、もう一枚の板の下にも二つの台座を置いた。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 26:22; 出エジプト記 26:27"> 幕屋の奥、すなわち西側のために六枚の板を造った。</span>
<span className="v" id="v28" data-v="28"> 幕屋の奥の両隅のために二枚の板を造った。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒の働き 4:32; エペソ人への手紙 3:18–19; コリント人への第一の手紙 1:10"> これらは下で二重になり、同じように頂部でも一つの環に向けて一つとなるようにした。彼は二つの隅にある両方の板をそのようにした。</span>
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 26:25"> 八枚の板と、その銀の台座は十六の台座となった。すべての板の下に二つずつ台座があった。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 26:26–29; 出エジプト記 25:28; 出エジプト記 30:5"> 彼はアカシアの木で横木を造った。幕屋の一方の側の板のために五本、</span>
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 26:26"> 幕屋のもう一方の側の板のために五本の横木、そして幕屋の奥、すなわち西側の板のために五本の横木を造った。</span>
<span className="v" id="v33" data-v="33"> 彼は板の真ん中を通る中央の横木を、端から端まで通るようにした。</span>
<span className="v" id="v34" data-v="34"> 彼は板に金をかぶせ、横木を通す場所として金の環を造り、横木にも金をかぶせた。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="マタイ 27:51; ヘブル人への手紙 10:20; 出エジプト記 40:21"> 彼は青色、紫色、緋色の糸、撚り糸で織った亜麻布で垂れ幕を造った。それにケルビムを熟練した職人の細工として織り出した。</span>
<span className="v" id="v36" data-v="36" data-xref="エレミヤ書 1:18"> そのために四本のアカシアの木の柱を造り、それに金をかぶせた。その掛け釘は金であった。彼はそのために四つの銀の台座を鋳造した。</span>
<span className="v" id="v37" data-v="37" data-xref="出エジプト記 26:36–37; 出エジプト記 40:28"> 彼は天幕の入り口のために、青色、紫色、緋色の糸、撚り糸で織った亜麻布で、刺繍をする者の細工による幕を造った。</span>
<span className="v" id="v38" data-v="38" data-xref="出エジプト記 27:10"> また、その五本の柱とその掛け釘を造り、その柱頭と帯飾りに金をかぶせた。その五つの台座は青銅であった。</span>
</div>

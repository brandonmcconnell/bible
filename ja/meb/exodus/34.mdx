<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 32:19; 出エジプト記 31:18; 詩篇 119:89"> 主はモーセに言われた。「最初と同じ石の板を二枚切り出しなさい。あなたが砕いた最初の板にあった言葉を、その板に書き記す。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 19:20; 申命記 9:25; 出エジプト記 19:11"> 朝までに備え、朝、シナイ山に上り、山の頂でわたしの前に立ちなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 19:12–13; 出エジプト記 19:21; テモテへの手紙第一 2:5"> 誰もあなたと一緒に上って来てはならず、山のどこにも姿を見せてはならない。羊の群れも牛の群れも、その山の前で草をはませてはならない。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> モーセは最初と同じ石の板を二枚切り出した。朝早く起き、主が命じられた通りシナイ山へ上り、二枚の石の板を手に携えた。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 33:19; 民数記 11:25; ルカ 9:34–35"> 主は雲の中に降り、そこでモーセと共に立ち、主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「主」は、神の固有名であるヘブライ語 יהוה（通常「ヤハウェ」と表記される）の訳語である。">a</a></sup>の名を宣言された。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 86:15; ヨエル書 2:13; 詩篇 103:8–13"> 主は彼の前を通り過ぎて宣言された。「主、主、あわれみ深く恵み豊かな神、怒るのに遅く、慈しみと真実に満ちる方。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 20:5–6; 詩篇 103:3; 申命記 5:9–10"> 幾千代にも慈しみを保ち、咎と背きと罪を赦す。しかし、罪ある者を決して罪なしとはせず、父の咎を子や孫に、三代、四代にまで報いる方。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 4:31; 歴代誌 第二 20:18; 創世記 17:3"> モーセは急いで地に頭を下げて礼拝した。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 33:12; 申命記 32:9; 詩篇 94:14"> モーセは言った。「主よ、もし私があなたの目に恵みを得ているなら、どうか主が私たちのただ中を共に行かれますように。うなじの固い民ですが、私たちの咎と罪を赦し、私たちをご自分の嗣業としてください。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命記 10:21; 詩篇 77:14; イザヤ書 64:3"> 主は言われた。「見よ、わたしは契約を結ぶ。あなたの民すべての前で、全地のどの国にもかつて行われたことのない驚くべき業を行う。あなたの周囲の民はみな、主の業を見る。わたしがあなたと共に行うことは、畏るべきものである。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 33:2; 出エジプト記 3:17; 出エジプト記 3:8"> 今日わたしがあなたに命じることを守りなさい。見よ、わたしはアモリ人、カナン人、ヘト人、ペリジ人、ヒビ人、エブス人をあなたの前から追い出す。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 23:32–33; ヨシュア記 23:12–13; 申命記 7:2"> あなたが入って行く地の住民と契約を結ばないよう気をつけなさい。それがあなたがたの間で罠となるからである。</span>
<span className="v" id="v13" data-v="13" data-xref="列王記第二 18:4; 出エジプト記 23:24; 申命記 7:25–26"> 彼らの祭壇を壊し、石の柱を打ち砕き、アシェラ像を切り倒しなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 4:24; 申命記 32:21; コリント人への第一の手紙 10:22"> ほかの神を拝んではならない。主はその名を「ねたみ」といい、ねたむ神だからである。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士師記 2:17; 詩篇 106:28; 民数記 25:2"> その地の住民と契約を結んではならない。彼らが神々を慕って淫行を行い、神々にいけにえを献げ、あなたを招いて、そのいけにえを食べさせることがないためである。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 7:3–4; 列王記第一 11:2–4; エズラ記 9:2"> また、彼らの娘を息子の妻に迎え、その娘たちが神々を慕って淫行を行い、息子たちにも同じことをさせることがないためである。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="レビ記 19:4; 出エジプト記 32:8; イザヤ書 46:6–7"> あなたは自分のために鋳造した神々を造ってはならない。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 13:4; レビ記 23:6; 出エジプト記 13:6–7"> 種なしパンの祭りを守りなさい。命じた通り、アビブの月の定められた時に七日間、種なしパンを食べる。アビブの月に、あなたはエジプトから出た。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 13:2; 出エジプト記 22:29; 出エジプト記 13:12"> 胎を開くものはみな、わたしのものである。あなたの家畜のうち、牛や羊の雄の初子もみなそうである。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 13:13; 出エジプト記 23:15; 申命記 16:16"> ろばの初子は小羊で贖いなさい。贖わないなら、その首を折る。息子の初子はみな贖いなさい。誰も手ぶらでわたしの前に出てはならない。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 23:12; 申命記 21:4; ルカ 13:14"> 六日間は働き、七日目には休みなさい。耕す時にも刈り入れの時にも休む。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 23:16; 申命記 16:10–15; ヨハネ 7:2"> 小麦の刈り入れの初穂をもって七週の祭りを、年の終わりには取り入れの祭りを祝いなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 23:14; 申命記 16:16; 出エジプト記 23:17"> 年に三度、男子はみなイスラエルの神、主なる神の前に出る。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 78:55; 出エジプト記 33:2; 箴言 16:7"> わたしはあなたの前から国々を追い出し、あなたの境界を広げる。あなたが年に三回、あなたの神、主の前に現れるために上って行く時、誰もあなたの地を欲しがることはない。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 23:18; 出エジプト記 12:10; コリント人への第一の手紙 5:7–8"> わたしのいけにえの血を、パン種が入ったものと共にささげてはならない。過越の祭りのいけにえを朝まで残しておいてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 23:19; 申命記 14:21; 申命記 26:2"> 土地の初穂の最上のものを、あなたの神、主の家へ持って来なさい。子山羊をその母の乳で煮てはならない。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 24:4; 申命記 31:9; 申命記 4:13"> 主はモーセに言われた。「これらの言葉を書き記しなさい。これらの言葉に基づいて、わたしはあなたとイスラエルと契約を結んだ。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 34:1; 出エジプト記 24:18; 申命記 9:18"> モーセはそこで四十日四十夜、主と共にいた。彼はパンも食べず、水も飲まなかった。彼は契約の言葉、十戒を板に書き記した。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="マタイ 17:2; ルカ 9:29; 出エジプト記 32:15"> モーセはシナイ山から下りて来た。手には二枚のあかしの板があった。主と語ったために、自分の顔の肌が光を放っていることを、モーセは知らなかった。</span>
<span className="v" id="v30" data-v="30" data-xref="マルコ 9:3; ルカ 5:8; 民数記 12:8"> アロンとイスラエルの子らはみな、モーセの顔の肌が光を放っているのを見て、恐れて近づけなかった。</span>
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 3:15; 出エジプト記 24:1–3; 創世記 45:3"> モーセが彼らを呼ぶと、アロンと会衆のすべての指導者たちが彼のもとに戻って来たので、モーセは彼らに語った。</span>
<span className="v" id="v32" data-v="32" data-xref="列王記第一 22:14; 出エジプト記 24:3; マタイ 28:20"> その後、イスラエルのすべての子らが近づいて来たので、彼は主がシナイ山で彼に語られたすべての命令を彼らに授けた。</span>
<span className="v" id="v33" data-v="33" data-xref="コリント人への第二の手紙 4:4–6; コリント人への第二の手紙 3:13–18; ローマ人への手紙 10:4"> モーセは彼らに語り終えると、顔に覆いを掛けた。</span>
<span className="v" id="v34" data-v="34" data-xref="コリント人への第二の手紙 3:16; ヘブル人への手紙 10:19–22; ヘブル人への手紙 4:16"> しかし、主と語るために御前へ入る時は、出て来るまで覆いを外していた。出て来ると、命じられたことをイスラエルの子らに語った。</span>
<span className="v" id="v35" data-v="35" data-xref="出エジプト記 34:29–30; ヨハネ 5:35; ダニエル書 12:3"> イスラエルの子らはモーセの顔の肌が光を放つのを見た。モーセは再び、主と語るため中へ入るまで、顔に覆いを掛けた。</span>
</div>

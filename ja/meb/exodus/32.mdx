<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 7:40; 申命記 9:9; 出エジプト記 24:18"> 民はモーセが山から下りて来るのが遅いのを見て、アロンのもとに集まり、言った。「さあ、私たちに先立って行く神々を造ってください。私たちをエジプトの地から導き上ったあのモーセが、どうなったのか分かりません。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="士師記 8:24–27; 出エジプト記 12:35–36; エゼキエル書 16:17"> アロンは彼らに言った。「あなたがたの妻や息子、娘たちの耳にある金の環を外し、私のところに持って来なさい。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 46:6; イザヤ書 40:19–20; エレミヤ書 10:9"> 民は皆、自分たちの耳にある金の環を外し、アロンのところに持って来た。</span>
<span className="v" id="v4" data-v="4" data-xref="ネヘミヤ記 9:18; 申命記 9:16; 列王記第一 12:28"> アロンは彼らから金を受け取り、彫刻具で型を作って、鋳造した子牛を造った。彼らは言った。「イスラエルよ、これがあなたをエジプトの地から導き上った神々だ。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王記第二 10:20; レビ記 23:2; レビ記 23:37"> アロンはこれを見て、その前に祭壇を築き、「明日は主への祭りである」と布告した。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="コリント人への第一の手紙 10:7; 民数記 25:2; 使徒の働き 7:41–42"> 彼らは翌日早く起き、全焼のいけにえをささげ、和解のいけにえを持って来た。民は座って飲み食いし、立ち上がって遊んだ。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 32:11; ホセア書 9:9; 士師記 2:19"> 主はモーセに言われた。「すぐに下りなさい。あなたがエジプトの地から導き上った民は堕落した。</span>
<span className="v" id="v8" data-v="8" data-xref="列王記第一 12:28; 出エジプト記 20:23; 出エジプト記 20:3–4"> 彼らは、わたしが彼らに命じた道から早くも外れてしまった。彼らは自分たちのために鋳造した子牛を造り、それを拝み、それにいけにえをささげて、『イスラエルよ、これがあなたをエジプトの地から導き上った、あなたの神々である』と言っている。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒の働き 7:51; 申命記 9:13; イザヤ書 48:4"> 主はモーセに言われた。「わたしはこの民を見た。見よ、彼らはうなじの固い民である。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 9:14; 民数記 14:12; 申命記 9:19"> 今、わたしを放っておきなさい。わたしの怒りは彼らに向かって燃え上がり、彼らを滅ぼし尽くす。わたしはあなたを大いなる国民とする。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="申命記 9:18–20; 申命記 9:26–29; 詩篇 106:23"> モーセは自分の神、主に懇願した。「主よ、なぜあなたの怒りが、大いなる力と力強い手によってエジプトの地から導き出されたご自分の民に向かって燃え上がるのですか。</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 14:13–16; 申命記 9:28; ヨシュア記 7:9"> なぜエジプト人に、『神は悪意をもって彼らを導き出し、山で殺し、地の面から滅ぼし尽くした』と言わせるのですか。激しい怒りをおさめ、ご自分の民に下そうとする災いを思い直してください。</span>
<span className="v" id="v13" data-v="13" data-xref="ヘブル人への手紙 6:13; 創世記 12:7; 創世記 22:16"> あなたのしもべであるアブラハム、イサク、イスラエルを思い出してください。あなたはご自身にかけて彼らに誓い、『わたしはあなたがたの子孫<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="あるいは、種。">a</a></sup>を空の星のように増やし、わたしが語ったこのすべての地をあなたがたの子孫に与え、彼らはそれを永遠に受け継ぐであろう』と言われました。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ヨナ書 3:10; 詩篇 106:45; エレミヤ書 26:13"> それで主は、ご自分の民に下すと言われた災いを思い直された。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命記 9:15; 出エジプト記 40:20; 申命記 5:22"> モーセは向き直り、あかしの板二枚を手に持って山から下りた。その板は両面に字が書かれていた。片面にも、もう片面にも書かれていた。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 31:18; ヘブル人への手紙 8:10; 申命記 10:1"> その板は神の作であり、その字は板に彫られた神の文字であった。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 24:13; 出エジプト記 17:9; ヨシュア記 6:20"> ヨシュアは民の叫ぶ声を聞き、モーセに言った。「陣営から戦いの声が聞こえます。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 15:1–18; ダニエル書 5:4; ダニエル書 5:23"> モーセは言った。「勝利を叫ぶ声でも、敗北を嘆く声でもない。私に聞こえるのは歌声だ。」</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 9:16–17; エレミヤ書 31:32; 哀歌 5:15"> 彼は陣営に近づくとすぐに、子牛と踊りを見た。するとモーセの怒りは激しく燃え上がり、彼は手から板を投げつけ、山のふもとでそれを砕いた。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 9:21; 列王記第二 23:6; 列王記第二 23:15"> 彼は彼らが造った子牛を取り、火で焼き、細かく砕いて粉にし、水の上にまき散らし、イスラエルの子らに飲ませた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="創世記 20:9; ヨシュア記 7:19–26; 列王記第一 21:22"> モーセはアロンに言った。「この民があなたに何をしたので、あなたは彼らに大きな罪をもたらしたのか。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命記 9:24; 出エジプト記 15:24; 出エジプト記 16:20"> アロンは言った。「我が主よ、怒らないでください。この民が悪に傾いていることは、あなたもご存じです。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 32:1–4; 出エジプト記 32:8"> 彼らは私に言いました。『私たちのために、私たちの先頭に立って行く神々を造ってください。私たちをエジプトの地から導き上ったあのモーセという人が、どうなってしまったのか分からないからです。』</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 32:4; ルカ 10:29; ローマ人への手紙 3:10"> そこで私は、『金を持っている者は外しなさい』と言いました。彼らが私に渡したので、火に投げ入れると、この子牛が出て来たのです。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 47:3; ミカ書 1:11; ヨハネの黙示録 16:15"> モーセは、民が抑えを失っているのを見た。アロンが彼らを放縦にし、敵の物笑いにしてしまったのである。</span>
<span className="v" id="v26" data-v="26" data-xref="列王記第二 9:32; マタイ 12:30; サムエル記第二 20:11"> その時、モーセは陣営の入り口に立って言った。「主の側につく者は誰でも、私のところに来なさい！」<br />すると、レビのすべての子らが彼のもとに集まった。</span>
<span className="v" id="v27" data-v="27" data-xref="民数記 25:5; ルカ 14:26; 申命記 33:8–9"> モーセは彼らに言った。「イスラエルの神、主はこう言われる。『各自、剣を腰に帯び、陣営の門から門へ行き巡り、兄弟、友、隣人を討て。』」</span>
<span className="v" id="v28" data-v="28" data-xref="申命記 33:9; マラキ書 2:4–6; コリント人への第一の手紙 10:8"> レビの子らはモーセの言葉通りにした。その日、民のうち約三千人が倒れた。</span>
<span className="v" id="v29" data-v="29" data-xref="民数記 25:11–13; マタイ 10:37; ゼカリヤ書 13:3"> モーセは言った。「今日、主に仕えるため自らを聖別しなさい。あなたがたは息子や兄弟にさえ立ち向かった。今日、主があなたがたに祝福を与えられるためである。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="サムエル記第一 12:20; 民数記 25:13; 列王記第二 17:21"> 翌日、モーセは民に言った。「あなたがたは大きな罪を犯した。今、私は主のもとに上って行く。もしかすると、あなたがたの罪のために贖いをすることができるかもしれない。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 20:23; ダニエル書 9:11; ダニエル書 9:8"> モーセは主のもとに戻って言った。「ああ、この民は大きな罪を犯し、自分たちのために金の神々を造りました。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 69:28; ローマ人への手紙 9:3; ヨハネの黙示録 21:27"> しかし今、どうか彼らの罪を赦してください。もし赦されないなら、あなたが書かれた書から、どうか私を消し去ってください。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="申命記 29:20; エゼキエル書 18:4; ヨハネの黙示録 20:12"> 主はモーセに言われた。「わたしに対して罪を犯した者は誰でも、わたしの書物から消し去る。</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 23:20; 申命記 32:35; マタイ 23:35"> 今、行って、わたしが告げた場所へ民を導きなさい。見よ、わたしの使いがあなたの前を行く。しかし、わたしが罰する日には、彼らの罪を罰する。」</span>
<span className="v" id="v35" data-v="35" data-xref="使徒の働き 7:41; 出エジプト記 32:25; サムエル記第二 12:9–10"> 主は民を打たれた。彼らが、アロンの造った子牛を拝んだからである。</span>
</div>
</div>

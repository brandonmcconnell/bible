<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌上 2:1–2; 創世記 46:8–26; 創世記 35:23–26"> ヤコブと共にエジプトへ来たイスラエルの子らの名は次の通りである。彼らはそれぞれ家族を伴って来た。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 35:22"> ルベン、シメオン、レビ、ユダ、</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 28:20; 創世記 35:23"> イッサカル、ゼブルン、ベニヤミン、</span>
<span className="v" id="v4" data-v="4"> ダンとナフタリ、ガドとアシェル。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 10:22; 創世記 46:26–27; 士師記 8:30"> ヤコブから生まれた者は、合わせて七十人であった。ヨセフはすでにエジプトにいた。</span>
<span className="v" id="v6" data-v="6" data-xref="創世記 50:26; 創世記 50:24; 使徒の働き 7:14–16"> ヨセフも、その兄弟たちも、その世代の者もみな死んだ。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 46:3; 創世記 1:28; 申命記 26:5"> イスラエルの子らは実を結び、おびただしく増え、増え広がり、極めて強くなった。その地は彼らで満ちた。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 7:18; 伝道者の書 2:18–19; 伝道者の書 9:15"> さて、ヨセフを知らない新しい王がエジプトに起こった。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 105:24–25; 伝道者の書 4:4; ヤコブの手紙 3:14–16"> 王は民に言った。「見よ、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「見よ」はヘブライ語 הִנֵּה に由来し、注意を促す間投詞として用いられる。">a</a></sup>イスラエルの民は、われわれより数が多く、しかも強い。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 7:19; 詩篇 83:3–4; 箴言 1:11"> さあ、彼らに対して賢く対処しよう。そうしなければ、彼らはますます増え、戦争が起これば敵に加わってわれわれと戦い、この地から出て行くかもしれない。」</span>
<span className="v" id="v11" data-v="11" data-xref="創世記 15:13; 創世記 47:11; 出エジプト記 3:7"> そこで彼らは、重労働で彼らを苦しめるために、彼らの上に奴隷監督を置いた。彼らはファラオのために、貯蔵庫の町ピトムとラメセスを建てた。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 105:24; 出エジプト記 1:9; ローマ人への手紙 8:28"> しかし、エジプト人が彼らを苦しめれば苦しめるほど、彼らはますます増え、ますます広がっていった。そのため彼らはイスラエルの子らに恐怖を抱くようになった。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 4:20"> エジプト人はイスラエルの子らを過酷に働かせ、</span>
<span className="v" id="v14" data-v="14" data-xref="使徒の働き 7:19; 民数記 20:15; 出エジプト記 2:23"> モルタルとれんが作りの激しい労働、畑でのあらゆる労働によって、彼らの生活を苦いものにした。エジプト人は、あらゆる労働で彼らを過酷に働かせた。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> エジプトの王は、ヘブル人の助産婦たちに言った。一人の名はシフラ、もう一人の名はプアであった。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 1:22; マタイ 21:38; ヨハネの黙示録 12:4"> 王は言った。「ヘブル人の女の出産を助ける時、産み台を見なさい。男の子なら殺し、女の子なら生かしておけ。」</span>
<span className="v" id="v17" data-v="17" data-xref="使徒の働き 5:29; 出エジプト記 1:21; マタイ 10:28"> しかし、助産婦たちは神を恐れ<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「神」と訳されたヘブル語は「אֱלֹהִים」（エロヒム）である。">b</a></sup>、エジプトの王が命じた通りにはせず、男の赤ん坊を生かしておいた。</span>
<span className="v" id="v18" data-v="18" data-xref="伝道者の書 8:4; サムエル記第二 13:28"> エジプトの王は助産婦たちを呼び寄せて言った。「なぜこのようなことをして、男の子たちを生かしておいたのか。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 2:4–24; サムエル記第二 17:19–20; サムエル記第一 21:2"> 助産婦たちはファラオに言った。「ヘブル人の女たちはエジプト人の女たちとは違います。彼女たちは元気で、助産婦が行く前に産んでしまうからです。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 3:10; 伝道者の書 8:12; 箴言 11:18"> 神は助産婦たちを恵まれた。民は増え、非常に強くなった。</span>
<span className="v" id="v21" data-v="21" data-xref="列王記第一 11:38; サムエル記第一 2:35; 詩篇 37:3"> 助産婦たちは神を恐れたので、神は彼女たちにも家庭を与えられた。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒の働き 7:19; 箴言 1:16; 出エジプト記 1:16"> ファラオは民全体に命じた。「生まれた男の子はみなナイル川に投げ込め。女の子はみな生かしておけ。」</span>
</div>
</div>

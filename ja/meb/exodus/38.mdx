<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 27:1–8; エゼキエル書 43:13–17; 出エジプト記 40:6"> 彼はアカシアの木で全焼のいけにえの祭壇を造った。それは四角形であった。長さは五キュビト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一キュビトは、大人の腕の中指の先から肘までの長さで、約18インチ、すなわち約46センチメートルである。">a</a></sup>、幅は五キュビト、高さは三キュビトであった。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 27:2; ヨブ記 6:12"> その四隅に角を造った。その角は祭壇と一体であり、それに青銅をかぶせた。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 27:3; サムエル記第一 2:13"> 彼は祭壇の器具、すなわち壺、灰取りシャベル、鉢、肉刺し、火皿を、すべて青銅で造った。</span>
<span className="v" id="v4" data-v="4"> 祭壇のために青銅の網目細工の格子を造り、祭壇の出っ張りの下、すなわち下部に取り付け、格子が祭壇の半分の高さに届くようにした。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 27:4"> 青銅の格子の四隅に、担ぎ棒を通すための環を四つ鋳造した。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 10:3; 出エジプト記 25:6"> アカシアの木で担ぎ棒を造り、青銅をかぶせた。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒の働き 9:15; コリント人への第一の手紙 2:2; コリント人への第一の手紙 1:24"> 祭壇を担ぐため、その両側の環に担ぎ棒を通した。祭壇は板で中空に造った。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="サムエル記第一 2:22; ルカ 2:37; 出エジプト記 40:7"> 彼は青銅の洗盤とその青銅の台を、会見の天幕の入り口で奉仕する女たちの鏡で造った。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 27:9–19; 詩篇 89:7; 列王記第一 6:36"> 彼は庭を造った。南側に向かう片側のために、撚り糸で織った亜麻布の庭の幕を百キュビト設けた。</span>
<span className="v" id="v10" data-v="10"> その二十本の柱と二十の台座は青銅であり、柱の掛け釘と帯飾りは銀であった。</span>
<span className="v" id="v11" data-v="11"> 北側には百キュビトの幕を設けた。その二十本の柱と二十の台座は青銅であり、柱の掛け釘と帯飾りは銀であった。</span>
<span className="v" id="v12" data-v="12"> 西側には五十キュビトの幕を設けた。その柱は十本、台座は十であり、柱の掛け釘と帯飾りは銀であった。</span>
<span className="v" id="v13" data-v="13"> 東に向かう東側は五十キュビトであった。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 27:14"> 入り口の一方の側の幕は十五キュビト、その柱は三本、台座は三つであった。</span>
<span className="v" id="v15" data-v="15"> もう一方の側も同様であった。庭の入り口の両側には十五キュビトの幕があり、その柱は三本、台座は三つであった。</span>
<span className="v" id="v16" data-v="16"> 庭の周囲のすべての幕は、撚り糸で織った亜麻布であった。</span>
<span className="v" id="v17" data-v="17"> 柱の台座は青銅であった。柱の掛け釘と帯飾りは銀であり、その柱頭には銀がかぶせられていた。庭のすべての柱には銀の帯飾りがあった。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代誌 第二 3:14"> 庭の入り口の幕は、青色、紫色、緋色の糸、撚り糸で織った亜麻布による、刺繍をする者の細工であった。長さは二十キュビトで、幅に沿った高さは庭の幕と同じく五キュビトであった。</span>
<span className="v" id="v19" data-v="19"> その柱は四本、青銅の台座は四つであった。その掛け釘は銀であり、柱頭の覆いと帯飾りも銀であった。</span>
<span className="v" id="v20" data-v="20" data-xref="歴代誌 第二 3:9; 出エジプト記 27:19; エペソ人への手紙 2:21–22"> 幕屋のすべての釘と、庭の周囲の釘は青銅であった。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 7:44; 民数記 9:15; 歴代誌 第二 24:6"> これは幕屋、すなわちあかしの幕屋に用いられた材料の総量である。モーセの命令により、祭司アロンの子イタマルの指揮の下、レビ人が数えた。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 35:30–3; 出エジプト記 31:1–5; 詩篇 119:6"> ユダ部族のフルの子であるウリの子ベツァルエルは、主がモーセに命じられたすべてのものを造った。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 35:34; 出エジプト記 31:6"> 彼と共に、ダン部族のアヒサマクの子オホリアブがいた。彼は彫刻師であり、熟練した職人であり、青色、紫色、緋色の糸、および亜麻布による刺繍をする者であった。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数記 18:16; 民数記 3:47; レビ記 27:25"> 聖所のすべての仕事、すなわちあらゆる奉仕の仕事に用いられた金、すなわちささげ物の金は、聖所のシェケル<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一シェケルは約10グラム、あるいは約0.35オンスである。">b</a></sup>に従って、二十九タラント<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一タラントは約30キログラム、すなわち66ポンド、あるいは965トロイオンスである。">c</a></sup>と七百三十シェケルであった。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 30:12"> 会衆の中で数えられた者たちの銀は、聖所のシェケルに従って百タラント<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一タラントは約30キログラム、すなわち66ポンドである。">d</a></sup>と千七百七十五シェケル<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一シェケルは約10グラム、あるいは約0.35オンスである。">e</a></sup>であった。</span>
<span className="v" id="v26" data-v="26" data-xref="民数記 1:46; 出エジプト記 30:13; 出エジプト記 12:37"> これは数えられる者たちの中に加わる二十歳以上の者、すなわち六十万三千五百五十人の一人一人について、一人当たり一ベカ<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一ベカは約5グラム、あるいは約0.175オンスである。">f</a></sup>、すなわち聖所のシェケル<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="一シェケルは約10グラム、あるいは約0.35オンスである。">g</a></sup>に従って半シェケルであった。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 26:19; 出エジプト記 26:25; 出エジプト記 26:21"> 百タラント<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="一タラントは約30キログラム、すなわち66ポンドである。">h</a></sup>の銀は、聖所の台座と垂れ幕の台座を鋳造するためのものであった。百タラントで百の台座を、すなわち一つの台座につき一タラントを用いた。</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 27:17"> 彼は千七百七十五シェケル<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="一シェケルは約10グラム、あるいは約0.35オンスである。したがって1775シェケルは約17.75キログラム、すなわち約39ポンドである。">i</a></sup>で柱のための掛け釘を作り、その柱頭に銀をかぶせ、そのための帯飾りを作った。</span>
<span className="v" id="v29" data-v="29"> ささげ物の青銅は、七十タラント<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="一タラントは約30キログラム、すなわち66ポンドである。">j</a></sup>と二千四百シェケル<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="70タラントと2400シェケルは約2124キログラム、すなわち2.124メートルトンである。">k</a></sup>であった。</span>
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 26:37; 出エジプト記 27:17; 出エジプト記 27:10"> 彼はこれで会見の天幕の入り口の台座、青銅の祭壇とその青銅の格子、祭壇のすべての器具、</span>
<span className="v" id="v31" data-v="31"> 庭の周囲の台座、庭の入り口の台座、幕屋のすべての釘、および庭の周囲のすべての釘を作った。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 12:33; 出エジプト記 12:31; 出エジプト記 3:19–20"> 主はモーセに言われた。「今、あなたはわたしがファラオにすることを見る。彼は力強い手に迫られて民を行かせ、力強い手に迫られて自分の地から彼らを追い出す。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 9:24; マラキ書 3:6; 使徒の働き 17:24–25"> 神はモーセに語り、彼に言われた。「わたしは主である。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 83:18; 詩篇 68:4; 創世記 17:1"> わたしはアブラハム、イサク、ヤコブに全能の神として現れたが、主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「主」は、神の固有名であるヘブライ語 יהוה（通常「ヤハウェ」と表記される）の訳語である。短縮形 יה（ヤハ）に由来する場合は、その旨を注記する。">a</a></sup>というわたしの名によっては、彼らに知られなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 28:4; 創世記 15:18; 創世記 17:7–8"> わたしは彼らと契約を立て、彼らが寄留していたカナンの地を与えると約束した。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 2:24; 詩篇 106:44–45; イザヤ書 63:9"> さらに、わたしはエジプト人が奴隷としているイスラエルの子らのうめきを聞き、わたしの契約を思い起こした。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 26:8; 歴代誌上 17:21; 出エジプト記 7:4"> それゆえ、イスラエルの子らに言いなさい。『わたしは主である。わたしはエジプト人の重労働の下からあなたがたを導き出し、彼らの奴隷の身からあなたがたを救い出す。わたしは伸ばした腕と大いなる裁きによってあなたがたを贖う。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 7:6; 申命記 29:13; 申命記 4:20"> わたしはあなたがたをわたしの民とし、あなたがたの神となる。あなたがたは、エジプト人の重労働の下から導き出す方が、あなたがたの神、主であることを知る。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 26:3; 創世記 15:18; エゼキエル書 20:42"> わたしは、アブラハム、イサク、ヤコブに与えると誓った地にあなたがたを導き入れ、それをあなたがたの所有として与える。わたしは主である。』」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 5:21; ヨブ記 21:4; 出エジプト記 14:12"> モーセはそのようにイスラエルの子らに語ったが、彼らは心が打ちひしがれ、過酷な奴隷労働のゆえに、モーセに聞き従わなかった。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 主はモーセに言われた。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 6:29; 出エジプト記 5:23; 出エジプト記 3:10"> 「行きなさい。エジプトの王ファラオに語り、イスラエルの子らを彼の地から去らせるように言いなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 4:10; エレミヤ書 1:6; 出エジプト記 6:30"> モーセは主の前で言った。「イスラエルの子らさえ私に聞き従いませんでした。ましてファラオが聞き従うでしょうか。私は唇に割礼のない者です。」</span>
<span className="v" id="v13" data-v="13" data-xref="民数記 27:23; テモテへの手紙第一 6:13; 詩篇 91:11"> 主はモーセとアロンに語り、イスラエルの子らとエジプトの王ファラオについて命じて、イスラエルの子らをエジプトの地から導き出させた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="創世記 46:9; 歴代誌上 5:3; 民数記 26:5–7"> 彼らの父祖の家々の長は次の通りである。イスラエルの長子ルベンの子らは、エノク、パル、ヘツロン、カルミ。これらはルベンの諸氏族である。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代誌上 4:24; 創世記 46:10; 民数記 26:12–13"> シメオンの子らは、イムエル、ヤミン、オハデ、ヤキン、ツォハル、そしてカナン人の女の息子サウル。これらはシメオンの諸氏族である。</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 3:17; 創世記 46:11; 歴代誌上 6:1"> その世代に基づくレビの子らの名前は次の通りである。ゲルション、ケハト、メラリ。レビの生涯の年は百三十七年であった。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代誌上 6:17; 民数記 3:18; 歴代誌上 23:7"> その諸氏族に基づくゲルションの子らは、リブニとシムイである。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代誌上 6:18; 歴代誌上 6:2; 民数記 3:19"> ケハトの子らは、アムラム、イツハル、ヘブロン、ウジエル。ケハトの生涯の年は百三十三年であった。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 3:20; 歴代誌上 23:21; 歴代誌上 6:19"> メラリの子らは、マフリとムシ。これらがその世代に基づくレビ人の諸氏族である。</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 26:59; 出エジプト記 2:1–2; 出エジプト記 6:18"> アムラムは父の妹ヨケベデを妻とし、彼女は彼にアロンとモーセを産んだ。アムラムの生涯の年は百三十七年であった。</span>
<span className="v" id="v21" data-v="21" data-xref="民数記 16:1; 歴代誌上 6:37–38; 民数記 16:32"> イツハルの子らは、コラ、ネフェグ、ジクリである。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 10:4; 民数記 3:30; ネヘミヤ記 3:20"> ウジエルの子らは、ミシャエル、エルツァファン、シトリである。</span>
<span className="v" id="v23" data-v="23" data-xref="ルツ記 4:19–20; 民数記 2:3; 民数記 1:7"> アロンはアミナダブの娘でナフションの妹であるエリシェバを妻とし、彼女は彼にナダブ、アビフ、エルアザル、イタマルを産んだ。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代誌上 6:22–23; 民数記 16:1; サムエル記第一 1:1"> コラの子らは、アシル、エルカナ、アビアサフ。これらがコラ人の諸氏族である。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 24:33; 民数記 25:7–13; ヨシュア記 22:31–32"> アロンの息子エルアザルはプティエルの娘の一人を妻とし、彼女は彼にピネハスを産んだ。これらがその諸氏族に基づくレビ人の父祖の家々の長である。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 12:51; 出エジプト記 12:17; 出エジプト記 7:4"> 「イスラエルの子らをその軍団ごとにエジプトの地から導き出せ」と主から命じられたのは、このアロンとモーセである。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 6:26; 出エジプト記 7:10; 詩篇 77:20"> イスラエルの子らをエジプトから導き出すため、エジプトの王ファラオに語ったのも、このモーセとアロンである。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 主がエジプトの地でモーセに語られた日、</span>
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 6:11; 出エジプト記 7:2; 出エジプト記 6:2"> 主はモーセに言われた。「わたしは主である。わたしがあなたに語るすべてのことを、エジプトの王ファラオに語りなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 6:12; 出エジプト記 4:10; コリント人への第一の手紙 9:16–17"> モーセは主の前で言った。「私は唇に割礼のない者です。どうしてファラオが私に聞き従うでしょうか。」</span>
</div>

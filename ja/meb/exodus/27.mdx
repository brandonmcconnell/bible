<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 38:1–7; 出エジプト記 20:24–26; 出エジプト記 40:10"> アカシアの木で祭壇を造りなさい。長さと幅は五キュビト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一キュビトは、大人の腕の中指の先から肘までの長さで、約十八インチ、すなわち約四十六センチメートルである。">a</a></sup>の正方形、高さは三キュビト<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="祭壇は約二・三×二・三×一・四メートル、または約七・五×七・五×四・五フィートであった。">b</a></sup>とする。</span>
<span className="v" id="v2" data-v="2" data-xref="詩篇 118:27; 出エジプト記 29:12; レビ記 4:7"> 四隅に祭壇と一体の角を造り、全体に青銅をかぶせなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="列王記第一 7:45; 民数記 4:14; 歴代誌上 28:17"> 灰を取り除く壺、灰取りシャベル、鉢、肉刺し、火皿を造りなさい。器具はすべて青銅とする。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 35:16; 出エジプト記 25:12; 出エジプト記 38:4–5"> そのために青銅の網目細工の格子を造りなさい。その格子の四隅に四つの青銅の環を造る。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 38:4"> それを祭壇の出っ張りの下、すなわち下部に取り付け、格子が祭壇の半分の高さに届くようにする。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 35:13–15; 民数記 4:44; 出エジプト記 30:4"> 祭壇のため、アカシアの木で担ぎ棒を造り、青銅をかぶせなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 25:28; 出エジプト記 30:4; 民数記 4:13–14"> 担ぎ棒を環に通し、祭壇を担ぐ時には両側に棒があるようにする。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 25:40; 出エジプト記 25:9; ヘブル人への手紙 8:5"> 板で中空に造りなさい。山で示された通りに造る。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 38:9–20; エゼキエル書 40:32; エゼキエル書 42:3"> 幕屋の庭を造りなさい。南側に向かう片側のために、撚り糸で織った亜麻布の庭の幕を設けなさい。長さは百キュビトとする。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 26:19–21; エレミヤ書 52:21; 出エジプト記 36:38"> その二十本の柱と二十の台座は青銅とする。柱の掛け釘と帯飾りは銀とする。</span>
<span className="v" id="v11" data-v="11"> 北側についても同様に、その長さに沿って百キュビトの幕を設ける。その二十本の柱と二十の台座は青銅とする。柱の掛け釘と帯飾りは銀とする。</span>
<span className="v" id="v12" data-v="12"> 西側の庭の幅については、五十キュビトの幕を設ける。その柱は十本、台座は十とする。</span>
<span className="v" id="v13" data-v="13"> 東に向かう東側の庭の幅は五十キュビトとする。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 27:9; 出エジプト記 26:36"> 入り口の一方の側の幕は十五キュビト、その柱は三本、台座は三つとする。</span>
<span className="v" id="v15" data-v="15"> もう一方の側の幕も十五キュビト、その柱は三本、台座は三つとする。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 26:36; 士師記 5:30; 出エジプト記 28:39"> 庭の入り口のためには、青色、紫色、緋色の糸、撚り糸で織った亜麻布で、刺繍をする者の細工による二十キュビトの幕を設ける。その柱は四本、台座は四つとする。</span>
<span className="v" id="v17" data-v="17"> 庭の周囲のすべての柱には銀の帯飾りを付け、その掛け釘は銀、台座は青銅とする。</span>
<span className="v" id="v18" data-v="18"> 庭の長さは百キュビト、幅は全体にわたって五十キュビト、高さは五キュビトとする。幕は撚り糸で織った亜麻布とし、その台座は青銅とする。</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 35:18; イザヤ書 22:23–25; 民数記 4:32"> すべての奉仕に用いる幕屋のすべての器具、そのすべての釘、および庭のすべての釘は青銅としなさい。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="レビ記 24:1–4; ゼカリヤ書 4:11–14; 詩篇 23:5"> イスラエルの子らに命じて、ともしびのために、ついて搾った純粋なオリーブ油をあなたのところに持って来させ、ともしびが常にともっているようにしなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="民数記 19:21; 民数記 18:23; サムエル記第一 3:3"> 会見の天幕の中、契約の前の垂れ幕の外側で、アロンとその子らは夕方から朝まで、主の前でともしびを整える。これはイスラエルの子らのための、代々にわたる永遠の掟である。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 4:15–16; 詩篇 82:6; ヨハネ 10:35–36"> 主はモーセに言われた。「見よ、わたしはあなたをファラオに対して神のような者とした。あなたの兄弟アロンは、あなたの預言者となる。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 4:15; 出エジプト記 6:29; 申命記 4:2"> あなたは、わたしが命じることをすべて語りなさい。あなたの兄弟アロンは、イスラエルの子らをその地から行かせるようファラオに告げる。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 4:21; 出エジプト記 11:9; 詩篇 105:27–36"> わたしはファラオの心をかたくなにし、エジプトの地でわたしのしるしと不思議な業を増し加える。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 11:9; 出エジプト記 6:6; 出エジプト記 12:51"> しかしファラオはあなたがたに聞き従わないであろう。それで、わたしはエジプトに手を下し、大いなる裁きによって、わたしの軍団でありわたしの民であるイスラエルの子らをエジプトの地から導き出す。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 14:18; 出エジプト記 7:17; 出エジプト記 8:22"> わたしがエジプトの上に手を伸ばし、イスラエルの子らを彼らの中から導き出す時、エジプト人はわたしが主であることを知るであろう。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 7:2; 創世記 6:22; 出エジプト記 7:10"> モーセとアロンはそのようにした。主が命じられた通りに行った。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 34:7; 使徒の働き 7:30; 申命記 31:2"> 彼らがファラオに語った時、モーセは八十歳、アロンは八十三歳であった。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 主はモーセとアロンに言われた。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 4:2; ヨハネ 2:18; イザヤ書 7:11"> 「ファラオが『奇跡を行え』と言うなら、アロンに『杖を取り、ファラオの前に投げなさい』と言いなさい。それは大蛇になる。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 4:3; ルカ 10:19; アモス書 9:3"> モーセとアロンはファラオのところに行き、主が命じられた通りにした。アロンはファラオとその家臣たちの前に杖を投げ、それは蛇になった。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 7:22; テモテへの第二の手紙 3:8; 出エジプト記 8:18"> そこでファラオも賢者たちや呪術師たちを呼び寄せた。エジプトの魔術師たちもまた、彼らの秘術を使って同じことをした。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの手紙第一 4:4; 出エジプト記 9:11; 出エジプト記 8:18–19"> 彼らもそれぞれ自分の杖を投げ、それらは蛇になった。しかしアロンの杖は彼らの杖を飲み込んだ。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 4:21; 出エジプト記 8:15; ゼカリヤ書 7:11–12"> しかしファラオの心はかたくなになり、主が語られた通り、彼らに聞き従わなかった。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 10:20; 出エジプト記 8:15; 出エジプト記 10:1"> 主はモーセに言われた。「ファラオの心は強情である。彼は民を行かせることを拒んでいる。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 8:20; 出エジプト記 2:5; 出エジプト記 7:10"> 朝、ファラオのもとへ行きなさい。彼は水辺へ出て来る。川岸に立って彼を待ち、蛇に変わった杖を手に取りなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 3:18; 出エジプト記 9:1; 出エジプト記 9:13"> 彼に言いなさい。『ヘブル人の神、主が私を遣わして、「わたしの民を行かせ、荒野でわたしに仕えさせよ」と言われました。しかし、あなたは今まで聞き従いませんでした。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 4:9; 出エジプト記 5:2; 出エジプト記 7:5"> 主はこう言われる。「これによって、あなたはわたしが主であることを知る。見よ、私は手にしている杖で川の水を打つ。水は血に変わる。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 7:24; 出エジプト記 7:21; 民数記 11:20"> 川の魚は死に、川は悪臭を放つようになる。エジプト人は川から水を飲むことを忌み嫌うようになるであろう。」』」</span>
<span className="v" id="v19" data-v="19" data-xref="出エジプト記 14:21; 出エジプト記 10:12; 出エジプト記 8:5–6"> 主はモーセに言われた。「アロンに言いなさい。『あなたの杖を取り、エジプトの水、その川、水路、池、およびすべての貯水池の上に手を伸ばして、それらを血に変えなさい。』そうすれば、エジプトの地全体で、木の器や石の器の中にさえ、血があるようになるであろう。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="詩篇 78:44; 詩篇 105:29; 出エジプト記 7:17–18"> モーセとアロンは主が命じられた通りにした。彼はファラオの目の前と、その家臣たちの目の前で杖を上げ、川の水を打った。すると、川の水はすべて血に変わった。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 7:18; ヨハネの黙示録 8:9"> 川の魚は死んだ。川は悪臭を放った。エジプト人は川から水を飲むことができなくなった。血はエジプトの地全体に及んだ。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 7:11; テモテへの第二の手紙 3:8; エレミヤ書 27:18"> エジプトの魔術師たちも彼らの秘術を使って同じことをした。そのため、ファラオの心はかたくなになり、主が語られた通り、彼らに聞き従わなかった。</span>
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 36:24; エゼキエル書 40:4; マラキ書 2:2"> ファラオは向き直って自分の家に入り、このことさえ心に留めなかった。</span>
<span className="v" id="v24" data-v="24"> エジプト人はみな、飲み水を得るため川の周りを掘った。川の水は飲めなかった。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 10:23; 出エジプト記 8:9–10; サムエル記第二 24:13"> 主が川を打たれてから、七日が満ちた。</span>
</div>

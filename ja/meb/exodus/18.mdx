<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 2:16; 詩篇 77:14–15; 出エジプト記 3:1"> ミディアンの祭司でモーセの義父であるエテロは、神がモーセとご自分の民イスラエルのためになされたすべてのこと、主がイスラエルをエジプトから導き出されたことを聞いた。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 2:21; 出エジプト記 4:25–26"> モーセの義父エテロは、送り返されていたモーセの妻チッポラと、</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 2:22; 使徒の働き 7:29; 詩篇 39:12"> また二人の息子を連れて来た。一人の名はゲルショム<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「ゲルショム」は、ヘブライ語の「そこにいる寄留者」という言葉に響きが似ている。">a</a></sup>であった。モーセが「私は異国の地で寄留者となった」と言ったからである。</span>
<span className="v" id="v4" data-v="4" data-xref="ヘブル人への手紙 13:6; テモテへの第二の手紙 4:17; コリント人への第二の手紙 1:8–10"> もう一人の名はエリエゼル<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「エリエゼル」は「私の神は助け」という意味である。">b</a></sup>であった。モーセが「父の神は私の助けとなり、ファラオの剣から救い出された」と言ったからである。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 3:1; 出エジプト記 3:12; 出エジプト記 24:16–17"> モーセの義父エテロは、モーセの息子たちと妻を連れ、荒野で神の山に宿営しているモーセのところに来た。</span>
<span className="v" id="v6" data-v="6"> エテロはモーセに使いを送り、「あなたの義父エテロが、あなたの妻と二人の息子を連れて来ました」と告げた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="創世記 29:13; 創世記 14:17; サムエル記第二 11:7"> モーセは義父を迎えるために出て行き、身をかがめて彼に口づけした。彼らは互いの安否を尋ね合い、天幕に入った。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 145:4–12; ネヘミヤ記 9:9–15; 詩篇 107:2"> モーセは義父に、主がイスラエルのためにファラオとエジプト人に行われたすべてのこと、途中で彼らに降りかかったすべての苦難、そして主が彼らをどのように救い出されたかを語った。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第一の手紙 12:26; ローマ人への手紙 12:15; イザヤ書 66:10"> エテロは、主がイスラエルをエジプト人の手から救い出して彼らに行われたすべての良いことを喜んだ。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 14:20; サムエル記第二 18:28; ルカ 1:68"> エテロは言った。「主はほめたたえられる方である。あなたがたをエジプト人とファラオの手から救い出し、民をエジプト人の支配から救い出された。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 95:3; 出エジプト記 15:11; 歴代誌 第二 2:5"> 今、私は知った。主はすべての神々にまさって大いなる方である。エジプト人がイスラエルに対して高ぶったその事によって、主が彼らにまさる方であることが明らかになった。」</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 31:54; 申命記 12:7; 出エジプト記 24:11"> モーセの義父エテロは全焼のいけにえと、神への犠牲を持って来た。アロンとイスラエルのすべての長老たちが来て、モーセの義父と共に神の前でパンを食べた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 16:5; ヨブ記 29:7; 士師記 5:10"> 翌日、モーセは民を裁くために座り、民は朝から夕方までモーセの周りに立っていた。</span>
<span className="v" id="v14" data-v="14"> モーセの義父は、彼が民のためにしていることを見て言った。「あなたが民のためにしているこの事は何ですか。なぜあなただけが座り、民はみな朝から夕方まであなたの周りに立っているのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数記 15:34; 民数記 27:5; 民数記 9:8"> モーセは義父に言った。「民が神に尋ねるために私のところに来るからです。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 24:14; コリント人への第一の手紙 6:1; サムエル記第二 15:3"> 彼らに事柄がある時、彼らは私のところに来ます。私は一人とその隣人との間を裁き、神の掟と律法を知らせるのです。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> モーセの義父は彼に言った。「あなたのしている事は良くありません。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 11:14–17; 使徒の働き 6:1–4; コリント人への第二の手紙 12:15"> あなたも、あなたと一緒にいるこの民も、必ず疲れ果ててしまいます。この事はあなたには重すぎます。あなた一人でそれを行うことはできません。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 27:5; 申命記 5:5; 出エジプト記 20:19"> 今、私の助言を聞きなさい。神があなたと共におられますように。あなたは民を代表して神の前に立ち、その事柄を神に持って行きなさい。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 5:1; 詩篇 143:8; 申命記 1:18"> あなたは彼らに掟と律法を教え、彼らが歩むべき道と、なすべき事を彼らに示しなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 6:3; 申命記 1:13–17; 歴代誌 第二 19:5–10"> さらにあなたは、すべての民の中から、神を恐れる有能な人々、真実な人々、不当な利益を憎む人々を見つけ出し、彼らを千人の長、百人の長、五十人の長、十人の長として民の上に立てなさい。</span>
<span className="v" id="v22" data-v="22" data-xref="民数記 11:17; 民数記 27:2; 民数記 15:33"> 彼らに常に民を裁かせなさい。すべての大きな事柄はあなたのところに持って来させ、すべての小さな事柄は彼ら自身で裁かせなさい。そうすれば、あなたには楽になり、彼らはあなたと重荷を分かち合うでしょう。</span>
<span className="v" id="v23" data-v="23" data-xref="サムエル記第一 8:6–7; 出エジプト記 18:18; サムエル記第一 8:22"> もしこのように行い、神もそう命じられるなら、あなたは耐えることができ、この民もみな無事に自分の所へ帰ることができるでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="エズラ記 10:2; 出エジプト記 18:19; 出エジプト記 18:2–5"> そこでモーセは義父の声に聞き従い、彼が言った通りのことをすべて行った。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 1:15; 出エジプト記 18:21; 使徒の働き 6:5"> モーセは全イスラエルの中から有能な人々を選び、彼らを民の頭、すなわち千人の長、百人の長、五十人の長、十人の長とした。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 18:22; 出エジプト記 18:14–15; 申命記 17:8"> 彼らは常に民を裁いた。難しい事柄はモーセのところに持って来たが、小さな事柄はすべて彼ら自身で裁いた。</span>
<span className="v" id="v27" data-v="27" data-xref="民数記 10:29–30; 士師記 19:9; 創世記 31:55"> モーセは義父を送り出し、彼は自分の地へ帰って行った。</span>
</div>
</div>

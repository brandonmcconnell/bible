<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数記 18:7; ヘブル人への手紙 5:1–5; 民数記 17:2–9"> あなたの兄弟アロンと、その子らを彼と共に、イスラエルの子らの中からあなたの近くに呼び寄せ、祭司としてわたしに仕えさせなさい。すなわち、アロンと、アロンの子らであるナダブ、アビフ、エルアザル、イタマルである。</span>
<span className="v" id="v2" data-v="2" data-xref="レビ記 8:30; 出エジプト記 31:10; ヨハネの黙示録 19:8"> 栄光と美しさのために、あなたの兄弟アロンのために聖なる衣服を造りなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="エペソ人への手紙 1:17; コリント人への第一の手紙 12:7–11; イザヤ書 11:2"> わたしが知恵の霊で満たした、心に知恵のある者たちに告げ、アロンの衣服を造らせなさい。彼を聖別し、祭司としてわたしに仕えさせるためである。</span>
<span className="v" id="v4" data-v="4" data-xref="エペソ人への手紙 6:14; ヨハネの黙示録 9:17; イザヤ書 59:17"> 造る衣服は、胸当て、エポデ、上着、織り模様の長衣、ターバン、飾り帯である。アロンとその子らが祭司として仕えるため、聖なる衣服を造りなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 25:3–4; 出エジプト記 39:2–3"> 金、青色、紫色、緋色の糸、および亜麻布を用いる。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 39:2–7; 出エジプト記 26:1"> 熟練した職人の細工によって、金、青色、紫色、緋色の糸と、撚り糸で織った亜麻布でエポデを造る。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 39:4"> 両端に二つの肩ひもを付け、つなぎ合わせる。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 28:27–28; レビ記 8:7; 出エジプト記 29:5"> エポデの上にある巧みに織られた帯は、同じような細工で、それと一体にしなさい。すなわち、金、青色、紫色、緋色の糸、撚り糸で織った亜麻布で作る。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 28:13; 歴代誌 第二 2:7; イザヤ書 49:16"> 二つの縞めのうを取り、その上にイスラエルの子らの名前を彫りなさい。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 1:1–4; 創世記 43:33"> 一方の石に彼らの名前を六つ、もう一方の石に残りの六つの名前を、生まれた順に彫りなさい。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテへの第二の手紙 2:19; ヨハネの黙示録 7:2; エレミヤ書 22:24"> 石の彫刻師が印章を彫るように、イスラエルの子らの名を二つの石に彫り、金の枠にはめ込みなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 28:29; ヨシュア記 4:7; 出エジプト記 39:6–7"> その二つの石をエポデの肩ひもに付け、イスラエルの子らのための記念の石としなさい。アロンは彼らの名前を主の前の両肩に負い、記念とする。</span>
<span className="v" id="v13" data-v="13"> 金の枠を造りなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 39:15; 出エジプト記 39:17–18; 列王記第一 7:17"> 純金で、撚り合わせたひものような二本の鎖を造り、枠に取り付けなさい。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 28:30; 出エジプト記 26:1; 出エジプト記 28:4"> 熟練した職人の細工によって裁きの胸当てを造りなさい。エポデと同じく、金、青色、紫色、緋色の糸と、撚り糸で織った亜麻布で造る。</span>
<span className="v" id="v16" data-v="16"> 正方形に二つ折りにし、長さも幅も一スパン<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一スパンは、大人が手を広げた時の親指の先から小指の先までの長さで、約半キュビト、すなわち約二十二・八センチメートルである。">a</a></sup>とする。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 28:13; 出エジプト記 39:10–21; 箴言 8:11"> その中に石をはめ込み、四列の石を並べなさい。第一列はルビー、トパーズ、緑柱石の列としなさい。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 27:16; ヨブ記 28:6; 雅歌 5:14"> 第二列はトルコ石、サファイア<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="あるいは、ラピスラズリ。">b</a></sup>、エメラルドとする。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 54:12; 出エジプト記 39:12"> 第三列はヒヤシンス石、めのう、紫水晶とする。</span>
<span className="v" id="v20" data-v="20" data-xref="エゼキエル書 1:16; ヨハネの黙示録 4:3; ダニエル書 10:6"> 第四列はクリソライト、縞めのう、碧玉とし、金の枠にはめ込む。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨハネの黙示録 21:12; ヨハネの黙示録 7:4–8; 列王記第一 18:31"> 石はイスラエルの子らの名に従って十二個とする。印章を彫るように、それぞれ十二部族の名を彫りなさい。</span>
<span className="v" id="v22" data-v="22"> 胸当ての上に、純金で撚り合わせた編んだひものような鎖を造りなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 25:11–15"> 胸当ての上に二つの金の環を造り、その二つの環を胸当ての両端に取り付けなさい。</span>
<span className="v" id="v24" data-v="24"> その二つの金の編んだ鎖を、胸当ての端にある二つの環に通しなさい。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 39:15; 出エジプト記 39:4; 出エジプト記 28:14"> 二つの編んだ鎖の他の二つの端を、二つの枠に取り付け、それをエポデの前面の肩ひもに取り付けなさい。</span>
<span className="v" id="v26" data-v="26"> 二つの金の環を造り、胸当ての両端、すなわち内側のエポデに向いている側の縁にそれを取り付けなさい。</span>
<span className="v" id="v27" data-v="27"> 二つの金の環を造り、それをエポデの二つの肩ひもの下部、前面のつなぎ目の近く、エポデの巧みに織られた帯の上に取り付けなさい。</span>
<span className="v" id="v28" data-v="28" data-xref="民数記 15:38; 出エジプト記 28:31; 出エジプト記 39:30–31"> 胸当ての環とエポデの環を青いひもで結び、胸当てをエポデの帯の上に固定して、ずれないようにする。</span>
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 28:12; 出エジプト記 28:30; エレミヤ書 30:21"> アロンは聖所に入る時、裁きの胸当てにあるイスラエルの子らの名を胸に帯び、主の前で絶えず記念とする。</span>
<span className="v" id="v30" data-v="30" data-xref="ネヘミヤ記 7:65; エズラ記 2:63; 民数記 27:21"> 裁きの胸当てにウリムとトンミムを入れなさい。アロンが主の前に進み出る時、それらを胸に帯びる。こうしてアロンは、イスラエルの子らの裁きを常に主の前で胸に負う。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="レビ記 8:7; 出エジプト記 28:4; 出エジプト記 39:22–26"> エポデの上着を、すべて青色で造りなさい。</span>
<span className="v" id="v32" data-v="32" data-xref="ネヘミヤ記 4:16; ヨハネ 19:23–24; 出エジプト記 39:28"> 中央に頭を通す穴を設け、よろいの襟のように周囲を織物で縁取り、裂けないようにする。</span>
<span className="v" id="v33" data-v="33" data-xref="出エジプト記 39:24–26; ゼカリヤ書 14:20; 列王記第一 7:18"> その裾の周囲には、青色、紫色、緋色の糸でざくろを造り、その裾の周囲に置き、それらの間に金の鈴を配置しなさい。</span>
<span className="v" id="v34" data-v="34" data-xref="雅歌 8:2; ヨハネ 15:4–8; コロサイ人への手紙 1:10"> 上着の裾の周囲に、金の鈴とざくろ、金の鈴とざくろを交互に配置する。</span>
<span className="v" id="v35" data-v="35" data-xref="ヘブル人への手紙 9:12; レビ記 16:2"> アロンは奉仕の時にこれを着る。彼が主の前の聖所に入る時も、出る時も、その音が聞こえるようにする。そうすれば死ぬことはない。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="ゼカリヤ書 14:20; レビ記 8:9; 出エジプト記 39:30"> 純金の札を造り、印章を彫るように、その上に『主に聖なるもの』と彫りなさい。</span>
<span className="v" id="v37" data-v="37" data-xref="出エジプト記 29:6; 出エジプト記 28:4; ゼカリヤ書 3:5"> それを青いひもに付け、ターバンの前面に置きなさい。</span>
<span className="v" id="v38" data-v="38" data-xref="ペテロの手紙第一 2:24; 民数記 18:1; レビ記 10:17"> それをアロンの額に置く。アロンは、イスラエルの子らが聖なる贈り物として献げる聖なる物に関わる咎を負う。それが常に額にあれば、彼らは主の前に受け入れられる。</span>
<span className="v" id="v39" data-v="39" data-xref="詩篇 45:14"> 亜麻布で長衣とターバンを造り、刺繍をする者の細工によって飾り帯を造りなさい。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="出エジプト記 39:41; 出エジプト記 28:4; 出エジプト記 28:2"> アロンの子らのためにも長衣、飾り帯、頭帯を造り、栄光と美しさを表しなさい。</span>
<span className="v" id="v41" data-v="41" data-xref="出エジプト記 29:7; レビ記 8:1–36; 出エジプト記 40:15"> あなたの兄弟アロンと、彼と共にいるその子らにこれらを着せ、彼らに油を注ぎ、彼らを任職し、聖別して、祭司としてわたしに仕えさせなさい。</span>
<span className="v" id="v42" data-v="42" data-xref="エゼキエル書 44:18; レビ記 6:10; レビ記 16:4"> 裸を覆うため、亜麻布の下衣を造りなさい。腰からももまでを覆うものとする。</span>
<span className="v" id="v43" data-v="43" data-xref="出エジプト記 27:21; 出エジプト記 20:26; レビ記 5:17"> アロンとその子らが会見の天幕に入る時、また聖所で仕えるため祭壇に近づく時に、これを身に着ける。咎を負って死ぬことのないためである。これは彼とその子孫に対する永遠の掟である。</span>
</div>

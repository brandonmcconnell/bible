<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ルカ 19:8; サムエル記第二 12:6; 箴言 6:31"> 人が牛や羊を盗み、それを殺すか売ったなら、牛一頭には牛五頭、羊一匹には羊四匹をもって償う。</span>
<span className="v" id="v2" data-v="2" data-xref="マタイ 24:43; マタイ 6:19–20; 民数記 35:27"> もし泥棒が押し入るところを見つけられ、打たれて死んだ場合、彼について血を流した罪はない。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 21:2; イザヤ書 50:1; マタイ 18:25"> しかし、日が昇ってからなら、打った者には血を流した罪がある。泥棒は必ず償う。何も持っていなければ、その盗みの償いとして売られる。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 22:7; 出エジプト記 22:1; 出エジプト記 22:9"> 盗んだ牛、ろば、羊が生きたまま手元で見つかったなら、二倍にして償う。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 22:3; 出エジプト記 22:12; ヨブ記 20:18"> 人が自分の家畜を放し、畑やぶどう園を食い荒らさせて他人の畑で食べさせたなら、自分の畑とぶどう園の最良のものをもって償う。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 22:9; 出エジプト記 21:33–34; サムエル記第二 14:30–31"> 火が出ていばらに燃え移り、積んだ穀物、立ち穂、または畑を焼いたなら、火をつけた者が必ず償う。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 22:4; 箴言 6:30–31; エレミヤ書 2:26"> 人が隣人に金銭や物品を預け、それが家から盗まれた場合、泥棒が見つかれば、泥棒は二倍にして償う。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 22:28; 申命記 16:18; 出エジプト記 21:6"> 泥棒が見つからなければ、家の主人は神の前に出て、隣人の財産に手をつけなかったかどうか、裁きを受ける。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 25:1; 出エジプト記 22:4; 民数記 5:6–7"> 牛、ろば、羊、衣服、そのほか失われた物について、双方が「これは私のものだ」と主張するなら、その訴えを神の前に持ち出す。神が有罪とされた者は、隣人に二倍にして償う。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ルカ 12:48; テモテへの第二の手紙 1:12; ルカ 16:11"> 人が隣人に、ろば、牛、羊、あるいはいかなる動物でも預けて保管させ、それが死ぬか、傷つくか、あるいは誰も見ていないところで追い去られた場合、</span>
<span className="v" id="v11" data-v="11" data-xref="ヘブル人への手紙 6:16; レビ記 5:1; 列王記第一 2:42–43"> 隣人の財産に手をつけなかったことを、主にかけて誓いなさい。持ち主はその誓いを受け入れ、預かった者は償わなくてよい。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 31:39; 出エジプト記 22:7"> しかし、預かった者のもとから盗まれたなら、その人が持ち主に償う。</span>
<span className="v" id="v13" data-v="13" data-xref="ナホム書 2:12; ミカ書 5:8; エゼキエル書 4:14"> 野獣に引き裂かれたなら、証拠としてその死骸を持って来なさい。引き裂かれたものを償う必要はない。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命記 23:19–20; 出エジプト記 21:34; 申命記 15:2"> 人が隣人から動物を借り、持ち主が一緒にいない時に傷つくか死んだなら、必ず償う。</span>
<span className="v" id="v15" data-v="15" data-xref="ゼカリヤ書 8:10"> もしその持ち主が一緒にいたなら、彼は償う必要はない。それが賃借りされたものであったなら、借り賃に含まれる。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命記 22:28–29; 創世記 34:2–4"> 人が婚約していない処女を誘い、彼女と寝たなら、結納金を払い、妻として迎える。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 34:12; サムエル記第一 18:25; 申命記 22:29"> 父が娘を与えることを固く拒むなら、処女の結納金に相当する額を支払う。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="レビ記 20:27; 申命記 18:10–11; サムエル記第一 28:3"> 呪術を使う女を生かしておいてはならない。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="レビ記 18:23; 申命記 27:21; レビ記 20:15–16"> 動物と寝る者はみな、必ず死刑に処せられる。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命記 17:2–5; 民数記 25:7–8; 申命記 18:20"> 主おひとりのほか、神々にいけにえを献げる者は、必ず滅ぼされる。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 23:9; 申命記 10:19; レビ記 19:33"> 寄留者を不当に扱ったり、しいたげたりしてはならない。あなたがたもエジプトの地で寄留者であった。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命記 24:17; イザヤ書 1:17; イザヤ書 1:23"> あなたはどのようなやもめも、孤児も苦しめてはならない。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 18:6; 詩篇 10:17–18; ルカ 18:7"> もしあなたが彼らを少しでも苦しめ、彼らが少しでもわたしに向かって叫ぶなら、わたしは必ず彼らの叫びを聞く。</span>
<span className="v" id="v24" data-v="24" data-xref="詩篇 109:9; エレミヤ書 15:8; 詩篇 76:7"> そしてわたしの怒りは燃え上がり、わたしは剣であなたがたを殺す。あなたがたの妻はやもめとなり、あなたがたの子どもたちは孤児となるであろう。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="詩篇 15:5; レビ記 25:35–37; 申命記 23:19–20"> もしあなたが、あなたと共にいるわたしの民の貧しい者にお金を貸すなら、彼に対して金貸しのようになってはならない。彼から利息を取ってはならない。</span>
<span className="v" id="v26" data-v="26" data-xref="箴言 20:16; アモス書 2:8; 申命記 24:6"> 隣人の上着を担保に取ったなら、日が沈む前に返しなさい。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 34:6; 歴代誌 第二 30:9; 詩篇 136:10–11"> それは彼の唯一の覆い、身を包む上着である。ほかに何を着て眠ることができよう。彼がわたしに叫ぶなら、わたしは聞く。わたしは恵み深い。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="使徒の働き 23:5; 伝道者の書 10:20; 出エジプト記 22:8–9"> 神を冒瀆してはならない。また、あなたの民の指導者をのろってはならない。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 23:16; 出エジプト記 13:2; ヤコブの手紙 1:18"> 収穫物と搾り場からあふれるものを献げるのに、遅れてはならない。息子たちの初子をわたしに献げなさい。</span>
<span className="v" id="v30" data-v="30" data-xref="レビ記 22:27; 申命記 15:19; 出エジプト記 13:12"> 牛と羊についても同じようにする。七日間は母親と共に置き、八日目にわたしに献げなさい。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="エゼキエル書 4:14; レビ記 19:2; 申命記 14:21"> あなたがたは、わたしにとって聖なる民となりなさい。それゆえ、野で獣に引き裂かれた肉を食べてはならない。犬に投げ与えなさい。</span>
</div>

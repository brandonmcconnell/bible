<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 16:1; 出エジプト記 12:6; レビ記 23:16–18"> イスラエルの子らがエジプトの地を出てから三か月目、その同じ日に、彼らはシナイの荒野に着いた。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 3:1; 出エジプト記 17:1; 出エジプト記 3:12"> 彼らはレフィディムから旅立ち、シナイの荒野に来て、荒野に宿営した。イスラエルはそこで山の前に宿営した。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 3:4; 使徒の働き 7:38; 出エジプト記 20:21"> モーセは神のもとへ上って行った。主は山から彼を呼んで言われた。「ヤコブの家にこう言い、イスラエルの子らに告げなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="申命記 32:11–12; イザヤ書 63:9; イザヤ書 40:31"> 『あなたがたは、わたしがエジプト人に行ったこと、また、わたしがあなたがたを鷲の翼に乗せて、わたしのもとに連れて来たことを見た。</span>
<span className="v" id="v5" data-v="5" data-xref="申命記 14:2; 申命記 7:6; 申命記 26:18"> 今、もしあなたがたがわたしの声によく聞き従い、わたしの契約を守るなら、あなたがたはすべての民の中でわたしの宝の民となる。全地はわたしのものである。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネの黙示録 5:10; ペテロの手紙第一 2:9; ペテロの手紙第一 2:5"> あなたがたはわたしにとって、祭司の王国、聖なる国民となる。』これが、あなたがイスラエルの子らに語るべき言葉である。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 4:29–30; 出エジプト記 3:16; コリント人への第一の手紙 15:1"> モーセは来て、民の長老たちを呼び寄せ、主が彼に命じられたこれらすべての言葉を彼らの前に置いた。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 24:7; 出エジプト記 24:3; ヨシュア記 24:24"> 民は皆一緒に答えて言った。「主が言われたことを、私たちはすべて行います。」モーセは民の言葉を主に持ち帰った。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命記 4:36; 出エジプト記 19:16; 出エジプト記 24:15–16"> 主はモーセに言われた。「見よ、わたしは濃い雲の中であなたのもとへ来る。わたしがあなたと語るのを民が聞き、いつまでもあなたを信じるためである。」モーセは民の言葉を主に告げた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 10:22; 創世記 35:2; レビ記 11:44–45"> 主はモーセに言われた。「民のところに行き、今日と明日、彼らを聖別しなさい。彼らに衣服を洗わせ、</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 19:16; 出エジプト記 34:5; 申命記 33:2"> 三日目に備えさせなさい。三日目に、主はすべての民の目の前でシナイ山に下られる。</span>
<span className="v" id="v12" data-v="12" data-xref="ヘブル人への手紙 12:20–21; ヨシュア記 3:4; 出エジプト記 19:21"> 民のために山の周囲に境を設け、告げなさい。『山に上ったり、その境に触れたりしないよう気をつけよ。山に触れる者は必ず死刑に処せられる。</span>
<span className="v" id="v13" data-v="13" data-xref="テサロニケ人への手紙第一 4:16; ヘブル人への手紙 12:20; 出エジプト記 19:16"> その者に手を触れてはならない。石で打つか、矢で射抜かなければならない。人でも動物でも、生かしておいてはならない。』角笛が長く鳴り響く時、彼らは山のふもとへ近づいてよい。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 19:10"> モーセは山から民のところに下り、民を聖別した。彼らは衣服を洗った。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 7:5; サムエル記第一 21:4–5; 出エジプト記 19:11"> 彼は民に言った。「三日目に備えなさい。女に近づいてはならない。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 12:18–19; 詩篇 18:11–14; ヘブル人への手紙 12:21"> 三日目の朝になると、雷と稲妻があり、濃い雲が山の上にあった。そして非常に大きな角笛の音がして、陣営にいたすべての民は震えた。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 4:10; 申命記 5:5"> モーセは神に会うために、民を陣営から導き出し、彼らは山のふもとに立った。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 5:5; 出エジプト記 3:2; 詩篇 144:5"> シナイ山は全体が煙に包まれた。主が火の中でその上に下られたのである。煙はかまどの煙のように立ち上り、山全体が激しく震えた。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 81:7; 出エジプト記 19:16; ネヘミヤ記 9:13"> 角笛の音がますます大きくなった時、モーセは語り、神は声を出して彼に答えられた。</span>
<span className="v" id="v20" data-v="20" data-xref="ネヘミヤ記 9:13; 出エジプト記 34:2; 出エジプト記 19:11"> 主はシナイ山の上、その山の頂に下られた。主はモーセを山の頂に呼ばれ、モーセは上って行った。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="サムエル記第一 6:19; 出エジプト記 3:5; ヘブル人への手紙 12:28–29"> 主はモーセに言われた。「下って行き、民が境を破って主を見ようとし、多くの者が滅びることのないよう警告しなさい。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 24:5; 使徒の働き 5:10; 歴代誌上 13:9–11"> 主に近づく祭司たちも自らを聖別しなさい。主が彼らを打つことのないためである。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 19:12; ヨシュア記 3:4–5"> モーセは主に言った。「民はシナイ山に上ることはできません。あなたが私たちに『山の周囲に境界を設け、それを聖別しなさい』と言って警告されたからです。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヘブル人への手紙 4:16; ヘブル人への手紙 12:18–25; ヘブル人への手紙 12:29"> 主は彼に言われた。「下りなさい。そしてアロンを連れて上りなさい。しかし、祭司たちや民が境を破って主のもとへ上り、主が彼らを打つことのないようにしなさい。」</span>
<span className="v" id="v25" data-v="25"> そこでモーセは民のところに下り、彼らに語った。</span>
</div>
</div>

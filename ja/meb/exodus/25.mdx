<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに言われた。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第二の手紙 9:7; ネヘミヤ記 11:2; エズラ記 2:68"> 「イスラエルの子らに、わたしのためにささげ物を持って来るように言いなさい。心から喜んでささげるすべての人から、わたしのためのささげ物を受け取りなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="申命記 8:9; ヨブ記 28:2"> あなたがたが彼らから受け取るべきささげ物は、次の通りである。金、銀、青銅、</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの黙示録 19:8; 創世記 41:42; エゼキエル書 16:10"> 青色、紫色、緋色の糸、撚り糸で織った亜麻布、山羊の毛、</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 26:37–1; 出エジプト記 26:14–15; 出エジプト記 36:20"> 赤く染めた雄羊の皮、ジュゴンの皮<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="あるいは、上質な革。">a</a></sup>、アカシアの木、</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 27:20; 出エジプト記 25:37; 出エジプト記 40:24–25"> 灯火のための油、注ぎ油と香りのよい香のための香料、</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 28:4; 出エジプト記 28:6–30"> 縞めのう、そしてエポデや胸当てにはめ込むための宝石である。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第二の手紙 6:16; 列王記第一 6:13; ヨハネの黙示録 21:3"> 彼らにわたしのための聖所を造らせなさい。わたしは彼らのただ中に住む。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 25:40; ヘブル人への手紙 8:5; 使徒の働き 7:44"> わたしが示す幕屋の型と、そのすべての器具の型に従って造りなさい。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ヘブル人への手紙 9:4; 出エジプト記 37:1–3; 申命記 10:1–3"> アカシアの木で箱を造りなさい。長さは二・五キュビト<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一キュビトは、大人の腕の中指の先から肘までの長さで、約十八インチ、すなわち約四十六センチメートルである。">b</a></sup>、幅は一・五キュビト、高さは一・五キュビトとする。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 25:24; 出エジプト記 30:3; 歴代誌 第二 3:4"> 内側にも外側にも純金をかぶせ、その周囲に金の飾り縁を造りなさい。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 27:7; 出エジプト記 25:26; 出エジプト記 25:15"> そのために四つの金の環を鋳造し、その四つの足に取り付けなさい。一方の側に二つの環、もう一方の側にも二つの環を取り付ける。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代誌上 15:15; 民数記 4:11; 出エジプト記 27:6"> アカシアの木で担ぎ棒を造り、金をかぶせなさい。</span>
<span className="v" id="v14" data-v="14"> 担ぎ棒を箱の両側の環に通し、それで箱を担ぐ。</span>
<span className="v" id="v15" data-v="15" data-xref="列王記第一 8:8; 歴代誌 第二 5:9"> 担ぎ棒は箱の環に差したままにし、外してはならない。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 31:26; 列王記第一 8:9; ヘブル人への手紙 9:4"> わたしが与えるあかしを箱の中に納めなさい。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 9:5; 出エジプト記 37:6; ヘブル人への手紙 4:16"> 純金で贖いの座を造りなさい。その長さは二・五キュビト、幅は一・五キュビトとする。</span>
<span className="v" id="v18" data-v="18" data-xref="エゼキエル書 10:20; ヘブル人への手紙 9:5; 列王記第一 8:6–7"> 打ち出し細工の金で二つのケルビムを造り、贖いの座の両端に置きなさい。</span>
<span className="v" id="v19" data-v="19"> 一方の端に一つ、もう一方の端に一つのケルブを造り、贖いの座と一体にする。</span>
<span className="v" id="v20" data-v="20" data-xref="歴代誌上 28:18; 列王記第一 8:7; ヘブル人への手紙 9:5"> ケルビムは翼を上に広げ、その翼で贖いの座を覆う。顔を互いに向け、贖いの座の方を向くようにする。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 26:34; ローマ人への手紙 10:4; 出エジプト記 25:16–17"> その贖いの座を箱の上に置き、箱の中にはわたしがあなたに与えるあかしを納めなさい。</span>
<span className="v" id="v22" data-v="22" data-xref="出エジプト記 29:42–43; 民数記 7:89; イザヤ書 37:16"> そこでわたしはあなたと会い、贖いの座の上から、すなわちあかしの箱の上にある二つのケルビムの間から、イスラエルの子らのためにあなたに命じるすべてのことを語る。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ヘブル人への手紙 9:2; 出エジプト記 37:10–16; 列王記第一 7:48"> アカシアの木で机を造りなさい。その長さは二キュビト、幅は一キュビト、高さは一・五キュビトとする。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 25:11; 列王記第一 6:20–22"> それに純金をかぶせ、その周りに金の飾り縁を造りなさい。</span>
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 37:2; 出エジプト記 30:3"> その周りに手の幅の枠を造り、その枠の周りにも金の飾り縁を造りなさい。</span>
<span className="v" id="v26" data-v="26"> そのために四つの金の環を造り、四つの足にある四隅にその環を取り付けなさい。</span>
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 25:14; 出エジプト記 25:28"> 環は枠の近くに設け、机を担ぐ棒を通す場所とする。</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 25:14; 使徒の働き 9:15; 民数記 10:17"> アカシアの木で担ぎ棒を造り、金をかぶせ、それで机を担ぐ。</span>
<span className="v" id="v29" data-v="29" data-xref="民数記 4:7; 出エジプト記 37:16; ヨハネの黙示録 3:20"> 注ぎのささげ物に用いる皿、さじ、水差し、鉢を純金で造りなさい。</span>
<span className="v" id="v30" data-v="30" data-xref="レビ記 24:5–9; マタイ 12:4; 出エジプト記 39:36"> 常にわたしの前の机の上に、供えのパンを置きなさい。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王記第一 7:49; ゼカリヤ書 4:2; 出エジプト記 37:17–24"> 純金で燭台を造りなさい。打ち出し細工とし、台座、支柱、杯、節、花をすべて一体にする。</span>
<span className="v" id="v32" data-v="32"> その側面からは六つの枝を出させる。すなわち、一方の側から燭台の三つの枝を出し、もう一方の側から燭台の三つの枝を出す。</span>
<span className="v" id="v33" data-v="33" data-xref="民数記 17:4–8; エレミヤ書 1:11–12; ゼカリヤ書 4:3"> 一つの枝にはアーモンドの花のような三つの杯、節、花を造り、もう一つの枝にもアーモンドの花のような三つの杯、節、花を造る。燭台から出ている六つの枝をそのようにする。</span>
<span className="v" id="v34" data-v="34"> 燭台の支柱には、アーモンドの花のような四つの杯、節、花を造る。</span>
<span className="v" id="v35" data-v="35"> 燭台から出ている六つの枝のために、それと一体の二つの枝の下に一つの節、それと一体の他の二つの枝の下に一つの節、それと一体のさらに他の二つの枝の下に一つの節を造る。</span>
<span className="v" id="v36" data-v="36" data-xref="出エジプト記 25:18; 列王記第一 10:16–17; 歴代誌 第二 9:15"> それらの節と枝は燭台と一体とし、その全体を一つの純金の打ち出し細工としなさい。</span>
<span className="v" id="v37" data-v="37" data-xref="民数記 8:2; ヨハネの黙示録 1:20–1; レビ記 24:2–4"> 七つのともしび皿を造り、前方を照らすように火をともす。</span>
<span className="v" id="v38" data-v="38" data-xref="列王記第二 12:13; エレミヤ書 52:18; 列王記第二 25:14"> その芯切りばさみも芯取り皿も純金とする。</span>
<span className="v" id="v39" data-v="39"> これらの器具を含め、一タラント<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一タラントは約三十キログラム、すなわち六十六ポンド、または九百六十五トロイオンスである。">c</a></sup>の純金で造る。</span>
<span className="v" id="v40" data-v="40" data-xref="ヘブル人への手紙 8:5; 出エジプト記 26:30; 使徒の働き 7:44"> 山で示された型の通りに造るよう、注意しなさい。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 主はモーセに言われた。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカ 2:23; 民数記 3:13; 申命記 15:19"> 「イスラエルの子らのうち、人でも動物でも、胎を開く初子はすべて、わたしのために聖別しなさい。それはわたしのものである。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命記 24:18; 申命記 5:15; 出エジプト記 20:2"> モーセは民に言った。「エジプト、奴隷の家から出たこの日を覚えていなさい。主が力強い手であなたがたをそこから導き出された。種入りパンを食べてはならない。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 34:18; 出エジプト記 23:15; 出エジプト記 12:2"> あなたがたは今日、アビブの月に旅立った。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 3:8; ヨシュア記 24:11; 出エジプト記 12:25–26"> 主が、カナン人、ヘト人、アモリ人、ヒビ人、エブス人の地、すなわち父祖たちに与えると誓われた乳と蜜の流れる地へ導き入れられた時、この月にこの儀式を行いなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 12:15–20; 出エジプト記 34:18; レビ記 23:8"> 七日間、種なしパンを食べ、七日目には主への祭りを祝う。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 12:19; マタイ 16:6"> 七日間、種なしパンを食べなさい。種入りパンもパン種も、あなたの領土のどこにもあってはならない。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 13:14; 出エジプト記 12:26–27; 詩篇 44:1"> その日、子に告げなさい。『これは、私がエジプトから出た時、主が私のためになさったことのゆえである。』</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 6:8; 申命記 11:18–19; 民数記 15:39"> これを手のしるし、目の間の記念とし、主の律法があなたの口にあるようにしなさい。主が力強い手であなたをエジプトから導き出されたからである。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 12:14; 出エジプト記 12:24–25; 出エジプト記 23:15"> この掟を、定められた時に年ごとに守りなさい。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 13:5"> 主があなたとあなたの父祖たちに誓われたように、あなたをカナン人の地に導き入れ、そこをあなたに与えられる時、</span>
<span className="v" id="v12" data-v="12" data-xref="民数記 18:15; レビ記 27:26; 出エジプト記 34:19"> 胎を開くものをすべて主のために取り分けなさい。家畜の初子の雄は、すべて主のものである。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 34:20; 民数記 18:15–17; ヨハネの黙示録 14:4"> ろばの初子は小羊で贖いなさい。贖わないなら、その首を折る。あなたの息子の初子はみな贖いなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 13:3; ヨシュア記 4:6; 詩篇 145:4"> 後になってあなたの子が『これは何ですか』と尋ねるなら、あなたは彼に言いなさい。『主は力強い手で、奴隷の家であるエジプトから私たちを導き出された。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 12:29"> ファラオが頑なになって私たちを行かせることを拒んだ時、主はエジプトの地の初子を、人から家畜に至るまでみな殺された。それゆえ私は、胎を開く雄の初子を主に献げ、息子の初子はみな贖う。』</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 13:9; 申命記 11:18; 申命記 6:7–9"> これを手のしるし、目の間の記章としなさい。主が力強い手で私たちをエジプトから導き出されたからである。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 14:11–12; ネヘミヤ記 9:17; 民数記 14:1–4"> ファラオが民を行かせた時、ペリシテ人の地を通る道は近かったが、神はその道に導かれなかった。神は「民は戦いを見れば心を変え、エジプトへ戻るかもしれない」と考えられた。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 14:2; 申命記 32:10; 民数記 33:6–8"> 神は民を、荒野の道を通って紅海の方へと回り道させた。イスラエルの子らはエジプトの地から武装して上った。</span>
<span className="v" id="v19" data-v="19" data-xref="創世記 50:24–25; ヨシュア記 24:32; 使徒の働き 7:16"> モーセはヨセフの骨を携えていた。ヨセフがイスラエルの子らに、「神は必ずあなたがたを顧みられる。その時、私の骨をここから携えて上りなさい」と固く誓わせていたからである。</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 33:5–6; 出エジプト記 12:37"> 彼らはスコテを出発し、荒野の端にあるエタムに宿営した。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第一の手紙 10:1–2; ネヘミヤ記 9:12; 申命記 1:33"> 主は、昼は雲の柱で彼らを導き、夜は火の柱で彼らを照らして、彼らを昼夜とも進ませるために、彼らの前を進まれた。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 121:5–8; ヨハネの黙示録 10:1"> 昼は雲の柱、夜は火の柱が、民の前から離れることはなかった。</span>

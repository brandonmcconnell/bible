<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 8:1; 出エジプト記 10:3; 出エジプト記 8:20"> 主はモーセに言われた。「ファラオのところに行き、彼に言いなさい。『ヘブル人の神、主はこう言われる。「わたしの民を行かせ、わたしに仕えさせなさい。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 8:2; 出エジプト記 4:23; レビ記 26:27–28"> もしあなたが行かせることを拒み、依然として彼らを留めておくなら、</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 7:4; 使徒の働き 13:11; サムエル記第一 6:9"> 見よ、主の手が野にいる家畜、馬、ろば、らくだ、牛、羊の上に下り、非常に激しい疫病が起こる。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 8:22; 出エジプト記 10:23; マラキ書 3:18"> 主はイスラエルの家畜とエジプトの家畜とを区別される。イスラエルの子らに属するものは、一頭も死ぬことはない。」』」</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 8:23; 出エジプト記 10:4; エレミヤ書 28:16–17"> 主は時を定め、「明日、主はこの地でこの事を行う」と言われた。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 78:48; 出エジプト記 9:25; 詩篇 78:50"> 主は次の日にその事を行われた。エジプトの家畜はすべて死んだが、イスラエルの子らの家畜は一頭も死ななかった。</span>
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 7:14; 出エジプト記 8:32; イザヤ書 48:4"> ファラオが人を遣わして調べさせると、イスラエルの家畜は一頭も死んでいなかった。それでもファラオの心は強情で、民を行かせなかった。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 8:16"> 主はモーセとアロンに言われた。「炉のすすを両手いっぱいに取り、モーセがファラオの目の前で天に向かってまき散らしなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 16:2; 申命記 28:27; ヨブ記 2:7"> それはエジプトの地全体に細かいちりとなり、エジプトの地全体で、人や動物に腫れ物と水ぶくれを生じさせるであろう。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命記 28:27"> 彼らは炉の灰を取り、ファラオの前に立った。モーセがそれを天に向かってまき散らすと、それは人や動物に腫れ物と水ぶくれを生じさせた。</span>
<span className="v" id="v11" data-v="11" data-xref="出エジプト記 7:11–12; 出エジプト記 8:18–19; ヨハネの黙示録 16:2"> 魔術師たちは腫れ物に苦しみ、モーセの前に立つことができなかった。腫れ物は魔術師にも、すべてのエジプト人にもできていた。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 4:21; 出エジプト記 7:13–14; 詩篇 81:11–12"> 主はファラオの心をかたくなにされ、主がモーセに語られた通り、彼は彼らに聞き従わなかった。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 8:20; 出エジプト記 7:15; 出エジプト記 9:1"> 主はモーセに言われた。「朝早く起き、ファラオの前に立ち、彼に言いなさい。『ヘブル人の神、主はこう言われる。「わたしの民を行かせ、わたしに仕えさせなさい。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 8:10; レビ記 26:28; 歴代誌上 17:20"> 今度は、わたしのすべての災いをあなた自身と、あなたの家臣と民に下す。全地にわたしのような者はいないことを、あなたに知らせるためである。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 3:20; 出エジプト記 9:3; 出エジプト記 9:16"> 今、わたしが手を伸ばし、あなたとあなたの民を疫病で打っていたなら、あなたは地から断ち切られていたであろう。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 9:17; 箴言 16:4; 詩篇 83:17–18"> しかし、わたしはこのことのためにあなたを立たせた。すなわち、あなたにわたしの力を示し、わたしの名が全地に宣言されるためである。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 37:29; イザヤ書 10:15; イザヤ書 37:23–24"> あなたはまだわたしの民に対して高ぶり、彼らを行かせないのか。</span>
<span className="v" id="v18" data-v="18" data-xref="列王記第一 20:6; 詩篇 83:15; 出エジプト記 9:22–25"> 見よ、明日の今頃、エジプトが建国された日から今までなかったほど激しい雹を降らせる。</span>
<span className="v" id="v19" data-v="19" data-xref="ハバクク書 3:2"> 今、家畜と野にあるすべてのものを避難させよ。家に入れられず野に残る人や動物は、雹に打たれて死ぬ。」』」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="箴言 13:13; 箴言 22:3; ヘブル人への手紙 11:7"> ファラオの家臣の中で主の言葉を恐れた者は、自分のしもべたちや家畜を家の中に逃げ込ませた。</span>
<span className="v" id="v21" data-v="21" data-xref="エゼキエル書 40:4; ヨブ記 34:14; 歴代誌上 22:19"> 主の言葉を心に留めなかった者は、自分のしもべたちや家畜を野に残した。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨハネの黙示録 16:21; 出エジプト記 7:19; 出エジプト記 8:5"> 主はモーセに言われた。「あなたの手を天に向けて伸ばし、エジプトの地全体で、人や動物、また野のすべての草の上に、雹が降るようにしなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="詩篇 18:13; ヨシュア記 10:11; イザヤ書 30:30"> モーセが杖を天に向けて伸ばすと、主は雷と雹を送られ、稲妻が地に向かってひらめいた。主はエジプトの地に雹を降らせた。</span>
<span className="v" id="v24" data-v="24" data-xref="出エジプト記 9:23; マタイ 24:21; 出エジプト記 10:6"> 非常に激しい雹が降り、雹の間に稲妻がひらめいた。それはエジプトが国となって以来、その地全体でかつてなかったほどのものであった。</span>
<span className="v" id="v25" data-v="25" data-xref="詩篇 78:47; 詩篇 105:32–33"> 雹はエジプトの地全体で、野にいるすべての人と動物を打った。雹は野のすべての草を打ち、野のすべての木を打ち砕いた。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 11:7; 出エジプト記 9:4; 出エジプト記 10:23"> イスラエルの子らがいたゴシェンの地にだけは、雹は降らなかった。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="哀歌 1:18; 詩篇 129:4; 出エジプト記 10:16"> ファラオは人をやってモーセとアロンを呼び寄せ、彼らに言った。「今回、私は罪を犯した。主は義であり、私と私の民は悪者だ。</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 8:8; 出エジプト記 10:17; 出エジプト記 8:28"> 主に祈ってくれ。激しい雷と雹はもうたくさんだ。あなたがたを行かせよう。これ以上とどまることはない。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="コリント人への第一の手紙 10:26; 列王記第一 8:38; イザヤ書 1:15"> モーセは彼に言った。「町を出たらすぐに、私は主に向かって両手を広げます。雷は止み、もはや雹は降らないでしょう。それは、この地が主のものであることを、あなたが知るためです。</span>
<span className="v" id="v30" data-v="30" data-xref="イザヤ書 26:10; 箴言 16:6; イザヤ書 63:17"> しかし、あなたとあなたの家臣については、あなたがたがまだ神である主を恐れていないことを私は知っています。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ルツ記 1:22; ルツ記 2:23; ハバクク書 3:17"> 亜麻と大麦は打たれた。大麦は穂を出し、亜麻は花を咲かせていた。</span>
<span className="v" id="v32" data-v="32" data-xref="出エジプト記 10:22"> しかし、小麦とスペルト小麦はまだ育ちきっていなかったので、打たれなかった。</span>
<span className="v" id="v33" data-v="33" data-xref="出エジプト記 9:29; 出エジプト記 8:12; ヤコブの手紙 5:17–18"> モーセはファラオのところから町を出て、主に向かって両手を広げた。すると雷と雹は止み、雨は地に注がれなくなった。</span>
<span className="v" id="v34" data-v="34" data-xref="出エジプト記 7:14; 歴代誌 第二 36:13; 出エジプト記 4:21"> 雨と雹と雷が止んだのを見ると、ファラオはさらに罪を重ね、彼もその家臣も心をかたくなにした。</span>
<span className="v" id="v35" data-v="35" data-xref="出エジプト記 4:21"> ファラオの心はかたくなになり、主がモーセを通して語られた通り、彼はイスラエルの子らを行かせなかった。</span>
</div>

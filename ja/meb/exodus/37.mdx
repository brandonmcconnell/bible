<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 25:10–20; 出エジプト記 26:33; 民数記 10:33–36"> ベツァルエルはアカシアの木で箱を造った。その長さは二・五キュビト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一キュビトは、大人の腕の中指の先から肘までの長さで、約18インチ、すなわち約46センチメートルである。">a</a></sup>、幅は一・五キュビト、高さは一・五キュビトであった。</span>
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 30:3"> 彼はその内側と外側に純金をかぶせ、その周りに金の飾り縁を造った。</span>
<span className="v" id="v3" data-v="3"> 彼はその四つの足に四つの金の環を鋳造した。一方の側に二つの環、もう一方の側にも二つの環を取り付けた。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 9:15; ペテロの手紙第一 1:7; 民数記 4:14–15"> 彼はアカシアの木で担ぎ棒を造り、金をかぶせた。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 4:15; サムエル記第二 6:3–7; 民数記 1:50"> 箱を担ぐため、その担ぎ棒を箱の両側の環に通した。</span>
<span className="v" id="v6" data-v="6" data-xref="ヘブル人への手紙 9:5; テトス 2:14; ローマ人への手紙 3:25"> 彼は純金で贖いの座を造った。その長さは二・五キュビト、幅は一・五キュビトであった。</span>
<span className="v" id="v7" data-v="7" data-xref="エゼキエル書 10:2; 詩篇 104:4; 詩篇 80:1"> 彼は金のケルビムを二つ造った。贖いの座の両端に、それらを打ち出し細工で造った。</span>
<span className="v" id="v8" data-v="8"> 一つのケルブを一方の端に、もう一つのケルブをもう一方の端に造った。彼はケルビムを贖いの座の両端に、座と一体にして造った。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネ 1:51; ヘブル人への手紙 1:14; 創世記 28:12"> ケルビムはその翼を上に向けて広げ、その翼で贖いの座を覆い、互いに顔を向かい合わせていた。ケルビムの顔は贖いの座の方に向けられていた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ヨハネ 1:14; エゼキエル書 40:39–42; マラキ書 1:12"> 彼はアカシアの木で机を造った。その長さは二キュビト、幅は一キュビト、高さは一・五キュビトであった。</span>
<span className="v" id="v11" data-v="11"> 彼はそれに純金をかぶせ、その周りに金の飾り縁を造った。</span>
<span className="v" id="v12" data-v="12"> 彼はその周りに手の幅の枠を造り、その枠の周りにも金の飾り縁を造った。</span>
<span className="v" id="v13" data-v="13"> 彼はそのために四つの金の環を鋳造し、四つの足にある四隅にその環を取り付けた。</span>
<span className="v" id="v14" data-v="14"> 環は枠の近くにあり、机を担ぐ棒を通す場所となった。</span>
<span className="v" id="v15" data-v="15"> 机を担ぐため、アカシアの木で担ぎ棒を造り、金をかぶせた。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 25:29; 列王記第一 7:50; 列王記第二 12:13"> 彼は机の上にある器具、すなわち皿、さじ、鉢、注ぎのささげ物を注ぐための水差しを純金で造った。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 25:31–39; ヘブル人への手紙 9:2; 歴代誌 第二 13:11"> 彼は純金で燭台を造った。彼は燭台を打ち出し細工で造った。その台座、支柱、杯、節、花は、それと一体であった。</span>
<span className="v" id="v18" data-v="18"> その側面からは六つの枝が出ていた。一方の側から燭台の三つの枝、もう一方の側から燭台の三つの枝が出ていた。</span>
<span className="v" id="v19" data-v="19"> 一つの枝にはアーモンドの花のような三つの杯、節、花があり、もう一つの枝にもアーモンドの花のような三つの杯、節、花があった。燭台から出ている六つの枝がそのようであった。</span>
<span className="v" id="v20" data-v="20" data-xref="伝道者の書 12:5; エレミヤ書 1:11; 出エジプト記 25:33"> 燭台の支柱には、アーモンドの花のような四つの杯、節、花があった。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 25:35"> 燭台から出ている六つの枝のために、それと一体の二つの枝の下に一つの節、それと一体の他の二つの枝の下に一つの節、それと一体のさらに他の二つの枝の下に一つの節があった。</span>
<span className="v" id="v22" data-v="22" data-xref="コロサイ人への手紙 3:5; 出エジプト記 25:31; 詩篇 51:17"> それらの節と枝は燭台と一体であった。その全体が一つの純金の打ち出し細工であった。</span>
<span className="v" id="v23" data-v="23" data-xref="ヨハネの黙示録 1:12; 出エジプト記 25:37; ヨハネの黙示録 1:20–1"> 彼はその七つのともしび、芯切りばさみ、芯取り皿を純金で造った。</span>
<span className="v" id="v24" data-v="24"> 彼はそのすべての器具を含めて、一タラント<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一タラントは約30キログラム、すなわち66ポンド、あるいは965トロイオンスである。">b</a></sup>の純金でこれを造った。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 30:1–5; ヘブル人への手紙 7:25; ヨハネの黙示録 8:3–4"> 彼はアカシアの木で香の祭壇を造った。それは四角形で、長さは一キュビト、幅は一キュビトであった。高さは二キュビトであった。その角は祭壇と一体であった。</span>
<span className="v" id="v26" data-v="26"> 彼はその上面、周囲の側面、およびその角に純金をかぶせた。彼はその周囲に金の飾り縁を造った。</span>
<span className="v" id="v27" data-v="27"> 飾り縁の下、両側の側面に二つの金の環を造り、祭壇を担ぐ棒を通す場所とした。</span>
<span className="v" id="v28" data-v="28"> アカシアの木で担ぎ棒を造り、金をかぶせた。</span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 141:2; ヘブル人への手紙 7:25; ヨハネの手紙第一 2:20"> 彼は香料作りの技法に従って、聖なる注ぎ油と、香りのよい純粋な香を造った。</span>
</div>

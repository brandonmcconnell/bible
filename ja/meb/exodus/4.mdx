<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 3:18; 出エジプト記 2:14; エレミヤ書 1:6"> モーセは答えた。「しかし、彼らは私を信じず、私の声に聞き従わないでしょう。『主はあなたに現れなかった』と言うでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="出エジプト記 4:17; 出エジプト記 4:20; イザヤ書 11:4"> 主は彼に言われた。「あなたの手にあるそれは何か。」<br />彼は言った。「杖です。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 7:10–15; アモス書 5:19; 出エジプト記 4:17"> 主は言われた。「それを地面に投げなさい。」<br />彼がそれを地面に投げると、それは蛇になった。モーセはそれから逃げ出した。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 28:3–6; 創世記 22:1–2; 詩篇 91:13"> 主はモーセに言われた。「手を伸ばし、その尾をつかみなさい。」<br />彼が手を伸ばしてそれをつかむと、彼の手の中で杖になった。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 19:9; 創世記 48:3; 出エジプト記 3:15"> 「これは、彼らの父祖の神、アブラハムの神、イサクの神、ヤコブの神である主が、あなたに現れたことを彼らが信じるためである。」</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第二 5:27; 民数記 12:10"> 主はさらに言われた。「手をふところに入れなさい。」彼が手を入れ、取り出すと、その手は皮膚病に冒され、雪のように白くなっていた。<br />彼が手をふところに入れ、それを取り出すと、見よ、彼の手は皮膚病に冒され、雪のように白くなっていた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王記第二 5:14; 申命記 32:39; マタイ 8:3"> 主は言われた。「手をもう一度ふところに入れなさい。」彼がもう一度手を入れ、取り出すと、手は元の肌に戻っていた。<br />彼がもう一度手をふところに入れ、ふところからそれを取り出すと、見よ、それは再び元の肉のようになっていた。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 28:10; 申命記 32:39; 出エジプト記 4:30–31"> 「彼らがあなたを信じず、最初のしるしが語ることに耳を傾けなくても、後のしるしが語ることには耳を傾けるだろう。</span>
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 7:19–25; 出エジプト記 1:22; マタイ 7:2"> もし彼らがこれら二つのしるしさえも信じず、あなたの声にも聞き従わないなら、あなたはナイル川の水を取って乾いた土の上に注ぎなさい。川から取った水は乾いた土の上で血となるであろう。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 1:6; 出エジプト記 6:12; 使徒の働き 7:22"> モーセは主に言った。「ああ、主よ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「主」と訳された言葉は「アドナイ」である。">a</a></sup>、私はもともと口の達者な者ではありません。あなたがしもべに語られてからも同じです。私は口が重く、舌も重いのです。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="アモス書 3:6; 詩篇 146:8; エゼキエル書 3:26–27"> 主は彼に言われた。「誰が人の口を造ったのか。誰が人を口のきけない者にし、耳の聞こえない者にし、目の見える者にし、また盲目の者にするのか。それは主であるわたしではないか。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 1:9; ルカ 12:11–12; マタイ 10:19–20"> だから今、行きなさい。わたしはあなたの口と共にあり、あなたが何を語るべきかを教えよう。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ヨナ書 1:3; 出エジプト記 4:1; マタイ 13:41"> モーセは言った。「主よ、どうか、ほかの者を遣わしてください。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="マルコ 14:13–15; 出エジプト記 4:27; 歴代誌上 21:7"> 主の怒りはモーセに向かって燃え上がった。主は言われた。「あなたの兄弟、レビ人アロンがいるではないか。彼がよく話せることを、わたしは知っている。今、彼はあなたを迎えに来ている。あなたを見れば、心から喜ぶだろう。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 51:16; 申命記 18:18; ルカ 21:15"> あなたは彼に語り、その口に言葉を授けなさい。わたしはあなたの口と彼の口と共にあり、あなたがたのなすべきことを教えよう。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 7:1–2; 詩篇 82:6; ヨハネ 10:34–35"> 彼はあなたに代わって民に語る口となる。彼はあなたにとって口となり、あなたは彼にとって神のようになる。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 4:2; コリント人への第一の手紙 1:27; 出エジプト記 7:9–20"> あなたはこの杖を手に取りなさい。それによってしるしを行うのである。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 3:1; サムエル記第一 1:17; テモテへの手紙第一 6:1"> モーセは義父エテロのもとへ帰り、言った。「どうか私をエジプトにいる同胞のもとへ帰らせ、彼らがまだ生きているか見させてください。」<br />エテロはモーセに「安心して行きなさい」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="マタイ 2:20; 出エジプト記 2:23; 出エジプト記 2:15"> 主はミディアンでモーセに言われた。「エジプトへ帰りなさい。あなたの命を狙っていた者たちはみな死んだ。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 17:9; 民数記 20:8–9; 出エジプト記 18:3–4"> モーセは妻と息子たちを連れ、彼らをろばに乗せてエジプトの地へ帰って行った。モーセは手に神の杖を持っていた。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 9:18; イザヤ書 63:17; 出エジプト記 14:8"> 主はモーセに言われた。「エジプトへ戻ったら、わたしがあなたの手に授けたすべての不思議な業を、必ずファラオの前で行いなさい。しかし、わたしは彼の心をかたくなにするので、彼は民を行かせない。</span>
<span className="v" id="v22" data-v="22" data-xref="ホセア書 11:1; ローマ人への手紙 9:4; エレミヤ書 31:9"> あなたはファラオに言いなさい。『主はこう言われる。イスラエルはわたしの子、わたしの長子である。</span>
<span className="v" id="v23" data-v="23" data-xref="出エジプト記 11:5; 出エジプト記 12:29; 詩篇 135:8"> わたしはあなたに『わたしの子を行かせ、わたしに仕えさせよ』と言った。それでもあなたは行かせることを拒んだ。見よ、わたしはあなたの長子を殺す。』」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="創世記 17:14; 民数記 22:22–23; ホセア書 13:8"> 途中の宿泊所で、主はモーセに出会い、彼を殺そうとされた。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 5:2–3; 創世記 17:14; サムエル記第二 16:7"> その時、チッポラは火打石を取り、息子の包皮を切り取り、それを彼の足もとに投げて言った。「あなたは確かに私にとって血の花婿です。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> それで主は彼を放された。その時チッポラは、割礼のゆえに「血の花婿」と言ったのである。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="出エジプト記 3:1; 出エジプト記 4:14–16; 列王記第一 19:8"> 主はアロンに言われた。「荒野に行ってモーセに会いなさい。」<br />彼は行き、神の山でモーセに会い、彼に口づけした。</span>
<span className="v" id="v28" data-v="28" data-xref="出エジプト記 4:8–9; 出エジプト記 4:15–16; マタイ 21:29"> モーセは、自分を遣わした主のすべての言葉と、主が命じたすべてのしるしをアロンに伝えた。</span>
<span className="v" id="v29" data-v="29" data-xref="出エジプト記 3:16; 出エジプト記 24:11; 出エジプト記 24:1"> モーセとアロンは行って、イスラエルの子らのすべての長老を集めた。</span>
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 4:16"> アロンは、主がモーセに語られたすべての言葉を語り、民の目の前でしるしを行った。</span>
<span className="v" id="v31" data-v="31" data-xref="出エジプト記 3:18; 出エジプト記 2:25; 詩篇 106:12–13"> 民は信じた。主がイスラエルの子らを顧み、彼らの苦しみをご覧になったことを聞いた時、彼らは頭を下げて礼拝した。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ローマ人への手紙 8:6; マタイ 6:33; コリント人への第二の手紙 4:18"> あなたがたはキリストと共によみがえらされたのですから、上にあるものを求めなさい。そこではキリストが、神の右に座っておられます。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの手紙第一 2:15–17; 歴代誌上 22:19; コロサイ人への手紙 3:1"> 地上にあるものではなく、上にあるものに心を向けなさい。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 2:20; ローマ人への手紙 6:2; コロサイ人への手紙 2:20"> あなたがたはすでに死んでおり、あなたがたの命はキリストと共に神のうちに隠されているからです。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネ 11:25; ヨハネの手紙第一 3:2; ガラテヤ人への手紙 2:20"> 私たちの命であるキリストが現れるとき、あなたがたもキリストと共に栄光のうちに現れます。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 8:13; ガラテヤ人への手紙 5:19–21; ガラテヤ人への手紙 5:24"> ですから、あなたがたのうちにある地上のもの、すなわち性的不品行、汚れ、堕落した情欲、悪い欲望、そして偶像礼拝である貪欲を死なせなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="エペソ人への手紙 5:6; ローマ人への手紙 1:18; ペテロの手紙第一 1:14"> これらのことのために、神の怒りが不従順な者たちの上に下ります。</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 2:2; ペテロの手紙第一 4:3–4; ローマ人への手紙 6:19–20"> あなたがたも以前、それらの中に生きていたころは、そのように歩んでいました。</span>
<span className="v" id="v8" data-v="8" data-xref="エペソ人への手紙 4:29; エペソ人への手紙 4:22; ヤコブの手紙 1:20–21"> しかし今は、怒り、憤り、悪意、中傷、口から出る恥ずべき言葉を、すべて捨て去りなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="エペソ人への手紙 4:22; エペソ人への手紙 4:25; レビ記 19:11"> 互いに偽りを言ってはなりません。あなたがたは古い人をその行いと共に脱ぎ捨て、</span>
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 4:23–24; ローマ人への手紙 12:2; エペソ人への手紙 2:10"> 新しい人を身に着けたからです。この新しい人は、造り主のかたちに従い、知識において新しくされ続けています。</span>
<span className="v" id="v11" data-v="11" data-xref="ガラテヤ人への手紙 3:28–29; コリント人への第一の手紙 12:13; ローマ人への手紙 10:12"> そこには、ギリシャ人とユダヤ人、割礼を受けた者と受けていない者、未開人、スキタイ人、奴隷、自由人という区別はありません。キリストがすべてであり、すべての人のうちにおられるのです。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 4:32; エペソ人への手紙 4:2; ヨハネの手紙第一 4:19"> ですから、神に選ばれた者、聖なる者、愛されている者として、心からのあわれみ、親切、へりくだった心、慎み深さ、忍耐を身に着けなさい。</span>
<span className="v" id="v13" data-v="13" data-xref="エペソ人への手紙 4:32; マルコ 11:25; ヤコブの手紙 2:13"> 互いに耐え忍び、だれかに不満を抱くことがあっても、互いに赦し合いなさい。キリストがあなたがたを赦してくださったように、あなたがたもそうしなさい。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ペテロの手紙第一 4:8; エペソ人への手紙 5:2; コリント人への第一の手紙 13:1–13"> これらすべてにまさって、愛のうちを歩みなさい。愛は、完全さをもたらすきずなです。</span>
<span className="v" id="v15" data-v="15" data-xref="ピリピ人への手紙 4:6–7; ヨハネ 14:27; イザヤ書 26:3"> 神の平和があなたがたの心を支配するようにしなさい。あなたがたが一つの体として召されたのも、この平和のためです。また、感謝する人となりなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 119:11; エペソ人への手紙 5:19; ヨハネ 15:7"> キリストの言葉をあなたがたのうちに豊かに住まわせなさい。あらゆる知恵をもって、詩篇と賛美歌と霊の歌によって互いに教え、戒め、恵みに満たされた心で主に向かって歌いなさい。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 10:31; コロサイ人への手紙 3:23; 箴言 3:6"> 言葉であれ行いであれ、何をするにも、すべてを主イエスの名によって行い、主を通して父なる神に感謝しなさい。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 5:22–9; テトス 2:4–5; コリント人への第一の手紙 11:3"> 妻たちよ、主にあってふさわしく、夫に従いなさい。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ペテロの手紙第一 3:7; 創世記 2:23–24; コロサイ人への手紙 3:21"> 夫たちよ、妻を愛しなさい。妻につらく当たってはなりません。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 20:12; エペソ人への手紙 6:1–3; 箴言 6:20"> 子どもたちよ、すべてのことにおいて両親に従いなさい。それは主に喜ばれることだからです。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="箴言 4:1–4; エペソ人への手紙 6:4; 詩篇 103:13"> 父親たちよ、子どもをいらだたせてはなりません。子どもを気落ちさせないためです。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="エペソ人への手紙 6:5–7; テモテへの手紙第一 6:1–2; ガラテヤ人への手紙 1:10"> しもべたちよ、すべてのことにおいて、この世で主人である人たちに従いなさい。人に気に入られようとして、見られているときだけ仕えるのではなく、神を恐れ、真心から仕えなさい。</span>
<span className="v" id="v23" data-v="23" data-xref="コロサイ人への手紙 3:17; エペソ人への手紙 6:6–7; ローマ人への手紙 14:8"> 何をするにも、人に対してではなく主に対してするように、心を込めて働きなさい。</span>
<span className="v" id="v24" data-v="24" data-xref="エペソ人への手紙 6:8; ガラテヤ人への手紙 1:10; 使徒の働き 20:32"> あなたがたは、主から相続財産という報いを受けることを知っています。あなたがたが仕えているのは、主キリストなのです。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 10:34; ローマ人への手紙 2:11; コリント人への第二の手紙 5:10"> 不正を行う者は、自分が行った不正の報いを受けます。そこにえこひいきはありません。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コロサイ人への手紙 1:29; ピリピ人への手紙 1:30; ヨハネの黙示録 3:14–22"> 私があなたがたとラオディキアにいる人々のために、また、私とじかに顔を合わせたことのないすべての人々のために、どれほど激しく苦闘しているかを知ってほしいのです。</span>
<span className="v" id="v2" data-v="2" data-xref="コロサイ人への手紙 1:27; コロサイ人への手紙 4:8; エペソ人への手紙 6:22"> それは、彼らの心が励まされ、愛によって結び合わされ、理解に基づく確信の豊かさを余すところなく得て、神の奥義、すなわち父とキリストの奥義を知るようになるためです。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第一の手紙 1:24; コリント人への第一の手紙 1:30; ローマ人への手紙 11:33"> キリストのうちには、知恵と知識の宝がすべて隠されています。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネの手紙第一 4:1; エペソ人への手紙 4:14; ローマ人への手紙 16:18–19"> 私がこう言うのは、もっともらしい言葉でだれにも惑わされないためです。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第一の手紙 5:3–4; テサロニケ人への手紙第一 2:17; コリント人への第一の手紙 16:13"> 私は肉体では離れていても、霊ではあなたがたと共にいて、あなたがたの秩序と、キリストに対する信仰の堅固さを見て喜んでいます。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="コロサイ人への手紙 1:10; ヨハネの手紙第一 2:6; テサロニケ人への手紙第一 4:1"> あなたがたは主キリスト・イエスを受け入れたのですから、この方にあって歩みなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 3:17; エレミヤ書 17:8; エペソ人への手紙 2:20–22"> キリストのうちに根を下ろし、その上に建てられ、教えられたとおり信仰に堅く立ち、感謝にあふれなさい。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="テモテへの手紙第一 6:20; エペソ人への手紙 5:6; マタイ 7:15"> 人間の言い伝えやこの世の諸霊に従い、キリストに従わない哲学とむなしい欺きによって、だれかのとりこにされないよう注意しなさい。</span>
<span className="v" id="v9" data-v="9" data-xref="コロサイ人への手紙 1:19; ヨハネ 10:30; ヨハネ 1:14"> 神性のすべてが、キリストのうちに体をもって宿っているからです。</span>
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 3:19; コロサイ人への手紙 1:16–18; エペソ人への手紙 1:20–23"> そしてあなたがたは、キリストにあって満たされています。キリストは、すべての支配と権威のかしらです。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 2:29; ピリピ人への手紙 3:3; ローマ人への手紙 6:6"> また、あなたがたはキリストにあって、人の手によらない割礼を受けました。それは、肉に属する罪の体を脱ぎ捨てることであり、キリストによる割礼です。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 6:3–5; ペテロの手紙第一 3:21; ガラテヤ人への手紙 3:27"> あなたがたは洗礼によってキリストと共に葬られ、また、キリストを死者の中からよみがえらせた神の働きを信じる信仰によって、キリストと共によみがえらされました。</span>
<span className="v" id="v13" data-v="13" data-xref="エペソ人への手紙 2:5–6; ローマ人への手紙 8:11; エペソ人への手紙 2:1"> あなたがたは背きと肉の無割礼のために死んでいましたが、神はあなたがたをキリストと共に生かし、私たちのすべての背きを赦してくださいました。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 44:22; エペソ人への手紙 2:14–16; イザヤ書 43:25"> 神は、私たちに不利な規定の記された証書を消し去り、それを取り除いて十字架に釘づけにされました。</span>
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 2:14; エペソ人への手紙 4:8; マタイ 12:29"> また神は、もろもろの支配と権威を武装解除し、彼らを公然とさらしものにして、十字架によって彼らに勝利されました。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 14:5–6; ローマ人への手紙 14:10; ガラテヤ人への手紙 4:10"> ですから、食べ物や飲み物について、また祭り、新月、安息日について、だれにもあなたがたを裁かせてはなりません。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 10:1; ヘブル人への手紙 8:5; ヨハネ 1:17"> これらは来たるべきものの影です。しかし、その体はキリストのものです。</span>
<span className="v" id="v18" data-v="18" data-xref="コロサイ人への手紙 2:8; ヨハネの手紙第一 4:1–2; コロサイ人への手紙 2:23"> 自己卑下や天使礼拝を好む者に、あなたがたの受ける賞を奪わせてはなりません。そのような者は、自分が見てもいないことに深入りし、肉の思いによってむなしく思い上がり、</span>
<span className="v" id="v19" data-v="19" data-xref="エペソ人への手紙 4:15–16; ヨハネ 15:4–6; ペテロの第二の手紙 3:18"> かしらである方にしっかり結びついていません。このかしらから、体全体は関節と靱帯によって支えられ、結び合わされ、神が与える成長を遂げるのです。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="コロサイ人への手紙 2:8; コロサイ人への手紙 2:16; ガラテヤ人への手紙 4:3"> あなたがたはこの世の諸霊に対してキリストと共に死んだのに、なぜ、まだこの世に生きているかのように、</span>
<span className="v" id="v21" data-v="21" data-xref="テモテへの手紙第一 4:3; 創世記 3:3; イザヤ書 52:11"> 「手をつけるな。味わうな。触れるな」という規定に従うのですか。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 29:13; テトス 1:14; コリント人への第一の手紙 6:13"> これらはすべて、用いればなくなってしまうもので、人間の戒めや教えに基づいています。</span>
<span className="v" id="v23" data-v="23" data-xref="テモテへの手紙第一 4:8; コロサイ人への手紙 2:18; コロサイ人への手紙 2:8"> このような規定は、勝手に作り上げた礼拝、自己卑下、体を厳しく扱うことによって、いかにも知恵があるように見えます。しかし、肉の欲望を抑えるには何の価値もありません。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第二の手紙 1:1; コリント人への第一の手紙 1:1; フィレモンへの手紙 1:1"> 神のみこころによってキリスト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「キリスト」は「油を注がれた者」という意味である。">a</a></sup>・イエスの使徒であるパウロと、兄弟テモテから、</span>
<span className="v" id="v2" data-v="2" data-xref="ペテロの第二の手紙 1:2; エペソ人への手紙 1:1; ローマ人への手紙 1:7"> コロサイにいる聖徒たち、キリストにある忠実な兄弟たち<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ここで「兄弟たち」と訳された語は、文脈によっては「兄弟姉妹」または「きょうだいたち」と訳すこともできる。">b</a></sup>へ。私たちの父なる神と主イエス・キリストから、恵みと平和があなたがたにありますように。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="テサロニケ人への手紙第一 1:2; コロサイ人への手紙 1:9; テモテへの第二の手紙 1:3"> 私たちは、いつもあなたがたのために祈り、私たちの主イエス・キリストの父なる神に感謝しています。</span>
<span className="v" id="v4" data-v="4" data-xref="エペソ人への手紙 1:15; テサロニケ人への第二の手紙 1:3; テサロニケ人への手紙第一 1:3"> キリスト・イエスに対するあなたがたの信仰と、すべての聖徒への愛について聞いているからです。</span>
<span className="v" id="v5" data-v="5" data-xref="ペテロの手紙第一 1:3–4; エペソ人への手紙 1:13; テモテへの第二の手紙 4:8"> その信仰と愛は、あなたがたのために天に蓄えられている希望によるものです。あなたがたは以前、真理の言葉である福音によって、この希望について聞きました。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 15:16; ピリピ人への手紙 1:11; コロサイ人への手紙 1:23"> この福音はあなたがたのもとまで届き、世界中で実を結び、成長しています。あなたがたが神の恵みを聞き、それを真実に知った日から、あなたがたの間でも同じように実を結び、成長しています。</span>
<span className="v" id="v7" data-v="7" data-xref="コロサイ人への手紙 4:12; フィレモンへの手紙 1:23; コロサイ人への手紙 4:7"> あなたがたはこの恵みを、私たちと共に仕える愛するしもべエパフラスから学びました。彼はあなたがた<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="NU本文では「私たち」">c</a></sup>のために仕える、キリストの忠実なしもべです。</span>
<span className="v" id="v8" data-v="8" data-xref="ローマ人への手紙 15:30; テモテへの第二の手紙 1:7; ガラテヤ人への手紙 5:22"> エパフラスはまた、聖霊によるあなたがたの愛を私たちに知らせてくれました。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヤコブの手紙 3:17; ピリピ人への手紙 1:9–11; ヤコブの手紙 1:5"> そのため私たちも、このことを聞いた日から、あなたがたのために祈り求めることをやめません。どうかあなたがたが、あらゆる霊的な知恵と理解をもって、神のみこころについての知識に満たされますように。</span>
<span className="v" id="v10" data-v="10" data-xref="エペソ人への手紙 4:1; ヘブル人への手紙 13:21; ペテロの第二の手紙 1:2–3"> そして、あらゆる点で主を喜ばせるよう、主にふさわしく歩み、あらゆる良い行いによって実を結び、神を知る知識において成長しますように。</span>
<span className="v" id="v11" data-v="11" data-xref="エペソ人への手紙 3:16; ピリピ人への手紙 4:13; エペソ人への手紙 4:2"> また、神の栄光の力に従い、あらゆる力をもって強められ、喜びをもって、どんなことにも耐え忍ぶことができますように。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 20:32; エペソ人への手紙 1:11; エペソ人への手紙 1:18"> 光の中にある聖徒たちの相続分にあずかるにふさわしい者としてくださった父に、感謝をささげることができますように。</span>
<span className="v" id="v13" data-v="13" data-xref="エペソ人への手紙 5:8; 使徒の働き 26:18; ペテロの手紙第一 2:9"> 父は私たちを闇の力から救い出し、ご自分の愛する御子の国へ移してくださいました。</span>
<span className="v" id="v14" data-v="14" data-xref="エペソ人への手紙 1:7; ローマ人への手紙 3:24–25; ペテロの手紙第一 1:19–20"> 私たちはこの御子にあって、贖い<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="TRは「その血によって」を加えている。">d</a></sup>、すなわち罪の赦しを得ています。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヘブル人への手紙 1:3; ヨハネ 14:9; ヨハネ 1:1"> 御子は、目に見えない神のかたちであり、すべての被造物の長子です。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 11:36; ヨハネ 1:3; コリント人への第一の手紙 8:6"> 天にあるものも地にあるものも、目に見えるものも見えないものも、王座も主権も支配も権威も、すべてのものは御子によって造られたからです。万物は御子を通して、御子のために造られました。</span>
<span className="v" id="v17" data-v="17" data-xref="ヘブル人への手紙 1:3; コリント人への第一の手紙 8:6; 使徒の働き 17:28"> 御子はすべてのものより先に存在し、万物は御子にあって成り立っています。</span>
<span className="v" id="v18" data-v="18" data-xref="エペソ人への手紙 1:22–23; ヨハネの黙示録 1:5; エペソ人への手紙 4:15–16"> 御子はその体、すなわち教会のかしらです。御子は初めであり、死者の中からの長子です。それは、御子があらゆることにおいて第一の方となるためです。</span>
<span className="v" id="v19" data-v="19" data-xref="コロサイ人への手紙 2:9; ヨハネ 1:16; エペソ人への手紙 1:23"> 満ち満ちた豊かさのすべてが御子のうちに宿ることが、みこころにかなったからです。</span>
<span className="v" id="v20" data-v="20" data-xref="コリント人への第二の手紙 5:18–21; エペソ人への手紙 1:10; ヨハネの手紙第一 4:9–10"> そして、御子の十字架の血によって平和をもたらし、地にあるものも天にあるものも、万物を御子によってご自分と和解させることを喜ばれました。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="エペソ人への手紙 2:12; テトス 3:3–7; エペソ人への手紙 2:1–3"> あなたがたは以前、悪い行いによって神から離れ、心では神に敵対していました。</span>
<span className="v" id="v22" data-v="22" data-xref="エペソ人への手紙 5:27; ユダ 1:24; エペソ人への手紙 1:4"> しかし今、神は、御子が肉の体をもって死なれたことにより、あなたがたをご自分と和解させてくださいました。それは、あなたがたを聖なる者、傷のない者、責められるところのない者として、ご自分の前に立たせるためです。</span>
<span className="v" id="v23" data-v="23" data-xref="ヘブル人への手紙 3:14; ヘブル人への手紙 3:6; マタイ 24:13–14"> もっとも、あなたがたが信仰にとどまり、土台を据えられて堅く立ち、聞いた福音の希望から動かされずにいるならばです。この福音は、天の下のすべての被造物に宣べ伝えられ、私パウロはそのしもべとなりました。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ローマ人への手紙 5:3; テモテへの第二の手紙 1:8; コリント人への第二の手紙 1:5–8"> 今、私はあなたがたのために受ける苦しみを喜んでいます。そしてキリストの体、すなわち教会のために、キリストの苦難に欠けているものを、自分の肉体において補っています。</span>
<span className="v" id="v25" data-v="25" data-xref="エペソ人への手紙 3:2; コロサイ人への手紙 1:23; ガラテヤ人への手紙 2:7–8"> 私は、あなたがたのために神から委ねられた管理の務めに従い、神の言葉を余すところなく伝えるために、教会のしもべとなりました。</span>
<span className="v" id="v26" data-v="26" data-xref="ルカ 8:10; ローマ人への手紙 16:25–26; エペソ人への手紙 3:3–10"> その言葉とは、幾つもの時代と世代にわたって隠されてきた奥義です。しかし今、この奥義は神の聖徒たちに現されました。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨハネ 14:20; ローマ人への手紙 8:10; エペソ人への手紙 3:16–17"> 神は聖徒たちに、この奥義が異邦人の間でどれほど栄光に富むものかを知らせることを喜ばれました。この奥義とは、あなたがたのうちにおられるキリスト、すなわち栄光の希望です。</span>
<span className="v" id="v28" data-v="28" data-xref="エペソ人への手紙 5:27; エレミヤ書 3:15; エペソ人への手紙 4:11–13"> 私たちはこのキリストを宣べ伝え、あらゆる知恵をもって一人ひとりを戒め、一人ひとりを教えています。それは、すべての人をキリスト・イエスにあって完全な者として立たせるためです。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第一の手紙 15:10; エペソ人への手紙 1:19; コリント人への第一の手紙 9:25–27"> このために私も労苦し、私のうちに力強く働くキリストの力に従って奮闘しています。</span>
</div>

<span className="v" id="v2" data-v="2" data-xref="イザヤ書 2:12–17; エゼキエル書 31:17; イザヤ書 10:33–34"> <span className="pl pl-1">糸杉よ、泣き叫べ。杉が倒れ、</span><br /><span className="pl pl-2">威厳ある木々が滅ぼされたからだ。</span><br /><span className="pl pl-1">バシャンの樫の木々よ、泣き叫べ。</span><br /><span className="pl pl-2">深い森が切り倒されたからだ。</span></span>
<span className="v" id="v3" data-v="3" data-xref="エレミヤ書 50:44; エレミヤ書 25:34–36; ゼカリヤ書 11:8"> <span className="pl pl-1">羊飼いたちの泣き叫ぶ声がする。</span><br /><span className="pl pl-2">彼らの栄光が滅ぼされたからだ。</span><br /><span className="pl pl-1">若い獅子たちのほえる声がする。</span><br /><span className="pl pl-2">ヨルダンの誇りが荒らされたからだ。</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ゼカリヤ書 11:7; マタイ 23:37; ローマ人への手紙 15:8"> 私の神、主はこう言われる。「ほふられる羊の群れを養え。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 50:7; ホセア書 12:8; テモテへの手紙第一 6:5–10"> それを買う者たちは羊をほふっても罪に問われない。売る者たちは、『主はほめたたえられる方だ。私は富んだ』と言う。その羊飼いたちも、羊をあわれまない。</span>
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 13:14; マタイ 22:7; イザヤ書 9:19–21"> 私はもう、この地の住民をあわれまない」と主は言われる。「見よ、私は一人一人をその隣人の手と、その王の手に渡す。彼らはこの地を打つが、私はその手から彼らを救い出さない。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ゼカリヤ書 11:14; ゼカリヤ書 11:4; イザヤ書 11:4"> そこで私は、ほふられる羊の群れ、特に群れの中の虐げられた者たちを養った。私は二本の杖を取り、一方を「恵み」と名づけ、もう一方を「結合」と名づけて、群れを養った。</span>
<span className="v" id="v8" data-v="8" data-xref="イザヤ書 49:7; マタイ 23:34–36; ヨハネ 15:18"> 私は一か月のうちに三人の羊飼いを絶った。私は彼らに耐えられなくなり、彼らも私を忌み嫌ったからだ。</span>
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 43:11; マタイ 13:10–11; マタイ 21:19"> 私は言った。「私はもうあなたがたを養わない。死ぬものは死なせ、断ち滅ぼされるものは断ち滅ぼされるままにせよ。残った者たちは互いの肉を食べよ。」</span>
<span className="v" id="v10" data-v="10" data-xref="ゼカリヤ書 11:7; 詩篇 89:39; ヘブル人への手紙 8:8–13"> 私は「恵み」という杖を取り、それを折った。すべての民と結んでいた私の契約を破るためであった。</span>
<span className="v" id="v11" data-v="11" data-xref="ゼパニヤ書 3:12; ルカ 2:38; 申命記 31:21"> その契約はその日に破られた。私の言葉に耳を傾けていた群れの中の貧しい者たちは、これが主の言葉であることを知った。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイ 26:15; 出エジプト記 21:32; ルカ 22:3–6"> 私は彼らに言った。「良いと思うなら、私に賃金を払え。そうでなければ、払うな。」そこで彼らは私の賃金として、銀三十枚を量った。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイ 27:3–10; 使徒の働き 1:18–19; イザヤ書 53:2–3"> 主は私に言われた。「それを陶器師に投げ与えよ。彼らが私につけた、見事な値段だ。」私は銀三十枚を取り、主の家で陶器師に投げ与えた。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 9:21; イザヤ書 11:13; 使徒の働き 23:7–10"> それから私は「結合」というもう一方の杖を折った。ユダとイスラエルの兄弟関係を破るためであった。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 6:10–12; ルカ 11:40; エレミヤ書 2:26–27"> 主は私に言われた。「もう一度、愚かな羊飼いの道具を取れ。</span>
<span className="v" id="v16" data-v="16" data-xref="エゼキエル書 34:2–6; エレミヤ書 23:2; マタイ 23:2–4"> 見よ、私はこの地に一人の羊飼いを起こす。その者は、滅びようとしている羊を顧みず、散らされた羊を捜さず、傷ついた羊を癒さず、健やかな羊を養わない。かえって肥えた羊の肉を食べ、そのひづめを引き裂く。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 23:1; エゼキエル書 13:3; コリント人への第一の手紙 8:4"> 群れを見捨てる無益な羊飼いには災いがある。剣がその腕と右の目を打つ。その腕は完全にしなび、その右の目は全く見えなくなる。」</span>
</div>

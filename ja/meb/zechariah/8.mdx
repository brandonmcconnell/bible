<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 万軍の主の言葉が私に臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨエル書 2:18; ゼカリヤ書 1:14–16; イザヤ書 42:13–14"> 万軍の主はこう言われる。「私はシオンへの激しい熱情に燃え、彼女のために大いなる憤りを燃やしている。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ゼカリヤ書 1:16; ゼカリヤ書 2:10–11; ヨハネ 1:14"> 主はこう言われる。「私はシオンに帰り、エルサレムのただ中に住む。エルサレムは『真実の都』と呼ばれ、万軍の主の山は『聖なる山』と呼ばれる。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 65:20–22; ヨブ記 5:26; 哀歌 5:11–15"> 万軍の主はこう言われる。「再び、老人も老女もエルサレムの広場に座り、それぞれ年老いたために杖を手に持つ。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 31:13; マタイ 11:16–17; エレミヤ書 30:19–20"> 町の広場は、そこで遊ぶ少年と少女で満ちる。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 32:27; ローマ人への手紙 4:20–21; 民数記 11:22–23"> 万軍の主はこう言われる。「その日、この民の残りの者の目にそれが驚くべきことであっても、私の目にも驚くべきことだろうか」と万軍の主は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="エレミヤ書 31:8; ローマ人への手紙 11:25–27; マラキ書 1:11"> 万軍の主はこう言われる。「見よ、私は日の昇る地から、日の沈む地から、私の民を救う。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 36:28; エゼキエル書 11:20; エレミヤ書 31:33"> 私は彼らを連れて来る。彼らはエルサレムの中に住む。彼らは私の民となり、私は真実と義をもって彼らの神となる。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 35:4; 歴代誌上 22:13; エズラ記 5:1–2"> 万軍の主はこう言われる。「万軍の主の家、すなわち神殿の基礎が据えられた日に、預言者たちの口から語られたこれらの言葉を今日聞いている者たちよ、手を強くせよ。</span>
<span className="v" id="v10" data-v="10" data-xref="ハガイ書 1:6–11; ハガイ書 2:16–18; アモス書 3:6"> その日々より前には、人にも賃金がなく、家畜にも報酬がなかった。敵のために、出て行く者にも帰って来る者にも平安はなかった。私はすべての人を互いに争わせた。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 12:1; ハガイ書 2:19; ゼカリヤ書 8:8–9"> しかし今、私はこの民の残りの者に対して、以前の日々のようにはしない」と万軍の主は言われる。</span>
<span className="v" id="v12" data-v="12" data-xref="レビ記 26:4–5; 申命記 33:13; 創世記 27:28"> 「平安の種がまかれ、ぶどうの木は実を結び、地は産物を出し、天は露を与える。私はこの民の残りの者に、これらすべてを受け継がせる。</span>
<span className="v" id="v13" data-v="13" data-xref="ゼパニヤ書 3:20; ゼカリヤ書 8:9; 詩篇 72:17"> ユダの家とイスラエルの家よ、あなたがたが諸国民の間でのろいとなっていたように、私はあなたがたを救い、あなたがたは祝福となる。恐れるな。あなたがたの手を強くせよ。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 31:28; エゼキエル書 24:14; エレミヤ書 4:28"> 万軍の主はこう言われる。「あなたがたの父祖が私を怒らせた時、私はあなたがたに災いを下そうと決め、思い直さなかった」と万軍の主は言われる。</span>
<span className="v" id="v15" data-v="15" data-xref="ゼカリヤ書 8:13; ミカ書 7:18–20; ルカ 12:32"> 「同じように今、私はこの日々にエルサレムとユダの家に良いことをしようと決めた。恐れるな。</span>
<span className="v" id="v16" data-v="16" data-xref="エペソ人への手紙 4:25; ゼカリヤ書 7:9; 詩篇 15:2"> あなたがたが行うべきことはこれである。それぞれ隣人に真実を語り、門で真実と平和の裁きを行え。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 6:16–19; ミカ書 2:1–3; エレミヤ書 44:4"> だれも心の中で隣人に対して悪を企むな。偽りの誓いを愛するな。これらはすべて、私が憎むものだからだ」と主は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 万軍の主の言葉が私に臨んだ。</span>
<span className="v" id="v19" data-v="19" data-xref="ゼカリヤ書 8:16; エレミヤ書 39:2; ゼカリヤ書 7:5"> 万軍の主はこう言われる。「第四の月、第五の月、第七の月、第十の月の断食は、ユダの家にとって喜びと楽しみ、喜ばしい祭りとなる。それゆえ、真実と平和を愛せよ。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 2:2–3; ミカ書 4:1–2; ゼカリヤ書 2:11"> 万軍の主はこう言われる。「なお、多くの民と多くの町の住民がやって来る。</span>
<span className="v" id="v21" data-v="21" data-xref="ゼカリヤ書 7:2; ホセア書 6:3; 詩篇 146:1–2"> 一つの町の住民が別の町へ行って言う。『さあ、急いで主の恵みを願い求め、万軍の主を尋ねに行こう。私も行く。』</span>
<span className="v" id="v22" data-v="22" data-xref="ゼカリヤ書 8:21; イザヤ書 60:3–22; ヨハネの黙示録 21:24"> 多くの民と強い国々が、エルサレムで万軍の主を尋ね、主の恵みを願い求めるために来る。」</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 55:5; コリント人への第一の手紙 14:25; イザヤ書 60:3"> 万軍の主はこう言われる。「その日々には、諸国民のあらゆる言語を話す者の中から十人が、一人のユダヤ人の衣の裾をつかんで言う。『私たちはあなたがたと一緒に行きます。神があなたがたとともにおられると聞いたからです。』」</span>
</div>

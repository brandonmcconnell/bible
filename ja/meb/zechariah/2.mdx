<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 31:39; エゼキエル書 45:6; ヨハネの黙示録 21:15–17"> 私は尋ねた。「どこへ行くのですか。」<br />彼は私に言った。「エルサレムの幅と長さがどれほどかを知るために、これを測りに行く。」</span>

<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ゼカリヤ書 1:19; ゼカリヤ書 1:8–11; ゼカリヤ書 4:5"> 見よ、私と話していた御使いが出て行くと、もう一人の御使いが彼に会うために出て来た。</span>
<span className="v" id="v4" data-v="4" data-xref="ゼカリヤ書 1:17; エレミヤ書 33:22; エゼキエル書 38:11"> 彼はその御使いに言った。「走って、あの若者にこう告げよ。『エルサレムは、その中に人と家畜があふれるため、城壁のない村々のように広がる。</span>
<span className="v" id="v5" data-v="5" data-xref="イザヤ書 4:5; ゼカリヤ書 9:8; 詩篇 3:3"> 私がその周囲を囲む火の城壁となり、そのただ中の栄光となる』と主は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 48:20; エゼキエル書 17:21; イザヤ書 52:11–12"> 『さあ、さあ、北の地から逃げよ』と主は言われる。『私はあなたがたを天の四方の風のように散らしたからだ』と主は言われる。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 48:20; 創世記 19:17; イザヤ書 52:11"> 『シオンよ、さあ逃れよ。バビロンの娘とともに住む者よ。』</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 17:8; 申命記 32:10; ヨハネ 15:21–23"> 万軍の主はこう言われる。『ご自分の栄光のために、主はあなたがたを略奪した国々へ私を遣わされた。あなたがたに触れる者は、主の瞳に触れる者だからだ。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 19:16; イザヤ書 14:2; ゼカリヤ書 4:9"> 見よ、私は彼らに向かって手を振る。彼らは自分たちに仕えていた者たちの略奪物となる。その時、あなたがたは万軍の主が私を遣わされたことを知る。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイ 28:20; ヨハネ 1:14; ゼパニヤ書 3:14–15"> シオンの娘よ、歌い、喜べ。見よ、私は来て、あなたの中に住む』と主は言われる。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨハネの黙示録 11:15; ペテロの手紙第一 2:9–10; 使徒の働き 28:28"> その日、多くの国々が主に結びついて、私の民となる。私はあなたの中に住む。その時、あなたは万軍の主が私をあなたに遣わされたことを知る。</span>
<span className="v" id="v12" data-v="12" data-xref="ゼカリヤ書 1:17; 申命記 32:9; エレミヤ書 10:16"> 主は聖なる地でユダをご自分の受け継ぐ分とし、再びエルサレムを選ばれる。</span>
<span className="v" id="v13" data-v="13" data-xref="ハバクク書 2:20; 詩篇 68:5; 詩篇 78:65"> すべての肉なる者よ、主の前で静まれ。主はその聖なる住まいから立ち上がられたからだ。」</span>

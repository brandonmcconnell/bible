<span className="v" id="v1" data-v="1" data-xref="ネヘミヤ記 12:4; ゼカリヤ書 7:1; ゼカリヤ書 1:7"> ダレイオスの第二年、第八の月に、主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="すべて大文字の「主」または「神」はヘブル語のיהוה（ヤハウェ）から来ている。ただし、短い形のיה（ヤハ）から来ていると記されている場合を除く。">a</a></sup>の言葉が、イドの孫、ベレクヤの子である預言者ゼカリヤに臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="エレミヤ書 44:6; 哀歌 5:7; エゼキエル書 22:31"> 「主は、あなたがたの父祖に対して激しく怒った。</span>
<span className="v" id="v3" data-v="3" data-xref="マラキ書 3:7; エレミヤ書 3:22; エレミヤ書 4:1"> それゆえ、彼らに告げよ。万軍の主はこう言う。『私に立ち返れ。そうすれば、私もあなたがたに立ち返る』と万軍の主は言う。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 78:8; 詩篇 106:6–7; エレミヤ書 35:15"> あなたがたの父祖のようになってはならない。かつての預言者たちは彼らに呼びかけた。『万軍の主はこう言う。悪い道と悪い行いから立ち返れ。』しかし、彼らは聞かず、私に耳を傾けなかった」と主は言う。</span>
<span className="v" id="v5" data-v="5" data-xref="伝道者の書 12:5; ヨブ記 14:10–12; 伝道者の書 12:7"> 「あなたがたの父祖はどこにいるのか。預言者たちは永遠に生きるのか。</span>
<span className="v" id="v6" data-v="6" data-xref="哀歌 2:17; 申命記 28:15; エゼキエル書 12:25–28"> しかし、私がしもべである預言者たちに命じた言葉と定めは、あなたがたの父祖に及んだではないか。」<br />そこで彼らは悔い改めて言った。「万軍の主は、われわれの道と行いに応じて扱おうと定められたとおり、われわれを扱われた。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ゼカリヤ書 1:1"> ダレイオスの第二年、第十一の月、すなわちシェバトの月の二十四日に、主の言葉が、イドの孫でベレクヤの子である預言者ゼカリヤに臨んだ。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの黙示録 6:4; イザヤ書 55:13; ゼカリヤ書 13:7"> 「私は夜、一つの幻を見た。見よ、<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「見よ」は、ヘブル語の「הִנֵּה」から来る語で、「見よ」「注意せよ」「よく見よ」という意味を持ち、しばしば間投詞として用いられる。">b</a></sup>赤い馬に乗った一人の人が、谷あいのミルトスの木々の間に立っていた。その後ろには、赤い馬、栗色の馬、白い馬がいた。</span>
<span className="v" id="v9" data-v="9" data-xref="ゼカリヤ書 4:4–5; ゼカリヤ書 5:5; ゼカリヤ書 2:3"> 私は尋ねた。『わが主よ、これらは何ですか。』」<br />私と話していた御使いは言った。「これらが何であるか、あなたに示そう。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ゼカリヤ書 1:11; ゼカリヤ書 6:5–8; ヘブル人への手紙 1:14"> すると、ミルトスの木々の間に立っていた人が答えた。「これらは、地を行き巡らせるために主が遣わされた者たちだ。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ゼカリヤ書 1:10; ゼカリヤ書 1:15; 詩篇 103:20–21"> 彼らはミルトスの木々の間に立っていた主の使いに報告した。「私たちは地を行き巡りました。見よ、全地は安らかで、静まっています。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ゼカリヤ書 7:5; エレミヤ書 29:10; 詩篇 102:13"> すると主の使いは答えた。「万軍の主よ、いつまでエルサレムとユダの町々をあわれんでくださらないのですか。あなたはこの七十年間、これらの町々に憤ってこられました。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 29:10; イザヤ書 40:1–2; エレミヤ書 30:10–22"> 主は、私と話していた御使いに、優しい慰めの言葉をもって答えられた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨエル書 2:18; イザヤ書 40:1; ゼカリヤ書 1:17"> そこで、私と話していた御使いは私に言った。「叫んで告げよ。万軍の主はこう言う。『私はエルサレムとシオンへの激しい熱情に燃えている。</span>
<span className="v" id="v15" data-v="15" data-xref="エゼキエル書 25:12–17; エレミヤ書 51:24; イザヤ書 54:8"> 私は安逸をむさぼる国々に激しく怒っている。私が少し怒った時、彼らは災いをいっそう深くした。</span>
<span className="v" id="v16" data-v="16" data-xref="ゼカリヤ書 8:3; エズラ記 6:14–15; ゼカリヤ書 2:10–11"> それゆえ、主はこう言う。私はあわれみをもってエルサレムに帰る。私の家はそこに建てられ、測り縄がエルサレムの上に張られる』と万軍の主は言う。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 51:3; ゼカリヤ書 2:12; ゼパニヤ書 3:15–17"> 「さらに叫んで告げよ。万軍の主はこう言う。『私の町々には再び繁栄があふれる。主は再びシオンを慰め、再びエルサレムを選ぶ。』」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 5:13; 列王記第二 24:1–20; ゼカリヤ書 5:9"> 私が目を上げて見ると、見よ、四本の角があった。</span>
<span className="v" id="v19" data-v="19" data-xref="ゼカリヤ書 1:21; ゼカリヤ書 8:14; ゼカリヤ書 2:2"> 私は、私と話していた御使いに尋ねた。「これらは何ですか。」<br />彼は私に答えた。「これらはユダ、イスラエル、エルサレムを散らした角だ。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ゼカリヤ書 10:3–5; ゼカリヤ書 12:2–6; ゼカリヤ書 9:12–16"> 主は私に四人の職人を見せられた。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 75:10; ゼカリヤ書 1:19; 詩篇 75:4–5"> 私は尋ねた。「この職人たちは何をしに来たのですか。」<br />彼は言った。「これらの角はユダを散らし、だれも頭を上げられないようにした。しかし、この職人たちは、ユダの地を散らすために角を上げた国々の角を震え上がらせ、打ち倒すために来たのだ。」</span>
</div>

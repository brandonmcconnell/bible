<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への手紙第一 5:25; コロサイ人への手紙 4:3; コリント人への第一の手紙 16:9"> 最後に兄弟たち、私たちのために祈ってください。主のことばが、あなたがたのところでそうであったように、速やかに広がり、栄光を受けますように。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第二の手紙 4:3–4; ローマ人への手紙 15:31; 申命記 32:20"> また、私たちが道理をわきまえない悪い人々から救い出されますように。すべての人に信仰があるわけではないからです。</span>
<span className="v" id="v3" data-v="3" data-xref="テモテへの第二の手紙 4:18; テサロニケ人への手紙第一 5:24; コリント人への第一の手紙 10:13"> しかし、主は真実な方です。主はあなたがたを堅く立たせ、悪い者から守ってくださいます。</span>
<span className="v" id="v4" data-v="4" data-xref="ピリピ人への手紙 1:6; フィレモンへの手紙 1:21; テサロニケ人への手紙第一 4:10"> 私たちは主にあって、あなたがたが私たちの命じることを今も行い、これからも行うと確信しています。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 119:36; 歴代誌上 29:18; 申命記 30:6"> 主が、あなたがたの心を神の愛とキリストにある忍耐へと向けてくださいますように。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="テサロニケ人への第二の手紙 3:10–11; テサロニケ人への第二の手紙 3:7; ローマ人への手紙 16:17"> 兄弟たち、私たちの主イエス・キリストの名によって、あなたがたに命じます。秩序を乱した生活をし、私たちから受けた教えに従わない兄弟から離れなさい。</span>
<span className="v" id="v7" data-v="7" data-xref="テサロニケ人への第二の手紙 3:6; テサロニケ人への第二の手紙 3:9; コリント人への第一の手紙 4:16"> 私たちにどのように倣うべきかは、あなたがた自身が知っています。私たちは、あなたがたの間で秩序を乱すような生活をせず、</span>
<span className="v" id="v8" data-v="8" data-xref="マタイ 6:11; テサロニケ人への手紙第一 2:9; エペソ人への手紙 4:28"> だれのパンも、ただで食べることはしませんでした。むしろ、あなたがたのだれにも負担をかけないように、労苦を重ね、夜昼働きました。</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への第二の手紙 3:7; テサロニケ人への手紙第一 2:6; コリント人への第一の手紙 9:4–14"> それは、私たちにその権利がないからではなく、あなたがたが私たちに倣うよう、自分たちを模範として示すためでした。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 3:19; 箴言 13:4; 箴言 20:4"> 私たちは、あなたがたと一緒にいた時にも、「働こうとしない者は、食べてはならない」と命じました。</span>
<span className="v" id="v11" data-v="11" data-xref="テモテへの手紙第一 5:13; テサロニケ人への第二の手紙 3:6; テサロニケ人への手紙第一 4:11"> ところが聞くところによると、あなたがたの中には秩序を乱した生活をし、少しも働かず、かえって他人のことに口を出している人たちがいるとのことです。</span>
<span className="v" id="v12" data-v="12" data-xref="エペソ人への手紙 4:28; テサロニケ人への手紙第一 4:11; テサロニケ人への第二の手紙 3:8"> そのような人たちに、静かに働き、自分のパンを食べるよう、主イエス・キリストにあって命じ、勧めます。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ガラテヤ人への手紙 6:9–10; ヘブル人への手紙 12:3; コリント人への第二の手紙 4:1"> しかし兄弟たち、正しいことを行うのに、くじけてはなりません。</span>
<span className="v" id="v14" data-v="14" data-xref="テトス 3:10; テサロニケ人への第二の手紙 3:6; コリント人への第一の手紙 5:11"> この手紙に記した私たちのことばに従わない人がいれば、その人がだれかを見定め、交わりを持たないようにしなさい。その人が恥じるようになるためです。</span>
<span className="v" id="v15" data-v="15" data-xref="テトス 3:10; テサロニケ人への手紙第一 5:14; コリント人への第一の手紙 5:5"> けれども、その人を敵とはみなさず、兄弟として戒めなさい。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="詩篇 29:11; ヨハネ 16:33; マタイ 1:23"> どうか、平和の主ご自身が、いつでも、あらゆる仕方で、あなたがたに平和を与えてくださいますように。主があなたがたすべてとともにおられますように。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 16:21; テサロニケ人への第二の手紙 1:5; コロサイ人への手紙 4:18"> 私パウロが、自分の手でこのあいさつを書きます。これはどの手紙にもある印です。これが私の筆跡です。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 16:20; ローマ人への手紙 16:23"> 私たちの主イエス・キリストの恵みが、あなたがたすべてとともにありますように。アーメン。</span>
</div>

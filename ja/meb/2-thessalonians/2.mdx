<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への手紙第一 4:14–17; マルコ 13:27; マタイ 24:31"> さて兄弟たち、私たちの主イエス・キリストの来臨と、私たちが主のもとに集められることについて、あなたがたにお願いします。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの手紙第一 4:1–2; マルコ 13:7; マタイ 24:4–6"> キリストの日がすでに来たと言われても、それが霊によるものであれ、ことばによるものであれ、私たちから出たかのような手紙によるものであれ、すぐに心を揺さぶられたり、動揺したりしないでください。</span>
<span className="v" id="v3" data-v="3" data-xref="マタイ 24:4–6; ヨハネの手紙第一 2:18; エペソ人への手紙 5:6"> どのようなことがあっても、だれにも惑わされてはなりません。まず反逆<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="あるいは、離れ去ること、または、離反">a</a></sup>が起こり、罪の人、すなわち滅びの子が現れないかぎり、その日は来ないからです。</span>
<span className="v" id="v4" data-v="4" data-xref="エゼキエル書 28:2; ダニエル書 7:25; ヨハネの黙示録 13:6–7"> 彼は、神と呼ばれるものや礼拝の対象となるものすべてに逆らい、それらすべての上に自分を高く上げます。そして神として神の神殿に座り、自分こそ神であると示します。</span>
<span className="v" id="v5" data-v="5" data-xref="ペテロの第二の手紙 1:15; ガラテヤ人への手紙 5:21; マタイ 16:9"> 私がまだあなたがたと一緒にいた時、これらのことを語っていたのを覚えていないのですか。</span>
<span className="v" id="v6" data-v="6" data-xref="テサロニケ人への第二の手紙 2:3; テサロニケ人への第二の手紙 2:8"> 彼が定められた時に現れるよう、何が彼を押しとどめているのかを、あなたがたは今知っています。</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの手紙第一 4:3; ヨハネの黙示録 17:7; テモテへの第二の手紙 2:17–18"> 不法の奥義は、すでに働いています。ただ、今はそれを押しとどめる者がいて、その者が取り除かれる時までです。</span>
<span className="v" id="v8" data-v="8" data-xref="テサロニケ人への第二の手紙 2:3; ヨハネの黙示録 19:20–21; イザヤ書 11:4"> その時、不法の者が現れます。主は、その者を御口の息によって殺し、ご自分の来臨を現す時、その者を滅ぼされます。</span>
<span className="v" id="v9" data-v="9" data-xref="マタイ 24:24; ヨハネの黙示録 19:20; エペソ人への手紙 2:2"> その不法の者が来るのは、サタンの働きによるもので、あらゆる力としるし、偽りの不思議を伴い、</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 1:18; 箴言 1:7; コリント人への第二の手紙 4:2–3"> 滅びつつある者たちを、あらゆる不義の欺きによって惑わします。彼らが救われるために、真理への愛を受け入れなかったからです。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 1:28; ヨハネ 12:39–43; テモテへの手紙第一 4:1"> そのため神は、彼らが偽りを信じるように、強い惑わしを送られます。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 1:32; ローマ人への手紙 8:7–8; マルコ 16:16"> こうして、真理を信じず、不義を喜んだ者たちは、みな裁かれるのです。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="テモテへの第二の手紙 1:9; エペソ人への手紙 1:4–5; テサロニケ人への手紙第一 1:4"> しかし、主に愛されている兄弟たち、私たちは、あなたがたのことでいつも神に感謝しなければなりません。神は初めから、聖霊によって聖なる者とされ、真理を信じることによって救われるように、あなたがたを選ばれたからです。</span>
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への手紙第一 2:12; ペテロの手紙第一 5:10; テサロニケ人への手紙第一 1:5"> 神は、このために、私たちの福音を通してあなたがたを召されました。それは、私たちの主イエス・キリストの栄光にあずからせるためです。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 11:2; テサロニケ人への第二の手紙 3:6; テサロニケ人への第二の手紙 2:2"> ですから兄弟たち、堅く立ち、私たちが口頭であれ手紙であれ教えたことを、しっかり守りなさい。</span>
</div>

<span className="v" id="v17" data-v="17" data-xref="テサロニケ人への第二の手紙 3:3; テサロニケ人への手紙第一 3:13; テサロニケ人への手紙第一 3:2"> あなたがたの心を慰め、あらゆる良い行いとことばにおいて、あなたがたを堅く立たせてくださいますように。</span>

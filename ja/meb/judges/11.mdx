<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヘブル人への手紙 11:32; 士師記 6:12; 列王記第二 5:1"> ギルアデ人エフタは勇士であったが、遊女の子であった。ギルアデがエフタの父である。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 12:10; 箴言 2:16; 申命記 23:2"> ギルアデの妻も息子たちを産んだ。その息子たちが成長すると、エフタを追い出して言った。「あなたは父の家で相続を受けることはできない。別の女の息子だからだ。」</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 9:4; サムエル記第一 22:2; サムエル記第二 10:8"> そこでエフタは自分の兄弟たちから逃れ、トブの地に住んだ。ならず者たちがエフタの周りに集まり、彼とともに出て行った。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士師記 10:9"> しばらくして、アンモンの子らがイスラエルに対して戦いを仕掛けた。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 118:22–23; 使徒の働き 7:35–39; コリント人への第一の手紙 1:27–29"> アンモンの子らがイスラエルに対して戦いを仕掛けたとき、ギルアデの長老たちはエフタをトブの地から連れ戻そうと出かけた。</span>
<span className="v" id="v6" data-v="6"> 彼らはエフタに言った。「来て、私たちの指揮官になってほしい。そうすれば、私たちはアンモンの子らと戦うことができる。」</span>
<span className="v" id="v7" data-v="7" data-xref="ヨハネの黙示録 3:9; 創世記 45:4–5; イザヤ書 60:14"> エフタはギルアデの長老たちに言った。「あなたがたは私を憎み、父の家から私を追い出したではないか。あなたがたが苦難にある今になって、なぜ私のところに来たのか。」</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 10:18; 列王記第一 13:6; 出エジプト記 10:17"> ギルアデの長老たちはエフタに言った。「それゆえ、私たちは今、再びあなたのもとに帰って来たのだ。あなたが私たちとともに行き、アンモンの子らと戦ってくれるためである。そうすれば、あなたはギルアデの全住民の上に立つ私たちの頭となる。」</span>
<span className="v" id="v9" data-v="9" data-xref="民数記 32:20–29"> エフタはギルアデの長老たちに言った。「あなたがたが私を連れ戻してアンモン人と戦わせ、主が彼らを私に渡されるなら、私は本当にあなたがたのかしらとなるのか。」</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 42:5; 創世記 31:50; エレミヤ書 29:23"> ギルアデの長老たちはエフタに言った。「主が私たちの間の証人となられる。私たちは必ずあなたの言葉どおりに行う。」</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 10:17; サムエル記第一 10:17; 士師記 20:1"> そこでエフタはギルアデの長老たちとともに行った。民は彼を自分たちのかしら、また指揮官とした。エフタはミツパで、主の御前に自分の言葉をすべて語った。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 2:26; マタイ 18:15–16; 箴言 25:8–9"> エフタはアンモンの子らの王に使者たちを遣わして言った。「あなたと私との間に何のかかわりがあって、あなたは私の地に対して戦うために、私のところに来たのか。」</span>
<span className="v" id="v13" data-v="13" data-xref="創世記 32:22; 民数記 21:24–26; 申命記 2:37"> アンモンの子らの王はエフタの使者たちに答えた。「イスラエルがエジプトから上って来たとき、アルノンからヤボク、そしてヨルダン川に至るまで、私の地を奪い取ったからだ。それゆえ今、それらの地を平和のうちに返しなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ペテロの手紙第一 3:11; ローマ人への手紙 12:18; ヘブル人への手紙 12:14"> エフタは再びアンモンの子らの王に使者たちを遣わした。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 2:19; 申命記 2:9; 民数記 21:27–30"> 彼は彼に言った。「エフタはこう言う。イスラエルはモアブの地も、アンモンの子らの地も奪い取ってはいない。</span>
<span className="v" id="v16" data-v="16" data-xref="民数記 14:25; 申命記 1:40; 民数記 20:1"> イスラエルがエジプトから上って来たとき、イスラエルは荒野を通って紅海に行き、カデシュに来た。</span>
<span className="v" id="v17" data-v="17" data-xref="民数記 20:14–21; 申命記 2:4–9; 民数記 20:1"> そのとき、イスラエルはエドムの王に使者たちを遣わして、『どうか、あなたの地を通らせてほしい』と言ったが、エドムの王は聞き入れなかった。同じようにモアブの王にも遣わしたが、彼も承知しなかった。それでイスラエルはカデシュに留まった。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 2:1–8; 民数記 22:36; 民数記 21:4–13"> それから彼らは荒野を通り、エドムの地とモアブの地を迂回し、モアブの地の東側に来て、アルノンの向こう側に陣を敷いた。しかし彼らはモアブの領土の内には入らなかった。アルノンはモアブの境界だったからである。</span>
<span className="v" id="v19" data-v="19" data-xref="民数記 21:21–35; 申命記 2:26–36; 申命記 3:1–17"> イスラエルはアモリ人の王、ヘシュボンの王シホンに使者を送り、『どうか、私たちの目的地まであなたの地を通らせてください』と言った。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨシュア記 13:15–32; 民数記 21:23–25; 詩篇 136:17–21"> しかしシホンは、イスラエルが自分の境界を通ることを信用しなかった。それどころか、シホンは自分のすべての民を呼び集め、ヤハツに陣を敷いてイスラエルと戦った。</span>
<span className="v" id="v21" data-v="21"> イスラエルの神、主は、シホンとそのすべての民をイスラエルの手に引き渡されたため、彼らはこれを打ち倒した。こうしてイスラエルは、その地方の住民であるアモリ人の全地を所有した。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 2:36"> 彼らはアルノンからヤボクに至るまで、また荒野からヨルダン川に至るまで、アモリ人の全境界を所有した。</span>
<span className="v" id="v23" data-v="23"> 今、イスラエルの神、主が、その民イスラエルの前からアモリ人を追い払われた。それなのに、あなたがその地を所有しようというのか。</span>
<span className="v" id="v24" data-v="24" data-xref="民数記 21:29; 詩篇 78:55; ミカ書 4:5"> あなたは、自分の神ケモシュが与えるものを所有するのではないか。私たちも、私たちの神、主が私たちの前から追い払われた者の地を所有する。</span>
<span className="v" id="v25" data-v="25" data-xref="ミカ書 6:5; ヨシュア記 24:9–10; 申命記 23:3–4"> 今、あなたはモアブの王ツィポルの子バラクにまさっているというのか。彼はかつてイスラエルと争っただろうか。あるいは彼らと戦っただろうか。</span>
<span className="v" id="v26" data-v="26" data-xref="申命記 2:36; ヨシュア記 12:5; 士師記 10:8"> イスラエルがヘシュボンとその町々、アロエルとその町々、またアルノン沿いのすべての町々に三百年の間住んでいたのに、なぜあなたがたはその間にそれらを取り戻さなかったのか。</span>
<span className="v" id="v27" data-v="27" data-xref="サムエル記第一 24:15; 創世記 16:5; サムエル記第一 24:12"> それゆえ、私はあなたに対して罪を犯していないが、あなたは私に対して戦いを仕掛けて悪を行っている。さばき主である主が今日、イスラエルの人々とアンモンの子らとの間をさばかれますように。」</span>
<span className="v" id="v28" data-v="28" data-xref="列王記第二 14:11; 箴言 16:18"> しかし、アンモンの子らの王は、エフタが遣わした言葉に聞き入れなかった。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数記 11:25; 士師記 3:10; 士師記 13:25"> そのとき主の霊がエフタに臨んだ。彼はギルアデとマナセを通り、ギルアデのミツパへ進み、そこからアンモン人のところへ渡って行った。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 28:20; サムエル記第一 1:11; 伝道者の書 5:1–2"> エフタは主に誓願を立てて言った。「もしあなたが本当に、アンモンの子らを私の手に渡してくださるなら、</span>
<span className="v" id="v31" data-v="31" data-xref="詩篇 66:13–14; レビ記 27:28–29; サムエル記第一 1:28"> 私がアンモン人のところから無事に帰るとき、私の家の戸口から私を迎えに出て来るものは主のものとなり、私はそれを全焼のささげ物としてささげます。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="士師記 1:4; 士師記 2:18; 士師記 3:10"> そこでエフタはアンモンの子らと戦うために彼らのところへ渡って行った。主は彼らを彼の手に渡された。</span>
<span className="v" id="v33" data-v="33" data-xref="エゼキエル書 27:17; 申命記 2:36"> 彼はアロエルからミニテに至るまで二十の町を打ち、さらにアベル・ケラミムまで大打撃を与えた。こうしてアンモン人はイスラエルの人々の前に屈服した。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="エレミヤ書 31:4; 出エジプト記 15:20; 士師記 10:17"> エフタがミツパの自分の家に帰って来ると、娘がタンバリンを鳴らし、踊りながら迎えに出て来た。彼女は彼の一人娘であった。彼女のほかに彼には息子も娘もいなかった。</span>
<span className="v" id="v35" data-v="35" data-xref="マタイ 14:7–9; 創世記 37:29–30; 創世記 42:36–38"> 彼女を見ると、エフタは衣を裂いて言った。「ああ、娘よ。おまえは私を打ちのめした。おまえまでが私を苦しめる者となった。私は主に口を開いて誓った。もう取り消すことはできない。」</span>
<span className="v" id="v36" data-v="36" data-xref="サムエル記第二 18:19; ピリピ人への手紙 2:30; ローマ人への手紙 16:4"> 彼女は彼に言った。「私の父よ。あなたは主に口を開かれたのですから、あなたの口から出たとおりに私にしてください。主があなたの敵であるアンモンの子らに、あなたのために復讐してくださったからです。」</span>
<span className="v" id="v37" data-v="37" data-xref="ルカ 1:25; サムエル記第一 1:6"> 彼女は父に言った。「このことを私にさせてください。二か月の間、私をそのままにしてください。私が出かけて山々へ行き、私の処女であることを友たちとともに嘆き悲しむためです。」</span>
<span className="v" id="v38" data-v="38"> 彼は「行きなさい」と言った。彼は彼女を二か月の間送り出し、彼女は友たちとともに去って行き、山々で自分の処女であることを嘆き悲しんだ。</span>
<span className="v" id="v39" data-v="39" data-xref="イザヤ書 66:3; 士師記 11:31; レビ記 27:28–29"> 二か月の終わりに彼女は父のもとへ帰った。父は誓った誓願のとおりに彼女に行った。彼女は男を知らなかった。このことから、イスラエルでは一つの慣わしが生まれ、</span>
<span className="v" id="v40" data-v="40" data-xref="列王記第一 9:25; 士師記 5:11"> イスラエルの娘たちは毎年四日間、ギルアデ人エフタの娘をしのぶために出て行くようになった。</span>
</div>

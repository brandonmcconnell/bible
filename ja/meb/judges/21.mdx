<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 20:1; マルコ 6:23; 使徒の働き 23:12"> さて、イスラエルの男たちはミツパで誓って言った。「私たちのうち、だれ一人として自分の娘をベニヤミンに妻として与えてはならない。」</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 20:26; 士師記 20:18; サムエル記第一 30:4"> 民はベテルに来て、そこで夕暮れまで神の前に座り、声を上げて激しく泣いた。</span>
<span className="v" id="v3" data-v="3" data-xref="詩篇 74:1; ヨシュア記 7:7–9; イザヤ書 63:17"> 彼らは言った。「イスラエルの神、主よ。なぜイスラエルにこのことが起こり、今日、イスラエルから一つの部族が欠けることになったのでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="サムエル記第二 24:25; 列王記第一 8:64; 詩篇 78:34–35"> 翌日、民は朝早く起き、そこに祭壇を築いて、全焼のささげ物と和解のいけにえを献げた。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 5:23; 士師記 21:18; 士師記 21:1"> イスラエルの人々は言った。「イスラエルの全部族のうち、主の集会に上って来なかった者はだれか。」彼らは、ミツパで主のもとに上らなかった者について、「その者は必ず死ななければならない」と固く誓っていた。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 21:15; 士師記 20:23; ルカ 19:41–42"> イスラエルの人々は兄弟であるベニヤミンのために悲しんで言った。「今日、イスラエルから一つの部族が断ち切られてしまった。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 21:1; 士師記 21:18; サムエル記第一 14:28–29"> 私たちは主にかけて、私たちの娘たちを彼らに妻として与えないと誓ったのだから、残っている者たちに妻を備えるにはどうすればよいのか。」</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記第一 31:11–13; サムエル記第一 11:1–3; サムエル記第二 2:5–6"> 彼らは言った。「イスラエルの部族のうち、ミツパで主のもとに上って来なかったのはだれか。」調べると、ヤベシュ・ギルアデからはだれ一人、陣営の集会に来ていなかった。</span>
<span className="v" id="v9" data-v="9"> 民を数えてみると、ヤベシュ・ギルアデの住民は一人もいなかった。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="士師記 5:23; 士師記 21:5; サムエル記第一 11:7"> 会衆は最も勇敢な者一万二千人をそこへ送り、命じた。「行って、ヤベシュ・ギルアデの住民を、女も子どもも剣で打て。</span>
<span className="v" id="v11" data-v="11" data-xref="民数記 31:17–18; 申命記 2:34"> こうせよ。すべての男と、男を知ったすべての女を聖絶せよ。」</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 18:1; エレミヤ書 7:12; 詩篇 78:60"> 彼らはヤベシュ・ギルアデの住民の中に、男と寝たことのない若い処女四百人を見つけ、カナンの地にあるシロの陣営へ連れて来た。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="士師記 20:47; 申命記 20:10; エペソ人への手紙 2:17"> 全会衆はリモンの岩にいるベニヤミンの人々に使者を遣わして語り、彼らに平和を告げた。</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 21:12; コリント人への第一の手紙 7:2; 士師記 20:47"> ベニヤミン人はその時、戻って来たので、彼らはヤベシュ・ギルアデの女たちの中で生かしておいた女たちを彼らに与えた。それでも彼らには十分ではなかった。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 21:6; 歴代誌上 15:13; イザヤ書 58:12"> 主がイスラエルの諸部族の間に裂け目を生じさせられたので、民はベニヤミンのために悲しんだ。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> その時、会衆の長老たちは言った。「ベニヤミンの女たちは滅ぼされてしまったので、残っている者たちに妻を備えるにはどうすればよいのか。」</span>
<span className="v" id="v17" data-v="17" data-xref="民数記 26:55; 民数記 36:7"> 彼らは言った。「イスラエルから一つの部族が消し去られないために、生き残ったベニヤミン人の相続地が保たれなければならない。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 21:1; 士師記 11:35"> しかし、私たちは自分たちの娘を彼らに妻として与えることはできない。イスラエルの人々は、『ベニヤミンに妻を与える者はのろわれる』と言って誓ったからである。」</span>
<span className="v" id="v19" data-v="19" data-xref="申命記 16:10; 申命記 16:1; 申命記 16:13"> 彼らは言った。「毎年、シロで主の祭りが行われる。シロはベテルの北、ベテルからシェケムへ上る大通りの東、レボナの南にある。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 彼らはベニヤミンの人々に命じて言った。「行って、ぶどう畑で待ち伏せしなさい。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 11:34; 出エジプト記 15:20; 伝道者の書 3:4"> そして見なさい。シロの娘たちが踊りを踊るために出て来たら、あなたがたはぶどう畑から出て来て、シロの娘たちの中からそれぞれ自分の妻を捕らえ、ベニヤミンの地へ行きなさい。</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 21:1; 士師記 21:18; 士師記 21:14"> 彼女たちの父や兄弟が私たちに訴えに来たら、こう言おう。『私たちのために、彼らに娘たちを恵んでやってほしい。戦いの時、私たちは彼ら一人一人の妻を確保できなかった。あなたがたが娘を彼らに与えたのではないから、誓いを破った罪に問われることもない。』」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="士師記 20:48"> ベニヤミン人はそのように行い、踊っていた娘たちの中から、自分たちの数に応じて妻をさらった。それから相続地へ帰り、町々を建て直して住んだ。</span>
<span className="v" id="v24" data-v="24"> イスラエルの人々はその時、それぞれ自分の部族、自分の氏族のところへ去って行った。彼らはそこから出て、それぞれ自分の相続地へ行った。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 12:8; 士師記 17:6; 箴言 3:5"> その頃、イスラエルには王がなく、それぞれが自分の目に正しいと見えることを行っていた。</span>
</div>

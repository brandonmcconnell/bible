<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 11:11; サムエル記第一 3:20; サムエル記第一 10:17"> その時、イスラエルの人々は皆、ダンからベエル・シェバに至るまで、またギルアデの地からも出て来た。会衆は一人の人のように、ミツパで主の御前に集まった。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 8:10; 士師記 20:17; 士師記 20:15"> 民全体のかしらたち、すなわちイスラエルの全部族のかしらたちは、神の民の集会に立った。剣を抜くことのできる歩兵は四十万人であった。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 19:22–27; ルカ 14:31–32; ルカ 12:58–59"> ベニヤミンの人々は、イスラエルの人々がミツパへ上ったことを聞いた。イスラエルの人々は言った。「この悪事がどのように起こったのか、話しなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士師記 19:15–28"> 殺された女の夫であるレビ人は答えた。「私とそばめは、泊まるためにベニヤミンのギベアへ入りました。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 19:22; 士師記 19:25–26; 創世記 19:4–8"> ギベアの男たちは私に襲いかかり、夜、私のいる家を取り囲みました。私を殺そうとし、そばめを犯して死なせました。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 19:29; ヨシュア記 7:15; 士師記 19:23"> 私はそばめの体を切り分け、イスラエルの相続地の全地方へ送りました。彼らがイスラエルの中で、みだらで恥ずべきことを行ったからです。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 19:30; コリント人への第一の手紙 5:6; コリント人への第一の手紙 5:10–12"> イスラエルの人々よ、あなたがたは皆ここにいる。今、意見を述べ、協議せよ。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="伝道者の書 9:10; 士師記 20:1; 箴言 21:3"> 民は皆、一人の人のように立ち上がって言った。「私たちはだれ一人、自分の天幕へ行かない。だれ一人、自分の家へ帰らない。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨナ書 1:7; ネヘミヤ記 11:1; ヨシュア記 14:2"> 今、私たちがギベアに対して行うことはこれである。私たちはくじによってそこへ上って行く。</span>
<span className="v" id="v10" data-v="10"> イスラエルの全部族から、百人ごとに十人、千人ごとに百人、一万人ごとに千人を選び、民の食料を調達させよう。そして民がベニヤミンのギベアへ着いたら、彼らがイスラエルで行ったすべての恥ずべきことに応じて報いよう。」</span>
<span className="v" id="v11" data-v="11"> こうしてイスラエルの男たちは皆、一人の人のように結び合わされ、その町に向かって集まった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命記 13:14; 申命記 20:10; ローマ人への手紙 12:18"> イスラエルの部族は、ベニヤミンの部族全体に使者を遣わして言った。「あなたがたの間で起こったこの悪事は何なのか。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 17:12; 申命記 13:13; 士師記 19:22"> 今、ギベアにいるよこしまな男たちを引き渡せ。彼らを死刑にし、イスラエルから悪を除き去ろう。」しかしベニヤミン人は、兄弟であるイスラエルの人々の声に聞き従わなかった。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 20:20; ヨブ記 15:25–26; 民数記 21:23"> ベニヤミンの人々は、イスラエルの人々と戦うため、町々からギベアに集まった。</span>
<span className="v" id="v15" data-v="15" data-xref="民数記 26:41; 士師記 20:25; 民数記 1:37"> その日、町々から集まったベニヤミンの人々のうち、剣を抜くことのできる者は二万六千人と数えられた。これに加えて、ギベアの住民から七百人のえり抜きの者たちが数えられた。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 3:15; 歴代誌上 12:2; サムエル記第一 17:49–50"> この全軍の中に、左利きのえり抜きの兵が七百人いた。彼らは皆、髪の毛一本を狙って石を投げても外さなかった。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民数記 1:46; 歴代誌 第二 17:14–18; 民数記 26:51"> ベニヤミン以外のイスラエルの男たちは、剣を抜くことのできる者が四十万人と数えられた。これらは皆、戦士であった。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 20:23; 士師記 20:26–27; 民数記 27:21"> イスラエルの人々は立ってベテルへ上り、神に尋ねた。「私たちのうち、だれが最初にベニヤミン人との戦いに上るべきでしょうか。」主は言われた。「ユダが最初に上れ。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 7:16; ヨシュア記 3:1; ヨシュア記 6:12"> イスラエルの人々は朝早く起き、ギベアに向かって陣を敷いた。</span>
<span className="v" id="v20" data-v="20"> イスラエルの男たちはベニヤミンと戦うために出て行き、ギベアで彼らに向かって陣形を整えた。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 20:25; 詩篇 73:18–19; 歴代誌 第二 28:10"> ベニヤミンの人々はギベアから出て来て、その日、イスラエル人二万二千人を地に打ち倒した。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 64:5; 士師記 20:17; サムエル記第一 30:6"> しかし民、すなわちイスラエルの男たちは自らを奮い立たせ、最初の日に陣形を整えた場所で、再び陣形を整えた。</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 20:26–27; 詩篇 78:34–36; ヨシュア記 7:6"> イスラエルの人々は上り、夕方まで主の御前で泣いた。そして主に尋ねた。「兄弟ベニヤミンとの戦いに、もう一度進むべきでしょうか。」主は言われた。「彼らに向かって上れ。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> イスラエルの人々は二日目に、ベニヤミンの人々に近づいた。</span>
<span className="v" id="v25" data-v="25" data-xref="士師記 20:21; 創世記 18:25; ローマ人への手紙 2:5"> ベニヤミンは二日目にギベアから彼らに向かって出て行き、イスラエルの人々のうち、さらに一万八千人を地に打ち倒した。これらは皆、剣を抜くことのできる者たちであった。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="士師記 20:23; ヨエル書 2:12–18; 士師記 20:18"> その時、イスラエルの人々と民は皆上って行き、ベテルに来て泣き、主の御前に座り、その日は夕暮れまで断食し、主の御前に全焼のささげ物と和解のいけにえを献げた。</span>
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 18:1; 士師記 20:18; サムエル記第一 4:3–4"> イスラエルの人々は主に尋ねた。その頃、神の契約の箱がそこにあり、</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 7:9; ヨシュア記 24:33; 申命記 18:5"> アロンの子エルアザルの子ピネハスが、その頃その前に立っていた。彼らは言った。「私たちの兄弟であるベニヤミンの人々との戦いに、再び出て行くべきでしょうか。それともやめるべきでしょうか。」主は言われた。「上って行け。明日、わたしは彼らをあなたの手に渡す。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 8:4; サムエル記第二 5:23; 士師記 20:34"> イスラエルはギベアの周囲に伏兵を置いた。</span>
<span className="v" id="v30" data-v="30"> イスラエルの人々は三日目にベニヤミンの人々に向かって上って行き、前の時と同じようにギベアに向かって陣形を整えた。</span>
<span className="v" id="v31" data-v="31" data-xref="士師記 19:13–14; ヨシュア記 7:5; イザヤ書 10:29"> ベニヤミン人は民に向かって出て行き、町から引き離された。彼らは前と同じように、野を通る二つの大通りでイスラエルの人々を打ち始め、およそ三十人を殺した。一方の道はベテルへ、もう一方はギベアへ上っていた。</span>
<span className="v" id="v32" data-v="32" data-xref="ヨシュア記 8:15–16"> ベニヤミンの人々は、「彼らは最初の時と同じように、私たちの前で打ち倒されている」と言った。しかしイスラエルの人々は、「私たちは逃げて、彼らを町から大通りへ引き離そう」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="ヨシュア記 8:18–22"> イスラエルの男たちは皆その場所から立ち上がり、バアル・タマルで陣形を整えた。イスラエルの伏兵たちは、その場所、すなわちマアレ・ゲバから突進した。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨシュア記 8:14; イザヤ書 47:11; ヨブ記 21:13"> 全イスラエルから選ばれた一万人がギベアの前に来て、戦いは激しくなった。しかしベニヤミンの人々は、わざわいが自分たちに迫っていることを知らなかった。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨブ記 20:5; 士師記 20:15; 士師記 20:44–46"> 主はイスラエルの前でベニヤミンを打たれた。その日、イスラエルの人々はベニヤミンのうち二万五千百人を滅ぼした。これらは皆、剣を抜くことのできる者たちであった。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="ヨシュア記 8:15–29"> ベニヤミン人は自分たちが打ち破られたのを見た。イスラエルの男たちは、ギベアに置いた伏兵を頼み、ベニヤミンに場所を譲っていたのである。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨシュア記 8:19; ヨシュア記 6:5; 出エジプト記 19:13"> 伏兵は急いでギベアに突進した。伏兵は広がり、剣の刃で町全体を打った。</span>
<span className="v" id="v38" data-v="38" data-xref="ヨシュア記 8:20; 創世記 17:21; 列王記第二 4:16"> さて、イスラエルの男たちと伏兵との間の合図は、町から大きな煙の雲を立ち上らせることであった。</span>
<span className="v" id="v39" data-v="39" data-xref="士師記 20:32"> イスラエルの男たちが戦いの中で退き始めると、ベニヤミンは彼らを打ち、およそ三十人を殺し始めた。「確かに、最初の戦いのように彼らは私たちの前に倒れている」と思ったからである。</span>
<span className="v" id="v40" data-v="40" data-xref="ヨシュア記 8:20; ヨハネの黙示録 19:3; 創世記 19:28"> ところが、町から合図の煙が柱となって立ち上り始めた。ベニヤミン人が振り返ると、町全体が天へ向かって燃え上がっていた。</span>
<span className="v" id="v41" data-v="41" data-xref="ペテロの第二の手紙 2:12; ルカ 21:26; ヨハネの黙示録 6:15–17"> イスラエルの男たちが向きを変えると、ベニヤミンの男たちはおののいた。災いが自分たちに迫ったのを見たからである。</span>
<span className="v" id="v42" data-v="42" data-xref="ヨシュア記 8:15; ホセア書 9:9; 哀歌 1:3"> それで彼らはイスラエルの男たちの前で背を向け、荒野への道に向かった。しかし戦いは彼らに激しく迫り、町々から出て来た者たちは、そのただ中で彼らを滅ぼした。</span>
<span className="v" id="v43" data-v="43" data-xref="ヨシュア記 8:20–22"> イスラエル人はベニヤミン人を包囲し、追い立て、休む間もなく踏みにじって、日の昇る方、ギベアの近くまで迫った。</span>
<span className="v" id="v44" data-v="44"> ベニヤミンのうち一万八千人が倒れた。これらは皆、勇士たちであった。</span>
<span className="v" id="v45" data-v="45" data-xref="ヨシュア記 15:32; 士師記 21:13; ゼカリヤ書 14:10"> 彼らは向きを変え、荒野のリモンの岩へ逃げた。イスラエル人は大通りで五千人を討ち取り、さらにギドムまで激しく追って二千人を打った。</span>
<span className="v" id="v46" data-v="46" data-xref="士師記 20:35; 士師記 20:15"> こうしてその日、ベニヤミンのうち倒れた者は皆で二万五千人であり、剣を抜くことのできる者たちであった。これらは皆、勇士たちであった。</span>
<span className="v" id="v47" data-v="47" data-xref="イザヤ書 1:9; 詩篇 103:9–10; ハバクク書 3:2"> しかし六百人は向きを変え、荒野に向かってリモンの岩へ逃げ、四か月の間、リモンの岩に留まった。</span>
<span className="v" id="v48" data-v="48" data-xref="申命記 13:15–17; 歴代誌 第二 25:13; 歴代誌 第二 28:6–9"> イスラエルの男たちは引き返してベニヤミンの人々を襲い、町も家畜も見つけたものをすべて剣で打った。さらに、見つけたすべての町に火を放った。</span>
</div>

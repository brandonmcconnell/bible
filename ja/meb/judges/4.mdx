<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 5:3; 士師記 3:12; 士師記 3:7"> エフドが死ぬと、イスラエルの人々は再び主の目に悪を行った。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 11:1; 士師記 4:16; 士師記 4:13"> そこで主は彼らを、ハツォルで治めていたカナンの王ヤビンの手に売り渡された。彼の軍の長はシセラであり、彼は異邦人のハロシェテに住んでいた。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 1:19; 詩篇 106:42; 士師記 3:9"> イスラエルの人々は主に叫び求めた。シセラは鉄の戦車九百両を持ち、二十年の間、イスラエルの人々を容赦なくしいたげていたからである。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 15:20; ルカ 2:36; 列王記第二 22:14"> そのとき、女預言者でラピドテの妻であるデボラがイスラエルをさばいていた。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 18:19; エレミヤ書 31:15; 出エジプト記 18:26"> 彼女はエフライムの山地、ラマとベテルの間にある「デボラのなつめやしの木」の下に座していた。イスラエルの人々は、さばきを求めて彼女のもとに上って来た。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒の働き 13:47; 士師記 8:18; ヘブル人への手紙 11:32"> 彼女は人を遣わして、ナフタリのケデシュからアビノアムの子バラクを呼び寄せ、彼に言った。「イスラエルの神、主はこう命じられたではないか。『行き、ナフタリの子らとゼブルンの子らの中から一万人を率いて、タボル山へ進軍せよ。</span>
<span className="v" id="v7" data-v="7" data-xref="列王記第一 18:40; エゼキエル書 38:10–16; 詩篇 83:9–10"> わたしはヤビンの軍の長シセラと、その戦車およびその大軍を、キション川のあなたのもとに引き寄せ、彼をあなたの手に渡す。』」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 4:10–14; マタイ 14:30–31"> バラクは彼女に言った。「あなたが私とともに行くなら、私も行きます。しかし、ともに行かないなら、私は行きません。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="士師記 2:14; サムエル記第一 2:30; 士師記 4:17–22"> 彼女は言った。「私は必ずあなたとともに行きます。ただし、あなたがこれから進む道によって、あなたは誉れを得ません。主がシセラを一人の女の手に売り渡されるからです。」デボラは立ち上がり、バラクとともにケデシュへ行った。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="士師記 5:18; 士師記 5:15; 士師記 4:14"> バラクはゼブルンとナフタリをケデシュに呼び集めた。一万人が彼の後に従って行き、デボラも彼と一緒に上って行った。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="士師記 1:16; ヨシュア記 19:33; 民数記 10:29"> さて、ケニ人ヘベルは、モーセの義理の兄弟であるホバブの子孫であるケニ人から離れ、ケデシュのそばにあるツァアナニムの樫の木の傍らに天幕を張っていた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="詩篇 89:12; エレミヤ書 46:18; ヨシュア記 19:12"> 人々は、アビノアムの子バラクがタボル山に上ったことをシセラに告げた。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 4:2–3; 士師記 4:7"> シセラは、すべての戦車、すなわち九百両の鉄の戦車と、自分と一緒にいるすべての民を、異邦人のハロシェテからキション川へと呼び集めた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命記 9:3; サムエル記第二 5:24; イザヤ書 52:12"> デボラはバラクに言った。「立ち上がりなさい。今日こそ、主がシセラをあなたの手に渡される日です。主はあなたの前に出て行かれたではありませんか。」そこでバラクはタボル山から下り、一万人が彼に従った。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 10:10; 詩篇 83:9–10; 士師記 5:20–21"> 主はバラクの前で、シセラとそのすべての戦車、全軍勢を剣によって混乱に陥れられた。シセラは戦車から飛び降り、徒歩で逃げた。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 2:12; レビ記 26:7–8; ヤコブの手紙 2:13"> しかしバラクは戦車と軍勢を追って異邦人のハロシェテまで行き、シセラの全軍勢は剣の刃に倒れた。一人も残る者はなかった。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="詩篇 69:22; イザヤ書 57:21; アモス書 5:19–20"> しかしシセラは徒歩でケニ人ヘベルの妻ヤエルの天幕へ逃げ去った。ハツォルの王ヤビンとケニ人ヘベルの家との間には平和があったからである。</span>
<span className="v" id="v18" data-v="18" data-xref="列王記第二 6:19"> ヤエルはシセラを迎えに出て、彼に言った。「お入りください、ご主人様。私のところにお入りください。恐れることはありません。」そこで彼が彼女の天幕に入ると、彼女は彼を敷物で覆った。</span>
<span className="v" id="v19" data-v="19" data-xref="士師記 5:25–26; 創世記 24:43; イザヤ書 41:17"> 彼は彼女に言った。「どうか、私に少し水を飲ませてほしい。喉が渇いているのだ。」<br />彼女は乳の皮袋を開けて彼に飲ませ、彼を覆った。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨシュア記 2:3–5; サムエル記第二 17:20"> 彼は彼女に言った。「天幕の入り口に立っていてほしい。もしだれかが来てあなたに、『ここにだれかいるか』と尋ねたら、あなたは『いない』と言わなければならない。」</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 5:26–27; コリント人への第一の手紙 1:27; 士師記 3:21"> ヘベルの妻ヤエルは天幕の杭を取り、手に槌を持つと、音を立てずにシセラへ近づいた。そして杭をそのこめかみに打ち込み、地面まで突き通した。彼は疲れ果て、深く眠っていた。こうして彼は死んだ。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記第二 17:10–15; サムエル記第二 17:3"> 見よ、バラクがシセラを追って来たとき、ヤエルは彼を迎えに出て、彼に言った。「来なさい。あなたが探している男を見せましょう。」彼が彼女のところに入ると、見よ、シセラは死んで倒れており、そのこめかみには天幕の杭があった。</span>
<span className="v" id="v23" data-v="23" data-xref="ネヘミヤ記 9:24; 詩篇 18:47; 詩篇 18:39"> こうして神はその日、イスラエルの人々の前でカナンの王ヤビンを屈服させられた。</span>
<span className="v" id="v24" data-v="24" data-xref="サムエル記第一 3:12"> イスラエルの人々の勢力はカナンの王ヤビンに対してますます強くなり、ついに彼を滅ぼした。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 8:31; 詩篇 83:2–4; サムエル記第二 15:6"> エルバアルの子アビメレクは、シェケムにいる母の兄弟たちのところへ行き、彼らと母方の祖父の一族全体に言った。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 29:14; 士師記 8:30; ヘブル人への手紙 2:14"> 「どうか、シェケムのすべての有力者に尋ねてほしい。『エルバアルの息子七十人全員に治められるのと、一人に治められるのと、どちらがよいか。』私があなたがたの骨肉であることも思い出してほしい。」</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 29:15; 詩篇 10:3; 箴言 1:11–14"> 母の兄弟たちは、アビメレクについてのこれらの言葉をシェケムのすべての有力者に伝えた。彼らは「彼は私たちの兄弟だ」と言い、心をアビメレクに傾けた。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 8:33; 使徒の働き 17:5; 歴代誌 第二 13:7"> 彼らはバアル・ベリテの宮から彼に銀七十枚を与えた。アビメレクはそれで、軽薄で無頼な者たちを雇い、彼らは彼に従った。</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第二 11:1–2; 歴代誌 第二 21:4; 士師記 6:24"> 彼はオフラにある彼の父の家へ行き、エルバアルの息子たちである彼の兄弟七十人を一つの石の上で殺した。ただ、エルバアルの末の息子ヨタムだけは残った。彼が身を隠したからである。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記第二 5:9; 列王記第一 12:20; 列王記第二 12:20"> シェケムのすべての人々とミロの全家はともに集まり、行って、シェケムにある柱の樫の木のそばでアビメレクを王とした。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命記 11:29; ヨハネ 4:20; 申命記 27:12"> 人々がヨタムにそれを告げると、彼は行ってゲリジム山の頂に立ち、声を上げて叫び、彼らに言った。「わたしに聞き従いなさい、シェケムの人々よ。そうすれば神があなたがたに聞き従ってくださる。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 8:22–23; ダニエル書 4:10–18; 列王記第二 14:9"> 木々が自分たちの上に王を油注いで立てるために出かけて行った。彼らはオリーブの木に言った。『私たちを治めてくれ。』</span>
<span className="v" id="v9" data-v="9" data-xref="レビ記 2:1; 出エジプト記 29:7; 使徒の働き 4:27"> しかしオリーブの木は言った。『神と人を尊ぶために用いられる私の油を捨てて、木々の上を揺れ動きに行くというのか。』</span>
<span className="v" id="v10" data-v="10"> 木々はいちじくの木に言った。『来て、私たちを治めてくれ。』</span>
<span className="v" id="v11" data-v="11" data-xref="ルカ 13:6–7"> しかしいちじくの木は言った。『私の甘さと良い実を捨てて、木々の上を揺れ動きに行くというのか。』</span>
<span className="v" id="v12" data-v="12"> 木々はぶどうの木に言った。『来て、私たちを治めてくれ。』</span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 104:15; 伝道者の書 10:19; 民数記 15:5"> ぶどうの木は言った。『神と人を喜ばせる私の新しいぶどう酒を捨てて、木々の上を揺れ動きに行くというのか。』</span>
<span className="v" id="v14" data-v="14" data-xref="列王記第二 14:9"> そこで、すべての木々はいばらに言った。『来て、私たちを治めてくれ。』</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 30:2; 士師記 9:20; ホセア書 14:7"> いばらは木々に言った。『もし本当に、あなたがたがわたしを油注いであなたがたの王とするなら、来て、私の陰に身を避けなさい。そうでないなら、火がいばらから出て、レバノンの杉を焼き尽くすように。』</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="士師記 8:35"> それで今、あなたがたが真実と誠実をもってアビメレクを王としたのか、エルバアルとその家に善をなし、その手の働きにふさわしく報いたのか、考えてみよ。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 16:4; ローマ人への手紙 5:8; ヨハネの黙示録 12:11"> （私の父はあなたがたのために戦い、命を懸けて、ミディアンの手からあなたがたを救い出した。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 9:5–6; 士師記 8:30–31; 士師記 9:14"> なのにあなたがたは今日、私の父の家に逆らって立ち上がり、その息子たち七十人を一つの石の上で殺し、彼の女奴隷の息子であるアビメレクがあなたがたの兄弟であるという理由で、彼をシェケムの人々の王とした）、</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 8:6; ヤコブの手紙 4:16; ピリピ人への手紙 3:3"> もし今日、エルバアルとその家に真実と誠実をもって行ったのであれば、アビメレクを喜べ。彼もあなたがたを喜ぶがよい。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 9:15; 士師記 9:56–57; 歴代誌 第二 20:22–23"> しかしそうでないなら、アビメレクから火が出て、シェケムの人々とミロの家を焼き尽くし、またシェケムの人々とミロの家から火が出て、アビメレクを焼き尽くすように。」</span>
<span className="v" id="v21" data-v="21" data-xref="民数記 21:16; サムエル記第二 20:14; ヨシュア記 19:8"> 兄弟アビメレクを恐れたため、ヨタムは逃げ去り、ベエル<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「ベエル」はヘブル語で「井戸」を意味し、井戸にちなんで名づけられた村である。">a</a></sup>へ行ってそこに住んだ。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> アビメレクは三年の間、イスラエルを治めた。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 33:1; イザヤ書 19:14; イザヤ書 19:2"> 神はアビメレクとシェケムの人々との間に悪霊を送られた。シェケムの人々はアビメレクを裏切った。</span>
<span className="v" id="v24" data-v="24" data-xref="列王記第一 2:32; 詩篇 7:16; エステル記 9:25"> これは、エルバアルの七十人の息子に加えられた暴虐の報いが下り、その血の責任が、兄弟を殺したアビメレクと、兄弟たちを殺すために彼を助けたシェケムの人々に帰するためであった。</span>
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 8:12–13; 箴言 1:11–12; ヨシュア記 8:4"> シェケムの人々は彼のために、山々の頂に伏兵を置いた。彼らはその道をとおり過ぎるすべての者を略奪した。そしてそれはアビメレクに告げられた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="創世記 13:8; 創世記 19:7"> エベデの子ガアルが彼の兄弟たちとともに来て、シェケムへ渡って行った。シェケムの人々は彼を信頼した。</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 9:4; 士師記 9:46; 詩篇 109:17"> 彼らは野に出て自分たちのぶどう畑のぶどうを収穫し、それを踏んで祭りを催した。そして彼らの神の宮に入り、飲み食いしてアビメレクをのろった。</span>
<span className="v" id="v28" data-v="28" data-xref="創世記 34:2; 創世記 34:6; サムエル記第一 25:10"> エベデの子ガアルは言った。「アビメレクとは何者か。シェケムとは何者か。なぜ私たちが彼に仕えるのか。彼はエルバアルの子、ゼブルはその役人ではないか。シェケムの父ハモルの一族に仕えよ。なぜ私たちがアビメレクに仕えるのか。</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記第二 15:4; サムエル記第二 2:14–17; イザヤ書 36:8–9"> この民が私の手の下にあれば、私はアビメレクを追い払うのに。」そしてアビメレクに向かって、「軍勢を増やして出て来い」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 町の長官であるゼブルは、エベデの子ガアルの言葉を聞いて怒りを燃やした。</span>
<span className="v" id="v31" data-v="31"> 彼はひそかに使者をアビメレクに送り、こう言わせた。「エベデの子ガアルとその兄弟たちがシェケムに来て、町をあなたに逆らわせようとしています。</span>
<span className="v" id="v32" data-v="32" data-xref="ローマ人への手紙 3:15; 詩篇 36:4; 箴言 1:11–16"> それゆえ今、あなたと、あなたと一緒にいる民は夜の間に起き上がり、野で待ち伏せしなさい。</span>
<span className="v" id="v33" data-v="33" data-xref="サムエル記第一 10:7; 伝道者の書 9:10; レビ記 25:26"> 朝、日が昇るとすぐに起き、町を襲ってください。ガアルと彼とともにいる民が出て来たら、機を見て彼らを攻めてください。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> そこでアビメレクと、彼と一緒にいたすべての民は夜の間に起き上がり、四つの部隊に分かれてシェケムに向かって待ち伏せした。</span>
<span className="v" id="v35" data-v="35"> エベデの子ガアルが出て来て、町の門の入り口に立った。アビメレクと、彼と一緒にいた民は待ち伏せから起き上がった。</span>
<span className="v" id="v36" data-v="36" data-xref="マルコ 8:24; エゼキエル書 7:7"> ガアルがその民を見たとき、彼はゼブルに言った。「見よ。民が山々の頂から下って来る。」<br />ゼブルは彼に言った。「あなたは山々の影を人だと思っているのだ。」</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 18:14"> ガアルは再び言った。「見よ。民が地の中央から下って来る。また一つの部隊がメオネニムの樫の木の道を通って来る。」</span>
<span className="v" id="v38" data-v="38" data-xref="士師記 9:28–29; 列王記第二 14:8–14; サムエル記第二 2:26–27"> するとゼブルは彼に言った。「『私たちが彼に仕えなければならないとは、アビメレクとは何者か』と言ったあなたの口は、今どこにあるのか。これが、あなたの軽蔑した民ではないか。さあ、今出て行って彼らと戦え。」</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39"> そこでガアルはシェケムの人々の前に立って出て行き、アビメレクと戦った。</span>
<span className="v" id="v40" data-v="40" data-xref="列王記第一 20:18–21; 列王記第一 20:30"> アビメレクは彼を追撃し、彼は彼から逃げた。そして多くの者が傷ついて倒れ、門の入り口にまで及んだ。</span>
<span className="v" id="v41" data-v="41" data-xref="士師記 9:28; 士師記 9:30"> アビメレクはアルマに留まった。ゼブルはガアルとその兄弟たちを追い出し、シェケムに住むことができないようにした。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> 翌日になって、民は野に出て行った。人々はそれをアビメレクに告げた。</span>
<span className="v" id="v43" data-v="43"> アビメレクは民を三隊に分け、野に伏せた。町から民が出て来るのを見ると、立ち上がって彼らを打った。</span>
<span className="v" id="v44" data-v="44" data-xref="ガラテヤ人への手紙 5:15; 士師記 9:15; 士師記 9:20"> アビメレクと、彼と一緒にいた部隊は突進し、町の門の入り口に立った。他の二つの部隊は野にいるすべての者に向かって突進し、彼らを打ち倒した。</span>
<span className="v" id="v45" data-v="45" data-xref="列王記第二 3:25; 申命記 29:23; ヤコブの手紙 2:13"> アビメレクはその日一日中、町と戦った。彼は町を攻め取り、その中にいた民を殺した。彼は町を打ち壊し、そこに塩を蒔いた。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="士師記 8:33; 士師記 9:4; 列王記第一 8:26"> シェケムの塔のすべての人々がそれを聞いたとき、彼らはエル・ベリテの宮の要害に入った。</span>
<span className="v" id="v47" data-v="47"> シェケムの塔のすべての人々が集まっていることが、アビメレクに告げられた。</span>
<span className="v" id="v48" data-v="48" data-xref="詩篇 68:14; 箴言 1:11–12; 士師記 7:17–18"> アビメレクは、自分とともにいた民を率いてツァルモン山へ上った。彼は斧を手に取り、木の枝を切って肩に担ぎ、民に言った。「私がしたことを見ただろう。急いで同じようにせよ。」</span>
<span className="v" id="v49" data-v="49" data-xref="ガラテヤ人への手紙 5:15; ヤコブの手紙 3:16; 士師記 9:20"> そこで民も皆、おのおの自分の枝を切り落とし、アビメレクに従い、それらを要害の上に置き、彼らの上の要害に火を放った。こうしてシェケムの塔のすべての人々もまた死んだ。男女約千人であった。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50"> その後、アビメレクはテベツへ行き、テベツに向かって陣を敷き、これを攻め取った。</span>
<span className="v" id="v51" data-v="51"> しかし町の中には強固な塔があり、町のすべての男女がそこへ逃げ込み、内側から鍵をかけ、塔の屋根に上った。</span>
<span className="v" id="v52" data-v="52" data-xref="士師記 9:48–49; 列王記第二 14:10; 列王記第二 15:16"> アビメレクは塔に来てそれと戦い、火でそれを燃やそうと塔の戸に近づいた。</span>
<span className="v" id="v53" data-v="53" data-xref="サムエル記第二 11:21; ヨブ記 31:3; エレミヤ書 49:20"> すると一人の女がアビメレクの頭の上にひき臼の上石を投げ落とし、彼の頭蓋骨を砕いた。</span>
<span className="v" id="v54" data-v="54" data-xref="サムエル記第一 31:4–5"> 彼は急いで武具を持つ若者を呼び、「剣を抜いて私を殺せ。『女に殺された』と言われないためだ」と言った。若者が彼を刺し貫き、彼は死んだ。</span>
<span className="v" id="v55" data-v="55" data-xref="サムエル記第二 18:16; サムエル記第二 20:21–22; 列王記第一 22:35–36"> イスラエルの人々はアビメレクが死んだのを見て、それぞれ自分の場所へ去って行った。</span>
</div>
<div className="bp">
<span className="v" id="v56" data-v="56" data-xref="詩篇 94:23; 士師記 9:24; 箴言 5:22"> このように神は、アビメレクが七十人の兄弟を殺して自分の父に対して行った悪に報いられた。</span>
<span className="v" id="v57" data-v="57" data-xref="士師記 9:20; ヨシュア記 6:26; 列王記第一 16:34"> 神はまた、シェケムの人々のすべての悪を彼らの頭上に報いられた。そして、エルバアルの子ヨタムののろいが彼らに臨んだ。</span>
</div>

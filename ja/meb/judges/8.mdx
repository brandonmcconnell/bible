<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記第二 19:41; 士師記 12:1–6; ヨブ記 5:2"> エフライムの人々はギデオンに言った。「ミディアンと戦いに行くとき、なぜ私たちを呼ばなかったのか。どうしてこのような扱いをしたのか。」彼らは激しく彼を責めた。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第一の手紙 13:4–7; ピリピ人への手紙 2:2–3; ヤコブの手紙 3:13–18"> 彼は彼らに言った。「今私がしたことは、あなたがたに比べれば何だろうか。エフライムのぶどうの落ち穂拾いは、アビエゼルのぶどうの収穫にまさるではないか。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 15:1; 士師記 7:24–25; ヨハネ 4:37"> 神はミディアンの君主オレブとゼエブを、あなたがたの手に渡された。あなたがたに比べて、私に何ができただろう。」彼がこう言うと、彼らの怒りは和らいだ。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ガラテヤ人への手紙 6:9; コリント人への第二の手紙 4:16; サムエル記第一 14:28–29"> ギデオンと、彼とともにいた三百人はヨルダン川に着いて渡った。彼らは疲れ果てていたが、なお追撃を続けた。</span>
<span className="v" id="v5" data-v="5" data-xref="創世記 33:17; 詩篇 60:6; サムエル記第一 25:18"> 彼はスコテの人々に言った。「どうか、私について来ている民にパンのかたまりを与えてほしい。彼らは疲れ果てており、私はミディアンの王たち、ゼバとツァルムナの後を追撃しているからだ。」</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第一 20:11; ピリピ人への手紙 2:21; 箴言 18:23"> スコテの君主たちは言った。「ゼバとツァルムナをすでに捕らえたとでもいうのか。なぜ私たちがあなたの軍勢にパンを与えなければならないのか。」</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 7:15"> ギデオンは言った。「それゆえ、主がゼバとツァルムナを私の手に渡されたとき、私は荒野のいばらと野ばらであなたがたの肉を裂く。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="創世記 32:30–31; 列王記第一 12:25"> 彼はそこからペヌエルへ上って行き、彼らにも同じように語った。ペヌエルの人々も、スコテの人々が答えたのと同じように彼に答えた。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 8:17; 列王記第一 22:27–28"> 彼はペヌエルの人々にも語って、「私が無事に帰って来るとき、この塔を打ち壊す」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="士師記 7:12; 士師記 20:25; 士師記 20:2"> ゼバとツァルムナはカルコルにおり、その軍勢約一万五千人もともにいた。東の人々の全軍勢で生き残った者たちである。剣を取る者十二万人はすでに倒れていた。</span>
<span className="v" id="v11" data-v="11" data-xref="民数記 32:35; 民数記 32:42; 士師記 18:27"> ギデオンはノバとヨグベハの東、天幕に住む者たちの道を通って上り、油断していた軍勢を打った。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 83:11; アモス書 2:14; ヨブ記 12:16–21"> ゼバとツァルムナは逃げたが、彼は彼らを追撃した。彼はミディアンの二人の王、ゼバとツァルムナを捕らえ、全軍勢を混乱に陥れた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> ヨアシュの子ギデオンは、ヘレスの坂道を通って戦いから帰って来た。</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 1:24–25; サムエル記第一 30:11–15"> 彼はスコテの人々のうちの一人の若者を捕らえて尋問した。その若者は彼のために、スコテの君主たちと長老たち、七十七人の名を書き記した。</span>
<span className="v" id="v15" data-v="15" data-xref="士師記 8:6–7"> 彼はスコテの人々のところへ来て言った。「ここにゼバとツァルムナがいる。あなたがたはこの二人のことで私をあざけり、『ゼバとツァルムナをすでに捕らえたとでもいうのか。なぜ疲れたあなたの兵にパンを与えなければならないのか』と言った。」</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 8:7; エズラ記 2:6; 箴言 10:13"> 彼は町の長老たちを捕らえ、荒野のいばらと茨を用いて、スコテの人々を懲らしめた。</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 8:9; 列王記第一 12:25"> また彼はペヌエルの塔を打ち壊し、その町の人々を殺した。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="士師記 4:6; ユダ 1:16; 詩篇 89:12"> それから彼はゼバとツァルムナに言った。「おまえたちがタボルで殺した者たちは、どのような男たちであったか。」<br />彼らは答えた。「彼らはあなたのようでした。一人一人が王の子のようでした。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 彼は言った。「彼らは私の兄弟であり、私の母の息子たちであった。主は生きておられる。もしおまえたちが彼らを生かしておいてくれたなら、私はおまえたちを殺しはしない。」</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 149:9; サムエル記第一 15:33; ヨシュア記 10:24"> 彼は長子エテルに「立って、彼らを殺せ」と言った。しかし若者は剣を抜かなかった。彼はまだ若かったため、恐れたのである。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 83:11; 士師記 8:26; イザヤ書 3:18"> ゼバとツァルムナは言った。「あなた自身が立って、私たちを打て。人の力はその人にふさわしいものだ。」ギデオンは立ち上がって二人を殺し、らくだの首にあった三日月形の飾りを取った。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ヨハネ 6:15; 士師記 9:8–15; サムエル記第一 12:12"> その後、イスラエルの人々はギデオンに言った。「あなたも、あなたの子も、あなたの孫も私たちを治めてください。あなたが私たちをミディアンの手から救い出してくださったからです。」</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 33:22; サムエル記第一 12:12; サムエル記第一 10:19"> ギデオンは彼らに言った。「私はあなたがたを治めない。私の子もあなたがたを治めない。主があなたがたを治められる。」</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 25:13; 創世記 37:25; 創世記 37:28"> ギデオンはさらに言った。「あなたがたに一つ願いがある。それぞれ分捕り品の耳輪を私に与えてほしい。」彼らはイシュマエル人だったので、金の耳輪を身につけていた。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 彼らは答えた。「喜んで差し上げます。」彼らが上着を広げると、それぞれが分捕り品の中から耳輪をそこに投げ入れた。</span>
<span className="v" id="v26" data-v="26" data-xref="ヨハネの黙示録 18:16; ヨハネ 19:2; ヨハネの黙示録 18:12"> 彼が求めた金の耳輪の重さは、金一千七百シェケル<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一シェケルは約10グラム、あるいは約0.32トロイオンスである。一千七百シェケルは約17キログラム、または37.4ポンドである。">a</a></sup>であった。このほかに、三日月形の飾り、耳飾り、ミディアンの王たちが着ていた紫の衣、らくだの首の鎖があった。</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 17:5; 士師記 18:14; 詩篇 106:39"> ギデオンはその金でエポデを作り、自分の町オフラに置いた。全イスラエルはそこでそれを慕って淫行にふけった。それはギデオンとその家にとって罠となった。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="士師記 5:31; 士師記 3:11; 士師記 3:30"> こうしてミディアンはイスラエルの人々の前に屈し、二度と頭を上げなかった。ギデオンの時代、その地には四十年の間、平穏があった。</span>
<span className="v" id="v29" data-v="29" data-xref="士師記 6:32; 士師記 7:1; サムエル記第一 12:11"> ヨアシュの子エルバアルは行って、自分の家に住んだ。</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 9:5; 士師記 9:2; 列王記第一 11:3"> ギデオンには、自分の身から生まれた息子が七十人いた。多くの妻を持っていたからである。</span>
<span className="v" id="v31" data-v="31" data-xref="士師記 9:18; 創世記 22:24; 創世記 16:15"> シェケムにいた彼のそばめも彼に男の子を産み、彼はその子をアビメレクと名付けた。</span>
<span className="v" id="v32" data-v="32" data-xref="創世記 25:8; 士師記 6:24; ヨブ記 5:26"> ヨアシュの子ギデオンは長寿を全うして死に、アビエゼル人のオフラにある、彼の父ヨアシュの墓に葬られた。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="士師記 9:46; 士師記 2:19; 士師記 9:4"> ギデオンが死ぬと、イスラエルの人々は再びバアルの神々を追って淫行にふけり、バアル・ベリテを自分たちの神とした。</span>
<span className="v" id="v34" data-v="34" data-xref="詩篇 78:42; 詩篇 106:21; 詩篇 78:11"> イスラエルの人々は、周囲のすべての敵の手から自分たちを救い出してくださった自分たちの神、主を思い出さなかった。</span>
<span className="v" id="v35" data-v="35" data-xref="伝道者の書 9:14–15; 士師記 9:5; 士師記 9:16–19"> また彼らは、ギデオンすなわちエルバアルの家に対し、彼がイスラエルに示したすべての良いことに応じて慈しみを示すこともなかった。</span>
</div>

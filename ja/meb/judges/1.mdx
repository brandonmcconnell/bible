<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 20:18; 民数記 27:21; 士師記 20:28"> ヨシュアの死後、イスラエルの人々は主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="すべて大文字の「主」または「神」はヘブル語のיהוה（ヤハウェ）から来ている。ただし、短い形のיה（ヤハ）から来ていると記されている場合を除く。">a</a></sup>に尋ねた。「カナン人と戦うため、私たちのうちだれが最初に上るべきでしょうか。」</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 5:5; ヘブル人への手紙 7:14; 民数記 2:3"> 主は言われた。「ユダが上れ。見よ、<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「見よ」はヘブル語の「הִנֵּה」に由来し、「見なさい」「注意せよ」「よく見よ」などの意味を持つ。しばしば間投詞として用いられる。">b</a></sup>わたしはその地をユダの手に渡した。」</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記第二 10:11; ヨシュア記 19:1; 士師記 1:17"> ユダは兄弟シメオンに言った。「私とともに、くじで私に割り当てられた地へ上り、カナン人と戦ってほしい。私も、くじであなたに割り当てられた地へともに行こう。」そこでシメオンは彼とともに行った。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記第一 11:8; 出エジプト記 23:28–29; ヨシュア記 11:6–8"> ユダは上って行った。主はカナン人とペリジ人を彼らの手に渡された。彼らはベゼクで一万人を打ち倒した。</span>
<span className="v" id="v5" data-v="5"> 彼らはベゼクでアドニ・ベゼクを見つけ、彼と戦い、カナン人とペリジ人を打ち倒した。</span>
<span className="v" id="v6" data-v="6"> アドニ・ベゼクは逃げたが、彼らはその後を追って彼を捕らえ、その手の親指と足の親指を切り落とした。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記第一 15:33; ヨハネの黙示録 13:10; ルカ 6:37–38"> アドニ・ベゼクは言った。「手の親指と足の親指を切り落とされた七十人の王が、私の食卓の下で食べ物を拾っていた。私がしたとおりに、神<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「神」と訳されたヘブル語は「אֱלֹהִים」（エロヒム）である。">c</a></sup>は私に報いられた。」人々は彼をエルサレムに連れて行き、彼はそこで死んだ。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 15:63; 士師記 1:21"> ユダの子らはエルサレムと戦ってこれを攻め取り、剣の刃でそれを打ち、町に火を放った。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 15:13–20; ヨシュア記 11:21; ヨシュア記 10:36"> その後、ユダの子らは山地、南の地、および低地に住むカナン人と戦うために下って行った。</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 13:22; ヨシュア記 14:15; エレミヤ書 9:23"> ユダはヘブロンに住むカナン人に向かって行った。（なお、ヘブロンの以前の名はキルヤテ・アルバであった。）そして彼らはシェシャイ、アヒマン、タルマイを打ち倒した。</span>
<span className="v" id="v11" data-v="11" data-xref="ヨシュア記 15:15; ヨシュア記 10:38–39"> そこから彼はデビルの住民に向かって行った。（なお、デビルの以前の名はキルヤテ・セフェルであった。）</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 15:16–17; サムエル記第一 17:25; サムエル記第一 18:23"> カレブは言った。「キルヤテ・セフェルを打ってこれを攻め取る者には、私の娘アクサを妻として与えよう。」</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 3:9"> カレブの弟であるケナズの子オトニエルがそれを攻め取ったので、カレブは彼に娘アクサを妻として与えた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 15:18–19"> 彼女が彼のもとに来たとき、彼女は父に畑を求めるよう彼に促した。彼女がろばから降りると、カレブは彼女に言った。「何が欲しいのか。」</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記第一 25:18; コリント人への第二の手紙 9:5; ペテロの手紙第一 3:9"> 彼女は言った。「どうか私を祝福してください。あなたは私を南の地に嫁がせたのですから、水の泉も与えてください。」そこでカレブは、上の泉と下の泉を彼女に与えた。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数記 10:29–32; 士師記 4:11; サムエル記第一 15:6"> モーセの義理の兄弟であるケニ人の子らは、ユダの子らと一緒に、なつめやしの町からアラドの南にあるユダの荒野に上って行った。そして彼らは行って、その民とともに住んだ。</span>
<span className="v" id="v17" data-v="17" data-xref="民数記 21:3; 士師記 1:3; ヨシュア記 19:4"> ユダは兄弟のシメオンと一緒に行き、ゼファテに住むカナン人を打ち倒し、そこを完全に滅ぼした。その町の名はホルマと呼ばれた。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 11:22; 士師記 3:3; ヨシュア記 15:45–47"> またユダは、その領域とともにガザを、その領域とともにアシュケロンを、その領域とともにエクロンを攻め取った。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 41:10; 士師記 1:2; 詩篇 60:12"> 主はユダとともにおられ、ユダは山地の住民を追い出した。しかし谷の住民は鉄の戦車を持っていたので、追い出すことができなかった。</span>
<span className="v" id="v20" data-v="20" data-xref="士師記 1:10; ヨシュア記 15:13–14; 民数記 14:24"> モーセが語っていたとおりに、人々はカレブにヘブロンを与えた。彼はそこからアナクの三人の息子を追い出した。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨシュア記 15:63; 士師記 19:10–12; 士師記 1:8"> ベニヤミンの子らはエルサレムに住んでいたエブス人を追い出さなかった。そのため、エブス人は今日に至るまでエルサレムでベニヤミンの子らとともに住んでいる。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="士師記 1:19; 列王記第二 18:7; 民数記 1:32"> ヨセフの家もまた、ベテルに向かって上って行った。主は彼らとともにおられた。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 28:19; 創世記 35:6; 創世記 48:3"> ヨセフの家はベテルを偵察させた。（なお、その町の以前の名はルズであった。）</span>
<span className="v" id="v24" data-v="24" data-xref="ヨシュア記 2:12–14; サムエル記第一 30:15"> 見張り人たちは、一人の男が町から出て来るのを見て、彼に言った。「どうか、町の入り口を私たちに教えてほしい。そうすれば、私たちはあなたに親切にしよう。」</span>
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 6:22–25"> 彼が町の入り口を教えたので、彼らは剣の刃で町を打ち倒したが、その男と彼のすべての家族は逃がした。</span>
<span className="v" id="v26" data-v="26" data-xref="列王記第二 7:6; 歴代誌 第二 1:17"> その男はヘト人の地に行き、町を建ててその名をルズと呼んだ。それが今日に至るまでその名である。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 17:11–13; エレミヤ書 48:10; 詩篇 106:34–35"> マナセは、ベテ・シェアンとその周辺の町々、タアナクとその周辺の町々、ドルとその周辺の町々、イブレアムとその周辺の町々、メギドとその周辺の町々の住民を追い出さなかった。カナン人はその地に住み続けた。</span>
<span className="v" id="v28" data-v="28"> イスラエルが強くなったとき、彼らはカナン人を強制労働に就かせたが、彼らを完全に追い出すことはしなかった。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 16:10; 列王記第一 9:16"> エフライムはゲゼルに住んでいたカナン人を追い出さなかった。そのため、カナン人はゲゼルで彼らの間に住んだ。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨシュア記 19:15"> ゼブルンはキトロンの住民もナハラルの住民も追い出さなかった。そのため、カナン人は彼らの間に住み、強制労働に服するようになった。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨシュア記 19:24–30"> アシェルはアッコの住民、シドンの住民、アフラブ、アクジブ、ヘルバ、アフィク、およびレホブの住民を追い出さなかった。</span>
<span className="v" id="v32" data-v="32" data-xref="詩篇 106:34–35"> アシェル人はその地の住民であるカナン人を追い出さず、彼らの間に住んだ。</span>
<span className="v" id="v33" data-v="33" data-xref="ヨシュア記 19:32–38; 士師記 1:30; 詩篇 18:24"> ナフタリはベテ・シェメシュの住民もベテ・アナテの住民も追い出さず、その地の住民であるカナン人の間に住んだ。それでも、ベテ・シェメシュとベテ・アナテの住民は彼らのために強制労働に服するようになった。</span>
<span className="v" id="v34" data-v="34" data-xref="ヨシュア記 19:47; 士師記 18:1"> アモリ人はダンの子らを山地に押し込め、谷へ下りることを許さなかった。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨシュア記 19:42; 士師記 12:12; ヨシュア記 10:12"> アモリ人はヘレス山、アヤロン、シャアルビムに住み続けた。しかしヨセフの家の勢力が強くなると、彼らは強制労働に服した。</span>
<span className="v" id="v36" data-v="36" data-xref="民数記 34:4; ヨシュア記 15:2–3"> アモリ人の境界は、アクラビムの坂、すなわち岩から上であった。</span>
</div>

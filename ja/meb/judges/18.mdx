<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 17:6; 士師記 19:1; 士師記 1:34"> その頃、イスラエルには王がなかった。ダン人の部族は住むべき相続地を探していた。その日まで、イスラエルの諸部族の中で、彼らには相続地が割り当てられていなかった。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 13:25; ヨシュア記 2:1; 士師記 18:11"> ダンの子らは、その地を偵察して探るために、全数の中から自分たちの氏族の五人の男、すなわちツォルアとエシュタオルから勇士たちを遣わした。彼らは彼らに、「行ってその地を探れ」と言った。<br />彼らはエフライムの山地にあるミカの家に来て、そこに泊まった。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 12:6; 創世記 27:22; マタイ 26:73"> 彼らはミカの家の近くに来ると、若いレビ人の声に気づいた。そこへ立ち寄って尋ねた。「だれがあなたをここへ連れて来たのか。ここで何をしているのか。ここにどんな用があるのか。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士師記 17:10; エゼキエル書 13:19; 箴言 28:21"> 彼は彼らに言った。「ミカは私にこれこれの事をしてくれました。彼は私を雇い、私は彼の祭司なのです。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒の働き 8:10; イザヤ書 30:1; 列王記第一 22:5"> 彼らは彼に言った。「どうか神に伺って、私たちが歩んでいる道が栄えるかどうか、私たちに知らせてほしい。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王記第一 22:6; 列王記第一 22:15; 詩篇 33:18"> 祭司は言った。「安心して行きなさい。あなたがたの行く道は主の御前にあります。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 19:47; 士師記 18:27–28; サムエル記第一 3:13"> 五人は出発してライシュへ行った。そこに住む民は、シドン人のように穏やかで安心し、安全に暮らしていた。その地には彼らを何事にも辱める支配者がおらず、シドン人から遠く離れ、ほかのだれとも関わりを持っていなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 18:11; 士師記 18:2; 士師記 13:2"> 彼らがツォルアとエシュタオルにいる兄弟たちのところに帰って来ると、兄弟たちは彼らに言った。「あなたがたは何と報告するのか。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 2:23–24; 民数記 13:30; ヨシュア記 18:3"> 彼らは言った。「さあ、彼らに向かって上ろう。私たちはその地を見た。実に非常に良い。なぜ黙っているのか。ためらわずに進み、その地に入って所有せよ。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 18:27; 士師記 18:7; 申命記 2:29"> 行けば、警戒していない民と、広々とした地に着く。神がその地をあなたがたの手に渡された。そこには地にあるものが何一つ欠けていない。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="士師記 18:16"> そこでダン人の氏族のうち六百人の男が、戦いの武器を身に帯びて、ツォルアとエシュタオルから出発した。</span>
<span className="v" id="v12" data-v="12" data-xref="士師記 13:25; ヨシュア記 15:60; 歴代誌 第二 1:4"> 彼らは上り、ユダのキルヤテ・ヤアリムに陣を敷いた。それで、その場所は今日までマハネ・ダンと呼ばれている。それはキルヤテ・ヤアリムの西にある。</span>
<span className="v" id="v13" data-v="13" data-xref="ヨシュア記 24:30; 士師記 19:1; 士師記 18:2–3"> 彼らはそこからエフライムの山地に進み、ミカの家に来た。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="士師記 17:5; 士師記 18:3–4; サムエル記第一 14:28"> ライシュの地方を偵察した五人は、兄弟たちに言った。「この家々に、エポデ、テラフィム<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="テラフィムは家の神々で、家の財産の相続権と関係していた可能性がある。">a</a></sup>、彫像、鋳像があるのを知っているか。何をすべきか、よく考えよ。」</span>
<span className="v" id="v15" data-v="15" data-xref="創世記 43:27; サムエル記第一 17:22; ヨハネ 14:27"> 彼らはそこへ立ち寄り、レビ人の若者の家、すなわちミカの家に来て、彼に安否を尋ねた。</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 18:11"> ダンの子らである、戦いの武器を身に帯びた六百人の男たちは、町の門のそばに立っていた。</span>
<span className="v" id="v17" data-v="17" data-xref="士師記 18:14; 士師記 17:4–5; 士師記 18:2"> その地を偵察に行った五人の男が上って来て中に入り、彫像、エポデ、テラフィム、および鋳像を取った。その間、祭司は戦いの武器を身に帯びた六百人の男たちとともに町の門のそばに立っていた。</span>
<span className="v" id="v18" data-v="18"> これらがミカの家に入り、彫像、エポデ、テラフィム、および鋳像を取り出したとき、祭司は彼らに言った。「あなたがたは何をしているのか。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨブ記 29:9; ヨブ記 21:5; 士師記 17:10"> 彼らは彼に言った。「黙れ。口に手を当てて、私たちとともに行き、私たちのために父となり、祭司となれ。あなたにとって、一人の男の家の祭司となるのと、イスラエルの部族と氏族の祭司となるのとでは、どちらが良いか。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 56:11; エゼキエル書 13:19; 箴言 30:15"> 祭司の心は喜び、彼はエポデ、テラフィム、および彫像を取り、民の中に入って行った。</span>
<span className="v" id="v21" data-v="21"> こうして彼らは向きを変えて出発し、子供たち、家畜、および財産を自分たちの前に置いた。</span>
<span className="v" id="v22" data-v="22"> 彼らがミカの家からかなり遠ざかったとき、ミカの家の近くにある家々の男たちが呼び集められ、ダンの子らに追いついた。</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 114:5; サムエル記第二 14:5; サムエル記第一 11:5"> 彼らがダンの子らに向かって叫ぶと、ダンの子らは振り向いてミカに言った。「どうしたのか。なぜこれほど大勢を集めて来たのか。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ハバクク書 2:18–19; イザヤ書 44:18–20; 詩篇 115:8"> 彼は言った。「あなたがたは私が造った私の神々と、祭司を奪って去って行った。私に何が残っているのか。それなのに、あなたがたはどうして私に『一体どうしたというのか』と言えるのか。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ヨブ記 27:2; ヨブ記 3:5; サムエル記第一 30:6"> ダンの子らは言った。「私たちの間で声を上げるな。気の荒い者たちがおまえたちを襲い、おまえも家族も命を失うことになる。」</span>
<span className="v" id="v26" data-v="26"> ダンの子らは自分たちの道を行き、ミカは彼らが自分より強すぎるのを見て、向きを変えて自分の家に帰って行った。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ヨシュア記 19:47; 士師記 18:7; 士師記 18:10"> 彼らはミカが造ったものと、その祭司を奪い、穏やかで警戒していないライシュの民のところへ行った。彼らを剣で打ち、町を火で焼いた。</span>
<span className="v" id="v28" data-v="28" data-xref="サムエル記第二 10:6; 士師記 18:7; 民数記 13:21"> 救い出す者はいなかった。町はシドンから遠く、住民はほかのだれとも関わりを持っていなかったからである。町はベテ・レホブに近い谷にあった。ダン人は町を建て直して住んだ。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 19:47; 創世記 14:14; 列王記第一 15:20"> 彼らはその町の名を、イスラエルに生まれた自分たちの父ダンの名にちなんでダンと呼んだ。ただし、その町の最初の名はライシュであった。</span>
<span className="v" id="v30" data-v="30" data-xref="サムエル記第一 4:10–11; 士師記 13:1; 士師記 17:5"> ダンの子らは自分たちのためにその彫像を立てた。そしてモーセの子ゲルショムの子ヨナタン、彼とその子らは、その地が捕囚となる日までダン人の部族の祭司であった。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨシュア記 18:1; サムエル記第一 1:3; 士師記 19:18"> 彼らは、神の家がシロにあった間ずっと、ミカが造った彫像を自分たちのために立てていた。</span>
</div>

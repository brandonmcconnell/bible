<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="サムエル記第一 12:9; 士師記 6:1; ローマ人への手紙 2:6"> イスラエルの人々は再び主の目に悪を行った。主は彼らを四十年の間、ペリシテ人の手に渡された。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨシュア記 19:41; ルカ 1:7; ヨシュア記 15:33"> ツォルアのダン人の氏族に、マノアという名の一人の男がいた。彼の妻は不妊の女であり、子がなかった。</span>
<span className="v" id="v3" data-v="3" data-xref="ルカ 1:13; ルカ 1:11; 士師記 6:11–12"> 主の使いがその女に現れて言った。「あなたは不妊で、子を産んだことがない。だが、あなたは身ごもり、男の子を産む。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカ 1:15; 士師記 13:14; 民数記 6:2–3"> それゆえ今、どうか気をつけて、ぶどう酒や強い酒を飲まないようにし、どんな汚れたものも食べないようにしなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="民数記 6:5; サムエル記第一 1:11; 歴代誌上 18:1"> あなたは身ごもり、男の子を産む。その頭にかみそりを当ててはならない。その子は胎内にいる時から神にささげられたナジル人となる。彼はペリシテ人の手からイスラエルを救い始める。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="士師記 13:17–18; サムエル記第一 9:6; マタイ 28:3–4"> 女は夫のところへ来て告げた。「神の人が私のところに来られました。そのお姿は神の使いのようで、非常に畏れを起こさせるものでした。私は彼がどこから来られたのかお尋ねせず、彼もご自分の名を私に教えてはくださいませんでした。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 13:4"> ただ、こう言われました。『あなたは身ごもり、男の子を産む。今からぶどう酒も強い酒も飲まず、汚れたものを何も食べてはならない。その子は胎内にいる時から死ぬ日まで、神にささげられたナジル人となる。』」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒の働き 9:6; ヨブ記 34:32; 箴言 3:5–6"> マノアは主に願った。「ああ、主よ。どうか、あなたが遣わされた神の人をもう一度私たちのところへ来させ、生まれる子に何をすべきか教えさせてください。」</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 65:2; マタイ 7:7–11"> 神はマノアの声に聞き入れられた。神の使いは、女が野に座っていたとき、再び女のところに来た。しかし彼女の夫マノアは彼女とともにいなかった。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネ 4:28–29; ヨハネ 1:41–42"> 女は急いで走り、夫に告げた。「あの日、私のところに来られた方が、また現れました。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> マノアは立ち上がって妻の後について行き、その人のところに来て彼に言った。「あなたはあの女と話した方ですか。」<br />彼は言った。「私である。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="箴言 22:6; エペソ人への手紙 6:4; 創世記 18:19"> マノアは言った。「あなたの言葉が実現するとき、その子はどのように生き、何をすべきでしょうか。」</span>
<span className="v" id="v13" data-v="13"> 主の使いはマノアに言った。「私が女に言ったすべてのことについて、彼女は気をつけなければならない。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨハネ 2:5; 士師記 13:4; テサロニケ人への第二の手紙 3:4"> 彼女はぶどうの木から生じるものを一切食べてはならず、ぶどう酒や強い酒を飲んでもならず、またどんな汚れたものも食べてはならない。私が彼女に命じたすべてのことを、彼女は守らなければならない。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士師記 6:18–19; 創世記 18:3–5; 士師記 13:3"> マノアは主の使いに言った。「どうか、私たちがあなたを引き留めて、あなたのために子やぎ一匹を用意させてください。」</span>
<span className="v" id="v16" data-v="16" data-xref="士師記 13:23; 士師記 6:20; 士師記 6:26"> 主の使いはマノアに言った。「あなたが私を引き留めても、私はあなたの食物を食べない。全焼のささげ物を用意するなら、主にささげなさい。」マノアは、その方が主の使いであるとは知らなかった。</span>
<span className="v" id="v17" data-v="17" data-xref="創世記 32:29"> マノアは主の使いに言った。「あなたの名は何といいますか。あなたの言葉が実現したとき、私たちがあなたをあがめるためです。」</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 32:29; イザヤ書 9:6; 士師記 13:6"> 主の使いは言った。「なぜ私の名を尋ねるのか。それは理解を超えている。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="あるいは、「不思議である」。">a</a></sup>」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="士師記 6:19–21; 列王記第一 18:30–38"> そこでマノアは子やぎと穀物のささげ物を取り、それを岩の上で主にささげた。すると、マノアとその妻が見ている間に、使いは不思議なことを行った。</span>
<span className="v" id="v20" data-v="20" data-xref="レビ記 9:24; 歴代誌上 21:16; 列王記第二 2:11"> 祭壇から天に向かって炎が上ったとき、主の使いが祭壇の炎の中を上って行ったのである。マノアとその妻はそれを見て、地にひれ伏した。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 6:22; ホセア書 12:4–5; 士師記 13:16"> しかし主の使いは、マノアやその妻に二度と現れなかった。そのときマノアは、彼が主の使いであったことを知った。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 32:30; 申命記 5:26; ヨハネ 1:18"> マノアは妻に言った。「私たちは神を見てしまったので、間違いなく死ぬだろう。」</span>
<span className="v" id="v23" data-v="23" data-xref="詩篇 25:14; コリント人への第一の手紙 12:21; ヨハネ 15:15"> 妻は言った。「もし主が私たちを殺そうと望んでおられたなら、私たちの手から全焼のささげ物と穀物のささげ物を受け取られず、これらすべてを見せることも、今このようなことを告げることもなさらなかったでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ルカ 1:80; サムエル記第一 3:19; ヘブル人への手紙 11:32"> 女は男の子を産み、彼をサムソンと名付けた。その子は成長し、主は彼を祝福された。</span>
<span className="v" id="v25" data-v="25" data-xref="士師記 3:10; ヨシュア記 15:33; ヨハネ 3:34"> 主の霊は、ツォルアとエシュタオルの間にあるマハネ・ダンで、彼を奮い立たせ始めた。</span>
</div>
</div>

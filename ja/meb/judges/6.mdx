<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ネヘミヤ記 9:26–29; 士師記 2:19–20; 士師記 2:13–14"> イスラエルの人々は主の目に悪を行った。主は彼らを七年の間、ミディアンの手に渡された。</span>
<span className="v" id="v2" data-v="2" data-xref="ヘブル人への手紙 11:38; サムエル記第一 13:6; 申命記 28:47–48"> ミディアンはイスラエルを圧倒した。イスラエルの人々はミディアンを避け、山中の隠れ場や洞窟、要害を造った。</span>
<span className="v" id="v3" data-v="3" data-xref="士師記 6:33; 士師記 3:13; 士師記 7:12"> イスラエルが種を蒔いたとき、ミディアン人、アマレク人、そして東の人々が彼らに対して上って来た。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 26:16; 申命記 28:51; ミカ書 6:15"> 彼らはイスラエルに対して陣を敷き、ガザに至るまで地の産物を荒らした。イスラエルには食糧も、羊も、牛も、ろばも残さなかった。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 7:12; 士師記 8:10; エレミヤ書 46:23"> 彼らは家畜と天幕を携えて上って来た。その数はいなごの大群のようで、人もらくだも数えきれなかった。彼らはその地を滅ぼすために入って来た。</span>
<span className="v" id="v6" data-v="6" data-xref="士師記 3:9; エレミヤ書 5:17; 詩篇 50:15"> イスラエルはミディアンによってひどく衰えた。そこでイスラエルの人々は主に叫び求めた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> イスラエルの人々がミディアンに苦しめられて主に叫び求めたとき、</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 20:5–32; イザヤ書 63:9–14; 詩篇 136:10–16"> 主はイスラエルの人々に一人の預言者を遣わされた。彼は彼らに言った。「イスラエルの神、主はこう言われる。『わたしはあなたがたをエジプトから上らせ、奴隷の家から導き出した。</span>
<span className="v" id="v9" data-v="9" data-xref="詩篇 44:2–3"> わたしはあなたがたをエジプト人の手と、あなたがたをしいたげるすべての者の手から救い出し、あなたがたの前から彼らを追い払い、彼らの地をあなたがたに与えた。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 10:2; 列王記第二 17:35–39; エレミヤ書 9:13"> わたしはあなたがたに言った。「わたしはあなたがたの神、主である。あなたがたが住んでいる地のアモリ人の神々を恐れてはならない。」しかし、あなたがたはわたしの声に聞き従わなかった。』」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヨシュア記 17:2; ヘブル人への手紙 11:32; 士師記 13:3"> 主の使いが来て、アビエゼル人ヨアシュに属する、オフラにある樫の木の下に座った。そのとき、彼の子ギデオンはミディアン人から隠すために、酒ぶねで小麦を打っていた。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨシュア記 1:5; ルカ 1:28; 士師記 2:18"> 主の使いが彼に現れて言った。「勇士よ、主はあなたとともにおられる。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 77:7–9; 歴代誌 第二 15:2; イザヤ書 59:1–2"> ギデオンは言った。「ああ、わが主よ。主が私たちとともにおられるのなら、なぜこのすべてが私たちに起こったのでしょう。父祖たちは、『主は私たちをエジプトから導き上られたではないか』と言い、主の驚くべきみわざを語り伝えました。それは今どこにあるのでしょう。今や主は私たちを捨て、ミディアンの手に渡されました。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ヨシュア記 1:5–9; ヘブル人への手紙 11:34; サムエル記第一 12:11"> 主は彼に目を向けて言われた。「あなたのその力をもって行き、イスラエルをミディアンの手から救い出しなさい。わたしがあなたを遣わしたではないか。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="サムエル記第一 9:21; 出エジプト記 3:11; 出エジプト記 4:10"> ギデオンは言った。「主よ、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「主」と訳された言葉は「アドナイ」である。">a</a></sup>私にどうしてイスラエルを救えるでしょう。私の氏族はマナセの中で最も弱く、私自身も父の家で最も小さい者です。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヨシュア記 1:5; 出エジプト記 3:12; 使徒の働き 11:21"> 主は言われた。「わたしがあなたとともにいる。あなたは一人を打つように、ミディアン人を打つ。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="詩篇 86:17; 出エジプト記 33:13; イザヤ書 7:11"> 彼は言った。「もし今、私があなたの目に恵みを得たのであれば、私と語っているのがあなたであるというしるしを私に見せてください。</span>
<span className="v" id="v18" data-v="18" data-xref="士師記 13:15; 創世記 18:3; 創世記 18:5"> どうか、私があなたのもとに戻り、私の贈り物を持って来てあなたの前に供えるまで、ここから立ち去らないでください。」<br />主は言われた。「あなたが戻って来るまで、わたしは待とう。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 18:6–8; 士師記 13:15–19; レビ記 2:4"> ギデオンは家に入り、子やぎ一匹と、一エパ<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一エパは約22リットル、または約3分の2ブッシェルである。">b</a></sup>の小麦粉で種なしパンを用意した。肉をかごに入れ、煮汁を壺に入れて、樫の木の下の使いのもとへ運び、差し出した。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="士師記 13:19; 列王記第一 18:33–34"> 神の使いは彼に言った。「その肉と種なしパンを取り、この岩の上に置き、煮汁を注ぎなさい。」<br />彼はそのようにした。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 9:24; 列王記第一 18:38; 歴代誌 第二 7:1"> すると主の使いは、手に持っていた杖の先を伸ばし、肉と種なしパンに触れた。すると岩から火が燃え上がり、肉と種なしパンを焼き尽くした。そして主の使いは彼の目の前から見えなくなった。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 32:30; 出エジプト記 33:20; 申命記 5:26"> ギデオンは、その方が主の使いであると悟って言った。「ああ、主なる神よ。私は主の使いを顔と顔を合わせて見てしまいました。」</span>
<span className="v" id="v23" data-v="23" data-xref="ダニエル書 10:19; ヨハネ 20:26; 創世記 43:23"> 主は彼に言われた。「あなたに平安があるように。恐れるな。あなたは死ぬことはない。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="創世記 22:14; 出エジプト記 17:15; 士師記 8:32"> そこでギデオンはその場所に主のための祭壇を築き、「主は平安」<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="または「シャローム」。">c</a></sup>と名づけた。それは今日に至るまで、アビエゼル人のオフラにある。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出エジプト記 34:13; 士師記 3:7; 使徒の働き 5:29"> その夜、主は彼に言われた。「あなたの父の雄牛、すなわち七歳になる二番目の雄牛を取り、父が持つバアルの祭壇を打ち壊し、そのそばのアシェラ像を切り倒せ。</span>
<span className="v" id="v26" data-v="26" data-xref="コリント人への第一の手紙 14:40; サムエル記第二 24:18; コリント人への第一の手紙 14:33"> それから、この要害の頂に、定められた方法であなたの神、主のための祭壇を築きなさい。そしてあの二番目の雄牛を取り、あなたが切り倒すアシェラ像の木を使って全焼のささげ物をささげなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="テサロニケ人への手紙第一 2:4; ヨハネ 2:5; 申命記 4:1"> そこでギデオンはしもべたちの中から十人の者を取り、主が彼に語られたとおりに行った。彼は父の家の者たちや町の人々を恐れたため、昼にそれを行うことができず、夜にそれを行った。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 町の人々が朝早く起きると、見よ、バアルの祭壇は打ち壊され、そのそばのアシェラ像は切り倒され、築かれた祭壇の上には二番目の雄牛がささげられていた。</span>
<span className="v" id="v29" data-v="29"> 彼らは互いに言った。「だれがこんなことをしたのか。」<br />彼らが調べて尋ねると、人々は言った。「ヨアシュの子ギデオンがこのことをしたのだ。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒の働き 26:9; ピリピ人への手紙 3:6; エレミヤ書 50:38"> そこで町の人々はヨアシュに言った。「あなたの息子を引き出しなさい。彼は死ななければならない。彼がバアルの祭壇を打ち壊し、そのそばにあったアシェラ像を切り倒したからだ。」</span>
<span className="v" id="v31" data-v="31" data-xref="エレミヤ書 10:11; コリント人への第一の手紙 8:4; エペソ人への手紙 5:11"> ヨアシュは自分に立ち向かう者たちに言った。「あなたがたがバアルのために争うのか。あなたがたが彼を救うのか。彼のために争う者は、朝までに死ななければならない。もしバアルが神なら、自分の祭壇が打ち壊されたのだから、自分で争えばよい。」</span>
<span className="v" id="v32" data-v="32" data-xref="サムエル記第一 12:11; 士師記 7:1; サムエル記第二 11:21"> それゆえその日、彼はギデオンをエルバアル<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="「エルバアル」は「バアルに争わせよ」という意味である。">d</a></sup>と名付けて言った。「彼が祭壇を打ち壊したのだから、バアル自身に彼と争わせよ。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="ヨシュア記 17:16; 士師記 6:3; ローマ人への手紙 8:35–39"> その後、すべてのミディアン人、アマレク人、そして東の人々がともに集まり、川を渡ってエズレルの谷に陣を敷いた。</span>
<span className="v" id="v34" data-v="34" data-xref="士師記 3:27; 歴代誌 第二 24:20; 士師記 3:10"> 主の霊がギデオンを包んだ。彼が角笛を吹くと、アビエゼルの人々が召集され、彼に従った。</span>
<span className="v" id="v35" data-v="35" data-xref="歴代誌 第二 30:6–12; 士師記 4:6"> 彼はマナセ全域に使者を送り、マナセの人々も召集されて彼に従った。またアシェル、ゼブルン、ナフタリにも使者を送り、彼らも迎えに上って来た。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="士師記 6:14; マタイ 16:1; 士師記 6:17–20"> ギデオンは神に言った。「あなたが語られたとおりに、もし私の手によってイスラエルをお救いになるのであれば、</span>
<span className="v" id="v37" data-v="37" data-xref="ホセア書 14:5; マタイ 10:5–6; マタイ 15:24"> 見てください。私は打ち場に羊毛を一束置きます。もし羊毛にだけ露が降り、地面がすべて乾いていれば、あなたが語られたとおり、私の手によってイスラエルを救われることが分かります。」</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="イザヤ書 35:7"> するとそのようになった。彼が翌朝早く起きてその羊の毛を押し絞ると、羊の毛から露が絞り出され、鉢に一杯の水となった。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="創世記 18:32; イザヤ書 50:2; 詩篇 107:33–35"> ギデオンは神に言った。「どうか、私に向かって怒りを燃やさないでください。この一度だけ言わせてください。どうか、この羊の毛でもう一度だけ試させてください。今度は羊の毛だけが乾いていて、他のすべての地面には露が降りますように。」</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40"> 神はその夜、そのようにされた。すなわち、羊の毛だけが乾いていて、他のすべての地面には露が降りていた。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士師記 2:21–22; 申命記 7:22; 箴言 17:3"> 主が残しておかれた国々は次のとおりである。これは、カナンでの戦いを経験しなかったイスラエルの者たちを試すためであり、</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 3:5; 創世記 3:7; コリント人への第一の手紙 9:26–27"> それまで戦いを知らなかったイスラエルの世代に、戦いを教えるためでもあった。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨシュア記 13:3; ヨシュア記 13:5; 士師記 10:7"> ペリシテ人の五人の君主、すべてのカナン人、シドン人、およびバアル・ヘルモン山からハマテの入り口に至るまでのレバノン山に住むヒビ人である。</span>
<span className="v" id="v4" data-v="4" data-xref="士師記 3:1; 士師記 2:22; 出エジプト記 15:25"> 彼らが残されたのは、彼らによってイスラエルを試み、主がモーセを通して彼らの父祖たちに命じられた主の戒めに、彼らが聞き従うかどうかを知るためであった。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 106:34–38; 創世記 10:15–18; 出エジプト記 3:8"> イスラエルの人々はカナン人、ヘト人、アモリ人、ペリジ人、ヒビ人、およびエブス人の間に住んだ。</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 7:3–4; 出エジプト記 34:16; 列王記第一 11:1–5"> 彼らはその娘たちを自分たちの妻としてめとり、自分たちの娘たちを彼らの息子たちに与え、彼らの神々に仕えた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 34:13; 列王記第二 23:6; 列王記第一 18:19"> イスラエルの人々は主の目に悪を行い、自分たちの神、主を忘れ、バアルとアシェラに仕えた。</span>
<span className="v" id="v8" data-v="8" data-xref="士師記 2:14; ハバクク書 3:7; 士師記 4:9"> それゆえ、主の怒りはイスラエルに向かって燃え上がり、主は彼らをメソポタミアの王クシャン・リシュアタイムの手に売り渡された。イスラエルの人々は八年の間、クシャン・リシュアタイムに仕えた。</span>
<span className="v" id="v9" data-v="9" data-xref="士師記 3:15; 士師記 1:13; 詩篇 22:5"> イスラエルの人々が主に向かって叫び求めると、主はイスラエルの人々のために一人の救い主を起こし、彼らを救い出された。すなわちカレブの弟であるケナズの子オトニエルである。</span>
<span className="v" id="v10" data-v="10" data-xref="士師記 13:25; サムエル記第一 11:6; 士師記 14:19"> 主の霊が彼に臨み、彼はイスラエルをさばいた。彼が戦いに出ると、主はメソポタミアの王クシャン・リシュアタイムを彼の手に渡され、オトニエルは彼を制圧した。</span>
<span className="v" id="v11" data-v="11" data-xref="士師記 5:31; 士師記 8:28; ヨシュア記 11:23"> その地には四十年の間、平穏があった。その後、ケナズの子オトニエルは死んだ。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="サムエル記第一 12:9; 士師記 2:19; 士師記 2:14"> イスラエルの人々は再び主の目に悪を行った。彼らが主の目に悪を行ったので、主はモアブの王エグロンを強くしてイスラエルに立ち向かわせた。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 1:16; 申命記 34:3; 士師記 5:14"> エグロンはアンモンの子らとアマレクを自分のところに集め、行ってイスラエルを打ち、なつめやしの町を所有した。</span>
<span className="v" id="v14" data-v="14" data-xref="申命記 28:47–48; 申命記 28:40; レビ記 26:23–25"> イスラエルの人々は十八年の間、モアブの王エグロンに仕えた。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士師記 3:9; 詩篇 78:34; イザヤ書 36:16"> しかしイスラエルの人々が主に向かって叫び求めたとき、主は彼らのために一人の救い主を起こされた。ベニヤミン人であるゲラの子で、左利きの男エフドである。イスラエルの人々は彼を通してモアブの王エグロンに貢ぎ物を送った。</span>
<span className="v" id="v16" data-v="16" data-xref="雅歌 3:8; ヨハネの黙示録 2:12; 詩篇 149:6"> エフドは自分のために、長さ一キュビト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一キュビトは男性の中指の先から肘までの長さで、約46センチメートル、または約18インチである。">a</a></sup>の諸刃の剣を作り、それを自分の右の太ももの服の下に帯びた。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 34:20; ヨブ記 15:27; エレミヤ書 50:11"> 彼はモアブの王エグロンに貢ぎ物をささげた。エグロンは非常に太った人であった。</span>
<span className="v" id="v18" data-v="18"> 彼が貢ぎ物をささげ終えたとき、彼は貢ぎ物を運んできた人々を去らせた。</span>
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 4:20; 士師記 3:20; 使徒の働き 23:18–19"> しかし彼自身はギルガルのそばにある石の偶像のところから引き返し、「王よ、あなたに秘密の用件があります」と言った。<br />王は「静かにせよ」と言った。彼のそばに立っていた者たちは皆、彼の前から出て行った。</span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 10:7; アモス書 3:15; 詩篇 29:1"> エフドが彼のもとに近づいて行くと、王は涼しい階上の部屋に一人で座っていた。エフドは「あなたに神からの言葉があります」と言った。王は座から立ち上がった。</span>
<span className="v" id="v21" data-v="21" data-xref="ゼカリヤ書 13:3; ヨブ記 20:25; サムエル記第一 15:33"> エフドは左手を伸ばし、右の太ももから剣を抜き取って、彼の腹に突き刺した。</span>
<span className="v" id="v22" data-v="22"> 柄も刃の後から入り込み、脂肪が刃を包み込んだ。エフドが剣を腹から抜かなかったので、刃先は背後に突き出た。</span>
<span className="v" id="v23" data-v="23"> それからエフドは玄関の間に出て行き、自分の後ろで階上の部屋の戸を閉めて鍵をかけた。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="サムエル記第一 24:3"> エフドが去った後、王のしもべたちが来て見ると、階上の部屋の戸には鍵がかかっていた。彼らは、「きっと涼しい部屋で足を覆っておられる<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="すなわち、「用を足している」。">b</a></sup>のだ」と言った。</span>
<span className="v" id="v25" data-v="25"> 彼らは途方に暮れるほど待ったが、王は階上の部屋の戸を開けなかった。そこで鍵を取って開けると、主君が床に倒れて死んでいた。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> エフドは彼らが待っている間に逃げ、石の偶像をとおり過ぎてセイラへ逃れた。</span>
<span className="v" id="v27" data-v="27" data-xref="士師記 6:34; サムエル記第一 13:3; 士師記 5:14"> 彼がそこに着いたとき、彼はエフライムの山地で角笛を吹き鳴らした。そしてイスラエルの人々は彼と一緒に山地から下って行き、彼は彼らを率いた。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 12:5; 士師記 7:9; 士師記 7:15"> 彼は言った。「私について来なさい。主があなたがたの敵モアブ人を、あなたがたの手に渡された。」彼らは彼に従って下り、モアブに通じるヨルダン川の渡り場を押さえ、一人も渡らせなかった。</span>
<span className="v" id="v29" data-v="29" data-xref="申命記 32:15; 士師記 3:17; 詩篇 17:10"> そのとき、彼らはモアブ人を約一万人打ち倒した。みな屈強な者、みな勇士であった。逃げ延びた者は一人もいなかった。</span>
<span className="v" id="v30" data-v="30" data-xref="士師記 3:11; 士師記 5:31"> こうしてその日、モアブはイスラエルの手に屈服した。その地には八十年の間、平穏があった。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="士師記 5:6; コリント人への第一の手紙 1:17; サムエル記第一 17:50"> 彼の後にはアナテの子シャムガルがいた。彼は牛追い棒でペリシテ人を六百人打ち倒した。彼もまたイスラエルを救った。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 20:2; 創世記 17:7–8; レビ記 26:42"> 主の使いがギルガルからボキムに上って来て言った。「わたしはあなたがたをエジプトから上らせ、あなたがたの父祖たちに誓った地に導き入れた。そしてわたしは言った。『わたしはあなたがたとの契約を決して破らない。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 7:2–4; エレミヤ書 2:36; エズラ記 9:1–3"> あなたがたはこの地の住民と契約を結んではならない。あなたがたは彼らの祭壇を打ち壊さなければならない。』しかし、あなたがたはわたしの声に聞き従わなかった。なぜこのようなことをしたのか。</span>
<span className="v" id="v3" data-v="3" data-xref="ヨシュア記 23:13; 民数記 33:55; 申命記 7:16"> それゆえ、わたしは言う。『わたしは彼らをあなたがたの前から追い出さない。彼らはあなたがたのわき腹を刺す者となり、彼らの神々はあなたがたの罠となる。』」</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 31:9; 箴言 17:10; ゼカリヤ書 12:10"> 主の使いがこれらの言葉をイスラエルのすべての人々に語ったとき、民は声を上げて泣いた。</span>
<span className="v" id="v5" data-v="5" data-xref="サムエル記第一 7:9; 創世記 35:8; ヨシュア記 7:26"> 彼らはその場所の名をボキム<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「ボキム」は「泣く者たち」を意味する。">a</a></sup>と呼び、そこで主にいけにえをささげた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ヨシュア記 24:28–31; ヨシュア記 22:6"> ヨシュアが民を送り出すと、イスラエルの人々はそれぞれ自分の相続地へ行き、その地を所有した。</span>
<span className="v" id="v7" data-v="7" data-xref="ピリピ人への手紙 2:12; ヨシュア記 24:31; 歴代誌 第二 24:2"> 民はヨシュアの生きている間、また、ヨシュアより長生きし、主がイスラエルのために行われたすべての偉大なみわざを見た長老たちの生きている間、主に仕えた。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 24:29–30"> 主のしもべ、ヌンの子ヨシュアは、百十歳で死んだ。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 19:50; ヨシュア記 24:30"> 人々は彼を、エフライムの山地、ガアシュ山の北にあるティムナテ・ヘレスの、彼の相続地に葬った。</span>
<span className="v" id="v10" data-v="10" data-xref="サムエル記第一 2:12; テトス 1:16; 出エジプト記 5:2"> また、その世代の者たちも皆その父祖たちのところに集められ、彼らの後に、主を知らず、主がイスラエルのために行われたみわざも知らない別の世代が起こった。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="士師記 4:1; 士師記 6:1; 士師記 3:7"> イスラエルの人々は主の目に悪を行い、バアルの神々に仕えた。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 20:5; 申命記 13:5; 申命記 6:14–15"> 彼らをエジプトの地から導き出された彼らの父祖たちの神、主を捨て、周囲にいる国々の民の神々である他の神々に従い、それらにひれ伏した。こうして彼らは主を怒らせた。</span>
<span className="v" id="v13" data-v="13" data-xref="士師記 10:6; 詩篇 106:36; 士師記 3:7"> 彼らは主を捨て、バアルとアシュタロテに仕えた。</span>
<span className="v" id="v14" data-v="14" data-xref="列王記第二 17:20; 詩篇 106:40–42; 申命記 32:30"> 主の怒りはイスラエルに向かって燃え上がった。主は彼らを略奪者の手に渡して略奪させ、周囲の敵の手に売り渡されたので、彼らはもはや敵の前に立つことができなかった。</span>
<span className="v" id="v15" data-v="15" data-xref="申命記 28:15–68; ヨシュア記 23:15–16; レビ記 26:14–46"> 彼らがどこへ出て行っても、主が語り、誓われたとおり、主の手が彼らに災いをもたらした。彼らはひどく苦しんだ。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 13:20; 詩篇 106:43–45; サムエル記第一 12:11"> 主は士師たちを起こし、略奪する者たちの手から彼らを救い出された。</span>
<span className="v" id="v17" data-v="17" data-xref="ガラテヤ人への手紙 1:6; 申命記 9:12; 士師記 2:7"> しかし彼らは士師たちにも聞き従わず、他の神々を追って淫行にふけり、それらにひれ伏した。父祖たちが主の戒めに聞き従って歩んだ道から、たちまちそれて行き、父祖たちのようには行わなかった。</span>
<span className="v" id="v18" data-v="18" data-xref="申命記 32:36; ヨシュア記 1:5; 出エジプト記 2:24"> 主が彼らのために士師を起こされると、主はその士師とともにおられ、士師の生きている間、彼らを敵の手から救われた。しいたげ苦しめる者のために彼らがうめくのを聞き、主があわれまれたからである。</span>
<span className="v" id="v19" data-v="19" data-xref="士師記 8:33; 士師記 4:1; マタイ 23:32"> しかし士師が死ぬと、彼らは再び堕落し、父祖たちよりもさらに悪くなった。他の神々に従って仕え、ひれ伏し、その行いも、かたくなな道も捨てなかった。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="士師記 2:14; ヨシュア記 23:16; 出エジプト記 32:10–11"> 主の怒りはイスラエルに向かって燃え上がり、主は言われた。「この民は、わたしが彼らの父祖たちに命じたわたしの契約を破り、わたしの声に聞き従わなかった。</span>
<span className="v" id="v21" data-v="21" data-xref="ヨシュア記 23:13; 士師記 2:3; 士師記 3:3"> それゆえわたしも、ヨシュアが死んだときに残しておいた国々を、もはや一つも彼らの前から追い出さない。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 8:2; 申命記 8:16; 申命記 13:3"> それは、彼らの父祖たちが主の道を守って歩んだように、彼らもそれを守って歩むかどうか、彼らによってイスラエルを試みるためである。」</span>
<span className="v" id="v23" data-v="23"> それゆえ主は、それらの国々をすぐに追い出すことなく残しておかれた。主は彼らをヨシュアの手に渡されなかったのである。</span>
</div>

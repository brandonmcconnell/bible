<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 21:13; 詩篇 125:2; ヨエル書 3:12"> 幻の谷についての宣告。<br />今、あなたはどうしたのか。なぜ、みな屋根の上に上ったのか。</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 32:13; イザヤ書 23:7; 哀歌 2:20"> 叫び声に満ちた、騒がしい都、喜びに満ちた町よ。あなたの殺された者たちは剣で殺されたのではなく、戦いで死んだのでもない。</span>
<span className="v" id="v3" data-v="3" data-xref="列王記第二 25:4–7; イザヤ書 3:1–8; エレミヤ書 39:4–7"> あなたの支配者たちはみな一緒に逃げたが、弓を持つ者たちに捕らえられた。あなたのうちで見つかった者たちはみな一緒に縛られた。彼らは遠くへ逃げていた。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 9:1; マタイ 2:18; 詩篇 77:2"> それゆえ、私は言った。「私から目をそらしてほしい。私は激しく泣く。わが民の娘が滅ぼされたために、私を慰めようと努めないでほしい。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ミカ書 7:4; イザヤ書 37:3; ルカ 23:30"> 幻の谷には、主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「主」は、神の固有名であるヘブライ語のיהוה（ヤハウェ）を表す。">a</a></sup>、万軍の主から来る混乱と踏みにじりと困惑の日がある。城壁は崩され、叫び声は山々に向かって上がる。」</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第二 16:9; イザヤ書 21:2; アモス書 1:5"> エラムは矢筒を負い、人の乗る戦車と騎兵を従え、キルは盾の覆いを外した。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 8:7–8; イザヤ書 10:28–32; エレミヤ書 39:1–3"> あなたの最も良い谷々は戦車で満ち、騎兵は門に向かって隊列を整えた。</span>
<span className="v" id="v8" data-v="8" data-xref="列王記第一 7:2; 列王記第一 10:17; イザヤ書 36:1–3"> 主はユダの覆いを取り去られた。その日、あなたは森の家にある武器に目を向けた。</span>
<span className="v" id="v9" data-v="9" data-xref="列王記第二 20:20; ネヘミヤ記 3:16; 歴代誌 第二 32:1–6"> あなたがたはダビデの町の破れが多いのを見て、下の池の水を集めた。</span>
<span className="v" id="v10" data-v="10"> あなたがたはエルサレムの家々を数え、城壁を補強するために家々を取り壊した。</span>
<span className="v" id="v11" data-v="11" data-xref="ミカ書 7:7; エレミヤ書 33:2–3; イザヤ書 31:1"> また、古い池の水をためるため、二つの城壁の間に貯水池を造った。しかし、これをなさった方に目を向けず、これを遠い昔に計画された方を顧みなかった。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ヨエル書 2:17; ミカ書 1:16; ヨエル書 1:13"> その日、主<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「主」は、神の固有名であるヘブライ語のיהוה（ヤハウェ）を表す。">b</a></sup>、万軍の主は、泣き、嘆き、頭をそり、粗布をまとうように呼びかけられた。</span>
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 56:12; コリント人への第一の手紙 15:32; ルカ 17:26–29"> しかし見よ、そこには喜びと楽しみがあり、牛を殺し、羊をほふり、肉を食べ、ぶどう酒を飲んでいる。「食べて飲もう。明日は死ぬのだから。」</span>
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 24:13; サムエル記第一 3:14; イザヤ書 5:9"> 万軍の主<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「主」は、神の固有名であるヘブライ語のיהוה（ヤハウェ）を表す。">c</a></sup>は私の耳にこう明らかにされた。「あなたがたが死ぬまで、この咎が赦されることは決してない」と主、万軍の主は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 36:3; 列王記第二 18:18; 列王記第二 19:2"> 主、万軍の主はこう言われる。「宮廷管理官、すなわち王宮をつかさどるシェブナのところへ行き、こう言いなさい。</span>
<span className="v" id="v16" data-v="16" data-xref="マタイ 27:60; 歴代誌 第二 16:14; サムエル記第二 18:18"> 『あなたはここで何をしているのか。ここにだれがいるというので、自分の墓を掘ったのか。』彼は高い所に自分の墓を掘り、岩に自分の住まいを刻んでいる。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 14:3; ヨブ記 9:24; エステル記 7:8"> 見よ、主はあなたを力ずくで放り投げる。主はあなたをしっかりとつかむ。</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 17:13; アモス書 7:17"> 主はあなたを固く巻き上げ、まりのように広大な地へ投げ飛ばす。あなたはそこで死に、あなたの誇りである戦車もそこに残る。あなたは主人の家の恥だ。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 17:24; 詩篇 75:6–7; ヨブ記 40:11–12"> わたしはあなたをその職から追い出す。あなたはその地位から引き降ろされる。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 36:3; 列王記第二 18:18; イザヤ書 37:2"> その日、わたしはヒルキヤの子である、わたしのしもべエルヤキムを呼ぶ。</span>
<span className="v" id="v21" data-v="21" data-xref="創世記 45:8; イザヤ書 9:6–7; 創世記 41:42–43"> わたしは彼にあなたの長衣を着せ、あなたの帯を締めさせ、あなたの権限を彼の手に委ねる。彼はエルサレムの住民とユダの家の父となる。</span>
<span className="v" id="v22" data-v="22" data-xref="マタイ 16:18–19; ヨハネの黙示録 3:7; ヨブ記 12:14"> わたしはダビデの家の鍵を彼の肩に置く。彼が開けば、閉じる者はなく、彼が閉じれば、開く者はない。</span>
<span className="v" id="v23" data-v="23" data-xref="エズラ記 9:8; ヨブ記 36:7; ゼカリヤ書 10:4"> わたしは彼を確かな場所に打ち込まれた釘のようにする。彼は父の家にとって栄光の王座となる。</span>
<span className="v" id="v24" data-v="24" data-xref="ダニエル書 6:1–3; ヨハネ 20:21–23; マタイ 28:18"> 彼の上には父の家のすべての栄光、子孫とその末、すべての小さな器、杯からすべての壺に至るまでが掛けられる。」</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 46:11; エステル記 9:24–25; 詩篇 146:3"> 万軍の主は言われる。「その日、確かな場所に打ち込まれた釘は抜け落ちる。それは切り落とされて倒れ、その上に掛かっていたすべてのものも断ち切られる。主がこれを語られたからだ。」</span>
</div>

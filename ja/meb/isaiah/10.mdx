<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="ルカ 11:52; ミカ書 3:1–4; マタイ 23:23"> 不義な法令を定め、虐げる命令を書き記す者たちに災いがある。</span>
<span className="v" id="v2" data-v="2" data-xref="マラキ書 3:5; イザヤ書 3:14; イザヤ書 29:21"> 彼らは貧しい者から公正を奪い、わたしの民の困窮している者から権利を奪い、やもめを分捕り物とし、父のない子を獲物とする。</span>
<span className="v" id="v3" data-v="3" data-xref="ホセア書 9:7; ルカ 19:44; ヨブ記 31:14"> 裁きの日、遠くから荒廃が来る時、あなたがたはどうするのか。助けを求めて、だれのもとへ逃げるのか。自分の財産をどこに残すのか。</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 5:25; イザヤ書 9:12; エレミヤ書 37:10"> <span className="pl pl-1">捕虜の中に身をかがめ、</span><br /><span className="pl pl-2">殺された者たちの下に倒れるほかない。</span><br /><span className="pl pl-1">それでも主の怒りは去らず、</span><br /><span className="pl pl-2">その御手はなお伸ばされたままである。</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 51:20–24; イザヤ書 14:25; イザヤ書 30:30"> ああ、アッシリア。彼はわたしの怒りのむちであり、その手にある杖はわたしの憤りである。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 9:17; エレミヤ書 25:9; ゼカリヤ書 10:5"> わたしは彼を神を恐れない国に遣わし、わたしを怒らせた民に向かって命じる。分捕り物を奪い、獲物を取り、彼らを通りの泥のように踏みにじらせる。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 50:20; ミカ書 4:11–12; 使徒の働き 2:23"> しかし、彼自身はそのように考えず、その心もそうは思っていない。その心にあるのは、多くの国々を滅ぼし、断ち滅ぼすことである。</span>
<span className="v" id="v8" data-v="8" data-xref="列王記第二 18:24; 列王記第二 19:10; エゼキエル書 26:7"> 彼は言う。「私の高官たちは、みな王ではないか。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代誌 第二 35:20; 列王記第二 16:9; 創世記 10:10"> カルノはカルケミシュのようになったではないか。ハマテはアルパデのように、サマリアはダマスコのようになったではないか。</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 10:14; 列王記第二 19:17–19; 列王記第二 18:33–35"> 私の手は偶像の王国を捕らえた。その彫像はエルサレムやサマリアのものにまさっていた。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 37:10–13; イザヤ書 2:8; イザヤ書 36:19–20"> サマリアとその偶像にしたように、エルサレムとその偶像にも同じことをするではないか。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王記第二 19:31; イザヤ書 65:7; エレミヤ書 50:18"> 主がシオンの山とエルサレムでご自分の働きをすべて終えるとき、わたしはアッシリアの王の高慢な心の実と、その傲慢な目の誇りを罰する。</span>
<span className="v" id="v13" data-v="13" data-xref="申命記 8:17; ダニエル書 4:30; エゼキエル書 26:2"> 彼はこう言ったからだ。「私は自分の手の力と自分の知恵によってこれを行った。私には分別があるからだ。私は諸国の境を取り除き、その宝を奪い、勇士のように支配者たちを引きずり下ろした。</span>
<span className="v" id="v14" data-v="14" data-xref="ヨブ記 31:25; 箴言 21:6–7; ナホム書 2:9–1"> 私の手は、巣を見つけるように諸国の富を見つけた。置き去りにされた卵を集めるように、私は全地を集めた。翼を動かす者も、口を開く者も、さえずる者もいなかった。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 9:20–21; イザヤ書 45:9; イザヤ書 10:5"> 斧が、それを使って切る者に向かって誇るだろうか。のこぎりが、それを引く者よりも自分を高くするだろうか。それはまるで、むちがそれを振るう者を振り回し、木の杖が人を持ち上げるようなものだ。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代誌 第二 32:21; 使徒の働き 12:23; 詩篇 106:15"> それゆえ、主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「主」は、神の固有名であるヘブライ語のיהוה（ヤハウェ）を表す。">a</a></sup>、万軍の主は、彼の肥えた者たちをやせ衰えさせ、その栄光の下に、火が燃えるような炎を燃え上がらせる。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 27:4; 民数記 11:1–3; イザヤ書 37:23"> イスラエルの光は火となり、その聖なる方は炎となる。その火は一日のうちに、彼のいばらと茨を焼き尽くす。</span>
<span className="v" id="v18" data-v="18" data-xref="列王記第二 19:23; イザヤ書 10:33–34; イザヤ書 9:18"> 主は彼の森と実り豊かな畑の栄光を、身も命も焼き尽くす。それは旗手が衰え果てる時のようになる。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 21:17; イザヤ書 37:36"> その森に残る木はわずかとなり、子どもでもその数を書き記せるほどになる。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 37:31–32; イザヤ書 50:10; イザヤ書 1:9"> その日、イスラエルの残りの者と、ヤコブの家の逃れた者たちは、もはや自分たちを打った者に頼らず、真実をもって、イスラエルの聖なる方である主<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「主」は、神の固有名であるヘブライ語のיהוה（ヤハウェ）を表す。">b</a></sup>に頼る。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 9:6; コリント人への第二の手紙 3:14–16; ホセア書 7:10"> 残りの者、すなわちヤコブの残りの者は、力ある神に立ち返る。</span>
<span className="v" id="v22" data-v="22" data-xref="ローマ人への手紙 9:27–28; イザヤ書 6:13; ヨハネの黙示録 20:8"> イスラエルよ、あなたの民が海の砂のように多くても、そのうち立ち返るのは残りの者だけである。義にあふれる滅びが定められている。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 28:22; イザヤ書 24:1–23; ローマ人への手紙 9:28"> 主<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「主」は、神の固有名であるヘブライ語のיהוה（ヤハウェ）を表す。">c</a></sup>、万軍の主は、全地に定められた完全な滅びを行う。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヘブル人への手紙 12:22–24; イザヤ書 37:6; イザヤ書 61:3"> それゆえ、主、万軍の主はこう言われる。「シオンに住むわたしの民よ、エジプトがしたように、アッシリアがむちであなたを打ち、あなたに向かって杖を振り上げても、彼を恐れてはならない。</span>
<span className="v" id="v25" data-v="25" data-xref="ダニエル書 11:36; 列王記第二 19:35; ヘブル人への手紙 10:37"> ほんのしばらくすれば、あなたに対する憤りは終わり、わたしの怒りは彼を滅ぼすことに向けられる。」</span>
<span className="v" id="v26" data-v="26" data-xref="イザヤ書 9:4; 士師記 7:25; 列王記第二 19:35"> 万軍の主は、オレブの岩でミディアンを打ち殺した時のように、彼に向かってむちを振るう。主は海の上に杖を伸ばし、エジプトに対してしたように、それを振り上げる。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 9:4; ルカ 4:18; イザヤ書 14:25"> その日、彼の重荷はあなたの肩から離れ、彼のくびきはあなたの首から外される。そのくびきは、油注ぎのゆえに砕かれる。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="サムエル記第一 14:2; サムエル記第一 13:2; サムエル記第一 13:5"> 彼はアイアテに来た。ミグロンを通り、ミクマスに荷物を置く。</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記第一 13:23; サムエル記第一 7:17; ヨシュア記 21:17"> 彼らは峠を越え、ゲバで夜を過ごす。ラマは震え、サウルのギブアは逃げ去った。</span>
<span className="v" id="v30" data-v="30" data-xref="サムエル記第一 25:44; エレミヤ書 1:1; ヨシュア記 21:18"> ガリムの娘よ、声を上げて叫べ。ライシャよ、聞け。哀れなアナトテよ。</span>
<span className="v" id="v31" data-v="31" data-xref="ヨシュア記 15:31"> マデメナは逃げ去り、ゲビムの住民は安全な場所へ逃れる。</span>
<span className="v" id="v32" data-v="32" data-xref="サムエル記第一 21:1; イザヤ書 37:22; イザヤ書 19:16"> 今日のうちに、彼はノブにとどまり、シオンの娘の山、エルサレムの丘に向かって手を振り上げる。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="アモス書 2:9; ダニエル書 4:37; イザヤ書 37:38"> 見よ、主、万軍の主は、恐るべき力で大枝を切り落とす。背の高い者は切り倒され、高ぶる者は低くされる。</span>
<span className="v" id="v34" data-v="34" data-xref="イザヤ書 37:24; ダニエル書 4:23; エレミヤ書 48:2"> 主は鉄で森の茂みを切り払い、レバノンは力ある方によって倒される。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 65:2; イザヤ書 1:2; ホセア書 7:13"> 主は言われる。「背く子どもたちに災いがある。彼らは計画を立てるが、わたしから出たものではない。同盟を結ぶが、わたしの霊によるものではない。こうして罪に罪を重ねている。</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 36:6; 民数記 27:21; 申命記 28:68"> 彼らはわたしの助言を求めず、エジプトへ下って行こうとする。ファラオの力によって自分たちを強くし、エジプトの陰に逃れようとしている。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 20:5; ローマ人への手紙 10:11; エレミヤ書 17:5–6"> それゆえ、ファラオの力はあなたがたの恥となり、エジプトの陰に逃れることはあなたがたの辱めとなる。</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 19:11; イザヤ書 57:9; エレミヤ書 43:7"> 彼らの高官たちはツォアンにおり、その使者たちはハネスに着いた。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 2:36; イザヤ書 30:7; イザヤ書 30:16"> 彼らはみな、自分たちの役に立たない民のために恥を受ける。その民は助けにも利益にもならず、ただ恥とそしりをもたらす。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="申命記 8:15; イザヤ書 46:1–2; エレミヤ書 11:4"> 南の獣についての宣告。<br />苦しみと悩みの地、雌獅子と獅子、まむしと火のように飛ぶ蛇のいる地を通り、彼らは若いろばの肩に富を、らくだのこぶに宝を載せ、役に立たない民のもとへ運んで行く。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 2:22; イザヤ書 7:4; 詩篇 118:8–9"> エジプトの助けはむなしく、何の役にも立たない。それゆえ、わたしは彼女を「何もせず座っているラハブ」と呼んだ。</span>
<span className="v" id="v8" data-v="8" data-xref="申命記 31:22; ハバクク書 2:2; イザヤ書 8:1"> 今、行って、彼らの前でこれを板に書き、書物に記せ。それが後の時代のために、永遠に残るように。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 30:1; 使徒の働き 7:51; ゼカリヤ書 1:4–6"> 彼らは背く民、偽りを言う子どもたち、主の律法を聞こうとしない子どもたちだからだ。</span>
<span className="v" id="v10" data-v="10" data-xref="エゼキエル書 13:7–10; ローマ人への手紙 16:18; アモス書 2:12"> 彼らは先見者たちに「見るな」と言い、預言者たちに言う。「われわれに正しいことを預言するな。耳に心地よいことを語り、偽りを預言せよ。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 8:7; ローマ人への手紙 1:30; ヨハネ 15:23–24"> 道から離れ、道筋から外れよ。イスラエルの聖なる方を、われわれの前から消し去れ。」</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 31:1–3; イザヤ書 5:24; テサロニケ人への手紙第一 4:8"> それゆえ、イスラエルの聖なる方はこう言われる。「あなたがたはこの言葉を侮り、虐げと不正に信頼し、それに頼っている。</span>
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 29:5; エゼキエル書 13:10–15; 列王記第一 20:30"> それゆえ、この咎はあなたがたにとって、高い城壁に膨らみ出た、今にも崩れそうな裂け目のようになる。その崩壊は一瞬のうちに、突然起こる。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 2:9; エレミヤ書 19:10–11; ペテロの第二の手紙 2:4–5"> 主はそれを、陶器師の器が砕かれるように砕き、容赦なく粉々にされる。その破片の中には、炉から火を取るにも、貯水槽から水をくむにも使えるかけらさえ見つからない。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 26:3–4; イザヤ書 32:17; エレミヤ書 3:22–23"> 主なる神、イスラエルの聖なる方はこう言われた。「立ち返って安らぐことによって、あなたがたは救われる。静かにして信頼することに、あなたがたの力がある。」しかし、あなたがたは拒んだ。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 31:1; イザヤ書 31:3; 申命記 28:25"> あなたがたは言った。「いや、われわれは馬に乗って逃げよう。」それゆえ、あなたがたは逃げることになる。「速い馬に乗ろう。」それゆえ、あなたがたを追う者たちも速くなる。</span>
<span className="v" id="v17" data-v="17" data-xref="申命記 28:25; ヨシュア記 23:10; 申命記 32:30"> 一人の脅しによって千人が逃げ、五人の脅しによってあなたがたは逃げる。ついには、山の頂の旗ざおのように、丘の上の旗のように取り残される。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="哀歌 3:25–26; ペテロの第二の手紙 3:9; 箴言 16:20"> それゆえ、主はあなたがたに恵みを示そうと待っておられる。それゆえ、あなたがたをあわれむために高く立ち上がられる。主は公正の神だからだ。主を待ち望む者はみな幸いである。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 60:20; 詩篇 50:15; イザヤ書 65:24"> エルサレムのシオンに住む民よ、あなたはもう泣くことがない。あなたの叫ぶ声を聞くと、主は必ずあなたに恵みを示される。主はそれを聞くと、あなたに答えられる。</span>
<span className="v" id="v20" data-v="20" data-xref="列王記第一 22:27; 詩篇 80:5; アモス書 8:11–12"> 主があなたがたに苦難のパンと苦しみの水を与えられても、あなたの教師たちはもはや隠されず、あなたの目はあなたの教師たちを見る。</span>
<span className="v" id="v21" data-v="21" data-xref="詩篇 32:8; 箴言 3:5–6; イザヤ書 58:11"> あなたが右に曲がる時も、左に曲がる時も、あなたの耳は後ろから「これが道だ。この道を歩め」と言う声を聞く。</span>
<span className="v" id="v22" data-v="22" data-xref="士師記 17:3–4; イザヤ書 31:7; ゼカリヤ書 13:2"> あなたがたは銀の彫像を覆うものと、金の鋳像を覆うものを汚れたものとする。それらを不浄なもののように投げ捨て、「出て行け」と言う。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ゼカリヤ書 8:11–12; イザヤ書 32:20; 詩篇 65:9–13"> 主は、あなたが地にまく種のために雨を与えられる。地の産物で作るパンは豊かで、十分にある。その日、あなたの家畜は広い牧場で草を食べる。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 45:6; 申命記 25:4; サムエル記第一 8:12"> 地を耕す牛と若いろばも、シャベルと熊手でふるい分けられた味の良い飼料を食べる。</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 43:19–20; イザヤ書 35:6–7; イザヤ書 2:14–15"> 大いなる虐殺の日、塔が倒れる時、すべての高い山と、すべての高く上げられた丘に、水の流れる小川ができる。</span>
<span className="v" id="v26" data-v="26" data-xref="イザヤ書 60:19–20; 申命記 32:39; ヨハネの黙示録 22:5"> 主がご自分の民の裂け傷を包み、打たれた傷を癒やされる日、月の光は太陽の光のようになり、太陽の光は七倍、七日分の光のようになる。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="テサロニケ人への第二の手紙 2:8; ナホム書 1:5–6; 詩篇 18:7–9"> 見よ、主の御名が遠くから来る。怒りに燃え、濃い煙を上げて来る。その唇は憤りに満ち、その舌は焼き尽くす火のようだ。</span>
<span className="v" id="v28" data-v="28" data-xref="イザヤ書 37:29; イザヤ書 11:4; テサロニケ人への第二の手紙 2:8"> その息は、首にまで達するあふれる流れのようであり、諸国の民を滅びのふるいにかける。人々のあごには、彼らを破滅へ導くくつわがある。</span>
<span className="v" id="v29" data-v="29" data-xref="詩篇 42:4; 詩篇 95:1–2; 出エジプト記 15:1–21"> あなたがたは、聖なる祭りを守る夜のように歌い、笛に合わせて主の山、イスラエルの岩のもとへ上る時のように、心から喜ぶ。</span>
<span className="v" id="v30" data-v="30" data-xref="詩篇 18:13–14; ヨシュア記 10:11; イザヤ書 29:6"> 主は威厳ある御声を聞かせ、激しい怒りと焼き尽くす火の炎、豪雨、暴風、雹の石をもって、その御腕を振り下ろすさまを示される。</span>
<span className="v" id="v31" data-v="31" data-xref="イザヤ書 11:4; イザヤ書 9:4; ミカ書 5:5–6"> 主の御声によってアッシリアはおびえる。主は杖でアッシリアを打たれる。</span>
<span className="v" id="v32" data-v="32" data-xref="イザヤ書 11:15; イザヤ書 19:16; イザヤ書 2:19"> 主が彼の上に下される懲らしめの杖の一打ちごとに、タンバリンと竪琴が鳴る。主は武器を振るいながら彼らと戦われる。</span>
<span className="v" id="v33" data-v="33" data-xref="列王記第二 23:10; 創世記 19:24; エレミヤ書 19:6"> 焼き場は昔から備えられている。王のためにも用意されている。主はその薪の山を深く広くし、火と多くの薪を備えられた。硫黄の流れのような主の息が、それに火をつける。</span>
</div>

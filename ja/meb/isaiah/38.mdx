<span className="v" id="v1" data-v="1" data-xref="イザヤ書 38:1–8; 歴代誌 第二 32:24; 列王記第二 20:1–11"> そのころ、ヒゼキヤは病気になり、死にかかっていた。アモツの子である預言者イザヤが彼のもとに来て言った。「主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「主」は、神の固有名であるヘブライ語のיהוה（ヤハウェ）を表す。">a</a></sup>はこう言われる。『あなたの家を整えなさい。あなたは死ぬ。生きることはない。』」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="マタイ 6:6; 詩篇 91:15; 列王記第一 8:30"> そこでヒゼキヤは顔を壁に向け、主に祈って、</span>
<span className="v" id="v3" data-v="3" data-xref="ヘブル人への手紙 5:7; 詩篇 18:20–27; ヘブル人への手紙 6:10"> 言った。「主よ、どうか思い出してください。私が真実と全き心をもって御前を歩み、あなたの目に良いとされたことを行ってきたことを。」そしてヒゼキヤは激しく泣いた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> すると、主の言葉がイザヤに臨んだ。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 34:5–6; ヨハネの手紙第一 5:14–15; ヨハネの黙示録 7:17"> 「行って、ヒゼキヤに告げなさい。『あなたの父ダビデの神、主はこう言われる。「わたしはあなたの祈りを聞き、あなたの涙を見た。見よ、わたしはあなたの寿命に十五年を加える。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 37:35; イザヤ書 31:4–5; イザヤ書 12:6"> わたしはあなたとこの町をアッシリアの王の手から救い出し、この町を守る。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 6:37–39; イザヤ書 37:30; イザヤ書 7:11–14"> 主が語ったことを行うという、主からのしるしはこれである。</span>
<span className="v" id="v8" data-v="8" data-xref="列王記第二 20:9–11; ヨシュア記 10:12–14; マタイ 16:1"> 見よ、わたしはアハズの日時計の上を、太陽の動きに伴って下った影を十段後ろへ戻す。」』」すると、太陽は日時計の上を下っていた十段を戻った。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="詩篇 18:1; 出エジプト記 15:1–21; ヨブ記 5:18"> ユダの王ヒゼキヤが病気になり、その病気から回復した時に書いたもの。</span>
<span className="v" id="v10" data-v="10" data-xref="詩篇 102:24; コリント人への第二の手紙 1:9; 詩篇 107:18"> <span className="pl pl-1">私は言った。「人生の半ばで、私はよみ</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="よみ（シェオル）は死者の場所である。">b</a></sup><br /><span className="pl pl-1">の門に入る。</span><br /><span className="pl pl-2">私の残された年月は奪われた。」</span></span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 27:13; 詩篇 116:8–9; 詩篇 31:22"> <span className="pl pl-1">私は言った。「私は主</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="ヘブライ語ではיה（ヤハ）である。">c</a></sup><br /><span className="pl pl-1">を見ることはない。</span><br /><span className="pl pl-2">生ける者の地で、主</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="ヘブライ語ではיה（ヤハ）である。">d</a></sup><br /><span className="pl pl-2">を見ることはない。</span><br /><span className="pl pl-2">この世の住民とともに、人を見ることも二度とない。</span></span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 73:14; コリント人への第二の手紙 5:1; ヘブル人への手紙 1:12"> <span className="pl pl-1">私の住まいは取り去られ、</span><br /><span className="pl pl-2">羊飼いの天幕のように、私から運び去られた。</span><br /><span className="pl pl-1">私は織物のように自分の命を巻き上げた。</span><br /><span className="pl pl-2">主は私を織機から切り離す。</span><br /><span className="pl pl-2">昼から夜までのうちに、あなたは私を終わらせられる。</span></span>
<span className="v" id="v13" data-v="13" data-xref="詩篇 51:8; ダニエル書 6:24; 詩篇 50:22"> <span className="pl pl-1">私は朝まで耐え忍んだ。</span><br /><span className="pl pl-2">主は獅子のように私の骨をすべて砕く。</span><br /><span className="pl pl-2">昼から夜までのうちに、あなたは私を終わらせられる。</span></span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 59:11; 詩篇 69:3; 詩篇 123:1–4"> <span className="pl pl-1">私はつばめや鶴のように鳴き、</span><br /><span className="pl pl-2">鳩のようにうめいた。</span><br /><span className="pl pl-2">私の目は上を見続けて弱り果てた。</span><br /><span className="pl pl-2">主よ、私は虐げられている。</span><br /><span className="pl pl-2">私の保証となってください。」</span></span>
<span className="v" id="v15" data-v="15" data-xref="列王記第一 21:27; ヨブ記 7:11; ヨブ記 10:1"> <span className="pl pl-1">私は何と言えばよいのか。</span><br /><span className="pl pl-2">主が私に語り、ご自身でそれを行われた。</span><br /><span className="pl pl-2">私はこの心の苦しみを抱え、残る年月を慎んで歩もう。</span></span>
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 12:10–11; コリント人への第一の手紙 11:32; 詩篇 119:25"> <span className="pl pl-1">主よ、人はこれらによって生きる。</span><br /><span className="pl pl-2">私の霊も、これらによって生かされる。</span><br /><span className="pl pl-2">私を回復させ、生かしてください。</span></span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 43:25; ミカ書 7:18–19; ヨナ書 2:6"> <span className="pl pl-1">見よ、平安のために、私は大きな苦しみを味わった。</span><br /><span className="pl pl-2">しかし、あなたは私の命を愛し、滅びの穴から救い出してくださった。</span><br /><span className="pl pl-2">私のすべての罪を、ご自分の後ろに投げ捨ててくださった。</span></span>
<span className="v" id="v18" data-v="18" data-xref="伝道者の書 9:10; 詩篇 30:9; 詩篇 6:5"> <span className="pl pl-1">よみ</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="よみ（シェオル）は死者の場所である。">e</a></sup><br /><span className="pl pl-1">はあなたをほめたたえず、</span><br /><span className="pl pl-2">死はあなたを祝わない。</span><br /><span className="pl pl-1">穴に下る者たちは、あなたの真実を待ち望めない。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="申命記 6:7; 詩篇 119:175; 詩篇 78:3–6"> <span className="pl pl-1">生きている者、生きている者こそ、今日の私のように、あなたをほめたたえる。</span><br /><span className="pl pl-2">父は子どもたちに、あなたの真実を知らせる。</span></span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 116:2; 詩篇 150:4; 詩篇 145:2"> <span className="pl pl-1">主は私を救ってくださる。</span><br /><span className="pl pl-2">それゆえ、われわれは生きているすべての日々、主の宮で弦楽器に合わせて私の歌を歌おう。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王記第二 20:7–8; マルコ 7:33; ヨハネ 9:6"> イザヤは、「干しいちじくの菓子を持って来て、腫れ物の上に湿布として当てなさい。そうすれば、王は回復する」と言っていた。</span>
<span className="v" id="v22" data-v="22" data-xref="詩篇 118:18–19; 列王記第二 20:8; ヨハネ 5:14"> ヒゼキヤも、「私が主の宮に上るというしるしは何ですか」と尋ねていた。</span>
</div>

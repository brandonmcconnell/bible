<span className="v" id="v1" data-v="1" data-xref="イザヤ書 14:23; イザヤ書 13:1; エレミヤ書 51:42"> 海の荒野についての宣告。<br />南方のつむじ風が吹き荒れるように、それは荒野から、恐るべき地から来る。</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 33:1; エレミヤ書 49:34; 詩篇 60:3"> 厳しい幻が私に告げられた。裏切る者は裏切り、滅ぼす者は滅ぼす。エラムよ、上れ。攻めよ。わたしはメディアのすべての嘆きを終わらせた。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 13:8; 詩篇 48:6; イザヤ書 26:17"> それゆえ、私の腰は苦しみに満ちた。産みの苦しみを味わう女のような痛みが私を捕らえた。痛みのために聞くこともできず、うろたえて見ることもできない。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカ 21:34–36; サムエル記第一 25:36–38; ダニエル書 5:1"> 私の心は震え、恐怖が私を襲った。私が待ち望んだ夕暮れは、私にとっておののきに変わった。</span>
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 51:11; エレミヤ書 51:57; エレミヤ書 51:39"> 彼らは食卓を整え、見張りを立て、食べ、飲む。高官たちよ、立ち上がれ。盾に油を塗れ。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 33:2–7; エゼキエル書 3:17; ハバクク書 2:1–2"> 主は私にこう言われた。「行って、見張りを立てよ。彼が見たことを報告させよ。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 21:9; イザヤ書 37:24; ヘブル人への手紙 2:1"> 二列に並ぶ騎兵の一隊、ろばの一隊、らくだの一隊を見たなら、細心の注意を払い、よく耳を澄ませよ。」</span>
<span className="v" id="v8" data-v="8" data-xref="ハバクク書 2:1–2; イザヤ書 56:10; ペテロの手紙第一 5:8"> 彼は獅子のように叫んだ。「主よ、私は昼の間、絶えず物見の塔に立ち、夜ごとに自分の持ち場についています。</span>
<span className="v" id="v9" data-v="9" data-xref="ヨハネの黙示録 18:2; ヨハネの黙示録 14:8; エレミヤ書 51:8"> 見よ、今、人々の一隊が、騎兵を二列にしてやって来ます。」彼は答えた。「倒れた。バビロンは倒れた。その神々の彫像はすべて地に打ち砕かれた。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 51:33; ミカ書 4:13; 列王記第二 13:7"> わたしの打ち場で打たれた穀物よ。万軍の主、イスラエルの神から聞いたことを、私はあなたがたに告げた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="創世記 25:14; オバデヤ書 1:1–16; アモス書 1:6"> ドマについての宣告。<br />セイルから私に呼びかける者がいる。「見張りよ、夜はどうなっているのか。見張りよ、夜はどうなっているのか。」</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 17:30–32; 使徒の働き 2:37–38; エゼキエル書 18:30–32"> 見張りは言った。「朝が来る。だが、夜もまた来る。尋ねたいなら、尋ねよ。また戻って来なさい。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 25:23–24; 歴代誌上 1:32; エゼキエル書 27:15"> アラビアについての宣告。<br />デダン人の隊商よ、あなたがたはアラビアの茂みで夜を過ごす。</span>
<span className="v" id="v14" data-v="14" data-xref="創世記 25:15; ヨブ記 6:19; ローマ人への手紙 12:20"> テマの地の住民は、渇いている者に水を持って来て、逃れて来た者をパンで迎えた。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨブ記 6:19–20; イザヤ書 13:14"> 彼らは剣から、抜かれた剣から、引き絞られた弓から、激しい戦いから逃げて来たからだ。</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 120:5; イザヤ書 60:7; イザヤ書 16:14"> 主は私にこう言われた。「雇われ人が数えるように、一年以内に、ケダルのすべての栄光は消え失せる。</span>
<span className="v" id="v17" data-v="17" data-xref="ゼカリヤ書 1:6; 民数記 23:19; マタイ 24:35"> ケダルの子らのうち、弓を引く勇士たちも、残る者はわずかになる。主、イスラエルの神がこれを語られたからだ。」</span>

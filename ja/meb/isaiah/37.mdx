<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王記第二 19:1–37; エズラ記 9:5; イザヤ書 36:22–38"> ヒゼキヤ王はそれを聞くと、衣を裂き、粗布をまとって主の宮に入った。</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 1:1; 列王記第二 18:18; イザヤ書 36:3"> そして、王宮をつかさどるエルヤキム、書記官シェブナ、祭司の長老たちに粗布をまとわせ、アモツの子である預言者イザヤのもとへ遣わした。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 66:9; ホセア書 13:13; イザヤ書 26:17–18"> 彼らはイザヤに言った。「ヒゼキヤはこう言っています。『今日は苦難と叱責と拒絶の日です。子どもが生まれようとしているのに、産み出す力がないからです。</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 1:9; イザヤ書 36:20; イザヤ書 10:22"> おそらく、あなたの神、主は、彼の主人であるアッシリアの王が生ける神を侮るために遣わしたラブ・シャケの言葉を聞き、その言葉を責めてくださるでしょう。それゆえ、残されている残りの者のために祈りをささげてください。』」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> こうして、ヒゼキヤ王のしもべたちはイザヤのもとへ来た。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 7:4; イザヤ書 35:4; マルコ 5:36"> イザヤは彼らに言った。「あなたがたの主人にこう告げなさい。『主はこう言われる。「あなたが聞いた言葉を恐れてはならない。アッシリアの王のしもべたちは、その言葉でわたしを冒涜した。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 31:8–9; 歴代誌 第二 32:21; イザヤ書 33:10–12"> 見よ、わたしは彼のうちに一つの霊を置く。彼はある知らせを聞いて、自分の国へ帰る。わたしは彼を自分の国で剣に倒れさせる。」』」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ヨシュア記 10:29; 民数記 33:20–21; 列王記第二 19:8–9"> ラブ・シャケは帰って、アッシリアの王がリブナと戦っているのを見た。王がラキシュを去ったことを聞いていたからである。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 18:1; イザヤ書 20:5; イザヤ書 37:7"> 王はエチオピアの王ティルハカについて、「彼はあなたと戦うために出て来た」との知らせを聞いた。王はそれを聞くと、ヒゼキヤに使者を遣わして言った。</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 36:15; 列王記第二 18:5; マタイ 27:43"> 「ユダの王ヒゼキヤにこう告げよ。『あなたが信頼している神に欺かれてはならない。その神は、「エルサレムはアッシリアの王の手に渡されない」と言っている。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 36:18–20; 列王記第二 18:33–35; イザヤ書 14:17"> 見よ、あなたはアッシリアの王たちがすべての国々を完全に滅ぼすために行ったことを聞いている。それでも、あなたは救い出されるのか。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 11:31; 列王記第二 17:6; 列王記第二 18:11"> 私の父祖たちが滅ぼしたゴザン、ハラン、レツェフ、テラサルにいたエデンの子らを、諸国の神々は救い出したか。</span>
<span className="v" id="v13" data-v="13" data-xref="列王記第二 19:13; 列王記第二 17:24; イザヤ書 36:19"> ハマテの王、アルパデの王、セファルワイムの町の王、ヘナとイワの王はどこにいるのか。』」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王記第二 19:14; 詩篇 123:1–4; ヨエル書 2:17–20"> ヒゼキヤは使者たちの手から手紙を受け取り、それを読んだ。それからヒゼキヤは主の宮に上り、それを主の前に広げた。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記第一 7:8–9; ダニエル書 9:3–4; ヤコブの手紙 5:13"> ヒゼキヤは主に祈って言った。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 25:22; 詩篇 99:1; 詩篇 86:10"> 「ケルビムの間で王座に着いておられるイスラエルの神、万軍の主よ、地のすべての王国の神は、あなただけです。あなたは天と地を造られました。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代誌 第二 6:40; 詩篇 17:6; イザヤ書 37:4"> 主よ、耳を傾けて聞いてください。主よ、目を開いて見てください。生ける神を侮るためにセナケリブが送ったすべての言葉を聞いてください。</span>
<span className="v" id="v18" data-v="18" data-xref="ナホム書 2:11–12; 列王記第二 15:29; 列王記第二 17:6"> 主よ、確かにアッシリアの王たちは、すべての国々とその土地を滅ぼし、</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 44:9–10; エレミヤ書 10:11; ホセア書 8:6"> その神々を火に投げ込みました。それらは神ではなく、人の手で造られた木や石にすぎなかったので、彼らはそれらを滅ぼすことができたのです。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 46:10; 列王記第一 18:36–37; 詩篇 83:17–18"> それゆえ今、われわれの神、主よ、どうか彼の手からわれわれを救ってください。地のすべての王国が、あなただけが主であることを知るためです。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 58:9; イザヤ書 38:3–6; 使徒の働き 4:31"> すると、アモツの子イザヤはヒゼキヤに人を遣わして言った。「イスラエルの神、主はこう言われる。『あなたがアッシリアの王セナケリブについてわたしに祈ったので、</span>
<span className="v" id="v22" data-v="22" data-xref="ヨブ記 16:4; 哀歌 2:13; イザヤ書 1:8"> 主が彼について語られた言葉はこれである。処女であるシオンの娘は、あなたを侮り、あざ笑った。エルサレムの娘は、あなたの後ろで頭を振った。</span>
<span className="v" id="v23" data-v="23" data-xref="エゼキエル書 39:7; ダニエル書 5:20–23; イザヤ書 17:7"> あなたはだれを侮り、冒涜したのか。だれに向かって声を上げ、高ぶって目を上げたのか。イスラエルの聖なる方に対してである。</span>
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 14:8; イザヤ書 10:18; 出エジプト記 15:9"> あなたはしもべたちを通して主を侮り、こう言った。「私はおびただしい戦車を率いて山々の高い所に上り、レバノンの奥深くにまで来た。その高くそびえる杉と選り抜きの糸杉を切り倒そう。その最も遠い高みに入り、その実り豊かな森に入ろう。</span>
<span className="v" id="v25" data-v="25" data-xref="列王記第一 20:10; イザヤ書 36:12; 列王記第二 19:23–24"> 私は井戸を掘って水を飲んだ。足の裏でエジプトのすべての川を干上がらせよう。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 4:27–28; 使徒の働き 2:23; ペテロの手紙第一 2:8"> 「あなたは聞かなかったのか。わたしが遠い昔にそれを行い、古代にそれを定めたことを。今、わたしはそれを実現させた。あなたが城壁のある町々を滅ぼし、瓦礫の山とするためである。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 129:6; 詩篇 37:2; ペテロの手紙第一 1:24"> その住民は力を失い、うろたえ、恥じた。彼らは野の草、若草、屋根の上の草、育つ前に枯れる畑の草のようになった。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 2:13; 詩篇 139:1–11; エレミヤ書 23:23–24"> しかし、わたしはあなたが座る時も、出て行く時も、入って来る時も、わたしに対して荒れ狂うことも知っている。</span>
<span className="v" id="v29" data-v="29" data-xref="エゼキエル書 38:4; イザヤ書 30:28; イザヤ書 37:34"> あなたがわたしに対して荒れ狂い、あなたの傲慢がわたしの耳に届いたので、わたしはあなたの鼻に鉤を掛け、あなたの唇にくつわをはめ、あなたが来た道を通って引き返させる。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="列王記第二 19:29; レビ記 25:4–5; 列王記第一 13:3–5"> 「これがあなたへのしるしとなる。今年は自然に生えたものを食べ、二年目にはそこから生えたものを食べる。三年目には種をまいて刈り入れ、ぶどう畑を植えて、その実を食べる。</span>
<span className="v" id="v31" data-v="31" data-xref="イザヤ書 27:6; 列王記第二 19:30–31; 詩篇 80:9"> ユダの家の逃れた残りの者は、再び下に根を張り、上に実を結ぶ。</span>
<span className="v" id="v32" data-v="32" data-xref="イザヤ書 9:7; 列王記第二 19:31; イザヤ書 59:17"> エルサレムから残りの者が出て来て、シオン山から生き残った者たちが出て来るからだ。万軍の主の熱意がこれを成し遂げる。』</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="イザヤ書 17:12; イザヤ書 10:32–34; イザヤ書 17:14"> 「それゆえ、主はアッシリアの王についてこう言われる。『彼はこの町に来ず、ここに矢を射ることもない。盾を持ってその前に進むことも、これに向かって土塁を築くこともない。</span>
<span className="v" id="v34" data-v="34" data-xref="イザヤ書 37:29; 箴言 21:30"> 彼は来た道を通って帰り、この町には入らない』と主は言われる。</span>
<span className="v" id="v35" data-v="35" data-xref="列王記第二 20:6; イザヤ書 38:6; イザヤ書 31:5"> 『わたしは自分のため、またわたしのしもべダビデのために、この町を守って救う。』」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="イザヤ書 10:12; 列王記第二 19:35; イザヤ書 10:33–34"> その時、主の使いが出て行き、アッシリア人の陣営で十八万五千人を打った。人々が朝早く起きると、見よ、彼らはみな死体となっていた。</span>
<span className="v" id="v37" data-v="37" data-xref="ヨナ書 1:2; ヨナ書 3:3; 創世記 10:11–12"> そこで、アッシリアの王セナケリブは出発して去り、ニネベに帰って、そこにとどまった。</span>
<span className="v" id="v38" data-v="38" data-xref="創世記 8:4; エレミヤ書 51:27; エズラ記 4:2"> 彼が自分の神ニスロクの神殿で礼拝していた時、その息子アデラメレクとシャレツェルが剣で彼を打ち殺した。彼らはアララテの地へ逃げた。セナケリブの子エサル・ハドンが代わって王となった。</span>
</div>

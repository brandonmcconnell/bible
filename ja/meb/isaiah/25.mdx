<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 15:2; 詩篇 118:28; 民数記 23:19"> 主よ、あなたは私の神。私はあなたをあがめ、御名をほめたたえる。あなたは不思議なことを行われた。遠い昔に定めた計画を、揺るぎない真実をもって成し遂げられた。</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 17:1; イザヤ書 13:22; イザヤ書 25:12"> あなたは町を瓦礫の山とし、城壁のある町を廃墟とされた。よそ者たちの宮殿は町でなくなり、二度と建て直されない。</span>
<span className="v" id="v3" data-v="3" data-xref="ゼカリヤ書 14:9; イザヤ書 49:23–26; 詩篇 46:10–11"> それゆえ、強い民はあなたに栄光を帰し、恐るべき諸国の町はあなたを恐れる。</span>
<span className="v" id="v4" data-v="4" data-xref="ゼパニヤ書 3:12; イザヤ書 32:2; ヤコブの手紙 2:5"> あなたは貧しい者のとりで、困窮する者が苦しむ時のとりで、嵐からの逃れ場、暑さを避ける陰となられた。恐るべき者たちの猛威は、城壁を打つ嵐のようだった。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネの黙示録 20:8–9; イザヤ書 49:10; 詩篇 105:39"> 乾いた地の暑さを静めるように、あなたはよそ者たちの騒ぎを静められた。雲の陰が暑さを静めるように、恐るべき者たちの歌声を鎮められた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="マタイ 8:11; 詩篇 63:5; ゼカリヤ書 9:16–17"> 万軍の主は、この山ですべての民のために、選りすぐった肉<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="直訳では「脂肪の多いもの」。">a</a></sup>の宴、上等なぶどう酒の宴を催される。髄に満ちた選りすぐった肉と、よくこされた上等なぶどう酒の宴である。</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 4:18; イザヤ書 60:1–3; マタイ 27:51"> 主はこの山で、すべての民を覆う覆いと、すべての国々の上に広げられた幕を取り除かれる。</span>
<span className="v" id="v8" data-v="8" data-xref="ヨハネの黙示録 21:4; ヨハネの黙示録 7:17; コリント人への第一の手紙 15:54"> 主は死を永遠にのみ込まれる。主なる神は、すべての顔から涙をぬぐい、ご自分の民の受けた辱めを全地から取り除かれる。主がこれを語られた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="詩篇 27:14; 創世記 49:18; ミカ書 7:7"> その日、人々は言う。「見よ、この方こそわれわれの神。われわれはこの方を待ち望んだ。この方はわれわれを救ってくださる。この方こそ主。われわれはこの方を待ち望んだ。その救いを喜び、楽しもう。」</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 25:6; イザヤ書 18:4; ゼパニヤ書 2:9"> 主の御手がこの山の上にとどまる。<br />モアブはその場所で、肥だめの水の中でわらが踏みつけられるように踏みつけられる。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 16:14; イザヤ書 2:11; イザヤ書 16:6"> 泳ぐ者が泳ぐために両手を広げるように、モアブはその中で両手を広げる。しかし、主はその高ぶりを、その手の策略とともに低くされる。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 26:5; ヨハネの黙示録 18:21; イザヤ書 14:23"> 主はあなたの城壁の高い要塞を引き倒し、低くし、地に、ちりにまで打ち倒す。</span>
</div>

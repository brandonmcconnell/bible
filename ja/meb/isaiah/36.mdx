<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌 第二 32:1; 列王記第二 18:13; 列王記第二 18:17"> ヒゼキヤ王の第十四年に、アッシリアの王セナケリブがユダの城壁のあるすべての町々を攻め、これを占領した。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代誌 第二 32:9–23; イザヤ書 7:3; 列王記第二 18:17–37"> アッシリアの王は、ラキシュからラブ・シャケを大軍とともにエルサレムのヒゼキヤ王のもとへ遣わした。ラブ・シャケは、布さらしの野へ向かう大路にある、上の池の水路のそばに立った。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記第二 8:16–17; イザヤ書 22:15–21; サムエル記第二 20:24–25"> すると、王宮をつかさどるヒルキヤの子エルヤキム、書記官シェブナ、記録官であるアサフの子ヨアフが、彼のもとへ出て行った。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王記第二 18:19–37; ユダ 1:16; 箴言 16:18"> ラブ・シャケは彼らに言った。「ヒゼキヤにこう告げなさい。『大王、アッシリアの王はこう言う。「あなたが頼りにしているその自信は、いったい何なのか。</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第二 18:7; エレミヤ書 52:3; 箴言 21:30–31"> 戦いのための助言と力があると言うが、それはただのむなしい言葉にすぎない。今、あなたはだれに頼って、私に背いたのか。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 29:6–7; エレミヤ書 37:5–8; 列王記第二 18:21"> 見よ、あなたはこの傷ついた葦の杖、すなわちエジプトに頼っている。それに寄りかかる者がいれば、それはその手に刺さり、貫く。エジプトの王ファラオは、彼に頼るすべての者にとって、そのような者だ。</span>
<span className="v" id="v7" data-v="7" data-xref="列王記第二 18:4–5; 詩篇 42:10–11; 詩篇 42:5"> しかし、あなたが私に、『われわれは、われわれの神、主に信頼している』と言うなら、その主とは、ヒゼキヤがその高き所と祭壇を取り除き、ユダとエルサレムに、『あなたがたはこの祭壇の前で礼拝しなければならない』と言った方ではないか。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記第一 17:40–43; 列王記第一 20:10; ネヘミヤ記 4:2–5"> それなら今、どうか私の主人、アッシリアの王と賭けをしてみなさい。あなたの側で乗り手を用意できるなら、私はあなたに二千頭の馬を与えよう。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 10:8; イザヤ書 30:16–17; イザヤ書 36:6"> あなたは、私の主人の最も小さいしもべの一隊長さえ、どうして退けることができるのか。戦車と騎兵を得ようと、エジプトに頼っているのか。</span>
<span className="v" id="v10" data-v="10" data-xref="列王記第二 18:25; イザヤ書 10:5–7; 列王記第一 13:18"> 今、私が主によらずにこの地を滅ぼすために攻め上って来たとでもいうのか。主が私に、『この地に攻め上り、これを滅ぼせ』と言われたのだ」』」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エズラ記 4:7; ダニエル書 2:4; 列王記第二 18:26–27"> そこでエルヤキムとシェブナとヨアフは、ラブ・シャケに言った。「どうか、しもべたちにはアラム語で話してください。私たちはそれを理解できます。城壁の上にいる民に聞こえるところで、私たちにユダヤ語で話さないでください。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王記第二 18:27; レビ記 26:29; 哀歌 4:9–10"> しかし、ラブ・シャケは言った。「私の主人は、これらの言葉を語るために、あなたの主人とあなたにだけ私を遣わしたのか。城壁の上に座り、あなたがたとともに自分の糞を食べ、自分の尿を飲むことになる者たちにも遣わしたのではないか。」</span>
<span className="v" id="v13" data-v="13" data-xref="歴代誌 第二 32:18; 詩篇 73:8–9; 列王記第二 18:28–32"> それからラブ・シャケは立ち上がり、ユダヤ語で大声に叫んで言った。「大王、アッシリアの王の言葉を聞け。</span>
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への第二の手紙 2:4; ヨハネの黙示録 13:5–6; ダニエル書 6:20"> 王はこう言う。『ヒゼキヤにだまされてはならない。彼はあなたがたを救い出すことができない。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 37:23–24; マタイ 27:43; 詩篇 71:9–11"> ヒゼキヤに、「主は必ずわれわれを救い出してくださる。この町がアッシリアの王の手に渡されることはない」と言って、あなたがたを主に信頼させてはならない。』</span>
<span className="v" id="v16" data-v="16" data-xref="列王記第一 4:25; ゼカリヤ書 3:10; ミカ書 4:4"> ヒゼキヤの言うことを聞いてはならない。アッシリアの王はこう言うからだ。『私と和平を結び、私のもとへ出て来なさい。そうすれば、あなたがたはそれぞれ自分のぶどうの木の実を食べ、自分のいちじくの木の実を食べ、それぞれ自分の水ための水を飲むことができる。</span>
<span className="v" id="v17" data-v="17" data-xref="列王記第二 18:32; 申命記 8:7–9; ヨブ記 20:17"> やがて私が来て、あなたがたの国のような国へあなたがたを連れて行く。そこは穀物と新しいぶどう酒の地、パンとぶどう畑の地である。</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 37:17–18; イザヤ書 36:15; イザヤ書 37:10"> ヒゼキヤが、「主はわれわれを救い出してくださる」と言って、あなたがたを説き伏せないように気をつけよ。諸国の神々のうち、アッシリアの王の手から自分の国を救い出した神があったか。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 10:9–11; エレミヤ書 49:23; サムエル記第二 8:9"> ハマテとアルパデの神々はどこにいるのか。セファルワイムの神々はどこにいるのか。彼らはサマリアを私の手から救い出したか。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 50:21; 歴代誌 第二 32:19; イザヤ書 37:23–29"> これらすべての国々の神々のうち、だれが自分の国を私の手から救い出したというのか。主がエルサレムを私の手から救い出せるとでもいうのか。』」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="箴言 26:4; 詩篇 38:13–15; マタイ 7:6"> しかし、彼らは黙ったまま、一言も答えなかった。王が「彼に答えてはならない」と命じていたからだ。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 36:3; イザヤ書 33:7; マタイ 26:65"> それから、王宮をつかさどるヒルキヤの子エルヤキム、書記官シェブナ、記録官であるアサフの子ヨアフは、衣を裂いてヒゼキヤのもとへ行き、ラブ・シャケの言葉を彼に告げた。</span>
</div>
</div>

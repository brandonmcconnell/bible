<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出エジプト記 12:12; ヨハネの黙示録 1:7; ヨシュア記 2:11"> エジプトについての宣告。<br />「見よ、主は速い雲に乗ってエジプトに来る。エジプトの偶像はその前で震え、エジプト人の心は内で溶ける。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 7:22; サムエル記第一 14:20; マタイ 10:36"> わたしはエジプト人をエジプト人に対して奮い立たせる。彼らはそれぞれ自分の兄弟と戦い、それぞれ自分の隣人と戦う。町は町と、王国は王国と戦う。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 8:19; ダニエル書 2:2; 歴代誌上 10:13"> エジプト人の霊はその内で力を失う。わたしは彼らの計画を打ち砕く。彼らは偶像、呪術師、霊媒、魔術師に尋ねる。</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 20:4; エレミヤ書 46:26; エゼキエル書 29:19"> わたしはエジプト人を残酷な主人の手に渡す。荒々しい王が彼らを支配する」と主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「主」は、神の固有名であるヘブライ語のיהוה（ヤハウェ）を表す。">a</a></sup>、万軍の主は言う。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="エレミヤ書 51:36; エゼキエル書 30:12; ゼカリヤ書 14:18"> 海から水が失われ、川は干上がって乾く。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 37:25; 出エジプト記 7:18; 列王記第二 19:24"> 川々は悪臭を放ち、エジプトの水路は水が減って干上がる。葦とい草は枯れる。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 32:20; ヨエル書 1:17–18; イザヤ書 23:3"> ナイル川のほとり、その岸辺の草地と、ナイル川のそばにまかれたすべての畑は乾き、吹き飛ばされ、消え失せる。</span>
<span className="v" id="v8" data-v="8" data-xref="エゼキエル書 47:10; ハバクク書 1:15; 民数記 11:5"> 漁師たちは嘆き、ナイル川に釣り針を投げる者はみな悲しみ、水の上に網を広げる者たちは力を失う。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 27:7; 箴言 7:16; 列王記第一 10:28"> 梳いた亜麻を加工する者と、白い布を織る者は恥じる。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 11:10; 出エジプト記 7:19; 出エジプト記 8:5"> その柱は打ち砕かれ、賃金のために働く者はみな心を痛める。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民数記 13:22; 使徒の働き 7:22; 列王記第一 4:30"> ツォアンの高官たちは全く愚かである。ファラオの最も賢い助言者たちの進言も愚かなものとなった。どうしてあなたがたはファラオに、「私は知恵ある者たちの子、昔の王たちの子です」と言えるのか。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 1:20; イザヤ書 14:24; 士師記 9:38"> では、あなたの知恵ある者たちはどこにいるのか。万軍の主がエジプトについて何を計画したのかを、今、彼らにあなたへ告げさせよ。</span>
<span className="v" id="v13" data-v="13" data-xref="エゼキエル書 30:13; エレミヤ書 2:16; エレミヤ書 46:14"> ツォアンの高官たちは愚かになり、メンフィスの高官たちは欺かれた。エジプトの諸部族の礎である者たちが、エジプトを迷わせた。</span>
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への第二の手紙 2:11; 列王記第一 22:20–23; エゼキエル書 14:7–9"> 主はそのただ中にねじれた霊を混ぜた。彼らは、酔った者が自分の吐いた物の中でよろめくように、エジプトのすべての働きを迷わせた。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 9:14–15; テサロニケ人への手紙第一 4:11–12; 箴言 14:23"> エジプトには、頭にも尾にも、なつめやしの枝にも葦にも、できる仕事が何もなくなる。</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 51:30; ナホム書 3:13; イザヤ書 11:15"> その日、エジプト人は女たちのようになり、万軍の主が彼らの上に振りかざす手を見て、震え恐れる。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 14:24; ダニエル書 4:35; エゼキエル書 29:6–7"> ユダの地はエジプトにとって恐怖となる。その名を聞く者はみな、万軍の主がエジプトに対して定められた計画のために恐れる。</span>
<span className="v" id="v18" data-v="18" data-xref="ゼパニヤ書 3:9; ゼカリヤ書 2:11; イザヤ書 19:21"> その日、エジプトの地には、カナンの言語を語り、万軍の主に誓う五つの町がある。その一つは「滅びの町」と呼ばれる。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="創世記 28:18; ヨシュア記 22:10; ヨシュア記 22:26"> その日、エジプトの地の中央には主のための祭壇があり、その国境には主のための柱がある。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 50:15; テトス 2:13; イザヤ書 45:21–22"> それはエジプトの地で万軍の主のためのしるしとなり、あかしとなる。彼らが虐げる者たちに苦しめられて主に叫ぶと、主は彼らに救い主と擁護者を遣わし、彼らを救い出す。</span>
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 11:9; マラキ書 1:11; ヨハネ 17:3"> 主はエジプトにご自分を知らせ、エジプト人はその日に主を知る。彼らはいけにえとささげ物をもって礼拝し、主に誓願を立て、それを果たす。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 32:39; ヘブル人への手紙 12:11; ホセア書 14:1"> 主はエジプトを打つが、また癒やす。彼らは主に立ち返り、主は彼らの願いを聞き入れ、彼らを癒やす。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 11:16; エペソ人への手紙 2:18–22; イザヤ書 35:8–10"> その日、エジプトからアッシリアへ通じる大路ができる。アッシリア人はエジプトへ行き、エジプト人はアッシリアへ行く。エジプト人はアッシリア人とともに礼拝する。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 65:8; 創世記 12:2; ガラテヤ人への手紙 3:14"> その日、イスラエルはエジプト、アッシリアと並ぶ第三の国となり、地のただ中で祝福となる。</span>
<span className="v" id="v25" data-v="25" data-xref="イザヤ書 29:23; ホセア書 2:23; ローマ人への手紙 9:24–25"> 万軍の主が彼らを祝福して言うからだ。「わたしの民エジプト、わたしの手の業であるアッシリア、わたしの相続財産であるイスラエルは幸いである。」</span>
</div>

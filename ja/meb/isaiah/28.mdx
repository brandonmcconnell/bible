<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ホセア書 7:5; イザヤ書 28:7; 列王記第二 14:25–27"> ぶどう酒に酔いつぶれたエフライムの者たちの高ぶりの冠と、その栄光ある美しさのしおれゆく花に災いがある。それは、ぶどう酒に打ち負かされた者たちの肥沃な谷の頂にある。</span>
<span className="v" id="v2" data-v="2" data-xref="イザヤ書 30:30; ナホム書 1:8; エゼキエル書 13:11"> 見よ、主には力に満ちた強い者がおられる。雹の嵐、破壊する暴風、あふれる大水の激しい嵐のように、主は御手で彼らを地に投げ倒される。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 26:6; ヘブル人への手紙 10:29; ヨハネの黙示録 11:2"> ぶどう酒に酔いつぶれたエフライムの者たちの高ぶりの冠は、足で踏みつけられる。</span>
<span className="v" id="v4" data-v="4" data-xref="ナホム書 3:12; ミカ書 7:1; イザヤ書 28:1"> 肥沃な谷の頂にある、その栄光ある美しさのしおれゆく花は、夏前に熟す初物のいちじくのようになる。見つけた者は、それを見るとすぐに摘み取って食べる。</span>
<span className="v" id="v5" data-v="5" data-xref="ペテロの手紙第一 5:4; イザヤ書 62:3; イザヤ書 60:19"> その日、万軍の主は、ご自分の民の残りの者にとって、栄光の冠、美しい冠となられる。</span>
<span className="v" id="v6" data-v="6" data-xref="詩篇 18:32–34; ヨハネ 5:30; ヨシュア記 1:9"> また、裁きの座に着く者には公正の霊となり、門で戦いを押し返す者たちには力となられる。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 56:10–12; ルカ 21:34; イザヤ書 19:14"> しかし、この者たちもぶどう酒によろめき、濃い酒にふらつく。祭司と預言者も濃い酒によろめく。彼らはぶどう酒にのみ込まれ、濃い酒にふらつく。幻を見ても誤り、裁きを行ってもつまずく。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 48:26; 箴言 26:11; ハバクク書 2:15–16"> すべての食卓は汚らしい吐いたものと汚物でいっぱいで、きれいな場所は一つもない。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="詩篇 131:2; エレミヤ書 6:10; ヨハネ 12:38"> 彼はだれに知識を教えるのか。だれにその教えを説明するのか。乳離れした者たち、乳房から離された者たちにか。</span>
<span className="v" id="v10" data-v="10" data-xref="イザヤ書 28:13; テモテへの第二の手紙 3:7; エレミヤ書 11:7"> 命令に命令、命令に命令。線に線、線に線。ここに少し、そこに少し。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 14:21; 申命記 28:49; イザヤ書 33:19"> しかし主は、どもる唇と異国の言葉をもって、この民に語られる。</span>
<span className="v" id="v12" data-v="12" data-xref="マタイ 11:28–29; イザヤ書 30:15; エレミヤ書 6:16"> 主は彼らに、「ここが休み場である。疲れた者を休ませよ」「ここが憩いの場所である」と言われた。それでも彼らは聞こうとしなかった。</span>
<span className="v" id="v13" data-v="13" data-xref="マタイ 13:14; イザヤ書 6:9–10; ペテロの第二の手紙 3:16"> それゆえ、主の言葉は彼らにとって、「命令に命令、命令に命令。線に線、線に線。ここに少し、そこに少し」となる。そのため、彼らは進んでは後ろに倒れ、砕かれ、罠にかかり、捕らえられる。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 28:22; イザヤ書 29:20; イザヤ書 1:10"> それゆえ、エルサレムでこの民を治める、あざける者たちよ、主の言葉を聞け。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 8:7–8; エゼキエル書 13:22; アモス書 2:4"> あなたがたはこう言った。「われわれは死と契約を結び、よみ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="よみ（シェオル）は死者の場所である。">a</a></sup>と協定を結んだ。押し寄せるむちが通り過ぎても、われわれのところには来ない。われわれは偽りを逃れ場とし、虚偽の下に身を隠したからだ。」</span>
<span className="v" id="v16" data-v="16" data-xref="詩篇 118:22; 使徒の働き 4:11–12; ペテロの手紙第一 2:6–8"> それゆえ、主なる神はこう言われる。「見よ、わたしはシオンに一つの石を土台として据える。試された石、確かな土台となる尊い隅の礎石である。信じる者は慌てることがない。</span>
<span className="v" id="v17" data-v="17" data-xref="列王記第二 21:13; アモス書 7:7–9; ヨハネの黙示録 16:21"> わたしは公正を測り縄とし、義を下げ振りとする。雹は偽りの逃れ場を一掃し、水は隠れ場にあふれる。</span>
<span className="v" id="v18" data-v="18" data-xref="イザヤ書 7:7; イザヤ書 8:10; イザヤ書 28:15"> あなたがたの死との契約は無効となり、よみ<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="よみ（シェオル）は死者の場所である。">b</a></sup>との協定は成立しない。押し寄せるむちが通り過ぎる時、あなたがたはそれに踏みにじられる。</span>
<span className="v" id="v19" data-v="19" data-xref="ハバクク書 3:16; イザヤ書 36:22; 列王記第二 24:2"> それが通るたびに、あなたがたを捕らえる。それは朝ごとに、昼も夜も通り過ぎる。その知らせを聞き取るだけでも、恐怖となる。」</span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 64:6; コリント人への第一の手紙 1:18–31; ローマ人への手紙 9:30–32"> 体を伸ばして寝るには寝床が短すぎ、身を包むには上掛けが狭すぎる。</span>
<span className="v" id="v21" data-v="21" data-xref="歴代誌上 14:11; ヨシュア記 10:12; サムエル記第二 5:20"> 主はペラツィム山で立ち上がった時のように立ち上がり、ギブオンの谷で怒った時のように怒られる。それはご自分の業、異例の業を行い、ご自分の働き、並外れた働きを成し遂げるためである。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 10:22–23; イザヤ書 24:1–23; マタイ 27:44"> それゆえ今、あざけってはならない。そうしなければ、あなたがたの束縛はさらに強くなる。私は主<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「主」は、神の固有名であるヘブライ語のיהוה（ヤハウェ）を表す。">c</a></sup>、万軍の主から、全地に対して滅びが定められたことを聞いたからだ。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 1:2; エレミヤ書 22:29; ヨハネの黙示録 2:11"> 耳を傾けて、私の声を聞け。注意を払い、私の言葉を聞け。</span>
<span className="v" id="v24" data-v="24" data-xref="エレミヤ書 4:3; ホセア書 10:11–12"> 種をまくために耕す者は、絶えず耕し続けるだろうか。いつまでも土を掘り返し、土くれを砕き続けるだろうか。</span>
<span className="v" id="v25" data-v="25" data-xref="エゼキエル書 4:9; マタイ 23:23; 出エジプト記 9:31–32"> 地面を平らにしたなら、ディルをまき、クミンの種を散らし、小麦を畝に植え、大麦を定められた場所に、スペルト小麦をその場所に植えるではないか。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 31:3–6; 出エジプト記 36:2; ヨブ記 39:17"> その人の神が正しい仕方を教え、彼を導かれるからだ。</span>
<span className="v" id="v27" data-v="27" data-xref="イザヤ書 41:15; イザヤ書 27:7–8; エレミヤ書 46:28"> ディルは鋭い脱穀器で脱穀せず、クミンの上で荷車の車輪を転がすこともしない。ディルは棒で打ち、クミンは杖で打つ。</span>
<span className="v" id="v28" data-v="28" data-xref="コリント人への第一の手紙 9:9–10; マタイ 3:12; ヨハネ 12:24"> パン用の穀物は砕かなければならない。しかし、いつまでも脱穀し続けることはない。脱穀用の荷車の車輪をその上に走らせても、馬にそれを砕かせることはない。</span>
<span className="v" id="v29" data-v="29" data-xref="ローマ人への手紙 11:33; エレミヤ書 32:19; ヨブ記 5:9"> これも万軍の主から出る。その助言は不思議で、その知恵は優れている。</span>
</div>

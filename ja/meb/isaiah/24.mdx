<span className="v" id="v1" data-v="1" data-xref="ナホム書 2:10; イザヤ書 2:19; イザヤ書 42:15"> 見よ、主は地を空にして荒れ果てさせ、その面を覆し、住民を散らされる。</span>
<span className="v" id="v2" data-v="2" data-xref="ホセア書 4:9; 哀歌 5:12–14; エゼキエル書 7:12–13"> 民も祭司も同じようになり、しもべも主人も、女奴隷も女主人も、買う者も売る者も、貸す者も借りる者も、利息を取る者も利息を払う者も同じようになる。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 24:1; イザヤ書 6:11; 申命記 29:23"> 地は完全に空にされ、徹底的に荒れ果てる。主がこの言葉を語られたからだ。</span>
<span className="v" id="v4" data-v="4" data-xref="ホセア書 4:3; イザヤ書 33:9; イザヤ書 3:26"> 地は悲しみ、衰える。世界は弱り、衰える。地の高ぶる者たちも弱り果てる。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 13:20; ローマ人への手紙 8:20–21; ダニエル書 7:25"> 地はその住民の下で汚された。彼らが律法に背き、定めを破り、永遠の契約を破ったからだ。</span>
<span className="v" id="v6" data-v="6" data-xref="マラキ書 4:1; マタイ 7:14; ゼカリヤ書 5:3–4"> それゆえ、呪いが地を食い尽くし、そこに住む者たちは罪に定められる。それゆえ、地の住民は焼かれ、残る人はわずかになる。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 16:10; ヨエル書 1:10–12; イザヤ書 16:8"> 新しいぶどう酒は悲しみ、ぶどうの木は衰える。心の喜びに満ちていた者たちはみな嘆く。</span>
<span className="v" id="v8" data-v="8" data-xref="ホセア書 2:11; ヨハネの黙示録 18:22; エゼキエル書 26:13"> タンバリンの楽しみはやみ、喜ぶ者たちの騒ぎは終わり、竪琴の喜びの音もやむ。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 5:22; 伝道者の書 9:7; イザヤ書 5:20"> 人々は歌いながらぶどう酒を飲むことはない。濃い酒は、それを飲む者にとって苦くなる。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネの黙示録 18:2; ヨハネの黙示録 17:5–6; イザヤ書 24:12"> 混乱の町は崩され、どの家も閉ざされて、だれも入れない。</span>
<span className="v" id="v11" data-v="11" data-xref="ホセア書 7:14; イザヤ書 24:7–9; エレミヤ書 48:33"> ぶどう酒がないため、通りには叫び声がある。すべての喜びは暗くなり、地の楽しみは消え去った。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 9:11; ミカ書 1:12; 哀歌 5:18"> 町には荒廃だけが残り、門は打ち砕かれている。</span>
<span className="v" id="v13" data-v="13" data-xref="イザヤ書 1:9; エゼキエル書 6:8–11; エゼキエル書 11:16–20"> 地の中、諸国の民の間では、オリーブの木を揺すった後のように、ぶどうの収穫後に落ち穂を拾う時のようになる。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 40:9; エレミヤ書 31:12; イザヤ書 54:1"> 残った者たちは声を上げる。主の威厳のために喜び叫び、海のかなたから声高らかに叫ぶ。</span>
<span className="v" id="v15" data-v="15" data-xref="マラキ書 1:11; イザヤ書 42:4; イザヤ書 60:9"> それゆえ、東で主をあがめよ。海の島々で、主、イスラエルの神の御名をあがめよ。</span>
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 21:2; エレミヤ書 5:11; イザヤ書 33:1"> 地の果てから、われわれは歌を聞いた。「義人に栄光あれ。」<br />しかし、私は言った。「私はやせ衰える。私はやせ衰える。ああ、災いだ。」裏切る者たちは裏切った。まことに、裏切る者たちは大いに裏切った。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 48:43–44; 列王記第一 19:17; レビ記 26:21–22"> 地に住む者よ、恐怖と穴と罠があなたに臨む。</span>
<span className="v" id="v18" data-v="18" data-xref="創世記 7:11; 詩篇 18:7; ヨシュア記 10:10–11"> 恐怖の音から逃げる者は穴に落ち、穴の中からはい上がる者は罠に捕らえられる。上の窓が開かれ、地の基が震えるからだ。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 34:4–10; 申命記 11:6; ヨハネの黙示録 20:11"> 地は完全に砕かれ、地は引き裂かれ、地は激しく揺り動かされる。</span>
<span className="v" id="v20" data-v="20" data-xref="イザヤ書 19:14; ホセア書 4:1–5; ダニエル書 11:19"> 地は酔った者のようによろめき、ハンモックのように揺れ動く。その背きは地の上に重くのしかかる。地は倒れ、二度と起き上がることはない。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="詩篇 76:12; イザヤ書 34:2–17; ゼカリヤ書 14:12–19"> その日、主は高い所にいる軍勢を高い所で、地の王たちを地の上で罰される。</span>
<span className="v" id="v22" data-v="22" data-xref="ゼカリヤ書 9:11; イザヤ書 42:22; エレミヤ書 38:6–13"> 彼らは捕虜が穴に集められるように集められ、牢獄に閉じ込められる。多くの日の後、彼らは顧みられる。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 60:19; ヨハネの黙示録 21:23; イザヤ書 13:10"> 月はうろたえ、太陽は恥じる。万軍の主がシオン山とエルサレムで王となられ、その長老たちの前に栄光を現されるからだ。</span>

<div className="bible-chapter" lang="ja" dir="ltr" data-lang="ja" data-translation="meb" data-translation-id="jpn_meb" data-translation-label="MEB" data-book="2CH" data-book-slug="2-chronicles" data-book-name="歴代誌 第二" data-chapter="18" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌 第二 17:5; 歴代誌 第二 21:6; 歴代誌 第二 19:2"> ヨシャファテは豊かな富と誉れを持っていた。彼はアハブと婚姻関係を結んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="列王記第二 9:1; 歴代誌 第二 19:2; 列王記第一 1:9"> 何年かして、彼はサマリアのアハブのところに下って行った。アハブは彼と、彼とともにいた人々のために、多数の羊と牛をほふってもてなし、ラモテ・ギレアデへ攻め上るように彼をそそのかした。</span>
<span className="v" id="v3" data-v="3" data-xref="列王記第一 22:4; 列王記第二 3:7; ヨハネの手紙第二 1:10–11"> イスラエルの王アハブはユダの王ヨシャファテに言った。「わたしと一緒にラモテ・ギレアデへ行ってくれませんか。」彼は答えた。「わたしはあなたと同じです。わたしの民はあなたの民と同じです。わたしたちは戦いにおいてあなたとともにいます。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 21:2; サムエル記第二 5:19; サムエル記第二 2:1"> ヨシャファテはイスラエルの王に言った。「どうか、まず主の言葉を伺ってください。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="テモテへの第二の手紙 4:3; ミカ書 3:11; エレミヤ書 28:1–17"> そこでイスラエルの王は預言者たち四百人を集めて、彼らに言った。「わたしたちはラモテ・ギレアデへ戦いに行くべきか、それともやめるべきか。」彼らは言った。「上りなさい。神がそれを王の手に渡されるからです。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王記第一 22:7–9; 列王記第二 3:11–13"> しかしヨシャファテは言った。「このほかに、わたしたちが尋ね求めることのできる主の預言者は、ここにいないのですか。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="アモス書 5:10; ミカ書 2:7; 列王記第一 21:20"> イスラエルの王はヨシャファテに言った。「主に尋ね求めることのできる者が、まだもう一人います。しかしわたしは彼を憎んでいます。彼はわたしについて決して良いことを預言せず、常に悪いことを預言するからです。それはイムラの子ミカヤです。」ヨシャファテは言った。「王よ、そのように言われませんように。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王記第一 22:9; イザヤ書 39:7; 歴代誌 第二 18:25–26"> そこでイスラエルの王はある役人を呼んで、「イムラの子ミカヤを早く連れて来なさい」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 14:9; ダニエル書 7:9; マタイ 19:28"> イスラエルの王とユダの王ヨシャファテは、それぞれ王服を着て王座に座っていた。彼らはサマリアの門の入り口にある広場に座っており、すべての預言者たちが彼らの前で預言していた。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 23:17; ゼカリヤ書 1:18–21; エレミヤ書 28:2–3"> ケナアナの子ゼデキヤは自分のために鉄の角を造って言った。「主はこう言われる。『あなたはこれらをもってアラム人を突き、ついに彼らを滅ぼし尽くす。』」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="箴言 24:24–25; 歴代誌 第二 18:33–34; ユダ 1:16"> すべての預言者たちも同じように預言して言った。「ラモテ・ギレアデへ上り、勝利を得てください。主はそれを王の手に渡されるからです。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ミカ書 2:6; 詩篇 10:11; ミカ書 2:11"> ミカヤを呼びに行った使者は彼に言った。「預言者たちは口をそろえて王に良いことを告げている。どうか、あなたの言葉も彼らのうちの一人の言葉のようであって、良いことを語ってほしい。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数記 22:35; 民数記 24:13; 民数記 22:18–20"> ミカヤは言った。「主は生きておられる。わたしの神が言われること、それをわたしは語る。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王記第一 22:15; 哀歌 4:21; アモス書 4:4–5"> 彼が王のところに来ると、王は彼に言った。「ミカヤよ。わたしたちはラモテ・ギレアデへ戦いに行くべきか、それともやめるべきか。」彼は言った。「上りなさい、そして勝利を得なさい。彼らはあなたがたの手に渡されるでしょう。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="マタイ 26:63; サムエル記第一 14:24; 列王記第一 22:16"> 王は彼に言った。「主の御名によって真実以外のことをわたしに語らないようにと、わたしは何度あなたに誓わせなければならないのか。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="マタイ 9:36; エゼキエル書 34:5–6; 民数記 27:17"> 彼は言った。「わたしは、全イスラエルが羊飼いのいない羊のように、山々に散らされているのを見た。主は『彼らには主人がいない。それぞれ平安のうちに自分の家へ帰らせよ』と言われた。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歴代誌 第二 18:7; 列王記第一 22:18; 箴言 29:1"> イスラエルの王はヨシャファテに言った。「彼がわたしについて良いことを預言せず、悪いことだけを預言すると、あなたに言ったではないか。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="ダニエル書 7:9; イザヤ書 6:1–5; 列王記第一 22:19–23"> ミカヤは言った。「それゆえ、主の言葉を聞きなさい。わたしは主がその王座に座り、天の全軍勢がその右と左に立っているのを見た。</span>
<span className="v" id="v19" data-v="19" data-xref="エゼキエル書 14:9; 歴代誌 第二 25:19; 箴言 11:5"> 主は言われた。『だれがイスラエルの王アハブをそそのかして、ラモテ・ギレアデへ上らせ、倒れさせるのか。』ある者はこのように言い、別の者はあのように言った。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨブ記 1:6; コリント人への第二の手紙 11:13–15; コリント人への第二の手紙 11:3"> すると、ある霊が進み出て主の前に立ち、『わたしが彼をそそのかします』と言った。主は彼に『どのようにしてか』と言われた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ヨハネ 8:44; 列王記第一 22:21–22; ヨハネの手紙第一 4:6"> 彼は言った。『わたしは出て行き、彼のすべての預言者たちの口にあって偽りの霊となります。』すると主は言われた。『あなたは彼をそそのかし、しかも成功する。出て行って、そのようにせよ。』</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 19:14; エゼキエル書 14:9; ヨブ記 12:16"> だから今、見よ。主はあなたのこれらすべての預言者たちの口に偽りの霊を置かれた。主はあなたに対して災いを告げられたのだ。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="マルコ 14:65; エレミヤ書 20:2; 歴代誌 第二 18:10"> そのとき、ケナアナの子ゼデキヤが近づき、ミカヤの頬を打って言った。「主の霊はどの道を通ってわたしから離れ、あなたに語ったというのか。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="エレミヤ書 29:21–22; イザヤ書 26:20; エレミヤ書 28:16–17"> ミカヤは言った。「見よ。あなたが隠れようとして奥の部屋に入るその日に、あなたは見るだろう。」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="歴代誌 第二 18:8; 歴代誌 第二 34:8; エレミヤ書 38:6–7"> イスラエルの王は言った。「ミカヤを捕らえ、町の長アモンと王の子ヨアシュのところに連れ戻し、</span>
<span className="v" id="v26" data-v="26" data-xref="歴代誌 第二 16:10; 詩篇 80:5; ルカ 23:2"> 言え。『王はこう言われる。「わたしが平安に帰って来るまで、この者を牢獄に入れ、苦しみのパンと苦しみの水を与えよ。」』」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="ルカ 20:45–46; アモス書 9:10; ミカ書 1:2"> ミカヤは言った。「もしあなたが平安に帰って来るようなことがあれば、主はわたしによって語られなかったということだ。」彼はまた言った。「すべての民よ、聞きなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王記第一 22:29–33"> こうしてイスラエルの王とユダの王ヨシャファテは、ラモテ・ギレアデへ上って行った。</span>
<span className="v" id="v29" data-v="29" data-xref="サムエル記第一 28:8; エレミヤ書 23:24; 箴言 26:25"> イスラエルの王はヨシャファテに言った。「わたしは変装して戦いに入る。しかし、あなたは自分の王服を着ていなさい。」そこでイスラエルの王は変装して戦いに入った。</span>
<span className="v" id="v30" data-v="30" data-xref="創世記 19:11; 申命記 1:17; 列王記第一 20:42"> さて、アラムの王は自分の戦車の長たちに命じて言った。「小さい者とも大きい者とも戦ってはならない。ただイスラエルの王とだけ戦え。」</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="歴代誌 第二 13:14; 詩篇 118:13; コリント人への第二の手紙 1:9–10"> 戦車の長たちはヨシャファテを見ると、「これはイスラエルの王だ」と言った。それゆえ、彼らは彼と戦うために向きを変えた。しかしヨシャファテが叫び声を上げると、主は彼を助けられた。神は彼らを彼から離れ去らせたのである。</span>
<span className="v" id="v32" data-v="32" data-xref="列王記第一 22:33"> 戦車の長たちは、それがイスラエルの王ではないのを見ると、彼を追うのをやめて引き返した。</span>
<span className="v" id="v33" data-v="33" data-xref="歴代誌 第二 35:23; サムエル記第二 15:11; 列王記第一 22:34–35"> ある人が狙いを定めずに弓を引き、イスラエルの王の鎧の継ぎ目を射た。それで王は戦車の御者に言った。「向きを変えて、わたしを戦場から連れ出してくれ。わたしはひどい傷を負った。」</span>
<span className="v" id="v34" data-v="34" data-xref="箴言 13:21; 歴代誌 第二 18:27; 箴言 28:17"> その日の戦いは激しくなった。しかしイスラエルの王は、夕暮れまでアラム人に向かって戦車の中で身を支えていたが、日の沈むころに死んだ。</span>
</div>
</div>

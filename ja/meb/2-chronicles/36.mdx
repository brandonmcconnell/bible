<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エレミヤ書 22:11; 歴代誌 第二 33:25; 歴代誌 第二 26:1"> その地の民はヨシヤの子エホアハズを選び、彼をその父に代わってエルサレムで王とした。</span>
<span className="v" id="v2" data-v="2"> ヨアハズ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="ヨアハズ は エホアハズ の変形である。">a</a></sup>は二十三歳で王となり、エルサレムで三か月間治めた。</span>
<span className="v" id="v3" data-v="3" data-xref="列王記第二 23:33"> エジプトの王は彼をエルサレムの王位から退け、その地に銀百タラントと金一タラント<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一タラントは約30キログラム、または66ポンドである。">b</a></sup>の罰金を科した。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 22:10–12; 列王記第二 23:34–35; エゼキエル書 19:3–4"> エジプトの王は彼の兄弟エリアキムをユダとエルサレムの王とし、その名をエホヤキムと改めさせた。ネコはその兄弟ヨアハズ<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="ヨアハズ は エホアハズの異名である。">c</a></sup>を捕らえ、エジプトへ連れて行った。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王記第二 23:36–37; エレミヤ書 22:13–19; エレミヤ書 26:1"> エホヤキムは二十五歳で王となり、エルサレムで十一年間治めた。彼は自分の神、主の目に悪を行った。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代誌 第二 33:11; 列王記第二 24:5–6; エゼキエル書 19:5–9"> バビロンの王ネブカドネザルが彼に向かって攻め上って来て、彼をバビロンへ連れて行くために足枷で縛った。</span>
<span className="v" id="v7" data-v="7" data-xref="列王記第二 24:13; ダニエル書 5:2–4; エレミヤ書 27:16–18"> ネブカドネザルはまた、主の家の器の一部をバビロンへ運び、バビロンにある彼の神殿にそれを置いた。</span>
<span className="v" id="v8" data-v="8" data-xref="列王記第二 24:5–6; マタイ 1:11–12; 歴代誌上 3:16–17"> エホヤキムのその他の事績、彼が行った忌まわしいこと、および彼に認められた悪については、見よ、イスラエルとユダの王たちの書に記されている。その子エホヤキンが代わって王となった。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王記第二 24:8–17"> エホヤキンは八歳で王となり、エルサレムで三か月十日間治めた。彼は主の目に悪を行った。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 37:1; 歴代誌 第二 36:7; 列王記第二 24:10–17"> 年が改まると、ネブカドネザル王は人を遣わして、彼を主の家の高価な器とともにバビロンへ連れて行き、その兄弟ゼデキヤをユダとエルサレムの王とした。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王記第二 24:18–20; エレミヤ書 52:1–3; エレミヤ書 27:1"> ゼデキヤは二十一歳で王となり、エルサレムで十一年間治めた。</span>
<span className="v" id="v12" data-v="12" data-xref="歴代誌 第二 33:23; エレミヤ書 37:2–21; エレミヤ書 38:14–28"> 彼は自分の神、主の目に悪を行った。彼は主の言葉を語る預言者エレミヤの前にへりくだらなかった。</span>
<span className="v" id="v13" data-v="13" data-xref="エレミヤ書 52:2–3; 歴代誌 第二 30:8; エゼキエル書 17:11–20"> 彼はまた、神の名によって誓わせたネブカドネザル王に背いた。彼はうなじを固くし、心を頑なにしてイスラエルの神、主に立ち返ろうとしなかった。</span>
<span className="v" id="v14" data-v="14" data-xref="ダニエル書 9:8; エゼキエル書 22:6; ミカ書 3:9–11"> さらに、祭司たちのすべての長と民は、国々のすべての忌まわしい行いに従って、非常にひどく背信の罪を犯した。彼らは主がエルサレムで聖別された主の家を汚した。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="エレミヤ書 35:15; エレミヤ書 7:13; エレミヤ書 25:3–4"> 彼らの父祖の神、主は、ご自分の民と住まいをあわれまれたので、ご自分の使者たちを繰り返し遣わされた。</span>
<span className="v" id="v16" data-v="16" data-xref="エレミヤ書 5:12–13; 歴代誌 第二 30:10; ルカ 22:63–64"> しかし彼らは神の使者たちをあざ笑い、その言葉を軽蔑し、その預言者たちを嘲った。ついに、主の激しい怒りがその民に向かって燃え上がり、もはや救いようがなくなった。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="詩篇 74:20; エズラ記 9:7; エゼキエル書 9:5–7"> それゆえ主は、カルデア人の王を彼らに向かって攻め上らせた。彼は彼らの聖所で若者たちを剣で殺し、若者にも処女にも、老人にも年老いて弱った者にもあわれみを示さなかった。主はすべてを彼の手に渡された。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代誌 第二 36:7; 歴代誌 第二 36:10; イザヤ書 39:6"> 彼は神の家の大小のすべての器、主の家の財宝、および王とその君たちの財宝、これらすべてをバビロンへ持ち去った。</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 79:1; 列王記第一 9:8; エレミヤ書 52:13–15"> 彼らは神の家を焼き、エルサレムの城壁を打ち壊し、そのすべての宮殿を火で焼き、その高価な器をすべて滅ぼした。</span>
<span className="v" id="v20" data-v="20" data-xref="エレミヤ書 27:7; エズラ記 1:1–11; 歴代誌 第二 36:22"> 彼は剣から逃れた者たちをバビロンへ捕虜として連れ去った。彼らはペルシア王国の支配が始まるまで、彼とその子らのしもべとなった。</span>
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 29:10; レビ記 26:34–35; ゼカリヤ書 1:12"> それはエレミヤの口を通して語られた主の言葉が果たされ、その地が安息年を取り戻すためであった。その地は荒れ果てている間、ずっと安息を守り、七十年を満たした。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="エレミヤ書 25:12; エズラ記 1:1–3; エレミヤ書 29:10"> さて、ペルシアの王キュロスの第一年に、エレミヤの口を通して語られた主の言葉が成し遂げられるため、主はペルシアの王キュロスの心を奮い立たせられた。彼はその王国の全土に布告を出し、文書にも記して言った。</span>
<span className="v" id="v23" data-v="23" data-xref="イザヤ書 44:26–28; エズラ記 7:13; ローマ人への手紙 8:31"> 「ペルシアの王キュロスはこう言う。『天の神、主は地上のすべての王国をわたしに与えられた。主はユダにあるエルサレムに、ご自分のために家を建てるようにわたしに命じられた。あなたがたのうち、主の民に属する者はだれでも、その神、主がともにおられるように。その者は上って行け。』」</span>
</div>

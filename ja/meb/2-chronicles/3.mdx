<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌上 21:18; 創世記 22:14; 歴代誌上 22:1"> その後、ソロモンはエルサレムのモリヤ山で主の家を建て始めた。そこは主が父ダビデに現れた場所であり、ダビデが指定したエブス人オルナンの打ち場であった。</span>
<span className="v" id="v2" data-v="2" data-xref="列王記第一 6:1"> 彼はその治世の第四年、第二の月の二日に建築を始めた。</span>
<span className="v" id="v3" data-v="3" data-xref="列王記第一 6:2–3; 歴代誌上 28:11–19"> ソロモンが神の家を建てるために定めた基礎寸法は次のとおりである。昔の寸法によるキュビト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一キュビトは約46センチメートル、または約18インチである。">a</a></sup>で、長さは六十キュビト、幅は二十キュビトであった。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネ 10:23; 使徒の働き 5:12; 使徒の働き 3:11"> その前にある玄関は、家の幅に応じた長さが二十キュビト、高さが百二十キュビトであった。彼はその内側に純金をかぶせた。</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第一 6:15–17; 列王記第一 6:21–22"> 彼は大広間の天井をイトスギ材で張り、さらに純金をかぶせ、そこにヤシの木と鎖の飾りを施した。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 54:11–12; 歴代誌上 29:8; ヨハネの黙示録 21:18–21"> 彼は美しくするために、その家を宝石で飾った。金はパルワイムの金であった。</span>
<span className="v" id="v7" data-v="7" data-xref="列王記第一 6:20–22; 出エジプト記 26:29; エゼキエル書 7:20"> 彼はまた、その家、すなわちその梁、敷居、壁、および戸に金をかぶせ、壁にケルビムを彫った。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 26:33; 列王記第一 6:19–20; 列王記第一 6:16"> 彼は至聖所を造った。その長さは家の幅に応じて二十キュビト、その幅も二十キュビトであった。彼はそれに六百タラント<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一タラントは約30キログラム、または約66ポンドである。六百タラントは約18メートルトンである。">b</a></sup>に上る純金をかぶせた。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代誌上 28:11"> 釘の重さは金五十シェケル<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一シェケルは約10グラム、あるいは約0.35オンスである。五十シェケルは約0.5キログラム、または約1.1ポンドである。">c</a></sup>であった。彼は階上の部屋にも金をかぶせた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="列王記第一 6:23–28; 出エジプト記 25:18"> 至聖所の中に、彼は彫刻細工で二つのケルビムを造り、それに金をかぶせた。</span>
<span className="v" id="v11" data-v="11"> ケルビムの翼の長さは合わせて二十キュビトであった。一方のケルビムの一つの翼は五キュビトで、家の壁に届いており、もう一つの翼も五キュビトで、もう一方のケルビムの翼に届いていた。</span>
<span className="v" id="v12" data-v="12"> もう一方のケルビムの一つの翼も五キュビトで、家の壁に届いており、もう一つの翼も五キュビトで、一方のケルビムの翼に連なっていた。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 25:20"> これらのケルビムの翼は二十キュビトに広がっていた。ケルビムは足をつけて立ち、その顔を大広間の方へ向けていた。</span>
<span className="v" id="v14" data-v="14" data-xref="ヘブル人への手紙 9:3; ヘブル人への手紙 10:20; マタイ 27:51"> 彼は青、紫、緋色の糸、および上質の亜麻布で垂れ幕を造り、それにケルビムの模様を施した。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王記第一 7:15–24; エレミヤ書 52:20–23"> また彼は、家の前に高さ三十五キュビトの二本の柱を造った。それぞれの上に五キュビトの柱頭があった。</span>
<span className="v" id="v16" data-v="16" data-xref="列王記第一 7:20; 列王記第一 6:21"> 彼は内陣に鎖飾りを造り、それを柱の頂に置いた。また、百のザクロを造り、それを鎖の飾りに取り付けた。</span>
<span className="v" id="v17" data-v="17" data-xref="列王記第一 7:21"> 彼は神殿の前に、一本を右に、もう一本を左にしてその柱を立てた。右の柱の名をヤキンと呼び、左の柱の名をボアズと呼んだ。</span>
</div>
</div>

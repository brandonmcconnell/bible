<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌上 29:25; 列王記第一 2:12; 創世記 39:2"> ダビデの子ソロモンは王位を確かなものとした。主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="すべて大文字の「主」または「神」は、神の固有名であるヘブル語「יהוה」（通常ヤハウェと発音される）の訳である。">a</a></sup>、彼の神<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="「神」と訳されたヘブル語は「אֱלֹהִים」（エロヒム）である。">b</a></sup>は彼とともにおられ、彼をこの上なく偉大な者とされた。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="歴代誌上 28:1; 歴代誌上 27:1; 歴代誌 第二 30:2"> ソロモンは全イスラエル、すなわち千人の長たち、百人の長たち、裁き人たち、全イスラエルのすべての有力者、父祖の家々の長たちに語りかけた。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代誌上 21:29; 歴代誌上 16:39; レビ記 1:1"> そしてソロモンと彼に従う全会衆は、ギベオンにある高き所へ行った。そこには、主のしもべモーセが荒野で造った神の会見の天幕があったからである。</span>
<span className="v" id="v4" data-v="4" data-xref="サムエル記第二 6:17; 歴代誌上 15:25–28; サムエル記第二 6:2"> 一方、ダビデは神の箱をキルヤテ・エアリムから、エルサレムに用意した場所へ運び上げ、そのために天幕を張っていた。</span>
<span className="v" id="v5" data-v="5" data-xref="出エジプト記 31:2; 出エジプト記 38:1–7; 歴代誌上 2:19–20"> さらに、フルの子ウリの子ベツァルエルが造った青銅の祭壇も、そこ、すなわち主の幕屋の前にあった。ソロモンと会衆はそこで主を求めた。</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第一 3:4; 列王記第一 8:63; 歴代誌上 29:21"> ソロモンは会見の天幕の前、主の御前にある青銅の祭壇へ上り、その上で一千の全焼のささげ物をささげた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="マタイ 7:7–8; ヨハネの手紙第一 5:14–15; ヨハネ 16:23"> その夜、神はソロモンに現れて言われた。「あなたに何を与えようか、求めなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歴代誌上 28:5; イザヤ書 55:3; サムエル記第二 22:51–1"> ソロモンは神に言った。「あなたは、わたしの父ダビデに大いなる慈しみを示し、わたしを彼に代わって王とされました。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記第二 7:12–16; 創世記 13:16; 詩篇 132:11–12"> 主なる神よ。今、わたしの父ダビデに与えられた約束を確かなものとしてください。あなたは、地のちりのように数の多い民の上に、わたしを王とされたからです。</span>
<span className="v" id="v10" data-v="10" data-xref="列王記第一 3:9; 箴言 4:7; 箴言 2:2–6"> 今、わたしに知恵と知識を与えてください。この民の前に立って彼らを導くためです。だれが、この大いなるあなたの民をさばくことができるでしょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ヤコブの手紙 3:17; 箴言 23:7; サムエル記第一 16:7"> 神はソロモンに言われた。「これがあなたの心にあり、富や財宝や誉れ、またあなたを憎む者たちの命を求めず、長寿をも求めず、むしろ、わたしがあなたを王として立てたわたしの民をさばくことができるように、自分のために知恵と知識を求めたので、</span>
<span className="v" id="v12" data-v="12" data-xref="ヤコブの手紙 1:5; 歴代誌 第二 9:22; マタイ 6:33"> 知恵と知識があなたに与えられる。わたしはまた、あなたより前のどの王たちも持ったことがなく、あなたの後の者も持つことのないような、富と財宝と誉れをあなたに与える。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歴代誌 第二 1:3; 列王記第一 4:24–25"> こうして、ソロモンはギベオンの高き所、会見の天幕の前からエルサレムへ帰り、イスラエルを治めた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王記第一 4:26; 列王記第一 10:26–29; 歴代誌 第二 9:25"> ソロモンは戦車と騎兵を集めた。彼は戦車一千四百両と騎兵一万二千人を持ち、それらを戦車の町々と、王のいるエルサレムに配置した。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代誌 第二 9:27; イザヤ書 9:10; 列王記第一 10:27–29"> 王はエルサレムにおいて、銀と金を石のようにありふれたものにし、香柏を低地にあるいちじく桑の木のようにありふれたものにした。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代誌 第二 9:28; 列王記第一 10:28–29"> ソロモンの持っていた馬は、エジプトとクエから運び出された。王の商人たちがクエから買い取ったのである。</span>
<span className="v" id="v17" data-v="17" data-xref="列王記第二 10:29"> 王の商人たちは、戦車一両を銀六百枚<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="銀の枚数はおそらくシェケルであった。一シェケルは約10グラム、あるいは約0.35オンスである。六百枚は銀約6キログラム、または約13.2ポンド、百五十枚は銀約1.5キログラム、または約3.3ポンドである。">c</a></sup>で、馬一頭を銀百五十枚でエジプトから仕入れ、ヒッタイトのすべての王たちとアラム人の王たち<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="または、シリアの王たち。">d</a></sup>にも売り渡した。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第一の手紙 5:7–8; 歴代誌 第二 11:13; ホセア書 5:4"> ヒゼキヤは全イスラエルとユダに人を遣わし、エフライムとマナセにも手紙を書いて、エルサレムの主の家に来て、イスラエルの神、主のために過越の祭りを祝うように伝えた。</span>
<span className="v" id="v2" data-v="2" data-xref="民数記 9:10–11; 歴代誌上 13:1–3; 歴代誌 第二 30:13"> 王、君たち、およびエルサレムの全会衆は、第二の月に過越の祭りを祝うように協議していた。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代誌 第二 29:34; 出エジプト記 12:6; 出エジプト記 12:18"> 定められた時に祝うことができなかったのは、十分な数の祭司たちが自らを聖別しておらず、民もエルサレムに集まっていなかったからである。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌上 13:4"> この事は王と全会衆の目に正しいと思われた。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 20:1; レビ記 23:2; エステル記 8:8–10"> そこで彼らは、ベエル・シェバからダンに至るまでの全イスラエルに布告を出し、エルサレムに来てイスラエルの神、主のために過越の祭りを祝うように定めた。彼らは記されている定めどおりに、大勢でそれを祝っていなかったからである。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エレミヤ書 51:31; エステル記 8:14; 列王記第二 15:19"> こうして飛脚たちが王とその君たちからの手紙を携え、王の命令に従って全イスラエルとユダを巡り、こう言った。「イスラエルの子らよ。アブラハム、イサク、イスラエルの神、主に再び立ち返りなさい。そうすれば、アッシリアの王たちの手から逃れて生き残ったあなたがたの残りの者に、主が立ち返ってくださる。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌 第二 29:8; エゼキエル書 20:13–18; ゼカリヤ書 1:3–4"> あなたがたの父祖や兄弟たちのようになってはならない。彼らが父祖の神、主に対して背信の罪を犯したため、あなたがたが見ているように、主は彼らを荒廃に渡されたのである。</span>
<span className="v" id="v8" data-v="8" data-xref="出エジプト記 32:9; 歴代誌 第二 29:10; 申命記 10:16"> 今、あなたがたの父祖たちのようにうなじを固くしてはならない。身を主に委ね、主がとこしえに聖別されたその聖所に入り、あなたがたの神、主に仕えなさい。そうすれば、主の激しい怒りはあなたがたから遠ざかる。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 55:7; ミカ書 7:18; 詩篇 86:5"> もしあなたがたが再び主に立ち返るなら、あなたがたの兄弟たちや子どもたちは、彼らを捕虜として連れ去った者たちの前であわれみを受け、この地に帰って来る。あなたがたの神、主は恵み深くあわれみ深い方であり、あなたがたが主に立ち返るなら、あなたがたから御顔を背けることはないからである。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歴代誌 第二 36:16; 歴代誌 第二 30:6; ネヘミヤ記 2:19"> こうして飛脚たちは、エフライムとマナセの地方を通ってゼブルンに至るまで町から町へと巡り歩いた。しかし人々は彼らをあざ笑い、嘲った。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代誌 第二 30:18; 歴代誌 第二 30:21; 歴代誌 第二 30:25"> それでも、アシェル、マナセ、およびゼブルンの一部の人々はへりくだって、エルサレムにやって来た。</span>
<span className="v" id="v12" data-v="12" data-xref="エレミヤ書 32:39; エレミヤ書 24:7; ピリピ人への手紙 2:13"> また、ユダにも神の御手が臨み、主の言葉による王と君たちの命令を行うための、一つの心を彼らに与えられた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歴代誌 第二 30:2; 詩篇 84:7"> 第二の月に種なしパンの祭りを祝うため、多くの民がエルサレムに集まった。それは非常に大きな会衆であった。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代誌 第二 28:24; サムエル記第二 15:23; 歴代誌 第二 15:16"> 彼らは立ち上がり、エルサレムにあった祭壇を取り除き、香をたくためのすべての祭壇を取り除いて、キデロンの谷川に投げ捨てた。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代誌 第二 29:34; 歴代誌 第二 5:11; 出エジプト記 19:22"> それから彼らは第二の月の第十四の日に過越のいけにえをほふった。祭司たちとレビ人は恥じ入り、自らを聖別して、全焼のささげ物を主の家に持って来た。</span>
<span className="v" id="v16" data-v="16" data-xref="申命記 33:1; 歴代誌 第二 35:15; 列王記第二 11:14"> 彼らは神の人モーセの律法に従って、自分たちの順序に従ってその定位置に立った。祭司たちはレビ人の手から受け取った血を振りかけた。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代誌 第二 29:34; 歴代誌 第二 35:3–6; 出エジプト記 12:6"> 会衆の中には自らを聖別していない者が多くいたため、レビ人が、きよくないすべての者のために過越のいけにえをほふることを任され、彼らを主のために聖別した。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 11:28; ヤコブの手紙 5:15–16; ダニエル書 9:19"> 多くの民、すなわちエフライム、マナセ、イッサカル、ゼブルンの多くの者が自らをきよめていなかったが、記されている定めに反して過越のいけにえを食べた。ヒゼキヤは彼らのために祈って言った。「どうか、良い方である主が、</span>
<span className="v" id="v19" data-v="19" data-xref="歴代誌 第二 19:3; 箴言 23:26; ヨブ記 11:13"> その心を定めて神、すなわち主、その父祖の神を尋ね求めるすべての人をお赦しくださいますように。たとえその人が聖所のきよめの規定どおりにはきよくなくても。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 15:26; ヤコブの手紙 5:15–16; 詩篇 103:3"> 主はヒゼキヤの祈りを聞き入れ、民をいやされた。</span>
<span className="v" id="v21" data-v="21" data-xref="出エジプト記 12:15; 出エジプト記 13:6; 申命記 12:12"> エルサレムにいたイスラエルの子らは、七日間、大いなる喜びをもって種なしパンの祭りを祝った。レビ人と祭司たちは日ごとに主を賛美し、力強く楽器を奏でて主を賛美した。</span>
<span className="v" id="v22" data-v="22" data-xref="歴代誌 第二 32:6; ネヘミヤ記 9:3; イザヤ書 40:1–2"> ヒゼキヤは、主への奉仕をよく理解していたすべてのレビ人に、励ましの言葉をかけた。こうして彼らは七日間、祭りの間食べ、和解のいけにえをささげ、彼らの父祖の神、主に告白した。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王記第一 8:65; 歴代誌 第二 7:9"> 全会衆はさらに七日間祝うことを協議し、さらに七日間、喜びをもって祝った。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代誌 第二 29:34; 歴代誌 第二 35:7–8; エペソ人への手紙 4:8"> ユダの王ヒゼキヤは会衆に、ささげ物として雄牛千頭と羊七千匹を与え、君たちは会衆に雄牛千頭と羊一万匹を与えた。そして多くの祭司たちが自らを聖別した。</span>
<span className="v" id="v25" data-v="25" data-xref="歴代誌 第二 30:11; 歴代誌 第二 30:18; 歴代誌上 16:10–11"> ユダの全会衆は、祭司たちとレビ人、およびイスラエルから来た全会衆、またイスラエルの地から来てユダに住んでいた異国人たちとともに喜んだ。</span>
<span className="v" id="v26" data-v="26" data-xref="歴代誌 第二 7:8–10"> こうしてエルサレムには大きな喜びがあった。イスラエルの王、ダビデの子ソロモンの時代以来、エルサレムにこのようなことはなかったからである。</span>
<span className="v" id="v27" data-v="27" data-xref="申命記 26:15; 詩篇 68:5; 民数記 6:23–26"> それからレビ人である祭司たちが立ち上がって民を祝福した。その声は神に届き、その祈りは主の聖なる住まい、天にまで届いた。</span>
</div>
</div>

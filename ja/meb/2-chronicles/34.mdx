<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ゼパニヤ書 1:1; エレミヤ書 1:2; 歴代誌 第二 33:25"> ヨシヤは八歳で王となり、エルサレムで三十一年間治めた。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代誌 第二 29:2; ヨシュア記 1:7; 列王記第二 22:2"> 彼は主の目に正しいことを行い、その父祖ダビデの道を歩み、右にも左にもそれることはなかった。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代誌 第二 33:22; 歴代誌 第二 15:2; 箴言 8:17"> その治世の第八年に、彼はまだ若かったが、その父祖ダビデの神を尋ね求め始めた。そして第十二年に、高き所、アシェラ像、刻んだ像、および鋳造の像からユダとエルサレムをきよめ始めた。</span>
<span className="v" id="v4" data-v="4" data-xref="出エジプト記 32:20; レビ記 26:30; 列王記第二 23:4–6"> 彼の前でバアルの祭壇が打ち壊された。彼はその上に高く置かれていた香の祭壇を切り倒した。彼はアシェラ像、刻んだ像、および鋳造の像を粉々に砕き、それらにいけにえをささげていた者たちの墓の上に散らした。</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第一 13:2; エレミヤ書 3:10; 民数記 35:33"> 彼は祭司たちの骨を彼らの祭壇の上で焼き、ユダとエルサレムをきよめた。</span>
<span className="v" id="v6" data-v="6" data-xref="サムエル記第一 13:20–21; イザヤ書 7:25; 歴代誌 第二 30:1"> 彼はマナセ、エフライム、シメオンの町々からナフタリに至るまで、周囲の荒れ果てた地域でも同じようにした。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌 第二 31:1; 申命記 9:21; 歴代誌 第二 34:1"> 彼はイスラエルの全地で、祭壇を打ち壊し、アシェラ像と刻んだ像を打ち砕いて粉々にし、すべての香の祭壇を切り倒して、エルサレムへ帰った。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="サムエル記第二 8:16; 歴代誌上 18:15; エレミヤ書 29:25"> 彼の治世の第十八年、彼が国と神殿をきよめ終えたとき、彼はアツァルヤの子シャファン、町の長マアセヤ、および記録官であるヨアハズの子ヨアハを遣わして、彼の神、主の家を修復させた。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代誌 第二 30:18; 歴代誌 第二 30:10; 歴代誌 第二 35:8"> 彼らは大祭司ヒルキヤのところへ行き、神の家に持ち込まれた金銭、すなわち門衛であるレビ人がマナセとエフライム、およびイスラエルのすべての残りの者から集めた金銭、さらに全ユダとベニヤミン、およびエルサレムの住民から集めた金銭を手渡した。</span>
<span className="v" id="v10" data-v="10" data-xref="列王記第二 12:11–12; エズラ記 3:7; 列王記第二 22:5–6"> 彼らはそれを、主の家を監督する工事人たちの手に渡し、工事人たちはそれを用いて、主の家で働き、家を修繕し、修復した。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代誌 第二 33:4–7; 歴代誌 第二 33:22"> 彼らはそれを大工や建築家たちに渡し、切り石を買い、ユダの王たちが荒らした建物の梁と、その修復に用いる木材を買わせた。</span>
<span className="v" id="v12" data-v="12" data-xref="列王記第二 12:15; 歴代誌上 23:5; 列王記第二 22:7"> その人々は忠実に仕事を行った。彼らの上には、メラリの子らのうちのヤハテとオバデヤ、またケハテの子らのうちのゼカリヤとメシュラムが監督として任命され、仕事を指揮した。他の者たちは、楽器の演奏に熟練したレビ人たちであった。</span>
<span className="v" id="v13" data-v="13" data-xref="ネヘミヤ記 4:10; 歴代誌 第二 2:18; エレミヤ書 8:8"> 彼らはまた、荷を担ぐ者たちの上に立ち、あらゆる仕事に携わる者たちを監督した。レビ人の一部は書記、役人、門衛であった。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="レビ記 8:36; 詩篇 1:2; レビ記 10:11"> 彼らが主の家に持ち込まれた金を取り出していたとき、祭司ヒルキヤはモーセを通して伝えられた主の律法の書を見つけた。</span>
<span className="v" id="v15" data-v="15"> ヒルキヤは書記シャファンに言った。「わたしは主の家で律法の書を見つけました。」ヒルキヤはその書をシャファンに手渡した。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王記第二 22:9–10; エレミヤ書 36:20–21"> シャファンはその書を王のところに持って行き、王に報告して言った。「あなたのしもべたちに委ねられたすべてのことを、彼らは行っています。</span>
<span className="v" id="v17" data-v="17"> 彼らは主の家で見つかった金銭を取り出し、それを監督者たちの手、また工事人たちの手に渡しました。」</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 119:46; エレミヤ書 36:20–21; 申命記 17:19"> 書記シャファンは王に告げて、「祭司ヒルキヤがわたしに一つの書を渡しました」と言った。そしてシャファンは王の前でそれを読み上げた。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨシュア記 7:6; 申命記 28:3–68; 列王記第二 22:19"> 王は律法の言葉を聞くと、自分の衣を引き裂いた。</span>
<span className="v" id="v20" data-v="20" data-xref="列王記第二 22:12; エレミヤ書 26:24; エレミヤ書 40:9"> 王はヒルキヤ、シャファンの子アヒカム、ミカの子アブドン、書記シャファン、および王のしもべアサヤに命じて言った。</span>
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 21:2; エゼキエル書 14:1–11; 歴代誌 第二 28:6"> 「行って、わたしのため、またイスラエルとユダに残されている者たちのために、見つかったこの書の言葉について主に尋ね求めなさい。わたしたちの父祖たちが主の言葉を守らず、この書に記されているすべてのことに従って行わなかったために、わたしたちの上に注ぎ出された主の御怒りは大きいからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ルカ 2:36; 出エジプト記 15:20; 列王記第二 22:14"> そこでヒルキヤと王が命じた者たちは、衣の番人であるハスラの孫、トケハテの子シャルムの妻である女預言者フルダのところへ行った。彼女はエルサレムの第二区に住んでいた。彼らはこのように彼女に語った。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="エレミヤ書 37:7–10; エレミヤ書 21:3–7; 列王記第二 22:15–20"> 彼女は彼らに言った。「イスラエルの神、主はこう言われる。『あなたがたをわたしのところに遣わした人に告げよ。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代誌 第二 36:14–20; ヨシュア記 23:16; 申命記 28:15–68"> 主はこう言われる。「見よ、わたしはこの場所とその住民に災いをもたらす。それは、ユダの王の前で彼らが読み上げた書に記されているすべてののろいである。</span>
<span className="v" id="v25" data-v="25" data-xref="エレミヤ書 7:20; マルコ 9:43–48; ナホム書 1:6"> 彼らがわたしを捨て、他の神々に香をたき、自分たちの手のすべてのわざによってわたしを怒らせたためである。それゆえわたしの怒りはこの場所に注ぎ出され、消えることはない。」』</span>
<span className="v" id="v26" data-v="26" data-xref="歴代誌 第二 34:23; 歴代誌 第二 34:21"> しかし、主に尋ね求めるためにあなたがたを遣わしたユダの王には、このように告げよ。『あなたが聞いた言葉について、イスラエルの神、主はこう言われる。</span>
<span className="v" id="v27" data-v="27" data-xref="歴代誌 第二 32:26; エゼキエル書 9:4; 詩篇 34:18"> あなたは心が柔らかく、この場所とその住民に対する神の言葉を聞いたとき、わたしの前にへりくだり、衣を引き裂いて泣いたので、わたしもあなたの声を聞いた、と主は言われる。</span>
<span className="v" id="v28" data-v="28" data-xref="イザヤ書 39:8; 詩篇 37:37; 列王記第一 21:29"> 見よ、わたしはあなたをあなたの父祖たちのもとへ集める。あなたは平安のうちに自分の墓に集められる。わたしがこの場所とその住民にもたらすすべての災いを、あなたは目にすることはない。』」彼らはその言葉を王に持ち帰った。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王記第二 23:1–3; 歴代誌 第二 30:2; マルコ 14:8"> そこで王は人を遣わし、ユダとエルサレムのすべての長老たちを集めた。</span>
<span className="v" id="v30" data-v="30" data-xref="出エジプト記 24:7; 列王記第二 23:2; 歴代誌 第二 34:15"> 王は主の家に上って行った。ユダのすべての人々、エルサレムの住民、祭司たち、レビ人、そして大きい者から小さい者まで、すべての民もともに上って行った。彼は、主の家で見つかった契約の書のすべての言葉を彼らの耳に読み聞かせた。</span>
<span className="v" id="v31" data-v="31" data-xref="歴代誌 第二 23:16; 列王記第二 23:3; 列王記第二 11:14"> 王はその場所に立ち、主に従って歩み、心を尽くし魂を尽くして主の戒めとあかしと掟を守り、この書に記されている契約の言葉を行うという契約を、主の御前で結んだ。</span>
<span className="v" id="v32" data-v="32" data-xref="歴代誌 第二 30:12; エレミヤ書 3:10; 歴代誌 第二 14:4"> 彼はエルサレムとベニヤミンにいるすべての者を、その契約に立たせた。エルサレムの住民は神、すなわち彼らの父祖の神の契約に従って行った。</span>
<span className="v" id="v33" data-v="33" data-xref="歴代誌 第二 34:3–7; ヨシュア記 24:31; 列王記第二 23:4–20"> ヨシヤは、イスラエルの全領土から、すべての忌まわしいものを取り除き、イスラエルにいるすべての者に彼らの神、主に仕えさせた。彼の時代には、彼らは父祖の神、主に従い続けた。</span>
</div>

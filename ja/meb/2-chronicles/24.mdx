<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌上 3:11; 列王記第二 11:21–15"> ヨアシュは七歳で王となり、エルサレムで四十年間治めた。母の名はベエル・シェバのツィブヤであった。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代誌 第二 26:4–5; 歴代誌 第二 25:2; 歴代誌 第二 24:17–22"> ヨアシュは祭司エホヤダの生きている間、主の目に正しいことを行った。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代誌 第二 24:15; マタイ 19:4–8; 創世記 4:19"> エホヤダはヨアシュに二人の妻を迎えさせ、彼は息子と娘たちの父となった。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> その後、ヨアシュは主の家を修復しようと心に決めた。</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第二 12:4–7; 歴代誌 第二 34:8–9; 歴代誌 第二 29:3"> 彼は祭司たちとレビ人を集めて、彼らに言った。「ユダの町々へ出て行き、全イスラエルから金銭を集め、年ごとにあなたがたの神の家を修復しなさい。この事を急いで行いなさい。」しかしレビ人は急がなかった。</span>
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 30:12–16; 民数記 1:50; 民数記 17:7–8"> 王は長であるエホヤダを呼んで彼に言った。「なぜあなたは、主のしもべモーセとイスラエルの会衆が定めたあかしの幕屋のための税を、ユダとエルサレムから持って来るようにレビ人に要求しなかったのか。」</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌 第二 21:17; 歴代誌 第二 28:22–24; 列王記第二 12:4"> あの悪い女アタルヤの子らが神の家を破壊し、主の家のすべての聖別された物をバアルに与えてしまったからである。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="マルコ 12:41; 列王記第二 12:8–9"> そこで王が命じると、彼らは一つの箱を作り、それを主の家の門の外に置いた。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代誌 第二 24:6; マタイ 17:24–27"> 彼らはユダとエルサレムに、神のしもべモーセが荒野でイスラエルに課した税を主のために持って来るようにと布告を出した。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒の働き 2:45–47; コリント人への第二の手紙 9:7; 歴代誌上 29:9"> すべての君たちとすべての民は喜び、持って来て、箱がいっぱいになるまでその中に投げ入れた。</span>
<span className="v" id="v11" data-v="11" data-xref="列王記第二 12:10–12; コリント人への第一の手紙 16:2"> レビ人の手によって箱が王の役人たちのところに運ばれ、そこに多くの金銭があるのを見ると、王の書記と大祭司の役人が来て箱を空にし、それを取ってまた元の場所に戻した。彼らはこれを毎日行い、多額の金銭を集めた。</span>
<span className="v" id="v12" data-v="12" data-xref="列王記第一 5:15; 歴代誌 第二 34:9–11"> 王とエホヤダはそれを、主の家の奉仕のわざを行う者たちに与えた。彼らは主の家を修復するために石工や大工を雇い、また主の家を修理するために鉄や青銅を扱う者たちも雇った。</span>
<span className="v" id="v13" data-v="13" data-xref="ネヘミヤ記 4:7; マルコ 13:1–2; ハガイ書 2:3"> 働き手たちが働き、修復は彼らの手によって順調に進んだ。彼らは神の家をその設計どおりに立て直し、それを強固にした。</span>
<span className="v" id="v14" data-v="14" data-xref="民数記 28:2–29; 箴言 27:22; 列王記第二 12:13–14"> 彼らが終えると、残りの金銭を王とエホヤダの前に持って来た。それで主の家のための器、すなわち仕えるため、またささげるための器、さじ、金や銀の器が作られた。彼らはエホヤダの生きている間、主の家で絶えず全焼のささげ物をささげた。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="創世記 47:9; 歴代誌上 23:1; 詩篇 90:10"> しかしエホヤダは高齢となり、長寿を全うして死んだ。彼が死んだときは百三十歳であった。</span>
<span className="v" id="v16" data-v="16" data-xref="ヘブル人への手紙 6:10; 歴代誌 第二 31:20; ネヘミヤ記 13:14"> 人々は彼をダビデの町で王たちとともに葬った。彼がイスラエルにおいて、また神と神の家のために良いことを行ったからである。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="申命記 31:27; 箴言 26:28; 使徒の働き 20:29–30"> エホヤダの死後、ユダの君たちが来て王にひれ伏した。そのとき王は彼らの言うことを聞き入れた。</span>
<span className="v" id="v18" data-v="18" data-xref="ヨシュア記 22:20; 歴代誌 第二 19:2; エペソ人への手紙 5:6"> 彼らは父祖の神、主の家を捨てて、アシェラ像や偶像に仕えた。彼らのこの罪過のために、ユダとエルサレムに御怒りが下った。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 42:23; ルカ 20:9–15; マタイ 13:9"> それでも、主は彼らを主のもとに立ち返らせるために預言者たちを彼らのもとに遣わされた。預言者たちは彼らを戒めたが、彼らは耳を傾けようとはしなかった。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数記 14:41; エレミヤ書 5:25; 歴代誌 第二 15:1–2"> 神の霊が祭司エホヤダの子ゼカリヤに臨み、彼は民の前に立って彼らに言った。「神はこう言われる。『なぜあなたがたは主の命令に背くのか。そのため、あなたがたは栄えない。あなたがたが主を捨てたので、主もあなたがたを捨てられたのだ。』」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒の働き 7:58–59; ネヘミヤ記 9:26; エレミヤ書 38:4–6"> しかし彼らはゼカリヤに対して陰謀を企て、王の命令によって、主の家の庭で彼を石で打ち殺した。</span>
<span className="v" id="v22" data-v="22" data-xref="創世記 9:5; ルカ 11:51; ヨハネの黙示録 6:9–11"> こうしてヨアシュ王は、ゼカリヤの父エホヤダが自分に示した恩を思い起こさず、その子を殺した。ゼカリヤは死ぬとき、「主がこれを顧みて、報いてくださるように」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王記第二 12:17–18; 申命記 32:35; 列王記第一 20:22"> その年の終わりに、アラムの軍隊が彼に向かって攻め上って来た。彼らはユダとエルサレムに来て、民の中からすべての君たちを滅ぼし、そのすべての分捕り品をダマスコの王に送った。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代誌 第二 22:8; レビ記 26:37; レビ記 26:8"> アラムの軍隊はわずかな人数で来たが、ユダが彼らの父祖の神、主を捨てていたため、主は非常に大きな軍隊をアラム人の手に渡された。こうして彼らはヨアシュにさばきを下した。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="歴代誌 第二 24:21–22; 歴代誌 第二 28:27; 歴代誌 第二 21:18–20"> 彼らが彼を離れ去ったとき（彼らは彼を重病のまま残していった）、彼自身のしもべたちが祭司エホヤダの子らの血のゆえに彼に対して陰謀を企て、彼の寝台の上で彼を殺した。彼は死に、人々は彼をダビデの町に葬ったが、王たちの墓には葬らなかった。</span>
<span className="v" id="v26" data-v="26" data-xref="列王記第二 12:21"> 彼に対して陰謀を企てた者は次のとおりである。アンモン人の女シムアテの子ザバドと、モアブ人の女シムリテの子エホザバドである。</span>
<span className="v" id="v27" data-v="27" data-xref="歴代誌 第二 16:11; 歴代誌 第二 13:22; 歴代誌 第二 24:12"> 彼の子らに関すること、彼に課せられた重い宣告、および神の家の再建については、見よ、王たちの書の註解書に記されている。彼の子アマツヤが代わって王となった。</span>
</div>

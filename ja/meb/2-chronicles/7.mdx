<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="列王記第一 18:38; 歴代誌上 21:26; レビ記 9:23–24"> ソロモンが祈り終えると、天から火が降ってきて、全焼のささげ物と、いけにえを焼き尽くし、主の栄光がその家に満ちた。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネの黙示録 15:8; 歴代誌 第二 5:14; 出エジプト記 24:17"> 祭司たちは主の家に入ることができなかった。主の栄光が主の家に満ちたからである。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代誌 第二 5:13; 歴代誌 第二 20:21; ルカ 1:50"> イスラエルのすべての子らは、火が降ってきて主の栄光が家の上に現れるのを見た。彼らは敷石の上で地に顔を伏せて拝み、主に感謝をささげて言った。<br /><span className="pl pl-1">「主はいつくしみ深く、</span><br /><span className="pl pl-2">その慈しみはとこしえまで続く。」</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王記第一 8:62–63"> そして王とすべての民は、主の御前でいけにえをささげた。</span>
<span className="v" id="v5" data-v="5" data-xref="ヨハネ 10:22; エゼキエル書 45:17; 歴代誌 第二 30:24"> ソロモン王は牛二万二千頭、羊十二万匹のいけにえをささげた。このようにして、王とすべての民は神の家を奉献した。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代誌 第二 5:12; 歴代誌上 15:16–21; 歴代誌 第二 7:3"> 祭司たちはその部署に従って立ち、レビ人も主を賛美する楽器を持って立った。それらは、ダビデ王が主に感謝をささげるために造った楽器であり、レビ人は「その慈しみはとこしえまで続く」と歌った。祭司たちは彼らの前でラッパを吹き鳴らし、全イスラエルは立っていた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王記第一 8:64–66; ヘブル人への手紙 13:10–12; 歴代誌 第二 36:14"> さらに、ソロモンは主の家の前にある庭の中央を聖別した。ソロモンが造った青銅の祭壇は、全焼のささげ物、穀物のささげ物、そして脂肪を受け入れるには小さすぎたので、彼はそこで全焼のささげ物と、和解のいけにえの脂肪をささげたのである。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="創世記 15:18; 列王記第一 8:65; ネヘミヤ記 8:13–18"> こうしてその時、ソロモンは全イスラエルとともに七日間の祭りを祝った。ハマトの入口からエジプトの川に至るまで、非常に大勢の会衆が集まった。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="レビ記 23:36; 列王記第一 8:65; ヨエル書 1:14"> 八日目に彼らは厳粛な集会を開いた。彼らが祭壇の奉献を七日間行い、祭りを七日間祝ったからである。</span>
<span className="v" id="v10" data-v="10" data-xref="列王記第一 8:66; 詩篇 100:2; 申命記 12:18"> 第七の月の二十三日に、彼は民をその天幕へ送り帰した。彼らは主がダビデとソロモンと、ご自分の民イスラエルに施された恵みのゆえに、喜び、心楽しく帰って行った。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王記第一 9:1–9; 伝道者の書 2:10–11; 歴代誌 第二 2:1"> このようにして、ソロモンは主の家と王の家を完成させた。ソロモンが主の家と自分の王宮について心に思い描いたことは、すべて見事に成し遂げられた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 17:1; 列王記第一 9:2; 歴代誌 第二 7:16"> 主は夜、ソロモンに現れて彼に言われた。「わたしはあなたの祈りを聞き、この場所をわたしのためのいけにえをささげる家として選んだ。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="歴代誌 第二 6:26–28; 申命記 11:17; ヨハネの黙示録 11:6"> もしわたしが天を閉ざして雨が降らないようにするとき、あるいはわたしがいなごに命じてこの地を食い尽くさせるとき、あるいはわたしがわたしの民の中に疫病を送るとき、</span>
<span className="v" id="v14" data-v="14" data-xref="哀歌 3:40–41; ヤコブの手紙 4:9–10; イザヤ書 55:6–7"> わたしの名で呼ばれているわたしの民が自らへりくだり、祈りをささげてわたしの顔を慕い求め、その悪の道から立ち返るなら、わたしは天から聞いて彼らの罪を赦し、彼らの地を癒やす。</span>
<span className="v" id="v15" data-v="15" data-xref="ペテロの手紙第一 3:12; 歴代誌 第二 6:40; ネヘミヤ記 1:6"> 今、わたしの目は開かれ、わたしの耳はこの場所でささげられる祈りに傾けられる。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代誌 第二 7:15; 歴代誌 第二 7:12; 歴代誌 第二 6:5–6"> 今、わたしはこの家を選んで聖別した。それはわたしの名がとこしえにそこにあるためである。わたしの目とわたしの心は、絶えずそこにある。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="ゼカリヤ書 3:7; エゼキエル書 36:27; 列王記第一 11:38"> あなたについて言えば、あなたがあなたの父ダビデが歩んだようにわたしの前を歩み、わたしがあなたに命じたすべてのことに従って行い、わたしの掟と法を守るなら、</span>
<span className="v" id="v18" data-v="18" data-xref="歴代誌 第二 6:16; エレミヤ書 33:20–21; サムエル記第二 7:13–16"> わたしはあなたの父ダビデと契約を結び、『イスラエルの支配者となる者が、あなたから断たれることはない』と言ったとおりに、あなたの王座を堅く立てる。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="レビ記 26:14; 申命記 28:15; レビ記 26:33–46"> しかし、もしあなたがたが背を向け、わたしがあなたがたの前に置いたわたしの掟と命令を捨て去り、行って他の神々に仕え、それらを拝むなら、</span>
<span className="v" id="v20" data-v="20" data-xref="列王記第二 17:20; 申命記 28:37; エレミヤ書 24:9"> わたしは彼らに与えたわたしの地から彼らを根こぎにする。そして、わたしがわたしの名のために聖別したこの家をわたしの目の前から投げ捨て、すべての民の間のことわざとし、笑いぐさとする。</span>
<span className="v" id="v21" data-v="21" data-xref="エレミヤ書 22:8–9; エレミヤ書 16:10–12; エレミヤ書 19:8"> この家がどんなに高くそびえていても、そのそばを通り過ぎる者は皆驚いて言うだろう。『なぜ主はこの地とこの家に、このようなことをされたのか。』</span>
<span className="v" id="v22" data-v="22" data-xref="ダニエル書 9:12; 哀歌 2:16–17; エゼキエル書 14:23"> すると人々は答えるだろう。『彼らをエジプトの地から導き出した父祖の神、主を捨てて、他の神々につき従い、それらを拝み、それらに仕えたからだ。それゆえ、主はこのすべてのわざわいを彼らの上に下されたのだ。』」</span>
</div>
</div>

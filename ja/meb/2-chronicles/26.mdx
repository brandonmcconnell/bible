<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌 第二 22:1; マタイ 1:8–9; 歴代誌 第二 33:25"> 全ユダの民は、十六歳であったウジヤを取り、彼の父アマツヤに代わって王とした。</span>
<span className="v" id="v2" data-v="2" data-xref="列王記第二 16:6; 歴代誌 第二 25:28; 歴代誌 第二 25:23"> 父王がその父祖たちとともに眠った後、ウジヤはエロテを建て直し、それをユダに取り戻した。</span>
<span className="v" id="v3" data-v="3" data-xref="列王記第二 15:2–3; アモス書 1:1; ホセア書 1:1"> ウジヤは十六歳で王となり、エルサレムで五十二年間治めた。母の名はエキルヤといい、エルサレムの出身であった。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌 第二 25:2"> 彼は、その父アマツヤが行ったすべてのことに従って、主の目に正しいことを行った。</span>
<span className="v" id="v5" data-v="5" data-xref="歴代誌 第二 15:2; 歴代誌 第二 24:2; 歴代誌上 22:13"> 彼は、神の幻に通じていたゼカリヤの時代に、神を尋ね求めることに心を定めた。彼が主を尋ね求めている間、神は彼を栄えさせられた。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 14:29; サムエル記第一 5:6; サムエル記第一 5:1"> 彼は出て行ってペリシテ人と戦い、ガテの城壁、ヤブネの城壁、アシュドドの城壁を打ち壊した。そして彼はアシュドドの地方とペリシテ人の間に町々を建てた。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌 第二 21:16; 歴代誌上 5:20; 歴代誌 第二 14:11"> 神は、ペリシテ人、グル・バアルに住むアラビア人、およびメウニムに彼が戦うのを助けられた。</span>
<span className="v" id="v8" data-v="8" data-xref="サムエル記第二 8:2; 歴代誌 第二 17:11; 創世記 19:38"> アンモン人はウジヤに貢ぎ物を持って来た。彼は非常に強くなったので、その名はエジプトの入り口にまで広まった。</span>
<span className="v" id="v9" data-v="9" data-xref="ネヘミヤ記 3:13; 歴代誌 第二 25:23; 列王記第二 14:13"> さらにウジヤはエルサレムで、隅の門、谷の門、および城壁の曲がり角に塔を建て、それらを堅固にした。</span>
<span className="v" id="v10" data-v="10" data-xref="創世記 26:18–21; イザヤ書 29:17; 列王記第二 3:4"> 彼は荒野に塔を建て、多くの貯水池を掘った。彼には低地にも平野にも多くの家畜がいたからである。また、彼には山地や豊かな畑に農夫やぶどう畑の番人がいた。彼が農業を愛していたからである。</span>
<span className="v" id="v11" data-v="11" data-xref="列王記第二 5:2"> さらに、ウジヤには部隊ごとに戦いに出る軍勢があった。その登録は、王の指揮官の一人ハナニヤのもとで、書記エイエルと役人マアセヤが行った。</span>
<span className="v" id="v12" data-v="12"> 父祖の家々の長たち、すなわち力ある勇士たちの総数は二千六百人であった。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代誌 第二 25:5; 歴代誌 第二 14:8; 歴代誌 第二 11:1"> 彼らの指揮の下には三十万七千五百人の軍隊があり、王を助けて敵に立ち向かうために、強大な力をもって戦った。</span>
<span className="v" id="v14" data-v="14" data-xref="士師記 20:16; サムエル記第一 17:49"> ウジヤは彼らのため、すなわち全軍隊のために、大盾、槍、兜、鎧、弓、および石投げのための石を準備した。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 31:4; マタイ 4:24; 歴代誌 第二 2:7"> 彼はエルサレムに、熟練した者たちが考案した仕掛けを造り、それを塔や城壁の頂の上に置いて、矢や大きな石を放てるようにした。彼が強くなるまで驚くべき助けを得たため、その名は遠くまで広まった。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歴代誌 第二 32:25; 歴代誌 第二 25:19; 箴言 16:18"> しかし、彼が強くなると、その心は高ぶって堕落し、自分の神、主に対して背信の罪を犯した。彼が香の祭壇で香をたくために、主の神殿に入ったからである。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代誌上 6:10; 歴代誌上 26:6; 歴代誌上 12:28"> 祭司アザルヤは彼に続いて中に入った。彼とともに、主に仕える祭司たち八十人がいた。彼らはいずれも勇敢な者たちであった。</span>
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 30:7–8; 民数記 18:7; エレミヤ書 13:18"> 彼らはウジヤ王に立ち向かって、彼に言った。「ウジヤよ、主に香をたくことはあなたのすることではなく、香をたくために聖別されたアロンの子らである祭司たちのすることです。聖所から出てください。あなたは背信の罪を犯しました。主なる神から誉れを受けることもありません。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="民数記 12:10; 歴代誌 第二 25:16; 列王記第二 5:25–27"> するとウジヤは怒った。彼は香をたくために香炉を手にしていた。彼が祭司たちに向かって怒っている間に、主の家の香の祭壇のそばで、祭司たちの前で彼の額に規定の病が発生した。</span>
<span className="v" id="v20" data-v="20" data-xref="申命記 28:22; エステル記 6:12; レビ記 14:34"> 祭司長アザルヤとすべての祭司たちが彼を見ると、見よ、彼は額に規定の病を患っていたので、彼らは急いで彼をそこから追い出した。彼自身も主が彼を打たれたので、急いで出て行った。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 13:46; 民数記 12:15; 列王記第二 7:3"> ウジヤ王は死ぬ日まで規定の病に冒され、規定の病を患っていたため、隔離された家に住んだ。彼は主の家から締め出されていたからである。彼の子ヨタムが王の家を管理し、その地の民をさばいた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 1:1; イザヤ書 6:1; 歴代誌 第二 9:29"> ウジヤのその他の事績は、最初から最後まで、アモツの子である預言者イザヤが書き記した。</span>
<span className="v" id="v23" data-v="23" data-xref="歴代誌 第二 28:27; 歴代誌 第二 21:20; 歴代誌 第二 26:18"> ウジヤはその父祖たちとともに眠り、人々は「彼は規定の病を患っている」と言って、王たちの墓地に隣接する野にその父祖たちとともに彼を葬った。その子ヨタムが代わって王となった。</span>
</div>

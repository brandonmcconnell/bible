<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王記第二 18:13–37; 列王記第二 17:6; 歴代誌 第二 20:1–2"> これらの忠実な働きの後、アッシリアの王セナケリブが来てユダに侵入した。彼は防備の町々に向かって陣を敷き、それらを自分のものにしようと考えた。</span>
<span className="v" id="v2" data-v="2" data-xref="ルカ 9:53; ルカ 9:51; 列王記第二 12:17"> ヒゼキヤはセナケリブが来たこと、そして彼がエルサレムと戦うつもりであることを見ると、</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 24:6; 箴言 20:18; 箴言 15:22"> 君たちおよび勇士たちと相談し、町の外にある泉の水を止めることにした。彼らは彼を助けた。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌 第二 32:30; 列王記第二 18:9; 列王記第一 19:21"> 多くの民が集まり、すべての泉と、その地の中央を流れる谷川を止めて言った。「なぜアッシリアの王に来て豊かな水を見つけさせるのか。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歴代誌 第二 25:23; 列王記第一 9:24; 列王記第二 25:4"> 彼は勇気を出して、崩れていた城壁をすべて建て直して塔まで築き上げ、さらに外側にもう一つの城壁を築き、ダビデの町のミロを堅固にし、武器と盾を大量に造った。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 40:2; 歴代誌 第二 30:22; ネヘミヤ記 8:16"> 彼は民の上に戦いの長たちを任命し、彼らを町の門の広場に集め、彼らを励まして言った。</span>
<span className="v" id="v7" data-v="7" data-xref="列王記第二 6:16; ローマ人への手紙 8:31; エペソ人への手紙 6:10"> 「強く、雄々しくありなさい。アッシリアの王と、彼とともにいるすべての大軍を恐れてはならない。おののいてはならない。彼とともにいる者よりも大いなる方が、わたしたちとともにおられるからだ。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 17:5; 歴代誌 第二 20:17; イザヤ書 41:10"> 彼とともにあるのは肉の腕であるが、わたしたちとともにあるのは、わたしたちを助け、わたしたちの戦いを戦ってくださるわたしたちの神、主である。」民はユダの王ヒゼキヤの言葉に勇気づけられた。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王記第二 18:17; ヨシュア記 10:31; イザヤ書 36:2"> この後、アッシリアの王セナケリブは、ラキシュの前におり、その全軍勢も彼とともにいたが、ユダの王ヒゼキヤと、エルサレムにいる全ユダのもとに、そのしもべたちをエルサレムへ遣わして言った。</span>
<span className="v" id="v10" data-v="10" data-xref="列王記第二 18:19; イザヤ書 36:4"> 「アッシリアの王セナケリブはこう言う。『包囲されたエルサレムにとどまるあなたがたは、何を頼みとしているのか。</span>
<span className="v" id="v11" data-v="11" data-xref="マタイ 27:43; 詩篇 11:1–3; イザヤ書 36:18"> ヒゼキヤは、「わたしたちの神、主がアッシリアの王の手からわたしたちを救い出してくださる」と言って、ききんと渇きによってあなたがたを死なせるために、あなたがたをそそのかしているではないか。</span>
<span className="v" id="v12" data-v="12" data-xref="歴代誌 第二 31:1; 申命記 12:13–14; 申命記 12:26–27"> その主の高き所と祭壇を取り除き、ユダとエルサレムに命じて、「一つの祭壇の前で礼拝し、その上で香をたかなければならない」と言ったのは、このヒゼキヤではないか。</span>
<span className="v" id="v13" data-v="13" data-xref="列王記第二 18:33–35; イザヤ書 44:8–10; ダニエル書 4:30"> あなたがたは、わたしとわたしの父祖たちが他の国々のすべての民にしてきたことを知らないのか。他の国々の神々は、わたしの手から自分の国を救い出すことが少しでもできたか。</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 10:11–12; 出エジプト記 15:9–11; イザヤ書 42:8"> わたしの父祖たちが完全に滅ぼした国々のすべての神々のうち、だれが自分の民をわたしの手から救い出すことができたというのか。それなのに、あなたがたの神がわたしの手からあなたがたを救い出すことができるのか。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 5:2; ダニエル書 3:15; イザヤ書 36:18"> だから今、ヒゼキヤに欺かれてはならない。このようにそそのかされてはならない。彼を信じてはならない。どんな国の、どんな王国の神も、自分の民をわたしの手やわたしの父祖たちの手から救い出すことはできなかった。ましてや、あなたがたの神がわたしの手からあなたがたを救い出せるはずがない。』」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="詩篇 73:9; ヨハネ 15:21; ヨブ記 15:25–26"> 彼のしもべたちは、神、主と、そのしもべヒゼキヤに対してさらに言葉を重ねた。</span>
<span className="v" id="v17" data-v="17" data-xref="イザヤ書 37:14; 列王記第二 19:12; イザヤ書 37:28–29"> 彼はまた、イスラエルの神、主をそしり、主に逆らって次のように語る手紙を書いた。「他の国々の神々が自分の民をわたしの手から救い出さなかったように、ヒゼキヤの神もその民をわたしの手から救い出すことはない。」</span>
<span className="v" id="v18" data-v="18" data-xref="サムエル記第一 17:10; 列王記第二 18:26–28; サムエル記第一 17:26"> 彼らは、城壁の上にいるエルサレムの民に向かって大声でユダヤの言葉で叫び、彼らを恐れさせ、おじけづかせようとした。それは彼らが町を奪い取るためであった。</span>
<span className="v" id="v19" data-v="19" data-xref="列王記第二 19:18; イザヤ書 2:8; エレミヤ書 32:30"> 彼らはエルサレムの神について、人の手で造られた地上の民の神々と同じように語った。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="詩篇 91:14–15; イザヤ書 37:14–20; 歴代誌 第二 14:11"> ヒゼキヤ王と、アモツの子である預言者イザヤは、このことのゆえに祈り、天に向かって叫び求めた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="イザヤ書 37:36–38; 詩篇 76:5; 詩篇 18:50"> 主は御使いを遣わし、アッシリアの王の宿営にいたすべての力ある勇士たち、指導者たち、および長たちを断ち切られた。こうして彼は恥を受けて自分の国へ帰った。彼が自分の神の家に入ったとき、彼自身の体から出た者たち<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="すなわち、彼自身の息子たちである。">a</a></sup>が、そこで彼を剣で打ち倒した。</span>
<span className="v" id="v22" data-v="22" data-xref="イザヤ書 31:4–5; 詩篇 18:48–50; テサロニケ人への第二の手紙 3:5"> このようにして、主はヒゼキヤとエルサレムの住民を、アッシリアの王セナケリブの手とあらゆる敵の手から救い出し、四方で彼らを守られた。</span>
<span className="v" id="v23" data-v="23" data-xref="歴代誌 第二 17:5; マタイ 2:11; 歴代誌 第二 1:1"> 多くの者が主への贈り物をエルサレムに持って来、またユダの王ヒゼキヤに貴重な品々を持って来た。この後、彼はすべての国々の目にあがめられた。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 38:1–8; 列王記第二 20:1–11; イザヤ書 38:21–22"> そのころ、ヒゼキヤは死ぬほどの病になった。彼が主に祈ると、主は彼に語りかけ、しるしを与えられた。</span>
<span className="v" id="v25" data-v="25" data-xref="歴代誌 第二 24:18; 歴代誌 第二 26:16; 歴代誌 第二 32:31"> しかしヒゼキヤは、彼に与えられた恵みに応えなかった。彼の心が高ぶっていたからである。それゆえ、彼と、ユダおよびエルサレムの上に御怒りが下った。</span>
<span className="v" id="v26" data-v="26" data-xref="エレミヤ書 26:18–19; 歴代誌 第二 34:27–28; 歴代誌 第二 33:12"> しかしヒゼキヤは心の高ぶりを悔いてへりくだり、エルサレムの住民もともにへりくだったので、ヒゼキヤの時代に主の御怒りが彼らに臨むことはなかった。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歴代誌上 27:25–31; 歴代誌 第二 1:12; 箴言 10:22"> ヒゼキヤは非常に豊かな富と誉れを持っていた。彼は銀、金、宝石、香料、盾、およびあらゆる種類の高価な器のために宝物倉を造った。</span>
<span className="v" id="v28" data-v="28" data-xref="サムエル記第二 7:8; 歴代誌 第二 26:10; 列王記第一 4:26"> また、穀物、新しいぶどう酒、油の収穫のための倉を造り、あらゆる種類の家畜のための厩、および羊の群れのための囲いを造った。</span>
<span className="v" id="v29" data-v="29" data-xref="歴代誌上 29:12; 箴言 10:22; サムエル記第一 2:7"> さらに彼は自分のために町々を建て、羊や牛の群れを豊富に持っていた。神が彼に非常に豊かな財産を与えられたからである。</span>
<span className="v" id="v30" data-v="30" data-xref="列王記第一 1:33; イザヤ書 22:9–11; 詩篇 1:1–3"> ギホンの上の水源をせき止め、ダビデの町の西側にまっすぐ流れを下らせたのも、このヒゼキヤである。ヒゼキヤはそのすべてのわざにおいて栄えた。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="申命記 8:2; 箴言 17:3; 創世記 22:1"> ただし、その地で起こった不思議について尋ねるため、バビロンの君たちから使節が来たとき、神は彼を試し、その心にあるものをすべて明らかにするために、彼を離れられた。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="イザヤ書 36:1–22; 列王記第二 18:1–20; 歴代誌 第二 31:20–21"> ヒゼキヤのその他の事績とその良い行いは、見よ、アモツの子である預言者イザヤの幻の中、すなわちユダとイスラエルの王たちの書に記されている。</span>
<span className="v" id="v33" data-v="33" data-xref="箴言 10:7; 列王記第一 1:21; 歴代誌 第二 16:14"> ヒゼキヤはその父祖たちとともに眠り、人々は彼をダビデの子らの墓へ上る所に葬った。全ユダとエルサレムの住民は彼の死に際して彼に誉れを与えた。その子マナセが代わって王となった。</span>
</div>
</div>

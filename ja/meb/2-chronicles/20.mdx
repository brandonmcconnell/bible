<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="詩篇 83:5–8; イザヤ書 16:6; 歴代誌 第二 32:1"> その後、モアブの子らとアンモンの子ら、また彼らとともにメウニ人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="七十人訳では メウニ人、ヘブル語本文では アンモン人となっている。">a</a></sup>の一部が、ヨシャファテに向かって戦いにやって来た。</span>
<span className="v" id="v2" data-v="2" data-xref="創世記 14:7; サムエル記第一 23:29; ヨシュア記 15:62"> すると、ある者たちが来てヨシャファテに告げた。「大軍が海のかなた、アラムからあなたに向かって来ています。見よ、彼らはハツァツォン・タマル、すなわちエン・ゲディにいます。」</span>
<span className="v" id="v3" data-v="3" data-xref="ダニエル書 9:3; 歴代誌 第二 19:3; サムエル記第一 7:6"> ヨシャファテは恐れたが、主を尋ね求めることに心を定めた。彼は全ユダに断食を布告した。</span>
<span className="v" id="v4" data-v="4" data-xref="詩篇 50:15; 詩篇 60:10–12; 詩篇 69:35"> ユダは主からの助けを求めるために集まった。彼らは主を尋ね求めるために、ユダのすべての町々からやって来た。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王記第二 19:15–19; 歴代誌 第二 6:12–13; 歴代誌 第二 34:31"> ヨシャファテは、主の家の新しい庭の前で、ユダとエルサレムの会衆の中に立ち、</span>
<span className="v" id="v6" data-v="6" data-xref="申命記 4:39; 歴代誌上 29:11–12; ダニエル書 4:17"> 言った。「わたしたちの父祖の神、主よ。あなたは天におられる神ではありませんか。あなたは国々のすべての王国を治める支配者ではありませんか。あなたの御手には力と勢いがあり、だれもあなたに立ち向かうことはできません。</span>
<span className="v" id="v7" data-v="7" data-xref="イザヤ書 41:8; ヤコブの手紙 2:23; 詩篇 44:2"> わたしたちの神よ。あなたは、あなたの民イスラエルの前からこの地の住民を追い出し、それをあなたの友であるアブラハムの子孫<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または「種」。">b</a></sup>にとこしえに与えられたではありませんか。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代誌 第二 6:10; 歴代誌 第二 2:4"> 彼らはそこに住み、あなたの御名のために聖所を建てて言いました。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代誌 第二 6:28–30; 歴代誌 第二 6:20; 列王記第一 8:33"> 『もしわたしたちに悪が、すなわち剣、さばき、疫病、またはききんが臨むなら、わたしたちはこの家の前、およびあなたの御前に立ち（あなたの御名がこの家にあるからです）、わたしたちの苦しみの中であなたに叫び求めます。そうすれば、あなたは聞いて救ってくださるでしょう。』</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 2:19; 申命記 2:4–5; 申命記 2:9"> 今、見よ。アンモン、モアブ、およびセイル山の子らがいます。イスラエルがエジプトの地から出て来たとき、あなたは彼らがそこに攻め入ることをお許しになりませんでした。それで彼らはそこから身を避け、彼らを滅ぼしませんでした。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 83:3–12; 士師記 11:23–24; エレミヤ書 18:20"> 見よ、彼らがどのようにわたしたちに報いているかを。あなたがわたしたちに受け継がせてくださったあなたがわたしたちに受け継がせた領地から、彼らはわたしたちを追い出そうとしています。</span>
<span className="v" id="v12" data-v="12" data-xref="詩篇 121:1–2; 詩篇 25:15; 詩篇 141:8"> わたしたちの神よ。あなたは彼らをさばかれないのですか。わたしたちに向かって来るこの大軍に対して、わたしたちには何の力もありません。わたしたちは何をすればよいか分かりませんが、わたしたちの目はあなたに向かっています。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="エズラ記 10:1; 使徒の働き 21:5; 申命記 29:10"> 全ユダは、幼い者たち、妻たち、子どもたちとともに、主の御前に立っていた。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歴代誌 第二 15:1; 歴代誌 第二 24:20; 使徒の働き 10:31"> そのとき、会衆の真ん中で、主の霊がアサフの子らの一人であるレビ人、マタヌヤの子エヒエルの子ベナヤの子ゼカリヤの子ヤハジエルに臨んだ。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代誌 第二 32:7–8; 申命記 31:6; 出エジプト記 14:13–14"> 彼は言った。「全ユダとエルサレムの住民、およびヨシャファテ王よ、聞きなさい。主はあなたがたにこう言われる。『この大軍のゆえに恐れてはならない。おののいてはならない。この戦いはあなたがたのものではなく、神のものだからである。</span>
<span className="v" id="v16" data-v="16"> 明日、彼らに向かって下って行きなさい。見よ、彼らはツィツの坂を上って来る。あなたがたは、エルエルの荒野の前の谷の端で彼らを見つけるだろう。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 14:13–14; 歴代誌 第二 15:2; イザヤ書 41:10"> あなたがたはこの戦いで戦う必要はない。配置につき、じっと立って、あなたがたとともにいる主の救いを見よ、ユダとエルサレムよ。恐れてはならない。おののいてはならない。明日、彼らに向かって出て行きなさい。主があなたがたとともにいるからである。』」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出エジプト記 4:31; 歴代誌 第二 7:3; 創世記 24:26"> ヨシャファテは地に顔を伏せて頭を下げ、全ユダとエルサレムの住民も主の御前にひれ伏して、主を礼拝した。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代誌上 15:16–22; 歴代誌上 16:42; 歴代誌上 16:5"> ケハテ人の子らとコラ人の子らであるレビ人たちが立ち上がり、非常に大きな声でイスラエルの神、主を賛美した。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ローマ人への手紙 8:31; ヨハネ 14:1; ヨハネ 11:40"> 彼らは朝早く起き、テコアの荒野へ出て行った。彼らが出て行くとき、ヨシャファテは立って言った。「ユダとエルサレムの住民よ、わたしに聞きなさい。あなたがたの神、主を信じなさい。そうすれば、あなたがたは揺るがない。その預言者たちを信じなさい。そうすれば、あなたがたは栄える。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="詩篇 107:1; 詩篇 106:1; 歴代誌 第二 5:13"> 彼は民と相談し、主に向かって歌を歌う者たち、および軍隊の前に進み出て聖なる装いをして賛美する者たちを任命し、彼らに「主に感謝せよ。その慈しみはとこしえまで続く」と言わせた。</span>
<span className="v" id="v22" data-v="22" data-xref="サムエル記第一 14:20; イザヤ書 19:2; エゼキエル書 38:21"> 彼らが喜びの歌と賛美を上げ始めたとき、主はユダに向かって来ていたアンモン、モアブ、セイル山の子らに対して伏兵を設けられたので、彼らは打ち負かされた。</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 7:22; サムエル記第一 14:20; エゼキエル書 35:2–3"> アンモンとモアブの子らがセイル山の住民に立ち向かい、彼らを完全に殺して滅ぼしたからである。彼らがセイルの住民を滅ぼし尽くすと、彼らは互いに滅ぼし合った。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="イザヤ書 37:36; 詩篇 110:6; 歴代誌上 5:22"> ユダが荒野を見渡す場所に来て、その大軍を見ると、見よ、彼らは地に倒れた死体となっており、逃れた者はだれもいなかった。</span>
<span className="v" id="v25" data-v="25" data-xref="サムエル記第一 30:19–20; 列王記第二 7:9–16; 民数記 31:15"> ヨシャファテとその民が彼らの戦利品を奪い取りに来たとき、彼らはそこに多くの財宝と、遺体につけられた高価な品々を見つけ、自分たちのものとした。それは運びきれないほどであった。彼らは戦利品を三日間奪い取った。それは非常に多かったからである。</span>
<span className="v" id="v26" data-v="26" data-xref="出エジプト記 17:15; 創世記 32:20; 歴代誌 第二 5:9"> 四日目に彼らはベラカの谷に集まった。彼らがそこで主をほめたたえたからである。それゆえ、その場所の名は今日に至るまでベラカの谷<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="「ベラカ」は「祝福」を意味する。">c</a></sup>と呼ばれている。</span>
<span className="v" id="v27" data-v="27" data-xref="ネヘミヤ記 12:43; ヘブル人への手紙 6:20; 詩篇 30:1"> それからユダとエルサレムのすべての人々は、ヨシャファテを先頭にして、喜びをもって再びエルサレムへ帰って行った。主が敵に勝たせ、彼らを喜ばせてくださったからである。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 14:2–3; 詩篇 57:8; 詩篇 92:3"> 彼らは琴と竪琴とラッパを奏でて、エルサレムの主の家に来た。</span>
<span className="v" id="v29" data-v="29" data-xref="歴代誌 第二 17:10; 列王記第二 7:6; 出エジプト記 23:27"> 主がイスラエルの敵と戦われたことを聞いたとき、神の恐れがその国々のすべての王国に臨んだ。</span>
<span className="v" id="v30" data-v="30" data-xref="歴代誌 第二 15:15; 歴代誌 第二 14:6–7; サムエル記第二 7:1"> こうしてヨシャファテの国は穏やかであった。彼の神が四方に安息を与えられたからである。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王記第一 22:41–44"> ヨシャファテはユダを治めた。彼は三十五歳で王となり、エルサレムで二十五年間治めた。その母の名はアズバといい、シルヒの娘であった。</span>
<span className="v" id="v32" data-v="32" data-xref="歴代誌 第二 14:2–5; 列王記第一 15:11; 歴代誌 第二 14:11–13"> 彼は父アサの道を歩んでそれからそれることなく、主の目に正しいことを行った。</span>
<span className="v" id="v33" data-v="33" data-xref="歴代誌 第二 17:6; 歴代誌 第二 19:3; 歴代誌 第二 12:14"> しかし、高き所は取り除かれず、民はなお、自分たちの父祖の神に心を定めていなかった。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="列王記第一 16:1; 歴代誌 第二 19:2; 列王記第一 16:7"> ヨシャファテのその他の事績は、最初から最後まで、見よ、イスラエルの王たちの書に収められているハナニの子イエフの記録に記されている。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="列王記第一 22:48–49; 列王記第二 1:2–16"> その後、ユダの王ヨシャファテはイスラエルの王アハズヤと手を結んだ。このアハズヤは非常に悪いことを行った。</span>
<span className="v" id="v36" data-v="36" data-xref="列王記第一 10:22; 歴代誌 第二 9:21; 列王記第一 9:26"> 彼はタルシシュへ行く船を造るために彼と手を結んだ。彼らはエツヨン・ゲベルで船を造った。</span>
<span className="v" id="v37" data-v="37" data-xref="箴言 13:20; 歴代誌 第二 19:2; 歴代誌 第二 9:21"> そのとき、マレシャのドダワフの子エリエゼルがヨシャファテに向かって預言して言った。「あなたがアハズヤと手を結んだため、主はあなたのわざを打ち砕かれた。」船は難破し、タルシシュへ行くことができなかった。</span>
</div>
</div>

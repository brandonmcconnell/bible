<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王記第二 18:1–3; 歴代誌上 3:13; 歴代誌 第二 26:5"> ヒゼキヤは二十五歳で王となり、エルサレムで二十九年間治めた。母の名はアビヤといい、ゼカリヤの娘であった。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代誌 第二 34:2; 歴代誌 第二 28:1"> 彼は、その父ダビデが行ったすべてのことに従って、主の目に正しいことを行った。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代誌 第二 28:24; 歴代誌 第二 29:7; マタイ 6:33"> 彼はその治世の第一年の最初の月に、主の家の戸を開き、それを修理した。</span>
<span className="v" id="v4" data-v="4" data-xref="エレミヤ書 19:2; ネヘミヤ記 3:29; 歴代誌 第二 32:6"> 彼は祭司たちとレビ人を連れて来て、彼らを東の広場に集め、</span>
<span className="v" id="v5" data-v="5" data-xref="歴代誌 第二 35:6; コリント人への第一の手紙 3:16–17; 歴代誌 第二 34:3–8"> 彼らに言った。「レビ人たちよ、わたしの言うことを聞きなさい。今、自らを聖別し、あなたがたの父祖の神、主の家を聖別し、聖所から汚れを持ち出しなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="エゼキエル書 8:16; エレミヤ書 2:27; ダニエル書 9:16"> わたしたちの父祖たちは背信の罪を犯し、わたしたちの神、主の目に悪とされることを行い、主を捨て、主の住まいから顔を背け、背を向けたからである。</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌 第二 28:24; レビ記 24:2–8; 歴代誌 第二 29:3"> また彼らは玄関の扉を閉じ、ともしびを消し、イスラエルの神に対して聖所で香をたくことも、全焼のささげ物をささげることもしなかった。</span>
<span className="v" id="v8" data-v="8" data-xref="エレミヤ書 25:9; エレミヤ書 25:18; エレミヤ書 29:18"> それゆえ、主の御怒りがユダとエルサレムに臨み、あなたがたが自分の目で見ているように、主は彼らを恐怖と驚きと嘲りの的とされた。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代誌 第二 28:17; 歴代誌 第二 28:5–8; 哀歌 5:7"> 見よ。このためにわたしたちの父祖たちは剣に倒れ、わたしたちの息子、娘、そして妻たちは捕囚となっている。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 50:5; 歴代誌 第二 23:16; エズラ記 10:3"> 今、わたしはイスラエルの神、主と契約を結び、主の激しい怒りをわたしたちから遠ざけようと思う。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 10:8; ガラテヤ人への手紙 6:7–8; 民数記 8:6–14"> わたしの子らよ。今、怠ってはならない。主があなたがたを選んで、主の御前に立って仕える者とし、主に仕える者となって香をたくようにされたからである。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数記 3:19–20; 歴代誌上 15:5–7; 民数記 4:2–20"> そこでレビ人たちが立ち上がった。ケハテ人の子らのうちからは、アマサイの子マハテ、アザルヤの子ヨエル。メラリの子らのうちからは、アブディの子キシュ、エハレルエルの子アザルヤ。ゲルション人のうちからは、ジムマの子ヨア、ヨアの子エデン。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代誌上 6:39; 歴代誌上 15:8; 歴代誌上 15:17"> エリツァファンの子らのうちからは、シムリとエウエル。アサフの子らのうちからは、ゼカリヤとマタヌヤ。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代誌上 6:33; 歴代誌上 25:1; 歴代誌上 25:6"> ヘマンの子らのうちからは、エヒエルとシムイ。エドトンの子らのうちからは、シェマヤとウジエル。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代誌 第二 30:12; 歴代誌上 23:28; 歴代誌 第二 29:5"> 彼らは自分たちの兄弟を集め、自らを聖別し、主の言葉に基づく王の命令に従って、主の家をきよめるために入った。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代誌 第二 15:16; マタイ 21:12–13; マタイ 23:27"> 祭司たちは主の家をきよめるためにその内側に入り、主の神殿で見つけたすべての汚れを主の家の庭に持ち出した。レビ人はそれを受け取り、外のキデロンの谷川へ運び出した。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 12:2–8; 歴代誌 第二 3:4; 列王記第一 6:3"> 彼らは第一の月の一日に聖別し始め、その月の第八の日に主の玄関に達した。彼らは八日間で主の家を聖別し、最初の月の第十六の日に終えた。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代誌 第二 4:1; 歴代誌 第二 4:7–8; 歴代誌 第二 13:11"> それから彼らは宮殿の中にいるヒゼキヤ王のところに行って、言った。「わたしたちは主の家全体、全焼のささげ物の祭壇とそのすべての器、備えのパンの机とそのすべての器をきよめました。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代誌 第二 28:24"> さらに、アハズ王がその治世において背信の罪を犯したときに捨てたすべての器を、わたしたちは整えて聖別しました。見よ、それらは主の祭壇の前にあります。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="ヨシュア記 6:12; エレミヤ書 25:4; 出エジプト記 24:4"> そこでヒゼキヤ王は朝早く起き、町の君たちを集めて主の家に上って行った。</span>
<span className="v" id="v21" data-v="21" data-xref="レビ記 4:3–14; ヨブ記 42:8; エゼキエル書 45:23"> 彼らは王国のため、聖所のため、そしてユダのために、罪のささげ物として、雄牛七頭、雄羊七頭、子羊七匹、雄ヤギ七頭を引いて来た。王はアロンの子らである祭司たちに命じて、主の祭壇でそれらをささげさせた。</span>
<span className="v" id="v22" data-v="22" data-xref="レビ記 4:18; レビ記 8:19; レビ記 8:24"> そこで彼らは雄牛をほふり、祭司たちはその血を受け取って祭壇に振りかけた。彼らは雄羊をほふり、その血を祭壇に振りかけた。また、彼らは子羊をほふり、その血を祭壇に振りかけた。</span>
<span className="v" id="v23" data-v="23" data-xref="レビ記 4:15; レビ記 4:24; レビ記 1:4"> 彼らは罪のささげ物とする雄ヤギを王と会衆の前に引いて行き、それらの上に手を置いた。</span>
<span className="v" id="v24" data-v="24" data-xref="レビ記 14:20; エゼキエル書 45:15; コリント人への第二の手紙 5:18–21"> 祭司たちはそれらをほふり、全イスラエルのために贖いをするために、その血をもって祭壇で罪のささげ物をした。王が、全焼のささげ物と罪のささげ物は全イスラエルのためにささげられるべきだと命じたからである。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="歴代誌 第二 8:14; 歴代誌上 23:5; サムエル記第二 24:11"> 王は、ダビデ、王の先見者ガド、および預言者ナタンの命令に従って、主の家にレビ人を配置し、シンバル、竪琴、琴を持たせた。その命令は預言者たちを通して主から出たものだったからである。</span>
<span className="v" id="v26" data-v="26" data-xref="歴代誌上 23:5; 歴代誌上 15:24; アモス書 6:5"> レビ人はダビデの楽器を持ち、祭司たちはラッパを持って立った。</span>
<span className="v" id="v27" data-v="27" data-xref="歴代誌 第二 23:18; 詩篇 137:3–4; 歴代誌 第二 20:21"> ヒゼキヤは祭壇で全焼のささげ物をささげるように命じた。全焼のささげ物が始まると、主への歌も始まり、ラッパとともに、イスラエルの王ダビデの楽器が奏でられた。</span>
<span className="v" id="v28" data-v="28" data-xref="ヨハネの黙示録 5:8–14; 詩篇 89:15; 詩篇 68:24–26"> 全会衆は礼拝し、歌う者たちは歌い、ラッパを吹き鳴らす者たちはラッパを吹いた。このすべては全焼のささげ物が終わるまで続いた。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="歴代誌 第二 20:18; 歴代誌上 29:20; ピリピ人への手紙 2:10–11"> ささげ物が終わると、王と、彼とともにいたすべての者たちはひざまずいて礼拝した。</span>
<span className="v" id="v30" data-v="30" data-xref="ピリピ人への手紙 4:4; 詩篇 95:1–2; 歴代誌上 16:7–36"> さらにヒゼキヤ王と君たちは、ダビデと先見者アサフの言葉をもって主を賛美するようにレビ人に命じた。彼らは喜びをもって賛美し、頭を垂れて礼拝した。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="歴代誌 第二 13:9; 出エジプト記 35:22; レビ記 7:12"> その後、ヒゼキヤは言った。「今、あなたがたは主に身を献げた。近づいて、いけにえと感謝のささげ物を主の家に持って来なさい。」会衆はいけにえと感謝のささげ物を持って来た。また、心から進んでささげる者は皆、全焼のささげ物を持って来た。</span>
<span className="v" id="v32" data-v="32" data-xref="エズラ記 6:17; 列王記第一 3:4; 歴代誌上 29:21"> 会衆が持って来た全焼のささげ物の数は、雄牛七十頭、雄羊百頭、子羊二百匹であった。これらはすべて主への全焼のささげ物であった。</span>
<span className="v" id="v33" data-v="33"> 聖別されたものは、雄牛六百頭と羊三千匹であった。</span>
<span className="v" id="v34" data-v="34" data-xref="歴代誌 第二 35:11; 歴代誌 第二 30:3; 詩篇 94:15"> しかし、祭司の数が少なすぎて、すべての全焼のささげ物の皮を剥ぐことができなかった。そのため、彼らの兄弟であるレビ人が、その働きが終わるまで、また祭司たちが自らを聖別するまで彼らを助けた。自らを聖別することにおいて、レビ人のほうが祭司たちよりも、心を整えて身を聖別していたからである。</span>
<span className="v" id="v35" data-v="35" data-xref="民数記 15:5–10; 出エジプト記 29:13; 歴代誌上 16:37–42"> また、全焼のささげ物は、和解のいけにえの脂肪や、全焼のささげ物ごとの注ぎのささげ物とともに豊富にあった。このようにして、主の家の奉仕が整えられた。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒の働き 2:41; テサロニケ人への手紙第一 3:8–9; 歴代誌上 29:9"> ヒゼキヤとすべての民は、神が民のために備えてくださったことを喜んだ。このことが短期間に成し遂げられたからである。</span>
</div>

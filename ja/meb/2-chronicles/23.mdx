<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌 第二 15:12; 列王記第二 11:4–20; ネヘミヤ記 9:38"> 第七年に、エホヤダは決意を固め、百人の長たち、すなわちエロハムの子アザルヤ、エホハナンの子イシュマエル、オベドの子アザルヤ、アダヤの子マアセヤ、ジクリの子エリシャファテと契約を結んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代誌 第二 11:13–17; 歴代誌 第二 21:2; 歴代誌上 15:12"> 彼らはユダを巡り歩き、ユダのすべての町々からレビ人を、またイスラエルの父祖の家々の長たちを集めた。そして彼らはエルサレムに来た。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代誌 第二 21:7; サムエル記第二 7:12; 歴代誌 第二 6:16"> 全会衆は神の家で王と契約を結んだ。エホヤダ<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="ヘブル語本文では 彼">a</a></sup>は彼らに言った。「見よ。主がダビデの子らについて語られたとおりに、王の子が治めなければならない。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌上 23:3–6; 歴代誌上 26:13–16; ルカ 1:8–9"> あなたがたがしなければならないことは、これである。安息日に入って来るあなたがた、すなわち祭司とレビ人の三分の一は、入口の門衛となりなさい。</span>
<span className="v" id="v5" data-v="5" data-xref="エゼキエル書 46:2–3; 使徒の働き 3:2; 列王記第二 11:5–6"> 三分の一は王の家に、三分の一は礎の門にいなさい。すべての民は主の家の庭にいなさい。</span>
<span className="v" id="v6" data-v="6" data-xref="歴代誌上 23:28–32; 列王記第二 11:6–7"> しかし、祭司たちと、仕えるレビ人のほかは、だれも主の家に入ってはならない。彼らは聖なる者であるから入ることができる。しかし、すべての民は主の定めを守らなければならない。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 3:38; 民数記 3:10; 列王記第二 11:8–9"> レビ人はおのおの手に武器を持ち、王を取り囲みなさい。家に入って来る者はだれでも殺されなければならない。王が入って来るときも、出て行くときも、王とともにいなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王記第二 11:9; 歴代誌上 24:1–26"> こうしてレビ人と全ユダは、祭司エホヤダが命じたすべてのことに従って行った。おのおの自分の部下たち、すなわち安息日に入って来る者たちと、安息日に出て行く者たちを連れて行った。祭司エホヤダがその組を解散させなかったからである。</span>
<span className="v" id="v9" data-v="9" data-xref="サムエル記第一 21:9; サムエル記第二 8:7"> 祭司エホヤダは、神の家にあったダビデ王の槍、小盾、大盾を百人の長たちに渡した。</span>
<span className="v" id="v10" data-v="10" data-xref="出エジプト記 40:6; 歴代誌 第二 6:12; 列王記第二 11:11"> 彼はすべての民を、おのおの手に武器を持たせ、家の右側から家の左側まで、祭壇と家のそばに沿って王の周囲に配置した。</span>
<span className="v" id="v11" data-v="11" data-xref="サムエル記第一 10:24; 出エジプト記 25:16; 列王記第二 11:12"> それから彼らは王の子を連れ出し、彼に冠をかぶらせ、契約の書を授け、彼を王とした。エホヤダとその子らは彼に油を注ぎ、「王万歳」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王記第二 11:13–16; 列王記第二 9:32–37"> アタルヤは、民が走り回り、王を賛美している音を聞いて、主の家にある民のところへ行った。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 29:2; 歴代誌 第二 34:31; 列王記第二 9:23"> 彼女が見ると、見よ、王は入口にある王の柱のそばに立っており、王のそばには長たちとラッパを吹き鳴らす者たちがいた。この地のすべての民は喜び、ラッパを吹き鳴らしていた。歌うたいたちも楽器を奏でて、賛美の歌を導いていた。そこでアタルヤは自分の衣を引き裂き、「反逆だ、反逆だ」と言った。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="エゼキエル書 9:7; 列王記第二 11:8; 列王記第二 11:15"> 祭司エホヤダは軍隊の上に立てられた百人の長たちを引き出し、彼らに言った。「彼女を隊列の間に引き出しなさい。彼女に従う者はだれでも剣で殺しなさい。」祭司が「主の家で彼女を殺してはならない」と言ったからである。</span>
<span className="v" id="v15" data-v="15" data-xref="ネヘミヤ記 3:28; エレミヤ書 31:40; 歴代誌 第二 22:10"> そこで彼らは彼女のために道を開いた。彼女は王の家の馬の門の入り口に行き、彼らはそこで彼女を殺した。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歴代誌 第二 29:10; ネヘミヤ記 9:38; 列王記第二 11:17"> エホヤダは、自分とすべての民と王との間に、彼らが主の民となるという契約を結んだ。</span>
<span className="v" id="v17" data-v="17" data-xref="列王記第一 18:40; 列王記第二 10:25–28; 列王記第二 18:4"> すべての民はバアルの家に行き、それを打ち壊した。彼らはその祭壇と像を粉々に砕き、祭壇の前でバアルの祭司マタンを殺した。</span>
<span className="v" id="v18" data-v="18" data-xref="歴代誌 第二 5:5; 民数記 28:1–31; 歴代誌 第二 29:25"> エホヤダは、主の家の務めをレビ族の祭司たちの手に委ねた。彼らはダビデが主の家に割り当てた者たちで、モーセの律法に記されているとおりに主の全焼のささげ物をささげ、ダビデの定めに従って喜びと歌をもって仕えるためであった。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代誌上 26:1–32; 歴代誌上 9:22–24"> 彼は主の家の門に門衛を置き、何事においても汚れた者が入ってこないようにした。</span>
<span className="v" id="v20" data-v="20" data-xref="列王記第二 11:19; 列王記第二 15:35; 列王記第二 11:9–10"> 彼は百人の長たち、有力者たち、民の支配者たち、およびこの地のすべての民を連れて、王を主の家から連れ下った。彼らは上の門を通って王の家に入り、王を王国の王座に座らせた。</span>
<span className="v" id="v21" data-v="21" data-xref="列王記第二 11:20; ヨハネの黙示録 18:20; ヨハネの黙示録 19:1–4"> こうしてこの地のすべての民は喜び、町は静かであった。アタルヤは剣で殺された。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マタイ 12:42; ルカ 11:31; 列王記第一 10:1–13"> シェバの女王はソロモンの名声を聞くと、エルサレムで難問をもってソロモンを試すためにやって来た。彼女は大勢の従者を伴い、香料と、非常に多くの金と、宝石をらくだに負わせていた。彼女はソロモンのもとに来ると、自分の心にあるすべてのことについて彼と語り合った。</span>
<span className="v" id="v2" data-v="2" data-xref="ヨハネ 15:15; 列王記第一 3:12; マルコ 4:34"> ソロモンは彼女のすべての質問に答えた。ソロモンに隠されていて、彼が彼女に説明できなかったことは何一つなかった。</span>
<span className="v" id="v3" data-v="3" data-xref="歴代誌 第二 3:1–4; 列王記第一 10:3; 列王記第一 6:1–7"> シェバの女王はソロモンの知恵と、彼が建てた家、</span>
<span className="v" id="v4" data-v="4" data-xref="ルカ 12:37; 列王記第一 4:22–23; 詩篇 143:7"> その食卓の食物、しもべたちの座席、給仕たちの立ち居振る舞いとその衣装、献酌官たちとその衣装、そして彼が主の家に上る上り段を見ると、彼女はすっかり圧倒された<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または、「息をのむほどであった」。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王記第一 10:6"> 彼女は王に言った。「わたしが自分の国であなたの事績とあなたの知恵について聞いたうわさは本当でした。</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第一 10:7; 歴代誌 第二 9:5; 列王記第一 4:34"> しかし、わたしが来て自分の目で見るまでは、彼らの言葉を信じませんでした。見よ。あなたの知恵の偉大さの半分も、わたしには知らされていませんでした。あなたはわたしが聞いたうわさにまさっています。</span>
<span className="v" id="v7" data-v="7" data-xref="詩篇 27:4; 箴言 3:14; 箴言 10:21"> あなたの家臣たちは幸いです。絶えずあなたの前に立って、あなたの知恵を聞くこのあなたのしもべたちは幸いです。</span>
<span className="v" id="v8" data-v="8" data-xref="歴代誌 第二 2:11; 歴代誌上 29:23; イザヤ書 32:1–2"> あなたの神、主がほめたたえられますように。主はあなたを喜び、あなたを主の王座に座らせて、あなたの神、主のために王とされました。あなたの神はイスラエルを愛し、彼らをとこしえに堅く立てるために、あなたを彼らの上の王とし、さばきと義を行わせられたのです。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="歴代誌 第二 9:1; 詩篇 72:10; 詩篇 72:15"> 彼女は王に金百二十タラント<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一タラントは約30キログラム、または約66ポンドである。百二十タラントは約3.6メートルトンであり、六百六十六タラントは約20メートルトンである。">b</a></sup>と、非常に豊かな香料と、宝石を贈った。シェバの女王がソロモン王に贈ったような香料は二度となかった。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歴代誌 第二 8:18; 列王記第一 10:11; 列王記第一 10:22"> フラムのしもべたちと、オフィルから金を運んできたソロモンのしもべたちもまた、アルグムの木<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="おそらくインド産の白檀で、木目が美しく、よい香りがあり、木工に適している。">c</a></sup>と宝石を運んできた。</span>
<span className="v" id="v11" data-v="11" data-xref="列王記第一 10:12; 歴代誌上 23:5; 詩篇 92:1–3"> 王はそのアルグムの木で、主の家と王宮のための歩廊、また歌い手たちのための竪琴と琴を造った。このようなものは、ユダの地でそれまで見られたことがなかった。</span>
<span className="v" id="v12" data-v="12" data-xref="列王記第一 10:13; エペソ人への手紙 3:20; 詩篇 20:4"> ソロモン王はシェバの女王に、彼女が王に持って来たもののほかに、彼女が願うすべてのもの、彼女が求めるものを何でも与えた。こうして彼女は、しもべたちとともに帰途についた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 72:15; 詩篇 68:29; 列王記第一 10:14–28"> 一年間にソロモンに入ってきた金の目方は、金六百六十六タラント<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一タラントは約30キログラム、または約66ポンドである。六百六十六タラントは約20メートルトンである。">d</a></sup>であった。</span>
<span className="v" id="v14" data-v="14" data-xref="詩篇 68:29; 詩篇 72:10"> そのほかに、商人たちや貿易商たちが持って来たものがあった。アラビアのすべての王たちと、その国の総督たちも、金と銀をソロモンに持って来た。</span>
<span className="v" id="v15" data-v="15" data-xref="列王記第一 10:16–17; 歴代誌 第二 12:9–10"> ソロモン王は打ち延ばした金で大きな盾を二百枚造った。一つの大きな盾に六百シェケル<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一シェケルは約10グラム、あるいは約0.35オンスである。六百シェケルは約6キログラム、または約13.2ポンド、三百シェケルは約3キログラム、または約6.6ポンドである。">e</a></sup>の打ち延ばした金が使われた。</span>
<span className="v" id="v16" data-v="16" data-xref="列王記第一 7:2"> 彼はまた、打ち延ばした金で盾を三百枚造った。一つの盾に三百シェケル<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一シェケルは約10グラムである。三百シェケルは約3キログラムである。">f</a></sup>の金が使われた。王はそれらをレバノンの森の家に置いた。</span>
<span className="v" id="v17" data-v="17" data-xref="列王記第一 10:18–20; 詩篇 45:8; ヨハネの黙示録 20:11"> さらに、王は象牙の大きな王座を造り、それに純金をかぶせた。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 24:9; ヨハネの黙示録 5:5; 民数記 23:24"> 王座には六つの段と金の足台があり、それらは王座に取り付けられていた。また、座席の場所の両側にはひじ掛けがあり、そのひじ掛けのそばに二頭のライオンが立っていた。</span>
<span className="v" id="v19" data-v="19" data-xref="マタイ 19:28; ヨハネの黙示録 21:12"> その六つの段の上、こちら側とあちら側に、十二頭のライオンが立っていた。どの王国でも、これに似たものは造られたことがなかった。</span>
<span className="v" id="v20" data-v="20" data-xref="列王記第一 10:21; エステル記 1:7; 歴代誌 第二 9:27"> ソロモン王の飲むための器はすべて金であり、レバノンの森の家の器もすべて純金であった。ソロモンの時代には、銀は価値あるものとはみなされなかった。</span>
<span className="v" id="v21" data-v="21" data-xref="列王記第一 22:48; ヨブ記 39:13; 列王記第一 10:22"> 王の船は、フラムのしもべたちとともにタルシシュへ行っていたからである。三年に一度、タルシシュの船が来て、金、銀、象牙、猿、孔雀を運んできた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歴代誌 第二 1:12; 詩篇 89:27; 列王記第一 4:30–31"> こうしてソロモン王は、富と知恵において地上のどの王にもまさっていた。</span>
<span className="v" id="v23" data-v="23" data-xref="ヤコブの手紙 1:5; ヤコブの手紙 3:17; 箴言 2:6"> 地上のすべての王たちは、神が彼の心に授けられたその知恵を聞こうとして、ソロモンへの謁見を求めた。</span>
<span className="v" id="v24" data-v="24" data-xref="列王記第一 10:25; ヨブ記 42:11; 詩篇 72:10"> 彼らはおのおの貢ぎ物として、銀の器、金の器、衣服、武具、香料、馬、らばを、毎年持って来た。</span>
<span className="v" id="v25" data-v="25" data-xref="列王記第一 4:26; 列王記第一 10:26; 歴代誌 第二 1:14"> ソロモンには馬と戦車のための馬屋が四千あり、騎兵が一万二千人いた。彼はそれらを戦車の町々に、またエルサレムの王のもとに置いた。</span>
<span className="v" id="v26" data-v="26" data-xref="列王記第一 4:21; 創世記 15:18; 列王記第一 4:24"> 彼は大河からペリシテ人の地、またエジプトの境界に至るまでのすべての王たちを支配した。</span>
<span className="v" id="v27" data-v="27" data-xref="歴代誌 第二 1:15–17; イザヤ書 9:10; 列王記第一 10:27–29"> 王はエルサレムで銀を石のようにありふれたものにし、香柏を低地にあるいちじく桑の木のようにありふれたものにした。</span>
<span className="v" id="v28" data-v="28" data-xref="歴代誌 第二 1:16; 列王記第一 10:28; イザヤ書 31:1"> 人々はエジプトから、またすべての国々から、ソロモンのために馬を連れて来た。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="歴代誌上 29:29; 列王記第一 11:41–43; 列王記第一 11:29"> ソロモンのその他の事績は、最初から最後まで、預言者ナタンの記録、シロ人アヒヤの預言、およびネバテの子ヤロブアムに関する先見者イドの幻に記されているのではないか。</span>
<span className="v" id="v30" data-v="30" data-xref="列王記第一 11:42–43"> ソロモンはエルサレムで全イスラエルを四十年治めた。</span>
<span className="v" id="v31" data-v="31" data-xref="列王記第一 2:10; サムエル記第二 7:12; 列王記第一 1:21"> ソロモンはその父祖たちとともに眠り、その父ダビデの町に葬られた。その子レハブアムが代わって王となった。</span>
</div>
</div>

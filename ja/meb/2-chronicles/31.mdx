<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王記第二 18:4; 歴代誌 第二 32:12; 創世記 19:15"> このすべてのことが終わると、そこにいた全イスラエルはユダの町々へ出て行き、石の柱を打ち砕き、アシェラ像を切り倒し、ユダとベニヤミンの全土、またエフライムとマナセに至るまで、高き所と祭壇を完全に打ち壊した。その後、イスラエルのすべての子らは、それぞれ自分の所有地、自分たちの町々に帰って行った。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="歴代誌上 24:1; 歴代誌上 16:4–6; 歴代誌 第二 29:24–26"> ヒゼキヤは、祭司たちとレビ人を組ごとに分け、それぞれの奉仕を割り当てた。それは全焼のささげ物と和解のいけにえのためであり、主の宿営の門々で仕え、感謝をささげ、賛美するためであった。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 45:17; 歴代誌 第二 35:7; コロサイ人への手紙 2:16–17"> 彼はまた、主の律法に記されているとおりに、全焼のささげ物、すなわち朝と夕の全焼のささげ物、および安息日、新月、定めの祭りのための全焼のささげ物として、王の財産から王の取り分を定めた。</span>
<span className="v" id="v4" data-v="4" data-xref="マラキ書 2:7; 民数記 18:8–21; ネヘミヤ記 13:10–13"> さらに彼は、エルサレムに住む民に、祭司たちとレビ人が主の律法に専念できるように、彼らの取り分を与えるように命じた。</span>
<span className="v" id="v5" data-v="5" data-xref="ネヘミヤ記 13:12; 歴代誌 第二 24:10–11; ネヘミヤ記 10:35–39"> この命令が伝わると、イスラエルの子らは穀物、新しいぶどう酒、油、蜂蜜、および畑のすべての収穫の初物を豊かにささげ、またすべての物の十分の一を豊かに持って来た。</span>
<span className="v" id="v6" data-v="6" data-xref="レビ記 27:30; 歴代誌 第二 11:16–17; 申命記 14:28"> ユダの町々に住んでいたイスラエルの子らとユダの人々もまた、牛や羊の十分の一、および彼らの神、主に聖別されたささげ物の十分の一を持って来て、それを幾つもの山に積み上げた。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="レビ記 23:16–24"> 第三の月に彼らは積み上げ始め、第七の月にそれを終えた。</span>
<span className="v" id="v8" data-v="8" data-xref="エペソ人への手紙 1:3; 創世記 14:19–20; ピリピ人への手紙 4:10"> ヒゼキヤと君たちが来てそれらの山を見ると、彼らは主をほめたたえ、その民イスラエルを祝福した。</span>
<span className="v" id="v9" data-v="9"> そしてヒゼキヤが祭司たちとレビ人にそれらの山について尋ねると、</span>
<span className="v" id="v10" data-v="10" data-xref="マラキ書 3:10; 歴代誌上 6:8; コリント人への第二の手紙 9:8–11"> ツァドクの家の大祭司アザルヤは彼に答えた。「民がささげ物を主の家に持って来始めてから、わたしたちは食べて満足し、大量の残りができました。主がその民を祝福されたからです。残ったものがこの大きな蓄えです。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ネヘミヤ記 10:38–39; ネヘミヤ記 13:5; ネヘミヤ記 13:12–13"> そこでヒゼキヤは主の家に部屋を用意するように命じ、彼らはそれを準備した。</span>
<span className="v" id="v12" data-v="12" data-xref="歴代誌 第二 35:9; 列王記第二 12:15; 歴代誌上 26:20–26"> 彼らはささげ物、十分の一、および聖別された物を忠実に運び入れた。レビ人コナンヤが彼らの上の監督者であり、その兄弟シムイが二番目であった。</span>
<span className="v" id="v13" data-v="13" data-xref="歴代誌上 24:5; 歴代誌 第二 31:10–11; 歴代誌上 9:11"> エヒエル、アザズヤ、ナハテ、アサエル、エリモテ、ヨザバド、エリエル、イスマクヤ、マハテ、ベナヤは、ヒゼキヤ王および神の家の支配者アザルヤの任命により、コナンヤとその兄弟シムイの手の下にある監督者であった。</span>
<span className="v" id="v14" data-v="14" data-xref="レビ記 23:38; 歴代誌上 26:12; レビ記 27:28"> 東の門の門衛であったレビ人イムナの子コレは、神への自発のささげ物を管理し、主へのささげ物と最も聖なるものを分配した。</span>
<span className="v" id="v15" data-v="15" data-xref="ヨシュア記 21:9–19; 歴代誌上 9:22; 歴代誌 第二 29:12"> 彼の下にはエデン、ミニヤミン、エシュア、シェマヤ、アマルヤ、シェカニヤがおり、祭司たちの町々で忠実に務め、組ごとに、身分の高い者にも低い者にも等しく分配した。</span>
<span className="v" id="v16" data-v="16" data-xref="エズラ記 3:4; レビ記 21:22–23; 歴代誌上 23:3"> これは、三歳以上の男子として系図に記された者のほかに、その組に従って日々の務めが求めるままに、彼らの職務における奉仕のために主の家に入るすべての者に対するものであった。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代誌上 23:24; 歴代誌上 23:27; 民数記 3:15"> 祭司たちについては彼らの父祖の家ごとに系図に記された者たち、またレビ人については二十歳以上の者が、その組による彼らの職務において系図に記された。</span>
<span className="v" id="v18" data-v="18" data-xref="ローマ人への手紙 15:16; イザヤ書 5:16; 歴代誌 第二 31:15"> これはまた、全会衆を通して、彼らの幼い子供たち、妻たち、息子たち、娘たちとして系図に記されたすべての者に対するものであった。彼らは信頼される職務において自らをきよめて聖別していたからである。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代誌 第二 31:12–15; レビ記 25:34; 民数記 35:2–5"> また、彼らの町々の牧草地の野にいたアロンの子らである祭司たちについても、それぞれの町に名前を指定された者たちがいて、祭司たちのうちのすべての男子、およびレビ人のうちの系図に記されたすべての者に割り当てを与えた。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王記第二 20:3; 列王記第二 22:2; 使徒の働き 24:16"> ヒゼキヤは全ユダにわたってこのように行い、彼の神、主の御前で、良いこと、正しいこと、そして忠実なことを行った。</span>
<span className="v" id="v21" data-v="21" data-xref="マタイ 6:33; エレミヤ書 29:13; ヨシュア記 1:7–8"> 彼は神の家の奉仕にも、律法と命令を守ることにも、神を求めることにも、心を尽くして取り組み、栄えた。</span>
</div>

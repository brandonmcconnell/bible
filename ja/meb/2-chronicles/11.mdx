<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王記第一 12:21–24; 詩篇 33:10; 詩篇 33:16"> レハブアムがエルサレムに着いたとき、彼はユダとベニヤミンの家から、戦士であるえり抜きの者十八万人を集め、王権をレハブアムに取り戻すためにイスラエルと戦おうとした。</span>
<span className="v" id="v2" data-v="2" data-xref="歴代誌 第二 12:15; 歴代誌 第二 12:5–7; 歴代誌 第二 8:14"> しかし、主の言葉が神の人シェマヤに臨んだ。</span>
<span className="v" id="v3" data-v="3" data-xref="列王記第二 17:34; 創世記 49:28; ヨハネの黙示録 7:4–8"> 「ユダの王、ソロモンの子レハブアム、およびユダとベニヤミンにいる全イスラエルに告げて言いなさい。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 50:20; 列王記第一 11:29–38; 歴代誌 第二 10:15–16"> 『主はこう言われる。「あなたがたは上って行ってはならない。また兄弟たちと戦ってはならない。それぞれ自分の家へ帰れ。この事はわたしから出たことだからである。」』」そこで彼らは主の言葉に聞き従い、ヤロブアムに向かって行くのをやめて帰った。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歴代誌 第二 8:2–6; 歴代誌 第二 14:6–7; イザヤ書 22:8–11"> レハブアムはエルサレムに住み、ユダに防備の町々を建てた。</span>
<span className="v" id="v6" data-v="6" data-xref="ネヘミヤ記 3:5; アモス書 1:1; 歴代誌上 4:32"> 彼はベツレヘム、エタム、テコア、</span>
<span className="v" id="v7" data-v="7" data-xref="ヨシュア記 15:35; サムエル記第一 22:1; ヨシュア記 15:58"> ベテ・ツル、ソコ、アドラム、</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 54:1; ヨシュア記 15:24; サムエル記第一 23:19"> ガテ、マレシャ、ジフ、</span>
<span className="v" id="v9" data-v="9" data-xref="ヨシュア記 15:39; ヨシュア記 15:35; ヨシュア記 10:5"> アドライム、ラキシュ、アゼカ、</span>
<span className="v" id="v10" data-v="10" data-xref="民数記 13:22; ヨシュア記 15:33; ヨシュア記 14:14"> ツォラ、アヤロン、およびヘブロンを建てた。これらはユダとベニヤミンにある防備の町である。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代誌 第二 17:19; イザヤ書 22:10–11; 歴代誌 第二 11:23"> 彼は要害を堅固にし、そこに長たちを置き、食物と油とぶどう酒の蓄えを置いた。</span>
<span className="v" id="v12" data-v="12" data-xref="サムエル記第二 13:22; 歴代誌 第二 26:14–15; 歴代誌 第二 32:5"> また、すべての町に盾と槍を置き、それらを非常に堅固にした。ユダとベニヤミンは彼の支配下にあった。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 全イスラエルにいた祭司たちとレビ人たちは、各地から来て彼の側についた。</span>
<span className="v" id="v14" data-v="14" data-xref="歴代誌 第二 13:9; 民数記 35:2–5; 列王記第一 12:28–33"> レビ人たちは自分たちの放牧地と所有地を捨てて、ユダとエルサレムに来た。ヤロブアムとその子らが彼らを祭司職から追放し、主に仕えることを許さなかったからである。</span>
<span className="v" id="v15" data-v="15" data-xref="列王記第一 12:28; 列王記第一 12:31; 列王記第一 13:33"> ヤロブアムは、高き所のため、また彼が造った雄ヤギの偶像と子牛の偶像のために、自分で祭司たちを任命していた。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代誌 第二 15:9; 使徒の働き 11:23; 詩篇 84:5–7"> レビ人たちの後に続いて、イスラエルのすべての部族の中から、イスラエルの神、主を尋ね求めることに心を定めた者たちが、彼らの父祖の神、主にいけにえをささげるためにエルサレムに来た。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代誌 第二 12:1; 歴代誌 第二 1:1–12; 歴代誌 第二 7:17–19"> 彼らはユダ王国を支え、ソロモンの子レハブアムを三年間強くした。彼らは三年の間、ダビデとソロモンの道を歩んだからである。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="サムエル記第一 16:6; 歴代誌上 27:18; サムエル記第一 17:13"> レハブアムは、ダビデの子エリモトと、エッサイの子エリアブの娘アビハイルとの娘であるマハラテを妻にめとった。</span>
<span className="v" id="v19" data-v="19"> 彼女は彼にエウシュ、シェマルヤ、ザハムという息子たちを産んだ。</span>
<span className="v" id="v20" data-v="20" data-xref="歴代誌 第二 13:2; 歴代誌 第二 11:21; 歴代誌 第二 12:16"> 彼女の後に、彼はアブサロムの娘マアカをめとった。彼女は彼にアビヤ、アタイ、ジザ、シェロミテを産んだ。</span>
<span className="v" id="v21" data-v="21" data-xref="士師記 8:30; 申命記 17:17; 列王記第一 11:3"> レハブアムは、すべての妻やそばめたちよりも、アブサロムの娘マアカを愛した（彼は十八人の妻と六十人のそばめをめとり、二十八人の息子と六十人の娘の父となった）。</span>
<span className="v" id="v22" data-v="22" data-xref="申命記 21:15–17; 歴代誌上 29:1; 歴代誌上 5:1–2"> レハブアムはマアカの子アビヤを長とし、その兄弟たちの間の君とした。彼を王にしようと意図していたからである。</span>
<span className="v" id="v23" data-v="23" data-xref="歴代誌 第二 21:3; 創世記 25:6; ルカ 16:8"> 彼は賢明に行動し、息子たちをユダとベニヤミン全土の防備の町々に分散させ、豊かな食糧を与え、多くの妻を迎えさせた。</span>
</div>

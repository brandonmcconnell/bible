<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歴代誌 第二 24:20; 歴代誌 第二 20:14; 民数記 24:2"> 神の霊がオデドの子アザルヤに臨んだ。</span>
<span className="v" id="v2" data-v="2" data-xref="ヤコブの手紙 4:8; 歴代誌 第二 24:20; 歴代誌 第二 15:4"> 彼はアサを迎えに出て行って、彼に言った。「アサ、そしてユダとベニヤミンのすべての人々よ、わたしに聞きなさい。あなたがたが主とともにいる間、主はあなたがたとともにおられる。もしあなたがたが主を尋ね求めるなら、あなたがたは主を見いだす。しかし、もしあなたがたが主を捨てるなら、主はあなたがたを捨てられる。</span>
<span className="v" id="v3" data-v="3" data-xref="ネヘミヤ記 8:9; レビ記 10:11; 歴代誌 第二 17:8–9"> さて長い間、イスラエルにはまことの神がなく、教える祭司もなく、律法もなかった。</span>
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 55:6; 申命記 4:29–30; 歴代誌 第二 15:15"> しかし、彼らが苦しみの中でイスラエルの神、主に立ち返り、主を尋ね求めたとき、彼らは主を見いだした。</span>
<span className="v" id="v5" data-v="5" data-xref="士師記 5:6; 詩篇 121:8; サムエル記第一 13:6"> その時代には、出て行く者にも入って来る者にも平安はなく、すべての地の住民に大きな騒乱があった。</span>
<span className="v" id="v6" data-v="6" data-xref="ルカ 21:22–24; マタイ 24:7; 歴代誌 第二 33:11"> 神があらゆる苦難をもって彼らを悩まされたため、彼らは打ち砕かれ、国は国に、町は町に逆らった。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第一の手紙 15:58; ヨシュア記 1:7; ヨシュア記 1:9"> しかし、あなたがたは強くありなさい。手を垂れてはならない。あなたがたの働きには報いがあるからだ。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歴代誌 第二 8:12; 歴代誌 第二 13:19; 歴代誌 第二 4:1"> アサはこれらの言葉と預言者オデドの預言を聞くと、勇気を出して、ユダとベニヤミンの全地、および彼がエフライムの山地から奪い取った町々から忌まわしいものを取り除き、主の玄関の前にあった主の祭壇を新しくした。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代誌 第二 11:16; 使徒の働き 9:31; ゼカリヤ書 8:21–23"> 彼はユダとベニヤミンのすべての人々、およびエフライム、マナセ、シメオンから来て彼らとともに住んでいた者たちを集めた。アサの神、主が彼とともにおられるのを見て、イスラエルから彼のもとに多くの者がやって来たからである。</span>
<span className="v" id="v10" data-v="10" data-xref="エステル記 8:9"> こうして彼らは、アサの治世の第十五年の第三の月に、エルサレムに集まった。</span>
<span className="v" id="v11" data-v="11" data-xref="歴代誌 第二 14:13–15; 民数記 31:28–29; 民数記 31:50"> その日、彼らは自分たちが持って来た戦利品の中から、牛七百頭と羊七千匹を主にいけにえとしてささげた。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 24:14; 歴代誌 第二 23:16; 申命記 10:12"> 彼らは、心を尽くし魂を尽くして、彼らの父祖の神、主を尋ね求めるという契約を結んだ。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 22:20; 詩篇 115:13; 列王記第一 18:40"> そして、小さい者も大きい者も、男も女も、イスラエルの神、主を尋ね求めない者はみな死刑に処されることになった。</span>
<span className="v" id="v14" data-v="14" data-xref="ネヘミヤ記 5:13; 詩篇 81:1–4; ネヘミヤ記 10:29"> 彼らは大声で叫び、ラッパと角笛を鳴らして、主に誓った。</span>
<span className="v" id="v15" data-v="15" data-xref="歴代誌 第二 14:7; 歴代誌 第二 15:12; イザヤ書 26:8"> 全ユダはこの誓いのゆえに喜んだ。彼らが全き心をもって誓い、心から主を尋ね求めたので、彼らは主を見いだし、主は周囲に彼らのための安息を与えられたからである。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王記第一 15:13–24; 列王記第一 15:10; 列王記第二 23:15"> また、アサ王の母マアカについても、彼女がアシェラのための忌まわしい像を造っていたので、彼は彼女を母后の座から退けた。アサは彼女の像を切り倒し、それを粉々に砕き、キデロン川で焼いた。</span>
<span className="v" id="v17" data-v="17" data-xref="列王記第二 14:4; 列王記第二 12:3; 列王記第一 11:4"> しかし、高き所はイスラエルから取り除かれなかった。それでもアサの心はその一生の間、全きものであった。</span>
<span className="v" id="v18" data-v="18" data-xref="列王記第一 7:51; 歴代誌上 26:20–26; 列王記第一 15:14–15"> 彼はその父が聖別したものと、彼自身が聖別したもの、すなわち銀、金、および器を神の家に運び入れた。</span>
<span className="v" id="v19" data-v="19" data-xref="列王記第一 15:31; 列王記第一 15:33; 列王記第一 15:16–17"> アサの治世の第三十五年まで、もはや戦いはなかった。</span>
</div>

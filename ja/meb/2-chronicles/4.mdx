<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王記第一 8:64; エゼキエル書 43:13–17; 列王記第一 9:25"> さらに彼は青銅の祭壇を造った。その長さは二十キュビト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一キュビトは約46センチメートル、または約18インチである。">a</a></sup>、幅は二十キュビト、高さは十キュビトであった。</span>
<span className="v" id="v2" data-v="2" data-xref="テトス 3:5; ゼカリヤ書 13:1; 出エジプト記 30:18–21"> また、彼は鋳物の海<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="または、「水盤」、あるいは「貯水槽」。">b</a></sup>を造った。縁から縁まで十キュビトで、周囲は丸く、高さは五キュビトであり、三十キュビトの測り縄がその周囲を巡っていた。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 1:10; エゼキエル書 10:14; コリント人への第一の手紙 9:9–10"> その下には、周囲を巡る牛の像があり、十キュビトにわたって海を囲んでいた。牛は二列に並んでおり、海を鋳たときに一緒に鋳られた。</span>
<span className="v" id="v4" data-v="4" data-xref="マタイ 28:19–20; ヨハネの黙示録 21:14; マルコ 16:15"> それは十二頭の牛の上に据えられていた。三頭は北を向き、三頭は西を向き、三頭は南を向き、三頭は東を向いていた。海はその上に載せられ、牛の後部はすべて内側に向いていた。</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第一 7:26"> その厚さは手の幅ほどあり、その縁は杯の縁のように、ゆりの花のように造られていた。それは三千バテ<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一バテは約21リットル、または5.6ガロンである。三千バテは約63.3キロリットル、または約16,800ガロンである。">c</a></sup>の容量があった。</span>
<span className="v" id="v6" data-v="6" data-xref="列王記第一 7:38; 出エジプト記 30:18–21; 列王記第一 7:40"> 彼はまた十の洗盤を造り、五つを右に、五つを左に置いて、そこで洗うようにした。全焼のささげ物に用いるものはそこで洗われた。しかし海は祭司たちが洗うためのものであった。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出エジプト記 25:31–40; 列王記第一 7:49; ヨハネ 8:12"> 彼は規定に従って金の燭台を十個造り、それを神殿の中の右に五つ、左に五つ置いた。</span>
<span className="v" id="v8" data-v="8" data-xref="列王記第一 7:48; マラキ書 1:12; 出エジプト記 25:23–30"> 彼はまた机を十個造り、それを神殿の中の右に五つ、左に五つ置いた。また、百の金の鉢を造った。</span>
<span className="v" id="v9" data-v="9" data-xref="列王記第一 6:36; 列王記第二 21:5; 列王記第一 7:12"> さらに彼は、祭司たちの庭、大庭、およびその庭の戸を造り、その戸に青銅をかぶせた。</span>
<span className="v" id="v10" data-v="10" data-xref="列王記第一 7:39"> 彼は海を家の右側、東のほう、南寄りに置いた。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王記第一 7:40–51; 列王記第一 7:14"> フラムは、鍋、十能、鉢を造った。こうしてフラムは、ソロモン王のために神の家で行った仕事を終えた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王記第一 7:41; 歴代誌 第二 3:15–17"> すなわち、二本の柱、二つの鉢、柱の頂にある二つの柱頭、柱の頂にある二つの鉢の柱頭を覆うための二つの網細工、</span>
<span className="v" id="v13" data-v="13" data-xref="列王記第一 7:20; 列王記第一 7:42; エレミヤ書 52:23"> 二つの網細工のための四百のザクロ（柱の上にある二つの鉢の柱頭を覆うために、各々の網細工に二列のザクロ）、</span>
<span className="v" id="v14" data-v="14" data-xref="列王記第一 7:27–43"> さらに彼は台座を造り、台座の上に洗盤を造った。</span>
<span className="v" id="v15" data-v="15"> 一つの海と、その下の十二頭の牛。</span>
<span className="v" id="v16" data-v="16" data-xref="歴代誌 第二 2:13; 列王記第一 7:13–14; 歴代誌 第二 4:11"> また、鍋、十能、肉刺し、およびすべての器を、フラム・アビ<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="「アビ」は「彼の父」を意味する。">d</a></sup>はソロモン王のために、主の家のために磨かれた青銅で造った。</span>
<span className="v" id="v17" data-v="17" data-xref="列王記第一 7:46"> 王はヨルダン川の低地、スコテとツェレダの間の粘土の地でこれらを鋳造した。</span>
<span className="v" id="v18" data-v="18" data-xref="列王記第一 7:47; エレミヤ書 52:20; 歴代誌上 22:14"> ソロモンはこれらすべての器を非常に大量に造った。青銅の重さは量りきれなかったからである。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ヨハネの黙示録 9:13; ダニエル書 5:2–3; 出エジプト記 25:23–30"> ソロモンは神の家にあるすべての器、すなわち金の祭壇と、備えのパンを載せる机、</span>
<span className="v" id="v20" data-v="20" data-xref="歴代誌 第二 4:7; 出エジプト記 25:31–37; 列王記第一 6:5"> 内側の聖所の前で規定に従ってともすための純金の燭台とそのともしび、</span>
<span className="v" id="v21" data-v="21" data-xref="列王記第一 6:29; 出エジプト記 37:20; 列王記第一 6:35"> 花飾り、ともしび皿、火ばさみも最高の純金で造り、</span>
<span className="v" id="v22" data-v="22" data-xref="列王記第二 12:13; 列王記第二 25:14; エレミヤ書 52:18"> さらに純金の芯切りばさみ、鉢、さじ、火皿を造った。神殿の入口には、至聖所へ通じる内側の戸と、大広間の戸があり、いずれも金で造られていた。</span>
</div>

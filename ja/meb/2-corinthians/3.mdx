<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第二の手紙 12:11; コリント人への第二の手紙 10:12; コリント人への第二の手紙 5:12"> 私たちはまた自分を推薦し始めているのでしょうか。それとも、ある人々のように、あなたがたへの推薦状や、あなたがたからの推薦状が必要なのでしょうか。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第一の手紙 9:1–2; テサロニケ人への手紙第一 1:8; ローマ人への手紙 1:8"> あなたがたこそ私たちの手紙であり、私たちの心に書き記され、すべての人に知られ、読まれています。</span>
<span className="v" id="v3" data-v="3" data-xref="エゼキエル書 11:19; エレミヤ書 31:33; ヘブル人への手紙 8:10"> あなたがたは、私たちの奉仕によって書かれたキリストの手紙であることを明らかにしています。それは墨ではなく、生ける神の霊によって、石の板ではなく、肉の心の板に書かれた手紙です。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ピリピ人への手紙 1:6; エペソ人への手紙 3:12; コリント人への第二の手紙 2:14"> 私たちはキリストを通して、神に対してこのような確信を抱いています。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 12:9; ピリピ人への手紙 4:13; コリント人への第一の手紙 15:10"> 私たちは、何かを自分から生み出したと言えるほど、自分自身に力があるわけではありません。私たちの力は神から来るのです。</span>
<span className="v" id="v6" data-v="6" data-xref="ヨハネ 6:63; ローマ人への手紙 7:6; エレミヤ書 31:31"> 神はまた私たちを、文字によるのではなく、聖霊による新しい契約に仕える者としてふさわしくしてくださいました。文字は殺しますが、聖霊は命を与えるからです。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="コリント人への第二の手紙 3:9–11; ローマ人への手紙 10:4; 出エジプト記 31:18"> 石に文字で刻まれた、死をもたらす務めでさえ栄光を伴って現れました。そのためイスラエルの子らは、やがて消え去る輝きであったにもかかわらず、モーセの顔をじっと見つめることができませんでした。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 3:16; エペソ人への手紙 2:18; ガラテヤ人への手紙 3:14"> まして、聖霊に仕える務めは、はるかに大きな栄光を伴わないでしょうか。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 3:21–22; ヘブル人への手紙 12:18–21; コリント人への第二の手紙 5:21"> 罪に定める務めに栄光があるなら、義をもたらす務めは、はるかに大きな栄光に満ちています。</span>
<span className="v" id="v10" data-v="10" data-xref="ペテロの第二の手紙 1:17; ハガイ書 2:7–9; 使徒の働き 26:13"> 実に、かつて栄光を帯びていたものも、それをはるかにしのぐ栄光に比べれば、この点では栄光がなかったと言えるほどです。</span>
<span className="v" id="v11" data-v="11" data-xref="ローマ人への手紙 5:20–21; ヘブル人への手紙 8:13; ヘブル人への手紙 7:21–25"> 消え去るものが栄光を伴っていたのなら、残るものは、なおさら栄光に満ちています。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="コリント人への第二の手紙 7:4; 使徒の働き 4:13; ピリピ人への手紙 1:20"> このような希望を抱いているので、私たちはきわめて大胆に語ります。</span>
<span className="v" id="v13" data-v="13" data-xref="出エジプト記 34:33–35; ヘブル人への手紙 10:1–9; エペソ人への手紙 2:14–15"> 私たちは、消え去っていく輝きの行く末をイスラエルの子らがじっと見つめないように、自分の顔に覆いを掛けたモーセのようにはしません。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第二の手紙 4:3–4; 使徒の働き 26:18; ローマ人への手紙 11:25"> しかし、彼らの思いはかたくなにされました。今日に至るまで、古い契約が朗読されるとき、同じ覆いが残ったままです。その覆いは、キリストにあって初めて取り除かれるからです。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒の働き 13:27–29"> 今日に至るまで、モーセが朗読されるとき、彼らの心には覆いが掛かっています。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 34:34; イザヤ書 29:18; イザヤ書 25:7"> しかし、人が主に立ち返るなら、覆いは取り除かれます。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 8:2; ガラテヤ人への手紙 5:13; ヨハネ 8:32"> 主は御霊です。そして、主の御霊がおられるところには自由があります。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第二の手紙 4:6; エペソ人への手紙 4:22–24; ローマ人への手紙 12:2"> 私たちは皆、覆いのない顔で、鏡に映すように主の栄光を見つめながら、栄光から栄光へと主と同じ姿に変えられていきます。これは聖霊である主によることです。</span>
</div>

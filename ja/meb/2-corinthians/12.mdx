<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ガラテヤ人への手紙 1:12; コリント人への第二の手紙 12:7; ヨハネの手紙第一 5:20"> 誇ることは、確かに私の益にはなりません。それでも私は、主からの幻と啓示について語ることにします。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒の働き 22:17; エゼキエル書 8:1–3; テサロニケ人への手紙第一 4:17"> 私はキリストにある一人の人を知っています。その人は十四年前、第三の天にまで引き上げられました。体のままであったのか、体を離れていたのか、私には分かりません。神がご存じです。</span>
<span className="v" id="v3" data-v="3"> 私はそのような人を知っています。体のままであったのか、体の外にいたのか、私には分かりません。神がご存じです。</span>
<span className="v" id="v4" data-v="4" data-xref="ルカ 23:43; ヨハネの黙示録 2:7; エゼキエル書 31:9"> その人は楽園にまで引き上げられ、人が口にすることを許されていない、言い表すことのできない言葉を聞きました。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 11:30; コリント人への第一の手紙 2:3; コリント人への第二の手紙 12:9–10"> そのような人については誇ります。しかし、自分自身については、弱さ以外は誇りません。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第二の手紙 11:16; コリント人への第二の手紙 11:31; コリント人への第二の手紙 12:11"> たとえ誇りたいと思っても、私は愚か者にはなりません。真実を語るからです。しかし、私を見たり、私から聞いたりする以上に、だれかが私を評価することのないよう、誇ることを控えます。</span>
<span className="v" id="v7" data-v="7" data-xref="民数記 33:55; 士師記 2:3; 歴代誌 第二 32:25–26"> また、あまりにもすばらしい啓示のために私が高ぶりすぎないよう、肉体に一つのとげが与えられました。それは私を苦しめるサタンの使いであり、私が高ぶりすぎないようにするためです。</span>
<span className="v" id="v8" data-v="8" data-xref="ヘブル人への手紙 5:7; マタイ 26:39–44; サムエル記第一 15:11"> このとげが私から離れるようにと、私は三度、主に願いました。</span>
<span className="v" id="v9" data-v="9" data-xref="ピリピ人への手紙 4:13; コリント人への第二の手紙 12:10; イザヤ書 40:29–31"> しかし主は私に、<span className="woj">「わたしの恵みはあなたに十分である。わたしの力は弱さのうちで完全なものとなるからだ。」</span>と言われました。ですから私は、キリストの力が私の上にとどまるように、むしろ大いに喜んで自分の弱さを誇ります。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="コリント人への第二の手紙 12:9; エペソ人への手紙 6:10; ローマ人への手紙 5:3"> それゆえ私は、キリストのためなら、弱さ、侮辱、窮乏、迫害、苦境を喜びます。私が弱いときにこそ、強いからです。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第二の手紙 11:5; コリント人への第二の手紙 11:1; コリント人への第一の手紙 15:8–10"> 私は誇ることによって愚か者になってしまいました。あなたがたが私をそうさせたのです。本来なら、あなたがたから推薦されるべきでした。私は取るに足りない者ですが、あの「大使徒」たちに少しも劣っていないからです。</span>
<span className="v" id="v12" data-v="12" data-xref="ローマ人への手紙 15:18–19; コリント人への第二の手紙 11:4; コリント人への第二の手紙 4:2"> 使徒であることの証拠は、あらゆる忍耐と、しるし、不思議、力ある業によって、あなたがたの間ではっきり示されました。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第一の手紙 9:12; コリント人への第一の手紙 9:6; コリント人への第二の手紙 11:7–9"> 私自身があなたがたの負担にならなかったこと以外に、あなたがたがほかの諸教会より劣った扱いを受けたことがあるでしょうか。この不正をどうか赦してください。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="箴言 19:14; 創世記 24:35–36; コリント人への第一の手紙 10:33"> 見よ、私は三度目にあなたがたのところへ行く用意ができています。あなたがたの負担にはなりません。私が求めているのは、あなたがたの財産ではなく、あなたがた自身だからです。子どもが親のために蓄えるべきなのではなく、親が子どものために蓄えるべきです。</span>
<span className="v" id="v15" data-v="15" data-xref="テサロニケ人への手紙第一 2:8; コリント人への第二の手紙 1:6; ピリピ人への手紙 2:17"> 私はあなたがた自身のために、喜んで自分の持ち物を使い尽くし、自分自身をも使い尽くしましょう。私があなたがたをより深く愛すれば、私はますます愛されなくなるのでしょうか。</span>
<span className="v" id="v16" data-v="16" data-xref="テサロニケ人への手紙第一 2:5; コリント人への第二の手紙 10:2–3; コリント人への第二の手紙 12:13"> 確かに、私はあなたがたに負担をかけませんでした。それなのに、私は悪賢く、策略によってあなたがたを捕らえたというのでしょうか。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第二の手紙 9:5; コリント人への第一の手紙 4:17; 列王記第二 5:20–27"> 私があなたがたのところへ送った人のだれかを使って、あなたがたから不当に利益を得たでしょうか。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第二の手紙 8:6; ローマ人への手紙 4:12; 使徒の働き 20:33–35"> 私はテトスに行くよう勧め、一人の兄弟を彼と一緒に送りました。テトスがあなたがたから不当に利益を得たでしょうか。私たちは同じ心で歩み、同じ足跡をたどったではありませんか。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ローマ人への手紙 9:1; コリント人への第一の手紙 14:26; コリント人への第二の手紙 10:8"> また、私たちがあなたがたに対して自分を弁明していると思っているのですか。私たちは神の御前で、キリストにあって語っています。しかし、愛する者たち、すべてはあなたがたを築き上げるためです。</span>
<span className="v" id="v20" data-v="20" data-xref="ガラテヤ人への手紙 5:19–21; ペテロの手紙第一 2:1; ローマ人への手紙 1:29"> 私が行ったとき、あなたがたが私の望むような状態ではなく、私もあなたがたの望まないような者になっているのではないかと心配しています。争い、ねたみ、激しい怒り、派閥、悪口、陰口、高ぶった思い、騒動があるのではないかと恐れています。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第二の手紙 13:2; ペテロの手紙第一 4:2–3; コロサイ人への手紙 3:5"> 私が再び行ったとき、私の神があなたがたの前で私を低くされるのではないか、また、以前に罪を犯し、自分たちが行った汚れ、淫らな行い、みだらな欲望を悔い改めていない多くの人のために、私が嘆くことになるのではないかと恐れています。</span>
</div>

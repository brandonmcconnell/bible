<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テモテへの第二の手紙 1:1; ピリピ人への手紙 1:1; エペソ人への手紙 1:1"> 神のみこころによってキリスト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「キリスト」は「油を注がれた者」という意味である。">a</a></sup>・イエスの使徒となったパウロと、兄弟テモテから、コリントにある神の教会、ならびにアカイア全土にいるすべての聖徒たちへ。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 1:7; エペソ人への手紙 6:23; ピリピ人への手紙 1:2"> 私たちの父なる神と主イエス・キリストから、恵みと平安があなたがたにありますように。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="エペソ人への手紙 1:3; ペテロの手紙第一 1:3; ローマ人への手紙 15:5–6"> 私たちの主イエス・キリストの父なる神、あわれみの父、あらゆる慰めの神がほめたたえられますように。</span>
<span className="v" id="v4" data-v="4" data-xref="テサロニケ人への手紙第一 5:11; イザヤ書 51:12; テサロニケ人への第二の手紙 2:16–17"> 神は、どのような苦難の中でも私たちを慰めてくださいます。それは、私たち自身が神から受ける慰めによって、どのような苦難の中にいる人をも慰めることができるためです。</span>
<span className="v" id="v5" data-v="5" data-xref="コロサイ人への手紙 1:24; ピリピ人への手紙 3:10; コリント人への第二の手紙 4:10–11"> キリストの苦しみが私たちのうちに満ちあふれているように、私たちの慰めもまた、キリストを通して満ちあふれています。</span>
<span className="v" id="v6" data-v="6" data-xref="テモテへの第二の手紙 2:10; コリント人への第二の手紙 1:4; コリント人への第二の手紙 4:15–18"> 私たちが苦難に遭うなら、それはあなたがたの慰めと救いのためです。私たちが慰められるなら、それもあなたがたの慰めのためです。その慰めは、私たちも受けているのと同じ苦しみを、あなたがたが忍耐強く耐え抜く力となります。</span>
<span className="v" id="v7" data-v="7" data-xref="ローマ人への手紙 8:17–18; テサロニケ人への第二の手紙 1:4–7; ヤコブの手紙 1:12"> あなたがたに対する私たちの希望は揺るぎません。あなたがたが苦しみを共にしているように、慰めをも共にしていることを知っているからです。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="コリント人への第二の手紙 4:7–12; コリント人への第一の手紙 15:32; コリント人への第一の手紙 4:8"> 兄弟たち、<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ここや文脈上可能な箇所で「兄弟たち」と訳された言葉は、「兄弟姉妹」または「きょうだいたち」と訳すこともできる。">b</a></sup>アジアで私たちが遭った苦難について、知らずにいてほしくありません。私たちは力に余るほど激しく圧迫され、生きる望みさえ失うほどでした。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第二の手紙 3:5; ヘブル人への手紙 11:19; コリント人への第二の手紙 4:7"> 実際、私たちは自分たちの内に死の宣告を受けたも同然でした。それは、自分自身に頼らず、死者をよみがえらせる神に頼るようになるためでした。</span>
<span className="v" id="v10" data-v="10" data-xref="テモテへの手紙第一 4:10; 詩篇 34:19; ペテロの第二の手紙 2:9"> 神はそれほど大きな死から私たちを救い出し、今も救い出してくださいます。私たちは、この方がこれからも救い出してくださると望みを置いています。</span>
<span className="v" id="v11" data-v="11" data-xref="ピリピ人への手紙 1:19; コリント人への第二の手紙 4:15; 使徒の働き 12:5"> あなたがたも祈りによって私たちを助けてください。そうすれば、多くの人の祈りによって私たちに与えられた恵みの賜物について、多くの人があなたがた<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="MTでは「あなたがた」、TRとNUでは「私たち」。">c</a></sup>に代わって感謝をささげるでしょう。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="コリント人への第二の手紙 2:17; コリント人への第一の手紙 2:13; ヤコブの手紙 3:13–18"> 私たちが誇りとするのは、この世で、特にあなたがたに対して、肉の知恵によらず、神から来る聖さと誠実さをもって、神の恵みによって歩んできたという良心のあかしです。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第二の手紙 4:2; フィレモンへの手紙 1:6; コリント人への第二の手紙 13:6"> 私たちがあなたがたに書いているのは、あなたがたが読んで理解できることだけです。私は、あなたがたが最後まで十分に理解してくれることを願っています。</span>
<span className="v" id="v14" data-v="14" data-xref="ピリピ人への手紙 2:16; コリント人への第一の手紙 1:8; テサロニケ人への手紙第一 2:19–20"> あなたがたが私たちをある程度理解しているとおり、主イエスの日には、私たちがあなたがたの誇りであり、あなたがたも私たちの誇りとなるのです。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 4:19; ローマ人への手紙 1:11; ローマ人への手紙 15:29"> この確信があったので、私はまずあなたがたのところへ行き、あなたがたがもう一度恵みを受けられるようにしたいと考えていました。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への第一の手紙 16:5–7; 使徒の働き 21:5; 使徒の働き 19:21–22"> そして、あなたがたのところを通ってマケドニアへ行き、再びマケドニアからあなたがたのところへ戻り、ユダヤへ向かう旅に送り出してもらうつもりでした。</span>
<span className="v" id="v17" data-v="17" data-xref="マタイ 5:37; ヤコブの手紙 5:12; コリント人への第二の手紙 10:2–3"> では、このように計画した私は、気まぐれだったのでしょうか。それとも、私の計画は肉に従ったもので、私の中では「はい、はい」と「いいえ、いいえ」が同居しているのでしょうか。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 1:9; ヨハネの黙示録 3:7; ヨハネ 7:28"> 神が真実であられることにかけて言います。あなたがたに対する私たちの言葉は、「はい」であると同時に「いいえ」ではありません。</span>
<span className="v" id="v19" data-v="19" data-xref="ヘブル人への手紙 13:8; ヨハネの黙示録 1:17; ヨハネの手紙第二 1:9"> 私とシルワノとテモテがあなたがたの間で宣べ伝えた神の御子イエス・キリストには、「はい」と「いいえ」が同居していたのではなく、ただ「はい」だけがあったのです。</span>
<span className="v" id="v20" data-v="20" data-xref="ヨハネの手紙第一 2:24–25; ガラテヤ人への手紙 3:22; ヨハネの黙示録 7:12"> 神の約束はどれほど多くても、この方においてすべて「はい」となります。それゆえ、私たちはこの方を通して「アーメン」と唱え、神に栄光を帰すのです。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ヨハネの手紙第一 2:27; ペテロの手紙第一 5:10; ヨハネの手紙第一 2:20"> あなたがたと共に私たちをキリストに結びつけて堅く立たせ、私たちに油を注いでくださった方は神です。</span>
<span className="v" id="v22" data-v="22" data-xref="エペソ人への手紙 4:30; コリント人への第二の手紙 5:5; エペソ人への手紙 1:13–14"> 神はまた私たちに証印を押し、保証として私たちの心に聖霊を与えてくださいました。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="ガラテヤ人への手紙 1:20; コリント人への第一の手紙 4:21; ローマ人への手紙 1:9"> 私は神を証人として、自分の命にかけて言います。私がコリントへ行かなかったのは、あなたがたを容赦するためでした。</span>
<span className="v" id="v24" data-v="24" data-xref="ペテロの手紙第一 5:3; コリント人への第一の手紙 15:1; ピリピ人への手紙 1:25–26"> 私たちはあなたがたの信仰を支配しようとしているのではなく、あなたがたの喜びのために共に働く者です。あなたがたは信仰によって堅く立っているからです。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="テサロニケ人への第二の手紙 3:13; ガラテヤ人への手紙 6:9; エペソ人への手紙 3:13"> こういうわけで、私たちはあわれみを受けてこの務めを与えられているので、落胆しません。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第二の手紙 2:17; テサロニケ人への手紙第一 2:3–5; コリント人への第二の手紙 5:11"> かえって、恥ずべき隠れた行いを捨て、悪賢く振る舞わず、神の言葉を曲げることもせず、真理を明らかに示し、神の御前で自分たちをすべての人の良心の判断に委ねています。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 3:14; コリント人への第一の手紙 1:18; テサロニケ人への第二の手紙 2:9–11"> たとえ私たちの福音に覆いが掛かっているとしても、それは滅びに向かう人々にとって覆われているのです。</span>
<span className="v" id="v4" data-v="4" data-xref="ヨハネ 12:40; コリント人への第二の手紙 3:14; 使徒の働き 26:18"> この世の神が、信じない人々の思いをくらませ、神のかたちであるキリストの栄光の福音の光が彼らを照らさないようにしています。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 1:24; コリント人への第一の手紙 1:23; テサロニケ人への手紙第一 2:5–6"> 私たちは自分自身を宣べ伝えているのではありません。キリスト・イエスを主として宣べ伝え、私たち自身は、イエスのゆえにあなたがたに仕える僕にすぎないと語っています。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 60:2; 創世記 1:3; ペテロの手紙第一 2:9"> 「闇の中から光が輝き出る」と言われた神が、私たちの心を照らしてくださいました。それは、イエス・キリストの顔に輝く神の栄光を知る光を与えるためです。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="コリント人への第二の手紙 3:5–6; コリント人への第二の手紙 5:1; エペソ人への手紙 2:8–9"> しかし、私たちはこの宝を土の器に持っています。それは、この並外れた力が神のものであって、私たちから出たものではないことが明らかになるためです。</span>
<span className="v" id="v8" data-v="8" data-xref="ヤコブの手紙 1:2–4; ローマ人への手紙 8:35–37; ペテロの手紙第一 4:12–14"> 私たちは四方から圧迫されても、押しつぶされることはありません。途方に暮れても、絶望することはありません。</span>
<span className="v" id="v9" data-v="9" data-xref="イザヤ書 43:2; ミカ書 7:8; 詩篇 37:24–25"> 迫害されても、見捨てられることはありません。打ち倒されても、滅ぼされることはありません。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 6:5; テモテへの第二の手紙 2:11; ペテロの手紙第一 4:13"> 私たちはいつも、イエスの死をこの身に負っています。それは、イエスの命もまた、私たちの体に現れるためです。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第一の手紙 15:49; ローマ人への手紙 8:36; 詩篇 44:22"> 生きている私たちは、イエスのために絶えず死に引き渡されています。それは、イエスの命もまた、死ぬべき私たちの肉体に現れるためです。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第二の手紙 13:9; コリント人への第一の手紙 4:10; 使徒の働き 20:24"> こうして、私たちのうちには死が働き、あなたがたのうちには命が働いています。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 116:10; ヘブル人への手紙 11:1–40; コリント人への第二の手紙 3:12"> 「私は信じた。それゆえ語った」と書かれているとおり、私たちも同じ信仰の霊を持っており、信じているので語ります。</span>
<span className="v" id="v14" data-v="14" data-xref="テサロニケ人への手紙第一 4:14; ローマ人への手紙 8:11; ユダ 1:24"> 主イエスをよみがえらせた方が、イエスを通して<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NUでは「イエスと共に」とあり、「イエスを通して」ではない。">a</a></sup>私たちをもよみがえらせ、あなたがたと共に御前に立たせてくださることを知っているからです。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 8:28; エペソ人への手紙 3:20–21; コリント人への第二の手紙 9:11–12"> すべてはあなたがたのためです。それは、恵みがますます多くの人に及び、感謝が満ちあふれて、神の栄光となるためです。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="イザヤ書 40:31; コロサイ人への手紙 3:10; イザヤ書 40:29"> ですから、私たちは落胆しません。たとえ外なる人は衰えていっても、内なる人は日々新しくされています。</span>
<span className="v" id="v17" data-v="17" data-xref="ローマ人への手紙 8:18; ペテロの手紙第一 5:10; ローマ人への手紙 5:3–5"> 今しばらくの軽い苦難は、比べようもなく重い永遠の栄光を私たちにもたらします。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第二の手紙 5:7; ローマ人への手紙 8:24–25; ヘブル人への手紙 11:1"> 私たちは見えるものではなく、見えないものに目を向けています。見えるものは一時的ですが、見えないものは永遠だからです。</span>
</div>

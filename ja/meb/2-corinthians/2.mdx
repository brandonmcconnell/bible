<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第二の手紙 1:23; コリント人への第二の手紙 12:20–21; コリント人への第二の手紙 13:10"> そこで私は、再びあなたがたのところへ行って悲しませることはすまい、と心に決めました。</span>
<span className="v" id="v2" data-v="2" data-xref="コリント人への第二の手紙 7:8; コリント人への第二の手紙 1:14; コリント人への第一の手紙 12:26"> 私があなたがたを悲しませるなら、私に悲しませられたその人以外に、だれが私を喜ばせてくれるでしょうか。</span>
<span className="v" id="v3" data-v="3" data-xref="ガラテヤ人への手紙 5:10; コリント人への第二の手紙 8:22; フィレモンへの手紙 1:21"> 私があのことを書いたのは、そちらへ行ったとき、本来なら私を喜ばせてくれるはずの人々から悲しみを受けないためでした。私の喜びはあなたがた全員の喜びでもあると、あなたがた皆を信頼していたからです。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第二の手紙 7:12; 箴言 27:5–6; レビ記 19:17–18"> 私は大きな苦難と心の痛みの中で、多くの涙を流しながらあなたがたに書きました。あなたがたを悲しませるためではなく、私があなたがたをどれほど深く愛しているか知ってもらうためでした。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="コリント人への第一の手紙 5:12–13; ガラテヤ人への手紙 4:12; 箴言 17:25"> もし悲しみを引き起こした人がいるなら、その人は私だけを悲しませたのではありません。言い過ぎにならないように言えば、ある程度、あなたがた全員を悲しませたのです。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第一の手紙 5:4–5; テモテへの手紙第一 5:20; コリント人への第二の手紙 7:11"> その人には、多くの人から受けたこの処分で十分です。</span>
<span className="v" id="v7" data-v="7" data-xref="エペソ人への手紙 4:32; ガラテヤ人への手紙 6:1–2; コロサイ人への手紙 3:13"> ですから、今はむしろその人を赦し、慰めなさい。そうしないと、その人はあまりの悲しみにのみ込まれてしまうかもしれません。</span>
<span className="v" id="v8" data-v="8" data-xref="ユダ 1:22–23; ガラテヤ人への手紙 6:1–2; ガラテヤ人への手紙 6:10"> そこで、その人に対する愛をはっきり示すよう、あなたがたにお願いします。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第二の手紙 10:6; フィレモンへの手紙 1:21; ピリピ人への手紙 2:22"> 私が書いたのは、あなたがたがすべてのことにおいて従順であるかどうかを試し、確かめるためでもありました。</span>
<span className="v" id="v10" data-v="10" data-xref="ヨハネ 20:23; マタイ 18:18; コリント人への第二の手紙 5:20"> あなたがたが何かを赦す人を、私も赦します。実際、私が赦すべきことを赦したとすれば、それはあなたがたのために、キリストの御前で赦したのです。</span>
<span className="v" id="v11" data-v="11" data-xref="ペテロの手紙第一 5:8; エペソ人への手紙 6:11–12; コリント人への第二の手紙 11:3"> それは、私たちがサタンにつけ込まれないためです。私たちはサタンの策略を知らないわけではありません。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒の働き 16:8; 使徒の働き 14:27; コロサイ人への手紙 4:3"> さて、キリストの福音を伝えるためにトロアスへ行ったとき、主にあって私のために働きの門が開かれていました。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第二の手紙 7:5–6; コリント人への第二の手紙 12:18; テトス 1:4"> しかし、兄弟テトスに会えなかったので、私の心には安らぎがありませんでした。それで人々に別れを告げ、マケドニアへ向かいました。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="エペソ人への手紙 5:2; ローマ人への手紙 8:37; コリント人への第二の手紙 2:15–16"> しかし、神に感謝します。神はいつも私たちをキリストの凱旋の行列に連ならせ、私たちを通して、キリストを知る香りをあらゆる所に放ってくださいます。</span>
<span className="v" id="v15" data-v="15" data-xref="エペソ人への手紙 5:2; コリント人への第一の手紙 1:18; エゼキエル書 20:41"> 救われつつある人々の中でも、滅びつつある人々の中でも、私たちは神にささげられるキリストのかぐわしい香りです。</span>
<span className="v" id="v16" data-v="16" data-xref="コリント人への第二の手紙 3:5–6; ヨハネ 9:39; ペテロの手紙第一 2:7–8"> 一方の人々にとっては、死から死へ至らせる死の臭いであり、他方の人々にとっては、命から命へ至らせる命の香りです。このような務めを果たす資格がだれにあるでしょうか。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第二の手紙 4:2; コリント人への第二の手紙 1:12; ペテロの第二の手紙 2:1–3"> 私たちは、多くの人のように神の言葉を売り物にしてはいません。神から遣わされた者として、誠実に、神の御前で、キリストにあって語っています。</span>
</div>

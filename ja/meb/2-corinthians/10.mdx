<span className="v" id="v2" data-v="2" data-xref="コリント人への第二の手紙 13:10; コリント人への第二の手紙 13:2; ガラテヤ人への手紙 5:16–25"> どうか、私がそちらに行ったとき、強い態度に出ずに済むようにしてください。私たちを肉に従って歩む者と見なす人々には、断固として臨むつもりです。</span>
<span className="v" id="v3" data-v="3" data-xref="コリント人への第二の手紙 10:4; ガラテヤ人への手紙 2:20; ペテロの手紙第一 4:1–2"> 私たちは肉体をもって生きていますが、肉に従って戦っているのではありません。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第二の手紙 6:7; エペソ人への手紙 6:13–18; エレミヤ書 1:10"> 私たちが戦いに用いる武器は肉のものではなく、神の力を帯び、要塞を打ち倒すほど強力なものです。</span>
<span className="v" id="v5" data-v="5" data-xref="ヘブル人への手紙 4:12; イザヤ書 55:7; ペテロの手紙第一 1:14–15"> 私たちは、あらゆる議論と、神を知ることに逆らって高くそびえるものをことごとく打ち倒し、すべての思いを捕らえてキリストに従わせます。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第二の手紙 2:9; 民数記 16:26–30; コリント人への第二の手紙 7:15"> そして、あなたがたの従順が完全になったとき、あらゆる不従順を罰する用意ができています。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="コリント人への第二の手紙 5:12; ヨハネ 7:24; コリント人への第一の手紙 14:37"> あなたがたは外見だけを見ているのですか。自分がキリストのものであると確信している人は、自分がキリストのものであるように、私たちもキリストのものであることを、もう一度よく考えなさい。</span>
<span className="v" id="v8" data-v="8" data-xref="コリント人への第二の手紙 13:10; コリント人への第二の手紙 12:6; ガラテヤ人への手紙 1:1"> 主が私たちに与えてくださった権威は、あなたがたを打ち倒すためではなく、築き上げるためのものです。私がその権威について多少誇りすぎたとしても、恥をかくことはありません。</span>
<span className="v" id="v9" data-v="9" data-xref="コリント人への第二の手紙 10:10; コリント人への第一の手紙 4:19–21; コリント人への第一の手紙 4:5"> 私が手紙であなたがたを脅そうとしているかのようには思われたくありません。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第一の手紙 1:17; 出エジプト記 4:10; ガラテヤ人への手紙 4:13–14"> ある人々は言います。「彼の手紙は重々しく力強いが、実際に会ってみると弱々しく、話すことも軽蔑されるほどだ。」</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第二の手紙 12:20; コリント人への第二の手紙 13:2–3; コリント人への第二の手紙 13:10"> そのような人は、離れているときに手紙の言葉で示す私たちと、そちらにいるときに行いで示す私たちは同じだと考えなさい。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="箴言 27:2; 箴言 26:12; ルカ 18:11"> 私たちは、自分を推薦する人々の中のある者と自分を同列に置いたり、比べたりするほど大胆ではありません。彼らは自分たちを基準にして自分たちを測り、自分たち同士で比べていますが、分別がありません。</span>
<span className="v" id="v13" data-v="13" data-xref="ローマ人への手紙 12:6; ローマ人への手紙 15:20; ペテロの手紙第一 4:10"> しかし、私たちは定められた範囲を越えて誇ることはせず、神が私たちに割り当ててくださった領域の中で誇ります。その領域はあなたがたのところにまで及んでいます。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第一の手紙 4:15; テモテへの手紙第一 1:11; ローマ人への手紙 1:16"> 私たちは、あなたがたのところまで達していなかったかのように、領域を越えて無理に手を伸ばしているのではありません。実際、キリストの福音を携え、あなたがたのところまで行ったのです。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 15:20; テサロニケ人への第二の手紙 1:3; コリント人への第二の手紙 10:13"> 私たちは定められた範囲を越え、ほかの人々の労苦を自分のものとして誇ることはしません。むしろ、あなたがたの信仰が成長するにつれて、あなたがたによって、私たちの働きが割り当てられた領域の中で大いに広がることを望んでいます。</span>
<span className="v" id="v16" data-v="16" data-xref="ローマ人への手紙 15:24–28; 使徒の働き 19:21"> それは、あなたがたの地域を越えた所にまで福音を宣べ伝えるためであり、ほかの人の領域ですでに行われたことを誇るためではありません。</span>
<span className="v" id="v17" data-v="17" data-xref="エレミヤ書 9:23–24; コリント人への第一の手紙 1:31; ヤコブの手紙 1:9–10"> しかし、「誇る者は、主を誇りなさい。」</span>
<span className="v" id="v18" data-v="18" data-xref="ルカ 16:15; 箴言 21:2; コリント人への第一の手紙 4:5"> 自分で自分を認める人ではなく、主に認められる人こそ、本当に認められるからです。</span>

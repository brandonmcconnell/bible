<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ヨブ記 19:25–26; ヨハネの手紙第一 3:2; ペテロの第二の手紙 1:13–14"> 私たちは知っています。地上の幕屋であるこの住まいが壊されても、神がくださる建物、すなわち人の手で造られたものではない、天にある永遠の住まいが私たちにはあります。</span>
<span className="v" id="v2" data-v="2" data-xref="ローマ人への手紙 8:23; コリント人への第一の手紙 15:53–54; コリント人への第二の手紙 5:3–4"> 私たちはこの幕屋にあってうめき、天から与えられる住まいを着せられたいと切に願っています。</span>
<span className="v" id="v3" data-v="3" data-xref="創世記 3:7–11; ヨハネの黙示録 16:15; ヨハネの黙示録 3:18"> それを着ていれば、裸のままでいることはないからです。</span>
<span className="v" id="v4" data-v="4" data-xref="コリント人への第一の手紙 15:53–54; コリント人への第二の手紙 5:2; イザヤ書 25:8"> 実際、この幕屋にいる私たちは重荷を負ってうめいています。脱ぎたいのではなく、上から着せられたいのです。こうして、死ぬべきものが命にのみ込まれます。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 1:22; エペソ人への手紙 1:13–14; ローマ人への手紙 8:23"> まさにこのために私たちを造ってくださった方は神であり、保証として聖霊をも与えてくださいました。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="コリント人への第二の手紙 5:1; ピリピ人への手紙 3:20–21; ヘブル人への手紙 11:13"> ですから、私たちはいつも確信を抱いています。そして、この体に住んでいる間は、主から離れていることを知っています。</span>
<span className="v" id="v7" data-v="7" data-xref="ヘブル人への手紙 11:1–27; コリント人への第二の手紙 4:18; ローマ人への手紙 8:24–25"> 私たちは見えるものによってではなく、信仰によって歩んでいるからです。</span>
<span className="v" id="v8" data-v="8" data-xref="ピリピ人への手紙 1:20–24; コリント人への第二の手紙 5:6; ヨハネ 14:3"> 私たちは確信を抱いており、むしろ体を離れて、主のもとに住みたいと願っています。</span>
<span className="v" id="v9" data-v="9" data-xref="コロサイ人への手紙 1:10; ペテロの第二の手紙 3:14; ローマ人への手紙 14:18"> それゆえ、この体に住んでいても、体を離れていても、主に喜ばれることを私たちの目標としています。</span>
<span className="v" id="v10" data-v="10" data-xref="マタイ 16:27; ヨハネの黙示録 22:12; エペソ人への手紙 6:8"> 私たちは皆、キリストの裁きの座の前に姿を現さなければなりません。それぞれが、良いことであれ悪いことであれ、体にあって行ったことに応じて報いを受けるためです。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="ユダ 1:23; ヘブル人への手紙 10:31; テモテへの第二の手紙 2:24–26"> このように主への畏れを知る私たちは、人々を説得しています。私たちのことは神には明らかです。また、あなたがたの良心にも明らかになっていることを願っています。</span>
<span className="v" id="v12" data-v="12" data-xref="コリント人への第二の手紙 3:1; コリント人への第二の手紙 1:14; ガラテヤ人への手紙 6:12–14"> 私たちは再び自分たちをあなたがたに推薦しているのではありません。内面ではなく外見を誇る人々に答えられるよう、私たちのことを誇る機会をあなたがたに与えているのです。</span>
<span className="v" id="v13" data-v="13" data-xref="コリント人への第二の手紙 11:16–17; コリント人への第二の手紙 11:1; コリント人への第二の手紙 12:6"> もし私たちが正気でないように見えるなら、それは神のためです。正気でいるなら、それはあなたがたのためです。</span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 2:20; ローマ人への手紙 14:7–9; マタイ 10:37–38"> キリストの愛が私たちを駆り立てています。私たちはこう考えるからです。一人の方がすべての人のために死なれたのだから、すべての人が死んだのです。</span>
<span className="v" id="v15" data-v="15" data-xref="ローマ人への手紙 14:7–9; ペテロの手紙第一 4:2–4; ペテロの手紙第一 1:14–15"> この方がすべての人のために死なれたのは、生きている人々がもはや自分のためではなく、自分たちのために死んでよみがえられた方のために生きるようになるためです。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="コロサイ人への手紙 3:11; ピリピ人への手紙 3:7–8; ヨハネ 6:63"> ですから、今後、私たちはだれをも人間的な基準では見ません。たとえかつてキリストをそのように知っていたとしても、今はもうそのようには知りません。</span>
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 36:26; エペソ人への手紙 4:22–24; イザヤ書 43:18–19"> ですから、だれでもキリストのうちにいるなら、その人は新しい創造です。古いものは過ぎ去りました。見よ、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「見よ」は、ギリシャ語の「ἰδοὺ」に由来し、目を向ける、注意する、観察する、見る、またはじっと見つめるという意味である。しばしば間投詞として用いられる。">a</a></sup>すべてが新しくなりました。</span>
<span className="v" id="v18" data-v="18" data-xref="コロサイ人への手紙 1:20–21; コリント人への第二の手紙 5:19–20; ローマ人への手紙 5:10–11"> これらすべては神から出ています。神はイエス・キリストを通して私たちをご自分と和解させ、和解の務めを私たちに与えてくださいました。</span>
<span className="v" id="v19" data-v="19" data-xref="イザヤ書 43:25; イザヤ書 44:22; ヨハネの手紙第一 2:1–2"> すなわち、神はキリストにあって世をご自分と和解させ、人々の背きを彼らに負わせず、和解の言葉を私たちに託されたのです。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="エペソ人への手紙 6:20; ルカ 14:23; マラキ書 2:7"> ですから、私たちはキリストの使節です。神が私たちを通して呼びかけておられるのです。キリストに代わってお願いします。神と和解してください。</span>
<span className="v" id="v21" data-v="21" data-xref="ペテロの手紙第一 2:22–24; ペテロの手紙第一 3:18; ローマ人への手紙 5:19"> 神は、罪を知らなかった方を私たちのために罪とされました。それは、私たちがこの方にあって神の義となるためです。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 16:9; コリント人への第二の手紙 9:2; コリント人への第二の手紙 9:4"> さて、兄弟たち、マケドニアの諸教会に与えられた神の恵みについて、あなたがたに知らせます。</span>
<span className="v" id="v2" data-v="2" data-xref="ヤコブの手紙 2:5; 箴言 11:25; コリント人への第二の手紙 6:10"> 彼らは苦難による厳しい試練の中にありながら、喜びに満ちあふれ、極度の貧しさの中から惜しみなく豊かにささげました。</span>
<span className="v" id="v3" data-v="3" data-xref="出エジプト記 35:29; 出エジプト記 35:5; 出エジプト記 35:21–22"> 私は証言します。彼らは力に応じて、いや、力以上に、自ら進んでささげました。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒の働き 24:17; ガラテヤ人への手紙 6:10; コリント人への第二の手紙 9:1"> そして、聖徒たちに仕えるこの恵みの業と交わりに加わらせてほしいと、熱心に私たちに願ったのです。</span>
<span className="v" id="v5" data-v="5" data-xref="ローマ人への手紙 12:1; ローマ人への手紙 14:7–9; 歴代誌 第二 30:12"> それは私たちの予想を超えていました。彼らはまず自分自身を主にささげ、さらに神のみこころによって私たちにも身を委ねました。</span>
<span className="v" id="v6" data-v="6" data-xref="コリント人への第二の手紙 12:18; コリント人への第二の手紙 8:19; コリント人への第二の手紙 8:4"> そこで私たちはテトスに、以前始めたこの恵みの業を、あなたがたの間でも完成させるよう勧めました。</span>
<span className="v" id="v7" data-v="7" data-xref="コリント人への第二の手紙 9:8; ペテロの第二の手紙 1:5–8; テサロニケ人への第二の手紙 1:3"> あなたがたは、信仰、言葉、知識、あらゆる熱意、そして私たちへの愛において、すべてに満ちあふれています。この恵みの業にも豊かにあずかってください。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="コリント人への第一の手紙 7:6; ヨハネの手紙第一 3:17–19; ヤコブの手紙 2:14–16"> 私は命令として言うのではありません。他の人々の熱意を示すことによって、あなたがたの愛が真実であるかどうかを確かめようとしているのです。</span>
<span className="v" id="v9" data-v="9" data-xref="ローマ人への手紙 8:32; ピリピ人への手紙 2:6–8; マタイ 20:28"> あなたがたは、私たちの主イエス・キリストの恵みを知っています。この方は富んでおられたのに、あなたがたのために貧しくなられました。それは、ご自分の貧しさによって、あなたがたを富ませるためでした。</span>
<span className="v" id="v10" data-v="10" data-xref="テモテへの手紙第一 6:18–19; ヘブル人への手紙 13:16; コリント人への第二の手紙 9:2"> このことについて、私の意見を述べます。あなたがたは一年前、実行に着手しただけでなく、進んで行いたいと願った最初の人々でした。ですから、今それを完成させることがあなたがたの益になります。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第二の手紙 9:2"> 今、その実行もやり遂げなさい。進んで願ったその熱意に応じて、自分たちの持っているもので完成させるのです。</span>
<span className="v" id="v12" data-v="12" data-xref="マルコ 12:42–44; コリント人への第二の手紙 9:7; ルカ 21:1–4"> 進んで行う心があるなら、そのささげ物は、持っていないものによってではなく、持っているものに応じて受け入れられるからです。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 4:34; ローマ人への手紙 15:26–27"> これは、ほかの人々には楽をさせ、あなたがたには苦労させるためではありません。</span>
<span className="v" id="v14" data-v="14" data-xref="コリント人への第二の手紙 9:12; 使徒の働き 4:34"> むしろ、公平にするためです。今、あなたがたの豊かさが彼らの不足を補い、彼らの豊かさもあなたがたの不足を補うようになれば、公平になります。</span>
<span className="v" id="v15" data-v="15" data-xref="出エジプト記 16:18; ルカ 22:35"> 「多く集めた者にも余ることがなく、少なく集めた者にも足りないことがなかった」と書かれているとおりです。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 17:17; エレミヤ書 32:40; コリント人への第二の手紙 2:13–14"> 神に感謝します。神は、あなたがたに対する私と同じ熱意をテトスの心に与えてくださいました。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第二の手紙 8:6; ヘブル人への手紙 13:22; コリント人への第二の手紙 8:10"> 彼は私たちの勧めを受け入れただけでなく、非常に熱心だったので、自ら進んであなたがたのところへ向かいました。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第二の手紙 12:18; コリント人への第二の手紙 8:19; コリント人への第一の手紙 7:17"> 私たちは彼と一緒に、福音の働きによってすべての教会に名の知られた一人の兄弟を送りました。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第一の手紙 16:3–4; コリント人への第二の手紙 4:15; コリント人への第二の手紙 9:8"> そればかりでなく、彼はこの恵みの業のために私たちと同行する者として、諸教会から選ばれました。私たちはこの業に奉仕することによって、主ご自身に栄光を帰し、私たちの熱意を示そうとしています。</span>
<span className="v" id="v20" data-v="20" data-xref="テサロニケ人への手紙第一 5:22; ローマ人への手紙 14:16; エペソ人への手紙 5:15"> 私たちが取り扱っているこの豊かな贈り物について、だれからも非難されないように用心しています。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 12:17; ペテロの手紙第一 2:12; ピリピ人への手紙 4:8"> 私たちは、主の御前だけでなく、人々の前でも立派なことを行うよう心がけています。</span>
<span className="v" id="v22" data-v="22" data-xref="ピリピ人への手紙 2:20–22"> また、彼らと一緒にもう一人の兄弟を送りました。私たちは何度も、さまざまなことにおいて彼が熱心であることを確かめてきました。今では、あなたがたに対する大きな信頼のゆえに、いっそう熱心になっています。</span>
<span className="v" id="v23" data-v="23" data-xref="ピリピ人への手紙 2:25; フィレモンへの手紙 1:17; コリント人への第二の手紙 8:6"> テトスについて言えば、彼は私の仲間であり、あなたがたのために共に働く者です。私たちの兄弟たちについて言えば、彼らは諸教会から遣わされた使者であり、キリストの栄光です。</span>
<span className="v" id="v24" data-v="24" data-xref="コリント人への第二の手紙 7:14; コリント人への第二の手紙 7:4; コリント人への第二の手紙 9:2–4"> ですから、あなたがたの愛の証拠と、私たちがあなたがたを誇ってきたことが真実である証拠とを、諸教会の前で彼らに示してください。</span>

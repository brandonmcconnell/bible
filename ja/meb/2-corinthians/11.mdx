<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="コリント人への第二の手紙 11:4; コリント人への第一の手紙 1:21; コリント人への第二の手紙 11:19"> 私の少しばかりの愚かさに、どうか堪えてください。いや、実際あなたがたは堪えてくれています。</span>
<span className="v" id="v2" data-v="2" data-xref="ホセア書 2:19–20; エペソ人への手紙 5:26–27; イザヤ書 54:5"> 私は神から来るねたみをもって、あなたがたをねたんでいます。あなたがたを一人の夫と婚約させ、純潔な処女としてキリストにささげようとしたからです。</span>
<span className="v" id="v3" data-v="3" data-xref="コロサイ人への手紙 2:8; ガラテヤ人への手紙 1:6; エペソ人への手紙 4:14"> しかし、蛇が悪賢さによってエバを欺いたように、あなたがたの思いが惑わされ、キリストにある純真さから離れてしまうのではないかと心配しています。</span>
<span className="v" id="v4" data-v="4" data-xref="ガラテヤ人への手紙 1:6–8; コリント人への第一の手紙 3:11; テモテへの手紙第一 2:5"> というのも、だれかが来て、私たちが宣べ伝えなかった別のイエスを宣べ伝えても、あなたがたが受けなかった異なる霊を受けても、受け入れなかった異なる「福音」を受け入れても、あなたがたはよくも平気で受け入れているからです。</span>
<span className="v" id="v5" data-v="5" data-xref="コリント人への第二の手紙 12:11–12; コリント人への第一の手紙 15:10; ガラテヤ人への手紙 2:6–9"> 私は、あの「大使徒」たちに少しも劣っていないと思っています。</span>
<span className="v" id="v6" data-v="6" data-xref="エペソ人への手紙 3:4; コリント人への第一の手紙 1:17; コリント人への第二の手紙 4:2"> 私は話し方は未熟でも、知識まで未熟なわけではありません。私たちはあらゆることを、あらゆる面であなたがたに明らかにしてきました。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="コリント人への第二の手紙 12:13; テサロニケ人への手紙第一 2:9; コリント人への第二の手紙 10:1"> それとも、あなたがたを高くするために自分を低くし、神の福音を無償で宣べ伝えたことは、私の罪だったのでしょうか。</span>
<span className="v" id="v8" data-v="8" data-xref="ピリピ人への手紙 4:18; コリント人への第二の手紙 11:9; ピリピ人への手紙 4:14–16"> 私はほかの諸教会から報酬を受け、いわば彼らから奪うことによって、あなたがたに仕えました。</span>
<span className="v" id="v9" data-v="9" data-xref="テサロニケ人への第二の手紙 3:8–9; テサロニケ人への手紙第一 2:9; テサロニケ人への手紙第一 2:6"> あなたがたのところにいて不足したときも、だれにも負担をかけませんでした。マケドニアから来た兄弟たちが、私に必要なものを補ってくれたからです。私はあらゆることにおいて、あなたがたの負担にならないようにしてきましたし、これからもそうします。</span>
<span className="v" id="v10" data-v="10" data-xref="ローマ人への手紙 9:1; ローマ人への手紙 1:9; 使徒の働き 18:12"> 私のうちにあるキリストの真理にかけて言います。アカイア地方で、この誇りを私から奪う者はいません。</span>
<span className="v" id="v11" data-v="11" data-xref="コリント人への第二の手紙 12:15; コリント人への第二の手紙 6:11–12; コリント人への第二の手紙 7:3"> なぜでしょうか。私があなたがたを愛していないからですか。神がご存じです。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="コリント人への第一の手紙 9:12; コリント人への第一の手紙 5:6; コリント人への第二の手紙 5:12"> 私は今していることを、これからも続けます。誇る機会を得ようとする者たちから、その口実を断つためです。そうすれば、彼らが誇る点で私たちと同じだというなら、実際に同じであることを示さなければならなくなります。</span>
<span className="v" id="v13" data-v="13" data-xref="ガラテヤ人への手紙 1:7; ヨハネの黙示録 2:2; ヨハネの手紙第一 4:1"> そのような者たちは偽使徒であり、人を欺く働き手であって、キリストの使徒になりすましています。</span>
<span className="v" id="v14" data-v="14" data-xref="ガラテヤ人への手紙 1:8; コリント人への第二の手紙 2:11; コリント人への第二の手紙 11:3"> それも不思議ではありません。サタンでさえ光の天使になりすますからです。</span>
<span className="v" id="v15" data-v="15" data-xref="ピリピ人への手紙 3:19; ヨハネの黙示録 9:11; イザヤ書 9:14–15"> ですから、サタンに仕える者たちが義に仕える者になりすましたとしても、驚くには及びません。彼らの最後は、その行いに応じたものとなります。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="コリント人への第二の手紙 11:1; コリント人への第二の手紙 12:6; コリント人への第二の手紙 12:11"> もう一度言います。だれも私を愚か者だと思わないでください。しかし、もしそう思うなら、愚か者としてでも私を受け入れ、私にも少し誇らせてください。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第一の手紙 7:12; ピリピ人への手紙 3:3–6; コリント人への第二の手紙 9:4"> このように自信をもって誇る言葉は、主に従って語るものではなく、愚かさの中で語るものです。</span>
<span className="v" id="v18" data-v="18" data-xref="コリント人への第一の手紙 4:10; コリント人への第二の手紙 11:21–23; コリント人への第二の手紙 10:12–18"> 多くの人が肉に従って誇っているので、私も誇ることにします。</span>
<span className="v" id="v19" data-v="19" data-xref="コリント人への第一の手紙 4:10; コリント人への第一の手紙 10:15; コリント人への第一の手紙 8:1"> あなたがたは賢いのですから、愚かな者たちを喜んで堪えているのですね。</span>
<span className="v" id="v20" data-v="20" data-xref="ガラテヤ人への手紙 2:4; ガラテヤ人への手紙 4:3; ガラテヤ人への手紙 5:1"> 実際、だれかがあなたがたを奴隷にし、食い物にし、捕らえ、自分を高くし、顔を殴っても、あなたがたは我慢しています。</span>
<span className="v" id="v21" data-v="21" data-xref="コリント人への第二の手紙 10:10; コリント人への第二の手紙 11:17; コリント人への第二の手紙 10:1–2"> 恥を忍んで言えば、私たちはそんなことをするには弱すぎたようです。しかし、だれかが何かについて大胆に誇るなら、私も大胆に誇ります。愚か者のように言うのですが。</span>
<span className="v" id="v22" data-v="22" data-xref="ピリピ人への手紙 3:5; ローマ人への手紙 11:1; ローマ人への手紙 9:4"> 彼らはヘブル人ですか。私もそうです。イスラエル人ですか。私もそうです。アブラハムの子孫<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="別訳、「種」。">a</a></sup>ですか。私もそうです。</span>
<span className="v" id="v23" data-v="23" data-xref="コリント人への第二の手紙 6:4–5; コリント人への第二の手紙 1:9–10; コリント人への第二の手紙 6:9"> 彼らはキリストに仕える者ですか。正気でない者のように語りますが、私は彼ら以上です。はるかに多く労苦し、はるかに多く投獄され、数えきれないほどむち打たれ、幾度も死に直面しました。</span>
<span className="v" id="v24" data-v="24" data-xref="マルコ 13:9; 申命記 25:2–3; マタイ 10:17"> ユダヤ人から四十に一つ足りないむちを受けたことが五度あります。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒の働き 14:19; 使徒の働き 16:37; ヘブル人への手紙 11:37"> 棒で打たれたことが三度、石打ちにされたことが一度、難船したことが三度あり、一昼夜を沖合で漂ったこともあります。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒の働き 14:5; 使徒の働き 17:5; 使徒の働き 13:50"> 幾度も旅をし、川の危険、強盗の危険、同胞から受ける危険、異邦人から受ける危険、町での危険、荒野での危険、海での危険、偽兄弟たちの間での危険に遭い、</span>
<span className="v" id="v27" data-v="27" data-xref="ピリピ人への手紙 4:12; コリント人への第二の手紙 6:5; テサロニケ人への手紙第一 2:9"> 労苦と苦難の中にあり、幾度も眠らず、飢え渇き、しばしば食べずに過ごし、寒さに震え、着る物もありませんでした。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="コリント人への第一の手紙 7:17; ローマ人への手紙 15:16; 使徒の働き 20:18–35"> これら外からの苦難のほかに、すべての教会に対する心配が、日々私に重くのしかかっています。</span>
<span className="v" id="v29" data-v="29" data-xref="コリント人への第一の手紙 8:13; コリント人への第一の手紙 9:22; ガラテヤ人への手紙 4:8–20"> だれかが弱っているのに、私も弱らずにいられるでしょうか。だれかがつまずかされているのに、私が憤りに燃えずにいられるでしょうか。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="コリント人への第二の手紙 12:5–11; 箴言 25:27; コリント人への第一の手紙 2:3"> どうしても誇らなければならないのなら、私は自分の弱さにかかわることを誇ります。</span>
<span className="v" id="v31" data-v="31" data-xref="ローマ人への手紙 9:5; エペソ人への手紙 1:3; ヨハネ 10:30"> 永遠にほめたたえられる方、主イエス・キリストの父なる神は、私が偽っていないことをご存じです。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒の働き 9:24–25; コリント人への第二の手紙 11:26"> ダマスコでは、アレタ王の配下の総督が、私を捕らえようとしてダマスコ人の町を見張っていました。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒の働き 9:25; サムエル記第一 19:12; ヨシュア記 2:18"> しかし私は城壁の窓から、かごに入れられてつり降ろされ、彼の手を逃れました。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="ルツ記 1:9; テモテへの手紙第一 5:8; テモテへの手紙第一 5:14"> しゅうとめのナオミはルツに言った。「娘よ。あなたが幸せに暮らせるよう、安住の場を探してあげるべきではありませんか。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 25:5–10; ルツ記 2:20–23; ルツ記 2:8"> あなたが一緒に働いた若い女たちの主人ボアズは、私たちの親族でしょう。見なさい。今夜、彼は打ち場で大麦をふるい分けます。</span>
<span className="v" id="v3" data-v="3" data-xref="サムエル記第二 14:2; テモテへの手紙第一 2:9–10; エステル記 5:1"> 体を洗い、香油を塗り、衣をまとって、打ち場へ下って行きなさい。ただし、彼が食べたり飲んだりし終えるまでは、姿を見せてはなりません。</span>
<span className="v" id="v4" data-v="4" data-xref="テサロニケ人への手紙第一 5:22"> 彼が横になったら、その場所をよく見ておきなさい。それから近づいて足元の覆いをめくり、そこに横になりなさい。何をすべきかは、彼が教えてくれます。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="コロサイ人への手紙 3:20; エペソ人への手紙 6:1"> ルツは言った。「おっしゃることは、すべていたします。」</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 1:8; ヨハネ 2:5; 出エジプト記 20:12"> 彼女は打ち場へ下って行き、しゅうとめに命じられたとおり、すべて行った。</span>
<span className="v" id="v7" data-v="7" data-xref="士師記 19:6; エステル記 1:10; サムエル記第二 13:28"> ボアズは食べて飲み、満ち足りた気分になって、穀物の山の端に横になった。ルツはそっと近づき、彼の足元の覆いをめくって横になった。</span>
<span className="v" id="v8" data-v="8"> 真夜中になって、ボアズは驚いて身を起こした。見ると、一人の女が足元に横たわっていた。</span>
<span className="v" id="v9" data-v="9" data-xref="エゼキエル書 16:8; ルツ記 2:20; ルツ記 3:12"> 彼は言った。「あなたはだれですか。」<br />ルツは答えた。「私は、あなたのしもべルツです。どうか衣の裾をこのしもべの上に広げてください。あなたは私たちを贖う権利を持つ近親者です。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ルツ記 2:20; コリント人への第一の手紙 13:4–5; ルツ記 1:8"> ボアズは言った。「娘よ、主があなたを祝福されるように。あなたは初めに示した慈しみにもまして、今また大きな慈しみを示しました。貧しい者であれ富む者であれ、若い男たちの後を追わなかったからです。</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 31:29–31; 箴言 31:10; 箴言 12:4"> さあ、娘よ、恐れることはありません。あなたの願うことはすべてしてあげましょう。この町の者は皆、あなたが立派な女性であることを知っています。</span>
<span className="v" id="v12" data-v="12" data-xref="ルツ記 4:1; テサロニケ人への手紙第一 4:6; マタイ 7:12"> 確かに、私は贖いの権利を持つ近親者です。しかし、私よりさらに近い親族がいます。</span>
<span className="v" id="v13" data-v="13" data-xref="ルツ記 4:5; エレミヤ書 4:2; ルツ記 2:20"> 今夜はここにとどまりなさい。朝になって、その人があなたのために近親者の務めを果たすなら、それでよい。その人に果たしてもらいましょう。しかし、その人が務めを果たそうとしないなら、主が生きておられるように、私があなたのために果たします。朝まで横になっていなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="コリント人への第二の手紙 8:21; ローマ人への手紙 14:16; コリント人への第一の手紙 10:32"> ルツは朝まで彼の足元に横たわり、人の顔を見分けられるようになる前に起き上がった。ボアズが、「この女が打ち場に来たことを知られてはならない」と言ったからである。</span>
<span className="v" id="v15" data-v="15" data-xref="イザヤ書 32:8; ガラテヤ人への手紙 6:10"> ボアズは言った。「まとっている上着を広げて、しっかり持ちなさい。」ルツが広げると、彼は大麦を六杯分量って彼女に負わせ、それから町へ入って行った。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> ルツがしゅうとめのもとへ戻ると、ナオミは尋ねた。「どうでしたか、娘よ。」<br />ルツは、その人がしてくれたことをすべて話した。</span>
<span className="v" id="v17" data-v="17"> そして言った。「『しゅうとめのところへ手ぶらで帰ってはならない』と言って、この大麦六杯分をくださいました。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="詩篇 37:3–5; イザヤ書 28:16; イザヤ書 30:7"> ナオミは言った。「娘よ、このことがどう決まるか分かるまで待っていなさい。あの方は今日中に決着をつけるまで、休みはしないでしょう。」</span>
</div>

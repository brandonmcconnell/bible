<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 25:7; ルツ記 3:12; 申命記 16:18"> ボアズは町の門へ上って行き、そこに座った。すると、ボアズが話していた贖いの権利を持つ近親者が、ちょうど通りかかった。ボアズは言った。「こちらへ来て、ここに座ってください。」その人は近寄って座った。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 31:23; 列王記第一 21:8; 使徒の働き 6:12"> ボアズは町の長老たちから十人を招き、「ここに座ってください」と言った。彼らも座った。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 13:10; 詩篇 112:5"> ボアズはその近親者に言った。「モアブの地から帰って来たナオミが、私たちの身内エリメレクの畑を売りに出しています。</span>
<span className="v" id="v4" data-v="4" data-xref="レビ記 25:25–29; エレミヤ書 32:7–12; ローマ人への手紙 12:17"> そこで、ここに座っている人々と私の民の長老たちの前で買い取っていただきたいと、あなたに知らせておこうと思いました。あなたが贖うなら、そうしてください。贖わないなら、私に告げてください。あなたのほかに贖う者はなく、私はあなたの次だからです。」<br />その人は言った。「私が贖いましょう。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="創世記 38:8; 申命記 25:5–6; マタイ 22:24"> するとボアズは言った。「ナオミから畑を買い取る日には、死んだ者の名をその相続地に残すため、死んだ者の妻であるモアブの女ルツをも妻として迎えなければなりません。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="レビ記 25:25; ルツ記 3:13"> その近親者は言った。「それでは、私には贖うことができません。自分の相続地を損なうことになるかもしれないからです。私の贖いの権利を、あなたが引き受けてください。私には贖えません。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命記 25:7–10"> 昔イスラエルでは、贖いや交換に関する事柄を確定するとき、一方が履き物を脱いで相手に渡す習慣があった。これがイスラエルで取引を成立させるしるしであった。</span>
<span className="v" id="v8" data-v="8"> そこでその近親者はボアズに、「あなたが買い取ってください」と言い、自分の履き物を脱いだ。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="エレミヤ書 32:10–12; 創世記 23:16–18"> ボアズは長老たちとすべての民に言った。「私が今日、エリメレクのもの、キルヨンとマフロンのものをすべてナオミから買い取ったことについて、あなたがたは証人です。</span>
<span className="v" id="v10" data-v="10" data-xref="申命記 25:6; エペソ人への手紙 5:25; 創世記 29:27"> 私はまた、死んだ者の名をその相続地に残し、その名が兄弟たちの間からも、その町の門からも絶えないようにするため、マフロンの妻であったモアブの女ルツを妻として迎えます。あなたがたは今日、その証人です。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="創世記 29:32–24; ミカ書 5:2; マタイ 2:6"> 門にいたすべての民と長老たちは言った。「私たちは証人です。主が、あなたの家に入るこの女性を、ともにイスラエルの家を築いたラケルとレアのようにしてくださいますように。あなたがエフラタで栄え、ベツレヘムで名を上げますように。</span>
<span className="v" id="v12" data-v="12" data-xref="創世記 38:29; サムエル記第一 2:20; 歴代誌上 2:4"> 主がこの若い女性によってあなたに与えられる子孫<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「種」。">a</a></sup>により、あなたの家が、タマルがユダに産んだペレツの家のようになりますように。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="創世記 33:5; 創世記 29:31; ルツ記 3:11"> こうしてボアズはルツを迎え、彼女はその妻となった。ボアズが彼女のところに入ると、主はルツを身ごもらせ、彼女は男の子を産んだ。</span>
<span className="v" id="v14" data-v="14" data-xref="マタイ 1:5–20; ルカ 1:58; 創世記 12:2"> 女たちはナオミに言った。「今日、あなたに贖う者を絶やされなかった主がほめたたえられますように。その名がイスラエルでたたえられますように。</span>
<span className="v" id="v15" data-v="15" data-xref="詩篇 55:22; イザヤ書 46:4; 創世記 45:11"> その子はあなたの命を新たにし、老年のあなたを支えるでしょう。あなたを愛し、七人の息子にもまさる嫁が、その子を産んだのですから。」</span>
<span className="v" id="v16" data-v="16"> ナオミはその子を胸に抱き、世話をする者となった。</span>
<span className="v" id="v17" data-v="17" data-xref="ルカ 1:58–63"> 近所の女たちは、「ナオミに男の子が生まれた」と言って、その子に名を付けた。彼女たちは彼をオベデと名付けた。オベデはエッサイの父、ダビデの祖父である。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="マタイ 1:3–6; 歴代誌上 2:4–8; ルカ 3:33"> ペレツの系図は次のとおりである。ペレツにはヘツロンが生まれ、</span>
<span className="v" id="v19" data-v="19" data-xref="ルカ 3:33; 歴代誌上 2:9–10; マタイ 1:4"> ヘツロンにはラムが生まれ、ラムにはアミナダブが生まれ、</span>
<span className="v" id="v20" data-v="20" data-xref="民数記 1:7; ルカ 3:32; マタイ 1:4"> アミナダブにはナフションが生まれ、ナフションにはサルモンが生まれ、</span>
<span className="v" id="v21" data-v="21" data-xref="ルカ 3:32; マタイ 1:5; 歴代誌上 2:11–12"> サルモンにはボアズが生まれ、ボアズにはオベデが生まれ、</span>
<span className="v" id="v22" data-v="22" data-xref="歴代誌上 2:15; イザヤ書 11:1; マタイ 1:6"> オベデにはエッサイが生まれ、エッサイにはダビデが生まれた。</span>
</div>

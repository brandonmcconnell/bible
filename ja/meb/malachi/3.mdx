<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="マラキ書 4:5; ルカ 1:76; マルコ 1:2–3"> 「見よ、私は私の使者を遣わす。彼は私の前に道を備える。あなたがたが求めている主が、突然その神殿に来られる。見よ、あなたがたが望んでいる契約の使者が来る」と万軍の主は言われる。</span>
<span className="v" id="v2" data-v="2" data-xref="ゼカリヤ書 13:9; イザヤ書 4:4; コリント人への第一の手紙 3:13–15"> 「しかし、だれがその方の来られる日に耐えられるだろうか。その方が現れる時、だれが立っていられるだろうか。その方は精錬する者の火のようであり、布を洗う者の灰汁のようだからだ。</span>
<span className="v" id="v3" data-v="3" data-xref="イザヤ書 1:25; 箴言 17:3; ゼカリヤ書 13:9"> その方は銀を精錬し、清める者として座り、レビの子らを清め、金や銀のように精錬する。彼らは義にかなうささげ物を主にささげる。</span>
<span className="v" id="v4" data-v="4" data-xref="歴代誌 第二 7:1–3; イザヤ書 56:7; ゼカリヤ書 8:3"> その時、ユダとエルサレムのささげ物は、昔の日々、遠い昔の年月のように、主に喜ばれる。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="ヤコブの手紙 5:8–9; ヘブル人への手紙 13:4; 申命記 5:11"> 私は裁きのためにあなたがたに近づく。私は、魔術を行う者、姦淫する者、偽って誓う者、雇い人の賃金を奪う者、やもめとみなしごを虐げる者、寄留者から公正を奪う者、私を畏れない者に対して、すみやかに証言する」と万軍の主は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数記 23:19; ヘブル人への手紙 13:8; ヤコブの手紙 1:17"> 「主である私は変わらない。それゆえ、ヤコブの子らよ、あなたがたは滅ぼし尽くされない。</span>
<span className="v" id="v7" data-v="7" data-xref="ゼカリヤ書 1:3; ローマ人への手紙 10:21; ローマ人への手紙 10:3"> あなたがたは父祖の時代から、私の定めに背き、それを守らなかった。私に立ち返れ。そうすれば、私もあなたがたに立ち返る」と万軍の主は言われる。「しかし、あなたがたは言う。『どのようにして立ち返ればよいのですか。』</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="箴言 3:9–10; マタイ 22:21; マルコ 12:17"> 人が神から奪うことがあるだろうか。しかし、あなたがたは私から奪っている。それでも言う。『われわれはどのようにあなたから奪ったのですか。』十分の一とささげ物によってである。</span>
<span className="v" id="v9" data-v="9" data-xref="申命記 28:15–19; ハガイ書 1:6–11; ハガイ書 2:14–17"> あなたがたは、のろいの下にある。この民全体が私から奪っているからだ。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第二の手紙 9:6–8; マタイ 6:33; 箴言 3:9–10"> 十分の一をすべて倉に携えて来て、私の家に食物があるようにせよ。このことで、今、私を試してみよ」と万軍の主は言われる。「私があなたがたのために天の窓を開き、受けきれないほどの祝福を注ぐかどうか、確かめよ。</span>
<span className="v" id="v11" data-v="11" data-xref="申命記 11:14; ヨエル書 2:22; ゼカリヤ書 8:12"> 私はあなたがたのために食い荒らすものを責める。それはあなたがたの土地の実りを滅ぼさない。畑のぶどうの木も、実る前にその実を落とさない」と万軍の主は言われる。</span>
<span className="v" id="v12" data-v="12" data-xref="イザヤ書 61:9; イザヤ書 62:4; ゼカリヤ書 8:23"> 「すべての国々は、あなたがたを幸いな者と呼ぶ。あなたがたは喜ばしい地となるからだ」と万軍の主は言われる。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="マラキ書 2:17; イザヤ書 37:23; ローマ人への手紙 9:20"> 「あなたがたは私に逆らって、厳しい言葉を語った」と主は言われる。「それでも、あなたがたは言う。『われわれはあなたに逆らって何を語ったのですか。』</span>
<span className="v" id="v14" data-v="14" data-xref="イザヤ書 58:3; ゼパニヤ書 1:12; 詩篇 73:8–13"> あなたがたは言った。『神に仕えることはむなしい。神の命令を守り、万軍の主の前で嘆きながら歩んでも、何の益があるだろうか。</span>
<span className="v" id="v15" data-v="15" data-xref="マラキ書 4:1; エレミヤ書 12:1–2; マラキ書 2:17"> 今、われわれは高ぶる者を幸いだと言う。悪を行う者たちは栄え、神を試みても逃れている。』」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ヨハネの黙示録 20:12; 詩篇 56:8; マラキ書 4:2"> その時、主を畏れる者たちは互いに語り合った。主は耳を傾けて聞かれ、主を畏れ、その御名を尊ぶ者たちのために、御前で記念の書が記された。</span>
<span className="v" id="v17" data-v="17" data-xref="出エジプト記 19:5; 申命記 7:6; コリント人への第二の手紙 6:18"> 「私が定める日に、彼らは私のもの、私の宝となる」と万軍の主は言われる。「人が自分に仕える息子をあわれんで守るように、私は彼らを守る。</span>
<span className="v" id="v18" data-v="18" data-xref="マタイ 25:46; 詩篇 58:10–11; 創世記 18:25"> その時、あなたがたは再び、義人と悪者との違い、神に仕える者と仕えない者との違いを見分ける。」</span>
</div>

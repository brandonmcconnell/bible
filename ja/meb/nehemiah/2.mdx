<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="エズラ記 7:1; ネヘミヤ記 1:11; ネヘミヤ記 1:1"> アルタクセルクセス王の第二十年、ニサンの月に、王の前にぶどう酒が置かれた。私はぶどう酒を取り、王に差し出した。それまで、王の前で悲しそうな顔をしたことはなかった。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 15:13; 創世記 40:7"> 王は私に言った。「あなたは病気ではないのに、なぜ悲しそうな顔をしているのか。これは心の悲しみにほかならない。」<br />そこで、私は非常に恐れた。</span>
<span className="v" id="v3" data-v="3" data-xref="ネヘミヤ記 1:3; ダニエル書 2:4; 列王記第一 1:31"> 私は王に言った。「王がとこしえに生きられますように。私の先祖の墓のある町が荒れ果て、その門が火で焼かれたままなのです。どうして悲しそうな顔をせずにいられましょうか。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ピリピ人への手紙 4:6; 箴言 3:6; ネヘミヤ記 1:4"> すると、王は私に言った。「あなたは何を求めているのか。」<br />そこで私は天の神に祈った。</span>
<span className="v" id="v5" data-v="5" data-xref="サムエル記第二 14:22; ルツ記 2:13; エステル記 7:3"> 私は王に言った。「もし王がよしとされ、このしもべが王のご好意を得ているなら、どうか私をユダへ、先祖の墓のある町へ遣わし、そこを再建させてください。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ネヘミヤ記 13:6; イザヤ書 65:24; ネヘミヤ記 5:14"> 王は私に言った。王妃も王のそばに座っていた。「旅にはどれほどかかるのか。いつ戻るのか。」<br />王は私を遣わすことをよしとされ、私は期限を申し上げた。</span>
<span className="v" id="v7" data-v="7" data-xref="エズラ記 7:21; エズラ記 8:36; ネヘミヤ記 2:9"> さらに私は王に言った。「もし王がよしとされるなら、私がユダに着くまで通行を許すよう、川の向こう側の総督たちへの手紙をお与えください。</span>
<span className="v" id="v8" data-v="8" data-xref="エズラ記 7:6; イザヤ書 66:14; ネヘミヤ記 7:2"> また、神殿のそばの要塞の門、町の城壁、そして私が住む家の梁に用いる木材を与えるよう、王の森林の管理者アサフへの手紙もお与えください。」<br />私の神の恵み深い御手が私の上にあったので、王は私の願いを聞き入れた。</span>
<span className="v" id="v9" data-v="9" data-xref="エズラ記 8:22"> 私は川の向こう側の総督たちのもとへ行き、王の手紙を渡した。王は軍の隊長たちと騎兵を私とともに遣わしていた。</span>
<span className="v" id="v10" data-v="10" data-xref="ネヘミヤ記 2:19; ネヘミヤ記 4:7; ネヘミヤ記 13:4"> ホロニ人サンバラテと、アモン人の役人トビヤはこれを聞き、イスラエルの子らの繁栄を図る者が来たことを、ひどく不快に思った。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="エズラ記 8:32"> こうして私はエルサレムに着き、そこに三日間滞在した。</span>
<span className="v" id="v12" data-v="12" data-xref="ヨハネの黙示録 17:17; エズラ記 7:27; エレミヤ書 31:33"> 私は夜、数人の者とともに起き出した。私の神がエルサレムのために行うよう私の心に与えられたことを、だれにも話していなかった。私が乗っていた動物のほかには、一頭も連れていなかった。</span>
<span className="v" id="v13" data-v="13" data-xref="ネヘミヤ記 1:3; ネヘミヤ記 2:3; ネヘミヤ記 3:13–14"> 私は夜、谷の門を出て、ジャッカルの井戸から糞の門へ進み、崩れたエルサレムの城壁と、火で焼け落ちた門を調べた。</span>
<span className="v" id="v14" data-v="14" data-xref="ネヘミヤ記 3:15; 列王記第二 20:20; 歴代誌 第二 32:30"> それから泉の門と王の池へ進んだが、私の乗っていた動物が通れる場所がなかった。</span>
<span className="v" id="v15" data-v="15" data-xref="サムエル記第二 15:23; ヨハネ 18:1; エレミヤ書 31:38–40"> そこで私は夜のうちに谷川沿いに上って城壁を調べ、引き返して谷の門から入り、戻った。</span>
<span className="v" id="v16" data-v="16"> 役人たちは、私がどこへ行き、何をしたかを知らなかった。私はまだ、ユダヤ人にも、祭司にも、貴族にも、役人にも、その他の工事に携わる者にも、そのことを話していなかった。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="エゼキエル書 5:14; ネヘミヤ記 1:3; イザヤ書 35:3–4"> そこで私は彼らに言った。「私たちが置かれている惨状を、あなたがたは見ている。エルサレムは荒れ果て、その門は火で焼かれている。さあ、エルサレムの城壁を建て直し、もはや恥を受けないようにしよう。」</span>
<span className="v" id="v18" data-v="18" data-xref="ピリピ人への手紙 2:13; 歴代誌 第二 32:5; 歴代誌上 19:13"> 私は、私の上にあった神の恵み深い御手のことと、王が私に語った言葉を彼らに告げた。<br />彼らは「立ち上がって建てよう」と言い、この良い働きのために力を奮い起こした。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ネヘミヤ記 6:6; ネヘミヤ記 6:1–2; 詩篇 44:13–14"> しかし、ホロニ人サンバラテ、アモン人のしもべトビヤ、アラビア人ゲシェムがそれを聞いたとき、彼らは私たちを嘲笑し、見下して言った。「あなたがたがしているこのことは何だ。王に反逆しようとしているのか。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="使徒の働き 8:21; エズラ記 4:3; 詩篇 35:27"> 私は彼らに答えた。「天の神が私たちを栄えさせてくださる。そのしもべである私たちは立ち上がって建てる。しかし、あなたがたにはエルサレムに何の分け前も、権利も、名を残す記録もない。」</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ネヘミヤ記 12:39; エレミヤ書 31:38; ヨハネ 5:2"> 大祭司エリアシブは、兄弟である祭司たちとともに立ち上がり、羊の門を建てた。彼らはそれを聖別し、扉を取り付け、ハメアのやぐらからハナネルのやぐらまでを聖別した。</span>
<span className="v" id="v2" data-v="2" data-xref="ネヘミヤ記 7:36; エズラ記 2:34; ネヘミヤ記 10:12"> 彼の隣では、エリコの人々が建てた。彼らの隣では、イムリの子ザクルが建てた。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="歴代誌 第二 33:14; ネヘミヤ記 12:39; ゼパニヤ書 1:10"> 魚の門はハセナアの子らが建てた。彼らは梁を渡し、扉、かんぬき、横木を取り付けた。</span>
<span className="v" id="v4" data-v="4" data-xref="エズラ記 8:33; ネヘミヤ記 3:21; ネヘミヤ記 10:7"> 彼らの隣では、ハコツの子であるウリヤの子メレモテが修復を行った。彼らの隣では、メシェザべるの子であるベレクヤの子メシュラムが修復を行った。彼らの隣では、バアナの子ザドクが修復を行った。</span>
<span className="v" id="v5" data-v="5" data-xref="ネヘミヤ記 3:27; サムエル記第二 14:2; エレミヤ書 27:2"> その隣ではテコア人が修復した。しかし彼らの貴族たちは、主の働きに肩を入れようとしなかった。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ネヘミヤ記 12:39"> 古い門はパセアの子ヨヤダと、ベソデヤの子メシュラムが修復した。彼らは梁を渡し、扉、かんぬき、横木を取り付けた。</span>
<span className="v" id="v7" data-v="7" data-xref="サムエル記第二 21:2; ヨシュア記 9:3–27; ネヘミヤ記 3:19"> その隣では、ギベオン人メラテヤ、メロノテ人ヤドン、ギベオンとミツパの人々が、川の向こう側の総督の官邸までを修復した。</span>
<span className="v" id="v8" data-v="8" data-xref="ネヘミヤ記 12:38; ネヘミヤ記 3:31–32; 創世記 50:2"> その隣では、金細工人の一人、ハルハヤの子ウジエルが修復した。その隣では、香料作りの一人ハナニヤが修復し、彼らは広い城壁までエルサレムを補強した。</span>
<span className="v" id="v9" data-v="9" data-xref="ネヘミヤ記 3:12; ネヘミヤ記 3:17"> 彼らの隣では、エルサレムの半区の支配者であるフルの子レファヤが修復を行った。</span>
<span className="v" id="v10" data-v="10" data-xref="ネヘミヤ記 3:28–30; ネヘミヤ記 10:4; ネヘミヤ記 3:23"> 彼らの隣では、ハルマフの子エダヤが自分の家の向かい側を修復した。彼の隣では、ハシャブネヤの子ハトシュが修復を行った。</span>
<span className="v" id="v11" data-v="11" data-xref="ネヘミヤ記 12:38; エズラ記 2:6; ネヘミヤ記 10:14"> ハリムの子マルキヤとパハテ・モアブの子ハシュブは、別の区画とかまどのやぐらを修復した。</span>
<span className="v" id="v12" data-v="12" data-xref="ネヘミヤ記 3:9; 使徒の働き 21:8–9; 出エジプト記 35:25"> 彼の隣では、エルサレムの半区の支配者であるハロヘシュの子シャルムが、娘たちとともに修復を行った。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ネヘミヤ記 2:13; ヨシュア記 15:34; 歴代誌 第二 26:9"> 谷の門はハヌンとザノアの住民が修復した。彼らはこれを建て、扉、かんぬき、横木を取り付け、さらに糞の門までの城壁一千キュビト<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一キュビトは約46センチメートル、または約18インチである。">a</a></sup>を修復した。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="エレミヤ書 6:1; ネヘミヤ記 2:13; ネヘミヤ記 3:12–13"> 糞の門は、ベテ・ハケレムの地区の支配者、レカブの子マルキヤが修復した。彼はこれを建て、扉、かんぬき、横木を取り付けた。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ヨハネ 9:7; イザヤ書 8:6; ネヘミヤ記 12:37"> 泉の門は、ミツパの地区の支配者、コル・ホゼの子シャルンが修復した。彼はこれを建てて屋根を設け、扉、かんぬき、横木を取り付けた。また、王の園のそばにあるシェラの池の城壁を、ダビデの町から下る階段まで修復した。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 2:29; ネヘミヤ記 3:9; 列王記第二 20:20"> その後では、ベテ・ツルの半地区の支配者、アズブクの子ネヘミヤが、ダビデの墓の向かい側から、造られた池と勇士たちの家までを修復した。</span>
<span className="v" id="v17" data-v="17" data-xref="ヨシュア記 15:44; ネヘミヤ記 3:16; サムエル記第一 23:1–13"> その後では、レビ人バニの子レフムが修復した。彼の隣では、ケイラの半区の支配者ハシャビヤが、自分の区のために修復した。</span>
<span className="v" id="v18" data-v="18"> その後では、彼らの兄弟である、ケイラのもう半地区の支配者、ヘナダデの子バワイが修復した。</span>
<span className="v" id="v19" data-v="19" data-xref="歴代誌 第二 26:9; ネヘミヤ記 10:9; ネヘミヤ記 12:8"> その隣では、ミツパの支配者エシュアの子エゼルが、城壁の曲がり角にある武器庫への上り口の向かい側の、別の区画を修復した。</span>
<span className="v" id="v20" data-v="20" data-xref="ネヘミヤ記 3:1; 伝道者の書 9:10; ローマ人への手紙 12:11"> 彼の後では、ザバイの子バルクが、城壁の曲がり角から大祭司エリアシブの家の戸口に至るまでの別の区画を、熱心に修復した。</span>
<span className="v" id="v21" data-v="21" data-xref="ネヘミヤ記 7:63; エズラ記 2:61"> 彼の後では、ハコツの子であるウリヤの子メレモテが、エリアシブの家の戸口からエリアシブの家の端に至るまでの、別の区画を修復した。</span>
<span className="v" id="v22" data-v="22" data-xref="ネヘミヤ記 12:28; ネヘミヤ記 6:2"> その後では、周辺地域に住む祭司たちが修復した。</span>
<span className="v" id="v23" data-v="23" data-xref="ネヘミヤ記 10:2; ネヘミヤ記 8:4; ネヘミヤ記 3:29–30"> 彼らの後では、ベニヤミンとハシュブが自分たちの家の向かい側を修復した。彼らの後では、アナニヤの子であるマアセヤの子アザルヤが自分の家のそばを修復した。</span>
<span className="v" id="v24" data-v="24" data-xref="ネヘミヤ記 3:19; ネヘミヤ記 3:27; ネヘミヤ記 10:9"> その後では、ヘナダデの子ビヌイが、アザルヤの家から城壁の曲がり角を経て、角までの別の区画を修復した。</span>
<span className="v" id="v25" data-v="25" data-xref="エレミヤ書 32:2; エレミヤ書 37:21; ネヘミヤ記 12:39"> ウザイの子パラルは、城壁の曲がり角の向かい側と、監視の庭のそばにある王宮の上部から突き出したやぐらの向かい側を修復した。その後では、パロシュの子ペダヤが修復した。</span>
<span className="v" id="v26" data-v="26" data-xref="ネヘミヤ記 8:1; ネヘミヤ記 11:21; ネヘミヤ記 12:37"> （宮のしもべたちは、東向きの水の門の向かい側から、突き出たやぐらのところまでのオフェルに住んでいた。）</span>
<span className="v" id="v27" data-v="27" data-xref="ネヘミヤ記 3:5"> 彼らの後では、テコア人が突き出ている大きなやぐらの向かい側から、オフェルの城壁に至るまでの別の区画を修復した。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="歴代誌 第二 23:15; エレミヤ書 31:40; 列王記第二 11:16"> 馬の門の上からは、祭司たちがそれぞれ自分の家の向かい側を修復した。</span>
<span className="v" id="v29" data-v="29" data-xref="エレミヤ書 19:2; エズラ記 2:37; ネヘミヤ記 7:40"> 彼らの後では、イムルの子ザドクが自分の家の向かい側を修復した。彼の後では、東の門の門衛であるシェカニヤの子シェマヤが修復を行った。</span>
<span className="v" id="v30" data-v="30"> 彼の後では、シェレミヤの子ハナニヤと、ザラフの第六子ハヌンが別の区画を修復した。彼の後では、ベレクヤの子メシュラムが自分の部屋の向かい側を修復した。</span>
<span className="v" id="v31" data-v="31" data-xref="ネヘミヤ記 3:8; ネヘミヤ記 3:32"> その後では、金細工人の一人マルキヤが、ハミフカデの門の向かい側から角の上り口まで、宮のしもべたちと商人たちの家の方へ向かって修復した。</span>
<span className="v" id="v32" data-v="32" data-xref="ネヘミヤ記 3:1; ヨハネ 5:2; ネヘミヤ記 12:39"> 角の上り口と羊の門の間は、金細工人と商人たちが修復した。</span>
</div>
</div>

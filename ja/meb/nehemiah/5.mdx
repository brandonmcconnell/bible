<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 5:7; 出エジプト記 22:25–27; コリント人への第一の手紙 6:6–8"> 民とその妻たちから、同胞であるユダヤ人に対して、大きな叫びが上がった。</span>
<span className="v" id="v2" data-v="2" data-xref="マラキ書 2:2; 詩篇 128:2–4; 詩篇 127:3–5"> ある者たちは言った。「私たちには息子や娘が大勢いる。食べて生きるために、穀物を得させてほしい。」</span>
<span className="v" id="v3" data-v="3" data-xref="レビ記 25:35–39; マラキ書 3:8–11; 創世記 47:15–25"> またある者たちは言った。「飢饉のために穀物を得ようと、畑、ぶどう園、家を抵当に入れている。」</span>
<span className="v" id="v4" data-v="4" data-xref="エズラ記 4:13; エズラ記 4:20; 申命記 28:47–48"> さらにある者たちは言った。「王への貢ぎ物を納めるため、畑とぶどう園を担保にして金を借りた。</span>
<span className="v" id="v5" data-v="5" data-xref="列王記第二 4:1; レビ記 25:39–43; イザヤ書 58:7"> 今、私たちも同胞も同じ血肉であり、私たちの子どもも彼らの子どもと同じだ。見よ、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="「見よ」はヘブル語の「הִנֵּה」に由来し、「見なさい」「注目せよ」などの意味を持ち、しばしば間投詞として用いられる。">a</a></sup>私たちは息子や娘を奴隷として差し出し、娘たちの中には、すでに奴隷にされた者もいる。畑やぶどう園がほかの人々のものとなった今、私たちにはどうする力もない。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出エジプト記 11:8; ネヘミヤ記 13:25; エペソ人への手紙 4:26"> 彼らの叫びとこれらの言葉を聞いたとき、私は非常に怒った。</span>
<span className="v" id="v7" data-v="7" data-xref="申命記 23:19–20; レビ記 25:36; 出エジプト記 22:25"> 私はよく考えた上で、貴族と役人を責めて言った。「あなたがたは同胞から利息を取り立てている。」そして彼らに対して大集会を召集した。</span>
<span className="v" id="v8" data-v="8" data-xref="レビ記 25:47–49; コリント人への第一の手紙 8:11; マタイ 25:29"> 私は彼らに言った。「私たちは力の及ぶ限り、諸国の民に売られた同胞ユダヤ人を買い戻してきた。それなのに、あなたがたは同胞を売ろうというのか。今度は私たちが彼らを買い戻さなければならないのか。」彼らは黙り、返す言葉もなかった。</span>
<span className="v" id="v9" data-v="9" data-xref="レビ記 25:36; サムエル記第二 12:14; ローマ人への手紙 2:24"> 私はさらに言った。「あなたがたのしていることは良くない。敵である諸国の民のそしりを受けないためにも、私たちの神を恐れて歩むべきではないか。</span>
<span className="v" id="v10" data-v="10" data-xref="コリント人への第二の手紙 6:1; 出エジプト記 22:25–27; エゼキエル書 18:13"> 私も、兄弟たちも、しもべたちも、彼らに金や穀物を貸している。私たちも、この利息を免除しよう。</span>
<span className="v" id="v11" data-v="11" data-xref="イザヤ書 58:6; レビ記 6:4–5; ルカ 3:8"> 今日、彼らの畑、ぶどう園、オリーブ園、家を返しなさい。あなたがたが取り立てている金、穀物、新しいぶどう酒、油の百分の一も返しなさい。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="エズラ記 10:5; エレミヤ書 34:8–10; マタイ 19:21–22"> すると彼らは言った。「私たちはそれらを返し、彼らには何も求めません。あなたの言うとおりにします。」<br />そこで私は祭司たちを呼び、この約束のとおりに彼らが行うことを誓わせた。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒の働き 18:6; 歴代誌上 16:36; マタイ 10:14"> 私はまた衣の懐を振り払い、言った。「この約束を果たさない者を、神がこのように、その家と働きの実から振り払われるように。その者がこのように振り払われ、空にされるように。」<br />会衆は皆「アーメン」と言って主をほめたたえ、民はこの約束のとおりに行った。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="ネヘミヤ記 13:6; テサロニケ人への第二の手紙 3:8–9; コリント人への第一の手紙 9:4–15"> 私がユダの地で総督に任命されたときから、すなわちアルタクセルクセス王の第二十年から第三十二年までの十二年間、私も兄弟たちも、総督に支給される食糧を受けなかった。</span>
<span className="v" id="v15" data-v="15" data-xref="ネヘミヤ記 5:9; イザヤ書 50:10; 箴言 16:6"> 私より前の総督たちは民に重い負担を負わせ、パンとぶどう酒のほか、銀四十シェケル<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一シェケルは約10グラム、または約0.35オンスである。">b</a></sup>を取り立てた。そのしもべたちさえ民に威張った。しかし私は神を恐れ、そのようにはしなかった。</span>
<span className="v" id="v16" data-v="16" data-xref="ガラテヤ人への手紙 6:9; テサロニケ人への手紙第一 2:5–6; コリント人への第一の手紙 15:58"> 私はこの城壁の工事にも力を尽くした。私たちは土地を一つも買わず、私のしもべたちも皆、工事に集まった。</span>
<span className="v" id="v17" data-v="17" data-xref="列王記第一 18:19; ペテロの手紙第一 4:9–10; サムエル記第二 9:7"> また、私の食卓には、ユダヤ人と役人たち百五十人のほか、私たちの周囲の諸国の民の中から私たちのもとに来た者たちがいた。</span>
<span className="v" id="v18" data-v="18" data-xref="列王記第一 4:22–23; 詩篇 37:21; 詩篇 37:26"> 一日に用意されたのは、雄牛一頭と選り抜きの羊六頭であった。鳥も用意され、十日に一度はあらゆる種類のぶどう酒が豊かに備えられた。それでも私は総督の俸禄を要求しなかった。この民に課せられた労役が重かったからである。</span>
<span className="v" id="v19" data-v="19" data-xref="ネヘミヤ記 13:31; 詩篇 106:4; ネヘミヤ記 13:14"> 私の神よ、私がこの民のために行ったすべての良いことを覚え、私に恵みを施してください。</span>
</div>

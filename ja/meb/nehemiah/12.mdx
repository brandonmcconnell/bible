<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ネヘミヤ記 10:2–8; ネヘミヤ記 12:12–21; エズラ記 2:1–2"> シェアルティエルの子ゼルバベルとエシュアとともに上って来た祭司とレビ人は次のとおりである。セラヤ、エレミヤ、エズラ、</span>
<span className="v" id="v2" data-v="2"> アマルヤ、マルク、ハトシュ、</span>
<span className="v" id="v3" data-v="3"> シェカニヤ、レフム、メレモテ、</span>
<span className="v" id="v4" data-v="4" data-xref="ルカ 1:5"> イド、ギネトイ、アビヤ、</span>
<span className="v" id="v5" data-v="5"> ミヤミン、マアデヤ、ビルガ、</span>
<span className="v" id="v6" data-v="6" data-xref="歴代誌上 9:10; ネヘミヤ記 11:10"> シェマヤ、ヨヤリブ、エダヤ、</span>
<span className="v" id="v7" data-v="7" data-xref="歴代誌上 24:18; ゼカリヤ書 3:1; エズラ記 3:2"> サル、アモク、ヒルキヤ、エダヤ。彼らはエシュアの時代の祭司と、その兄弟たちの長であった。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="ネヘミヤ記 11:17; ネヘミヤ記 12:24; ネヘミヤ記 11:22"> レビ人は、エシュア、ビヌイ、カドミエル、シェレブヤ、ユダ、そして感謝の歌を取り仕切るマタヌヤと、その兄弟たちであった。</span>
<span className="v" id="v9" data-v="9" data-xref="ネヘミヤ記 12:24; 詩篇 134:1–3"> 彼らの兄弟バクブクヤとウノは、それぞれの務めの組で彼らと向かい合っていた。</span>
<span className="v" id="v10" data-v="10" data-xref="歴代誌上 6:3–15; ネヘミヤ記 13:28; ネヘミヤ記 13:4"> エシュアにヨヤキムが生まれ、ヨヤキムにエリアシブが生まれ、エリアシブにヨヤダが生まれ、</span>
<span className="v" id="v11" data-v="11"> ヨヤダにヨナタンが生まれ、ヨナタンにヤドゥアが生まれた。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="ネヘミヤ記 12:22; 歴代誌上 9:33–34; 歴代誌上 24:6–31"> ヨヤキムの時代に、祭司であり父の家の長であった者は次のとおりである。セラヤの家ではメラヤ、エレミヤの家ではハナニヤ、</span>
<span className="v" id="v13" data-v="13"> エズラの家系ではメシュラム。アマルヤの家系ではエホハナン。</span>
<span className="v" id="v14" data-v="14"> マルキの家系ではヨナタン。シェバニヤの家系ではヨセフ。</span>
<span className="v" id="v15" data-v="15"> ハリムの家系ではアデナ。メラヨテの家系ではヘルカイ。</span>
<span className="v" id="v16" data-v="16"> イドの家系ではゼカリヤ。ギネトンの家系ではメシュラム。</span>
<span className="v" id="v17" data-v="17"> アビヤの家ではジクリ、ミンヤミンの家では、またモアデヤの家ではピルタイ、</span>
<span className="v" id="v18" data-v="18"> ビルガの家系ではシャムア。シェマヤの家系ではエホナタン。</span>
<span className="v" id="v19" data-v="19"> ヨヤリブの家系ではマテナイ。エダヤの家系ではウジ。</span>
<span className="v" id="v20" data-v="20"> サライの家系ではカライ。アモクの家系ではエベル。</span>
<span className="v" id="v21" data-v="21"> ヒルキヤの家系ではハシャビヤ。エダヤの家系ではネタンエル。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ネヘミヤ記 12:10–13"> エリアシブ、ヨヤダ、ヨハナン、ヤドゥアの時代に、レビ人の父の家の長たちが記録された。祭司たちも、ペルシア人ダレイオスの治世に記録された。</span>
<span className="v" id="v23" data-v="23" data-xref="歴代誌上 9:14–44"> レビの子らで父の家の長である者たちは、エリアシブの子ヨハナンの時代に至るまで、年代記の書に記録された。</span>
<span className="v" id="v24" data-v="24" data-xref="歴代誌上 25:1–26; ネヘミヤ記 11:17; エズラ記 3:10–11"> レビ人の長たちは、ハシャビヤ、シェレブヤ、カドミエルの子エシュアであり、兄弟たちは彼らと向かい合い、神の人ダビデの命令に従って、組ごとに賛美と感謝をささげた。</span>
<span className="v" id="v25" data-v="25" data-xref="歴代誌上 26:15; ネヘミヤ記 12:8–9; 歴代誌上 26:12"> マタヌヤ、バクブクヤ、オバデヤ、メシュラム、タルモン、アクブは門衛で、門にある倉を見張っていた。</span>
<span className="v" id="v26" data-v="26" data-xref="ネヘミヤ記 8:9; エズラ記 7:6; エズラ記 7:11"> これらの者は、エホツァダクの子エシュアの子ヨヤキムの時代、また総督ネヘミヤと、祭司であり書記官であるエズラの時代にいた。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歴代誌上 15:16; 歴代誌上 15:28; 歴代誌 第二 29:30"> エルサレムの城壁の奉献式にあたり、彼らは各地からレビ人を捜し出してエルサレムへ連れて来た。感謝と歌、シンバル、弦楽器、竪琴をもって、喜びのうちに奉献式を行うためであった。</span>
<span className="v" id="v28" data-v="28" data-xref="歴代誌上 9:16; 歴代誌上 2:54; ネヘミヤ記 6:2"> 歌うたいたちの子らは、エルサレム周辺の平地とネトファ人の村々から集まった。</span>
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 10:43; 歴代誌上 6:60; エズラ記 2:24"> またベテ・ギルガルから、そしてゲバとアズマベテの畑からも集まった。歌うたいたちはエルサレムの周囲に自分たちのための村々を建てていたからである。</span>
<span className="v" id="v30" data-v="30" data-xref="ヨブ記 1:5; 出エジプト記 19:10; 歴代誌 第二 29:5"> 祭司とレビ人は自らをきよめ、民、門、城壁をもきよめた。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="ネヘミヤ記 2:13; ネヘミヤ記 12:38; 歴代誌上 13:1"> それから私はユダの指導者たちを城壁の上に上らせ、感謝をささげながら行進する二つの大きな隊を任命した。一隊は城壁の上を右へ進み、糞の門に向かった。</span>
<span className="v" id="v32" data-v="32"> 彼らの後にはホシャヤと、ユダの指導者たちの半数が続いた。</span>
<span className="v" id="v33" data-v="33" data-xref="ネヘミヤ記 10:2–7"> またアザルヤ、エズラ、メシュラム、</span>
<span className="v" id="v34" data-v="34"> ユダ、ベニヤミン、シェマヤ、エレミヤもいた。</span>
<span className="v" id="v35" data-v="35" data-xref="ヨシュア記 6:4; 民数記 10:2–10; 歴代誌 第二 5:12"> 祭司の子らの何人かはラッパを持っていた。すなわち、アサフの子ザクルの子ミカヤの子マタヌヤの子シェマヤの子ヨナタンの子ゼカリヤ、</span>
<span className="v" id="v36" data-v="36" data-xref="ネヘミヤ記 12:24; 歴代誌 第二 8:14; 歴代誌上 23:5"> および彼の兄弟シェマヤ、アザルエル、ミラライ、ギラライ、マアイ、ネタンエル、ユダ、ハナニである。彼らは神の人ダビデの楽器を持ち、書記エズラが先頭に立った。</span>
<span className="v" id="v37" data-v="37" data-xref="ネヘミヤ記 3:26; ネヘミヤ記 2:14; ネヘミヤ記 8:3"> 泉の門のところで、彼らはまっすぐダビデの町の階段を上り、城壁の上り口からダビデの家の上をとおり、東の水の門まで進んだ。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="ネヘミヤ記 3:8; ネヘミヤ記 3:11; ネヘミヤ記 12:31"> 感謝をささげるもう一つの隊は、彼らに向かって進み、私は民の半数とともにその後に従った。城壁の上を、かまどのやぐらの上から広い城壁まで進み、</span>
<span className="v" id="v39" data-v="39" data-xref="ネヘミヤ記 3:1; ネヘミヤ記 3:3; ネヘミヤ記 8:16"> エフライムの門の上、古い門、魚の門、ハナネルのやぐら、ハメアのやぐらをとおり、羊の門まで進んだ。そして監視の門で立ち止まった。</span>
<span className="v" id="v40" data-v="40" data-xref="詩篇 42:4; 詩篇 134:1–3; ネヘミヤ記 12:31–32"> こうして、感謝をささげる二つの隊は神の家に立ち、私も、私とともにいた役人たちの半数もそこに立った。</span>
<span className="v" id="v41" data-v="41"> 祭司であるエリアキム、マアセヤ、ミンヤミン、ミカヤ、エリョエナイ、ゼカリヤ、ハナニヤはラッパを持ち、</span>
<span className="v" id="v42" data-v="42" data-xref="詩篇 81:1; ネヘミヤ記 11:14; 詩篇 100:1–2"> また、マアセヤ、シェマヤ、エレアザル、ウジ、エホハナン、マルキヤ、エラム、エゼルもいた。歌うたいたちは、指揮者イズラフヤのもとで声高く歌った。</span>
<span className="v" id="v43" data-v="43" data-xref="エズラ記 3:13; 詩篇 92:4; エレミヤ書 31:13"> その日、彼らは大きないけにえをささげて喜んだ。神が彼らに大きな喜びを与えられたからである。女たちも子どもたちも喜び、エルサレムの喜びの声は遠くまで聞こえた。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="ネヘミヤ記 13:12–13; ネヘミヤ記 10:37–39; 歴代誌 第二 31:11–13"> その日、宝物、奉納物、初穂、十分の一を納める部屋を管理する者たちが任命された。律法によって祭司とレビ人に定められた分を、町々の畑からその部屋へ集めるためであった。ユダの人々は、務めに就く祭司とレビ人を喜んでいた。</span>
<span className="v" id="v45" data-v="45" data-xref="歴代誌上 25:1–26; 歴代誌 第二 23:6; 歴代誌上 23:28"> 彼らは神への務めと、きよめの務めを守った。歌うたいと門衛も、ダビデとその子ソロモンの命令に従って務めを守った。</span>
<span className="v" id="v46" data-v="46" data-xref="歴代誌 第二 29:30; 詩篇 73:1; 歴代誌上 25:1–31"> 昔、ダビデとアサフの時代には、歌うたいたちの長がおり、神への賛美と感謝の歌があった。</span>
<span className="v" id="v47" data-v="47" data-xref="民数記 18:21–29; ネヘミヤ記 12:26; ネヘミヤ記 13:10–12"> ゼルバベルの時代とネヘミヤの時代に、全イスラエルは歌うたいと門衛に、日ごとに必要な分を与えた。またレビ人の分を聖別し、レビ人はアロンの子らの分を聖別した。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="イザヤ書 48:2; イザヤ書 52:1; ネヘミヤ記 11:18"> 民の指導者たちはエルサレムに住んだ。残りの民はくじを引き、十人に一人を聖なる町エルサレムに住ませ、残る九人をほかの町々に住ませた。</span>
<span className="v" id="v2" data-v="2" data-xref="士師記 5:9; コリント人への第二の手紙 8:16–17; ヨブ記 29:13"> 民は、自ら進んでエルサレムに住もうとしたすべての人を祝福した。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="エズラ記 2:1; エズラ記 2:43; 歴代誌上 9:1–34"> エルサレムに住んだ州の長たちは次のとおりである。一方、ユダの町々では、イスラエル人、祭司、レビ人、宮のしもべたち、ソロモンのしもべたちの子らが、それぞれ自分の町の所有地に住んだ。</span>
<span className="v" id="v4" data-v="4" data-xref="創世記 38:29; マタイ 1:3; ルカ 3:33"> エルサレムには、ユダの子らとベニヤミンの子らの一部が住んだ。ユダの子らのうちでは、ペレツの子孫であるマハラレルの子シェファテヤの子アマルヤの子ゼカリヤの子ウジヤの子アタヤ、</span>
<span className="v" id="v5" data-v="5" data-xref="歴代誌上 9:5; ネヘミヤ記 3:15; 民数記 26:20"> また、シロ人の子孫であるゼカリヤの子ヨヤリブの子アダヤの子ハザヤの子コル・ホゼの子バルクの子マアセヤ。</span>
<span className="v" id="v6" data-v="6"> エルサレムに住んだペレツの子らは、合わせて四百六十八人の勇士であった。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歴代誌上 9:7–9"> ベニヤミンの子らは次のとおりである。エシャヤの子イティエルの子マアセヤの子コラヤの子ペダヤの子ヨエドの子メシュラムの子サル、</span>
<span className="v" id="v8" data-v="8"> その後にガバイとサライ。合わせて九百二十八人。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代誌上 9:7"> ジクリの子ヨエルが彼らの監督であり、ハセヌアの子ユダが町の副責任者であった。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="歴代誌上 9:10; ネヘミヤ記 12:6; ネヘミヤ記 12:19"> 祭司のうちでは、ヨヤリブの子エダヤ、ヤキン、</span>
<span className="v" id="v11" data-v="11" data-xref="歴代誌上 9:11; 歴代誌上 6:7–14; 民数記 3:32"> アヒトブの子メライオテの子ザドクの子メシュラムの子ヒルキヤの子セラヤ。彼は神の家の長であった。</span>
<span className="v" id="v12" data-v="12" data-xref="歴代誌上 9:12–13"> また、神の家の務めを行った彼らの兄弟たち、八百二十二人。さらに、マルキヤの子パシュフルの子ゼカリヤの子アムジの子ペラルヤの子エロハムの子アダヤ、</span>
<span className="v" id="v13" data-v="13"> および父の家の長である彼の兄弟たち、二百四十二人。また、イムルの子メシレモテの子アフザイの子アザルエルの子アマシャイ、</span>
<span className="v" id="v14" data-v="14"> およびその兄弟である力ある勇士たち、百二十八人。ハゲドリムの子ザブディエルが彼らの監督であった。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="歴代誌上 9:14; 歴代誌上 9:19"> レビ人のうちでは、ブニの子ハシャビヤの子アズリカムの子ハシュブの子シェマヤ。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒の働き 6:2–3; ネヘミヤ記 8:7; エズラ記 8:33"> また、レビ人の長たちのうち、神の家の外務を監督したシャベタイとヨザバド。</span>
<span className="v" id="v17" data-v="17" data-xref="歴代誌上 9:15; 歴代誌上 25:1–6; ネヘミヤ記 12:8–9"> また、アサフの子ザブディの子ミカの子マタヌヤ。彼は祈りで感謝を唱える際の先導者であった。さらに、兄弟たちの中で第二の者バクブクヤと、エドトンの子ガラルの子シャムアの子アブダがいた。</span>
<span className="v" id="v18" data-v="18" data-xref="ネヘミヤ記 11:1; ヨハネの黙示録 21:2; ダニエル書 9:24"> 聖なる町にいたレビ人は、合わせて二百八十四人であった。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="ネヘミヤ記 7:45; 歴代誌上 9:17–22; 詩篇 84:10"> 門衛は、アクブ、タルモン、および門で見張りをした彼らの兄弟たち、百七十二人。</span>
<span className="v" id="v20" data-v="20" data-xref="ネヘミヤ記 11:3"> 残りのイスラエル人、祭司、レビ人は、ユダのすべての町々で、それぞれ自分の相続地に住んだ。</span>
<span className="v" id="v21" data-v="21" data-xref="ネヘミヤ記 3:26; 歴代誌 第二 27:3; ネヘミヤ記 3:31"> 宮のしもべたちはオフェルに住み、ツィハとギシュパが宮のしもべたちを監督していた。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="ネヘミヤ記 12:42; 歴代誌上 25:1–6; エズラ記 8:19"> エルサレムにおけるレビ人の監督は、バニの子ウジであった。ウジはハシャビヤの子、ハシャビヤはマタヌヤの子、マタヌヤはミカの子であり、神の家の奉仕を担うアサフの子孫の歌うたいたちに属していた。</span>
<span className="v" id="v23" data-v="23" data-xref="エズラ記 7:20–24; ネヘミヤ記 12:47; エズラ記 6:8–9"> 歌うたいたちについては王の命令があり、日ごとに定められた分が与えられていた。</span>
<span className="v" id="v24" data-v="24" data-xref="創世記 38:30; 歴代誌上 18:17; 歴代誌上 23:28"> ユダの子ゼラの子孫、メシェザベルの子ペタフヤは、民に関するすべての事柄について王のもとで取り次ぐ者であった。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="ヨシュア記 14:15; ヨシュア記 15:21–22"> 畑のある村々について言えば、ユダの子らの一部は、キルヤテ・アルバとその周辺の町、ディボンとその周辺の町、エカブツェエルとその村々、</span>
<span className="v" id="v26" data-v="26" data-xref="ヨシュア記 15:26–27; ヨシュア記 19:2"> エシュア、モラダ、ベテ・ペレト、</span>
<span className="v" id="v27" data-v="27" data-xref="創世記 26:33; ヨシュア記 15:28; 士師記 20:1"> ハツァル・シュアル、ベエル・シェバとその村々、</span>
<span className="v" id="v28" data-v="28" data-xref="サムエル記第一 27:6; ヨシュア記 15:31"> ツィクラグ、メコナとその村々、</span>
<span className="v" id="v29" data-v="29" data-xref="ヨシュア記 19:41; ヨシュア記 15:32–33; ヨシュア記 15:35"> エン・リンモン、ツォルア、ヤルムテ、</span>
<span className="v" id="v30" data-v="30" data-xref="ヨシュア記 10:3; ヨシュア記 15:8; ヨシュア記 18:16"> ザノア、アデュラムとその村々、ラキシュとその畑、アゼカとその周辺の町に住んだ。こうして彼らはベエル・シェバからヒンノムの谷まで居住した。</span>
<span className="v" id="v31" data-v="31" data-xref="創世記 12:8; ヨシュア記 8:9; ヨシュア記 18:13"> ベニヤミンの子らも、ゲバから先、ミクマス、アヤ、ベテルとその周辺の町、</span>
<span className="v" id="v32" data-v="32" data-xref="ヨシュア記 21:18; イザヤ書 10:30; サムエル記第一 21:1"> アナトテ、ノブ、アナニヤ、</span>
<span className="v" id="v33" data-v="33" data-xref="サムエル記第二 4:3; サムエル記第一 7:17; ヨシュア記 18:25"> ハツォル、ラマ、ギタイム、</span>
<span className="v" id="v34" data-v="34" data-xref="サムエル記第一 13:18"> ハディド、ツェボイム、ネバラテ、</span>
<span className="v" id="v35" data-v="35" data-xref="歴代誌上 8:12; ネヘミヤ記 7:37; 歴代誌上 4:14"> ロド、オノ、職人の谷に住んだ。</span>
<span className="v" id="v36" data-v="36" data-xref="ヨシュア記 21:1–45; 創世記 49:7; 歴代誌上 6:54–81"> レビ人のうち、ユダにいたいくつかの組は、ベニヤミンの地に住んだ。</span>
</div>

<span className="v" id="v2" data-v="2" data-xref="詩篇 101:6; ネヘミヤ記 1:2; マタイ 25:21"> 私は兄弟ハナニと、要塞の長官ハナニヤに、エルサレムの管理を任せた。ハナニヤは忠実な人で、人一倍神を恐れていたからである。</span>
<span className="v" id="v3" data-v="3" data-xref="ネヘミヤ記 3:28–30; 詩篇 127:1; ネヘミヤ記 3:23"> 私は彼らに言った。「日が高くなるまでは、エルサレムの門を開けてはならない。門衛が持ち場にいるうちに扉を閉じ、かんぬきを掛けよ。また、エルサレムの住民から見張りを任命し、それぞれを持ち場に就かせ、自分の家の近くを守らせよ。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="イザヤ書 58:12; マタイ 6:33; ハガイ書 1:4–6"> 町は広く大きかったが、その中に住む民は少なく、家々もまだ建てられていなかった。</span>
</div>
<div className="bp">

</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="エズラ記 5:8; エズラ記 2:1–70; エレミヤ書 52:1–34"> 州の人々のうち、バビロンの王ネブカドネザルによって捕らえ移され、その後そこから上って来て、エルサレムとユダのそれぞれ自分の町へ帰った者たちは次のとおりである。</span>
<span className="v" id="v7" data-v="7" data-xref="エズラ記 2:2; ハガイ書 1:1; ゼカリヤ書 3:1–3"> 彼らはゼルバベル、エシュア、ネヘミヤ、アザルヤ、ラアミヤ、ナハマニ、モルデカイ、ビルシャン、ミスペレテ、ビグワイ、ネフム、バアナとともに来た。<br />イスラエルの民の男たちの数：</span>
<span className="v" id="v8" data-v="8" data-xref="エズラ記 2:3; エズラ記 8:3; ネヘミヤ記 10:14"> パロシュの子ら、二千百七十二人。</span>
<span className="v" id="v9" data-v="9" data-xref="エズラ記 2:4; エズラ記 8:8"> シェファテヤの子ら、三百七十二人。</span>

<span className="v" id="v12" data-v="12" data-xref="エズラ記 10:26; エズラ記 2:7; エズラ記 8:7"> エラムの子ら、千二百五十四人。</span>
<span className="v" id="v13" data-v="13" data-xref="エズラ記 2:8"> ザトの子ら、八百四十五人。</span>
<span className="v" id="v14" data-v="14" data-xref="エズラ記 2:9"> ザッカイの子ら、七百六十人。</span>
<span className="v" id="v15" data-v="15" data-xref="エズラ記 2:10"> ビヌイの子ら、六百四十八人。</span>
<span className="v" id="v16" data-v="16" data-xref="エズラ記 2:11"> ベバイの子ら、六百二十八人。</span>
<span className="v" id="v17" data-v="17" data-xref="エズラ記 2:12"> アズガドの子ら、二千三百二十二人。</span>
<span className="v" id="v18" data-v="18" data-xref="エズラ記 2:13"> アドニカムの子ら、六百六十七人。</span>

<span className="v" id="v21" data-v="21" data-xref="エズラ記 2:16"> アテルの子ら、すなわちヒゼキヤの家系、九十八人。</span>

<span className="v" id="v27" data-v="27" data-xref="エレミヤ書 11:21; イザヤ書 10:30; エズラ記 2:23"> アナトテの人々、百二十八人。</span>

<span className="v" id="v30" data-v="30" data-xref="ヨシュア記 18:24–25; エズラ記 2:26"> ラマとゲバの人々、六百二十一人。</span>

<span className="v" id="v32" data-v="32" data-xref="エズラ記 2:28; ヨシュア記 8:9; ヨシュア記 8:17"> ベテルとアイの人々、百二十三人。</span>
<span className="v" id="v33" data-v="33" data-xref="エズラ記 2:29"> もう一つのネボの人々、五十二人。</span>
<span className="v" id="v34" data-v="34" data-xref="ネヘミヤ記 7:12; エズラ記 2:31"> もう一つのエラムの子ら、千二百五十四人。</span>

</div>
<div className="bp">

</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="エズラ記 2:43; レビ記 27:2–8; ヨシュア記 9:23–27"> 宮のしもべたち：ツィハの子ら、ハスファの子ら、タバオテの子ら、</span>
<span className="v" id="v47" data-v="47" data-xref="エズラ記 2:44"> ケロスの子ら、シアの子ら、パドンの子ら、</span>
<span className="v" id="v48" data-v="48" data-xref="エズラ記 2:45–46"> レバナの子ら、ハガバの子ら、サルマイの子ら、</span>
<span className="v" id="v49" data-v="49"> ハナンの子ら、ギデルの子ら、ガハルの子ら、</span>
<span className="v" id="v50" data-v="50"> レアヤの子ら、レツィンの子ら、ネコダの子ら、</span>
<span className="v" id="v51" data-v="51" data-xref="エズラ記 2:49"> ガザムの子ら、ウザの子ら、パセアの子ら、</span>
<span className="v" id="v52" data-v="52" data-xref="エズラ記 2:50"> ベサイの子ら、メウニムの子ら、ネフシェシムの子ら、</span>
<span className="v" id="v53" data-v="53"> バクブクの子ら、ハクファの子ら、ハルフルの子ら、</span>
<span className="v" id="v54" data-v="54" data-xref="エズラ記 2:52"> バツリテの子ら、メヒダの子ら、ハルシャの子ら、</span>
<span className="v" id="v55" data-v="55" data-xref="エズラ記 2:53"> バルコスの子ら、シセラの子ら、テマの子ら、</span>
<span className="v" id="v56" data-v="56"> ネツィアの子ら、ハティファの子ら。</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="エズラ記 2:55; ネヘミヤ記 11:3"> ソロモンのしもべたちの子ら：ソタイの子ら、ソフェレテの子ら、ペリダの子ら、</span>
<span className="v" id="v58" data-v="58" data-xref="エズラ記 2:56"> ヤアラの子ら、ダルコンの子ら、ギデルの子ら、</span>
<span className="v" id="v59" data-v="59" data-xref="エズラ記 2:57"> シェファテヤの子ら、ハティルの子ら、ポケレテ・ハツェバイムの子ら、アモンの子ら。</span>
<span className="v" id="v60" data-v="60" data-xref="エズラ記 2:58"> 宮のしもべたちとソロモンのしもべたちの子らは、合わせて三百九十二人であった。</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61" data-xref="エズラ記 2:59"> テル・メラ、テル・ハルシャ、ケルブ、アドン、イムルから上って来た者たちは次のとおりである。しかし彼らは、自分たちの父の家と血筋<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="または「種」。">a</a></sup>がイスラエルに属することを示せなかった。</span>
<span className="v" id="v62" data-v="62" data-xref="エズラ記 2:60"> デラヤの子ら、トビヤの子ら、ネコダの子ら、六百四十二人。</span>
<span className="v" id="v63" data-v="63" data-xref="エズラ記 2:61–63; 列王記第一 2:7; サムエル記第二 17:27"> 祭司のうちでは、ホバヤの子ら、ハコツの子ら、バルジライの子ら。このバルジライは、ギルアデ人バルジライの娘の一人を妻に迎え、その家の名で呼ばれるようになった。</span>
</div>
<div className="bp">
<span className="v" id="v64" data-v="64" data-xref="歴代誌上 9:1; ネヘミヤ記 7:5; ネヘミヤ記 13:29"> これらの者は系図の記録を探したが、見つからなかった。そのため資格がないとされ、祭司の務めから退けられた。</span>
<span className="v" id="v65" data-v="65" data-xref="出エジプト記 28:30; ネヘミヤ記 8:9; ネヘミヤ記 10:1"> 総督は彼らに、ウリムとトンミムを用いて仕える祭司が立つまで、最も聖なるものを食べてはならないと告げた。</span>
</div>
<div className="bp">
<span className="v" id="v66" data-v="66" data-xref="エズラ記 2:64"> 会衆は皆合わせて四万二千三百六十人であった。</span>
<span className="v" id="v67" data-v="67" data-xref="エズラ記 2:65; イザヤ書 45:1–2; エレミヤ書 27:7"> このほかに、男女の奴隷が七千三百三十七人おり、歌う男と女が二百四十五人いた。</span>
<span className="v" id="v68" data-v="68" data-xref="エズラ記 2:66–67"> 馬は七百三十六頭、騾馬は二百四十五頭、</span>
<span className="v" id="v69" data-v="69"> らくだは四百三十五頭、ろばは六千七百二十頭であった。</span>
</div>
<div className="bp">
<span className="v" id="v70" data-v="70" data-xref="ネヘミヤ記 8:9; 民数記 7:2–86; 出エジプト記 12:22"> 父の家の長たちのうち、工事のためにささげる者がいた。総督は宝物倉に、金一千ダリク<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="ダリクはペルシア王が発行した金貨で、一枚約8.4グラム、または約0.27トロイオンスである。">b</a></sup>、鉢五十個、祭司の衣服五百三十着をささげた。</span>
<span className="v" id="v71" data-v="71" data-xref="コリント人への第二の手紙 8:12; ルカ 21:1–4; ヨブ記 34:19"> 父の家の長たちのうち、工事の宝物倉に金二万ダリクと、銀二千二百ミナ<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一ミナは約600グラム、または約1.3ポンドである。二千二百ミナは約1.3トンである。">c</a></sup>をささげる者たちがいた。</span>

<span className="v" id="v73" data-v="73" data-xref="エズラ記 2:70–1"> こうして、祭司、レビ人、門衛、歌うたい、民の一部、宮のしもべたち、および全イスラエルは、それぞれ自分の町に住んだ。<br />第七の月になると、イスラエルの子らは自分たちの町々にいた。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命記 23:3–5; ネヘミヤ記 9:3; ネヘミヤ記 13:23"> その日、民の聞くところでモーセの書が読まれ、その中に、アンモン人とモアブ人は永遠に神の会衆に加わってはならないと書かれているのが見つかった。</span>
<span className="v" id="v2" data-v="2" data-xref="申命記 23:5; ヨシュア記 24:9–10; 民数記 23:8–11"> 彼らがパンと水をもってイスラエルの子らを迎えず、バラムを雇って彼らをのろわせようとしたからである。しかし、私たちの神はそののろいを祝福に変えられた。</span>
<span className="v" id="v3" data-v="3" data-xref="ネヘミヤ記 9:2; 出エジプト記 12:38; 民数記 11:4"> 民は律法を聞くと、入り混じった者たちをすべてイスラエルから分けた。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="ネヘミヤ記 12:44; ネヘミヤ記 6:17–18; ネヘミヤ記 13:28"> これより前、私たちの神の家の部屋を管理していた祭司エリアシブは、トビヤと縁戚関係にあり、</span>
<span className="v" id="v5" data-v="5" data-xref="ネヘミヤ記 12:44; 歴代誌 第二 34:11; 民数記 18:21–24"> 彼のために大きな部屋を用意していた。そこには以前、穀物のささげ物、乳香、器、また命令によってレビ人、歌うたい、門衛に与えられる穀物、新しいぶどう酒、油の十分の一と、祭司たちへの奉納物が置かれていた。</span>
<span className="v" id="v6" data-v="6" data-xref="ネヘミヤ記 5:14; ネヘミヤ記 2:5–6; マタイ 13:25"> この間、私はエルサレムにいなかった。バビロンの王アルタクセルクセスの第三十二年に、王のもとへ行っていたからである。しばらくして王に暇を願い、</span>
<span className="v" id="v7" data-v="7" data-xref="ネヘミヤ記 13:5; マタイ 21:12–13; 哀歌 1:10"> エルサレムに戻った。そして、エリアシブがトビヤのために神の家の庭に部屋を用意した悪事を知った。</span>
<span className="v" id="v8" data-v="8" data-xref="マルコ 11:15–17; エズラ記 10:1; 詩篇 69:9"> 私はひどく心を痛め、トビヤの家財道具をすべて部屋の外へ投げ出した。</span>
<span className="v" id="v9" data-v="9" data-xref="歴代誌 第二 29:5; 歴代誌 第二 29:15–19; ネヘミヤ記 12:45"> 私は命じて部屋をきよめさせ、神の家の器、穀物のささげ物、乳香を再びそこへ戻した。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="ネヘミヤ記 10:37; マラキ書 3:8; マラキ書 1:6–14"> また私は、レビ人の分が与えられていなかったため、務めに就いていたレビ人と歌うたいが、それぞれ自分の畑へ帰ってしまったことを知った。</span>
<span className="v" id="v11" data-v="11" data-xref="ネヘミヤ記 10:39; ネヘミヤ記 13:17; ネヘミヤ記 13:25"> そこで私は役人たちを責めて言った。「なぜ神の家が見捨てられているのか。」私は彼らを集め、元の持ち場に就かせた。</span>
<span className="v" id="v12" data-v="12" data-xref="ネヘミヤ記 10:37–39; マラキ書 3:10; ネヘミヤ記 12:44"> すると全ユダが、穀物、新しいぶどう酒、油の十分の一を宝物倉に持って来た。</span>
<span className="v" id="v13" data-v="13" data-xref="列王記第二 22:7; ネヘミヤ記 7:2; ネヘミヤ記 12:44"> 私は宝物倉の管理者に、祭司シェレミヤ、書記ツァドク、レビ人ペダヤを任命し、その補佐にマタヌヤの子ザクルの子ハナンを置いた。彼らは忠実であると認められており、兄弟たちに分配するのがその務めであった。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="詩篇 122:6–9; ネヘミヤ記 13:22; ネヘミヤ記 13:31"> 私の神よ、このことについて私を覚え、私の神の家とその務めのために行った慈しみの業を、ぬぐい去らないでください。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="ネヘミヤ記 10:31; ネヘミヤ記 13:21; 出エジプト記 34:21"> そのころ私はユダで、安息日にぶどう搾り場を踏む者、穀物の束を運び、ろばに積む者を見た。また彼らは、ぶどう酒、ぶどう、いちじく、あらゆる荷を安息日にエルサレムへ運び込んでいた。私は、彼らが食物を売っていたその日に警告した。</span>
<span className="v" id="v16" data-v="16" data-xref="出エジプト記 23:12; 申命記 5:14"> そこにはツロの人々も住んでおり、魚やあらゆる品物を持ち込み、安息日にエルサレムでユダの子らに売っていた。</span>
<span className="v" id="v17" data-v="17" data-xref="ネヘミヤ記 13:11; ネヘミヤ記 13:25; イザヤ書 1:10"> そこで私はユダの貴族たちを責めて言った。「安息日を汚すとは、あなたがたのしているこの悪事は何か。</span>
<span className="v" id="v18" data-v="18" data-xref="エレミヤ書 17:21–23; エレミヤ書 44:9; 民数記 32:14"> あなたがたの先祖もこのように行い、私たちの神は、このすべての災いを私たちとこの町にもたらされたではないか。それなのに、あなたがたは安息日を汚し、イスラエルに対する御怒りをさらに増している。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="レビ記 23:32; 出エジプト記 31:14–17; エレミヤ書 17:19–22"> 安息日に先立ち、エルサレムの門に影が落ち始めると、私は扉を閉じるよう命じ、安息日が終わるまで開けてはならないと命じた。また、しもべの何人かを門に配置し、安息日に荷が運び込まれないようにした。</span>
<span className="v" id="v20" data-v="20"> そのため、商人やあらゆる品物を売る者たちは、一度か二度、エルサレムの外で夜を過ごした。</span>
<span className="v" id="v21" data-v="21" data-xref="ローマ人への手紙 13:3–4; ペテロの手紙第一 2:14; エズラ記 7:26"> 私は彼らに警告して言った。「なぜ城壁の前で夜を過ごすのか。もう一度するなら、力ずくで追い払う。」そのとき以来、彼らは安息日には来なくなった。</span>
<span className="v" id="v22" data-v="22" data-xref="ネヘミヤ記 12:30; ネヘミヤ記 13:14; ネヘミヤ記 13:31"> 私はレビ人に、自らをきよめ、来て門を守り、安息日を聖なるものとするよう命じた。私の神よ、このことについても私を覚え、あなたの大いなる慈しみによって、私をあわれんでください。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="エズラ記 9:1–2; エズラ記 10:10; ネヘミヤ記 10:30"> そのころまた、私はアシュドド人、アンモン人、モアブ人の女を妻に迎えたユダヤ人たちを見た。</span>
<span className="v" id="v24" data-v="24" data-xref="ゼパニヤ書 3:9"> その子どもたちは半分ほどアシュドドの言葉を話し、ユダヤ人の言葉を話せず、それぞれの民の言葉を話していた。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 7:3; ネヘミヤ記 13:17; ネヘミヤ記 10:29–30"> 私は彼らを責め、のろい、何人かを打ち、その髪を引き抜いた。そして神にかけて誓わせて言った。「あなたがたの娘を彼らの息子に与えてはならない。あなたがたの息子のためにも、自分自身のためにも、彼らの娘を迎えてはならない。</span>
<span className="v" id="v26" data-v="26" data-xref="列王記第一 11:1–8; 列王記第一 3:13; 伝道者の書 7:26"> イスラエルの王ソロモンは、これらのことによって罪を犯したのではないか。多くの国々の中に彼のような王はおらず、彼は神に愛され、神は彼を全イスラエルの王とされた。それでも異国の女たちは、彼にさえ罪を犯させた。</span>
<span className="v" id="v27" data-v="27" data-xref="エズラ記 10:2; サムエル記第一 30:24"> それなのに、あなたがたが異国の女を妻に迎え、私たちの神に背いて、この大きな悪を行うのを、私たちが聞き入れてよいだろうか。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="ネヘミヤ記 2:19; ネヘミヤ記 3:1; ネヘミヤ記 12:22"> 大祭司エリアシブの子ヨヤダの息子の一人は、ホロニ人サンバラテの婿であった。そのため私は彼を追い払った。</span>
<span className="v" id="v29" data-v="29" data-xref="ネヘミヤ記 6:14; 民数記 25:12–13; マラキ書 2:4–8"> 私の神よ、彼らを覚えてください。彼らは祭司の職と、祭司およびレビ人の契約を汚した。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="ネヘミヤ記 10:30; ネヘミヤ記 12:1–26; 歴代誌上 23:1–26"> こうして私は、異国人との関わりをすべて取り除いて彼らをきよめ、祭司とレビ人に、それぞれの務めを定めた。</span>
<span className="v" id="v31" data-v="31" data-xref="ネヘミヤ記 13:14; ネヘミヤ記 13:22; 詩篇 106:4"> また、定められた時期に薪のささげ物と初穂を持って来るようにした。私の神よ、どうか私を覚え、恵みを施してください。</span>
</div>
</div>

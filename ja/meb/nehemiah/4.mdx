<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="ネヘミヤ記 2:10; ヘブル人への手紙 11:36; 詩篇 35:15–16"> サンバラテは、私たちが城壁を建てていると聞くと怒り、激しく憤って、ユダヤ人を嘲笑した。</span>
<span className="v" id="v2" data-v="2" data-xref="エズラ記 4:9–10; コリント人への第一の手紙 1:27; エゼキエル書 37:3–13"> 彼は仲間とサマリアの軍隊の前で言った。「あの弱々しいユダヤ人たちは何をしているのか。自分たちで防備を整えるつもりか。いけにえをささげるつもりか。一日で仕上げるつもりか。焼けた瓦礫の山から石を生き返らせるつもりか。」</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="ネヘミヤ記 2:19; 列王記第一 20:10; ネヘミヤ記 2:10"> アモン人トビヤが彼のそばにいて言った。「彼らが建てているものは、狐が上っても、その石垣を崩してしまうだろう。」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="詩篇 79:12; 詩篇 123:3–4; 箴言 3:34"> 「私たちの神よ、耳を傾けてください。私たちは侮られています。彼らのそしりを彼ら自身の頭に返し、捕囚の地で略奪に渡してください。</span>
<span className="v" id="v5" data-v="5" data-xref="詩篇 109:14; エレミヤ書 18:23; 詩篇 69:27–28"> 彼らの咎を覆わず、その罪を御前からぬぐい去らないでください。彼らは建てる者たちを侮辱したのです。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="ピリピ人への手紙 2:13; ネヘミヤ記 6:15; ヘブル人への手紙 13:21"> こうして私たちは城壁を建てた。城壁全体は高さの半分までつながった。民には働く意欲があったからである。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="ネヘミヤ記 2:10; ネヘミヤ記 4:1; 使徒の働き 5:33"> しかし、サンバラテ、トビヤ、アラビア人、アモン人、アシュドド人たちは、エルサレムの城壁の修復が進み、破れ口がふさがれ始めたと聞いて、非常に怒った。</span>
<span className="v" id="v8" data-v="8" data-xref="詩篇 83:3–11; イザヤ書 8:9–10; エレミヤ書 20:10"> そして彼らは皆、エルサレムに来て戦い、私たちの間に混乱を引き起こそうと共謀した。</span>
<span className="v" id="v9" data-v="9" data-xref="ペテロの手紙第一 5:8; 使徒の働き 4:24–30; 詩篇 50:15"> しかし私たちは神に祈り、彼らに備えて昼も夜も見張りを立てた。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="詩篇 11:1–2; ハガイ書 1:2; 歴代誌 第二 2:18"> ユダの人々は言った。「荷を担う者の力は衰え、瓦礫は多い。これでは城壁を建て続けられない。」</span>
<span className="v" id="v11" data-v="11" data-xref="テサロニケ人への手紙第一 5:2; 使徒の働き 23:12; 詩篇 56:6"> 敵は言った。「彼らが気づきも見もしないうちに、その中へ入り込み、彼らを殺して工事をやめさせよう。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="創世記 31:7; 創世記 31:41; 民数記 14:22"> 敵の近くに住むユダヤ人たちが来て、あらゆる方角から十回も、「どこへ向かっても、彼らは私たちを襲って来ます」と告げた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="ネヘミヤ記 4:17–18; エペソ人への手紙 6:11–20; 雅歌 3:7–8"> そこで私は、城壁の後ろの低い場所、開けた所に、民を家族ごとに配置し、剣、槍、弓を持たせた。</span>
<span className="v" id="v14" data-v="14" data-xref="サムエル記第二 10:12; 民数記 14:9; イザヤ書 41:10–14"> 私は見渡し、立ち上がって、貴族、役人、その他の民に言った。「彼らを恐れてはならない。偉大で恐るべき主を覚え、兄弟、息子、娘、妻、家のために戦え。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="サムエル記第二 17:14; ローマ人への手紙 12:11; ヨブ記 5:12–13"> 私たちの敵は、それが私たちに知られたこと、そして神が彼らの企てを無に帰されたことを聞いた。こうして私たちは皆、城壁に戻り、それぞれ自分の仕事についた。</span>
<span className="v" id="v16" data-v="16" data-xref="ネヘミヤ記 4:23; 詩篇 101:6; ネヘミヤ記 5:15–16"> そのとき以来、私のしもべの半数は工事をし、半数は槍、盾、弓、鎧を手にした。指揮官たちはユダの民全体の背後に控えた。</span>
<span className="v" id="v17" data-v="17" data-xref="コリント人への第二の手紙 6:7; テモテへの第二の手紙 4:7; テモテへの第二の手紙 2:3"> 城壁を建てる者も、荷を担って運ぶ者も、片手で仕事をし、もう一方の手に武器を持った。</span>
<span className="v" id="v18" data-v="18" data-xref="民数記 10:9; 歴代誌 第二 13:12–17"> 建てる者たちは皆、腰に剣を帯びて建てた。角笛を吹き鳴らす者は私のそばにいた。</span>
<span className="v" id="v19" data-v="19"> 私は貴族、役人、その他の民に言った。「工事は大きく、広い範囲に及び、私たちは城壁の上で互いに遠く離れている。</span>
<span className="v" id="v20" data-v="20" data-xref="出エジプト記 14:14; 申命記 1:30; 申命記 20:4"> どこであれ角笛の音を聞いたなら、そこへ、私たちのもとへ集まれ。私たちの神が私たちのために戦ってくださる。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="ガラテヤ人への手紙 6:9; コロサイ人への手紙 1:29; コリント人への第一の手紙 15:58"> こうして私たちは工事を続け、民の半数は夜明けから星が現れるまで槍を手にした。</span>
<span className="v" id="v22" data-v="22" data-xref="ネヘミヤ記 11:1–2"> そのころ私は民に言った。「それぞれ、しもべとともにエルサレムの中に泊まれ。夜は私たちの見張りとなり、昼は働くためである。」</span>
<span className="v" id="v23" data-v="23" data-xref="士師記 9:48; ネヘミヤ記 7:2; コリント人への第一の手紙 15:10"> 私も、兄弟たちも、しもべたちも、私に従う見張りの者たちも、衣服を脱がなかった。水を汲みに行くときも、皆が武器を携えた。</span>
</div>

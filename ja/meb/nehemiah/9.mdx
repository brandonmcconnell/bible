<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒の働き 13:2–3; エズラ記 8:23; ネヘミヤ記 8:2"> この月の第二十四日に、イスラエルの子らは断食し、荒布をまとい、土をかぶって集まった。</span>
<span className="v" id="v2" data-v="2" data-xref="ダニエル書 9:3–10; ネヘミヤ記 13:3; エズラ記 10:11"> イスラエルの子孫はすべての異国人から離れ、立って、自分たちの罪と先祖の咎を告白した。</span>
<span className="v" id="v3" data-v="3" data-xref="ネヘミヤ記 8:7–8; ネヘミヤ記 8:3–4"> 彼らはその場に立ち、一日の四分の一は彼らの神、主の律法の書を読み、もう四分の一は罪を告白して、彼らの神、主を礼拝した。</span>
<span className="v" id="v4" data-v="4" data-xref="ネヘミヤ記 8:7; ネヘミヤ記 12:8; ネヘミヤ記 9:5"> レビ人エシュア、バニ、カドミエル、シェバニヤ、ブニ、シェレブヤ、バニ、ケナニは階段の上に立ち、彼らの神、主に大声で叫び求めた。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="詩篇 103:1–2; ペテロの手紙第一 1:3; コリント人への第二の手紙 4:6"> それから、レビ人エシュア、カドミエル、バニ、ハシャブネヤ、シェレブヤ、ホディヤ、シェバニヤ、ペタフヤが言った。「立ち上がり、とこしえからとこしえまで、あなたがたの神、主をほめたたえよ。栄光に満ちたあなたの御名はほめたたえられよ。その御名は、すべての祝福と賛美を超えて高く上げられている。</span>
<span className="v" id="v6" data-v="6" data-xref="イザヤ書 37:16; 創世記 1:1; ヨハネの黙示録 4:11"> あなたこそ主、ただあなただけ。あなたは天と、天の天と、そのすべての万象、地とその上にあるすべてのもの、海とその中にあるすべてのものを造られた。あなたはそれらすべてを生かしておられる。天の万象はあなたを礼拝する。</span>
<span className="v" id="v7" data-v="7" data-xref="創世記 11:31; 創世記 17:5; イザヤ書 51:2"> あなたこそ主なる神。アブラムを選び、カルデヤ人のウルから導き出し、アブラハムという名を与えられた。</span>
<span className="v" id="v8" data-v="8" data-xref="創世記 15:6; 創世記 15:18–21; ヘブル人への手紙 6:18"> あなたは彼の心が御前に忠実であるのを認め、カナン人、ヒッタイト人、アモリ人、ペリジ人、エブス人、ギルガシ人の地を彼の子孫に与えるとの契約を結ばれた。そして御言葉を果たされた。あなたは正しい方だからである。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出エジプト記 3:7–9; 使徒の働き 7:34; 出エジプト記 3:16"> 「あなたはエジプトにいた私たちの先祖の苦しみを見、紅海のほとりで彼らの叫びを聞かれた。</span>
<span className="v" id="v10" data-v="10" data-xref="エレミヤ書 32:20; ダニエル書 9:15; 出エジプト記 18:11"> ファラオと、そのすべてのしもべ、その地のすべての民に対して、しるしと不思議を行われた。彼らが先祖たちに対して高慢に振る舞ったことを知っておられたからである。こうして、今日あるとおり、ご自身の名を高くされた。</span>
<span className="v" id="v11" data-v="11" data-xref="詩篇 78:13; 出エジプト記 14:21–22; 出エジプト記 14:27–28"> あなたは彼らの前で海を分け、彼らは海の中の乾いた地を渡った。追う者たちを、激しい水に投げ込まれる石のように、深みに投げ込まれた。</span>
<span className="v" id="v12" data-v="12" data-xref="出エジプト記 13:21–22; ネヘミヤ記 9:19; 詩篇 107:7"> 昼は雲の柱で彼らを導き、夜は火の柱で、進むべき道を照らされた。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="詩篇 119:160; 出エジプト記 20:1; 詩篇 119:127–128"> 「あなたはシナイ山に下り、天から彼らに語り、正しい定め、真実な律法、良い掟と戒めを与えられた。</span>
<span className="v" id="v14" data-v="14" data-xref="出エジプト記 20:8–11; 創世記 2:3; エゼキエル書 20:12"> 聖なる安息日を知らせ、しもべモーセを通して、戒めと掟と律法を命じられた。</span>
<span className="v" id="v15" data-v="15" data-xref="コリント人への第一の手紙 10:3–4; 申命記 1:8; 出エジプト記 17:6"> 飢えた彼らに天からパンを与え、渇く彼らのために岩から水を出された。また、与えると誓われた地へ入って所有するよう命じられた。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="ネヘミヤ記 9:29; 詩篇 81:11–14; ヘブル人への手紙 3:15"> 「しかし彼ら、すなわち私たちの先祖は高慢に振る舞い、うなじを固くし、あなたの戒めに聞き従わなかった。</span>
<span className="v" id="v17" data-v="17" data-xref="詩篇 86:5; ヨエル書 2:13; 詩篇 145:8–9"> 彼らは従うことを拒み、その間で行われた不思議を心に留めず、うなじを固くし、反逆して、奴隷の身に戻るための指導者を立てた。しかしあなたは、赦しに富む神、恵み深く、あわれみ深く、怒るのに遅く、慈しみに満ちた方。彼らを見捨てられなかった。</span>
<span className="v" id="v18" data-v="18" data-xref="詩篇 106:19–23; 出エジプト記 32:4–8; エゼキエル書 20:7–44"> 彼らが鋳物の子牛を造り、『これが、あなたをエジプトから導き上った神だ』と言い、ひどい冒瀆を重ねたときでさえ、</span>
<span className="v" id="v19" data-v="19" data-xref="詩篇 106:45; ネヘミヤ記 9:27; マラキ書 3:6"> あなたは豊かなあわれみにより、荒野で彼らを見捨てられなかった。昼は雲の柱が彼らの上を離れず、道を導いた。夜は火の柱が離れず、進むべき道を照らした。</span>
<span className="v" id="v20" data-v="20" data-xref="詩篇 143:10; 民数記 11:17; イザヤ書 63:11–14"> 彼らを教えるためにあなたの良き御霊を与え、彼らの口からマナを取り去らず、渇きのために水を与えられた。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命記 2:7; 申命記 8:4; 詩篇 34:10"> 「四十年の間、あなたは荒野で彼らを養われた。彼らには何一つ欠けず、衣はすり切れず、足も腫れなかった。</span>
<span className="v" id="v22" data-v="22" data-xref="民数記 21:21–35; 申命記 3:1–17; 申命記 2:26–36"> さらに、王国と諸国の民を彼らに与え、それぞれの領地として分けられた。彼らはシホンの地、ヘシュボンの王の地と、バシャンの王オグの地を所有した。</span>
<span className="v" id="v23" data-v="23" data-xref="創世記 22:17; 創世記 15:5; 歴代誌上 27:23"> その子らを空の星のように増やし、先祖たちに、入って所有せよと言われた地へ導き入れられた。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="ヨシュア記 21:43; ヨシュア記 11:23; 詩篇 44:2–3"> 「子らは入って地を所有した。あなたはその地の住民カナン人を彼らの前に屈服させ、王たちも地の民も彼らの手に渡し、思いのままに扱わせた。</span>
<span className="v" id="v25" data-v="25" data-xref="申命記 32:15; ネヘミヤ記 9:35; 申命記 3:5"> 彼らは城壁のある町々と肥沃な地を取り、あらゆる良いもので満ちた家、掘られた貯水槽、ぶどう園、オリーブ園、豊かな果樹を所有した。彼らは食べて満ち足り、太り、あなたの大いなる恵みを喜び楽しんだ。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王記第一 14:9; 士師記 2:11–12; ネヘミヤ記 9:18"> 「それでも彼らは不従順となり、あなたに逆らい、律法を背後に投げ捨て、あなたに立ち返らせようと警告した預言者たちを殺し、ひどい冒瀆を重ねた。</span>
<span className="v" id="v27" data-v="27" data-xref="詩篇 106:41–45; 列王記第二 14:27; 列王記第二 13:5"> そこであなたは、彼らを苦しめる敵の手に渡された。苦難のとき、彼らが叫び求めると、あなたは天から聞き、豊かなあわれみによって救う者たちを与え、敵の手から救い出された。</span>
<span className="v" id="v28" data-v="28" data-xref="士師記 5:31–1; 士師記 4:1; 列王記第一 8:39"> しかし安息を得ると、彼らは再び御前に悪を行った。それであなたは彼らを敵の手に任せ、敵に支配させられた。それでも彼らが立ち返って叫び求めると、天から聞き、あわれみによって幾度も救い出された。</span>
<span className="v" id="v29" data-v="29" data-xref="ネヘミヤ記 9:16; レビ記 18:5; ネヘミヤ記 9:26"> 彼らを律法に立ち返らせようと警告された。しかし彼らは高ぶり、戒めに聞き従わず、定めに背いて罪を犯した。人はそれを行うなら、それによって生きるのに。彼らは背を向け、うなじを固くし、聞こうとしなかった。</span>
<span className="v" id="v30" data-v="30" data-xref="ローマ人への手紙 2:4; 歴代誌 第二 36:15–16; イザヤ書 42:24"> 長い年月、あなたは彼らを忍び、預言者たちを通して、あなたの霊によって警告された。それでも彼らは耳を傾けなかった。それゆえ、その地の諸国の民の手に渡された。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="哀歌 3:22; エレミヤ書 4:27; ネヘミヤ記 9:17"> 「それでも、豊かなあわれみによって、彼らを滅ぼし尽くさず、見捨てもされなかった。あなたは恵み深く、あわれみ深い神だからである。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="申命記 7:9; ネヘミヤ記 1:5; ダニエル書 9:4"> それゆえ今、私たちの神よ。大いなる、力強い、恐るべき神、契約と慈しみを守られる方よ。アッシリアの王たちの時代から今日まで、私たちと、私たちの王、君、祭司、預言者、先祖、あなたのすべての民に臨んだ苦難を、どうか小さなことと見なさないでください。</span>
<span className="v" id="v33" data-v="33" data-xref="創世記 18:25; 詩篇 106:6; ヨブ記 34:23"> 私たちに臨んだすべてのことにおいて、あなたは正しい。あなたは真実を行われたが、私たちは悪を行った。</span>
<span className="v" id="v34" data-v="34" data-xref="エレミヤ書 29:19; 列王記第二 17:13; 申命記 31:21"> 私たちの王、君、祭司、先祖は、あなたの律法を守らず、戒めにも、彼らに与えられた警告にも耳を傾けなかった。</span>
<span className="v" id="v35" data-v="35" data-xref="申命記 28:47; 申命記 32:12–15; エレミヤ書 5:19"> 彼らは自分たちの王国にあっても、あなたが与えられた大いなる恵みの中でも、彼らの前に与えられた広く肥沃な地にあっても、あなたに仕えず、悪い行いから立ち返らなかった。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="エズラ記 9:9; 申命記 28:48; 歴代誌 第二 12:8"> 「見よ、私たちは今日、しもべとなっている。先祖たちに、その実と良いものを食べるために与えられた地で、見よ、私たちはしもべとなっている。</span>
<span className="v" id="v37" data-v="37" data-xref="申命記 28:33; 申命記 28:48; エズラ記 7:24"> この地は、私たちの罪のゆえにあなたが立てられた王たちのために、多くの実りを生み出している。彼らは思いのままに、私たちの体と家畜を支配している。私たちは大きな苦難の中にいる。</span>
<span className="v" id="v38" data-v="38" data-xref="ネヘミヤ記 10:1; 歴代誌 第二 34:31; エズラ記 10:3"> このすべてのゆえに、私たちは確かな契約を結んで書き記し、指導者たち、レビ人、祭司たちがこれに印を押す。」</span>
</div>

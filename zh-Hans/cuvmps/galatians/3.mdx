## 责备加拉太人受了迷惑

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 5:7–8; 哥林多后书 11:3; 加拉太书 1:6"> 无知的加拉太人哪！耶稣基督钉十字架，已经活画在你们眼前，谁又迷惑了你们呢？</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 10:16–17; 加拉太书 3:14; 使徒行传 15:8"> 我只要问你们这一件：你们受了圣灵，是因行律法呢，是因听信福音呢？</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 5:4–8; 加拉太书 4:7–10; 希伯来书 7:16–19"> 你们既靠圣灵入门，如今还靠肉身成全吗？你们是这样的无知吗？</span>
<span className="v" id="v4" data-v="4" data-xref="约翰二书 1:8; 哥林多前书 15:2; 希伯来书 10:32–39"> 你们受苦如此之多，都是徒然的吗？难道果真是徒然的吗？</span>
</div>
</div>

## 信与律法相比

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="加拉太书 3:2; 使徒行传 14:9–10; 使徒行传 19:11–12"> 那赐给你们圣灵，又在你们中间行异能的，是因你们行律法呢，是因你们听信福音呢？</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 15:6; 罗马书 4:21–22; 雅各书 2:23"> 正如“亚伯拉罕信神，这就算为他的义”。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 9:7–8; 加拉太书 3:9; 加拉太书 3:26–29"> 所以你们要知道：那以信为本的人，就是亚伯拉罕的子孙。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 12:3; 创世记 22:18; 创世记 28:14"> 并且圣经既然预先看明神要叫外邦人因信称义，就早已传福音给亚伯拉罕，说：“万国都必因你得福。”</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 4:16; 加拉太书 3:29; 罗马书 4:24"> 可见那以信为本的人和有信心的亚伯拉罕一同得福。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 27:26; 罗马书 8:7; 罗马书 3:19–20"> 凡以行律法为本的，都是被咒诅的，因为经上记着：“凡不常照律法书上所记一切之事去行的，就被咒诅。”</span>
</div>
</div>

## 义人必因信得生

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哈巴谷书 2:4; 罗马书 1:17; 希伯来书 10:38"> 没有一个人靠着律法在神面前称义，这是明显的，因为经上说：“义人必因信得生。”</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 18:5; 罗马书 10:5–6; 尼希米记 9:29"> 律法原不本乎信，只说：“行这些事的，就必因此活着。”</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前书 2:24; 申命记 21:23; 希伯来书 9:12"> 基督既为我们受<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“受”原文作“成”。">a</a></sup>了咒诅，就赎出我们脱离律法的咒诅，因为经上记着：“凡挂在木头上都是被咒诅的。”</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 3:28–29; 哥林多前书 12:13; 以西结书 36:26–27"> 这便叫亚伯拉罕的福，因基督耶稣可以临到外邦人，使我们因信得着所应许的圣灵。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="希伯来书 9:17; 罗马书 6:19; 罗马书 3:5"> 弟兄们，我且照着人的常话说：虽然是人的文约，若已经立定了，就没有能废弃或加增的。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 17:7–8; 罗马书 4:13; 路加福音 1:55"> 所应许的原是向亚伯拉罕和他子孙说的，神并不是说“众子孙”，指着许多人；乃是说“你那一个子孙”，指着一个人，就是基督。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 11:39–40; 创世记 15:13; 罗马书 4:13–14"> 我是这么说：神预先所立的约，不能被那四百三十年以后的律法废掉，叫应许归于虚空。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 6:12–15; 加拉太书 2:21; 罗马书 4:13–16"> 因为承受产业，若本乎律法，就不本乎应许；但神是凭着应许，把产业赐给亚伯拉罕。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 7:53; 罗马书 7:7–13; 希伯来书 2:2"> 这样说来，律法是为什么有的呢？原是为过犯添上的，等候那蒙应许的子孙来到；并且是藉天使、经中保之手设立的。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太前书 2:5; 申命记 6:4; 约伯记 9:33"> 但中保本不是为一面做的，神却是一位。</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太书 2:21; 罗马书 9:31; 罗马书 3:20–22"> 这样，律法是与神的应许反对吗？断乎不是。若曾传一个能叫人得生的律法，义就诚然本乎律法了。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 11:32; 希伯来书 9:15; 加拉太书 3:23"> 但圣经把众人都圈在罪里，使所应许的福因信耶稣基督归给那信的人。</span>
</div>
</div>

## 律法是福音的先声

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="加拉太书 5:18; 加拉太书 3:24–25; 加拉太书 3:19"> 但这因信得救的理还未来以先，我们被看守在律法之下，直圈到那将来的真道显明出来。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 10:4; 使徒行传 13:38–39; 罗马书 7:24–25"> 这样，律法是我们训蒙的师傅，引我们到基督那里，使我们因信称义。</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 6:14; 罗马书 7:4; 希伯来书 10:15–18"> 但这因信得救的理既然来到，我们从此就不在师傅的手下了。</span>
<span className="v" id="v26" data-v="26" data-xref="以弗所书 1:5; 哥林多后书 6:18; 约翰福音 1:12–13"> 所以，你们因信基督耶稣，都是神的儿子。</span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 13:14; 哥林多前书 12:13; 罗马书 6:3–4"> 你们受洗归入基督的，都是披戴基督了；</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 12:12–13; 歌罗西书 3:11; 罗马书 3:29–30"> 并不分犹太人、希腊人，自主的、为奴的，或男或女，因为你们在基督耶稣里都成为一了。</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所书 3:6; 罗马书 9:7–8; 加拉太书 3:7"> 你们既属乎基督，就是亚伯拉罕的后裔，是照着应许承受产业的了。</span>
</div>
</div>

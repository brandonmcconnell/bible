## 基督使人得自由

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 3:17; 加拉太书 5:13; 彼得前书 2:16"> 基督释放了我们，叫我们得以自由，所以要站立得稳，不要再被奴仆的轭挟制。</span>
</div>
</div>

## 在基督里割礼无功效

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="加拉太书 5:6; 使徒行传 15:1; 罗马书 9:31–32"> 我保罗告诉你们，若受割礼，基督就于你们无益了。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 3:10; 罗马书 2:25; 雅各书 2:10–11"> 我再指着凡受割礼的人确实地说：他是欠着行全律法的债。</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 9:31–32; 彼得后书 2:20–22; 罗马书 11:6"> 你们这要靠律法称义的，是与基督隔绝，从恩典中坠落了。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 130:5; 帖撒罗尼迦前书 1:10; 诗篇 62:5"> 我们靠着圣灵，凭着信心，等候所盼望的义。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 6:15; 哥林多前书 7:19; 雅各书 2:14–26"> 原来在基督耶稣里，受割礼不受割礼全无功效，唯独使人生发仁爱的信心才有功效。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 9:24; 加拉太书 3:1; 希伯来书 12:1"> 你们向来跑得好，有谁拦阻你们，叫你们不顺从真理呢？</span>
<span className="v" id="v8" data-v="8" data-xref="加拉太书 1:6; 罗马书 8:28"> 这样的劝导不是出于那召你们的。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 15:33; 哥林多前书 5:6–7; 马可福音 8:15"> 一点面酵能使全团都发起来。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 5:12; 哥林多后书 2:3; 加拉太书 1:7"> 我在主里很信你们必不怀别样的心，但搅扰你们的，无论是谁，必担当他的罪名。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 1:23; 加拉太书 6:12; 加拉太书 4:29"> 弟兄们，我若仍旧传割礼，为什么还受逼迫呢？若是这样，那十字架讨厌的地方就没有了。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 5:10; 哥林多前书 5:13; 提多书 3:10"> 恨不得那搅乱你们的人把自己割绝了！</span>
</div>
</div>

## 爱心乃包括全律法的义

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="彼得前书 2:16; 哥林多前书 9:19; 哥林多前书 8:9"> 弟兄们，你们蒙召是要得自由，只是不可将你们的自由当做放纵情欲的机会，总要用爱心互相服侍。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 7:12; 利未记 19:18; 加拉太书 6:2"> 因为全律法都包在“爱人如己”这一句话之内了。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 3:3; 雅各书 3:14–3; 加拉太书 5:26"> 你们要谨慎，若相咬相吞，只怕要彼此消灭了。</span>
</div>
</div>

## 圣灵和情欲为敌

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="加拉太书 5:24–25; 罗马书 8:12–14; 加拉太书 6:8"> 我说，你们当顺着圣灵而行，就不放纵肉体的情欲了。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 8:13; 约翰福音 3:6; 罗马书 8:5–8"> 因为情欲和圣灵相争，圣灵和情欲相争，这两个是彼此相敌，使你们不能做所愿意做的。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 8:14; 罗马书 6:14–15; 加拉太书 5:25"> 但你们若被圣灵引导，就不在律法以下。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 6:9–10; 歌罗西书 3:5–8; 马太福音 15:18–19"> 情欲的事都是显而易见的，就如奸淫、污秽、邪荡、</span>
<span className="v" id="v20" data-v="20" data-xref="提多书 3:10; 哥林多前书 11:19; 启示录 21:8"> 拜偶像、邪术、仇恨、争竞、忌恨、恼怒、结党、纷争、异端、</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 6:9–10; 罗马书 8:13; 罗马书 13:13"> 嫉妒、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷在此有“凶杀”二字。">a</a></sup>醉酒、荒宴等类。我从前告诉你们，现在又告诉你们：行这样事的人必不能承受神的国。</span>
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 3:12–17; 哥林多前书 13:4–7; 约翰福音 15:5"> 圣灵所结的果子，就是仁爱、喜乐、和平、忍耐、恩慈、良善、信实、</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太前书 1:9; 使徒行传 24:25; 提多书 2:2"> 温柔、节制；这样的事没有律法禁止。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 6:6; 罗马书 13:14; 罗马书 8:13"> 凡属基督耶稣的人，是已经把肉体连肉体的邪情私欲同钉在十字架上了。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="加拉太书 5:16; 罗马书 8:4–5; 罗马书 8:2"> 我们若是靠圣灵得生，就当靠圣灵行事。</span>
<span className="v" id="v26" data-v="26" data-xref="雅各书 3:14–16; 腓立比书 2:1–3; 雅各书 4:16"> 不要贪图虚名，彼此惹气，互相嫉妒。</span>
</div>
</div>

## 凶恶园户的比喻

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 5:1–4; 马可福音 13:34; 雅歌 8:11–12"> 耶稣就用比喻对他们说：<span className="woj">“有人栽了一个葡萄园，周围圈上篱笆，挖了一个压酒池，盖了一座楼，租给园户，就往外国去了。</span></span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 15:1–8; 希伯来书 1:1; 耶利米书 44:4"> <span className="woj">到了时候，打发一个仆人到园户那里，要从园户收葡萄园的果子。</span></span>
<span className="v" id="v3" data-v="3" data-xref="帖撒罗尼迦前书 2:15; 尼希米记 9:26; 耶利米书 29:26"> <span className="woj">园户拿住他，打了他，叫他空手回去。</span></span>
<span className="v" id="v4" data-v="4"> <span className="woj">再打发一个仆人到他们那里，他们打伤他的头，并且凌辱他。</span></span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 22:6; 马太福音 23:37; 尼希米记 9:30"> <span className="woj">又打发一个仆人去，他们就杀了他。后又打发好些仆人去，有被他们打的，有被他们杀的。</span></span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 1:1–2; 马太福音 3:17; 约翰福音 1:34"> <span className="woj">园主还有一位是他的爱子，末后又打发他去，意思说：‘他们必尊敬我的儿子。’</span></span>
<span className="v" id="v7" data-v="7" data-xref="创世记 37:20; 马太福音 2:16; 使徒行传 2:23"> <span className="woj">不料那些园户彼此说：‘这是承受产业的。来吧，我们杀他，产业就归我们了！’</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 21:39; 路加福音 20:15; 马太福音 21:33"> <span className="woj">于是拿住他，杀了他，把他丢在园外。</span></span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 10:20–12; 马太福音 21:43; 路加福音 19:27"> <span className="woj">这样，葡萄园的主人要怎么办呢？他要来除灭那些园户，将葡萄园转给别人。</span></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 118:22–23; 彼得前书 2:7–8; 以赛亚书 28:16"> <span className="woj">经上写着说：</span><br /><span className="pl pl-1 woj">‘匠人所弃的石头，</span><br /><span className="pl pl-1 woj">已做了房角的头块石头。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 118:23; 使徒行传 3:12–16; 哈巴谷书 1:5"> <span className="pl pl-1 woj">这是主所做的，</span><br /><span className="pl pl-1 woj">在我们眼中看为稀奇。’</span><br /><span className="woj">这经你们没有念过吗？”</span></span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 11:18; 马太福音 22:22; 约翰福音 7:44"> 他们看出这比喻是指着他们说的，就想要捉拿他，只是惧怕百姓，于是离开他走了。</span>
</div>
</div>

## 巧言盘问

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 20:20–26; 路加福音 11:54; 马可福音 3:6"> 后来，他们打发几个法利赛人和几个希律党的人到耶稣那里，要就着他的话陷害他。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:4; 路加福音 20:22; 约翰福音 7:18"> 他们来了，就对他说：“夫子，我们知道你是诚实的，什么人你都不徇情面，因为你不看人的外貌，乃是诚诚实实传神的道。纳税给凯撒可以不可以？</span>
</div>
</div>

## 纳税给凯撒

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西结书 17:2; 启示录 2:23; 马可福音 10:2"> “我们该纳不该纳？”耶稣知道他们的假意，就对他们说：<span className="woj">“你们为什么试探我？拿一个银钱来给我看。”</span></span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 20:24–26; 启示录 3:12; 马太福音 22:19–22"> 他们就拿了来。耶稣说：<span className="woj">“这像和这号是谁的？”</span>他们说：“是凯撒的。”</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 13:7; 彼得前书 2:17; 哥林多后书 5:14–15"> 耶稣说：<span className="woj">“凯撒的物当归给凯撒，神的物当归给神。”</span>他们就很稀奇他。</span>
</div>
</div>

## 撒都该人辩驳复活之事

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 22:23–33; 使徒行传 4:1–2; 使徒行传 23:6–9"> 撒都该人常说没有复活的事。他们来问耶稣，说：</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 25:5–10; 路得记 4:5; 路得记 1:11–13"> “夫子，摩西为我们写着说：‘人若死了，撇下妻子，没有孩子，他兄弟当娶他的妻，为哥哥生子立后。’</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 22:25–28; 路加福音 20:29–33"> 有弟兄七人，第一个娶了妻，死了，没有留下孩子。</span>
<span className="v" id="v21" data-v="21"> 第二个娶了她，也死了，没有留下孩子。第三个也是这样。</span>
<span className="v" id="v22" data-v="22"> 那七个人都没有留下孩子。末了，那妇人也死了。</span>
<span className="v" id="v23" data-v="23"> 当复活的时候，她是哪一个的妻子呢？因为他们七个人都娶过她。”</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 20:9; 提摩太后书 3:15–17; 马太福音 22:29"> 耶稣说：<span className="woj">“你们所以错了，岂不是因为不明白圣经，不晓得神的大能吗？</span></span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 20:35–36; 马太福音 22:30; 约翰一书 3:2"> <span className="woj">人从死里复活，也不娶也不嫁，乃像天上的使者一样。</span></span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 3:2–6; 路加福音 20:37; 创世记 17:7–8"> <span className="woj">论到死人复活，你们没有念过摩西的书‘荆棘篇’上所载的吗？神对摩西说：‘我是亚伯拉罕的神、以撒的神、雅各的神。’</span></span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 14:9; 罗马书 4:17; 马可福音 12:24"> <span className="woj">神不是死人的神，乃是活人的神。你们是大错了！”</span></span>
</div>
</div>

## 最大的诫命

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马太福音 22:34–40; 路加福音 10:25–28; 路加福音 20:39"> 有一个文士来，听见他们辩论，晓得耶稣回答得好，就问他说：“诫命中哪是第一要紧的呢？”</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 6:4; 路加福音 10:27; 加拉太书 3:20"> 耶稣回答说：<span className="woj">“第一要紧的就是说：‘以色列啊，你要听，主我们神是独一的主。</span></span>
<span className="v" id="v30" data-v="30" data-xref="申命记 6:5"> <span className="woj">你要尽心、尽性、尽意、尽力爱主你的神。’</span></span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 13:8–9; 马太福音 22:39; 利未记 19:18"> <span className="woj">其次就是说：‘要爱人如己。’再没有比这两条诫命更大的了。”</span></span>
<span className="v" id="v32" data-v="32" data-xref="申命记 4:39; 申命记 4:35; 以赛亚书 46:9"> 那文士对耶稣说：“夫子说神是一位，实在不错！除了他以外，再没有别的神。</span>
<span className="v" id="v33" data-v="33" data-xref="何西阿书 6:6; 弥迦书 6:6–8; 撒母耳记上 15:22"> 并且尽心、尽智、尽力爱他，又爱人如己，就比一切燔祭和各样祭祀好得多。”</span>
<span className="v" id="v34" data-v="34" data-xref="歌罗西书 4:6; 路加福音 20:40; 马太福音 22:46"> 耶稣见他回答得有智慧，就对他说：<span className="woj">“你离神的国不远了。”</span>从此以后，没有人敢再问他什么。</span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="路加福音 20:41–44; 马太福音 22:41–45; 马太福音 26:55"> 耶稣在殿里教训人，就问他们说：<span className="woj">“文士怎么说基督是大卫的子孙呢？</span></span>
<span className="v" id="v36" data-v="36" data-xref="诗篇 110:1; 希伯来书 1:13; 马太福音 22:43–45"> <span className="woj">大卫被圣灵感动，说：</span><br /><span className="pl pl-1 woj">‘主对我主说：</span><br /><span className="pl pl-1 woj">“你坐在我的右边，</span><br /><span className="pl pl-1 woj">等我使你仇敌做你的脚凳。”’</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="罗马书 1:3–4; 马太福音 11:25; 马太福音 1:23"> <span className="woj">大卫既自己称他为主，他怎么又是大卫的子孙呢？”</span>众人都喜欢听他。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="马太福音 23:1–7; 路加福音 20:45–47; 路加福音 11:43"> 耶稣在教训之间说：<span className="woj">“你们要防备文士。他们好穿长衣游行，喜爱人在街市上问他们的安，</span></span>
<span className="v" id="v39" data-v="39" data-xref="雅各书 2:2–3"> <span className="woj">又喜爱会堂里的高位、筵席上的首座。</span></span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 23:13; 路加福音 20:47; 马太福音 23:33"> <span className="woj">他们侵吞寡妇的家产，假意作很长的祷告。这些人要受更重的刑罚！”</span></span>
</div>
</div>

## 主称赞寡妇的捐资

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 21:1–4; 列王纪下 12:9; 约翰福音 8:20"> 耶稣对银库坐着，看众人怎样投钱入库。有好些财主往里投了若干的钱。</span>
<span className="v" id="v42" data-v="42"> 有一个穷寡妇来，往里投了两个小钱，就是一个大钱。</span>
<span className="v" id="v43" data-v="43" data-xref="哥林多后书 9:6–8; 哥林多后书 8:2; 使徒行传 11:29"> 耶稣叫门徒来，说：<span className="woj">“我实在告诉你们：这穷寡妇投入库里的比众人所投的更多，</span></span>
<span className="v" id="v44" data-v="44" data-xref="哥林多后书 8:2–3; 约翰一书 3:17; 以斯拉记 2:68–69"> <span className="woj">因为他们都是自己有余，拿出来投在里头，但这寡妇是自己不足，把她一切养生的都投上了。”</span></span>
</div>

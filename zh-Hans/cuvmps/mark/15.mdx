## 耶稣在彼拉多前受审

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 27:1–2; 路加福音 23:1–5; 路加福音 22:66"> 一到早晨，祭司长和长老、文士、全公会的人大家商议，就把耶稣捆绑，解去交给彼拉多。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 2:2; 马太福音 27:11–14; 提摩太前书 6:13"> 彼拉多问他说：“你是犹太人的王吗？”耶稣回答说：<span className="woj">“你说的是。”</span></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 53:7; 马可福音 15:5; 约翰福音 18:29–31"> 祭司长告他许多的事。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 19:10; 马太福音 27:13; 马太福音 26:62"> 彼拉多又问他说：“你看，他们告你这么多的事，你什么都不回答吗？”</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 53:7; 撒迦利亚书 3:8; 诗篇 71:7"> 耶稣仍不回答，以致彼拉多觉得稀奇。</span>
</div>
</div>

## 祭司长唆众释放巴拉巴

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约翰福音 18:39–40; 使徒行传 25:9; 使徒行传 24:27"> 每逢这节期，巡抚照众人所求的释放一个囚犯给他们。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 23:18–19; 马太福音 27:16; 路加福音 23:25"> 有一个人名叫巴拉巴，和作乱的人一同捆绑；他们作乱的时候，曾杀过人。</span>
<span className="v" id="v8" data-v="8"> 众人上去求巡抚照常例给他们办。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 19:14–16; 约翰福音 19:4–5; 约翰福音 18:39"> 彼拉多说：“你们要我释放犹太人的王给你们吗？”</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 27:4; 提多书 3:3; 创世记 4:4–6"> 他原晓得祭司长是因为嫉妒才把耶稣解了来。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 3:14; 约翰福音 18:40; 何西阿书 5:1"> 只是祭司长挑唆众人，宁可释放巴拉巴给他们。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 23:5–6; 以赛亚书 9:6–7; 撒迦利亚书 9:9"> 彼拉多又说：“那么样，你们所称为犹太人的王，我怎么办他呢？”</span>
<span className="v" id="v13" data-v="13"> 他们又喊着说：“把他钉十字架！”</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 23:41; 路加福音 23:23–24; 以赛亚书 53:3"> 彼拉多说：“为什么呢？他做了什么恶事呢？”他们便极力地喊着说：“把他钉十字架！”</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 19:1; 马太福音 27:26; 以赛亚书 50:6"> 彼拉多要叫众人喜悦，就释放巴拉巴给他们，将耶稣鞭打了，交给人钉十字架。</span>
</div>
</div>

## 戏弄耶稣

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰福音 19:9; 马太福音 27:27–31; 约翰福音 18:28"> 兵丁把耶稣带进衙门院里，叫齐了全营的兵。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 27:28–30; 约翰福音 19:2–5; 路加福音 23:11"> 他们给他穿上紫袍，又用荆棘编做冠冕给他戴上，</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 27:42–43; 马可福音 15:2; 创世记 37:10"> 就庆贺他说：“恭喜，犹太人的王啊！”</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 14:65; 以赛亚书 53:3–5; 路加福音 23:11"> 又拿一根苇子打他的头，吐唾沫在他脸上，屈膝拜他。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 19:16; 马太福音 27:31"> 戏弄完了，就给他脱了紫袍，仍穿上他自己的衣服，带他出去，要钉十字架。</span>
</div>
</div>

## 耶稣被钉十字架

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马太福音 27:32; 路加福音 23:26; 罗马书 16:13"> 有一个古利奈人西门，就是亚历山大和鲁孚的父亲，从乡下来，经过那地方。他们就勉强他同去，好背着耶稣的十字架。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 27:33–44; 约翰福音 19:17–27; 路加福音 23:27–38"> 他们带耶稣到了各各他地方（“各各他”翻出来就是“髑髅地”），</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 27:34; 约翰福音 19:28–30; 路加福音 23:36"> 拿没药调和的酒给耶稣，他却不受。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 23:34; 约翰福音 19:23–24; 马太福音 27:35–36"> 于是将他钉在十字架上，拈阄分他的衣服，看是谁得什么。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 19:14; 马可福音 15:33; 马太福音 27:45"> 钉他在十字架上是巳初的时候。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 27:37; 马太福音 2:2; 约翰福音 19:18–22"> 在上面有他的罪状，写的是：“犹太人的王。”</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 23:32–33; 马太福音 27:38; 约翰福音 19:18"> 他们又把两个强盗和他同钉十字架，一个在右边，一个在左边。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷在此有：28 这就应了经上的话说：“他被列在罪犯之中。”">a</a></sup></span>
</div>
</div>

## 辱骂主不能救自己

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马可福音 14:58; 诗篇 109:25; 耶利米哀歌 1:12"> 从那里经过的人辱骂他，摇着头说：“咳！你这拆毁圣殿、三日又建造起来的，</span>
<span className="v" id="v30" data-v="30"> 可以救自己，从十字架上下来吧！”</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 12:23–24; 马太福音 27:41–43; 路加福音 23:35–37"> 祭司长和文士也是这样戏弄他，彼此说：“他救了别人，不能救自己。</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 27:44; 路加福音 23:39–43; 撒迦利亚书 9:9"> 以色列的王基督，现在可以从十字架上下来，叫我们看见就信了！”那和他同钉的人也是讥诮他。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 27:45; 路加福音 23:44–45; 阿摩司书 8:9–10"> 从午正到申初，遍地都黑暗了。</span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 22:1; 马太福音 27:46; 希伯来书 5:7"> 申初的时候，耶稣大声喊着说：<span className="woj">“以罗伊！以罗伊！拉马撒巴各大尼？”</span>（翻出来就是：<span className="woj">“我的神！我的神！为什么离弃我？”</span>）</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 27:47–49; 马可福音 9:11–13; 马太福音 17:11–13"> 旁边站着的人，有的听见就说：“看哪，他叫以利亚呢！”</span>
<span className="v" id="v36" data-v="36" data-xref="诗篇 69:21; 马可福音 15:23; 约翰福音 19:28–30"> 有一个人跑去，把海绒蘸满了醋，绑在苇子上，送给他喝，说：“且等着，看以利亚来不来把他取下。”</span>
</div>
</div>

## 耶稣死的景象

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="约翰福音 19:30; 路加福音 23:46; 马太福音 27:50"> 耶稣大声喊叫，气就断了。</span>
<span className="v" id="v38" data-v="38" data-xref="希伯来书 10:19–23; 路加福音 23:45; 希伯来书 9:3–12"> 殿里的幔子从上到下裂为两半。</span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 27:54; 路加福音 23:47–48; 马太福音 27:43"> 对面站着的百夫长看见耶稣这样喊叫<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷无“喊叫”二字。">b</a></sup>断气，就说：“这人真是神的儿子！”</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 23:49; 路加福音 8:2–3; 马太福音 27:55–56"> 还有些妇女远远地观看，内中有抹大拉的马利亚，又有小雅各和约西的母亲马利亚，并有撒罗米，</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 8:2–3; 马太福音 27:55–56"> 就是耶稣在加利利的时候，跟随他、服侍他的那些人；还有同耶稣上耶路撒冷的好些妇女在那里观看。</span>
</div>
</div>

## 安放在坟墓里

<div className="bt">
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="路加福音 23:50–56; 约翰福音 19:38–42; 约翰福音 19:31"> 到了晚上，因为这是预备日，就是安息日的前一日，</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 2:38; 路加福音 2:25; 路加福音 23:51"> 有亚利马太的约瑟前来，他是尊贵的议士，也是等候神国的。他放胆进去见彼拉多，求耶稣的身体。</span>
<span className="v" id="v44" data-v="44" data-xref="约翰福音 19:31–37"> 彼拉多诧异耶稣已经死了，便叫百夫长来，问他耶稣死了久不久。</span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 27:58; 约翰福音 19:38; 马可福音 15:39"> 既从百夫长得知实情，就把耶稣的尸首赐给约瑟。</span>
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 53:9; 马太福音 27:59–60; 以赛亚书 22:16"> 约瑟买了细麻布，把耶稣取下来，用细麻布裹好，安放在磐石中凿出来的坟墓里，又滚过一块石头来挡住墓门。</span>
<span className="v" id="v47" data-v="47" data-xref="马可福音 15:40; 马可福音 16:1; 路加福音 23:55–2"> 抹大拉的马利亚和约西的母亲马利亚都看见安放他的地方。</span>
</div>

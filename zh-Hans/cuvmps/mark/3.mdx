## 在安息日治病

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 12:9–14; 路加福音 6:6–11; 马可福音 1:21"> 耶稣又进了会堂。在那里有一个人枯干了一只手。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 37:32; 路加福音 14:1; 路加福音 6:7"> 众人窥探耶稣在安息日医治不医治，意思是要控告耶稣。</span>
<span className="v" id="v3" data-v="3" data-xref="腓立比书 1:28–30; 以赛亚书 42:4; 路加福音 6:8"> 耶稣对那枯干一只手的人说：<span className="woj">“起来，站在当中！”</span></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 6:9; 马太福音 12:10–12; 何西阿书 6:6"> 又问众人说：<span className="woj">“在安息日行善、行恶，救命、害命，哪样是可以的呢？”</span>他们都不作声。</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 6:10; 以弗所书 4:18; 罗马书 11:25"> 耶稣怒目周围看他们，忧愁他们的心刚硬，就对那人说：<span className="woj">“伸出手来！”</span>他把手一伸，手就复了原。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 22:16; 马可福音 12:13; 马太福音 12:14"> 法利赛人出去，同希律一党的人商议怎样可以除灭耶稣。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 4:25; 路加福音 6:17; 马太福音 12:15"> 耶稣和门徒退到海边去，有许多人从加利利跟随他。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 35:15; 以赛亚书 34:5; 马太福音 11:21"> 还有许多人听见他所做的大事，就从犹太、耶路撒冷、以土买、约旦河外，并推罗、西顿的四方来到他那里。</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 5:30; 约翰福音 6:15"> 他因为人多，就吩咐门徒叫一只小船伺候着，免得众人拥挤他。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 14:36; 马可福音 6:56; 马太福音 4:23"> 他治好了许多人，所以凡有灾病的都挤进来要摸他。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 4:41; 马可福音 1:23–24; 路加福音 8:28"> 污鬼无论何时看见他，就俯伏在他面前，喊着说：“你是神的儿子！”</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 12:16; 马可福音 1:25; 马可福音 1:34"> 耶稣再三地嘱咐他们，不要把他显露出来。</span>
</div>
</div>

## 耶稣设立十二门徒

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:1; 路加福音 6:12–16; 马太福音 10:1–4"> 耶稣上了山，随自己的意思叫人来，他们便来到他那里。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 1:8; 路加福音 9:1–6; 约翰福音 15:16"> 他就设立十二个人，要他们常和自己同在，也要差他们去传道，</span>
<span className="v" id="v15" data-v="15"> 并给他们权柄赶鬼。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 1:42; 使徒行传 1:13; 马太福音 16:16–18"> 这十二个人有西门，耶稣又给他起名叫彼得；</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 4:12; 马可福音 14:33; 耶利米书 23:29"> 还有西庇太的儿子雅各和雅各的兄弟约翰，又给这两个人起名叫半尼其，就是雷子的意思；</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 1:13; 马可福音 2:14; 马太福音 9:9"> 又有安得烈，腓力，巴多罗买，马太，多马，亚勒腓的儿子雅各，和达太，并奋锐党的西门；</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 6:71; 约翰福音 13:2; 使徒行传 1:16–25"> 还有卖耶稣的加略人犹大。</span>
</div>
</div>

## 驳倒文士的谗言

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马可福音 6:31; 约翰福音 4:31–34; 马可福音 9:28"> 耶稣进了一个屋子，众人又聚集，甚至他连饭也顾不得吃。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 26:24; 约翰福音 10:20; 马可福音 3:31"> 耶稣的亲属听见，就出来要拉住他，因为他们说他癫狂了。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 15:1; 马太福音 10:25; 马太福音 9:34"> 从耶路撒冷下来的文士说：“他是被别西卜附着。”又说：“他是靠着鬼王赶鬼。”</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 11:17–23; 马太福音 12:25–30; 马太福音 13:34"> 耶稣叫他们来，用比喻对他们说：<span className="woj">“撒旦怎能赶出撒旦呢？</span></span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亚书 11:14; 以赛亚书 19:2–3; 撒母耳记下 20:6"> <span className="woj">若一国自相纷争，那国就站立不住；</span></span>
<span className="v" id="v25" data-v="25" data-xref="雅各书 3:16; 诗篇 133:1; 加拉太书 5:15"> <span className="woj">若一家自相纷争，那家就站立不住。</span></span>
<span className="v" id="v26" data-v="26"> <span className="woj">若撒旦自相攻打纷争，他就站立不住，必要灭亡。</span></span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 49:24–26; 马太福音 12:29; 路加福音 11:21–23"> <span className="woj">没有人能进壮士家里抢夺他的家具，必先捆住那壮士，才可以抢夺他的家。</span></span>
</div>
</div>

## 亵渎圣灵永不赦免

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 12:10; 马太福音 12:31–32; 约翰一书 5:16"> <span className="woj">“我实在告诉你们：世人一切的罪和一切亵渎的话都可得赦免，</span></span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 12:31–32; 路加福音 12:10; 帖撒罗尼迦后书 1:9"> <span className="woj">凡亵渎圣灵的，却永不得赦免，乃要担当永远的罪。”</span></span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 10:20; 马可福音 3:22"> 这话是因为他们说他是被污鬼附着的。</span>
</div>
</div>

## 信者皆为亲属

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 8:19–21; 马太福音 12:46–50"> 当下，耶稣的母亲和弟兄来，站在外边，打发人去叫他。</span>
<span className="v" id="v32" data-v="32"> 有许多人在耶稣周围坐着，他们就告诉他说：“看哪，你母亲和你弟兄在外边找你。”</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 3:21; 申命记 33:9; 马可福音 6:3"> 耶稣回答说：<span className="woj">“谁是我的母亲？谁是我的弟兄？”</span></span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 12:49–50; 路加福音 11:27–28; 罗马书 8:29"> 就四面观看那周围坐着的人，说：<span className="woj">“看哪，我的母亲，我的弟兄！</span></span>
<span className="v" id="v35" data-v="35" data-xref="约翰一书 2:17; 马太福音 7:21; 约翰一书 3:22–23"> <span className="woj">凡遵行神旨意的人，就是我的弟兄、姐妹和母亲了。”</span></span>
</div>
</div>

## 撒种的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 5:1–3; 马可福音 2:13; 路加福音 8:4–10"> 耶稣又在海边教训人。有许多人到他那里聚集，他只得上船坐下。船在海里，众人都靠近海，站在岸上。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 13:34–35; 马可福音 3:23; 马可福音 4:11"> 耶稣就用比喻教训他们许多道理。在教训之间，对他们说：</span>
<span className="v" id="v3" data-v="3" data-xref="雅各书 2:5; 马太福音 13:26; 马可福音 4:26–29"> <span className="woj">“你们听啊！有一个撒种的出去撒种。</span></span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 13:19; 马可福音 4:15; 马太福音 13:4"> <span className="woj">撒的时候，有落在路旁的，飞鸟来吃尽了。</span></span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 36:26; 路加福音 8:6; 路加福音 8:13"> <span className="woj">有落在土浅石头地上的，土既不深，发苗最快，</span></span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 1:11; 耶利米书 17:5–8; 约拿书 4:8"> <span className="woj">日头出来一晒，因为没有根，就枯干了。</span></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 4:3; 路加福音 8:14; 创世记 3:17–18"> <span className="woj">有落在荆棘里的，荆棘长起来，把它挤住了，就不结实。</span></span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 15:5; 歌罗西书 1:6; 马可福音 4:20"> <span className="woj">又有落在好土里的，就发生长大，结实有三十倍的，有六十倍的，有一百倍的。”</span></span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 11:15; 马可福音 4:23–24; 启示录 3:22"> 又说：<span className="woj">“有耳可听的，就应当听！”</span></span>
</div>
</div>

## 用比喻的因由

<div className="bt">
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="马太福音 13:10–17; 马可福音 4:34; 箴言 13:20"> 无人的时候，跟随耶稣的人和十二个门徒问他这比喻的意思。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 11:25; 路加福音 8:10; 约翰一书 5:20"> 耶稣对他们说：<span className="woj">“神国的奥秘只叫你们知道，若是对外人讲，凡事就用比喻，</span></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 6:9–10; 以赛亚书 44:18; 马太福音 13:14–15"> <span className="woj">叫</span><br /><span className="pl pl-1 woj">‘他们看是看见，却不晓得，</span><br /><span className="pl pl-1 woj">听是听见，却不明白；</span><br /><span className="pl pl-1 woj">恐怕他们回转过来，就得赦免’。”</span></span>
</div>
</div>

## 解明撒种的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="启示录 3:19; 马太福音 13:51–52; 马可福音 7:17–18"> 又对他们说：<span className="woj">“你们不明白这比喻吗？这样怎能明白一切的比喻呢？</span></span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 8:4; 马太福音 13:19; 马太福音 13:37"> <span className="woj">撒种之人所撒的就是道。</span></span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 5:8; 马太福音 13:19; 哥林多后书 2:11"> <span className="woj">那撒在路旁的，就是人听了道，撒旦立刻来，把撒在他心里的道夺了去。</span></span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 6:20; 路加福音 8:13; 马太福音 13:20–21"> <span className="woj">那撒在石头地上的，就是人听了道，立刻欢喜领受，</span></span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 11:6; 帖撒罗尼迦前书 3:3–5; 马太福音 12:31"> <span className="woj">但他心里没有根，不过是暂时的，及至为道遭了患难，或是受了逼迫，立刻就跌倒了。</span></span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 8:14; 耶利米书 4:3; 马太福音 13:22"> <span className="woj">还有那撒在荆棘里的，就是人听了道，</span></span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 2:15–17; 提摩太前书 6:9–10; 提摩太前书 6:17"> <span className="woj">后来有世上的思虑、钱财的迷惑和别样的私欲进来，把道挤住了，就不能结实。</span></span>
<span className="v" id="v20" data-v="20" data-xref="歌罗西书 1:10; 路加福音 8:15; 约翰福音 15:4–5"> <span className="woj">那撒在好地上的，就是人听道又领受，并且结实，有三十倍的，有六十倍的，有一百倍的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马太福音 5:15; 路加福音 11:33; 路加福音 8:16"> 耶稣又对他们说：<span className="woj">“人拿灯来，岂是要放在斗底下、床底下，不放在灯台上吗？</span></span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 8:17; 传道书 12:14; 马太福音 10:26–27"> <span className="woj">因为掩藏的事没有不显出来的，隐瞒的事没有不露出来的。</span></span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 4:9; 马太福音 11:15; 启示录 2:29"> <span className="woj">有耳可听的，就应当听！”</span></span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 2:1; 路加福音 8:18; 马太福音 7:2"> 又说：<span className="woj">“你们所听的要留心。你们用什么量器量给人，也必用什么量器量给你们，并且要多给你们。</span></span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 13:12; 路加福音 8:18; 马太福音 25:28–29"> <span className="woj">因为有的，还要给他；没有的，连他所有的也要夺去。”</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 13:24; 哥林多前书 3:6–9; 路加福音 8:11"> 又说：<span className="woj">“神的国如同人把种撒在地上，</span></span>
<span className="v" id="v27" data-v="27" data-xref="传道书 11:5; 帖撒罗尼迦后书 1:3; 哥林多前书 15:37–38"> <span className="woj">黑夜睡觉，白日起来，这种就发芽渐长，那人却不晓得如何这样。</span></span>
<span className="v" id="v28" data-v="28" data-xref="马可福音 4:31–32; 何西阿书 6:3; 腓立比书 1:9–11"> <span className="woj">地生五谷是出于自然的，先发苗，后长穗，再后穗上结成饱满的子粒。</span></span>
<span className="v" id="v29" data-v="29" data-xref="约珥书 3:13; 马太福音 13:30; 马太福音 13:40–43"> <span className="woj">谷既熟了，就用镰刀去割，因为收成的时候到了。”</span></span>
</div>
</div>

## 芥菜种的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="马太福音 13:31–32; 路加福音 13:18–21; 耶利米哀歌 2:13"> 又说：<span className="woj">“神的国，我们可用什么比较呢？可用什么比喻表明呢？</span></span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 19:20; 路加福音 13:18–19; 但以理书 2:44–45"> <span className="woj">好像一粒芥菜种，种在地里的时候，虽比地上的百种都小，</span></span>
<span className="v" id="v32" data-v="32" data-xref="但以理书 4:20–22; 但以理书 4:10–14; 以西结书 31:3–10"> <span className="woj">但种上以后，就长起来，比各样的菜都大，又长出大枝来，甚至天上的飞鸟可以宿在它的荫下。”</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 13:34–35; 约翰福音 16:12; 希伯来书 5:11–14"> 耶稣用许多这样的比喻，照他们所能听的，对他们讲道。</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 16:25; 马可福音 4:10; 马太福音 15:15–20"> 若不用比喻，就不对他们讲；没有人的时候，就把一切的道讲给门徒听。</span>
</div>
</div>

## 平静风和海

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 8:18; 路加福音 8:22; 路加福音 8:25"> 当那天晚上，耶稣对门徒说：<span className="woj">“我们渡到那边去吧。”</span></span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 3:9; 马可福音 4:1; 马可福音 5:2"> 门徒离开众人，耶稣仍在船上，他们就把他一同带去；也有别的船和他同行。</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 8:23–24; 约伯记 1:19; 路加福音 8:22–23"> 忽然起了暴风，波浪打入船内，甚至船要满了水。</span>
<span className="v" id="v38" data-v="38" data-xref="彼得前书 5:7; 希伯来书 4:15; 以赛亚书 54:6–8"> 耶稣在船尾上枕着枕头睡觉。门徒叫醒了他，说：“夫子！我们丧命，你不顾吗？”</span>
<span className="v" id="v39" data-v="39" data-xref="诗篇 107:29; 诗篇 89:9; 诗篇 65:7"> 耶稣醒了，斥责风，向海说：<span className="woj">“住了吧！静了吧！”</span>风就止住，大大地平静了。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 8:25; 马太福音 8:26; 马太福音 14:31"> 耶稣对他们说：<span className="woj">“为什么胆怯？你们还没有信心吗？”</span></span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 8:25; 约伯记 38:11; 诗篇 89:7"> 他们就大大地惧怕，彼此说：“这到底是谁？连风和海也听从他了！”</span>
</div>

## 施洗约翰传道

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约翰一书 5:11–12; 马太福音 4:3; 马太福音 3:17"> 神的儿子，耶稣基督福音的起头。</span>
<span className="v" id="v2" data-v="2" data-xref="玛拉基书 3:1; 马太福音 11:10; 路加福音 1:76"> 正如先知以赛亚<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷无“以赛亚”三字。">a</a></sup>书上记着说：<br /><span className="pl pl-1">“看哪！我要差遣我的使者在你前面，</span><br /><span className="pl pl-1">预备道路。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 40:3–5; 马太福音 3:3; 路加福音 3:4–6"> <span className="pl pl-1">在旷野有人声喊着说：</span><br /><span className="pl pl-1">‘预备主的道，</span><br /><span className="pl pl-1">修直他的路！’”</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="使徒行传 19:3–4; 马太福音 3:6; 使徒行传 13:24–25"> 照这话，约翰来了，在旷野施洗，传悔改的洗礼，使罪得赦。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 26:40–42; 使徒行传 19:18; 马太福音 3:5–6"> 犹太全地和耶路撒冷的人都出去到约翰那里，承认他们的罪，在约旦河里受他的洗。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 1:8; 利未记 11:22; 马太福音 3:4"> 约翰穿骆驼毛的衣服，腰束皮带，吃的是蝗虫、野蜜。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 13:25; 路加福音 3:16; 约翰福音 1:27"> 他传道说：“有一位在我以后来的，能力比我更大，我就是弯腰给他解鞋带也是不配的。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 1:5; 哥林多前书 12:13; 使徒行传 19:4–6"> 我是用水给你们施洗，他却要用圣灵给你们施洗。”</span>
</div>
</div>

## 耶稣受洗

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马太福音 3:13–17; 马太福音 2:23; 路加福音 3:21–22"> 那时，耶稣从加利利的拿撒勒来，在约旦河里受了约翰的洗。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 1:31–34; 路加福音 3:22; 以赛亚书 42:1"> 他从水里一上来，就看见天裂开了，圣灵仿佛鸽子降在他身上；</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 42:1; 马可福音 9:7; 马太福音 3:17"> 又有声音从天上来说：“你是我的爱子，我喜悦你。”</span>
</div>
</div>

## 耶稣受试探

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 4:1–11; 路加福音 4:1–13"> 圣灵就把耶稣催到旷野里去。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 2:17–18; 希伯来书 4:15; 出埃及记 34:28"> 他在旷野四十天，受撒旦的试探，并与野兽同在一处，且有天使来伺候他。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 4:23; 马太福音 4:12; 路加福音 8:1"> 约翰下监以后，耶稣来到加利利，宣传神的福音，</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 3:2; 使徒行传 2:36–38; 马太福音 4:17"> 说：<span className="woj">“日期满了，神的国近了！你们当悔改，信福音！”</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马太福音 4:18–22; 约翰福音 1:40–42; 约翰福音 6:8"> 耶稣顺着加利利的海边走，看见西门和西门的兄弟安得烈在海里撒网，他们本是打鱼的。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 5:10; 马太福音 4:19–20; 使徒行传 2:38–41"> 耶稣对他们说：<span className="woj">“来跟从我，我要叫你们得人如得鱼一样。”</span></span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 18:28–30; 路加福音 5:11; 马可福音 10:28–31"> 他们就立刻舍了网，跟从了他。</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 5:37; 使徒行传 1:13; 马可福音 10:35"> 耶稣稍往前走，又见西庇太的儿子雅各和雅各的兄弟约翰在船上补网，</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 10:37; 路加福音 14:26; 马可福音 10:29"> 耶稣随即招呼他们。他们就把父亲西庇太和雇工人留在船上，跟从耶稣去了。</span>
</div>
</div>

## 在迦百农赶逐污鬼

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马可福音 6:2; 马可福音 1:39; 马太福音 4:23"> 到了迦百农，耶稣就在安息日进了会堂教训人。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 7:28–29; 马太福音 13:54; 路加福音 4:32"> 众人很稀奇他的教训，因为他教训他们正像有权柄的人，不像文士。</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 9:25; 马可福音 7:25; 马可福音 1:34"> 在会堂里有一个人被污鬼附着，他喊叫说：</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 8:29; 雅各书 2:19; 使徒行传 3:14"> “拿撒勒人耶稣，我们与你有什么相干？你来灭我们吗？我知道你是谁，乃是神的圣者！”</span>
<span className="v" id="v25" data-v="25" data-xref="马可福音 1:34; 路加福音 4:41; 使徒行传 16:17"> 耶稣责备他说：<span className="woj">“不要作声！从这人身上出来吧！”</span></span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 9:26; 马可福音 9:20; 路加福音 11:22"> 污鬼叫那人抽了一阵风，大声喊叫，就出来了。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 15:31; 马可福音 7:37; 路加福音 9:1"> 众人都惊讶，以致彼此对问说：“这是什么事？是个新道理啊！他用权柄吩咐污鬼，连污鬼也听从了他。”</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 9:31; 路加福音 4:37; 马可福音 1:45"> 耶稣的名声就传遍了加利利的四方。</span>
</div>
</div>

## 医西门岳母

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 4:38–39; 马太福音 8:14–15; 马可福音 1:21"> 他们一出会堂，就同着雅各、约翰进了西门和安得烈的家。</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前书 9:5; 马可福音 5:23; 约翰福音 11:3"> 西门的岳母正害热病躺着，就有人告诉耶稣。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 9:41; 诗篇 116:12; 马可福音 5:41"> 耶稣进前拉着她的手，扶她起来，热就退了，她就服侍他们。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马太福音 8:16; 马可福音 3:2; 路加福音 4:40"> 天晚日落的时候，有人带着一切害病的和被鬼附的来到耶稣跟前。</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 1:5; 使徒行传 13:44"> 合城的人都聚集在门前。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 4:41; 马可福音 3:12; 马太福音 4:23"> 耶稣治好了许多害各样病的人，又赶出许多鬼，不许鬼说话，因为鬼认识他。</span>
</div>
</div>

## 到旷野祷告

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="路加福音 6:12; 路加福音 5:16; 路加福音 22:39–46"> 次日早晨，天未亮的时候，耶稣起来到旷野地方去，在那里祷告。</span>
<span className="v" id="v36" data-v="36"> 西门和同伴追了他去，</span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 12:19; 马可福音 1:5; 撒迦利亚书 11:11"> 遇见了就对他说：“众人都找你。”</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 4:43; 约翰福音 17:8; 以赛亚书 61:1–3"> 耶稣对他们说：<span className="woj">“我们可以往别处去，到邻近的乡村，我也好在那里传道，因为我是为这事出来的。”</span></span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 4:23; 马可福音 1:21; 路加福音 4:43–44"> 于是在加利利全地，进了会堂，传道、赶鬼。</span>
</div>
</div>

## 洁净长大麻风的

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="路加福音 5:12–14; 马太福音 8:2–4; 利未记 13:1–14"> 有一个长大麻风的来求耶稣，向他跪下，说：“你若肯，必能叫我洁净了。”</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 9:36; 希伯来书 2:17; 希伯来书 4:15"> 耶稣动了慈心，就伸手摸他，说：<span className="woj">“我肯，你洁净了吧！”</span></span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 15:3; 马可福音 5:29; 约翰福音 4:50–53"> 大麻风即时离开他，他就洁净了。</span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 9:30; 马可福音 7:36; 路加福音 8:56"> 耶稣严严地嘱咐他，就打发他走，</span>
<span className="v" id="v44" data-v="44" data-xref="利未记 14:1–32; 路加福音 17:14; 马太福音 8:4"> 对他说：<span className="woj">“你要谨慎，什么话都不可告诉人，只要去把身体给祭司察看，又因为你洁净了，献上摩西所吩咐的礼物，对众人做证据。”</span></span>
<span className="v" id="v45" data-v="45" data-xref="马可福音 2:13; 马太福音 9:31; 约翰福音 6:2"> 那人出去，倒说许多的话，把这件事传扬开了，叫耶稣以后不得再明明地进城，只好在外边旷野地方。人从各处都就了他来。</span>
</div>
</div>

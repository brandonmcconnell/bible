## 医治瘫子

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 4:47; 路加福音 5:18; 路加福音 18:35–38"> 过了些日子，耶稣又进了迦百农。人听见他在房子里，</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 2:13; 马可福音 1:45; 诗篇 40:9"> 就有许多人聚集，甚至连门前都没有空地。耶稣就对他们讲道。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 5:18–26; 马太福音 9:1–8; 马太福音 4:24"> 有人带着一个瘫子来见耶稣，是用四个人抬来的。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 5:19; 申命记 22:8"> 因为人多，不得近前，就把耶稣所在的房子拆了房顶。既拆通了，就把瘫子连所躺卧的褥子都缒下来。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 9:2; 雅各书 5:15; 马可福音 2:9–10"> 耶稣见他们的信心，就对瘫子说：<span className="woj">“小子，你的罪赦了！”</span></span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 5:21–22; 马可福音 8:17; 哥林多后书 10:5"> 有几个文士坐在那里，心里议论说：</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 43:25; 路加福音 5:21; 弥迦书 7:18"> “这个人为什么这样说呢？他说僭妄的话了！除了神以外，谁能赦罪呢？”</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 139:2; 使徒行传 8:22; 路加福音 5:22"> 耶稣心中知道他们心里这样议论，就说：<span className="woj">“你们心里为什么这样议论呢？</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 5:22–25; 马太福音 9:5"> <span className="woj">或对瘫子说‘你的罪赦了’，或说‘起来，拿你的褥子行走’，哪一样容易呢？</span></span>
<span className="v" id="v10" data-v="10" data-xref="但以理书 7:13–14; 马太福音 9:6–8; 约翰福音 5:20–27"> <span className="woj">但要叫你们知道，人子在地上有赦罪的权柄。”</span>就对瘫子说：</span>
<span className="v" id="v11" data-v="11" data-xref="马可福音 1:41; 约翰福音 5:8–10; 约翰福音 6:63"> <span className="woj">“我吩咐你，起来，拿你的褥子回家去吧！”</span></span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 9:33; 马太福音 9:8; 路加福音 7:16"> 那人就起来，立刻拿着褥子，当众人面前出去了。以致众人都惊奇，归荣耀于神，说：“我们从来没有见过这样的事！”</span>
</div>
</div>

## 耶稣召利未

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马可福音 4:1; 箴言 1:20–22; 路加福音 19:48"> 耶稣又出到海边去，众人都就了他来，他便教训他们。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 5:27–32; 路加福音 6:15; 马太福音 9:9–13"> 耶稣经过的时候，看见亚勒腓的儿子利未坐在税关上，就对他说：<span className="woj">“你跟从我来！”</span>他就起来跟从了耶稣。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 15:1; 路加福音 5:29–30; 马太福音 9:10–11"> 耶稣在利未家里坐席的时候，有好些税吏和罪人与耶稣并门徒一同坐席，因为这样的人多，他们也跟随耶稣。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:10; 路加福音 19:7; 路加福音 18:11"> 法利赛人中的文士<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷作：文士和法利赛人。">a</a></sup>看见耶稣和罪人并税吏一同吃饭，就对他门徒说：“他和税吏并罪人一同吃喝吗？”</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 9:12–13; 路加福音 15:7; 路加福音 5:31–32"> 耶稣听见，就对他们说：<span className="woj">“康健的人用不着医生，有病的人才用得着。我来本不是召义人，乃是召罪人。”</span></span>
</div>
</div>

## 论禁食

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 18:12; 马太福音 6:18; 马太福音 9:14–17"> 当下，约翰的门徒和法利赛人禁食。他们来问耶稣说：“约翰的门徒和法利赛人的门徒禁食，你的门徒倒不禁食，这是为什么呢？”</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 25:1–10; 创世记 29:22; 士师记 14:10–11"> 耶稣对他们说：<span className="woj">“新郎和陪伴之人同在的时候，陪伴之人岂能禁食呢？新郎还同在，他们不能禁食。</span></span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 17:22; 启示录 21:9; 以赛亚书 54:5"> <span className="woj">但日子将到，新郎要离开他们，那日他们就要禁食。</span></span>
</div>
</div>

## 新旧难合的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马太福音 9:16; 哥林多前书 10:13; 以赛亚书 57:16"> <span className="woj">“没有人把新布缝在旧衣服上，恐怕所补上的新布带坏了旧衣服，破的就更大了。</span></span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 9:17; 诗篇 119:83; 路加福音 5:37–38"> <span className="woj">也没有人把新酒装在旧皮袋里，恐怕酒把皮袋裂开，酒和皮袋就都坏了。唯把新酒装在新皮袋里。”</span></span>
</div>

## 人子是安息日的主

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 12:1–8; 申命记 23:24–25; 路加福音 6:1–5"> 耶稣当安息日从麦地经过，他门徒行路的时候掐了麦穗。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 20:10; 希伯来书 12:3; 马太福音 12:2"> 法利赛人对耶稣说：“看哪，他们在安息日为什么做不可做的事呢？”</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 21:3–6; 路加福音 10:26; 马太福音 22:31"> 耶稣对他们说：<span className="woj">“经上记着大卫和跟从他的人缺乏、饥饿之时所做的事，你们没有念过吗？</span></span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 8:17; 利未记 24:5–9; 撒母耳记上 21:1"> <span className="woj">他当亚比亚他做大祭司的时候，怎么进了神的殿，吃了陈设饼，又给跟从他的人吃？这饼除了祭司以外，人都不可吃。”</span></span>
<span className="v" id="v27" data-v="27" data-xref="歌罗西书 2:16; 路加福音 6:9; 申命记 5:14"> 又对他们说：<span className="woj">“安息日是为人设立的，人不是为安息日设立的。</span></span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 12:8; 启示录 1:10; 约翰福音 5:17"> <span className="woj">所以，人子也是安息日的主。”</span></span>
</div>
</div>

## 保罗在何事不用自由

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 9:17; 提摩太前书 2:7; 哥林多前书 9:19"> 我不是自由的吗？我不是使徒吗？我不是见过我们的主耶稣吗？你们不是我在主里面所做之工吗？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 12:12; 约翰福音 6:27; 哥林多后书 3:1–3"> 假若在别人我不是使徒，在你们我总是使徒，因为你们在主里正是我做使徒的印证。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 12:16–19; 哥林多后书 13:3; 哥林多后书 13:10"> 我对那盘问我的人就是这样分诉。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 2:6; 帖撒罗尼迦后书 3:8–9; 路加福音 10:7"> 难道我们没有权柄靠福音吃喝吗？</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 1:42; 希伯来书 13:4; 马太福音 8:14"> 难道我们没有权柄娶信主的姐妹为妻，带着一同往来，仿佛其余的使徒和主的弟兄并矶法一样吗？</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦后书 3:7–9; 使徒行传 13:1–2; 使徒行传 4:36"> 独有我与巴拿巴没有权柄不做工吗？</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 27:18; 申命记 20:6; 提摩太后书 2:3–4"> 有谁当兵自备粮饷呢？有谁栽葡萄园不吃园里的果子呢？有谁牧养牛羊不吃牛羊的奶呢？</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 8:20; 帖撒罗尼迦前书 4:8; 罗马书 3:31"> 我说这话，岂是照人的意见？律法不也是这样说吗？</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 25:4; 提摩太前书 5:18; 诗篇 104:27"> 就如摩西的律法记着说：“牛在场上踹谷的时候，不可笼住它的嘴。”难道神所挂念的是牛吗？</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太后书 2:6; 罗马书 15:4; 罗马书 4:23–24"> 不全是为我们说的吗？分明是为我们说的。因为耕种的当存着指望去耕种，打场的也当存得粮的指望去打场。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 15:27; 加拉太书 6:6; 哥林多后书 11:15"> 我们若把属灵的种子撒在你们中间，就是从你们收割奉养肉身之物，这还算大事吗？</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 9:15; 哥林多前书 9:18; 哥林多后书 11:12"> 若别人在你们身上有这权柄，何况我们呢？然而，我们没有用过这权柄，倒凡事忍受，免得基督的福音被阻隔。</span>
</div>
</div>

## 传福音的当靠福音养生

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 18:8–20; 民数记 5:9–10; 利未记 6:26"> 你们岂不知为圣事劳碌的，就吃殿中的物吗？伺候祭坛的，就分领坛上的物吗？</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 10:10; 提摩太前书 5:17–18; 哥林多前书 9:4"> 主也是这样命定，叫传福音的靠着福音养生。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 2:9; 帖撒罗尼迦后书 3:8; 哥林多前书 9:12"> 但这权柄我全没有用过。我写这话，并非要你们这样待我，因为我宁可死，也不叫人使我所夸的落了空。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 1:14; 耶利米书 20:9; 歌罗西书 4:17"> 我传福音原没有可夸的，因为我是不得已的；若不传福音，我便有祸了。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 2:7; 哥林多前书 3:8; 历代志上 28:9"> 我若甘心做这事，就有赏赐；若不甘心，责任却已经托付我了。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 11:7–9; 哥林多前书 8:9; 帖撒罗尼迦前书 2:6"> 既是这样，我的赏赐是什么呢？就是我传福音的时候，叫人不花钱得福音，免得用尽我传福音的权柄。</span>
<span className="v" id="v19" data-v="19" data-xref="加拉太书 5:13; 马太福音 18:15; 雅各书 5:19–20"> 我虽是自由的，无人辖管，然而我甘心做了众人的仆人，为要多得人。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 16:3; 加拉太书 5:18; 使徒行传 21:20–26"> 向犹太人，我就做犹太人，为要得犹太人。向律法以下的人，我虽不在律法以下，还是做律法以下的人，为要得律法以下的人。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 2:12; 罗马书 2:14; 加拉太书 3:2"> 向没有律法的人，我就做没有律法的人，为要得没有律法的人；其实我在神面前不是没有律法，在基督面前正在律法之下。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 10:33; 罗马书 15:1; 哥林多前书 9:19"> 向软弱的人，我就做软弱的人，为要得软弱的人。向什么样的人，我就做什么样的人，无论如何总要救些人。</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太后书 2:10; 马可福音 8:35; 哥林多前书 9:25–27"> 凡我所行的，都是为福音的缘故，为要与人同得这福音的好处。</span>
</div>
</div>

## 当为不坏的冠冕赛跑

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="腓立比书 3:14; 希伯来书 12:1; 提摩太后书 4:7–8"> 岂不知在场上赛跑的都跑，但得奖赏的只有一人？你们也当这样跑，好叫你们得着奖赏。</span>
<span className="v" id="v25" data-v="25" data-xref="提摩太后书 2:5; 启示录 2:10; 提摩太后书 4:7–8"> 凡较力争胜的，诸事都有节制。他们不过是要得能坏的冠冕，我们却是要得不能坏的冠冕。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得后书 1:10; 腓立比书 1:21; 提摩太后书 2:5"> 所以，我奔跑不像无定向的，我斗拳不像打空气的。</span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 8:13; 哥林多前书 9:25; 歌罗西书 3:5"> 我是攻克己身，叫身服我，恐怕我传福音给别人，自己反被弃绝了。</span>
</div>
</div>

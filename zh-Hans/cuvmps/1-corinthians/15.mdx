## 述说基督复活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 1:6–12; 彼得前书 5:12; 哥林多前书 15:3–11"> 弟兄们，我如今把先前所传给你们的福音告诉你们知道。这福音你们也领受了，又靠着站立得住，</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 3:6; 希伯来书 2:1; 希伯来书 3:14"> 并且你们若不是徒然相信，能以持守我所传给你们的，就必因这福音得救。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得前书 2:24; 加拉太书 1:4; 以赛亚书 53:1–12"> 我当日所领受又传给你们的，第一就是：基督照圣经所说，为我们的罪死了，</span>
<span className="v" id="v4" data-v="4" data-xref="何西阿书 6:2; 马太福音 12:40; 诗篇 16:10–11"> 而且埋葬了，又照圣经所说第三天复活了；</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 16:14; 哥林多前书 1:12; 约翰福音 1:42"> 并且显给矶法看，然后显给十二使徒看；</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 28:10; 马可福音 16:7; 使徒行传 13:36"> 后来一时显给五百多弟兄看，其中一大半到如今还在，却也有已经睡了的；</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 24:50; 使徒行传 1:2–12; 路加福音 24:33"> 以后显给雅各看，再显给众使徒看；</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 9:1; 使徒行传 26:16; 使徒行传 22:18"> 末了也显给我看，我如同未到产期而生的人一般。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 3:7–8; 提摩太前书 1:13–15; 使徒行传 8:3"> 我原是使徒中最小的，不配称为使徒，因为我从前逼迫神的教会。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比书 4:13; 哥林多后书 3:5; 腓立比书 2:13"> 然而我今日成了何等人，是蒙神的恩才成的，并且他所赐我的恩不是徒然的；我比众使徒格外劳苦，这原不是我，乃是神的恩与我同在。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 15:3–4; 哥林多前书 2:2"> 不拘是我，是众使徒，我们如此传，你们也如此信了。</span>
</div>
</div>

## 基督复活做得救的凭据

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 26:8; 使徒行传 17:32; 提摩太后书 2:18"> 既传基督是从死里复活了，怎么在你们中间有人说没有死人复活的事呢？</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 11:25–26; 罗马书 8:11; 帖撒罗尼迦前书 4:14"> 若没有死人复活的事，基督也就没有复活了。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 15:17; 帖撒罗尼迦前书 4:14; 加拉太书 2:2"> 若基督没有复活，我们所传的便是枉然，你们所信的也是枉然。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 2:24; 约伯记 13:7–10; 使徒行传 2:32"> 并且明显我们是为神妄作见证的，因我们见证神是叫基督复活了；若死人真不复活，神也就没有叫基督复活了。</span>
<span className="v" id="v16" data-v="16"> 因为死人若不复活，基督也就没有复活了。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 4:25; 彼得前书 1:3; 哥林多前书 15:14"> 基督若没有复活，你们的信便是徒然，你们仍在罪里。</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 4:13–14; 启示录 14:13; 帖撒罗尼迦前书 4:16"> 就是在基督里睡了的人，也灭亡了。</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前书 1:21; 启示录 14:13; 提摩太后书 1:12"> 我们若靠基督只在今生有指望，就算比众人更可怜！</span>
</div>
</div>

## 在基督里都要复活

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 15:23; 使徒行传 26:23; 启示录 1:5"> 但基督已经从死里复活，成为睡了之人初熟的果子。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 11:25; 罗马书 5:12–17; 哥林多前书 15:22"> 死既是因一人而来，死人复活也是因一人而来。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 5:12–21; 哥林多前书 15:45–49; 约翰福音 5:21–29"> 在亚当里众人都死了，照样，在基督里众人也都要复活。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 26:19; 加拉太书 3:29; 哥林多前书 15:52"> 但各人是按着自己的次序复活：初熟的果子是基督，以后在他来的时候，是那些属基督的。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理书 7:27; 但以理书 7:14; 马太福音 28:18"> 再后末期到了，那时基督既将一切执政的、掌权的、有能的都毁灭了，就把国交于父神。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 10:12–13; 诗篇 110:1; 马太福音 22:44"> 因为基督必要做王，等神把一切仇敌都放在他的脚下。</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太后书 1:10; 哥林多前书 15:55; 启示录 21:4"> 尽末了所毁灭的仇敌就是死，</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 8:6; 希伯来书 2:8; 马太福音 28:18"> 因为经上说：“神叫万物都服在他的脚下。”既说万物都服了他，明显那叫万物服他的不在其内了。</span>
<span className="v" id="v28" data-v="28" data-xref="歌罗西书 3:11; 哥林多前书 3:23; 以弗所书 1:23"> 万物既服了他，那时子也要自己服那叫万物服他的，叫神在万物之上、为万物之主。</span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="罗马书 6:3–4; 哥林多前书 15:16; 马太福音 20:22"> 不然，那些为死人受洗的将来怎样呢？若死人总不复活，因何为他们受洗呢？</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多后书 6:9; 加拉太书 5:11; 哥林多后书 4:7–12"> 我们又因何时刻冒险呢？</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多后书 4:10–11; 罗马书 8:36; 哥林多前书 4:9–13"> 弟兄们，我在我主基督耶稣里指着你们所夸的口极力地说：我是天天冒死！</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 22:13; 以赛亚书 56:12; 路加福音 12:19"> 我若当日像寻常人在以弗所同野兽战斗，那于我有什么益处呢？若死人不复活，<br /><span className="pl pl-1">“我们就吃吃喝喝吧！</span><br /><span className="pl pl-1">因为明天要死了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="箴言 13:20; 马太福音 24:4; 哥林多前书 5:6"> 你们不要自欺，滥交是败坏善行。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 6:5; 罗马书 13:11; 希伯来书 5:11–12"> 你们要醒悟为善，不要犯罪，因为有人不认识神。我说这话是要叫你们羞愧！</span>
</div>
</div>

## 论复活之体如何

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="以西结书 37:3; 哥林多前书 15:38–53; 罗马书 9:19"> 或有人问：“死人怎样复活，带着什么身体来呢？”</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 12:24; 路加福音 11:40; 以弗所书 5:15"> 无知的人哪！你所种的，若不死就不能生。</span>
<span className="v" id="v37" data-v="37"> 并且你所种的不是那将来的形体，不过是子粒，即如麦子，或是别样的谷；</span>
<span className="v" id="v38" data-v="38" data-xref="哥林多前书 3:7; 以赛亚书 61:11; 马可福音 4:26–29"> 但神随自己的意思给它一个形体，并叫各等子粒各有自己的形体。</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 1:20–26"> 凡肉体各有不同：人是一样，兽又是一样，鸟又是一样，鱼又是一样。</span>
<span className="v" id="v40" data-v="40"> 有天上的形体，也有地上的形体；但天上形体的荣光是一样，地上形体的荣光又是一样。</span>
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 24:23; 诗篇 148:3–5; 申命记 4:19"> 日有日的荣光，月有月的荣光，星有星的荣光，这星和那星的荣光也有分别。</span>
<span className="v" id="v42" data-v="42" data-xref="马太福音 13:43; 但以理书 12:3; 罗马书 8:21"> 死人复活也是这样：所种的是必朽坏的，复活的是不朽坏的；</span>
<span className="v" id="v43" data-v="43" data-xref="哥林多前书 6:14; 歌罗西书 3:4; 腓立比书 3:20–21"> 所种的是羞辱的，复活的是荣耀的；所种的是软弱的，复活的是强壮的；</span>
<span className="v" id="v44" data-v="44" data-xref="哥林多前书 15:50; 路加福音 24:31; 约翰福音 20:19"> 所种的是血气的身体，复活的是灵性的身体。若有血气的身体，也必有灵性的身体。</span>
<span className="v" id="v45" data-v="45" data-xref="约翰福音 5:21; 创世记 2:7; 罗马书 8:2"> 经上也是这样记着说，首先的人亚当成了有灵<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“灵”或作“血气”。">a</a></sup>的活人，末后的亚当成了叫人活的灵。</span>
<span className="v" id="v46" data-v="46" data-xref="歌罗西书 3:9–10; 罗马书 6:6; 以弗所书 4:22–24"> 但属灵的不在先，属血气的在先，以后才有属灵的。</span>
<span className="v" id="v47" data-v="47" data-xref="约翰福音 3:31; 创世记 2:7; 创世记 3:19"> 头一个人是出于地，乃属土；第二个人是出于天。</span>
<span className="v" id="v48" data-v="48" data-xref="创世记 5:3; 罗马书 5:12–21; 约翰福音 3:6"> 那属土的怎样，凡属土的也就怎样；属天的怎样，凡属天的也就怎样。</span>
<span className="v" id="v49" data-v="49" data-xref="罗马书 8:29; 哥林多后书 3:18; 创世记 5:3"> 我们既有属土的形状，将来也必有属天的形状。</span>
</div>
</div>

## 血肉之体不能承受神的国

<div className="bt">
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="约翰福音 3:3–6; 马太福音 16:17; 以弗所书 4:17"> 弟兄们，我告诉你们说，血肉之体不能承受神的国，必朽坏的不能承受不朽坏的。</span>
<span className="v" id="v51" data-v="51" data-xref="帖撒罗尼迦前书 4:14–17; 腓立比书 3:21; 哥林多前书 15:20"> 我如今把一件奥秘的事告诉你们：我们不是都要睡觉，乃是都要改变，</span>
<span className="v" id="v52" data-v="52" data-xref="帖撒罗尼迦前书 4:16–17; 马太福音 24:31; 约翰福音 5:28"> 就在一霎时，眨眼之间，号筒末次吹响的时候。因号筒要响，死人要复活成为不朽坏的，我们也要改变。</span>
<span className="v" id="v53" data-v="53" data-xref="哥林多后书 5:2–4; 约翰一书 3:2; 罗马书 2:7"> 这必朽坏的总要变成<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“变成”原文作“穿”，下同。">b</a></sup>不朽坏的，这必死的总要变成不死的。</span>
<span className="v" id="v54" data-v="54" data-xref="以赛亚书 25:8; 启示录 20:14; 希伯来书 2:14–15"> 这必朽坏的既变成不朽坏的，这必死的既变成不死的，那时经上所记“死被得胜吞灭”的话就应验了。</span>
</div>
</div>

## 罪是死的毒钩唯独靠基督得胜

<div className="bt">
<div className="bp poetry">
<span className="v" id="v55" data-v="55" data-xref="何西阿书 13:14; 诗篇 89:48; 使徒行传 2:27"> <span className="pl pl-1">“死啊，你得胜的权势在哪里？</span><br /><span className="pl pl-1">死啊，你的毒钩在哪里？”</span></span>
</div>
<div className="bp">
<span className="v" id="v56" data-v="56" data-xref="罗马书 4:15; 加拉太书 3:10–13; 罗马书 7:5–13"> 死的毒钩就是罪，罪的权势就是律法。</span>
<span className="v" id="v57" data-v="57" data-xref="哥林多后书 2:14; 罗马书 8:37; 约翰一书 5:4–5"> 感谢神，使我们藉着我们的主耶稣基督得胜！</span>
<span className="v" id="v58" data-v="58" data-xref="加拉太书 6:9; 历代志下 15:7; 希伯来书 6:10"> 所以，我亲爱的弟兄们，你们务要坚固，不可摇动，常常竭力多做主工，因为知道，你们的劳苦在主里面不是徒然的。</span>
</div>

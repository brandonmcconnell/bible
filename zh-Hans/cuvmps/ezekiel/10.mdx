## 见火炭

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 24:10; 启示录 4:2–3; 启示录 1:13"> 我观看，见基路伯头上的穹苍之中显出蓝宝石的形状，仿佛宝座的形像。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 8:5; 以西结书 10:16; 以西结书 1:13"> 主对那穿细麻衣的人说：“你进去，在旋转的轮内，基路伯以下，从基路伯中间将火炭取满两手，撒在城上。”我就见他进去。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 43:4; 以西结书 9:3; 以西结书 8:16"> 那人进去的时候，基路伯站在殿的右边，云彩充满了内院。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 1:28; 以西结书 9:3; 出埃及记 40:35"> 耶和华的荣耀从基路伯那里上升，停在门槛以上。殿内满了云彩，院宇也被耶和华荣耀的光辉充满。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 1:24; 约伯记 40:9; 出埃及记 19:16"> 基路伯翅膀的响声听到外院，好像全能神说话的声音。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 10:2; 诗篇 99:1; 诗篇 80:1"> 他吩咐那穿细麻衣的人说：“要从旋转的轮内、基路伯中间取火。”那人就进去站在一个轮子旁边。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 13:41–42; 以西结书 1:13; 以西结书 41:23–26"> 有一个基路伯从基路伯中伸手到基路伯中间的火那里，取些放在那穿细麻衣的人两手中，那人就拿出去了。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 1:8; 以西结书 10:21; 以赛亚书 6:6"> 在基路伯翅膀之下显出有人手的样式。</span>
</div>
</div>

## 又见四轮

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以西结书 1:15–17; 但以理书 10:6; 启示录 21:20"> 我又观看，见基路伯旁边有四个轮子。这基路伯旁有一个轮子，那基路伯旁有一个轮子，每基路伯都是如此，轮子的颜色<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：形状。">a</a></sup>仿佛水苍玉。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 1:16; 诗篇 36:6; 诗篇 104:24"> 至于四轮的形状，都是一个样式，仿佛轮中套轮。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 1:17; 以西结书 10:22; 以西结书 1:20"> 轮行走的时候，向四方都能直行，并不掉转。头向何方，他们也随向何方，行走的时候并不掉转。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 1:18; 启示录 4:8; 启示录 4:6"> 他们全身，连背带手和翅膀，并轮周围都满了眼睛，这四个基路伯的轮子都是如此。</span>
<span className="v" id="v13" data-v="13"> 至于这些轮子，我耳中听见说是旋转的。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 4:7; 以西结书 10:21; 列王纪上 7:36"> 基路伯各有四脸，第一是基路伯的脸，第二是人的脸，第三是狮子的脸，第四是鹰的脸。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西结书 1:5; 何西阿书 9:12; 以西结书 11:22"> 基路伯升上去了，这是我在迦巴鲁河边所见的活物。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 1:19–21"> 基路伯行走，轮也在旁边行走；基路伯展开翅膀，离地上升，轮也不转离他们旁边。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 1:20–21; 罗马书 8:2; 以西结书 1:12"> 那些站住，这些也站住，那些上升，这些也一同上升，因为活物的灵在轮中。</span>
</div>
</div>

## 耶和华之荣耀离殿止于基路伯

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="诗篇 18:10; 马太福音 23:37–39; 诗篇 78:60–61"> 耶和华的荣耀从殿的门槛那里出去，停在基路伯以上。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 8:16; 以西结书 1:17–21; 以西结书 1:26–28"> 基路伯出去的时候，就展开翅膀，在我眼前离地上升，轮也在他们的旁边，都停在耶和华殿的东门口。在他们以上有以色列神的荣耀。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西结书 1:1; 以西结书 10:15; 列王纪上 7:36"> 这是我在迦巴鲁河边所见以色列神荣耀以下的活物，我就知道他们是基路伯。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 1:6; 以西结书 41:18–19; 以西结书 10:14"> 各有四个脸面，四个翅膀，翅膀以下有人手的样式。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 10:11; 以西结书 1:10; 以西结书 1:12"> 至于他们脸的模样并身体的形像，是我从前在迦巴鲁河边所看见的。他们俱各直往前行。</span>
</div>
</div>

## 以色列长老咨诹耶和华不蒙启示

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 8:1; 以西结书 30:20; 以西结书 24:1"> 第七年五月初十日，有以色列的几个长老来求问耶和华，坐在我面前。</span>
<span className="v" id="v2" data-v="2"> 耶和华的话临到我说：</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 28:9; 马太福音 15:8–9; 诗篇 50:15–21"> “人子啊，你要告诉以色列的长老说：‘主耶和华如此说：你们来是求问我吗？主耶和华说：我指着我的永生起誓，我必不被你们求问。’</span>

## 追述以色列人在埃及之违逆

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以西结书 22:2; 以西结书 23:36; 以西结书 14:20"> “人子啊，你要审问审问他们吗？你当使他们知道他们列祖那些可憎的事，</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 7:6; 以西结书 20:15; 出埃及记 3:8"> 对他们说：‘主耶和华如此说：当日我拣选以色列，向雅各家的后裔起誓，在埃及地将自己向他们显现，说：“我是耶和华你们的神。”</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 3:8; 耶利米书 32:22; 以西结书 20:15"> 那日我向他们起誓，必领他们出埃及地，到我为他们察看的流奶与蜜之地，那地在万国中是有荣耀的。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 18:3; 以西结书 20:8; 利未记 11:44"> 我对他们说：“你们各人要抛弃眼所喜爱那可憎之物，不可因埃及的偶像玷污自己。我是耶和华你们的神。”</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 20:7; 以赛亚书 63:10; 以西结书 20:21"> 他们却悖逆我，不肯听从我，不抛弃他们眼所喜爱那可憎之物，不离弃埃及的偶像。我就说，我要将我的愤怒倾在他们身上，在埃及地向他们成就我怒中所定的。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 39:7; 以西结书 20:22; 出埃及记 32:12"> 我却为我名的缘故没有这样行，免得我名在他们所住的列国人眼前被亵渎。我领他们出埃及地，在这列国人的眼前将自己向他们显现。</span>
</div>
</div>

## 在旷野之违逆

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及记 15:22; 出埃及记 13:17–18; 出埃及记 14:17–22"> ‘这样，我就使他们出埃及地，领他们到旷野，</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 10:5; 利未记 18:5; 申命记 4:8"> 将我的律例赐给他们，将我的典章指示他们——人若遵行，就必因此活着。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 20:20; 以西结书 37:28; 利未记 21:23"> 又将我的安息日赐给他们，好在我与他们中间为证据，使他们知道我耶和华是叫他们成为圣的。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 20:21; 以西结书 20:8; 以赛亚书 56:6"> 以色列家却在旷野悖逆我，不顺从我的律例，厌弃我的典章——人若遵行，就必因此活着——大大干犯我的安息日。我就说，要在旷野将我的愤怒倾在他们身上，灭绝他们。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 20:9; 以西结书 36:22–23; 以西结书 20:22"> 我却为我名的缘故没有这样行，免得我的名在我领他们出埃及的列国人眼前被亵渎。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 95:11; 诗篇 106:26; 希伯来书 3:18"> 并且我在旷野向他们起誓，必不领他们进入我所赐给他们流奶与蜜之地，那地在万国中是有荣耀的。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 15:39; 以西结书 20:8; 以西结书 14:3–4"> 因为他们厌弃我的典章，不顺从我的律例，干犯我的安息日，他们的心随从自己的偶像。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 11:13; 耶利米书 4:27; 耶利米书 5:18"> 虽然如此，我眼仍顾惜他们，不毁灭他们，不在旷野将他们灭绝净尽。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒迦利亚书 1:2–4; 诗篇 78:6–8; 彼得前书 1:18"> ‘我在旷野对他们的儿女说：“不要遵行你们父亲的律例，不要谨守他们的恶规，也不要因他们的偶像玷污自己。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 36:27; 申命记 5:32–8; 以西结书 37:24"> 我是耶和华你们的神，你们要顺从我的律例，谨守遵行我的典章，</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 58:13; 耶利米书 17:22; 出埃及记 31:13–17"> 且以我的安息日为圣。这日在我与你们中间为证据，使你们知道我是耶和华你们的神。”</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 20:13; 民数记 21:5; 以西结书 20:8"> 只是他们的儿女悖逆我，不顺从我的律例，也不谨守遵行我的典章——人若遵行，就必因此活着——干犯我的安息日。我就说，要将我的愤怒倾在他们身上，在旷野向他们成就我怒中所定的。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 20:14; 以西结书 20:9; 耶利米书 14:21"> 虽然如此，我却为我名的缘故缩手没有这样行，免得我的名在我领他们出埃及的列国人眼前被亵渎。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 26:33; 申命记 28:64–68; 申命记 32:26–27"> 并且我在旷野向他们起誓，必将他们分散在列国，四散在列邦。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 20:16; 以西结书 6:9; 阿摩司书 2:4"> 因为他们不遵行我的典章，竟厌弃我的律例，干犯我的安息日，眼目仰望他们父亲的偶像。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 81:12; 以赛亚书 66:4; 以西结书 20:39"> 我也任他们遵行不美的律例，谨守不能使人活着的恶规。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 6:7; 利未记 18:21; 以西结书 20:31"> 因他们将一切头生的经火，我就任凭他们在这供献的事上玷污自己，好叫他们凄凉，使他们知道我是耶和华。’</span>
</div>
</div>

## 在迦南之违逆

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="罗马书 2:24; 以西结书 2:7; 以西结书 3:11"> “人子啊，你要告诉以色列家说：‘主耶和华如此说：你们的列祖在得罪我的事上亵渎我，</span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 6:13; 尼希米记 9:22–26; 耶利米书 3:6"> 因为我领他们到了我起誓应许赐给他们的地，他们看见各高山、各茂密树，就在那里献祭，奉上惹我发怒的供物，也在那里焚烧馨香的祭牲，并浇上奠祭。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 16:24–25; 以西结书 16:31"> 我就对他们说：“你们所上的那高处叫什么呢？”那高处的名字叫巴麻，直到今日。’</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 16:12; 耶利米书 7:26; 士师记 2:19"> 所以你要对以色列家说：‘主耶和华如此说：你们仍照你们列祖所行的玷污自己吗？仍照他们可憎的事行邪淫吗？</span>
<span className="v" id="v31" data-v="31" data-xref="以西结书 20:26; 诗篇 106:37–39; 耶利米书 7:31"> 你们奉上供物使你们儿子经火的时候，仍将一切偶像玷污自己，直到今日吗？以色列家啊，我岂被你们求问吗？主耶和华说：我指着我的永生起誓，我必不被你们求问。</span>
<span className="v" id="v32" data-v="32" data-xref="以西结书 11:5; 耶利米书 44:17; 诗篇 139:2"> 你们说“我们要像外邦人和列国的宗族一样，去侍奉木头与石头”，你们所起的这心意万不能成就。</span>
</div>
</div>

## 许以必由散居之国导返故土

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="耶利米书 21:5; 以西结书 8:18; 耶利米书 44:6"> ‘主耶和华说：我指着我的永生起誓，我总要做王，用大能的手和伸出来的膀臂，并倾出来的愤怒，治理你们。</span>
<span className="v" id="v34" data-v="34" data-xref="以西结书 20:38; 阿摩司书 9:9–10; 以西结书 34:16"> 我必用大能的手和伸出来的膀臂，并倾出来的愤怒，将你们从万民中领出来，从分散的列国内聚集你们。</span>
<span className="v" id="v35" data-v="35" data-xref="何西阿书 2:14; 耶利米书 2:35; 以西结书 17:20"> 我必带你们到外邦人的旷野，在那里当面刑罚你们。</span>
<span className="v" id="v36" data-v="36" data-xref="哥林多前书 10:5–10; 民数记 11:1–35; 以西结书 20:13"> 我怎样在埃及地的旷野刑罚你们的列祖，也必照样刑罚你们。这是主耶和华说的。</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 33:13; 利未记 27:32; 马太福音 25:32–33"> 我必使你们从杖下经过，使你们被约拘束。</span>
<span className="v" id="v38" data-v="38" data-xref="以西结书 13:9; 阿摩司书 9:9–10; 诗篇 95:11"> 我必从你们中间除净叛逆和得罪我的人，将他们从所寄居的地方领出来，他们却不得入以色列地，你们就知道我是耶和华。</span>
<span className="v" id="v39" data-v="39" data-xref="何西阿书 4:17; 以赛亚书 1:13–15; 以西结书 43:7"> 以色列家啊，至于你们，主耶和华如此说：从此以后若不听从我，就任凭你们去侍奉偶像，只是不可再因你们的供物和偶像亵渎我的圣名。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="以赛亚书 56:7; 玛拉基书 3:4; 以赛亚书 60:7"> ‘主耶和华说：在我的圣山，就是以色列高处的山，所有以色列的全家都要侍奉我。我要在那里悦纳你们，向你们要供物和初熟的土产，并一切的圣物。</span>
<span className="v" id="v41" data-v="41" data-xref="以西结书 28:25; 以西结书 11:17; 以西结书 38:23"> 我从万民中领你们出来，从分散的列国内聚集你们，那时我必悦纳你们好像馨香之祭，要在外邦人眼前，在你们身上显为圣。</span>
<span className="v" id="v42" data-v="42" data-xref="以西结书 34:13; 以西结书 38:23; 以西结书 36:23–24"> 我领你们进入以色列地，就是我起誓应许赐给你们列祖之地，那时你们就知道我是耶和华。</span>
<span className="v" id="v43" data-v="43" data-xref="以西结书 6:9; 何西阿书 5:15; 耶利米书 31:18"> 你们在那里要追念玷污自己的行动作为，又要因所做的一切恶事厌恶自己。</span>
<span className="v" id="v44" data-v="44" data-xref="以西结书 24:24; 诗篇 115:1; 以西结书 20:9"> 主耶和华说：以色列家啊，我为我名的缘故，不照着你们的恶行和你们的坏事待你们，你们就知道我是耶和华。’”</span>
</div>
</div>

## 以林木见焚为喻

<div className="bt">
<div className="bp">
<span className="v" id="v45" data-v="45"> 耶和华的话临到我说：</span>
<span className="v" id="v46" data-v="46" data-xref="阿摩司书 7:16; 以西结书 21:2; 耶利米书 13:19"> “人子啊，你要面向南方，向南滴下预言攻击南方田野的树林。</span>
<span className="v" id="v47" data-v="47" data-xref="耶利米书 21:14; 以赛亚书 24:1–6; 以西结书 17:24"> 对南方的树林说：‘要听耶和华的话！主耶和华如此说：我必使火在你中间着起，烧灭你中间的一切青树和枯树，猛烈的火焰必不熄灭。从南到北，人的脸面都被烧焦。</span>
<span className="v" id="v48" data-v="48" data-xref="耶利米书 40:2–3; 耶利米书 7:20; 申命记 29:24–28"> 凡有血气的都必知道，是我耶和华使火着起，这火必不熄灭。’”</span>
<span className="v" id="v49" data-v="49" data-xref="约翰福音 16:25; 使徒行传 17:18; 以西结书 17:2"> 于是我说：“哎，主耶和华啊！人都指着我说：‘他岂不是说比喻的吗？’”</span>
</div>

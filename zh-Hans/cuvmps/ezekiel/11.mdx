## 申述其罪与罚

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="耶利米书 17:10; 耶利米书 16:17; 启示录 2:23"> 耶和华的灵降在我身上，对我说：“你当说：‘耶和华如此说：以色列家啊，你们口中所说的，心里所想的，我都知道。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 7:23; 以西结书 22:27; 以西结书 22:12"> 你们在这城中杀人增多，使被杀的人充满街道。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 24:3–13; 弥迦书 3:2–3; 列王纪下 25:18–22"> 所以主耶和华如此说：“你们杀在城中的人就是肉，这城就是锅，你们却要从其中被带出去。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 10:24; 以赛亚书 24:17–18; 约伯记 3:25"> 你们怕刀剑，我必使刀剑临到你们。”这是主耶和华说的。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 5:8; 诗篇 106:41; 申命记 28:36"> 我必从这城中带出你们去，交在外邦人的手中，且要在你们中间施行审判。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 14:25; 耶利米书 52:9–10; 列王纪下 25:19–21"> 你们必倒在刀下，我必在以色列的境界审判你们，你们就知道我是耶和华。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 11:3; 以西结书 11:7–10"> 这城必不做你们的锅，你们也不做其中的肉。我必在以色列的境界审判你们，</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 8:10; 以西结书 8:16; 以西结书 8:14"> 你们就知道我是耶和华。因为你们没有遵行我的律例，也没有顺从我的典章，却随从你们四围列国的恶规。’”</span>
</div>
</div>

## 耶和华谕以悔改者必得拯救旋返故土

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14"> 耶和华的话临到我说：</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 33:24; 以赛亚书 65:5; 约翰福音 16:2"> “人子啊，耶路撒冷的居民对你的弟兄、你的本族、你的亲属、以色列全家，就是对大众说：‘你们远离耶和华吧！这地是赐给我们为业的。’</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 8:14; 申命记 30:3–4; 诗篇 90:1"> 所以你当说：‘耶和华如此说：我虽将以色列全家远远迁移到列国中，将他们分散在列邦内，我还要在他们所到的列邦暂做他们的圣所。’</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 28:25; 耶利米书 3:18; 以西结书 34:13"> 你当说：‘主耶和华如此说：我必从万民中招聚你们，从分散的列国内聚集你们，又要将以色列地赐给你们。’</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 37:23; 以西结书 5:11; 以西结书 42:7–8"> 他们必到那里，也必从其中除掉一切可憎可厌的物。</span>
</div>
</div>

## 去其石心赐以肉心

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西结书 36:26–27; 耶利米书 31:33; 诗篇 51:10"> “我要使他们有合一的心，也要将新灵放在他们里面，又从他们肉体中除掉石心，赐给他们肉心，</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 14:11; 诗篇 105:45; 耶利米书 30:22"> 使他们顺从我的律例，谨守遵行我的典章。他们要做我的子民，我要做他们的神。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 9:10; 传道书 11:9; 耶利米书 1:16"> 至于那些心中随从可憎可厌之物的，我必照他们所行的报应在他们头上。这是主耶和华说的。”</span>
</div>
</div>

<div className="bp">

<span className="v" id="v23" data-v="23" data-xref="撒迦利亚书 14:4; 以西结书 8:4; 以西结书 10:4"> 耶和华的荣耀从城中上升，停在城东的那座山上。</span>

<span className="v" id="v25" data-v="25" data-xref="以西结书 3:4; 以西结书 3:27; 以西结书 3:17"> 我便将耶和华所指示我的一切事都说给被掳的人听。</span>

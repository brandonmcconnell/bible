## 预言歌革受灾之重

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话临到我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 39:1; 以西结书 27:13; 以西结书 38:3"> “人子啊，你要面向玛各地的歌革，就是罗施、米设、土巴的王发预言攻击他，</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 13:8; 以西结书 39:1–10; 以西结书 29:3"> 说：‘主耶和华如此说：罗施、米设、土巴的王歌革啊，我与你为敌。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 29:4; 但以理书 11:40; 以西结书 38:15"> 我必用钩子钩住你的腮颊，调转你，将你和你的军兵、马匹、马兵带出来，都披挂整齐，成了大队，有大小盾牌，各拿刀剑。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 27:10; 创世记 10:6; 以西结书 30:5"> 波斯人、古实人和弗人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="又作：吕彼亚人。">a</a></sup>各拿盾牌，头上戴盔，</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 27:14; 创世记 10:2–3; 历代志上 1:5–6"> 歌篾人和他的军队，北方极处的陀迦玛族和他的军队，这许多国的民都同着你。</span>
</div>
</div>

## 述其暴行

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志下 25:8; 约珥书 3:9–12; 以赛亚书 37:22"> ‘那聚集到你这里的各队都当准备，你自己也要准备，做他们的大帅。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 38:16; 以赛亚书 24:22; 以西结书 38:11–12"> 过了多日，你必被差派。到末后之年，你必来到脱离刀剑从列国收回之地，到以色列长久荒凉的山上。但那从列国中招聚出来的，必在其上安然居住。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 28:2; 耶利米书 4:13; 约珥书 2:2"> 你和你的军队，并同着你许多国的民，必如暴风上来，如密云遮盖地面。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="诗篇 36:4; 弥迦书 2:1; 诗篇 83:3–4"> ‘主耶和华如此说：到那时，你心必起意念，图谋恶计，</span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亚书 2:4–5; 箴言 3:29–30; 耶利米书 49:31–32"> 说：“我要上那无城墙的乡村，我要到那安静的民那里，他们都没有城墙，无门无闩，安然居住。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 10:6; 以西结书 38:8; 以西结书 29:19"> 我去要抢财为掳物，夺货为掠物，反手攻击那从前荒凉，现在有人居住之地，又攻击那住世界中间，从列国招聚，得了牲畜财货的民。”</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 27:15; 以西结书 27:22–23; 以西结书 32:2"> 示巴人、底但人、他施的客商和其间的少壮狮子都必问你说：“你来要抢财为掳物吗？你聚集军队要夺货为掠物吗？要夺取金银，掳去牲畜、财货吗？要抢夺许多财宝为掳物吗？”’</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西结书 38:8; 撒迦利亚书 2:5; 耶利米书 23:6"> “人子啊，你要因此发预言，对歌革说：‘主耶和华如此说：到我民以色列安然居住之日，你岂不知道吗？</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 39:2; 以西结书 38:6; 启示录 20:8"> 你必从本地，从北方的极处率领许多国的民来，都骑着马，乃一大队极多的军兵。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 39:21; 以西结书 38:23; 何西阿书 3:5"> 歌革啊，你必上来攻击我的民以色列，如密云遮盖地面。末后的日子，我必带你来攻击我的地，到我在外邦人眼前，在你身上显为圣的时候，好叫他们认识我。</span>
</div>
</div>

## 受主烈怒

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="但以理书 11:40–45; 以赛亚书 63:1–6; 约珥书 3:9–14"> ‘主耶和华如此说：我在古时藉我的仆人以色列的先知所说的，就是你吗？当日他们多年预言我必带你来攻击以色列人。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 36:5–6; 希伯来书 12:29; 诗篇 89:46"> 主耶和华说：歌革上来攻击以色列地的时候，我的怒气要从鼻孔里发出。</span>
<span className="v" id="v19" data-v="19" data-xref="哈该书 2:6–7; 启示录 11:13; 启示录 16:20"> 我发愤恨和烈怒如火说，那日在以色列地必有大震动，</span>
<span className="v" id="v20" data-v="20" data-xref="何西阿书 4:3; 那鸿书 1:4–6; 启示录 6:12–13"> 甚至海中的鱼、天空的鸟、田野的兽，并地上的一切昆虫和其上的众人，因见我的面就都震动。山岭必崩裂，陡岩必塌陷，墙垣都必坍倒。</span>
<span className="v" id="v21" data-v="21" data-xref="哈该书 2:22; 士师记 7:22; 以西结书 14:17"> 主耶和华说：我必命我的诸山发刀剑来攻击歌革，人都要用刀剑杀害弟兄。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 66:16; 诗篇 11:6; 启示录 16:21"> 我必用瘟疫和流血的事刑罚他，我也必将暴雨、大雹与火并硫磺降于他和他的军队，并他所率领的众民。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 9:16; 启示录 19:1–6; 以西结书 38:16"> 我必显为大，显为圣，在多国人的眼前显现，他们就知道我是耶和华。’</span>
</div>
</div>

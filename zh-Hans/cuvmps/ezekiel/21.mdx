## 耶和华拔刃击以色列地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话临到我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 20:46; 以西结书 4:7; 以西结书 25:2"> “人子啊，你要面向耶路撒冷和圣所滴下预言攻击以色列地，</span>
<span className="v" id="v3" data-v="3" data-xref="约伯记 9:22; 耶利米书 21:13; 以西结书 5:8"> 对以色列地说：‘耶和华如此说：我与你为敌，并要拔刀出鞘，从你中间将义人和恶人一并剪除。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 20:47; 以西结书 7:2; 以西结书 6:11–14"> 我既要从你中间剪除义人和恶人，所以我的刀要出鞘，自南至北攻击一切有血气的。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 21:30; 那鸿书 1:9; 撒母耳记上 3:12"> 一切有血气的就知道，我耶和华已经拔刀出鞘，必不再入鞘。’</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 22:4; 以西结书 6:11; 耶利米书 19:10"> 人子啊，你要叹息，在他们眼前弯着腰，苦苦地叹息。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 7:17; 以西结书 7:26; 以赛亚书 13:7"> 他们问你说：‘为何叹息呢？’你就说：‘因为有风声，灾祸要来。人心都必消化，手都发软，精神衰败，膝弱如水。看哪！这灾祸临近，必然成就。’这是主耶和华说的。”</span>
</div>
</div>

## 预言有刃临于以色列之牧伯及民

<div className="bt">
<div className="bp poetry">
<span className="v" id="v8" data-v="8"> 耶和华的话临到我说：</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 34:5–6; 以西结书 21:28; 以西结书 21:3"> “人子啊，你要预言：‘耶和华吩咐我如此说：<br /><span className="pl pl-1">有刀，有刀，</span><br /><span className="pl pl-1">是磨快擦亮的！</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 110:5–6; 以西结书 20:47; 以西结书 21:25–27"> <span className="pl pl-1">磨快为要行杀戮，</span><br /><span className="pl pl-1">擦亮为要像闪电！</span><br />我们岂可快乐吗？罚我子的杖藐视各树。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 21:19; 耶利米书 25:33; 耶利米书 51:20–23"> 这刀已经交给人擦亮，为要应手使用；这刀已经磨快擦亮，好交在行杀戮的人手中。’</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 21:6; 约珥书 1:13; 以西结书 21:14"> 人子啊，你要呼喊、哀号，因为这刀临到我的百姓和以色列一切的首领。他们和我的百姓都交在刀下，所以你要拍腿叹息。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 21:10; 哥林多后书 8:2; 以西结书 21:25"> 有试验的事：若那藐视的杖归于无有，怎么样呢？这是主耶和华说的。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 24:1; 民数记 24:10; 利未记 26:24"> 人子啊，你要拍掌预言。我耶和华要使这刀，就是致死伤的刀，一连三次加倍刺人，进入他们的内屋，使大人受死伤的就是这刀。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 21:10; 耶利米书 17:27; 以西结书 21:22"> 我设立这恐吓人的刀，攻击他们的一切城门，使他们的心消化，加增他们跌倒的事。哎！这刀造得像闪电，磨得尖利，要行杀戮。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 21:20; 以西结书 21:4; 以西结书 14:17"> 刀啊，你归在右边，摆在左边，你面向哪方，就向哪方杀戮。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 5:13; 以西结书 21:14; 撒迦利亚书 6:8"> 我也要拍掌，并要使我的愤怒止息。这是我耶和华说的。”</span>
</div>
</div>

## 预言巴比伦王必击拉巴及耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18"> 耶和华的话又临到我说：</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 4:1–3; 耶利米书 1:10; 以西结书 5:1–17"> “人子啊，你要定出两条路，好使巴比伦王的刀来。这两条路必从一地分出来，又要在通城的路口上画出一只手来。</span>
<span className="v" id="v20" data-v="20" data-xref="阿摩司书 1:14; 耶利米书 49:2; 以西结书 25:5"> 你要定出一条路，使刀来到亚扪人的拉巴，又要定出一条路，使刀来到犹大的坚固城耶路撒冷。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 18:20; 箴言 16:33; 士师记 17:5"> 因为巴比伦王站在岔路那里，在两条路口上要占卜。他摇签<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：箭。">a</a></sup>求问神像，察看牺牲的肝。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 4:2; 以西结书 26:9; 耶利米书 51:14"> 在右手中拿着为耶路撒冷占卜的签，使他安设撞城锤，张口叫杀，扬声呐喊，筑垒造台，以撞城锤，攻打城门。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 5:15; 以西结书 21:24; 以西结书 29:16"> 据那些曾起誓的犹大人看来，这是虚假的占卜，但巴比伦王要使他们想起罪孽，以致将他们捉住。</span>
</div>
</div>

## 以色列君必因罪受罚

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="何西阿书 4:2; 弥迦书 3:10–12; 耶利米书 3:2"> “主耶和华如此说：因你们的过犯显露，使你们的罪孽被记念，以致你们的罪恶在行为上都彰显出来。又因你们被记念，就被捉住。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 35:5; 以西结书 21:29; 以西结书 17:19"> 你这受死伤行恶的以色列王啊，罪孽的尽头到了，受报的日子已到。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 17:24; 诗篇 75:7; 耶利米书 13:18"> 主耶和华如此说：当除掉冠，摘下冕，景况必不再像先前。要使卑者升为高，使高者降为卑。</span>
<span className="v" id="v27" data-v="27" data-xref="弥迦书 5:2; 耶利米书 23:5–6; 撒迦利亚书 9:9"> 我要将这国倾覆，倾覆，而又倾覆。这国也必不再有，直等到那应得的人来到，我就赐给他。</span>
</div>
</div>

## 亚扪人亦将遭报

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以西结书 21:20; 以西结书 21:9–10; 西番雅书 2:8–10"> “人子啊，要发预言说：‘主耶和华论到亚扪人和他们的凌辱，吩咐我如此说：有刀，有拔出来的刀，已经擦亮，为行杀戮，使它像闪电以行吞灭。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 21:25; 以西结书 22:28; 诗篇 37:13"> 人为你见虚假的异象，行谎诈的占卜，使你倒在受死伤之恶人的颈项上。他们罪孽到了尽头，受报的日子已到。</span>
<span className="v" id="v30" data-v="30" data-xref="以西结书 16:38; 创世记 15:14; 耶利米书 47:6–7"> 你将刀收入鞘吧！在你受造之处，生长之地，我必刑罚你。</span>
<span className="v" id="v31" data-v="31" data-xref="那鸿书 1:6; 耶利米书 6:22–23; 以西结书 14:19"> 我必将我的恼恨倒在你身上，将我烈怒的火喷在你身上，又将你交在善于杀灭的畜类人手中。</span>
<span className="v" id="v32" data-v="32" data-xref="以西结书 25:10; 玛拉基书 4:1; 以西结书 20:47–48"> 你必当柴被火焚烧，你的血必流在国中，你必不再被记念，因为这是我耶和华说的。’”</span>
</div>

## 命以西结迁徙以兆犹大君被掳

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话又临到我说：</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 4:12; 耶利米书 5:21; 诗篇 78:40"> “人子啊，你住在悖逆的家中，他们有眼睛看不见，有耳朵听不见，因为他们是悖逆之家。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 36:3; 提摩太后书 2:25; 耶利米书 26:3"> 所以，人子啊，你要预备掳去使用的物件，在白日当他们眼前，从你所住的地方移到别处去。他们虽是悖逆之家，或者可以揣摩思想。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 39:4; 以西结书 12:12; 列王纪下 25:4"> 你要在白日当他们眼前带出你的物件去，好像预备掳去使用的物件。到了晚上，你要在他们眼前亲自出去，像被掳的人出去一样。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 25:4; 耶利米书 39:2–4"> 你要在他们眼前挖通了墙，从其中将物件带出去。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 4:3; 以赛亚书 8:18; 以西结书 24:24"> 到天黑时，你要当他们眼前搭在肩头上带出去，并要蒙住脸看不见地，因为我立你做以色列家的预兆。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以西结书 24:18; 以西结书 37:10; 以西结书 37:7"> 我就照着所吩咐的去行。白日带出我的物件，好像预备掳去使用的物件。到了晚上，我用手挖通了墙。天黑的时候，就当他们眼前搭在肩头上带出去。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 次日早晨，耶和华的话临到我说：</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 24:19; 以西结书 17:12; 以西结书 20:49"> “人子啊，以色列家，就是那悖逆之家，岂不是问你说：‘你做什么呢？’</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 9:25; 以赛亚书 13:1; 耶利米书 24:8"> 你要对他们说：‘主耶和华如此说：这是关乎耶路撒冷的君王和他周围以色列全家的预表<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：担子。">a</a></sup>。’</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 52:15; 耶利米书 15:2; 耶利米书 52:28–30"> 你要说：‘我做你们的预兆。我怎样行，他们所遭遇的也必怎样，他们必被掳去。’</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 25:4; 耶利米书 39:4; 以西结书 12:6"> 他们中间的君王也必在天黑的时候将物件搭在肩头上带出去。他们要挖通了墙，从其中带出去。他必蒙住脸，眼看不见地。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 39:7; 何西阿书 7:12; 以西结书 17:20"> 我必将我的网撒在他身上，他必在我的网罗中缠住。我必带他到迦勒底人之地的巴比伦，他虽死在那里，却看不见那地。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 5:2; 列王纪下 25:4–5; 以西结书 17:21"> 周围一切帮助他的和他所有的军队，我必分散四方<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“方”原文作“风”。">b</a></sup>，也要拔刀追赶他们。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 6:7; 以西结书 12:16; 以西结书 12:20"> 我将他们四散在列国、分散在列邦的时候，他们就知道我是耶和华。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 22:8–9; 以西结书 14:22–23; 以西结书 6:8–10"> 我却要留下他们几个人得免刀剑、饥荒、瘟疫，使他们在所到的各国中述说他们一切可憎的事，人就知道我是耶和华。”</span>
</div>
</div>

## 以西结战惧以兆犹大人惊惶

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和华的话又临到我说：</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米哀歌 5:9; 诗篇 80:5; 约伯记 3:24"> “人子啊，你吃饭必胆战，喝水必惶惶忧虑。</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 7:14; 以西结书 6:6–7; 以西结书 6:14"> 你要对这地的百姓说：‘主耶和华论耶路撒冷和以色列地的居民如此说：他们吃饭必忧虑，喝水必惊惶。因其中居住的众人所行强暴的事，这地必然荒废，一无所存。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 4:7; 以赛亚书 7:23–24; 耶利米书 25:9"> 有居民的城邑必变为荒场，地也必变为荒废，你们就知道我是耶和华。’”</span>
</div>
</div>

## 斥以色列俗谚之非

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21"> 耶和华的话临到我说：</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 18:2–3; 以西结书 11:3; 以西结书 12:27"> “人子啊，在你们以色列地怎么有这俗语说‘日子迟延，一切异象都落了空’呢？</span>
<span className="v" id="v23" data-v="23" data-xref="约珥书 2:1; 以西结书 7:5–7; 西番雅书 1:14"> 你要告诉他们说：‘主耶和华如此说：我必使这俗语止息，以色列中不再用这俗语。’你却要对他们说：‘日子临近，一切的异象必都应验。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 14:13–16; 以西结书 13:23; 撒迦利亚书 13:2–4"> 从此，在以色列家中必不再有虚假的异象和奉承的占卜。</span>
<span className="v" id="v25" data-v="25" data-xref="哈巴谷书 1:5; 以西结书 12:28; 以赛亚书 55:11"> 我耶和华说话，所说的必定成就，不再耽延。你们这悖逆之家，我所说的话必趁你们在世的日子成就。’这是主耶和华说的。”</span>
</div>
</div>

## 启示预言应验伊迩

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和华的话又临到我说：</span>
<span className="v" id="v27" data-v="27" data-xref="但以理书 10:14; 以西结书 12:22; 彼得后书 3:4"> “人子啊，以色列家的人说：‘他所见的异象是关乎后来许多的日子，所说的预言是指着极远的时候。’</span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 12:23–25; 马可福音 13:32–37; 帖撒罗尼迦前书 5:2–3"> 所以你要对他们说：‘主耶和华如此说：我的话没有一句再耽延的，我所说的必定成就。’这是主耶和华说的。”</span>
</div>
</div>

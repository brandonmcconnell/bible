## 以西结感灵见以色列地有建城之异象

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 33:21; 以西结书 1:2–3; 以西结书 3:14"> 我们被掳掠第二十五年，耶路撒冷城攻破后十四年，正在年初，月之初十日，耶和华的灵<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：手。">a</a></sup>降在我身上，他把我带到以色列地。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 1:1; 但以理书 7:1; 但以理书 7:7"> 在神的异象中，带我到以色列地，安置在至高的山上，在山上的南边有仿佛一座城建立。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 47:3; 启示录 11:1; 但以理书 10:5–6"> 他带我到那里，见有一人，颜色<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：形状。">b</a></sup>如铜，手拿麻绳和量度的竿，站在门口。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 44:5; 马太福音 10:27; 以西结书 2:7–8"> 那人对我说：“人子啊，凡我所指示你的，你都要用眼看，用耳听，并要放在心上。我带你到这里来，特为要指示你。凡你所见的，你都要告诉以色列家。”</span>
</div>
</div>

## 东门之式度

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以西结书 42:20; 以赛亚书 26:1; 启示录 21:12"> 我见殿四围有墙。那人手拿量度的竿，长六肘，每肘是一肘零一掌。他用竿量墙，厚一竿，高一竿。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 43:1; 以西结书 8:16; 以西结书 11:1"> 他到了朝东的门，就上门的台阶，量门的这槛，宽一竿，又量门的那槛，宽一竿。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 40:36; 以西结书 40:33; 历代志上 23:28"> 又有卫房，每房长一竿，宽一竿，相隔五肘。门槛，就是挨着向殿的廊门槛，宽一竿。</span>
<span className="v" id="v8" data-v="8"> 他又量向殿门的廊子，宽一竿。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 45:19"> 又量门廊，宽八肘，墙柱厚二肘，那门的廊子向着殿。</span>
<span className="v" id="v10" data-v="10"> 东门洞有卫房，这旁三间，那旁三间，都是一样的尺寸，这边的柱子和那边的柱子也是一样的尺寸。</span>
<span className="v" id="v11" data-v="11"> 他量门口，宽十肘，长十三肘。</span>
<span className="v" id="v12" data-v="12"> 卫房前展出的境界，这边一肘，那边一肘；卫房这边六肘，那边六肘。</span>
<span className="v" id="v13" data-v="13"> 又量门洞，从这卫房顶的后檐到那卫房顶的后檐，宽二十五肘，卫房门与门相对。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 27:9; 以赛亚书 62:9; 以西结书 42:1"> 又量<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“量”原文作“造”。">c</a></sup>廊子，六十肘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="七十经作：二十肘。">d</a></sup>，墙柱外是院子，有廊为界，在门洞两边。</span>
<span className="v" id="v15" data-v="15"> 从大门口到内廊前，共五十肘。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 3:5; 列王纪上 6:4; 以西结书 41:26"> 卫房和门洞两旁柱间并廊子，都有严紧的窗棂，里边都有窗棂，柱上有雕刻的棕树。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="启示录 11:2; 以西结书 42:1; 历代志上 23:28"> 他带我到外院，见院的四围有铺石地，铺石地上有屋子三十间。</span>
<span className="v" id="v18" data-v="18"> 铺石地，就是矮铺石地，在各门洞两旁，以门洞的长短为度。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 40:23; 以西结书 40:27; 以西结书 46:1–2"> 他从下门量到内院外，共宽一百肘，东面、北面都是如此。</span>
</div>
</div>

## 外院北门之式度

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西结书 40:6"> 他量外院朝北的门，长宽若干。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 40:29–30; 以西结书 40:25–26; 以西结书 40:10–16"> 门洞的卫房，这旁三间，那旁三间。门洞的柱子和廊子，与第一门的尺寸一样。门洞长五十肘，宽二十五肘。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 40:31; 以西结书 40:37; 以西结书 40:6"> 其窗棂和廊子并雕刻的棕树，与朝东的门尺寸一样。登七层台阶上到这门，前面有廊子。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 40:19; 以西结书 40:27–28; 出埃及记 38:9–12"> 内院有门与这门相对，北面、东面都是如此。他从这门量到那门，共一百肘。</span>
</div>
</div>

## 南门之式度

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以西结书 46:9; 以西结书 40:6; 以西结书 40:20–21"> 他带我往南去，见朝南有门。又照先前的尺寸，量门洞的柱子和廊子。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 40:33; 以西结书 40:16; 以西结书 40:21–22"> 门洞两旁与廊子的周围都有窗棂，和先量的窗棂一样。门洞长五十肘，宽二十五肘。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 40:22; 以西结书 40:16; 以西结书 40:6"> 登七层台阶上到这门，前面有廊子。柱上有雕刻的棕树，这边一棵，那边一棵。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 40:23; 以西结书 40:32; 以西结书 40:19"> 内院朝南有门，从这门量到朝南的那门，共一百肘。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以西结书 40:35; 以西结书 40:32"> 他带我从南门到内院，就照先前的尺寸量南门。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 40:25; 以西结书 40:16; 以西结书 40:7"> 卫房和柱子并廊子，都照先前的尺寸。门洞两旁与廊子的周围都有窗棂。门洞长五十肘，宽二十五肘。</span>
<span className="v" id="v30" data-v="30" data-xref="以西结书 40:21; 以西结书 40:36; 以西结书 40:25"> 周围有廊子，长二十五肘，宽五肘。</span>
<span className="v" id="v31" data-v="31" data-xref="以西结书 40:26; 以西结书 40:34; 以西结书 40:22"> 廊子朝着外院，柱上有雕刻的棕树。登八层台阶上到这门。</span>
</div>
</div>

## 内院东门之式度

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以西结书 40:35; 以西结书 40:28–31"> 他带我到内院的东面，就照先前的尺寸量东门。</span>
<span className="v" id="v33" data-v="33" data-xref="以西结书 40:21; 以西结书 40:36; 以西结书 40:25"> 卫房和柱子并廊子，都照先前的尺寸。门洞两旁与廊子的周围都有窗棂。门洞长五十肘，宽二十五肘。</span>
<span className="v" id="v34" data-v="34" data-xref="以西结书 40:22; 以西结书 40:31; 以西结书 40:37"> 廊子朝着外院，门洞两旁的柱子都有雕刻的棕树。登八层台阶上到这门。</span>
</div>
</div>

## 北门之式度

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="以西结书 47:2; 以西结书 40:32; 以西结书 44:4"> 他带我到北门，就照先前的尺寸量那门，</span>
<span className="v" id="v36" data-v="36" data-xref="以西结书 40:29; 以西结书 40:21; 以西结书 40:16"> 就是量卫房和柱子并廊子。门洞周围都有窗棂。门洞长五十肘，宽二十五肘。</span>
<span className="v" id="v37" data-v="37" data-xref="以西结书 40:34; 以西结书 40:31"> 廊柱朝着外院，门洞两旁的柱子都有雕刻的棕树。登八层台阶上到这门。</span>
</div>
</div>

## 门旁备宰祭牲之桌

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="历代志下 4:6; 以西结书 40:17; 利未记 8:21"> 门洞的柱旁有屋子和门，祭司<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原文作：他们。">e</a></sup>在那里洗燔祭牲。</span>
<span className="v" id="v39" data-v="39" data-xref="以西结书 46:2; 利未记 1:3–17; 利未记 4:2–3"> 在门廊内，这边有两张桌子，那边有两张桌子，在其上可以宰杀燔祭牲、赎罪祭牲和赎愆祭牲。</span>
<span className="v" id="v40" data-v="40"> 上到朝北的门口，这边有两张桌子，门廊那边也有两张桌子。</span>
<span className="v" id="v41" data-v="41" data-xref="以西结书 40:39–40"> 门这边有四张桌子，那边有四张桌子，共八张，在其上祭司宰杀牺牲。</span>
<span className="v" id="v42" data-v="42" data-xref="以西结书 40:39; 出埃及记 20:25"> 为燔祭牲有四张桌子，是凿过的石头做成的，长一肘半，宽一肘半，高一肘，祭司将宰杀燔祭牲和平安祭牲所用的器皿放在其上。</span>
<span className="v" id="v43" data-v="43" data-xref="利未记 1:8; 利未记 1:6; 利未记 8:20"> 有钩子，宽一掌，钉在廊内的四围。桌子上有牺牲的肉。</span>
</div>
</div>

## 讴歌者及祭司之室

<div className="bt">
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="历代志上 6:31–32; 历代志上 16:41–43; 以西结书 40:27"> 在北门旁，内院里有屋子，为歌唱的人而设。这屋子朝南<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="“南”原文作“东”。">f</a></sup>，在南门旁又有一间朝北。</span>
<span className="v" id="v45" data-v="45" data-xref="历代志上 9:23; 诗篇 134:1; 利未记 8:35"> 他对我说：“这朝南的屋子是为看守殿宇的祭司，</span>
<span className="v" id="v46" data-v="46" data-xref="以西结书 44:15; 以西结书 43:19; 列王纪上 2:35"> 那朝北的屋子是为看守祭坛的祭司。这些祭司是利未人中撒督的子孙，近前来侍奉耶和华的。”</span>
<span className="v" id="v47" data-v="47" data-xref="以西结书 40:19; 以西结书 40:23; 以西结书 40:27"> 他又量内院，长一百肘，宽一百肘，是见方的。祭坛在殿前。</span>
</div>
</div>

## 殿前廊之式度

<div className="bt">
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="历代志下 3:4; 列王纪上 6:3"> 于是他带我到殿前的廊子，量廊子的墙柱，这面厚五肘，那面厚五肘。门两旁，这边三肘，那边三肘。</span>
<span className="v" id="v49" data-v="49" data-xref="列王纪上 7:15–21; 以西结书 40:34; 历代志下 3:17"> 廊子长二十肘，宽十一肘。上廊子有台阶。靠近墙柱又有柱子，这边一根，那边一根。</span>
</div>

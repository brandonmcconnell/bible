## 以色列之结局已临必受惩罚

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话又临到我说：</span>
<span className="v" id="v2" data-v="2" data-xref="阿摩司书 8:2; 彼得前书 4:7; 以西结书 7:3"> “人子啊，主耶和华对以色列地如此说：结局到了！结局到了地的四境。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 18:30; 以西结书 5:13; 以西结书 33:20"> 现在你的结局已经临到，我必使我的怒气归于你，也必按你的行为审判你，照你一切可憎的事刑罚你。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 6:7; 以西结书 11:21; 以西结书 5:11"> 我眼必不顾惜你，也不可怜你，却要按你所行的报应你，照你中间可憎的事刑罚你，你就知道我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="那鸿书 1:9; 列王纪下 21:12–13; 以西结书 5:9"> “主耶和华如此说：有一灾，独有一灾，看哪，临近了！</span>
<span className="v" id="v6" data-v="6" data-xref="撒迦利亚书 13:7; 以西结书 7:3; 彼得后书 2:5"> 结局来了，结局来了，向你兴起。看哪，来到了！</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 12:28; 以西结书 7:12; 以赛亚书 22:5"> 境内的居民哪，所定的灾临到你，时候到了，日子近了，乃是哄嚷，并非在山上欢呼的日子。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 9:8; 以西结书 14:19; 以西结书 20:8"> 我快要将我的愤怒倾在你身上，向你成就我怒中所定的，按你的行为审判你，照你一切可憎的事刑罚你。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 20:13; 弥迦书 6:9; 以赛亚书 9:13"> 我眼必不顾惜你，也不可怜你，必按你所行的报应你，照你中间可憎的事刑罚你，你就知道击打你的是我耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 10:5; 雅各书 4:6; 帖撒罗尼迦前书 5:3"> “看哪，看哪，日子快到了！所定的灾已经发出，杖已经开花，骄傲已经发芽。</span>
<span className="v" id="v11" data-v="11" data-xref="西番雅书 1:18; 以西结书 7:23; 以赛亚书 59:6–8"> 强暴兴起，成了罚恶的杖。以色列人，或是他们的群众，或是他们的财宝，无一存留，他们中间也没有得尊荣的。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 5:13–14; 哥林多前书 7:29–31; 以西结书 7:5–7"> 时候到了，日子近了，买主不可欢喜，卖主不可愁烦，因为烈怒已经临到他们众人身上。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 25:24–28; 利未记 25:31; 约伯记 15:25"> 卖主虽然存活，却不能归回再得所卖的，因为这异象关乎他们众人。谁都不得归回，也没有人在他的罪孽中坚立自己。</span>
</div>
</div>

## 得脱者必因己罪哀鸣

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米书 4:5; 耶利米书 7:20; 耶利米书 51:27"> “他们已经吹角，预备齐全，却无一人出战，因为我的烈怒临到他们众人身上。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 14:18; 以西结书 5:12; 耶利米哀歌 1:20"> 在外有刀剑，在内有瘟疫、饥荒，在田野的必遭刀剑而死，在城中的必有饥荒、瘟疫吞灭他。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 59:11; 以赛亚书 38:14; 以斯拉记 9:15"> 其中所逃脱的就必逃脱，各人因自己的罪孽在山上发出悲声，好像谷中的鸽子哀鸣。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 21:7; 希伯来书 12:12; 耶利米书 6:24"> 手都发软，膝弱如水。</span>
<span className="v" id="v18" data-v="18" data-xref="阿摩司书 8:10; 以赛亚书 15:2–3; 以赛亚书 3:24"> 要用麻布束腰，被战兢所盖，各人脸上羞愧，头上光秃。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 11:4; 西番雅书 1:18; 路加福音 12:19–20"> 他们要将银子抛在街上，金子看如污秽之物。当耶和华发怒的日子，他们的金银不能救他们，不能使心里知足，也不能使肚腹饱满，因为这金银做了他们罪孽的绊脚石。</span>
</div>
</div>

## 因制可憎之像敌至污殿行掠

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西结书 24:21; 耶利米书 7:30; 以西结书 8:15–16"> “论到耶和华装饰华美的殿，他建立得威严，他们却在其中制造可憎可厌的偶像，所以这殿我使他们看如污秽之物。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 24:13; 诗篇 74:2–8; 历代志下 36:18–19"> 我必将这殿交付外邦人为掠物，交付地上的恶人为掳物，他们也必亵渎这殿。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 18:17; 诗篇 74:18–23; 诗篇 74:10–11"> 我必转脸不顾以色列人，他们亵渎我隐密之所，强盗也必进去亵渎。</span>
</div>
</div>

## 命制锁链以兆被掳

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以西结书 9:9; 耶利米书 27:2; 以西结书 11:6"> “要制造锁链，因为这地遍满流血的罪，城邑充满强暴的事。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 28:7; 诗篇 106:41; 以西结书 21:31"> 所以我必使列国中最恶的人来占据他们的房屋，我必使强暴人的骄傲止息，他们的圣所都要被亵渎。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 8:15–16; 以赛亚书 57:21; 耶利米哀歌 4:17–18"> 毁灭临近了，他们要求平安，却无平安可得。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 4:20; 以西结书 14:1; 弥迦书 3:6"> 灾害加上灾害，风声接连风声，他们必向先知求异象，但祭司讲的律法、长老设的谋略都必断绝。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 18:30; 以西结书 7:4–8; 以西结书 26:16"> 君要悲哀，王要披凄凉为衣，国民的手都发颤。我必照他们的行为待他们，按他们应得的审判他们，他们就知道我是耶和华。”</span>
</div>
</div>

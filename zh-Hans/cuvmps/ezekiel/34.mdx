## 谴责牧者

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话临到我说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 23:1; 耶利米书 3:15; 以赛亚书 40:11"> “人子啊，你要向以色列的牧人发预言攻击他们，说：‘主耶和华如此说：祸哉，以色列的牧人！只知牧养自己。牧人岂不当牧养群羊吗？</span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亚书 11:16; 耶利米书 2:30; 以西结书 33:25–26"> 你们吃脂油，穿羊毛，宰肥壮的，却不牧养群羊。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 18:12–13; 马太福音 9:36; 以西结书 34:16"> 瘦弱的你们没有养壮，有病的你们没有医治，受伤的你们没有缠裹，被逐的你们没有领回，失丧的你们没有寻找，但用强暴严严地辖制。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 9:36; 历代志下 18:16; 耶利米书 23:2"> 因无牧人，羊就分散，既分散，便做了一切野兽的食物。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 142:4; 彼得前书 2:25; 约翰福音 10:16"> 我的羊在诸山间、在各高冈上流离，在全地上分散，无人去寻，无人去找。</span>
</div>
</div>

## 必加惩罚

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="耶利米书 22:2–3; 弥迦书 3:8–9; 诗篇 82:1–7"> ‘所以你们这些牧人，要听耶和华的话。</span>
<span className="v" id="v8" data-v="8" data-xref="彼得后书 2:13; 使徒行传 20:33; 以西结书 34:5–6"> 主耶和华说：我指着我的永生起誓，我的羊因无牧人就成为掠物，也做了一切野兽的食物。我的牧人不寻找我的羊，这些牧人只知牧养自己，并不牧养我的羊。</span>
<span className="v" id="v9" data-v="9"> 所以你们这些牧人，要听耶和华的话。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 34:2; 撒迦利亚书 10:3; 以西结书 13:8"> 主耶和华如此说：我必与牧人为敌，必向他们的手追讨我的羊，使他们不再牧放群羊，牧人也不再牧养自己。我必救我的羊脱离他们的口，不再做他们的食物。’</span>
</div>
</div>

## 耶和华躬自做牧

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约翰福音 10:16; 路加福音 19:10; 耶利米书 23:3"> “主耶和华如此说：看哪，我必亲自寻找我的羊，将他们寻见。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 40:11; 约翰福音 10:11–12; 路加福音 19:10"> 牧人在羊群四散的日子怎样寻找他的羊，我必照样寻找我的羊。这些羊在密云黑暗的日子散到各处，我必从那里救回他们来。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 28:25–26; 以西结书 11:17; 以赛亚书 11:11–16"> 我必从万民中领出他们，从各国内聚集他们，引导他们归回故土。也必在以色列山上一切溪水旁边，境内一切可居之处牧养他们。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 10:9; 耶利米书 31:25; 诗篇 31:8–10"> 我必在美好的草场牧养他们，他们的圈必在以色列高处的山上。他们必在佳美之圈中躺卧，也在以色列山肥美的草场吃草。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 3:15; 诗篇 23:1–2; 约翰福音 21:15"> 主耶和华说：我必亲自做我羊的牧人，使他们得以躺卧。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:10; 以西结书 34:4; 以西结书 34:11"> 失丧的我必寻找，被逐的我必领回，受伤的我必缠裹，有病的我必医治，只是肥的壮的我必除灭，也要秉公牧养他们。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西结书 34:20–22; 马太福音 25:32–33; 撒迦利亚书 10:3"> “我的羊群哪，论到你们，主耶和华如此说：我必在羊与羊中间，公绵羊与公山羊中间施行判断。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 23:13; 路加福音 11:52; 民数记 16:13"> 你们这些肥壮的羊，在美好的草场吃草还以为小事吗？剩下的草你们竟用蹄践踏了！你们喝清水，剩下的水你们竟用蹄搅浑了！</span>
<span className="v" id="v19" data-v="19"> 至于我的羊，只得吃你们所践踏的，喝你们所搅浑的。</span>
</div>
</div>

## 预言其仆必牧群羊

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马太福音 25:31–46; 以西结书 34:10; 诗篇 22:12–16"> “所以主耶和华如此说：我必在肥羊和瘦羊中间施行判断。</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亚书 11:5; 申命记 33:17; 路加福音 13:14–16"> 因为你们用胁用肩拥挤一切瘦弱的，又用角抵触，以致使他们四散，</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 23:2–3; 诗篇 72:12–14; 以西结书 34:10"> 所以我必拯救我的群羊不再做掠物，我也必在羊和羊中间施行判断。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 37:24–25; 耶利米书 30:9; 以赛亚书 40:11"> 我必立一牧人照管他们，牧养他们，就是我的仆人大卫。他必牧养他们，做他们的牧人。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 31:33; 以西结书 36:28; 耶利米书 23:5–6"> 我耶和华必做他们的神，我的仆人大卫必在他们中间做王。这是耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 11:6–9; 以西结书 37:26; 利未记 26:6"> “我必与他们立平安的约，使恶兽从境内断绝，他们就必安居在旷野，躺卧在林中。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 28:12; 以赛亚书 44:3; 利未记 26:4"> 我必使他们与我山的四围成为福源，我也必叫时雨落下，必有福如甘霖而降。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 30:8; 利未记 26:4; 利未记 26:13"> 田野的树必结果，地也必有出产，他们必在故土安然居住。我折断他们所负的轭，救他们脱离那以他们为奴之人的手，那时他们就知道我是耶和华。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 46:27; 耶利米书 30:10; 以西结书 39:26"> 他们必不再做外邦人的掠物，地上的野兽也不再吞吃他们，却要安然居住，无人惊吓。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 36:29; 以赛亚书 4:2; 以西结书 34:26–27"> 我必给他们兴起有名的植物，他们在境内不再为饥荒所灭，也不再受外邦人的羞辱，</span>
<span className="v" id="v30" data-v="30" data-xref="以西结书 37:27; 以西结书 34:24; 诗篇 46:11"> 必知道我耶和华他们的神是与他们同在，并知道他们以色列家是我的民。这是主耶和华说的。</span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 100:3; 约翰福音 10:16; 诗篇 78:52"> 你们做我的羊，我草场上的羊，乃是以色列人，我也是你们的神。这是主耶和华说的。”</span>
</div>
</div>

## 埃及与其同盟必偕败亡

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 耶和华的话又临到我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 13:6; 以西结书 21:12; 约珥书 1:11"> “人子啊，你要发预言说：‘主耶和华如此说：<br /><span className="pl pl-1">哀哉这日！你们应当哭号。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="俄巴底亚书 1:15; 约珥书 2:1–2; 约珥书 1:15"> <span className="pl pl-1">因为耶和华的日子临近，</span><br /><span className="pl pl-1">就是密云之日，</span><br /><span className="pl pl-1">列国受罚之期。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 29:19; 以西结书 29:8; 以赛亚书 16:7"> <span className="pl pl-1">必有刀剑临到埃及，</span><br /><span className="pl pl-1">在埃及被杀之人仆倒的时候，</span><br /><span className="pl pl-1">古实人就有痛苦；</span><br /><span className="pl pl-1">人民必被掳掠，</span><br /><span className="pl pl-1">基址必被拆毁。</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="耶利米书 25:20; 以西结书 27:10; 耶利米书 25:24"> 古实人、弗人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：吕彼亚人。">a</a></sup>、路德人、杂族的人民并古巴人，以及同盟之地的人，都要与埃及人一同倒在刀下。</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="以西结书 29:10; 以赛亚书 20:3–6; 以赛亚书 31:3"> ‘耶和华如此说：<br /><span className="pl pl-1">扶助埃及的也必倾倒，</span><br /><span className="pl pl-1">埃及因势力而有的骄傲必降低微，</span><br /><span className="pl pl-1">其中的人民从色弗尼塔起</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="见29章10节。">b</a></sup><br /><span className="pl pl-1">必倒在刀下。</span><br /><span className="pl pl-1">这是主耶和华说的。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 29:12; 耶利米书 25:18–26; 以西结书 32:18–32"> <span className="pl pl-1">埃及地在荒凉的国中必成为荒凉，</span><br /><span className="pl pl-1">埃及城在荒废的城中也变为荒废。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 29:6; 以西结书 29:16; 阿摩司书 1:7"> <span className="pl pl-1">我在埃及中使火着起，</span><br /><span className="pl pl-1">帮助埃及的都被灭绝，</span><br /><span className="pl pl-1">那时他们就知道我是耶和华。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 18:1–2; 以赛亚书 23:5; 以西结书 32:9–10"> 到那日，必有使者坐船从我面前出去，使安逸无虑的古实人惊惧；必有痛苦临到他们，好像埃及遭灾的日子一样。看哪，这事临近了！</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="以西结书 29:19; 以西结书 32:11–16; 以西结书 29:4–5"> ‘主耶和华如此说：<br /><span className="pl pl-1">我必藉巴比伦王尼布甲尼撒的手</span><br /><span className="pl pl-1">除灭埃及众人。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 28:7; 以西结书 32:12; 以西结书 39:11–20"> <span className="pl pl-1">他和随从他的人，</span><br /><span className="pl pl-1">就是列国中强暴的，</span><br /><span className="pl pl-1">必进来毁灭这地。</span><br /><span className="pl pl-1">他们必拔刀攻击埃及，</span><br /><span className="pl pl-1">使遍地有被杀的人。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 29:3; 那鸿书 1:4; 启示录 16:12"> <span className="pl pl-1">我必使江河干涸，</span><br /><span className="pl pl-1">将地卖在恶人的手中。</span><br /><span className="pl pl-1">我必藉外邦人的手，</span><br /><span className="pl pl-1">使这地和其中所有的变为凄凉。</span><br /><span className="pl pl-1">这是我耶和华说的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="撒迦利亚书 10:11; 耶利米书 46:14; 耶利米书 2:16"> ‘主耶和华如此说：<br /><span className="pl pl-1">我必毁灭偶像，</span><br /><span className="pl pl-1">从挪弗除灭神像。</span><br /><span className="pl pl-1">必不再有君王出自埃及地，</span><br /><span className="pl pl-1">我要使埃及地的人惧怕。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 29:14; 耶利米书 46:25; 诗篇 78:43"> <span className="pl pl-1">我必使巴忒罗荒凉，</span><br /><span className="pl pl-1">在琐安中使火着起，</span><br /><span className="pl pl-1">向挪施行审判。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="启示录 16:1; 那鸿书 1:6; 诗篇 11:6"> <span className="pl pl-1">我必将我的愤怒倒在埃及的保障上，</span><br /><span className="pl pl-1">就是训上，</span><br /><span className="pl pl-1">并要剪除挪的众人。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 30:8–9; 以西结书 28:18"> <span className="pl pl-1">我必在埃及中使火着起，</span><br /><span className="pl pl-1">训必大大痛苦，</span><br /><span className="pl pl-1">挪必被攻破，</span><br /><span className="pl pl-1">挪弗白日</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“白日”或作“终日”。">c</a></sup><br /><span className="pl pl-1">见仇敌。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="创世记 41:45"> <span className="pl pl-1">亚文和比伯实的少年人必倒在刀下，</span><br /><span className="pl pl-1">这些城的人必被掳掠。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 30:3; 以西结书 29:15; 以赛亚书 10:27"> <span className="pl pl-1">我在答比匿折断埃及的诸轭，</span><br /><span className="pl pl-1">使她因势力而有的骄傲在其中止息，</span><br /><span className="pl pl-1">那时日光必退去。</span><br /><span className="pl pl-1">至于这城，必有密云遮蔽，</span><br /><span className="pl pl-1">其中的女子必被掳掠。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 30:14; 启示录 17:1; 以西结书 5:8"> <span className="pl pl-1">我必这样向埃及施行审判，</span><br /><span className="pl pl-1">他们就知道我是耶和华。’”</span></span>
</div>
</div>

## 耶和华折法老之臂

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西结书 29:17; 以西结书 26:1; 以西结书 29:1"> 十一年正月初七日，耶和华的话临到我说：</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 30:13; 耶利米书 46:11; 诗篇 37:17"> “人子啊，我已打折埃及王法老的膀臂，没有敷药，也没有用布缠好，使他有力持刀。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 37:17; 耶利米书 37:7; 列王纪下 24:7"> 所以主耶和华如此说：看哪，我与埃及王法老为敌，必将他有力的膀臂和已打折的膀臂全行打断，使刀从他手中坠落。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 30:26; 以西结书 30:17–18; 以西结书 29:12–13"> 我必将埃及人分散在列国，四散在列邦。</span>
</div>
</div>

## 坚强巴比伦王之臂

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以西结书 30:25; 西番雅书 2:12; 以赛亚书 45:5"> “我必使巴比伦王的膀臂有力，将我的刀交在他手中；却要打断法老的膀臂，他就在巴比伦王面前唉哼，如同受死伤的人一样。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 29:21; 以西结书 32:15; 以西结书 29:16"> 我必扶持巴比伦王的膀臂，法老的膀臂却要下垂。我将我的刀交在巴比伦王手中，他必举刀攻击埃及地，他们就知道我是耶和华。</span>
<span className="v" id="v26" data-v="26" data-xref="但以理书 11:42; 以西结书 29:12; 以西结书 30:23"> 我必将埃及人分散在列国，四散在列邦，他们就知道我是耶和华。”</span>
</div>

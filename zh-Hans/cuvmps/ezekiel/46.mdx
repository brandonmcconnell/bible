## 君王献祭之例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 66:23; 以西结书 44:1–2; 出埃及记 20:9"> ‘主耶和华如此说：内院朝东的门在办理事务的六日内必须关闭，唯有安息日和月朔必须敞开。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 44:3; 以西结书 46:8; 历代志上 29:10–12"> 王要从这门的廊进入，站在门框旁边。祭司要为他预备燔祭和平安祭，他就要在门槛那里敬拜，然后出去。这门直到晚上不可关闭。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:10; 约翰福音 10:9; 希伯来书 10:19–22"> 在安息日和月朔，国内的居民要在这门口，耶和华面前敬拜。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 45:17; 民数记 28:9–10"> 安息日，王所献于耶和华的燔祭要用无残疾的羊羔六只，无残疾的公绵羊一只。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 45:24; 以西结书 46:7; 申命记 16:17"> 同献的素祭要为公绵羊献一伊法细面，为羊羔照他的力量而献，一伊法细面加油一欣。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结书 46:1"> ‘当月朔，要献无残疾的公牛犊一只，羊羔六只，公绵羊一只，都要无残疾的。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 46:5"> 他也要预备素祭，为公牛献一伊法细面，为公绵羊献一伊法细面，为羊羔照他的力量而献，一伊法细面加油一欣。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 46:2; 以西结书 44:1–3; 歌罗西书 1:18"> 王进入的时候，必由这门的廊而入，也必由此而出。</span>
</div>
</div>

## 庶民献祭之例

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命记 16:16; 出埃及记 23:14–17; 彼得后书 2:20–21"> ‘在各节期，国内居民朝见耶和华的时候，从北门进入敬拜的必由南门而出，从南门进入的必由北门而出。不可从所入的门而出，必要直往前行，由对门而出。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 42:4; 历代志上 29:20; 历代志上 29:22"> 民进入，王也要在民中进入；民出去，王也要一同出去。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 46:5; 以西结书 46:7; 民数记 15:1–41"> 在节期和圣会的日子同献的素祭，要为一只公牛献一伊法细面，为一只公绵羊献一伊法细面，为羊羔照他的力量而献，一伊法细面加油一欣。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 46:1–2; 以西结书 45:17; 以西结书 44:3"> 王预备甘心献的燔祭或平安祭，就是向耶和华甘心献的，当有人为他开朝东的门。他就预备燔祭和平安祭，与安息日预备的一样，献毕就出去。他出去之后，当有人将门关闭。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 50:4; 约翰福音 1:29; 出埃及记 12:5"> ‘每日你要预备无残疾、一岁的羊羔一只，献于耶和华为燔祭，要每早晨预备。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 28:5"> 每早晨也要预备同献的素祭，细面一伊法六分之一，并油一欣三分之一，调和细面。这素祭要常献于耶和华为永远的定例。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 10:1–10; 民数记 28:6; 出埃及记 29:42"> 每早晨要这样预备羊羔、素祭并油为常献的燔祭。</span>
</div>
</div>

## 王子承业之例

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志下 21:3; 加拉太书 4:7; 创世记 25:5–6"> ‘主耶和华如此说：王若将产业赐给他的儿子，就成了他儿子的产业，那是他们承受为业的。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 25:10; 路加福音 19:25–26; 加拉太书 4:30–31"> 倘若王将一份产业赐给他的臣仆，就成了他臣仆的产业，到自由之年仍要归于王。至于王的产业，必归于他的儿子。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 45:8; 列王纪上 21:19; 以西结书 22:27"> 王不可夺取民的产业，以致驱逐他们离开所承受的。他要从自己的地业中，将产业赐给他儿子，免得我的民分散，各人离开所承受的。’”</span>
</div>
</div>

## 祭司烹祭牲之所

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西结书 42:9; 以西结书 44:4–5; 以西结书 40:44–46"> 那带我的，将我从门旁进入之处领进为祭司预备的圣屋，是朝北的，见后头西边有一块地。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 35:13; 以西结书 44:29; 以西结书 44:19"> 他对我说：“这是祭司煮赎愆祭、赎罪祭，烤素祭之地，免得带到外院，使民成圣。”</span>
<span className="v" id="v21" data-v="21"> 他又带我到外院，使我经过院子的四拐角，见每拐角各有一个院子。</span>
<span className="v" id="v22" data-v="22"> 院子四拐角的院子周围有墙，每院长四十肘，宽三十肘，四拐角院子的尺寸都是一样。</span>
<span className="v" id="v23" data-v="23"> 其中周围有一排房子，房子内有煮肉的地方。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 46:20; 约翰福音 21:15–17; 彼得前书 5:2"> 他对我说：“这都是煮肉的房子，殿内的仆役要在这里煮民的祭物。”</span>
</div>
</div>

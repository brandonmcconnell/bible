## 撒种的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 8:4–10; 马太福音 13:1–15; 马可福音 4:1–12"> 当那一天，耶稣从房子里出来，坐在海边。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 5:3; 马太福音 4:25; 马可福音 4:1"> 有许多人到他那里聚集，他只得上船坐下，众人都站在岸上。</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 4:2–9; 马可福音 4:13; 诗篇 78:2"> 他用比喻对他们讲许多道理，说：<span className="woj">“有一个撒种的出去撒种。</span></span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 13:18–19"> <span className="woj">撒的时候，有落在路旁的，飞鸟来吃尽了。</span></span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 11:19; 以西结书 36:26; 撒迦利亚书 7:12"> <span className="woj">有落在土浅石头地上的，土既不深，发苗最快，</span></span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 13:21; 雅各书 1:11–12; 歌罗西书 1:23"> <span className="woj">日头出来一晒，因为没有根，就枯干了。</span></span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 4:18–19; 耶利米书 4:3–4; 创世记 3:18"> <span className="woj">有落在荆棘里的，荆棘长起来，把它挤住了。</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 13:23; 路加福音 8:15; 创世记 26:12"> <span className="woj">又有落在好土里的，就结实，有一百倍的，有六十倍的，有三十倍的。</span></span>
<span className="v" id="v9" data-v="9" data-xref="启示录 2:11; 马太福音 11:15; 启示录 2:7"> <span className="woj">有耳可听的，就应当听！”</span></span>
</div>
</div>

## 用比喻的因由

<div className="bt">
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="马可福音 4:33–34; 马可福音 4:10"> 门徒进前来，问耶稣说：“对众人讲话为什么用比喻呢？”</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 2:9–10; 哥林多前书 2:14; 马太福音 19:11"> 耶稣回答说：<span className="woj">“因为天国的奥秘只叫你们知道，不叫他们知道。</span></span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 25:29; 马可福音 4:24–25; 路加福音 8:18"> <span className="woj">凡有的，还要加给他，叫他有余；凡没有的，连他所有的也要夺去。</span></span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 12:2; 耶利米书 5:21; 以赛亚书 42:18–20"> <span className="woj">所以我用比喻对他们讲，是因他们看也看不见，听也听不见，也不明白。</span></span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 6:9–10; 以西结书 12:2; 哥林多后书 3:14"> <span className="woj">在他们身上，正应了以赛亚的预言说：</span><br /><span className="pl pl-1 woj">‘你们听是要听见，却不明白；</span><br /><span className="pl pl-1 woj">看是要看见，却不晓得。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 6:10; 马可福音 4:12; 撒迦利亚书 7:11"> <span className="pl pl-1 woj">因为这百姓油蒙了心，</span><br /><span className="pl pl-1 woj">耳朵发沉，</span><br /><span className="pl pl-1 woj">眼睛闭着，</span><br /><span className="pl pl-1 woj">恐怕眼睛看见，</span><br /><span className="pl pl-1 woj">耳朵听见，</span><br /><span className="pl pl-1 woj">心里明白，回转过来，</span><br /><span className="pl pl-1 woj">我就医治他们。’</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 10:23–24; 以弗所书 1:17–18; 马太福音 16:17"> <span className="woj">但你们的眼睛是有福的，因为看见了；你们的耳朵也是有福的，因为听见了。</span></span>
</div>
</div>

## 解明撒种的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 8:56; 希伯来书 11:13; 彼得前书 1:10–12"> <span className="woj">“我实在告诉你们：从前有许多先知和义人要看你们所看的，却没有看见；要听你们所听的，却没有听见。</span></span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 13:11–12; 路加福音 8:11–15; 马可福音 4:13–20"> <span className="woj">所以，你们当听这撒种的比喻：</span></span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 8:11–15; 马太福音 13:38; 希伯来书 2:1"> <span className="woj">凡听见天国道理不明白的，那恶者就来，把所撒在他心里的夺了去，这就是撒在路旁的了。</span></span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 33:31–32; 诗篇 106:12–13; 约翰福音 5:35"> <span className="woj">撒在石头地上的，就是人听了道，当下欢喜领受，</span></span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 11:6; 彼得后书 1:8–9; 以弗所书 3:17"> <span className="woj">只因心里没有根，不过是暂时的，及至为道遭了患难，或是受了逼迫，立刻就跌倒了。</span></span>
<span className="v" id="v22" data-v="22" data-xref="提摩太前书 6:17; 路加福音 8:14; 提摩太前书 6:9–10"> <span className="woj">撒在荆棘里的，就是人听了道，后来有世上的思虑、钱财的迷惑把道挤住了，不能结实。</span></span>
<span className="v" id="v23" data-v="23" data-xref="腓立比书 1:11; 马太福音 12:33; 约翰福音 15:16"> <span className="woj">撒在好地上的，就是人听道明白了，后来结实，有一百倍的，有六十倍的，有三十倍的。”</span></span>
</div>
</div>

## 稗子的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="马太福音 25:1; 马太福音 13:47; 马太福音 20:1"> 耶稣又设个比喻对他们说：<span className="woj">“天国好像人撒好种在田里，</span></span>
<span className="v" id="v25" data-v="25" data-xref="彼得前书 5:8; 彼得后书 2:1; 使徒行传 20:30–31"> <span className="woj">及至人睡觉的时候，有仇敌来，将稗子撒在麦子里就走了。</span></span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 4:26–29"> <span className="woj">到长苗吐穗的时候，稗子也显出来。</span></span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 16:17; 哥林多后书 6:1; 哥林多后书 5:18–20"> <span className="woj">田主的仆人来告诉他说：‘主啊，你不是撒好种在田里吗？从哪里来的稗子呢？’</span></span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 5:3–7; 帖撒罗尼迦前书 5:14; 路加福音 9:49–54"> <span className="woj">主人说：‘这是仇敌做的。’仆人说：‘你要我们去薅出来吗？’</span></span>
<span className="v" id="v29" data-v="29"> <span className="woj">主人说：‘不必，恐怕薅稗子，连麦子也拔出来。</span></span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 3:12; 提摩太前书 5:24; 哥林多前书 4:5"> <span className="woj">容这两样一齐长，等着收割。当收割的时候，我要对收割的人说：先将稗子薅出来，捆成捆，留着烧，唯有麦子要收在仓里。’”</span></span>
</div>
</div>

## 芥菜种的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 13:18–19; 马太福音 17:20; 马可福音 4:30–32"> 他又设个比喻对他们说：<span className="woj">“天国好像一粒芥菜种，有人拿去种在田里。</span></span>
<span className="v" id="v32" data-v="32" data-xref="以西结书 31:6; 但以理书 4:12; 以西结书 17:23–24"> <span className="woj">这原是百种里最小的，等到长起来，却比各样的菜都大，且成了树，天上的飞鸟来宿在它的枝上。”</span></span>
</div>
</div>

## 面酵的比喻

<div className="bt">
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="加拉太书 5:9; 哥林多前书 5:6–7; 路加福音 13:21"> 他又对他们讲个比喻说：<span className="woj">“天国好像面酵，有妇人拿来藏在三斗面里，直等全团都发起来。”</span></span>
<span className="v" id="v34" data-v="34" data-xref="马可福音 4:33–34; 约翰福音 16:25; 马太福音 13:13"> 这都是耶稣用比喻对众人说的话，若不用比喻，就不对他们说什么。</span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 78:2; 以弗所书 3:9; 彼得前书 1:20–21"> 这是要应验先知的话说：<br /><span className="pl pl-1">“我要开口用比喻，</span><br /><span className="pl pl-1">把创世以来所隐藏的事发明出来。”</span></span>
</div>
</div>

## 解明稗子的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="约翰福音 16:17–20; 马太福音 13:11; 马太福音 9:28"> 当下，耶稣离开众人，进了房子。他的门徒进前来，说：“请把田间稗子的比喻讲给我们听。”</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前书 3:5–7; 马太福音 13:41; 路加福音 10:16"> 他回答说：<span className="woj">“那撒好种的就是人子，</span></span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 8:44; 腓立比书 3:18–19; 使徒行传 13:10"> <span className="woj">田地就是世界，好种就是天国之子，稗子就是那恶者之子，</span></span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 13:49; 启示录 14:15–19; 马太福音 25:31"> <span className="woj">撒稗子的仇敌就是魔鬼，收割的时候就是世界的末了，收割的人就是天使。</span></span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 13:39"> <span className="woj">将稗子薅出来用火焚烧，世界的末了也要如此。</span></span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 24:31; 马太福音 18:7; 彼得后书 2:1–2"> <span className="woj">人子要差遣使者，把一切叫人跌倒的和作恶的，从他国里挑出来，</span></span>
<span className="v" id="v42" data-v="42" data-xref="马太福音 13:50; 路加福音 16:23–24; 马太福音 8:12"> <span className="woj">丢在火炉里，在那里必要哀哭切齿了。</span></span>
<span className="v" id="v43" data-v="43" data-xref="但以理书 12:3; 马太福音 11:15; 路加福音 12:32"> <span className="woj">那时，义人在他们父的国里要发出光来，像太阳一样。有耳可听的，就应当听！</span></span>
</div>
</div>

## 拿撒勒人厌弃耶稣

<div className="bt">
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="马太福音 7:28; 马可福音 4:33–35"> 耶稣说完了这些比喻，就离开那里，</span>
<span className="v" id="v54" data-v="54" data-xref="马太福音 7:28; 约翰福音 7:15–16; 马可福音 6:1–6"> 来到自己的家乡，在会堂里教训人，甚至他们都稀奇，说：“这人从哪里有这等智慧和异能呢？</span>
<span className="v" id="v55" data-v="55" data-xref="约翰福音 6:42; 马可福音 6:3; 路加福音 3:23"> 这不是木匠的儿子吗？他母亲不是叫马利亚吗？他弟兄们不是叫雅各、约西<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷作：约瑟。">a</a></sup>、西门、犹大吗？</span>
<span className="v" id="v56" data-v="56"> 他妹妹们不是都在我们这里吗？这人从哪里有这一切的事呢？”</span>
<span className="v" id="v57" data-v="57" data-xref="约翰福音 4:44; 马太福音 11:6; 路加福音 4:24"> 他们就厌弃他<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“厌弃他”原文作“因他跌倒”。">b</a></sup>。耶稣对他们说：<span className="woj">“大凡先知，除了本地、本家之外，没有不被人尊敬的。”</span></span>
<span className="v" id="v58" data-v="58" data-xref="马可福音 6:5–6; 罗马书 11:20; 希伯来书 3:12–19"> 耶稣因为他们不信，就在那里不多行异能了。</span>
</div>

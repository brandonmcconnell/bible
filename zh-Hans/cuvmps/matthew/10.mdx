## 耶稣差遣十二使徒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 9:1–6; 马可福音 3:13–15; 马可福音 6:7–13"> 耶稣叫了十二个门徒来，给他们权柄，能赶逐污鬼，并医治各样的病症。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="马太福音 4:21; 使徒行传 1:13; 路加福音 5:10"> 这十二使徒的名：头一个叫西门，又称彼得，还有他兄弟安得烈，西庇太的儿子雅各和雅各的兄弟约翰，</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 3:18; 使徒行传 1:13; 马可福音 2:14"> 腓力和巴多罗买，多马和税吏马太，亚勒腓的儿子雅各，和达太，</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 26:14; 马太福音 26:47; 约翰福音 13:2"> 奋锐党的西门，还有卖耶稣的加略人犹大。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 4:9; 使徒行传 22:21–23; 列王纪下 17:24–41"> 耶稣差这十二个人去，吩咐他们说：<span className="woj">“外邦人的路你们不要走，撒马利亚人的城你们不要进，</span></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 50:6; 以西结书 34:6; 以赛亚书 53:6"> <span className="woj">宁可往以色列家迷失的羊那里去。</span></span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 28:31; 马太福音 3:2; 路加福音 9:60"> <span className="woj">随走随传，说‘天国近了’。</span></span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 3:6; 路加福音 10:9; 使徒行传 4:30"> <span className="woj">医治病人，叫死人复活，叫长大麻风的洁净，把鬼赶出去。你们白白地得来，也要白白地舍去。</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 22:35; 路加福音 9:3–5; 路加福音 10:4–12"> <span className="woj">腰袋里不要带金银铜钱，</span></span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 10:7–12; 提摩太前书 5:17–18; 哥林多前书 9:4–14"> <span className="woj">行路不要带口袋，不要带两件褂子，也不要带鞋和拐杖，因为工人得饮食是应当的。</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 10:7–8; 约伯记 31:32; 士师记 19:16–21"> <span className="woj">你们无论进哪一城、哪一村，要打听那里谁是好人，就住在他家，直住到走的时候。</span></span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 25:6; 路加福音 10:5–6; 使徒行传 10:36"> <span className="woj">进他家里去，要请他的安。</span></span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 10:6; 诗篇 35:13; 哥林多后书 2:16"> <span className="woj">那家若配得平安，你们所求的平安就必临到那家；若不配得，你们所求的平安仍归你们。</span></span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 10:10–11; 使徒行传 18:6; 尼希米记 5:13"> <span className="woj">凡不接待你们、不听你们话的人，你们离开那家或是那城的时候，就把脚上的尘土跺下去。</span></span>
<span className="v" id="v15" data-v="15" data-xref="彼得后书 2:6; 约翰一书 4:17; 约翰福音 15:22–24"> <span className="woj">我实在告诉你们：当审判的日子，所多玛和蛾摩拉所受的比那城还容易受呢！</span></span>
</div>
</div>

## 警戒勉励

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 10:3; 腓立比书 2:15; 哥林多前书 14:20"> <span className="woj">“我差你们去，如同羊进入狼群，所以你们要灵巧像蛇，驯良像鸽子。</span></span>
<span className="v" id="v17" data-v="17" data-xref="马可福音 13:9; 马太福音 23:34; 使徒行传 26:11"> <span className="woj">你们要防备人，因为他们要把你们交给公会，也要在会堂里鞭打你们，</span></span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 5:25–27; 马太福音 8:4; 诗篇 2:1–6"> <span className="woj">并且你们要为我的缘故被送到诸侯君王面前，对他们和外邦人作见证。</span></span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 4:12; 马可福音 13:11–13; 提摩太后书 4:17"> <span className="woj">你们被交的时候，不要思虑怎样说话或说什么话，到那时候必赐给你们当说的话；</span></span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 21:15; 使徒行传 6:10; 路加福音 12:12"> <span className="woj">因为不是你们自己说的，乃是你们父的灵在你们里头说的。</span></span>
</div>
</div>

## 服侍主之艰难

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 21:16–17; 弥迦书 7:5–6; 马可福音 13:12–13"> <span className="woj">“弟兄要把弟兄，父亲要把儿子，送到死地；儿女要与父母为敌，害死他们。</span></span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 24:13; 雅各书 1:12; 启示录 2:10"> <span className="woj">并且你们要为我的名被众人恨恶，唯有忍耐到底的，必然得救。</span></span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 16:28; 使徒行传 8:1; 马可福音 13:26"> <span className="woj">有人在这城里逼迫你们，就逃到那城里去。我实在告诉你们：以色列的城邑你们还没有走遍，人子就到了。</span></span>
</div>
</div>

## 学生不能高过先生

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约翰福音 15:20; 路加福音 6:40; 约翰福音 13:16"> <span className="woj">“学生不能高过先生，仆人不能高过主人。</span></span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 11:15; 马太福音 12:24; 马太福音 9:34"> <span className="woj">学生和先生一样，仆人和主人一样，也就罢了。人既骂家主是别西卜</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“别西卜”是鬼王的名。">a</a></sup><span className="woj">，何况他的家人呢？</span></span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 8:17; 马可福音 4:22; 耶利米书 1:8"> <span className="woj">所以不要怕他们，因为掩盖的事没有不露出来的，隐藏的事没有不被人知道的。</span></span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 5:20; 约翰福音 16:13; 约翰福音 16:1"> <span className="woj">我在暗中告诉你们的，你们要在明处说出来；你们耳中所听的，要在房上宣扬出来。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 12:4–5; 以赛亚书 8:12–13; 启示录 2:10"> <span className="woj">那杀身体不能杀灵魂的，不要怕他们；唯有能把身体和灵魂都灭在地狱里的，正要怕他。</span></span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 12:6–7; 诗篇 104:27–30"> <span className="woj">两个麻雀不是卖一分银子吗？若是你们的父不许，一个也不能掉在地上。</span></span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 12:7; 撒母耳记上 14:45; 使徒行传 27:34"> <span className="woj">就是你们的头发，也都被数过了。</span></span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 12:24; 诗篇 8:5; 马太福音 6:26"> <span className="woj">所以，不要惧怕，你们比许多麻雀还贵重。</span></span>
<span className="v" id="v32" data-v="32" data-xref="启示录 3:5; 罗马书 10:9–10; 路加福音 12:8–9"> <span className="woj">凡在人面前认我的，我在我天上的父面前也必认他；</span></span>
<span className="v" id="v33" data-v="33" data-xref="提摩太后书 2:12; 路加福音 9:26; 路加福音 12:9"> <span className="woj">凡在人面前不认我的，我在我天上的父面前也必不认他。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="路加福音 12:49–53; 使徒行传 14:4; 使徒行传 13:45–50"> <span className="woj">“你们不要想我来是叫地上太平，我来并不是叫地上太平，乃是叫地上动刀兵。</span></span>
<span className="v" id="v35" data-v="35" data-xref="弥迦书 7:5–6; 马太福音 10:21; 路加福音 21:16"> <span className="woj">因为我来是叫</span><br /><span className="pl pl-1 woj">‘人与父亲生疏，</span><br /><span className="pl pl-1 woj">女儿与母亲生疏，</span><br /><span className="pl pl-1 woj">媳妇与婆婆生疏；</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="弥迦书 7:6; 耶利米书 12:6; 诗篇 41:9"> <span className="pl pl-1 woj">人的仇敌就是自己家里的人’。</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 14:26; 马太福音 22:37; 腓立比书 3:7–9"> <span className="woj">爱父母过于爱我的，不配做我的门徒；爱儿女过于爱我的，不配做我的门徒；</span></span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 14:27; 马可福音 8:34; 马太福音 16:24"> <span className="woj">不背着他的十字架跟从我的，也不配做我的门徒。</span></span>

## 服侍主的赏赐

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="约翰福音 13:20; 路加福音 9:48; 路加福音 10:16"> <span className="woj">“人接待你们，就是接待我；接待我，就是接待那差我来的。</span></span>

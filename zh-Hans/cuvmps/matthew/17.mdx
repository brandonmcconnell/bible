## 改变形像

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 9:28–36; 马太福音 26:37; 马可福音 5:37"> 过了六天，耶稣带着彼得、雅各和雅各的兄弟约翰暗暗地上了高山，</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 104:2; 马太福音 28:3; 路加福音 9:29"> 就在他们面前变了形像，脸面明亮如日头，衣裳洁白如光。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 24:44; 马可福音 9:4; 玛拉基书 4:5"> 忽然，有摩西、以利亚向他们显现，同耶稣说话。</span>
<span className="v" id="v4" data-v="4" data-xref="马可福音 9:5–6; 路加福音 9:33; 约翰福音 14:8–9"> 彼得对耶稣说：“主啊，我们在这里真好！你若愿意，我就在这里搭三座棚：一座为你，一座为摩西，一座为以利亚。”</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 3:17; 马太福音 12:18; 申命记 18:15"> 说话之间，忽然有一朵光明的云彩遮盖他们，且有声音从云彩里出来说：“这是我的爱子，我所喜悦的，你们要听他！”</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 26:14; 彼得后书 1:18; 但以理书 8:17"> 门徒听见，就俯伏在地，极其害怕。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 10:18; 马太福音 14:27; 但以理书 8:18"> 耶稣进前来，摸他们说：<span className="woj">“起来，不要害怕！”</span></span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 9:36; 马可福音 9:8; 使徒行传 12:10–11"> 他们举目不见一人，只见耶稣在那里。</span>
</div>
</div>

## 以约翰譬以利亚

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马可福音 8:30; 马可福音 9:9–13; 马太福音 17:23"> 下山的时候，耶稣吩咐他们说：<span className="woj">“人子还没有从死里复活，你们不要将所看见的告诉人。”</span></span>
<span className="v" id="v10" data-v="10" data-xref="玛拉基书 4:5–6; 马太福音 11:14; 约翰福音 1:21"> 门徒问耶稣说：“文士为什么说以利亚必须先来？”</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 3:21; 路加福音 1:16–17; 玛拉基书 4:6"> 耶稣回答说：<span className="woj">“以利亚固然先来，并要复兴万事。</span></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 53:3–12; 马太福音 16:21; 使徒行传 13:24–28"> <span className="woj">只是我告诉你们：以利亚已经来了，人却不认识他，竟任意待他。人子也将要这样受他们的害。”</span></span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 11:14"> 门徒这才明白耶稣所说的是指着施洗的约翰。</span>
</div>
</div>

## 害癫痫病的孩子

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马可福音 9:14–29; 马可福音 1:40; 使徒行传 10:25–26"> 耶稣和门徒到了众人那里，有一个人来见耶稣，跪下，</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 4:24; 约伯记 1:10–19; 马可福音 9:20–22"> 说：“主啊，怜悯我的儿子！他害癫痫的病很苦，屡次跌在火里，屡次跌在水里。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 17:19–20; 路加福音 9:40; 使徒行传 19:15–16"> 我带他到你门徒那里，他们却不能医治他。”</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 14:11; 马太福音 6:30; 马可福音 16:14"> 耶稣说：<span className="woj">“唉！这又不信又悖谬的世代啊，我在你们这里要到几时呢？我忍耐你们要到几时呢？把他带到我这里来吧！”</span></span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 9:22; 马可福音 1:34; 马可福音 5:8"> 耶稣斥责那鬼，鬼就出来，从此孩子就痊愈了。</span>
</div>
</div>

## 信心的能力

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马可福音 9:28; 马可福音 4:10"> 门徒暗暗地到耶稣跟前说：“我们为什么不能赶出那鬼呢？”</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 17:6; 马可福音 11:23; 路加福音 1:37"> 耶稣说：<span className="woj">“是因你们的信心小。我实在告诉你们：你们若有信心像一粒芥菜种，就是对这座山说：‘你从这边挪到那边！’，它也必挪去；并且你们没有一件不能做的事了。</span></span>
<span className="v" id="v21" data-v="21"> <span className="woj">至于这一类的鬼，若不祷告、禁食，他就不出来</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：不能赶他出来。">a</a></sup><span className="woj">。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马太福音 16:21; 路加福音 18:31–34; 马太福音 17:23"> 他们还住在加利利的时候，耶稣对门徒说：<span className="woj">“人子将要被交在人手里，</span></span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 16:21; 以赛亚书 53:10–12; 马可福音 8:31"> <span className="woj">他们要杀害他，第三日他要复活。”</span>门徒就大大地忧愁。</span>
</div>
</div>

## 从鱼口得税银

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出埃及记 38:26; 出埃及记 30:13; 马可福音 9:33"> 到了迦百农，有收丁税的人来见彼得，说：“你们的先生不纳丁税<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="丁税约有半块钱。">b</a></sup>吗？”</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 22:21; 罗马书 13:6–7; 马太福音 22:17"> 彼得说：“纳。”他进了屋子，耶稣先向他说：<span className="woj">“西门，你的意思如何？世上的君王向谁征收关税、丁税？是向自己的儿子呢，是向外人呢？”</span></span>
<span className="v" id="v26" data-v="26"> 彼得说：“是向外人。”耶稣说：<span className="woj">“既然如此，儿子就可以免税了。</span></span>
<span className="v" id="v27" data-v="27" data-xref="哥林多后书 6:3; 哥林多前书 8:9; 哥林多前书 9:19–22"> <span className="woj">但恐怕触犯</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“触犯”原文作“绊倒”。">c</a></sup><span className="woj">他们，你且往海边去钓鱼，把先钓上来的鱼拿起来，开了它的口，必得一块钱，可以拿去给他们，做你我的税银。”</span></span>

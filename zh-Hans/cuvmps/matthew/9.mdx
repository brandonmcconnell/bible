## 医治瘫子

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 4:13; 路加福音 8:37; 马太福音 8:18"> 耶稣上了船，渡过海，来到自己的城里。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 2:1–12; 路加福音 5:18–26; 耶利米书 31:33–34"> 有人用褥子抬着一个瘫子到耶稣跟前来。耶稣见他们的信心，就对瘫子说：<span className="woj">“小子，放心吧，你的罪赦了！”</span></span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 26:65; 路加福音 5:21; 利未记 24:16"> 有几个文士心里说：“这个人说僭妄的话了！”</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 6:8; 马太福音 12:25; 启示录 2:23"> 耶稣知道他们的心意，就说：<span className="woj">“你们为什么心里怀着恶念呢？</span></span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 5:8–14; 马可福音 2:9–12; 使徒行传 3:16"> <span className="woj">或说‘你的罪赦了’，或说‘你起来行走’，哪一样容易呢？</span></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 43:25; 马太福音 9:5; 约翰福音 20:21–23"> <span className="woj">但要叫你们知道，人子在地上有赦罪的权柄。”</span>就对瘫子说：<span className="woj">“起来，拿你的褥子回家去吧！”</span></span>
<span className="v" id="v7" data-v="7"> 那人就起来，回家去了。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 7:16; 马太福音 15:31; 使徒行传 4:21"> 众人看见都惊奇，就归荣耀于神，因为他将这样的权柄赐给人。</span>
</div>
</div>

## 马太被召

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 5:27–38; 马可福音 2:14–22; 路加福音 19:2–10"> 耶稣从那里往前走，看见一个人，名叫马太，坐在税关上，就对他说：<span className="woj">“你跟从我来！”</span>他就起来跟从了耶稣。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 1:13–16; 路加福音 5:29–32; 马可福音 2:15–17"> 耶稣在屋里坐席的时候，有好些税吏和罪人来，与耶稣和他的门徒一同坐席。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 11:19; 路加福音 5:30; 马可福音 2:16"> 法利赛人看见，就对耶稣的门徒说：“你们的先生为什么和税吏并罪人一同吃饭呢？”</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 5:31; 启示录 3:17–18; 马可福音 2:17"> 耶稣听见就说：<span className="woj">“康健的人用不着医生，有病的人才用得着。</span></span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 2:17; 路加福音 19:10; 何西阿书 6:6"> <span className="woj">经上说：‘我喜爱怜恤，不喜爱祭祀’，这句话的意思你们且去揣摩；我来本不是召义人，乃是召罪人。”</span></span>
</div>
</div>

## 新旧难合的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 5:33–39; 马可福音 2:18–22; 马太福音 6:16"> 那时，约翰的门徒来见耶稣，说：“我们和法利赛人常常禁食，你的门徒倒不禁食，这是为什么呢？”</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 19:9; 约翰福音 3:29; 启示录 21:2"> 耶稣对他们说：<span className="woj">“新郎和陪伴之人同在的时候，陪伴之人岂能哀恸呢？但日子将到，新郎要离开他们，那时候他们就要禁食。</span></span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 3:1–2; 约翰福音 16:12; 诗篇 125:3"> <span className="woj">没有人把新布补在旧衣服上，因为所补上的反带坏了那衣服，破的就更大了。</span></span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 9:4; 约伯记 32:19; 诗篇 119:83"> <span className="woj">也没有人把新酒装在旧皮袋里，若是这样，皮袋就裂开，酒漏出来，连皮袋也坏了。唯独把新酒装在新皮袋里，两样就都保全了。”</span></span>
</div>
</div>

## 医患血漏的女人

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 8:41–56; 马可福音 5:22–43; 马太福音 8:2"> 耶稣说这话的时候，有一个管会堂的来拜他，说：“我女儿刚才死了，求你去按手在她身上，她就必活了。”</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 10:38; 加拉太书 6:9–10; 马太福音 8:7"> 耶稣便起来跟着他去，门徒也跟了去。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 8:43–56; 马太福音 14:36; 马可福音 6:56"> 有一个女人患了十二年的血漏，来到耶稣背后，摸他的衣裳穗子，</span>
<span className="v" id="v21" data-v="21" data-xref="马可福音 5:26–33; 路加福音 8:45–47; 使徒行传 19:12"> 因为她心里说：“我只摸他的衣裳，就必痊愈。”</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 7:50; 马太福音 15:28; 马太福音 9:2"> 耶稣转过来看见她，就说：<span className="woj">“女儿，放心！你的信救了你。”</span>从那时候，女人就痊愈了。</span>
</div>
</div>

<span className="v" id="v26" data-v="26" data-xref="马太福音 4:24; 马太福音 14:1–2; 马可福音 1:45"> 于是这风声传遍了那地方。</span>

## 两个瞎子得医治

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马太福音 15:22; 马太福音 20:30–31; 马可福音 10:46–48"> 耶稣从那里往前走，有两个瞎子跟着他，喊叫说：“大卫的子孙，可怜我们吧！”</span>
<span className="v" id="v28" data-v="28" data-xref="马可福音 9:23–24; 马太福音 13:58; 马太福音 8:2"> 耶稣进了房子，瞎子就来到他跟前，耶稣说：<span className="woj">“你们信我能做这事吗？”</span>他们说：“主啊，我们信。”</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 15:28; 马可福音 10:52; 马太福音 8:13"> 耶稣就摸他们的眼睛，说：<span className="woj">“照着你们的信给你们成全了吧！”</span></span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 8:4; 路加福音 5:14; 马太福音 17:9"> 他们的眼睛就开了。耶稣切切地嘱咐他们，说：<span className="woj">“你们要小心，不可叫人知道。”</span></span>
<span className="v" id="v31" data-v="31" data-xref="马可福音 7:36; 马太福音 9:26; 马可福音 1:44–45"> 他们出去，竟把他的名声传遍了那地方。</span>

## 赶出哑巴鬼

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马太福音 4:24; 马太福音 12:22–24; 路加福音 11:14"> 他们出去的时候，有人将鬼所附的一个哑巴带到耶稣跟前来。</span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 35:6; 马可福音 7:32–37; 出埃及记 4:11–12"> 鬼被赶出去，哑巴就说出话来。众人都稀奇说：“在以色列中从来没有见过这样的事！”</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 11:15; 马可福音 3:22; 马太福音 12:23–24"> 法利赛人却说：“他是靠着鬼王赶鬼。”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 4:23–24; 使徒行传 10:38; 马可福音 6:56"> 耶稣走遍各城各乡，在会堂里教训人，宣讲天国的福音，又医治各样的病症。</span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 6:34; 民数记 27:17; 耶利米书 50:6"> 他看见许多的人，就怜悯他们，因为他们困苦流离，如同羊没有牧人一般。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 10:2; 马可福音 16:15; 哥林多前书 3:9"> 于是对门徒说：<span className="woj">“要收的庄稼多，做工的人少。</span></span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 10:1–2; 耶利米书 3:15; 帖撒罗尼迦后书 3:1"> <span className="woj">所以，你们当求庄稼的主打发工人出去收他的庄稼。”</span></span>
</div>
</div>

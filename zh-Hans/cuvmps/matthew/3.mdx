## 施洗约翰传道

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 40:3–6; 约翰福音 1:6–8; 路加福音 1:76"> 那时，有施洗的约翰出来，在犹太的旷野传道说：</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 4:17; 马可福音 1:15; 但以理书 2:44"> “天国近了，你们应当悔改！”</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 40:3; 玛拉基书 3:1; 约翰福音 1:23"> 这人就是先知以赛亚所说的，他说：“在旷野有人声喊着说：<br /><span className="pl pl-1">‘预备主的道，</span><br /><span className="pl pl-1">修直他的路！’”</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 1:8; 撒迦利亚书 13:4; 马可福音 1:6"> 这约翰身穿骆驼毛的衣服，腰束皮带，吃的是蝗虫、野蜜。</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 1:5; 路加福音 3:7; 约翰福音 3:23"> 那时，耶路撒冷和犹太全地并约旦河一带地方的人，都出去到约翰那里，</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 19:18; 马太福音 3:13–16; 使徒行传 2:38–41"> 承认他们的罪，在约旦河里受他的洗。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 12:34; 帖撒罗尼迦前书 1:10; 罗马书 5:9"> 约翰看见许多法利赛人和撒都该人也来受洗，就对他们说：“毒蛇的种类！谁指示你们逃避将来的愤怒呢？</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 3:8; 使徒行传 26:20; 彼得后书 1:4–8"> 你们要结出果子来，与悔改的心相称！</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 3:8; 罗马书 9:7–8; 加拉太书 3:27–29"> 不要自己心里说：‘有亚伯拉罕为我们的祖宗。’我告诉你们，神能从这些石头中给亚伯拉罕兴起子孙来。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 15:6; 路加福音 3:9; 马太福音 7:19"> 现在斧子已经放在树根上，凡不结好果子的树就砍下来，丢在火里。</span>
</div>
</div>

## 必有圣灵与火的洗

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 4:4; 路加福音 3:16; 使徒行传 1:5"> “我是用水给你们施洗，叫你们悔改；但那在我以后来的，能力比我更大，我就是给他提鞋也不配，他要用圣灵与火给你们施洗。</span>
<span className="v" id="v12" data-v="12" data-xref="玛拉基书 4:1; 马太福音 13:30; 路加福音 3:17"> 他手里拿着簸箕，要扬净他的场，把麦子收在仓里，把糠用不灭的火烧尽了。”</span>
</div>
</div>

## 耶稣受洗

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约翰福音 1:32–34; 马太福音 2:22; 马可福音 1:9–11"> 当下耶稣从加利利来到约旦河，见了约翰，要受他的洗。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 3:3–7; 使徒行传 1:5–8; 约翰福音 13:6–8"> 约翰想要拦住他，说：“我当受你的洗，你反倒上我这里来吗？”</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 4:34; 约翰福音 15:10; 诗篇 40:7–8"> 耶稣回答说：<span className="woj">“你暂且许我，因为我们理当这样尽诸般的义</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：礼。">a</a></sup><span className="woj">。”</span>于是约翰许了他。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 11:2; 马可福音 1:10; 路加福音 3:21–22"> 耶稣受了洗，随即从水里上来。天忽然为他开了，他就看见神的灵仿佛鸽子降下，落在他身上；</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 42:1; 诗篇 2:7; 马太福音 17:5"> 从天上有声音说：“这是我的爱子，我所喜悦的。”</span>
</div>
</div>

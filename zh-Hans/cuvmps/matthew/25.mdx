## 十童女的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:35–36; 腓立比书 2:15–16; 马太福音 24:42–51"> <span className="woj">“那时，天国好比十个童女拿着灯出去迎接新郎。</span></span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 24:2; 哥林多前书 10:1–5; 马太福音 13:19–23"> <span className="woj">其中有五个是愚拙的，五个是聪明的。</span></span>
<span className="v" id="v3" data-v="3" data-xref="启示录 3:15–16; 提摩太后书 3:5; 以赛亚书 48:1–2"> <span className="woj">愚拙的拿着灯，却不预备油；</span></span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 8:9; 约翰一书 2:27; 约翰一书 2:20"> <span className="woj">聪明的拿着灯，又预备油在器皿里。</span></span>
<span className="v" id="v5" data-v="5" data-xref="哈巴谷书 2:3; 帖撒罗尼迦前书 5:6–8; 彼得后书 3:4–9"> <span className="woj">新郎迟延的时候，她们都打盹睡着了。</span></span>
<span className="v" id="v6" data-v="6" data-xref="彼得后书 3:10; 马太福音 24:31; 马太福音 24:44"> <span className="woj">半夜有人喊着说：‘新郎来了，你们出来迎接他！’</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 12:35; 启示录 3:19–20; 彼得后书 3:14"> <span className="woj">那些童女就都起来收拾灯。</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 13:9; 路加福音 12:35; 希伯来书 4:1"> <span className="woj">愚拙的对聪明的说：‘请分点油给我们，因为我们的灯要灭了。’</span></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 49:7–9; 启示录 3:17–18; 以赛亚书 55:6–7"> <span className="woj">聪明的回答说：‘恐怕不够你我用的，不如你们自己到卖油的那里去买吧。’</span></span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 13:25; 马太福音 24:44; 路加福音 12:36–37"> <span className="woj">她们去买的时候，新郎到了，那预备好了的同他进去坐席，门就关了。</span></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 7:21–23; 希伯来书 12:16–17"> <span className="woj">其余的童女随后也来了，说：‘主啊，主啊，给我们开门！’</span></span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 8:3; 提摩太后书 2:19; 约翰福音 10:27"> <span className="woj">他却回答说：‘我实在告诉你们：我不认识你们。’</span></span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 24:42–44; 启示录 16:15; 帖撒罗尼迦前书 5:6"> <span className="woj">所以，你们要警醒，因为那日子、那时辰，你们不知道。</span></span>
</div>
</div>

## 按才干受责任

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马可福音 13:34; 路加福音 19:12–27; 彼得前书 4:9–11"> <span className="woj">“天国又好比一个人要往外国去，就叫了仆人来，把他的家业交给他们，</span></span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 18:24; 路加福音 19:13–14; 路加福音 12:48"> <span className="woj">按着各人的才干给他们银子，一个给了五千，一个给了二千，一个给了一千，就往外国去了。</span></span>
<span className="v" id="v16" data-v="16" data-xref="约翰三书 1:5–8; 提摩太前书 6:17–18; 提摩太后书 2:6"> <span className="woj">那领五千的随即拿去做买卖，另外赚了五千。</span></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 3:9–10; 以弗所书 5:16; 彼得前书 4:10"> <span className="woj">那领二千的也照样另赚了二千。</span></span>
<span className="v" id="v18" data-v="18" data-xref="彼得后书 1:8; 哈该书 1:2–4; 玛拉基书 1:10"> <span className="woj">但那领一千的去掘开地，把主人的银子埋藏了。</span></span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 3:12–15; 哥林多后书 5:10; 罗马书 14:7–12"> <span className="woj">过了许久，那些仆人的主人来了，和他们算账。</span></span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 20:24; 路加福音 19:16–17; 歌罗西书 1:29"> <span className="woj">那领五千银子的又带着那另外的五千来，说：‘主啊，你交给我五千银子，请看，我又赚了五千。’</span></span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 25:23; 路加福音 16:10; 约翰福音 12:26"> <span className="woj">主人说：‘好，你这又良善又忠心的仆人，你在不多的事上有忠心，我要把许多事派你管理。可以进来享受你主人的快乐！’</span></span>
<span className="v" id="v22" data-v="22" data-xref="哥林多后书 8:12; 哥林多后书 8:7–8; 哥林多后书 8:1–3"> <span className="woj">那领二千的也来，说：‘主啊，你交给我二千银子，请看，我又赚了二千。’</span></span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 25:21; 马可福音 14:8–9; 马可福音 12:41–44"> <span className="woj">主人说：‘好，你这又良善又忠心的仆人，你在不多的事上有忠心，我要把许多事派你管理。可以进来享受你主人的快乐！’</span></span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 19:20–22; 路加福音 15:29; 玛拉基书 3:14–15"> <span className="woj">那领一千的也来，说：‘主啊，我知道你是忍心的人，没有种的地方要收割，没有散的地方要聚敛。</span></span>
<span className="v" id="v25" data-v="25" data-xref="提摩太后书 1:6–7; 罗马书 8:15; 启示录 21:8"> <span className="woj">我就害怕，去把你的一千银子埋藏在地里。请看，你的原银子在这里。’</span></span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 18:32; 约伯记 15:5–6"> <span className="woj">主人回答说：‘你这又恶又懒的仆人！你既知道我没有种的地方要收割，没有散的地方要聚敛，</span></span>
<span className="v" id="v27" data-v="27" data-xref="申命记 23:19–20; 罗马书 3:19; 犹大书 1:15"> <span className="woj">就当把我的银子放给兑换银钱的人，到我来的时候，可以连本带利收回。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 19:24; 路加福音 10:42"> <span className="woj">夺过他这一千来，给那有一万的！</span></span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 8:18; 马可福音 4:25; 马太福音 13:12"> <span className="woj">因为凡有的，还要加给他，叫他有余；没有的，连他所有的也要夺过来。</span></span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 8:12; 启示录 3:15–16; 马太福音 13:50"> <span className="woj">把这无用的仆人丢在外面黑暗里，在那里必要哀哭切齿了。’</span></span>
</div>

## 论审判的日子

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="启示录 1:7; 帖撒罗尼迦后书 1:7–8; 马太福音 19:28"> <span className="woj">“当人子在他荣耀里同着众天使降临的时候，要坐在他荣耀的宝座上。</span></span>
<span className="v" id="v32" data-v="32" data-xref="玛拉基书 3:18; 马太福音 13:49; 哥林多后书 5:10"> <span className="woj">万民都要聚集在他面前，他要把他们分别出来，好像牧羊的分别绵羊山羊一般：</span></span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 100:3; 约翰福音 10:26–28; 约翰福音 21:15–17"> <span className="woj">把绵羊安置在右边，山羊在左边。</span></span>
<span className="v" id="v34" data-v="34" data-xref="彼得前书 1:19–20; 雅各书 2:5; 启示录 21:7"> <span className="woj">于是，王要向那右边的说：‘你们这蒙我父赐福的，可来承受那创世以来为你们所预备的国。</span></span>
<span className="v" id="v35" data-v="35" data-xref="约翰一书 3:16–19; 雅各书 2:15–16; 申命记 15:7–11"> <span className="woj">因为我饿了，你们给我吃；渴了，你们给我喝；我做客旅，你们留我住；</span></span>
<span className="v" id="v36" data-v="36" data-xref="雅各书 1:27; 提摩太后书 1:16–18; 雅各书 5:14–15"> <span className="woj">我赤身露体，你们给我穿；我病了，你们看顾我；我在监里，你们来看我。’</span></span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 6:3; 历代志上 29:14; 彼得前书 5:5–6"> <span className="woj">义人就回答说：‘主啊，我们什么时候见你饿了给你吃，渴了给你喝？</span></span>
<span className="v" id="v38" data-v="38"> <span className="woj">什么时候见你做客旅留你住，或是赤身露体给你穿？</span></span>
<span className="v" id="v39" data-v="39"> <span className="woj">又什么时候见你病了或是在监里，来看你呢？’</span></span>
<span className="v" id="v40" data-v="40" data-xref="箴言 19:17; 箴言 14:31; 马太福音 10:42"> <span className="woj">王要回答说：‘我实在告诉你们：这些事你们既做在我这弟兄中一个最小的身上，就是做在我身上了。’</span></span>
<span className="v" id="v41" data-v="41" data-xref="彼得后书 2:4; 犹大书 1:6–7; 帖撒罗尼迦后书 1:9"> <span className="woj">王又要向那左边的说：‘你们这被咒诅的人，离开我，进入那为魔鬼和他的使者所预备的永火里去！</span></span>
<span className="v" id="v42" data-v="42" data-xref="雅各书 2:15–24; 约翰福音 5:23; 马太福音 12:30"> <span className="woj">因为我饿了，你们不给我吃；渴了，你们不给我喝；</span></span>
<span className="v" id="v43" data-v="43"> <span className="woj">我做客旅，你们不留我住；我赤身露体，你们不给我穿；我病了，我在监里，你们不来看顾我。’</span></span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 7:22; 路加福音 10:29; 马太福音 25:24–27"> <span className="woj">他们也要回答说：‘主啊，我们什么时候见你饿了，或渴了，或做客旅，或赤身露体，或病了，或在监里，不伺候你呢？’</span></span>
<span className="v" id="v45" data-v="45" data-xref="箴言 21:13; 箴言 17:5; 箴言 14:31"> <span className="woj">王要回答说：‘我实在告诉你们：这些事你们既不做在我这弟兄中一个最小的身上，就是不做在我身上了。’</span></span>
<span className="v" id="v46" data-v="46" data-xref="但以理书 12:2; 约翰福音 3:36; 约翰福音 5:29"> <span className="woj">这些人要往永刑里去，那些义人要往永生里去。”</span></span>

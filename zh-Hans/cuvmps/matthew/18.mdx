## 天国里谁为大

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 9:33–37; 路加福音 9:46–48; 马太福音 20:20–28"> 当时，门徒进前来，问耶稣说：“天国里谁是最大的？”</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 19:13–14; 马可福音 9:36–37; 列王纪上 3:7"> 耶稣便叫一个小孩子来，使他站在他们当中，</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 10:14–15; 彼得前书 2:2; 马太福音 19:14"> 说：<span className="woj">“我实在告诉你们：你们若不回转，变成小孩子的样式，断不得进天国。</span></span>
<span className="v" id="v4" data-v="4" data-xref="雅各书 4:10; 路加福音 14:11; 马可福音 10:43"> <span className="woj">所以，凡自己谦卑像这小孩子的，他在天国里就是最大的。</span></span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 25:40; 马可福音 9:37; 约翰福音 13:20"> <span className="woj">凡为我的名接待一个像这小孩子的，就是接待我。</span></span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 9:42; 路加福音 17:1–2; 马太福音 18:10"> <span className="woj">凡使这信我的一个小子跌倒的，倒不如把大磨石拴在这人的颈项上，沉在深海里。</span></span>
</div>
</div>

## 绊倒人的有祸

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="路加福音 17:1; 哥林多前书 11:19; 马太福音 26:24"> <span className="woj">“这世界有祸了，因为将人绊倒；绊倒人的事是免不了的，但那绊倒人的有祸了！</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 5:29–30; 腓立比书 3:8–9; 罗马书 13:12"> <span className="woj">倘若你一只手或是一只脚叫你跌倒，就砍下来丢掉！你缺一只手或是一只脚进入永生，强如有两手两脚被丢在永火里。</span></span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 14:22; 马太福音 18:8; 马太福音 5:29"> <span className="woj">倘若你一只眼叫你跌倒，就把它剜出来丢掉！你只有一只眼进入永生，强如有两只眼被丢在地狱的火里。</span></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 91:11; 诗篇 34:7; 希伯来书 1:14"> <span className="woj">你们要小心，不可轻看这小子里的一个。我告诉你们，他们的使者在天上，常见我天父的面。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷在此有：11 人子来，为要拯救失丧的人。">a</a></sup></span>
</div>
</div>

## 迷路的羊

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西结书 34:12; 路加福音 15:4–7; 以西结书 34:16"> <span className="woj">“一个人若有一百只羊，一只走迷了路，你们的意思如何？他岂不撇下这九十九只，往山里去找那只迷路的羊吗？</span></span>
<span className="v" id="v13" data-v="13" data-xref="西番雅书 3:17; 路加福音 15:5–10; 雅各书 2:13"> <span className="woj">若是找着了，我实在告诉你们：他为这一只羊欢喜，比为那没有迷路的九十九只欢喜还大呢。</span></span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 17:12; 约翰福音 6:39–40; 彼得后书 3:9"> <span className="woj">你们在天上的父也是这样，不愿意这小子里失丧一个。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="利未记 19:17; 路加福音 17:3–4; 加拉太书 6:1"> <span className="woj">“倘若你的弟兄得罪你，你就去，趁着只有他和你在一处的时候，指出他的错来。他若听你，你便得了你的弟兄。</span></span>
<span className="v" id="v16" data-v="16" data-xref="申命记 19:15; 哥林多后书 13:1; 约翰福音 8:17"> <span className="woj">他若不听，你就另外带一两个人同去，要凭两三个人的口作见证，句句都可定准。</span></span>
<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦后书 3:6; 哥林多前书 5:9–7; 帖撒罗尼迦后书 3:14–15"> <span className="woj">若是不听他们，就告诉教会。若是不听教会，就看他像外邦人和税吏一样。</span></span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 16:19; 哥林多后书 2:10; 约翰福音 20:23"> <span className="woj">我实在告诉你们：凡你们在地上所捆绑的，在天上也要捆绑；凡你们在地上所释放的，在天上也要释放。</span></span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 7:7; 约翰一书 5:14–16; 马可福音 11:24"> <span className="woj">我又告诉你们：若是你们中间有两个人在地上同心合意地求什么事，我在天上的父必为他们成全。</span></span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 5:4; 启示录 21:3; 马太福音 28:20"> <span className="woj">因为无论在哪里，有两三个人奉我的名聚会，那里就有我在他们中间。”</span></span>
</div>
</div>

## 饶恕七十个七次

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 17:3–4; 马太福音 18:15"> 那时，彼得进前来，对耶稣说：“主啊，我弟兄得罪我，我当饶恕他几次呢？到七次可以吗？”</span>
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 3:13; 马可福音 11:25; 马太福音 6:14–15"> 耶稣说：<span className="woj">“我对你说，不是到七次，乃是到七十个七次。</span></span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 13:24; 罗马书 14:12; 马太福音 3:2"> <span className="woj">天国好像一个王要和他仆人算账。</span></span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 38:4; 诗篇 130:3–4; 路加福音 16:5"> <span className="woj">才算的时候，有人带了一个欠一千万银子的来。</span></span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 4:1; 尼希米记 5:5; 路加福音 7:42"> <span className="woj">因为他没有什么偿还之物，主人吩咐把他和他妻子儿女并一切所有的都卖了偿还。</span></span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 18:29; 路加福音 7:43; 马太福音 8:2"> <span className="woj">那仆人就俯伏拜他，说：‘主啊，宽容我！将来我都要还清。’</span></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 145:8; 尼希米记 9:17; 诗篇 86:15"> <span className="woj">那仆人的主人就动了慈心，把他释放了，并且免了他的债。</span></span>
</div>
</div>

## 不怜悯人的必不蒙怜悯

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马太福音 20:2; 以西结书 45:9; 申命记 15:2"> <span className="woj">“那仆人出来，遇见他的一个同伴欠他十两银子，便揪着他，掐住他的喉咙，说：‘你把所欠的还我！’</span></span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 18:26; 马太福音 6:12; 腓利门书 1:18–19"> <span className="woj">他的同伴就俯伏央求他，说：‘宽容我吧！将来我必还清。’</span></span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 22:27; 列王纪上 21:27–29"> <span className="woj">他不肯，竟去把他下在监里，等他还了所欠的债。</span></span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 12:15; 希伯来书 13:3; 马可福音 3:5"> <span className="woj">众同伴看见他所做的事，就甚忧愁，去把这事都告诉了主人。</span></span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 19:22; 马太福音 25:26; 罗马书 3:19"> <span className="woj">于是主人叫了他来，对他说：‘你这恶奴才！你央求我，我就把你所欠的都免了。</span></span>
<span className="v" id="v33" data-v="33" data-xref="歌罗西书 3:13; 马太福音 6:12; 以弗所书 4:32–2"> <span className="woj">你不应当怜恤你的同伴，像我怜恤你吗？’</span></span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 5:25–26; 雅各书 2:13; 路加福音 12:58–59"> <span className="woj">主人就大怒，把他交给掌刑的，等他还清了所欠的债。</span></span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 6:14–15; 雅各书 2:13; 路加福音 6:37–38"> <span className="woj">你们各人若不从心里饶恕你的弟兄，我天父也要这样待你们了。”</span></span>
</div>

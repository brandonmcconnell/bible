<div className="bp">

<span className="v" id="v10" data-v="10"> <span className="woj">及至那先雇的来了，他们以为必要多得，谁知也是各得一钱。</span></span>

## 谁愿为首当做仆人

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马太福音 4:21; 马可福音 10:35–45; 马太福音 8:2"> 那时，西庇太儿子的母亲同她两个儿子上前来拜耶稣，求他一件事。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 19:28; 马可福音 10:36–37; 以斯帖记 5:3"> 耶稣说：<span className="woj">“你要什么呢？”</span>她说：“愿你叫我这两个儿子在你国里，一个坐在你右边，一个坐在你左边。”</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 26:42; 路加福音 22:42; 马太福音 26:39"> 耶稣回答说：<span className="woj">“你们不知道所求的是什么。我将要喝的杯，你们能喝吗？”</span>他们说：“我们能。”</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 1:9; 马太福音 25:34; 使徒行传 12:2"> 耶稣说：<span className="woj">“我所喝的杯，你们必要喝；只是坐在我的左右，不是我可以赐的，乃是我父为谁预备的，就赐给谁。”</span></span>
<span className="v" id="v24" data-v="24" data-xref="彼得前书 5:5; 腓立比书 2:3; 马可福音 10:41"> 那十个门徒听见，就恼怒他们弟兄二人。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 22:25–27; 马太福音 20:25–28; 约翰福音 13:12–17"> 耶稣叫了他们来，说：<span className="woj">“你们知道，外邦人有君王为主治理他们，有大臣操权管束他们。</span></span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 10:43; 马可福音 9:35; 马可福音 10:45"> <span className="woj">只是在你们中间不可这样，你们中间谁愿为大，就必做你们的用人；</span></span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 22:26; 马可福音 9:33–35; 马太福音 18:4"> <span className="woj">谁愿为首，就必做你们的仆人。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 22:27; 希伯来书 9:28; 提多书 2:14"> <span className="woj">正如人子来不是要受人的服侍，乃是要服侍人，并且要舍命做多人的赎价。”</span></span>
</div>

## 使两个瞎子看见

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马可福音 10:46–52; 路加福音 18:35–43; 马太福音 9:27–31"> 他们出耶利哥的时候，有极多的人跟随他。</span>
<span className="v" id="v30" data-v="30" data-xref="马可福音 10:46; 以赛亚书 42:16; 马太福音 21:9"> 有两个瞎子坐在路旁，听说是耶稣经过，就喊着说：“主啊，大卫的子孙，可怜我们吧！”</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 19:13; 歌罗西书 4:2; 马太福音 7:7–8"> 众人责备他们，不许他们作声，他们却越发喊着说：“主啊，大卫的子孙，可怜我们吧！”</span>
<span className="v" id="v32" data-v="32" data-xref="以西结书 36:37; 腓立比书 4:6; 马太福音 20:21"> 耶稣就站住，叫他们来，说：<span className="woj">“要我为你们做什么？”</span></span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 119:18; 以弗所书 1:17–19"> 他们说：“主啊，要我们的眼睛能看见！”</span>
<span className="v" id="v34" data-v="34" data-xref="希伯来书 4:15–16; 马太福音 9:29; 使徒行传 26:18"> 耶稣就动了慈心，把他们的眼睛一摸，他们立刻看见，就跟从了耶稣。</span>

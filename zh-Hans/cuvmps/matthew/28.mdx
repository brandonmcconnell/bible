## 从死里复活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 16:1–8; 约翰福音 20:1–10; 马太福音 27:56"> 安息日将尽，七日的头一日天快亮的时候，抹大拉的马利亚和那个马利亚来看坟墓。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 16:26; 约翰福音 20:12–13; 马可福音 16:3–5"> 忽然，地大震动，因为有主的使者从天上下来，把石头滚开，坐在上面。</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 9:3; 使徒行传 1:10; 马可福音 16:5"> 他的相貌如同闪电，衣服洁白如雪。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 1:17; 但以理书 10:7; 马太福音 27:65–66"> 看守的人就因他吓得浑身乱战，甚至和死人一样。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 1:17–18; 希伯来书 1:14; 以赛亚书 41:10"> 天使对妇女说：“不要害怕！我知道你们是寻找那钉十字架的耶稣。</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 16:6; 马太福音 12:40; 路加福音 24:6–8"> 他不在这里，照他所说的，已经复活了。你们来看安放主的地方！</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 26:32; 路加福音 24:22–24; 马太福音 28:10"> 快去告诉他的门徒，说他从死里复活了，并且在你们以先往加利利去，在那里你们要见他。看哪，我已经告诉你们了！”</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 2:11; 马可福音 16:8; 路加福音 24:36–41"> 妇女们就急忙离开坟墓，又害怕又大大地欢喜，跑去要报给他的门徒。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 28:17; 约翰福音 20:14–17; 马太福音 14:33"> 忽然，耶稣遇见她们，说：<span className="woj">“愿你们平安！”</span>她们就上前抱住他的脚拜他。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 8:29; 约翰福音 20:17; 马太福音 28:7"> 耶稣对她们说：<span className="woj">“不要害怕！你们去告诉我的弟兄，叫他们往加利利去，在那里必见我。”</span></span>
</div>
</div>

## 公会捏造谎言

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马太福音 27:65–66; 马太福音 28:4"> 她们去的时候，看守的兵有几个进城去，将所经历的事都报给祭司长。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 26:3–4; 使徒行传 4:5–22; 马太福音 27:1–2"> 祭司长和长老聚集商议，就拿许多银钱给兵丁，说：</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 26:64"> “你们要这样说：‘夜间我们睡觉的时候，他的门徒来把他偷去了。’</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 27:2; 使徒行传 12:19"> 倘若这话被巡抚听见，有我们劝他，保你们无事。”</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太前书 6:10; 马太福音 27:8; 马太福音 26:15"> 兵丁受了银钱，就照所嘱咐他们的去行。这话就传说在犹太人中间，直到今日。</span>
</div>
</div>

<span className="v" id="v17" data-v="17" data-xref="诗篇 45:11; 诗篇 2:12; 约翰福音 5:23"> 他们见了耶稣就拜他，然而还有人疑惑。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 3:35; 彼得前书 3:22; 马太福音 11:27"> 耶稣进前来，对他们说：<span className="woj">“天上地下所有的权柄都赐给我了。</span></span>

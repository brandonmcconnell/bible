## 耶和华不欲与民偕往

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 12:7; 出埃及记 32:13; 出埃及记 32:7"> 耶和华吩咐摩西说：“我曾起誓应许亚伯拉罕、以撒、雅各说：‘要将迦南地赐给你的后裔。’现在你和你从埃及地所领出来的百姓，要从这里往那地去。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 32:34; 约书亚记 24:11; 出埃及记 23:27–31"> 我要差遣使者在你前面，撵出迦南人、亚摩利人、赫人、比利洗人、希未人、耶布斯人，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 32:9–10; 出埃及记 3:8; 使徒行传 7:51"> 领你到那流奶与蜜之地。我自己不同你们上去，因为你们是硬着颈项的百姓，恐怕我在路上把你们灭绝。”</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 14:39; 民数记 14:1; 以西结书 26:16"> 百姓听见这凶信就悲哀，也没有人佩戴装饰。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 16:21; 民数记 16:45–46; 出埃及记 33:3–4"> 耶和华对摩西说：“你告诉以色列人说：‘耶和华说：你们是硬着颈项的百姓，我若一霎时临到你们中间，必灭绝你们。现在你们要把身上的装饰摘下来，使我可以知道怎样待你们。’”</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 33:4; 出埃及记 32:3; 耶利米书 2:19"> 以色列人从住何烈山以后，就把身上的装饰摘得干净。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 55:6–7; 出埃及记 29:42–43; 箴言 15:29"> 摩西素常将帐篷支搭在营外，离营却远，他称这帐篷为会幕。凡求问耶和华的，就到营外的会幕那里去。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 16:27"> 当摩西出营到会幕去的时候，百姓就都起来，各人站在自己帐篷的门口，望着摩西，直等到他进了会幕。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 99:7; 出埃及记 31:18; 出埃及记 13:21–22"> 摩西进会幕的时候，云柱降下来，立在会幕的门前，耶和华便与摩西说话。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 8:22; 列王纪上 8:14; 出埃及记 4:31"> 众百姓看见云柱立在会幕门前，就都起来，各人在自己帐篷的门口下拜。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 12:8; 申命记 34:10; 出埃及记 24:13"> 耶和华与摩西面对面说话，好像人与朋友说话一般。摩西转到营里去，唯有他的帮手，一个少年人嫩的儿子约书亚，不离开会幕。</span>
</div>
</div>

## 摩西祈耶和华与之偕往

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及记 33:17; 耶利米书 1:5; 约翰福音 10:14–15"> 摩西对耶和华说：“你吩咐我说：‘将这百姓领上去’，却没有叫我知道你要打发谁与我同去，只说：‘我按你的名认识你，你在我眼前也蒙了恩。’</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 119:33; 诗篇 25:4; 诗篇 27:11"> 我如今若在你眼前蒙恩，求你将你的道指示我，使我可以认识你，好在你眼前蒙恩。求你想到这民是你的民。”</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 21:44; 马太福音 11:28; 约书亚记 1:5"> 耶和华说：“我必亲自和你同去，使你得安息。”</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 34:9; 诗篇 4:6; 出埃及记 33:3"> 摩西说：“你若不亲自和我同去，就不要把我们从这里领上去。</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 4:7; 民数记 14:14; 列王纪上 8:53"> 人在何事上得以知道我和你的百姓在你眼前蒙恩呢？岂不是因你与我们同去，使我和你的百姓与地上的万民有分别吗？”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 65:24; 约翰一书 5:14–15; 出埃及记 33:12"> 耶和华对摩西说：“你这所求的我也要行，因为你在我眼前蒙了恩，并且我按你的名认识你。”</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 21:23; 出埃及记 33:20; 提多书 2:13"> 摩西说：“求你显出你的荣耀给我看。”</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 9:15–18; 以弗所书 1:6–8; 耶利米书 31:14"> 耶和华说：“我要显我一切的恩慈，在你面前经过，宣告我的名。我要恩待谁就恩待谁，要怜悯谁就怜悯谁。”</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 32:30; 约翰福音 1:18; 提摩太前书 6:16"> 又说：“你不能看见我的面，因为人见我的面不能存活。”</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 5:31; 撒迦利亚书 3:7; 约书亚记 20:4"> 耶和华说：“看哪，在我这里有地方，你要站在磐石上。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 91:1; 以赛亚书 2:21; 诗篇 91:4"> 我的荣耀经过的时候，我必将你放在磐石穴中，用我的手遮掩你，等我过去。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 33:20; 约翰福音 1:18; 提摩太前书 6:16"> 然后我要将我的手收回，你就得见我的背，却不得见我的面。”</span>
</div>
</div>

## 以色列人至旷野

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 33:10–12; 出埃及记 15:27; 出埃及记 17:1"> 以色列全会众从以琳起行，在出埃及后第二个月十五日，到了以琳和西奈中间汛的旷野。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 10:10; 出埃及记 15:24; 诗篇 106:25"> 以色列全会众在旷野向摩西、亚伦发怨言，</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 11:4–5; 民数记 20:3–5; 出埃及记 17:3"> 说：“巴不得我们早死在埃及地耶和华的手下，那时我们坐在肉锅旁边，吃得饱足。你们将我们领出来，到这旷野，是要叫这全会众都饿死啊！”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 10:3; 诗篇 78:24–25; 申命记 8:2"> 耶和华对摩西说：“我要将粮食从天降给你们。百姓可以出去，每天收每天的份，我好试验他们遵不遵我的法度。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 16:22–23; 出埃及记 35:2–3; 利未记 25:21–22"> 到第六天，他们要把所收进来的预备好了，比每天所收的多一倍。”</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 6:7; 民数记 16:28; 出埃及记 16:12–13"> 摩西、亚伦对以色列众人说：“到了晚上，你们要知道是耶和华将你们从埃及地领出来的。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 40:5; 民数记 16:11; 约翰福音 11:40"> 早晨，你们要看见耶和华的荣耀，因为耶和华听见你们向他所发的怨言了。我们算什么，你们竟向我们发怨言呢？”</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 13:2; 撒母耳记上 8:7; 帖撒罗尼迦前书 4:8"> 摩西又说：“耶和华晚上必给你们肉吃，早晨必给你们食物得饱，因为你们向耶和华发的怨言，他都听见了。我们算什么？你们的怨言不是向我们发的，乃是向耶和华发的。”</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 16:16; 出埃及记 16:2; 出埃及记 16:8"> 摩西对亚伦说：“你告诉以色列全会众说：‘你们就近耶和华面前，因为他已经听见你们的怨言了。’”</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 16:7; 民数记 16:19; 民数记 16:42"> 亚伦正对以色列全会众说话的时候，他们向旷野观看，不料，耶和华的荣光在云中显现。</span>
<span className="v" id="v11" data-v="11"> 耶和华晓谕摩西说：</span>
<span className="v" id="v12" data-v="12" data-xref="约珥书 3:17; 以西结书 39:22; 出埃及记 6:7"> “我已经听见以色列人的怨言。你告诉他们说：‘到黄昏的时候，你们要吃肉，早晨必有食物得饱，你们就知道我是耶和华你们的神。’”</span>
</div>
</div>

## 使鹑至降吗哪

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 11:9; 诗篇 105:40; 诗篇 78:27–28"> 到了晚上，有鹌鹑飞来，遮满了营。早晨，在营四围的地上有露水。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 11:7–9; 诗篇 105:40; 诗篇 78:24"> 露水上升之后，不料，野地面上有如白霜的小圆物。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 16:4; 约翰福音 6:58; 出埃及记 16:31"> 以色列人看见，不知道是什么，就彼此对问说：“这是什么呢？”摩西对他们说：“这就是耶和华给你们吃的食物。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 16:36; 出埃及记 16:18; 出埃及记 16:32–33"> 耶和华所吩咐的是这样：你们要按着各人的饭量，为帐篷里的人按着人数收起来，各拿一俄梅珥。”</span>
<span className="v" id="v17" data-v="17"> 以色列人就这样行，有多收的，有少收的。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 8:14–15"> 及至用俄梅珥量一量，多收的也没有余，少收的也没有缺，各人按着自己的饭量收取。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 12:10; 出埃及记 23:18; 马太福音 6:34"> 摩西对他们说：“所收的，不许什么人留到早晨。”</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 10:14; 民数记 16:15; 以弗所书 4:26"> 然而他们不听摩西的话，内中有留到早晨的，就生虫变臭了。摩西便向他们发怒。</span>
</div>
</div>

## 收取吗哪之例

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="箴言 6:6–11; 传道书 12:1; 哥林多后书 6:2"> 他们每日早晨，按着各人的饭量收取，日头一发热，就消化了。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 16:5; 利未记 25:22; 出埃及记 16:16"> 到第六天，他们收了双倍的食物，每人两俄梅珥。会众的官长来告诉摩西，</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 23:3; 出埃及记 31:15; 出埃及记 20:8–11"> 摩西对他们说：“耶和华这样说：‘明天是圣安息日，是向耶和华守的圣安息日。你们要烤的就烤了，要煮的就煮了，所剩下的都留到早晨。’”</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 16:20; 出埃及记 16:33"> 他们就照摩西的吩咐留到早晨，也不臭，里头也没有虫子。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 16:23; 出埃及记 16:29; 尼希米记 9:14"> 摩西说：“你们今天吃这个吧，因为今天是向耶和华守的安息日，你们在田野必找不着了。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 5:13; 出埃及记 20:9–11; 以西结书 46:1"> 六天可以收取，第七天乃是安息日，那一天必没有了。”</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 20:4"> 第七天，百姓中有人出去收，什么也找不着。</span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 78:10; 诗篇 106:13; 民数记 14:11"> 耶和华对摩西说：“你们不肯守我的诫命和律法，要到几时呢？</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 31:13; 以赛亚书 58:13–14; 以西结书 20:12"> 你们看，耶和华既将安息日赐给你们，所以第六天他赐给你们两天的食物，第七天各人要住在自己的地方，不许什么人出去。”</span>
<span className="v" id="v30" data-v="30" data-xref="申命记 5:12–14; 利未记 23:3; 希伯来书 4:9"> 于是百姓第七天安息了。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="雅歌 2:3; 民数记 11:6–9; 出埃及记 16:15"> 这食物，以色列家叫吗哪，样子像芫荽子，颜色是白的，滋味如同搀蜜的薄饼。</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 105:5; 路加福音 22:19; 诗篇 111:4–5"> 摩西说：“耶和华所吩咐的是这样：要将一满俄梅珥吗哪留到世世代代，使后人可以看见我当日将你们领出埃及地，在旷野所给你们吃的食物。”</span>
<span className="v" id="v33" data-v="33" data-xref="希伯来书 9:4"> 摩西对亚伦说：“你拿一个罐子，盛一满俄梅珥吗哪，存在耶和华面前，要留到世世代代。”</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 27:21; 出埃及记 25:21; 出埃及记 25:16"> 耶和华怎么吩咐摩西，亚伦就怎么行，把吗哪放在法柜前存留。</span>
<span className="v" id="v35" data-v="35" data-xref="尼希米记 9:20–21; 约书亚记 5:12; 申命记 8:2–3"> 以色列人吃吗哪共四十年，直到进了有人居住之地，就是迦南的境界。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 16:16; 出埃及记 16:32–33"> （俄梅珥乃伊法十分之一。）</span>
</div>
</div>

</div>

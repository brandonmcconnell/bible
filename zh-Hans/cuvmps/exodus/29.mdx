## 示以立亚伦及其子为祭司当献之物当行之礼

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 4:3; 玛拉基书 1:13–14; 出埃及记 12:5"> “你使亚伦和他儿子成圣，给我供祭司的职分，要如此行。取一只公牛犊，两只无残疾的公绵羊，</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 6:15; 利未记 2:15; 利未记 7:12"> 无酵饼和调油的无酵饼，与抹油的无酵薄饼，这都要用细麦面做成。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 6:17; 利未记 8:26; 利未记 8:2"> 这饼要装在一个筐子里，连筐子带来，又把公牛和两只公绵羊牵来。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 40:12; 希伯来书 10:22; 出埃及记 26:36"> 要使亚伦和他儿子到会幕门口来，用水洗身。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 28:2–8; 利未记 8:7–8"> 要给亚伦穿上内袍和以弗得的外袍并以弗得，又戴上胸牌，束上以弗得巧工织的带子。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 8:9; 出埃及记 28:36–39"> 把冠冕戴在他头上，将圣冠加在冠冕上，</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 35:25; 利未记 21:10; 约翰福音 3:34"> 就把膏油倒在他头上膏他。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 8:13; 出埃及记 28:40"> 要叫他的儿子来，给他们穿上内袍。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 18:7; 利未记 8:22–28; 申命记 18:5"> 给亚伦和他儿子束上腰带，包上裹头巾，他们就凭永远的定例得了祭司的职任。又要将亚伦和他儿子分别为圣。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未记 1:4; 利未记 8:14; 出埃及记 29:15"> “你要把公牛牵到会幕前，亚伦和他儿子要按手在公牛的头上。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 9:8; 利未记 9:12; 出埃及记 29:4"> 你要在耶和华面前，在会幕门口，宰这公牛。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 27:2; 利未记 9:9; 利未记 8:15"> 要取些公牛的血，用指头抹在坛的四角上，把血都倒在坛脚那里。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 3:3–4; 撒母耳记上 2:16; 利未记 9:10"> 要把一切盖脏的脂油与肝上的网子，并两个腰子和腰子上的脂油，都烧在坛上。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 4:11–12; 利未记 4:21; 出埃及记 30:10"> 只是公牛的皮、肉、粪都要用火烧在营外。这牛是赎罪祭。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及记 29:19; 出埃及记 29:3; 利未记 8:18–21"> “你要牵一只公绵羊来，亚伦和他儿子要按手在这羊的头上。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 29:11–12"> 要宰这羊，把血洒在坛的周围。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 4:14; 利未记 1:13; 利未记 1:9"> 要把羊切成块子，洗净五脏和腿，连块子带头，都放在一处。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 8:21; 腓立比书 4:18; 创世记 22:7"> 要把全羊烧在坛上，是给耶和华献的燔祭，是献给耶和华为馨香的火祭。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及记 29:3; 利未记 8:22–29"> “你要将那一只公绵羊牵来，亚伦和他儿子要按手在羊的头上。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 50:5; 希伯来书 10:22; 利未记 14:16"> 你要宰这羊，取点血抹在亚伦的右耳垂上和他儿子的右耳垂上，又抹在他们右手的大拇指上和右脚的大拇指上，并要把血洒在坛的四围。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 9:22; 出埃及记 29:7; 出埃及记 29:1"> 你要取点膏油和坛上的血，弹在亚伦和他的衣服上，并他儿子和他儿子的衣服上，他们和他们的衣服就一同成圣。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 29:13; 利未记 9:21; 利未记 9:19"> 你要取这羊的脂油和肥尾巴，并盖脏的脂油与肝上的网子，两个腰子和腰子上的脂油并右腿，这是承接圣职所献的羊。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 29:2–3; 利未记 8:26"> 再从耶和华面前装无酵饼的筐子中取一个饼，一个调油的饼和一个薄饼，</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 7:30; 利未记 8:27; 利未记 9:21"> 都放在亚伦的手上和他儿子的手上，作为摇祭，在耶和华面前摇一摇。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 8:28; 出埃及记 29:41; 利未记 3:16"> 要从他们手中接过来，烧在耶和华面前坛上的燔祭上，是献给耶和华为馨香的火祭。</span>
</div>
</div>

## 祭司当得之份

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="利未记 8:29; 利未记 7:31; 利未记 7:34"> “你要取亚伦承接圣职所献公羊的胸，作为摇祭，在耶和华面前摇一摇，这就可以做你的份。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 10:15; 民数记 18:11; 申命记 18:3"> 那摇祭的胸和举祭的腿，就是承接圣职所摇的、所举的，是归亚伦和他儿子的。这些你都要成为圣，</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 15:19–20; 利未记 7:11–38; 利未记 10:14–15"> 做亚伦和他子孙从以色列人中永远所得的份，因为是举祭。这要从以色列人的平安祭中，作为献给耶和华的举祭。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数记 18:8; 出埃及记 28:3–4; 出埃及记 30:30"> “亚伦的圣衣要留给他的子孙，可以穿着受膏，又穿着承接圣职。</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 20:28; 利未记 13:5; 使徒行传 20:6–7"> 他的子孙接续他当祭司的，每逢进会幕在圣所供职的时候，要穿七天。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="利未记 8:31; 撒母耳记上 2:13; 以西结书 46:20–24"> “你要将承接圣职所献公羊的肉煮在圣处。</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 12:4; 出埃及记 29:23; 出埃及记 29:2–3"> 亚伦和他儿子要在会幕门口吃这羊的肉和筐内的饼。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 18:4; 利未记 10:13–18; 诗篇 22:26"> 他们吃那些赎罪之物，好承接圣职，使他们成圣；只是外人不可吃，因为这是圣物。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 12:10; 利未记 8:32; 出埃及记 29:22"> 那承接圣职所献的肉或饼，若有一点留到早晨，就要用火烧了，不可吃这物，因为是圣物。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="出埃及记 29:30; 利未记 14:8–11; 利未记 8:4–36"> “你要这样照我一切所吩咐的，向亚伦和他儿子行承接圣职的礼七天。</span>
<span className="v" id="v36" data-v="36" data-xref="希伯来书 10:11; 希伯来书 9:22–23; 出埃及记 30:28–29"> 每天要献公牛一只为赎罪祭。你洁净坛的时候，坛就洁净了，且要用膏抹坛，使坛成圣。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及记 40:10; 马太福音 23:19; 出埃及记 30:28–29"> 要洁净坛七天，使坛成圣，坛就成为至圣。凡挨着坛的都成为圣。</span>
</div>
</div>

## 每日当献之祭

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="历代志下 2:4; 历代志上 16:40; 民数记 28:3–8"> “你每天所要献在坛上的就是两只一岁的羊羔，</span>
<span className="v" id="v39" data-v="39" data-xref="以西结书 46:13–15; 列王纪下 16:15; 诗篇 5:3"> 早晨要献这一只，黄昏的时候要献那一只。</span>
<span className="v" id="v40" data-v="40" data-xref="腓立比书 2:17; 以西结书 46:14; 约珥书 2:14"> 和这一只羊羔同献的，要用细面伊法十分之一与捣成的油一欣四分之一调和，又用酒一欣四分之一作为奠祭。</span>
<span className="v" id="v41" data-v="41" data-xref="以西结书 46:13–15; 列王纪上 18:29; 诗篇 141:2"> 那一只羊羔要在黄昏的时候献上，照着早晨的素祭和奠祭的礼办理，作为献给耶和华馨香的火祭。</span>
<span className="v" id="v42" data-v="42" data-xref="出埃及记 25:22"> 这要在耶和华面前，会幕门口，做你们世世代代常献的燔祭。我要在那里与你们相会，和你们说话。</span>
<span className="v" id="v43" data-v="43" data-xref="列王纪上 8:11; 历代志下 7:1–3; 玛拉基书 3:1"> 我要在那里与以色列人相会，会幕就要因我的荣耀成为圣。</span>
<span className="v" id="v44" data-v="44" data-xref="利未记 21:15; 利未记 22:9; 利未记 22:16"> 我要使会幕和坛成圣，也要使亚伦和他的儿子成圣，给我供祭司的职分。</span>
<span className="v" id="v45" data-v="45" data-xref="利未记 26:12; 哥林多后书 6:16; 出埃及记 25:8"> 我要住在以色列人中间，做他们的神。</span>
<span className="v" id="v46" data-v="46" data-xref="出埃及记 20:2; 耶利米书 31:33; 以西结书 20:5"> 他们必知道我是耶和华他们的神，是将他们从埃及地领出来的，为要住在他们中间。我是耶和华他们的神。</span>
</div>
</div>

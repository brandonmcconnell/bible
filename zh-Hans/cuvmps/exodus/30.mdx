## 造香坛之法则

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 8:3; 出埃及记 37:25–28; 出埃及记 40:5"> “你要用皂荚木做一座烧香的坛。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 27:2"> 这坛要四方的，长一肘，宽一肘，高二肘。坛的四角要与坛接连一块。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 25:11; 出埃及记 25:24"> 要用精金把坛的上面与坛的四围并坛的四角包裹，又要在坛的四围镶上金牙边。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 25:27; 出埃及记 26:29; 出埃及记 27:7"> 要做两个金环安在牙子边以下，在坛的两旁两根横撑上，作为穿杠的用处，以便抬坛。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 25:13; 出埃及记 25:27"> 要用皂荚木做杠，用金包裹。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 25:21–22; 出埃及记 30:36; 利未记 16:13"> 要把坛放在法柜前的幔子外，对着法柜上的施恩座，就是我要与你相会的地方。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 2:28; 历代志上 23:13; 出埃及记 27:20–21"> 亚伦在坛上要烧馨香料做的香，每早晨他收拾灯的时候，要烧这香。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 9:24; 帖撒罗尼迦前书 5:17; 希伯来书 7:25"> 黄昏点灯的时候，他要在耶和华面前烧这香，作为世世代代常烧的香。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 10:1"> 在这坛上不可奉上异样的香，不可献燔祭、素祭，也不可浇上奠祭。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 16:18; 希伯来书 9:22–23; 利未记 16:29–30"> 亚伦一年一次要在坛的角上行赎罪之礼。他一年一次要用赎罪祭牲的血在坛上行赎罪之礼，作为世世代代的定例。这坛在耶和华面前为至圣。”</span>
</div>
</div>

## 每人当献赎命之价

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和华晓谕摩西说：</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 31:50; 历代志上 27:24; 出埃及记 38:25–26"> “你要按以色列人被数的计算总数，你数的时候，他们各人要为自己的生命把赎价奉给耶和华，免得数的时候在他们中间有灾殃。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 27:25; 民数记 3:47; 以西结书 45:12"> 凡过去归那些被数之人的，每人要按圣所的平，拿银子半舍客勒，这半舍客勒是奉给耶和华的礼物，一舍客勒是二十季拉。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 1:20; 民数记 1:18; 民数记 1:3"> 凡过去归那些被数的人，从二十岁以外的，要将这礼物奉给耶和华。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 31:50; 利未记 17:11; 出埃及记 30:12"> 他们为赎生命将礼物奉给耶和华，富足的不可多出，贫穷的也不可少出，各人要出半舍客勒。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米记 10:32–33; 民数记 16:40; 出埃及记 38:25–31"> 你要从以色列人收这赎罪银，作为会幕的使用，可以在耶和华面前为以色列人做纪念，赎生命。”</span>
</div>
</div>

## 当以铜做浴盆

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和华晓谕摩西说：</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 40:7; 出埃及记 38:8; 列王纪上 7:23"> “你要用铜做洗濯盆和盆座，以便洗濯。要将盆放在会幕和坛的中间，在盆里盛水。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 52:11; 出埃及记 40:31–32; 诗篇 26:6"> 亚伦和他的儿子要在这盆里洗手洗脚。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 10:1–3; 希伯来书 12:28–29; 历代志上 13:10"> 他们进会幕，或是就近坛前供职给耶和华献火祭的时候，必用水洗濯，免得死亡。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 28:43; 出埃及记 27:21"> 他们洗手洗脚，就免得死亡。这要做亚伦和他后裔世世代代永远的定例。”</span>
</div>
</div>

## 制圣膏之法则

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22"> 耶和华晓谕摩西说：</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 27:19; 雅歌 4:14; 以西结书 27:22"> “你要取上品的香料，就是流质的没药五百舍客勒，香肉桂一半，就是二百五十舍客勒，菖蒲二百五十舍客勒，</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 45:8; 出埃及记 29:40; 民数记 3:47"> 桂皮五百舍客勒，都按着圣所的平，又取橄榄油一欣，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 37:29; 历代志上 9:30; 出埃及记 40:9"> 按做香之法调和做成圣膏油。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 7:1; 约翰一书 2:20; 以赛亚书 61:1"> 要用这膏油抹会幕和法柜，</span>
<span className="v" id="v27" data-v="27"> 桌子与桌子的一切器具，灯台和灯台的器具并香坛，</span>
<span className="v" id="v28" data-v="28"> 燔祭坛和坛的一切器具，洗濯盆和盆座。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 23:19; 出埃及记 29:37; 利未记 6:18"> 要使这些物成为圣，好成为至圣，凡挨着的都成为圣。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 8:12; 出埃及记 28:3; 利未记 8:30"> 要膏亚伦和他的儿子，使他们成为圣，可以给我供祭司的职分。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 37:29; 利未记 21:10; 诗篇 89:20"> 你要对以色列人说：‘这油，我要世世代代以为圣膏油。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 30:25; 出埃及记 30:37–38; 利未记 21:10"> 不可倒在别人的身上，也不可按这调和之法做与此相似的。这膏油是圣的，你们也要以为圣。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 30:38; 创世记 17:14; 出埃及记 12:15"> 凡调和与此相似的，或将这膏膏在别人身上的，这人要从民中剪除。’”</span>
</div>
</div>

## 制圣香之法则

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="出埃及记 37:29; 出埃及记 25:6; 出埃及记 30:23"> 耶和华吩咐摩西说：“你要取馨香的香料，就是拿他弗、施喜列、喜利比拿，这馨香的香料和净乳香各样要一般大的分量。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 2:13; 出埃及记 30:25; 约翰福音 12:3"> 你要用这些加上盐，按做香之法做成清净圣洁的香。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 25:22; 出埃及记 30:6; 出埃及记 16:34"> 这香要取点捣得极细，放在会幕内法柜前，我要在那里与你相会。你们要以这香为至圣。</span>
<span className="v" id="v37" data-v="37" data-xref="利未记 2:3; 出埃及记 29:37; 出埃及记 30:32–33"> 你们不可按这调和之法为自己做香，要以这香为圣，归耶和华。</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及记 30:33"> 凡做香和这香一样，为要闻香味的，这人要从民中剪除。”</span>
</div>

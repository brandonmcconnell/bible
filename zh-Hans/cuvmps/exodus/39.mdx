## 做圣衣

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 31:10; 出埃及记 35:23; 出埃及记 35:19"> 比撒列用蓝色、紫色、朱红色线做精致的衣服，在圣所用以供职，又为亚伦做圣衣，是照耶和华所吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="出埃及记 28:6–12; 利未记 8:7; 出埃及记 25:7"> 他用金线和蓝色、紫色、朱红色线并捻的细麻做以弗得。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 36:8; 出埃及记 26:1"> 把金子锤成薄片，剪出线来，与蓝色、紫色、朱红色线，用巧匠的手工一同绣上。</span>
<span className="v" id="v4" data-v="4"> 又为以弗得做两条相连的肩带，接连在以弗得的两头。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 1:13; 马太福音 28:20; 以赛亚书 11:5"> 其上巧工织的带子和以弗得一样的做法，用以束上，与以弗得接连一块，是用金线和蓝色、紫色、朱红色线并捻的细麻做的，是照耶和华所吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 28:9; 以西结书 28:13; 约伯记 28:16"> 又琢出两块红玛瑙，镶在金槽上，仿佛刻图书，按着以色列儿子的名字雕刻，</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 4:7; 出埃及记 28:12; 出埃及记 28:29"> 将这两块宝石安在以弗得的两条肩带上，为以色列人做纪念石，是照耶和华所吩咐摩西的。</span>
</div>
</div>

## 做胸牌

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 28:4; 利未记 8:8–9; 以赛亚书 59:17"> 他用巧匠的手工做胸牌，和以弗得一样的做法，用金线与蓝色、紫色、朱红色线并捻的细麻做的。</span>
<span className="v" id="v9" data-v="9"> 胸牌是四方的，叠为两层，这两层长一虎口，宽一虎口，</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 28:21; 出埃及记 28:16–17; 启示录 21:19–21"> 上面镶着宝石四行：第一行是红宝石、红璧玺、红玉，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 28:18; 以西结书 28:13"> 第二行是绿宝石、蓝宝石、金钢石，</span>
<span className="v" id="v12" data-v="12"> 第三行是紫玛瑙、白玛瑙、紫晶，</span>
<span className="v" id="v13" data-v="13"> 第四行是水苍玉、红玛瑙、碧玉。这都镶在金槽中。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 21:12"> 这些宝石都是按着以色列十二个儿子的名字，仿佛刻图书，刻十二个支派的名字。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 10:28; 约翰福音 17:12; 彼得前书 1:5"> 在胸牌上，用精金拧成如绳子的链子。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 25:12"> 又做两个金槽和两个金环，安在胸牌的两头。</span>
<span className="v" id="v17" data-v="17"> 把那两条拧成的金链子穿过胸牌两头的环子，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 28:14; 雅歌 1:10"> 又把链子的那两头接在两槽上，安在以弗得前面肩带上。</span>
<span className="v" id="v19" data-v="19"> 做两个金环，安在胸牌的两头，在以弗得里面的边上。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 26:3"> 又做两个金环，安在以弗得前面两条肩带的下边，挨近相接之处，在以弗得巧工织的带子以上。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 16:24; 哥林多前书 1:25; 哥林多前书 1:27"> 用一条蓝细带子把胸牌的环子和以弗得的环子系住，使胸牌贴在以弗得巧工织的带子上，不可与以弗得离缝，是照耶和华所吩咐摩西的。</span>
</div>
</div>

## 做外袍

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及记 28:31–35"> 他用织工做以弗得的外袍，颜色全是蓝的。</span>
<span className="v" id="v23" data-v="23"> 袍上留一领口，口的周围织出领边来，仿佛铠甲的领口，免得破裂。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 28:33; 加拉太书 5:22"> 在袍子底边上，用蓝色、紫色、朱红色线并捻的细麻做石榴。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 28:33–34; 雅歌 4:13; 诗篇 89:15"> 又用精金做铃铛，把铃铛钉在袍子周围底边上的石榴中间：</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 28:34; 雅歌 4:13; 雅歌 6:7"> 一个铃铛，一个石榴，一个铃铛，一个石榴，在袍子周围底边上，用以供职，是照耶和华所吩咐摩西的。</span>
</div>
</div>

## 幕工告竣

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="出埃及记 39:42–43; 马太福音 28:20; 出埃及记 25:40"> 帐幕，就是会幕，一切的工就这样做完了。凡耶和华所吩咐摩西的，以色列人都照样做了。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 35:11–19; 出埃及记 31:7–11; 出埃及记 36:1–38"> 他们送到摩西那里，帐幕和帐幕的一切器具，就是钩子、板、闩、柱子、带卯的座，</span>
<span className="v" id="v34" data-v="34"> 染红公羊皮的盖、海狗皮的顶盖和遮掩柜的幔子，</span>
<span className="v" id="v35" data-v="35" data-xref="希伯来书 9:5; 出埃及记 25:17; 希伯来书 9:8"> 法柜和柜的杠并施恩座，</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 25:30; 列王纪上 7:48"> 桌子和桌子的一切器具并陈设饼，</span>
<span className="v" id="v37" data-v="37" data-xref="腓立比书 2:15; 出埃及记 27:21; 马太福音 5:14–16"> 精金的灯台和摆列的灯盏与灯台的一切器具并点灯的油，</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及记 30:7; 出埃及记 37:29; 出埃及记 30:3"> 金坛，膏油，馨香的香料，会幕的门帘，</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪上 8:64; 出埃及记 38:30"> 铜坛和坛上的铜网，坛的杠并坛的一切器具，洗濯盆和盆座，</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及记 27:9–16"> 院子的帷子和柱子，并带卯的座，院子的门帘、绳子、橛子，并帐幕和会幕中一切使用的器具，</span>
<span className="v" id="v41" data-v="41" data-xref="出埃及记 28:2; 出埃及记 31:10; 出埃及记 39:1"> 精工做的礼服和祭司亚伦并他儿子在圣所用以供祭司职分的圣衣。</span>
<span className="v" id="v42" data-v="42" data-xref="出埃及记 35:10; 出埃及记 23:21–22; 提摩太后书 2:15"> 这一切工作都是以色列人照耶和华所吩咐摩西做的。</span>
<span className="v" id="v43" data-v="43" data-xref="民数记 6:23–27; 利未记 9:22–23; 撒母耳记下 6:18"> 耶和华怎样吩咐的，他们就怎样做了。摩西看见一切的工都做成了，就给他们祝福。</span>
</div>

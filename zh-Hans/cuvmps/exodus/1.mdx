<span className="v" id="v4" data-v="4"> 但、拿弗他利、迦得、亚设。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 10:22; 创世记 46:26–27; 士师记 8:30"> 凡从雅各而生的，共有七十人。约瑟已经在埃及。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 50:26; 创世记 50:24; 使徒行传 7:14–16"> 约瑟和他的弟兄，并那一代的人都死了。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 46:3; 创世记 1:28; 申命记 26:5"> 以色列人生养众多，并且繁茂，极其强盛，满了那地。</span>

## 埃及新王虐待以色列人

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 7:18; 传道书 2:18–19; 传道书 9:15"> 有不认识约瑟的新王起来，治理埃及，</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 105:24–25; 传道书 4:4; 雅各书 3:14–16"> 对他的百姓说：“看哪，这以色列民比我们还多，又比我们强盛。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 7:19; 诗篇 83:3–4; 箴言 1:11"> 来吧，我们不如用巧计待他们，恐怕他们多起来，日后若遇什么争战的事，就联合我们的仇敌攻击我们，离开这地去了。”</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 15:13; 创世记 47:11; 出埃及记 3:7"> 于是埃及人派督工的辖制他们，加重担苦害他们。他们为法老建造两座积货城，就是比东和兰塞。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 105:24; 出埃及记 1:9; 罗马书 8:28"> 只是越发苦害他们，他们越发多起来，越发蔓延，埃及人就因以色列人愁烦。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 4:20"> 埃及人严严地使以色列人做工，</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 7:19; 民数记 20:15; 出埃及记 2:23"> 使他们因做苦工觉得命苦。无论是和泥，是做砖，是做田间各样的工，在一切的工上都严严地待他们。</span>
</div>
</div>

## 收生者敬畏神存留男子

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15"> 有希伯来的两个收生婆，一名施弗拉，一名普阿。埃及王对她们说：</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 1:22; 马太福音 21:38; 启示录 12:4"> “你们为希伯来妇人收生，看她们临盆的时候，若是男孩，就把他杀了，若是女孩，就留她存活。”</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 5:29; 出埃及记 1:21; 马太福音 10:28"> 但是收生婆敬畏神，不照埃及王的吩咐行，竟存留男孩的性命。</span>
<span className="v" id="v18" data-v="18" data-xref="传道书 8:4; 撒母耳记下 13:28"> 埃及王召了收生婆来，说：“你们为什么做这事，存留男孩的性命呢？”</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 2:4–24; 撒母耳记下 17:19–20; 撒母耳记上 21:2"> 收生婆对法老说：“因为希伯来妇人与埃及妇人不同，希伯来妇人本是健壮的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：活泼的。">a</a></sup>，收生婆还没有到，她们已经生产了。”</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 3:10; 传道书 8:12; 箴言 11:18"> 神厚待收生婆。以色列人多起来，极其强盛。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 11:38; 撒母耳记上 2:35; 诗篇 37:3"> 收生婆因为敬畏神，神便叫她们成立家室。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 7:19; 箴言 1:16; 出埃及记 1:16"> 法老吩咐他的众民说：“以色列人所生的男孩，你们都要丢在河里；一切的女孩，你们要存留她的性命。”</span>
</div>
</div>

## 亚伦造犊

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 7:40; 申命记 9:9; 出埃及记 24:18"> 百姓见摩西迟延不下山，就大家聚集到亚伦那里，对他说：“起来，为我们做神像，可以在我们前面引路，因为领我们出埃及地的那个摩西，我们不知道他遭了什么事。”</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 8:24–27; 出埃及记 12:35–36; 以西结书 16:17"> 亚伦对他们说：“你们去摘下你们妻子、儿女耳上的金环，拿来给我。”</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 46:6; 以赛亚书 40:19–20; 耶利米书 10:9"> 百姓就都摘下他们耳上的金环，拿来给亚伦。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米记 9:18; 申命记 9:16; 列王纪上 12:28"> 亚伦从他们手里接过来，铸了一只牛犊，用雕刻的器具做成。他们就说：“以色列啊，这是领你出埃及地的神！”</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 10:20; 利未记 23:2; 利未记 23:37"> 亚伦看见，就在牛犊面前筑坛，且宣告说：“明日要向耶和华守节。”</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 10:7; 民数记 25:2; 使徒行传 7:41–42"> 次日清早，百姓起来献燔祭和平安祭，就坐下吃喝，起来玩耍。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 32:11; 何西阿书 9:9; 士师记 2:19"> 耶和华吩咐摩西说：“下去吧，因为你的百姓，就是你从埃及地领出来的，已经败坏了。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 12:28; 出埃及记 20:23; 出埃及记 20:3–4"> 他们快快偏离了我所吩咐的道，为自己铸了一只牛犊，向它下拜献祭，说：‘以色列啊，这就是领你出埃及地的神！’”</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 7:51; 申命记 9:13; 以赛亚书 48:4"> 耶和华对摩西说：“我看这百姓真是硬着颈项的百姓。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 9:14; 民数记 14:12; 申命记 9:19"> 你且由着我，我要向他们发烈怒，将他们灭绝，使你的后裔成为大国。”</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 9:18–20; 申命记 9:26–29; 诗篇 106:23"> 摩西便恳求耶和华他的神说：“耶和华啊，你为什么向你的百姓发烈怒呢？这百姓是你用大力和大能的手从埃及地领出来的。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 14:13–16; 申命记 9:28; 约书亚记 7:9"> 为什么使埃及人议论说‘他领他们出去，是要降祸于他们，把他们杀在山中，将他们从地上除灭’？求你转意，不发你的烈怒；后悔，不降祸与你的百姓。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 6:13; 创世记 12:7; 创世记 22:16"> 求你记念你的仆人亚伯拉罕、以撒、以色列，你曾指着自己起誓说：‘我必使你们的后裔像天上的星那样多，并且我所应许的这全地，必给你们的后裔，他们要永远承受为业。’”</span>
<span className="v" id="v14" data-v="14" data-xref="约拿书 3:10; 诗篇 106:45; 耶利米书 26:13"> 于是耶和华后悔，不把所说的祸降于他的百姓。</span>
</div>
</div>

## 摩西怒碎法版

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命记 9:15; 出埃及记 40:20; 申命记 5:22"> 摩西转身下山，手里拿着两块法版。这版是两面写的，这面那面都有字，</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 31:18; 希伯来书 8:10; 申命记 10:1"> 是神的工作，字是神写的，刻在版上。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 24:13; 出埃及记 17:9; 约书亚记 6:20"> 约书亚一听见百姓呼喊的声音，就对摩西说：“在营里有争战的声音。”</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 15:1–18; 但以理书 5:4; 但以理书 5:23"> 摩西说：“这不是人打胜仗的声音，也不是人打败仗的声音，我所听见的乃是人歌唱的声音。”</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 9:16–17; 耶利米书 31:32; 耶利米哀歌 5:15"> 摩西挨近营前，就看见牛犊，又看见人跳舞，便发烈怒，把两块版扔在山下摔碎了，</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 9:21; 列王纪下 23:6; 列王纪下 23:15"> 又将他们所铸的牛犊用火焚烧，磨得粉碎，撒在水面上，叫以色列人喝。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 20:9; 约书亚记 7:19–26; 列王纪上 21:22"> 摩西对亚伦说：“这百姓向你做了什么？你竟使他们陷在大罪里！”</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 9:24; 出埃及记 15:24; 出埃及记 16:20"> 亚伦说：“求我主不要发烈怒。这百姓专于作恶，是你知道的。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 32:1–4; 出埃及记 32:8"> 他们对我说：‘你为我们做神像，可以在我们前面引路，因为领我们出埃及地的那个摩西，我们不知道他遭了什么事。’</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 32:4; 路加福音 10:29; 罗马书 3:10"> 我对他们说：‘凡有金环的，可以摘下来。’他们就给了我，我把金环扔在火中，这牛犊便出来了。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 47:3; 弥迦书 1:11; 启示录 16:15"> 摩西见百姓放肆（亚伦纵容他们，使他们在仇敌中间被讥刺），</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 9:32; 马太福音 12:30; 撒母耳记下 20:11"> 就站在营门中，说：“凡属耶和华的，都要到我这里来！”于是利未的子孙都到他那里聚集。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 25:5; 路加福音 14:26; 申命记 33:8–9"> 他对他们说：“耶和华以色列的神这样说：‘你们各人把刀跨在腰间，在营中往来，从这门到那门，各人杀他的弟兄与同伴并邻舍。’”</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 33:9; 玛拉基书 2:4–6; 哥林多前书 10:8"> 利未的子孙照摩西的话行了。那一天百姓中被杀的约有三千。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 25:11–13; 马太福音 10:37; 撒迦利亚书 13:3"> 摩西说：“今天你们要自洁，归耶和华为圣，各人攻击他的儿子和弟兄，使耶和华赐福于你们。”</span>
</div>
</div>

## 耶和华讨民之罪

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 12:20; 民数记 25:13; 列王纪下 17:21"> 到了第二天，摩西对百姓说：“你们犯了大罪，我如今要上耶和华那里去，或者可以为你们赎罪。”</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 20:23; 但以理书 9:11; 但以理书 9:8"> 摩西回到耶和华那里，说：“唉！这百姓犯了大罪，为自己做了金像。</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 69:28; 罗马书 9:3; 启示录 21:27"> 倘或你肯赦免他们的罪——不然，求你从你所写的册上涂抹我的名。”</span>
<span className="v" id="v33" data-v="33" data-xref="申命记 29:20; 以西结书 18:4; 启示录 20:12"> 耶和华对摩西说：“谁得罪我，我就从我的册上涂抹谁的名。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 23:20; 申命记 32:35; 马太福音 23:35"> 现在你去领这百姓，往我所告诉你的地方去，我的使者必在你前面引路，只是到我追讨的日子，我必追讨他们的罪。”</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 7:41; 出埃及记 32:25; 撒母耳记下 12:9–10"> 耶和华杀百姓的缘故是因他们同亚伦做了牛犊。</span>
</div>
</div>

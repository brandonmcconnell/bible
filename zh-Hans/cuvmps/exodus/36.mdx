<span className="v" id="v7" data-v="7" data-xref="历代志下 31:10"> 因为他们所有的材料够做一切当做的物，而且有余。</span>

## 造幕幔

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪上 6:23; 出埃及记 26:1–37; 以西结书 1:5–28"> 他们中间凡心里有智慧做工的，用十幅幔子做帐幕。这幔子是比撒列用捻的细麻和蓝色、紫色、朱红色线制造的，并用巧匠的手工绣上基路伯。</span>
<span className="v" id="v9" data-v="9"> 每幅幔子长二十八肘，宽四肘，都是一样的尺寸。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 12:27; 出埃及记 26:3; 诗篇 122:3"> 他使这五幅幔子幅幅相连，又使那五幅幔子幅幅相连。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 26:4"> 在这相连的幔子末幅边上做蓝色的纽扣，在那相连的幔子末幅边上也照样做。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 26:5; 出埃及记 26:10"> 在这相连的幔子上做五十个纽扣，在那相连的幔子上也做五十个纽扣，都是两两相对。</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前书 2:4–5; 以弗所书 2:20–22; 哥林多前书 12:20"> 又做五十个金钩，使幔子相连。这才成了一个帐幕。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及记 26:7–13"> 他用山羊毛织十一幅幔子，作为帐幕以上的罩篷。</span>
<span className="v" id="v15" data-v="15"> 每幅幔子长三十肘，宽四肘，十一幅幔子都是一样的尺寸。</span>
<span className="v" id="v16" data-v="16"> 他把五幅幔子连成一幅，又把六幅幔子连成一幅。</span>
<span className="v" id="v17" data-v="17"> 在这相连的幔子末幅边上做五十个纽扣，在那相连的幔子末幅边上也做五十个纽扣。</span>
<span className="v" id="v18" data-v="18"> 又做五十个铜钩，使罩篷连成一个。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 26:14"> 并用染红的公羊皮做罩篷的盖，再用海狗皮做一层罩篷上的顶盖。</span>
</div>
</div>

## 造幕板

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 25:5; 民数记 25:1; 出埃及记 40:18–19"> 他用皂荚木做帐幕的竖板。</span>
<span className="v" id="v21" data-v="21"> 每块长十肘，宽一肘半，</span>
<span className="v" id="v22" data-v="22"> 每块有两榫相对。帐幕一切的板都是这样做。</span>
<span className="v" id="v23" data-v="23"> 帐幕的南面做板二十块，</span>
<span className="v" id="v24" data-v="24"> 在这二十块板底下又做四十个带卯的银座，两卯接这块板上的两榫，两卯接那块板上的两榫。</span>
<span className="v" id="v25" data-v="25"> 帐幕的第二面，就是北面，也做板二十块，</span>
<span className="v" id="v26" data-v="26"> 和带卯的银座四十个，这板底下有两卯，那板底下也有两卯。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 26:22; 出埃及记 26:27"> 帐幕的后面，就是西面，做板六块。</span>
<span className="v" id="v28" data-v="28"> 帐幕后面的拐角做板两块，</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 4:32; 以弗所书 3:18–19; 哥林多前书 1:10"> 板的下半截是双的，上半截是整的，直到第一个环子，在帐幕的两个拐角上都是这样做。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 26:25"> 有八块板和十六个带卯的银座，每块板底下有两卯。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及记 26:26–29; 出埃及记 25:28; 出埃及记 30:5"> 他用皂荚木做闩，为帐幕这面的板做五闩，</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 26:26"> 为帐幕那面的板做五闩，又为帐幕后面的板做五闩，</span>
<span className="v" id="v33" data-v="33"> 使板腰间的中闩从这一头通到那一头。</span>
<span className="v" id="v34" data-v="34"> 用金子将板包裹，又做板上的金环套闩，闩也用金子包裹。</span>
</div>
</div>

## 造帘

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 27:51; 希伯来书 10:20; 出埃及记 40:21"> 他用蓝色、紫色、朱红色线和捻的细麻织幔子，以巧匠的手工绣上基路伯。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 1:18"> 为幔子做四根皂荚木柱子，用金包裹，柱子上有金钩，又为柱子铸了四个带卯的银座。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及记 26:36–37; 出埃及记 40:28"> 拿蓝色、紫色、朱红色线和捻的细麻，用绣花的手工织帐幕的门帘，</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及记 27:10"> 又为帘子做五根柱子和柱子上的钩子，用金子把柱顶和柱子上的杆子包裹。柱子有五个带卯的座，是铜的。</span>
</div>
</div>

## 法老追袭以色列人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 12:1; 出埃及记 13:1"> 耶和华晓谕摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 33:7–8; 耶利米书 44:1; 出埃及记 13:17–18"> “你吩咐以色列人转回，安营在比哈希录前、密夺和海的中间，对着巴力洗分，靠近海边安营。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 4:28; 撒母耳记上 23:23; 诗篇 71:11"> 法老必说：‘以色列人在地中绕迷了，旷野把他们困住了。’</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 9:22–23; 出埃及记 7:5; 罗马书 9:17"> 我要使法老的心刚硬，他要追赶他们，我便在法老和他全军身上得荣耀，埃及人就知道我是耶和华。”于是以色列人这样行了。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 105:25; 出埃及记 12:33; 路加福音 11:24–26"> 有人告诉埃及王说：“百姓逃跑！”法老和他的臣仆就向百姓变心，说：“我们容以色列人去，不再服侍我们，这做的是什么事呢？”</span>
<span className="v" id="v6" data-v="6"> 法老就预备他的车辆，带领军兵同去，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 15:4; 士师记 4:3; 诗篇 68:17"> 并带着六百辆特选的车和埃及所有的车，每辆都有车兵长。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 13:17; 民数记 33:3; 申命记 26:8"> 耶和华使埃及王法老的心刚硬，他就追赶以色列人，因为以色列人是昂然无惧地出埃及。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 15:9; 约书亚记 24:6; 出埃及记 14:2"> 埃及人追赶他们，法老一切的马匹、车辆、马兵与军兵就在海边上，靠近比哈希录，对着巴力洗分，在他们安营的地方追上了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约书亚记 24:7; 诗篇 34:17; 尼希米记 9:9"> 法老临近的时候，以色列人举目看见埃及人赶来，就甚惧怕，向耶和华哀求。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 106:7–8; 民数记 14:1–4; 出埃及记 15:23–24"> 他们对摩西说：“难道在埃及没有坟地，你把我们带来死在旷野吗？你为什么这样待我们，将我们从埃及领出来呢？</span>
<span className="v" id="v12" data-v="12" data-xref="约拿书 4:3; 出埃及记 6:9; 约拿书 4:8"> 我们在埃及岂没有对你说过，不要搅扰我们，容我们服侍埃及人吗？因为服侍埃及人比死在旷野还好。”</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 20:17; 历代志下 20:15; 出埃及记 14:30"> 摩西对百姓说：“不要惧怕，只管站住，看耶和华今天向你们所要施行的救恩。因为你们今天所看见的埃及人，必永远不再看见了。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 3:22; 申命记 20:4; 历代志下 20:17"> 耶和华必为你们争战，你们只管静默，不要作声。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约书亚记 7:10; 以斯拉记 10:4–5; 尼希米记 9:9"> 耶和华对摩西说：“你为什么向我哀求呢？你吩咐以色列人往前走。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 7:19; 出埃及记 4:20; 出埃及记 4:2"> 你举手向海伸杖，把水分开，以色列人要下海中走干地。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 14:8; 出埃及记 14:4; 以西结书 34:11"> 我要使埃及人的心刚硬，他们就跟着下去，我要在法老和他的全军、车辆、马兵上得荣耀。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 7:5; 出埃及记 14:4; 出埃及记 7:17"> 我在法老和他的车辆、马兵上得荣耀的时候，埃及人就知道我是耶和华了。”</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 63:9; 出埃及记 32:34; 出埃及记 23:20–21"> 在以色列营前行走神的使者，转到他们后边去，云柱也从他们前边转到他们后边立住。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 8:14; 哥林多后书 2:15–16; 箴言 4:18–19"> 在埃及营和以色列营中间有云柱，一边黑暗，一边发光，终夜两下不得相近。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 63:12; 出埃及记 15:8; 诗篇 66:6"> 摩西向海伸杖，耶和华便用大东风使海水一夜退去，水便分开，海就成了干地。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 11:29; 诗篇 66:6; 出埃及记 15:19"> 以色列人下海中走干地，水在他们的左右做了墙垣。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 15:19; 出埃及记 14:17; 出埃及记 15:9"> 埃及人追赶他们，法老一切的马匹、车辆和马兵都跟着下到海中。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 13:21; 诗篇 77:16–19; 出埃及记 14:25"> 到了晨更的时候，耶和华从云火柱中向埃及的军兵观看，使埃及的军兵混乱了，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 14:14; 申命记 3:22; 约伯记 20:24"> 又使他们的车轮脱落，难以行走，以致埃及人说：“我们从以色列人面前逃跑吧！因耶和华为他们攻击我们了。”</span>
</div>
</div>

## 投埃及人于海

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 14:16; 出埃及记 8:5; 雅各书 2:13"> 耶和华对摩西说：“你向海伸杖，叫水仍合在埃及人并他们的车辆、马兵身上。”</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 4:18; 诗篇 78:53; 希伯来书 11:29"> 摩西就向海伸杖，到了天一亮，海水仍旧复原。埃及人避水逃跑的时候，耶和华把他们推翻在海中，</span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 78:53; 诗篇 106:9–11; 哈巴谷书 3:13"> 水就回流，淹没了车辆和马兵。那些跟着以色列人下海法老的全军，连一个也没有剩下。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 14:22; 诗篇 77:19–20; 以赛亚书 43:2"> 以色列人却在海中走干地，水在他们的左右做了墙垣。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 106:8; 诗篇 106:10; 诗篇 92:9–11"> 当日，耶和华这样拯救以色列人脱离埃及人的手，以色列人看见埃及人的死尸都在海边了。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 2:11; 约翰福音 11:45; 约翰福音 2:23–25"> 以色列人看见耶和华向埃及人所行的大事，就敬畏耶和华，又信服他和他的仆人摩西。</span>
</div>
</div>

## 以色列中凡首生者当分别为圣

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华晓谕摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 2:23; 民数记 3:13; 申命记 15:19"> “以色列中凡头生的，无论是人是牲畜，都是我的，要分别为圣归我。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命记 24:18; 申命记 5:15; 出埃及记 20:2"> 摩西对百姓说：“你们要记念从埃及为奴之家出来的这日，因为耶和华用大能的手将你们从这地方领出来。有酵的饼都不可吃。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 34:18; 出埃及记 23:15; 出埃及记 12:2"> 亚笔月间的这日是你们出来的日子。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 3:8; 约书亚记 24:11; 出埃及记 12:25–26"> 将来耶和华领你进迦南人、赫人、亚摩利人、希未人、耶布斯人之地，就是他向你的祖宗起誓应许给你那流奶与蜜之地，那时你要在这月间守这礼。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 12:15–20; 出埃及记 34:18; 利未记 23:8"> 你要吃无酵饼七日，到第七日要向耶和华守节。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 12:19; 马太福音 16:6"> 这七日之久，要吃无酵饼，在你四境之内不可见有酵的饼，也不可见发酵的物。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 13:14; 出埃及记 12:26–27; 诗篇 44:1"> 当那日，你要告诉你的儿子说：‘这是因耶和华在我出埃及的时候为我所行的事。’</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 6:8; 申命记 11:18–19; 民数记 15:39"> 这要在你手上做记号，在你额上做纪念，使耶和华的律法常在你口中，因为耶和华曾用大能的手将你从埃及领出来。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 12:14; 出埃及记 12:24–25; 出埃及记 23:15"> 所以你每年要按着日期守这例。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出埃及记 13:5"> “将来，耶和华照他向你和你祖宗所起的誓将你领进迦南人之地，把这地赐给你，</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 18:15; 利未记 27:26; 出埃及记 34:19"> 那时你要将一切头生的，并牲畜中头生的，归给耶和华，公的都要属耶和华。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 34:20; 民数记 18:15–17; 启示录 14:4"> 凡头生的驴，你要用羊羔代赎，若不代赎，就要打折它的颈项。凡你儿子中头生的都要赎出来。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 13:3; 约书亚记 4:6; 诗篇 145:4"> 日后，你的儿子问你说：‘这是什么意思？’你就说：‘耶和华用大能的手将我们从埃及为奴之家领出来。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 12:29"> 那时法老几乎不容我们去，耶和华就把埃及地所有头生的，无论是人是牲畜，都杀了。因此，我把一切头生的公牲畜献给耶和华为祭，但将头生的儿子都赎出来。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 13:9; 申命记 11:18; 申命记 6:7–9"> 这要在你手上做记号，在你额上做经文，因为耶和华用大能的手将我们从埃及领出来。’”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及记 14:11–12; 尼希米记 9:17; 民数记 14:1–4"> 法老容百姓去的时候，非利士地的道路虽近，神却不领他们从那里走，因为神说：“恐怕百姓遇见打仗后悔，就回埃及去。”</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 14:2; 申命记 32:10; 民数记 33:6–8"> 所以神领百姓绕道而行，走红海旷野的路。以色列人出埃及地，都带着兵器上去。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 50:24–25; 约书亚记 24:32; 使徒行传 7:16"> 摩西把约瑟的骸骨一同带去，因为约瑟曾叫以色列人严严地起誓，对他们说：“神必眷顾你们，你们要把我的骸骨从这里一同带上去。”</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 33:5–6; 出埃及记 12:37"> 他们从疏割起行，在旷野边的以倘安营。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 10:1–2; 尼希米记 9:12; 申命记 1:33"> 日间耶和华在云柱中领他们的路，夜间在火柱中光照他们，使他们日夜都可以行走。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 121:5–8; 启示录 10:1"> 日间云柱，夜间火柱，总不离开百姓的面前。</span>
</div>
</div>

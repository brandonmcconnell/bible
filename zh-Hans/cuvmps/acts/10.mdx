## 哥尼流蒙主指示

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 27:1; 马太福音 8:5–13; 马太福音 27:27"> 在凯撒利亚有一个人名叫哥尼流，是“意大利营”的百夫长。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 7:7–8; 使徒行传 10:4; 使徒行传 10:22"> 他是个虔诚人，他和全家都敬畏神，多多周济百姓，常常祷告神。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理书 9:20–21; 使徒行传 3:1; 使徒行传 5:19"> 有一天，约在申初，他在异象中明明看见神的一个使者进去，到他那里，说：“哥尼流！”</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比书 4:6; 希伯来书 6:10; 使徒行传 10:31"> 哥尼流定睛看他，惊怕说：“主啊，什么事呢？”天使说：“你的祷告和你的周济达到神面前，已蒙记念了。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 16:9; 使徒行传 9:38; 使徒行传 15:7"> 现在你当打发人往约帕去，请那称呼彼得的西门来。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 9:43; 使徒行传 11:13–14; 罗马书 10:14–17"> 他住在海边一个硝皮匠西门的家里，房子在海边上。”</span>
<span className="v" id="v7" data-v="7" data-xref="腓利门书 1:16; 撒母耳记上 14:6–7; 马太福音 8:9–10"> 向他说话的天使去后，哥尼流叫了两个家人和常伺候他的一个虔诚兵来，</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 9:36; 诗篇 119:59–60; 使徒行传 10:33"> 把这事都述说给他们听，就打发他们往约帕去。</span>
</div>
</div>

## 彼得见异象

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="西番雅书 1:5; 诗篇 55:17; 撒母耳记上 9:25"> 第二天，他们行路将近那城，彼得约在午正上房顶去祷告。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 22:17; 启示录 4:2–3; 哥林多后书 12:2–4"> 觉得饿了，想要吃。那家的人正预备饭的时候，彼得魂游象外，</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 3:6; 约翰福音 1:51; 罗马书 16:25–26"> 看见天开了，有一物降下，好像一块大布，系着四角，缒在地上，</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 7:8–9; 约翰福音 7:37; 哥林多前书 6:9–11"> 里面有地上各样四足的走兽和昆虫，并天上的飞鸟。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 4:31–34; 耶利米书 35:2–5; 使徒行传 10:10"> 又有声音向他说：<span className="woj">“彼得，起来，宰了吃！”</span></span>
<span className="v" id="v14" data-v="14" data-xref="利未记 20:25; 以西结书 4:14; 但以理书 1:8"> 彼得却说：“主啊，这是不可的！凡俗物和不洁净的物，我从来没有吃过。”</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 10:25; 马太福音 15:11; 提多书 1:15"> 第二次有声音向他说：<span className="woj">“神所洁净的，你不可当做俗物。”</span></span>
<span className="v" id="v16" data-v="16" data-xref="创世记 41:32; 约翰福音 21:17; 哥林多后书 13:1"> 这样一连三次，那物随即收回天上去了。</span>
</div>
</div>

## 哥尼流所差的人来寻彼得

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 13:12; 使徒行传 10:7–19; 使徒行传 5:24"> 彼得心里正在猜疑之间，不知所看见的异象是什么意思，哥尼流所差来的人已经访问到西门的家，站在门外，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 10:5–6; 使徒行传 11:11"> 喊着问：“有称呼彼得的西门住在这里没有？”</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 8:29; 使徒行传 11:12; 使徒行传 21:4"> 彼得还思想那异象的时候，圣灵向他说：“有三个人来找你。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 15:7–9; 撒迦利亚书 2:9–11; 以赛亚书 48:16"> 起来，下去，和他们同往，不要疑惑，因为是我差他们来的。”</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 1:38–39; 马可福音 10:51; 使徒行传 10:29"> 于是彼得下去见那些人，说：“我就是你们所找的人。你们来是为什么缘故？”</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 11:14; 使徒行传 10:2; 使徒行传 22:12"> 他们说：“百夫长哥尼流是个义人，敬畏神，为犹太通国所称赞。他蒙一位圣天使指示，叫他请你到他家里去，听你的话。”</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 10:45; 使徒行传 11:12; 彼得前书 4:9"> 彼得就请他们进去，住了一宿。 彼得往哥尼流家传道<br />次日起身和他们同去，还有约帕的几个弟兄同着他去。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 8:40; 撒迦利亚书 8:20–23; 撒迦利亚书 3:10"> 又次日，他们进入凯撒利亚。哥尼流已经请了他的亲属密友等候他们。</span>
<span className="v" id="v25" data-v="25" data-xref="启示录 19:10; 启示录 22:8–9; 但以理书 2:46"> 彼得一进去，哥尼流就迎接他，俯伏在他脚前拜他。</span>
<span className="v" id="v26" data-v="26" data-xref="启示录 19:10; 启示录 22:8–9; 使徒行传 14:14–15"> 彼得却拉他，说：“你起来，我也是人。”</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多后书 2:12; 约翰福音 4:35; 使徒行传 10:24"> 彼得和他说着话进去，见有好些人在那里聚集，</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 4:9; 以弗所书 3:6–7; 加拉太书 2:12–14"> 就对他们说：“你们知道，犹太人和别国的人亲近来往本是不合例的，但神已经指示我，无论什么人都不可看做俗而不洁净的。</span>
<span className="v" id="v29" data-v="29" data-xref="诗篇 119:60; 彼得前书 3:15; 使徒行传 10:19–20"> 所以我被请的时候，就不推辞而来。现在请问：你们叫我来有什么意思呢？”</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 10:3; 但以理书 9:20–21; 尼希米记 9:1–3"> 哥尼流说：“前四天这个时候，我在家中守着申初的祷告，忽然有一个人穿着光明的衣裳，站在我面前，</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 10:4; 但以理书 9:23; 路加福音 1:13"> 说：‘哥尼流，你的祷告已蒙垂听，你的周济达到神面前已蒙记念了。</span>
<span className="v" id="v32" data-v="32"> 你当打发人往约帕去，请那称呼彼得的西门来，他住在海边一个硝皮匠西门的家里。’</span>
<span className="v" id="v33" data-v="33" data-xref="雅各书 1:19; 加拉太书 4:14; 历代志下 30:12"> 所以我立时打发人去请你。你来了很好！现今我们都在神面前，要听主所吩咐你的一切话。”</span>
</div>
</div>

## 彼得宣传耶稣

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="罗马书 2:11; 历代志下 19:7; 申命记 10:17"> 彼得就开口说：“我真看出神是不偏待人，</span>
<span className="v" id="v35" data-v="35" data-xref="约翰一书 2:29; 使徒行传 10:2; 罗马书 10:12–13"> 原来各国中那敬畏主、行义的人都为主所悦纳。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 28:18; 使徒行传 2:36; 启示录 17:14"> 神藉着耶稣基督——他是万有的主——传和平的福音，将这道赐给以色列人。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 4:14; 使徒行传 2:22; 使徒行传 28:22"> 这话在约翰宣传洗礼以后，从加利利起，传遍了犹太。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 4:18; 使徒行传 2:22; 以赛亚书 61:1–3"> 神怎样以圣灵和能力膏拿撒勒人耶稣，这都是你们知道的。他周流四方，行善事，医好凡被魔鬼压制的人，因为神与他同在。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 24:48; 使徒行传 1:8; 使徒行传 10:41"> 他在犹太人之地并耶路撒冷所行的一切事，有我们作见证。他们竟把他挂在木头上杀了！</span>
<span className="v" id="v40" data-v="40" data-xref="彼得前书 1:21; 使徒行传 13:30–31; 哥林多前书 15:3–4"> 第三日，神叫他复活，显现出来，</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 14:22; 使徒行传 10:39; 约翰福音 21:13"> 不是显现给众人看，乃是显现给神预先所拣选为他作见证的人看，就是我们这些在他从死里复活以后和他同吃同喝的人。</span>
<span className="v" id="v42" data-v="42" data-xref="哥林多后书 5:10; 提摩太后书 4:1; 彼得前书 4:5"> 他吩咐我们传道给众人，证明他是神所立定的，要做审判活人、死人的主。</span>
<span className="v" id="v43" data-v="43" data-xref="撒迦利亚书 13:1; 使徒行传 2:38; 以赛亚书 53:11"> 众先知也为他作见证说：‘凡信他的人，必因他的名得蒙赦罪。’”</span>
</div>
</div>

## 圣灵降在众人身上

<div className="bt">
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="使徒行传 11:15; 使徒行传 19:6; 使徒行传 15:8"> 彼得还说这话的时候，圣灵降在一切听道的人身上。</span>
<span className="v" id="v45" data-v="45" data-xref="使徒行传 10:23; 使徒行传 2:38; 加拉太书 3:13–14"> 那些奉割礼、和彼得同来的信徒，见圣灵的恩赐也浇在外邦人身上，就都稀奇，</span>
<span className="v" id="v46" data-v="46" data-xref="使徒行传 19:6; 使徒行传 2:4; 马可福音 16:17"> 因听见他们说方言，称赞神为大。</span>
<span className="v" id="v47" data-v="47" data-xref="使徒行传 8:36; 罗马书 10:12; 使徒行传 11:15–17"> 于是彼得说：“这些人既受了圣灵，与我们一样，谁能禁止用水给他们施洗呢？”</span>
<span className="v" id="v48" data-v="48" data-xref="使徒行传 2:38; 使徒行传 8:16; 加拉太书 3:27"> 就吩咐奉耶稣基督的名给他们施洗。他们又请彼得住了几天。</span>
</div>
</div>

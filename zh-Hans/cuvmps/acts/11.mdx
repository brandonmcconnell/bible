## 彼得辩白给外邦人施洗的事

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 22:27; 玛拉基书 1:11; 以赛亚书 32:15"> 使徒和在犹太的众弟兄听说外邦人也领受了神的道。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 10:45; 使徒行传 10:9; 使徒行传 15:1"> 及至彼得上了耶路撒冷，那些奉割礼的门徒和他争辩，说：</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 10:28; 加拉太书 2:12; 路加福音 15:2"> “你进入未受割礼之人的家，和他们一同吃饭了！”</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 1:3; 使徒行传 14:27; 约书亚记 22:21–31"> 彼得就开口把这事挨次给他们讲解，说：</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 10:9–32; 使徒行传 9:10; 使徒行传 22:17"> “我在约帕城里祷告的时候，魂游象外，看见异象：有一物降下，好像一块大布，系着四角，从天缒下，直来到我跟前。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 4:20; 使徒行传 3:4"> 我定睛观看，见内中有地上四足的牲畜和野兽、昆虫并天上的飞鸟。</span>
<span className="v" id="v7" data-v="7"> 我且听见有声音向我说：<span className="woj">‘彼得，起来，宰了吃！’</span></span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 14:14; 何西阿书 9:3; 哥林多前书 7:14"> 我说：‘主啊，这是不可的！凡俗而不洁净的物从来没有入过我的口。’</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 15:9; 希伯来书 9:13–14; 使徒行传 10:34–35"> 第二次有声音从天上说：<span className="woj">‘神所洁净的，你不可当做俗物。’</span></span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 21:17; 民数记 24:10; 哥林多后书 12:8"> 这样一连三次，就都收回天上去了。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 4:27; 使徒行传 9:10–12; 出埃及记 4:14"> 正当那时，有三个人站在我们所住的房门前，是从凯撒利亚差来见我的。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 8:29; 罗马书 3:22; 帖撒罗尼迦后书 2:2"> 圣灵吩咐我和他们同去，不要疑惑<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：不要分别等类。">a</a></sup>。同着我去的，还有这六位弟兄，我们都进了那人的家。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 10:30–32; 使徒行传 10:3–6; 使徒行传 9:43"> 那人就告诉我们他如何看见一位天使站在他屋里，说：‘你打发人往约帕去，请那称呼彼得的西门来，</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 16:15; 使徒行传 10:22; 使徒行传 16:31–34"> 他有话告诉你，可以叫你和你的全家得救。’</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 19:6; 使徒行传 10:34–46; 使徒行传 2:2–12"> 我一开讲，圣灵便降在他们身上，正像当初降在我们身上一样。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 1:5; 马可福音 1:8; 箴言 1:23"> 我就想起主的话说：<span className="woj">‘约翰是用水施洗，但你们要受圣灵的洗。’</span></span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 10:47; 罗马书 9:20–26; 但以理书 4:35"> 神既然给他们恩赐，像在我们信主耶稣基督的时候给了我们一样，我是谁，能拦阻神呢？”</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 10:12–13; 哥林多后书 7:10; 以西结书 36:26"> 众人听见这话，就不言语了，只归荣耀于神，说：“这样看来，神也赐恩给外邦人，叫他们悔改得生命了。”</span>
</div>
</div>

## 教会兴盛在安提阿

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 4:36; 使徒行传 21:2; 使徒行传 15:3"> 那些因司提反的事遭患难四散的门徒，直走到腓尼基和塞浦路斯并安提阿，他们不向别人讲道，只向犹太人讲。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 27:32; 使徒行传 13:1; 哥林多前书 1:23–24"> 但内中有塞浦路斯和古利奈人，他们到了安提阿，也向希腊人传讲主耶稣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷作：也向说希腊话的犹太人传讲主耶稣。">b</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:66; 使徒行传 2:47; 使徒行传 5:14"> 主与他们同在，信而归主的人就很多了。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 9:27; 使徒行传 8:14; 使徒行传 13:1–3"> 这风声传到耶路撒冷教会人的耳中，他们就打发巴拿巴出去，走到安提阿为止。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 15:58; 使徒行传 14:22; 使徒行传 13:43"> 他到了那里，看见神所赐的恩就欢喜，劝勉众人立定心志，恒久靠主。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 11:21; 使徒行传 5:14; 使徒行传 9:31"> 这巴拿巴原是个好人，被圣灵充满，大有信心。于是，有许多人归服了主。</span>
</div>
</div>

## 门徒初次称为基督徒是在安提阿

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行传 9:11; 使徒行传 9:27; 使徒行传 9:30"> 他又往大数去找扫罗，</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前书 4:16; 使徒行传 26:28; 彼得前书 4:14"> 找着了，就带他到安提阿去。他们足有一年的工夫和教会一同聚集，教训了许多人。门徒称为“基督徒”是从安提阿起首。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行传 13:1; 哥林多前书 12:28; 以弗所书 4:11"> 当那些日子，有几位先知从耶路撒冷下到安提阿。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 21:10; 使徒行传 18:2; 路加福音 3:1"> 内中有一位名叫亚迦布，站起来，藉着圣灵指明天下将有大饥荒；这事到克劳迪年间果然有了。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多后书 8:12–14; 加拉太书 2:10; 哥林多后书 8:2–4"> 于是门徒定意照各人的力量捐钱，送去供给住在犹太的弟兄。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 14:23; 使徒行传 12:25; 使徒行传 15:4"> 他们就这样行，把捐项托巴拿巴和扫罗送到众长老那里。</span>
</div>
</div>

## 保罗坐船往意大利去

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 25:25; 使徒行传 25:12; 使徒行传 10:1"> 非斯都既然定规了叫我们坐船往意大利去，便将保罗和别的囚犯交给御营里的一个百夫长，名叫犹流。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 19:29; 腓利门书 1:24; 歌罗西书 4:10"> 有一只亚大米田的船要沿着亚细亚一带地方的海边走，我们就上了那船开行，有马其顿的帖撒罗尼迦人亚里达古和我们同去。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 24:23; 使徒行传 28:16; 使徒行传 27:43"> 第二天，到了西顿，犹流宽待保罗，准他往朋友那里去，受他们的照应。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 4:36; 使徒行传 15:39; 使徒行传 13:4"> 从那里又开船，因为风不顺，就贴着塞浦路斯背风岸行去。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 6:9; 使徒行传 13:13; 使徒行传 15:41"> 过了基利家、旁非利亚前面的海，就到了吕家的每拉。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 28:11; 使徒行传 27:1; 使徒行传 6:9"> 在那里，百夫长遇见一只亚历山大的船要往意大利去，便叫我们上了那船。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 27:21; 提多书 1:5; 提多书 1:12"> 一连多日，船行得慢，仅仅来到革尼土的对面。因为被风拦阻，就贴着克里特背风岸，从撒摩尼对面行过。</span>
<span className="v" id="v8" data-v="8"> 我们沿岸行走，仅仅来到一个地方，名叫佳澳，离那里不远有拉西亚城。</span>
</div>
</div>

## 保罗劝众

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数记 29:7; 利未记 23:27–29; 利未记 16:29–31"> 走的日子多了，已经过了禁食的节期，行船又危险，保罗就劝众人说：</span>
<span className="v" id="v10" data-v="10" data-xref="但以理书 2:30; 使徒行传 27:20–26; 使徒行传 27:41–44"> “众位，我看这次行船，不但货物和船要受伤损，大遭破坏，连我们的性命也难保。”</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 33:4; 希伯来书 11:7; 以西结书 3:17–18"> 但百夫长信从掌船的和船主，不信从保罗所说的。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 107:30; 使徒行传 27:8"> 且因在这海口过冬不便，船上的人就多半说，不如开船离开这地方，或者能到非尼基过冬。非尼基是克里特的一个海口，一面朝东北，一面朝东南。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:55; 雅歌 4:16; 约伯记 37:17"> 这时微微起了南风，他们以为得意，就起了锚，贴近克里特行去。</span>
</div>
</div>

## 水路的危险

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马可福音 4:37; 诗篇 107:25–27; 出埃及记 14:21–27"> 不多几时，狂风从岛上扑下来，那风名叫友拉革罗。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各书 3:4; 使徒行传 27:27"> 船被风抓住，敌不住风，我们就任风刮去。</span>
<span className="v" id="v16" data-v="16"> 贴着一个小岛的背风岸奔行，那岛名叫高大，在那里仅仅收住了小船。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 27:29; 使徒行传 27:26; 使徒行传 27:41"> 既然把小船拉上来，就用缆索捆绑船底，又恐怕在赛耳底沙滩上搁了浅，就落下篷来，任船飘去。</span>
<span className="v" id="v18" data-v="18" data-xref="约拿书 1:5; 使徒行传 27:38; 马太福音 16:26"> 我们被风浪逼得甚急，第二天众人就把货物抛在海里。</span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 2:4; 路加福音 9:24–25; 马可福音 8:35–37"> 到第三天，他们又亲手把船上的器具抛弃了。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 24:29; 马太福音 8:24–25; 耶利米书 2:25"> 太阳和星辰多日不显露，又有狂风大浪催逼，我们得救的指望就都绝了。</span>
</div>
</div>

## 安慰众人

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 42:22; 诗篇 107:5–6; 使徒行传 27:7"> 众人多日没有吃什么，保罗就出来站在他们中间，说：“众位，你们本该听我的话不离开克里特，免得遭这样的伤损破坏。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 27:25; 使徒行传 27:36; 哥林多后书 4:8–9"> 现在我还劝你们放心，你们的性命一个也不失丧，唯独失丧这船。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 23:11; 罗马书 1:9; 提摩太后书 4:17"> 因我所属、所侍奉的神，他的使者昨夜站在我旁边说：</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 23:11; 提摩太后书 4:16–17; 马太福音 10:28"> ‘保罗，不要害怕！你必定站在凯撒面前；并且与你同船的人，神都赐给你了。’</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 4:20–21; 路加福音 1:45; 民数记 23:19"> 所以众位可以放心，我信神他怎样对我说，事情也要怎样成就。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 28:1; 使徒行传 27:17; 使徒行传 27:29"> 只是我们必要撞在一个岛上。”</span>
</div>
</div>

## 水手想逃

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约拿书 1:6; 使徒行传 27:30; 启示录 18:17"> 到了第十四天夜间，船在亚得里亚海飘来飘去，约到半夜，水手以为渐近旱地，</span>
<span className="v" id="v28" data-v="28"> 就探深浅，探得有十二丈；稍往前行，又探深浅，探得有九丈。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 27:17; 希伯来书 6:19; 申命记 28:67"> 恐怕撞在石头上，就从船尾抛下四个锚，盼望天亮。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 27:16; 使徒行传 27:32"> 水手想要逃出船去，把小船放在海里，假作要从船头抛锚的样子。</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒罗尼迦后书 2:13–14; 诗篇 91:11–12; 耶利米书 29:11–13"> 保罗对百夫长和兵丁说：“这些人若不等在船上，你们必不能得救。”</span>
<span className="v" id="v32" data-v="32" data-xref="腓立比书 3:7–9; 路加福音 16:8"> 于是兵丁砍断小船的绳子，由它飘去。</span>
<span className="v" id="v33" data-v="33"> 天渐亮的时候，保罗劝众人都吃饭，说：“你们悬望忍饿不吃什么，已经十四天了。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 10:30; 列王纪上 1:52; 路加福音 21:18"> 所以我劝你们吃饭，这是关乎你们救命的事，因为你们各人连一根头发也不至于损坏。”</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 15:36; 哥林多前书 10:30–31; 提摩太前书 4:3–4"> 保罗说了这话，就拿着饼，在众人面前祝谢了神，掰开吃。</span>
<span className="v" id="v36" data-v="36" data-xref="哥林多后书 1:4–6; 使徒行传 27:22; 诗篇 27:14"> 于是他们都放下心，也就吃了。</span>
</div>
</div>

## 船被大浪损坏

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒行传 2:41; 罗马书 13:1; 彼得前书 3:20"> 我们在船上的共有二百七十六个人。</span>
<span className="v" id="v38" data-v="38" data-xref="约拿书 1:5; 马太福音 6:25; 使徒行传 27:18–19"> 他们吃饱了，就把船上的麦子抛在海里，为要叫船轻一点。</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 28:1"> 到了天亮，他们不认识那地方，但见一个海湾有岸可登，就商议能把船拢进去不能。</span>
<span className="v" id="v40" data-v="40" data-xref="以赛亚书 33:23; 使徒行传 27:29–30"> 于是砍断缆索，弃锚在海里，同时也松开舵绳，拉起头篷，顺着风向岸行去。</span>
<span className="v" id="v41" data-v="41" data-xref="哥林多后书 11:25–26; 以西结书 27:26; 使徒行传 27:26–29"> 但遇着两水夹流的地方，就把船搁了浅，船头胶住不动，船尾被浪的猛力冲坏。</span>
</div>
</div>

## 众人得救

<div className="bt">
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="马可福音 15:15–20; 传道书 9:3; 诗篇 74:20"> 兵丁的意思要把囚犯杀了，恐怕有洑水脱逃的。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行传 27:3; 箴言 16:7; 使徒行传 27:11"> 但百夫长要救保罗，不准他们任意而行，就吩咐会洑水的跳下水去先上岸，</span>
<span className="v" id="v44" data-v="44" data-xref="使徒行传 27:22; 诗篇 107:28–30; 约翰福音 6:39–40"> 其余的人可以用板子或船上的零碎东西上岸。这样，众人都得了救，上了岸。</span>
</div>
</div>

## 教会被害门徒分散

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 22:20; 但以理书 3:16–18; 使徒行传 5:40"> 从这日起，耶路撒冷的教会大遭逼迫。除了使徒以外，门徒都分散在犹太和撒马利亚各处。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 50:10–11; 创世记 23:2; 耶利米书 22:18"> 有虔诚的人把司提反埋葬了，为他捶胸大哭。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前书 1:13; 加拉太书 1:13; 哥林多前书 15:9"> 扫罗却残害教会，进各人的家，拉着男女下在监里。</span>
</div>
</div>

## 腓利往撒马利亚传道

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="马太福音 10:23; 使徒行传 11:19; 使徒行传 8:1"> 那些分散的人往各处去传道。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 6:5; 使徒行传 21:8; 使徒行传 8:35–36"> 腓利下撒马利亚城去宣讲基督。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 4:41–42; 历代志下 30:12; 马太福音 20:15–16"> 众人听见了，又看见腓利所行的神迹，就同心合意地听从他的话。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 10:1; 使徒行传 14:8–10; 马可福音 16:17–18"> 因为有许多人被污鬼附着，那些鬼大声呼叫，从他们身上出来；还有许多瘫痪的、瘸腿的，都得了医治。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 13:52; 使徒行传 13:48; 使徒行传 8:39"> 在那城里就大有欢喜。</span>
</div>
</div>

## 行邪术的西门

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 13:6; 使徒行传 5:36; 约翰福音 7:18"> 有一个人名叫西门，向来在那城里行邪术，妄自尊大，使撒马利亚的百姓惊奇。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 31:34; 彼得后书 2:2; 启示录 13:3"> 无论大小都听从他，说：“这人就是那称为神的大能者。”</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 8:9; 加拉太书 3:1; 以赛亚书 44:25"> 他们听从他，因他久用邪术使他们惊奇。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 2:38; 使徒行传 1:3; 马太福音 28:19"> 及至他们信了腓利所传神国的福音和耶稣基督的名，连男带女就受了洗。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 8:6–7; 约翰福音 5:20; 使徒行传 19:11"> 西门自己也信了，既受了洗，就常与腓利在一处，看见他所行的神迹和大异能，就甚惊奇。</span>
</div>
</div>

## 彼得约翰传教于撒马利亚

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:13; 帖撒罗尼迦前书 3:2; 加拉太书 2:9"> 使徒在耶路撒冷听见撒马利亚人领受了神的道，就打发彼得、约翰往他们那里去。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 2:38; 约翰福音 16:23–24; 约翰福音 14:13–14"> 两个人到了，就为他们祷告，要叫他们受圣灵，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 2:38; 使徒行传 19:2; 马太福音 28:19"> 因为圣灵还没有降在他们一个人身上，他们只奉主耶稣的名受了洗。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 19:6; 使徒行传 6:6; 提摩太后书 1:6"> 于是使徒按手在他们头上，他们就受了圣灵。</span>
</div>
</div>

## 西门贪心受责

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="提摩太前书 6:5; 马太福音 10:8; 列王纪下 8:9"> 西门看见使徒按手便有圣灵赐下，就拿钱给使徒，</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 14:7–11; 约翰三书 1:9; 约翰福音 5:44"> 说：“把这权柄也给我，叫我手按着谁，谁就可以受圣灵。”</span>
<span className="v" id="v20" data-v="20" data-xref="但以理书 5:17; 马太福音 10:8; 使徒行传 2:38"> 彼得说：“你的银子和你一同灭亡吧！因你想神的恩赐是可以用钱买的。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 4:13; 诗篇 36:1; 马太福音 6:22–24"> 你在这道上无份无关，因为在神面前你的心不正。</span>
<span className="v" id="v22" data-v="22" data-xref="提摩太后书 2:25–26; 但以理书 4:27; 希伯来书 4:12"> 你当懊悔你这罪恶，祈求主，或者你心里的意念可得赦免。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 58:6; 箴言 5:22; 约翰福音 8:34"> 我看出你正在苦胆之中，被罪恶捆绑。”</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 8:8; 民数记 21:7; 约伯记 42:8"> 西门说：“愿你们为我求主，叫你们所说的，没有一样临到我身上！”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行传 20:21; 使徒行传 26:22–23; 使徒行传 1:8"> 使徒既证明主道而且传讲，就回耶路撒冷去，一路在撒马利亚好些村庄传扬福音。</span>
</div>
</div>

## 腓利传道于埃塞俄比亚的太监

<div className="bt">
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 5:19; 希伯来书 1:14; 列王纪下 1:3"> 有主的一个使者对腓利说：“起来，向南走，往那从耶路撒冷下加沙的路上去！”那路是旷野。</span>
<span className="v" id="v27" data-v="27" data-xref="西番雅书 3:10; 诗篇 68:31; 以赛亚书 56:3–8"> 腓利就起身去了。不料，有一个埃塞俄比亚<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="即古实，见《以赛亚书》18章1节。">a</a></sup>人，是个有大权的太监，在埃塞俄比亚女王干大基的手下总管银库。他上耶路撒冷礼拜去了，</span>
<span className="v" id="v28" data-v="28" data-xref="歌罗西书 3:16; 以赛亚书 1:1; 使徒行传 28:25"> 现在回来，在车上坐着，念先知以赛亚的书。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 10:19; 使徒行传 11:12; 使徒行传 20:22–23"> 圣灵对腓利说：“你去，贴近那车走！”</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 24:44–45; 约翰福音 5:39; 以弗所书 5:17"> 腓利就跑到太监那里，听见他念先知以赛亚的书，便问他说：“你所念的你明白吗？”</span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 10:14; 诗篇 73:16–17; 以赛亚书 29:18–19"> 他说：“没有人指教我，怎能明白呢？”于是请腓利上车与他同坐。</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 53:7–8; 彼得前书 2:21–24; 耶利米书 51:40"> 他所念的那段经说：<br /><span className="pl pl-1">“他像羊被牵到宰杀之地，</span><br /><span className="pl pl-1">又像羊羔在剪毛的人手下无声，</span><br /><span className="pl pl-1">他也是这样不开口。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 53:12; 以赛亚书 53:8; 撒迦利亚书 13:7"> <span className="pl pl-1">他卑微的时候，</span><br /><span className="pl pl-1">人不按公义审判他</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：他的审判被夺去。">b</a></sup><br /><span className="pl pl-1">。</span><br /><span className="pl pl-1">谁能述说他的世代？</span><br /><span className="pl pl-1">因为他的生命从地上夺去。’</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马太福音 15:15; 马太福音 13:36; 马太福音 2:2–4"> 太监对腓利说：“请问，先知说这话是指着谁？是指着自己呢，是指着别人呢？”</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 24:27; 使徒行传 18:28; 使徒行传 28:23"> 腓利就开口从这经上起，对他传讲耶稣。</span>
</div>
</div>

## 太监信而受洗

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行传 10:47; 约翰福音 3:5; 提多书 3:5–6"> 二人正往前走，到了有水的地方，太监说：“看哪，这里有水！我受洗有什么妨碍呢？”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古卷在此有：37 腓利说：“你若是一心相信，就可以。”他回答说：“我信耶稣基督是神的儿子。”">c</a></sup></span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 4:1; 约翰福音 3:22–23"> 于是吩咐车站住，腓利和太监二人同下水里去，腓利就给他施洗。</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪上 18:12; 列王纪下 2:16; 以西结书 8:3"> 从水里上来，主的灵把腓利提了去。太监也不再见他了，就欢欢喜喜地走路。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行传 21:8; 使徒行传 23:23; 使徒行传 23:33"> 后来有人在亚锁都遇见腓利；他走遍那地方，在各城宣传福音，直到凯撒利亚。</span>
</div>
</div>

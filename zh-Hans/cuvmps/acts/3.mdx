## 彼得医治瘸腿的

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 55:17; 使徒行传 10:3; 使徒行传 4:13"> 申初祷告的时候，彼得、约翰上圣殿去。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 14:8; 约翰福音 9:8; 路加福音 16:20"> 有一个人，生来是瘸腿的，天天被人抬来，放在殿的一个门口——那门名叫美门——要求进殿的人周济。</span>
<span className="v" id="v3" data-v="3"> 他看见彼得、约翰将要进殿，就求他们周济。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 14:9–10; 约翰福音 11:40; 路加福音 4:20"> 彼得、约翰定睛看他，彼得说：“你看我们！”</span>
<span className="v" id="v5" data-v="5"> 那人就留意看他们，指望得着什么。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 3:16; 使徒行传 10:38; 使徒行传 4:10"> 彼得说：“金银我都没有，只把我所有的给你：我奉拿撒勒人耶稣基督的名，叫你起来行走！”</span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 1:31; 马可福音 9:27; 使徒行传 9:41"> 于是拉着他的右手，扶他起来。他的脚和踝子骨立刻健壮了，</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 14:10; 以赛亚书 35:6; 诗篇 107:20–22"> 就跳起来站着，又行走，同他们进了殿，走着跳着，赞美神。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 4:21; 使徒行传 4:16; 路加福音 13:17"> 百姓都看见他行走、赞美神，</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 3:2; 约翰福音 5:20; 约翰福音 9:3"> 认得他是那素常坐在殿的美门口求周济的，就因他所遇着的事满心稀奇、惊讶。</span>
</div>
</div>

## 彼得对众讲论医治瘸腿的因由

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 5:12; 约翰福音 10:23; 路加福音 8:38"> 那人正在称为所罗门的廊下拉着彼得、约翰，众百姓一齐跑到他们那里，很觉稀奇。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 3:5; 约翰福音 3:27–28; 但以理书 2:28–30"> 彼得看见，就对百姓说：“以色列人哪，为什么把这事当做稀奇呢？为什么定睛看我们，以为我们凭自己的能力和虔诚使这人行走呢？</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 22:32; 使徒行传 7:32; 马太福音 27:17–25"> 亚伯拉罕、以撒、雅各的神，就是我们列祖的神，已经荣耀了他的仆人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“仆人”或作“儿子”。">a</a></sup>耶稣，你们却把他交付彼拉多，彼拉多定意要释放他，你们竟在彼拉多面前弃绝了他。</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 1:24; 使徒行传 7:52; 彼得前书 3:18"> 你们弃绝了那圣洁公义者，反求着释放一个凶手给你们。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 2:24; 启示录 21:6; 使徒行传 2:32"> 你们杀了那生命的主，神却叫他从死里复活了。我们都是为这事作见证。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 21:21–22; 使徒行传 4:10; 使徒行传 14:9"> 我们因信他的名，他的名便叫你们所看见、所认识的这人健壮了。正是他所赐的信心，叫这人在你们众人面前全然好了。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 23:34; 使徒行传 13:27; 约翰福音 16:3"> 弟兄们，我晓得你们做这事是出于不知，你们的官长也是如此。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 53:1–12; 使徒行传 26:22–23; 使徒行传 2:23"> 但神曾藉众先知的口预言基督将要受害，就这样应验了。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 2:38; 以赛亚书 44:22; 以赛亚书 43:25"> 所以，你们当悔改归正，使你们的罪得以涂抹，这样那安舒的日子就必从主面前来到，</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 24:30–36; 启示录 19:11–16; 帖撒罗尼迦后书 2:2"> 主也必差遣所预定给你们的基督——耶稣降临。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 8:21; 以赛亚书 1:26; 使徒行传 1:11"> 天必留他，等到万物复兴的时候，就是神从创世以来藉着圣先知的口所说的。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 18:15–19; 使徒行传 7:37; 加拉太书 4:4"> 摩西曾说：‘主神要从你们弟兄中间给你们兴起一位先知像我，凡他向你们所说的，你们都要听从。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 18:19; 约翰福音 12:48; 希伯来书 10:28–30"> 凡不听从那先知的，必要从民中全然灭绝。’</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 3:21; 路加福音 24:27; 撒母耳记上 3:20"> 从撒母耳以来的众先知，凡说预言的，也都说到这些日子。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 22:18; 加拉太书 3:8; 使徒行传 2:39"> 你们是先知的子孙，也承受神与你们祖宗所立的约，就是对亚伯拉罕说：‘地上万族都要因你的后裔得福。’</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 1:21; 使徒行传 3:22; 犹大书 1:24"> 神既兴起他的仆人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：儿子。">b</a></sup>，就先差他到你们这里来，赐福给你们，叫你们各人回转，离开罪恶。”</span>
</div>
</div>

## 保罗在公会前声明

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 24:16; 提摩太后书 1:3; 哥林多后书 1:12"> 保罗定睛看着公会的人，说：“弟兄们，我在神面前行事为人都是凭着良心，直到今日。”</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 18:22; 使徒行传 24:1; 弥迦书 5:1"> 大祭司亚拿尼亚就吩咐旁边站着的人打他的嘴。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 25:1–2; 约翰福音 7:51; 马太福音 23:27–28"> 保罗对他说：“你这粉饰的墙，神要打你！你坐堂为的是按律法审问我，你竟违背律法，吩咐人打我吗？”</span>
<span className="v" id="v4" data-v="4"> 站在旁边的人说：“你辱骂神的大祭司吗？”</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 22:28; 传道书 10:20; 犹大书 1:8–9"> 保罗说：“弟兄们，我不晓得他是大祭司。经上记着说：‘不可毁谤你百姓的官长。’”</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 24:15; 使徒行传 24:21; 使徒行传 26:5–8"> 保罗看出大众一半是撒都该人，一半是法利赛人，就在公会中大声说：“弟兄们，我是法利赛人，也是法利赛人的子孙。我现在受审问，是为盼望死人复活。”</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 55:9; 约翰福音 7:40–43; 马太福音 10:34"> 说了这话，法利赛人和撒都该人就争论起来，会众分为两党。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 20:27; 马太福音 22:23; 马可福音 12:18"> 因为撒都该人说没有复活，也没有天使和鬼魂，法利赛人却说两样都有。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 22:7; 使徒行传 22:17–18; 约翰福音 12:29"> 于是大大地喧嚷起来，有几个法利赛党的文士站起来争辩，说：“我们看不出这人有什么恶处。倘若有鬼魂或是天使对他说过话，怎么样呢？”</span>
<span className="v" id="v10" data-v="10" data-xref="雅各书 1:19; 雅各书 3:14–2; 使徒行传 22:24"> 那时大起争吵，千夫长恐怕保罗被他们扯碎了，就吩咐兵丁下去，把他从众人当中抢出来，带进营楼去。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 18:9; 使徒行传 19:21; 提摩太后书 4:17"> 当夜，主站在保罗旁边，说：<span className="woj">“放心吧！你怎样在耶路撒冷为我作见证，也必怎样在罗马为我作见证。”</span></span>
</div>
</div>

## 四十多人同谋杀害保罗

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 23:30; 以赛亚书 8:9–10; 使徒行传 23:21"> 到了天亮，犹太人同谋起誓，说若不先杀保罗就不吃不喝。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 16:2; 撒母耳记下 15:31; 撒母耳记下 15:12"> 这样同心起誓的有四十多人。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 23:12; 耶利米书 8:12; 以赛亚书 3:9"> 他们来见祭司长和长老说：“我们已经起了一个大誓，若不先杀保罗就不吃什么。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 59:7; 诗篇 37:32–33; 箴言 1:16"> 现在你们和公会要知会千夫长，叫他带下保罗到你们这里来，假作要详细察考他的事。我们已经预备好了，不等他来到跟前就杀他。”</span>
</div>
</div>

## 计谋泄漏

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行传 23:10; 哥林多前书 3:19; 使徒行传 23:32"> 保罗的外甥听见他们设下埋伏，就来到营楼里告诉保罗。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 22:3; 马太福音 8:8–9; 马太福音 10:16"> 保罗请一个百夫长来，说：“你领这少年人去见千夫长，他有事告诉他。”</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 3:1; 以弗所书 4:1; 使徒行传 28:17"> 于是把他领去见千夫长，说：“被囚的保罗请我到他那里，求我领这少年人来见你，他有事告诉你。”</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 31:32; 以斯帖记 9:12; 以斯帖记 7:2"> 千夫长就拉着他的手，走到一旁，私下问他说：“你有什么事告诉我呢？”</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 23:14–15; 使徒行传 23:1; 诗篇 12:2"> 他说：“犹太人已经约定，要求你明天带下保罗到公会里去，假作要详细查问他的事。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 23:12–14; 使徒行传 14:5–6; 哥林多后书 11:26"> 你切不要随从他们，因为他们有四十多人埋伏，已经起誓说，若不先杀保罗就不吃不喝。现在预备好了，只等你应允。”</span>
<span className="v" id="v22" data-v="22" data-xref="马可福音 1:44; 约书亚记 2:14"> 于是千夫长打发少年人走，嘱咐他说：“不要告诉人你将这事报给我了。”</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 14:25; 使徒行传 23:33; 路加福音 12:38"> 千夫长便叫了两个百夫长来，说：“预备步兵二百、马兵七十、长枪手二百，今夜亥初往凯撒利亚去。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 25:14; 使徒行传 23:26; 使徒行传 24:10"> 也要预备牲口叫保罗骑上，护送到巡抚腓力斯那里去。”</span>
</div>
</div>

## 克劳迪呈文书给腓力斯

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25"> 千夫长又写了文书，</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 15:23; 使徒行传 26:25; 路加福音 1:3"> 大略说：“克劳迪·吕西亚请巡抚腓力斯大人安！</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 22:25–29; 使徒行传 21:31–33; 使徒行传 24:6"> 这人被犹太人拿住，将要杀害，我得知他是罗马人，就带兵丁下去救他出来。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 22:30"> 因要知道他们告他的缘故，我就带他下到他们的公会去，</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 26:31; 使徒行传 25:25; 使徒行传 18:15"> 便查知他被告是因他们律法的辩论，并没有什么该死、该绑的罪名。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 23:35; 使徒行传 25:16; 使徒行传 25:5–6"> 后来有人把要害他的计谋告诉我，我就立时解他到你那里去，又吩咐告他的人在你面前告他。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷在此有：愿你平安！">a</a></sup>”</span>
</div>

## 保罗在凯撒利亚被看守

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="提摩太后书 2:3–4; 路加福音 7:8; 使徒行传 23:23–24"> 于是兵丁照所吩咐他们的，将保罗夜里带到安提帕底。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 23:23; 使徒行传 23:10"> 第二天，让马兵护送，他们就回营楼去。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 23:26; 使徒行传 23:23–24; 使徒行传 28:16"> 马兵来到凯撒利亚，把文书呈给巡抚，便叫保罗站在他面前。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 21:39; 使徒行传 25:1; 但以理书 2:49"> 巡抚看了文书，问保罗是哪省的人，既晓得他是基利家人，</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 23:30; 使徒行传 25:16; 马太福音 27:27"> 就说：“等告你的人来到，我要细听你的事。”便吩咐人把他看守在希律的衙门里。</span>
</div>

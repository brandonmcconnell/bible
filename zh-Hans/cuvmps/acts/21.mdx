## 推罗的门徒劝保罗不要上耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 2:17; 路加福音 5:4; 撒母耳记上 20:41–42"> 我们离别了众人，就开船一直行到哥士。第二天到了罗底，从那里到帕大喇，</span>
<span className="v" id="v2" data-v="2" data-xref="约拿书 1:3; 使徒行传 11:19; 使徒行传 15:3"> 遇见一只船要往腓尼基去，就上船起行。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 21:16; 使徒行传 4:36; 马太福音 4:24"> 望见塞浦路斯，就从南边行过，往叙利亚去。我们就在推罗上岸，因为船要在那里卸货。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 20:22–23; 使徒行传 21:10–12; 使徒行传 20:6–7"> 找着了门徒，就在那里住了七天。他们被圣灵感动，对保罗说：“不要上耶路撒冷去。”</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 20:36; 使徒行传 9:40; 诗篇 95:6"> 过了这几天，我们就起身前行，他们众人同妻子儿女送我们到城外。我们都跪在岸上祷告，彼此辞别。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 19:27; 约翰福音 1:11; 哥林多后书 2:13"> 我们上了船，他们就回家去了。</span>
</div>
</div>

## 亚迦布预言保罗必被捆绑

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="希伯来书 13:24; 撒母耳记上 10:4; 使徒行传 28:12"> 我们从推罗行尽了水路，来到多利买，就问那里的弟兄安，和他们同住了一天。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 6:5; 使徒行传 8:26–40; 以弗所书 4:11"> 第二天，我们离开那里，来到凯撒利亚，就进了传福音的腓利家里，和他同住。他是那七个执事里的一个。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 2:17; 启示录 2:20; 约珥书 2:28"> 他有四个女儿，都是处女，是说预言的。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 11:28; 使徒行传 21:4; 使徒行传 20:16"> 我们在那里多住了几天，有一个先知名叫亚迦布，从犹太下来，</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 21:33; 耶利米书 13:1–11; 撒母耳记上 15:27–28"> 到了我们这里，就拿保罗的腰带捆上自己的手脚，说：“圣灵说：犹太人在耶路撒冷要如此捆绑这腰带的主人，把他交在外邦人手里。”</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 16:21–23; 使徒行传 20:22; 使徒行传 21:4"> 我们和那本地的人听见这话，都苦劝保罗不要上耶路撒冷去。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 20:24; 腓立比书 2:17; 腓立比书 1:20–21"> 保罗说：“你们为什么这样痛哭，使我心碎呢？我为主耶稣的名，不但被人捆绑，就是死在耶路撒冷也是愿意的。”</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 22:42; 马太福音 26:42; 马太福音 26:39"> 保罗既不听劝，我们便住了口，只说“愿主的旨意成就”便了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行传 25:1; 使徒行传 25:6; 使徒行传 25:9"> 过了几日，我们收拾行李上耶路撒冷去。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 16:31; 使徒行传 21:8; 诗篇 92:14"> 有凯撒利亚的几个门徒和我们同去，带我们到一个久为<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“久为”或作“老”。">a</a></sup>门徒的家里，叫我们与他同住。他名叫拿孙，是塞浦路斯人。</span>
</div>
</div>

## 在耶路撒冷的门徒欢喜接待保罗

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行传 15:4; 罗马书 15:7; 希伯来书 13:1–2"> 到了耶路撒冷，弟兄们欢欢喜喜地接待我们。</span>
<span className="v" id="v18" data-v="18" data-xref="加拉太书 1:19; 加拉太书 2:9; 使徒行传 15:13"> 第二天，保罗同我们去见雅各，长老们也都在那里。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 14:27; 使徒行传 1:17; 罗马书 15:18–19"> 保罗问了他们安，便将神用他传教，在外邦人中间所行之事一一地述说了。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 10:2; 加拉太书 1:14; 使徒行传 22:3"> 他们听见，就归荣耀于神，对保罗说：“兄台，你看犹太人中信主的有多少万，并且都为律法热心。</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太书 6:12–15; 哥林多前书 9:19–21; 加拉太书 5:1–6"> 他们听见人说，你教训一切在外邦的犹太人离弃摩西，对他们说不要给孩子行割礼，也不要遵行条规。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 15:12; 使徒行传 15:22; 使徒行传 19:32"> 众人必听见你来了，这可怎么办呢？</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 18:18; 民数记 6:2–7"> 你就照着我们的话行吧。我们这里有四个人，都有愿在身。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 21:26; 使徒行传 24:18; 使徒行传 18:18"> 你带他们去，与他们一同行洁净的礼，替他们拿出规费，叫他们得以剃头。这样，众人就可知道先前所听见你的事都是虚的，并可知道你自己为人循规蹈矩，遵行律法。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 15:29; 使徒行传 15:19–20"> 至于信主的外邦人，我们已经写信拟定，叫他们谨忌那祭偶像之物和血，并勒死的牲畜与奸淫。”</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 24:18; 使徒行传 21:24; 民数记 6:13–20"> 于是，保罗带着那四个人，第二天与他们一同行了洁净的礼，进了殿，报明洁净的日期满足，只等祭司为他们各人献祭。</span>
</div>
</div>

## 犹太人耸动众人捉拿保罗

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行传 26:21; 使徒行传 24:18; 使徒行传 13:50"> 那七日将完，从亚细亚来的犹太人看见保罗在殿里，就耸动了众人下手拿他，</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 24:5–6; 使徒行传 21:21; 使徒行传 26:20–21"> 喊叫说：“以色列人来帮助！这就是在各处教训众人糟践我们百姓和律法并这地方的。他又带着希腊人进殿，污秽了这圣地。”</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 20:4; 提摩太后书 4:20; 使徒行传 18:19"> 这话是因他们曾看见以弗所人特罗非摩同保罗在城里，以为保罗带他进了殿。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 26:21; 哥林多后书 11:26; 使徒行传 16:19–22"> 合城都震动，百姓一齐跑来，拿住保罗，拉他出殿，殿门立刻都关了。</span>
</div>
</div>

## 千夫长解救保罗

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="哥林多后书 11:23–33; 使徒行传 17:5; 使徒行传 26:9–10"> 他们正想要杀他，有人报信给营里的千夫长说：“耶路撒冷合城都乱了。”</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 23:27; 以赛亚书 3:15; 使徒行传 5:40"> 千夫长立时带着兵丁和几个百夫长，跑下去到他们那里。他们见了千夫长和兵丁，就止住不打保罗。</span>
<span className="v" id="v33" data-v="33" data-xref="以弗所书 6:20; 使徒行传 21:11; 使徒行传 20:23"> 于是千夫长上前拿住他，吩咐用两条铁链捆锁，又问他是什么人，做的是什么事。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 19:32; 使徒行传 23:10; 使徒行传 22:24"> 众人有喊叫这个的，有喊叫那个的，千夫长因为这样乱嚷，得不着实情，就吩咐人将保罗带进营楼去。</span>
<span className="v" id="v35" data-v="35" data-xref="哈巴谷书 1:2–3; 诗篇 55:9; 诗篇 58:2"> 到了台阶上，众人挤得凶猛，兵丁只得将保罗抬起来。</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 19:15; 使徒行传 22:22; 路加福音 23:18"> 众人跟在后面，喊着说：“除掉他！”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒行传 21:34; 路加福音 21:15; 使徒行传 19:30"> 将要带他进营楼，保罗对千夫长说：“我对你说句话可以不可以？”他说：“你懂得希腊话吗？</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 24:26; 使徒行传 5:36–37; 马太福音 5:11"> 你莫非是从前作乱、带领四千凶徒往旷野去的那埃及人吗？”</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 22:3; 使徒行传 9:11; 使徒行传 23:27"> 保罗说：“我本是犹太人，生在基利家的大数，并不是无名小城的人。求你准我对百姓说话。”</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行传 12:17; 使徒行传 22:2; 约翰福音 5:2"> 千夫长准了。保罗就站在台阶上，向百姓摆手。他们都静默无声，保罗便用希伯来话对他们说：</span>

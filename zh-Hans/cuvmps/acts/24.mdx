## 保罗在腓力斯前为自己分诉

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 24:11; 使徒行传 23:2; 使徒行传 25:2"> 过了五天，大祭司亚拿尼亚同几个长老和一个辩士帖土罗下来，向巡抚控告保罗。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 29:5; 箴言 26:28; 使徒行传 24:26–27"> 保罗被提了来，帖土罗就告他说：</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 23:26; 使徒行传 26:25; 路加福音 1:3"> “腓力斯大人，我们因你得以大享太平，并且这一国的弊病因着你的先见得以更正了，我们随时随地满心感谢不尽。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 11:32"> 唯恐多说，你嫌烦絮，只求你宽容听我们说几句话。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 28:22; 使徒行传 24:14; 使徒行传 26:5"> 我们看这个人如同瘟疫一般，是鼓动普天下众犹太人生乱的，又是拿撒勒教党里的一个头目。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 24:12; 使徒行传 21:27–32; 约翰福音 18:31"> 连圣殿他也想要污秽，我们把他捉住了。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷在此有：要按我们的律法审问，7 不料千夫长吕西亚前来，甚是强横，从我们手中把他夺去，吩咐告他的人到你这里来。">a</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 23:35; 使徒行传 25:15–16; 使徒行传 25:5"> 你自己究问他，就可以知道我们告他的一切事了。”</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦前书 2:16; 弥迦书 7:2–3; 诗篇 4:2"> 众犹太人也随着告他说：“事情诚然是这样。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="彼得前书 3:15; 撒母耳记上 2:25; 路加福音 18:2"> 巡抚点头叫保罗说话，他就说：“我知道你在这国里断事多年，所以我乐意为自己分诉。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 24:1; 使徒行传 21:18; 使徒行传 23:11"> 你查问就可以知道，从我上耶路撒冷礼拜到今日，不过有十二天。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 25:8; 使徒行传 28:17; 使徒行传 24:18"> 他们并没有看见我在殿里或是在会堂里，或是在城里，和人辩论，耸动众人。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 25:7; 彼得前书 3:16"> 他们现在所告我的事并不能对你证实了。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 9:2; 罗马书 3:21; 使徒行传 3:13"> 但有一件事，我向你承认，就是他们所称为异端的道，我正按着那道侍奉我祖宗的神，又信合乎律法的和先知书上一切所记载的；</span>
<span className="v" id="v15" data-v="15" data-xref="但以理书 12:2; 约翰福音 5:28–29; 帖撒罗尼迦前书 4:14–16"> 并且靠着神，盼望死人无论善恶都要复活，就是他们自己也有这个盼望。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 23:1; 提摩太前书 1:5; 哥林多后书 4:2"> 我因此自己勉励，对神、对人常存无亏的良心。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 2:10; 罗马书 15:25–28; 哥林多前书 16:1–4"> 过了几年，我带着周济本国的捐项和供献的物上去。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 26:21; 使徒行传 21:26–30; 使徒行传 24:12"> 正献的时候，他们看见我在殿里已经洁净了，并没有聚众，也没有吵嚷，唯有几个从亚细亚来的犹太人。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 23:30; 使徒行传 25:16"> 他们若有告我的事，就应当到你面前来告我。</span>
<span className="v" id="v20" data-v="20"> 即或不然，这些人若看出我站在公会前有妄为的地方，他们自己也可以说明。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 23:6; 使徒行传 4:2; 使徒行传 26:6–8"> 纵然有，也不过一句话，就是我站在他们中间大声说：‘我今日在你们面前受审，是为死人复活的道理。’”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 24:6; 使徒行传 24:24; 使徒行传 25:26"> 腓力斯本是详细晓得这道，就支吾他们，说：“且等千夫长吕西亚下来，我要审断你们的事。”</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 28:16; 使徒行传 27:3; 箴言 16:7"> 于是吩咐百夫长看守保罗，并且宽待他，也不拦阻他的亲友来供给他。</span>
</div>
</div>

## 腓力斯留保罗在监里

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行传 20:21; 加拉太书 2:16; 马可福音 6:20"> 过了几天，腓力斯和他夫人犹太的女子土西拉一同来到，就叫了保罗来，听他讲论信基督耶稣的道。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 16:8; 彼得前书 3:15; 使徒行传 10:42"> 保罗讲论公义、节制和将来的审判，腓力斯甚觉恐惧，说：“你暂且去吧，等我得便再叫你来。”</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太前书 6:9–10; 箴言 17:23; 以赛亚书 56:11"> 腓力斯又指望保罗送他银钱，所以屡次叫他来，和他谈论。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 25:9; 使徒行传 25:14; 使徒行传 12:3"> 过了两年，波求·非斯都接了腓力斯的任；腓力斯要讨犹太人的喜欢，就留保罗在监里。</span>
</div>
</div>

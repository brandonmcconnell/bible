## 司提反当众申诉

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 18:19–21; 马太福音 26:61–62; 使徒行传 6:13–14"> 大祭司就说：“这些事果然有吗？”</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 22:1; 创世记 11:31; 诗篇 29:3"> 司提反说：“诸位父兄请听！当日我们的祖宗亚伯拉罕在美索不达米亚，还未住哈兰的时候，荣耀的神向他显现，</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 12:1; 希伯来书 11:8; 约书亚记 24:3"> 对他说：‘你要离开本地和亲族，往我所要指示你的地方去。’</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 12:4–5; 创世记 11:31–32; 以赛亚书 41:9"> 他就离开迦勒底人之地，住在哈兰。他父亲死了以后，神使他从那里搬到你们现在所住之地。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 17:8; 创世记 12:7; 创世记 13:15"> 在这地方，神并没有给他产业，连立足之地也没有给他；但应许要将这地赐给他和他的后裔为业，那时他还没有儿子。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 15:13; 出埃及记 12:40–41; 加拉太书 3:17"> 神说他的后裔‘必寄居外邦，那里的人要叫他们做奴仆，苦待他们四百年’。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 3:12; 诗篇 105:27–36; 尼希米记 9:9–11"> 神又说‘使他们做奴仆的那国，我要惩罚。以后他们要出来，在这地方侍奉我’。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 35:23–26; 创世记 17:9–14; 创世记 21:1–4"> 神又赐他割礼的约；于是亚伯拉罕生了以撒，第八日给他行了割礼。以撒生雅各，雅各生十二位先祖。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 39:2; 诗篇 105:17; 以赛亚书 43:2"> 先祖嫉妒约瑟，把他卖到埃及去。神却与他同在，</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 3:4; 提摩太后书 4:18; 箴言 2:6"> 救他脱离一切苦难，又使他在埃及王法老面前得恩典、有智慧。法老就派他做埃及国的宰相兼管全家。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 41:54–57; 创世记 45:11; 创世记 42:5"> 后来埃及和迦南全地遭遇饥荒，大受艰难，我们的祖宗就绝了粮。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 42:1–24; 创世记 43:2"> 雅各听见在埃及有粮，就打发我们的祖宗初次往那里去。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 45:1–18; 创世记 46:31–10"> 第二次约瑟与弟兄们相认，他的亲族也被法老知道了。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 46:26–27; 申命记 10:22; 出埃及记 1:5"> 约瑟就打发弟兄请父亲雅各和全家七十五个人都来。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 49:33; 出埃及记 1:6; 创世记 46:3–7"> 于是雅各下了埃及。后来他和我们的祖宗都死在那里，</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 24:32; 创世记 23:16; 出埃及记 13:19"> 又被带到示剑，葬于亚伯拉罕在示剑用银子从哈抹子孙买来的坟墓里。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 1:7–12; 使徒行传 7:6; 使徒行传 13:17"> 及至神应许亚伯拉罕的日期将到，以色列民在埃及兴盛众多，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 1:8"> 直到有不晓得约瑟的新王兴起。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 105:25; 出埃及记 1:9–22; 启示录 12:4–5"> 他用诡计待我们的宗族，苦害我们的祖宗，叫他们丢弃婴孩，使婴孩不能存活。</span>
<span className="v" id="v20" data-v="20" data-xref="希伯来书 11:23; 出埃及记 2:2–10; 撒母耳记上 16:12"> 那时，摩西生下来，俊美非凡，在他父亲家里抚养了三个月。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 11:24; 出埃及记 2:2–10; 申命记 32:26"> 他被丢弃的时候，法老的女儿拾了去，养为自己的儿子。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 19:11; 但以理书 1:17–20; 历代志下 9:22"> 摩西学了埃及人一切的学问，说话行事都有才能。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 2:11–12; 箴言 21:1; 希伯来书 11:24–26"> 他将到四十岁，心中起意去看望他的弟兄以色列人。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 18:10–11; 使徒行传 7:28; 约翰福音 18:25–27"> 到了那里，见他们一个人受冤屈，就护庇他，为那受欺压的人报仇，打死了那埃及人。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 15:7; 马可福音 9:32; 列王纪下 5:1"> 他以为弟兄必明白神是藉他的手搭救他们，他们却不明白。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 2:13–15; 箴言 18:19; 约翰一书 3:11–15"> 第二天遇见两个以色列人争斗，就劝他们和睦，说：‘你们二位是弟兄，为什么彼此欺负呢？’</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 7:35; 路加福音 12:14; 使徒行传 7:54"> 那欺负邻舍的把他推开，说：‘谁立你做我们的首领和审判官呢？</span>
<span className="v" id="v28" data-v="28"> 难道你要杀我，像昨天杀那埃及人吗？’</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 18:2–4; 出埃及记 2:14–22; 出埃及记 4:19–20"> 摩西听见这话就逃走了，寄居于米甸，在那里生了两个儿子。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 3:1–2; 使徒行传 7:35; 以赛亚书 43:2"> 过了四十年，在西奈山的旷野，有一位天使从荆棘火焰中向摩西显现。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 3:3–4"> 摩西见了那异象，便觉稀奇，正进前观看的时候，有主的声音说：</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 3:6; 马太福音 22:32; 约伯记 4:14"> ‘我是你列祖的神，就是亚伯拉罕的神、以撒的神、雅各的神。’摩西战战兢兢，不敢观看。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 3:5; 约书亚记 5:15; 传道书 5:1"> 主对他说：‘把你脚上的鞋脱下来，因为你所站之地是圣地。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 3:7–10; 出埃及记 4:31; 诗篇 106:44"> 我的百姓在埃及所受的困苦，我实在看见了；他们悲叹的声音，我也听见了。我下来要救他们。你来！我要差你往埃及去。’</span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 118:22–23; 路加福音 19:14; 诗篇 113:7–8"> 这摩西就是百姓弃绝说‘谁立你做我们的首领和审判官’的，神却藉那在荆棘中显现之使者的手，差派他做首领、做救赎的。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 12:41; 出埃及记 14:21; 出埃及记 33:1"> 这人领百姓出来，在埃及，在红海，在旷野四十年间，行了奇事神迹。</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 18:15–19; 使徒行传 3:22–23; 约翰福音 18:37"> 那曾对以色列人说‘神要从你们弟兄中间给你们兴起一位先知像我’的，就是这位摩西。</span>
<span className="v" id="v38" data-v="38" data-xref="罗马书 3:2; 希伯来书 5:12; 彼得前书 4:11"> 这人曾在旷野会中和西奈山上与那对他说话的天使同在，又与我们的祖宗同在，并且领受活泼的圣言传给我们。</span>
<span className="v" id="v39" data-v="39" data-xref="民数记 14:3–4; 民数记 11:5; 尼希米记 9:16–17"> 我们的祖宗不肯听从，反弃绝他，心里归向埃及，</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及记 32:1; 出埃及记 32:23"> 对亚伦说：‘你且为我们造些神像，在我们前面引路，因为领我们出埃及地的那个摩西，我们不知道他遭了什么事。’</span>
<span className="v" id="v41" data-v="41" data-xref="诗篇 106:19–21; 尼希米记 9:18; 启示录 9:20"> 那时，他们造了一个牛犊，又拿祭物献给那像，欢喜自己手中的工作。</span>
<span className="v" id="v42" data-v="42" data-xref="阿摩司书 5:25–26; 以西结书 20:39; 耶利米书 19:13"> 神就转脸不顾，任凭他们侍奉天上的日月星辰，正如先知书上所写的说：<br /><span className="pl pl-1">‘以色列家啊，</span><br /><span className="pl pl-1">你们四十年间在旷野，</span><br /><span className="pl pl-1">岂是将牺牲和祭物献给我吗？</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="阿摩司书 5:26–27; 出埃及记 20:4–5; 申命记 5:8–9"> <span className="pl pl-1">你们抬着摩洛的帐幕和理番神的星，</span><br /><span className="pl pl-1">就是你们所造为要敬拜的像。</span><br /><span className="pl pl-1">因此，我要把你们迁到巴比伦外去。’</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v44" data-v="44" data-xref="出埃及记 25:40; 出埃及记 38:21; 希伯来书 8:5"> 我们的祖宗在旷野有法柜的帐幕，是神吩咐摩西叫他照所看见的样式做的。</span>
<span className="v" id="v45" data-v="45" data-xref="诗篇 44:2; 约书亚记 18:1; 约书亚记 23:9"> 这帐幕，我们的祖宗相继承受。当神在他们面前赶出外邦人去的时候，他们同约书亚把帐幕搬进承受为业之地，直存到大卫的日子。</span>
<span className="v" id="v46" data-v="46" data-xref="诗篇 132:1–5; 使徒行传 13:22; 撒母耳记下 7:1–5"> 大卫在神面前蒙恩，祈求为雅各的神预备居所，</span>
<span className="v" id="v47" data-v="47" data-xref="列王纪上 8:20; 列王纪上 6:37–38; 撒母耳记下 7:13"> 却是所罗门为神造成殿宇。</span>
<span className="v" id="v48" data-v="48" data-xref="使徒行传 17:24–25; 以赛亚书 66:1–2; 列王纪上 8:27"> 其实，至高者并不住人手所造的，就如先知所言：</span>
<span className="v" id="v49" data-v="49" data-xref="以赛亚书 66:1; 诗篇 11:4; 约翰福音 4:21"> <span className="pl pl-1">‘主说：“天是我的座位，</span><br /><span className="pl pl-1">地是我的脚凳，</span><br /><span className="pl pl-1">你们要为我造何等的殿宇？</span><br /><span className="pl pl-1">哪里是我安息的地方呢？</span><br /></span>
<span className="v" id="v50" data-v="50" data-xref="耶利米书 32:17; 诗篇 33:6–9; 使徒行传 14:15"> <span className="pl pl-1">这一切不都是我手所造的吗？”’</span></span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="申命记 10:16; 以弗所书 4:30; 以赛亚书 63:10"> 你们这硬着颈项、心与耳未受割礼的人，常时抗拒圣灵！你们的祖宗怎样，你们也怎样。</span>
<span className="v" id="v52" data-v="52" data-xref="马太福音 5:12; 历代志下 36:16; 列王纪上 19:10"> 哪一个先知不是你们祖宗逼迫呢？他们也把预先传说那义者要来的人杀了，如今你们又把那义者卖了、杀了。</span>
<span className="v" id="v53" data-v="53" data-xref="希伯来书 2:2; 加拉太书 3:19; 使徒行传 7:38"> 你们受了天使所传的律法，竟不遵守！”</span>
</div>
</div>

## 看见神的荣耀

<div className="bt">
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="使徒行传 5:33; 诗篇 35:16; 马太福音 25:30"> 众人听见这话，就极其恼怒，向司提反咬牙切齿。</span>
<span className="v" id="v55" data-v="55" data-xref="马可福音 16:19; 希伯来书 1:3; 哥林多后书 4:6"> 但司提反被圣灵充满，定睛望天，看见神的荣耀，又看见耶稣站在神的右边，</span>
<span className="v" id="v56" data-v="56" data-xref="马太福音 26:64–65; 使徒行传 10:11; 启示录 11:19"> 就说：“我看见天开了，人子站在神的右边！”</span>
</div>
</div>

## 众人用石打死他

<div className="bt">
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="撒迦利亚书 7:11; 诗篇 58:4; 使徒行传 23:27"> 众人大声喊叫，捂着耳朵，齐心拥上前去，</span>
<span className="v" id="v58" data-v="58" data-xref="使徒行传 22:20; 使徒行传 8:1; 使徒行传 6:13"> 把他推到城外，用石头打他。作见证的人把衣裳放在一个少年人名叫扫罗的脚前。</span>
<span className="v" id="v59" data-v="59" data-xref="路加福音 23:46; 诗篇 31:5; 使徒行传 22:16"> 他们正用石头打的时候，司提反呼吁主说：“求主耶稣接收我的灵魂！”</span>
<span className="v" id="v60" data-v="60" data-xref="马太福音 5:44; 路加福音 23:34; 哥林多前书 15:20"> 又跪下大声喊着说：“主啊，不要将这罪归于他们！”说了这话就睡了。扫罗也喜悦他被害。</span>
</div>

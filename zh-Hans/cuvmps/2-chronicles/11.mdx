## 耶和华禁罗波安与以色列战

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 12:21–24; 诗篇 33:10; 诗篇 33:16"> 罗波安来到耶路撒冷，招聚犹大家和便雅悯家，共十八万人，都是挑选的战士，要与以色列人争战，好将国夺回再归自己。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 12:15; 历代志下 12:5–7; 历代志下 8:14"> 但耶和华的话临到神人示玛雅说：</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 17:34; 创世记 49:28; 启示录 7:4–8"> “你去告诉所罗门的儿子犹大王罗波安和住犹大、便雅悯的以色列众人说：</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 50:20; 列王纪上 11:29–38; 历代志下 10:15–16"> ‘耶和华如此说：你们不可上去与你们的弟兄争战。各归各家去吧，因为这事出于我。’”众人就听从耶和华的话归回，不去与耶罗波安争战。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="历代志下 8:2–6; 历代志下 14:6–7; 以赛亚书 22:8–11"> 罗波安住在耶路撒冷，在犹大地修筑城邑，</span>
<span className="v" id="v6" data-v="6" data-xref="尼希米记 3:5; 阿摩司书 1:1; 历代志上 4:32"> 为保障修筑伯利恒、以坦、提哥亚、</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 15:35; 撒母耳记上 22:1; 约书亚记 15:58"> 伯夙、梭哥、亚杜兰、</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 54:1; 约书亚记 15:24; 撒母耳记上 23:19"> 迦特、玛利沙、西弗、</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 15:39; 约书亚记 15:35; 约书亚记 10:5"> 亚多莱音、拉吉、亚西加、</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 13:22; 约书亚记 15:33; 约书亚记 14:14"> 琐拉、亚雅仑、希伯仑，这都是犹大和便雅悯的坚固城。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 17:19; 以赛亚书 22:10–11; 历代志下 11:23"> 罗波安又坚固各处的保障，在其中安置军长，又预备下粮食、油、酒。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 13:22; 历代志下 26:14–15; 历代志下 32:5"> 他在各城里预备盾牌和枪，且使城极其坚固。犹大和便雅悯都归了他。</span>
</div>
</div>

## 祭司利未人咸归罗波安

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13"> 以色列全地的祭司和利未人都从四方来归罗波安。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 13:9; 民数记 35:2–5; 列王纪上 12:28–33"> 利未人撇下他们的郊野和产业，来到犹大与耶路撒冷，是因耶罗波安和他的儿子拒绝他们，不许他们供祭司职分侍奉耶和华。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 12:28; 列王纪上 12:31; 列王纪上 13:33"> 耶罗波安为丘坛，为鬼魔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：公山羊。">a</a></sup>，为自己所铸造的牛犊，设立祭司。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 15:9; 使徒行传 11:23; 诗篇 84:5–7"> 以色列各支派中，凡立定心意寻求耶和华以色列神的，都随从利未人来到耶路撒冷，祭祀耶和华他们列祖的神。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 12:1; 历代志下 1:1–12; 历代志下 7:17–19"> 这样，就坚固犹大国，使所罗门的儿子罗波安强盛三年，因为他们三年遵行大卫和所罗门的道。</span>
</div>
</div>

## 罗波安之室家

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 16:6; 历代志上 27:18; 撒母耳记上 17:13"> 罗波安娶大卫儿子耶利摩的女儿玛哈拉为妻，又娶耶西儿子以利押的女儿亚比孩为妻。</span>
<span className="v" id="v19" data-v="19"> 从她生了几个儿子，就是耶乌施、示玛利雅、撒罕。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 13:2; 历代志下 11:21; 历代志下 12:16"> 后来又娶押沙龙的女儿玛迦<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="13章2节作“乌列的女儿米该雅”。">b</a></sup>，从她生了亚比雅、亚太、细撒、示罗密。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 8:30; 申命记 17:17; 列王纪上 11:3"> 罗波安娶十八个妻，立六十个妾，生二十八个儿子、六十个女儿，他却爱押沙龙的女儿玛迦比爱别的妻妾更甚。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 21:15–17; 历代志上 29:1; 历代志上 5:1–2"> 罗波安立玛迦的儿子亚比雅做太子，在他弟兄中为首，因为想要立他接续做王。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 21:3; 创世记 25:6; 路加福音 16:8"> 罗波安办事精明，使他众子分散在犹大和便雅悯全地各坚固城里，又赐他们许多粮食，为他们多寻妻子。</span>
</div>
</div>

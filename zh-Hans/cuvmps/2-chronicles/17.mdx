## 约沙法做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 15:24; 以弗所书 6:10; 马太福音 1:8"> 亚撒的儿子约沙法接续他做王，奋勇自强，防备以色列人，</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 15:8; 历代志下 11:5; 历代志下 11:11–12"> 安置军兵在犹大一切坚固城里，又安置防兵在犹大地和他父亚撒所得以法莲的城邑中。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 22:2; 以赛亚书 41:10; 提摩太后书 4:22"> 耶和华与约沙法同在，因为他行他祖大卫初行的道，不寻求巴力，</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 12:28; 路加福音 1:6; 帖撒罗尼迦前书 2:12"> 只寻求他父亲的神，遵行他的诫命，不效法以色列人的行为。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 18:1; 马太福音 6:33; 诗篇 127:1"> 所以耶和华坚定他的国，犹大众人给他进贡，约沙法大有尊荣、资财。</span>
<span className="v" id="v6" data-v="6" data-xref="何西阿书 14:9; 历代志下 15:17; 历代志下 20:33"> 他高兴遵行耶和华的道，并且从犹大除掉一切丘坛和木偶。</span>
</div>
</div>

## 奋志为善

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志下 35:3; 尼希米记 8:7–8; 传道书 12:9–10"> 他做王第三年，就差遣臣子便亥伊勒、俄巴底、撒迦利雅、拿坦业、米该亚往犹大各城去教训百姓。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 7:1–6; 历代志下 19:8; 玛拉基书 2:7"> 同着他们有利未人示玛雅、尼探雅、西巴第雅、亚撒黑、示米拉末、约拿单、亚多尼雅、多比雅、驼巴多尼雅，又有祭司以利沙玛、约兰同着他们。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 5:46; 罗马书 3:2; 使徒行传 8:40"> 他们带着耶和华的律法书，走遍犹大各城教训百姓。</span>
</div>
</div>

## 列国畏其强盛臣服纳贡

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志下 14:14; 出埃及记 15:14–16; 箴言 16:7"> 耶和华使犹大四围的列国都甚恐惧，不敢与约沙法争战。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 26:8; 历代志下 9:14; 撒母耳记下 8:2"> 有些非利士人与约沙法送礼物纳贡银，阿拉伯人也送他公绵羊七千七百只、公山羊七千七百只。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 8:2–6; 历代志下 14:6–7; 历代志下 32:5"> 约沙法日渐强大，在犹大建造营寨和积货城。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 27:25–31; 历代志下 26:10–15"> 他在犹大城邑中有许多工程，又在耶路撒冷有战士，就是大能的勇士。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 11:1; 创世记 15:5; 民数记 1:18"> 他们的数目，按着宗族记在下面：犹大族的，千夫长押拿为首，率领大能的勇士三十万；</span>
<span className="v" id="v15" data-v="15"> 其次是千夫长约哈难，率领大能的勇士二十八万；</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 5:9; 士师记 5:2; 历代志上 29:9"> 其次是细基利的儿子亚玛斯雅，他为耶和华牺牲自己，率领大能的勇士二十万。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 14:8; 撒母耳记下 1:21–22"> 便雅悯族，是大能的勇士以利雅大，率领拿弓箭和盾牌的二十万；</span>
<span className="v" id="v18" data-v="18"> 其次是约萨拔，率领预备打仗的十八万。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 17:2; 历代志下 11:12; 历代志下 11:23"> 这都是伺候王的，还有王在犹大全地坚固城所安置的，不在其内。</span>

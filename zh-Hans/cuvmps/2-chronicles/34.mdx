## 约西亚做王毁除崇邱偶像

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="西番雅书 1:1; 耶利米书 1:2; 历代志下 33:25"> 约西亚登基的时候年八岁，在耶路撒冷做王三十一年。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 29:2; 约书亚记 1:7; 列王纪下 22:2"> 他行耶和华眼中看为正的事，效法他祖大卫所行的，不偏左右。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 33:22; 历代志下 15:2; 箴言 8:17"> 他做王第八年，尚且年幼，就寻求他祖大卫的神。到了十二年，才洁净犹大和耶路撒冷，除掉丘坛、木偶、雕刻的像和铸造的像。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 32:20; 利未记 26:30; 列王纪下 23:4–6"> 众人在他面前拆毁巴力的坛，砍断坛上高高的日像，又把木偶和雕刻的像并铸造的像打碎成灰，撒在祭偶像人的坟上，</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 13:2; 耶利米书 3:10; 民数记 35:33"> 将他们祭司的骸骨烧在坛上，洁净了犹大和耶路撒冷。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 13:20–21; 以赛亚书 7:25; 历代志下 30:1"> 又在玛拿西、以法莲、西缅、拿弗他利各城和四围破坏之处，都这样行。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 31:1; 申命记 9:21; 历代志下 34:1"> 又拆毁祭坛，把木偶和雕刻的像打碎成灰，砍断以色列遍地所有的日像，就回耶路撒冷去了。</span>
</div>
</div>

## 修葺圣殿

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 8:16; 历代志上 18:15; 耶利米书 29:25"> 约西亚王十八年，净地净殿之后，就差遣亚萨利雅的儿子沙番、邑宰玛西雅、约哈斯的儿子史官约亚去修理耶和华他神的殿。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 30:18; 历代志下 30:10; 历代志下 35:8"> 他们就去见大祭司希勒家，将奉到神殿的银子交给他，这银子是看守殿门的利未人从玛拿西、以法莲和一切以色列剩下的人，以及犹大、便雅悯众人，并耶路撒冷的居民收来的。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 12:11–12; 以斯拉记 3:7; 列王纪下 22:5–6"> 又将这银子交给耶和华殿里督工的，转交修理耶和华殿的工匠，</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 33:4–7; 历代志下 33:22"> 就是交给木匠、石匠，买凿成的石头和架木与栋梁，修犹大王所毁坏的殿。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 12:15; 历代志上 23:5; 列王纪下 22:7"> 这些人办事诚实，督工的是利未人米拉利的子孙雅哈、俄巴底，督催的是哥辖的子孙撒迦利亚、米书兰，还有善于作乐的利未人。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 4:10; 历代志下 2:18; 耶利米书 8:8"> 他们又监管扛抬的人，督催一切做工的，利未人中也有做书记、做司事、做守门的。</span>
</div>
</div>

## 希勒家得律书

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="利未记 8:36; 诗篇 1:2; 利未记 10:11"> 他们将奉到耶和华殿的银子运出来的时候，祭司希勒家偶然得了摩西所传耶和华的律法书。</span>
<span className="v" id="v15" data-v="15"> 希勒家对书记沙番说：“我在耶和华殿里得了律法书。”遂将书递给沙番。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 22:9–10; 耶利米书 36:20–21"> 沙番把书拿到王那里，回复王说：“凡交给仆人们办的都办理了。</span>
<span className="v" id="v17" data-v="17"> 耶和华殿里的银子倒出来，交给督工的和匠人的手里了。”</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 119:46; 耶利米书 36:20–21; 申命记 17:19"> 书记沙番又对王说：“祭司希勒家递给我一卷书。”沙番就在王面前读那书。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 7:6; 申命记 28:3–68; 列王纪下 22:19"> 王听见律法上的话，就撕裂衣服，</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 22:12; 耶利米书 26:24; 耶利米书 40:9"> 吩咐希勒家与沙番的儿子亚希甘、米迦的儿子亚比顿、书记沙番和王的臣仆亚撒雅说：</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 21:2; 以西结书 14:1–11; 历代志下 28:6"> “你们去，为我，为以色列和犹大剩下的人，以这书上的话求问耶和华。因我们列祖没有遵守耶和华的言语，没有照这书上所记的去行，耶和华的烈怒就倒在我们身上。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 2:36; 出埃及记 15:20; 列王纪下 22:14"> 于是，希勒家和王所派的众人都去见女先知户勒大。户勒大是掌管礼服沙龙的妻，沙龙是哈斯拉的孙子、特瓦的儿子。户勒大住在耶路撒冷第二区，他们请问于她。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 37:7–10; 耶利米书 21:3–7; 列王纪下 22:15–20"> 她对他们说：“耶和华以色列的神如此说：你们可以回复那差遣你们来见我的人说：</span>
<span className="v" id="v24" data-v="24" data-xref="历代志下 36:14–20; 约书亚记 23:16; 申命记 28:15–68"> ‘耶和华如此说：我必照着在犹大王面前所读那书上的一切咒诅，降祸于这地和其上的居民。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 7:20; 马可福音 9:43–48; 那鸿书 1:6"> 因为他们离弃我，向别神烧香，用他们手所做的惹我发怒，所以我的愤怒如火倒在这地上，总不熄灭。’</span>
<span className="v" id="v26" data-v="26" data-xref="历代志下 34:23; 历代志下 34:21"> 然而，差遣你们来求问耶和华的犹大王，你们要这样回复他说：‘耶和华以色列的神如此说：至于你所听见的话，</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 32:26; 以西结书 9:4; 诗篇 34:18"> 就是听见我指着这地和其上居民所说的话，你便心里敬服，在我面前自卑，撕裂衣服，向我哭泣，因此我应允了你。这是我耶和华说的。</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 39:8; 诗篇 37:37; 列王纪上 21:29"> 我必使你平平安安地归到坟墓，到你列祖那里。我要降于这地和其上居民的一切灾祸，你也不致亲眼看见。’”他们就回复王去了。</span>
</div>
</div>

## 王诵约书于民众

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王纪下 23:1–3; 历代志下 30:2; 马可福音 14:8"> 王差遣人招聚犹大和耶路撒冷的众长老来。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 24:7; 列王纪下 23:2; 历代志下 34:15"> 王和犹大众人与耶路撒冷的居民，并祭司、利未人，以及所有的百姓，无论大小，都一同上到耶和华的殿。王就把殿里所得的约书念给他们听。</span>
</div>
</div>

## 立约守诫

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="历代志下 23:16; 列王纪下 23:3; 列王纪下 11:14"> 王站在他的地位上，在耶和华面前立约，要尽心、尽性地顺从耶和华，遵守他的诫命、法度、律例，成就这书上所记的约言，</span>
<span className="v" id="v32" data-v="32" data-xref="历代志下 30:12; 耶利米书 3:10; 历代志下 14:4"> 又使住耶路撒冷和便雅悯的人都服从这约。于是耶路撒冷的居民都遵行他们列祖之神的约。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志下 34:3–7; 约书亚记 24:31; 列王纪下 23:4–20"> 约西亚从以色列各处将一切可憎之物尽都除掉，使以色列境内的人都侍奉耶和华他们的神。约西亚在世的日子，就跟从耶和华他们列祖的神，总不离开。</span>
</div>
</div>

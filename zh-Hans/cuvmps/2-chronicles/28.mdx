## 亚哈斯做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 3:13; 以赛亚书 1:1; 列王纪下 16:1–20"> 亚哈斯登基的时候年二十岁，在耶路撒冷做王十六年。不像他祖大卫行耶和华眼中看为正的事，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 34:17; 士师记 2:11; 历代志下 22:3–4"> 却行以色列诸王的道，又铸造巴力的像，</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 33:2; 历代志下 33:6; 利未记 18:21"> 并且在欣嫩子谷烧香，用火焚烧他的儿女，行耶和华在以色列人面前所驱逐的外邦人那可憎的事，</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 16:4; 申命记 12:2–3; 利未记 26:30"> 并在丘坛上、山冈上、各青翠树下献祭烧香。</span>
</div>
</div>

## 为亚兰王所败

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 7:1; 历代志下 24:24; 列王纪下 16:5–6"> 所以耶和华他的神将他交在亚兰王手里，亚兰王打败他，掳了他许多的民，带到大马士革去。神又将他交在以色列王手里，以色列王向他大行杀戮。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 15:27; 约书亚记 24:20; 耶利米书 15:6"> 利玛利的儿子比加一日杀了犹大人十二万，都是勇士，因为他们离弃了耶和华他们列祖的神。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 43:15; 创世记 41:43; 以斯帖记 10:3"> 有一个以法莲中的勇士，名叫细基利，杀了王的儿子玛西雅和管理王宫的押斯利甘并宰相以利加拿。</span>
</div>
</div>

## 以色列人返犹大俘虏

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="历代志下 11:4; 申命记 28:25; 申命记 28:41"> 以色列人掳了他们的弟兄，连妇人带儿女共有二十万，又掠了许多的财物，带到撒马利亚去了。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 47:6; 以斯拉记 9:6; 启示录 18:5"> 但那里有耶和华的一个先知，名叫俄德，出来迎接往撒马利亚去的军兵，对他们说：“因为耶和华你们列祖的神恼怒犹大人，所以将他们交在你们手里，你们竟怒气冲天，大行杀戮。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 25:39–46; 马太福音 7:2–4; 耶利米书 25:29"> 如今你们又有意强逼犹大人和耶路撒冷人做你们的奴婢，你们岂不也有得罪耶和华你们神的事吗？</span>
<span className="v" id="v11" data-v="11" data-xref="雅各书 2:13; 以斯拉记 10:14; 马太福音 5:7"> 现在你们当听我说，要将掳来的弟兄释放回去，因为耶和华向你们已经大发烈怒。”</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 28:1; 耶利米书 26:6"> 于是以法莲人的几个族长，就是约哈难的儿子亚撒利雅、米实利末的儿子比利家、沙龙的儿子耶希西家、哈得莱的儿子亚玛撒，起来拦挡出兵回来的人，</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 32:14; 马太福音 23:32; 约书亚记 22:17–18"> 对他们说：“你们不可带进这被掳的人来。你们想要使我们得罪耶和华，加增我们的罪恶过犯！因为我们的罪过甚大，已经有烈怒临到以色列人了。”</span>
<span className="v" id="v14" data-v="14"> 于是，带兵器的人将掳来的人口和掠来的财物都留在众首领和会众的面前。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 25:21–22; 申命记 34:3; 士师记 1:16"> 以上提名的那些人就站起，使被掳的人前来，其中有赤身的，就从所掠的财物中拿出衣服和鞋来给他们穿，又给他们吃喝，用膏抹他们，其中有软弱的，就使他们骑驴，送到棕树城耶利哥他们弟兄那里。随后，就回撒马利亚去了。</span>
</div>
</div>

## 亚哈斯求助于亚述王

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪下 16:5–7; 以赛亚书 7:17; 以赛亚书 7:1–9"> 那时，亚哈斯王差遣人去见亚述诸王，求他们帮助，</span>
<span className="v" id="v17" data-v="17" data-xref="俄巴底亚书 1:10; 俄巴底亚书 1:13–14; 利未记 26:18"> 因为以东人又来攻击犹大，掳掠子民。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 16:57; 以西结书 16:27; 撒母耳记上 6:9"> 非利士人也来侵占高原和犹大南方的城邑，取了伯示麦，亚雅仑，基低罗，梭哥和属梭哥的乡村，亭纳和属亭纳的乡村，瑾锁和属瑾锁的乡村，就住在那里。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 21:2; 约伯记 40:12; 申命记 28:43"> 因为以色列王亚哈斯在犹大放肆，大大干犯耶和华，所以耶和华使犹大卑微。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 15:29; 历代志上 5:26; 以赛亚书 30:16"> 亚述王提革拉毗尼色上来，却没有帮助他，反倒欺凌他。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 16:8–9; 列王纪下 18:15–16; 历代志下 12:9"> 亚哈斯从耶和华殿里和王宫中并首领家内所取的财宝给了亚述王，这也无济于事。</span>
</div>
</div>

## 祭大马士革之神

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 1:5; 以西结书 21:13; 耶利米书 5:3"> 这亚哈斯王在急难的时候，越发得罪耶和华。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 25:14; 耶利米书 44:20–28; 哈巴谷书 1:11"> 他祭祀攻击他的大马士革之神，说：“因为亚兰王的神帮助他们，我也献祭于他，他好帮助我。”但那些神使他和以色列众人败亡了。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志下 29:7; 列王纪下 16:17–18; 历代志下 30:14"> 亚哈斯将神殿里的器皿都聚了来，毁坏了，且封锁耶和华殿的门，在耶路撒冷各处的拐角建筑祭坛。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 28:3"> 又在犹大各城建立丘坛，与别神烧香，惹动耶和华他列祖神的怒气。</span>
</div>
</div>

## 亚哈斯卒

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王纪下 16:19–20; 历代志下 20:34; 历代志下 27:7–9"> 亚哈斯其余的事和他的行为，自始至终，都写在《犹大和以色列诸王记》上。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 21:20; 历代志下 24:25; 箴言 10:7"> 亚哈斯与他列祖同睡，葬在耶路撒冷城里，没有送入以色列诸王的坟墓中。他儿子希西家接续他做王。</span>
</div>
</div>

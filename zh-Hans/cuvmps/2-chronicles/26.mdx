## 乌西雅做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 22:1; 马太福音 1:8–9; 历代志下 33:25"> 犹大众民立亚玛谢的儿子乌西雅<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="又名亚撒利雅。">a</a></sup>接续他父做王，那时他年十六岁。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 16:6; 历代志下 25:28; 历代志下 25:23"> 亚玛谢与他列祖同睡之后，乌西雅收回以禄仍归犹大，又重新修理。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 15:2–3; 阿摩司书 1:1; 何西阿书 1:1"> 乌西雅登基的时候年十六岁，在耶路撒冷做王五十二年。他母亲名叫耶可利雅，是耶路撒冷人。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 25:2"> 乌西雅行耶和华眼中看为正的事，效法他父亚玛谢一切所行的。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 15:2; 历代志下 24:2; 历代志上 22:13"> 通晓神默示撒迦利亚在世的时候，乌西雅定意寻求神，他寻求耶和华，神就使他亨通。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 14:29; 撒母耳记上 5:6; 撒母耳记上 5:1"> 他出去攻击非利士人，拆毁了迦特城、雅比尼城和亚实突城；在非利士人中，在亚实突境内，又建筑了些城。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 21:16; 历代志上 5:20; 历代志下 14:11"> 神帮助他攻击非利士人和住在姑珥巴力的阿拉伯人，并米乌尼人。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 8:2; 历代志下 17:11; 创世记 19:38"> 亚扪人给乌西雅进贡，他的名声传到埃及，因他甚是强盛。</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米记 3:13; 历代志下 25:23; 列王纪下 14:13"> 乌西雅在耶路撒冷的角门和谷门并城墙转弯之处，建筑城楼，且甚坚固。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 26:18–21; 以赛亚书 29:17; 列王纪下 3:4"> 又在旷野与高原和平原建筑望楼，挖了许多井，因他的牲畜甚多。又在山地和佳美之地有农夫和修理葡萄园的人，因为他喜悦农事。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 5:2"> 乌西雅又有军兵，照书记耶利和官长玛西雅所数点的，在王的一个将军哈拿尼雅手下，分队出战。</span>
<span className="v" id="v12" data-v="12"> 族长大能勇士的总数共有二千六百人，</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 25:5; 历代志下 14:8; 历代志下 11:1"> 他们手下的军兵共有三十万七千五百人，都有大能，善于争战，帮助王攻击仇敌。</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 20:16; 撒母耳记上 17:49"> 乌西雅为全军预备盾牌、枪、盔、甲、弓和甩石的机弦，</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 31:4; 马太福音 4:24; 历代志下 2:7"> 又在耶路撒冷使巧匠做机器，安在城楼和角楼上，用以射箭发石。乌西雅的名声传到远方，因为他得了非常的帮助，甚是强盛。</span>
</div>
</div>

## 乌西雅干罪生大麻风

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志下 32:25; 历代志下 25:19; 箴言 16:18"> 他既强盛，就心高气傲，以致行事邪僻，干犯耶和华他的神，进耶和华的殿，要在香坛上烧香。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 6:10; 历代志上 26:6; 历代志上 12:28"> 祭司亚撒利雅率领耶和华勇敢的祭司八十人，跟随他进去。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 30:7–8; 民数记 18:7; 耶利米书 13:18"> 他们就阻挡乌西雅王，对他说：“乌西雅啊，给耶和华烧香不是你的事，乃是亚伦子孙承接圣职祭司的事。你出圣殿吧，因为你犯了罪。你行这事，耶和华神必不使你得荣耀。”</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 12:10; 历代志下 25:16; 列王纪下 5:25–27"> 乌西雅就发怒，手拿香炉要烧香。他向祭司发怒的时候，在耶和华殿中香坛旁众祭司面前，额上忽然发出大麻风。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 28:22; 以斯帖记 6:12; 利未记 14:34"> 大祭司亚撒利雅和众祭司观看，见他额上发出大麻风，就催他出殿，他自己也急速出去，因为耶和华降灾于他。</span>
</div>
</div>

## 乌西雅卒

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="利未记 13:46; 民数记 12:15; 列王纪下 7:3"> 乌西雅王长大麻风直到死日，因此住在别的宫里，与耶和华的殿隔绝。他儿子约坦管理家事，治理国民。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 1:1; 以赛亚书 6:1; 历代志下 9:29"> 乌西雅其余的事，自始至终，都是亚摩斯的儿子先知以赛亚所记的。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 28:27; 历代志下 21:20; 历代志下 26:18"> 乌西雅与他列祖同睡，葬在王陵的田间他列祖的坟地里，因为人说他是长大麻风的。他儿子约坦接续他做王。</span>
</div>
</div>

## 希西家做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 18:1–3; 历代志上 3:13; 历代志下 26:5"> 希西家登基的时候年二十五岁，在耶路撒冷做王二十九年。他母亲名叫亚比雅，是撒迦利雅的女儿。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 34:2; 历代志下 28:1"> 希西家行耶和华眼中看为正的事，效法他祖大卫一切所行的。</span>
</div>
</div>

## 命利未人洁殿

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="历代志下 28:24; 历代志下 29:7; 马太福音 6:33"> 元年正月，开了耶和华殿的门，重新修理。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 19:2; 尼希米记 3:29; 历代志下 32:6"> 他召众祭司和利未人来，聚集在东边的宽阔处，</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 35:6; 哥林多前书 3:16–17; 历代志下 34:3–8"> 对他们说：“利未人哪，当听我说！现在你们要洁净自己，又洁净耶和华你们列祖神的殿，从圣所中除去污秽之物。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 8:16; 耶利米书 2:27; 但以理书 9:16"> 我们列祖犯了罪，行耶和华我们神眼中看为恶的事，离弃他，转脸背向他的居所，</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 28:24; 利未记 24:2–8; 历代志下 29:3"> 封锁廊门，吹灭灯火，不在圣所中向以色列神烧香或献燔祭。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 25:9; 耶利米书 25:18; 耶利米书 29:18"> 因此，耶和华的愤怒临到犹大和耶路撒冷，将其中的人抛来抛去，令人惊骇、嗤笑，正如你们亲眼所见的。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 28:17; 历代志下 28:5–8; 耶利米哀歌 5:7"> 所以我们的祖宗倒在刀下，我们的妻子、儿女也被掳掠。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 50:5; 历代志下 23:16; 以斯拉记 10:3"> 现在我心中有意与耶和华以色列的神立约，好使他的烈怒转离我们。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 10:8; 加拉太书 6:7–8; 民数记 8:6–14"> 我的众子啊，现在不要懈怠，因为耶和华拣选你们站在他面前侍奉他，与他烧香。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数记 3:19–20; 历代志上 15:5–7; 民数记 4:2–20"> 于是，利未人哥辖的子孙亚玛赛的儿子玛哈、亚撒利雅的儿子约珥，米拉利的子孙亚伯底的儿子基士、耶哈利勒的儿子亚撒利雅，革顺的子孙薪玛的儿子约亚、约亚的儿子伊甸，</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 6:39; 历代志上 15:8; 历代志上 15:17"> 以利撒反的子孙申利和耶利，亚萨的子孙撒迦利雅和玛探雅，</span>
<span className="v" id="v14" data-v="14" data-xref="历代志上 6:33; 历代志上 25:1; 历代志上 25:6"> 希幔的子孙耶歇和示每，耶杜顿的子孙示玛雅和乌薛，</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 30:12; 历代志上 23:28; 历代志下 29:5"> 起来聚集他们的弟兄，洁净自己，照着王的吩咐、耶和华的命令，进去洁净耶和华的殿。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 15:16; 马太福音 21:12–13; 马太福音 23:27"> 祭司进入耶和华的殿要洁净殿，将殿中所有污秽之物搬到耶和华殿的院内，利未人接去，搬到外头汲沦溪边。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 12:2–8; 历代志下 3:4; 列王纪上 6:3"> 从正月初一日洁净起，初八日到了耶和华的殿廊，用八日的工夫洁净耶和华的殿，到正月十六日才洁净完了。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 4:1; 历代志下 4:7–8; 历代志下 13:11"> 于是，他们晋见希西家王，说：“我们已将耶和华的全殿和燔祭坛并坛的一切器皿，陈设饼的桌子与桌子的一切器皿，都洁净了。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 28:24"> 并且亚哈斯王在位犯罪的时候所废弃的器皿，我们预备齐全，且洁净了，现今都在耶和华的坛前。”</span>
</div>
</div>

## 献赎罪祭

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约书亚记 6:12; 耶利米书 25:4; 出埃及记 24:4"> 希西家王清早起来，聚集城里的首领，都上耶和华的殿。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 4:3–14; 约伯记 42:8; 以西结书 45:23"> 牵了七只公牛、七只公羊、七只羊羔、七只公山羊，要为国、为殿、为犹大人做赎罪祭。王吩咐亚伦的子孙众祭司献在耶和华的坛上，</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 4:18; 利未记 8:19; 利未记 8:24"> 就宰了公牛，祭司接血洒在坛上；宰了公羊，把血洒在坛上；又宰了羊羔，也把血洒在坛上。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 4:15; 利未记 4:24; 利未记 1:4"> 把那做赎罪祭的公山羊牵到王和会众面前，他们就按手在其上。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 14:20; 以西结书 45:15; 哥林多后书 5:18–21"> 祭司宰了羊，将血献在坛上做赎罪祭，为以色列众人赎罪，因为王吩咐将燔祭和赎罪祭为以色列众人献上。</span>
</div>
</div>

## 献燔祭

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="历代志下 8:14; 历代志上 23:5; 撒母耳记下 24:11"> 王又派利未人在耶和华殿中敲钹、鼓瑟、弹琴，乃照大卫和他先见迦得并先知拿单所吩咐的，就是耶和华藉先知所吩咐的。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志上 23:5; 历代志上 15:24; 阿摩司书 6:5"> 利未人拿大卫的乐器，祭司拿号，一同站立。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 23:18; 诗篇 137:3–4; 历代志下 20:21"> 希西家吩咐在坛上献燔祭。燔祭一献，就唱赞美耶和华的歌，用号并用以色列王大卫的乐器相和。</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 5:8–14; 诗篇 89:15; 诗篇 68:24–26"> 会众都敬拜，歌唱的歌唱，吹号的吹号，如此直到燔祭献完了。</span>
</div>
</div>

## 献感谢祭与燔祭

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="历代志下 20:18; 历代志上 29:20; 腓立比书 2:10–11"> 献完了祭，王和一切跟随的人都俯伏敬拜。</span>
<span className="v" id="v30" data-v="30" data-xref="腓立比书 4:4; 诗篇 95:1–2; 历代志上 16:7–36"> 希西家王与众首领又吩咐利未人用大卫和先见亚萨的诗词颂赞耶和华，他们就欢欢喜喜地颂赞耶和华，低头敬拜。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="历代志下 13:9; 出埃及记 35:22; 利未记 7:12"> 希西家说：“你们既然归耶和华为圣，就要前来把祭物和感谢祭奉到耶和华殿里。”会众就把祭物和感谢祭奉来，凡甘心乐意的也将燔祭奉来。</span>
<span className="v" id="v32" data-v="32" data-xref="以斯拉记 6:17; 列王纪上 3:4; 历代志上 29:21"> 会众所奉的燔祭如下：公牛七十只，公羊一百只，羊羔二百只，这都是做燔祭献给耶和华的。</span>
<span className="v" id="v33" data-v="33"> 又有分别为圣之物：公牛六百只，绵羊三千只。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志下 35:11; 历代志下 30:3; 诗篇 94:15"> 但祭司太少，不能剥尽燔祭牲的皮，所以他们的弟兄利未人帮助他们，直等燔祭的事完了，又等别的祭司自洁了，因为利未人诚心自洁，胜过祭司。</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 15:5–10; 出埃及记 29:13; 历代志上 16:37–42"> 燔祭和平安祭牲的脂油并燔祭同献的奠祭甚多。这样，耶和华殿中的事务俱都齐备了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：就整顿了。">a</a></sup>。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 2:41; 帖撒罗尼迦前书 3:8–9; 历代志上 29:9"> 这事办得甚速，希西家和众民都喜乐，是因神为众民所预备的。</span>
</div>
</div>

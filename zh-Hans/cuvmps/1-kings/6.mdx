## 始建圣殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 3:1–2; 使徒行传 7:47; 历代志上 29:19"> 以色列人出埃及地后四百八十年，所罗门做以色列王第四年西弗月，就是二月，开工建造耶和华的殿。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 40:1–41; 以西结书 41:1–15; 启示录 21:16–17"> 所罗门王为耶和华所建的殿，长六十肘，宽二十肘，高三十肘。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 28:11; 历代志下 3:3–4; 以西结书 41:15"> 殿前的廊子长二十肘，与殿的宽窄一样，阔十肘。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 40:16; 以西结书 41:26; 以西结书 41:16"> 又为殿做了严紧的窗棂。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 6:16; 列王纪上 6:19–21; 列王纪上 6:31"> 靠着殿墙，围着外殿、内殿，造了三层旁屋，</span>
<span className="v" id="v6" data-v="6"> 下层宽五肘，中层宽六肘，上层宽七肘。殿外旁屋的梁木搁在殿墙坎上，免得插入殿墙。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 27:5–6; 彼得前书 2:5; 出埃及记 20:25"> 建殿是用山中凿成的石头，建殿的时候，锤子、斧子和别样铁器的响声都没有听见。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 41:6–7"> 在殿右边当中的旁屋有门，门内有旋螺的楼梯，可以上到第二层，从第二层可以上到第三层。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 6:14; 列王纪上 6:38"> 所罗门建殿，安置香柏木的栋梁，又用香柏木板遮盖。</span>
<span className="v" id="v10" data-v="10"> 靠着殿所造的旁屋，每层高五肘，香柏木的栋梁搁在殿墙坎上。</span>
</div>
</div>

## 耶和华之约

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和华的话临到所罗门说：</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 22:10; 歌罗西书 1:23; 列王纪上 3:14"> “论到你所建的这殿，你若遵行我的律例，谨守我的典章，遵从我的一切诫命，我必向你应验我所应许你父亲大卫的话。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 31:6; 出埃及记 25:8; 利未记 26:11"> 我必住在以色列人中间，并不丢弃我民以色列。”</span>
</div>
</div>

## 造内殿

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王纪上 6:9; 列王纪上 6:38; 使徒行传 7:47–48"> 所罗门建造殿宇。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 7:7"> 殿里面用香柏木板贴墙，从地到篷顶都用木板遮蔽，又用松木板铺地。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 3:8; 列王纪上 8:6; 希伯来书 9:3"> 内殿，就是至圣所，长二十肘，从地到篷顶用香柏木板遮蔽<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：隔断。">a</a></sup>。</span>
<span className="v" id="v17" data-v="17"> 内殿前的外殿，长四十肘。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 7:24"> 殿里一点石头都不显露，一概用香柏木遮蔽，上面刻着野瓜和初开的花。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 8:6–10; 诗篇 28:2; 列王纪上 6:5"> 殿里预备了内殿，好安放耶和华的约柜。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 6:2–3; 列王纪上 6:22; 列王纪上 7:48"> 内殿长二十肘，宽二十肘，高二十肘，墙面都贴上精金。又用香柏木做坛，包上精金。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志下 3:7–9; 历代志下 3:14–16; 列王纪上 6:5"> 所罗门用精金贴了殿内的墙，又用金链子挂在内殿前门扇，用金包裹。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 30:1; 出埃及记 30:3; 历代志下 3:7–14"> 全殿都贴上金子，直到贴完。内殿前的坛，也都用金包裹。</span>
</div>
</div>

## 造二基路伯

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出埃及记 37:7–9; 创世记 3:24; 彼得前书 1:12"> 他用橄榄木做两个基路伯，各高十肘，安在内殿。</span>
<span className="v" id="v24" data-v="24"> 这一个基路伯有两个翅膀，各长五肘，从这翅膀尖到那翅膀尖共有十肘。</span>
<span className="v" id="v25" data-v="25"> 那一个基路伯的两个翅膀也是十肘，两个基路伯的尺寸、形像都是一样。</span>
<span className="v" id="v26" data-v="26"> 这基路伯高十肘，那基路伯也是如此。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 37:9; 出埃及记 25:20; 历代志下 5:8"> 他将两个基路伯安在内殿里，基路伯的翅膀是张开的，这基路伯的一个翅膀挨着这边的墙，那基路伯的一个翅膀挨着那边的墙，里边的两个翅膀在殿中间彼此相接。</span>
<span className="v" id="v28" data-v="28"> 又用金子包裹二基路伯。</span>
</div>
</div>

## 殿之装饰

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王纪上 6:32; 诗篇 92:12–15; 历代志下 4:2–5"> 内殿、外殿周围的墙上都刻着基路伯、棕树和初开的花。</span>
<span className="v" id="v30" data-v="30" data-xref="启示录 21:18–21; 以赛亚书 60:17; 以赛亚书 54:11–12"> 内殿、外殿的地板都贴上金子。</span>
<span className="v" id="v31" data-v="31" data-xref="希伯来书 10:19–20; 以弗所书 3:18; 约翰福音 14:6"> 又用橄榄木制造内殿的门扇、门楣、门框，门口有墙的五分之一。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 6:18; 列王纪上 6:29"> 在橄榄木做的两门扇上刻着基路伯、棕树和初开的花，都贴上金子。</span>
<span className="v" id="v33" data-v="33"> 又用橄榄木制造外殿的门框，门口有墙的四分之一。</span>
<span className="v" id="v34" data-v="34" data-xref="以西结书 41:23–25; 列王纪上 5:8"> 用松木做门两扇，这扇分两扇，是折叠的，那扇分两扇，也是折叠的。</span>
<span className="v" id="v35" data-v="35"> 上面刻着基路伯、棕树和初开的花，都用金子贴了。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 7:12; 历代志下 7:7; 出埃及记 27:9–19"> 他又用凿成的石头三层，香柏木一层建筑内院。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="列王纪上 6:1; 历代志下 3:2"> 所罗门在位第四年西弗月，立了耶和华殿的根基。</span>
<span className="v" id="v38" data-v="38" data-xref="以斯拉记 6:14–15; 列王纪上 7:1; 撒迦利亚书 4:9"> 到十一年布勒月，就是八月，殿和一切属殿的都按着样式造成。他建殿的工夫共有七年。</span>
</div>
</div>

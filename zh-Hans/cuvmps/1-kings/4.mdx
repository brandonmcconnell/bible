## 记所罗门诸臣之名

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="传道书 1:12; 历代志下 9:30; 列王纪上 12:19–20"> 所罗门做以色列众人的王。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 18:21; 哥林多前书 12:28; 撒母耳记下 8:15–18"> 他的臣子记在下面：撒督的儿子亚撒利雅做祭司，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 8:16; 以赛亚书 62:6; 历代志上 18:15"> 示沙的两个儿子以利何烈、亚希亚做书记，亚希律的儿子约沙法做史官，</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 2:35; 列王纪上 2:26–27"> 耶何耶大的儿子比拿雅做元帅，撒督和亚比亚他做祭司长，</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 27:33; 撒母耳记下 15:37; 撒母耳记下 16:16"> 拿单的儿子亚撒利雅做众吏长，王的朋友拿单的儿子撒布得做领袖，</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 9:15; 撒母耳记下 20:24; 列王纪上 12:18"> 亚希煞做家宰，亚比大的儿子亚多尼兰掌管服苦的人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志上 27:1–15"> 所罗门在以色列全地立了十二个官吏，使他们供给王和王家的食物，每年各人供给一月。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 24:33; 士师记 19:1; 士师记 17:1"> 他们的名字记在下面：在以法莲山地有便户珥；</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 21:16; 撒母耳记上 6:20; 撒母耳记上 6:12"> 在玛迦斯、沙宾、伯示麦、以伦伯哈南有便底甲；</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 15:35; 约书亚记 12:17; 约书亚记 17:2"> 在亚鲁泊有便希悉，他管理梭哥和希弗全地；</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 11:2; 约书亚记 12:23; 约书亚记 17:11"> 在多珥山冈<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：全境。">a</a></sup>有便亚比拿达，他娶了所罗门的女儿她法为妻；</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 17:11; 士师记 5:19; 约书亚记 3:16"> 在他纳和米吉多，并靠近撒拉他拿，耶斯列下边的伯善全地，从伯善到亚伯米何拉直到约念之外，有亚希律的儿子巴拿；</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 3:4; 民数记 32:41; 列王纪上 22:3"> 在基列的拉末有便基别，他管理在基列的玛拿西子孙睚珥的城邑，巴珊的亚珥歌伯地的大城六十座，都有城墙和铜闩；</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 13:26; 撒母耳记下 17:24; 撒母耳记下 2:8"> 在玛哈念有易多的儿子亚希拿达；</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 19:32–39; 撒母耳记下 15:27; 撒母耳记上 18:18"> 在拿弗他利有亚希玛斯，他也娶了所罗门的一个女儿巴实抹为妻；</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 19:24–31; 撒母耳记下 15:32"> 在亚设和亚禄有户筛的儿子巴拿；</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 19:17–23"> 在以萨迦有帕路亚的儿子约沙法；</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 1:8; 约书亚记 18:20–28; 撒迦利亚书 12:13"> 在便雅悯有以拉的儿子示每；</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 2:26–17; 约书亚记 13:9–12; 民数记 21:21–35"> 在基列地，就是从前属亚摩利王西宏和巴珊王噩之地，有乌利的儿子基别一人管理。</span>
</div>
</div>

## 所罗门之富强

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 22:17; 列王纪上 3:8; 创世记 32:12"> 犹大人和以色列人如同海边的沙那样多，都吃喝快乐。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 15:18; 约书亚记 1:4; 诗篇 68:29"> 所罗门统管诸国，从大河到非利士地，直到埃及的边界。所罗门在世的日子，这些国都进贡服侍他。</span>
<span className="v" id="v22" data-v="22"> 所罗门每日所用的食物，细面三十歌珥，粗面六十歌珥，</span>
<span className="v" id="v23" data-v="23" data-xref="尼希米记 5:17–18"> 肥牛十只，草场的牛二十只，羊一百只，还有鹿、羚羊、狍子并肥禽。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 22:9; 诗篇 72:11; 诗篇 72:3"> 所罗门管理大河西边的诸王，以及从提弗萨直到加沙的全地，四境尽都平安。</span>
<span className="v" id="v25" data-v="25" data-xref="弥迦书 4:4; 撒迦利亚书 3:10; 士师记 20:1"> 所罗门在世的日子，从但到别是巴的犹大人和以色列人，都在自己的葡萄树下和无花果树下安然居住。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志下 1:14; 历代志下 9:25; 撒母耳记下 8:4"> 所罗门有套车的马四万，还有马兵一万二千。</span>
<span className="v" id="v27" data-v="27"> 那十二个官吏各按各月供给所罗门王，并一切与他同席之人的食物，一无所缺。</span>
<span className="v" id="v28" data-v="28" data-xref="以斯帖记 8:10; 以斯帖记 8:14; 弥迦书 1:13"> 众人各按各分，将养马与快马的大麦和干草送到官吏那里。</span>
</div>
</div>

## 所罗门之智能

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王纪上 3:12; 雅各书 3:17; 列王纪上 4:20"> 神赐给所罗门极大的智慧、聪明和广大的心，如同海沙不可测量。</span>
<span className="v" id="v30" data-v="30" data-xref="但以理书 5:11–12; 创世记 25:6; 但以理书 1:20"> 所罗门的智慧超过东方人和埃及人的一切智慧。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 2:6; 历代志上 15:19; 列王纪上 3:12"> 他的智慧胜过万人，胜过以斯拉人以探并玛曷的儿子希幔、甲各、达大的智慧。他的名声传扬在四围的列国。</span>
<span className="v" id="v32" data-v="32" data-xref="雅歌 1:1–17; 马太福音 13:35; 箴言 1:1–31"> 他作箴言三千句，诗歌一千零五首。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪下 19:23; 诗篇 51:7; 诗篇 92:12"> 他讲论草木，自黎巴嫩的香柏树直到墙上长的牛膝草，又讲论飞禽走兽、昆虫水族。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志下 9:23; 列王纪上 10:1; 历代志下 9:1"> 天下列王听见所罗门的智慧，就都差人来听他的智慧话。</span>
</div>
</div>

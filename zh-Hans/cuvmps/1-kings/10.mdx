## 示巴女王觐所罗门

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 12:42; 路加福音 11:31; 历代志下 9:1–12"> 示巴女王听见所罗门因耶和华之名所得的名声，就来要用难解的话试问所罗门。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 25:23; 诗篇 4:4; 约伯记 4:2"> 跟随她到耶路撒冷的人甚多，又有骆驼驮着香料、宝石和许多金子。她来见了所罗门王，就把心里所有的对所罗门都说出来。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 1:5–6; 马太福音 13:11; 列王纪上 10:1"> 所罗门王将她所问的都答上了，没有一句不明白不能答的。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 12:42; 列王纪上 3:28; 历代志下 9:3–4"> 示巴女王见所罗门大有智慧，和他所建造的宫室，</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 26:16; 列王纪上 4:22–23; 列王纪下 16:18"> 席上的珍馐美味，群臣分列而坐，仆人两旁侍立，以及他们的衣服装饰和酒政的衣服装饰，又见他上耶和华殿的台阶<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：他在耶和华殿里所献的燔祭。">a</a></sup>，就诧异得神不守舍，</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 9:5–6"> 对王说：“我在本国里所听见论到你的事和你的智慧实在是真的！</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 2:9; 约翰福音 20:25–29; 约翰一书 3:2"> 我先不信那些话，及至我来，亲眼见了，才知道人所告诉我的还不到一半。你的智慧和你的福分越过我所听见的风声。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 8:34; 箴言 10:21; 路加福音 11:31"> 你的臣子、你的仆人常侍立在你面前听你智慧的话是有福的！</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 72:2; 列王纪上 5:7; 撒母耳记下 8:15"> 耶和华你的神是应当称颂的！他喜悦你，使你坐以色列的国位。因为他永远爱以色列，所以立你做王，使你秉公行义。”</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 10:2; 马太福音 2:11; 列王纪上 9:14"> 于是示巴女王将一百二十他连得金子和宝石，与极多的香料送给所罗门王。她送给王的香料，以后奉来的不再有这样多。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪上 9:27–28; 历代志下 8:18; 诗篇 45:9"> 希兰的船只从俄斐运了金子来，又从俄斐运了许多檀香木<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：乌木。下同。">b</a></sup>和宝石来。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 25:1–31; 诗篇 150:3–5; 启示录 14:2–3"> 王用檀香木为耶和华殿和王宫做栏杆，又为歌唱的人做琴瑟。以后再没有这样的檀香木进国来，也没有人看见过，直到如今。</span>
</div>
</div>

## 所罗门厚馈女王

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="诗篇 37:4; 马太福音 15:28; 诗篇 20:4"> 示巴女王一切所要所求的，所罗门王都送给她，另外照自己的厚意馈送她。于是女王和她臣仆转回本国去了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志下 9:13–28; 列王纪上 9:28"> 所罗门每年所得的金子共有六百六十六他连得，</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 72:10; 历代志上 9:24; 以赛亚书 21:13"> 另外还有商人和杂族<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“杂族”《历代志下》9章14节作“阿拉伯”。">c</a></sup>的诸王与国中的省长所进的金子。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 14:26–28; 历代志下 12:9–10; 历代志下 9:15–16"> 所罗门王用锤出来的金子打成挡牌二百面，每面用金子六百舍客勒，</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 7:2; 列王纪上 14:26"> 又用锤出来的金子打成盾牌三百面，每面用金子三弥那，都放在黎巴嫩林宫里。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 45:8; 列王纪上 10:22; 启示录 20:11"> 王用象牙制造一个宝座，用精金包裹。</span>
<span className="v" id="v19" data-v="19"> 宝座有六层台阶，座的后背是圆的，两旁有扶手，靠近扶手有两个狮子站立。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 24:9; 创世记 49:9; 民数记 23:24"> 六层台阶上有十二个狮子站立，每层有两个，左边一个，右边一个。在列国中没有这样做的。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 10:17; 列王纪上 7:2; 历代志下 9:20–22"> 所罗门王一切的饮器都是金子的，黎巴嫩林宫里的一切器皿都是精金的，所罗门年间银子算不了什么。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 22:48; 创世记 10:4; 历代志下 20:36–37"> 因为王有他施船只与希兰的船只一同航海，三年一次，装载金银、象牙、猿猴、孔雀回来。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪上 3:12–13; 歌罗西书 2:2–3; 列王纪上 4:29–34"> 所罗门王的财宝与智慧胜过天下的列王。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 3:12; 雅各书 1:5; 列王纪上 3:28"> 普天下的王都求见所罗门，要听神赐给他智慧的话。</span>
<span className="v" id="v25" data-v="25" data-xref="约伯记 42:11; 诗篇 72:10; 诗篇 72:15"> 他们各带贡物，就是金器、银器、衣服、军械、香料、骡马，每年有一定之例。</span>
</div>
</div>

## 所罗门之车骑

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="历代志下 9:25; 列王纪上 4:26; 申命记 17:16"> 所罗门聚集战车马兵，有战车一千四百辆，马兵一万二千名，安置在屯车的城邑和耶路撒冷，就是王那里。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 1:15–17; 申命记 17:17; 历代志下 9:27"> 王在耶路撒冷使银子多如石头，香柏木多如高原的桑树。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 17:16; 历代志下 9:28; 以赛亚书 31:1–3"> 所罗门的马是从埃及带来的，是王的商人一群一群按着定价买来的。</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 1:4; 列王纪下 7:6–7; 玛拉基书 1:1"> 从埃及买来的车，每辆价银六百舍客勒，马每匹一百五十舍客勒。赫人诸王和亚兰诸王所买的车马，也是按这价值经他们手买来的。</span>
</div>
</div>

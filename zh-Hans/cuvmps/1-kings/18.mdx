## 以利亚奉命见亚哈

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 4:25; 雅各书 5:17; 申命记 28:12"> 过了许久，到第三年，耶和华的话临到以利亚说：“你去，使亚哈得见你，我要降雨在地上。”</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 6:25; 箴言 28:1; 利未记 26:26"> 以利亚就去，要使亚哈得见他。那时撒马利亚有大饥荒。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 7:2; 列王纪上 16:9; 马太福音 10:28"> 亚哈将他的家宰俄巴底召了来。俄巴底甚是敬畏耶和华，</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 18:13; 马太福音 10:40–42; 启示录 17:4–6"> 耶洗别杀耶和华众先知的时候，俄巴底将一百个先知藏了，每五十人藏在一个洞里，拿饼和水供养他们。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 14:5–6; 约珥书 1:18; 约珥书 2:22"> 亚哈对俄巴底说：“我们走遍这地，到一切水泉旁和一切溪边，或者找得着青草，可以救活骡马，免得绝了牲畜。”</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 14:3"> 于是二人分地游行，亚哈独走一路，俄巴底独走一路。</span>
</div>
</div>

## 俄巴底寻草遇以利亚

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王纪下 1:6–8; 创世记 44:20; 以赛亚书 60:14"> 俄巴底在路上恰与以利亚相遇，俄巴底认出他来，就俯伏在地，说：“你是我主以利亚不是？”</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 13:7; 列王纪上 18:3; 彼得前书 2:17–18"> 回答说：“是。你去告诉你主人说，以利亚在这里。”</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 5:21; 列王纪上 18:12; 列王纪上 17:18"> 俄巴底说：“仆人有什么罪，你竟要将我交在亚哈手里，使他杀我呢？</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 17:1; 列王纪上 1:29; 列王纪上 18:15"> 我指着永生耶和华你的神起誓，无论哪一邦哪一国，我主都打发人去找你。若说你没有在那里，就必使那邦那国的人起誓说实在是找不着你。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 18:8; 列王纪上 18:14"> 现在你说‘要去告诉你主人说以利亚在这里’！</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 2:16; 使徒行传 8:39; 以西结书 8:3"> 恐怕我一离开你，耶和华的灵就提你到我所不知道的地方去。这样，我去告诉亚哈，他若找不着你，就必杀我。仆人却是自幼敬畏耶和华的！</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 18:4; 马太福音 25:35; 诗篇 18:21–24"> 耶洗别杀耶和华众先知的时候，我将耶和华的一百个先知藏了，每五十人藏在一个洞里，拿饼和水供养他们。岂没有人将这事告诉我主吗？</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 10:28"> 现在你说‘要去告诉你主人说，以利亚在这里’，他必杀我！”</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 17:1; 列王纪上 18:10; 路加福音 2:13–14"> 以利亚说：“我指着所侍奉永生的万军之耶和华起誓：我今日必使亚哈得见我。”</span>
</div>
</div>

## 亚哈迎以利亚

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16"> 于是俄巴底去迎着亚哈，告诉他，亚哈就去迎着以利亚。</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 7:25; 列王纪上 21:20; 使徒行传 16:20"> 亚哈见了以利亚，便说：“使以色列遭灾的就是你吗？”</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 15:2; 列王纪上 9:9; 耶利米书 2:19"> 以利亚说：“使以色列遭灾的不是我，乃是你和你父家，因为你们离弃耶和华的诫命，去随从巴力。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 19:26; 列王纪上 16:33; 彼得后书 2:1"> 现在你当差遣人，招聚以色列众人和侍奉巴力的那四百五十个先知，并耶洗别所供养侍奉亚舍拉的那四百个先知，使他们都上迦密山去见我。”</span>
</div>
</div>

## 于迦密山试先知之真伪

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王纪上 22:9"> 亚哈就差遣人招聚以色列众人和先知都上迦密山。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 6:24; 约书亚记 24:15; 哥林多前书 10:21–22"> 以利亚前来对众民说：“你们心持两意要到几时呢？若耶和华是神，就当顺从耶和华；若巴力是神，就当顺从巴力。”众民一言不答。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 19:10; 列王纪上 19:14; 提摩太后书 4:3–4"> 以利亚对众民说：“做耶和华先知的只剩下我一个人，巴力的先知却有四百五十个人。</span>
<span className="v" id="v23" data-v="23"> 当给我们两只牛犊，巴力的先知可以挑选一只，切成块子，放在柴上，不要点火。我也预备一只牛犊放在柴上，也不点火。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 18:38; 历代志上 21:26; 历代志下 7:1"> 你们求告你们神的名，我也求告耶和华的名。那降火显应的神，就是神。”众民回答说：“这话甚好。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 以利亚对巴力的先知说：“你们既是人多，当先挑选一只牛犊，预备好了，就求告你们神的名，却不要点火。”</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 10:5; 哥林多前书 8:4; 马太福音 6:7"> 他们将所得的牛犊预备好了，从早晨到午间，求告巴力的名说：“巴力啊，求你应允我们！”却没有声音，没有应允的。他们在所筑的坛四围踊跳。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 78:65–66; 以赛亚书 41:23; 传道书 11:9"> 到了正午，以利亚戏笑他们，说：“大声求告吧！因为他是神，他或默想，或走到一边，或行路，或睡觉，你们当叫醒他。”</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 19:28; 申命记 14:1; 马可福音 5:5"> 他们大声求告，按着他们的规矩，用刀枪自割自刺，直到身体流血。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪上 18:26; 撒母耳记上 18:10; 出埃及记 29:39"> 从午后直到献晚祭的时候，他们狂呼乱叫，却没有声音，没有应允的，也没有理会的。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="历代志下 33:16; 列王纪上 19:14; 列王纪上 19:10"> 以利亚对众民说：“你们到我这里来。”众民就到他那里。他便重修已经毁坏耶和华的坛。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 17:34; 创世记 35:10; 创世记 32:28"> 以利亚照雅各子孙支派的数目，取了十二块石头（耶和华的话曾临到雅各说“你的名要叫以色列”），</span>
<span className="v" id="v32" data-v="32" data-xref="歌罗西书 3:17; 出埃及记 20:24–25; 士师记 21:4"> 用这些石头为耶和华的名筑一座坛，在坛的四围挖沟，可容谷种二细亚。</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 22:9; 士师记 6:20; 利未记 1:6–8"> 又在坛上摆好了柴，把牛犊切成块子放在柴上，对众人说：“你们用四个桶盛满水，倒在燔祭和柴上。”</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多后书 8:21; 哥林多后书 4:2"> 又说：“倒第二次。”他们就倒第二次。又说：“倒第三次。”他们就倒第三次。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 18:32; 列王纪上 18:38"> 水流在坛的四围，沟里也满了水。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 18:29; 列王纪下 19:19; 出埃及记 3:6"> 到了献晚祭的时候，先知以利亚近前来，说：“亚伯拉罕、以撒、以色列的神，耶和华啊，求你今日使人知道你是以色列的神，也知道我是你的仆人，又是奉你的命行这一切事。</span>
<span className="v" id="v37" data-v="37" data-xref="但以理书 9:17–19; 路加福音 1:16–17; 以西结书 36:25–27"> 耶和华啊，求你应允我，应允我，使这民知道你耶和华是神，又知道是你叫这民的心回转。”</span>
<span className="v" id="v38" data-v="38" data-xref="历代志上 21:26; 利未记 9:24; 历代志下 7:1"> 于是，耶和华降下火来，烧尽燔祭、木柴、石头、尘土，又烧干沟里的水。</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪上 18:24; 历代志下 7:3; 列王纪上 18:21"> 众民看见了，就俯伏在地，说：“耶和华是神！耶和华是神！”</span>
<span className="v" id="v40" data-v="40" data-xref="申命记 18:20; 士师记 4:7; 申命记 13:5"> 以利亚对他们说：“拿住巴力的先知，不容一人逃脱！”众人就拿住他们。以利亚带他们到基顺河边，在那里杀了他们。</span>
</div>
</div>

## 天降大雨

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="列王纪上 18:1; 传道书 9:7; 列王纪上 17:1"> 以利亚对亚哈说：“你现在可以上去吃喝，因为有多雨的响声了。”</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 6:12; 但以理书 9:7; 约书亚记 7:6"> 亚哈就上去吃喝。以利亚上了迦密山顶，屈身在地，将脸伏在两膝之中。</span>
<span className="v" id="v43" data-v="43" data-xref="哈巴谷书 2:3; 路加福音 18:7; 路加福音 18:1"> 对仆人说：“你上去，向海观看。”仆人就上去观看，说：“没有什么。”他说：“你再去观看。”如此七次。</span>
<span className="v" id="v44" data-v="44" data-xref="路加福音 12:54; 约伯记 8:7; 撒迦利亚书 4:10"> 第七次仆人说：“我看见有一小片云从海里上来，不过如人手那样大。”以利亚说：“你上去告诉亚哈，当套车下去，免得被雨阻挡。”</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪上 18:39–40; 约书亚记 17:16; 列王纪上 21:1"> 霎时间，天因风云黑暗，降下大雨。亚哈就坐车往耶斯列去了。</span>
<span className="v" id="v46" data-v="46" data-xref="以西结书 3:14; 以西结书 1:3; 列王纪下 9:1"> 耶和华的灵<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：手。">a</a></sup>降在以利亚身上，他就束上腰，奔在亚哈前头，直到耶斯列的城门。</span>
</div>
</div>

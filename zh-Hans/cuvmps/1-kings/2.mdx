## 大卫遗命所罗门

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 47:29; 申命记 31:14; 提摩太前书 1:18"> 大卫的死期临近了，就嘱咐他儿子所罗门说：</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 1:6–7; 约书亚记 23:14; 以弗所书 6:10"> “我现在要走世人必走的路，所以你当刚强，做大丈夫，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 29:9; 申命记 17:18–20; 箴言 3:1–4"> 遵守耶和华你神所吩咐的，照着摩西律法上所写的行主的道，谨守他的律例、诫命、典章、法度。这样，你无论做什么事，不拘往何处去，尽都亨通。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 20:3; 撒母耳记下 7:25; 列王纪上 8:25"> 耶和华必成就向我所应许的话说：‘你的子孙若谨慎自己的行为，尽心、尽意，诚诚实实地行在我面前，就不断人坐以色列的国位。’</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 3:27; 撒母耳记下 20:10; 撒母耳记下 18:5"> 你知道洗鲁雅的儿子约押向我所行的，就是杀了以色列的两个元帅——尼珥的儿子押尼珥和益帖的儿子亚玛撒。他在太平之时流这二人的血，如在争战之时一样，将这血染了腰间束的带和脚上穿的鞋。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 2:9; 以赛亚书 57:21; 诗篇 37:37"> 所以你要照你的智慧行，不容他白头安然下阴间。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 17:27–29; 撒母耳记下 9:7; 撒母耳记下 19:31–40"> 你当恩待基列人巴西莱的众子，使他们常与你同席吃饭，因为我躲避你哥哥押沙龙的时候，他们拿食物来迎接我。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 16:5–8; 列王纪上 2:36–46; 撒母耳记下 19:16–23"> 在你这里有巴户琳的便雅悯人基拉的儿子示每。我往玛哈念去的那日，他用狠毒的言语咒骂我，后来却下约旦河迎接我，我就指着耶和华向他起誓说：‘我必不用刀杀你。’</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 2:6; 创世记 42:38; 创世记 44:31"> 现在你不要以他为无罪。你是聪明人，必知道怎样待他，使他白头见杀，流血下到阴间。”</span>
</div>
</div>

## 大卫寿终

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 2:29; 使徒行传 13:36; 列王纪上 1:21"> 大卫与他列祖同睡，葬在大卫城。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 5:4–5; 历代志上 29:26–27"> 大卫做以色列王四十年，在希伯仑做王七年，在耶路撒冷做王三十三年。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 1:1; 历代志上 29:23–25; 诗篇 132:12"> 所罗门坐他父亲大卫的位，他的国甚是坚固。</span>
</div>
</div>

## 亚多尼雅求亚比煞为妻

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 16:4–5; 列王纪上 1:5–10; 路加福音 10:5–6"> 哈及的儿子亚多尼雅去见所罗门的母亲拔示巴，拔示巴问他说：“你来是为平安吗？”回答说：“是为平安。”</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 14:12; 路加福音 7:40"> 又说：“我有话对你说。”拔示巴说：“你说吧。”</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 22:9–10; 历代志上 28:5–7; 列王纪上 1:25"> 亚多尼雅说：“你知道国原是归我的，以色列众人也都仰望我做王，不料，国反归了我兄弟，因他得国是出乎耶和华。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 30:7; 诗篇 132:10"> 现在我有一件事求你，望你不要推辞。”拔示巴说：“你说吧。”</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 12:8; 列王纪上 1:2–4; 撒母耳记下 3:7"> 他说：“求你请所罗门王将书念的女子亚比煞赐我为妻，因他必不推辞你。”</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 14:15"> 拔示巴说：“好，我必为你对王提说。”</span>
</div>
</div>

## 亚多尼雅见杀

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="诗篇 45:9; 列王纪上 15:13; 利未记 19:32"> 于是，拔示巴去见所罗门王，要为亚多尼雅提说。王起来迎接，向她下拜，就坐在位上，吩咐人为王母设一座位，她便坐在王的右边。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 7:7–11; 马太福音 11:24; 约翰福音 2:3–4"> 拔示巴说：“我有一件小事求你，望你不要推辞。”王说：“请母亲说，我必不推辞。”</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 1:3; 撒母耳记下 16:21–22"> 拔示巴说：“求你将书念的女子亚比煞赐给你哥哥亚多尼雅为妻。”</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 3:2; 历代志上 3:5; 马太福音 20:22"> 所罗门王对他母亲说：“为何单替他求书念的女子亚比煞呢？也可以为他求国吧！他是我的哥哥，他有祭司亚比亚他和洗鲁雅的儿子约押为辅佐。”</span>
<span className="v" id="v23" data-v="23" data-xref="路得记 1:17; 诗篇 140:9; 诗篇 64:8"> 所罗门王就指着耶和华起誓说：“亚多尼雅这话是自己送命，不然，愿神重重地降罚于我！</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 22:10; 历代志上 17:10; 历代志上 17:17"> 耶和华坚立我，使我坐在父亲大卫的位上，照着所应许的话为我建立家室。现在我指着永生的耶和华起誓：亚多尼雅今日必被治死！”</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 8:18; 列王纪上 2:46; 士师记 8:20–21"> 于是所罗门王差遣耶何耶大的儿子比拿雅，将亚多尼雅杀死。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="约书亚记 21:18; 撒母耳记上 22:20–23; 耶利米书 1:1"> 王对祭司亚比亚他说：“你回亚拿突归自己的田地去吧！你本是该死的，但因你在我父亲大卫面前抬过主耶和华的约柜，又与我父亲同受一切苦难，所以我今日不将你杀死。”</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 2:27–36; 撒母耳记上 3:12–14; 耶利米书 7:12–14"> 所罗门就革除亚比亚他，不许他做耶和华的祭司。这样，便应验耶和华在示罗论以利家所说的话。</span>
</div>
</div>

## 约押见杀

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王纪上 1:50; 列王纪上 1:7; 撒母耳记下 18:2"> 约押虽然没有归从押沙龙，却归从了亚多尼雅。他听见这风声，就逃到耶和华的帐幕，抓住祭坛的角。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪上 2:25; 出埃及记 21:14; 列王纪上 2:46"> 有人告诉所罗门王说：“约押逃到耶和华的帐幕，现今在祭坛的旁边。”所罗门就差遣耶何耶大的儿子比拿雅，说：“你去将他杀死。”</span>
<span className="v" id="v30" data-v="30"> 比拿雅来到耶和华的帐幕，对约押说：“王吩咐说，你出来吧！”他说：“我不出去，我要死在这里！”比拿雅就去回复王说：“约押如此如此回答我。”</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 21:8–9; 民数记 35:33; 出埃及记 21:14"> 王说：“你可以照着他的话行，杀死他，将他葬埋，好叫约押流无辜人血的罪不归我和我的父家了。</span>
<span className="v" id="v32" data-v="32" data-xref="士师记 9:24; 士师记 9:57; 诗篇 7:16"> 耶和华必使约押流人血的罪归到他自己的头上，因为他用刀杀了两个比他又义又好的人，就是以色列元帅尼珥的儿子押尼珥和犹大元帅益帖的儿子亚玛撒，我父亲大卫却不知道。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 27:25; 列王纪上 2:32; 路加福音 2:14"> 故此，流这二人血的罪必归到约押和他后裔的头上，直到永远。唯有大卫和他的后裔，并他的家与国，必从耶和华那里得平安，直到永远。”</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 3:1; 约书亚记 15:61; 列王纪上 2:25"> 于是耶何耶大的儿子比拿雅上去，将约押杀死，葬在旷野约押自己的坟墓<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“坟墓”原文作“房屋”。">a</a></sup>里。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 2:27; 历代志上 24:3; 历代志上 29:22"> 王就立耶何耶大的儿子比拿雅做元帅，代替约押，又使祭司撒督代替亚比亚他。</span>
</div>
</div>

## 戒示每勿出耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="撒母耳记下 16:5–9; 列王纪上 2:8–9; 箴言 20:26"> 王差遣人将示每召来，对他说：“你要在耶路撒冷建造房屋居住，不可出来往别处去。</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳记下 1:16; 撒母耳记下 15:23; 约书亚记 2:19"> 你当确实地知道：你何日出来过汲沦溪，何日必死，你的罪<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：血。">b</a></sup>必归到自己的头上。”</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪上 20:4; 列王纪下 20:19"> 示每对王说：“这话甚好。我主我王怎样说，仆人必怎样行。”于是示每多日住在耶路撒冷。</span>
</div>
</div>

## 示每见杀

<div className="bt">
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="撒母耳记上 21:10; 撒母耳记上 27:2–3"> 过了三年，示每的两个仆人逃到迦特王玛迦的儿子亚吉那里去。有人告诉示每说：“你的仆人在迦特。”</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 12:15; 箴言 15:27; 提摩太前书 6:10"> 示每起来，备上驴，往迦特到亚吉那里去找他的仆人，就从迦特带他仆人回来。</span>
<span className="v" id="v41" data-v="41"> 有人告诉所罗门说：“示每出耶路撒冷往迦特去，回来了。”</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 15:4; 列王纪上 2:36–38; 路加福音 15:22"> 王就差遣人将示每召了来，对他说：“我岂不是叫你指着耶和华起誓，并且警戒你说‘你当确实地知道，你哪日出来往别处去，哪日必死’吗？你也对我说‘这话甚好，我必听从’。</span>
<span className="v" id="v43" data-v="43" data-xref="罗马书 13:5; 历代志下 30:12; 传道书 8:2"> 现在你为何不遵守你指着耶和华起的誓和我所吩咐你的命令呢？”</span>
<span className="v" id="v44" data-v="44" data-xref="撒母耳记下 16:5–13; 诗篇 7:16; 以西结书 17:19"> 王又对示每说：“你向我父亲大卫所行的一切恶事，你自己心里也知道，所以耶和华必使你的罪恶归到自己的头上。</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 25:5; 列王纪上 2:24; 以赛亚书 9:6–7"> 唯有所罗门王必得福，并且大卫的国位必在耶和华面前坚定，直到永远。”</span>
<span className="v" id="v46" data-v="46" data-xref="历代志下 1:1; 列王纪上 2:12; 列王纪上 2:45"> 于是王吩咐耶何耶大的儿子比拿雅，他就去杀死示每。这样，便坚定了所罗门的国位。</span>
</div>
</div>

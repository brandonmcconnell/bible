## 建黎巴嫩林宫

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 9:10; 历代志下 8:1; 传道书 2:4–5"> 所罗门为自己建造宫室，十三年方才造成。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 10:17; 历代志下 9:16; 列王纪上 10:21"> 又建造黎巴嫩林宫，长一百肘，宽五十肘，高三十肘。有香柏木柱三<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：四。">a</a></sup>行，柱上有香柏木柁梁，</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 6:5"> 其上以香柏木为盖，每行柱子十五根，共有四十五根。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 40:22; 以西结书 40:16; 列王纪上 6:4"> 有窗户三层，窗与窗相对。</span>
<span className="v" id="v5" data-v="5"> 所有的门框都是厚木见方的，有窗户三层，窗与窗相对。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 7:12; 以西结书 41:25–26"> 并建造有柱子的廊子，长五十肘，宽三十肘。在这廊前又有廊子，廊外有柱子和台阶。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 20:8; 诗篇 122:5; 以赛亚书 9:7"> 又建造一廊，其中设立审判的座位，这廊从地到顶都用香柏木遮蔽。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 8:11; 列王纪上 3:1; 列王纪上 9:24"> 廊后院内有所罗门住的宫室，工作与这工作相同。所罗门又为所娶法老的女儿建造一宫，做法与这廊子一样。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王纪上 7:10–11; 列王纪上 5:17"> 建造这一切所用的石头都是宝贵的，是按着尺寸凿成的，是用锯里外锯齐的。从根基直到檐石，从外头直到大院，都是如此。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 21:19–20; 哥林多前书 3:10–11; 以赛亚书 54:11"> 根基是宝贵的大石头，有长十肘的，有长八肘的，</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 2:20–22; 彼得前书 2:5"> 上面有香柏木和按着尺寸凿成宝贵的石头。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 6:36; 列王纪上 7:6; 约翰福音 10:23"> 大院周围有凿成的石头三层，香柏木一层，都照耶和华殿的内院和殿廊的样式。</span>
</div>
</div>

## 户兰之巧技

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志下 4:11; 历代志下 2:13–14; 列王纪上 7:40"> 所罗门王差遣人往推罗去，将户兰召了来。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 2:14; 历代志下 4:16; 出埃及记 31:2–6"> 他是拿弗他利支派中一个寡妇的儿子，他父亲是推罗人，做铜匠的。户兰满有智慧、聪明、技能，善于各样铜作。他来到所罗门王那里，做王一切所要做的。</span>
</div>
</div>

## 制铜柱

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米书 52:21; 历代志下 3:15–17; 列王纪上 7:21"> 他制造两根铜柱，每根高十八肘，围十二肘。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 38:19; 历代志下 4:12–13; 出埃及记 38:17"> 又用铜铸了两个柱顶安在柱上，各高五肘。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 28:14; 出埃及记 28:24–25; 出埃及记 28:22"> 柱顶上有装修的网子和拧成的链索，每顶七个。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 28:14; 出埃及记 39:15–18; 出埃及记 28:22"> 网子周围有两行石榴遮盖柱顶，两个柱顶都是如此。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 7:22; 列王纪上 6:32–35; 列王纪上 6:18"> 廊子的柱顶径四肘，刻着百合花。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 3:16; 历代志下 4:13; 耶利米书 52:22–23"> 两柱顶的鼓肚上挨着网子，各有两行石榴环绕，两行共有二百。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志下 3:17; 列王纪上 6:3; 列王纪上 7:12"> 他将两根柱子立在殿廊前头，右边立一根，起名叫雅斤，左边立一根，起名叫波阿斯。</span>
<span className="v" id="v22" data-v="22"> 在柱顶上刻着百合花。这样，造柱子的工就完毕了。</span>
</div>
</div>

## 铸铜海

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="历代志下 4:2; 列王纪下 25:13; 耶利米书 52:17"> 他又铸一个铜海，样式是圆的，高五肘，径十肘，围三十肘。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 6:18; 历代志下 4:3; 出埃及记 37:17–22"> 在海边之下，周围有野瓜的样式，每肘十瓜，共有两行，是铸海的时候铸上的。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 52:20; 历代志下 4:4–5; 马太福音 28:19"> 有十二只铜牛驮海，三只向北，三只向西，三只向南，三只向东。海在牛上，牛尾都向内。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志下 4:5; 列王纪上 7:38; 列王纪上 6:18"> 海厚一掌，边如杯边，又如百合花，可容二千罢特。</span>
</div>
</div>

## 制铜座

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="历代志下 4:14; 列王纪下 25:13; 耶利米书 52:17"> 他用铜制造十个盆座，每座长四肘，宽四肘，高三肘。</span>
<span className="v" id="v28" data-v="28"> 座的造法是这样：四面都有心子，心子在边子当中。</span>
<span className="v" id="v29" data-v="29" data-xref="何西阿书 5:14; 以西结书 10:14; 出埃及记 37:7"> 心子上有狮子和牛并基路伯。边上有小座，狮子和牛以下有垂下的璎珞。</span>
<span className="v" id="v30" data-v="30" data-xref="以西结书 10:10–13; 以西结书 3:13; 以西结书 1:15–21"> 每盆座有四个铜轮和铜轴。小座的四角上在盆以下，有铸成的盆架，其旁都有璎珞。</span>
<span className="v" id="v31" data-v="31"> 小座高一肘，口是圆的，仿佛座的样式，径一肘半，在口上有雕工，心子是方的，不是圆的。</span>
<span className="v" id="v32" data-v="32"> 四个轮子在心子以下，轮轴与座相连，每轮高一肘半。</span>
<span className="v" id="v33" data-v="33" data-xref="以西结书 1:18; 以西结书 1:16"> 轮的样式如同车轮，轴、辋、辐、毂都是铸的。</span>
<span className="v" id="v34" data-v="34"> 每座四角上都有盆架，是与座一同铸成的。</span>
<span className="v" id="v35" data-v="35"> 座上有圆架，高半肘。座上有撑子和心子，是与座一同铸的。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 7:29; 列王纪上 6:29; 以西结书 41:18–20"> 在撑子和心子上刻着基路伯、狮子和棕树，周围有璎珞。</span>
<span className="v" id="v37" data-v="37"> 十个盆座都是这样，铸法、尺寸、样式相同。</span>
</div>
</div>

## 制铜盆

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="出埃及记 40:11–12; 撒迦利亚书 13:1; 约翰一书 1:7"> 又用铜制造十个盆，每盆可容四十罢特，盆径四肘。在那十座上，每座安设一盆。</span>
<span className="v" id="v39" data-v="39" data-xref="历代志下 4:10; 历代志下 4:6"> 五个安在殿门的右边，五个放在殿门的左边。又将海放在殿门的右旁，就是南边。</span>
<span className="v" id="v40" data-v="40" data-xref="历代志下 4:11–16; 出埃及记 24:6; 出埃及记 39:32–43"> 户兰又造了盆、铲子和盘子。这样，他为所罗门王做完了耶和华殿的一切工。</span>
<span className="v" id="v41" data-v="41" data-xref="列王纪上 7:15–22; 历代志下 4:12"> 所造的就是两根柱子和柱上两个如球的顶，并两个盖柱顶的网子，</span>
<span className="v" id="v42" data-v="42" data-xref="列王纪上 7:20"> 和四百石榴，安在两个网子上，每网两行，盖着两个柱上如球的顶。</span>
<span className="v" id="v43" data-v="43"> 十个座和其上的十个盆，</span>
<span className="v" id="v44" data-v="44" data-xref="列王纪上 7:23; 列王纪上 7:25"> 海和海下的十二只牛，</span>
<span className="v" id="v45" data-v="45" data-xref="出埃及记 27:3; 出埃及记 38:3; 历代志下 4:16"> 盆、铲子、盘子。这一切都是户兰给所罗门王用光亮的铜为耶和华的殿造成的，</span>
<span className="v" id="v46" data-v="46" data-xref="约书亚记 3:16; 历代志下 4:17; 创世记 33:17"> 是遵王命在约旦平原，疏割和撒拉但中间藉胶泥铸成的。</span>
<span className="v" id="v47" data-v="47" data-xref="历代志上 22:14; 历代志上 22:3; 历代志下 4:18"> 这一切所罗门都没有过秤，因为甚多，铜的轻重也无法可查。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="出埃及记 37:10–16; 历代志下 4:8; 出埃及记 39:36"> 所罗门又造耶和华殿里的金坛和陈设饼的金桌子；</span>
<span className="v" id="v49" data-v="49" data-xref="历代志下 4:7; 历代志下 4:20; 撒迦利亚书 4:11–14"> 内殿前的精金灯台，右边五个，左边五个；并其上的金花、灯盏、蜡剪；</span>
<span className="v" id="v50" data-v="50" data-xref="出埃及记 25:29; 历代志下 4:21–22; 出埃及记 27:3"> 与精金的杯、盘、镊子、调羹、火鼎；以及至圣所，内殿的门枢和外殿的门枢。</span>
</div>
</div>

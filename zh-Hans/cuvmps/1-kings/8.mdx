## 运约柜入殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 5:2–10; 历代志上 15:25; 撒母耳记下 6:12–17"> 那时，所罗门将以色列的长老和各支派的首领并以色列的族长，招聚到耶路撒冷，要把耶和华的约柜从大卫城就是锡安运上来。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 23:34; 历代志下 7:8–10; 撒迦利亚书 14:16–19"> 以他念月，就是七月，在节前，以色列人都聚集到所罗门王那里。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 31:9; 约书亚记 3:6; 民数记 4:15"> 以色列长老来到，祭司便抬起约柜，</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 3:4; 历代志下 1:3; 出埃及记 40:2–33"> 祭司和利未人将耶和华的约柜运上来，又将会幕和会幕的一切圣器具都带上来。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 6:13; 历代志上 16:1; 列王纪上 8:62–63"> 所罗门王和聚集到他那里的以色列全会众，一同在约柜前献牛羊为祭，多得不可胜数。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 6:19; 撒母耳记下 6:17; 列王纪上 6:27"> 祭司将耶和华的约柜抬进内殿，就是至圣所，放在两个基路伯的翅膀底下。</span>
<span className="v" id="v7" data-v="7"> 基路伯张着翅膀在约柜之上，遮掩约柜和抬柜的杠。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 25:13–15; 出埃及记 37:4–5; 约书亚记 4:9"> 这杠甚长，杠头在内殿前的圣所可以看见，在殿外却不能看见，直到如今还在那里。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 25:21; 希伯来书 9:4; 出埃及记 40:20"> 约柜里唯有两块石版，就是以色列人出埃及地后，耶和华与他们立约的时候，摩西在何烈山所放的，除此以外，并无别物。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 40:34–35; 历代志下 7:1–2"> 祭司从圣所出来的时候，有云充满耶和华的殿，</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 43:4–5; 以西结书 44:4; 哥林多后书 3:18"> 甚至祭司不能站立供职，因为耶和华的荣光充满了殿。</span>
</div>
</div>

## 所罗门宣述建殿之来由

<div className="bt">
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="诗篇 97:2; 历代志下 6:1–11; 利未记 16:2"> 那时所罗门说：<br /><span className="pl pl-1">“耶和华曾说</span><br /><span className="pl pl-1">他必住在幽暗之处。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 7:13; 诗篇 132:13–14; 希伯来书 9:24"> <span className="pl pl-1">我已经建造殿宇做你的居所，</span><br /><span className="pl pl-1">为你永远的住处。”</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 6:18; 列王纪上 8:55–56; 历代志下 30:18–20"> 王转脸为以色列会众祝福，以色列会众就都站立。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 1:68; 历代志上 29:20; 历代志上 29:10"> 所罗门说：“耶和华以色列的神是应当称颂的！因他亲口向我父大卫所应许的，也亲手成就了。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 16:1; 列王纪上 8:29; 撒母耳记下 7:4–8"> 他说：‘自从我领我民以色列出埃及以来，我未曾在以色列各支派中选择一城建造殿宇为我名的居所，但拣选大卫治理我民以色列。’”</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 7:2–3; 历代志上 22:7; 历代志上 28:2"> 所罗门说：“我父大卫曾立意要为耶和华以色列神的名建殿，</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 6:7–9; 哥林多后书 8:12"> 耶和华却对我父大卫说：‘你立意为我的名建殿，这意思甚好，</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 7:5; 历代志上 22:8–10; 历代志上 28:6"> 只是你不可建殿，唯你所生的儿子，必为我名建殿。’</span>
<span className="v" id="v20" data-v="20" data-xref="历代志上 28:5–6; 腓立比书 1:6; 列王纪上 8:15"> 现在耶和华成就了他所应许的话，使我接续我父大卫坐以色列的国位，又为耶和华以色列神的名建造了殿。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 8:9; 申命记 31:26; 列王纪上 8:5–6"> 我也在其中为约柜预备一处，约柜内有耶和华的约，就是他领我们列祖出埃及地的时候，与他们所立的约。”</span>
</div>
</div>

## 大申祈祷

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以斯拉记 9:5; 列王纪上 8:54; 出埃及记 9:33"> 所罗门当着以色列会众，站在耶和华的坛前，向天举手说：</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 7:22; 申命记 7:9; 但以理书 9:4"> “耶和华以色列的神啊，天上地下，没有神可比你的。你向那尽心行在你面前的仆人守约施慈爱，</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 7:16; 列王纪上 8:15; 撒母耳记下 7:12"> 向你仆人我父大卫所应许的话现在应验了。你亲口应许，亲手成就，正如今日一样。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 2:4; 列王纪上 9:4–6; 耶利米书 33:17–26"> 耶和华以色列的神啊，你所应许你仆人我父大卫的话说‘你的子孙若谨慎自己的行为，在我面前行事像你所行的一样，就不断人坐以色列的国位’，现在求你应验这话。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 7:25–29; 以赛亚书 41:17; 撒母耳记上 1:17"> 以色列的神啊，求你成就向你仆人我父大卫所应许的话！</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="历代志下 2:6; 以赛亚书 66:1; 耶利米书 23:24"> “神果真住在地上吗？看哪，天和天上的天尚且不足你居住的，何况我所建的这殿呢！</span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 88:1–2; 诗篇 5:1; 路加福音 18:1"> 唯求耶和华我的神垂顾仆人的祷告、祈求，俯听仆人今日在你面前的祈祷、呼吁。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志下 6:20; 列王纪上 8:16; 历代志下 7:15–16"> 愿你昼夜看顾这殿，就是你应许立为你名的居所；求你垂听仆人向此处祷告的话。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 8:39; 列王纪上 8:34; 列王纪上 8:36"> 你仆人和你民以色列向此处祈祷的时候，求你在天上你的居所垂听，垂听而赦免。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及记 22:8–11; 历代志下 6:22–23; 利未记 5:1"> “人若得罪邻舍，有人叫他起誓，他来到这殿，在你的坛前起誓，</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 25:1; 以赛亚书 3:10–11; 罗马书 2:6–10"> 求你在天上垂听，判断你的仆人：定恶人有罪，照他所行的报应在他头上；定义人有理，照他的义赏赐他。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="利未记 26:17; 申命记 28:25; 约拿书 3:10"> “你的民以色列若得罪你，败在仇敌面前，又归向你，承认你的名，在这殿里祈求、祷告，</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米书 31:4–9; 但以理书 9:12; 创世记 13:15"> 求你在天上垂听，赦免你民以色列的罪，使他们归回你赐给他们列祖之地。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="利未记 26:19; 申命记 11:17; 列王纪上 8:33"> “你的民因得罪你，你惩罚他们，使天闭塞不下雨，他们若向此处祷告，承认你的名，离开他们的罪，</span>
<span className="v" id="v36" data-v="36" data-xref="诗篇 27:11; 撒母耳记上 12:23; 耶利米书 6:16"> 求你在天上垂听，赦免你仆人以色列民的罪，将当行的善道指教他们，且降雨在你的地，就是你赐给你民为业之地。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="申命记 28:21–22; 利未记 26:16; 历代志下 20:9"> “国中若有饥荒、瘟疫、旱风、霉烂、蝗虫、蚂蚱，或有仇敌犯境围困城邑，无论遭遇什么灾祸疾病，</span>
<span className="v" id="v38" data-v="38" data-xref="诗篇 73:21–22; 列王纪上 8:22; 腓立比书 4:6"> 你的民以色列，或是众人，或是一人，自觉有罪<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：灾。">a</a></sup>，向这殿举手，无论祈求什么，祷告什么，</span>
<span className="v" id="v39" data-v="39" data-xref="历代志上 28:9; 耶利米书 17:10; 使徒行传 1:24"> 求你在天上你的居所垂听赦免。你是知道人心的，要照各人所行的待他们——唯有你知道世人的心——</span>
<span className="v" id="v40" data-v="40" data-xref="诗篇 130:4; 启示录 19:5; 申命记 6:2"> 使他们在你赐给我们列祖之地上一生一世敬畏你。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="列王纪上 10:1–2; 使徒行传 8:27–40; 出埃及记 18:8–12"> “论到不属你民以色列的外邦人，为你名从远方而来——</span>
<span className="v" id="v42" data-v="42" data-xref="申命记 3:24; 列王纪下 17:36; 出埃及记 3:13–16"> 他们听人论说你的大名和大能的手并伸出来的膀臂——向这殿祷告，</span>
<span className="v" id="v43" data-v="43" data-xref="诗篇 102:15; 撒母耳记上 17:46; 诗篇 22:27"> 求你在天上你的居所垂听，照着外邦人所祈求的而行，使天下万民都认识你的名，敬畏你，像你的民以色列一样，又使他们知道我建造的这殿是称为你名下的。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="历代志下 6:34; 诗篇 78:67–69; 列王纪上 8:16"> “你的民若奉你的差遣，无论往何处去与仇敌争战，向耶和华所选择的城与我为你名所建造的殿祷告，</span>
<span className="v" id="v45" data-v="45" data-xref="创世记 18:25; 诗篇 9:4; 耶利米书 5:28"> 求你在天上垂听他们的祷告、祈求，使他们得胜。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="传道书 7:20; 箴言 20:9; 约翰一书 1:8–10"> “你的民若得罪你——世上没有不犯罪的人——你向他们发怒，将他们交给仇敌掳到仇敌之地，或远或近，</span>
<span className="v" id="v47" data-v="47" data-xref="诗篇 106:6; 尼希米记 1:6–11; 尼希米记 9:26–30"> 他们若在掳到之地想起罪来，回心转意，恳求你说‘我们有罪了，我们悖逆了，我们作恶了’，</span>
<span className="v" id="v48" data-v="48" data-xref="但以理书 6:10; 耶利米书 29:12–14; 申命记 4:29"> 他们若在掳到之地尽心、尽性归服你，又向自己的地，就是你赐给他们列祖之地，和你所选择的城，并我为你名所建造的殿祷告，</span>
<span className="v" id="v49" data-v="49" data-xref="列王纪下 19:19; 列王纪上 8:45; 撒迦利亚书 1:15–16"> 求你在天上你的居所垂听他们的祷告、祈求，为他们申冤，</span>
<span className="v" id="v50" data-v="50" data-xref="诗篇 106:46; 历代志下 30:9; 使徒行传 7:10"> 饶恕得罪你的民，赦免他们的一切过犯，使他们在掳他们的人面前蒙怜恤，</span>
<span className="v" id="v51" data-v="51" data-xref="尼希米记 1:10; 耶利米书 11:4; 申命记 4:20"> 因为他们是你的子民，你的产业，是你从埃及领出来脱离铁炉的。</span>
<span className="v" id="v52" data-v="52" data-xref="诗篇 145:18; 列王纪上 8:29; 诗篇 86:5"> 愿你的眼目看顾仆人，听你民以色列的祈求，无论何时向你祈求，愿你垂听。</span>
<span className="v" id="v53" data-v="53" data-xref="出埃及记 19:5–6; 申命记 14:2; 申命记 32:9"> 主耶和华啊，你将他们从地上的万民中分别出来做你的产业，是照你领我们列祖出埃及的时候，藉你仆人摩西所应许的话。”</span>
</div>

## 为民祝福

<div className="bt">
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="历代志下 7:1; 历代志下 6:12–13; 路加福音 22:45"> 所罗门在耶和华的坛前屈膝跪着，向天举手，在耶和华面前祷告祈求已毕，就起来，</span>
<span className="v" id="v55" data-v="55" data-xref="列王纪上 8:14; 撒母耳记下 6:18; 民数记 6:23–26"> 站着，大声为以色列全会众祝福，说：</span>
<span className="v" id="v56" data-v="56" data-xref="约书亚记 23:14–15; 约书亚记 21:44–45; 路加福音 21:33"> “耶和华是应当称颂的！因为他照着一切所应许的赐平安给他的民以色列人，凡藉他仆人摩西应许赐福的话，一句都没有落空。</span>
<span className="v" id="v57" data-v="57" data-xref="约书亚记 1:5; 申命记 31:6; 申命记 31:8"> 愿耶和华我们的神与我们同在，像与我们列祖同在一样，不撇下我们，不丢弃我们，</span>
<span className="v" id="v58" data-v="58" data-xref="诗篇 119:36; 以西结书 36:26–27; 耶利米书 31:33"> 使我们的心归向他，遵行他的道，谨守他吩咐我们列祖的诫命、律例、典章。</span>
<span className="v" id="v59" data-v="59" data-xref="诗篇 141:2; 约翰福音 17:9; 约翰福音 17:20–24"> 我在耶和华面前祈求的这些话，愿耶和华我们的神昼夜垂念，每日为他仆人与他民以色列申冤，</span>
<span className="v" id="v60" data-v="60" data-xref="申命记 4:35; 耶利米书 10:10–12; 列王纪上 18:39"> 使地上的万民都知道唯独耶和华是神，并无别神。</span>
<span className="v" id="v61" data-v="61" data-xref="列王纪上 11:4; 列王纪下 20:3; 哥林多后书 7:1"> 所以你们当向耶和华我们的神存诚实的心，遵行他的律例，谨守他的诫命，至终如今日一样。”</span>
</div>
</div>

## 献祭

<div className="bt">
<div className="bp">
<span className="v" id="v62" data-v="62" data-xref="撒母耳记下 6:17–19; 以斯拉记 6:16–17; 历代志下 7:4–10"> 王和以色列众民一同在耶和华面前献祭。</span>
<span className="v" id="v63" data-v="63" data-xref="以斯拉记 6:16–17; 历代志下 15:11; 尼希米记 12:27"> 所罗门向耶和华献平安祭，用牛二万二千，羊十二万。这样，王和以色列众民为耶和华的殿行奉献之礼。</span>
<span className="v" id="v64" data-v="64" data-xref="历代志下 4:1; 历代志下 7:7"> 当日，王因耶和华殿前的铜坛太小，容不下燔祭、素祭和平安祭牲的脂油，便将耶和华殿前院子当中分别为圣，在那里献燔祭、素祭和平安祭牲的脂油。</span>
<span className="v" id="v65" data-v="65" data-xref="民数记 34:5; 民数记 34:8; 列王纪上 8:2"> 那时所罗门和以色列众人，就是从哈马口直到埃及小河所有的以色列人，都聚集成为大会，在耶和华我们的神面前守节七日又七日，共十四日。</span>
<span className="v" id="v66" data-v="66" data-xref="腓立比书 4:4; 使徒行传 2:46; 撒迦利亚书 9:17"> 第八日，王遣散众民，他们都为王祝福。因见耶和华向他仆人大卫和他民以色列所施的一切恩惠，就都心中喜乐，各归各家去了。</span>
</div>

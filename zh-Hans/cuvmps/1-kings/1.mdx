## 大卫王年迈之景况

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 23:1–2; 历代志上 29:27–28; 历代志上 23:1"> 大卫王年纪老迈，虽用被遮盖，仍不觉暖。</span>
<span className="v" id="v2" data-v="2" data-xref="传道书 4:11; 创世记 16:5; 弥迦书 7:5"> 所以臣仆对他说：“不如为我主我王寻找一个处女，使她伺候王，奉养王，睡在王的怀中，好叫我主我王得暖。”</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 19:18; 以斯帖记 2:4; 以斯帖记 2:2"> 于是在以色列全境寻找美貌的童女，寻得书念的一个童女亚比煞，就带到王那里。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 1:25"> 这童女极其美貌，她奉养王，伺候王，王却没有与她亲近。</span>
</div>
</div>

## 亚多尼雅谋窃王位

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 15:1; 撒母耳记下 3:4; 申命记 17:15–16"> 那时，哈及的儿子亚多尼雅自尊，说：“我必做王。”就为自己预备车辆、马兵，又派五十人在他前头奔走。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 3:3–4; 撒母耳记上 3:13; 希伯来书 12:5–6"> 他父亲素来没有使他忧闷，说：“你是做什么呢？”他甚俊美，生在押沙龙之后。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 20:25; 列王纪上 2:22; 撒母耳记上 22:20–23"> 亚多尼雅与洗鲁雅的儿子约押和祭司亚比亚他商议，二人就顺从他，帮助他。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 4:18; 撒母耳记下 23:8–39; 撒母耳记下 20:25"> 但祭司撒督、耶何耶大的儿子比拿雅、先知拿单、示每、利以并大卫的勇士都不顺从亚多尼雅。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 17:17; 撒母耳记下 13:23–27; 撒母耳记下 15:11–12"> 一日，亚多尼雅在隐罗结旁琐希列磐石那里宰了牛羊、肥犊，请他的诸弟兄，就是王的众子，并所有做王臣仆的犹大人；</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 12:24; 列王纪上 1:19; 撒母耳记下 12:1–15"> 唯独先知拿单和比拿雅并勇士，与他的兄弟所罗门，他都没有请。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 3:4; 撒母耳记下 7:12–17; 撒母耳记下 12:24–25"> 拿单对所罗门的母亲拔示巴说：“哈及的儿子亚多尼雅做王了，你没有听见吗？我们的主大卫却不知道。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 11:14; 使徒行传 27:31; 创世记 19:17"> 现在我可以给你出个主意，好保全你和你儿子所罗门的性命。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 1:30; 列王纪上 1:17; 诗篇 132:11–12"> 你进去见大卫王，对他说：‘我主我王啊，你不曾向婢女起誓说“你儿子所罗门必接续我做王，坐在我的位上”吗？现在亚多尼雅怎么做了王呢？’</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 13:1; 列王纪上 1:17–27"> 你还与王说话的时候，我也随后进去，证实你的话。”</span>
</div>
</div>

## 拨示巴觐王陈诉

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王纪上 1:1"> 拔示巴进入内室见王，王甚老迈，书念的童女亚比煞正伺候王。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 25:23; 撒母耳记上 24:8; 撒母耳记上 20:41"> 拔示巴向王屈身下拜。王说：“你要什么？”</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 1:13; 列王纪上 1:30; 彼得前书 3:6"> 她说：“我主啊，你曾向婢女指着耶和华你的神起誓说：‘你儿子所罗门必接续我做王，坐在我的位上。’</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 1:24; 列王纪上 1:11; 使徒行传 3:17"> 现在亚多尼雅做王了，我主我王却不知道。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 1:25; 列王纪上 1:7–10"> 他宰了许多牛羊、肥犊，请了王的众子和祭司亚比亚他并元帅约押，唯独王的仆人所罗门他没有请。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志上 29:1; 诗篇 123:2; 历代志上 22:8–10"> 我主我王啊，以色列众人的眼目都仰望你，等你晓谕他们，在我主我王之后谁坐你的位。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 2:10; 申命记 31:16; 创世记 15:15"> 若不然，到我主我王与列祖同睡以后，我和我儿子所罗门必算为罪人了。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约伯记 1:16–18; 创世记 24:15; 但以理书 9:20"> 拔示巴还与王说话的时候，先知拿单也进来了。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 1:16; 彼得前书 2:17; 罗马书 13:7"> 有人奏告王说：“先知拿单来了。”拿单进到王前，脸伏于地。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 1:17–18; 列王纪上 1:5; 列王纪上 1:13–14"> 拿单说：“我主我王果然应许亚多尼雅说‘你必接续我做王，坐在我的位上’吗？</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 10:24; 列王纪上 1:19; 列王纪上 1:9"> 他今日下去，宰了许多牛羊、肥犊，请了王的众子和军长并祭司亚比亚他。他们正在亚多尼雅面前吃喝，说：‘愿亚多尼雅王万岁！’</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 1:8; 列王纪上 1:10; 撒母耳记下 7:2"> 唯独我，就是你的仆人，和祭司撒督、耶何耶大的儿子比拿雅，并王的仆人所罗门，他都没有请。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 15:15; 列王纪上 1:24; 列王纪下 4:27"> 这事果然出乎我主我王吗？王却没有告诉仆人们，在我主我王之后谁坐你的位。”</span>
</div>
</div>

## 大卫誓许所罗门为王

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28"> 大卫王吩咐说：“叫拔示巴来。”拔示巴就进来，站在王面前。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 4:9; 诗篇 136:24; 撒母耳记上 14:45"> 王起誓说：“我指着救我性命脱离一切苦难，永生的耶和华起誓：</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 1:13; 列王纪上 1:17"> 我既然指着耶和华以色列的神向你起誓说‘你儿子所罗门必接续我做王，坐在我的位上’，我今日就必照这话而行。”</span>
<span className="v" id="v31" data-v="31" data-xref="但以理书 2:4; 但以理书 5:10; 但以理书 3:9"> 于是，拔示巴脸伏于地，向王下拜，说：“愿我主大卫王万岁！”</span>
</div>
</div>

## 所罗门在基训受膏

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="列王纪上 1:8; 列王纪上 1:38; 列王纪上 1:26"> 大卫王又吩咐说：“将祭司撒督、先知拿单、耶何耶大的儿子比拿雅召来。”他们就都来到王面前。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志下 32:30; 列王纪上 1:38; 历代志下 33:14"> 王对他们说：“要带领你们主的仆人，使我儿子所罗门骑我的骡子，送他下到基训。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 1:25; 撒母耳记下 15:10; 撒母耳记上 10:1"> 在那里，祭司撒督和先知拿单要膏他做以色列的王。你们也要吹角，说：‘愿所罗门王万岁！’</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 1:17; 诗篇 72:1–2; 列王纪上 1:13"> 然后要跟随他上来，使他坐在我的位上，接续我做王。我已立他做以色列和犹大的君。”</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 28:6; 哥林多前书 14:16; 诗篇 72:19"> 耶何耶大的儿子比拿雅对王说：“阿们！愿耶和华我主我王的神也这样命定。</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳记上 20:13; 列王纪上 1:47; 约书亚记 1:17"> 耶和华怎样与我主我王同在，愿他照样与所罗门同在，使他的国位比我主大卫王的国位更大。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="撒母耳记下 8:18; 列王纪上 1:8; 列王纪上 1:33"> 于是，祭司撒督、先知拿单、耶何耶大的儿子比拿雅和基利提人、比利提人都下去，使所罗门骑大卫王的骡子，将他送到基训。</span>
<span className="v" id="v39" data-v="39" data-xref="诗篇 89:20; 列王纪上 1:34; 历代志上 29:22"> 祭司撒督就从帐幕中取了盛膏油的角来，用膏膏所罗门。人就吹角，众民都说：“愿所罗门王万岁！”</span>
<span className="v" id="v40" data-v="40" data-xref="列王纪下 11:14; 撒迦利亚书 9:9; 列王纪下 11:20"> 众民跟随他上来，且吹笛，大大欢呼，声音震地。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="约伯记 15:21–22; 路加福音 17:26–29; 使徒行传 21:31"> 亚多尼雅和所请的众客筵宴方毕，听见这声音。约押听见角声就说：“城中为何有这响声呢？”</span>
<span className="v" id="v42" data-v="42" data-xref="撒母耳记下 15:36; 撒母耳记下 17:17; 撒母耳记下 18:27"> 他正说话的时候，祭司亚比亚他的儿子约拿单来了。亚多尼雅对他说：“进来吧！你是个忠义的人，必是报好信息。”</span>
<span className="v" id="v43" data-v="43"> 约拿单对亚多尼雅说：“我们的主大卫王诚然立所罗门为王了！</span>
<span className="v" id="v44" data-v="44"> 王差遣祭司撒督、先知拿单、耶何耶大的儿子比拿雅和基利提人、比利提人都去，使所罗门骑王的骡子。</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪上 1:40; 但以理书 5:26–28; 撒母耳记上 4:5"> 祭司撒督和先知拿单在基训已经膏他做王。众人都从那里欢呼着上来，声音使城震动，这就是你们所听见的声音。</span>
<span className="v" id="v46" data-v="46" data-xref="历代志上 29:23; 诗篇 132:11; 列王纪上 1:13"> 并且，所罗门登了国位。</span>
<span className="v" id="v47" data-v="47" data-xref="创世记 47:31; 列王纪上 1:37; 以斯拉记 6:10"> 王的臣仆也来为我们的主大卫王祝福，说：‘愿王的神使所罗门的名比王的名更尊荣，使他的国位比王的国位更大。’王就在床上屈身下拜。</span>
<span className="v" id="v48" data-v="48" data-xref="列王纪上 3:6; 诗篇 132:11–12; 诗篇 145:2"> 王又说：‘耶和华以色列的神是应当称颂的！因他赐我一人今日坐在我的位上，我也亲眼看见了。’”</span>
</div>
</div>

## 亚多尼雅闻信惊惧

<div className="bt">
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="以赛亚书 21:4–5; 箴言 28:1; 但以理书 5:4–6"> 亚多尼雅的众客听见这话就都惊惧，起来四散。</span>
<span className="v" id="v50" data-v="50" data-xref="列王纪上 2:28; 出埃及记 21:14; 出埃及记 27:2"> 亚多尼雅惧怕所罗门，就起来，去抓住祭坛的角。</span>
<span className="v" id="v51" data-v="51"> 有人告诉所罗门说：“亚多尼雅惧怕所罗门王，现在抓住祭坛的角，说：‘愿所罗门王今日向我起誓，必不用刀杀仆人。’”</span>
<span className="v" id="v52" data-v="52" data-xref="撒母耳记上 14:45; 撒母耳记下 14:11; 箴言 13:6"> 所罗门说：“他若做忠义的人，连一根头发也不至落在地上；他若行恶，必要死亡。”</span>
<span className="v" id="v53" data-v="53" data-xref="列王纪上 1:16; 撒母耳记下 14:24; 撒母耳记下 1:2"> 于是所罗门王差遣人，使亚多尼雅从坛上下来，他就来，向所罗门王下拜。所罗门对他说：“你回家去吧！”</span>
</div>
</div>

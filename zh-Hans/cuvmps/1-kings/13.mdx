## 神仆警告耶罗波安

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 12:32–33; 列王纪下 23:17; 帖撒罗尼迦前书 4:15"> 那时，有一个神人奉耶和华的命从犹大来到伯特利，耶罗波安正站在坛旁要烧香。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 36:1; 列王纪下 23:15–18; 列王纪下 22:1–2"> 神人奉耶和华的命向坛呼叫，说：“坛哪，坛哪！耶和华如此说：‘大卫家里必生一个儿子，名叫约西亚，他必将丘坛的祭司，就是在你上面烧香的，杀在你上面，人的骨头也必烧在你上面。’”</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 1:22; 出埃及记 4:3–5; 士师记 6:17"> 当日，神人设个预兆，说：“这坛必破裂，坛上的灰必倾撒，这是耶和华说的预兆。”</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 11:5; 历代志下 18:25–27; 路加福音 6:10"> 耶罗波安王听见神人向伯特利的坛所呼叫的话，就从坛上伸手，说：“拿住他吧！”王向神人所伸的手就枯干了，不能弯回。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 13:3; 耶利米书 28:16–17; 申命记 18:22"> 坛也破裂了，坛上的灰倾撒了，正如神人奉耶和华的命所设的预兆。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 9:28; 使徒行传 8:24; 出埃及记 10:17"> 王对神人说：“请你为我祷告，求耶和华你神的恩典使我的手复原。”于是神人祈祷耶和华，王的手就复了原，仍如寻常一样。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 5:15; 撒母耳记上 9:7–8; 士师记 13:15"> 王对神人说：“请你同我回去吃饭，加添心力，我也必给你赏赐。”</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 24:13; 民数记 22:18; 马可福音 6:23"> 神人对王说：“你就是把你的宫一半给我，我也不同你进去，也不在这地方吃饭喝水，</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 13:17; 申命记 13:13–18; 罗马书 16:17"> 因为有耶和华的话嘱咐我说：‘不可在伯特利吃饭喝水，也不可从你去的原路回来。’”</span>
<span className="v" id="v10" data-v="10"> 于是神人从别的路回去，不从伯特利来的原路回去。</span>
</div>
</div>

## 神仆受诱违命

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪下 23:18; 列王纪上 13:20–21; 民数记 24:2"> 有一个老先知住在伯特利，他儿子们来，将神人当日在伯特利所行的一切事和向王所说的话都告诉了父亲。</span>
<span className="v" id="v12" data-v="12"> 父亲问他们说：“神人从哪条路去了呢？”儿子们就告诉他。原来他们看见那从犹大来的神人所去的路。</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 10:4; 撒母耳记下 19:26; 士师记 5:10"> 老先知就吩咐他儿子们说：“你们为我备驴。”他们备好了驴，他就骑上，</span>
<span className="v" id="v14" data-v="14" data-xref="腓立比书 4:12–13; 哥林多后书 11:27; 哥林多前书 4:11–12"> 去追赶神人，遇见他坐在橡树底下，就问他说：“你是从犹大来的神人不是？”他说：“是。”</span>
<span className="v" id="v15" data-v="15"> 老先知对他说：“请你同我回家吃饭。”</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 13:8–9; 马太福音 16:23; 民数记 22:19"> 神人说：“我不可同你回去进你的家，也不可在这里同你吃饭喝水，</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 20:35; 帖撒罗尼迦前书 4:15; 列王纪上 13:1"> 因为有耶和华的话嘱咐我说：‘你在那里不可吃饭喝水，也不可从你去的原路回来。’”</span>
<span className="v" id="v18" data-v="18" data-xref="约翰一书 4:1; 马太福音 7:15; 民数记 22:35"> 老先知对他说：“我也是先知，和你一样。有天使奉耶和华的命对我说：‘你去把他带回你的家，叫他吃饭喝水。’”这都是老先知诓哄他。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 13:1; 创世记 3:6; 使徒行传 4:19"> 于是神人同老先知回去，在他家里吃饭喝水。</span>
</div>
</div>

## 见责于耶和华

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马太福音 7:22; 民数记 24:4; 民数记 24:16–24"> 二人坐席的时候，耶和华的话临到那带神人回来的先知，</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 13:17; 撒母耳记上 13:13–14; 撒母耳记上 4:18"> 他就对那从犹大来的神人说：“耶和华如此说：‘你既违背耶和华的话，不遵守耶和华你神的命令，</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 14:18–20; 列王纪上 14:13; 耶利米书 22:18–19"> 反倒回来，在耶和华禁止你吃饭喝水的地方吃了喝了，因此你的尸身不得入你列祖的坟墓。’”</span>
</div>
</div>

## 见噬于狮

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23"> 吃喝完了，老先知为所带回来的先知备驴。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 20:36; 列王纪下 2:24; 箴言 26:13"> 他就去了，在路上有个狮子遇见他，将他咬死，尸身倒在路上，驴站在尸身旁边，狮子也站在尸身旁边。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 13:11"> 有人从那里经过，看见尸身倒在路上，狮子站在尸身旁边，就来到老先知所住的城里述说这事。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以西结书 9:6; 箴言 11:31; 诗篇 119:120"> 那带神人回来的先知听见这事，就说：“这是那违背了耶和华命令的神人，所以耶和华把他交给狮子。狮子抓伤他，咬死他，是应验耶和华对他说的话。”</span>
<span className="v" id="v27" data-v="27"> 老先知就吩咐他儿子们说：“你们为我备驴。”他们就备了驴。</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪上 17:6; 诗篇 148:7–8; 但以理书 6:22–24"> 他去了，看见神人的尸身倒在路上，驴和狮子站在尸身旁边，狮子却没有吃尸身，也没有抓伤驴。</span>
<span className="v" id="v29" data-v="29"> 老先知就把神人的尸身驮在驴上，带回自己的城里，要哀哭他，葬埋他。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 22:18; 使徒行传 8:2; 列王纪上 14:13"> 就把他的尸身葬在自己的坟墓里，哀哭他，说：“哀哉，我兄啊！”</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 23:17–18; 民数记 23:10; 路加福音 16:22–23"> 安葬之后，老先知对他儿子们说：“我死了，你们要葬我在神人的坟墓里，使我的尸骨靠近他的尸骨，</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 16:24; 列王纪上 13:2; 列王纪上 12:31"> 因为他奉耶和华的命，指着伯特利的坛和撒马利亚各城有丘坛之殿所说的话必定应验。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="历代志下 11:15; 历代志下 13:9; 民数记 17:12–13"> 这事以后，耶罗波安仍不离开他的恶道，将凡民立为丘坛的祭司。凡愿意的，他都分别为圣，立为丘坛的祭司。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 14:10; 列王纪上 15:29–30; 列王纪上 12:30"> 这事叫耶罗波安的家陷在罪里，甚至他的家从地上除灭了。</span>
</div>
</div>

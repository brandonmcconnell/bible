## 约沙法与亚哈合攻基列拉末

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 20:34"> 亚兰国和以色列国三年没有争战。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 15:24; 列王纪上 22:1; 列王纪上 22:41"> 到第三年，犹大王约沙法下去见以色列王。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 4:43; 列王纪上 4:13; 约书亚记 21:38"> 以色列王对臣仆说：“你们不知道基列的拉末是属我们的吗？我们岂可静坐不动，不从亚兰王手里夺回来吗？”</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 3:7; 以弗所书 5:11; 约翰二书 1:11"> 亚哈问约沙法说：“你肯同我去攻取基列的拉末吗？”约沙法对以色列王说：“你我不分彼此，我的民与你的民一样，我的马与你的马一样。”</span>
</div>
</div>

## 以色列王召先知咨诹耶和华

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="箴言 3:5–6; 历代志下 18:4–5; 耶利米书 42:2–6"> 约沙法对以色列王说：“请你先求问耶和华。”</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 18:19; 耶利米书 23:14–17; 以西结书 13:7–16"> 于是以色列王招聚先知，约有四百人，问他们说：“我上去攻取基列的拉末可以不可以？”他们说：“可以上去，因为主必将那城交在王的手里。”</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 3:11–13; 历代志下 18:6–7"> 约沙法说：“这里不是还有耶和华的先知我们可以求问他吗？”</span>
<span className="v" id="v8" data-v="8" data-xref="阿摩司书 5:10; 约翰福音 3:19–21; 约翰福音 7:7"> 以色列王对约沙法说：“还有一个人，是音拉的儿子米该雅，我们可以托他求问耶和华。只是我恨他，因为他指着我所说的预言不说吉语，单说凶言。”约沙法说：“王不必这样说。”</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 9:32; 以赛亚书 39:7; 列王纪上 22:26–27"> 以色列王就召了一个太监来，说：“你快去将音拉的儿子米该雅召来。”</span>
<span className="v" id="v10" data-v="10" data-xref="以斯帖记 5:1; 以斯帖记 6:8–9; 列王纪上 18:29"> 以色列王和犹大王约沙法在撒马利亚城门前的空场上，各穿朝服，坐在位上，所有的先知都在他们面前说预言。</span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亚书 1:18–21; 申命记 33:17; 以西结书 22:27–28"> 基拿拿的儿子西底家造了两个铁角，说：“耶和华如此说：你要用这角抵触亚兰人，直到将他们灭尽。”</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 35:22; 列王纪上 22:6–15; 列王纪上 22:32–36"> 所有的先知也都这样预言说：“可以上基列的拉末去，必然得胜，因为耶和华必将那城交在王的手中。”</span>
</div>
</div>

## 米该雅预言其败

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="弥迦书 2:6–7; 诗篇 11:1; 以赛亚书 30:10–11"> 那去召米该雅的使者对米该雅说：“众先知一口同音地都向王说吉言，你不如与他们说一样的话，也说吉言。”</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 24:13; 民数记 22:18; 历代志下 18:12–13"> 米该雅说：“我指着永生的耶和华起誓：耶和华对我说什么，我就说什么。”</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 18:27; 士师记 10:14; 马太福音 26:45"> 米该雅到王面前，王问他说：“米该雅啊，我们上去攻取基列的拉末可以不可以？”他回答说：“可以上去，必然得胜，耶和华必将那城交在王的手中。”</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 19:13; 马太福音 26:63; 约书亚记 6:26"> 王对他说：“我当嘱咐你几次，你才奉耶和华的名向我说实话呢？”</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 27:17; 马太福音 9:36; 列王纪上 22:34–36"> 米该雅说：“我看见以色列众民散在山上，如同没有牧人的羊群一般。耶和华说：‘这民没有主人，他们可以平平安安地各归各家去。’”</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 22:8; 箴言 10:24; 路加福音 11:45"> 以色列王对约沙法说：“我岂没有告诉你，这人指着我所说的预言不说吉语，单说凶言吗？”</span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 2:1; 约伯记 1:6; 但以理书 7:9–10"> 米该雅说：“你要听耶和华的话！我看见耶和华坐在宝座上，天上的万军侍立在他左右。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 14:9; 约伯记 12:16; 耶利米书 4:10"> 耶和华说：‘谁去引诱亚哈上基列的拉末去阵亡呢？’这个就这样说，那个就那样说。</span>
<span className="v" id="v21" data-v="21" data-xref="约伯记 2:1; 列王纪上 22:23; 约伯记 1:6–7"> 随后有一个神灵出来，站在耶和华面前，说：‘我去引诱他。’</span>
<span className="v" id="v22" data-v="22" data-xref="士师记 9:23; 撒母耳记上 19:9; 撒母耳记上 16:14"> 耶和华问他说：‘你用何法呢？’他说：‘我去，要在他众先知口中做谎言的灵。’耶和华说：‘这样，你必能引诱他，你去如此行吧。’</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 14:9; 马太福音 24:24–25; 以赛亚书 44:20"> 现在耶和华使谎言的灵入了你这些先知的口，并且耶和华已经命定降祸于你。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行传 23:2; 耶利米哀歌 3:30; 弥迦书 5:1"> 基拿拿的儿子西底家前来，打米该雅的脸，说：“耶和华的灵从哪里离开我与你说话呢？”</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 20:30; 彼得后书 2:1; 启示录 19:20"> 米该雅说：“你进严密的屋子藏躲的那日，就必看见了。”</span>
<span className="v" id="v26" data-v="26"> 以色列王说：“将米该雅带回，交给邑宰亚们和王的儿子约阿施，说：</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 16:10; 历代志下 18:25–27; 启示录 2:10"> ‘王如此说：把这个人下在监里，使他受苦，吃不饱喝不足，等候我平平安安地回来。’”</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 16:29; 弥迦书 1:2; 使徒行传 13:10–11"> 米该雅说：“你若能平平安安地回来，那就是耶和华没有藉我说这话了！”又说：“众民哪，你们都要听！”</span>
</div>
</div>

## 亚哈阵亡

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="历代志下 18:28; 列王纪上 22:2–9"> 以色列王和犹大王约沙法上基列的拉末去了。</span>
<span className="v" id="v30" data-v="30" data-xref="历代志下 35:22; 耶利米书 23:24; 撒母耳记上 28:8"> 以色列王对约沙法说：“我要改装上阵，你可以仍穿王服。”以色列王就改装上阵。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪上 20:24; 历代志下 18:30; 耶利米书 16:6"> 先是亚兰王吩咐他的三十二个车兵长说：“他们的兵将，无论大小，你们都不可与他们争战，只要与以色列王争战。”</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 13:20; 约拿书 2:1–2; 诗篇 130:1–4"> 车兵长看见约沙法，便说：“这必是以色列王。”就转过去与他争战。约沙法便呼喊。</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 76:10; 列王纪上 22:31"> 车兵长见不是以色列王，就转去不追他了。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志下 35:23; 弥迦书 6:13; 撒母耳记上 17:49"> 有一人随便开弓，恰巧射入以色列王的甲缝里。王对赶车的说：“我受了重伤，你转过车来，拉我出阵吧。”</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 22:28; 列王纪上 20:42"> 那日阵势越战越猛，有人扶王站在车上，抵挡亚兰人。到晚上，王就死了，血从伤处流在车中。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪下 14:12; 列王纪上 22:31; 士师记 21:24"> 约在日落的时候，有号令传遍军中，说：“各归本城，各归本地吧！”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37"> 王既死了，众人将他送到撒马利亚，就葬在那里。</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪上 21:19; 马太福音 24:35; 耶利米书 44:21–23"> 又有人把他的车洗在撒马利亚的池旁（妓女在那里洗澡），狗来舔他的血，正如耶和华所说的话。</span>
<span className="v" id="v39" data-v="39" data-xref="阿摩司书 3:15; 以西结书 27:6; 诗篇 45:8"> 亚哈其余的事，凡他所行的和他所修造的象牙宫，并所建筑的一切城邑，都写在《以色列诸王记》上。</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳记下 7:12; 列王纪下 1:17; 列王纪下 1:2"> 亚哈与他列祖同睡。他儿子亚哈谢接续他做王。</span>
</div>
</div>

## 约沙法做犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="历代志下 20:31; 列王纪上 22:2; 历代志下 17:1"> 以色列王亚哈第四年，亚撒的儿子约沙法登基做了犹大王。</span>
<span className="v" id="v42" data-v="42" data-xref="列王纪下 1:17; 列王纪上 15:2; 列王纪上 15:10"> 约沙法登基的时候年三十五岁，在耶路撒冷做王二十五年。他母亲名叫阿苏巴，乃示利希的女儿。</span>
<span className="v" id="v43" data-v="43" data-xref="列王纪上 15:14; 列王纪下 12:3; 箴言 4:27"> 约沙法行他父亲亚撒所行的道，不偏离左右，行耶和华眼中看为正的事。只是丘坛还没有废去，百姓仍在那里献祭烧香。</span>
<span className="v" id="v44" data-v="44" data-xref="列王纪上 22:2; 历代志下 19:2; 列王纪下 8:18"> 约沙法与以色列王和好。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="列王纪上 14:29; 列王纪上 11:41; 历代志下 20:34"> 约沙法其余的事和他所显出的勇力，并他怎样争战，都写在《犹大列王记》上。</span>
<span className="v" id="v46" data-v="46" data-xref="列王纪上 15:12; 列王纪上 14:24; 申命记 23:17"> 约沙法将他父亲亚撒在世所剩下的娈童都从国中除去了。</span>
<span className="v" id="v47" data-v="47" data-xref="撒母耳记下 8:14; 列王纪下 3:9; 列王纪下 8:20"> 那时以东没有王，有总督治理。</span>
<span className="v" id="v48" data-v="48" data-xref="列王纪上 9:26; 列王纪上 10:22; 列王纪上 9:28"> 约沙法制造他施船只，要往俄斐去，将金子运来。只是没有去，因为船在以旬迦别破坏了。</span>
<span className="v" id="v49" data-v="49"> 亚哈的儿子亚哈谢对约沙法说：“容我的仆人和你的仆人坐船同去吧。”约沙法却不肯。</span>
<span className="v" id="v50" data-v="50" data-xref="历代志下 21:1; 列王纪上 22:40; 列王纪上 15:24"> 约沙法与列祖同睡，葬在大卫城他列祖的坟地里。他儿子约兰接续他做王。</span>
</div>
</div>

## 亚哈谢做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="列王纪下 1:17; 列王纪上 22:40; 列王纪上 15:25"> 犹大王约沙法十七年，亚哈的儿子亚哈谢在撒马利亚登基，做以色列王共二年。</span>
<span className="v" id="v52" data-v="52" data-xref="列王纪上 15:26; 列王纪上 21:25; 启示录 3:20"> 他行耶和华眼中看为恶的事，效法他的父母，又行尼八的儿子耶罗波安使以色列人陷在罪里的事。</span>
<span className="v" id="v53" data-v="53" data-xref="列王纪上 16:30–32; 以赛亚书 65:3; 列王纪下 3:2"> 他照他父亲一切所行的，侍奉敬拜巴力，惹耶和华以色列神的怒气。</span>
</div>
</div>

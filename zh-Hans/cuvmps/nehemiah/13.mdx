## 亚扪摩押人不得入神会

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 23:3–5; 尼希米记 9:3; 尼希米记 13:23"> 当日，人念摩西的律法书给百姓听，遇见书上写着说：亚扪人和摩押人永不可入神的会，</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 23:5; 约书亚记 24:9–10; 民数记 23:8–11"> 因为他们没有拿食物和水来迎接以色列人，且雇了巴兰咒诅他们，但我们的神使那咒诅变为祝福。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 9:2; 出埃及记 12:38; 民数记 11:4"> 以色列民听见这律法，就与一切闲杂人绝交。</span>
</div>
</div>

## 掷出多比雅之家具

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="尼希米记 12:44; 尼希米记 6:17–18; 尼希米记 13:28"> 先是蒙派管理我们神殿中库房的祭司以利亚实与多比雅结亲，</span>
<span className="v" id="v5" data-v="5" data-xref="尼希米记 12:44; 历代志下 34:11; 民数记 18:21–24"> 便为他预备一间大屋子，就是从前收存素祭、乳香、器皿，和照命令供给利未人、歌唱的、守门的五谷、新酒和油的十分之一，并归祭司举祭的屋子。</span>
<span className="v" id="v6" data-v="6" data-xref="尼希米记 5:14; 尼希米记 2:5–6; 马太福音 13:25"> 那时我不在耶路撒冷，因为巴比伦王亚达薛西三十二年，我回到王那里。过了多日，我向王告假。</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米记 13:5; 马太福音 21:12–13; 耶利米哀歌 1:10"> 我来到耶路撒冷，就知道以利亚实为多比雅在神殿的院内预备屋子的那件恶事。</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 11:15–17; 以斯拉记 10:1; 诗篇 69:9"> 我甚恼怒，就把多比雅的一切家具从屋里都抛出去，</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 29:5; 历代志下 29:15–19; 尼希米记 12:45"> 吩咐人洁净这屋子，遂将神殿的器皿和素祭、乳香又搬进去。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="尼希米记 10:37; 玛拉基书 3:8; 玛拉基书 1:6–14"> 我见利未人所当得的份无人供给他们，甚至供职的利未人与歌唱的俱各奔回自己的田地去了。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 10:39; 尼希米记 13:17; 尼希米记 13:25"> 我就斥责官长说：“为何离弃神的殿呢？”我便招聚利未人，使他们照旧供职。</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米记 10:37–39; 玛拉基书 3:10; 尼希米记 12:44"> 犹大众人就把五谷、新酒和油的十分之一送入库房。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 22:7; 尼希米记 7:2; 尼希米记 12:44"> 我派祭司示利米雅、文士撒督和利未人毗大雅做库官，管理库房；副官是哈难，哈难是撒刻的儿子，撒刻是玛他尼的儿子。这些人都是忠信的，他们的职分是将所供给的分给他们的弟兄。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 122:6–9; 尼希米记 13:22; 尼希米记 13:31"> 我的神啊，求你因这事记念我，不要涂抹我为神的殿与其中的礼节所行的善。</span>
</div>
</div>

## 戒民犯安息日

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="尼希米记 10:31; 尼希米记 13:21; 出埃及记 34:21"> 那些日子，我在犹大见有人在安息日榨酒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：踹酒榨。">a</a></sup>，搬运禾捆驮在驴上，又把酒、葡萄、无花果和各样的担子在安息日担入耶路撒冷，我就在他们卖食物的那日警戒他们。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 23:12; 申命记 5:14"> 又有推罗人住在耶路撒冷，他们把鱼和各样货物运进来，在安息日卖给犹大人。</span>
<span className="v" id="v17" data-v="17" data-xref="尼希米记 13:11; 尼希米记 13:25; 以赛亚书 1:10"> 我就斥责犹大的贵胄说：“你们怎么行这恶事，犯了安息日呢？</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 17:21–23; 耶利米书 44:9; 民数记 32:14"> 从前你们列祖岂不是这样行，以致我们神使一切灾祸临到我们和这城吗？现在你们还犯安息日，使愤怒越发临到以色列！”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="利未记 23:32; 出埃及记 31:14–17; 耶利米书 17:19–22"> 在安息日的前一日，耶路撒冷城门有黑影的时候，我就吩咐人将门关锁，不过安息日不准开放。我又派我几个仆人管理城门，免得有人在安息日担什么担子进城。</span>
<span className="v" id="v20" data-v="20"> 于是商人和贩卖各样货物的一两次住宿在耶路撒冷城外。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 13:3–4; 彼得前书 2:14; 以斯拉记 7:26"> 我就警戒他们说：“你们为何在城外住宿呢？若再这样，我必下手拿办你们。”从此以后，他们在安息日不再来了。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米记 12:30; 尼希米记 13:14; 尼希米记 13:31"> 我吩咐利未人洁净自己，来守城门，使安息日为圣。我的神啊，求你因这事记念我，照你的大慈爱怜恤我。</span>
</div>
</div>

## 禁与异族联姻

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以斯拉记 9:1–2; 以斯拉记 10:10; 尼希米记 10:30"> 那些日子，我也见犹大人娶了亚实突、亚扪、摩押的女子为妻。</span>
<span className="v" id="v24" data-v="24" data-xref="西番雅书 3:9"> 他们的儿女说话，一半是亚实突的话，不会说犹大的话，所说的是照着各族的方言。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 7:3; 尼希米记 13:17; 尼希米记 10:29–30"> 我就斥责他们，咒诅他们，打了他们几个人，拔下他们的头发，叫他们指着神起誓，必不将自己的女儿嫁给外邦人的儿子，也不为自己和儿子娶他们的女儿。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 11:1–8; 列王纪上 3:13; 传道书 7:26"> 我又说：“以色列王所罗门不是在这样的事上犯罪吗？在多国中并没有一王像他，且蒙他神所爱，神立他做以色列全国的王，然而连他也被外邦女子引诱犯罪。</span>
<span className="v" id="v27" data-v="27" data-xref="以斯拉记 10:2; 撒母耳记上 30:24"> 如此，我岂听你们行这大恶，娶外邦女子干犯我们的神呢？”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="尼希米记 2:19; 尼希米记 3:1; 尼希米记 12:22"> 大祭司以利亚实的孙子、耶何耶大的一个儿子是和伦人参巴拉的女婿，我就从我这里把他赶出去。</span>
<span className="v" id="v29" data-v="29" data-xref="尼希米记 6:14; 民数记 25:12–13; 玛拉基书 2:4–8"> 我的神啊，求你记念他们的罪，因为他们玷污了祭司的职任，违背你与祭司、利未人所立的约。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="尼希米记 10:30; 尼希米记 12:1–26; 历代志上 23:1–26"> 这样，我洁净他们，使他们离绝一切外邦人，派定祭司和利未人的班次，使他们各尽其职。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米记 13:14; 尼希米记 13:22; 诗篇 106:4"> 我又派百姓按定期献柴和初熟的土产。我的神啊，求你记念我，施恩于我。</span>
</div>
</div>

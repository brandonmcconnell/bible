## 记与所罗巴伯同归之祭司利未人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 10:2–8; 尼希米记 12:12–21; 以斯拉记 2:1–2"> 同着撒拉铁的儿子所罗巴伯和耶书亚回来的祭司与利未人记在下面：祭司是西莱雅、耶利米、以斯拉、</span>
<span className="v" id="v2" data-v="2"> 亚玛利雅、玛鹿、哈突、</span>
<span className="v" id="v3" data-v="3"> 示迦尼、利宏、米利末、</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 1:5"> 易多、近顿、亚比雅、</span>
<span className="v" id="v5" data-v="5"> 米雅民、玛底雅、璧迦、</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 9:10; 尼希米记 11:10"> 示玛雅、约雅立、耶大雅、</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 24:18; 撒迦利亚书 3:1; 以斯拉记 3:2"> 撒路、亚木、希勒家、耶大雅。这些人在耶书亚的时候做祭司和他们弟兄的首领。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="尼希米记 11:17; 尼希米记 12:24; 尼希米记 11:22"> 利未人是耶书亚、宾内、甲篾、示利比、犹大、玛他尼，这玛他尼和他的弟兄管理称谢的事。</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米记 12:24; 诗篇 134:1–3"> 他们的弟兄八布迦和乌尼照自己的班次与他们相对。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 6:3–15; 尼希米记 13:28; 尼希米记 13:4"> 耶书亚生约雅金，约雅金生以利亚实，以利亚实生耶何耶大，</span>
<span className="v" id="v11" data-v="11"> 耶何耶大生约拿单，约拿单生押杜亚。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="尼希米记 12:22; 历代志上 9:33–34; 历代志上 24:6–31"> 在约雅金的时候，祭司做族长的：西莱雅族<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：班。本段同。">a</a></sup>有米拉雅，耶利米族有哈拿尼雅，</span>
<span className="v" id="v13" data-v="13"> 以斯拉族有米书兰，亚玛利雅族有约哈难，</span>
<span className="v" id="v14" data-v="14"> 米利古族有约拿单，示巴尼族有约瑟，</span>
<span className="v" id="v15" data-v="15"> 哈琳族有押拿，米拉约族有希勒恺，</span>
<span className="v" id="v16" data-v="16"> 易多族有撒迦利亚，近顿族有米书兰，</span>
<span className="v" id="v17" data-v="17"> 亚比雅族有细基利，米拿民族某，摩亚底族有毗勒太，</span>
<span className="v" id="v18" data-v="18"> 璧迦族有沙母亚，示玛雅族有约拿单，</span>
<span className="v" id="v19" data-v="19"> 约雅立族有玛特乃，耶大雅族有乌西，</span>
<span className="v" id="v20" data-v="20"> 撒来族有加莱，亚木族有希伯，</span>
<span className="v" id="v21" data-v="21"> 希勒家族有哈沙比雅，耶大雅族有拿坦业。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="尼希米记 12:10–13"> 至于利未人，当以利亚实、耶何耶大、约哈难、押杜亚的时候，他们的族长记在册上；波斯王大流士在位的时候，做族长的祭司也记在册上。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 9:14–44"> 利未人做族长的记在历史上，直到以利亚实的儿子约哈难的时候。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 25:1–26; 尼希米记 11:17; 以斯拉记 3:10–11"> 利未人的族长是哈沙比雅、示利比、甲篾的儿子耶书亚，与他们弟兄的班次相对，照着神人大卫的命令，一班一班地赞美称谢。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志上 26:15; 尼希米记 12:8–9; 历代志上 26:12"> 玛他尼、八布迦、俄巴底亚、米书兰、达们、亚谷是守门的，就是在库房那里守门。</span>
<span className="v" id="v26" data-v="26" data-xref="尼希米记 8:9; 以斯拉记 7:6; 以斯拉记 7:11"> 这都是在约萨达的孙子、耶书亚的儿子约雅金和省长尼希米，并祭司文士以斯拉的时候有职任的。</span>
</div>
</div>

## 为邑垣行告成礼

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="历代志上 15:16; 历代志上 15:28; 历代志下 29:30"> 耶路撒冷城墙告成的时候，众民就把各处的利未人招到耶路撒冷，要称谢、歌唱、敲钹、鼓瑟、弹琴，欢欢喜喜地行告成之礼。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志上 9:16; 历代志上 2:54; 尼希米记 6:2"> 歌唱的人从耶路撒冷的周围和尼陀法的村庄与伯吉甲，又从迦巴和押玛弗的田地聚集，因为歌唱的人在耶路撒冷四围为自己立了村庄。</span>
<span className="v" id="v30" data-v="30" data-xref="约伯记 1:5; 出埃及记 19:10; 历代志下 29:5"> 祭司和利未人就洁净自己，也洁净百姓和城门并城墙。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="尼希米记 2:13; 尼希米记 12:38; 历代志上 13:1"> 我带犹大的首领上城，使称谢的人分为两大队，排列而行。第一队在城上往右边向粪厂门行走。</span>
<span className="v" id="v32" data-v="32"> 在他们后头的有何沙雅与犹大首领的一半；</span>
<span className="v" id="v33" data-v="33" data-xref="尼希米记 10:2–7"> 又有亚撒利雅、以斯拉、米书兰、</span>
<span className="v" id="v34" data-v="34"> 犹大、便雅悯、示玛雅、耶利米；</span>
<span className="v" id="v35" data-v="35" data-xref="约书亚记 6:4; 民数记 10:2–10; 历代志下 5:12"> 还有些吹号之祭司的子孙约拿单的儿子撒迦利亚，约拿单是示玛雅的儿子，示玛雅是玛他尼的儿子，玛他尼是米该亚的儿子，米该亚是撒刻的儿子，撒刻是亚萨的儿子；</span>
<span className="v" id="v36" data-v="36" data-xref="尼希米记 12:24; 历代志下 8:14; 历代志上 23:5"> 又有撒迦利亚的弟兄示玛雅、亚撒利、米拉莱、基拉莱、玛艾、拿坦业、犹大、哈拿尼，都拿着神人大卫的乐器。文士以斯拉引领他们。</span>
<span className="v" id="v37" data-v="37" data-xref="尼希米记 3:26; 尼希米记 2:14; 尼希米记 8:3"> 他们经过泉门往前，从大卫城的台阶随地势而上，在大卫宫殿以上，直行到朝东的水门。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="尼希米记 3:8; 尼希米记 3:11; 尼希米记 12:31"> 第二队称谢的人要与那一队相迎而行。我和民的一半跟随他们，在城墙上过了炉楼，直到宽墙，</span>
<span className="v" id="v39" data-v="39" data-xref="尼希米记 3:1; 尼希米记 3:3; 尼希米记 8:16"> 又过了以法莲门、古门、鱼门、哈楠业楼、哈米亚楼，直到羊门，就在护卫门站住。</span>
<span className="v" id="v40" data-v="40" data-xref="诗篇 42:4; 诗篇 134:1–3; 尼希米记 12:31–32"> 于是，这两队称谢的人，连我和官长的一半，站在神的殿里。</span>
<span className="v" id="v41" data-v="41"> 还有祭司以利亚金、玛西雅、米拿民、米该雅、以利约乃、撒迦利亚、哈楠尼亚吹号。</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 81:1; 尼希米记 11:14; 诗篇 100:1–2"> 又有玛西雅、示玛雅、以利亚撒、乌西、约哈难、玛基雅、以拦和以谢奏乐。歌唱的就大声歌唱，伊斯拉希雅管理他们。</span>
<span className="v" id="v43" data-v="43" data-xref="以斯拉记 3:13; 诗篇 92:4; 耶利米书 31:13"> 那日，众人献大祭而欢乐，因为神使他们大大欢乐，连妇女带孩童也都欢乐，甚至耶路撒冷中的欢声听到远处。</span>
</div>
</div>

## 立司库储祭司利未人所需

<div className="bt">
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="尼希米记 13:12–13; 尼希米记 10:37–39; 历代志下 31:11–13"> 当日，派人管理库房，将举祭、初熟之物和所取的十分之一，就是按各城田地，照律法所定，归给祭司和利未人的份，都收在里头。犹大人因祭司和利未人供职，就欢乐了。</span>
<span className="v" id="v45" data-v="45" data-xref="历代志上 25:1–26; 历代志下 23:6; 历代志上 23:28"> 祭司、利未人遵守神所吩咐的，并守洁净的礼。歌唱的、守门的照着大卫和他儿子所罗门的命令，也如此行。</span>
<span className="v" id="v46" data-v="46" data-xref="历代志下 29:30; 诗篇 73:1; 历代志上 25:1–31"> 古时，在大卫和亚萨的日子，有歌唱的伶长并有赞美称谢神的诗歌。</span>
<span className="v" id="v47" data-v="47" data-xref="民数记 18:21–29; 尼希米记 12:26; 尼希米记 13:10–12"> 当所罗巴伯和尼希米的时候，以色列众人将歌唱的、守门的每日所当得的份供给他们，又给利未人当得的份，利未人又给亚伦的子孙当得的份。</span>
</div>

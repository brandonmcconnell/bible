## 始建邑垣依次修筑

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 12:39; 耶利米书 31:38; 约翰福音 5:2"> 那时，大祭司以利亚实和他的弟兄众祭司起来建立羊门，分别为圣，安立门扇，又筑城墙到哈米亚楼，直到哈楠业楼，分别为圣。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米记 7:36; 以斯拉记 2:34; 尼希米记 10:12"> 其次是耶利哥人建造。其次是音利的儿子撒刻建造。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="历代志下 33:14; 尼希米记 12:39; 西番雅书 1:10"> 哈西拿的子孙建立鱼门，架横梁，安门扇和闩、锁。</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉记 8:33; 尼希米记 3:21; 尼希米记 10:7"> 其次是哈哥斯的孙子、乌利亚的儿子米利末修造。其次是米示萨别的孙子、比利迦的儿子米书兰修造。其次是巴拿的儿子撒督修造。</span>
<span className="v" id="v5" data-v="5" data-xref="尼希米记 3:27; 撒母耳记下 14:2; 耶利米书 27:2"> 其次是提哥亚人修造，但是他们的贵胄不用肩<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“肩”原文作“颈项”。">a</a></sup>担他们主的工作。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="尼希米记 12:39"> 巴西亚的儿子耶何耶大与比所玳的儿子米书兰修造古门，架横梁，安门扇和闩、锁。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 21:2; 约书亚记 9:3–27; 尼希米记 3:19"> 其次是基遍人米拉提、米仑人雅顿与基遍人，并属河西总督所管的米斯巴人修造。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米记 12:38; 尼希米记 3:31–32; 创世记 50:2"> 其次是银匠哈海雅的儿子乌薛修造。其次是做香的哈拿尼雅修造，这些人修坚耶路撒冷，直到宽墙。</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米记 3:12; 尼希米记 3:17"> 其次是管理耶路撒冷一半，户珥的儿子利法雅修造。</span>
<span className="v" id="v10" data-v="10" data-xref="尼希米记 3:28–30; 尼希米记 10:4; 尼希米记 3:23"> 其次是哈路抹的儿子耶大雅对着自己的房屋修造。其次是哈沙尼的儿子哈突修造。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 12:38; 以斯拉记 2:6; 尼希米记 10:14"> 哈琳的儿子玛基雅和巴哈摩押的儿子哈述修造一段，并修造炉楼。</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米记 3:9; 使徒行传 21:8–9; 出埃及记 35:25"> 其次是管理耶路撒冷那一半，哈罗黑的儿子沙龙和他的女儿们修造。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="尼希米记 2:13; 约书亚记 15:34; 历代志下 26:9"> 哈嫩和撒挪亚的居民修造谷门，立门，安门扇和闩、锁，又建筑城墙一千肘，直到粪厂门。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米书 6:1; 尼希米记 2:13; 尼希米记 3:12–13"> 管理伯哈基琳，利甲的儿子玛基雅修造粪厂门，立门，安门扇和闩、锁。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 9:7; 以赛亚书 8:6; 尼希米记 12:37"> 管理米斯巴，各荷西的儿子沙仑修造泉门，立门，盖门顶，安门扇和闩、锁，又修造靠近王园西罗亚池的墙垣，直到那从大卫城下来的台阶。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 2:29; 尼希米记 3:9; 列王纪下 20:20"> 其次是管理伯夙一半，押卜的儿子尼希米修造，直到大卫坟地的对面，又到挖成的池子并勇士的房屋。</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 15:44; 尼希米记 3:16; 撒母耳记上 23:1–13"> 其次是利未人巴尼的儿子利宏修造。其次是管理基伊拉一半，哈沙比雅为他所管的本境修造。</span>
<span className="v" id="v18" data-v="18"> 其次是利未人弟兄中管理基伊拉那一半，希拿达的儿子巴瓦伊修造。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 26:9; 尼希米记 10:9; 尼希米记 12:8"> 其次是管理米斯巴，耶书亚的儿子以谢修造一段，对着武库的上坡城墙转弯之处。</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米记 3:1; 传道书 9:10; 罗马书 12:11"> 其次是萨拜的儿子巴录竭力修造一段，从城墙转弯直到大祭司以利亚实的府门。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米记 7:63; 以斯拉记 2:61"> 其次是哈哥斯的孙子、乌利亚的儿子米利末修造一段，从以利亚实的府门直到以利亚实府的尽头。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米记 12:28; 尼希米记 6:2"> 其次是住平原的祭司修造。</span>
<span className="v" id="v23" data-v="23" data-xref="尼希米记 10:2; 尼希米记 8:4; 尼希米记 3:29–30"> 其次是便雅悯与哈述对着自己的房屋修造。其次是亚难尼的孙子、玛西雅的儿子亚撒利雅在靠近自己的房屋修造。</span>
<span className="v" id="v24" data-v="24" data-xref="尼希米记 3:19; 尼希米记 3:27; 尼希米记 10:9"> 其次是希拿达的儿子宾内修造一段，从亚撒利雅的房屋直到城墙转弯，又到城角。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 32:2; 耶利米书 37:21; 尼希米记 12:39"> 乌赛的儿子巴拉修造对着城墙的转弯和王上宫凸出来的城楼，靠近护卫院的那一段。其次是巴录的儿子毗大雅修造。</span>
<span className="v" id="v26" data-v="26" data-xref="尼希米记 8:1; 尼希米记 11:21; 尼希米记 12:37"> （尼提宁住在俄斐勒，直到朝东水门的对面和凸出来的城楼。）</span>
<span className="v" id="v27" data-v="27" data-xref="尼希米记 3:5"> 其次是提哥亚人又修一段，对着那凸出来的大楼，直到俄斐勒的墙。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="历代志下 23:15; 耶利米书 31:40; 列王纪下 11:16"> 从马门往上，众祭司各对自己的房屋修造。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 19:2; 以斯拉记 2:37; 尼希米记 7:40"> 其次是音麦的儿子撒督对着自己的房屋修造。其次是守东门示迦尼的儿子示玛雅修造。</span>
<span className="v" id="v30" data-v="30"> 其次是示利米雅的儿子哈拿尼雅和萨拉的第六子哈嫩又修一段。其次是比利迦的儿子米书兰对着自己的房屋修造。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米记 3:8; 尼希米记 3:32"> 其次是银匠玛基雅修造到尼提宁和商人的房屋，对着哈米弗甲门，直到城的角楼。</span>
<span className="v" id="v32" data-v="32" data-xref="尼希米记 3:1; 约翰福音 5:2; 尼希米记 12:39"> 银匠与商人在城的角楼和羊门中间修造。</span>
</div>
</div>

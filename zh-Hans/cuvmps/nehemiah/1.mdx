## 尼希米为故土禁食祈祷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 10:1; 撒迦利亚书 7:1; 以斯帖记 1:2"> 哈迦利亚的儿子尼希米的言语如下：<br />亚达薛西王二十年基斯流月，我在书珊城的宫中。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米记 7:2; 以西结书 6:9; 耶利米书 44:14"> 那时，有我一个弟兄哈拿尼同着几个人从犹大来。我问他们那些被掳归回剩下逃脱的犹大人和耶路撒冷的光景。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 2:17; 列王纪下 25:10; 尼希米记 7:6"> 他们对我说：“那些被掳归回剩下的人在犹大省遭大难，受凌辱，并且耶路撒冷的城墙拆毁，城门被火焚烧。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="但以理书 9:3; 诗篇 137:1; 以斯拉记 10:1"> 我听见这话，就坐下哭泣，悲哀几日，在天上的神面前禁食祈祷，说：</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 20:6; 但以理书 9:4–19; 申命记 7:21"> “耶和华天上的神，大而可畏的神啊，你向爱你守你诫命的人守约施慈爱，</span>
<span className="v" id="v6" data-v="6" data-xref="但以理书 9:20; 但以理书 9:4; 诗篇 34:15"> 愿你睁眼看、侧耳听，你仆人昼夜在你面前为你众仆人以色列民的祈祷，承认我们以色列人向你所犯的罪。我与我父家都有罪了！</span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 9:5–6; 但以理书 9:11; 但以理书 9:13"> 我们向你所行的甚是邪恶，没有遵守你藉着仆人摩西所吩咐的诫命、律例、典章。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 28:64; 申命记 4:25–27; 利未记 26:33–46"> 求你记念所吩咐你仆人摩西的话说：‘你们若犯罪，我就把你们分散在万民中。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 29:11–14; 申命记 30:2–5; 申命记 4:29–31"> 但你们若归向我，谨守遵行我的诫命，你们被赶散的人虽在天涯，我也必从那里将他们招聚回来，带到我所选择立为我名的居所。’</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 9:29; 但以理书 9:15–27; 出埃及记 32:11"> 这都是你的仆人、你的百姓，就是你用大力和大能的手所救赎的。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 1:6; 尼希米记 2:8; 箴言 21:1"> 主啊，求你侧耳听你仆人的祈祷和喜爱敬畏你名众仆人的祈祷，使你仆人现今亨通，在王面前蒙恩。”<br />我是做王酒政的。</span>
</div>

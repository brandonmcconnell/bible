## 生该隐亚伯

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰一书 3:12; 创世记 3:15; 创世记 4:25"> 有一日，那人和他妻子夏娃同房，夏娃就怀孕，生了该隐<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是“得”的意思。">a</a></sup>，便说：“耶和华使我得了一个男子。”</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 3:15; 约翰一书 3:12; 路加福音 11:51"> 又生了该隐的兄弟亚伯。亚伯是牧羊的，该隐是种地的。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 18:12; 利未记 2:1–11; 列王纪上 17:7"> 有一日，该隐拿地里的出产为供物献给耶和华，</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 11:4; 箴言 3:9; 出埃及记 13:12"> 亚伯也将他羊群中头生的和羊的脂油献上。耶和华看中了亚伯和他的供物，</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 11:4; 约伯记 5:2; 路加福音 15:28–30"> 只是看不中该隐和他的供物。该隐就大大地发怒，变了脸色。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 1:18; 约伯记 5:2; 路加福音 15:31–32"> 耶和华对该隐说：“你为什么发怒呢？你为什么变了脸色呢？</span>
<span className="v" id="v7" data-v="7" data-xref="雅各书 1:15; 罗马书 2:6–10; 以赛亚书 3:10–11"> 你若行得好，岂不蒙悦纳？你若行得不好，罪就伏在门前。它必恋慕你，你却要制伏它。”</span>
</div>
</div>

## 该隐杀其弟

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="马太福音 23:35; 约翰一书 3:12–15; 犹大书 1:11"> 该隐与他兄弟亚伯说话，二人正在田间，该隐起来打他兄弟亚伯，把他杀了。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="箴言 28:13; 约翰福音 8:44; 诗篇 9:12"> 耶和华对该隐说：“你兄弟亚伯在哪里？”他说：“我不知道。我岂是看守我兄弟的吗？”</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 12:24; 诗篇 72:14; 希伯来书 11:4"> 耶和华说：“你做了什么事呢？你兄弟的血有声音从地里向我哀告。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太书 3:10; 约伯记 16:18; 创世记 3:14"> 地开了口，从你手里接受你兄弟的血，现在你必从这地受咒诅。</span>
<span className="v" id="v12" data-v="12" data-xref="何西阿书 9:17; 利未记 26:36; 利未记 26:20"> 你种地，地不再给你效力；你必流离飘荡在地上。”</span>
<span className="v" id="v13" data-v="13" data-xref="约伯记 15:22; 启示录 16:9; 启示录 16:11"> 该隐对耶和华说：“我的刑罚太重，过于我所能当的。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 35:19; 诗篇 143:7; 约伯记 15:20–24"> 你如今赶逐我离开这地，以致不见你面，我必流离飘荡在地上，凡遇见我的必杀我。”</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 9:4; 诗篇 79:12; 创世记 4:24"> 耶和华对他说：“凡杀该隐的，必遭报七倍。”耶和华就给该隐立一个记号，免得人遇见他就杀他。</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="耶利米书 23:39; 约伯记 2:7; 创世记 4:14"> 于是，该隐离开耶和华的面，去住在伊甸东边挪得之地。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 49:11; 传道书 2:4–11; 但以理书 4:30"> 该隐与妻子同房，他妻子就怀孕，生了以诺。该隐建造了一座城，就按着他儿子的名，将那城叫做以诺。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 36:2; 创世记 5:21"> 以诺生以拿，以拿生米户雅利，米户雅利生玛土撒利，玛土撒利生拉麦。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 2:24; 马太福音 19:8; 创世记 2:18"> 拉麦娶了两个妻，一个名叫亚大，一个名叫洗拉。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 4:2; 耶利米书 35:9–10; 约翰福音 8:44"> 亚大生雅八。雅八就是住帐篷、牧养牲畜之人的祖师。</span>
<span className="v" id="v21" data-v="21" data-xref="约伯记 21:12; 以赛亚书 5:12; 创世记 31:27"> 雅八的兄弟名叫犹八，他是一切弹琴吹箫之人的祖师。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 33:25; 申命记 8:9; 历代志下 2:7"> 洗拉又生了土八该隐，他是打造各样铜铁利器的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：是铜匠铁匠的祖师。">b</a></sup>。土八该隐的妹子是拿玛。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 23:18; 出埃及记 20:13; 利未记 19:18"> 拉麦对他两个妻子说：<br /><span className="pl pl-1">“亚大、洗拉，听我的声音，</span><br /><span className="pl pl-1">拉麦的妻子，细听我的话语：</span><br /><span className="pl pl-1">壮年人伤我，我把他杀了；</span><br /><span className="pl pl-1">少年人损我，我把他害了</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作：我杀壮士却伤自己，我害幼童却损本身。">c</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 18:22; 创世记 4:15"> <span className="pl pl-1">若杀该隐遭报七倍，</span><br /><span className="pl pl-1">杀拉麦必遭报七十七倍。”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 4:8; 创世记 4:10–11; 历代志上 1:1"> 亚当又与妻子同房，她就生了一个儿子，起名叫塞特，意思说：“神另给我立了一个儿子代替亚伯，因为该隐杀了他。”</span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 116:17; 列王纪上 18:24; 约珥书 2:32"> 塞特也生了一个儿子，起名叫以挪士。那时候，人才求告耶和华的名。</span>
</div>
</div>

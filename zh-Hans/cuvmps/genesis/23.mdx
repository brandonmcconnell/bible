<span className="v" id="v1" data-v="1" data-xref="创世记 17:17"> 撒拉享寿一百二十七岁，这是撒拉一生的岁数。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 23:19; 创世记 13:18; 历代志上 6:57"> 撒拉死在迦南地的基列亚巴，就是希伯仑。亚伯拉罕为她哀恸哭号。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 10:15; 创世记 23:7; 撒母耳记上 26:6"> 后来亚伯拉罕从死人面前起来，对赫人说：</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 29:15; 希伯来书 11:9; 创世记 17:8"> “我在你们中间是外人，是寄居的。求你们在这里给我一块地，我好埋葬我的死人，使她不在我眼前。”</span>
<span className="v" id="v5" data-v="5"> 赫人回答亚伯拉罕说：</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 24:35; 创世记 14:14; 出埃及记 32:22"> “我主请听，你在我们中间是一位尊大的王子，只管在我们最好的坟地里埋葬你的死人，我们没有一人不容你在他的坟地里埋葬你的死人。”</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 12:14; 创世记 19:1; 箴言 18:24"> 亚伯拉罕就起来，向那地的赫人下拜，</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 25:9; 约翰一书 2:1–2; 列王纪上 2:17"> 对他们说：“你们若有意叫我埋葬我的死人，使她不在我眼前，就请听我的话，为我求琐辖的儿子以弗仑，</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 13:8; 罗马书 12:17"> 把田头上那麦比拉洞给我。他可以按着足价卖给我，做我在你们中间的坟地。”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 34:20; 创世记 34:24; 创世记 23:18"> 当时以弗仑正坐在赫人中间。于是，赫人以弗仑在城门出入的赫人面前对亚伯拉罕说：</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:24; 以赛亚书 32:8; 申命记 19:15"> “不然，我主请听，我送给你这块田，连田间的洞也送给你。在我同族的人面前都给你，可以埋葬你的死人。”</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 23:7; 创世记 18:2; 创世记 19:1"> 亚伯拉罕就在那地的人民面前下拜，</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 13:8; 撒母耳记下 24:24; 创世记 14:22–23"> 在他们面前对以弗仑说：“你若应允，请听我的话，我要把田价给你，求你收下，我就在那里埋葬我的死人。”</span>
<span className="v" id="v14" data-v="14"> 以弗仑回答亚伯拉罕说：</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 45:12; 出埃及记 30:13; 出埃及记 30:15"> “我主请听，值四百舍客勒银子的一块田，在你我中间还算什么呢？只管埋葬你的死人吧。”</span>
<span className="v" id="v16" data-v="16" data-xref="撒迦利亚书 11:12; 耶利米书 32:9; 出埃及记 30:13"> 亚伯拉罕听从了以弗仑，照着他在赫人面前所说的话，把买卖通用的银子平了四百舍客勒给以弗仑。</span>
</div>

## 撒拉埋葬

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 25:9; 创世记 50:13; 创世记 23:20"> 于是，麦比拉，幔利前，以弗仑的那块田和其中的洞，并田间四围的树木，</span>
<span className="v" id="v18" data-v="18" data-xref="路得记 4:1; 耶利米书 32:12; 创世记 34:20"> 都定准归于亚伯拉罕，乃是他在赫人面前并城门出入的人面前买妥的。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 50:13; 传道书 12:7; 传道书 12:5"> 此后，亚伯拉罕把他妻子撒拉埋葬在迦南地幔利前的麦比拉田间的洞里，幔利就是希伯仑。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 32:10–14; 路得记 4:7–10; 创世记 49:31–32"> 从此，那块田和田间的洞，就藉着赫人定准归于亚伯拉罕做坟地。</span>
</div>

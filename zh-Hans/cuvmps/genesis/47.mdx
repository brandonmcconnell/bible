## 约瑟简弟兄见法老

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 45:10; 创世记 46:31; 创世记 46:28"> 约瑟进去告诉法老说：“我的父亲和我的弟兄带着羊群牛群，并一切所有的，从迦南地来了，如今在歌珊地。”</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 7:13; 歌罗西书 1:28; 犹大书 1:24"> 约瑟从他弟兄中挑出五个人来，引他们去见法老。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 46:33–34; 帖撒罗尼迦后书 3:10; 创世记 4:2"> 法老问约瑟的弟兄说：“你们以何事为业？”他们对法老说：“你仆人是牧羊的，连我们的祖宗也是牧羊的。”</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 46:34; 创世记 15:13; 申命记 26:5"> 他们又对法老说：“迦南地的饥荒甚大，仆人的羊群没有草吃，所以我们来到这地寄居。现在求你容仆人住在歌珊地。”</span>
<span className="v" id="v5" data-v="5"> 法老对约瑟说：“你父亲和你弟兄到你这里来了，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 18:21; 箴言 22:29; 创世记 47:11"> 埃及地都在你面前，只管叫你父亲和你弟兄住在国中最好的地，他们可以住在歌珊地。你若知道他们中间有什么能人，就派他们看管我的牲畜。”</span>
</div>
</div>

## 约瑟引雅各见法老

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="创世记 47:10; 撒母耳记下 8:10; 撒母耳记上 2:20"> 约瑟领他父亲雅各进到法老面前，雅各就给法老祝福。</span>
<span className="v" id="v8" data-v="8"> 法老问雅各说：“你平生的年日是多少呢？”</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 39:12; 诗篇 39:5; 约伯记 14:1"> 雅各对法老说：“我寄居在世的年日是一百三十岁。我平生的年日又少又苦，不及我列祖在世寄居的年日。”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 47:7; 诗篇 129:8; 希伯来书 7:7"> 雅各又给法老祝福，就从法老面前出去了。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 47:6; 出埃及记 1:11; 出埃及记 12:37"> 约瑟遵着法老的命，把埃及国最好的地，就是兰塞境内的地，给他父亲和弟兄居住，作为产业。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 45:11; 提摩太前书 5:8; 创世记 47:1"> 约瑟用粮食奉养他父亲和他弟兄，并他父亲全家的眷属，都是照各家的人口奉养他们。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 7:11; 列王纪上 18:5; 耶利米哀歌 4:9"> 饥荒甚大，全地都绝了粮，甚至埃及地和迦南地的人因那饥荒的缘故都饿昏了。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 41:56; 路加福音 16:10–12; 路加福音 16:1–2"> 约瑟收聚了埃及地和迦南地所有的银子，就是众人籴粮的银子，约瑟就把那银子带到法老的宫里。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 8:8; 诗篇 37:3; 马太福音 6:11"> 埃及地和迦南地的银子都花尽了，埃及众人都来见约瑟，说：“我们的银子都用尽了，求你给我们粮食，我们为什么死在你面前呢？”</span>
</div>
</div>

## 约瑟以粮易畜

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 4:5; 但以理书 6:5–7; 哥林多前书 10:32"> 约瑟说：“若是银子用尽了，可以把你们的牲畜给我，我就为你们的牲畜给你们粮食。”</span>
<span className="v" id="v17" data-v="17" data-xref="约伯记 2:4; 出埃及记 9:3; 以赛亚书 31:1"> 于是他们把牲畜赶到约瑟那里，约瑟就拿粮食换了他们的牛、羊、驴、马。那一年因换他们一切的牲畜，就用粮食养活他们。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 6:26; 耶利米书 38:9"> 那一年过去，第二年他们又来见约瑟，说：“我们不瞒我主，我们的银子都花尽了，牲畜也都归了我主。我们在我主眼前，除了我们的身体和田地之外，一无所剩。</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米记 5:2–3; 约伯记 2:4; 耶利米哀歌 1:11"> 你何忍见我们人死地荒呢？求你用粮食买我们和我们的地，我们和我们的地就要给法老效力。又求你给我们种子，使我们得以存活，不致死亡，地土也不致荒凉。”</span>
</div>
</div>

## 以粮易地

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20"> 于是，约瑟为法老买了埃及所有的地。埃及人因被饥荒所迫，各都卖了自己的田地，那地就都归了法老。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 41:48"> 至于百姓，约瑟叫他们从埃及这边直到埃及那边，都各归各城。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯拉记 7:24; 尼希米记 13:10; 帖撒罗尼迦后书 3:10"> 唯有祭司的地，约瑟没有买，因为祭司有从法老所得的常俸。他们吃法老所给的常俸，所以他们不卖自己的地。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 112:5; 诗篇 41:1; 传道书 11:6"> 约瑟对百姓说：“我今日为法老买了你们和你们的地，看哪，这里有种子给你们，你们可以种地。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 41:34; 诗篇 41:1; 诗篇 112:5"> 后来打粮食的时候，你们要把五分之一纳给法老，四分可以归你们做地里的种子，也做你们和你们家口孩童的食物。”</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 33:15; 箴言 11:26–27; 创世记 18:3"> 他们说：“你救了我们的性命！但愿我们在我主眼前蒙恩，我们就做法老的仆人。”</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 47:22; 以西结书 7:24"> 于是约瑟为埃及地定下常例，直到今日，法老必得五分之一，唯独祭司的地不归法老。</span>
</div>
</div>

## 雅各遗命于约瑟

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="创世记 46:3; 出埃及记 1:7; 使徒行传 7:17"> 以色列人住在埃及的歌珊地，他们在那里置了产业，并且生育甚多。</span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 90:10; 创世记 47:8–9; 创世记 37:2"> 雅各住在埃及地十七年，雅各平生的年日是一百四十七岁。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 31:14; 创世记 24:49; 创世记 24:2"> 以色列的死期临近了，他就叫了他儿子约瑟来，说：“我若在你眼前蒙恩，请你把手放在我大腿底下，用慈爱和诚实待我，请你不要将我葬在埃及。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 49:29–32; 创世记 23:19; 创世记 25:9"> 我与我祖我父同睡的时候，你要将我带出埃及，葬在他们所葬的地方。”约瑟说：“我必遵着你的命而行。”</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪上 1:47; 希伯来书 11:21; 创世记 24:3"> 雅各说：“你要向我起誓。”约瑟就向他起了誓，于是以色列在床头上<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：扶着杖头。">a</a></sup>敬拜神。</span>
</div>

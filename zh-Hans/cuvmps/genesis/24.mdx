## 亚伯拉罕遣仆为子娶妻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 112:1–3; 加拉太书 3:9; 马太福音 6:33"> 亚伯拉罕年纪老迈，向来在一切事上耶和华都赐福给他。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 47:29; 创世记 39:4–6; 创世记 15:2"> 亚伯拉罕对管理他全业最老的仆人说：“请你把手放在我大腿底下，</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 6:14–17; 创世记 26:34–35; 创世记 28:8"> 我要叫你指着耶和华天地的主起誓：不要为我儿子娶这迦南地中的女子为妻，</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 28:2; 创世记 22:20–23; 创世记 12:7"> 你要往我本地本族去，为我的儿子以撒娶一个妻子。”</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 4:2; 出埃及记 9:2; 出埃及记 20:7"> 仆人对他说：“倘若女子不肯跟我到这地方来，我必须将你的儿子带回你原出之地吗？”</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 5:1; 彼得后书 2:20–22; 希伯来书 10:39"> 亚伯拉罕对他说：“你要谨慎，不要带我的儿子回那里去！</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 33:2; 创世记 13:15; 希伯来书 1:14"> 耶和华天上的主曾带领我离开父家和本族的地，对我说话，向我起誓说：‘我要将这地赐给你的后裔。’他必差遣使者在你面前，你就可以从那里为我儿子娶一个妻子。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 2:17–20; 民数记 30:5; 民数记 30:8"> 倘若女子不肯跟你来，我使你起的誓就与你无干了，只是不可带我的儿子回那里去。”</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 24:2"> 仆人就把手放在他主人亚伯拉罕的大腿底下，为这事向他起誓。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 11:31; 申命记 23:4; 创世记 27:43"> 那仆人从他主人的骆驼里取了十匹骆驼，并带些他主人各样的财物，起身往美索不达米亚去，到了拿鹤的城。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 9:11; 出埃及记 2:16; 约翰福音 4:7"> 天将晚，众女子出来打水的时候，他便叫骆驼跪在城外的水井那里。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 24:27; 出埃及记 3:6; 创世记 26:24"> 他说：“耶和华我主人亚伯拉罕的神啊，求你施恩给我主人亚伯拉罕，使我今日遇见好机会。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 24:43; 诗篇 37:5; 出埃及记 2:16"> 我现今站在井旁，城内居民的女子们正出来打水，</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 6:37; 士师记 6:17; 创世记 15:8"> 我向哪一个女子说：‘请你拿下水瓶来，给我水喝’，她若说：‘请喝，我也给你的骆驼喝’，愿那女子就做你所预定给你仆人以撒的妻。这样，我便知道你施恩给我主人了。”</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 11:29; 创世记 24:45; 以赛亚书 65:24"> 话还没有说完，不料，利百加肩头上扛着水瓶出来。利百加是彼土利所生的，彼土利是亚伯拉罕兄弟拿鹤妻子密迦的儿子。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 26:7; 民数记 31:17–18; 创世记 39:6"> 那女子容貌极其俊美，还是处女，也未曾有人亲近她。她下到井旁，打满了瓶，又上来。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 4:7; 以赛亚书 21:14; 创世记 26:1–35"> 仆人跑上前去迎着她，说：“求你将瓶里的水给我一点喝。”</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 31:26; 彼得前书 3:8; 创世记 24:14"> 女子说：“我主请喝。”就急忙拿下瓶来，托在手上给他喝。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 24:14; 彼得前书 4:9; 创世记 24:45–46"> 女子给他喝了，就说：“我再为你的骆驼打水，叫骆驼也喝足。”</span>
<span className="v" id="v20" data-v="20"> 她就急忙把瓶里的水倒在槽里，又跑到井旁打水，就为所有的骆驼打上水来。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 107:43; 创世记 24:12; 撒母耳记下 7:18–20"> 那人定睛看她，一句话也不说，要晓得耶和华赐他通达的道路没有。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 16:11–12; 出埃及记 32:2–3; 创世记 23:15–16"> 骆驼喝足了，那人就拿一个金环，重半舍客勒，两个金镯，重十舍客勒，给了那女子，</span>
<span className="v" id="v23" data-v="23"> 说：“请告诉我，你是谁的女儿？你父亲家里有我们住宿的地方没有？”</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 24:15; 创世记 22:23; 创世记 22:20"> 女子说：“我是密迦与拿鹤之子彼土利的女儿。”</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 32:8; 彼得前书 4:9; 士师记 19:19–21"> 又说：“我们家里足有粮草，也有住宿的地方。”</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 24:48; 出埃及记 4:31; 创世记 24:52"> 那人就低头向耶和华下拜，</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 24:48; 创世记 24:12; 诗篇 98:3"> 说：“耶和华我主人亚伯拉罕的神是应当称颂的！因他不断地以慈爱、诚实待我主人。至于我，耶和华在路上引领我，直走到我主人的兄弟家里。”</span>
</div>
</div>

## 拉班迎接仆人

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="创世记 24:67; 创世记 24:55; 创世记 31:33"> 女子跑回去，照着这些话告诉她母亲和她家里的人。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 29:5; 创世记 29:13; 创世记 24:55"> 利百加有一个哥哥，名叫拉班，看见金环，又看见金镯在他妹子的手上，并听见他妹子利百加的话，说“那人对我如此如此说”，拉班就跑出来往井旁去。到那人跟前，见他仍站在骆驼旁边的井旁那里，</span>
<span className="v" id="v31" data-v="31" data-xref="路得记 3:10; 创世记 26:29; 诗篇 115:15"> 便对他说：“你这蒙耶和华赐福的，请进来，为什么站在外边？我已经收拾了房屋，也为骆驼预备了地方。”</span>
</div>
</div>

## 仆人述说来意

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="士师记 19:21; 创世记 43:24; 创世记 18:4"> 那人就进了拉班的家。拉班卸了骆驼，用草料喂上，拿水给那人和跟随的人洗脚，</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 132:3–5; 提摩太前书 6:2; 以弗所书 6:5–8"> 把饭摆在他面前，叫他吃。他却说：“我不吃，等我说明白我的事情再吃。”拉班说：“请说。”</span>
<span className="v" id="v34" data-v="34"> 他说：“我是亚伯拉罕的仆人。</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 24:1; 创世记 13:2; 箴言 10:22"> 耶和华大大地赐福给我主人，使他昌大，又赐给他羊群、牛群、金银、仆婢、骆驼和驴。</span>
<span className="v" id="v36" data-v="36" data-xref="创世记 25:5; 创世记 21:10; 创世记 21:1–7"> 我主人的妻子撒拉年老的时候给我主人生了一个儿子，我主人也将一切所有的都给了这个儿子。</span>
<span className="v" id="v37" data-v="37" data-xref="创世记 27:46; 以斯拉记 9:1–3; 创世记 24:2–9"> 我主人叫我起誓说：‘你不要为我儿子娶迦南地的女子为妻。</span>
<span className="v" id="v38" data-v="38" data-xref="创世记 24:4; 创世记 31:19; 创世记 12:1"> 你要往我父家、我本族那里去，为我的儿子娶一个妻子。’</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 24:5"> 我对我主人说：‘恐怕女子不肯跟我来。’</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及记 23:20; 诗篇 16:8; 创世记 5:24"> 他就说：‘我所侍奉的耶和华必要差遣他的使者与你同去，叫你的道路通达，你就得以在我父家、我本族那里，给我的儿子娶一个妻子。</span>
<span className="v" id="v41" data-v="41" data-xref="创世记 24:8; 申命记 29:12"> 只要你到了我本族那里，我使你起的誓就与你无干。他们若不把女子交给你，我使你起的誓也与你无干。’</span>
<span className="v" id="v42" data-v="42" data-xref="尼希米记 1:11; 创世记 24:12–14; 以斯拉记 8:21"> 我今日到了井旁，便说：‘耶和华我主人亚伯拉罕的神啊，愿你叫我所行的道路通达。</span>
<span className="v" id="v43" data-v="43" data-xref="创世记 24:13–14"> 我如今站在井旁，对哪一个出来打水的女子说：“请你把你瓶里的水给我一点喝”，</span>
<span className="v" id="v44" data-v="44" data-xref="创世记 24:14; 彼得前书 3:8; 创世记 2:22"> 她若说：“你只管喝，我也为你的骆驼打水”，愿那女子就做耶和华给我主人儿子所预定的妻。’</span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 7:7; 使徒行传 12:12–17; 创世记 24:15–20"> 我心里的话还没有说完，利百加就出来，肩头上扛着水瓶，下到井旁打水。我便对她说：‘请你给我水喝。’</span>
<span className="v" id="v46" data-v="46" data-xref="创世记 24:18–19"> 她就急忙从肩头上拿下瓶来，说：‘请喝，我也给你的骆驼喝。’我便喝了，她又给我的骆驼喝了。</span>
<span className="v" id="v47" data-v="47" data-xref="诗篇 45:13–14; 创世记 24:22–24; 以赛亚书 62:3–5"> 我问她说：‘你是谁的女儿？’她说：‘我是密迦与拿鹤之子彼土利的女儿。’我就把环子戴在她鼻子上，把镯子戴在她两手上。</span>
<span className="v" id="v48" data-v="48" data-xref="箴言 3:5–6; 创世记 24:26–27; 诗篇 48:14"> 随后我低头向耶和华下拜，称颂耶和华我主人亚伯拉罕的神，因为他引导我走合适的道路，使我得着我主人兄弟的孙女，给我主人的儿子为妻。</span>
<span className="v" id="v49" data-v="49" data-xref="创世记 47:29; 约书亚记 2:14; 箴言 3:3"> 现在你们若愿以慈爱、诚实待我主人，就告诉我，若不然，也告诉我，使我可以或向左或向右。”</span>
</div>
</div>

## 拉班彼土利允诺

<div className="bt">
<div className="bp poetry">
<span className="v" id="v50" data-v="50" data-xref="诗篇 118:23; 创世记 31:24; 创世记 31:29"> 拉班和彼土利回答说：“这事乃出于耶和华，我们不能向你说好说歹。</span>
<span className="v" id="v51" data-v="51" data-xref="创世记 20:15; 创世记 24:15; 撒母耳记下 16:10"> 看哪，利百加在你面前，可以将她带去，照着耶和华所说的，给你主人的儿子为妻。”</span>
<span className="v" id="v52" data-v="52" data-xref="创世记 24:26; 创世记 24:48; 诗篇 116:1–2"> 亚伯拉罕的仆人听见他们这话，就向耶和华俯伏在地。</span>
<span className="v" id="v53" data-v="53" data-xref="创世记 24:22; 创世记 24:10; 出埃及记 12:35"> 当下仆人拿出金器、银器和衣服送给利百加，又将宝物送给她哥哥和她母亲。</span>
<span className="v" id="v54" data-v="54" data-xref="创世记 24:56; 创世记 24:59; 创世记 28:5–6"> 仆人和跟从他的人吃了喝了，住了一夜。早晨起来，仆人就说：“请打发我回我主人那里去吧。”</span>
<span className="v" id="v55" data-v="55" data-xref="创世记 4:3; 利未记 25:29; 士师记 14:8"> 利百加的哥哥和她母亲说：“让女子同我们再住几天，至少十天，然后她可以去。”</span>
<span className="v" id="v56" data-v="56" data-xref="箴言 25:25; 约书亚记 1:8; 以赛亚书 48:15"> 仆人说：“耶和华既赐给我通达的道路，你们不要耽误我，请打发我走，回我主人那里去吧。”</span>
<span className="v" id="v57" data-v="57"> 他们说：“我们把女子叫来问问她。”</span>
<span className="v" id="v58" data-v="58" data-xref="路加福音 1:38; 诗篇 45:10–11"> 就叫了利百加来，问她说：“你和这人同去吗？”利百加说：“我去。”</span>
<span className="v" id="v59" data-v="59" data-xref="创世记 35:8; 民数记 11:12; 创世记 24:50"> 于是他们打发妹子利百加和她的乳母，同亚伯拉罕的仆人，并跟从仆人的，都走了。</span>
<span className="v" id="v60" data-v="60" data-xref="创世记 22:17; 创世记 17:16; 路得记 4:11–12"> 他们就给利百加祝福说：<br /><span className="pl pl-1">“我们的妹子啊，愿你做千万人的母！</span><br /><span className="pl pl-1">愿你的后裔得着仇敌的城门！”</span></span>
</div>

## 以撒娶利百加为妻

<div className="bt">
<div className="bp">
<span className="v" id="v61" data-v="61" data-xref="诗篇 45:10; 创世记 2:24; 以斯帖记 8:14"> 利百加和她的使女们起来，骑上骆驼，跟着那仆人，仆人就带着利百加走了。</span>
<span className="v" id="v62" data-v="62" data-xref="创世记 25:11; 创世记 16:14; 创世记 12:9"> 那时，以撒住在南地，刚从庇耳拉海莱回来。</span>
<span className="v" id="v63" data-v="63" data-xref="诗篇 119:15; 诗篇 1:2; 诗篇 104:34"> 天将晚，以撒出来在田间默想，举目一看，见来了些骆驼。</span>
<span className="v" id="v64" data-v="64" data-xref="士师记 1:14; 约书亚记 15:18"> 利百加举目看见以撒，就急忙下了骆驼，</span>
<span className="v" id="v65" data-v="65" data-xref="提摩太前书 2:9; 哥林多前书 11:5–6; 哥林多前书 11:10"> 问那仆人说：“这田间走来迎接我们的是谁？”仆人说：“是我的主人。”利百加就拿帕子蒙上脸。</span>
<span className="v" id="v66" data-v="66" data-xref="马可福音 6:30"> 仆人就将所办的一切事都告诉以撒。</span>
<span className="v" id="v67" data-v="67" data-xref="雅歌 8:2; 以弗所书 5:22–33; 创世记 23:1–2"> 以撒便领利百加进了他母亲撒拉的帐篷，娶了她为妻，并且爱她。以撒自从他母亲不在了，这才得了安慰。</span>
</div>
</div>

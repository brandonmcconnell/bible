<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 18:14; 诗篇 91:15; 耶利米书 15:20"> 约瑟住在他主人埃及人的家中，耶和华与他同在，他就百事顺利。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 1:3; 创世记 30:27; 马太福音 5:16"> 他主人见耶和华与他同在，又见耶和华使他手里所办的尽都顺利，</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 39:21–22; 箴言 27:18; 创世记 19:19"> 约瑟就在主人眼前蒙恩，伺候他主人，并且主人派他管理家务，把一切所有的都交在他手里。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 30:27; 撒母耳记下 6:11–12; 使徒行传 27:24"> 自从主人派约瑟管理家务和他一切所有的，耶和华就因约瑟的缘故赐福于那埃及人的家；凡家里和田间一切所有的，都蒙耶和华赐福。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 16:12; 路加福音 19:17; 箴言 31:11"> 波提乏将一切所有的都交在约瑟的手中，除了自己所吃的饭，别的事一概不知。约瑟原来秀雅俊美。</span>

## 主母诬约瑟

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 13:11; 以西结书 16:34; 彼得后书 2:14"> 这事以后，约瑟主人的妻以目送情给约瑟，说：“你与我同寝吧！”</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 23:26–28; 箴言 22:14; 箴言 9:13–18"> 约瑟不从，对他主人的妻说：“看哪，一切家务我主人都不知道，他把所有的都交在我手里。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 12:13; 创世记 20:6; 创世记 42:18"> 在这家里没有比我大的，并且他没有留下一样不交给我，只留下了你，因为你是他的妻子。我怎能做这大恶得罪神呢？”</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前书 2:11; 创世记 39:8; 帖撒罗尼迦前书 5:22"> 后来她天天和约瑟说，约瑟却不听从她，不与她同寝，也不和她在一处。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 5:12; 以弗所书 5:3; 玛拉基书 3:5"> 有一天，约瑟进屋里去办事，家中人没有一个在那屋里。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太后书 2:22; 箴言 7:13–27; 传道书 7:26"> 妇人就拉住他的衣裳，说：“你与我同寝吧！”约瑟把衣裳丢在妇人手里，跑到外边去了。</span>
<span className="v" id="v13" data-v="13"> 妇人看见约瑟把衣裳丢在她手里跑出去了，</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 10:21; 彼得前书 2:20; 诗篇 35:11"> 就叫了家里的人来，对他们说：“你们看！他带了一个希伯来人进入我们家里，要戏弄我们。他到我这里来，要与我同寝，我就大声喊叫。</span>
<span className="v" id="v15" data-v="15"> 他听见我放声喊起来，就把衣裳丢在我这里，跑到外边去了。”</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 37:32; 耶利米书 4:22; 耶利米书 9:3–5"> 妇人把约瑟的衣裳放在自己那里，等着他主人回家，</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 23:1; 列王纪上 18:17; 诗篇 37:14"> 就对他如此如此说：“你所带到我们这里的那希伯来仆人进来要戏弄我，</span>
<span className="v" id="v18" data-v="18"> 我放声喊起来，他就把衣裳丢在我这里跑出去了。”</span>
</div>
</div>

## 波提乏囚约瑟于监

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="创世记 4:5–6; 箴言 18:17; 箴言 6:34–35"> 约瑟的主人听见他妻子对他所说的话，说“你的仆人如此如此待我”，他就生气，</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 40:15; 提摩太后书 2:9; 诗篇 105:18–19"> 把约瑟下在监里，就是王的囚犯被囚的地方。于是约瑟在那里坐监。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 3:21; 以赛亚书 41:10; 彼得前书 3:17"> 但耶和华与约瑟同在，向他施恩，使他在司狱的眼前蒙恩。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 40:3–4; 创世记 39:4; 撒母耳记上 2:30"> 司狱就把监里所有的囚犯都交在约瑟手下，他们在那里所办的事都是经他的手。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 43:2; 创世记 39:2–3; 诗篇 1:3"> 凡在约瑟手下的事，司狱一概不察，因为耶和华与约瑟同在，耶和华使他所做的尽都顺利。</span>
</div>
</div>

## 神应许亚伯兰之后裔多如众星

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 41:10; 诗篇 119:114; 诗篇 84:11"> 这事以后，耶和华在异象中有话对亚伯兰说：“亚伯兰，你不要惧怕！我是你的盾牌，必大大地赏赐你。”</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 25:21; 使徒行传 7:5; 创世记 12:1–3"> 亚伯兰说：“主耶和华啊，我既无子，你还赐我什么呢？并且要承受我家业的是大马士革人以利以谢。”</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 14:14; 箴言 29:21; 传道书 2:7"> 亚伯兰又说：“你没有给我儿子，那生在我家中的人就是我的后嗣。”</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 17:16; 加拉太书 4:28; 撒母耳记下 7:12"> 耶和华又有话对他说：“这人必不成为你的后嗣，你本身所生的才成为你的后嗣。”</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 11:12; 罗马书 4:18; 申命记 1:10"> 于是领他走到外边，说：“你向天观看，数算众星，能数得过来吗？”又对他说：“你的后裔将要如此。”</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 2:23; 加拉太书 3:6–14; 罗马书 4:9"> 亚伯兰信耶和华，耶和华就以此为他的义。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 12:1; 使徒行传 7:2–4; 罗马书 4:13"> 耶和华又对他说：“我是耶和华，曾领你出了迦勒底的吾珥，为要将这地赐你为业。”</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 1:18; 路加福音 1:34; 以赛亚书 7:11"> 亚伯兰说：“主耶和华啊，我怎能知道必得这地为业呢？”</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 2:24; 利未记 14:30; 利未记 14:22"> 他说：“你为我取一只三年的母牛，一只三年的母山羊，一只三年的公绵羊，一只斑鸠，一只雏鸽。”</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 34:18–19; 利未记 1:17; 创世记 15:17"> 亚伯兰就取了这些来，每样劈开分成两半，一半对着一半地摆列，只有鸟没有劈开。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 13:4; 诗篇 119:13; 以西结书 17:3"> 有鸷鸟下来落在那死畜的肉上，亚伯兰就把它吓飞了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 2:21; 约伯记 33:15; 但以理书 10:8–9"> 日头正落的时候，亚伯兰沉沉地睡了，忽然有惊人的大黑暗落在他身上。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 7:6–7; 出埃及记 1:11; 出埃及记 12:40–41"> 耶和华对亚伯兰说：“你要的确知道，你的后裔必寄居别人的地，又服侍那地的人，那地的人要苦待他们四百年。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 9:9–11; 出埃及记 6:5–6; 出埃及记 12:32–38"> 并且他们所要服侍的那国，我要惩罚，后来他们必带着许多财物从那里出来。</span>
<span className="v" id="v15" data-v="15" data-xref="约伯记 5:26; 创世记 25:7–9; 历代志下 34:28"> 但你要享大寿数，平平安安地归到你列祖那里，被人埋葬。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 21:26; 但以理书 8:23; 出埃及记 12:40"> 到了第四代，他们必回到此地，因为亚摩利人的罪孽还没有满盈。”</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 34:18–19; 士师记 6:21; 耶利米书 11:4"> 日落天黑，不料有冒烟的炉并烧着的火把从那些肉块中经过。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 1:3–4; 创世记 12:7; 创世记 24:7"> 当那日，耶和华与亚伯兰立约，说：“我已赐给你的后裔，从埃及河直到幼发拉底大河之地，</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 24:21–22"> 就是基尼人、基尼洗人、甲摩尼人、</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 17:5; 创世记 14:5"> 赫人、比利洗人、利乏音人、</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 10:15–19; 出埃及记 23:23–28; 申命记 7:1"> 亚摩利人、迦南人、革迦撒人、耶布斯人之地。”</span>
</div>

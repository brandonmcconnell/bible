<span className="v" id="v2" data-v="2" data-xref="创世记 15:1; 约伯记 33:14–15; 约伯记 4:13"> 夜间，神在异象中对以色列说：“雅各！雅各！”他说：“我在这里。”</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 12:2; 申命记 26:5; 以赛亚书 43:1–2"> 神说：“我是神，就是你父亲的神。你下埃及去不要害怕，因为我必使你在那里成为大族。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 3:8; 创世记 28:15; 创世记 48:21"> 我要和你同下埃及去，也必定带你上来。约瑟必给你送终<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：将手按在你的眼睛上。">a</a></sup>。”</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 45:21; 创世记 45:19; 创世记 45:27"> 雅各就从别是巴起行。以色列的儿子们使他们的父亲雅各和他们的妻子、儿女都坐在法老为雅各送来的车上。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 24:4; 以赛亚书 52:4; 使徒行传 7:15"> 他们又带着迦南地所得的牲畜、货财来到埃及。雅各和他的一切子孙都一同来了。</span>
<span className="v" id="v7" data-v="7"> 雅各把他的儿子、孙子、女儿、孙女，并他的子子孙孙，一同带到埃及。</span>
</div>

## 记雅各家下埃及者之名

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 1:1–5; 申命记 33:6; 历代志上 2:1–55"> 来到埃及的以色列人名字记在下面。雅各和他的儿孙：雅各的长子是鲁本，</span>
<span className="v" id="v9" data-v="9"> 鲁本的儿子是哈诺、法路、希斯仑、迦米。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 6:15; 创世记 29:33; 创世记 28:1"> 西缅的儿子是耶母利、雅悯、阿辖、雅斤、琐辖，还有迦南女子所生的扫罗。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 29:34; 历代志上 6:16; 民数记 8:1–26"> 利未的儿子是革顺、哥辖、米拉利。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 4:21; 创世记 38:10; 创世记 29:35"> 犹大的儿子是珥、俄南、示拉、法勒斯、谢拉，唯有珥与俄南死在迦南地；法勒斯的儿子是希斯仑、哈母勒。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 12:32; 创世记 35:23; 创世记 30:14–18"> 以萨迦的儿子是陀拉、普瓦、约伯、伸仑。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 33:18–19; 民数记 26:26–27; 民数记 1:30–31"> 西布伦的儿子是西烈、以伦、雅利。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 29:32–35; 创世记 30:17–21; 创世记 34:1–31"> 这是利亚在巴旦亚兰给雅各所生的儿子，还有女儿底拿，儿孙共三十三人。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 26:15–17; 创世记 30:11; 民数记 1:24–25"> 迦得的儿子是洗非芸、哈基、书尼、以斯本、以利、亚罗底、亚列利。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 49:20; 创世记 30:13; 民数记 1:13"> 亚设的儿子是音拿、亦施瓦、亦施韦、比利亚，还有他们的妹子西拉；比利亚的儿子是希别、玛结。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 29:24; 创世记 35:26; 创世记 30:9–13"> 这是拉班给他女儿利亚的婢女悉帕从雅各所生的儿孙，共有十六人。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 44:27; 创世记 29:18; 创世记 35:24"> 雅各之妻拉结的儿子是约瑟和便雅悯。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 41:50–52; 创世记 41:45; 申命记 33:13–17"> 约瑟在埃及地生了玛拿西和以法莲，就是安城的祭司波提非拉的女儿亚西纳给约瑟生的。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 7:6–12; 历代志上 8:1–7; 民数记 26:38–40"> 便雅悯的儿子是比拉、比结、亚实别、基拉、乃幔、以希、罗实、母平、户平、亚勒。</span>
<span className="v" id="v22" data-v="22"> 这是拉结给雅各所生的儿孙，共有十四人。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 1:38–39; 创世记 49:16–17; 民数记 1:12"> 但的儿子是户伸。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 7:13; 民数记 1:42–43; 创世记 35:25"> 拿弗他利的儿子是雅薛、沽尼、耶色、示冷。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 29:29; 创世记 35:25; 创世记 30:3–8"> 这是拉班给他女儿拉结的婢女辟拉从雅各所生的儿孙，共有七人。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 1:5; 创世记 35:11; 士师记 8:30"> 那与雅各同到埃及的，除了他儿妇之外，凡从他所生的，共有六十六人。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 10:22; 使徒行传 7:14; 出埃及记 1:5"> 还有约瑟在埃及所生的两个儿子。雅各家来到埃及的共有七十人。</span>
</div>
</div>

## 约瑟往歌珊迎父

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="创世记 45:10; 创世记 44:16–34; 创世记 49:8"> 雅各打发犹大先去见约瑟，请派人引路往歌珊去。于是他们来到歌珊地。</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 15:20; 创世记 45:14–15; 创世记 33:4"> 约瑟套车往歌珊去，迎接他父亲以色列，及至见了面，就伏在父亲的颈项上哭了许久。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 2:29–30; 创世记 45:28"> 以色列对约瑟说：“我既得见你的面，知道你还在，就是死我也甘心。”</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 47:1–3; 希伯来书 2:11; 使徒行传 18:3"> 约瑟对他的弟兄和他父的全家说：“我要上去告诉法老，对他说：‘我的弟兄和我父的全家从前在迦南地，现今都到我这里来了。</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 47:3; 列王纪上 9:27; 列王纪上 18:5–6"> 他们本是牧羊的人，以养牲畜为业。他们把羊群牛群和一切所有的都带来了。’</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 46:32; 创世记 47:2–4; 约拿书 1:8"> 等法老召你们的时候，问你们说：‘你们以何事为业？’</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 8:26; 创世记 43:32; 创世记 46:32"> 你们要说：‘你的仆人，从幼年直到如今，都以养牲畜为业，连我们的祖宗也都以此为业。’这样，你们可以住在歌珊地，因为凡牧羊的都被埃及人所厌恶。”</span>
</div>
</div>

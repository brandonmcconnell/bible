<span className="v" id="v3" data-v="3" data-xref="创世记 14:10; 出埃及记 1:14; 出埃及记 2:3"> 他们彼此商量说：“来吧！我们要做砖，把砖烧透了。”他们就拿砖当石头，又拿石漆当灰泥。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 1:28; 约翰福音 5:44; 路加福音 1:51"> 他们说：“来吧！我们要建造一座城和一座塔，塔顶通天，为要传扬我们的名，免得我们分散在全地上。”</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 18:21; 诗篇 33:13–14; 约翰福音 3:13"> 耶和华降临，要看看世人所建造的城和塔。</span>

## 变乱口音

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="诗篇 2:1–4; 创世记 3:22; 创世记 11:1"> 耶和华说：“看哪，他们成为一样的人民，都是一样的言语，如今既做起这事来，以后他们所要做的事就没有不成就的了。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 33:10; 诗篇 55:9; 约伯记 5:12–13"> 我们下去，在那里变乱他们的口音，使他们的言语彼此不通。”</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 1:51; 申命记 32:8; 创世记 10:25"> 于是，耶和华使他们从那里分散在全地上，他们就停工不造那城了。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 10:10; 创世记 10:5; 创世记 10:20"> 因为耶和华在那里变乱天下人的言语，使众人分散在全地上，所以那城名叫巴别<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是“变乱”的意思。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志上 1:17–27; 创世记 10:21–22; 路加福音 3:34–36"> 闪的后代记在下面。洪水以后二年，闪一百岁生了亚法撒。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 9:7; 诗篇 144:12; 创世记 1:28"> 闪生亚法撒之后，又活了五百年，并且生儿养女。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 3:36"> 亚法撒活到三十五岁，生了沙拉。</span>
<span className="v" id="v13" data-v="13"> 亚法撒生沙拉之后，又活了四百零三年，并且生儿养女。</span>
<span className="v" id="v14" data-v="14"> 沙拉活到三十岁，生了希伯。</span>
<span className="v" id="v15" data-v="15"> 沙拉生希伯之后，又活了四百零三年，并且生儿养女。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 10:21; 历代志上 1:19; 民数记 24:24"> 希伯活到三十四岁，生了法勒。</span>
<span className="v" id="v17" data-v="17"> 希伯生法勒之后，又活了四百三十年，并且生儿养女。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 3:35"> 法勒活到三十岁，生了拉吴。</span>
<span className="v" id="v19" data-v="19"> 法勒生拉吴之后，又活了二百零九年，并且生儿养女。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 3:35"> 拉吴活到三十二岁，生了西鹿。</span>
<span className="v" id="v21" data-v="21"> 拉吴生西鹿之后，又活了二百零七年，并且生儿养女。</span>
<span className="v" id="v22" data-v="22" data-xref="约书亚记 24:2"> 西鹿活到三十岁，生了拿鹤。</span>
<span className="v" id="v23" data-v="23"> 西鹿生拿鹤之后，又活了二百年，并且生儿养女。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 3:34; 约书亚记 24:2"> 拿鹤活到二十九岁，生了他拉。</span>
<span className="v" id="v25" data-v="25"> 拿鹤生他拉之后，又活了一百一十九年，并且生儿养女。</span>
<span className="v" id="v26" data-v="26" data-xref="约书亚记 24:2; 历代志上 1:26–27; 创世记 22:20–24"> 他拉活到七十岁，生了亚伯兰、拿鹤、哈兰。</span>
</div>
</div>

## 亚伯兰离吾珥往迦南

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="创世记 12:4; 创世记 14:12; 创世记 11:31"> 他拉的后代记在下面。他拉生亚伯兰、拿鹤、哈兰。哈兰生罗得。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 15:7; 尼希米记 9:7; 使徒行传 7:2–4"> 哈兰死在他的本地迦勒底的吾珥，在他父亲他拉之先。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 17:15; 创世记 22:20; 创世记 24:15"> 亚伯兰、拿鹤各娶了妻：亚伯兰的妻子名叫撒莱；拿鹤的妻子名叫密迦，是哈兰的女儿，哈兰是密迦和亦迦的父亲。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 29:31; 创世记 21:1–2; 路加福音 1:7"> 撒莱不生育，没有孩子。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米记 9:7; 使徒行传 7:2–4; 创世记 24:10"> 他拉带着他儿子亚伯兰和他孙子哈兰的儿子罗得，并他儿妇亚伯兰的妻子撒莱，出了迦勒底的吾珥，要往迦南地去。他们走到哈兰，就住在那里。</span>
<span className="v" id="v32" data-v="32"> 他拉共活了二百零五岁，就死在哈兰。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 22:1; 列王纪下 4:8; 箴言 13:20"> 那时，犹大离开他弟兄下去，到一个亚杜兰人名叫希拉的家里去。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 2:3; 创世记 24:3; 创世记 6:2"> 犹大在那里看见一个迦南人名叫书亚的女儿，就娶她为妻，与她同房。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 46:12; 民数记 26:19"> 她就怀孕，生了儿子，犹大给他起名叫珥。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 46:12; 民数记 26:19"> 她又怀孕，生了儿子，母亲给他起名叫俄南。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 26:20; 创世记 38:26; 创世记 46:12"> 她复又生了儿子，给他起名叫示拉。她生示拉的时候，犹大正在基悉。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 24:3; 创世记 21:21; 马太福音 1:3"> 犹大为长子珥娶妻，名叫她玛。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 2:3; 创世记 46:12; 民数记 26:19"> 犹大的长子珥在耶和华眼中看为恶，耶和华就叫他死了。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 25:5–10; 马太福音 22:23–27; 路得记 4:5–11"> 犹大对俄南说：“你当与你哥哥的妻子同房，向她尽你为弟的本分，为你哥哥生子立后。”</span>
<span className="v" id="v9" data-v="9" data-xref="提多书 3:3; 申命记 25:6; 雅各书 3:16"> 俄南知道生子不归自己，所以同房的时候便遗在地，免得给他哥哥留后。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 46:12; 民数记 11:1; 历代志上 21:7"> 俄南所做的在耶和华眼中看为恶，耶和华也就叫他死了。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 22:13; 路得记 1:11–13"> 犹大心里说：“恐怕示拉也死，像他两个哥哥一样”，就对他儿妇她玛说：“你去，在你父亲家里守寡，等我儿子示拉长大。”她玛就回去，住在她父亲家里。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约书亚记 15:10; 撒母耳记下 13:39; 士师记 14:1"> 过了许久，犹大的妻子书亚的女儿死了。犹大得了安慰，就和他朋友亚杜兰人希拉上亭拿去，到他剪羊毛的人那里。</span>
<span className="v" id="v13" data-v="13"> 有人告诉她玛说：“你的公公上亭拿剪羊毛去了。”</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 38:26; 创世记 38:11–13; 耶利米书 3:2"> 她玛见示拉已经长大，还没有娶她为妻，就脱了她做寡妇的衣裳，用帕子蒙着脸，又遮住身体，坐在亭拿路上的伊拿印城门口。</span>
<span className="v" id="v15" data-v="15"> 犹大看见她，以为是妓女，因为她蒙着脸。</span>
<span className="v" id="v16" data-v="16" data-xref="提摩太前书 6:10; 马太福音 26:15; 撒母耳记下 13:11"> 犹大就转到她那里去，说：“来吧，让我与你同寝。”他原不知道是他的儿妇。她玛说：“你要与我同寝，把什么给我呢？”</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 16:33; 创世记 38:20; 箴言 20:16"> 犹大说：“我从羊群里取一只山羊羔，打发人送来给你。”她玛说：“在未送以先，你愿意给我一个当头吗？”</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 38:25–26; 何西阿书 4:11; 耶利米书 22:24"> 他说：“我给你什么当头呢？”她玛说：“你的印、你的带子和你手里的杖。”犹大就给了她，与她同寝，她就从犹大怀了孕。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 38:14; 撒母耳记下 14:5; 撒母耳记下 14:2"> 她玛起来走了，除去帕子，仍旧穿上做寡妇的衣裳。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 20:9; 利未记 19:17; 撒母耳记下 13:3"> 犹大托他朋友亚杜兰人送一只山羊羔去，要从那女人手里取回当头来，却找不着她，</span>
<span className="v" id="v21" data-v="21"> 就问那地方的人说：“伊拿印路旁的妓女在哪里？”他们说：“这里并没有妓女。”</span>
<span className="v" id="v22" data-v="22"> 他回去见犹大说：“我没有找着她，并且那地方的人说这里没有妓女。”</span>
<span className="v" id="v23" data-v="23" data-xref="以弗所书 5:12; 箴言 6:33; 启示录 16:15"> 犹大说：“我把这山羊羔送去了，你竟找不着她。任凭她拿去吧，免得我们被羞辱。”</span>
</div>

## 她玛孪生二子

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="利未记 21:9; 以西结书 23:19; 士师记 19:2"> 约过了三个月，有人告诉犹大说：“你的儿妇她玛做了妓女，且因行淫有了身孕。”犹大说：“拉出她来，把她烧了！”</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 37:32; 创世记 38:18; 哥林多前书 4:5"> 她玛被拉出来的时候，便打发人去见她公公，对他说：“这些东西是谁的，我就是从谁怀的孕。请你认一认这印和带子并杖都是谁的？”</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记上 24:17; 约翰福音 8:9; 提多书 2:11–12"> 犹大承认说：“她比我更有义，因为我没有将她给我的儿子示拉。”从此犹大不再与她同寝了。</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 25:24"> 她玛将要生产，不料她腹里是一对双生。</span>
<span className="v" id="v28" data-v="28"> 到生产的时候，一个孩子伸出一只手来，收生婆拿红线拴在他手上，说：“这是头生的。”</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 2:4; 马太福音 1:3; 创世记 46:12"> 随后这孩子把手收回去，他哥哥生出来了。收生婆说：“你为什么抢着来呢？”因此给他起名叫法勒斯。</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 9:6; 历代志上 2:4; 马太福音 1:3"> 后来他兄弟，那手上有红线的也生出来，就给他起名叫谢拉。</span>

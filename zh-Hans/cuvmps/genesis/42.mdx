## 雅各遣子往埃及籴粮

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 7:12; 约书亚记 7:10; 列王纪下 8:3–4"> 雅各见埃及有粮，就对儿子们说：“你们为什么彼此观望呢？</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 43:8; 创世记 45:9; 创世记 43:2"> 我听见埃及有粮，你们可以下去，从那里为我们籴些来，使我们可以存活，不至于死。”</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 42:5; 创世记 42:13"> 于是，约瑟的十个哥哥都下埃及籴粮去了。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 42:38; 创世记 43:29; 创世记 11:4"> 但约瑟的兄弟便雅悯，雅各没有打发他和哥哥们同去，因为雅各说：“恐怕他遭害。”</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 41:57; 使徒行传 7:11; 创世记 12:10"> 来籴粮的人中有以色列的儿子们，因为迦南地也有饥荒。</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 3:9; 创世记 37:7–10; 创世记 41:40–41"> 当时治理埃及地的是约瑟，粜粮给那地众民的就是他。约瑟的哥哥们来了，脸伏于地，向他下拜。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 42:30; 创世记 42:14–17; 马太福音 15:23–26"> 约瑟看见他哥哥们，就认得他们，却装作生人，向他们说些严厉话，问他们说：“你们从哪里来？”他们说：“我们从迦南地来籴粮。”</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 37:2; 约翰福音 20:14; 路加福音 24:16"> 约瑟认得他哥哥们，他们却不认得他。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 37:5–9; 出埃及记 32:35; 约书亚记 2:1"> 约瑟想起从前所做的那两个梦，就对他们说：“你们是奸细，来窥探这地的虚实。”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 37:8; 撒母耳记上 26:17; 创世记 27:37"> 他们对他说：“我主啊，不是的，仆人们是籴粮来的。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 42:19; 哥林多后书 6:4; 约翰福音 7:18"> 我们都是一个人的儿子，是诚实人，仆人们并不是奸细。”</span>
<span className="v" id="v12" data-v="12"> 约瑟说：“不然！你们必是窥探这地的虚实来的。”</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 37:30; 创世记 42:32; 创世记 44:20"> 他们说：“仆人们本是弟兄十二人，是迦南地一个人的儿子，顶小的现今在我们的父亲那里，有一个没有了。”</span>
</div>
</div>

## 约瑟囚兄令携弟至

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 15:21–28; 约伯记 13:24; 创世记 42:9–11"> 约瑟说：“我才说你们是奸细，这话实在不错！</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 17:55; 耶利米书 5:7; 创世记 42:16"> 我指着法老的性命起誓，若是你们的小兄弟不到这里来，你们就不得出这地方，从此就可以把你们证验出来了。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 42:11"> 须要打发你们中间一个人去，把你们的兄弟带来。至于你们，都要囚在这里，好证验你们的话真不真。若不真，我指着法老的性命起誓，你们一定是奸细。”</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 40:4; 希伯来书 12:10; 创世记 40:7"> 于是约瑟把他们都下在监里三天。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未记 25:43; 尼希米记 5:15; 路加福音 18:2"> 到了第三天，约瑟对他们说：“我是敬畏神的，你们照我的话行就可以存活。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 45:23; 以赛亚书 42:7; 创世记 40:3"> 你们如果是诚实人，可以留你们中间的一个人囚在监里；但你们可以带着粮食回去，救你们家里的饥荒。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 44:23; 创世记 43:5; 创世记 42:34"> 把你们的小兄弟带到我这里来，如此你们的话便有证据，你们也不至于死。”他们就照样而行。</span>
<span className="v" id="v21" data-v="21" data-xref="何西阿书 5:15; 马可福音 9:43–45; 创世记 37:23–28"> 他们彼此说：“我们在兄弟身上实在有罪。他哀求我们的时候，我们见他心里的愁苦，却不肯听，所以这场苦难临到我们身上。”</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 24:22; 诗篇 9:12; 列王纪上 2:32"> 鲁本说：“我岂不是对你们说过不可伤害那孩子吗？只是你们不肯听，所以流他血的罪向我们追讨。”</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 5:20; 约翰福音 16:13–14"> 他们不知道约瑟听得出来，因为在他们中间用通事传话。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 43:30; 犹大书 1:22–23; 希伯来书 4:15"> 约瑟转身退去，哭了一场，又回来对他们说话，就从他们中间挑出西缅来，在他们眼前把他捆绑。</span>
<span className="v" id="v25" data-v="25" data-xref="彼得前书 3:9; 罗马书 12:17–21; 创世记 45:21"> 约瑟吩咐人把粮食装满他们的器具，把各人的银子归还在各人的口袋里，又给他们路上用的食物。人就照他的话办了。</span>
</div>
</div>

## 见金在囊则惧

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26"> 他们就把粮食驮在驴上，离开那里去了。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 4:24; 路加福音 2:7; 路加福音 10:34"> 到了住宿的地方，他们中间有一个人打开口袋，要拿料喂驴，才看见自己的银子仍在口袋里，</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 45:7; 耶利米哀歌 3:37; 创世记 42:36"> 就对弟兄们说：“我的银子归还了，看哪，仍在我口袋里！”他们就提心吊胆，战战兢兢地彼此说：“这是神向我们做什么呢？”</span>
<span className="v" id="v29" data-v="29"> 他们来到迦南地他们的父亲雅各那里，将所遭遇的事都告诉他，说：</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 42:7"> “那地的主对我们说严厉的话，把我们当做窥探那地的奸细。</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 42:11"> 我们对他说：‘我们是诚实人，并不是奸细。</span>
<span className="v" id="v32" data-v="32"> 我们本是弟兄十二人，都是一个父亲的儿子，有一个没有了，顶小的如今同我们的父亲在迦南地。’</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 42:19–20; 创世记 42:15"> 那地的主对我们说：‘若要我知道你们是诚实人，可以留下你们中间的一个人在我这里，你们可以带着粮食回去，救你们家里的饥荒。</span>
<span className="v" id="v34" data-v="34" data-xref="创世记 34:10; 创世记 34:21; 列王纪上 10:15"> 把你们的小兄弟带到我这里来，我便知道你们不是奸细，乃是诚实人。这样，我就把你们的弟兄交给你们，你们也可以在这地做买卖。’”</span>
</div>
</div>

## 雅各不容携幼子去

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="创世记 43:21; 创世记 43:12; 创世记 43:15"> 后来他们倒口袋，不料，各人的银包都在口袋里。他们和父亲看见银包就都害怕。</span>
<span className="v" id="v36" data-v="36" data-xref="创世记 43:14; 罗马书 8:31; 以赛亚书 27:9"> 他们的父亲雅各对他们说：“你们使我丧失我的儿子，约瑟没有了，西缅也没有了，你们又要将便雅悯带去，这些事都归到我身上了！”</span>
<span className="v" id="v37" data-v="37" data-xref="创世记 46:9; 弥迦书 6:7; 创世记 43:9"> 鲁本对他父亲说：“我若不带他回来交给你，你可以杀我的两个儿子。只管把他交在我手里，我必带他回来交给你。”</span>
<span className="v" id="v38" data-v="38" data-xref="创世记 37:35; 创世记 42:4; 创世记 37:33"> 雅各说：“我的儿子不可与你们一同下去。他哥哥死了，只剩下他，他若在你们所行的路上遭害，那便是你们使我白发苍苍、悲悲惨惨地下阴间去了。”</span>
</div>

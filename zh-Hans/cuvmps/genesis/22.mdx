## 神试验亚伯拉罕

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 11:17; 雅各书 2:21; 申命记 8:2"> 这些事以后，神要试验亚伯拉罕，就呼叫他说：“亚伯拉罕！”他说：“我在这里。”</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 3:16; 罗马书 8:32; 希伯来书 11:17"> 神说：“你带着你的儿子，就是你独生的儿子，你所爱的以撒，往摩利亚地去，在我所要指示你的山上，把他献为燔祭。”</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 119:60; 马太福音 10:37; 路加福音 14:26"> 亚伯拉罕清早起来，备上驴，带着两个仆人和他儿子以撒，也劈好了燔祭的柴，就起身往神所指示他的地方去了。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 13:32; 马太福音 17:23; 何西阿书 6:2"> 到了第三日，亚伯拉罕举目远远地看见那地方。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 11:19; 希伯来书 12:1"> 亚伯拉罕对他的仆人说：“你们和驴在此等候，我与童子往那里去拜一拜，就回到你们这里来。”</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 19:17; 彼得前书 2:24; 以赛亚书 53:6"> 亚伯拉罕把燔祭的柴放在他儿子以撒身上，自己手里拿着火与刀，于是二人同行。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:15; 马太福音 26:39; 创世记 8:20"> 以撒对他父亲亚伯拉罕说：“父亲哪！”亚伯拉罕说：“我儿，我在这里。”以撒说：“请看，火与柴都有了，但燔祭的羊羔在哪里呢？”</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 1:36; 约翰福音 1:29; 启示录 5:12"> 亚伯拉罕说：“我儿，神必自己预备做燔祭的羊羔。”于是二人同行。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="雅各书 2:21; 希伯来书 11:17–19; 腓立比书 2:7–8"> 他们到了神所指示的地方，亚伯拉罕在那里筑坛，把柴摆好，捆绑他的儿子以撒，放在坛的柴上。</span>
<span className="v" id="v10" data-v="10" data-xref="雅各书 2:21–23; 希伯来书 11:17–19; 以赛亚书 53:6–12"> 亚伯拉罕就伸手拿刀，要杀他的儿子。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 21:17; 出埃及记 3:4; 创世记 16:9–10"> 耶和华的使者从天上呼叫他说：“亚伯拉罕！亚伯拉罕！”他说：“我在这里。”</span>
<span className="v" id="v12" data-v="12" data-xref="雅各书 2:21–22; 雅各书 2:18; 撒母耳记上 15:22"> 天使说：“你不可在这童子身上下手，一点不可害他。现在我知道你是敬畏神的了，因为你没有将你的儿子，就是你独生的儿子，留下不给我。”</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 10:13; 诗篇 40:6–8; 哥林多后书 1:9–10"> 亚伯拉罕举目观看，不料，有一只公羊，两角扣在稠密的小树中。亚伯拉罕就取了那只公羊来，献为燔祭，代替他的儿子。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 22:13; 出埃及记 17:15; 创世记 22:8"> 亚伯拉罕给那地方起名叫耶和华以勒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="意思就是“耶和华必预备”。">a</a></sup>，直到今日人还说：“在耶和华的山上必有预备。”</span>
<span className="v" id="v15" data-v="15"> 耶和华的使者第二次从天上呼叫亚伯拉罕说：</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 6:13–14; 路加福音 1:73; 诗篇 105:9"> “耶和华说：‘你既行了这事，不留下你的儿子，就是你独生的儿子，我便指着自己起誓说：</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 15:5; 创世记 24:60; 耶利米书 33:22"> 论福，我必赐大福给你；论子孙，我必叫你的子孙多起来，如同天上的星，海边的沙；你子孙必得着仇敌的城门；</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 3:25; 创世记 12:3; 加拉太书 3:16"> 并且地上万国都必因你的后裔得福，因为你听从了我的话。’”</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 21:31; 士师记 20:1; 约书亚记 15:28"> 于是亚伯拉罕回到他仆人那里，他们一同起身往别是巴去，亚伯拉罕就住在别是巴。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 11:29; 创世记 24:24; 箴言 25:25"> 这事以后，有人告诉亚伯拉罕说：“密迦给你兄弟拿鹤生了几个儿子，</span>
<span className="v" id="v21" data-v="21" data-xref="约伯记 1:1; 约伯记 32:2; 诗篇 60:1–12"> 长子是乌斯，他的兄弟是布斯，和亚兰的父亲基母利，</span>
<span className="v" id="v22" data-v="22"> 并基薛、哈琐、必达、益拉、彼土利（彼土利生利百加）。”</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 24:15; 创世记 28:5; 创世记 24:51"> 这八个人都是密迦给亚伯拉罕的兄弟拿鹤生的。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 16:3; 创世记 25:6; 箴言 15:25"> 拿鹤的妾名叫流玛，生了提八、迦含、他辖和玛迦。</span>
</div>
</div>

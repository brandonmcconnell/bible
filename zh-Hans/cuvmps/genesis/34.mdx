## 雅各子用计戮示剑族

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 30:21; 耶利米书 2:36; 创世记 30:13"> 利亚给雅各所生的女儿底拿出去，要见那地的女子们。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 5:28; 约伯记 31:1; 约伯记 31:9"> 那地的主希未人哈抹的儿子示剑看见她，就拉住她，与她行淫，玷辱她。</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿书 2:14; 以赛亚书 40:2; 历代志下 30:22"> 示剑的心系恋雅各的女儿底拿，喜爱这女子，甜言蜜语地安慰她。</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 14:2; 撒母耳记下 13:13; 创世记 21:21"> 示剑对他父亲哈抹说：“求你为我聘这女子为妻。”</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 13:22; 利未记 10:3; 撒母耳记上 10:27"> 雅各听见示剑玷污了他的女儿底拿。那时他的儿子们正和群畜在田野，雅各就闭口不言，等他们回来。</span>
<span className="v" id="v6" data-v="6"> 示剑的父亲哈抹出来见雅各，要和他商议。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 7:15; 士师记 20:6; 申命记 22:21"> 雅各的儿子们听见这事，就从田野回来，人人愤恨，十分恼怒，因示剑在以色列家做了丑事，与雅各的女儿行淫，这本是不该做的事。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 11:2; 诗篇 119:20; 诗篇 84:2"> 哈抹和他们商议说：“我儿子示剑的心恋慕这女子，求你们将她给我的儿子为妻。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 7:3; 创世记 26:34–35; 创世记 19:14"> 你们与我们彼此结亲，你们可以把女儿给我们，也可以娶我们的女儿。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 20:15; 创世记 47:27; 创世记 42:34"> 你们与我们同住吧，这地都在你们面前，只管在此居住，做买卖，置产业。”</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 33:15; 创世记 18:3"> 示剑对女儿的父亲和弟兄们说：“但愿我在你们眼前蒙恩，你们向我要什么，我必给你们。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 22:16–17; 申命记 22:28–29; 撒母耳记上 18:25–27"> 任凭向我要多重的聘金和礼物，我必照你们所说的给你们，只要把女子给我为妻。”</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 25:27–34; 以赛亚书 59:13; 约伯记 13:4"> 雅各的儿子们因为示剑玷污了他们的妹子底拿，就用诡诈的话回答示剑和他父亲哈抹，</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 23:1–39; 撒母耳记下 15:7; 创世记 17:11"> 对他们说：“我们不能把我们的妹子给没有受割礼的人为妻，因为那是我们的羞辱。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 4:12"> 唯有一件才可以应允：若你们所有的男丁都受割礼，和我们一样，</span>
<span className="v" id="v16" data-v="16"> 我们就把女儿给你们，也娶你们的女儿，我们便与你们同住，两下成为一样的人民。</span>
<span className="v" id="v17" data-v="17"> 倘若你们不听从我们受割礼，我们就带着妹子走了。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 哈抹和他的儿子示剑喜欢这话。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 17:12; 使徒行传 13:50; 撒母耳记上 22:14"> 那少年人做这事并不迟延，因为他喜爱雅各的女儿，他在他父亲家中也是人最尊重的。</span>
<span className="v" id="v20" data-v="20" data-xref="路得记 4:1; 箴言 31:23; 阿摩司书 5:12"> 哈抹和他儿子示剑到本城的门口，对本城的人说：</span>
<span className="v" id="v21" data-v="21"> “这些人与我们和睦，不如许他们在这地居住、做买卖。这地也宽阔，足可容下他们。我们可以娶他们的女儿为妻，也可以把我们的女儿嫁给他们。</span>
<span className="v" id="v22" data-v="22"> 唯有一件事我们必须做，他们才肯应允和我们同住，成为一样的人民，就是我们中间所有的男丁都要受割礼，和他们一样。</span>
<span className="v" id="v23" data-v="23" data-xref="箴言 1:12–13; 约翰福音 6:26–27; 约翰福音 2:16"> 他们的群畜、货财和一切的牲口岂不都归我们吗？只要依从他们，他们就与我们同住。”</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 23:10; 哥林多前书 7:19; 以赛亚书 1:10–16"> 凡从城门出入的人就都听从哈抹和他儿子示剑的话，于是凡从城门出入的男丁都受了割礼。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 49:5–7; 创世记 29:33–34; 民数记 31:7"> 到第三天，众人正在疼痛的时候，雅各的两个儿子，就是底拿的哥哥西缅和利未，各拿刀剑，趁着众人想不到的时候来到城中，把一切男丁都杀了，</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 2:26; 申命记 32:42; 以赛亚书 31:8"> 又用刀杀了哈抹和他儿子示剑，把底拿从示剑家里带出来就走了。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 7:13; 约书亚记 7:21; 出埃及记 2:14"> 雅各的儿子们因为他们的妹子受了玷污，就来到被杀的人那里，掳掠那城，</span>
<span className="v" id="v28" data-v="28" data-xref="约伯记 1:15–16; 申命记 8:17–18; 约伯记 20:5"> 夺了他们的羊群、牛群和驴，并城里田间所有的，</span>
<span className="v" id="v29" data-v="29"> 又把他们一切货财、孩子、妇女，并各房中所有的，都掳掠去了。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 105:12; 约书亚记 7:25; 出埃及记 5:21"> 雅各对西缅和利未说：“你们连累我，使我在这地的居民中，就是在迦南人和比利洗人中，有了臭名。我的人丁既然稀少，他们必聚集来击杀我，我和全家的人都必灭绝。”</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 6:34; 创世记 34:13; 创世记 49:7"> 他们说：“他岂可待我们的妹子如同妓女吗？”</span>
</div>
</div>

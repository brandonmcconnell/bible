## 以扫之后裔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 22:17; 历代志上 1:35; 申命记 23:7"> 以扫，就是以东，他的后代记在下面。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 36:25; 创世记 28:9; 创世记 9:25"> 以扫娶迦南的女子为妻，就是赫人以伦的女儿亚大和希未人祭便的孙女、亚拿的女儿阿荷利巴玛，</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 28:9; 创世记 25:13"> 又娶了以实玛利的女儿、尼拜约的妹子巴实抹。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 1:35; 出埃及记 2:18; 约伯记 2:11"> 亚大给以扫生了以利法，巴实抹生了流珥，</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 35:29"> 阿荷利巴玛生了耶乌施、雅兰、可拉。这都是以扫的儿子，是在迦南地生的。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 32:3; 创世记 12:5; 创世记 17:8"> 以扫带着他的妻子、儿女与家中一切的人口，并他的牛羊、牲畜和一切货财，就是他在迦南地所得的，往别处去，离了他兄弟雅各。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 13:6; 创世记 17:8; 创世记 28:4"> 因为二人的财物群畜甚多，寄居的地方容不下他们，所以不能同居。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 32:3; 玛拉基书 1:3; 以西结书 35:2–7"> 于是，以扫住在西珥山里，以扫就是以东。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 19:37"> 以扫是西珥山里以东人的始祖，他的后代记在下面。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 36:3–4; 历代志上 1:35–54"> 以扫众子的名字如下：以扫的妻子亚大生以利法，以扫的妻子巴实抹生流珥。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 36:15–16; 历代志上 1:35–36"> 以利法的儿子是提幔、阿抹、洗玻、迦坦、基纳斯。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 17:8–16; 申命记 25:17–19; 撒母耳记上 15:2–9"> 亭纳是以扫儿子以利法的妾，她给以利法生了亚玛力。这是以扫的妻子亚大的子孙。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 1:37; 创世记 36:17"> 流珥的儿子是拿哈、谢拉、沙玛、米撒。这是以扫妻子巴实抹的子孙。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 36:2; 创世记 36:18; 历代志上 1:35"> 以扫的妻子阿荷利巴玛是祭便的孙女、亚拿的女儿，她给以扫生了耶乌施、雅兰、可拉。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="俄巴底亚书 1:9; 约伯记 2:11; 创世记 36:11–12"> 以扫子孙中做族长的记在下面。以扫的长子以利法的子孙中，有提幔族长、阿抹族长、洗玻族长、基纳斯族长、</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 15:15"> 可拉族长、迦坦族长、亚玛力族长。这是在以东地从以利法所出的族长，都是亚大的子孙。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 36:13; 历代志上 1:37; 创世记 36:4"> 以扫的儿子流珥的子孙中，有拿哈族长、谢拉族长、沙玛族长、米撒族长。这是在以东地从流珥所出的族长，都是以扫妻子巴实抹的子孙。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 36:14; 历代志上 1:35; 创世记 36:5"> 以扫的妻子阿荷利巴玛的子孙中，有耶乌施族长、雅兰族长、可拉族长。这是从以扫妻子，亚拿的女儿阿荷利巴玛子孙中所出的族长。</span>
<span className="v" id="v19" data-v="19"> 以上的族长都是以扫的子孙，以扫就是以东。</span>
</div>
</div>

## 西珥之后裔

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命记 2:12; 申命记 2:22; 创世记 14:6"> 那地原有的居民何利人西珥的子孙记在下面，就是罗坍、朔巴、祭便、亚拿、</span>
<span className="v" id="v21" data-v="21"> 底顺、以察、底珊。这是从以东地的何利人西珥子孙中所出的族长。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 1:39"> 罗坍的儿子是何利、希幔，罗坍的妹子是亭纳。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 1:40"> 朔巴的儿子是亚勒文、玛拿辖、以巴录、示玻、阿南。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 2:10; 撒母耳记下 18:9; 列王纪上 4:28"> 祭便的儿子是亚雅、亚拿（当时在旷野放他父亲祭便的驴，遇着温泉的，就是这亚拿）。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 36:2; 创世记 36:18; 历代志上 1:41"> 亚拿的儿子是底顺，亚拿的女儿是阿荷利巴玛。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志上 1:41"> 底顺的儿子是欣但、伊是班、益兰、基兰。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志上 1:42; 创世记 36:21; 历代志上 1:38"> 以察的儿子是辟罕、撒番、亚干。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米哀歌 4:21; 约伯记 1:1; 耶利米书 25:20"> 底珊的儿子是乌斯、亚兰。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 36:20; 创世记 36:28; 历代志上 1:41–42"> 从何利人所出的族长记在下面，就是罗坍族长、朔巴族长、祭便族长、亚拿族长、</span>
<span className="v" id="v30" data-v="30" data-xref="但以理书 7:23; 以赛亚书 23:15; 列王纪下 11:19"> 底顺族长、以察族长、底珊族长。这是从何利人所出的族长，都在西珥地，按着宗族做族长。</span>
</div>
</div>

## 记以东诸王

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="创世记 17:6; 历代志上 1:43–50; 创世记 17:16"> 以色列人未有君王治理以先，在以东地做王的记在下面。</span>
<span className="v" id="v32" data-v="32"> 比珥的儿子比拉在以东做王，他的京城名叫亭哈巴。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 49:13; 耶利米书 49:22; 阿摩司书 1:12"> 比拉死了，波斯拉人谢拉的儿子约巴接续他做王。</span>
<span className="v" id="v34" data-v="34" data-xref="创世记 36:11; 约伯记 2:11; 创世记 36:15"> 约巴死了，提幔地的人户珊接续他做王。</span>
<span className="v" id="v35" data-v="35"> 户珊死了，比达的儿子哈达接续他做王，这哈达就是在摩押地杀败米甸人的，他的京城名叫亚未得。</span>
<span className="v" id="v36" data-v="36" data-xref="历代志上 1:47"> 哈达死了，玛士利加人桑拉接续他做王。</span>
<span className="v" id="v37" data-v="37" data-xref="历代志上 1:48; 创世记 10:11"> 桑拉死了，大河边的利河伯人扫罗接续他做王。</span>
<span className="v" id="v38" data-v="38"> 扫罗死了，亚革波的儿子巴勒哈南接续他做王。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及记 15:15; 历代志上 1:50"> 亚革波的儿子巴勒哈南死了，哈达接续他做王，他的京城名叫巴乌，他的妻子名叫米希她别，是米萨合的孙女、玛特列的女儿。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="历代志上 1:51–54; 出埃及记 15:15; 创世记 36:31"> 从以扫所出的族长，按着他们的宗族、住处，名字记在下面，就是亭纳族长、亚勒瓦族长、耶帖族长、</span>
<span className="v" id="v41" data-v="41"> 阿何利巴玛族长、以拉族长、比嫩族长、</span>
<span className="v" id="v42" data-v="42"> 基纳斯族长、提幔族长、米比萨族长、</span>
<span className="v" id="v43" data-v="43" data-xref="创世记 45:8; 历代志上 4:14; 创世记 25:30"> 玛基叠族长、以兰族长。这是以东人在所得为业的地上，按着他们的住处，所有的族长都是以东人的始祖以扫的后代。</span>
</div>
</div>

## 安息日医治驼背的女人

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 4:23; 路加福音 4:44; 路加福音 4:15–16"> 安息日，耶稣在会堂里教训人。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 8:2; 路加福音 8:27; 路加福音 13:16"> 有一个女人被鬼附着，病了十八年，腰弯得一点直不起来。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 107:20; 马太福音 8:16; 路加福音 6:8–10"> 耶稣看见，便叫过她来，对她说：<span className="woj">“女人，你脱离这病了！”</span></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 107:20–22; 马可福音 16:18; 马可福音 5:23"> 于是用两只手按着她，她立刻直起腰来，就归荣耀于神。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 20:9; 马太福音 12:2; 约翰福音 9:14–16"> 管会堂的因为耶稣在安息日治病，就气愤愤地对众人说：“有六日应当做工，那六日之内可以来求医，在安息日却不可。”</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 14:5; 约翰福音 7:21–24; 使徒行传 13:9–10"> 主说：<span className="woj">“假冒为善的人哪，难道你们各人在安息日不解开槽上的牛、驴，牵去饮吗？</span></span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 2:27; 提摩太后书 2:26; 路加福音 19:9"> <span className="woj">况且这女人本是亚伯拉罕的后裔，被撒旦捆绑了这十八年，不当在安息日解开她的绑吗？”</span></span>
<span className="v" id="v17" data-v="17" data-xref="彼得前书 3:16; 诗篇 132:18; 以赛亚书 45:24"> 耶稣说这话，他的敌人都惭愧了；众人因他所行一切荣耀的事，就都欢喜了。</span>
</div>
</div>

<div className="bt">
<div className="bp">

## 当进窄门

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 9:51; 马太福音 9:35; 马可福音 10:32–34"> 耶稣往耶路撒冷去，在所经过的各城各乡教训人。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 7:14; 马太福音 22:14; 约翰福音 21:21–22"> 有一个人问他说：“主啊，得救的人少吗？”</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 7:13–14; 彼得后书 1:10; 哥林多前书 9:24–27"> 耶稣对众人说：<span className="woj">“你们要努力进窄门。我告诉你们：将来有许多人想要进去，却是不能。</span></span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 25:10–12; 路加福音 13:27; 马太福音 7:21–23"> <span className="woj">及至家主起来关了门，你们站在外面叩门，说：‘主啊，给我们开门！’他就回答说：‘我不认识你们，不晓得你们是哪里来的。’</span></span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 58:2; 提多书 1:16; 提摩太后书 3:5"> <span className="woj">那时，你们要说：‘我们在你面前吃过、喝过，你也在我们的街上教训过人。’</span></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 6:8; 马太福音 25:41; 马太福音 7:22–23"> <span className="woj">他要说：‘我告诉你们</span>，<span className="woj">我不晓得你们是哪里来的。你们这一切作恶的人，离开我去吧！’</span></span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 8:11–12; 马太福音 22:13; 马太福音 25:30"> <span className="woj">你们要看见亚伯拉罕、以撒、雅各和众先知都在神的国里，你们却被赶到外面，在那里必要哀哭切齿了。</span></span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 43:6; 以赛亚书 66:18–20; 以赛亚书 49:6"> <span className="woj">从东、从西、从南、从北将有人来，在神的国里坐席。</span></span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 19:30; 马可福音 10:31; 马太福音 20:16"> <span className="woj">只是有在后的将要在前，有在前的将要在后。”</span></span>
</div>
</div>

## 叹息耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="尼希米记 6:9–11; 诗篇 11:1–2; 马太福音 14:1"> 正当那时，有几个法利赛人来对耶稣说：“离开这里去吧，因为希律想要杀你。”</span>
<span className="v" id="v32" data-v="32" data-xref="希伯来书 2:10; 希伯来书 5:9; 约翰福音 17:4–5"> 耶稣说：<span className="woj">“你们去告诉那个狐狸说，今天、明天我赶鬼治病，第三天我的事就成全了。</span></span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 9:53; 马太福音 21:11; 使徒行传 13:27"> <span className="woj">虽然这样，今天、明天、后天我必须前行，因为先知在耶路撒冷之外丧命是不能的。</span></span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 23:37–39; 申命记 32:11–12; 使徒行传 7:52"> <span className="woj">耶路撒冷啊，耶路撒冷啊！你常杀害先知，又用石头打死那奉差遣到你这里来的人。我多次愿意聚集你的儿女，好像母鸡把小鸡聚集在翅膀底下，只是你们不愿意。</span></span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 118:26; 马可福音 11:9–10; 马太福音 21:9"> <span className="woj">看哪，你们的家成为荒场留给你们！我告诉你们：从今以后你们不得再见我，直等到你们说：‘奉主名来的是应当称颂的！’”</span></span>
</div>

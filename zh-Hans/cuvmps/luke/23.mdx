## 将耶稣解交彼拉多

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 27:1–2; 马太福音 27:11–14; 路加福音 22:66"> 众人都起来，把耶稣解到彼拉多面前，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 17:6–7; 约翰福音 19:12; 路加福音 23:14"> 就告他说：“我们见这人诱惑国民，禁止纳税给凯撒，并说自己是基督，是王。”</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 1:49; 提摩太前书 6:13; 路加福音 22:70"> 彼拉多问耶稣说：“你是犹太人的王吗？”耶稣回答说：<span className="woj">“你说的是。”</span></span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 18:38; 路加福音 23:14–15; 路加福音 23:22"> 彼拉多对祭司长和众人说：“我查不出这人有什么罪来。”</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 1:14; 约翰福音 1:43; 约翰福音 2:11"> 但他们越发极力地说：“他煽惑百姓，在犹太遍地传道，从加利利起直到这里了。”</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 5:37; 路加福音 13:1"> 彼拉多一听见，就问：“这人是加利利人吗？”</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 3:1; 路加福音 13:31; 马太福音 14:1"> 既晓得耶稣属希律所管，就把他送到希律那里去。那时希律正在耶路撒冷。</span>
</div>
</div>

## 耶稣在希律前被藐视

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 9:7–9; 马太福音 14:1; 马可福音 6:14"> 希律看见耶稣，就很欢喜，因为听见过他的事，久已想要见他，并且指望看他行一件神迹。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 27:14; 马太福音 7:6; 彼得前书 2:23"> 于是问他许多的话，耶稣却一言不答。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 11:53; 路加福音 23:14–15; 路加福音 23:5"> 祭司长和文士都站着，极力地告他。</span>
<span className="v" id="v11" data-v="11" data-xref="马可福音 15:16–20; 马太福音 27:27–30; 诗篇 69:19–20"> 希律和他的兵丁就藐视耶稣，戏弄他，给他穿上华丽衣服，把他送回彼拉多那里去。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 4:27; 启示录 17:13–14; 诗篇 83:4–6"> 从前希律和彼拉多彼此有仇，在那一天就成了朋友。</span>
</div>
</div>

## 在彼拉多前受审

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马可福音 15:14; 马太福音 27:21–23; 约翰福音 18:38"> 彼拉多传齐了祭司长和官府并百姓，</span>
<span className="v" id="v14" data-v="14" data-xref="但以理书 6:4; 希伯来书 7:26; 路加福音 23:1–2"> 就对他们说：“你们解这人到我这里，说他是诱惑百姓的。看哪，我也曾将你们告他的事在你们面前审问他，并没有查出他什么罪来。</span>
<span className="v" id="v15" data-v="15"> 就是希律也是如此，所以把他送回来。可见他没有做什么该死的事。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 27:26; 路加福音 23:22; 马可福音 15:15"> 故此，我要责打他，把他释放了。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷在此有：17 每逢这节期，巡抚必须释放一个囚犯给他们。">a</a></sup></span>

## 除掉耶稣释放巴拉巴

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行传 21:36; 使徒行传 3:14; 使徒行传 22:22"> 众人却一齐喊着说：“除掉这个人！释放巴拉巴给我们！”</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 3:14; 路加福音 23:5; 路加福音 23:2"> 这巴拉巴是因在城里作乱杀人，下在监里的。</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 15:15; 马太福音 14:8–9; 马太福音 27:19"> 彼拉多愿意释放耶稣，就又劝解他们。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 27:22–25; 马可福音 15:13; 约翰福音 19:15"> 无奈他们喊着说：“钉他十字架！钉他十字架！”</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 23:14; 路加福音 23:20; 彼得前书 3:18"> 彼拉多第三次对他们说：“为什么呢？这人做了什么恶事呢？我并没有查出他什么该死的罪来。所以，我要责打他，把他释放了。”</span>
<span className="v" id="v23" data-v="23" data-xref="撒迦利亚书 11:8; 诗篇 57:4; 诗篇 22:12–13"> 他们大声催逼彼拉多，求他把耶稣钉在十字架上，他们的声音就得了胜。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 27:26; 出埃及记 23:2; 箴言 17:15"> 彼拉多这才照他们所求的定案，</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 3:14; 马可福音 15:6–7; 马可福音 15:15"> 把他们所求的那作乱杀人下在监里的释放了，把耶稣交给他们，任凭他们的意思行。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 27:32–44; 马可福音 15:21–32; 使徒行传 6:9"> 带耶稣去的时候，有一个古利奈人西门从乡下来，他们就抓住他，把十字架搁在他身上，叫他背着跟随耶稣。</span>
</div>
</div>

## 许多人为耶稣号啕痛哭

<div className="bt">
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="路加福音 8:52; 路加福音 8:2; 马可福音 15:40"> 有许多百姓跟随耶稣，内中有好些妇女，妇女们为他号啕痛哭。</span>
<span className="v" id="v28" data-v="28" data-xref="雅歌 8:4; 雅歌 5:8; 雅歌 1:5"> 耶稣转身对她们说：<span className="woj">“耶路撒冷的女子，不要为我哭，当为自己和自己的儿女哭。</span></span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 24:19; 路加福音 21:23–24; 马可福音 13:17–19"> <span className="woj">因为日子要到，人必说：‘不生育的和未曾怀胎的、未曾乳养婴孩的有福了！’</span></span>
<span className="v" id="v30" data-v="30" data-xref="启示录 6:16; 何西阿书 10:8; 以赛亚书 2:19"> <span className="pl pl-1 woj">那时，人要向大山说</span><br /><span className="pl pl-1 woj">‘倒在我们身上！’，</span><br /><span className="pl pl-1 woj">向小山说</span><br /><span className="pl pl-1 woj">‘遮盖我们！’。</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="彼得前书 4:17–18; 约翰福音 15:6; 箴言 11:31"> <span className="woj">这些事既行在有汁水的树上，那枯干的树将来怎么样呢？”</span></span>

## 耶稣被钉十字架

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马可福音 15:22–23; 约翰福音 19:17–18; 约翰福音 18:32"> 到了一个地方，名叫髑髅地，就在那里把耶稣钉在十字架上，又钉了两个犯人，一个在左边，一个在右边。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 5:44; 使徒行传 7:60; 彼得前书 3:9"> 当下耶稣说：<span className="woj">“父啊，赦免他们！因为他们所做的他们不晓得。”</span>兵丁就拈阄分他的衣服。</span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 22:17; 以赛亚书 42:1; 彼得前书 2:4"> 百姓站在那里观看。官府也嗤笑他，说：“他救了别人，他若是基督，神所拣选的，可以救自己吧！”</span>
<span className="v" id="v36" data-v="36" data-xref="诗篇 69:21; 马太福音 27:48; 马太福音 27:34"> 兵丁也戏弄他，上前拿醋送给他喝，</span>
<span className="v" id="v37" data-v="37"> 说：“你若是犹太人的王，可以救自己吧！”</span>
<span className="v" id="v38" data-v="38" data-xref="马可福音 15:26; 马太福音 27:37; 约翰福音 19:19–22"> 在耶稣以上有一个牌子，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷在此有：用希腊、罗马、希伯来的文字。">b</a></sup>写着：“这是犹太人的王。”</span>
</div>

## 犯人求主记念

<div className="bt">
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="马太福音 27:44; 马可福音 15:32; 路加福音 23:35"> 那同钉的两个犯人，有一个讥诮他说：“你不是基督吗？可以救自己和我们吧！”</span>
<span className="v" id="v40" data-v="40" data-xref="以弗所书 5:11; 路加福音 12:5; 启示录 15:4"> 那一个就应声责备他说：“你既是一样受刑的，还不怕神吗？</span>
<span className="v" id="v41" data-v="41" data-xref="利未记 26:40–41; 以斯拉记 9:13; 彼得前书 1:19"> 我们是应该的，因我们所受的与我们所做的相称，但这个人没有做过一件不好的事。”</span>
<span className="v" id="v42" data-v="42" data-xref="罗马书 10:9–14; 使徒行传 16:31; 约翰一书 5:11–13"> 就说：“耶稣啊，你得国降临的时候，求你记念我！”</span>
<span className="v" id="v43" data-v="43" data-xref="启示录 2:7; 诗篇 50:15; 提摩太前书 1:15–16"> 耶稣对他说：<span className="woj">“我实在告诉你：今日你要同我在乐园里了！”</span></span>
</div>

## 耶稣死的景象

<div className="bt">
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="马太福音 27:45; 马可福音 15:33–34; 阿摩司书 8:9"> 那时约有午正，遍地都黑暗了，直到申初，</span>
<span className="v" id="v45" data-v="45" data-xref="希伯来书 10:19–22; 马太福音 27:51; 希伯来书 9:3–8"> 日头变黑了，殿里的幔子从当中裂为两半。</span>
<span className="v" id="v46" data-v="46" data-xref="诗篇 31:5; 使徒行传 7:59; 约翰福音 19:30"> 耶稣大声喊着说：<span className="woj">“父啊，我将我的灵魂交在你手里！”</span>说了这话，气就断了。</span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 27:54; 马可福音 15:39; 路加福音 23:41"> 百夫长看见所成的事，就归荣耀于神，说：“这真是个义人！”</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 18:13; 使徒行传 2:37; 耶利米书 31:19"> 聚集观看的众人见了这所成的事，都捶着胸回去了。</span>
<span className="v" id="v49" data-v="49" data-xref="路加福音 8:2; 诗篇 38:11; 路加福音 23:55"> 还有一切与耶稣熟识的人和从加利利跟着他来的妇女们，都远远地站着看这些事。</span>

## 安放在新坟墓里

<div className="bt">
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="约翰福音 19:38–42; 使徒行传 11:24; 使徒行传 10:22"> 有一个人名叫约瑟，是个议士，为人善良公义，</span>
<span className="v" id="v51" data-v="51" data-xref="路加福音 2:25; 路加福音 2:38; 以赛亚书 8:12"> 众人所谋所为他并没有附从；他本是犹太亚利马太城里素常盼望神国的人。</span>
<span className="v" id="v52" data-v="52" data-xref="约翰福音 19:38–42"> 这人去见彼拉多，求耶稣的身体。</span>
<span className="v" id="v53" data-v="53" data-xref="马太福音 27:59–60; 以赛亚书 53:9; 马可福音 15:46"> 就取下来，用细麻布裹好，安放在石头凿成的坟墓里，那里头从来没有葬过人。</span>
<span className="v" id="v54" data-v="54" data-xref="马太福音 27:62; 约翰福音 19:31; 马可福音 15:42"> 那日是预备日，安息日也快到了。</span>

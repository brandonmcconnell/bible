## 施洗约翰在旷野传道

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="路加福音 23:24; 创世记 49:10; 路加福音 9:7"> 凯撒提庇留在位第十五年，本丢·彼拉多做犹太巡抚，希律做加利利分封的王，他的兄弟腓力做以土利亚和特拉可尼地方分封的王，吕撒聂做亚比利尼分封的王，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 4:6; 约翰福音 18:24; 路加福音 1:80"> 亚那和该亚法做大祭司。那时，撒迦利亚的儿子约翰在旷野里，神的话临到他。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:77; 马太福音 3:5–6; 使徒行传 13:24"> 他就来到约旦河一带地方，宣讲悔改的洗礼，使罪得赦。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 40:3–5; 约翰福音 1:23; 路加福音 1:76–79"> 正如先知以赛亚书上所记的话说：<br /><span className="pl pl-1">“在旷野有人声喊着说：</span><br /><span className="pl pl-1">‘预备主的道，</span><br /><span className="pl pl-1">修直他的路！</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 40:4; 以赛亚书 42:16; 以赛亚书 45:2"> <span className="pl pl-1">一切山洼都要填满，</span><br /><span className="pl pl-1">大小山冈都要削平，</span><br /><span className="pl pl-1">弯弯曲曲的地方要改为正直，</span><br /><span className="pl pl-1">高高低低的道路要改为平坦。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 52:10; 以赛亚书 40:5; 诗篇 98:2–3"> <span className="pl pl-1">凡有血气的，都要见神的救恩。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 23:33; 马太福音 12:34; 帖撒罗尼迦前书 1:10"> 约翰对那出来要受他洗的众人说：“毒蛇的种类！谁指示你们逃避将来的愤怒呢？</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 18:27–31; 使徒行传 26:20; 以赛亚书 1:16–18"> 你们要结出果子来，与悔改的心相称！不要自己心里说：‘有亚伯拉罕为我们的祖宗。’我告诉你们，神能从这些石头中给亚伯拉罕兴起子孙来。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 7:19; 约翰福音 15:6; 路加福音 13:9"> 现在斧子已经放在树根上，凡不结好果子的树就砍下来，丢在火里。”</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 2:37; 路加福音 3:14; 使徒行传 16:30"> 众人问他说：“这样，我们当做什么呢？”</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 58:7–11; 约翰一书 3:17; 提摩太前书 6:18"> 约翰回答说：“有两件衣裳的，就分给那没有的，有食物的也当这样行。”</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 7:29; 路加福音 15:1–2; 路加福音 18:13"> 又有税吏来要受洗，问他说：“夫子，我们当做什么呢？”</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 19:8; 以弗所书 4:28; 哥林多前书 6:10"> 约翰说：“除了例定的数目，不要多取。”</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 13:5–6; 出埃及记 20:16; 出埃及记 23:1"> 又有兵丁问他说：“我们当做什么呢？”约翰说：“不要以强暴待人，也不要讹诈人，自己有钱粮就当知足。”</span>
</div>
</div>

## 必有圣灵与火的洗

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 10:24; 约翰福音 3:28–29; 约翰福音 1:19–28"> 百姓指望基督来的时候，人都心里猜疑或者约翰是基督。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 3:11; 使徒行传 1:5; 使徒行传 11:15–16"> 约翰说：“我是用水给你们施洗。但有一位能力比我更大的要来，我就是给他解鞋带也不配，他要用圣灵与火给你们施洗。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 15:7; 马太福音 13:30; 弥迦书 4:12"> 他手里拿着簸箕，要扬净他的场，把麦子收在仓里，把糠用不灭的火烧尽了。”</span>
</div>
</div>

## 约翰责备希律被囚

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰福音 3:29–36; 约翰福音 1:34; 约翰福音 1:29"> 约翰又用许多别的话劝百姓，向他们传福音。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 3:1; 马太福音 11:2; 马可福音 6:17–18"> 只是分封的王希律因他兄弟之妻希罗底的缘故，并因他所行的一切恶事，受了约翰的责备，</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 24:17–22; 约翰福音 3:24; 帖撒罗尼迦前书 2:15–16"> 又另外添了一件，就是把约翰收在监里。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约翰福音 1:32–34; 马太福音 3:13–17; 约翰福音 12:27–28"> 众百姓都受了洗，耶稣也受了洗，正祷告的时候天就开了，</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 2:7; 彼得后书 1:17–18; 约翰福音 1:32"> 圣灵降临在他身上，形状仿佛鸽子；又有声音从天上来说：“你是我的爱子，我喜悦你。”</span>

## 耶稣的家谱

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 4:22; 马太福音 13:55; 民数记 4:3"> 耶稣开头传道，年纪约有三十岁。依人看来，他是约瑟的儿子，约瑟是希里的儿子，</span>
<span className="v" id="v24" data-v="24"> 希里是玛塔的儿子，玛塔是利未的儿子，利未是麦基的儿子，麦基是雅拿的儿子，雅拿是约瑟的儿子，</span>
<span className="v" id="v25" data-v="25"> 约瑟是玛他提亚的儿子，玛他提亚是亚摩斯的儿子，亚摩斯是拿鸿的儿子，拿鸿是以斯利的儿子，以斯利是拿该的儿子，</span>
<span className="v" id="v26" data-v="26"> 拿该是玛押的儿子，玛押是玛他提亚的儿子，玛他提亚是西美的儿子，西美是约瑟的儿子，约瑟是犹大的儿子，犹大是约亚拿的儿子，</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 1:12"> 约亚拿是利撒的儿子，利撒是所罗巴伯的儿子，所罗巴伯是撒拉铁的儿子，撒拉铁是尼利的儿子，尼利是麦基的儿子，</span>
<span className="v" id="v28" data-v="28"> 麦基是亚底的儿子，亚底是哥桑的儿子，哥桑是以摩当的儿子，以摩当是珥的儿子，珥是约细的儿子，</span>
<span className="v" id="v29" data-v="29"> 约细是以利以谢的儿子，以利以谢是约令的儿子，约令是玛塔的儿子，玛塔是利未的儿子，</span>
<span className="v" id="v30" data-v="30"> 利未是西缅的儿子，西缅是犹大的儿子，犹大是约瑟的儿子，约瑟是约南的儿子，约南是以利亚敬的儿子，</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 3:5; 撒母耳记下 5:14; 撒迦利亚书 12:12"> 以利亚敬是米利亚的儿子，米利亚是买南的儿子，买南是玛达他的儿子，玛达他是拿单的儿子，拿单是大卫的儿子，</span>
<span className="v" id="v32" data-v="32" data-xref="路得记 4:18–22; 马太福音 1:3–6; 以赛亚书 11:1–2"> 大卫是耶西的儿子，耶西是俄备得的儿子，俄备得是波阿斯的儿子，波阿斯是撒门的儿子，撒门是拿顺的儿子，</span>
<span className="v" id="v33" data-v="33" data-xref="路得记 4:19–20; 创世记 49:8; 创世记 38:29"> 拿顺是亚米拿达的儿子，亚米拿达是亚兰的儿子，亚兰是希斯仑的儿子，希斯仑是法勒斯的儿子，法勒斯是犹大的儿子，</span>
<span className="v" id="v34" data-v="34" data-xref="创世记 21:3; 约书亚记 24:2; 历代志上 1:24–28"> 犹大是雅各的儿子，雅各是以撒的儿子，以撒是亚伯拉罕的儿子，亚伯拉罕是他拉的儿子，他拉是拿鹤的儿子，</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 11:12–21; 创世记 10:24–25"> 拿鹤是西鹿的儿子，西鹿是拉吴的儿子，拉吴是法勒的儿子，法勒是希伯的儿子，希伯是沙拉的儿子，</span>
<span className="v" id="v36" data-v="36" data-xref="创世记 5:28–32; 创世记 10:21–22; 创世记 9:1"> 沙拉是该南的儿子，该南是亚法撒的儿子，亚法撒是闪的儿子，闪是挪亚的儿子，挪亚是拉麦的儿子，</span>
<span className="v" id="v37" data-v="37" data-xref="历代志上 1:1–3; 创世记 5:6–28"> 拉麦是玛土撒拉的儿子，玛土撒拉是以诺的儿子，以诺是雅列的儿子，雅列是玛勒列的儿子，玛勒列是该南的儿子，该南是以挪士的儿子，</span>
<span className="v" id="v38" data-v="38" data-xref="创世记 2:7; 以赛亚书 64:8; 哥林多前书 15:45"> 以挪士是塞特的儿子，塞特是亚当的儿子，亚当是神的儿子。</span>

## 在安息日医治胀病

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 3:2; 路加福音 20:20; 诗篇 62:4"> 安息日，耶稣到一个法利赛人的首领家里去吃饭，他们就窥探他。</span>
<span className="v" id="v2" data-v="2"> 在他面前有一个患水臌的人。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 12:10; 马可福音 3:4; 路加福音 13:14–16"> 耶稣对律法师和法利赛人说：<span className="woj">“安息日治病可以不可以？”</span></span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 22:46; 马太福音 21:25–27"> 他们却不言语。耶稣就治好那人，叫他走了。</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 13:15; 出埃及记 23:4–5; 马太福音 12:11–12"> 便对他们说：<span className="woj">“你们中间谁有驴或有牛在安息日掉在井里，不立时拉它上来呢？”</span></span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 20:40; 路加福音 21:15; 使徒行传 6:10"> 他们不能对答这话。</span>
</div>
</div>

## 教训为客的

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="腓立比书 2:3; 路加福音 11:43; 马太福音 23:6"> 耶稣见所请的客拣择首位，就用比喻对他们说：</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 25:6–7"> <span className="woj">“你被人请去赴婚姻的筵席，不要坐在首位上，恐怕有比你尊贵的客被他请来，</span></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 16:18; 箴言 11:2; 箴言 3:35"> <span className="woj">那请你们的人前来对你说：‘让座给这一位吧！’你就羞羞惭惭地退到末位上去了。</span></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 25:6–7; 箴言 15:33; 撒母耳记上 15:17"> <span className="woj">你被请的时候，就去坐在末位上，好叫那请你的人来对你说：‘朋友，请上坐！’那时，你在同席的人面前就有光彩了。</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 18:14; 马太福音 23:12; 箴言 29:23"> <span className="woj">因为凡自高的，必降为卑；自卑的，必升为高。”</span></span>
</div>
</div>

## 教训为主的

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 5:46; 雅各书 2:1–6; 路加福音 6:32–36"> 耶稣又对请他的人说：<span className="woj">“你摆设午饭或晚饭，不要请你的朋友、弟兄、亲属和富足的邻舍，恐怕他们也请你，你就得了报答。</span></span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 14:21; 以赛亚书 58:10; 箴言 14:31"> <span className="woj">你摆设筵席，倒要请那贫穷的、残废的、瘸腿的、瞎眼的，你就有福了！</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 19:17; 使徒行传 24:15; 约翰福音 5:29"> <span className="woj">因为他们没有什么可报答你。到义人复活的时候，你要得着报答。”</span></span>
</div>
</div>

## 藐视救恩

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="启示录 19:9; 路加福音 22:30; 路加福音 13:29"> 同席的有一人听见这话，就对耶稣说：“在神国里吃饭的有福了！”</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 22:2–14; 启示录 22:17; 以赛亚书 55:1–7"> 耶稣对他说：<span className="woj">“有一人摆设大筵席，请了许多客。</span></span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 11:27–29; 马太福音 10:1–4; 马太福音 22:3–4"> <span className="woj">到了坐席的时候，打发仆人去对所请的人说：‘请来吧，样样都齐备了。’</span></span>
<span className="v" id="v18" data-v="18" data-xref="提摩太前书 6:9–10; 路加福音 17:26–31; 路加福音 18:24"> <span className="woj">众人一口同音地推辞。头一个说：‘我买了一块地，必须去看看。请你准我辞了。’</span></span>
<span className="v" id="v19" data-v="19"> <span className="woj">又有一个说：‘我买了五对牛，要去试一试。请你准我辞了。’</span></span>
<span className="v" id="v20" data-v="20" data-xref="申命记 24:5; 哥林多前书 7:33; 路加福音 14:26–28"> <span className="woj">又有一个说：‘我才娶了妻，所以不能去。’</span></span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 14:13; 马太福音 11:5; 路加福音 14:24"> <span className="woj">那仆人回来，把这事都告诉了主人。家主就动怒，对仆人说：‘快出去到城里大街小巷，领那贫穷的、残废的、瞎眼的、瘸腿的来。’</span></span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 14:2; 以弗所书 3:8; 提摩太前书 2:5–6"> <span className="woj">仆人说：‘主啊，你所吩咐的已经办了，还有空座。’</span></span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 22:9–10; 歌罗西书 1:28; 使徒行传 13:47–48"> <span className="woj">主人对仆人说：‘你出去到路上和篱笆那里，勉强人进来，坐满我的屋子。</span></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 21:43; 使徒行传 13:46; 约翰福音 8:24"> <span className="woj">我告诉你们：先前所请的人，没有一个得尝我的筵席！’”</span></span>
</div>
</div>

## 当背十架跟从主

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 6:24–27; 路加福音 12:1"> 有极多的人和耶稣同行。他转过来对他们说：</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 10:37; 约翰福音 12:25; 腓立比书 3:8"> <span className="woj">“人到我这里来，若不爱我胜过爱</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“爱我胜过爱”原文作“恨”。">a</a></sup><span className="woj">自己的父母、妻子、儿女、弟兄、姐妹和自己的性命，就不能做我的门徒。</span></span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 10:38; 路加福音 9:23–25; 马可福音 8:34–37"> <span className="woj">凡不背着自己十字架跟从我的，也不能做我的门徒。</span></span>
<span className="v" id="v28" data-v="28" data-xref="箴言 24:27; 马太福音 10:22; 约书亚记 24:19–24"> <span className="woj">你们哪一个要盖一座楼，不先坐下算计花费，能盖成不能呢？</span></span>
<span className="v" id="v29" data-v="29"> <span className="woj">恐怕安了地基，不能成功，看见的人都笑话他，</span></span>
<span className="v" id="v30" data-v="30" data-xref="希伯来书 6:11; 约翰二书 1:8; 哥林多前书 3:11–14"> <span className="woj">说：‘这个人开了工，却不能完工！’</span></span>
<span className="v" id="v31" data-v="31" data-xref="箴言 20:18; 箴言 25:8; 列王纪下 18:20–22"> <span className="woj">或是一个王出去和别的王打仗，岂不先坐下酌量，能用一万兵去敌那领二万兵来攻打他的吗？</span></span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 12:20; 雅各书 4:6–10; 路加福音 12:58"> <span className="woj">若是不能，就趁敌人还远的时候，派使者去求和息的条款。</span></span>
<span className="v" id="v33" data-v="33" data-xref="腓立比书 3:7–8; 约翰一书 2:15–16; 路加福音 5:28"> <span className="woj">这样，你们无论什么人，若不撇下一切所有的，就不能做我的门徒。</span></span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 5:13; 歌罗西书 4:6; 马可福音 9:49–50"> <span className="woj">盐本是好的，盐若失了味，可用什么叫它再咸呢？</span></span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 11:15; 路加福音 9:44; 启示录 2:11"> <span className="woj">或用在田里，或堆在粪里，都不合适，只好丢在外面。有耳可听的，就应当听！”</span></span>
</div>
</div>

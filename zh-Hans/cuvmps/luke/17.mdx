## 绊倒人的有祸

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 18:7; 罗马书 14:13; 哥林多前书 11:19"> 耶稣又对门徒说：<span className="woj">“绊倒人的事是免不了的，但那绊倒人的有祸了！</span></span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 9:42; 马太福音 18:14; 马太福音 18:3–6"> <span className="woj">就是把磨石拴在这人的颈项上，丢在海里，还强如他把这小子里的一个绊倒了。</span></span>
<span className="v" id="v3" data-v="3" data-xref="利未记 19:17; 马太福音 18:21; 马太福音 18:15–17"> <span className="woj">你们要谨慎！若是你的弟兄得罪你，就劝诫他。他若懊悔，就饶恕他。</span></span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 3:12–13; 马太福音 18:21–22; 罗马书 12:20"> <span className="woj">倘若他一天七次得罪你，又七次回转，说：‘我懊悔了’，你总要饶恕他。”</span></span>
</div>
</div>

## 信心的能力

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马可福音 9:24; 希伯来书 12:2; 腓立比书 4:13"> 使徒对主说：“求主加增我们的信心！”</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 17:20; 马太福音 21:21; 马可福音 9:23"> 主说：<span className="woj">“你们若有信心像一粒芥菜种，就是对这棵桑树说：‘你要拔起根来，栽在海里！’，它也必听从你们。</span></span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 12:11; 路加福音 13:15; 路加福音 14:5"> <span className="woj">你们谁有仆人耕地或是放羊，从田里回来，就对他说‘你快来坐下吃饭’呢？</span></span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 12:37; 创世记 43:16; 撒母耳记下 12:20"> <span className="woj">岂不对他说‘你给我预备晚饭，束上带子伺候我，等我吃喝完了，你才可以吃喝’吗？</span></span>
<span className="v" id="v9" data-v="9"> <span className="woj">仆人照所吩咐的去做，主人还谢谢他吗？</span></span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 9:16–17; 约伯记 22:2–3; 彼得前书 5:5–6"> <span className="woj">这样，你们做完了一切所吩咐的，只当说：‘我们是无用的仆人，所做的本是我们应分做的。’”</span></span>
</div>
</div>

## 治好十个长大麻风的

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路加福音 9:51–52; 约翰福音 4:3–4"> 耶稣往耶路撒冷去，经过撒马利亚和加利利。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 13:45–46; 路加福音 5:12; 列王纪下 7:3"> 进入一个村子，有十个长大麻风的迎面而来，远远地站着，</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 15:22; 马太福音 20:30–31; 马太福音 9:27"> 高声说：“耶稣，夫子，可怜我们吧！”</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 5:14; 利未记 13:1–46; 列王纪下 5:14"> 耶稣看见，就对他们说：<span className="woj">“你们去，把身体给祭司察看！”</span>他们去的时候就洁净了。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 30:11–12; 诗篇 103:1–4; 诗篇 118:18–19"> 内中有一个见自己已经好了，就回来大声归荣耀于神，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 8:5–25; 马太福音 10:5; 启示录 19:10"> 又俯伏在耶稣脚前感谢他。这人是撒马利亚人。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 1:21; 诗篇 106:13; 创世记 3:9"> 耶稣说：<span className="woj">“洁净了的不是十个人吗？那九个在哪里呢？</span></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 50:23; 马太福音 15:24–28; 诗篇 106:13"> <span className="woj">除了这外族人，再没有别人回来归荣耀于神吗？”</span></span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 7:50; 路加福音 8:48; 马可福音 10:52"> 就对那人说：<span className="woj">“起来走吧！你的信救了你了。”</span></span>
</div>
</div>

## 神的国在人心里

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约翰福音 18:36; 路加福音 19:11; 但以理书 2:44"> 法利赛人问神的国几时来到，耶稣回答说：<span className="woj">“神的国来到不是眼所能见的。</span></span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 12:28; 罗马书 14:17; 马可福音 13:21"> <span className="woj">人也不得说‘看哪，在这里！’、‘看哪，在那里！’，因为神的国就在你们心里</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“心里”或作“中间”。">a</a></sup><span className="woj">。”</span></span>
</div>
</div>

## 引证挪亚和罗得的事

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 5:35; 马太福音 9:15; 约翰福音 8:21–24"> 他又对门徒说：<span className="woj">“日子将到，你们巴不得看见人子的一个日子，却不得看见。</span></span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 21:8; 马太福音 24:23–26; 路加福音 17:21"> <span className="woj">人将要对你们说‘看哪，在那里！’、‘看哪，在这里！’，你们不要出去，也不要跟随他们。</span></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 24:27; 马太福音 24:30; 玛拉基书 4:1–2"> <span className="woj">因为人子在他降临的日子，好像闪电从天这边一闪，直照到天那边。</span></span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 16:21; 路加福音 9:22; 马可福音 8:31"> <span className="woj">只是他必须先受许多苦，又被这世代弃绝。</span></span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 24:37–39; 路加福音 17:24; 创世记 7:7–23"> <span className="woj">挪亚的日子怎样，人子的日子也要怎样。</span></span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 12:19–20; 帖撒罗尼迦前书 5:1–3; 路加福音 16:19–23"> <span className="woj">那时候的人又吃又喝，又娶又嫁，到挪亚进方舟的那日，洪水就来，把他们全都灭了。</span></span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 16:49–50; 创世记 18:20–21; 雅各书 5:1–5"> <span className="woj">又好像罗得的日子，人又吃又喝，又买又卖，又耕种又盖造，</span></span>
<span className="v" id="v29" data-v="29" data-xref="彼得后书 2:6; 西番雅书 2:9; 犹大书 1:7"> <span className="woj">到罗得出所多玛的那日，就有火与硫磺从天上降下来，把他们全都灭了。</span></span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前书 1:7; 帖撒罗尼迦后书 1:7; 启示录 1:7"> <span className="woj">人子显现的日子也要这样。</span></span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 21:21; 马可福音 13:14–16; 耶利米书 45:5"> <span className="woj">当那日，人在房上，器具在屋里，不要下来拿；人在田里，也不要回家。</span></span>
<span className="v" id="v32" data-v="32" data-xref="创世记 19:26; 希伯来书 10:38–39; 彼得后书 2:18–22"> <span className="woj">你们要回想罗得的妻子！</span></span>
</div>
</div>

## 舍生命得生命

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马可福音 8:35–37; 马太福音 10:39; 约翰福音 12:25"> <span className="woj">“凡想要保全生命的，必丧掉生命；凡丧掉生命的，必救活生命。</span></span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 24:40–41; 彼得后书 2:9; 玛拉基书 3:16–18"> <span className="woj">我对你们说：当那一夜，两个人在一个床上，要取去一个，撇下一个；</span></span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 24:41; 出埃及记 11:5; 士师记 16:21"> <span className="woj">两个女人一同推磨，要取去一个，撇下一个。</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷在此有：36 两个人在田里，要取去一个，撇下一个。">b</a></sup><span className="woj">”</span></span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 24:28; 约伯记 39:29–30; 启示录 19:17–18"> 门徒说：“主啊，在哪里有这事呢？”耶稣说：<span className="woj">“尸首在哪里，鹰也必聚在哪里。”</span></span>

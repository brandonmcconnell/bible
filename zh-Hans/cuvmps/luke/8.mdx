## 撒种的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="马可福音 4:1–9; 马太福音 13:2–9"> 当许多人聚集，又有人从各城里出来见耶稣的时候，耶稣就用比喻说：</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 2:1; 雅各书 1:23–24; 马可福音 4:15"> <span className="woj">“有一个撒种的出去撒种。撒的时候，有落在路旁的，被人践踏，天上的飞鸟又来吃尽了。</span></span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 3:7–8; 路加福音 8:13; 马可福音 4:5–6"> <span className="woj">有落在磐石上的，一出来就枯干了，因为得不着滋润。</span></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 4:3; 路加福音 8:14; 路加福音 21:34"> <span className="woj">有落在荆棘里的，荆棘一同生长，把它挤住了。</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 11:15; 启示录 2:11; 启示录 2:7"> <span className="woj">又有落在好土里的，生长起来，结实百倍。”</span>耶稣说了这些话，就大声说：<span className="woj">“有耳可听的，就应当听！”</span></span>
</div>
</div>

## 解明撒种的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马可福音 4:10; 马太福音 13:10; 马太福音 13:18"> 门徒问耶稣说：“这比喻是什么意思呢？”</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 6:9; 马可福音 4:11; 马太福音 11:25"> 他说：<span className="woj">“神国的奥秘只叫你们知道，至于别人，就用比喻，叫他们‘看也看不见，听也听不明’。</span></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 13:19; 马可福音 4:14–20; 雅各书 1:21"> <span className="woj">这比喻乃是这样：种子就是神的道。</span></span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦后书 2:9–14; 启示录 12:9; 雅各书 1:23–24"> <span className="woj">那些在路旁的，就是人听了道，随后魔鬼来，从他们心里把道夺去，恐怕他们信了得救。</span></span>
<span className="v" id="v13" data-v="13" data-xref="何西阿书 6:4; 约翰福音 5:35; 箴言 12:12"> <span className="woj">那些在磐石上的，就是人听道，欢喜领受，但心中没有根，不过暂时相信，及至遇见试炼就退后了。</span></span>
<span className="v" id="v14" data-v="14" data-xref="约翰一书 2:15–17; 提摩太前书 6:9–10; 提摩太前书 6:17"> <span className="woj">那落在荆棘里的，就是人听了道，走开以后，被今生的思虑、钱财、宴乐挤住了，便结不出成熟的子粒来。</span></span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 10:36; 加拉太书 5:22–26; 歌罗西书 1:10"> <span className="woj">那落在好土里的，就是人听了道，持守在诚实善良的心里，并且忍耐着结实。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 11:33; 马太福音 5:15–16; 马可福音 4:21–22"> <span className="woj">“没有人点灯用器皿盖上或放在床底下，乃是放在灯台上，叫进来的人看见亮光。</span></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 12:2–3; 马太福音 10:26; 马可福音 4:22"> <span className="woj">因为掩藏的事没有不显出来的，隐瞒的事没有不露出来被人知道的。</span></span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 13:12; 路加福音 19:26; 马可福音 4:23–25"> <span className="woj">所以，你们应当小心怎样听。因为凡有的，还要加给他；凡没有的，连他自以为有的也要夺去。”</span></span>
</div>
</div>

## 信者皆为亲属

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马太福音 12:46–50; 马可福音 3:31–35; 马可福音 3:21"> 耶稣的母亲和他弟兄来了，因为人多，不得到他跟前。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 1:14; 马可福音 6:3; 马太福音 13:55–56"> 有人告诉他说：“你母亲和你弟兄站在外边，要见你。”</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 11:27–28; 雅各书 1:22; 约翰福音 13:17"> 耶稣回答说：<span className="woj">“听了神之道而遵行的人，就是我的母亲、我的弟兄了。”</span></span>
</div>
</div>

## 平静风和海

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马太福音 8:23–27; 马可福音 4:35–41; 马可福音 6:45"> 有一天，耶稣和门徒上了船，对门徒说：<span className="woj">“我们可以渡到湖那边去。”</span>他们就开了船。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 93:3–4; 诗篇 124:2–4; 诗篇 148:8"> 正行的时候，耶稣睡着了。湖上忽然起了暴风，船将满了水，甚是危险。</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 107:25–29; 路加福音 4:39; 诗篇 104:6–9"> 门徒来叫醒了他，说：“夫子！夫子！我们丧命啦！”耶稣醒了，斥责那狂风大浪，风浪就止住，平静了。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 8:26; 箴言 30:4; 马可福音 4:40–41"> 耶稣对他们说：<span className="woj">“你们的信心在哪里呢？”</span>他们又惧怕又稀奇，彼此说：“这到底是谁？他吩咐风和水，连风和水也听从他了！”</span>
</div>
</div>

## 鬼入猪群

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马可福音 5:1–20; 马太福音 8:28–34"> 他们到了格拉森<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷作：加大拉。">a</a></sup>人的地方，就是加利利的对面。</span>
<span className="v" id="v27" data-v="27" data-xref="马可福音 5:2–5; 撒母耳记上 19:24; 民数记 19:16"> 耶稣上了岸，就有城里一个被鬼附着的人迎面而来。这个人许久不穿衣服，不住房子，只住在坟茔里。</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 8:29; 彼得后书 2:4; 马可福音 5:6–8"> 他见了耶稣，就俯伏在他面前，大声喊叫说：“至高神的儿子耶稣，我与你有什么相干？求你不要叫我受苦！”</span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 5:3–5; 路加福音 9:39; 提摩太后书 2:25–26"> 是因耶稣曾吩咐污鬼从那人身上出来。原来这鬼屡次抓住他；他常被人看守，又被铁链和脚镣捆锁，他竟把锁链挣断，被鬼赶到旷野去。</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 26:53; 路加福音 8:2; 马太福音 8:29"> 耶稣问他说：<span className="woj">“你名叫什么？”</span>他说：“我名叫‘群’。”这是因为附着他的鬼多。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 25:41; 腓立比书 2:10–11; 约伯记 2:5"> 鬼就央求耶稣，不要吩咐他们到无底坑里去。</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 65:4; 以赛亚书 66:3; 启示录 20:7"> 那里有一大群猪在山上吃食。鬼央求耶稣准他们进入猪里去，耶稣准了他们。</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前书 5:8; 约翰福音 8:44; 路加福音 8:22–23"> 鬼就从那人出来，进入猪里去。于是那群猪闯下山崖，投在湖里淹死了。</span>
<span className="v" id="v34" data-v="34" data-xref="马可福音 5:14; 马太福音 8:33; 马太福音 28:11"> 放猪的看见这事就逃跑了，去告诉城里和乡下的人。</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 10:39; 使徒行传 22:3; 约翰一书 3:8"> 众人出来要看是什么事，到了耶稣那里，看见鬼所离开的那人坐在耶稣脚前，穿着衣服，心里明白过来，他们就害怕。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 4:24"> 看见这事的，便将被鬼附着的人怎么得救告诉他们。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 16:39; 路加福音 8:28; 路加福音 10:10–11"> 格拉森四围的人因为害怕得很，都求耶稣离开他们，耶稣就上船回去了。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 9:13–16; 马可福音 5:18–20; 诗篇 145:3–12"> 鬼所离开的那人恳求和耶稣同在，耶稣却打发他回去，说：</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 17:15–18; 提摩太前书 5:8; 申命记 10:21"> <span className="woj">“你回家去，传说神为你做了何等大的事。”</span>他就去，满城里传扬耶稣为他做了何等大的事。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="马太福音 9:1; 马可福音 5:21; 马可福音 6:20"> 耶稣回来的时候，众人迎接他，因为他们都等候他。</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 5:22–43; 路加福音 13:14; 使徒行传 18:8"> 有一个管会堂的，名叫睚鲁，来俯伏在耶稣脚前，求耶稣到他家里去，</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 7:12; 路加福音 8:45; 约伯记 1:18–19"> 因他有一个独生女儿，约有十二岁，快要死了。耶稣去的时候，众人拥挤他。</span>
</div>
</div>

## 医患血漏的女人

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="马可福音 5:25–26; 马太福音 9:20–22; 利未记 15:25–33"> 有一个女人患了十二年的血漏，在医生手里花尽了她一切养生的，并没有一人能医好她。</span>
<span className="v" id="v44" data-v="44" data-xref="马可福音 5:27–28; 申命记 22:12; 使徒行传 19:12"> 她来到耶稣背后，摸他的衣裳穗子，血漏立刻就止住了。</span>
<span className="v" id="v45" data-v="45" data-xref="马可福音 5:30–32; 路加福音 9:13; 路加福音 5:5"> 耶稣说：<span className="woj">“摸我的是谁？”</span>众人都不承认。彼得和同行的人都说：“夫子，众人拥拥挤挤紧靠着你。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷在此有：你还问‘摸我的是谁’吗？">b</a></sup>”</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 6:19; 路加福音 5:17; 彼得前书 2:9"> 耶稣说：<span className="woj">“总有人摸我，因我觉得有能力从我身上出去。”</span></span>
<span className="v" id="v47" data-v="47" data-xref="马可福音 5:33; 路加福音 17:15–16; 哥林多前书 2:3"> 那女人知道不能隐藏，就战战兢兢地来俯伏在耶稣脚前，把摸他的缘故和怎样立刻得好了，当着众人都说出来。</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 7:50; 马太福音 9:22; 希伯来书 4:2"> 耶稣对她说：<span className="woj">“女儿，你的信救了你，平平安安地去吧！”</span></span>
</div>
</div>

## 耶稣叫睚鲁的女儿复活

<div className="bt">
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="马可福音 5:35–43; 以赛亚书 7:12; 路加福音 7:6"> 还说话的时候，有人从管会堂的家里来，说：“你的女儿死了，不要劳动夫子。”</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 11:40; 约翰福音 11:25; 马可福音 5:36"> 耶稣听见就对他说：<span className="woj">“不要怕，只要信！你的女儿就必得救。”</span></span>
<span className="v" id="v51" data-v="51" data-xref="马可福音 14:33; 马太福音 6:5–6; 列王纪上 17:19–23"> 耶稣到了他的家，除了彼得、约翰、雅各和女儿的父母，不许别人同他进去。</span>
<span className="v" id="v52" data-v="52" data-xref="路加福音 23:27; 约翰福音 11:4; 撒迦利亚书 12:10"> 众人都为这女儿哀哭捶胸。耶稣说：<span className="woj">“不要哭，她不是死了，是睡着了。”</span></span>
<span className="v" id="v53" data-v="53" data-xref="路加福音 16:14; 以赛亚书 53:3; 约翰福音 11:39"> 他们晓得女儿已经死了，就嗤笑耶稣。</span>
<span className="v" id="v54" data-v="54" data-xref="耶利米书 31:32; 约翰福音 11:43; 马可福音 1:31"> 耶稣拉着她的手，呼叫说：<span className="woj">“女儿，起来吧！”</span></span>
<span className="v" id="v55" data-v="55" data-xref="约翰福音 11:44; 列王纪上 17:21–23; 马可福音 5:43"> 她的灵魂便回来，她就立刻起来了。耶稣吩咐给她东西吃。</span>
<span className="v" id="v56" data-v="56" data-xref="马太福音 8:4; 马太福音 9:30; 路加福音 5:14"> 她的父母惊奇得很。耶稣嘱咐他们，不要把所做的事告诉人。</span>
</div>
</div>

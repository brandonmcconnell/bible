## 从死里复活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 20:1–2; 马可福音 16:1–8; 马太福音 28:1–8"> 七日的头一日，黎明的时候，那些妇女带着所预备的香料来到坟墓前，</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 16:3–4; 马太福音 27:60–66; 马可福音 15:46–47"> 看见石头已经从坟墓滚开了。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 24:23; 约翰福音 20:6–7; 马太福音 16:5"> 她们就进去，只是不见主耶稣的身体。</span>
<span className="v" id="v4" data-v="4" data-xref="马可福音 16:5; 约翰福音 20:11–12; 使徒行传 1:10"> 正在猜疑之间，忽然有两个人站在旁边，衣服放光。</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 16:5–6; 马太福音 28:3–5; 启示录 1:18"> 妇女们惊怕，将脸伏地。那两个人就对她们说：“为什么在死人中找活人呢？</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 17:22–23; 路加福音 9:22; 马可福音 8:31"> 他不在这里，已经复活了。当记念他还在加利利的时候怎样告诉你们，</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 16:21"> 说：<span className="woj">‘人子必须被交在罪人手里，钉在十字架上，第三日复活。’”</span></span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 12:16; 约翰福音 14:26; 约翰福音 2:19–22"> 她们就想起耶稣的话来，</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 24:22–24; 马可福音 16:7–8; 马太福音 28:7–8"> 便从坟墓那里回去，把这一切事告诉十一个使徒和其余的人。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 27:56; 约翰福音 20:11–18; 路加福音 8:2–3"> 那告诉使徒的就是抹大拉的马利亚和约亚拿，并雅各的母亲马利亚，还有与她们在一处的妇女。</span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 9:16; 马可福音 16:11; 创世记 19:14"> 她们这些话使徒以为是胡言，就不相信。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 20:3–10"> 彼得起来，跑到坟墓前，低头往里看，见细麻布独在一处，就回去了，心里稀奇所成的事。</span>
</div>
</div>

## 耶稣与两个行路的谈论

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 24:18; 马可福音 16:12–13"> 正当那日，门徒中有两个人往一个村子去。这村子名叫以马忤斯，离耶路撒冷约有二十五里。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 6:45; 申命记 6:7; 玛拉基书 3:6"> 他们彼此谈论所遇见的这一切事。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 18:20; 约翰福音 14:18–19; 路加福音 24:36"> 正谈论相问的时候，耶稣亲自就近他们，和他们同行，</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 20:14; 约翰福音 21:4; 路加福音 24:31"> 只是他们的眼睛迷糊了，不认识他。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 16:20–22; 约翰福音 16:6; 以西结书 9:4–6"> 耶稣对他们说：<span className="woj">“你们走路彼此谈论的是什么事呢？”</span>他们就站住，脸上带着愁容。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 19:25"> 二人中有一个名叫革流巴的回答说：“你在耶路撒冷作客，还不知道这几天在那里所出的事吗？”</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 21:11; 使徒行传 7:22; 约翰福音 4:19"> 耶稣说：<span className="woj">“什么事呢？”</span>他们说：“就是拿撒勒人耶稣的事。他是个先知，在神和众百姓面前说话行事都有大能，</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 3:13–15; 使徒行传 4:8–10; 路加福音 23:13"> 祭司长和我们的官府竟把他解去，定了死罪，钉在十字架上。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:68; 彼得前书 1:18–19; 路加福音 2:38"> 但我们素来所盼望、要赎以色列民的就是他。不但如此，而且这事成就，现在已经三天了。</span>
<span className="v" id="v22" data-v="22" data-xref="马可福音 16:9–10; 马太福音 28:7–8; 约翰福音 20:1–2"> 再者，我们中间有几个妇女使我们惊奇，她们清早到了坟墓那里，</span>
<span className="v" id="v23" data-v="23"> 不见他的身体，就回来告诉我们说看见了天使显现，说他活了。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 24:12; 约翰福音 20:1–10"> 又有我们的几个人往坟墓那里去，所遇见的正如妇女们所说的，只是没有看见他。”</span>
<span className="v" id="v25" data-v="25" data-xref="马可福音 7:18; 马可福音 9:19; 希伯来书 5:11–12"> 耶稣对他们说：<span className="woj">“无知的人哪，先知所说的一切话，你们的心信得太迟钝了！</span></span>
<span className="v" id="v26" data-v="26" data-xref="彼得前书 1:11; 以赛亚书 53:1–12; 撒迦利亚书 13:7"> <span className="woj">基督这样受害，又进入他的荣耀，岂不是应当的吗？”</span></span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 7:14; 路加福音 24:44; 申命记 18:15"> 于是从摩西和众先知起，凡经上所指着自己的话，都给他们讲解明白了。</span>
</div>
</div>

## 显现在以马忤斯

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马可福音 6:48; 创世记 19:2; 创世记 32:26"> 将近他们所去的村子，耶稣好像还要往前行，</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪下 4:8; 路加福音 14:23; 创世记 19:3"> 他们却强留他，说：“时候晚了，日头已经平西了，请你同我们住下吧！”耶稣就进去，要同他们住下。</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 14:19; 路加福音 24:35; 马太福音 15:36"> 到了坐席的时候，耶稣拿起饼来，祝谢了，掰开，递给他们。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 24:16; 约翰福音 8:59; 路加福音 4:30"> 他们的眼睛明亮了，这才认出他来。忽然耶稣不见了。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 24:45; 耶利米书 23:29; 希伯来书 4:12"> 他们彼此说：“在路上他和我们说话，给我们讲解圣经的时候，我们的心岂不是火热的吗？”</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 16:13; 约翰福音 20:19–26; 使徒行传 1:14"> 他们就立时起身，回耶路撒冷去。正遇见十一个使徒和他们的同人聚集在一处，</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 15:5; 马可福音 16:7; 路加福音 22:54–62"> 说：“主果然复活，已经现给西门看了。”</span>
<span className="v" id="v35" data-v="35" data-xref="马可福音 16:12–13; 使徒行传 2:42; 路加福音 24:30–31"> 两个人就把路上所遇见和掰饼的时候怎么被他们认出来的事，都述说了一遍。</span>
</div>
</div>

## 显现在耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="帖撒罗尼迦后书 3:16; 以赛亚书 57:18; 马可福音 16:14"> 正说这话的时候，耶稣亲自站在他们当中，说：<span className="woj">“愿你们平安！”</span></span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳记上 28:13; 马太福音 14:26–27; 约伯记 4:14–16"> 他们却惊慌害怕，以为所看见的是魂。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米书 4:14; 希伯来书 4:13; 但以理书 4:19"> 耶稣说：<span className="woj">“你们为什么愁烦？为什么心里起疑念呢？</span></span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 20:27; 约翰一书 1:1; 传道书 12:7"> <span className="woj">你们看我的手、我的脚，就知道实在是我了。摸我看看！魂无骨无肉，你们看，我是有的。”</span></span>
<span className="v" id="v40" data-v="40"> 说了这话，就把手和脚给他们看。</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 21:5; 诗篇 126:1–2; 创世记 45:26–28"> 他们正喜得不敢信，并且稀奇，耶稣就说：<span className="woj">“你们这里有什么吃的没有？”</span></span>
<span className="v" id="v42" data-v="42"> 他们便给他一片烧鱼，</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行传 10:41"> 他接过来，在他们面前吃了。</span>
</div>
</div>

## 等候主的应许

<div className="bt">
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="撒迦利亚书 12:10; 路加福音 24:26–27; 撒迦利亚书 9:9"> 耶稣对他们说：<span className="woj">“这就是我从前与你们同在之时所告诉你们的话说：摩西的律法、先知的书和诗篇上所记的，凡指着我的话都必须应验。”</span></span>
<span className="v" id="v45" data-v="45" data-xref="使徒行传 16:14; 约翰一书 5:20; 诗篇 119:18"> 于是耶稣开他们的心窍，使他们能明白圣经。</span>
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 53:2–12; 以赛亚书 50:6; 路加福音 24:44"> 又对他们说：<span className="woj">“照经上所写的，基督必受害，第三日从死里复活，</span></span>
<span className="v" id="v47" data-v="47" data-xref="使徒行传 5:31; 以赛亚书 49:6; 使徒行传 2:38"> <span className="woj">并且人要奉他的名传悔改、赦罪的道，从耶路撒冷起直传到万邦。</span></span>
<span className="v" id="v48" data-v="48" data-xref="使徒行传 1:8; 使徒行传 2:32; 使徒行传 13:31"> <span className="woj">你们就是这些事的见证。</span></span>
<span className="v" id="v49" data-v="49" data-xref="使徒行传 1:8; 使徒行传 1:4; 约珥书 2:28–32"> <span className="woj">我要将我父所应许的降在你们身上，你们要在城里等候，直到你们领受从上头来的能力。”</span></span>
</div>
</div>

## 主被带到天上

<div className="bt">
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="使徒行传 1:12; 马太福音 21:17; 马可福音 11:1"> 耶稣领他们到伯大尼的对面，就举手给他们祝福。</span>
<span className="v" id="v51" data-v="51" data-xref="使徒行传 1:9; 马可福音 16:19; 列王纪下 2:11"> 正祝福的时候，他就离开他们，被带到天上去了。</span>
<span className="v" id="v52" data-v="52" data-xref="马太福音 28:9; 约翰福音 16:22; 诗篇 30:11"> 他们就拜他，大大地欢喜，回耶路撒冷去，</span>
<span className="v" id="v53" data-v="53" data-xref="马可福音 16:20; 使徒行传 2:46–47; 使徒行传 5:41–42"> 常在殿里称颂神。</span>
</div>
</div>

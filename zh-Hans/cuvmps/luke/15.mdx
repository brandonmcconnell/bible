## 失羊的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3"> 耶稣就用比喻说：</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 34:16; 以西结书 34:11–12; 马太福音 18:12–14"> <span className="woj">“你们中间谁有一百只羊失去一只，不把这九十九只撇在旷野，去找那失去的羊，直到找着呢？</span></span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 12:2; 路加福音 19:9; 以赛亚书 46:3–4"> <span className="woj">找着了，就欢欢喜喜地扛在肩上，回到家里，</span></span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 15:10; 路加福音 15:24; 彼得前书 2:25"> <span className="woj">就请朋友邻舍来，对他们说：‘我失去的羊已经找着了，你们和我一同欢喜吧！’</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 5:32; 路加福音 15:10; 路加福音 15:32"> <span className="woj">我告诉你们：一个罪人悔改，在天上也要这样为他欢喜，较比为九十九个不用悔改的义人欢喜更大。”</span></span>
</div>
</div>

## 失钱的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 19:10; 以西结书 34:12; 约翰福音 10:16"> <span className="woj">“或是一个妇人有十块钱，若失落一块，岂不点上灯，打扫屋子，细细地找，直到找着吗？</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 15:6–7"> <span className="woj">找着了，就请朋友邻舍来，对他们说：‘我失落的那块钱已经找着了，你们和我一同欢喜吧！’</span></span>

## 浪子的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马太福音 21:23–31"> 耶稣又说：<span className="woj">“一个人有两个儿子。</span></span>
<span className="v" id="v12" data-v="12" data-xref="申命记 21:16–17; 马可福音 12:44; 路加福音 15:30"> <span className="woj">小儿子对父亲说：‘父亲，请你把我应得的家业分给我。’他父亲就把产业分给他们。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 29:3; 耶利米书 2:5; 箴言 21:17"> <span className="woj">过了不多几日，小儿子就把他一切所有的都收拾起来，往远方去了。在那里任意放荡，浪费资财。</span></span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 33:11; 阿摩司书 8:9–12; 何西阿书 2:9–14"> <span className="woj">既耗尽了一切所有的，又遇着那地方大遭饥荒，就穷苦起来。</span></span>
<span className="v" id="v15" data-v="15" data-xref="提多书 3:3; 提摩太后书 2:25–26; 以赛亚书 1:5"> <span className="woj">于是去投靠那地方的一个人，那人打发他到田里去放猪。</span></span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 6:19–21; 耶利米哀歌 4:5; 何西阿书 12:1"> <span className="woj">他恨不得拿猪所吃的豆荚充饥，也没有人给他。</span></span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 18:28; 以弗所书 2:4–5; 路加福音 15:18–19"> <span className="woj">他醒悟过来，就说：‘我父亲有多少的雇工，口粮有余，我倒在这里饿死吗？</span></span>
<span className="v" id="v18" data-v="18" data-xref="耶利米哀歌 3:40; 约翰一书 1:8–10; 路加福音 15:21"> <span className="woj">我要起来，到我父亲那里去，向他说：“父亲，我得罪了天，又得罪了你。</span></span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 42:6; 路加福音 5:8; 诗篇 84:10"> <span className="woj">从今以后，我不配称为你的儿子，把我当做一个雇工吧！”’</span></span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 103:10–13; 诗篇 86:5; 诗篇 86:15"> <span className="woj">于是起来，往他父亲那里去。相离还远，他父亲看见，就动了慈心，跑去抱着他的颈项，连连与他亲嘴。</span></span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 51:4; 路加福音 15:18–19; 耶利米书 3:13"> <span className="woj">儿子说：‘父亲，我得罪了天，又得罪了你。从今以后，我不配称为你的儿子。’</span></span>
<span className="v" id="v22" data-v="22" data-xref="创世记 41:42; 以斯帖记 8:2; 启示录 6:11"> <span className="woj">父亲却吩咐仆人说：‘把那上好的袍子快拿出来给他穿，把戒指戴在他指头上，把鞋穿在他脚上，</span></span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 25:6; 马太福音 22:2–14; 诗篇 63:5"> <span className="woj">把那肥牛犊牵来宰了，我们可以吃喝快乐！</span></span>
<span className="v" id="v24" data-v="24" data-xref="以弗所书 2:5; 以西结书 34:16; 路加福音 19:10"> <span className="woj">因为我这个儿子是死而复活，失而又得的。’他们就快乐起来。</span></span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 150:4; 耶利米书 31:4; 路加福音 15:11–12"> <span className="woj">那时，大儿子正在田里。他回来，离家不远，听见作乐跳舞的声音，</span></span>
<span className="v" id="v26" data-v="26"> <span className="woj">便叫过一个仆人来，问是什么事。</span></span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 9:17; 腓利门书 1:16; 使徒行传 22:13"> <span className="woj">仆人说：‘你兄弟来了，你父亲因为得他无灾无病地回来，把肥牛犊宰了。’</span></span>
<span className="v" id="v28" data-v="28" data-xref="约拿书 4:9; 撒母耳记上 18:8; 约拿书 4:1–4"> <span className="woj">大儿子却生气，不肯进去。他父亲就出来劝他。</span></span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 18:11–12; 撒迦利亚书 7:3; 以赛亚书 65:5"> <span className="woj">他对父亲说：‘我服侍你这多年，从来没有违背过你的命，你并没有给我一只山羊羔，叫我和朋友一同快乐。</span></span>
<span className="v" id="v30" data-v="30" data-xref="箴言 29:3; 路加福音 15:12–13; 路加福音 15:32"> <span className="woj">但你这个儿子和娼妓吞尽了你的产业，他一来了，你倒为他宰了肥牛犊！’</span></span>
<span className="v" id="v31" data-v="31" data-xref="马可福音 7:27–28; 罗马书 9:4; 罗马书 11:1"> <span className="woj">父亲对他说：‘儿啊！你常和我同在，我一切所有的都是你的。</span></span>
<span className="v" id="v32" data-v="32" data-xref="以弗所书 2:1–10; 路加福音 15:24; 以赛亚书 35:10"> <span className="woj">只是你这个兄弟是死而复活、失而又得的，所以我们理当欢喜快乐。’”</span></span>
</div>

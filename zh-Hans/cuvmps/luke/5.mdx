## 在革尼撒勒湖边教训人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 1:16–20; 马太福音 4:18–22; 马可福音 3:9"> 耶稣站在革尼撒勒湖边，众人拥挤他，要听神的道。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 1:19; 马太福音 4:21"> 他见有两只船湾在湖边，打鱼的人却离开船洗网去了。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 4:18; 马太福音 13:1–2; 约翰福音 1:41–42"> 有一只船是西门的，耶稣就上去，请他把船撑开，稍微离岸，就坐下，从船上教训众人。</span>
</div>
</div>

## 打鱼的将来得人

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰福音 21:6; 马太福音 17:27"> 讲完了，对西门说：<span className="woj">“把船开到水深之处，下网打鱼。”</span></span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 2:5; 约翰福音 15:14; 路加福音 6:46–48"> 西门说：“夫子，我们整夜劳力，并没有打着什么，但依从你的话，我就下网。”</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 15:58; 约翰福音 21:6–11; 传道书 11:6"> 他们下了网，就圈住许多鱼，网险些裂开，</span>
<span className="v" id="v7" data-v="7" data-xref="加拉太书 6:2; 腓立比书 4:3; 使徒行传 11:25"> 便招呼那只船上的同伴来帮助。他们就来，把鱼装满了两只船，甚至船要沉下去。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 6:5; 约伯记 42:5–6; 启示录 1:17"> 西门彼得看见，就俯伏在耶稣膝前，说：“主啊！离开我，我是个罪人！”</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 4:32; 诗篇 8:8; 马可福音 9:6"> 他和一切同在的人都惊讶这一网所打的鱼。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 4:19; 马太福音 13:47; 以西结书 47:9–10"> 他的伙伴西庇太的儿子雅各、约翰也是这样。耶稣对西门说：<span className="woj">“不要怕，从今以后你要得人了。”</span></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 4:20; 路加福音 5:28; 马太福音 19:27"> 他们把两只船拢了岸，就撇下所有的，跟从了耶稣。</span>
</div>
</div>

## 耶稣洁净长大麻风的

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="诗篇 50:15; 路加福音 17:16; 马太福音 8:2–4"> 有一回，耶稣在一个城里，有人满身长了大麻风，看见他，就俯伏在地，求他说：“主若肯，必能叫我洁净了。”</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 9:29–30; 约翰福音 4:50–53; 何西阿书 14:4"> 耶稣伸手摸他，说：<span className="woj">“我肯，你洁净了吧！”</span>大麻风立刻就离了他的身。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 14:2–32; 路加福音 17:14; 马可福音 1:44"> 耶稣嘱咐他：<span className="woj">“你切不可告诉人，只要去把身体给祭司察看，又要为你得了洁净，照摩西所吩咐的献上礼物，对众人做证据。”</span></span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 15:30–31; 路加福音 12:1; 马可福音 1:45–2"> 但耶稣的名声越发传扬出去，有极多的人聚集来听道，也指望医治他们的病。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 6:12; 马可福音 1:35–36; 马太福音 14:23"> 耶稣却退到旷野去祷告。</span>
</div>
</div>

## 医治瘫子

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 6:19; 路加福音 8:46; 马太福音 11:5"> 有一天，耶稣教训人，有法利赛人和教法师在旁边坐着，他们是从加利利各乡村和犹太并耶路撒冷来的。主的能力与耶稣同在，使他能医治病人。</span>
<span className="v" id="v18" data-v="18" data-xref="马可福音 2:3–12; 马太福音 9:2–8; 约翰福音 5:5–6"> 有人用褥子抬着一个瘫子，要抬进去放在耶稣面前，</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 2:4; 马太福音 10:27; 马太福音 24:17"> 却因人多，寻不出法子抬进去，就上了房顶，从瓦间把他连褥子缒到当中，正在耶稣面前。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 14:9; 马太福音 9:2; 马可福音 2:5"> 耶稣见他们的信心，就对瘫子说：<span className="woj">“你的罪赦了！”</span></span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 43:25; 马可福音 2:6–7; 路加福音 7:49"> 文士和法利赛人就议论说：“这说僭妄话的是谁？除了神以外，谁能赦罪呢？”</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 24:38; 以赛亚书 66:18; 诗篇 139:2"> 耶稣知道他们所议论的，就说：<span className="woj">“你们心里议论的是什么呢？</span></span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 2:9; 马太福音 9:5"> <span className="woj">或说‘你的罪赦了’，或说‘你起来行走’，哪一样容易呢？</span></span>
<span className="v" id="v24" data-v="24" data-xref="启示录 1:13; 以赛亚书 53:11; 路加福音 8:54"> <span className="woj">但要叫你们知道，人子在地上有赦罪的权柄。”</span>就对瘫子说：<span className="woj">“我吩咐你，起来，拿你的褥子回家去吧！”</span></span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 9:24; 路加福音 5:13; 诗篇 107:20–22"> 那人当众人面前立刻起来，拿着他所躺卧的褥子回家去，归荣耀于神。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 9:8; 马太福音 12:23; 路加福音 7:16"> 众人都惊奇，也归荣耀于神，并且满心惧怕，说：“我们今日看见非常的事了！”</span>
</div>
</div>

## 利未被召

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马可福音 2:13–22; 马太福音 9:9–17; 约翰福音 1:43"> 这事以后，耶稣出去，看见一个税吏，名叫利未，坐在税关上，就对他说：<span className="woj">“你跟从我来！”</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 5:11; 马太福音 19:22–27; 列王纪上 19:19–21"> 他就撇下所有的，起来跟从了耶稣。</span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 2:15; 路加福音 15:1; 哥林多前书 10:27"> 利未在自己家里为耶稣大摆筵席，有许多税吏和别人与他们一同坐席。</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 21:28–32; 路加福音 5:17; 马可福音 7:3"> 法利赛人和文士就向耶稣的门徒发怨言说：“你们为什么和税吏并罪人一同吃喝呢？”</span>
<span className="v" id="v31" data-v="31" data-xref="马可福音 2:17; 马太福音 9:12–13; 耶利米书 8:22"> 耶稣对他们说：<span className="woj">“无病的人用不着医生，有病的人才用得着。</span></span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 19:10; 路加福音 15:10; 提摩太前书 1:15–16"> <span className="woj">我来本不是召义人悔改，乃是召罪人悔改。”</span></span>
</div>
</div>

## 论禁食

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 9:14–17; 马可福音 2:18–22; 约翰福音 3:25"> 他们说：“约翰的门徒屡次禁食、祈祷，法利赛人的门徒也是这样，唯独你的门徒又吃又喝。”</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 3:29; 哥林多后书 11:2; 以赛亚书 54:5"> 耶稣对他们说：<span className="woj">“新郎和陪伴之人同在的时候，岂能叫陪伴之人禁食呢？</span></span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 17:22; 使徒行传 14:23; 使徒行传 3:21"> <span className="woj">但日子将到，新郎要离开他们，那日他们就要禁食了。”</span></span>
</div>
</div>

## 新旧难合的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="马太福音 9:16–17; 马可福音 2:21–22; 哥林多后书 6:16"> 耶稣又设一个比喻，对他们说：<span className="woj">“没有人把新衣服撕下一块来补在旧衣服上，若是这样，就把新的撕破了，并且所撕下来的那块新的和旧的也不相称。</span></span>
<span className="v" id="v37" data-v="37" data-xref="约书亚记 9:13; 诗篇 119:83; 约书亚记 9:4"> <span className="woj">也没有人把新酒装在旧皮袋里，若是这样，新酒必将皮袋裂开，酒便漏出来，皮袋也就坏了。</span></span>
<span className="v" id="v38" data-v="38" data-xref="希伯来书 8:8–13; 哥林多后书 5:17; 以西结书 36:26"> <span className="woj">但新酒必须装在新皮袋里。</span></span>
<span className="v" id="v39" data-v="39" data-xref="希伯来书 11:39; 马可福音 7:7–13; 耶利米书 6:16"> <span className="woj">没有人喝了陈酒又想喝新的，他总说陈的好。”</span></span>
</div>
</div>

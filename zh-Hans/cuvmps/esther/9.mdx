## 犹大人杀戮诸敌

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖记 3:13; 以斯帖记 8:12; 诗篇 30:11"> 十二月，乃亚达月十三日，王的谕旨将要举行，就是犹大人的仇敌盼望辖制他们的日子，犹大人反倒辖制恨他们的人。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯帖记 8:17; 以斯帖记 8:11; 诗篇 71:13"> 犹大人在亚哈随鲁王各省的城里聚集，下手击杀那要害他们的人。无人能抵挡他们，因为各族都惧怕他们。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 8:36; 以斯帖记 8:5; 但以理书 6:1–2"> 各省的首领、总督、省长和办理王事的人，因惧怕末底改，就都帮助犹大人。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 3:1; 历代志上 11:9; 撒母耳记上 2:30"> 末底改在朝中为大，名声传遍各省，日渐昌盛。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 18:34–40; 诗篇 20:7–8; 诗篇 149:6–9"> 犹大人用刀击杀一切仇敌，任意杀灭恨他们的人。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯帖记 3:15"> 在书珊城，犹大人杀灭了五百人；</span>
<span className="v" id="v7" data-v="7"> 又杀巴珊大他、达分、亚斯帕他、</span>
<span className="v" id="v8" data-v="8"> 破拉他、亚大利雅、亚利大他、</span>
<span className="v" id="v9" data-v="9"> 帕玛斯他、亚利赛、亚利代、瓦耶撒他，</span>
<span className="v" id="v10" data-v="10" data-xref="以斯帖记 5:11; 以斯帖记 8:11; 创世记 14:23"> 这十人都是哈米大他的孙子、犹大人仇敌哈曼的儿子。犹大人却没有下手夺取财物。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 当日，将书珊城被杀的人数呈在王前。</span>
<span className="v" id="v12" data-v="12" data-xref="以斯帖记 7:2; 以斯帖记 5:6"> 王对王后以斯帖说：“犹大人在书珊城杀灭了五百人，又杀了哈曼的十个儿子，在王的各省不知如何呢！现在你要什么，我必赐给你；你还求什么，也必为你成就。”</span>
<span className="v" id="v13" data-v="13" data-xref="以斯帖记 8:11; 申命记 21:23; 以斯帖记 9:15"> 以斯帖说：“王若以为美，求你准书珊的犹大人明日也照今日的旨意行，并将哈曼十个儿子的尸首挂在木架上。”</span>
<span className="v" id="v14" data-v="14"> 王便允准如此行。旨意传在书珊，人就把哈曼十个儿子的尸首挂起来了。</span>
<span className="v" id="v15" data-v="15" data-xref="以斯帖记 8:11; 以斯帖记 9:10; 以斯帖记 9:16"> 亚达月十四日，书珊的犹大人又聚集在书珊，杀了三百人，却没有下手夺取财物。</span>
<span className="v" id="v16" data-v="16" data-xref="以斯帖记 8:11; 以斯帖记 9:2; 利未记 26:7–8"> 在王各省其余的犹大人也都聚集保护性命，杀了恨他们的人七万五千，却没有下手夺取财物。这样，就脱离仇敌，得享平安。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以斯帖记 9:21; 以斯帖记 9:1; 以斯帖记 8:9"> 亚达月十三日行了这事，十四日安息，以这日为设筵欢乐的日子。</span>
<span className="v" id="v18" data-v="18" data-xref="以斯帖记 9:21; 以斯帖记 9:1; 以斯帖记 9:15"> 但书珊的犹大人，这十三、十四日聚集杀戮仇敌，十五日安息，以这日为设筵欢乐的日子。</span>
<span className="v" id="v19" data-v="19" data-xref="以斯帖记 8:17; 启示录 11:10; 尼希米记 8:10–12"> 所以住无城墙乡村的犹大人如今都以亚达月十四日为设筵欢乐的吉日，彼此馈送礼物。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命记 31:19–22; 哥林多后书 1:10–11; 诗篇 145:4–12"> 末底改记录这事，写信于亚哈随鲁王各省远近所有的犹大人，</span>
<span className="v" id="v21" data-v="21"> 嘱咐他们每年守亚达月十四、十五两日，</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 30:11; 以赛亚书 14:3; 以斯帖记 9:19"> 以这月的两日为犹大人脱离仇敌得平安，转忧为喜，转悲为乐的吉日。在这两日设筵欢乐，彼此馈送礼物，周济穷人。</span>
<span className="v" id="v23" data-v="23"> 于是，犹大人按着末底改所写于他们的信，应承照初次所守的守为永例。</span>
<span className="v" id="v24" data-v="24" data-xref="以斯帖记 3:5–13; 以斯帖记 9:10"> 是因犹大人的仇敌亚甲族哈米大他的儿子哈曼设谋杀害犹大人，掣普珥，就是掣签，为要杀尽、灭绝他们，</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 7:16; 诗篇 140:9; 诗篇 141:10"> 这事报告于王，王便降旨使哈曼谋害犹大人的恶事归到他自己的头上，并吩咐把他和他的众子都挂在木架上。</span>
</div>
</div>

## 定普珥日

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以斯帖记 9:20; 民数记 16:40; 以西结书 39:11"> 照着普珥的名字，犹大人就称这两日为普珥日。他们因这信上的话，又因所看见所遇见的事，</span>
<span className="v" id="v27" data-v="27" data-xref="撒迦利亚书 2:11; 以赛亚书 56:6; 以斯帖记 8:17"> 就应承自己与后裔并归附他们的人，每年按时必守这两日，永远不废。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 13:8–9; 约书亚记 4:7; 诗篇 103:2"> 各省各城、家家户户、世世代代纪念遵守这两日，使这普珥日在犹大人中不可废掉，在他们后裔中也不可忘记。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以斯帖记 9:20; 以斯帖记 2:15; 以斯帖记 8:10"> 亚比孩的女儿王后以斯帖和犹大人末底改以全权写第二封信，坚嘱犹大人守这普珥日。</span>
<span className="v" id="v30" data-v="30" data-xref="以斯帖记 1:1; 以斯帖记 8:9; 撒迦利亚书 8:19"> 用和平诚实话写信给亚哈随鲁王国中一百二十七省所有的犹大人，</span>
<span className="v" id="v31" data-v="31" data-xref="以斯帖记 4:3; 以斯帖记 4:16; 约拿书 3:2–9"> 劝他们按时守这普珥日，禁食、呼求，是照犹大人末底改和王后以斯帖所嘱咐的，也照犹大人为自己与后裔所应承的。</span>
<span className="v" id="v32" data-v="32" data-xref="以斯帖记 9:26"> 以斯帖命定守普珥日，这事也记录在书上。</span>
</div>
</div>

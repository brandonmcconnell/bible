## 马利亚用香膏抹主

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 14:3–8; 约翰福音 11:1; 路加福音 24:50"> 逾越节前六日，耶稣来到伯大尼，就是他叫拉撒路从死里复活之处。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 22:27; 路加福音 10:38–42; 启示录 3:20"> 有人在那里给耶稣预备筵席，马大伺候，拉撒路也在那同耶稣坐席的人中。</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 14:3–9; 约翰福音 11:2; 路加福音 10:38–39"> 马利亚就拿着一斤极贵的真哪哒香膏，抹耶稣的脚，又用自己的头发去擦，屋里就满了膏的香气。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 10:4; 撒母耳记上 17:28–29; 约翰福音 13:2"> 有一个门徒，就是那将要卖耶稣的加略人犹大，</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 18:22; 路加福音 12:33; 马可福音 14:4–5"> 说：“这香膏为什么不卖三十两银子周济穷人呢？”</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 13:29; 诗篇 50:16–20; 雅各书 2:6"> 他说这话，并不是挂念穷人，乃因他是个贼，又带着钱囊，常取其中所存的。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 26:12; 马可福音 14:6; 马太福音 27:57–60"> 耶稣说：<span className="woj">“由她吧！她是为我安葬之日存留的。</span></span>
<span className="v" id="v8" data-v="8" data-xref="申命记 15:11; 马可福音 14:7; 马太福音 26:11"> <span className="woj">因为常有穷人和你们同在，只是你们不常有我。”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 4:14; 约翰福音 11:43–45; 使徒行传 3:10–11"> 有许多犹太人知道耶稣在那里，就来了，不但是为耶稣的缘故，也是要看他从死里所复活的拉撒路。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 16:31; 马太福音 2:16; 约翰福音 11:47–53"> 但祭司长商议连拉撒路也要杀了，</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 11:45; 约翰福音 12:18; 使徒行传 13:45"> 因有好些犹太人为拉撒路的缘故，回去信了耶稣。</span>
</div>
</div>

## 主骑驴进耶路撒冷

<div className="bt">
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="马可福音 11:7–10; 马太福音 21:4–9; 路加福音 19:35–38"> 第二天，有许多上来过节的人听见耶稣将到耶路撒冷，</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 118:25–26; 启示录 15:3; 马太福音 21:9–11"> 就拿着棕树枝出去迎接他，喊着说：<br /><span className="pl pl-1">“和散那！</span><br /><span className="pl pl-1">奉主名来的以色列王是应当称颂的！”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="撒迦利亚书 9:9; 马可福音 11:1–7; 马太福音 21:1–7"> 耶稣得了一个驴驹，就骑上，如经上所记的说：</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 9:9; 以赛亚书 62:11; 西番雅书 3:16–17"> <span className="pl pl-1">“锡安的民</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“民”原文作“女子”。">a</a></sup><br /><span className="pl pl-1">哪，不要惧怕！</span><br /><span className="pl pl-1">你的王骑着驴驹来了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰福音 2:22; 约翰福音 14:26; 约翰福音 7:39"> 这些事门徒起先不明白，等到耶稣得了荣耀以后，才想起这话是指着他写的，并且众人果然向他这样行了。</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 1:2; 约翰一书 5:9–12; 约翰福音 19:35"> 当耶稣呼唤拉撒路，叫他从死复活出坟墓的时候，同耶稣在那里的众人就作见证。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 12:11"> 众人因听见耶稣行了这神迹，就去迎接他。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 17:6; 诗篇 22:27; 约翰一书 2:2"> 法利赛人彼此说：“看哪，你们是徒劳无益，世人都随从他去了！”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约翰福音 7:35; 以赛亚书 11:10; 使徒行传 17:4"> 那时，上来过节礼拜的人中，有几个希腊人。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 2:2; 路加福音 19:2–4; 约翰福音 6:40"> 他们来见加利利伯赛大的腓力，求他说：“先生，我们愿意见耶稣。”</span>
<span className="v" id="v22" data-v="22" data-xref="马可福音 10:13–14; 路加福音 9:49–50; 约翰福音 1:40–41"> 腓力去告诉安得烈，安得烈同腓力去告诉耶稣。</span>
</div>
</div>

## 耶稣向百姓末了的讲论

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约翰福音 13:31–32; 约翰福音 17:1–5; 以赛亚书 60:9"> 耶稣说：<span className="woj">“人子得荣耀的时候到了。</span></span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 15:36–38; 以赛亚书 53:10–12; 希伯来书 2:9–10"> <span className="woj">我实实在在地告诉你们：一粒麦子不落在地里死了，仍旧是一粒；若是死了，就结出许多子粒来。</span></span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 10:39; 路加福音 9:23–24; 马可福音 8:35"> <span className="woj">爱惜自己生命的，就失丧生命；在这世上恨恶自己生命的，就要保守生命到永生。</span></span>
<span className="v" id="v26" data-v="26" data-xref="歌罗西书 3:24; 加拉太书 1:10; 撒母耳记上 2:30"> <span className="woj">若有人服侍我，就当跟从我；我在哪里，服侍我的人也要在哪里。若有人服侍我，我父必尊重他。</span></span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 12:23; 希伯来书 5:7; 马太福音 26:42"> <span className="woj">我现在心里忧愁，我说什么才好呢？父啊，救我脱离这时候！但我原是为这时候来的。</span></span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 13:31–32; 马太福音 26:42; 启示录 5:9–14"> <span className="woj">父啊，愿你荣耀你的名！”</span>当时就有声音从天上来说：“我已经荣耀了我的名，还要再荣耀。”</span>
<span className="v" id="v29" data-v="29" data-xref="约伯记 37:2–5; 启示录 6:1; 启示录 14:2"> 站在旁边的众人听见，就说：“打雷了。”还有人说：“有天使对他说话。”</span>
</div>
</div>

## 主要吸引万人归己

<div className="bt">
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="约翰福音 11:42; 约翰福音 11:15; 约翰福音 5:34"> 耶稣说：<span className="woj">“这声音不是为我，是为你们来的。</span></span>
<span className="v" id="v31" data-v="31" data-xref="哥林多后书 4:4; 约翰一书 5:19; 约翰一书 3:8"> <span className="woj">现在这世界受审判，这世界的王要被赶出去。</span></span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 3:14; 约翰福音 8:28; 彼得前书 2:24"> <span className="woj">我若从地上被举起来，就要吸引万人来归我。”</span></span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 18:32; 约翰福音 21:19"> 耶稣这话原是指着自己将要怎样死说的。</span>
<span className="v" id="v34" data-v="34" data-xref="以西结书 37:24–25; 以赛亚书 9:7; 但以理书 7:14"> 众人回答说：“我们听见律法上有话说基督是永存的，你怎么说人子必须被举起来呢？这人子是谁呢？”</span>
<span className="v" id="v35" data-v="35" data-xref="约翰福音 12:46; 约翰福音 16:16; 以弗所书 5:8"> 耶稣对他们说：<span className="woj">“光在你们中间还有不多的时候，应当趁着有光行走，免得黑暗临到你们。那在黑暗里行走的，不知道往何处去。</span></span>
<span className="v" id="v36" data-v="36" data-xref="以弗所书 5:8; 约翰福音 8:59; 使徒行传 13:47–48"> <span className="woj">你们应当趁着有光，信从这光，使你们成为光明之子。”</span>应验以赛亚的预言<br />耶稣说了这话，就离开他们隐藏了。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 16:31; 约翰福音 1:11; 约翰福音 15:24"> 他虽然在他们面前行了许多神迹，他们还是不信他。</span>
<span className="v" id="v38" data-v="38" data-xref="以赛亚书 53:1; 罗马书 10:16; 罗马书 10:20"> 这是要应验先知以赛亚的话说：<br /><span className="pl pl-1">“主啊，我们所传的有谁信呢？</span><br /><span className="pl pl-1">主的膀臂向谁显露呢？”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v39" data-v="39" data-xref="约翰福音 10:38; 约翰福音 5:44; 彼得后书 2:14"> 他们所以不能信，因为以赛亚又说：</span>
<span className="v" id="v40" data-v="40" data-xref="以赛亚书 6:10; 马太福音 13:13–15; 路加福音 8:10"> <span className="pl pl-1">“主叫他们瞎了眼，</span><br /><span className="pl pl-1">硬了心，</span><br /><span className="pl pl-1">免得他们眼睛看见，</span><br /><span className="pl pl-1">心里明白，回转过来，</span><br /><span className="pl pl-1">我就医治他们。”</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 6:1–5; 以赛亚书 6:9–10; 约翰福音 1:14"> 以赛亚因为看见他的荣耀，就指着他说这话。</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 9:22; 约翰福音 7:13; 以赛亚书 51:7"> 虽然如此，官长中却有好些信他的，只因法利赛人的缘故，就不承认，恐怕被赶出会堂。</span>
<span className="v" id="v43" data-v="43" data-xref="约翰福音 5:44; 马太福音 23:5–7; 约翰福音 5:41"> 这是因他们爱人的荣耀过于爱神的荣耀。</span>
</div>
</div>

## 信子就是信父

<div className="bt">
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="马太福音 10:40; 约翰福音 13:20; 约翰福音 5:24"> 耶稣大声说：<span className="woj">“信我的，不是信我，乃是信那差我来的。</span></span>
<span className="v" id="v45" data-v="45" data-xref="约翰福音 14:9–10; 哥林多后书 4:6; 歌罗西书 1:15"> <span className="woj">人看见我，就是看见那差我来的。</span></span>
<span className="v" id="v46" data-v="46" data-xref="约翰福音 8:12; 诗篇 36:9; 约翰福音 9:5"> <span className="woj">我到世上来，乃是光，叫凡信我的不住在黑暗里。</span></span>
<span className="v" id="v47" data-v="47" data-xref="约翰福音 3:17; 约翰福音 8:15–16; 约翰福音 12:48"> <span className="woj">若有人听见我的话不遵守，我不审判他。我来本不是要审判世界，乃是要拯救世界。</span></span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 10:16; 希伯来书 9:27–28; 罗马书 2:16"> <span className="woj">弃绝我、不领受我话的人，有审判他的，就是我所讲的道在末日要审判他。</span></span>
<span className="v" id="v49" data-v="49" data-xref="约翰福音 14:10; 约翰福音 8:26; 约翰福音 5:30"> <span className="woj">因为我没有凭着自己讲，唯有差我来的父已经给我命令，叫我说什么、讲什么。</span></span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 17:3; 约翰福音 6:68; 约翰一书 5:20"> <span className="woj">我也知道他的命令就是永生。故此，我所讲的话正是照着父对我所说的。”</span></span>
</div>
</div>

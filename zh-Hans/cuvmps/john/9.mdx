## 医好生来瞎眼的

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶稣过去的时候，看见一个人生来是瞎眼的。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 13:2; 约翰福音 9:34; 使徒行传 28:4"> 门徒问耶稣说：“拉比，这人生来是瞎眼的，是谁犯了罪？是这人呢，是他父母呢？”</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 11:4; 约翰福音 11:40; 传道书 9:1–2"> 耶稣回答说：<span className="woj">“也不是这人犯了罪，也不是他父母犯了罪，是要在他身上显出神的作为来。</span></span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 12:35; 以弗所书 5:16; 约翰福音 4:34"> <span className="woj">趁着白日，我们必须做那差我来者的工；黑夜将到，就没有人能做工了。</span></span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 8:12; 约翰福音 12:46; 使徒行传 13:47"> <span className="woj">我在世上的时候，是世上的光。”</span></span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 8:23; 马可福音 7:33; 启示录 3:18"> 耶稣说了这话，就吐唾沫在地上，用唾沫和泥抹在瞎子的眼睛上，</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 35:5; 约翰福音 9:11; 约翰福音 11:37"> 对他说：<span className="woj">“你往西罗亚池子里去洗。”</span>（“西罗亚”翻出来就是“奉差遣”。）他去一洗，回头就看见了。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 2:8; 撒母耳记上 21:11; 路加福音 18:35"> 他的邻舍和那素常见他是讨饭的，就说：“这不是那从前坐着讨饭的人吗？”</span>
<span className="v" id="v9" data-v="9"> 有人说：“是他。”又有人说：“不是，却是像他。”他自己说：“是我。”</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 9:26; 约翰福音 9:21; 传道书 11:5"> 他们对他说：“你的眼睛是怎样开的呢？”</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 9:6–7; 约翰福音 9:27; 耶利米书 36:17"> 他回答说：“有一个人名叫耶稣，他和泥抹我的眼睛，对我说：‘你往西罗亚池子去洗。’我去一洗，就看见了。”</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 5:11–13; 出埃及记 2:18–20; 约翰福音 7:11"> 他们说：“那个人在哪里？”他说：“我不知道。”</span>
</div>
</div>

## 法利赛人盘问医好的瞎子

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约翰福音 11:57; 约翰福音 11:46–47; 约翰福音 12:42"> 他们把从前瞎眼的人带到法利赛人那里。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 5:9; 路加福音 13:10–17; 马太福音 12:1–14"> 耶稣和泥开他眼睛的日子是安息日。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 9:26–27; 约翰福音 9:10–11"> 法利赛人也问他是怎么得看见的。瞎子对他们说：“他把泥抹在我的眼睛上，我去一洗，就看见了。”</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 7:43; 约翰福音 10:19; 马太福音 12:2"> 法利赛人中有的说：“这个人不是从神来的，因为他不守安息日。”又有人说：“一个罪人怎能行这样的神迹呢？”他们就起了纷争。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 4:19; 约翰福音 6:14; 使徒行传 3:22–26"> 他们又对瞎子说：“他既然开了你的眼睛，你说他是怎样的人呢？”他说：“是个先知。”</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 3:15–19; 约翰福音 5:44; 以赛亚书 26:11"> 犹太人不信他从前是瞎眼、后来能看见的，等到叫了他的父母来，</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 9:8–9; 使徒行传 4:14; 使徒行传 3:10"> 问他们说：“这是你们的儿子吗？你们说他生来是瞎眼的，如今怎么能看见了呢？”</span>
<span className="v" id="v20" data-v="20"> 他父母回答说：“他是我们的儿子，生来就瞎眼，这是我们知道的。</span>
<span className="v" id="v21" data-v="21"> 至于他如今怎么能看见，我们却不知道。是谁开了他的眼睛，我们也不知道。他已经成了人，你们问他吧，他自己必能说。”</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 7:13; 约翰福音 16:2; 路加福音 6:22"> 他父母说这话是怕犹太人，因为犹太人已经商议定了，若有认耶稣是基督的，要把他赶出会堂。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 9:21"> 因此他父母说“他已经成了人，你们问他吧”。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 7:19; 约翰福音 9:16; 约翰福音 8:49"> 所以法利赛人第二次叫了那从前瞎眼的人来，对他说：“你该将荣耀归给神，我们知道这人是个罪人。”</span>
<span className="v" id="v25" data-v="25" data-xref="约翰一书 5:10; 约翰福音 9:30; 约翰福音 5:11"> 他说：“他是个罪人不是，我不知道。有一件事我知道：从前我是眼瞎的，如今能看了！”</span>
<span className="v" id="v26" data-v="26"> 他们就问他说：“他向你做什么？是怎么开了你的眼睛呢？”</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 22:67; 约翰福音 9:10–15"> 他回答说：“我方才告诉你们，你们不听，为什么又要听呢？莫非你们也要做他的门徒吗？”</span>
<span className="v" id="v28" data-v="28" data-xref="罗马书 2:17; 约翰福音 7:19; 马太福音 27:39"> 他们就骂他，说：“你是他的门徒！我们是摩西的门徒。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 8:14; 民数记 12:2–7; 使徒行传 7:35"> 神对摩西说话是我们知道的，只是这个人，我们不知道他从哪里来！”</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 12:37; 诗篇 119:18; 以赛亚书 29:18"> 那人回答说：“他开了我的眼睛，你们竟不知道他从哪里来，这真是奇怪！</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 15:29; 以赛亚书 1:15; 箴言 28:9"> 我们知道神不听罪人，唯有敬奉神、遵行他旨意的，神才听他。</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 64:4; 启示录 16:18; 约伯记 20:4"> 从创世以来，未曾听见有人把生来是瞎子的眼睛开了。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 9:16; 约翰福音 3:2; 使徒行传 5:38–39"> 这人若不是从神来的，什么也不能做。”</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 9:22; 约翰福音 9:2; 以赛亚书 66:5"> 他们回答说：“你全然生在罪孽中，还要教训我们吗？”于是把他赶出去了。</span>
</div>
</div>

## 耶稣收留被逐的瞎子

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="约翰福音 20:31; 约翰一书 5:13; 约翰福音 10:36"> 耶稣听说他们把他赶出去，后来遇见他，就说：<span className="woj">“你信神的儿子吗？”</span></span>
<span className="v" id="v36" data-v="36" data-xref="罗马书 10:14; 雅歌 5:9; 约翰福音 1:38"> 他回答说：“主啊，谁是神的儿子，叫我信他呢？”</span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 4:26; 诗篇 25:8–9; 约翰福音 14:21–23"> 耶稣说：<span className="woj">“你已经看见他，现在和你说话的就是他。”</span></span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 14:33; 马太福音 28:9; 路加福音 24:52"> 他说：“主啊，我信！”就拜耶稣。</span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 3:19; 约翰福音 12:46; 使徒行传 26:18"> 耶稣说：<span className="woj">“我为审判到这世上来，叫不能看见的可以看见，能看见的反瞎了眼。”</span></span>
<span className="v" id="v40" data-v="40" data-xref="启示录 3:17; 马太福音 15:12–14; 约翰福音 7:47–52"> 同他在那里的法利赛人听见这话，就说：“难道我们也瞎了眼吗？”</span>
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 5:21; 约翰福音 15:22–24; 约翰一书 1:8–10"> 耶稣对他们说：<span className="woj">“你们若瞎了眼，就没有罪了；但如今你们说‘我们能看见’，所以你们的罪还在。</span></span>
</div>

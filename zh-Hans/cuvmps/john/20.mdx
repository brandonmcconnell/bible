## 马利亚往看坟墓

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 16:9; 马太福音 27:60; 约翰福音 19:25"> 七日的第一日清早，天还黑的时候，抹大拉的马利亚来到坟墓那里，看见石头从坟墓挪开了，</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 13:23; 约翰福音 20:13; 约翰福音 21:24"> 就跑来见西门彼得和耶稣所爱的那个门徒，对他们说：“有人把主从坟墓里挪了去，我们不知道放在哪里！”</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 24:12"> 彼得和那门徒就出来，往坟墓那里去。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 18:23; 哥林多后书 8:12; 哥林多前书 9:24"> 两个人同跑，那门徒比彼得跑的更快，先到了坟墓，</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 19:40; 约翰福音 20:11; 约翰福音 11:44"> 低头往里看，就见细麻布还放在那里，只是没有进去。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 18:17; 约翰福音 21:7; 马太福音 16:15–16"> 西门彼得随后也到了，进坟墓里去，就看见细麻布还放在那里，</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 11:44"> 又看见耶稣的裹头巾没有和细麻布放在一处，是另在一处卷着。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 20:25; 约翰福音 20:4; 约翰福音 1:50"> 先到坟墓的那门徒也进去，看见就信了。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 16:10; 以赛亚书 25:8; 以赛亚书 53:10–12"> 因为他们还不明白圣经的意思，就是耶稣必要从死里复活。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 7:53; 约翰福音 16:32"> 于是两个门徒回自己的住处去了。</span>
</div>
</div>

## 见证主复活

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约翰福音 20:5"> 马利亚却站在坟墓外面哭。哭的时候，低头往坟墓里看，</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 24:3–7; 启示录 3:4; 马可福音 16:5–6"> 就见两个天使，穿着白衣，在安放耶稣身体的地方坐着，一个在头，一个在脚。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 20:15; 约翰福音 2:4; 撒母耳记上 1:8"> 天使对她说：“妇人，你为什么哭？”她说：“因为有人把我主挪了去，我不知道放在哪里。”</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 24:16; 约翰福音 21:4; 马太福音 28:9"> 说了这话，就转过身来，看见耶稣站在那里，却不知道是耶稣。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 20:13; 约翰福音 18:7; 约翰福音 1:38"> 耶稣问她说：<span className="woj">“妇人，为什么哭？你找谁呢？”马利亚</span>以为是看园的，就对他说：“先生，若是你把他移了去，请告诉我你把他放在哪里，我便去取他。”</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 10:3; 约翰福音 1:38; 使徒行传 10:3"> 耶稣说：<span className="woj">“马利亚！”马利亚</span>就转过来，用希伯来话对他说：“拉波尼！”（“拉波尼”就是“夫子”的意思。）</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 16:28; 以弗所书 4:8–10; 加拉太书 4:6–7"> 耶稣说：<span className="woj">“不要摸我，因我还没有升上去见我的父。你往我弟兄那里去，告诉他们说我要升上去见我的父，也是你们的父，见我的神，也是你们的神。”</span></span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 24:10; 马太福音 28:10; 约翰福音 20:1"> 抹大拉的马利亚就去告诉门徒说：“我已经看见了主！”她又将主对她说的这话告诉他们。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约翰福音 20:26; 约翰福音 14:27; 约翰福音 20:21"> 那日，就是七日的第一日晚上，门徒所在的地方，因怕犹太人，门都关了。耶稣来站在当中，对他们说：<span className="woj">“愿你们平安！”</span></span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 16:22; 约翰福音 16:20; 约翰福音 20:27"> 说了这话，就把手和肋旁指给他们看。门徒看见主，就喜乐了。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 17:18–19; 约翰福音 13:20; 约翰福音 3:17"> 耶稣又对他们说：<span className="woj">“愿你们平安！父怎样差遣了我，我也照样差遣你们。”</span></span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 33:4; 创世记 2:7; 使徒行传 8:15"> 说了这话，就向他们吹一口气，说：<span className="woj">“你们受圣灵！</span></span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 18:18; 马太福音 16:19; 马可福音 2:5–10"> <span className="woj">你们赦免谁的罪，谁的罪就赦免了；你们留下谁的罪，谁的罪就留下了。”</span></span>
</div>
</div>

## 多马不信

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约翰福音 11:16; 约翰福音 6:66–67; 希伯来书 10:25"> 那十二个门徒中有称为低土马的多马，耶稣来的时候，他没有和他们同在。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 6:30; 马可福音 16:11; 希伯来书 3:12"> 那些门徒就对他说：“我们已经看见主了！”多马却说：“我非看见他手上的钉痕，用指头探入那钉痕，又用手探入他的肋旁，我总不信。”</span>
</div>
</div>

## 多马释疑

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="约翰福音 20:19; 以赛亚书 54:10; 约翰福音 20:21"> 过了八日，门徒又在屋里，多马也和他们同在。门都关了，耶稣来站在当中说：<span className="woj">“愿你们平安！”</span></span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 20:25; 约翰一书 1:1–2; 约翰福音 20:20"> 就对多马说：<span className="woj">“伸过你的指头来，摸</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“摸”原文作“看”。">a</a></sup><span className="woj">我的手！伸出你的手来，探入我的肋旁！不要疑惑，总要信！”</span></span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 1:1; 以赛亚书 9:6; 以赛亚书 7:14"> 多马说：“我的主！我的神！”</span>
<span className="v" id="v29" data-v="29" data-xref="彼得前书 1:8; 哥林多后书 5:7; 希伯来书 11:1"> 耶稣对他说：<span className="woj">“你因看见了我才信，那没有看见就信的有福了！”</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约翰福音 21:25; 提摩太后书 3:15–17; 罗马书 15:4"> 耶稣在门徒面前另外行了许多神迹，没有记在这书上。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 10:43; 约翰福音 3:15–16; 约翰一书 5:1"> 但记这些事要叫你们信耶稣是基督，是神的儿子，并且叫你们信了他，就可以因他的名得生命。</span>
</div>
</div>

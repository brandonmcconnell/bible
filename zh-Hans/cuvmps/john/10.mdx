## 羊圈的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 7:15; 约翰福音 10:8–10; 罗马书 16:18"> <span className="woj">“我实实在在地告诉你们：人进羊圈，不从门进去，倒从别处爬进去，那人就是贼，就是强盗。</span></span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 10:14; 使徒行传 20:28; 彼得前书 5:4"> <span className="woj">从门进去的，才是羊的牧人。</span></span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 34:11–16; 提摩太后书 2:19; 约翰福音 10:4"> <span className="woj">看门的就给他开门，羊也听他的声音。他按着名叫自己的羊，把羊领出来。</span></span>
<span className="v" id="v4" data-v="4" data-xref="申命记 1:30; 约翰福音 10:16; 约翰福音 12:26"> <span className="woj">既放出自己的羊来，就在前头走，羊也跟着他，因为认得他的声音。</span></span>
<span className="v" id="v5" data-v="5" data-xref="约翰一书 4:5–6; 歌罗西书 2:6–10; 马可福音 4:24"> <span className="woj">羊不跟着生人，因为不认得他的声音，必要逃跑。”</span></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 56:11; 诗篇 82:5; 箴言 28:5"> 耶稣将这比喻告诉他们，但他们不明白所说的是什么意思。</span>
</div>
</div>

## 主是羊的门

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约翰福音 14:6; 以弗所书 2:18; 约翰福音 10:1"> 所以，耶稣又对他们说：<span className="woj">“我实实在在地告诉你们：我就是羊的门。</span></span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 34:2; 耶利米书 23:1; 约翰福音 10:1"> <span className="woj">凡在我以先来的都是贼，是强盗，羊却不听他们。</span></span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 14:6; 以弗所书 2:18; 约翰福音 10:7"> <span className="woj">我就是门，凡从我进来的，必然得救，并且出入得草吃。</span></span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 19:10; 约翰福音 6:51; 约翰福音 12:47"> <span className="woj">盗贼来，无非要偷窃、杀害、毁坏；我来了，是要叫羊</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：人。">a</a></sup><span className="woj">得生命，并且得的更丰盛。</span></span>
</div>
</div>

## 主是好牧人

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约翰福音 10:14–15; 诗篇 23:1; 约翰福音 15:13"> <span className="woj">“我是好牧人，好牧人为羊舍命。</span></span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 20:29; 撒迦利亚书 11:16–17; 以西结书 34:2–6"> <span className="woj">若是雇工，不是牧人，羊也不是他自己的，他看见狼来，就撇下羊逃走，狼抓住羊，赶散了羊群。</span></span>
<span className="v" id="v13" data-v="13" data-xref="腓立比书 2:20; 约翰福音 12:6; 使徒行传 18:17"> <span className="woj">雇工逃走，因他是雇工，并不顾念羊。</span></span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 10:27; 约翰福音 10:11; 提摩太后书 2:19"> <span className="woj">我是好牧人，我认识我的羊，我的羊也认识我，</span></span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 1:4; 约翰福音 10:11; 以赛亚书 53:10"> <span className="woj">正如父认识我，我也认识父一样；并且我为羊舍命。</span></span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 56:8; 约翰福音 11:52; 彼得前书 2:25"> <span className="woj">我另外有羊，不是这圈里的，我必须领它们来，它们也要听我的声音，并且要合成一群，归一个牧人了。</span></span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 10:18; 约翰福音 10:11; 希伯来书 2:9"> <span className="woj">我父爱我，因我将命舍去，好再取回来。</span></span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 2:9; 提多书 2:14; 约翰福音 2:19–21"> <span className="woj">没有人夺我的命去，是我自己舍的。我有权柄舍了，也有权柄取回来，这是我从我父所受的命令。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约翰福音 9:16; 哥林多前书 3:3; 约翰福音 7:40–43"> 犹太人为这些话又起了纷争。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 7:20; 马可福音 3:21; 约翰福音 8:47–48"> 内中有好些人说：“他是被鬼附着，而且疯了！为什么听他呢？”</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 4:11; 以赛亚书 35:5–6; 诗篇 94:9"> 又有人说：“这不是鬼附之人所说的话。鬼岂能叫瞎子的眼睛开了呢？”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 在耶路撒冷有修殿节，是冬天的时候。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 5:12; 使徒行传 3:11"> 耶稣在殿里所罗门的廊下行走。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 22:67–70; 约翰福音 1:19; 约翰福音 8:25"> 犹太人围着他，说：“你叫我们犹疑不定到几时呢？你若是基督，就明明地告诉我们。”</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 10:38; 约翰福音 8:58; 约翰福音 14:11"> 耶稣回答说：<span className="woj">“我已经告诉你们，你们不信。我奉我父之名所行的事可以为我作见证，</span></span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 8:47; 哥林多后书 4:3–4; 约翰福音 12:37–40"> <span className="woj">只是你们不信，因为你们不是我的羊。</span></span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 10:16; 约翰福音 10:14; 启示录 3:20"> <span className="woj">我的羊听我的声音，我也认识他们，他们也跟着我。</span></span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 6:39–40; 约翰福音 6:37; 约翰福音 3:15–16"> <span className="woj">我又赐给他们永生，他们永不灭亡，谁也不能从我手里把他们夺去。</span></span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 6:37; 约翰福音 17:2; 约翰福音 17:9"> <span className="woj">我父把羊赐给我，他比万有都大，谁也不能从我父手里把他们夺去。</span></span>
</div>
</div>

## 主与父原为一

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约翰福音 1:1–2; 约翰福音 14:9; 约翰福音 17:21–23"> <span className="woj">“我与父原为一。”</span></span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 5:18; 约翰福音 8:59; 撒母耳记上 30:6"> 犹太人又拿起石头来要打他。</span>
<span className="v" id="v32" data-v="32" data-xref="约翰一书 3:12; 约翰福音 5:36; 诗篇 35:12"> 耶稣对他们说：<span className="woj">“我从父显出许多善事给你们看，你们是为哪一件拿石头打我呢？”</span></span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 5:18; 利未记 24:16; 约翰福音 10:30"> 犹太人回答说：“我们不是为善事拿石头打你，是为你说僭妄的话；又为你是个人，反将自己当做神。”</span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 82:6–7; 出埃及记 7:1; 诗篇 82:1"> 耶稣说：<span className="woj">“你们的律法上岂不是写着‘我曾说你们是神’吗？</span></span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 24:35; 罗马书 13:1; 路加福音 16:17"> <span className="woj">经上的话是不能废的。若那些承受神道的人尚且称为神，</span></span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 5:17–18; 约翰福音 3:17; 耶利米书 1:5"> <span className="woj">父所分别为圣又差到世间来的，他自称是神的儿子，你们还向他说‘你说僭妄的话’吗？</span></span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 15:24; 约翰福音 10:25; 约翰福音 12:37–40"> <span className="woj">我若不行我父的事，你们就不必信我。</span></span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 14:20; 约翰福音 10:25; 约翰福音 10:30"> <span className="woj">我若行了，你们纵然不信我，也当信这些事，叫你们又知道又明白：父在我里面，我也在父里面。”</span></span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 7:30; 约翰福音 8:59; 约翰福音 7:44"> 他们又要拿他，他却逃出他们的手走了。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="约翰福音 1:28; 约翰福音 11:54; 约翰福音 7:1"> 耶稣又往约旦河外去，到了约翰起初施洗的地方，就住在那里。</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 1:33–34; 约翰福音 1:29–30; 马可福音 1:37"> 有许多人来到他那里，他们说：“约翰一件神迹没行过，但约翰指着这人所说的一切话是真的。”</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 4:41; 约翰福音 2:23; 约翰福音 7:31"> 在那里信耶稣的人就多了。</span>
</div>
</div>

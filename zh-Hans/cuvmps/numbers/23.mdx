## 巴兰歌诗

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="民数记 23:29; 犹大书 1:11; 出埃及记 27:1–8"> 巴兰对巴勒说：“你在这里给我筑七座坛，为我预备七只公牛、七只公羊。”</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 23:14; 民数记 23:30"> 巴勒照巴兰的话行了。巴勒和巴兰在每座坛上献一只公牛、一只公羊。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 23:15; 创世记 8:20; 创世记 22:2"> 巴兰对巴勒说：“你站在你的燔祭旁边，我且往前去，或者耶和华来迎见我。他指示我什么，我必告诉你。”于是巴兰上一净光的高处。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 23:16; 以弗所书 2:9; 路加福音 18:12"> 神迎见巴兰。巴兰说：“我预备了七座坛，在每座坛上献了一只公牛、一只公羊。”</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 18:18; 耶利米书 1:9; 以赛亚书 59:21"> 耶和华将话传给巴兰，又说：“你回到巴勒那里，要如此如此说。”</span>
<span className="v" id="v6" data-v="6"> 他就回到巴勒那里，见他同摩押的使臣都站在燔祭旁边。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 23:4; 民数记 24:3; 民数记 22:5–6"> 巴兰便题起诗歌说：<br /><span className="pl pl-1">“巴勒引我出亚兰，</span><br /><span className="pl pl-1">摩押王引我出东山，说：</span><br /><span className="pl pl-1">‘来啊，为我咒诅雅各！</span><br /><span className="pl pl-1">来啊，怒骂以色列！’</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="民数记 23:23; 以赛亚书 44:25; 民数记 23:20"> <span className="pl pl-1">神没有咒诅的，我焉能咒诅？</span><br /><span className="pl pl-1">耶和华没有怒骂的，我焉能怒骂？</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="申命记 33:28; 申命记 32:8; 出埃及记 33:16"> <span className="pl pl-1">我从高峰看他，从小山望他，</span><br /><span className="pl pl-1">这是独居的民，不列在万民中。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 37:37; 创世记 13:16; 诗篇 116:15"> <span className="pl pl-1">谁能数点雅各的尘土？</span><br /><span className="pl pl-1">谁能计算以色列的四分之一？</span><br /><span className="pl pl-1">我愿如义人之死而死，</span><br /><span className="pl pl-1">我愿如义人之终而终。”</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="尼希米记 13:2; 民数记 24:10; 民数记 22:17"> 巴勒对巴兰说：“你向我做的是什么事呢？我领你来咒诅我的仇敌，不料，你竟为他们祝福！”</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 22:38; 民数记 23:20; 民数记 23:26"> 他回答说：“耶和华传给我的话，我能不谨慎传说吗？”</span>
</div>
</div>

## 复歌诗

<div className="bt">
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="诗篇 109:17; 雅各书 3:9–10; 民数记 22:41"> 巴勒说：“求你同我往别处去，在那里可以看见他们。你不能全看见，只能看见他们边界上的人。在那里要为我咒诅他们。”</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 46:6; 民数记 23:29; 以赛亚书 1:10–11"> 于是领巴兰到了琐腓田，上了毗斯迦山顶，筑了七座坛，每座坛上献一只公牛、一只公羊。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 23:3; 民数记 22:8"> 巴兰对巴勒说：“你站在这燔祭旁边，等我往那边去迎见耶和华。”</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 23:5; 民数记 24:1; 民数记 22:35"> 耶和华临到巴兰那里，将话传给他，又说：“你回到巴勒那里，要如此如此说。”</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 23:26; 撒母耳记上 3:17; 耶利米书 37:17"> 他就回到巴勒那里，见他站在燔祭旁边，摩押的使臣也和他在一处。巴勒问他说：“耶和华说了什么话呢？”</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 3:20"> 巴兰就题诗歌说：<br /><span className="pl pl-1">“巴勒，你起来听；</span><br /><span className="pl pl-1">西拨的儿子，你听我言。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 15:29; 雅各书 1:17; 玛拉基书 3:6"> <span className="pl pl-1">神非人，必不至说谎；</span><br /><span className="pl pl-1">也非人子，必不至后悔。</span><br /><span className="pl pl-1">他说话岂不照着行呢？</span><br /><span className="pl pl-1">他发言岂不要成就呢？</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 10:27–29; 民数记 22:12; 创世记 12:2"> <span className="pl pl-1">我奉命祝福，</span><br /><span className="pl pl-1">神也曾赐福，此事我不能翻转。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 23:4; 马太福音 1:23; 耶利米书 50:20"> <span className="pl pl-1">他未见雅各中有罪孽，</span><br /><span className="pl pl-1">也未见以色列中有奸恶。</span><br /><span className="pl pl-1">耶和华他的神和他同在，</span><br /><span className="pl pl-1">有欢呼王的声音在他们中间。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="民数记 24:8; 申命记 33:17; 约伯记 39:9–11"> <span className="pl pl-1">神领他们出埃及，</span><br /><span className="pl pl-1">他们似乎有野牛之力。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 10:18–19; 约书亚记 13:22; 加拉太书 1:23–24"> <span className="pl pl-1">断没有法术可以害雅各，</span><br /><span className="pl pl-1">也没有占卜可以害以色列。</span><br /><span className="pl pl-1">现在必有人论及雅各，就是论及以色列说：</span><br /><span className="pl pl-1">‘神为他行了何等的大事！’</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="创世记 49:27; 创世记 49:9; 民数记 24:17"> <span className="pl pl-1">这民起来仿佛母狮，</span><br /><span className="pl pl-1">挺身好像公狮，</span><br /><span className="pl pl-1">未曾吃野食，</span><br /><span className="pl pl-1">未曾喝被伤者之血，决不躺卧。”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="诗篇 2:1–3"> 巴勒对巴兰说：“你一点不要咒诅他们，也不要为他们祝福。”</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 5:29; 民数记 22:18; 使徒行传 4:19–20"> 巴兰回答巴勒说：“我岂不是告诉你说，凡耶和华所说的，我必须遵行吗？”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="罗马书 11:29; 箴言 21:30; 民数记 23:19–20"> 巴勒对巴兰说：“来吧，我领你往别处去，或者神喜欢你在那里为我咒诅他们。”</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 21:20; 诗篇 106:28"> 巴勒就领巴兰到那下望旷野的毗珥山顶上。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 23:1–2"> 巴兰对巴勒说：“你在这里为我筑七座坛，又在这里为我预备七只公牛、七只公羊。”</span>
<span className="v" id="v30" data-v="30"> 巴勒就照巴兰的话行，在每座坛上献一只公牛、一只公羊。</span>
</div>
</div>

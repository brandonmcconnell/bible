## 哥辖子孙之职任

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华晓谕摩西、亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 3:27; 民数记 3:19"> “你从利未人中，将哥辖子孙的总数，照他们的家室、宗族，</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 4:23; 历代志上 23:3–5; 列王纪下 11:4–12"> 从三十岁直到五十岁，凡前来任职，在会幕里办事的，全都计算。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 4:19; 马可福音 13:34; 民数记 4:30"> 哥辖子孙在会幕搬运至圣之物，所办的事乃是这样：</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 27:51; 希伯来书 9:3; 出埃及记 40:3"> 起营的时候，亚伦和他儿子要进去摘下遮掩柜的幔子，用以蒙盖法柜。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 25:13–15; 出埃及记 35:19; 民数记 4:7–8"> 又用海狗皮盖在上头，再蒙上纯蓝色的毯子，把杠穿上。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 24:5–8; 出埃及记 37:10–16; 出埃及记 25:23–30"> 又用蓝色毯子铺在陈设饼的桌子上，将盘子、调羹、奠酒的爵和杯摆在上头，桌子上也必有常设的饼。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 4:6–7; 民数记 4:11–13; 民数记 4:9"> 在其上又要蒙朱红色的毯子，再蒙上海狗皮，把杠穿上。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 25:31–39; 出埃及记 37:17–24; 启示录 1:20–1"> 要拿蓝色毯子，把灯台和灯台上所用的灯盏、剪子、蜡花盘并一切盛油的器皿，全都遮盖。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 4:12; 民数记 4:6"> 又要把灯台和灯台的一切器具包在海狗皮里，放在抬架上。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 40:5; 出埃及记 30:1–19; 出埃及记 40:26–27"> 在金坛上要铺蓝色毯子，蒙上海狗皮，把杠穿上。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 9:29; 出埃及记 25:9; 历代志下 4:22"> 又要把圣所用的一切器具包在蓝色毯子里，用海狗皮蒙上，放在抬架上。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 6:12–13; 出埃及记 39:1; 出埃及记 39:41"> 要收去坛上的灰，把紫色毯子铺在坛上。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 4:19; 出埃及记 38:1–7"> 又要把所用的一切器具，就是火鼎、肉叉子、铲子、盘子，一切属坛的器具都摆在坛上。又蒙上海狗皮，把杠穿上。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 6:6–7; 民数记 7:9; 申命记 31:9"> 将要起营的时候，亚伦和他儿子把圣所和圣所的一切器具遮盖完了，哥辖的子孙就要来抬，只是不可摸圣物，免得他们死亡。会幕里这些物件是哥辖子孙所当抬的。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 25:6; 利未记 24:2; 出埃及记 30:23–38"> 祭司亚伦的儿子以利亚撒所要看守的是点灯的油与香料，并当献的素祭和膏油，也要看守全帐幕与其中所有的，并圣所和圣所的器具。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和华晓谕摩西、亚伦说：</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 6:6–7; 民数记 17:10; 民数记 18:5"> “你们不可将哥辖人的支派从利未人中剪除。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 4:15"> 他们挨近至圣物的时候，亚伦和他儿子要进去，派他们各人所当办的、所当抬的。这样待他们，好使他们活着，不致死亡。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 6:19; 出埃及记 19:21; 民数记 4:15"> 只是他们连片时不可进去观看圣所，免得他们死亡。”</span>
</div>
</div>

## 革顺子孙之职任

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21"> 耶和华晓谕摩西说：</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 3:18; 民数记 3:21; 民数记 3:24"> “你要将革顺子孙的总数，照着宗族、家室，</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 4:3; 提摩太前书 1:18; 哥林多前书 9:7"> 从三十岁直到五十岁，凡前来任职，在会幕里办事的，全都数点。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 4:19; 民数记 4:31–32; 民数记 4:47"> 革顺人各族所办的事、所抬的物乃是这样：</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 3:25–26; 出埃及记 26:14; 民数记 7:5–7"> 他们要抬帐幕的幔子和会幕，并会幕的盖与其上的海狗皮和会幕的门帘，</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 35:18; 出埃及记 27:9"> 院子的帷子和门帘（院子是围帐幕和坛的）、绳子，并所用的器具，不论是做什么用的，他们都要经理。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 1:70; 哥林多前书 11:2"> 革顺的子孙在一切抬物办事之上都要凭亚伦和他儿子的吩咐。他们所当抬的，要派他们看守。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 4:33; 哥林多前书 12:5–6"> 这是革顺子孙的各族在会幕里所办的事。他们所看守的，必在祭司亚伦儿子以他玛的手下。</span>
</div>
</div>

## 米拉利子孙之职任

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数记 3:33–35"> “至于米拉利的子孙，你要照着家室、宗族把他们数点。</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 4:3; 民数记 4:23; 提摩太后书 2:4"> 从三十岁直到五十岁，凡前来任职，在会幕里办事的，你都要数点。</span>
<span className="v" id="v31" data-v="31" data-xref="民数记 3:36–37; 出埃及记 26:15; 民数记 7:8–9"> 他们办理会幕的事，就是抬帐幕的板、闩、柱子和带卯的座，</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 38:21; 历代志上 9:29; 民数记 3:8"> 院子四围的柱子和其上带卯的座，橛子、绳子，并一切使用的器具。他们所抬的器具，你们要按名指定。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 4:28; 约书亚记 3:6; 以赛亚书 3:6"> 这是米拉利子孙各族在会幕里所办的事，都在祭司亚伦儿子以他玛的手下。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> 摩西、亚伦与会众的诸首领将哥辖的子孙，照着家室、宗族，</span>
<span className="v" id="v35" data-v="35" data-xref="历代志上 23:24; 民数记 4:23; 历代志上 23:3"> 从三十岁直到五十岁，凡前来任职，在会幕里办事的，都数点了，</span>
<span className="v" id="v36" data-v="36"> 被数的共有二千七百五十名。</span>
<span className="v" id="v37" data-v="37"> 这是哥辖各族中被数的，是在会幕里办事的，就是摩西、亚伦照耶和华藉摩西所吩咐数点的。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> 革顺子孙被数的，照着家室、宗族，</span>
<span className="v" id="v39" data-v="39"> 从三十岁直到五十岁，凡前来任职，在会幕里办事的，共有二千六百三十名。</span>
<span className="v" id="v41" data-v="41"> 这是革顺子孙各族中被数的，是在会幕里办事的，就是摩西、亚伦照耶和华藉摩西所吩咐数点的。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> 米拉利子孙中各族被数的，照着家室、宗族，</span>
<span className="v" id="v43" data-v="43"> 从三十岁直到五十岁，凡前来任职，在会幕里办事的，共有三千二百名。</span>
<span className="v" id="v45" data-v="45" data-xref="民数记 4:29"> 这是米拉利子孙各族中被数的，就是摩西、亚伦照耶和华藉摩西所吩咐数点的。</span>
</div>
</div>

## 记利未人自三十岁至五十岁者之数

<div className="bt">
<div className="bp">
<span className="v" id="v46" data-v="46"> 凡被数的利未人，就是摩西、亚伦并以色列众首领，照着家室、宗族所数点的，</span>
<span className="v" id="v47" data-v="47" data-xref="哥林多前书 12:4–31; 罗马书 12:6–8; 民数记 4:3"> 从三十岁直到五十岁，凡前来任职，在会幕里做抬物之工的，共有八千五百八十名。</span>
<span className="v" id="v49" data-v="49" data-xref="民数记 1:54; 民数记 4:31; 民数记 4:15"> 摩西按他们所办的事、所抬的物，凭耶和华的吩咐数点他们。他们这样被摩西数点，正如耶和华所吩咐他的。</span>
</div>
</div>

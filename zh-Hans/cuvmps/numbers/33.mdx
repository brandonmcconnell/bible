## 记以色列人由兰塞起行至伯亚什亭

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 77:20; 弥迦书 6:4; 出埃及记 12:51"> 以色列人按着军队，在摩西、亚伦的手下出埃及地所行的路程<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：站口。下同。">a</a></sup>记在下面。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 9:17–23; 申命记 10:11; 民数记 10:6"> 摩西遵着耶和华的吩咐记载他们所行的路程，其路程乃是这样：</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 14:8; 出埃及记 12:37; 出埃及记 13:4"> 正月十五日，就是逾越节的次日，以色列人从兰塞起行，在一切埃及人眼前昂然无惧地出去。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 12:12; 以赛亚书 19:1; 出埃及记 18:11"> 那时，埃及人正葬埋他们的长子，就是耶和华在他们中间所击杀的，耶和华也败坏他们的神。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及记 12:37"> 以色列人从兰塞起行，安营在疏割。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 13:20"> 从疏割起行，安营在旷野边的以倘。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 14:2; 出埃及记 14:9; 民数记 33:8"> 从以倘起行，转到比哈希录，是在巴力洗分对面，就在密夺安营。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 15:22–26; 出埃及记 14:21–31"> 从比哈希录对面起行，经过海中到了书珥旷野，又在伊坦的旷野走了三天的路程，就安营在玛拉。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 15:27"> 从玛拉起行，来到以琳，以琳有十二股水泉，七十棵棕树，就在那里安营。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 16:1; 出埃及记 17:1"> 从以琳起行，安营在红海边。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 16:1"> 从红海边起行，安营在汛的旷野。</span>
<span className="v" id="v12" data-v="12"> 从汛的旷野起行，安营在脱加。</span>
<span className="v" id="v13" data-v="13"> 从脱加起行，安营在亚录。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 17:1–8; 出埃及记 19:2"> 从亚录起行，安营在利非订，在那里百姓没有水喝。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 19:1–2; 出埃及记 16:1"> 从利非订起行，安营在西奈的旷野。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 11:34; 民数记 10:11–13; 民数记 10:33"> 从西奈的旷野起行，安营在基博罗哈他瓦。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 11:35"> 从基博罗哈他瓦起行，安营在哈洗录。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 12:16"> 从哈洗录起行，安营在利提玛。</span>
<span className="v" id="v19" data-v="19"> 从利提玛起行，安营在临门帕烈。</span>
<span className="v" id="v20" data-v="20"> 从临门帕烈起行，安营在立拿。</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 1:1"> 从立拿起行，安营在勒撒。</span>
<span className="v" id="v22" data-v="22"> 从勒撒起行，安营在基希拉他。</span>
<span className="v" id="v23" data-v="23"> 从基希拉他起行，安营在沙斐山。</span>
<span className="v" id="v24" data-v="24"> 从沙斐山起行，安营在哈拉大。</span>
<span className="v" id="v25" data-v="25"> 从哈拉大起行，安营在玛吉希录。</span>
<span className="v" id="v26" data-v="26"> 从玛吉希录起行，安营在他哈。</span>
<span className="v" id="v27" data-v="27"> 从他哈起行，安营在他拉。</span>
<span className="v" id="v28" data-v="28"> 从他拉起行，安营在密加。</span>
<span className="v" id="v29" data-v="29"> 从密加起行，安营在哈摩拿。</span>
<span className="v" id="v30" data-v="30" data-xref="申命记 10:5–6"> 从哈摩拿起行，安营在摩西录。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 10:6; 创世记 36:27; 历代志上 1:43"> 从摩西录起行，安营在比尼亚干。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 10:7"> 从比尼亚干起行，安营在曷哈及甲。</span>
<span className="v" id="v33" data-v="33" data-xref="申命记 10:7"> 从曷哈及甲起行，安营在约巴他。</span>
<span className="v" id="v34" data-v="34"> 从约巴他起行，安营在阿博拿。</span>
<span className="v" id="v35" data-v="35" data-xref="申命记 2:8; 列王纪上 9:26; 列王纪上 22:48"> 从阿博拿起行，安营在以旬迦别。</span>
<span className="v" id="v36" data-v="36" data-xref="民数记 20:1; 民数记 27:14; 申命记 32:51"> 从以旬迦别起行，安营在寻的旷野，就是加低斯。</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 21:4; 民数记 20:22–23; 民数记 20:16"> 从加低斯起行，安营在何珥山，以东地的边界。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="申命记 10:6; 申命记 32:50; 民数记 20:24–28"> 以色列人出了埃及地后四十年，五月初一日，祭司亚伦遵着耶和华的吩咐上何珥山，就死在那里。</span>
<span className="v" id="v39" data-v="39"> 亚伦死在何珥山的时候年一百二十三岁。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="民数记 21:1–9"> 住在迦南南地的迦南人亚拉得王听说以色列人来了。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数记 21:4"> 以色列人从何珥山起行，安营在撒摩拿。</span>
<span className="v" id="v42" data-v="42"> 从撒摩拿起行，安营在普嫩。</span>
<span className="v" id="v43" data-v="43" data-xref="民数记 21:10"> 从普嫩起行，安营在阿伯。</span>
<span className="v" id="v44" data-v="44" data-xref="民数记 21:11"> 从阿伯起行，安营在以耶亚巴琳，摩押的边界。</span>
<span className="v" id="v45" data-v="45"> 从以耶亚巴琳起行，安营在底本迦得。</span>
<span className="v" id="v46" data-v="46" data-xref="耶利米书 48:18; 以西结书 6:14; 以赛亚书 15:2"> 从底本迦得起行，安营在亚门低比拉太音。</span>
<span className="v" id="v47" data-v="47" data-xref="申命记 32:49; 申命记 34:1; 民数记 27:12"> 从亚门低比拉太音起行，安营在尼波对面的亚巴琳山里。</span>
<span className="v" id="v48" data-v="48" data-xref="民数记 22:1"> 从亚巴琳山起行，安营在摩押平原约旦河边，耶利哥对面。</span>
<span className="v" id="v49" data-v="49" data-xref="约书亚记 2:1; 约书亚记 13:20; 民数记 25:1–9"> 他们在摩押平原沿约旦河边安营，从伯耶施末直到亚伯什亭。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="民数记 33:48–49"> 耶和华在摩押平原约旦河边，耶利哥对面，晓谕摩西说：</span>
<span className="v" id="v51" data-v="51" data-xref="约书亚记 3:17; 申命记 9:1; 申命记 7:1"> “你吩咐以色列人说：你们过约旦河进迦南地的时候，</span>
<span className="v" id="v52" data-v="52" data-xref="出埃及记 23:24; 利未记 26:1; 申命记 20:16–18"> 就要从你们面前赶出那里所有的居民，毁灭他们一切錾成的石像和他们一切铸成的偶像，又拆毁他们一切的丘坛。</span>
<span className="v" id="v53" data-v="53" data-xref="申命记 11:31; 诗篇 115:16; 申命记 32:8"> 你们要夺那地，住在其中，因我把那地赐给你们为业。</span>
<span className="v" id="v54" data-v="54" data-xref="民数记 26:53–56; 约书亚记 18:11–48; 约书亚记 15:1–12"> 你们要按家室拈阄，承受那地。人多的，要把产业多分给他们；人少的，要把产业少分给他们。拈出何地给何人，就要归何人。你们要按宗族的支派承受。</span>
<span className="v" id="v55" data-v="55" data-xref="士师记 2:3; 诗篇 106:34–36; 申命记 7:16"> 倘若你们不赶出那地的居民，所容留的居民就必做你们眼中的刺，肋下的荆棘，也必在你们所住的地上扰害你们。</span>
<span className="v" id="v56" data-v="56" data-xref="路加福音 21:23–24; 申命记 28:63; 利未记 20:23"> 而且我素常有意怎样待他们，也必照样待你们。”</span>
</div>
</div>

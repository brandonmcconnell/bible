## 恒献燔祭之例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华晓谕摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 3:11; 创世记 8:21; 民数记 9:2–3"> “你要吩咐以色列人说：献给我的供物，就是献给我做馨香火祭的食物，你们要按日期献给我。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 6:9; 但以理书 11:31; 约翰福音 1:29"> 又要对他们说：你们要献给耶和华的火祭，就是没有残疾、一岁的公羊羔，每日两只，作为常献的燔祭。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理书 9:21; 列王纪上 18:36; 出埃及记 12:6"> 早晨要献一只，黄昏的时候要献一只。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 2:1; 出埃及记 16:36; 出埃及记 29:38–42"> 又用细面伊法十分之一，并捣成的油一欣四分之一，调和作为素祭。</span>
<span className="v" id="v6" data-v="6" data-xref="阿摩司书 5:25; 利未记 6:9; 诗篇 50:8"> 这是西奈山所命定为常献的燔祭，是献给耶和华为馨香的火祭。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 29:42; 民数记 28:14; 以赛亚书 57:6"> 为这一只羊羔，要同献奠祭的酒一欣四分之一。在圣所中，你要将醇酒奉给耶和华为奠祭。</span>
<span className="v" id="v8" data-v="8"> 晚上，你要献那一只羊羔，必照早晨的素祭和同献的奠祭献上，作为馨香的火祭献给耶和华。</span>
</div>
</div>

## 安息日当献之祭

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 58:13; 诗篇 92:1–4; 启示录 1:10"> “当安息日，要献两只没有残疾、一岁的公羊羔，并用调油的细面伊法十分之二为素祭，又将同献的奠祭献上。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 46:4–5; 民数记 29:22; 民数记 29:31"> 这是每安息日献的燔祭，那常献的燔祭和同献的奠祭在外。</span>
</div>
</div>

## 月朔当献之祭

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民数记 10:10; 以西结书 46:6; 以斯拉记 3:5"> “每月朔，你们要将两只公牛犊，一只公绵羊，七只没有残疾、一岁的公羊羔，献给耶和华为燔祭。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 15:4–12; 以西结书 46:5–7; 民数记 29:10"> 每只公牛要用调油的细面伊法十分之三作为素祭，那只公羊也用调油的细面伊法十分之二作为素祭，</span>
<span className="v" id="v13" data-v="13"> 每只羊羔要用调油的细面伊法十分之一作为素祭和馨香的燔祭，是献给耶和华的火祭。</span>
<span className="v" id="v14" data-v="14"> 一只公牛要奠酒半欣，一只公羊要奠酒一欣三分之一，一只羊羔也奠酒一欣四分之一。这是每月的燔祭，一年之中要月月如此。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 28:3; 民数记 28:22; 民数记 15:24"> 又要将一只公山羊为赎罪祭，献给耶和华，要献在常献的燔祭和同献的奠祭以外。</span>
</div>
</div>

## 逾越节当献之祭

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命记 16:1–8; 出埃及记 12:18; 利未记 23:5–8"> “正月十四日是耶和华的逾越节。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 23:6; 出埃及记 23:15; 出埃及记 13:6"> 这月十五日是节期，要吃无酵饼七日。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 12:16; 利未记 23:7–8"> 第一日当有圣会，什么劳碌的工都不可做。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 15:21; 以西结书 45:21–25; 民数记 29:8"> 当将公牛犊两只、公绵羊一只、一岁的公羊羔七只，都要没有残疾的，用火献给耶和华为燔祭。</span>
<span className="v" id="v20" data-v="20"> 同献的素祭用调油的细面：为一只公牛要献伊法十分之三，为一只公羊要献伊法十分之二，</span>
<span className="v" id="v21" data-v="21"> 为那七只羊羔每只要献伊法十分之一。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 8:3"> 并献一只公山羊做赎罪祭，为你们赎罪。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 28:3; 民数记 28:10"> 你们献这些，要在早晨常献的燔祭以外。</span>
<span className="v" id="v24" data-v="24"> 一连七日，每日要照这例把馨香火祭的食物献给耶和华，是在常献的燔祭和同献的奠祭以外。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 23:8; 民数记 28:18; 出埃及记 13:6"> 第七日当有圣会，什么劳碌的工都不可做。</span>
</div>
</div>

## 七七节当献之祭

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 23:16; 出埃及记 34:22; 利未记 23:10"> “七七节庄稼初熟，你们献新素祭给耶和华的日子，当有圣会，什么劳碌的工都不可做。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 23:18–19; 民数记 28:11; 民数记 28:19"> 只要将公牛犊两只、公绵羊一只、一岁的公羊羔七只，作为馨香的燔祭献给耶和华。</span>
<span className="v" id="v28" data-v="28"> 同献的素祭用调油的细面：为每只公牛要献伊法十分之三，为一只公羊要献伊法十分之二，</span>
<span className="v" id="v29" data-v="29"> 为那七只羊羔每只要献伊法十分之一。</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 28:15; 民数记 28:22; 彼得前书 2:24"> 并献一只公山羊为你们赎罪。</span>
<span className="v" id="v31" data-v="31" data-xref="民数记 28:19; 民数记 28:3; 玛拉基书 1:13–14"> 这些，你们要献在常献的燔祭和同献的素祭并同献的奠祭以外，都要没有残疾的。</span>
</div>
</div>

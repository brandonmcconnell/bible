## 命定迦南地之境界

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华晓谕摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 17:8; 诗篇 105:11; 申命记 1:7–8"> “你吩咐以色列人说：你们到了迦南地，就是归你们为业的迦南四境之地：</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 14:3; 以西结书 47:13; 约书亚记 3:16"> 南角要从寻的旷野，贴着以东的边界。南界要从盐海东头起，</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 32:8; 约书亚记 15:3–4; 民数记 13:26"> 绕到亚克拉滨坡的南边，接连到寻，直通到加低斯巴尼亚的南边，又通到哈萨亚达，接连到押们，</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 15:4; 创世记 15:18; 列王纪上 8:65"> 从押们转到埃及小河，直通到海为止。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约书亚记 1:4; 以西结书 47:20; 以西结书 47:15"> “西边要以大海为界。这就是你们的西界。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="民数记 33:37; 民数记 34:6; 民数记 34:3"> “北界要从大海起，划到何珥山，</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 13:21; 列王纪下 14:25; 约书亚记 13:5–6"> 从何珥山划到哈马口，通到西达达，</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 47:17"> 又通到西斐仑，直到哈萨以难。这要做你们的北界。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> “你们要从哈萨以难划到示番为东界。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 23:33; 申命记 3:17; 约书亚记 11:2"> 这界要从示番下到亚延东边的利比拉，又要达到基尼烈湖的东边。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 34:3; 创世记 13:10; 创世记 19:24–26"> 这界要下到约旦河，通到盐海为止。这四围的边界以内，要做你们的地。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 34:1; 约书亚记 14:1–5"> 摩西吩咐以色列人说：“这地就是耶和华吩咐拈阄给九个半支派承受为业的。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 32:33; 民数记 32:23; 约书亚记 14:2–3"> 因为鲁本支派和迦得支派按着宗族受了产业，玛拿西半个支派也受了产业。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 32:32"> 这两个半支派已经在耶利哥对面，约旦河东，向日出之地受了产业。”</span>
</div>
</div>

## 拣选分地之人

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16"> 耶和华晓谕摩西说：</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 14:1; 约书亚记 19:51; 民数记 13:8"> “要给你们分地为业之人的名字是祭司以利亚撒和嫩的儿子约书亚。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 1:4–16"> 又要从每支派中选一个首领帮助他们。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 26:65; 民数记 13:30; 民数记 14:24"> 这些人的名字：犹大支派有耶孚尼的儿子迦勒；</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 49:5"> 西缅支派有亚米忽的儿子示母利；</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 49:27; 诗篇 68:27"> 便雅悯支派有基斯伦的儿子以利达；</span>
<span className="v" id="v22" data-v="22"> 但支派有一个首领，约利的儿子布基；</span>
<span className="v" id="v23" data-v="23"> 约瑟的子孙玛拿西支派有一个首领，以弗的儿子汉聂；</span>
<span className="v" id="v24" data-v="24"> 以法莲支派有一个首领，拾弗但的儿子基母利；</span>
<span className="v" id="v25" data-v="25"> 西布伦支派有一个首领，帕纳的儿子以利撒番；</span>
<span className="v" id="v26" data-v="26"> 以萨迦支派有一个首领，阿散的儿子帕铁；</span>
<span className="v" id="v27" data-v="27"> 亚设支派有一个首领，示罗米的儿子亚希忽；</span>
<span className="v" id="v28" data-v="28"> 拿弗他利支派有一个首领，亚米忽的儿子比大黑。”</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 19:51; 民数记 34:18"> 这些人就是耶和华所吩咐，在迦南地把产业分给以色列人的。</span>
</div>
</div>

</div>

## 以色列人在什亭奉巴力毗珥

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 10:8; 民数记 33:49; 约书亚记 2:1"> 以色列人住在什亭，百姓与摩押女子行起淫乱。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 10:20; 出埃及记 20:5; 出埃及记 34:15–16"> 因为这女子叫百姓来，一同给她们的神献祭，百姓就吃她们的祭物，跪拜她们的神。</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 22:17; 诗篇 106:28–29; 何西阿书 9:10"> 以色列人与巴力毗珥联合，耶和华的怒气就向以色列人发作。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 13:17; 申命记 4:3; 申命记 21:23"> 耶和华吩咐摩西说：“将百姓中所有的族长在我面前对着日头悬挂，使我向以色列人所发的怒气可以消了。”</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 18:21; 列王纪上 18:40; 申命记 13:9"> 于是摩西吩咐以色列的审判官说：“凡属你们的人，有与巴力毗珥联合的，你们各人要把他们杀了。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约珥书 2:17; 民数记 22:4; 耶利米书 36:23"> 摩西和以色列全会众正在会幕门前哭泣的时候，谁知，有以色列中的一个人，当他们眼前，带着一个米甸女人到他弟兄那里去。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 6:25; 诗篇 106:30; 约书亚记 22:30–31"> 祭司亚伦的孙子、以利亚撒的儿子非尼哈看见了，就从会中起来，手里拿着枪，</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 16:46–48; 诗篇 106:29–31; 历代志上 21:22"> 跟随那以色列人进亭子里去，便将以色列人和那女人由腹中刺透。这样，在以色列人中瘟疫就止息了。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 10:8; 申命记 4:3–4; 民数记 25:4–5"> 那时遭瘟疫死的有二万四千人。</span>
</div>
</div>

## 非尼哈之热衷

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10"> 耶和华晓谕摩西说：</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 32:21; 诗篇 78:58; 申命记 32:16"> “祭司亚伦的孙子、以利亚撒的儿子非尼哈，使我向以色列人所发的怒消了，因他在他们中间，以我的忌邪为心，使我不在忌邪中把他们除灭。</span>
<span className="v" id="v12" data-v="12" data-xref="玛拉基书 2:4–5; 玛拉基书 3:1; 以赛亚书 54:10"> 因此，你要说：我将我平安的约赐给他，</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 2:17; 罗马书 10:2–4; 耶利米书 33:22"> 这约要给他和他的后裔，作为永远当祭司职任的约，因他为神，有忌邪的心，为以色列人赎罪。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 1:23; 民数记 26:14; 历代志下 19:7"> 那与米甸女人一同被杀的以色列人，名叫心利，是撒路的儿子，是西缅一个宗族的首领。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 31:8; 约书亚记 13:21; 民数记 25:18"> 那被杀的米甸女人，名叫哥斯比，是苏珥的女儿。这苏珥是米甸一个宗族的首领。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 耶和华晓谕摩西说：</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 31:1–3; 启示录 18:6"> “你要扰害米甸人，击杀他们。</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 2:14; 出埃及记 32:35; 哥林多后书 11:3"> 因为他们用诡计扰害你们，在毗珥的事上和他们的姐妹米甸首领的女儿哥斯比的事上，用这诡计诱惑了你们。”这哥斯比，当瘟疫流行的日子，因毗珥的事被杀了。</span>
</div>
</div>

## 劝其寻主得生

<div className="bt">
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="历代志下 15:2; 西番雅书 2:3; 耶利米书 29:12–13"> 耶和华向以色列家如此说：<br /><span className="pl pl-1">“你们要寻求我，就必存活。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="何西阿书 4:15; 阿摩司书 4:4; 阿摩司书 8:14"> <span className="pl pl-1">不要往伯特利寻求，</span><br /><span className="pl pl-1">不要进入吉甲，</span><br /><span className="pl pl-1">不要过到别是巴，</span><br /><span className="pl pl-1">因为吉甲必被掳掠，</span><br /><span className="pl pl-1">伯特利也必归于无有。”</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 33:11; 以赛亚书 55:6; 以西结书 20:47–48"> <span className="pl pl-1">要寻求耶和华，就必存活，</span><br /><span className="pl pl-1">免得他在约瑟家像火发出，</span><br /><span className="pl pl-1">在伯特利焚烧无人扑灭。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="阿摩司书 6:12; 阿摩司书 5:11–12; 西番雅书 1:6"> <span className="pl pl-1">你们这使公平变为茵陈，</span><br /><span className="pl pl-1">将公义丢弃于地的，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="阿摩司书 4:13; 约伯记 9:9; 阿摩司书 9:6"> <span className="pl pl-1">要寻求那造昴星和参星，</span><br /><span className="pl pl-1">使死荫变为晨光，</span><br /><span className="pl pl-1">使白日变为黑夜，</span><br /><span className="pl pl-1">命海水来浇在地上的，</span><br /><span className="pl pl-1">耶和华是他的名。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 13:17; 耶利米书 37:10; 弥迦书 5:11"> <span className="pl pl-1">他使力强的忽遭灭亡，</span><br /><span className="pl pl-1">以致保障遭遇毁坏。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 29:21; 列王纪上 22:8; 约翰福音 8:45–47"> <span className="pl pl-1">你们怨恨那在城门口责备人的，</span><br /><span className="pl pl-1">憎恶那说正直话的。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="申命记 28:30; 弥迦书 6:15; 西番雅书 1:13"> <span className="pl pl-1">你们践踏贫民，</span><br /><span className="pl pl-1">向他们勒索麦子。</span><br /><span className="pl pl-1">你们用凿过的石头建造房屋，</span><br /><span className="pl pl-1">却不得住在其内；</span><br /><span className="pl pl-1">栽种美好的葡萄园，</span><br /><span className="pl pl-1">却不得喝所出的酒。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="阿摩司书 2:6–7; 阿摩司书 5:10; 以赛亚书 1:23"> <span className="pl pl-1">我知道你们的罪过何等多，</span><br /><span className="pl pl-1">你们的罪恶何等大，</span><br /><span className="pl pl-1">你们苦待义人，收受贿赂，在城门口屈枉穷乏人。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="何西阿书 4:4; 提摩太后书 3:1; 传道书 3:7"> <span className="pl pl-1">所以通达人见这样的时势，必静默不言，</span><br /><span className="pl pl-1">因为时势真恶。</span></span>

<div className="bp poetry">

<span className="v" id="v15" data-v="15" data-xref="罗马书 12:9; 约翰三书 1:11; 诗篇 97:10"> <span className="pl pl-1">要恶恶好善，</span><br /><span className="pl pl-1">在城门口秉公行义，</span><br /><span className="pl pl-1">或者耶和华万军之神向约瑟的余民施恩。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="约珥书 1:11; 耶利米书 9:17–20; 耶利米书 9:10"> 主耶和华万军之神如此说：<br /><span className="pl pl-1">“在一切宽阔处必有哀号的声音，</span><br /><span className="pl pl-1">在各街市上必有人说：</span><br /><span className="pl pl-1">‘哀哉！哀哉！’</span><br /><span className="pl pl-1">又必叫农夫来哭号，</span><br /><span className="pl pl-1">叫善唱哀歌的来举哀。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="约珥书 1:15; 约珥书 2:1–2; 约珥书 2:31"> <span className="pl pl-1">想望耶和华日子来到的有祸了！</span><br /><span className="pl pl-1">你们为何想望耶和华的日子呢？</span><br /><span className="pl pl-1">那日黑暗没有光明，</span><br /></span>

<span className="v" id="v22" data-v="22" data-xref="弥迦书 6:6–7; 阿摩司书 4:4–5; 以赛亚书 66:3"> <span className="pl pl-1">你们虽然向我献燔祭和素祭，</span><br /><span className="pl pl-1">我却不悦纳，</span><br /><span className="pl pl-1">也不顾你们用肥畜献的平安祭。</span><br /></span>

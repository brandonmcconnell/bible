## 再兴圣殿之工

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒迦利亚书 4:6–10; 哈该书 1:1; 撒迦利亚书 1:1–21"> 那时，先知哈该和易多的孙子撒迦利亚奉以色列神的名，向犹大和耶路撒冷的犹大人说劝勉的话。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯拉记 3:2; 以斯拉记 6:14; 撒迦利亚书 3:1–4"> 于是，撒拉铁的儿子所罗巴伯和约萨达的儿子耶书亚都起来，动手建造耶路撒冷神的殿，有神的先知在那里帮助他们。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 6:6; 以斯拉记 6:13; 以斯拉记 5:9"> 当时河西的总督达乃和示他波斯乃并他们的同党来问说：“谁降旨让你们建造这殿，修成这墙呢？”</span>
<span className="v" id="v4" data-v="4"> 我们便告诉他们建造这殿的人叫什么名字。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 33:18; 以斯拉记 7:6; 以斯拉记 7:28"> 神的眼目看顾犹大的长老，以致总督等没有叫他们停工，直到这事奏告大流士得着他的回谕。</span>
</div>
</div>

## 达乃党上本大流士王

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以斯拉记 4:9; 以斯拉记 4:11; 以斯拉记 6:6"> 河西的总督达乃和示他波斯乃，并他们的同党，就是住河西的亚法萨迦人，上本奏告大流士王。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 4:17; 但以理书 6:21; 帖撒罗尼迦后书 3:16"> 本上写着说：“愿大流士王诸事平安！</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米记 7:6; 马可福音 13:1–2; 但以理书 3:26"> 王该知道，我们往犹大省去，到了至大神的殿，这殿是用大石建造的，梁木插入墙内，工作甚速，他们手下亨通。</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉记 5:3–4"> 我们就问那些长老说：‘谁降旨让你们建造这殿，修成这墙呢？’</span>
<span className="v" id="v10" data-v="10"> 又问他们的名字，要记录他们首领的名字，奏告于王。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 6:16; 约拿书 1:9; 使徒行传 27:23"> 他们回答说：‘我们是天地之神的仆人，重建前多年所建造的殿，就是以色列的一位大君王建造修成的。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 36:16–17; 但以理书 9:5; 列王纪下 24:2"> 只因我们列祖惹天上的神发怒，神把他们交在迦勒底人巴比伦王尼布甲尼撒的手中，他就拆毁这殿，又将百姓掳到巴比伦。</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 6:3–5; 以赛亚书 44:28–1; 以斯拉记 1:1–8"> 然而巴比伦王居鲁士元年，他降旨允准建造神的这殿。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯拉记 6:5; 但以理书 5:2–3; 以斯拉记 5:16"> 神殿中的金银器皿，就是尼布甲尼撒从耶路撒冷的殿中掠去带到巴比伦庙里的，居鲁士王从巴比伦庙里取出来，交给派为省长的，名叫设巴萨，</span>
<span className="v" id="v15" data-v="15" data-xref="以斯拉记 6:3; 以斯拉记 1:2; 以斯拉记 3:3"> 对他说：“可以将这些器皿带去，放在耶路撒冷的殿中，在原处建造神的殿。”</span>
<span className="v" id="v16" data-v="16" data-xref="以斯拉记 3:10; 以斯拉记 6:15; 以斯拉记 3:8"> 于是，这设巴萨来建立耶路撒冷神殿的根基。这殿从那时直到如今，尚未造成。’</span>
</div>
</div>

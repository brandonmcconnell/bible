## 民因娶异族女觉罪痛哭

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理书 9:20; 诗篇 119:136; 罗马书 9:2"> 以斯拉祷告、认罪、哭泣，俯伏在神殿前的时候，有以色列中的男女、孩童聚集到以斯拉那里，成了大会，众民无不痛哭。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米记 13:27; 以斯拉记 9:2; 耶利米书 3:12–13"> 属以拦的子孙，耶歇的儿子示迦尼对以斯拉说：“我们在此地娶了外邦女子为妻，干犯了我们的神，然而以色列人还有指望。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 7:2–3; 以斯拉记 9:4; 约书亚记 23:12–13"> 现在当与我们的神立约，休这一切的妻，离绝她们所生的，照着我主和那因神命令战兢之人所议定的，按律法而行。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 28:10; 传道书 9:10; 希伯来书 12:12–13"> 你起来，这是你当办的事，我们必帮助你，你当奋勉而行。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="尼希米记 13:25; 尼希米记 5:12; 箴言 9:9"> 以斯拉便起来，使祭司长和利未人并以色列众人起誓说，必照这话去行。他们就起了誓。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 9:18; 尼希米记 3:1; 尼希米记 12:22"> 以斯拉从神殿前起来，进入以利亚实的儿子约哈难的屋里，到了那里不吃饭，也不喝水，因为被掳归回之人所犯的罪心里悲伤。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 1:1; 历代志下 30:5"> 他们通告犹大和耶路撒冷被掳归回的人，叫他们在耶路撒冷聚集。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 7:26; 约翰福音 9:22; 士师记 21:5"> 凡不遵首领和长老所议定三日之内不来的，就必抄他的家，使他离开被掳归回之人的会。</span>
</div>
</div>

## 以斯拉劝民认罪出其异族之妻

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 12:17–18; 耶利米书 10:13; 以斯拉记 7:8–9"> 于是，犹大和便雅悯众人三日之内都聚集在耶路撒冷。那日正是九月二十日，众人都坐在神殿前的宽阔处；因这事，又因下大雨，就都战兢。</span>
<span className="v" id="v10" data-v="10" data-xref="以斯拉记 9:6; 民数记 32:14; 马太福音 23:32"> 祭司以斯拉站起来，对他们说：“你们有罪了，因你们娶了外邦的女子为妻，增添以色列人的罪恶。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 12:2; 以斯拉记 10:3; 以赛亚书 1:16–18"> 现在当向耶和华你们列祖的神认罪，遵行他的旨意，离绝这些国的民和外邦的女子。”</span>
</div>
</div>

## 会众愿遵劝言而行

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="尼希米记 13:23; 诗篇 78:57; 以斯拉记 10:3–4"> 会众都大声回答说：“我们必照着你的话行。</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 10:18–44; 马太福音 7:13–14"> 只是百姓众多，又逢大雨的时令，我们不能站在外头；这也不是一两天办完的事，因我们在这事上犯了大罪。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 29:10; 历代志下 30:8; 民数记 25:4"> 不如为全会众派首领办理，凡我们城邑中娶外邦女子为妻的，当按所定的日期，同着本城的长老和士师而来，直到办完这事，神的烈怒就转离我们了。”</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米记 11:16; 尼希米记 10:20; 尼希米记 12:33"> 唯有亚撒黑的儿子约拿单、特瓦的儿子雅哈谢阻挡<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：总办。">a</a></sup>这事，并有米书兰和利未人沙比太帮助他们。</span>
</div>
</div>

## 记娶异族女为妻之人

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约伯记 29:16; 申命记 13:14; 约翰福音 7:51"> 被掳归回的人如此而行。祭司以斯拉和些族长按着宗族，都指名见派，在十月初一日，一同在座查办这事。</span>
<span className="v" id="v17" data-v="17"> 到正月初一日，才查清娶外邦女子的人数。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以斯拉记 5:2; 以斯拉记 3:2; 撒迦利亚书 3:1"> 在祭司中查出娶外邦女子为妻的，就是耶书亚的子孙约萨达的儿子和他弟兄玛西雅、以利以谢、雅立、基大利，</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 6:6; 列王纪下 10:15; 历代志下 30:8"> 他们便应许必休他们的妻。他们因有罪，就献群中的一只公绵羊赎罪。</span>
<span className="v" id="v20" data-v="20" data-xref="以斯拉记 2:37; 历代志上 24:14; 尼希米记 7:40"> 音麦的子孙中有哈拿尼、西巴第雅；</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 24:8; 以斯拉记 2:39; 尼希米记 7:42"> 哈琳的子孙中有玛西雅、以利雅、示玛雅、耶歇、乌西雅；</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 9:12; 尼希米记 7:41; 以斯拉记 2:38"> 巴施户珥的子孙中有以利约乃、玛西雅、以实玛利、拿坦业、约撒拔、以利亚撒。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="尼希米记 10:10; 尼希米记 11:16; 以斯拉记 8:33"> 利未人中，有约撒拔、示每、基拉雅（基拉雅就是基利他），还有毗他希雅、犹大、以利以谢。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 歌唱的人中，有以利亚实。守门的人中，有沙龙、提联、乌利。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以斯拉记 2:3; 尼希米记 7:8"> 以色列人，巴录的子孙中有拉米、耶西雅、玛基雅、米雅民、以利亚撒、玛基雅、比拿雅；</span>
<span className="v" id="v26" data-v="26" data-xref="以斯拉记 10:2; 以斯拉记 2:31; 尼希米记 7:12"> 以拦的子孙中有玛他尼、撒迦利亚、耶歇、押底、耶利末、以利雅；</span>
<span className="v" id="v27" data-v="27" data-xref="尼希米记 7:13; 以斯拉记 2:8"> 萨土的子孙中有以利约乃、以利亚实、玛他尼、耶利末、撒拔、亚西撒；</span>
<span className="v" id="v28" data-v="28" data-xref="以斯拉记 8:11; 以斯拉记 2:11; 尼希米记 7:16"> 比拜的子孙中有约哈难、哈拿尼雅、萨拜、亚勒；</span>
<span className="v" id="v29" data-v="29" data-xref="尼希米记 7:15; 尼希米记 10:4; 以斯拉记 2:10"> 巴尼的子孙中有米书兰、玛鹿、亚大雅、雅述、示押、耶利末；</span>
<span className="v" id="v30" data-v="30" data-xref="以斯拉记 8:4; 尼希米记 7:11; 以斯拉记 2:6"> 巴哈摩押的子孙中有阿底拿、基拉、比拿雅、玛西雅、玛他尼、比撒列、宾内、玛拿西；</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米记 3:11; 尼希米记 7:35; 以斯拉记 2:32"> 哈琳的子孙中有以利以谢、伊示雅、玛基雅、示玛雅、西缅、</span>
<span className="v" id="v32" data-v="32"> 便雅悯、玛鹿、示玛利雅；</span>
<span className="v" id="v33" data-v="33" data-xref="以斯拉记 2:19; 尼希米记 7:22"> 哈顺的子孙中有玛特乃、玛达他、撒拔、以利法列、耶利买、玛拿西、示每；</span>
<span className="v" id="v34" data-v="34"> 巴尼的子孙中有玛玳、暗兰、乌益、</span>
<span className="v" id="v35" data-v="35"> 比拿雅、比底雅、基禄、</span>
<span className="v" id="v36" data-v="36"> 瓦尼雅、米利末、以利亚实、</span>
<span className="v" id="v37" data-v="37"> 玛他尼、玛特乃、雅扫、</span>
<span className="v" id="v38" data-v="38"> 巴尼、宾内、示每、</span>
<span className="v" id="v39" data-v="39"> 示利米雅、拿单、亚大雅、</span>
<span className="v" id="v40" data-v="40"> 玛拿底拜、沙赛、沙赖、</span>
<span className="v" id="v41" data-v="41"> 亚萨利、示利米雅、示玛利雅、</span>
<span className="v" id="v42" data-v="42"> 沙龙、亚玛利雅、约瑟；</span>
<span className="v" id="v43" data-v="43" data-xref="以斯拉记 2:29; 尼希米记 7:33"> 尼波的子孙中有耶利、玛他提雅、撒拔、西比拿、雅玳、约珥、比拿雅。</span>
<span className="v" id="v44" data-v="44" data-xref="箴言 5:20; 以斯拉记 10:3; 箴言 2:16"> 这些人都娶了外邦女子为妻，其中也有生了儿女的。</span>

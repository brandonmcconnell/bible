## 劝门徒警醒谨守

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 1:7; 帖撒罗尼迦前书 4:9; 马太福音 24:36"> 弟兄们，论到时候、日期，不用写信给你们，</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 16:15; 彼得后书 3:10; 马太福音 24:42–44"> 因为你们自己明明晓得，主的日子来到好像夜间的贼一样。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 21:34–35; 马太福音 24:37–39; 路加福音 17:26–30"> 人正说平安稳妥的时候，灾祸忽然临到他们，如同产难临到怀胎的妇人一样，他们绝不能逃脱。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰一书 2:8; 彼得后书 3:10; 申命记 19:6"> 弟兄们，你们却不在黑暗里，叫那日子临到你们像贼一样。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 5:8; 使徒行传 26:18; 约翰福音 12:36"> 你们都是光明之子，都是白昼之子。我们不是属黑夜的，也不是属幽暗的。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前书 1:13; 马太福音 24:42; 路加福音 22:46"> 所以，我们不要睡觉，像别人一样，总要警醒谨守。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 13:13; 哥林多前书 15:34; 彼得后书 2:13"> 因为睡了的人是在夜间睡，醉了的人是在夜间醉。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 13:12–13; 以弗所书 6:11; 彼得前书 1:13"> 但我们既然属乎白昼，就应当谨守，把信和爱当做护心镜遮胸，把得救的盼望当做头盔戴上。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦前书 1:10; 彼得前书 2:10; 提摩太后书 2:10"> 因为神不是预定我们受刑，乃是预定我们藉着我们主耶稣基督得救。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 14:8–9; 彼得前书 3:18; 罗马书 8:34"> 他替我们死，叫我们无论醒着、睡着，都与他同活。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 4:29; 希伯来书 10:25; 罗马书 15:2"> 所以，你们该彼此劝慰，互相建立，正如你们素常所行的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="希伯来书 13:17; 希伯来书 13:7; 提摩太前书 5:17–18"> 弟兄们，我们劝你们敬重那在你们中间劳苦的人，就是在主里面治理你们、劝诫你们的。</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 9:50; 希伯来书 12:14; 加拉太书 6:6"> 又因他们所做的工，用爱心格外尊重他们。你们也要彼此和睦。</span>
<span className="v" id="v14" data-v="14" data-xref="提摩太后书 4:2; 罗马书 14:1; 使徒行传 20:35"> 我们又劝弟兄们，要警戒不守规矩的人，勉励灰心的人，扶助软弱的人，也要向众人忍耐。</span>
</div>
</div>

## 毋以恶报恶

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="彼得前书 3:9; 加拉太书 6:10; 利未记 19:18"> 你们要谨慎，无论是谁都不可以恶报恶。或是彼此相待，或是待众人，常要追求良善。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 12:12; 腓立比书 4:4; 马太福音 5:12"> 要常常喜乐，</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 12:12; 歌罗西书 4:2; 以弗所书 6:18"> 不住地祷告，</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 5:20; 腓立比书 4:6; 歌罗西书 3:17"> 凡事谢恩，因为这是神在基督耶稣里向你们所定的旨意。</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所书 4:30; 使徒行传 7:51; 提摩太后书 1:6"> 不要消灭圣灵的感动，</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 14:3–6; 哥林多前书 14:1; 民数记 11:25–29"> 不要藐视先知的讲论。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 4:1; 罗马书 12:2; 以弗所书 5:10"> 但要凡事察验，善美的要持守，</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多后书 6:3; 腓立比书 4:8; 哥林多前书 10:31–33"> 各样的恶事要禁戒不做。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="犹大书 1:24; 希伯来书 4:12; 哥林多前书 1:8–9"> 愿赐平安的神亲自使你们全然成圣！又愿你们的灵与魂与身子得蒙保守，在我们主耶稣基督降临的时候完全无可指摘！</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦后书 3:3; 民数记 23:19; 哥林多前书 1:9"> 那召你们的本是信实的，他必成就这事。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="希伯来书 13:18–19; 腓立比书 1:19; 腓利门书 1:22"> 请弟兄们为我们祷告。</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 16:16; 哥林多前书 16:20"> 与众弟兄亲嘴问安务要圣洁。</span>
<span className="v" id="v27" data-v="27" data-xref="歌罗西书 4:16; 使徒行传 19:13; 提摩太前书 1:3"> 我指着主嘱咐你们，要把这信念给众弟兄听。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="罗马书 16:20; 帖撒罗尼迦后书 3:18; 罗马书 16:23"> 愿我主耶稣基督的恩常与你们同在！</span>
</div>
</div>

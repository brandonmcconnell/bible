## 示以后建之殿较前建者荣美尤大

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哈该书 1:1; 哈该书 2:20; 哈该书 2:10"> 七月二十一日，耶和华的话临到先知哈该说：</span>
<span className="v" id="v2" data-v="2" data-xref="哈该书 1:1; 尼希米记 8:9; 以斯拉记 2:63"> “你要晓谕犹大省长撒拉铁的儿子所罗巴伯和约萨答的儿子大祭司约书亚，并剩下的百姓，说：</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 3:12; 哈该书 2:9; 以西结书 7:20"> ‘你们中间存留的，有谁见过这殿从前的荣耀呢？现在你们看着如何？岂不在眼中看如无有吗？</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 28:20; 约书亚记 1:9; 撒迦利亚书 8:9"> 耶和华说：所罗巴伯啊，虽然如此，你当刚强！约萨答的儿子大祭司约书亚啊，你也当刚强！这地的百姓，你们都当刚强做工！因为我与你们同在。这是万军之耶和华说的。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 34:10; 出埃及记 29:45–46; 以赛亚书 41:13"> 这是照着你们出埃及我与你们立约的话，那时我的灵住在你们中间。你们不要惧怕！</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 12:26–28; 以赛亚书 10:25; 马可福音 13:24–26"> 万军之耶和华如此说：过不多时，我必再一次震动天地、沧海与旱地。</span>
<span className="v" id="v7" data-v="7" data-xref="玛拉基书 3:1; 列王纪上 8:11; 约翰福音 7:37–39"> 我必震动万国，万国的珍宝必都运来<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：万国所羡慕的必来到。">a</a></sup>，我就使这殿满了荣耀。这是万军之耶和华说的。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 50:10–12; 诗篇 24:1; 以赛亚书 60:17"> 万军之耶和华说：银子是我的，金子也是我的。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 85:8–9; 哥林多后书 3:9–10; 歌罗西书 1:19–21"> 这殿后来的荣耀必大过先前的荣耀，在这地方我必赐平安。这是万军之耶和华说的。’”</span>
</div>
</div>

## 未建殿以前民所献者不洁故诸事不利

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="哈该书 2:20; 哈该书 1:1; 哈该书 1:15–1"> 大流士王第二年九月二十四日，耶和华的话临到先知哈该说：</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 10:10–11; 玛拉基书 2:7; 申命记 33:10"> “万军之耶和华如此说：你要向祭司问律法，</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 6:27; 马太福音 23:19; 利未记 7:6"> 若有人用衣襟兜圣肉，这衣襟挨着饼或汤，或酒，或油，或别的食物，便算为圣吗？”祭司说：“不算为圣。”</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 5:2–3; 民数记 19:11–22; 利未记 22:4–6"> 哈该又说：“若有人因摸死尸染了污秽，然后挨着这些物的哪一样，这物算污秽吗？”祭司说：“必算污秽。”</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 28:9; 提多书 1:15; 以赛亚书 1:11–15"> 于是哈该说：“耶和华说：这民这国在我面前也是如此，他们手下的各样工作都是如此，他们在坛上所献的也是如此。</span>
<span className="v" id="v15" data-v="15" data-xref="哈该书 1:5; 以斯拉记 3:10; 以斯拉记 4:24"> 现在你们要追想，此日以前，耶和华的殿没有一块石头垒在石头上的光景。</span>
<span className="v" id="v16" data-v="16" data-xref="哈该书 1:6; 玛拉基书 2:2; 箴言 3:9–10"> 在那一切日子，有人来到谷堆，想得二十斗只得了十斗；有人来到酒池，想得五十桶只得了二十桶。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 28:22; 哈该书 1:11; 哈该书 1:9"> 在你们手下的各样工作上，我以旱风、霉烂、冰雹攻击你们，你们仍不归向我。这是耶和华说的。</span>
<span className="v" id="v18" data-v="18" data-xref="撒迦利亚书 8:9; 哈该书 2:15; 以斯拉记 5:1–2"> 你们要追想此日以前，就是从这九月二十四日起，追想到立耶和华殿根基的日子。</span>
<span className="v" id="v19" data-v="19" data-xref="玛拉基书 3:10; 哈巴谷书 3:17–18; 箴言 3:9–10"> 仓里有谷种吗？葡萄树、无花果树、石榴树、橄榄树都没有结果子。从今日起，我必赐福于你们。”</span>
</div>
</div>

## 主许简所罗巴伯

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20"> 这月二十四日，耶和华的话二次临到哈该说：</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亚书 4:6–10; 哈该书 2:6–7; 哈该书 1:1"> “你要告诉犹大省长所罗巴伯说，我必震动天地。</span>
<span className="v" id="v22" data-v="22" data-xref="弥迦书 5:10; 士师记 7:22; 西番雅书 3:8"> 我必倾覆列国的宝座，除灭列邦的势力，并倾覆战车和坐在其上的。马必跌倒，骑马的败落，各人被弟兄的刀所杀。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 43:10; 以赛亚书 42:1; 雅歌 8:6"> 万军之耶和华说：我仆人撒拉铁的儿子所罗巴伯啊，到那日，我必以你为印，因我拣选了你。这是万军之耶和华说的。”</span>
</div>

## 当在各等德行上求进步

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="彼得前书 5:10; 提摩太后书 1:9; 罗马书 8:28–30"> 神的神能已将一切关乎生命和虔敬的事赐给我们，皆因我们认识那用自己荣耀和美德召我们的主。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 4:23–24; 以西结书 36:25–27; 哥林多后书 3:18"> 因此，他已将又宝贵又极大的应许赐给我们，叫我们既脱离世上从情欲来的败坏，就得与神的性情有份。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 4:8; 箴言 4:23; 彼得后书 3:18"> 正因这缘故，你们要分外地殷勤：有了信心，又要加上德行；有了德行，又要加上知识；</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 10:36; 罗马书 5:3–4; 路加福音 21:19"> 有了知识，又要加上节制；有了节制，又要加上忍耐；有了忍耐，又要加上虔敬；</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 13:1; 罗马书 12:10; 帖撒罗尼迦前书 3:12"> 有了虔敬，又要加上爱弟兄的心；有了爱弟兄的心，又要加上爱众人的心。</span>
<span className="v" id="v8" data-v="8" data-xref="提多书 3:14; 约翰福音 15:2; 希伯来书 6:12"> 你们若充充足足地有这几样，就必使你们在认识我们的主耶稣基督上，不至于闲懒不结果子了。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得后书 2:18–20; 以弗所书 5:26; 提多书 2:14"> 人若没有这几样，就是眼瞎，只看见近处的，忘了他旧日的罪已经得了洁净。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得后书 3:17; 路加福音 6:47–49; 希伯来书 6:11"> 所以弟兄们，应当更加殷勤，使你们所蒙的恩召和拣选坚定不移。你们若行这几样，就永不失脚。</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 5:10; 马太福音 25:34; 启示录 3:21"> 这样，必叫你们丰丰富富地得以进入我们主救主耶稣基督永远的国。</span>
</div>
</div>

## 使徒亲眼见过主的威荣

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约翰一书 2:21; 罗马书 15:14–15; 腓立比书 3:1"> 你们虽然晓得这些事，并且在你们已有的真道上坚固，我却要将这些事常常提醒你们。</span>
<span className="v" id="v13" data-v="13" data-xref="彼得后书 3:1; 彼得后书 1:14; 希伯来书 13:3"> 我以为应当趁我还在这帐篷的时候提醒你们，激发你们，</span>
<span className="v" id="v14" data-v="14" data-xref="提摩太后书 4:6; 约翰福音 21:18–19; 申命记 31:14"> 因为知道我脱离这帐篷的时候快到了，正如我们主耶稣基督所指示我的；</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 31:19–29; 诗篇 71:18; 约书亚记 24:24–29"> 并且我要尽心竭力，使你们在我去世以后时常记念这些事。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰一书 4:14; 约翰福音 1:14; 提摩太前书 1:4"> 我们从前将我们主耶稣基督的大能和他降临的事告诉你们，并不是随从乖巧捏造的虚言，乃是亲眼见过他的威荣。</span>
<span className="v" id="v17" data-v="17" data-xref="马可福音 9:7; 马太福音 17:5; 马太福音 3:17"> 他从父神得尊贵、荣耀的时候，从极大荣光之中有声音出来，向他说：“这是我的爱子，我所喜悦的。”</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 17:6; 约书亚记 5:15; 出埃及记 3:5"> 我们同他在圣山的时候，亲自听见这声音从天上出来。</span>
</div>
</div>

## 预言如照在暗处的灯

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="启示录 22:16; 以赛亚书 9:2; 诗篇 119:105"> 我们并有先知更确的预言，如同灯照在暗处。你们在这预言上留意，直等到天发亮、晨星在你们心里出现的时候，才是好的。</span>
<span className="v" id="v20" data-v="20" data-xref="彼得后书 3:3; 罗马书 12:6; 罗马书 6:6"> 第一要紧的，该知道经上所有的预言没有可随私意解说的。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 3:15–17; 彼得前书 1:11; 撒母耳记下 23:2"> 因为预言从来没有出于人意的，乃是人被圣灵感动，说出神的话来。</span>
</div>

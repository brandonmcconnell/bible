## 利甲族克守其先祖遗训

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 23:35; 耶利米书 1:3; 耶利米书 25:1"> 当犹大王约西亚之子约雅敬的时候，耶和华的话临到耶利米说：</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 2:55; 历代志上 9:26; 列王纪上 6:5–6"> “你去见利甲族的人，和他们说话，领他们进入耶和华殿的一间屋子，给他们酒喝。”</span>
<span className="v" id="v3" data-v="3"> 我就将哈巴洗尼雅的孙子、雅利米雅的儿子雅撒尼亚和他弟兄，并他众子以及利甲全族的人，</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 33:1; 列王纪下 12:9; 历代志下 8:14"> 领到耶和华的殿，进入神人伊基大利的儿子哈难众子的屋子。那屋子在首领的屋子旁边，在沙龙之子把门的玛西雅屋子以上。</span>
<span className="v" id="v5" data-v="5" data-xref="传道书 9:7; 阿摩司书 2:12; 哥林多后书 2:9"> 于是我在利甲族人面前设摆盛满酒的碗和杯，对他们说：“请你们喝酒。”</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 1:15; 历代志上 2:55; 列王纪下 10:15"> 他们却说：“我们不喝酒，因为我们先祖利甲的儿子约拿达曾吩咐我们说：‘你们与你们的子孙永不可喝酒，</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 35:10; 创世记 25:27; 尼希米记 8:14–16"> 也不可盖房、撒种、栽种葡萄园，但一生的年日要住帐篷，使你们的日子在寄居之地得以延长。’</span>
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 3:20; 箴言 4:10; 箴言 1:8–9"> 凡我们先祖利甲的儿子约拿达所吩咐我们的话，我们都听从了。我们和我们的妻子、儿女一生的年日都不喝酒，</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前书 6:6; 耶利米书 35:7; 诗篇 37:16"> 也不盖房居住，也没有葡萄园、田地和种子，</span>
<span className="v" id="v10" data-v="10"> 但住帐篷，听从我们先祖约拿达的话，照他所吩咐我们的去行。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 8:14; 耶利米书 4:5–7; 但以理书 1:1–2"> 巴比伦王尼布甲尼撒上此地来，我们因怕迦勒底的军队和亚兰的军队，就说：‘来吧，我们到耶路撒冷去。’这样，我们才住在耶路撒冷。”</span>
</div>
</div>

## 主藉耶利米责民不守其命

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12"> 耶和华的话临到耶利米说：</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 32:33; 耶利米书 5:3; 耶利米书 6:8–10"> “万军之耶和华以色列的神如此说：你去对犹大人和耶路撒冷的居民说：‘耶和华说：你们不受教训，不听从我的话吗？</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 25:3–4; 耶利米书 7:24–26; 箴言 1:20–33"> 利甲的儿子约拿达所吩咐他子孙不可喝酒的话，他们已经遵守，直到今日也不喝酒，因为他们听从先祖的吩咐。我从早起来警戒你们，你们却不听从我。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 18:11; 以西结书 18:30–32; 耶利米书 25:5–6"> 我从早起来，差遣我的仆人众先知去，说：“你们各人当回头离开恶道，改正行为，不随从侍奉别神，就必住在我所赐给你们和你们列祖的地上。”只是你们没有听从我，也没有侧耳而听。</span>
<span className="v" id="v16" data-v="16" data-xref="玛拉基书 1:6; 耶利米书 35:14; 路加福音 15:11–13"> 利甲的儿子约拿达的子孙能遵守先人所吩咐他们的命，这百姓却没有听从我。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 66:4; 以赛亚书 65:12; 罗马书 10:21"> 因此耶和华万军之神，以色列的神如此说：我要使我所说的一切灾祸临到犹大人和耶路撒冷的一切居民。因为我对他们说话，他们没有听从；我呼唤他们，他们没有答应。’”</span>
</div>
</div>

## 利甲族因守命致福

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命记 5:16; 出埃及记 20:12; 以弗所书 6:1–3"> 耶利米对利甲族的人说：“万军之耶和华以色列的神如此说：因你们听从你们先祖约拿达的吩咐，谨守他的一切诫命，照他所吩咐你们的去行，</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 15:19; 路加福音 21:36; 耶利米书 33:17–18"> 所以万军之耶和华以色列的神如此说：利甲的儿子约拿达必永不缺人侍立在我面前。”</span>
</div>
</div>

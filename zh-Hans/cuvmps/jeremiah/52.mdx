## 西底家叛巴比伦王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 24:18; 约书亚记 10:29; 历代志下 36:11"> 西底家登基的时候年二十一岁，在耶路撒冷做王十一年。他母亲名叫哈慕她，是立拿人耶利米的女儿。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 14:22; 列王纪下 24:19–20; 以西结书 17:16–20"> 西底家行耶和华眼中看为恶的事，是照约雅敬一切所行的。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 3:4–5; 历代志下 36:13; 以赛亚书 3:1"> 因此耶和华的怒气在耶路撒冷和犹大发作，以致将人民从自己的面前赶出。</span>
</div>
</div>

## 耶路撒冷沦陷

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="耶利米书 39:1; 撒迦利亚书 8:19; 以西结书 24:1–2"> 西底家背叛巴比伦王。他做王第九年十月初十日，巴比伦王尼布甲尼撒率领全军来攻击耶路撒冷，对城安营，四围筑垒攻城。</span>
<span className="v" id="v5" data-v="5"> 于是城被围困，直到西底家王十一年。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 39:2; 以赛亚书 3:1; 列王纪下 25:3"> 四月初九日，城里有大饥荒，甚至百姓都没有粮食。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 39:4–7; 耶利米书 51:32; 列王纪下 25:4"> 城被攻破，一切兵丁就在夜间从靠近王园两城中间的门出城逃跑。迦勒底人正在四围攻城，他们就往亚拉巴逃去。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 34:21; 耶利米书 32:4; 耶利米书 38:23"> 迦勒底的军队追赶西底家王，在耶利哥的平原追上他；他的全军都离开他四散了。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 39:5; 民数记 13:21; 列王纪下 25:6"> 迦勒底人就拿住王，带他到哈马地的利比拉巴比伦王那里。巴比伦王便审判他。</span>
</div>
</div>

## 巴比伦王剜西底家之目戮其众子

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 22:30; 列王纪下 25:7; 创世记 21:16"> 巴比伦王在西底家眼前杀了他的众子，又在利比拉杀了犹大的一切首领。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 12:13; 耶利米书 34:3–5"> 并且剜了西底家的眼睛，用铜链锁着他，带到巴比伦去，将他囚在监里，直到他死的日子。</span>
</div>
</div>

## 焚毁城垣

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王纪下 25:8; 耶利米书 39:9; 耶利米书 52:29"> 巴比伦王尼布甲尼撒十九年五月初十日，在巴比伦王面前侍立的护卫长尼布撒拉旦进入耶路撒冷，</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 79:1; 弥迦书 3:12; 历代志下 36:19"> 用火焚烧耶和华的殿和王宫，又焚烧耶路撒冷的房屋，就是各大户家的房屋。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 1:3; 列王纪下 25:10"> 跟从护卫长迦勒底的全军就拆毁耶路撒冷四围的城墙。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 15:1–2; 撒迦利亚书 14:2"> 那时，护卫长尼布撒拉旦将民中最穷的和城里所剩下的百姓，并已经投降巴比伦王的人，以及大众所剩下的人，都掳去了。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 25:12; 耶利米书 39:9–10; 耶利米书 40:5–7"> 但护卫长尼布撒拉旦留下些民中最穷的，使他们修理葡萄园，耕种田地。</span>
</div>
</div>

## 圣殿被掠

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="耶利米书 27:19–22; 耶利米书 52:21–23; 历代志下 4:12–15"> 耶和华殿的铜柱并殿内的盆座和铜海，迦勒底人都打碎了，将那铜运到巴比伦去了。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 27:3; 民数记 4:14; 列王纪上 7:45"> 又带去锅、铲子、蜡剪、盘子、调羹，并所用的一切铜器。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 7:49–50; 历代志下 4:6–22; 利未记 26:12"> 杯、火鼎、碗、盆、灯台、调羹、爵，无论金的银的，护卫长也都带去了。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 7:47; 列王纪下 25:16; 历代志下 4:18"> 所罗门为耶和华殿所造的两根铜柱、一个铜海并座下的十二只铜牛，这一切的铜，多得无法可称。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 25:17; 列王纪上 7:15–21; 历代志下 3:15–17"> 这一根柱子高十八肘，厚四指，是空的，围十二肘。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 28:25; 列王纪下 25:17; 历代志下 3:15"> 柱上有铜顶，高五肘，铜顶的周围有网子和石榴，都是铜的。那一根柱子照此一样，也有石榴。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 7:20"> 柱子四面有九十六个石榴，在网子周围共有一百石榴。</span>
</div>
</div>

## 祭司与官吏遭戮

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王纪下 25:18; 耶利米书 29:25; 耶利米书 35:4"> 护卫长拿住大祭司西莱雅、副祭司西番亚和三个把门的，</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 25:19; 以斯帖记 1:14; 马太福音 18:10"> 又从城中拿住一个管理兵丁的官<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：太监。">a</a></sup>，并在城里所遇常见王面的七个人和检点国民军长的书记，以及城里所遇见的国民六十个人。</span>
<span className="v" id="v26" data-v="26"> 护卫长尼布撒拉旦将这些人带到利比拉巴比伦王那里。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 33:28; 以赛亚书 32:13–14; 以赛亚书 6:11–12"> 巴比伦王就把他们击杀在哈马地的利比拉。这样，犹大人被掳去离开本地。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王纪下 24:12–16; 列王纪下 24:2–3; 但以理书 1:1–3"> 尼布甲尼撒所掳的民数记在下面：在他第七年掳去犹大人三千零二十三名，</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 52:12; 创世记 12:5; 列王纪下 25:11"> 尼布甲尼撒十八年从耶路撒冷掳去八百三十二人，</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 52:15; 耶利米书 6:9"> 尼布甲尼撒二十三年护卫长尼布撒拉旦掳去犹大人七百四十五名，共有四千六百人。</span>
</div>
</div>

## 巴比伦王恩待约雅斤

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪下 25:27–30; 诗篇 3:3; 创世记 40:13"> 犹大王约雅斤被掳后三十七年，巴比伦王以未米罗达元年十二月二十五日，使犹大王约雅斤抬头，提他出监，</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 12:25; 但以理书 5:18–19; 但以理书 2:37"> 又对他说恩言，使他的位高过与他一同在巴比伦众王的位，</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 9:7; 列王纪上 2:7; 创世记 41:14"> 给他脱了囚服。他终身在巴比伦王面前吃饭。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记下 9:10; 路加福音 11:3; 马太福音 6:11"> 巴比伦王赐他所需用的食物，日日赐他一份，终身是这样，直到他死的日子。</span>
</div>
</div>

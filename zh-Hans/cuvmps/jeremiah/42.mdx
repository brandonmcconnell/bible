## 约哈难求耶利米咨诹神

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 41:11; 耶利米书 40:13; 耶利米书 6:13"> 众军长和加利亚的儿子约哈难，并何沙雅的儿子耶撒尼亚<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="耶撒尼亚又名亚撒利雅，见43章2节。">a</a></sup>，以及众百姓从最小的到至大的，都进前来，</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 36:7; 利未记 26:22; 使徒行传 8:24"> 对先知耶利米说：“求你准我们在你面前祈求，为我们这剩下的人祷告耶和华你的神。我们本来众多，现在剩下的极少，这是你亲眼所见的。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 86:11; 箴言 3:6; 诗篇 25:4–5"> 愿耶和华你的神指示我们所当走的路，所当做的事。”</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 12:23; 撒母耳记上 3:17–18; 出埃及记 8:29"> 先知耶利米对他们说：“我已经听见你们了，我必照着你们的话祷告耶和华你们的神。耶和华无论回答什么，我必都告诉你们，毫不隐瞒。”</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 31:50; 士师记 11:10; 玛拉基书 3:5"> 于是他们对耶利米说：“我们若不照耶和华你的神差遣你来说的一切话行，愿耶和华在我们中间做真实诚信的见证。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 7:23; 申命记 5:29; 罗马书 8:7"> 我们现在请你到耶和华我们的神面前，他说的无论是好是歹，我们都必听从。我们听从耶和华我们神的话，就可以得福。”</span>
</div>
</div>

## 示以仍居犹大得享安逸

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="诗篇 27:14; 以赛亚书 28:16; 哈巴谷书 2:3"> 过了十天，耶和华的话临到耶利米。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 42:1; 耶利米书 41:11–16; 耶利米书 43:2–5"> 他就将加利亚的儿子约哈难和同着他的众军长，并众百姓从最小的到至大的，都叫了来，</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 19:4; 耶利米书 42:2; 列王纪下 19:6"> 对他们说：“耶和华以色列的神，就是你们请我在他面前为你们祈求的主，如此说：</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 31:28; 以西结书 36:36; 耶利米书 24:6"> 你们若仍住在这地，我就建立你们必不拆毁，栽植你们并不拔出，因我为降于你们的灾祸后悔了。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 8:31; 耶利米书 1:19; 耶利米书 1:8"> 不要怕你们所怕的巴比伦王。耶和华说：不要怕他，因为我与你们同在，要拯救你们脱离他的手。</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米记 1:11; 诗篇 106:45–46; 箴言 16:7"> 我也要使他发怜悯，好怜悯你们，叫你们归回本地。</span>
</div>
</div>

## 如往埃及必遭诸灾

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="耶利米书 44:16; 出埃及记 5:2; 耶利米书 42:10"> “倘若你们说‘我们不住在这地’，以致不听从耶和华你们神的话，</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 41:17; 耶利米书 4:19; 以赛亚书 31:1"> 说：‘我们不住这地，却要进入埃及地，在那里看不见争战，听不见角声，也不致无食饥饿。我们必住在那里。’</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 17:16; 耶利米书 44:12–14; 耶利米书 42:17"> 你们所剩下的犹大人哪，现在要听耶和华的话！万军之耶和华以色列的神如此说：你们若定意要进入埃及，在那里寄居，</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 44:27; 以西结书 11:8; 阿摩司书 9:1–4"> 你们所惧怕的刀剑在埃及地必追上你们，你们所惧怕的饥荒在埃及要紧紧地跟随你们，你们必死在那里。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 42:22; 耶利米书 44:28; 耶利米书 44:13–14"> 凡定意要进入埃及在那里寄居的，必遭刀剑、饥荒、瘟疫而死，无一人存留，逃脱我所降于他们的灾祸。</span>
</div>
</div>

## 责其不听警教

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米书 7:20; 耶利米书 18:16; 耶利米书 29:18"> “万军之耶和华以色列的神如此说：我怎样将我的怒气和愤怒倾在耶路撒冷的居民身上，你们进入埃及的时候，我也必照样将我的愤怒倾在你们身上，以致你们令人辱骂、惊骇、咒诅、羞辱，你们不得再见这地方。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 17:16; 以赛亚书 30:1–7; 尼希米记 9:26"> 所剩下的犹大人哪，耶和华论到你们说：不要进入埃及去！你们要确实地知道，我今日警教你们了。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 14:3–4; 以西结书 33:31; 马太福音 22:15–18"> 你们用诡诈自害，因为你们请我到耶和华你们的神那里，说：‘求你为我们祷告耶和华我们神，照耶和华我们的神一切所说的告诉我们，我们就必遵行。’</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 2:7; 撒迦利亚书 7:11–12; 使徒行传 20:26–27"> 我今日将这话告诉你们，耶和华你们的神为你们的事差遣我到你们那里说的，你们却一样没有听从。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 42:17; 以西结书 6:11; 何西阿书 9:6"> 现在你们要确实地知道：你们在所要去寄居之地必遭刀剑、饥荒、瘟疫而死。”</span>
</div>
</div>

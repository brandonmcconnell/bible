## 西底家因耶利米预言而囚之

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 39:1–2; 列王纪下 25:1–2; 耶利米书 25:1"> 犹大王西底家第十年，就是尼布甲尼撒十八年，耶和华的话临到耶利米。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 37:21; 尼希米记 3:25; 耶利米书 33:1"> 那时巴比伦王的军队围困耶路撒冷，先知耶利米囚在护卫兵的院内，在犹大王的宫中。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 34:2–3; 耶利米书 21:4–7; 耶利米书 26:8–9"> 因为犹大王西底家已将他囚禁，说：“你为什么预言说‘耶和华如此说：我必将这城交在巴比伦王的手中，他必攻取这城。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 39:4–7; 列王纪下 25:4–7; 耶利米书 37:17"> 犹大王西底家必不能逃脱迦勒底人的手，定要交在巴比伦王的手中，要口对口彼此说话，眼对眼彼此相看。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 39:7; 以西结书 17:9–10; 以西结书 17:15"> 巴比伦王必将西底家带到巴比伦，西底家必住在那里，直到我眷顾他的时候。你们虽与迦勒底人争战，却不顺利。这是耶和华说的’？”</span>
</div>
</div>

## 耶利米购哈拿篾之田

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6"> 耶利米说：耶和华的话临到我说：</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 1:1; 耶利米书 11:21; 利未记 25:25"> “你叔叔沙龙的儿子哈拿篾必来见你，说：‘我在亚拿突的那块地，求你买来，因你买这地是合乎赎回之理。’”</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 32:7; 耶利米书 32:2; 耶利米书 33:1"> 我叔叔的儿子哈拿篾果然照耶和华的话来到护卫兵的院内，对我说：“我在便雅悯境内亚拿突的那块地，求你买来，因你买来是合乎承受之理，是你当赎的。你为自己买来吧。”我耶利米就知道这是耶和华的话。</span>
<span className="v" id="v9" data-v="9" data-xref="撒迦利亚书 11:12–13; 以斯帖记 3:9; 列王纪上 20:39"> 我便向我叔叔的儿子哈拿篾买了亚拿突的那块地，平了十七舍客勒银子给他。</span>
</div>
</div>

## 命付田契于巴录

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 32:44; 耶利米书 32:12; 耶利米书 32:25"> 我在契上画押，将契封缄，又请见证人来，并用天平将银子平给他。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 2:27; 哥林多前书 11:16; 使徒行传 26:3"> 我便将照例按规所立的买契，就是封缄的那一张和敞着的那一张，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 32:16; 耶利米书 51:59; 耶利米书 36:4–5"> 当着我叔叔的儿子哈拿篾和画押做见证的人，并坐在护卫兵院内的一切犹大人眼前，交给玛西雅的孙子、尼利亚的儿子巴录。</span>
<span className="v" id="v13" data-v="13"> 当着他们众人眼前，我嘱咐巴录说：</span>
<span className="v" id="v14" data-v="14"> “万军之耶和华以色列的神如此说：要将这封缄的和敞着的两张契放在瓦器里，可以存留多日。</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 3:10; 阿摩司书 9:14–15; 耶利米书 30:18"> 因为万军之耶和华以色列的神如此说：将来在这地必有人再买房屋、田地和葡萄园。”</span>
</div>
</div>

## 耶利米祈祷

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米书 12:1; 创世记 32:9–12; 腓立比书 4:6–7"> 我将买契交给尼利亚的儿子巴录以后，便祷告耶和华说：</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 1:37; 耶利米书 32:27; 创世记 18:14"> “主耶和华啊，你曾用大能和伸出来的膀臂创造天地，在你没有难成的事。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 10:16; 申命记 5:9–10; 出埃及记 34:7"> 你施慈爱于千万人，又将父亲的罪孽报应在他后世子孙的怀中，是至大全能的神，万军之耶和华是你的名。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 17:10; 马太福音 16:27; 诗篇 62:12"> 谋事有大略，行事有大能，注目观看世人一切的举动，为要照各人所行的和他做事的结果报应他。</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米记 9:10; 撒母耳记下 7:23; 出埃及记 10:2"> 在埃及地显神迹奇事，直到今日在以色列和别人中间也是如此，使自己得了名声，正如今日一样。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 6:6; 申命记 26:8; 诗篇 105:43"> 用神迹奇事和大能的手，并伸出来的膀臂与大可畏的事，领你的百姓以色列出了埃及，</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 3:8; 出埃及记 13:5; 耶利米书 11:5"> 将这地赐给他们，就是你向他们列祖起誓应许赐给他们流奶与蜜之地。</span>
<span className="v" id="v23" data-v="23" data-xref="以斯拉记 9:7; 诗篇 78:54–55; 但以理书 9:10–14"> 他们进入这地得了为业，却不听从你的话，也不遵行你的律法。你一切所吩咐他们行的，他们一无所行。因此，你使这一切的灾祸临到他们。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 32:36; 申命记 4:26; 约书亚记 23:15–16"> 看哪，敌人已经来到，筑垒要攻取这城，城也因刀剑、饥荒、瘟疫交在攻城的迦勒底人手中。你所说的话都成就了，你也看见了。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 32:24; 诗篇 97:2; 诗篇 77:19"> 主耶和华啊，你对我说‘要用银子为自己买那块地，又请见证人’，其实这城已交在迦勒底人的手中了。”</span>
</div>
</div>

## 耶和华以民掳城毁示耶利米

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和华的话临到耶利米说：</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 19:26; 耶利米书 32:17; 以赛亚书 64:8"> “我是耶和华，是凡有血气者的神，岂有我难成的事吗？</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 32:3; 耶利米书 32:24; 耶利米书 19:7–12"> 耶和华如此说：我必将这城交付迦勒底人的手和巴比伦王尼布甲尼撒的手，他必攻取这城。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 21:10; 耶利米书 19:13; 耶利米书 52:13"> 攻城的迦勒底人必来放火焚烧这城和其中的房屋，在这房屋上，人曾向巴力烧香，向别神浇奠，惹我发怒。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 7:22–26; 申命记 9:7–12; 耶利米书 25:7"> 以色列人和犹大人自从幼年以来，专行我眼中看为恶的事，以色列人尽以手所做的惹我发怒。这是耶和华说的。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 23:27; 耶利米书 27:10; 列王纪下 21:4–7"> 这城自从建造的那日直到今日，常惹我的怒气和愤怒，使我将这城从我面前除掉。</span>
<span className="v" id="v32" data-v="32" data-xref="但以理书 9:8; 耶利米书 2:26; 以赛亚书 1:4–6"> 是因以色列人和犹大人一切的邪恶，就是他们和他们的君王、首领、祭司、先知，并犹大的众人以及耶路撒冷的居民所行的，惹我发怒。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 7:13; 耶利米书 2:27; 以西结书 8:16"> 他们以背向我，不以面向我。我虽从早起来教训他们，他们却不听从，不受教训，</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米书 7:30; 以西结书 8:5–16; 列王纪下 21:4–7"> 竟把可憎之物设立在称为我名下的殿中，污秽了这殿。</span>
<span className="v" id="v35" data-v="35" data-xref="耶利米书 7:31; 历代志下 33:6; 利未记 18:21"> 他们在欣嫩子谷建筑巴力的丘坛，好使自己的儿女经火归摩洛，他们行这可憎的事，使犹大陷在罪里。这并不是我所吩咐的，也不是我心所起的意。</span>
</div>
</div>

## 后必导民复归故土

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="耶利米书 32:24; 耶利米书 32:3; 耶利米书 32:28"> “现在论到这城，就是你们所说已经因刀剑、饥荒、瘟疫交在巴比伦王手中的，耶和华以色列的神如此说：</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 23:3; 耶利米书 23:6; 以西结书 34:12–14"> 我在怒气、愤怒和大恼恨中将以色列人赶到各国，日后我必从那里将他们招聚出来，领他们回到此地，使他们安然居住。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米书 24:7; 以西结书 11:19–20; 希伯来书 8:10"> 他们要做我的子民，我要做他们的神。</span>
<span className="v" id="v39" data-v="39" data-xref="以西结书 11:19–20; 使徒行传 4:32; 约翰福音 17:21"> 我要使他们彼此同心同道，好叫他们永远敬畏我，使他们和他们后世的子孙得福乐。</span>
<span className="v" id="v40" data-v="40" data-xref="耶利米书 31:31–33; 以西结书 36:26; 耶利米书 24:7"> 又要与他们立永远的约，必随着他们施恩，并不离开他们，且使他们有敬畏我的心，不离开我。</span>
<span className="v" id="v41" data-v="41" data-xref="耶利米书 24:6; 西番雅书 3:17; 以赛亚书 62:5"> 我必欢喜施恩于他们，要尽心、尽意，诚诚实实将他们栽于此地。</span>
<span className="v" id="v42" data-v="42" data-xref="耶利米书 31:28; 约书亚记 23:14–15; 耶利米书 33:10–11"> 因为耶和华如此说：我怎样使这一切大祸临到这百姓，我也要照样使我所应许他们的一切福乐都临到他们。</span>
<span className="v" id="v43" data-v="43" data-xref="以西结书 37:11–14; 耶利米书 32:15; 耶利米书 32:36"> 你们说‘这地是荒凉无人民、无牲畜，是交付迦勒底人手之地’，日后在这境内必有人置买田地。</span>
<span className="v" id="v44" data-v="44" data-xref="耶利米书 17:26; 耶利米书 33:26; 耶利米书 33:11"> 在便雅悯地、耶路撒冷四围的各处、犹大的城邑、山地的城邑、高原的城邑并南地的城邑，人必用银子买田地，在契上画押，将契封缄，请出见证人，因为我必使被掳的人归回。这是耶和华说的。”</span>
</div>
</div>

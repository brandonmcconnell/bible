## 主示耶利米被掳之民必返故土

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 26:15; 耶利米书 1:1–2"> 耶和华的话临到耶利米说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 36:32; 以赛亚书 30:8; 哈巴谷书 2:2–3"> “耶和华以色列的神如此说：你将我对你说过的一切话都写在书上。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 29:14; 耶利米书 16:15; 耶利米书 30:18"> 耶和华说：日子将到，我要使我的百姓以色列和犹大被掳的人归回。我也要使他们回到我所赐给他们列祖之地，他们就得这地为业。这是耶和华说的。”</span>
</div>
</div>

## 遭祸之后必获拯救

<div className="bt">
<div className="bp poetry">
<span className="v" id="v4" data-v="4"> 以下是耶和华论到以色列和犹大所说的话。</span>
<span className="v" id="v5" data-v="5" data-xref="西番雅书 1:10–11; 阿摩司书 8:10; 以赛亚书 5:30"> 耶和华如此说：<br /><span className="pl pl-1">“我们听见声音，</span><br /><span className="pl pl-1">是战抖惧怕而不平安的声音。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="那鸿书 2:10; 约珥书 2:6; 耶利米书 4:31"> <span className="pl pl-1">你们且访问看看，</span><br /><span className="pl pl-1">男人有产难吗？</span><br /><span className="pl pl-1">我怎么看见人人用手掐腰，</span><br /><span className="pl pl-1">像产难的妇人，</span><br /><span className="pl pl-1">脸面都变青了呢？</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 12:1; 撒迦利亚书 14:1–2; 玛拉基书 4:1"> <span className="pl pl-1">哀哉！那日为大，</span><br /><span className="pl pl-1">无日可比。</span><br /><span className="pl pl-1">这是雅各遭难的时候，</span><br /><span className="pl pl-1">但他必被救出来。”</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="那鸿书 1:13; 以西结书 34:27; 以赛亚书 9:4"> 万军之耶和华说：“到那日，我必从你颈项上折断仇敌的轭，扭开他的绳索，外邦人不得再使你做他们的奴仆。</span>
<span className="v" id="v9" data-v="9" data-xref="何西阿书 3:5; 以赛亚书 55:3–5; 路加福音 1:69"> 你们却要侍奉耶和华你们的神，和我为你们所要兴起的王大卫。”</span>
</div>
</div>

## 慰藉雅各

<div className="bt">
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 46:27–28; 以赛亚书 43:5; 耶利米书 29:14"> 故此，耶和华说：<br /><span className="pl pl-1">“我的仆人雅各啊，不要惧怕！</span><br /><span className="pl pl-1">以色列啊，不要惊惶！</span><br /><span className="pl pl-1">因我要从远方拯救你，</span><br /><span className="pl pl-1">从被掳到之地拯救你的后裔，</span><br /><span className="pl pl-1">雅各必回来得享平靖安逸，</span><br /><span className="pl pl-1">无人使他害怕。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 10:24; 耶利米书 1:19; 以赛亚书 8:10"> <span className="pl pl-1">因我与你同在，要拯救你。</span><br /><span className="pl pl-1">也要将所赶散你到的那些国灭绝净尽，</span><br /><span className="pl pl-1">却不将你灭绝净尽。倒要从宽惩治你，</span><br /><span className="pl pl-1">万不能不罚你</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“不罚你”或作“以你为无罪”。">a</a></sup><br /><span className="pl pl-1">。”</span><br /><span className="pl pl-1">这是耶和华说的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="耶利米书 15:18; 耶利米书 30:15; 耶利米书 14:17"> 耶和华如此说：<br /><span className="pl pl-1">“你的损伤无法医治，</span><br /><span className="pl pl-1">你的伤痕极其重大。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 46:11; 耶利米书 8:22; 耶利米书 30:17"> <span className="pl pl-1">无人为你分诉，</span><br /><span className="pl pl-1">使你的伤痕得以缠裹，</span><br /><span className="pl pl-1">你没有医治的良药。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 5:6; 约伯记 30:21; 耶利米哀歌 1:2"> <span className="pl pl-1">你所亲爱的都忘记你，</span><br /><span className="pl pl-1">不来探问</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：理会。">b</a></sup><br /><span className="pl pl-1">你。</span><br /><span className="pl pl-1">我因你的罪孽甚大、罪恶众多，</span><br /><span className="pl pl-1">曾用仇敌加的伤害伤害你，</span><br /><span className="pl pl-1">用残忍者的惩治惩治你。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 30:14; 耶利米书 30:12; 耶利米书 6:6–7"> <span className="pl pl-1">你为何因损伤哀号呢？</span><br /><span className="pl pl-1">你的痛苦无法医治。</span><br /><span className="pl pl-1">我因你的罪孽甚大，罪恶众多，</span><br /><span className="pl pl-1">曾将这些加在你身上。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 10:25; 以赛亚书 33:1; 出埃及记 23:22"> <span className="pl pl-1">故此，凡吞吃你的必被吞吃，</span><br /><span className="pl pl-1">你的敌人个个都被掳去，</span><br /><span className="pl pl-1">掳掠你的必成为掳物，</span><br /><span className="pl pl-1">抢夺你的必成为掠物。”</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 107:20; 耶利米书 33:6; 彼得前书 2:24"> <span className="pl pl-1">耶和华说：“我必使你痊愈，</span><br /><span className="pl pl-1">医好你的伤痕，</span><br /><span className="pl pl-1">都因人称你为被赶散的，</span><br /><span className="pl pl-1">说‘这是锡安，无人来探问</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作：理会。">c</a></sup><br /><span className="pl pl-1">的’。”</span></span>
</div>
</div>

## 返故土者必将欢乐称谢

<div className="bt">
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="哈该书 2:7–9; 诗篇 102:13; 耶利米书 30:3"> 耶和华如此说：<br /><span className="pl pl-1">“我必使雅各被掳去的帐篷归回，</span><br /><span className="pl pl-1">也必顾惜他的住处，</span><br /><span className="pl pl-1">城必建造在原旧的山冈，</span><br /><span className="pl pl-1">宫殿也照旧有人居住。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 33:22; 以赛亚书 51:11; 以赛亚书 60:22"> <span className="pl pl-1">必有感谢和欢乐的声音从其中发出。</span><br /><span className="pl pl-1">我要使他们增多，不致减少；</span><br /><span className="pl pl-1">使他们尊荣，不致卑微。</span></span>
</div>
</div>

## 虐主民者必受重罚

<div className="bt">
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="耶利米书 32:39; 耶利米书 2:3; 耶利米书 50:33–34"> <span className="pl pl-1">“他们的儿女要如往日，</span><br /><span className="pl pl-1">他们的会众坚立在我面前，</span><br /><span className="pl pl-1">凡欺压他们的，我必刑罚他。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="民数记 16:5; 以西结书 34:23–24; 使徒行传 5:31"> <span className="pl pl-1">他们的君王必是属乎他们的，</span><br /><span className="pl pl-1">掌权的必从他们中间而出。</span><br /><span className="pl pl-1">我要使他就近我，</span><br /><span className="pl pl-1">他也要亲近我，</span><br /><span className="pl pl-1">不然谁有胆量亲近我呢？”</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="耶利米书 23:19–20; 撒迦利亚书 9:14; 耶利米书 25:32"> <span className="pl pl-1">看哪，耶和华的愤怒</span><br /><span className="pl pl-1">好像暴风，已经发出，</span><br /><span className="pl pl-1">是扫灭的暴风，</span><br /><span className="pl pl-1">必转到恶人的头上。</span><br /></span>

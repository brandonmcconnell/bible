## 先知警劝君民归正

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 34:2; 路加福音 3:19–20; 撒母耳记下 24:11–12"> 耶和华如此说：“你下到犹大王的宫中，在那里说这话，</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 1:32; 以赛亚书 9:7; 耶利米书 22:4"> 说：‘坐大卫宝座的犹大王啊，你和你的臣仆并进入城门的百姓，都当听耶和华的话。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 21:12; 弥迦书 6:8; 耶利米书 22:17"> 耶和华如此说：你们要施行公平和公义，拯救被抢夺的脱离欺压人的手，不可亏负寄居的和孤儿寡妇，不可以强暴待他们，在这地方也不可流无辜人的血。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 17:25"> 你们若认真行这事，就必有坐大卫宝座的君王和他的臣仆百姓，或坐车或骑马从这城的各门进入。</span>
<span className="v" id="v5" data-v="5" data-xref="阿摩司书 6:8; 希伯来书 6:13; 创世记 22:16"> 你们若不听这些话，耶和华说：我指着自己起誓，这城必变为荒场！</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 107:34; 以赛亚书 6:11; 以赛亚书 27:10"> 耶和华论到犹大王的家如此说：<br /><span className="pl pl-1">我看你如基列，</span><br /><span className="pl pl-1">如黎巴嫩顶，</span><br /><span className="pl pl-1">然而我必使你变为旷野，</span><br /><span className="pl pl-1">为无人居住的城邑。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 37:24; 以赛亚书 10:33–34; 耶利米书 4:6–7"> <span className="pl pl-1">我要预备行毁灭的人，</span><br /><span className="pl pl-1">各拿器械攻击你。</span><br /><span className="pl pl-1">他们要砍下你佳美的香柏树，</span><br /><span className="pl pl-1">扔在火中。</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪上 9:8–9; 历代志下 7:20–22; 申命记 29:23–26"> 许多国的民要经过这城，各人对邻舍说：“耶和华为何向这大城如此行呢？”</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 22:17; 历代志下 34:25; 耶利米书 50:7"> 他们必回答说：“是因离弃了耶和华他们神的约，侍奉敬拜别神。”</span>
</div>
</div>

## 预言沙龙之祸

<div className="bt">
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="传道书 4:2; 耶利米书 22:11; 以赛亚书 57:1"> <span className="pl pl-1">‘不要为死人哭号，</span><br /><span className="pl pl-1">不要为他悲伤，</span><br /><span className="pl pl-1">却要为离家出外的人大大哭号，</span><br /><span className="pl pl-1">因为他不得再回来，</span><br /><span className="pl pl-1">也不得再见他的本国。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="历代志上 3:15; 历代志下 36:1–4; 列王纪下 23:34"> 因为耶和华论到从这地方出去的犹大王约西亚的儿子沙龙<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="《列王纪下》23章30节名“约哈斯”。">a</a></sup>，就是接续他父亲约西亚做王的，这样说：他必不得再回到这里来，</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 23:34; 耶利米书 22:18"> 却要死在被掳去的地方，必不得再见这地。</span>
</div>
</div>

## 约雅敬之祸

<div className="bt">
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="雅各书 5:4; 弥迦书 3:10; 利未记 19:13"> <span className="pl pl-1">‘那行不义盖房，行不公造楼，</span><br /><span className="pl pl-1">白白使用人的手工不给工价的，有祸了！</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 7:2; 以赛亚书 5:8–9; 哈该书 1:4"> <span className="pl pl-1">他说：“我要为自己盖广大的房、宽敞的楼，</span><br /><span className="pl pl-1">为自己开窗户，</span><br /><span className="pl pl-1">这楼房的护墙板是香柏木的，</span><br /><span className="pl pl-1">楼房是丹色油漆的。”</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 23:25; 以赛亚书 3:10; 传道书 10:17"> <span className="pl pl-1">难道你做王是在乎造香柏木楼房争胜吗？</span><br /><span className="pl pl-1">你的父亲岂不是也吃也喝，</span><br /><span className="pl pl-1">也施行公平和公义吗？</span><br /><span className="pl pl-1">那时他得了福乐。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 9:24; 以赛亚书 1:17; 约翰一书 2:3–4"> <span className="pl pl-1">他为困苦和穷乏人申冤，</span><br /><span className="pl pl-1">那时就得了福乐，</span><br /><span className="pl pl-1">认识我不在乎此吗？</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="彼得后书 2:14; 列王纪下 24:4; 耶利米书 22:3"> <span className="pl pl-1">唯有你的眼和你的心专顾贪婪，</span><br /><span className="pl pl-1">流无辜人的血，</span><br /><span className="pl pl-1">行欺压和强暴。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="列王纪上 13:30; 耶利米书 16:6; 耶利米书 16:4"> 所以耶和华论到犹大王约西亚的儿子约雅敬如此说：<br /><span className="pl pl-1">人必不为他举哀说</span><br /><span className="pl pl-1">“哀哉，我的哥哥”，</span><br /><span className="pl pl-1">或说“哀哉，我的姐姐”；</span><br /><span className="pl pl-1">也不为他举哀说</span><br /><span className="pl pl-1">“哀哉，我的主”，</span><br /><span className="pl pl-1">或说“哀哉，我主的荣华”。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 36:30; 列王纪上 21:23–24; 历代志下 36:6"> <span className="pl pl-1">他被埋葬，好像埋驴一样，</span><br /><span className="pl pl-1">要拉出去扔在耶路撒冷的城门之外。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="民数记 27:12; 以西结书 23:22; 耶利米哀歌 1:2"> <span className="pl pl-1">‘你要上黎巴嫩哀号，</span><br /><span className="pl pl-1">在巴珊扬声，</span><br /><span className="pl pl-1">从亚巴琳哀号，</span><br /><span className="pl pl-1">因为你所亲爱的都毁灭了。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 32:30; 耶利米书 3:25; 耶利米书 7:22–28"> <span className="pl pl-1">你兴盛的时候，我对你说话，</span><br /><span className="pl pl-1">你却说：“我不听！”</span><br /><span className="pl pl-1">你自幼年以来总是这样，</span><br /><span className="pl pl-1">不听从我的话。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 5:30–31; 耶利米书 12:10; 耶利米书 23:1–2"> <span className="pl pl-1">你的牧人要被风吞吃，</span><br /><span className="pl pl-1">你所亲爱的必被掳去，</span><br /><span className="pl pl-1">那时你必因你一切的恶抱愧蒙羞。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 6:24; 耶利米书 4:30–31; 耶利米书 22:6"> <span className="pl pl-1">你这住黎巴嫩，在香柏树上搭窝的，</span><br /><span className="pl pl-1">有痛苦临到你，</span><br /><span className="pl pl-1">好像疼痛临到产难的妇人，</span><br /><span className="pl pl-1">那时你何等可怜！</span></span>
</div>
</div>

## 哥尼雅之祸

<div className="bt">
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="耶利米书 37:1; 雅歌 8:6; 历代志上 3:16"> ‘耶和华说：犹大王约雅敬的儿子哥尼雅<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="又名耶哥尼雅，下同。">b</a></sup>，虽是我右手上带印的戒指，我凭我的永生起誓，也必将你从其上摘下来。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 34:20–21; 耶利米书 21:7; 列王纪下 24:15–16"> 并且我必将你交给寻索你命的人和你所惧怕的人手中，就是巴比伦王尼布甲尼撒和迦勒底人的手中。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 24:15; 耶利米书 15:2–4; 以赛亚书 22:17"> 我也必将你和生你的母亲赶到别国，并不是你们生的地方，你们必死在那里。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 44:14; 列王纪下 25:27–30; 诗篇 86:4"> 但心中甚想归回之地，必不得归回。</span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 31:12; 何西阿书 8:8; 耶利米书 48:38"> <span className="pl pl-1">哥尼雅这人是被轻看、破坏的器皿吗？</span><br /><span className="pl pl-1">是无人喜爱的器皿吗？</span><br /><span className="pl pl-1">他和他的后裔为何被赶到不认识之地呢？</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="申命记 32:1; 弥迦书 1:2; 耶利米书 6:19"> <span className="pl pl-1">地啊，地啊，地啊，当听耶和华的话！</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 36:30; 诗篇 94:20; 马太福音 1:11–16"> <span className="pl pl-1">耶和华如此说：</span><br /><span className="pl pl-1">要写明这人算为无子，</span><br /><span className="pl pl-1">是平生不得亨通的，</span><br /><span className="pl pl-1">因为他后裔中再无一人得亨通，</span><br /><span className="pl pl-1">能坐在大卫的宝座上治理犹大。’”</span></span>
</div>
</div>

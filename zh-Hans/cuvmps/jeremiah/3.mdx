## 犹大之恶较以色列尤甚

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王纪下 17:7–17; 以西结书 16:31; 耶利米书 7:24"> 约西亚王在位的时候，耶和华又对我说：“背道的以色列所行的，你看见没有？她上各高山，在各青翠树下行淫。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 16:46; 何西阿书 6:1–4; 何西阿书 14:1"> 她行这些事以后，我说她必归向我，她却不归向我。她奸诈的妹妹犹大也看见了。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 24:1; 何西阿书 4:15–17; 以赛亚书 50:1"> 背道的以色列行淫，我为这缘故给她休书休她。我看见她奸诈的妹妹犹大还不惧怕，也去行淫。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 2:27; 以赛亚书 57:6; 耶利米书 3:2"> 因以色列轻忽了她的淫乱，和石头木头行淫，地就被玷污了。</span>
<span className="v" id="v10" data-v="10" data-xref="何西阿书 7:14; 耶利米书 12:2; 历代志下 34:33–18"> 虽有这一切的事，她奸诈的妹妹犹大还不一心归向我，不过是假意归我。”这是耶和华说的。</span>
</div>
</div>

## 悔罪归诚仍施矜悯

<div className="bt">
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="以西结书 23:11; 以西结书 16:51–52; 何西阿书 11:7"> 耶和华对我说：“背道的以色列比奸诈的犹大还显为义。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 86:15; 以西结书 33:11; 申命记 4:29–31"> 你去向北方宣告说：<br /><span className="pl pl-1">‘耶和华说：背道的以色列啊，回来吧！</span><br /><span className="pl pl-1">我必不怒目看你们，</span><br /><span className="pl pl-1">因为我是慈爱的，</span><br /><span className="pl pl-1">我必不永远存怒。</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 2:25; 耶利米书 3:6; 申命记 12:2"> <span className="pl pl-1">只要承认你的罪孽，</span><br /><span className="pl pl-1">就是你违背耶和华你的神，</span><br /><span className="pl pl-1">在各青翠树下向别神东奔西跑，</span><br /><span className="pl pl-1">没有听从我的话。</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="何西阿书 2:19–20; 耶利米书 2:19; 耶利米书 31:32"> <span className="pl pl-1">耶和华说：背道的儿女啊，回来吧！</span><br /><span className="pl pl-1">因为我做你们的丈夫，</span><br /><span className="pl pl-1">并且我必将你们从一城取一人，</span><br /><span className="pl pl-1">从一族取两人，带到锡安。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米书 23:4; 使徒行传 20:28; 以弗所书 4:11–12"> 我也必将合我心的牧者赐给你们，他们必以知识和智慧牧养你们。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 65:17; 阿摩司书 9:14–15; 以西结书 37:26"> 耶和华说：你们在国中生养众多，当那些日子，人必不再提说耶和华的约柜，不追想，不记念，不觉缺少，也不再制造。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 43:7; 弥迦书 4:1–5; 耶利米书 17:12"> 那时，人必称耶路撒冷为耶和华的宝座，万国必到耶路撒冷，在耶和华立名的地方聚集。他们必不再随从自己顽梗的恶心行事。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 31:8; 何西阿书 1:11; 阿摩司书 9:15"> 当那些日子，犹大家要和以色列家同行，从北方之地一同来到我赐给你们列祖为业之地。</span>
</div>
</div>

## 以色列认罪蒙恩

<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="耶利米书 3:4; 耶利米书 31:9; 以赛亚书 63:16"> <span className="pl pl-1">‘我说，我怎样将你安置在儿女之中，</span><br /><span className="pl pl-1">赐给你美地，</span><br /><span className="pl pl-1">就是万国中肥美的产业！</span><br /><span className="pl pl-1">我又说，你们必称我为父，</span><br /><span className="pl pl-1">也不再转去不跟从我。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 48:8; 耶利米书 5:11; 何西阿书 5:7"> <span className="pl pl-1">以色列家，你们向我行诡诈，</span><br /><span className="pl pl-1">真像妻子行诡诈离开她丈夫一样。</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 7:10; 耶利米书 31:9; 耶利米书 2:32"> <span className="pl pl-1">在净光的高处听见人声，</span><br /><span className="pl pl-1">就是以色列人哭泣恳求之声，</span><br /><span className="pl pl-1">乃因他们走弯曲之道，</span><br /><span className="pl pl-1">忘记耶和华他们的神。</span><br /></span>

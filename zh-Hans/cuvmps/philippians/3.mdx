## 保罗只在基督里夸口

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 5:11; 腓立比书 4:4; 雅各书 1:2"> 弟兄们，我还有话说，你们要靠主喜乐！我把这话再写给你们，于我并不为难，于你们却是妥当。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 11:13; 提多书 1:16; 启示录 22:15"> 应当防备犬类，防备作恶的，防备妄自行割的。</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 2:11; 申命记 30:6; 罗马书 7:6"> 因为真受割礼的，乃是我们这以神的灵敬拜，在基督耶稣里夸口，不靠着肉体的。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 11:18–22"> 其实我也可以靠肉体，若是别人想他可以靠肉体，我更可以靠着了。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 11:22; 罗马书 11:1; 使徒行传 23:6"> 我第八天受割礼，我是以色列族便雅悯支派的人，是希伯来人所生的希伯来人。就律法说，我是法利赛人；</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 1:13–14; 使徒行传 8:3; 使徒行传 26:9–10"> 就热心说，我是逼迫教会的；就律法上的义说，我是无可指摘的。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 14:33; 马太福音 16:26; 马太福音 13:44–46"> 只是我先前以为于我有益的，我现在因基督都当做有损的。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 9:23–24; 罗马书 8:18; 腓立比书 3:7"> 不但如此，我也将万事当做有损的，因我以认识我主基督耶稣为至宝。 为基督丢弃万事<br />我为他已经丢弃万事，看做粪土，为要得着基督，</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 5:21; 哥林多前书 1:30; 加拉太书 2:16"> 并且得以在他里面，不是有自己因律法而得的义，乃是有信基督的义，就是因信神而来的义；</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 2:20; 罗马书 8:17; 彼得前书 4:1–2"> 使我认识基督，晓得他复活的大能，并且晓得和他一同受苦，效法他的死，</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 20:35–36; 启示录 20:5; 使徒行传 23:6"> 或者我也得以从死里复活。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太前书 6:11–12; 彼得后书 1:5–8; 诗篇 138:8"> 这不是说我已经得着了，已经完全了，我乃是竭力追求，或者可以得着基督耶稣所以得着我的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“所以得着我的”或作“所要我得的”。">a</a></sup>。</span>
</div>
</div>

## 忘记背后努力面前的

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:62; 希伯来书 12:1–2; 腓立比书 3:12"> 弟兄们，我不是以为自己已经得着了，我只有一件事，就是忘记背后，努力面前的，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 9:24; 彼得前书 5:10; 启示录 3:21"> 向着标竿直跑，要得神在基督耶稣里从上面召我来得的奖赏。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 7:17; 雅各书 1:4–5; 箴言 2:3–6"> 所以我们中间凡是完全人，总要存这样的心；若在什么事上存别样的心，神也必以此指示你们。</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 2:6; 启示录 3:3; 启示录 2:4–5"> 然而我们到了什么地步，就当照着什么地步行。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="腓立比书 4:9; 哥林多前书 4:16; 彼得前书 5:3"> 弟兄们，你们要一同效法我，也当留意看那些照我们榜样行的人。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 4:17; 以赛亚书 8:11; 加拉太书 6:12"> 因为有许多人行事是基督十字架的仇敌，我屡次告诉你们，现在又流泪地告诉你们。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 16:18; 罗马书 8:5–7; 彼得后书 2:3"> 他们的结局就是沉沦，他们的神就是自己的肚腹！他们以自己的羞辱为荣耀，专以地上的事为念。</span>
</div>
</div>

## 门徒是天上的国民

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以弗所书 2:19; 歌罗西书 3:1–3; 哥林多后书 4:18–1"> 我们却是天上的国民，并且等候救主，就是主耶稣基督，从天上降临。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 3:2; 歌罗西书 3:4; 哥林多前书 15:42–56"> 他要按着那能叫万有归服自己的大能，将我们这卑贱的身体改变形状，和他自己荣耀的身体相似。</span>
</div>

## 大卫闻报基利波山之噩耗

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 27:6; 撒母耳记上 31:6; 撒母耳记上 30:17–26"> 扫罗死后，大卫击杀亚玛力人回来，在洗革拉住了两天。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 4:12; 撒母耳记下 4:10; 约书亚记 7:6"> 第三天，有一人从扫罗的营里出来，衣服撕裂，头蒙灰尘，到大卫面前伏地叩拜。</span>
<span className="v" id="v3" data-v="3" data-xref="约伯记 1:15–19; 列王纪下 5:25"> 大卫问他说：“你从哪里来？”他说：“我从以色列的营里逃来。”</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 4:16; 撒母耳记上 31:1–6; 历代志上 10:1–6"> 大卫又问他说：“事情怎样？请你告诉我。”他回答说：“百姓从阵上逃跑，也有许多人仆倒死亡，扫罗和他儿子约拿单也死了。”</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 25:2; 箴言 14:15"> 大卫问报信的少年人说：“你怎么知道扫罗和他儿子约拿单死了呢？”</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 28:4; 撒母耳记下 1:21; 历代志上 10:4–6"> 报信的少年人说：“我偶然到基利波山，看见扫罗伏在自己枪上，有战车、马兵紧紧地追他。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 22:12; 撒母耳记下 9:6; 士师记 9:54"> 他回头看见我，就呼叫我。我说：‘我在这里。’</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 30:17; 撒母耳记上 30:13; 撒母耳记上 30:1"> 他问我说：‘你是什么人？’我说：‘我是亚玛力人。’</span>
<span className="v" id="v9" data-v="9"> 他说：‘请你来将我杀死，因为痛苦抓住我，我的生命尚存。’</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 7:2; 士师记 9:54; 列王纪下 11:12"> 我准知他仆倒必不能活，就去将他杀死，把他头上的冠冕、臂上的镯子拿到我主这里。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 13:31; 创世记 37:29; 撒母耳记下 3:31"> 大卫就撕裂衣服，跟随他的人也是如此，</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 24:17; 诗篇 35:13–14; 马太福音 5:44"> 而且悲哀哭号，禁食到晚上，是因扫罗和他儿子约拿单，并耶和华的民以色列家的人倒在刀下。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 1:8"> 大卫问报信的少年人说：“你是哪里的人？”他说：“我是亚玛力客人的儿子。”</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 26:9; 撒母耳记上 31:4; 彼得后书 2:10"> 大卫说：“你伸手杀害耶和华的受膏者，怎么不畏惧呢？”</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 2:34; 士师记 8:20; 撒母耳记下 4:10–12"> 大卫叫了一个少年人来，说：“你去杀他吧！”</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 27:25; 路加福音 19:22; 利未记 20:9"> 大卫对他说：“你流人血的罪归到自己的头上，因为你亲口作见证说‘我杀了耶和华的受膏者’。”少年人就把他杀了。</span>
</div>
</div>

## 为扫罗及约拿单作哀歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="历代志下 35:25; 撒母耳记下 1:19; 创世记 50:11"> 大卫作哀歌，吊扫罗和他儿子约拿单，</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 10:13; 创世记 49:8; 申命记 4:10"> 且吩咐将这歌教导犹大人。这歌名叫弓歌，写在《雅煞珥书》上。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 1:27; 撒母耳记下 1:25; 申命记 4:7–8"> 歌中说：<br /><span className="pl pl-1">“以色列啊，你尊荣者在山上被杀，</span><br /><span className="pl pl-1">大英雄何竟死亡！</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="弥迦书 1:10; 撒母耳记上 18:6; 士师记 11:34"> <span className="pl pl-1">不要在迦特报告，</span><br /><span className="pl pl-1">不要在亚实基伦街上传扬，</span><br /><span className="pl pl-1">免得非利士的女子欢乐，</span><br /><span className="pl pl-1">免得未受割礼之人的女子矜夸。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 31:1; 以赛亚书 21:5; 撒母耳记上 10:1"> <span className="pl pl-1">基利波山哪，愿你那里没有雨露，</span><br /><span className="pl pl-1">愿你田地无土产可做供物！</span><br /><span className="pl pl-1">因为英雄的盾牌在那里被污丢弃，</span><br /><span className="pl pl-1">扫罗的盾牌仿佛未曾抹油。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 18:4; 以赛亚书 34:6–7; 撒母耳记上 14:6–14"> <span className="pl pl-1">约拿单的弓箭非流敌人的血不退缩，</span><br /><span className="pl pl-1">扫罗的刀剑非剖勇士的油不收回。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 4:13; 士师记 14:18; 耶利米哀歌 4:19"> <span className="pl pl-1">扫罗和约拿单，</span><br /><span className="pl pl-1">活时相悦相爱，死时也不分离；</span><br /><span className="pl pl-1">他们比鹰更快，比狮子还强。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="彼得前书 3:3–5; 耶利米书 2:32; 士师记 5:30"> <span className="pl pl-1">以色列的女子啊，当为扫罗哭号！</span><br /><span className="pl pl-1">他曾使你们穿朱红色的美衣，</span><br /><span className="pl pl-1">使你们衣服有黄金的装饰。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 1:19; 撒母耳记下 1:27; 士师记 5:18"> <span className="pl pl-1">英雄何竟在阵上仆倒，</span><br /><span className="pl pl-1">约拿单何竟在山上被杀！</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记上 20:17; 撒母耳记上 23:16; 撒母耳记上 20:41"> <span className="pl pl-1">我兄约拿单哪，我为你悲伤！</span><br /><span className="pl pl-1">我甚喜悦你，</span><br /><span className="pl pl-1">你向我发的爱情奇妙非常，</span><br /><span className="pl pl-1">过于妇女的爱情。</span><br /></span>

## 大卫立意为耶和华建殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 16:7; 路加福音 1:74–75; 列王纪上 5:4"> 王住在自己宫中，耶和华使他安靖，不被四围的仇敌扰乱。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 16:1; 撒母耳记下 5:11; 哈该书 1:4"> 那时，王对先知拿单说：“看哪，我住在香柏木的宫中，神的约柜反在幔子里！”</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 22:7; 列王纪上 8:17–18; 列王纪下 4:27"> 拿单对王说：“你可以照你的心意而行，因为耶和华与你同在。”</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 17:3; 民数记 12:6; 阿摩司书 3:7"> 当夜，耶和华的话临到拿单说：</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 23:3–32; 列王纪上 5:3–4; 列王纪上 8:16–19"> “你去告诉我仆人大卫说：‘耶和华如此说：你岂可建造殿宇给我居住呢？</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 8:16; 约书亚记 18:1; 出埃及记 40:18–19"> 自从我领以色列人出埃及直到今日，我未曾住过殿宇，常在会幕和帐幕中行走。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 17:6; 撒母耳记下 5:2; 利未记 26:11–12"> 凡我同以色列人所走的地方，我何曾向以色列一支派的士师，就是我吩咐牧养我民以色列的，说：“你们为何不给我建造香柏木的殿宇呢？”’</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 78:70–71; 撒母耳记下 6:21; 撒母耳记下 12:7"> 现在你要告诉我仆人大卫说：‘万军之耶和华如此说：我从羊圈中将你召来，叫你不再跟从羊群，立你做我民以色列的君。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 5:10; 历代志上 17:8; 撒母耳记上 18:14"> 你无论往哪里去，我常与你同在，剪除你的一切仇敌。我必使你得大名，好像世上大大有名的人一样。</span>
<span className="v" id="v10" data-v="10" data-xref="阿摩司书 9:15; 历代志上 17:9; 耶利米书 24:6"> 我必为我民以色列选定一个地方，栽培他们，使他们住自己的地方，不再迁移。凶恶之子也不像从前扰害他们，</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 7:27; 撒母耳记下 7:1; 历代志上 17:10"> 并不像我命士师治理我民以色列的时候一样。我必使你安靖，不被一切仇敌扰乱。并且我耶和华应许你，必为你建立家室。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 8:20; 使徒行传 2:30; 使徒行传 13:36"> 你寿数满足与你列祖同睡的时候，我必使你的后裔接续你的位，我也必坚定他的国。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 1:31–33; 列王纪上 8:19; 撒母耳记下 7:16"> 他必为我的名建造殿宇，我必坚定他的国位直到永远。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 1:5; 启示录 3:19; 历代志上 17:13"> 我要做他的父，他要做我的子。他若犯了罪，我必用人的杖责打他，用人的鞭责罚他。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 15:23; 撒母耳记上 15:28; 诗篇 89:28"> 但我的慈爱仍不离开他，像离开在你面前所废弃的扫罗一样。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 1:32–33; 诗篇 89:36–37; 撒母耳记下 7:13"> 你的家和你的国必在我<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：你。">a</a></sup>面前永远坚立，你的国位也必坚定直到永远。’”</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 17:15; 使徒行传 20:27; 哥林多前书 15:3"> 拿单就按这一切话，照这默示，告诉大卫。</span>
</div>
</div>

## 大卫之祈祷与颂感

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="诗篇 8:4; 历代志上 17:16; 撒母耳记上 18:18"> 于是大卫王进去，坐在耶和华面前，说：“主耶和华啊，我是谁，我的家算什么，你竟使我到这地步呢？</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 55:8–9; 历代志上 17:17; 诗篇 36:7"> 主耶和华啊，这在你眼中还看为小，又应许你仆人的家至于久远。主耶和华啊，这岂是人所常遇的事吗？</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 21:17; 撒母耳记上 16:7; 诗篇 139:1"> 主耶和华啊，我还有何言可以对你说呢？因为你知道你的仆人。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 115:1; 诗篇 138:2; 以弗所书 1:9"> 你行这大事使仆人知道，是因你所应许的话，也是照你的心意。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 86:10; 出埃及记 15:11; 诗篇 86:8"> 主耶和华啊，你本为大，照我们耳中听见，没有可比你的，除你以外再无神。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 9:26; 申命记 10:21; 申命记 15:15"> 世上有何民能比你的民以色列呢？你从埃及救赎他们做自己的子民，又在你赎出来的民面前行大而可畏的事，驱逐列邦人和他们的神，显出你的大名。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 26:18; 彼得前书 2:10; 创世记 17:7"> 你曾坚立你的民以色列做你的子民直到永远，你耶和华也做了他们的神。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 119:49; 以西结书 36:37; 创世记 32:12"> 耶和华神啊，你所应许仆人和仆人家的话，求你坚定直到永远，照你所说的而行。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志上 17:23–24; 诗篇 72:18–19; 马太福音 6:9"> 愿人永远尊你的名为大，说：‘万军之耶和华是治理以色列的神！’这样，你仆人大卫的家必在你面前坚立。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志上 17:25–26; 诗篇 10:17; 路得记 4:4"> 万军之耶和华以色列的神啊，因你启示你的仆人说‘我必为你建立家室’，所以仆人大胆向你如此祈祷。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 17:17; 出埃及记 34:6; 民数记 23:19"> 主耶和华啊，唯有你是神，你的话是真实的，你也应许将这福气赐给仆人。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 6:24–26; 历代志上 17:27; 诗篇 115:12–15"> 现在求你赐福于仆人的家，可以永存在你面前。主耶和华啊，这是你所应许的，愿你永远赐福于仆人的家。”</span>
</div>

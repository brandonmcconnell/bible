## 大卫初生之子

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 14:30; 箴言 4:18–19; 约伯记 8:7"> 扫罗家和大卫家争战许久，大卫家日见强盛，扫罗家日见衰弱。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="历代志上 3:1–4; 创世记 49:3–4; 撒母耳记下 13:1–29"> 大卫在希伯仑得了几个儿子：长子暗嫩，是耶斯列人亚希暖所生的；</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 27:8; 历代志上 3:1; 申命记 3:14"> 次子基利押<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“基利押”《历代志上》3章1节作“但以利”。">a</a></sup>，是做过迦密人拿八的妻亚比该所生的；三子押沙龙，是基述王达买的女儿玛迦所生的；</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 2:13–25; 列王纪上 1:5–18"> 四子亚多尼雅，是哈及所生的；五子示法提雅，是亚比她所生的；</span>
<span className="v" id="v5" data-v="5"> 六子以特念，是大卫的妻以格拉所生的。大卫这六个儿子都是在希伯仑生的。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 2:8–9; 历代志下 25:8; 以赛亚书 8:9–10"> 扫罗家和大卫家争战的时候，押尼珥在扫罗家大有权势。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 21:8–11; 列王纪上 2:21–22; 撒母耳记下 12:8"> 扫罗有一妃嫔，名叫利斯巴，是爱亚的女儿。一日，伊施波设对押尼珥说：“你为什么与我父的妃嫔同房呢？”</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 9:8; 撒母耳记下 16:9; 马可福音 6:18–19"> 押尼珥因伊施波设的话就甚发怒，说：“我岂是犹大的狗头呢？我恩待你父扫罗的家和他的弟兄、朋友，不将你交在大卫手里，今日你竟为这妇人责备我吗？</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 15:28; 列王纪上 19:2; 路得记 1:17"> 我若不照着耶和华起誓应许大卫的话行，废去扫罗的位，建立大卫的位，使他治理以色列和犹大，从但直到别是巴，愿神重重地降罚于我！”</span>
<span className="v" id="v11" data-v="11"> 伊施波设惧怕押尼珥，不敢回答一句。</span>
</div>
</div>

## 押尼珥结约归大卫

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="历代志上 12:38–40; 撒母耳记下 3:21; 路加福音 16:5–8"> 押尼珥打发人去见大卫，替他说：“这国归谁呢？”又说：“你与我立约，我必帮助你，使以色列人都归服你。”</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 43:3; 撒母耳记上 19:11–17; 创世记 44:23"> 大卫说：“好！我与你立约。但有一件，你来见我面的时候，若不将扫罗的女儿米甲带来，必不得见我的面。”</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 18:27; 撒母耳记上 18:25; 撒母耳记下 2:10"> 大卫就打发人去见扫罗的儿子伊施波设，说：“你要将我的妻米甲归还我，她是我从前用一百非利士人的阳皮所聘定的。”</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 25:44"> 伊施波设就打发人去，将米甲从拉亿的儿子，她丈夫帕铁那里接回来。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 16:5; 撒母耳记下 19:16; 列王纪上 2:8"> 米甲的丈夫跟着她，一面走一面哭，直跟到巴户琳。押尼珥说：“你回去吧！”帕铁就回去了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 押尼珥对以色列长老说：“从前你们愿意大卫做王治理你们，</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 15:28; 诗篇 89:19–23; 撒母耳记上 9:16"> 现在你们可以照心愿而行。因为耶和华曾论到大卫说：‘我必藉我仆人大卫的手，救我民以色列脱离非利士人和众仇敌的手。’”</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 12:29; 撒母耳记上 10:20–21; 诗篇 68:27"> 押尼珥也用这话说给便雅悯人听，又到希伯仑，将以色列人和便雅悯全家一切所喜悦的事说给大卫听。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 31:54; 创世记 26:30; 以斯帖记 1:3"> 押尼珥带着二十个人来到希伯仑见大卫，大卫就为押尼珥和他带来的人设摆筵席。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记下 3:12; 列王纪上 11:37; 撒母耳记下 3:10"> 押尼珥对大卫说：“我要起身去招聚以色列众人来见我主我王，与你立约，你就可以照着心愿做王。”于是大卫送押尼珥去，押尼珥就平平安安地去了。</span>
</div>
</div>

## 约押疑忌押尼珥

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22"> 约押和大卫的仆人攻击敌军，带回许多的掠物。那时押尼珥不在希伯仑大卫那里，因大卫已经送他去，他也平平安安地去了。</span>
<span className="v" id="v23" data-v="23"> 约押和跟随他的全军到了，就有人告诉约押说，尼珥的儿子押尼珥来见王，王送他去，他也平平安安地去了。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 3:8; 撒母耳记下 19:5–7; 约翰福音 18:35"> 约押去见王说：“你这是做什么呢？押尼珥来见你，你为何送他去，他就踪影不见了呢？</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 28:6; 以赛亚书 37:28; 民数记 27:17"> 你当晓得，尼珥的儿子押尼珥来是要诓哄你，要知道你的出入和你一切所行的事。”</span>
<span className="v" id="v26" data-v="26" data-xref="箴言 26:23–26; 箴言 27:4–6"> 约押从大卫那里出来，就打发人去追赶押尼珥，在西拉井追上他，将他带回来，大卫却不知道。</span>
</div>
</div>

## 刺杀押尼珥

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="列王纪上 2:5; 撒母耳记下 20:9–10; 列王纪上 2:32"> 押尼珥回到希伯仑，约押领他到城门的瓮洞，假作要与他说机密话，就在那里刺透他的肚腹，他便死了。这是报杀他兄弟亚撒黑的仇。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 35:33; 出埃及记 21:12; 创世记 9:6"> 大卫听见了，就说：“流尼珥的儿子押尼珥的血，这罪在耶和华面前必永不归我和我的国。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 1:16; 诗篇 109:8–19; 利未记 13:44–46"> 愿流他血的罪归到约押头上和他父的全家！又愿约押家不断有患漏症的，长大麻风的，架拐而行的，被刀杀死的，缺乏饮食的！”</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 28:17; 使徒行传 28:4; 撒母耳记下 2:19–23"> 约押和他兄弟亚比筛杀了押尼珥，是因押尼珥在基遍争战的时候杀了他们的兄弟亚撒黑。</span>
</div>
</div>

## 大卫哀悼押尼珥

<div className="bt">
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="创世记 37:34; 撒母耳记下 1:11; 撒母耳记下 1:2"> 大卫吩咐约押和跟随他的众人说：“你们当撕裂衣服，腰束麻布，在押尼珥棺前哀哭。”大卫王也跟在棺后。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 24:17; 约伯记 31:28; 撒母耳记上 30:4"> 他们将押尼珥葬在希伯仑。王在押尼珥的墓旁放声而哭，众民也都哭了。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 1:17; 历代志下 35:25; 路加福音 12:19–20"> 王为押尼珥举哀，说：<br /><span className="pl pl-1">“押尼珥何竟像愚顽人死呢？</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="士师记 16:21; 撒母耳记下 1:12; 约伯记 24:14"> <span className="pl pl-1">你手未曾捆绑，脚未曾锁住，</span><br /><span className="pl pl-1">你死如人死在罪孽之辈手下一样。”</span><br />于是众民又为押尼珥哀哭。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 12:17; 撒母耳记下 1:12; 路得记 1:17"> 日头未落的时候，众民来劝大卫吃饭，但大卫起誓说：“我若在日头未落以前吃饭，或吃别物，愿神重重地降罚于我！”</span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 7:37; 诗篇 62:9; 马可福音 15:11–13"> 众民知道了就都喜悦。凡王所行的，众民无不喜悦。</span>
<span className="v" id="v37" data-v="37"> 那日，以色列众民才知道杀尼珥的儿子押尼珥并非出于王意。</span>
<span className="v" id="v38" data-v="38" data-xref="约伯记 32:9; 撒母耳记下 2:8; 撒母耳记下 3:12"> 王对臣仆说：“你们岂不知今日以色列人中死了一个做元帅的大丈夫吗？</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪上 2:33–34; 诗篇 101:8; 诗篇 28:4"> 我虽然受膏为王，今日还是软弱，这洗鲁雅的两个儿子比我刚强。愿耶和华照着恶人所行的恶报应他！”</span>
</div>
</div>

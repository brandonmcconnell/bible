## 预示推罗之荒废

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约珥书 3:4–8; 阿摩司书 1:9–10; 创世记 10:4"> 论推罗的默示。<br /><span className="pl pl-1">他施的船只，都要哀号！</span><br /><span className="pl pl-1">因为推罗变为荒场，</span><br /><span className="pl pl-1">甚至没有房屋，没有可进之路。</span><br /><span className="pl pl-1">这消息是从基提地得来的。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 47:5; 以赛亚书 41:1; 以西结书 28:2"> <span className="pl pl-1">沿海的居民，</span><br /><span className="pl pl-1">就是素来靠航海西顿的商家得丰盛的，</span><br /><span className="pl pl-1">你们当静默无言！</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 2:18; 历代志上 13:5; 以西结书 27:33"> <span className="pl pl-1">在大水之上，</span><br /><span className="pl pl-1">西曷的粮食、</span><br /><span className="pl pl-1">尼罗河的庄稼是推罗的进项，</span><br /><span className="pl pl-1">她做列国的大码头。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="启示录 18:23; 创世记 10:15; 耶利米书 47:3–4"> <span className="pl pl-1">西顿哪，你当惭愧！</span><br /><span className="pl pl-1">因为大海说，</span><br /><span className="pl pl-1">就是海中的保障说：</span><br /><span className="pl pl-1">“我没有劬劳，也没有生产；</span><br /><span className="pl pl-1">没有养育男子，也没有抚养童女。”</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 2:9–11; 出埃及记 15:14–16; 启示录 18:17–19"> <span className="pl pl-1">这风声传到埃及，</span><br /><span className="pl pl-1">埃及人为推罗的风声极其疼痛。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 23:12; 以赛亚书 21:15; 以赛亚书 23:10"> <span className="pl pl-1">推罗人哪，你们当过到他施去！</span><br /><span className="pl pl-1">沿海的居民哪，你们都当哀号！</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 22:2; 以赛亚书 32:13; 约书亚记 19:29"> <span className="pl pl-1">这是你们欢乐的城，</span><br /><span className="pl pl-1">从上古而有的吗？</span><br /><span className="pl pl-1">其中的居民往远方寄居。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 10:8; 耶利米书 50:44–45; 申命记 29:24–28"> <span className="pl pl-1">推罗本是赐冠冕的，</span><br /><span className="pl pl-1">她的商家是王子，</span><br /><span className="pl pl-1">她的买卖人是世上的尊贵人。</span><br /><span className="pl pl-1">遭遇如此，是谁定的呢？</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="雅各书 4:6; 以赛亚书 13:11; 约伯记 40:11–12"> <span className="pl pl-1">是万军之耶和华所定的，</span><br /><span className="pl pl-1">为要污辱一切高傲的荣耀，</span><br /><span className="pl pl-1">使地上一切的尊贵人被藐视。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="约伯记 12:21; 以赛亚书 23:14; 诗篇 18:32"> <span className="pl pl-1">他施的民</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“民”原文作“女”。">a</a></sup><br /><span className="pl pl-1">哪，</span><br /><span className="pl pl-1">可以流行你的地，好像尼罗河，</span><br /><span className="pl pl-1">不再有腰带拘紧你。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亚书 9:3–4; 出埃及记 14:21; 耶利米书 47:7"> <span className="pl pl-1">耶和华已经向海伸手，</span><br /><span className="pl pl-1">震动列国；</span><br /><span className="pl pl-1">至于迦南，</span><br /><span className="pl pl-1">他已经吩咐拆毁其中的保障。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="启示录 18:22; 以西结书 26:13–14; 以赛亚书 23:1–2"> <span className="pl pl-1">他又说：“受欺压西顿的居民</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“居民”原文作“处女”。">b</a></sup><br /><span className="pl pl-1">哪，</span><br /><span className="pl pl-1">你必不得再欢乐！</span><br /><span className="pl pl-1">起来，过到基提去，</span><br /><span className="pl pl-1">就是在那里也不得安歇！”</span></span>
</div>
</div>

## 越七十年推罗必蒙眷顾

<div className="bt">
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="哈巴谷书 1:6; 以赛亚书 10:5; 列王纪下 17:24"> 看哪，迦勒底人之地！向来没有这民，这国是亚述人为住旷野的人所立的，现在他们建筑戍楼，拆毁推罗的宫殿，使她成为荒凉。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 23:1; 以赛亚书 23:6; 以西结书 27:25–30"> <span className="pl pl-1">他施的船只，都要哀号！</span><br /><span className="pl pl-1">因为你们的保障变为荒场。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="耶利米书 25:22; 耶利米书 25:9–11; 但以理书 7:14"> 到那时，推罗必被忘记七十年，照着一王的年日。七十年后，推罗的景况必像妓女所唱的歌。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 30:14; 箴言 7:10–12"> <span className="pl pl-1">你这被忘记的妓女啊，</span><br /><span className="pl pl-1">拿琴周流城内！</span><br /><span className="pl pl-1">巧弹多唱使人再想念你！</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="那鸿书 3:4; 以西结书 27:6–36; 启示录 19:2"> 七十年后，耶和华必眷顾推罗，她就仍得利息<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文作：雇价。下同。">c</a></sup>，与地上的万国交易<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原文作：行淫。">d</a></sup>。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 72:10; 申命记 26:12–14; 腓立比书 4:17–18"> 她的货财和利息要归耶和华为圣，必不积攒存留，因为她的货财必为住在耶和华面前的人所得，使他们吃饱，穿耐久的衣服。</span>
</div>

## 亚述王攻犹大

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 32:1; 列王纪下 18:13; 列王纪下 18:17"> 希西家王十四年，亚述王西拿基立上来攻击犹大的一切坚固城，将城攻取。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 32:9–23; 以赛亚书 7:3; 列王纪下 18:17–37"> 亚述王从拉吉差遣拉伯沙基率领大军往耶路撒冷，到希西家王那里去。他就站在上池的水沟旁，在漂布地的大路上。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 8:16–17; 以赛亚书 22:15–21; 撒母耳记下 20:24–25"> 于是希勒家的儿子家宰以利亚敬，并书记舍伯那和亚萨的儿子史官约亚，出来见拉伯沙基。</span>
</div>
</div>

## 拉伯沙基之狂语

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 18:19–37; 犹大书 1:16; 箴言 16:18"> 拉伯沙基对他们说：“你们去告诉希西家说：‘亚述大王如此说：你所倚靠的有什么可仗赖的呢？</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 18:7; 耶利米书 52:3; 箴言 21:30–31"> 你说有打仗的计谋和能力，我看不过是虚话！你到底倚靠谁才背叛我呢？</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 29:6–7; 耶利米书 37:5–8; 列王纪下 18:21"> 看哪，你所倚靠的埃及是那压伤的苇杖，人若靠这杖，就必刺透他的手，埃及王法老向一切倚靠他的人也是这样。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 18:4–5; 诗篇 42:10–11; 诗篇 42:5"> 你若对我说“我们倚靠耶和华我们的神”，希西家岂不是将神的丘坛和祭坛废去，且对犹大和耶路撒冷的人说“你们当在这坛前敬拜”吗？’</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 17:40–43; 列王纪上 20:10; 尼希米记 4:2–5"> 现在，你把当头给我主亚述王，我给你二千匹马，看你这一面骑马的人够不够！</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 10:8; 以赛亚书 30:16–17; 以赛亚书 36:6"> 若不然，怎能打败我主臣仆中最小的军长呢？你竟倚靠埃及的战车马兵吗？</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 18:25; 以赛亚书 10:5–7; 列王纪上 13:18"> 现在我上来攻击毁灭这地，岂没有耶和华的意思吗？耶和华吩咐我说：‘你上去攻击毁灭这地吧！’”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以斯拉记 4:7; 但以理书 2:4; 列王纪下 18:26–27"> 以利亚敬、舍伯那、约亚对拉伯沙基说：“求你用亚兰言语和仆人说话，因为我们懂得。不要用犹大言语和我们说话，达到城上百姓的耳中。”</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 18:27; 利未记 26:29; 耶利米哀歌 4:9–10"> 拉伯沙基说：“我主差遣我来，岂是单对你和你的主说这些话吗？不也是对这些坐在城上，要与你们一同吃自己粪喝自己尿的人说吗？”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志下 32:18; 诗篇 73:8–9; 列王纪下 18:28–32"> 于是拉伯沙基站着，用犹大言语大声喊着说：“你们当听亚述大王的话！</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦后书 2:4; 启示录 13:5–6; 但以理书 6:20"> 王如此说：‘你们不要被希西家欺哄了，因他不能拯救你们。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 37:23–24; 马太福音 27:43; 诗篇 71:9–11"> 也不要听希西家使你们倚靠耶和华说：“耶和华必要拯救我们，这城必不交在亚述王的手中。”’</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 4:25; 撒迦利亚书 3:10; 弥迦书 4:4"> 不要听希西家的话，因亚述王如此说：‘你们要与我和好，出来投降我，各人就可以吃自己葡萄树和无花果树的果子，喝自己井里的水。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 18:32; 申命记 8:7–9; 约伯记 20:17"> 等我来领你们到一个地方，与你们本地一样，就是有五谷和新酒之地，有粮食和葡萄园之地。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 37:17–18; 以赛亚书 36:15; 以赛亚书 37:10"> 你们要谨防，恐怕希西家劝导你们说：“耶和华必拯救我们。”列国的神，有哪一个救他本国脱离亚述王的手呢？</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 10:9–11; 耶利米书 49:23; 撒母耳记下 8:9"> 哈马和亚珥拔的神在哪里呢？西法瓦音的神在哪里呢？他们曾救撒马利亚脱离我的手吗？</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 50:21; 历代志下 32:19; 以赛亚书 37:23–29"> 这些国的神有谁曾救自己的国脱离我的手呢？难道耶和华能救耶路撒冷脱离我的手吗？’”</span>
</div>
</div>

## 以拉伯沙基之言告希西家

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="箴言 26:4; 诗篇 38:13–15; 马太福音 7:6"> 百姓静默不言，并不回答一句，因为王曾吩咐说：“不要回答他。”</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 36:3; 以赛亚书 33:7; 马太福音 26:65"> 当下，希勒家的儿子家宰以利亚敬，和书记舍伯那并亚萨的儿子史官约亚，都撕裂衣服来到希西家那里，将拉伯沙基的话告诉了他。</span>
</div>
</div>

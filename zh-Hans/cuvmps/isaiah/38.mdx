## 希西家遘疾祈祷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 38:1–8; 历代志下 32:24; 列王纪下 20:1–11"> 那时，希西家病得要死。亚摩斯的儿子先知以赛亚去见他，对他说：“耶和华如此说：你当留遗命于你的家，因为你必死，不能活了。”</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 6:6; 诗篇 91:15; 列王纪上 8:30"> 希西家就转脸朝墙，祷告耶和华说：</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 5:7; 诗篇 18:20–27; 希伯来书 6:10"> “耶和华啊，求你记念我在你面前怎样存完全的心，按诚实行事，又做你眼中所看为善的。”希西家就痛哭了。</span>
</div>
</div>

## 以赛亚奉谕慰藉之

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4"> 耶和华的话临到以赛亚说：</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 34:5–6; 约翰一书 5:14–15; 启示录 7:17"> “你去告诉希西家说：‘耶和华你祖大卫的神如此说：我听见了你的祷告，看见了你的眼泪。我必加增你十五年的寿数，</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 37:35; 以赛亚书 31:4–5; 以赛亚书 12:6"> 并且我要救你和这城脱离亚述王的手，也要保护这城。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 6:37–39; 以赛亚书 37:30; 以赛亚书 7:11–14"> 我耶和华必成就我所说的，我先给你一个兆头，</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪下 20:9–11; 约书亚记 10:12–14; 马太福音 16:1"> 就是叫亚哈斯的日晷向前进的日影往后退十度。’”于是前进的日影果然在日晷上往后退了十度。</span>
</div>
</div>

## 希西家感恩之歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="诗篇 18:1; 出埃及记 15:1–21; 约伯记 5:18"> 犹大王希西家患病已经痊愈，就作诗说：</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 102:24; 哥林多后书 1:9; 诗篇 107:18"> <span className="pl pl-1">“我说，正在我中年</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：晌午。">a</a></sup><br /><span className="pl pl-1">之日，</span><br /><span className="pl pl-1">必进入阴间的门，</span><br /><span className="pl pl-1">我余剩的年岁不得享受。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 27:13; 诗篇 116:8–9; 诗篇 31:22"> <span className="pl pl-1">我说，我必不得见耶和华，</span><br /><span className="pl pl-1">就是在活人之地不见耶和华，</span><br /><span className="pl pl-1">我与世上的居民不再见面。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 73:14; 哥林多后书 5:1; 希伯来书 1:12"> <span className="pl pl-1">我的住处被迁去离开我，</span><br /><span className="pl pl-1">好像牧人的帐篷一样。</span><br /><span className="pl pl-1">我将性命卷起，</span><br /><span className="pl pl-1">像织布的卷布一样，</span><br /><span className="pl pl-1">耶和华必将我从机头剪断；</span><br /><span className="pl pl-1">从早到晚，他要使我完结。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 51:8; 但以理书 6:24; 诗篇 50:22"> <span className="pl pl-1">我使自己安静直到天亮，</span><br /><span className="pl pl-1">他像狮子折断我一切的骨头；</span><br /><span className="pl pl-1">从早到晚，他要使我完结。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 59:11; 诗篇 69:3; 诗篇 123:1–4"> <span className="pl pl-1">我像燕子呢喃，</span><br /><span className="pl pl-1">像白鹤鸣叫，</span><br /><span className="pl pl-1">又像鸽子哀鸣，</span><br /><span className="pl pl-1">我因仰观，眼睛困倦。</span><br /><span className="pl pl-1">耶和华啊，我受欺压，</span><br /><span className="pl pl-1">求你为我作保！</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 21:27; 约伯记 7:11; 约伯记 10:1"> <span className="pl pl-1">我可说什么呢？</span><br /><span className="pl pl-1">他应许我的，也给我成就了。</span><br /><span className="pl pl-1">我因心里的苦楚，</span><br /><span className="pl pl-1">在一生的年日必悄悄而行。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 12:10–11; 哥林多前书 11:32; 诗篇 119:25"> <span className="pl pl-1">主啊，人得存活乃在乎此，</span><br /><span className="pl pl-1">我灵存活也全在此，</span><br /><span className="pl pl-1">所以求你使我痊愈，仍然存活。</span><br /></span>

<div className="bp">

## 参孙束炬于狐尾烧禾稼

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 38:17; 创世记 29:21; 路加福音 15:29"> 过了些日子，到割麦子的时候，参孙带着一只山羊羔去看他的妻，说：“我要进内室见我的妻。”他岳父不容他进去，</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 14:20; 士师记 14:16; 创世记 38:14"> 说：“我估定你是极其恨她，因此我将她给了你的陪伴。她的妹子不是比她还美丽吗？你可以娶来代替她吧。”</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 14:15"> 参孙说：“这回我加害于非利士人不算有罪。”</span>
<span className="v" id="v4" data-v="4" data-xref="雅歌 2:15; 诗篇 63:10; 耶利米哀歌 5:18"> 于是参孙去捉了三百只狐狸<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：野狗。">a</a></sup>，将狐狸尾巴一对一对地捆上，将火把捆在两条尾巴中间，</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 14:30; 出埃及记 22:6"> 点着火把，就放狐狸进入非利士人站着的禾稼，将堆集的禾捆和未割的禾稼，并橄榄园尽都烧了。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 14:15; 帖撒罗尼迦前书 4:6; 箴言 22:8"> 非利士人说：“这事是谁做的呢？”有人说：“是亭拿人的女婿参孙，因为他岳父将他的妻给了他的陪伴。”于是非利士人上去，用火烧了妇人和她的父亲。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 14:4; 罗马书 12:19; 士师记 14:19"> 参孙对非利士人说：“你们既然这样行，我必向你们报仇才肯罢休！”</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 63:3; 以赛亚书 63:6; 以赛亚书 25:10"> 参孙就大大击杀他们，连腿带腰都砍断了。他便下去，住在以坦磐的穴内。</span>
</div>
</div>

## 犹大人缚参孙

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="士师记 15:17; 士师记 15:19; 士师记 15:14"> 非利士人上去安营在犹大，布散在利希。</span>
<span className="v" id="v10" data-v="10"> 犹大人说：“你们为何上来攻击我们呢？”他们说：“我们上来是要捆绑参孙。他向我们怎样行，我们也要向他怎样行。”</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 13:1; 士师记 14:4; 申命记 28:47–48"> 于是有三千犹大人下到以坦磐的穴内，对参孙说：“非利士人辖制我们，你不知道吗？你向我们行的是什么事呢？”他回答说：“他们向我怎样行，我也要向他们怎样行。”</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 8:21; 使徒行传 7:25; 列王纪上 2:25"> 犹大人对他说：“我们下来是要捆绑你，将你交在非利士人手中。”参孙说：“你们要向我起誓，应承你们自己不害死我。”</span>
<span className="v" id="v13" data-v="13"> 他们说：“我们断不杀你，只要将你捆绑交在非利士人手中。”于是用两条新绳捆绑参孙，将他从以坦磐带上去。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="士师记 14:19; 士师记 3:10; 诗篇 118:11"> 参孙到了利希，非利士人都迎着喧嚷。耶和华的灵大大感动参孙，他臂上的绳就像火烧的麻一样，他的绑绳都从他手上脱落下来。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 23:10; 利未记 26:8; 士师记 3:31"> 他见一块未干的驴腮骨，就伸手拾起来，用以击杀一千人。</span>
<span className="v" id="v16" data-v="16"> 参孙说：<br /><span className="pl pl-1">“我用驴腮骨杀人成堆，</span><br /><span className="pl pl-1">用驴腮骨杀了一千人。”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 说完这话，就把那腮骨从手里抛出去了。那地便叫拉末利希。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 12:7–8; 希伯来书 11:32; 士师记 8:4"> 参孙甚觉口渴，就求告耶和华说：“你既藉仆人的手施行这么大的拯救，岂可任我渴死，落在未受割礼的人手中呢？”</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 44:3; 创世记 45:27; 诗篇 34:6"> 神就使利希的洼处裂开，有水从其中涌出来，参孙喝了精神复原。因此那泉名叫隐哈歌利，那泉直到今日还在利希。</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 13:1; 士师记 16:31; 士师记 13:5"> 当非利士人辖制以色列人的时候，参孙做以色列的士师二十年。</span>
</div>
</div>

## 玛挪亚与妻见天使

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="约书亚记 19:41; 路加福音 1:7; 约书亚记 15:33"> 那时，有一个琐拉人，是属但族的，名叫玛挪亚。他的妻不怀孕，不生育。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:13; 路加福音 1:11; 士师记 6:11–12"> 耶和华的使者向那妇人显现，对她说：“向来你不怀孕，不生育，如今你必怀孕生一个儿子。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 1:15; 士师记 13:14; 民数记 6:2–3"> 所以你当谨慎，清酒浓酒都不可喝，一切不洁之物也不可吃。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 6:5; 撒母耳记上 1:11; 历代志上 18:1"> 你必怀孕生一个儿子，不可用剃头刀剃他的头，因为这孩子一出胎就归神做拿细耳人。他必起首拯救以色列人脱离非利士人的手。”</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 13:17–18; 撒母耳记上 9:6; 马太福音 28:3–4"> 妇人就回去对丈夫说：“有一个神人到我面前来，他的相貌如神使者的相貌，甚是可畏。我没有问他从哪里来，他也没有将他的名告诉我，</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 13:4"> 却对我说：‘你要怀孕生一个儿子，所以清酒浓酒都不可喝，一切不洁之物也不可吃。因为这孩子从出胎一直到死，必归神做拿细耳人。’”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 9:6; 约伯记 34:32; 箴言 3:5–6"> 玛挪亚就祈求耶和华说：“主啊，求你再差遣那神人到我们这里来，好指教我们怎样待这将要生的孩子。”</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 65:2; 马太福音 7:7–11"> 神应允玛挪亚的话。妇人正坐在田间的时候，神的使者又到她那里，她丈夫玛挪亚却没有同她在一处。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 4:28–29; 约翰福音 1:41–42"> 妇人急忙跑去告诉丈夫说：“那日到我面前来的人，又向我显现。”</span>
<span className="v" id="v11" data-v="11"> 玛挪亚起来，跟随他的妻来到那人面前，对他说：“与这妇人说话的就是你吗？”他说：“是我。”</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 22:6; 以弗所书 6:4; 创世记 18:19"> 玛挪亚说：“愿你的话应验！我们当怎样待这孩子，他后来当怎样呢？”</span>
<span className="v" id="v13" data-v="13"> 耶和华的使者对玛挪亚说：“我告诉妇人的一切事，她都当谨慎。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 2:5; 士师记 13:4; 帖撒罗尼迦后书 3:4"> 葡萄树所结的都不可吃，清酒浓酒都不可喝，一切不洁之物也不可吃。凡我所吩咐的，她都当遵守。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士师记 6:18–19; 创世记 18:3–5; 士师记 13:3"> 玛挪亚对耶和华的使者说：“求你容我们款留你，好为你预备一只山羊羔。”</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 13:23; 士师记 6:20; 士师记 6:26"> 耶和华的使者对玛挪亚说：“你虽然款留我，我却不吃你的食物；你若预备燔祭，就当献于耶和华。”原来玛挪亚不知道他是耶和华的使者。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 32:29"> 玛挪亚对耶和华的使者说：“请将你的名告诉我，到你话应验的时候，我们好尊敬你。”</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 32:29; 以赛亚书 9:6; 士师记 13:6"> 耶和华的使者对他说：“你何必问我的名？我名是奇妙的。”</span>
<span className="v" id="v19" data-v="19" data-xref="士师记 6:19–21; 列王纪上 18:30–38"> 玛挪亚将一只山羊羔和素祭在磐石上献于耶和华。使者行奇妙的事，玛挪亚和他的妻观看，</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 9:24; 历代志上 21:16; 列王纪下 2:11"> 见火焰从坛上往上升，耶和华的使者在坛上的火焰中也升上去了。玛挪亚和他的妻看见，就俯伏于地。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="士师记 6:22; 何西阿书 12:4–5; 士师记 13:16"> 耶和华的使者不再向玛挪亚和他的妻显现，玛挪亚才知道他是耶和华的使者。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 32:30; 申命记 5:26; 约翰福音 1:18"> 玛挪亚对他的妻说：“我们必要死，因为看见了神。”</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 25:14; 哥林多前书 12:21; 约翰福音 15:15"> 他的妻却对他说：“耶和华若要杀我们，必不从我们手里收纳燔祭和素祭，并不将这一切事指示我们，今日也不将这些话告诉我们。”</span>
</div>
</div>

## 参孙生

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 1:80; 撒母耳记上 3:19; 希伯来书 11:32"> 后来妇人生了一个儿子，给他起名叫参孙。孩子长大，耶和华赐福于他。</span>
<span className="v" id="v25" data-v="25" data-xref="士师记 3:10; 约书亚记 15:33; 约翰福音 3:34"> 在玛哈尼但，就是琐拉和以实陶中间，耶和华的灵才感动他。</span>
</div>
</div>

## 以色列人为米甸人所虐

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 9:26–29; 士师记 2:19–20; 士师记 2:13–14"> 以色列人又行耶和华眼中看为恶的事，耶和华就把他们交在米甸人手里七年。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:38; 撒母耳记上 13:6; 申命记 28:47–48"> 米甸人压制以色列人，以色列人因为米甸人，就在山中挖穴、挖洞，建造营寨。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 6:33; 士师记 3:13; 士师记 7:12"> 以色列人每逢撒种之后，米甸人、亚玛力人和东方人都上来攻打他们，</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 26:16; 申命记 28:51; 弥迦书 6:15"> 对着他们安营，毁坏土产，直到加沙，没有给以色列人留下食物，牛、羊、驴也没有留下。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 7:12; 士师记 8:10; 耶利米书 46:23"> 因为那些人带着牲畜、帐篷来，像蝗虫那样多，人和骆驼无数，都进入国内，毁坏全地。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 3:9; 耶利米书 5:17; 诗篇 50:15"> 以色列人因米甸人的缘故，极其穷乏，就呼求耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 以色列人因米甸人的缘故，呼求耶和华，</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 20:5–32; 以赛亚书 63:9–14; 诗篇 136:10–16"> 耶和华就差遣先知到以色列人那里，对他们说：“耶和华以色列的神如此说：‘我曾领你们从埃及上来，出了为奴之家，</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 44:2–3"> 救你们脱离埃及人的手，并脱离一切欺压你们之人的手，把他们从你们面前赶出，将他们的地赐给你们。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 10:2; 列王纪下 17:35–39; 耶利米书 9:13"> 又对你们说：“我是耶和华你们的神。你们住在亚摩利人的地，不可敬畏他们的神。”你们竟不听从我的话。’”</span>
</div>
</div>

## 耶和华之使者向基甸显现

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约书亚记 17:2; 希伯来书 11:32; 士师记 13:3"> 耶和华的使者到了俄弗拉，坐在亚比以谢族人约阿施的橡树下。约阿施的儿子基甸正在酒榨那里打麦子，为要防备米甸人。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 1:5; 路加福音 1:28; 士师记 2:18"> 耶和华的使者向基甸显现，对他说：“大能的勇士啊，耶和华与你同在！”</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 77:7–9; 历代志下 15:2; 以赛亚书 59:1–2"> 基甸说：“主啊！耶和华若与我们同在，我们何至遭遇这一切事呢？我们的列祖不是向我们说，耶和华领我们从埃及上来吗？他那样奇妙的作为在哪里呢？现在他却丢弃我们，将我们交在米甸人手里。”</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 1:5–9; 希伯来书 11:34; 撒母耳记上 12:11"> 耶和华观看基甸，说：“你靠着你这能力，去从米甸人手里拯救以色列人。不是我差遣你去的吗？”</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 9:21; 出埃及记 3:11; 出埃及记 4:10"> 基甸说：“主啊，我有何能拯救以色列人呢？我家在玛拿西支派中是至贫穷的，我在我父家是至微小的。”</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 1:5; 出埃及记 3:12; 使徒行传 11:21"> 耶和华对他说：“我与你同在，你就必击打米甸人，如击打一人一样。”</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 86:17; 出埃及记 33:13; 以赛亚书 7:11"> 基甸说：“我若在你眼前蒙恩，求你给我一个证据，使我知道与我说话的就是主。</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 13:15; 创世记 18:3; 创世记 18:5"> 求你不要离开这里，等我归回将礼物带来供在你面前。”主说：“我必等你回来。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="创世记 18:6–8; 士师记 13:15–19; 利未记 2:4"> 基甸去预备了一只山羊羔，用一伊法细面做了无酵饼，将肉放在筐内，把汤盛在壶中，带到橡树下，献在使者面前。</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 13:19; 列王纪上 18:33–34"> 神的使者吩咐基甸说：“将肉和无酵饼放在这磐石上，把汤倒出来。”他就这样行了。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 9:24; 列王纪上 18:38; 历代志下 7:1"> 耶和华的使者伸出手内的杖，杖头挨了肉和无酵饼，就有火从磐石中出来，烧尽了肉和无酵饼。耶和华的使者也就不见了。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 32:30; 出埃及记 33:20; 申命记 5:26"> 基甸见他是耶和华的使者，就说：“哀哉！主耶和华啊，我不好了，因为我觌面看见耶和华的使者。”</span>
<span className="v" id="v23" data-v="23" data-xref="但以理书 10:19; 约翰福音 20:26; 创世记 43:23"> 耶和华对他说：“你放心，不要惧怕，你必不致死。”</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 22:14; 出埃及记 17:15; 士师记 8:32"> 于是基甸在那里为耶和华筑了一座坛，起名叫耶和华沙龙<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是“耶和华赐平安”的意思。">a</a></sup>。这坛在亚比以谢族的俄弗拉，直到如今。</span>
</div>
</div>

## 基甸奉命毁巴力祭坛

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及记 34:13; 士师记 3:7; 使徒行传 5:29"> 当那夜，耶和华吩咐基甸说：“你取你父亲的牛来，就是<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：和。">b</a></sup>那七岁的第二只牛，并拆毁你父亲为巴力所筑的坛，砍下坛旁的木偶。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多前书 14:40; 撒母耳记下 24:18; 哥林多前书 14:33"> 在这磐石<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文作：保障。">c</a></sup>上整整齐齐地为耶和华你的神筑一座坛，将第二只牛献为燔祭，用你所砍下的木偶做柴。”</span>
<span className="v" id="v27" data-v="27" data-xref="帖撒罗尼迦前书 2:4; 约翰福音 2:5; 申命记 4:1"> 基甸就从他仆人中挑了十个人，照着耶和华吩咐他的行了。他因怕父家和本城的人，不敢在白昼行这事，就在夜间行了。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 城里的人清早起来，见巴力的坛拆毁，坛旁的木偶砍下，第二只牛献在新筑的坛上，</span>
<span className="v" id="v29" data-v="29"> 就彼此说：“这事是谁做的呢？”他们访查之后，就说：“这是约阿施的儿子基甸做的。”</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 26:9; 腓立比书 3:6; 耶利米书 50:38"> 城里的人对约阿施说：“将你儿子交出来，好治死他，因为他拆毁了巴力的坛，砍下坛旁的木偶。”</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米书 10:11; 哥林多前书 8:4; 以弗所书 5:11"> 约阿施回答站着攻击他的众人说：“你们是为巴力争论吗？你们要救他吗？谁为他争论，趁早将谁治死。巴力若果是神，有人拆毁他的坛，让他为自己争论吧！”</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 12:11; 士师记 7:1; 撒母耳记下 11:21"> 所以当日人称基甸为耶路巴力，意思说：“他拆毁巴力的坛，让巴力与他争论。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约书亚记 17:16; 士师记 6:3; 罗马书 8:35–39"> 那时，米甸人、亚玛力人和东方人都聚集过河，在耶斯列平原安营。</span>
<span className="v" id="v34" data-v="34" data-xref="士师记 3:27; 历代志下 24:20; 士师记 3:10"> 耶和华的灵降在基甸身上，他就吹角，亚比以谢族都聚集跟随他。</span>
<span className="v" id="v35" data-v="35" data-xref="历代志下 30:6–12; 士师记 4:6"> 他打发人走遍玛拿西地，玛拿西人也聚集跟随他。又打发人去见亚设人、西布伦人、拿弗他利人，他们也都出来与他们会合。</span>
</div>
</div>

## 以羊毛干湿为证

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="士师记 6:14; 马太福音 16:1; 士师记 6:17–20"> 基甸对神说：“你若果照着所说的话，藉我手拯救以色列人，</span>
<span className="v" id="v37" data-v="37" data-xref="何西阿书 14:5; 马太福音 10:5–6; 马太福音 15:24"> 我就把一团羊毛放在禾场上，若单是羊毛上有露水，别的地方都是干的，我就知道你必照着所说的话，藉我手拯救以色列人。”</span>
<span className="v" id="v38" data-v="38" data-xref="以赛亚书 35:7"> 次日早晨基甸起来，见果然是这样，将羊毛挤一挤，从羊毛中拧出满盆的露水来。</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 18:32; 以赛亚书 50:2; 诗篇 107:33–35"> 基甸又对神说：“求你不要向我发怒，我再说这一次，让我将羊毛再试一次。但愿羊毛是干的，别的地方都有露水。”</span>
<span className="v" id="v40" data-v="40"> 这夜神也如此行，独羊毛上是干的，别的地方都有露水。</span>
</div>
</div>

<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 15:1; 启示录 19:1–3; 诗篇 18:1"> 那时，底波拉和亚比挪庵的儿子巴拉作歌，说：</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 5:9; 历代志下 17:16; 诗篇 110:3"> <span className="pl pl-1">“因为以色列中有军长率领，</span><br /><span className="pl pl-1">百姓也甘心牺牲自己，</span><br /><span className="pl pl-1">你们应当颂赞耶和华。</span><br /></span>

<div className="bp poetry">

<span className="v" id="v8" data-v="8" data-xref="申命记 32:16–17; 士师记 2:12; 士师记 2:17"> <span className="pl pl-1">以色列人选择新神，</span><br /><span className="pl pl-1">争战的事就临到城门，</span><br /><span className="pl pl-1">那时，以色列四万人中</span><br /><span className="pl pl-1">岂能见藤牌枪矛呢？</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="士师记 5:2; 哥林多后书 8:3–4; 哥林多后书 9:5"> <span className="pl pl-1">我心倾向以色列的首领，</span><br /><span className="pl pl-1">他们在民中甘心牺牲自己。</span><br /><span className="pl pl-1">你们应当颂赞耶和华！</span><br /></span>

<span className="v" id="v11" data-v="11" data-xref="弥迦书 6:5; 士师记 5:8; 撒母耳记上 12:7"> <span className="pl pl-1">在远离弓箭响声打水之处，</span><br /><span className="pl pl-1">人必述说耶和华公义的作为，</span><br /><span className="pl pl-1">就是他治理以色列公义的作为。</span><br /><span className="pl pl-1">那时耶和华的民下到城门。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="以弗所书 4:8; 诗篇 68:18; 诗篇 57:8"> <span className="pl pl-1">“底波拉啊，兴起，兴起！</span><br /><span className="pl pl-1">你当兴起，兴起，唱歌！</span><br /><span className="pl pl-1">亚比挪庵的儿子巴拉啊，你当奋兴，</span><br /><span className="pl pl-1">掳掠你的敌人！</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="启示录 2:26–27; 罗马书 8:37; 诗篇 75:7"> <span className="pl pl-1">那时有余剩的贵胄和百姓一同下来；</span><br /><span className="pl pl-1">耶和华降临，为我攻击勇士。</span><br /></span>

<span className="v" id="v17" data-v="17" data-xref="约书亚记 13:25; 约书亚记 19:24–31; 约书亚记 13:31"> <span className="pl pl-1">基列人安居在约旦河外。</span><br /><span className="pl pl-1">但人为何等在船上？</span><br /><span className="pl pl-1">亚设人在海口静坐，</span><br /><span className="pl pl-1">在港口安居。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="士师记 5:30; 士师记 1:27; 列王纪上 4:12"> <span className="pl pl-1">“君王都来争战。</span><br /><span className="pl pl-1">那时迦南诸王在米吉多水旁的他纳争战，</span><br /><span className="pl pl-1">却未得掳掠银钱。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="路加福音 1:42; 路加福音 1:28; 士师记 4:17"> <span className="pl pl-1">愿基尼人希百的妻雅亿比众妇人多得福气，</span><br /><span className="pl pl-1">比住帐篷的妇人更蒙福祉！</span><br /></span>

## 得救是本乎恩也因着信

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 2:13; 以弗所书 2:5–6; 歌罗西书 3:1–4"> 你们死在过犯罪恶之中，他叫你们活过来。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 6:12; 约翰一书 5:19; 以弗所书 2:3"> 那时你们在其中行事为人，随从今世的风俗，顺服空中掌权者的首领，就是现今在悖逆之子心中运行的邪灵。</span>
<span className="v" id="v3" data-v="3" data-xref="提多书 3:3; 以弗所书 4:22; 加拉太书 5:16–24"> 我们从前也都在他们中间，放纵肉体的私欲，随着肉体和心中所喜好的去行，本为可怒之子，和别人一样。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前书 1:3; 以弗所书 1:7; 诗篇 86:15"> 然而，神既有丰富的怜悯，因他爱我们的大爱，</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 3:24; 以弗所书 2:8; 罗马书 5:10"> 当我们死在过犯中的时候，便叫我们与基督一同活过来。你们得救是本乎恩。</span>
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 3:1–3; 以弗所书 1:3; 罗马书 6:4–5"> 他又叫我们与基督耶稣一同复活，一同坐在天上，</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前书 1:16–17; 提多书 3:4; 以弗所书 2:4"> 要将他极丰富的恩典，就是他在基督耶稣里向我们所施的恩慈，显明给后来的世代看。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 3:22–26; 以弗所书 2:5; 罗马书 4:16"> 你们得救是本乎恩，也因着信。这并不是出于自己，乃是神所赐的；</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太后书 1:9; 罗马书 11:6; 提多书 3:3–5"> 也不是出于行为，免得有人自夸。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比书 2:13; 歌罗西书 1:10; 希伯来书 13:21"> 我们原是他的工作，在基督耶稣里造成的，为要叫我们行善，就是神所预备叫我们行的。</span>
</div>
</div>

## 从前门徒不知道神

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="歌罗西书 2:11; 歌罗西书 2:13; 歌罗西书 3:11"> 所以你们应当记念：你们从前按肉体是外邦人，是称为没受割礼的，这名原是那些凭人手在肉身上称为受割礼之人所起的；</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 4:8; 歌罗西书 1:21; 耶利米书 31:31–34"> 那时你们与基督无关，在以色列国民以外，在所应许的诸约上是局外人，并且活在世上没有指望，没有神。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 2:39; 歌罗西书 1:20–22; 歌罗西书 1:13–14"> 你们从前远离神的人，如今却在基督耶稣里，靠着他的血，已经得亲近了。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 3:28; 歌罗西书 3:11; 歌罗西书 3:15"> 因他使我们和睦<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：因他是我们的和睦。">a</a></sup>，将两下合而为一，拆毁了中间隔断的墙，</span>
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 2:14; 加拉太书 3:10; 歌罗西书 1:21–22"> 而且以自己的身体废掉冤仇，就是那记在律法上的规条，为要将两下藉着自己造成一个新人，如此便成就了和睦。</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 1:20–22; 罗马书 5:10; 哥林多后书 5:18–21"> 既在十字架上灭了冤仇，便藉这十字架，使两下归为一体，与神和好了。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 57:19–21; 使徒行传 10:36; 罗马书 5:1"> 并且来传和平的福音给你们远处的人，也给那近处的人；</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 12:13; 以弗所书 3:12; 罗马书 5:2"> 因为我们两下藉着他被一个圣灵所感，得以进到父面前。</span>
</div>
</div>

## 如今是神家里的人

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="腓立比书 3:20; 约翰一书 3:1; 加拉太书 6:10"> 这样，你们不再做外人和客旅，是与圣徒同国，是神家里的人了。</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前书 2:4–5; 以赛亚书 28:16; 彼得前书 2:7–8"> 并且被建造在使徒和先知的根基上，有基督耶稣自己为房角石，</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 3:16–17; 哥林多前书 3:9; 哥林多后书 6:16"> 各<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：全。">b</a></sup>房靠他联络得合式，渐渐成为主的圣殿，</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:4–5; 哥林多前书 3:16; 约翰一书 4:16"> 你们也靠他同被建造，成为神藉着圣灵居住的所在。</span>
</div>

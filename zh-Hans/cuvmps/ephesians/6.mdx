## 父母和儿女的本分

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 3:20–25; 箴言 23:22; 箴言 6:20"> 你们做儿女的，要在主里听从父母，这是理所当然的。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 20:12; 申命记 27:16; 马太福音 15:4–6"> “要孝敬父母，使你得福，在世长寿。”这是第一条带应许的诫命。</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 3:21; 箴言 22:6; 箴言 29:15"> 你们做父亲的，不要惹儿女的气，只要照着主的教训和警戒养育他们。</span>
</div>
</div>

## 主人和仆人的本分

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="彼得前书 2:18–21; 提多书 2:9–10; 歌罗西书 3:17–24"> 你们做仆人的，要惧怕战兢，用诚实的心听从你们肉身的主人，好像听从基督一般。</span>
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 3:22–23; 帖撒罗尼迦前书 2:4; 加拉太书 1:10"> 不要只在眼前侍奉，像是讨人喜欢的，要像基督的仆人，从心里遵行神的旨意，</span>
<span className="v" id="v7" data-v="7" data-xref="歌罗西书 3:23; 以弗所书 6:5–6; 哥林多前书 10:31"> 甘心侍奉，好像服侍主，不像服侍人。</span>
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 3:24; 路加福音 14:14; 箴言 11:18"> 因为晓得各人所行的善事，不论是为奴的，是自主的，都必按所行的得主的赏赐。</span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 3:25–1; 使徒行传 10:34; 罗马书 2:11"> 你们做主人的，待仆人也是一理，不要威吓他们。因为知道，他们和你们同有一位主在天上，他并不偏待人。</span>
</div>
</div>

## 须穿戴神所赐的全副军装

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="腓立比书 4:13; 以赛亚书 40:31; 约书亚记 1:9"> 我还有末了的话，你们要靠着主，倚赖他的大能大力做刚强的人。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 10:4; 罗马书 13:12; 以弗所书 6:13"> 要穿戴神所赐的全副军装，就能抵挡魔鬼的诡计。</span>
<span className="v" id="v12" data-v="12" data-xref="歌罗西书 1:13; 哥林多后书 4:4; 以弗所书 2:2"> 因我们并不是与属血气的争战，乃是与那些执政的、掌权的、管辖这幽暗世界的，以及天空属灵气的恶魔争战<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="两“争战”原文都作“摔跤”。">a</a></sup>。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 10:4; 路加福音 21:36; 以弗所书 6:11–17"> 所以，要拿起神所赐的全副军装，好在磨难的日子抵挡仇敌；并且成就了一切，还能站立得住。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 59:17; 帖撒罗尼迦前书 5:8; 以赛亚书 11:5"> 所以要站稳了，用真理当做带子束腰，用公义当做护心镜遮胸，</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 52:7; 罗马书 10:15; 哥林多后书 5:18–21"> 又用平安的福音当做预备走路的鞋穿在脚上。</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前书 5:8–9; 约翰一书 5:4–5; 箴言 18:10"> 此外，又拿着信德当做藤牌，可以灭尽那恶者一切的火箭；</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 4:12; 以赛亚书 59:17; 启示录 19:15"> 并戴上救恩的头盔，拿着圣灵的宝剑，就是神的道。</span>
</div>
</div>

## 当随时警醒祷告

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 5:17; 歌罗西书 4:2; 腓立比书 4:6"> 靠着圣灵，随时多方祷告祈求，并要在此警醒不倦，为众圣徒祈求；</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 4:3; 使徒行传 4:29; 帖撒罗尼迦后书 3:1"> 也为我祈求，使我得着口才，能以放胆开口讲明福音的奥秘——</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 5:20; 歌罗西书 4:4; 提摩太后书 2:9"> 我为这福音的奥秘做了戴锁链的使者——并使我照着当尽的本分放胆讲论。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 20:4; 提摩太后书 4:12; 提多书 3:12"> 今有所亲爱、忠心侍奉主的兄弟推基古，他要把我的事情并我的景况如何全告诉你们，叫你们知道。</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比书 2:25; 歌罗西书 4:7–8; 帖撒罗尼迦后书 2:17"> 我特意打发他到你们那里去，好叫你们知道我们的光景，又叫他安慰你们的心。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="加拉太书 6:16; 加拉太书 5:6; 彼得前书 5:14"> 愿平安、仁爱、信心从父神和主耶稣基督归于弟兄们！</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 22:37; 哥林多后书 8:12; 马太福音 6:13"> 并愿所有诚心爱我们主耶稣基督的人都蒙恩惠！</span>
</div>
</div>

</div>

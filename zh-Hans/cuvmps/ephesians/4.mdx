## 劝门徒合而为一

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 1:10; 腓立比书 1:27; 帖撒罗尼迦前书 2:12"> 我为主被囚的劝你们：既然蒙召，行事为人就当与蒙召的恩相称，</span>
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 3:12–13; 哥林多前书 13:7; 哥林多前书 13:4–5"> 凡事谦虚、温柔、忍耐，用爱心互相宽容，</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 1:10; 歌罗西书 3:13–15; 哥林多前书 12:12–13"> 用和平彼此联络，竭力保守圣灵所赐合而为一的心。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 2:18; 罗马书 12:4–5; 哥林多前书 12:4–13"> 身体只有一个，圣灵只有一个，正如你们蒙召同有一个指望；</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 8:6; 哥林多前书 12:13; 彼得前书 3:21"> 一主，一信，一洗，</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 11:36; 玛拉基书 2:10; 哥林多前书 8:6"> 一神，就是众人的父，超乎众人之上，贯乎众人之中，也住在众人之内。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前书 4:10; 罗马书 12:3; 哥林多前书 12:7–11"> 我们各人蒙恩，都是照基督所量给各人的恩赐。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 68:18; 歌罗西书 2:15; 撒母耳记上 30:26"> 所以经上说：<br /><span className="pl pl-1">“他升上高天的时候，掳掠了仇敌，</span><br /><span className="pl pl-1">将各样的恩赐赏给人。”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约翰福音 3:13; 马太福音 12:40; 箴言 30:4"> （既说升上，岂不是先降在地下吗？</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 7:26; 希伯来书 4:14; 以弗所书 1:20–23"> 那降下的，就是远升诸天之上要充满万有的。）</span>
</div>
</div>

## 满有基督长成的身量

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米书 3:15; 哥林多前书 12:28–29; 以弗所书 2:20"> 他所赐的有使徒，有先知，有传福音的，有牧师和教师，</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦前书 5:11–14; 以弗所书 4:16; 哥林多前书 12:27"> 为要成全圣徒，各尽其职，建立基督的身体，</span>
<span className="v" id="v13" data-v="13" data-xref="歌罗西书 1:28; 约翰福音 17:21; 以弗所书 4:5"> 直等到我们众人在真道上同归于一，认识神的儿子，得以长大成人，满有基督长成的身量，</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 13:9; 罗马书 16:17–18; 哥林多前书 14:20"> 使我们不再做小孩子，中了人的诡计和欺骗的法术，被一切异教之风摇动飘来飘去，就随从各样的异端，</span>
<span className="v" id="v15" data-v="15" data-xref="约翰一书 3:18; 以弗所书 4:25; 撒迦利亚书 8:16"> 唯用爱心说诚实话，凡事长进，连于元首基督。</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 2:19; 约翰福音 15:5; 歌罗西书 2:2"> 全身都靠他联络得合式，百节各按各职，照着各体的功用彼此相助，便叫身体渐渐增长，在爱中建立自己。</span>
</div>
</div>

## 凡事效法基督

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 1:21; 彼得前书 4:3–4; 帖撒罗尼迦前书 4:1–2"> 所以我说，且在主里确实地说：你们行事不要再像外邦人，存虚妄的心行事。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 13:15; 以弗所书 2:12; 罗马书 1:21–23"> 他们心地昏昧，与神所赐的生命隔绝了，都因自己无知，心里刚硬；</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 3:5; 罗马书 1:24–26; 提摩太前书 4:2"> 良心既然丧尽，就放纵私欲，贪行种种的污秽。</span>
</div>
</div>

## 穿上新人

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="提多书 2:11–14; 约翰福音 6:45; 马太福音 11:29"> 你们学了基督，却不是这样。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 5:20; 以弗所书 1:13; 希伯来书 3:7–8"> 如果你们听过他的道，领了他的教，学了他的真理，</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 6:6; 希伯来书 12:1; 雅各书 1:21"> 就要脱去你们从前行为上的旧人，这旧人是因私欲的迷惑渐渐变坏的；</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 12:2; 罗马书 8:6; 诗篇 51:10"> 又要将你们的心志改换一新，</span>
<span className="v" id="v24" data-v="24" data-xref="歌罗西书 3:10–14; 哥林多后书 5:17; 以弗所书 2:10"> 并且穿上新人，这新人是照着神的形像造的，有真理的仁义和圣洁。</span>
</div>
</div>

## 不可给魔鬼留地步

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="歌罗西书 3:9; 撒迦利亚书 8:16; 箴言 12:22"> 所以你们要弃绝谎言，各人与邻舍说实话，因为我们是互相为肢体。</span>
<span className="v" id="v26" data-v="26" data-xref="雅各书 1:19; 诗篇 4:4; 诗篇 37:8"> 生气却不要犯罪，不可含怒到日落，</span>
<span className="v" id="v27" data-v="27" data-xref="雅各书 4:7; 彼得前书 5:8; 以弗所书 6:16"> 也不可给魔鬼留地步。</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太前书 6:18; 帖撒罗尼迦前书 4:11–12; 加拉太书 6:10"> 从前偷窃的，不要再偷，总要劳力，亲手做正经事，就可有余，分给那缺少的人。</span>
</div>
</div>

## 不要叫圣灵担忧

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="歌罗西书 4:6; 帖撒罗尼迦前书 5:11; 传道书 10:12"> 污秽的言语一句不可出口，只要随事说造就人的好话，叫听见的人得益处。</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒罗尼迦前书 5:19; 以赛亚书 63:10; 以弗所书 1:13–14"> 不要叫神的圣灵担忧，你们原是受了他的印记，等候得赎的日子来到。</span>
<span className="v" id="v31" data-v="31" data-xref="歌罗西书 3:8; 传道书 7:9; 提多书 3:2–3"> 一切苦毒、恼恨、愤怒、嚷闹、毁谤，并一切的恶毒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：阴毒。">a</a></sup>，都当从你们中间除掉；</span>
<span className="v" id="v32" data-v="32" data-xref="歌罗西书 3:12–13; 马太福音 6:14–15; 马可福音 11:25"> 并要以恩慈相待，存怜悯的心，彼此饶恕，正如神在基督里饶恕了你们一样。</span>
</div>
</div>

## 律法是将来美事的影儿

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 8:5; 希伯来书 9:11; 歌罗西书 2:17"> 律法既是将来美事的影儿，不是本物的真像，总不能藉着每年常献一样的祭物，叫那近前来的人得以完全。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 43:25; 弥迦书 7:19; 诗篇 103:12"> 若不然，献祭的事岂不早已止住了吗？因为礼拜的人，良心既被洁净，就不再觉得有罪了。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 9:7; 出埃及记 30:10; 利未记 23:27–28"> 但这些祭物是叫人每年想起罪来，</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 10:11; 以赛亚书 1:11–15; 弥迦书 6:6–8"> 因为公牛和山羊的血断不能除罪。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 40:6–8; 以赛亚书 1:11; 以赛亚书 7:14"> 所以，基督到世上来的时候就说：<br /><span className="pl pl-1">“神啊，祭物和礼物是你不愿意的，</span><br /><span className="pl pl-1">你曾给我预备了身体。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="玛拉基书 1:10; 马太福音 3:17; 诗篇 147:11"> <span className="pl pl-1">燔祭和赎罪祭是你不喜欢的。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 40:7–8; 约翰福音 4:34; 约翰福音 6:38"> <span className="pl pl-1">那时我说：‘神啊，我来了，</span><br /><span className="pl pl-1">为要照你的旨意行，</span><br /><span className="pl pl-1">我的事在经卷上已经记载了。’”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="希伯来书 10:5; 马可福音 12:33"> 以上说：“祭物和礼物，燔祭和赎罪祭，是你不愿意的，也是你不喜欢的。”这都是按着律法献的。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 7:18–19; 希伯来书 12:27–28; 希伯来书 10:7"> 后又说：“我来了为要照你的旨意行。”可见他是除去在先的，为要立定在后的。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 10:14; 希伯来书 10:12; 哥林多前书 6:11"> 我们凭这旨意，靠耶稣基督只一次献上他的身体，就得以成圣。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 5:1; 民数记 28:3; 希伯来书 10:4"> 凡祭司天天站着侍奉神，屡次献上一样的祭物，这祭物永不能除罪。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 1:3; 歌罗西书 3:1; 罗马书 8:34"> 但基督献了一次永远的赎罪祭，就在神的右边坐下了，</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 1:13; 诗篇 110:1; 路加福音 20:43"> 从此等候他仇敌成了他的脚凳。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 7:25; 希伯来书 10:1; 希伯来书 9:14"> 因为他一次献祭，便叫那得以成圣的人永远完全。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 3:7; 启示录 2:11; 启示录 3:6"> 圣灵也对我们作见证，因为他既已说过：</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 31:33–34; 希伯来书 8:8–12; 罗马书 11:27"> <span className="pl pl-1">“主说：‘那些日子以后，</span><br /><span className="pl pl-1">我与他们所立的约乃是这样：</span><br /><span className="pl pl-1">我要将我的律法写在他们心上，</span><br /><span className="pl pl-1">又要放在他们的里面’”，</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="耶利米书 31:34; 希伯来书 8:12"> 以后就说：<br /><span className="pl pl-1">“我不再记念他们的罪愆和他们的过犯。”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="希伯来书 10:2; 希伯来书 10:14"> 这些罪过既已赦免，就不用再为罪献祭了。</span>
</div>
</div>

## 当存诚心和充足的信心来到神面前

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以弗所书 2:18; 希伯来书 9:12; 希伯来书 4:16"> 弟兄们，我们既因耶稣的血得以坦然进入至圣所，</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 14:6; 约翰福音 10:9; 希伯来书 9:3"> 是藉着他给我们开了一条又新又活的路，从幔子经过，这幔子就是他的身体；</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 2:17; 希伯来书 4:14–16; 希伯来书 8:1"> 又有一位大祭司治理神的家，</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 36:25; 约翰福音 3:5; 以弗所书 5:26"> 并我们心中天良的亏欠已经洒去，身体用清水洗净了，就当存着诚心和充足的信心来到神面前。</span>
<span className="v" id="v23" data-v="23" data-xref="帖撒罗尼迦前书 5:24; 哥林多前书 1:9; 帖撒罗尼迦后书 3:3"> 也要坚守我们所承认的指望，不致摇动，因为那应许我们的是信实的。</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦前书 5:11; 约翰一书 3:18; 希伯来书 13:1"> 又要彼此相顾，激发爱心，勉励行善。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 2:42; 帖撒罗尼迦前书 5:11; 马太福音 18:20"> 你们不可停止聚会，好像那些停止惯了的人，倒要彼此劝勉；既知道<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：看见。">a</a></sup>那日子临近，就更当如此。</span>
</div>
</div>

## 警戒故意犯罪

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="彼得后书 2:20–22; 希伯来书 6:4–6; 约翰福音 9:41"> 因为我们得知真道以后，若故意犯罪，赎罪的祭就再没有了，</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 26:11; 希伯来书 2:3; 西番雅书 1:18"> 唯有战惧等候审判和那烧灭众敌人的烈火。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 2:2; 申命记 19:15; 申命记 17:2–13"> 人干犯摩西的律法，凭两三个见证人，尚且不得怜恤而死；</span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 6:6; 以弗所书 4:30; 以赛亚书 63:10"> 何况人践踏神的儿子，将那使他成圣之约的血当做平常，又亵慢施恩的圣灵，你们想，他要受的刑罚该怎样加重呢！</span>
<span className="v" id="v30" data-v="30" data-xref="申命记 32:35–36; 罗马书 12:19; 那鸿书 1:2"> 因为我们知道谁说“申冤在我，我必报应”，又说“主要审判他的百姓”。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 10:28; 路加福音 12:5; 希伯来书 12:29"> 落在永生神的手里，真是可怕的！</span>
</div>
</div>

## 义人必因信得生

<div className="bt">
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="希伯来书 6:4; 希伯来书 12:4; 提摩太后书 2:3–13"> 你们要追念往日蒙了光照以后，所忍受大争战的各样苦难。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 4:9; 腓立比书 4:14; 希伯来书 11:36"> 一面被毁谤，遭患难，成了戏景叫众人观看；一面陪伴那些受这样苦难的人。</span>
<span className="v" id="v34" data-v="34" data-xref="彼得前书 1:4; 提摩太后书 1:16; 马太福音 5:11–12"> 因为你们体恤了那些被捆锁的人，并且你们的家业被人抢去，也甘心忍受，知道自己有更美、长存的家业。</span>
<span className="v" id="v35" data-v="35" data-xref="哥林多前书 15:58; 加拉太书 6:8–10; 希伯来书 3:6"> 所以，你们不可丢弃勇敢的心，存这样的心必得大赏赐。</span>
<span className="v" id="v36" data-v="36" data-xref="希伯来书 12:1; 诗篇 37:7; 雅各书 5:7–11"> 你们必须忍耐，使你们行完了神的旨意，就可以得着所应许的。</span>
<span className="v" id="v37" data-v="37" data-xref="雅各书 5:7–9; 哈巴谷书 2:3–4; 路加福音 18:8"> <span className="pl pl-1">“因为还有一点点时候，</span><br /><span className="pl pl-1">那要来的就来，并不迟延。</span><br /></span>
<span className="v" id="v38" data-v="38" data-xref="加拉太书 3:11; 哈巴谷书 2:4; 罗马书 1:17"> <span className="pl pl-1">只是义人</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“义人”有古卷作“我的义人”。">b</a></sup><br /><span className="pl pl-1">必因信得生；</span><br /><span className="pl pl-1">他若退后，我心里就不喜欢他。”</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="约翰一书 5:5; 彼得前书 1:5; 马可福音 16:16"> 我们却不是退后入沉沦的那等人，乃是有信心以致灵魂得救的人。</span>
</div>
</div>

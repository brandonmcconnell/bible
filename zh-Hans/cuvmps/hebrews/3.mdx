## 耶稣比摩西更配得荣耀

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太后书 1:9; 腓立比书 3:14; 希伯来书 4:14–15"> 同蒙天召的圣洁弟兄啊，你们应当思想我们所认为使者、为大祭司的耶稣。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 12:7; 提摩太前书 3:15; 以弗所书 2:22"> 他为那设立他的尽忠，如同摩西在神的全家尽忠一样。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 3:9; 彼得前书 2:5–7; 撒迦利亚书 6:12–13"> 他比摩西算是更配多得荣耀，好像建造房屋的比房屋更尊荣。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 3:3; 希伯来书 1:2; 以斯帖记 2:10"> 因为房屋都必有人建造，但建造万物的就是神。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 12:7; 希伯来书 3:2; 出埃及记 14:31"> 摩西为仆人，在神的全家诚然尽忠，为要证明将来必传说的事；</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 6:16; 哥林多前书 3:16; 希伯来书 10:35"> 但基督为儿子，治理神的家。我们若将可夸的盼望和胆量坚持到底，便是他的家了。</span>
</div>
</div>

## 当警戒硬心

<div className="bt">
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="诗篇 95:7–11; 希伯来书 3:15; 以赛亚书 55:3"> 圣灵有话说：<br /><span className="pl pl-1">“你们今日若听他的话，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 28:14; 出埃及记 17:7; 撒迦利亚书 7:11–12"> <span className="pl pl-1">就不可硬着心，</span><br /><span className="pl pl-1">像在旷野惹他发怒、</span><br /><span className="pl pl-1">试探他的时候一样。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 7:36; 申命记 4:9; 出埃及记 19:4"> <span className="pl pl-1">在那里，你们的祖宗试我探我，</span><br /><span className="pl pl-1">并且观看我的作为有四十年之久。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 95:10; 帖撒罗尼迦后书 2:10–12; 诗篇 67:2"> <span className="pl pl-1">所以，我厌烦那世代的人，说：</span><br /><span className="pl pl-1">‘他们心里常常迷糊，</span><br /><span className="pl pl-1">竟不晓得我的作为。’</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="申命记 1:34–35; 希伯来书 4:3; 民数记 32:10–13"> <span className="pl pl-1">我就在怒中起誓说：</span><br /><span className="pl pl-1">‘他们断不可进入我的安息。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米书 17:5; 耶利米书 7:24; 耶利米书 17:9"> 弟兄们，你们要谨慎，免得你们中间或有人存着不信的恶心，把永生神离弃了。</span>
<span className="v" id="v13" data-v="13" data-xref="帖撒罗尼迦前书 5:11; 希伯来书 10:24–25; 提摩太后书 4:2"> 总要趁着还有今日，天天彼此相劝，免得你们中间有人被罪迷惑，心里就刚硬了。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 3:6; 希伯来书 6:11; 希伯来书 12:10"> 我们若将起初确实的信心坚持到底，就在基督里有份了。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 3:7–8; 诗篇 95:7; 希伯来书 10:38"> 经上说：“你们今日若听他的话，就不可硬着心，像惹他发怒的日子一样。”</span>
</div>
</div>

## 不信之人不能享受安息

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数记 14:2; 民数记 14:30; 民数记 26:65"> 那时听见他话惹他发怒的是谁呢？岂不是跟着摩西从埃及出来的众人吗？</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 14:29; 民数记 26:64–65; 民数记 14:32–33"> 神四十年之久又厌烦谁呢？岂不是那些犯罪尸首倒在旷野的人吗？</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 14:30; 希伯来书 4:6; 申命记 1:34–35"> 又向谁起誓，不容他们进入他的安息呢？岂不是向那些不信从的人吗？</span>
<span className="v" id="v19" data-v="19" data-xref="犹大书 1:5; 约翰福音 3:36; 马可福音 16:16"> 这样看来，他们不能进入安息是因为不信的缘故了。</span>
</div>
</div>

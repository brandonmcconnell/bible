## 喜乐福祉亦属虚空

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:19; 传道书 8:15; 雅各书 5:5"> 我心里说：“来吧，我以喜乐试试你，你好享福。”谁知，这也是虚空。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 14:13; 传道书 7:2–6; 彼得前书 4:2–4"> 我指喜笑说：“这是狂妄”，论喜乐说：“有何功效呢？”</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 20:1; 传道书 1:17; 箴言 31:4–5"> 我心里察究如何用酒使我肉体舒畅，我心却仍以智慧引导我；又如何持住愚昧，等我看明世人，在天下一生当行何事为美。</span>
</div>
</div>

## 房舍田园仍属虚空

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪上 7:1–12; 历代志下 8:11; 历代志下 26:10"> 我为自己动大工程，建造房屋，栽种葡萄园，</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 17:27–29; 雅歌 4:12–1; 耶利米书 39:4"> 修造园囿，在其中栽种各样果木树，</span>
<span className="v" id="v6" data-v="6" data-xref="尼希米记 2:14; 诗篇 1:3; 耶利米书 17:8"> 挖造水池，用以浇灌嫩小的树木。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 3:4; 创世记 15:3; 列王纪上 4:23"> 我买了仆婢，也有生在家中的仆婢；又有许多牛群羊群，胜过以前在耶路撒冷众人所有的。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 10:10; 列王纪上 9:28; 撒母耳记下 19:35"> 我又为自己积蓄金银和君王的财宝，并各省的财宝；又得唱歌的男女和世人所喜爱的物，并许多的妃嫔。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 29:25; 传道书 1:16; 列王纪上 10:23"> 这样，我就日见昌盛，胜过以前在耶路撒冷的众人。我的智慧仍然存留。</span>
<span className="v" id="v10" data-v="10" data-xref="传道书 9:9; 传道书 5:18; 传道书 3:22"> 凡我眼所求的，我没有留下不给它的；我心所乐的，我没有禁止不享受的。因我的心为我一切所劳碌的快乐，这就是我从劳碌中所得的份。</span>
<span className="v" id="v11" data-v="11" data-xref="传道书 1:14; 约翰一书 2:16–17; 传道书 1:3"> 后来我察看我手所经营的一切事和我劳碌所成的功，谁知都是虚空，都是捕风，在日光之下毫无益处。</span>
</div>
</div>

## 智慧终属虚空

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="传道书 1:17; 传道书 7:25; 传道书 1:9–10"> 我转念观看智慧、狂妄和愚昧。在王以后而来的人还能做什么呢？也不过行早先所行的就是了。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 5:8; 传道书 7:11–12; 马太福音 6:23"> 我便看出智慧胜过愚昧，如同光明胜过黑暗。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 49:10; 箴言 17:24; 传道书 9:11"> 智慧人的眼目光明<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“光明”原文作“在他头上”。">a</a></sup>，愚昧人在黑暗里行，我却看明有一件事，这两等人都必遇见。</span>
<span className="v" id="v15" data-v="15" data-xref="传道书 6:8; 传道书 1:14; 传道书 1:2"> 我就心里说：“愚昧人所遇见的，我也必遇见，我为何更有智慧呢？”我心里说：“这也是虚空。”</span>
<span className="v" id="v16" data-v="16" data-xref="传道书 1:11; 传道书 9:5; 诗篇 88:12"> 智慧人和愚昧人一样，永远无人记念，因为日后都被忘记。可叹智慧人死亡，与愚昧人无异！</span>
<span className="v" id="v17" data-v="17" data-xref="传道书 2:11; 约拿书 4:8; 传道书 4:2"> 我所以恨恶生命，因为在日光之下所行的事我都以为烦恼，都是虚空，都是捕风。</span>
</div>
</div>

## 劳碌所得不知遗谁斯亦虚空

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="诗篇 39:6; 诗篇 49:10; 路加福音 16:27–28"> 我恨恶一切的劳碌，就是我在日光之下的劳碌，因为我得来的必留给我以后的人。</span>
<span className="v" id="v19" data-v="19" data-xref="雅各书 3:17; 传道书 3:22; 传道书 9:13"> 那人是智慧是愚昧，谁能知道？他竟要管理我劳碌所得的，就是我在日光之下用智慧所得的。这也是虚空。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 43:14; 约伯记 17:11–15; 哥林多后书 1:8–10"> 故此，我转想我在日光之下所劳碌的一切工作，心便绝望。</span>
<span className="v" id="v21" data-v="21" data-xref="传道书 2:17–18; 历代志下 31:20–21; 历代志下 34:2"> 因为有人用智慧、知识、灵巧所劳碌得来的，却要留给未曾劳碌的人为份。这也是虚空，也是大患。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 127:2; 传道书 1:3; 腓立比书 4:6"> 人在日光之下劳碌、累心，在他一切的劳碌上得着什么呢？</span>
<span className="v" id="v23" data-v="23" data-xref="约伯记 14:1; 约伯记 5:7; 诗篇 6:6–7"> 因为他日日忧虑，他的劳苦成为愁烦，连夜间心也不安。这也是虚空。</span>
</div>
</div>

## 神所悦者赐以智慧

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="传道书 3:22; 传道书 8:15; 提摩太前书 6:17"> 人莫强如吃喝，且在劳碌中享福，我看这也是出于神的手。</span>
<span className="v" id="v25" data-v="25" data-xref="传道书 2:1–12; 列王纪上 4:21–24"> 论到吃用享福，谁能胜过我呢？</span>
<span className="v" id="v26" data-v="26" data-xref="箴言 13:22; 约伯记 27:16–17; 箴言 28:8"> 神喜悦谁，就给谁智慧、知识和喜乐，唯有罪人，神使他劳苦，叫他将所收聚的、所堆积的归给神所喜悦的人。这也是虚空，也是捕风。</span>
</div>
</div>

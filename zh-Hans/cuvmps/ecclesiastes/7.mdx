## 美名愈于香膏

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="启示录 14:13; 箴言 22:1; 传道书 4:2"> <span className="pl pl-1">名誉强如美好的膏油，</span><br /><span className="pl pl-1">人死的日子胜过人生的日子。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 90:12; 申命记 32:29; 希伯来书 9:27"> <span className="pl pl-1">往遭丧的家去</span><br /><span className="pl pl-1">强如往宴乐的家去，</span><br /><span className="pl pl-1">因为死是众人的结局，</span><br /><span className="pl pl-1">活人也必将这事放在心上。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 7:9–11; 罗马书 5:3–4; 雅各书 4:8–10"> <span className="pl pl-1">忧愁强如喜笑，</span><br /><span className="pl pl-1">因为面带愁容终必使心喜乐。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 8:14–16; 撒母耳记上 25:36; 路加福音 7:12–13"> <span className="pl pl-1">智慧人的心在遭丧之家，</span><br /><span className="pl pl-1">愚昧人的心在快乐之家。</span></span>
</div>
</div>

## 受智者责胜于听愚者歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="箴言 15:31–32; 诗篇 141:5; 启示录 3:19"> <span className="pl pl-1">听智慧人的责备，</span><br /><span className="pl pl-1">强如听愚昧人的歌唱。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 58:9; 诗篇 118:12; 传道书 2:2"> <span className="pl pl-1">愚昧人的笑声</span><br /><span className="pl pl-1">好像锅下烧荆棘的爆声。</span><br /><span className="pl pl-1">这也是虚空。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="申命记 16:19; 出埃及记 23:8; 箴言 17:23"> <span className="pl pl-1">勒索使智慧人变为愚妄，</span><br /><span className="pl pl-1">贿赂能败坏人的慧心。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="希伯来书 10:36; 箴言 14:29; 诗篇 126:5–6"> <span className="pl pl-1">事情的终局强如事情的起头，</span><br /><span className="pl pl-1">存心忍耐的胜过居心骄傲的。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="雅各书 1:19; 箴言 14:17; 以弗所书 4:26–27"> <span className="pl pl-1">你不要心里急躁恼怒，</span><br /><span className="pl pl-1">因为恼怒存在愚昧人的怀中。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="士师记 6:13; 诗篇 14:2–3; 创世记 6:11–12"> <span className="pl pl-1">不要说：</span><br /><span className="pl pl-1">“先前的日子强过如今的日子</span><br /><span className="pl pl-1">是什么缘故呢？”</span><br /><span className="pl pl-1">你这样问，不是出于智慧。</span></span>
</div>
</div>

## 智慧美于产业

<div className="bt">
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="传道书 11:7; 提摩太前书 6:17–19; 传道书 2:13"> <span className="pl pl-1">智慧和产业并好，</span><br /><span className="pl pl-1">而且见天日的人得智慧更为有益。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 8:35; 箴言 2:7; 箴言 3:18"> <span className="pl pl-1">因为智慧护庇人</span><br /><span className="pl pl-1">好像银钱护庇人一样，</span><br /><span className="pl pl-1">唯独智慧能保全智慧人的生命，</span><br /><span className="pl pl-1">这就是知识的益处。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="传道书 1:15; 约伯记 12:14; 诗篇 107:43"> <span className="pl pl-1">你要察看神的作为，</span><br /><span className="pl pl-1">因神使为曲的，谁能变为直呢？</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="传道书 3:4; 传道书 3:22; 传道书 12:13"> 遇亨通的日子你当喜乐，遭患难的日子你当思想，因为神使这两样并列，为的是叫人查不出身后有什么事。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="传道书 8:12–14; 传道书 6:12; 诗篇 73:3–13"> 有义人行义反致灭亡，有恶人行恶倒享长寿，这都是我在虚度之日中所见过的。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 12:3; 箴言 25:16; 歌罗西书 2:18"> 不要行义过分，也不要过于自逞智慧，何必自取败亡呢？</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 10:27; 诗篇 55:23; 约伯记 22:16"> 不要行恶过分，也不要为人愚昧，何必不到期而死呢？</span>
<span className="v" id="v18" data-v="18" data-xref="传道书 12:13; 玛拉基书 4:2; 传道书 11:6"> 你持守这个为美，那个也不要松手，因为敬畏神的人必从这两样出来。</span>
</div>
</div>

## 义人难免无罪

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="箴言 21:22; 歌罗西书 1:9–11; 箴言 24:5"> 智慧使有智慧的人比城中十个官长更有能力。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 3:23; 以赛亚书 53:6; 约翰一书 1:8–10"> 时常行善而不犯罪的义人，世上实在没有。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 30:10; 以赛亚书 29:21; 撒母耳记下 16:10"> 人所说的一切话，你不要放在心上，恐怕听见你的仆人咒诅你。</span>
<span className="v" id="v22" data-v="22" data-xref="雅各书 3:9; 马太福音 18:32–35; 约翰福音 8:7–9"> 因为你心里知道，自己也曾屡次咒诅别人。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="罗马书 1:22; 创世记 3:5; 哥林多前书 1:20"> 我曾用智慧试验这一切事，我说要得智慧，智慧却离我远。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 11:33; 提摩太前书 6:16; 以赛亚书 55:8–9"> 万事之理离我甚远，而且最深，谁能测透呢？</span>
<span className="v" id="v25" data-v="25" data-xref="传道书 10:13; 约书亚记 7:13; 传道书 2:20"> 我转念，一心要知道，要考察，要寻求智慧和万事的理由，又要知道邪恶为愚昧，愚昧为狂妄。</span>
<span className="v" id="v26" data-v="26" data-xref="箴言 22:14; 箴言 5:3–5; 箴言 2:18–19"> 我得知有等妇人比死还苦，她的心是网罗，手是锁链，凡蒙神喜悦的人必能躲避她，有罪的人却被她缠住了。</span>
<span className="v" id="v27" data-v="27" data-xref="传道书 12:8–10; 传道书 1:1–2"> 传道者说：看哪，一千男子中，我找到一个正直人，但众女子中没有找到一个。我将这事一一比较，要寻求其理，我心仍要寻找，却未曾找到。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 4:22; 马可福音 7:8–9; 提多书 3:3"> 我所找到的只有一件，就是神造人原是正直，但他们寻出许多巧计。</span>
</div>

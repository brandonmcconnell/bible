## 于神前勿造次多言

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="雅各书 1:19; 希伯来书 12:28–29; 箴言 15:8"> 你到神的殿要谨慎脚步，因为近前听胜过愚昧人献祭<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：胜过献愚昧人的祭。">a</a></sup>，他们本不知道所做的是恶。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 6:7; 箴言 10:19; 以赛亚书 55:9"> 你在神面前不可冒失开口，也不可心急发言。因为神在天上，你在地下，所以你的言语要寡少。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 15:2; 箴言 10:19; 传道书 10:12–14"> 事务多就令人做梦，言语多就显出愚昧。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 30:2; 申命记 23:21–23; 诗篇 76:11"> 你向神许愿，偿还不可迟延，因他不喜悦愚昧人。所以你许的愿应当偿还，</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 5:4; 申命记 23:22; 箴言 20:25"> 你许愿不还，不如不许。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 1:26; 约翰二书 1:8; 雅各书 3:2"> 不可任你的口使肉体犯罪，也不可在祭司<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：使者。">b</a></sup>面前说是错许了。为何使神因你的声音发怒，败坏你手所做的呢？</span>
<span className="v" id="v7" data-v="7" data-xref="传道书 12:13; 马太福音 12:36; 传道书 8:12"> 多梦和多言，其中多有虚幻，你只要敬畏神。</span>
</div>
</div>

## 金银难餍人心货财亦无所益

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="诗篇 12:5; 传道书 4:1; 传道书 3:16"> 你若在一省之中见穷人受欺压，并夺去公义、公平的事，不要因此诧异。因有一位高过居高位的鉴察，在他们以上还有更高的。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 4:7–23; 诗篇 115:16; 创世记 1:29–30"> 况且地的益处归众人，就是君王也受田地的供应。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 6:10; 马太福音 6:24; 路加福音 12:15"> 贪爱银子的不因得银子知足，贪爱丰富的也不因得利益知足。这也是虚空。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰一书 2:16; 哈巴谷书 2:13; 诗篇 119:36–37"> 货物增添，吃的人也增添，物主得什么益处呢？不过眼看而已。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 3:24; 诗篇 4:8; 耶利米书 31:26"> 劳碌的人不拘吃多吃少，睡得香甜；富足人的丰满，却不容他睡觉。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="传道书 6:1–2; 路加福音 18:22–23; 创世记 19:14"> 我见日光之下有一宗大祸患，就是财主积存资财，反害自己。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 6:19–20; 哈该书 2:16–17; 箴言 23:5"> 因遭遇祸患，这些资财就消灭，那人若生了儿子，手里也一无所有。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 49:17; 约伯记 1:21; 提摩太前书 6:7"> 他怎样从母胎赤身而来，也必照样赤身而去，他所劳碌得来的，手中分毫不能带去。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 11:29; 传道书 1:3; 约翰福音 6:27"> 他来的情形怎样，他去的情形也怎样，这也是一宗大祸患。他为风劳碌，有什么益处呢？</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 127:2; 以西结书 4:16–17; 诗篇 90:7–11"> 并且他终身在黑暗中吃喝，多有烦恼，又有病患呕气。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="传道书 2:24; 传道书 3:12–13; 传道书 3:22"> 我所见为善为美的，就是人在神赐他一生的日子吃喝，享受日光之下劳碌得来的好处，因为这是他的份。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 8:18; 传道书 3:13; 传道书 6:2"> 神赐人资财丰富，使他能以吃用，能取自己的份，在他劳碌中喜乐，这乃是神的恩赐。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 65:21–24; 以赛亚书 65:13–14; 诗篇 37:16"> 他不多思念自己一生的年日，因为神应他的心使他喜乐。</span>
</div>
</div>

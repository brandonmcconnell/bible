## 路得有求于波阿斯

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路得记 1:9; 提摩太前书 5:8; 提摩太前书 5:14"> 路得的婆婆拿俄米对她说：“女儿啊，我不当为你找个安身之处，使你享福吗？</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 25:5–10; 路得记 2:20–23; 路得记 2:8"> 你与波阿斯的使女常在一处，波阿斯不是我们的亲族吗？他今夜在场上簸大麦，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 14:2; 提摩太前书 2:9–10; 以斯帖记 5:1"> 你要沐浴抹膏，换上衣服，下到场上，却不要使那人认出你来。你等他吃喝完了，</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 5:22"> 到他睡的时候，你看准他睡的地方，就进去掀开他脚上的被，躺卧在那里。他必告诉你所当做的事。”</span>
<span className="v" id="v5" data-v="5" data-xref="歌罗西书 3:20; 以弗所书 6:1"> 路得说：“凡你所吩咐的，我必遵行。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="箴言 1:8; 约翰福音 2:5; 出埃及记 20:12"> 路得就下到场上，照她婆婆所吩咐她的而行。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 19:6; 以斯帖记 1:10; 撒母耳记下 13:28"> 波阿斯吃喝完了，心里欢畅，就去睡在麦堆旁边。路得便悄悄地来掀开他脚上的被，躺卧在那里。</span>
<span className="v" id="v8" data-v="8"> 到了夜半，那人忽然惊醒，翻过身来，不料有女子躺在他的脚下。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 16:8; 路得记 2:20; 路得记 3:12"> 他就说：“你是谁？”回答说：“我是你的婢女路得。求你用你的衣襟遮盖我，因为你是我一个至近的亲属。”</span>
<span className="v" id="v10" data-v="10" data-xref="路得记 2:20; 哥林多前书 13:4–5; 路得记 1:8"> 波阿斯说：“女儿啊，愿你蒙耶和华赐福！你末后的恩比先前更大，因为少年人无论贫富，你都没有跟从。</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 31:29–31; 箴言 31:10; 箴言 12:4"> 女儿啊，现在不要惧怕，凡你所说的，我必照着行。我本城的人都知道你是个贤德的女子。</span>
<span className="v" id="v12" data-v="12" data-xref="路得记 4:1; 帖撒罗尼迦前书 4:6; 马太福音 7:12"> 我实在是你一个至近的亲属，只是还有一个人比我更近。</span>
<span className="v" id="v13" data-v="13" data-xref="路得记 4:5; 耶利米书 4:2; 路得记 2:20"> 你今夜在这里住宿，明早他若肯为你尽亲属的本分，就由他吧。倘若不肯，我指着永生的耶和华起誓：我必为你尽了本分！你只管躺到天亮。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 8:21; 罗马书 14:16; 哥林多前书 10:32"> 路得便在他脚下躺到天快亮，人彼此不能辨认的时候就起来了。波阿斯说：“不可使人知道有女子到场上来。”</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 32:8; 加拉太书 6:10"> 又对路得说：“打开你所披的外衣。”她打开了，波阿斯就撮了六簸箕大麦，帮她扛在肩上，她便进城去了。</span>
<span className="v" id="v16" data-v="16"> 路得回到婆婆那里，婆婆说：“女儿啊，怎么样了？”路得就将那人向她所行的述说了一遍。</span>
<span className="v" id="v17" data-v="17"> 又说：“那人给了我六簸箕大麦，对我说：‘你不可空手回去见你的婆婆。’”</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 37:3–5; 以赛亚书 28:16; 以赛亚书 30:7"> 婆婆说：“女儿啊，你只管安坐等候，看这事怎样成就，因为那人今日不办成这事必不休息。”</span>
</div>
</div>

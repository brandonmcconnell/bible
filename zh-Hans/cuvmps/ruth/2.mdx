## 路得往波阿斯田拾遗穗

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路得记 4:21; 路得记 3:12; 路得记 3:2"> 拿俄米的丈夫以利米勒的亲族中，有一个人名叫波阿斯，是个大财主。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 23:22; 利未记 19:9; 申命记 24:19–21"> 摩押女子路得对拿俄米说：“容我往田间去，我蒙谁的恩，就在谁的身后拾取麦穗。”拿俄米说：“女儿啊，你只管去。”</span>
<span className="v" id="v3" data-v="3" data-xref="帖撒罗尼迦后书 3:12; 马太福音 10:29; 路加福音 10:31"> 路得就去了，来到田间，在收割的人身后拾取麦穗。她恰巧到了以利米勒本族的人波阿斯那块田里。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 129:7–8; 士师记 6:12; 路加福音 1:28"> 波阿斯正从伯利恒来，对收割的人说：“愿耶和华与你们同在！”他们回答说：“愿耶和华赐福于你！”</span>
<span className="v" id="v5" data-v="5" data-xref="路得记 4:21; 历代志上 2:11–12"> 波阿斯问监管收割的仆人说：“那是谁家的女子？”</span>
<span className="v" id="v6" data-v="6" data-xref="路得记 1:22; 马太福音 24:45; 创世记 24:2"> 监管收割的仆人回答说：“是那摩押女子，跟随拿俄米从摩押地回来的。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 13:4; 箴言 18:23; 箴言 15:33"> 她说：‘请你容我跟着收割的人，拾取打捆剩下的麦穗。’她从早晨直到如今，除了在屋子里坐一会儿，常在这里。”</span>
</div>
</div>

## 波阿斯厚遇路得

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪下 5:13; 雅歌 1:7–8; 撒母耳记上 3:6"> 波阿斯对路得说：“女儿啊，听我说，不要往别人田里拾取麦穗，也不要离开这里，要常与我使女们在一处。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 5:18; 创世记 20:6; 箴言 6:29"> 我的仆人在哪块田收割，你就跟着他们去。我已经吩咐仆人不可欺负你。你若渴了，就可以到器皿那里喝仆人打来的水。”</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 25:23; 路得记 2:13; 路加福音 1:43"> 路得就俯伏在地叩拜，对他说：“我既是外邦人，怎么蒙你的恩，这样顾恤我呢？”</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 14:33; 路加福音 18:29–30; 路加福音 5:11"> 波阿斯回答说：“自从你丈夫死后，凡你向婆婆所行的，并你离开父母和本地到素不认识的民中，这些事，人全都告诉我了。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 36:7; 诗篇 91:4; 诗篇 63:7"> 愿耶和华照你所行的赏赐你。你来投靠耶和华以色列神的翅膀下，愿你满得他的赏赐。”</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 1:18; 创世记 34:3; 创世记 33:8"> 路得说：“我主啊，愿在你眼前蒙恩。我虽然不及你的一个使女，你还用慈爱的话安慰我的心。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路得记 2:18; 列王纪下 4:43–44; 马太福音 14:20"> 到了吃饭的时候，波阿斯对路得说：“你到这里来吃饼，将饼蘸在醋里。”路得就在收割的人旁边坐下。他们把烘了的穗子递给她，她吃饱了，还有余剩的。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各书 1:5"> 她起来又拾取麦穗。波阿斯吩咐仆人说：“她就是在捆中拾取麦穗，也可以容她，不可羞辱她；</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 12:13; 约翰一书 3:17–18; 申命记 24:19–21"> 并要从捆里抽出些来，留在地下任她拾取，不可叱吓她。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西结书 45:11–12; 箴言 31:27; 出埃及记 16:36"> 这样，路得在田间拾取麦穗，直到晚上。将所拾取的打了，约有一伊法大麦。</span>
<span className="v" id="v18" data-v="18" data-xref="路得记 2:14; 约翰福音 6:12–13; 提摩太前书 5:4"> 她就把所拾取的带进城去给婆婆看，又把她吃饱了所剩的给了婆婆。</span>
<span className="v" id="v19" data-v="19" data-xref="路得记 2:10; 诗篇 41:1; 列王纪上 7:21"> 婆婆问她说：“你今日在哪里拾取麦穗，在哪里做工呢？愿那顾恤你的得福！”路得就告诉婆婆说：“我今日在一个名叫波阿斯的人那里做工。”</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记下 2:5; 路得记 3:9–10; 利未记 25:25"> 拿俄米对儿妇说：“愿那人蒙耶和华赐福！因为他不断地恩待活人死人。”拿俄米又说：“那是我们本族的人，是一个至近的亲属。”</span>
<span className="v" id="v21" data-v="21" data-xref="雅歌 1:7–8; 路得记 2:7–8; 路得记 2:22"> 摩押女子路得说：“他对我说：‘你要紧随我的仆人拾取麦穗，直等他们收完了我的庄稼。’”</span>
<span className="v" id="v22" data-v="22" data-xref="雅歌 1:8; 箴言 27:10"> 拿俄米对儿妇路得说：“女儿啊，你跟着他的使女出去，不叫人遇见你在别人田间，这才为好。”</span>
<span className="v" id="v23" data-v="23" data-xref="箴言 6:6–8; 申命记 16:9; 以弗所书 6:1–3"> 于是路得与波阿斯的使女常在一处拾取麦穗，直到收完了大麦和小麦。路得仍与婆婆同住。</span>
</div>
</div>

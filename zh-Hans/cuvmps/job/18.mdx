## 恶人之祸患

<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="箴言 13:9; 箴言 24:20; 箴言 20:20"> <span className="pl pl-1">“恶人的亮光必要熄灭，</span><br /><span className="pl pl-1">他的火焰必不照耀。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="启示录 18:23; 约伯记 21:17; 诗篇 18:28"> <span className="pl pl-1">他帐篷中的亮光要变为黑暗，</span><br /><span className="pl pl-1">他以上的灯也必熄灭。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 4:12; 诗篇 33:10; 诗篇 18:36"> <span className="pl pl-1">他坚强的脚步必见狭窄，</span><br /><span className="pl pl-1">自己的计谋必将他绊倒。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 9:15; 约伯记 22:10; 诗篇 35:8"> <span className="pl pl-1">因为他被自己的脚陷入网中，</span><br /><span className="pl pl-1">走在缠人的网罗上。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 8:14–15; 约伯记 1:15; 约伯记 1:17"> <span className="pl pl-1">圈套必抓住他的脚跟，</span><br /><span className="pl pl-1">机关必擒获他。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 12:13; 罗马书 11:9; 诗篇 11:6"> <span className="pl pl-1">活扣为他藏在土内，</span><br /><span className="pl pl-1">羁绊为他藏在路上。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 15:21; 耶利米书 6:25; 利未记 26:36"> <span className="pl pl-1">四面的惊吓要使他害怕，</span><br /><span className="pl pl-1">并且追赶他的脚跟。</span><br /></span>

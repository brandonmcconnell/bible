## 约伯自述昔之佳景

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约伯记 27:1; 约伯记 13:12; 民数记 23:7"> 约伯又接着说：</span>
<span className="v" id="v2" data-v="2" data-xref="约伯记 1:10; 约伯记 1:1–5; 耶利米书 31:28"> <span className="pl pl-1">“唯愿我的景况如从前的月份，</span><br /><span className="pl pl-1">如神保守我的日子。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 18:28; 约翰福音 8:12; 约伯记 18:6"> <span className="pl pl-1">那时他的灯照在我头上，</span><br /><span className="pl pl-1">我藉他的光行过黑暗。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 25:14; 箴言 3:32; 诗篇 27:5"> <span className="pl pl-1">我愿如壮年的时候，</span><br /><span className="pl pl-1">那时我在帐篷中，</span><br /><span className="pl pl-1">神待我有密友之情。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 128:3; 诗篇 127:3–5; 申命记 33:27–29"> <span className="pl pl-1">全能者仍与我同在，</span><br /><span className="pl pl-1">我的儿女都环绕我。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 81:16; 约伯记 20:17; 申命记 32:13–14"> <span className="pl pl-1">奶多可洗我的脚，</span><br /><span className="pl pl-1">磐石为我出油成河。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="撒迦利亚书 8:16; 路得记 4:1–2; 申命记 16:18"> <span className="pl pl-1">我出到城门，</span><br /><span className="pl pl-1">在街上设立座位，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="利未记 19:32; 箴言 16:31; 罗马书 13:7"> <span className="pl pl-1">少年人见我而回避，</span><br /><span className="pl pl-1">老年人也起身站立；</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="约伯记 21:5; 约伯记 40:4; 箴言 10:19"> <span className="pl pl-1">王子都停止说话，</span><br /><span className="pl pl-1">用手捂口；</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 137:6; 以西结书 3:26"> <span className="pl pl-1">首领静默无声，</span><br /><span className="pl pl-1">舌头贴住上膛。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 4:22; 约伯记 31:20; 箴言 29:2"> <span className="pl pl-1">耳朵听我的就称我有福，</span><br /><span className="pl pl-1">眼睛看我的便称赞我，</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 72:12; 箴言 21:13; 雅各书 1:27"> <span className="pl pl-1">因我拯救哀求的困苦人</span><br /><span className="pl pl-1">和无人帮助的孤儿。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="腓利门书 1:7; 约伯记 22:9; 约伯记 31:19–20"> <span className="pl pl-1">将要灭亡的为我祝福，</span><br /><span className="pl pl-1">我也使寡妇心中欢乐。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 61:10; 以赛亚书 59:17; 诗篇 132:9"> <span className="pl pl-1">我以公义为衣服，</span><br /><span className="pl pl-1">以公平为外袍和冠冕。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="民数记 10:31; 马太福音 11:5; 哥林多前书 12:12–31"> <span className="pl pl-1">我为瞎子的眼，</span><br /><span className="pl pl-1">瘸子的脚。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 29:7; 诗篇 68:5; 约伯记 31:18"> <span className="pl pl-1">我为穷乏人的父，</span><br /><span className="pl pl-1">素不认识的人，我查明他的案件。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 3:7; 箴言 30:14; 撒母耳记上 17:35"> <span className="pl pl-1">我打破不义之人的牙床，</span><br /><span className="pl pl-1">从他牙齿中夺了所抢的。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 30:6–7; 创世记 32:12; 约伯记 42:16–17"> <span className="pl pl-1">我便说：‘我必死在家中</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：窝中。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">必增添我的日子多如尘沙。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 1:3; 耶利米书 17:8; 何西阿书 14:5–7"> <span className="pl pl-1">我的根长到水边，</span><br /><span className="pl pl-1">露水终夜沾在我的枝上。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="创世记 49:24; 以赛亚书 40:31; 诗篇 18:34"> <span className="pl pl-1">我的荣耀在身上增新，</span><br /><span className="pl pl-1">我的弓在手中日强。’</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="约伯记 32:11–12; 约伯记 29:9–10"> <span className="pl pl-1">人听见我而仰望，</span><br /><span className="pl pl-1">静默等候我的指教。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="申命记 32:2; 雅歌 4:11; 马太福音 22:46"> <span className="pl pl-1">我说话之后，他们就不再说，</span><br /><span className="pl pl-1">我的言语像雨露滴在他们身上。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="何西阿书 6:3; 诗篇 72:6; 撒迦利亚书 10:1"> <span className="pl pl-1">他们仰望我如仰望雨，</span><br /><span className="pl pl-1">又张开口如切慕春雨。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 89:15; 诗篇 4:6; 诗篇 126:1"> <span className="pl pl-1">他们不敢自信，我就向他们含笑；</span><br /><span className="pl pl-1">他们不使我脸上的光改变。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="哥林多后书 1:3–4; 帖撒罗尼迦前书 3:2–3; 创世记 14:14–17"> <span className="pl pl-1">我为他们选择道路，又坐首位；</span><br /><span className="pl pl-1">我如君王在军队中居住，</span><br /><span className="pl pl-1">又如吊丧的安慰伤心的人。</span></span>

## 以利户责约伯自义向神烦言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 以利户又说：</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 1:5; 哥林多前书 14:20; 哥林多前书 10:15"> <span className="pl pl-1">“你们智慧人，要听我的话；</span><br /><span className="pl pl-1">有知识的人，要留心听我说。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="约伯记 12:11; 哥林多前书 2:15; 约伯记 33:2"> <span className="pl pl-1">因为耳朵试验话语，</span><br /><span className="pl pl-1">好像上膛尝食物。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 5:21; 士师记 19:30; 罗马书 12:2"> <span className="pl pl-1">我们当选择何为是，</span><br /><span className="pl pl-1">彼此知道何为善。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="约伯记 27:2; 约伯记 33:9; 约伯记 16:17"> <span className="pl pl-1">约伯曾说：‘我是公义，</span><br /><span className="pl pl-1">神夺去我的理。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="约伯记 6:4; 约伯记 27:4–6; 约伯记 16:13"> <span className="pl pl-1">我虽有理，还算为说谎言的；</span><br /><span className="pl pl-1">我虽无过，受的伤还不能医治。’</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="约伯记 15:16; 申命记 29:19; 箴言 1:22"> <span className="pl pl-1">谁像约伯，</span><br /><span className="pl pl-1">喝讥诮如同喝水呢？</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 1:1; 哥林多前书 15:33; 箴言 13:20"> <span className="pl pl-1">他与作孽的结伴，</span><br /><span className="pl pl-1">和恶人同行。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="约伯记 21:14–16; 约伯记 35:3; 玛拉基书 3:14"> <span className="pl pl-1">他说，人以神为乐</span><br /><span className="pl pl-1">总是无益。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="罗马书 9:14; 申命记 32:4; 约伯记 8:3"> <span className="pl pl-1">“所以你们明理的人，要听我的话：</span><br /><span className="pl pl-1">神断不至行恶，</span><br /><span className="pl pl-1">全能者断不至作孽。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 5:10; 罗马书 2:6; 启示录 22:12"> <span className="pl pl-1">他必按人所做的报应人，</span><br /><span className="pl pl-1">使各人照所行的得报。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="约伯记 8:3; 诗篇 11:7; 诗篇 145:17"> <span className="pl pl-1">神必不作恶，</span><br /><span className="pl pl-1">全能者也不偏离公平。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 29:11; 以赛亚书 40:13–14; 罗马书 11:34–36"> <span className="pl pl-1">谁派他治理地，</span><br /><span className="pl pl-1">安定全世界呢？</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 104:29; 约伯记 7:17; 约伯记 9:4"> <span className="pl pl-1">他若专心为己，</span><br /><span className="pl pl-1">将灵和气收归自己，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="创世记 3:19; 传道书 12:7; 以赛亚书 57:16"> <span className="pl pl-1">凡有血气的就必一同死亡，</span><br /><span className="pl pl-1">世人必仍归尘土。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="约伯记 13:2–6; 约伯记 12:3"> <span className="pl pl-1">“你若明理，就当听我的话，</span><br /><span className="pl pl-1">留心听我言语的声音。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="约伯记 40:8; 创世记 18:25; 撒母耳记下 23:3"> <span className="pl pl-1">难道恨恶公平的可以掌权吗？</span><br /><span className="pl pl-1">那有公义的，有大能的，岂可定他有罪吗？</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 22:28; 箴言 17:26; 罗马书 13:7"> <span className="pl pl-1">他对君王说：‘你是鄙陋的！’</span><br /><span className="pl pl-1">对贵臣说：‘你是邪恶的！’</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="申命记 10:17; 使徒行传 10:34; 雅各书 2:5"> <span className="pl pl-1">他待王子不徇情面，</span><br /><span className="pl pl-1">也不看重富足的过于贫穷的，</span><br /><span className="pl pl-1">因为都是他手所造。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 73:19; 撒母耳记上 25:37–39; 撒母耳记上 26:10"> <span className="pl pl-1">在转眼之间，半夜之中，</span><br /><span className="pl pl-1">他们就死亡，</span><br /><span className="pl pl-1">百姓被震动而去世，</span><br /><span className="pl pl-1">有权力的被夺去非藉人手。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="箴言 15:3; 约伯记 31:4; 耶利米书 16:17"> <span className="pl pl-1">“神注目观看人的道路，</span><br /><span className="pl pl-1">看明人的脚步。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 4:13; 阿摩司书 9:2–3; 箴言 10:29"> <span className="pl pl-1">没有黑暗、阴翳能给作孽的藏身。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="以斯拉记 9:13; 诗篇 119:137; 罗马书 9:20"> <span className="pl pl-1">神审判人，不必使人到他面前再三鉴察。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 113:7–8; 诗篇 94:5; 但以理书 2:21"> <span className="pl pl-1">他用难测之法打破有能力的人，</span><br /><span className="pl pl-1">设立别人代替他们。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="何西阿书 7:2; 约伯记 34:20; 阿摩司书 8:7"> <span className="pl pl-1">他原知道他们的行为，</span><br /><span className="pl pl-1">使他们在夜间倾倒灭亡。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 58:10–11; 申命记 21:21; 以赛亚书 66:24"> <span className="pl pl-1">他在众人眼前击打他们，</span><br /><span className="pl pl-1">如同击打恶人一样。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 28:5; 撒母耳记上 15:11; 以赛亚书 5:12"> <span className="pl pl-1">因为他们偏行不跟从他，</span><br /><span className="pl pl-1">也不留心他的道，</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="雅各书 5:4; 出埃及记 3:7; 约伯记 35:9"> <span className="pl pl-1">甚至使贫穷人的哀声达到他那里，</span><br /><span className="pl pl-1">他也听了困苦人的哀声。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="约伯记 23:13; 约翰福音 14:27; 诗篇 27:9"> <span className="pl pl-1">他使人安静，谁能扰乱</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：定罪。">a</a></sup><br /><span className="pl pl-1">呢？</span><br /><span className="pl pl-1">他掩面，谁能见他呢？</span><br /><span className="pl pl-1">无论待一国或一人，都是如此，</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="箴言 29:2–12; 约伯记 34:21; 列王纪下 21:9"> <span className="pl pl-1">使不虔敬的人不得做王，</span><br /><span className="pl pl-1">免得有人牢笼百姓。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="弥迦书 7:9; 约伯记 33:27; 约伯记 42:6"> <span className="pl pl-1">“有谁对神说</span><br /><span className="pl pl-1">‘我受了责罚，不再犯罪。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 32:8; 诗篇 25:4–5; 诗篇 139:23–24"> <span className="pl pl-1">我所看不明的，求你指教我。</span><br /><span className="pl pl-1">我若作了孽，必不再做’？</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="约伯记 33:32; 以赛亚书 45:9; 诗篇 135:6"> <span className="pl pl-1">他施行报应，</span><br /><span className="pl pl-1">岂要随你的心愿，叫你推辞不受吗？</span><br /><span className="pl pl-1">选定的是你，不是我，</span><br /><span className="pl pl-1">你所知道的只管说吧！</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 10:15; 约伯记 34:4; 约伯记 34:16"> <span className="pl pl-1">明理的人和听我话的智慧人，必对我说：</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="约伯记 35:16; 约伯记 38:2; 约伯记 15:2"> <span className="pl pl-1">‘约伯说话没有知识，</span><br /><span className="pl pl-1">言语中毫无智慧。’</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="约伯记 21:7; 约伯记 23:16; 约伯记 12:6"> <span className="pl pl-1">愿约伯被试验到底，</span><br /><span className="pl pl-1">因他回答像恶人一样。</span><br /></span>
<span className="v" id="v37" data-v="37" data-xref="约伯记 27:23; 以赛亚书 1:19–20; 撒母耳记上 15:23"> <span className="pl pl-1">他在罪上又加悖逆，</span><br /><span className="pl pl-1">在我们中间拍手，</span><br /><span className="pl pl-1">用许多言语轻慢神。”</span></span>
</div>

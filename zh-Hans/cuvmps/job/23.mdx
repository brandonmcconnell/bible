## 约伯自言愿诣神陈述其冤

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 约伯回答说：</span>
<span className="v" id="v2" data-v="2" data-xref="约伯记 10:1; 诗篇 32:4; 约伯记 7:11"> <span className="pl pl-1">“如今我的哀告还算为悖逆，</span><br /><span className="pl pl-1">我的责罚比我的唉哼还重。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="约伯记 16:21; 耶利米书 14:7; 约伯记 13:3"> <span className="pl pl-1">唯愿我能知道在哪里可以寻见神，</span><br /><span className="pl pl-1">能到他的台前，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="约伯记 13:18; 但以理书 9:18–19; 出埃及记 32:12–13"> <span className="pl pl-1">我就在他面前将我的案件陈明，</span><br /><span className="pl pl-1">满口辩白。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="约伯记 13:22–23; 约伯记 10:2; 哥林多前书 4:3–4"> <span className="pl pl-1">我必知道他回答我的言语，</span><br /><span className="pl pl-1">明白他向我所说的话。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="约伯记 13:21; 约伯记 9:33–34; 哥林多后书 12:9–10"> <span className="pl pl-1">他岂用大能与我争辩吗？</span><br /><span className="pl pl-1">必不这样，他必理会我。</span><br /></span>

<span className="v" id="v8" data-v="8" data-xref="诗篇 10:1; 约伯记 9:11; 约伯记 35:14"> <span className="pl pl-1">只是我往前行，他不在那里；</span><br /><span className="pl pl-1">往后退，也不能见他。</span><br /></span>

<div className="bp poetry">

## 为门徒的信与爱与望感谢神

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="帖撒罗尼迦前书 1:2; 歌罗西书 1:9; 提摩太后书 1:3"> 我们感谢神我们主耶稣基督的父，常常为你们祷告，</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 1:15; 帖撒罗尼迦后书 1:3; 帖撒罗尼迦前书 1:3"> 因听见你们在基督耶稣里的信心并向众圣徒的爱心——</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前书 1:3–4; 以弗所书 1:13; 提摩太后书 4:8"> 是为那给你们存在天上的盼望。这盼望就是你们从前在福音真理的道上所听见的。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 15:16; 腓立比书 1:11; 歌罗西书 1:23"> 这福音传到你们那里，也传到普天之下，并且结果、增长，如同在你们中间，自从你们听见福音真知道神恩惠的日子一样。</span>
<span className="v" id="v7" data-v="7" data-xref="歌罗西书 4:12; 腓利门书 1:23; 歌罗西书 4:7"> 正如你们从我们所亲爱、一同做仆人的以巴弗所学的。他为我们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷作：你们。">a</a></sup>做了基督忠心的执事，</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 15:30; 提摩太后书 1:7; 加拉太书 5:22"> 也把你们因圣灵所存的爱心告诉了我们。</span>
</div>
</div>

## 为门徒加增智慧力量忍耐祷告神

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="雅各书 3:17; 腓立比书 1:9–11; 雅各书 1:5"> 因此，我们自从听见的日子，也就为你们不住地祷告祈求，愿你们在一切属灵的智慧悟性上，满心知道神的旨意，</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 4:1; 希伯来书 13:21; 彼得后书 1:2–3"> 好叫你们行事为人对得起主，凡事蒙他喜悦，在一切善事上结果子，渐渐地多知道神；</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 3:16; 腓立比书 4:13; 以弗所书 4:2"> 照他荣耀的权能，得以在各样的力上加力，好叫你们凡事欢欢喜喜地忍耐宽容。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 20:32; 以弗所书 1:11; 以弗所书 1:18"> 又感谢父，叫我们能与众圣徒在光明中同得基业。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 5:8; 使徒行传 26:18; 彼得前书 2:9"> 他救了我们脱离黑暗的权势，把我们迁到他爱子的国里；</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所书 1:7; 罗马书 3:24–25; 彼得前书 1:19–20"> 我们在爱子里得蒙救赎，罪过得以赦免。</span>
</div>
</div>

## 爱子是不能看见之神的像

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="希伯来书 1:3; 约翰福音 14:9; 约翰福音 1:1"> 爱子是那不能看见之神的像，是首生的，在一切被造的以先。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 11:36; 约翰福音 1:3; 哥林多前书 8:6"> 因为万有都是靠他造的，无论是天上的、地上的，能看见的、不能看见的，或是有位的、主治的、执政的、掌权的，一概都是藉着他造的，又是为他造的。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 1:3; 哥林多前书 8:6; 使徒行传 17:28"> 他在万有之先，万有也靠他而立。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 1:22–23; 启示录 1:5; 以弗所书 4:15–16"> 他也是教会全体之首。他是元始，是从死里首先复生的，使他可以在凡事上居首位，</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 2:9; 约翰福音 1:16; 以弗所书 1:23"> 因为父喜欢叫一切的丰盛在他里面居住。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 5:18–21; 以弗所书 1:10; 约翰一书 4:9–10"> 既然藉着他在十字架上所流的血成就了和平，便藉着他叫万有，无论是地上的、天上的，都与自己和好了。</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所书 2:12; 提多书 3:3–7; 以弗所书 2:1–3"> 你们从前与神隔绝，因着恶行，心里与他为敌；</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 5:27; 犹大书 1:24; 以弗所书 1:4"> 但如今他藉着基督的肉身受死，叫你们与自己和好，都成了圣洁，没有瑕疵，无可责备，把你们引到自己面前。</span>
</div>
</div>

## 应当稳固不离开福音的盼望

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="希伯来书 3:14; 希伯来书 3:6; 马太福音 24:13–14"> 只要你们在所信的道上恒心，根基稳固，坚定不移，不致被引动失去<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：离开。">b</a></sup>福音的盼望。这福音就是你们所听过的，也是传于普天下万人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“万人”原文作“凡受造的”。">c</a></sup>听的。我保罗也做了这福音的执事。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="罗马书 5:3; 提摩太后书 1:8; 哥林多后书 1:5–8"> 现在我为你们受苦，倒觉欢乐，并且为基督的身体，就是为教会，要在我肉身上补满基督患难的缺欠。</span>
<span className="v" id="v25" data-v="25" data-xref="以弗所书 3:2; 歌罗西书 1:23; 加拉太书 2:7–8"> 我照神为你们所赐我的职分做了教会的执事，要把神的道理传得全备。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 8:10; 罗马书 16:25–26; 以弗所书 3:3–10"> 这道理就是历世历代所隐藏的奥秘，但如今向他的圣徒显明了。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 14:20; 罗马书 8:10; 以弗所书 3:16–17"> 神愿意叫他们知道，这奥秘在外邦人中有何等丰盛的荣耀，就是基督在你们心里成了有荣耀的盼望。</span>
</div>
</div>

## 使各人在基督里完全

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以弗所书 5:27; 耶利米书 3:15; 以弗所书 4:11–13"> 我们传扬他，是用诸般的智慧劝诫各人，教导各人，要把各人在基督里完完全全地引到神面前。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 15:10; 以弗所书 1:19; 哥林多前书 9:25–27"> 我也为此劳苦，照着他在我里面运用的大能尽心竭力。</span>
</div>
</div>

## 战败巴珊王噩

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 21:33–35; 申命记 1:4; 申命记 29:7"> “以后，我们转回，向巴珊去。巴珊王噩和他的众民都出来，在以得来与我们交战。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 2:10; 历代志下 20:17; 民数记 21:23–25"> 耶和华对我说：‘不要怕他，因我已将他和他的众民并他的地，都交在你手中。你要待他像从前待住希实本的亚摩利王西宏一样。’</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 21:35; 约书亚记 13:12; 约书亚记 13:30"> 于是耶和华我们的神也将巴珊王噩和他的众民都交在我们手中。我们杀了他们，没有留下一个。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 4:13; 约书亚记 12:4; 约书亚记 13:30–31"> 那时，我们夺了他所有的城，共有六十座，没有一座城不被我们所夺。这为亚珥歌伯的全境，就是巴珊地噩王的国。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 1:28; 民数记 13:28; 希伯来书 11:30"> 这些城都有坚固的高墙，有门有闩。此外还有许多无城墙的乡村。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 2:34; 诗篇 135:10–12; 申命记 2:24"> 我们将这些都毁灭了，像从前待希实本王西宏一样，把有人烟的各城，连女人带孩子，尽都毁灭。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 2:35; 约书亚记 8:27; 约书亚记 11:11–14"> 唯有一切牲畜和城中的财物，都取为自己的掠物。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 13:9–12; 约书亚记 12:2–6; 民数记 32:33–42"> 那时，我们从约旦河东两个亚摩利王的手将亚嫩谷直到黑门山之地夺过来</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 5:23; 诗篇 29:6; 以西结书 27:5"> （这黑门山，西顿人称为西连，亚摩利人称为示尼珥），</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 13:31; 约书亚记 13:11–12; 申命记 4:49"> 就是夺了平原的各城，基列全地，巴珊全地，直到撒迦和以得来，都是巴珊王噩国内的城邑。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 14:5; 耶利米书 49:2; 撒母耳记下 12:26"> （利乏音人所剩下的只有巴珊王噩。他的床是铁的，长九肘，宽四肘，都是以人肘为度，现今岂不是在亚扪人的拉巴吗？）</span>
</div>
</div>

## 以约旦东地给予二支派有半

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命记 2:36; 民数记 32:32–38; 约书亚记 13:8–28"> “那时，我们得了这地。从亚嫩谷边的亚罗珥起，我将基列山地的一半，并其中的城邑，都给了鲁本人和迦得人。</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 32:39–42; 约书亚记 13:29–32; 历代志上 5:23–26"> 其余的基列地和巴珊全地，就是噩王的国，我给了玛拿西半支派。（亚珥歌伯全地乃是巴珊全地，这叫做利乏音人之地。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 32:41; 约书亚记 13:13; 撒母耳记下 3:3"> 玛拿西的子孙睚珥占了亚珥歌伯全境，直到基述人和玛迦人的交界，就按自己的名称这巴珊地为哈倭特睚珥，直到今日。）</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 32:39–40; 约书亚记 17:1–3; 约书亚记 22:7"> 我又将基列给了玛吉。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 21:24; 申命记 2:37; 撒母耳记下 24:5"> 从基列到亚嫩谷，以谷中为界，直到亚扪人交界的雅博河，我给了鲁本人和迦得人；</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 12:3; 创世记 14:3; 约书亚记 3:16"> 又将亚拉巴和靠近约旦河之地，从基尼烈直到亚拉巴海，就是盐海，并毗斯迦山根东边之地，都给了他们。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民数记 32:20–24; 约书亚记 4:12–13; 约书亚记 1:12–15"> “那时我吩咐你们说：‘耶和华你们的神已将这地赐给你们为业。你们所有的勇士都要带着兵器，在你们的弟兄以色列人前面过去。</span>
<span className="v" id="v19" data-v="19"> 但你们的妻子、孩子、牲畜（我知道你们有许多的牲畜），可以住在我所赐给你们的各城里。</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 22:4; 约书亚记 22:8"> 等到你们弟兄在约旦河那边也得耶和华你们神所赐给他们的地，又使他们得享平安，与你们一样，你们才可以回到我所赐给你们为业之地。’</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 27:18–23; 哥林多后书 12:10; 诗篇 9:10"> 那时我吩咐约书亚说：‘你亲眼看见了耶和华你神向这二王所行的，耶和华也必向你所要去的各国照样行。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 14:14; 申命记 20:4; 申命记 1:30"> 你不要怕他们，因那为你争战的是耶和华你的神。’</span>
</div>
</div>

## 摩西不得渡约旦

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 12:8–9"> “那时我恳求耶和华说：</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 15:11; 申命记 11:2; 诗篇 71:19"> ‘主耶和华啊，你已将你的大力大能显给仆人看。在天上，在地下，有什么神能像你行事，像你有大能的作为呢？</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 4:21–22; 以西结书 20:6; 出埃及记 3:8"> 求你容我过去，看约旦河那边的美地，就是那佳美的山地和黎巴嫩。’</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 1:37; 申命记 31:2; 历代志上 22:7–9"> 但耶和华因你们的缘故向我发怒，不应允我，对我说：‘罢了，你不要向我再提这事。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 27:12; 申命记 34:1–4; 创世记 13:14–15"> 你且上毗斯迦山顶去，向东、西、南、北举目观望，因为你必不能过这约旦河。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 31:3; 申命记 31:7; 申命记 1:38"> 你却要嘱咐约书亚，勉励他，使他胆壮，因为他必在这百姓前面过去，使他们承受你所要观看之地。’</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 34:6; 申命记 4:46; 民数记 25:3"> 于是我们住在伯毗珥对面的谷中。</span>
</div>
</div>

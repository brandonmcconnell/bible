## 当记念神之引导

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 4:1; 申命记 5:32–3; 帖撒罗尼迦前书 4:1–2"> “我今日所吩咐的一切诫命，你们要谨守遵行，好叫你们存活，人数增多，且进去得耶和华向你们列祖起誓应许的那地。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各书 1:3; 彼得前书 1:7; 申命记 8:16"> 你也要记念耶和华你的神在旷野引导你这四十年，是要苦炼你、试验你，要知道你心内如何，肯守他的诫命不肯。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 4:4; 路加福音 4:4; 希伯来书 13:5–6"> 他苦炼你，任你饥饿，将你和你列祖所不认识的吗哪赐给你吃，使你知道人活着不是单靠食物，乃是靠耶和华口里所出的一切话。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米记 9:21; 申命记 29:5; 马太福音 26:25–30"> 这四十年，你的衣服没有穿破，你的脚也没有肿。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 3:19; 箴言 3:12; 撒母耳记下 7:14"> 你当心里思想，耶和华你神管教你，好像人管教儿子一样。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 6:31; 申命记 5:33; 撒母耳记上 12:24"> 你要谨守耶和华你神的诫命，遵行他的道，敬畏他。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 11:9–12; 出埃及记 3:8; 以西结书 20:6"> 因为耶和华你神领你进入美地，那地有河，有泉，有源，从山谷中流出水来，</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 6:13; 诗篇 147:14; 申命记 32:14"> 那地有小麦、大麦、葡萄树、无花果树、石榴树、橄榄树和蜜。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 22:14; 申命记 33:25; 约书亚记 22:8"> 你在那地不缺食物，一无所缺。那地的石头是铁，山内可以挖铜。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 103:2; 罗马书 14:6; 箴言 3:9"> 你吃得饱足，就要称颂耶和华你的神，因他将那美地赐给你了。</span>
</div>
</div>

## 慎起骄傲致忘耶和华恩

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="诗篇 106:21; 何西阿书 2:8–9; 箴言 1:32"> “你要谨慎，免得忘记耶和华你的神，不守他的诫命、典章、律例，就是我今日所吩咐你的。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 30:9; 申命记 28:47; 申命记 32:15"> 恐怕你吃得饱足，建造美好的房屋居住，</span>
<span className="v" id="v13" data-v="13" data-xref="约伯记 1:3; 创世记 13:1–5; 路加福音 12:13–21"> 你的牛羊加多，你的金银增添，并你所有的全都加增，</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 106:21; 哥林多前书 4:7–8; 申命记 8:11"> 你就心高气傲，忘记耶和华你的神（就是将你从埃及地为奴之家领出来的，</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 21:6; 民数记 20:11; 耶利米书 2:6"> 引你经过那大而可怕的旷野，那里有火蛇、蝎子、干旱无水之地。他曾为你使水从坚硬的磐石中流出来，</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 8:3; 雅各书 1:12; 出埃及记 16:15"> 又在旷野将你列祖所不认识的吗哪赐给你吃，是要苦炼你、试验你，叫你终久享福），</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 9:4; 哥林多前书 4:7; 但以理书 4:30"> 恐怕你心里说：‘这货财是我力量，我能力得来的。’</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:22; 何西阿书 2:8; 申命记 7:8"> 你要记念耶和华你的神，因为得货财的力量是他给你的，为要坚定他向你列祖起誓所立的约，像今日一样。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 4:26; 撒母耳记上 12:25; 西番雅书 1:18"> 你若忘记耶和华你的神，随从别神，侍奉敬拜，你们必定灭亡，这是我今日警戒你们的。</span>
<span className="v" id="v20" data-v="20" data-xref="但以理书 9:11–12; 历代志下 36:16–17"> 耶和华在你们面前怎样使列国的民灭亡，你们也必照样灭亡，因为你们不听从耶和华你们神的话。</span>
</div>

## 禁为死者划身剃额

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 21:5; 罗马书 9:8; 加拉太书 3:26"> “你们是耶和华你们神的儿女。不可为死人用刀划身，也不可将额上剃光。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 7:6; 利未记 20:26; 出埃及记 19:5–6"> 因为你归耶和华你神为圣洁的民，耶和华从地上的万民中拣选你特做自己的子民。</span>
</div>
</div>

## 示以洁与不洁之物

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以西结书 4:14; 罗马书 14:14; 利未记 20:25"> “凡可憎的物都不可吃。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 11:2–45; 使徒行传 10:14; 列王纪上 4:23"> 可吃的牲畜就是：牛、绵羊、山羊、</span>
<span className="v" id="v5" data-v="5"> 鹿、羚羊、狍子、野山羊、麋鹿、黄羊、青羊。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 18:1; 哥林多后书 6:17; 诗篇 1:1–2"> 凡分蹄成为两瓣又倒嚼的走兽，你们都可以吃。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 7:22–23; 提多书 1:16; 提摩太后书 3:5"> 但那些倒嚼或是分蹄之中不可吃的乃是：骆驼，兔子，沙番，因为是倒嚼不分蹄，就于你们不洁净；</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 11:26–27; 以赛亚书 66:3; 彼得后书 2:22"> 猪，因为是分蹄却不倒嚼，就于你们不洁净。这些兽的肉，你们不可吃，死的也不可摸。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="利未记 11:9–12"> “水中可吃的乃是这些：凡有翅有鳞的，都可以吃。</span>
<span className="v" id="v10" data-v="10"> 凡无翅无鳞的都不可吃，是于你们不洁净。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> “凡洁净的鸟，你们都可以吃。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 11:13–19"> 不可吃的乃是：雕，狗头雕，红头雕，</span>
<span className="v" id="v13" data-v="13"> 鹯，小鹰，鹞鹰与其类，</span>
<span className="v" id="v14" data-v="14"> 乌鸦与其类，</span>
<span className="v" id="v15" data-v="15" data-xref="约伯记 30:29"> 鸵鸟，夜鹰，鱼鹰，鹰与其类，</span>
<span className="v" id="v16" data-v="16"> 鸮鸟，猫头鹰，角鸱，</span>
<span className="v" id="v17" data-v="17"> 鹈鹕，秃雕，鸬鹚，</span>
<span className="v" id="v18" data-v="18"> 鹳，鹭鸶与其类，戴鵀与蝙蝠。</span>
<span className="v" id="v19" data-v="19" data-xref="腓立比书 3:19; 利未记 11:20–23"> 凡有翅膀爬行的物是于你们不洁净，都不可吃。</span>
<span className="v" id="v20" data-v="20"> 凡洁净的鸟，你们都可以吃。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及记 23:19; 出埃及记 34:26; 利未记 22:8"> “凡自死的，你们都不可吃，可以给你城里寄居的吃，或卖于外人吃，因为你是归耶和华你神为圣洁的民。不可用山羊羔母的奶煮山羊羔。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="尼希米记 10:37; 申命记 12:17; 申命记 26:12–15"> “你要把你撒种所产的，就是你田地每年所出的，十分取一分；</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 12:5–7; 申命记 4:10; 申命记 12:17–18"> 又要把你的五谷、新酒和油的十分之一，并牛群、羊群中头生的，吃在耶和华你神面前，就是他所选择要立为他名的居所。这样，你可以学习时常敬畏耶和华你的神。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 12:21; 申命记 12:5; 申命记 11:24"> 当耶和华你神赐福于你的时候，耶和华你神所选择要立为他名的地方若离你太远，那路也太长，使你不能把这物带到那里去，</span>
<span className="v" id="v25" data-v="25"> 你就可以换成银子，将银子包起来，拿在手中，往耶和华你神所要选择的地方去。</span>
<span className="v" id="v26" data-v="26" data-xref="传道书 9:7; 申命记 12:7; 马太福音 21:12"> 你用这银子，随心所欲，或买牛羊，或买清酒浓酒，凡你心所想的都可以买。你和你的家属在耶和华你神的面前吃喝快乐。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 18:20; 申命记 14:29; 申命记 12:12"> 住在你城里的利未人，你不可丢弃他，因为他在你们中间无份无业。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命记 14:22; 阿摩司书 4:4; 申命记 26:12–15"> “每逢三年的末一年，你要将本年的土产十分之一都取出来，积存在你的城中。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 15:10; 申命记 14:27; 箴言 19:17"> 在你城里无份无业的利未人，和你城里寄居的，并孤儿寡妇，都可以来，吃得饱足。这样，耶和华你的神必在你手里所办的一切事上赐福于你。</span>
</div>
</div>

## 摩西祝福以色列人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 14:6; 诗篇 90:1; 创世记 27:4"> 以下是神人摩西在未死之先为以色列人所祝的福。</span>
<span className="v" id="v2" data-v="2" data-xref="犹大书 1:14; 哈巴谷书 3:3; 启示录 5:11"> 他说：<br /><span className="pl pl-1">“耶和华从西奈而来，</span><br /><span className="pl pl-1">从西珥向他们显现，</span><br /><span className="pl pl-1">从巴兰山发出光辉，</span><br /><span className="pl pl-1">从万万圣者中来临，</span><br /><span className="pl pl-1">从他右手为百姓传出烈火的律法。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 10:39; 玛拉基书 1:2; 申命记 7:6–8"> <span className="pl pl-1">他疼爱百姓，</span><br /><span className="pl pl-1">众圣徒都在他手中；</span><br /><span className="pl pl-1">他们坐在他的脚下，</span><br /><span className="pl pl-1">领受他的言语。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 1:17; 诗篇 119:111; 约翰福音 7:19"> <span className="pl pl-1">摩西将律法传给我们，</span><br /><span className="pl pl-1">作为雅各会众的产业；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="申命记 32:15; 士师记 17:6; 民数记 23:21"> <span className="pl pl-1">百姓的众首领，</span><br /><span className="pl pl-1">以色列的各支派，</span><br /><span className="pl pl-1">一同聚会的时候，</span><br /><span className="pl pl-1">耶和华</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：他。">a</a></sup><br /><span className="pl pl-1">在耶书仑中为王。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="创世记 49:8; 民数记 32:31–32; 约书亚记 22:1–9"> <span className="pl pl-1">“愿鲁本存活，不致死亡，</span><br /><span className="pl pl-1">愿他人数不致稀少。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="创世记 49:8–12; 诗篇 20:2; 撒母耳记下 7:9–12"> 为犹大祝福说：<br /><span className="pl pl-1">“求耶和华俯听犹大的声音，</span><br /><span className="pl pl-1">引导他归于本族。</span><br /><span className="pl pl-1">他曾用手为自己争战，</span><br /><span className="pl pl-1">你必帮助他攻击敌人。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 17:7; 出埃及记 28:30; 民数记 20:13"> 论利未说：<br /><span className="pl pl-1">“耶和华啊，你的土明和乌陵</span><br /><span className="pl pl-1">都在你的虔诚人那里。</span><br /><span className="pl pl-1">你在玛撒曾试验他，</span><br /><span className="pl pl-1">在米利巴水与他争论。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 10:37; 出埃及记 32:25–29; 马太福音 12:48"> <span className="pl pl-1">他论自己的父母说</span><br /><span className="pl pl-1">‘我未曾看见’，</span><br /><span className="pl pl-1">他也不承认弟兄，</span><br /><span className="pl pl-1">也不认识自己的儿女。</span><br /><span className="pl pl-1">这是因利未人遵行你的话，</span><br /><span className="pl pl-1">谨守你的约。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="利未记 10:11; 诗篇 51:19; 申命记 17:9–11"> <span className="pl pl-1">他们要将你的典章教训雅各，</span><br /><span className="pl pl-1">将你的律法教训以色列。</span><br /><span className="pl pl-1">他们要把香焚在你面前，</span><br /><span className="pl pl-1">把全牲的燔祭献在你的坛上。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 24:23; 以西结书 43:27; 以西结书 20:40–41"> <span className="pl pl-1">求耶和华降福在他的财物上，</span><br /><span className="pl pl-1">悦纳他手里所办的事。</span><br /><span className="pl pl-1">那些起来攻击他和恨恶他的人，</span><br /><span className="pl pl-1">愿你刺透他们的腰，</span><br /><span className="pl pl-1">使他们不得再起来。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="历代志下 15:2; 诗篇 91:4; 马太福音 23:37"> 论便雅悯说：<br /><span className="pl pl-1">“耶和华所亲爱的必同耶和华安然居住。</span><br /><span className="pl pl-1">耶和华终日遮蔽他，也住在他两肩之中。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="创世记 49:22–26; 弥迦书 5:7; 以赛亚书 18:4"> 论约瑟说：<br /><span className="pl pl-1">“愿他的地蒙耶和华赐福，</span><br /><span className="pl pl-1">得天上的宝物、甘露，</span><br /><span className="pl pl-1">以及地里所藏的泉水；</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 104:19; 马太福音 5:45; 诗篇 8:3"> <span className="pl pl-1">得太阳所晒熟的美果，</span><br /><span className="pl pl-1">月亮所养成的宝物；</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="哈巴谷书 3:6; 创世记 49:26; 雅各书 5:7"> <span className="pl pl-1">得上古之山的至宝，</span><br /><span className="pl pl-1">永世之岭的宝物；</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 7:35; 诗篇 24:1; 出埃及记 3:2–4"> <span className="pl pl-1">得地和其中所充满的宝物，</span><br /><span className="pl pl-1">并住荆棘中上主的喜悦。</span><br /><span className="pl pl-1">愿这些福都归于约瑟的头上，</span><br /><span className="pl pl-1">归于那与弟兄迥别之人的顶上。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 22:11; 民数记 23:22; 诗篇 44:5"> <span className="pl pl-1">他为牛群中头生的，有威严；</span><br /><span className="pl pl-1">他的角是野牛的角，</span><br /><span className="pl pl-1">用以抵触万邦，直到地极。</span><br /><span className="pl pl-1">这角是以法莲的万万，</span><br /><span className="pl pl-1">玛拿西的千千。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="创世记 49:13–15; 约书亚记 19:11; 士师记 5:14"> 论西布伦说：<br /><span className="pl pl-1">“西布伦哪，你出外可以欢喜。</span><br /><span className="pl pl-1">以萨迦啊，在你帐篷里可以快乐。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 60:5; 以赛亚书 2:3; 诗篇 4:5"> <span className="pl pl-1">他们要将列邦召到山上，</span><br /><span className="pl pl-1">在那里献公义的祭。</span><br /><span className="pl pl-1">因为他们要吸取海里的丰富，</span><br /><span className="pl pl-1">并沙中所藏的珍宝。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="创世记 49:19; 创世记 9:26–27; 历代志上 5:18–21"> 论迦得说：<br /><span className="pl pl-1">“使迦得扩张的应当称颂！</span><br /><span className="pl pl-1">迦得住如母狮，</span><br /><span className="pl pl-1">他撕裂膀臂，连头顶也撕裂。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="民数记 32:16–42; 士师记 5:11; 士师记 5:2"> <span className="pl pl-1">他为自己选择头一段地，</span><br /><span className="pl pl-1">因在那里有设立律法者的份存留。</span><br /><span className="pl pl-1">他与百姓的首领同来，</span><br /><span className="pl pl-1">他施行耶和华的公义</span><br /><span className="pl pl-1">和耶和华与以色列所立的典章。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="士师记 18:27; 约书亚记 19:47; 士师记 15:8"> 论但说：<br /><span className="pl pl-1">“但为小狮子，</span><br /><span className="pl pl-1">从巴珊跳出来。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="创世记 49:21; 诗篇 36:8; 马太福音 4:16"> 论拿弗他利说：<br /><span className="pl pl-1">“拿弗他利啊，你足沾恩惠，</span><br /><span className="pl pl-1">满得耶和华的福，</span><br /><span className="pl pl-1">可以得西方和南方为业。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="创世记 49:20; 约伯记 29:6; 罗马书 14:18"> 论亚设说：<br /><span className="pl pl-1">“愿亚设享受多子的福乐，</span><br /><span className="pl pl-1">得他弟兄的喜悦，</span><br /><span className="pl pl-1">可以把脚蘸在油中。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 41:10; 诗篇 138:3; 腓立比书 4:13"> <span className="pl pl-1">你的门闩</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“门闩”或作“鞋”。">b</a></sup><br /><span className="pl pl-1">是铜的，铁的。</span><br /><span className="pl pl-1">你的日子如何，你的力量也必如何。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 15:11; 以赛亚书 43:11–13; 耶利米书 10:6"> <span className="pl pl-1">“耶书仑哪，没有能比神的。</span><br /><span className="pl pl-1">他为帮助你，乘在天空，</span><br /><span className="pl pl-1">显其威荣，驾行穹苍。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 18:2; 诗篇 90:1–2; 诗篇 46:1"> <span className="pl pl-1">永生的神是你的居所，</span><br /><span className="pl pl-1">他永久的膀臂在你以下。</span><br /><span className="pl pl-1">他在你前面撵出仇敌，</span><br /><span className="pl pl-1">说：‘毁灭吧！’</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="民数记 23:9; 创世记 27:28; 出埃及记 33:16"> <span className="pl pl-1">以色列安然居住，</span><br /><span className="pl pl-1">雅各的本源独居五谷、新酒之地，</span><br /><span className="pl pl-1">他的天也滴甘露。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 45:17; 以赛亚书 12:2; 诗篇 115:9–11"> <span className="pl pl-1">以色列啊，你是有福的！</span><br /><span className="pl pl-1">谁像你这蒙耶和华所拯救的百姓呢？</span><br /><span className="pl pl-1">他是你的盾牌，帮助你，</span><br /><span className="pl pl-1">是你威荣的刀剑。</span><br /><span className="pl pl-1">你的仇敌必投降你，</span><br /><span className="pl pl-1">你必踏在他们的高处。”</span></span>
</div>

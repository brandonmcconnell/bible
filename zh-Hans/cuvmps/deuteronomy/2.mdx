## 自加低斯巴尼亚至撒烈溪之路

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 21:4; 申命记 1:40; 民数记 14:25"> “此后，我们转回，从红海的路往旷野去，是照耶和华所吩咐我的。我们在西珥山绕行了许多日子。</span>
<span className="v" id="v2" data-v="2"> 耶和华对我说：</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 1:6; 申命记 2:14; 申命记 2:7"> ‘你们绕行这山的日子够了，要转向北去。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 20:14–21; 出埃及记 15:15; 申命记 23:7"> 你吩咐百姓说：你们弟兄以扫的子孙住在西珥，你们要经过他们的境界。他们必惧怕你们，所以你们要分外谨慎，</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 36:8; 约书亚记 24:4; 耶利米书 27:5"> 不可与他们争战。他们的地，连脚掌可踏之处，我都不给你们，因我已将西珥山赐给以扫为业。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 7:12; 民数记 20:19; 罗马书 12:17"> 你们要用钱向他们买粮吃，也要用钱向他们买水喝。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 22:35; 尼希米记 9:21; 申命记 8:2–4"> 因为耶和华你的神在你手里所办的一切事上已赐福于你。你走这大旷野，他都知道了。这四十年，耶和华你的神常与你同在，故此你一无所缺。’</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 9:26; 士师记 11:18; 列王纪下 16:6"> 于是我们离了我们弟兄以扫子孙所住的西珥，从亚拉巴的路，经过以拉他、以旬迦别，转向摩押旷野的路去。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 19:36–37; 民数记 21:15; 民数记 21:28"> 耶和华吩咐我说：‘不可扰害摩押人，也不可与他们争战。他们的地，我不赐给你为业，因我已将亚珥赐给罗得的子孙为业。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 14:5; 申命记 2:11; 民数记 13:22"> （先前有以米人住在那里，民数众多，身体高大，像亚衲人一样。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 1:28; 民数记 13:28; 创世记 14:5"> 这以米人像亚衲人，也算为利乏音人，摩押人称他们为以米人。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 2:22; 创世记 14:6; 申命记 2:32–11"> 先前何利人也住在西珥，但以扫的子孙将他们除灭，得了他们的地，接着居住，就如以色列在耶和华赐给他为业之地所行的一样。）</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 21:12; 民数记 13:23"> 现在起来，过撒烈溪。’于是我们过了撒烈溪。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 26:64–65; 民数记 14:28–35; 申命记 1:34–35"> 自从离开加低斯巴尼亚，到过了撒烈溪的时候，共有三十八年，等那世代的兵丁都从营中灭尽，正如耶和华向他们所起的誓。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 106:26; 以赛亚书 66:14; 诗篇 32:4"> 耶和华的手也攻击他们，将他们从营中除灭，直到灭尽。</span>
</div>
</div>

## 经过摩押亚扪之地

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16"> “兵丁从民中都灭尽死亡以后，</span>
<span className="v" id="v17" data-v="17"> 耶和华吩咐我说：</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 21:23; 以赛亚书 15:1; 民数记 21:15"> ‘你今天要从摩押的境界亚珥经过，</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 2:9; 士师记 11:13–27; 历代志下 20:10"> 走近亚扪人之地，不可扰害他们，也不可与他们争战。亚扪人的地，我不赐给你们为业，因我已将那地赐给罗得的子孙为业。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 14:5"> （那地也算为利乏音人之地，先前利乏音人住在那里，亚扪人称他们为散送冥。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 27:7–8; 申命记 1:28; 申命记 2:22"> 那民众多，身体高大，像亚衲人一样，但耶和华从亚扪人面前除灭他们，亚扪人就得了他们的地，接着居住。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 36:8; 创世记 36:20–30; 申命记 2:12"> 正如耶和华从前为住西珥的以扫子孙将何利人从他们面前除灭，他们得了何利人的地，接着居住一样，直到今日。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 10:14; 约书亚记 13:3; 阿摩司书 9:7"> 从迦斐托出来的迦斐托人将先前住在乡村直到加沙的亚卫人除灭，接着居住。）</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 27:5; 但以理书 4:17; 士师记 11:18–21"> 你们起来前往，过亚嫩谷。我已将亚摩利人希实本王西宏和他的地交在你手中，你要与他争战，得他的地为业。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 11:25; 出埃及记 15:14–16; 申命记 28:10"> 从今日起，我要使天下万民听见你的名声都惊恐惧怕，且因你发颤伤恸。’</span>
</div>
</div>

## 战败希实本王西宏

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 10:5–6; 路加福音 10:10–12; 约书亚记 13:18"> “我从基底莫的旷野差遣使者去见希实本王西宏，用和睦的话说：</span>
<span className="v" id="v27" data-v="27" data-xref="士师记 11:19; 申命记 2:6; 民数记 21:21–23"> ‘求你容我从你的地经过，只走大道，不偏左右。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 20:19"> 你可以卖粮给我吃，也可以卖水给我喝，只要容我步行过去，</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 20:18; 士师记 11:17–18; 申命记 23:3–4"> 就如住西珥的以扫子孙和住亚珥的摩押人待我一样，等我过了约旦河，好进入耶和华我们神所赐给我们的地。’</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 21:23; 出埃及记 4:21; 约书亚记 11:19–20"> 但希实本王西宏不容我们从他那里经过，因为耶和华你的神使他心中刚硬，性情顽梗，为要将他交在你手中，像今日一样。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 1:8; 申命记 2:24"> 耶和华对我说：‘从此起首，我要将西宏和他的地交给你。你要得他的地为业！’</span>
<span className="v" id="v32" data-v="32" data-xref="民数记 21:23–30; 士师记 11:20–23; 诗篇 136:19"> 那时，西宏和他的众民出来攻击我们，在雅杂与我们交战。</span>
<span className="v" id="v33" data-v="33" data-xref="申命记 7:2; 约书亚记 21:44; 申命记 3:2–3"> 耶和华我们的神将他交给我们，我们就把他和他的儿子并他的众民，都击杀了。</span>
<span className="v" id="v34" data-v="34" data-xref="申命记 7:2; 撒母耳记上 15:3; 申命记 3:6"> 我们夺了他的一切城邑，将有人烟的各城，连女人带孩子，尽都毁灭，没有留下一个。</span>
<span className="v" id="v35" data-v="35" data-xref="约书亚记 8:27; 申命记 20:14; 民数记 31:9–11"> 唯有牲畜和所夺的各城，并其中的财物，都取为自己的掠物。</span>
<span className="v" id="v36" data-v="36" data-xref="约书亚记 13:9; 申命记 4:48; 申命记 3:12"> 从亚嫩谷边的亚罗珥和谷中的城，直到基列，耶和华我们的神都交给我们了，没有一座城高得使我们不能攻取的。</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 21:24; 申命记 3:16; 创世记 32:22"> 唯有亚扪人之地，凡靠近雅博河的地，并山地的城邑，与耶和华我们神所禁止我们去的地方，都没有挨近。</span>
</div>

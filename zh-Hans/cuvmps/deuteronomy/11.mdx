<span className="v" id="v7" data-v="7" data-xref="诗篇 145:4–6; 诗篇 145:12; 诗篇 150:2"> 唯有你们亲眼看见耶和华所做的一切大事。</span>

## 遵守诫命必蒙福祉

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以弗所书 6:10; 约书亚记 1:6–7; 以弗所书 3:16"> “所以，你们要守我今日所吩咐的一切诫命，使你们胆壮，能以进去，得你们所要得的那地；</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 3:8; 申命记 4:40; 申命记 6:2"> 并使你们的日子，在耶和华向你们列祖起誓应许给他们和他们后裔的地上得以长久，那是流奶与蜜之地。</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亚书 14:18"> 你要进去得为业的那地，本不像你出来的埃及地，你在那里撒种，用脚浇灌，像浇灌菜园一样。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 6:7; 申命记 8:7–9; 诗篇 65:12–13"> 你们要过去得为业的那地乃是有山有谷，雨水滋润之地，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 24:6; 诗篇 33:18; 列王纪上 9:3"> 是耶和华你神所眷顾的。从岁首到年终，耶和华你神的眼目时常看顾那地。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命记 10:12; 申命记 4:29; 申命记 6:17"> “你们若留意听从我今日所吩咐的诫命，爱耶和华你们的神，尽心、尽性侍奉他，</span>
<span className="v" id="v14" data-v="14" data-xref="雅各书 5:7; 利未记 26:4; 以西结书 34:26"> 他<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：我。">a</a></sup>必按时降秋雨春雨在你们的地上，使你们可以收藏五谷、新酒和油，</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 104:14; 申命记 6:11; 约珥书 2:19"> 也必使你吃得饱足，并使田野为你的牲畜长草。</span>
<span className="v" id="v16" data-v="16" data-xref="约伯记 31:27; 希伯来书 3:12; 希伯来书 2:1"> 你们要谨慎，免得心中受迷惑，就偏离正路，去侍奉敬拜别神。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 8:35; 申命记 6:15; 历代志下 6:26"> 耶和华的怒气向你们发作，就使天闭塞不下雨，地也不出产，使你们在耶和华所赐给你们的美地上速速灭亡。</span>
</div>
</div>

## 当恒忆耶和华之言

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 3:16; 申命记 6:6–9; 箴言 3:1"> “你们要将我这话存在心内，留在意中，系在手上为记号，戴在额上为经文，</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 6:7; 以赛亚书 38:19; 申命记 4:9–10"> 也要教训你们的儿女，无论坐在家里、行在路上，躺下、起来，都要谈论，</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 6:9"> 又要写在房屋的门框上，并城门上，</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 4:10; 箴言 3:2; 箴言 9:11"> 使你们和你们子孙的日子，在耶和华向你们列祖起誓应许给他们的地上得以增多，如天覆地的日子那样多。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 6:17; 申命记 11:13; 申命记 10:20"> 你们若留意谨守遵行我所吩咐这一切的诫命，爱耶和华你们的神，行他的道，专靠他，</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 4:38; 申命记 9:1; 申命记 7:1–2"> 他必从你们面前赶出这一切国民，就是比你们更大更强的国民，你们也要得他们的地。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 14:9; 出埃及记 23:31; 创世记 15:18–21"> 凡你们脚掌所踏之地都必归你们，从旷野和黎巴嫩，并幼发拉底大河，直到西海，都要做你们的境界。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 7:24; 出埃及记 23:27; 约书亚记 1:5"> 必无一人能在你们面前站立得住，耶和华你们的神必照他所说的，使惧怕惊恐临到你们所踏之地的居民。</span>
</div>
</div>

## 论诅与祝

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="申命记 30:1; 申命记 30:15–20; 加拉太书 3:10"> “看哪，我今日将祝福与咒诅的话都陈明在你们面前。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 1:19; 申命记 28:1–14; 以赛亚书 3:10"> 你们若听从耶和华你们神的诫命，就是我今日所吩咐你们的，就必蒙福。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 28:15–68; 罗马书 2:8–9; 加拉太书 3:10"> 你们若不听从耶和华你们神的诫命，偏离我今日所吩咐你们的道，去侍奉你们素来所不认识的别神，就必受祸。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 27:12–26; 约书亚记 8:30–35"> 及至耶和华你的神领你进入要去得为业的那地，你就要将祝福的话陈明在基利心山上，将咒诅的话陈明在以巴路山上。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 12:6; 士师记 7:1; 约书亚记 4:19"> 这二山岂不是在约旦河那边，日落之处，在住亚拉巴的迦南人之地与吉甲相对，靠近摩利橡树吗？</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 1:11; 申命记 9:1; 约书亚记 3:13–17"> 你们要过约旦河，进去得耶和华你们神所赐你们为业之地，在那地居住。</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 28:20; 申命记 12:32; 帖撒罗尼迦前书 4:1–2"> 你们要谨守遵行我今日在你们面前所陈明的一切律例、典章。</span>
</div>
</div>

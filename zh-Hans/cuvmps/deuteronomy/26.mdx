## 献初熟土产之例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 17:14; 申命记 13:9; 申命记 6:1–10"> “你进去得了耶和华你神所赐你为业之地居住，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 23:19; 出埃及记 23:16; 以西结书 44:30"> 就要从耶和华你神赐你的地上，将所收的各种初熟的土产取些来，盛在筐子里，往耶和华你神所选择要立为他名的居所去，</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 105:9–10; 申命记 19:17; 创世记 26:3"> 见当时做祭司的，对他说：‘我今日向耶和华你神明认，我已来到耶和华向我们列祖起誓应许赐给我们的地。’</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 23:19; 马太福音 5:23–24; 希伯来书 13:10–12"> 祭司就从你手里取过筐子来，放在耶和华你神的坛前。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 10:22; 创世记 46:27; 创世记 31:20"> 你要在耶和华你神面前说：‘我祖原是一个将亡的亚兰人，下到埃及寄居。他人口稀少，在那里却成了又大又强、人数很多的国民。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 1:11; 出埃及记 1:14; 出埃及记 5:23"> 埃及人恶待我们，苦害我们，将苦工加在我们身上。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 2:23–4; 以弗所书 3:20–21; 出埃及记 3:9"> 于是我们哀求耶和华我们列祖的神，耶和华听见我们的声音，看见我们所受的困苦、劳碌、欺压，</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 4:34; 申命记 5:15; 诗篇 78:12–13"> 他就用大能的手和伸出来的膀臂，并大可畏的事与神迹奇事，领我们出了埃及，</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 3:8; 诗篇 105:44; 诗篇 107:7–8"> 将我们领进这地方，把这流奶与蜜之地赐给我们。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 26:2; 申命记 18:4; 启示录 22:9"> 耶和华啊，现在我把你所赐给我地上初熟的土产奉了来。’随后你要把筐子放在耶和华你神面前，向耶和华你的神下拜。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 16:11; 申命记 12:7; 腓立比书 4:4"> 你和利未人，并在你们中间寄居的，要因耶和华你神所赐你和你家的一切福分欢乐。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="利未记 27:30; 民数记 18:24; 腓立比书 4:18–19"> “每逢三年，就是十分取一之年，你取完了一切土产的十分之一，要分给利未人和寄居的与孤儿寡妇，使他们在你城中可以吃得饱足。</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 119:176; 诗篇 119:153; 诗篇 119:141"> 你又要在耶和华你神面前说：‘我已将圣物从我家里拿出来，给了利未人和寄居的与孤儿寡妇，是照你所吩咐我的一切命令。你的命令我都没有违背，也没有忘记。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 7:20; 利未记 21:11; 何西阿书 9:4"> 我守丧的时候，没有吃这圣物；不洁净的时候，也没有拿出来，又没有为死人送去。我听从了耶和华我神的话，都照你所吩咐的行了。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 63:15; 撒迦利亚书 2:13; 耶利米书 31:23"> 求你从天上你的圣所垂看，赐福给你的百姓以色列与你所赐给我们的地，就是你向我们列祖起誓赐我们流奶与蜜之地。’</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命记 12:1; 约翰福音 14:15; 约翰一书 5:2–3"> “耶和华你的神今日吩咐你行这些律例、典章，所以你要尽心、尽性谨守遵行。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 24:7; 以赛亚书 12:2; 哥林多前书 6:19–20"> 你今日认耶和华为你的神，应许遵行他的道，谨守他的律例、诫命、典章，听从他的话。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 7:6; 申命记 14:2; 申命记 28:9"> 耶和华今日照他所应许你的，也认你为他的子民，使你谨守他的一切诫命，</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前书 2:9; 申命记 7:6; 申命记 28:1"> 又使你得称赞、美名、尊荣，超乎他所造的万民之上，并照他所应许的使你归耶和华你神为圣洁的民。”</span>
</div>

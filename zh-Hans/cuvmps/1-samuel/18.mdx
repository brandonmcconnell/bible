<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 20:17; 箴言 18:24; 撒母耳记上 18:3"> 大卫对扫罗说完了话，约拿单的心与大卫的心深相契合，约拿单爱大卫，如同爱自己的性命。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 17:15; 撒母耳记上 16:21–23"> 那日扫罗留住大卫，不容他再回父家。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 20:8–17; 撒母耳记上 20:42; 撒母耳记下 21:7"> 约拿单爱大卫如同爱自己的性命，就与他结盟。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 41:42; 路加福音 15:22; 以斯帖记 6:8–9"> 约拿单从身上脱下外袍，给了大卫，又将战衣、刀、弓、腰带都给了他。</span>

## 扫罗立之为战士长

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 18:30; 撒母耳记上 18:14–15; 歌罗西书 4:5"> 扫罗无论差遣大卫往何处去，他都做事精明。扫罗就立他做战士长，众百姓和扫罗的臣仆无不喜悦。</span>
</div>

## 妇女赞大卫之勇扫罗不悦

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 15:20; 士师记 11:34; 诗篇 68:25"> 大卫打死了那非利士人，同众人回来的时候，妇女们从以色列各城里出来，欢欢喜喜，打鼓击磬，歌唱跳舞，迎接扫罗王。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 21:11; 撒母耳记上 29:5; 出埃及记 15:21"> 众妇女舞蹈唱和，说：“扫罗杀死千千，大卫杀死万万。”</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 15:28; 箴言 13:10; 雅各书 4:5"> 扫罗甚发怒，不喜悦这话，就说：“将万万归大卫，千千归我，只剩下王位没有给他了！”</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 7:22; 创世记 31:2; 马太福音 20:15"> 从这日起，扫罗就怒视大卫。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 19:9; 帖撒罗尼迦后书 2:11; 列王纪上 18:29"> 次日，从神那里来的恶魔大大降在扫罗身上，他就在家中胡言乱语。大卫照常弹琴，扫罗手里拿着枪。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 20:33; 以赛亚书 54:17; 路加福音 4:30"> 扫罗把枪一抡，心里说：“我要将大卫刺透，钉在墙上。”大卫躲避他两次。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 18:15; 撒母耳记上 18:29; 撒母耳记上 16:13–14"> 扫罗惧怕大卫，因为耶和华离开自己，与大卫同在。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 5:2; 诗篇 121:8; 撒母耳记上 18:16–17"> 所以扫罗使大卫离开自己，立他为千夫长，他就领兵出入。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 39:23; 马太福音 28:20; 撒母耳记上 16:18"> 大卫做事无不精明，耶和华也与他同在。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各书 3:17; 歌罗西书 4:5; 雅各书 1:5"> 扫罗见大卫做事精明，就甚怕他。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 18:5; 民数记 27:17; 列王纪上 3:7"> 但以色列和犹大众人都爱大卫，因为他领他们出入。</span>
</div>
</div>

## 扫罗以女米拉许大卫

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 17:25; 撒母耳记上 25:28; 撒母耳记上 18:25"> 扫罗对大卫说：“我将大女儿米拉给你为妻，只要你为我奋勇，为耶和华争战。”扫罗心里说：“我不好亲手害他，要藉非利士人的手害他。”</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 7:18; 撒母耳记上 9:21; 撒母耳记上 18:23"> 大卫对扫罗说：“我是谁，我是什么出身，我父家在以色列中是何等的家，岂敢做王的女婿呢？”</span>
<span className="v" id="v19" data-v="19" data-xref="士师记 7:22; 撒母耳记下 21:8; 士师记 14:20"> 扫罗的女儿米拉到了当给大卫的时候，扫罗却给了米何拉人亚得列为妻。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 18:28"> 扫罗的次女米甲爱大卫。有人告诉扫罗，扫罗就喜悦。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 18:17; 出埃及记 10:7; 耶利米书 9:8"> 扫罗心里说：“我将这女儿给大卫，做他的网罗，好藉非利士人的手害他。”所以扫罗对大卫说：“你今日可以第二次做我的女婿。”</span>
</div>
</div>

## 扫罗畏大卫

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="诗篇 36:1–3; 诗篇 55:21; 撒母耳记下 13:28–29"> 扫罗吩咐臣仆说：“你们暗中对大卫说：‘王喜悦你，王的臣仆也都喜爱你，所以你当做王的女婿。’”</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 119:141; 箴言 14:20; 传道书 9:15–16"> 扫罗的臣仆就照这话说给大卫听。大卫说：“你们以为做王的女婿是一件小事吗？我是贫穷卑微的人。”</span>
<span className="v" id="v24" data-v="24"> 扫罗的臣仆回奏说：“大卫所说的如此如此。”</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 34:12; 撒母耳记上 18:17; 撒母耳记上 14:24"> 扫罗说：“你们要对大卫这样说：‘王不要什么聘礼，只要一百非利士人的阳皮，好在王的仇敌身上报仇。’”扫罗的意思要使大卫丧在非利士人的手里。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记上 18:21"> 扫罗的臣仆将这话告诉大卫，大卫就欢喜做王的女婿。日期还没有到，</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记下 3:14; 士师记 14:19; 撒母耳记上 18:13"> 大卫和跟随他的人起身前往，杀了二百非利士人，将阳皮满数交给王，为要做王的女婿。于是扫罗将女儿米甲给大卫为妻。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 24:20; 撒母耳记上 26:25; 创世记 37:8–11"> 扫罗见耶和华与大卫同在，又知道女儿米甲爱大卫，</span>
<span className="v" id="v29" data-v="29" data-xref="传道书 4:4; 约翰福音 11:53; 雅各书 2:19"> 就更怕大卫，常做大卫的仇敌。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 18:5; 撒母耳记下 11:1; 彼得前书 2:4"> 每逢非利士军长出来打仗，大卫比扫罗的臣仆做事精明，因此他的名被人尊重。</span>
</div>
</div>

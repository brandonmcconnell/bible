## 大卫救基伊拉

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 15:44; 弥迦书 6:15; 尼希米记 3:17–18"> 有人告诉大卫说，非利士人攻击基伊拉，抢夺禾场，</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 23:4; 撒母耳记下 5:19; 撒母耳记下 5:23"> 所以大卫求问耶和华说：“我去攻打那些非利士人，可以不可以？”耶和华对大卫说：“你可以去攻打非利士人，拯救基伊拉。”</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 12:5; 诗篇 11:1; 撒母耳记上 23:15"> 跟随大卫的人对他说：“我们在犹大地这里尚且惧怕，何况往基伊拉去攻打非利士人的军旅呢？”</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 7:7; 约书亚记 8:7; 列王纪下 3:18"> 大卫又求问耶和华。耶和华回答说：“你起身下基伊拉去，我必将非利士人交在你手里。”</span>
<span className="v" id="v5" data-v="5"> 大卫和跟随他的人往基伊拉去，与非利士人打仗，大大杀败他们，又夺获他们的牲畜。这样，大卫救了基伊拉的居民。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 22:20; 撒母耳记上 14:3; 撒母耳记上 14:18"> 亚希米勒的儿子亚比亚他逃到基伊拉见大卫的时候，手里拿着以弗得。</span>
</div>
</div>

## 扫罗追索大卫

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 24:4–6; 约伯记 20:5; 撒母耳记上 26:8–9"> 有人告诉扫罗说：“大卫到了基伊拉。”扫罗说：“他进了有门有闩的城，困闭在里头，这是神将他交在我手里了。”</span>
<span className="v" id="v8" data-v="8"> 于是扫罗招聚众民，要下去攻打基伊拉城，围困大卫和跟随他的人。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 30:7; 撒母耳记上 23:6; 民数记 27:21"> 大卫知道扫罗设谋害他，就对祭司亚比亚他说：“将以弗得拿过来。”</span>
</div>
</div>

## 大卫去基伊拉

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="罗马书 3:15–16; 撒母耳记上 23:8; 创世记 18:24"> 大卫祷告说：“耶和华以色列的神啊，你仆人听真了，扫罗要往基伊拉来，为我的缘故灭城。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 33:3; 诗篇 50:15; 马太福音 7:7–8"> 基伊拉人将我交在扫罗手里不交？扫罗照着你仆人所听的话下来不下来？耶和华以色列的神啊，求你指示仆人。”耶和华说：“扫罗必下来。”</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 23:20; 诗篇 31:8; 诗篇 62:1"> 大卫又说：“基伊拉人将我和跟随我的人交在扫罗手里不交？”耶和华说：“必交出来。”</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 22:2; 撒母耳记上 25:13; 撒母耳记上 30:9–10"> 大卫和跟随他的约有六百人，就起身出了基伊拉，往他们所能往的地方去。有人告诉扫罗，大卫离开基伊拉逃走，于是扫罗不出来了。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 54:3–4; 诗篇 32:7; 约书亚记 15:24"> 大卫住在旷野的山寨里，常在西弗旷野的山地。扫罗天天寻索大卫，神却不将大卫交在他手里。</span>
</div>
</div>

## 复与约拿单立约

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15"> 大卫知道扫罗出来寻索他的命，那时他住在西弗旷野的树林里。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 35:3–4; 希伯来书 12:12–13; 约伯记 4:3–4"> 扫罗的儿子约拿单起身，往那树林里去见大卫，使他倚靠神得以坚固，</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 20:31; 撒母耳记上 24:20; 使徒行传 28:16"> 对他说：“不要惧怕，我父扫罗的手必不加害于你。你必做以色列的王，我也做你的宰相。这事我父扫罗知道了。”</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 21:7; 撒母耳记上 20:42; 撒母耳记上 18:3"> 于是二人在耶和华面前立约。大卫仍住在树林里，约拿单回家去了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 26:1; 撒母耳记上 26:3; 诗篇 54:1–7"> 西弗人上到基比亚见扫罗，说：“大卫不是在我们那里的树林里山寨中，旷野南边的哈基拉山藏着吗？</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 23:12; 箴言 29:26; 箴言 11:23"> 王啊，请你随你的心愿下来，我们必亲自将他交在王的手里。”</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 22:8; 以赛亚书 66:5; 弥迦书 3:11"> 扫罗说：“愿耶和华赐福于你们，因你们顾恤我。</span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 5:13"> 请你们回去，再确实查明他的住处和行踪，是谁看见他在那里，因为我听见人说他甚狡猾。</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 3:15–16; 马可福音 14:1; 民数记 10:36"> 所以要看准他藏匿的地方，回来据实地告诉我，我就与你们同去。他若在犹大的境内，我必从千门万户中搜出他来。”</span>
</div>
</div>

## 扫罗追大卫于玛云野

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒母耳记上 25:2; 约书亚记 15:55"> 西弗人就起身，在扫罗以先往西弗去。大卫和跟随他的人却在玛云旷野南边的亚拉巴。</span>
<span className="v" id="v25" data-v="25" data-xref="士师记 15:8; 撒母耳记上 23:28"> 扫罗和跟随他的人去寻找大卫。有人告诉大卫，他就下到磐石，住在玛云的旷野。扫罗听见，便在玛云的旷野追赶大卫。</span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 17:9; 哥林多后书 1:8; 诗篇 140:1–9"> 扫罗在山这边走，大卫和跟随他的人在山那边走。大卫急忙躲避扫罗，因为扫罗和跟随他的人，四面围住大卫和跟随他的人，要拿获他们。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 19:9; 诗篇 116:3; 申命记 32:36"> 忽有使者来报告扫罗说：“非利士人犯境抢掠，请王快快回去。”</span>
<span className="v" id="v28" data-v="28"> 于是扫罗不追赶大卫，回去攻打非利士人。因此那地方名叫西拉哈玛希罗结。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志下 20:2; 约书亚记 15:62; 以西结书 47:10"> 大卫从那里上去，住在隐基底的山寨里。</span>
</div>
</div>

## 撒母耳自白于民众

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 10:24; 撒母耳记上 11:14–15; 撒母耳记上 10:1"> 撒母耳对以色列众人说：“你们向我所求的，我已应允了，为你们立了一个王。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 8:5; 撒母耳记上 8:1; 撒母耳记上 8:20"> 现在有这王在你们前面行。我已年老发白，我的儿子都在你们这里。我从幼年直到今日都在你们前面行。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 20:33; 民数记 16:15; 彼得前书 5:2"> 我在这里，你们要在耶和华和他的受膏者面前给我作见证：我夺过谁的牛，抢过谁的驴，欺负过谁，虐待过谁，从谁手里受过贿赂因而眼瞎呢？若有，我必偿还。”</span>
<span className="v" id="v4" data-v="4" data-xref="但以理书 6:4; 诗篇 37:5–6; 约翰三书 1:12"> 众人说：“你未曾欺负我们，虐待我们，也未曾从谁手里受过什么。”</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 22:4; 使徒行传 24:20; 使徒行传 23:9"> 撒母耳对他们说：“你们在我手里没有找着什么，有耶和华和他的受膏者今日为证。”他们说：“愿他为证。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="弥迦书 6:4; 出埃及记 6:26; 诗篇 99:6"> 撒母耳对百姓说：“从前立摩西、亚伦，又领你们列祖出埃及地的是耶和华。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 1:18; 弥迦书 6:1–5; 使徒行传 17:3"> 现在你们要站住，等我在耶和华面前对你们讲论耶和华向你们和你们列祖所行一切公义的事。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 4:14–16; 出埃及记 2:23–24; 诗篇 78:54–55"> 从前雅各到了埃及，后来你们列祖呼求耶和华，耶和华就差遣摩西、亚伦领你们列祖出埃及，使他们在这地方居住。</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 13:1; 士师记 10:7; 士师记 3:12"> 他们却忘记耶和华他们的神，他就把他们付于夏琐将军西西拉的手里，和非利士人并摩押王的手里，于是这些人常来攻击他们。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 10:10; 士师记 2:13; 士师记 3:7"> 他们就呼求耶和华说：‘我们离弃耶和华，侍奉巴力和亚斯她录，是有罪了。现在求你救我们脱离仇敌的手，我们必侍奉你。’</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 6:32; 士师记 4:6; 士师记 8:35"> 耶和华就差遣耶路巴力、比但、耶弗他、撒母耳救你们脱离四围仇敌的手，你们才安然居住。</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 8:23; 撒母耳记上 8:5–7; 创世记 17:7"> 你们见亚扪人的王拿辖来攻击你们，就对我说：‘我们定要一个王治理我们。’其实耶和华你们的神是你们的王。</span>
<span className="v" id="v13" data-v="13" data-xref="何西阿书 13:11; 撒母耳记上 10:24; 撒母耳记上 8:5"> 现在，你们所求所选的王在这里。看哪，耶和华已经为你们立王了！</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 24:14; 申命记 28:1–14; 诗篇 81:12–15"> 你们若敬畏耶和华，侍奉他，听从他的话，不违背他的命令，你们和治理你们的王也都顺从耶和华你们的神，就好了。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 24:20; 以赛亚书 1:20; 以赛亚书 3:11"> 倘若不听从耶和华的话，违背他的命令，耶和华的手必攻击你们，像从前攻击你们列祖一样。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 14:13; 出埃及记 14:31; 撒母耳记上 12:7"> 现在你们要站住，看耶和华在你们眼前要行一件大事。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 8:7; 箴言 26:1; 撒母耳记上 7:9–10"> 这不是割麦子的时候吗？我求告耶和华，他必打雷降雨，使你们又知道又看出，你们求立王的事是在耶和华面前犯大罪了。”</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 14:31; 以斯拉记 10:9; 诗篇 106:12–13"> 于是撒母耳求告耶和华，耶和华就在这日打雷降雨，众民便甚惧怕耶和华和撒母耳。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及记 9:28; 约翰一书 5:16; 撒母耳记上 12:23"> 众民对撒母耳说：“求你为仆人们祷告耶和华你的神，免得我们死亡，因为我们求立王的事正是罪上加罪了。”</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 11:16; 约书亚记 23:6; 彼得前书 3:16"> 撒母耳对百姓说：“不要惧怕！你们虽然行了这恶，却不要偏离耶和华，只要尽心侍奉他。</span>
<span className="v" id="v21" data-v="21" data-xref="哈巴谷书 2:18; 耶利米书 10:15; 耶利米书 16:19"> 若偏离耶和华，去顺从那不能救人的虚神，是无益的。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 7:7–8; 申命记 14:2; 诗篇 106:8"> 耶和华既喜悦选你们做他的子民，就必因他的大名不撇弃你们。</span>
<span className="v" id="v23" data-v="23" data-xref="歌罗西书 1:9; 罗马书 1:9; 提摩太后书 1:3"> 至于我，断不停止为你们祷告，以致得罪耶和华。我必以善道正路指教你们。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 10:21; 箴言 1:7; 以赛亚书 5:12"> 只要你们敬畏耶和华，诚诚实实地尽心侍奉他，想念他向你们所行的事何等大。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 24:20; 何西阿书 10:3; 撒母耳记上 31:1–5"> 你们若仍然作恶，你们和你们的王必一同灭亡。”</span>
</div>

## 歌利亚狂语索战

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 15:35; 历代志下 28:18; 历代志上 11:13"> 非利士人招聚他们的军旅，要来争战，聚集在属犹大的梭哥，安营在梭哥和亚西加中间的以弗大悯。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 21:9; 撒母耳记上 17:19"> 扫罗和以色列人也聚集，在以拉谷安营，摆列队伍，要与非利士人打仗。</span>
<span className="v" id="v3" data-v="3"> 非利士人站在这边山上，以色列人站在那边山上，当中有谷。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 11:22; 撒母耳记下 21:16–22; 历代志上 20:4–8"> 从非利士营中出来一个讨战的人，名叫歌利亚，是迦特人，身高六肘零一虎口；</span>
<span className="v" id="v5" data-v="5"> 头戴铜盔，身穿铠甲，甲重五千舍客勒；</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 17:45; 历代志下 9:15; 列王纪上 10:16"> 腿上有铜护膝，两肩之中背负铜戟；</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 21:19; 撒母耳记上 17:41; 历代志上 11:23"> 枪杆粗如织布的机轴，铁枪头重六百舍客勒。有一个拿盾牌的人在他前面走。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 8:17; 历代志上 21:3; 撒母耳记上 17:26"> 歌利亚对着以色列的军队站立，呼叫说：“你们出来摆列队伍做什么呢？我不是非利士人吗？你们不是扫罗的仆人吗？可以从你们中间拣选一人，使他下到我这里来。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 11:1"> 他若能与我战斗，将我杀死，我们就做你们的仆人。我若胜了他，将他杀死，你们就做我们的仆人，服侍我们。”</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 17:25–26; 撒母耳记上 17:45; 撒母耳记上 17:36"> 那非利士人又说：“我今日向以色列人的军队骂阵。你们叫一个人出来，与我战斗。”</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 1:9; 申命记 31:8; 箴言 28:1"> 扫罗和以色列众人听见非利士人的这些话，就惊惶，极其害怕。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 16:10–11; 创世记 35:19; 撒母耳记上 16:18"> 大卫是犹大伯利恒的以法他人耶西的儿子，耶西有八个儿子。当扫罗的时候，耶西已经老迈。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 2:13; 撒母耳记下 21:21; 撒母耳记上 17:28"> 耶西的三个大儿子跟随扫罗出征，这出征的三个儿子，长子名叫以利押，次子名叫亚比拿达，三子名叫沙玛。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 16:11; 创世记 25:23"> 大卫是最小的。那三个大儿子跟随扫罗。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 16:11; 撒母耳记上 16:19–23"> 大卫有时离开扫罗，回伯利恒放他父亲的羊。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 4:2; 路加福音 4:2"> 那非利士人早晚都出来站着，如此四十日。</span>
</div>
</div>

## 大卫闻歌利亚言则愤

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 25:18; 撒母耳记下 17:28; 路得记 2:14"> 一日，耶西对他儿子大卫说：“你拿一伊法烘了的穗子和十个饼，速速地送到营里去，交给你哥哥们。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 37:14; 撒母耳记上 16:20; 撒母耳记下 17:29"> 再拿这十块奶饼，送给他们的千夫长，且问你哥哥们好，向他们要一封信来。”</span>
<span className="v" id="v19" data-v="19"> 扫罗与大卫的三个哥哥和以色列众人，在以拉谷与非利士人打仗。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 26:5; 路加福音 19:43; 以弗所书 6:1–2"> 大卫早晨起来，将羊交托一个看守的人，照着他父亲所吩咐的话，带着食物去了。到了辎重营，军兵刚出到战场，呐喊要战。</span>
<span className="v" id="v21" data-v="21"> 以色列人和非利士人都摆列队伍，彼此相对。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 10:5–6; 士师记 18:15; 以赛亚书 10:28"> 大卫把他带来的食物留在看守物件人的手下，跑到战场，问他哥哥们安。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 17:8–10"> 与他们说话的时候，那讨战的，就是属迦特的非利士人歌利亚，从非利士队中出来，说从前所说的话。大卫都听见了。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记上 13:6–7; 利未记 26:36; 以赛亚书 7:2"> 以色列众人看见那人，就逃跑，极其害怕。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 15:16; 启示录 2:7; 启示录 3:12"> 以色列人彼此说：“这上来的人你看见了吗？他上来是要向以色列人骂阵。若有能杀他的，王必赏赐他大财，将自己的女儿给他为妻，并在以色列人中免他父家纳粮当差。”</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 5:26; 撒母耳记上 11:2; 撒母耳记上 14:6"> 大卫问站在旁边的人说：“有人杀这非利士人，除掉以色列人的耻辱，怎样待他呢？这未受割礼的非利士人是谁呢？竟敢向永生神的军队骂阵吗？”</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 17:25"> 百姓照先前的话回答他说：“有人能杀这非利士人，必如此如此待他。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马太福音 10:36; 创世记 37:11; 箴言 18:19"> 大卫的长兄以利押听见大卫与他们所说的话，就向他发怒，说：“你下来做什么呢？在旷野的那几只羊，你交托了谁呢？我知道你的骄傲和你心里的恶意，你下来特为要看争战！”</span>
<span className="v" id="v29" data-v="29" data-xref="彼得前书 3:9; 哥林多前书 2:15; 箴言 15:1"> 大卫说：“我做了什么呢？我来岂没有缘故吗？”</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 17:26–27"> 大卫就离开他转向别人，照先前的话而问。百姓仍照先前的话回答他。</span>
</div>
</div>

## 大卫自请出战

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="箴言 22:29"> 有人听见大卫所说的话，就告诉了扫罗，扫罗便打发人叫他来。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 16:18; 申命记 20:1–3; 诗篇 3:6"> 大卫对扫罗说：“人都不必因那非利士人胆怯，你的仆人要去与那非利士人战斗。”</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 13:31; 申命记 9:2; 启示录 13:4"> 扫罗对大卫说：“你不能去与那非利士人战斗，因为你年纪太轻，他自幼就做战士。”</span>
<span className="v" id="v34" data-v="34"> 大卫对扫罗说：“你仆人为父亲放羊，有时来了狮子，有时来了熊，从群中衔一只羊羔去，</span>
<span className="v" id="v35" data-v="35" data-xref="阿摩司书 3:12; 提摩太后书 4:17–18; 但以理书 6:22"> 我就追赶它，击打它，将羊羔从它口中救出来。它起来要害我，我就揪着它的胡子，将它打死。</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳记上 17:10; 使徒行传 5:38–39; 罗马书 2:28–29"> 你仆人曾打死狮子和熊，这未受割礼的非利士人向永生神的军队骂阵，也必像狮子和熊一般。”</span>
<span className="v" id="v37" data-v="37" data-xref="提摩太后书 4:17–18; 诗篇 138:7–8; 哥林多后书 1:9–10"> 大卫又说：“耶和华救我脱离狮子和熊的爪，也必救我脱离这非利士人的手。”扫罗对大卫说：“你可以去吧，耶和华必与你同在。”</span>
<span className="v" id="v38" data-v="38"> 扫罗就把自己的战衣给大卫穿上，将铜盔给他戴上，又给他穿上铠甲。</span>
<span className="v" id="v39" data-v="39" data-xref="撒迦利亚书 4:6; 哥林多后书 10:4–5; 何西阿书 1:7"> 大卫把刀挎在战衣外，试试能走不能走。因为素来没有穿惯，就对扫罗说：“我穿戴这些不能走，因为素来没有穿惯。”于是摘脱了。</span>
<span className="v" id="v40" data-v="40" data-xref="哥林多前书 1:27–29; 马太福音 10:10; 士师记 15:15–16"> 他手中拿杖，又在溪中挑选了五块光滑石子，放在袋里，就是牧人带的囊里。手中拿着甩石的机弦，就去迎那非利士人。</span>
</div>
</div>

## 击杀歌利亚

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41"> 非利士人也渐渐地迎着大卫来，拿盾牌的走在前头。</span>
<span className="v" id="v42" data-v="42" data-xref="撒母耳记上 16:12; 撒母耳记上 17:33; 诗篇 123:3–4"> 非利士人观看，见了大卫，就藐视他，因为他年轻，面色光红，容貌俊美。</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳记下 9:8; 撒母耳记下 3:8; 撒母耳记上 24:14"> 非利士人对大卫说：“你拿杖到我这里来，我岂是狗呢？”非利士人就指着自己的神咒诅大卫。</span>
<span className="v" id="v44" data-v="44" data-xref="以西结书 28:9–10; 箴言 18:12; 列王纪上 20:10–11"> 非利士人又对大卫说：“来吧！我将你的肉给空中的飞鸟、田野的走兽吃。”</span>
<span className="v" id="v45" data-v="45" data-xref="哥林多后书 10:4; 历代志下 32:8; 哥林多后书 3:5"> 大卫对非利士人说：“你来攻击我，是靠着刀枪和铜戟。我来攻击你，是靠着万军之耶和华的名，就是你所怒骂带领以色列军队的神。</span>
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 52:10; 约书亚记 4:24; 列王纪下 19:19"> 今日耶和华必将你交在我手里。我必杀你，斩你的头，又将非利士军兵的尸首给空中的飞鸟、地上的野兽吃，使普天下的人都知道以色列中有神；</span>
<span className="v" id="v47" data-v="47" data-xref="诗篇 44:6–7; 撒迦利亚书 4:6; 何西阿书 1:7"> 又使这众人知道，耶和华使人得胜不是用刀用枪，因为争战的胜败全在乎耶和华。他必将你们交在我们手里。”</span>
<span className="v" id="v48" data-v="48" data-xref="箴言 28:1; 诗篇 27:1"> 非利士人起身，迎着大卫前来。大卫急忙迎着非利士人，往战场跑去。</span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前书 1:27–28; 列王纪下 9:24; 列王纪上 22:34"> 大卫用手从囊中掏出一块石子来，用机弦甩去，打中非利士人的额，石子进入额内，他就仆倒，面伏于地。</span>
</div>
</div>

## 非利士人溃败

<div className="bt">
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="士师记 15:15; 撒母耳记上 17:39; 撒母耳记上 23:21"> 这样，大卫用机弦甩石，胜了那非利士人，打死他，大卫手中却没有刀。</span>
<span className="v" id="v51" data-v="51" data-xref="希伯来书 11:34; 撒母耳记上 21:9; 撒母耳记下 23:21"> 大卫跑去，站在非利士人身旁，将他的刀从鞘中拔出来，杀死他，割了他的头。非利士众人看见他们讨战的勇士死了，就都逃跑。</span>
<span className="v" id="v52" data-v="52" data-xref="约书亚记 15:11; 约书亚记 15:33–36; 约书亚记 15:45–46"> 以色列人和犹大人便起身呐喊，追赶非利士人，直到迦特<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：该。">a</a></sup>和以革伦的城门。被杀的非利士人倒在沙拉音的路上，直到迦特和以革伦。</span>
<span className="v" id="v53" data-v="53" data-xref="耶利米书 4:20; 列王纪下 7:7–16; 耶利米书 30:16"> 以色列人追赶非利士人回来，就夺了他们的营盘。</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及记 16:33; 约书亚记 4:7–8; 撒母耳记上 21:9"> 大卫将那非利士人的头拿到耶路撒冷，却将他军装放在自己的帐篷里。</span>
</div>
</div>

## 押尼珥引大卫见扫罗

<div className="bt">
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="撒母耳记上 16:21–22; 撒母耳记上 17:58"> 扫罗看见大卫去攻击非利士人，就问元帅押尼珥说：“押尼珥啊，那少年人是谁的儿子？”押尼珥说：“我敢在王面前起誓，我不知道。”</span>
<span className="v" id="v56" data-v="56"> 王说：“你可以问问那幼年人是谁的儿子。”</span>
<span className="v" id="v57" data-v="57" data-xref="撒母耳记上 17:54"> 大卫打死非利士人回来，押尼珥领他到扫罗面前，他手中拿着非利士人的头。</span>
<span className="v" id="v58" data-v="58" data-xref="撒母耳记上 17:12; 撒母耳记上 16:18–19"> 扫罗问他说：“少年人哪，你是谁的儿子？”大卫说：“我是你仆人伯利恒人耶西的儿子。”</span>
</div>

## 撒母耳诣耶西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 9:1; 撒母耳记上 15:23; 诗篇 78:68–71"> 耶和华对撒母耳说：“我既厌弃扫罗做以色列的王，你为他悲伤要到几时呢？你将膏油盛满了角，我差遣你往伯利恒人耶西那里去。因为我在他众子之内，预定一个做王的。”</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 9:12; 撒母耳记上 20:29; 马太福音 10:16"> 撒母耳说：“我怎能去呢？扫罗若听见，必要杀我。”耶和华说：“你可以带一只牛犊去，就说：‘我来是要向耶和华献祭。’”</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 9:16; 撒母耳记上 16:12–13; 撒母耳记下 15:11"> 你要请耶西来吃祭肉，我就指示你所当行的事。我所指给你的人，你要膏他。”</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 2:13; 历代志上 12:17–18; 撒母耳记上 21:1"> 撒母耳就照耶和华的话去行。到了伯利恒，那城里的长老都战战兢兢地出来迎接他，问他说：“你是为平安来的吗？”</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 3:5; 利未记 20:7–8; 出埃及记 19:10"> 他说：“为平安来的，我是给耶和华献祭。你们当自洁，来与我同吃祭肉。”撒母耳就使耶西和他众子自洁，请他们来吃祭肉。</span>
</div>
</div>

## 撒母耳膏大卫

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 17:13; 历代志上 2:13; 撒母耳记上 17:22"> 他们来的时候，撒母耳看见以利押，就心里说：“耶和华的受膏者必定在他面前。”</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 7:24; 耶利米书 17:10; 路加福音 16:15"> 耶和华却对撒母耳说：“不要看他的外貌和他身材高大，我不拣选他。因为耶和华不像人看人，人是看外貌，耶和华是看内心。”</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 17:13; 历代志上 2:13"> 耶西叫亚比拿达从撒母耳面前经过，撒母耳说：“耶和华也不拣选他。”</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 17:13; 历代志上 2:13; 撒母耳记下 13:3"> 耶西又叫沙玛从撒母耳面前经过，撒母耳说：“耶和华也不拣选他。”</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 2:13–15"> 耶西叫他七个儿子都从撒母耳面前经过，撒母耳说：“这都不是耶和华所拣选的。”</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 78:70–71; 撒母耳记下 7:8; 撒母耳记下 13:3"> 撒母耳对耶西说：“你的儿子都在这里吗？”他回答说：“还有个小的，现在放羊。”撒母耳对耶西说：“你打发人去叫他来。他若不来，我们必不坐席。”</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米哀歌 4:7; 诗篇 89:19–20; 雅歌 5:10"> 耶西就打发人去叫了他来。他面色光红，双目清秀，容貌俊美。耶和华说：“这就是他，你起来膏他。”</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 10:6; 希伯来书 1:9; 约翰福音 3:34"> 撒母耳就用角里的膏油，在他诸兄中膏了他。从这日起，耶和华的灵就大大感动大卫。撒母耳起身回拉玛去了。</span>
</div>
</div>

## 扫罗召大卫鼓琴驱魔

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="诗篇 51:11; 撒母耳记上 18:12; 士师记 9:23"> 耶和华的灵离开扫罗，有恶魔从耶和华那里来扰乱他。</span>
<span className="v" id="v15" data-v="15"> 扫罗的臣仆对他说：“现在有恶魔从神那里来扰乱你。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 3:15; 列王纪上 10:8; 撒母耳记上 19:9"> 我们的主可以吩咐面前的臣仆，找一个善于弹琴的来，等神那里来的恶魔临到你身上的时候，使他用手弹琴，你就好了。”</span>
<span className="v" id="v17" data-v="17"> 扫罗对臣仆说：“你们可以为我找一个善于弹琴的，带到我这里来。”</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 3:19; 创世记 39:23; 创世记 39:2"> 其中有一个少年人说：“我曾见伯利恒城耶西的一个儿子善于弹琴，是大有勇敢的战士，说话合宜，容貌俊美，耶和华也与他同在。”</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 16:11; 撒母耳记上 17:15; 诗篇 78:70–72"> 于是扫罗差遣使者去见耶西，说：“请你打发你放羊的儿子大卫到我这里来。”</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 10:27; 箴言 18:16; 撒母耳记上 17:18"> 耶西就把几个饼和一皮袋酒，并一只山羊羔，都驮在驴上，交给他儿子大卫，送于扫罗。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 41:46; 箴言 22:29; 诗篇 146:3"> 大卫到了扫罗那里，就侍立在扫罗面前。扫罗甚喜爱他，他就做了扫罗拿兵器的人。</span>
<span className="v" id="v22" data-v="22"> 扫罗差遣人去见耶西，说：“求你容大卫侍立在我面前，因为他在我眼前蒙了恩。”</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 16:14–16; 撒母耳记上 18:10–11; 路加福音 11:24–26"> 从神那里来的恶魔临到扫罗身上的时候，大卫就拿琴，用手而弹，扫罗便舒畅爽快，恶魔离了他。</span>
</div>
</div>

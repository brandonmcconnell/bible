## 许愿之例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 6:2; 撒母耳记上 1:28; 士师记 11:30–31"> “你晓谕以色列人说：人还特许的愿，被许的人要按你所估的价值归给耶和华。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 30:13; 利未记 27:25; 民数记 18:16"> 你估定的，从二十岁到六十岁的男人，要按圣所的平，估定价银五十舍客勒，</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 27:9–10; 撒迦利亚书 11:12–13; 马太福音 26:15"> 若是女人，你要估定三十舍客勒。</span>
<span className="v" id="v5" data-v="5"> 若是从五岁到二十岁，男子你要估定二十舍客勒，女子估定十舍客勒。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 3:40–43; 民数记 18:14–16"> 若是从一月到五岁，男子你要估定五舍客勒，女子估定三舍客勒。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 90:10"> 若是从六十岁以上，男人你要估定十五舍客勒，女人估定十舍客勒。</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 14:7; 利未记 14:21–22; 路加福音 21:1–4"> 他若贫穷，不能照你所估定的价，就要把他带到祭司面前，祭司要按许愿人的力量估定他的价。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> “所许的若是牲畜，就是人献给耶和华为供物的，凡这一类献给耶和华的，都要成为圣。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 27:15–33; 雅各书 1:8"> 人不可改换，也不可更换，或是好的换坏的，或是坏的换好的。若以牲畜更换牲畜，所许的与所换的都要成为圣。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 23:18; 玛拉基书 1:14"> 若牲畜不洁净，是不可献给耶和华为供物的，就要把牲畜安置在祭司面前。</span>
<span className="v" id="v12" data-v="12"> 祭司就要估定价值，牲畜是好是坏，祭司怎样估定，就要以怎样为是。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 27:19; 利未记 27:15; 利未记 22:14"> 他若一定要赎回，就要在你所估定的价值以外加上五分之一。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 18:14; 利未记 25:29–31; 利未记 27:21"> “人将房屋分别为圣，归给耶和华，祭司就要估定价值。房屋是好是坏，祭司怎样估定，就要以怎样为定。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 27:13"> 将房屋分别为圣的人，若要赎回房屋，就必在你所估定的价值以外加上五分之一，房屋仍旧归他。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以西结书 45:11–14; 何西阿书 3:2; 使徒行传 4:34–37"> “人若将承受为业的几分地分别为圣，归给耶和华，你要按这地撒种多少估定价值，若撒大麦一贺梅珥，要估价五十舍客勒。</span>
<span className="v" id="v17" data-v="17"> 他若从禧年将地分别为圣，就要以你所估定的价为定。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 25:15–16; 利未记 25:51–52; 利未记 25:27"> 倘若他在禧年以后将地分别为圣，祭司就要按着未到禧年所剩的年数推算价值，也要从你所估的减去价值。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 27:13"> 将地分别为圣的人若定要把地赎回，他便要在你所估的价值以外加上五分之一，地就准定归他。</span>
<span className="v" id="v20" data-v="20"> 他若不赎回那地，或是将地卖给别人，就再不能赎了。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 44:29; 民数记 18:14; 利未记 25:31"> 但到了禧年，那地从买主手下出来的时候，就要归耶和华为圣，和永献的地一样，要归祭司为业。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 25:10; 利未记 25:25"> 他若将所买的一块地，不是承受为业的，分别为圣归给耶和华，</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 27:18; 利未记 27:12"> 祭司就要将你所估的价值给他推算到禧年，当日他要以你所估的价银为圣，归给耶和华。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 25:28; 利未记 27:20"> 到了禧年，那地要归卖主，就是那承受为业的原主。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 30:13; 民数记 18:16; 民数记 3:47"> 凡你所估定的价银都要按着圣所的平，二十季拉为一舍客勒。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 13:2; 出埃及记 13:12–13; 民数记 18:17"> “唯独牲畜中头生的，无论是牛是羊，既归耶和华，谁也不可再分别为圣，因为这是耶和华的。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 27:11"> 若是不洁净的牲畜生的，就要按你所估定的价值加上五分之一赎回；若不赎回，就要按你所估定的价值卖了。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约书亚记 6:17–19; 利未记 27:21; 出埃及记 22:20"> “但一切永献的，就是人从他所有永献给耶和华的，无论是人，是牲畜，是他承受为业的地，都不可卖，也不可赎。凡永献的，是归给耶和华为至圣。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记上 15:18–23; 民数记 21:2–3"> 凡从人中当灭的都不可赎，必被治死。</span>
</div>
</div>

## 十输其一

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="马太福音 23:23; 尼希米记 13:12; 创世记 28:22"> “地上所有的，无论是地上的种子是树上的果子，十分之一是耶和华的，是归给耶和华为圣的。</span>
<span className="v" id="v31" data-v="31"> 人若要赎这十分之一的什么物，就要加上五分之一。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 33:13; 以西结书 20:37; 弥迦书 7:14"> 凡牛群羊群中，一切从杖下经过的，每第十只要归给耶和华为圣。</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 27:10"> 不可问是好是坏，也不可更换；若定要更换，所更换的与本来的牲畜都要成为圣，不可赎回。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="利未记 26:46; 民数记 1:1; 希伯来书 12:18–25"> 这就是耶和华在西奈山为以色列人所吩咐摩西的命令。</span>
</div>
</div>

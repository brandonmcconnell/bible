## 祭司献赎愆祭之任

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 6:17; 利未记 5:14–7; 利未记 6:25"> “赎愆祭的条例乃是如此：这祭是至圣的。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 1:5; 利未记 6:25; 利未记 1:11"> 人在那里宰燔祭牲，也要在那里宰赎愆祭牲，其血，祭司要洒在坛的周围。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 29:13; 利未记 3:15–16; 诗篇 51:6"> 又要将肥尾巴和盖脏的脂油，</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 3:4"> 两个腰子和腰子上的脂油，就是靠腰两旁的脂油，并肝上的网子和腰子，一概取下。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 1:13; 加拉太书 5:24; 彼得前书 4:1–2"> 祭司要在坛上焚烧，为献给耶和华的火祭，是赎愆祭。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 6:29; 民数记 18:9–10; 利未记 2:3"> 祭司中的男丁都可以吃这祭物，要在圣处吃，是至圣的。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 6:25–26; 利未记 14:13; 哥林多前书 9:13"> 赎罪祭怎样，赎愆祭也是怎样，两个祭是一个条例。献赎愆祭赎罪的祭司要得这祭物。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 4:11; 出埃及记 29:14; 罗马书 13:14"> 献燔祭的祭司，无论为谁奉献，要亲自得他所献那燔祭牲的皮。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 18:9; 以西结书 44:29; 利未记 2:10"> 凡在炉中烤的素祭和煎盘中做的，并铁鏊上做的，都要归那献祭的祭司。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 8:14; 出埃及记 16:18"> 凡素祭，无论是油调和的是干的，都要归亚伦的子孙，大家均分。</span>
</div>
</div>

## 祭司献平安祭之任

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="利未记 22:18–21; 以西结书 45:15; 利未记 3:1–17"> “人献于耶和华平安祭的条例乃是这样：</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 2:4; 民数记 6:15; 彼得前书 2:5"> 他若为感谢献上，就要用调油的无酵饼和抹油的无酵薄饼，并用油调匀细面做的饼，与感谢祭一同献上。</span>
<span className="v" id="v13" data-v="13" data-xref="阿摩司书 4:5; 利未记 23:17; 马太福音 13:33"> 要用有酵的饼和为感谢献的平安祭，与供物一同献上。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 18:19; 出埃及记 29:27–28; 民数记 18:24–32"> 从各样的供物中，他要把一个饼献给耶和华为举祭，是要归给洒平安祭牲血的祭司。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="利未记 22:29–30"> “为感谢献平安祭牲的肉，要在献的日子吃，一点不可留到早晨。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 19:5–8; 申命记 12:6; 诗篇 116:14"> 若所献的是为还愿，或是甘心献的，必在献祭的日子吃，所剩下的第二天也可以吃。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 12:10; 何西阿书 6:2; 哥林多前书 15:4"> 但所剩下的祭肉，到第三天要用火焚烧。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 19:7–8; 利未记 11:41; 民数记 18:27"> 第三天若吃了平安祭的肉，这祭必不蒙悦纳，人所献的也不算为祭，反为可憎嫌的，吃这祭肉的，就必担当他的罪孽。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 11:41; 提多书 1:15; 使徒行传 10:15–16"> “挨了污秽物的肉就不可吃，要用火焚烧。至于平安祭的肉，凡洁净的人都要吃。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 15:2–33; 创世记 17:14; 利未记 22:3–7"> 只是献于耶和华平安祭的肉，人若不洁净而吃了，这人必从民中剪除。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 12:1–59; 利未记 11:20; 以西结书 4:14"> 有人摸了什么不洁净的物，或是人的不洁净，或是不洁净的牲畜，或是不洁可憎之物，吃了献于耶和华平安祭的肉，这人必从民中剪除。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 耶和华对摩西说：</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 3:16–17; 利未记 17:6; 撒母耳记上 2:15–17"> “你晓谕以色列人说：牛的脂油，绵羊的脂油，山羊的脂油，你们都不可吃。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 22:31; 利未记 17:15; 利未记 22:8"> 自死的和被野兽撕裂的，那脂油可以做别的使用，只是你们万不可吃。</span>
<span className="v" id="v25" data-v="25"> 无论何人吃了献给耶和华当火祭牲畜的脂油，那人必从民中剪除。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 9:4; 利未记 3:17; 使徒行传 15:20"> 在你们一切的住处，无论是雀鸟的血是野兽的血，你们都不可吃。</span>
<span className="v" id="v27" data-v="27" data-xref="希伯来书 10:29; 利未记 7:20–21; 利未记 7:25"> 无论是谁吃血，那人必从民中剪除。”</span>
</div>
</div>

## 祭司当得之份

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28"> 耶和华对摩西说：</span>
<span className="v" id="v29" data-v="29" data-xref="歌罗西书 1:20; 约翰一书 1:7; 利未记 3:1–17"> “你晓谕以色列人说：献平安祭给耶和华的，要从平安祭中取些来奉给耶和华。</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 6:20; 利未记 3:9; 利未记 3:14"> 他亲手献给耶和华的火祭，就是脂油和胸，要带来，好把胸在耶和华面前做摇祭，摇一摇。</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 3:5; 利未记 3:11; 利未记 3:16"> 祭司要把脂油在坛上焚烧，但胸要归亚伦和他的子孙。</span>
<span className="v" id="v32" data-v="32" data-xref="民数记 6:20; 利未记 7:34; 利未记 9:21"> 你们要从平安祭中把右腿做举祭，奉给祭司。</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 26:1–46; 利未记 6:1–30; 利未记 7:3"> 亚伦子孙中，献平安祭牲血和脂油的，要得这右腿为份。</span>
<span className="v" id="v34" data-v="34" data-xref="民数记 18:18–19; 利未记 10:14–15; 出埃及记 29:9"> 因为我从以色列人的平安祭中，取了这摇的胸和举的腿给祭司亚伦和他子孙，做他们从以色列人中所永得的份。”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="约翰一书 2:20; 约翰一书 2:27; 民数记 18:7–19"> 这是从耶和华火祭中，做亚伦受膏的份和他子孙受膏的份，正在摩西<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：他。">a</a></sup>叫他们前来给耶和华供祭司职分的日子，</span>
<span className="v" id="v36" data-v="36" data-xref="利未记 8:12; 利未记 8:30; 出埃及记 40:13–15"> 就是在摩西<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：他。">b</a></sup>膏他们的日子，耶和华吩咐以色列人给他们的。这是他们世世代代永得的份。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="出埃及记 29:1; 利未记 1:1–6; 利未记 6:9–18"> 这就是燔祭、素祭、赎罪祭、赎愆祭和平安祭的条例，并承接圣职的礼，</span>
<span className="v" id="v38" data-v="38" data-xref="利未记 1:1–2"> 都是耶和华在西奈山所吩咐摩西的，就是他在西奈旷野吩咐以色列人献供物给耶和华之日所说的。</span>
</div>
</div>

## 赎愆祭之例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 5:17; 箴言 29:24; 利未记 19:8"> “若有人听见发誓的声音<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：若有人听见叫人发誓的声音。">a</a></sup>，他本是见证，却不把所看见的、所知道的说出来，这就是罪，他要担当他的罪孽。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 5:17; 申命记 14:8; 哈该书 2:13"> 或是有人摸了不洁的物，无论是不洁的死兽，是不洁的死畜，是不洁的死虫，他却不知道，因此成了不洁，就有了罪。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 19:11–16; 利未记 15:1–33; 利未记 12:1–8"> 或是他摸了别人的污秽，无论是染了什么污秽，他却不知道，一知道了，就有了罪。</span>
<span className="v" id="v4" data-v="4" data-xref="传道书 5:2–6; 使徒行传 23:12; 士师记 11:31"> 或是有人嘴里冒失发誓，要行恶，要行善，无论人在什么事上冒失发誓，他却不知道，一知道了，就要在这其中的一件上有了罪。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 28:13; 民数记 5:7; 利未记 26:40"> 他有了罪的时候，就要承认所犯的罪，</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 4:28; 利未记 4:32; 利未记 4:20"> 并要因所犯的罪，把他的赎愆祭牲，就是羊群中的母羊，或是一只羊羔，或是一只山羊，牵到耶和华面前为赎罪祭。至于他的罪，祭司要为他赎了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="利未记 12:8; 利未记 14:21–22; 马太福音 3:16"> “他的力量若不够献一只羊羔，就要因所犯的罪，把两只斑鸠或是两只雏鸽带到耶和华面前为赎愆祭，一只做赎罪祭，一只做燔祭。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 1:15; 利未记 1:17; 罗马书 4:25"> 把这些带到祭司那里，祭司就要先把那赎罪祭献上，从鸟的颈项上揪下头来，只是不可把鸟撕断；</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 4:30; 利未记 4:34; 利未记 4:18"> 也把些赎罪祭牲的血弹在坛的旁边，剩下的血要流在坛的脚那里。这是赎罪祭。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 1:14–17; 利未记 4:26; 利未记 4:20"> 他要照例献第二只为燔祭。至于他所犯的罪，祭司要为他赎了，他必蒙赦免。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民数记 5:15; 利未记 2:1–2; 出埃及记 16:36"> “他的力量若不够献两只斑鸠或是两只雏鸽，就要因所犯的罪带供物来，就是细面伊法十分之一，为赎罪祭；不可加上油，也不可加上乳香，因为是赎罪祭。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 4:35; 利未记 2:9; 利未记 2:2"> 他要把供物带到祭司那里，祭司要取出自己的一把来作为纪念，按献给耶和华火祭的条例烧在坛上。这是赎罪祭。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 2:3; 利未记 4:26; 哥林多前书 9:13"> 至于他在这几件事中所犯的罪，祭司要为他赎了，他必蒙赦免。剩下的面都归于祭司，和素祭一样。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 耶和华晓谕摩西说：</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 30:13; 利未记 4:2; 利未记 6:6"> “人若在耶和华的圣物上误犯了罪，有了过犯，就要照你所估的，按圣所的舍客勒拿银子，将赎愆祭牲，就是羊群中一只没有残疾的公绵羊，牵到耶和华面前为赎愆祭；</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 22:14; 民数记 5:7; 利未记 27:27"> 并且他因在圣物上的差错要偿还，另外加五分之一，都给祭司。祭司要用赎愆祭的公绵羊为他赎罪，他必蒙赦免。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="利未记 4:27; 利未记 4:13; 利未记 4:2–4"> “若有人犯罪，行了耶和华所吩咐不可行的什么事，他虽然不知道，还是有了罪，就要担当他的罪孽。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 5:15–16; 提摩太前书 2:5–6; 利未记 1:4"> 也要照你所估定的价，从羊群中牵一只没有残疾的公绵羊来，给祭司做赎愆祭。至于他误行的那错事，祭司要为他赎罪，他必蒙赦免。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 51:4; 玛拉基书 3:8; 哥林多后书 5:19–21"> 这是赎愆祭，因他在耶和华面前实在有了罪。”</span>
</div>
</div>

## 安息年

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 1:1; 加拉太书 4:24–25; 出埃及记 19:1"> 耶和华在西奈山对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 36:21; 利未记 26:34–35; 出埃及记 23:10"> “你晓谕以色列人说：你们到了我所赐你们那地的时候，地就要向耶和华守安息。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 23:10"> 六年要耕种田地，也要修理葡萄园，收藏地的出产。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 36:21; 利未记 25:20–23; 出埃及记 23:10–11"> 第七年，地要守圣安息，就是向耶和华守的安息，不可耕种田地，也不可修理葡萄园。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 19:29; 以赛亚书 37:30"> 遗落自长的庄稼不可收割，没有修理的葡萄树也不可摘取葡萄。这年，地要守圣安息。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 2:44; 出埃及记 23:11; 使徒行传 4:34–35"> 地在安息年所出的，要给你和你的仆人、婢女、雇工人，并寄居的外人当食物。</span>
<span className="v" id="v7" data-v="7"> 这年的土产也要给你的牲畜和你地上的走兽当食物。</span>
</div>
</div>

## 禧年

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未记 23:15; 创世记 2:2"> “你要计算七个安息年，就是七七年。这便为你成了七个安息年，共是四十九年。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 23:24; 利未记 23:27; 帖撒罗尼迦前书 1:8"> 当年七月初十日，你要大发角声，这日就是赎罪日，要在遍地发出角声。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 34:8; 以赛亚书 63:4; 彼得前书 2:16"> 第五十年，你们要当做圣年，在遍地给一切的居民宣告自由。这年必为你们的禧年，各人要归自己的产业，各归本家。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 27:17; 利未记 25:4–5"> 第五十年要作为你们的禧年，这年不可耕种，地中自长的不可收割，没有修理的葡萄树也不可摘取葡萄。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 25:6–7"> 因为这是禧年，你们要当做圣年，吃地中自出的土产。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未记 25:10; 利未记 27:17–24; 民数记 36:4"> “这禧年，你们各人要归自己的地业。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 19:13; 利未记 25:17; 撒母耳记上 12:3–4"> 你若卖什么给邻舍，或是从邻舍的手中买什么，彼此不可亏负。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 27:18–23; 腓立比书 4:5"> 你要按禧年以后的年数向邻舍买，他也要按年数的收成卖给你。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 25:27; 利未记 25:51"> 年岁若多，要照数加添价值，年岁若少，要照数减去价值，因为他照收成的数目卖给你。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 19:14; 利未记 19:32; 利未记 25:43"> 你们彼此不可亏负，只要敬畏你们的神，因为我是耶和华你们的神。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米书 23:6; 申命记 12:10; 箴言 1:33"> “我的律例你们要遵行，我的典章你们要谨守，就可以在那地上安然居住。</span>
<span className="v" id="v19" data-v="19" data-xref="约珥书 2:26; 诗篇 85:12; 利未记 26:5"> 地必出土产，你们就要吃饱，在那地上安然居住。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 25:4; 路加福音 12:29; 民数记 11:4"> 你们若说：‘这第七年我们不耕种，也不收藏土产，吃什么呢？’</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 28:8; 箴言 10:22; 哥林多后书 9:10"> 我必在第六年将我所命的福赐给你们，地便生三年的土产。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 19:29; 利未记 26:10; 以赛亚书 37:30"> 第八年，你们要耕种，也要吃陈粮，等到第九年出产收来的时候，你们还吃陈粮。</span>
</div>
</div>

## 赎地之例

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="彼得前书 2:11; 诗篇 39:12; 以西结书 48:14"> “地不可永卖，因为地是我的，你们在我面前是客旅，是寄居的。</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所书 1:7; 利未记 25:51–53; 利未记 25:27"> 在你们所得为业的全地，也要准人将地赎回。</span>
<span className="v" id="v25" data-v="25" data-xref="路得记 2:20; 耶利米书 32:7–8; 路得记 3:12"> 你的弟兄<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“弟兄”指本国人说，下同。">a</a></sup>若渐渐穷乏，卖了几分地业，他至近的亲属就要来把弟兄所卖的赎回。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 5:7"> 若没有能给他赎回的，他自己渐渐富足，能够赎回，</span>
<span className="v" id="v27" data-v="27"> 就要算出卖地的年数，把余剩年数的价值还那买主，自己便归回自己的地业。</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 35:9–10; 利未记 25:10; 彼得前书 1:4–5"> 倘若不能为自己得回所卖的，仍要存在买主的手里直到禧年，到了禧年，地业要出买主的手，自己便归回自己的地业。</span>
</div>
</div>

## 赎宅之例

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29"> “人若卖城内的住宅，卖了以后，一年之内可以赎回；在一整年，必有赎回的权柄。</span>
<span className="v" id="v30" data-v="30"> 若在一整年之内不赎回，这城内的房屋就定准永归买主，世世代代为业，在禧年也不得出买主的手。</span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 49:7–8"> 但房屋在无城墙的村庄里，要看如乡下的田地一样，可以赎回，到了禧年，都要出买主的手。</span>
<span className="v" id="v32" data-v="32" data-xref="约书亚记 21:1–45; 民数记 35:1–8"> 然而利未人所得为业的城邑，其中的房屋，利未人可以随时赎回。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 18:20–24; 申命记 18:1–2"> 若是一个利未人不将所卖的房屋赎回，是在所得为业的城内，到了禧年就要出买主的手，因为利未人城邑的房屋是他们在以色列人中的产业。</span>
<span className="v" id="v34" data-v="34" data-xref="利未记 25:23; 使徒行传 4:36–37; 民数记 35:2–5"> 只是他们各城郊野之地不可卖，因为是他们永远的产业。</span>
</div>
</div>

## 勿取贫者之利

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="申命记 15:7–8; 使徒行传 11:29; 利未记 25:25"> “你的弟兄在你那里若渐渐贫穷，手中缺乏，你就要帮补他，使他与你同住，像外人和寄居的一样。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 22:25; 申命记 23:19–20; 以西结书 18:8"> 不可向他取利，也不可向他多要，只要敬畏你的神，使你的弟兄与你同住。</span>
<span className="v" id="v37" data-v="37"> 你借钱给他，不可向他取利；借粮给他，也不可向他多要。</span>
<span className="v" id="v38" data-v="38" data-xref="利未记 11:45; 民数记 15:41; 出埃及记 20:2"> 我是耶和华你们的神，曾领你们从埃及地出来，为要把迦南地赐给你们，要做你们的神。</span>
</div>
</div>

## 穷乏者自鬻之例

<div className="bt">
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出埃及记 21:2; 列王纪上 9:22; 列王纪下 4:1"> “你的弟兄若在你那里渐渐穷乏，将自己卖给你，不可叫他像奴仆服侍你。</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及记 21:2–3"> 他要在你那里像雇工人和寄居的一样，要服侍你直到禧年。</span>
<span className="v" id="v41" data-v="41" data-xref="利未记 25:28; 出埃及记 21:3; 约翰福音 8:32"> 到了禧年，他和他儿女要离开你，一同出去归回本家，到他祖宗的地业那里去，</span>
<span className="v" id="v42" data-v="42" data-xref="利未记 25:55; 罗马书 6:22; 哥林多前书 7:21–23"> 因为他们是我的仆人，是我从埃及地领出来的，不可卖为奴仆。</span>
<span className="v" id="v43" data-v="43" data-xref="歌罗西书 4:1; 利未记 25:46; 出埃及记 1:13–14"> 不可严严地辖管他，只要敬畏你的神。</span>
<span className="v" id="v44" data-v="44" data-xref="出埃及记 12:44; 诗篇 2:8–9; 以赛亚书 14:1–2"> 至于你的奴仆、婢女，可以从你四围的国中买；</span>
<span className="v" id="v45" data-v="45" data-xref="以赛亚书 56:3–6"> 并且那寄居在你们中间的外人和他们的家属，在你们地上所生的，你们也可以从其中买人，他们要做你们的产业。</span>
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 14:2; 利未记 25:43"> 你们要将他们遗留给你们的子孙为产业，要永远从他们中间拣出奴仆，只是你们的弟兄以色列人，你们不可严严地辖管。</span>
</div>
</div>

## 鬻于外人者宜赎之

<div className="bt">
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="雅各书 2:5; 利未记 25:26; 撒母耳记上 2:7–8"> “住在你那里的外人或是寄居的，若渐渐富足，你的弟兄却渐渐穷乏，将自己卖给那外人，或是寄居的，或是外人的宗族，</span>
<span className="v" id="v48" data-v="48" data-xref="尼希米记 5:5; 希伯来书 2:11–13; 利未记 25:35"> 卖了以后，可以将他赎回。无论是他的弟兄，</span>
<span className="v" id="v49" data-v="49" data-xref="利未记 25:26"> 或伯叔，伯叔的儿子，本家的近支，都可以赎他。他自己若渐渐富足，也可以自赎。</span>
<span className="v" id="v50" data-v="50" data-xref="以赛亚书 16:14; 以赛亚书 21:16; 利未记 25:53"> 他要和买主计算，从卖自己的那年起，算到禧年，所卖的价值照着年数多少，好像工人每年的工价。</span>
<span className="v" id="v51" data-v="51"> 若缺少的年数多，就要按着年数从买价中偿还他的赎价。</span>
<span className="v" id="v52" data-v="52"> 若到禧年只缺少几年，就要按着年数和买主计算，偿还他的赎价。</span>
<span className="v" id="v53" data-v="53" data-xref="利未记 25:46; 利未记 25:43"> 他和买主同住，要像每年雇的工人，买主不可严严地辖管他。</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及记 21:2–3; 利未记 25:40–41; 以赛亚书 49:9"> 他若不这样被赎，到了禧年，要和他的儿女一同出去，</span>
<span className="v" id="v55" data-v="55" data-xref="利未记 25:42; 以赛亚书 43:3; 出埃及记 13:3"> 因为以色列人都是我的仆人，是我从埃及地领出来的。我是耶和华你们的神。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 23:4; 利未记 23:37; 民数记 29:39"> “你晓谕以色列人说：耶和华的节期，你们要宣告为圣会的节期。</span>
</div>
</div>

## 安息日

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="利未记 19:3; 出埃及记 23:12; 出埃及记 35:2–3"> “六日要做工，第七日是圣安息日，当有圣会，你们什么工都不可做。这是在你们一切的住处向耶和华守的安息日。</span>
</div>
</div>

## 无酵节

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="利未记 23:2; 出埃及记 23:14; 利未记 23:37"> “耶和华的节期，就是你们到了日期要宣告为圣会的，乃是这些：</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 5:10; 申命记 16:1–8; 民数记 28:16–17"> 正月十四日黄昏的时候，是耶和华的逾越节。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 34:18; 申命记 16:8; 出埃及记 12:15–16"> 这月十五日是向耶和华守的无酵节，你们要吃无酵饼七日。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 28:18–25; 利未记 23:8; 利未记 23:21"> 第一日当有圣会，什么劳碌的工都不可做。</span>
<span className="v" id="v8" data-v="8"> 要将火祭献给耶和华七日。第七日是圣会，什么劳碌的工都不可做。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 耶和华对摩西说：</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 34:26; 出埃及记 23:19; 申命记 16:9"> “你晓谕以色列人说：你们到了我赐给你们的地，收割庄稼的时候，要将初熟的庄稼一捆带给祭司。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 29:24; 利未记 10:14; 利未记 9:21"> 他要把这一捆在耶和华面前摇一摇，使你们得蒙悦纳。祭司要在安息日的次日把这捆摇一摇。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 10:10–12; 彼得前书 1:19; 利未记 1:10"> 摇这捆的日子，你们要把一岁、没有残疾的公绵羊羔献给耶和华为燔祭；</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 2:14–16; 约珥书 1:9; 民数记 28:10"> 同献的素祭，就是调油的细面伊法十分之二，作为馨香的火祭献给耶和华；同献的奠祭，要酒一欣四分之一。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 34:26; 创世记 4:4–5; 利未记 3:17"> 无论是饼，是烘的子粒，是新穗子，你们都不可吃，直等到把你们献给神的供物带来的那一天才可以吃。这在你们一切的住处作为世世代代永远的定例。</span>
</div>
</div>

## 五旬节

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="利未记 23:10–11; 利未记 25:8; 申命记 16:9–10"> “你们要从安息日的次日，献禾捆为摇祭的那日算起，要满了七个安息日，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 2:1; 民数记 28:26"> 到第七个安息日的次日，共计五十天，又要将新素祭献给耶和华。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 23:10; 出埃及记 34:26; 出埃及记 34:22"> 要从你们的住处取出细面伊法十分之二，加酵，烤成两个摇祭的饼，当做初熟之物献给耶和华。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 28:27–31; 利未记 23:12–13; 玛拉基书 1:13–14"> 又要将一岁、没有残疾的羊羔七只，公牛犊一只，公绵羊两只，和饼一同奉上。这些与同献的素祭和奠祭要作为燔祭献给耶和华，就是做馨香的火祭献给耶和华。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 28:30; 利未记 4:23–28; 利未记 7:11–18"> 你们要献一只公山羊为赎罪祭，两只一岁的公绵羊羔为平安祭。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 18:4; 以弗所书 2:14; 民数记 18:8–12"> 祭司要把这些和初熟麦子做的饼一同做摇祭，在耶和华面前摇一摇，这是献于耶和华为圣物，归给祭司的。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 23:2; 利未记 23:4; 民数记 18:23"> 当这日，你们要宣告圣会，什么劳碌的工都不可做。这在你们一切的住处作为世世代代永远的定例。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命记 24:19–21; 利未记 19:9–10; 以赛亚书 58:10"> “在你们的地收割庄稼，不可割尽田角，也不可拾取所遗落的，要留给穷人和寄居的。我是耶和华你们的神。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和华对摩西说：</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 15:52; 帖撒罗尼迦前书 4:16; 利未记 25:9"> “你晓谕以色列人说：七月初一，你们要守为圣安息日，要吹角做纪念，当有圣会。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 23:21"> 什么劳碌的工都不可做，要将火祭献给耶和华。”</span>
</div>
</div>

## 赎罪日

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和华晓谕摩西说：</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 16:29–31; 出埃及记 30:10; 利未记 16:24"> “七月初十是赎罪日，你们要守为圣会，并要刻苦己心，也要将火祭献给耶和华。</span>
<span className="v" id="v28" data-v="28" data-xref="撒迦利亚书 3:9; 利未记 16:34; 希伯来书 10:10"> 当这日，什么工都不可做，因为是赎罪日，要在耶和华你们的神面前赎罪。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 17:14; 民数记 5:2; 利未记 23:27"> 当这日，凡不刻苦己心的，必从民中剪除。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 20:3; 西番雅书 2:5; 耶利米书 15:7"> 凡这日做什么工的，我必将他从民中除灭。</span>
<span className="v" id="v31" data-v="31"> 你们什么工都不可做。这在你们一切的住处作为世世代代永远的定例。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 16:31; 马太福音 11:28–30; 诗篇 69:10–11"> 你们要守这日为圣安息日，并要刻苦己心，从这月初九日晚上到次日晚上，要守为安息日。”</span>
</div>
</div>

## 住棚节

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33"> 耶和华对摩西说：</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 7:2; 尼希米记 8:14; 以斯拉记 3:4"> “你晓谕以色列人说：这七月十五日是住棚节，要在耶和华面前守这节七日。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 23:24–25; 利未记 23:7–8"> 第一日当有圣会，什么劳碌的工都不可做。</span>
<span className="v" id="v36" data-v="36" data-xref="尼希米记 8:18; 约翰福音 7:37; 历代志下 7:8–11"> 七日内要将火祭献给耶和华。第八日当守圣会，要将火祭献给耶和华。这是严肃会，什么劳碌的工都不可做。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="利未记 23:2; 利未记 23:4; 传道书 3:1"> “这是耶和华的节期，就是你们要宣告为圣会的节期，要将火祭、燔祭、素祭、祭物并奠祭，各归各日，献给耶和华。</span>
<span className="v" id="v38" data-v="38" data-xref="民数记 29:39; 利未记 19:3; 以斯拉记 2:68–69"> 这是在耶和华的安息日以外，又在你们的供物和所许的愿，并甘心献给耶和华的以外。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出埃及记 23:16; 申命记 16:13; 利未记 23:34"> “你们收藏了地的出产，就从七月十五日起，要守耶和华的节七日。第一日为圣安息，第八日也为圣安息。</span>
<span className="v" id="v40" data-v="40" data-xref="腓立比书 4:4; 启示录 7:9; 申命记 16:14–15"> 第一日要拿美好树上的果子和棕树上的枝子，与茂密树的枝条并河旁的柳枝，在耶和华你们的神面前欢乐七日。</span>
<span className="v" id="v41" data-v="41" data-xref="民数记 29:12; 尼希米记 8:18"> 每年七月间，要向耶和华守这节七日。这为你们世世代代永远的定例。</span>
<span className="v" id="v42" data-v="42" data-xref="尼希米记 8:14–17; 创世记 33:17; 民数记 24:5"> 你们要住在棚里七日，凡以色列家的人都要住在棚里，</span>
<span className="v" id="v43" data-v="43" data-xref="申命记 31:10–13; 诗篇 78:5–6; 出埃及记 13:14"> 好叫你们世世代代知道，我领以色列人出埃及地的时候曾使他们住在棚里。我是耶和华你们的神。”</span>
<span className="v" id="v44" data-v="44" data-xref="利未记 23:1–2; 马太福音 18:20; 利未记 21:24"> 于是摩西将耶和华的节期传给以色列人。</span>
</div>
</div>

</div>

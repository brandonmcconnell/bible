<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华晓谕摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 28:2–4; 出埃及记 39:41; 希伯来书 7:27"> “你将亚伦和他儿子一同带来，并将圣衣，膏油，与赎罪祭的一只公牛，两只公绵羊，一筐无酵饼都带来，</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 30:13; 使徒行传 2:1; 尼希米记 8:1"> 又招聚会众到会幕门口。”</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 39:26; 出埃及记 39:7; 出埃及记 39:5"> 摩西就照耶和华所吩咐的行了，于是会众聚集在会幕门口。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 29:4–37"> 摩西告诉会众说：“这就是耶和华所吩咐当行的事。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 6:11; 以弗所书 5:26; 出埃及记 29:4"> 摩西带了亚伦和他儿子来，用水洗了他们，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 28:4; 以赛亚书 61:10; 加拉太书 3:27"> 给亚伦穿上内袍，束上腰带，穿上外袍，又加上以弗得，用其上巧工织的带子把以弗得系在他身上，</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 2:63; 帖撒罗尼迦前书 5:8; 以赛亚书 59:17"> 又给他戴上胸牌，把乌陵和土明放在胸牌内，</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比书 2:9–11; 撒迦利亚书 6:11–14; 出埃及记 28:36–38"> 把冠冕戴在他头上，在冠冕的前面钉上金牌，就是圣冠，都是照耶和华所吩咐摩西的。</span>
</div>
</div>

## 膏亚伦使之成圣

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及记 40:9–11; 利未记 8:2; 出埃及记 30:23–29"> 摩西用膏油抹帐幕和其中所有的，使它成圣，</span>
<span className="v" id="v11" data-v="11" data-xref="提多书 3:6; 出埃及记 30:29; 出埃及记 16:19"> 又用膏油在坛上弹了七次，又抹了坛和坛的一切器皿，并洗濯盆和盆座，使它成圣，</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 30:30; 诗篇 133:2; 出埃及记 29:7"> 又把膏油倒在亚伦的头上膏他，使他成圣。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 29:8–9; 启示录 5:10; 启示录 1:6"> 摩西带了亚伦的儿子来，给他们穿上内袍，束上腰带，包上裹头巾，都是照耶和华所吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西结书 43:19; 诗篇 66:15; 彼得前书 3:18"> 他牵了赎罪祭的公牛来，亚伦和他儿子按手在赎罪祭公牛的头上，</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 4:7; 希伯来书 9:18–23; 以西结书 43:19–27"> 就宰了公牛。摩西用指头蘸血，抹在坛上四角的周围，使坛洁净，把血倒在坛的脚那里，使坛成圣，坛就洁净了，</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 29:13; 利未记 3:3–5; 利未记 4:8–9"> 又取脏上所有的脂油和肝上的网子，并两个腰子与腰子上的脂油，都烧在坛上，</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 4:11–12; 出埃及记 29:14; 利未记 6:30"> 唯有公牛，连皮带肉并粪，用火烧在营外，都是照耶和华所吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未记 8:2; 利未记 1:4–13; 出埃及记 29:15–18"> 他奉上燔祭的公绵羊，亚伦和他儿子按手在羊的头上，</span>
<span className="v" id="v19" data-v="19"> 就宰了公羊。摩西把血洒在坛的周围，</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 1:8"> 把羊切成块子，把头和肉块并脂油都烧了，</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所书 5:2; 出埃及记 29:18; 利未记 1:17"> 用水洗了脏腑和腿，就把全羊烧在坛上为馨香的燔祭，是献给耶和华的火祭，都是照耶和华所吩咐摩西的。</span>
</div>
</div>

## 亚伦与其子任圣职

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未记 8:2; 利未记 8:29; 出埃及记 29:19–31"> 他又奉上第二只公绵羊，就是承接圣职之礼的羊，亚伦和他儿子按手在羊的头上，</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 29:20; 利未记 14:14; 罗马书 12:1"> 就宰了羊。摩西把些血抹在亚伦的右耳垂上和右手的大拇指上，并右脚的大拇指上；</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 9:18–22"> 又带了亚伦的儿子来，把些血抹在他们的右耳垂上和右手的大拇指上，并右脚的大拇指上；又把血洒在坛的周围。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 3:9; 利未记 3:3–5; 以赛亚书 53:10"> 取脂油和肥尾巴，并脏上一切的脂油与肝上的网子，两个腰子和腰子上的脂油，并右腿；</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 29:23; 提摩太前书 2:5; 使徒行传 5:12"> 再从耶和华面前盛无酵饼的筐子里取出一个无酵饼、一个油饼、一个薄饼，都放在脂油和右腿上；</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 30:21; 希伯来书 9:14; 出埃及记 29:24–37"> 把这一切放在亚伦的手上和他儿子的手上做摇祭，在耶和华面前摇一摇。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 29:25; 诗篇 22:13–14; 希伯来书 10:14–22"> 摩西从他们的手上拿下来，烧在坛上的燔祭上，都是为承接圣职献给耶和华馨香的火祭。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 10:31; 彼得前书 4:11; 利未记 7:30–34"> 摩西拿羊的胸作为摇祭，在耶和华面前摇一摇，是承接圣职之礼，归摩西的份，都是照耶和华所吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及记 29:21; 民数记 3:3; 出埃及记 30:30"> 摩西取点膏油和坛上的血，弹在亚伦和他的衣服上，并他儿子和他儿子的衣服上，使他和他们的衣服一同成圣。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及记 29:31–32; 加拉太书 2:20; 撒母耳记上 2:13–17"> 摩西对亚伦和他儿子说：“把肉煮在会幕门口，在那里吃，又吃承接圣职筐子里的饼；按我所吩咐的说<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：按所吩咐我的说。">a</a></sup>，这是亚伦和他儿子要吃的。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 29:34; 出埃及记 12:10; 希伯来书 3:13–14"> 剩下的肉和饼，你们要用火焚烧。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 29:35; 民数记 19:12; 以西结书 43:25–27"> 你们七天不可出会幕的门，等到你们承接圣职的日子满了，因为主叫你们七天承接圣职。</span>
<span className="v" id="v34" data-v="34" data-xref="希伯来书 7:27; 希伯来书 7:16; 希伯来书 10:11–12"> 像今天所行的，都是耶和华吩咐行的，为你们赎罪。</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 3:7; 申命记 11:1; 列王纪上 2:3"> 七天你们要昼夜住在会幕门口，遵守耶和华的吩咐，免得你们死亡，因为所吩咐我的就是这样。”</span>
<span className="v" id="v36" data-v="36" data-xref="申命记 12:32; 申命记 4:2; 出埃及记 40:16"> 于是亚伦和他儿子行了耶和华藉着摩西所吩咐的一切事。</span>
</div>
</div>

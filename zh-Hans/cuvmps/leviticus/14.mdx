## 患大麻风者成洁之例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华晓谕摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 17:14; 路加福音 5:12–14; 马可福音 1:40–44"> “长大麻风得洁净的日子，其例乃是这样：要带他去见祭司，</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 13:46; 路加福音 7:22; 路加福音 17:15–19"> 祭司要出到营外察看，若见他的大麻风痊愈了，</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 19:6; 利未记 14:6; 希伯来书 9:19"> 就要吩咐人为那求洁净的拿两只洁净的活鸟和香柏木、朱红色线并牛膝草来。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 14:50; 希伯来书 2:14; 哥林多后书 5:1"> 祭司要吩咐用瓦器盛活水，把一只鸟宰在上面。</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 1:5; 撒迦利亚书 13:1; 腓立比书 2:9–11"> 至于那只活鸟，祭司要把它和香柏木、朱红色线并牛膝草一同蘸于宰在活水上的鸟血中，</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 5:14; 以西结书 36:25; 以赛亚书 52:15"> 用以在那长大麻风求洁净的人身上洒七次，就定他为洁净，又把活鸟放在田野里。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 11:25; 民数记 8:7; 彼得前书 3:21"> 求洁净的人当洗衣服，剃去毛发，用水洗澡，就洁净了，然后可以进营，只是要在自己的帐篷外居住七天。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 6:9; 利未记 14:8; 民数记 8:7"> 第七天，再把头上所有的头发与胡须、眉毛并全身的毛都剃了，又要洗衣服，用水洗身，就洁净了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未记 2:1; 马太福音 8:4; 路加福音 5:14"> “第八天，他要取两只没有残疾的公羊羔和一只没有残疾、一岁的母羊羔，又要把调油的细面伊法十分之三为素祭，并油一罗革，一同取来。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 5:26–27; 出埃及记 29:1–4; 民数记 8:21"> 行洁净之礼的祭司要将那求洁净的人和这些东西安置在会幕门口，耶和华面前。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 29:24; 利未记 6:6–7; 利未记 8:27–29"> 祭司要取一只公羊羔献为赎愆祭，和那一罗革油一同做摇祭，在耶和华面前摇一摇。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 29:11; 利未记 1:11; 利未记 4:24"> 把公羊羔宰于圣地，就是宰赎罪祭牲和燔祭牲之地，赎愆祭要归祭司，与赎罪祭一样，是至圣的。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 29:20; 利未记 8:23–24; 哥林多后书 7:1"> 祭司要取些赎愆祭牲的血，抹在求洁净人的右耳垂上和右手的大拇指上，并右脚的大拇指上。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 45:7; 约翰福音 3:34; 约翰一书 2:20"> 祭司要从那一罗革油中取些倒在自己的左手掌里，</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 4:17; 哥林多前书 10:31; 利未记 4:6"> 把右手的一个指头蘸在左手的油里，在耶和华面前用指头弹七次，</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前书 1:2; 以西结书 36:27; 利未记 14:14"> 将手里所剩的油抹在那求洁净人的右耳垂上和右手的大拇指上，并右脚的大拇指上，就是抹在赎愆祭牲的血上。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 4:26; 哥林多后书 1:21–22; 以弗所书 1:17–18"> 祭司手里所剩的油要抹在那求洁净人的头上，在耶和华面前为他赎罪。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 14:12; 利未记 5:1; 利未记 12:6–8"> 祭司要献赎罪祭，为那本不洁净求洁净的人赎罪，然后要宰燔祭牲，</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 14:10; 以弗所书 5:2; 利未记 14:8"> 把燔祭和素祭献在坛上，为他赎罪，他就洁净了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="利未记 5:7; 利未记 12:8; 箴言 17:5"> “他若贫穷不能预备够数，就要取一只公羊羔做赎愆祭，可以摇一摇，为他赎罪；也要把调油的细面伊法十分之一为素祭，和油一罗革一同取来；</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 7:16; 以赛亚书 59:11; 耶利米书 48:28"> 又照他的力量取两只斑鸠或是两只雏鸽，一只做赎罪祭，一只做燔祭。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 14:10–11"> 第八天，要为洁净，把这些带到会幕门口，耶和华面前，交给祭司。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 14:12; 利未记 14:10"> 祭司要把赎愆祭的羊羔和那一罗革油一同做摇祭，在耶和华面前摇一摇。</span>
<span className="v" id="v25" data-v="25" data-xref="传道书 5:1; 诗篇 40:6; 利未记 14:14–20"> 要宰了赎愆祭的羊羔，取些赎愆祭牲的血，抹在那求洁净人的右耳垂上和右手的大拇指上，并右脚的大拇指上。</span>
<span className="v" id="v26" data-v="26"> 祭司要把些油倒在自己的左手掌里，</span>
<span className="v" id="v27" data-v="27"> 把左手里的油在耶和华面前，用右手的一个指头弹七次，</span>
<span className="v" id="v28" data-v="28"> 又把手里的油抹些在那求洁净人的右耳垂上和右手的大拇指上，并右脚的大拇指上，就是抹赎愆祭之血的原处。</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 14:18; 约翰一书 2:1–2; 出埃及记 30:15–16"> 祭司手里所剩的油要抹在那求洁净人的头上，在耶和华面前为他赎罪。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 14:22; 罗马书 8:3; 利未记 12:8"> 那人又要照他的力量献上一只斑鸠或是一只雏鸽，</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 14:18; 利未记 5:7"> 就是他所能办的，一只为赎罪祭，一只为燔祭，与素祭一同献上。祭司要在耶和华面前为他赎罪。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 14:10; 利未记 14:21; 马太福音 11:5"> 这是那有大麻风灾病的人不能将关乎得洁净之物预备够数的条例。”</span>
</div>
</div>

## 染疾之宅成洁之例

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33"> 耶和华晓谕摩西、亚伦说：</span>
<span className="v" id="v34" data-v="34" data-xref="申命记 32:49; 创世记 17:8; 民数记 32:22"> “你们到了我赐给你们为业的迦南地，我若使你们所得为业之地的房屋中有大麻风的灾病，</span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 91:10; 申命记 7:26; 撒迦利亚书 5:4"> 房主就要去告诉祭司说：‘据我看，房屋中似乎有灾病。’</span>
<span className="v" id="v36" data-v="36" data-xref="启示录 18:4; 希伯来书 12:15; 提摩太后书 2:17–18"> 祭司还没有进去察看灾病以前，就要吩咐人把房子腾空，免得房子里所有的都成了不洁净，然后祭司要进去察看房子。</span>
<span className="v" id="v37" data-v="37" data-xref="利未记 13:42; 利未记 13:3; 利未记 13:19–20"> 他要察看那灾病，灾病若在房子的墙上有发绿或发红的凹斑纹，现象洼于墙，</span>
<span className="v" id="v38" data-v="38" data-xref="利未记 13:50"> 祭司就要出到房门外，把房子封锁七天。</span>
<span className="v" id="v39" data-v="39" data-xref="利未记 13:36; 利未记 13:27; 利未记 13:22"> 第七天，祭司要再去察看，灾病若在房子的墙上发散，</span>
<span className="v" id="v40" data-v="40" data-xref="启示录 2:20; 提多书 3:10; 哥林多前书 5:5–6"> 就要吩咐人把那有灾病的石头挖出来，扔在城外不洁净之处；</span>
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 65:4; 启示录 22:15; 马太福音 24:51"> 也要叫人刮房内的四围，所刮掉的灰泥要倒在城外不洁净之处；</span>
<span className="v" id="v42" data-v="42" data-xref="提摩太后书 2:2; 提摩太前书 5:21–22; 历代志下 17:7–9"> 又要用别的石头代替那挖出来的石头，要另用灰泥墁房子。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="耶利米书 6:28–30; 犹大书 1:12; 彼得后书 2:20"> “他挖出石头，刮了房子，墁了以后，灾病若在房子里又发现，</span>
<span className="v" id="v44" data-v="44" data-xref="利未记 13:51–52; 撒迦利亚书 5:4"> 祭司就要进去察看，灾病若在房子里发散，这就是房内蚕食的大麻风，是不洁净。</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪下 10:27; 马太福音 24:2; 列王纪上 9:6–9"> 他就要拆毁房子，把石头、木头、灰泥都搬到城外不洁净之处。</span>
<span className="v" id="v46" data-v="46" data-xref="民数记 19:21–22; 利未记 22:6; 利未记 11:28"> 在房子封锁的时候，进去的人必不洁净到晚上，</span>
<span className="v" id="v47" data-v="47" data-xref="利未记 14:8–9; 利未记 11:25"> 在房子里躺着的必洗衣服，在房子里吃饭的也必洗衣服。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="哥林多前书 6:11; 约伯记 5:18; 马可福音 5:29"> “房子墁了以后，祭司若进去察看，见灾病在房内没有发散，就要定房子为洁净，因为灾病已经消除。</span>
<span className="v" id="v49" data-v="49" data-xref="利未记 14:4"> 要为洁净房子取两只鸟和香柏木、朱红色线并牛膝草，</span>
<span className="v" id="v50" data-v="50"> 用瓦器盛活水，把一只鸟宰在上面，</span>
<span className="v" id="v51" data-v="51" data-xref="诗篇 51:7"> 把香柏木、牛膝草、朱红色线并那活鸟，都蘸在被宰的鸟血中与活水中，用以洒房子七次。</span>
<span className="v" id="v52" data-v="52"> 要用鸟血、活水、活鸟、香柏木、牛膝草并朱红色线，洁净那房子，</span>
<span className="v" id="v53" data-v="53" data-xref="利未记 14:20; 利未记 14:7"> 但要把活鸟放在城外田野里。这样洁净房子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：为房子赎罪。">a</a></sup>，房子就洁净了。</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="利未记 15:32; 利未记 14:32; 利未记 6:9"> “这是为各类大麻风的灾病和头疥，</span>
<span className="v" id="v55" data-v="55" data-xref="利未记 13:47–59"> 并衣服与房子的大麻风，</span>
<span className="v" id="v56" data-v="56" data-xref="利未记 13:2"> 以及疖子、癣、火斑所立的条例，</span>
<span className="v" id="v57" data-v="57" data-xref="利未记 10:10; 以西结书 44:23; 耶利米书 15:19"> 指明何时为洁净，何时为不洁净。这是大麻风的条例。”</span>
</div>
</div>

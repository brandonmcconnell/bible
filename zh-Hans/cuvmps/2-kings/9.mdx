## 以利沙遣徒诣耶户

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 10:1; 列王纪下 4:29; 列王纪上 1:39"> 先知以利沙叫了一个先知门徒来，吩咐他说：“你束上腰，手拿这瓶膏油往基列的拉末去。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 9:5; 列王纪上 19:16–17; 列王纪下 9:11"> 到了那里，要寻找宁示的孙子、约沙法的儿子耶户，使他从同僚中起来，带他进严密的屋子，</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 19:16; 出埃及记 29:7; 撒母耳记上 16:2"> 将瓶里的膏油倒在他头上，说：‘耶和华如此说：我膏你做以色列王。’说完了，就开门逃跑，不要迟延。”</span>
<span className="v" id="v4" data-v="4"> 于是那少年先知往基列的拉末去了。</span>
</div>
</div>

## 耶户为以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="士师记 3:19"> 到了那里，看见众军长都坐着，就说：“将军哪，我有话对你说。”耶户说：“我们众人里，你要对哪一个说呢？”回答说：“将军哪，我要对你说。”</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 22:7; 列王纪上 19:16; 列王纪下 9:3"> 耶户就起来，进了屋子。少年人将膏油倒在他头上，对他说：“耶和华以色列的神如此说：我膏你做耶和华民以色列的王。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 21:15; 列王纪上 18:4; 申命记 32:43"> 你要击杀你主人亚哈的全家，我好在耶洗别身上申我仆人众先知和耶和华一切仆人流血的冤。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 25:22; 申命记 32:36; 列王纪下 14:26"> 亚哈全家必都灭亡，凡属亚哈的男丁，无论是困住的、自由的，我必从以色列中剪除，</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 15:29; 列王纪上 21:22; 列王纪上 14:10–11"> 使亚哈的家像尼八儿子耶罗波安的家，又像亚希雅儿子巴沙的家。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 21:23; 列王纪下 9:35–36; 列王纪下 9:3"> 耶洗别必在耶斯列田里被狗所吃，无人葬埋。”说完了，少年人就开门逃跑了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米书 29:26; 使徒行传 26:24; 何西阿书 9:7"> 耶户出来，回到他主人的臣仆那里。有一人问他说：“平安吗？这狂妄的人来见你有什么事呢？”回答说：“你们认得那人，也知道他说什么。”</span>
<span className="v" id="v12" data-v="12"> 他们说：“这是假话，你据实地告诉我们。”回答说：“他如此如此对我说，他说：‘耶和华如此说：我膏你做以色列王。’”</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 11:7–8; 列王纪上 1:39; 列王纪上 1:34"> 他们就急忙各将自己的衣服铺在上层台阶，使耶户坐在其上。他们吹角，说：“耶户做王了！”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王纪下 8:28; 列王纪上 22:3; 列王纪上 16:16"> 这样，宁示的孙子、约沙法的儿子耶户背叛约兰。先是约兰和以色列众人因为亚兰王哈薛的缘故，把守基列的拉末，</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 8:29; 撒母耳记上 27:9–11; 历代志下 22:6"> 但约兰王回到耶斯列，医治与亚兰王哈薛打仗所受的伤。耶户说：“若合你们的意思，就不容人逃出城往耶斯列报信去。”</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 22:6–7; 列王纪下 8:28–29"> 于是耶户坐车往耶斯列去，因为约兰病卧在那里；犹大王亚哈谢已经下去望看他。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 16:4; 以西结书 33:2–9; 列王纪下 7:14"> 有一个守望的人站在耶斯列的楼上，看见耶户带着一群人来，就说：“我看见一群人。”约兰说：“打发一个骑马的去迎接他们，问说：‘平安不平安？’”</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 9:19; 列王纪下 9:22; 耶利米书 16:5"> 骑马的就去迎接耶户，说：“王问说：‘平安不平安？’”耶户说：“平安不平安与你何干？你转在我后头吧！”守望的人又说：“使者到了他们那里，却不回来。”</span>
<span className="v" id="v19" data-v="19"> 王又打发一个骑马的去。这人到了他们那里，说：“王问说：‘平安不平安？’”耶户说：“平安不平安与你何干？你转在我后头吧！”</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记下 18:27; 列王纪上 19:17; 传道书 9:10"> 守望的人又说：“他到了他们那里，也不回来。车赶得甚猛，像宁示的孙子耶户的赶法。”</span>
</div>
</div>

## 射杀约兰

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王纪上 21:1–7; 历代志下 22:7; 弥迦书 1:13"> 约兰吩咐说：“套车！”人就给他套车。以色列王约兰和犹大王亚哈谢各坐自己的车出去迎接耶户，在耶斯列人拿伯的田那里遇见他。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 21:13; 那鸿书 3:4; 列王纪上 16:30–33"> 约兰见耶户就说：“耶户啊，平安吗？”耶户说：“你母亲耶洗别的淫行邪术这样多，焉能平安呢？”</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 11:14; 历代志下 23:13"> 约兰就转车逃跑，对亚哈谢说：“亚哈谢啊，反了！”</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 22:34; 箴言 21:30; 帖撒罗尼迦前书 5:3"> 耶户开满了弓，射中约兰的脊背，箭从心窝穿出，约兰就仆倒在车上。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 21:19; 列王纪上 21:24–29; 以赛亚书 13:1"> 耶户对他的军长毕甲说：“你把他抛在耶斯列人拿伯的田间！你当追想，你我一同坐车跟随他父亚哈的时候，耶和华对亚哈所说的预言，</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 21:19; 申命记 5:9; 历代志下 25:4"> 说：‘我昨日看见拿伯的血和他众子的血，我必在这块田上报应你。’这是耶和华说的。现在你要照着耶和华的话，把他抛在这田间。”</span>
</div>
</div>

## 击杀亚哈谢

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="士师记 1:27; 约书亚记 17:11; 列王纪下 8:29"> 犹大王亚哈谢见这光景，就从园亭之路逃跑。耶户追赶他，说：“把这人也杀在车上！”到了靠近以伯莲姑珥的坡上，击伤了他。他逃到米吉多，就死在那里。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 35:24; 列王纪下 23:30; 列王纪下 12:21"> 他的臣仆用车将他的尸首送到耶路撒冷，葬在大卫城他自己的坟墓里，与他列祖同葬。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="历代志下 21:18–19; 历代志下 22:1–2; 列王纪下 8:24–25"> 亚哈谢登基做犹大王的时候，是在亚哈的儿子约兰第十一年。</span>
</div>
</div>

## 掷杀耶洗别

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米书 4:30; 以西结书 23:40; 以西结书 24:17"> 耶户到了耶斯列，耶洗别听见就擦粉，梳头，从窗户里往外观看。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪上 16:9–20"> 耶户进门的时候，耶洗别说：“杀主人的心利啊，平安吗？”</span>
<span className="v" id="v32" data-v="32" data-xref="以斯帖记 2:15; 出埃及记 32:26; 历代志下 11:12"> 耶户抬头向窗户观看，说：“谁顺从我？”有两三个太监从窗户往外看他。</span>
<span className="v" id="v33" data-v="33" data-xref="弥迦书 7:10; 耶利米哀歌 1:15; 以赛亚书 25:10"> 耶户说：“把她扔下来！”他们就把她扔下来。她的血溅在墙上和马上，于是把她践踏了。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 16:31; 列王纪上 21:25; 以赛亚书 65:15"> 耶户进去，吃了喝了，吩咐说：“你们把这被咒诅的妇人葬埋了，因为她是王的女儿。”</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 12:23; 以赛亚书 14:18–20; 约伯记 31:3"> 他们就去葬埋她，只寻得她的头骨和脚并手掌。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 21:23; 利未记 8:36; 列王纪下 14:25"> 他们回去告诉耶户，耶户说：“这正应验耶和华藉他仆人提斯比人以利亚所说的话，说：‘在耶斯列田间，狗必吃耶洗别的肉。</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 8:2; 诗篇 83:10; 耶利米书 16:4"> 耶洗别的尸首必在耶斯列田间如同粪土，甚至人不能说这是耶洗别。’”</span>
</div>
</div>

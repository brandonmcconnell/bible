## 以利沙为嫠妇行奇事

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 18:25; 列王纪下 2:3; 尼希米记 5:2–5"> 有一个先知门徒的妻哀求以利沙说：“你仆人我丈夫死了，他敬畏耶和华是你所知道的。现在有债主来，要取我两个儿子做奴仆。”</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 17:12; 雅各书 2:5; 列王纪下 6:26–27"> 以利沙问她说：“我可以为你做什么呢？你告诉我，你家里有什么？”她说：“婢女家中除了一瓶油之外，没有什么。”</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 2:7; 诗篇 81:10; 约翰福音 16:24"> 以利沙说：“你去，向你众邻舍借空器皿，不要少借。</span>
<span className="v" id="v4" data-v="4" data-xref="马可福音 8:5–9; 马太福音 6:6; 以弗所书 3:20"> 回到家里，关上门，你和你儿子在里面将油倒在所有的器皿里，倒满了的放在一边。”</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 5:11; 希伯来书 11:7–8; 列王纪上 17:15–16"> 于是妇人离开以利沙去了，关上门，自己和儿子在里面，儿子把器皿拿来，她就倒油。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 14:20; 列王纪下 13:19; 路加福音 6:19"> 器皿都满了，她对儿子说：“再给我拿器皿来。”儿子说：“再没有器皿了。”油就止住了。</span>
<span className="v" id="v7" data-v="7" data-xref="帖撒罗尼迦后书 3:7–12; 列王纪上 12:22; 罗马书 12:17"> 妇人去告诉神人，神人说：“你去卖油还债，所剩的，你和你儿子可以靠着度日。”</span>
</div>
</div>

## 书念妇接待以利沙

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约书亚记 19:18; 创世记 19:3; 列王纪下 4:11–12"> 一日，以利沙走到书念，在那里有一个大户的妇人强留他吃饭。此后以利沙每从那里经过，就进去吃饭。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 17:24; 箴言 31:10–11; 列王纪下 4:7"> 妇人对丈夫说：“我看出那常从我们这里经过的是圣洁的神人。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 12:13; 马太福音 10:41–42; 马太福音 25:40"> 我们可以为他在墙上盖一间小楼，在其中安放床榻、桌子、椅子、灯台，他来到我们这里，就可以住在其间。”</span>
<span className="v" id="v11" data-v="11"> 一日以利沙来到那里，就进了那楼躺卧。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 8:4–5; 列王纪下 3:11; 列王纪下 4:29–31"> 以利沙吩咐仆人基哈西说：“你叫这书念妇人来。”他就把妇人叫了来，妇人站在以利沙面前。</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太后书 1:16–18; 腓立比书 4:18–19; 希伯来书 6:10"> 以利沙吩咐仆人说：“你对她说：‘你既为我们费了许多心思，可以为你做什么呢？你向王或元帅有所求的没有？’”她回答说：“我在我本乡安居无事。”</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 1:7; 创世记 15:2–3; 撒母耳记上 1:8"> 以利沙对仆人说：“究竟当为她做什么呢？”基哈西说：“她没有儿子，她丈夫也老了。”</span>
<span className="v" id="v15" data-v="15"> 以利沙说：“再叫她来。”于是叫了她来，她就站在门口。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 18:10; 路加福音 1:13; 列王纪下 4:28"> 以利沙说：“明年到这时候，你必抱一个儿子。”她说：“神人，我主啊，不要那样欺哄婢女！”</span>
</div>
</div>

## 子死以利沙苏之

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路得记 2:4"> 孩子渐渐长大，一日到他父亲和收割的人那里。</span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 14:1–2; 耶利米书 4:19"> 他对父亲说：“我的头啊！我的头啊！”他父亲对仆人说：“把他抱到他母亲那里。”</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 7:12; 约翰福音 11:3; 约翰福音 11:14"> 仆人抱去，交给他母亲，孩子坐在母亲的膝上，到晌午就死了。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 4:32; 列王纪下 4:10; 列王纪下 4:7"> 他母亲抱他上了楼，将他放在神人的床上，关上门出来，</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 9:38; 列王纪下 4:26; 约翰福音 11:3"> 呼叫她丈夫说：“你叫一个仆人，给我牵一匹驴来，我要快快地去见神人，就回来。”</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 10:10; 民数记 28:11; 历代志上 23:31"> 丈夫说：“今日不是月朔，也不是安息日，你为何要去见他呢？”妇人说：“平安无事。”</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 4:20; 列王纪上 13:13; 撒母耳记上 25:19–20"> 于是备上驴，对仆人说：“你快快赶着走，我若不吩咐你，就不要迟慢。”</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 2:25; 以赛亚书 35:2; 列王纪上 18:19"> 妇人就往迦密山去见神人。<br />神人远远地看见她，对仆人基哈西说：“看哪，书念的妇人来了。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 15:36; 列王纪下 4:23; 撒母耳记上 17:18"> 你跑去迎接她，问她说：‘你平安吗？你丈夫平安吗？孩子平安吗？’”她说：“平安。”</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记下 7:3; 创世记 18:17; 阿摩司书 3:7"> 妇人上了山，到神人那里，就抱住神人的脚。基哈西前来要推开她，神人说：“由她吧！因为她心里愁苦。耶和华向我隐瞒，没有指示我。”</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 30:1; 列王纪下 4:16"> 妇人说：“我何尝向我主求过儿子呢？我岂没有说过，不要欺哄我吗？”</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪下 2:14; 列王纪上 18:46; 出埃及记 14:16"> 以利沙吩咐基哈西说：“你束上腰，手拿我的杖前去。若遇见人，不要向他问安，人若向你问安，也不要回答。要把我的杖放在孩子脸上。”</span>
<span className="v" id="v30" data-v="30" data-xref="路得记 1:16–18; 列王纪下 2:2; 出埃及记 33:12–16"> 孩子的母亲说：“我指着永生的耶和华，又敢在你面前起誓：我必不离开你！”于是以利沙起身，随着她去了。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 11:11; 马可福音 5:39; 马可福音 9:19–29"> 基哈西先去，把杖放在孩子脸上，却没有声音，也没有动静。基哈西就迎着以利沙回来，告诉他说：“孩子还没有醒过来。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="路加福音 8:52–53; 约翰福音 11:17; 列王纪上 17:17"> 以利沙来到，进了屋子，看见孩子死了，放在自己的床上。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 6:6; 列王纪下 4:4; 使徒行传 9:40"> 他就关上门，只有自己和孩子在里面，他便祈祷耶和华。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 17:21; 使徒行传 20:10"> 上床伏在孩子身上，口对口，眼对眼，手对手。既伏在孩子身上，孩子的身体就渐渐温和了。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪下 8:5; 列王纪下 13:21; 列王纪上 17:22"> 然后他下来，在屋里来往走了一趟，又上去伏在孩子身上。孩子打了七个喷嚏，就睁开眼睛了。</span>
<span className="v" id="v36" data-v="36" data-xref="希伯来书 11:35; 列王纪上 17:23; 路加福音 7:15"> 以利沙叫基哈西说：“你叫这书念妇人来。”于是叫了她来。以利沙说：“将你儿子抱起来。”</span>
<span className="v" id="v37" data-v="37" data-xref="希伯来书 11:35; 列王纪下 2:15; 列王纪上 17:24"> 妇人就进来，在以利沙脚前俯伏于地，抱起她儿子出去了。</span>
</div>
</div>

## 先知徒中毒以利沙解之

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="列王纪下 8:1; 列王纪下 2:3; 列王纪下 2:1"> 以利沙又来到吉甲，那地正有饥荒。先知门徒坐在他面前，他吩咐仆人说：“你将大锅放在火上，给先知门徒熬汤。”</span>
<span className="v" id="v39" data-v="39" data-xref="耶利米书 2:21; 以赛亚书 5:4; 马太福音 15:13"> 有一个人去到田野掐菜，遇见一棵野瓜藤，就摘了一兜野瓜回来，切了搁在熬汤的锅中，因为他们不知道是什么东西。</span>
<span className="v" id="v40" data-v="40" data-xref="马可福音 16:18; 出埃及记 15:23; 出埃及记 10:17"> 倒出来给众人吃，吃的时候，都喊叫说：“神人哪，锅中有致死的毒物！”所以众人不能吃了。</span>
<span className="v" id="v41" data-v="41" data-xref="列王纪下 2:21; 出埃及记 15:25; 哥林多前书 1:25"> 以利沙说：“拿点面来。”就把面撒在锅中，说：“倒出来给众人吃吧。”锅中就没有毒了。</span>
</div>
</div>

## 以二十饼饱百人

<div className="bt">
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="撒母耳记上 9:7; 约翰福音 6:9; 马太福音 14:16–21"> 有一个人从巴力沙利沙来，带着初熟大麦做的饼二十个并新穗子，装在口袋里送给神人。神人说：“把这些给众人吃。”</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 9:13; 马太福音 14:20; 约翰福音 6:9"> 仆人说：“这一点岂可摆给一百人吃呢？”以利沙说：“你只管给众人吃吧，因为耶和华如此说：‘众人必吃了，还剩下。’”</span>
<span className="v" id="v44" data-v="44"> 仆人就摆在众人面前。他们吃了，果然还剩下，正如耶和华所说的。</span>
</div>
</div>

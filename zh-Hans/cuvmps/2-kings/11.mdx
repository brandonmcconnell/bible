## 亚她利雅灭王室自立

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 41:1; 列王纪下 25:25; 历代志下 22:10–12"> 亚哈谢的母亲亚她利雅见她儿子死了，就起来剿灭王室。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 33:26; 耶利米书 35:2; 以赛亚书 7:6–7"> 但约兰王的女儿、亚哈谢的妹子约示巴将亚哈谢的儿子约阿施从那被杀的王子中偷出来，把他和他的乳母都藏在卧房里，躲避亚她利雅，免得被杀。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 12:8; 历代志下 22:12; 玛拉基书 3:15"> 约阿施和他的乳母藏在耶和华的殿里六年。亚她利雅篡了国位。</span>
</div>
</div>

## 耶何耶大与众立约誓辅王子

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 11:19; 列王纪下 11:9; 列王纪下 11:17"> 第七年，耶何耶大打发人叫迦利人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：亲兵。">a</a></sup>和护卫兵的众百夫长来，领他们进了耶和华的殿，与他们立约，使他们在耶和华殿里起誓，又将王的儿子指给他们看，</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 9:25; 以西结书 44:2–3; 历代志上 23:32"> 吩咐他们说：“你们当这样行：凡安息日进班的，三分之一要看守王宫，</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 23:4–5; 历代志上 26:13–19"> 三分之一要在苏珥门，三分之一要在护卫兵院的后门。这样把守王宫，拦阻闲人。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 23:6; 列王纪下 11:5"> 你们安息日所有出班的三分之二，要在耶和华的殿里护卫王。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 27:17; 历代志下 23:7; 列王纪上 2:28–31"> 各人手拿兵器，四围护卫王，凡擅入你们班次的必当治死。王出入的时候，你们当跟随他。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="历代志下 23:8; 列王纪下 11:4; 历代志上 26:26"> 众百夫长就照着祭司耶何耶大一切所吩咐的去行，各带所管安息日进班出班的人来见祭司耶何耶大。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 8:7; 历代志上 18:7; 历代志下 5:1"> 祭司便将耶和华殿里所藏大卫王的枪和盾牌交给百夫长。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 11:8; 以西结书 8:16; 列王纪下 11:10"> 护卫兵手中各拿兵器，在坛和殿那里，从殿右直到殿左，站在王子的四围。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 25:16; 撒母耳记上 10:24; 列王纪上 1:39"> 祭司领王子出来，给他戴上冠冕，将律法书交给他，膏他做王。众人就拍掌说：“愿王万岁！”</span>
</div>
</div>

## 亚她利雅见杀

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志下 23:12–15"> 亚她利雅听见护卫兵和民的声音，就到民那里，进耶和华的殿。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 34:31; 列王纪下 23:3; 列王纪下 9:23"> 看见王照例站在柱旁，百夫长和吹号的人侍立在王左右，国中的众民欢乐、吹号，亚她利雅就撕裂衣服，喊叫说：“反了！反了！”</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 9:7; 历代志下 23:14; 历代志下 23:9"> 祭司耶何耶大吩咐管辖军兵的百夫长说：“将她赶出班外，凡跟随她的必用刀杀死。”因为祭司说：“不可在耶和华殿里杀她。”</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 9:6; 历代志下 23:15; 马太福音 7:2"> 众兵就闪开让她去，她从马路上王宫去，便在那里被杀。</span>
</div>
</div>

## 耶何耶大使王与民崇侍耶和华

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 5:3; 历代志下 15:12–14; 历代志下 34:31"> 耶何耶大使王和民与耶和华立约，做耶和华的民，又使王与民立约。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 12:3; 列王纪下 10:26; 列王纪上 18:40"> 于是国民都到巴力庙，拆毁了庙，打碎坛和像，又在坛前将巴力的祭司玛坦杀了。祭司耶何耶大派官看守耶和华的殿，</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 17:25; 耶利米书 22:4; 历代志下 23:19"> 又率领百夫长和迦利人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：亲兵。">b</a></sup>与护卫兵，以及国中的众民，请王从耶和华殿下来，由护卫兵的门进入王宫。他就坐了王位。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 11:10; 箴言 29:2; 列王纪下 11:14"> 国民都欢乐，合城都安静。众人已将亚她利雅在王宫那里用刀杀了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="历代志下 24:1–14; 列王纪下 22:1; 列王纪下 11:4"> 约阿施登基的时候年方七岁。</span>
</div>
</div>

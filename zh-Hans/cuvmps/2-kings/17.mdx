## 何细亚做以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 15:30"> 犹大王亚哈斯十二年，以拉的儿子何细亚在撒马利亚登基，做以色列王九年。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 3:2; 列王纪下 13:11; 历代志下 30:5–11"> 他行耶和华眼中看为恶的事，只是不像在他以前的以色列诸王。</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿书 10:14; 列王纪下 15:19; 列王纪下 19:36–37"> 亚述王撒缦以色上来攻击何细亚，何细亚就服侍他，给他进贡。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 18:21; 列王纪下 24:20; 以西结书 17:13–19"> 何细亚背叛，差人去见埃及王梭，不照往年所行的与亚述王进贡。亚述王知道了，就把他锁禁，囚在监里。</span>
</div>
</div>

## 亚述王陷撒马利亚

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="何西阿书 13:16; 列王纪下 25:1–3; 列王纪下 18:9"> 亚述王上来攻击以色列遍地，上到撒马利亚，围困三年。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 5:26; 何西阿书 13:16; 申命记 28:64"> 何细亚第九年，亚述王攻取了撒马利亚，将以色列人掳到亚述，把他们安置在哈腊与歌散的哈博河边，并玛代人的城邑。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约书亚记 23:16; 诗篇 106:35–41; 尼希米记 9:26"> 这是因以色列人得罪那领他们出埃及地，脱离埃及王法老手的耶和华他们的神，去敬畏别神，</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 18:3; 列王纪下 16:3; 申命记 18:9"> 随从耶和华在他们面前所赶出外邦人的风俗和以色列诸王所立的条规。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 18:8; 约伯记 31:27; 申命记 13:6"> 以色列人暗中行不正的事，违背耶和华他们的神，在他们所有的城邑，从瞭望楼直到坚固城，建筑丘坛；</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 14:23; 弥迦书 5:14; 出埃及记 34:13"> 在各高冈上、各青翠树下立柱像和木偶；</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 28:25; 列王纪下 21:6; 耶利米书 44:17"> 在丘坛上烧香，效法耶和华在他们面前赶出的外邦人所行的；又行恶事，惹动耶和华的怒气；</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 12:4; 出埃及记 20:3–5; 申命记 4:23–25"> 且侍奉偶像，就是耶和华警戒他们不可行的。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 35:15; 撒母耳记上 9:9; 耶利米书 18:11"> 但耶和华藉众先知、先见劝诫以色列人和犹大人说：“当离开你们的恶行，谨守我的诫命、律例，遵行我吩咐你们列祖并藉我仆人众先知所传给你们的律法。”</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 31:27; 使徒行传 7:51; 诗篇 106:24"> 他们却不听从，竟硬着颈项，效法他们列祖，不信服耶和华他们的神，</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 12:30–31; 申命记 32:21; 罗马书 1:21–23"> 厌弃他的律例和他与他们列祖所立的约并劝诫他们的话，随从虚无的神，自己成为虚妄，效法周围的外邦人，就是耶和华嘱咐他们不可效法的。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 14:23; 列王纪上 16:31; 列王纪上 14:15"> 离弃耶和华他们神的一切诫命，为自己铸了两个牛犊的像，立了亚舍拉，敬拜天上的万象，侍奉巴力；</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 21:6; 列王纪下 16:3; 申命记 18:10–12"> 又使他们的儿女经火，用占卜，行法术，卖了自己行耶和华眼中看为恶的事，惹动他的怒气。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 12:20; 列王纪上 11:13; 何西阿书 11:12"> 所以耶和华向以色列人大大发怒，从自己面前赶出他们，只剩下犹大一个支派。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王纪下 16:3; 列王纪上 14:22–23; 以西结书 16:51–52"> 犹大人也不遵守耶和华他们神的诫命，随从以色列人所立的条规。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 15:29; 耶利米书 6:30; 列王纪下 13:3"> 耶和华就厌弃以色列全族，使他们受苦，把他们交在抢夺他们的人手中，以致赶出他们离开自己面前，</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 11:11; 列王纪上 11:31; 列王纪上 14:16"> 将以色列国从大卫家夺回，他们就立尼八的儿子耶罗波安做王。耶罗波安引诱以色列人不随从耶和华，陷在大罪里。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 3:3; 列王纪下 13:6; 列王纪下 13:11"> 以色列人犯耶罗波安所犯的一切罪，总不离开，</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 17:6; 列王纪下 17:13; 列王纪下 17:20"> 以致耶和华从自己面前赶出他们，正如藉他仆人众先知所说的。这样，以色列人从本地被掳到亚述，直到今日。</span>
</div>
</div>

## 置异族人于撒马利亚

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王纪下 18:34; 列王纪下 17:30–31; 马太福音 10:5"> 亚述王从巴比伦、古他、亚瓦、哈马和西法瓦音迁移人来，安置在撒马利亚的城邑，代替以色列人。他们就得了撒马利亚，住在其中。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 17:32; 列王纪下 17:34; 列王纪下 17:41"> 他们才住那里的时候，不敬畏耶和华，所以耶和华叫狮子进入他们中间，咬死了些人。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 17:27; 撒母耳记上 8:9; 阿摩司书 8:14"> 有人告诉亚述王说：“你所迁移安置在撒马利亚各城的那些民不知道那地之神的规矩，所以那神叫狮子进入他们中间，咬死他们。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="士师记 17:13; 列王纪上 12:31; 列王纪上 13:2"> 亚述王就吩咐说：“叫所掳来的祭司回去一个，使他住在那里，将那地之神的规矩指教那些民。”</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪上 12:29–32; 以赛亚书 29:13; 马太福音 15:14"> 于是有一个从撒马利亚掳去的祭司回来，住在伯特利，指教他们怎样敬畏耶和华。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪上 12:31; 弥迦书 4:5; 列王纪上 13:32"> 然而各族之人在所住的城里各为自己制造神像，安置在撒马利亚人所造有丘坛的殿中。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 17:24"> 巴比伦人造疏割比讷像，古他人造匿甲像，哈马人造亚示玛像，</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 17:24; 列王纪下 17:17; 列王纪下 19:37"> 亚瓦人造匿哈和他珥他像，西法瓦音人用火焚烧儿女献给西法瓦音的神亚得米勒和亚拿米勒。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 12:31; 列王纪下 17:29; 列王纪上 13:33"> 他们惧怕耶和华，也从他们中间立丘坛的祭司，为他们在有丘坛的殿中献祭。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪下 17:41; 路加福音 16:13; 马太福音 6:24"> 他们又惧怕耶和华，又侍奉自己的神，从何邦迁移，就随何邦的风俗。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="创世记 32:28; 创世记 35:10; 列王纪下 17:27–28"> 他们直到如今仍照先前的风俗去行，不专心敬畏耶和华，不全守自己的规矩、典章，也不遵守耶和华吩咐雅各后裔的律法、诫命；雅各，就是从前耶和华起名叫以色列的。</span>
<span className="v" id="v35" data-v="35" data-xref="士师记 6:10; 约书亚记 23:16; 约书亚记 23:7"> 耶和华曾与他们立约，嘱咐他们说：“不可敬畏别神，不可跪拜侍奉他，也不可向他献祭。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 6:6; 申命记 6:13; 利未记 19:32"> 但那用大能和伸出来的膀臂领你们出埃及地的耶和华，你们当敬畏、跪拜，向他献祭。</span>
<span className="v" id="v37" data-v="37" data-xref="利未记 19:37; 申命记 5:31–2; 申命记 4:44–45"> 他给你们写的律例、典章、律法、诫命，你们应当永远谨守遵行，不可敬畏别神。</span>
<span className="v" id="v38" data-v="38" data-xref="申命记 4:23; 申命记 6:12; 申命记 8:14–18"> 我耶和华与你们所立的约，你们不可忘记，也不可敬畏别神，</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 1:74–75; 撒母耳记上 12:24; 马太福音 10:28"> 但要敬畏耶和华你们的神，他必救你们脱离一切仇敌的手。”</span>
<span className="v" id="v40" data-v="40" data-xref="申命记 4:28; 列王纪下 17:8; 耶利米书 13:23"> 他们却不听从，仍照先前的风俗去行。</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 6:24; 西番雅书 1:5; 列王纪上 18:21"> 如此，这些民又惧怕耶和华，又侍奉他们的偶像。他们子子孙孙也都照样行，效法他们的祖宗，直到今日。</span>
</div>
</div>

## 摩押王米沙叛

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 1:17; 列王纪上 22:51; 列王纪下 8:16"> 犹大王约沙法十八年，亚哈的儿子约兰在撒马利亚登基，做了以色列王十二年。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 10:18; 列王纪下 10:26–28; 列王纪上 21:25"> 他行耶和华眼中看为恶的事，但不至像他父母所行的，因为除掉他父所造巴力的柱像。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 14:16; 列王纪上 15:34; 列王纪下 15:18"> 然而，他贴近尼八的儿子耶罗波安使以色列人陷在罪里的那罪，总不离开。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 8:2; 创世记 26:13–14; 约伯记 1:3"> 摩押王米沙牧养许多羊，每年将十万羊羔的毛和十万公绵羊的毛给以色列王进贡。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 1:1; 列王纪下 8:20; 历代志下 21:8–10"> 亚哈死后，摩押王背叛以色列王。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 24:1–25; 撒母耳记上 11:8; 撒母耳记上 15:4"> 那时约兰王出撒马利亚，数点以色列众人。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 22:4; 历代志下 22:10–12; 历代志下 18:3"> 前行的时候，差人去见犹大王约沙法，说：“摩押王背叛我，你肯同我去攻打摩押吗？”他说：“我肯上去。你我不分彼此，我的民与你的民一样，我的马与你的马一样。”</span>
<span className="v" id="v8" data-v="8" data-xref="玛拉基书 1:2–3; 民数记 21:4"> 约兰说：“我们从哪条路上去呢？”回答说：“从以东旷野的路上去。”</span>
</div>
</div>

## 三王合攻摩押

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王纪上 22:47; 民数记 20:2; 出埃及记 17:1"> 于是，以色列王和犹大王并以东王都一同去。绕行七日的路程，军队和所带的牲畜没有水喝。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 78:34–36; 以赛亚书 51:20; 以赛亚书 8:21"> 以色列王说：“哀哉！耶和华招聚我们这三王，乃要交在摩押人的手里！”</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 22:7; 列王纪上 19:21; 列王纪下 3:3"> 约沙法说：“这里不是有耶和华的先知吗？我们可以托他求问耶和华。”以色列王的一个臣子回答说：“这里有沙法的儿子以利沙，就是从前服侍以利亚的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：倒水在以利亚手上的。">a</a></sup>。”</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 5:15; 列王纪下 2:21; 以赛亚书 60:14"> 约沙法说：“他必有耶和华的话。”于是以色列王和约沙法并以东王都下去见他。</span>
</div>
</div>

## 以利沙之训导与预言

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王纪上 22:6; 列王纪上 18:19; 列王纪上 22:10–11"> 以利沙对以色列王说：“我与你何干？去问你父亲的先知和你母亲的先知吧！”以色列王对他说：“不要这样说，耶和华招聚我们这三王，乃要交在摩押人的手里。”</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 5:16; 列王纪上 17:1; 历代志下 19:3–4"> 以利沙说：“我指着所侍奉永生的万军耶和华起誓，我若不看犹大王约沙法的情面，必不理你，不顾你。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 16:23; 以弗所书 5:18–19; 以西结书 1:3"> 现在你们给我找一个弹琴的来。”弹琴的时候，耶和华的灵<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：手。">b</a></sup>就降在以利沙身上。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 2:16–18; 列王纪下 4:3"> 他便说：“耶和华如此说：你们要在这谷中满处挖沟。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 107:35; 以赛亚书 41:17–18; 以赛亚书 48:21"> 因为耶和华如此说：你们虽不见风，不见雨，这谷必满了水，使你们和牲畜有水喝。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 32:27; 路加福音 1:37; 耶利米书 32:17"> 在耶和华眼中这还算为小事，他也必将摩押人交在你们手中。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 13:17; 申命记 20:19–20; 士师记 6:16"> 你们必攻破一切坚城美邑，砍伐各种佳树，塞住一切水泉，用石头糟蹋一切美田。”</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 29:39–40; 但以理书 9:21; 列王纪上 18:36"> 次日早晨，约在献祭的时候，有水从以东而来，遍地就满了水。</span>
</div>
</div>

## 摩押人败遁

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以弗所书 6:14; 列王纪上 20:11"> 摩押众人听见这三王上来要与他们争战，凡能顶盔贯甲的，无论老少，尽都聚集站在边界上。</span>
<span className="v" id="v22" data-v="22"> 次日早晨，日光照在水上，摩押人起来，看见对面水红如血，</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 5:30; 出埃及记 15:9; 以赛亚书 10:14"> 就说：“这是血啊！必是三王互相击杀，俱都灭亡。摩押人哪，我们现在去抢夺财物吧！”</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦前书 5:3–4; 约书亚记 8:20–22; 士师记 20:40–46"> 摩押人到了以色列营，以色列人就起来攻打他们，以致他们在以色列人面前逃跑。以色列人往前追杀摩押人，直杀入摩押的境内，</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 16:7; 耶利米书 48:36; 耶利米书 48:31"> 拆毁摩押的城邑，各人抛石填满一切美田，塞住一切水泉，砍伐各种佳树，只剩下吉珥哈列设的石墙，甩石的兵在四围攻打那城。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 3:9; 阿摩司书 2:1"> 摩押王见阵势甚大，难以对敌，就率领七百拿刀的兵，要冲过阵去到以东王那里，却是不能。</span>
<span className="v" id="v27" data-v="27" data-xref="弥迦书 6:7; 申命记 12:31; 士师记 11:31"> 便将那应当接续他做王的长子，在城上献为燔祭。以色列人遭遇耶和华的大怒<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作：招人痛恨。">c</a></sup>，于是三王离开摩押王，各回本国去了。</span>
</div>
</div>

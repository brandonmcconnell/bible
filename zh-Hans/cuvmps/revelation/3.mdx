## 当回想所听见所领受的

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="启示录 2:5; 彼得后书 3:10; 帖撒罗尼迦前书 5:2"> <span className="woj">‘所以要回想你是怎样领受、怎样听见的，又要遵守，并要悔改。若不警醒，我必临到你那里，如同贼一样。我几时临到，你也决不能知道。</span></span>
<span className="v" id="v4" data-v="4" data-xref="启示录 3:5; 启示录 7:9; 传道书 9:8"> <span className="woj">然而在撒狄，你还有几名是未曾污秽自己衣服的，他们要穿白衣与我同行，因为他们是配得过的。</span></span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 10:32; 路加福音 12:8; 启示录 21:27"> <span className="woj">凡得胜的，必这样穿白衣，我也必不从生命册上涂抹他的名，且要在我父面前和我父众使者面前，认他的名。</span></span>
<span className="v" id="v6" data-v="6" data-xref="启示录 2:7"> <span className="woj">圣灵向众教会所说的话，凡有耳的，就应当听！’</span></span>
</div>
</div>

## 寄信给非拉铁非

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 22:22; 马太福音 16:19; 启示录 1:18"> <span className="woj">“你要写信给非拉铁非教会的使者说：‘那圣洁、真实，拿着大卫的钥匙，开了就没有人能关、关了就没有人能开的说：</span></span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 16:9; 歌罗西书 4:3; 启示录 3:7"> <span className="woj">我知道你的行为，你略有一点力量，也曾遵守我的道，没有弃绝我的名，看哪，我在你面前给你一个敞开的门，是无人能关的。</span></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 60:14; 启示录 2:9; 以赛亚书 49:23"> <span className="woj">那撒旦一会的，自称是犹太人，其实不是犹太人，乃是说谎话的，我要使他们来在你脚前下拜，也使他们知道我是已经爱你了。</span></span>
</div>
</div>

## 要持守免得失去冠冕

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="彼得后书 2:9; 启示录 14:12; 撒迦利亚书 13:9"> <span className="woj">‘你既遵守我忍耐的道，我必在普天下人受试炼的时候，保守你免去你的试炼。</span></span>
<span className="v" id="v11" data-v="11" data-xref="雅各书 1:12; 启示录 22:12; 启示录 2:10"> <span className="woj">我必快来！你要持守你所有的，免得人夺去你的冠冕。</span></span>
<span className="v" id="v12" data-v="12" data-xref="启示录 22:4; 启示录 21:2; 启示录 14:1"> <span className="woj">得胜的，我要叫他在我神殿中做柱子，他也必不再从那里出去。我又要将我神的名和我神城的名——这城就是从天上、从我神那里降下来的新耶路撒冷——并我的新名，都写在他上面。</span></span>
<span className="v" id="v13" data-v="13" data-xref="启示录 2:7"> <span className="woj">圣灵向众教会所说的话，凡有耳的，就应当听！’</span></span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="箴言 13:7; 何西阿书 12:8; 罗马书 7:24"> <span className="woj">‘你说“我是富足，已经发了财，一样都不缺”，却不知道你是那困苦、可怜、贫穷、瞎眼、赤身的。</span></span>
<span className="v" id="v18" data-v="18" data-xref="启示录 16:15; 彼得前书 1:7; 以赛亚书 55:1"> <span className="woj">我劝你向我买火炼的金子，叫你富足；又买白衣穿上，叫你赤身的羞耻不露出来；又买眼药擦你的眼睛，使你能看见。</span></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 3:11–12; 哥林多前书 11:32; 希伯来书 12:5–11"> <span className="woj">凡我所疼爱的，我就责备管教他，所以你要发热心，也要悔改。</span></span>

<span className="v" id="v21" data-v="21" data-xref="提摩太后书 2:12; 马太福音 19:28; 启示录 2:26–27"> <span className="woj">得胜的，我要赐他在我宝座上与我同坐，就如我得了胜，在我父的宝座上与他同坐一般。</span></span>

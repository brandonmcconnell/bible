## 丢了起初的爱心

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="马太福音 24:12–13; 耶利米书 2:2–5; 希伯来书 6:10–11"> <span className="woj">‘然而，有一件事我要责备你，就是你把起初的爱心离弃了。</span></span>
<span className="v" id="v5" data-v="5" data-xref="启示录 3:2–3; 启示录 3:19; 启示录 2:16"> <span className="woj">所以，应当回想你是从哪里坠落的，并要悔改，行起初所行的事。你若不悔改，我就临到你那里，把你的灯台从原处挪去。</span></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 101:3; 约翰二书 1:9–10; 诗篇 26:5"> <span className="woj">然而，你还有一件可取的事，就是你恨恶尼哥拉一党人的行为，这也是我所恨恶的。</span></span>
<span className="v" id="v7" data-v="7" data-xref="启示录 2:17; 启示录 2:11; 马太福音 11:15"> <span className="woj">圣灵向众教会所说的话，凡有耳的，就应当听！得胜的，我必将神乐园中生命树的果子赐给他吃。’</span></span>
</div>
</div>

## 寄信给士每拿

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="启示录 1:17–18; 启示录 1:8; 启示录 1:11"> <span className="woj">“你要写信给士每拿教会的使者说：‘那首先的、末后的、死过又活的说：</span></span>
<span className="v" id="v9" data-v="9" data-xref="启示录 3:9; 哥林多后书 8:9; 雅各书 2:5–6"> <span className="woj">我知道你的患难、你的贫穷，你却是富足的；也知道那自称是犹太人所说的毁谤话，其实他们不是犹太人，乃是撒旦一会的人。</span></span>
</div>
</div>

## 至死忠心必得生命冠冕

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="雅各书 1:12; 马太福音 10:22; 启示录 3:10–11"> <span className="woj">‘你将要受的苦你不用怕。魔鬼要把你们中间几个人下在监里，叫你们被试炼，你们必受患难十日。你务要至死忠心，我就赐给你那生命的冠冕。</span></span>
<span className="v" id="v11" data-v="11" data-xref="启示录 20:6; 启示录 20:14; 启示录 21:8"> <span className="woj">圣灵向众教会所说的话，凡有耳的，就应当听！得胜的，必不受第二次死的害。’</span></span>
</div>
</div>

## 寄信给别迦摩

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="启示录 2:16; 希伯来书 4:12; 启示录 1:16"> <span className="woj">“你要写信给别迦摩教会的使者说：‘那有两刃利剑的说：</span></span>
<span className="v" id="v13" data-v="13" data-xref="启示录 2:9–10; 提摩太前书 5:8; 启示录 3:8–9"> <span className="woj">我知道你的居所，就是有撒旦座位之处。当我忠心的见证人安提帕在你们中间、撒旦所住的地方被杀之时，你还坚守我的名，没有弃绝我的道。</span></span>
<span className="v" id="v14" data-v="14" data-xref="民数记 31:16; 彼得后书 2:15; 启示录 2:20"> <span className="woj">然而，有几件事我要责备你，因为在你那里，有人服从了巴兰的教训。这巴兰曾教导巴勒将绊脚石放在以色列人面前，叫他们吃祭偶像之物，行奸淫的事。</span></span>
<span className="v" id="v15" data-v="15" data-xref="启示录 2:6"> <span className="woj">你那里也有人照样服从了尼哥拉一党人的教训。</span></span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦后书 2:8; 启示录 1:16; 启示录 2:5"> <span className="woj">‘所以，你当悔改！若不悔改，我就快临到你那里，用我口中的剑攻击他们。</span></span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 62:2; 以赛亚书 65:15; 启示录 19:12–13"> <span className="woj">圣灵向众教会所说的话，凡有耳的，就应当听！得胜的，我必将那隐藏的吗哪赐给他，并赐他一块白石，石上写着新名，除了那领受的以外，没有人能认识。’</span></span>
</div>
</div>

## 寄信给推雅推喇

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="启示录 1:14–15; 启示录 1:11; 约翰福音 3:35–36"> <span className="woj">“你要写信给推雅推喇教会的使者说：‘那眼目如火焰、脚像光明铜的神之子说：</span></span>
<span className="v" id="v19" data-v="19" data-xref="提摩太前书 1:5; 彼得后书 1:7; 约翰福音 15:2"> <span className="woj">我知道你的行为、爱心、信心、勤劳、忍耐，又知道你末后所行的善事比起初所行的更多。</span></span>
<span className="v" id="v20" data-v="20" data-xref="启示录 2:14; 列王纪上 16:31; 哥林多前书 10:18–21"> <span className="woj">然而，有一件事我要责备你，就是你容让那自称是先知的妇人耶洗别教导我的仆人，引诱他们行奸淫，吃祭偶像之物。</span></span>
<span className="v" id="v21" data-v="21" data-xref="彼得后书 3:9; 罗马书 2:4–5; 启示录 9:20–21"> <span className="woj">我曾给她悔改的机会，她却不肯悔改她的淫行。</span></span>
<span className="v" id="v22" data-v="22" data-xref="启示录 17:2; 路加福音 13:5; 以西结书 16:37–41"> <span className="woj">看哪，我要叫她病卧在床；那些与她行淫的人，若不悔改所行的，我也要叫他们同受大患难。</span></span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 16:27; 罗马书 8:27; 诗篇 7:9"> <span className="woj">我又要杀死她的党类</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“党类”原文作“儿女”。">a</a></sup><span className="woj">，叫众教会知道我是那察看人肺腑心肠的，并要照你们的行为报应你们各人。</span></span>
</div>
</div>

<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 2:11; 启示录 12:9; 哥林多后书 11:3"> <span className="woj">‘至于你们推雅推喇其余的人，就是一切不从那教训、不晓得他们素常所说撒旦深奥之理的人，我告诉你们：我不将别的担子放在你们身上；</span></span>
<span className="v" id="v25" data-v="25" data-xref="启示录 3:11; 启示录 3:3; 希伯来书 10:23"> <span className="woj">但你们已经有的，总要持守，直等到我来。</span></span>
<span className="v" id="v26" data-v="26" data-xref="启示录 3:21; 但以理书 7:27; 启示录 2:7"> <span className="woj">那得胜又遵守我命令到底的，我要赐给他权柄制伏列国，</span></span>

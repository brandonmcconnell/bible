## 主未降临必有不法者显露

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 4:14–17; 马可福音 13:27; 马太福音 24:31"> 弟兄们，论到我们主耶稣基督降临和我们到他那里聚集，</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 4:1–2; 马可福音 13:7; 马太福音 24:4–6"> 我劝你们：无论有灵，有言语，有冒我名的书信，说主的日子现在<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“现在”或作“就”。">a</a></sup>到了，不要轻易动心，也不要惊慌。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 24:4–6; 约翰一书 2:18; 以弗所书 5:6"> 人不拘用什么法子，你们总不要被他诱惑；因为那日子以前，必有离道反教的事，并有那大罪人，就是沉沦之子，显露出来。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 28:2; 但以理书 7:25; 启示录 13:6–7"> 他是抵挡主，高抬自己超过一切称为神的和一切受人敬拜的，甚至坐在神的殿里自称是神。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得后书 1:15; 加拉太书 5:21; 马太福音 16:9"> 我还在你们那里的时候，曾把这些事告诉你们，你们不记得吗？</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦后书 2:3; 帖撒罗尼迦后书 2:8"> 现在你们也知道那拦阻他的是什么，是叫他到了的时候才可以显露。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰一书 4:3; 启示录 17:7; 提摩太后书 2:17–18"> 因为那不法的隐意已经发动；只是现在有一个拦阻的，等到那拦阻的被除去。</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦后书 2:3; 启示录 19:20–21; 以赛亚书 11:4"> 那时这不法的人必显露出来，主耶稣要用口中的气灭绝他，用降临的荣光废掉他。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 24:24; 启示录 19:20; 以弗所书 2:2"> 这不法的人来，是照撒旦的运动，行各样的异能、神迹和一切虚假的奇事，</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 1:18; 箴言 1:7; 哥林多后书 4:2–3"> 并且在那沉沦的人身上行各样出于不义的诡诈，因他们不领受爱真理的心使他们得救。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 1:28; 约翰福音 12:39–43; 提摩太前书 4:1"> 故此，神就给他们一个生发错误的心，叫他们信从虚谎，</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 1:32; 罗马书 8:7–8; 马可福音 16:16"> 使一切不信真理倒喜爱不义的人都被定罪。</span>
</div>
</div>

## 门徒当坚守保罗之教训

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="提摩太后书 1:9; 以弗所书 1:4–5; 帖撒罗尼迦前书 1:4"> 主所爱的弟兄们哪，我们本该常为你们感谢神，因为他从起初拣选了你们，叫你们因信真道，又被圣灵感动成为圣洁，能以得救。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:12; 彼得前书 5:10; 帖撒罗尼迦前书 1:5"> 神藉我们所传的福音召你们到这地步，好得着我们主耶稣基督的荣光。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 11:2; 帖撒罗尼迦后书 3:6; 帖撒罗尼迦后书 2:2"> 所以弟兄们，你们要站立得稳，凡所领受的教训，不拘是我们口传的，是信上写的，都要坚守。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="罗马书 5:2–5; 约翰福音 3:16; 彼得前书 1:3–8"> 但愿我们主耶稣基督和那爱我们、开恩将永远的安慰并美好的盼望赐给我们的父神，</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦后书 3:3; 帖撒罗尼迦前书 3:13; 帖撒罗尼迦前书 3:2"> 安慰你们的心，并且在一切善行善言上坚固你们！</span>
</div>
</div>

## 颂赞神之大能

<div className="bt">
<div className="hs">一篇诗歌，交于伶长。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="历代志上 16:23–24; 诗篇 100:1; 诗篇 98:4"> <span className="pl pl-1">全地都当向神欢呼！</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 105:2–3; 启示录 5:13; 以赛亚书 49:13"> <span className="pl pl-1">歌颂他名的荣耀，</span><br /><span className="pl pl-1">用赞美的言语将他的荣耀发明！</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 18:44; 诗篇 65:5; 诗篇 81:15"> <span className="pl pl-1">当对神说：“你的作为何等可畏！</span><br /><span className="pl pl-1">因你的大能，仇敌要投降你。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 22:27; 诗篇 117:1; 诗篇 96:1–2"> <span className="pl pl-1">全地要敬拜你，歌颂你，</span><br /><span className="pl pl-1">要歌颂你的名。”（细拉）</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="诗篇 126:1–3; 民数记 23:23; 诗篇 66:16"> <span className="pl pl-1">你们来看神所行的，</span><br /><span className="pl pl-1">他向世人所做之事是可畏的。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 3:16; 出埃及记 15:1–21; 约书亚记 3:14"> <span className="pl pl-1">他将海变成干地，众民步行过河，</span><br /><span className="pl pl-1">我们在那里因他欢喜。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 11:4; 马太福音 28:18; 诗篇 140:8"> <span className="pl pl-1">他用权能治理万民直到永远，</span><br /><span className="pl pl-1">他的眼睛鉴察列邦，</span><br /><span className="pl pl-1">悖逆的人不可自高。（细拉）</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="诗篇 98:4; 启示录 19:1; 耶利米书 33:11"> <span className="pl pl-1">万民哪，你们当称颂我们的神，</span><br /><span className="pl pl-1">使人得听赞美他的声音。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 121:3; 诗篇 112:6; 诗篇 94:18"> <span className="pl pl-1">他使我们的性命存活，</span><br /><span className="pl pl-1">也不叫我们的脚摇动。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 48:10; 诗篇 17:3; 彼得前书 1:6–7"> <span className="pl pl-1">神啊，你曾试验我们，</span><br /><span className="pl pl-1">熬炼我们如熬炼银子一样。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米哀歌 1:13; 以西结书 12:13; 耶利米哀歌 3:2–66"> <span className="pl pl-1">你使我们进入网罗，</span><br /><span className="pl pl-1">把重担放在我们的身上。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 43:1–2; 以赛亚书 51:23; 诗篇 40:2–3"> <span className="pl pl-1">你使人坐车轧我们的头，</span><br /><span className="pl pl-1">我们经过水火，</span><br /><span className="pl pl-1">你却使我们到丰富之地。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="诗篇 100:4; 诗篇 56:12; 传道书 5:4"> <span className="pl pl-1">我要用燔祭进你的殿，</span><br /><span className="pl pl-1">向你还我的愿，</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 1:11; 士师记 11:35–36; 诗篇 18:6"> <span className="pl pl-1">就是在急难时我嘴唇所发的，</span><br /><span className="pl pl-1">口中所许的。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 51:19; 撒母耳记下 6:17–19; 历代志上 16:1–3"> <span className="pl pl-1">我要把肥牛做燔祭，</span><br /><span className="pl pl-1">将公羊的香祭献给你，</span><br /><span className="pl pl-1">又把公牛和山羊献上。（细拉）</span></span>
</div>
</div>

<div className="bp poetry">

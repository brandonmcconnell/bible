## 遭难时吁主眷顾

<div className="bt">
<div className="hs">困苦人发昏的时候，在耶和华面前吐露苦情的祷告。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 18:6; 诗篇 130:1–2; 诗篇 142:2–3"> <span className="pl pl-1">耶和华啊，求你听我的祷告，</span><br /><span className="pl pl-1">容我的呼求达到你面前！</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 69:17; 诗篇 27:9; 以赛亚书 8:17"> <span className="pl pl-1">我在急难的日子，求你向我侧耳，</span><br /><span className="pl pl-1">不要向我掩面；</span><br /><span className="pl pl-1">我呼求的日子，求你快快应允我。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="雅各书 4:14; 诗篇 37:20; 约伯记 30:30"> <span className="pl pl-1">因为我的年日如烟云消灭，</span><br /><span className="pl pl-1">我的骨头如火把烧着。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 40:7; 诗篇 37:2; 诗篇 77:3"> <span className="pl pl-1">我的心被伤，如草枯干，</span><br /><span className="pl pl-1">甚至我忘记吃饭。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="约伯记 19:20; 耶利米哀歌 4:8; 诗篇 6:8"> <span className="pl pl-1">因我唉哼的声音，</span><br /><span className="pl pl-1">我的肉紧贴骨头。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="西番雅书 2:14; 以赛亚书 38:14; 以赛亚书 34:11–15"> <span className="pl pl-1">我如同旷野的鹈鹕，</span><br /><span className="pl pl-1">我好像荒场的鸮鸟。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 77:4; 诗篇 38:11; 申命记 28:66–67"> <span className="pl pl-1">我警醒不睡，</span><br /><span className="pl pl-1">我像房顶上孤单的麻雀。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 26:11; 诗篇 69:9–10; 以赛亚书 65:15"> <span className="pl pl-1">我的仇敌终日辱骂我，</span><br /><span className="pl pl-1">向我猖狂的人指着我赌咒。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 42:3; 诗篇 80:5; 弥迦书 1:10"> <span className="pl pl-1">我吃过炉灰，如同吃饭，</span><br /><span className="pl pl-1">我所喝的与眼泪掺杂，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 38:3; 诗篇 90:7–9; 诗篇 147:6"> <span className="pl pl-1">这都因你的恼恨和愤怒。</span><br /><span className="pl pl-1">你把我拾起来，又把我摔下去。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 14:2; 诗篇 109:23; 诗篇 144:4"> <span className="pl pl-1">我的年日如日影偏斜，</span><br /><span className="pl pl-1">我也如草枯干。</span></span>
</div>
</div>

## 祈主怜恤锡安

<div className="bp poetry">

<span className="v" id="v13" data-v="13" data-xref="以赛亚书 60:1; 加拉太书 4:4; 以赛亚书 40:2"> <span className="pl pl-1">你必起来怜恤锡安，</span><br /><span className="pl pl-1">因现在是可怜她的时候，</span><br /><span className="pl pl-1">日期已经到了。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 4:2; 以斯拉记 7:27; 以斯拉记 3:1–3"> <span className="pl pl-1">你的仆人原来喜悦她的石头，</span><br /><span className="pl pl-1">可怜她的尘土。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 8:43; 诗篇 138:4; 以赛亚书 60:3–22"> <span className="pl pl-1">列国要敬畏耶和华的名，</span><br /><span className="pl pl-1">世上诸王都敬畏你的荣耀。</span><br /></span>

</div>

<span className="v" id="v19" data-v="19" data-xref="申命记 26:15; 诗篇 14:2; 列王纪上 8:43"> <span className="pl pl-1">因为他从至高的圣所垂看，</span><br /><span className="pl pl-1">耶和华从天向地观察，</span><br /></span>

<span className="v" id="v21" data-v="21" data-xref="诗篇 22:22; 以赛亚书 51:11; 诗篇 79:13"> <span className="pl pl-1">使人在锡安传扬耶和华的名，</span><br /><span className="pl pl-1">在耶路撒冷传扬赞美他的话，</span><br /></span>

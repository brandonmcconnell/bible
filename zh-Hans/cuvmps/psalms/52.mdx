## 叹恶人狂妄自夸

<div className="bt">
<div className="hs">以东人多益来告诉扫罗说：“大卫到了亚希米勒家。”那时，大卫作这训诲诗，交于伶长。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 103:17; 诗篇 94:4; 诗篇 107:1"> <span className="pl pl-1">勇士啊，你为何以作恶自夸？</span><br /><span className="pl pl-1">神的慈爱是常存的。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 18:21; 诗篇 57:4; 耶利米书 9:3–4"> <span className="pl pl-1">你的舌头邪恶诡诈，</span><br /><span className="pl pl-1">好像剃头刀，快利伤人。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 9:3–5; 提摩太后书 3:4; 约翰福音 8:44"> <span className="pl pl-1">你爱恶胜似爱善，</span><br /><span className="pl pl-1">又爱说谎，不爱说公义。（细拉）</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 120:3; 雅各书 3:6–9; 撒母耳记上 22:18–19"> <span className="pl pl-1">诡诈的舌头啊，</span><br /><span className="pl pl-1">你爱说一切毁灭的话！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="箴言 2:22; 诗篇 27:13; 启示录 21:8"> <span className="pl pl-1">神也要毁灭你，直到永远。</span><br /><span className="pl pl-1">他要把你拿去，从你的帐篷中抽出，</span><br /><span className="pl pl-1">从活人之地将你拔出。（细拉）</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="约伯记 22:19; 诗篇 40:3; 诗篇 37:34"> <span className="pl pl-1">义人要看见而惧怕，</span><br /><span className="pl pl-1">并要笑他，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 17:5; 诗篇 73:18–20; 传道书 8:8"> <span className="pl pl-1">说：“看哪！这就是那不以神为他力量的人，</span><br /><span className="pl pl-1">只倚仗他丰富的财物，在邪恶上坚立自己。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="诗篇 92:12–14; 诗篇 1:3; 何西阿书 14:6–8"> <span className="pl pl-1">至于我，就像神殿中的青橄榄树，</span><br /><span className="pl pl-1">我永永远远倚靠神的慈爱。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 130:5–6; 耶利米哀歌 3:25–26; 诗篇 54:6"> <span className="pl pl-1">我要称谢你，直到永远，</span><br /><span className="pl pl-1">因为你行了这事。</span><br /><span className="pl pl-1">我也要在你圣民面前仰望你的名，</span><br /><span className="pl pl-1">这名本为美好。</span></span>
</div>

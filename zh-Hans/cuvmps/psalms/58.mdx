## 求神降罚恶人

<div className="bt">
<div className="hs">大卫的金诗，交于伶长。调用休要毁坏。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 57:1; 申命记 16:18–19; 诗篇 72:1–4"> <span className="pl pl-1">世人哪，你们默然不语，真合公义吗？</span><br /><span className="pl pl-1">施行审判，岂按正直吗？</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 94:20; 以赛亚书 10:1; 以西结书 22:27"> <span className="pl pl-1">不然！你们是心中作恶，</span><br /><span className="pl pl-1">你们在地上称出你们手所行的强暴。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="诗篇 51:5; 以赛亚书 48:8; 箴言 22:15"> <span className="pl pl-1">恶人一出母胎，就与神疏远；</span><br /><span className="pl pl-1">一离母腹，便走错路，说谎话。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 140:3; 雅各书 3:8; 传道书 10:11"> <span className="pl pl-1">他们的毒气好像蛇的毒气，</span><br /><span className="pl pl-1">他们好像塞耳的聋虺，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 8:17; 以赛亚书 19:3; 申命记 18:11"> <span className="pl pl-1">不听行法术的声音，</span><br /><span className="pl pl-1">虽用极灵的咒语，也是不听。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="诗篇 3:7; 约伯记 4:10–11; 何西阿书 5:14"> <span className="pl pl-1">神啊，求你敲碎他们口中的牙！</span><br /><span className="pl pl-1">耶和华啊，求你敲掉少壮狮子的大牙！</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 112:10; 约书亚记 7:5; 诗篇 64:3"> <span className="pl pl-1">愿他们消灭如急流的水一般，</span><br /><span className="pl pl-1">他们瞅准射箭的时候，愿箭头仿佛砍断。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="约伯记 3:16; 传道书 6:3; 诗篇 37:35–36"> <span className="pl pl-1">愿他们像蜗牛消化过去，</span><br /><span className="pl pl-1">又像妇人坠落未见天日的胎。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 118:12; 箴言 10:25; 传道书 7:6"> <span className="pl pl-1">你们用荆棘烧火，锅还未热，</span><br /><span className="pl pl-1">他要用旋风把青的和烧着的一齐刮去。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="诗篇 68:23; 诗篇 91:8; 诗篇 64:10"> <span className="pl pl-1">义人见仇敌遭报就欢喜，</span><br /><span className="pl pl-1">要在恶人的血中洗脚。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 67:4; 以赛亚书 3:10; 诗篇 64:9"> <span className="pl pl-1">因此，人必说：“义人诚然有善报，</span><br /><span className="pl pl-1">在地上果有施行判断的神。”</span></span>
</div>

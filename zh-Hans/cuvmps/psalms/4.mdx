## 求耶和华矜恤允其所祈

<div className="bt">
<div className="hs">大卫的诗，交于伶长。用丝弦的乐器。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 1:10; 出埃及记 34:6–7; 诗篇 40:1–3"> <span className="pl pl-1">显我为义的神啊，</span><br /><span className="pl pl-1">我呼吁的时候，求你应允我。</span><br /><span className="pl pl-1">我在困苦中，你曾使我宽广；</span><br /><span className="pl pl-1">现在求你怜恤我，听我的祷告。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="箴言 1:22; 何西阿书 4:7; 诗篇 3:3"> <span className="pl pl-1">你们这上流人哪，你们将我的尊荣变为羞辱，要到几时呢？</span><br /><span className="pl pl-1">你们喜爱虚妄，寻找虚假，要到几时呢？（细拉）</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 15:16; 诗篇 34:15; 帖撒罗尼迦后书 2:13–14"> <span className="pl pl-1">你们要知道，耶和华已经分别虔诚人归他自己，</span><br /><span className="pl pl-1">我求告耶和华，他必听我。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="以弗所书 4:26; 诗篇 77:6; 诗篇 46:10"> <span className="pl pl-1">你们应当畏惧，不可犯罪；</span><br /><span className="pl pl-1">在床上的时候要心里思想，并要肃静。（细拉）</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 13:15–16; 诗篇 37:3; 诗篇 51:19"> <span className="pl pl-1">当献上公义的祭，</span><br /><span className="pl pl-1">又当倚靠耶和华。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 80:19; 民数记 6:26; 诗篇 119:135"> <span className="pl pl-1">有许多人说：“谁能指示我们什么好处？”</span><br /><span className="pl pl-1">耶和华啊，求你仰起脸来，光照我们！</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 9:3; 诗篇 63:2–5; 诗篇 37:4"> <span className="pl pl-1">你使我心里快乐，</span><br /><span className="pl pl-1">胜过那丰收五谷、新酒的人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="箴言 3:24; 诗篇 3:5; 约伯记 11:18–19"> <span className="pl pl-1">我必安然躺下睡觉，</span><br /><span className="pl pl-1">因为独有你耶和华使我安然居住。</span></span>
</div>

## 颂美耶和华之恩惠慈爱

<div className="bt">
<div className="hs">大卫的诗。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 146:1–2; 诗篇 57:7–11; 约翰福音 4:24"> <span className="pl pl-1">我的心哪，你要称颂耶和华；</span><br /><span className="pl pl-1">凡在我里面的，也要称颂他的圣名！</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 63:7; 诗篇 116:12; 诗篇 105:5"> <span className="pl pl-1">我的心哪，你要称颂耶和华，</span><br /><span className="pl pl-1">不可忘记他的一切恩惠。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 15:26; 以赛亚书 53:5; 耶利米书 17:14"> <span className="pl pl-1">他赦免你的一切罪孽，</span><br /><span className="pl pl-1">医治你的一切疾病。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 56:13; 诗篇 71:23; 诗篇 103:12"> <span className="pl pl-1">他救赎你的命脱离死亡，</span><br /><span className="pl pl-1">以仁爱和慈悲为你的冠冕。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 40:31; 诗篇 107:9; 提摩太前书 6:17"> <span className="pl pl-1">他用美物使你所愿的得以知足，</span><br /><span className="pl pl-1">以致你如鹰返老还童。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="诗篇 9:9; 诗篇 12:5; 诗篇 72:12"> <span className="pl pl-1">耶和华施行公义，</span><br /><span className="pl pl-1">为一切受屈的人申冤。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 33:13; 诗篇 147:19; 诗篇 78:11"> <span className="pl pl-1">他使摩西知道他的法则，</span><br /><span className="pl pl-1">叫以色列人晓得他的作为。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 86:15; 约珥书 2:13; 出埃及记 34:6–7"> <span className="pl pl-1">耶和华有怜悯，有恩典，</span><br /><span className="pl pl-1">不轻易发怒，且有丰盛的慈爱。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 57:16; 诗篇 30:5; 弥迦书 7:18–19"> <span className="pl pl-1">他不长久责备，</span><br /><span className="pl pl-1">也不永远怀怒。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以斯拉记 9:13; 耶利米哀歌 3:22; 尼希米记 9:31"> <span className="pl pl-1">他没有按我们的罪过待我们，</span><br /><span className="pl pl-1">也没有照我们的罪孽报应我们。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 57:10; 路加福音 1:50; 诗篇 36:5"> <span className="pl pl-1">天离地何等的高，</span><br /><span className="pl pl-1">他的慈爱向敬畏他的人也是何等的大。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 43:25; 约翰一书 1:7; 弥迦书 7:18"> <span className="pl pl-1">东离西有多远，</span><br /><span className="pl pl-1">他叫我们的过犯离我们也有多远。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 11:11–12; 希伯来书 12:5–11; 路加福音 15:21–22"> <span className="pl pl-1">父亲怎样怜恤他的儿女，</span><br /><span className="pl pl-1">耶和华也怎样怜恤敬畏他的人。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="传道书 12:7; 约伯记 10:9; 诗篇 78:38–39"> <span className="pl pl-1">因为他知道我们的本体，</span><br /><span className="pl pl-1">思念我们不过是尘土。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="彼得前书 1:24; 雅各书 1:10–11; 以赛亚书 51:12"> <span className="pl pl-1">至于世人，他的年日如草一样，</span><br /><span className="pl pl-1">他发旺如野地的花。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 40:7; 约伯记 20:9; 约伯记 14:10"> <span className="pl pl-1">经风一吹，便归无有，</span><br /><span className="pl pl-1">他的原处也不再认识他。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 100:5; 出埃及记 20:6; 以弗所书 2:4–7"> <span className="pl pl-1">但耶和华的慈爱归于敬畏他的人，</span><br /><span className="pl pl-1">从亘古到永远；</span><br /><span className="pl pl-1">他的公义也归于子子孙孙，</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="申命记 7:9; 诗篇 132:12; 路加福音 1:6"> <span className="pl pl-1">就是那些遵守他的约，</span><br /><span className="pl pl-1">记念他的训词而遵行的人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="诗篇 47:2; 腓立比书 2:9–10; 诗篇 9:7"> <span className="pl pl-1">耶和华在天上立定宝座，</span><br /><span className="pl pl-1">他的权柄</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：国。">a</a></sup><br /><span className="pl pl-1">统管万有。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="希伯来书 1:14; 诗篇 148:2; 路加福音 1:19"> <span className="pl pl-1">听从他命令、成全他旨意、</span><br /><span className="pl pl-1">有大能的天使，都要称颂耶和华！</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 22:19; 尼希米记 9:6; 路加福音 2:13"> <span className="pl pl-1">你们做他的诸军、做他的仆役、</span><br /><span className="pl pl-1">行他所喜悦的，都要称颂耶和华！</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 49:13; 诗篇 145:10; 以赛亚书 42:10–12"> <span className="pl pl-1">你们一切被他造的，</span><br /><span className="pl pl-1">在他所治理的各处</span><br /><span className="pl pl-1">都要称颂耶和华！</span><br /><span className="pl pl-1">我的心哪，你要称颂耶和华！</span></span>

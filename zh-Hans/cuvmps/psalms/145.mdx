## 称颂耶和华之威荣慈惠

<div className="bt">
<div className="hs">大卫的赞美诗。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 47:6–8; 诗篇 45:6; 诗篇 34:1"> <span className="pl pl-1">我的神我的王啊，我要尊崇你，</span><br /><span className="pl pl-1">我要永永远远称颂你的名！</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="启示录 7:15; 诗篇 71:6; 诗篇 119:164"> <span className="pl pl-1">我要天天称颂你，</span><br /><span className="pl pl-1">也要永永远远赞美你的名！</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="诗篇 78:3–7; 诗篇 71:18; 申命记 6:7"> <span className="pl pl-1">这代要对那代颂赞你的作为，</span><br /><span className="pl pl-1">也要传扬你的大能。</span><br /></span>

<span className="v" id="v6" data-v="6" data-xref="哈巴谷书 2:14; 但以理书 3:28–29; 诗篇 107:31–32"> <span className="pl pl-1">人要传说你可畏之事的能力，</span><br /><span className="pl pl-1">我也要传扬你的大德。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 63:7; 诗篇 36:10; 哥林多后书 9:11–12"> <span className="pl pl-1">他们记念你的大恩就要传出来，</span><br /><span className="pl pl-1">并要歌唱你的公义。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="民数记 14:18; 诗篇 103:8; 诗篇 86:5"> <span className="pl pl-1">耶和华有恩惠，有怜悯，</span><br /><span className="pl pl-1">不轻易发怒，大有慈爱。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="那鸿书 1:7; 诗篇 100:5; 马太福音 5:45"> <span className="pl pl-1">耶和华善待万民，</span><br /><span className="pl pl-1">他的慈悲覆庇他一切所造的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="诗篇 19:1; 诗篇 103:22; 启示录 7:9–12"> <span className="pl pl-1">耶和华啊，你一切所造的都要称谢你，</span><br /><span className="pl pl-1">你的圣民也要称颂你。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 9:6–7; 历代志上 29:11–12; 诗篇 93:1–2"> <span className="pl pl-1">传说你国的荣耀，</span><br /><span className="pl pl-1">谈论你的大能，</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="启示录 12:10; 诗篇 105:1; 马太福音 28:18"> <span className="pl pl-1">好叫世人知道你大能的作为，</span><br /><span className="pl pl-1">并你国度威严的荣耀。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="提摩太前书 1:17; 但以理书 7:14; 诗篇 10:16"> <span className="pl pl-1">你的国是永远的国，</span><br /><span className="pl pl-1">你执掌的权柄存到万代。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="诗篇 146:8; 诗篇 37:24; 诗篇 94:18"> <span className="pl pl-1">凡跌倒的，耶和华将他们扶持；</span><br /><span className="pl pl-1">凡被压下的，将他们扶起。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 136:25; 诗篇 104:27; 使徒行传 17:25"> <span className="pl pl-1">万民都举目仰望你，</span><br /><span className="pl pl-1">你随时给他们食物。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 104:28; 诗篇 107:9; 诗篇 132:15"> <span className="pl pl-1">你张手，</span><br /><span className="pl pl-1">使有生气的都随愿饱足。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="申命记 32:4; 西番雅书 3:5; 以赛亚书 45:21"> <span className="pl pl-1">耶和华在他一切所行的无不公义，</span><br /><span className="pl pl-1">在他一切所做的都有慈爱。</span><br /></span>

<span className="v" id="v20" data-v="20" data-xref="出埃及记 20:6; 约翰福音 10:27–29; 罗马书 8:28–30"> <span className="pl pl-1">耶和华保护一切爱他的人，</span><br /><span className="pl pl-1">却要灭绝一切的恶人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="诗篇 71:8; 诗篇 51:15; 诗篇 150:6"> <span className="pl pl-1">我的口要说出赞美耶和华的话，</span><br /><span className="pl pl-1">唯愿凡有血气的都永永远远称颂他的圣名！</span></span>

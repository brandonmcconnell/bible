## 作恶者之危殆

<div className="bt">
<div className="hs">大卫的诗。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 37:7; 箴言 23:17; 箴言 24:19"> <span className="pl pl-1">不要为作恶的心怀不平，</span><br /><span className="pl pl-1">也不要向那行不义的生出嫉妒。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 92:7; 诗篇 90:5–6; 雅各书 1:10–11"> <span className="pl pl-1">因为他们如草快被割下，</span><br /><span className="pl pl-1">又如青菜快要枯干。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="耶利米书 17:7–8; 马太福音 6:31–33; 诗篇 62:8"> <span className="pl pl-1">你当倚靠耶和华而行善，</span><br /><span className="pl pl-1">住在地上，以他的信实为粮。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 15:7; 诗篇 145:19; 约翰福音 15:16"> <span className="pl pl-1">又要以耶和华为乐，</span><br /><span className="pl pl-1">他就将你心里所求的赐给你。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="箴言 16:3; 彼得前书 5:7; 腓立比书 4:6–7"> <span className="pl pl-1">当将你的事交托耶和华，</span><br /><span className="pl pl-1">并倚靠他，他就必成全。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 54:17; 约伯记 11:17; 以赛亚书 58:8"> <span className="pl pl-1">他要使你的公义如光发出，</span><br /><span className="pl pl-1">使你的公平明如正午。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="雅各书 5:7–11; 诗篇 27:14; 诗篇 62:5"> <span className="pl pl-1">你当默然倚靠耶和华，耐性等候他，</span><br /><span className="pl pl-1">不要因那道路通达的和那恶谋成就的心怀不平。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="箴言 14:29; 箴言 16:32; 雅各书 1:19–20"> <span className="pl pl-1">当止住怒气，离弃愤怒，</span><br /><span className="pl pl-1">不要心怀不平，以致作恶。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 60:21; 诗篇 25:13; 诗篇 37:29"> <span className="pl pl-1">因为作恶的必被剪除，</span><br /><span className="pl pl-1">唯有等候耶和华的必承受地土。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="约伯记 24:24; 诗篇 103:16; 诗篇 37:35–36"> <span className="pl pl-1">还有片时，恶人要归于无有，</span><br /><span className="pl pl-1">你就是细察他的住处，也要归于无有。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 5:5; 加拉太书 5:22–23; 以赛亚书 26:3"> <span className="pl pl-1">但谦卑人必承受地土，</span><br /><span className="pl pl-1">以丰盛的平安为乐。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="弥迦书 2:1; 诗篇 35:16; 诗篇 31:13"> <span className="pl pl-1">恶人设谋害义人，</span><br /><span className="pl pl-1">又向他咬牙。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 2:4; 箴言 1:26; 撒母耳记上 26:10"> <span className="pl pl-1">主要笑他，</span><br /><span className="pl pl-1">因见他受罚的日子将要来到。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="箴言 29:27; 诗篇 11:2; 约翰一书 3:12"> <span className="pl pl-1">恶人已经弓上弦，刀出鞘，</span><br /><span className="pl pl-1">要打倒困苦穷乏的人，</span><br /><span className="pl pl-1">要杀害行动正直的人。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 7:14–15; 诗篇 35:8; 耶利米书 51:56"> <span className="pl pl-1">他们的刀必刺入自己的心，</span><br /><span className="pl pl-1">他们的弓必被折断。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="箴言 16:8; 箴言 15:16–17; 提摩太前书 6:6"> <span className="pl pl-1">一个义人所有的虽少，</span><br /><span className="pl pl-1">强过许多恶人的富余。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 41:10; 诗篇 63:8; 诗篇 145:14"> <span className="pl pl-1">因为恶人的膀臂必被折断，</span><br /><span className="pl pl-1">但耶和华是扶持义人。</span></span>
</div>
</div>

## 恃主者之安稳

<div className="bt">
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="诗篇 1:6; 罗马书 6:23; 诗篇 103:17"> <span className="pl pl-1">耶和华知道完全人的日子，</span><br /><span className="pl pl-1">他们的产业要存到永远。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 33:19; 箴言 10:3; 约伯记 5:20–22"> <span className="pl pl-1">他们在急难的时候不致羞愧，</span><br /><span className="pl pl-1">在饥荒的日子必得饱足。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="诗篇 68:2; 诗篇 102:3; 路加福音 13:3"> <span className="pl pl-1">恶人却要灭亡，</span><br /><span className="pl pl-1">耶和华的仇敌要像羊羔的脂油</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：像草地的华美。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">他们要消灭，要如烟消灭。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="希伯来书 13:16; 诗篇 112:5; 箴言 22:7"> <span className="pl pl-1">恶人借贷而不偿还，</span><br /><span className="pl pl-1">义人却恩待人，并且施舍。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 3:33; 哥林多前书 16:22; 加拉太书 3:13"> <span className="pl pl-1">蒙耶和华赐福的必承受地土，</span><br /><span className="pl pl-1">被他咒诅的必被剪除。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="箴言 16:9; 诗篇 119:133; 箴言 4:26"> <span className="pl pl-1">义人的脚步被耶和华立定，</span><br /><span className="pl pl-1">他的道路耶和华也喜爱。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 24:16; 诗篇 145:14; 诗篇 94:18"> <span className="pl pl-1">他虽失脚，也不至全身仆倒，</span><br /><span className="pl pl-1">因为耶和华用手搀扶他</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：搀扶他的手。">b</a></sup><br /><span className="pl pl-1">。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="希伯来书 13:5; 诗篇 37:28; 诗篇 112:2"> <span className="pl pl-1">我从前年幼，现在年老，</span><br /><span className="pl pl-1">却未见过义人被弃，</span><br /><span className="pl pl-1">也未见过他的后裔讨饭。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 112:5; 马太福音 5:7; 诗篇 37:21"> <span className="pl pl-1">他终日恩待人，借给人，</span><br /><span className="pl pl-1">他的后裔也蒙福。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="诗篇 34:14; 箴言 16:6; 约翰一书 2:16–17"> <span className="pl pl-1">你当离恶行善，</span><br /><span className="pl pl-1">就可永远安居。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 11:7; 箴言 2:22; 诗篇 21:10"> <span className="pl pl-1">因为耶和华喜爱公平，</span><br /><span className="pl pl-1">不撇弃他的圣民，</span><br /><span className="pl pl-1">他们永蒙保佑，</span><br /><span className="pl pl-1">但恶人的后裔必被剪除。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 2:21; 诗篇 37:9; 彼得后书 3:13"> <span className="pl pl-1">义人必承受地土，</span><br /><span className="pl pl-1">永居其上。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="歌罗西书 4:6; 箴言 25:11–13; 以弗所书 4:29"> <span className="pl pl-1">义人的口谈论智慧，</span><br /><span className="pl pl-1">他的舌头讲说公平。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 40:8; 申命记 6:6; 以赛亚书 51:7"> <span className="pl pl-1">神的律法在他心里，</span><br /><span className="pl pl-1">他的脚总不滑跌。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="路加福音 19:47–48; 诗篇 10:8–10; 诗篇 37:12"> <span className="pl pl-1">恶人窥探义人，</span><br /><span className="pl pl-1">想要杀他。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 109:31; 彼得后书 2:9; 罗马书 8:1"> <span className="pl pl-1">耶和华必不撇他在恶人手中，</span><br /><span className="pl pl-1">当审判的时候，也不定他的罪。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="诗篇 27:14; 诗篇 37:9; 箴言 20:22"> <span className="pl pl-1">你当等候耶和华，遵守他的道，</span><br /><span className="pl pl-1">他就抬举你，使你承受地土，</span><br /><span className="pl pl-1">恶人被剪除的时候，你必看见。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="约伯记 5:3; 以西结书 31:18; 以赛亚书 14:14–19"> <span className="pl pl-1">我见过恶人大有势力，</span><br /><span className="pl pl-1">好像一根青翠树在本土生发。</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="诗篇 37:10; 使徒行传 12:22–23; 以赛亚书 10:16–19"> <span className="pl pl-1">有人从那里经过，不料，他没有了；</span><br /><span className="pl pl-1">我也寻找他，却寻不着。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v37" data-v="37" data-xref="以赛亚书 32:17; 以赛亚书 57:1–2; 提摩太后书 4:6–8"> <span className="pl pl-1">你要细察那完全人，观看那正直人，</span><br /><span className="pl pl-1">因为和平人有好结局。</span><br /></span>
<span className="v" id="v38" data-v="38" data-xref="箴言 14:32; 诗篇 52:5; 诗篇 1:4–6"> <span className="pl pl-1">至于犯法的人，必一同灭绝，</span><br /><span className="pl pl-1">恶人终必剪除。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v39" data-v="39" data-xref="诗篇 9:9; 诗篇 91:15; 以赛亚书 12:2"> <span className="pl pl-1">但义人得救，是由于耶和华，</span><br /><span className="pl pl-1">他在患难时做他们的营寨。</span><br /></span>
<span className="v" id="v40" data-v="40" data-xref="以赛亚书 31:5; 历代志上 5:20; 但以理书 6:23"> <span className="pl pl-1">耶和华帮助他们，解救他们。</span><br /><span className="pl pl-1">他解救他们脱离恶人，把他们救出来，</span><br /><span className="pl pl-1">因为他们投靠他。</span></span>
</div>

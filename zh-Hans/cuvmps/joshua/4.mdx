## 命取约旦河石立之为记

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 27:2; 约书亚记 3:17"> 国民尽都过了约旦河，耶和华就对约书亚说：</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 3:12; 民数记 1:4–15; 列王纪上 18:31"> “你从民中要拣选十二个人，每支派一人，</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 4:19–20; 约书亚记 3:13; 约书亚记 4:8"> 吩咐他们说：‘你们从这里，从约旦河中，祭司脚站定的地方，取十二块石头带过去，放在你们今夜要住宿的地方。’”</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 4:2; 马可福音 3:14–19"> 于是，约书亚将他从以色列人中所预备的那十二个人，每支派一人，都召了来，</span>
<span className="v" id="v5" data-v="5"> 对他们说：“你们下约旦河中，过到耶和华你们神的约柜前头，按着以色列人十二支派的数目，每人取一块石头扛在肩上。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 13:14; 约书亚记 4:21; 诗篇 44:1"> 这些石头在你们中间可以作为证据。日后，你们的子孙问你们说：‘这些石头是什么意思？’</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 12:14; 民数记 16:40; 出埃及记 28:12"> 你们就对他们说：‘这是因为约旦河的水在耶和华的约柜前断绝。约柜过约旦河的时候，约旦河的水就断绝了。这些石头要做以色列人永远的纪念。’”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约书亚记 4:2–5; 约书亚记 1:16–18; 约书亚记 4:20"> 以色列人就照约书亚所吩咐的，按着以色列人支派的数目，从约旦河中取了十二块石头，都遵耶和华所吩咐约书亚的行了。他们把石头带过去，到他们所住宿的地方，就放在那里。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 7:12; 士师记 1:26; 历代志下 5:9"> 约书亚另把十二块石头立在约旦河中，在抬约柜的祭司脚站立的地方，直到今日那石头还在那里。</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 3:13; 诗篇 119:60; 箴言 27:1"> 抬约柜的祭司站在约旦河中，等到耶和华晓谕约书亚吩咐百姓的事办完了，是照摩西所吩咐约书亚的一切话。于是百姓急速过去了。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 3:8; 约书亚记 4:18; 约书亚记 3:17"> 众百姓尽都过了河，耶和华的约柜和祭司就在百姓面前过去。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 32:20–32; 约书亚记 1:14"> 鲁本人、迦得人、玛拿西半支派的人都照摩西所吩咐他们的，带着兵器在以色列人前头过去。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 6:11; 耶利米书 39:5; 耶利米书 52:8"> 约有四万人都准备打仗，在耶和华面前过去，到耶利哥的平原，等候上阵。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 3:7; 历代志下 30:12; 列王纪上 3:28"> 当那日，耶和华使约书亚在以色列众人眼前尊大。在他平生的日子，百姓敬畏他，像从前敬畏摩西一样。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 耶和华晓谕约书亚说：</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 11:19; 出埃及记 25:16–22; 约书亚记 3:3–6"> “你吩咐抬法柜的祭司从约旦河里上来。”</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 8:16–18; 使徒行传 16:35–39; 使徒行传 16:23"> 约书亚就吩咐祭司说：“你们从约旦河里上来。”</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 3:15; 历代志上 12:15; 约书亚记 3:13"> 抬耶和华约柜的祭司从约旦河里上来，脚掌刚落旱地，约旦河的水就流到原处，仍旧涨过两岸。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约书亚记 5:9; 弥迦书 6:5; 出埃及记 12:2–3"> 正月初十日，百姓从约旦河里上来，就在吉甲，在耶利哥的东边安营。</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 4:3; 约书亚记 4:8"> 他们从约旦河中取来的那十二块石头，约书亚就立在吉甲，</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 4:6; 诗篇 145:4–7; 诗篇 105:2–5"> 对以色列人说：“日后你们的子孙问他们的父亲说：‘这些石头是什么意思？’</span>
<span className="v" id="v22" data-v="22" data-xref="约书亚记 3:17; 以赛亚书 51:10; 以赛亚书 44:27"> 你们就告诉他们说：‘以色列人曾走干地过这约旦河。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 14:21; 以赛亚书 43:16; 以赛亚书 63:12–14"> 因为耶和华你们的神在你们前面使约旦河的水干了，等着你们过来，就如耶和华你们的神从前在我们前面使红海干了，等着我们过来一样。</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 106:8; 诗篇 89:13; 列王纪上 8:42–43"> 要使地上万民都知道耶和华的手大有能力，也要使你们永远敬畏耶和华你们的神。’”</span>
</div>
</div>

## 命分未取之地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 14:10; 申命记 31:3; 约书亚记 24:29"> 约书亚年纪老迈，耶和华对他说：“你年纪老迈了，还有许多未得之地，</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 13:11; 撒母耳记上 27:8; 约珥书 3:4"> 就是非利士人的全境和基述人的全地：</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 2:23; 士师记 3:3; 耶利米书 2:18"> 从埃及前的西曷河往北，直到以革伦的境界，就算属迦南人之地，有非利士人五个首领所管的加沙人、亚实突人、亚实基伦人、迦特人、以革伦人之地，并有南方亚卫人之地。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 19:30; 撒母耳记上 4:1; 士师记 1:34–36"> 又有迦南人的全地，并属西顿人的米亚拉到亚弗，直到亚摩利人的境界。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 5:18; 约书亚记 12:7; 诗篇 83:7"> 还有迦巴勒人之地，并向日出的全黎巴嫩，就是从黑门山根的巴力迦得，直到哈马口。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 11:8; 约书亚记 23:13; 士师记 2:21–23"> 山地的一切居民，从黎巴嫩直到米斯利弗玛音，就是所有的西顿人，我必在以色列人面前赶出他们去。你只管照我所吩咐的，将这地拈阄分给以色列人为业。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 26:53–56; 民数记 33:54; 以西结书 48:23–29"> 现在你要把这地分给九个支派和玛拿西半个支派为业。”</span>
</div>
</div>

## 二支派半所得之地

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约书亚记 12:6; 申命记 3:12–17; 约书亚记 22:4"> 玛拿西那半支派和鲁本、迦得二支派已经受了产业，就是耶和华的仆人摩西在约旦河东所赐给他们的，</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 13:16; 民数记 21:30; 约书亚记 12:2"> 是从亚嫩谷边的亚罗珥和谷中的城，并米底巴的全平原，直到底本；</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 21:24–26"> 和在希实本做王亚摩利王西宏的诸城，直到亚扪人的境界；</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 2:23; 约书亚记 12:2–5; 申命记 4:47–48"> 又有基列地，基述人、玛迦人的地界，并黑门全山，巴珊全地，直到撒迦；</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 12:4; 约书亚记 14:3–4; 民数记 21:23–35"> 又有巴珊王噩的全国，他在亚斯他录和以得来做王（利乏音人所存留的只剩下他）。这些地的人都是摩西所击杀、所赶逐的。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 23:12–13; 约书亚记 13:11; 民数记 33:55"> 以色列人却没有赶逐基述人、玛迦人，这些人仍住在以色列中，直到今日。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 18:20–24; 约书亚记 14:3–4; 申命记 18:1–2"> 只是利未支派，摩西<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：他。">a</a></sup>没有把产业分给他们，他们的产业乃是献于耶和华以色列神的火祭，正如耶和华所应许他们的。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 摩西按着鲁本支派的宗族分给他们产业。</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 13:9; 约书亚记 12:2; 以赛亚书 16:7–9"> 他们的境界是亚嫩谷边的亚罗珥和谷中的城，靠近米底巴的全平原；</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 22:41; 民数记 32:38; 民数记 21:19"> 希实本并属希实本平原的各城，底本，巴末巴力，伯巴力勉，</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 21:23; 约书亚记 21:36–37; 历代志上 6:78–79"> 雅杂，基底莫，米法押，</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 32:37–38"> 基列亭，西比玛，谷中山的细列哈沙辖，</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 12:3; 申命记 4:46; 以西结书 25:9"> 伯毗珥，毗斯迦山坡，伯耶西末；</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 31:8; 申命记 3:10; 申命记 2:30–36"> 平原的各城，并亚摩利王西宏的全国。这西宏曾在希实本做王，摩西把他和米甸的族长以未、利金、苏珥、户珥、利巴击杀了。这都是住那地属西宏为首领的。</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 31:8; 犹大书 1:11; 彼得后书 2:15"> 那时以色列人在所杀的人中，也用刀杀了比珥的儿子术士巴兰。</span>
<span className="v" id="v23" data-v="23"> 鲁本人的境界就是约旦河与靠近约旦河的地。以上是鲁本人按着宗族所得为业的诸城，并属城的村庄。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数记 32:34–36"> 摩西按着迦得支派的宗族分给他们产业。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 12:26; 撒母耳记下 11:1; 民数记 32:35"> 他们的境界是雅谢和基列的各城，并亚扪人的一半地，直到拉巴前的亚罗珥；</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 17:27; 撒母耳记下 2:8; 士师记 10:17"> 从希实本到拉抹米斯巴和比多宁，又从玛哈念到底璧的境界，</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 32:36; 民数记 34:11; 创世记 33:17"> 并谷中的伯亚兰、伯宁拉、疏割、撒分，就是希实本王西宏国中的余地；以及约旦河与靠近约旦河的地，直到基尼烈海的极边，都在约旦河东。</span>
<span className="v" id="v28" data-v="28"> 以上是迦得人按着宗族所得为业的诸城，并属城的村庄。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 摩西把产业分给玛拿西半支派，是按着玛拿西半支派的宗族所分的。</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 13:26; 申命记 3:13–15; 民数记 32:39–41"> 他们的境界是从玛哈念起，包括巴珊全地，就是巴珊王噩的全国，并在巴珊、睚珥的一切城邑，共六十个；</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 12:4; 民数记 32:39–40"> 基列的一半，并亚斯他录、以得来，就是属巴珊王噩国的二城；是按着宗族给玛拿西的儿子玛吉的一半子孙。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 以上是摩西在约旦河东对着耶利哥的摩押平原所分给他们的产业。</span>
<span className="v" id="v33" data-v="33" data-xref="约书亚记 18:7; 约书亚记 13:14; 申命记 18:1–2"> 只是利未支派，摩西没有把产业分给他们，耶和华以色列的神是他们的产业，正如耶和华所应许他们的。</span>
</div>
</div>

## 诸王会盟谋攻以色列人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 34:6; 出埃及记 3:17; 出埃及记 23:23"> 约旦河西住山地、高原，并对着黎巴嫩山沿大海一带的诸王，就是赫人、亚摩利人、迦南人、比利洗人、希未人、耶布斯人的诸王，听见这事，</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 16:14; 约珥书 3:9–13; 诗篇 2:1–2"> 就都聚集，同心合意地要与约书亚和以色列人争战。</span>
</div>
</div>

## 基遍人设诡计

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="约书亚记 10:2; 约书亚记 9:17; 撒母耳记下 21:1–2"> 基遍的居民听见约书亚向耶利哥和艾城所行的事，</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 16:8; 马太福音 10:16; 马可福音 2:22"> 就设诡计，假充使者，拿旧口袋和破裂缝补的旧皮酒袋驮在驴上，</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 15:22; 申命记 33:25; 申命记 29:5"> 将补过的旧鞋穿在脚上，把旧衣服穿在身上。他们所带的饼都是干的，长了霉了。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 5:10; 列王纪下 20:14; 约书亚记 9:9"> 他们到吉甲营中见约书亚，对他和以色列人说：“我们是从远方来的，现在求你与我们立约。”</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 11:19; 士师记 2:2; 出埃及记 34:12"> 以色列人对这些希未人说：“只怕你们是住在我们中间的，若是这样，怎能和你们立约呢？”</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 20:11; 列王纪下 10:5; 约书亚记 9:11"> 他们对约书亚说：“我们是你的仆人。”约书亚问他们说：“你们是什么人？是从哪里来的？”</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 20:15; 约书亚记 9:24; 以赛亚书 55:5"> 他们回答说：“仆人从极远之地而来，是因听见耶和华你神的名声和他在埃及所行的一切事，</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 21:24–35; 申命记 1:4; 约书亚记 12:4"> 并他向约旦河东的两个亚摩利王，就是希实本王西宏和在亚斯他录的巴珊王噩一切所行的事。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 9:8; 以斯帖记 8:17; 约书亚记 1:11"> 我们的长老和我们那地的一切居民对我们说：“你们手里要带着路上用的食物去迎接以色列人，对他们说：‘我们是你们的仆人，现在求你们与我们立约。’</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 9:4–5"> 我们出来要往你们这里来的日子，从家里带出来的这饼还是热的，看哪，现在都干了，长了霉了。</span>
<span className="v" id="v13" data-v="13"> 这皮酒袋，我们盛酒的时候还是新的，看哪，现在已经破裂。我们这衣服和鞋，因为道路甚远，也都穿旧了。”</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 3:5–6; 民数记 27:21; 历代志上 10:13–14"> 以色列人受了他们些食物，并没有求问耶和华。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 21:2; 申命记 20:10–11; 约书亚记 11:19"> 于是约书亚与他们讲和，与他们立约，容他们活着。会众的首领也向他们起誓。</span>
</div>
</div>

## 奴役基遍人

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="箴言 12:19"> 以色列人与他们立约之后，过了三天才听见他们是近邻，住在以色列人中间的。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯拉记 2:25; 约书亚记 18:25–28; 约书亚记 18:14"> 以色列人起行，第三天到了他们的城邑，就是基遍、基非拉、比录、基列耶琳。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 15:4; 撒母耳记下 21:7; 传道书 5:6"> 因为会众的首领已经指着耶和华以色列的神向他们起誓，所以以色列人不击杀他们。全会众就向首领发怨言。</span>
<span className="v" id="v19" data-v="19" data-xref="传道书 8:2; 约书亚记 9:20; 传道书 9:2"> 众首领对全会众说：“我们已经指着耶和华以色列的神向他们起誓，现在我们不能害他们。</span>
<span className="v" id="v20" data-v="20" data-xref="玛拉基书 3:5; 箴言 20:25; 提摩太前书 1:10"> 我们要如此待他们，容他们活着，免得有愤怒因我们所起的誓临到我们身上。”</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 29:11; 约书亚记 9:27; 约书亚记 9:23"> 首领又对会众说：“要容他们活着。”于是他们为全会众做了劈柴挑水的人，正如首领对他们所说的话。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约书亚记 9:6; 约书亚记 9:16; 创世记 3:13–14"> 约书亚召了他们来，对他们说：“为什么欺哄我们说我们离你们甚远呢？其实你们是住在我们中间。</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 9:21; 创世记 9:25–26; 约书亚记 9:27"> 现在你们是被咒诅的。你们中间的人必断不了做奴仆，为我神的殿做劈柴挑水的人。”</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 20:15–17; 申命记 7:1–2; 出埃及记 23:31–33"> 他们回答约书亚说：“因为有人实在告诉你的仆人，耶和华你的神曾吩咐他的仆人摩西，把这全地赐给你们，并在你们面前灭绝这地的一切居民，所以我们为你们的缘故甚怕丧命，就行了这事。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 16:6; 士师记 10:15; 耶利米书 26:14"> 现在我们在你手中，你以怎样待我们为善为正，就怎样做吧！”</span>
<span className="v" id="v26" data-v="26"> 于是约书亚这样待他们，救他们脱离以色列人的手，以色列人就没有杀他们。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 12:5"> 当日约书亚使他们在耶和华所要选择的地方，为会众和耶和华的坛做劈柴挑水的人，直到今日。</span>
</div>
</div>

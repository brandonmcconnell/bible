## 以色列人败于艾城

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 22:20; 传道书 9:18; 历代志上 2:6–7"> 以色列人在当灭的物上犯了罪，因为犹大支派中，谢拉的曾孙、撒底的孙子、迦米的儿子亚干取了当灭的物。耶和华的怒气就向以色列人发作。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="约书亚记 18:12; 何西阿书 4:15; 撒母耳记上 14:23"> 当下，约书亚从耶利哥打发人往伯特利东边，靠近伯亚文的艾城去，吩咐他们说：“你们上去窥探那地。”他们就上去窥探艾城。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 6:11–12; 路加福音 13:24; 彼得后书 1:5"> 他们回到约书亚那里，对他说：“众民不必都上去，只要二三千人上去就能攻取艾城。不必劳累众民都去，因为那里的人少。”</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 28:25; 利未记 26:17; 申命记 32:30"> 于是民中约有三千人上那里去，竟在艾城人面前逃跑了。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 2:11; 约书亚记 2:9; 利未记 26:36"> 艾城的人击杀了他们三十六人，从城门前追赶他们，直到示巴琳，在下坡杀败他们。众民的心就消化如水。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 37:29; 创世记 37:34; 启示录 18:19"> 约书亚便撕裂衣服，他和以色列的长老把灰撒在头上，在耶和华的约柜前俯伏在地，直到晚上。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 12:5; 列王纪下 3:10; 马太福音 17:20"> 约书亚说：“哀哉！主耶和华啊，你为什么竟领这百姓过约旦河，将我们交在亚摩利人的手中，使我们灭亡呢？我们不如住在约旦河那边倒好！</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 3:5–6; 以斯拉记 9:10; 哈巴谷书 2:1"> 主啊，以色列人既在仇敌面前转背逃跑，我还有什么可说的呢？</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 32:12; 诗篇 83:4; 以西结书 36:22–23"> 迦南人和这地一切的居民听见了，就必围困我们，将我们的名从地上除灭。那时你为你的大名要怎样行呢？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 15:22; 出埃及记 14:15; 撒母耳记上 16:1"> 耶和华吩咐约书亚说：“起来！你为何这样俯伏在地呢？</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 5:1–2; 希伯来书 4:13; 约书亚记 6:17–19"> 以色列人犯了罪，违背了我所吩咐他们的约，取了当灭的物，又偷窃，又行诡诈，又把那当灭的放在他们的家具里。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 5:4–5; 以赛亚书 59:2; 约书亚记 6:18"> 因此，以色列人在仇敌面前站立不住。他们在仇敌面前转背逃跑，是因成了被咒诅的。你们若不把当灭的物从你们中间除掉，我就不再与你们同在了。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米哀歌 3:40–41; 约书亚记 3:5; 马太福音 7:5"> 你起来，叫百姓自洁，对他们说：‘你们要自洁，预备明天，因为耶和华以色列的神这样说：“以色列啊，你们中间有当灭的物，你们若不除掉，在仇敌面前必站立不住。”</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 16:33; 约拿书 1:7; 约书亚记 7:17–18"> 到了早晨，你们要按着支派近前来；耶和华所取的支派，要按着宗族近前来；耶和华所取的宗族，要按着家室近前来；耶和华所取的家室，要按着人丁，一个一个地近前来。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 34:7; 撒母耳记上 14:38–39; 士师记 20:6"> 被取的人有当灭的物在他那里，他和他所有的必被火焚烧；因他违背了耶和华的约，又因他在以色列中行了愚妄的事。’”</span>
</div>
</div>

## 亚干认罪

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="诗篇 119:60; 约书亚记 3:1; 创世记 22:3"> 于是，约书亚清早起来，使以色列人按着支派近前来，取出来的是犹大支派；</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 26:20; 历代志上 2:4–7; 创世记 38:30"> 使犹大支派<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：宗族。">a</a></sup>近前来，就取了谢拉的宗族；使谢拉的宗族，按着家室人丁，一个一个地近前来，取出来的是撒底；</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 32:23; 使徒行传 5:1–10; 撒母耳记上 14:42"> 使撒底的家室，按着人丁，一个一个地近前来，就取出犹大支派的人谢拉的曾孙、撒底的孙子、迦米的儿子亚干。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 6:5; 耶利米书 13:16; 约翰福音 9:24"> 约书亚对亚干说：“我儿，我劝你将荣耀归给耶和华以色列的神，在他面前认罪，将你所做的事告诉我，不要向我隐瞒。”</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 38:18; 约伯记 33:27; 创世记 42:21"> 亚干回答约书亚说：“我实在得罪了耶和华以色列的神！我所做的事如此如此：</span>
<span className="v" id="v21" data-v="21" data-xref="雅各书 1:15; 诗篇 119:37; 约翰一书 2:15–16"> 我在所夺的财物中看见一件美好的示拿衣服，二百舍客勒银子，一条金子重五十舍客勒，我就贪爱这些物件，便拿去了。现今藏在我帐篷内的地里，银子在衣服底下。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 约书亚就打发人跑到亚干的帐篷里，那件衣服果然藏在他帐篷内，银子在底下。</span>
<span className="v" id="v23" data-v="23"> 他们就从帐篷里取出来，拿到约书亚和以色列众人那里，放在耶和华面前。</span>
<span className="v" id="v24" data-v="24" data-xref="箴言 15:27; 提摩太前书 6:9–10; 约书亚记 7:26"> 约书亚和以色列众人把谢拉的曾孙亚干和那银子、那件衣服、那条金子，并亚干的儿女、牛、驴、羊、帐篷，以及他所有的，都带到亚割谷去。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 6:18; 历代志上 2:7; 利未记 24:14"> 约书亚说：“你为什么连累我们呢？今日耶和华必叫你受连累。”于是以色列众人用石头打死他，将石头扔在其上，又用火焚烧他所有的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“他所有的”原文作“他们”。">b</a></sup>。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 65:10; 何西阿书 2:15; 申命记 13:17"> 众人在亚干身上堆成一大堆石头，直存到今日。于是耶和华转意，不发他的烈怒。因此那地方名叫亚割<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“亚割”就是“连累”的意思。">c</a></sup>谷，直到今日。</span>
</div>
</div>

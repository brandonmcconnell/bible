## 犹大所得之地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 26:55–56; 约书亚记 14:2; 民数记 33:36–37"> 犹大支派按着宗族拈阄所得之地是在尽南边，到以东的交界，向南直到寻的旷野。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 14:3; 以西结书 47:8; 以赛亚书 11:15"> 他们的南界是从盐海的尽边，就是从朝南的海汊起，</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 34:4; 士师记 1:36; 民数记 20:1"> 通到亚克拉滨坡的南边，接连到寻，上到加低斯巴尼亚的南边，又过希斯仑，上到亚达珥，绕到甲加，</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 34:5; 约书亚记 13:3; 出埃及记 23:31"> 接连到押们，通到埃及小河，直通到海为止。这就是他们的南界。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 34:12; 约书亚记 18:15–19; 民数记 34:10"> 东界是从盐海南边到约旦河口。北界是从约旦河口的海汊起，</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 18:17; 约书亚记 18:19–21"> 上到伯曷拉，过伯亚拉巴的北边，上到鲁本之子波罕的磐石；</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 1:9; 撒母耳记下 17:17; 约书亚记 7:26"> 从亚割谷往北，上到底璧，直向河南亚都冥坡对面的吉甲；又接连到隐示麦泉，直通到隐罗结，</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 18:16; 约书亚记 15:63; 约书亚记 18:28"> 上到欣嫩子谷，贴近耶布斯的南界（耶布斯就是耶路撒冷）；又上到欣嫩谷西边的山顶，就是在利乏音谷极北的边界；</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 13:6; 约书亚记 18:15; 士师记 18:12"> 又从山顶延到尼弗多亚的水源，通到以弗仑山的城邑，又延到巴拉（巴拉就是基列耶琳），</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 14:1; 士师记 14:5; 创世记 38:12–13"> 又从巴拉往西绕到西珥山，接连到耶琳山的北边（耶琳就是基撒仑）；又下到伯示麦过亭纳，</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 15:45; 列王纪下 1:2–3; 撒母耳记上 5:10"> 通到以革伦北边，延到施基仑，接连到巴拉山，又通到雅比聂，直通到海为止。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 34:6–7; 约书亚记 15:47; 以西结书 47:20"> 西界就是大海和靠近大海之地。这是犹大人按着宗族所得之地四围的交界。</span>
</div>
</div>

## 俄陀聂攻取基列西弗

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 13:30; 申命记 1:34–36; 民数记 14:23–24"> 约书亚照耶和华所吩咐的，将犹大人中的一段地，就是基列亚巴，分给耶孚尼的儿子迦勒；亚巴是亚衲族的始祖，基列亚巴就是希伯仑。</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 1:20; 士师记 1:10; 民数记 13:22–23"> 迦勒就从那里赶出亚衲族的三个族长，就是示筛、亚希幔、挞买。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 10:38; 约书亚记 10:3; 士师记 1:11–13"> 又从那里上去，攻击底璧的居民，这底璧从前名叫基列西弗。</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 1:12–13; 士师记 1:6"> 迦勒说：“谁能攻打基列西弗将城夺取，我就把我女儿押撒给他为妻。”</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 3:9; 士师记 1:13; 约书亚记 14:6"> 迦勒兄弟基纳斯的儿子俄陀聂夺取了那城，迦勒就把女儿押撒给他为妻。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 24:64; 撒母耳记上 25:23"> 押撒过门的时候，劝丈夫向她父亲求一块田。押撒一下驴，迦勒问她说：“你要什么？”</span>
<span className="v" id="v19" data-v="19" data-xref="士师记 1:14–15; 撒母耳记上 25:27; 申命记 33:7"> 她说：“求你赐福给我，你既将我安置在南地，求你也给我水泉。”她父亲就把上泉下泉赐给她。</span>
</div>
</div>

<span className="v" id="v22" data-v="22"> 基拿、底摩拿、亚大达、</span>

<span className="v" id="v42" data-v="42" data-xref="约书亚记 10:29; 列王纪下 8:22; 约书亚记 19:7"> 又有立拿、以帖、亚珊、</span>

<div className="bp">

</div>

<span className="v" id="v49" data-v="49" data-xref="约书亚记 15:15; 士师记 1:11"> 大拿、基列萨拿（基列萨拿就是底璧）、</span>

</div>

</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="撒母耳记上 25:2; 约书亚记 15:24; 撒母耳记上 23:25"> 又有玛云、迦密、西弗、淤他、</span>
<span className="v" id="v56" data-v="56"> 耶斯列、约甸、撒挪亚、</span>
<span className="v" id="v57" data-v="57" data-xref="约书亚记 15:10; 创世记 38:12; 耶利米书 14:1"> 该隐、基比亚、亭纳，共十座城，还有属城的村庄。</span>

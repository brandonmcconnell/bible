## 五王合攻基遍

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 6:21; 希伯来书 7:1; 约书亚记 8:2"> 耶路撒冷王亚多尼洗德听见约书亚夺了艾城，尽行毁灭，怎样待耶利哥和耶利哥的王，也照样待艾城和艾城的王，又听见基遍的居民与以色列人立了和约，住在他们中间，</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 11:25; 约书亚记 2:24; 出埃及记 15:14–16"> 就甚惧怕。因为基遍是一座大城，如都城一般，比艾城更大，并且城内的人都是勇士。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 11:9; 弥迦书 1:13; 约书亚记 10:1"> 所以耶路撒冷王亚多尼洗德打发人去见希伯仑王何咸、耶末王毗兰、拉吉王雅非亚和伊矶伦王底璧，说：</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 9:15; 约书亚记 10:1; 以赛亚书 8:9–10"> “求你们上来帮助我，我们好攻打基遍，因为他们与约书亚和以色列人立了和约。”</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 8:9–10; 创世记 15:16; 约书亚记 10:6"> 于是五个亚摩利王，就是耶路撒冷王、希伯仑王、耶末王、拉吉王、伊矶伦王，大家聚集，率领他们的众军上去，对着基遍安营，攻打基遍。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约书亚记 9:6; 约书亚记 5:10; 申命记 1:15"> 基遍人就打发人往吉甲的营中去见约书亚，说：“你不要袖手不顾你的仆人，求你速速上来拯救我们，帮助我们，因为住山地亚摩利人的诸王都聚集攻击我们。”</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 8:1; 以赛亚书 8:12; 以赛亚书 8:14"> 于是约书亚和他一切兵丁，并大能的勇士，都从吉甲上去。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 8:31; 申命记 3:2; 诗篇 27:1–2"> 耶和华对约书亚说：“不要怕他们，因为我已将他们交在你手里，他们无一人能在你面前站立得住。”</span>
<span className="v" id="v9" data-v="9" data-xref="传道书 9:10; 提摩太后书 2:3; 箴言 24:11–12"> 约书亚就终夜从吉甲上去，猛然临到他们那里。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 18:14; 约书亚记 16:3; 约书亚记 16:5"> 耶和华使他们在以色列人面前溃乱。约书亚在基遍大大地杀败他们，追赶他们，在伯和仑的上坡路击杀他们，直到亚西加和玛基大。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 28:2; 士师记 5:20; 诗篇 18:12–14"> 他们在以色列人面前逃跑，正在伯和仑下坡的时候，耶和华从天上降大冰雹<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“冰雹”原文作“石头”。">a</a></sup>在他们身上，直降到亚西加，打死他们。被冰雹打死的，比以色列人用刀杀死的还多。</span>
</div>
</div>

## 日月停止

<div className="bt">
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="哈巴谷书 3:11; 以赛亚书 38:8; 以赛亚书 60:20"> 当耶和华将亚摩利人交付以色列人的日子，约书亚就祷告耶和华，在以色列人眼前说：<br /><span className="pl pl-1">“日头啊，你要停在基遍！</span><br /><span className="pl pl-1">月亮啊，你要止在亚雅仑谷！”</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="哈巴谷书 3:11; 以赛亚书 38:8; 约书亚记 10:14"> <span className="pl pl-1">于是日头停留，月亮止住，</span><br /><span className="pl pl-1">直等国民向敌人报仇。</span><br />这事岂不是写在《雅煞珥书》上吗？“日头在天当中停住，不急速下落，约有一日之久。”</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 1:30; 出埃及记 14:14; 约书亚记 10:42"> 在这日以前，这日以后，耶和华听人的祷告没有像这日的，是因耶和华为以色列争战。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约书亚记 10:43; 约书亚记 10:6"> 约书亚和以色列众人回到吉甲的营中。</span>
</div>
</div>

## 五王被擒见杀

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 24:8; 阿摩司书 9:2; 诗篇 139:7–10"> 那五王逃跑，藏在玛基大洞里。</span>
<span className="v" id="v17" data-v="17"> 有人告诉约书亚说：“那五王已经找到了，都藏在玛基大洞里。”</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 27:66; 约伯记 21:30; 阿摩司书 9:1"> 约书亚说：“你们把几块大石头滚到洞口，派人看守。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 18:37–41; 耶利米书 8:14; 以赛亚书 9:14–15"> 你们却不可耽延，要追赶你们的仇敌，击杀他们尽后边的人，不容他们进自己的城邑，因为耶和华你们的神已经把他们交在你们手里。”</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 8:24; 撒母耳记下 20:6; 约书亚记 10:10"> 约书亚和以色列人大大杀败他们，直到将他们灭尽，其中剩下的人都进了坚固的城。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 11:7; 以赛亚书 54:17; 以赛亚书 57:4"> 众百姓就安然回玛基大营中，到约书亚那里。没有一人敢向以色列人饶舌。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 15:32"> 约书亚说：“打开洞口，将那五王从洞里带出来，领到我面前。”</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 10:1; 约书亚记 10:5; 约书亚记 10:3"> 众人就这样行，将那五王，就是耶路撒冷王、希伯仑王、耶末王、拉吉王、伊矶伦王，从洞里带出来，领到约书亚面前。</span>
<span className="v" id="v24" data-v="24" data-xref="玛拉基书 4:3; 罗马书 16:20; 启示录 2:26–27"> 带出那五王到约书亚面前的时候，约书亚就召了以色列众人来，对那些和他同去的军长说：“你们近前来，把脚踏在这些王的颈项上。”他们就近前来，把脚踏在这些王的颈项上。</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多后书 1:10; 约书亚记 1:9; 以弗所书 6:10"> 约书亚对他们说：“你们不要惧怕，也不要惊惶。应当刚强壮胆，因为耶和华必这样待你们所要攻打的一切仇敌。”</span>
<span className="v" id="v26" data-v="26" data-xref="约书亚记 8:29; 撒母耳记下 21:9; 马太福音 27:25"> 随后约书亚将这五王杀死，挂在五棵树上。他们就在树上直挂到晚上。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 8:29; 申命记 21:22–23; 约书亚记 7:26"> 日头要落的时候，约书亚一吩咐，人就把尸首从树上取下来，丢在他们藏过的洞里，把几块大石头放在洞口，直存到今日。</span>
</div>
</div>

## 约书亚攻取诸邑

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约书亚记 6:21; 申命记 7:16; 申命记 20:16–17"> 当日，约书亚夺了玛基大，用刀击杀城中的人和王，将其中一切人口尽行杀灭，没有留下一个。他待玛基大王像从前待耶利哥王一样。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约书亚记 21:13; 约书亚记 15:42; 耶利米书 52:1"> 约书亚和以色列众人从玛基大往立拿去，攻打立拿。</span>
<span className="v" id="v30" data-v="30"> 耶和华将立拿和立拿的王也交在以色列人手里。约书亚攻打这城，用刀击杀了城中的一切人口，没有留下一个。他待立拿王像从前待耶利哥王一样。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约书亚记 10:3; 约书亚记 12:11; 约书亚记 10:5"> 约书亚和以色列众人从立拿往拉吉去，对着拉吉安营，攻打这城。</span>
<span className="v" id="v32" data-v="32"> 耶和华将拉吉交在以色列人的手里。第二天约书亚就夺了拉吉，用刀击杀了城中的一切人口，是照他向立拿一切所行的。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约书亚记 16:10; 士师记 1:29; 约书亚记 16:3"> 那时基色王荷兰上来帮助拉吉，约书亚就把他和他的民都击杀了，没有留下一个。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="约书亚记 10:3; 约书亚记 12:12; 约书亚记 15:39"> 约书亚和以色列众人从拉吉往伊矶伦去，对着伊矶伦安营，攻打这城。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 26:44; 约书亚记 10:37; 约伯记 19:10"> 当日就夺了城，用刀击杀了城中的人。那日，约书亚将城中的一切人口尽行杀灭，是照他向拉吉一切所行的。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="士师记 1:10; 约书亚记 15:13; 约书亚记 14:13–14"> 约书亚和以色列众人从伊矶伦上希伯仑去，攻打这城，</span>
<span className="v" id="v37" data-v="37"> 就夺了希伯仑和属希伯仑的诸城邑，用刀将城中的人与王，并那些城邑中的人口，都击杀了，没有留下一个，是照他向伊矶伦所行的，把城中的一切人口尽行杀灭。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="约书亚记 15:15; 约书亚记 12:13; 约书亚记 15:49"> 约书亚和以色列众人回到底璧，攻打这城，</span>
<span className="v" id="v39" data-v="39" data-xref="俄巴底亚书 1:18; 约书亚记 11:8; 申命记 3:3"> 就夺了底璧和属底璧的城邑，又擒获底璧的王，用刀将这些城中的人口尽行杀灭，没有留下一个。他待底璧和底璧王，像从前待希伯仑和立拿与立拿王一样。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="申命记 7:2–16; 出埃及记 23:31–33; 约书亚记 8:27"> 这样，约书亚击杀全地的人，就是山地、南地、高原、山坡的人和那些地的诸王，没有留下一个。将凡有气息的尽行杀灭，正如耶和华以色列的神所吩咐的。</span>
<span className="v" id="v41" data-v="41" data-xref="约书亚记 11:16; 约书亚记 15:51; 申命记 9:23"> 约书亚从加低斯巴尼亚攻击到加沙，又攻击歌珊全地，直到基遍。</span>
<span className="v" id="v42" data-v="42" data-xref="约书亚记 10:14; 诗篇 46:7; 诗篇 80:3"> 约书亚一时杀败了这些王，并夺了他们的地，因为耶和华以色列的神为以色列争战。</span>
<span className="v" id="v43" data-v="43" data-xref="约书亚记 10:15; 约书亚记 4:19; 撒母耳记上 11:14"> 于是约书亚和以色列众人回到吉甲的营中。</span>
</div>
</div>

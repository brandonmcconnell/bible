## 约书亚再攻艾城

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 1:9; 申命记 7:18; 申命记 1:21"> 耶和华对约书亚说：“不要惧怕，也不要惊惶。你起来，率领一切兵丁上艾城去，我已经把艾城的王和他的民、他的城并他的地，都交在你手里。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 20:14; 约书亚记 6:21; 历代志下 20:22"> 你怎样待耶利哥和耶利哥的王，也当照样待艾城和艾城的王；只是城内所夺的财物和牲畜，你们可以取为自己的掠物。你要在城后设下伏兵。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马太福音 24:39; 马太福音 25:6; 帖撒罗尼迦前书 5:2"> 于是，约书亚和一切兵丁都起来，要上艾城去。约书亚选了三万大能的勇士，夜间打发他们前往，</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 20:29; 约书亚记 8:16; 士师记 20:36"> 吩咐他们说：“你们要在城后埋伏，不可离城太远，都要各自准备。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 7:5; 马太福音 10:16; 士师记 20:31–33"> 我与我所带领的众民要向城前往。城里的人像初次出来攻击我们的时候，我们就在他们面前逃跑，</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 20:32; 出埃及记 15:9; 传道书 8:11"> 他们必出来追赶我们，直到我们引诱他们离开城，因为他们必说：‘这些人像初次在我们面前逃跑。’所以我们要在他们面前逃跑，</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 21:30–31; 列王纪下 5:1; 约书亚记 8:1"> 你们就从埋伏的地方起来，夺取那城，因为耶和华你们的神必把城交在你们手里。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 13:28; 约书亚记 1:16; 约书亚记 1:9"> 你们夺了城以后，就放火烧城，要照耶和华的话行。这是我吩咐你们的。”</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 7:2; 创世记 12:8; 以斯拉记 2:28"> 约书亚打发他们前往，他们就上埋伏的地方去，住在伯特利和艾城的中间，就是在艾城的西边。这夜约书亚却在民中住宿。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约书亚记 6:12; 诗篇 119:60; 创世记 22:3"> 约书亚清早起来，点齐百姓，他和以色列的长老在百姓前面上艾城去。</span>
<span className="v" id="v11" data-v="11"> 众民，就是他所带领的兵丁，都上去，向前直往，来到城前，在艾城北边安营。在约书亚和艾城中间有一山谷。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 8:2–3"> 他挑了约有五千人，使他们埋伏在伯特利和艾城的中间，就是在艾城的西边。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 8:12; 约书亚记 8:8"> 于是安置了百姓，就是城北的全军和城西的伏兵。这夜约书亚进入山谷之中。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 24:39; 士师记 20:34–36; 申命记 1:1"> 艾城的王看见这景况，就和全城的人清早急忙起来，按所定的时候，出到亚拉巴前，要与以色列人交战。王却不知道在城后有伏兵。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 18:12; 约书亚记 16:1; 士师记 20:36"> 约书亚和以色列众人在他们面前装败，往那通旷野的路逃跑。</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 20:31; 士师记 20:36–39; 约书亚记 8:5–6"> 城内的众民都被招聚，追赶他们。艾城人追赶的时候，就被引诱离开城。</span>
<span className="v" id="v17" data-v="17" data-xref="约伯记 5:13; 约书亚记 8:3; 以赛亚书 19:11–13"> 艾城和伯特利城没有一人不出来追赶以色列人的，撇了敞开的城门，去追赶以色列人。</span>
</div>
</div>

## 取艾城而焚之

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约书亚记 8:26; 约伯记 15:25; 撒母耳记上 17:41"> 耶和华吩咐约书亚说：“你向艾城伸出手里的短枪，因为我要将城交在你手里。”约书亚就向城伸出手里的短枪。</span>
<span className="v" id="v19" data-v="19"> 他一伸手，伏兵就从埋伏的地方急忙起来，夺了城，跑进城去，放火焚烧。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 76:5; 约伯记 11:20; 创世记 19:28"> 艾城的人回头一看，不料，城中烟气冲天，他们就无力向左向右逃跑。那往旷野逃跑的百姓便转身攻击追赶他们的人。</span>
<span className="v" id="v21" data-v="21"> 约书亚和以色列众人见伏兵已经夺了城，城中烟气飞腾，就转身回去，击杀艾城的人。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 7:2; 约书亚记 10:28; 约书亚记 6:21"> 伏兵也出城迎击艾城人。艾城人就困在以色列人中间，前后都是以色列人。于是以色列人击杀他们，没有留下一个，也没有一个逃脱的，</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 15:8; 约书亚记 10:17; 启示录 19:20"> 生擒了艾城的王，将他解到约书亚那里。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约书亚记 11:10–14; 约书亚记 10:30–41; 民数记 21:24"> 以色列人在田间和旷野杀尽所追赶一切艾城的居民。艾城人倒在刀下，直到灭尽。以色列众人就回到艾城，用刀杀了城中的人。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 20:16–18"> 当日杀毙的人，连男带女共有一万二千，就是艾城所有的人。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 17:11–12; 约书亚记 8:18"> 约书亚没有收回手里所伸出来的短枪，直到把艾城的一切居民尽行杀灭。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 8:2; 民数记 31:26; 诗篇 50:10"> 唯独城中的牲畜和财物，以色列人都取为自己的掠物，是照耶和华所吩咐约书亚的话。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 13:16; 耶利米书 49:2; 列王纪下 19:25"> 约书亚将艾城焚烧，使城永为高堆、荒场，直到今日。</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 7:26; 撒母耳记下 18:17; 申命记 21:22–23"> 又将艾城王挂在树上，直到晚上。日落的时候，约书亚吩咐人把尸首从树上取下来，丢在城门口，在尸首上堆成一大堆石头，直存到今日。</span>
</div>
</div>

## 约书亚筑坛录法于石

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="申命记 27:4–6; 出埃及记 20:24; 创世记 12:7–8"> 那时，约书亚在以巴路山上为耶和华以色列的神筑一座坛，</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 27:5–7; 出埃及记 20:24–25; 约书亚记 8:34–35"> 是用没有动过铁器的整石头筑的，照着耶和华仆人摩西所吩咐以色列人的话，正如摩西律法书上所写的。众人在这坛上给耶和华奉献燔祭和平安祭。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 27:2–3; 申命记 27:8"> 约书亚在那里，当着以色列人面前，将摩西所写的律法抄写在石头上。</span>
<span className="v" id="v33" data-v="33" data-xref="申命记 11:29; 申命记 31:12; 申命记 31:9"> 以色列众人，无论是本地人是寄居的，和长老、官长并审判官都站在约柜两旁，在抬耶和华约柜的祭司利未人面前，一半对着基利心山，一半对着以巴路山，为以色列民祝福，正如耶和华仆人摩西先前所吩咐的。</span>
<span className="v" id="v34" data-v="34" data-xref="尼希米记 8:2–3; 尼希米记 13:1; 申命记 31:10–12"> 随后约书亚将律法上祝福、咒诅的话，照着律法书上一切所写的，都宣读了一遍。</span>
<span className="v" id="v35" data-v="35" data-xref="申命记 31:12; 尼希米记 8:2; 耶利米书 26:2"> 摩西所吩咐的一切话，约书亚在以色列全会众和妇女、孩子，并他们中间寄居的外人面前，没有一句不宣读的。</span>
</div>
</div>

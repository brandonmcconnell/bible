<span className="v" id="v3" data-v="3" data-xref="出埃及记 20:14; 马太福音 5:32; 马可福音 10:6–12"> 所以丈夫活着，她若归于别人，便叫淫妇；丈夫若死了，她就脱离了丈夫的律法，虽然归于别人，也不是淫妇。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前书 2:24; 加拉太书 5:22–23; 以赛亚书 54:5"> 我的弟兄们，这样说来，你们藉着基督的身体，在律法上也是死了，叫你们归于别人，就是归于那从死里复活的，叫我们结果子给神。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 2:3; 加拉太书 5:16–17; 加拉太书 5:24"> 因为我们属肉体的时候，那因律法而生的恶欲就在我们肢体中发动，以致结成死亡的果子；</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 3:23–25; 哥林多后书 3:6; 罗马书 7:4"> 但我们既然在捆我们的律法上死了，现今就脱离了律法，叫我们服侍主，要按着心灵<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“心灵”或作“圣灵”。">a</a></sup>的新样，不按着仪文的旧样。</span>

## 律法使人知罪

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="罗马书 3:20; 罗马书 4:15; 哥林多前书 15:56"> 这样，我们可说什么呢？律法是罪吗？断乎不是。只是非因律法，我就不知何为罪。非律法说“不可起贪心”，我就不知何为贪心。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 7:11; 哥林多前书 15:56; 罗马书 4:15"> 然而罪趁着机会，就藉着诫命叫诸般的贪心在我里头发动，因为没有律法罪是死的。</span>
<span className="v" id="v9" data-v="9" data-xref="加拉太书 3:10; 罗马书 8:7; 雅各书 2:10–11"> 我以前没有律法是活着的，但是诫命来到，罪又活了，我就死了。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 3:7; 罗马书 10:5; 利未记 18:5"> 那本来叫人活的诫命，反倒叫我死；</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 3:13; 罗马书 7:8; 希伯来书 3:13"> 因为罪趁着机会，就藉着诫命引诱我，并且杀了我。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太前书 1:8; 诗篇 119:137; 诗篇 19:7–12"> 这样看来，律法是圣洁的，诫命也是圣洁、公义、良善的。</span>
<span className="v" id="v13" data-v="13" data-xref="雅各书 1:13–15; 加拉太书 3:21; 罗马书 8:3"> 既然如此，那良善的是叫我死吗？断乎不是。叫我死的乃是罪。但罪藉着那良善的叫我死，就显出真是罪，叫罪因着诫命更显出是恶极了。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 21:25; 列王纪下 17:17; 罗马书 7:18"> 我们原晓得律法是属乎灵的，但我是属乎肉体的，是已经卖给罪了。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 5:17; 罗马书 7:19–20; 传道书 7:20"> 因为我所做的，我自己不明白；我所愿意的，我并不做；我所恨恶的，我倒去做。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 7:12; 罗马书 7:14; 提摩太前书 1:8"> 若我所做的，是我所不愿意的，我就应承律法是善的。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 7:20; 腓立比书 3:8–9; 罗马书 7:18"> 既是这样，就不是我做的，乃是住在我里头的罪做的。</span>
</div>
</div>

## 良心与情欲交战

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰福音 3:6; 诗篇 51:5; 加拉太书 5:17"> 我也知道，在我里头，就是我肉体之中，没有良善。因为立志为善由得我，只是行出来由不得我。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 7:15"> 故此，我所愿意的善，我反不做；我所不愿意的恶，我倒去做。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 7:17"> 若我去做所不愿意做的，就不是我做的，乃是住在我里头的罪做的。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 6:14; 罗马书 7:23; 诗篇 119:133"> 我觉得有个律，就是我愿意为善的时候，便有恶与我同在。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 1:2; 诗篇 40:8; 诗篇 119:35"> 因为按着我里面的意思<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：人。">b</a></sup>，我是喜欢神的律，</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 5:17; 雅各书 4:1; 罗马书 8:2"> 但我觉得肢体中另有个律和我心中的律交战，把我掳去，叫我附从那肢体中犯罪的律。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 6:6; 提摩太后书 4:18; 提多书 2:14"> 我真是苦啊！谁能救我脱离这取死的身体呢？</span>
<span className="v" id="v25" data-v="25" data-xref="加拉太书 5:17–24; 歌罗西书 3:17; 哥林多后书 12:9–10"> 感谢神！靠着我们的主耶稣基督就能脱离了。这样看来，我以内心顺服神的律，我肉体却顺服罪的律了。</span>
</div>

## 犹太人的长处

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="罗马书 2:25–29; 创世记 25:32; 传道书 6:11"> 这样说来，犹太人有什么长处，割礼有什么益处呢？</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 9:4; 使徒行传 7:38; 哥林多前书 9:17"> 凡事大有好处，第一是神的圣言交托他们。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太后书 2:13; 希伯来书 4:2; 罗马书 9:6"> 即便有不信的，这有何妨呢？难道他们的不信就废掉神的信吗？</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 51:4; 诗篇 116:11; 加拉太书 2:17"> 断乎不能！不如说，神是真实的，人都是虚谎的。如经上所记：<br /><span className="pl pl-1">“你责备人的时候显为公义，</span><br /><span className="pl pl-1">被人议论的时候可以得胜。”</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="罗马书 6:19; 加拉太书 3:15; 罗马书 9:18–20"> 我且照着人的常话说，我们的不义若显出神的义来，我们可以怎么说呢？神降怒是他不义吗？</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 18:25; 使徒行传 17:31; 约伯记 8:3"> 断乎不是！若是这样，神怎能审判世界呢？</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 3:4; 罗马书 9:19–20; 使徒行传 13:27–29"> 若神的真实因我的虚谎越发显出他的荣耀，为什么我还受审判，好像罪人呢？</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 6:1; 罗马书 6:15; 罗马书 5:20"> 为什么不说“我们可以作恶以成善”呢？这是毁谤我们的人说我们有这话。这等人定罪是该当的。</span>
</div>
</div>

## 引证犹太和外邦都在罪恶之下

<div className="bt">
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="加拉太书 3:22; 罗马书 6:15; 以赛亚书 65:5"> 这却怎么样呢？我们比他们强吗？决不是的！因我们已经证明：犹太人和希腊人都在罪恶之下。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 53:1–3; 诗篇 14:1–3; 罗马书 3:23"> 就如经上所记：<br /><span className="pl pl-1">“没有义人，连一个也没有。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 14:2–4; 诗篇 53:2; 提多书 3:3"> <span className="pl pl-1">没有明白的，</span><br /><span className="pl pl-1">没有寻求神的。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 14:3; 传道书 7:20; 以赛亚书 64:6"> <span className="pl pl-1">都是偏离正路，</span><br /><span className="pl pl-1">一同变为无用；</span><br /><span className="pl pl-1">没有行善的，连一个也没有。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 5:9; 诗篇 140:3; 马太福音 23:27–28"> <span className="pl pl-1">他们的喉咙是敞开的坟墓，</span><br /><span className="pl pl-1">他们用舌头弄诡诈，</span><br /><span className="pl pl-1">嘴唇里有虺蛇的毒气，</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 10:7; 诗篇 109:17–18; 诗篇 59:12"> <span className="pl pl-1">满口是咒骂苦毒。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 59:7–8; 箴言 1:16; 箴言 6:18"> <span className="pl pl-1">杀人流血，</span><br /><span className="pl pl-1">他们的脚飞跑；</span><br /></span>
<span className="v" id="v16" data-v="16"> <span className="pl pl-1">所经过的路，便行残害暴虐的事；</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 59:8; 罗马书 5:1; 路加福音 1:79"> <span className="pl pl-1">平安的路，他们未曾知道。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 36:1; 箴言 23:17; 箴言 16:6"> <span className="pl pl-1">他们眼中不怕神。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="加拉太书 3:10; 加拉太书 3:22–23; 罗马书 2:12–18"> 我们晓得律法上的话都是对律法以下之人说的，好塞住各人的口，叫普世的人都伏在神审判之下。</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太书 2:16; 使徒行传 13:39; 罗马书 3:28"> 所以凡有血气的，没有一个因行律法能在神面前称义，因为律法本是叫人知罪。</span>
</div>
</div>

## 信靠耶稣乃得称义

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 10:43; 耶利米书 33:16; 腓立比书 3:9"> 但如今，神的义在律法以外已经显明出来，有律法和先知为证，</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 10:12; 加拉太书 3:28; 罗马书 8:1"> 就是神的义因信耶稣基督加给一切相信的人，并没有分别。</span>
<span className="v" id="v23" data-v="23" data-xref="传道书 7:20; 约翰一书 1:8–10; 罗马书 3:9"> 因为世人都犯了罪，亏缺了神的荣耀，</span>
<span className="v" id="v24" data-v="24" data-xref="彼得前书 1:18–19; 提多书 3:5–7; 歌罗西书 1:14"> 如今却蒙神的恩典，因基督耶稣的救赎，就白白地称义。</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 3:23–24; 彼得前书 1:18–20; 约翰一书 4:10"> 神设立耶稣做挽回祭，是凭着耶稣的血，藉着人的信，要显明神的义。因为他用忍耐的心宽容人先时所犯的罪，</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 32:4; 罗马书 4:5; 罗马书 3:30"> 好在今时显明他的义，使人知道他自己为义，也称信耶稣的人为义。</span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 4:2; 罗马书 2:23; 哥林多前书 1:29–31"> 既是这样，哪里能夸口呢？没有可夸的了。用何法没有的呢？是用立功之法吗？不是，乃用信主之法。</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太书 2:16; 加拉太书 3:8; 提多书 3:7"> 所以<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷作：因为。">a</a></sup>我们看定了，人称义是因着信，不在乎遵行律法。</span>
<span className="v" id="v29" data-v="29" data-xref="歌罗西书 3:11; 以弗所书 3:6; 撒迦利亚书 2:11"> 难道神只做犹太人的神吗？不也是做外邦人的神吗？是的，也做外邦人的神。</span>
<span className="v" id="v30" data-v="30" data-xref="加拉太书 3:8; 加拉太书 3:20; 腓立比书 3:3"> 神既是一位，他就要因信称那受割礼的为义，也要因信称那未受割礼的为义。</span>
<span className="v" id="v31" data-v="31" data-xref="加拉太书 2:21; 马太福音 5:17; 罗马书 13:8–10"> 这样，我们因信废了律法吗？断乎不是，更是坚固律法。</span>
</div>
</div>

## 举荐非比

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 18:18; 彼得前书 1:22–23; 提摩太前书 5:9–10"> 我对你们举荐我们的姐妹非比，她是坚革哩教会中的女执事。</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比书 2:29; 腓立比书 1:27; 马太福音 10:40–42"> 请你们为主接待她，合乎圣徒的体统。她在何事上要你们帮助，你们就帮助她，因她素来帮助许多人，也帮助了我。</span>

## 几样的问安

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 16:19; 提摩太后书 4:19; 使徒行传 18:26"> 问百基拉和亚居拉安。他们在基督耶稣里与我同工，</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比书 2:30; 约翰一书 3:16; 哥林多前书 16:1"> 也为我的命将自己的颈项置之度外。不但我感谢他们，就是外邦的众教会也感谢他们。</span>
<span className="v" id="v5" data-v="5" data-xref="歌罗西书 4:15; 腓利门书 1:2; 哥林多前书 16:19"> 又问在他们家中的教会安。问我所亲爱的以拜尼土安，他在亚细亚是归基督初结的果子。</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 16:12; 马太福音 27:55; 提摩太前书 5:10"> 又问马利亚安，她为你们多受劳苦。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 16:11; 罗马书 16:21; 腓利门书 1:23"> 又问我亲属与我一同坐监的安多尼古和犹尼亚安，他们在使徒中是有名望的，也是比我先在基督里。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比书 4:1; 约翰一书 3:14; 罗马书 16:5"> 又问我在主里面所亲爱的暗伯利安。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 16:2–3; 罗马书 16:21"> 又问在基督里与我们同工的耳巴奴并我所亲爱的士大古安。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 14:18; 彼得前书 1:7; 申命记 8:2"> 又问在基督里经过试验的亚比利安。问亚利多布家里的人安。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 16:21; 罗马书 16:7"> 又问我亲属希罗天安。问拿其数家在主里的人安。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦前书 5:12–13; 希伯来书 6:10–11; 哥林多前书 15:58"> 又问为主劳苦的土非拿氏和土富撒氏安。问可亲爱为主多受劳苦的彼息氏安。</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 15:21; 提摩太前书 5:2; 约翰二书 1:1"> 又问在主蒙拣选的鲁孚和他母亲安，他的母亲就是我的母亲。</span>
<span className="v" id="v14" data-v="14" data-xref="歌罗西书 1:2; 罗马书 8:29; 希伯来书 3:1"> 又问亚逊其土、弗勒干、黑米、八罗巴、黑马，并与他们在一处的弟兄们安。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 16:2; 罗马书 1:7; 罗马书 16:14"> 又问非罗罗古和犹利亚，尼利亚和他姐妹，同阿林巴，并与他们在一处的众圣徒安。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦前书 5:26; 哥林多前书 16:20; 哥林多后书 13:12"> 你们亲嘴问安彼此务要圣洁。基督的众教会都问你们安。</span>
</div>
</div>

## 防避背道者的诱惑

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="犹大书 1:19; 帖撒罗尼迦后书 3:6; 提摩太前书 6:3–5"> 弟兄们，那些离间你们、叫你们跌倒，背乎所学之道的人，我劝你们要留意躲避他们。</span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 2:4; 马太福音 7:15; 提摩太前书 6:5"> 因为这样的人不服侍我们的主基督，只服侍自己的肚腹，用花言巧语诱惑那些老实人的心。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 10:16; 哥林多前书 14:20; 腓立比书 2:15"> 你们的顺服已经传于众人，所以我为你们欢喜，但我愿意你们在善上聪明，在恶上愚拙。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:19; 约翰一书 3:8; 创世记 3:15"> 赐平安的神快要将撒旦践踏在你们脚下。愿我主耶稣基督的恩常和你们同在！</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 20:4; 使徒行传 17:5; 使徒行传 13:1"> 与我同工的提摩太和我的亲属路求、耶孙、所西巴德问你们安。</span>
<span className="v" id="v22" data-v="22" data-xref="加拉太书 6:11; 哥林多前书 16:21; 罗马书 16:8"> 我这代笔写信的德丢在主里面问你们安。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 1:14; 使徒行传 19:22; 提摩太后书 4:20"> 那接待我，也接待全教会的该犹问你们安。</span>
<span className="v" id="v24" data-v="24"> 城内管银库的以拉都和兄弟括土问你们安。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="哥林多前书 2:7; 罗马书 2:16; 歌罗西书 1:26–27"> 唯有神能照我所传的福音和所讲的耶稣基督，并照永古隐藏不言的奥秘，坚固你们的心。</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 1:5; 加拉太书 3:8; 罗马书 15:18"> 这奥秘如今显明出来，而且按着永生神的命，藉众先知的书指示万国的民，使他们信服真道。</span>
<span className="v" id="v27" data-v="27" data-xref="提摩太前书 1:17; 罗马书 11:36; 启示录 7:10–12"> 愿荣耀因耶稣基督归于独一全智的神，直到永远！阿们。</span>
</div>
</div>

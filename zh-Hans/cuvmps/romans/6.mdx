## 信徒向罪而死向神活着

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 2:16; 加拉太书 5:13; 罗马书 6:15"> 这样，怎么说呢？我们可以仍在罪中，叫恩典显多吗？</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 3:9; 歌罗西书 3:3; 罗马书 7:4"> 断乎不可！我们在罪上死了的人，岂可仍在罪中活着呢？</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 3:27; 加拉太书 2:20–21; 罗马书 6:8"> 岂不知我们这受洗归入基督耶稣的人，是受洗归入他的死吗？</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 5:17; 歌罗西书 3:10; 以弗所书 4:22–24"> 所以，我们藉着洗礼归入死，和他一同埋葬，原是叫我们一举一动有新生的样式，像基督藉着父的荣耀从死里复活一样。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 3:10–11; 哥林多后书 4:10; 歌罗西书 2:12"> 我们若在他死的形状上与他联合，也要在他复活的形状上与他联合。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 2:20; 以弗所书 4:22; 加拉太书 5:24"> 因为知道，我们的旧人和他同钉十字架，使罪身灭绝，叫我们不再做罪的奴仆，</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前书 4:1; 歌罗西书 3:1–3; 罗马书 7:4"> 因为已死的人是脱离了罪。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太后书 2:11–12; 歌罗西书 3:3–4; 哥林多后书 4:10–14"> 我们若是与基督同死，就信必与他同活。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 6:14; 启示录 1:18; 使徒行传 2:24–28"> 因为知道，基督既从死里复活，就不再死，死也不再做他的主了。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 5:21; 彼得前书 4:6; 彼得前书 3:18"> 他死是向罪死了，只有一次；他活是向神活着。</span>
<span className="v" id="v11" data-v="11" data-xref="歌罗西书 3:3–5; 哥林多前书 6:20; 罗马书 6:2"> 这样，你们向罪也当看自己是死的；向神，在基督耶稣里，却当看自己是活的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="加拉太书 5:16; 罗马书 6:16; 罗马书 8:13"> 所以，不要容罪在你们必死的身上做王，使你们顺从身子的私欲。</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 12:1; 罗马书 6:16; 歌罗西书 3:5"> 也不要将你们的肢体献给罪做不义的器具，倒要像从死里复活的人，将自己献给神，并将肢体做义的器具献给神。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 5:18; 罗马书 8:2; 罗马书 7:4–11"> 罪必不能做你们的主，因你们不在律法之下，乃在恩典之下。</span>
</div>
</div>

## 罪与恩的结局

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="提多书 2:11–14; 以弗所书 2:8–10; 罗马书 6:1–2"> 这却怎么样呢？我们在恩典之下，不在律法之下，就可以犯罪吗？断乎不可！</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 8:34; 马太福音 6:24; 约书亚记 24:15"> 岂不晓得你们献上自己做奴仆，顺从谁，就做谁的奴仆吗？或做罪的奴仆，以至于死；或做顺命的奴仆，以致成义。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前书 2:9; 提摩太后书 1:13; 罗马书 1:8"> 感谢神！因为你们从前虽然做罪的奴仆，现今却从心里顺服了所传给你们道理的模范。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 6:22; 罗马书 8:2; 加拉太书 5:1"> 你们既从罪里得了释放，就做了义的奴仆。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 6:13; 彼得前书 4:2–4; 歌罗西书 3:5–7"> 我因你们肉体的软弱，就照人的常话对你们说：你们从前怎样将肢体献给不洁、不法做奴仆，以至于不法；现今也要照样将肢体献给义做奴仆，以至于成圣。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 6:16–17; 约翰福音 8:34"> 因为你们做罪之奴仆的时候，就不被义约束了。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 1:32; 罗马书 7:5; 罗马书 6:23"> 你们现今所看为羞耻的事，当日有什么果子呢？那些事的结局就是死。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:16; 罗马书 6:18; 罗马书 8:2"> 但现今，你们既从罪里得了释放，做了神的奴仆，就有成圣的果子，那结局就是永生。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 3:36; 罗马书 5:12; 雅各书 1:15"> 因为罪的工价乃是死，唯有神的恩赐，在我们的主基督耶稣里乃是永生。</span>
</div>
</div>

## 亚古珥之箴言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 31:1; 彼得后书 1:19–21"> 雅基的儿子亚古珥的言语，就是真言。<br />这人对以铁和乌甲说：</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 73:22; 哥林多前书 3:18; 以赛亚书 6:5"> <span className="pl pl-1">我比众人更蠢笨，</span><br /><span className="pl pl-1">也没有人的聪明。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="启示录 3:7; 以弗所书 3:18–19; 罗马书 11:33"> <span className="pl pl-1">我没有学好智慧，</span><br /><span className="pl pl-1">也不认识至圣者。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 3:13; 以弗所书 4:8–10; 约伯记 26:8"> <span className="pl pl-1">谁升天又降下来？</span><br /><span className="pl pl-1">谁聚风在掌握中？</span><br /><span className="pl pl-1">谁包水在衣服里？</span><br /><span className="pl pl-1">谁立定地的四极？</span><br /><span className="pl pl-1">他名叫什么？</span><br /><span className="pl pl-1">他儿子名叫什么？</span><br /><span className="pl pl-1">你知道吗？</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="诗篇 18:30; 雅各书 3:17; 诗篇 12:6"> <span className="pl pl-1">神的言语句句都是炼净的，</span><br /><span className="pl pl-1">投靠他的，他便做他们的盾牌。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="申命记 12:32; 申命记 4:2; 启示录 22:18–19"> <span className="pl pl-1">他的言语你不可加添，</span><br /><span className="pl pl-1">恐怕他责备你，你就显为说谎言的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="路加福音 10:42; 列王纪下 2:9; 诗篇 27:4"> <span className="pl pl-1">我求你两件事，</span><br /><span className="pl pl-1">在我未死之先不要不赐给我：</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="提摩太前书 6:6–8; 诗篇 62:9–10; 诗篇 119:37"> <span className="pl pl-1">求你使虚假和谎言远离我；</span><br /><span className="pl pl-1">使我也不贫穷也不富足，</span><br /><span className="pl pl-1">赐给我需用的饮食。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="何西阿书 13:6; 申命记 31:20; 以西结书 16:49–50"> <span className="pl pl-1">恐怕我饱足不认你，说：</span><br /><span className="pl pl-1">“耶和华是谁呢？”</span><br /><span className="pl pl-1">又恐怕我贫穷就偷窃，</span><br /><span className="pl pl-1">以致亵渎我神的名。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="罗马书 14:4; 传道书 7:21; 申命记 23:15"> <span className="pl pl-1">你不要向主人谗谤仆人，</span><br /><span className="pl pl-1">恐怕他咒诅你，你便算为有罪。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="箴言 20:20; 箴言 30:17; 出埃及记 21:17"> <span className="pl pl-1">有一宗</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“宗”原文作“代”，下同。">a</a></sup><br /><span className="pl pl-1">人，咒诅父亲，</span><br /><span className="pl pl-1">不给母亲祝福。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 18:11; 箴言 16:2; 提摩太后书 3:5"> <span className="pl pl-1">有一宗人，自以为清洁，</span><br /><span className="pl pl-1">却没有洗去自己的污秽。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 6:17; 以赛亚书 2:11; 诗篇 101:5"> <span className="pl pl-1">有一宗人，眼目何其高傲，</span><br /><span className="pl pl-1">眼皮也是高举。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 57:4; 诗篇 3:7; 诗篇 14:4"> <span className="pl pl-1">有一宗人，牙如剑，齿如刀，</span><br /><span className="pl pl-1">要吞灭地上的困苦人和世间的穷乏人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="箴言 30:21; 箴言 30:29; 箴言 6:16"> <span className="pl pl-1">蚂蟥有两个女儿，</span><br /><span className="pl pl-1">常说：“给呀！给呀！”</span><br /><span className="pl pl-1">有三样不知足的，</span><br /><span className="pl pl-1">连不说够的共有四样，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 27:20; 哈巴谷书 2:5; 创世记 30:1"> <span className="pl pl-1">就是阴间和石胎，</span><br /><span className="pl pl-1">浸水不足的地，并火。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="箴言 23:22; 申命记 21:18–21; 箴言 30:11"> <span className="pl pl-1">戏笑父亲，藐视而不听从母亲的，</span><br /><span className="pl pl-1">他的眼睛必为谷中的乌鸦啄出来，为鹰雏所吃。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="约伯记 42:3; 诗篇 139:6"> <span className="pl pl-1">我所测不透的奇妙有三样，</span><br /><span className="pl pl-1">连我所不知道的共有四样，</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 40:31; 约伯记 39:27; 出埃及记 22:16"> <span className="pl pl-1">就是鹰在空中飞的道，</span><br /><span className="pl pl-1">蛇在磐石上爬的道，</span><br /><span className="pl pl-1">船在海中行的道，</span><br /><span className="pl pl-1">男与女交合的道。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="箴言 5:6; 箴言 7:13–23; 民数记 5:11–30"> <span className="pl pl-1">淫妇的道也是这样，</span><br /><span className="pl pl-1">她吃了把嘴一擦，就说：</span><br /><span className="pl pl-1">“我没有行恶。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21"> <span className="pl pl-1">使地震动的有三样，</span><br /><span className="pl pl-1">连地担不起的共有四样，</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 19:10; 传道书 10:7; 撒母耳记上 25:10–11"> <span className="pl pl-1">就是仆人做王，</span><br /><span className="pl pl-1">愚顽人吃饱，</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 21:19; 箴言 27:15; 箴言 29:21"> <span className="pl pl-1">丑恶的女子出嫁，</span><br /><span className="pl pl-1">婢女接续主母。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="约伯记 12:7"> <span className="pl pl-1">地上有四样小物，却甚聪明：</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 6:6–8"> <span className="pl pl-1">蚂蚁是无力之类，</span><br /><span className="pl pl-1">却在夏天预备粮食；</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 104:18; 利未记 11:5"> <span className="pl pl-1">沙番是软弱之类，</span><br /><span className="pl pl-1">却在磐石中造房；</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="约珥书 2:25; 约珥书 1:6–7; 约珥书 2:7–11"> <span className="pl pl-1">蝗虫没有君王，</span><br /><span className="pl pl-1">却分队而出；</span><br /></span>
<span className="v" id="v28" data-v="28"> <span className="pl pl-1">守宫用爪抓墙，</span><br /><span className="pl pl-1">却住在王宫。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29"> <span className="pl pl-1">步行威武的有三样，</span><br /><span className="pl pl-1">连行走威武的共有四样，</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="民数记 23:24; 士师记 14:18"> <span className="pl pl-1">就是狮子，乃百兽中最为猛烈、无所躲避的，</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="但以理书 3:15–18; 箴言 20:2; 箴言 16:14"> <span className="pl pl-1">猎狗、公山羊和无人能敌的君王。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="约伯记 21:5; 约伯记 40:4; 箴言 26:12"> <span className="pl pl-1">你若行事愚顽自高自傲，</span><br /><span className="pl pl-1">或是怀了恶念，就当用手捂口。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="箴言 17:14; 箴言 29:22; 箴言 28:25"> <span className="pl pl-1">摇牛奶必成奶油，</span><br /><span className="pl pl-1">扭鼻子必出血，</span><br /><span className="pl pl-1">照样，激动怒气必起争端。</span></span>
</div>
</div>

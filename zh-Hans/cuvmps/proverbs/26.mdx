## 箴言杂记

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 19:10; 箴言 28:16; 以斯帖记 4:6"> <span className="pl pl-1">夏天落雪，收割时下雨，都不相宜，</span><br /><span className="pl pl-1">愚昧人得尊荣，也是如此。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="民数记 23:8; 尼希米记 13:2; 诗篇 109:28"> <span className="pl pl-1">麻雀往来，燕子翻飞，</span><br /><span className="pl pl-1">这样，无故的咒诅也必不临到。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 10:13; 诗篇 32:9; 哥林多前书 4:21"> <span className="pl pl-1">鞭子是为打马，辔头是为勒驴，</span><br /><span className="pl pl-1">刑杖是为打愚昧人的背。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 26:5; 彼得前书 3:9; 犹大书 1:9"> <span className="pl pl-1">不要照愚昧人的愚妄话回答他，</span><br /><span className="pl pl-1">恐怕你与他一样。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 12:16; 马太福音 16:1–4; 箴言 28:11"> <span className="pl pl-1">要照愚昧人的愚妄话回答他，</span><br /><span className="pl pl-1">免得他自以为有智慧。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 10:26; 箴言 25:13; 箴言 13:17"> <span className="pl pl-1">藉愚昧人手寄信的，</span><br /><span className="pl pl-1">是砍断自己的脚，自受</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“自受”原文作“喝”。">a</a></sup><br /><span className="pl pl-1">损害。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 26:9; 诗篇 64:8; 箴言 17:7"> <span className="pl pl-1">瘸子的脚空存无用，</span><br /><span className="pl pl-1">箴言在愚昧人的口中也是如此。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 26:1; 箴言 30:22; 箴言 19:10"> <span className="pl pl-1">将尊荣给愚昧人的，</span><br /><span className="pl pl-1">好像人把石子包在机弦里。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 23:35"> <span className="pl pl-1">箴言在愚昧人的口中，</span><br /><span className="pl pl-1">好像荆棘刺入醉汉的手。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 2:6; 箴言 11:31"> <span className="pl pl-1">雇愚昧人的与雇过路人的，</span><br /><span className="pl pl-1">就像射伤众人的弓箭手。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="彼得后书 2:22; 马太福音 12:45; 出埃及记 8:15"> <span className="pl pl-1">愚昧人行愚妄事，行了又行，</span><br /><span className="pl pl-1">就如狗转过来吃他所吐的。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 29:20; 哥林多前书 3:18–19; 箴言 26:5"> <span className="pl pl-1">你见自以为有智慧的人吗？</span><br /><span className="pl pl-1">愚昧人比他更有指望。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 22:13; 箴言 19:15; 箴言 15:19"> <span className="pl pl-1">懒惰人说：“道上有猛狮！</span><br /><span className="pl pl-1">街上有壮狮！”</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 6:12; 箴言 12:27; 箴言 12:24"> <span className="pl pl-1">门在枢纽转动，</span><br /><span className="pl pl-1">懒惰人在床上也是如此。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 19:24"> <span className="pl pl-1">懒惰人放手在盘子里，</span><br /><span className="pl pl-1">就是向口撤回，也以为劳乏。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 26:12; 彼得前书 3:15; 箴言 12:15"> <span className="pl pl-1">懒惰人看自己比七个善于应对的人更有智慧。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 20:3; 提摩太后书 2:23–24; 路加福音 12:14"> <span className="pl pl-1">过路被事激动，管理不干己的争竞，</span><br /><span className="pl pl-1">好像人揪住狗耳。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 25:18; 以赛亚书 50:11; 箴言 7:23"> <span className="pl pl-1">人欺凌邻舍，却说：</span><br /><span className="pl pl-1">“我岂不是戏耍吗？”</span><br /><span className="pl pl-1">他就像疯狂的人抛掷火把、利箭</span><br /><span className="pl pl-1">与杀人的兵器</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="-19 “杀人的兵器”原文作“死亡”。">b</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="箴言 22:10; 雅各书 3:6; 箴言 16:28"> <span className="pl pl-1">火缺了柴就必熄灭，</span><br /><span className="pl pl-1">无人传舌，争竞便止息。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 15:18; 箴言 29:22; 撒母耳记下 20:1"> <span className="pl pl-1">好争竞的人煽惑争端，</span><br /><span className="pl pl-1">就如余火加炭，火上加柴一样。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 18:8; 箴言 20:19; 以西结书 22:9"> <span className="pl pl-1">传舌人的言语如同美食，</span><br /><span className="pl pl-1">深入人的心腹。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 22:47–48; 路加福音 11:39; 箴言 10:18"> <span className="pl pl-1">火热的嘴奸恶的心，</span><br /><span className="pl pl-1">好像银渣包的瓦器。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 12:20; 箴言 10:18; 诗篇 41:6"> <span className="pl pl-1">怨恨人的用嘴粉饰，</span><br /><span className="pl pl-1">心里却藏着诡诈。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 6:16–19; 耶利米书 12:6; 诗篇 28:3"> <span className="pl pl-1">他用甜言蜜语，你不可信他，</span><br /><span className="pl pl-1">因为他心中有七样可憎恶的。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 55:21–23; 撒母耳记上 18:17; 撒母耳记上 18:21"> <span className="pl pl-1">他虽用诡诈遮掩自己的怨恨，</span><br /><span className="pl pl-1">他的邪恶必在会中显露。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 28:10; 诗篇 9:15; 诗篇 7:15–16"> <span className="pl pl-1">挖陷坑的，自己必掉在其中；</span><br /><span className="pl pl-1">滚石头的，石头必反滚在他身上。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 8:44–49; 路加福音 20:20–21; 约翰福音 10:32–33"> <span className="pl pl-1">虚谎的舌恨他所压伤的人，</span><br /><span className="pl pl-1">谄媚的口败坏人的事。</span></span>

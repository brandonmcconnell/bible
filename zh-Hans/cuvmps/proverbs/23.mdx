## 劝世箴言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="犹大书 1:12; 创世记 43:32–34"> <span className="pl pl-1">你若与官长坐席，</span><br /><span className="pl pl-1">要留意在你面前的是谁，</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="腓立比书 3:19; 马太福音 18:8–9; 哥林多前书 9:27"> <span className="pl pl-1">你若是贪食的</span><br /><span className="pl pl-1">就当拿刀放在喉咙上。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 23:6; 诗篇 141:4; 以弗所书 4:22"> <span className="pl pl-1">不可贪恋他的美食，</span><br /><span className="pl pl-1">因为是哄人的食物。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 13:5; 箴言 28:20; 马太福音 6:19"> <span className="pl pl-1">不要劳碌求富，</span><br /><span className="pl pl-1">休仗自己的聪明。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 27:24; 约翰一书 2:16; 雅各书 5:1–2"> <span className="pl pl-1">你岂要定睛在虚无的钱财上吗？</span><br /><span className="pl pl-1">因钱财必长翅膀，如鹰向天飞去。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 141:4; 箴言 23:3; 但以理书 1:8–10"> <span className="pl pl-1">不要吃恶眼人的饭，</span><br /><span className="pl pl-1">也不要贪他的美味。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 12:2; 诗篇 55:21; 士师记 16:15"> <span className="pl pl-1">因为他心怎样思量，</span><br /><span className="pl pl-1">他为人就是怎样。</span><br /><span className="pl pl-1">他虽对你说“请吃，请喝”，</span><br /><span className="pl pl-1">他的心却与你相背。</span><br /></span>
<span className="v" id="v8" data-v="8"> <span className="pl pl-1">你所吃的那点食物必吐出来，</span><br /><span className="pl pl-1">你所说的甘美言语也必落空。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 9:7–8; 马太福音 7:6; 箴言 26:4–5"> <span className="pl pl-1">你不要说话给愚昧人听，</span><br /><span className="pl pl-1">因他必藐视你智慧的言语。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 22:28; 撒迦利亚书 7:10; 申命记 27:17"> <span className="pl pl-1">不可挪移古时的地界，</span><br /><span className="pl pl-1">也不可侵入孤儿的田地。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 22:23; 约伯记 19:25; 耶利米书 51:36"> <span className="pl pl-1">因他们的救赎主大有能力，</span><br /><span className="pl pl-1">他必向你为他们辨屈。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 5:1–2; 箴言 2:2–6; 箴言 23:19"> <span className="pl pl-1">你要留心领受训诲，</span><br /><span className="pl pl-1">侧耳听从知识的言语。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 13:24; 箴言 19:18; 箴言 29:15"> <span className="pl pl-1">不可不管教孩童，</span><br /><span className="pl pl-1">你用杖打他，他必不至于死。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 5:5; 箴言 22:15; 哥林多前书 11:32"> <span className="pl pl-1">你要用杖打他，</span><br /><span className="pl pl-1">就可以救他的灵魂免下阴间。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 23:24–25; 约翰二书 1:4; 箴言 29:3"> <span className="pl pl-1">我儿，你心若存智慧，</span><br /><span className="pl pl-1">我的心也甚欢喜。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 8:6; 以弗所书 5:4; 雅各书 3:2"> <span className="pl pl-1">你的嘴若说正直话，</span><br /><span className="pl pl-1">我的心肠也必快乐。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 28:14; 哥林多后书 7:1; 彼得前书 1:17"> <span className="pl pl-1">你心中不要嫉妒罪人，</span><br /><span className="pl pl-1">只要终日敬畏耶和华。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 10:35; 耶利米书 29:11; 诗篇 9:18"> <span className="pl pl-1">因为至终必有善报，</span><br /><span className="pl pl-1">你的指望也不致断绝。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 23:26; 箴言 23:12; 箴言 4:10–23"> <span className="pl pl-1">我儿，你当听，当存智慧，</span><br /><span className="pl pl-1">好在正道上引导你的心。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 21:34; 以弗所书 5:18; 以赛亚书 5:22"> <span className="pl pl-1">好饮酒的，好吃肉的，</span><br /><span className="pl pl-1">不要与他们来往。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 21:17; 箴言 19:15; 申命记 21:20"> <span className="pl pl-1">因为好酒贪食的必致贫穷，</span><br /><span className="pl pl-1">好睡觉的必穿破烂衣服。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 30:17; 箴言 1:8; 约翰福音 19:26–27"> <span className="pl pl-1">你要听从生你的父亲，</span><br /><span className="pl pl-1">你母亲老了，也不可藐视她。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 18:15; 马太福音 13:44; 诗篇 119:72"> <span className="pl pl-1">你当买真理，</span><br /><span className="pl pl-1">就是智慧、训诲和聪明也都不可卖。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 10:1; 箴言 15:20; 箴言 23:15–16"> <span className="pl pl-1">义人的父亲必大得快乐，</span><br /><span className="pl pl-1">人生智慧的儿子，必因他欢喜。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 17:25; 路加福音 11:27–28; 路加福音 1:58"> <span className="pl pl-1">你要使父母欢喜，</span><br /><span className="pl pl-1">使生你的快乐。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 119:2; 诗篇 119:9–11; 申命记 6:5"> <span className="pl pl-1">我儿，要将你的心归我，</span><br /><span className="pl pl-1">你的眼目也要喜悦我的道路。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 22:14"> <span className="pl pl-1">妓女是深坑，</span><br /><span className="pl pl-1">外女是窄阱。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="传道书 7:26; 箴言 7:12; 箴言 22:14"> <span className="pl pl-1">她埋伏好像强盗，</span><br /><span className="pl pl-1">她使人中多有奸诈的。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="以弗所书 5:18; 以赛亚书 5:11; 箴言 23:21"> <span className="pl pl-1">谁有祸患？谁有忧愁？</span><br /><span className="pl pl-1">谁有争斗？谁有哀叹</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：怨言。">a</a></sup><br /><span className="pl pl-1">？</span><br /><span className="pl pl-1">谁无故受伤？谁眼目红赤？</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="以弗所书 5:18; 以赛亚书 5:11; 箴言 20:1"> <span className="pl pl-1">就是那流连饮酒，</span><br /><span className="pl pl-1">常去寻找调和酒的人。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="约翰一书 2:16; 撒母耳记下 11:2; 诗篇 119:37"> <span className="pl pl-1">酒发红，在杯中闪烁，</span><br /><span className="pl pl-1">你不可观看，</span><br /><span className="pl pl-1">虽然下咽舒畅，</span><br /><span className="pl pl-1">终久是咬你如蛇，刺你如毒蛇。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="犹大书 1:12–13; 诗篇 69:12; 但以理书 5:4"> <span className="pl pl-1">你眼必看见异怪的事</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“异怪的事”或作“淫妇”。">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">你心必发出乖谬的话。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="帖撒罗尼迦前书 5:2–7; 列王纪上 20:16–22; 撒母耳记上 30:16–17"> <span className="pl pl-1">你必像躺在海中，</span><br /><span className="pl pl-1">或像卧在桅杆上。</span><br /></span>

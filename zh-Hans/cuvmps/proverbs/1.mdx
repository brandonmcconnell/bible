## 箴言之妙用

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 10:1; 历代志上 22:9; 历代志上 28:5"> 以色列王大卫儿子所罗门的箴言。</span>

<span className="v" id="v3" data-v="3" data-xref="箴言 2:1–9; 约伯记 22:22; 箴言 8:10–11"> <span className="pl pl-1">使人处事领受智慧、</span><br /><span className="pl pl-1">仁义、公平、正直的训诲，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 8:5; 箴言 8:17; 诗篇 119:9"> <span className="pl pl-1">使愚人灵明，</span><br /><span className="pl pl-1">使少年人有知识和谋略，</span><br /></span>

</div>

## 勿从恶人之诱

<div className="bt">
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="约伯记 28:28; 诗篇 111:10–1; 传道书 12:13"> <span className="pl pl-1">敬畏耶和华是知识的开端，</span><br /><span className="pl pl-1">愚妄人藐视智慧和训诲。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 6:20; 箴言 30:17; 箴言 5:1–2"> <span className="pl pl-1">我儿，要听你父亲的训诲，</span><br /><span className="pl pl-1">不可离弃你母亲的法则</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：指教。">a</a></sup><br /><span className="pl pl-1">，</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="但以理书 5:29; 箴言 4:9; 创世记 41:42"> <span className="pl pl-1">因为这要做你头上的华冠，</span><br /><span className="pl pl-1">你项上的金链。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 5:11; 箴言 16:29; 诗篇 1:1"> <span className="pl pl-1">我儿，恶人若引诱你，</span><br /><span className="pl pl-1">你不可随从。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 5:26; 箴言 1:18; 箴言 12:6"> <span className="pl pl-1">他们若说：“你与我们同去，</span><br /><span className="pl pl-1">我们要埋伏流人之血，</span><br /><span className="pl pl-1">要蹲伏害无罪之人。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 124:3; 诗篇 28:1; 罗马书 3:13"> <span className="pl pl-1">我们好像阴间，把他们活活吞下；</span><br /><span className="pl pl-1">他们如同下坑的人，</span><br /><span className="pl pl-1">被我们囫囵吞了。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="提摩太前书 6:9–10; 路加福音 12:15; 约伯记 24:2–3"> <span className="pl pl-1">我们必得各样宝物，</span><br /><span className="pl pl-1">将所掳来的装满房屋。</span><br /></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">你与我们大家同分，</span><br /><span className="pl pl-1">我们共用一个囊袋”，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 119:101; 诗篇 1:1; 箴言 4:14–15"> <span className="pl pl-1">我儿，不要与他们同行一道，</span><br /><span className="pl pl-1">禁止你脚走他们的路。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 59:7; 箴言 6:18; 箴言 4:16"> <span className="pl pl-1">因为他们的脚奔跑行恶，</span><br /><span className="pl pl-1">他们急速流人的血。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="约伯记 35:11; 箴言 7:23; 耶利米书 8:7"> <span className="pl pl-1">好像飞鸟，</span><br /><span className="pl pl-1">网罗设在眼前仍不躲避，</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 9:16; 以斯帖记 7:10; 箴言 5:22–23"> <span className="pl pl-1">这些人埋伏是为自流己血，</span><br /><span className="pl pl-1">蹲伏是为自害己命。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 15:27; 彼得后书 2:3; 雅各书 5:1–4"> <span className="pl pl-1">凡贪恋财利的，所行之路都是如此，</span><br /><span className="pl pl-1">这贪恋之心乃夺去得财者之命。</span></span>
</div>
</div>

## 愚者厌恶知识

<div className="bt">
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="箴言 9:3; 歌罗西书 2:3; 路加福音 11:49"> <span className="pl pl-1">智慧在街市上呼喊，</span><br /><span className="pl pl-1">在宽阔处发声，</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 5:20; 箴言 9:3; 马太福音 13:2"> <span className="pl pl-1">在热闹街头喊叫，</span><br /><span className="pl pl-1">在城门口、在城中发出言语，</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 1:29; 诗篇 1:1; 箴言 5:12"> <span className="pl pl-1">说：“你们愚昧人喜爱愚昧，</span><br /><span className="pl pl-1">亵慢人喜欢亵慢，</span><br /><span className="pl pl-1">愚顽人恨恶知识，要到几时呢？</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 3:19; 以西结书 33:11; 以西结书 18:27–30"> <span className="pl pl-1">你们当因我的责备回转，</span><br /><span className="pl pl-1">我要将我的灵浇灌你们，</span><br /><span className="pl pl-1">将我的话指示你们。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 65:12; 罗马书 10:21; 耶利米书 7:13"> <span className="pl pl-1">我呼唤，你们不肯听从，</span><br /><span className="pl pl-1">我伸手，无人理会，</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 81:11; 路加福音 7:30; 箴言 1:30"> <span className="pl pl-1">反轻弃我一切的劝诫，</span><br /><span className="pl pl-1">不肯受我的责备。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 2:4; 箴言 10:24; 诗篇 37:13"> <span className="pl pl-1">你们遭灾难，我就发笑；</span><br /><span className="pl pl-1">惊恐临到你们，我必嗤笑。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 3:25–26; 路加福音 21:34–35; 诗篇 58:9"> <span className="pl pl-1">惊恐临到你们好像狂风，</span><br /><span className="pl pl-1">灾难来到如同暴风，</span><br /><span className="pl pl-1">急难痛苦临到你们身上。</span><br /></span>

<span className="v" id="v29" data-v="29" data-xref="箴言 1:22; 约伯记 21:14–15; 箴言 6:23"> <span className="pl pl-1">因为你们恨恶知识，</span><br /><span className="pl pl-1">不喜爱敬畏耶和华，</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 81:11; 箴言 1:25; 路加福音 14:18–20"> <span className="pl pl-1">不听我的劝诫，</span><br /><span className="pl pl-1">藐视我一切的责备，</span><br /></span>

</div>
</div>

## 善恶互论垂为箴言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 19:21; 箴言 16:9; 路加福音 21:14–15"> <span className="pl pl-1">心中的谋算在乎人，</span><br /><span className="pl pl-1">舌头的应对由于耶和华。</span><br /></span>

<span className="v" id="v3" data-v="3" data-xref="诗篇 37:4–5; 箴言 3:6; 诗篇 55:22"> <span className="pl pl-1">你所做的要交托耶和华，</span><br /><span className="pl pl-1">你所谋的就必成立。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="彼得后书 2:9; 罗马书 9:22; 以赛亚书 43:21"> <span className="pl pl-1">耶和华所造的各适其用，</span><br /><span className="pl pl-1">就是恶人也为祸患的日子所造。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 6:16–17; 箴言 11:21; 箴言 8:13"> <span className="pl pl-1">凡心里骄傲的，为耶和华所憎恶，</span><br /><span className="pl pl-1">虽然连手，他必不免受罚。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 14:16; 约伯记 28:28; 哥林多后书 7:1"> <span className="pl pl-1">因怜悯、诚实，罪孽得赎；</span><br /><span className="pl pl-1">敬畏耶和华的，远离恶事。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:31; 约翰一书 3:22; 歌罗西书 1:10"> <span className="pl pl-1">人所行的若蒙耶和华喜悦，</span><br /><span className="pl pl-1">耶和华也使他的仇敌与他和好。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 15:16; 诗篇 37:16; 提摩太前书 6:6–9"> <span className="pl pl-1">多有财利行事不义，</span><br /><span className="pl pl-1">不如少有财利行事公义。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 19:21; 诗篇 37:23; 箴言 16:1"> <span className="pl pl-1">人心筹算自己的道路，</span><br /><span className="pl pl-1">唯耶和华指引他的脚步。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 32:1–2; 创世记 44:5; 创世记 44:15"> <span className="pl pl-1">王的嘴中有神语，</span><br /><span className="pl pl-1">审判之时，他的口必不差错。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 11:1; 箴言 20:10; 箴言 20:23"> <span className="pl pl-1">公道的天平和秤都属耶和华，</span><br /><span className="pl pl-1">囊中一切法码都为他所定。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 25:5; 箴言 29:14; 路加福音 12:48"> <span className="pl pl-1">作恶为王所憎恶，</span><br /><span className="pl pl-1">因国位是靠公义坚立。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 14:35; 诗篇 101:5–7; 箴言 22:11"> <span className="pl pl-1">公义的嘴为王所喜悦，</span><br /><span className="pl pl-1">说正直话的为王所喜爱。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 20:2; 箴言 19:12; 传道书 10:4"> <span className="pl pl-1">王的震怒如杀人的使者，</span><br /><span className="pl pl-1">但智慧人能止息王怒。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 72:6; 约伯记 29:23–24; 何西阿书 6:3"> <span className="pl pl-1">王的脸光使人有生命，</span><br /><span className="pl pl-1">王的恩典好像春云时雨。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 8:10–11; 马太福音 16:26; 箴言 8:19"> <span className="pl pl-1">得智慧胜似得金子，</span><br /><span className="pl pl-1">选聪明强如选银子。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 35:8; 箴言 19:16; 箴言 10:9"> <span className="pl pl-1">正直人的道是远离恶事，</span><br /><span className="pl pl-1">谨守己路的是保全性命。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 11:2; 以赛亚书 2:11–12; 箴言 18:12"> <span className="pl pl-1">骄傲在败坏以先，</span><br /><span className="pl pl-1">狂心在跌倒之前。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 5:3; 以赛亚书 57:15; 诗篇 138:6"> <span className="pl pl-1">心里谦卑与穷乏人来往，</span><br /><span className="pl pl-1">强如将掳物与骄傲人同分。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 17:7–8; 诗篇 2:12; 以赛亚书 30:18"> <span className="pl pl-1">谨守训言的必得好处，</span><br /><span className="pl pl-1">倚靠耶和华的便为有福。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 16:23–24; 以赛亚书 50:4; 箴言 15:7"> <span className="pl pl-1">心中有智慧必称为通达人，</span><br /><span className="pl pl-1">嘴中的甜言加增人的学问。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 13:14; 约翰福音 6:63; 约翰福音 5:24"> <span className="pl pl-1">人有智慧就有生命的泉源，</span><br /><span className="pl pl-1">愚昧人必被愚昧惩治。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 15:28; 马太福音 12:34–35; 歌罗西书 3:16"> <span className="pl pl-1">智慧人的心教训他的口，</span><br /><span className="pl pl-1">又使他的嘴增长学问。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 12:18; 箴言 24:13–14; 箴言 25:11–12"> <span className="pl pl-1">良言如同蜂房，</span><br /><span className="pl pl-1">使心觉甘甜，使骨得医治。</span><br /></span>

<span className="v" id="v28" data-v="28" data-xref="箴言 17:9; 箴言 18:8; 箴言 15:18"> <span className="pl pl-1">乖僻人播散纷争，</span><br /><span className="pl pl-1">传舌的离间密友。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 2:12–15; 箴言 12:26; 箴言 1:10–14"> <span className="pl pl-1">强暴人诱惑邻舍，</span><br /><span className="pl pl-1">领他走不善之道。</span><br /></span>

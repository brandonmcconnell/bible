<span className="v" id="v8" data-v="8" data-xref="箴言 11:11; 耶利米书 15:1; 雅各书 5:15–18"> <span className="pl pl-1">亵慢人煽惑通城，</span><br /><span className="pl pl-1">智慧人止息众怒。</span><br /></span>

<span className="v" id="v12" data-v="12" data-xref="箴言 20:8; 列王纪下 10:6–7; 诗篇 52:2–4"> <span className="pl pl-1">君王若听谎言，</span><br /><span className="pl pl-1">他一切臣仆都是奸恶。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 5:45; 箴言 22:2; 诗篇 13:3"> <span className="pl pl-1">贫穷人强暴人在世相遇，</span><br /><span className="pl pl-1">他们的眼目都蒙耶和华光照。</span><br /></span>

<span className="v" id="v17" data-v="17" data-xref="箴言 10:1; 箴言 29:15; 箴言 23:13–14"> <span className="pl pl-1">管教你的儿子，他就使你得安息，</span><br /><span className="pl pl-1">也必使你心里喜乐。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="雅各书 1:25; 路加福音 11:28; 约翰福音 13:17"> <span className="pl pl-1">没有异象</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：默示。">a</a></sup><br /><span className="pl pl-1">，民就放肆；</span><br /><span className="pl pl-1">唯遵守律法的，便为有福。</span><br /></span>

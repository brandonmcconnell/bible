<div className="bp poetry">

<span className="v" id="v3" data-v="3" data-xref="启示录 16:9–11; 诗篇 37:7; 民数记 16:19–41"> <span className="pl pl-1">人的愚昧倾败他的道，</span><br /><span className="pl pl-1">他的心也抱怨耶和华。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 14:20; 箴言 19:6–7; 路加福音 15:13–15"> <span className="pl pl-1">财物使朋友增多，</span><br /><span className="pl pl-1">但穷人，朋友远离。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 21:28; 箴言 19:9; 箴言 6:19"> <span className="pl pl-1">作假见证的必不免受罚，</span><br /><span className="pl pl-1">吐出谎言的终不能逃脱。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 29:26; 箴言 18:16; 箴言 17:8"> <span className="pl pl-1">好施散的，有多人求他的恩情；</span><br /><span className="pl pl-1">爱送礼的，人都为他的朋友。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 19:4; 约翰一书 3:17–18; 雅各书 2:15–16"> <span className="pl pl-1">贫穷人，弟兄都恨他，</span><br /><span className="pl pl-1">何况他的朋友，更远离他。</span><br /><span className="pl pl-1">他用言语追随，他们却走了。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 16:20; 箴言 8:35–36; 箴言 3:18"> <span className="pl pl-1">得着智慧的爱惜生命，</span><br /><span className="pl pl-1">保守聪明的必得好处。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="启示录 22:15; 箴言 19:5; 启示录 19:20"> <span className="pl pl-1">作假见证的不免受罚，</span><br /><span className="pl pl-1">吐出谎言的也必灭亡。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 30:21–22; 箴言 26:1; 路加福音 16:19"> <span className="pl pl-1">愚昧人宴乐度日是不合宜的，</span><br /><span className="pl pl-1">何况仆人管辖王子呢？</span><br /></span>

<span className="v" id="v15" data-v="15" data-xref="箴言 23:21; 箴言 20:13; 帖撒罗尼迦后书 3:10"> <span className="pl pl-1">懒惰使人沉睡，</span><br /><span className="pl pl-1">懈怠的人必受饥饿。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 10:28; 箴言 13:13; 路加福音 11:28"> <span className="pl pl-1">谨守诫命的保全生命，</span><br /><span className="pl pl-1">轻忽己路的必致死亡。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 28:27; 希伯来书 6:10; 路加福音 6:38"> <span className="pl pl-1">怜悯贫穷的就是借给耶和华，</span><br /><span className="pl pl-1">他的善行耶和华必偿还。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 13:24; 箴言 29:15; 箴言 22:15"> <span className="pl pl-1">趁有指望管教你的儿子，</span><br /><span className="pl pl-1">你的心不可任他死亡。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 25:28; 撒母耳记下 16:5–6; 撒母耳记上 24:17–22"> <span className="pl pl-1">暴怒的人必受刑罚，</span><br /><span className="pl pl-1">你若救他，必须再救。</span><br /></span>

## 便雅悯之后裔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 46:21; 历代志上 7:6–12; 民数记 26:38"> 便雅悯的长子比拉，次子亚实别，三子亚哈拉，</span>
<span className="v" id="v2" data-v="2"> 四子挪哈，五子拉法。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 46:21; 民数记 26:40"> 比拉的儿子是亚大、基拉、亚比忽、</span>
<span className="v" id="v4" data-v="4"> 亚比书、乃幔、亚何亚、</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 7:12; 民数记 26:39; 士师记 3:15"> 基拉、示孚汛、户兰。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 2:54; 士师记 3:20–30; 历代志上 7:10"> 以忽的儿子做迦巴居民的族长，被掳到玛拿辖，</span>
<span className="v" id="v7" data-v="7"> 以忽的儿子乃幔、亚希亚、基拉也被掳去。基拉生乌撒、亚希忽。</span>
<span className="v" id="v8" data-v="8" data-xref="路得记 1:1; 创世记 25:6"> 沙哈连休他二妻户伸和巴拉之后，在摩押地生了儿子。</span>
<span className="v" id="v9" data-v="9"> 他与妻贺得同房，生了约巴、洗比雅、米沙、玛拉干、</span>
<span className="v" id="v10" data-v="10"> 耶乌斯、沙迦、米玛，他这些儿子都是族长。</span>
<span className="v" id="v11" data-v="11"> 他的妻户伸给他生的儿子有亚比突、以利巴力。</span>
<span className="v" id="v12" data-v="12" data-xref="以斯拉记 2:33; 尼希米记 7:37; 尼希米记 6:2"> 以利巴力的儿子是希伯、米珊、沙麦，沙麦建立阿挪和罗德二城与其村庄。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 2:52; 约书亚记 19:42; 历代志上 4:4"> 又有比利亚和示玛，是亚雅仑居民的族长，是驱逐迦特人的。</span>
<span className="v" id="v14" data-v="14"> 亚希约、沙煞、耶利末、</span>
<span className="v" id="v15" data-v="15"> 西巴第雅、亚拉得、亚得、</span>
<span className="v" id="v16" data-v="16"> 米迦勒、伊施巴、约哈，都是比利亚的儿子。</span>
<span className="v" id="v17" data-v="17"> 西巴第雅、米书兰、希西基、希伯、</span>
<span className="v" id="v18" data-v="18"> 伊施米莱、伊斯利亚、约巴，都是以利巴力的儿子。</span>
<span className="v" id="v19" data-v="19"> 雅金、细基利、撒底、</span>
<span className="v" id="v20" data-v="20"> 以利乃、洗勒太、以列、</span>
<span className="v" id="v21" data-v="21"> 亚大雅、比拉雅、申拉，都是示每的儿子。</span>
<span className="v" id="v22" data-v="22"> 伊施班、希伯、以列、</span>
<span className="v" id="v23" data-v="23"> 亚伯顿、细基利、哈难、</span>
<span className="v" id="v24" data-v="24"> 哈拿尼雅、以拦、安陀提雅、</span>
<span className="v" id="v25" data-v="25"> 伊弗底雅、毗努伊勒，都是沙煞的儿子。</span>
<span className="v" id="v26" data-v="26"> 珊示莱、示哈利、亚他利雅、</span>
<span className="v" id="v27" data-v="27"> 雅利西、以利亚、细基利，都是耶罗罕的儿子。</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 1:21; 约书亚记 15:63; 尼希米记 11:1"> 这些人都是著名的族长，住在耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="历代志上 9:35–38"> 在基遍住的有基遍的父亲耶利，他的妻名叫玛迦。</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 9:36–37"> 他长子是亚伯顿，他又生苏珥、基士、巴力、拿答、</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 9:37"> 基多、亚希约、撒迦、米基罗。</span>
<span className="v" id="v32" data-v="32" data-xref="历代志上 9:38"> 米基罗生示米暗。这些人和他们的弟兄在耶路撒冷对面居住。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记上 9:1; 撒母耳记下 2:8; 撒母耳记上 31:2"> 尼珥生基士，基士生扫罗，扫罗生约拿单、麦基舒亚、亚比拿达、伊施巴力。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记下 4:4; 撒母耳记下 9:12; 撒母耳记下 9:10"> 约拿单的儿子是米力巴力<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“米力巴力”《撒母耳记下》4章4节作“米非波设”。">a</a></sup>，米力巴力生米迦。</span>
<span className="v" id="v35" data-v="35" data-xref="历代志上 9:41"> 米迦的儿子是毗敦、米勒、他利亚、亚哈斯。</span>
<span className="v" id="v36" data-v="36" data-xref="历代志上 9:42"> 亚哈斯生耶何阿达，耶何阿达生亚拉篾、亚斯玛威、心利，心利生摩撒，</span>
<span className="v" id="v37" data-v="37" data-xref="历代志上 9:43"> 摩撒生比尼亚。比尼亚的儿子是拉法，拉法的儿子是以利亚萨，以利亚萨的儿子是亚悉。</span>
<span className="v" id="v38" data-v="38"> 亚悉有六个儿子，他们的名字是亚斯利干、波基路、以实玛利、示亚利雅、俄巴底雅、哈难，这都是亚悉的儿子。</span>
<span className="v" id="v39" data-v="39"> 亚悉兄弟以设的长子是乌兰，次子耶乌施，三子是以利法列。</span>
<span className="v" id="v40" data-v="40" data-xref="诗篇 128:3–6; 历代志下 14:8; 历代志上 12:2"> 乌兰的儿子都是大能的勇士，是弓箭手，他们有许多的子孙，共一百五十名，都是便雅悯人。</span>
</div>

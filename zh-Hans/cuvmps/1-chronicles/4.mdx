## 复记犹大之后裔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 46:12; 创世记 38:29; 民数记 26:20–21"> 犹大的儿子是法勒斯、希斯仑、迦米、户珥、朔巴。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 13:25; 历代志上 2:52–54; 约书亚记 15:33"> 朔巴的儿子利亚雅生雅哈，雅哈生亚户买和拉哈，这是琐拉人的诸族。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 15:11; 历代志下 11:6"> 以坦之祖的儿子是耶斯列、伊施玛、伊得巴，他们的妹子名叫哈悉勒玻尼；</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 4:18; 历代志上 2:50; 历代志上 4:39"> 基多之祖是毗努伊勒；户沙之祖是以谢珥。这都是伯利恒之祖以法她的长子户珥所生的。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 2:24"> 提哥亚之祖亚施户有两个妻子，一名希拉，一名拿拉。</span>
<span className="v" id="v6" data-v="6"> 拿拉给亚施户生亚户撒、希弗、提米尼、哈辖斯他利，这都是拿拉的儿子。</span>
<span className="v" id="v7" data-v="7"> 希拉的儿子是洗列、琐辖、伊提南。</span>
<span className="v" id="v8" data-v="8"> 哥斯生亚诺、琐比巴并哈仑儿子亚哈黑的诸族。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 4:21; 历代志上 7:23; 创世记 35:18"> 雅比斯比他众弟兄更尊贵，他母亲给他起名叫雅比斯，意思说：“我生他甚是痛苦。”</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 7:7–11; 诗篇 116:1–4; 箴言 10:22"> 雅比斯求告以色列的神说：“甚愿你赐福于我，扩张我的境界，常与我同在，保佑我不遭患难，不受艰苦。”神就应允他所求的。</span>
<span className="v" id="v11" data-v="11"> 书哈的弟兄基绿生米黑，米黑是伊施屯之祖。</span>
<span className="v" id="v12" data-v="12"> 伊施屯生伯拉巴、巴西亚并珥拿辖之祖提欣拿，这都是利迦人。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 15:17; 士师记 1:13; 士师记 3:9–11"> 基纳斯的儿子是俄陀聂、西莱雅。俄陀聂的儿子是哈塔；</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 11:35; 列王纪下 24:14"> 悯挪太生俄弗拉。西莱雅生革夏纳欣人之祖约押，他们都是匠人。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 13:6; 民数记 14:6–10; 约书亚记 15:13–20"> 耶孚尼的儿子是迦勒，迦勒的儿子是以路、以拉、拿安，以拉的儿子是基纳斯。</span>
<span className="v" id="v16" data-v="16"> 耶哈利勒的儿子是西弗、西法、提利、亚撒列。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 4:19; 历代志上 6:57; 约书亚记 15:50"> 以斯拉的儿子是益帖、米列、以弗、雅伦。米列娶法老女儿比提雅为妻，生米利暗、沙买和以实提摩之祖益巴。米列又娶犹大女子为妻，生基多之祖雅列、梭哥之祖希伯和撒挪亚之祖耶古铁。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 15:44; 撒母耳记上 23:1–13"> 荷第雅的妻是拿含的妹子，她所生的儿子是迦米人基伊拉和玛迦人以实提摩之祖。</span>
<span className="v" id="v20" data-v="20"> 示门的儿子是暗嫩、林拿、便哈南、提伦。以示的儿子是梭黑与便梭黑。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 38:5; 历代志上 2:3; 民数记 26:20"> 犹大的儿子是示拉，示拉的儿子是利迦之祖珥、玛利沙之祖拉大和属亚实比族织细麻布的各家，</span>
<span className="v" id="v22" data-v="22"> 还有约敬、哥西巴人、约阿施、萨拉，就是在摩押地掌权的，又有雅叔比利恒，这都是古时所记载的。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 81:6; 历代志上 4:14"> 这些人都是窑匠，是尼他应和基低拉的居民，与王同处，为王做工。</span>
</div>
</div>

## 西缅之后裔

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="创世记 46:10; 出埃及记 6:15; 民数记 26:12–14"> 西缅的儿子是尼母利、雅悯、雅立、谢拉、扫罗。</span>
<span className="v" id="v25" data-v="25"> 扫罗的儿子是沙龙，沙龙的儿子是米比衫，米比衫的儿子是米施玛，</span>
<span className="v" id="v26" data-v="26"> 米施玛的儿子是哈母利，哈母利的儿子是撒刻，撒刻的儿子是示每。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 26:14; 民数记 26:22; 民数记 2:13"> 示每有十六个儿子、六个女儿，他弟兄的儿女不多，他们各家不如犹大族的人丁增多。</span>
<span className="v" id="v28" data-v="28" data-xref="约书亚记 19:2–3; 约书亚记 15:28–29; 约书亚记 19:9"> 西缅人住在别是巴、摩拉大、哈萨书亚、</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 19:3–4"> 辟拉、以森、陀腊、</span>
<span className="v" id="v30" data-v="30" data-xref="尼希米记 11:28; 约书亚记 19:4–5; 撒母耳记上 30:1"> 彼土利、何珥玛、洗革拉、</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 19:5–6"> 伯玛加博、哈萨苏撒、伯比利、沙拉音，这些城邑直到大卫做王的时候都是属西缅人的。</span>
<span className="v" id="v32" data-v="32" data-xref="约书亚记 19:7"> 他们的五个城邑是以坦、亚因、临门、陀健、亚珊，</span>
<span className="v" id="v33" data-v="33" data-xref="约书亚记 19:8"> 还有属城的乡村，直到巴力。这是他们的住处，他们都有家谱。</span>
<span className="v" id="v34" data-v="34"> 还有米所巴、雅米勒、亚玛谢的儿子约沙、</span>
<span className="v" id="v35" data-v="35"> 约珥、约示比的儿子耶户，约示比是西莱雅的儿子，西莱雅是亚薛的儿子。</span>
<span className="v" id="v36" data-v="36"> 还有以利约乃、雅哥巴、约朔海、亚帅雅、亚底业、耶西篾、比拿雅、</span>
<span className="v" id="v37" data-v="37"> 示非的儿子细撒，示非是亚龙的儿子，亚龙是耶大雅的儿子，耶大雅是申利的儿子，申利是示玛雅的儿子。</span>
<span className="v" id="v38" data-v="38" data-xref="历代志上 5:24; 创世记 6:4"> 以上所记的人名都是做族长的，他们宗族的人数增多。</span>
<span className="v" id="v39" data-v="39" data-xref="历代志上 4:4; 历代志上 4:18; 约书亚记 15:58"> 他们往平原东边基多口去，寻找牧放羊群的草场，</span>
<span className="v" id="v40" data-v="40" data-xref="士师记 18:7–10; 诗篇 105:23; 诗篇 78:51"> 寻得肥美的草场，地又宽阔又平静，从前住那里的是含族的人。</span>
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 14:28–32; 列王纪下 18:8–12; 历代志上 4:34–38"> 以上录名的人在犹大王希西家年间，来攻击含族人的帐篷和那里所有的米乌尼人，将他们灭尽，就住在他们的地方，直到今日，因为那里有草场可以牧放羊群。</span>
<span className="v" id="v42" data-v="42" data-xref="创世记 36:8–9; 申命记 1:2"> 这西缅人中有五百人上西珥山（率领他们的是以示的儿子毗拉提、尼利雅、利法雅和乌薛），</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳记上 30:17; 撒母耳记上 15:7–8; 撒母耳记下 8:12"> 杀了逃脱剩下的亚玛力人，就住在那里，直到今日。</span>
</div>

## 大卫王备金银铜铁木石建殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 22:5; 列王纪上 3:7; 历代志下 13:7"> 大卫王对会众说：“我儿子所罗门是神特选的，还年幼娇嫩。这工程甚大，因这殿不是为人，乃是为耶和华神建造的。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 22:3–5; 哥林多后书 8:3; 以赛亚书 54:11–12"> 我为我神的殿已经尽力预备金子做金器，银子做银器，铜做铜器，铁做铁器，木做木器，还有红玛瑙、可镶嵌的宝石、彩石和一切的宝石，并许多汉白玉。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 21:24; 诗篇 27:4; 诗篇 26:8"> 且因我心中爱慕我神的殿，就在预备建造圣殿的材料之外，又将我自己积蓄的金银献上，建造我神的殿，</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 9:28; 历代志上 22:14; 约伯记 28:16"> 就是俄斐金三千他连得，精炼的银子七千他连得，以贴殿墙，</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 7:2–3; 出埃及记 35:5–9; 以斯拉记 7:15–16"> 金子做金器，银子做银器，并藉匠人的手制造一切。今日有谁乐意将自己献给耶和华呢？”</span>
</div>
</div>

## 会众尽心乐输

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 9:7; 历代志上 27:25–1; 以赛亚书 60:3–10"> 于是，众族长和以色列各支派的首领、千夫长、百夫长，并监管王工的官长，都乐意献上。</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米记 7:70–71; 以斯拉记 2:69"> 他们为神殿的使用，献上金子五千他连得零一万达利克，银子一万他连得，铜一万八千他连得，铁十万他连得。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志上 23:8; 历代志上 26:21–22"> 凡有宝石的都交给革顺人耶歇，送入耶和华殿的府库。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 9:7–8; 哥林多后书 8:3; 列王纪上 8:61"> 因这些人诚心乐意献给耶和华，百姓就欢喜，大卫王也大大欢喜。</span>
</div>
</div>

## 大卫称颂耶和华

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以弗所书 1:3; 彼得前书 1:3; 罗马书 1:7"> 所以，大卫在会众面前称颂耶和华说：“耶和华，我们的父以色列的神，是应当称颂直到永永远远的！</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 1:3; 但以理书 4:34–35; 提摩太前书 1:17"> 耶和华啊，尊大、能力、荣耀、强盛、威严都是你的，凡天上地下的都是你的，国度也是你的，并且你为至高，为万有之首。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 3:16; 历代志下 20:6; 申命记 8:18"> 丰富、尊荣都从你而来，你也治理万物。在你手里有大能大力，使人尊大、强盛都出于你。</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 106:1; 哥林多后书 9:15; 哥林多后书 8:16"> 我们的神啊，现在我们称谢你，赞美你荣耀之名。</span>
<span className="v" id="v14" data-v="14" data-xref="雅各书 1:17; 哥林多后书 3:5; 罗马书 11:36"> 我算什么，我的民算什么，竟能如此乐意奉献？因为万物都从你而来，我们把从你而得的献给你。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 144:4; 利未记 25:23; 诗篇 102:11"> 我们在你面前是客旅，是寄居的，与我们列祖一样。我们在世的日子如影儿，不能长存<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：没有长存的指望。">a</a></sup>。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 29:14; 诗篇 24:1; 历代志下 31:10"> 耶和华我们的神啊，我们预备这许多材料要为你的圣名建造殿宇，都是从你而来，都是属你的。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 17:10; 箴言 11:20; 历代志上 28:9"> 我的神啊，我知道你察验人心，喜悦正直。我以正直的心乐意献上这一切物，现在我喜欢见你的民在这里都乐意奉献于你。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 32:39; 耶利米书 10:23; 希伯来书 13:21"> 耶和华我们列祖亚伯拉罕、以撒、以色列的神啊，求你使你的民常存这样的心思意念，坚定他们的心归向你。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 72:1; 历代志上 28:9; 雅各书 1:17"> 又求你赐我儿子所罗门诚实的心，遵守你的命令、法度、律例，成就这一切的事，用我所预备的建造殿宇。”</span>
</div>
</div>

## 会众称颂耶和华

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="诗篇 95:6; 出埃及记 4:31; 诗篇 135:19–21"> 大卫对全会众说：“你们应当称颂耶和华你们的神！”于是会众称颂耶和华他们列祖的神，低头拜耶和华与王。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志下 7:4–9; 民数记 15:7; 以斯拉记 6:17"> 次日，他们向耶和华献平安祭和燔祭，就是献公牛一千只、公绵羊一千只、羊羔一千只，并同献的奠祭，又为以色列众人献许多的祭。那日他们在耶和华面前吃喝，大大欢乐。</span>
</div>
</div>

## 复膏所罗门立之为王

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="列王纪上 2:35; 历代志上 23:1; 出埃及记 24:11"> 他们奉耶和华的命再膏大卫的儿子所罗门做王，又膏撒督做祭司。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 2:12; 历代志上 28:5; 罗马书 13:1"> 于是所罗门坐在耶和华所赐的位上，接续他父亲大卫做王，万事亨通。以色列众人也都听从他。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 2:3–9; 以西结书 17:18; 创世记 24:2"> 众首领和勇士，并大卫王的众子，都顺服所罗门王。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 1:12; 历代志下 1:1; 传道书 2:9"> 耶和华使所罗门在以色列众人眼前甚为尊大，极其威严，胜过在他以前的以色列王。</span>
</div>
</div>

## 大卫寿终

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="历代志上 18:14; 诗篇 78:71–72"> 耶西的儿子大卫做以色列众人的王。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 2:11; 撒母耳记下 5:4–5; 历代志上 3:4"> 做王共四十年，在希伯仑做王七年，在耶路撒冷做王三十三年。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 15:15; 使徒行传 13:36; 历代志上 23:1"> 他年纪老迈，日子满足，享受丰富、尊荣，就死了，他儿子所罗门接续他做王。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记上 9:9; 撒母耳记下 12:1–7; 历代志上 21:9–11"> 大卫王始终的事，都写在先见撒母耳的书上和先知拿单并先见迦得的书上。</span>
<span className="v" id="v30" data-v="30" data-xref="但以理书 4:25; 但以理书 4:23; 但以理书 2:21"> 他的国事和他的勇力，以及他和以色列并列国所经过的事，都写在这书上。</span>
</div>
</div>

## 大卫有意为耶和华建殿神不许

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 6:7–9; 历代志上 15:1; 历代志上 17:5"> 大卫住在自己宫中，对先知拿单说：“看哪，我住在香柏木的宫中，耶和华的约柜反在幔子里！”</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 28:2; 哥林多前书 13:9; 撒迦利亚书 8:23"> 拿单对大卫说：“你可以照你的心意而行，因为神与你同在。”</span>
<span className="v" id="v3" data-v="3" data-xref="阿摩司书 3:7; 民数记 12:6; 以赛亚书 30:21"> 当夜，神的话临到拿单说：</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 28:2–3; 以赛亚书 55:8–9; 历代志下 6:8–9"> “你去告诉我仆人大卫说：‘耶和华如此说：你不可建造殿宇给我居住。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 7:6; 出埃及记 40:2–3; 列王纪上 8:16"> 自从我领以色列人出埃及直到今日，我未曾住过殿宇，乃从这会幕到那会幕，从这帐幕到那帐幕。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 7:7; 民数记 10:33–36; 哥林多后书 6:16"> 凡我同以色列人所走的地方，我何曾向以色列的一个士师，就是我吩咐牧养我民的，说：“你为何不给我建造香柏木的殿宇呢？”’</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 6:21; 出埃及记 3:1–10; 撒母耳记上 17:15"> 现在你要告诉我仆人大卫说：‘万军之耶和华如此说：我从羊圈中将你召来，叫你不再跟从羊群，立你做我民以色列的君。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 18:14; 历代志上 17:2; 诗篇 113:7–8"> 你无论往哪里去，我常与你同在，剪除你的一切仇敌。我必使你得大名，好像世上大大有名的人一样。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 2:23; 以西结书 28:4; 以弗所书 5:6"> 我必为我民以色列选定一个地方，栽培他们，使他们住自己的地方，不再迁移。凶恶之子也不像从前扰害他们，</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 7:11; 士师记 2:14–18; 出埃及记 1:21"> 并不像我命士师治理我民以色列的时候一样。我必制伏你的一切仇敌，并且我耶和华应许你，必为你建立家室。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 132:11; 列王纪上 1:21; 历代志上 28:5"> 你寿数满足归你列祖的时候，我必使你的后裔接续你的位，我也必坚定他的国。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 5:5; 但以理书 2:44; 以赛亚书 9:7"> 他必为我建造殿宇，我必坚定他的国位直到永远。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 1:5; 以赛亚书 55:3; 历代志上 17:12"> 我要做他的父，他要做我的子；并不使我的慈爱离开他，像离开在你以前的扫罗一样。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 89:36; 路加福音 1:32–33; 诗篇 72:17"> 我却要将他永远坚立在我家里和我国里，他的国位也必坚定直到永远。’”</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 23:28; 使徒行传 20:27; 撒母耳记下 7:17"> 拿单就按这一切话，照这默示，告诉大卫。</span>
</div>
</div>

## 大卫之祈祷

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 7:18; 创世记 32:10; 以弗所书 3:8"> 于是大卫王进去，坐在耶和华面前，说：“耶和华神啊，我是谁，我的家算什么，你竟使我到这地步呢？</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 17:11–15; 腓立比书 2:8–11; 以赛亚书 49:6"> 神啊，这在你眼中还看为小，又应许你仆人的家至于久远。耶和华神啊，你看顾我好像看顾高贵的人！</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 21:17; 撒母耳记上 2:30; 撒母耳记下 7:20–24"> 你加于仆人的尊荣，我还有何言可说呢？因为你知道你的仆人。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 37:35; 撒母耳记下 7:21; 但以理书 9:17"> 耶和华啊，你行了这大事，并且显明出来，是因你仆人的缘故，也是照你的心意。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 44:6; 耶利米书 10:6–7; 以弗所书 3:20"> 耶和华啊，照我们耳中听见，没有可比你的，除你以外再无神。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 20:9–10; 以赛亚书 63:9; 以赛亚书 48:9"> 世上有何民能比你的民以色列呢？你神从埃及救赎他们做自己的子民，又在你赎出来的民面前行大而可畏的事，驱逐列邦人，显出你的大名。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 19:5–6; 彼得前书 2:9; 罗马书 11:1–12"> 你使以色列人做你的子民直到永远，你耶和华也做他们的神。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 119:49; 耶利米书 11:5; 路加福音 1:38"> 耶和华啊，你所应许仆人和仆人家的话，求你坚定直到永远，照你所说的而行。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 6:13; 耶利米书 31:1; 启示录 21:3"> 愿你的名永远坚立，被尊为大，说：‘万军之耶和华是以色列的神，是治理以色列的神！’这样，你仆人大卫的家必在你面前坚立。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 9:15; 以西结书 36:37; 诗篇 10:17"> 我的神啊，因你启示仆人说‘我必为你建立家室’，所以仆人大胆在你面前祈祷。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 34:6–7; 希伯来书 6:18; 提多书 1:2"> 耶和华啊，唯有你是神，你也应许将这福气赐给仆人。</span>
<span className="v" id="v27" data-v="27" data-xref="以弗所书 1:3; 罗马书 11:29; 诗篇 72:17"> 现在你喜悦赐福于仆人的家，可以永存在你面前。耶和华啊，你已经赐福，还要赐福到永远。”</span>
</div>

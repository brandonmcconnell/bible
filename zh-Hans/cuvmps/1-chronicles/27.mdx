## 以色列族之班长

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 4:27; 历代志下 26:11–13; 申命记 1:15"> 以色列人的族长、千夫长、百夫长和官长都分定班次，每班是二万四千人，周年按月轮流，替换出入服侍王。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 11:11; 撒母耳记下 23:8"> 正月第一班的班长是撒巴第业的儿子雅朔班，他班内有二万四千人。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 26:20; 民数记 10:14; 创世记 49:8–10"> 他是法勒斯的子孙，统管正月班的一切军长。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 23:9; 历代志上 11:12"> 二月的班长是亚合人朵代，还有副官密基罗，他班内有二万四千人。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 18:17; 列王纪上 4:4–5"> 三月第三班的班长<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：军长。下同。">a</a></sup>是祭司耶何耶大的儿子比拿雅，他班内有二万四千人。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 23:20–23; 历代志上 11:22–25; 撒母耳记下 22:20–23"> 这比拿雅是那三十人中的勇士，管理那三十人，他班内又有他儿子暗米萨拔。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 11:26; 撒母耳记下 23:24; 撒母耳记下 2:18–23"> 四月第四班的班长是约押的兄弟亚撒黑，接续他的是他儿子西巴第雅，他班内有二万四千人。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志上 11:27; 撒母耳记下 23:25; 历代志上 26:29"> 五月第五班的班长是伊斯拉人珊合，他班内有二万四千人。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 11:28; 撒母耳记下 23:26"> 六月第六班的班长是提哥亚人益吉的儿子以拉，他班内有二万四千人。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 11:27; 撒母耳记下 23:26"> 七月第七班的班长是以法莲族比伦人希利斯，他班内有二万四千人。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 21:18; 历代志上 11:29; 民数记 26:20"> 八月第八班的班长是谢拉族户沙人西比该，他班内有二万四千人。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 11:28; 撒母耳记下 23:27"> 九月第九班的班长是便雅悯族亚拿突人亚比以谢，他班内有二万四千人。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 11:30; 撒母耳记下 23:28"> 十月第十班的班长是谢拉族尼陀法人玛哈莱，他班内有二万四千人。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志上 11:31; 撒母耳记下 23:30"> 十一月第十一班的班长是以法莲族比拉顿人比拿雅，他班内有二万四千人。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 23:29; 历代志上 4:13; 士师记 3:9"> 十二月第十二班的班长是俄陀聂族尼陀法人黑玳，他班内有二万四千人。</span>
</div>
</div>

## 记各支派之长

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16"> 管理以色列众支派的记在下面：管鲁本人的，是细基利的儿子以利以谢；管西缅人的，是玛迦的儿子示法提雅；</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 26:30; 历代志上 24:31; 历代志上 12:27–28"> 管利未人的，是基母利的儿子哈沙比雅；管亚伦子孙的，是撒督；</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 16:6; 撒母耳记上 17:29; 撒母耳记上 17:13"> 管犹大人的，是大卫的一个哥哥以利户；管以萨迦人的，是米迦勒的儿子暗利；</span>
<span className="v" id="v19" data-v="19"> 管西布伦人的，是俄巴第雅的儿子伊施玛雅；管拿弗他利人的，是亚斯列的儿子耶利摩；</span>
<span className="v" id="v20" data-v="20"> 管以法莲人的，是阿撒细雅的儿子何细亚；管玛拿西半支派的，是毗大雅的儿子约珥；</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记下 3:27; 撒母耳记上 14:50–51; 撒母耳记下 3:37"> 管基列地玛拿西那半支派的，是撒迦利亚的儿子易多；管便雅悯人的，是押尼珥的儿子雅西业；</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 28:1"> 管但人的，是耶罗罕的儿子亚萨列。以上是以色列众支派的首领。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 15:5; 历代志上 21:2–5; 希伯来书 11:12"> 以色列人二十岁以内的，大卫没有记其数目，因耶和华曾应许说必加增以色列人如天上的星那样多。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 21:1–17; 撒母耳记下 24:1–15"> 洗鲁雅的儿子约押动手数点，当时耶和华的烈怒临到以色列人，因此没有点完，数目也没有写在《大卫王记》上。</span>
</div>
</div>

## 记大卫诸臣及其职守

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="历代志下 16:2; 出埃及记 1:11; 历代志下 26:10"> 掌管王府库的，是亚叠的儿子押斯马威；掌管田野城邑村庄保障之仓库的，是乌西雅的儿子约拿单；</span>
<span className="v" id="v26" data-v="26"> 掌管耕田种地的，是基绿的儿子以斯利；</span>
<span className="v" id="v27" data-v="27"> 掌管葡萄园的，是拉玛人示每；掌管葡萄园酒窖的，是实弗米人撒巴底；</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪上 10:27; 历代志下 1:15; 列王纪上 4:7"> 掌管高原橄榄树和桑树的，是基第利人巴勒哈南；掌管油库的，是约阿施；</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 5:16; 以赛亚书 65:10"> 掌管沙仑牧放牛群的，是沙仑人施提赉；掌管山谷牧养牛群的，是亚第赉的儿子沙法；</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 47:6; 约伯记 1:3"> 掌管驼群的，是以实玛利人阿比勒；掌管驴群的，是米仑人耶希底亚；掌管羊群的，是夏甲人雅悉。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 5:10"> 这都是给大卫王掌管产业的。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="撒母耳记下 21:21; 撒母耳记下 13:3; 历代志上 11:11"> 大卫的叔叔约拿单做谋士，这人有智慧，又做书记。哈摩尼的儿子耶歇做王众子的师傅。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 15:12; 撒母耳记下 15:37; 撒母耳记下 15:32"> 亚希多弗也做王的谋士。亚基人户筛做王的陪伴。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志上 11:6; 列王纪上 1:7; 历代志上 27:5"> 亚希多弗之后，有比拿雅的儿子耶何耶大和亚比亚他接续他做谋士。约押做王的元帅。</span>
</div>

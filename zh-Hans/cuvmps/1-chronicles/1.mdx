## 亚当之谱系

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 3:38; 创世记 4:25–32"> 亚当生塞特，塞特生以挪士，</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 3:37; 创世记 5:12–20; 创世记 5:9"> 以挪士生该南，该南生玛勒列，玛勒列生雅列，</span>
<span className="v" id="v3" data-v="3" data-xref="犹大书 1:14; 创世记 5:21–31; 路加福音 3:36–37"> 雅列生以诺，以诺生玛土撒拉，玛土撒拉生拉麦，</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 5:32; 创世记 9:18; 路加福音 17:26"> 拉麦生挪亚，挪亚生闪、含、雅弗。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 10:1–5; 以西结书 38:6; 以西结书 27:13"> 雅弗的儿子是歌篾、玛各、玛代、雅完、土巴、米设、提拉。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 10:3"> 歌篾的儿子是亚实基拿、低法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“低法”《创世记》10章3节作“利法”。">a</a></sup>、陀迦玛。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 2:10; 民数记 24:24; 以赛亚书 66:19"> 雅完的儿子是以利沙、他施、基提、多单<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“多单”有作“罗单”的。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="创世记 10:6–7"> 含的儿子是古实、麦西、弗、迦南。</span>
<span className="v" id="v9" data-v="9"> 古实的儿子是西巴、哈腓拉、撒弗他、拉玛、撒弗提迦。拉玛的儿子是示巴、底但。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 10:8–12; 弥迦书 5:6"> 古实生宁录，他为世上英雄之首。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 10:13–18"> 麦西生路低人、亚拿米人、利哈比人、拿弗土希人、</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 2:23; 耶利米书 47:4; 阿摩司书 9:7"> 帕斯鲁细人、迦斯路希人、迦斐托人，从迦斐托出来的有非利士人。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 9:22; 创世记 23:20; 创世记 10:15–19"> 迦南生长子西顿，又生赫，</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 15:21; 约书亚记 3:10; 出埃及记 33:2"> 和耶布斯人、亚摩利人、革迦撒人、</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 3:8; 列王纪上 9:20; 出埃及记 13:5"> 希未人、亚基人、西尼人、</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 34:8; 列王纪上 8:65"> 亚瓦底人、洗玛利人并哈马人。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 10:22–32; 以斯拉记 4:2; 以西结书 32:24"> 闪的儿子是以拦、亚述、亚法撒、路德、亚兰、乌斯、户勒、基帖、米设<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“米设”《创世记》10章23节作“玛施”。">c</a></sup>。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 11:12–15; 创世记 10:24"> 亚法撒生沙拉，沙拉生希伯。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 10:21; 创世记 11:16–17; 创世记 10:25"> 希伯生了两个儿子，一个名叫法勒<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“法勒”就是“分”的意思。">d</a></sup>，因为那时人就分地居住；法勒的兄弟名叫约坍。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 10:26–27"> 约坍生亚摩答、沙列、哈萨玛非、耶拉、</span>
<span className="v" id="v21" data-v="21"> 哈多兰、乌萨、德拉、</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 10:28"> 以巴录、亚比玛利、示巴、</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 10:11; 创世记 25:18; 撒母耳记上 15:7"> 阿斐、哈腓拉、约巴，这都是约坍的儿子。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="创世记 11:10–26; 路加福音 3:34–36"> 闪生亚法撒，亚法撒生沙拉，</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 3:35"> 沙拉生希伯，希伯生法勒，法勒生拉吴，</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 3:34–35"> 拉吴生西鹿，西鹿生拿鹤，拿鹤生他拉，</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 11:27–32; 尼希米记 9:7; 约书亚记 24:2"> 他拉生亚伯兰，亚伯兰就是亚伯拉罕。</span>
</div>
</div>

## 亚伯拉罕之后裔

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="创世记 17:19–21; 创世记 21:2–5; 创世记 21:9–10"> 亚伯拉罕的儿子是以撒、以实玛利。</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 60:7; 创世记 25:12–16; 雅歌 1:5"> 以实玛利的儿子记在下面：以实玛利的长子是尼拜约，其次是基达、亚德别、米比衫、</span>
<span className="v" id="v30" data-v="30" data-xref="以赛亚书 21:11; 创世记 25:15"> 米施玛、度玛、玛撒、哈达、提玛、</span>
<span className="v" id="v31" data-v="31"> 伊突、拿非施、基底玛。这都是以实玛利的儿子。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="创世记 25:1–4; 耶利米书 25:23; 士师记 6:1–6"> 亚伯拉罕的妾基土拉所生的儿子就是心兰、约珊、米但、米甸、伊施巴、书亚。约珊的儿子是示巴、底但。</span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 60:6"> 米甸的儿子是以法、以弗、哈诺、亚比大、以勒大。这都是基土拉的子孙。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="创世记 32:28; 使徒行传 7:8; 马太福音 1:2"> 亚伯拉罕生以撒，以撒的儿子是以扫和以色列。</span>
</div>
</div>

## 以扫之后裔

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="创世记 36:9–10; 创世记 36:4–5"> 以扫的儿子是以利法、流珥、耶乌施、雅兰、可拉。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 49:20; 阿摩司书 1:12; 俄巴底亚书 1:9"> 以利法的儿子是提幔、阿抹、洗玻、迦坦、基纳斯、亭纳、亚玛力。</span>
<span className="v" id="v37" data-v="37"> 流珥的儿子是拿哈、谢拉、沙玛、米撒。</span>
</div>
</div>

## 西珥之后裔

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="创世记 36:20–30"> 西珥的儿子是罗坍、朔巴、祭便、亚拿、底顺、以察、底珊。</span>
<span className="v" id="v39" data-v="39" data-xref="申命记 2:12; 创世记 36:22; 申命记 2:22"> 罗坍的儿子是何利、荷幔，罗坍的妹子是亭纳。</span>
<span className="v" id="v40" data-v="40" data-xref="创世记 36:23–24"> 朔巴的儿子是亚勒文、玛拿辖、以巴录、示非、阿南。祭便的儿子是亚雅、亚拿。</span>
<span className="v" id="v41" data-v="41" data-xref="创世记 36:25–26"> 亚拿的儿子是底顺。底顺的儿子是哈默兰、伊是班、益兰、基兰。</span>
<span className="v" id="v42" data-v="42" data-xref="耶利米哀歌 4:21; 创世记 36:27–28"> 以察的儿子是辟罕、撒番、亚干。底珊的儿子是乌斯、亚兰。</span>
</div>
</div>

## 以东诸王

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="创世记 36:31–43; 民数记 24:17–19; 创世记 49:10"> 以色列人未有君王治理之先，在以东地做王的记在下面。有比珥的儿子比拉，他的京城名叫亭哈巴。</span>
<span className="v" id="v44" data-v="44" data-xref="以赛亚书 34:6; 以赛亚书 63:1; 阿摩司书 1:12"> 比拉死了，波斯拉人谢拉的儿子约巴接续他做王。</span>
<span className="v" id="v45" data-v="45" data-xref="创世记 36:11; 约伯记 2:11"> 约巴死了，提幔地的人户珊接续他做王。</span>
<span className="v" id="v46" data-v="46"> 户珊死了，比达的儿子哈达接续他做王，这哈达就是在摩押地杀败米甸人的，他的京城名叫亚未得。</span>
<span className="v" id="v47" data-v="47" data-xref="创世记 36:36"> 哈达死了，玛士利加人桑拉接续他做王。</span>
<span className="v" id="v48" data-v="48" data-xref="创世记 36:37"> 桑拉死了，大河边的利河伯人扫罗接续他做王。</span>
<span className="v" id="v49" data-v="49"> 扫罗死了，亚革波的儿子巴勒哈南接续他做王。</span>
<span className="v" id="v50" data-v="50" data-xref="创世记 36:39"> 巴勒哈南死了，哈达接续他做王，他的京城名叫巴伊，他的妻子名叫米希她别，是米萨合的孙女、玛特列的女儿。</span>
</div>
</div>

## 以东诸族长

<div className="bt">
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="创世记 36:40"> 哈达死了，以东人的族长有亭纳族长、亚勒瓦族长、耶帖族长、</span>
<span className="v" id="v52" data-v="52"> 阿何利巴玛族长、以拉族长、比嫩族长、</span>
<span className="v" id="v53" data-v="53"> 基纳斯族长、提幔族长、米比萨族长、</span>
<span className="v" id="v54" data-v="54" data-xref="创世记 36:41–43"> 玛基叠族长、以兰族长。这都是以东人的族长。</span>
</div>
</div>

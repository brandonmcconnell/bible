## 鲁本之后裔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 35:22; 创世记 29:32; 创世记 48:15–22"> 以色列的长子原是鲁本，因他污秽了父亲的床，他长子的名分就归了约瑟，只是按家谱他不算长子。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 2:6; 弥迦书 5:2; 希伯来书 7:14"> 犹大胜过一切弟兄，君王也是从他而出，长子的名分却归约瑟。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 46:9; 出埃及记 6:14; 民数记 26:5–9"> 以色列长子鲁本的儿子是哈诺、法路、希斯仑、迦米。</span>
<span className="v" id="v4" data-v="4"> 约珥的儿子是示玛雅，示玛雅的儿子是歌革，歌革的儿子是示每，</span>
<span className="v" id="v5" data-v="5"> 示每的儿子是米迦，米迦的儿子是利亚雅，利亚雅的儿子是巴力，</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 5:26; 列王纪下 15:29; 历代志下 28:20"> 巴力的儿子是备拉，这备拉做鲁本支派的首领，被亚述王提革拉毗尼色掳去。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 5:17"> 他的弟兄照着宗族，按着家谱做族长的是耶利、撒迦利雅、比拉，</span>
<span className="v" id="v8" data-v="8" data-xref="历代志上 5:4; 民数记 32:34; 民数记 32:38"> 比拉是亚撒的儿子，亚撒是示玛的儿子，示玛是约珥的儿子。约珥所住的地方是从亚罗珥直到尼波和巴力免，</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 22:8–9"> 又向东延到幼发拉底河这边的旷野，因为他们在基列地牲畜增多。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 21:9; 历代志上 5:18–21; 诗篇 83:6"> 扫罗年间，他们与夏甲人争战，夏甲人倒在他们手下，他们就在基列东边的全地，住在夏甲人的帐篷里。</span>
</div>
</div>

## 迦得之后裔

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约书亚记 13:11; 约书亚记 13:24–28; 申命记 3:10–17"> 迦得的子孙在鲁本对面，住在巴珊地，延到撒迦。</span>
<span className="v" id="v12" data-v="12"> 他们中间有做族长的约珥，有做副族长的沙番，还有雅乃和住在巴珊的沙法。</span>
<span className="v" id="v13" data-v="13"> 他们族弟兄是米迦勒、米书兰、示巴、约赖、雅干、细亚、希伯，共七人。</span>
<span className="v" id="v14" data-v="14"> 这都是亚比孩的儿子。亚比孩是户利的儿子，户利是耶罗亚的儿子，耶罗亚是基列的儿子，基列是米迦勒的儿子，米迦勒是耶示筛的儿子，耶示筛是耶哈多的儿子，耶哈多是布斯的儿子。</span>
<span className="v" id="v15" data-v="15"> 还有古尼的孙子、押比叠的儿子亚希，这都是做族长的。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 27:29; 雅歌 2:1; 以赛亚书 35:2"> 他们住在基列与巴珊和巴珊的乡村，并沙仑的郊野，直到四围的交界。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 14:16; 列王纪下 14:28; 列王纪下 15:32"> 这些人在犹大王约坦并在以色列王耶罗波安年间，都载入家谱。</span>
</div>
</div>

## 鲁本迦得玛拿西族胜敌据地

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民数记 1:3; 约书亚记 4:12–13"> 鲁本人、迦得人和玛拿西半支派的人能拿盾牌和刀剑、拉弓射箭、出征善战的勇士，共有四万四千七百六十名。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 25:15; 历代志上 1:31; 历代志上 5:10"> 他们与夏甲人、伊突人、拿非施人、挪答人争战。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 22:4–5; 诗篇 9:10; 历代志下 18:31"> 他们得了神的帮助，夏甲人和跟随夏甲的人都交在他们手中；因为他们在阵上呼求神，倚赖神，神就应允他们。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 18:13; 民数记 31:35"> 他们掳掠了夏甲人的牲畜，有骆驼五万，羊二十五万，驴二千，又有人十万。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 32:8; 罗马书 8:31; 约书亚记 23:10"> 敌人被杀仆倒的甚多，因为这争战是出乎神。他们就住在敌人的地上，直到被掳的时候。</span>
</div>
</div>

## 玛拿西半支派所居之地

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="申命记 3:8–9; 雅歌 4:8; 诗篇 133:3"> 玛拿西半支派的人住在那地，从巴珊延到巴力黑们、示尼珥与黑门山。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 4:38"> 他们的族长是以弗、以示、以列、亚斯列、耶利米、何达威雅、雅叠，都是大能的勇士，是有名的人，也是做族长的。</span>
</div>
</div>

## 二支派半人违逆神

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="启示录 17:5; 诗篇 106:34–39; 出埃及记 34:15"> 他们得罪了他们列祖的神，随从那地之民的神行邪淫，这民就是神在他们面前所除灭的。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 15:19; 列王纪下 17:6; 列王纪下 15:29"> 故此，以色列的神激动亚述王普勒和亚述王提革拉毗尼色的心，他们就把鲁本人、迦得人、玛拿西半支派的人掳到哈腊、哈博、哈拉与歌散河边，直到今日还在那里。</span>
</div>
</div>

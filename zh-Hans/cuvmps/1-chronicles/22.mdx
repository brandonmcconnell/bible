## 嘱所罗门为主建殿

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪上 3:7; 历代志上 29:1; 约翰福音 3:30"> 大卫召了他儿子所罗门来，嘱咐他给耶和华以色列的神建造殿宇，</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 27:23; 使徒行传 20:25–31; 使徒行传 1:2"> 对所罗门说：“我儿啊，我心里本想为耶和华我神的名建造殿宇，</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 132:5; 列王纪上 8:16–20; 历代志下 6:7–9"> 只是耶和华的话临到我说：‘你流了多人的血，打了多次大仗，你不可为我的名建造殿宇，因为你在我眼前使多人的血流在地上。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 5:3; 历代志上 28:3; 历代志上 17:4–10"> 你要生一个儿子，他必做太平的人。我必使他安静，不被四围的仇敌扰乱。他的名要叫所罗门<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="即“太平”之意。">a</a></sup>，他在位的日子，我必使以色列人平安康泰。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 4:25; 列王纪上 5:4; 列王纪上 4:20"> 他必为我的名建造殿宇。他要做我的子，我要做他的父。他做以色列王，我必坚定他的国位直到永远。’</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 1:5; 撒母耳记下 7:13–14; 历代志上 17:12–14"> 我儿啊，现今愿耶和华与你同在，使你亨通，照他指着你说的话，建造耶和华你神的殿。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 22:16; 历代志上 28:20; 提摩太后书 4:22"> 但愿耶和华赐你聪明、智慧，好治理以色列国，遵行耶和华你神的律法。</span>
<span className="v" id="v12" data-v="12" data-xref="雅各书 1:5; 箴言 14:8; 列王纪上 3:9–12"> 你若谨守遵行耶和华藉摩西吩咐以色列的律例、典章，就得亨通。你当刚强壮胆，不要惧怕，也不要惊惶。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 1:6–9; 历代志上 28:20; 历代志上 28:7"> 我在困难之中为耶和华的殿预备了金子十万他连得，银子一百万他连得，铜和铁多得无法可称。我也预备了木头、石头，你还可以增添。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志上 22:3; 列王纪下 25:16; 历代志上 29:4–7"> 你有许多匠人，就是石匠、木匠和一切能做各样工的巧匠，</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 28:6; 出埃及记 35:32; 列王纪上 7:14"> 并有无数的金、银、铜、铁。你当起来办事，愿耶和华与你同在。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志上 22:11; 腓立比书 4:13; 以弗所书 5:14"> 大卫又吩咐以色列的众首领帮助他儿子所罗门，说：</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 28:1–6; 约翰三书 1:8; 历代志上 29:6"> “耶和华你们的神不是与你们同在吗？不是叫你们四围都平安吗？因他已将这地的居民交在我手中，这地就在耶和华与他百姓面前制伏了。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 22:9; 历代志上 23:25; 撒母耳记下 7:1"> 现在你们应当立定心意，寻求耶和华你们的神，也当起来建造耶和华神的圣所，好将耶和华的约柜和供奉神的圣器皿都搬进为耶和华名建造的殿里。”</span>
</div>
</div>

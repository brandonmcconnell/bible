## 诣洗革拉归大卫之勇士

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 27:2–6; 历代志上 11:24–25; 历代志上 8:33"> 大卫因怕基士的儿子扫罗躲在洗革拉的时候，有勇士到他那里帮助他打仗。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 3:15; 士师记 20:16; 撒母耳记上 17:49"> 他们善于拉弓，能用左右两手甩石射箭，都是便雅悯人，扫罗的族弟兄。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 11:28; 撒母耳记下 21:6; 历代志上 11:33"> 为首的是亚希以谢，其次是约阿施，都是基比亚人示玛的儿子；还有亚斯玛威的儿子耶薛和毗力；又有比拉迦，并亚拿突人耶户，</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 9:3; 约书亚记 15:36; 历代志上 11:15"> 基遍人以实买雅，他在三十人中是勇士，管理他们；且有耶利米，雅哈悉，约哈难和基得拉人约撒拔，</span>
<span className="v" id="v5" data-v="5"> 伊利乌赛，耶利摩，比亚利雅，示玛利雅，哈律弗人示法提雅，</span>
<span className="v" id="v6" data-v="6"> 可拉人以利加拿，耶西亚，亚萨列，约以谢，雅朔班，</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 15:58; 历代志上 4:18; 历代志上 4:39"> 基多人耶罗罕的儿子犹拉和西巴第雅。</span>
</div>
</div>

## 迦得族归大卫之勇士

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 2:18; 撒母耳记下 17:10; 撒母耳记下 23:20"> 迦得支派中有人到旷野的山寨投奔大卫，都是大能的勇士，能拿盾牌和枪的战士。他们的面貌好像狮子，快跑如同山上的鹿。</span>
<span className="v" id="v9" data-v="9"> 第一以薛，第二俄巴底雅，第三以利押，</span>
<span className="v" id="v10" data-v="10"> 第四弥施玛拿，第五耶利米，</span>
<span className="v" id="v11" data-v="11"> 第六亚太，第七以利业，</span>
<span className="v" id="v12" data-v="12"> 第八约哈难，第九以利萨巴，</span>
<span className="v" id="v13" data-v="13"> 第十耶利米，第十一末巴奈。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 32:30; 利未记 26:8"> 这都是迦得人中的军长，至小的能抵一百人，至大的能抵一千人。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 3:15; 约书亚记 4:18; 耶利米书 49:19"> 正月约旦河水涨过两岸的时候，他们过河，使一切住平原的人东奔西逃。</span>
</div>
</div>

## 归大卫之便雅悯犹大人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v16" data-v="16"> 又有便雅悯和犹大人到山寨大卫那里。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前书 2:23; 犹大书 1:9; 哥林多后书 13:11"> 大卫出去迎接他们，对他们说：“你们若是和和平平地来帮助我，我心就与你们相契；你们若是将我这无罪的人卖在敌人手里，愿我们列祖的神察看、责罚。”</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 6:34; 士师记 3:10; 撒母耳记下 17:25"> 那时神的灵感动那三十个勇士的首领亚玛撒，他就说：<br /><span className="pl pl-1">“大卫啊，我们是归于你的；</span><br /><span className="pl pl-1">耶西的儿子啊，我们是帮助你的！</span><br /><span className="pl pl-1">愿你平平安安，</span><br /><span className="pl pl-1">愿帮助你的也都平安，</span><br /><span className="pl pl-1">因为你的神帮助你！”</span><br />大卫就收留他们，立他们做军长。</span>
</div>
</div>

## 归大卫之玛拿西人

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 29:2–9"> 大卫从前与非利士人同去，要与扫罗争战，有些玛拿西人来投奔大卫。他们却没有帮助非利士人，因为非利士人的首领商议，打发他们回去，说：“恐怕大卫拿我们的首级归降他的主人扫罗。”</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 33:17; 申命记 1:15; 撒母耳记上 29:11"> 大卫往洗革拉去的时候，有玛拿西人的千夫长押拿、约撒拔、耶叠、米迦勒、约撒拔、以利户、洗勒太都来投奔他。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 30:1–17; 历代志上 12:20; 历代志上 5:24"> 这些人帮助大卫攻击群贼，他们都是大能的勇士，且做军长。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 3:1; 约伯记 17:9; 创世记 32:2"> 那时，天天有人来帮助大卫，以致成了大军，如神的军一样。</span>
</div>
</div>

## 归大卫之战士成军

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 2:3–4; 历代志上 11:10; 撒母耳记上 16:1"> 预备打仗的兵来到希伯仑见大卫，要照着耶和华的话将扫罗的国位归于大卫。他们的数目如下：</span>
<span className="v" id="v24" data-v="24"> 犹大支派，拿盾牌和枪预备打仗的有六千八百人；</span>
<span className="v" id="v25" data-v="25"> 西缅支派，能上阵大能的勇士有七千一百人；</span>
<span className="v" id="v26" data-v="26"> 利未支派，有四千六百人，</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 11:9; 列王纪下 25:18; 历代志上 6:49–57"> 耶何耶大是亚伦家的首领，跟从他的有三千七百人，</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 8:17; 历代志上 6:8; 历代志上 6:53"> 还有少年大能的勇士撒督，同着他的有族长二十二人。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 2:8–9; 历代志上 12:2; 创世记 31:23"> 便雅悯支派，扫罗的族弟兄也有三千人，他们向来大半归顺扫罗家；</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 6:4"> 以法莲支派，大能的勇士、在本族著名的有二万零八百人；</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 17:1–18"> 玛拿西半支派，册上有名的共一万八千人，都来立大卫做王；</span>
<span className="v" id="v32" data-v="32" data-xref="以弗所书 5:17; 路加福音 12:56–57; 以斯帖记 1:13"> 以萨迦支派，有二百族长，都通达时务，知道以色列人所当行的，他们族弟兄都听从他们的命令；</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 12:2; 约翰福音 1:47"> 西布伦支派，能上阵用各样兵器打仗，行伍整齐，不生二心的有五万人；</span>
<span className="v" id="v34" data-v="34"> 拿弗他利支派，有一千军长，跟从他们拿盾牌和枪的有三万七千人；</span>
<span className="v" id="v35" data-v="35"> 但支派，能摆阵的有二万八千六百人；</span>
<span className="v" id="v36" data-v="36" data-xref="历代志上 12:33; 约珥书 2:7"> 亚设支派，能上阵打仗的有四万人；</span>
<span className="v" id="v37" data-v="37" data-xref="约书亚记 14:3; 申命记 3:12–16; 约书亚记 13:7–32"> 约旦河东的鲁本支派、迦得支派、玛拿西半支派，拿着各样兵器打仗的有十二万人。</span>
</div>
</div>

## 以色列民同心立大卫为王

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="创世记 49:8–10; 列王纪上 8:61; 诗篇 101:2"> 以上都是能守行伍的战士，他们都诚心来到希伯仑，要立大卫做以色列的王。以色列其余的人也都一心要立大卫做王。</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 31:54; 撒母耳记下 19:42; 创世记 26:30"> 他们在那里三日，与大卫一同吃喝，因为他们的族弟兄给他们预备了。</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳记上 25:18; 撒母耳记下 16:1; 耶利米书 23:5–6"> 靠近他们的人以及以萨迦、西布伦、拿弗他利人，将许多面饼、无花果饼、干葡萄、酒、油，用驴、骆驼、骡子、牛驮来，又带了许多的牛和羊来，因为以色列人甚是欢乐。</span>
</div>

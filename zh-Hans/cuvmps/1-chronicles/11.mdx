## 以色列民集于希伯仑膏大卫为王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 5:1–16; 历代志上 12:23–40; 士师记 9:2"> 以色列众人聚集到希伯仑见大卫，说：“我们原是你的骨肉。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 5:2; 约翰福音 10:4; 诗篇 78:71"> 从前扫罗做王的时候，率领以色列人出入的是你。耶和华你的神也曾应许你说：‘你必牧养我的民以色列，做以色列的君。’”</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 16:12–13; 撒母耳记上 16:1; 撒母耳记下 5:3"> 于是以色列的长老都来到希伯仑见大卫王，大卫在希伯仑耶和华面前与他们立约，他们就膏大卫做以色列的王，是照耶和华藉撒母耳所说的话。</span>
</div>
</div>

## 大卫攻取锡安保障

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士师记 1:21; 创世记 15:21; 约书亚记 15:8"> 大卫和以色列众人到了耶路撒冷，就是耶布斯，那时耶布斯人住在那里。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 5:2; 列王纪上 8:1; 诗篇 87:2"> 耶布斯人对大卫说：“你决不能进这地方。”然而大卫攻取锡安的保障，就是大卫的城。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 8:16; 撒母耳记下 20:23; 撒母耳记下 3:27"> 大卫说：“谁先攻打耶布斯人，必做首领元帅。”洗鲁雅的儿子约押先上去，就做了元帅。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 11:5; 撒母耳记下 5:7; 诗篇 2:6"> 大卫住在保障里，所以那保障叫做大卫城。</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 9:6; 列王纪上 11:27; 列王纪下 12:20"> 大卫又从米罗起，四围建筑城墙，其余的是约押修理。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 3:1; 以赛亚书 41:10; 历代志上 9:20"> 大卫日见强盛，因为万军之耶和华与他同在。</span>
</div>
</div>

## 记大卫之诸勇士

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志上 11:3; 撒母耳记上 16:1; 历代志上 12:38"> 以下记录跟随大卫勇士的首领，就是奋勇帮助他得国，照着耶和华吩咐以色列人的话与以色列人一同立他做王的。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 23:8; 历代志上 27:2; 历代志上 12:18"> 大卫勇士的数目记在下面：哈革摩尼的儿子雅朔班，他是军长的统领，一时举枪杀了三百人。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 27:4; 撒母耳记下 23:17–19; 撒母耳记下 23:23"> 其次是亚合人朵多的儿子以利亚撒，他是三个勇士里的一个。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 23:11–12; 撒母耳记上 17:1"> 他从前与大卫在巴斯达闵，非利士人聚集要打仗。那里有一块长满大麦的田，众民就在非利士人面前逃跑，</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 144:10; 列王纪下 5:1; 撒母耳记上 14:23"> 这勇士便站在那田间击杀非利士人，救护了那田。耶和华使以色列人大获全胜。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="历代志上 14:9; 撒母耳记下 5:18; 以赛亚书 17:5"> 三十个勇士中的三个人下到磐石那里，进了亚杜兰洞见大卫；非利士的军队在利乏音谷安营。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 10:5; 撒母耳记上 13:4; 撒母耳记上 13:23"> 那时大卫在山寨，非利士人的防营在伯利恒。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 4:14; 以赛亚书 12:3; 撒母耳记下 23:15–16"> 大卫渴想，说：“甚愿有人将伯利恒城门旁井里的水打来给我喝！”</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 21:13; 撒母耳记上 19:5; 使徒行传 20:24"> 这三个勇士就闯过非利士人的营盘，从伯利恒城门旁的井里打水，拿来奉给大卫。他却不肯喝，将水奠在耶和华面前，</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 23:17; 诗篇 72:14; 士师记 9:17"> 说：“我的神啊，这三个人冒死去打水，这水好像他们的血一般，我断不敢喝！”如此，大卫不肯喝。这是三个勇士所做的事。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 26:6; 历代志上 2:16; 撒母耳记下 20:6"> 约押的兄弟亚比筛是这三个勇士的首领，他举枪杀了三百人，就在三个勇士里得了名。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 15:41; 马太福音 13:8"> 他在这三个勇士里是最尊贵的，所以做他们的首领，只是不及前三个勇士。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 23:20–23; 撒母耳记下 8:18; 约书亚记 15:21"> 有甲薛勇士耶何耶大的儿子比拿雅，行过大能的事，他杀了摩押人亚利伊勒的两个儿子，又在下雪的时候下坑里去杀了一个狮子。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 17:7; 撒母耳记上 17:4; 申命记 3:11"> 又杀了一个埃及人，埃及人身高五肘，手里拿着枪，枪杆粗如织布的机轴。比拿雅只拿着棍子下去，从埃及人手里夺过枪来，用那枪将他刺死。</span>
<span className="v" id="v24" data-v="24"> 这是耶何耶大的儿子比拿雅所行的事，就在三个勇士里得了名。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 20:23"> 他比那三十个勇士都尊贵，只是不及前三个勇士。大卫立他做护卫长。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="历代志上 27:7; 撒母耳记下 21:19; 撒母耳记下 2:18–23"> 军中的勇士，有约押的兄弟亚撒黑，伯利恒人朵多的儿子伊勒哈难，</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记下 23:25–26"> 哈律人沙玛，比伦人希利斯，</span>
<span className="v" id="v28" data-v="28" data-xref="历代志上 27:12; 历代志上 27:9; 撒母耳记下 23:27"> 提哥亚人益吉的儿子以拉，亚拿突人亚比以谢，</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 23:27–28; 历代志上 27:11"> 户沙人西比该，亚合人以来，</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 27:13; 历代志上 27:15; 撒母耳记下 23:29"> 尼陀法人玛哈莱，尼陀法人巴拿的儿子希立，</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 23:29"> 便雅悯族基比亚人利拜的儿子以太，比拉顿人比拿雅，</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记下 23:30–31"> 迦实溪人户莱，亚拉巴人亚比，</span>
<span className="v" id="v33" data-v="33"> 巴路米人押斯玛弗，沙本人以利雅哈巴，</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记下 23:32–33"> 基孙人哈深的众子，哈拉人沙基的儿子约拿单，</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 23:33–34"> 哈拉人沙甲的儿子亚希暗，吾珥的儿子以利法勒，</span>
<span className="v" id="v36" data-v="36"> 米基拉人希弗，比伦人亚希雅，</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳记下 23:35"> 迦密人希斯罗，伊斯拜的儿子拿莱，</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳记下 23:36"> 拿单的兄弟约珥，哈基利的儿子弥伯哈，</span>
<span className="v" id="v39" data-v="39"> 亚扪人洗勒，比录人拿哈莱（拿哈莱是给洗鲁雅的儿子约押拿兵器的），</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳记下 20:26"> 以帖人以拉，以帖人迦立，</span>
<span className="v" id="v41" data-v="41" data-xref="历代志上 2:36; 撒母耳记下 23:39; 撒母耳记下 11:6–27"> 赫人乌利亚，亚莱的儿子撒拔，</span>
<span className="v" id="v42" data-v="42"> 鲁本人示撒的儿子亚第拿（他是鲁本支派中的一个族长，率领三十人），</span>
<span className="v" id="v43" data-v="43"> 玛迦的儿子哈难，弥特尼人约沙法，</span>
<span className="v" id="v44" data-v="44"> 亚施他拉人乌西亚，亚罗珥人何坦的儿子沙玛、耶利，</span>
<span className="v" id="v45" data-v="45"> 提洗人申利的儿子耶叠和他的兄弟约哈，</span>
<span className="v" id="v46" data-v="46"> 玛哈未人以利业，伊利拿安的儿子耶利拜、约沙未雅，摩押人伊特玛，</span>
<span className="v" id="v47" data-v="47"> 以利业，俄备得，并米琐八人雅西业。</span>
</div>
</div>

## 利未之后裔

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 46:11; 出埃及记 6:16; 民数记 26:57"> 利未的儿子是革顺、哥辖、米拉利。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 6:18; 出埃及记 6:21–24; 历代志上 23:12"> 哥辖的儿子是暗兰、以斯哈、希伯伦、乌薛。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 6:20; 利未记 10:1; 利未记 10:12"> 暗兰的儿子是亚伦、摩西，还有女儿米利暗。亚伦的儿子是拿答、亚比户、以利亚撒、以他玛。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 6:50; 出埃及记 6:25; 以斯拉记 7:1–5"> 以利亚撒生非尼哈，非尼哈生亚比书，</span>
<span className="v" id="v5" data-v="5"> 亚比书生布基，布基生乌西，</span>
<span className="v" id="v6" data-v="6"> 乌西生西拉希雅，西拉希雅生米拉约，</span>
<span className="v" id="v7" data-v="7"> 米拉约生亚玛利雅，亚玛利雅生亚希突，</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 8:17; 撒母耳记下 15:27; 列王纪上 1:44"> 亚希突生撒督，撒督生亚希玛斯，</span>
<span className="v" id="v9" data-v="9"> 亚希玛斯生亚撒利雅，亚撒利雅生约哈难，</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 3:4; 历代志下 3:1; 列王纪上 6:1–7"> 约哈难生亚撒利雅（这亚撒利雅在所罗门于耶路撒冷所建造的殿中供祭司的职分），</span>
<span className="v" id="v11" data-v="11" data-xref="以斯拉记 7:3"> 亚撒利雅生亚玛利雅，亚玛利雅生亚希突，</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米记 11:11; 历代志上 9:11"> 亚希突生撒督，撒督生沙龙，</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 35:8; 列王纪下 22:12–14; 列王纪下 22:4"> 沙龙生希勒家，希勒家生亚撒利雅，</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 25:18; 尼希米记 11:11; 撒迦利亚书 6:11"> 亚撒利雅生西莱雅，西莱雅生约萨答。</span>
<span className="v" id="v15" data-v="15" data-xref="哈该书 2:2; 列王纪下 25:18; 哈该书 1:1"> 当耶和华藉尼布甲尼撒的手掳掠犹大和耶路撒冷人的时候，这约萨答也被掳去。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及记 6:16; 历代志上 6:1"> 利未的儿子是革顺、哥辖、米拉利。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 23:7; 民数记 3:18; 民数记 3:21"> 革顺的儿子名叫立尼、示每。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 23:12; 历代志上 6:2–3"> 哥辖的儿子是暗兰、以斯哈、希伯伦、乌薛。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 23:21; 历代志上 24:26; 出埃及记 6:19"> 米拉利的儿子是抹利、母示。这是按着利未人宗族分的各家。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志上 6:43"> 革顺的儿子是立尼，立尼的儿子是雅哈，雅哈的儿子是薪玛，</span>
<span className="v" id="v21" data-v="21"> 薪玛的儿子是约亚，约亚的儿子是易多，易多的儿子是谢拉，谢拉的儿子是耶特赖。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 6:24; 历代志上 6:18; 历代志上 6:2"> 哥辖的儿子是亚米拿达，亚米拿达的儿子是可拉，可拉的儿子是亚惜，</span>
<span className="v" id="v23" data-v="23"> 亚惜的儿子是以利加拿，以利加拿的儿子是以比雅撒，以比雅撒的儿子是亚惜，</span>
<span className="v" id="v24" data-v="24"> 亚惜的儿子是他哈，他哈的儿子是乌列，乌列的儿子是乌西雅，乌西雅的儿子是少罗。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 6:24; 历代志上 6:35–36"> 以利加拿的儿子是亚玛赛和亚希摩。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记上 1:1; 历代志上 6:35"> 亚希摩的儿子是以利加拿，以利加拿的儿子是琐菲，琐菲的儿子是拿哈，</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 1:1; 撒母耳记上 1:19–20"> 拿哈的儿子是以利押，以利押的儿子是耶罗罕，耶罗罕的儿子是以利加拿，以利加拿的儿子是撒母耳。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志上 6:33; 撒母耳记上 8:2"> 撒母耳的长子是约珥，次子是亚比亚。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 6:19; 民数记 3:33"> 米拉利的儿子是抹利，抹利的儿子是立尼，立尼的儿子是示每，示每的儿子是乌撒，</span>
<span className="v" id="v30" data-v="30"> 乌撒的儿子是示米亚，示米亚的儿子是哈基雅，哈基雅的儿子是亚帅雅。</span>
</div>

## 大卫立司理讴歌者

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 6:17; 历代志上 15:25–1; 历代志上 15:16–22"> 约柜安设之后，大卫派人在耶和华殿中管理歌唱的事。</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 135:1–3; 列王纪上 8:6–13; 以斯拉记 6:18"> 他们就在会幕前当歌唱的差，及至所罗门在耶路撒冷建造了耶和华的殿，他们便按着班次供职。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志上 6:28; 历代志上 15:17; 历代志上 25:1–5"> 供职的人和他们的子孙记在下面：哥辖的子孙中有歌唱的希幔，希幔是约珥的儿子，约珥是撒母耳的儿子，</span>
<span className="v" id="v34" data-v="34"> 撒母耳是以利加拿的儿子，以利加拿是耶罗罕的儿子，耶罗罕是以列的儿子，以列是陀亚的儿子，</span>
<span className="v" id="v35" data-v="35"> 陀亚是苏弗的儿子，苏弗是以利加拿的儿子，以利加拿是玛哈的儿子，玛哈是亚玛赛的儿子，</span>
<span className="v" id="v36" data-v="36"> 亚玛赛是以利加拿的儿子，以利加拿是约珥的儿子，约珥是亚撒利雅的儿子，亚撒利雅是西番雅的儿子，</span>
<span className="v" id="v37" data-v="37" data-xref="诗篇 45:1; 民数记 26:10–11; 出埃及记 6:21–24"> 西番雅是他哈的儿子，他哈是亚惜的儿子，亚惜是以比雅撒的儿子，以比雅撒是可拉的儿子，</span>
<span className="v" id="v38" data-v="38" data-xref="民数记 3:19; 历代志上 16:1"> 可拉是以斯哈的儿子，以斯哈是哥辖的儿子，哥辖是利未的儿子，利未是以色列的儿子。</span>
<span className="v" id="v39" data-v="39" data-xref="尼希米记 7:44; 以斯拉记 2:41; 诗篇 75:1"> 希幔的族兄亚萨是比利家的儿子，亚萨在希幔右边供职，比利家是示米亚的儿子，</span>
<span className="v" id="v40" data-v="40"> 示米亚是米迦勒的儿子，米迦勒是巴西雅的儿子，巴西雅是玛基雅的儿子，</span>
<span className="v" id="v41" data-v="41"> 玛基雅是伊特尼的儿子，伊特尼是谢拉的儿子，谢拉是亚大雅的儿子，</span>
<span className="v" id="v42" data-v="42"> 亚大雅是以探的儿子，以探是薪玛的儿子，薪玛是示每的儿子，</span>
<span className="v" id="v43" data-v="43" data-xref="出埃及记 6:16; 历代志上 6:16–17; 创世记 46:11"> 示每是雅哈的儿子，雅哈是革顺的儿子，革顺是利未的儿子。</span>
<span className="v" id="v44" data-v="44" data-xref="诗篇 89:1; 历代志上 15:17; 历代志上 25:1"> 他们的族弟兄米拉利的子孙，在他们左边供职的有以探，以探是基示的儿子，基示是亚伯底的儿子，亚伯底是玛鹿的儿子，</span>
<span className="v" id="v45" data-v="45"> 玛鹿是哈沙比雅的儿子，哈沙比雅是亚玛谢的儿子，亚玛谢是希勒家的儿子，</span>
<span className="v" id="v46" data-v="46"> 希勒家是暗西的儿子，暗西是巴尼的儿子，巴尼是沙麦的儿子，</span>
<span className="v" id="v47" data-v="47" data-xref="约书亚记 21:7; 出埃及记 6:19; 历代志上 23:21"> 沙麦是末力的儿子，末力是母示的儿子，母示是米拉利的儿子，米拉利是利未的儿子。</span>
<span className="v" id="v48" data-v="48" data-xref="历代志上 23:2; 民数记 3:1–4; 民数记 18:1–32"> 他们的族弟兄利未人也被派办神殿中的一切事。</span>
</div>
</div>

<span className="v" id="v50" data-v="50" data-xref="利未记 10:16; 历代志上 24:1; 民数记 20:26–28"> 亚伦的儿子是以利亚撒，以利亚撒的儿子是非尼哈，非尼哈的儿子是亚比书，</span>

## 亚伦后裔之邑郊

<div className="bt">
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="创世记 25:16; 约书亚记 21:10; 约书亚记 21:3–8"> 他们的住处按着境内的营寨记在下面。哥辖族亚伦的子孙先拈阄得地，</span>
<span className="v" id="v55" data-v="55" data-xref="约书亚记 14:13; 约书亚记 21:11–13; 约书亚记 15:13"> 在犹大地中得了希伯仑和四围的郊野，</span>
<span className="v" id="v56" data-v="56" data-xref="约书亚记 15:13; 约书亚记 14:13"> 只是属城的田地和村庄都为耶孚尼的儿子迦勒所得。</span>
<span className="v" id="v57" data-v="57" data-xref="约书亚记 21:13–14; 约书亚记 15:48; 约书亚记 10:29"> 亚伦的子孙得了逃城希伯仑，又得了立拿与其郊野，雅提珥，以实提莫与其郊野，</span>
<span className="v" id="v58" data-v="58" data-xref="约书亚记 10:3; 约书亚记 15:49; 约书亚记 12:13"> 希仑与其郊野，底璧与其郊野，</span>
<span className="v" id="v59" data-v="59" data-xref="约书亚记 21:16; 约书亚记 15:42; 撒母耳记上 6:12–19"> 亚珊与其郊野，伯示麦与其郊野。</span>
<span className="v" id="v60" data-v="60" data-xref="耶利米书 1:1; 列王纪上 2:26; 耶利米书 11:23"> 在便雅悯支派的地中得了迦巴与其郊野，阿勒篾与其郊野，亚拿突与其郊野。他们诸家所得的城共十三座。</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61" data-xref="约书亚记 21:4–5; 历代志上 6:18; 约书亚记 21:20–26"> 哥辖族其余的人又拈阄，在玛拿西半支派的地中得了十座城。</span>
<span className="v" id="v62" data-v="62" data-xref="约书亚记 21:27–33; 历代志上 6:71–76; 出埃及记 2:22"> 革顺族按着宗族，在以萨迦支派的地中、亚设支派的地中、拿弗他利支派的地中、巴珊内玛拿西支派的地中得了十三座城。</span>
<span className="v" id="v63" data-v="63" data-xref="约书亚记 21:7; 约书亚记 21:34–40; 民数记 3:20"> 米拉利族按着宗族拈阄，在鲁本支派的地中、迦得支派的地中、西布伦支派的地中得了十二座城。</span>
<span className="v" id="v64" data-v="64" data-xref="约书亚记 21:41–42; 约书亚记 21:3; 民数记 35:1–8"> 以色列人将这些城与其郊野给了利未人。</span>
<span className="v" id="v65" data-v="65" data-xref="历代志上 6:57–60"> 这以上录名的城，在犹大、西缅、便雅悯三支派的地中，以色列人拈阄给了他们。</span>
</div>
<div className="bp">
<span className="v" id="v66" data-v="66" data-xref="约书亚记 21:20–26"> 哥辖族中有几家在以法莲支派的地中也得了城邑，</span>
<span className="v" id="v67" data-v="67" data-xref="约书亚记 21:21; 创世记 33:18; 创世记 35:4"> 在以法莲山地得了逃城示剑与其郊野，又得了基色与其郊野，</span>
<span className="v" id="v68" data-v="68" data-xref="约书亚记 21:22; 约书亚记 16:5; 撒母耳记上 13:18"> 约缅与其郊野，伯和仑与其郊野，</span>
<span className="v" id="v69" data-v="69" data-xref="约书亚记 10:12; 约书亚记 21:24–25"> 亚雅仑与其郊野，迦特临门与其郊野。</span>
<span className="v" id="v70" data-v="70" data-xref="约书亚记 21:25; 约书亚记 17:11"> 哥辖族其余的人在玛拿西半支派的地中得了亚乃与其郊野，比连与其郊野。</span>
</div>
<div className="bp">
<span className="v" id="v71" data-v="71" data-xref="约书亚记 21:27; 约书亚记 9:10; 约书亚记 20:8"> 革顺族在玛拿西半支派的地中得了巴珊的哥兰与其郊野，亚斯他录与其郊野；</span>
<span className="v" id="v72" data-v="72" data-xref="约书亚记 21:28–29; 约书亚记 21:32; 约书亚记 19:37"> 又在以萨迦支派的地中得了基低斯与其郊野，大比拉与其郊野，</span>
<span className="v" id="v73" data-v="73"> 拉末与其郊野，亚年与其郊野；</span>
<span className="v" id="v74" data-v="74" data-xref="约书亚记 19:26; 约书亚记 21:30"> 在亚设支派的地中得了玛沙与其郊野，押顿与其郊野，</span>
<span className="v" id="v75" data-v="75" data-xref="约书亚记 21:31"> 户割与其郊野，利合与其郊野；</span>
<span className="v" id="v76" data-v="76" data-xref="约书亚记 21:32; 约书亚记 19:37; 士师记 4:6"> 在拿弗他利支派的地中得了加利利的基低斯与其郊野，哈们与其郊野，基列亭与其郊野。</span>
</div>
<div className="bp">
<span className="v" id="v77" data-v="77" data-xref="约书亚记 21:34–35"> 还有米拉利族的人，在西布伦支派的地中得了临摩挪与其郊野，他泊与其郊野；</span>
<span className="v" id="v78" data-v="78" data-xref="约书亚记 20:8; 约书亚记 21:36–37; 申命记 4:41–43"> 又在耶利哥的约旦河东，在鲁本支派的地中得了旷野的比悉与其郊野，雅哈撒与其郊野，</span>
<span className="v" id="v79" data-v="79"> 基底莫与其郊野，米法押与其郊野；</span>
<span className="v" id="v80" data-v="80" data-xref="创世记 32:2; 列王纪下 9:1; 约书亚记 21:38–39"> 又在迦得支派的地中得了基列的拉末与其郊野，玛哈念与其郊野，</span>
<span className="v" id="v81" data-v="81" data-xref="约书亚记 21:39; 民数记 21:32; 民数记 32:3"> 希实本与其郊野，雅谢与其郊野。</span>
</div>
</div>

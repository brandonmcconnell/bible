## 承认神之国乃历世永存

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="但以理书 6:25; 彼得前书 1:2; 但以理书 3:4"> 尼布甲尼撒王晓谕住在全地各方、各国、各族的人说：愿你们大享平安！</span>
<span className="v" id="v2" data-v="2" data-xref="但以理书 3:26; 诗篇 66:16; 诗篇 71:18"> 我乐意将至高的神向我所行的神迹奇事宣扬出来。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 145:13; 以赛亚书 25:1; 但以理书 2:44"> <span className="pl pl-1">他的神迹何其大，</span><br /><span className="pl pl-1">他的奇事何其盛！</span><br /><span className="pl pl-1">他的国是永远的，</span><br /><span className="pl pl-1">他的权柄存到万代！</span></span>
</div>
</div>

## 尼布甲尼撒王自述得梦术士不能详解

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 47:7–8; 帖撒罗尼迦前书 5:2–3; 诗篇 30:6–7"> 我尼布甲尼撒安居在宫中，平顺在殿内。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 2:1; 约伯记 7:13–14; 但以理书 2:28–29"> 我做了一梦，使我惧怕，我在床上的思念并脑中的异象使我惊惶。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理书 2:2; 创世记 41:7–8; 以赛亚书 8:19"> 所以我降旨召巴比伦的一切哲士到我面前，叫他们把梦的讲解告诉我。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 44:25; 但以理书 2:7; 创世记 41:8"> 于是那些术士、用法术的、迦勒底人、观兆的都进来，我将那梦告诉了他们，他们却不能把梦的讲解告诉我。</span>
</div>
</div>

## 以梦告但以理

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="但以理书 1:7; 但以理书 5:14; 但以理书 4:18"> 末后那照我神的名称为伯提沙撒的但以理来到我面前，他里头有圣神的灵。我将梦告诉他说：</span>
<span className="v" id="v9" data-v="9" data-xref="但以理书 2:48; 但以理书 5:11; 但以理书 4:8"> “术士的领袖伯提沙撒啊，因我知道你里头有圣神的灵，什么奥秘的事都不能使你为难，现在要把我梦中所见的异象和梦的讲解告诉我。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 12:2; 但以理书 4:5; 诗篇 37:35–36"> 我在床上脑中的异象是这样：我看见地当中有一棵树，极其高大。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 4:21–22; 申命记 9:1; 马太福音 11:23"> 那树渐长，而且坚固，高得顶天，从地极都能看见。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 13:19; 耶利米哀歌 4:20; 以西结书 31:6–7"> 叶子华美，果子甚多，可做众生的食物。田野的走兽卧在荫下，天空的飞鸟宿在枝上，凡有血气的都从这树得食。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 33:2; 但以理书 8:13; 但以理书 7:1"> 我在床上脑中的异象，见有一位守望的圣者从天而降，</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 3:10; 但以理书 4:23; 以西结书 31:12–13"> 大声呼叫说：‘伐倒这树，砍下枝子，摇掉叶子，抛散果子，使走兽离开树下，飞鸟躲开树枝。</span>
<span className="v" id="v15" data-v="15" data-xref="约伯记 14:7–9; 但以理书 4:25–27; 以西结书 29:14–15"> 树𣎴却要留在地内，用铁圈和铜圈箍住，在田野的青草中让天露滴湿，使他与地上的兽一同吃草。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理书 4:23; 启示录 12:14; 但以理书 4:25"> 使他的心改变，不如人心，给他一个兽心，使他经过七期<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“期”或作“年”，本章同。">a</a></sup>。</span>
<span className="v" id="v17" data-v="17" data-xref="但以理书 4:25; 但以理书 2:21; 诗篇 75:6–7"> 这是守望者所发的命，圣者所出的令，好叫世人知道至高者在人的国中掌权，要将国赐予谁就赐予谁，或立极卑微的人执掌国权。’</span>
<span className="v" id="v18" data-v="18" data-xref="但以理书 5:15; 创世记 41:8; 但以理书 5:8"> 这是我尼布甲尼撒王所做的梦。伯提沙撒啊，你要说明这梦的讲解，因为我国中的一切哲士都不能将梦的讲解告诉我，唯独你能，因你里头有圣神的灵。”</span>
</div>
</div>

## 但以理为王解梦

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="但以理书 8:27; 但以理书 7:28; 但以理书 4:24"> 于是称为伯提沙撒的但以理惊讶片时，心意惊惶。王说：“伯提沙撒啊，不要因梦和梦的讲解惊惶。”伯提沙撒回答说：“我主啊，愿这梦归于恨恶你的人，讲解归于你的敌人！</span>
<span className="v" id="v20" data-v="20" data-xref="但以理书 4:10–12; 以西结书 31:3; 以西结书 31:16"> 你所见的树渐长，而且坚固，高得顶天，从地极都能看见。</span>
<span className="v" id="v21" data-v="21"> 叶子华美，果子甚多，可做众生的食物。田野的走兽住在其下，天空的飞鸟宿在枝上。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理书 2:37–38; 撒母耳记下 12:7; 耶利米书 27:6–8"> 王啊，这渐长又坚固的树就是你。你的威势渐长及天，你的权柄管到地极。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理书 5:21; 但以理书 4:13–16"> 王既看见一位守望的圣者从天而降，说：‘将这树砍伐毁坏，树𣎴却要留在地内，用铁圈和铜圈箍住，在田野的青草中，让天露滴湿，使他与地上的兽一同吃草，直到经过七期。’</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 107:40; 约伯记 40:11–12; 以赛亚书 46:10–11"> 王啊，讲解就是这样：临到我主我王的事是出于至高者的命。</span>
<span className="v" id="v25" data-v="25" data-xref="但以理书 4:17; 耶利米书 27:5; 诗篇 83:18"> 你必被赶出离开世人，与野地的兽同居，吃草如牛，被天露滴湿，且要经过七期，等你知道至高者在人的国中掌权，要将国赐予谁就赐予谁。</span>
<span className="v" id="v26" data-v="26" data-xref="但以理书 4:15; 马太福音 5:34; 马太福音 21:20"> 守望者既吩咐存留树𣎴，等你知道诸天掌权，以后你的国必定归你。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 55:6–7; 约拿书 3:9; 使徒行传 8:22"> 王啊，求你悦纳我的谏言，以施行公义断绝罪过，以怜悯穷人除掉罪孽，或者你的平安可以延长。”</span>
</div>
</div>

## 梦兆应于王身

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="民数记 23:19; 撒迦利亚书 1:6; 箴言 10:24"> 这事都临到尼布甲尼撒王。</span>
<span className="v" id="v29" data-v="29" data-xref="启示录 2:21; 传道书 8:11; 彼得前书 3:20"> 过了十二个月，他游行在巴比伦王宫里<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文作：上。">b</a></sup>，</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 16:18; 启示录 18:10; 路加福音 14:11"> 他说：“这大巴比伦不是我用大能大力建为京都，要显我威严的荣耀吗？”</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 9:3–5; 启示录 16:7; 路加福音 12:20"> 这话在王口中尚未说完，有声音从天降下，说：“尼布甲尼撒王啊，有话对你说：你的国位离开你了！</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 27:5; 但以理书 5:21; 箴言 8:15–16"> 你必被赶出离开世人，与野地的兽同居，吃草如牛，且要经过七期，等你知道至高者在人的国中掌权，要将国赐予谁就赐予谁。”</span>
<span className="v" id="v33" data-v="33" data-xref="但以理书 4:32; 但以理书 4:25; 但以理书 5:5"> 当时这话就应验在尼布甲尼撒的身上，他被赶出离开世人，吃草如牛，身被天露滴湿，头发长长好像鹰毛，指甲长长如同鸟爪。</span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="启示录 4:10; 耶利米书 10:10; 但以理书 12:7"> 日子满足，我尼布甲尼撒举目望天，我的聪明复归于我，我便称颂至高者，赞美、尊敬活到永远的神。<br /><span className="pl pl-1">他的权柄是永有的，</span><br /><span className="pl pl-1">他的国存到万代。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="约伯记 42:2; 诗篇 135:6; 诗篇 115:3"> <span className="pl pl-1">世上所有的居民都算为虚无，</span><br /><span className="pl pl-1">在天上的万军和世上的居民中，</span><br /><span className="pl pl-1">他都凭自己的意旨行事。</span><br /><span className="pl pl-1">无人能拦住他手，</span><br /><span className="pl pl-1">或问他说：“你做什么呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="但以理书 4:34; 箴言 22:4; 但以理书 4:15–16"> 那时，我的聪明复归于我，为我国的荣耀，威严和光耀也都复归于我，并且我的谋士和大臣也来朝见我。我又得坚立在国位上，至大的权柄加增于我。</span>
<span className="v" id="v37" data-v="37" data-xref="雅各书 4:6–7; 诗篇 33:4–5; 彼得前书 5:5–6"> 现在我尼布甲尼撒赞美、尊崇、恭敬天上的王，因为他所做的全都诚实，他所行的也都公平，那行动骄傲的，他能降为卑。</span>
</div>
</div>

## 尼布甲尼撒王得梦遗忘迫令术士告之

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理书 4:5; 以斯帖记 6:1; 约伯记 33:15–17"> 尼布甲尼撒在位第二年，他做了梦，心里烦乱，不能睡觉。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理书 1:20; 但以理书 4:6; 创世记 41:8"> 王吩咐人将术士、用法术的、行邪术的和迦勒底人召来，要他们将王的梦告诉王，他们就来站在王前。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 40:8; 创世记 41:15; 但以理书 4:5"> 王对他们说：“我做了一梦，心里烦乱，要知道这是什么梦。”</span>
<span className="v" id="v4" data-v="4" data-xref="但以理书 3:9; 但以理书 5:10; 以斯拉记 4:7"> 迦勒底人用亚兰的言语对王说：“愿王万岁！请将那梦告诉仆人，仆人就可以讲解。”</span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 3:29; 以斯拉记 6:11; 列王纪下 10:27"> 王回答迦勒底人说：“梦我已经忘了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：我已定命。8节同。">a</a></sup>，你们若不将梦和梦的讲解告诉我，就必被凌迟，你们的房屋必成为粪堆。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理书 5:7; 但以理书 2:48; 但以理书 5:29"> 你们若将梦和梦的讲解告诉我，就必从我这里得赠品和赏赐并大尊荣。现在你们要将梦和梦的讲解告诉我。”</span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 2:4; 但以理书 2:9; 传道书 10:4"> 他们第二次对王说：“请王将梦告诉仆人，仆人就可以讲解。”</span>
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 4:5; 以弗所书 5:16"> 王回答说：“我准知道你们是故意迟延，因为你们知道那梦我已经忘了。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 41:23; 但以理书 7:25; 以斯帖记 4:11"> 你们若不将梦告诉我，只有一法待你们。因为你们预备了谎言乱语向我说，要等候时势改变。现在你们要将梦告诉我，因我知道你们能将梦的讲解告诉我。”</span>
</div>
</div>

## 术士回奏无人能告

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="但以理书 2:27"> 迦勒底人在王面前回答说：“世上没有人能将王所问的事说出来。因为没有君王、大臣、掌权的向术士，或用法术的，或迦勒底人问过这样的事。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 5:11; 以赛亚书 57:15; 创世记 41:39"> 王所问的事甚难，除了不与世人同居的神明，没有人在王面前能说出来。”</span>
</div>
</div>

## 王怒拟歼灭之

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="但以理书 3:13; 马太福音 2:16; 但以理书 3:19"> 因此，王气愤愤地大发烈怒，吩咐灭绝巴比伦所有的哲士。</span>
<span className="v" id="v13" data-v="13" data-xref="但以理书 1:19–20; 以斯帖记 3:12–15; 以赛亚书 10:1"> 于是命令发出，哲士将要见杀，人就寻找但以理和他的同伴，要杀他们。</span>
</div>
</div>

## 但以理求宽限

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="但以理书 2:24; 耶利米书 52:12; 撒母耳记下 20:16–22"> 王的护卫长亚略出来，要杀巴比伦的哲士，但以理就用婉言回答他，</span>
<span className="v" id="v15" data-v="15"> 向王的护卫长亚略说：“王的命令为何这样紧急呢？”亚略就将情节告诉但以理。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理书 1:18–19; 但以理书 2:9–11"> 但以理遂进去求王宽限，就可以将梦的讲解告诉王。</span>
</div>
</div>

## 与同侪祷主蒙示以王梦与兆

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="但以理书 1:6–7; 但以理书 3:12; 但以理书 1:11"> 但以理回到他的居所，将这事告诉他的同伴哈拿尼雅、米沙利、亚撒利雅，</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 33:3; 马太福音 18:19; 马太福音 18:12"> 要他们祈求天上的神施怜悯，将这奥秘的事指明，免得但以理和他的同伴与巴比伦其余的哲士一同灭亡。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 12:6; 阿摩司书 3:7; 但以理书 7:7"> 这奥秘的事就在夜间异象中给但以理显明，但以理便称颂天上的神。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 113:2; 诗篇 145:1–2; 启示录 5:12"> 但以理说：“神的名是应当称颂的，从亘古直到永远！因为智慧能力都属乎他。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 75:5–7; 诗篇 31:14–15; 诗篇 113:7–8"> 他改变时候、日期，废王、立王，将智慧赐予智慧人，将知识赐予聪明人。</span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 12:22; 约翰一书 1:5; 耶利米书 23:24"> 他显明深奥隐秘的事，知道暗中所有的，光明也与他同居。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理书 2:18; 出埃及记 3:15; 但以理书 2:29–30"> 我列祖的神啊，我感谢你，赞美你！因你将智慧、才能赐给我，允准我们所求的，把王的事给我们指明。”</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 27:24; 但以理书 2:12–14"> 于是但以理进去见亚略，就是王所派灭绝巴比伦哲士的，对他说：“不要灭绝巴比伦的哲士，求你领我到王面前，我要将梦的讲解告诉王。”</span>
</div>
</div>

## 但以理觐王

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="哥林多前书 1:27–28; 但以理书 6:13; 但以理书 5:13"> 亚略就急忙将但以理领到王面前，对王说：“我在被掳的犹大人中遇见一人，他能将梦的讲解告诉王。”</span>
<span className="v" id="v26" data-v="26" data-xref="但以理书 1:7; 但以理书 5:16; 但以理书 5:12"> 王问称为伯提沙撒的但以理说：“你能将我所做的梦和梦的讲解告诉我吗？”</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 47:12–14; 但以理书 2:2; 以赛亚书 44:25"> 但以理在王面前回答说：“王所问的那奥秘事，哲士、用法术的、术士、观兆的都不能告诉王。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 40:8; 阿摩司书 4:13; 但以理书 10:14"> 只有一位在天上的神能显明奥秘的事，他已将日后必有的事指示尼布甲尼撒王。你的梦和你在床上脑中的异象是这样：</span>
<span className="v" id="v29" data-v="29" data-xref="但以理书 2:28; 阿摩司书 4:13; 但以理书 2:47"> 王啊，你在床上想到后来的事，那显明奥秘事的主把将来必有的事指示你。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 41:16; 使徒行传 3:12; 但以理书 2:17–18"> 至于那奥秘的事显明给我，并非因我的智慧胜过一切活人，乃为使王知道梦的讲解和心里的思念。</span>
</div>
</div>

## 述王之梦

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="哈巴谷书 1:7; 以西结书 28:7; 但以理书 7:3–17"> “王啊，你梦见一个大像，这像甚高，极其光耀，站在你面前，形状甚是可怕。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 51:7; 但以理书 7:4–6; 启示录 17:4"> 这像的头是精金的，胸膛和膀臂是银的，肚腹和腰是铜的，</span>
<span className="v" id="v33" data-v="33" data-xref="但以理书 7:19–26; 但以理书 7:7–8; 但以理书 2:40–43"> 腿是铁的，脚是半铁半泥的。</span>
<span className="v" id="v34" data-v="34" data-xref="但以理书 2:44–45; 但以理书 8:25; 撒迦利亚书 12:3"> 你观看，见有一块非人手凿出来的石头打在这像半铁半泥的脚上，把脚砸碎。</span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 2:2–3; 诗篇 37:10; 启示录 20:11"> 于是金、银、铜、铁、泥都一同砸得粉碎，成如夏天禾场上的糠秕，被风吹散，无处可寻。打碎这像的石头变成一座大山，充满天下。</span>
</div>
</div>

## 详解梦兆

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="但以理书 2:23–24"> “这就是那梦，我们在王面前要讲解那梦。</span>
<span className="v" id="v37" data-v="37" data-xref="以西结书 26:7; 耶利米书 27:6–7; 以斯拉记 7:12"> 王啊，你是诸王之王，天上的神已将国度、权柄、能力、尊荣都赐给你。</span>
<span className="v" id="v38" data-v="38" data-xref="但以理书 4:21–22; 诗篇 50:10–11; 耶利米书 27:5–7"> 凡世人所住之地的走兽，并天空的飞鸟，他都交付你手，使你掌管这一切，你就是那金头。</span>
<span className="v" id="v39" data-v="39" data-xref="但以理书 5:28–31; 以赛亚书 44:28–5; 但以理书 2:32"> 在你以后必另兴一国，不及于你。又有第三国，就是铜的，必掌管天下。</span>
<span className="v" id="v40" data-v="40" data-xref="但以理书 7:7; 但以理书 7:19–26; 但以理书 11:36–45"> 第四国，必坚壮如铁，铁能打碎克制百物，又能压碎一切，那国也必打碎压制列国。</span>
<span className="v" id="v41" data-v="41" data-xref="启示录 17:12; 但以理书 2:33–35; 启示录 12:3"> 你既见像的脚和脚指头一半是窑匠的泥，一半是铁，那国将来也必分开。你既见铁与泥掺杂，那国也必有铁的力量。</span>
<span className="v" id="v42" data-v="42" data-xref="但以理书 7:24; 启示录 13:1"> 那脚指头既是半铁半泥，那国也必半强半弱。</span>
<span className="v" id="v43" data-v="43"> 你既见铁与泥掺杂，那国民也必与各种人掺杂，却不能彼此相合，正如铁与泥不能相合一样。</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 28:18; 路加福音 1:32–33; 但以理书 6:26"> 当那列王在位的时候，天上的神必另立一国，永不败坏，也不归别国的人，却要打碎灭绝那一切国，这国必存到永远。</span>
<span className="v" id="v45" data-v="45" data-xref="以赛亚书 28:16; 创世记 41:32; 申命记 10:17"> 你既看见非人手凿出来的一块石头从山而出，打碎金、银、铜、铁、泥，那就是至大的神把后来必有的事给王指明。这梦准是这样，这讲解也是确实的。”</span>
</div>
</div>

## 王尊崇但以理加以重赉

<div className="bt">
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="使徒行传 10:25; 使徒行传 14:13; 以斯拉记 6:10"> 当时尼布甲尼撒王俯伏在地，向但以理下拜，并且吩咐人给他奉上供物和香品。</span>
<span className="v" id="v47" data-v="47" data-xref="但以理书 2:22; 但以理书 2:28; 阿摩司书 3:7"> 王对但以理说：“你既能显明这奥秘的事，你们的神诚然是万神之神，万王之主，又是显明奥秘事的。”</span>
<span className="v" id="v48" data-v="48" data-xref="但以理书 2:6; 但以理书 4:9; 但以理书 5:11"> 于是王高抬但以理，赏赐他许多上等礼物，派他管理巴比伦全省，又立他为总理，掌管巴比伦的一切哲士。</span>
<span className="v" id="v49" data-v="49" data-xref="但以理书 1:7; 以斯帖记 2:19; 但以理书 3:12–30"> 但以理求王，王就派沙得拉、米煞、亚伯尼歌管理巴比伦省的事务，只是但以理常在朝中侍立。</span>
</div>

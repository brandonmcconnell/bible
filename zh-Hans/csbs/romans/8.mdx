<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 3:18–19; 哥林多后书 5:17; 加拉太书 3:13"> 所以现在，那些在基督耶稣里的人，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附“就是那些不顺着肉体却顺着圣灵而行走的人，”。">a</a></sup>就不被定罪了，</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 6:14; 哥林多后书 3:17; 罗马书 6:18"> 因为圣灵的生命法则，在基督耶稣里把你<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="你——有古抄本作“我”。">b</a></sup>从罪和死的法则中释放了出来。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 13:39; 加拉太书 4:4–5; 希伯来书 7:18–19"> 因肉体软弱的缘故，律法所做不到的，神却做到了<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="神却做到了——辅助词语。">c</a></sup>——神派遣了自己的儿子成为罪的肉身样式，并且为了赎罪，用肉身判决了罪，</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 5:16; 加拉太书 5:22–25; 歌罗西书 1:22"> 使律法的公义规定，成全在我们这些不顺着肉体却顺着圣灵行走的人身上。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 2:14; 加拉太书 5:19–25; 约翰福音 3:6"> 要知道，顺着肉体的人，思想属肉体的事；顺着圣灵的人，思想属圣灵的事。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 6:8; 罗马书 8:7; 罗马书 8:13"> 属肉体的思想带来死亡；属圣灵的思想带来生命和平安。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 2:14; 约翰一书 2:15–16; 雅各书 4:4"> 原来属肉体的思想是敌对神的，因为它不服从神的律法，其实也不能服从；</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 3:5–6; 希伯来书 11:5–6; 罗马书 8:9"> 并且，属肉体的人无法得到神的喜悦。</span>
<span className="v" id="v9" data-v="9" data-xref="加拉太书 4:6; 哥林多前书 3:16; 提摩太后书 1:14"> 但既然神的灵真是住在你们里面，你们就不属于肉体，而属于圣灵了。不过如果有人没有基督的灵，这个人就不属于基督了。</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 3:17; 加拉太书 2:20; 哥林多后书 5:21"> 但如果基督在你们里面，那么，你们的身体虽然因罪是死的<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="是死的——或译作“要死”。">d</a></sup>，灵却因义是活的<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="灵却因义是活的——或译作“圣灵却因义赐生命”。">e</a></sup>；</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 4:14; 罗马书 6:4–5; 哥林多后书 4:11"> 不但如此，使耶稣从死人中复活的那一位——他的灵如果住在你们里面，那么，使基督从死人中复活的那一位，也将藉着<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="藉着——有古抄本作“因为”。">f</a></sup>住在你们里面的圣灵，使你们会死的身体得着生命。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="罗马书 6:2–15; 哥林多前书 6:19–20; 彼得前书 4:2–3"> 弟兄们，由此可见，我们都是有责任<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有责任——原文直译“欠债”。">g</a></sup>的，但不是对肉体有责任去顺着肉体而活；</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太书 6:8; 彼得前书 2:11; 哥林多前书 9:27"> 因为你们如果顺着肉体而活，就将死去；但如果顺着圣灵治死身体的所作所为，就将活着。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 5:18; 约翰福音 1:12; 加拉太书 3:26"> 原来，凡是蒙神的灵带领的人，他们才是神的儿女。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 4:5–7; 提摩太后书 1:7; 哥林多前书 2:12"> 就是说，你们所领受的不是一个奴役的灵，使你们再有惧怕；相反，你们所领受的是使你们有儿子名份的圣灵——藉着他，我们呼叫：“阿爸！父啊！”</span>
<span className="v" id="v16" data-v="16" data-xref="约翰一书 4:13; 哥林多后书 1:22; 哥林多后书 5:5"> 圣灵亲自与我们的灵一同作证：我们是神的儿女。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 4:7; 加拉太书 3:29; 以弗所书 3:6"> 既然是儿女，也就是继承人；如果我们真是为了与他一同得荣耀而与他一同受苦，我们就是神的继承人，而且与基督同做继承人。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 4:17–18; 彼得前书 4:13; 彼得前书 1:5–7"> 事实上，我认为现今时刻的苦难，与将来要显明给我们的荣耀，是无法相比的。</span>
<span className="v" id="v19" data-v="19" data-xref="玛拉基书 3:17–18; 罗马书 8:23; 约翰一书 3:2"> 被造之物都热切盼望、热切等待着神的儿女显现出来，</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 3:17–19; 创世记 5:29; 罗马书 8:22"> 因为被造之物屈从在虚妄之下，并不是出于自愿，而是出于使它屈从的那一位；</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 22:3–5; 使徒行传 3:21; 彼得后书 3:13"> 被造之物自己也盼望着从使之衰朽<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="衰朽——或译作“败坏”。">h</a></sup>的奴役中得到释放，归入神儿女荣耀的自由。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 12:4; 耶利米书 12:11; 约翰福音 16:21"> 我们知道，所有被造之物都一同呻吟、同受阵痛，直到如今。</span>
<span className="v" id="v23" data-v="23" data-xref="腓立比书 3:20–21; 哥林多后书 5:2–5; 希伯来书 9:28"> 不仅如此，连我们这些有圣灵为初熟果子的人，也在自己里面呻吟叹息，热切等待得到儿子的名份<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本没有“得到儿子的名份”。">i</a></sup>，就是等待我们的身体得蒙救赎。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 5:7; 希伯来书 11:1; 哥林多后书 4:18"> 因为我们得救在于这盼望。然而，看得见的盼望，就不是盼望了；谁会盼望自己所看得见的呢？</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 12:12; 希伯来书 10:36; 诗篇 27:14"> 但如果我们盼望那看不见的，就要藉着忍耐来热切等待。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 10:20; 以弗所书 6:18; 加拉太书 4:6"> 况且，圣灵也照样扶助我们的软弱。事实上，我们不知道该祷告什么、如何祷告，但圣灵却亲自用说不出的叹息，为我们<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本没有“为我们”。">j</a></sup>代求。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 17:10; 约翰一书 5:14–15; 以弗所书 2:18"> 而且，洞察人心的那一位，知道圣灵的意念是什么，因为圣灵是按神的意思<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="的意思——辅助词语。">k</a></sup>为圣徒代求的。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="彼得前书 5:10; 雅各书 1:12; 创世记 50:20"> 我们也知道，神使万事相辅相成<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="神使万事相辅相成——或译作“万事相辅相成”。">l</a></sup>，是为了爱神之人的益处，就是那些按照他的心意蒙召之人的益处。</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所书 1:4–5; 耶利米书 1:5; 以弗所书 1:11"> 因为神预先所知道的人，神也预先定下他们和他儿子的形像相似，使他儿子在众多弟兄中做长子<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="长子——原文直译“首生者”。">m</a></sup>；</span>
<span className="v" id="v30" data-v="30" data-xref="启示录 17:14; 罗马书 8:28; 以弗所书 1:11"> 而且，神预先所定下的人，神又召他们来；所召来的人，又称他们为义；所称为义的人，又使他们得荣耀。</span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="诗篇 118:6; 耶利米书 1:19; 诗篇 56:11"> <span className="pl pl-1">那么，对这些事我们要怎么说呢？</span><br /><span className="pl pl-1">神如果支持我们，谁还能反对我们呢？</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 3:16; 罗马书 8:28; 诗篇 84:11"> <span className="pl pl-1">神既然没有顾惜自己的儿子，</span><br /><span className="pl pl-1">为我们所有的人舍弃了他，</span><br /><span className="pl pl-1">难道不会把万有也连同他一起赐给我们吗？</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="启示录 12:10–11; 以赛亚书 50:8–9; 以赛亚书 54:17"> <span className="pl pl-1">到底谁能控告那些蒙神拣选的人呢？</span><br /><span className="pl pl-1">神是称人为义的那一位！</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="希伯来书 7:25; 罗马书 8:27; 希伯来书 9:24"> <span className="pl pl-1">到底谁能定我们的罪呢？</span><br /><span className="pl pl-1">基督耶稣是已经死了的那一位——</span><br /><span className="pl pl-1">但更要说，他已经复活了，</span><br /><span className="pl pl-1">而且现今在神的右边，还为我们代求！</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="约翰福音 10:28; 诗篇 103:17; 约翰福音 16:33"> <span className="pl pl-1">到底谁能使我们与基督</span><sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="基督——有古抄本作“神”。">n</a></sup><br /><span className="pl pl-1">的爱分开呢？</span><br /><span className="pl pl-1">难道是患难吗？是困苦吗？是逼迫吗？</span><br /><span className="pl pl-1">是饥饿吗？是赤身吗？是危险吗？是刀剑吗？</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="诗篇 44:22; 以赛亚书 53:7; 哥林多前书 15:30"> <span className="pl pl-1">正如经上所记：</span><br /><span className="pl pl-1">“为你的缘故，我们终日被置于死地，</span><br /><span className="pl pl-1">被看为要宰杀的羊。”</span><br /></span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前书 15:57; 约翰一书 4:4; 哥林多后书 2:14"> <span className="pl pl-1">然而，靠着爱我们的那一位，</span><br /><span className="pl pl-1">我们在这一切事上已经得胜有余了。</span><br /></span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 10:28; 罗马书 14:8; 提摩太后书 1:12"> <span className="pl pl-1">事实上，我深信：</span><br /><span className="pl pl-1">无论是死、是生、</span><br /><span className="pl pl-1">是天使、是统治者、</span><br /><span className="pl pl-1">是现在的事、是将来的事、是有势力的、</span><br /></span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 10:28–30; 罗马书 8:35; 罗马书 5:8"> <span className="pl pl-1">是高处的、是深处的，或是任何别的被造之物，</span><br /><span className="pl pl-1">都不能使我们与神的爱分开，</span><br /><span className="pl pl-1">这爱是在我们主基督耶稣里的。</span></span>
</div>
</div>

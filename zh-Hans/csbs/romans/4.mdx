<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 51:2; 罗马书 4:16; 哥林多后书 11:22"> 那么，我们说我们肉体上的先祖亚伯拉罕得到了什么呢？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 1:31; 哥林多后书 11:30; 腓立比书 3:9"> 事实上，如果亚伯拉罕本于行为被称为义，他就有可夸耀的；然而在神面前他并没有可夸耀的。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 15:6; 雅各书 2:23; 加拉太书 3:6–8"> 经上到底是怎么说的呢？<br /><span className="pl pl-1">“亚伯拉罕信神，</span><br /><span className="pl pl-1">这就被算为他的义。”</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="罗马书 11:6; 罗马书 9:32; 罗马书 11:35"> 做工的人得工钱，不算是恩典，而是应得的；</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 3:9; 罗马书 3:22; 提多书 3:3–7"> 但是，一个人虽没有做工，却信靠那称不敬虔之人为义的神，这人的信就被算为义。</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="提摩太后书 1:9; 腓立比书 3:9; 哥林多前书 1:30"> 正如大卫也论到神所算为义之人的福份，这义与行为无关；他说：</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 32:1–2; 诗篇 130:3–4; 路加福音 7:47–50"> <span className="pl pl-1">“罪恶</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="罪恶——原文直译“不法”。">a</a></sup><br /><span className="pl pl-1">被赦免、</span><br /><span className="pl pl-1">罪孽被遮盖的人，</span><br /><span className="pl pl-1">这人是蒙福的。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 32:2; 彼得前书 2:24; 哥林多后书 5:19–20"> <span className="pl pl-1">主绝不算为有罪的，</span><br /><span className="pl pl-1">这人是蒙福的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="加拉太书 3:14; 歌罗西书 3:11; 加拉太书 3:26–28"> 既然如此，这福份到底是只赐给那些受割礼的人，还是也赐给那些没有受割礼的人呢？我们说：“亚伯拉罕因着信，就被算为义了。”</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 6:15; 加拉太书 5:6; 创世记 17:10"> 那么，是怎么被算为义的呢？到底是在他受割礼之后，还是在他没有受割礼的时候呢？不是在受割礼之后，而是在没有受割礼的时候。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 3:22; 路加福音 19:9; 哥林多后书 1:22"> 并且他领受了割礼的标记，做为他没有受割礼时因信称义的印证，使他成为所有不凭着割礼而信之人的父，也使他们被算为义；</span>
<span className="v" id="v12" data-v="12" data-xref="雅歌 1:8; 约翰福音 8:39–40; 箴言 2:20"> 而且他也成为受割礼之人的父，不仅为那些受了割礼的人，还为那些顺着我们的先祖亚伯拉罕信心之脚踪行走的人；亚伯拉罕的信心在他没有受割礼的时候就已经有了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="加拉太书 3:29; 创世记 22:17–18; 创世记 28:14"> 原来，赐给亚伯拉罕和他后裔继承世界的应许，不是藉着律法，而是藉着因信而得的义。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 3:18–24; 腓立比书 3:9; 罗马书 4:16"> 这是因为，如果本于律法的才是继承人，信就落了空，应许也就无效了。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 5:13; 加拉太书 3:10; 罗马书 3:19–20"> 事实上，律法带来了震怒，所以哪里没有律法，哪里也就没有过犯。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="罗马书 3:24–26; 以弗所书 2:8; 加拉太书 3:22"> 为此，这应许是本于信，好使这应许照着恩典，能确保给所有的后裔——不仅是给属律法的，也是给属亚伯拉罕信心的。亚伯拉罕在神面前是我们每个人的父，</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 1:28; 创世记 17:4–5; 约翰福音 5:21"> 正如经上所记：“我已经指派你为众多民族的父。”亚伯拉罕所信的那一位，就是叫死人得生命、使无变为有的神。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 8:24; 创世记 15:5–6; 使徒行传 27:25"> 亚伯拉罕在没有盼望的时候，仍然怀着盼望去相信，因而成为众多民族的父，正如先前所说：“你的后裔将要如此众多<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="众多——辅助词语。">b</a></sup>。”</span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 11:11–19; 罗马书 4:20–21; 创世记 17:17"> 他快到一百岁的时候，想到自己的身体如同<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="如同——辅助词语。">c</a></sup>已经死了，又想到撒拉也已经不能生育，但是他的信仰却没有软弱。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 1:45; 哥林多前书 16:13; 但以理书 10:19"> 他也没有因着不信去怀疑神的应许，反而因着信得以刚强，把荣耀归给神，</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:37; 耶利米书 32:27; 创世记 18:14"> 并且确信不疑：神所应许的，神也能成就。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 4:6; 罗马书 4:3"> 因此，这就被算为他的义了。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 10:11; 罗马书 15:4; 哥林多前书 10:6"> 不但如此，“被算为他的义”这句话不仅是为亚伯拉罕写的，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 2:24; 彼得前书 1:21; 使徒行传 13:30"> 也是为我们写的；我们信靠使我们的主耶稣从死人中复活的那一位，就将被算为义。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰一书 4:9–10; 以赛亚书 53:5–6; 哥林多后书 5:21"> 主耶稣被交出去，是为了我们的过犯；复活，是为了我们称义。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 6:14; 罗马书 7:6; 罗马书 6:3"> 弟兄们，我现在对明白律法的人说：难道你们不明白，律法只是在一个人活着的时候辖制这个人吗？</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 2:23–24; 哥林多前书 7:39; 哥林多前书 7:4"> 要知道，已婚的女人，在丈夫活着的时候，是被律法约束的；但如果丈夫死了，她就脱离了那关于丈夫的律法。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 20:14; 马太福音 5:32; 马可福音 10:6–12"> 由此可见，丈夫还活着的时候，她如果归向别的男人，就被称为淫妇；但如果丈夫死了，她就脱离那律法得了自由，即使归向别的男人，也不是淫妇。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="彼得前书 2:24; 加拉太书 5:22–23; 以赛亚书 54:5"> 因此，我的弟兄们，你们藉着基督的身体，在律法上也被处死了，使你们归向另一位，就是从死人中复活的那一位，好让我们能为神结出果子来。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 2:3; 加拉太书 5:16–17; 加拉太书 5:24"> 原来，当我们还在肉体中的时候，罪的欲望藉着律法在我们身体的各部分<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="身体的各部分——或译作“肢体”。">a</a></sup>做工，以致为死亡结了果子。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 3:23–25; 哥林多后书 3:6; 罗马书 7:4"> 但如今，我们既然在那捆绑我们的律法上死了，就脱离了律法，结果我们得以按照圣灵的新样式来服事，而不按照律法条文的旧样式。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="罗马书 3:20; 罗马书 4:15; 哥林多前书 15:56"> 那么，我们要怎么说呢？难道律法是罪吗？绝对不是！然而，要不是藉着律法，我就不知道什么是罪。如果律法没有说“不可贪心”，我就不知道什么是贪心；</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 7:11; 哥林多前书 15:56; 罗马书 4:15"> 但是，罪藉着诫命，趁机在我里面生出种种贪念。原来在律法之外，罪是死的。</span>
<span className="v" id="v9" data-v="9" data-xref="加拉太书 3:10; 罗马书 8:7; 雅各书 2:10–11"> 我从前活在律法之外，但是诫命一来，罪就活起来了，</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 3:7; 罗马书 10:5; 利未记 18:5"> 我却死了。于是我发现，那本该带来生命的诫命，它却导致了死亡。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 3:13; 罗马书 7:8; 希伯来书 3:13"> 事实上，罪藉着诫命趁机欺骗了我，并藉着诫命杀了我。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太前书 1:8; 诗篇 119:137; 诗篇 19:7–12"> 因此，律法是神圣的，诫命也是神圣、公义、美善的。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="雅各书 1:13–15; 加拉太书 3:21; 罗马书 8:3"> 那么，是那美善的导致了我的死吗？<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="导致了我的死吗？——原文直译“成了我的死吗？”">b</a></sup>绝对不是！而是罪。罪为要显出是罪，就藉着那美善的带来了我的死，使罪藉着诫命变得极其邪恶。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 21:25; 列王纪下 17:17; 罗马书 7:18"> 我们知道律法是属灵的；而我是属肉体的，已经卖给罪了。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 5:17; 罗马书 7:19–20; 传道书 7:20"> 实际上，我所做的，我不明白，因为我所愿意的，我没有去做；我所恨恶的，我反而去做。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 7:12; 罗马书 7:14; 提摩太前书 1:8"> 那么，如果我做我不愿意做的事，我就赞同了律法是好的。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 7:20; 腓立比书 3:8–9; 罗马书 7:18"> 所以现在这事就不再是我所做的，而是住在我里面的罪所做的。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 3:6; 诗篇 51:5; 加拉太书 5:17"> 事实上，我知道在我里面，就是在我肉体中，没有良善；因为行善的意愿在我里面，却行不出来。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 7:15"> 这样，我愿意行的善，我没有去行；我不愿意做的恶，我反而去做。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 7:17"> 那么，如果我做我不愿意做的事，这事就不再是我所做的，而是住在我里面的罪所做的。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 6:14; 罗马书 7:23; 诗篇 119:133"> 因此我发现一个法则：当我愿意行善的时候，恶就在我里面。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 1:2; 诗篇 40:8; 诗篇 119:35"> 就是说，按着内在的人，我喜爱神的法则，</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 5:17; 雅各书 4:1; 罗马书 8:2"> 然而我发现在我身体<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="身体——或译作“身体的各部分”或“肢体”。">c</a></sup>中另有一个法则，与我理性的法则交战，把我掳到我身体中罪的法则里。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 6:6; 提摩太后书 4:18; 提多书 2:14"> 我这个人真是可悲呀！谁能救我脱离这属于死亡的身体呢？</span>
<span className="v" id="v25" data-v="25" data-xref="加拉太书 5:17–24; 歌罗西书 3:17; 哥林多后书 12:9–10"> 藉着我们的主耶稣基督，感谢归于神！<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="藉着我们的主耶稣基督，感谢归于神！——或译作“感谢神！藉着我们的主耶稣基督（，就能脱离了）。”">d</a></sup>由此可见，我自己一方面在理性上服从神的法则，另一方面在肉体中却服从罪的法则。</span>
</div>
</div>

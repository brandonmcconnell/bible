<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 2:16; 加拉太书 5:13; 罗马书 6:15"> 那么，我们要怎么说呢？难道我们可以留在罪中，好让恩典增多吗？</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 3:9; 歌罗西书 3:3; 罗马书 7:4"> 绝对不可！我们这些向罪已经死了的人，怎么还能活在罪中呢？</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 3:27; 加拉太书 2:20–21; 罗马书 6:8"> 难道你们不明白，所有受洗归入基督耶稣的人，就是受洗归入了他的死吗？</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 5:17; 歌罗西书 3:10; 以弗所书 4:22–24"> 所以，我们藉着洗礼归入死，和他一同埋葬，好使我们也能以生命的新样式行事为人，就像基督藉着父的荣耀从死人中复活那样。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 3:10–11; 哥林多后书 4:10; 歌罗西书 2:12"> 就是说，如果我们在基督死的样式上与他联合，也将要在他复活的形式上与他联合。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 2:20; 以弗所书 4:22; 加拉太书 5:24"> 我们知道，我们的旧我<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我——原文直译“人”。">a</a></sup>已经和基督一起被钉十字架，好让罪的身体被废除，使我们不再做罪的奴仆，</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前书 4:1; 歌罗西书 3:1–3; 罗马书 7:4"> 因为一个死了的人，已经脱离了罪。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太后书 2:11–12; 歌罗西书 3:3–4; 哥林多后书 4:10–14"> 那么，如果我们与基督一同死了，就相信也要与他一同活着。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 6:14; 启示录 1:18; 使徒行传 2:24–28"> 我们知道，基督既从死人中复活，就不会再死，死亡再也辖制不了他。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 5:21; 彼得前书 4:6; 彼得前书 3:18"> 原来他死，是一次性地向罪而死；他活，是向神而活。</span>
<span className="v" id="v11" data-v="11" data-xref="歌罗西书 3:3–5; 哥林多前书 6:20; 罗马书 6:2"> 照样，你们就当看自己向罪是死的，但在<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附“我们的主”。">b</a></sup>基督耶稣里向神却是活的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="加拉太书 5:16; 罗马书 6:16; 罗马书 8:13"> 所以，不要让罪在你们会死的身体上掌权，使你们顺从身体的私欲；</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 12:1; 罗马书 6:16; 歌罗西书 3:5"> 也不要把你们身体的任何部分<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="身体的任何部分——或译做“肢体”。">c</a></sup>献给罪，做不义的器具；相反，要像从死人中复活的人，把自己献给神，并把身体的各部分做义的器具献给神。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 5:18; 罗马书 8:2; 罗马书 7:4–11"> 这样，罪就不能辖制你们了，因为你们不在律法之下，而在恩典之下。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="提多书 2:11–14; 以弗所书 2:8–10; 罗马书 6:1–2"> 那又怎么样呢？难道因为我们不在律法之下而在恩典之下，就可以犯罪吗？绝对不可！</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 8:34; 马太福音 6:24; 约书亚记 24:15"> 你们难道不知道吗？你们把自己献上做奴仆去顺从谁，那么，顺从谁就是谁的奴仆：或做罪的奴仆，以至于死；或做顺从的奴仆，以致称义。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前书 2:9; 提摩太后书 1:13; 罗马书 1:8"> 感谢神！虽然你们过去是罪的奴仆，但现在却从心里顺从了所传给你们的<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="传给你们的——或译作“交托给你们的”。">d</a></sup>教导内容，</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 6:22; 罗马书 8:2; 加拉太书 5:1"> 从罪中得了释放，成为义的奴仆。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 6:13; 彼得前书 4:2–4; 歌罗西书 3:5–7"> 因着你们肉体的软弱，我就按照人的说法来讲，那就是，你们从前怎样把身体的各部分<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="身体的各部分——或译作“肢体”。">e</a></sup>献给污秽和罪恶<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="罪恶——原文直译“不法”。">f</a></sup>做奴仆，以致罪恶<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="罪恶——原文直译“不法”。">g</a></sup>；现在也要照样把你们身体的各部分献给义做奴仆，以致分别为圣。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 6:16–17; 约翰福音 8:34"> 原来，你们做罪的奴仆时，不受义的管束；</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 1:32; 罗马书 7:5; 罗马书 6:23"> 那么，在你们现在看为羞耻的那些事上，你们当时到底得了什么果子呢？那些事的结局就是死。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:16; 罗马书 6:18; 罗马书 8:2"> 但如今，你们既从罪中得了释放，成为神的奴仆，就得了果子，以致分别为圣，那结局就是永恒的生命。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 3:36; 罗马书 5:12; 雅各书 1:15"> 因为罪的工价就是死；但神的恩赐，在我们的主基督耶稣里，却是永恒的生命。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太前书 2:7; 罗马书 1:9; 加拉太书 1:20"> 我在基督里说真话，不是在说谎；我的良心藉着圣灵与我一同作证：</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比书 3:18; 诗篇 119:136; 耶利米书 13:17"> 我极其忧伤，心里时常苦痛。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 32:32; 以斯帖记 8:6; 罗马书 11:14"> 为了我的同胞<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="同胞——原文直译“兄弟”。">a</a></sup>，我的骨肉之亲，就算我自己被诅咒、与基督分离，我也愿意。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 2:12; 诗篇 147:19; 罗马书 9:6"> 他们是以色列人：儿子的名份、荣耀、诸约、所赐的律法、礼仪、各样应许，都是他们的；</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 10:30; 约翰福音 1:1–3; 歌罗西书 1:16–19"> 祖先也是他们的；照着肉身说，基督也是出自他们的——他是那在万有之上当受颂赞的神，直到永远！阿们。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="罗马书 2:28–29; 加拉太书 6:16; 罗马书 11:1–2"> 但这并不是说神的话语<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="神的话语——或译作“神的道”。">b</a></sup>落了空，因为由以色列所生的，并不都是以色列人；</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 21:12; 希伯来书 11:18; 约翰福音 8:37–39"> 也不因为是亚伯拉罕的后裔，就都是他的儿女；只有“从以撒生的，才会被称为你的后裔。”</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 1:13; 罗马书 4:11–16; 加拉太书 3:26–29"> 这就是说，肉身的儿女并不是神的儿女，只有应许的儿女才算是后裔。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 18:10; 创世记 18:14; 创世记 17:21"> 原来所应许的话是这样的：“到明年<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="明年——辅助词语。">c</a></sup>这时候我要来，撒拉会生一个儿子。”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 25:21–23; 路加福音 16:26; 罗马书 5:11"> 不仅如此，莉百加也是这样。她由一个人，就是由我们的先祖以撒怀了孕。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太后书 1:9; 以弗所书 1:4–5; 彼得后书 1:10"> 实际上，双子<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="双子——辅助词语。">d</a></sup>还没有出生，也没有行善或作恶以前——为了要显明神的拣选心意不是本于人的行为，而是出于召唤人的那一位——</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 25:22–23; 撒母耳记下 8:14; 列王纪上 22:47"> 神<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="神——辅助词语。">e</a></sup>就对莉百加说：“大的将要服事小的。”</span>
<span className="v" id="v13" data-v="13" data-xref="玛拉基书 1:2–3; 申命记 21:15; 创世记 29:33"> 正如经上所记：“我爱雅各，却恨以扫。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="历代志下 19:7; 诗篇 145:17; 申命记 32:4"> 那么，我们要怎么说呢？难道神不公义吗？绝对不是！</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 33:19; 罗马书 9:16; 弥迦书 7:18"> 因为神对摩西说：<br /><span className="pl pl-1">“我要怜悯谁，就怜悯谁；</span><br /><span className="pl pl-1">我要同情谁，就同情谁。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="以弗所书 2:8; 马太福音 11:25–26; 彼得前书 2:9–10"> 由此可见，这不在于人的意愿，也不在于人的努力<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="努力——原文直译“奔跑”。">f</a></sup>，而在于施怜悯的神。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 9:16; 箴言 16:4; 出埃及记 14:17–18"> 原来经上有话对法老说：<br /><span className="pl pl-1">“我兴起你，正是为此：</span><br /><span className="pl pl-1">好让我藉着你来显出我的大能，</span><br /><span className="pl pl-1">使我的名传遍天下。”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约书亚记 11:20; 出埃及记 4:21; 罗马书 9:15–16"> 这样看来，神要怜悯谁，就怜悯谁；要使谁顽固，就使谁顽固。</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="但以理书 4:35; 历代志下 20:6; 哥林多前书 15:12"> 那么，你会对我说：“既然如此，神为什么还要指责人呢？到底谁能抵挡他的旨意呢？”</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 29:16; 以赛亚书 45:9–11; 以赛亚书 64:8"> 哦，人哪！你到底是谁，竟然向神顶嘴呢？被造的难道可以对造它的说：“你为什么把我造成这样呢？”</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 64:8; 箴言 16:4; 提摩太后书 2:20–21"> 难道陶匠没有权柄从同一团泥中，既造出贵重的器皿，又造出卑贱的器皿吗？</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 16:4; 犹大书 1:4; 罗马书 9:21"> 但如果神想要显出他的震怒，显明他的能力，就以极大的耐心容忍那些承受震怒的器皿，就是他早已预备要归于灭亡<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="灭亡——或译作“沉沦”。">g</a></sup>的器皿，那又怎么样呢？</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 2:4; 彼得前书 1:2–5; 歌罗西书 1:27"> 再者，如果这是为要将他那荣耀的丰盛显明在这些得蒙怜悯的器皿，就是他早已预备要归于荣耀的器皿上，那又怎么样呢？</span>
<span className="v" id="v24" data-v="24" data-xref="歌罗西书 3:11; 使徒行传 13:47–48; 以弗所书 3:6–8"> 这些器皿就是我们这些蒙召的人：不仅是从犹太人中，也是从外邦人中蒙召的人。</span>
<span className="v" id="v25" data-v="25" data-xref="何西阿书 2:23; 彼得前书 2:10; 约翰福音 16:27"> 正如神在何西阿书上也说：<br /><span className="pl pl-1">“我将要称那不是我子民的为‘我的子民’，</span><br /><span className="pl pl-1">那不蒙爱的为‘蒙爱的’。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="何西阿书 1:9–10; 约翰一书 3:1–3; 加拉太书 3:26"> <span className="pl pl-1">从前在什么地方对他们说</span><br /><span className="pl pl-1">‘你们不是我的子民’，</span><br /><span className="pl pl-1">就在那里，他们将被称为‘永生神的儿女。’ ”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 10:20–23; 罗马书 11:4–6; 以赛亚书 1:9"> 以赛亚论到以色列人，呼喊说：<br /><span className="pl pl-1">“以色列子民的人数虽然多如海沙，</span><br /><span className="pl pl-1">将要得救的却是剩余的少数。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 10:23; 启示录 19:11; 使徒行传 17:31"> <span className="pl pl-1">主就是要在地上</span><br /><span className="pl pl-1">彻底、迅速地成就他的话。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 1:9; 以赛亚书 13:19; 阿摩司书 4:11"> 又如以赛亚预先说过：<br /><span className="pl pl-1">“要不是万军之主给我们留下后裔，</span><br /><span className="pl pl-1">我们早就变得像所多玛、格摩拉那样了。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="腓立比书 3:9; 希伯来书 11:7; 加拉太书 2:16"> 那么，我们要怎么说呢？那原来没有追求义的外邦人，却得到了义，就是因信而得的义；</span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 11:7; 罗马书 3:20; 雅各书 2:10–11"> 而以色列人追求律法的义，却没有达到律法的义<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="律法的义——有古抄本作“律法”。">h</a></sup>。</span>
<span className="v" id="v32" data-v="32" data-xref="哥林多前书 1:23; 彼得前书 2:8; 路加福音 7:23"> 这是为什么呢？因为他们不是本于信，倒像是本于<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附“律法上的”。">i</a></sup>行为去追求的，所以他们就绊倒在那“绊脚的石头”上。</span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 28:16; 以赛亚书 8:14–15; 罗马书 10:11"> 正如经上所记：<br /><span className="pl pl-1">“看哪，我在锡安放一块绊脚的石头，</span><br /><span className="pl pl-1">是使人绊倒的磐石；</span><br /><span className="pl pl-1">可是信靠他的人将不至于蒙羞。”</span></span>
</div>
</div>

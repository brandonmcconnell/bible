<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 9:20–22; 罗马书 9:1–3; 约翰福音 5:34"> 弟兄们，我心里热切盼望，并替以色列人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以色列人——有古抄本作“他们”。">a</a></sup>向神祈求，是为了他们的救恩。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 21:20; 罗马书 9:31–32; 箴言 19:2"> 我见证他们对神有热心，但不是按着真正的认识。</span>
<span className="v" id="v3" data-v="3" data-xref="腓立比书 3:9; 路加福音 16:15; 哥林多后书 5:21"> 就是说，他们不明白神的义，想要确立自己的义，就不服从神的义了。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 3:24; 罗马书 8:3–4; 马太福音 5:17–18"> 事实上，基督是律法的终结，使所有相信的人都以致称义。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 18:5; 以西结书 20:11; 尼希米记 9:29"> 原来，有关出于律法的义，摩西写道：“遵行这些事的人，将因此而活”；</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 30:11–14; 箴言 30:4; 以弗所书 4:8–10"> 而有关本于信的义，却这样吩咐：“你心里不用说：谁要升到天上去？”——这意思是要把基督带下来；</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 13:20; 启示录 1:18; 罗马书 4:25"> “也不用说：谁要下到无底坑去？”——这意思是将基督从死人中领上来。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 30:14; 罗马书 1:16–17; 提摩太前书 4:6"> 然而，这是怎么说呢？“这话就在你身边，在你口中，在你心里。”这就是我们所传的有关信仰的话语：</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 12:8; 使徒行传 16:31; 腓立比书 2:11"> 你如果口里承认耶稣是主，心里相信神使他从死人中复活，就将得救。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 4:15; 罗马书 10:9; 加拉太书 2:16"> 就是说，人心里相信以致称义，口里承认以致救恩，</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 28:16; 罗马书 9:33; 彼得前书 2:6"> 因为经上说：“所有信靠他的人将不至于蒙羞。”</span>
<span className="v" id="v12" data-v="12" data-xref="腓立比书 4:19; 启示录 17:14; 加拉太书 3:28"> 犹太人和外邦人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="外邦人——原文直译“希腊人”；指“希腊文化区的非犹太人”。">b</a></sup>并没有分别，原来，万人共同的主，使所有求告他的人都富足。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 2:21; 约珥书 2:32"> 的确，“无论谁求告主名，都将得救。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="马可福音 16:15–16; 使徒行传 26:17–18; 提多书 1:3"> 既然如此，人没有相信他，怎么能求告他呢？没有听说过他，怎么能相信他呢？没有人传讲，怎么能听到呢？</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 52:7; 那鸿书 1:15; 以弗所书 2:17"> 如果没有奉差派，又怎么能去传讲呢？正如经上所记：“<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附“传讲和平福音的人、”。">c</a></sup>传讲美好福音的人，他们的脚踪多么美丽！”</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 53:1; 罗马书 3:3; 约翰福音 12:38–40"> 但是，并不是所有的人都顺从了福音，就如以赛亚所说：“主啊，我们所传的，有谁信了呢？”</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 3:2; 加拉太书 3:5; 帖撒罗尼迦前书 2:13"> 因此，信是由听而来，听是藉着基督<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="基督——有古抄本作“神”。">d</a></sup>的话而来。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 19:4; 罗马书 1:8; 马太福音 24:14"> 那么我要说，他们难道没有听过吗？当然听过——<br /><span className="pl pl-1">“那声音传遍了天下，</span><br /><span className="pl pl-1">那话语传到了地极。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="申命记 32:21; 罗马书 11:11; 罗马书 11:14"> 我再说“以色列人难道不明白吗？”首先，摩西说：<br /><span className="pl pl-1">“我要用不是子民的，激起你们的嫉妒之心，</span><br /><span className="pl pl-1">用无知的民族激起你们的怒气。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 65:1–2; 罗马书 9:30; 以赛亚书 55:4–5"> 后来，以赛亚大胆地说：<br /><span className="pl pl-1">“没有寻找我的，我让他们寻见；</span><br /><span className="pl pl-1">没有求问我的，我向他们显现。”</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 65:2–5; 彼得前书 2:8; 耶利米书 35:15"> 但是关于以色列人，他却说：“我整天向那悖逆、顶嘴的子民伸出双手。”</span>
</div>

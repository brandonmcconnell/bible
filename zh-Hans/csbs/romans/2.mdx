<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 6:37; 罗马书 2:3; 约翰福音 8:7–9"> 哦，人哪，所以你是无法推诿的！一切评断人的啊，你在什么事上评断别人，就在什么事上定自己的罪；因为你这评断人的，你自己也在做同样的事。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 9:7–8; 西番雅书 3:5; 诗篇 145:17"> 况且我们知道，对做这样事的人，神是按照真理来审判他们的。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 16:5; 路加福音 12:14; 罗马书 1:32–1"> 哦，人哪！你评断做这样事的人，而自己也做同样的事，你以为你能逃脱神的审判吗？</span>
<span className="v" id="v4" data-v="4" data-xref="彼得后书 3:9; 以赛亚书 30:18; 出埃及记 34:6"> 难道你轻视神丰富的仁慈、宽容、耐心，不明白他的仁慈是引领你来悔改的吗？</span>
<span className="v" id="v5" data-v="5" data-xref="传道书 12:14; 罗马书 1:18; 罗马书 2:2–3"> 可是你照着顽固和不悔改的心，为那震怒的日子，就是神公义审判显现的日子，给自己积蓄了震怒。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 62:12; 耶利米书 32:19; 马太福音 16:27"> 神将照着各人的行为回报各人：</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太后书 4:7–8; 路加福音 8:15; 提摩太后书 1:10"> 对那些恒心行善，寻求荣耀、尊贵、不朽的，就以永恒的生命回报他们；</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 3:18–21; 帖撒罗尼迦后书 1:8; 提摩太前书 6:3–4"> 而对那些营私争竞<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="营私争竞——或译作“结党”。">a</a></sup>、不肯信从真理、反信从不义的，就以震怒和愤恨回报他们。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 4:17; 以西结书 18:4; 罗马书 1:16"> 神要把患难和困苦加给一切作恶之人的灵魂，先是犹太人的，后是外邦人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="外邦人——原文直译“希腊人”；指“希腊文化区的非犹太人”。">b</a></sup>的；</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 32:17; 以赛亚书 26:12; 民数记 6:26"> 而把荣耀、尊贵、平安赐给所有做美善事的人，先是犹太人，后是外邦人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="外邦人——原文直译“希腊人”；指“希腊文化区的非犹太人”。">c</a></sup>。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 10:17; 使徒行传 10:34; 历代志下 19:7"> 要知道，神是不偏待人的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 9:21; 加拉太书 3:10; 加拉太书 2:16–19"> 凡是在律法之外犯过罪的，也将要在律法之外灭亡；凡是在律法之下犯过罪的，将要照着律法受审判。</span>
<span className="v" id="v13" data-v="13" data-xref="雅各书 1:22–25; 约翰一书 3:7; 雅各书 2:21–25"> 因为在神面前，不是律法的听者为义，而是律法的实行者被称为义。</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 2:12; 罗马书 1:19–20; 罗马书 2:27"> 其实没有律法的外邦人，一旦按照本性去行律法上的事，他们虽然没有律法，但自己就是自己的律法了。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多后书 5:11; 哥林多后书 1:12; 罗马书 1:18–19"> 这就显出律法的要求<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="律法的要求——原文直译“律法的行为”或“律法所要求的行为”。">d</a></sup>刻在他们的心里，他们的良心也一同作证，而且自己的心思之间，互相控告或辩解。</span>
<span className="v" id="v16" data-v="16" data-xref="传道书 12:14; 哥林多前书 4:5; 使徒行传 17:31"> 正如我的福音，这些事要在那日，神藉着基督耶稣审判各人隐秘事的时候，显明出来。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 2:23; 弥迦书 3:11; 以赛亚书 48:1–2"> 你既然<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="你既然——有古抄本作“看哪，你”。">e</a></sup>称为犹太人，依靠律法，以神夸耀；</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 5:21; 申命记 4:8; 雅各书 4:17"> 又从律法中受教，明白神的<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="神的——辅助词语。">f</a></sup>旨意，也能分辨是非<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="分辨是非——或译作“分辨那些更重要的事”。">g</a></sup>；</span>
<span className="v" id="v19" data-v="19" data-xref="启示录 3:17–18; 马太福音 15:14; 以赛亚书 49:6"> 又深信自己是瞎子的领路人，是在黑暗中人的光，</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太后书 3:5; 提多书 1:16; 提摩太后书 1:13"> 是愚妄人的导师，是小孩子的教师，拥有着律法上知识和真理的规范，</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 9:27; 马太福音 23:3–28; 路加福音 12:47"> 那么，你这教导别人的，难道不教导自己吗？你这宣讲不可偷窃的，难道自己还偷窃吗？</span>
<span className="v" id="v22" data-v="22" data-xref="玛拉基书 3:8; 马太福音 12:39; 马可福音 11:17"> 你这说不可通奸的，难道自己还通奸吗？你这憎恶偶像的，难道自己还偷取庙里的东西吗？</span>
<span className="v" id="v23" data-v="23" data-xref="雅各书 4:16–17; 罗马书 2:17; 罗马书 3:2"> 你这以律法夸耀的，难道自己还违犯律法侮辱神吗？</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 36:20–23; 以赛亚书 52:5; 彼得后书 2:2"> 事实上，正如经上所记：“因你们的缘故，神的名在外邦人中受到亵渎。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="耶利米书 4:4; 加拉太书 5:3–6; 使徒行传 7:51"> 你如果是遵行律法的，割礼才有益处；但你如果是违犯律法的人，你的割礼就不是割礼了。</span>
<span className="v" id="v26" data-v="26" data-xref="歌罗西书 2:11; 哥林多前书 7:18–19; 罗马书 8:4"> 因此，那没有受割礼的人，如果遵守律法的公义规定，他虽然没有受割礼，难道不是算是受了割礼吗？</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 12:41–42; 罗马书 2:29; 哥林多后书 3:6"> 并且，那生来没有受割礼却完全实行律法的人，对你这虽有律法条文和割礼却违犯律法的人，难道不是要施行审判吗？</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太书 6:15; 马太福音 3:9; 罗马书 9:6–8"> 其实外表上做犹太人的，并不是犹太人；外表上、肉身上的割礼，也不是割礼。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 30:6; 腓立比书 3:3; 申命记 10:16"> 然而，在内心做犹太人的才是犹太人；同样，内心的割礼才是割礼——不是靠着律法条文而是靠着圣灵；这样的人得到的称赞不是从人来的，而是从神来的。</span>
</div>

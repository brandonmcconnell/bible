<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 11:22; 撒母耳记上 12:22; 腓立比书 3:5"> 那么，我要问，难道神弃绝了他的子民吗？绝对没有！其实我也是以色列人，亚伯拉罕的后裔，属于便雅悯支派。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 94:14; 罗马书 8:29–30; 出埃及记 32:1"> 神并没有弃绝自己预先所知道的子民。难道你们不知道那有关以利亚的经文怎么说吗？他怎样向神抱怨以色列人呢？</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 19:10–18; 列王纪上 18:13; 尼希米记 9:26"> <span className="pl pl-1">“主啊，他们杀了你的先知们，拆毁了你的祭坛，</span><br /><span className="pl pl-1">只剩下我一个人，他们还要追索我的命。”</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪上 19:18; 民数记 25:3; 西番雅书 1:4"> 但神对他的答复是怎么说的呢？“我为自己保留了七千人，他们是没有向巴力屈膝的。”</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 9:27; 以弗所书 1:5–6; 罗马书 9:11"> 照样，在现今的时刻也有剩余的少数，就是藉着恩典蒙拣选的人。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 2:21; 罗马书 4:4–5; 提摩太后书 1:9"> 既然藉着恩典，就不再本于行为了；否则，恩典就不再是恩典了。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附“但如果是本于行为，就不再是恩典了；否则，行为就不再是行为了。”">a</a></sup></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="罗马书 9:18; 罗马书 11:5; 哥林多后书 4:4"> 所以怎么样呢？以色列人并没有获得他们所寻求的，蒙拣选的人却获得了，而其余的人都成了刚硬的，</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 29:4; 以赛亚书 29:10; 以西结书 12:2"> 正如经上所记：<br /><span className="pl pl-1">“神给了他们昏迷的心灵、</span><br /><span className="pl pl-1">看不见的眼睛、听不见的耳朵，</span><br /><span className="pl pl-1">直到今天。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="诗篇 69:22–23; 路加福音 12:20; 诗篇 28:4"> 大卫也说：<br /><span className="pl pl-1">“让他们的筵席成为网罗、陷阱、绊脚石，</span><br /><span className="pl pl-1">又成为他们的报应。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 69:23; 申命记 28:64–68; 彼得后书 2:4"> <span className="pl pl-1">让他们的眼睛昏暗不能看。</span><br /><span className="pl pl-1">让他们的腰背永远弯曲。”</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 13:46–48; 罗马书 11:31; 罗马书 10:19"> 所以我要问，难道以色列人跌倒了，是要他们败落吗？绝对不是！相反，因他们的过犯，救恩就临到了外邦人，为要激起以色列人的嫉妒之心。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 11:25; 歌罗西书 1:27; 罗马书 11:15"> 既然他们的过犯能使世人富足，他们的失败能使外邦人富足，更何况他们的全数满足呢！</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 9:15; 提摩太后书 1:11–12; 以弗所书 3:8"> 现在我向你们外邦人说话：既然我确实是外邦人的使徒，我就以我的服事工作为荣耀，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 7:16; 提摩太前书 4:16; 罗马书 9:3"> 或许激起我同胞<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="同胞——原文直译“肉体”。">b</a></sup>的嫉妒之心，好拯救他们中的一些人。</span>
<span className="v" id="v15" data-v="15" data-xref="以弗所书 1:10; 罗马书 5:10–11; 歌罗西书 1:20–21"> 实际上，如果他们被丢弃，使世人与神<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="与神——辅助词语。">c</a></sup>和好了，那么他们蒙接纳，如果不是从死人中复生，又是什么呢？</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 44:30; 雅各书 1:18; 箴言 3:9"> 如果初熟的麦子<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="初熟的麦子——原文直译“初熟的果子”。">d</a></sup>是圣洁的，那面团也就圣洁了；如果树根是圣洁的，那树枝也就圣洁了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以弗所书 2:11–13; 以弗所书 3:6; 马太福音 21:43"> 但如果有些树枝被折下来，而你这野橄榄枝被接在其上，并且一同有份于那橄榄树根的丰富养分，</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 10:12; 罗马书 11:20; 以弗所书 2:19–20"> 那么你就不应该向那些树枝自夸了。而就算你自夸，也不是你托着树根，而是树根托着你。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 11:17; 罗马书 11:11–12; 罗马书 11:23–24"> 这样，你会说：“那些树枝被折下来，就是要我能被接上去。”</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 12:16; 哥林多后书 1:24; 哥林多前书 10:12"> 不错！他们因不信被折了下来，而你因信已经站立得住；你不可心高气傲，反要惧怕；</span>
<span className="v" id="v21" data-v="21" data-xref="彼得后书 2:4–9; 耶利米书 25:29; 耶利米书 49:12"> 因为神如果没有顾惜原生的树枝，恐怕也不会顾惜你。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 3:14; 希伯来书 3:6; 哥林多前书 15:2"> 所以看哪！神的仁慈和严厉——对堕落的人，神一定是严厉的，但是对你，如果你留在他的仁慈中，神就是仁慈的；否则，你也将被砍下来。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 3:16; 撒迦利亚书 12:10; 马太福音 23:39"> 而且，那些被折下来的树枝<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="那些被折下来的树枝——原文直译“他们”。">e</a></sup>如果不再坚持不信，也将被接上，因为神能够把他们重新接上。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 11:17–18; 罗马书 11:30"> 要知道，如果你从天然的野橄榄树上被砍下来，尚且能违反自然、被接在栽培的橄榄树上，何况那些原生的树枝<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="树枝——辅助词语。">f</a></sup>，难道不更能接在自己的橄榄树上吗？</span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="路加福音 21:24; 哥林多后书 3:14–16; 罗马书 16:25"> 弟兄们，我不愿意你们不明白这奥秘，免得你们自以为聪明。这奥秘就是：以色列人中的部分人变得刚硬，直到外邦人的全数满足了，</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 59:20; 耶利米书 31:31–37; 诗篇 14:7"> 以色列全家才会得救，正如经上所记：<br /><span className="pl pl-1">“一位拯救者将从锡安而来，</span><br /><span className="pl pl-1">他要从雅各除去不敬神的心，</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 31:31–34; 以赛亚书 59:21; 以西结书 36:25–29"> <span className="pl pl-1">这就是我的约——</span><br /><span className="pl pl-1">当我除去他们罪孽的时候，所给他们的约。”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命记 10:15; 申命记 7:7–8; 马太福音 21:43"> 就福音而言，他们因你们的缘故，固然是神的<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="神的——辅助词语。">g</a></sup>敌人<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="敌人——或译作“反对者”。">h</a></sup>；但就拣选而言，他们因祖先的缘故，却是蒙爱的，</span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 7:21; 民数记 23:19; 玛拉基书 3:6"> 因为神的恩赐和召唤是不撤回的<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="不撤回的——或译作“不反悔的”。">i</a></sup>。</span>
<span className="v" id="v30" data-v="30" data-xref="歌罗西书 3:7; 以弗所书 2:1–2; 哥林多前书 7:25"> 正如你们以前不肯信从神而现在却因他们的不信从反而蒙了怜悯；</span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 11:15; 罗马书 10:16; 罗马书 11:25"> 照样，他们如今也不肯信从，为要藉着你们所蒙的怜悯，让他们现在<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本没有“现在”。">j</a></sup>也可以蒙怜悯，</span>
<span className="v" id="v32" data-v="32" data-xref="加拉太书 3:22; 罗马书 3:9; 提摩太前书 2:4–6"> 因为神把所有的人都圈在不信从之中，是为了要怜悯所有的人。</span>
</div>
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="约伯记 5:9; 约伯记 11:7–9; 诗篇 92:5"> <span className="pl pl-1">哦，深奥啊！神的智慧和知识的财富！</span><br /><span className="pl pl-1">他的判断是多么地无法探究，</span><br /><span className="pl pl-1">他的道</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="道——或译作“路”。">k</a></sup><br /><span className="pl pl-1">是多么地无法测度！</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="以赛亚书 40:13; 哥林多前书 2:16; 约伯记 15:8"> <span className="pl pl-1">“到底是谁知道主的心意？</span><br /><span className="pl pl-1">是谁做过他的谋士？</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="约伯记 41:11; 约伯记 35:7; 哥林多前书 4:7"> <span className="pl pl-1">又是谁首先给了主，</span><br /><span className="pl pl-1">使自己将来得到回报呢？ ”</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="歌罗西书 1:15–17; 哥林多前书 8:6; 希伯来书 2:10"> <span className="pl pl-1">因为万有都是出于他、藉着他、归于他。</span><br /><span className="pl pl-1">愿荣耀归于他，直到永远！阿们。</span></span>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="ROM" data-book-slug="romans" data-book-name="罗马书" data-chapter="1" data-verses="32">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 9:15; 罗马书 15:16; 哥林多前书 1:1"> 我<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我——辅助词语。">a</a></sup>保罗做基督耶稣的奴仆、蒙召的使徒，是为了神的福音被分别出来的。</span>
<span className="v" id="v2" data-v="2" data-xref="提多书 1:2; 路加福音 1:70; 罗马书 3:21"> 这福音是神先前藉着他的先知们，在圣经上所应许的，</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 1:1; 加拉太书 4:4; 耶利米书 23:5–6"> 是关于他的儿子——我们的主耶稣基督的。照着肉身说，他出自大卫的后裔；</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 9:14; 希伯来书 5:5–6; 以弗所书 1:19–23"> 照着圣洁的灵<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="圣洁的灵——或译作“圣灵”。">b</a></sup>说，藉着从死人中复活，他被显明是神大能的儿子。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 9:15; 罗马书 16:26; 使徒行传 6:7"> 我们从他领受了恩典和使徒的职份，为了他名的缘故，要在万民中带来信仰上的顺从；</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前书 2:9; 启示录 17:14; 彼得后书 1:10"> 其中也有你们这些蒙召唤、属耶稣基督的人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歌罗西书 1:2; 犹大书 1:1–2; 以弗所书 1:2"> 致所有在罗马、蒙神所爱、蒙召成为圣徒的人：<br />愿恩典与平安从神我们的父和主耶稣基督临到你们！</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="罗马书 16:19; 哥林多前书 1:4; 帖撒罗尼迦前书 1:8–9"> 首先，我藉着耶稣基督，为你们各位感谢我的神，因为你们的忠信被传遍全世界。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 6:18; 提摩太后书 1:3; 以弗所书 1:16–19"> 事实上，神——就是我在他儿子的福音工作上用心灵所事奉的那一位，可以为我见证：我怎样不住地提到你们，</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 15:30–32; 使徒行传 18:21; 腓利门书 1:22"> 在我的祷告中总是祈求，或许可以照着神的旨意，终有一天能顺利地到你们那里去；</span>
<span className="v" id="v11" data-v="11" data-xref="彼得后书 1:12; 罗马书 16:25; 罗马书 15:29"> 因为我切切地想见到你们，好把一些属灵的恩赐分给你们，使你们得以坚固。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦前书 3:7–10; 约翰三书 1:3–4; 哥林多后书 7:13"> 这就是说，在你们那里，藉着你们和我里面彼此的信仰，大家可以同得鼓励。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 19:21; 腓立比书 4:17; 提摩太后书 4:17"> 弟兄们，我不愿意你们不明白：我多次计划到你们那里去，为要在你们那里也得一些果实，就像我在其他外邦人中那样，可是直到如今还受到拦阻。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 9:16–23; 使徒行传 9:15; 歌罗西书 3:11"> 无论是希腊人或是外族人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="外族人——或译作“非希腊人”。">c</a></sup>，有智慧的或是无知的，我都对他们有责任<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有责任——原文直译“欠债”。">d</a></sup>。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 15:20; 以赛亚书 6:8; 哥林多前书 9:17"> 因此，我愿意尽我所能，把福音也传给你们在罗马的人。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马可福音 8:38; 提摩太后书 1:8; 彼得前书 4:16"> 的确，我不以<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附“基督的”。">e</a></sup>福音为耻，因为这福音是神的大能，把救恩带给一切相信的人，先是犹太人、后是外邦人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="外邦人——原文直译“希腊人”；指“希腊文化区的非犹太人”。">f</a></sup>。</span>
<span className="v" id="v17" data-v="17" data-xref="哈巴谷书 2:4; 加拉太书 3:11; 希伯来书 10:38"> 原来，神的义就在这福音上显明出来——本于信，以至于信，正如经上所记：“义人将因信而活。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以弗所书 5:6; 提摩太前书 4:1–2; 罗马书 1:32"> 要知道，人用不公义抵挡真理，神的震怒就从天上显明在人的一切不敬虔和不公义上。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 14:16–17; 诗篇 19:1–6; 罗马书 1:20"> 实际上，有关神的事，人所能知道的，在他们里面是清清楚楚的，因为神已经向他们显明了。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 1:19; 以赛亚书 40:26; 诗篇 19:1–6"> 原来，自从创世以来，神那不可见的本性，就是他永恒的大能和神性，都藉着所造之物，被人明白、被人看见，以致使人无法推诿。</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所书 4:17–18; 列王纪下 17:15; 耶利米书 2:5"> 所以人是已经知道神的，但是却不把他当做神来荣耀他，也不感谢他；相反，他们在思想上变得虚妄，他们无知的心就昏暗了。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 1:19–21; 罗马书 11:25; 箴言 26:12"> 他们自称是有智慧的，却成了愚拙，</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 106:20; 耶利米书 2:11; 使徒行传 17:29"> 甚至用偶像，就是会朽坏的人、飞禽、走兽、爬行动物的形像，来取代那不朽之神的荣耀。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="诗篇 81:11–12; 使徒行传 7:42; 使徒行传 14:16"> 因此，神任凭他们顺着心中的情欲去做污秽的事，以致彼此玷污自己的身体。</span>
<span className="v" id="v25" data-v="25" data-xref="哈巴谷书 2:18; 耶利米书 13:25; 约翰一书 2:15–16"> 他们用虚假取代神的真理，去崇拜、事奉被造之物，而不事奉造物之主——主是当受颂赞的，直到永远！阿们。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="犹大书 1:7; 提摩太前书 1:10; 罗马书 1:24"> 为此，神任凭他们陷入可耻的情欲，连他们的女人也把天性的功用变为违反天性的；</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 20:13; 利未记 18:22; 罗马书 1:23–24"> 同样，男人也放弃了女人天性的功用，彼此之间欲火中烧，男人与男人做出羞耻的事，就在自己身上<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="在自己身上——原文直译“在自己里面”。">g</a></sup>受到他们的妄为<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="妄为——或译作“迷途行为”。">h</a></sup>所应得的报应。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="帖撒罗尼迦后书 2:10–12; 罗马书 1:21; 提多书 1:16"> 既然人不愿意真正认识神，神就任凭他们存败坏的理性，去做那些不该做的事。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多后书 12:20; 箴言 16:28; 诗篇 41:7"> 他们充满了各种不义、<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附“淫乱、”。">i</a></sup>邪恶、贪心、恶毒；满心是嫉妒、凶杀、纷争、欺诈、狠毒；他们搬弄是非、</span>
<span className="v" id="v30" data-v="30" data-xref="提摩太后书 3:2; 犹大书 1:16; 彼得后书 2:18"> 诽谤人、憎恨神、侮慢人、骄傲、自夸、制造恶行、悖逆父母、</span>
<span className="v" id="v31" data-v="31" data-xref="提摩太后书 3:3; 箴言 18:2; 罗马书 3:11"> 愚昧无知、不守信用、没有亲情、<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附“不肯和解、”。">j</a></sup>毫无怜悯。</span>
<span className="v" id="v32" data-v="32" data-xref="罗马书 2:1–5; 罗马书 1:21; 罗马书 6:21"> 人虽然知道神的公义规定是：行这样事的人是该死的；然而他们不仅自己去做，还赞同做这些事的人。</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="罗马书 2:25–29; 创世记 25:32; 传道书 6:11"> 这样说来，犹太人有什么优越呢？割礼有什么益处呢？</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 9:4; 使徒行传 7:38; 哥林多前书 9:17"> 在各方面都有很多。首要的，是神的话语确实委托给他们了。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太后书 2:13; 希伯来书 4:2; 罗马书 9:6"> 即使他们中有些人不信，到底又怎么样呢？难道他们的不信会使神的信实无效吗？</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 51:4; 诗篇 116:11; 加拉太书 2:17"> 绝对不会！即使每个人都是说谎者，神还是真实的。正如经上所记：<br /><span className="pl pl-1">“这样，你说话的时候，显为公义；</span><br /><span className="pl pl-1">被评断的时候，必然得胜。”</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="罗马书 6:19; 加拉太书 3:15; 罗马书 9:18–20"> 但是，如果我按人的意思来说，我们的不义可以显明神的义，那我们要怎么说呢？难道降震怒的神是不公正的吗？</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 18:25; 使徒行传 17:31; 约伯记 8:3"> 绝对不是！否则，神怎么能审判世界呢？</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 3:4; 罗马书 9:19–20; 使徒行传 13:27–29"> 那么，如果神的真实因我的虚谎使他的荣耀更加丰盛，为什么我还要像罪人一样被定罪呢？</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 6:1; 罗马书 6:15; 罗马书 5:20"> 这样，为什么不说“让我们作恶好带来善”呢？——我们正是如此受到毁谤，也有些人说过我们讲了这话——这些人被定罪倒是应该的。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="加拉太书 3:22; 罗马书 6:15; 以赛亚书 65:5"> 那么怎么样呢？我们犹太人比别人好吗？当然不是！我们已经指出：犹太人和外邦人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="外邦人——原文直译“希腊人”；指“希腊文化区的非犹太人”。">a</a></sup>都在罪孽之下。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 53:1–3; 诗篇 14:1–3; 罗马书 3:23"> 正如经上所记：<br /><span className="pl pl-1">“没有义人，连一个也没有；</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 14:2–4; 诗篇 53:2; 提多书 3:3"> <span className="pl pl-1">没有领悟的，</span><br /><span className="pl pl-1">没有寻求神的。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 14:3; 传道书 7:20; 以赛亚书 64:6"> <span className="pl pl-1">人人都远离了正道，</span><br /><span className="pl pl-1">一同成了无用的；</span><br /><span className="pl pl-1">没有仁慈的，</span><br /><span className="pl pl-1">连一个也没有。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 5:9; 诗篇 140:3; 马太福音 23:27–28"> <span className="pl pl-1">他们的喉咙是敞开的坟墓，</span><br /><span className="pl pl-1">他们用舌头玩弄诡诈，</span><br /><span className="pl pl-1">他们的嘴唇含有蛇毒，</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 10:7; 诗篇 109:17–18; 诗篇 59:12"> <span className="pl pl-1">他们满口是咒骂和苦毒，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 59:7–8; 箴言 1:16; 箴言 6:18"> <span className="pl pl-1">他们的脚步为杀人</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="杀人——辅助词语。">b</a></sup><br /><span className="pl pl-1">流血而飞快，</span><br /></span>
<span className="v" id="v16" data-v="16"> <span className="pl pl-1">他们的路上只有毁灭和惨祸；</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 59:8; 罗马书 5:1; 路加福音 1:79"> <span className="pl pl-1">和平之路</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="和平之路——或译作“平安之路”。">c</a></sup><br /><span className="pl pl-1">，他们从来不知道。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 36:1; 箴言 23:17; 箴言 16:6"> <span className="pl pl-1">他们的眼目中没有对神的敬畏。 ”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="加拉太书 3:10; 加拉太书 3:22–23; 罗马书 2:12–18"> 我们知道，律法上的一切话都是对律法之下的人讲的，好堵住每个人的口，使全世界的人都在神的审判之下有罪，</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太书 2:16; 使徒行传 13:39; 罗马书 3:28"> 因为没有一个人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="人——原文直译“肉体”。">d</a></sup>本于律法上的行为在神面前被称为义；原来，藉着律法，只能对罪有真正的认识。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 10:43; 耶利米书 33:16; 腓立比书 3:9"> 但如今，神的义已经在律法之外显明出来，被律法和先知们所见证，</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 10:12; 加拉太书 3:28; 罗马书 8:1"> 那就是：神的义藉着对耶稣基督的信仰<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="藉着对耶稣基督的信仰——或译作“由于耶稣基督的信实”。">e</a></sup>，临到所有信的人，并没有分别。</span>
<span className="v" id="v23" data-v="23" data-xref="传道书 7:20; 约翰一书 1:8–10; 罗马书 3:9"> 要知道，每个人都犯了罪，亏缺了神的荣耀；</span>
<span className="v" id="v24" data-v="24" data-xref="彼得前书 1:18–19; 提多书 3:5–7; 歌罗西书 1:14"> 但藉着神的恩典，藉着在基督耶稣里的救赎，却无偿地被称为义。</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 3:23–24; 彼得前书 1:18–20; 约翰一书 4:10"> 神预先定下耶稣为平息祭<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="平息祭——或译作“挽回祭”。">f</a></sup>，是用耶稣的血、藉着人的信，为要显明神自己的义；因为他用忍耐的心，宽容人过去所犯的罪，</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 32:4; 罗马书 4:5; 罗马书 3:30"> 为了在现今的时刻显明他的义，好表明他自己为义，也称信耶稣的人为义。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="罗马书 4:2; 罗马书 2:23; 哥林多前书 1:29–31"> 既然如此，还有什么可夸耀的呢？根本没有。凭着什么法则呢？凭着行为的法则吗？不是！而是凭着信的法则。</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太书 2:16; 加拉太书 3:8; 提多书 3:7"> 就是说，我们认为：人被称为义，是藉着信，与律法上的行为无关。</span>
<span className="v" id="v29" data-v="29" data-xref="歌罗西书 3:11; 以弗所书 3:6; 撒迦利亚书 2:11"> 难道神只是犹太人的神吗？不也是外邦人的神吗？是的，他也是外邦人的神，</span>
<span className="v" id="v30" data-v="30" data-xref="加拉太书 3:8; 加拉太书 3:20; 腓立比书 3:3"> 既然神真是一位；他要使受割礼的人因信称义，也要使没有受割礼的人因信称义。</span>
<span className="v" id="v31" data-v="31" data-xref="加拉太书 2:21; 马太福音 5:17; 罗马书 13:8–10"> 那么，我们是藉着信废掉律法吗？绝对不是！反而确立了律法。</span>
</div>
</div>

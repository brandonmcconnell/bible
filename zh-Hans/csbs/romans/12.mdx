<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 2:5; 罗马书 6:13; 希伯来书 13:15–16"> 所以弟兄们，我藉着神的各样怜悯劝你们，要把自己的身体献上，做为圣洁、蒙神喜悦的活祭；这是你们理所当然的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="理所当然的——或译作“灵里的”。">a</a></sup>事奉。</span>
<span className="v" id="v2" data-v="2" data-xref="彼得前书 1:14; 以弗所书 4:22–24; 哥林多后书 5:17"> 不要效法这世代，要藉着理性的更新而改变，使你们可以分辨什么是神的旨意——那美善、可喜悦、完美的旨意。</span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="加拉太书 6:3; 腓立比书 2:3–8; 箴言 26:12"> 我藉着所赐给我的恩典，对你们中间的每个人说：不要自视过高，过于所当看的，而要照着神所分给每个人信心的尺度，清醒地看自己。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 12:27; 哥林多前书 12:12–14; 以弗所书 4:15–16"> 正如我们一个身体有很多部分<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="部分——或译作“肢体”。">b</a></sup>，而且各部分都有不同的功用；</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 12:20; 哥林多前书 10:17; 哥林多前书 12:27–28"> 照样，我们这许多人，在基督里是一个身体，而且各个部分都彼此相属。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前书 4:10–11; 哥林多前书 7:7; 哥林多前书 12:28–31"> 照着所赐给我们的恩典，我们各有不同的恩赐：<br /><span className="pl pl-1">如果是做先知传道</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="做先知传道——原文直译“说预言”。">c</a></sup><br /><span className="pl pl-1">的恩赐</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="恩赐——辅助词语。">d</a></sup><br /><span className="pl pl-1">，就按照信心的程度用它</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="用它——辅助词语。">e</a></sup><br /><span className="pl pl-1">；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 4:11; 提摩太后书 4:2; 使徒行传 13:1"> <span className="pl pl-1">如果是服事的，就用在服事上；</span><br /><span className="pl pl-1">如果是教导的，就用在教导上；</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 9:7; 提摩太前书 5:17; 哥林多前书 12:28"> <span className="pl pl-1">如果是劝勉的，就用在劝勉上；</span><br /><span className="pl pl-1">分享的，要慷慨；</span><br /><span className="pl pl-1">带领</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="带领——或译作“管理”。">f</a></sup><br /><span className="pl pl-1">的，要殷勤；</span><br /><span className="pl pl-1">怜悯人的，要甘心乐意。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="诗篇 34:14; 彼得前书 4:8; 提摩太前书 1:5"> 爱，不要虚假；要厌弃恶、持守善；</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比书 2:3; 约翰福音 13:34–35; 希伯来书 13:1"> 要以弟兄之情彼此相爱，以尊敬之心彼此谦让，</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 6:10–11; 使徒行传 18:25; 启示录 3:15–16"> 殷勤而不懒惰，灵里时时火热，常常服事主。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 15:13; 希伯来书 10:36; 诗篇 62:8"> 在盼望中要欢喜，在患难里要忍耐，在祷告上要恒切。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 13:16; 哥林多后书 9:12; 约翰一书 3:17"> 要分担圣徒的缺乏；尽力款待客旅。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 3:9; 马太福音 5:44; 帖撒罗尼迦前书 5:15"> 要祝福那些逼迫你们的人；要祝福，不要诅咒。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 12:26; 希伯来书 13:3; 诗篇 35:13–14"> 要与快乐的人一同快乐；与哀哭的人一同哀哭。</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前书 3:8; 箴言 3:7; 雅各书 3:13–17"> 要彼此同心；不要心高气傲，而要俯就卑微<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="卑微——或译作“谦卑”。">g</a></sup>的人；不要自以为聪明。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 20:22; 帖撒罗尼迦前书 5:15; 马太福音 5:39"> 不要对任何人以恶报恶；要顾念众人看为美善的事；</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 12:14; 马太福音 5:9; 罗马书 14:19"> 如果有可能，尽量在你们的事上与所有的人和睦。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 32:35; 希伯来书 10:30; 箴言 24:29"> 各位蒙爱的人哪，不要自己报复，宁可给神的震怒留地步，因为经上记着：“主说：报应在我，我将回报。”</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 25:21–22; 马太福音 5:44; 路加福音 6:27"> 不但如此，<br /><span className="pl pl-1">“如果你的敌人</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="敌人——或译作“反对者”。">h</a></sup><br /><span className="pl pl-1">饿了，就给他吃；</span><br /><span className="pl pl-1">如果他渴了，就给他喝；</span><br /><span className="pl pl-1">因为你这样做，就是把炭火堆在他的头上。”</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="彼得前书 3:9; 路加福音 6:27–30; 箴言 16:32"> 不要被恶所胜，反要以善胜恶。</span>
</div>

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="罗马书 13:1–7; 彼得前书 2:13–17; 传道书 10:4"> 你提醒他们要服从统治者和掌权者，要顺从，并要为一切美善的工作做好准备；</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 4:31; 提摩太后书 2:24–25; 以弗所书 4:2"> 不要毁谤人、不要争吵；要谦和，在一切事上对所有的人都要显出温柔。</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所书 2:1–3; 罗马书 6:17; 歌罗西书 1:21"> 其实，我们从前也是无知、悖逆、被迷惑的，做各种欲望和享乐的奴仆，活在恶毒和嫉妒中，是可憎恶的，又彼此相恨。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 2:4–10; 提多书 2:10–11; 提摩太前书 4:10"> <span className="pl pl-1">但是，当神我们救主的仁慈和他对人的爱显明的时候，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 2:8–9; 提摩太后书 1:9; 哥林多前书 6:11"> <span className="pl pl-1">他拯救了我们；</span><br /><span className="pl pl-1">这不是本于我们所做的义行，</span><br /><span className="pl pl-1">而是照着他的怜悯，</span><br /><span className="pl pl-1">藉着重生的洗涤和圣灵的更新。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="约珥书 2:28; 罗马书 5:5; 使徒行传 10:45"> <span className="pl pl-1">神藉着我们的救主耶稣基督，</span><br /><span className="pl pl-1">将圣灵丰丰富富地倾注在我们身上，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:17; 提多书 2:11; 哥林多前书 6:11"> <span className="pl pl-1">使我们藉着他的恩典被称为义，</span><br /><span className="pl pl-1">可以照着永恒生命的盼望成为继承人。</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="提多书 3:14; 提多书 1:9; 诗篇 16:2–3"> 这话是信实的。我希望你强调这些事，好让那些信了神的人专心投入美好的工作；这些事对人是好事，是有益处的。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太后书 2:14; 提摩太后书 2:23; 提摩太前书 4:7"> 至于愚拙的辩论、家谱、纷争和律法上的争执，你都要避免；因为这些都是无用的，是虚妄的。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 16:17; 约翰二书 1:10; 马太福音 18:15–17"> 对那制造分裂的人，在第一次、第二次的警戒以后，就要弃绝他，</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 10:26; 路加福音 19:22; 马太福音 25:26–28"> 因为你知道，这样的人已经背道，一直犯罪，定了自己的罪。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="提摩太后书 4:9; 提摩太后书 4:12; 哥林多前书 16:8–9"> 我派阿特马斯或特其库斯到你那里以后，你要尽快到尼科波利斯来见我，因为我已经决定在那里过冬。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 18:24; 马太福音 22:35; 约翰三书 1:6–8"> 你要尽快送齐纳斯律师和阿波罗上路，好让他们一无所缺。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歌罗西书 1:10; 提多书 3:8; 马太福音 7:19"> 我们自己的人，为了紧要的需用也应该学会投入美好的工作，免得成为不结果子的人。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太前书 1:5; 以弗所书 6:23–24; 约翰二书 1:1–2"> 所有与我在一起的人都问候你。请问候那些在信仰上爱我们的人。愿恩典与你们大家同在！<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附“阿们。”">a</a></sup></span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 4:14–17; 马可福音 13:27; 马太福音 24:31"> 弟兄们，论到我们主耶稣基督的来临，以及我们聚集归于他的事，我们请求你们：</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 4:1–2; 马可福音 13:7; 马太福音 24:4–6"> 无论是藉着灵，还是藉着话语，或藉着一封好像是来自我们的书信，说主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="主——有古抄本作“基督”。">a</a></sup>的日子<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="日子——指“基督再来的日子”。">b</a></sup>已经来到了，你们都不要轻易被摇动而失去理性，也不要惊慌；</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 24:4–6; 约翰一书 2:18; 以弗所书 5:6"> 不要让任何人用任何方法把你们欺骗了；因为那日子来临以前<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="那日子来临以前——辅助词语。">c</a></sup>，必定先有离道反教之事来到，并且那不法之人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="不法之人——有古抄本作“罪孽之人”。">d</a></sup>，就是那灭亡<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="灭亡——或译作“沉沦”。">e</a></sup>之子也会被显露出来。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 28:2; 但以理书 7:25; 启示录 13:6–7"> 他反对一切被称为神的，或受人敬拜的，他又高抬自己在这一切之上，甚至坐在神的圣所里宣称自己是神。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="彼得后书 1:15; 加拉太书 5:21; 马太福音 16:9"> 我还在你们那里的时候，一直告诉你们这些事，你们不记得吗？</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦后书 2:3; 帖撒罗尼迦后书 2:8"> 你们也知道，现在什么拦阻了他，好使他在所定的时候<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="所定的时候——原文直译“自己的时候”。">f</a></sup>被显露出来。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰一书 4:3; 启示录 17:7; 提摩太后书 2:17–18"> 其实这不法的奥秘已经在做工，只是要等到那现在拦阻他的不在其中，</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦后书 2:3; 启示录 19:20–21; 以赛亚书 11:4"> 然后这不法之人要被显露出来。主耶稣要以自己口中的气杀掉<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="杀掉——有古抄本作“毁灭”。">g</a></sup>他，藉着自己来临的显现除去他。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 24:24; 启示录 19:20; 以弗所书 2:2"> 这不法之人的到来，是出于撒旦的作为，对那些正在灭亡的人，使用一切能力、虚假的神迹和奇事，</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 1:18; 箴言 1:7; 哥林多后书 4:2–3"> 并且使用一切不义的诡计，因为他们不接受那能使他们得救的真理之爱。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 1:28; 约翰福音 12:39–43; 提摩太前书 4:1"> 为此，神就把一种迷惑人的力量送进他们里面，使他们相信虚假之事，</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 1:32; 罗马书 8:7–8; 马可福音 16:16"> 好使所有不相信真理而喜悦不义的人，都被定罪。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="提摩太后书 1:9; 以弗所书 1:4–5; 帖撒罗尼迦前书 1:4"> 蒙主所爱的弟兄们，我们应该为你们常常感谢神，因为神为了救恩的缘故，就藉着在圣灵里的分别为圣，以及真理的信仰，拣选了你们做为初熟的果子<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="拣选了你们做为初熟的果子——有古抄本作“从起初拣选了你们”。">h</a></sup>。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:12; 彼得前书 5:10; 帖撒罗尼迦前书 1:5"> 为此，神也藉着我们的福音召唤了你们，使你们获得我们主耶稣基督的荣耀。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 11:2; 帖撒罗尼迦后书 3:6; 帖撒罗尼迦后书 2:2"> 弟兄们，由此可见，你们当站立得稳；你们所领受的传统，无论是藉着我们的话语，还是藉着我们的书信，你们都要持守。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="罗马书 5:2–5; 约翰福音 3:16; 彼得前书 1:3–8"> 愿我们的主耶稣基督自己和神我们的父，就是爱我们又在恩典中把永恒的安慰和美好的盼望赐给我们的那一位，</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦后书 3:3; 帖撒罗尼迦前书 3:13; 帖撒罗尼迦前书 3:2"> 安慰你们的心，并且在一切美善的工作和言语上坚固你们。</span>
</div>
</div>

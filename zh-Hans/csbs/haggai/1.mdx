<span className="v" id="v1" data-v="1" data-xref="以斯拉记 2:2; 以斯拉记 3:8; 以斯拉记 3:2"> 大流士王在位第二年的六月一日，耶和华的话语藉着先知哈该，传达给撒拉铁的儿子犹大省长所罗巴伯，以及约萨达的儿子大祭司约书亚。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="以斯拉记 4:23–2; 尼希米记 4:10; 传道书 11:4"> 万军之耶和华如此说：“这子民说，建造耶和华殿宇的时候还没有到。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 5:1; 撒迦利亚书 1:1"> 那时，耶和华的话语临到先知哈该，说：</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 7:2; 诗篇 132:3–5; 腓立比书 2:21"> “难道这殿宇还荒废的时候，你们却住有天花板的房屋吗？</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米哀歌 3:40; 哥林多后书 13:5; 哈该书 1:7"> 所以，万军之耶和华如此说：你们要反思自己的行为<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="行为——或译作“情况”。">a</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="哈该书 1:9; 申命记 28:38–40; 何西阿书 4:10"> <span className="pl pl-1">你们种的多，收的少，</span><br /><span className="pl pl-1">吃却不得饱，</span><br /><span className="pl pl-1">喝却不得足，</span><br /><span className="pl pl-1">穿却不得暖，</span><br /><span className="pl pl-1">挣钱的，把挣来的装在有洞的钱袋里。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="诗篇 119:59–60; 哈该书 1:5; 腓立比书 3:1"> 万军之耶和华如此说：你们要反思自己的行为<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="行为——或译作“情况”。">b</a></sup>。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 132:13–14; 历代志下 7:16; 哈该书 2:7"> 你们要上山运来木材，建造这殿宇，我就因此喜悦，并得尊荣。这是耶和华说的。</span>
<span className="v" id="v9" data-v="9" data-xref="哈该书 1:4; 哈该书 2:16–17; 哈该书 1:6"> 你们盼望的多，看哪，却收的少。你们收到屋里的，我却把它吹走。为什么呢？因为我的殿宇荒废，你们却为各自的房屋奔忙。这是万军之耶和华的宣告。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 8:35; 利未记 26:19; 申命记 28:23–24"> <span className="pl pl-1">所以，因你们的缘故，</span><br /><span className="pl pl-1">天就止住露水，</span><br /><span className="pl pl-1">地也止住了出产。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="哈该书 2:17; 申命记 28:22; 列王纪下 8:1"> <span className="pl pl-1">我召唤干旱临到大地和群山，</span><br /><span className="pl pl-1">临到五谷、新酒和新油，</span><br /><span className="pl pl-1">临到田地的出产，</span><br /><span className="pl pl-1">临到人类和动物，</span><br /><span className="pl pl-1">临到双手辛劳所得的一切。”</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 50:10; 以斯拉记 5:2; 哈该书 1:14"> 那时，撒拉铁的儿子所罗巴伯和约萨达的儿子大祭司约书亚，以及所有的余剩之民，都听从了他们的神耶和华的吩咐，就是他们的神耶和华派遣先知哈该所说的话；子民都在耶和华面前心存敬畏。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 43:2; 马太福音 28:20; 玛拉基书 3:1"> 耶和华的使者哈该，奉耶和华的差遣对子民说：“我与你们同在。这是耶和华的宣告。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志下 36:22; 希伯来书 13:21; 哈该书 2:21"> 耶和华触动了撒拉铁的儿子犹大省长所罗巴伯的心，约萨达的儿子大祭司约书亚的心，以及所有余剩之民的心，他们就来，为他们的神万军之耶和华的殿宇做工。</span>
<span className="v" id="v15" data-v="15" data-xref="哈该书 1:1; 哈该书 2:20; 哈该书 2:1"> 这是在大流士王第二年的六月二十四日。</span>
</div>
</div>

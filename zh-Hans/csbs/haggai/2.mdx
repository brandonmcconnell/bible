<span className="v" id="v1" data-v="1" data-xref="哈该书 1:1; 哈该书 2:20; 哈该书 2:10"> 七月二十一日，耶和华的话语临到先知哈该，说：</span>
<span className="v" id="v2" data-v="2" data-xref="哈该书 1:1; 尼希米记 8:9; 以斯拉记 2:63"> “现在你要吩咐撒拉铁的儿子犹大省长所罗巴伯，约萨达的儿子大祭司约书亚，以及余剩之民，说：</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 3:12; 哈该书 2:9; 以西结书 7:20"> 你们中间，哪个余剩者见过这殿宇先前的荣耀呢？你们现在怎么看这殿宇呢？在你们眼中，难道它不是如同无有吗？</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 28:20; 约书亚记 1:9; 撒迦利亚书 8:9"> 现在，所罗巴伯啊，你要坚强！这是耶和华的宣告。约萨达的儿子大祭司约书亚啊，你要坚强！这地所有的子民哪，你们要坚强！这是耶和华的宣告。你们行动吧，因为我与你们同在。这是万军之耶和华的宣告。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 34:10; 出埃及记 29:45–46; 以赛亚书 41:13"> 这是照着你们出埃及时我与你们所立的约，我的灵住在你们中间，你们不要害怕。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="希伯来书 12:26–28; 以赛亚书 10:25; 马可福音 13:24–26"> “是的，万军之耶和华如此说：再过不久，我必震动诸天和大地、海洋和陆地。</span>
<span className="v" id="v7" data-v="7" data-xref="玛拉基书 3:1; 列王纪上 8:11; 约翰福音 7:37–39"> 我必震动万国，万国的财宝都必运来，我要使这殿宇充满荣耀。这是万军之耶和华说的。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 50:10–12; 诗篇 24:1; 以赛亚书 60:17"> 银子是我的，金子也是我的。这是万军之耶和华的宣告。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 85:8–9; 哥林多后书 3:9–10; 歌罗西书 1:19–21"> 万军之耶和华说：这殿宇后来的荣耀，必大过先前的荣耀；并且在这地方，我必赐下平安。这是万军之耶和华的宣告。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="哈该书 2:20; 哈该书 1:1; 哈该书 1:15–1"> 大流士第二年的九月二十四日，耶和华的话语临到先知哈该，说：</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 10:10–11; 玛拉基书 2:7; 申命记 33:10"> “万军之耶和华如此说：你去向祭司们询问律法，说：</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 6:27; 马太福音 23:19; 利未记 7:6"> 如果有人用衣襟兜了神圣的肉，又用那衣襟碰了饼、汤、酒、油等任何食物，这些食物就会分别为圣吗？”<br />祭司们回答说：“不会。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 5:2–3; 民数记 19:11–22; 利未记 22:4–6"> 哈该又问：“如果有人碰了尸体而成为不洁净的，又碰了这些东西里的任何一样，这东西会不洁净吗？”<br />祭司们回答说：“会不洁净。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="箴言 28:9; 提多书 1:15; 以赛亚书 1:11–15"> 哈该就说：“这子民、这民族在我面前也是如此。这是耶和华的宣告。他们手所做的一切也是如此，他们在我面前献上的，都是不洁净的。</span>
<span className="v" id="v15" data-v="15" data-xref="哈该书 1:5; 以斯拉记 3:10; 以斯拉记 4:24"> 现在你们要反思，今天之前，就是耶和华的圣殿还没有一块石头垒在另一块石头上的时候，</span>
<span className="v" id="v16" data-v="16" data-xref="哈该书 1:6; 玛拉基书 2:2; 箴言 3:9–10"> 有人来到二十斗的谷堆，那里却只有十斗；有人来到榨酒池，想舀五十桶，那里却只有二十桶。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 28:22; 哈该书 1:11; 哈该书 1:9"> 我用枯焦、霉烂、冰雹打击你们和你们手所做的一切，但你们还是不归向我。这是耶和华的宣告。</span>
<span className="v" id="v18" data-v="18" data-xref="撒迦利亚书 8:9; 哈该书 2:15; 以斯拉记 5:1–2"> 现在你们要反思，今天之前，就是九月二十四日奠定耶和华圣殿根基的日子之前——你们要反思——</span>
<span className="v" id="v19" data-v="19" data-xref="玛拉基书 3:10; 哈巴谷书 3:17–18; 箴言 3:9–10"> 仓里还有种子吗？葡萄树、无花果树、石榴树和橄榄树，也都没有结果子。但从今天开始，我要祝福你们。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 耶和华的话语在当月二十四日，第二次临到哈该，说：</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亚书 4:6–10; 哈该书 2:6–7; 哈该书 1:1"> “你要告诉犹大省长所罗巴伯说：我将震动诸天和大地，</span>
<span className="v" id="v22" data-v="22" data-xref="弥迦书 5:10; 士师记 7:22; 西番雅书 3:8"> 倾覆各国的王权，除灭列邦的势力；我要倾覆战车和乘驾者，战马和骑士都将倒在各人兄弟的刀剑之下。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 43:10; 以赛亚书 42:1; 雅歌 8:6"> 这是万军之耶和华的宣告：在那日，我必拣选你；我的仆人，撒拉铁的儿子所罗巴伯啊，这是耶和华的宣告：我必以你为印戒，因为我拣选了你。这是万军之耶和华的宣告。”</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 8:6; 马太福音 6:33; 哥林多后书 4:18"> 所以，你们如果已经与基督一同复活了，就应当寻求上面的事；在那里，基督坐在神的右边。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 2:15–17; 历代志上 22:19; 歌罗西书 3:1"> 你们要思想上面的事，不要思想地上的事，</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 2:20; 罗马书 6:2; 歌罗西书 2:20"> 因为你们已经死了，你们的生命与基督一同藏在神里面。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 11:25; 约翰一书 3:2; 加拉太书 2:20"> 基督是你们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你们——有古抄本作“我们”。">a</a></sup>的生命，当他显现的时候，你们那时也就和他一同在荣耀里显现。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="罗马书 8:13; 加拉太书 5:19–21; 加拉太书 5:24"> 所以，当把你们属世的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="属世的——原文直译“地上的”。">b</a></sup>各个部分看为死了的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="看为死了的——或译作“处死”。">c</a></sup>，就如淫乱、污秽、邪情、恶欲和贪心，贪心就是拜偶像。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所书 5:6; 罗马书 1:18; 彼得前书 1:14"> 为了这些事，神的震怒就临到那些不信从的儿女身上<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="神的震怒就临到那些不信从的儿女身上——有古抄本作“神的震怒就要来临”。">d</a></sup>；</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 2:2; 彼得前书 4:3–4; 罗马书 6:19–20"> 当你们从前生活在这些事中的时候，也在其中生活<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="生活——原文直译“行走”。">e</a></sup>。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 4:29; 以弗所书 4:22; 雅各书 1:20–21"> 但如今，你们也要脱去一切暴怒、愤恨、恶毒、毁谤，以及从你们口中所出的污秽的话；</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 4:22; 以弗所书 4:25; 利未记 19:11"> 不要彼此说谎，因你们已经脱去了旧人和旧人的所作所为，</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 4:23–24; 罗马书 12:2; 以弗所书 2:10"> 并且穿上了新人。这新人照着创造他那一位的形像不断地被更新，以致真正认识他。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太书 3:28–29; 哥林多前书 12:13; 罗马书 10:12"> 在这里没有希腊人和犹太人，受割礼的和不受割礼的，外族人、塞西亚人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="塞西亚人——原文直译“野蛮人”。">f</a></sup>、奴隶、自由人；而基督就是一切，也在一切之中。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以弗所书 4:32; 以弗所书 4:2; 约翰一书 4:19"> 因此，你们身为蒙神拣选、圣洁和蒙爱的人，就应当穿上怜悯的心肠<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="心肠——或译作“情感”。">g</a></sup>，以及仁慈、谦卑、温柔、耐心。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 4:32; 马可福音 11:25; 雅各书 2:13"> 如果一个人对另一个人怀有不满，总要彼此容忍，互相饶恕。正如主<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="主——有古抄本作“基督”。">h</a></sup>饶恕了你们，你们也当如此。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 4:8; 以弗所书 5:2; 哥林多前书 13:1–13"> 在这一切之上，还要穿上爱——爱就是成熟境界的联结。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比书 4:6–7; 约翰福音 14:27; 以赛亚书 26:3"> 又要让基督<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="基督——有古抄本作“神”。">i</a></sup>的和平在你们心里做主；你们也为此蒙召归于一体。你们要有感谢的心。</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 119:11; 以弗所书 5:19; 约翰福音 15:7"> 你们要让基督的话语丰丰富富地住在你们里面，要用一切的智慧彼此教导、劝诫，怀着感恩的心，以诗篇、圣诗、属灵的诗歌来歌颂神<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="神——有古抄本作“主”。">j</a></sup>。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 10:31; 歌罗西书 3:23; 箴言 3:6"> 你们无论做什么，或在言语上或在行为上，都要奉主耶稣的名，藉着他感谢父神。</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="以弗所书 5:22–9; 提多书 2:4–5; 哥林多前书 11:3"> <span className="pl pl-1">你们做妻子的，要服从丈夫，这在主里是合宜的；</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="彼得前书 3:7; 创世记 2:23–24; 歌罗西书 3:21"> <span className="pl pl-1">你们做丈夫的，要爱妻子，不可对她们怀有苦毒；</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 20:12; 以弗所书 6:1–3; 箴言 6:20"> <span className="pl pl-1">你们做儿女的，要凡事顺从父母，因为这在主里是蒙喜悦的；</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 4:1–4; 以弗所书 6:4; 诗篇 103:13"> <span className="pl pl-1">你们做父亲的，不要惹自己儿女生气，免得他们灰心丧志；</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 6:5–7; 提摩太前书 6:1–2; 加拉太书 1:10"> <span className="pl pl-1">你们做奴仆的，凡事都要顺从自己在世上的</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="世上的——原文直译“肉体的”。">k</a></sup><br /><span className="pl pl-1">主人，不要只在人眼前服事，像是讨人的欢心，而要以忠实的心敬畏主</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="主——有古抄本作“神”。">l</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="歌罗西书 3:17; 以弗所书 6:6–7; 罗马书 14:8"> <span className="pl pl-1">你们无论做什么，都要从心里去做，像是为主做的，不是为人做的；</span></span>
<span className="v" id="v24" data-v="24" data-xref="以弗所书 6:8; 加拉太书 1:10; 使徒行传 20:32"> <br /><span className="pl pl-1">因为你们知道，你们将要从主那里得到继业为报偿；你们当服事主基督</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="你们当服事主基督——或译作“你们当为主基督做奴仆”。">m</a></sup><br /><span className="pl pl-1">。</span></span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 10:34; 罗马书 2:11; 哥林多后书 5:10"> <br /><span className="pl pl-1">要知道，那行不义的，将要照着他所行的不义来领受回报；主是不偏待人的。</span></span>
</div>
</div>

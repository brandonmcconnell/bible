<span className="v" id="v1" data-v="1" data-xref="以弗所书 6:8–20; 雅各书 2:13; 申命记 24:14–15"> <span className="pl pl-1">你们做主人的，要公正、公平地对待奴仆，因为你们知道，你们也有一位主人在天上。</span></span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦前书 5:17–18; 腓立比书 4:6; 以弗所书 6:18"> 你们要恒切祷告，祷告中要保持警醒，怀着感谢的心。</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所书 6:19–20; 使徒行传 14:27; 帖撒罗尼迦后书 3:1–2"> 同时也要为我们祷告：愿神给我们开福音<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="福音——原文直译“话语”或“道”。">a</a></sup>的门，使我们能传讲基督的奥秘——我也是为此被捆锁的，</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 4:1–4; 以弗所书 6:20; 歌罗西书 4:6"> 愿我能照着所当说的，把这奥秘显明出来。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 5:15–17; 帖撒罗尼迦前书 4:12; 雅各书 3:13"> 你们要把握机会<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="要把握机会——原文直译“要赎回时机”。">b</a></sup>，对外面的人靠智慧行事。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所书 4:29; 彼得前书 3:15; 传道书 10:12"> 你们的话语总要带着恩惠，像用盐调和过的，好使你们知道该怎样回答每一个人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以弗所书 6:21–23; 使徒行传 20:4; 提摩太后书 4:12"> 有关我的一切事，特其库斯会让你们明白。他是蒙爱的弟兄、忠心的仆人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="仆人——或译作“执事”。">c</a></sup>，是在主里同做奴仆<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="奴仆——或译作“仆人”。">d</a></sup>的。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 6:22; 歌罗西书 2:2; 腓立比书 2:28"> 我正是为此派他到你们那里去，好让你们知道有关我们的事<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="好让你们知道有关我们的事——有古抄本作“好让他知道有关你们的事”。">e</a></sup>，并且让他安慰你们的心。</span>
<span className="v" id="v9" data-v="9" data-xref="腓利门书 1:10–19; 歌罗西书 4:7"> 与他一起去的奥尼斯莫，是一位忠心、蒙爱的弟兄，是你们那里的人。他们会把这里的一切情况都让你们明白。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="腓利门书 1:24; 提摩太后书 4:11; 使徒行传 19:29"> 与我一起坐牢的亚里达古问候你们。巴拿巴的表弟马可也问候你们。关于马可，你们已经领受了指示：如果他到你们那里去，你们要接受他。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 11:2; 哥林多后书 6:1; 使徒行传 10:45"> 称为犹斯托的耶数也问候你们。在割礼派的人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="割礼派的人——或译作“受割礼的人”。">f</a></sup>中，只有这几个人是为了神的国与我同工的；他们也成了我的安慰。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 15:30; 歌罗西书 1:9; 歌罗西书 1:7"> 以帕弗拉问候你们；他来自你们那里，是基督耶稣的奴仆；他在祷告中，总是为你们竭力祈求<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="竭力祈求——原文直译“争战”。">g</a></sup>：愿你们成熟、站立得住，在神的一切旨意中确信不疑<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="确信不疑——有古抄本作“得以完全”。">h</a></sup>；</span>
<span className="v" id="v13" data-v="13" data-xref="歌罗西书 2:1; 罗马书 10:2; 启示录 1:11"> 其实我可以为他见证：他为了你们和那些在劳迪西亚和希拉波利斯的人，多受劳苦<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="多受劳苦——有古抄本作“多有热心”。">i</a></sup>。</span>
<span className="v" id="v14" data-v="14" data-xref="腓利门书 1:24; 提摩太后书 4:10–11"> 蒙爱的医生路加和迪马斯问候你们。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 16:5; 腓利门书 1:2; 哥林多前书 16:9"> 请问候在劳迪西亚的弟兄们，还有宁法以及在她<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="她——有古抄本作“他”。">j</a></sup>家里的教会。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦前书 5:27; 帖撒罗尼迦后书 3:14"> 这封书信在你们那里宣读了以后，也一定要在劳迪西亚的教会中宣读；你们也要宣读从劳迪西亚转来的书信。</span>
<span className="v" id="v17" data-v="17" data-xref="腓利门书 1:2; 使徒行传 1:17; 以西结书 44:23–24"> 请你们告诉阿其波斯：“在主里所领受的服事工作，要留心把它完成。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="希伯来书 13:3; 提摩太后书 4:22; 提摩太前书 6:21"> 我保罗亲笔问候：请你们记住我所受的捆锁。愿恩典与你们同在！<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="有古抄本附“阿们。”">k</a></sup></span>

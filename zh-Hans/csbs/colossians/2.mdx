<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 1:29; 腓立比书 1:30; 启示录 3:14–22"> 我希望你们知道，我为你们和那些在劳迪西亚的人，以及一切没有亲自<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="亲自——原文直译“在肉体上”。">a</a></sup>看到我面的人，有多么大的争战，</span>
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 1:27; 歌罗西书 4:8; 以弗所书 6:22"> 好让他们的心受到安慰，在爱中结合在一起，以致得到<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="得到——辅助词语。">b</a></sup>由悟性的确信不疑而来的一切丰盛，直到真正认识神的奥秘，就是基督<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="基督——有古抄本作“父与基督”。">c</a></sup>——</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 1:24; 哥林多前书 1:30; 罗马书 11:33"> 在他里面隐藏着一切智慧和知识的财宝。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰一书 4:1; 以弗所书 4:14; 罗马书 16:18–19"> 我说这话，是免得有人用花言巧语欺骗你们。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 5:3–4; 帖撒罗尼迦前书 2:17; 哥林多前书 16:13"> 因为，我虽然身体不在你们那里，心灵却与你们同在，而且看见你们有秩序，对基督的信仰也坚定不移，我就感到快乐。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 1:10; 约翰一书 2:6; 帖撒罗尼迦前书 4:1"> 所以，你们怎样接受了主基督耶稣<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="接受了主基督耶稣——或译作“接受了基督耶稣为主”。">d</a></sup>，就应当怎样在他里面行事<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="行事——原文直译“行走”。">e</a></sup>，</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 3:17; 耶利米书 17:8; 以弗所书 2:20–22"> 照着你们所受的教导，在他里面得以扎根、建造，在信仰上得以确立，在感谢中丰足有余。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="提摩太前书 6:20; 以弗所书 5:6; 马太福音 7:15"> 你们要当心，免得有人用哲学和虚空的妄言把你们掳去；那些是出于人的传统，出于世界的原则，而不是出于基督。</span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 1:19; 约翰福音 10:30; 约翰福音 1:14"> 这是因为神本性的一切丰盛完美都有形有体地居住在基督里面；</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 3:19; 歌罗西书 1:16–18; 以弗所书 1:20–23"> 你们在他里面已经得以满足，他是一切统治者和掌权者的元首<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="元首——原文直译“头”。">f</a></sup>；</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 2:29; 腓立比书 3:3; 罗马书 6:6"> 在他里面，你们也受了割礼，不是藉着人的手，而是藉着脱去那血肉之躯，藉着基督的割礼。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 6:3–5; 彼得前书 3:21; 加拉太书 3:27"> 你们既然在洗礼中与基督一同被埋葬，也就在洗礼中<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="在洗礼中——或译作“在基督里面”。">g</a></sup>与基督一同复活了，这是藉着相信使基督从死人中复活之神的作为。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 2:5–6; 罗马书 8:11; 以弗所书 2:1"> 你们从前在自己的过犯和没有受割礼的肉体中是死的，神却使你们与基督一同活过来了。神已经赦免了我们<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="我们——有古抄本作“你们”。">h</a></sup>的一切过犯，</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 44:22; 以弗所书 2:14–16; 以赛亚书 43:25"> 抹去了在敌对我们的那些规条中反对我们的债务记录，并且把它从中除掉，钉在十字架上。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 2:14; 以弗所书 4:8; 马太福音 12:29"> 神既然剥夺了那些统治者和掌权者的权势<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="的权势——辅助词语。">i</a></sup>，就公开羞辱<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="公开羞辱——或译作“示众”。">j</a></sup><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="羞辱——原文直译“展示”。">k</a></sup>他们；藉着基督<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="基督——原文直译“他”或“它”；或指“十字架”。">l</a></sup>向他们夸胜<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="夸胜——原文直译“举行凯旋仪式”或“使……做凯旋仪式中的俘虏”。">m</a></sup>了。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="罗马书 14:5–6; 罗马书 14:10; 加拉太书 4:10"> 所以，在吃喝的事上，或在有关节日、月朔或安息日的事上，不要让人评断你们。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 10:1; 希伯来书 8:5; 约翰福音 1:17"> 这些不过是将来之事的影子，而实体却属于基督。</span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 2:8; 约翰一书 4:1–2; 歌罗西书 2:23"> 不要让任何人藉着故意谦卑和敬拜天使来夺去你们的奖赏；他们沉迷在自己所看到的幻象<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="幻象——辅助词语。">n</a></sup>中，在自己肉体的理性之下，毫无理由地自我膨胀，</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所书 4:15–16; 约翰福音 15:4–6; 彼得后书 3:18"> 不与元首<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="元首——原文直译“头”。">o</a></sup>紧密相连。本于他，全身得到供应，藉着关节和筋络结合在一起，在属神的成长中长大。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="歌罗西书 2:8; 歌罗西书 2:16; 加拉太书 4:3"> 你们如果已经和基督一同死了，脱离了世界的原则，为什么还像活在这世俗中一样，拘守那些</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太前书 4:3; 创世记 3:3; 以赛亚书 52:11"> “不可碰，不可尝，不可摸”之类的条例呢？</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 29:13; 提多书 1:14; 哥林多前书 6:13"> 这些东西都是一经使用就要衰朽<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="衰朽——或译作“败坏”。">p</a></sup>的，是出于人的规条和教义；</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太前书 4:8; 歌罗西书 2:18; 歌罗西书 2:8"> 它们虽然藉着自造宗教、谦卑低微、苦待身体，外表有智慧，但在对付放任肉体的事上，没有任何价值。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 1:1; 哥林多前书 1:1; 腓利门书 1:1"> 照着神的旨意做基督耶稣使徒的保罗，以及弟兄提摩太，</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="彼得后书 1:2; 以弗所书 1:1; 罗马书 1:7"> 致歌罗西的圣徒们，就是在基督里忠心的弟兄：<br />愿恩典与平安从神我们的父<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="父——有古抄本作“父和主耶稣基督”。">a</a></sup>临到你们！</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="帖撒罗尼迦前书 1:2; 歌罗西书 1:9; 提摩太后书 1:3"> 我们为你们祷告的时候，总是感谢神我们主耶稣基督的父，</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 1:15; 帖撒罗尼迦后书 1:3; 帖撒罗尼迦前书 1:3"> 因为我们听说了你们在基督耶稣里的信仰，以及对所有圣徒所怀的爱——</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前书 1:3–4; 以弗所书 1:13; 提摩太后书 4:8"> 这信心和爱是藉着那为你们存留在天上的盼望，这盼望是你们在传到你们那里的福音真理之话语中所听过的，</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 15:16; 腓立比书 1:11; 歌罗西书 1:23"> 正如它在全世界，不断地结果子和扩展<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="扩展——原文直译“生长”。">b</a></sup><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="不断地结果子和扩展——有古抄本作“不断地结果子”。">c</a></sup>；自从你们在真理中听见并了解神恩典的那一天起，在你们中间也像这一样，</span>
<span className="v" id="v7" data-v="7" data-xref="歌罗西书 4:12; 腓利门书 1:23; 歌罗西书 4:7"> 正如你们从蒙爱的人，就是与我们同做奴仆的以帕弗拉那里所学到的；他为你们<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="你们——有古抄本作“我们”。">d</a></sup>做了基督忠心的仆人<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="仆人——或译作“执事”。">e</a></sup>，</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 15:30; 提摩太后书 1:7; 加拉太书 5:22"> 也把你们在圣灵里的爱告诉了我们。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="雅各书 3:17; 腓立比书 1:9–11; 雅各书 1:5"> 为此，我们自从听到这事的那一天起，就不断地为你们祷告和祈求：愿你们藉着一切属灵的智慧和悟性，能被神旨意的真正知识所充满；</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 4:1; 希伯来书 13:21; 彼得后书 1:2–3"> 好让你们行事为人配得上主，凡事蒙他喜悦，在一切美善的工作中结出果子，在神的真正知识上不断长进。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 3:16; 腓立比书 4:13; 以弗所书 4:2"> 愿你们按照他荣耀的权能，藉着一切能力得以刚强，好让你们凡事忍耐宽容，怀着喜乐的心</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 20:32; 以弗所书 1:11; 以弗所书 1:18"> 感谢父——他使你们<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="你们——有古抄本作“我们”。">f</a></sup>能够分享圣徒们在光明中的继业；</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 5:8; 使徒行传 26:18; 彼得前书 2:9"> 他救我们脱离了黑暗的权势，把我们迁入他爱子的国度；</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所书 1:7; 罗马书 3:24–25; 彼得前书 1:19–20"> 在他里面，<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附“藉着他的血，”。">g</a></sup>我们得蒙救赎，罪得赦免。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="希伯来书 1:3; 约翰福音 14:9; 约翰福音 1:1"> <span className="pl pl-1">爱子是那不可见之神的形像，</span><br /><span className="pl pl-1">是一切被造之物的长子</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="长子——原文直译“首生者”。">h</a></sup><br /><span className="pl pl-1">，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 11:36; 约翰福音 1:3; 哥林多前书 8:6"> <span className="pl pl-1">因为万有都是藉着他造的：</span><br /><span className="pl pl-1">天上和地上的，看得见和看不见的，</span><br /><span className="pl pl-1">无论王位或主权，统治的或掌权的，</span><br /><span className="pl pl-1">一切都是藉着他造的，也是为他而造的，</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 1:3; 哥林多前书 8:6; 使徒行传 17:28"> <span className="pl pl-1">他在万有之先，万有也藉着他而存在，</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 1:22–23; 启示录 1:5; 以弗所书 4:15–16"> <span className="pl pl-1">他是身体的头，就是教会的头，</span><br /><span className="pl pl-1">他是元始，是从死人中首先复活的</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="首先复活的——原文直译“首生的”或“长子”。">i</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">为要使他能在万有中居首位，</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 2:9; 约翰福音 1:16; 以弗所书 1:23"> <span className="pl pl-1">因为父</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="父——原文直译“他”。">j</a></sup><br /><span className="pl pl-1">乐意使一切的丰盛完美都住在他里面，</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 5:18–21; 以弗所书 1:10; 约翰一书 4:9–10"> <span className="pl pl-1">又藉着他在十字架上所流的血成就了和平，</span><br /><span className="pl pl-1">就是藉着他使万有——无论地上的或天上的——</span><br /><span className="pl pl-1">都与他自己和好了。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以弗所书 2:12; 提多书 3:3–7; 以弗所书 2:1–3"> 从前，你们在邪恶的行为中与神<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="与神——辅助词语。">k</a></sup>隔绝，在意念中与他为敌；</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 5:27; 犹大书 1:24; 以弗所书 1:4"> 但如今，神在基督的血肉之躯上，藉着死使你们与他自己和好了，并且使你们站在他面前，是圣洁、毫无瑕疵、无可指责的。</span>
<span className="v" id="v23" data-v="23" data-xref="希伯来书 3:14; 希伯来书 3:6; 马太福音 24:13–14"> 可是你们要持守信仰，立定根基，坚定不移，不要从你们所听到的福音盼望上被挪去。这福音是传给天下万人<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="万人——原文直译“一切被造之物”。">l</a></sup>的，我保罗也成了这福音的仆人<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="仆人——或译作“执事”。">m</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="罗马书 5:3; 提摩太后书 1:8; 哥林多后书 1:5–8"> 如今我为你们受苦难，感到欢喜；并且我为基督的身体，就是教会，要在我的肉体上补满基督患难的缺欠。</span>
<span className="v" id="v25" data-v="25" data-xref="以弗所书 3:2; 歌罗西书 1:23; 加拉太书 2:7–8"> 神为了你们的缘故赐给了我任务<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="任务——或译作“管家的任务”。">n</a></sup>，我按照这任务成为教会的仆人<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="仆人——或译作“执事”。">o</a></sup>，为要使神的话语<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="神的话语——或译作“神的道”。">p</a></sup>完全传开<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="传开——辅助词语。">q</a></sup>。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 8:10; 罗马书 16:25–26; 以弗所书 3:3–10"> 这话语就是历世历代被隐藏的奥秘，但如今已经显明给他的圣徒们。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 14:20; 罗马书 8:10; 以弗所书 3:16–17"> 神愿意在外邦人中，让他们明白什么是这奥秘的荣耀的丰盛；那就是：基督在你们里面，他是荣耀的盼望！</span>
<span className="v" id="v28" data-v="28" data-xref="以弗所书 5:27; 耶利米书 3:15; 以弗所书 4:11–13"> 我们传扬基督，用一切的智慧劝诫所有人，教导所有人，好让我们使所有的人在基督<sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="基督——有古抄本作“基督耶稣”。">r</a></sup>里成熟<sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="成熟——或译作“完全”。">s</a></sup>，能够献给神<sup className="fn"><a href="#fn-t" id="fnref-t" data-fn="神——辅助词语。">t</a></sup>。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 15:10; 以弗所书 1:19; 哥林多前书 9:25–27"> 我也为此劳苦，藉着他在我里面的大能作为而争战。</span>
</div>
</div>

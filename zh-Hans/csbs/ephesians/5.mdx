<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰一书 4:11; 彼得前书 1:15–16; 以弗所书 4:32"> 所以，做为蒙爱的儿女，你们要效法神；</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 13:34; 加拉太书 2:20; 歌罗西书 3:14"> 要在爱中行事<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="行事——原文直译“行走”。">a</a></sup>，就像基督也爱了我们，为我们舍弃了自己，做供物和祭物献给神，成为馨香的气味。</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 3:5; 以弗所书 5:5; 加拉太书 5:19–21"> 至于淫乱和一切污秽，或是贪心，在你们中间连提都不可提，这样才与圣徒相宜。</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 3:8; 以弗所书 4:29; 帖撒罗尼迦前书 5:18"> 污秽的言行、愚妄的话语、下流的笑话，这些都不合宜；反而倒要说感谢的话。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 5:21; 哥林多前书 6:9–10; 以弗所书 5:3"> 实际上你们应当清楚知道这一点：所有淫乱的、污秽的，或贪心的——就是拜偶像的——在基督和神的国度里都得不到继业。</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="罗马书 1:18; 歌罗西书 2:8; 马太福音 24:4"> 不要让任何人用虚空的话把你们欺骗了；正是为了这些，神的震怒就临到那些不信从的儿女<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="不信从的儿女——或译作“悖逆的人”。">b</a></sup>身上。</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 18:4; 以弗所书 5:11; 提摩太前书 5:22"> 所以，不要与他们同伙。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 8:12; 约翰一书 1:7; 使徒行传 26:18"> 你们从前原是黑暗，但如今在主里就是光；你们要像属于光的儿女行走，</span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 3:9–10; 加拉太书 5:22–23; 约翰三书 1:11"> 原来属于光的果子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="属于光的果子——有古抄本作“圣灵的果子”。参《加拉太书》5:22。">c</a></sup>，就是一切良善、公义、真理；</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 12:1–2; 希伯来书 12:28; 诗篇 19:14"> 要分辨什么是主所喜悦的事。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 13:12; 提摩太前书 5:20; 帖撒罗尼迦后书 3:6"> 你们不要参与那些属黑暗结不出果子的事，反而要把那些事揭露出来，</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 5:3; 耶利米书 23:24; 传道书 12:14"> 因为他们暗中所做的，连说出来也是可耻的。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 3:20–21; 哥林多前书 4:5; 何西阿书 2:10"> 然而，一切被光所揭露的事，都要成为明显的，</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 60:1; 罗马书 13:11–12; 以赛亚书 26:19"> 因为使一切成为明显的，就是光。所以有话说：<br /><span className="pl pl-1">“醒过来！睡着的人哪，从死人中起来吧！</span><br /><span className="pl pl-1">基督就要光照你了！”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 4:5; 雅各书 3:13; 腓立比书 1:27"> 所以，你们要仔细察看怎样行事为人，不要像没有智慧的人，而要像有智慧的人；</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 4:5; 阿摩司书 5:13; 约翰福音 12:35"> 要把握机会<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="要把握机会——原文直译“要赎回时机”。">d</a></sup>，因为这时代是邪恶的。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 12:2; 帖撒罗尼迦前书 5:18; 歌罗西书 1:9"> 为此，不要做愚妄的人，而要领悟主的旨意是什么。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 20:1; 路加福音 1:15; 罗马书 13:13"> 不要醉酒，醉酒带来<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="带来——原文直译“就是”。">e</a></sup>放荡，而要被圣灵充满：</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 3:16; 哥林多前书 14:26; 诗篇 95:2"> <span className="pl pl-1">用诗篇、圣诗、属灵的诗歌彼此对说，</span><br /><span className="pl pl-1">从你们的心里，歌颂赞美主；</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="歌罗西书 3:17; 帖撒罗尼迦前书 5:18; 希伯来书 13:15"> <span className="pl pl-1">奉我们主耶稣基督的名，</span><br /><span className="pl pl-1">为一切常常感谢父神；</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="腓立比书 2:3; 以弗所书 5:24; 以弗所书 5:22"> <span className="pl pl-1">怀着敬畏基督</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="基督——有古抄本作“神”。">f</a></sup><br /><span className="pl pl-1">的心，彼此服从。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 3:18–1; 彼得前书 3:1–6; 提多书 2:5"> 你们做妻子的，要服从<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本没有“服从”。">g</a></sup>自己的丈夫，如同服从主，</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 11:3–10; 歌罗西书 1:18; 以弗所书 1:22–23"> 因为丈夫是妻子的头，正如基督是教会的头；他也是这身体的救主。</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所书 5:33; 歌罗西书 3:20; 提多书 2:7"> 而且教会怎样服从基督，妻子也照样要在一切事上服从<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附“自己的”。">h</a></sup>丈夫。</span>
<span className="v" id="v25" data-v="25" data-xref="彼得前书 3:7; 歌罗西书 3:19; 以弗所书 5:28"> 你们做丈夫的，要爱自己的妻子，就像基督也爱了教会，为她舍弃了自己。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 10:22; 约翰福音 15:3; 以西结书 36:25"> 基督这么做<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="基督这么做——辅助词语。">i</a></sup>，是要藉着话语，用水<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="用水——或译作“在水里”。">j</a></sup>的洗涤而洁净教会，使她分别为圣，</span>
<span className="v" id="v27" data-v="27" data-xref="歌罗西书 1:22; 希伯来书 9:14; 彼得前书 1:19"> 为要给自己预备一个荣耀的教会，没有污渍、皱纹或任何这类的事，却要她成为圣洁、毫无瑕疵。</span>
<span className="v" id="v28" data-v="28" data-xref="以弗所书 5:25; 马太福音 19:5; 创世记 2:21–24"> 照样，丈夫也应该爱自己的妻子，就像爱自己的身体一样；那爱自己妻子的，就是爱自己。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 34:14–15; 以弗所书 5:31; 传道书 4:5"> 从来没有人恨恶自己的身体，总是保养、顾惜它，就像基督<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="基督——有古抄本作“主”。">k</a></sup>对待教会那样，</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前书 6:15; 哥林多前书 12:12–27; 罗马书 12:5"> 因为我们是基督身体的各个部分<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="部分——或译作“肢体”。">l</a></sup><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="有古抄本附“是属他的肉，属他的骨”。">m</a></sup>。</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 2:24; 马太福音 19:5; 马可福音 10:7–8"> <span className="pl pl-1">“为这缘故，人将离开父母，</span><br /><span className="pl pl-1">与妻子结合，</span><br /><span className="pl pl-1">两个人就成为一体。”</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="启示录 21:2; 哥林多后书 11:2; 以赛亚书 54:5"> 这是极大的奥秘，但我是指着基督和教会说的。</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前书 3:2–7; 以斯帖记 1:20; 以弗所书 5:25"> 不过，你们每一个人也要爱自己的妻子，就像爱自己一样；而妻子要敬重<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="敬重——或译作“敬畏”。">n</a></sup>丈夫。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 1:24; 提摩太后书 1:8; 腓立比书 1:13–16"> 因此，我保罗为你们外邦人做了基督耶稣的囚犯。</span>
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 1:25–27; 提摩太前书 1:11; 提摩太后书 1:11"> 你们一定听说过，为了你们的缘故，神那恩典的任务已经赐给我了；</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 1:12; 罗马书 16:25; 以弗所书 1:9–11"> 也就是说，藉着启示，那奥秘已经显明给我，就像我先前简略写过的那样。</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 4:3; 哥林多前书 4:1; 哥林多后书 11:6"> 你们读了，就能明白我在基督奥秘上的悟性。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前书 1:10–12; 彼得后书 3:2; 提多书 1:1–3"> 这奥秘在别的各世代并不显明给人类<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="人类——原文直译“人的子孙”。">a</a></sup>，不像如今藉着圣灵启示给了他的圣使徒和先知们。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 3:26–29; 约翰一书 1:3; 约翰一书 2:25"> 这奥秘就是：外邦人在基督耶稣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="基督耶稣——有古抄本作“基督”。">b</a></sup>里，藉着福音，成为共同的继承人，同属一体、同蒙应许。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 1:19; 以弗所书 3:20; 以弗所书 3:2"> 我成了这福音的仆人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="仆人——或译作“执事”。">c</a></sup>，是照着神恩典的赏赐；这赏赐是照着他大能的作为赐给我的。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 1:27; 哥林多前书 15:9; 以弗所书 2:7"> 我在所有圣徒中，比最小的还小，但被赐予了这恩典，是为了把基督那无法测度的丰盛传给外邦人；</span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 1:26; 马太福音 13:35; 提摩太后书 1:9"> 并且使所有的人都明白这奥秘的计划<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="计划——或译作“任务”或“管家任务”；有古抄本作“契合”。">d</a></sup>到底是什么，这奥秘自古以来被隐藏在<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附“藉着耶稣基督”。">e</a></sup>创造万有的神里面，</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前书 1:12; 以弗所书 6:12; 哥林多前书 2:7"> 为要使天上的统治者和掌权者，如今藉着教会能明白神各种各样的智慧。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太后书 1:9; 以弗所书 1:11; 以弗所书 1:4"> 这都是照着他在我们主基督耶稣里所成就的永恒心意。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 2:18; 罗马书 5:2; 希伯来书 4:14–16"> 在基督里，藉着信基督，我们能坦然无惧、确信无疑地来到神面前<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="神面前——辅助词语。">f</a></sup>。</span>
<span className="v" id="v13" data-v="13" data-xref="歌罗西书 1:24; 帖撒罗尼迦后书 3:13; 哥林多后书 1:6"> 所以，我请求你们<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="你们——辅助词语。">g</a></sup>，不要因我为你们所受的患难而丧胆<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="丧胆——或译作“胆怯”。">h</a></sup>；这患难是你们的荣耀。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="诗篇 95:6; 以弗所书 1:16–19; 腓立比书 2:10"> 因此，我屈膝在<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附“我们主耶稣基督的”。">i</a></sup>父面前——</span>
<span className="v" id="v15" data-v="15" data-xref="以弗所书 1:10; 启示录 5:8–14; 以弗所书 1:21"> 天上地上的万族都是从他得名的，</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 1:11; 腓立比书 4:13; 以赛亚书 40:29–31"> 愿他按照他那荣耀的丰盛，藉着他的灵，以大能使你们内在的人坚强起来；</span>
<span className="v" id="v17" data-v="17" data-xref="歌罗西书 2:7; 约翰一书 4:16; 约翰福音 14:23"> 使基督藉着你们的信仰，住在你们心里；使你们在爱中扎根，根基稳固，</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 103:11–12; 约伯记 11:7–9; 以弗所书 1:18–23"> 好让你们有能力与所有圣徒一起了解基督的爱<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="基督的爱——辅助词语。">j</a></sup>是多么长、阔、高、深——</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所书 1:23; 歌罗西书 2:9–10; 歌罗西书 1:10"> 明白那超越了人所能<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="人所能——辅助词语。">k</a></sup>理解的基督之爱，好让你们得以满足，达到神一切的丰盛完美。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 9:8; 罗马书 4:21; 耶利米书 32:27"> 神能照着在我们里面做工的大能，成就那远超过我们所求所想的一切事——</span>
<span className="v" id="v21" data-v="21" data-xref="犹大书 1:25; 罗马书 11:36; 彼得后书 3:18"> 愿荣耀在教会里、在基督耶稣里归于神，直到世世代代，永永远远！阿们。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 3:20–25; 箴言 23:22; 箴言 6:20"> 你们做儿女的，要在主里顺从自己的父母，因为这是理所当然的。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 20:12; 申命记 27:16; 马太福音 15:4–6"> “要孝敬父母，使你得福，在地上长寿。”这是第一条<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="-3 第一条——或译作“最重要的”。">a</a></sup>带着应许的诫命。</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 3:21; 箴言 22:6; 箴言 29:15"> 你们做父亲的，不要惹自己儿女生气，而要照着主的训练和警戒养育他们。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="彼得前书 2:18–21; 提多书 2:9–10; 歌罗西书 3:17–24"> 你们做奴仆的，要怀着敬畏和战兢，以忠实的心顺从自己在世上的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="世上的——原文直译“肉体的”。">b</a></sup>主人，就像听从基督一样。</span>
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 3:22–23; 帖撒罗尼迦前书 2:4; 加拉太书 1:10"> 不要只在人眼前服事，像是讨人的欢心，而要像基督的奴仆，从心里遵行神的旨意。</span>
<span className="v" id="v7" data-v="7" data-xref="歌罗西书 3:23; 以弗所书 6:5–6; 哥林多前书 10:31"> 要甘心乐意地服事，如同服事主，不是服事人，</span>
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 3:24; 路加福音 14:14; 箴言 11:18"> 因为你们知道：每个人，无论是奴隶或是自由人，如果做了什么美善的事，就将从主那里领受这事的回报。</span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 3:25–1; 使徒行传 10:34; 罗马书 2:11"> 你们做主人的，对奴仆也要这样做，不要威吓他们，因为你们知道，他们和你们同样有一位主人在天上，而且他是不偏待人的。</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="腓立比书 4:13; 以赛亚书 40:31; 约书亚记 1:9"> 最后，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附“我的弟兄们，”。">c</a></sup>你们要在主里藉着他力量的权能得以刚强。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 10:4; 罗马书 13:12; 以弗所书 6:13"> 你们要配上神的全副武装，使你们得以站立，对付魔鬼的骗局，</span>
<span className="v" id="v12" data-v="12" data-xref="歌罗西书 1:13; 哥林多后书 4:4; 以弗所书 2:2"> 因为我们不是与血肉之体搏斗，而是与那些统治的、掌权的、管辖这黑暗世界的<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="管辖这黑暗世界的——原文直译“属这黑暗的世界掌管者”。">d</a></sup>，以及天上邪恶的属灵势力搏斗。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 10:4; 路加福音 21:36; 以弗所书 6:11–17"> 为此，要拿起神的全副武装，好使你们在邪恶的日子能够抵挡，并且在完成一切以后，还站立得住。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 59:17; 帖撒罗尼迦前书 5:8; 以赛亚书 11:5"> 所以，你们要站立得住：<br /><span className="pl pl-1">用真理束上腰，穿上公义的护胸甲；</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 52:7; 罗马书 10:15; 哥林多后书 5:18–21"> <span className="pl pl-1">把所预备好的和平</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="和平——或译作“平安”。">e</a></sup><br /><span className="pl pl-1">福音，穿在脚上；</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="彼得前书 5:8–9; 约翰一书 5:4–5; 箴言 18:10"> <span className="pl pl-1">在任何情况下，要拿起信仰的盾牌；</span><br /><span className="pl pl-1">你们藉着它就能消灭那恶者一切燃烧的飞箭；</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 4:12; 以赛亚书 59:17; 启示录 19:15"> <span className="pl pl-1">并且要接受救恩的头盔和圣灵的宝剑——就是神的话语。</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 5:17; 歌罗西书 4:2; 腓立比书 4:6"> 你们要以各样的祷告和祈求，藉着圣灵时刻祈祷；而且为此警醒，以极大的忍耐，为所有圣徒祈求，</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 4:3; 使徒行传 4:29; 帖撒罗尼迦后书 3:1"> 也为我祈求，好使我在开口的时候被赐予话语，能坦然无惧地让人明白福音的奥秘——</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 5:20; 歌罗西书 4:4; 提摩太后书 2:9"> 为此，我成了带锁链的特使。请为我祈求<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="请为我祈求——辅助词语。">f</a></sup>，使我能照着应该说的，放胆传道。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 20:4; 提摩太后书 4:12; 提多书 3:12"> 在主里蒙爱的弟兄、忠心的仆人<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="仆人——或译作“执事”。">g</a></sup>特其库斯，会让你们明白一切，好让你们也知道有关我的事和我现在所做的事。</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比书 2:25; 歌罗西书 4:7–8; 帖撒罗尼迦后书 2:17"> 我正是为此派他到你们那里去，好让你们知道有关我们的事，并且让他安慰你们的心。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="加拉太书 6:16; 加拉太书 5:6; 彼得前书 5:14"> 愿平安以及随着信仰的爱，从父神和主耶稣基督临到弟兄们！</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 22:37; 哥林多后书 8:12; 马太福音 6:13"> 愿恩典与所有爱我们主耶稣基督的人同在——直到永远<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="直到永远——原文直译“在不朽中”。">h</a></sup>！<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附“阿们。”">i</a></sup></span>
</div>
</div>

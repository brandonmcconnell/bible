<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 2:13; 以弗所书 2:5–6; 歌罗西书 3:1–4"> 你们因着自己的过犯和罪孽，原是死的；</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 6:12; 约翰一书 5:19; 以弗所书 2:3"> 在其中，你们从前行事为人，是顺着这世界的潮流，顺着那空中势力的掌权者，就是现今在那些不信从的儿女里面做工的灵。</span>
<span className="v" id="v3" data-v="3" data-xref="提多书 3:3; 以弗所书 4:22; 加拉太书 5:16–24"> 我们从前也都生活在他们中间，生活在自己肉体的欲望里，行肉体和意念所愿的事。我们正如其他人，生来也是震怒之下的儿女。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前书 1:3; 以弗所书 1:7; 诗篇 86:15"> 不过神有丰富的怜悯，因着他爱我们的大爱，</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 3:24; 以弗所书 2:8; 罗马书 5:10"> 甚至当我们还死在过犯中的时候，就使我们与基督一同活过来——你们得救是藉着恩典！</span>
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 3:1–3; 以弗所书 1:3; 罗马书 6:4–5"> 神又使我们在基督耶稣里，与基督一同复活、一同坐在天上，</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前书 1:16–17; 提多书 3:4; 以弗所书 2:4"> 为了在将来的各世代中，在基督耶稣里，藉着对我们的仁慈，可以显出他那无限恩典的丰盛。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 3:22–26; 以弗所书 2:5; 罗马书 4:16"> 你们得救确实是藉着恩典、藉着信，这不是出于你们自己，而是神的恩赐；</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太后书 1:9; 罗马书 11:6; 提多书 3:3–5"> 也不是本于行为，免得有人自夸。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比书 2:13; 歌罗西书 1:10; 希伯来书 13:21"> 实际上，我们是神的创作，是为了美善的工作在基督耶稣里被造成的；神早已预备好了美善工作，要我们在其中行事<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="行事——原文直译“行走”。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="歌罗西书 2:11; 歌罗西书 2:13; 歌罗西书 3:11"> 所以你们当记住：从前，你们照着肉体说是外邦人，被那些所谓“受割礼的”称为“没受割礼的”；割礼是人手在肉体上所行的。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 4:8; 歌罗西书 1:21; 耶利米书 31:31–34"> 那时候，你们与基督无关；被排除在以色列国民之外；在那些所应许的诸约上是外人；在这世界上没有盼望、没有神。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 2:39; 歌罗西书 1:20–22; 歌罗西书 1:13–14"> 但如今，在基督耶稣里，你们这些从前在远处的人，藉着基督的血，已经被带到近处了。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 3:28; 歌罗西书 3:11; 歌罗西书 3:15"> 因为他自己是我们的和平，他使两者合而为一，废除了那隔在中间仇恨的墙；以自己的身体，</span>
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 2:14; 加拉太书 3:10; 歌罗西书 1:21–22"> 废除了谕令中诫命的律法，为了把两者在他自己里面造成一个新人，缔造和平。</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 1:20–22; 罗马书 5:10; 哥林多后书 5:18–21"> 他在十字架上既然消除了仇恨，就藉着十字架使两者得以在一个身体里，与神和好；</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 57:19–21; 使徒行传 10:36; 罗马书 5:1"> 并且来传和平<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="和平——或译作“平安”。">b</a></sup>的福音给你们在远处的人，也给那些在近处的人。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 12:13; 以弗所书 3:12; 罗马书 5:2"> 因为藉着基督，我们两者能够在同一位圣灵里，来到父面前。</span>
<span className="v" id="v19" data-v="19" data-xref="腓立比书 3:20; 约翰一书 3:1; 加拉太书 6:10"> 由此可见，你们不再是外人，或寄居的；你们是圣徒的同国之民，是神家里的人，</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前书 2:4–5; 以赛亚书 28:16; 彼得前书 2:7–8"> 并且被建造在使徒和先知的根基上，有基督耶稣自己为房角石。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 3:16–17; 哥林多前书 3:9; 哥林多后书 6:16"> 在基督耶稣里，全部建筑互相连接，渐渐成为在主里的圣殿；</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:4–5; 哥林多前书 3:16; 约翰一书 4:16"> 在他里面，你们也一同被建造，藉着圣灵成为神居住的地方。</span>
</div>

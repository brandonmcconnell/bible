<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 1:10; 腓立比书 1:27; 帖撒罗尼迦前书 2:12"> 所以，我这个在主里的囚犯劝你们：行事为人要配得上你们所蒙的召唤，</span>
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 3:12–13; 哥林多前书 13:7; 哥林多前书 13:4–5"> 要以完全的谦卑和温柔，以耐心，在爱中彼此容忍；</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 1:10; 歌罗西书 3:13–15; 哥林多前书 12:12–13"> 以和平的联结，努力保持属圣灵的合一：</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 2:18; 罗马书 12:4–5; 哥林多前书 12:4–13"> 一个身体、一位圣灵，就像你们蒙召时也被召入一个盼望，</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 8:6; 哥林多前书 12:13; 彼得前书 3:21"> 一位主、一个信仰、一个洗礼、</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 11:36; 玛拉基书 2:10; 哥林多前书 8:6"> 一位神——就是万有之父，他超越万有<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="万有——或译作“万人”。">a</a></sup>，贯通万有，在万有之中。</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="彼得前书 4:10; 罗马书 12:3; 哥林多前书 12:7–11"> 然而，我们每一个人都按照基督恩赐的尺度被赐予了恩典。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 68:18; 歌罗西书 2:15; 撒母耳记上 30:26"> 所以经上说：<br /><span className="pl pl-1">他升上高天的时候，掳掠了俘虏，</span><br /><span className="pl pl-1">把各样的恩惠赐给了人。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约翰福音 3:13; 马太福音 12:40; 箴言 30:4"> 那么“他升上”这话是什么意思呢？难道不也是说<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附“首先”。">b</a></sup>他曾降到地的低层<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="地的低层——或译作“地上更低微的地方”。">c</a></sup>吗？</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 7:26; 希伯来书 4:14; 以弗所书 1:20–23"> 降下来的那一位，也就是为要充满<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="充满——或译作“成就”或“完成”。">d</a></sup>万有而升到诸天之上的那一位。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 3:15; 哥林多前书 12:28–29; 以弗所书 2:20"> 他赐下一些人做使徒，一些人做先知传道<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="做先知传道——原文直译“做先知”。">e</a></sup>，一些人做传福音者，一些人做牧人或教师，</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦前书 5:11–14; 以弗所书 4:16; 哥林多前书 12:27"> 为了要装备圣徒去做服事的工作，以建立基督的身体；</span>
<span className="v" id="v13" data-v="13" data-xref="歌罗西书 1:28; 约翰福音 17:21; 以弗所书 4:5"> 直到我们大家达到在信仰上以及对神儿子真正认识上的合一，达到成熟人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="成熟人——或译作“完全人”。">f</a></sup>的地步，达到基督那丰盛完美的身量。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 13:9; 罗马书 16:17–18; 哥林多前书 14:20"> 这样，我们就不再是小孩子，在人的狡诈和诡计中陷入那迷惑人的骗局，被各种教义之风摇动，飘来飘去。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰一书 3:18; 以弗所书 4:25; 撒迦利亚书 8:16"> 我们却要在爱中说真话，在一切事上向着他长进；他就是头，是基督。</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 2:19; 约翰福音 15:5; 歌罗西书 2:2"> 本于他，全身藉着每一个关节的支持，照着每一个部分<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="部分——或译作“肢体”。">g</a></sup>适当的功用，互相连接，结合在一起，使身体渐渐成长，以致在爱中建立自己。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 1:21; 彼得前书 4:3–4; 帖撒罗尼迦前书 4:1–2"> 所以，我这样说，并且在主里忠告：你们行事不要再像<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附“其余”。">h</a></sup>外邦人那样，在自己虚妄的理性中行事<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="行事——原文直译“行走”。">i</a></sup>；</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 13:15; 以弗所书 2:12; 罗马书 1:21–23"> 他们的意念变为黑暗，因着那在自己里面的愚昧无知和心里的刚硬，就与神的生命隔绝了；</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 3:5; 罗马书 1:24–26; 提摩太前书 4:2"> 他们麻木不仁，任凭自己好色，以致贪婪地行出各样污秽的事。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="提多书 2:11–14; 约翰福音 6:45; 马太福音 11:29"> 但你们学了基督，就不是这样——</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 5:20; 以弗所书 1:13; 希伯来书 3:7–8"> 如果你们真的听从了他，又照着在耶稣里的真理，在他里面受了教导，</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 6:6; 希伯来书 12:1; 雅各书 1:21"> 为了你们脱去在过去行为上的旧人。这旧人顺着迷惑人的私欲受败坏，</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 12:2; 罗马书 8:6; 诗篇 51:10"> 而你们在自己的心灵里得以更新，</span>
<span className="v" id="v24" data-v="24" data-xref="歌罗西书 3:10–14; 哥林多后书 5:17; 以弗所书 2:10"> 并且穿上新人；这新人是照着神的形像<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="的形像——辅助词语。">j</a></sup>，在真理的公义和圣洁中被造成的。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="歌罗西书 3:9; 撒迦利亚书 8:16; 箴言 12:22"> 所以，你们既然脱去虚假，每个人就要与自己邻人说真话，因为我们都是身体的一部分，彼此相属。</span>
<span className="v" id="v26" data-v="26" data-xref="雅各书 1:19; 诗篇 4:4; 诗篇 37:8"> 你们发怒却不可继续犯罪，不可生气到日落，</span>
<span className="v" id="v27" data-v="27" data-xref="雅各书 4:7; 彼得前书 5:8; 以弗所书 6:16"> 也不可给魔鬼留地步。</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太前书 6:18; 帖撒罗尼迦前书 4:11–12; 加拉太书 6:10"> 偷窃的，不可再偷，反而要劳苦做工，亲手做有益处的事<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="有益处的事——或译作“美善的事”。">k</a></sup>，好使自己能有所得，分给有需要的人。</span>
<span className="v" id="v29" data-v="29" data-xref="歌罗西书 4:6; 帖撒罗尼迦前书 5:11; 传道书 10:12"> 任何坏话都不可出口，而是按着需要说造就人的好话，使听的人得到益处。</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒罗尼迦前书 5:19; 以赛亚书 63:10; 以弗所书 1:13–14"> 不要让神的圣灵忧伤；你们蒙了他的印记，直到得赎的日子<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="日子——指“基督再来的日子”。">l</a></sup>。</span>
<span className="v" id="v31" data-v="31" data-xref="歌罗西书 3:8; 传道书 7:9; 提多书 3:2–3"> 你们要除掉一切苦毒、暴怒、愤怒、喧嚷、毁谤，以及一切的恶毒；</span>
<span className="v" id="v32" data-v="32" data-xref="歌罗西书 3:12–13; 马太福音 6:14–15; 马可福音 11:25"> 要以仁慈彼此相待，心存怜悯，互相饶恕，就像神在基督里饶恕了你们<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="你们——有古抄本作“我们”。">m</a></sup>那样。</span>
</div>
</div>

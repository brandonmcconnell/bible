<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理书 11:4; 但以理书 9:2; 但以理书 7:28"> 伯沙撒王在位第三年，又有一个异象向我但以理显现，是在先前向我显现的异象之后。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯帖记 1:2; 尼希米记 1:1; 创世记 10:22"> 我在异象中观看，看见自己在以拦省的苏萨城堡中；我在异象中继续观看，又看见自己在乌莱运河边。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理书 8:20; 但以理书 10:5; 撒迦利亚书 6:1"> 我举目观看，看哪，有一只公绵羊站在运河边！它有两只犄角，两只犄角都很高，其中一只高过另一只，那较高的是后来长起来的。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理书 11:16; 但以理书 11:36; 但以理书 8:7"> 我看见那公绵羊向西、向北、向南冲撞，没有野兽能在它面前站立得住，也没有谁能解救它们脱离它的权势；它任意而行，并高抬自己。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="但以理书 8:21; 但以理书 11:3; 但以理书 8:8"> 我正在领悟这事，看哪，有一只公山羊从西边而来，穿越整个地面，脚<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="脚——辅助词语。">a</a></sup>不沾地！这公山羊的双眼之间有一只显眼的犄角。</span>
<span className="v" id="v6" data-v="6"> 它来到我所看见的站在运河边、有两只犄角的公绵羊那里，在猛烈的怒火中冲向公绵羊。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 7:7; 但以理书 11:11; 约书亚记 8:20"> 我看见公山羊接近公绵羊，怒气冲冲地撞击它，折断了它的两只犄角，公绵羊就没有力量在公山羊面前站立得住。公山羊把它撞倒在地，踩踏它，没有谁能解救公绵羊脱离公山羊的权势。</span>
<span className="v" id="v8" data-v="8" data-xref="但以理书 7:2; 启示录 7:1; 但以理书 5:20"> 于是公山羊极度高抬自己，但正在它强盛的时候，大犄角却被折断了；在其原处有四只显眼的犄角向着天上四方的风长了起来。</span>
<span className="v" id="v9" data-v="9" data-xref="但以理书 11:16; 以西结书 20:6; 以西结书 20:15"> 从其中的一只又长出一只小犄角，向南、向东、向那荣美之地长得极其强大。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 14:13; 启示录 12:4; 但以理书 8:7"> 它变得强大，高达天军<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="天军——或译作“天上的万象”。">b</a></sup>，把一部分天军、一部分星辰摔落在地，并踩踏它们。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 12:11; 启示录 13:5–7; 但以理书 8:25"> 它还高抬自己到天军元帅的地位，废除天军元帅的常献祭，拆毁他的圣所。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 12:1; 以赛亚书 59:14; 但以理书 11:31–36"> 因罪过的缘故，天军与常献的祭一同被交出去；这小犄角把真理抛弃在地，它所做的都顺利。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="启示录 11:2; 启示录 6:10; 路加福音 21:24"> 然后我听见一位圣者在说话，又有一位圣者问那说话的：“这异象，就是有关常献的祭、带来荒凉的罪过、圣所和天军被践踏之事，要到什么时候呢？”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="但以理书 12:7; 但以理书 7:25; 启示录 11:2–3"> 他就回答我：“要经过两千三百个晚上和早晨，那时圣所就必重归为圣<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="圣——或译作“义”。">c</a></sup>。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理书 10:16; 启示录 1:13; 彼得前书 1:10–11"> 我但以理正在观看这异象，想要领悟它，看哪，有一位样貌像人的站在我面前！</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 1:19; 路加福音 1:26; 但以理书 8:2"> 我又听见在乌莱运河中间有人的声音呼喊说：“加百列啊，你当使这人领悟这异象！”</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="但以理书 8:19; 但以理书 12:4; 哈巴谷书 2:3"> 于是加百列来到我所站的地方。他一来，我就惊慌失措，脸伏于地。他对我说：“人子啊，你当领悟，这异象是关于末后的时期！”</span>
<span className="v" id="v18" data-v="18" data-xref="但以理书 10:18; 以西结书 2:2; 但以理书 10:16"> 他与我说话的时候，我脸伏于地沉睡了。他碰了我一下，使我站立起来。</span>
<span className="v" id="v19" data-v="19" data-xref="哈巴谷书 2:3; 但以理书 11:27; 启示录 17:17"> 他说：“看哪，我要使你明白在那愤怒的末期将要发生的事，因为这是关于所定的末后时期。</span>
<span className="v" id="v20" data-v="20" data-xref="但以理书 8:3; 但以理书 11:1–2"> 你所看见的那有两只犄角的公绵羊，就是米底亚王和波斯王。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理书 10:20; 但以理书 11:3; 但以理书 8:5–8"> 那多毛的公山羊就是希腊<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="希腊——原文作“雅完”。">d</a></sup>王，它双眼之间的大犄角是第一个王。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理书 11:4; 但以理书 8:3; 但以理书 8:8"> 这犄角被折断，在它的原处兴起的四只犄角，就是从希腊王的<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="希腊王的——辅助词语。">e</a></sup>国中将要兴起的四个王权，只是他们都没有他的力量。</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 13:11–14; 帖撒罗尼迦后书 2:9–11; 启示录 19:20"> <span className="pl pl-1">在这些王权的末期，</span><br /><span className="pl pl-1">当悖逆者们的悖逆达到极点</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="的悖逆达到极点——传统译作“恶贯满盈”。">f</a></sup><br /><span className="pl pl-1">的时候，</span><br /><span className="pl pl-1">将要兴起一个王，</span><br /><span className="pl pl-1">他傲慢残暴</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="傲慢残暴——原文直译“面貌凶猛”。">g</a></sup><br /><span className="pl pl-1">，诡计多端</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="诡计多端——或译作“能领悟谜题”。">h</a></sup><br /><span className="pl pl-1">；</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="但以理书 8:12; 但以理书 11:31–36; 但以理书 7:25"> <span className="pl pl-1">他的力量必强盛，</span><br /><span className="pl pl-1">却不是出于自己的力量；</span><br /><span className="pl pl-1">他必带来极不寻常的毁灭，</span><br /><span className="pl pl-1">他所做的都顺利；</span><br /><span className="pl pl-1">他必毁灭强者和圣民；</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="但以理书 8:11; 启示录 17:14; 约伯记 34:20"> <span className="pl pl-1">他凭着自己的狡猾，藉着自己的手腕，</span><br /><span className="pl pl-1">使诡诈得逞，</span><br /><span className="pl pl-1">又在心中高抬自己；</span><br /><span className="pl pl-1">他在人安稳无备的时候毁灭许多人，</span><br /><span className="pl pl-1">甚至起来与万君之君作对，</span><br /><span className="pl pl-1">但他必被摧毁，却不是出于人的</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="人的——辅助词语。">i</a></sup><br /><span className="pl pl-1">手。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="但以理书 10:1; 但以理书 12:9; 但以理书 12:4"> <span className="pl pl-1">至于所提到的有关两千三百个晚上和早晨的异象是真实的</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="真实的——或译作“真理”。">j</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">但你要封住这异象，</span><br /><span className="pl pl-1">因为这是关于将来许多的日子。”</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="但以理书 7:28; 哈巴谷书 3:16; 但以理书 8:7"> 我但以理为此精疲力竭，病了几天；然后起来办理王的事务。我因这异象而惊恐，无法领悟它。</span>
</div>

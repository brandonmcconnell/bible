<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="DAN" data-book-slug="daniel" data-book-name="但以理书" data-chapter="3" data-verses="30">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哈巴谷书 2:19; 耶利米书 16:20; 以赛亚书 46:6"> 尼布甲尼撒王造了一座金像，高六十肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="六十肘——相当于27.4公尺。1肘=45.7公分。">a</a></sup>，宽六肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="六肘——相当于2.7公尺。">b</a></sup>；他把这像立在巴比伦省的杜拉平原上。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理书 3:27; 箴言 29:12; 列王纪上 12:32"> 尼布甲尼撒王派遣人招聚行政官、总长、省长、参谋、司库官、司法官、审判官和各省所有的官员，来参加尼布甲尼撒王所立之像的奉献礼。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 17:17; 启示录 17:13; 启示录 13:13–16"> 于是，行政官、总长、省长、参谋、司库官、司法官、审判官和各省所有的官员，都被招聚来参加尼布甲尼撒王所立之像的奉献礼；他们站在尼布甲尼撒所立之像的前面。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="但以理书 4:1; 但以理书 6:25; 弥迦书 6:16"> 那时，传令官大声宣告：“各民族、各国家、各语言群体，以下是给你们的命令：</span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 3:15; 但以理书 3:10; 但以理书 3:7"> 你们一听见号角、竖笛、里拉琴、弦琴、竖琴、风笛和各种乐器的声音，就要向尼布甲尼撒王所立的金像俯伏膜拜；</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 13:50; 马太福音 13:42; 耶利米书 29:22"> 谁不俯伏膜拜，谁就立刻被扔进烈火燃烧的窑中。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="启示录 17:8; 启示录 13:3; 启示录 13:8"> 因此那时候，所有的民族、国家、语言群体一听见号角、竖笛、里拉琴、弦琴、竖琴和各种乐器的声音，就都向尼布甲尼撒王所立的金像俯伏膜拜。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 4:12–16; 但以理书 6:12–13; 以斯帖记 3:8–9"> 当时，有些迦勒底人前来恶意控告犹太人。</span>
<span className="v" id="v9" data-v="9" data-xref="但以理书 5:10; 但以理书 6:6; 但以理书 6:21"> 他们开口对尼布甲尼撒王说：“愿王万岁！</span>
<span className="v" id="v10" data-v="10" data-xref="但以理书 3:4–7; 但以理书 6:12; 以斯帖记 3:12–14"> 王啊，你曾下令：所有听见号角、竖笛、里拉琴、弦琴、竖琴、风笛和各种乐器声音的人，都要向这金像俯伏膜拜；</span>
<span className="v" id="v11" data-v="11"> 谁不俯伏膜拜，谁就必被扔进烈火燃烧的窑中。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理书 6:13; 但以理书 2:49; 使徒行传 17:7"> 有几个你所指派管理巴比伦省事务的犹太人，就是沙德拉克、米沙克、亚伯尼哥；王啊，这些人却不理会你的命令，既不事奉你的神，也不向你所立的金像膜拜！”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="但以理书 3:19; 但以理书 2:12; 以斯帖记 3:5–6"> 尼布甲尼撒就勃然大怒，下令把沙德拉克、米沙克、亚伯尼哥带来；于是这些人被带到王面前。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 50:2; 但以理书 3:1; 以赛亚书 46:1"> 尼布甲尼撒开口对他们说：“沙德拉克、米沙克、亚伯尼哥，你们不事奉我的神，也不向我所立的金像膜拜，是真的吗？</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 5:29; 历代志下 32:15–17; 出埃及记 5:2"> 现在，你们一听见号角、竖笛、里拉琴、弦琴、竖琴、风笛和各种乐器的声音，如果准备向我所造的像俯伏膜拜，那就没有事了<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="那就没有事了——辅助词语。">c</a></sup>；如果不膜拜，你们就立刻被扔进烈火燃烧的窑中。有什么神能从我的手中拯救你们呢？”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="但以理书 1:7; 但以理书 3:12"> 沙德拉克、米沙克、亚伯尼哥回答尼布甲尼撒王，说：“对于这事，我们不需要回应你。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 8:31; 路加福音 1:37; 希伯来书 7:25"> 如果真被扔进火窑中，我们所事奉的神也能从烈火燃烧的窑中拯救我们；王啊，他必从你的手中拯救我们！</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 5:29–32; 马太福音 10:39; 启示录 2:10–11"> 即或不然，王啊，你要知道，我们也绝不会事奉你的神明，不会向你所立的金像膜拜！”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="但以理书 3:13; 利未记 26:24; 箴言 21:24"> 尼布甲尼撒就怒火填膺，对沙德拉克、米沙克、亚伯尼哥变了脸色。他下令把窑烧热，比平常更热七倍；</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 16:23; 使徒行传 16:25; 但以理书 3:15"> 又命令他军队中几个最强壮的人，把沙德拉克、米沙克、亚伯尼哥绑起来，扔进烈火燃烧的窑中。</span>
<span className="v" id="v21" data-v="21"> 于是这三个人穿着长袍、长裤和其他的衣服，戴着头巾，被绑起来扔进了烈火燃烧的窑中。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 12:33; 箴言 21:18; 箴言 11:8"> 由于从王发出的命令急迫，窑又烧得非常热，烈火的火焰烧死了那些抬沙德拉克、米沙克、亚伯尼哥的人。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理书 6:16–17; 耶利米书 38:6; 诗篇 34:19"> 就这样，沙德拉克、米沙克、亚伯尼哥这三个人，被绑着落入了烈火燃烧的窑中。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="但以理书 6:7; 但以理书 6:22; 但以理书 3:9–10"> 那时，尼布甲尼撒王感到惊奇，急忙站起来，开口问他的谋士们：“我们绑起来扔进烈火中的，难道不是三个人吗？”<br />他们回答王，说：“王啊，是的！”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 43:2; 使徒行传 28:5; 马可福音 16:18"> 王回应说：“看哪，我看到有四个人，并没有被绑着，在烈火中行走，身上也没有损伤，而那第四个人，他的样貌仿佛神子。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="但以理书 3:17; 以赛亚书 52:12; 启示录 19:5"> 于是，尼布甲尼撒靠近烈火燃烧的窑门，开口说：“至高神的仆人沙德拉克、米沙克、亚伯尼哥，你们出来，到这里来吧！”沙德拉克、米沙克、亚伯尼哥就从烈火中出来了。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 43:2; 希伯来书 11:34; 以赛亚书 26:11"> 那些行政官、总长、省长和王的谋士们都聚集过来，看到这三个人——烈火无力伤他们的身体，他们的头发没有烧焦，他们的长袍没有变化，他们身上也没有火烧的气味。</span>
<span className="v" id="v28" data-v="28" data-xref="罗马书 14:7–8; 诗篇 34:7–8; 诗篇 84:11–12"> 尼布甲尼撒就开口说：“沙德拉克、米沙克、亚伯尼哥的神是当受颂赞的！他派遣他的使者拯救了他的仆人们；他们信靠神，违抗王的命令，甚至舍弃己身，除了自己的神以外，不事奉、不膜拜任何其他神明。</span>
<span className="v" id="v29" data-v="29" data-xref="但以理书 2:5; 诗篇 76:10; 申命记 32:31"> 因此我下令：所有的民族、国家、语言群体中，谁说话冒犯了沙德拉克、米沙克、亚伯尼哥的神，谁就必被千刀万剐，他的家必成为废堆，因为没有别的神能这样解救人。”</span>
<span className="v" id="v30" data-v="30" data-xref="但以理书 2:49; 撒母耳记上 2:30; 但以理书 3:12"> 随后，王使沙德拉克、米沙克、亚伯尼哥在巴比伦省高升。</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理书 6:25; 彼得前书 1:2; 但以理书 3:4"> 尼布甲尼撒王，<br />致住在全地的所有民族、国家、语言群体：<br />愿你们大有平安！</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="但以理书 3:26; 诗篇 66:16; 诗篇 71:18"> 我很高兴能把至高神向我所行的神迹奇事讲明出来——</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 145:13; 以赛亚书 25:1; 但以理书 2:44"> <span className="pl pl-1">他的神迹多么伟大，</span><br /><span className="pl pl-1">他的奇事多么有能力！</span><br /><span className="pl pl-1">他的国度是永远的国度，</span><br /><span className="pl pl-1">他的权柄世世代代长存！</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 47:7–8; 帖撒罗尼迦前书 5:2–3; 诗篇 30:6–7"> 我尼布甲尼撒在殿里安居，在宫中兴盛。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 2:1; 约伯记 7:13–14; 但以理书 2:28–29"> 我做了一个梦，这梦使我恐惧；我在床上时的梦境和我脑海中的异象使我惶恐。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理书 2:2; 创世记 41:7–8; 以赛亚书 8:19"> 因此我下令，要把巴比伦的所有智慧人带到我面前，好让他们把梦的释义显明给我。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 44:25; 但以理书 2:7; 创世记 41:8"> 于是术士、占卜者、迦勒底人和算命者都来了；我就向他们说了这梦，他们却不能把这梦的释义显明给我。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="但以理书 1:7; 但以理书 5:14; 但以理书 4:18"> 最后，那照着我神的名称为伯提沙撒的但以理，来到我面前，他里面有圣神之灵；我就向他说了这梦：</span>
<span className="v" id="v9" data-v="9" data-xref="但以理书 2:48; 但以理书 5:11; 但以理书 4:8"> “术士的领袖伯提沙撒啊，我知道你里面有圣神之灵，任何奥秘都难不倒你！你就讲说我所看到的梦中异象和梦的释义吧！</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 12:2; 但以理书 4:5; 诗篇 37:35–36"> 我在床上时，我脑海中的异象是这样的：<br /><span className="pl pl-1">我正在观看，看哪，</span><br /><span className="pl pl-1">在大地中间有一棵树，极其高大！</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 4:21–22; 申命记 9:1; 马太福音 11:23"> <span className="pl pl-1">这树继续长大，变得茁壮，</span><br /><span className="pl pl-1">高达于天，全地极都能看到；</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 13:19; 耶利米哀歌 4:20; 以西结书 31:6–7"> <span className="pl pl-1">它的叶子美丽，果实繁多，</span><br /><span className="pl pl-1">足以给众生作食物；</span><br /><span className="pl pl-1">田野的走兽在它之下得荫庇，</span><br /><span className="pl pl-1">天空的飞鸟在它枝子上栖息，</span><br /><span className="pl pl-1">一切有血肉的都从它得供养。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="申命记 33:2; 但以理书 8:13; 但以理书 7:1"> “我在床上时，我在脑海中的异象里继续观看，看哪，有一位守望者，就是一位圣者，从天上降下！</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 3:10; 但以理书 4:23; 以西结书 31:12–13"> 他大声高呼，这样说：<br /><span className="pl pl-1">‘你们当砍倒这树，砍掉它的枝子，</span><br /><span className="pl pl-1">打落它的叶子，抛散它的果实；</span><br /><span className="pl pl-1">使走兽从树下逃离，</span><br /><span className="pl pl-1">使飞鸟从树枝逃离！</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="约伯记 14:7–9; 但以理书 4:25–27; 以西结书 29:14–15"> <span className="pl pl-1">然而你们当把带根的树桩留在地里，</span><br /><span className="pl pl-1">在田野的青草中用铁圈和铜圈套住——</span><br /><span className="pl pl-1">让他被天上的露水湿透，</span><br /><span className="pl pl-1">在地上的牧草中与走兽一同有份；</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="但以理书 4:23; 启示录 12:14; 但以理书 4:25"> <span className="pl pl-1">让他的心从人的心改变，</span><br /><span className="pl pl-1">并给他一个兽的心，</span><br /><span className="pl pl-1">让七个时期从他流过。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="但以理书 4:25; 但以理书 2:21; 诗篇 75:6–7"> <span className="pl pl-1">这是守望者们所宣告的裁决，</span><br /><span className="pl pl-1">是圣者们所宣布的决定，</span><br /><span className="pl pl-1">为要使活人明白：</span><br /><span className="pl pl-1">至高者在人的国中掌权，</span><br /><span className="pl pl-1">他愿意把国赐给谁就赐给谁，</span><br /><span className="pl pl-1">甚至把最卑微的人立在一国之上。’</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="但以理书 5:15; 创世记 41:8; 但以理书 5:8"> “以上就是我尼布甲尼撒王所做的梦。伯提沙撒啊，你讲说梦的释义吧！因为我国中的所有智慧人都不能把梦的释义显明给我；只有你能，因为你里面有圣神之灵。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="但以理书 8:27; 但以理书 7:28; 但以理书 4:24"> 那时，称为伯提沙撒的但以理一阵惊恐，他的意念使他惶恐。王就开口说：“伯提沙撒啊，不要让这梦和梦的释义使你惶恐！”<br />伯提沙撒回应说：“我主啊，愿这梦归于那些恨恶你的人，愿梦的释义归于你的敌人！</span>
<span className="v" id="v20" data-v="20" data-xref="但以理书 4:10–12; 以西结书 31:3; 以西结书 31:16"> 你所看到的那树继续长大，变得茁壮，高达于天，全地都能看到；</span>
<span className="v" id="v21" data-v="21"> 它的叶子美丽，果实繁多，足以给众生作食物；田野的走兽在它之下安居，天空的飞鸟在它枝子上栖息。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理书 2:37–38; 撒母耳记下 12:7; 耶利米书 27:6–8"> 王啊，这树就是你！你继续强大，变得坚壮，你的权势继续强大，高达于天，你的权柄直到地极。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="但以理书 5:21; 但以理书 4:13–16"> “王又看到有一位守望者，就是一位圣者，从天上降下，说：‘你们当砍倒毁坏这树！然而你们当把带根的树桩留在地里，在田野的青草中用铁圈和铜圈套住——让他被天上的露水湿透，与田野的走兽一同有份，让七个时期从他流过。’</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 107:40; 约伯记 40:11–12; 以赛亚书 46:10–11"> 王啊，梦的释义是这样的，它是至高者的裁决临到了我主我王：</span>
<span className="v" id="v25" data-v="25" data-xref="但以理书 4:17; 耶利米书 27:5; 诗篇 83:18"> 你必从人间被赶出，你的住处必与田野的走兽在一起；你必像牛那样吃牧草，被天上的露水湿透，让七个时期从你流过，直到你明白：至高者在人的国中掌权，他愿意把国赐给谁就赐给谁。</span>
<span className="v" id="v26" data-v="26" data-xref="但以理书 4:15; 马太福音 5:34; 马太福音 21:20"> 既然守望者们吩咐要留下带根的树桩，那么当你明白了上天掌权时，你的国必定再归于你。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 55:6–7; 约拿书 3:9; 使徒行传 8:22"> 因此，王啊，愿我的劝告蒙你悦纳：请你藉着施行公义断绝你的罪恶，藉着恩待受苦人断绝你的罪孽，或许你的安稳可以延长。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="民数记 23:19; 撒迦利亚书 1:6; 箴言 10:24"> 这一切事果然都临到了尼布甲尼撒王：</span>
<span className="v" id="v29" data-v="29" data-xref="启示录 2:21; 传道书 8:11; 彼得前书 3:20"> 过了十二个月，王在巴比伦王宫的宫顶<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="的宫顶——辅助词语。">a</a></sup>上行走时，</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 16:18; 启示录 18:10; 路加福音 14:11"> 开口说：“这大巴比伦，难道不是我以自己的权能力量建为国都，为要显出<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="显出——辅助词语。">b</a></sup>我威严的尊荣吗？”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="使徒行传 9:3–5; 启示录 16:7; 路加福音 12:20"> 这话还在王的口中，就有声音从天上降下，说：“尼布甲尼撒王啊，这是对你的宣告：你的国权从你那里被移除了！</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 27:5; 但以理书 5:21; 箴言 8:15–16"> 你必从人间被赶出，你的住处必与田野的走兽在一起；你必像牛那样吃牧草，让七个时期从你流过，直到你明白：至高者在人的国中掌权，他愿意把国赐给谁就赐给谁。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="但以理书 4:32; 但以理书 4:25; 但以理书 5:5"> 这话立刻就应验在尼布甲尼撒身上；他从人间被赶出，像牛那样吃牧草，身体被天上的露水湿透，直到他的头发长得像鹰的羽毛<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="羽毛——辅助词语。">c</a></sup>，指甲长得像鸟的爪子<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="爪子——辅助词语。">d</a></sup>。</span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="启示录 4:10; 耶利米书 10:10; 但以理书 12:7"> 那些日子结束了，我尼布甲尼撒举目望天，我的理智回到我身上。我就颂赞至高者，称赞、尊崇永远活着的那一位——<br /><span className="pl pl-1">他的权柄是永远的权柄，</span><br /><span className="pl pl-1">他的国度世世代代长存！</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="约伯记 42:2; 诗篇 135:6; 诗篇 115:3"> <span className="pl pl-1">地上所有的居民都算为无有，</span><br /><span className="pl pl-1">他照着自己的旨意对待天上的众军和地上的居民。</span><br /><span className="pl pl-1">没有人能拦住他的手，</span><br /><span className="pl pl-1">或对他说：“你做什么？”</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="但以理书 4:34; 箴言 22:4; 但以理书 4:15–16"> ——当时，我的理智回到我身上；为了我国家的尊荣，我的威严、我的光辉也回到我身上。我的谋士们、我的大臣们又来寻求我，我的国权重新坚立，超卓的权势也加增给我。</span>
<span className="v" id="v37" data-v="37" data-xref="雅各书 4:6–7; 诗篇 33:4–5; 彼得前书 5:5–6"> 如今我尼布甲尼撒称赞、高举、尊崇天上的王，因为他一切的作为都是确实的，一切的道路都是公正的，他能使行事骄傲的人降卑。</span>
</div>

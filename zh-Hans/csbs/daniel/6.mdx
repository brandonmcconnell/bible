<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="DAN" data-book-slug="daniel" data-book-name="但以理书" data-chapter="6" data-verses="28">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 18:21–22; 但以理书 5:31; 以斯帖记 1:1"> 大流士认为最好任命一百二十个行政官来管理国家，分治全国，</span>
<span className="v" id="v2" data-v="2" data-xref="但以理书 2:48–49; 但以理书 5:29; 以斯帖记 7:4"> 又在他们之上任命三位总督察，但以理是其中之一；这些行政官要向他们三位负责交代，好使王不受损失。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理书 5:14; 箴言 22:29; 创世记 41:38–41"> 这但以理在总督察和行政官中出类拔萃，因为在他里面有超卓的灵性；王就打算任命他治理全国。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前书 3:16; 腓立比书 2:15; 彼得前书 2:12"> 于是其他总督察和行政官就试图在他处理<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="处理——辅助词语。">a</a></sup>国事上找出把柄控告但以理，却找不出他的任何把柄或过失；因为他忠心可靠，在他身上找不出任何疏忽或过失。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 24:13–16; 以斯帖记 3:8; 使徒行传 24:20–21"> 这些人就说：“我们如果不在他的神的法令上找出把柄攻击他，就找不出任何把柄控告这但以理。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="但以理书 2:4; 尼希米记 2:3; 但以理书 6:21"> 于是这些总督察和行政官合谋来到王那里，对王这样说：“愿大流士王万岁！</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 59:3; 诗篇 62:4; 但以理书 3:27"> 国中所有的总督察、总长、行政官、谋士和省长一同商议，要请王设立一条法规，强制执行一条禁令：王啊，三十天之内，无论何人，如果向你以外的任何神明或任何人祈祷，就必被扔进狮子坑！</span>
<span className="v" id="v8" data-v="8" data-xref="但以理书 6:15; 以斯帖记 1:19; 但以理书 6:12"> 王啊，现在请你照着不能废除的米底亚和波斯的法令，设立这禁令并签署这文告，使它不能更改！”</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 146:3; 诗篇 118:9; 诗篇 62:9–10"> 于是，大流士王签署了这禁令文告。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 5:29; 诗篇 55:17; 帖撒罗尼迦前书 5:17–18"> 但以理知道这文书已经签署了，回到自己的家里——他阁楼上的窗户朝耶路撒冷开着——仍然一天三次双膝跪下，在他的神面前祷告、感谢，就像以前那样做。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 37:32–33; 诗篇 10:9; 但以理书 6:6"> 那时，这些人合谋而来，发现但以理正在他的神面前祈祷、恳求。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理书 6:8; 但以理书 3:8–12; 以斯帖记 1:19"> 于是他们来到王面前，提起有关王的禁令：“王啊，难道你不是签署了以下的禁令吗？三十天之内，无论何人，如果向你以外的任何神明或任何人祈祷，就必被扔进狮子坑！”<br />王开口说：“照着不能废除的米底亚和波斯的法令，确实如此。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="但以理书 3:12; 使徒行传 5:29; 但以理书 2:25"> 他们就在王面前回应说：“王啊，犹大掳民中的但以理，不理会你的命令，也不理会你所签署的禁令，他仍然一天三次祈祷。”</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 6:26; 马太福音 27:17–24; 撒母耳记下 3:28–29"> 王听见了这话，就极其烦恼，定意要拯救但以理；直到日落的时候，他还在尽一切努力要解救但以理。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理书 6:12; 诗篇 94:20–21; 但以理书 6:8"> 这些人又合谋来到王那里，对王说：“王啊，你要知道，照着米底亚和波斯的法令，王所设立的任何禁令和法规都不能更改！”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="诗篇 37:39–40; 约伯记 5:19; 诗篇 91:14–16"> 王下令，人就把但以理带来，扔进狮子坑中。王开口对但以理说：“愿你的神，你一直事奉的那一位，亲自拯救你！”</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米哀歌 3:53; 使徒行传 12:4; 马太福音 27:60–66"> 人又把一块石头搬来，放在坑口上，王就用自己的印和大臣们的印封上石头；这样，有关但以理的事就不能更改了。</span>
<span className="v" id="v18" data-v="18" data-xref="以斯帖记 6:1; 但以理书 2:1; 撒母耳记下 12:16–17"> 然后，王回到宫中，整夜禁食，不让人给他带来任何娱乐享受，他也睡不着觉。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="帖撒罗尼迦前书 3:5; 马可福音 16:2; 马太福音 28:1"> 清晨天一亮，王就起来，急忙前往狮子坑。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志上 16:11; 希伯来书 7:25; 但以理书 6:27"> 他靠近那坑的时候，用忧伤的声音呼叫但以理，开口对但以理说：“永生神的仆人但以理啊！你的神，你一直事奉的那一位，有没有拯救你脱离那些狮子呢？”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="但以理书 2:4; 但以理书 6:6; 尼希米记 2:3"> 那时但以理对王说：“愿王万岁！</span>
<span className="v" id="v22" data-v="22" data-xref="提摩太后书 4:17; 希伯来书 11:33; 使徒行传 12:11"> 我的神派遣他的使者封住了狮子的口，使它们没有伤害我，因为我在神面前是清白的；王啊，我在你面前也没有做过任何害人的事。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="历代志上 5:20; 马可福音 9:23; 但以理书 3:27–28"> 王因此极其高兴，下令把但以理从坑里拉上来；但以理就被人从坑里拉上来，在他身上找不到任何损伤，因为他信靠他的神。</span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 38:13; 以斯帖记 7:10; 申命记 24:16"> 王又下令，人就把那些恶意控告但以理的人带来，把他们连同他们的儿女、妻子都扔进狮子坑。他们还没有落到坑底，那些狮子就扑住他们，把他们全身的骨头都咬碎了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="但以理书 4:1; 以斯拉记 1:1–2; 以斯帖记 3:12"> 随后，大流士王写诏书给住在全地的所有民族、国家、语言群体，说：“愿你们大有平安！</span>
<span className="v" id="v26" data-v="26" data-xref="但以理书 4:34; 路加福音 1:33; 但以理书 3:29"> 现在我下令，在我国的一切权柄之下，人人都要在但以理的神面前恐惧战兢——<br /><span className="pl pl-1">因为他是永生的神，</span><br /><span className="pl pl-1">他永远长存，</span><br /><span className="pl pl-1">他的国度不会毁灭，</span><br /><span className="pl pl-1">他的权柄没有穷尽！</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="但以理书 4:2–3; 诗篇 18:50; 使徒行传 4:30"> <span className="pl pl-1">他拯救人、解救人，</span><br /><span className="pl pl-1">在天上地上施行神迹奇事，</span><br /><span className="pl pl-1">他拯救了但以理脱离狮子的爪。”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="但以理书 1:21; 历代志下 36:22–2; 以赛亚书 44:28–1"> 这样，大流士在位的时候和波斯人居鲁士在位的时候，这但以理都事事通达。</span>
</div>
</div>

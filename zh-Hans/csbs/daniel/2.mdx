<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="DAN" data-book-slug="daniel" data-book-name="但以理书" data-chapter="2" data-verses="49">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理书 4:5; 以斯帖记 6:1; 约伯记 33:15–17"> 尼布甲尼撒在位第二年，尼布甲尼撒做梦，灵里烦乱，睡不着觉。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理书 1:20; 但以理书 4:6; 创世记 41:8"> 于是王吩咐人召来术士、占卜者、行巫术的和迦勒底人，要他们把王的梦告诉王。他们就来了，站在王面前。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 40:8; 创世记 41:15; 但以理书 4:5"> 王对他们说：“我做了一个梦，灵里烦乱，想要明白这梦。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="但以理书 3:9; 但以理书 5:10; 以斯拉记 4:7"> 那些迦勒底人用亚兰语对王说：“愿王万岁！请把梦告诉你的仆人们，我们就会讲明梦的释义。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="但以理书 3:29; 以斯拉记 6:11; 列王纪下 10:27"> 王回应那些迦勒底人，说：“我所发出的命令是确定的：如果你们不把这梦和梦的释义显明给我，你们就必被千刀万剐，你们的家必成为废堆；</span>
<span className="v" id="v6" data-v="6" data-xref="但以理书 5:7; 但以理书 2:48; 但以理书 5:29"> 但如果你们讲明这梦和梦的释义，你们就必从我得到礼物、赏赐和极大的尊荣；因此你们要把这梦和梦的释义讲明给我！”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="但以理书 2:4; 但以理书 2:9; 传道书 10:4"> 他们第二次回应说：“请王把那梦告诉你的仆人们，我们就会讲明那梦的释义。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 4:5; 以弗所书 5:16"> 王回应说：“我清楚地知道你们是在拖延<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="拖延——原文直译“赢得”。">a</a></sup>时间，因为你们看到我所发出的命令是确定的：</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 41:23; 但以理书 7:25; 以斯帖记 4:11"> 如果你们不把这梦显明给我，给你们的就只有一条法令。你们互相串通好了，要在我面前说谎言和乱语，直到时势有所改变。现在你们要把这梦告诉我，好让我知道你们能把梦的释义讲明给我。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="但以理书 2:27"> 那些迦勒底人在王面前回应说：“地上没有人能讲明王所要求的事；事实上，没有任何一个伟大、有权势的君王，向任何一个术士、占卜者或迦勒底人问过这样的事。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 5:11; 以赛亚书 57:15; 创世记 41:39"> 王所问的事，是件难事，除了不与属肉体的人住在一起的神明，没有谁能在王面前讲明它。”</span>
<span className="v" id="v12" data-v="12" data-xref="但以理书 3:13; 马太福音 2:16; 但以理书 3:19"> 王因此发怒，极其震怒，下令消灭巴比伦的所有智慧人。</span>
<span className="v" id="v13" data-v="13" data-xref="但以理书 1:19–20; 以斯帖记 3:12–15; 以赛亚书 10:1"> 法令发出，要杀掉智慧人；人就寻找但以理和他的同伴，要杀掉他们。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="但以理书 2:24; 耶利米书 52:12; 撒母耳记下 20:16–22"> 那时，但以理谨慎机智地回应阿约克——他是王的护卫长，出来要杀掉巴比伦的智慧人。</span>
<span className="v" id="v15" data-v="15"> 但以理开口对王的官长阿约克说：“从王而来的法令为什么这样急迫呢？”阿约克就把以上的事告诉了但以理。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理书 1:18–19; 但以理书 2:9–11"> 但以理就进去，请求王给他一些时间，好使他可以把那梦的释义讲明给王。</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="但以理书 1:6–7; 但以理书 3:12; 但以理书 1:11"> 但以理回到自己的家里，把这事告诉了他的同伴哈纳尼雅、米沙利和亚撒利雅，</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 33:3; 马太福音 18:19; 马太福音 18:12"> 让他们在这奥秘的事上，向天上的神祈求怜悯，免得但以理和他的同伴与巴比伦其余的智慧人一同灭亡。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 12:6; 阿摩司书 3:7; 但以理书 7:7"> 于是这奥秘的事在夜间的异象中显明给了但以理；但以理就颂赞天上的神。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 113:2; 诗篇 145:1–2; 启示录 5:12"> 但以理开口说：<br /><span className="pl pl-1">“愿神的名受颂赞，从永远到永远</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="永远到永远——或译作“亘古到永远”。">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">因智慧和大能都属于他；</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 75:5–7; 诗篇 31:14–15; 诗篇 113:7–8"> <span className="pl pl-1">是他改变时势和时期；</span><br /><span className="pl pl-1">是他废王、立王；</span><br /><span className="pl pl-1">是他赐智慧给智慧人，</span><br /><span className="pl pl-1">赐知识给有悟性的人；</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 12:22; 约翰一书 1:5; 耶利米书 23:24"> <span className="pl pl-1">是他显明深奥和隐秘的事；</span><br /><span className="pl pl-1">他知道黑暗中有什么，</span><br /><span className="pl pl-1">光明也与他同在。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="但以理书 2:18; 出埃及记 3:15; 但以理书 2:29–30"> <span className="pl pl-1">我祖先的神哪，</span><br /><span className="pl pl-1">我感谢、称赞你！</span><br /><span className="pl pl-1">因为你赐给我智慧和大能；</span><br /><span className="pl pl-1">我们向你祈求的，</span><br /><span className="pl pl-1">如今你已显明给我，</span><br /><span className="pl pl-1">又把王的事显明给了我们。”</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行传 27:24; 但以理书 2:12–14"> 于是，但以理进去见阿约克——他是王所指派要消灭巴比伦智慧人的。但以理对他这样说：“不要消灭巴比伦的智慧人；请把我带到王面前，我要把那梦的释义讲明给王。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="哥林多前书 1:27–28; 但以理书 6:13; 但以理书 5:13"> 阿约克就急忙把但以理带到王面前，对王这样说：“我在犹大的掳民中找到一个人，他能把那梦的释义显明给王。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="但以理书 1:7; 但以理书 5:16; 但以理书 5:12"> 王问那称为伯提沙撒的但以理说：“难道你能把我做的梦和梦的释义显明给我吗？”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 47:12–14; 但以理书 2:2; 以赛亚书 44:25"> 但以理在王面前回答说：“王所问的那奥秘的事，没有智慧人、占卜者、术士或算命者能讲明给王。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 40:8; 阿摩司书 4:13; 但以理书 10:14"> 然而天上有一位神，就是显明奥秘的那一位，他已经使尼布甲尼撒王明白了末后的日子将要发生的事——这就是你在床上所做的梦和脑海中的异象。</span>
<span className="v" id="v29" data-v="29" data-xref="但以理书 2:28; 阿摩司书 4:13; 但以理书 2:47"> 王啊，你在床上所怀的意念是此后将要发生的事，而显明奥秘的那一位已经使你明白了将要发生的事！</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 41:16; 使徒行传 3:12; 但以理书 2:17–18"> 至于那奥秘的事显明给我，不是因为我比所有的活人更有智慧，而是要使王明白那梦的释义和王心里的意念。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="哈巴谷书 1:7; 以西结书 28:7; 但以理书 7:3–17"> “王啊，你正在观看，看哪，有一座巨大的像！这像极大，非常光耀，立在你前面，它的样貌令人恐惧。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 51:7; 但以理书 7:4–6; 启示录 17:4"> 这像的头是纯金的，它的胸膛和膀臂是银的，它的腹部和大腿是铜的，</span>
<span className="v" id="v33" data-v="33" data-xref="但以理书 7:19–26; 但以理书 7:7–8; 但以理书 2:40–43"> 它的小腿是铁的，它的脚有部分是铁的，有部分是泥的。</span>
<span className="v" id="v34" data-v="34" data-xref="但以理书 2:44–45; 但以理书 8:25; 撒迦利亚书 12:3"> 你继续观看，有一块非人手凿出的石头，砸在这像的铁和泥的脚上，把脚砸碎了。</span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 2:2–3; 诗篇 37:10; 启示录 20:11"> 这样，铁、泥、铜、银、金都一同被砸得粉碎了，就像夏天打谷场上的糠秕，被风吹散，无踪迹可寻；但砸这像的石头却变成一座大山，充满全地。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="但以理书 2:23–24"> “以上就是那梦；现在我们要在王面前讲说梦的释义。</span>
<span className="v" id="v37" data-v="37" data-xref="以西结书 26:7; 耶利米书 27:6–7; 以斯拉记 7:12"> 王啊，你是王中之王！天上的神把国度、权能、力量和尊荣都赐给了你，</span>
<span className="v" id="v38" data-v="38" data-xref="但以理书 4:21–22; 诗篇 50:10–11; 耶利米书 27:5–7"> 也把世人、田野的走兽、天空的飞鸟，无论住在哪里，都交在你的手中，让你统辖这一切；你就是那金的头。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="但以理书 5:28–31; 以赛亚书 44:28–5; 但以理书 2:32"> “在你之后，会有另一个国兴起，却不如你；接下来会再有一个国，就是那铜的第三个国，要统辖全地；</span>
<span className="v" id="v40" data-v="40" data-xref="但以理书 7:7; 但以理书 7:19–26; 但以理书 11:36–45"> 然后会有第四个国，它必强硬如铁。铁怎样砸碎、击破一切，怎样压碎一切，这国也照样砸碎、压碎一切。</span>
<span className="v" id="v41" data-v="41" data-xref="启示录 17:12; 但以理书 2:33–35; 启示录 12:3"> 正如你看到那像的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="那像的——辅助词语。">c</a></sup>脚和脚趾有部分是陶匠的泥，有部分是铁，这国也必是一个分裂的国；但这国里面会有铁的坚硬，就像你看到有铁与湿泥混合那样。</span>
<span className="v" id="v42" data-v="42" data-xref="但以理书 7:24; 启示录 13:1"> 脚趾怎样有部分是铁，有部分是泥，这国也怎样有部分强硬，有部分脆弱。</span>
<span className="v" id="v43" data-v="43"> 正如你看到有铁与湿泥混合，他们也必与各人种混合；但他们彼此却不会粘合，就像铁不与泥混合那样。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="马太福音 28:18; 路加福音 1:32–33; 但以理书 6:26"> “这些君王年间，天上的神必立起一个永不毁灭的国度，这国度不会交给别的民族，却会砸碎、终结所有这些国，而它会存到永远，</span>
<span className="v" id="v45" data-v="45" data-xref="以赛亚书 28:16; 创世记 41:32; 申命记 10:17"> 就像你看到那块从山而出、非人手凿出的石头，砸碎了铁、铜、泥、银、金那样。伟大的神已经给王显明了此后将要发生的事。这梦是确实的，梦的释义也是可靠的。”</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="使徒行传 10:25; 使徒行传 14:13; 以斯拉记 6:10"> 于是尼布甲尼撒王就脸伏于地，向但以理下拜，并且吩咐人向他献上祭物和香品。</span>
<span className="v" id="v47" data-v="47" data-xref="但以理书 2:22; 但以理书 2:28; 阿摩司书 3:7"> 王开口对但以理说：“你既然能显明这奥秘，那么你们的神真是万神之神、万王之主，是显明奥秘的那一位！”</span>
<span className="v" id="v48" data-v="48" data-xref="但以理书 2:6; 但以理书 4:9; 但以理书 5:11"> 王就提拔了但以理，赐给他许多贵重的礼物，使他统辖巴比伦全省，并且立他为总长之首管理巴比伦的所有智慧人。</span>
<span className="v" id="v49" data-v="49" data-xref="但以理书 1:7; 以斯帖记 2:19; 但以理书 3:12–30"> 但以理向王提出请求，王就指派沙德拉克、米沙克、亚伯尼哥管理巴比伦省的事务；但以理却留在王的宫廷中。</span>
</div>
</div>

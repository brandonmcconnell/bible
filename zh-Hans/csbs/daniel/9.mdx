<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="DAN" data-book-slug="daniel" data-book-name="但以理书" data-chapter="9" data-verses="27">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理书 11:1; 但以理书 1:21; 但以理书 5:31–1"> 米底亚人的后裔，亚哈随鲁的儿子大流士被立为王统治迦勒底国的第一年，</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 29:10; 耶利米书 25:11–12; 历代志下 36:21"> 就是他作王的第一年，我但以理从书卷中领悟到：照着耶和华给先知耶利米的话，耶路撒冷荒废期满的年数是七十年。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 33:3; 耶利米书 29:10–13; 雅各书 5:16–18"> 于是我转向主耶和华，以祷告、恳求、禁食、披麻蒙灰来寻求他。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="罗马书 8:28; 出埃及记 20:6; 申命记 5:10"> 我向我的神耶和华祷告、认罪，说：“哦，主啊，大而可畏的神，你向那些爱你并遵守你诫命的人持守你的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你的——辅助词语。">a</a></sup>约和慈爱！</span>
<span className="v" id="v5" data-v="5" data-xref="玛拉基书 3:7; 但以理书 9:11; 但以理书 9:15"> 我们犯了罪，行事扭曲，作恶背叛，偏离了你的诫命和法规，</span>
<span className="v" id="v6" data-v="6" data-xref="但以理书 9:10; 历代志下 36:15–16; 路加福音 20:10–12"> 没有听从你的仆人众先知——他们奉你的名向我们的君王们、首领们、祖先们和这地所有的子民说话。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="诗篇 44:15; 耶利米书 3:25; 耶利米书 2:26–27"> “主啊，公义在于你；至于我们犹大人、耶路撒冷的居民，以及你驱散到远近各地的全体以色列人，因为对你行事不忠，都满面羞耻，就像今日这样！</span>
<span className="v" id="v8" data-v="8" data-xref="但以理书 9:6–7; 耶利米哀歌 1:7–8; 耶利米哀歌 1:18"> 耶和华啊，我们和我们的君王们、首领们、祖先们都满面羞耻，因为我们对你犯了罪！</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 1:6–8; 但以理书 9:7; 但以理书 9:5"> 怜悯和赦免在于主我们的神；我们却背叛了他，</span>
<span className="v" id="v10" data-v="10" data-xref="但以理书 9:6; 列王纪下 18:12; 尼希米记 9:13–17"> 没有听从我们的神耶和华的话，没有遵行他藉着他的仆人众先知在我们面前设立的律法。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米书 8:5–10; 以赛亚书 1:4–6; 申命记 28:15–68"> “全体以色列人都违背、偏离了你的律法，不听从你的话；因此神的仆人摩西的律法上所记的诅咒和审判<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="审判——原文直译“起的誓”。">b</a></sup>都倾泻在我们身上，因为我们对神犯了罪。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 5:9; 耶利米哀歌 1:12; 约伯记 12:17"> 神实现了他的话语，就是他针对我们、针对那些审判我们的审判官所说的，为要使极大的祸患临到我们身上；像这样在耶路撒冷所发生的祸患，在普天之下从来没有发生过。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 28:15–68; 以赛亚书 9:13; 但以理书 9:11"> 照着摩西的律法上所记的，这一切祸患都临到我们身上；然而我们却没有恳求我们神耶和华的恩宠，好使我们转离自己的罪孽，留心你的真理。</span>
<span className="v" id="v14" data-v="14" data-xref="但以理书 9:7; 尼希米记 9:33; 诗篇 51:14"> 于是耶和华有意使这祸患临到我们身上，因为我们的神耶和华所做的一切都是公义的，但我们却没有听从他的话。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="尼希米记 9:10; 出埃及记 32:11; 尼希米记 1:10"> “主我们的神哪，你曾用大能的手把你的子民从埃及地领出来，为自己成就了名声，就像今日这样；我们犯了罪，作了恶！</span>
<span className="v" id="v16" data-v="16" data-xref="撒迦利亚书 8:3; 约珥书 3:17; 诗篇 87:1–3"> 主啊，现在求你照着你一切的公义，从你的城耶路撒冷和你的圣山收回你的怒气和你的怒火！因我们的罪过和我们祖先的罪孽，耶路撒冷和你的子民被四围所有的人羞辱。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="诗篇 80:19; 耶利米哀歌 5:18; 哥林多后书 1:20"> “我们的神哪，现在求你垂听你仆人的祷告和恳求；主啊，为你自己的缘故，求你使你的脸照亮你荒凉的圣所！</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 37:17; 耶利米书 36:7; 列王纪下 19:16"> 我的神哪，求你侧耳听，求你垂听！求你睁眼看我们的荒凉和这被称为你名下的城，因为我们在你面前呈上的恳求不是因着我们的义，而是因着你丰盛的怜悯。</span>
<span className="v" id="v19" data-v="19" data-xref="但以理书 9:18; 以弗所书 1:12; 阿摩司书 7:2"> 主啊，求你垂听！主啊，求你赦免！主啊，求你留心听并且行动！我的神哪，为你自己的缘故，求你不要迟延，因为你的城和你的子民都是被称为你名下的。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="诗篇 145:18; 但以理书 9:3–4; 罗马书 3:23"> 我还在说话、祷告，承认我的罪和我民以色列的罪，并为我神的圣山在我的神耶和华面前呈上恳求——</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:19; 但以理书 8:16; 列王纪上 18:36"> 我还在祷告中说话的时候，先前的异象中见过的那位样貌像人的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="那位样貌像人的——原文直译“那人”。">c</a></sup>加百列快速地飞<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="快速地飞——或译作“在我精疲力竭时”。">d</a></sup>到我这里来；那时大约是献晚祭的时候。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理书 9:24–27; 但以理书 10:21; 但以理书 8:16"> 他指示我，对我说：“但以理啊，现在我出来，为要使你明达、有悟性！</span>
<span className="v" id="v23" data-v="23" data-xref="但以理书 10:19; 马太福音 24:15; 但以理书 10:11–12"> 在你开始恳求的时候，就有命令发出，于是我来告诉你，因为你是蒙爱的；你当领悟这话语，要领悟这异象！</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="希伯来书 9:11–14; 罗马书 5:10; 耶利米书 23:5–6"> “为了你的民，为了你的圣城，有七十个‘七’被定下了，为要结束罪过，终止罪恶，赎清罪孽，带来永远的公义，封住异象和预言，膏抹至圣所<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="至圣所——或译作“至圣者”。">e</a></sup>。</span>
<span className="v" id="v25" data-v="25" data-xref="以斯拉记 4:24; 以赛亚书 9:6; 以赛亚书 55:4"> 因此你当知道，你要明白：从发出命令恢复<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="恢复——或译作“回归”。">f</a></sup>、重建耶路撒冷，直到受膏之君的时候，有七个‘七’和六十二个‘七’；那时耶路撒冷连同她的广场和沟渠都必被恢复、重建，但那将是一个困苦的时期。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 53:8; 那鸿书 1:8; 马可福音 13:2"> 那六十二个‘七’之后，受膏者必被剪除，他将一无所有。将要来一位领袖，他的民众必毁灭这城和圣所，其结局必伴随着洪流，必有战争直到末了；荒凉的事已经被注定了。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 24:15; 路加福音 21:20; 但以理书 12:11"> 他将与许多人订立一个‘七’之久的坚固盟约；而在半个‘七’的时候，他将使祭物和供物止息。在那些可憎者<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="可憎者——或译作“可憎之物”。">g</a></sup>的羽翼上，必出现一个带来荒凉的人，直到那被注定的灭绝倾泻在这带来荒凉的人身上。”</span>
</div>
</div>

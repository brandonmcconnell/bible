<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 36:5–7; 列王纪下 24:1–2; 列王纪下 24:13"> 犹大王约雅敬在位第三年，巴比伦王尼布甲尼撒来到耶路撒冷，围困了它。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 36:7; 撒迦利亚书 5:11; 耶利米书 27:19–20"> 主把犹大王约雅敬以及神殿中的一部分器具，交在尼布甲尼撒的手中；他就都带到示拿地他神明的庙宇，把器具放入他神明的宝库。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 39:7; 列王纪下 20:17–18; 列王纪下 24:15"> 尼布甲尼撒王吩咐他的太监长亚施培纳，从以色列子孙中，带来一些王室后裔和贵族中的年轻人——</span>
<span className="v" id="v4" data-v="4" data-xref="但以理书 5:11; 使徒行传 7:22; 箴言 22:29"> 他们没有任何残疾，样貌美好，在各样的学问上明达，富有学识，在知识上有悟性，有能力在王宫中侍立；王又吩咐太监长教导他们迦勒底人的典籍和语言。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 1:19; 列王纪上 10:8; 但以理书 1:8"> 王从自己的美食和所饮用的酒中，给他们指定了每天的份额，要他们受教养三年；三年结束后，他们将在王面前侍立。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 14:14; 马太福音 24:15; 但以理书 2:17"> 他们中有犹大子孙的但以理、哈纳尼雅、米沙利和亚撒利雅。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 5:12; 但以理书 4:8; 但以理书 2:49"> 太监总管给了他们新的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="新的——辅助词语。">a</a></sup>名字，称但以理为伯提沙撒，哈纳尼雅为沙德拉克，米沙利为米沙克，亚撒利雅为亚伯尼哥。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="诗篇 141:4; 以西结书 4:13–14; 利未记 11:45–47"> 但以理决心不让王的美食和王所饮用的酒玷污自己；于是请求太监总管允许他不因这些玷污自己。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 39:21; 箴言 16:7; 诗篇 106:46"> 神使但以理在太监总管面前蒙恩慈和怜悯。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 6:16–18; 约翰福音 12:42–43; 箴言 29:25"> 太监总管对但以理说：“我惧怕我主我王，他已经指定了你们的食物和饮物。为什么要让他看到你们的脸色与你们同龄的年轻人相比显得憔悴呢？你们会使我的头在王面前保不住！”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 但以理对太监总管所指定负责但以理、哈纳尼雅、米沙利、亚撒利雅的管事者说：</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 14:2; 但以理书 1:16; 创世记 1:29–30"> “请你试验你的仆人们十天，给我们吃素菜、喝清水；</span>
<span className="v" id="v13" data-v="13"> 之后，请你察看我们的样貌以及那些吃王美食的年轻人的样貌，然后照着你所察看的对待你的仆人们吧！”</span>
<span className="v" id="v14" data-v="14"> 管事者就听允了他们这请求，试验了他们十天。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 23:25; 箴言 10:22; 列王纪下 4:42–44"> 十天结束后，他们的样貌看起来比所有吃王美食的年轻人更加美好肥壮。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理书 1:12"> 于是，管事者就继续撤掉他们的美食和饮用酒，给他们素菜。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王纪上 3:12; 雅各书 1:5; 但以理书 2:21"> 至于这四个年轻人，神赐给他们在各种典籍和学问上的知识和明达；但以理甚至能领悟各样的异象和异梦。</span>
<span className="v" id="v18" data-v="18" data-xref="但以理书 1:5"> 王所吩咐的那些日子结束时，就是要把他们带进宫中<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="宫中——辅助词语。">b</a></sup>的时候，太监总管就把他们带到尼布甲尼撒面前。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 22:29; 创世记 41:46; 但以理书 1:5"> 王与他们谈论，在那些年轻人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="那些年轻人——原文直译“他们所有人”。">c</a></sup>中找不到一个像但以理、哈纳尼雅、米沙利、亚撒利雅那样的。于是这四个人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="这四个人——原文直译“他们”。">d</a></sup>就在王面前侍立。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 8:19; 以赛亚书 47:12–14; 列王纪上 4:29–34"> 王向他们寻问各样有关学问和悟性的事，发现他们胜过全国所有的术士和占卜者十倍。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理书 6:28; 但以理书 10:1"> 但以理在王面前<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="王面前——辅助词语。">e</a></sup>，一直到居鲁士王元年。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理书 1:17; 阿摩司书 3:7; 但以理书 5:1"> 巴比伦王伯沙撒元年，但以理在床上做了一个梦，看见脑海中的异象。于是他写下了这梦，又述说这梦<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这梦——原文直译“事情”或“话语”。">a</a></sup>的概要。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 7:1; 启示录 17:15"> 但以理开口说：“我在夜间的异象中正在观看，看哪，天上四方的风搅动大海！</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 13:1; 但以理书 7:17; 但以理书 2:32–33"> 有四只巨兽从海里上来，各个都不相同。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="耶利米书 4:7; 以赛亚书 14:13–17; 以西结书 17:3"> “第一只兽好像狮子，却有鹰的翅膀。我继续观看，它的翅膀被拔掉，它从地上被举起，像人那样用双脚站立，又被赐予了一颗人的心。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="但以理书 2:39; 以赛亚书 13:17–18; 箴言 17:12"> “看哪，有另一只兽，就是第二只，仿佛一只熊！它用一侧站立，口齿间有三根肋骨<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="肋骨——或译作“獠牙”。">b</a></sup>；有话对它这样说：‘起来，吞吃大量的肉！’</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="启示录 13:2; 但以理书 8:20–22; 但以理书 8:5–8"> “此后我继续观看，看哪，又有另一只兽好像豹子！它的背上有鸟的四个翅膀；这兽有四个头，并且被赐予了权柄。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="启示录 13:1; 启示录 12:3; 启示录 17:12"> “此后在夜间的异象中我继续观看，看哪，第四只兽非常恐怖、十分可怕、极其强壮！它有大铁牙，吞吃咬碎，又把剩余的用脚踩踏；它与之前的各兽都不相同，它有十只犄角。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="启示录 13:5–6; 启示录 13:1; 诗篇 12:3"> “我正在注视这些犄角，看哪，有另一只小犄角在它们中间长出来，先前的那些犄角中有三只从它面前被连根拔出！看哪，这犄角上有眼睛，好像人的眼睛，又有说大话的口！</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="启示录 1:14; 马可福音 9:3; 但以理书 7:13"> “我继续观看，<br /><span className="pl pl-1">宝座已经安放好，</span><br /><span className="pl pl-1">亘古永存者入座了；</span><br /><span className="pl pl-1">他的衣服洁白如雪，</span><br /><span className="pl pl-1">他的头发纯净如羊毛；</span><br /><span className="pl pl-1">他的宝座是烈火的火焰，</span><br /><span className="pl pl-1">宝座的轮子是燃烧的烈火。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 30:27; 申命记 33:2; 启示录 20:11–15"> <span className="pl pl-1">从他面前有一条火河涌流而出；</span><br /><span className="pl pl-1">事奉他的有千千，</span><br /><span className="pl pl-1">侍立在他面前的有万万；</span><br /><span className="pl pl-1">庭审已经开始</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="庭审已经开始——或译作“审判者入座了”。">c</a></sup><br /><span className="pl pl-1">，书卷都打开了。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="启示录 19:20; 启示录 20:10; 帖撒罗尼迦后书 2:8"> “那时，我继续观看——因那犄角说大话的声音，我继续观看，那兽被杀掉，身体被毁坏，交于焚烧的烈火。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理书 8:7; 但以理书 7:4–6"> 至于其余的兽，它们的权柄被夺去，它们的寿命却得以延长到所定的时候和时期。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 26:64; 启示录 1:7; 路加福音 21:27"> 我在夜间的异象中继续观看，<br /><span className="pl pl-1">看哪，有一位像人子的，</span><br /><span className="pl pl-1">在天上的云彩中来临，</span><br /><span className="pl pl-1">被引领来到亘古永存者面前！</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="启示录 11:15; 但以理书 7:27; 约翰福音 3:35"> <span className="pl pl-1">他被赐予了权柄、尊荣和国度，</span><br /><span className="pl pl-1">所有的民族、国家、语言群体都事奉他；</span><br /><span className="pl pl-1">他的权柄是永远的权柄，不会废去，</span><br /><span className="pl pl-1">他的国度不会毁灭。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理书 7:28; 耶利米书 17:16; 创世记 40:7–8"> “至于我但以理，我的灵在我里面<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="在我里面——原文直译“在鞘里”；或译作“在躯体里”。">d</a></sup>忧伤，我脑海中的异象使我惶恐。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 7:13–14; 撒迦利亚书 2:3; 启示录 5:5"> 我靠近其中一位侍立者，向他寻问有关这一切事情的真义。他就告诉我，把事情的释义显明给我：</span>
<span className="v" id="v17" data-v="17" data-xref="但以理书 8:19–22; 但以理书 2:37–40; 约翰福音 18:36"> ‘这四只巨兽就是从地上将要兴起的四个王；</span>
<span className="v" id="v18" data-v="18" data-xref="但以理书 7:27; 以赛亚书 60:12–14; 启示录 5:10"> 但至高者的圣徒们必领受国度，拥有国度直到永远，永永远远。’</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="但以理书 7:7; 但以理书 2:40–43"> “那时我很想知道有关那第四只兽的真义；那兽与其他各兽都不相同，它极其恐怖，有铁牙和铜爪，吞吃咬碎，又把剩余的用脚踩踏。</span>
<span className="v" id="v20" data-v="20" data-xref="但以理书 7:23; 但以理书 7:8; 但以理书 7:11"> 我也很想知道有关它头上的十只犄角和那另长出的犄角的真义——在这犄角面前有三只犄角倒下了；这犄角有眼睛，有说大话的口，它的样子比它的同类更大。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理书 12:7; 启示录 17:14; 但以理书 8:24"> 我继续观看，这犄角与圣徒们作战，并胜过了他们，</span>
<span className="v" id="v22" data-v="22" data-xref="但以理书 7:18; 启示录 20:4; 启示录 5:10"> 直到亘古永存者来临，为至高者的圣徒们伸张公正，圣徒们拥有国度的所定时候就来到了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="但以理书 2:40; 但以理书 7:7; 路加福音 2:1"> “那位侍立者这样说：‘那第四只兽是地上将有的第四个国，与其他各国都不相同，必吞吃全地，把它践踏咬碎。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理书 7:20; 但以理书 11:36; 启示录 13:1"> 至于那十只犄角，是从这国中将要兴起的十个王；在他们之后将有另一个王兴起，与先前的那些都不相同，必使三个王屈服。</span>
<span className="v" id="v25" data-v="25" data-xref="但以理书 12:7; 启示录 12:14; 帖撒罗尼迦后书 2:4"> 他必说话敌对至高者，折磨至高者的圣徒们，又企图更改所定的时候和法令；圣徒们将被交在他的手中一期、二期、半期。</span>
<span className="v" id="v26" data-v="26" data-xref="启示录 20:10–11; 帖撒罗尼迦后书 2:8; 启示录 11:13"> 然而庭审将要开始<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="庭审将要开始——或译作“审判者要入座”。">e</a></sup>，那王<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="那王——原文直译“他”。">f</a></sup>的权柄必被夺去，除灭消亡，直到永远。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 72:11; 路加福音 1:33; 启示录 11:15"> 国度、权柄和普天之下万国的权势，都必赐给至高者的众圣民；至高者的国度是永远的国度，所有掌权的都必事奉、顺从至高者。’</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 2:19; 路加福音 2:51; 但以理书 10:8"> “这事到此结束。至于我但以理，我的意念使我极其惶恐，脸色也变了，但我却把这事存在心里。”</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="DAN" data-book-slug="daniel" data-book-name="但以理书" data-chapter="5" data-verses="31">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖记 1:3; 马可福音 6:21–22; 以赛亚书 21:4–5"> 伯沙撒王为他的一千名大臣摆设了盛大的宴席，当着这一千人的面喝酒。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理书 1:2; 列王纪下 24:13; 耶利米书 27:16–22"> 伯沙撒酒酣之时，吩咐人把他先王<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="先王——原文直译“父亲”或“先祖”。">a</a></sup>尼布甲尼撒从耶路撒冷的圣殿中取走的金银器皿带来，好让王和他的大臣们、妻子们、妃嫔们都用这些来喝酒。</span>
<span className="v" id="v3" data-v="3"> 于是人把圣殿——耶路撒冷神的殿中所取走的金器带来，王和他的大臣们、妻子们、妃嫔们就用这些来喝酒。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理书 5:23; 哈巴谷书 2:19; 诗篇 135:15–18"> 他们一边喝酒，一边称赞那些用金、银、铜、铁、木、石所做的神明。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="但以理书 4:31; 但以理书 5:24–28; 约伯记 20:5"> 那时，忽然有人的手指出现，在灯台对面王宫的粉墙上写字。王看到那正在写字的手<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="手——原文直译“手掌”。">b</a></sup>，</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 7:17; 但以理书 7:28; 那鸿书 2:10"> 王的脸色就变了，他的意念使他惶恐，他的腰骨松脱，双膝彼此相碰。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 5:29; 但以理书 5:16; 但以理书 2:48"> 王大声高呼，要人把占卜者、迦勒底人和算命者带来。王开口对巴比伦的智慧人说：“任何人读出这文字，并把它的释义讲明给我，他就必身穿紫袍，项戴金链，在国中掌权，位居第三。”</span>
<span className="v" id="v8" data-v="8" data-xref="但以理书 2:27; 但以理书 4:7; 创世记 41:8"> 那时，王所有的智慧人都来了，却不能读出这文字，也不能把它的释义显明给王。</span>
<span className="v" id="v9" data-v="9" data-xref="但以理书 5:6; 但以理书 2:1; 耶利米书 6:24"> 于是伯沙撒王极其惶恐，脸色大变，他的大臣们也都惊愕困惑。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="但以理书 3:9; 但以理书 6:6; 但以理书 2:4"> 太后因王和他大臣们所说的话，就来到宴会大厅。太后开口说：“愿王万岁！不要让你的意念使你惶恐，脸色也不要变。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 4:8–9; 但以理书 2:47–48; 但以理书 4:18"> 在你的国中有一个人，他里面有圣神之灵；你先王年间就发现这人里面有亮光、有悟性、有智慧如同神的智慧；你先王尼布甲尼撒亲自任命他为术士、占卜者、迦勒底人和算命者的领袖。你先王这样做<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="这样做——辅助词语。">c</a></sup>，</span>
<span className="v" id="v12" data-v="12" data-xref="但以理书 5:14; 但以理书 6:3; 但以理书 1:7"> 是因为发现但以理里面有超卓的灵性、有理智、有悟性，还能解梦、讲解谜语、解答难题；先王给他起名为伯提沙撒。现在让人把但以理召来，他必讲明那文字的释义。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="但以理书 6:13; 但以理书 5:11; 但以理书 2:25"> 于是但以理被带到王面前，王就开口对但以理说：“你就是我先王从犹大带来的犹大掳民中的但以理吧！</span>
<span className="v" id="v14" data-v="14" data-xref="但以理书 5:11–12"> 我听说过你里面有神的灵，也发现你里面有亮光、悟性、超卓的智慧。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理书 5:7–8; 以赛亚书 47:12; 以赛亚书 29:10–12"> 现在智慧人和占卜者都被带到我面前，为要他们读出这文字，并把它的释义显明给我，但他们却不能讲明这句话的释义；</span>
<span className="v" id="v16" data-v="16" data-xref="但以理书 5:7; 创世记 40:8; 但以理书 5:29"> 而我听说过你能讲解释义，解答难题。现在如果你能读出这文字，并把它的释义显明给我，你就必身穿紫袍，项戴金链，在国中掌权，位居第三。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王纪下 5:16; 创世记 14:23; 列王纪下 5:26"> 那时，但以理在王面前回应说：“愿你的礼物归自己，愿你的赏赐给别人；然而我要为王读出这文字，并把那释义显明给王。</span>
<span className="v" id="v18" data-v="18" data-xref="但以理书 2:37–38; 但以理书 4:17; 但以理书 4:22–25"> 王啊，至高神把国度、权势、尊荣和威严赐给了你先王尼布甲尼撒！</span>
<span className="v" id="v19" data-v="19" data-xref="但以理书 3:6; 但以理书 2:12–13; 但以理书 3:4"> 因着神所赐给他的权势，所有的民族、国家、语言群体都在他面前战兢恐惧；他想要杀谁就杀谁，想要让谁活就让谁活，想要高举谁就高举谁，想要降卑谁就降卑谁。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 9:17; 耶利米书 13:18; 希伯来书 3:13"> 然而，他心里高举自己，灵里变得刚硬，以致行事狂傲，就从王权的宝座上被废黜，他的尊荣也被夺去了。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理书 4:25; 以西结书 17:24; 但以理书 4:35"> 他从世人中被赶出，他的心变得像兽的心一样，他的住处与野驴在一起，他像牛那样吃牧草，身体被天上的露水湿透，直到他明白：至高神在人的国中掌权，愿意立谁就立谁治理国家。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="历代志下 33:23; 出埃及记 10:3; 雅各书 4:17"> “至于你，他的继位人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="继位人——原文直译“儿子”或“子孙”。">d</a></sup>伯沙撒啊！你虽然知道这一切，自己的心却不降卑，</span>
<span className="v" id="v23" data-v="23" data-xref="约伯记 12:10; 但以理书 4:37; 耶利米书 10:23"> 反而对天上的主高举自己，让人把他殿中的器皿带到你面前来，你和你的大臣们、妻子们、妃嫔们都用这些来喝酒；你称赞那些不能看、不能听、不能知——用金、银、铜、铁、木、石所做的神明，却不尊崇那位掌握你的气息、掌握你一切道路的神。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理书 5:5"> 于是，有一只手<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="手——原文直译“手掌”。">e</a></sup>从神那里被派来，写下了这文字。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> “所写下的文字是：弥尼，弥尼，提客勒，赔珥新。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 25:11–12; 以赛亚书 47:1–15; 耶利米书 27:7"> 这句话的释义是这样的：‘弥尼’就是神已经数算了你国的年日<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="的年日——辅助词语。">f</a></sup>，使它终结了；</span>
<span className="v" id="v27" data-v="27" data-xref="约伯记 31:6; 哥林多前书 3:13; 诗篇 62:9"> ‘提客勒’就是在天平上你已经被称量了，发现了亏缺；</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 13:17; 但以理书 6:28; 但以理书 5:31"> ‘赔珥新’就是你的国已经被分割，赐给了米底亚和波斯。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="但以理书 5:16; 但以理书 5:7"> 伯沙撒下令，人就给但以理穿上紫袍，把金链戴在他的颈项上，并宣布他是国中位居第三的掌权者。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米书 51:31; 耶利米书 51:57; 耶利米书 51:39"> 当夜，迦勒底人的王伯沙撒被杀了。</span>
<span className="v" id="v31" data-v="31" data-xref="但以理书 9:1; 但以理书 6:1"> 米底亚人大流士接取这国；当时他六十二岁。</span>
</div>
</div>

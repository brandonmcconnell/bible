<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 17:29; 士师记 10:4; 士师记 5:10"> 王问洗巴：“你带这些是为了什么？”<br />洗巴回答：“驴子是给王的家人骑的，饼和夏天的果实是给年轻人吃的，酒是给在旷野里疲乏的人喝的。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 9:9–10; 诗篇 15:3; 撒母耳记下 19:24–30"> 王问：“你主人的儿子在哪里？”<br />洗巴回答王：“看哪，他留在耶路撒冷，因为他说：‘今天以色列家必将我父的王国归还给我。’”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="箴言 18:13; 箴言 18:17; 箴言 19:2"> 王就对洗巴说：“看哪，一切属于米非波设的，都归你了。”<br />洗巴说：“我向我主我王下拜，愿我在你眼前蒙恩！”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 3:16; 撒母耳记上 17:43; 出埃及记 22:28"> 大卫王来到巴户琳，看哪，从那里出来一个扫罗家族的人，名叫示每，是基拉的儿子。他一边出来，一边咒骂，</span>
<span className="v" id="v6" data-v="6"> 又向大卫王和王的所有臣仆扔石头；那时所有军兵和勇士都在王的左右。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 13:13; 撒母耳记上 25:17; 列王纪上 21:10"> 示每这样咒骂说：“滚出去，滚出去！你这杀人流血的人，你这卑劣的人！</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 1:16; 撒母耳记下 3:28–29; 列王纪上 2:32–33"> 你流了扫罗家的血，取代他作王，耶和华现在把这血债全报应在你身上了，耶和华已经把王权交在你儿子押沙龙手中了。看哪，你自取其祸，因为你是个杀人流血的人。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 22:28; 撒母耳记下 9:8; 撒母耳记上 24:14"> 洗鲁雅的儿子亚比筛对王说：“为什么让这条死狗咒骂我主我王呢？请让我过去，把他的头砍下来！”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 19:22; 罗马书 9:20; 约翰福音 18:11"> 王说：“洗鲁雅的儿子们，我与你们有什么相干呢？如果他这样咒骂是因为耶和华吩咐他‘你要诅咒大卫’，那么谁能说‘你为什么这样做呢？’”</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 17:1–4; 创世记 45:5; 撒母耳记下 12:11–12"> 大卫对亚比筛和所有的臣仆说：“看哪，我亲生的儿子尚且寻索我的性命，更何况这便雅悯的子孙呢！由他吧，让他咒骂！因为是耶和华吩咐了他。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 23:5; 希伯来书 12:10; 诗篇 25:18"> 或许耶和华看见我的苦难，就以恩惠回报我，替代今天这人的咒骂。”</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 23:23; 撒母耳记下 16:5–6"> 大卫和他的部下继续赶路，示每也沿着大卫对面的山坡随行，一边走一边咒骂，从对面向他扔石头、扬尘土。</span>
<span className="v" id="v14" data-v="14"> 王和所有随同他的人走得很疲乏，就在那里休息。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 15:37; 撒母耳记下 15:12"> 押沙龙和以色列众人进了耶路撒冷，亚希多弗也与他一起。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 11:12; 撒母耳记上 10:24; 列王纪上 1:25"> 那时候，大卫的朋友亚基人户筛去见押沙龙，户筛对押沙龙说：“愿王万岁！愿王万岁！”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 19:25; 撒母耳记下 15:32–37; 申命记 32:6"> 押沙龙问户筛：“这是你对朋友的忠诚吗？你为什么没有与你的朋友一起离开呢？”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 16:13; 撒母耳记下 5:1–3"> 户筛对押沙龙说：“不！耶和华和这民——全体以色列人拣选了谁，我就归于谁，留在谁那里。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 15:34; 诗篇 55:21; 撒母耳记上 28:2"> 再者，我该服事谁呢？难道不该服事朋友的儿子吗？我怎样服事你父亲，也会怎样服事你。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 8:10; 诗篇 37:12–13; 以赛亚书 29:15"> 押沙龙对亚希多弗说：“你们给个建议，我们该怎么做呢？”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳记下 20:3; 撒母耳记下 15:16; 撒迦利亚书 8:13"> 亚希多弗对押沙龙说：“你去与你父亲所留下看守宫殿的妃嫔们同房，这样全以色列都会听到你被你父亲憎恶，所有随同你的人就更加坚强。”</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 12:11–12; 撒母耳记下 15:16; 撒母耳记下 20:3"> 于是他们为押沙龙在屋顶上支搭了一座帐篷，押沙龙就在全体以色列人眼前与他父亲的妃嫔们同房。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 15:12; 撒母耳记下 17:14; 撒母耳记下 17:23"> 在那些日子，亚希多弗所提的建议如同人向神求得的话语。亚希多弗的所有建议，无论是给大卫的还是给押沙龙的，都是如此。</span>
</div>

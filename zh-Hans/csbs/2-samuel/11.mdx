<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 20:1; 列王纪上 20:26; 列王纪上 20:22"> 年初，正是诸王出战的时候，大卫派出约押，带领他的臣仆和以色列全军。他们毁灭了亚扪人，然后围困拉巴。那时大卫一直留在耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="马太福音 5:28; 诗篇 119:37; 约伯记 31:1"> 有一天，傍晚的时候，大卫从床上起来，在王宫的屋顶上走动。他从屋顶上看见一个女人在洗澡，这女人容貌极其美丽。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 23:39; 历代志上 3:5; 雅各书 1:14–15"> 大卫派人去打听那个女人。有人说：“这不是伊连的女儿、赫提人乌利亚的妻子芭示巴吗？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="利未记 18:19; 雅各书 1:14–15; 诗篇 51:1–19"> 大卫派人把她带来。她进到大卫那里，大卫就与她同睡——那时她正在从月事<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="月事——原文直译“她”。">a</a></sup>的不洁中得洁净——之后她回家去了。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 22:22; 箴言 6:34"> 那妇人怀了孕，就派人去告诉大卫说：“我怀孕了！”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="箴言 28:13; 创世记 4:7; 撒母耳记上 15:30"> 大卫派人到约押那里说：“你派赫提人乌利亚来见我。”约押就派乌利亚去见大卫。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 37:14; 撒母耳记上 17:22; 创世记 29:6"> 乌利亚来了，大卫问他约押是否平安、军兵是否平安、战事是否顺利。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 18:4; 创世记 43:34; 以赛亚书 29:15"> 然后大卫对乌利亚说：“你回自己家去，洗脚休息<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="休息——辅助词语。">b</a></sup>吧。”乌利亚就从王宫出来，随后有一份王的礼物也跟着送来。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 21:30; 约伯记 5:12–14"> 乌利亚却与他主人的众臣仆一起睡在王宫门口，没有回自己的家。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 有人向大卫报告说：“乌利亚没有回自己的家。”大卫就问乌利亚：“你不是从远路而来吗？为什么不回家去呢？”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 7:2; 撒母耳记下 20:6; 撒母耳记下 7:6"> 乌利亚回答大卫：“约柜、以色列人和犹大人都住在帐幕里，我主约押和我主的臣仆们都在野外扎营，我却回自己家去吃喝，与妻子同睡吗？我指着王和王的生命起誓：我绝不做这样的事！”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米书 2:37; 耶利米书 2:22–23"> 大卫对乌利亚说：“你今天也留在这里，明天我送你走。”那天，乌利亚就留在耶路撒冷。第二天，</span>
<span className="v" id="v13" data-v="13" data-xref="哈巴谷书 2:15; 创世记 19:32–35; 箴言 20:1"> 大卫召他来一起吃喝，把他灌醉了。傍晚他出去，还是到他主人的臣仆们那里，睡在自己的床铺上，没有回自己的家。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米书 17:9; 列王纪上 21:8–10; 诗篇 19:13"> 到了早晨，大卫写了一封书信给约押，让乌利亚带去。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 12:9; 诗篇 51:4; 耶利米书 20:13"> 他在书信里写着说：“你要把乌利亚派到战事激烈的前线，然后你们退到他后面，让他被击杀而死。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="箴言 29:12; 撒母耳记上 22:17–19; 使徒行传 5:29"> 那时约押正在围攻敌城，他就把乌利亚安排到他所知道敌兵最强的地方。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 12:9; 诗篇 51:14"> 城里的人出来与约押交战，军队中大卫的一些臣仆倒下了，赫提人乌利亚也死了。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 于是约押派人去把战事的所有信息报告大卫。</span>
<span className="v" id="v19" data-v="19"> 他吩咐使者说：“你把战事的所有信息对王说完以后，</span>
<span className="v" id="v20" data-v="20"> 如果王发火，对你说：‘你们为什么靠近城墙攻打呢？难道不知道他们会从城墙上射箭吗？</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 7:1; 士师记 9:50–54; 撒母耳记下 3:27"> 谁击杀了耶路·比设的儿子亚比米勒呢？难道不是一个女人从城墙上把一块磨石扔在他身上，他就死在了提贝斯吗？你们为什么靠近城墙呢？’你就说：‘你的臣仆赫提人乌利亚也死了。’”</span>
<span className="v" id="v22" data-v="22"> 那使者就去了。<br />使者到达后，把约押派他来说的一切都报告给大卫。</span>
<span className="v" id="v23" data-v="23"> 使者对大卫说：“敌人实在强过我们，出来在郊外攻打我们，但我们反击他们直到城门口。</span>
<span className="v" id="v24" data-v="24"> 那时射手从城墙上射你的臣仆们，王的臣仆中有一些阵亡了，你的臣仆赫提人乌利亚也死了。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 12:26; 约书亚记 7:8–9; 传道书 9:1–3"> 大卫就对使者说：“你要对约押如此说：‘不要为这件事难过<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="为这件事难过——原文直译“把这件事看为恶”。">c</a></sup>，因为刀剑有时吞灭这个，有时吞灭那个。你只要竭力攻击那城，把它摧毁！’你要这样鼓励约押。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 14:2; 创世记 27:41; 撒母耳记下 3:31"> 乌利亚的妻子听说丈夫乌利亚死了，就为丈夫哀哭。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 51:4–5; 撒母耳记下 12:9; 申命记 22:29"> 哀悼的日子过了，大卫派人去把她接到宫里，她就作了大卫的妻子，为他生了一个儿子。大卫所做的这事，在耶和华眼中看为恶。</span>
</div>
</div>

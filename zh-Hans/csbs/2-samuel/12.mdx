<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 20:35–41; 诗篇 51:1–19; 撒母耳记下 11:10–17"> 耶和华派遣拿单去见大卫。拿单来到大卫那里，对他说：“在一座城中有两个人，一个富有，一个贫穷。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 15:16; 约伯记 1:3; 撒母耳记下 5:13–16"> 那富人有极多的牛羊，</span>
<span className="v" id="v3" data-v="3" data-xref="弥迦书 7:5; 撒母耳记下 11:3; 箴言 5:18–19"> 而那穷人除了一只买来养活的小母羊以外，一无所有。小母羊在他身边与他的孩子们一起长大，吃他所吃的、喝他所喝的、睡在他的怀中，小母羊就像是他的女儿。</span>
<span className="v" id="v4" data-v="4" data-xref="雅各书 1:14; 撒母耳记下 11:3–4; 创世记 18:2–7"> 有一个旅客来到那富人那里，他舍不得从自己的牛羊中取出一只来招待到他那里的旅客，却取了那穷人的小母羊来招待到他那里的人。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 38:24; 罗马书 2:1; 撒母耳记上 26:16"> 大卫就因那人非常恼火，他对拿单说：“我指着耶和华的永生起誓：做这事的人，实在该死！</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 22:1; 路加福音 19:8; 箴言 6:31"> 他必须为小母羊赔偿四倍，因为他做了这事，毫无怜恤之心。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 14:14; 撒母耳记上 16:13; 撒母耳记下 22:1"> 拿单对大卫说：“你就是那人！以色列的神耶和华如此说：‘我膏立你为以色列的王，解救你脱离扫罗的手。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 84:11; 罗马书 8:32; 撒母耳记下 9:7"> 我把你主人的家交给你，把你主人的妃嫔交在你怀中，又把以色列和犹大家交给了你。如果这些还不够，我会增添给你更多；</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 15:19; 诗篇 139:1–2; 撒母耳记上 15:23"> 但你为什么藐视耶和华的话，做他眼中看为恶的事呢？你用刀剑击杀了赫提人乌利亚，又娶他的妻子作你的妻子，你藉着亚扪人的刀剑杀了他！</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 18:14–15; 马太福音 26:52; 罗马书 2:4"> 现在，刀剑必永不离开你的家，因为你藐视了我，娶了赫提人乌利亚的妻子作你的妻子。’</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 16:21–22; 申命记 28:30; 撒母耳记下 15:10"> “耶和华如此说：‘看哪，我必从你家里兴起祸患攻击你。我将在你眼前把你的妃嫔夺去，交给在你身边的人，他会在日光之下、在你眼前与你的妃嫔同睡。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 16:22; 撒母耳记下 11:4–15; 传道书 12:14"> 你虽然在暗中行事，我却要在全体以色列人面前，在日光之下施行这报应。’”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="诗篇 51:4; 撒母耳记下 24:10; 箴言 28:13"> 大卫对拿单说：“我对耶和华犯了罪！”<br />拿单对大卫说：“耶和华已经除去你的罪，你不会死。</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 2:24; 以赛亚书 52:5; 诗篇 89:31–33"> 但因你这行为大大藐视了耶和华<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="大大藐视了耶和华——或译作“使耶和华的仇敌大得亵渎的机会”。">a</a></sup>，你所生的儿子必定死。”</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 25:38; 诗篇 104:29; 历代志下 13:20"> 之后拿单回自己的家去了。 大卫与芭示巴的儿子夭折<br />耶和华打击乌利亚的妻子给大卫所生的孩子，孩子就得了重病。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 13:31; 使徒行传 9:9; 诗篇 69:10"> 大卫为孩子向神祈求，并且禁食，进了房躺在地上过夜。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 3:35; 撒母耳记上 28:23"> 他家中的老臣来站在他旁边，要扶他从地上起来，他却不肯，也不与他们一起吃饭。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民数记 20:15"> 到了第七天，孩子死了。大卫的臣仆们害怕告诉他孩子死了，因为他们说：“看哪，孩子活着的时候，我们对他说话，他都不听劝，我们怎能告诉他孩子已经死了呢？他可能会做出不好的事。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 大卫看见臣仆们低声耳语，就知道孩子已经死了。大卫问臣仆们：“孩子死了吗？”<br />他们回答：“死了。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约伯记 1:20; 路得记 3:3; 耶利米哀歌 3:39–41"> 大卫就从地上起来，洗澡，抹油，更换衣服，进耶和华的殿去敬拜，然后回到宫中，让人给他摆上饭，他就吃了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 2:15"> 臣仆们就问他：“你所做的这些是什么意思呢？孩子活着的时候，你禁食、哭泣；孩子死了，你却起来吃饭。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 38:1–3; 以赛亚书 38:5; 约拿书 3:9–10"> 他说：“孩子还活着的时候，我禁食、哭泣，是因为我想：‘谁知道呢，或许耶和华会恩待我，让孩子得以存活。’</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 37:35; 约伯记 30:23; 路加福音 23:43"> 现在，孩子死了，我为什么还要禁食呢？我能使他回来吗？我必到他那里去，他却不能回到我这里来。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="马太福音 1:6; 历代志上 28:5–6; 历代志上 22:9–10"> 大卫安慰他的妻子芭示巴，进到她那里，与她同睡。她就生了一个儿子，大卫给他起名为所罗门。耶和华爱他，</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 7:4; 尼希米记 13:26; 列王纪上 1:11"> 就派遣先知拿单，为耶和华的缘故给他起名为耶迪底亚。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="历代志上 20:1–3; 申命记 3:11; 撒母耳记下 11:25"> 约押攻打亚扪人的拉巴，攻取了水城<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="水城——原文直译“王城”。">b</a></sup>。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 21:20; 撒母耳记下 11:1; 申命记 3:11"> 约押派遣使者去见大卫，说：“我攻打拉巴，已经攻取了水城。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 7:18"> 现在你要聚集其余的军队，扎营攻击这城，攻取它，免得我攻取了这城，它就会以我的名字命名。”</span>
<span className="v" id="v29" data-v="29"> 于是大卫聚集全军去攻打拉巴，并攻取了它。</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 20:2"> 大卫夺取了亚扪王<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="亚扪王——原文直译“他们的王”；七十士译本和有些古抄本作“米勒公”，就是亚扪人的神。">c</a></sup>头上的王冠，其金子的重量是一他连得<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一他连得——相当于34.2公斤。">d</a></sup>，其上有宝石；这王冠就戴在大卫的头上。大卫从那城带走了极多的战利品，</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 20:3; 诗篇 21:8–9; 阿摩司书 1:3"> 并且把城里的居民带出来，让他们用锯子、铁镐、铁斧做工，或者在砖窑里劳动；他对待亚扪人的各城都是这样。然后大卫和全军回耶路撒冷去了。</span>
</div>

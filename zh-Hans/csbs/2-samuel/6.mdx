<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 13:1–4; 列王纪上 8:1; 历代志上 13:6–14"> 大卫再次招聚以色列中所有的精兵，共三万人。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 4:4; 撒母耳记上 7:1; 诗篇 80:1"> 大卫与所有随同他的人起身前往犹大的巴阿拉<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="巴阿拉——就是基列-耶琳。参《历代志上》13:6；《约书亚记》15:9。">a</a></sup>，要把神的约柜从那里抬上来；这约柜是以坐在基路伯之上万军之耶和华的名而命名的。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 6:7; 民数记 7:4–9; 民数记 4:5–12"> 他们把神的约柜安放在一辆新车上，从丘陵上亚比拿达的家运出来。亚比拿达的两个儿子乌撒和亚希约引领这辆新车，</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 13:7; 撒母耳记上 7:1–2"> 把神的约柜从丘陵上亚比拿达的家运出来；那时亚希约走在约柜前面。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 13:8; 诗篇 150:3–5; 阿摩司书 5:23"> 大卫和以色列全家伴着各种松木乐器，以及竖琴、里拉琴、铃鼓、响板、铜钹，在耶和华面前欢庆。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="历代志上 13:9; 民数记 4:15; 民数记 4:19–20"> 当他们来到拿垦禾场时，牛绊了一下，乌撒就伸手扶住神的约柜。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 6:19; 历代志上 15:13; 历代志上 13:10"> 于是耶和华的怒气向乌撒发作，神因这过失而击杀他，他就当场死在神的约柜面前。</span>
<span className="v" id="v8" data-v="8" data-xref="约拿书 4:1; 历代志上 13:11–12; 约拿书 4:9"> 大卫很恼火，因为耶和华向乌撒怒气爆发。因此那地方被称为佩勒斯-乌撒，直到今日。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 119:120; 历代志上 13:11–12; 民数记 17:12–13"> 那一天，大卫惧怕耶和华，说：“耶和华的约柜怎能到我这里来呢？”</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 26:4–8; 撒母耳记下 15:19; 历代志上 15:18"> 大卫不愿意把耶和华的约柜迁移到大卫城自己那里，于是把它转运到迦特人俄别·以东的家。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 39:5; 创世记 30:27; 箴言 3:9–10"> 耶和华的约柜停留在迦特人俄别·以东的家三个月，耶和华祝福了俄别·以东和他全家。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="历代志上 15:25–3; 列王纪上 8:1; 马太福音 10:42"> 有人告诉大卫王说：“因神约柜的缘故，耶和华祝福了俄别·以东的家和一切属于他的。”大卫就去，欢欢喜喜把神的约柜从俄别·以东家里抬上来，放到大卫城。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 8:5; 历代志上 15:15; 民数记 4:15"> 当抬耶和华约柜的人前进六步，大卫就祭献一头公牛和一只肥畜。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 2:18; 出埃及记 15:20; 诗篇 150:4"> 大卫束着细麻布的以弗得，在耶和华面前极力跳舞。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 68:24–27; 历代志上 15:28; 历代志上 15:25"> 这样，在欢呼和号角声中，大卫和以色列全家把耶和华的约柜抬上来了。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 2:14; 历代志上 15:29; 诗篇 69:7"> 当耶和华的约柜进入大卫城时，扫罗的女儿米甲透过窗户俯看，看见大卫王在耶和华面前踊跃跳舞，心里就藐视他。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="历代志上 15:1; 历代志下 1:4; 列王纪上 8:5"> 他们把耶和华的约柜抬来，安放在预备好的地方，在大卫为它支搭的帐篷内，然后大卫在耶和华面前献上燔祭和平安祭。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 8:55; 历代志上 16:2; 创世记 14:19"> 大卫献完了燔祭和平安祭，就奉万军之耶和华的名祝福民众，</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米记 8:10; 历代志下 35:7–8; 历代志上 16:3"> 又分给以色列所有民众，所有的人无论男女，每人一个饼、一个枣饼、一个葡萄饼。然后全体民众各回各家去了。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳记下 6:16; 撒母耳记下 6:14; 士师记 9:4"> 大卫回去要祝福自己的家人时，扫罗的女儿米甲出来迎接大卫，她说：“今天以色列王多么光彩啊！竟然在臣仆们的婢女眼前露体，如同一个下贱人赤身露体。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 13:22; 诗篇 89:19–20; 撒母耳记上 13:14"> 大卫对米甲说：“我这是在耶和华面前做的，是他拣选了我，胜过拣选你父亲和他全家，任命我作耶和华子民以色列的领袖，所以我要在耶和华面前欢庆。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 4:14; 希伯来书 12:2; 以赛亚书 51:7"> 我还要比这更显为轻贱，自视卑微；至于你提到的那些婢女，她们却会尊重我。”</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 1:25; 以赛亚书 22:14; 以赛亚书 4:1"> 扫罗的女儿米甲，直到死的日子都没有孩子。</span>
</div>
</div>

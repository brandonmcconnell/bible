</div>
<div className="bp poetry">

<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="历代志上 27:4; 历代志上 11:12–14; 撒母耳记上 17:26"> 其次是阿赫阿人朵多的儿子以利亚撒。他是跟随大卫向非利士人骂阵的三勇士之一。当时非利士人聚集在那里要打仗，以色列人撤退，</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 19:5; 撒母耳记上 11:13; 士师记 15:14"> 他却坚守，击杀非利士人，直到手臂疲惫，手粘住刀。那日耶和华施行了大拯救。军兵转回跟着他，只是来剥去死者的衣物。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="历代志上 11:13–14; 历代志上 11:27; 撒母耳记下 23:33"> 再其次是哈拉人亚基的儿子沙玛。有一次，非利士人聚集成队<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="成队——或译作“在利希”。">d</a></sup>，那里有一块长满了扁豆的田地。以色列军兵从非利士人面前逃跑，</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 21:31; 撒母耳记下 23:10; 诗篇 3:8"> 沙玛却在那块田中站立，守护那块田，击杀非利士人。这样耶和华施行了大拯救。</span>
</div>
<div className="bp">

<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 22:4–5; 撒母耳记上 13:4; 撒母耳记上 10:5"> 那时大卫在要塞中，而非利士人的驻军在伯利恒。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 4:14; 诗篇 42:1–2; 以赛亚书 41:17"> 大卫心中渴望，说：“谁能把伯利恒城门旁水窖里的水带来给我喝啊！”</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 35:14; 哥林多后书 5:14; 腓立比书 2:17"> 那三勇士就突破非利士人的防营，从伯利恒城门旁的水窖里打水，提上来带回大卫那里。但大卫不肯喝，而是把水浇奠在耶和华面前，</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 17:10; 马可福音 14:24; 哥林多前书 15:30"> 说：“耶和华啊，我绝不可做这事！这水不是那些冒生命危险之人的血吗？”所以他不肯喝。这些是三勇士的事迹。</span>
</div>
<div className="bp">

<span className="v" id="v19" data-v="19" data-xref="马太福音 13:8; 马太福音 13:23; 哥林多前书 15:41"> 他在三十<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="三十—— 依据古叙利亚文译本；马索拉文本作“三”。">f</a></sup>勇士中最受尊崇，所以成为他们的首领，只是不及那三勇士。</span>
</div>
<div className="bp">

<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 17:51; 历代志上 11:23; 歌罗西书 2:15"> 他还击杀了一个埃及人，是个身材健壮的人；这埃及人手中有长矛，比纳雅却拿着棍子下去攻击他，从他手中抢夺了长矛，用那长矛把他杀了。</span>
<span className="v" id="v22" data-v="22"> 这些是耶赫亚达的儿子比纳雅的事迹，他和那三勇士一样有名。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 20:23; 历代志上 27:6; 撒母耳记上 22:14"> 他在三十勇士中受尊崇，但不及那三勇士。大卫立他作侍卫长。</span>
</div>

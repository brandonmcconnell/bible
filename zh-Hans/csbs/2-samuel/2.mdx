<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="2SA" data-book-slug="2-samuel" data-book-name="撒母耳记下" data-chapter="2" data-verses="32">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 30:31; 撒母耳记上 23:4; 创世记 32:2"> 此后，大卫求问耶和华说：“我可以上犹大的一座城去吗？”<br />耶和华对他说：“可以上去。”<br />大卫又问：“我应该上哪里去呢？”<br />耶和华说：“希伯仑。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 25:42–43; 撒母耳记上 30:5; 路加福音 22:28–29"> 于是大卫和他的两个妻子——耶斯列人娅希暖和迦密人纳巴尔的遗孀娅比盖，就上希伯仑去了。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 30:1; 历代志上 12:1–7; 撒母耳记上 27:2–3"> 大卫把跟随他的部下和各人的家属，也带了上去。他们就在希伯仑的城镇住下。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 5:5; 撒母耳记上 31:11–13; 撒母耳记下 5:3"> 犹大人前来，在那里膏立大卫作犹大家的王。<br />有人告诉大卫说：“是基列-雅比人埋葬了扫罗。”</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 23:21; 诗篇 115:15; 路得记 2:20"> 大卫就派遣使者去见基列-雅比人，对他们说：“愿你们蒙耶和华的祝福！因为你们以恩慈对待你们的主扫罗，把他埋葬了。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 14:22; 出埃及记 34:6; 马太福音 5:44"> 你们既然做了这事，如今愿耶和华以慈爱和信实对待你们！我也会为此善待你们。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 6:10; 撒母耳记下 10:12; 创世记 15:1"> 现在，你们的主扫罗死了，犹大家已经膏立我作他们的王，所以你们要坚强，作英勇的人。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 14:50; 创世记 32:2; 撒母耳记下 3:7–8"> 尼珥的儿子押尼珥——扫罗的元帅，带着扫罗的儿子伊施波设过河<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="河——辅助词语。">a</a></sup>到玛哈念，</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 19:18; 约书亚记 13:8–11; 民数记 1:40"> 然后立他为王治理基列、亚书利、耶斯列、以法莲、便雅悯——整个以色列。</span>
<span className="v" id="v10" data-v="10"> 扫罗的儿子伊施波设作以色列王的时候四十岁，统治了两年。犹大家却跟随大卫；</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 2:11; 撒母耳记下 5:4–5; 历代志上 3:4"> 大卫在希伯仑作犹大家的王共七年零六个月。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约书亚记 18:25; 约书亚记 10:2; 约书亚记 9:3"> 有一次，尼珥的儿子押尼珥与扫罗的儿子伊施波设的臣仆们，从玛哈念出来去基遍；</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 8:16; 历代志上 2:16; 撒母耳记下 20:23"> 洗鲁雅的儿子约押与大卫的臣仆们也出来，在基遍的水池旁边与对方相遇。双方都坐下，一方在水池这边，一方在水池那边。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 2:17; 箴言 10:23; 箴言 17:14"> 押尼珥对约押说：“让年轻人起来，在我们面前较量一下吧！”<br />约押说：“那就让他们起来吧。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 年轻人就起来，按着数目过去：属于扫罗之子伊施波设的便雅悯人有十二个，大卫的臣仆也有十二个。</span>
<span className="v" id="v16" data-v="16"> 他们各人抓住对方的头，把刀刺进对方的肋旁，一同倒毙了。因此那地方被称为希利甲-哈素林，就在基遍。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 3:1"> 那天的战事极其激烈，押尼珥和以色列人败在大卫的臣仆们面前。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 12:8; 哈巴谷书 3:19; 雅歌 8:14"> 当时洗鲁雅的三个儿子约押、亚比筛和亚撒晖都在那里。亚撒晖腿脚敏捷，如同野羚羊。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 2:21; 约书亚记 1:7; 箴言 4:27"> 亚撒晖追赶押尼珥，不偏左右，紧跟在押尼珥后面。</span>
<span className="v" id="v20" data-v="20"> 押尼珥回头说：“亚撒晖，是你吗？”<br />他说：“是我。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="士师记 14:19"> 押尼珥对他说：“你或转向左或转向右，捉住一个年轻人，夺走他的装备吧！”但亚撒晖不肯停止追赶他。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 3:27; 箴言 29:1; 列王纪下 14:10–12"> 押尼珥再次对亚撒晖说：“你转开不要追我了！我何必把你击杀在地呢？那样我怎么有脸见你的哥哥约押呢？”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 3:27; 撒母耳记下 4:6; 撒母耳记下 5:6"> 亚撒晖不肯转开，押尼珥就用矛尾刺入他的腹部，甚至矛从他背后穿出，亚撒晖就仆倒在那里，当场死了；所有来到亚撒晖倒毙之处的人都站住了，</span>
<span className="v" id="v24" data-v="24"> 但约押和亚比筛却继续追赶押尼珥。日落的时候，他们来到亚玛山，在基亚对面、基遍旷野的路旁。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 便雅悯人集结在押尼珥身后，成为一队，站在一座山顶上。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 46:14; 耶利米书 46:10; 使徒行传 7:26"> 押尼珥向约押呼喊，说：“难道刀剑要永久吞噬下去吗？你不知道结局将是苦果吗？你要到什么时候才吩咐大家转回不追赶自己的兄弟呢？”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="箴言 17:14; 撒母耳记下 2:14; 箴言 15:1"> 约押说：“我指着永生的神起誓：要不是你这样说，大家必定不停止追赶自己的兄弟，直到清晨！”</span>
<span className="v" id="v28" data-v="28"> 于是约押吹响号角，所有军兵就停下，不再追赶以色列人，不再继续打仗了。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 2:8; 雅歌 2:17"> 押尼珥和他的部下经过亚拉巴，走了一整夜，然后过了约旦河，又走了一上午<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="走了一上午——传统译法作“穿过毕伦”。">b</a></sup>，回到玛哈念。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 约押追击押尼珥回来，聚集所有军兵，大卫的臣仆中少了十九个人，还少了亚撒晖；</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 3:1; 列王纪上 20:11"> 但大卫的臣仆们击杀押尼珥的部下便雅悯人，杀死了三百六十个人。</span>
<span className="v" id="v32" data-v="32" data-xref="历代志上 2:13–16; 撒母耳记上 17:58; 历代志下 21:1"> 他们抬走亚撒晖，葬在伯利恒他父亲的坟墓里。约押和他的部下走了一整夜，天亮的时候到了希伯仑。</span>
</div>
</div>

</div>

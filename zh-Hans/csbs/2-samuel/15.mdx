<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 1:5; 撒母耳记下 12:11; 撒母耳记上 8:11"> 这事以后，押沙龙为自己配备了一辆车和马匹，以及五十个在他前面奔走开路的人。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 18:14; 路得记 4:1; 约伯记 24:14"> 押沙龙总是清早起来，站在通往城门口的路旁。凡有争讼来见王求裁决的人，押沙龙都会叫他过来，问：“你是哪一城的人？”那人回答：“你仆人来自以色列的一个支派。”</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 8:15; 以西结书 22:7; 彼得前书 2:17"> 押沙龙就会对他说：“你看，你的请求合情合理，但是王那里没有听你诉说的人。”</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 9:29; 士师记 9:1–5; 箴言 27:2"> 押沙龙又说：“但愿有人立我作这地的审判官，这样，任何一个有争讼案件的人都可以到我这里来，我必为他秉公办理。”</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 14:33; 诗篇 55:21; 箴言 26:25"> 每当有人上前来，要向他下拜时，他就伸手扶住那人，并且亲吻他。</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 16:18; 彼得后书 2:3; 箴言 11:9"> 押沙龙如此对待所有来见王求裁决的以色列人，这样押沙龙暗中夺走了以色列人的心。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 58:4; 撒母耳记上 16:13; 撒母耳记上 16:1–2"> 过了四年，押沙龙对王说：“请让我去希伯仑向耶和华还我所许的愿。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 28:20–21; 撒母耳记下 13:37–38; 撒母耳记上 1:11"> 因为仆人住在亚兰的基述时许了一个愿，说：‘如果耶和华让我再回到耶路撒冷，我就敬拜耶和华。’”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 王对他说：“平平安安地去吧！”他就起身，往希伯仑去了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志上 12:38; 撒母耳记下 5:5; 撒母耳记下 3:2–3"> 押沙龙派遣探子到以色列所有的支派中，说：“你们一听见号角声，就要说：‘押沙龙在希伯仑作王了！’”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 9:13; 撒母耳记上 22:15; 罗马书 16:18–19"> 有两百个人随同押沙龙从耶路撒冷前去，他们受邀请，很单纯地去了，什么事情都不知道。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 41:9; 撒母耳记下 15:31; 约书亚记 15:51"> 押沙龙献祭的时候，派人去把大卫的谋士基罗人亚希多弗从他的本城基罗请了来。于是谋反势力强大起来，拥护押沙龙的民众越来越多。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="士师记 9:3; 马太福音 27:22; 撒母耳记下 15:6"> 有一个报信的人来见大卫说：“以色列人的心都归向押沙龙了。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 19:9; 以西结书 46:18; 诗篇 55:3–11"> 大卫就对所有在耶路撒冷随同他的臣仆说：“起来，我们必须逃走，否则我们就来不及从押沙龙面前逃脱。要赶快走，免得他很快追上我们，加害我们，用刀击杀城里的人。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 6:66–69; 箴言 18:24; 路加福音 22:28–29"> 王的臣仆们对王说：“我主我王所决定的一切，看哪，仆人都必遵行<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="必遵行——辅助词语。">a</a></sup>。”</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 16:21–22; 撒母耳记下 20:3; 诗篇 3:1"> 于是王就出发，他的全家都跟随他<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="跟随他——原文直译“在他的脚边”。">b</a></sup>；王留下十个妃嫔看守宫殿。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 3:1–2; 传道书 10:7; 诗篇 66:12"> 王出发时，全体民众都跟随他<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="跟随他——原文直译“在他的脚边”。">c</a></sup>。他们在郊外最后一个房屋那里停下来。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 8:18; 撒母耳记上 30:14; 撒母耳记下 20:7"> 所有的臣仆都从他身边过去，所有的基利提人、比利提人、迦特人，就是从迦特来跟随他<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="跟随他——原文直译“在他的脚边”。">d</a></sup>的六百个人，都从王面前过去。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 18:2; 路得记 1:11–13"> 王对迦特人伊太说：“你怎么也与我们一起离开呢？你回去，留在新<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="新——辅助词语。">e</a></sup>王那里吧！因为你是个外族人，而且是远离家乡的流亡者。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 23:13; 撒母耳记下 2:6; 约翰福音 1:17"> 你昨天才来，今天我就让你与我们一同四处漂泊吗？毕竟我要到处迁移了。你回去吧，带着你的兄弟们回去吧。愿耶和华的慈爱和信实与你同在！”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路得记 1:16–17; 箴言 17:17; 列王纪下 4:30"> 伊太回答王说：“我指着耶和华的永生和我主我王的生命起誓：无论我主我王在什么地方，无论是生是死，仆人都必在那里。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 于是大卫对伊太说：“走，你也过去吧！”迦特人伊太就带着他的所有部下和随同家属，都过去了。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 16:2; 列王纪上 2:37; 约翰福音 18:1"> 当地的人都放声大哭，全体民众过去后，王也过了汲沦溪谷，全体民众都踏上通往旷野的路。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数记 4:15; 撒母耳记下 8:17; 撒母耳记下 20:25"> 看哪，撒督也在那里，所有的利未人都随同他，抬着神的约柜。他们把神的约柜放下，亚比亚特献祭<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="献祭——或译作“也上来”。">f</a></sup>，直到所有民众都离开城完全过去。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 25:30; 诗篇 26:8; 诗篇 43:3–4"> 王对撒督说：“把神的约柜抬回城去吧。如果我在耶和华眼前蒙恩，他必让我回来，再看到约柜和他的居所。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记上 3:18; 撒母耳记下 22:20; 列王纪上 10:9"> 如果他说：‘我不喜悦你’，看哪，我在这里，就让他照着他看为好的对待我吧！”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 9:9; 撒母耳记下 17:17; 撒母耳记下 24:11"> 王对祭司撒督说：“你不是先见吗？带着你的儿子亚希玛斯和亚比亚特的儿子约拿单——你们二人的儿子，平平安安地回城去吧！</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 17:16; 撒母耳记下 15:23; 撒母耳记下 17:1"> 看，我会在旷野的渡口<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="渡口——或译作“荒原”。">g</a></sup>等候，直到有消息从你们那里传来给我。”</span>
<span className="v" id="v29" data-v="29"> 于是撒督和亚比亚特把神的约柜带回耶路撒冷，他们就留在那里。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="以斯帖记 6:12; 撒母耳记下 19:4; 路加福音 19:41"> 大卫沿着橄榄山的斜坡上去，边走边哭。他蒙着头，赤着脚行走。随同他的所有民众也各自蒙着头上去，边走边哭。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 17:14; 撒母耳记下 17:23; 雅各书 3:15"> 有人向大卫报告说：“亚希多弗也在叛党中，随从押沙龙。”<br />大卫就祷告：“耶和华啊，求你使亚希多弗的谋略变为愚拙！”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="约书亚记 16:2; 撒母耳记下 1:2; 诗篇 3:3–5"> 大卫来到山顶敬拜神的地方，看哪，亚基人户筛衣服撕裂、头蒙灰尘来迎接他。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 19:35"> 大卫对他说：“你如果与我一起过去，就会成为我的负担。</span>
<span className="v" id="v34" data-v="34" data-xref="约书亚记 8:2; 撒母耳记下 16:16–19; 马太福音 10:16"> 你如果回城对押沙龙说‘王啊，我是你的仆人，我从前是你父亲的仆人，现在也是你的仆人’，你就可以为我破坏亚希多弗的谋略。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 17:15–16"> 那里不是有祭司撒督和亚比亚特与你在一起吗？你把在王宫里所听见的一切信息告诉祭司撒督和亚比亚特。</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳记下 17:17; 撒母耳记下 15:27; 撒母耳记下 18:19–33"> 看哪，那里还有他们两人的儿子——撒督的儿子亚希玛斯和亚比亚特的儿子约拿单；你们可以派遣他们，把你们听到的一切信息传给我。”</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳记下 16:15–16; 历代志上 27:33"> 于是大卫的朋友户筛进了城，那时押沙龙正在进入耶路撒冷。</span>
</div>
</div>

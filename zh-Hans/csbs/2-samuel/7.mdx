<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 16:7; 路加福音 1:74–75; 列王纪上 5:4"> 当王住进自己的宫殿，耶和华使他得享安息，脱离四围一切仇敌的时候，</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 16:1; 撒母耳记下 5:11; 哈该书 1:4"> 王对先知拿单说：“你看，如今我住在香柏木的宫殿里，神的约柜却在帐幕里。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="历代志上 22:7; 列王纪上 8:17–18; 列王纪下 4:27"> 拿单对王说：“你心里所想的一切，只管去做，因为耶和华与你同在。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="历代志上 17:3; 民数记 12:6; 阿摩司书 3:7"> 当天夜里，耶和华的话语临到拿单，说：</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 23:3–32; 列王纪上 5:3–4; 列王纪上 8:16–19"> “你去告诉我的仆人大卫：‘耶和华如此说：你要为我建造殿宇让我居住吗？</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 8:16; 约书亚记 18:1; 出埃及记 40:18–19"> 要知道，自从我带以色列子民出埃及的那天起直到今日，我从来没有住过殿宇，我一直以帐幕为住所，到处迁移。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 17:6; 撒母耳记下 5:2; 利未记 26:11–12"> 在我与全体以色列子民走过的哪一个地方，我何曾对哪一个以色列士师<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="士师——原文直译“支派”；参《历代志上》17:6。">a</a></sup>，就是我吩咐要牧养我子民以色列的士师，说过这话：你们怎么不为我建造一座香柏木的殿宇呢？’</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="诗篇 78:70–71; 撒母耳记下 6:21; 撒母耳记下 12:7"> “现在，你要对我的仆人大卫这样说：‘万军之耶和华如此说：是我把你从牧场上、从羊群后带出来，作我子民以色列的领袖。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 5:10; 历代志上 17:8; 撒母耳记上 18:14"> 我在你所去的任何地方一直与你同在，并且从你面前剪除了你的一切仇敌。我将为你成就大名，如同世上那些伟人的名。</span>
<span className="v" id="v10" data-v="10" data-xref="阿摩司书 9:15; 历代志上 17:9; 耶利米书 24:6"> 我必为我的子民以色列选定一个地方，栽植他们，使他们安居在那里，不再受搅扰，也不再像先前那样被不义之人苦待——</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 7:27; 撒母耳记下 7:1; 历代志上 17:10"> 从我吩咐士师治理我子民以色列的日子以来，他们一直被苦待。我要使你得享安息，脱离一切仇敌。<br />“‘耶和华向你宣告：耶和华将为你建立家室。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 8:20; 使徒行传 2:30; 使徒行传 13:36"> 当你寿数满足，与你列祖长眠时，我必兴起你亲生的后裔接续你，也必坚立他的王权。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 1:31–33; 列王纪上 8:19; 撒母耳记下 7:16"> 他将为我的名建造殿宇，我必坚立他的王位，直到永远。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 1:5; 启示录 3:19; 历代志上 17:13"> 我要作他的父亲，他要作我的儿子。当他行事扭曲，我要用人的杖、用世人的鞭来惩戒他；</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 15:23; 撒母耳记上 15:28; 诗篇 89:28"> 我的慈爱却不会离开他，像离开在你面前所废除的扫罗那样。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 1:32–33; 诗篇 89:36–37; 撒母耳记下 7:13"> 你的家和你的国必在我<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="我——依据七十士译本；马索拉文本作“你”。">b</a></sup>面前永远坚固，你的王位必永远坚立。’”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="历代志上 17:15; 使徒行传 20:27; 哥林多前书 15:3"> 拿单就把这一切话语，把这整个异象，如实地告诉了大卫。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="诗篇 8:4; 历代志上 17:16; 撒母耳记上 18:18"> 于是大卫王进去，坐在耶和华面前，说：“主耶和华啊，我是谁，我的家算什么，你竟带领我到这地步！</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 55:8–9; 历代志上 17:17; 诗篇 36:7"> 主耶和华啊，这在你眼中还看为小事，你竟又提说仆人家的未来！主耶和华啊，这难道是人的常例吗？</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 21:17; 撒母耳记上 16:7; 诗篇 139:1"> 大卫还能对你说什么呢？主耶和华啊，你知道你的仆人。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 115:1; 诗篇 138:2; 以弗所书 1:9"> 你因着自己的应许，照着自己的心意行了这一切大事，为要显明给你的仆人。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="诗篇 86:10; 出埃及记 15:11; 诗篇 86:8"> “主耶和华啊，你是如此伟大！照着我们耳中所听见的一切，没有像你的，除你以外没有别的神。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 9:26; 申命记 10:21; 申命记 15:15"> 世上有哪一国像你的子民以色列呢？神为自己赎回一个民族，为自己立名，在你从埃及、列国和他们神明那里救赎的子民面前，为你的地行了大而可畏的事。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 26:18; 彼得前书 2:10; 创世记 17:7"> 你为自己坚立了你的子民以色列，使他们永远作你的子民；耶和华啊，你也作了他们的神。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="诗篇 119:49; 以西结书 36:37; 创世记 32:12"> “现在，耶和华神哪，你所应许的有关你仆人和他家的话，求你永远确立。求你照着你所应许的行事，</span>
<span className="v" id="v26" data-v="26" data-xref="历代志上 17:23–24; 诗篇 72:18–19; 马太福音 6:9"> 这样，你的名就永远被尊为大，人必说：‘万军之耶和华就是掌管以色列的神。’你仆人大卫的家也将在你面前被坚立，</span>
<span className="v" id="v27" data-v="27" data-xref="历代志上 17:25–26; 诗篇 10:17; 路得记 4:4"> 因为你——万军之耶和华以色列的神，是你亲自启示你的仆人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="启示你的仆人——原文直译“开启你仆人的耳朵”。">c</a></sup>，说：‘我要为你建立家室。’所以你的仆人有了勇气来向你献上这祷告。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 17:17; 出埃及记 34:6; 民数记 23:19"> 是的，主耶和华啊，你是神，你的话语就是真理，是你向你的仆人应许了这福份。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 6:24–26; 历代志上 17:27; 诗篇 115:12–15"> 现在，愿你祝福你仆人的家，使它在你面前永远长存，因为主耶和华啊，你已经发话了。愿你仆人的家因你的祝福而永远蒙福。”</span>
</div>
</div>

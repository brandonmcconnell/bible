<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 13:39; 撒母耳记下 2:18; 撒母耳记下 18:33"> 洗鲁雅的儿子约押知道王的心中想念押沙龙，</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 11:6; 阿摩司书 1:1; 路得记 3:3"> 约押就派人去提克亚，从那里带来一个有智慧的妇人，对她说：“请你装作居丧的人，穿上丧服，不要涂抹膏油，要装作为死者悲恸多日的妇人。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 14:19; 出埃及记 4:15; 以赛亚书 51:16"> 你去见王，对他说以下这些话。”然后约押把要说的话教给了妇人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="把要说的话教给了妇人——原文直译“把话放在她口中”。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 1:2; 列王纪下 6:26–28; 撒母耳记上 25:23"> 提克亚的那妇人就去见王<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="去见王——依据七十士译本以及有些古抄本；马索拉文本作“对王说”。">b</a></sup>，脸伏于地下拜，说：“王啊，求你救我！”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="士师记 9:8–15; 撒母耳记下 12:1–3"> 王问她：“你有什么事呢？”<br />她说：“是这样，我是个寡妇，我的丈夫死了。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 4:8; 申命记 22:26–27; 出埃及记 2:13"> 你的婢女有两个儿子，他们两个在田里打架，没有人从中调解，一个攻击另一个，把他打死了。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 35:19; 马太福音 21:38; 撒母耳记下 12:17"> 看哪，全家族都起来攻击婢女，说：‘把那打死兄弟的人交出来，让我们把他处死，抵偿被杀的兄弟的性命。让我们把这继承人也除灭了！’他们这是要熄灭我的余火，不让我丈夫在这地上存留名字和余种！”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="箴言 18:13; 以赛亚书 11:3–4; 约伯记 29:16"> 王对妇人说：“你回家去吧！我会为你的事下达指示。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 25:24; 列王纪上 2:33; 马太福音 27:25"> 提克亚的那妇人就对王说：“我主我王，愿这罪孽归于我和我父家！王和你的王权是清白的。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 王说：“谁要对你说什么，就把他带来见我，他绝不会再扰害你了。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 14:45; 马太福音 10:30; 民数记 35:19"> 她说：“请王提说你的神耶和华为证，不让报血仇的人增添毁灭，以免他们把我的儿子除灭了。”<br />王说：“我指着耶和华的永生起誓：你儿子连一根头发也不会落在地上。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 18:27; 撒母耳记上 25:24; 使徒行传 26:1"> 妇人又说：“请让婢女对我主我王再说一句话。”<br />王说：“你说吧。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 13:37–38; 撒母耳记下 12:7; 士师记 20:2"> 妇人说：“你为什么想出类似的事对待神的子民呢？王说这样的话，就像是定了自己的罪，因为王不让流亡者回来。</span>
<span className="v" id="v14" data-v="14" data-xref="约伯记 30:23; 民数记 35:28; 希伯来书 9:27"> 确实我们都会死去，如同泼在地上的水不能收回，但神不是要取人性命，而是要想出方法不让流亡者一直被驱逐而远离他。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> “现在我来对我主我王说这话，因为族人恐吓我，婢女就想：‘我去求告王，或许王会成全女仆的请求。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 26:19"> 王必定垂听，解救女仆脱离那些人的手，就是那些要从神的继业上把我和我儿子一同除灭的人。’</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 29:9; 撒母耳记下 19:27; 撒母耳记下 14:20"> 婢女想：‘唯愿我主我王的话带来安慰，因为我主我王明辨是非，就像神的使者那样。’愿你的神耶和华与你同在！”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米书 38:25; 撒母耳记上 3:17–18; 耶利米书 38:14"> 王回应那妇人，说：“我将要问你的事情，不要向我隐瞒。”<br />妇人说：“我主我王请说。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 14:3; 撒母耳记上 1:26; 撒母耳记上 20:3"> 王就问：“这一切都是约押一手安排的吗？”<br />妇人回答说：“我指着我主我王的生命起誓：我主我王所说的一切不偏左右<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="不偏左右——或译作“没有人能偏左偏右”。">c</a></sup>，正是你的臣仆约押吩咐我的，是他把这一切话教给了你的婢女。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记下 14:17; 撒母耳记下 19:27; 约伯记 32:21–22"> 王的臣仆约押做这事，是为了扭转局面。我主有智慧，像神使者的智慧那样，明察地上的一切事。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳记下 14:11; 撒母耳记上 14:39; 马可福音 6:26"> 于是王对约押说：“看哪！我现在应允这事。你去把那年轻人押沙龙带回来吧！”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路得记 2:2; 约伯记 31:20; 约伯记 29:11"> 约押脸伏于地下拜，祝福王，然后约押说：“今天你的臣仆知道，我在我主我王眼前蒙恩，因为王应允了你臣仆的请求。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 3:3; 撒母耳记下 13:37–38"> 于是约押起身，往基述去，把押沙龙带回耶路撒冷。</span>
<span className="v" id="v24" data-v="24" data-xref="启示录 22:4; 创世记 43:3; 撒母耳记下 3:13"> 王说：“让他回自己的家吧，不要来见我的面。”押沙龙就回自己家去，没有见王的面。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 1:6; 申命记 28:35; 约伯记 2:7"> 全以色列没有人像押沙龙那样俊美而大受称赞的，他从脚底到头顶，身上没有一点缺陷。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 44:20; 哥林多前书 11:14; 撒母耳记下 18:9"> 他每年年底都要剃头，这是因为头发太重就要剃掉；他剃了头，总是要称一下头发，按照王的砝码标准约有两百谢克尔<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="两百谢克尔——相当于2.3公斤。1谢克尔=11.4公克。">d</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="撒母耳记下 18:18; 撒母耳记下 13:1; 以赛亚书 14:22"> 押沙龙生了三个儿子、一个女儿，女儿名叫塔玛尔，是个容貌俊美的女子。</span>
<span className="v" id="v28" data-v="28"> 押沙龙在耶路撒冷住了整整两年，都没有见王的面。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 14:30–31; 以斯帖记 1:12; 马太福音 22:3"> 押沙龙派人请约押来，想委托他去见王，约押却不肯来见他。他第二次再派人去，约押还是不肯来。</span>
<span className="v" id="v30" data-v="30" data-xref="士师记 15:4–5; 列王纪下 10:6–7; 列王纪下 9:33"> 于是押沙龙对他的仆人说：“你们看，约押的一块地在我隔壁，那地里有大麦。你们去放火烧了它！”押沙龙的仆人就放火烧了那块地。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31"> 约押起身，来到押沙龙的家，问他：“你的仆人为什么放火烧了我那块地呢？”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 20:8; 出埃及记 14:12; 箴言 28:13"> 押沙龙对约押说：“看哪，我曾派人去你那里说：‘请你过来，我想委托你去见王说：“我何必从基述回来呢？我不如留在那里。”’现在我要见王的面，如果我身上有罪孽，就让他把我处死吧！”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="创世记 33:4; 路加福音 15:20; 创世记 27:26"> 于是约押去见王，告诉了王，王就召见押沙龙。押沙龙去见王，在王面前脸伏于地向他下拜，王就亲吻押沙龙。</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="2SA" data-book-slug="2-samuel" data-book-name="撒母耳记下" data-chapter="19" data-verses="43">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 18:5; 撒母耳记下 18:14; 箴言 17:25"> 有人告诉约押：“看哪，王在为押沙龙哀哭、悲恸。”</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 19:12; 箴言 16:15"> 当天的胜利就变为全军的悲哀，因为军兵那天听说了王在为他的儿子悲伤。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 31:27; 撒母耳记下 19:32; 撒母耳记下 17:24"> 那天，军兵偷偷进城，就像从战场逃跑后羞惭地偷偷进城一样。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 18:33; 撒母耳记下 15:30"> 王蒙着脸，大声哀叫：“我儿押沙龙！押沙龙，我儿，我儿啊！”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="诗篇 18:47–48; 诗篇 3:8; 尼希米记 9:27"> 约押进屋见王，说：“你今天使你的所有臣仆满面羞愧了！今天是他们救了你的性命、你儿女的性命、你妃嫔的性命。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 23:5; 撒母耳记下 3:24–25; 箴言 19:9–10"> 你却爱那些恨你的人，而恨这些爱你的。你今天实在表明了，首领们和臣仆们对你不算什么。我今天看明了：还不如押沙龙活着，而我们大家都死了，你就高兴了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="箴言 14:28; 创世记 34:3; 箴言 19:15"> “现在，你要起来，出去对你的臣仆们说宽心的话。我指着耶和华起誓：如果你不出去，今夜就没有人留下来与你在一起了——这将比你从年幼到现在所遭受的一切祸患都严重。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 18:24; 撒母耳记下 18:4; 撒母耳记下 19:3"> 于是王起来，坐在城门口。有人向全体军兵传告说：“看哪，王坐在城门口。”所有人就来到王面前。<br />那时，以色列人已经各自逃回自己的帐篷去了。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 15:14; 创世记 3:12–13; 撒母耳记下 8:1–14"> 以色列各支派的人都在议论说：“王曾经把我们从仇敌手中解救出来，是他救我们脱离了非利士人的手；如今他因押沙龙而逃离了这地，</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 18:14; 士师记 18:9; 何西阿书 8:4"> 但我们所膏立统治我们的押沙龙却已经死在战场上了。现在我们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我们——原文直译“你们”，但立场是我们。">a</a></sup>为什么保持沉默，不请王回来呢？”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 15:29; 列王纪上 2:35; 撒母耳记下 15:35–36"> 大卫王派人去见祭司撒督和亚比亚特，说：“你们要问犹大的长老们，说：‘你们怎么能作最后请王回宫的人呢？以色列众人的话已经传到王和他的居所那里。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 5:1; 创世记 2:23; 以弗所书 5:30"> 你们是我的兄弟、我的骨肉之亲，怎么能作最后请王回来的人呢？’</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 17:25; 列王纪上 19:2; 路得记 1:17"> 也要对亚玛撒说：‘你不是我的骨肉之亲吗？我如果不立你在我面前作元帅，终身替代约押，就愿神处置我，重重地处置我！’”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="士师记 20:1; 使徒行传 4:32; 诗篇 110:2–3"> 这样大卫赢得犹大所有人的心，如同一人的心。他们就派人来见王，说：“请你和你所有的臣仆都回来！”</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 5:9; 撒母耳记上 11:14–15"> 王就回来，到了约旦河；犹大人赶到吉甲去迎接王，请王渡约旦河。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪上 2:8; 撒母耳记下 16:5–13; 列王纪上 2:36–46"> 巴户琳的便雅悯人基拉的儿子示每，急忙与犹大人一同下去迎接大卫王。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 16:1–4; 撒母耳记下 9:2; 撒母耳记下 9:10"> 有一千个便雅悯人与他一起，还有扫罗家的仆人洗巴带着十五个儿子、二十个仆人。他们在王之前赶到了约旦河，</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 81:15; 启示录 3:9; 诗篇 66:3"> 然后渡过河，把王的家人接过来，做王眼中看为好的事。<br />王过约旦河的时候，基拉的儿子示每俯伏在王面前，</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 22:15; 撒母耳记下 13:20; 撒母耳记下 13:33"> 对王说：“求我主不要计算我的罪孽；我主我王离开耶路撒冷的那天，仆人行事扭曲，求王不要记念、不要放在心上。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 12:25; 诗篇 78:34–37; 创世记 48:14"> 因为你的仆人知道自己实在犯了罪，看哪，我今天是约瑟全家第一个下来迎接我主我王的。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及记 22:28; 撒母耳记上 26:9; 列王纪上 21:10–11"> 洗鲁雅的儿子亚比筛回应说：“示每竟然咒骂耶和华的受膏者，难道不应该为此被处死吗？”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 11:13; 撒母耳记下 16:10; 撒母耳记下 3:39"> 大卫说：“洗鲁雅的儿子们，我与你们有什么相干呢？难道今天你们要与我作对吗？今天在以色列中怎么可以处死人呢？难道我不知道今天我是以色列的王吗？”</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 2:46; 列王纪上 2:8–9; 列王纪上 2:37"> 然后王对示每说：“你不会死！”王又向他起了誓。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米书 41:5; 马太福音 6:16; 撒母耳记下 15:30"> 扫罗的孙子米非波设也下去迎接王；自从王走的那天起，直到王平安回来这天，他没有修脚，没有修剪胡子，也没有洗衣服。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 16:17"> 他从耶路撒冷来迎接王的时候，王问他：“米非波设，你为什么没有与我一同离开呢？”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 16:2–3; 撒母耳记下 4:4; 撒母耳记下 9:3"> 他回答：“我主我王啊，你仆人本来说‘我要给驴子备好鞍，骑上驴子与王一同离开’，因为你仆人是瘸腿的；可是我的仆人欺骗了我！</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记下 14:17; 撒母耳记下 14:20; 撒母耳记上 29:9"> 他又向我主我王诽谤了你仆人。然而我主我王像神的使者一样，你看怎样好就怎样做吧！</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 9:13; 撒母耳记下 9:10; 撒母耳记下 21:6–9"> 我父的全家，本来就在我主我王面前什么都不是，只不过是该死之人，你却把仆人安排在你筵席上吃饭的人当中。我还有什么权利向王呼求更多呢？”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行传 18:15; 诗篇 101:5; 诗篇 82:2"> 王就对他说：“何必再提你那些事呢？我已经定了：你和洗巴平分田地。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="腓立比书 1:20; 使徒行传 20:24; 撒母耳记下 1:26"> 米非波设对王说：“既然我主我王平安回宫，就是洗巴全部拿去也好。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪上 2:7; 尼希米记 7:63; 以斯拉记 2:61"> 基列人巴尔兹莱从罗格琳下来，与王一同前往约旦河，要在约旦河那里给王送行。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 25:2; 约伯记 1:3; 箴言 16:31"> 巴尔兹莱很老了，已经八十岁。王住在玛哈念的时候，他供应了王，因为他是一个非常富有的人。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 25:34–40; 路加福音 22:28–30; 撒母耳记下 9:11"> 王对巴尔兹莱说：“你与我一起过去吧，我会在耶路撒冷、在我的身边供养你。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="雅各书 4:14; 哥林多前书 7:29; 创世记 47:8–9"> 巴尔兹莱对王说：“我就算与王一起上耶路撒冷，还能活多少年日呢？</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 15:33; 以斯拉记 2:65; 诗篇 90:10"> 我现在已经八十岁了，还能辨别好坏吗？难道你的仆人还能品尝所吃的、所喝的吗？难道我还能听出男女歌唱的声音吗？你的仆人何必成为我主我王额外的负担呢？</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 6:38"> 仆人只不过是陪同王过约旦河，王何必以这样的赏赐恩待我呢？</span>
<span className="v" id="v37" data-v="37" data-xref="列王纪上 2:7; 耶利米书 41:17; 撒母耳记下 19:40"> 请让仆人回去吧，我要死在本乡，靠近我父母的坟墓。看哪，你的仆人金罕在这里，让他与我主我王一同过去吧。你看怎样好，就怎样对待他。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> 王说：“就让金罕与我一同过去，我必按你看为好的对待他。你希望我做的一切，我都会为你成全。”</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 31:55; 路得记 1:14; 创世记 47:7"> 于是全体军兵过了约旦河，王也过去了。王亲吻巴尔兹莱，祝福了他，然后巴尔兹莱回自己的地方去了。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="马太福音 21:9; 创世记 49:10; 撒母耳记下 19:11–15"> 王前往吉甲，金罕也与他一同过去；所有的犹大军兵，还有以色列军兵的一半，都护送王过去。</span>
<span className="v" id="v41" data-v="41" data-xref="士师记 8:1; 士师记 12:1; 约翰福音 7:5–6"> 看哪，以色列众人来见王，问王：“我们的兄弟犹大人为什么偷偷地带走王，把王和家人、以及所有大卫的部下接过约旦河呢？”</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="撒母耳记下 19:12; 撒母耳记下 5:1; 历代志上 2:3–17"> 犹大众人回应以色列人，说：“因为王与我们是亲族。你们为什么因这事恼火呢？难道我们吃了王的什么东西，或者我们得了什么好处吗？”</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="加拉太书 5:20; 撒母耳记下 5:1; 列王纪上 11:30–31"> 以色列人回应犹大人，说：“在王的一切事上，我们占有十份，所以我们比你们与大卫更有份。你们为什么藐视我们呢？不是我们先说要我们的王回来的吗？”但是犹大人的话比以色列人的话更强硬。</span>
</div>
</div>

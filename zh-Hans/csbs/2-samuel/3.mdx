<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="2SA" data-book-slug="2-samuel" data-book-name="撒母耳记下" data-chapter="3" data-verses="38">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 14:30; 箴言 4:18–19; 约伯记 8:7"> 扫罗家和大卫家之间的争战持续了很久，大卫家日渐强盛，扫罗家日渐衰弱。</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="历代志上 3:1–4; 创世记 49:3–4; 撒母耳记下 13:1–29"> 大卫在希伯仑生了几个儿子：<br /><span className="pl pl-1">长子暗嫩，</span><br /><span className="pl pl-1">是耶斯列人娅希暖所生；</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 27:8; 历代志上 3:1; 申命记 3:14"> <span className="pl pl-1">次子基利押，</span><br /><span className="pl pl-1">是迦密人纳巴尔的遗孀娅比盖所生；</span><br /><span className="pl pl-1">三子押沙龙，</span><br /><span className="pl pl-1">是基述王塔尔迈的女儿玛迦的儿子；</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 2:13–25; 列王纪上 1:5–18"> <span className="pl pl-1">四子亚多尼雅，</span><br /><span className="pl pl-1">是哈及的儿子；</span><br /><span className="pl pl-1">五子示法提雅，</span><br /><span className="pl pl-1">是亚比塔的儿子；</span><br /></span>
<span className="v" id="v5" data-v="5"> <span className="pl pl-1">六子以特念，</span><br /><span className="pl pl-1">是大卫的妻子以格拉所生。</span><br />这些儿子都是大卫在希伯仑所生的。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 2:8–9; 历代志下 25:8; 以赛亚书 8:9–10"> 在扫罗家与大卫家争战期间，押尼珥在扫罗家强盛起来。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 21:8–11; 列王纪上 2:21–22; 撒母耳记下 12:8"> 扫罗有一个妃嫔，名叫利斯巴，是阿亚的女儿。伊施波设对押尼珥说：“你为什么与我父亲的妃嫔同房呢？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 9:8; 撒母耳记下 16:9; 马可福音 6:18–19"> 押尼珥因伊施波设的话非常恼火，他说：“我是犹大的狗头吗？我如今以恩慈对待你父亲扫罗的家和他的兄弟、伙伴，没有把你交在大卫手中，你现在竟指控我和这女人犯罪！</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 15:28; 列王纪上 19:2; 路得记 1:17"> 我如果不照着耶和华向大卫所起的誓为大卫去行——从扫罗家挪去王权，确立大卫的宝座，使他统治以色列和犹大，从但直到比尔-谢巴——就愿神处置押尼珥，重重地处置他！”</span>
<span className="v" id="v11" data-v="11"> 伊施波设一句话也不敢再回应押尼珥，因为他惧怕押尼珥。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="历代志上 12:38–40; 撒母耳记下 3:21; 路加福音 16:5–8"> 押尼珥派遣使者代表他去见大卫，说：“这地属于谁呢？”又说：“你与我立约吧，看哪，我的手必辅助你，使全体以色列人都归向你。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 43:3; 撒母耳记上 19:11–17; 创世记 44:23"> 大卫说：“好，我与你立约。只是我请求你一件事：你来见我的时候，要先把扫罗的女儿米甲带来，否则不得见我的面。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 18:27; 撒母耳记上 18:25; 撒母耳记下 2:10"> 随后大卫派遣使者去见扫罗的儿子伊施波设，说：“请把我的妻子米甲还给我，她是我用一百个非利士人的包皮聘娶的。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 25:44"> 伊施波设就派人去，把米甲从她丈夫——拉伊的儿子帕尔提业那里带回来。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 16:5; 撒母耳记下 19:16; 列王纪上 2:8"> 她丈夫与她一起去，跟在她后面边走边哭，直到巴户琳。押尼珥对帕尔提业说：“走吧，回去吧！”他就回去了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 押尼珥与以色列的长老们商议，说：“你们从前就一直想要大卫作你们的王，</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 15:28; 诗篇 89:19–23; 撒母耳记上 9:16"> 现在行动吧！因为耶和华论到大卫曾说：‘我要藉着我仆人大卫的手，拯救我的子民以色列脱离非利士人的手和一切仇敌的手。’”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="历代志上 12:29; 撒母耳记上 10:20–21; 诗篇 68:27"> 押尼珥把这话也说给便雅悯人听，然后他去希伯仑，把以色列人和便雅悯全家眼中看为好的都说给大卫听。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 31:54; 创世记 26:30; 以斯帖记 1:3"> 押尼珥带着二十个人，来到希伯仑见大卫，大卫就为押尼珥和随同他的人摆设宴席。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳记下 3:12; 列王纪上 11:37; 撒母耳记下 3:10"> 押尼珥对大卫说：“让我动身，去把全体以色列人都招聚到我主我王这里，让他们与你立约，这样你就可以照着自己的心愿统治一切。”于是大卫送押尼珥走，他就平安地离开了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 看哪，大卫的臣仆和约押出击回来了，带着许多战利品。那时押尼珥不在希伯仑大卫那里，因为大卫已经把他送走，他也平安地离开了。</span>
<span className="v" id="v23" data-v="23"> 约押和随同的全军到达后，有人告诉约押说，尼珥的儿子押尼珥曾来过王这里，王已经把他送走，他也平安地离开了。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 3:8; 撒母耳记下 19:5–7; 约翰福音 18:35"> 约押来见王，说：“你做了什么呢？看哪，押尼珥来见你，你为什么把他送走呢？他竟然离开了！</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 28:6; 以赛亚书 37:28; 民数记 27:17"> 你知道尼珥的儿子押尼珥，他来是要引诱你，要了解你的出入，了解你的一切行动。”</span>
<span className="v" id="v26" data-v="26" data-xref="箴言 26:23–26; 箴言 27:4–6"> 约押从大卫那里出来，派人去追赶押尼珥；他们从西拉的水井那里请他回来，大卫却不知道。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 2:5; 撒母耳记下 20:9–10; 列王纪上 2:32"> 押尼珥回到希伯仑，约押把他拉到城门里要与他私下说话。约押在那里刺穿他的腹部，他就死了，因为他流了约押弟弟亚撒晖的血。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="民数记 35:33; 出埃及记 21:12; 创世记 9:6"> 事后大卫听说了，就说：“对于尼珥的儿子押尼珥被杀流血的事，我和我的王国在耶和华面前永远是清白的。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 1:16; 诗篇 109:8–19; 利未记 13:44–46"> 愿这罪归到约押的头上以及他父亲的全家，愿约押家不断有患漏症的、患麻风的、拄拐杖的、倒在刀下的和缺乏食物的！”</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 28:17; 使徒行传 28:4; 撒母耳记下 2:19–23"> 约押和他弟弟亚比筛杀押尼珥，是因他在基遍战场上杀了他们的弟弟亚撒晖。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="创世记 37:34; 撒母耳记下 1:11; 撒母耳记下 1:2"> 大卫对约押和跟随他的全体民众说：“你们当撕裂衣服、束上麻布，在押尼珥面前哀哭。”然后大卫王跟在棺材后面。</span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="箴言 24:17; 约伯记 31:28; 撒母耳记上 30:4"> 他们把押尼珥葬在希伯仑，王在押尼珥的坟墓旁放声大哭，全体民众也都哭了。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 1:17; 历代志下 35:25; 路加福音 12:19–20"> 王为押尼珥作哀歌，说：<br /><span className="pl pl-1">“押尼珥死去，怎么像愚顽人死去！</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="士师记 16:21; 撒母耳记下 1:12; 约伯记 24:14"> <span className="pl pl-1">你的手没有被捆住，</span><br /><span className="pl pl-1">你的脚没有被铜镣枷住，</span><br /><span className="pl pl-1">你却仆倒，像人仆倒在不义之子面前！”</span><br />全体民众就又为他哀哭。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 12:17; 撒母耳记下 1:12; 路得记 1:17"> 人们在白天的时候都来劝大卫吃点东西，但大卫起誓说：“如果我在日落之前吃了饼或其他任何东西，就愿神处置我，重重地处置我！”</span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 7:37; 诗篇 62:9; 马可福音 15:11–13"> 人们都认同了，这在他们眼中看为好，正如王所做的每一件事在他们眼中都看为好。</span>
<span className="v" id="v37" data-v="37"> 那天，全体民众和全以色列都知道，杀尼珥的儿子押尼珥不是出于王意。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="约伯记 32:9; 撒母耳记下 2:8; 撒母耳记下 3:12"> 王又对他的臣仆说：“难道你们不知道，今天在以色列中有一位领袖、一位伟人倒下了吗？</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪上 2:33–34; 诗篇 101:8; 诗篇 28:4"> 我虽然被膏立为王，今天却软弱；这些人——洗鲁雅的儿子们强硬得令我作难。愿耶和华照着恶人所行的恶，报应恶人！”</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="2SA" data-book-slug="2-samuel" data-book-name="撒母耳记下" data-chapter="13" data-verses="39">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 3:9; 撒母耳记下 3:2–3; 撒母耳记下 13:15"> 此后发生了一件事：大卫的儿子押沙龙有一个美丽的妹妹，名叫塔玛尔，大卫的儿子暗嫩爱上了她。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 7:10; 列王纪上 21:4; 雅歌 5:8"> 暗嫩因妹妹塔玛尔的缘故忧闷成疾，因为她是个处女，在暗嫩看来很难对她做什么。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 16:9; 哥林多前书 3:19; 雅各书 3:15"> 暗嫩有一个朋友，名叫约拿达，是大卫的哥哥示米亚的儿子。约拿达是一个非常精明的人。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 20:17; 利未记 18:9; 以斯帖记 5:13–14"> 他对暗嫩说：“王子啊，你为什么天天都这样憔悴呢？你不能告诉我吗？”<br />暗嫩对他说：“我爱上了我弟弟押沙龙的妹妹塔玛尔。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马可福音 6:24–25; 箴言 19:27; 使徒行传 23:15"> 约拿达对他说：“你躺在床上装病。你父亲来看你，你就对他说：‘请让我的妹妹塔玛尔来，给我东西吃。让她在我眼前预备吃的，让我可以看见，并且从她的手中吃。’”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 18:6; 马太福音 13:33"> 于是暗嫩躺着装病。王来看他，暗嫩就对王说：“请让我妹妹塔玛尔来，在我眼前做两个饼，我好从她手中吃。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 大卫就派人到宫里对塔玛尔说：“请你去你哥哥暗嫩的家，给他做点吃的。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 于是塔玛尔去了她哥哥暗嫩的家，暗嫩正躺着。她取了面团揉好，在暗嫩眼前做饼，把饼做熟了。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 45:1; 约翰福音 3:20; 士师记 3:19"> 塔玛尔拿起锅，在他面前倒出饼，他却不肯吃。暗嫩说：“所有人离开我出去！”所有的人就离开他出去了。</span>
<span className="v" id="v10" data-v="10"> 暗嫩对塔玛尔说：“把吃的带到卧室来，我好从你手中吃。”塔玛尔就拿了做好的饼，带到她哥哥暗嫩的卧室，</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 39:11–12"> 上前来给他吃。他却抓住塔玛尔，对她说：“我的妹妹，来与我同睡吧！”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="士师记 19:23; 利未记 20:17; 士师记 20:6"> 塔玛尔对他说：“不，哥哥，不要玷辱我！在以色列绝不可做这样的事，你不要做这丑恶的事。</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 19:24; 创世记 20:12; 创世记 19:8"> 不然，我到哪里除去我的羞辱呢？而你也会在以色列中成为一个愚昧人！现在你去向王提说，他绝不会阻止我归你的。”</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 12:11; 以斯帖记 7:8; 士师记 20:5"> 但暗嫩不肯听她的话，因比她力大，就玷辱了她，与她同睡。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西结书 23:17"> 事后，暗嫩非常恨恶她，甚至对她的恨恶超过先前对她的爱。暗嫩对她说：“你起来走吧！”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 塔玛尔说：“不要这样！你赶我走这样的恶，比你刚才对我所做的更严重。”但暗嫩不肯听，</span>
<span className="v" id="v17" data-v="17"> 叫来侍候他的仆人，说：“把这女人从我这里赶出去，然后把门锁住！”</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 5:30; 创世记 37:3; 诗篇 45:13–14"> 当时塔玛尔身上穿着彩色的袍子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="彩色的袍子——依据七十士译本；或译作“长袖的袍子”。">a</a></sup>，因为未嫁的公主都穿这样的外袍。侍候暗嫩的仆人把她赶到外面去，随后锁住了门。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 7:6; 耶利米书 2:37; 撒母耳记下 1:11"> 塔玛尔把灰烬撒在头上，撕裂身上彩色的袍子<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="彩色的袍子——依据七十士译本；或译作“长袖的袍子”。">b</a></sup>，然后手抱着头离开，一边走一边哀号。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="罗马书 12:19; 创世记 46:15; 创世记 34:2"> 她的哥哥押沙龙问她：“你哥哥暗嫩亲近你了吗？妹妹，现在你要保持沉默，他是你的哥哥，你不要把这事放在心上。”于是塔玛尔凄凉地住在她哥哥押沙龙家里。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 34:7; 撒母耳记下 3:28–29; 撒母耳记上 2:29"> 大卫王听说了这一切事，非常恼火；<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="七十士译本以及有些古译本附“但由于暗嫩是他长子，又喜爱他，就不愿责备儿子”。">c</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="利未记 19:17–18; 创世记 31:24; 创世记 24:50"> 而押沙龙无论坏话好话都没有对暗嫩说。因为暗嫩玷辱了他妹妹塔玛尔，所以押沙龙恨他。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="创世记 38:12–13; 撒母耳记上 25:4; 历代志下 26:10"> 过了整整两年，在以法莲附近的巴力哈索，有人为押沙龙剪羊毛，押沙龙就邀请了所有的王子。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 11:8–15; 耶利米书 41:6–7; 诗篇 55:21"> 押沙龙来见王，说：“看哪，现在有人为仆人剪羊毛，请王和王的臣仆们与仆人同去。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 14:23; 士师记 19:7–10; 撒母耳记下 14:22"> 王对押沙龙说：“不，我儿，我们不必所有人都去，以免成为你的负担。”押沙龙再三地求王，但王不肯去，只是祝福了他。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 20:9; 撒母耳记下 3:27; 撒母耳记下 11:13–15"> 押沙龙就说：“王不去的话，请让我哥哥暗嫩与我们一起去。”<br />王问他：“为什么要他与你同去呢？”</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 26:24–26"> 押沙龙再三地求王，王就让暗嫩和所有的王子与他一起去了。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="士师记 19:6; 士师记 19:22; 士师记 19:9"> 押沙龙吩咐他的仆人们说：“你们要注意！当暗嫩喝酒畅快的时候，我对你们说：‘击杀暗嫩！’你们就把他杀了。不要害怕！这不是我吩咐你们的吗？你们要坚强，作英勇的人！”</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 18:9; 列王纪上 1:33; 列王纪下 1:9–12"> 押沙龙的仆人们就照他所吩咐的向暗嫩行了。王子们都起来，各人骑上骡子逃跑了。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 他们还在路上，消息就传到大卫那里，说：“押沙龙击杀了所有的王子，没有剩下一个。”</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 1:11; 撒母耳记下 12:16; 约伯记 1:20"> 王就起来，撕裂衣服，伏在地上，侍立的臣仆们也都撕裂衣服。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 16:9; 撒母耳记下 13:3; 创世记 27:41"> 大卫的哥哥示米亚的儿子约拿达就说：“我主不要以为他们把所有的年轻人——王子们都杀了，其实只有暗嫩一人死了。因为自从他玷辱了押沙龙的妹妹塔玛尔那天起，押沙龙就决意要杀他了。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 19:19"> 现在，我主我王不要把这事放在心上，以为王子们都死了，其实只有暗嫩一人死了。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="创世记 4:8–14; 箴言 28:17; 阿摩司书 5:19"> 押沙龙逃走了。守望的年轻人举目观看，看哪，有许多人从西边山旁的路上过来。</span>
<span className="v" id="v35" data-v="35"> 约拿达就对王说：“看哪，王子们回来了，正如你仆人所说的那样。”</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳记下 18:33; 撒母耳记下 12:21; 撒母耳记下 13:15"> 他刚说完，看哪，王子们就到了。他们放声大哭，王和他的所有臣仆也都号啕大哭。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="撒母耳记下 3:3; 撒母耳记下 14:32; 撒母耳记下 13:34"> 押沙龙逃走了，去了亚米忽的儿子基述王塔尔迈那里。大卫天天为他的儿子悲恸。</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳记下 15:8; 撒母耳记下 14:23; 撒母耳记下 14:32"> 押沙龙逃到基述，在那里三年。</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 24:67; 创世记 38:12; 创世记 37:35"> 这时，大卫王在暗嫩死的事上已经受了安慰，渴望去见押沙龙。</span>
</div>
</div>

</div>

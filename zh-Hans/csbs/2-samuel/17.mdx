<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="2SA" data-book-slug="2-samuel" data-book-name="撒母耳记下" data-chapter="17" data-verses="29">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 59:7–8; 诗篇 109:2–4; 诗篇 3:3–5"> 亚希多弗对押沙龙说：“请让我挑选一万两千人，今夜就动身追赶大卫。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 16:14; 列王纪上 22:31; 撒迦利亚书 13:7"> 我要趁他困倦手发软的时候追上他，让他恐慌，这样随同他的人都会逃跑。我只击杀王，</span>
<span className="v" id="v3" data-v="3" data-xref="帖撒罗尼迦前书 5:3; 以赛亚书 48:22; 以赛亚书 57:21"> 让所有人都归顺你，就像他们曾都归顺你所寻索的那人一样；所有人必平安无事。”</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 18:20–21; 罗马书 1:32; 历代志下 30:4"> 这建议在押沙龙和以色列所有长老眼中都看为好。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 15:32–37; 撒母耳记下 16:16–19"> 押沙龙说：“去把亚基人户筛也召来，我们也听听他怎么说。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 于是户筛来见押沙龙，押沙龙对他说：“亚希多弗提了这样的建议，我们可以照他的话行事吗？如果不可，你就提议吧！”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="箴言 31:8"> 户筛对押沙龙说：“亚希多弗这次提的建议不好。”</span>
<span className="v" id="v8" data-v="8" data-xref="何西阿书 13:8; 撒母耳记上 16:18; 希伯来书 11:32–34"> 户筛说：“你知道，你父亲和他的部下都是勇士，他们现在心里狂怒如野外失去幼仔的母熊；况且你父亲是个有经验的战士，不会与军兵在一起过夜。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 24:3; 撒母耳记上 14:14–15; 士师记 20:32–33"> 看哪，他现在或躲藏在一个坑中，或躲藏在某个地方。一旦他开始袭击我们的人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他开始袭击我们的人——或译作“军兵中开始有人倒毙”。">a</a></sup>，听见的就会说：‘跟从押沙龙的军兵遭到了杀戮！’</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 2:9–11; 出埃及记 15:15; 创世记 49:9"> 纵然有英勇的人，他的心如狮子心，也会彻底消融，因为全以色列都知道你父亲是个勇士，与他在一起的也都是英勇的人。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 22:17; 士师记 20:1; 诗篇 9:16"> 因此我建议，把以色列全军从但到比尔-谢巴都招聚到你这里，他们多如海边的沙；你亲自率领出战，</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 23:23; 俄巴底亚书 1:3; 列王纪上 20:10"> 不管他在哪里被发现，我们就过去，临到他如同露水落在地上。这样，他和所有随同的人，一个也不会存留。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 24:2; 弥迦书 1:6"> 如果他撤到城里，以色列全军就拿绳子围绕那城，把城拖到溪谷里去，使原处连一粒石子也找不到。”</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 15:34; 哥林多前书 1:19–20; 箴言 19:21"> 押沙龙和以色列众人都说：“亚基人户筛的建议比亚希多弗的建议好。”耶和华定意要破坏亚希多弗的好建议，好降灾祸给押沙龙。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 15:35–36"> 随后户筛对祭司撒督和亚比亚特说，亚希多弗为押沙龙和以色列的长老们是如此如此建议的，而他是如此如此建议的。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 15:28; 哥林多前书 15:54; 哥林多后书 5:4"> 他又说：“现在，你们要迅速派人去告诉大卫：今夜不要在旷野的渡口<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="渡口——或译作“荒原”。">b</a></sup>过夜，一定要过河，免得王和所有随同他的人都被吞灭。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 15:36; 约书亚记 18:16; 撒母耳记下 15:27"> 那时约拿单和亚希玛斯在恩罗格尔等候，有一个婢女去传话给他们，他们再去报信给大卫王，因为不能让人看见他们进城。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 3:16; 撒母耳记下 16:5; 撒母耳记下 19:16"> 不过，有一个年轻人看见了他们，报告了押沙龙。因此他们二人迅速离去，来到巴户琳一户人家。那人院子里有一口井，他们就下到井里。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 1:19; 约书亚记 2:4–24"> 那家的妇人拿了一块帘布铺在井口上，然后在上面摊了一些麦子，这事就没有被发现。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 1:19; 约书亚记 2:22–23; 撒母耳记上 19:12–17"> 押沙龙的仆人们来到那家，问那妇人：“亚希玛斯和约拿单在哪里？”<br />妇人回答：“他们已经过了河。”于是那些仆人去寻找，却没有找到，就回耶路撒冷去了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳记下 17:15–16"> 那些仆人走了之后，二人从井里上来，去向大卫王报信，对大卫说：“你要迅速起身过河，因为亚希多弗已经如此建议对付你们。”</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 10:16; 约翰福音 18:9; 箴言 27:12"> 于是大卫和所有跟随他的人起身过约旦河，早晨天亮之前没有剩下一个还没有过约旦河的。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 27:5; 列王纪下 20:1; 撒母耳记下 15:12"> 亚希多弗见自己的建议没有被采纳，就给驴子备上鞍，起身回本乡本家去。他安排好家里的事，然后上吊死了。他被葬在他父亲的坟墓里。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="创世记 32:2; 撒母耳记下 2:8; 约书亚记 13:26"> 大卫来到玛哈念，押沙龙和跟随他的以色列众人也过了约旦河。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志上 2:13; 撒母耳记下 19:13; 撒母耳记下 20:9–12"> 押沙龙立亚玛撒代替约押统管军队，亚玛撒是一个名叫耶特拉的以实玛利人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="以实玛利人——或译作“以色列人”。">c</a></sup>的儿子，耶特拉娶了娅比盖，娅比盖是纳哈什的女儿、洗鲁雅的姐妹，洗鲁雅是约押的母亲。</span>
<span className="v" id="v26" data-v="26" data-xref="约书亚记 17:1; 申命记 3:15; 民数记 32:1–42"> 以色列人和押沙龙在基列地扎营。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 2:7; 撒母耳记下 10:1–2; 撒母耳记下 9:4"> 大卫来到玛哈念的时候，拉巴的亚扪人纳哈什的儿子朔比，还有罗迪巴人亚米利的儿子玛吉，罗格琳的基列人巴尔兹莱，</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 25:18; 俄巴底亚书 1:3; 撒母耳记下 16:1–2"> 带来了寝具、钵、瓦器，还带来小麦、大麦、面粉、烤麦子、豆子、红豆、炒豆<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="炒豆——或译作“烤麦”。">d</a></sup>、</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 16:2; 以赛亚书 21:14; 撒母耳记下 16:14"> 蜂蜜、乳酪、羊肉<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="肉——辅助词语。">e</a></sup>和牛奶酪，供大卫和跟随他的人吃，因为他们说：“人们在旷野里一定又饥渴，又疲乏。”</span>
</div>
</div>

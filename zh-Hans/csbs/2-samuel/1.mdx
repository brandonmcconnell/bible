<span className="v" id="v3" data-v="3" data-xref="约伯记 1:15–19; 列王纪下 5:25"> 大卫问他：“你从哪里来？”<br />他回答大卫：“我从以色列的营地逃了出来。”</span>

<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 4:16; 撒母耳记上 31:1–6; 历代志上 10:1–6"> 大卫又问：“情况怎么样？请告诉我！”<br />他回答：“军兵从战场上逃跑，军兵当中有很多人倒下阵亡，扫罗和他的儿子约拿单也死了。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="箴言 25:2; 箴言 14:15"> 大卫就问向他报信的年轻人：“你怎么知道扫罗和他儿子约拿单死了呢？”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 28:4; 撒母耳记下 1:21; 历代志上 10:4–6"> 那报信的年轻人回答：“我正巧来到基利波山上，看哪，扫罗靠在他的长矛上，战车和骑兵正向他逼近。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 22:12; 撒母耳记下 9:6; 士师记 9:54"> 他回头看见我，就呼唤我。我说：‘我在这里！’</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 30:17; 撒母耳记上 30:13; 撒母耳记上 30:1"> 他问我：‘你是谁？’我回答他：‘我是亚玛力人。’</span>
<span className="v" id="v9" data-v="9"> 他就对我说：‘请到我身边来，把我杀了，死亡的痛苦抓住我，但我性命还在。’</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 7:2; 士师记 9:54; 列王纪下 11:12"> 我就到他身边，把他杀了，因为我知道他倒下后必不能活了。这样我取下他头上的冠冕和胳膊上的臂环，带到我主这里来。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 13:31; 创世记 37:29; 撒母耳记下 3:31"> 大卫就抓着自己的衣服，把衣服撕裂，所有与他在一起的人也都这样。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 24:17; 诗篇 35:13–14; 马太福音 5:44"> 他们为扫罗和他儿子约拿单、为耶和华的子民和以色列家哀恸、哭泣、禁食，直到傍晚，因为他们倒在刀下。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 1:8"> 大卫问那报信的年轻人：“你是哪里的人？”<br />他回答：“我是一个寄居者的儿子，是亚玛力人。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 26:9; 撒母耳记上 31:4; 彼得后书 2:10"> 大卫对他说：“你伸手杀害耶和华的受膏者，怎么没有畏惧呢？”</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 2:34; 士师记 8:20; 撒母耳记下 4:10–12"> 于是大卫叫来一个仆人，说：“你过去把他杀了！”那仆人击杀他，他就死了。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 27:25; 路加福音 19:22; 利未记 20:9"> 大卫对他说：“你的血债归在你自己头上！因为你亲口指证自己说‘我杀了耶和华的受膏者。’”</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="历代志下 35:25; 撒母耳记下 1:19; 创世记 50:11"> 大卫为扫罗和他儿子约拿单作了以下这首哀歌，</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 10:13; 创世记 49:8; 申命记 4:10"> 并吩咐要教犹大子孙这首《弓之歌》，这首歌被记在《雅煞尔书》<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="《雅煞尔书》——或译作“《正直人之书》”；是古以色列的诗歌集，已失传。">a</a></sup>上：</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 1:27; 撒母耳记下 1:25; 申命记 4:7–8"> <span className="pl pl-1">以色列啊，你的尊荣者在你的高处被杀</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="你的尊荣者在你的高处被杀——或译作“羚羊在你的高处被杀”。">b</a></sup><br /><span className="pl pl-1">！</span><br /><span className="pl pl-1">勇士竟然倒下！</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="弥迦书 1:10; 撒母耳记上 18:6; 士师记 11:34"> <span className="pl pl-1">不要在迦特报信，</span><br /><span className="pl pl-1">不要在阿实基伦的街上传扬，</span><br /><span className="pl pl-1">免得非利士女子欢喜，</span><br /><span className="pl pl-1">免得未受割礼之人的女子们欢跃。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 31:1; 以赛亚书 21:5; 撒母耳记上 10:1"> <span className="pl pl-1">基利波的众山哪，</span><br /><span className="pl pl-1">愿你们那里没有露水、没有雨水，</span><br /><span className="pl pl-1">田地也没有出产作供物，</span><br /><span className="pl pl-1">因为勇士的盾牌在那里被玷污，</span><br /><span className="pl pl-1">扫罗的盾牌不再抹油。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 18:4; 以赛亚书 34:6–7; 撒母耳记上 14:6–14"> <span className="pl pl-1">约拿单的弓不缩回，</span><br /><span className="pl pl-1">扫罗的刀也不空回，</span><br /><span className="pl pl-1">除非沾了被杀之人的血，</span><br /><span className="pl pl-1">沾了勇士的脂油。</span><br /></span>

<span className="v" id="v24" data-v="24" data-xref="彼得前书 3:3–5; 耶利米书 2:32; 士师记 5:30"> <span className="pl pl-1">以色列女子啊，要为扫罗哀哭，</span><br /><span className="pl pl-1">是他使你们穿上朱红的美衣，</span><br /><span className="pl pl-1">使你们的衣袍佩上黄金的妆饰。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 1:19; 撒母耳记下 1:27; 士师记 5:18"> <span className="pl pl-1">勇士竟然在战场上仆倒！</span><br /><span className="pl pl-1">约拿单在你的高处被杀！</span><br /></span>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="1KI" data-book-slug="1-kings" data-book-name="列王纪上" data-chapter="13" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 12:32–33; 列王纪下 23:17; 帖撒罗尼迦前书 4:15"> 看哪，有一个神人奉耶和华的命令从犹大来到伯特利，那时耶罗波安正站在祭坛旁烧香。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 36:1; 列王纪下 23:15–18; 列王纪下 22:1–2"> 神人奉耶和华的命令对着祭坛呼唤，说：“祭坛哪，祭坛哪，耶和华如此说：看哪，大卫家将生一个儿子，名叫约西亚，他必把那些向你烧香的高坛祭司祭献在你上面，也必有人的骸骨焚烧在你上面。”</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 1:22; 出埃及记 4:3–5; 士师记 6:17"> 当天，神人又给了一个预兆，说：“这是耶和华所宣告的预兆：看哪，这祭坛必破裂，祭坛上的灰烬必倾洒出来。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="启示录 11:5; 历代志下 18:25–27; 路加福音 6:10"> 耶罗波安王一听见神人对伯特利的祭坛所呼喊的话，就从祭坛上伸出手下令：“捉住他！”王伸出的手却枯干了，不能收回去。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 13:3; 耶利米书 28:16–17; 申命记 18:22"> 祭坛破裂了，祭坛上的灰烬也倾洒出来，正如神人奉耶和华的命令所给的预兆。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 9:28; 使徒行传 8:24; 出埃及记 10:17"> 于是王回应神人说：“请恳求你神耶和华的恩宠，为我祷告，使我的手可以收回。”神人恳求耶和华的恩宠，王的手就收回，像原先一样了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王纪下 5:15; 撒母耳记上 9:7–8; 士师记 13:15"> 王对神人说：“请跟我一起回宫，你可以恢复精力，我也要送你一件礼物。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="民数记 24:13; 民数记 22:18; 马可福音 6:23"> 但神人对王说：“就算你把你宫殿的一半赐给我，我也不跟你一起回去，不在这地方吃饭喝水。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 13:17; 申命记 13:13–18; 罗马书 16:17"> 因为有耶和华的话语如此吩咐我说：‘你不可吃饭，不可喝水，也不可从你原路返回。’”</span>
<span className="v" id="v10" data-v="10"> 于是神人从另外一条路走了，没有从他来伯特利的原路返回。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪下 23:18; 列王纪上 13:20–21; 民数记 24:2"> 有一个老先知住在伯特利，他的儿子们回来，把神人当天在伯特利所做的一切事都讲述给他。神人对王所说的那些话，他们也给父亲讲述了。</span>
<span className="v" id="v12" data-v="12"> 父亲问他们：“他从哪一条路回去的？”儿子们都看到了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="都看到了——有古抄本作“就指明了”。">a</a></sup>那位从犹大来的神人回去的路。</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 10:4; 撒母耳记下 19:26; 士师记 5:10"> 父亲就对儿子们说：“给驴子备好鞍。”他们为父亲备好驴、上好鞍，他骑上去</span>
<span className="v" id="v14" data-v="14" data-xref="腓立比书 4:12–13; 哥林多后书 11:27; 哥林多前书 4:11–12"> 追赶神人，发现他正坐在一棵橡树底下，就问他：“你是从犹大来的神人吗？”<br />他回答：“我是。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 老先知对神人说：“请跟我一起回家吃个饭吧。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪上 13:8–9; 马太福音 16:23; 民数记 22:19"> 神人说：“我不能跟你一起回去，与你前往，也不能在这地方与你一起吃饭喝水。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 20:35; 帖撒罗尼迦前书 4:15; 列王纪上 13:1"> 因为有耶和华的话语吩咐我：‘你不可在那里吃饭，不可在那里喝水，也不可从你原路回去。’”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰一书 4:1; 马太福音 7:15; 民数记 22:35"> 老先知对他说：“我与你一样，也是先知。有一位天使奉耶和华的命令对我说：‘你把他带回家来，请他吃饭喝水。’”老先知是在哄骗他。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 13:1; 创世记 3:6; 使徒行传 4:19"> 于是神人跟着老先知一起回去，在他家里吃饭喝水。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马太福音 7:22; 民数记 24:4; 民数记 24:16–24"> 他们正坐席的时候，耶和华的话语临到了那带神人回来的先知。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 13:17; 撒母耳记上 13:13–14; 撒母耳记上 4:18"> 他就对那从犹大来的神人宣告说：“耶和华如此说：因为你违背了耶和华的话，不遵守你的神耶和华所吩咐你的命令，</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 14:18–20; 列王纪上 14:13; 耶利米书 22:18–19"> 反而回来，在耶和华吩咐你不可吃饭、不可喝水的地方吃饭喝水，因此你的尸体必不得葬入你祖先的坟墓。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 吃喝之后，老先知为那个请回来的先知备好驴、上好鞍，</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 20:36; 列王纪下 2:24; 箴言 26:13"> 他就走了。在路上有一只狮子遇见他，把他咬死了，尸体抛在路上，驴子站在尸体旁边，狮子也站在尸体旁边。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王纪上 13:11"> 看哪，人们路过，看见尸体抛在路上，狮子站在尸体旁边，就去老先知所住的城里报告这件事。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 9:6; 箴言 11:31; 诗篇 119:120"> 那将神人从路上请回来的老先知听到了，就说：“这是那违背耶和华命令的神人。耶和华把他交给狮子，狮子撕裂他，把他咬死了，正如耶和华对他所宣告的话。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 于是他吩咐儿子们，说：“给驴子备好鞍。”他们就为父亲备好驴，上好鞍。</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪上 17:6; 诗篇 148:7–8; 但以理书 6:22–24"> 老先知前去，看见神人的尸体抛在路上，驴子和狮子站在尸体旁边，狮子却没有吃那尸体，也没有伤害那头驴子。</span>
<span className="v" id="v29" data-v="29"> 老先知就抬起神人的尸体，驮在驴子上带回去。老先知回到城里，为他哀哭，把他安葬了。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 22:18; 使徒行传 8:2; 列王纪上 14:13"> 他把神人的尸体安放在自己的坟墓里，人们为他哀悼说：“唉，我的兄弟啊！”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪下 23:17–18; 民数记 23:10; 路加福音 16:22–23"> 老先知把他安葬之后，吩咐儿子们说：“当我死了，你们要把我葬在神人被安葬的坟墓里，要把我的骸骨放在他的骸骨旁边。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 16:24; 列王纪上 13:2; 列王纪上 12:31"> 他奉耶和华的命令，针对伯特利的祭坛和撒玛利亚各城的一切高坛庙宇所宣告的话，必定成就。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="历代志下 11:15; 历代志下 13:9; 民数记 17:12–13"> 这事以后，耶罗波安不但不转离他邪恶的道路，反而继续设立各类的人为高坛的祭司。凡是愿意的，他就让那人承接神职，成为高坛的祭司。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 14:10; 列王纪上 15:29–30; 列王纪上 12:30"> 这事成了耶罗波安家的罪孽，以致他的家从地面上被剪除灭尽。</span>
</div>
</div>

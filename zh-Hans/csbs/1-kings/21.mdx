<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 6:33; 历代志下 28:22; 约书亚记 19:18"> 这些事以后，又发生了一件事。耶斯列人拿伯有一个葡萄园，位于耶斯列，靠近撒玛利亚王亚哈的宫殿。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 8:14; 雅各书 1:14–15; 提摩太前书 6:9"> 亚哈告诉拿伯说：“请把你的葡萄园给我，作我的菜园，因为它靠近我的宫殿。我可以给你一个更好的葡萄园作交换，或者如果你眼中看为好，我也可以按葡萄园的售价付给你银子。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="民数记 36:7; 利未记 25:23; 以西结书 46:18"> 拿伯对亚哈说：“耶和华绝不允许我把祖先的继业让给你。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪上 20:43; 雅各书 1:14; 约拿书 4:9"> 亚哈因为耶斯列人拿伯回复他说“我不能把祖先的继业让给你”，就闷闷不乐地回到王宫，躺在床上，转过脸去，也不吃饭。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪上 16:31; 创世记 3:6; 列王纪上 19:2"> 王后耶洗别来见他，问他说：“你为什么心里这样忧闷，甚至不吃饭呢？”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以斯帖记 5:9–14; 雅各书 4:2–7; 提摩太前书 6:9–10"> 亚哈回答：“因为我与耶斯列人拿伯商量，对他说：‘把你的葡萄园按银价卖给我吧，或者如果你愿意，我可以给你另一个葡萄园作交换’；他却说：‘我不能把我的葡萄园让给你。’”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 8:14; 弥迦书 7:3; 撒母耳记下 13:4"> 王后耶洗别对他说：“你不是现在执掌着以色列的王权吗？起来吃饭，开心点吧。我来为你拿到耶斯列人拿伯的葡萄园。”</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米记 6:5; 列王纪下 10:11; 以斯拉记 4:7–8"> 于是王后用亚哈的名义写信，盖上王的印章，然后送达那些与拿伯同城居住的长老和贵族。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 58:4; 马太福音 23:13; 路加福音 20:47"> 她在书信里写着说：<br />“你们要宣告禁食，让拿伯坐在民众的首席上；</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 22:28; 使徒行传 6:11; 利未记 24:15–16"> 安排两个卑劣之徒坐在他对面，作见证控告他说：‘你诅咒了神和王’。然后你们把他拉出去，用石头砸死。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 4:19; 利未记 19:15; 列王纪下 10:6–7"> 于是城里的人——那些与拿伯同城居住的长老和贵族，就照着耶洗别吩咐他们的去做，照着送来的书信中所写的，</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 58:4; 列王纪上 21:8–10"> 宣告禁食，让拿伯坐在民众的首席上。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 9:26; 申命记 22:24; 传道书 10:20"> 接着来了两个人，是卑劣之徒，坐在拿伯对面。两个卑劣之徒当着民众的面作见证控告拿伯说：“拿伯诅咒了神和王。”人们就把拿伯拉出城外，用石头把他砸死了。</span>
<span className="v" id="v14" data-v="14" data-xref="传道书 8:14; 撒母耳记下 11:14–24; 传道书 5:8"> 随后，他们派人去告诉耶洗别：“拿伯已经被石头砸死了。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="箴言 1:10–16; 箴言 4:17; 列王纪上 21:7"> 当耶洗别听说拿伯被石头砸死了，她就对亚哈说：“起来去获得耶斯列人拿伯不肯出价卖给你的葡萄园吧，因为拿伯不在了，已经死了。”</span>
<span className="v" id="v16" data-v="16" data-xref="俄巴底亚书 1:12–14; 罗马书 1:32; 撒母耳记下 11:25–27"> 亚哈一听说拿伯死了，就起来下到耶斯列人拿伯的葡萄园，去占有这园子。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="诗篇 9:12; 以赛亚书 26:21; 列王纪下 5:26"> 于是，耶和华的话语临到提斯比人以利亚，说：</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 13:32; 历代志下 22:9"> “你起来，下去迎见以色列王亚哈，他在撒玛利亚，看哪，就在拿伯的葡萄园里，他下去要占有那地方。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 22:38; 撒母耳记下 12:9; 哈巴谷书 2:9"> 你要对亚哈说：‘耶和华如此说：你既杀人又占有抢夺吗？’要对他说：‘耶和华如此说：狗在什么地方舔拿伯的血，也必在那地方舔你的血；是的，就是你！’”</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="列王纪下 17:17; 罗马书 7:14; 列王纪上 21:25"> 亚哈对以利亚说：“我的仇敌啊，你竟然找到了我！”<br />以利亚回答：“找到了！因为你卖掉了自己，去做耶和华眼中看为恶的事。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 14:10; 撒母耳记上 25:34; 列王纪下 10:1–7"> 耶和华说<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="耶和华说——辅助词语。">a</a></sup>：<br /><span className="pl pl-1">‘看哪，我必使祸患临到你，除灭你的后代。</span><br /><span className="pl pl-1">以色列中凡属亚哈的男丁</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="男丁——原文直译“对着墙撒尿的”。">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">无论是为奴的还是自由的，</span><br /><span className="pl pl-1">我都必剪除。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 16:3; 列王纪上 14:16; 列王纪上 16:11"> <span className="pl pl-1">我要使你的家像尼八之子耶罗波安的家，</span><br /><span className="pl pl-1">又像亚希雅的儿子巴沙的家那样，</span><br /><span className="pl pl-1">因为你惹怒我，并且使以色列犯罪。’</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="列王纪下 9:10; 列王纪下 9:30–37; 列王纪上 21:25"> 耶和华还论到耶洗别说：<br /><span className="pl pl-1">‘狗必在耶斯列地界内</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="地界内——依据一些古抄本；参《列王纪下》9:10,36；马索拉文本作“城垣边”。">c</a></sup><br /><span className="pl pl-1">吃掉耶洗别。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 16:4; 列王纪上 14:11; 耶利米书 15:3"> <span className="pl pl-1">属于亚哈的人，</span><br /><span className="pl pl-1">死在城里的将被狗吃掉，</span><br /><span className="pl pl-1">死在田野的将被天空的飞鸟吃掉。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="箴言 22:14; 列王纪上 21:20; 列王纪上 16:30–33"> 实在是没有像亚哈这样的，卖掉自己，受他妻子耶洗别的怂恿，去做耶和华眼中看为恶的事。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 21:11; 创世记 15:16; 利未记 18:25–30"> 他效法从前在以色列子民面前被耶和华赶出的亚摩利人所做的一切，做极为可憎的事，去追随偶像。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="列王纪下 6:30; 创世记 37:34; 撒母耳记下 3:31"> 亚哈听了这些话，就撕裂衣服，贴身穿着麻衣，禁食，睡卧在麻布上，行走时也很消沉。</span>
<span className="v" id="v28" data-v="28"> 于是，耶和华的话语临到提斯比人以利亚，说：</span>
<span className="v" id="v29" data-v="29" data-xref="彼得后书 3:9; 弥迦书 7:18; 诗篇 86:15"> “你看见了吗，亚哈在我面前谦卑下来了。既然他在我面前谦卑下来，我必不在他的日子里使这祸患临到他；不过他儿子在世的日子，我要使这祸患临到他的家。”</span>
</div>
</div>

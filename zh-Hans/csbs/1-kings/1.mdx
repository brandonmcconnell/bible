<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 23:1–2; 历代志上 29:27–28; 历代志上 23:1"> 大卫王老了，上了年纪，人们给他盖上厚毯子，他还是不能暖和。</span>
<span className="v" id="v2" data-v="2" data-xref="传道书 4:11; 创世记 16:5; 弥迦书 7:5"> 臣仆们对他说：“请让人为我主我王寻找一个年轻处女，她可以在王面前侍候，照顾王，睡在王的怀中，使我主我王暖和。”</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 19:18; 以斯帖记 2:4; 以斯帖记 2:2"> 于是他们在以色列全境寻找美丽年轻的女子，找到了书念女子娅比莎，把她带到王那里。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 1:25"> 这女子极其美丽，她照顾王，侍候他，但王却没有与她行房。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 15:1; 撒母耳记下 3:4; 申命记 17:15–16"> 那时，哈及的儿子亚多尼雅高抬自己说：“我要作王。”他就为自己配备战车和马兵，还有五十人在他前面奔跑开道。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 3:3–4; 撒母耳记上 3:13; 希伯来书 12:5–6"> 他的父亲从来没有责问他说：“你为什么这样做？”他的身材也非常健美，他是在押沙龙之后出生的。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 20:25; 列王纪上 2:22; 撒母耳记上 22:20–23"> 亚多尼雅与洗鲁雅的儿子约押、祭司亚比亚特一同商议，他们就辅助亚多尼雅。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 4:18; 撒母耳记下 23:8–39; 撒母耳记下 20:25"> 但祭司撒督、耶赫亚达的儿子比纳雅、先知拿单、示每、列伊和大卫的勇士们，没有附从亚多尼雅。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 17:17; 撒母耳记下 13:23–27; 撒母耳记下 15:11–12"> 于是，亚多尼雅在恩罗格尔附近，琐希列的磐石那里，祭献牛羊和肥畜。他邀请了他所有的兄弟——王子们，以及所有作王臣仆的犹大人，</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 12:24; 列王纪上 1:19; 撒母耳记下 12:1–15"> 但没有邀请先知拿单、比纳雅、勇士们和他的兄弟所罗门。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 3:4; 撒母耳记下 7:12–17; 撒母耳记下 12:24–25"> 拿单对所罗门的母亲芭示巴说：“你没有听说吗，哈及的儿子亚多尼雅作王了，而我们的主大卫还不知道。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 11:14; 使徒行传 27:31; 创世记 19:17"> 现在，请让我给你提个建议，保全你的性命和你儿子所罗门的性命。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 1:30; 列王纪上 1:17; 诗篇 132:11–12"> 你到大卫王那里去，对他说：‘我主我王啊，你不是曾经向你的女仆起誓说“你儿子所罗门将接续我作王，他将坐在我的宝座上”吗？现在为什么亚多尼雅却作了王呢？’</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 13:1; 列王纪上 1:17–27"> 看哪，你还在那里与王说话的时候，我会随后进去，证实你的话。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王纪上 1:1"> 于是芭示巴来到内室见王。王已经很老了，书念女子娅比莎正在侍候王。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 25:23; 撒母耳记上 24:8; 撒母耳记上 20:41"> 芭示巴向王俯身下拜，王问：“你有什么事呢？”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王纪上 1:13; 列王纪上 1:30; 彼得前书 3:6"> 她回答王：“我主啊，你曾指着你的神耶和华向女仆起誓说：‘你儿子所罗门将接续我作王，他将坐在我的宝座上。’</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 1:24; 列王纪上 1:11; 使徒行传 3:17"> 现在看哪，亚多尼雅却作了王，而我主我王现在还不知道。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 1:25; 列王纪上 1:7–10"> 他祭献了大量的牛羊和肥畜，还邀请了众王子、祭司亚比亚特和元帅约押，却没有邀请你的仆人所罗门。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志上 29:1; 诗篇 123:2; 历代志上 22:8–10"> 现在，我主我王啊，全以色列都瞩目在你身上，盼着你告诉他们，谁才会接续你坐在我主我王的宝座上。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 2:10; 申命记 31:16; 创世记 15:15"> 否则，当我主我王与列祖长眠之后，我和我儿子所罗门就要成为罪人了！”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约伯记 1:16–18; 创世记 24:15; 但以理书 9:20"> 看哪，芭示巴还在与王说话的时候，先知拿单进来了。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 1:16; 彼得前书 2:17; 罗马书 13:7"> 有人禀告王说：“看哪，先知拿单来了。”拿单就来到王面前，脸伏于地向王下拜。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王纪上 1:17–18; 列王纪上 1:5; 列王纪上 1:13–14"> 拿单说：“我主我王啊，你是否说过‘亚多尼雅将接续我作王，他将坐在我的宝座上’？</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 10:24; 列王纪上 1:19; 列王纪上 1:9"> 要知道，亚多尼雅今天下去祭献了大量的牛羊和肥畜，还邀请了众王子、将领们和祭司亚比亚特。看哪，他们在亚多尼雅面前吃喝，说：‘亚多尼雅王万岁！’</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 1:8; 列王纪上 1:10; 撒母耳记下 7:2"> 他却没有邀请你仆人我，并祭司撒督、耶赫亚达的儿子比纳雅以及你的仆人所罗门。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 15:15; 列王纪上 1:24; 列王纪下 4:27"> 这件事是否出于我主我王呢？王并没有告诉仆人，谁将接续我主我王坐在你的宝座上啊。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 大卫王就回应说：“叫芭示巴到我这里来。”于是芭示巴进来，站在王面前。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 4:9; 诗篇 136:24; 撒母耳记上 14:45"> 王起誓说：“我指着那救赎我性命脱离一切患难的耶和华的永生起誓：</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 1:13; 列王纪上 1:17"> 我从前怎样指着以色列的神耶和华向你起誓说：‘你的儿子所罗门将接续我作王，他将接替我坐在我的宝座上’，我今天必如此实行。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="但以理书 2:4; 但以理书 5:10; 但以理书 3:9"> 于是芭示巴脸伏于地，向王下拜，说：“愿我主大卫王万岁！”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="列王纪上 1:8; 列王纪上 1:38; 列王纪上 1:26"> 大卫王又说：“把祭司撒督、先知拿单和耶赫亚达的儿子比纳雅召来见我。”他们就来到王面前。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志下 32:30; 列王纪上 1:38; 历代志下 33:14"> 王吩咐他们：“带上你们主人的众仆人，让我儿子所罗门骑上我的骡子，送他下到基训去。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 1:25; 撒母耳记下 15:10; 撒母耳记上 10:1"> 在那里让祭司撒督和先知拿单膏立他为以色列的王。你们要吹响号角，说：‘所罗门王万岁！’</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 1:17; 诗篇 72:1–2; 列王纪上 1:13"> 然后你们跟随他上来，让他坐在我的宝座上。他要接替我作王，我已经指定他作以色列和犹大的领袖。”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="耶利米书 28:6; 哥林多前书 14:16; 诗篇 72:19"> 耶赫亚达的儿子比纳雅回应王说：“阿们！愿我主我王的神耶和华也如此说。</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳记上 20:13; 列王纪上 1:47; 约书亚记 1:17"> 耶和华怎样与我主我王同在，愿他也照样与所罗门同在，使他的王位比我主大卫王的王位更尊大。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="撒母耳记下 8:18; 列王纪上 1:8; 列王纪上 1:33"> 于是祭司撒督、先知拿单和耶赫亚达的儿子比纳雅，以及基利提人和比利提人都下去，让所罗门骑上大卫王的骡子，送他到基训去。</span>
<span className="v" id="v39" data-v="39" data-xref="诗篇 89:20; 列王纪上 1:34; 历代志上 29:22"> 祭司撒督取出帐幕里盛膏油的犄角，膏抹了所罗门。他们就吹响号角，全体民众都说：“所罗门王万岁！”</span>
<span className="v" id="v40" data-v="40" data-xref="列王纪下 11:14; 撒迦利亚书 9:9; 列王纪下 11:20"> 全体民众都跟随他上来，民众吹着横笛，极其欢喜快乐，似乎大地都因他们的声音震裂。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="约伯记 15:21–22; 路加福音 17:26–29; 使徒行传 21:31"> 亚多尼雅和所有与他在一起的客人刚结束吃喝，听到了这声音。约押听到号角声，就说：“城中为什么有喧闹的声音呢？”</span>
<span className="v" id="v42" data-v="42" data-xref="撒母耳记下 15:36; 撒母耳记下 17:17; 撒母耳记下 18:27"> 他还在说话，看哪，祭司亚比亚特的儿子约拿单来了。亚多尼雅说：“进来吧！你是个忠义的人，一定是来报好消息的。”</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43"> 约拿单回答亚多尼雅说：“不好了！我们的主大卫王已经立所罗门为王了。</span>
<span className="v" id="v44" data-v="44"> 王派遣祭司撒督、先知拿单和耶赫亚达的儿子比纳雅，以及基利提人和比利提人，与所罗门同去，他们让他骑上了王的骡子。</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪上 1:40; 但以理书 5:26–28; 撒母耳记上 4:5"> 祭司撒督和先知拿单在基训膏立他为王，人们欢喜地从那里上来，全城都轰动了。这就是你们所听见的声音。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="历代志上 29:23; 诗篇 132:11; 列王纪上 1:13"> “不但所罗门坐上了王位，</span>
<span className="v" id="v47" data-v="47" data-xref="创世记 47:31; 列王纪上 1:37; 以斯拉记 6:10"> 而且王的臣仆们也去为我们的主大卫王祝福说：‘愿你的神使所罗门的名比你的名更美，使他的王位比你的王位更尊大。’王就在床上敬拜，</span>
<span className="v" id="v48" data-v="48" data-xref="列王纪上 3:6; 诗篇 132:11–12; 诗篇 145:2"> 然后这样说：‘以色列的神耶和华是当受颂赞的！因为他今天设立一人坐上我的宝座，让我亲眼看到了。’”</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="以赛亚书 21:4–5; 箴言 28:1; 但以理书 5:4–6"> 于是亚多尼雅的所有客人都战战兢兢起身，各自上路散去了。</span>
<span className="v" id="v50" data-v="50" data-xref="列王纪上 2:28; 出埃及记 21:14; 出埃及记 27:2"> 亚多尼雅惧怕所罗门，就动身，前去抓住祭坛的犄角。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51"> 有人禀告所罗门说：“看哪，亚多尼雅惧怕所罗门王。你看，他抓住了祭坛的犄角说：‘请所罗门王今天向我起誓，绝不用刀处死他的仆人。’”</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="撒母耳记上 14:45; 撒母耳记下 14:11; 箴言 13:6"> 所罗门说：“如果他是个忠义的人，他连一根头发也不会掉在地上；但如果在他身上发现了恶行，他就必死。”</span>
<span className="v" id="v53" data-v="53" data-xref="列王纪上 1:16; 撒母耳记下 14:24; 撒母耳记下 1:2"> 于是所罗门王派人去把亚多尼雅从祭坛上带下来。他前来向所罗门王下拜，所罗门对他说：“你回家去吧。”</span>
</div>
</div>

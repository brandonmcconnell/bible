<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="1KI" data-book-slug="1-kings" data-book-name="列王纪上" data-chapter="10" data-verses="29">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 12:42; 路加福音 11:31; 历代志下 9:1–12"> 示巴女王听说了所罗门因耶和华的名而得的名声，就来要用一些难题试验所罗门。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 25:23; 诗篇 4:4; 约伯记 4:2"> 她带着大队随从，并有骆驼驮着香料、极多的金子以及宝石，来到耶路撒冷。她来到所罗门那里，与所罗门谈论自己心中的一切问题。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 1:5–6; 马太福音 13:11; 列王纪上 10:1"> 所罗门解答了她的一切问题，没有一个问题对于王是深奥无解的。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 12:42; 列王纪上 3:28; 历代志下 9:3–4"> 示巴女王看到所罗门的一切智慧，还有他建造的宫殿，</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 26:16; 列王纪上 4:22–23; 列王纪下 16:18"> 他筵席上的食物，他臣仆们的座次，他侍从的服务和服装，他的司酒官，以及他在耶和华殿中所献的燔祭，示巴女王心里就深深震撼了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="心里就深深震撼了——原文直译“喘不过气来”或“里面不再有气息了”。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="历代志下 9:5–6"> 她对王说：“有关你的事迹和你的智慧，我在本国听说的那些消息都是真实的！</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 2:9; 约翰福音 20:25–29; 约翰一书 3:2"> 我本来不相信那些话，直到我来之后亲眼看到了，看哪，他们连一半都没有告诉我，你的智慧和福份远超我所听到的传闻。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 8:34; 箴言 10:21; 路加福音 11:31"> 你的臣民多么有福啊！这些常侍立在你面前、聆听你智慧的臣仆，是多么有福啊！</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 72:2; 列王纪上 5:7; 撒母耳记下 8:15"> 耶和华你的神是当受颂赞的！他喜悦你，使你坐以色列的王位。因耶和华永远爱以色列，所以他立你为王，来实行公正和公义。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="列王纪上 10:2; 马太福音 2:11; 列王纪上 9:14"> 示巴女王送给所罗门王一百二十他连得<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一百二十他连得——相当于4.1公吨。1他连得=34.2公斤。">b</a></sup>金子、极多的香料以及宝石，示巴女王送给所罗门王的香料如此之多，再也没有这样运来过。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪上 9:27–28; 历代志下 8:18; 诗篇 45:9"> 希兰的船队从俄斐运来黄金，此外还从俄斐运来了极多的檀香木和宝石。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 25:1–31; 诗篇 150:3–5; 启示录 14:2–3"> 王用这些檀香木为耶和华的殿和王宫做了护拦，为歌手制作竖琴和里拉琴；这样的檀香木至今没有运来过，也没有人看见过。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="诗篇 37:4; 马太福音 15:28; 诗篇 20:4"> 除了王慷慨回赠示巴女王的东西，所罗门王还赠送她所想所求的一切。随后，女王和她的臣仆返回本国去了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志下 9:13–28; 列王纪上 9:28"> 每年带到所罗门那里的金子，重六百六十六他连得<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="六百六十六他连得——相当于22.8公吨。1他连得=34.2公斤。">c</a></sup>；</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 72:10; 历代志上 9:24; 以赛亚书 21:13"> 此外还有来自商贩和客商，以及阿拉伯诸王和地方省长们的进献。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪上 14:26–28; 历代志下 12:9–10; 历代志下 9:15–16"> 所罗门王制作了两百个锤揲的金盾牌，每个盾牌用六百谢克尔<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="六百谢克尔——相当于6.8公斤。1谢克尔=11.4公克。">d</a></sup>金子；</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 7:2; 列王纪上 14:26"> 又制作了三百个锤揲的小金盾牌，每个盾牌用三弥纳<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="三弥纳——相当于1.7公斤。1弥纳=570公克。">e</a></sup>金子。王就把这些都放在黎巴嫩林宫里。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="诗篇 45:8; 列王纪上 10:22; 启示录 20:11"> 王制作了一个很大的象牙宝座，镀上纯金。</span>
<span className="v" id="v19" data-v="19"> 宝座有六级台阶，宝座的后背有一个圆顶，座位的左边右边都有扶手，有两只狮子站在扶手两边。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 24:9; 创世记 49:9; 民数记 23:24"> 在六级台阶上，共有十二只狮子分站左右。在列国中，没有制作过这样的宝座。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王纪上 10:17; 列王纪上 7:2; 历代志下 9:20–22"> 所罗门王的一切饮酒器皿都是金的，黎巴嫩林宫的一切器皿都是纯金的，没有银的，银子在所罗门年间算不了什么。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 22:48; 创世记 10:4; 历代志下 20:36–37"> 因为王有一支塔尔施船队与希兰的船队一同出海，这塔尔施船队每三年回来一次，装载着金银、象牙、猿猴和孔雀。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪上 3:12–13; 歌罗西书 2:2–3; 列王纪上 4:29–34"> 所罗门王在财富和智慧上超过地上所有的君王。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 3:12; 雅各书 1:5; 列王纪上 3:28"> 世上的众王<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="世上的众王——原文直译“全地”；参《历代志下》9:23。">f</a></sup>都想要见所罗门的面，聆听神赐予他心中的智慧。</span>
<span className="v" id="v25" data-v="25" data-xref="约伯记 42:11; 诗篇 72:10; 诗篇 72:15"> 他们各自带来贡物，有银器、金器、衣裳、兵器、香料、马匹和骡子，年年都是如此。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="历代志下 9:25; 列王纪上 4:26; 申命记 17:16"> 所罗门屯集战车和马兵，有一千四百辆战车、一万两千马兵，都安置在屯车城，以及王所在的耶路撒冷。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 1:15–17; 申命记 17:17; 历代志下 9:27"> 王使银子在耶路撒冷多如石头，使香柏木像丘陵的西克莫无花果树那样多。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 17:16; 历代志下 9:28; 以赛亚书 31:1–3"> 所罗门的马匹是埃及和库威出口的，由王的商人按照市价从库威买来。</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 1:4; 列王纪下 7:6–7; 玛拉基书 1:1"> 他们从埃及进口的战车每辆六百谢克尔<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="六百谢克尔——相当于6.8公斤。1谢克尔=11.4公克。">g</a></sup>银子，马每匹一百五十谢克尔<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="一百五十谢克尔——相当于1.7公斤。">h</a></sup>；这些也经由他们出口到赫提人诸王以及亚兰众王那里。</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 9:10; 历代志下 8:1; 传道书 2:4–5"> 此后，所罗门建造自己的王宫，用十三年完成了他全部的殿宇。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 10:17; 历代志下 9:16; 列王纪上 10:21"> 他建造黎巴嫩林宫，长一百肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一百肘——相当于45.7公尺。1肘=45.7公分。">a</a></sup>，宽五十肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="五十肘——相当于22.8公尺；下同。">b</a></sup>，高三十肘<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="三十肘——相当于13.7公尺；下同。">c</a></sup>。有四排香柏木立柱，柱子上有香柏木横梁。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 6:5"> 还有四十五根立柱——每排十五根——支撑着檩条，上面铺上香柏木板。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 40:22; 以西结书 40:16; 列王纪上 6:4"> 有三排格子窗，面面相对，有三层。</span>
<span className="v" id="v5" data-v="5"> 所有的门和门框都是方形的，还有窗户，三层面面相对。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 7:12; 以西结书 41:25–26"> 他建造了一个圆柱大厅，长五十肘，宽三十肘，前面有一个门廊，门廊前有柱子和廊檐。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 20:8; 诗篇 122:5; 以赛亚书 9:7"> 他建造有宝座的大厅，就是“审判大厅”，要在那里施行审判；大厅从地面到顶部都铺上香柏木板。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 8:11; 列王纪上 3:1; 列王纪上 9:24"> 大厅后面的另一个院子是他自己住的宫殿，构造像这大厅一样。所罗门迎娶法老的女儿并为她建造的宫殿，也像这大厅一样。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王纪上 7:10–11; 列王纪上 5:17"> 从根基到墙顶、从外围到大院，这一切所用的都是贵重的石材，是按尺寸凿成的料石，用锯内外平整切割。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 21:19–20; 哥林多前书 3:10–11; 以赛亚书 54:11"> 根基是贵重的石材、巨大的块石，有长十肘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="十肘——相当于4.6公尺。1肘=45.7公分。">d</a></sup>的块石，有长八肘<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="八肘——相当于3.7公尺。">e</a></sup>的块石；</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 2:20–22; 彼得前书 2:5"> 其上也有按尺寸凿成的贵重石材以及香柏木材。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 6:36; 列王纪上 7:6; 约翰福音 10:23"> 大院四围有三层凿好的料石，以及一层香柏木梁。耶和华殿的内院和殿宇门廊也是一样。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志下 4:11; 历代志下 2:13–14; 列王纪上 7:40"> 所罗门王派人从提尔把户兰请来。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 2:14; 历代志下 4:16; 出埃及记 31:2–6"> 他是拿弗他利支派中一个寡妇的儿子，父亲是提尔人，是个铜匠。他满有才能、聪慧和知识，会制作各样铜器。他来到所罗门王那里，做他一切的工作。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米书 52:21; 历代志下 3:15–17; 列王纪上 7:21"> 户兰铸造了两根铜柱，一根柱子高十八肘<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="十八肘——相当于8.2公尺。1肘=45.7公分。">f</a></sup>，周长<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="周长——原文直译“绳子绕一圈”。">g</a></sup>十二肘<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="十二肘——相当于5.5公尺。">h</a></sup>，另一根柱子也一样。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 38:19; 历代志下 4:12–13; 出埃及记 38:17"> 他做了两个柱头，装在柱子的顶上，是用铜铸成的；一个柱头高五肘<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="五肘——相当于2.3公尺；下同。">i</a></sup>，另一个柱头也高五肘。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 28:14; 出埃及记 28:24–25; 出埃及记 28:22"> 柱子顶上的柱头有网格状、链条交织的缨络，第一个柱头上有七条，第二个柱头上也有七条。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 28:14; 出埃及记 39:15–18; 出埃及记 28:22"> 他做的柱子，每一个网格上环绕着两行石榴，用来装饰柱子顶上的柱头，另一个柱头也这样做。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 7:22; 列王纪上 6:32–35; 列王纪上 6:18"> 门廊里柱子顶上的柱头有百合花雕饰，高四肘<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="四肘——相当于1.8公尺。">j</a></sup>。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 3:16; 历代志下 4:13; 耶利米书 52:22–23"> 两根柱子的柱头上，挨着网格的鼓肚边上，还有两百个石榴分行环绕着两个柱头。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志下 3:17; 列王纪上 6:3; 列王纪上 7:12"> 他把两根柱子竖立在正殿的门廊前：右边竖立一根，起名为雅斤；左边竖立一根，起名为波阿斯。</span>
<span className="v" id="v22" data-v="22"> 在柱子顶上，有百合花雕饰。这样，柱子的工作就完成了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="历代志下 4:2; 列王纪下 25:13; 耶利米书 52:17"> 他铸造了一个铜海，直径<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="直径——原文直译“从口沿到口沿”。">k</a></sup>十肘<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="十肘——相当于4.6公尺。1肘=45.7公分。">l</a></sup>，是圆形的，高五肘<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="五肘——相当于2.3公尺。">m</a></sup>，周长<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="周长——原文直译“绳子绕一圈”。">n</a></sup>三十肘<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="三十肘——相当于13.7公尺。">o</a></sup>。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 6:18; 历代志下 4:3; 出埃及记 37:17–22"> 铜海口沿的下方有匏瓜的图形，围绕在铜海周围，每肘十个，环绕在铜海周围；匏瓜图形有两行，是与铜海一体铸造的。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 52:20; 历代志下 4:4–5; 马太福音 28:19"> 铜海安装在十二头铜牛上面，三头朝北，三头朝西，三头朝南，三头朝东。铜海在牛背上，牛尾全都向内。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志下 4:5; 列王纪上 7:38; 列王纪上 6:18"> 铜海厚一掌<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="一掌——相当于7.4公分。">p</a></sup>，口沿如杯沿的工艺，像绽开的百合花，它的容量为两千罢特<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="两千罢特——相当于44,000公升。1罢特=22公升。">q</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="历代志下 4:14; 列王纪下 25:13; 耶利米书 52:17"> 他做了十个铜底座，每个底座长四肘<sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="四肘——相当于1.8公尺；下同。1肘=45.7公分。">r</a></sup>，宽四肘，高三肘<sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="三肘——相当于1.4公尺。">s</a></sup>。</span>
<span className="v" id="v28" data-v="28"> 底座的构造是这样：它们都有镶板，镶板在支架中间。</span>
<span className="v" id="v29" data-v="29" data-xref="何西阿书 5:14; 以西结书 10:14; 出埃及记 37:7"> 支架之间的镶板上有狮子、牛和基路伯的浮雕，各支架上面有盆座；狮子和牛的下面有花环浮雕。</span>
<span className="v" id="v30" data-v="30" data-xref="以西结书 10:10–13; 以西结书 3:13; 以西结书 1:15–21"> 每个底座有四个铜轮子和铜轴。盆下面的四角有支架，各支架的边上都有铸造的花环。</span>
<span className="v" id="v31" data-v="31"> 盆座的口是在顶部的内面，高一肘<sup className="fn"><a href="#fn-t" id="fnref-t" data-fn="一肘——相当于45.7公分。">t</a></sup>；口是圆形的。盆座的构造直径一肘半<sup className="fn"><a href="#fn-u" id="fnref-u" data-fn="一肘半——相当于68.6公分；下同。">u</a></sup>，口上也有雕刻，镶板是方形的，不是圆的。</span>
<span className="v" id="v32" data-v="32"> 四个轮子在镶板下方，轮子的轴连接在底座下，每个轮子直径一肘半。</span>
<span className="v" id="v33" data-v="33" data-xref="以西结书 1:18; 以西结书 1:16"> 轮子的工艺如同战车轮子的工艺，轮轴、轮圈、轮辐、轮毂都是铸造的。</span>
<span className="v" id="v34" data-v="34"> 每一个底座有四个支架，在四个角上；支架与底座是一体的。</span>
<span className="v" id="v35" data-v="35"> 底座顶部有半肘<sup className="fn"><a href="#fn-v" id="fnref-v" data-fn="半肘——相当于22.8公分。">v</a></sup>高的圆形支架，底座上面的支架和镶板与盆座是一体的。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 7:29; 列王纪上 6:29; 以西结书 41:18–20"> 支架和镶板的表面上雕刻着基路伯、狮子和棕榈树，四围各个空白的地方有花环浮雕。</span>
<span className="v" id="v37" data-v="37"> 他这样做了十个底座，铸模全都一样，尺寸一样，形状一样。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="出埃及记 40:11–12; 撒迦利亚书 13:1; 约翰一书 1:7"> 他做了十个铜盆，每个盆可容纳四十罢特<sup className="fn"><a href="#fn-w" id="fnref-w" data-fn="四十罢特——相当于880公升。1罢特=22公升。">w</a></sup>，每个盆直径四肘<sup className="fn"><a href="#fn-x" id="fnref-x" data-fn="四肘——相当于1.8公尺。1肘=45.7公分。">x</a></sup>。盆放在十个底座上，每个底座上一个。</span>
<span className="v" id="v39" data-v="39" data-xref="历代志下 4:10; 历代志下 4:6"> 五个底座放在殿宇的右侧，五个底座放在殿宇的左侧；铜海放在殿宇的右侧，在东南角。</span>
<span className="v" id="v40" data-v="40" data-xref="历代志下 4:11–16; 出埃及记 24:6; 出埃及记 39:32–43"> 户兰还做了盆、铲子和碗。 所有铜器<br />这样，户兰完成了他为所罗门王在耶和华殿中做的各样工程，</span>
<span className="v" id="v41" data-v="41" data-xref="列王纪上 7:15–22; 历代志下 4:12"> 包括：两根柱子，两根柱子顶上盆状的柱头，以及两个用来装饰柱子顶上盆状柱头的网格，</span>
<span className="v" id="v42" data-v="42" data-xref="列王纪上 7:20"> 还有两个网格上的四百个石榴，每个网格上有两行石榴，用来装饰各柱子上面盆状的柱头。</span>
<span className="v" id="v43" data-v="43"> 还有十个底座和底座上的十个盆，</span>
<span className="v" id="v44" data-v="44" data-xref="列王纪上 7:23; 列王纪上 7:25"> 一个铜海和铜海底下的十二头牛，</span>
<span className="v" id="v45" data-v="45" data-xref="出埃及记 27:3; 出埃及记 38:3; 历代志下 4:16"> 锅、铲子、碗。户兰为所罗门王给耶和华殿制作的这一切器皿，都是用磨亮的铜制作的。</span>
<span className="v" id="v46" data-v="46" data-xref="约书亚记 3:16; 历代志下 4:17; 创世记 33:17"> 王在约旦平原、疏割和撒拉坦之间的土模场铸造了这些。</span>
<span className="v" id="v47" data-v="47" data-xref="历代志上 22:14; 历代志上 22:3; 历代志下 4:18"> 所罗门没有称量这一切器物，因为数量极多，铜的重量无法计算。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="出埃及记 37:10–16; 历代志下 4:8; 出埃及记 39:36"> 所罗门制作了耶和华殿中的一切器物：金祭坛和摆放陈设饼的金桌；</span>
<span className="v" id="v49" data-v="49" data-xref="历代志下 4:7; 历代志下 4:20; 撒迦利亚书 4:11–14"> 内殿前面的纯金灯台，右边五个，左边五个；金制的花朵、灯盏、灯剪；</span>
<span className="v" id="v50" data-v="50" data-xref="出埃及记 25:29; 历代志下 4:21–22; 出埃及记 27:3"> 纯金的钵、蜡剪、碗、勺子、香炉；内殿至圣所的门和殿宇正殿的门，铰链<sup className="fn"><a href="#fn-y" id="fnref-y" data-fn="铰链——或译作“表层”。">y</a></sup>都是金的。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="历代志下 5:1; 撒母耳记下 8:7–11; 历代志上 28:11–18"> 所罗门王为耶和华殿所做的一切工作都完成了，所罗门就把他父亲大卫分别为圣献出的金银和器皿都拿来，放在耶和华殿的库房里。</span>
</div>
</div>

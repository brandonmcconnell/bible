<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="1KI" data-book-slug="1-kings" data-book-name="列王纪上" data-chapter="15" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 14:31; 历代志下 13:1–22"> 尼八之子耶罗波安王在位第十八年，亚比雅姆作犹大的王，</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 13:2; 历代志下 11:20–22; 列王纪上 15:13"> 在耶路撒冷统治了三年。他的母亲名叫玛迦，是押沙龙的外孙女<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="押沙龙的外孙女——或译作“押沙龙之女”。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="列王纪上 11:4; 诗篇 119:80; 列王纪上 3:14"> 亚比雅姆随从他父亲先前所行的一切罪恶，他的心没有像他先祖大卫的心那样完全忠于耶和华他的神。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 11:36; 历代志下 21:7; 以赛亚书 37:35"> 然而他的神耶和华为大卫的缘故，给大卫在耶路撒冷留下一盏灯，兴起他的后裔接续他，坚立耶路撒冷。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 14:8; 撒母耳记下 11:15–17; 列王纪上 15:3"> 这是因为大卫除了赫提人乌利亚那件事以外，一生的日子都做耶和华眼中看为正的事，没有偏离耶和华所吩咐的一切。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王纪上 14:30"> 罗波安一生中和耶罗波安之间一直有争战。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 13:2–22; 列王纪上 14:29"> 亚比雅姆其余的事迹和他所做的一切，不是都记在《犹大诸王年代志》上吗？亚比雅姆和耶罗波安之间常有战争。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 14:1; 列王纪上 14:31; 马太福音 1:7–8"> 亚比雅姆与他的列祖长眠，人们把他葬在大卫城；他的儿子亚撒接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 以色列王耶罗波安在位第二十年，亚撒作犹大的王，</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 15:2; 列王纪上 15:13; 历代志下 13:2"> 在耶路撒冷统治了四十一年。他的祖母名叫玛迦，是押沙龙的外孙女<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="押沙龙的外孙女——或译作“押沙龙之女”。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="历代志下 14:2; 历代志下 15:17; 列王纪上 15:3"> 亚撒像他的先祖大卫那样，做耶和华眼中看为正的事。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 22:46; 列王纪上 14:23–24; 历代志下 14:2–5"> 他从国中除去那些男庙妓，又除掉他祖先造的所有偶像。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 32:20; 申命记 7:5; 撒迦利亚书 13:3"> 他还废除了他祖母玛迦的太后之位，因为她制作了淫秽的亚舍拉柱。亚撒把那淫秽的神柱砍掉，并在汲沦溪谷焚烧了。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 22:43; 列王纪上 8:61; 列王纪上 15:3"> 虽然那些高坛还没有除掉，但亚撒一生的日子完全对耶和华忠心。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 7:51; 历代志下 14:13; 历代志下 15:18"> 亚撒把他父亲和他自己分别为圣的金银和器皿，都带到了耶和华的殿。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪上 15:32; 列王纪上 14:30; 历代志下 16:1–6"> 亚撒和以色列王巴沙之间一直有争战。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 12:27; 历代志下 16:1–6; 约书亚记 18:25"> 以色列王巴沙上来攻击犹大，修筑了拉玛，不让人与犹大王亚撒往来。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 14:26; 列王纪下 12:18; 列王纪上 11:23–24"> 于是亚撒把耶和华殿的库房和王宫的库房剩下的所有金银都取出来，交在臣仆手中，然后亚撒王派遣他们去见住在大马士革的亚兰王——希旬的孙子、塔伯利门的儿子本哈达，说：</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 1:31; 历代志下 16:7; 罗马书 3:8"> “你我之间立约吧，就像我父亲与你父亲之间那样。看哪，我把金银送给你为礼物，请你废除你与以色列王巴沙所立的约，好让他从我这里撤离。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王纪下 15:29; 士师记 18:29; 约书亚记 11:2"> 本哈达听取了亚撒王，就派遣他的将领们去攻击以色列的城镇，攻占了伊永、但、亚贝勒-伯玛迦，革尼勒全域以及拿弗他利全地。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 14:17; 列王纪上 16:15–18; 历代志下 16:5"> 巴沙听说了，就停止修筑拉玛，滞留在提尔撒。</span>
<span className="v" id="v22" data-v="22" data-xref="约书亚记 21:17; 约书亚记 18:24; 约书亚记 18:26"> 于是亚撒王通告全体犹大人，无人能免，将巴沙用于修筑拉玛的石头和木材运走。亚撒王用这些来修筑便雅悯的迦巴和米斯巴。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="历代志下 16:11–14; 列王纪上 14:29–31; 列王纪上 15:7–8"> 亚撒其余的一切事迹，他的所有武力、所成就的一切，以及他所建造的城镇，不是都记在《犹大诸王年代志》上吗？只是他年老的时候，双脚患了病。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 1:8; 列王纪上 22:41–43; 历代志下 17:1–9"> 亚撒与他的列祖长眠，葬在先祖大卫的城，与他的列祖在一起；他的儿子约沙法接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王纪上 14:20; 列王纪上 14:12"> 犹大王亚撒在位第二年，耶罗波安的儿子纳达布作了以色列的王，统治以色列两年。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 14:16; 列王纪上 15:34; 列王纪上 15:30"> 纳达布做耶和华眼中看为恶的事，走他父亲的道路，效法他父亲使以色列所犯的罪。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约书亚记 19:44; 约书亚记 21:23; 列王纪上 14:14"> 以萨迦家族亚希雅的儿子巴沙密谋反叛纳达布。巴沙在非利士人的基比顿击杀了他，那时纳达布和全体以色列人正在围攻基比顿。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 32:35"> 犹大王亚撒在位第三年，巴沙杀了纳达布，接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王纪上 14:9–16; 列王纪下 19:25; 列王纪下 10:10–11"> 巴沙一作王，就把耶罗波安的全家都击杀了。他没有留下耶罗波安家任何有气息的，全都除灭了，正如耶和华藉着他仆人示罗人亚希雅所宣告的话。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 15:26; 列王纪上 14:22; 列王纪上 14:9–16"> 这是因耶罗波安所犯的罪，以及他使以色列所犯的罪，惹怒了耶和华以色列的神。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪上 14:19; 列王纪上 16:20; 列王纪上 16:14"> 纳达布其余的事迹和他所做的一切，不是都记在《以色列诸王年代志》上吗？</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 15:16"> 亚撒和以色列王巴沙之间一直有争战。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="列王纪上 16:8"> 犹大王亚撒在位第三年，亚希雅的儿子巴沙在提尔撒作全以色列的王，统治了二十四年。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 15:26; 列王纪上 14:16; 列王纪上 12:28–29"> 他做耶和华眼中看为恶的事，走耶罗波安的道路，效法耶罗波安使以色列所犯的罪。</span>
</div>
</div>

<span className="v" id="v1" data-v="1" data-xref="历代志下 5:2–10; 历代志上 15:25; 撒母耳记下 6:12–17"> 那时，所罗门把以色列的长老、各支派的首领、以色列子孙各父系的首领，都招聚到耶路撒冷所罗门王那里，要把耶和华的约柜从大卫城锡安抬上来。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 23:34; 历代志下 7:8–10; 撒迦利亚书 14:16–19"> 于是以色列众人在以塔宁月，就是在七月的节期时，都聚集到所罗门王那里。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命记 31:9; 约书亚记 3:6; 民数记 4:15"> 以色列所有的长老来到后，祭司们就抬起约柜，</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 3:4; 历代志下 1:3; 出埃及记 40:2–33"> 把耶和华的约柜和会幕以及其中一切神圣的器具都抬上来；祭司和利未人把它们抬上来了。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 6:13; 历代志上 16:1; 列王纪上 8:62–63"> 所罗门王与会合到他那里的全体以色列会众，在约柜前一起祭献牛羊，多得无法数清、不可胜数。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 6:19; 撒母耳记下 6:17; 列王纪上 6:27"> 然后祭司们把耶和华的约柜抬进来，放在预备好的地方，在内殿至圣所两个基路伯的翅膀底下。</span>
<span className="v" id="v7" data-v="7"> 基路伯在约柜的位置之上展开翅膀，这样基路伯从上方遮掩约柜和约柜的杠子。</span>

<span className="v" id="v9" data-v="9" data-xref="出埃及记 25:21; 希伯来书 9:4; 出埃及记 40:20"> 约柜里只有那两块石版，没有别的；那是以色列子孙出埃及地之后，耶和华与他们立约时，摩西在何烈山放进去的。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及记 40:34–35; 历代志下 7:1–2"> 祭司们从圣所出来的时候，云雾充满了耶和华的殿，</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 43:4–5; 以西结书 44:4; 哥林多后书 3:18"> 以致祭司们因那云雾的缘故不能事奉供职，因为耶和华的荣耀充满了耶和华的殿。</span>
</div>

<span className="v" id="v12" data-v="12" data-xref="诗篇 97:2; 历代志下 6:1–11; 利未记 16:2"> 那时所罗门说：<br /><span className="pl pl-1">“耶和华曾说要居于幽暗之中，</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 7:13; 诗篇 132:13–14; 希伯来书 9:24"> <span className="pl pl-1">我竟然为你建造了一座宏伟的殿宇，</span><br /><span className="pl pl-1">作为你永远的居所。”</span></span>

<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="历代志下 7:1; 历代志下 6:12–13; 路加福音 22:45"> 所罗门在耶和华的祭坛前双膝跪下，向天伸开双手，在耶和华面前做完这一切祷告和恳求，就起来了。</span>
<span className="v" id="v55" data-v="55" data-xref="列王纪上 8:14; 撒母耳记下 6:18; 民数记 6:23–26"> 他站着，大声祝福以色列全体会众，说：</span>
<span className="v" id="v56" data-v="56" data-xref="约书亚记 23:14–15; 约书亚记 21:44–45; 路加福音 21:33"> “耶和华是当受颂赞的！他照着他所应许的一切，赐予他的子民以色列安息；凡藉着他仆人摩西所应许的一切福份，一句也没有落空。</span>

<span className="v" id="v59" data-v="59" data-xref="诗篇 141:2; 约翰福音 17:9; 约翰福音 17:20–24"> 愿我在耶和华面前所恳求的这些话，昼夜上达耶和华我们的神，使他照着每天的事务听取他仆人的申诉，听取他子民以色列的申诉，</span>
<span className="v" id="v60" data-v="60" data-xref="申命记 4:35; 耶利米书 10:10–12; 列王纪上 18:39"> 好让地上的万民都知道：唯独耶和华是神，没有另一位。</span>

<div className="bp">
<span className="v" id="v62" data-v="62" data-xref="撒母耳记下 6:17–19; 以斯拉记 6:16–17; 历代志下 7:4–10"> 王和全体以色列人一起在耶和华面前献祭。</span>
<span className="v" id="v63" data-v="63" data-xref="以斯拉记 6:16–17; 历代志下 15:11; 尼希米记 12:27"> 所罗门献上祭物，就是向耶和华献上的平安祭，有两万两千头牛、十二万只羊。这样，王和所有的以色列子民为耶和华的殿举行了奉献礼。</span>

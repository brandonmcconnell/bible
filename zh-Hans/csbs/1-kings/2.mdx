<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 47:29; 申命记 31:14; 提摩太前书 1:18"> 大卫死的日子临近了，他嘱咐他的儿子所罗门说：</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 1:6–7; 约书亚记 23:14; 以弗所书 6:10"> “我就要走世人都必走的路了；你要坚强，要作大丈夫。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 29:9; 申命记 17:18–20; 箴言 3:1–4"> 你要遵守你的神耶和华的吩咐，照着摩西律法上所记的，遵行他的道，谨守他的律例、诫命、规定和法度，好使你无论做什么，无论转向哪里，都会通达。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 20:3; 撒母耳记下 7:25; 列王纪上 8:25"> 这样，耶和华必成就他所论到我的话说：你的子孙如果谨守自己的道路，全心、全灵诚实地行走在我面前，你的子孙中就不会断绝人坐以色列的王位。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 3:27; 撒母耳记下 20:10; 撒母耳记下 18:5"> “此外，你也知道洗鲁雅的儿子约押对我所做的事，就是他对以色列的两个元帅——尼珥的儿子押尼珥和耶特尔的儿子亚玛撒所做的：他在和平时期杀人流血，像在战争时期一样<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他在和平时期杀人流血，像在战争时期一样——原文直译“他杀了他们，在和平时期流了战争的血”。">a</a></sup>，使战争的血染透了他的腰带和脚上的鞋。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 2:9; 以赛亚书 57:21; 诗篇 37:37"> 所以你要凭智慧行事，不要让他白头安然地下阴间。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 17:27–29; 撒母耳记下 9:7; 撒母耳记下 19:31–40"> “你要向基列人巴尔兹莱的儿子们施慈爱，把他们列在你筵席上吃饭的人当中，因为我逃避你哥哥押沙龙的时候，他们也如此接待了我。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 16:5–8; 列王纪上 2:36–46; 撒母耳记下 19:16–23"> “看哪，你这里还有巴户琳的便雅悯人基拉的儿子示每：他在我去玛哈念那天，用严厉的恶言咒骂我。但后来他下到约旦河来迎接我的时候，我指着耶和华向他起誓说：‘我绝不动刀杀你。’</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 2:6; 创世记 42:38; 创世记 44:31"> 现在你不要让他免于罪罚，你是有智慧的人，一定知道怎样对待他，要让他白头见血下阴间。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 2:29; 使徒行传 13:36; 列王纪上 1:21"> 此后大卫与他列祖长眠，葬在大卫城。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 5:4–5; 历代志上 29:26–27"> 大卫统治以色列的日子有四十年：在希伯仑统治七年，在耶路撒冷统治三十三年。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 1:1; 历代志上 29:23–25; 诗篇 132:12"> 所罗门坐上了他父亲大卫的宝座，他的王权极其稳固。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 16:4–5; 列王纪上 1:5–10; 路加福音 10:5–6"> 哈及的儿子亚多尼雅去见所罗门的母亲芭示巴，芭示巴问：“你是带着平安来的吗？”<br />他回答：“平安。”</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 14:12; 路加福音 7:40"> 他接着说：“我有事要对你说。”<br />芭示巴说：“请说。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="历代志上 22:9–10; 历代志上 28:5–7; 列王纪上 1:25"> 他说：“你知道这王国本来是归属我的，全以色列也期望我作王，但王国却转归了我弟弟，因为这是出于耶和华。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 30:7; 诗篇 132:10"> 现在我请求你一件事，请你不要回绝我。”<br />芭示巴对他说：“你说吧。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 12:8; 列王纪上 1:2–4; 撒母耳记下 3:7"> 亚多尼雅就说：“求你向所罗门王提说，让他把书念女子娅比莎赐给我为妻；他一定不会回绝你的。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="箴言 14:15"> 芭示巴说：“好，我可以为你向王提说。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="诗篇 45:9; 列王纪上 15:13; 利未记 19:32"> 于是芭示巴去见所罗门王，为亚多尼雅向王提说。王起身迎接她，向她下拜，然后坐回宝座上，又给母后摆设一个座位，她就在王的右边坐下。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马太福音 7:7–11; 马太福音 11:24; 约翰福音 2:3–4"> 芭示巴说：“我要向你提出一个小小的请求，请你不要回绝我。”<br />王对她说：“请说吧，母亲，我不会回绝你。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王纪上 1:3; 撒母耳记下 16:21–22"> 芭示巴说：“请你把书念女子娅比莎赐给你的哥哥亚多尼雅为妻。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="历代志上 3:2; 历代志上 3:5; 马太福音 20:22"> 所罗门王回答他母亲说：“你为什么替亚多尼雅求书念女子娅比莎呢？既然他是比我年长的哥哥，你也为他——以及祭司亚比亚特和洗鲁雅的儿子约押——求这王国吧。”</span>
<span className="v" id="v23" data-v="23" data-xref="路得记 1:17; 诗篇 140:9; 诗篇 64:8"> 于是所罗门王指着耶和华起誓说：“亚多尼雅提出这请求，如果他不赔上自己的性命，就愿神处置我，重重地处置我！</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 22:10; 历代志上 17:10; 历代志上 17:17"> 耶和华坚立了我，使我坐上我父亲大卫的宝座，照着他所应许的为我建立家室，现在我指着耶和华的永生起誓：亚多尼雅今天必被处死！”</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 8:18; 列王纪上 2:46; 士师记 8:20–21"> 然后，所罗门王派耶赫亚达的儿子比纳雅去击杀亚多尼雅，他就死了。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="约书亚记 21:18; 撒母耳记上 22:20–23; 耶利米书 1:1"> 王对祭司亚比亚特说：“回亚纳图你自己的田地去吧。你本来是该死的人，但我今天不杀你，因为你从前在我父亲大卫面前抬主耶和华的约柜，并且与我父亲同受他的一切苦难。”</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 2:27–36; 撒母耳记上 3:12–14; 耶利米书 7:12–14"> 这样，所罗门驱逐了亚比亚特，不让他作耶和华的祭司，应验了耶和华在示罗所说有关以利家的话。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王纪上 1:50; 列王纪上 1:7; 撒母耳记下 18:2"> 这消息传到了约押那里；约押虽然没有附从押沙龙，却附从了亚多尼雅。约押就逃到耶和华的帐幕那里，抓住祭坛的犄角。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王纪上 2:25; 出埃及记 21:14; 列王纪上 2:46"> 有人禀告所罗门王：“约押逃到耶和华的帐幕那里了，看哪，就在祭坛旁边。”所罗门就派耶赫亚达的儿子比纳雅，说：“去把他杀了！”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 比纳雅进入耶和华的帐幕，对约押说：“王如此吩咐：你出来！”<br />约押回应：“不，我要死在这里。”<br />比纳雅就去回禀王说：“约押如此说，如此回答我。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="申命记 21:8–9; 民数记 35:33; 出埃及记 21:14"> 王对比纳雅说：“你就照着他的话去做吧，把他杀掉，埋葬了，这样就从我和我父家除去了约押无故杀人流血的罪。</span>
<span className="v" id="v32" data-v="32" data-xref="士师记 9:24; 士师记 9:57; 诗篇 7:16"> 耶和华必使约押的血债归到他自己头上，因为他在我父亲大卫不知道的情况下，杀害两个比他公义良善的人，用刀杀了尼珥之子以色列的元帅押尼珥和耶特尔之子犹大的元帅亚玛撒。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 27:25; 列王纪上 2:32; 路加福音 2:14"> 这血债必永远归到约押头上，以及他后裔的头上；至于大卫和他的后裔，他的家和王位，愿耶和华赐予平安，直到永远。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马太福音 3:1; 约书亚记 15:61; 列王纪上 2:25"> 于是耶赫亚达的儿子比纳雅上去击杀约押，把他处死了，葬在旷野他的家<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="家——或译作“墓穴”。">b</a></sup>。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 2:27; 历代志上 24:3; 历代志上 29:22"> 此后，王立耶赫亚达的儿子比纳雅替代约押统管军队，王又立祭司撒督替代亚比亚特。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="撒母耳记下 16:5–9; 列王纪上 2:8–9; 箴言 20:26"> 王派人召来示每，对他说：“你要在耶路撒冷为自己建造房屋，住在这里，不可离开去任何地方。</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳记下 1:16; 撒母耳记下 15:23; 约书亚记 2:19"> 当你离开，越过汲沦溪谷那天，你要确切知道：你必定死，你的血债将归到你自己头上。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="列王纪上 20:4; 列王纪下 20:19"> 示每回答王：“这话甚好，我主我王怎么说，你仆人就怎么做。”于是示每在耶路撒冷住了许多日子。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="撒母耳记上 21:10; 撒母耳记上 27:2–3"> 过了三年，示每的两个奴仆逃到了玛迦的儿子迦特王亚吉那里。有人告诉示每说：“看哪，你的奴仆在迦特。”</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 12:15; 箴言 15:27; 提摩太前书 6:10"> 示每就动身，给驴子备好鞍，往迦特到亚吉那里去寻找他的奴仆。示每去把他们从迦特带回来了。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41"> 有人禀告所罗门：示每离开耶路撒冷去了迦特，又回来了。</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 15:4; 列王纪上 2:36–38; 路加福音 15:22"> 王就派人把示每召来，对他说：“我不是让你指着耶和华起誓，并且警诫过你吗？我说：‘当你离开去任何地方那天，你要确切知道：你必定死。’你也回答我：‘这话甚好，我会听从。’</span>
<span className="v" id="v43" data-v="43" data-xref="罗马书 13:5; 历代志下 30:12; 传道书 8:2"> 现在，你为什么不遵守你向耶和华所起的誓，以及我吩咐你的命令呢？”</span>
<span className="v" id="v44" data-v="44" data-xref="撒母耳记下 16:5–13; 诗篇 7:16; 以西结书 17:19"> 王又对示每说：“你知道你对我父亲大卫所做的一切恶事，你心里很清楚。现在耶和华把你的罪恶报应在你头上了。</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 25:5; 列王纪上 2:24; 以赛亚书 9:6–7"> 所罗门王却必蒙福，大卫的宝座也必在耶和华面前坚立，直到永远。”</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="历代志下 1:1; 列王纪上 2:12; 列王纪上 2:45"> 于是王吩咐耶赫亚达的儿子比纳雅，他出去击杀示每，示每就死了。这样，王国在所罗门手中得以稳固。</span>
</div>
</div>

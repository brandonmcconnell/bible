<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="历代志下 20:34; 历代志下 19:2; 列王纪上 16:7"> 耶和华的话语临到哈纳尼的儿子耶户，论到巴沙说：</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 15:34; 列王纪上 14:7; 撒母耳记上 2:8"> “我从尘土中提拔了你，立你作我子民以色列的领袖，你却走耶罗波安的道路，使我的子民以色列犯罪，以他们的罪恶惹怒我。既然如此，</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 14:10; 列王纪上 15:29–30; 以赛亚书 66:24"> 看哪，我必除灭巴沙和他的家，我要使你的家像尼八之子耶罗波安的家那样。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 14:11; 列王纪上 21:24"> <span className="pl pl-1">属于巴沙的人，</span><br /><span className="pl pl-1">死在城里的将被狗吃掉，</span><br /><span className="pl pl-1">死在田野的将被天空的飞鸟吃掉。”</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪上 14:19; 列王纪上 15:31; 历代志下 16:1–6"> 巴沙其余的事迹和他所做的，以及他的武力，不是都记在《以色列诸王年代志》上吗？</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 14:17; 列王纪上 15:21; 列王纪上 16:13–14"> 巴沙与他的列祖长眠，葬在提尔撒；他的儿子以拉接替他作王。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 14:14; 何西阿书 1:4; 诗篇 115:4"> 还有耶和华的话语藉着哈纳尼的儿子先知耶户临到巴沙和他的家，是因他做了一切耶和华眼中看为恶的事，像耶罗波安的家那样以他手所造的惹怒了耶和华，又因他击杀了耶罗波安的全家。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 犹大王亚撒在位第二十六年，巴沙的儿子以拉在提尔撒作以色列的王，统治了两年。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王纪上 18:3; 创世记 39:4; 但以理书 5:1–4"> 他的臣仆泽姆利，这位掌管一半战车队的将领密谋反叛了他。当时他在提尔撒，在提尔撒宫廷的总管阿尔扎家中喝醉了。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 9:31"> 泽姆利进去攻击他，把他杀了。这样犹大王亚撒在位第二十七年，泽姆利接替以拉作王。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 25:22; 列王纪上 16:3; 列王纪上 15:29"> 他一作王登上王位，就把巴沙的全家都击杀了，连他的亲属朋友，一个男丁<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="男丁——原文直译“对着墙撒尿的”。">a</a></sup>也没有留下。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 16:1; 列王纪上 16:7; 历代志下 10:15"> 泽姆利除灭了巴沙的全家，正如耶和华藉着先知耶户对巴沙所宣告的话。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 32:21; 列王纪上 15:30; 以赛亚书 41:29"> 这是因为巴沙和他儿子以拉所犯的一切罪，他们使以色列犯罪，以他们的假神惹怒了耶和华以色列的神。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 以拉其余的事迹和他所做的一切，不是都记在《以色列诸王年代志》上吗？</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王纪上 15:27; 约书亚记 19:44; 约伯记 20:5"> 犹大王亚撒在位第二十七年，泽姆利在提尔撒作王七天。当时军兵正扎营攻击非利士的基比顿。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 22:2; 列王纪下 8:26; 弥迦书 6:16"> 正在扎营的军兵听说泽姆利密谋击杀了王，于是以色列全军就在那天，在营地中立元帅欧姆利为以色列王。</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 9:50; 路加福音 19:43–44; 列王纪下 18:9–12"> 欧姆利和跟随他的以色列全军从基比顿上来，围攻提尔撒。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 17:23; 撒母耳记上 31:4–5; 约伯记 2:9–10"> 泽姆利看见城被攻取，就进入了王宫的城堡，放火烧毁王宫，自焚而死。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 15:26; 列王纪上 14:16; 列王纪上 12:28"> 这是因他所犯的罪恶，他做耶和华眼中看为恶的事，走耶罗波安的道路，效法耶罗波安所行的罪恶，使以色列犯罪。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王纪上 16:14; 列王纪上 16:5; 列王纪上 16:27"> 泽姆利其余的事迹，包括他谋反的事，不是都记在《以色列诸王年代志》上吗？</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 12:25; 以弗所书 4:3–5; 箴言 28:2"> 那时以色列民分成两半，一半人跟随基纳的儿子提比尼，要立他为王，另一半跟随欧姆利。</span>
<span className="v" id="v22" data-v="22"> 但跟随欧姆利的人战胜了跟随基纳的儿子提比尼的人，结果提比尼死了，欧姆利作了王。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪上 16:8; 列王纪上 16:29; 历代志下 22:2"> 犹大王亚撒在位第三十一年，欧姆利作王，他统治以色列十二年，有六年是在提尔撒统治的。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 13:32; 列王纪上 16:32; 使徒行传 8:5–8"> 欧姆利用二他连得<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="二他连得——相当于68.4公斤。1他连得=34.2公斤。">b</a></sup>银子从谢梅尔那里买下了撒玛利亚山，在山上建造了一座城，照着山的主人谢梅尔<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="谢梅尔——传统音译作“撒玛”。">c</a></sup>的名字，给他所建造的城起名为撒玛利亚。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="弥迦书 6:16; 列王纪上 16:30–31; 列王纪上 14:9"> 欧姆利做耶和华眼中看为恶的事，作恶超过他之前所有的王。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 16:19; 列王纪上 16:13; 列王纪上 12:26–33"> 他走尼八之子耶罗波安一切的道路，效法耶罗波安使以色列所犯的罪，以他们的假神惹怒耶和华以色列的神。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 16:20; 列王纪上 16:14; 列王纪上 16:5"> 欧姆利所做的其余事迹，他行使的武力，不是都记在《以色列诸王年代志》上吗？</span>
<span className="v" id="v28" data-v="28"> 欧姆利与他的列祖长眠，葬在撒玛利亚；他的儿子亚哈接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 犹大王亚撒在位第三十八年，欧姆利的儿子亚哈作了以色列的王；欧姆利的儿子亚哈在撒玛利亚统治以色列二十二年。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 16:25; 列王纪上 21:25; 列王纪上 14:9"> 欧姆利的儿子亚哈做耶和华眼中看为恶的事，超过他之前的所有人。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 17:16; 列王纪下 10:18; 士师记 18:7"> 他效法尼八之子耶罗波安的罪恶，对他还算为小事，他又娶了西顿王埃特巴力的女儿耶洗别为妻，去服事巴力，向它下拜。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪下 10:21; 列王纪下 10:26–27"> 他在撒玛利亚建造巴力庙宇，在其中为巴力设立了一座祭坛。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪下 13:6; 列王纪上 21:25; 列王纪下 21:3"> 亚哈又制作了亚舍拉柱。亚哈所做的事，比他之前的任何一位以色列王更惹怒耶和华以色列的神。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="约书亚记 6:26; 约书亚记 23:14–15; 马太福音 24:35"> 在亚哈年间，有伯特利人希伊勒建造耶利哥城。他奠定城的根基时丧了长子亚比兰，竖立城门时丧了小儿子西割，正如耶和华藉着嫩的儿子约书亚所宣告的话。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 9:6; 历代志下 10:1–19; 士师记 9:1"> 罗波安前往示剑，因为全体以色列人来到了示剑，要立他为王。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 11:40; 历代志下 10:2–3; 列王纪上 11:26–31"> 尼八之子耶罗波安听说了这事；那时他还在埃及，从所罗门王面前逃走之后，耶罗波安一直住在埃及。</span>
<span className="v" id="v3" data-v="3"> 以色列人派人去把他请来，耶罗波安就和以色列全体会众来与罗波安交涉，说：</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 8:11–18; 列王纪上 4:7; 马太福音 11:29–30"> “你父亲使我们负轭严酷，现在求你减轻你父亲加给我们的严酷劳役和繁重的轭，我们就服事你。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪上 12:12"> 罗波安对他们说：“你们走吧，三天后再回来见我。”民众就走了。</span>
<span className="v" id="v6" data-v="6" data-xref="约伯记 12:12; 约伯记 32:7; 撒母耳记下 16:20"> 罗波安王与那些在所罗门活着时侍立在他父亲面前的长老们商议，说：“你们如何建议，好让我回复这民众呢？”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="箴言 15:1; 历代志下 10:6–7; 列王纪上 12:13"> 他们回答他说：“现在如果你愿作这民众的公仆，为他们服务，用和善的言词对他们说话、回应他们，他们也必终身作你的仆人。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="箴言 19:20; 传道书 10:2–3; 历代志下 10:8"> 王却不采纳长老们给他提的建议，而去与那些同他一起长大、侍立在他面前的年轻人商议，</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 22:6–8; 撒母耳记下 17:5–6; 历代志下 10:9"> 问他们：“你们有什么建议，我们好回复这民众呢？他们对我说：求你减轻你父亲加在我们身上的轭。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志下 10:10–11; 箴言 10:14; 以赛亚书 47:6"> 那些与他一起长大的年轻人说：“你要这样回复这民众，他们既然对你说‘你父亲使我们的轭沉重，求你给我们减轻’，你就告诉他们：‘我的小拇指比我父亲的腰还粗。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 27:11; 以西结书 2:6; 耶利米书 28:13–14"> 我父亲使你们负重轭，现在我要使你们的轭更重；我父亲用鞭子管教你们，我要用蝎子鞭管教你们！’”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王纪上 12:5; 历代志下 10:12–14"> 耶罗波安和全体民众照着王吩咐的“三天后回来见我”，在第三天来到罗波安那里，</span>
<span className="v" id="v13" data-v="13" data-xref="雅各书 3:17; 箴言 13:20; 传道书 10:12"> 王严厉地回应了民众。他不采纳长老们给他提的建议，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 5:16–18; 列王纪上 12:10–11; 出埃及记 5:5–9"> 而是照着年轻人的建议回答他们，说：“我父亲使你们的轭沉重，我要使它更重；我父亲用鞭子管教你们，我要用蝎子鞭管教你们！”</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="列王纪上 12:24; 申命记 2:30; 士师记 14:4"> 王没有听从民众，因为事态的变化是出于耶和华，好让耶和华成就他藉着示罗人亚希雅对尼八之子耶罗波安所宣告的话。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 20:1; 耶利米书 23:5–6; 历代志下 10:16"> 全体以色列人见王没有听从他们，民众就回应王说：<br /><span className="pl pl-1">“我们在大卫这里有什么份呢？</span><br /><span className="pl pl-1">我们在耶西的儿子这里没有继业。</span><br /><span className="pl pl-1">以色列人哪，回自己的帐篷去吧！</span><br /><span className="pl pl-1">大卫啊，你自己看顾你的家吧！”</span><br />于是以色列人都回自己的家<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="家——或译作“帐篷”。">a</a></sup>去了。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 11:36; 列王纪上 11:13; 历代志下 11:13–17"> 只有住在犹大各城的以色列子民，罗波安继续统治他们。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王纪上 4:6; 撒母耳记下 20:24; 列王纪上 5:14"> 罗波安王把掌管苦役的亚多兰派去，以色列众人却用石头砸死了他。罗波安王急忙上车，逃回耶路撒冷去了。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 17:21; 历代志下 10:19; 约书亚记 4:9"> 这样以色列人反叛了大卫家，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王纪上 11:13; 列王纪上 11:32; 何西阿书 8:4"> 以色列众人听说耶罗波安回来了，就派人去邀请他来参加集会，然后立他为全以色列的王。除了犹大支派以外，没有跟随大卫家的。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志下 11:1–3; 历代志上 21:5; 历代志下 14:8"> 罗波安回到耶路撒冷，招聚了犹大全家和便雅悯支派十八万善战的精兵，要与以色列家争战，恢复所罗门的儿子罗波安的王国。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 11:2; 历代志下 12:5–7; 列王纪上 13:1"> 但神的话语临到神人示玛雅，说：</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 12:17"> “你要告诉所罗门的儿子犹大王罗波安、犹大和便雅悯全家，以及其余的子民，说：</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 12:15; 历代志下 25:7–8; 何西阿书 8:4"> ‘耶和华如此说：你们不可上去，不可与你们的兄弟以色列人争战。各回自己的家去吧，因为这事出于我。’”<br />于是他们听从耶和华的话，照着耶和华的吩咐都回去了。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="士师记 8:17; 士师记 8:8; 士师记 9:45–49"> 耶罗波安在以法莲山地建造了示剑，住在那里。他又从示剑出去，建造了毗努伊勒。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 38:18–21; 以赛亚书 7:9; 马可福音 2:6–8"> 耶罗波安心里说：“恐怕这王国重归大卫家：</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 12:5–7; 箴言 29:25; 申命记 12:14"> 民众如果上耶路撒冷去，在耶和华殿中献祭，民众的心就会归向他们的主犹大王罗波安；他们会杀了我，回归犹大王罗波安。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王纪下 10:29; 出埃及记 32:8; 列王纪下 17:16"> 于是，耶罗波安王经过商议后，铸造了两只金牛犊，对民众说：“你们上耶路撒冷太费事。以色列啊，看，这就是你们的神，把你们从埃及地带上来的那一位。”</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 28:19; 士师记 18:27–31; 何西阿书 4:15"> 这样，他把金牛犊一只设立在伯特利，另一只设立在但。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 17:21; 列王纪上 13:34; 列王纪下 10:31"> 这事带来了罪孽，人们甚至前往但去在另一只金牛犊面前下拜。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="历代志下 13:9; 列王纪下 17:32; 列王纪上 13:32–33"> 耶罗波安又建造了高坛庙宇，甚至把不属利未支派的各类人立为祭司。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 8:5; 列王纪上 8:2; 阿摩司书 7:10–13"> 耶罗波安设定八月十五日为节期，就像在犹大的节期一样；他亲自上祭坛去献祭。他在伯特利也如此做，向他铸造的公牛犊献祭，并且在伯特利他建造的高坛设立祭司。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪上 13:1; 民数记 15:39; 马太福音 15:6"> 他在自己选定的八月十五日，上伯特利他建造的祭坛去献祭。他为以色列子民设定节期，并且上祭坛去烧香。</span>
</div>
</div>

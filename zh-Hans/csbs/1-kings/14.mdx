<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 20:5; 列王纪上 13:33–34; 撒母耳记上 31:2"> 那时，耶罗波安的儿子亚比雅病了。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 28:8; 列王纪上 11:29–38; 撒母耳记下 14:2"> 耶罗波安对他的妻子说：“你起身乔装改扮，不要让人认出你是耶罗波安的妻子，然后往示罗去。看哪，先知亚希雅在那里，就是他从前对我说我将作这子民的王。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 9:7–8; 列王纪上 13:7; 列王纪下 4:42"> 你手里带十个饼、一些点心和一罐蜂蜜去见他，他会告诉你这孩子将会怎样。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪上 11:29; 撒母耳记上 3:2; 撒母耳记上 4:15"> 耶罗波安的妻子就这样做，她动身往示罗去，来到亚希雅的家。亚希雅因为年纪老迈，眼睛昏花不能看见。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 6:8–12; 箴言 21:30; 列王纪下 4:27"> 耶和华对亚希雅说：“看哪，耶罗波安的妻子要来问你有关她儿子的事，因为她儿子病了。你要如此如此回答她。她进来的时候，会掩饰自己。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="但以理书 5:17–28; 使徒行传 5:9–10; 路加福音 20:20–23"> 王后来到门口，亚希雅听见她的脚步声，就说：“耶罗波安的妻子啊，进来吧。你何必这样掩饰自己呢？我受派遣给你一个严酷的消息。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 16:2; 撒母耳记下 12:7–8; 撒母耳记上 15:16"> 你去告诉耶罗波安：‘以色列的神耶和华如此说：我从子民中提拔了你，立你作我子民以色列的领袖，</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 15:5; 列王纪上 11:33–38; 历代志下 28:1"> 我把王国从大卫家撕去，赐给了你，可是你却没有像我仆人大卫那样遵守我的诫命、全心跟从我，做我眼中看为正的事。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 23:35; 尼希米记 9:26; 诗篇 50:17"> 你反而行恶超过所有在你之前的人，去为自己制造别的神和铸像惹怒我，把我抛在背后。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 32:36; 列王纪上 21:21; 列王纪下 14:26"> 所以看哪，我必使祸患临到耶罗波安的家，<br /><span className="pl pl-1">凡是属于耶罗波安的男丁</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="男丁——原文直译“对着墙撒尿的”。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">无论是为奴的还是自由的，我都要从以色列剪除。</span><br /><span className="pl pl-1">我要除尽耶罗波安家的后代，</span><br /><span className="pl pl-1">如同除尽粪土。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 16:4; 耶利米书 15:3; 列王纪上 21:23–24"> <span className="pl pl-1">属于耶罗波安的人，</span><br /><span className="pl pl-1">死在城里的将被狗吃掉，</span><br /><span className="pl pl-1">死在田野的将被天空的飞鸟吃掉。</span><br /><span className="pl pl-1">这是耶和华说的。’</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王纪上 14:3; 列王纪上 14:16–17; 列王纪下 1:6"> “你起身回家去吧。你的脚踏进城的时候，你孩子必定死。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 19:3; 历代志下 12:12; 约伯记 19:28"> 全以色列会为他哀哭，把他安葬。要知道，凡是属于耶罗波安的人，唯独他一人得以入坟墓，因为在耶罗波安家中，只有这孩子身上还能找到以色列的神耶和华看为美善的事。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 15:27–29; 以西结书 7:2–7; 以西结书 12:22–28"> 耶和华要为自己兴起一个王来治理以色列，他必在当天剪除耶罗波安的家。什么时候？现在就是了！</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 23:15–16; 诗篇 52:5; 列王纪下 15:29"> 耶和华要打击以色列，使以色列如同水中摇荡的芦苇。他要把以色列人从耶和华赐给他们祖先的美地上拔出来，把他们驱散到大河<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="大河——指幼发拉底河。">b</a></sup>那边去，因为他们制作亚舍拉柱惹怒了耶和华。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 15:34; 列王纪上 16:2; 列王纪上 13:34"> 因着耶罗波安所犯的罪，以及他使以色列所犯的罪，耶和华必撇弃以色列。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王纪上 15:33; 列王纪上 16:15; 列王纪上 16:23"> 于是耶罗波安的妻子起身离开，回到提尔撒；她一跨进家门槛，孩子就死了。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 14:13"> 人们安葬了他，全以色列为他哀哭，正如耶和华藉着他的仆人亚希雅先知所宣告的话。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="历代志下 13:2–20; 历代志上 27:24; 列王纪上 16:20"> 耶罗波安其余的事迹，他的争战、他的统治，看哪，都记在《以色列诸王年代志》上。</span>
<span className="v" id="v20" data-v="20" data-xref="约伯记 14:12; 诗篇 3:5; 列王纪上 11:43"> 耶罗波安统治的日子有二十二年，他与他的列祖长眠，他的儿子纳达布接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="历代志下 12:13; 列王纪上 11:36; 列王纪上 14:31"> 所罗门的儿子罗波安在犹大作王。他作王的时候四十一岁，在耶路撒冷统治了十七年，这城是耶和华从以色列众支派所拣选要安置他名的地方。罗波安的母亲名叫拿玛，是亚扪人。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="历代志下 12:1; 哥林多前书 10:22; 诗篇 78:58"> 犹大人做耶和华眼中看为恶的事，他们犯罪惹耶和华嫉愤，比他们祖先所做的一切还严重。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 12:2; 以赛亚书 57:5; 列王纪下 17:9–10"> 他们在各高丘上、各青翠树下，为自己建立高坛、神柱和亚舍拉柱；</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 23:17; 哥林多前书 6:9; 列王纪上 15:12"> 国中甚至有男庙妓。他们效法耶和华在以色列子民面前赶出的那些民族的一切可憎行为。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王纪上 11:40; 历代志下 12:2–4; 历代志下 12:9"> 到了罗波安王第五年，埃及王示撒上来攻打耶路撒冷。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 15:18; 历代志下 9:15–16; 列王纪上 7:51"> 他夺走耶和华殿的宝物和王宫的宝物，全都夺走了，所罗门做的那些金盾牌也都夺走了。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 8:11; 撒母耳记上 22:17; 列王纪上 18:46"> 罗波安王就做了铜盾牌代替它们，交托在那些看守王宫大门的卫队长手上。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 12:11"> 每当王进入耶和华的殿时，守卫们就拿出这些盾牌，之后再放回守卫室。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王纪上 22:45; 列王纪上 15:23; 列王纪上 14:19"> 罗波安其余的事迹和他所做的一切，不是都记在《犹大诸王年代志》上吗？</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 12:24; 列王纪上 12:21; 列王纪上 15:6–7"> 罗波安和耶罗波安之间一直有争战。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志下 12:16; 马太福音 1:7; 列王纪上 15:3"> 罗波安与他的列祖长眠，葬在大卫城，与他的列祖在一起。他的母亲名叫拿玛，是亚扪人。他的儿子亚比雅姆接替他作王。</span>
</div>
</div>

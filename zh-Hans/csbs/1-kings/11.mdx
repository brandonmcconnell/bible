<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 17:17; 箴言 6:24; 尼希米记 13:23–27"> 所罗门王除了法老的女儿之外，还贪爱许多外邦女子，有摩押人、亚扪人、以东人、西顿人和赫提人。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 34:16; 申命记 7:3–4; 约书亚记 23:12–13"> 论到这些国民，耶和华曾吩咐过以色列子孙：“你们不可与他们通婚，他们也不可与你们通婚；因为他们必定使你们的心偏离，去随从他们的神明。”但所罗门却深深迷恋她们。</span>
<span className="v" id="v3" data-v="3" data-xref="传道书 7:28; 撒母耳记下 5:13–16; 历代志下 11:21"> 他有七百个妃，都出身贵族，又有三百个嫔，他的妃嫔使他的心偏离。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪上 9:4; 列王纪上 8:61; 列王纪上 11:6"> 所罗门年老的时候，他的妃嫔使他的心偏离，去随从别的神，他的心没有像他父亲大卫的心那样完全忠于耶和华他的神。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 2:13; 列王纪上 11:7; 列王纪下 23:13"> 所罗门去随从西顿人的女神亚斯她录，也随从亚扪人的可憎偶像米勒公。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 14:24; 约书亚记 14:8; 约书亚记 14:14"> 所罗门做耶和华眼中看为恶的事，不像他父亲大卫那样全心跟从耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="民数记 21:29; 士师记 11:24; 使徒行传 7:43"> 那时，所罗门为摩押的可憎偶像基抹和亚扪人的可憎偶像摩洛，在耶路撒冷东边的山上建造高坛；</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 10:11–12; 列王纪上 11:1; 以西结书 16:22–29"> 他为所有的妃嫔，就是那些向自己的神明烧香献祭的外邦女子，都这样做。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王纪上 9:2; 列王纪上 3:5; 申命记 7:4"> 耶和华对所罗门发怒，因为他的心偏离了曾经两次向他显现的耶和华以色列的神；</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 6:12–13; 历代志下 7:17–22; 列王纪上 9:4–7"> 耶和华曾为这事吩咐他不可跟从别的神，他却不遵守耶和华所吩咐的。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪上 12:15–16; 列王纪上 11:31; 列王纪下 17:21"> 于是耶和华对所罗门说：“你既然如此行事，不遵守我的约以及我所吩咐你的律例，我必定从你撕去王国，将它赐给你的臣仆。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 20:19; 撒母耳记上 9:4–5; 列王纪下 22:19–20"> 然而我为你父亲大卫的缘故，不会在你在世的日子做这事，我将从你的儿子手中撕去王国。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 12:20; 申命记 12:11; 列王纪上 11:32"> 不过我不会撕去整个王国，为我仆人大卫的缘故，为我所拣选的耶路撒冷的缘故，我会留下一个支派给你的儿子。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志上 5:26; 诗篇 89:30–34; 以赛亚书 13:17"> 此后耶和华兴起一个敌对所罗门的人，就是以东人哈达，他是以东王室的后裔。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 8:14; 历代志上 18:12–13; 申命记 20:13"> 先前大卫在以东的时候，元帅约押上去埋葬那些阵亡的人，还把以东的所有男丁都击杀了。</span>
<span className="v" id="v16" data-v="16"> 约押和以色列全军留在那里六个月，直到他剪除了以东所有的男丁。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 2:13–14; 出埃及记 2:1–10; 列王纪下 11:2"> 哈达却逃走了，他和他父亲的臣仆——几个以东人一起逃往埃及，那时哈达还是个小孩子。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 10:12; 申命记 33:2; 申命记 1:1"> 他们从米甸起行，来到帕兰，又从帕兰带了几个人一同来到埃及，到了埃及王法老那里。法老赐给他房屋，吩咐供应他粮食，并赐给他土地。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 39:4; 耶利米书 43:7–9; 创世记 39:21"> 哈达在法老眼前蒙大恩，法老把他妻子的妹妹，就是王后塔佩妮斯的妹妹，赐给他为妻。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 21:7; 撒母耳记上 1:24"> 塔佩妮斯的妹妹给哈达生了儿子格努巴特，塔佩妮斯在法老的宫殿里抚养他到断奶，格努巴特就在法老的宫殿里，与法老的儿子们在一起。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王纪上 2:10; 出埃及记 4:19; 马太福音 2:20"> 当哈达在埃及听说大卫与他的列祖长眠，元帅约押也已经死了，他就对法老说：“请让我走吧，我要回我本土去。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 18:22–23; 路加福音 22:35; 马可福音 14:31"> 法老对他说：“你在我这里到底有什么缺乏，以致你突然想回本土去呢？”<br />他回答：“没有什么缺乏，只求你让我走。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪上 11:14; 撒母耳记下 8:3; 撒母耳记下 10:15–18"> 神还兴起另外一个敌对所罗门的人，就是以利雅大的儿子利逊。他先前从他的主人琐巴王哈大底谢那里逃走。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 10:8; 撒母耳记下 10:18; 列王纪上 20:34"> 当时大卫击杀琐巴人，利逊就招聚了一伙人，并自立为队伍的首领。他们来到大马士革，在那里住下来，统治大马士革。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 15:2; 诗篇 106:40; 列王纪上 5:4"> 在所罗门一生的日子，除了哈达为祸患之外，利逊也与以色列敌对，他厌恶以色列，并且统治了亚兰。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="历代志下 13:6; 列王纪上 12:2; 列王纪上 11:28"> 还有所罗门的一个臣仆，尼八之子耶罗波安，他是泽利达的以法莲人，母亲是个寡妇，名叫洗鲁阿；这耶罗波安也起来反叛<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="起来反叛——原文直译“举手反对”。">a</a></sup>王。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 9:24; 列王纪上 9:15; 箴言 30:32"> 他起来反叛<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="起来反叛——原文直译“举手反对”。">b</a></sup>所罗门王的经过如下：先前所罗门修筑梯垒，修补他父亲大卫之城的破口。</span>
<span className="v" id="v28" data-v="28" data-xref="箴言 22:29; 撒母耳记下 19:20; 士师记 1:22–23"> 耶罗波安这人很有能力，所罗门见这年轻人工作勤奋，就指派他管理约瑟家的一切劳役。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王纪上 12:15; 列王纪上 14:2; 历代志下 9:29"> 那时，耶罗波安从耶路撒冷出来，示罗人先知亚希雅在路上遇见了他。亚希雅穿着一件新外袍，当时只有他们二人在田野。</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 15:27–28; 撒母耳记上 24:4–5"> 亚希雅抓住自己身上的新外袍，把它撕成十二片。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪上 11:11–12"> 他对耶罗波安说：<br />“拿去十片吧！因为以色列的神耶和华如此说：‘看哪，我必把王国从所罗门手中撕去，将十个支派赐给你。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 11:13; 列王纪上 12:20–21; 列王纪上 14:21"> 但为我仆人大卫的缘故，为我从以色列众支派所拣选的耶路撒冷城的缘故，会有一个支派留给所罗门。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪上 11:9; 列王纪上 11:5–7; 列王纪上 9:5–7"> 因为他离弃了我，去膜拜西顿人的女神亚斯她录、摩押的神基抹和亚扪人的神米勒公，没有像他父亲大卫那样遵行我的道，做我眼中看为正的事，遵守我的律例和法规。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="列王纪上 11:12–13; 列王纪上 11:31; 约伯记 11:6"> “‘然而，我不会从他手中夺去整个王国，我要让他一生的日子都作君王；这是为了我所拣选的仆人大卫的缘故，因大卫遵守了我的诫命和律例。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 12:20; 列王纪上 11:12; 出埃及记 20:5–6"> 我要从他儿子手中夺去王权，把十个支派赐给你，</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪下 8:19; 列王纪上 11:13; 列王纪上 15:4"> 只留下一个支派给他的儿子，好让我仆人大卫在我面前、在我所拣选安置我名的城——耶路撒冷，永远有一盏灯。</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 14:26; 列王纪上 11:26; 撒母耳记下 3:21"> 我选择你，让你照着自己的心愿统治一切，作王掌管以色列。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="撒母耳记下 7:11; 约书亚记 1:5; 申命记 31:8"> “‘如果你听从我所吩咐你的一切，遵行我的道，像我仆人大卫所行的那样，做我眼中看为正的事，谨守我的律例和诫命，我就与你同在，为你建立一个持久的家室，像我为大卫建立的家室一样；并且我要把以色列赐给你。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 1:32–33; 路加福音 2:11; 以赛亚书 11:1–10"> 我要因所罗门的罪<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="因所罗门的罪——原文直译“因此”。">c</a></sup>而苦待大卫的后裔，但不会永远这样。’”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="历代志下 12:2–9; 以赛亚书 14:24–27; 耶利米哀歌 3:37"> 所罗门想要杀耶罗波安，耶罗波安就动身逃往埃及，到了埃及王示撒那里。他留在埃及，直到所罗门去世。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="历代志下 9:29–31"> 所罗门其余的事迹和他所做的一切，以及他的智慧，不是都记在《所罗门纪事》上吗？</span>
<span className="v" id="v42" data-v="42" data-xref="列王纪上 2:11"> 所罗门在耶路撒冷统治全以色列的日子有四十年。</span>
<span className="v" id="v43" data-v="43" data-xref="列王纪下 21:18; 列王纪上 2:10; 马太福音 1:7"> 所罗门与他的列祖长眠，葬在他父亲大卫的城；他的儿子罗波安接替他作王。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 9:24; 列王纪上 11:1; 列王纪上 6:1–15"> 所罗门与埃及王法老结亲，娶了法老的女儿，把她先接到大卫城，直到所罗门建完自己的宫殿以及耶和华的殿和耶路撒冷四围的城墙。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 22:43; 历代志下 33:17; 申命记 12:2–5"> 那时百姓仍旧在高坛献祭，因为还没有为耶和华的名建造好殿宇。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 8:3; 诗篇 31:23; 申命记 30:16"> 所罗门爱耶和华，遵行他父亲大卫的律例，不过他也在高坛献祭、烧香。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="历代志上 16:39; 历代志下 1:3; 历代志下 7:5"> 有一天，所罗门王到基遍去，在那里献祭，因为那是个重要的高坛。所罗门在那祭坛上献了一千只燔祭。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 9:2; 雅各书 1:5–6; 民数记 12:6"> 在基遍，耶和华藉着夜间的梦向所罗门显现，神说：“你要我赐给你什么，尽管求吧。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王纪上 9:4; 列王纪上 1:48; 哥林多后书 9:11"> 所罗门说：“你以极大的慈爱对待你仆人我父亲大卫，因他以真理、公义和一颗正直的心行走在你面前；你还持守这极大的慈爱对待他，赐给他一个儿子坐在他的宝座上，就像今日这样。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志上 29:1; 民数记 27:17; 耶利米书 1:6"> “耶和华我的神哪，如今你立你的仆人为王接替我父亲大卫，但我是个小孩子，不知怎样出入。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 15:5; 创世记 13:16; 历代志上 21:2"> 你的仆人在你所拣选的子民当中，而这众多的子民多得不可胜数、无法数清，</span>
<span className="v" id="v9" data-v="9" data-xref="雅各书 1:5; 箴言 16:16; 希伯来书 5:14"> 所以求你赐给仆人一颗明辨的心，使我能治理你的子民，辨别是非。否则，谁能治理你这众多的子民呢？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="箴言 15:8"> 所罗门祈求这事，在主的眼中看为好。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 8:26; 雅各书 4:2–3; 箴言 16:31"> 神就对他说：“既然你求这事，而不为自己求长寿，不为自己求富贵，也不求你仇敌的性命，却为自己求悟性，为要明辨申诉，</span>
<span className="v" id="v12" data-v="12" data-xref="约翰一书 5:14–15; 传道书 1:16; 马太福音 12:42"> 看哪，我必成全你的请求。现在我要赐给你一颗智慧明辨的心，在你之前未曾有像你这样的人，在你之后也不会兴起像你这样的人。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 3:20; 马太福音 6:33; 箴言 3:16"> 此外，你没有求的富贵和荣华，我也赐给你，在你一生的日子，君王中没有一个人能与你相比。</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 3:2; 诗篇 91:16; 列王纪上 15:5"> 而且如果你像你父亲大卫所行的那样遵行我的道，谨守我的律例和诫命，我就使你长寿。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="创世记 41:7; 列王纪上 8:65; 以斯帖记 1:3"> 所罗门醒来后，看哪，是一个梦。他就回到耶路撒冷，站在主的约柜前，献上燔祭，又献平安祭，也为他所有的臣仆摆设宴席。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及记 18:16; 士师记 11:1; 民数记 27:2"> 有一天，两个妓女来见王，站在他面前。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 13:7; 创世记 43:20"> 其中一个妇人说：“哦，我主啊，我和那妇人同住一间房屋，我生孩子的时候，她也在屋子里。</span>
<span className="v" id="v18" data-v="18"> 我生了孩子的第三天，那妇人也生了孩子，当时我们在一起。屋子里没有别人，只有我们两个在屋子里。</span>
<span className="v" id="v19" data-v="19"> 夜间，那妇人的儿子死了，因为她压在孩子身上了。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 3:20; 马太福音 13:25; 诗篇 139:11"> 她就半夜起来，趁着婢女我沉睡的时候，把我的儿子从我身边抱走，放在她怀中，而把她死了的儿子放在我怀中。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 21:7; 撒母耳记上 1:23; 耶利米哀歌 4:3–4"> 我清早起来给我儿子吃奶，看哪，他已经死了。但清早我仔细察看时，发现那不是我生的儿子。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="列王纪上 3:23–24"> 另一个妇人却说：“不！活的是我儿子，死的才是你儿子。”<br />这个妇人就说：“不！死的是你儿子，活的是我儿子。”两人在王面前彼此争辩。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 王说：“这个说‘活的是我儿子，死的是你儿子’，那个说‘不！死的才是你儿子，活的是我儿子’”，</span>
<span className="v" id="v24" data-v="24"> 王就吩咐：“给我拿一把刀来！”于是有人把刀拿到王面前。</span>
<span className="v" id="v25" data-v="25" data-xref="箴言 25:8"> 王说：“把活孩子劈成两半，一半给这妇人，一半给那妇人。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 49:15; 耶利米书 31:20; 约翰一书 3:17"> 那活孩子的母亲因为怜子之心涌上来，就对王说：“哦，我主啊，把活孩子给她吧，千万不要杀他！”<br />另一个妇人却说：“这孩子也不归我，也不归你，劈了吧！”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 于是王宣判说：“把活孩子交给这妇人，千万不要杀他，这妇人就是他的母亲。”</span>
<span className="v" id="v28" data-v="28" data-xref="但以理书 2:47; 列王纪上 3:9–12; 歌罗西书 2:3"> 全以色列都听说了王所做的判决，就敬畏王，因为他们看到王里面有神的智慧，能实行公正。</span>
</div>
</div>

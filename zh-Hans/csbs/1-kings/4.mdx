<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="传道书 1:12; 历代志下 9:30; 列王纪上 12:19–20"> 所罗门王作了全以色列的王，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 18:21; 哥林多前书 12:28; 撒母耳记下 8:15–18"> 他的群臣如下：<br /><span className="pl pl-1">撒督的儿子亚撒利雅作祭司，</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 8:16; 以赛亚书 62:6; 历代志上 18:15"> <span className="pl pl-1">示沙的两个儿子以利赫列和亚希雅作书记，</span><br /><span className="pl pl-1">亚希律的儿子约沙法作史官，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 2:35; 列王纪上 2:26–27"> <span className="pl pl-1">耶赫亚达的儿子比纳雅统管军队，</span><br /><span className="pl pl-1">撒督和亚比亚特作祭司，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 27:33; 撒母耳记下 15:37; 撒母耳记下 16:16"> <span className="pl pl-1">拿单的儿子亚撒利雅统管总督们，</span><br /><span className="pl pl-1">拿单的儿子撒布德作内官，是王的朋友</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="作内官，是王的朋友——或译作“作王的祭司兼顾问”。">a</a></sup><br /><span className="pl pl-1">，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 9:15; 撒母耳记下 20:24; 列王纪上 12:18"> <span className="pl pl-1">阿希沙作宫廷总管，</span><br /><span className="pl pl-1">阿布达的儿子亚多尼兰掌管服苦役的人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="历代志上 27:1–15"> 所罗门在全以色列设立十二个总督，他们要供应王和王室，一年中每人负责供应一个月。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 24:33; 士师记 19:1; 士师记 17:1"> 他们的名字如下：<br /><span className="pl pl-1">本户珥，管理以法莲山地；</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 21:16; 撒母耳记上 6:20; 撒母耳记上 6:12"> <span className="pl pl-1">本迪克，管理玛迦斯、沙勒宾、伯示麦、埃隆-伯哈南；</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 15:35; 约书亚记 12:17; 约书亚记 17:2"> <span className="pl pl-1">本希悉，管理亚鲁泊，梭哥和希弗全地也归他管理；</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 11:2; 约书亚记 12:23; 约书亚记 17:11"> <span className="pl pl-1">本亚比拿达，管理全多珥高地，他娶了所罗门的女儿塔法特为妻；</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 17:11; 士师记 5:19; 约书亚记 3:16"> <span className="pl pl-1">亚希律的儿子巴拿，管理特纳克、米吉多，以及撒拉坦附近、耶斯列下边的伯珊全地，从伯珊到亚贝勒-米何拉，一直到约克缅对面；</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="申命记 3:4; 民数记 32:41; 列王纪上 22:3"> <span className="pl pl-1">本基别，管理拉末-基列，以及在基列的玛拿西子孙的那些睚珥镇，另外巴珊的亚珥歌伯地区也归他管理，共六十座大城，都有城墙和铜门闩；</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 13:26; 撒母耳记下 17:24; 撒母耳记下 2:8"> <span className="pl pl-1">易多的儿子亚希纳达，管理玛哈念；</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 19:32–39; 撒母耳记下 15:27; 撒母耳记上 18:18"> <span className="pl pl-1">亚希玛斯，管理拿弗他利，他也娶了所罗门的女儿，娶了巴丝玛为妻；</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 19:24–31; 撒母耳记下 15:32"> <span className="pl pl-1">户筛的儿子巴拿，管理亚设和比亚录；</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 19:17–23"> <span className="pl pl-1">帕路阿的儿子约沙法，管理以萨迦；</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 1:8; 约书亚记 18:20–28; 撒迦利亚书 12:13"> <span className="pl pl-1">以拉的儿子示每，管理便雅悯；</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="申命记 2:26–17; 约书亚记 13:9–12; 民数记 21:21–35"> <span className="pl pl-1">乌利的儿子基别，管理基列地，就是从前属亚摩利王西宏和巴珊王欧革的领土，</span><br />他是这地区唯一的总督。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 22:17; 列王纪上 3:8; 创世记 32:12"> 犹大人和以色列人多如海边的沙，他们有吃有喝，欢喜快乐。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 15:18; 约书亚记 1:4; 诗篇 68:29"> <sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="此节至5:18在马索拉文本为5:1至5:32。">b</a></sup>所罗门统管列国，从大河<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="大河——指幼发拉底河；本章下同。">c</a></sup>到非利士人之地，直到埃及的边界。所罗门在世的日子，这些王国都向他进贡，臣服于他。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 所罗门每日所用的食物，有细面粉三十柯珥<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="三十柯珥——相当于6,600公升。1柯珥=220公升。">d</a></sup>，粗面粉六十柯珥<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="六十柯珥——相当于13,200公升。">e</a></sup>，</span>
<span className="v" id="v23" data-v="23" data-xref="尼希米记 5:17–18"> 圈养的肥牛十只，放牧的牛二十只，羊一百只，此外有鹿、羚羊、狍子和各类肉禽。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 22:9; 诗篇 72:11; 诗篇 72:3"> 所罗门统辖大河西边的全域，从提弗萨到加沙，统治大河西边的所有君王，他周围四境都有平安。</span>
<span className="v" id="v25" data-v="25" data-xref="弥迦书 4:4; 撒迦利亚书 3:10; 士师记 20:1"> 所罗门在世的日子，犹大和以色列——从但直到比尔-谢巴，各人在自己的葡萄树下、无花果树下，安然居住。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志下 1:14; 历代志下 9:25; 撒母耳记下 8:4"> 所罗门有四千个<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="四千个——依据七十士译本；参《历代志下》9:25；马索拉文本作“四万个”。">f</a></sup>马厩存放战车马匹，还有一万两千马兵。</span>
<span className="v" id="v27" data-v="27"> 那些总督各按自己的月份，供应所罗门王和所有与王同席的人，保证一无所缺。</span>
<span className="v" id="v28" data-v="28" data-xref="以斯帖记 8:10; 以斯帖记 8:14; 弥迦书 1:13"> 他们各照自己的任务，把战马和驿马所需用的大麦和干草，送到指定的地方。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王纪上 3:12; 雅各书 3:17; 列王纪上 4:20"> 神赐予所罗门智慧、极大的聪慧和广阔的心思，多如海边的沙。</span>
<span className="v" id="v30" data-v="30" data-xref="但以理书 5:11–12; 创世记 25:6; 但以理书 1:20"> 所罗门的智慧超过所有东方人的智慧和埃及人的一切智慧。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 2:6; 历代志上 15:19; 列王纪上 3:12"> 他比任何人都有智慧，超过以斯拉人伊坦、玛赫勒的儿子希幔、卡珥克勒、达尔达；他的名声传遍了四围列邦。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="雅歌 1:1–17; 马太福音 13:35; 箴言 1:1–31"> 他写作<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="写作——原文直译“述说”。">g</a></sup>了三千句箴言，他的诗歌有一千零五首。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪下 19:23; 诗篇 51:7; 诗篇 92:12"> 他讲论草木植物，从黎巴嫩的香柏树到墙上长的牛膝草；又讲论飞禽走兽、爬虫水族。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志下 9:23; 列王纪上 10:1; 历代志下 9:1"> 万民中，那些听说所罗门智慧的各国君王中，都有人来聆听所罗门的智慧。</span>
</div>

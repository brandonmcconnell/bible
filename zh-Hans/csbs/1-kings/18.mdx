<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 4:25; 雅各书 5:17; 申命记 28:12"> 许多日子过去，到了第三年，耶和华的话语临到以利亚，说：“去让亚哈见到你，我将要在这地上赐下雨水。”</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 6:25; 箴言 28:1; 利未记 26:26"> 以利亚就去，要与亚哈见面。<br />那时撒玛利亚的饥荒很严重。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 7:2; 列王纪上 16:9; 马太福音 10:28"> 亚哈召来宫廷总管俄巴底亚，俄巴底亚非常敬畏耶和华，</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 18:13; 马太福音 10:40–42; 启示录 17:4–6"> 当耶洗别除灭耶和华的众先知时，俄巴底亚曾收留一百个先知，把他们藏起来，每五十人一个山洞，供应他们饼和水。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 14:5–6; 约珥书 1:18; 约珥书 2:22"> 亚哈吩咐俄巴底亚：“你去走遍这地所有的水泉、所有的溪流，或许我们能找到一些青草，使马和骡子得以存活，不至于使牲畜断绝。”</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 14:3"> 于是他们划分地区巡行，亚哈独自往一个方向去，俄巴底亚独自往另一个方向去了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王纪下 1:6–8; 创世记 44:20; 以赛亚书 60:14"> 俄巴底亚正在路上，看哪，以利亚向他迎面过来了。俄巴底亚认出以利亚，就脸伏于地，说：“你是我主以利亚吗？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="罗马书 13:7; 列王纪上 18:3; 彼得前书 2:17–18"> 以利亚回答：“是我。去告诉你的主人，以利亚在这里。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 5:21; 列王纪上 18:12; 列王纪上 17:18"> 俄巴底亚说：“我犯了什么罪，你竟要把仆人交在亚哈手中处死？</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 17:1; 列王纪上 1:29; 列王纪上 18:15"> 我指着你的神耶和华的永生起誓：没有一邦一国我主不派人去寻找你的。如果他们说你不在，他就要求那邦那国起誓说真找不到你。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪上 18:8; 列王纪上 18:14"> “现在你竟然说：‘去告诉你的主人，以利亚在这里。’</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 2:16; 使徒行传 8:39; 以西结书 8:3"> 我一旦离开你，耶和华的灵就会把你带到我所不知道的地方去，这样如果我去告诉亚哈，他却找不到你，就必杀我。其实你仆人从年幼时就敬畏耶和华！</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 18:4; 马太福音 25:35; 诗篇 18:21–24"> 难道没有人把我所做的事告诉我主吗？耶洗别杀戮耶和华众先知的时候，我把耶和华的一百个先知藏了起来，每五十人一个山洞，供应他们饼和水。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 10:28"> 现在你竟然说：‘去告诉你的主人，以利亚在这里。’他一定会杀我的。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王纪上 17:1; 列王纪上 18:10; 路加福音 2:13–14"> 以利亚说：“我指着我所事奉的万军之耶和华的永生起誓：今天我必让亚哈见到我。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 于是俄巴底亚去与亚哈会合，把这件事禀告王。亚哈就去迎见以利亚。</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 7:25; 列王纪上 21:20; 使徒行传 16:20"> 亚哈一看见以利亚，就对他说：“是你吗？你这给以色列带来祸患的人！”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="历代志下 15:2; 列王纪上 9:9; 耶利米书 2:19"> 以利亚说：“给以色列带来祸患的人不是我，而是你和你父家，因为你们离弃耶和华的诫命，去追随巴力。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 19:26; 列王纪上 16:33; 彼得后书 2:1"> 现在，你派人去招聚全体以色列人，以及那四百五十个巴力的先知，还有与耶洗别同席吃饭的四百个亚舍拉先知，都到迦密山见我。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王纪上 22:9"> 亚哈就派人到以色列众人那里，把那些先知都招聚到迦密山。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 6:24; 约书亚记 24:15; 哥林多前书 10:21–22"> 以利亚走近全体民众，说：“你们心怀二意摇摆不定<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="心怀二意摇摆不定——原文直译“两条拐杖上瘸着走”。">a</a></sup>，要到什么时候呢？如果耶和华是神，就当跟从耶和华；如果巴力是神，就当跟从巴力。”民众一句话也不回答。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="列王纪上 19:10; 列王纪上 19:14; 提摩太后书 4:3–4"> 以利亚对民众说：“耶和华的先知唯独剩下我一个，巴力的先知却有四百五十人。</span>
<span className="v" id="v23" data-v="23"> 请给我们提供两头公牛，让巴力的先知自己挑选一头，切成块，放在木柴上，但不要点火；我会把另一头公牛也预备好，放在木柴上，不点火。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 18:38; 历代志上 21:26; 历代志下 7:1"> 然后你们呼求你们神的名，我也呼求耶和华的名；那用烈火回应的神，他才是神。”<br />全体民众回答：“这提议很好。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 以利亚对巴力的众先知说：“你们既然人多，请你们先来吧，为自己挑选一头公牛，预备好，然后呼求你们神的名，但不要点火。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="耶利米书 10:5; 哥林多前书 8:4; 马太福音 6:7"> 他们就把提供给他们的公牛取来献上，从清晨到正午呼求巴力的名，说：“巴力啊，求你回应我们！”可是没有动静，没有回应。他们在修筑的祭坛周围摇摆蹦跳。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="诗篇 78:65–66; 以赛亚书 41:23; 传道书 11:9"> 到了中午，以利亚嘲弄他们说：“他既然是神，你们大声呼求吧！他一定是在默想，或者他正忙着，或者他在旅行，或者他在沉睡，需要叫醒。”</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 19:28; 申命记 14:1; 马可福音 5:5"> 于是他们大声呼求，照着他们的习俗用刀用矛刺伤自己，以致满身流血。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪上 18:26; 撒母耳记上 18:10; 出埃及记 29:39"> 过了中午，他们继续说神言，直到下午献祭的时间；但还是没有动静，没有回应，没有反应。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="历代志下 33:16; 列王纪上 19:14; 列王纪上 19:10"> 于是，以利亚对全体民众说：“到我这里来吧。”全体民众近前来，他就修复那被拆毁的耶和华的祭坛。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 17:34; 创世记 35:10; 创世记 32:28"> 以利亚按照雅各子孙的支派数目取了十二块石头——耶和华的话语曾临到雅各说“你的名字要叫以色列”——</span>
<span className="v" id="v32" data-v="32" data-xref="歌罗西书 3:17; 出埃及记 20:24–25; 士师记 21:4"> 以利亚用这些石头以耶和华的名筑了一座祭坛，又在祭坛四围挖了一条可容下二斗<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="二斗——原文作“二细亚”；相当于14公升。1细亚=7.3公升。">b</a></sup>谷物的沟渠。</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 22:9; 士师记 6:20; 利未记 1:6–8"> 他摆好木柴，把公牛切成块，放在木柴上，然后吩咐说：“装满四桶水，倒在燔祭和木柴上。”</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多后书 8:21; 哥林多后书 4:2"> 他又说：“再倒一次。”他们就再倒了一次。他又说：“倒第三次。”他们就倒了第三次。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 18:32; 列王纪上 18:38"> 水向祭坛的四围流下来，连沟渠里也满了水。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="列王纪上 18:29; 列王纪下 19:19; 出埃及记 3:6"> 到了下午献祭的时间，先知以利亚上前来祷告：“亚伯拉罕、以撒、以色列的神耶和华啊，求你今天显明：你是以色列的神，我是你的仆人，并且是遵照你的话语做了这一切事。</span>
<span className="v" id="v37" data-v="37" data-xref="但以理书 9:17–19; 路加福音 1:16–17; 以西结书 36:25–27"> 应允我，耶和华啊，应允我！让这子民知道：你耶和华才是神，你使他们的心回转。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="历代志上 21:26; 利未记 9:24; 历代志下 7:1"> 于是耶和华的火降下来，把燔祭、木柴、石头、尘土都吞噬了，连沟渠里的水也吞没了。</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪上 18:24; 历代志下 7:3; 列王纪上 18:21"> 全体民众看见了，就脸伏于地，说：“耶和华是神！耶和华是神！”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="申命记 18:20; 士师记 4:7; 申命记 13:5"> 以利亚吩咐他们：“把巴力的先知都抓起来，不让一个逃脱！”人们就抓住那些先知。以利亚把他们带到基顺河边，在那里都杀了。</span>
<span className="v" id="v41" data-v="41" data-xref="列王纪上 18:1; 传道书 9:7; 列王纪上 17:1"> 以利亚对亚哈说：“你上去吃喝吧，已经有了大雨的嘈杂声。”</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="路加福音 6:12; 但以理书 9:7; 约书亚记 7:6"> 亚哈就上去吃喝，以利亚却上到迦密山顶，屈身在地，脸伏在双膝间。</span>
<span className="v" id="v43" data-v="43" data-xref="哈巴谷书 2:3; 路加福音 18:7; 路加福音 18:1"> 他对仆人说：“你上去朝着大海观看。”<br />仆人上去观看了，然后说：“什么也没有。”<br />以利亚说：“再去。”这样有七次。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="路加福音 12:54; 约伯记 8:7; 撒迦利亚书 4:10"> 到了第七次，仆人说：“看哪，有一片像手掌那么小的乌云从海面升起来。”<br />以利亚说：“你上去告诉亚哈：备好车下去吧，免得被大雨困住。”</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="列王纪上 18:39–40; 约书亚记 17:16; 列王纪上 21:1"> 刹那间，天空风云变色，下起了大雨。亚哈乘车前往耶斯列去；</span>
<span className="v" id="v46" data-v="46" data-xref="以西结书 3:14; 以西结书 1:3; 列王纪下 9:1"> 耶和华的手<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="手——或译作“大能”。">c</a></sup>落在以利亚身上，他就束上腰，跑在亚哈的前面，直到耶斯列的城门口。</span>
</div>
</div>

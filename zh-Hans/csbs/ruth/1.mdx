<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 12:10; 创世记 26:1; 以西结书 14:13"> 在士师们治理的日子里，犹大地有了饥荒。犹大的伯利恒有一个人，带着他的妻子和两个儿子，去摩押地寄居。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 35:19; 弥迦书 5:2; 撒母耳记上 17:21"> 这人名叫以利米勒，他的妻子名叫娜娥米，他两个儿子，一个叫玛伦，一个叫基连；他们是犹大伯利恒的以法他人；他们来到摩押地，就在那里住了下来。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 12:10–11; 诗篇 34:19; 希伯来书 12:6"> 后来，娜娥米的丈夫以利米勒死了，留下她和她的两个儿子。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 1:5; 列王纪上 11:1–2; 申命记 23:3"> 两个儿子各自娶了摩押女子为妻，一个叫娥珥巴，另一个叫路得；他们在那里住了大约十年。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 32:39; 诗篇 89:30–32; 以赛亚书 49:21"> 后来，玛伦和基连两个人也死了，留下娜娥米<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="娜娥米——原文直译“妇女”。">a</a></sup>，既没有了两个孩子，也没有了丈夫。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="诗篇 132:15; 出埃及记 3:16; 诗篇 111:5"> 她和她的儿媳们起身，从摩押地回去；因为她在摩押地听说了耶和华眷顾自己的子民，赐粮食给他们。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 8:3; 路得记 1:14; 出埃及记 18:27"> 这样她与她的两个儿媳一起，从所住的地方离开，上路返回犹大地。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路得记 2:20; 路得记 1:5; 歌罗西书 3:18"> 娜娥米对她的两个儿媳说：“你们走吧，各自回娘家去吧！愿耶和华以慈爱对待你们，像你们先前对待已故的人和一直对待我那样。</span>
<span className="v" id="v9" data-v="9" data-xref="路得记 3:1; 使徒行传 20:37; 创世记 29:11"> 愿耶和华使你们在各自新的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="新的——辅助词语。">b</a></sup>丈夫家中找到安宁。”然后娜娥米亲吻了她们；她们就放声大哭，</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亚书 8:23; 诗篇 16:3; 诗篇 119:63"> 对她说：“不，我们一定要与你一同回到你的族人那里！”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="申命记 25:5; 创世记 38:11"> 娜娥米说：“我的女儿们哪，回去吧！为什么要与我一起走呢？难道我腹中还有儿子将来可以作你们的丈夫吗？</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 17:17; 提摩太前书 5:9"> 我的女儿们哪，回去吧！走吧，我太老了，不会再有丈夫了！就算我说我还有希望，甚至今夜就有丈夫，而且生了儿子，</span>
<span className="v" id="v13" data-v="13" data-xref="约伯记 19:21; 士师记 2:15; 诗篇 32:4"> 难道你们会等到他们长大吗？难道你们会为他们守住自己不嫁人吗？我的女儿们哪，不要这样！我的命<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="命——辅助词语。">c</a></sup>比你们的更苦，因为耶和华伸手攻击了我。”</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 18:24; 马太福音 16:24; 马太福音 10:37"> 她们又放声大哭；娥珥巴吻别了她的婆婆，但路得却紧跟着娜娥米。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 11:24; 约书亚记 24:15; 西番雅书 1:6"> 娜娥米说：“看哪，你嫂子已经回到她的族人和她的神那里去了，你也随着你嫂子回去吧！”</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 15:21; 路得记 2:11–12; 列王纪下 2:2–6"> 路得就说：<br /><span className="pl pl-1">“不要催我离开你，</span><br /><span className="pl pl-1">也不要催我回去，不让我跟随你；</span><br /><span className="pl pl-1">因为你去哪里，我也去哪里；</span><br /><span className="pl pl-1">你在哪里过夜，我也在哪里过夜；</span><br /><span className="pl pl-1">你的族人就是我的族人；</span><br /><span className="pl pl-1">你的神就是我的神；</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 3:17; 列王纪上 2:23; 列王纪下 6:31"> <span className="pl pl-1">你死在哪里，我也死在哪里、葬在哪里。</span><br /><span className="pl pl-1">除了死以外，如果有什么使你我分离，</span><br /><span className="pl pl-1">就愿耶和华处置我，重重地处置我！”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行传 21:14; 以弗所书 6:10; 使徒行传 2:42"> 娜娥米看见路得已经决意要与她一同走，就不再对她说什么了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马太福音 21:10; 以赛亚书 23:7; 耶利米哀歌 2:15"> 于是她们两个人继续走，一直来到伯利恒。她们来到伯利恒的时候，整个城都因她们轰动了；妇女们说：“这是娜娥米吗？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约伯记 6:4; 希伯来书 12:11; 诗篇 73:14"> 娜娥米对她们说：“不要叫我娜娥米，要叫我玛拉，因为全能者使我受尽苦痛；</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 2:7–8; 约伯记 1:21; 约伯记 16:8"> 我满满地出去，但耶和华使我空空地回来；既然耶和华证实了我的不是，全能者向我降下了灾祸，你们为什么还叫我娜娥米呢？”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路得记 2:23; 撒母耳记下 21:9; 出埃及记 9:31–32"> 这样，娜娥米回来了——她的儿媳摩押女子路得也与她一起从摩押地回来了。她们在大麦开始收割的时候来到了伯利恒。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 25:7; 路得记 3:12; 申命记 16:18"> 波阿斯来到城门口，在那里坐下。看哪！波阿斯所说的那个有赎回权的近亲正经过那里；波阿斯就说：“某某人哪，请过来，坐在这里吧！”那个人就过来坐下。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 31:23; 列王纪上 21:8; 使徒行传 6:12"> 波阿斯又从城里的长老中请来十个人，说：“请你们坐在这里。”他们就都坐下。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 13:10; 诗篇 112:5"> 然后他对那个有赎回权的近亲说：“从摩押地回来的娜娥米，要把我们兄弟以利米勒的那块田卖了。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 25:25–29; 耶利米书 32:7–12; 罗马书 12:17"> 我想我应该让你知道这事，并建议你当着在座各位的面，当着我族人的长老们的面，买下那块田。如果你要赎取就赎取吧！但如果你不赎取，请告诉我，我好知道；因为除你以外没有人可以先赎取，而我是在你之后的。”那人说：“我要赎取！”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 38:8; 申命记 25:5–6; 马太福音 22:24"> 接着波阿斯说：“你从娜娥米的手中买下这块田的那天，你也要得到那死者的妻子摩押女子路得，好使那死者在继业上立名。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="利未记 25:25; 路得记 3:13"> 那个有赎回权的近亲就说：“那我就不能赎取那块田了，免得毁掉了我自己的继业。你赎取那块田吧！你可以拥有我的赎回权，因为我不能赎取了。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命记 25:7–10"> 从前在以色列中，确立任何有关赎回权或有关替换权的事，就要这样做：一方要脱下鞋子交给另一方。这是以色列中作见证的方式。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 那个有赎回权的近亲对波阿斯说：“你买下那块田吧！”于是他就脱下了鞋子。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="耶利米书 32:10–12; 创世记 23:16–18"> 接着波阿斯对长老们和全体民众说：“今天你们都是见证人：所有属于以利米勒的、所有属于基连和玛伦的，我都从娜娥米的手中买下了；</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 25:6; 以弗所书 5:25; 创世记 29:27"> 此外我也得到玛伦的妻子摩押女子路得作我的妻子，好使那死者在继业上立名，以免那死者的名从他的兄弟中、从本地的城门口断绝。今天你们都是见证人。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="创世记 29:32–24; 弥迦书 5:2; 马太福音 2:6"> 在城门口的全体民众和长老们都说：“我们都是见证人！愿耶和华使进到你家的这女子像建立以色列家的拉结和莉亚两人那样！愿你在以法他<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以法他——就是伯利恒。">a</a></sup>做大能的事，在伯利恒得名声！</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 38:29; 撒母耳记上 2:20; 历代志上 2:4"> 愿耶和华从这年轻女子赐你后裔，使你的家像塔玛尔给犹大所生的法勒斯的家那样！”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 33:5; 创世记 29:31; 路得记 3:11"> 于是波阿斯娶了路得，路得就成为他的妻子；波阿斯与她同房，耶和华使她怀胎，她就生了一个儿子。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 1:5–20; 路加福音 1:58; 创世记 12:2"> 妇女们对娜娥米说：“耶和华是当受颂赞的！因为他今天没有使你缺失有赎回权的近亲。愿这孩子在以色列得名声！</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 55:22; 以赛亚书 46:4; 创世记 45:11"> 他必使你的灵魂苏醒，在你年老时供养你，因为他是爱你的儿媳所生的；对你来说，有她比有七个儿子更好。”</span>
<span className="v" id="v16" data-v="16"> 娜娥米把那孩子接过来，抱在怀中，抚养他。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 1:58–63"> 邻居的妇女们给孩子起名，说：“有一个儿子为娜娥米而生！”她们就给他起名为俄备得。俄备得是耶西的父亲，耶西是大卫的父亲。</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="马太福音 1:3–6; 历代志上 2:4–8; 路加福音 3:33"> 以下是法勒斯的谱系：<br /><span className="pl pl-1">法勒斯生希斯伦，</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 3:33; 历代志上 2:9–10; 马太福音 1:4"> <span className="pl pl-1">希斯伦生兰，</span><br /><span className="pl pl-1">兰生亚米拿达，</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="民数记 1:7; 路加福音 3:32; 马太福音 1:4"> <span className="pl pl-1">亚米拿达生拿顺，</span><br /><span className="pl pl-1">拿顺生撒门，</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 3:32; 马太福音 1:5; 历代志上 2:11–12"> <span className="pl pl-1">撒门生波阿斯，</span><br /><span className="pl pl-1">波阿斯生俄备得，</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 2:15; 以赛亚书 11:1; 马太福音 1:6"> <span className="pl pl-1">俄备得生耶西，</span><br /><span className="pl pl-1">耶西生大卫。</span></span>
</div>

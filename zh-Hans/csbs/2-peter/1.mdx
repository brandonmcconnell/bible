<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提多书 2:13; 罗马书 3:21–26; 提多书 1:4"> 耶稣基督的奴仆和使徒西门彼得，<br />致那些藉着我们的神、救主耶稣基督的义，与我们领受同样宝贵信仰的人：</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="彼得后书 3:18; 约翰福音 17:3; 腓立比书 3:8"> 愿恩典与平安，藉着你们真正认识神，我们的主耶稣，多多地加给你们！</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="彼得前书 5:10; 提摩太后书 1:9; 罗马书 8:28–30"> 主耶稣<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="主耶稣——原文直译“他”。">a</a></sup>神性的大能，因我们真正认识以自己的荣耀和美德召唤我们的那一位，就把一切有关生命和敬神的事都赐给了我们。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 4:23–24; 以西结书 36:25–27; 哥林多后书 3:18"> 藉着这荣耀和美德<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这荣耀和美德——原文直译“这些”。">b</a></sup>，他把那些又宝贵又极大的应许赐给了我们，好使你们能藉着这些应许，逃脱世上因欲望而来的衰朽<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="衰朽——或译作“败坏”。">c</a></sup>，成为在神的本性上有份的人。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 4:8; 箴言 4:23; 彼得后书 3:18"> 是的，也正是为此，你们应当尽量地殷勤，在信仰上加美德；在美德上加知识；</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 10:36; 罗马书 5:3–4; 路加福音 21:19"> 在知识上加自制；在自制上加忍耐；在忍耐上加敬神；</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 13:1; 罗马书 12:10; 帖撒罗尼迦前书 3:12"> 在敬神上加弟兄之情；在弟兄之情上加爱；</span>
<span className="v" id="v8" data-v="8" data-xref="提多书 3:14; 约翰福音 15:2; 希伯来书 6:12"> 因为你们如果有了这些，并且不断增多这些，它们就会使你们在真正认识我们主耶稣基督的事上，不会成为懒惰的<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="懒惰的——或译作“无益的”。">d</a></sup>或不结果子的人；</span>
<span className="v" id="v9" data-v="9" data-xref="彼得后书 2:18–20; 以弗所书 5:26; 提多书 2:14"> 就是说，没有具备这些的就是瞎眼的，他只看得见眼前的，忘记自己过去的罪孽已经得了洁净。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得后书 3:17; 路加福音 6:47–49; 希伯来书 6:11"> 所以弟兄们，你们当更加努力地确定你们所蒙的召唤和拣选。要知道，如果你们如此行，就绝不会跌倒；</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 5:10; 马太福音 25:34; 启示录 3:21"> 而这样，你们就丰丰富富地得到供应，进入我们的主、救主耶稣基督永恒的国度。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约翰一书 2:21; 罗马书 15:14–15; 腓立比书 3:1"> 所以，虽然你们已经知道这些事，又在你们已有的真理上得了坚固，我还是要<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="要——有古抄本作“不能忽略”。">e</a></sup>不断地提醒你们。</span>
<span className="v" id="v13" data-v="13" data-xref="彼得后书 3:1; 彼得后书 1:14; 希伯来书 13:3"> 我认为，只要我还在这帐篷里，就理当用提醒的话来激发你们，</span>
<span className="v" id="v14" data-v="14" data-xref="提摩太后书 4:6; 约翰福音 21:18–19; 申命记 31:14"> 因为我知道我脱离这帐篷的时候快到了，就像我们的主耶稣基督也曾向我指明的。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 31:19–29; 诗篇 71:18; 约书亚记 24:24–29"> 我也要努力，使你们在我离世以后，时常想起这些事。</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="约翰一书 4:14; 约翰福音 1:14; 提摩太前书 1:4"> 要知道，我们从前让你们明白我们主耶稣基督的大能和他来临的事，并不是随从巧言编造的故事，相反，我们是亲眼见过他威荣的人。</span>
<span className="v" id="v17" data-v="17" data-xref="马可福音 9:7; 马太福音 17:5; 马太福音 3:17"> 他从父神领受尊贵和荣耀的时候，从那威严的荣耀中，有这样的声音向他传来，说：<br /><span className="pl pl-1">“这是我的爱子，</span><br /><span className="pl pl-1">我所喜悦的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 17:6; 约书亚记 5:15; 出埃及记 3:5"> 这从天上传来的声音，是我们与他一起在圣山上的时候听见的，</span>
<span className="v" id="v19" data-v="19" data-xref="启示录 22:16; 以赛亚书 9:2; 诗篇 119:105"> 并且我们有先知更确切的话语。你们如果留心这些话语，把它当做照耀在暗处的灯，一直到天光破晓、晨星在你们心中升起，你们就做得很好了。</span>
<span className="v" id="v20" data-v="20" data-xref="彼得后书 3:3; 罗马书 12:6; 罗马书 6:6"> 你们首先要知道这一点：经上的一切预言都不是出于人自己的解释<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="不是出于人自己的解释——或译作“不可做出自己的解释”。">f</a></sup>；</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 3:15–17; 彼得前书 1:11; 撒母耳记下 23:2"> 因为预言从来不是藉着人的意思传来的，而是人受圣灵的感动<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="受圣灵的感动——或译作“被圣灵带领”。">g</a></sup>说出从神而来的话<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="而是人受圣灵的感动说出从神而来的话——有古抄本作“而是神的圣人受圣灵感动说出来的”。">h</a></sup>。</span>
</div>
</div>

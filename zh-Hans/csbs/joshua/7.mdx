<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 22:20; 传道书 9:18; 历代志上 2:6–7"> 然而，以色列子民违犯了当灭之物的禁令<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="的禁令——辅助词语。">a</a></sup>，犹大支派谢拉的曾孙、扎布迪的孙子、迦米的儿子亚干，取走了一些当灭之物。于是，耶和华的怒气向以色列子民发作。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="约书亚记 18:12; 何西阿书 4:15; 撒母耳记上 14:23"> 当时约书亚从耶利哥派人去艾城，在伯特利东边，靠近伯亚文。他吩咐他们说：“你们上去窥探那地。”那些人就上去窥探艾城。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="希伯来书 6:11–12; 路加福音 13:24; 彼得后书 1:5"> 他们回到约书亚那里，对他说：“不用所有人都上去，大约两三千人上去就能攻取艾城。不用劳烦所有人去那里，因为他们人很少。”</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 28:25; 利未记 26:17; 申命记 32:30"> 于是军中约有三千人上那里去，结果他们在艾城的人面前逃跑了。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 2:11; 约书亚记 2:9; 利未记 26:36"> 艾城的人击杀了他们大约三十六人，又从城门前追赶他们，直到示巴琳，在下坡那里击杀他们。军兵的心都消融如水。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 37:29; 创世记 37:34; 启示录 18:19"> 约书亚就撕裂衣服，他和以色列的长老们在耶和华约柜前脸伏于地，直到傍晚，并且把尘土撒在自己头上。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 12:5; 列王纪下 3:10; 马太福音 17:20"> 约书亚说：“唉，主耶和华啊！你为什么非要让这民众过约旦河，把我们交在亚摩利人手中，消灭我们呢？还不如让我们留在约旦河对岸。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 3:5–6; 以斯拉记 9:10; 哈巴谷书 2:1"> 哦，主啊，我还能说什么呢？以色列已经在仇敌面前转身而逃！</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 32:12; 诗篇 83:4; 以西结书 36:22–23"> 迦南人和这地所有的居民听见这事，必围攻我们，从这地上剪除我们的名。那时你为你的大名还能做什么呢？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 15:22; 出埃及记 14:15; 撒母耳记上 16:1"> 耶和华对约书亚说：“你起来吧！为什么这样脸伏于地呢？</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 5:1–2; 希伯来书 4:13; 约书亚记 6:17–19"> 以色列犯了罪！他们竟然违背我为他们立定的约，取走了当灭之物；他们竟然偷窃、哄骗，把它们放进自己的物品中。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 5:4–5; 以赛亚书 59:2; 约书亚记 6:18"> 所以，以色列子民在他们的仇敌面前站立不住；他们从仇敌面前转身而逃，是因为他们自己成了当灭之物。如果你们不把当灭之物从你们中间灭尽，我就不再与你们同在了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="耶利米哀歌 3:40–41; 约书亚记 3:5; 马太福音 7:5"> “你起来，把这民众分别为圣，吩咐他们为了明天洁净自己。因为以色列的神耶和华如此说：‘以色列啊，你们中间有当灭之物！除非把当灭之物从你们中间除掉，你们绝不能在仇敌面前站立得住。’</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 16:33; 约拿书 1:7; 约书亚记 7:17–18"> 明天早晨，你们要按着支派上前来，然后耶和华抽取的支派，要按着家族上前来；耶和华抽中的家族，要按着家庭上前来；耶和华抽中的家庭，要按着男丁上前来。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 34:7; 撒母耳记上 14:38–39; 士师记 20:6"> 最后，那个取了当灭之物而被抽出来的人，他和属于他的一切都要被火烧掉，因为他违背了耶和华的约，也因为他在以色列做了愚顽的事。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="诗篇 119:60; 约书亚记 3:1; 创世记 22:3"> 于是约书亚清早起来，让以色列人按着支派上前来，犹大支派就被抽中了。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 26:20; 历代志上 2:4–7; 创世记 38:30"> 他让犹大家上前来，然后抽中了谢拉的家族；又让谢拉家族的男丁一个个上前来，然后扎布迪被抽中了；</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 32:23; 使徒行传 5:1–10; 撒母耳记上 14:42"> 又让扎布迪家的男丁一个个上前来，结果犹大支派谢拉的曾孙、扎布迪的孙子、迦米的儿子亚干被抽出来了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 6:5; 耶利米书 13:16; 约翰福音 9:24"> 约书亚就对亚干说：“我儿啊，你要把荣耀归给耶和华以色列的神，向他认罪<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="认罪——原文直译“献上感谢”。">b</a></sup>。请告诉我你做了什么，不要向我隐瞒。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="诗篇 38:18; 约伯记 33:27; 创世记 42:21"> 亚干回答约书亚，说：“我确实对以色列的神耶和华犯了罪！我是这样做的：</span>
<span className="v" id="v21" data-v="21" data-xref="雅各书 1:15; 诗篇 119:37; 约翰一书 2:15–16"> 我看见战利品中，有一件漂亮的示拿外衣、两百谢克尔<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="两百谢克尔——相当于2,280公克。1谢克尔=11.4公克。">c</a></sup>银子、一条重五十谢克尔<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="五十谢克尔——相当于570公克。">d</a></sup>的金子，我就贪爱它们，把它们拿走了。看哪，它们都藏在我帐篷内的地里，银子在外衣底下。”</span>
<span className="v" id="v22" data-v="22"> 约书亚就派遣使者，他们跑到帐篷那里，看哪，东西果然藏在亚干的帐篷中，银子在外衣底下。</span>
<span className="v" id="v23" data-v="23"> 他们把这些东西从帐篷里拿出来，带到约书亚和全体以色列子民那里，摊放在耶和华面前。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="箴言 15:27; 提摩太前书 6:9–10; 约书亚记 7:26"> 约书亚就和全体以色列人一起带着谢拉的曾孙亚干，还有那银子、外衣、金条，以及他的儿女、牛、驴、羊，他的帐篷和属于他的一切，上到亚割谷。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 6:18; 历代志上 2:7; 利未记 24:14"> 约书亚说：“你为什么给我们带来祸患呢？今天耶和华也要给你带来祸患。”于是全体以色列人用石头把他砸死了，然后用火焚烧这一切，又把石头扔在其上。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 65:10; 何西阿书 2:15; 申命记 13:17"> 人们在他上面堆了一大堆石头，那石堆至今还在。于是耶和华收回了他猛烈的怒气。因此那地方名叫亚割谷，直到今日。</span>
</div>
</div>

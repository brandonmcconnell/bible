<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 26:29; 创世记 41:51; 创世记 50:23"> 以下是玛拿西支派抽签所得之地，玛拿西是约瑟的长子。玛拿西的长子玛吉，是基列的父亲，是个战士，他得了基列和巴珊。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 7:18; 民数记 26:29–32; 士师记 6:11"> 玛拿西其余的子孙，就是亚比以谢的子孙、希勒的子孙、亚斯列的子孙、示剑的子孙、希弗的子孙、谢米达的子孙，也按着他们的家族得了继业。这些人各按家族，都是约瑟之子玛拿西后裔的男丁。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="民数记 27:1; 民数记 26:33; 民数记 36:2–11"> 至于西罗非哈，他是希弗的儿子、基列的孙子、玛吉的曾孙、玛拿西的玄孙，他没有儿子，只有女儿，他女儿的名字是：玛拉，挪阿，霍格拉，米尔卡，提尔撒。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 14:1; 民数记 27:5–7; 加拉太书 3:28"> 她们上前来，到祭司以利亚撒和嫩的儿子约书亚，以及族长们面前，说：“耶和华曾经指示摩西，要使我们与我们的兄弟一同分得继业。”于是约书亚照着耶和华所指示的，使她们与她们父亲的兄弟一同分得继业。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 17:2–3; 民数记 32:30–42; 约书亚记 13:29–31"> 这样，除了在约旦河对岸的基列和巴珊地以外，玛拿西还抽签分得了十份地，</span>
<span className="v" id="v6" data-v="6"> 因为这些女子也与玛拿西的子孙一同得了继业。基列地属于玛拿西其余的子孙。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约书亚记 21:21; 约书亚记 20:7; 约书亚记 24:32"> 玛拿西的地界，是从亚设开始，到示剑对面的米格梅特，然后向南延伸到恩塔普阿的居民那里；</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 16:8; 约书亚记 15:34; 约书亚记 12:17"> 塔普阿地区是属于玛拿西的，只是玛拿西边界上的塔普阿城，归属以法莲子孙。</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 16:3; 约书亚记 19:29; 约书亚记 16:8–9"> 边界又下到加拿河，河流南边那些城镇在玛拿西的城镇当中，却属于以法莲；玛拿西的边界在加拿河北边，终点是大海；</span>
<span className="v" id="v10" data-v="10"> 南边属于以法莲，北边属于玛拿西，以海为边界；北边抵达亚设，东边抵达以萨迦。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 7:29; 列王纪下 9:27; 士师记 5:19"> 以萨迦和亚设境内，分给玛拿西的有：伯珊和附属的村镇，以伯莲和附属的村镇，多珥的居民和附属的村镇；还有恩多尔的居民和附属的村镇，特纳克的居民和附属的村镇，米吉多的居民和附属的村镇，三处都是高地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="三处都是高地——或译作“第三处是高地”。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="士师记 1:27–28; 出埃及记 23:29–33; 罗马书 6:12–14"> 不过玛拿西子孙不能占领这些城，迦南人坚持住在这地。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 16:10; 腓立比书 4:13; 士师记 1:35"> 当以色列人强盛的时候，就使迦南人服苦役，并没有把他们完全赶出去。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 26:34–37; 创世记 48:19; 创世记 48:22"> 约瑟子孙问约书亚说：“我们人口众多，耶和华一直这样祝福我们，你为什么只分给我们一支签、一份地为继业呢？”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="创世记 13:7; 创世记 14:5; 路加福音 12:48"> 约书亚对他们说：“既然你们人口众多，以法莲山地对你们太小，你们就上森林那里去吧，到比利洗人、利乏音人之地，在那里为自己开拓。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪上 4:12; 士师记 4:3; 士师记 1:19"> 约瑟子孙回答：“那山地也容不下我们，而且所有住在平原地区的迦南人——在伯珊和附属的村镇以及耶斯列平原的人，都有铁战车。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 约书亚就告诉约瑟家——以法莲和玛拿西，说：“你们人口众多，势力强大，不该只有一支签，</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 13:6; 罗马书 8:31; 民数记 14:6–9"> 所以那山地归属你们了。虽然它是一片森林，但你们去开拓吧，它直到尽头都必成为你们的。你们必赶出迦南人，尽管他们有铁战车，尽管他们很强大。”</span>
</div>
</div>

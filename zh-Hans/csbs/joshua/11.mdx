<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 11:10; 诗篇 2:1–4; 士师记 4:2"> 哈佐王耶宾听说了这些事，<br /><span className="pl pl-1">就派人去见玛顿王约巴、</span><br /><span className="pl pl-1">希姆仑王、阿克沙弗王，</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 12:3; 士师记 1:27; 约书亚记 17:11"> <span className="pl pl-1">还有北方山地的众王，</span><br /><span className="pl pl-1">革尼勒南边的亚拉巴、</span><br /><span className="pl pl-1">示非拉</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="亚拉巴、示非拉——或译作“流域荒滩、丘陵地带”。">a</a></sup><br /><span className="pl pl-1">、西边多珥高地的众王，</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="士师记 3:3; 约书亚记 18:26; 创世记 31:49"> <span className="pl pl-1">以及东边和西边的迦南人，</span><br /><span className="pl pl-1">山地的亚摩利人、赫提人、比利洗人、耶布斯人，</span><br /><span className="pl pl-1">黑门山脚下米斯巴地的希未人。</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士师记 7:12; 撒母耳记上 13:5; 创世记 32:12"> 于是，他们和他们的全军一起出来，有许多军兵，多如海边的沙，还有极多的战车马匹。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 118:10–12; 启示录 16:14; 以赛亚书 8:9"> 这些王都会合起来，到米伦水边一同扎营，与以色列作战。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约书亚记 10:8; 撒母耳记下 8:4; 士师记 20:28"> 耶和华对约书亚说：“不要怕他们，因为明天这个时候，我必使他们全都死在以色列面前。你要砍断他们马的蹄筋，用火烧毁他们的战车。”</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 10:9; 帖撒罗尼迦前书 5:2–3"> 于是约书亚和跟随他的全体军兵突然来到米伦水边，袭击他们。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 13:6; 约书亚记 19:28; 撒迦利亚书 9:2"> 耶和华把他们交在以色列人手中，以色列人就击杀他们，追击他们直到西顿大城、米斯利弗-玛音以及东边的米斯巴平原。以色列人击杀他们，没有留下一人存活。</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 11:6; 以西结书 39:9–10"> 约书亚照着耶和华吩咐他的处置他们，砍断他们马的蹄筋，用火烧毁了他们的战车。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约书亚记 11:1; 士师记 4:2"> 那时，约书亚又转去攻取哈佐，用刀击杀了哈佐王，因为之前哈佐是这些王国的首领。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 10:40; 申命记 20:16"> 他们把城里的人都击杀了，灭绝于刀刃之下，没有留下任何有气息的，然后放火烧毁了哈佐。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命记 20:16–17; 申命记 7:2; 民数记 33:50–53"> 约书亚征服了这些王以及他们所有的城镇，用刀击杀他们，照着耶和华的仆人摩西所吩咐的把他们灭绝净尽。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 30:18"> 只是所有坐落在高岗上的城，除了哈佐以外，以色列人都没有烧毁，约书亚只烧毁了哈佐。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 20:14; 民数记 31:9; 约书亚记 8:27"> 这些城所有的财物和牲畜，以色列人都掠夺归于自己，只把所有的人都用刀击杀了，直到除灭他们，没有留下任何有气息的。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 1:7; 出埃及记 34:11–13; 使徒行传 20:20"> 耶和华怎样指示他的仆人摩西，摩西就怎样指示约书亚，约书亚也就怎样做。耶和华所指示摩西的一切话，约书亚都没有偏离。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约书亚记 10:41; 约书亚记 11:21; 约书亚记 12:8"> 这样，约书亚夺取了那全地——就是山地、整个南地<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="南地——音译作“内盖夫”。">b</a></sup>、歌珊全地、示非拉、亚拉巴<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="示非拉、亚拉巴——或译作“丘陵地带、流域荒滩”。">c</a></sup>——以色列的山地和丘陵，</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 7:24; 约书亚记 11:3; 约书亚记 13:5"> 从往西珥上去的哈拉山，直到黑门山脚下黎巴嫩平原的巴力迦得。他征服那里所有的王，击败他们，把他们处死了。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 14:7–10; 约书亚记 11:23"> 约书亚与这些王作战，有许多日子。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 9:3–27"> 除了基遍的居民希未人以外，没有一城与以色列人讲和，都是以色列人作战夺取的。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 9:18; 申命记 20:16–17; 出埃及记 4:21"> 因为这是出于耶和华，要使他们的心刚硬，来迎战以色列，为要使他们灭绝净尽，使他们不蒙怜悯而被除灭，正如耶和华指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命记 9:2; 民数记 13:22–23; 约书亚记 15:13–14"> 那时约书亚前来剪除了亚衲人，他们分布<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="他们分布——辅助词语。">d</a></sup>在山地、希伯仑、底璧、阿纳布，以及整个犹大山地、整个以色列山地。约书亚把他们和他们的城镇灭绝净尽。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 17:4; 历代志上 18:1; 约书亚记 15:46"> 以色列人境内没有留下一个亚衲人，只在加沙、迦特和阿实突存留了一些。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约书亚记 21:44–45; 民数记 26:52–55; 约书亚记 14:1–15"> 约书亚照着耶和华所指示摩西的一切，夺取了全地，然后按照以色列的支派划分，把地分给他们为继业。于是国中太平，没有战争。</span>
</div>
</div>

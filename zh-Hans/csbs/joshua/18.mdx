<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 19:51; 撒母耳记上 1:3; 约书亚记 21:2"> 全体以色列会众聚集在示罗，把会幕安置在那里，那地已经被他们征服了。</span>
<span className="v" id="v2" data-v="2"> 以色列子民中剩下七个支派，还没有分得继业。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 18:9; 箴言 13:4; 箴言 10:4"> 约书亚对以色列子民说：“你们要拖延到什么时候，才去占有你们祖先的神耶和华所赐给你们的土地呢？</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 18:6; 约书亚记 4:2; 约书亚记 18:3"> 你们按着支派带来三个人，我要派遣他们。他们要起身走遍那地，按着各支派继业的份做记录，然后回到我这里。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 16:1–10; 约书亚记 19:1–9; 约书亚记 15:1–12"> 他们要把地分成七份；犹大留在南方自己的境内，约瑟家留在北方自己的境内。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 14:2; 约书亚记 18:10; 使徒行传 13:19"> 你们把那七份地做好记录，把记录拿到我这里来，我要在这里，在我们的神耶和华面前为你们抽签。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 13:33; 约书亚记 13:8–31; 民数记 18:20"> 利未人在你们中间没有继业的份，因为耶和华的祭司职份就是他们的继业。至于迦得、鲁本和玛拿西半支派，他们已经在约旦河东岸得了继业，是耶和华的仆人摩西分给他们的。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约书亚记 18:10; 罗马书 14:19; 撒母耳记上 14:41"> 于是，那些人起身前往。约书亚吩咐前往记录那地的人说：“你们要去，走遍那地，把它记录好，然后回到我这里来。我要在示罗，在耶和华面前为你们抽签。”</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 13:19"> 那些人就去，走遍全地，按着城镇把它分为七份，记录在册子上，然后回到示罗营地约书亚那里。</span>
<span className="v" id="v10" data-v="10" data-xref="歌罗西书 1:12; 使徒行传 13:19; 约书亚记 18:6"> 约书亚就在示罗，在耶和华面前为他们抽签。约书亚在那里，照着他们的支派划分，把土地分给了以色列子民。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约书亚记 16:1–10; 约书亚记 15:1–8; 申命记 10:1–22"> 便雅悯支派按着他们的家族抽签，他们的签抽出来，地界是在犹大子孙和约瑟子孙之间。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约书亚记 16:1; 约书亚记 7:2; 约书亚记 2:1"> 他们北面的边界是从约旦河开始，上到耶利哥北边的山坡，又往西上去，穿过山地，终点在伯亚文旷野。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 28:19; 约书亚记 16:2–3; 约书亚记 10:11"> 边界又从那里经过路斯，往南到路斯山坡，路斯就是伯特利；然后边界下到亚塔罗-亚达珥，靠近下伯贺仑南边的山。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="约书亚记 15:9; 历代志上 13:5–6; 撒母耳记上 7:1–2"> 边界又转向，从南边伯贺仑对面的山绕到西边又往南，终点是犹大子孙的城基列-巴力，就是基列-耶琳。这是西面的疆界。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约书亚记 15:9"> 南面从基列-耶琳的边缘为起点，边界往西延伸，到尼弗多亚水泉。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 23:10; 约书亚记 15:7–8; 以赛亚书 30:33"> 边界又下到欣嫩子谷对面、利乏音谷北边那座山的边缘，再下到欣嫩子谷，沿着耶布斯的南坡下到恩罗格尔；</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 15:6"> 再转向北，延伸到恩示麦，又延伸到阿杜米姆山坡对面的格利录，又下到鲁本之子波罕的磐石那里；</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 15:6; 约书亚记 15:61"> 又向北经过亚拉巴对面的山坡，下到亚拉巴流域。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 14:3; 约书亚记 15:2; 民数记 34:3"> 边界又经过伯霍格拉的北坡，边界的终点是约旦河南端盐海北边的湾汊。这是南面的边界。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 约旦河被划定为东面的疆界。<br />这就是便雅悯子孙按着他们的家族，按着他们四围的边界所得的继业。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约书亚记 18:12; 约书亚记 6:1; 约书亚记 18:19"> 便雅悯支派按着他们的家族所得的城镇有：<br />耶利哥，伯霍格拉，伊麦基悉，</span>
<span className="v" id="v22" data-v="22" data-xref="约书亚记 15:6; 列王纪上 12:29–32; 约书亚记 18:18"> 伯亚拉巴，策玛莲，伯特利，</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 13:17"> 阿维姆，帕拉，俄弗拉，</span>
<span className="v" id="v24" data-v="24" data-xref="以斯拉记 2:26; 约书亚记 21:17; 以赛亚书 10:29"> 克法阿莫尼，俄弗尼，迦巴，共十二座城，还有附属的村庄；</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 9:17; 列王纪上 3:4–5; 约书亚记 10:2"> 基遍，拉玛，比录，</span>
<span className="v" id="v26" data-v="26" data-xref="士师记 10:17; 以斯拉记 2:25; 约书亚记 9:17"> 米斯巴，克非拉，莫扎，</span>
<span className="v" id="v27" data-v="27"> 利肯，伊利培勒，塔尔阿拉，</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 21:14; 约书亚记 15:8; 士师记 20:4–5"> 洗拉，以利弗，耶布斯——就是耶路撒冷，基比亚，基列，共十四座城，还有附属的村庄。<br />这就是便雅悯子孙按着他们的家族所得的继业。</span>
</div>

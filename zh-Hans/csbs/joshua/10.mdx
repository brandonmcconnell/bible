<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 6:21; 希伯来书 7:1; 约书亚记 8:2"> 耶路撒冷王亚多尼·希德听说约书亚攻取了艾城并把它灭绝净尽，怎样处置耶利哥城和它的王，也怎样处置了艾城和它的王；也听说基遍的居民与以色列人讲和了，归附于他们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="归附于他们——原文直译“在他们当中”。">a</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 11:25; 约书亚记 2:24; 出埃及记 15:14–16"> 耶路撒冷的人就极其害怕，因为基遍是个大城，像一座王城，比艾城更大，城里的人都是勇士。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 11:9; 弥迦书 1:13; 约书亚记 10:1"> 耶路撒冷王亚多尼·希德派人去见希伯仑王霍含、雅尔慕王皮兰、拉吉王雅非亚和伊矶伦王底璧，说：</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 9:15; 约书亚记 10:1; 以赛亚书 8:9–10"> “你们上我这里来帮助我吧，我们一起攻打基遍，因为他们与约书亚和以色列人讲和了。”</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 8:9–10; 创世记 15:16; 约书亚记 10:6"> 于是亚摩利人的五个王——耶路撒冷王、希伯仑王、雅尔慕王、拉吉王、伊矶伦王聚集起来，带着他们所有的军兵上去，对着基遍扎营，攻打它。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约书亚记 9:6; 约书亚记 5:10; 申命记 1:15"> 基遍人就派人到吉甲营地去见约书亚，说：“不要袖手不顾你的奴仆，请赶快上我们这里来，拯救我们，帮助我们，因为住在山地的亚摩利诸王都聚集来攻击我们了。”</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 8:1; 以赛亚书 8:12; 以赛亚书 8:14"> 于是约书亚和跟随他的全体军兵，以及所有的英勇战士，都从吉甲上去。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="罗马书 8:31; 申命记 3:2; 诗篇 27:1–2"> 耶和华对约书亚说：“不要怕他们，因为我已经把他们交在你手中了，他们当中没有一个人能在你面前站立得住。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="传道书 9:10; 提摩太后书 2:3; 箴言 24:11–12"> 约书亚连夜从吉甲上去，突然进攻他们。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 18:14; 约书亚记 16:3; 约书亚记 16:5"> 耶和华使他们在以色列人面前溃乱，以色列人在基遍大大击杀他们，沿着伯贺仑山坡的路追赶、击杀他们，直到亚西加和玛克达。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 28:2; 士师记 5:20; 诗篇 18:12–14"> 他们从以色列人面前逃跑，正在伯贺仑的下坡那里时，耶和华从天上降下大冰雹在他们身上，直到亚西加，他们就被砸死了。那时死于冰雹的，比以色列人用刀杀死的还多。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="哈巴谷书 3:11; 以赛亚书 38:8; 以赛亚书 60:20"> 当时，就在耶和华把亚摩利人交给以色列子民的那一天，约书亚求告耶和华，他在以色列人眼前说：<br /><span className="pl pl-1">“太阳啊，停留在基遍；</span><br /><span className="pl pl-1">月亮啊，停留在阿雅仑谷！”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="哈巴谷书 3:11; 以赛亚书 38:8; 约书亚记 10:14"> 太阳就停住，月亮就站住，直到这民报复了他们的仇敌。这不都记在《雅煞尔书》<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="《雅煞尔书》——或译作“《正直人之书》”；是古以色列的诗歌集，已失传。">b</a></sup>上吗？<br /><span className="pl pl-1">太阳在天空中站住，不急于下落，</span><br /><span className="pl pl-1">大约整整一天。</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命记 1:30; 出埃及记 14:14; 约书亚记 10:42"> 这以前或者以后，耶和华都没有像这一天那样垂听人的祷告；这是耶和华在为以色列争战。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 10:43; 约书亚记 10:6"> 然后，约书亚和跟随他的以色列全军返回吉甲的营地。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 24:8; 阿摩司书 9:2; 诗篇 139:7–10"> 那五个王逃跑，躲藏在玛克达的洞穴里。</span>
<span className="v" id="v17" data-v="17"> 有人向约书亚报告说：“那五个王找到了，躲藏在玛克达的洞穴里。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 27:66; 约伯记 21:30; 阿摩司书 9:1"> 约书亚说：“把几块大石头滚到洞口，派人在洞口看守他们！</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 18:37–41; 耶利米书 8:14; 以赛亚书 9:14–15"> 你们不要停留，要追击你们的仇敌，从后面击杀他们，不让他们逃回城里，因为你们的神耶和华已经把他们交在你们手中了。”</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 8:24; 撒母耳记下 20:6; 约书亚记 10:10"> 于是，约书亚和以色列人大大击杀他们，直到把他们灭尽了，只剩下一些幸存者逃进堡垒城。这事结束之后，</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 11:7; 以赛亚书 54:17; 以赛亚书 57:4"> 全体军兵平安回到玛克达营地约书亚那里，再没有人敢对任何以色列人饶舌了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 15:32"> 约书亚说：“打开洞口，把那五个王从洞穴里给我带出来！”</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 10:1; 约书亚记 10:5; 约书亚记 10:3"> 人们就这样做，把那五个王——耶路撒冷王、希伯仑王、雅尔慕王、拉吉王、伊矶伦王，从洞穴里带出来，带到约书亚面前。</span>
<span className="v" id="v24" data-v="24" data-xref="玛拉基书 4:3; 罗马书 16:20; 启示录 2:26–27"> 当他们把那些王带到约书亚那里，约书亚就召来以色列的全体军兵，对同行的军队统帅们说：“你们上前来，把脚踏在这些王的脖子上。”他们就上前来，把脚踏在那些王的脖子上。</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多后书 1:10; 约书亚记 1:9; 以弗所书 6:10"> 约书亚对他们说：“不要害怕，不要丧胆。你们要坚强、勇敢，因为耶和华必这样处置你们所攻打的一切仇敌。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="约书亚记 8:29; 撒母耳记下 21:9; 马太福音 27:25"> 随后，约书亚处死了那五个王，把他们挂在五棵树上。他们被挂在树上，直到傍晚。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 8:29; 申命记 21:22–23; 约书亚记 7:26"> 到了日落的时候，约书亚下令，人们就把他们从树上取下来，扔进他们曾经躲藏的洞穴里，并把几块大石头堆在洞口，那石堆至今还在。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约书亚记 6:21; 申命记 7:16; 申命记 20:16–17"> 那天约书亚攻取玛克达，用刀击杀了那城和它的王，把城里的人都灭绝净尽，没有留下一人存活。他处置玛克达王，像处置耶利哥王一样。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约书亚记 21:13; 约书亚记 15:42; 耶利米书 52:1"> 约书亚和跟随他的以色列全军，又从玛克达前往立拿，攻打立拿。</span>
<span className="v" id="v30" data-v="30"> 耶和华把那城和它的王都交在以色列手中，约书亚把城里的人都用刀击杀了，没有留下一人存活。他处置立拿王，像处置耶利哥王一样。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约书亚记 10:3; 约书亚记 12:11; 约书亚记 10:5"> 约书亚和跟随他的以色列全军，又从立拿前往拉吉，对着城扎营，攻打它。</span>
<span className="v" id="v32" data-v="32"> 耶和华把拉吉交在以色列手中，约书亚在第二天就攻取了它，把城里的人都用刀击杀了，就像他对立拿所做的一切。</span>
<span className="v" id="v33" data-v="33" data-xref="约书亚记 16:10; 士师记 1:29; 约书亚记 16:3"> 那时基色王何兰上来帮助拉吉，约书亚击败了他和他的军队，没有给他留下一人存活。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="约书亚记 10:3; 约书亚记 12:12; 约书亚记 15:39"> 约书亚和跟随他的以色列全军，又从拉吉前往伊矶伦，对着城扎营，攻打它。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 26:44; 约书亚记 10:37; 约伯记 19:10"> 他们当天就攻取了它，用刀击杀那城。那一天约书亚把城里的人灭绝净尽，就像他对拉吉所做的一切。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="士师记 1:10; 约书亚记 15:13; 约书亚记 14:13–14"> 约书亚和跟随他的以色列全军，又从伊矶伦上到希伯仑，攻打它。</span>
<span className="v" id="v37" data-v="37"> 他们攻取那城，把它的王和所有附属的城镇以及其中的人都用刀击杀了，没有留下一人存活，就像他对伊矶伦所做的一切。他灭绝了那城和其中所有的人。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="约书亚记 15:15; 约书亚记 12:13; 约书亚记 15:49"> 约书亚和跟随他的以色列全军，又转向底璧，攻打它。</span>
<span className="v" id="v39" data-v="39" data-xref="俄巴底亚书 1:18; 约书亚记 11:8; 申命记 3:3"> 他攻取那城，用刀击杀它的王，击杀它所有附属的城镇，把其中的人都灭绝净尽，没有留下一人存活。他怎样处置希伯仑、处置立拿和它的王，也怎样处置底璧和它的王。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="申命记 7:2–16; 出埃及记 23:31–33; 约书亚记 8:27"> 这样，约书亚击败了那全地，就是山地、南地、丘陵<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="南地、丘陵——音译作“内盖夫、示非拉”。">c</a></sup>、山坡地带，以及他们所有的王，没有留下一人存活，他照着以色列的神耶和华所指示的，把一切有气息的都灭绝净尽。</span>
<span className="v" id="v41" data-v="41" data-xref="约书亚记 11:16; 约书亚记 15:51; 申命记 9:23"> 约书亚击败他们，从加低斯-巴尼亚直到加沙，从歌珊全地直到基遍。</span>
<span className="v" id="v42" data-v="42" data-xref="约书亚记 10:14; 诗篇 46:7; 诗篇 80:3"> 约书亚一次就征服了这些王以及他们的领土，因为是以色列的神耶和华在为以色列争战。</span>
<span className="v" id="v43" data-v="43" data-xref="约书亚记 10:15; 约书亚记 4:19; 撒母耳记上 11:14"> 然后，约书亚和跟随他的以色列全军返回吉甲营地。</span>
</div>
</div>

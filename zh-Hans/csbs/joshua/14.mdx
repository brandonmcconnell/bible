<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 34:17–29"> 以下是以色列子民在迦南地分得的继业，是祭司以利亚撒和嫩的儿子约书亚，以及以色列子孙各支派父系的首领分给他们的，</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 33:54; 民数记 34:13; 民数记 26:55–56"> 是按照耶和华藉着摩西所指示的，以抽签的方式把继业分给了九个半支派。</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 13:14; 约书亚记 13:8; 约书亚记 13:32–33"> 那时摩西已经在约旦河对岸，把继业分给了两个半支派，不过没有在他们中间给利未人分继业；</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 48:5; 历代志上 5:1–2; 民数记 35:2–8"> 约瑟子孙是两个支派，玛拿西和以法莲。利未人没有在那地分得继业，只得了城镇居住，还有附属的牧野，好安置他们的牲畜财产。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 21:2; 民数记 35:1–2"> 耶和华怎样指示摩西，以色列子民就怎样做，分配了土地。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数记 14:30; 民数记 13:6; 民数记 14:24"> 那时，犹大子孙前来吉甲见约书亚，基尼洗人耶弗尼的儿子迦勒对约书亚说：“你知道，在加低斯-巴尼亚，耶和华对神人摩西论到你和我的那些话。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 13:6; 民数记 13:26–33; 民数记 14:6–10"> 耶和华的仆人摩西派遣我从加低斯-巴尼亚去窥探这地时，我四十岁；我给他带回了发自内心的报告。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 14:24; 申命记 1:36; 民数记 13:31"> 虽然与我一同上去的兄弟们使民众的心融化，我却全心跟从耶和华我的神。</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 1:3; 申命记 1:36; 民数记 14:22–24"> 所以，摩西那天起誓说：‘你脚所踏之地必定归于你和你的子孙为继业，直到永远，因为你全心跟从耶和华我的神。’</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民数记 14:33–34; 民数记 14:30; 约书亚记 11:18"> “现在看哪，自从耶和华对摩西说了这话以来，耶和华照着他所应许的使我存活了这四十五年，这期间以色列一直走在旷野。你看，我现在八十五岁了。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 34:7; 诗篇 103:5; 申命记 31:2"> 我今天还是强壮，像摩西派遣我去的那天一样。当时我的力量怎样，如今我的力量还是怎样，能出入，能作战。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 11:33; 腓立比书 4:13; 民数记 13:33"> 所以，请你把耶和华那天所应许的这些山地分给我。你那天确实也听到了，那里有亚衲人，有高大坚固的城；但如果耶和华与我同在，我必赶出他们，正如耶和华所应许的。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="士师记 1:20; 约书亚记 22:6; 历代志上 6:55–56"> 约书亚就祝福他，把希伯仑给了耶弗尼的儿子迦勒为继业。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 14:8–9; 哥林多前书 15:58"> 因此希伯仑成为基尼洗人耶弗尼的儿子迦勒的继业，直到今日，因为他全心跟从耶和华以色列的神。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 11:23; 创世记 23:2; 约书亚记 15:13"> 希伯仑从前名叫基列-阿尔巴，阿尔巴原是亚衲人中的伟人。<br />于是国中太平，没有战争。</span>
</div>
</div>

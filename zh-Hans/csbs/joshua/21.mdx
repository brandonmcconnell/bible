<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 14:1; 约书亚记 19:51; 约书亚记 17:4"> 那时，利未人各父系的首领前来见祭司以利亚撒和嫩的儿子约书亚，以及以色列子孙各支派父系的首领，</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 18:1; 民数记 35:2–8; 马太福音 10:10"> 在迦南地的示罗对他们说：“耶和华曾藉着摩西指示，要给我们城镇居住，也为我们的牲畜提供周围的牧野。”</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 49:7; 申命记 33:8–10; 历代志上 6:54–81"> 以色列子民就照耶和华的吩咐，从自己的继业中分给利未人以下城镇和附属的牧野：</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="历代志上 6:54–60; 约书亚记 24:33; 约书亚记 21:8–19"> 第一支签为哥辖的各家族抽出来。这些利未人，祭司亚伦的子孙从犹大支派、西缅支派、便雅悯支派的产业中，抽签得了十三座城；</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 21:20–26; 出埃及记 6:16–25; 历代志上 6:66–70"> 哥辖其余的子孙，从以法莲支派各家族、但支派、玛拿西半支派的产业中，抽签得了十座城。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约书亚记 21:27–33; 历代志上 6:71–76; 出埃及记 6:16–17"> 革顺的子孙，从以萨迦支派各家族、亚设支派、拿弗他利支派，以及在巴珊的玛拿西半支派的产业中，抽签得了十三座城。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约书亚记 21:34–40; 历代志上 6:77–81; 出埃及记 6:19"> 米拉利的子孙，按着他们的家族，从鲁本支派、迦得支派、西布伦支派的产业中，得了十二座城。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约书亚记 21:3; 约书亚记 18:6; 民数记 33:54"> 这样，以色列子民照耶和华藉着摩西所指示的，把这些城和附属的牧野抽签分给了利未人。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="历代志上 6:65; 约书亚记 21:13–18"> 他们从犹大支派、西缅支派中，把以下点到名字的城分出来，</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 21:4; 民数记 3:27; 出埃及记 6:20–26"> 给利未人中哥辖各家族的亚伦子孙，因为第一支签给了他们。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 6:55; 路加福音 1:39; 撒母耳记下 5:1–5"> 以色列人给了他们犹大山地的基列-阿尔巴和四围的牧野；阿尔巴是亚衲人的祖先，基列-阿尔巴就是希伯仑。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 14:13–15; 历代志上 6:55–57"> 至于这城的田野和附属的村庄，以色列人已经给了耶弗尼的儿子迦勒为产业。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约书亚记 15:42; 约书亚记 10:29; 约书亚记 15:54"> 祭司亚伦的子孙分得了杀人者的逃城希伯仑和附属的牧野，还有立拿和附属的牧野，</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 15:48; 约书亚记 15:50; 撒母耳记上 30:27–28"> 雅提珥和附属的牧野，以实提莫和附属的牧野，</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 15:49; 约书亚记 15:51; 约书亚记 12:13"> 霍仑和附属的牧野，底璧和附属的牧野，</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 15:10; 历代志上 6:59; 约书亚记 15:55"> 阿音和附属的牧野，犹特和附属的牧野，伯示麦和附属的牧野；共九座城，都是出自这两个支派。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约书亚记 18:24–25; 约书亚记 9:3; 历代志上 6:60"> 从便雅悯支派中，他们得了基遍和附属的牧野，迦巴和附属的牧野，</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 10:30; 历代志上 6:60; 耶利米书 1:1"> 亚纳图和附属的牧野，阿勒蒙和附属的牧野，共四座城。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 作祭司的亚伦子孙总共得了十三座城，还有附属的牧野。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="历代志上 6:66; 约书亚记 21:5"> 利未人哥辖子孙的其他家族，就是哥辖其余的子孙抽签：<br />从以法莲支派中，</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 20:7; 士师记 9:1; 列王纪上 12:1"> 分得了杀人者的逃城以法莲山地的示剑和附属的牧野，还有基色和附属的牧野，</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 6:68; 约书亚记 16:3; 约书亚记 18:13–14"> 基伯先和附属的牧野，伯贺仑和附属的牧野，共四座城。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约书亚记 19:44–45"> 从但支派中，他们得了伊利特克和附属的牧野，基比顿和附属的牧野，</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 19:42; 约书亚记 10:12; 历代志上 6:69"> 阿雅仑和附属的牧野，迦特临门和附属的牧野，共四座城。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约书亚记 17:11; 士师记 5:19"> 从玛拿西半支派中，他们得了特纳克和附属的牧野，迦特临门和附属的牧野，共两座城。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 哥辖其余子孙的各家族，总共得了十座城，还有附属的牧野。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="历代志上 6:71; 申命记 1:4; 约书亚记 20:8"> 利未人各家族中革顺的子孙，<br />从玛拿西半支派中，得了杀人者的逃城巴珊的戈兰和附属的牧野，还有比施提拉和附属的牧野，共两座城。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约书亚记 19:12; 历代志上 6:72–73"> 从以萨迦支派中，得了其雄和附属的牧野，达比拉和附属的牧野，</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 10:23; 约书亚记 12:11; 约书亚记 10:3"> 雅尔慕和附属的牧野，恩干宁和附属的牧野，共四座城。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="历代志上 6:74–75; 约书亚记 19:25–28"> 从亚设支派中，得了米沙勒和附属的牧野，阿布顿和附属的牧野，</span>
<span className="v" id="v31" data-v="31" data-xref="士师记 18:21; 历代志上 6:75; 士师记 1:31"> 赫尔卡特和附属的牧野，利合和附属的牧野，共四座城。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="历代志上 6:76; 约书亚记 20:7; 约书亚记 19:37"> 从拿弗他利支派中，得了杀人者的逃城加利利的基低斯和附属的牧野，还有哈末多珥和附属的牧野，加珥坦和附属的牧野，共三座城。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 革顺人按着他们的家族，总共得了十三座城，还有附属的牧野。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="历代志上 6:77; 约书亚记 19:11; 约书亚记 21:7"> 其余的利未人，就是米拉利子孙的各家族，<br />从西布伦支派中，得了约念和附属的牧野，加珥他和附属的牧野，</span>
<span className="v" id="v35" data-v="35"> 丁拿和附属的牧野，拿哈拉和附属的牧野，共四座城。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="约书亚记 20:8; 申命记 4:43; 民数记 21:23"> 从鲁本支派中，得了比册尔和附属的牧野，雅哈兹和附属的牧野，</span>
<span className="v" id="v37" data-v="37"> 基底莫和附属的牧野，米法押和附属的牧野，共四座城。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="创世记 32:2; 列王纪上 22:3; 历代志上 6:80"> 从迦得支派中，得了杀人者的逃城基列的拉末和附属的牧野，还有玛哈念和附属的牧野，</span>
<span className="v" id="v39" data-v="39" data-xref="以赛亚书 16:8–9; 民数记 32:35; 民数记 32:1"> 希实本和附属的牧野，雅谢和附属的牧野，总共四座城。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40"> 以上是利未人其余的家族，就是米拉利子孙的各家族所有城镇，他们抽签得了十二座城。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数记 35:1–8; 申命记 33:10; 创世记 49:7"> 利未人在以色列子孙的产业中，总共得了四十八座城，还有附属的牧野。</span>
<span className="v" id="v42" data-v="42"> 这些城四围都有附属的牧野，这些城全都如此。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="创世记 13:15; 诗篇 106:42–45; 出埃及记 23:27–31"> 这样，耶和华把他起誓要赐给以色列先祖的全地，都赐给了以色列人，他们占领那地，住在其中。</span>
<span className="v" id="v44" data-v="44" data-xref="约书亚记 11:23; 希伯来书 4:9; 申命记 31:3–5"> 耶和华照着向他们先祖所起誓的一切，使他们四围安定下来。他们一切仇敌，没有一个能在他们面前站立得住，耶和华把他们的仇敌全都交在了他们手中。</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪上 8:56; 约书亚记 23:14–15; 民数记 23:19"> 耶和华对以色列家所说的一切美好应许，没有一句落空，全都应验了。</span>
</div>

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 23:2; 撒母耳记上 10:19; 创世记 33:18–19"> 约书亚把以色列众支派都招聚到示剑，召来了以色列的长老、首领、审判官和官长，他们就站在神面前。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 24:15; 以西结书 16:3; 创世记 31:30"> 约书亚对全体民众说：<br />“以色列的神耶和华如此说：<br /><span className="pl pl-1">古时你们的祖先，包括亚伯拉罕和拿鹤的父亲塔拉，住在大河</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="大河——指幼发拉底河；本章下同。">a</a></sup><br /><span className="pl pl-1">对岸，服事别的神。</span></span>
<span className="v" id="v3" data-v="3" data-xref="创世记 12:1–4; 创世记 21:2–3; 使徒行传 7:2–3"> <span className="pl pl-1">那时我把你们的祖先亚伯拉罕从大河对岸带过来，带领他走遍迦南全地，又使他后裔增多。我把以撒赐给他，</span></span>
<span className="v" id="v4" data-v="4" data-xref="创世记 36:8; 申命记 2:5; 创世记 25:24–26"> <span className="pl pl-1">又把雅各和以扫赐给以撒；我把西珥山赐给以扫为产业，而雅各和他的子孙下埃及去了。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 3:10; 出埃及记 7:1–12; 诗篇 105:26–36"> <span className="pl pl-1">我又派遣了摩西和亚伦，藉着我在埃及人当中所行的打击埃及，然后把你们领出来。</span></span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 7:36; 希伯来书 11:29; 以赛亚书 63:12–13"> <br /><span className="pl pl-1">我领你们祖先出埃及，来到了海边。埃及人带着战车和马兵，追赶你们祖先到红海。</span></span>
<span className="v" id="v7" data-v="7" data-xref="申命记 4:34; 出埃及记 14:10; 出埃及记 14:20"> <br /><span className="pl pl-1">你们祖先呼求耶和华，他就使黑暗隔在你们和埃及人之间，使海水冲来淹没他们。你们亲眼看见了我在埃及所做的，并在旷野中住了许多日子。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="民数记 21:21–35; 诗篇 135:10–11; 尼希米记 9:22"> <span className="pl pl-1">我把你们领到住在约旦河对岸的亚摩利人之地。他们与你们争战，我把他们交在你们手中，你们就拥有了那些土地，我也把他们从你们面前除灭了。</span></span>
<span className="v" id="v9" data-v="9" data-xref="士师记 11:25; 弥迦书 6:5; 民数记 22:2"> <br /><span className="pl pl-1">后来西拨的儿子摩押王巴勒起来与以色列争战，派人把比珥的儿子巴兰召来诅咒你们。</span></span>
<span className="v" id="v10" data-v="10" data-xref="申命记 23:5; 民数记 24:5–10; 以赛亚书 54:17"> <br /><span className="pl pl-1">我不愿垂听巴兰，反而使他再三祝福你们，这样我解救你们脱离了巴勒的手。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 4:10–12; 约书亚记 3:14–17; 诗篇 114:5"> <span className="pl pl-1">你们过了约旦河，来到耶利哥。耶利哥人</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="人——原文直译“主人”。">b</a></sup><br /><span className="pl pl-1">，以及亚摩利人、比利洗人、迦南人、赫提人、革迦撒人、希未人、耶布斯人，都曾与你们争战，我把他们交在你们手中。</span></span>
<span className="v" id="v12" data-v="12" data-xref="申命记 7:20; 出埃及记 23:28; 诗篇 44:3–6"> <br /><span className="pl pl-1">我派出黄蜂在你们前面，从你们面前驱逐了亚摩利人的两个王，不是用你的刀，也不是用你的弓。</span></span>
<span className="v" id="v13" data-v="13" data-xref="申命记 6:10–12; 申命记 8:7; 约书亚记 21:45"> <br /><span className="pl pl-1">我把不是你们辛劳所得的土地赐给了你们；不是你们建造的城，你们住在其中，不是你们栽种的葡萄园和橄榄园，你们得以享用。</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 12:24; 申命记 10:12; 创世记 35:2"> “所以，你们要敬畏耶和华，真诚无伪地服事他，除掉你们祖先在大河对岸和埃及所服事的神明，而服事耶和华。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 18:21; 约翰福音 6:67–68; 路得记 1:15–16"> 但如果你们不愿意服事耶和华<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="不愿意服事耶和华——原文直译“眼中看服事耶和华不好”。">c</a></sup>，你们今天就选择要服事谁吧：或是你们祖先在大河对岸所服事的神明，或是你们所住之地亚摩利人的神明。至于我和我的家，我们必服事耶和华！”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="希伯来书 10:38–39; 撒母耳记上 12:23; 罗马书 6:2"> 民众回应说：“我们绝不离弃耶和华去服事别的神！</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 19:4; 以赛亚书 63:7–14; 以赛亚书 46:4"> 因为是我们的神耶和华亲自把我们和我们的祖先从埃及地为奴之家带了上来，他在我们眼前行了那些大神迹，并且在我们所走的整个路途中、所经过的一切民族中保护了我们。</span>
<span className="v" id="v18" data-v="18" data-xref="弥迦书 4:2; 出埃及记 10:2; 诗篇 116:16"> 耶和华还从我们面前驱逐了各民族，包括住在这地的亚摩利人。所以我们也必服事耶和华，因为他是我们的神。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 5:16; 出埃及记 23:21; 诗篇 99:9"> 约书亚对民众说：“你们不能服事耶和华！因为他是圣洁的神，他是忌邪的神，他不会饶恕你们的过犯和罪恶。</span>
<span className="v" id="v20" data-v="20" data-xref="希伯来书 10:26–27; 以西结书 18:24; 历代志上 28:9"> 如果你们离弃耶和华，服事外邦的神明，那么，他在降福给你们之后，必转而降祸给你们，把你们灭绝。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及记 20:19; 以赛亚书 44:5; 申命记 5:27–28"> 民众回答约书亚：“不，我们一定要服事耶和华！”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="诗篇 119:173; 诗篇 119:11; 约伯记 15:6"> 约书亚对民众说：“你们就是自己的见证人：你们自己选择了服事耶和华！”<br />他们说：“我们是见证人！”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 6:16–18; 约书亚记 24:14; 希伯来书 12:28–29"> 约书亚说：“那么现在，你们要除掉你们当中的外邦神明，一心归向耶和华以色列的神。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出埃及记 24:7; 出埃及记 24:3; 申命记 5:27–29"> 民众回答约书亚：“我们必服事耶和华我们的神，听从他的话。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="尼希米记 9:38; 历代志下 23:16; 出埃及记 15:25"> 约书亚就在那一天为民众立约，在示剑为他们立定律例和法规。</span>
<span className="v" id="v26" data-v="26" data-xref="士师记 9:6; 创世记 35:4; 约书亚记 4:20–24"> 约书亚把这些话写在神的律法书上，又取来一块大石头，立在耶和华圣所旁的橡树下。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 19:40; 约书亚记 22:34; 约书亚记 22:27–28"> 约书亚对全体民众说：“看哪，这块石头给我们作见证，因为它听见了耶和华对我们所说的一切话。它给你们作见证，免得你们否认你们的神。”</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 2:6"> 然后约书亚遣散民众，让各人回自己的继业之地去了。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="士师记 2:8; 提摩太后书 4:7–8; 申命记 34:5"> 这些事以后，耶和华的仆人嫩的儿子约书亚死了，享年一百一十岁。</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 19:50; 士师记 2:9; 撒母耳记下 23:30"> 人们把他葬在他继业的境内，在迦实山的北边，以法莲山地的亭拿-西拉。</span>
<span className="v" id="v31" data-v="31" data-xref="士师记 2:7; 申命记 31:13; 申命记 11:2"> 约书亚在世的日子以及他死后，那些知道耶和华为以色列所行一切事的长老们还在世的日子，以色列人都服事耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="创世记 50:25; 创世记 33:19; 出埃及记 13:19"> 以色列子孙从埃及带上来的约瑟的骸骨，葬在了示剑，葬在雅各用一百个银钱从示剑之父哈莫尔的儿子们买下的那块地里，这地成为了约瑟子孙的继业。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约书亚记 22:13; 出埃及记 6:25; 以赛亚书 57:1–2"> 亚伦的儿子以利亚撒也死了，人们把他葬在他儿子非尼哈在以法莲山地分得的小山上。</span>
</div>
</div>

<span className="v" id="v1" data-v="1" data-xref="约书亚记 13:1; 约书亚记 21:44; 约书亚记 11:23"> 耶和华使以色列脱离四围一切仇敌得享安息，后来又过了许多日子，约书亚老了，上了年纪。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 24:1; 申命记 31:28; 历代志上 28:1"> 约书亚召来全体以色列人——他们的长老、首领、审判官和官长，对他们说：“我已经老了，上了年纪。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 14:14; 约书亚记 10:42; 约书亚记 10:14"> 你们的神耶和华为你们的缘故向这些国家所行的一切，你们都看见了；是耶和华你们的神，亲自为你们争战。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 13:6–7; 约书亚记 18:10; 约书亚记 13:2"> 你们看，我已经把剩下的这些国家，还有我所剪除的各国，从约旦河到日落方向的大海，都抽签分给了你们，作为你们各支派的继业。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 11:23; 约书亚记 13:6; 出埃及记 33:2"> 你们的神耶和华会亲自把他们从你们面前驱逐出去，从你们面前赶出去，你们必占有他们的土地，正如你们的神耶和华向你们所应许的。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="申命记 5:32; 申命记 28:14; 箴言 4:26–27"> “你们要格外坚强，谨守遵行摩西律法书上所记的一切，不偏离左右，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 23:13; 诗篇 16:4; 申命记 7:2–3"> 不与这些留在你们中间的民族往来。他们神的名，你们不可提起，不可指着起誓；你们不可服事那些神明，不可向它们下拜。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 10:20; 约书亚记 22:5; 申命记 13:4"> 只要紧紧跟随耶和华你们的神，正如你们至今所行的。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约书亚记 1:5; 申命记 11:23; 约书亚记 23:5"> “耶和华已经从你们面前赶出强大的民族，至今没有一个人在你们面前站立得住。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 32:30; 利未记 26:8; 申命记 3:22"> 你们一人能追赶千人，因为是你们的神耶和华照着他向你们所应许的，亲自为你们争战。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 22:5; 申命记 6:5–12; 箴言 4:23"> 所以你们要极力保守自己的灵魂，爱耶和华你们的神。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 7:3; 以西结书 18:24; 西番雅书 1:6"> 如果你们决然转离，与留在你们中间的这些民族的遗民联结，与他们通婚，彼此往来，</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 7:16; 民数记 33:55; 出埃及记 23:33"> 你们要确实知道：你们的神耶和华必不再从你们面前赶出这些民族，他们将成为你们的网罗、陷阱，成为你们肋旁的鞭子、眼中的荆棘，直到你们在你们神耶和华所赐的这美地上灭亡。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 21:33; 列王纪上 2:2; 利未记 26:3–13"> “看哪，如今我就要走世人都必走的路了。你们要全心全意认识到：你们的神耶和华向你们所说的一切美好应许，没有一句落空，全都应验在你们身上了，他的话语没有一句落空。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 28:15–68; 利未记 26:14–46; 士师记 3:8"> 你们的神耶和华对你们所说的一切美好应许，怎样应验在你们身上，耶和华也会怎样使一切祸患的事都应验在你们身上，直到把你们从你们神耶和华所赐的这美地上除灭。</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 4:25–26; 列王纪下 24:20"> 如果你们违背你们的神耶和华为你们立定的约，去服事别的神，向它们下拜，耶和华的怒气必向你们发作，你们就会从他所赐给你们的美地上迅速灭亡。”</span>
</div>

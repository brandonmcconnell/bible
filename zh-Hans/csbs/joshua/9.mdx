<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="JOS" data-book-slug="joshua" data-book-name="约书亚记" data-chapter="9" data-verses="27">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 34:6; 出埃及记 3:17; 出埃及记 23:23"> 约旦河对岸所有的王，就是在山地、丘陵地带、黎巴嫩对面大海沿岸整个地区的王——赫提人、亚摩利人、迦南人、比利洗人、希未人、耶布斯人的王，他们听见了这事，</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 16:14; 约珥书 3:9–13; 诗篇 2:1–2"> 就聚集在一起，一口同声要与约书亚和以色列人争战。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="约书亚记 10:2; 约书亚记 9:17; 撒母耳记下 21:1–2"> 基遍的居民听说了约书亚对耶利哥和艾城所做的事，</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 16:8; 马太福音 10:16; 马可福音 2:22"> 就用诡计采取行动。他们去预备了干粮，在驴背上驮着破旧的麻袋和裂开又缝补过的破旧酒囊，</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 15:22; 申命记 33:25; 申命记 29:5"> 脚上穿着补过的旧鞋，身上穿着破旧的衣服，所有预备的干粮都是干硬发霉的。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 5:10; 列王纪下 20:14; 约书亚记 9:9"> 他们前往吉甲营地，到了约书亚那里，对他和以色列人说：“我们从遥远之地而来，现在求你们与我们立约。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约书亚记 11:19; 士师记 2:2; 出埃及记 34:12"> 以色列人对这些希未人说：“或许你们就住在我们附近，那我们怎能与你们立约呢？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="申命记 20:11; 列王纪下 10:5; 约书亚记 9:11"> 他们对约书亚说：“我们是<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="是——或译作“愿作”。">a</a></sup>你的奴仆。”<br />约书亚问他们：“你们是什么人，从哪里来？”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命记 20:15; 约书亚记 9:24; 以赛亚书 55:5"> 他们回答约书亚：“你的奴仆为了你的神耶和华的名，从遥远之地而来。我们听说了他的名声和他在埃及所做的一切，</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 21:24–35; 申命记 1:4; 约书亚记 12:4"> 以及他向约旦河对岸的两个亚摩利王——希实本王西宏和亚斯他录的巴珊王欧革——所做的一切。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 9:8; 以斯帖记 8:17; 约书亚记 1:11"> 所以我们的长老和本地所有的居民对我们说：‘你们手中拿着路上用的食物，去迎见他们吧。要对他们说：我们是<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="是——或译作“愿作”。">b</a></sup>你们的奴仆，现在求你们与我们立约！’</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 9:4–5"> 我们出发来你们这里的那天，从家里预备的这干粮还是热的，现在你看，它们都干硬发霉了。</span>
<span className="v" id="v13" data-v="13"> 这些酒囊装满酒的时候还是新的，看哪，现在它们都裂开了。还有我们的这些衣服和鞋子，由于路途太遥远，现在都破旧了。”</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 3:5–6; 民数记 27:21; 历代志上 10:13–14"> 人们接过来他们的一些干粮查看<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="查看——辅助词语。">c</a></sup>，却没有请示耶和华。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 21:2; 申命记 20:10–11; 约书亚记 11:19"> 约书亚与他们讲和，并与他们立约，让他们存活；会众的领袖们也向他们起了誓。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="箴言 12:19"> 以色列人与他们立约之后，过了三天才听说他们是近邻，住在附近。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯拉记 2:25; 约书亚记 18:25–28; 约书亚记 18:14"> 于是以色列人就出发，第三天来到他们的城镇，他们的城镇是基遍、克非拉、比录、基列-耶琳。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 15:4; 撒母耳记下 21:7; 传道书 5:6"> 以色列人没有攻击他们，因为会众的领袖们已经指着以色列的神耶和华向他们起了誓。全体会众就向领袖们发怨言。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="传道书 8:2; 约书亚记 9:20; 传道书 9:2"> 众领袖对全体会众说：“我们已经指着以色列的神耶和华向他们起了誓，如今不能碰他们了。</span>
<span className="v" id="v20" data-v="20" data-xref="玛拉基书 3:5; 箴言 20:25; 提摩太前书 1:10"> 我们要这样处置他们：让他们存活，以免因我们向他们所起的誓，就有震怒临到我们。”</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 29:11; 约书亚记 9:27; 约书亚记 9:23"> 领袖们吩咐会众要让他们存活，于是他们成了给全体会众砍柴打水的人，正如领袖们向他们承诺的。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约书亚记 9:6; 约书亚记 9:16; 创世记 3:13–14"> 约书亚把基遍人召来，责问他们说：“你们怎么欺骗我们说‘我们离你们很远’？其实你们就住在我们附近。</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 9:21; 创世记 9:25–26; 约书亚记 9:27"> 如今你们是受诅咒的！你们必不会停止作奴仆，要为我神的殿作砍柴打水的人。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="申命记 20:15–17; 申命记 7:1–2; 出埃及记 23:31–33"> 他们回答约书亚说：“因为有人确切告诉过你的奴仆：你的神耶和华曾指示他的仆人摩西，要把全地赐给你们，并且要把这地所有的居民从你们面前除灭。所以，因你们的缘故，我们极其害怕失去性命，就做了这事。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 16:6; 士师记 10:15; 耶利米书 26:14"> 现在看哪，我们在你手中，你看怎样好、怎样合适，就怎样处置我们吧！”</span>
<span className="v" id="v26" data-v="26"> 于是约书亚这样处置了他们，他解救他们脱离以色列人的手，以色列人就没有杀他们。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 12:5"> 那一天，约书亚使他们在耶和华所选择的地方，为会众和耶和华的祭坛作砍柴打水的人，直到今日。</span>
</div>
</div>

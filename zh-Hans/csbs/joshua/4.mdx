<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 27:2; 约书亚记 3:17"> 所有的民完全过了约旦河之后，耶和华就对约书亚说：</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 3:12; 民数记 1:4–15; 列王纪上 18:31"> “你要从民中选出十二个人，每支派一人，</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 4:19–20; 约书亚记 3:13; 约书亚记 4:8"> 吩咐他们说：‘你们要从约旦河中，祭司们的脚所站的位置，从那里取十二块石头，随着你们带过去，安置在你们今夜的宿营地。’”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约书亚记 4:2; 马可福音 3:14–19"> 于是，约书亚召来他从以色列子民中指定的十二个人，每支派一人。</span>
<span className="v" id="v5" data-v="5"> 约书亚对他们说：“你们过去，到约旦河中你们神耶和华的约柜面前，按着以色列子民的支派数目，各人取一块石头扛在肩上，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 13:14; 约书亚记 4:21; 诗篇 44:1"> 好让这些石头在你们中间作为标记。日后如果你们的子孙问你们说：‘这些石头对你们是什么意思呢？’</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 12:14; 民数记 16:40; 出埃及记 28:12"> 你们就告诉他们：约旦河的水曾经在耶和华的约柜面前被截断；当约柜过约旦河时，约旦河的水被截断了。这些石头要给以色列子孙作记念，直到永远。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约书亚记 4:2–5; 约书亚记 1:16–18; 约书亚记 4:20"> 以色列子民就照着约书亚的吩咐做了。他们照着耶和华对约书亚所说的，按着以色列子民支派的数目，从约旦河中取了十二块石头，随着他们带过去，到宿营地把它们安置在那里。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 7:12; 士师记 1:26; 历代志下 5:9"> 约书亚又在约旦河中，在抬约柜的祭司双脚所站的位置，竖立了十二块石头，它们至今还在那里。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约书亚记 3:13; 诗篇 119:60; 箴言 27:1"> 抬约柜的祭司们一直站在约旦河中，直到耶和华指示约书亚告诉子民的一切事都完成了，正如摩西所吩咐约书亚的一切；民众很快过去了。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 3:8; 约书亚记 4:18; 约书亚记 3:17"> 全体民众完全过去之后，耶和华的约柜和祭司们也在民众面前过去了。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 32:20–32; 约书亚记 1:14"> 鲁本子孙、迦得子孙和玛拿西半支派，也都照着摩西对他们所说的，整装列队在以色列子民前面过去。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 6:11; 耶利米书 39:5; 耶利米书 52:8"> 有大约四万武装队伍准备出战，在耶和华面前过去，前往耶利哥平原。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="约书亚记 3:7; 历代志下 30:12; 列王纪上 3:28"> 那一天，耶和华在全体以色列人眼前高抬约书亚，他们在他一生的日子都敬畏他，像敬畏摩西一样。</span>
<span className="v" id="v15" data-v="15"> 耶和华对约书亚说：</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 11:19; 出埃及记 25:16–22; 约书亚记 3:3–6"> “你吩咐抬见证柜的祭司们从约旦河里上来吧。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 8:16–18; 使徒行传 16:35–39; 使徒行传 16:23"> 于是约书亚吩咐祭司们说：“你们从约旦河里上来。”</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 3:15; 历代志上 12:15; 约书亚记 3:13"> 抬耶和华约柜的祭司们从约旦河里上来，祭司们的脚掌一踏上干地，约旦河的水就流回原处，像先前那样漫过整个河岸。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约书亚记 5:9; 弥迦书 6:5; 出埃及记 12:2–3"> 一月十日，民众从约旦河上来，在耶利哥东边的吉甲扎营。</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 4:3; 约书亚记 4:8"> 约书亚把人们从约旦河中取来的那十二块石头竖立在吉甲，</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 4:6; 诗篇 145:4–7; 诗篇 105:2–5"> 然后对以色列子民说：“日后你们的子孙问他们的父亲说：‘这些石头是什么意思呢？’</span>
<span className="v" id="v22" data-v="22" data-xref="约书亚记 3:17; 以赛亚书 51:10; 以赛亚书 44:27"> 你们要教导子孙说：‘以色列曾经走干地过了这约旦河。’</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 14:21; 以赛亚书 43:16; 以赛亚书 63:12–14"> 因为你们的神耶和华在你们面前使约旦河的水干涸，直到你们过去，就像你们的神耶和华曾经所做的，他在我们面前使红海干涸，直到我们都过去。</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 106:8; 诗篇 89:13; 列王纪上 8:42–43"> 这样，地上的万民就知道耶和华的手大有能力，你们也会终生敬畏耶和华你们的神。”</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="JOS" data-book-slug="joshua" data-book-name="约书亚记" data-chapter="22" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 32:18–33; 申命记 29:7–8"> 那时，约书亚召来鲁本人、迦得人和玛拿西半支派的人，</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 1:12–18; 申命记 3:16–20; 民数记 32:20–29"> 对他们说：“你们遵守了耶和华的仆人摩西所吩咐你们的一切，也听从了我所吩咐你们的一切话。</span>
<span className="v" id="v3" data-v="3" data-xref="腓立比书 1:23–27"> 这许多日子以来直到今天，你们没有离弃你们的兄弟，而是持守了你们的神耶和华规定的职责。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 13:8; 民数记 32:18; 申命记 3:20"> 现在，你们的神耶和华已经照着他所应许的，使你们的兄弟得享安息。所以，你们返回自己的帐篷去吧，回到耶和华的仆人摩西在约旦河对岸给你们的产业之地。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 22:37; 出埃及记 20:6; 罗马书 8:28"> 只是要特别谨慎，遵行耶和华的仆人摩西所吩咐你们的诫命和律法，爱耶和华你们的神，走在他的一切道路上，遵守他的诫命，紧紧跟随他，全心、全灵服事他。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约书亚记 14:13; 路加福音 24:50; 创世记 47:7"> 然后约书亚祝福他们，让他们回去，他们就回自己的帐篷去了。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 17:1–12; 民数记 32:33; 约书亚记 13:29–31"> 摩西已经在巴珊给了玛拿西半支派产业；另外的半支派，约书亚在约旦河西岸使他们与他们的兄弟一同得了产业。约书亚让他们回自己的帐篷时，祝福了他们，</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 31:27; 申命记 8:9–14; 箴言 3:16"> 并吩咐他们说：“你们带着大量财物，极多的牲畜，金、银、铜、铁，极多的衣裳，回自己的帐篷去吧，也要与你们的兄弟分享从仇敌夺来的战利品。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数记 32:29; 民数记 32:26; 民数记 32:1"> 鲁本子孙、迦得子孙和玛拿西半支派的人就回去，离开迦南地的示罗，离开以色列子孙，回到基列地，就是他们照耶和华藉着摩西所指示而分得的产业之地。</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 24:26–27; 创世记 31:46–52; 约书亚记 4:5–9"> 他们来到迦南地的约旦河地带，鲁本子孙、迦得子孙和玛拿西半支派的人就在约旦河旁边筑了一座祭坛，那祭坛很壮观。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="申命记 13:12–14; 利未记 17:8–9; 约书亚记 2:7"> 以色列子民听到消息<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="消息——辅助词语。">a</a></sup>说：“看哪，鲁本子孙、迦得子孙和玛拿西半支派的人，在迦南地对岸的约旦河地带，在以色列子民的对面筑了一座祭坛。”</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 20:1–11; 申命记 13:15; 加拉太书 4:17–18"> 以色列子民听到了，全体以色列会众就聚集在示罗，要上去与他们争战。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 25:7; 诗篇 106:30–31; 出埃及记 6:25"> 以色列子民派遣以利亚撒的儿子祭司非尼哈，到基列地去见鲁本子孙、迦得子孙和玛拿西半支派的人；</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 1:4; 出埃及记 18:25"> 还有十个领袖与他同去，以色列每支派中一个父家领袖，每一个都是以色列千军的父家首领。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 21:3; 撒母耳记上 15:23; 申命记 30:17"> 他们来到基列地鲁本子孙、迦得子孙和玛拿西半支派那里，与他们讲论说：</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 12:13–14"> “耶和华的全体会众如此说：这是何等不忠的事啊！你们如今转离不跟从耶和华，不忠于以色列的神，你们如今为自己筑祭坛，背叛了耶和华。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 25:1–18; 诗篇 106:28–29; 申命记 4:3–4"> 我们在毗珥的罪孽还不够吗？当时瘟疫临到了耶和华的会众，而我们至今还没有洗净这罪孽。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 16:22; 约书亚记 22:16; 约书亚记 7:11"> 你们今天竟然转离不跟从耶和华！今天如果你们背叛耶和华，明天他就会对全体以色列会众发怒。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 18:1; 历代志下 11:16–17; 使徒行传 10:14–15"> 如果你们的产业之地真是不洁净的，你们可以过来，到耶和华的产业之地——耶和华的帐幕所安置的地方，在我们中间得产业；但绝不要背叛耶和华，不要背叛我们，在我们的神耶和华的祭坛以外为自己筑祭坛！</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 7:1; 约书亚记 7:5; 约书亚记 7:18"> 谢拉的曾孙亚干难道不是违犯了当灭之物的禁令<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="的禁令——辅助词语。">b</a></sup>，以致震怒临到了全体以色列会众吗？因他罪孽而死的，不只他一个人哪！”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="雅各书 1:19; 箴言 16:1; 彼得前书 3:15"> 鲁本子孙、迦得子孙和玛拿西半支派的人，回答以色列千军的首领们说：</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 8:39; 诗篇 44:21; 申命记 10:17"> “大能者神耶和华！大能者神耶和华！他是知道的，愿以色列也知道。我们如果是叛逆，如果是对耶和华不忠，今天就不要饶过我们<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="饶过我们——或译作“让我们得拯救”。">c</a></sup>！</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 20:16; 申命记 18:19; 以西结书 3:18"> 我们筑祭坛如果是要转离不跟从耶和华，如果是要在坛上献燔祭、素祭，或是献上平安祭，就愿耶和华亲自追讨！</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 4:6; 申命记 6:20; 创世记 30:33"> 我们做这事实在是有原因的，是出于忧虑，心想日后你们的子孙会对我们的子孙说：‘你们与以色列的神耶和华有什么相干呢？</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 12:16; 以斯拉记 4:2–3; 撒母耳记上 26:19"> 耶和华在我们与你们鲁本子孙、迦得子孙之间划定了约旦河为界限，你们与耶和华无份。’这样，你们的子孙就使我们的子孙不再敬畏耶和华了。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> “所以我们说：‘让我们行动，为自己筑一座祭坛吧。’这不是为献燔祭，也不是为献祭物，</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 24:27; 创世记 31:48; 申命记 12:17–18"> 而是要它在我们和你们之间，以及在我们的后代之间作见证，好让我们到耶和华面前用我们的燔祭、祭物和平安祭来服事他，以免日后你们的子孙对我们的子孙说：‘你们与耶和华无份。’</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 25:40; 以西结书 43:10–11; 希伯来书 8:5"> 我们想，日后如果他们对我们或我们的后代这样说，我们就可以回答：‘你们看我们祖先所筑的耶和华祭坛的样式，它不是为献燔祭，不是为献祭物，而是要在我们和你们之间作见证。’</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 24:16; 申命记 12:13–14; 约书亚记 22:23"> 我们如今绝不是要背叛耶和华，转去不跟从耶和华，在我们神耶和华的帐幕前的祭坛以外，筑祭坛献燔祭、素祭和其他祭物。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约书亚记 22:33; 以斯帖记 1:21; 箴言 15:1"> 祭司非尼哈和会众的领袖们，就是与他同去的以色列千军的首领，听见鲁本子孙、迦得子孙和玛拿西子孙所说的话，这在他们眼中看为好。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志下 15:2; 利未记 26:11–12; 以赛亚书 12:6"> 以利亚撒的儿子祭司非尼哈就对鲁本子孙、迦得子孙和玛拿西子孙说：“今天我们知道：耶和华就在我们当中，因为你们没有对耶和华行这不忠的事。现在你们救了以色列子民脱离耶和华的手。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="约书亚记 22:12–14; 箴言 25:13"> 于是，以利亚撒的儿子祭司非尼哈和领袖们离开了鲁本子孙和迦得子孙，从基列地回到迦南地以色列子民那里，把这话带给他们。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志上 29:20; 路加福音 2:28; 但以理书 2:19"> 这事在以色列子民眼中看为好，以色列子民就颂赞神，不再说要上去攻打他们，毁灭鲁本子孙、迦得子孙的居住地了。</span>
<span className="v" id="v34" data-v="34" data-xref="约书亚记 22:27; 马太福音 4:10; 以赛亚书 43:10"> 于是鲁本子孙和迦得子孙给那坛起名，说“这坛在我们之间见证：耶和华是神”。</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="JOS" data-book-slug="joshua" data-book-name="约书亚记" data-chapter="8" data-verses="35">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 1:9; 申命记 7:18; 申命记 1:21"> 耶和华对约书亚说：“不要害怕，不要丧胆。你要带领全体军兵，起来上艾城去。你看，我已经把艾城的王和他的子民、他的城、他的领土都交在你手中了。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 20:14; 约书亚记 6:21; 历代志下 20:22"> 你怎样处置耶利哥和它的王，也要怎样处置艾城和它的王；唯有城里的财物和牲畜，你们可以掠夺归于自己。你要在城的后面设下伏兵。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马太福音 24:39; 马太福音 25:6; 帖撒罗尼迦前书 5:2"> 于是约书亚和全体军兵起来，要上艾城去。约书亚挑选了三万英勇的战士，夜间派出他们。</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 20:29; 约书亚记 8:16; 士师记 20:36"> 约书亚吩咐他们说：“看，你们要埋伏在城的后面，不要离城太远；你们全都要做好准备。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 7:5; 马太福音 10:16; 士师记 20:31–33"> 我与跟随我的所有军兵将上前攻城，当他们像先前那样出来迎战我们时，我们就从他们面前逃走。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 20:32; 出埃及记 15:9; 传道书 8:11"> 他们必出来追赶我们，直到我们引诱他们远离那城，因为他们会想：‘这些人像先前那样在我们面前逃跑了！’我们在他们面前逃跑时，</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 21:30–31; 列王纪下 5:1; 约书亚记 8:1"> 你们要从埋伏的地方起来，占领那城，你们的神耶和华必把它交在你们手中。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 13:28; 约书亚记 1:16; 约书亚记 1:9"> 你们攻取那城之后，要放火烧城。你们要照着耶和华的话行事，看，我已经吩咐你们了。”</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 7:2; 创世记 12:8; 以斯拉记 2:28"> 约书亚派出他们，他们就到埋伏的地方去，潜伏在艾城的西边，伯特利和艾城之间。那天晚上，约书亚在军兵中间过夜。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约书亚记 6:12; 诗篇 119:60; 创世记 22:3"> 第二天清晨，约书亚早早起来，数点了军兵，他和以色列的长老们就率领军兵上艾城去。</span>
<span className="v" id="v11" data-v="11"> 所有跟随他的军兵都上去，向前逼近，来到城的对面，在艾城北边扎营。他们与艾城之间，隔着一个山谷。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 8:2–3"> 约书亚选出大约五千人，安排他们埋伏在艾城的西边，伯特利和艾城之间。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 8:12; 约书亚记 8:8"> 这样，他们安置好了军兵，整个军队在城北，侧翼在城西。那天夜里，约书亚进了山谷。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 24:39; 士师记 20:34–36; 申命记 1:1"> 艾城的王看见了这情况，城里的人就清早急忙起来，出去迎战以色列人。他和他的全军到了面向亚拉巴荒原的约战之处，并不知道城后有埋伏。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 18:12; 约书亚记 16:1; 士师记 20:36"> 约书亚和全体以色列人在他们面前假装败退，往旷野的方向逃跑。</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 20:31; 士师记 20:36–39; 约书亚记 8:5–6"> 城里的所有军兵都被召去追赶，他们追赶约书亚，就被引诱远离了那城。</span>
<span className="v" id="v17" data-v="17" data-xref="约伯记 5:13; 约书亚记 8:3; 以赛亚书 19:11–13"> 艾城和伯特利城中，没有一个人留下不去追赶以色列的。他们撇下城任其敞开，去追赶以色列。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约书亚记 8:26; 约伯记 15:25; 撒母耳记上 17:41"> 那时耶和华对约书亚说：“伸出你手中的标枪指向艾城！我要把城交在你手中了。”约书亚就伸出他手中的标枪指向那城。</span>
<span className="v" id="v19" data-v="19"> 他一伸出手，伏兵就从原处迅速起来冲上去，进城攻取了它，并立刻放火烧城。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="诗篇 76:5; 约伯记 11:20; 创世记 19:28"> 艾城的人回头一看，看哪，城中浓烟向天上腾，他们无论往哪个方向都无法逃脱，因为那些逃往旷野的军兵，现在转身攻击追来的人。</span>
<span className="v" id="v21" data-v="21"> 约书亚和以色列全军看见伏兵已经攻取那城，城中浓烟上腾，他们就返回击杀艾城的人。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 7:2; 约书亚记 10:28; 约书亚记 6:21"> 伏兵也从城里出来夹击，这样艾城的人就在以色列人中间腹背受敌。他们被击杀，没有留下一人存活或逃脱。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 15:8; 约书亚记 10:17; 启示录 19:20"> 以色列人活捉了艾城的王，把他带到约书亚那里。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约书亚记 11:10–14; 约书亚记 10:30–41; 民数记 21:24"> 以色列人在田野和旷野杀尽了所有出来追击他们的艾城居民，这些人全都倒在刀刃之下，直到灭尽了。然后以色列全军回到艾城，用刀击杀城里的人。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 20:16–18"> 那一天倒毙的，无论男女，共有一万两千人，是艾城所有的人。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 17:11–12; 约书亚记 8:18"> 约书亚一直没有收回他伸出标枪的那只手，直到灭绝艾城所有的居民。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 8:2; 民数记 31:26; 诗篇 50:10"> 唯有城里的牲畜和财物，以色列人掠夺归于自己，正如耶和华所吩咐约书亚的话。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命记 13:16; 耶利米书 49:2; 列王纪下 19:25"> 约书亚烧毁了艾城，使它成为永远的废堆，荒凉直到今日。</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 7:26; 撒母耳记下 18:17; 申命记 21:22–23"> 他把艾城的王挂在树上，直到傍晚时分。日落的时候，约书亚下令，人们就把他的尸体从树上取下来，扔在城门口那里，上面堆了一大堆石头，那石堆至今还在。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="申命记 27:4–6; 出埃及记 20:24; 创世记 12:7–8"> 那时，约书亚在以巴录山上，为以色列的神耶和华筑了一座祭坛。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 27:5–7; 出埃及记 20:24–25; 约书亚记 8:34–35"> 这祭坛是照着耶和华的仆人摩西所吩咐以色列子民的，照着摩西律法书上所记的，用完整的石头筑成，其上没有动过铁器。他们在这坛上向耶和华献了燔祭，又献上平安祭。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 27:2–3; 申命记 27:8"> 约书亚在那里，当着以色列子民的面，把摩西写下的律法，刻了一份副本在石头上。</span>
<span className="v" id="v33" data-v="33" data-xref="申命记 11:29; 申命记 31:12; 申命记 31:9"> 全体以色列人，无论是外人还是本族人，都与他们的长老、官长、审判官一起站在约柜两旁，在抬耶和华约柜的利未祭司面前，一半对着基利心山，一半对着以巴录山，照着耶和华的仆人摩西先前所吩咐的，祝福以色列子民。</span>
<span className="v" id="v34" data-v="34" data-xref="尼希米记 8:2–3; 尼希米记 13:1; 申命记 31:10–12"> 然后，他又照着律法书上所记的一切，宣读了律法上有关祝福和诅咒的一切话语。</span>
<span className="v" id="v35" data-v="35" data-xref="申命记 31:12; 尼希米记 8:2; 耶利米书 26:2"> 约书亚在以色列全体会众面前，包括女人、孩童以及他们当中往来的寄居者，把摩西所吩咐的一切话语都宣读了，没有漏下一句<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="都宣读了，没有漏下一句——原文直译“没有一句不向他们宣读的”。">a</a></sup>。</span>
</div>

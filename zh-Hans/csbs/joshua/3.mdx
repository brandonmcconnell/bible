<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 2:1; 马可福音 1:35; 民数记 25:1"> 约书亚清早起来，与全体以色列人从什亭出发，来到约旦河。过去之前，他们在那里安营。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 1:10–11"> 过了三天，官长们走遍营中，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 31:9; 撒母耳记下 6:13; 申命记 31:25"> 吩咐民众说：“你们看见你们神耶和华的约柜，以及抬约柜的利未祭司时，就要从自己的地方出发，跟随约柜前行；</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 89:7; 希伯来书 12:28–29; 出埃及记 3:5"> 只是你们和约柜之间要保持距离，相隔大约两千肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="两千肘——相当于914公尺。1肘=45.7公分。">a</a></sup>，不可靠近它。这样你们就知道当走的路，因为你们从未走过这条路。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约书亚记 7:13; 利未记 20:7; 约珥书 2:16"> 约书亚对民众说：“你们要把自己分别为圣，因为明天耶和华要在你们中间行奇妙的事。”</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 14:2–3; 民数记 14:15; 弥迦书 2:13"> 约书亚又对祭司说：“你们要抬起约柜，在民众前面过去。”他们就抬起约柜，走在民众的前面。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约书亚记 4:14; 约书亚记 1:5; 历代志上 29:25"> 耶和华对约书亚说：“从今天开始，我要在全体以色列人眼前高抬你，好让他们知道，我怎样与摩西同在，也怎样与你同在。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 3:3; 约书亚记 3:17; 历代志下 29:15"> 你要吩咐抬约柜的祭司说：‘你们来到约旦河水边时，要停在约旦河中。’”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命记 4:1; 申命记 12:8"> 于是约书亚对以色列子民说：“你们上前来，听你们的神耶和华的话语，”</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 7:1; 出埃及记 33:2; 诗篇 44:2–3"> 约书亚说，“你们藉此就知道：永生的神就在你们中间，他必从你们面前赶出迦南人、赫提人、希未人、比利洗人、革迦撒人、亚摩利人和耶布斯人。</span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亚书 6:5; 撒迦利亚书 4:14; 诗篇 24:1"> 看哪，全地之主的约柜就要在你们前面过去，进入约旦河了。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 4:2; 约书亚记 4:9; 约书亚记 4:4"> 现在，你们要从以色列众支派选出十二个人，每支派一人。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 15:8; 诗篇 78:13; 约书亚记 3:15–16"> 那些扛抬全地之主耶和华约柜的祭司，脚掌一踏进约旦河水，约旦河从上游流下的水就会被截断，立起成垒。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="使徒行传 7:44–45; 约书亚记 6:6; 哥林多前书 1:24–25"> 于是，民众从自己的帐篷那里出发，要过约旦河，那时抬约柜的祭司走在民众前面。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 12:15; 约书亚记 4:18; 约书亚记 3:13"> 通常在收割的时候，约旦河水都会漫过整个河岸。当他们抬着约柜来到约旦河，抬约柜的祭司们脚一沾到水边，</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 3:13; 列王纪上 4:12; 列王纪上 7:46"> 从上游流下的水就停住了，远远在撒拉坦旁边的亚当城那里立起成垒。往亚拉巴海，就是往盐海流下去的水，完全被截断了。这样，民众在耶利哥对面过了河。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 14:22; 出埃及记 14:29; 诗篇 66:6"> 抬耶和华约柜的祭司们在约旦河中的干地上稳稳站住，全体以色列人就从干地上过去，直到所有的民完全过了约旦河。</span>
</div>
</div>

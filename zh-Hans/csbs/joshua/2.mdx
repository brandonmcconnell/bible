<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="JOS" data-book-slug="joshua" data-book-name="约书亚记" data-chapter="2" data-verses="24">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 11:31; 雅各书 2:25; 马太福音 1:5"> 那时嫩的儿子约书亚从什亭暗中派出两个人作探子，说：“你们去，察看那地和耶利哥。”他们就去了。他们来到一个名叫拉合的妓女家，就在那里住下。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 43:13; 但以理书 4:35; 箴言 21:30"> 有人告诉耶利哥王说：“看哪，今夜有人从以色列人那边来到这里了，要窥探这地。”</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 10:3; 创世记 42:9–12; 使徒行传 12:6"> 耶利哥王就派人到拉合那里，说：“把那些来到你这里，进了你家的人交出来！因为他们是来窥探全地的。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 6:19; 撒母耳记下 17:19–20; 撒母耳记下 16:18–19"> 但那妇人已经把两人带去藏了起来。她回答：“那些人确实来过我这里，但我不知道他们来自哪里。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 50:20; 以西结书 47:12; 启示录 21:25"> 天黑关城门的时候，那些人出去了，我也不知道他们去了哪里。你们赶快追他们吧，一定能追上。”</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 11:23; 雅各书 2:25; 歌罗西书 3:3"> 其实她把他们带上了屋顶，藏在屋顶上摆放的亚麻秆中。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 3:28; 约书亚记 2:5; 士师记 12:5"> 追赶他们的人朝着约旦河的方向，往渡口追去。追赶的人一出城，城门就关上了。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 他们睡下之前，那妇人上了屋顶到他们那里，</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 23:27; 申命记 2:25; 约书亚记 2:11"> 对这二人说：“我知道耶和华已经把这地赐给你们了，并且对你们的恐惧笼罩了我们，这地所有的居民都因你们的缘故而心融胆丧。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 21:21–35; 出埃及记 15:14–16; 出埃及记 14:21–31"> 因为我们听说了你们出埃及时，耶和华怎样在你们面前使红海的水干涸，以及你们怎样处置约旦河对岸那两个亚摩利王西宏和欧革，把他们灭绝净尽。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 4:39; 约书亚记 5:1; 约书亚记 7:5"> 我们听了，心就消融。因你们的缘故，人人再也提不起勇气，因为耶和华你们的神，他是天上地上的神。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 2:18; 约书亚记 9:18–20; 提摩太后书 1:16–18"> 所以，现在请你们指着耶和华向我起誓：既然我以恩慈对待了你们，你们也要以恩慈对待我的父家；也请给我一个信实的凭据，</span>
<span className="v" id="v13" data-v="13"> 使我的父母、兄弟、姐妹，以及所有属于他们的人得以存活，救我们的性命免于死亡。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 5:7; 士师记 1:24–25; 创世记 24:49"> 二人回答妇人：“你们如果不泄漏我们这事，我们就以生死来担保你们。当耶和华把这地赐给我们的时候，我们必以恩慈和真诚对待你。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行传 9:25; 哥林多后书 11:33; 约书亚记 6:20"> 于是妇人用绳子把他们从窗口缒下去，因为她的房屋就在城墙上，她住在城墙上。</span>
<span className="v" id="v16" data-v="16" data-xref="雅各书 2:25; 撒母耳记上 23:14; 诗篇 11:1"> 她对他们说：“你们往山上去，免得追赶的人遇见你们。你们在那里躲藏三天，等追赶的人回来，然后再上路。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民数记 30:2; 撒母耳记下 21:7; 创世记 24:3–8"> 二人对她说：“你要这样做，否则，你让我们起的这誓就与我们无干了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你要这样做，否则，你让我们起的这誓就与我们无干了——原文直译“对于你让我们起的这誓，我们必清白”。">a</a></sup>：</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 6:23; 约书亚记 2:21; 约书亚记 2:12–13"> 看哪，我们来到这地的时候，你要把这根朱红的线绳系在你缒我们下去的窗户上，并且把你的父母、兄弟以及你的整个父家都聚集到你这房屋里。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 27:31; 列王纪上 2:36–42; 出埃及记 12:13"> 任何人走出你的家门到外面去，他的血债都要归在自己头上，与我们无干；但任何人与你一起在房屋里，如果有人对他下手，他的血债就归在我们头上。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 11:13"> 此外，你如果泄漏我们这事，你让我们起的誓也就与我们无干了。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约翰福音 2:5; 约书亚记 2:18; 马太福音 7:24"> 妇人说：“就照你们的话做吧。”于是她送走他们。他们走后，她把朱红的线绳系在窗户上。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 19:10–12; 撒母耳记下 17:20; 诗篇 32:6–7"> 他们离开，来到山上，在那里停留了三天，直到追赶的人回去。追赶的人一路寻找，都没有找到。</span>
<span className="v" id="v23" data-v="23"> 二人返回，下了山，过河来到嫩的儿子约书亚那里，向他讲述了他们遇见的一切事。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 23:31; 约书亚记 1:8; 约书亚记 2:9–11"> 他们对约书亚说：“耶和华确实把那全地交在我们手中了，并且那地的居民都因我们的缘故而心融胆丧。”</span>
</div>
</div>

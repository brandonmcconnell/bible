<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 26:55–56; 约书亚记 14:2; 民数记 33:36–37"> 犹大支派按着家族抽签所得之地，是在最南边，到以东的边界，往南到寻的旷野。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="创世记 14:3; 以西结书 47:8; 以赛亚书 11:15"> 南面的边界是从盐海下端南边的湾汊开始，</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 34:4; 士师记 1:36; 民数记 20:1"> 往南穿过阿克拉宾斜坡，沿着寻的旷野，从加低斯-巴尼亚南边上去，经过希斯伦，上到阿达尔，绕到卡尔卡，</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 34:5; 约书亚记 13:3; 出埃及记 23:31"> 又经过阿兹蒙，沿着埃及河下去，边界的终点是大海。这就是他们南面的边界。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民数记 34:12; 约书亚记 18:15–19; 民数记 34:10"> 东面的边界是盐海，直到约旦河的南端。<br />北面的边界从约旦河南端的湾汊开始，</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 18:17; 约书亚记 18:19–21"> 上到伯霍格拉，经过伯亚拉巴的北边，然后上到鲁本之子波罕的磐石那里。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 1:9; 撒母耳记下 17:17; 约书亚记 7:26"> 边界又从亚割谷上到底璧，往北转到阿杜米姆山坡对面、溪谷南边的吉甲；然后边界经过恩示麦水泉，终点是恩罗格尔。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 18:16; 约书亚记 15:63; 约书亚记 18:28"> 边界又从欣嫩子谷上到耶布斯的南坡——耶布斯就是耶路撒冷，然后上到西边欣嫩子谷对面、利乏音谷北端的山顶。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 13:6; 约书亚记 18:15; 士师记 18:12"> 边界又从山顶转向尼弗多亚水泉，穿过以弗仑山的城镇，然后转到巴阿拉，就是基列-耶琳。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 14:1; 士师记 14:5; 创世记 38:12–13"> 边界又从巴阿拉往西绕到西珥山，经过耶琳山的北坡——也就是克撒仑；然后下到伯示麦，经过亭拿。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 15:45; 列王纪下 1:2–3; 撒母耳记上 5:10"> 边界又延伸到以革伦的北坡，然后转向希克仑，经过巴阿拉山，延伸到雅比聂；边界的终点是大海。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="民数记 34:6–7; 约书亚记 15:47; 以西结书 47:20"> 西面的边界是大海和海岸线。<br /><span className="pl pl-1">以上是犹大子孙各家族四围的边界。</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 13:30; 申命记 1:34–36; 民数记 14:23–24"> 约书亚照着耶和华的吩咐，把犹大子孙当中的一份地——基列-阿尔巴——分给了耶弗尼的儿子迦勒；基列-阿尔巴就是希伯仑，阿尔巴是亚衲人的祖先。</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 1:20; 士师记 1:10; 民数记 13:22–23"> 迦勒从那里赶出三支亚衲子孙——示筛、亚希幔、塔尔迈，都是亚衲人的后裔。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 10:38; 约书亚记 10:3; 士师记 1:11–13"> 他又从那里上去攻打底璧的居民，底璧从前名叫基列西弗。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="士师记 1:12–13; 士师记 1:6"> 迦勒说：“谁攻打基列西弗，攻取那城，我就把女儿娅撒嫁给他为妻。”</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 3:9; 士师记 1:13; 约书亚记 14:6"> 迦勒的弟弟基纳斯的儿子俄陀聂攻取了那城，迦勒就把女儿娅撒嫁给他为妻。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 24:64; 撒母耳记上 25:23"> 娅撒出嫁的时候，鼓动丈夫从她父亲那里求一块田。她下了驴，迦勒问她：“你有什么事呢？”</span>
<span className="v" id="v19" data-v="19" data-xref="士师记 1:14–15; 撒母耳记上 25:27; 申命记 33:7"> 她就说：“求你给我一个祝福：你既然把南地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="南地——音译作“内盖夫”。">a</a></sup>给了我，请你把水泉也给我。”于是迦勒把上泉和下泉都给了她。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 49:8–12; 申命记 33:7"> 以下是犹大支派按着他们的家族所得的继业：</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 35:21; 尼希米记 11:25"> 犹大支派最南边靠近以东边界的城镇，有卡布策勒，伊德，雅古尔，</span>
<span className="v" id="v22" data-v="22"> 基拿，底摩拿，亚大达，</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 12:22; 民数记 33:37; 申命记 1:19"> 基低斯，哈佐，伊特楠，</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记上 23:14; 撒母耳记上 23:24; 撒母耳记上 23:19"> 西弗，特勒姆，比亚录，</span>
<span className="v" id="v25" data-v="25"> 哈佐-哈达特，加略-希斯伦——就是哈佐，</span>
<span className="v" id="v26" data-v="26" data-xref="历代志上 4:28"> 亚曼，示玛，莫拉达，</span>
<span className="v" id="v27" data-v="27" data-xref="尼希米记 11:26"> 哈萨伽达，赫示蒙，伯帕列，</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 26:33; 历代志上 4:28; 创世记 21:31–33"> 哈萨书尔，比尔-谢巴，比斯犹提亚，</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 15:9–11; 约书亚记 19:3; 历代志上 4:29"> 巴阿拉，伊音，埃曾，</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 19:4; 民数记 14:45; 申命记 1:44"> 伊利多拉，克希尔，霍尔玛，</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记上 27:6; 撒母耳记上 30:1; 历代志上 12:1"> 洗革拉，玛德曼纳，叁叁纳，</span>
<span className="v" id="v32" data-v="32" data-xref="民数记 34:11; 尼希米记 11:29"> 利巴奥，希津，阿音，临门，总共二十九座城，还有附属的村庄。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="士师记 13:25; 士师记 16:31; 民数记 13:23"> 在丘陵地带，有以实陶，佐拉，亚实拿，</span>
<span className="v" id="v34" data-v="34" data-xref="约书亚记 12:17; 约书亚记 15:53"> 撒挪亚，恩干宁，塔普阿，恩纳因，</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记上 17:1; 撒母耳记上 22:1; 约书亚记 10:3"> 雅尔慕，亚杜兰，梭哥，亚西加，</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳记上 17:52"> 沙拉音，阿迪塔音，格德拉（格德罗塔音），共十四座城，还有附属的村庄。</span>
<span className="v" id="v37" data-v="37"> 策楠，哈达沙，米格达-迦得，</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪下 14:7; 士师记 20:1; 撒母耳记上 10:17"> 迪勒安，米斯巴，约克帖，</span>
<span className="v" id="v39" data-v="39" data-xref="约书亚记 10:3; 列王纪下 22:1; 约书亚记 10:31–32"> 拉吉，波斯加，伊矶伦，</span>
<span className="v" id="v40" data-v="40"> 卡本，拉玛斯，其特利示，</span>
<span className="v" id="v41" data-v="41" data-xref="约书亚记 10:21; 约书亚记 12:16; 约书亚记 10:10"> 格德罗，伯大衮，拿玛，玛克达，共十六座城，还有附属的村庄。</span>
<span className="v" id="v42" data-v="42" data-xref="约书亚记 10:29; 列王纪下 8:22; 约书亚记 19:7"> 立拿，伊特尔，阿珊，</span>
<span className="v" id="v43" data-v="43"> 耶弗塔，亚实拿，尼茨布，</span>
<span className="v" id="v44" data-v="44" data-xref="创世记 38:5; 弥迦书 1:14–15; 撒母耳记上 23:1–14"> 基伊拉，阿克济，玛利沙，共九座城，还有附属的村庄。</span>
<span className="v" id="v45" data-v="45" data-xref="约书亚记 13:3; 阿摩司书 1:8; 撒母耳记上 6:17"> 以革伦和附属的村镇、村庄；</span>
<span className="v" id="v46" data-v="46" data-xref="历代志下 26:6; 阿摩司书 1:8; 撒母耳记上 5:1"> 从以革伦直到大海，所有靠近阿实突边界的城镇，以及附属的村庄；</span>
<span className="v" id="v47" data-v="47" data-xref="约书亚记 15:4; 出埃及记 23:31; 阿摩司书 1:6–7"> 阿实突和附属的村镇、村庄；加沙和附属的村镇、村庄；直到埃及河、大海和海岸线。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="约书亚记 21:14"> 在山地，有沙米尔，雅提珥，梭哥，</span>
<span className="v" id="v49" data-v="49" data-xref="约书亚记 15:15; 士师记 1:11"> 达纳，基列萨拿——就是底璧，</span>
<span className="v" id="v50" data-v="50"> 阿纳布，以实提莫，阿尼姆，</span>
<span className="v" id="v51" data-v="51" data-xref="约书亚记 11:16; 约书亚记 10:41; 撒母耳记下 15:12"> 歌珊，霍仑，基罗，共十一座城，还有附属的村庄。</span>
<span className="v" id="v52" data-v="52" data-xref="以赛亚书 21:11"> 阿拉布，鲁玛，伊珊，</span>
<span className="v" id="v53" data-v="53"> 雅努姆，伯塔普阿，阿非卡，</span>
<span className="v" id="v54" data-v="54" data-xref="约书亚记 15:13; 创世记 23:2; 约书亚记 14:15"> 胡姆塔，基列-阿尔巴——就是希伯仑，齐奥尔，共九座城，还有附属的村庄。</span>
<span className="v" id="v55" data-v="55" data-xref="撒母耳记上 25:2; 约书亚记 15:24; 撒母耳记上 23:25"> 玛云，迦密，西弗，犹特，</span>
<span className="v" id="v56" data-v="56"> 耶斯列，约克甸，撒挪亚，</span>
<span className="v" id="v57" data-v="57" data-xref="约书亚记 15:10; 创世记 38:12; 耶利米书 14:1"> 基尼，基比亚，亭拿，共十座城，还有附属的村庄。</span>
<span className="v" id="v58" data-v="58" data-xref="历代志上 4:39"> 哈尔胡勒，伯促尔，格多，</span>
<span className="v" id="v59" data-v="59"> 玛拉特，伯阿诺特，伊勒特孔，共六座城，还有附属的村庄。</span>
<span className="v" id="v60" data-v="60" data-xref="约书亚记 18:14; 撒母耳记上 7:1"> 基列-巴力——就是基列-耶琳，拉巴，共两座城，还有附属的村庄。</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61" data-xref="约书亚记 15:6; 约书亚记 18:18"> 在旷野，有伯亚拉巴，米丁，西喀喀，</span>
<span className="v" id="v62" data-v="62" data-xref="撒母耳记上 23:29; 历代志下 20:2"> 尼布珊，盐城，恩盖迪，共六座城，还有附属的村庄。</span>
</div>
<div className="bp">
<span className="v" id="v63" data-v="63" data-xref="士师记 1:21; 士师记 1:8; 撒母耳记下 5:6–9"> 至于住在耶路撒冷的耶布斯人，犹大子孙不能把他们赶出去，耶布斯人就与犹大子孙一起住在耶路撒冷，直到今日。</span>
</div>

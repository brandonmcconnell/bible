<div className="bp">

<span className="v" id="v11" data-v="11" data-xref="约书亚记 12:22; 历代志上 6:68; 列王纪上 4:12"> 然后他们的边界往西上去，到玛拉拉，抵达大巴设，又抵达约念对面的溪谷；</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 4:6; 历代志上 6:72; 约书亚记 19:22"> 又从撒立往东转到吉斯罗-他泊的边界，又延伸到达比拉，上到雅非亚；</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 14:25"> 又从那里往东边日出的方向，经过迦特希弗、伊特卡津，延伸到临门，转到尼亚；</span>
<span className="v" id="v14" data-v="14"> 边界又在北方绕过尼亚，到哈拿顿，终点是伊弗塔伊勒谷；</span>

</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 这些城和附属的村庄，就是西布伦子孙按着他们的家族所得的继业。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 第四支签是给以萨迦，按着他们的家族为以萨迦子孙抽出来。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 28:4; 列王纪下 4:8; 何西阿书 1:4–5"> 他们的地界是到耶斯列，包括了基苏律，书念，</span>
<span className="v" id="v19" data-v="19"> 哈弗连，示按，亚拿哈拉，</span>
<span className="v" id="v20" data-v="20"> 拉比特，其雄，埃贝兹，</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 21:29"> 雷梅特，恩干宁，恩哈达，伯帕泽兹；</span>

<div className="bp">
<span className="v" id="v23" data-v="23"> 这些城和附属的村庄，就是以萨迦支派按着他们的家族所得的继业。</span>

<span className="v" id="v24" data-v="24" data-xref="路加福音 2:26–38"> 第五支签为亚设支派，按着他们的家族抽出来。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约书亚记 12:20; 约书亚记 11:1; 撒母耳记下 2:16"> 他们的地界是：赫尔卡特，哈利，比田，阿克沙弗，</span>
<span className="v" id="v26" data-v="26" data-xref="雅歌 7:5; 列王纪上 18:42; 以赛亚书 33:9"> 阿拉米勒，阿玛德，米沙勒，向西抵达迦密和希赫尔-利布纳；</span>

<div className="bp">
<span className="v" id="v39" data-v="39"> 这些城和附属的村庄，就是拿弗他利支派按着他们的家族所得的继业。</span>

<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="历代志上 2:53; 约书亚记 15:33; 士师记 13:25"> 他们继业的地界是：佐拉，以实陶，伊珥示麦，</span>

<span className="v" id="v48" data-v="48"> 这些城和附属的村庄，就是但支派按着他们的家族所得的继业。</span>

<span className="v" id="v49" data-v="49" data-xref="以西结书 45:7–8"> 他们按着地界分完了那地为继业，以色列子民就在他们中间也分给嫩的儿子约书亚一份继业。</span>

<div className="bp">

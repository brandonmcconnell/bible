<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 14:10; 申命记 31:3; 约书亚记 24:29"> 约书亚老了，上了年纪，耶和华对他说：“你老了，上了年纪，但还剩下很多土地要去占领。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 13:11; 撒母耳记上 27:8; 约珥书 3:4"> 剩下的土地如下：<br />非利士人的全境和基述人的全境，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 2:23; 士师记 3:3; 耶利米书 2:18"> 从埃及东边的西赫河，直到北边的以革伦边界——这也算是迦南人之地——五个非利士首领管辖的加沙、阿实突、阿实基伦、迦特、以革伦；还有亚瓦人之地，</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 19:30; 撒母耳记上 4:1; 士师记 1:34–36"> 南边的迦南人全地，从西顿人的亚拉，直到阿费克，又到亚摩利人的边界；</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 5:18; 约书亚记 12:7; 诗篇 83:7"> 还有迦巴勒人之地，东边的整个黎巴嫩，就是从黑门山脚下的巴力迦得，直到哈马隘口。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约书亚记 11:8; 约书亚记 23:13; 士师记 2:21–23"> “从黎巴嫩直到米斯利弗-玛音山地的所有居民，所有的西顿人，我必把他们从以色列子民面前赶出去，你只管照着我所指示的，把这地抽签分给以色列人为继业。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 26:53–56; 民数记 33:54; 以西结书 48:23–29"> 现在，你要把这地分给九个支派和玛拿西半支派为继业。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约书亚记 12:6; 申命记 3:12–17; 约书亚记 22:4"> 鲁本和迦得与玛拿西半支派一起，已经照着耶和华的仆人摩西所分给他们的，得了摩西在约旦河东岸分给他们的继业：</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约书亚记 13:16; 民数记 21:30; 约书亚记 12:2"> 从亚嫩溪谷边的亚罗珥和溪谷之城，以及整个米底巴平原，直到迪本；</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 21:24–26"> 还有在希实本统治的亚摩利王西宏所有的城镇，直到亚扪人的边界；</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 2:23; 约书亚记 12:2–5; 申命记 4:47–48"> 又有基列地，基述人和玛迦人的地界，以及整个黑门山和巴珊全地，直到撒迦；</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 12:4; 约书亚记 14:3–4; 民数记 21:23–35"> 还有在亚斯他录和伊德赖统治的巴珊王欧革的整个王国，欧革是利乏音人遗民中残留下来的。<br />摩西击败他们，赶出了他们。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 23:12–13; 约书亚记 13:11; 民数记 33:55"> 以色列子民却没有把基述人和玛迦人赶出去，所以基述人和玛迦人住在以色列人当中，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 18:20–24; 约书亚记 14:3–4; 申命记 18:1–2"> 只有利未支派，摩西没有分给他们继业；因为照着耶和华向他们所应许的，献与以色列的神耶和华的火祭就是他们的继业。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 摩西按着鲁本子孙的家族，把继业分给了他们支派。</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 13:9; 约书亚记 12:2; 以赛亚书 16:7–9"> 他们的地界包括：<br />亚嫩溪谷边的亚罗珥和溪谷之城，还有靠近米底巴的整个平原；</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 22:41; 民数记 32:38; 民数记 21:19"> 希实本和平原上所有属它的城镇，迪本，巴莫巴力，伯巴力米恩；</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 21:23; 约书亚记 21:36–37; 历代志上 6:78–79"> 雅哈兹，基底莫，米法押，</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 32:37–38"> 基列亭，西比玛，谷中山上的泽列沙哈尔，</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 12:3; 申命记 4:46; 以西结书 25:9"> 伯毗珥，毗斯迦山坡，伯耶西莫，</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 31:8; 申命记 3:10; 申命记 2:30–36"> 以及平原上的所有城镇，在希实本统治的亚摩利王西宏的整个王国。摩西击败了西宏，以及米甸的领袖埃维、利肯、苏珥、户珥和利巴，他们是住在那地的西宏的众首领。</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 31:8; 犹大书 1:11; 彼得后书 2:15"> 以色列人击杀了这些人，也把比珥之子占卜者巴兰用刀杀了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 鲁本子孙的边界是约旦河沿岸。这是鲁本子孙按着他们的家族，所得为继业的城镇和附属的村庄。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数记 32:34–36"> 摩西按着迦得子孙的家族，把继业分给了他们支派。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 12:26; 撒母耳记下 11:1; 民数记 32:35"> 他们的地界包括：<br />雅谢，基列的所有城镇，亚扪人之地的一半，直到拉巴前面的亚罗珥；</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 17:27; 撒母耳记下 2:8; 士师记 10:17"> 从希实本直到拉玛-米斯巴和比多宁，又从玛哈念直到罗迪巴<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="罗迪巴——或音译“迪比”。">a</a></sup>的边界；</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 32:36; 民数记 34:11; 创世记 33:17"> 还有谷中的伯亚兰，伯宁拉，疏割，撒芬，就是希实本王西宏国中其余的土地；以约旦河为界，直到革尼勒湖<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="革尼勒湖——指加利利海；又称“革尼撒勒湖、太巴列湖”。">b</a></sup>的南端，约旦河的东岸。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 这是迦得子孙按着他们的家族，所得为继业的城镇和附属的村庄。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 摩西也把继业分给玛拿西半支派，按着他们的家族，分给了玛拿西子孙的半支派。</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 13:26; 申命记 3:13–15; 民数记 32:39–41"> 他们的地界包括：<br />玛哈念以及整个巴珊，巴珊王欧革的整个王国，巴珊所有的睚珥村镇，共六十座城；</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 12:4; 民数记 32:39–40"> 还有半个基列，巴珊的欧革王国的城亚斯他录和伊德赖。这些按着他们的家族，分给了玛拿西的儿子玛吉的子孙，就是玛吉的一半子孙。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 以上是摩西在耶利哥东边约旦河对面的摩押平原所分配的继业。</span>
<span className="v" id="v33" data-v="33" data-xref="约书亚记 18:7; 约书亚记 13:14; 申命记 18:1–2"> 摩西没有分继业给利未支派，因为照着耶和华向他们所应许的，以色列的神耶和华就是他们的继业。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 2:24; 约书亚记 2:9–14; 诗篇 127:1"> 那时，耶利哥城因以色列人的缘故紧紧关闭，没有人出入。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 7:24; 约书亚记 8:1; 约书亚记 2:24"> 耶和华对约书亚说：“你看，我已经把耶利哥城，以及那里的王和英勇的战士，都交在你手中了。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 4:7; 民数记 14:9; 约书亚记 6:7"> 你们所有的战士要环绕那城，绕城一次，六天都这样做，</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 20:17; 启示录 16:1; 列王纪上 18:43"> 要有七位祭司拿着七个羊角号走在约柜前头。到第七天，你们要绕城七次，祭司们要吹响号角。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 10:4–5; 希伯来书 11:30; 出埃及记 19:19"> 当羊角长鸣，你们一听见这号角声，全体军兵就要大声呐喊，城墙必坍塌，军兵各个都要冲上前去。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 9:1; 申命记 20:2–4; 约书亚记 3:3"> 嫩的儿子约书亚就召来祭司，对他们说：“你们要抬起约柜，要有七位祭司拿着七个羊角号走在耶和华的约柜前面。”</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 4:13; 约书亚记 6:3; 约书亚记 1:14"> 然后他对军兵说：“前进！环绕那城，武装士兵要走在耶和华的约柜前面。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="民数记 32:20; 约书亚记 6:3–4"> 约书亚吩咐了军兵之后，七位祭司就拿着七个羊角号，在耶和华面前吹着号角前行，耶和华的约柜跟在他们后面。</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 6:13; 民数记 10:25; 以赛亚书 58:8"> 武装士兵走在吹角的祭司前面，后卫队跟随约柜前行；他们一边走，一边吹着号角。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 24:49; 马太福音 12:19; 以赛亚书 42:2"> 约书亚吩咐民众说：“不要呐喊，不要让人听到你们的声音，一个字也不可出口，直到我吩咐你们呐喊的那一天，你们再呐喊。”</span>
<span className="v" id="v11" data-v="11"> 这样，他使耶和华的约柜环绕那城，绕行一次。然后他们回到营地，在营中过夜。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约书亚记 3:1; 希伯来书 11:7–8; 创世记 22:3"> 第二天清晨，约书亚早早起来，祭司们抬起耶和华的约柜。</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太书 6:9; 马太福音 24:13; 历代志上 15:26"> 七位祭司拿着七个羊角号走在耶和华的约柜前面，仍然是一边走，一边吹着号角。武装士兵走在他们前面，后卫队跟随耶和华的约柜前行；祭司一边走，一边吹着号角。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 6:15; 约书亚记 6:11; 约书亚记 6:3"> 这样，第二天他们又环绕那城一次，然后回到营地。他们六天都这样做。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="诗篇 119:147; 彼得后书 1:19; 马太福音 28:1"> 到了第七天，天亮的时候他们早早起来，照样环绕那城，绕了七次，他们只在这一天绕城七次。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 13:15; 约书亚记 6:5; 历代志下 20:22–23"> 到了第七次，祭司吹响号角的时候，约书亚吩咐军兵：“呐喊吧！耶和华已经把城交给你们了！</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 20:17; 雅各书 2:25; 弥迦书 4:13"> 这城和其中的一切都要归于耶和华为当灭之物，只有妓女拉合以及所有与她一起在家里的人可以存活，因为她隐藏了我们派去的使者。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰一书 5:21; 以弗所书 5:11; 约书亚记 7:1"> 你们务必谨慎，远离那些当灭之物，免得你们灭绝；你们取走当灭之物，就会使以色列营地也成为当灭之物，给营地带来祸患。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 26:20; 马太福音 27:6; 马可福音 12:41"> 只是所有的金银以及铜铁器具，都归耶和华为圣，要放进耶和华的宝库。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="希伯来书 11:30; 哥林多后书 10:4–5; 约书亚记 6:5"> 于是军兵呐喊，祭司们吹响号角。军兵一听见号角声就大声呐喊，城墙就坍塌了。军兵各个往前，冲上城去，攻取了那城。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 137:8–9; 耶利米书 48:18; 约书亚记 11:14"> 他们把城里的一切，无论男女老少，牛羊或驴，都灭绝于刀刃之下。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="希伯来书 11:31; 约书亚记 6:17; 以西结书 17:18–19"> 约书亚对窥探那地的两个人说：“你们到那妓女的家，照你们向那妇人所起的誓，把她和她所有的家人，都从那里带出来吧。”</span>
<span className="v" id="v23" data-v="23" data-xref="希伯来书 11:7; 创世记 18:24; 使徒行传 27:24"> 那两个年轻探子就去，把拉合与她的父母兄弟以及她所有的家人都带了出来。他们把她全家带出来，安置在以色列营地外面。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约书亚记 8:28; 启示录 17:16; 列王纪下 25:9"> 以色列人把那城和其中的一切都放火烧掉了，只把金银以及铜铁器具放进耶和华居所的宝库。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 11:31; 马太福音 1:5; 士师记 1:24–25"> 至于妓女拉合与她的父家，以及她所有的家人，约书亚都让他们存活，因为她把约书亚派去窥探耶利哥的使者藏了起来。这样，她就住在以色列人中，直到今天。</span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="列王纪上 16:34; 使徒行传 19:13; 民数记 5:19–21"> 那时，约书亚起誓说：<br /><span className="pl pl-1">“起来重建这耶利哥城的人，</span><br /><span className="pl pl-1">必在耶和华面前受诅咒！</span><br /><span className="pl pl-1">他奠定根基时，必丧长子；</span><br /><span className="pl pl-1">竖立城门时，必丧幼子。”</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约书亚记 9:3; 约书亚记 1:5; 马太福音 28:20"> 耶和华与约书亚同在，他的名声传遍了全地。</span>
</div>
</div>

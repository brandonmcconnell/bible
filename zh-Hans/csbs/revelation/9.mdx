<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 8:10; 罗马书 10:7; 启示录 9:2"> 第五位天使吹响号角，我就看见从天上坠落到地上的一颗星。它被赐予了无底坑口的钥匙。</span>
<span className="v" id="v2" data-v="2" data-xref="约珥书 2:10; 创世记 19:28; 约珥书 2:2"> 它打开了无底坑口，就有烟从坑口里往上冒，好像大<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本没有“大”。">a</a></sup>火炉的烟，甚至太阳和天空因坑口的烟而变为黑暗。</span>
<span className="v" id="v3" data-v="3" data-xref="约珥书 1:4; 启示录 9:5; 约珥书 2:25"> 有蝗虫从烟中出来，到了地上；它们被赐予了能力，就像地上的蝎子所具有的能力那样。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 7:2–4; 以西结书 9:4; 启示录 14:1"> 有话吩咐它们不可伤害地上的草、任何绿色植物、任何树木，只可伤害那些额上没有神印记的人；</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 9:10; 约伯记 2:6; 启示录 9:3"> 可是不准许杀死这些人，只可使他们受折磨五个月。他们所受的折磨，就像人被蝎子螫到时的折磨那样。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 23:30; 耶利米书 8:3; 启示录 6:16"> 在那些日子里，人们将会求死，却绝不得死；他们渴望死，死却逃避他们。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="但以理书 7:8; 那鸿书 3:17; 约珥书 2:4–5"> 这些蝗虫的样式仿佛是所预备好的要出战的马。它们的头上像有类似金子的冠冕；它们的脸面像人的脸面；</span>
<span className="v" id="v8" data-v="8" data-xref="约珥书 1:6; 哥林多前书 11:14–15; 彼得前书 3:3"> 它们有头发像女人的头发；它们的牙齿像狮子的牙齿；</span>
<span className="v" id="v9" data-v="9" data-xref="约珥书 2:5–8; 那鸿书 2:4–5; 约伯记 39:25"> 它们有护胸甲像铁甲；它们翅膀的声音像许多马匹的战车奔驰出战的声音；</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 9:5; 启示录 9:3; 启示录 9:19"> 它们有尾巴仿佛蝎子，又有毒刺，它们的威力在它们的尾巴上，可以伤害人五个月。</span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 26:6; 启示录 9:1–2; 以弗所书 2:2"> 有一个王统管它们，就是那无底坑的使者<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="使者——或译作“天使”。">b</a></sup>；他的名字，希伯来语是“阿巴顿<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="阿巴顿——希伯来文词语；意思为“破坏者”或“毁坏者”。">c</a></sup>”，按希腊语的名字是“阿波伦<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="阿波伦——希腊文词语；意思为“破坏者”或“毁坏者”。">d</a></sup>”。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 11:14; 启示录 8:13–2; 启示录 9:13–21"> 第一个灾祸过去了。看哪，这些事以后还有两个灾祸就要来临。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="启示录 8:3–5; 出埃及记 30:2–3; 启示录 9:1"> 第六位天使吹响号角，我就听见一个声音从神面前金祭坛的四只<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本没有“四只”。">e</a></sup>角传来，</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 16:12; 启示录 9:15; 撒母耳记下 8:3"> 对拿着号角的第六位天使说：“把那捆绑在幼发拉底大河的四个使者<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="使者——或译作“天使”。">f</a></sup>释放出来！”</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 9:18; 启示录 8:7; 启示录 8:9"> 于是那四个使者<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="使者——或译作“天使”。">g</a></sup>就被释放了。他们是为此年、此月、此日、此时所预备好的，为要杀死人类的三分之一。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 7:4; 诗篇 68:17; 但以理书 7:10"> 骑兵的数目有两亿<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="两亿——原文直译“两个几万的几万”；有古抄本作“一亿”。">h</a></sup>；我听见了它们的数目。</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 9:18; 启示录 14:10; 历代志上 12:8"> 我在异象中看见的那些马和骑马的是这样：他们穿着火红色、紫玛瑙色、硫磺色的护胸甲；马的头像狮子的头，从它们的口中有火、烟、硫磺喷出来。</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 9:17; 启示录 9:15"> 由于这三样灾害<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本没有“灾害”。">i</a></sup>，就是从马口中所喷出的火、烟、硫磺，人类的三分之一被杀了。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 9:15; 启示录 9:10; 以弗所书 4:14"> 原来这些马的<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="这些马的——有古抄本作“它们的”。">j</a></sup>威力在它们的口中和尾巴上，因为它们的尾巴仿佛蛇，有头；它们用这些头来伤害人。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="但以理书 5:23; 申命记 31:29; 提摩太前书 4:1"> 可是，其余没有被这些灾害所杀的人，还是不悔改离开自己手所做的，不停止<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="停止——辅助词语。">k</a></sup>拜鬼魔和那些金、银、铜、石、木的偶像——它们既不能看、也不能听、更不能走。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 21:8; 哥林多后书 12:21; 启示录 17:5"> 他们也不悔改离开自己那些杀人、邪术<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="邪术——或译作“巫术”或“毒品”。">l</a></sup>、淫乱、偷窃之事。</span>
</div>
</div>

<span className="v" id="v2" data-v="2" data-xref="启示录 14:8; 耶利米书 51:8; 耶利米书 51:37"> 他用强有力的声音呼喊说：<br /><span className="pl pl-1">“倒塌了！大巴比伦倒塌了！</span><br /><span className="pl pl-1">她成了鬼魔居住的地方、</span><br /><span className="pl pl-1">一切污灵的巢穴</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="巢穴——或译作“牢笼”。">a</a></sup><br /><span className="pl pl-1">、</span><br /><span className="pl pl-1">一切污秽鸟类的巢穴、</span><br /><span className="pl pl-1">一切污秽可憎野兽的巢穴</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一切污秽鸟类的巢穴、一切污秽可憎野兽的巢穴——有古抄本作“一切污秽可憎之鸟类的巢穴”。">b</a></sup><br /><span className="pl pl-1">。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 52:11; 哥林多后书 6:17; 耶利米书 51:6"> 接着，我听见另一个声音从天上传来，说：<br /><span className="pl pl-1">“我的子民哪，你们要从她那里出来，</span><br /><span className="pl pl-1">免得在她的罪孽上有份，</span><br /><span className="pl pl-1">也免得遭受她所受的灾害，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="创世记 18:20–21; 以斯拉记 9:6; 启示录 16:19"> <span className="pl pl-1">因为她的罪孽滔天，</span><br /><span className="pl pl-1">神也记得她的罪行。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 50:29; 诗篇 137:8; 耶利米书 51:24"> <span className="pl pl-1">她怎样待人，你们也要怎样待她，</span><br /><span className="pl pl-1">并照着她的行为加倍地报应她；</span><br /><span className="pl pl-1">你们要在她混合酒的杯子里，</span><br /><span className="pl pl-1">加倍地混合给她喝。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 47:7–9; 西番雅书 2:15; 耶利米哀歌 1:1"> <span className="pl pl-1">她怎样炫耀自己、骄奢淫逸，</span><br /><span className="pl pl-1">你们也要照样给她折磨和悲伤，</span><br /><span className="pl pl-1">因为她心里说：‘我坐着女王的位子</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="的位子——辅助词语。">d</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">我不是寡妇，绝不会经历悲伤。’</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 50:34; 耶利米书 50:31; 启示录 17:16"> <span className="pl pl-1">为此，在一天之内</span><br /><span className="pl pl-1">她所受的灾害，就是死亡、悲伤和饥荒，</span><br /><span className="pl pl-1">就要来到。</span><br /><span className="pl pl-1">她将要在烈火中被烧掉，</span><br /><span className="pl pl-1">因为主、神——审判她的那一位是强有力的。”</span></span>
</div>
<div className="bp poetry">

<span className="v" id="v10" data-v="10" data-xref="启示录 18:19; 启示录 18:8; 启示录 18:15–17"> 他们因惧怕她所受的折磨，就远远地站着，说：<br /><span className="pl pl-1">“有祸了！有祸了！宏大的城，</span><br /><span className="pl pl-1">强大的巴比伦城啊！</span><br /><span className="pl pl-1">因为一时之间，</span><br /><span className="pl pl-1">你的审判就来到了！”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="启示录 18:3; 启示录 18:23; 以西结书 27:27–36"> 地上的商人也为她哭泣、悲伤，因为再也没有人买他们的货物了；</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 17:4; 以西结书 27:5–25; 箴言 8:10–11"> 那些货物就是：金、银、宝石、珍珠，细麻布、紫色布、丝绸、深红色布，各种香木，各种象牙制品，各种极贵重的木、铜、铁和大理石的制品，</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 27:13; 阿摩司书 2:6; 彼得后书 2:3"> 肉桂、香料<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本没有“香料”。">e</a></sup>、香、香液、乳香；酒、油、面粉、麦子；牲畜、羊、马、马车；人的肉体和灵魂<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="灵魂——或译作“生命”。">f</a></sup>。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 10:6; 诗篇 106:14; 路加福音 16:25"> <span className="pl pl-1">“你心所贪恋的果子离开了你；</span><br /><span className="pl pl-1">一切珍馐美味、华丽物品，都从你那里消逝</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="消逝——有古抄本作“离开”。">g</a></sup><br /><span className="pl pl-1">了，</span><br /><span className="pl pl-1">人绝不能再看到它们了。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="启示录 18:3; 使徒行传 19:24–27; 以西结书 27:31"> 贩卖<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="贩卖——辅助词语。">h</a></sup>这些东西的商人，就是那些由于她而发了财的人，因惧怕她所受的折磨，就会远远地站着，哭泣、悲伤，</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 17:4; 路加福音 16:19–31; 启示录 18:10–11"> 说：<br /><span className="pl pl-1">“有祸了！有祸了！宏大的城，</span><br /><span className="pl pl-1">那曾身穿细麻、紫色、深红色衣服，</span><br /><span className="pl pl-1">以金子、宝石、珍珠为装饰的城啊！</span><br /></span>

<span className="v" id="v19" data-v="19" data-xref="启示录 18:10; 约书亚记 7:6; 以西结书 27:30"> 他们把尘土撒在自己头上，哭泣、悲伤，呼喊说：<br /><span className="pl pl-1">“有祸了！有祸了！宏大的城，所有靠着她在海上有船只的人</span><br /><span className="pl pl-1">都因她的财富发了财。</span><br /><span className="pl pl-1">她竟然在一时之间就化为乌有了！</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="启示录 6:10; 启示录 19:1–3; 路加福音 18:7–8"> <span className="pl pl-1">上天哪、圣徒们、使徒们、先知们哪，你们应当因她欢喜！</span><br /><span className="pl pl-1">因为神已经向她施行审判，为你们惩罚她！”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="耶利米书 51:63–64; 以西结书 26:21; 启示录 5:2"> 随后，一位强有力的天使拿起一块像大磨石那样的石头，把它丢进海里，说：<br /><span className="pl pl-1">“大巴比伦城也将这样被猛烈地扔下去，</span><br /><span className="pl pl-1">绝不会再找到了！</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 26:13; 耶利米书 25:10; 耶利米书 7:34"> <span className="pl pl-1">弹琴的、奏乐的、吹笛的、吹号之人的声音，</span><br /><span className="pl pl-1">在你中间绝不会再听到了！</span><br /><span className="pl pl-1">各种手艺的工匠，</span><br /><span className="pl pl-1">在你中间绝不会再找到了！</span><br /><span className="pl pl-1">磨石的声音，</span><br /><span className="pl pl-1">在你中间绝不会再听到了！</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="启示录 18:3; 以赛亚书 23:8; 那鸿书 3:4"> <span className="pl pl-1">灯的亮光，</span><br /><span className="pl pl-1">在你中间绝不会再照耀了！</span><br /><span className="pl pl-1">新郎和新娘的声音，</span><br /><span className="pl pl-1">在你中间绝不会再听到了！</span><br /><span className="pl pl-1">因为你的商人一向是地上的大人物，</span><br /><span className="pl pl-1">又因为万国都被你的邪术</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="邪术——或译作“巫术”或“毒品”。">j</a></sup><br /><span className="pl pl-1">所迷惑，</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="启示录 17:6; 启示录 16:6; 耶利米书 51:49"> <span className="pl pl-1">而且先知们、圣徒们以及地上一切被杀之人的血，</span><br /><span className="pl pl-1">在你</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="你——原文直译“她”；指“巴比伦”。">k</a></sup><br /><span className="pl pl-1">那里都被发现了。”</span></span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 12:3; 启示录 17:3; 但以理书 7:23–25"> 接着，我看见一只兽从海里上来。它有十只角和七个头，十只角上戴着十个王冠，七个头上都有亵渎的名号。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理书 7:4–7; 彼得前书 5:8; 启示录 17:12"> 我所看见的这兽，仿佛一只豹，它的脚像熊的脚，口像狮子的口。龙把自己的能力、王位和大权交给了这兽。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 17:8; 启示录 13:14; 启示录 17:17"> 这兽的七个头中有一个好像受了致命伤，可是这致命伤得了痊愈。全地的人都感到惊奇，跟随了这兽。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 13:2; 启示录 18:18; 启示录 13:15"> 他们膜拜龙，因为它把权柄交给了兽。他们也膜拜兽，说：“谁能与这兽相比呢？谁能与它交战呢？”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="但以理书 7:8; 但以理书 7:25; 但以理书 11:36"> 那兽被赐予了一张说大话和亵渎话的口；它又被赐予了权柄，可以任意<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="可以任意——辅助词语。">a</a></sup>行事四十二个月。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 12:34; 希伯来书 9:24; 启示录 12:12"> 它就开口向神说亵渎的话，亵渎了他的名和他的居所<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="居所——原文直译“帐幕”。">b</a></sup>，亵渎了那些居住在天上的。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 7:21; 启示录 11:7; 但以理书 7:25"> 它被准许与圣徒们作战，并胜过他们；它还被赐予了权柄统管各支派、各民族<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本没有“各民族”。">c</a></sup>、各语言群体、各国家。</span>
<span className="v" id="v8" data-v="8" data-xref="彼得前书 1:19–20; 以弗所书 1:4; 马太福音 25:34"> 住在地上的人，凡是名字从创世以来没有记在那被杀羔羊的生命册上的，都将膜拜它。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="启示录 2:7; 启示录 2:17; 启示录 2:11"> 凡是有耳的，就应当听！</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 15:2; 以赛亚书 33:1; 启示录 14:12"> <span className="pl pl-1">如果有人注定</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="注定——辅助词语。">d</a></sup><br /><span className="pl pl-1">被掳，</span><br /><span className="pl pl-1">他就会被掳去；</span><br /><span className="pl pl-1">如果有人注定</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="注定——辅助词语。">e</a></sup><br /><span className="pl pl-1">被刀杀</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="注定被刀杀——有古抄本作“用刀杀人”。">f</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">他就会被刀杀。</span><br />圣徒们的忍耐和信仰，就在这里。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="但以理书 7:8; 哥林多后书 11:13–15; 马太福音 7:15"> 接着，我看见另一只兽从地里上来。它有两只角仿佛羊羔，说话却像龙。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 17:10–11; 启示录 14:11; 启示录 14:9"> 它在第一只兽的面前，施行第一只兽的一切权柄，强迫大地和住在地上的人来膜拜第一只兽，就是致命伤得了痊愈的那兽。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 24:24; 启示录 19:20; 帖撒罗尼迦后书 2:9–10"> 它又行大奇迹，甚至在众人面前，使火从天降到地上。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 12:9; 启示录 19:20; 启示录 13:8"> 藉着那些奇迹，就是它被准许在第一只兽面前所行的奇迹，它就迷惑了住在地上的人，告诉住在地上的人，要为那受刀伤却活过来的兽，造一个像。</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 20:4; 启示录 19:20; 但以理书 3:3–6"> 它又被准许把气息<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="气息——或译作“灵”。">g</a></sup>给那兽像，甚至使那兽像能说话，又使所有不膜拜那兽像的人都被杀死。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 20:4; 启示录 19:20; 以西结书 9:4"> 它还强迫所有的人，无论卑微的或尊贵的、富有的或贫穷的、自由的或为奴的，都在右手或额上接受印记；</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 15:2; 启示录 13:16; 启示录 14:11"> 这样，除了有这印记的人，谁都不可以买或卖，这印记就是兽的名字或它名字的数目。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="启示录 15:2; 启示录 17:9; 启示录 21:17"> 智慧就在这里。有理性的人应当计算这兽的数目，因为这是一个人的数目；其数目是六百六十六<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="六百六十六——有古抄本作“六百一十六”。">h</a></sup>。</span>
</div>
</div>

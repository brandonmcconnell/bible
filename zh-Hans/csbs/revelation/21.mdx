<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 65:17–19; 彼得后书 3:13; 以赛亚书 66:22"> 接着，我看见一个新天新地，因为先前的天和先前的地都已经过去了，海也不再存在了。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:10; 启示录 3:12; 启示录 21:10"> 我<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我——有古抄本作“我约翰”。">a</a></sup>也看见圣城新耶路撒冷，从神那里、从天上降下来，已经被预备好了，就像为自己的丈夫装饰整齐的新娘那样。</span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="以西结书 37:27; 哥林多后书 6:16; 约翰福音 14:23"> 我又听见有大声音从宝座上<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="从宝座上——有古抄本作“从天上”。">b</a></sup>传来，说：<br /><span className="pl pl-1">“看哪，神的居所</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="居所——原文直译“帐幕”。">c</a></sup><br /><span className="pl pl-1">在人间，</span><br /><span className="pl pl-1">神将要与人一同居住</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="居住——原文直译“展开帐幕”。">d</a></sup><br /><span className="pl pl-1">。</span><br /><span className="pl pl-1">他们将要做他的子民，</span><br /><span className="pl pl-1">神将要亲自与他们同在，做他们的神</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本没有“做他们的神”。">e</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 25:8; 启示录 7:17; 哥林多前书 15:26"> <span className="pl pl-1">神</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="神——有古抄本作“他”。">f</a></sup><br /><span className="pl pl-1">要从他们的眼中抹去一切泪水。</span><br /><span className="pl pl-1">将来不再有死亡，</span><br /><span className="pl pl-1">也不再有悲伤、哭泣或痛苦，</span><br /><span className="pl pl-1">因为先前的事已经过去了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 5:17; 以赛亚书 42:9; 以赛亚书 43:19"> 坐在宝座上的那一位说：“看哪，我正在更新一切！”他又说：“你当写下，因为这些话是信实的、真实的。”</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 7:37–38; 约翰福音 4:10; 启示录 7:17"> 他又对我说：“成了！我就是‘阿尔法’，也是‘欧米伽’；是开始，也是终结。我将要从生命水的泉源把水无偿地赐给干渴的人。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 6:18; 希伯来书 8:10; 启示录 2:11"> 那得胜的，将要继承这些；我将要做他的神，他将要做我的儿子。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 6:9–10; 启示录 2:11; 以弗所书 5:5–6"> 但那些胆怯的、不信的、可憎的、杀人的、淫乱的、行邪术的、拜偶像的，和所有说谎的人，他们的份就在燃烧着烈火和硫磺的湖里。这是第二次的死亡。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="启示录 21:2; 启示录 19:7; 启示录 16:1–17"> 拿着七个盛满最后七灾害之碗的七位天使中，有一位过来对我讲话，说：“来，我要给你看看新娘，就是羔羊的妻子。”</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 21:2; 以西结书 11:24; 以西结书 40:1–49"> 于是我在灵里被天使带到一座高大的山上。他给我看那从神那里、从天上降下来的圣城耶路撒冷；</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 4:6; 启示录 22:5; 启示录 22:1"> 这城有神的荣耀，她的光辉仿佛极贵重的宝石，如同碧玉，清澈如水晶。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 48:31–34; 启示录 7:4–8; 启示录 21:17–21"> 她有又高又大的城墙，有十二个城门，城门前有十二位天使，又有名字刻在上头，是以色列子民十二支派的名字。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 48:31–34"> 东面三个门，北面三个门，南面三个门，西面三个门。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 11:10; 以弗所书 2:20; 以赛亚书 54:11"> 城墙有十二座基石，上面有羔羊十二使徒的十二个名字。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 2:1; 启示录 11:1–2; 以西结书 41:1–5"> 那位对我说话的天使<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="天使——辅助词语。">g</a></sup>，拿着一根金芦苇的量尺，要测量那城，就是<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="就是——或译作“以及”。">h</a></sup>她的城门和城墙。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 48:35; 以西结书 48:8–20"> 那城布置为四方形，长度和宽度一样<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="长度和宽度一样——有古抄本作“长度这么长，宽度也一样长”。">i</a></sup>。天使用芦苇测量那城，有两千两百公里<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="两千两百公里——原文直译“十二千视距”，包含了数字12。1视距=185公尺。">j</a></sup>；她的长、宽、高都是相等的。</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 7:4; 申命记 3:11; 启示录 13:18"> 天使又测量了她的城墙，按人的尺度有一百四十四肘<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="一百四十四肘——相当于66公尺。1肘=46公分。144是12个12，隐含了数字12。">k</a></sup>；这也是天使的尺度。</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 21:11; 启示录 21:21; 启示录 21:19"> 她的城墙是用碧玉建造的；城是纯金的，仿佛纯净的玻璃。</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 54:11–12; 出埃及记 28:17–21; 约伯记 28:16–19"> 城墙的基石是用各种宝石装饰的：<br /><span className="pl pl-1">第一座基石是碧玉，</span><br /><span className="pl pl-1">第二座是蓝宝石，</span><br /><span className="pl pl-1">第三座是绿玛瑙，</span><br /><span className="pl pl-1">第四座是绿宝石，</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="启示录 4:3"> <span className="pl pl-1">第五座是红玛瑙，</span><br /><span className="pl pl-1">第六座是红宝石，</span><br /><span className="pl pl-1">第七座是黄璧玺，</span><br /><span className="pl pl-1">第八座是水苍玉，</span><br /><span className="pl pl-1">第九座是黄玉，</span><br /><span className="pl pl-1">第十座是翡翠，</span><br /><span className="pl pl-1">第十一座是紫玛瑙，</span><br /><span className="pl pl-1">第十二座是紫水晶。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="启示录 21:18; 启示录 17:4; 启示录 22:2"> 十二个城门是十二颗珍珠；每一个门各自是由一颗珍珠造成的。城里的大街<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="大街——或译作“广场”。">l</a></sup>是纯金的，好像透明的玻璃。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约翰福音 4:23; 列王纪上 8:27; 历代志下 2:6"> 在城中我没有看见圣所，因为主、神、全能者和羔羊就是城的圣所。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 60:19–20; 启示录 22:5; 启示录 21:11"> 这城不需要太阳和月亮来照耀，因为神的荣耀照亮她，而羔羊就是她的灯。</span>
<span className="v" id="v24" data-v="24" data-xref="启示录 21:26; 启示录 22:2; 撒迦利亚书 8:22–23"> 列国<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="列国——有古抄本作“蒙得救的列国”。">m</a></sup>都将藉着城的光行走<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="将藉着城的光行走——有古抄本作“将在城的光里行走”。">n</a></sup>；地上的众君王都要把他们的荣耀<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="众君王都要把他们的荣耀——有古抄本作“众君王都要把列国的荣耀和尊贵”。">o</a></sup>带进城内。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 60:11; 撒迦利亚书 14:7; 启示录 22:5"> 她的各城门整天绝不关上，原来那里没有黑夜。</span>
<span className="v" id="v26" data-v="26" data-xref="启示录 21:24"> 人们将要把列国的荣耀和尊贵带进城内。</span>
<span className="v" id="v27" data-v="27" data-xref="启示录 22:14–15; 以赛亚书 52:1; 启示录 20:15"> 凡是不洁净的，行可憎和虚假之事的人，绝不能进到城内；唯有名字<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="名字——辅助词语。">p</a></sup>被记在羔羊生命册上的才能进去。</span>
</div>
</div>

<div className="bp">

<span className="v" id="v9" data-v="9" data-xref="以赛亚书 60:14; 启示录 2:9; 以赛亚书 49:23"> <span className="woj">看哪，我要使那些属于撒旦会堂的，就是那些自称是犹太人，其实不是犹太人，而是说谎的人——看哪，我要使他们来，在你脚前下拜；他们就会知道我已经爱了你，</span></span>
<span className="v" id="v10" data-v="10" data-xref="彼得后书 2:9; 启示录 14:12; 撒迦利亚书 13:9"> <span className="woj">因为你遵守了我忍耐的教导</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="教导——原文直译“话语”或“道”。">d</a></sup><span className="woj">，我还要保守你脱离那试炼的时刻，就是那将要临到普天下，考验住在地上之人的时刻。</span></span>
<span className="v" id="v11" data-v="11" data-xref="雅各书 1:12; 启示录 22:12; 启示录 2:10"> <sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附“看哪，”。">e</a></sup><span className="woj">我快要来了！你应当持守你所拥有的，免得有人拿走你的冠冕。</span></span>
<span className="v" id="v12" data-v="12" data-xref="启示录 22:4; 启示录 21:2; 启示录 14:1"> <span className="woj">那得胜的，我将要让他在我神的圣所中做柱石，他绝不再出去。我要把我神的名，我神之城的名——就是从我的神那里、从天上降下来的新耶路撒冷的名，和我的新名，都写在他身上。</span></span>

<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="歌罗西书 1:15; 启示录 1:5; 哥林多后书 1:20"> <span className="woj">“你要给那在劳迪西亚教会的使者</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="使者——或译作“天使”。">f</a></sup><span className="woj">写信说：</span><br /><span className="woj">“那位阿们，就是那信实的、真实的见证者，神创造之物的本源，这样说：</span></span>

<span className="v" id="v16" data-v="16" data-xref="启示录 2:5; 撒迦利亚书 11:8–9; 耶利米书 14:19"> <span className="woj">正因为你是温的，既不热也不冷，我就要把你从我口中吐出去，</span></span>

<span className="v" id="v19" data-v="19" data-xref="箴言 3:11–12; 哥林多前书 11:32; 希伯来书 12:5–11"> <span className="woj">凡是我所爱的，我都责备、管教。所以你应当热心，应当悔改。</span></span>

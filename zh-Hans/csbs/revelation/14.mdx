<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约珥书 2:32; 启示录 3:12; 启示录 7:3–17"> 我又观看，看哪，那羔羊站在锡安山上，与他在一起的有十四万四千<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十四万四千——原文直译“一百四十四千”；等于12个12千，隐含了数字12。">a</a></sup>人，他们的额上都写着他的名和<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本没有“他的名和”。">b</a></sup>他父的名。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 5:8; 以西结书 43:2; 启示录 1:15"> 接着，我听见有声音从天上传来，好像众水的声音，也像大雷鸣的声音。我所听见的这声音，又像琴师们弹奏竖琴的声音。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 5:9; 启示录 14:1; 启示录 15:3"> 他们在宝座前，并四个活物和长老们面前唱歌，像<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本没有“像”。">c</a></sup>是新歌，这首歌除了从地上被赎回来的那十四万四千人以外，没有人能学会。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 3:4; 哥林多后书 11:2; 雅各书 1:18"> 这些人没有与女人在一起而玷污自己，实际上他们是童身；无论羔羊到哪里去，他们都跟随他；这些人是<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附“藉着耶稣”。">d</a></sup>从人间被赎回来，做为初熟的果子归给神和羔羊的；</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 5:27; 诗篇 32:2; 西番雅书 3:13"> 在他们口中找不出虚假<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="虚假——有古抄本作“诡诈”。">e</a></sup>；<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附“在神的宝座前，”。">f</a></sup>他们是毫无瑕疵的。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="马可福音 16:15; 启示录 8:13; 以弗所书 3:9–11"> 随后，我看见另一位天使在空中飞翔；他带着永恒的福音要传给住在地上的人，传给各国家、各支派、各语言群体、各民族。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 20:11; 启示录 15:4; 尼希米记 9:6"> 他大声说：“你们当敬畏神，把荣耀归给他，因为他审判的时候到了。你们当敬拜造了天、地、海和众水泉源的那一位。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 21:9; 耶利米书 51:7–8; 启示录 18:2–3"> 另一位天使，就是第二位天使<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本没有“就是第二位天使”。">g</a></sup>跟着说：“倒塌了！大<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附“城”。">h</a></sup>巴比伦倒塌了！她给万国喝了她淫乱愤怒<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="愤怒——或译作“激情”。">i</a></sup>的酒。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="启示录 14:11; 启示录 14:6–8; 启示录 13:3–6"> 另一位天使，就是第三位天使，跟着他们大声说：“如果有人膜拜那兽和兽像，并在自己额上或手上接受印记，</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 51:17; 启示录 16:19; 耶利米书 25:15–17"> 就要喝神愤怒的酒，就是混合在神震怒之杯中那没有稀释的酒。他将要在圣天使们面前、羔羊面前，在烈火和硫磺中受折磨。</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 19:3; 以赛亚书 34:10; 马太福音 25:41"> 折磨他们时的烟往上冒，直到永永远远。那些膜拜兽和兽像的，以及任何接受它名字印记的，都将日夜得不到安息。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 13:10; 启示录 12:17; 启示录 3:10"> 遵守神的命令、持守对耶稣信仰的圣徒们的忍耐，就在这里。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="启示录 20:6; 提摩太后书 4:7–8; 帖撒罗尼迦前书 5:10"> 接着，我听见有声音从天上传来，说：“你当写下：从今以后，在主里死去的人是蒙福的！”<br />圣灵说：“是的！他们将脱离自己的劳苦进入安息<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="进入安息——原文直译“得到安息”。">j</a></sup>，因为他们的作为将伴随着他们。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="但以理书 7:13; 以赛亚书 19:1; 马太福音 17:5"> 我又观看，看哪，一朵白云，云上坐着一位仿佛人子的，头上戴着金冠冕，手里拿着一把锋利的镰刀。</span>
<span className="v" id="v15" data-v="15" data-xref="约珥书 3:13; 马太福音 13:39; 马可福音 4:29"> 另一位天使从圣所中出来，大声对坐在云上的那一位呼喊：“伸出你的镰刀去收割吧！因为收割的时候到了，地上的庄稼已经熟<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="熟——或译作“枯干”。">k</a></sup>了。”</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 16:27; 启示录 14:19; 启示录 14:14"> 于是坐在云上的那一位向大地挥动他的镰刀，大地的庄稼<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="的庄稼——辅助词语。">l</a></sup>就被收割了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="启示录 14:18; 启示录 14:14–15; 启示录 15:5–6"> 又一位天使从天上的圣所中出来，他也拿着一把锋利的镰刀。</span>
<span className="v" id="v18" data-v="18" data-xref="约珥书 3:13; 启示录 16:8; 启示录 14:15–16"> 另一位天使从祭坛那里出来，是有权柄统管火的；他对那位拿着锋利镰刀的大声呼唤说：“伸出你那锋利的镰刀，收取地上葡萄树累累的果子吧！因为葡萄已经熟了。”</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 32:32–33; 启示录 19:15–21"> 于是那位天使向大地挥动他的镰刀，收取了地上的葡萄，丢进神愤怒的大榨酒池里。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米哀歌 1:15; 启示录 19:14–21; 以赛亚书 63:1–3"> 榨酒池在城外被践踏，就有血从榨酒池里流出来，高到马的嚼子，远达三百公里<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="三百公里——原文为“1,600视距”。1视距=185公尺。">m</a></sup>。</span>
</div>

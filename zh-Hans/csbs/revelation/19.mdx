<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="启示录 7:10–12; 历代志上 29:11; 启示录 11:15"> 这些事以后，我听见天上有大声音，好像一大群人的声音，说：<br /><span className="pl pl-1">“哈利路亚！</span><br /><span className="pl pl-1">救恩、荣耀、</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附“尊贵、”。">a</a></sup><br /><span className="pl pl-1">权能都属于</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附“主——”。">b</a></sup><br /><span className="pl pl-1">我们的神！</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="申命记 32:43; 启示录 6:10; 启示录 18:20"> <span className="pl pl-1">因为他的审判是真实的、公义的，</span><br /><span className="pl pl-1">因为他审判了那用自己的淫乱败坏大地的大淫妇，</span><br /><span className="pl pl-1">并且为他奴仆们的血，向那淫妇</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="那淫妇——原文直译“她的手”。">c</a></sup><br /><span className="pl pl-1">讨回了公道。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 34:10; 启示录 18:18; 启示录 14:11"> 他们第二次说：<br /><span className="pl pl-1">“哈利路亚！</span><br /><span className="pl pl-1">焚烧她时的烟往上冒，直到永永远远！”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="启示录 5:14; 尼希米记 8:6; 诗篇 106:48"> 二十四位长老和四个活物就俯伏敬拜那坐在宝座上的神，说：<br /><span className="pl pl-1">“阿们！哈利路亚！”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="诗篇 134:1; 诗篇 148:11–13; 诗篇 150:6"> 随后，有声音从宝座上传来，说：<br /><span className="pl pl-1">“神所有的奴仆们哪，</span><br /><span className="pl pl-1">所有敬畏他的，无论卑微尊贵，</span><br /><span className="pl pl-1">你们要赞美我们的神！”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="诗篇 97:1; 启示录 14:2; 诗篇 93:1"> 接着，我听见好像一大群人的声音，也像众水的声音，又像大雷鸣的声音，说：<br /><span className="pl pl-1">“哈利路亚！</span><br /><span className="pl pl-1">因为我们的主、神、全能者做王了！</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="启示录 21:9; 启示录 21:2; 启示录 19:9"> <span className="pl pl-1">让我们欢喜、快乐，让我们把荣耀归给他！</span><br /><span className="pl pl-1">因为羔羊婚宴的时候到了，</span><br /><span className="pl pl-1">他的新娘</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="新娘——原文直译“妻子”。">d</a></sup><br /><span className="pl pl-1">也把自己预备好了；</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 61:10; 启示录 7:13–14; 诗篇 132:9"> <span className="pl pl-1">新娘</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="新娘——原文直译“她”。">e</a></sup><br /><span className="pl pl-1">被准许穿戴明亮洁白</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="洁白——原文直译“洁净”。">f</a></sup><br /><span className="pl pl-1">的细麻衣。”</span><br />原来，这细麻衣代表<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="代表——原文直译“是”。">g</a></sup>圣徒们的义行。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="启示录 22:6; 马太福音 22:2–4; 路加福音 14:15–16"> 随后，那位天使<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="那位天使——原文直译“他”。">h</a></sup>对我说：“你当写下：那些被邀请赴羔羊婚宴的人是蒙福的！”他又对我说：“这些都是神真实的话语。”</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 22:8–9; 使徒行传 10:25–26; 约翰福音 5:39"> 我就俯伏在他的脚前，要敬拜他。可是他对我说：“你要注意，不可这样！我与你和你的弟兄们——那些持守有关耶稣见证的，都是同做奴仆的。你应当敬拜神！因为有关耶稣的见证，才是预言<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="预言——或译作“做先知传道”。">i</a></sup>的灵魂所在<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="所在——辅助词语。">j</a></sup>。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="诗篇 96:13; 以赛亚书 11:3–5; 诗篇 98:9"> 接着，我看见天开了，看哪，有一匹白马。骑马的那一位被称为“信实的”和“真实的”；他以公义去审判、去作战。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 19:16; 路加福音 10:22; 启示录 2:17–18"> 他的眼睛像火焰，头上戴着许多王冠。他有一个写好的名字，除了他自己以外，没有人认识这名字。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 1:1; 以赛亚书 63:1–6; 约翰福音 1:14"> 他身穿一件浸过血的袍子；他的名字叫“神的话语<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="神的话语——或译作“神的道”。">k</a></sup>”。</span>
<span className="v" id="v14" data-v="14" data-xref="犹大书 1:14; 启示录 7:9; 启示录 19:8"> 天上的军兵，都骑着白马，身穿洁白干净的细麻衣，跟随着他。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 63:2–6; 启示录 1:16; 启示录 2:27"> 从他口中发出一把<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本附“双刃的”。">l</a></sup>利剑，好用它来击打列国。他将用铁杖治理<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="治理——原文直译“牧养”。">m</a></sup>列国，并且要践踏酒榨，就是神、全能者烈怒的酒榨。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 17:14; 提摩太前书 6:15; 但以理书 2:47"> 在他的袍子上、大腿上写着一个名号：“万王之王，万主之主。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="启示录 19:21; 启示录 8:13; 以西结书 39:17–20"> 随后，我看见一位天使站在太阳中<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="在太阳中——或译作“在太阳上”。">n</a></sup>，对所有在空中飞翔的鸟大声呼喊说：“来吧，聚集起来赴神的大宴席，</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 39:18–20; 启示录 6:15; 撒母耳记上 17:44"> 为要吃君王的肉、军官的肉、壮士的肉、马和骑士的肉，以及各种人的肉，包括自由人和奴隶，卑微人和尊贵人的肉。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="启示录 16:16; 启示录 16:14; 启示录 17:12–14"> 接着，我看见那兽和地上的众君王以及他们的军兵聚集在一起，要与骑白马的那一位和他的军队作战。</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 20:10; 启示录 21:8; 帖撒罗尼迦后书 2:8–11"> 但那兽被抓了；那假先知也与它一起被抓了——他在兽面前行了许多奇迹，藉此迷惑那些接受兽的印记并膜拜兽像的人。兽和那假先知两个都活生生地被丢进燃烧着硫磺的火湖里。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 19:11–15; 启示录 1:16; 启示录 19:17–19"> 其余的人，也都被骑白马那一位口中所发出的剑杀死了。所有的鸟都吃饱了他们的肉。</span>
</div>
</div>

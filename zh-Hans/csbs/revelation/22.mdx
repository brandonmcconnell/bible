<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 7:17; 约翰福音 4:14; 诗篇 36:8–9"> 接着，天使<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="天使——原文直译“他”。">a</a></sup>给我看一条生命水的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附“清净的”。">b</a></sup>河，明亮如水晶，从神和羔羊的宝座流出来，</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 22:1; 彼得前书 2:24; 启示录 2:7"> 从城的大街中间穿过。河的两边有生命树，结十二种果子；每个月都结果子，树上的叶子是为了医治万民。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 25:21; 启示录 21:3–4; 约翰福音 12:26"> 将来不再有任何诅咒。神和羔羊的宝座将要在城中，他的奴仆们将事奉他，</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 5:8; 启示录 14:1; 启示录 3:12"> 他们将要看到他的面容，而他的名字将要写<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="将要写——辅助词语。">c</a></sup>在他们的额上。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 60:19–20; 但以理书 7:18; 启示录 20:4"> 将来不再有黑夜<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="不再有黑夜——有古抄本作“那里不会有黑夜”。">d</a></sup>，他们不需要灯光<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="灯光——有古抄本作“灯”。">e</a></sup>或日光，因为主、神将照亮他们。他们将做王，直到永永远远。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="启示录 1:1; 启示录 21:5; 启示录 19:9"> 随后，天使<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="天使——原文直译“他”。">f</a></sup>对我说：“这些话是信实的、真实的。主——众先知之灵<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="先知之灵——有古抄本作“圣先知”。">g</a></sup>的神，差派了他的天使，要把这些必须快发生的事指示给他的奴仆们。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="启示录 1:3; 启示录 3:11; 启示录 22:20"> <span className="woj">“看哪，我快要来了！那遵守这书上预言之话的人，他是蒙福的！”</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="启示录 19:10; 启示录 1:1; 启示录 19:19"> 我约翰，是听见又看见这些事的人。我听见又看见了以后，就俯伏在那位指示我这些事的天使脚前，要敬拜他。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 19:10; 歌罗西书 2:18–19; 启示录 14:7"> 可是他对我说：“你要注意，不可这样！我和你，以及你的弟兄先知们，还有那些遵守这书上话语的人，都是同做奴仆的。你应当敬拜神！”</span>
<span className="v" id="v10" data-v="10" data-xref="但以理书 8:26; 启示录 1:3; 彼得前书 4:7"> 他又对我说：“不可封住这书上的预言之话，因为时候快到了。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 12:10; 箴言 4:18; 以西结书 3:27"> 行不义的，让他继续行不义；肮脏的，让他继续肮脏；公义的，让他继续行公义<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="行公义——有古抄本作“被称为义”。">h</a></sup>；圣洁的，让他继续被分别为圣。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 16:27; 以赛亚书 62:11; 以赛亚书 40:10"> <span className="woj">“看哪，我快要来了！我带着报偿，要按照各人的行为回报每个人。</span></span>
<span className="v" id="v13" data-v="13" data-xref="启示录 1:8; 启示录 21:6; 以赛亚书 44:6"> <span className="woj">我是‘阿尔法’，也是‘欧米伽’；是首先的，也是末后的；是开始，也是终结。</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="启示录 21:27; 约翰一书 5:3; 启示录 22:7"> <span className="woj">“凡是洗净自己袍子</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="洗净自己袍子——有古抄本作“遵行他命令”。">i</a></sup><span className="woj">，好使自己有权利到生命树那里，并且得以从城门进到城内的人——他们是蒙福的！</span></span>
<span className="v" id="v15" data-v="15" data-xref="启示录 21:8; 加拉太书 5:19–21; 腓立比书 3:2"> <span className="woj">那些犬类、行邪术的、淫乱的、杀人的、拜偶像的，以及所有爱虚假、行虚假的人，都在外面。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="启示录 5:5; 彼得后书 1:19; 以赛亚书 11:1"> <span className="woj">“我耶稣，派遣了我的使者</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="使者——或译作“天使”。">j</a></sup><span className="woj">，为各教会向你们见证了这些事。我就是大卫的根，也是他的后裔，那明亮的晨星。”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 4:14; 启示录 21:6; 以赛亚书 55:1–3"> 圣灵和新娘都说：“来吧！”那听见的人也当说：“来吧！”干渴的人也当来；愿意的人，当无偿地接受生命之水。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命记 12:32; 申命记 4:2; 箴言 30:6"> 我向一切听见这书上预言之话的人做见证<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="做见证——或译作“做警告”。">k</a></sup>：如果有人在这些话上加添什么，神将要把这书上所写的灾害加在他身上；</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 4:2; 路加福音 11:52; 启示录 22:2"> 如果有人从这书上的预言之话中删去什么<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="如果有人从这书上的预言之话中删去什么——或译作“如果有人删减这预言书中的话”。">l</a></sup>，神将要从这书上所写的生命树<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="生命树——有古抄本作“生命册”。">m</a></sup>和圣城中删去他的份。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="启示录 22:7; 希伯来书 9:28; 启示录 22:12"> 见证这些事的那一位说：<span className="woj">“是的，我快要来了！”</span><br />阿们！主耶稣啊，愿你来！</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="帖撒罗尼迦后书 3:18; 罗马书 16:20; 哥林多后书 13:14"> 愿主耶稣<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="主耶稣——有古抄本作“我们的主耶稣基督”。">n</a></sup>的恩典与所有的圣徒<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="所有的圣徒——有古抄本作“所有的人”或“你们大家”。">o</a></sup>同在！阿们。<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="有古抄本没有“阿们。”">p</a></sup></span>
</div>
</div>

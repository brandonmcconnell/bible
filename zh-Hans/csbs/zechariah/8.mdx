<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="ZEC" data-book-slug="zechariah" data-book-name="撒迦利亚书" data-chapter="8" data-verses="23">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 万军之耶和华的话语又临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="约珥书 2:18; 撒迦利亚书 1:14–16; 以赛亚书 42:13–14"> “万军之耶和华如此说：‘我为锡安大大嫉愤，以极大的愤怒为她嫉愤。’</span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亚书 1:16; 撒迦利亚书 2:10–11; 约翰福音 1:14"> 耶和华如此说：‘我要回到锡安，住在耶路撒冷中；耶路撒冷必被称为“真理之城”，万军之耶和华的山必被称为“圣山”。’</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 65:20–22; 约伯记 5:26; 耶利米哀歌 5:11–15"> 万军之耶和华如此说：‘年老的男人和女人必再次坐在耶路撒冷的广场上，他们因年纪老迈，个个手拿拐杖；</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 31:13; 马太福音 11:16–17; 耶利米书 30:19–20"> 城中的广场上必满是男孩和女孩，他们在广场上玩耍。’</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 32:27; 罗马书 4:20–21; 民数记 11:22–23"> 万军之耶和华如此说：‘在那些日子，这事在这余剩之民眼中看为奇妙，难道在我眼中也看为奇妙吗？’这是万军之耶和华的宣告。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 31:8; 罗马书 11:25–27; 玛拉基书 1:11"> 万军之耶和华如此说：‘看哪，我必从日出之地和日落之地拯救我的子民！</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 36:28; 以西结书 11:20; 耶利米书 31:33"> 我要把他们带回来，住在耶路撒冷中。他们必作我的子民，我必藉着真理和公义作他们的神。’</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 35:4; 历代志上 22:13; 以斯拉记 5:1–2"> “万军之耶和华如此说：‘在奠定万军之耶和华殿的根基、要建造圣殿的日子，你们这些当时听见众先知亲口说这些话的人，愿你们的手坚强！</span>
<span className="v" id="v10" data-v="10" data-xref="哈该书 1:6–11; 哈该书 2:16–18; 阿摩司书 3:6"> 因为在那些日子之前，人没有酬报，牲畜也没有酬报；因敌人的缘故，人出入都没有平安；我使所有的人彼此敌对。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 12:1; 哈该书 2:19; 撒迦利亚书 8:8–9"> 但如今，我对待这余剩之民必不像先前的日子那样。’万军之耶和华宣告：</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 26:4–5; 申命记 33:13; 创世记 27:28"> ‘和平的种子必被撒下<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="和平的种子必被撒下——原文直译“必有和平的种子”。">a</a></sup>，葡萄树必结果实，地必出收成，天必赐甘露；我要使这余剩之民继承这一切。</span>
<span className="v" id="v13" data-v="13" data-xref="西番雅书 3:20; 撒迦利亚书 8:9; 诗篇 72:17"> 犹大家和以色列家啊，你们曾经在列国中成了受诅咒的，现在我必拯救你们，使你们成为蒙祝福的！你们不要害怕，愿你们的手坚强！’</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 31:28; 以西结书 24:14; 耶利米书 4:28"> 万军之耶和华如此说：‘你们的祖先惹怒我的时候，我怎样决意向你们降下灾祸并不改变心意；</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 8:13; 弥迦书 7:18–20; 路加福音 12:32"> 照样，在这些日子，我必再次决意要善待耶路撒冷和犹大家。’万军之耶和华说：‘你们不要害怕！</span>
<span className="v" id="v16" data-v="16" data-xref="以弗所书 4:25; 撒迦利亚书 7:9; 诗篇 15:2"> 你们当行这些事：各人要与邻人说真话，要在你们的城门口施行真理与和平的审判。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 6:16–19; 弥迦书 2:1–3; 耶利米书 44:4"> 各人不要在心里向邻人谋划恶事，不要喜爱起假誓，因为这一切都是我所恨恶的。’这是耶和华的宣告。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 万军之耶和华的话语临到我，说：</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 8:16; 耶利米书 39:2; 撒迦利亚书 7:5"> “万军之耶和华如此说：‘四月的禁食、五月的禁食、七月的禁食和十月的禁食，都将成为犹大家的欢乐、喜乐、快乐的节期；你们要喜爱真理与和平。’</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 2:2–3; 弥迦书 4:1–2; 撒迦利亚书 2:11"> 万军之耶和华如此说：‘必有众民，就是许多城市的居民再次前来，</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亚书 7:2; 何西阿书 6:3; 诗篇 146:1–2"> 一个城市的居民将到另一个城市去说：“我们快去恳求耶和华的恩宠，寻求万军之耶和华吧！我也去！”</span>
<span className="v" id="v22" data-v="22" data-xref="撒迦利亚书 8:21; 以赛亚书 60:3–22; 启示录 21:24"> 必有许多的民和强盛的国家前来，在耶路撒冷寻求万军之耶和华，恳求耶和华的恩宠。’</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 55:5; 哥林多前书 14:25; 以赛亚书 60:3"> 万军之耶和华如此说：‘在那些日子，列国的语言群体中，必有十个人抓住一个犹太人的衣襟，说：让我们与你们同去，因为我们听说神与你们同在。’”</span>
</div>

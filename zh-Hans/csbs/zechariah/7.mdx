<span className="v" id="v1" data-v="1" data-xref="尼希米记 1:1; 以斯拉记 6:14–15; 撒迦利亚书 1:1"> 大流士王四年的九月（基斯流月）四日，耶和华的话语临到撒迦利亚。</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亚书 8:21; 耶利米书 26:19; 撒母耳记上 13:12"> 那时，伯特利人派遣了沙利色、利坚·米勒和随同他们的人，去恳求耶和华的恩宠，</span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亚书 8:19; 雅各书 4:8–10; 玛拉基书 2:7"> 问万军之耶和华殿中的祭司们和先知们说：“我们还要像这许多年来所做的那样，在五月哭泣、禁食吗？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 10:16"> 于是万军之耶和华的话语临到我，说：</span>
<span className="v" id="v5" data-v="5" data-xref="撒迦利亚书 1:12; 以赛亚书 58:4–6; 哥林多前书 10:31"> “你要对这地所有的民众和祭司说：‘这七十年来，你们在五月和七月禁食、哀哭，是真的为我禁食吗？</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 11:20–21; 哥林多前书 11:26–29; 何西阿书 8:13"> 当你们吃喝的时候，难道不是为自己吃，为自己喝吗？</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 1:16–20; 耶利米书 17:26; 耶利米书 7:5"> 这些话语难道不是耶和华藉着先前的众先知所宣告的吗？那时，耶路撒冷和四围的各城都有人居住，并且很安稳，南地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="南地——音译作“内盖夫”。">a</a></sup>和丘陵地带也有人居住。’”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 耶和华的话语又临到撒迦利亚，说：</span>
<span className="v" id="v9" data-v="9" data-xref="弥迦书 6:8; 诗篇 82:2–4; 箴言 21:3"> “万军之耶和华如此说：‘你们要施行真理的审判，各人要以恩慈和怜悯对待自己的兄弟。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 5:28; 以赛亚书 1:23; 雅各书 5:4"> 不要欺压寡妇、孤儿、寄居者和困苦人，各人不要在心里向自己的兄弟谋划恶事。’</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 9:29; 耶利米书 8:5; 何西阿书 4:16"> 然而，他们不肯留心听，竟扭转顽梗的肩头，充耳不闻；</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 11:19; 尼希米记 9:29–30; 历代志下 36:16"> 他们使自己的心硬如金刚石，不听从律法，不听从万军之耶和华藉着他的灵和先前的众先知所发出的话语。因此，有极大的震怒从万军之耶和华而来。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 1:24–28; 耶利米书 14:12; 以赛亚书 1:15"> 万军之耶和华说：‘既然我呼唤他们，他们不听，那么他们呼唤我，我也不听。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 28:33; 申命记 28:64; 耶利米书 23:19"> 我用旋风把他们吹散到他们不认识的万国去；他们身后的地变得荒凉，无人往来经过，他们使那美好之地成了荒场。’”</span>
</div>

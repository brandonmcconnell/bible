<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖记 9:20; 使徒行传 15:23; 希伯来书 13:22"> 以下是一封信中的话语，先知耶利米把书信从耶路撒冷送给了掳民中幸存的长老们，祭司和先知们以及全体民众，就是尼布甲尼撒从耶路撒冷掳到巴比伦的人。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 22:24–28; 耶利米书 27:20; 历代志下 36:9–10"> 这封信是在耶哥尼雅王、太后和内臣、犹大和耶路撒冷的首领们，以及木匠和铁匠离开耶路撒冷之后，</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 8:11; 历代志下 34:20; 耶利米书 39:14"> 藉着沙番的儿子以利亚萨和希勒加的儿子基玛利的手送去的；这二人被犹大王西底加派遣去巴比伦，到巴比伦王尼布甲尼撒那里。信中说：</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="耶利米书 24:5; 以赛亚书 10:5–6; 以赛亚书 45:7"> 以色列的神万军之耶和华对所有的掳民，就是耶和华使他们从耶路撒冷被掳到巴比伦的人，如此说：</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="耶利米书 29:28; 耶利米书 29:10; 以西结书 28:26"> “你们要建造房屋住下来，栽种果园，吃园中的果实。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 24:3–4; 创世记 24:51; 创世记 28:1–4"> 你们要娶妻，生养儿女；并为你们的儿子娶妻，使你们的女儿出嫁，让他们也生养儿女。你们要在那里增多，不要减少。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前书 2:1–2; 以斯拉记 6:10; 彼得前书 2:13–17"> 你们要为那城，就是我把你们流放到的那城求平安，为它向耶和华祈求；因为它有平安，你们也就有平安。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以弗所书 5:6; 耶利米书 5:31; 帖撒罗尼迦后书 2:9–11"> 以色列的神万军之耶和华如此说：<br />“不要让你们中间的先知和你们的占卜者欺哄你们，也不要听从你们做梦者所得的梦。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 27:15; 耶利米书 29:31; 耶利米书 29:23"> 因为他们奉我名向你们说的神言是谎言，我并没有派遣他们。这是耶和华的宣告。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="但以理书 9:2; 撒迦利亚书 7:5; 耶利米书 24:6–7"> 事实上，耶和华如此说：<br />“巴比伦的七十年期限满了以后，我必眷顾你们，为你们成就我美好的应许，把你们带回这地方。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 55:8–12; 诗篇 33:11; 弥迦书 4:12"> 我知道我为你们安排的计划，是平安的计划，不是降祸的计划，好使你们有前途和希望。这是耶和华的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 7:7–8; 耶利米书 33:3; 诗篇 50:15"> “那时你们呼求我，来向我祷告，我必垂听你们。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 4:29–31; 诗篇 119:2; 马太福音 7:7"> 你们寻找我，如果全心寻求我，就必找到；</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 36:1–38; 耶利米书 30:3; 历代志上 28:9"> 我必使你们找到我。这是耶和华的宣告。我也必使你们的掳民回归，把你们从我驱赶你们到的各国各地招聚起来，带回到我使你们被掳离开的地方。这是耶和华的宣告。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米书 29:8–9; 耶利米书 28:1–17; 以西结书 1:3"> 因为你们说“耶和华已经在巴比伦为我们兴起了众先知”，</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 38:2–3; 耶利米书 38:17–23; 以西结书 17:12–21"> 所以论到坐大卫宝座的王，以及住在这城的全体民众，就是没有与你们一起被掳去的同胞们，</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 24:8–10; 耶利米书 29:18; 耶利米书 24:1–3"> 万军之耶和华如此说：<br />“看哪，我必使刀剑、饥荒和瘟疫临到他们，使他们像腐烂的无花果，坏得不能吃。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 29:8; 耶利米书 15:4; 耶利米书 42:18"> 我必用刀剑、饥荒和瘟疫追赶他们，使他们令地上的万国战兢，在我驱赶他们到的所有国家中受诅咒、令人惊骇、被嗤笑、被羞辱，</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 6:19; 耶利米书 26:5; 耶利米书 7:24–26"> 因为他们不听从我的话。这是耶和华的宣告。我派遣我的仆人众先知到他们那里去，不断地派遣，他们却不听从。这是耶和华的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="耶利米书 24:5; 弥迦书 4:10; 以西结书 3:15"> “因此你们所有的掳民，就是我从耶路撒冷流放到巴比伦的人，都要听耶和华的话语。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 14:14–15; 耶利米哀歌 2:14; 耶利米书 29:8–9"> 论到奉我名向你们说假预言的科赖雅的儿子亚哈和玛西雅的儿子西底加，以色列的神万军之耶和华如此说：看哪，我必把这二人交在巴比伦王尼布甲尼撒手中，他将在你们眼前击杀他们。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 65:15; 但以理书 3:6; 但以理书 3:21"> 所有在巴比伦的犹大掳民，都会以他们诅咒人，说：‘愿耶和华使你像巴比伦王用火焚烧的西底加和亚哈那样！’</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 23:14; 希伯来书 4:13; 玛拉基书 3:5"> 因为他们在以色列做了丑恶的事，与邻人的妻子通奸，又藉我的名说我没有吩咐过他们的假话。我是知情者，也是见证人。这是耶和华的宣告。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米书 29:31–32"> “你要告诉尼希兰人示玛雅说，</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 37:3; 耶利米书 29:29; 耶利米书 52:24"> 以色列的神万军之耶和华如此说：你竟然用自己的名义送信给在耶路撒冷的全体民众，以及玛西雅的儿子祭司西番雅和所有的祭司，说：</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="耶利米书 20:1–2; 列王纪下 9:11; 约翰福音 10:20"> ‘耶和华已经立你西番雅为祭司，代替祭司耶赫亚达，作耶和华殿的监督，处治所有发狂说神言的人，给他们戴上枷锁和铁枷。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 25:16; 耶利米书 43:2–3; 耶利米书 29:26"> 现在，你为什么不斥责向你们说神言的亚拿突人耶利米呢？</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 29:5; 耶利米书 29:1; 耶利米书 29:10"> 因为他送信给我们在巴比伦的人，说：流亡必长久；你们要建造房屋住下来，栽种果园，吃园中的果实。’</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="耶利米书 29:25"> “祭司西番雅把这封信宣读给先知耶利米听，</span>
<span className="v" id="v30" data-v="30"> 所以耶和华的话语临到耶利米，说：</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米书 29:9; 耶利米书 29:23–24; 耶利米书 14:14–15"> 你要送信给所有的掳民说，论到尼希兰人示玛雅，耶和华如此说：‘示玛雅向你们说神言，我并没有派遣他，他竟使你们依靠虚谎。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 28:16; 列王纪下 7:19–20; 耶利米书 17:6"> 因此耶和华如此说：看哪，我必惩罚尼希兰人示玛雅和他的后裔！他必不会有后裔住在这子民中间，也不会看到我要为子民做的美事，因为他对耶和华说了叛逆的话。这是耶和华的宣告。’”</span>
</div>
</div>

</div>

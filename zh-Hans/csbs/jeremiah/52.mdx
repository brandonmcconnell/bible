<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 24:18; 约书亚记 10:29; 历代志下 36:11"> 西底加作王的时候二十一岁，在耶路撒冷统治了十一年。他的母亲名叫哈慕她勒，是立拿人耶利米的女儿。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 14:22; 列王纪下 24:19–20; 以西结书 17:16–20"> 西底加效法约雅敬所做的一切，做耶和华眼中看为恶的事。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 3:4–5; 历代志下 36:13; 以赛亚书 3:1"> 因此耶和华发怒，这些事就临到耶路撒冷和犹大，直到耶和华把他们从自己面前赶走了。后来，西底加背叛了巴比伦王。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="耶利米书 39:1; 撒迦利亚书 8:19; 以西结书 24:1–2"> 西底加在位第九年的十月十日，巴比伦王尼布甲尼撒率领全军来攻打耶路撒冷。他们在城外扎营，在城的四围造台筑垒。</span>
<span className="v" id="v5" data-v="5"> 城被围困，直到西底加王十一年。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="耶利米书 39:2; 以赛亚书 3:1; 列王纪下 25:3"> 到了四月九日，城中饥荒严重，当地百姓没有粮食了。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 39:4–7; 耶利米书 51:32; 列王纪下 25:4"> 城就被攻破，所有的战士从王室园子旁边两道城墙之间的门趁夜逃出城；那时迦勒底人正围攻这城。他们沿着亚拉巴方向的路逃走，</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 34:21; 耶利米书 32:4; 耶利米书 38:23"> 迦勒底军队追赶西底加王，在耶利哥平原追上了他，王的全军从他身边四散。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 39:5; 民数记 13:21; 列王纪下 25:6"> 迦勒底人捉住王，把他带到哈马地的利比拉，到巴比伦王那里，王就对他宣告裁决。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 22:30; 列王纪下 25:7; 创世记 21:16"> 巴比伦王在西底加眼前把他的儿子们杀了，在利比拉把犹大的众首领也都杀了，</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 12:13; 耶利米书 34:3–5"> 并且弄瞎西底加的双眼，用铜链捆住他。巴比伦王把他带到巴比伦去，关在监牢里，直到他死的日子。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王纪下 25:8; 耶利米书 39:9; 耶利米书 52:29"> 巴比伦王尼布甲尼撒王十九年的五月十日，在巴比伦王面前侍立的护卫长尼布撒拉旦进入耶路撒冷。</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 79:1; 弥迦书 3:12; 历代志下 36:19"> 他烧毁了耶和华的殿和王宫，以及耶路撒冷所有的房屋；所有高大的建筑，他都放火烧毁了。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 1:3; 列王纪下 25:10"> 护卫长率领的迦勒底全军还拆毁了耶路撒冷四围所有的城墙。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 15:1–2; 撒迦利亚书 14:2"> 护卫长尼布撒拉旦把民中一些穷人，还有城中残留的其余民众和那些之前向巴比伦王投降的人，以及其余的工匠，都掳走了。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 25:12; 耶利米书 39:9–10; 耶利米书 40:5–7"> 但护卫长尼布撒拉旦留下当地一些穷人，作葡萄园丁和耕田的农夫。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="耶利米书 27:19–22; 耶利米书 52:21–23; 历代志下 4:12–15"> 迦勒底人打碎了耶和华殿的铜柱，以及耶和华殿中的铜盆底座和铜海，把这些铜全都运到巴比伦去。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 27:3; 民数记 4:14; 列王纪上 7:45"> 他们带走了锅、铲子、蜡剪、碗、勺子，以及事奉用的所有铜器。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 7:49–50; 历代志下 4:6–22; 利未记 26:12"> 还有钵、盘子、碗、锅、灯台、勺子、祭酒杯，凡是纯金的、纯银的，护卫长都带走了。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王纪上 7:47; 列王纪下 25:16; 历代志下 4:18"> 所罗门王为耶和华殿制作的两根柱子，一个铜海和底座下面的十二头铜牛，这一切器物所用铜的重量无法确定。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 25:17; 列王纪上 7:15–21; 历代志下 3:15–17"> 两根柱子，一根柱子高十八肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十八肘——相当于8.2公尺。1肘=45.7公分。">a</a></sup>，周长十二肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="十二肘——相当于5.5公尺。">b</a></sup>，厚四指，是空心的，</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 28:25; 列王纪下 25:17; 历代志下 3:15"> 顶上有铜柱头，一个柱头高五肘<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="五肘——相当于2.3公尺。">c</a></sup>，柱头上环绕着网格和石榴，都是铜的。另一根柱子也一样，也有石榴。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 7:20"> 柱子周边的石榴有九十六个，网格周围全部的石榴有一百个。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王纪下 25:18; 耶利米书 29:25; 耶利米书 35:4"> 护卫长捉住了祭司长西莱雅、副祭司长西番雅和三个门卫，</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 25:19; 以斯帖记 1:14; 马太福音 18:10"> 他在城里还捉住一个监督军兵的内臣，七个留在城里的王室近臣，一个招募当地百姓的将军秘书，以及六十个留在城里的当地百姓。</span>
<span className="v" id="v26" data-v="26"> 护卫长尼布撒拉旦捉住他们，把他们带到利比拉，到巴比伦王那里。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 33:28; 以赛亚书 32:13–14; 以赛亚书 6:11–12"> 巴比伦王击杀他们，在哈马地的利比拉把他们处死了。这样犹大人就从自己的国土被掳走了。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王纪下 24:12–16; 列王纪下 24:2–3; 但以理书 1:1–3"> 以下是尼布甲尼撒所掳走的民众：他在位第七年，掳走犹大人三千零二十三人；</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 52:12; 创世记 12:5; 列王纪下 25:11"> 尼布甲尼撒十八年，从耶路撒冷掳走八百三十二人；</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 52:15; 耶利米书 6:9"> 尼布甲尼撒二十三年，护卫长尼布撒拉旦掳走犹大人七百四十五人；总共有四千六百人。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪下 25:27–30; 诗篇 3:3; 创世记 40:13"> 在犹大王约雅斤被掳后三十七年的十二月二十五日，也就是巴比伦王伊莫米罗达作王的那一年，巴比伦王恩赦<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="恩赦——原文直译“抬起～的头”。">d</a></sup>犹大王约雅斤，把他从牢房释放出来，</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 12:25; 但以理书 5:18–19; 但以理书 2:37"> 对他说和善的话，使他的地位高过那些与他同在巴比伦的王。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 9:7; 列王纪上 2:7; 创世记 41:14"> 约雅斤换下囚服，以后终生常在王面前吃饭。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记下 9:10; 路加福音 11:3; 马太福音 6:11"> 至于他的饮食，从巴比伦王那里有份例赐给他，每天一份，终生都是如此，直到他去世的日子。</span>
</div>
</div>

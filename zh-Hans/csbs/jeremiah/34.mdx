<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 1:15; 但以理书 2:37–38; 列王纪下 25:1–9"> 巴比伦王尼布甲尼撒和他的全军，以及他所统治的地上各国各族，攻打耶路撒冷和所有附属的城镇，那时有话语从耶和华临到耶利米，说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 21:10; 耶利米书 34:22; 耶利米书 37:8–10"> “以色列的神耶和华如此说：你去告诉犹大王西底加说，耶和华如此说：看哪，我要把这城交在巴比伦王手中，他必放火烧毁这城。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 32:4; 耶利米书 21:7; 列王纪下 25:4–7"> 你绝不会从他手中逃脱，一定会被抓住，交在他手中。你必与巴比伦王眼对眼相看，面对面说话；你必到巴比伦去。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> “然而，犹大王西底加啊，你要听耶和华的话语！论到你，耶和华如此说：你必不会死在刀下，</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 22:18; 历代志下 16:14; 列王纪下 22:20"> 而会平安死去。人们怎样为你的祖先，就是为你之前的君王们焚烧香料，也必怎样为你焚烧香料，并且为你哀哭说：‘哀哉，我主啊！’是的，我说了这话。这是耶和华的宣告。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 15:16–24; 撒母耳记上 3:18; 列王纪上 21:19"> 于是先知耶利米在耶路撒冷把这一切话语都告诉了犹大王西底加。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 10:3; 耶利米书 4:5; 列王纪下 18:13–14"> 那时巴比伦王的军队正攻打耶路撒冷和犹大剩下的城镇，就是拉吉和亚西加，因为在犹大的城镇中，只剩下这两座堡垒城。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未记 25:10; 列王纪下 23:2–3; 列王纪下 11:17"> 有话语从耶和华临到耶利米。此前西底加王与耶路撒冷的全体民众立约，向仆婢宣告自由：</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 15:12; 利未记 25:39–46; 出埃及记 3:18"> 各人要释放自己的希伯来男仆和婢女，谁也不可奴役他的兄弟犹大人。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 26:16; 耶利米书 26:10; 耶利米书 38:4"> 所有立约的首领和全体民众都听从，各人释放了自己的男仆和婢女，不再奴役他们。他们都听从，把仆婢释放了，</span>
<span className="v" id="v11" data-v="11" data-xref="彼得后书 2:20–22; 箴言 26:11; 马太福音 12:43–45"> 后来却反悔，把释放的那些男仆和婢女带回来，强迫他们再作仆婢。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 于是耶和华的话语从耶和华临到耶利米，说：</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 6:8; 约书亚记 24:17; 申命记 5:27"> “以色列的神耶和华如此说：我把你们祖先从埃及地、从为奴之家领出来的日子里，曾与他们立约说：</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 15:12; 列王纪上 9:22; 列王纪下 17:13–14"> ‘每七年的最后一年，你们各人要释放那被卖给你、服事了你六年的希伯来兄弟，要释放他，让他离开你得自由。’你们的祖先却不听从我，不侧耳听。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 34:8; 列王纪下 23:3; 尼希米记 10:29"> 如今你们回转了，做我眼中看为正的事，各人向自己的邻人宣告自由，并且在这被称为我名下的殿宇里，在我面前立了约；</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 19:12; 出埃及记 20:7; 耶利米书 34:11"> 你们却又反悔，亵渎了我的名，各人把那些得释放随心自由离去的男仆和婢女带回来，强迫他们再作你们的仆婢。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 7:2; 申命记 28:25; 加拉太书 6:7"> “因此耶和华如此说：既然你们不听从我，各人不向自己的兄弟和邻舍宣告自由；看哪，我必向你们宣告自由，让你们遭遇刀剑、瘟疫和饥荒，使你们令地上的万国战兢。这是耶和华的宣告。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 15:10; 创世记 15:17–18; 何西阿书 6:7"> 那些违背我的约，不遵行在我面前所立的誓约的人，我必使他们遭报，如同他们所劈成两半，并从两半之间经过的牛犊。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 34:10; 西番雅书 3:3–4; 但以理书 9:6"> 犹大的首领、耶路撒冷的首领、内臣和祭司，以及这地的全体民众，就是那些从牛犊两半之间经过的人，</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 7:33; 耶利米书 16:4; 耶利米书 19:7"> 我要把他们交在他们仇敌手中和寻索他们性命的人手中，他们的尸体必给天空的飞鸟和地上的走兽作食物。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 52:24–27; 耶利米书 39:6; 耶利米书 52:10"> 我也要把犹大王西底加和他的首领们交在他们仇敌手中和寻索他们性命的人手中，以及那些从你们面前撤离的巴比伦王军队手中。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 9:11; 耶利米书 39:8; 耶利米书 39:1–2"> 看哪，我要下令，使巴比伦王的军队回到这城，攻打它，攻取它，放火烧毁。我要使犹大的各城变得荒凉，无人居住。这是耶和华的宣告。”</span>
</div>

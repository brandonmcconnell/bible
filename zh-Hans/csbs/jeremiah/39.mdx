<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 24:1–2; 耶利米书 52:4–7; 列王纪下 25:1–12"> 耶路撒冷被攻取的时候是这样的：犹大王西底加九年十月，巴比伦王尼布甲尼撒和他的全军来到耶路撒冷，围困这城；</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 52:6–7; 弥迦书 2:12–13; 列王纪下 25:3–4"> 西底加十一年四月九日，城被攻破。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 21:4; 耶利米书 38:17; 耶利米书 39:13"> 巴比伦王所有的首领，就是尼甲沙利薛，叁甲尼波，内侍长撒西金，大总管尼甲沙利薛，以及巴比伦王其余的众首领，都进了城，坐镇在中门。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="阿摩司书 2:14; 历代志下 32:5; 列王纪下 25:4–7"> 那时，犹大王西底加和所有的战士看见他们，就从王室园子两道城墙之间的门趁夜逃出城，沿着亚拉巴方向的路逃去。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 23:33; 约书亚记 5:10; 耶利米书 52:26–27"> 迦勒底军队追赶他们，在耶利哥平原追上了西底加，捉住他，把他带到哈马地的利比拉，到巴比伦王尼布甲尼撒那里。尼布甲尼撒就对他宣告裁决。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="耶利米书 52:10; 耶利米书 34:19–21; 耶利米书 24:8–10"> 巴比伦王在利比拉，在西底加眼前把他的儿子们杀了。巴比伦王还杀了犹大所有的贵族，</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 12:13; 列王纪下 25:7; 耶利米书 52:11"> 并且弄瞎西底加的双眼，用铜链捆住他，要把他带到巴比伦去。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米记 1:3; 耶利米书 38:18; 耶利米书 21:10"> 迦勒底人放火烧毁了王宫和民众的房屋，也拆毁了耶路撒冷的城墙。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 40:1; 创世记 37:36; 耶利米书 10:18"> 护卫长尼布撒拉旦把城中残留的其余民众和那些之前向他投降的人，以及其余的余剩之民，都掳到了巴比伦。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 25:12; 耶利米书 40:7; 耶利米书 52:16"> 至于民中那些一无所有的穷人，护卫长尼布撒拉旦把他们留在犹大地，当时也给了他们一些葡萄园和田地。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 24:23; 耶利米书 15:21; 约伯记 5:19"> 巴比伦王尼布甲尼撒为耶利米吩咐护卫长尼布撒拉旦，说：</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 16:7; 耶利米书 40:4; 箴言 21:1"> “你把他带走，看顾他，不可做任何伤害他的事。他对你怎样说，你就怎样做。”</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 39:3; 耶利米书 39:9"> 于是护卫长尼布撒拉旦、内侍长尼布沙斯班、大总管尼甲沙利薛，以及巴比伦王所有的高官，就派人去，</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 38:28; 列王纪下 22:12; 耶利米书 26:24"> 把耶利米从护卫兵院子里带出来，交给沙番之子亚希甘的儿子基大利，让他把耶利米带回家。这样，耶利米就住在民众当中。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="提摩太后书 2:9; 耶利米书 32:1–2; 耶利米书 36:1–5"> 耶利米还被拘禁在护卫兵院子里的时候，耶和华的话语临到他说：</span>
<span className="v" id="v16" data-v="16" data-xref="但以理书 9:12; 撒迦利亚书 1:6; 约书亚记 23:14–15"> “你去告诉库实人伊伯米勒说，以色列的神万军之耶和华如此说：看哪，我必使我的话语临到这城，降祸而不降福！到那日，这一切必在你面前发生。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 41:1–2; 诗篇 91:14–15; 诗篇 50:15"> 到那日，我却要解救你，你不会被交在你所惧怕的那些人手中。这是耶和华的宣告。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 38:2; 诗篇 34:22; 耶利米书 21:9"> 我必定拯救你，你不会倒在刀下。你必保住自己的性命<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你必保住自己的性命——原文直译“你的性命必作为战利品归于你”。">a</a></sup>，因为你依靠我。这是耶和华的宣告。”</span>
</div>

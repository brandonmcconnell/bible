<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 39:1–2; 列王纪下 25:1–2; 耶利米书 25:1"> 犹大王西底加十年，就是尼布甲尼撒十八年，有话语从耶和华临到耶利米。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 37:21; 尼希米记 3:25; 耶利米书 33:1"> 那时巴比伦王的军队正围困耶路撒冷，先知耶利米被囚禁在犹大王宫中护卫兵的院子里。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 34:2–3; 耶利米书 21:4–7; 耶利米书 26:8–9"> 犹大王西底加囚禁他时，问他：“你为什么这样预言呢？你说：‘耶和华如此说：看哪，我要把这城交在巴比伦王手中，他必攻取这城。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 39:4–7; 列王纪下 25:4–7; 耶利米书 37:17"> 犹大王西底加必不能从迦勒底人手中逃脱，一定会被交在巴比伦王手中；他们必面对面说话，眼对眼相看。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 39:7; 以西结书 17:9–10; 以西结书 17:15"> 巴比伦王必把西底加带到巴比伦，西底加必留在那里，直到我眷顾他的时候。即使你们与迦勒底人争战，也不会成功。这是耶和华的宣告。’”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 耶利米说：<br />耶和华的话语临到我，说：</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 1:1; 耶利米书 11:21; 利未记 25:25"> “看哪，你叔叔沙勒姆的儿子哈拿米列必来见你，说：‘请你买下我在亚纳图的那块田地，因为你有买它的赎回权。’”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="耶利米书 32:7; 耶利米书 32:2; 耶利米书 33:1"> 之后，正如耶和华所说的，我叔叔的儿子哈拿米列来到护卫兵的院子见我，对我说：“请你买下我在便雅悯地亚纳图的那块田地，因为你有继承权和赎回权。你买下来吧！”我就知道这是耶和华的话语。</span>
<span className="v" id="v9" data-v="9" data-xref="撒迦利亚书 11:12–13; 以斯帖记 3:9; 列王纪上 20:39"> 于是我向我叔叔的儿子哈拿米列买下亚纳图的那块田地，称了十七谢克尔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十七谢克尔——相当于193.8公克。1谢克尔=11.4公克。">a</a></sup>银子给他。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 32:44; 耶利米书 32:12; 耶利米书 32:25"> 我在契约上签了字，然后封印，又请人做见证，并用天平称了银子。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 2:27; 哥林多前书 11:16; 使徒行传 26:3"> 然后我拿起含有细则和条款的购买契约，一份是封印的，一份是未封的，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 32:16; 耶利米书 51:59; 耶利米书 36:4–5"> 当着我叔叔的儿子哈拿米列的面，当着那些在购买契约上签字的见证人的面，当着所有坐在护卫兵院子里的犹大人的面，把购买契约交给了玛西雅的孙子、尼利亚的儿子巴录克。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 我当着他们的面，吩咐巴录克说：</span>
<span className="v" id="v14" data-v="14"> “以色列的神万军之耶和华如此说：你要把封印的和未封的这两份购买契约，拿去放在瓦器里，好使它们存留许多日子。</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 3:10; 阿摩司书 9:14–15; 耶利米书 30:18"> 因为以色列的神万军之耶和华如此说：在这地，人们必再次购买房屋、田地和葡萄园。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米书 12:1; 创世记 32:9–12; 腓立比书 4:6–7"> 我把购买契约交给尼利亚的儿子巴录克之后，向耶和华祷告说：</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 1:37; 耶利米书 32:27; 创世记 18:14"> “唉，主耶和华啊！看哪，是你以伟大的能力和伸出的膀臂造了诸天和大地，在你没有任何难成的事。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 10:16; 申命记 5:9–10; 出埃及记 34:7"> 你施行慈爱，直到千代，又把父亲的罪孽报应在他们的后代子孙怀中。伟大全能的神哪，万军之耶和华是你<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="你——原文直译“他”。">b</a></sup>的名！</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 17:10; 马太福音 16:27; 诗篇 62:12"> 你谋事有大略，行事有大能；你睁眼看世人一切的道路，要照着各人的道路，照着他行为所结的果实回报各人。</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米记 9:10; 撒母耳记下 7:23; 出埃及记 10:2"> 你曾在埃及地施行神迹和奇事，在以色列和世人中间也是如此，直到今日；你为自己成就了名声，就像今日这样。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 6:6; 申命记 26:8; 诗篇 105:43"> 你曾用神迹、奇事、大能的手、伸出的膀臂和极其可畏的事，把你的子民以色列从埃及地领出来，</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 3:8; 出埃及记 13:5; 耶利米书 11:5"> 又把这地赐给他们，就是你曾向他们的祖先起誓要赐给他们的流奶与蜜之地。</span>
<span className="v" id="v23" data-v="23" data-xref="以斯拉记 9:7; 诗篇 78:54–55; 但以理书 9:10–14"> 他们进去占有了这地，却不听从你的话，也不遵行你的律法；你吩咐他们做的任何事，他们都不做，所以你使这一切祸患临到他们。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 32:36; 申命记 4:26; 约书亚记 23:15–16"> 看哪，攻城的土垒已经迫近这城，要攻破它了！因刀剑、饥荒和瘟疫，这城被交在攻打它的迦勒底人手中。你所说的都成就了，看哪，你也都看见了！</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 32:24; 诗篇 97:2; 诗篇 77:19"> 主耶和华啊，你却对我说‘你要用银子为自己买下那块田地，并且请人做见证’，其实这城已经被交在迦勒底人手中了。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和华的话语临到耶利米，说：</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 19:26; 耶利米书 32:17; 以赛亚书 64:8"> “看哪，我是耶和华，是一切有血肉者的神。难道在我有什么难成的事吗？</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 32:3; 耶利米书 32:24; 耶利米书 19:7–12"> 耶和华如此说：看哪，我要把这城交在迦勒底人手中和巴比伦王尼布甲尼撒手中，他必攻取这城。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 21:10; 耶利米书 19:13; 耶利米书 52:13"> 攻打这城的迦勒底人必进来，放火烧毁这城和其中的房屋，因为在那些房屋顶上，人们曾向巴力烧香，向别的神浇奠酒祭，以致惹我恼怒。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 7:22–26; 申命记 9:7–12; 耶利米书 25:7"> 实际上，以色列子民和犹大子民从年幼时就专做我眼中看为恶的事，以色列子民专以他们手所造的惹怒我。这是耶和华的宣告。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 23:27; 耶利米书 27:10; 列王纪下 21:4–7"> 这城自从建造的那天起，直到今日，常惹动我的怒气和怒火，以致我要把这城从我面前除掉。</span>
<span className="v" id="v32" data-v="32" data-xref="但以理书 9:8; 耶利米书 2:26; 以赛亚书 1:4–6"> 以色列子民和犹大子民，就是他们和他们的君王、首领、祭司、先知，以及犹大人和耶路撒冷居民，以他们所做的一切恶事惹怒我。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 7:13; 耶利米书 2:27; 以西结书 8:16"> 他们转身背对着我，不面向我；我不断地教导他们，他们却不听从，不接受管教。</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米书 7:30; 以西结书 8:5–16; 列王纪下 21:4–7"> 他们把自己的可憎偶像放在这被称为我名下的殿宇里，玷污了它。</span>
<span className="v" id="v35" data-v="35" data-xref="耶利米书 7:31; 历代志下 33:6; 利未记 18:21"> 他们建造欣嫩子谷中的巴力高坛，为要把自己的儿女经火献给摩洛。这不是我所吩咐他们的，我也从来没有这样想过；他们行这可憎之事，以致犹大陷入罪恶。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="耶利米书 32:24; 耶利米书 32:3; 耶利米书 32:28"> “现在，论到这城，就是你们说‘因着刀剑、饥荒和瘟疫，被交在巴比伦王手中’的这城，以色列的神耶和华如此说：</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 23:3; 耶利米书 23:6; 以西结书 34:12–14"> 看哪，我必从各地，就是我在怒气、怒火和大震怒中驱赶他们所到的地方，把他们招聚起来，使他们回到这地方，安然居住。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米书 24:7; 以西结书 11:19–20; 希伯来书 8:10"> 他们要作我的子民，我要作他们的神。</span>
<span className="v" id="v39" data-v="39" data-xref="以西结书 11:19–20; 使徒行传 4:32; 约翰福音 17:21"> 我要使他们同心、同路，好让他们终日敬畏我，使他们和他们的后代子孙得享福份。</span>
<span className="v" id="v40" data-v="40" data-xref="耶利米书 31:31–33; 以西结书 36:26; 耶利米书 24:7"> 我要与他们立一个永远的约：我绝不转离他们，而要向他们施恩；我要使他们心中敬畏我，不再离开我。</span>
<span className="v" id="v41" data-v="41" data-xref="耶利米书 24:6; 西番雅书 3:17; 以赛亚书 62:5"> 我必乐意向他们施恩，全心、全灵、信实地把他们栽种在这地上。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="耶利米书 31:28; 约书亚记 23:14–15; 耶利米书 33:10–11"> “是的，耶和华如此说：我怎样使这一切大祸患临到这子民，也必怎样使我应许他们的一切福份临到他们。</span>
<span className="v" id="v43" data-v="43" data-xref="以西结书 37:11–14; 耶利米书 32:15; 耶利米书 32:36"> 在你们说‘荒凉，没有人，也没有牲畜，已被交在迦勒底人手中’的这地上，必有人购买田地。</span>
<span className="v" id="v44" data-v="44" data-xref="耶利米书 17:26; 耶利米书 33:26; 耶利米书 33:11"> 在便雅悯地、耶路撒冷的四围、犹大的各城、山地的各城、丘陵的各城和南地<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="南地——音译作“内盖夫”。">c</a></sup>的各城，人们必用银子购买田地，在契约上签字、封印，又请见证人做见证，因为我必使他们的掳民回归。这是耶和华的宣告。”</span>
</div>
</div>

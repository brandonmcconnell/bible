<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 有话语从耶和华临到耶利米，说：</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 1:1; 使徒行传 9:6; 耶利米书 19:1–2"> “起来，下到陶匠的家里去。我要在那里使你听到我的话语。”</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 15:14; 约拿书 1:3; 使徒行传 26:19"> 我就下到陶匠的家里去，看哪，他正在轮盘上做工。</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 9:20–23; 耶利米书 18:6; 以赛亚书 45:9"> 陶匠用陶泥做的器皿，在他手中做坏了，他就把这泥再做成别的器皿，照着陶匠眼中看为好的去做。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 那时耶和华的话语临到我，说：</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 64:8; 罗马书 9:20–21; 耶利米书 18:4"> “以色列家啊，难道我不能像这陶匠一样对待你们吗？以色列家啊，看哪，陶泥在陶匠手中怎样，你们在我手中也怎样。这是耶和华的宣告。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 1:10; 耶利米书 12:14–17; 耶利米书 45:4"> 我何时宣告要拔出、拆毁、消灭一邦或一国，</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 18:21; 耶利米书 26:13; 约拿书 3:9–10"> 如果我所宣告的那邦国转离了他们的恶行，我就改变心意，不把我所计划的灾祸降给他们。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 31:28; 阿摩司书 9:11–15; 耶利米书 1:10"> 我何时宣告要建立、栽种一邦或一国，</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 33:18; 撒母耳记上 2:30; 以西结书 18:24"> 如果他们做我眼中看为恶的事，不听从我的话，我就改变心意，不把我所说的福份赐给他们。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 17:13; 以赛亚书 55:6–7; 耶利米书 35:15"> 现在，你要告诉犹大人和耶路撒冷的居民说，耶和华如此说：看哪，我正在筹备灾祸攻击你们，谋划计策对付你们！你们各人要转离自己邪恶的道路，改正自己的所作所为。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 2:25; 耶利米书 7:24; 申命记 29:19"> 他们却说：‘算了吧！我们一定要照着自己的意图而行，各人随从自己顽固败坏的心行事。’</span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="耶利米书 5:30; 何西阿书 6:10; 耶利米书 23:14"> “因此，耶和华如此说：<br /><span className="pl pl-1">你们在列国中问问吧，</span><br /><span className="pl pl-1">有谁听过这样的事呢？</span><br /><span className="pl pl-1">少女以色列做了一件极其可怕的事。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 6:68"> <span className="pl pl-1">黎巴嫩的雪会从高原的磐石上消失吗？</span><br /><span className="pl pl-1">那从远处流下来的清凉之水会断绝吗？</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 6:16; 耶利米书 2:32; 何西阿书 11:2"> <span className="pl pl-1">然而我的子民却忘记了我，</span><br /><span className="pl pl-1">向虚妄的偶像烧香！</span><br /><span className="pl pl-1">他们在自己的道路上，</span><br /><span className="pl pl-1">在那古时的路途上绊跌，</span><br /><span className="pl pl-1">去走崎岖小路，而非平坦的大道，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 22:7; 耶利米书 25:9; 耶利米书 19:8"> <span className="pl pl-1">以致他们的国土令人惊骇，</span><br /><span className="pl pl-1">永远被嗤笑，</span><br /><span className="pl pl-1">所有经过这地的人都惊恐、摇头。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 13:24; 耶利米书 2:27; 约伯记 27:21"> <span className="pl pl-1">我要像一阵东风，</span><br /><span className="pl pl-1">使他们在仇敌面前四散；</span><br /><span className="pl pl-1">他们遭难的日子里，</span><br /><span className="pl pl-1">我只让他们看见我的背，</span><br /><span className="pl pl-1">不让他们看见我的面。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="诗篇 52:2; 耶利米书 11:19; 玛拉基书 2:7"> 他们说：“来吧，让我们谋划计策对付耶利米！反正律法不会从祭司消亡，谋略不会从智慧人消亡，话语也不会从先知消亡。来吧，让我们用舌头攻击他，不要理睬他的任何话语！”</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米记 6:9; 耶利米书 20:12; 诗篇 55:16–17"> <span className="pl pl-1">耶和华啊，求你倾听我的话，</span><br /><span className="pl pl-1">求你听听与我争斗之人的声音！</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 35:7; 诗篇 57:6; 诗篇 106:23"> <span className="pl pl-1">人怎能以恶报善呢？</span><br /><span className="pl pl-1">他们竟然挖坑害我的性命。</span><br /><span className="pl pl-1">求你记念我曾站在你面前为他们说好话，</span><br /><span className="pl pl-1">为要使你的怒火转离他们。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 109:9–20; 耶利米哀歌 5:3; 阿摩司书 4:10"> <span className="pl pl-1">因此，求你把他们的儿女交给饥荒，</span><br /><span className="pl pl-1">把他们交在刀剑之下！</span><br /><span className="pl pl-1">愿他们的妻子丧失儿女，并且成为寡妇，</span><br /><span className="pl pl-1">愿他们的男人被杀死，</span><br /><span className="pl pl-1">他们的青年人在战场上被刀剑击杀！</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 6:26; 诗篇 140:5; 西番雅书 1:10–11"> <span className="pl pl-1">你使袭击者突然来攻击他们的时候，</span><br /><span className="pl pl-1">愿哀声从他们的房屋里传出！</span><br /><span className="pl pl-1">他们竟然挖了坑，要捉住我；</span><br /><span className="pl pl-1">暗设网罗，要绊我的脚。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 35:4; 诗篇 69:22–28; 尼希米记 4:4–5"> <span className="pl pl-1">可是你，耶和华啊，</span><br /><span className="pl pl-1">你知道他们要杀我的一切谋划！</span><br /><span className="pl pl-1">求你不要赦免</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="赦免——原文直译“赎”。">a</a></sup><br /><span className="pl pl-1">他们的罪，</span><br /><span className="pl pl-1">不要从你面前抹掉他们的罪恶；</span><br /><span className="pl pl-1">求你使他们在你面前绊倒，</span><br /><span className="pl pl-1">求你在发怒的时候处治他们！</span></span>
</div>

<div className="bp">
<span className="v" id="v6" data-v="6"> 过了许多日子，耶和华对我说：“你起来往幼发拉底河去，把我吩咐你藏在那里的腰带从那里取出来。”</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 3:12; 以赛亚书 64:6; 耶利米书 13:10"> 我就往幼发拉底河去，在那里掏挖，把腰带从所藏的地方取出来。看哪，腰带已经毁掉，没有任何用处了。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 耶和华的话语又临到我，说：</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 26:19; 耶利米书 13:15–17; 西番雅书 3:11"> “耶和华如此说：我必照样摧毁犹大的骄傲，摧毁耶路撒冷极大的骄傲。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 16:12; 耶利米书 9:14; 历代志下 36:15–16"> 这败坏的子民，不肯听从我的话，照着自己顽固的心行事，又跟从别的神，服事它们，向它们下拜，这子民必像这腰带一样，没有任何用处。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 19:5–6; 耶利米书 33:9; 诗篇 81:11"> 因为正如腰带紧贴人的腰，我也曾使以色列全家和犹大全家照样紧贴着我，为要使他们作我的子民，使我得名声，得赞美，得荣耀，他们却不听从我的话<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我的话——辅助词语。">a</a></sup>。这是耶和华的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西结书 24:19"> “你要对他们说这话：‘以色列的神耶和华如此说：每个坛子都要装满酒。’他们会对你说：‘难道我们不知道每个坛子都要装满酒吗？’</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 63:6; 诗篇 75:8; 诗篇 60:3"> 你就对他们说：‘耶和华如此说：看哪，我必使这地所有的居民，就是坐大卫宝座的君王，还有祭司和先知，以及所有耶路撒冷的居民，都酩酊大醉。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 29:20; 诗篇 2:9; 耶利米书 19:9–11"> 我要使他们彼此碰撞，连父子也彼此碰撞。我必不怜恤、不顾惜、不怜悯，必把他们毁掉。’这是耶和华的宣告。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 28:14–22; 启示录 2:29; 使徒行传 4:19–20"> <span className="pl pl-1">你们要听，要倾听，不要自高，</span><br /><span className="pl pl-1">因为耶和华已经发话。</span><br /></span>

<span className="v" id="v17" data-v="17" data-xref="玛拉基书 2:2; 耶利米书 9:1; 耶利米书 14:17"> <span className="pl pl-1">如果你们不听从这话，</span><br /><span className="pl pl-1">我的心就因你们的骄傲而暗中哭泣；</span><br /><span className="pl pl-1">我的眼睛必痛哭流泪，</span><br /><span className="pl pl-1">因为耶和华的羊群被掳走了。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="耶利米书 22:26; 列王纪下 24:12; 列王纪下 24:15"> <span className="pl pl-1">“你要对君王和太后说：</span><br /><span className="pl pl-1">‘你们降卑坐下吧！</span><br /><span className="pl pl-1">你们的华冠已经从头上掉下来了。’</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 52:27; 耶利米书 39:9; 申命记 28:52"> <span className="pl pl-1">南地</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="南地——音译作“内盖夫”。">b</a></sup><br /><span className="pl pl-1">的各城已被封闭，</span><br /><span className="pl pl-1">没有人打开；</span><br /><span className="pl pl-1">犹大人全都被掳走，</span><br /><span className="pl pl-1">全然被掳去了。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 6:22; 耶利米书 1:14; 哈巴谷书 1:6"> <span className="pl pl-1">举目观看那些从北方来的人吧！</span><br /><span className="pl pl-1">从前交托给你的群羊，</span><br /><span className="pl pl-1">你荣美的羊群，</span><br /><span className="pl pl-1">如今在哪里呢？</span></span>

<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 13:8; 耶利米书 4:31; 耶利米书 5:31"> <span className="pl pl-1">“你所结交的</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="所结交的——或译作“曾教导的”。">c</a></sup><br /><span className="pl pl-1">那些同伴，</span><br /><span className="pl pl-1">耶和华将指派他们为首领管辖你，</span><br /><span className="pl pl-1">那时你会说什么呢？</span><br /><span className="pl pl-1">难道绞痛不会抓住你，</span><br /><span className="pl pl-1">像临产的妇人那样吗？</span><br /></span>

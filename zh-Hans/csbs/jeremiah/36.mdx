<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 25:1; 历代志下 36:5; 耶利米书 45:1"> 约西亚的儿子犹大王约雅敬四年，有这话语从耶和华临到耶利米，说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 30:2; 耶利米书 25:3; 耶利米书 1:10"> “你拿一个书卷，记下来我对你所说有关以色列和犹大以及列国的一切话语，就是从约西亚年间我对你说话的日子直到今日，我对你说过的一切话语。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 18:8; 使徒行传 3:19; 耶利米书 26:3"> 或许犹大家听到我计划要降给他们的一切灾祸，各人就会转离自己邪恶的道路，我就赦免他们的罪孽和罪恶。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="耶利米书 32:12; 耶利米书 36:32; 以西结书 2:9"> 于是耶利米召来尼利亚的儿子巴录克，巴录克就照耶利米的口述，把耶和华对耶利米说的一切话语都记在书卷上。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 32:2; 耶利米书 33:1; 哥林多后书 11:23"> 然后耶利米吩咐巴录克说：“我被拘禁，不能进入耶和华的殿。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 36:8–9; 耶利米书 26:2; 耶利米书 22:2"> 所以你要去，在禁食的日子，在耶和华殿中，把你照我的口述记在书卷上耶和华的话语，宣读给民众听，也宣读给所有从本城来的犹大人听。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 36:3; 耶利米书 21:5; 历代志下 33:12–13"> 或许他们的恳求会达到耶和华面前，各人会转离自己邪恶的道路，因为耶和华向这子民宣告的怒气和怒火是极大的。”</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 1:17; 哥林多前书 16:10; 路加福音 4:16–30"> 尼利亚的儿子巴录克就照着先知耶利米吩咐他的一切去做，在耶和华殿中宣读那书卷上耶和华的话语。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="历代志下 20:3; 约拿书 3:5; 以斯帖记 4:16"> 约西亚的儿子犹大王约雅敬五年九月，所有在耶路撒冷的民众和所有从犹大各城来到耶路撒冷的民众，都在耶和华面前宣告禁食。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 36:11; 耶利米书 26:10; 耶利米书 52:25"> 巴录克就在耶和华殿中，就是耶和华殿的新门入口处，在上院里书记沙番的儿子基玛利雅的房间，把那书卷上耶利米的话语宣读给全体民众听。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米书 36:10; 历代志下 34:20; 列王纪下 25:22"> 沙番之子基玛利雅的儿子米该亚，听见那书卷上耶和华的一切话语，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 26:22; 列王纪下 22:12; 耶利米书 36:25"> 就下到王宫，进入书记室。看哪，众首领都坐在那里，其中有书记以利沙玛，示玛雅的儿子德拉雅，亚革波的儿子以利拿单，沙番的儿子基玛利雅，哈纳尼雅的儿子西底加，以及其余的首领。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 22:10; 历代志下 34:24; 历代志下 34:16–18"> 米该亚把一切话语，就是他在巴录克宣读书卷给民众听的时候所听见的，都告诉了他们。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 36:2; 耶利米书 41:18; 耶利米书 41:1–2"> 于是众首领派遣犹底，就是尼坦亚的儿子、示勒米雅的孙子、库希的曾孙，去见巴录克说：“请你手里拿上宣读给民众听的书卷，到这里来。”尼利亚的儿子巴录克就手里拿上那书卷，到他们那里去。</span>
<span className="v" id="v15" data-v="15"> 他们对他说：“请你坐下，宣读给我们听吧。”巴录克就宣读给他们听。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米书 13:18; 耶利米书 36:24; 阿摩司书 7:10–11"> 他们听见这一切话语就惧怕，彼此相望。他们对巴录克说：“我们必须把这一切话报告给王。”</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 9:15; 约翰福音 9:10–11; 约翰福音 9:26–27"> 他们又问巴录克说：“请告诉我们，你是怎么记下这一切话语的？是照耶利米的口述吗？”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米书 36:4; 耶利米书 36:2; 箴言 26:4–5"> 巴录克对他们说：“他向我口述了这一切话语，我用墨水记在这书卷上。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王纪上 17:3; 列王纪上 18:10; 耶利米书 26:20–24"> 首领们就对巴录克说：“你和耶利米去躲藏起来吧，不要让人知道你们在哪里。”</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 36:12; 耶利米书 36:21"> 然后他们进到院子去见王，而把书卷存放在书记以利沙玛的房间里；他们把一切话语都报告给王听。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 22:10; 历代志下 34:18; 以西结书 2:4–5"> 王派遣犹底去取那书卷，犹底就从书记以利沙玛的房间里把书卷取来，宣读给王和侍立于王旁边的所有首领听。</span>
<span className="v" id="v22" data-v="22" data-xref="阿摩司书 3:15; 耶利米书 22:14–16; 耶利米书 36:9"> 那时正是九月，王坐在过冬的房屋里，在他面前有燃烧着的火盆。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 22:8; 箴言 21:30; 列王纪上 22:27"> 每当犹底宣读了三、四段，王就用书记的小刀把书卷割下，扔到火盆中的火里，直到整个书卷都在火盆中的火里烧尽了。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 36:16; 诗篇 36:1; 约拿书 3:6"> 王和所有听见这一切话语的臣仆都不惧怕，也不撕裂衣服；</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 37:22; 耶利米书 36:12; 使徒行传 5:34–39"> 甚至以利拿单、德拉雅和基玛利雅哀求王不要烧掉那书卷，王也不听他们。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 17:3; 列王纪上 19:1–3; 列王纪上 19:14"> 王又吩咐王子耶拉米列，以及亚斯列的儿子西莱雅和亚伯叠的儿子示勒米雅，去捉拿书记巴录克和先知耶利米，但耶和华隐藏了他们。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米书 36:4"> 王烧掉那书卷，烧掉巴录克照耶利米口述所记下的话语之后，耶和华的话语临到耶利米，说：</span>
<span className="v" id="v28" data-v="28" data-xref="撒迦利亚书 1:5–6; 约伯记 23:13; 耶利米书 44:28"> “你再另外拿一个书卷，把犹大王约雅敬烧掉的前一书卷上先前的话语全都记在上面。</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 30:10; 耶利米书 26:9; 申命记 29:19"> 你要论到犹大王约雅敬说，耶和华如此说：你烧掉这书卷，说：‘你为什么在它上面记着说，巴比伦王一定会来，毁灭这地，使人和牲畜从其上断绝呢？’</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 22:30; 列王纪下 24:12–15; 创世记 31:40"> 因此论到犹大王约雅敬，耶和华如此说：他必不会有后裔坐在大卫的宝座上，他的尸体必被抛弃，经受白天的炎热、夜间的寒霜。</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 29:1; 耶利米书 19:15; 耶利米书 35:17"> 我要因他和他后裔并他臣仆们的罪孽惩罚他们，我要使我所宣告的一切祸患临到他们，临到耶路撒冷的居民和犹大人；我对他们宣告了，他们却不听！”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="耶利米书 36:4; 耶利米书 36:18; 出埃及记 4:15–16"> 于是耶利米另外拿了一个书卷，交给尼利亚的儿子书记巴录克，巴录克就照耶利米的口述，把犹大王约雅敬在火中所烧掉书卷上的一切话语都记在上面，这次还增添了许多类似的话语。</span>
</div>
</div>

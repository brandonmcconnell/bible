<span className="v" id="v3" data-v="3" data-xref="利未记 26:19; 耶利米书 14:4; 申命记 28:23"> <span className="pl pl-1">因此甘霖止住，春雨不降，</span><br /><span className="pl pl-1">你却还是一副妓女面孔</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="面孔——原文直译“额”。">a</a></sup><br /><span className="pl pl-1">，不顾羞耻。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 2:2; 耶利米书 3:19; 诗篇 71:17"> <span className="pl pl-1">你不是刚刚呼唤我：</span><br /><span className="pl pl-1">“父啊，你是我年轻时的同伴！</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="弥迦书 7:3; 以赛亚书 57:16; 以西结书 22:6"> <span className="pl pl-1">难道耶和华会永远怀怒，</span><br /><span className="pl pl-1">永久存怒吗？”</span><br /><span className="pl pl-1">看哪，你虽然这样说，</span><br /><span className="pl pl-1">还是竭尽所能地作恶。</span></span>

<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王纪下 17:7–17; 以西结书 16:31; 耶利米书 7:24"> 约西亚王年间，耶和华对我说：“你看见背道的以色列所做的吗？她到各高山上，各青翠树下，在那里行淫。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 16:46; 何西阿书 6:1–4; 何西阿书 14:1"> 我以为她做了这一切事之后，就会回转归向我，她却没有回转；她奸诈的妹妹犹大也看见了。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 24:1; 何西阿书 4:15–17; 以赛亚书 50:1"> 因背道的以色列那些通奸之事，我休弃她，给了她一份休书；我看见她背信的妹妹犹大却不害怕，也去行淫。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 2:27; 以赛亚书 57:6; 耶利米书 3:2"> 以色列轻忽自己的淫行，与石头、木头通奸，因而玷污了这地。</span>
<span className="v" id="v10" data-v="10" data-xref="何西阿书 7:14; 耶利米书 12:2; 历代志下 34:33–18"> 即使如此，她奸诈的妹妹犹大还不全心回转归向我，而是假意回转。这是耶和华的宣告。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="以西结书 23:11; 以西结书 16:51–52; 何西阿书 11:7"> 耶和华对我说：“背道的以色列比背信的犹大倒显为义了！</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 86:15; 以西结书 33:11; 申命记 4:29–31"> 你去，向北方宣告这些话语说：<br /><span className="pl pl-1">背道的以色列啊，回转吧！</span><br /><span className="pl pl-1">这是耶和华的宣告。</span><br /><span className="pl pl-1">我不会怒视你们，</span><br /><span className="pl pl-1">因为我是信实的；</span><br /><span className="pl pl-1">我不会永远怀怒。</span><br /><span className="pl pl-1">这是耶和华的宣告。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 2:25; 耶利米书 3:6; 申命记 12:2"> <span className="pl pl-1">只要你承认自己的罪孽，</span><br /><span className="pl pl-1">就是悖逆了耶和华你的神，</span><br /><span className="pl pl-1">在各青翠树下追求外邦神明，</span><br /><span className="pl pl-1">没有听从我的话。</span><br /><span className="pl pl-1">这是耶和华的宣告。</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="何西阿书 2:19–20; 耶利米书 2:19; 耶利米书 31:32"> “背道的儿女啊，回转吧！这是耶和华的宣告。因为我是你们的主人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="主人——或译作“丈夫”。">b</a></sup>，我要从一城取一人、从一家取两人，把你们带到锡安。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 23:4; 使徒行传 20:28; 以弗所书 4:11–12"> 我要把合我心意的牧者赐给你们，他们要用知识和智慧牧养你们。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 65:17; 阿摩司书 9:14–15; 以西结书 37:26"> 在那些日子，当你们在这地上增多、繁衍的时候，人必不再说起‘耶和华的约柜’，不会想起，不会记念，不觉缺少，也不再制造。这是耶和华的宣告。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 43:7; 弥迦书 4:1–5; 耶利米书 17:12"> 那时，人必称耶路撒冷为‘耶和华的宝座’，万国必为耶和华的名聚集到耶路撒冷；他们必不再随从自己顽固败坏的心行事。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 31:8; 何西阿书 1:11; 阿摩司书 9:15"> 在那些日子，犹大家要与以色列家同行，从北方之地一同来到我赐给你们祖先为继业之地。</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="耶利米书 3:4; 耶利米书 31:9; 以赛亚书 63:16"> <span className="pl pl-1">“我说：‘我多想把你列在儿女当中，</span><br /><span className="pl pl-1">把美好之地，就是万国中</span><br /><span className="pl pl-1">最荣美的继业赐给你！’</span><br /><span className="pl pl-1">我以为你会称呼我‘父亲’，</span><br /><span className="pl pl-1">不会转离不跟从我。</span><br /></span>

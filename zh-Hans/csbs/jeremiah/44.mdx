<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 46:14; 以赛亚书 11:11; 出埃及记 14:2"> 论到所有住在埃及地，就是住在密夺、塔帕尼斯、挪弗<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="挪弗——希腊语音译为“孟菲斯”。">a</a></sup>和巴特罗地的犹大人，有话语临到耶利米，说：</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 6:11; 耶利米书 9:11; 耶利米书 34:22"> “以色列的神万军之耶和华如此说：你们看见了我降在耶路撒冷和犹大各城镇的一切灾祸。看哪，今日它们成为废墟，无人住在其中！</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 29:26; 申命记 13:6; 申命记 32:17"> 这是因为他们作恶惹怒我，他们去烧香，服事别的神，就是他们和你们以及你们祖先都不认识的神明。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 26:5; 耶利米书 7:25; 耶利米书 7:13"> 我派遣我的仆人众先知到你们那里去，不断地派遣，说：‘切不可行我所恨恶的这可憎之事！’</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 11:10; 耶利米书 19:13; 历代志下 36:16"> 他们却不听从，不侧耳听，不转离他们的恶行，仍向别的神烧香。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 7:20; 耶利米书 21:5; 以赛亚书 51:17"> 因此我的怒火和怒气倾泻而出，在犹大各城中和耶路撒冷的街道上燃烧，以致它们成为废墟和荒场，就像今日这样。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哈巴谷书 2:10; 耶利米书 51:22; 以西结书 33:11"> “现在，以色列的神万军之神耶和华如此说：你们为什么做极大的恶事自害己命，使你们男人、女人、幼童和婴儿从犹大被剪除，使你们一个余剩之民也不留下呢？</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 42:18; 耶利米书 25:6–7; 耶利米书 44:3"> 为什么用你们手所造的惹怒我，在你们去寄居的埃及地向别的神烧香，以致你们被剪除，在地上万国中被咒骂、被羞辱？</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 7:17–18; 约书亚记 22:17–20; 耶利米书 44:15–19"> 你们祖先的恶行，犹大列王的恶行和他们妻子的恶行，你们的恶行和你们妻子的恶行，就是在犹大地和耶路撒冷街道上所做的，你们都忘记了吗？</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 28:14; 彼得前书 5:6; 启示录 15:4"> 直到今日，你们还没有痛悔，没有畏惧，没有遵行我在你们和你们祖先面前设立的律法和律例。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米书 21:10; 利未记 26:17; 利未记 20:5–6"> “因此以色列的神万军之耶和华如此说：看哪，我决意要向你们降灾祸，剪除全体犹大人。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 42:15–18; 耶利米书 42:22; 以赛亚书 65:15"> 我要除掉那些执意去埃及地寄居的犹大余剩之民，他们必全都灭尽。他们必仆倒在埃及地，因刀剑和饥荒而灭尽，无论尊卑，都死于刀剑和饥荒；他们将被辱骂、令人惊骇、被咒骂、被羞辱。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 11:22; 耶利米书 43:11; 耶利米书 44:27–28"> 我要用刀剑、饥荒和瘟疫惩罚那些住在埃及地的人，就像我惩罚耶路撒冷那样。</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 9:27; 耶利米书 22:26–27; 耶利米书 42:17"> 那些去寄居在埃及地的犹大余剩之民，没有一个逃脱者或幸存者，没有人能回到他们心里盼望回去居住的犹大地；除了一些逃脱者之外，没有人能回去。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="箴言 11:21; 耶利米书 5:1–5; 创世记 19:4"> 那些知道妻子向别的神烧香的男人，以及所有站在那里的女人，这一大群人，包括住在埃及地巴特罗的全体民众，他们回应耶利米，说：</span>
<span className="v" id="v16" data-v="16" data-xref="约伯记 21:14–15; 路加福音 19:27; 耶利米书 16:15–17"> “你奉耶和华之名对我们所说的话，我们不会听从。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 7:18; 尼希米记 9:34; 耶利米书 44:21"> 我们一定照着我们口中所出的一切话去做，向天后烧香，向她浇奠酒祭，就像我们和我们的祖先、君王、首领，在犹大各城中和耶路撒冷街道上所做的那样。那时我们得以饱食，得享福乐，不见灾祸；</span>
<span className="v" id="v18" data-v="18" data-xref="玛拉基书 3:13–15; 民数记 11:5–6; 约伯记 21:14–15"> 但自从我们停止向天后烧香，停止向她浇奠酒祭以来，我们却样样缺少，又因刀剑和饥荒而灭尽。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="耶利米书 7:18; 耶利米书 44:15; 列王纪上 21:25"> 女人们也说：“我们向天后烧香，向她浇奠酒祭，照着天后的形像做祭饼供奉她，向她浇奠酒祭，难道没有经过我们的丈夫同意吗？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 耶利米就告诉全体民众，对男人和女人，以及所有用这话回应他的民众，说：</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 44:17; 耶利米书 44:9; 耶利米书 11:13"> “你们和你们的祖先、君王、首领，以及那地的民众，在犹大各城中和耶路撒冷街道上所烧的香，耶和华不是都记得，在他心里想起来了吗？</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 25:18; 以赛亚书 7:13; 玛拉基书 2:17"> 耶和华不能再忍受你们的恶行、你们所行的那些可憎之事，因此你们的土地成为废墟，令人惊骇、被咒骂，无人居住，就像今日这样。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 9:9; 但以理书 9:11–12; 尼希米记 13:18"> 因为你们烧香，对耶和华犯罪，不听从耶和华的话语，也不遵行他的律法、律例和法度，所以这祸患临到了你们，就像今日这样。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米书 43:7; 耶利米书 44:15–16; 耶利米书 42:15"> 耶利米又对全体民众和所有的女人说：“所有在埃及地的犹大人哪，你们要听耶和华的话语！</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 14:9; 使徒行传 23:12–15; 以赛亚书 28:15"> 以色列的神万军之耶和华如此说：你们和你们的妻子亲口说过、亲手做成了，你们说：‘我们一定要还我们所许的愿，向天后烧香，向她浇奠酒祭。’你们尽管守你们的愿，尽管还你们的愿吧！</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="诗篇 50:16; 以西结书 20:39; 希伯来书 6:13"> “因此，所有住在埃及地的犹大人哪，你们要听耶和华的话语！耶和华说：看哪，我指着我伟大的名起誓：在埃及全地，我的名绝不再被任何一个犹大人的口宣告说‘我指着永生的主耶和华起誓’！</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 31:28; 列王纪下 21:14; 耶利米书 1:10"> 看哪，我看管着他们，为要降祸而不降福，所有在埃及地的犹大人都必死于刀剑和饥荒，直到他们灭绝。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 44:14; 以赛亚书 27:12–13; 以赛亚书 10:19"> 只有少数的人逃脱刀剑，从埃及地返回犹大地。这样，所有去埃及地寄居的犹大余剩之民，就知道谁的话语会成就，是我的，还是他们的！</span>
<span className="v" id="v29" data-v="29" data-xref="箴言 19:21; 马太福音 24:15–16; 耶利米书 44:30"> 以下是给你们的征兆，这是耶和华的宣告；我必在这地方惩罚你们，好使你们知道我向你们降灾祸的话语必定成就。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 25:4–7; 耶利米书 43:9–13; 耶利米书 34:21"> 耶和华如此说：看哪，我要把埃及王法老合弗拉交在他仇敌和寻索他性命的人手中，就像我把犹大王西底加交在他仇敌和寻索他性命的巴比伦王尼布甲尼撒手中那样！”</span>
</div>
</div>

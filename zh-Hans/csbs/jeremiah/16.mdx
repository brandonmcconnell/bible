<span className="v" id="v1" data-v="1" data-xref="耶利米书 1:2; 耶利米书 2:1; 耶利米书 1:4"> 耶和华的话语临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 7:26–27; 路加福音 23:29; 创世记 19:14"> “你在这地方不可娶妻，不可有儿女。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 16:9; 耶利米书 16:5; 耶利米书 6:21"> 因为论到在这地方出生的儿女，以及在这地生养他们的父母，耶和华如此说：</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 25:33; 诗篇 83:10; 耶利米书 9:22"> 他们必因致命的疾病而死，无人哀哭，不被埋葬，成为地面上的粪土。他们也必被刀剑和饥荒灭绝，尸体给天空的飞鸟和地上的走兽作食物。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以西结书 24:16–23; 以赛亚书 27:11; 耶利米书 15:1–4"> 耶和华如此说：“你不要进入居丧之家，不要去哀哭，也不要为他们悲哀，因为我已从这子民身上收回我的平安，收回慈爱和怜悯。这是耶和华的宣告。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 14:1; 耶利米书 41:5; 耶利米书 47:5"> 尊贵的和卑微的都必死在这地，不被埋葬，无人哀哭，没有人为他们割伤自己、剃光头发；</span>
<span className="v" id="v7" data-v="7" data-xref="何西阿书 9:4; 以西结书 24:17; 申命记 26:14"> 也没有人为哀悼者掰饼，因死者而安慰他们，没有人因他们丧父或丧母给他们一杯安慰酒喝。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 15:17; 传道书 7:2–4; 以赛亚书 22:12–14"> 你也不要进入宴乐之家，与他们同坐吃喝。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="耶利米书 25:10; 耶利米书 7:34; 以西结书 26:13"> 是的，以色列的神万军之耶和华如此说：“看哪，我必在你们眼前，在你们的年日里，使这地方不再有欢喜快乐的声音、新郎新娘的声音。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 5:19; 列王纪上 9:8–9; 申命记 29:24–25"> “当你把这一切话语告诉这子民时，他们会对你说：‘耶和华为什么对我们宣告这一切大祸患呢？我们有什么过犯，对我们的神耶和华犯了什么罪呢？’</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 106:35–41; 申命记 29:25–26; 耶利米书 22:9"> 你就对他们说：这是因为你们的祖先离弃了我，跟从别的神，服事它们，向它们下拜；他们离弃了我，不遵守我的律法。这是耶和华的宣告。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 13:10; 耶利米书 7:26; 传道书 9:3"> 你们也行恶，甚至超过你们的祖先，看哪，你们各人随从自己顽固败坏的心行事，不听从我！</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 28:36; 申命记 4:26–28; 耶利米书 15:14"> 因此，我要把你们从这地抛出去，扔到你们和你们祖先都不认识的地方，你们将在那里昼夜服事别的神，因为我必不向你们施恩。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米书 23:7–8; 申命记 15:15; 出埃及记 20:2"> “所以看哪，这是耶和华的宣告：日子将到，那时人们必不再说‘我指着那从埃及地把以色列子孙带上来的耶和华的永生起誓’，</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 3:18; 耶利米书 24:6; 耶利米书 32:37"> 而会说‘我指着那从北方之地，从所有放逐之地把以色列子孙带上来的耶和华的永生起誓’。我必使他们回归自己的土地，就是我所赐给他们祖先的土地。</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="哈巴谷书 1:14–15; 阿摩司书 4:2; 弥迦书 7:2"> “看哪，我要派人召来许多渔夫，捕捞他们；此后我还要派人召来许多猎人，从各山各岭，从岩石缝猎取他们。这是耶和华的宣告。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 15:3; 耶利米书 23:24; 箴言 5:21"> 因为我的眼目察看他们一切的道路，他们不能从我面前隐藏，他们的罪孽也不能从我眼前藏匿。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 35:33–34; 以赛亚书 40:2; 启示录 18:6"> 我必须先双倍报应他们的罪孽和罪恶，因为他们玷污了我的土地，以毫无生气的可憎偶像<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="毫无生气的可憎偶像——或译作“可憎的尸体”。">a</a></sup>和可厌之物充满我的产业之地。”</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 25:4; 耶利米书 17:17; 那鸿书 1:7"> <span className="pl pl-1">耶和华我的力量、我的堡垒、</span><br /><span className="pl pl-1">我在患难之日的避难所啊，</span><br /><span className="pl pl-1">列国必从地极来到你这里，说：</span><br /><span className="pl pl-1">“我们祖先所继承的尽都虚假，</span><br /><span className="pl pl-1">是虚空无益的！</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 37:19; 诗篇 115:4–8; 加拉太书 4:8"> <span className="pl pl-1">人能为自己造神吗？</span><br /><span className="pl pl-1">其实那不是神。”</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 9:16; 诗篇 83:18; 耶利米书 33:2"> <span className="pl pl-1">“所以看哪，</span><br /><span className="pl pl-1">我必使他们知道，就是这一次，</span><br /><span className="pl pl-1">使他们知道我的手、我的大能。</span><br /><span className="pl pl-1">他们必知道：我的名是耶和华。”</span></span>

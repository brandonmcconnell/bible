<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 23:35; 耶利米书 1:3; 耶利米书 25:1"> 约西亚的儿子犹大王约雅敬年间，有话语从耶和华临到耶利米，说：</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 2:55; 历代志上 9:26; 列王纪上 6:5–6"> “你要去见利甲家族的人，与他们说话，并把他们带到耶和华殿的一个房间里，让他们喝酒。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3"> 于是我带来哈巴兹尼雅的孙子、耶利米雅的儿子雅撒尼亚，还有他的兄弟们和他所有的儿子，以及利甲整个家族，</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 33:1; 列王纪下 12:9; 历代志下 8:14"> 把他们带进耶和华的殿，带到伊基大利之子神人哈南儿子们的房间，就在首领们的房间旁边，在沙勒姆的儿子门卫玛西雅的房间上面。</span>
<span className="v" id="v5" data-v="5" data-xref="传道书 9:7; 阿摩司书 2:12; 哥林多后书 2:9"> 然后我在利甲家族的子孙面前摆上盛满酒的酒壶和杯子，对他们说：“请喝酒吧。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="路加福音 1:15; 历代志上 2:55; 列王纪下 10:15"> 他们却说：“我们不喝酒，因为我们先祖利甲的儿子约拿达曾吩咐我们说：‘你们和你们的子孙永远不可喝酒。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 35:10; 创世记 25:27; 尼希米记 8:14–16"> 你们也不可建造房屋，不可播种，不可栽种或拥有葡萄园；你们一生的日子都要住在帐篷中，好使你们在寄居的土地上长久存活。’</span>
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 3:20; 箴言 4:10; 箴言 1:8–9"> 我们在先祖利甲的儿子约拿达所吩咐的一切事上，都听从他的话，我们和我们的妻子、儿女一生的日子都不喝酒，</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前书 6:6; 耶利米书 35:7; 诗篇 37:16"> 不建造房屋居住，我们也没有葡萄园、田地和种子。</span>
<span className="v" id="v10" data-v="10"> 我们只住帐篷，听从并遵行我们先祖约拿达所吩咐的一切。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 8:14; 耶利米书 4:5–7; 但以理书 1:1–2"> 巴比伦王尼布甲尼撒上来攻打这地的时候，我们说：‘来吧！让我们去耶路撒冷，躲避迦勒底人的军队和亚兰人的军队。’这样，我们才住进耶路撒冷。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 于是耶和华的话语临到耶利米，说：</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 32:33; 耶利米书 5:3; 耶利米书 6:8–10"> “以色列的神万军之耶和华如此说：你去对犹大人和耶路撒冷的居民说：你们怎么不接受管教，不听从我的话呢？这是耶和华的宣告。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 25:3–4; 耶利米书 7:24–26; 箴言 1:20–33"> 利甲的儿子约拿达吩咐他子孙不可喝酒的话语，他们都遵行了。他们直到今日也不喝酒，因为他们听从先祖的诫命；而我不断地对你们说话，你们却不听从我。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 18:11; 以西结书 18:30–32; 耶利米书 25:5–6"> 我派遣我的仆人众先知到你们那里去，不断地派遣，说：‘现在你们各人要转离自己邪恶的道路，改正自己的行为，不要跟从别的神去服事它们；这样你们就必住在我赐给你们和你们祖先的土地上。’你们却不侧耳听，不听从我。</span>
<span className="v" id="v16" data-v="16" data-xref="玛拉基书 1:6; 耶利米书 35:14; 路加福音 15:11–13"> 利甲之子约拿达的子孙遵行了先祖吩咐他们的诫命，但这子民却不听从我。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 66:4; 以赛亚书 65:12; 罗马书 10:21"> 因此以色列的神万军之神耶和华如此说：看哪，我必使我对他们宣告的一切祸患临到犹大和所有耶路撒冷的居民。因为我对他们宣告，他们不听从；我呼唤他们，他们不回应。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命记 5:16; 出埃及记 20:12; 以弗所书 6:1–3"> 耶利米对利甲家族的人说：“以色列的神万军之耶和华如此说：因为你们听从你们先祖约拿达的诫命，遵守他的一切诫命，照着他所吩咐你们的一切去做，</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 15:19; 路加福音 21:36; 耶利米书 33:17–18"> 所以，以色列的神万军之耶和华如此说：利甲的儿子约拿达必永不断绝有人侍立在我面前。”</span>
</div>

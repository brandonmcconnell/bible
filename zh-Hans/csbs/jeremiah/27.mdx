<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 27:3; 耶利米书 28:1; 耶利米书 27:12"> 约西亚的儿子犹大王约雅敬开始执政的时候，有这话语从耶和华临到耶利米，</span>
<span className="v" id="v2" data-v="2" data-xref="阿摩司书 7:1; 阿摩司书 7:4; 耶利米书 27:12"> 耶和华对我如此说：“你要为自己做绳索和轭，放在你的颈项上，</span>
<span className="v" id="v3" data-v="3" data-xref="阿摩司书 1:9–3; 以西结书 25:1–17; 以西结书 17:15–21"> 然后藉着那些来耶路撒冷见犹大王西底加的使者的手，把信息<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="信息——原文直译“它们”。">a</a></sup>送到以东王、摩押王、亚扪人的王、提尔王和西顿王那里。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 51:19; 耶利米书 10:10; 耶利米书 25:27"> 你要吩咐那些使者对他们的主人说：‘以色列的神万军之耶和华如此说：你们要对你们的主人说，</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 32:17; 耶利米书 51:15; 诗篇 115:15–16"> 是我以伟大的能力和伸出的膀臂造了大地，以及地面上的人和走兽；我看谁合适，就把大地交给谁。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 28:14; 耶利米书 25:9; 但以理书 2:37–38"> 现在，我已经把这全地交在我的仆人巴比伦王尼布甲尼撒手中，也把田野的走兽交给了他，使它们服事他。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 52:31; 启示录 13:5–10; 但以理书 5:25–31"> 列国都必服事他和他的儿子、孙子，直到他自己的国土遭报的时候来到，那时许多国家和大君王将奴役他。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西结书 14:21; 以西结书 17:19–21; 耶利米书 38:17–19"> “如果哪一邦或哪一国不服事巴比伦王尼布甲尼撒，不把颈项放在巴比伦王的轭下，我就用刀剑、饥荒和瘟疫惩罚那邦国，直到我藉着巴比伦王的手把他们灭尽。这是耶和华的宣告。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 14:14; 玛拉基书 3:5; 耶利米书 29:8"> 至于你们，不要听从你们的先知、占卜者、解梦者、算命者和巫师。他们告诉你们说，你们不会服事巴比伦王。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 32:31; 耶利米书 28:16; 耶利米书 23:25"> 其实他们向你们说的是假预言，好使你们远离自己的土地；我驱逐你们，你们就会灭亡。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 27:8; 耶利米书 27:2; 耶利米书 38:2"> 如果哪一邦把颈项放在巴比伦王轭下服事他，我就使那邦国留在自己的土地上，在那里耕耘居住。这是耶和华的宣告。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米书 28:1; 耶利米书 38:17; 历代志下 36:11–13"> 我就照着这一切话语，向犹大王西底加宣告说：“你们要把颈项放在巴比伦王的轭下，服事他和他的子民，使你们存活。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 18:31; 耶利米书 27:8; 箴言 8:36"> 何必让你和你的子民像耶和华论到不服事巴比伦王的国家所说的，死于刀剑、饥荒和瘟疫呢？</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 14:14; 哥林多后书 11:13–15; 耶利米书 29:8–9"> 你们不要听从那些先知的话语，他们说你们不会服事巴比伦王，其实他们向你们说的是假预言。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 27:10; 历代志下 25:16; 耶利米书 6:13–15"> 我并没有派遣他们，他们却藉我的名说假预言，好让我驱逐你们，使你们和那些向你们说预言的先知都灭亡。这是耶和华的宣告。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪下 24:13; 耶利米书 28:3; 但以理书 1:2"> 我又向祭司们和这全体民众宣告说：“耶和华如此说：你们不要听从你们先知的话语，他们向你们预言说：‘看哪，耶和华殿中的器皿快要从巴比伦带回来了！’其实他们向你们说的是假预言。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 38:17; 耶利米书 38:23; 耶利米书 7:34"> 你们不要听从他们，而要服事巴比伦王，使你们存活。何必让这城变为废墟呢？</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 7:8; 耶利米书 18:20; 撒母耳记上 12:19"> 如果他们真是先知，如果真有耶和华的话语临到他们，就请他们哀求万军之耶和华吧，好使那些留在耶和华殿中和犹大王宫里，以及留在耶路撒冷的器皿，不被带到巴比伦去。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 25:13; 耶利米书 52:17–23; 列王纪下 25:17"> 因为万军之耶和华已经发话，论到那些柱子、铜海、铜盆底座，以及留在这城中的其余器皿，</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 24:1; 历代志下 36:10; 列王纪下 24:14–16"> 就是巴比伦王尼布甲尼撒掳走约雅敬的儿子犹大王耶哥尼雅，以及犹大和耶路撒冷所有的贵族，把他们从耶路撒冷掳到巴比伦的时候，没有拿走的那些器皿——</span>
<span className="v" id="v21" data-v="21"> 是的，关于那些留在耶和华殿中和犹大王宫里，以及留在耶路撒冷的器皿，以色列的神万军之耶和华如此说：</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 29:10; 以斯拉记 7:19; 耶利米书 32:5"> ‘那些器皿必被带到巴比伦，存放在那里，直到我眷顾它们的日子。那时我必把它们带上来，带回这地方。’这是耶和华的宣告。”</span>
</div>

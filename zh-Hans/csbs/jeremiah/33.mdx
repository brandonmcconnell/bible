<span className="v" id="v1" data-v="1" data-xref="耶利米书 38:28; 耶利米书 37:21; 耶利米书 32:2–3"> 耶利米还被拘禁在护卫兵院子里的时候，耶和华的话语第二次临到他，说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 6:3; 出埃及记 15:3; 以赛亚书 37:26"> “耶和华是创造者，是塑造坚立一切<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一切——七十士译本作“大地”。">a</a></sup>的那一位，耶和华是他的名。耶和华如此说：</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 29:12; 以赛亚书 65:24; 以弗所书 3:20"> 你呼求我，我就回应你，并且把你所不知道的那些大而深奥的事告诉你。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 32:24; 哈巴谷书 1:10; 以西结书 4:2"> 论到这城中的房屋和犹大王宫，就是为了抵挡攻城的土垒和刀剑而被拆毁的那些房屋，以色列的神耶和华如此说：</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 8:17; 耶利米书 21:10; 耶利米书 21:4–7"> 他们去与迦勒底人争战，实际是用我在怒气和怒火中所杀之人的尸体充满这些房屋。我已经因他们的一切恶行，向这城隐藏了我的脸。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 10:10; 以赛亚书 30:26; 提多书 3:5–6"> 然而，我必使这城康复、痊愈，我必医治他们，向他们显明丰盛的平安和信实。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 1:26; 耶利米书 30:3; 阿摩司书 9:14–15"> 我必使犹大的掳民和以色列的掳民回归<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="使犹大的掳民和以色列的掳民回归——或译作“复兴犹大和以色列的家业”。">b</a></sup>，重建他们，如起初一样。</span>
<span className="v" id="v8" data-v="8" data-xref="撒迦利亚书 13:1; 弥迦书 7:18–19; 诗篇 51:2"> 我必除净他们对我所犯的一切罪孽，赦免他们得罪我、悖逆我所犯的一切罪孽。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 126:2–3; 以赛亚书 60:5; 西番雅书 3:17–20"> 这城必在地上万国面前，就是那些听见我赐给这城一切福份的国家面前，使我获得喜乐的名，得赞美和荣耀；那些国家必因我赐给这城的一切福份和平安而惧怕、颤抖。</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 32:43; 耶利米书 32:36; 以西结书 37:11"> “耶和华如此说：在你们说‘荒废，没有人，也没有牲畜’的这地方，在荒凉无人、无居民无牲畜的犹大各城和耶路撒冷的街道上，必再次听见</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 16:34; 诗篇 106:1; 诗篇 107:22"> 欢喜快乐的声音、新郎新娘的声音，以及那些带着感谢祭到耶和华殿之人的声音，他们说：<br /><span className="pl pl-1">‘你们当称谢万军之耶和华，</span><br /><span className="pl pl-1">耶和华是美善的，</span><br /><span className="pl pl-1">他的慈爱永远长存！’</span><br />是的，我必使这地的掳民回归，如起初一样。这是耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 65:10; 以西结书 34:12–15; 耶利米书 36:29"> “万军之耶和华如此说：在这无人无牲畜的荒废之地，在它的各城镇，必再次有牧人们的牧场，使羊群躺卧。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 27:32; 路加福音 15:4; 耶利米书 17:26"> 在山地的各城、丘陵的各城、南地<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="南地——音译作“内盖夫”。">c</a></sup>的各城、便雅悯地、耶路撒冷的四围和犹大的各城，必再次有羊群从数点的人手下经过。这是耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="哈该书 2:6–9; 耶利米书 23:5; 历代志上 17:13–14"> “看哪，这是耶和华的宣告：日子将到，我必成就我向以色列家和犹大家所承诺的美好应许。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 11:1–5; 耶利米书 23:5–6; 以赛亚书 4:2"> 在那些日子，在那时候，我要使一个公义的苗裔为大卫长出，他必在地上施行公正和公义。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 23:6; 哥林多前书 1:30; 以赛亚书 45:17"> 在那些日子，犹大必得拯救，耶路撒冷必安然居住；它将被称为‘耶和华我们的公义’。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 2:4; 诗篇 89:29–37; 路加福音 1:32–33"> 因为耶和华如此说：大卫家必不断绝有人坐在以色列家的宝座上；</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 56:7; 启示录 1:6; 申命记 18:1"> 利未祭司们也不断绝有人在我面前献燔祭，烧献素祭，终日献祭。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 耶和华的话语临到耶利米，说：</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 8:22; 诗篇 89:37; 以赛亚书 54:9–10"> “耶和华如此说：除非你们能废除我所立白天黑夜的约，使白天和黑夜不按时来临，</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 89:34; 历代志下 7:18; 撒母耳记下 23:5"> 否则，我与我仆人大卫所立的约绝不会被废除，他必有子孙在他的宝座上作王，并且我与事奉我的利未祭司们所立的约也绝不会被废除。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 15:5; 创世记 22:17; 希伯来书 11:12"> 诸天的万象怎样无法数清，海沙怎样无法测量，我也必怎样使我仆人大卫的后裔和事奉我的利未人增多。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和华的话语临到耶利米，说：</span>
<span className="v" id="v24" data-v="24" data-xref="尼希米记 4:2–4; 诗篇 83:4; 诗篇 44:13–14"> “你没有注意到这子民说什么吗？他们说：‘耶和华所拣选的两个家族，他已经厌弃了。’他们这样藐视我的子民，不再把他们看为一个国家。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 74:16–17; 耶利米书 31:35–36; 诗篇 104:19"> 耶和华如此说：除非我没有立白天黑夜的约，没有立诸天大地的定律，</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 31:37; 以赛亚书 14:1; 何西阿书 2:23"> 否则，我绝不会弃绝雅各的后裔和我仆人大卫的后裔，必从大卫的后裔中拣选人管辖亚伯拉罕、以撒和雅各的后裔。我必使他们的掳民回归，我必怜悯他们。”</span>
</div>

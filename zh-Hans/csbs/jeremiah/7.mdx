<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="JER" data-book-slug="jeremiah" data-book-name="耶利米书" data-chapter="7" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 有话语从耶和华临到耶利米，说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 26:2; 启示录 3:22; 阿摩司书 7:16"> “你要站在耶和华殿的门口，在那里宣告这话，说：所有进入这些门来敬拜耶和华的犹大人哪，你们都要听耶和华的话语！”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米书 18:11; 耶利米书 26:13; 以赛亚书 1:16–19"> 以色列的神万军之耶和华如此说：“你们要改正自己的所作所为，我就让你们居住在这地方。</span>
<span className="v" id="v4" data-v="4" data-xref="弥迦书 3:11; 马太福音 3:9–10; 西番雅书 3:11"> 你们不要依靠虚妄的话语，说：‘这些是耶和华的圣殿，是耶和华的圣殿，是耶和华的圣殿。’</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 6:12–13; 以赛亚书 1:19; 耶利米书 7:3"> 如果你们彻底改正你们的所作所为，如果你们彼此真正实行公正，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 22:21–24; 撒迦利亚书 7:9–12; 耶利米书 13:10"> 不欺压寄居者、孤儿和寡妇，不在这地方流无辜人的血，也不跟从别的神而自招灾祸，</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 4:40; 耶利米书 25:5; 耶利米书 3:18"> 那么，我就让你们安居在这地方，就是我永永远远赐给你们祖先的这地。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 28:15; 以西结书 13:6–16; 耶利米书 23:14–16"> 看哪，你们却依靠虚妄无益的话语！</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="耶利米书 7:6; 出埃及记 20:3; 雅各书 4:1–4"> “你们偷窃、杀人、通奸、起假誓，向巴力烧香，跟从你们所不认识的别的神，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 32:34; 以西结书 23:37; 以西结书 23:39"> 然后来到这被称为我名下的殿宇，站在我面前，说‘我们得保全了’！难道可以任凭你们行这一切可憎之事吗？</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:45–46; 以赛亚书 56:7; 马太福音 21:13"> 难道这被称为我名下的殿宇，在你们眼中成了贼窝吗？看哪，我都看见了！这是耶和华的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约书亚记 18:1; 耶利米书 26:6; 撒母耳记上 4:10–11"> “现在，你们要前往我在示罗的居所，就是我先前使我的名安居的地方，看看我因子民以色列的罪恶而对那地做了什么。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 65:12; 历代志下 36:15–16; 耶利米书 7:25"> 现在，这是耶和华的宣告：因为你们做了这一切事，因为我不断地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="不断地——或译作“一大早就”。">a</a></sup>对你们说话，你们却不听从，我呼唤你们，你们却不回应，</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 78:60; 列王纪下 25:9; 耶利米书 7:4"> 因此我怎样对待示罗，也要怎样对待你们所依靠的这被称为我名下的殿宇，以及我所赐给你们和你们祖先的这地方。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 15:1; 列王纪下 17:23; 耶利米书 52:3"> 我要把你们从我面前赶走，正如我曾赶走你们的众兄弟——所有以法莲的后裔。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米书 11:14; 耶利米书 14:11–12; 耶利米书 15:1"> “至于你，不要为这子民祈祷，不要为他们扬声呼求或祷告，也不要为他们向我代求，因为我不会垂听你。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 8:6–18; 以西结书 14:23; 耶利米书 6:27"> 他们在犹大各城中和耶路撒冷的街道上做了什么，你没有看见吗？</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 19:13; 耶利米书 44:17–19; 哥林多前书 10:22"> 他们孩子捡木柴、父亲点火、女人揉面团为天后做祭饼，并且向别的神浇奠酒祭，以致惹我恼怒。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 20:11; 耶利米书 2:19; 但以理书 9:7–8"> 他们只是惹怒我吗？难道他们不是给自己惹祸，以致满脸耻辱吗？这是耶和华的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="耶利米书 42:18; 耶利米哀歌 2:3–5; 以赛亚书 42:25"> “因此主耶和华如此说：看哪，我的怒气和怒火必倾泻在这地方，倾泻在人和牲畜身上，以及田野的树木和这地的果实上；怒火燃烧，不会熄灭！”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="何西阿书 8:13; 耶利米书 6:20; 阿摩司书 5:21–23"> 以色列的神万军之耶和华如此说：“把你们的燔祭归入你们别的祭物，吃那肉吧！</span>
<span className="v" id="v22" data-v="22" data-xref="何西阿书 6:6; 撒母耳记上 15:22; 诗篇 51:16–17"> 因为我把你们祖先从埃及地领出来的日子，并没有对他们说过，也没有吩咐过他们有关燔祭和别的祭物的事。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 15:26; 申命记 5:33; 出埃及记 19:5–6"> 我只是吩咐他们这一件事，说：‘你们要听从我的话，我就作你们的神，你们也作我的子民；你们要走在我所吩咐你们的一切道路上，好让你们蒙福。’</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 81:11–12; 耶利米书 8:5; 耶利米书 7:26"> 他们却不听从，不侧耳听，反而随从自己的计谋，随从自己顽固败坏的心而行，背对着我，不面向我。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 36:15; 耶利米书 25:4; 尼希米记 9:26"> 自从你们祖先出埃及地那日直到今日，我派遣我的仆人众先知到你们那里去，每日不断地<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="不断地——或译作“一大早就”。">b</a></sup>派遣。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 16:12; 历代志下 30:8; 耶利米书 7:24"> 你们<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="你们——原文直译“他们”；本节下同。">c</a></sup>却不听从我，不侧耳听，反而硬着自己的颈项，作恶超过你们的祖先。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米书 26:2; 耶利米书 1:7; 以赛亚书 65:12"> “你要把这一切话语都告诉他们，但他们不会听从你；你要呼唤他们，但他们不会回应你。</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 59:14–15; 箴言 1:7; 以赛亚书 1:4–5"> 你要对他们说：‘这就是那民族，不听从他们的神耶和华的话，不接受管教！诚信已经消亡，从他们口中断绝了。’</span>
<span className="v" id="v29" data-v="29" data-xref="约伯记 1:20; 弥迦书 1:16; 耶利米书 6:30"> 你要剪去自己的头发扔掉，在光秃的高地上举哀，因为耶和华厌弃、撇弃了这惹怒他的世代。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米书 32:34; 以西结书 7:20; 但以理书 9:27"> 耶和华宣告：“犹大子民做了我眼中看为恶的事，把他们的可憎偶像放在这被称为我名下的殿宇里，玷污了它。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 23:10; 耶利米书 32:35; 利未记 18:21"> 他们还建造了欣嫩子谷中的陀斐特高坛，为要在火中焚烧自己的儿女；这不是我所吩咐的，我也从来没有这样想过。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="耶利米书 19:11; 耶利米书 19:6; 列王纪下 23:10"> “所以看哪，这是耶和华的宣告：日子将到，这地方不再被称为陀斐特或欣嫩子谷，而要被称为‘杀戮谷’。他们将在陀斐特埋葬尸体，直到无处可葬。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 12:9; 申命记 28:26; 启示录 19:17–18"> 这子民的尸体将给天空的飞鸟和地上的走兽作食物，无人吓走它们。</span>
<span className="v" id="v34" data-v="34" data-xref="启示录 18:23; 何西阿书 2:11; 以西结书 26:13"> 我要使犹大各城中和耶路撒冷的街道上，不再有欢喜快乐的声音、新郎新娘的声音，因为这地将成为废墟。”</span>
</div>
</div>

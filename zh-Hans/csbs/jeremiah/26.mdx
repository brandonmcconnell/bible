<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 36:4–5; 耶利米书 27:1; 列王纪下 23:34–36"> 约西亚的儿子犹大王约雅敬开始执政的时候，有这话语从耶和华临到耶利米，说：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 4:2; 使徒行传 20:27; 马太福音 28:20"> “耶和华如此说：你要站在耶和华殿的院宇里，把我指示你说的一切话，都告诉犹大各城的人，就是到耶和华的殿来敬拜的人，一个字也不可减去。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 36:3; 以赛亚书 1:16–19; 耶利米书 18:7–10"> 或许他们肯听从，各人转离邪恶的道路，我就改变心意，不把我因他们的恶行而计划的灾祸降给他们。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 9:6; 耶利米书 44:10; 以赛亚书 1:20"> 你要对他们说，耶和华如此说：如果你们不听从我，不遵行我在你们面前设立的律法，</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 11:7; 列王纪下 9:7; 耶利米书 7:13"> 不听从我仆人众先知的话语——我派遣他们到你们那里去，不断地派遣，你们却不听从——</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 24:9; 列王纪下 22:19; 耶利米书 25:18"> 我就使这殿宇像示罗那样，使这城被地上万国咒骂。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="耶利米书 5:31; 弥迦书 3:11; 使徒行传 5:17"> 耶利米在耶和华殿中说的这些话，祭司和先知们以及全体民众都听见了。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米哀歌 4:13–14; 使徒行传 7:52; 耶利米书 18:18"> 耶利米说完了耶和华吩咐他对全体民众说的一切话，祭司和先知们以及全体民众就抓住他，说：“你必须死！</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 4:17–19; 使徒行传 19:24–32; 弥迦书 2:6"> 你为什么奉耶和华的名预言说这殿宇必像示罗那样，这城必荒废，无人居住？”全体民众都在耶和华殿中聚集到耶利米那里。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 36:10; 耶利米书 38:4–6; 耶利米书 37:14–16"> 犹大的首领们听见这些事，就从王宫上耶和华的殿去，在耶和华殿的新门入口坐下。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 38:4; 马太福音 26:66; 申命记 18:20"> 祭司和先知们对首领们和全体民众说：“这人该受死刑！因为他说预言攻击这城，正如你们亲耳听见的。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 5:29; 耶利米书 26:15; 使徒行传 4:19"> 于是耶利米对众首领和全体民众说：“是耶和华派遣了我，针对这圣殿和这城，预言你们所听见的一切话。</span>
<span className="v" id="v13" data-v="13" data-xref="约拿书 3:9; 约拿书 4:2; 以赛亚书 1:19"> 现在，你们要改正你们的所作所为，听从你们的神耶和华的话，好让耶和华改变心意，不把他所宣告的灾祸降给你们。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 9:25; 撒母耳记下 15:26; 耶利米书 38:5"> 至于我，看哪，我在你们手中，你们看怎样好、怎样合适，就怎样对待我吧！</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 35:33; 箴言 6:17; 马太福音 26:25"> 不过你们要确实知道：你们如果把我处死，就是把无辜人的血债归在你们身上，归到这城和其中的居民身上，因为耶和华确实派遣了我到你们这里，把这一切话语传到你们的耳中。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行传 5:34–39; 使徒行传 23:29; 使徒行传 25:25"> 首领们和全体民众就对祭司和先知们说：“这人不该受死刑！因为他是奉我们神耶和华的名对我们说话。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="使徒行传 5:34; 弥迦书 1:1"> 那地的长老中有一些人起来，对聚集的全体民众说：</span>
<span className="v" id="v18" data-v="18" data-xref="弥迦书 1:1; 尼希米记 4:2; 撒迦利亚书 8:3"> “犹大王希西加年间，摩利沙人弥迦说预言，向犹大全体民众宣告说：‘万军之耶和华如此说：<br /><span className="pl pl-1">锡安必像田地被耕犁，</span><br /><span className="pl pl-1">耶路撒冷将变为荒堆，</span><br /><span className="pl pl-1">圣殿山将变为荒林高地。’</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及记 32:14; 撒母耳记下 24:16; 以赛亚书 37:15–20"> “那时，犹大王希西加和全体犹大人把他处死了吗？希西加难道不是敬畏耶和华，恳求耶和华的情面吗？耶和华就改变心意，没有把他所宣告的灾祸降给他们。现在我们却要使大祸临到我们！”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 7:2; 约书亚记 9:17; 约书亚记 15:60"> 另有一个人也奉耶和华的名说预言，这人是基列-耶琳人示玛雅的儿子乌利亚，他针对这城和这地说预言，与耶利米所说的话语全都一样。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 10:23; 马太福音 14:5; 耶利米书 36:26"> 约雅敬王和他的勇士们、首领们全都听见了乌利亚的话语，王就想要把他处死。乌利亚听说后就害怕，逃往埃及去了。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 36:12; 列王纪下 22:12; 列王纪下 22:14"> 约雅敬王派人前往埃及，他派亚革波的儿子以利拿单带着一些人一同到埃及去。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 2:30; 启示录 11:7; 以西结书 19:6"> 他们把乌利亚从埃及带出来，带到约雅敬王那里。王用刀杀了他，把他的尸体扔在平民的坟地里。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米书 40:5–7; 耶利米书 39:14; 耶利米书 1:18–19"> 然而沙番的儿子亚希甘保护了耶利米，使他不被交在民众的手中处死。</span>
</div>

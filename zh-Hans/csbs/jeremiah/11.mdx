<div className="bp">
<span className="v" id="v1" data-v="1"> 有话语从耶和华临到耶利米，说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 11:6; 出埃及记 19:5; 历代志下 29:10"> “你要听这约的话语，并把它们告诉犹大人和耶路撒冷的居民。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 27:26; 申命记 28:15–68; 申命记 29:19–20"> 你要对他们说，以色列的神耶和华如此说：不听从这约上话语的人，是受诅咒的！</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 26:12; 耶利米书 7:22–23; 申命记 4:20"> 这约是我与你们祖先立定的，在我从埃及地、从那铁的熔炉中领出他们的日子，我说：‘你们要听从我的话，遵行我所吩咐你们的一切。这样，你们就作我的子民，我也作你们的神。’</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 7:12–13; 诗篇 105:9–11; 耶利米书 28:6"> 这是为要确立我向你们祖先所起的誓，把流奶与蜜之地赐给他们，就像今日这样。”<br />我就回应说：“耶和华啊，阿们！”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="雅各书 1:22; 罗马书 2:13; 耶利米书 7:2"> 耶和华对我说：“你要在犹大的各城中和耶路撒冷的街道上宣告这一切话语，说：你们要听从这约的话语，遵行它们。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 36:15; 以弗所书 4:17; 撒母耳记上 8:9"> 自从我把你们的祖先从埃及地带上来的日子，直到今日，我都严厉地告诫他们，不断地警诫说：要听从我的话！</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 7:24; 耶利米书 7:26; 耶利米书 35:15"> 他们却不听从，不侧耳听，各人随从自己顽固败坏的心行事。因此我使这约上一切诅咒的话语都应验在他们身上，这约是我吩咐他们要遵行的，他们却没有遵行。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="何西阿书 6:9; 马太福音 26:3–4; 弥迦书 3:11"> 耶和华对我说：“在犹大人和耶路撒冷的居民中有叛逆的事。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 31:16; 以西结书 16:59; 诗篇 78:8–10"> 他们重复他们祖先的罪孽，不肯听从我的话，也去跟从服事别的神。以色列家和犹大家违背了我与他们祖先所立的约。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以西结书 8:18; 箴言 1:28; 以赛亚书 1:15"> 因此耶和华如此说：“看哪，我必使祸患临到他们，他们绝不能逃脱；即使他们向我哀求，我也不会垂听他们。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 2:28; 申命记 32:37; 历代志下 28:22"> 那时犹大的各城和耶路撒冷的居民必去哀求他们烧香所供奉的神明，但在祸患临到他们的时候，那些神明绝不能拯救他们。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 2:28; 列王纪下 23:13; 以赛亚书 2:8"> 犹大啊，你的神明与你城镇的数目一样多；你为可耻的偶像立的祭坛，就是向众巴力烧香的祭坛，与耶路撒冷街道的数目一样多！</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="耶利米书 7:16; 耶利米书 11:11; 约翰一书 5:16"> “至于你，不要为这子民祈祷，也不要为他们扬声呼求或祷告；他们遭祸患向我呼求的时候，我必不垂听。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 2:14; 提多书 1:15; 耶利米书 3:1–2"> <span className="pl pl-1">我所爱的人行了许多诡计，</span><br /><span className="pl pl-1">还有什么资格在我的殿宇中呢？</span><br /><span className="pl pl-1">难道神圣的肉能使你脱离祸患，</span><br /><span className="pl pl-1">使你欢跃吗？</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 11:17–24; 以赛亚书 27:11; 诗篇 52:8"> <span className="pl pl-1">耶和华曾给你起名为</span><br /><span className="pl pl-1">‘佳美、多结果实的青翠橄榄树’，</span><br /><span className="pl pl-1">但他必在极大的轰隆声中点火焚烧这树，</span><br /><span className="pl pl-1">树枝都将被烧毁。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 5:2; 耶利米书 2:21; 耶利米书 12:2"> “那栽种你的万军之耶和华已经对你宣告祸患，因为以色列家和犹大家作恶，他们向巴力烧香，惹我恼怒。”</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 23:11–12; 列王纪下 6:9–10; 以西结书 8:6–18"> <span className="pl pl-1">耶和华指示我，我就知道；</span><br /><span className="pl pl-1">那时你把他们的行为向我显明了。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 53:7–8; 耶利米书 20:10; 诗篇 83:4"> <span className="pl pl-1">我就像温顺的羊羔被牵去宰杀，</span><br /><span className="pl pl-1">并不知道他们谋划计策害我；</span><br /><span className="pl pl-1">他们说：</span><br /><span className="pl pl-1">“让我们把树连果子都毁掉吧，</span><br /><span className="pl pl-1">把他从活人之地剪除，</span><br /><span className="pl pl-1">使他的名不再被记念！”</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 20:12; 耶利米书 17:10; 撒母耳记上 16:7"> <span className="pl pl-1">万军之耶和华啊，</span><br /><span className="pl pl-1">你是按公义施行审判、</span><br /><span className="pl pl-1">察验肺腑心肠的，</span><br /><span className="pl pl-1">求你让我看见你在他们身上报仇！</span><br /><span className="pl pl-1">我已经向你陈明了我的案件。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="耶利米书 20:10; 阿摩司书 2:12; 路加福音 13:33–34"> 因此耶和华如此论到那些亚纳图人：“他们寻索你的性命说：‘你不要奉耶和华的名说预言，以免死在我们手中’，</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 18:21; 历代志下 36:17; 耶利米书 9:21"> 所以万军之耶和华如此说：看哪，我必惩罚他们！他们的青年人必死在刀下，他们的儿女必死在饥荒中。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 23:12; 弥迦书 7:4; 何西阿书 9:7"> 他们不会有余剩之民，因为我要在他们受惩罚之年，使祸患临到亚纳图人。”</span>
</div>

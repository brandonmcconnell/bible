<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 41:11; 耶利米书 40:13; 耶利米书 6:13"> 那时，所有的将领，加利亚的儿子约哈南和何沙雅的儿子耶撒尼亚，以及全体民众，无论尊卑都前来，</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 36:7; 利未记 26:22; 使徒行传 8:24"> 对先知耶利米说：“请接受我们的恳求<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="接受我们的恳求——原文直译“让我们的恳求达到你面前”。">a</a></sup>，为我们，为这所有的余剩之民向你的神耶和华祷告；因为就像你亲眼看到的，我们众多的人只剩下了少数。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 86:11; 箴言 3:6; 诗篇 25:4–5"> 愿你的神耶和华指示我们当走的路和当做的事！”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 12:23; 撒母耳记上 3:17–18; 出埃及记 8:29"> 先知耶利米对他们说：“我已经听见了。看哪，我必照着你们的话向你们的神耶和华祷告。耶和华回答你们的一切话语，我都会告诉你们，不会保留一句不告诉你们的。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 31:50; 士师记 11:10; 玛拉基书 3:5"> 他们就对耶利米说：“如果我们不照着耶和华你神派遣你告诉我们的一切话去做，就愿耶和华作真实诚信的见证，指控我们！</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 7:23; 申命记 5:29; 罗马书 8:7"> 我们派你去求问耶和华我们的神，他的话语无论是好是坏，我们都会听从，好使我们因听从我们神耶和华的话语而蒙福。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="诗篇 27:14; 以赛亚书 28:16; 哈巴谷书 2:3"> 过了十天，耶和华的话语临到耶利米。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 42:1; 耶利米书 41:11–16; 耶利米书 43:2–5"> 他就把加利亚的儿子约哈南和那些跟随他的将领，以及全体民众，无论尊卑都召来。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王纪下 19:4; 耶利米书 42:2; 列王纪下 19:6"> 他对他们说：“你们派我去在以色列的神耶和华面前呈上你们的恳求，现在他如此说：</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 31:28; 以西结书 36:36; 耶利米书 24:6"> 如果你们仍然住在这地，我就建立你们而不拆毁，栽种你们而不拔出，因为我对降给你们的灾祸感到后悔。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 8:31; 耶利米书 1:19; 耶利米书 1:8"> 不要怕你们所惧怕的巴比伦王，不要怕他，因为我与你们同在，必拯救你们，解救你们脱离他的手。这是耶和华的宣告。</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米记 1:11; 诗篇 106:45–46; 箴言 16:7"> 我要向你们施怜悯，使他怜悯你们，让你们回归自己的土地。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 44:16; 出埃及记 5:2; 耶利米书 42:10"> 但如果你们不听从你们的神耶和华的话语，而说‘我们不住在这地！</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 41:17; 耶利米书 4:19; 以赛亚书 31:1"> 不，我们还是要去埃及地，住在那里，在那里不会看到战争，不会听到号角声，也不会因缺乏粮食而挨饿’，</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 17:16; 耶利米书 44:12–14; 耶利米书 42:17"> 那么，犹大的余剩之民哪，现在你们要听耶和华的话语！以色列的神万军之耶和华如此说：如果你们执意要去埃及，去寄居在那里，</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 44:27; 以西结书 11:8; 阿摩司书 9:1–4"> 你们所惧怕的刀剑就会在埃及地追上你们，你们所担忧的饥荒也会在埃及紧跟着你们，你们必死在那里。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 42:22; 耶利米书 44:28; 耶利米书 44:13–14"> 所有执意要去埃及寄居的人，都必死于刀剑、饥荒和瘟疫，绝不会有幸存者或逃脱者躲避我降给他们的灾祸。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米书 7:20; 耶利米书 18:16; 耶利米书 29:18"> “以色列的神万军之耶和华如此说：我的怒气和怒火怎样倾泻在耶路撒冷的居民身上，当你们去埃及的时候，我的怒火也怎样倾泻在你们身上。你们将被辱骂、令人惊骇、被咒骂、被羞辱，再也看不到这地方。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 17:16; 以赛亚书 30:1–7; 尼希米记 9:26"> 犹大的余剩之民哪，耶和华已经对你们说：‘不要去埃及！’你们要确实知道：我今天已经警诫你们了！</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 14:3–4; 以西结书 33:31; 马太福音 22:15–18"> 你们实在是自欺，因为你们派我去求问你们的神耶和华，说‘请为我们向我们的神耶和华祷告，把我们神耶和华所说的全都告诉我们，我们必遵行’，</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 2:7; 撒迦利亚书 7:11–12; 使徒行传 20:26–27"> 我今天告诉了你们，你们却不听从你们的神耶和华的话语，不听从他所派我来告诉你们的一切。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 42:17; 以西结书 6:11; 何西阿书 9:6"> 现在你们要确实知道：你们在想要去寄居的地方，必死于刀剑、饥荒和瘟疫。”</span>
</div>

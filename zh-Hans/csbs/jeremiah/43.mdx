<span className="v" id="v1" data-v="1" data-xref="耶利米书 26:8; 耶利米书 51:63; 耶利米书 42:22"> 耶利米对全体民众说完了他们的神耶和华的一切话语，就是他们的神耶和华派遣他去对他们说的这一切话语。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 36:13; 以赛亚书 7:9; 耶利米书 40:8"> 何沙雅的儿子亚撒利雅和加利亚的儿子约哈南，以及所有傲慢的人，就对耶利米说：“你在说假话！耶和华我们的神没有派遣你来说：‘不可去埃及，不可寄居在那里。’</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 45:1–3; 耶利米书 36:4; 耶利米书 36:26"> 这是尼利亚的儿子巴录克怂恿你反对我们，为要把我们交在迦勒底人手中，杀死我们，或把我们掳到巴比伦去。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="耶利米书 42:5–6; 诗篇 37:3; 历代志下 25:16"> 于是加利亚的儿子约哈南和所有的将领，以及全体民众，没有听从耶和华要他们留在犹大地的话。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 40:11–12; 耶利米书 41:15–16; 撒母耳记上 26:19"> 加利亚的儿子约哈南和那些将领带走了犹大所有的余剩之民，就是从流亡的各个地方回来，要寄居在犹大地的人，</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 39:10; 耶利米书 40:7; 耶利米书 41:10"> 包括男人、女人、孩童，公主们，以及护卫长尼布撒拉旦留给沙番之子亚希甘的儿子基大利的那些人，还有先知耶利米和尼利亚的儿子巴录克。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 2:16; 耶利米书 44:1; 以赛亚书 30:4"> 他们去了埃及地，因为他们不听从耶和华的话语。这样，他们来到塔帕尼斯。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="耶利米书 2:16; 诗篇 139:7; 提摩太后书 2:9"> 在塔帕尼斯，耶和华的话语临到耶利米，说：</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 18:2–12; 耶利米书 19:1–15; 耶利米书 51:63–64"> “你手里拿上几块大石头，在犹大人眼前，把它们藏在塔帕尼斯法老宫殿门口那砖窑的灰泥中，</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 44:28–1; 耶利米书 1:15; 诗篇 31:20"> 然后对他们说，以色列的神万军之耶和华如此说：看哪，我必派人把我的仆人巴比伦王尼布甲尼撒带来，我要在我所藏的这些石头上安放他的宝座，他必在这些石头上张开他的华盖。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 15:2; 耶利米书 44:13; 以西结书 29:19–20"> 他要来攻击埃及地：命定死亡的，就归向死亡；命定掳掠的，就归向掳掠；命定刀剑的，就归向刀剑。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 30:13; 诗篇 109:18–19; 以赛亚书 19:1"> 我要点火焚烧埃及神明的殿宇，他必烧毁殿宇，掳走神像。他必清扫埃及地，像牧人清扫外衣那样，然后平安地离开那里。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 19:18"> 他必打碎埃及地伯示麦的神柱，放火烧毁埃及神明的殿宇。”</span>
</div>

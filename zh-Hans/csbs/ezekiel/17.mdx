<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="何西阿书 8:1; 耶利米书 48:40; 以西结书 17:7"> 你要说，主耶和华如此说：<br /><span className="pl pl-1">有一只大鹰，翅膀大，翎毛长，</span><br /><span className="pl pl-1">羽毛丰满，色彩缤纷。</span><br /><span className="pl pl-1">它来到黎巴嫩，</span><br /><span className="pl pl-1">抓住香柏树的树梢，</span><br /></span>

<span className="v" id="v5" data-v="5" data-xref="以赛亚书 44:4; 申命记 8:7–9; 耶利米书 37:1"> <span className="pl pl-1">它又取了这地的一株种苗，</span><br /><span className="pl pl-1">插在肥沃的田地里，</span><br /><span className="pl pl-1">丰富的水源旁，</span><br /><span className="pl pl-1">它把种苗像柳树那样栽下。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 17:14; 箴言 16:18–19"> <span className="pl pl-1">种苗生长，</span><br /><span className="pl pl-1">成为低矮蔓延的葡萄树，</span><br /><span className="pl pl-1">枝子朝向这鹰，</span><br /><span className="pl pl-1">根向下生长</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="向下生长——或译作“在鹰的下面”。">a</a></sup><br /><span className="pl pl-1">。</span><br /><span className="pl pl-1">种苗长成葡萄树，</span><br /><span className="pl pl-1">长出枝子，伸展枝条。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="以西结书 31:4; 以西结书 17:15; 列王纪下 24:20"> <span className="pl pl-1">然而另有一只大鹰，</span><br /><span className="pl pl-1">翅膀大，羽毛多，</span><br /><span className="pl pl-1">看哪，这葡萄树从所栽种的苗圃，</span><br /><span className="pl pl-1">把根向这鹰弯过去，把枝子伸向它，</span><br /><span className="pl pl-1">好得它的浇灌。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 17:5–6"> <span className="pl pl-1">其实这葡萄树已经栽种</span><br /><span className="pl pl-1">在好田地里、丰富的水源旁，</span><br /><span className="pl pl-1">可以生出枝条，结出果实，</span><br /><span className="pl pl-1">成为佳美的葡萄树。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="以西结书 17:10; 耶利米书 32:5; 以赛亚书 30:1–7"> 你要说，主耶和华如此说：<br /><span className="pl pl-1">它怎能发旺？</span><br /><span className="pl pl-1">先前的鹰难道不是要拽出它的根，</span><br /><span className="pl pl-1">扫落它的果实，</span><br /><span className="pl pl-1">以致它枯干吗？</span><br /><span className="pl pl-1">它所有长出的嫩叶都必枯干。</span><br /><span className="pl pl-1">不用强大的膀臂或许多人，</span><br /><span className="pl pl-1">就能把它连根拔出。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="何西阿书 13:15; 约翰福音 15:6; 马太福音 21:19"> <span className="pl pl-1">看哪，它被栽种，</span><br /><span className="pl pl-1">就能发旺吗？</span><br /><span className="pl pl-1">东风吹袭时，</span><br /><span className="pl pl-1">它不是要完全枯干吗？</span><br /><span className="pl pl-1">它必在所生长的苗圃里枯干。”</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和华的话语又临到我，说：</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 24:19; 以西结书 17:3; 以西结书 1:2"> “现在你要对那悖逆之家说：你们不知道这些是什么意思吗？你要说：看哪，巴比伦王曾来到耶路撒冷，掳走君王和首领们，把他们带到了巴比伦他那里。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 36:13; 列王纪下 24:15–17; 以西结书 17:5"> 巴比伦王挑选了一位王室后裔，与他立约，使他起了誓；并且掳走当地的权贵，</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 29:14; 申命记 28:43; 撒母耳记上 2:30"> 使这国衰微，不能再兴起，只有遵守他的约才得以存留。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 52:3; 耶利米书 38:18; 以西结书 17:7"> 但这人却背叛了巴比伦王，派遣使者到埃及去，要埃及给他马匹和许多军兵。难道他能成功吗？他做这些事，难道能逃脱吗？他违背誓约，能逃脱吗？</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以西结书 12:13; 耶利米书 52:11; 以西结书 17:18–19"> “这是主耶和华的宣告：我指着我的永生起誓，他必定死在巴比伦，就是立他作王的那位王的地方，因他轻看王的誓言，违背王与他所立的约。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 37:7; 以西结书 4:2; 以西结书 29:6–7"> 当敌人筑起土垒，建造高台，为要剪除许多人时，法老不会率领大军和众多的队伍到战场上救助他。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 29:24; 历代志下 30:8; 耶利米哀歌 5:6"> 他轻看誓言，违背誓约，看哪，他已经举手臣服，却做出这些事，他绝不能逃脱。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命记 5:11; 耶利米书 5:9; 耶利米书 5:2"> “因此主耶和华如此说：我指着我的永生起誓，他既轻看我的誓言，违背我的约，我必把这罪报应在他的头上。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 12:13; 以西结书 32:3; 耶利米书 2:35"> 我要向他张开我的网，他必被我的网罗捉住。我要把他带到巴比伦，在那里审判他，因他对我行事不忠。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 25:5; 列王纪下 25:11; 以西结书 12:14"> 他所有军队中溃逃的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="溃逃的——或译作“精兵”。">b</a></sup>都将倒在刀下，残留的也将被驱散到四方。那时你们就知道：是我耶和华发了话。</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 53:2; 撒迦利亚书 6:12–13; 以赛亚书 11:1–5"> “主耶和华如此说：<br /><span className="pl pl-1">然后，我要亲自从高大的香柏树梢</span><br /><span className="pl pl-1">取下嫩枝，安置它；</span><br /><span className="pl pl-1">我要从这树的嫩枝头上摘下嫩芽，</span><br /><span className="pl pl-1">栽种在高耸险峻的山岭上。</span><br /></span>

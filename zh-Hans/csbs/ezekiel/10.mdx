<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 24:10; 启示录 4:2–3; 启示录 1:13"> 我观看，看哪，在基路伯头顶上方的穹苍中，有仿佛宝座的形象，好像蓝宝石，出现在他们上方。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 8:5; 以西结书 10:16; 以西结书 1:13"> 耶和华吩咐身穿细麻衣的那人说：“你到基路伯下面、旋转的轮子中间，从基路伯之间取一满捧火炭，撒在城上。”他就在我眼前过去了。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以西结书 43:4; 以西结书 9:3; 以西结书 8:16"> 那人过去的时候，基路伯站在圣殿的右边，云雾充满了内院。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 1:28; 以西结书 9:3; 出埃及记 40:35"> 耶和华的荣耀升起离开基路伯的上方，到圣殿的门槛之上，圣殿充满了云雾，庭院也充满了耶和华荣耀的光辉。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 1:24; 约伯记 40:9; 出埃及记 19:16"> 基路伯翅膀的声音在外院也能听到，好像全能的神说话的声音。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结书 10:2; 诗篇 99:1; 诗篇 80:1"> 他吩咐身穿细麻衣的那人说：“你从旋转的轮子中间，从基路伯之间取火吧！”那人就过去，站在轮子旁边。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 13:41–42; 以西结书 1:13; 以西结书 41:23–26"> 有一个基路伯从基路伯之间伸出手，到基路伯之间的火中拿起一些火炭，放在身穿细麻衣的那人手中。他接过来，就出去了。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 1:8; 以西结书 10:21; 以赛亚书 6:6"> 那些基路伯翅膀底下，有人手的形态显出来。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以西结书 1:15–17; 但以理书 10:6; 启示录 21:20"> 我又观看，看哪，基路伯旁边有四个轮子。一个基路伯旁边有一个轮子，另一个基路伯旁边也有一个轮子，轮子的外观如同闪耀的黄水晶。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 1:16; 诗篇 36:6; 诗篇 104:24"> 它们的形状，四个轮子是同一个样式，像是轮中套轮。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 1:17; 以西结书 10:22; 以西结书 1:20"> 基路伯行走时，四个方向都可前行，行走并不转身。因为基路伯的头朝向什么地方，轮子也跟着去，它们行走时不必转身。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 1:18; 启示录 4:8; 启示录 4:6"> 基路伯全身，它们的背、手和翅膀，以及轮子，周身布满了眼睛，四个基路伯的轮子都是如此。</span>
<span className="v" id="v13" data-v="13"> 这些轮子，我听见它们被称为“旋转轮”。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 4:7; 以西结书 10:21; 列王纪上 7:36"> 每一个基路伯有四张脸：第一张脸是基路伯的脸，第二张脸是人的脸，第三张是狮子的脸，第四张是老鹰的脸。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西结书 1:5; 何西阿书 9:12; 以西结书 11:22"> 这时基路伯上升，正是我曾在迦巴鲁河边所看见的活物。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 1:19–21"> 基路伯行走时，轮子也在它们旁边行走；基路伯扬起翅膀离地上升时，轮子也不离开它们旁边。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 1:20–21; 罗马书 8:2; 以西结书 1:12"> 基路伯站住时，轮子也站住；基路伯上升时，轮子也与它们一起上升；因为活物的灵在轮子里。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="诗篇 18:10; 马太福音 23:37–39; 诗篇 78:60–61"> 耶和华的荣耀从圣殿的门槛之上离开，停留在基路伯上方。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 8:16; 以西结书 1:17–21; 以西结书 1:26–28"> 然后基路伯扬起翅膀，在我眼前离地上升；它们离去的时候，轮子也在它们旁边。它们停留在耶和华殿东门的入口，以色列神的荣耀在它们上方。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西结书 1:1; 以西结书 10:15; 列王纪上 7:36"> 这正是我曾在迦巴鲁河边所看见的活物，它们在以色列神的荣耀下方，我知道它们就是基路伯。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 1:6; 以西结书 41:18–19; 以西结书 10:14"> 四个基路伯，每一个有四张脸，每一个有四个翅膀，翅膀底下有人手的形象。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 10:11; 以西结书 1:10; 以西结书 1:12"> 它们脸的形象，正是我曾在迦巴鲁河边所看见的活物的脸，样貌相同；它们各都直往前行。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话语临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 13:17; 耶利米书 37:19; 以西结书 22:28"> “人子啊，你要针对那些说预言的以色列先知发预言，对随从自己心意的众先知说：你们要听耶和华的话语！</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米哀歌 2:14; 耶利米书 23:28–32; 何西阿书 9:7"> 主耶和华如此说：那些愚顽的先知有祸了！他们是随从自己的灵，什么也没有看见。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 19:20; 弥迦书 2:11; 帖撒罗尼迦后书 2:9–10"> 以色列啊，你的众先知就像废墟中的狐狸！</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 22:30; 诗篇 106:23; 以赛亚书 58:12"> 他们没有上去堵破口，也没有为以色列家修补围墙，好使以色列家在耶和华的日子里，在战场上站立得住。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 29:8; 以西结书 22:28; 耶利米书 28:15"> 他们所见的是虚假的异象，是虚谎的占卜。他们说‘这是耶和华的宣告’，其实耶和华并没有派遣他们；他们还期待那些话语成就！</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 13:6; 马太福音 24:23–24; 以西结书 13:2–3"> 难道你们不是见了虚假的异象，说了虚谎的占卜吗？你们说‘这是耶和华的宣告’，其实我并没有宣告。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西结书 5:8; 以西结书 21:3; 以西结书 28:22"> “因此主耶和华如此说：因为你们说虚假的事，见虚谎的异象，所以看哪，我敌对你们！这是主耶和华的宣告。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 87:6; 诗篇 69:28; 以西结书 20:38"> 我要出手攻击那些见虚假异象、行虚谎占卜的先知，他们必不被列入我子民的会中，不被记在以色列家的名册上，不得进入以色列地。那时你们就知道：我是主耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西结书 22:28; 以西结书 13:16; 耶利米书 6:14"> “这实在是因为他们误导我的子民说‘平安！’，其实并没有平安。看哪，有人建造脆弱的墙，他们却用白灰粉饰它！</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 38:22; 以赛亚书 28:2; 那鸿书 1:7–8"> 你要对那些用白灰粉饰的人说：墙必倒塌。必有雨水泛滥；冰雹啊，你们也要降下；必有暴风吹袭！</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 3:13; 耶利米哀歌 2:14–15; 士师记 9:38"> 看哪，这墙就倒塌了。人们岂不是要责问你们：‘你们粉饰的灰泥在哪里呢？’</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 30:30; 启示录 16:21; 诗篇 148:8"> “因此主耶和华如此说：我要在怒火中使暴风吹袭；必有雨水在我的怒气中泛滥，有冰雹在我的愤怒中施行毁灭。</span>
<span className="v" id="v14" data-v="14" data-xref="弥迦书 1:6; 耶利米书 14:15; 耶利米书 6:15"> 我要拆毁你们用白灰粉饰的墙，把它夷为平地，以致它根基裸露。它必倒塌，你们也将在墙下灭亡。那时你们就知道：我是耶和华。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 30:13; 诗篇 62:3; 尼希米记 4:3"> 我要向那墙和那些用白灰粉饰墙的人发尽我的怒火，然后对你们说：‘墙没有了！粉饰它的人也不在了！’</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 13:10; 耶利米书 6:14; 耶利米书 8:11"> 那些人就是向耶路撒冷说预言的以色列先知，他们见异象说耶路撒冷有平安，其实并没有平安。这是主耶和华的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西结书 13:2; 列王纪下 22:14; 士师记 4:4"> “人子啊，你要面向你子民中那些随从自己心意说预言的女人，针对她们发预言。</span>
<span className="v" id="v18" data-v="18" data-xref="彼得后书 2:14; 以西结书 13:20; 提摩太后书 4:3"> 你要说，主耶和华如此说：你们有祸了！你们照着各人的手腕缝制符咒带子，照着各样身高之人的头制作盖头巾，为要猎取灵魂。你们猎取我子民的灵魂，难道还能保全自己的灵魂吗？</span>
<span className="v" id="v19" data-v="19" data-xref="弥迦书 3:5; 箴言 28:21; 耶利米书 23:17"> 你们为了几把大麦、几小块饼，在我的子民中亵渎我；你们对爱听谎言的民众说谎，使不该死的人被处死，使不该活的人存活。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西结书 13:18; 提摩太后书 3:8–9; 以西结书 13:8–9"> “因此主耶和华如此说：看哪，我要对付你们的符咒带子，就是你们像猎取飞鸟那样猎取灵魂的带子。我必从你们膀臂上撕下它们，释放那些灵魂，就是你们像猎取飞鸟那样猎取的灵魂。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 91:3"> 我必撕碎你们的盖头巾，把我的子民从你们手中解救出来，不再作你们手中的猎物。那时你们就知道：我是耶和华。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 23:14; 耶利米书 14:13–17; 彼得后书 2:18–19"> 因为你们以虚谎使义人心里伤痛，其实我并没有使他心里伤痛；你们又稳固恶人的手，使他不转离邪恶的道路得以存活，</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 13:21; 以西结书 12:24; 弥迦书 3:6"> 因此你们绝不再见虚假的异象，不再行占卜；我也要把我的子民从你们手中解救出来。那时你们就知道：我是耶和华。”</span>
</div>

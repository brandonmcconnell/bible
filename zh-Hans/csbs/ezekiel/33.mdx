<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话语临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 33:30; 以西结书 33:17; 以西结书 3:11"> “人子啊，你要告诉你的同胞，对他们说：如果我使刀剑临到一个地方，那地的民众从他们中间选取了一个人立为守望者，</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿书 8:1; 尼希米记 4:20; 尼希米记 4:18"> 这人看见刀剑即将临到那地，就吹角警诫民众，</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 18:13; 使徒行传 18:6; 耶利米书 6:17"> 凡是听见号角声却不受警诫的，刀剑来除掉了他，他的血债将归到自己头上。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 9:19–21; 希伯来书 11:7; 约翰福音 8:39"> 他听见号角声，却不受警诫，他的血债就归到自己身上；他如果受警诫，就可保全自己的性命。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 3:18–20; 以西结书 33:8–9; 创世记 42:22"> 但那守望者如果看见刀剑即将临到，却不吹角，以致民众未曾被警诫，刀剑就来除掉他们中间某人的性命，这人因自己的罪孽而被除掉了，我却要从守望者手中追讨他的血债。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以西结书 3:17–21; 耶利米书 26:2; 以西结书 2:7–8"> “所以你，人子啊，我已经立你为以色列家的守望者，你从我口中听到了话语，就要使他们受我的警诫。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 20:26–27; 以西结书 33:6; 以西结书 33:14"> 当我对恶人说‘恶人哪，你必定死’，你却没有发话警诫恶人离开他的道路，那恶人就会因自己的罪孽而死，我却要从你手中追讨他的血债。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 3:19; 使徒行传 20:26; 箴言 15:10"> 但如果你警诫了恶人，要他转离他的道路，他却不转离自己的道路，他必因自己的罪孽而死，你却保全了你的性命。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 49:14; 以西结书 37:11; 以西结书 24:23"> “人子啊，你要对以色列家说：‘你们曾这样讨论说：我们既然有过犯和罪恶，正在因这些而衰亡，我们怎能存活呢？’</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 2:4; 以西结书 18:23; 彼得后书 3:9"> 你要对他们说，这是主耶和华的宣告：我指着我的永生起誓，我所乐意的绝不是恶人死亡，而是恶人转离他的道路而存活。以色列家啊，回转吧，转离你们邪恶的道路！你们何必死亡呢？</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="历代志下 7:14; 以西结书 33:18–19; 罗马书 3:25"> “人子啊，你要对你的同胞说：义人的义，在他有过犯的日子里不能解救他；恶人的恶，在他转离恶事的日子里不会使他倒下。义人在他犯罪的日子里，不能因他先前的义而存活。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 18:24; 希伯来书 10:38; 以西结书 18:4"> 当我对义人说‘你必定存活’，他却仗着自己的义而行不义，他先前所有的义都不再被提起，他必因所行的不义而死。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西结书 18:27; 耶利米书 18:7–8; 何西阿书 14:1"> “另外，当我对恶人说‘你必定死’，他就转离自己的罪，实行公正和公义，</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 20:11; 路加福音 19:8; 出埃及记 22:1–4"> 这恶人归还抵押，偿还抢来的东西，按照生命的律例行事，不再行不义，他必定存活，不会死亡。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 43:25; 以西结书 18:22; 弥迦书 7:18–19"> 他所犯的一切罪，都不会被提起；他实行公正和公义，必定存活。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 25:24–26; 以西结书 18:25; 以西结书 18:29"> “你的同胞说主做事不公平，其实是他们做事不公平。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 33:12–13; 彼得后书 2:20–22; 希伯来书 10:38"> 义人如果转离自己的义而行不义，他必因这些不义而死；</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 18:27–28; 以西结书 33:14"> 恶人如果转离自己的恶，实行公正和公义，他必因此而存活。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 16:27; 以西结书 18:25; 以西结书 33:17"> 你们却说主做事不公平！以色列家啊，我必照着你们各人的行为审判你们。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西结书 1:2; 耶利米书 39:1–8; 列王纪下 25:4"> 在我们被掳后第十二年的十月五日，有个从耶路撒冷逃脱的人来到我这里，说：“城已经被攻陷了。”</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 1:3; 以西结书 3:26–27; 以西结书 24:26–27"> 那逃脱的人来到的前一天傍晚，耶和华的手已经临到我了；直到清晨那人来到我这里，耶和华才开了我的口。我的口开了，我不再哑然无声。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和华的话语临到我，说：</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 33:27; 以赛亚书 51:2; 使徒行传 7:5"> “人子啊，以色列地这些废墟上的居民讨论说：‘亚伯拉罕一个人的时候，拥有了这地；现在我们有许多人，这地必定赐给我们为产业了。’</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 12:16; 耶利米书 7:9–10; 创世记 9:4"> 因此你要对他们说，主耶和华如此说：你们吃带血的肉，仰望你们的偶像，杀人流血，你们还能拥有这地吗？</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 27:40; 弥迦书 2:1–2; 西番雅书 3:3"> 你们依仗自己的刀剑做可憎的事，各人玷污邻人的妻子，你们还能拥有这地吗？</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 13:6; 耶利米书 42:22; 以西结书 39:4"> “你要对他们说，主耶和华如此说：我指着我的永生起誓，在废墟中的，必倒在刀下；在田野上的，我要交给野兽吃；在要塞和洞穴里的，必死于瘟疫。</span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 7:24; 耶利米书 44:2; 耶利米书 44:6"> 我要使这地荒废、凄凉，它所夸耀的势力必消亡，以色列的群山必荒凉，无人经过。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 6:7; 以西结书 36:17–18; 以西结书 22:2–15"> 我因他们所做的一切可憎之事，使这地荒废、凄凉，那时他们就知道：我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="马太福音 22:16–17; 耶利米书 23:35; 以赛亚书 29:13"> “至于你，人子啊，你的同胞，就是那些在城墙边、在家门口谈论你的人，他们这人与那人彼此谈论说：‘来吧，我们听听来自耶和华的信息是什么。’</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 13:22; 诗篇 78:36–37; 雅各书 1:22–24"> 他们来到你这里，像是民众到来；坐在你面前，像是我的子民。然而他们听到你的话语，却不遵行。他们虽然用嘴巴说出爱情，心里却追随私利。</span>
<span className="v" id="v32" data-v="32" data-xref="马可福音 6:20; 马可福音 4:16–17; 约翰福音 5:35"> 看哪，他们看你像是一首情歌，声音优美，弹得巧妙，但他们听到你的话语，却不遵行。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 28:9; 撒母耳记上 3:19–20; 以西结书 2:5"> 看哪，你所说的必应验！当它应验时，他们就知道：曾有一位先知在他们中间。”</span>
</div>
</div>

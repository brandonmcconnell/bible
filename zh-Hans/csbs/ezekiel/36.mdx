<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 37:4; 以西结书 34:14; 以西结书 37:22"> “人子啊，你还要向以色列的群山发预言，说：以色列的群山哪，你们要听耶和华的话语！</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 32:13; 以西结书 25:3; 以西结书 35:10"> 主耶和华如此说：<br />“因为仇敌论到你们说‘啊哈！古老的高地成为我们的产业了’，</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 44:13–14; 耶利米哀歌 2:15–16; 耶利米书 18:16"> 所以你要发预言说，主耶和华如此说：正是因四围的仇敌使你们荒凉，践踏你们，使你们成为其余列国的产业，成为人们的笑谈和辱骂，</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 34:28; 申命记 11:11; 以西结书 36:6"> 因此以色列的群山哪，你们要听主耶和华的话语！论到大山、小山，溪谷、山谷，荒凉的废墟和被遗弃的城镇，就是被四围其余列国所掠夺、所嘲笑的，主耶和华如此说：</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="弥迦书 7:8; 以西结书 36:3; 诗篇 137:7"> “因此主耶和华如此说：我确实在妒火中发了话，责备其余的列国，以及整个以东！他们满心幸灾乐祸，心存恨恶，把我的土地归自己为产业，使那里的牧野成为掠物。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 123:3–4; 以西结书 34:29; 诗篇 74:23"> 因此你要向以色列地发预言，对大山、小山、溪谷、山谷说，主耶和华如此说：看哪，我在妒火和愤怒中发话！因为你们承受了列国的羞辱，</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 20:5; 阿摩司书 1:1–15; 以西结书 20:15"> 所以主耶和华如此说：我举手起誓，你们四围的列国也必承受羞辱！</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 27:6; 希伯来书 10:37; 以西结书 34:26–29"> “但你们，以色列的群山哪，你们却将发出枝条，为我的子民以色列结出果实，因为他们快要回来了。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 46:11; 何西阿书 2:21–23; 以西结书 36:34"> 看哪，我必帮助你们，眷顾你们，你们将被耕耘、被播种。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 36:33; 耶利米书 33:12; 以西结书 36:37"> 我要使以色列全家的人口在你们上面增多，使城镇有人居住，废墟得以重建。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 33:12; 耶利米书 23:5–8; 耶利米书 31:27"> 我要使人和牲畜在你们上面增多，他们必增多、繁衍。我要使你们像先前那样有人居住，并且比起初更蒙福。那时你们就知道：我是耶和华。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 15:7; 以西结书 36:13; 耶利米书 32:44"> 我要引领人，就是我的子民以色列，在你上面行走；他们将拥有你，你必成为他们的继业，你也绝不再使他们丧掉儿女。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 13:32"> “主耶和华如此说：因为他们对你说‘你是吞噬人的，你使你的国民丧掉儿女’，</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 37:25–28; 阿摩司书 9:15; 以赛亚书 60:21"> 因此你必不再吞噬人，不再使你的国民丧掉儿女。这是主耶和华的宣告。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 34:29; 诗篇 89:50; 以西结书 36:6"> 我不再使你听到列国的羞辱；你不会再承受外邦人的辱骂，也不会再使你的国民丧亡<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="丧亡——或译作“倒下”。">a</a></sup>。这是主耶和华的宣告。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 耶和华的话语又临到我，说：</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 2:7; 民数记 35:33–34; 弥迦书 2:10"> “人子啊，以色列家居住在自己的土地上时，以他们的所作所为玷污了那地，他们的行为在我眼前好像经期的不洁。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 34:21; 以西结书 7:8; 耶利米哀歌 2:4"> 所以，因他们在那地上杀人流血，以偶像玷污那地，我就把怒火倾泻在他们身上。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 39:24; 申命记 28:64; 以西结书 5:12"> 我把他们驱散到列国，扬散在各地；我照着他们的所作所为审判了他们。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 2:24; 以赛亚书 52:5; 耶利米书 33:24"> 他们到了所去的列国，就使我的圣名受到亵渎，因为人们论到他们说：‘这些人是耶和华的子民，却从他的土地被赶出去了！’</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 48:9; 诗篇 74:18; 以西结书 20:9"> 但我顾惜我的圣名，就是以色列家在所去的列国亵渎的名。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="诗篇 106:8; 以西结书 36:32; 诗篇 115:1–2"> “因此你要对以色列家说，主耶和华如此说：以色列家啊，我将要做的事不是为了你们，而是为了我的圣名，就是你们在所去的列国亵渎的名。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 20:41; 以赛亚书 5:16; 以西结书 39:7"> 我被亵渎的大名，就是在列国中被你们所亵渎的名，我必使它显为圣。当我藉着你们在他们眼前显为圣时，列国就知道：我是耶和华。这是主耶和华的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以西结书 37:21; 以西结书 34:13; 阿摩司书 9:14–15"> “我要从列国领你们出来，从各地招聚你们，把你们带回你们的土地。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 10:22; 约翰福音 3:5; 耶利米书 33:8"> 我要把洁净之水洒在你们身上，你们必得洁净。我要使你们脱离一切不洁，脱离你们的一切偶像，得以洁净。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 11:19–20; 诗篇 51:10; 哥林多后书 5:17"> 我要赐给你们一颗新的心，把一个新的灵放在你们里面。我要从你们肉体中除掉石心，赐给你们肉心。</span>
<span className="v" id="v27" data-v="27" data-xref="提多书 3:3–6; 希伯来书 13:21; 哥林多前书 3:16"> 我要把我的灵放在你们里面，使你们遵从我的律例，谨守遵行我的法规。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 31:33; 耶利米书 32:38; 以西结书 37:27"> 你们必住在我所赐给你们祖先的土地上，你们将要作我的子民，我将要作你们的神。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 1:7–9; 马太福音 1:21; 何西阿书 2:21–23"> 我要把你们从你们的一切不洁中拯救出来，并且传令五谷，使它们增多，使饥荒不再临到你们。</span>
<span className="v" id="v30" data-v="30" data-xref="以西结书 34:27; 约珥书 2:26; 申命记 29:23–28"> 我要使树木多结果实，田野增多出产，好让你们在列国中不再因饥荒而遭受羞辱。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="以西结书 6:9; 以西结书 20:43; 尼希米记 9:26–35"> “那时你们就会想起你们的恶行和不好的行为，并因你们的罪孽和可憎之事而厌恶自己。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 9:5; 以西结书 36:22; 提摩太后书 1:9"> 你们要知道，我这样行事不是为了你们。这是主耶和华的宣告。以色列家啊，你们要因自己的行为而抱愧羞惭！</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 58:12; 以西结书 36:10; 耶利米书 33:10"> “主耶和华如此说：在我使你们得洁净，脱离一切罪孽的日子里，我要使城镇有人居住，废墟得以重建。</span>
<span className="v" id="v34" data-v="34" data-xref="以西结书 6:14; 耶利米书 25:9–11; 历代志下 36:21"> 这荒芜之地将被耕耘，不再是所有过路人眼中的荒场。</span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 51:3; 约珥书 2:3; 耶利米书 33:9"> 他们会说：‘这荒芜之地现在就像伊甸园，这些荒废、荒凉、被拆毁的城现在坚固了，有人居住了！’</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 24:35; 民数记 23:19; 以西结书 17:24"> 那时你们四围残留的列邦就知道：是我耶和华重建了这些被拆毁的城，种植了这荒芜之地。我耶和华发了话，就必成就。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="约翰一书 5:14; 希伯来书 10:21–22; 以西结书 14:3"> “主耶和华如此说：我必再次接受以色列家求问，给他们成就这事：我要使他们人口增多，如同羊群。</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪上 8:63; 使徒行传 2:5–11; 约翰福音 10:16"> 荒废的城镇必充满了人群，就像耶路撒冷在各约期充满了被献为圣的羊群。那时他们就知道：我是耶和华。”</span>
</div>
</div>

<div className="bp poetry">

<span className="v" id="v2" data-v="2" data-xref="耶利米书 39:1; 耶利米书 52:4; 列王纪下 25:1"> “人子啊，你要记下今天这日子的名称，就是在这个日子，巴比伦王围攻耶路撒冷。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 11:3; 以西结书 17:2; 以西结书 20:49"> 你要向这悖逆之家设比喻，对他们说，主耶和华如此说：<br /><span className="pl pl-1">要放上一口锅，</span><br /><span className="pl pl-1">放好后，往里面倒进水。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="弥迦书 3:2–3; 以西结书 22:18–22; 马太福音 7:2"> <span className="pl pl-1">要把肉块，所有肥美的肉，</span><br /><span className="pl pl-1">大腿和肩部，都放进去；</span><br /><span className="pl pl-1">要装满上好的骨头；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 52:24–27; 耶利米书 52:10; 耶利米书 39:6"> <span className="pl pl-1">要取羊群中最好的。</span><br /><span className="pl pl-1">然后把木柴堆在锅底下，</span><br /><span className="pl pl-1">烧开锅，</span><br /><span className="pl pl-1">把肉连骨头都在里面煮透。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="以西结书 22:2; 那鸿书 3:1; 俄巴底亚书 1:11"> 是的，主耶和华如此说：<br /><span className="pl pl-1">有祸了，这杀人流血的城，</span><br /><span className="pl pl-1">里面生锈的锅！</span><br /><span className="pl pl-1">它的锈还没有从其中除掉。</span><br /><span className="pl pl-1">要把肉一块一块都取出来，</span><br /><span className="pl pl-1">不必抽签挑选。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="利未记 17:13; 申命记 12:16; 约伯记 16:18"> <span className="pl pl-1">杀人流的血还在城中，</span><br /><span className="pl pl-1">留在光秃秃的岩石上，</span><br /><span className="pl pl-1">而不是倒在地上，</span><br /><span className="pl pl-1">用尘土掩盖起来。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="申命记 32:21–22; 启示录 18:5–10; 以西结书 22:30–31"> <span className="pl pl-1">其实，我任凭血</span><br /><span className="pl pl-1">留在光秃秃的岩石上不被掩盖，</span><br /><span className="pl pl-1">是为了激起我的怒火，施行报复。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="以西结书 24:6; 哈巴谷书 2:12; 以赛亚书 31:9"> 因此主耶和华如此说：<br /><span className="pl pl-1">有祸了，这杀人流血的城！</span><br /><span className="pl pl-1">我还要加大柴堆。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米哀歌 2:16; 耶利米书 17:3; 耶利米哀歌 1:10"> <span className="pl pl-1">你要增添木柴，点燃火，</span><br /><span className="pl pl-1">把肉煮烂，</span><br /><span className="pl pl-1">调入香料，</span><br /><span className="pl pl-1">把骨头烤焦。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 21:10; 玛拉基书 4:1; 以赛亚书 1:25"> <span className="pl pl-1">然后把倒空的锅放在炭火上，</span><br /><span className="pl pl-1">好把它烧热，</span><br /><span className="pl pl-1">把它的铜烧红，</span><br /><span className="pl pl-1">使它的污秽在其中熔化，</span><br /><span className="pl pl-1">除尽它的锈。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 9:5; 耶利米书 2:13; 耶利米书 5:3"> <span className="pl pl-1">虽劳碌疲倦，</span><br /><span className="pl pl-1">它厚厚的锈也无法从其中除掉，</span><br /><span className="pl pl-1">它的锈必须用火炙烤</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="它的锈必须用火炙烤——或译作“即使用火炙烤它的锈”。">b</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 22:24; 以西结书 5:13; 西番雅书 3:2"> <span className="pl pl-1">你实在污秽丑恶！</span><br /><span className="pl pl-1">因为我洁净你，</span><br /><span className="pl pl-1">你却不肯脱离污秽得洁净，</span><br /><span className="pl pl-1">所以在我对你的怒火平息之前，</span><br /><span className="pl pl-1">你再也不会得洁净！</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 16:27; 以西结书 18:30; 以赛亚书 3:11"> <span className="pl pl-1">我耶和华已经发了话；</span><br /><span className="pl pl-1">这事必临到，我必成就。</span><br /><span className="pl pl-1">我绝不放手，不顾惜，不后悔。</span><br /><span className="pl pl-1">我要照着你的所作所为审判你。</span><br /><span className="pl pl-1">这是主耶和华的宣告。”</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 耶和华的话语又临到我，说：</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 22:10; 耶利米书 13:17; 雅歌 7:10"> “人子啊，看哪，我即将击打你眼中的宝贝，把她从你身边取走，但你不可哀悼，不可哭泣，不可流泪。</span>
<span className="v" id="v17" data-v="17" data-xref="何西阿书 9:4; 撒母耳记下 15:30; 利未记 10:6"> 只可静默叹息，不可办丧事；要戴好头巾，脚上穿鞋；不可蒙着嘴，不可吃吊丧之人的食物。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 7:29–30"> 于是，清晨我向民众说了这事，傍晚我的妻子就死了。第二天早晨，我照着所受的指示去做，</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 12:9; 以西结书 37:18; 玛拉基书 3:7–8"> 民众问我：“你做的这些事与我们有什么关系，你不告诉我们吗？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 我回答他们：“耶和华的话语临到我，说：</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 23:47; 以西结书 23:25; 诗篇 27:4"> 你要告诉以色列家，主耶和华如此说：‘看哪，我即将亵渎我的圣所，就是你们所夸耀的势力，你们眼中的宝贝、心里所珍爱的；你们所留下的儿女必倒在刀下。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 78:64; 耶利米书 16:4–7; 以西结书 24:16–17"> 那时你们必照着以西结<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="以西结——原文作“我”。">c</a></sup>所做的去做：不蒙着嘴，不吃吊丧之人的食物，</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 33:10; 以西结书 4:17; 利未记 26:39"> 戴好头巾，脚上穿鞋；不哀悼，不哭泣，反而在自己的罪孽中衰弱，彼此哀叹。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 4:3; 以赛亚书 20:3; 路加福音 11:29–30"> 以西结是你们的预表，当这事临到的时候，你们必照着他所做的一切去做。那时你们就知道：我是主耶和华。’</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以西结书 24:21; 诗篇 48:2; 耶利米书 11:22"> “人子啊，那日我必除掉他们的保障，就是他们所夸耀、所喜悦的，除掉他们眼中的宝贝、心里所看重的儿女。</span>
<span className="v" id="v26" data-v="26" data-xref="约伯记 1:15–19; 以西结书 33:21–22; 撒母耳记上 4:12–18"> 那日，逃脱的人难道不会来到你这里，使你听见消息吗？</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 33:22; 以西结书 29:21; 路加福音 21:15"> 那日，你要向逃脱的人开口，你要说话，不再默然无声。这样，你成为他们的预表，他们就知道：我是耶和华。”</span>
</div>

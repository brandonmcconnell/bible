<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 3:16; 以西结书 11:24; 使徒行传 7:56"> 第三十年<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="第三十年——或译作“我三十岁那一年”。">a</a></sup>四月五日，我在迦巴鲁河边的掳民当中，那时诸天打开了，我看见神的异象。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 24:12–15; 以西结书 8:1; 以西结书 20:1"> 这是在约雅斤王被掳后第五年的四月五日，</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 3:14; 以西结书 3:22; 列王纪下 3:15"> 在迦勒底人之地迦巴鲁河边，耶和华的话语特别临到布西的儿子祭司以西结，耶和华的手在那里临到了他身上。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以西结书 1:27; 以西结书 8:2; 耶利米书 23:19"> 我观看，看哪，暴风从北方吹来，有一朵巨大的云，火光熠熠，四围环绕着光辉，中央的烈火内如同闪耀的琥珀。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 4:6–8; 以西结书 1:26; 启示录 6:6"> 火的中央有四个活物的形象，它们的外观是这样：都有人的样貌，</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 10:14; 启示录 4:7–8; 以西结书 1:15"> 但每一个活物都有四张脸，都有四个翅膀。</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 1:15; 但以理书 10:6; 诗篇 104:4"> 它们的腿是直的，脚掌像牛犊的蹄子；它们闪亮如抛光闪耀的铜。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 10:21; 以西结书 10:11; 以赛亚书 6:6"> 在它们四面的翅膀底下，都有人的手。至于这四个活物的脸和翅膀：</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 10:22; 以西结书 10:11; 以西结书 1:11–12"> 它们的翅膀彼此相接，行走时并不转身，各都直往前行。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 10:14; 启示录 4:7; 哥林多前书 9:9–10"> 它们脸的样貌，都有一张人的脸，四个活物的右边都有一张狮子的脸，左边都有一张公牛的脸，也都有一张老鹰的脸，</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 6:2; 以西结书 1:23; 以西结书 10:19"> 这是它们的脸。它们的翅膀，各有两个向上张开，彼此相接，另外两个遮蔽自己的身体。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 1:9; 以西结书 10:22; 希伯来书 1:14"> 它们各都直往前行，灵往哪里去，它们就往哪里去，行走时并不转身。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="启示录 4:5; 诗篇 104:4; 马太福音 28:3"> 这四个活物的形象和外观，像燃烧的火炭，又像火把。烈火在活物之间穿行，火光明亮，有闪电从烈火中发出。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 24:27; 撒迦利亚书 4:10; 马可福音 13:27"> 活物往返飞奔，快如闪电。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理书 7:9; 以西结书 10:9; 以西结书 1:19–21"> 我观看这些活物，看哪，这些有四张脸的活物旁边，各有一个轮子在地上。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理书 10:6; 以西结书 10:9–11; 出埃及记 39:13"> 至于轮子的形状和构造，它们如同闪耀的黄水晶，四个轮子是同一个样式，形状和构造像是轮中套轮。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 1:9; 以西结书 1:12; 以赛亚书 55:11"> 轮子移动时，四个方向都可前行，移动时并不转向。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 10:12; 启示录 4:6; 启示录 4:8"> 轮圈高大可畏，四个轮圈周身布满了眼睛。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 10:16; 以西结书 10:19; 诗篇 103:20"> 活物前行时，轮子也在它们旁边前行；活物离地上升时，轮子也上升。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 1:12; 以西结书 10:17; 哥林多前书 14:32"> 灵往哪里去，活物就往灵要去的地方前行；轮子在活物旁边一起上升，因为活物的灵在轮子里。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 10:17; 以西结书 1:19–20; 罗马书 8:2"> 活物行走时，轮子也行走；活物站住时，轮子也站住；活物离地上升时，轮子也在它们旁边上升，因为活物的灵在轮子里。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以西结书 10:1; 以西结书 1:26; 启示录 4:6"> 在活物的头顶上方有穹苍的景象，如同闪耀可畏的冰晶，高高地在它们头顶上方展开着。</span>
<span className="v" id="v23" data-v="23" data-xref="约伯记 4:18; 以西结书 1:11–12; 诗篇 89:7"> 在穹苍之下，活物的翅膀伸直，彼此相接；它们各用两个翅膀遮蔽<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="各用两个翅膀遮蔽——此句在马索拉文本里有重复。">b</a></sup>自己的身体。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 43:2; 但以理书 10:6; 启示录 1:15"> 它们行走时，我听见它们翅膀的声音，如同大水的声音，如同全能者的声音；有轰隆的声音，如同军队的声音。它们站住时，就垂下它们的翅膀。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以西结书 1:22"> 当它们站住垂下翅膀时<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="当它们站住垂下翅膀时——此句在马索拉文本里处于节尾，重复了前一节末尾。">c</a></sup>，有声音从它们头顶上方的穹苍之上传来。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 10:1; 出埃及记 24:10; 启示录 1:13"> 活物的头顶上方的穹苍之上，有宝座的形象，好像蓝宝石的外观。在宝座的形象之上，还有一个形象，好像人的样貌，高高坐在上面。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 1:4; 以西结书 8:2; 希伯来书 12:29"> 我看见从他腰部往上，好像闪耀的琥珀，四围仿佛环绕着烈火的景象。我又看见从他腰部往下，仿佛烈火的景象，四围环绕着光辉。</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 10:1; 启示录 4:3; 创世记 17:3"> 下雨的日子里云中彩虹是什么景象，他四围的光辉也是什么景象，这是耶和华荣耀形象的样子。我一看见，就脸伏于地，然后听见了说话的声音。</span>
</div>
</div>

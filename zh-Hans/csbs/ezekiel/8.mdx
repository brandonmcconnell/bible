<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 20:1; 以西结书 1:2–3; 以西结书 14:1"> 第六年<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="第六年——指约雅斤王被掳之后的第六年；参《以西结书》1:2。">a</a></sup>的六月五日，我坐在家里，犹大的长老们坐在我面前。在那里，主耶和华的手落在我身上。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 1:4; 以西结书 1:26–27; 但以理书 7:9–10"> 我观看，看哪，有一个形象，好像人的样貌<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="人的样貌——依据七十士译本；马索拉文本作“烈火的景象”。">b</a></sup>，从他腰部往下是烈火的景象，从他腰部往上如同光辉的景象，如同闪耀的琥珀，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 32:16; 以西结书 11:1; 以西结书 5:11"> 有一只手的形态伸出来，抓住我一绺头发。然后灵把我举到天地之间，在神的异象中把我带到耶路撒冷，到了朝北的内院门口，那里摆着惹动神妒火的偶像。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 3:22–23; 出埃及记 40:34–35; 以西结书 11:22–23"> 看哪，以色列神的荣耀在那里显现，正如我在平原看见的异象。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以西结书 8:3; 耶利米书 3:2; 耶利米书 32:34"> 神对我说：“人子啊，你要举目向北观看。”我就举目向北，看哪，祭坛门的北边，在门口有那惹动神妒火的偶像。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 5:11; 以西结书 10:19; 以西结书 8:9"> 他又对我说：“人子啊，他们做的事你看见了吗？以色列家在这里做那些极其可憎的事，以致我远离我的圣所。你还会看见更大的可憎之事！”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王纪下 21:5; 列王纪上 7:12"> 然后他把我带到外院门口，我观看，看哪，墙上有一个洞。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 29:15; 约伯记 34:22; 阿摩司书 9:2–3"> 他对我说：“人子啊，你要挖这面墙！”我就挖墙，看哪，有一道门。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 20:8"> 他说：“你进去，看看他们在这里所做的邪恶可憎之事。”</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 1:23; 出埃及记 20:4; 耶利米书 16:18"> 我就进去观看，看哪，在四围的墙上都雕刻着各种可憎的爬虫和走兽的形态，以及以色列家各样的偶像。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民数记 16:17; 民数记 16:35; 民数记 11:16"> 以色列家的长老有七十个人在偶像面前站立，沙番的儿子雅撒尼亚也站在他们中间；他们各人手拿自己的香炉，香料的烟云不断上腾。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 29:15; 以西结书 9:9; 以西结书 8:15"> 他对我说：“人子啊，以色列家的长老们各自在黑暗中，在他安放雕像的内室所做的事，你看见了吗？他们竟然说：‘耶和华不会查看我们，耶和华已经离弃了这地。’”</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 8:6; 耶利米书 9:3; 以西结书 8:15"> 他又对我说：“你还会看见他们所做更大的可憎之事。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西结书 46:9; 以西结书 44:4"> 然后他把我带到耶和华殿朝北的门口，看哪，妇女们坐在那里为塔穆兹哭泣。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 8:12–13; 以西结书 8:9; 以西结书 8:6"> 他对我说：“人子啊，你看见了吗？你还会看见比这些更大的可憎之事。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命记 4:19; 申命记 17:3; 耶利米书 32:33"> 然后他把我带到耶和华殿的内院，看哪，在耶和华的圣殿门口，就是在门廊和祭坛之间，大约有二十五个人背对着耶和华的圣殿，面向东方，朝东向太阳下拜。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 9:9; 以西结书 7:23; 耶利米书 6:7"> 他对我说：“人子啊，你看见了吗？犹大家在这里所做的可憎之事，能算为小事吗？他们实在使这地遍满了恶行，一再惹怒我。看哪，他们把葡萄枝伸向自己的鼻子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="他们把葡萄枝伸向自己的鼻子——七十士译本作“他们像嘲笑者”。">c</a></sup>！</span>
<span className="v" id="v18" data-v="18" data-xref="弥迦书 3:4; 耶利米书 11:11; 以赛亚书 1:15"> 因此，我必在怒火中行事，我眼中不会顾惜，绝不怜恤。他们向我耳中大声呼求，我也不会垂听他们！”</span>
</div>
</div>

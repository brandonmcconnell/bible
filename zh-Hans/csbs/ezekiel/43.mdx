<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 44:1; 以西结书 42:15; 以西结书 46:1"> 他又带我到一座门，就是朝东的门那里。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 18:1; 以西结书 11:23; 以赛亚书 6:3"> 看哪，以色列神的荣耀从东而来，他的声音如同大水的声音，全地因他的荣耀而发光。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 9:5; 以西结书 9:1; 耶利米书 1:10"> 我所看见的这异象，景象如同从前他<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他——依据有些古抄本；马索拉文本作“我”。">a</a></sup>来毁灭这城时我所看见的异象，又如同我在迦巴鲁河边所看见的异象；我就脸伏于地。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 10:18–19; 以西结书 44:2; 以西结书 43:2"> 耶和华的荣耀从面朝东的门进入圣殿。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 12:2–4; 列王纪上 8:10–11; 以西结书 8:3"> 随后，灵把我举起，带到内院，看哪，耶和华的荣耀充满了圣殿。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结书 40:3; 以赛亚书 66:6; 启示录 16:1"> 那人站在我旁边，我听见殿宇中有声音对我说话。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 43:9; 诗篇 47:8; 利未记 26:30"> 那声音对我说：“人子啊，这是我宝座设立之处，脚凳所在之地。我要居住在这里，在以色列子民中间，直到永远。以色列家和他们的君王，再不会以淫行和他们君王的死尸<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="死尸——或译作“高坛上的石碑”。">b</a></sup>来玷污我的圣名。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 5:11; 以西结书 8:3–16; 历代志下 33:7"> 他们曾把自己的门槛与我的门槛放在一起，把自己的门柱立在我的门柱旁边，他们和我之间只隔一道墙，他们以所做的可憎之事玷污了我的圣名，所以我在怒气中消灭他们。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 43:7; 以西结书 37:26–28; 以西结书 18:30–31"> 现在，但愿他们从我面前彻底清除他们的淫行和他们君王的尸体，我就居住在他们中间，直到永远。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西结书 40:4; 以西结书 16:61; 以西结书 16:63"> “人子啊，你要把这圣殿指示给以色列家，使他们因自己的罪孽而愧疚，让他们思量圣殿的完美<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="思量圣殿的完美——或译作“测量圣殿的尺寸”。">c</a></sup>。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 36:27; 以西结书 11:20; 马太福音 28:20"> 如果他们因自己所做的一切而愧疚，你就把这圣殿的形制，包括构造、出入口等所有的形制，把它所有的规范、所有的形制，以及所有相关的法规，都指示给他们，并在他们眼前记下来，使他们遵照所有的形制和规范去做。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 40:2; 启示录 21:27; 诗篇 93:5"> 这圣殿的法规是这样的：它要在山顶上，四围地界内全都是至圣的。看哪，这就是圣殿的法规。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西结书 40:5; 出埃及记 27:1–8; 以西结书 41:8"> “以下是祭坛的尺寸，以肘为标准，这肘是通用的肘加一掌<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="通用的肘加一掌——相当于53公分。1肘=45.7公分；1掌=7.4公分。">d</a></sup>：沟槽深一肘<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一肘——相当于53公分；下同。">e</a></sup>，宽一肘，四围起边高一拃<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一拃——约20公分；表示张开大拇指和中指或小指两端的距离。">f</a></sup>。祭坛的坛身如下：</span>
<span className="v" id="v14" data-v="14"> 从地面的沟槽到底层的磴台高两肘<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="两肘——相当于106公分。">g</a></sup>，宽一肘。从小磴台到大磴台高四肘<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="四肘——相当于2.1公尺；下同。">h</a></sup>，宽一肘。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 27:2; 诗篇 118:27; 利未记 9:9"> 祭坛的炉台高四肘，从炉台向上有四个犄角。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 27:1; 历代志下 4:1; 出埃及记 38:1–2"> 炉台长十二肘<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="十二肘——相当于6.4公尺；下同。">i</a></sup>，宽十二肘，是四方形的。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 20:26; 以西结书 40:6; 出埃及记 25:25"> 磴台长十四肘<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="十四肘——相当于7.4公尺；下同。">j</a></sup>，宽十四肘，是四方形的。四围的起边有半肘，四围的沟槽深一肘。台阶朝东。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 40:29; 希伯来书 10:4–12; 以西结书 2:1"> 那声音又对我说：“人子啊，主耶和华如此说：以下是祭坛造好那天，在其上献燔祭、洒血的律例。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 40:46; 以西结书 44:15; 民数记 16:40"> 你要把一头公牛作为赎罪祭交给利未祭司，就是那些近前来事奉我的撒督后裔。这是主耶和华的宣告。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 16:19; 利未记 8:15; 出埃及记 29:12"> 你要取一些公牛的血，抹在祭坛的四个犄角、磴台的四角和四围的边上。这样，你就洁净了它，为它行了赎罪礼。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 29:14; 利未记 4:12; 利未记 8:17"> 你要取来那赎罪祭公牛，在圣所外面为圣殿指定的地方烧掉。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以西结书 43:25–26; 以西结书 43:20; 彼得前书 1:19"> “第二天，你要献上一只无瑕疵的公山羊作赎罪祭。他们要洁净祭坛，就像用公牛洁净祭坛一样。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 29:1"> 当你洁净完了祭坛，要献上一头无瑕疵的公牛和羊群中一只无瑕疵的公绵羊，</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 2:13; 马可福音 9:49–50; 民数记 18:19"> 献在耶和华面前。祭司们要在其上撒盐，把它们献给耶和华为燔祭。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 8:33; 出埃及记 29:35–37; 利未记 8:35"> 一连七天，每天都要这样准备一只公山羊为赎罪祭，也要准备一头公牛和羊群中一只公绵羊，都是无瑕疵的。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 29:24; 利未记 8:34; 出埃及记 32:29"> 一连七天，他们要为祭坛行赎罪礼，洁净它，使它能承接圣职。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 9:1; 以西结书 20:40–41; 彼得前书 2:5"> 这些日子结束后，从第八天起，祭司们就可以在这祭坛上献你们的燔祭和平安祭，我必悦纳你们。这是主耶和华的宣告。”</span>
</div>
</div>

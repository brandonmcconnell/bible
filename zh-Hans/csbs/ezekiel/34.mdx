<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="EZK" data-book-slug="ezekiel" data-book-name="以西结书" data-chapter="34" data-verses="31">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话语临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 23:1; 耶利米书 3:15; 以赛亚书 40:11"> “人子啊，你要针对以色列的牧人说神言。你要说神言告诉他们，主耶和华对牧人们如此说：有祸了，那些只牧养自己的以色列牧人！牧人难道不是要牧养羊群吗？</span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亚书 11:16; 耶利米书 2:30; 以西结书 33:25–26"> 你们吃脂油，穿羊毛，宰杀肥壮的羊，却不牧养羊群。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 18:12–13; 马太福音 9:36; 以西结书 34:16"> 衰弱的，你们不扶助；患病的，你们不医治；受伤的，你们不包扎；走散的，你们不领回；失丧的，你们不寻找；你们只是粗暴、严酷地辖制他们。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 9:36; 历代志下 18:16; 耶利米书 23:2"> 羊群因为没有牧人就四散，成了田野各样走兽的食物。他们四散了！</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 142:4; 彼得前书 2:25; 约翰福音 10:16"> 我的羊群迷失在各山岭、各高丘，我的羊群四散在整个地面上，无人寻找，无人顾念。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="耶利米书 22:2–3; 弥迦书 3:8–9; 诗篇 82:1–7"> “因此牧人们哪，你们要听耶和华的话语，</span>
<span className="v" id="v8" data-v="8" data-xref="彼得后书 2:13; 使徒行传 20:33; 以西结书 34:5–6"> 这是主耶和华的宣告：我指着我的永生起誓，我的羊群竟然成了掠物！我的羊群因没有牧人而成为田野各样走兽的食物，我的牧人们却不寻找我的羊群，那些牧人只牧养自己，而不牧养我的羊群。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> “因此牧人们哪，你们要听耶和华的话语，</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 34:2; 撒迦利亚书 10:3; 以西结书 13:8"> 主耶和华如此说：看哪，我与那些牧人敌对！我必从他们手中要回我的羊群，不让他们牧养羊群，那些牧人也不能再牧养自己。我要把我的羊群从他们口中解救出来，不再作他们的食物。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约翰福音 10:16; 路加福音 19:10; 耶利米书 23:3"> “是的，主耶和华如此说：看哪，我要亲自寻找我的羊群，顾念<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="顾念——或译作“找回”；下节同。">a</a></sup>他们。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 40:11; 约翰福音 10:11–12; 路加福音 19:10"> 牧人在他身边的羊群四散的日子里，怎样顾念他的羊，我也照样顾念我的羊群。我要从各个地方，就是他们在密云和幽暗的日子里被驱散到的地方，解救他们。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 28:25–26; 以西结书 11:17; 以赛亚书 11:11–16"> 我要从万民中领他们出来，从各地招聚他们，把他们带回自己的土地。我要在以色列的群山上、溪谷中，在那地一切居住的地方牧养他们。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 10:9; 耶利米书 31:25; 诗篇 31:8–10"> 我要在佳美的草场上牧养他们，他们吃草的牧场在以色列的高山上。他们必躺卧在佳美的牧场，在以色列群山上享用肥美的草场。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 3:15; 诗篇 23:1–2; 约翰福音 21:15"> 我要亲自牧养我的羊群，使他们安然躺卧。这是主耶和华的宣告。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:10; 以西结书 34:4; 以西结书 34:11"> 失丧的，我要寻找；走散的，我要领回；受伤的，我要包扎；患病的，我要扶助；肥的壮的，我却要除灭。我要以公正牧养他们。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西结书 34:20–22; 马太福音 25:32–33; 撒迦利亚书 10:3"> “至于你们，我的羊群哪，主耶和华如此说：看哪，我必在羊与羊之间、公绵羊与公山羊之间施行审判。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 23:13; 路加福音 11:52; 民数记 16:13"> 你们享用佳美的草场，还不够吗？你们又用蹄子践踏剩下的草场。你们喝了清澈的水，又用蹄子蹚浑剩下的水。</span>
<span className="v" id="v19" data-v="19"> 我的羊只能吃你们蹄子所践踏的，喝你们蹄子所蹚浑的！</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马太福音 25:31–46; 以西结书 34:10; 诗篇 22:12–16"> “因此主耶和华对他们如此说：看哪，我必亲自在肥羊和瘦羊之间施行审判。</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亚书 11:5; 申命记 33:17; 路加福音 13:14–16"> 因为你们用胯和肩膀推挤、用犄角冲撞所有衰弱的，直到把他们驱散到外面，</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 23:2–3; 诗篇 72:12–14; 以西结书 34:10"> 所以我要拯救我的羊，使他们不再成为掠物；我要在羊与羊之间施行审判。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 37:24–25; 耶利米书 30:9; 以赛亚书 40:11"> 我要兴起一个牧人照管我的羊，牧养他们，他是我的仆人大卫。他将亲自牧养他们，作他们的牧人。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 31:33; 以西结书 36:28; 耶利米书 23:5–6"> 我耶和华要作他们的神，我的仆人大卫将在他们中间作君王。我耶和华已经发了话。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 11:6–9; 以西结书 37:26; 利未记 26:6"> “我要与他们立平安的约，使恶兽从这地断绝；他们在旷野中也能安然居住，在森林中也能安睡。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 28:12; 以赛亚书 44:3; 利未记 26:4"> 我要使他们以及我山岗的四围祝福满满，我必按时降下雨水，是祝福的甘霖。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 30:8; 利未记 26:4; 利未记 26:13"> 田野的树木必结出果实，这地必有出产，他们必安居在自己的土地上。我必打断他们身上的轭套，从奴役他们的人手中解救他们，那时他们就知道：我是耶和华。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 46:27; 耶利米书 30:10; 以西结书 39:26"> 他们不再成为列国的掠物，地上的野兽不再吞噬他们；他们必安然居住，无人惊吓。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 36:29; 以赛亚书 4:2; 以西结书 34:26–27"> 我要为他们建立一个著名的栽种之地，他们在这地不会再被饥荒除灭，不再受列国羞辱。</span>
<span className="v" id="v30" data-v="30" data-xref="以西结书 37:27; 以西结书 34:24; 诗篇 46:11"> 那时他们就知道：我是耶和华他们的神，与他们同在，他们以色列家是我的子民。这是主耶和华的宣告。</span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 100:3; 约翰福音 10:16; 诗篇 78:52"> 你们是我的羊，我牧场的羊群；你们是子民<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="子民——原文直译“人”。">b</a></sup>，我是你们的神。这是主耶和华的宣告。”</span>
</div>
</div>

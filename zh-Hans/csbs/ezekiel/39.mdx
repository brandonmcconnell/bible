<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 38:2–3; 以西结书 35:3; 那鸿书 3:5"> “人子啊，你要针对歌革发预言说，主耶和华如此说：米设和图巴的为首领袖<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="米设和图巴的为首领袖——或译作“米设、图巴和罗施的领袖”。">a</a></sup>歌革啊，看哪，我与你敌对！</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 40:14; 以西结书 38:15; 以赛亚书 37:29"> 我要把你调转过来，牵引你，把你从极远的北方带上来，带到以色列的群山上。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 76:3; 何西阿书 1:5; 耶利米书 21:4–5"> 我要击落你左手的弓，打落你右手的箭。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 39:17–20; 以西结书 33:27; 以西结书 38:21"> 你和你的全军，以及跟着你的各民族，都将倒在以色列的群山上。我要把你交给猛禽、各类飞鸟和田野的走兽，作为食物。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 22:19; 以西结书 32:4; 耶利米书 8:2"> 你必倒在田野上，是的，我已经发了话。这是主耶和华的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结书 30:16; 阿摩司书 1:4; 以西结书 30:8"> “我要降火在玛格，以及那些安居众海岛的人身上。那时他们就知道：我是耶和华。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 38:16; 以西结书 38:23; 出埃及记 20:7"> 我要在我子民以色列中间彰显我的圣名，不让我的圣名再被亵渎。那时列国就知道：我是耶和华，是以色列中的至圣者。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 38:17; 启示录 16:17; 以西结书 7:2–10"> 看哪，这事临近了，必定成就。这就是我所说的日子。这是主耶和华的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="诗篇 46:9; 以赛亚书 66:24; 玛拉基书 1:5"> “以色列各城的居民将出去，点火焚烧兵器，就是大小盾牌，以及弓箭、棍棒和长矛，用它们烧火七年之久。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 33:1; 以赛亚书 14:2; 弥迦书 5:8"> 他们不必从田野捡木柴，也不必从树林中伐木，因为他们将用兵器来烧火。他们将掳掠那些掳掠他们的，掠夺那些掠夺他们的。这是主耶和华的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以西结书 47:18; 民数记 34:11; 以西结书 38:2"> “到那日，我要在以色列给歌革预备一块墓地，就是盐海东边路人经过的山谷，它会挡住过路的人。人们将在那里埋葬歌革和他的全军，称那地为‘哈门-歌革谷’。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 21:23; 以西结书 39:14; 以西结书 39:16"> 以色列家将用七个月埋葬他们，好洁净那地；</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 28:22; 西番雅书 3:19–20; 耶利米书 33:9"> 那地所有的民众都要来埋葬他们。在我得荣耀的日子，这事必使以色列人得名声。这是主耶和华的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西结书 39:12; 民数记 19:11–19"> “他们将分派人时常巡行那地，埋葬地面上残留的入侵者的尸体，好洁净那地。过了七个月，他们还要探查。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 11:44"> 巡行的人经过那地，看见人的骸骨，就会在旁边立一个标记，等埋葬的人把它埋葬在‘哈门-歌革谷’，</span>
<span className="v" id="v16" data-v="16"> 所以那里的城也名叫哈莫纳。这样他们就洁净了那地。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="西番雅书 1:7; 启示录 19:17–18; 以赛亚书 34:6"> “人子啊，主耶和华如此说：你要对一切飞鸟和田野的一切走兽说：‘你们聚集而来吧！我在以色列群山上为你们祭献了盛大的祭筵，你们从四围聚来赴我的祭筵，吃肉喝血吧！</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 22:12; 耶利米书 51:40; 启示录 19:17–18"> 你们将吃勇士们的肉，喝那地领袖们的血，他们都是公绵羊、羊羔、公山羊、公牛，是巴珊的肥畜。</span>
<span className="v" id="v19" data-v="19"> 你们将从我为你们祭献的祭筵上饱餐脂油，醉饮鲜血。</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 19:18; 哈该书 2:22; 诗篇 76:5–6"> 你们将在我的筵席上饱餐马匹、战车兵、勇士和所有的战士。这是主耶和华的宣告。’</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西结书 38:16; 以西结书 38:23; 以赛亚书 37:20"> “我必在列国中彰显荣耀，万国都将看见我所施行的审判和我刑罚<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="刑罚——原文直译“施加于”。">b</a></sup>他们的手。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 24:7; 以西结书 28:26; 以西结书 39:28"> 从那天起，以色列家就知道：我是耶和华他们的神。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 22:8–9; 以赛亚书 1:15; 以赛亚书 59:2"> 列国也会知道，以色列家被掳走是因他们的罪孽。他们对我不忠，因此我向他们隐藏我的脸，把他们交在敌人手中，使他们全都倒在刀下。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 36:19; 耶利米书 2:17; 耶利米书 4:18"> 我照着他们的污秽和过犯处治他们，向他们隐藏了我的脸。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以西结书 34:13; 以赛亚书 27:12–13; 何西阿书 1:11"> “因此主耶和华如此说：现在我要使雅各的掳民回归<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="使雅各的掳民回归——或译作“复兴雅各的家业”。">c</a></sup>，我要怜悯以色列全家，为我的圣名发热心。</span>
<span className="v" id="v26" data-v="26" data-xref="弥迦书 4:4; 列王纪上 4:25; 以西结书 16:63"> 他们必在自己的土地上安然居住，无人惊吓；那时，他们已承受了自己的羞辱，承担了所有对我不忠的罪责。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 38:16; 以西结书 38:23; 以西结书 36:23–24"> 当我把他们从各民族中带回来，从他们仇敌之地招聚回来时，我就藉着他们在许多国家眼前显为圣了。</span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 39:22; 阿摩司书 9:9; 以赛亚书 27:12"> 那时他们就知道：我是耶和华他们的神；因为我使他们被掳到了外邦，又把他们招聚到他们的土地上，一个也不留在外邦。</span>
<span className="v" id="v29" data-v="29" data-xref="约珥书 2:28; 约翰一书 3:24; 以赛亚书 32:15"> 那时，我不再向他们隐藏我的脸，因我已经把我的灵倾注在以色列家身上。这是主耶和华的宣告。”</span>
</div>

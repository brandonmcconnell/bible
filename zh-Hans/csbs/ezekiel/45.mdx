<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 48:29; 撒迦利亚书 14:20–21; 民数记 34:13"> “你们为继业抽签分地时，要向耶和华献上一份供地，作为那地中的圣地；要长两万五千肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="两万五千肘——相当于13公里；下同。">a</a></sup>，宽一万肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一万肘——相当于5.3公里；下同。">b</a></sup>；它四围地界内都是神圣的。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 42:16–20; 以西结书 27:28"> 其中一部分用于建圣所，长五百肘<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="五百肘——相当于265公尺；下同。">c</a></sup>，宽五百肘，是四方形的，四周要有五十肘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="五十肘——相当于26.5公尺。">d</a></sup>的外围空地。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 48:10"> 你要按这个尺寸测量，长两万五千肘，宽一万肘，其中有圣所，是至圣的。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 43:19; 民数记 16:5; 以西结书 40:45"> 它是这地中的圣地，归属那些在圣所事奉的祭司，就是近前来事奉耶和华的人；这要作他们的房屋用地和圣所的圣地。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 48:13; 尼希米记 10:38–39; 以西结书 48:20"> 还要献上一份，长两万五千肘，宽一万肘，归属那些在圣殿事奉的利未人，作为他们的居住区<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="居住区——依据七十士译本；马索拉经文为“二十个房间的地业”。">e</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结书 48:15–18; 以西结书 48:30–35"> “你们还要给这城一份地业，宽五千肘<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="五千肘——相当于2.6公里。">f</a></sup>，长两万五千肘，靠近圣供地，归属以色列全家。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 48:21; 以西结书 34:24; 以西结书 46:16–18"> 至于归属君王的地业，是在圣供地和这城地业的两边，面向圣供地和这城的地业，从西边往西延伸，从东边往东延伸；它从西边界到东边界的跨度，与每支派的地界平行。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 11:3–5; 以西结书 46:18; 以西结书 22:27"> 这是以色列中归属君王为地业的土地；我所立的君王们绝不再欺压我的子民，而是会把土地按支派分给以色列家。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒迦利亚书 8:16; 耶利米书 22:3; 以西结书 44:6"> “主耶和华如此说：以色列的君王们哪，你们够了吧！你们要除去恶行和迫害，施行公正和公义，终止对我子民的剥夺。这是主耶和华的宣告。</span>
<span className="v" id="v10" data-v="10" data-xref="弥迦书 6:10–11; 阿摩司书 8:4–6; 箴言 16:11"> 你们要用公正的天平、公正的量斗<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="量斗——原文直译“伊法”；一伊法相等于22公升，计量谷物的量器。">g</a></sup>、公正的量筒<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="量筒——原文直译“罢特”；一罢特相当于22公升，计量液体的量器。">h</a></sup>。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 5:10"> 伊法要与罢特标准一样：一罢特量筒可容十分之一贺梅珥，一伊法量斗也可容十分之一贺梅珥，度量单位都以贺梅珥<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="贺梅珥——相当于220公升；本章下同。">i</a></sup>为准。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 30:13; 民数记 3:47; 利未记 27:25"> 一谢克尔是二十季拉<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="二十季拉——相当于11.4公克。1季拉=0.57公克。">j</a></sup>；二十谢克尔、二十五谢克尔又十五谢克尔，是你们的一弥纳<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="一弥纳——相当于684公克；对比《列王纪上》10:17。1弥纳=60谢克尔。">k</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> “以下是你们要献上的供物：小麦，每一贺梅珥要献上六分之一伊法<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="六分之一伊法——相当于3.6公升。1伊法=22公升。">l</a></sup>；大麦，每一贺梅珥要献上六分之一伊法。</span>
<span className="v" id="v14" data-v="14"> 油的份额，按油的罢特，每一柯珥<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="一柯珥——相当于220公升。">m</a></sup>油要献上十分之一罢特<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="十分之一罢特——相当于2.2公升。1罢特=22公升。">n</a></sup>；一柯珥相当于十罢特或一贺梅珥，因为一贺梅珥也相当于十罢特。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 1:4; 利未记 6:30; 歌罗西书 1:21"> 至于羔羊，要从以色列水源充足之地的羊群中，每两百只取一只，作为素祭、燔祭和平安祭，为以色列人赎罪。这是主耶和华的宣告。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 30:14–15; 以赛亚书 16:1"> 这地全体民众要把这样的供物交给以色列的君王；</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 46:4–12; 历代志下 31:3; 以赛亚书 66:23"> 君王负责的，是在各节期、新月节和安息日，在以色列家的一切约期，献上燔祭、素祭和酒祭。他要献上赎罪祭、素祭、燔祭和平安祭，替以色列家赎罪。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未记 16:16; 出埃及记 12:2; 以西结书 43:22"> “主耶和华如此说：一月一日，你要取一头无瑕疵的公牛，洁净圣所。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 43:20; 以西结书 43:14; 利未记 16:18–20"> 祭司要取来一些赎罪祭的血，抹在圣殿的门柱上、祭坛磴台的四角上，以及内院的门柱上。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 19:12; 利未记 4:27–35; 以西结书 45:15"> 这月七日，你也要为过失犯罪的人或因无知而犯罪的人照样做。这样，就为圣殿行了赎罪礼。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="利未记 23:5–8; 哥林多前书 5:7–8; 民数记 9:2–14"> “一月十四日，你们要守逾越节；节期七天，都要吃无酵饼。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 4:14; 哥林多后书 5:21; 马太福音 20:28"> 到那日，君王要为自己和这地所有的民众献上一头赎罪祭公牛。</span>
<span className="v" id="v23" data-v="23" data-xref="约伯记 42:8; 利未记 23:8; 民数记 23:1–2"> 这七天节期，在七天的每一天，他都要向耶和华献上燔祭，就是无瑕疵的七头公牛和七只公绵羊，每一天还要献上一只赎罪祭公山羊。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 46:5–7; 民数记 28:12–15"> 他还要献上素祭，每头公牛配上一伊法细面，每只公绵羊配上一伊法细面，每一伊法细面配上一欣<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="一欣——相当于3.7公升。">o</a></sup>油。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 23:33–43; 民数记 29:12–38; 历代志下 5:3"> 到七月十五日，节期中他一连七天都要这样献上赎罪祭、燔祭、素祭和油。</span>
</div>
</div>

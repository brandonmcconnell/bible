<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话语又临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 4:12; 耶利米书 5:21; 诗篇 78:40"> “人子啊，你是住在悖逆之家当中，他们有眼可看却不看，有耳可听却不听；他们实在是悖逆之家！</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米书 36:3; 提摩太后书 2:25; 耶利米书 26:3"> “所以你，人子啊，你要准备好被掳时的行李，白天使自己在他们眼前被掳走。你要在他们眼前，从自己的地方被掳到别的地方。或许他们会思索，尽管他们是悖逆之家。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 39:4; 以西结书 12:12; 列王纪下 25:4"> 你要在白天，在他们眼前带出你的行李，好像带出被掳时的行李；也要在傍晚，在他们眼前出去，好像被掳走的人。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 25:4; 耶利米书 39:2–4"> 你要在他们眼前挖墙，从墙洞把行李带出去。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 4:3; 以赛亚书 8:18; 以西结书 24:24"> 你要在天黑的时候，在他们眼前把行李扛在肩膀上带出去。你要蒙住脸，使你看不见这地。我已经立你作以色列家的预表。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以西结书 24:18; 以西结书 37:10; 以西结书 37:7"> 我就照着所受的指示去做，白天带出我的行李，像在被掳时的行李；到了傍晚用手挖墙，天黑的时候将行李扛在肩上，在他们眼前带出去。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 第二天早晨，耶和华的话语临到我，说：</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 24:19; 以西结书 17:12; 以西结书 20:49"> “人子啊，以色列家，就是那悖逆之家，他们不是问你在做什么吗？</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 9:25; 以赛亚书 13:1; 耶利米书 24:8"> 你要对他们说，主耶和华如此说：这默示关乎耶路撒冷的君王，以及在耶路撒冷的以色列全家。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 52:15; 耶利米书 15:2; 耶利米书 52:28–30"> 你要说：‘我是你们的预表。我怎样行事，事情也将怎样在你们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你们——原文直译“他们”；本节下同。">a</a></sup>身上发生。你们将成为俘虏，被掳去。’</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 25:4; 耶利米书 39:4; 以西结书 12:6"> 他们中间的君王必在天黑的时候，肩上扛着行李出去。他们将挖墙，好使他从墙洞出去。他将蒙住自己的脸，使他的眼睛看不见这地。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 39:7; 何西阿书 7:12; 以西结书 17:20"> 我要向他张开我的网，他必被我的网罗捉住。我要把他带到迦勒底人之地巴比伦，他却不会看见那地，并将死在那里。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 5:2; 列王纪下 25:4–5; 以西结书 17:21"> 我要把他四围所有帮助他的，以及他所有的军队，都驱散到四方，我还要拔刀追赶他们。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 6:7; 以西结书 12:16; 以西结书 12:20"> 当我把他们驱散到列国、扬散在各地的时候，他们就知道：我是耶和华。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 22:8–9; 以西结书 14:22–23; 以西结书 6:8–10"> 但我会使他们中间少数的人从刀剑、饥荒和瘟疫中存留下来，好让他们在所到的列国中述说自己一切可憎之事。那时他们就知道：我是耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和华的话语又临到我，说：</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米哀歌 5:9; 诗篇 80:5; 约伯记 3:24"> “人子啊，你要在战兢中吃饭，在颤栗和忧虑中喝水。</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 7:14; 以西结书 6:6–7; 以西结书 6:14"> 你要对这地的民众说，论到以色列地耶路撒冷的居民，主耶和华如此说：他们必在忧虑中吃饭，在惶恐中喝水；因为以色列地所充满的，将因其中所有居民的恶行而被摧毁。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 4:7; 以赛亚书 7:23–24; 耶利米书 25:9"> 有居民的各城将荒废，这地将变得荒凉。那时你们就知道：我是耶和华。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21"> 耶和华的话语临到我，说：</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 18:2–3; 以西结书 11:3; 以西结书 12:27"> “人子啊，你们在以色列地怎么有这样的俗语，说：<br /><span className="pl pl-1">‘日子漫长，异象都消亡’？</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约珥书 2:1; 以西结书 7:5–7; 西番雅书 1:14"> “因此你要告诉他们，主耶和华如此说：我必使这俗语终止，以色列将不再有人引用它。你却要对他们说：日子临近了，一切异象就要应验了。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 14:13–16; 以西结书 13:23; 撒迦利亚书 13:2–4"> 是的，在以色列家中，必不再有任何虚假的异象和谄媚的占卜。</span>
<span className="v" id="v25" data-v="25" data-xref="哈巴谷书 1:5; 以西结书 12:28; 以赛亚书 55:11"> 我耶和华说出我要说的话，它必成就，不再耽延；悖逆之家啊，它必在你们的年日里成就！我发了话，必定成就。这是主耶和华的宣告。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和华的话语又临到我，说：</span>
<span className="v" id="v27" data-v="27" data-xref="但以理书 10:14; 以西结书 12:22; 彼得后书 3:4"> “人子啊，看哪，以色列家说：‘他所见的异象是指着许多年日以后<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以后——辅助词语。">b</a></sup>，他所说的预言是指着遥远的时候。’</span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 12:23–25; 马可福音 13:32–37; 帖撒罗尼迦前书 5:2–3"> 因此你要对他们说，主耶和华如此说：我的一切话语都不再耽延，我所说的话必成就。这是主耶和华的宣告。”</span>
</div>
</div>

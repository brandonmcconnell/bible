<span className="v" id="v2" data-v="2" data-xref="以西结书 41:13"> 这排房间进深一百肘，宽五十肘，北面有入口。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 41:15–16; 以西结书 41:10; 雅歌 7:5"> 它们对着内院的二十肘空地，也对着外院的铺石地，三层都是走廊与走廊相对。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 46:19; 路加福音 13:24; 马太福音 7:14"> 在这些房间前面，朝着内院有一条过道，宽十肘，长一百<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一百——依据七十士译本；马索拉文本作“一”。">a</a></sup>肘；房间的门口都朝北。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 41:7"> 上层的房间，因为走廊占用了一些地方，就比下层和中层的建筑窄小。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 41:6; 列王纪上 6:8"> 它们有三层，并且没有像外院那样的柱子，因此从地面往上，上层比下层和中层缩进一些。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 42:12; 以西结书 42:10"> 外面有围墙，面向这些房间，沿着外院与这些房间平行，长五十肘。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 41:13–14"> 这样，那些挨着外院的房间进深五十肘，看哪，靠近圣殿的房间有一百肘。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 46:19; 以西结书 44:5"> 在这些房间下方，东侧有个入口，通过它从外院进来。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西结书 42:1; 以西结书 42:13; 以西结书 41:12–15"> 沿着南边<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="南边——依据七十士译本；马索拉文本作“东边”。">b</a></sup>内院围墙的横面，在空地对面、南边的建筑物对面也有一排房间，</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 42:4"> 在它们前面有通道，与朝北那些房间的样式一样，有同样的进深和宽；它们所有的出口规格一样，入口也一样。</span>
<span className="v" id="v12" data-v="12"> 它们与朝南那些房间的入口一样，入口在通道的起点；通道朝东，在围墙的正前面，通过它进入这些房间。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未记 10:17; 利未记 7:6; 以西结书 40:46"> 那人对我说：“南边、北边面向空地的房间，都是圣屋。近前来事奉耶和华的祭司们要在那里吃至圣物，在那里放置至圣物，就是素祭、赎罪祭和赎愆祭，因为那地方是分别为圣的。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 44:19; 利未记 8:7; 出埃及记 29:4–9"> 祭司们进来事奉后，要把事奉时穿的衣服留在那里，然后才可以从圣所出去到外院，因为这些衣服是圣物。他们要穿上别的衣服，才可以来到民众所在的地方。”</span>
</div>

<span className="v" id="v16" data-v="16" data-xref="以西结书 40:3; 启示录 11:1–2; 撒迦利亚书 2:1"> <span className="pl pl-1">他用量竿在东面测量，</span><br /><span className="pl pl-1">按着量竿，是五百竿；</span><br /></span>

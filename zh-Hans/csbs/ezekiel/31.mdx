<span className="v" id="v1" data-v="1" data-xref="以西结书 30:20; 耶利米书 52:5–6; 以西结书 1:2"> 第十一年<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="第十一年——指约雅斤王被掳之后的第十一年；参《以西结书》1:2。">a</a></sup>三月一日，耶和华的话语临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 29:19; 以西结书 30:10; 以西结书 31:18"> “人子啊，你要对埃及王法老和他的大军说：<br /><span className="pl pl-1">论到你的高大，谁能与你相比呢？</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 10:33–34; 但以理书 4:10; 但以理书 4:20–23"> <span className="pl pl-1">看哪，亚述是黎巴嫩的香柏树，</span><br /><span className="pl pl-1">枝条美丽，浓荫如林，</span><br /><span className="pl pl-1">树身高大，树梢上达云间。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="启示录 17:15; 箴言 14:28; 以西结书 17:5"> <span className="pl pl-1">水源滋润它，</span><br /><span className="pl pl-1">深渊的水使它长高；</span><br /><span className="pl pl-1">它的栽种之地有河流环绕，</span><br /><span className="pl pl-1">分出的沟渠流向田野所有的树木。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 4:11; 以西结书 17:5; 诗篇 1:3"> <span className="pl pl-1">因此，它的树身</span><br /><span className="pl pl-1">高过田野所有的树木；</span><br /><span className="pl pl-1">因它发旺时有丰富的水源，</span><br /><span className="pl pl-1">它就枝杈众多，枝条修长。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 17:23; 马太福音 13:32; 但以理书 4:12"> <span className="pl pl-1">天空的飞鸟都在它枝子上搭窝，</span><br /><span className="pl pl-1">田野的走兽都在它枝条下产仔，</span><br /><span className="pl pl-1">所有的大国都在它荫影下居住。</span><br /></span>
<span className="v" id="v7" data-v="7"> <span className="pl pl-1">这样，它因树身高大，</span><br /><span className="pl pl-1">因枝子修长而美丽，</span><br /><span className="pl pl-1">因为它的根在丰富的水源旁。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 28:13; 创世记 13:10; 以赛亚书 51:3"> <span className="pl pl-1">神园子里的香柏树比不上它，</span><br /><span className="pl pl-1">松树不能与它的枝子相比，</span><br /><span className="pl pl-1">枫树没有像它那样的枝条，</span><br /><span className="pl pl-1">神园子里一切树木都不如它美丽。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 28:13; 但以理书 2:37–38; 创世记 13:10"> <span className="pl pl-1">我使它因枝子繁多而美丽，</span><br /><span className="pl pl-1">神伊甸园里所有的树都羡慕它。</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西结书 28:17; 但以理书 5:20; 历代志下 32:25"> “因此主耶和华如此说：因为它树身高大，树梢伸到云间，它就因自己的高度而心里高傲。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 32:11–12; 那鸿书 3:18; 但以理书 5:18–19"> 所以我要把它交在列国一位领袖手中，这领袖必处治它。我已经照着它的恶行，驱逐了它。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 28:7; 以西结书 35:8; 以西结书 30:11"> 列国强横的外族人砍伐它，把它丢弃在山上。它的枝子掉落在各山谷中，枝条折断落在地上各溪谷中，地上的万民都从它的荫影下离去，抛弃它。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 32:4; 以西结书 29:5; 以赛亚书 18:6"> 天空的飞鸟都栖息在它倒下的树干上，田野的走兽都躺卧在它的枝子旁。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 63:9–10; 尼希米记 13:18; 彼得后书 2:6"> 这样，水边一切树木都不再因它们的树身而高傲，不再把树梢伸到云间，所有得水滋润的大树都不再高高挺立。因为它们全都被交于死亡，交到地府，与下阴坑的世人在一起。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="玛拉基书 3:4; 那鸿书 2:8–10; 启示录 18:9–11"> “主耶和华如此说：在它下阴间的日子里，我使人悲恸；我因它的缘故遮蔽深渊，拦住深渊的河流，止住丰富的水源。我使黎巴嫩因它而哀痛，田野的树木都因它而枯萎。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 14:15; 以赛亚书 14:8; 以西结书 26:15"> 当我使它下阴间，与下阴坑的人在一起的时候，我使列国因它倒下的声音而震动；伊甸所有的树木，就是黎巴嫩最佳最美的、所有得水滋润的树木，都在地府受了安慰。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 9:17; 以西结书 31:6; 以西结书 31:3"> 它们也与它一起下阴间，到了那些被刀剑所杀的人那里；它们曾是它的膀臂，在列国中居住在它的荫影下。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以西结书 32:19; 以西结书 32:21; 以西结书 28:10"> “论到你的荣美和高大，伊甸的树木中，谁能与你相比呢？然而你却将与伊甸的树木一起下到地府，与被刀剑所杀的人一起躺卧在未受割礼的人中间。法老和他的全军都必如此。这是主耶和华的宣告。”</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 8:1; 以西结书 20:1; 列王纪下 6:32"> 以色列的长老中有些人来到我这里，坐在我面前。</span>
<span className="v" id="v2" data-v="2" data-xref="阿摩司书 3:7; 列王纪上 14:4"> 那时耶和华的话语临到我，说：</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 14:7; 以西结书 7:19; 以西结书 20:3"> “人子啊，这些人把偶像供奉在心中，把导致犯罪的绊脚石放在自己面前，难道我会接受他们求问吗？</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 66:4; 以西结书 14:7; 以赛亚书 3:11"> “因此你要向他们宣告，对他们说，主耶和华如此说：在以色列家中，任何人把偶像供奉在心中，把导致犯罪的绊脚石放在自己面前，又来见先知，我耶和华都必照着他拜偶像的程度<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="拜偶像的程度——原文直译“偶像的众多”。">a</a></sup>，回应这前来的人，</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 1:4; 撒迦利亚书 11:8; 罗马书 1:28"> 好使我夺回以色列家的心——他们全都因着自己的偶像背离了我！</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结书 18:30; 以赛亚书 30:22; 以西结书 36:31–32"> “因此你要告诉以色列家，主耶和华如此说：回转吧！转离你们的偶像，转脸离开你们的一切可憎之物！</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 12:48; 以赛亚书 58:1–2; 利未记 24:22"> 无论以色列家中，还是寄居在以色列的外人中，任何人远离我，把偶像供奉在心中，把导致犯罪的绊脚石放在自己面前，又来见先知求问我，我耶和华都必亲自回应他。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 15:7; 耶利米书 44:11; 以西结书 5:15"> 我要向那人翻脸，使他成为鉴戒和笑柄；我要把他从我的子民中间剪除。那时你们就知道：我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以西结书 20:25; 耶利米书 4:10; 诗篇 81:11–12"> “至于先知，如果被引诱而说神言，那是我耶和华使这先知受了引诱。我要伸手攻击他，把他从我子民以色列中除灭。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 23:49; 以西结书 14:4; 耶利米书 8:11–12"> 他们必承担自己的罪责；求问之人的罪责怎样，先知的罪责也怎样。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 37:23; 以西结书 44:10; 启示录 21:7"> 这样，以色列家就不再迷失离开我，不再以他们的一切过犯玷污自己了。他们将要作我的子民，我将要作他们的神。这是主耶和华的宣告。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 耶和华的话语临到我，说：</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 26:26; 以西结书 4:16; 以赛亚书 24:20"> “人子啊，当一个地方行事不忠，对我犯罪时，如果我伸手攻击那地，断绝它的粮食供应，降下饥荒，从那里剪除人和牲畜，</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 14:20; 耶利米书 15:1; 以西结书 28:3"> 即使有挪亚、但以理和约伯这三人在那里，他们也只能因着自己的义救自己的性命。这是主耶和华的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西结书 5:17; 利未记 26:22; 耶利米书 15:3"> “如果我使恶兽遍行那地，使那地丧失居民，以致它因野兽而无人经过，变得荒凉，</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 19:29; 雅各书 5:16; 以西结书 33:11"> 即使有这三人在那里，我指着我的永生起誓：他们也绝不能救自己的儿女，唯独他们能得救，那地必变得荒凉。这是主耶和华的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="利未记 26:25; 以西结书 21:3–4; 西番雅书 1:3"> “如果我使刀剑临到那地，说：‘让刀剑遍行那地，我要从其中剪除人和牲畜’，</span>
<span className="v" id="v18" data-v="18"> 即使有这三人在那里，我指着我的永生起誓：他们也绝不能救自己的儿女，唯独他们能得救。这是主耶和华的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西结书 38:22; 以西结书 5:12; 耶利米书 14:12"> “如果我使瘟疫降到那地，把我的怒火倾泻在其上施行杀戮<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="施行杀戮——原文直译“带着血”。">b</a></sup>，要从那里剪除人和牲畜，</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 14:14; 约翰一书 2:29; 以赛亚书 3:10"> 即使有挪亚、但以理和约伯在那里，我指着我的永生起誓：他们也绝不能救自己的儿女，他们只能因着自己的义救自己的性命。这是主耶和华的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西结书 33:27; 以西结书 5:17; 以西结书 14:13"> “是的，主耶和华如此说：更何况，那时我会把这四样严厉的审判，就是刀剑、饥荒、恶兽和瘟疫，都降到耶路撒冷，要从其中剪除人和牲畜！</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 12:16; 以西结书 20:43; 希伯来书 12:6–11"> 然而，看哪，其中必有逃脱者存留，并且带出儿女。看哪，他们来到你们这里，你们看见他们的所作所为，就会因我向耶路撒冷降祸，因我向这城所降的一切而受到安慰。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 22:8–9; 启示录 15:4; 申命记 8:2"> 当你们看见他们的所作所为时，你们就因他们而受到安慰。那时你们就知道：我在耶路撒冷所做的一切都不是无故做的。这是主耶和华的宣告。”</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 8:1; 以西结书 30:20; 以西结书 24:1"> 第七年<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="第七年——指约雅斤王被掳之后的第七年；参《以西结书》1:2。">a</a></sup>五月十日，以色列的长老中有些人来求问耶和华，他们坐在我面前。</span>
<span className="v" id="v2" data-v="2"> 耶和华的话语临到我，说：</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 28:9; 马太福音 15:8–9; 诗篇 50:15–21"> “人子啊，你要告诉以色列的长老，对他们说，主耶和华如此说：你们来是要求问我吗？我指着我的永生起誓：我绝不让你们求问。这是主耶和华的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以西结书 22:2; 以西结书 23:36; 以西结书 14:20"> “你要谴责他们吗？人子啊，你要谴责他们吗？你要让他们知道他们祖先的可憎之事！</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 7:6; 以西结书 20:15; 出埃及记 3:8"> 你要对他们说，主耶和华如此说：我在拣选以色列的日子，曾向雅各家的后裔举手起誓；那时我在埃及地向他们显现，向他们举手起誓说：‘我是耶和华你们的神。’</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 3:8; 耶利米书 32:22; 以西结书 20:15"> 在那日，我向他们举手起誓要把他们从埃及地领出来，进入我为他们探察的流奶与蜜之地，它是全地中最美的。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 18:3; 以西结书 20:8; 利未记 11:44"> 我对他们说：‘你们各人要扔掉自己爱慕<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="爱慕——原文直译“眼中”；下同。">b</a></sup>的可憎之物，不要以埃及的偶像玷污自己。我是耶和华你们的神。’</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西结书 20:7; 以赛亚书 63:10; 以西结书 20:21"> “但是他们悖逆我，不肯听从我，不扔掉他们各人爱慕的可憎之物，不离弃埃及的偶像。我就说，我要向他们倾泻我的怒火，在埃及地对他们发尽我的怒气。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 39:7; 以西结书 20:22; 出埃及记 32:12"> 然而我为我的名行事，免得我的名在他们所住的列邦眼前被亵渎，因我曾在列邦眼前向他们显现，为要把他们从埃及地领出来。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及记 15:22; 出埃及记 13:17–18; 出埃及记 14:17–22"> “这样，我把他们从埃及地领出来，带到旷野。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 10:5; 利未记 18:5; 申命记 4:8"> 我把我的律例赐给他们，把我的法规告诉他们——人若遵行这些，就必因此而活。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 20:20; 以西结书 37:28; 利未记 21:23"> 我还把我的安息日赐给他们，作为我和他们之间的记号，使他们知道：我是把他们分别为圣的耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西结书 20:21; 以西结书 20:8; 以赛亚书 56:6"> “但是以色列家在旷野中悖逆我，不顺从我的律例，厌弃我的法规——人若遵行这些，就必因此而活——他们极大地亵渎了我的安息日。我就说，我要向他们倾泻怒火，在旷野灭绝他们。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 20:9; 以西结书 36:22–23; 以西结书 20:22"> 然而我为我的名克制<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="克制——辅助词语。">c</a></sup>行事，免得我的名在列邦眼前被亵渎，因我曾在列邦眼前把他们领出来。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 95:11; 诗篇 106:26; 希伯来书 3:18"> 不过我在旷野中向他们举手起誓，不再领他们进入我所赐给他们的流奶与蜜之地，它是全地中最美的。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 15:39; 以西结书 20:8; 以西结书 14:3–4"> 这是因为他们厌弃我的法规，不顺从我的律例，亵渎我的安息日，他们的心执意追随自己的偶像。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 11:13; 耶利米书 4:27; 耶利米书 5:18"> 然而我还是眼中顾惜他们，没有毁灭他们，没有在旷野灭绝他们。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒迦利亚书 1:2–4; 诗篇 78:6–8; 彼得前书 1:18"> “我在旷野中对他们的儿女说：‘不要随从你们祖先的定例，不要遵守他们的规条，也不要以他们的偶像玷污自己。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 36:27; 申命记 5:32–8; 以西结书 37:24"> 我是耶和华你们的神，你们要顺从我的律例，谨守遵行我的法规。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 58:13; 耶利米书 17:22; 出埃及记 31:13–17"> 你们要把我的安息日尊为圣，好让这安息日在我和你们之间作记号，使你们知道：我是耶和华你们的神。’</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西结书 20:13; 民数记 21:5; 以西结书 20:8"> “但是这些儿女悖逆我，不顺从我的律例，不谨守遵行我的法规——人若遵行这些，就必因此而活——他们亵渎了我的安息日。我就说，我要向他们倾泻怒火，在旷野对他们发尽我的怒气。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 20:14; 以西结书 20:9; 耶利米书 14:21"> 然而我为我的名克制<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="克制——原文直译“收回我的手”。">d</a></sup>行事，免得我的名在列邦眼前被亵渎，因我曾在列邦眼前把以色列人领出来。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 26:33; 申命记 28:64–68; 申命记 32:26–27"> 不过我在旷野中向他们举手起誓，要把他们驱散到列国，扬散在各地。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 20:16; 以西结书 6:9; 阿摩司书 2:4"> 这是因为他们不遵行我的法规，厌弃我的律例，亵渎我的安息日，他们的眼目追随他们祖先的偶像。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 81:12; 以赛亚书 66:4; 以西结书 20:39"> 因此我也任凭他们有无益的定例，有不能使人存活的规条。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 6:7; 利未记 18:21; 以西结书 20:31"> 因着他们使各人的头生子经火，我就任凭他们因这些供物而不洁，为要摧毁他们，使他们知道我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="罗马书 2:24; 以西结书 2:7; 以西结书 3:11"> “因此，人子啊，你要向以色列家说话，要对他们说，主耶和华如此说：你们的祖先一再对我行事不忠，这样亵渎我！</span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 6:13; 尼希米记 9:22–26; 耶利米书 3:6"> 我把他们带进了我举手起誓要赐给他们的那地，而他们看见各高丘、各种茂盛的树，就在那里献祭，在那里奉上惹怒我的祭品，献上馨香之气，又浇奠酒祭。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 16:24–25; 以西结书 16:31"> 我就对他们说：‘你们去的高坛叫什么呢？’于是那高坛的名字被称为‘巴麻’，直到今天。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米书 16:12; 耶利米书 7:26; 士师记 2:19"> “因此你要对以色列家说，主耶和华如此说：你们要继续照着你们祖先所行的玷污自己，继续追随他们的可憎之物行淫吗？</span>
<span className="v" id="v31" data-v="31" data-xref="以西结书 20:26; 诗篇 106:37–39; 耶利米书 7:31"> 你们献上供物，使你们的儿女经火；你们以各样的偶像玷污自己，直到今天。以色列家啊，我能让你们求问我吗？这是主耶和华的宣告：我指着我的永生起誓，我绝不让你们求问我！</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以西结书 11:5; 耶利米书 44:17; 诗篇 139:2"> “你们说‘我们要像列邦，像地上的各族那样，去事奉木头和石头’，你们灵里所起的这意念，绝不会实现。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 21:5; 以西结书 8:18; 耶利米书 44:6"> 这是主耶和华的宣告：我指着我的永生起誓，我必用大能的手和伸出的膀臂，以及倾泻的怒火统治你们。</span>
<span className="v" id="v34" data-v="34" data-xref="以西结书 20:38; 阿摩司书 9:9–10; 以西结书 34:16"> 我要把你们从万民中带出来，用大能的手和伸出的膀臂，以及倾泻的愤怒，把你们从被驱散到的各地招聚起来，</span>
<span className="v" id="v35" data-v="35" data-xref="何西阿书 2:14; 耶利米书 2:35; 以西结书 17:20"> 带到万民的旷野，在那里面对面审判你们。</span>
<span className="v" id="v36" data-v="36" data-xref="哥林多前书 10:5–10; 民数记 11:1–35; 以西结书 20:13"> 我怎样在埃及地的旷野审判你们的祖先，也必怎样审判你们。这是主耶和华的宣告。</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 33:13; 利未记 27:32; 马太福音 25:32–33"> 我要使你们从杖下经过，使你们受到誓约的管束。</span>
<span className="v" id="v38" data-v="38" data-xref="以西结书 13:9; 阿摩司书 9:9–10; 诗篇 95:11"> 我要从你们中间除尽那些背叛我、悖逆我的人；我要把他们从寄居之地带出来，他们却不得进入以色列地。那时你们就知道：我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="何西阿书 4:17; 以赛亚书 1:13–15; 以西结书 43:7"> “你们以色列家啊，主耶和华如此说：你们各人去服事自己的偶像吧！但以后你们必定听从我<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="你们各人去服事自己的偶像吧！但以后你们必定听从我——或译作“既然你们不愿听从我，你们各人去服事自己的偶像吧”。">e</a></sup>，不会再以你们的供物和偶像亵渎我的圣名。</span>
<span className="v" id="v40" data-v="40" data-xref="以赛亚书 56:7; 玛拉基书 3:4; 以赛亚书 60:7"> 这是主耶和华的宣告：以色列全家必在我的圣山，就是以色列的高山上，在那地服事我。我要在那里悦纳你们，在那里收取你们的供物和最好的供献，连同你们的一切圣物。</span>
<span className="v" id="v41" data-v="41" data-xref="以西结书 28:25; 以西结书 11:17; 以西结书 38:23"> 当我把你们从万民中领出来，从被驱散到的各地招聚起来时，我要悦纳你们如馨香之气，我要藉着你们在列邦眼前显为圣。</span>
<span className="v" id="v42" data-v="42" data-xref="以西结书 34:13; 以西结书 38:23; 以西结书 36:23–24"> 当我把你们带进以色列地，就是我曾举手起誓赐给你们祖先的那地时，你们就知道：我是耶和华。</span>
<span className="v" id="v43" data-v="43" data-xref="以西结书 6:9; 何西阿书 5:15; 耶利米书 31:18"> 你们在那里回想你们玷污自己的一切所作所为，就会因所做的一切恶事而厌恶自己。</span>
<span className="v" id="v44" data-v="44" data-xref="以西结书 24:24; 诗篇 115:1; 以西结书 20:9"> 以色列家啊，当我为我名的缘故行事，不照着你们的恶行和败坏行为对待你们，那时你们就知道：我是耶和华。这是主耶和华的宣告。”</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45"> <sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="此节至20:49在马索拉文本为21:1至21:5。">f</a></sup>耶和华的话语又临到我，说：</span>
<span className="v" id="v46" data-v="46" data-xref="阿摩司书 7:16; 以西结书 21:2; 耶利米书 13:19"> “人子啊，你要面向南方，向南方传道，针对南地<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="南地——音译作“内盖夫”；下同。">g</a></sup>田野的树林发预言。</span>
<span className="v" id="v47" data-v="47" data-xref="耶利米书 21:14; 以赛亚书 24:1–6; 以西结书 17:24"> 你要对南地的树林说：请听耶和华的话语！主耶和华如此说：看哪，我必在你中间点火，吞噬你中间一切青绿的树和一切枯干的树。炽烈的火焰无法扑灭，从南到北整个地面<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="整个地面——或译作“人们的脸”。">h</a></sup>都将被烧焦。</span>
<span className="v" id="v48" data-v="48" data-xref="耶利米书 40:2–3; 耶利米书 7:20; 申命记 29:24–28"> 一切有血肉的都将看到：是我耶和华点着了火，这火无法扑灭。”</span>
</div>

<span className="v" id="v49" data-v="49" data-xref="约翰福音 16:25; 使徒行传 17:18; 以西结书 17:2"> 于是我说：“唉，主耶和华啊！他们都议论我说：‘他不就是设个比喻吗？’”</span>

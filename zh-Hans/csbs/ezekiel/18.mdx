<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 耶和华的话语又临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 31:29–30; 耶利米哀歌 5:7; 以西结书 37:11"> “你们在以色列地怎么有这样的俗语，说：<br /><span className="pl pl-1">‘父亲吃酸葡萄，儿子的牙齿酸倒了’？</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以西结书 18:19–20; 以西结书 33:11–20; 以西结书 18:30"> “这是主耶和华的宣告：我指着我的永生起誓，你们在以色列绝不会再引用这俗语。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 18:20; 罗马书 6:23; 民数记 16:22"> 看哪，所有人的性命都是我的，父亲的性命与儿子的性命一样属于我；只有犯罪的人才会丧命。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以西结书 33:14; 约翰一书 3:7; 箴言 21:3"> “如果有人是公义的，实行公正和公义，</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 18:15; 申命记 4:19; 以西结书 6:13"> 不到山上吃祭物，不仰望以色列家的偶像；不玷污邻人的妻子，不亲近经期中的女人；</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 18:16; 出埃及记 22:26; 以西结书 18:12"> 不欺压人，反而归还欠债人的抵押物；不抢劫，反而给饥饿的人食物吃，给赤身的人衣服穿；</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 22:25; 撒迦利亚书 8:16; 申命记 23:19–20"> 借贷不收利息，不取厚利；不出手做不义的事，在人与人之间施行诚实的裁决；</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 20:11; 哈巴谷书 2:4; 阿摩司书 5:4"> 遵行我的律例，谨守我的法规，诚实行事——这人是公义的，他必定存活。这是主耶和华的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及记 21:12; 约翰一书 3:12; 约翰福音 18:40"> “但如果这人生养的儿子是个恶徒，是杀人流血的，做了这些事的任何一件——</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 22:14; 马太福音 7:21–27; 列王纪上 13:8"> 尽管他自己没有做这些事，但他儿子竟然到山上吃祭物，或玷污邻人的妻子，</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 8:17; 以西结书 8:6; 列王纪下 21:11"> 欺压困苦人和贫穷人，强取豪夺，不归还抵押物，仰望偶像，做可憎的事，</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 22:25; 利未记 20:9; 以西结书 3:18"> 借贷收利息，取厚利——这儿子能存活吗？他绝不能存活！他做了这些可憎的事，必须被处死，他的血债归在他自己身上。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志下 34:21; 箴言 23:24; 耶利米书 8:6"> “如果这人生养了一个儿子，儿子看见父亲所行的那些罪恶，看见了就不这样做，</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 18:6–7; 以西结书 18:11–13"> 不到山上吃祭物，不仰望以色列家的偶像，不玷污邻人的妻子，</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 18:7; 以赛亚书 58:7–10; 约伯记 22:7"> 不欺压人，不拿人的抵押物，不强取豪夺，反而给饥饿的人食物吃，给赤身的人衣服穿，</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 18:8–9; 马太福音 18:27–35; 以西结书 18:13"> 不出手害困苦人，不收取利息或厚利，遵行我的法规，遵从我的律例，他就不会因父亲的罪孽而死，他必定存活。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以西结书 3:18; 以西结书 18:26; 以西结书 18:24"> “至于这位父亲，因为他欺压人，抢夺弟兄，在同胞中做不善的事，看哪，他必因自己的罪孽而死。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 20:5; 撒迦利亚书 1:3–6; 申命记 5:9"> 你们会问：‘儿子为什么不承担父亲的罪责呢？’这儿子行公正和公义，谨守遵行我的一切律例，他当然要存活。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 24:16; 列王纪下 14:6; 以西结书 18:4"> 那犯罪之人，他才会丧命。儿子不承担父亲的罪责，父亲也不承担儿子的罪责。义人的义归属自己，恶人的恶也归属自己。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西结书 18:27–28; 提多书 2:11–14; 以西结书 33:19"> “恶人如果转离所行的一切罪恶，谨守我的一切律例，实行公正和公义，他必定存活，不致死亡。</span>
<span className="v" id="v22" data-v="22" data-xref="弥迦书 7:19; 以西结书 33:16; 以赛亚书 43:25"> 他所犯的一切过犯，都不会被记起，他必因所行的公义而存活。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 33:11; 提摩太前书 2:4; 彼得后书 3:9"> 这是主耶和华的宣告：难道我真的乐意恶人死亡吗？难道我不是乐意他转离自己的道路而存活吗？</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 33:18; 箴言 21:16; 约翰二书 1:8"> 但如果义人转离自己的义而行不义，照着恶人所做的那些可憎之事而行，他能存活吗？他所行的一切义都不会被提起，他必因自己行事不忠，因自己所犯的罪而死。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以西结书 33:17; 玛拉基书 3:13–15; 玛拉基书 2:17"> “你们竟然说：‘主做事不公平！’以色列家啊，你们听着：是我做事不公平吗？难道不是你们做事不公平吗？</span>
<span className="v" id="v26" data-v="26"> 义人如果转离他的义而行不义，就会因此而死，他必因所行的不义而死。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 18:21; 以赛亚书 1:18; 以赛亚书 55:7"> 恶人如果转离他所行的恶，实行公正和公义，他就会使自己的性命得以存活；</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 32:29; 路加福音 15:17–18; 雅各书 2:10–12"> 他思索后，就转离他所行的一切过犯，他必定存活，不致死亡。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 18:25; 箴言 19:3; 以西结书 18:2"> 以色列家竟然说：‘主做事不公平！’以色列家啊，是我做事不公平吗？难道不是你们做事不公平吗？</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="以西结书 18:21; 马太福音 16:27; 马太福音 3:2"> “因此以色列家啊，我必照着各人的行为审判你们。这是主耶和华的宣告。你们要回转，转离你们的一切过犯，免得罪孽成为你们的绊脚石。</span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 51:10; 以西结书 36:26; 以西结书 11:19"> 你们要抛弃你们的一切悖逆行为，为自己获得一个新的心、新的灵。以色列家啊，你们何必死亡呢？</span>
<span className="v" id="v32" data-v="32" data-xref="彼得后书 3:9; 以西结书 18:23; 以西结书 33:11"> 我绝不乐意有人死亡，这是主耶和华的宣告。你们要回转，要存活！”</span>
</div>
</div>

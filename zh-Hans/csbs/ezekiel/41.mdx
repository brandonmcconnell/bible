<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 40:2–3; 以西结书 40:17; 以西结书 41:23"> 他把我带到了正殿。他测量墙柱，这边宽六肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="六肘——相当于3.2公尺；下同。">a</a></sup>，那边宽六肘，是墙柱<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="墙柱——依据七十士译本；马索拉文本作“会幕”。">b</a></sup>的厚度。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 6:17; 历代志下 3:3; 列王纪上 6:2"> 门口宽十肘<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="十肘——相当于5.3公尺。">c</a></sup>；门口的两侧，这边五肘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="五肘——相当于2.7公尺；下同。">d</a></sup>，那边五肘。他测量正殿，进深四十肘<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="四十肘——相当于21.2公尺。">e</a></sup>，宽二十肘<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="二十肘——相当于10.6公尺；下同。">f</a></sup>。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 40:16"> 他来到内殿，测量门口的墙柱，是两肘<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="两肘——相当于1公尺。">g</a></sup>。门口六肘<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="六肘——相当于3.2公尺。">h</a></sup>，门口两侧宽七肘<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="七肘——相当于3.7公尺。">i</a></sup>。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 6:20; 希伯来书 9:3–8; 出埃及记 26:33–34"> 他测量内殿，进深二十肘，宽二十肘，面对着正殿。他对我说：“这是至圣所。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪上 6:5–6; 以西结书 42:3–14; 以西结书 41:6–9"> 他又测量圣殿的墙，厚六肘<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="六肘——相当于3.2公尺。">j</a></sup>；围绕殿宇四围的厢房，宽四肘<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="四肘——相当于2.1公尺。">k</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 6:10; 列王纪上 6:5–6; 以西结书 40:17"> 那些厢房，厢房叠加厢房，有三层，每层三十间；厢房四围以殿宇的墙坎为支撑，而不是直接以殿宇的墙为支撑。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 6:8; 希伯来书 6:1; 马太福音 13:32"> 厢房层层加宽，螺旋上升，因为殿宇四围的层架结构环绕上升。因此屋内越向上越宽，这样从下层经过中层，抵达上层。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西结书 40:5; 启示录 21:16"> 我看见有一个高台围绕着殿宇，是厢房的根基，足足高一竿，就是六肘<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="六肘——相当于3.2公尺。">l</a></sup>。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 41:11; 以西结书 42:4; 以西结书 42:1"> 厢房的外墙厚五肘<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="五肘——相当于2.7公尺；下同。">m</a></sup>；殿宇厢房的旁边有空隙地，</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 40:17"> 就是厢房与库房之间，宽二十肘<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="二十肘——相当于10.6公尺。">n</a></sup>，围绕着殿宇的周围。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 41:9; 以西结书 42:4"> 厢房门口面向那空隙地，一个门口朝北，一个门口向南，有一条五肘宽的走道围绕着厢房。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西结书 42:1; 以西结书 42:13; 以西结书 41:13–15"> 在西边，空地前面的建筑物宽七十肘<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="七十肘——相当于37.1公尺。">o</a></sup>，长九十肘<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="九十肘——相当于47.7公尺。">p</a></sup>；建筑物四围的墙厚五肘。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西结书 40:47"> 这样，他测量了圣殿，进深一百肘<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="一百肘——相当于53公尺；下同。">q</a></sup>；空地和那建筑物以及它的墙，进深也是一百肘；</span>
<span className="v" id="v14" data-v="14"> 圣殿前面、东面的空地，宽一百肘。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 42:3; 以西结书 42:1; 以西结书 41:12"> 他测量面向后边空地的建筑物，以及这边和那边的走廊，进深一百肘。 内部的木头构造<br />里面的正殿、院子的门廊、</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 6:4; 以西结书 40:25; 以西结书 40:16"> 门槛、狭窄的窗格和周围三面对着门槛的走道，四围都镶嵌着木板。从地面到窗格——窗格有遮罩——</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 42:15"> 直到门口上方，从圣殿的内部到外部，内外四围所有的墙上，都照着规格，</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 7:36; 以西结书 40:16; 以西结书 40:22"> 雕刻着基路伯和棕榈树。基路伯与基路伯之间，都间隔着一棵棕榈树；每个基路伯有两张脸，</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 10:14; 以西结书 1:10"> 这边是人的脸，对着棕榈树，那边是狮子的脸，对着棕榈树。整个殿宇四围都是这样的雕刻，</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 41:18"> 从地面到门口上方，都雕刻着基路伯和棕榈树，正殿的墙壁也是如此。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西结书 41:1; 列王纪上 6:33; 以西结书 40:14"> 正殿有方形的门框立柱。至圣所前面有一个物件，形状像<sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="此节或译作：正殿有方形的门框立柱；内殿前面，样式与正殿相似。">r</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="玛拉基书 1:12; 以西结书 23:41; 玛拉基书 1:7"> 木头的祭坛，高三肘<sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="三肘——相当于1.6公尺。">s</a></sup>，长两肘<sup className="fn"><a href="#fn-t" id="fnref-t" data-fn="两肘——相当于1公尺。">t</a></sup>，它的凸角、底座和四壁都是木头的。那人对我说：“这是耶和华面前的桌子。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪上 6:31–35; 历代志下 4:22; 以西结书 41:1"> 正殿和内殿都有双扇门，</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 6:34; 以西结书 40:48"> 各门有两个门扇，每扇又有两个折叠的门页。这一边门扇有两个门页，另一边门扇也有两个门页。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 41:18"> 正殿的门上雕刻着基路伯和棕榈树，与雕刻在墙上的一样。在门廊前面，有向外伸展的木头廊檐。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 41:16; 以西结书 40:16; 以西结书 41:5"> 门廊两侧的这边和那边，都有狭窄的窗格和棕榈树的雕饰。殿宇的厢房也有廊檐。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话语临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 39:1; 以西结书 27:13; 以西结书 38:3"> “人子啊，你要面向米设和图巴的为首领袖<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="米设和图巴的为首领袖——或译作“米设、图巴和罗施的领袖”；下节同。">a</a></sup>，就是玛格地的歌革，针对他发预言。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 13:8; 以西结书 39:1–10; 以西结书 29:3"> 你要说，主耶和华如此说：米设和图巴的为首领袖歌革啊，看哪，我与你敌对！</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 29:4; 但以理书 11:40; 以西结书 38:15"> 我要把你调转过来，用钩子钩住你的下巴，把你和你的全军、马匹和马兵带出来。他们全都披挂整齐，是极大的队伍，带着大小盾牌，全都握着刀剑。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 27:10; 创世记 10:6; 以西结书 30:5"> 波斯、库实<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="库实——指埃塞俄比亚。">b</a></sup>、普特人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="普特人——指利比亚。">c</a></sup>与他们一起，全都装备着盾牌和头盔；</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 27:14; 创世记 10:2–3; 历代志上 1:5–6"> 还有格梅尔和它的全军，极远的北方陀伽玛族和它的全军，有许多民族跟着你。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志下 25:8; 约珥书 3:9–12; 以赛亚书 37:22"> “做好准备吧！你与被招聚到你那里的所有队伍都要准备好，你要统领他们<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="统领他们——或译作“作他们的后盾”。">d</a></sup>。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 38:16; 以赛亚书 24:22; 以西结书 38:11–12"> 许多日子后，你将被征召；在末后的年日里，你将入侵一国——这国的民是脱离刀剑回归的民，从许多民族中被招聚回来，到了长久成为废墟的以色列群山上；他们从各民族中被带出来，全都安然居住。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 28:2; 耶利米书 4:13; 约珥书 2:2"> 你将上来，如同风暴来临；你和你的全军，以及跟着你的许多民族，如同密云遮盖大地。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="诗篇 36:4; 弥迦书 2:1; 诗篇 83:3–4"> “主耶和华如此说：到那日，你心中将起意念，谋划恶计，</span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亚书 2:4–5; 箴言 3:29–30; 耶利米书 49:31–32"> 说：‘我要上去攻打那无城墙的村镇之地，到那些安居太平的人那里去，他们全都居住在无城墙的地方，无门无闩。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 10:6; 以西结书 38:8; 以西结书 29:19"> 我要掳夺战利品，掠取财物，出手攻打那从前是废墟现在有了居民的地方，攻击那地的民，他们是从列国中被招聚回来的，获取了牲畜和财富，居住在大地中心。’</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 27:15; 以西结书 27:22–23; 以西结书 32:2"> 示巴、底但，塔尔施的商人和它们所有的少壮狮子<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="它们所有的少壮狮子——或译作“各城镇”。">e</a></sup>，就问你说：‘你来是要掳夺战利品吗？你招聚队伍，是要掠取财物，掳去金银，带走牲畜和财富，掳夺许多战利品吗？’</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西结书 38:8; 撒迦利亚书 2:5; 耶利米书 23:6"> “因此人子啊，你要发预言，对歌革说，主耶和华如此说：到那日，当我的子民以色列安然居住时，你岂不是知道这一切吗？</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 39:2; 以西结书 38:6; 启示录 20:8"> 你将带着许多民族从你本土，从极远的北方而来，他们全都骑着马，是极大的队伍，军兵众多。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 39:21; 以西结书 38:23; 何西阿书 3:5"> 你必上来攻打我的子民以色列，如同密云遮盖大地。歌革啊，在末后的日子，我要把你带来攻打我的土地。这样，当我藉着你在列国眼前显为圣时，他们就会认识我。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="但以理书 11:40–45; 以赛亚书 63:1–6; 约珥书 3:9–14"> “主耶和华如此说：我在早先的日子，藉着我的仆人以色列众先知所说的那人，不就是你吗？在那些年日里，他们曾预言我将把你带来攻打以色列。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 36:5–6; 希伯来书 12:29; 诗篇 89:46"> 到那日，在歌革来攻打以色列地的日子里，我鼻孔中的怒火必上腾。这是主耶和华的宣告。</span>
<span className="v" id="v19" data-v="19" data-xref="哈该书 2:6–7; 启示录 11:13; 启示录 16:20"> 我在我的妒爱和怒火中宣告：在那日，以色列地上必有大地震，</span>
<span className="v" id="v20" data-v="20" data-xref="何西阿书 4:3; 那鸿书 1:4–6; 启示录 6:12–13"> 海里的鱼、天空的飞鸟、田野的走兽、地上活动的一切爬虫，以及地面上所有的人，都将在我面前震动。山体崩裂，峭壁倒塌，所有的城墙都倒塌在地上。</span>
<span className="v" id="v21" data-v="21" data-xref="哈该书 2:22; 士师记 7:22; 以西结书 14:17"> 我必在我的众山上召唤刀剑攻击歌革，他们彼此刀剑相向。这是主耶和华的宣告。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 66:16; 诗篇 11:6; 启示录 16:21"> 我必用瘟疫和杀戮<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="杀戮——原文直译“血”。">f</a></sup>审判他，使暴雨、冰雹、烈火和硫磺降下攻击他和他的军队，以及跟着他的许多民族。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 9:16; 启示录 19:1–6; 以西结书 38:16"> 我必显为大、显为圣，在许多国家眼前显明自己。那时他们就知道：我是耶和华。”</span>
</div>
</div>

<span className="v" id="v1" data-v="1" data-xref="启示录 22:1; 撒迦利亚书 14:8; 约珥书 3:18"> 他把我带回到圣殿门口。看哪，有水从圣殿的门槛下面流出来，往东而去，因为圣殿面朝东。这水从圣殿的右侧下面，从祭坛南边流下来。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 44:4; 以西结书 44:2"> 他又带我从北门出来，从外面绕行到朝东的外门。看哪，有水从右侧涌出。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 40:3; 使徒行传 10:45–46; 使徒行传 11:16–18"> 那人手中拿着准绳，往东出去测量了一千肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一千肘——相当于530公尺；下同。">a</a></sup>，然后让我从水中趟过去，水到脚踝。</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 1:6; 罗马书 15:19; 使徒行传 19:10–20"> 他又测量了一千肘，然后让我从水中趟过去，水到膝盖。他又测量了一千肘，然后让我趟过去，水到腰部。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 11:9; 哈巴谷书 2:14; 马太福音 13:31–32"> 他又测量了一千肘，水成了我不能趟过去的河，因为水涨起来，成了可游泳的深水，不能趟过去的河。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结书 44:5; 以西结书 40:4; 撒迦利亚书 4:2"> 他对我说：“人子啊，你都看见了吗？”然后他带我回到河岸边。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 47:12; 启示录 22:2; 列王纪下 2:13"> 我返回的时候，看见这边和那边河岸上有极多的树木。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 3:16; 申命记 3:17; 列王纪下 2:19–22"> 他对我说：“这些水往东部地带流去，下到亚拉巴，流入死海。这水进入停滞的海，海水就会变成淡水<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="变成淡水——或译作“被治好”；下同。">b</a></sup>。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 7:37–38; 约翰福音 6:63; 约翰福音 4:14"> 这些河水所到的任何地方，一切繁衍的活物都会存活，并且有极多的鱼；因为这些水流到哪里，哪里就变成淡水，河水所到之处的一切活物都会存活。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 4:19; 诗篇 104:25; 民数记 34:6"> 从恩盖迪到恩以革莲，都有渔夫站在岸边，到处都是晒网的地方；那里的鱼各从其类，像大海的鱼那样极其众多。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 29:23; 启示录 22:11; 耶利米书 17:6"> 但死海的沼泽和水洼没有变成淡水，它们被留下为产盐地。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 22:2; 诗篇 1:3; 耶利米书 17:8"> 在两边的河岸上将长出各样的果树。它们叶子不凋零，果实也不断绝；每月都有新结的果实，因为它们的水是从圣所流出来的。它们的果实可作食物，叶子用于医治。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西结书 48:4–6; 耶利米书 3:18; 民数记 34:2–12"> 主耶和华如此说：“你们要按着以下边界，把这地分给以色列十二支派为继业，约瑟要得双份。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 20:5–6; 创世记 12:7; 以西结书 48:29"> 你们要彼此均分这地为继业，这是我所举手起誓赐给你们祖先的；你们要抽签分得这地为继业。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数记 34:8; 以西结书 48:1"> “那地的边界如下：<br />北部疆界是从大海经由希特伦，到泽达德隘口，</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 48:1; 民数记 13:21; 撒母耳记下 8:8"> 又到哈马，比罗塔，大马士革边界和哈马边界之间的西伯莲，以及浩兰边界旁边的哈撒-哈提干。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 48:1; 民数记 34:9"> 这样，边界是从大海到大马士革的边界哈萨耶楠，北部到达哈马的边界。这是北部疆界。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="创世记 13:10; 创世记 31:23; 创世记 31:47"> 东部疆界是在浩兰和大马士革之间，基列和以色列地之间，沿着约旦河，从北界下来测量到东边的海。这是东部疆界。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西结书 48:28; 申命记 32:51; 民数记 34:5"> 南部疆界，是从塔玛尔到米利巴-加低斯水，沿着埃及河到大海。这是南部疆界。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数记 34:6; 以西结书 48:1"> 西部疆界是大海，从南界上去到哈马隘口对面。这是西部疆界。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> “你们要按着以色列的支派分配这地。</span>
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 3:11; 以弗所书 3:6; 使徒行传 11:18"> 你们要把它抽签分给自己为继业，也要分给那些寄居在你们中间、在你们中间生养儿女的外人。他们对于你们，就像以色列子孙中的本族人，要与你们一同在以色列各支派中抽签分得继业。</span>
<span className="v" id="v23" data-v="23"> 外人在哪个支派寄居，你们就要在那里分给他们继业。这是主耶和华的宣告。</span>
</div>

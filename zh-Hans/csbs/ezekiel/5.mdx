<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 7:20; 以西结书 44:20; 利未记 21:5"> “人子啊，你要拿一把锐利的刀，用它作剃头匠的剃刀，剃你的头发和胡须，然后拿一个称量的天平，均分这些毛发。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 5:12; 利未记 26:33; 以西结书 4:1–8"> 当围城的日子满了，你要取三分之一在城中用火烧掉，再取三分之一在城的四围用刀砍碎，另外三分之一任风吹散，我还要拔刀追赶它们。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 52:16; 耶利米书 40:6; 耶利米书 39:10"> 但你要从中取出几根，包在你的衣襟里，</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 4:4; 耶利米书 41:1–18; 列王纪下 25:25"> 再从这其中拿一点扔在火中，用火烧掉它们，必有火从其中出来，蔓延到以色列全家。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以西结书 4:1; 申命记 4:6; 耶利米书 6:6"> 主耶和华如此说：“这就是耶路撒冷。我把它安置在列邦中心，列国在它的四围。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 11:10; 以西结书 16:47–48; 尼希米记 9:16–17"> 它却违背我的法规，作恶超过列邦；违背我的律例，超过它四围的列国。他们实在是厌弃我的法规，不遵行我的律例！”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="耶利米书 2:10–11; 历代志下 33:9; 列王纪下 21:9–11"> 因此主耶和华如此说：“因为你们反叛超过四围的列国，不遵从我的律例，不遵行我的法规，你们甚至行不出四围列国的标准，</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 15:7; 耶利米书 24:9; 以西结书 21:3"> 所以主耶和华如此说：看哪，连我也敌对你！我必在列国眼前，在你中间施行审判。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 24:21; 但以理书 9:12; 阿摩司书 3:2"> 因你的一切可憎之事，我要在你中间施行审判，是我未曾行过，将来也不再这样行的，</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亚书 2:6; 申命记 28:64; 以西结书 12:14"> 以致在你中间，父亲将吃儿子，儿子将吃父亲。我必对你施行审判，并且把你的余剩之民全都扬散到四面的风中。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以西结书 7:20; 以西结书 7:9; 以西结书 11:18"> 因此，这是主耶和华的宣告：“我指着我的永生起誓：实在是因你用一切可憎之物、可憎之事玷污了我的圣所，所以我要剪除你<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="剪除你——或译作“远离你”、“把你剃光”。">a</a></sup>，我眼中不会顾惜，我也不会怜恤。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 5:2; 耶利米书 15:2; 耶利米书 43:10–11"> 你的三分之一将在你当中因瘟疫而死，因饥荒而灭绝；三分之一将在你四围倒在刀下；三分之一，我要扬散到四面的风中，并且拔刀追赶他们。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 1:24; 以西结书 36:5–6; 以西结书 21:17"> 这样，我的怒气就发尽了。我对他们的怒火平息，就得了安慰。当我向他们发尽怒火，他们就知道：我是耶和华，我在妒爱中发了话。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西结书 22:4; 尼希米记 2:17; 诗篇 79:1–4"> “我要在四围的列国中，在所有路过的人眼前，使你荒废，被人羞辱。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 25:17; 耶利米书 22:8–9; 列王纪上 9:7"> 当我在怒气和怒火中，在烈怒的责备中对你施行审判的时候，你必成为四围列国辱骂和讽刺的对象，成为鉴戒，令人惊骇。我耶和华已经发了话。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 4:16; 申命记 32:23–24; 以西结书 14:13"> 那时我必向你们射出致命的饥荒之箭，这是毁灭的箭，我要射出去毁灭你们；我要加重你们的饥荒，断绝你们的粮食供应。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 38:22; 以西结书 14:21; 利未记 26:22"> 我要派遣饥荒和恶兽攻击你，使你丧掉儿女。在你当中将遍布瘟疫和鲜血，我也要使刀剑临到你。我耶和华已经发了话。”</span>
</div>

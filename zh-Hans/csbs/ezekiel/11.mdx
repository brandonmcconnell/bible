<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 3:14; 以西结书 11:24; 以西结书 11:13"> 灵又把我举起，带到耶和华殿朝东的东门。看哪，在门口有二十五个人，我看见其中有阿佐尔的儿子雅撒尼亚、比纳雅的儿子皮拉提，他们是民众的首领。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 30:1; 耶利米书 5:5; 诗篇 2:1–2"> 耶和华对我说：“人子啊，这些就是谋划奸恶的人，他们在这城中策划恶谋，</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 12:27; 以西结书 12:22; 以西结书 11:7–11"> 说：‘建造房屋的时候不是临近了吗<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="不是临近了吗——或译作“还没有临近”。">a</a></sup>？这城是锅，我们是肉。’</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 20:46–47; 以西结书 21:2; 以西结书 3:2–15"> 因此你要针对他们发预言，人子啊，你要说预言！”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="耶利米书 17:10; 耶利米书 16:17; 启示录 2:23"> 耶和华的灵降临在我身上，他对我说：“你要宣告，耶和华如此说：以色列家啊，这就是你们所想的；你们心里起的意念，我都知道。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 7:23; 以西结书 22:27; 以西结书 22:12"> 你们使这城中被杀的人增多，使街道上遍满了被杀的人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以西结书 24:3–13; 弥迦书 3:2–3; 列王纪下 25:18–22"> “因此主耶和华如此说：你们所杀害堆放在城中的人，他们才是肉，这城是锅，而你们却要从其中被抛出去。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 10:24; 以赛亚书 24:17–18; 约伯记 3:25"> 你们害怕刀剑，我就使刀剑临到你们。这是主耶和华的宣告。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 5:8; 诗篇 106:41; 申命记 28:36"> 我要把你们从其中抛出去，交在外族人手里；我要对你们施行审判。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 14:25; 耶利米书 52:9–10; 列王纪下 25:19–21"> 你们必倒在刀下，我要在以色列的边境审判你们。那时你们就知道：我是耶和华。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 11:3; 以西结书 11:7–10"> 这城不会是你们的锅，你们也不会是其中的肉；我要在以色列的边境审判你们。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 8:10; 以西结书 8:16; 以西结书 8:14"> 那时你们就知道：我是耶和华。因为你们不遵从我的律例，不遵行我的法规，反而效法你们四围列国的习俗。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西结书 11:1; 以西结书 9:8; 使徒行传 5:5"> 我正说预言的时候，比纳雅的儿子皮拉提死了。我就脸伏于地，大声哀叫说：“唉，主耶和华啊！你要灭绝以色列的余剩之民吗？”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 耶和华的话语临到我，说：</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 33:24; 以赛亚书 65:5; 约翰福音 16:2"> “人子啊，论到你的兄弟，你的亲族兄弟，以及以色列全家所有的人，那些耶路撒冷的居民曾对他们说：‘你们远离耶和华吧！这地已经赐给我们为产业了。’</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 8:14; 申命记 30:3–4; 诗篇 90:1"> “因此你要说，主耶和华如此说：虽然我把他们远远赶到了列国中，虽然我把他们驱散到各地，但我会在他们所到之地作圣所，略微庇护他们。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西结书 28:25; 耶利米书 3:18; 以西结书 34:13"> “因此你要说，主耶和华如此说：我必从万民中招聚你们，把你们从被驱散到的各地聚拢起来，并将以色列地赐给你们。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以西结书 37:23; 以西结书 5:11; 以西结书 42:7–8"> “他们回到那里时，将从其中除掉一切可憎之物、一切可憎之事。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 36:26–27; 耶利米书 31:33; 诗篇 51:10"> 我要赐给他们合一的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="合一的——或译作“专一的”。">b</a></sup>心，把新的灵放在他们里面；我要从他们肉体中除掉石心，赐给他们肉心，</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 14:11; 诗篇 105:45; 耶利米书 30:22"> 好使他们顺从我的律例，谨守遵行我的法规。他们将要作我的子民，我将要作他们的神。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 9:10; 传道书 11:9; 耶利米书 1:16"> 至于那些心中随从可憎之物、可憎之事的人，我要把他们的恶行报应在他们头上。这是主耶和华的宣告。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以西结书 10:19; 以西结书 1:19–20"> 然后，基路伯扬起了翅膀，轮子都在它们旁边，以色列神的荣耀在它们上方。</span>
<span className="v" id="v23" data-v="23" data-xref="撒迦利亚书 14:4; 以西结书 8:4; 以西结书 10:4"> 耶和华的荣耀就从城中上升，停留在城东边的山上。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 3:12; 以西结书 8:3; 以西结书 11:1"> 这时，灵把我举起，在异象中藉着神的灵把我带到迦勒底，带到掳民那里，我所看见的异象就上升离开了我。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 3:4; 以西结书 3:27; 以西结书 3:17"> 于是，我把耶和华所显明给我的一切事都告诉了掳民。</span>
</div>
</div>

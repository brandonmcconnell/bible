<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话语又临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 58:1; 以西结书 24:6; 以西结书 24:9"> “人子啊，你要谴责吗？要谴责这杀人流血的城吗？你要让她知道她的一切可憎之事。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 22:27; 罗马书 2:5; 彼得后书 2:3"> 你要说，主耶和华如此说：这城中有杀人流血的事，以致她的时候来到；她还制造偶像玷污自己！</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 21:16; 诗篇 44:13–14; 以西结书 22:2"> 你因杀人流血而有了罪责，你以制造的偶像玷污了自己。你使你的日子临近，使你的年数来到。因此，我要使你被列国羞辱，被全地讽刺。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 22:2; 耶利米书 15:2–3"> 你这声名狼藉、骚乱众多的城<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="城——辅助词语。">a</a></sup>啊，无论离你近的、离你远的，都将嘲讽你！</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结书 22:27; 以赛亚书 1:23; 撒迦利亚书 3:3"> “看哪，在你那里，以色列的领袖各人依仗权势，去杀人流血。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 27:16; 出埃及记 22:21–22; 利未记 20:9"> 在你那里有人藐视父母，在你中间有人欺压寄居者，在你那里有人欺负孤儿寡妇。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 23:38–39; 以西结书 22:26; 以西结书 20:13"> 你轻视我的圣物，亵渎我的安息日。</span>
<span className="v" id="v9" data-v="9" data-xref="何西阿书 4:14; 利未记 19:16; 何西阿书 4:10"> 在你那里有人搬弄是非，为要杀人流血。在你那里有人到山上吃祭物，在你中间有人行丑恶的事。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 18:19; 利未记 18:7–8; 以西结书 18:6"> 在你那里有人裸露父亲的下体，在你那里有人玷辱经期中不洁净的女人。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 18:15; 撒母耳记下 13:14; 利未记 20:17"> 有人与邻人的妻子做可憎的事；有人玷污自己的儿媳，做了丑恶的事；在你那里有人玷辱自己的姐妹——自己父亲的女儿。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 27:25; 以西结书 23:35; 诗篇 106:21"> 在你那里有人接受贿赂杀人流血。你收取利息和厚利，欺压剥削你的邻人。你忘记了我！这是主耶和华的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西结书 21:17; 以赛亚书 33:15; 阿摩司书 2:6–8"> “所以看哪，因你获取的不义之财，因你中间的血债，我要击掌奋起。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 21:7; 以西结书 17:24; 以西结书 24:14"> 到了我对付你的日子，你的心能承受得住吗？你的手还能稳固吗？我耶和华发了话，就必成就。</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米记 1:8; 以西结书 22:22; 申命记 4:27"> 我要把你驱散到列国，扬散在各地，从你中间除尽你的污秽。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 6:7; 诗篇 83:18; 以西结书 7:24"> 你必在列邦眼前被亵渎，那时你就知道：我是耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和华的话语临到我，说：</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 119:119; 以赛亚书 1:22; 耶利米书 6:28–30"> “人子啊，以色列家对我已经成了渣滓。他们全都是熔炉中的铜、锡、铁和铅，是银子的渣滓。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 13:30; 以西结书 24:3–6; 弥迦书 4:12"> 因此主耶和华如此说：因为你们全都成了渣滓，所以看哪，我必把你们聚拢在耶路撒冷当中。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 4:11–12; 以赛亚书 54:16; 以西结书 24:13"> 人怎样把银、铜、铁、铅和锡聚拢在熔炉中，向它吹火，好使它们熔化，我也照样在怒气和怒火中把你们聚拢起来，放在城中熔化。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 64:7; 那鸿书 1:6; 诗篇 50:3"> 我必聚拢你们，把我盛怒的火吹向你们，使你们在其中熔化。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 20:8; 以西结书 20:33; 何西阿书 5:10"> 银子怎样在熔炉中熔化，你们也必怎样在城中熔化。那时你们就知道：是我耶和华向你们倾泻我的怒火。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和华的话语临到我，说：</span>
<span className="v" id="v24" data-v="24" data-xref="历代志下 36:14–16; 耶利米书 2:30; 历代志下 28:22"> “人子啊，你要对这城说：在愤怒的日子里，你是未得洁净、无雨降下之地。</span>
<span className="v" id="v25" data-v="25" data-xref="何西阿书 6:9; 耶利米书 2:34; 以西结书 13:19"> 她的众先知同谋结伙<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="众先知同谋结伙——七十士译本作“领袖们”。">b</a></sup>，在她中间好像吼叫的狮子撕咬猎物，他们吞吃人，夺取财富和宝物，使寡妇在她中间增多。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 10:10; 以西结书 44:23; 以西结书 22:8"> 她的祭司们践踏我的律法，亵渎我的圣物，不分别圣与俗，也不教导人分辨洁净的与不洁净的，并且闭眼不顾我的安息日，以致我在他们中间被亵渎。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以西结书 22:13; 以赛亚书 1:23; 以西结书 22:6"> “她当中的首领们像撕咬猎物的豺狼，杀人流血，伤害人命，为要谋取不义之财。</span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 13:6–7; 以西结书 13:10–16; 耶利米书 23:25–32"> 她的众先知用白灰为人粉饰掩盖，他们见虚假的异象，为人行虚谎的占卜，说‘主耶和华如此说’，其实耶和华并没有发话。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 22:7; 出埃及记 23:9; 出埃及记 22:21"> 这地的民众施行欺压，强取豪夺，欺负困苦人和贫穷人，非法侵夺寄居者。</span>
<span className="v" id="v30" data-v="30" data-xref="以赛亚书 59:16; 耶利米书 5:1; 诗篇 106:23"> 我在他们中间寻找人修补围墙，在我面前为这地站在破口处，使我不毁灭这地；可是，我连一个也没找到。</span>
<span className="v" id="v31" data-v="31" data-xref="以西结书 16:43; 以西结书 7:8–9; 以西结书 9:10"> 所以我要向他们倾泻我的愤怒，用我盛怒的火灭绝他们，把他们的恶行报应在他们头上。这是主耶和华的宣告。”</span>
</div>
</div>

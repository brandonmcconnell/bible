<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 43:1; 以西结书 40:17; 以西结书 42:14"> 那人又把我带回到圣所外面朝东的门，门是关着的。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 43:2–4; 出埃及记 24:10; 以赛亚书 6:1–5"> 耶和华对我说：“这门必须关着，不可打开。谁也不可从它进入，因为以色列的神耶和华已经从它进入，所以它必须关着。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 46:2; 以西结书 34:24; 以西结书 37:25"> 至于君王，唯独君王可以坐在里面，在耶和华面前吃饭。他要从这门廊的通道进入，也要从它的通道出来。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以西结书 1:28; 启示录 1:17; 以西结书 3:23"> 他又带我经由北门来到殿宇前。我观看，看哪，耶和华的荣耀充满了耶和华的殿，我就脸伏于地。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 40:4; 以西结书 43:10–11; 申命记 12:32"> 耶和华对我说：“人子啊，我要把耶和华殿所有的律例和律法都告诉你，你要留意，要用眼看、用耳听，并要留意殿宇入口和圣所各出口的规定<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="的规定——辅助词语。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结书 3:9; 以西结书 45:9; 彼得前书 4:3"> “你要对悖逆的以色列家说，主耶和华如此说：以色列家啊，你们行一切可憎之事已经够多了！</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 22:25; 耶利米书 9:26; 以西结书 44:9"> 你们献上我的食物——脂油和血时，竟然把那些心未受割礼、身体也未受割礼的外邦人带进我的圣所，以致亵渎我的殿宇；你们以你们的一切可憎之事，违背了我的约。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 44:14; 民数记 18:3–5; 以西结书 40:45–46"> 你们没有为我的圣物谨守职责，却安排外人在我的圣所代替你们值守！</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约珥书 3:17; 以西结书 44:7; 撒迦利亚书 14:21"> “主耶和华如此说：所有心未受割礼、身体也未受割礼的外邦人，包括所有在以色列子民中间的外邦人，都不可进入我的圣所。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 22:26; 以西结书 48:11; 列王纪下 23:8–9"> 至于那些利未人，他们在以色列迷失的时候也远离了我，他们竟迷失离开我，追随自己的偶像，所以他们必承担自己的罪孽。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 16:9; 历代志下 29:34; 历代志下 30:17"> 然而他们将在我的圣所作仆役，看守圣殿各门，在圣殿里作仆役。他们要为民众宰杀燔祭牲和其他祭物，要侍立在他们面前，侍候他们。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 16:10–16; 诗篇 106:26; 以西结书 14:3–4"> 因为他们曾在民众的偶像面前侍候民众，成了绊脚石，导致以色列家犯罪，因此我针对他们举手起誓：他们必承担自己的罪孽。这是主耶和华的宣告。</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 18:3; 列王纪下 23:9; 以西结书 16:61"> 他们不可近前来作我的祭司，也不可接近我的任何圣物和至圣物；他们要承受自己的羞辱，承担他们所做可憎之事的后果。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志上 23:28–32; 民数记 18:4"> 不过我要让他们谨守圣殿的职责，负责圣殿的所有劳役，以及其中要做的一切事务。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命记 10:8; 以西结书 48:11; 以西结书 44:7"> “但撒督的子孙，就是那些利未祭司，当以色列子民迷失离开我时，他们在我的圣所谨守职责，所以他们必近前来事奉我，侍立在我面前，把脂油和血献给我。这是主耶和华的宣告。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 41:22; 玛拉基书 1:12; 民数记 18:7–8"> 唯独他们可以进入我的圣所，他们可以接近我的圣桌事奉我，为我谨守职责。</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 19:8; 出埃及记 28:43; 出埃及记 39:27–29"> 他们进入内院门的时候，要穿上细麻衣服；他们在内院里或圣殿内事奉的时候，不可穿戴羊毛衣料。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 39:28; 哥林多前书 11:4–10; 以赛亚书 3:20"> 他们要头戴细麻头巾，身穿细麻裤子，不可穿戴使身体出汗的衣物。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 46:20; 利未记 6:27; 利未记 6:10–11"> 他们出去到外院<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="到外院——马索拉文本重复此短语。">b</a></sup>民众那里的时候，要脱下他们的事奉衣服，放在那些圣屋中，然后穿上别的衣服，以免民众因他们的衣服而成为祭献的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="祭献的——辅助词语。">c</a></sup>圣物。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 11:14; 民数记 6:5; 利未记 21:5–24"> “他们不可剃光头，也不可留长发，只可修剪头发。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 10:9; 提多书 1:7–8; 提摩太前书 5:23"> 任何祭司要进入内院时，都不可喝酒。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 21:7; 利未记 21:13–14; 提摩太前书 3:2"> 他们不可娶寡妇或被休的女人为妻，只可娶以色列后裔中的处女或祭司遗留的寡妇。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 22:26; 利未记 10:10–11; 提摩太后书 2:24–25"> 他们要指教我的子民区分圣与俗，辨别洁净的与不洁净的。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="历代志上 23:4; 以西结书 22:26; 历代志下 19:8–10"> “对于争讼，祭司必须受理案件，按照我的公正来审断。他们在我的各约期要谨守我的律法和律例，要把我的安息日尊为圣。</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多后书 5:16; 利未记 22:4; 马太福音 8:21–22"> 他不可到死人那里，以致玷污自己；除非那死人是他父母、儿女、兄弟和未嫁人的姐妹，他才可使自己受玷污。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 9:13–14; 民数记 19:11–14; 民数记 6:10–21"> 等他洁净之后，再给他数算七天，</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 6:9–11; 以西结书 44:17; 利未记 4:3–35"> 然后到他进入内院圣所事奉的日子，他要献上自己的赎罪祭。这是主耶和华的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约书亚记 13:33; 民数记 18:20; 申命记 18:1–2"> “有关祭司的继业，我就是他们的继业。你们不可在以色列给他们地业，我就是他们的地业。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 18:14; 利未记 27:21; 利未记 27:28"> 他们可以吃素祭、赎罪祭和赎愆祭，以色列中所有的永献之物都归属他们。</span>
<span className="v" id="v30" data-v="30" data-xref="尼希米记 10:35–37; 历代志下 31:10; 申命记 18:4"> 各样初熟之物中上好的，以及你们各样供物中上好的供物，全都归属祭司。你们也要把初熟五谷的面团带给祭司，好使祝福临到你们的家。</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 22:8; 出埃及记 22:31; 申命记 14:21"> 凡是自然死去的或被咬死的飞禽走兽，祭司都不可吃。</span>
</div>
</div>

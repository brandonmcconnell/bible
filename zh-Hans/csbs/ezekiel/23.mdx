<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话语又临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 16:44–46; 耶利米书 3:7–10"> “人子啊，有两个女子，是一母所生。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 17:7; 以西结书 16:22; 约书亚记 24:14"> 她们在埃及行淫，在年幼时行淫。在那里，人们揉搓她们的乳房，抚弄她们贞洁的双乳。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 16:8; 诗篇 76:2; 耶利米书 2:2–3"> 她们的名字，年长的是阿荷拉，妹妹是阿荷利巴。她们归属我，并且生了儿女。她们的名字，阿荷拉就是撒玛利亚，阿荷利巴就是耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="何西阿书 5:13; 列王纪下 17:3; 列王纪下 16:7"> “阿荷拉属于我却行淫，爱恋她的情人，就是那些邻邦的亚述人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="邻邦的亚述人——或译作“亚述军人”。">a</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 23:23"> 他们身穿蓝色衣服，是省长和官长，是骑马的马兵，全都是英俊的青年人。</span>
<span className="v" id="v7" data-v="7" data-xref="何西阿书 5:3; 何西阿书 6:10; 以西结书 22:3–4"> 她与那些人放纵行淫，他们都是最优秀的亚述人；她追随所爱恋的那些人和他们的一切偶像，玷污了自己。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 23:19; 以西结书 23:3; 出埃及记 32:4"> 她从不离弃她在埃及就有的淫乱，那些人在她年幼时就与她同寝，他们抚弄她贞洁的双乳，向她倾泻淫欲。</span>
<span className="v" id="v9" data-v="9" data-xref="何西阿书 11:5; 列王纪下 15:29; 列王纪下 17:23"> 因此我把她交在她情人们手中，就是她所爱恋的亚述人手中。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 23:29; 何西阿书 2:10; 耶利米书 22:8–9"> 他们裸露她的下体，掳走她的儿女，用刀剑杀戮她，以致她在女人中成为笑柄。这样，他们对她施行了审判。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米书 3:8–11; 以西结书 16:47–51; 以西结书 23:4"> “妹妹阿荷利巴看见了这一切，却比她姐姐更沉陷情欲，她的淫乱超过姐姐的淫行。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 16:7–15; 以西结书 23:23; 历代志下 28:16–23"> 她爱恋亚述人，那些省长和官长，披挂整齐的军人，骑马的马兵，他们全都是英俊的青年人。</span>
<span className="v" id="v13" data-v="13" data-xref="何西阿书 12:1–2; 列王纪下 17:18–19; 以西结书 23:31"> 我看见她玷污了自己，她们两姐妹同行一路。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 8:10; 耶利米书 22:14; 耶利米书 50:2"> 她还增加淫乱：她看见墙上雕刻的人，就是用赤红色颜料涂画的迦勒底人的像，</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 8:18; 撒母耳记上 18:4; 以赛亚书 22:21"> 腰间束带，头裹下垂的头巾，全都是军官的样子，是巴比伦人的形象，迦勒底是他们的出生地；</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 16:29; 马太福音 5:28; 约伯记 31:1"> 她一看见，就爱恋他们，派使者到迦勒底去见他们。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 23:28; 以西结书 23:22; 创世记 10:10"> 于是巴比伦人来到她那里，上了欢爱的床，以他们的淫行玷污她。她让他们玷污了自己，随后心里就厌弃他们。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 78:59; 诗篇 106:40; 耶利米书 12:8"> 她暴露自己的淫行，裸露自己的下体，因此我的心厌弃她，如同我的心厌弃她姐姐。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 23:3; 以西结书 20:7; 以西结书 16:51"> 她增多自己的淫行，怀念她年幼时在埃及地行淫的时光；</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 17:15; 以西结书 16:26; 耶利米书 5:8"> 她甘愿作他们的情妇；他们的下体如驴，精壮如马。</span>
<span className="v" id="v21" data-v="21"> 你如此眷恋你年幼时的丑恶之事，那时埃及人抚弄你的双乳，你年幼时的乳房。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以西结书 16:37; 启示录 17:16; 耶利米书 6:22–23"> “因此阿荷利巴啊，主耶和华如此说：看哪，我必挑动你心里厌弃的情人们攻击你。我要使他们前来，从四围攻击你。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 50:21; 列王纪下 24:2; 列王纪下 20:14–17"> 他们是巴比伦人和所有的迦勒底人，比割人、书亚人、哥亚人，以及所有与他们在一起的亚述人；他们全都是英俊的青年人，是省长和官长、军官和名人，全都骑着骏马。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 24:14; 以西结书 26:10; 以西结书 23:45"> 他们将带着兵器、战车、攻城车，带着各民族的军队来攻击你；他们装备大小盾牌和头盔，从四围攻击你。我要把裁决权赐给他们，他们必以自己的裁决来审判你。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 23:47; 以西结书 8:1–18; 以西结书 15:6–7"> 我要使我的妒火临到你，他们必在愤怒中处治你。他们将割掉你的鼻子和耳朵，你残留的人将倒在刀下；他们将掳走你的儿女，你残留的人将被烈火吞噬；</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 16:39; 耶利米书 13:22; 以西结书 23:29"> 他们将剥去你的衣服，掳走你荣美的器物。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 16:41; 以西结书 23:3; 以西结书 23:19"> 这样，我使你的丑恶和你在埃及地就开始的淫行终止，你就不再仰望他们，不再思念埃及了。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以西结书 23:22; 以西结书 23:17; 耶利米书 34:20"> “是的，主耶和华如此说：看哪，我必把你交在你所厌恶、你心里厌弃的人手中。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 16:39; 以西结书 23:25–26; 以西结书 23:45–47"> 他们将以仇恨对待你，掳走你的一切辛苦所得，留下你赤身露体，以致你淫乱的下体、你的丑恶和淫行暴露出来。</span>
<span className="v" id="v30" data-v="30" data-xref="以西结书 6:9; 诗篇 106:35–38; 耶利米书 2:18–20"> 你遭遇这些，是因你随从列邦行淫，你以他们的偶像玷污自己。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 21:13; 耶利米书 7:14–15; 以西结书 16:47–51"> 你走了你姐姐的道路，所以我要把她的杯放在你手中。</span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 51:17; 诗篇 60:3; 以西结书 22:4–5"> “主耶和华如此说：<br /><span className="pl pl-1">你必喝你姐姐的杯，它又深又广，</span><br /><span className="pl pl-1">这杯盛满了讥讽和嘲笑，</span><br /><span className="pl pl-1">容量极大。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 51:17; 耶利米书 25:27; 耶利米书 25:15–16"> <span className="pl pl-1">你将酩酊大醉，充满悲哀，</span><br /><span className="pl pl-1">这是惊骇、荒凉之杯，</span><br /><span className="pl pl-1">是你姐姐撒玛利亚的杯。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 75:8; 以赛亚书 51:17; 启示录 18:7"> <span className="pl pl-1">你将喝这杯，一滴不剩，</span><br /><span className="pl pl-1">甚至啃舔杯子的碎片，</span><br /><span className="pl pl-1">撕扯自己的乳房。</span><br /><span className="pl pl-1">是的，我已经发了话。</span><br /><span className="pl pl-1">这是主耶和华的宣告。</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="列王纪上 14:9; 以赛亚书 17:10; 耶利米书 32:33"> “因此主耶和华如此说：因为你忘记了我，把我撇弃在背后，所以你也必承担你丑恶之事和你淫行的后果。”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以西结书 22:2; 以赛亚书 58:1; 以西结书 16:2"> 耶和华又对我说：“人子啊，你要谴责阿荷拉和阿荷利巴吗？你要向她们指出她们的可憎之事：</span>
<span className="v" id="v37" data-v="37" data-xref="以西结书 16:36; 耶利米书 32:35; 耶利米书 7:31"> 她们通奸，并且手中有血债。她们与她们的偶像通奸，还把为我所生的儿女经火献给偶像为食物。</span>
<span className="v" id="v38" data-v="38" data-xref="以西结书 20:13; 列王纪下 21:7; 以西结书 7:20"> 她们甚至对我做了这样的事：在同一天玷污我的圣所，亵渎我的安息日；</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪下 21:4; 以西结书 44:7; 耶利米书 23:11"> 她们宰杀儿女给她们的偶像，又在同一天进入我的圣所，亵渎了它。看哪，她们就是这样在我的殿宇中行事！</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="列王纪下 9:30; 耶利米书 4:30; 以西结书 16:13–16"> “她们还派使者去请人从远方来，使者被派去，看哪，他们就来了。为这些人，你洗澡，涂眼影，佩戴妆饰，</span>
<span className="v" id="v41" data-v="41" data-xref="以斯帖记 1:6; 耶利米书 44:17; 以赛亚书 65:11"> 坐在华美的床榻上，有桌子摆在床榻前，你把我的香料和膏油放在其上。</span>
<span className="v" id="v42" data-v="42" data-xref="以西结书 16:11–12; 启示录 12:3; 出埃及记 32:18–19"> 那里传出安乐喧嚣的声音，有杂乱的人群，从旷野请来的酒徒<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="酒徒——或译作“示巴人”。">b</a></sup>。那些人把镯子戴在她们手上，把华冠戴在她们头上。</span>
<span className="v" id="v43" data-v="43" data-xref="以西结书 23:3; 耶利米书 13:23; 以斯拉记 9:7"> 那时我论到这因通奸而衰残的妇人说：‘她都这样了，他们还与她犯奸淫！’</span>
<span className="v" id="v44" data-v="44" data-xref="以西结书 23:9–13; 以西结书 23:3"> 他们与她同寝，如同与妓女同寝。他们就是这样与丑恶的女人阿荷拉和阿荷利巴同寝！</span>
<span className="v" id="v45" data-v="45" data-xref="何西阿书 6:5; 利未记 20:10; 以西结书 23:36–39"> 但那些行公义的人，必以淫妇之罪和杀人流血之罪来审判她们；因为她们就是淫妇，并且手中有血债。”</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="以西结书 16:40; 耶利米书 15:4; 耶利米书 24:9"> 是的，主耶和华如此说：“召集队伍上去攻击她们吧，使她们成为掠物，令人战兢。</span>
<span className="v" id="v47" data-v="47" data-xref="以西结书 16:40–41; 耶利米书 39:8; 以西结书 24:21"> 这队伍将用石头砸死她们，用刀剑砍杀她们，杀掉她们的儿女，放火烧掉她们的房屋。</span>
<span className="v" id="v48" data-v="48" data-xref="以西结书 6:6; 以西结书 23:27; 以西结书 16:41"> 这样，我就使丑恶之事从这地上终止，所有的女人都会受到警诫，不会效法你们的淫行。</span>
<span className="v" id="v49" data-v="49" data-xref="以西结书 9:10; 以西结书 7:4; 以西结书 6:7"> 他们将把你们丑恶的事报应在你们身上，你们必承担你们拜偶像的罪责。那时你们就知道：我是主耶和华。”</span>
</div>

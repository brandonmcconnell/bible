<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 3:22; 以西结书 1:3; 使徒行传 8:39"> 耶和华的手临到我身上，耶和华藉着他的灵把我带出去，安置在平原中间，这平原遍满骸骨。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 141:7; 以西结书 37:11; 申命记 11:30"> 他使我在骸骨之间四处巡行，看哪，它们在平原上极其众多，看上去极其枯干。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 11:25–26; 约翰福音 5:21; 申命记 32:39"> 他问我：“人子啊，这些骸骨能活过来吗？”<br />我说：“主耶和华啊，你知道。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰福音 5:25; 约翰福音 5:28–29; 马太福音 21:21"> 他对我说：“你要向这些骸骨发预言，对他们说：枯干的骸骨啊，你们要听耶和华的话语！</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 37:14; 诗篇 104:29–30; 创世记 2:7"> 主耶和华对这些骸骨如此说：看哪，我将要使气息<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="气息——或译作“灵”；本章下同。">a</a></sup>进入你们里面，你们必活过来。</span>
<span className="v" id="v6" data-v="6" data-xref="约珥书 2:27; 以赛亚书 49:23; 约珥书 3:17"> 我要给你们加上筋，附上肉，覆盖上皮肤，然后使气息进入你们里面，你们就会活过来。那时你们就知道：我是耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行传 2:2; 列王纪上 19:11–13; 耶利米书 13:5–7"> 于是我照着所受的吩咐说预言。当我说预言的时候，有声音，看哪，是地震！骨头就合拢，骨头连接骨头。</span>
<span className="v" id="v8" data-v="8"> 我观看，看哪，骸骨上面有筋，也附上了肉，又有皮肤覆盖在上面，只是他们里面还没有气息。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 3:8; 雅歌 4:16; 诗篇 104:30"> 他对我说：“你向气息发预言吧，人子啊，你要向气息发预言说，主耶和华如此说：气息啊，从四方而来，吹进这些死人里面，使他们活过来！”</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 11:11; 诗篇 104:30; 启示录 20:4–5"> 于是我照着他所吩咐我的说预言。气息就进入他们里面，他们活了过来，双脚站立，成为极其庞大的军队。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以弗所书 2:1; 诗篇 77:7–9; 以西结书 39:25"> 他对我说：“人子啊，这些骸骨就是以色列全家。看哪，他们常说：‘我们的骨头枯干了，我们的希望破灭了，我们被剪除了！’</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 26:19; 何西阿书 13:14; 帖撒罗尼迦前书 4:16"> 因此你要发预言，对他们说，主耶和华如此说：我的子民哪，看，我必打开你们的坟墓，把你们从坟墓里带上来，把你们带回以色列地。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 37:6; 以西结书 16:62; 诗篇 126:2–3"> 我的子民哪，当我打开你们的坟墓，把你们从坟墓里带上来时，你们就知道：我是耶和华。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 36:27; 约珥书 2:28–29; 以西结书 36:36"> 我要使我的气息进入你们里面，使你们活过来；我要使你们在你们土地上安居。那时你们就知道：我耶和华发了话，就必成就。这是耶和华的宣告。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 耶和华的话语又临到我，说：</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 15:9; 历代志下 10:19; 历代志下 10:17"> “人子啊，你要取一根木杖，在它上面写下‘犹大和他的同伴以色列人’；再取一根木杖，在它上面写下‘约瑟——以法莲的杖——和他的同伴以色列全家’。</span>
<span className="v" id="v17" data-v="17" data-xref="何西阿书 1:11; 耶利米书 50:4; 以赛亚书 11:13"> 你要使它们彼此合拢，成为一根杖，在你手中合而为一。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 24:19; 以西结书 12:9; 以西结书 17:12"> 当你的同胞问你说：‘能不能告诉我们，你这是什么意思？’</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 10:6; 以西结书 37:16–17; 以弗所书 2:13–14"> 你要对他们说，主耶和华如此说：看哪，我要拿起约瑟的杖，就是以法莲和他同伴以色列众支派手中的杖，与犹大的杖放在一起，使它们成为一根杖，在我手中合而为一。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西结书 12:3; 民数记 17:6–9; 何西阿书 12:10"> “那时，你要在他们眼前，把你写上字的两根木杖拿在手中，</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 36:24; 耶利米书 29:14; 耶利米书 23:8"> 对他们说，主耶和华如此说：看哪，我必把以色列子孙从他们所到的列国中带出来，把他们从四方招聚起来，带回他们的土地。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 37:24; 以西结书 34:23–24; 耶利米书 3:18"> 我要使他们在那地，在以色列的群山上成为一国，有一位王作他们全体的王；他们再不会是两个国家，再不会分成两个王国。</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 21:3–4; 以西结书 36:28–29; 约翰一书 1:9"> 他们再也不会以偶像和可憎之物，以及他们的一切过犯而玷污自己；我必把他们从所犯的一切背道之罪中<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="所犯的一切背道之罪中——依据七十士译本；马索拉文本为“犯罪的一切居住之处”。">b</a></sup>拯救出来，洁净他们。他们将要作我的子民，我将要作他们的神。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 34:23–24; 何西阿书 3:5; 以西结书 37:25"> 我的仆人大卫是他们的王，他们全都归属一个牧人。他们将遵从我的法规，谨守遵行我的律例。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="阿摩司书 9:15; 以西结书 37:24; 以西结书 28:25"> “他们必居住在我赐给我仆人雅各的土地上，就是你们祖先所居住的那地。他们和他们的孩子、子子孙孙，都将居住在其上，直到永远。我的仆人大卫是他们的君王，直到永远。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 55:3; 耶利米书 30:19; 以西结书 34:25"> 我要与他们立平安的约，是我与他们永远的约。我要使他们安居，人数增多；我要把我的圣所永远设立在他们中间。</span>
<span className="v" id="v27" data-v="27" data-xref="启示录 21:3; 约翰福音 1:14; 以西结书 37:23"> 我的居所要在他们中间，我将要作他们的神，他们将要作我的子民。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 17:17–19; 以西结书 20:12; 出埃及记 31:13"> 当我的圣所永远在他们中间时，列国就知道：我是把以色列分别为圣的耶和华。”</span>
</div>
</div>

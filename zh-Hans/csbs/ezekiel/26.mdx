<span className="v" id="v2" data-v="2" data-xref="以赛亚书 23:1–18; 以西结书 36:2; 约珥书 3:4"> “人子啊，因为提尔对耶路撒冷说‘啊哈！这列邦之门已经被摧毁，被我取代了！它荒废了，我将富足’，</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 51:42; 以赛亚书 5:30; 弥迦书 4:11"> 因此主耶和华如此说：提尔啊，看哪，我敌对你！我要使许多国家上来攻打你，就如海洋使波涛涌上来。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 23:11; 阿摩司书 1:10; 以西结书 26:9"> 他们将摧毁提尔的城墙，拆掉它的塔楼。我要刮净它的尘土，使它成为光秃秃的岩石。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 29:19; 以西结书 27:32; 以西结书 25:7"> 它必在海中成为一个晒网的地方；是的，我已经发了话。这是主耶和华的宣告。它必成为列国的掠物，</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 16:46; 以西结书 26:8; 耶利米书 49:2"> 它陆地上的居民必遭刀剑杀戮。那时他们就知道：我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 7:12; 但以理书 2:37; 以西结书 23:24"> “是的，主耶和华如此说：看哪，我要使王中之王巴比伦王尼布甲尼撒从北方来到提尔，带着马匹、战车、马兵，那是许多民族的军队。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 21:22; 耶利米书 52:4; 耶利米书 32:24"> 他将用刀剑杀戮你陆地上的居民，建造高台、筑起土垒攻击你，举起盾牌攻击你，</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 26:15"> 架起攻城锤撞击你的城墙，用武器摧毁你的塔楼。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 26:15; 以西结书 27:28; 耶利米书 47:3"> 他的马匹成群结队，扬起尘土遮蔽你。他将进入你的城门，如同进入已攻破的城；那时你的城墙必因马兵、攻城车和战车的声音而震动。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 5:28; 以赛亚书 26:5; 哈巴谷书 1:8"> 他的马蹄将踩踏你所有的街道，他的刀剑将杀戮你的居民，你那些稳固的神柱必倒在地上。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 23:8; 历代志下 32:27; 撒迦利亚书 9:3–4"> 他们将掳掠你的财富，掠夺你的货物，摧毁你的城墙，拆毁你华美的房屋，把你的石头、木头和灰泥抛在水中。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 7:34; 以赛亚书 23:16; 以赛亚书 14:11"> 我要使你歌唱的喧嚣止息，你竖琴的声音不再被听见。</span>
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 1:4; 约伯记 12:14; 民数记 23:19"> 我要使你成为光秃秃的岩石，你必成为一个晒网的地方。你必不得重建，因为我耶和华已经发了话。这是主耶和华的宣告。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="以西结书 27:35; 耶利米书 49:21; 以西结书 26:18"> “主耶和华对提尔如此说：当你中间遭遇杀戮，受伤的人呻吟时，众海岛难道不会因你倾覆的声音而震动吗？</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 32:10; 约拿书 3:6; 约伯记 8:22"> 那时所有沿海的君王都将从宝座上下来，脱去外袍，脱下彩衣。他们将以恐慌为衣，坐在地上，时刻战兢，因你而惊恐。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 14:12; 以西结书 19:1; 撒母耳记下 1:25–27"> 他们将为你吟唱哀歌，对你说：<br /><span className="pl pl-1">‘这坐落在海边，受称赞的城啊，</span><br /><span className="pl pl-1">你怎么灭亡了呢？</span><br /><span className="pl pl-1">你曾是海上的强者，</span><br /><span className="pl pl-1">你和你的居民</span><br /><span className="pl pl-1">使其他所有的居民都惊恐。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 26:15; 以赛亚书 23:5–7; 以西结书 27:35"> <span className="pl pl-1">如今众海岛在你倾覆的日子战兢，</span><br /><span className="pl pl-1">海洋中的众海岛</span><br /><span className="pl pl-1">因你消逝而惶恐。’</span></span>

<span className="v" id="v20" data-v="20" data-xref="诗篇 27:13; 路加福音 10:15; 撒迦利亚书 2:8"> 我要使你与下阴坑的人一起下去，到古时的人那里。我要使你与下阴坑的人一起居住在地府，就是那从古时就有的废墟，以致你那里无人居住，你在活人之地再无荣耀<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="你在活人之地再无荣耀——或译作“我却要在活人之地赐下荣耀”。">c</a></sup>。</span>

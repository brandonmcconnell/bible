<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话语临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 49:1–6; 阿摩司书 1:13–15; 以西结书 6:2"> “人子啊，你要面向亚扪人，针对他们发预言。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 36:2; 诗篇 70:2–3; 箴言 17:5"> 要对亚扪人说：你们当听主耶和华的话语！主耶和华如此说：我的圣所被亵渎，以色列地变得荒凉，犹大家被掳去时，你竟然说‘啊哈’，</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 28:33; 士师记 6:33; 列王纪上 4:30"> 所以看哪，我必把你交给东方人为产业。他们将在你那里设立营寨，建造居所；他们将吃你的果实，喝你牛羊的奶。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 21:20; 撒母耳记下 12:26; 以赛亚书 17:2"> 我要使拉巴成为骆驼的牧场，使亚扪人之地成为羊群躺卧之处。那时你们就知道：我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="西番雅书 2:8; 俄巴底亚书 1:12; 西番雅书 2:10"> “是的，主耶和华如此说：因为你击掌顿足，对以色列地幸灾乐祸，满心恨恶，</span>
<span className="v" id="v7" data-v="7" data-xref="西番雅书 1:4; 以西结书 25:16; 以西结书 6:14"> 所以看哪，我必伸手攻击你，把你交给万国为掠物。我要从万民中剪除你，从列国中消灭你；我必除灭你。那时你就知道：我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 15:1–9; 耶利米书 25:21; 耶利米书 48:1–47"> “主耶和华如此说：因为摩押和西珥说‘看哪，犹大家与列国没有什么不同’，</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 48:23; 约书亚记 13:17; 约书亚记 13:19–20"> 所以看哪，我必从摩押边界的各城，就是从那地所夸耀的伯耶西莫、巴力梅翁和基列亭，破开摩押的侧翼。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 21:32; 诗篇 83:3–6; 以西结书 25:4"> 我要把它连同亚扪人交给东方人为产业，使亚扪人在列国中不再被记念。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 35:15; 以西结书 30:19; 诗篇 149:7"> 我要对摩押施行审判，那时他们就知道：我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米书 49:7–22; 以西结书 25:8; 诗篇 137:7"> “主耶和华如此说：因为以东向犹大家施行报复，他们报复犹大家而有了极大的罪责，</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 29:8; 玛拉基书 1:3–4; 耶利米书 25:23"> 所以主耶和华如此说：我必伸手攻击以东，从其中剪除人和牲畜，我要使它成为废墟。他们将倒在刀下，从提幔直到底但。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 11:14; 创世记 27:29; 希伯来书 10:30–31"> 我要藉着我子民以色列的手报复以东，他们必照着我的怒气和怒火处治以东。那时以东人就知道，这是我的报复。这是主耶和华的宣告。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西结书 25:6; 以赛亚书 14:29–31; 以西结书 25:12"> “主耶和华如此说：因为非利士人报复犹大家，满心恨恶施行报复，带着世代的仇恨要毁灭他们，</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 30:14; 西番雅书 2:4–15; 以西结书 25:13"> 所以主耶和华如此说：看哪，我必伸手攻击非利士人，我要剪除基利提人，消灭沿海一带余剩的居民。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 25:11; 以西结书 25:14; 以西结书 5:15"> 我要发烈怒责罚他们，向他们施行极大的报复。当我报复他们时，他们就知道：我是耶和华。”</span>
</div>

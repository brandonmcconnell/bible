<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 66:23; 以西结书 44:1–2; 出埃及记 20:9"> “主耶和华如此说：内院朝东的门，六天工作日都要关着，但在安息日要打开，在新月节那天也要打开。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 44:3; 以西结书 46:8; 历代志上 29:10–12"> 那时君王要由这门廊的通道从外面进来，站在门柱旁边。祭司们要献上他的燔祭和平安祭，然后他就在门槛那里下拜，随后出去。这门傍晚之前不可关上。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:10; 约翰福音 10:9; 希伯来书 10:19–22"> 安息日和新月节，这地的民众要在这门口，在耶和华面前下拜。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以西结书 45:17; 民数记 28:9–10"> “君王在安息日要向耶和华献上的燔祭，是六只无瑕疵的公羊羔和一只无瑕疵的公绵羊。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 45:24; 以西结书 46:7; 申命记 16:17"> 至于素祭，是每只公绵羊配上一伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一伊法——相当于22公升；下同。">a</a></sup>细面；为公羊羔配上的素祭，可量力而献；每一伊法细面要配上一欣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一欣——相当于3.7公升；下同。">b</a></sup>油。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 46:1"> 在新月节那天，君王要献上一头无瑕疵的公牛，还有六只公羊羔和一只公绵羊，都是无瑕疵的。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 46:5"> 他还要献上素祭，每头公牛配上一伊法细面，每只公绵羊配上一伊法细面；为公羊羔配上的素祭，是量力而献；每一伊法细面要配上一欣油。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 46:2; 以西结书 44:1–3; 歌罗西书 1:18"> 君王进入的时候，要从这门廊的通道进入，也从这通道出来。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命记 16:16; 出埃及记 23:14–17; 彼得后书 2:20–21"> “这地的民众在各约期来到耶和华面前时，那些从北门进来下拜的要从南门出去，从南门进来的要从北门出去；不可从原来进入的门返回，而是要从对面的门出去。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 42:4; 历代志上 29:20; 历代志上 29:22"> 他们进来时，君王也与他们一同进来；他们出去时，他也出去。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 46:5; 以西结书 46:7; 民数记 15:1–41"> 各节期、各约期中的素祭，是每头公牛配上一伊法细面，每只公绵羊配上一伊法细面；为公羊羔配上的素祭，可量力而献；每一伊法细面要配上一欣油。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西结书 46:1–2; 以西结书 45:17; 以西结书 44:3"> “当君王向耶和华献上甘心祭，就是甘心奉献的燔祭或平安祭时，要为君王打开朝东的门。他要像在安息日献祭那样，献上他的燔祭和平安祭，然后出去。他出去之后，门要关上。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 50:4; 约翰福音 1:29; 出埃及记 12:5"> “君王<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="君王——原文直译“你”。">c</a></sup>每天要向耶和华献上一只无瑕疵的一岁公羊羔为燔祭，在每天早晨献上它。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 28:5"> 也要在每天早晨献上同献的素祭，就是六分之一伊法<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="六分之一伊法——相当于3.6公升。1伊法=22公升。">d</a></sup>细面，并用三分之一欣<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="三分之一欣——相当于1.2公升。1欣=3.7公升。">e</a></sup>油来调和细面。这是归于耶和华的素祭，要作为永远的律例，一直持守。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 10:1–10; 民数记 28:6; 出埃及记 29:42"> 每天早晨都要这样献上公羊羔、素祭和油，这是常献的燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志下 21:3; 加拉太书 4:7; 创世记 25:5–6"> “主耶和华如此说：如果君王把地业<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="把地业——辅助词语。">f</a></sup>赏赐给了他任何一个儿子，那就是他儿子的继业，归属他的儿子，是他们所继承的地业。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 25:10; 路加福音 19:25–26; 加拉太书 4:30–31"> 如果他把继业之地赏赐给了他任何一个臣仆，这地就归属那臣仆直到自由年，然后要归还给君王。他的继业只能是他儿子们的，要归属他们。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 45:8; 列王纪上 21:19; 以西结书 22:27"> 君王不可夺取民众的继业之地，使他们被迫离开自己的地业。他要从自己的地业中分给他儿子们继业，免得我的子民离散，各人离开自己的地业。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西结书 42:9; 以西结书 44:4–5; 以西结书 40:44–46"> 那人又带我从东门旁边的入口来到北面祭司们的圣屋那里。看哪，在圣屋西边的尽头有一个场地。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 35:13; 以西结书 44:29; 以西结书 44:19"> 他对我说：“这是祭司们煮赎愆祭、赎罪祭以及烤素祭的地方，以免祭物被带到外院去，使民众成为祭献的<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="祭献的——辅助词语。">g</a></sup>圣物。”</span>
<span className="v" id="v21" data-v="21"> 他又带我出来到外院，让我经过外院的四个角落。看哪，这个角落有一个小院子，那个角落也有一个小院子；</span>
<span className="v" id="v22" data-v="22"> 外院的四个角落都有小院子<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="小院子——依据七十士译本；或译作“围起来的院子”。">h</a></sup>，每个长四十肘<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="四十肘——相当于21.2公尺。">i</a></sup>，宽三十肘<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="三十肘——相当于15.9公尺。">j</a></sup>，四个角落的院子尺寸都一样。</span>
<span className="v" id="v23" data-v="23"> 这四个院子里面的四围都有一排廊房，四围的廊房下面建造了一些炉灶。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 46:20; 约翰福音 21:15–17; 彼得前书 5:2"> 他对我说：“这些是厨房，圣殿仆役要在那里烤煮民众的祭物。”</span>
</div>
</div>

<span className="v" id="v1" data-v="1"> 耶和华的话语又临到我，说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 19:1; 耶利米书 9:10; 以西结书 28:12"> “人子啊，你要为提尔吟唱哀歌，</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 27:4; 以赛亚书 23:11; 以赛亚书 23:2–3"> 要对那居住在入海口、与许多海岛上的民众通商的提尔说，主耶和华如此说：<br /><span className="pl pl-1">提尔啊，你曾说：</span><br /><span className="pl pl-1">‘我全然美丽！’</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 26:5"> <span className="pl pl-1">你的边界在海洋中心，</span><br /><span className="pl pl-1">那些建造你的使你全然美丽。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="申命记 3:9; 以赛亚书 14:8; 雅歌 4:8"> <span className="pl pl-1">他们用示尼珥的松树</span><br /><span className="pl pl-1">为你造所有的木板，</span><br /><span className="pl pl-1">取来黎巴嫩的香柏树为你制作桅杆，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="创世记 10:4; 以赛亚书 2:13; 撒迦利亚书 11:2"> <span className="pl pl-1">用巴珊的橡树制作你的船桨，</span><br /><span className="pl pl-1">用基提</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="基提——就是塞浦路斯。">a</a></sup><br /><span className="pl pl-1">众海岛的丝柏木镶嵌象牙</span><br /><span className="pl pl-1">制作你的甲板。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 10:9; 出埃及记 25:4; 创世记 10:4"> <span className="pl pl-1">你的船帆用埃及的白细麻刺绣制作，</span><br /><span className="pl pl-1">成为你的旗帜；</span><br /><span className="pl pl-1">你的船篷</span><br /><span className="pl pl-1">用以利沙众海岛</span><br /><span className="pl pl-1">蓝色和紫色的布做成。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="创世记 10:18; 列王纪上 9:27; 以西结书 27:11"> <span className="pl pl-1">西顿和亚发的居民是你的桨手；</span><br /><span className="pl pl-1">提尔啊，你那里有智慧人，</span><br /><span className="pl pl-1">他们是你的舵手；</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 5:18; 约书亚记 13:5; 诗篇 83:7"> <span className="pl pl-1">你那里有迦巴勒的老师傅和巧匠，</span><br /><span className="pl pl-1">为你修补破损处。</span><br /><span className="pl pl-1">你那里有海上</span><br /><span className="pl pl-1">各处的船只和他们的水手，</span><br /><span className="pl pl-1">贩卖你的商品。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 38:5; 以西结书 30:5; 以赛亚书 66:19"> <span className="pl pl-1">波斯、吕底亚、普特</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="普特——指利比亚。">b</a></sup><br /><span className="pl pl-1">人</span><br /><span className="pl pl-1">在你军队中作战士，</span><br /><span className="pl pl-1">他们在你中间挂起盾牌和头盔，</span><br /><span className="pl pl-1">彰显你的威荣；</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 27:3–4"> <span className="pl pl-1">亚发人和赫勒克人</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="赫勒克人——或译作“你的军兵”。">c</a></sup><br /><span className="pl pl-1">在你四围的城墙上，</span><br /><span className="pl pl-1">加玛德人</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="加玛德人——或译作“勇士”。">d</a></sup><br /><span className="pl pl-1">在你的塔楼上，</span><br /><span className="pl pl-1">他们都把盾牌挂在你四围的城墙上；</span><br /><span className="pl pl-1">他们使你全然美丽。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="创世记 10:4; 以赛亚书 23:10; 以西结书 38:13"> “塔尔施因你各样的财物众多，就与你做买卖，用银、铁、锡、铅交换你的货物。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 10:2; 以赛亚书 66:19; 以西结书 39:1"> 雅完人<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="雅完人——指希腊人；下同。">e</a></sup>、图巴人、米设人都与你交易，用人口和铜器交换你的商品。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 10:3; 以西结书 38:6; 历代志上 1:6"> 伯陀伽玛的人用马匹、战马和骡子交换你的货物。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 10:7; 启示录 18:12; 列王纪上 10:22"> 底但人与你交易，众多海岛是你掌控的码头<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="码头——或译作“市场”。">f</a></sup>，他们以象牙和乌木偿付你的货款。</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 10:6; 以西结书 28:13; 撒母耳记下 10:6"> 以东人<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="以东人——依据有些古抄本；传统译法作“亚兰人”。">g</a></sup>因你的产品众多，就与你做买卖，用绿松石、紫色布、刺绣、细麻布、珊瑚和红宝石交换你的货物。</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 11:33; 列王纪上 5:9; 耶利米书 8:22"> 犹大和以色列地的人与你交易，用米尼特的小麦，以及饼、蜂蜜、油和乳香交换你的商品。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 7:8; 创世记 15:2; 以西结书 47:16–18"> 大马士革因你的产品众多，因你各样的财物众多，就用赫尔邦的酒和扎哈尔的羊毛与你做买卖。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 30:23–24; 诗篇 45:8; 雅歌 4:13–14"> 威但人和来自乌萨的雅完人交换你的货物，你的商品中有精铁、桂皮和菖蒲。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 25:3; 以西结书 27:15"> 底但人用马鞍垫子与你交易。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 60:7; 创世记 25:13; 列王纪上 10:15"> 阿拉伯人和基达所有的领袖是你手下的商人，用羊羔、公绵羊和公山羊与你做买卖。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 10:7; 以赛亚书 60:6; 诗篇 72:10"> 示巴和拉玛的客商都与你交易，用各种上等的香料、各种宝石以及金子交换你的货物。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 19:12; 以赛亚书 37:12; 阿摩司书 1:5"> 哈兰人、肯尼人、伊甸人、示巴的客商、亚述人、基抹人与你交易，</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪下 2:8"> 他们在你的市场上，用精美的衣服、刺绣的蓝色袍子，以及绳索紧紧捆扎的华丽地毯，与你交易。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 2:16; 诗篇 48:7; 以赛亚书 23:14"> 塔尔施的船只运载你的商品。<br /><span className="pl pl-1">你富足了，在海洋中心极其繁华。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 48:7; 以西结书 26:19; 使徒行传 27:14"> <span className="pl pl-1">你的桨手把你带到大水上，</span><br /><span className="pl pl-1">东风在大海深处摧毁你。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 11:4; 以西结书 27:24; 以西结书 27:12"> <span className="pl pl-1">在你倾覆的日子里，</span><br /><span className="pl pl-1">你的财物、货物、商品，</span><br /><span className="pl pl-1">你的水手、舵手、维修工，</span><br /><span className="pl pl-1">贩卖你商品的人，</span><br /><span className="pl pl-1">以及你船上的所有战士，</span><br /><span className="pl pl-1">都将随着你的全军沉入大海深处。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="以西结书 26:10; 出埃及记 15:14; 以西结书 31:16"> <span className="pl pl-1">因你舵手的哀叫声，四野震动。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 26:16; 以西结书 32:10; 启示录 18:17–24"> <span className="pl pl-1">所有的摇桨者、水手，</span><br /><span className="pl pl-1">海上所有的舵手，</span><br /><span className="pl pl-1">都将从船上下来，</span><br /><span className="pl pl-1">站在陆地上。</span><br /></span>

<span className="v" id="v31" data-v="31" data-xref="以西结书 7:18; 以赛亚书 22:12; 以赛亚书 15:2"> <span className="pl pl-1">他们将为你剃光头发，</span><br /><span className="pl pl-1">束上麻布，</span><br /><span className="pl pl-1">为你痛心哭泣，痛苦哀号。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="以西结书 26:17; 启示录 18:18; 以西结书 27:2"> <span className="pl pl-1">他们将在哀号中向你吟唱哀歌，</span><br /><span className="pl pl-1">为你哀唱说：</span><br /><span className="pl pl-1">‘有谁像提尔，</span><br /><span className="pl pl-1">在海中死寂无声呢？</span><br /></span>

<span className="v" id="v34" data-v="34" data-xref="以西结书 27:26–27; 撒迦利亚书 9:3–4; 以西结书 26:19–21"> <span className="pl pl-1">但你在水深处被海洋摧毁的时候，</span><br /><span className="pl pl-1">你的商品和你中间所有的队伍，</span><br /><span className="pl pl-1">都沉下去了！</span><br /></span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 10:9–10; 以西结书 3:17–21; 以西结书 2:8–9"> 他对我说：“人子啊，吃下你所看到的，吃下这书卷，然后你要去，向以色列家宣讲。”</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 25:17; 使徒行传 26:19"> 我张开口，他就使我吃下这书卷，</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 15:16; 启示录 10:9–10; 诗篇 119:103"> 并对我说：“人子啊，把我给你的这书卷吃到肚子里，充满你的肚腹。”我吃了，这书卷在我口中甘甜如蜜。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="马太福音 10:5–6; 使徒行传 1:8; 以西结书 2:3"> 他对我说：“人子啊，去吧，你到以色列家去，把我的话告诉他们。</span>
<span className="v" id="v5" data-v="5" data-xref="约拿书 1:2; 以赛亚书 33:19; 约拿书 3:2–4"> 你被派遣，并不是到口齿含混、语言难懂的民族中，而是到以色列家去。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 11:20–24; 罗马书 9:30–33; 约拿书 3:5–10"> 你不是到口齿含混、语言难懂的众多民族中去，他们的话你听不懂——其实我如果派你到他们那里，他们倒会听从你！</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 10:16; 以西结书 2:4; 撒母耳记上 8:7"> 但以色列家却不愿听从你，因为他们向来不愿听从我，以色列全家实在是额坚心硬的。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 1:18; 使徒行传 7:51–56; 弥迦书 3:8"> 看哪，我要使你的脸像他们的脸一样刚硬，使你的额头像他们的额头一样坚硬。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 2:6; 耶利米书 1:8; 以赛亚书 50:7"> 我要使你的额头如金刚石，比燧石还坚硬。你不要怕他们，也不要因他们的脸色而丧胆，他们实在是悖逆之家！”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="诗篇 119:11; 约伯记 22:22; 以西结书 3:1–3"> 他又对我说：“人子啊，我对你说的一切话，你都要记在心里、听到耳中。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 2:7; 以西结书 3:27; 以西结书 33:30"> 你去吧，到被掳的同胞那里去！无论他们听还是不听，你都要向他们宣讲，对他们说：‘主耶和华如此说。’”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西结书 8:3; 使徒行传 8:39; 以西结书 11:1"> 然后灵把我举起，我听见身后有巨大的轰鸣声，耶和华的荣耀从他所在之处升起<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="耶和华的荣耀从他所在之处升起——或译作“耶和华从他居所显出的荣耀是当受颂赞的”。">a</a></sup>；</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 1:24; 以西结书 10:16–17; 以西结书 10:5"> 那些活物翅膀彼此相接的声音、旁边轮子的声音，都是巨大的轰鸣声。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 37:1; 耶利米书 20:7–9; 列王纪下 3:15"> 灵举起我，把我带走。我离去时，灵里激愤，痛苦不已，耶和华的手在我身上大有能力。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 137:1; 约伯记 2:13; 创世记 50:10"> 我到了特拉维夫，就是住在迦巴鲁河边的掳民那里，在他们所住的地方坐下来。我在他们中间茫然地坐了七天。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米书 42:7"> 七天过后，耶和华的话语临到我，说：</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 52:8; 希伯来书 13:17; 历代志下 19:10"> “人子啊，我指派你作以色列家的守望者，你听了我口中的话，就要为我警诫他们。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以西结书 33:6; 雅各书 5:19–20; 以西结书 3:20"> “当我对恶人说‘你必定死’，如果你不警诫他，不发话警诫恶人离开他邪恶的道路，好使他得以存活，这恶人就必死在自己的罪孽中，我却要从你手中追讨他的血债。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 33:9; 以西结书 14:20; 提摩太前书 4:16"> 但如果你警诫了恶人，而他不转离自己的恶事和邪恶道路，他就必死在自己的罪孽中，你却保全了自己的性命。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西结书 18:24; 以西结书 18:26; 以西结书 33:12–13"> “当义人离开他的义而行不义，我把绊脚石放在他面前，他将要死，如果你不警诫他，他必死在自己的罪中，他所行的义不会被记念，我却要从你手中追讨他的血债。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太前书 4:16; 箴言 9:9; 提多书 2:15"> 但如果你警诫了义人，好使义人不犯罪，他也不再犯罪，他必因接受了警诫而存活，你也保全了自己的性命。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 9:6; 以西结书 37:1; 以西结书 8:4"> 然后，耶和华的手在那里临到我身上，他对我说：“起来，往平原去，我要在那里与你说话。”</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 1:28; 使徒行传 7:55; 启示录 1:17"> 于是我起来，往平原去。看哪，耶和华的荣耀停留在那里，正如我在迦巴鲁河边看见的荣耀，我就脸伏于地。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 2:2; 但以理书 10:19; 但以理书 10:8–10"> 那时，灵进入我里面，使我站了起来，耶和华吩咐我说：“你去，把自己关在家里。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 4:8; 使徒行传 9:16; 马可福音 3:21"> 人子啊，看哪，他们还将用绳子绑住你，捆住你，使你不能出去到他们中间。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 24:27; 弥迦书 3:6–7; 阿摩司书 8:11–12"> 我要使你的舌头紧贴上颚，使你哑然无声，不能作责备他们的人；他们实在是悖逆之家！</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 12:2–3; 以西结书 24:27; 以西结书 3:11"> 但我对你说话的时候，我会开你的口，你要对他们说：‘主耶和华如此说。’愿意听的，就让他听；拒绝的，就让他拒绝；他们实在是悖逆之家！</span>
</div>
</div>

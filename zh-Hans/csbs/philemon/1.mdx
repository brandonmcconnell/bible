<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 1:1; 以弗所书 3:1; 腓利门书 1:9"> 基督耶稣的囚犯保罗，以及弟兄提摩太，<br />致我们亲爱的弟兄和同工腓利门，</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比书 2:25; 歌罗西书 4:17; 罗马书 16:5"> 还有姐妹<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="姐妹——有古抄本作“蒙爱的”。">a</a></sup>阿菲娅和我们的战友阿其波斯，以及在你家里的教会：</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="罗马书 1:7; 以弗所书 1:2; 哥林多后书 13:14"> 愿恩典与平安从神我们的父和主耶稣基督临到你们！</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="罗马书 1:8; 以弗所书 1:16; 帖撒罗尼迦后书 1:3"> 我在祷告中提到你的时候，总是感谢我的神，</span>
<span className="v" id="v5" data-v="5" data-xref="歌罗西书 1:4; 以弗所书 1:15; 哥林多前书 16:1"> 因为我听说了你对主耶稣和所有圣徒所怀的爱心和信仰。</span>
<span className="v" id="v6" data-v="6" data-xref="腓立比书 1:9–11; 彼得后书 1:8; 歌罗西书 1:9"> 藉着认识在我们<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="我们——有古抄本作“你们”。">b</a></sup>中间为基督<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="基督——有古抄本作“基督耶稣”。">c</a></sup>所做的<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="所做的——辅助词语。">d</a></sup>一切美善之事，愿你在信仰上的契合<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="契合——或译作“沟通”或“分享”。">e</a></sup>能发挥功效。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 7:13; 帖撒罗尼迦前书 3:9; 哥林多后书 7:4"> 实际上，我由于你的爱得了极大的喜乐<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="喜乐——有古抄本作“恩典”或“感谢”。">f</a></sup>和鼓励，因为弟兄啊，圣徒们的情感藉着你得了安宁。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦前书 2:6; 哥林多后书 10:8; 哥林多后书 3:12"> 所以，虽然我在基督里大有胆量，可以吩咐你去做<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="去做——辅助词语。">g</a></sup>合宜的事，</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 5:20; 以弗所书 4:1; 罗马书 12:1"> 但为了爱的缘故，我宁愿恳求你。我<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="我——辅助词语。">h</a></sup>保罗——像我这样一个老人<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="老人——或译作“年长的”或“年老的”。">i</a></sup>，而现在又是基督耶稣的囚犯——</span>
<span className="v" id="v10" data-v="10" data-xref="歌罗西书 4:9; 哥林多前书 4:15; 提摩太前书 1:2"> 为我在捆锁中所生的孩子<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="我……所生的孩子——指“保罗带他信耶稣”。参《哥林多前书》4:15。">j</a></sup>奥尼斯莫<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="奥尼斯莫——意思为“有益处的”。">k</a></sup>，恳求你。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太后书 4:11; 约伯记 30:1–2; 彼得前书 2:10"> 他从前对你没有益处，但如今对你、对我都有益处了。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 6:14–15; 耶利米书 31:20; 马可福音 11:25"> 我把他本人送回你那里，就是说，把我的情感送回你那里。</span>
<span className="v" id="v13" data-v="13" data-xref="腓立比书 1:7; 以弗所书 3:1; 哥林多前书 16:17"> 我本来想把他留在自己身边，好让他在我为福音被捆锁的期间，能替你服事我。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 9:7; 历代志上 29:17; 彼得前书 5:2–3"> 但是没有你的同意，我就不愿意做什么，好让你的美善之事不是出于勉强，而是出于自愿。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 50:20; 创世记 45:5–8; 以赛亚书 20:6"> 其实，他暂时离开你，或许正是为了使你可以永远得着他——</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 3:22; 马太福音 23:8; 哥林多前书 7:22"> 不再像一个奴仆，而是高于奴仆，是一位蒙爱的弟兄。他对我尤其是这样，更何况对你呢！无论是在肉体上或在主里面都是这样。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 8:23; 马太福音 10:40; 腓利门书 1:12"> 因此，你如果把我当做同伴，就请接纳他，像接纳我一样。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 53:4–7"> 如果他亏负过你什么，或现在欠了你什么，请把它算在我的账上。</span>
<span className="v" id="v19" data-v="19" data-xref="加拉太书 6:11; 加拉太书 5:2; 哥林多前书 4:15"> 我保罗亲手写下：我必偿还——免得我对你说，连你自己也是欠我的呢！</span>
<span className="v" id="v20" data-v="20" data-xref="约翰三书 1:4; 腓利门书 1:7; 腓利门书 1:12"> 是的，弟兄！愿我在主里从你得到喜乐<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="喜乐——或译作“益处”。">l</a></sup>，请你使我的情感在基督<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="基督——有古抄本作“主”。">m</a></sup>里得到安宁。</span>
<span className="v" id="v21" data-v="21" data-xref="帖撒罗尼迦后书 3:4; 哥林多后书 2:3; 哥林多后书 7:16"> 我深信你会顺从，就写了信给你，因为我知道你所做的甚至会超过我所求的。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多后书 1:11; 腓立比书 2:24; 约翰二书 1:12"> 同时还请你为我预备住处，因为我希望藉着你们的祷告，能回到你们那里去。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="歌罗西书 1:7; 罗马书 16:7; 歌罗西书 4:12"> 在基督耶稣里与我一起坐牢的以帕弗拉问候你。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太后书 4:10–11; 歌罗西书 4:14; 歌罗西书 4:10"> 我的同工马可、亚里达古、迪马斯、路加也都问候你。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="提摩太后书 4:22; 罗马书 16:23; 罗马书 16:20"> 愿我们主耶稣基督的恩典与你们的灵同在！<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="有古抄本附“阿们。”">n</a></sup></span>
</div>
</div>

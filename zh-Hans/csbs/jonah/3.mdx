<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约拿书 1:1; 约翰福音 21:15–17"> 耶和华的话语第二次临到约拿，说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 2:7; 耶利米书 1:17; 约拿书 3:3"> “起来！到尼尼微大城去，向那城宣告我告诉你的信息！”</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 21:28–29; 诗篇 80:10; 创世记 22:3"> 约拿照着耶和华的话就起身，到尼尼微去。尼尼微是一座超级大城，走遍它需要<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="走遍它需要——辅助词语。">a</a></sup>三天的路程。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 18:22; 耶利米书 18:7–10; 列王纪下 20:1"> 约拿开始进入那城，走了<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="走了——辅助词语。">b</a></sup>一天的路程，宣告说：“再过四十天，尼尼微就要覆灭了。”</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 11:32; 马太福音 12:41; 约珥书 2:12–17"> 尼尼微人就相信神，并宣告禁食，无论尊卑，都披上麻布。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="雅各书 4:6–10; 以斯帖记 4:1–4; 但以理书 9:3"> 这话语传到尼尼微王的时候，他从自己的宝座上起来，从身上脱下王袍，披上麻布，坐在灰烬中。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 20:3; 约珥书 1:18; 约珥书 2:15–16"> 然后他颁布谕令，说：“在尼尼微，王和大臣有令：‘无论人或牲畜，牛或羊，都不可尝什么，不可吃什么，也不可喝水。</span>
<span className="v" id="v8" data-v="8" data-xref="约拿书 1:6; 以赛亚书 55:6–7; 以西结书 18:21–24"> 人和牲畜都当披上麻布；各人都当迫切地向神呼求，从自己邪恶的道路上、自己手里的残暴中转回。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 12:22; 约珥书 2:13–14; 诗篇 106:45"> 或许神回心转意，转消他猛烈的怒气，使我们不致灭亡。’”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 18:8; 列王纪上 21:27–29; 路加福音 15:20"> 神看到他们的行动，见他们转离了邪恶的道路，神就改变心意，不把他所说的灾祸降给他们了。</span>
</div>

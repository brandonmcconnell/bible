<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 37:7; 箴言 23:17; 箴言 24:19"> <span className="pl pl-1">不要因作恶者而心怀不平，</span><br /><span className="pl pl-1">也不要嫉妒那行不义的人，</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 92:7; 诗篇 90:5–6; 雅各书 1:10–11"> <span className="pl pl-1">因为他们就像青草快被割掉，</span><br /><span className="pl pl-1">也像青绿的嫩草即将衰残。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="耶利米书 17:7–8; 马太福音 6:31–33; 诗篇 62:8"> <span className="pl pl-1">你要依靠耶和华，要行善事，</span><br /><span className="pl pl-1">在地上安居，并要以信实为粮；</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 15:7; 诗篇 145:19; 约翰福音 15:16"> <span className="pl pl-1">你要以耶和华为乐，</span><br /><span className="pl pl-1">他就把你心里所求的赐给你。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="箴言 16:3; 彼得前书 5:7; 腓立比书 4:6–7"> <span className="pl pl-1">当把你的道路交托耶和华，</span><br /><span className="pl pl-1">当依靠他，他必成全；</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 54:17; 约伯记 11:17; 以赛亚书 58:8"> <span className="pl pl-1">他将使你的公义如光发出，</span><br /><span className="pl pl-1">使你的公正明</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="明——辅助词语。">b</a></sup><br /><span className="pl pl-1">如正午。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="雅各书 5:7–11; 诗篇 27:14; 诗篇 62:5"> <span className="pl pl-1">你要在耶和华面前静默，耐心等候他；</span><br /><span className="pl pl-1">不要因那道路通达、施行诡计的人而心怀不平。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 14:29; 箴言 16:32; 雅各书 1:19–20"> <span className="pl pl-1">当抑制怒气，离弃怒火；</span><br /><span className="pl pl-1">不要心怀不平，那只会导致恶事。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 60:21; 诗篇 25:13; 诗篇 37:29"> <span className="pl pl-1">因为作恶的必被剪除，</span><br /><span className="pl pl-1">唯有等候耶和华的必继承那地。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="约伯记 24:24; 诗篇 103:16; 诗篇 37:35–36"> <span className="pl pl-1">再过不久，恶人就不复存在；</span><br /><span className="pl pl-1">你就是在他的地方仔细查找，也找不到他。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 5:5; 加拉太书 5:22–23; 以赛亚书 26:3"> <span className="pl pl-1">但谦卑的人必继承那地，</span><br /><span className="pl pl-1">以丰盛的平安为乐。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="弥迦书 2:1; 诗篇 35:16; 诗篇 31:13"> <span className="pl pl-1">恶人决意要对付义人，</span><br /><span className="pl pl-1">向他咬牙切齿。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 2:4; 箴言 1:26; 撒母耳记上 26:10"> <span className="pl pl-1">但主必讥笑恶人，</span><br /><span className="pl pl-1">因为见他受罚的</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="受罚的——辅助词语。">c</a></sup><br /><span className="pl pl-1">日子将来到。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 29:27; 诗篇 11:2; 约翰一书 3:12"> <span className="pl pl-1">恶人已经拔出刀剑，拉开了弓，</span><br /><span className="pl pl-1">要使困苦人和贫穷人倒下，</span><br /><span className="pl pl-1">要杀戮行为正直的人。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 7:14–15; 诗篇 35:8; 耶利米书 51:56"> <span className="pl pl-1">但恶人的刀剑将刺入自己的心，</span><br /><span className="pl pl-1">他们的弓也将被打断。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 16:8; 箴言 15:16–17; 提摩太前书 6:6"> <span className="pl pl-1">一个义人拥有的虽少，</span><br /><span className="pl pl-1">却好过许多恶人的富有。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 41:10; 诗篇 63:8; 诗篇 145:14"> <span className="pl pl-1">因为恶人的膀臂必被打断，</span><br /><span className="pl pl-1">耶和华却扶助义人。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 1:6; 罗马书 6:23; 诗篇 103:17"> <span className="pl pl-1">耶和华知道纯全人的日子，</span><br /><span className="pl pl-1">他们的继业长存，直到永远。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 33:19; 箴言 10:3; 约伯记 5:20–22"> <span className="pl pl-1">他们在灾祸中不致蒙羞，</span><br /><span className="pl pl-1">在饥荒的日子里也会饱足。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 68:2; 诗篇 102:3; 路加福音 13:3"> <span className="pl pl-1">然而恶人必将灭亡，</span><br /><span className="pl pl-1">耶和华的仇敌如同草场</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="草场——或译作“羊羔”。">d</a></sup><br /><span className="pl pl-1">的华美必将消逝——</span><br /><span className="pl pl-1">如烟消逝。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="希伯来书 13:16; 诗篇 112:5; 箴言 22:7"> <span className="pl pl-1">恶人只借不还；</span><br /><span className="pl pl-1">义人却恩待人、给予人。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 3:33; 哥林多前书 16:22; 加拉太书 3:13"> <span className="pl pl-1">要知道，蒙耶和华祝福的，必继承那地；</span><br /><span className="pl pl-1">被耶和华诅咒的，必被剪除。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 16:9; 诗篇 119:133; 箴言 4:26"> <span className="pl pl-1">人的脚步被耶和华所立定，</span><br /><span className="pl pl-1">他的道路为耶和华所喜悦。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 24:16; 诗篇 145:14; 诗篇 94:18"> <span className="pl pl-1">他即使仆倒，也不被抛弃，</span><br /><span className="pl pl-1">因为耶和华扶助他的手。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 13:5; 诗篇 37:28; 诗篇 112:2"> <span className="pl pl-1">我曾经年少，现在老了，</span><br /><span className="pl pl-1">却未曾见过义人被离弃，</span><br /><span className="pl pl-1">也未曾见过他的后裔讨饭。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 112:5; 马太福音 5:7; 诗篇 37:21"> <span className="pl pl-1">他终日恩待人、借予人，</span><br /><span className="pl pl-1">连他的后裔也成为人的祝福</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="成为人的祝福——或译作“必蒙福”或“成为他的祝福”。">e</a></sup><br /><span className="pl pl-1">。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="诗篇 34:14; 箴言 16:6; 约翰一书 2:16–17"> <span className="pl pl-1">你当远离恶事，当行善事，</span><br /><span className="pl pl-1">就必安居直到永远；</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 11:7; 箴言 2:22; 诗篇 21:10"> <span className="pl pl-1">因为耶和华喜爱公正，</span><br /><span className="pl pl-1">不离弃他的忠信者，</span><br /><span className="pl pl-1">他们必蒙保守，直到永远；</span><br /><span className="pl pl-1">而恶人的后裔必被剪除。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 2:21; 诗篇 37:9; 彼得后书 3:13"> <span className="pl pl-1">义人将继承那地，</span><br /><span className="pl pl-1">在其上永远安居。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="歌罗西书 4:6; 箴言 25:11–13; 以弗所书 4:29"> <span className="pl pl-1">义人的口，述说智慧；</span><br /><span className="pl pl-1">他的舌头，讲说公正。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 40:8; 申命记 6:6; 以赛亚书 51:7"> <span className="pl pl-1">神的律法在他心里，</span><br /><span className="pl pl-1">他的步履不会摇摆。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 19:47–48; 诗篇 10:8–10; 诗篇 37:12"> <span className="pl pl-1">恶人窥伺义人，</span><br /><span className="pl pl-1">寻机置他于死地；</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 109:31; 彼得后书 2:9; 罗马书 8:1"> <span className="pl pl-1">但耶和华必不将他离弃在恶人的手中；</span><br /><span className="pl pl-1">在审判的时候，也不定他有罪。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="诗篇 27:14; 诗篇 37:9; 箴言 20:22"> <span className="pl pl-1">你当等候耶和华，谨守他的道路；</span><br /><span className="pl pl-1">他就高举你，使你继承那地；</span><br /><span className="pl pl-1">恶人被剪除的时候，你必看到。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="约伯记 5:3; 以西结书 31:18; 以赛亚书 14:14–19"> <span className="pl pl-1">我曾看到恶人的强横，</span><br /><span className="pl pl-1">像本地青翠的树那样蔓延；</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="诗篇 37:10; 使徒行传 12:22–23; 以赛亚书 10:16–19"> <span className="pl pl-1">但他很快就消逝了</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="他很快就消逝了——或译作“我再经过时”。">f</a></sup><br /><span className="pl pl-1">，看哪，他不复存在！</span><br /><span className="pl pl-1">虽然我寻找他，却找不到。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v37" data-v="37" data-xref="以赛亚书 32:17; 以赛亚书 57:1–2; 提摩太后书 4:6–8"> <span className="pl pl-1">你当留意纯全的人，观看正直的人，</span><br /><span className="pl pl-1">因为这些和平的人必有前途</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="前途——或译作“后代”。">g</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v38" data-v="38" data-xref="箴言 14:32; 诗篇 52:5; 诗篇 1:4–6"> <span className="pl pl-1">但悖逆者都要被除灭，</span><br /><span className="pl pl-1">恶人的前途必遭断绝。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v39" data-v="39" data-xref="诗篇 9:9; 诗篇 91:15; 以赛亚书 12:2"> <span className="pl pl-1">义人的拯救来自耶和华，</span><br /><span className="pl pl-1">他是他们在患难时的保障。</span><br /></span>
<span className="v" id="v40" data-v="40" data-xref="以赛亚书 31:5; 历代志上 5:20; 但以理书 6:23"> <span className="pl pl-1">耶和华帮助他们，搭救他们；</span><br /><span className="pl pl-1">他搭救他们脱离恶人，把他们拯救出来，</span><br /><span className="pl pl-1">因为他们投靠他。</span></span>
</div>

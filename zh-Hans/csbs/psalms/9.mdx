<div className="hs">大卫的诗，给乐队指挥，用“穆拉本<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="穆拉本——或译作“儿子之死”。">a</a></sup>”曲调。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 86:12; 历代志上 16:24; 诗篇 145:1–3"> <span className="pl pl-1">我要全心称谢耶和华，</span><br /><span className="pl pl-1">讲述你一切的奇妙作为。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 83:18; 诗篇 5:11; 诗篇 7:17"> <span className="pl pl-1">我要因你欢喜、欢庆；</span><br /><span className="pl pl-1">至高者啊，我要歌颂你的名！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="帖撒罗尼迦后书 1:9; 启示录 6:12–17; 诗篇 80:16"> <span className="pl pl-1">我的仇敌转身退后的时候，</span><br /><span className="pl pl-1">就在你面前绊倒、灭亡；</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 140:12; 彼得前书 2:23; 诗篇 98:9"> <span className="pl pl-1">因你为我施行公正、执行判决；</span><br /><span className="pl pl-1">你坐在宝座上施行公义的审判。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 10:7; 申命记 9:14; 箴言 13:9"> <span className="pl pl-1">你斥责了列国，消灭了恶人，</span><br /><span className="pl pl-1">抹掉了他们的名号，直到永永远远。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 14:22–23; 出埃及记 14:13; 弥迦书 7:8"> <span className="pl pl-1">仇敌被灭尽，敌国成为永久的废墟；</span><br /><span className="pl pl-1">你把他们的城镇拔出，连他们的名号也消亡了。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 103:19; 希伯来书 13:8; 诗篇 102:12"> <span className="pl pl-1">耶和华却永远坐着为王，</span><br /><span className="pl pl-1">他早已为审判设立了宝座。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 96:13; 诗篇 98:9; 启示录 20:12–13"> <span className="pl pl-1">是他以公义审判世界，</span><br /><span className="pl pl-1">以正直审断万民。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 18:10; 诗篇 91:1–2; 那鸿书 1:7"> <span className="pl pl-1">耶和华是受压迫之人的庇护所，</span><br /><span className="pl pl-1">是灾荒之时的庇护所。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 91:14; 箴言 18:10; 以赛亚书 26:3–4"> <span className="pl pl-1">耶和华啊，认识你名的人都要依靠你，</span><br /><span className="pl pl-1">因为你没有离弃寻求你的人！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="诗篇 107:22; 诗篇 96:1–2; 诗篇 148:1–5"> <span className="pl pl-1">你们当歌颂在锡安坐着为王</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="在锡安坐着为王——或译作“住在锡安”。">b</a></sup><br /><span className="pl pl-1">的耶和华，</span><br /><span className="pl pl-1">当在万民中宣告他的作为；</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 34:6; 出埃及记 3:7; 启示录 16:6"> <span className="pl pl-1">因为追讨血债的那一位会记念他们，</span><br /><span className="pl pl-1">不会忘记卑微人的呼声。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 86:13; 诗篇 30:3; 诗篇 107:18"> <span className="pl pl-1">耶和华啊，求你恩待我！</span><br /><span className="pl pl-1">愿你看到那些恨我的人加给我的苦难，</span><br /><span className="pl pl-1">求你把我从死门中拉上来，</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 13:5; 诗篇 51:12; 诗篇 106:2"> <span className="pl pl-1">好让我在女子锡安</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="女子锡安——或译作“锡安城”。">c</a></sup><br /><span className="pl pl-1">的城门，</span><br /><span className="pl pl-1">述说你当受的一切赞美，</span><br /><span className="pl pl-1">因你的救恩而欢乐。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="诗篇 7:15–16; 诗篇 57:6; 诗篇 35:8"> <span className="pl pl-1">列国陷入自己所挖的深坑里，</span><br /><span className="pl pl-1">他们的脚被自己暗设的网罗缠住。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 7:5; 士师记 1:7; 箴言 12:13"> <span className="pl pl-1">耶和华显明自己，施行公正；</span><br /><span className="pl pl-1">恶人因自己手所做的陷入圈套。希加永 细拉</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 50:22; 约伯记 8:13; 罗马书 2:8–9"> <span className="pl pl-1">恶人将归到阴间，</span><br /><span className="pl pl-1">所有忘记神的国家也是如此。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 12:5; 箴言 23:18; 箴言 24:14"> <span className="pl pl-1">是的，贫穷人不会被永久忘记，</span><br /><span className="pl pl-1">困苦人的希望不会永远消亡。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 3:7; 诗篇 44:23; 诗篇 7:6"> <span className="pl pl-1">耶和华啊，求你起来！</span><br /><span className="pl pl-1">不要让世人得胜，</span><br /><span className="pl pl-1">愿列国在你面前受审判。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 62:9; 诗篇 82:6–7; 以赛亚书 31:3"> <span className="pl pl-1">耶和华啊，求你使他们畏惧！</span><br /><span className="pl pl-1">愿列国的人都明白自己不过是人。细拉</span></span>
</div>

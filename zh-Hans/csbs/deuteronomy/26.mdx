<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 17:14; 申命记 13:9; 申命记 6:1–10"> 当你进入你神耶和华所赐给你为继业的土地，去拥有它，住在其中的时候，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 23:19; 出埃及记 23:16; 以西结书 44:30"> 你要从你神耶和华所赐给你的土地上所收获的各样初熟果实中，取出一些，放在篮子里，然后到你神耶和华所选择让他名安居的地方去。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 105:9–10; 申命记 19:17; 创世记 26:3"> 你要来到那时在任的祭司那里，对他说：“我今天向你神耶和华报告：我已经进入了耶和华向我们先祖起誓要赐给我们的那地。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="马太福音 23:19; 马太福音 5:23–24; 希伯来书 13:10–12"> 祭司要从你手中接过来篮子，放在你神耶和华的祭坛前。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 10:22; 创世记 46:27; 创世记 31:20"> 然后你要在你神耶和华面前声明说：<br />“我的祖先原是一个流亡<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="流亡——或译作“要灭亡”。">a</a></sup>的亚兰人，他下到埃及寄居在那里，那时人数很少，后来却在那里成为一个强大的民族，人数众多。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 1:11; 出埃及记 1:14; 出埃及记 5:23"> 埃及人迫害我们，苦待我们，把沉重的劳役加在我们身上。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 2:23–4; 以弗所书 3:20–21; 出埃及记 3:9"> 我们就向我们祖先的神耶和华呼求，耶和华听到了我们的声音，看到了我们的苦难、劳苦和压迫。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 4:34; 申命记 5:15; 诗篇 78:12–13"> 耶和华用大能的手和伸出的膀臂，用极其可畏的事，以及神迹和奇事，把我们从埃及领了出来。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 3:8; 诗篇 105:44; 诗篇 107:7–8"> 他把我们带到这地方，把这地——流奶与蜜之地赐给了我们。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 26:2; 申命记 18:4; 启示录 22:9"> 现在看哪，耶和华啊，我把你所赐给我之地的初熟果实带来了。”<br />然后你要把篮子放在你的神耶和华面前，在你的神耶和华面前下拜。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 16:11; 申命记 12:7; 腓立比书 4:4"> 你要与利未人，以及在你们中间的寄居者一起，因你的神耶和华赐给你和你家的一切福份而欢乐。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="利未记 27:30; 民数记 18:24; 腓立比书 4:18–19"> 每个第三年，就是在十一奉献年，当你献完了你所有收成的十分之一，并且分给了利未人、寄居者、孤儿和寡妇，使他们在你城中吃得饱足，</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 119:176; 诗篇 119:153; 诗篇 119:141"> 你要在你的神耶和华面前说：<br />“我已经把圣物从家里拿出来了，也照着你所吩咐我的一切诫命，把它分给了利未人、寄居者、孤儿和寡妇。我没有违背，也没有忘记你的诫命。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 7:20; 利未记 21:11; 何西阿书 9:4"> 我没有在举哀的时候吃它，没有在我不洁净的时候拿出它，也没有把它献给死人。我听从了我的神耶和华的话，照着你所吩咐我的一切做了。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 63:15; 撒迦利亚书 2:13; 耶利米书 31:23"> 愿你从天上，从你神圣的居所俯看，照着你向我们祖先所起的誓，祝福你的子民以色列，祝福你所赐给我们的这地——流奶与蜜之地。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命记 12:1; 约翰福音 14:15; 约翰一书 5:2–3"> 今天，你的神耶和华吩咐你遵行这些律例和法规，你要全心、全灵谨守遵行它们。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 24:7; 以赛亚书 12:2; 哥林多前书 6:19–20"> 你今天宣告了耶和华是你的神，并且你要走在他的道路上，遵守他的律例、诫命和法规，听从他的话。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 7:6; 申命记 14:2; 申命记 28:9"> 耶和华今天也宣告了你是他宝贵的子民，正如他向你所应许的，并且要你遵守他的一切诫命；</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前书 2:9; 申命记 7:6; 申命记 28:1"> 他要使你远高过他所造的一切民族，得着赞美、名声和光荣，并要照着他所应许的，使你成为你神耶和华的圣洁之民。</span>
</div>

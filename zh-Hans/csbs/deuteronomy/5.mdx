<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="申命记 4:1; 马太福音 23:3; 申命记 29:10"> 摩西召来全体以色列人，对他们说：<br />以色列啊，要听我今天向你们宣告的律例和法规，要学习，要谨守遵行。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 4:23; 出埃及记 19:5–8; 出埃及记 24:8"> 耶和华我们的神在何烈山与我们立了约；</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 29:10–15; 创世记 17:21; 创世记 17:7"> 耶和华不是与我们的祖先立这约，而是与我们这些今天在这里还活着的每一个人立约。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 19:18–19; 申命记 34:10; 出埃及记 19:9"> 耶和华在山上，从火焰中面对面与你们说话。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 3:19; 出埃及记 19:16; 出埃及记 20:18–21"> 那时我站在耶和华和你们之间，向你们传达耶和华的话语，因为你们惧怕那火焰，没有上山去。耶和华说：</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 20:2–17; 诗篇 81:5–10; 利未记 26:1–2"> <span className="pl pl-1">“我是耶和华你的神，是把你从埃及地为奴之家领出来的那一位。</span></span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 20:3; 马太福音 4:10; 约翰一书 5:21"> <span className="pl pl-1">除我以外，你不可有别的神。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 20:4; 申命记 4:15–19"> <span className="pl pl-1">不可为自己造偶像</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="偶像——或译作“雕像”。">a</a></sup><br /><span className="pl pl-1">，不可造上天、下地和地底下水中之物的任何形象。</span></span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 20:4–6; 出埃及记 34:7; 但以理书 9:4–9"> <br /><span className="pl pl-1">不可向它们下拜，也不可服事它们，因为我耶和华你的神是嫉愤的神。恨我的人，我必惩罚他们的罪孽，从父到子，甚至到三代、四代；</span></span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 8:28; 约翰一书 1:7; 耶利米书 32:18"> <br /><span className="pl pl-1">爱我并遵守我诫命的人，我必向他们施慈爱，直到千代。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 20:7; 利未记 19:12; 申命记 6:13"> <span className="pl pl-1">不可妄称你神耶和华的名，因为妄称耶和华名的人，耶和华必不让他免于罪罚。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 20:8–11; 以赛亚书 58:13; 以赛亚书 56:6"> <span className="pl pl-1">要谨守安息日，把它分别为圣，正如你神耶和华所指示你的。</span></span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 20:12; 路加福音 13:14–16; 出埃及记 23:12"> <br /><span className="pl pl-1">六天你要劳碌，做你一切工作；</span></span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 4:4; 创世记 2:2; 出埃及记 23:12"> <br /><span className="pl pl-1">但第七日是你神耶和华的安息日，你和你的儿女、仆婢，你的牛驴和一切牲畜，以及你城里的寄居者，都不可做任何工作，好让你的仆婢可以像你一样休息。</span></span>
<span className="v" id="v15" data-v="15" data-xref="申命记 5:6; 申命记 15:15; 申命记 16:12"> <br /><span className="pl pl-1">要记住，你曾在埃及地作奴隶，而耶和华你的神用大能的手和伸出的膀臂，把你从那里领了出来，因此耶和华你的神吩咐你要守安息日。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 20:12; 以弗所书 6:1–3; 歌罗西书 3:20"> <span className="pl pl-1">要孝敬父母，正如你神耶和华所指示你的，好让你的日子长久，在你神耶和华所赐给你的地上蒙福。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 20:13; 罗马书 13:9; 马太福音 5:21–22"> <span className="pl pl-1">不可杀人。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 20:14; 路加福音 18:20; 利未记 20:10"> <span className="pl pl-1">不可通奸。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 20:15; 罗马书 13:9; 以弗所书 4:28"> <span className="pl pl-1">不可偷窃。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 20:16; 出埃及记 23:1; 箴言 19:9"> <span className="pl pl-1">不可作假见证指证你的邻人。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 20:17; 罗马书 13:9; 路加福音 12:15"> <span className="pl pl-1">不可贪爱你邻人的妻子，不可贪图你邻人的房屋、田地、仆婢、牛驴，以及任何属于你邻人的东西。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及记 24:12; 出埃及记 31:18; 申命记 4:12–15"> 耶和华在山上，从火焰、密云和幽暗中，向你们全体会众大声宣告了这些话，没有增添别的；然后把这些话语写在两块石版上，交给了我。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 20:18–19; 希伯来书 12:18–21"> 当时你们听到黑暗中发出的声音，并且山在火焰中燃烧，你们所有支派的首领和长老就都靠近我，</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 4:33; 出埃及记 19:19; 出埃及记 33:20"> 说：“看哪，我们的神耶和华向我们显示了他的荣耀和伟大，我们也听到他从火焰中发出的声音。今天我们看见了神与人说话，而人竟然能存活。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 18:16; 加拉太书 3:10; 哥林多后书 3:7–9"> 但现在，我们何必要死呢？这猛烈的火就要吞噬我们了。如果我们继续听我们的神耶和华的声音，我们必定死。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 4:33; 罗马书 3:20; 马太福音 26:63"> 凡有血肉的，有谁像我们这样，听见永生神从火焰中说话的声音，还能存活呢？</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 20:19; 希伯来书 12:19"> 请你上前去，听我们神耶和华所说的一切，然后把我们神耶和华所告诉你的，全都传达给我们，我们会听从并遵行。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命记 18:17; 民数记 36:5; 民数记 27:7"> 你们对我说话时，耶和华听见了你们说的话。耶和华就对我说：“我听见了这子民对你说的话，他们说的都很好。</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 48:18; 以西结书 33:31–32; 申命记 11:1"> 但愿他们终生都有这样的心敬畏我，遵守我的一切诫命，好让他们和他们的子孙永远蒙福。</span>
<span className="v" id="v30" data-v="30"> 你去告诉他们，回自己的帐篷去。</span>
<span className="v" id="v31" data-v="31" data-xref="加拉太书 3:19; 以西结书 20:11; 申命记 5:1"> 至于你，要留在我这里，我会把你当教导他们的诫命、律例和法规都告诉你，好使他们在我所赐给他们去继承的那地上遵行。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="约书亚记 23:6; 箴言 4:27; 约书亚记 1:7"> 所以，你们要照着耶和华你们神所指示你们的，谨守遵行，不可偏离左右。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 7:23; 申命记 4:40; 路加福音 1:6"> 你们要走在耶和华你们神所指示你们的一切道路上，好使你们存活，并且蒙福，在你们将继承的那地上日子长久。</span>
</div>

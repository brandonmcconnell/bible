<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 21:4; 申命记 1:40; 民数记 14:25"> 然后我们转回，照着耶和华所吩咐我的，沿着通往红海的路前行往旷野去。我们绕行了西珥山许多日子。</span>
<span className="v" id="v2" data-v="2"> 耶和华吩咐我说：</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 1:6; 申命记 2:14; 申命记 2:7"> “你们绕行这山地已经很久了，你们要转向北去。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 20:14–21; 出埃及记 15:15; 申命记 23:7"> 你要吩咐百姓说：‘你们的兄弟以扫子孙住在西珥，你们即将从他们境内经过，他们会惧怕你们，所以你们要特别谨慎。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 36:8; 约书亚记 24:4; 耶利米书 27:5"> 你们不要挑战他们，他们的土地连一脚掌之地，我都不会给你们，因为我已经把西珥山赐给了以扫为产业。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 7:12; 民数记 20:19; 罗马书 12:17"> 你们要用银子向他们买食物吃，也要用银子向他们买水喝，</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 22:35; 尼希米记 9:21; 申命记 8:2–4"> 因为耶和华你的神在你手中一切工作上祝福了你。他知道你走这大旷野，这四十年你的神耶和华一直与你同在，你什么都不缺。’”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪上 9:26; 士师记 11:18; 列王纪下 16:6"> 于是我们绕过我们的兄弟——住在西珥的以扫子孙，绕过亚拉巴的路，绕过埃拉特和以旬迦别，然后转向，沿着通往摩押旷野的路前行。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 19:36–37; 民数记 21:15; 民数记 21:28"> 耶和华对我说：“不要骚扰摩押，也不要向他们挑起战争，我不会把他们的土地给你为产业，因为我已经把亚珥赐给了罗得的子孙为产业。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 14:5; 申命记 2:11; 民数记 13:22"> 从前以米人住在那里，这民雄伟众多，并且像亚衲人那样高大。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 1:28; 民数记 13:28; 创世记 14:5"> 他们像亚衲人一样，也算是利乏音人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="利乏音人——或译作“巨人”。">a</a></sup>，而摩押人称他们为以米人。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 2:22; 创世记 14:6; 申命记 2:32–11"> 从前何利人也住在西珥，但以扫的子孙赶出他们，把他们从自己面前除灭了，然后取代他们住下来，就像以色列在耶和华赐给他们的产业之地上所做的那样。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 21:12; 民数记 13:23"> “现在你们起身，越过撒烈溪谷。”我们就越过了撒烈溪谷；</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 26:64–65; 民数记 14:28–35; 申命记 1:34–35"> 从离开加低斯-巴尼亚，到我们越过撒烈溪谷，有三十八年的时间，直到那整个世代的战士都从营中灭尽了，正如耶和华向他们所起的誓。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 106:26; 以赛亚书 66:14; 诗篇 32:4"> 确实是耶和华出手对付了他们，使他们在营中溃乱，直到灭尽他们。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 民中的所有战士全都死了之后，</span>
<span className="v" id="v17" data-v="17"> 耶和华吩咐我说：</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 21:23; 以赛亚书 15:1; 民数记 21:15"> “你今天即将经过摩押的边界亚珥，</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 2:9; 士师记 11:13–27; 历代志下 20:10"> 接近亚扪人。你不要骚扰他们，也不要挑战他们，我不会把亚扪人之地给你为产业，因为我已经把它赐给了罗得的子孙为产业。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 14:5"> 那地也算是利乏音人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="利乏音人——或译作“巨人”。">b</a></sup>之地。利乏音人从前住在那里，亚扪人称他们为扎慕祖姆人，</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 27:7–8; 申命记 1:28; 申命记 2:22"> 这民雄伟众多，并且像亚衲人那样高大。但耶和华把他们从亚扪人面前除灭了，亚扪人赶出他们，然后取代他们住下来，</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 36:8; 创世记 36:20–30; 申命记 2:12"> 就像耶和华为住在西珥的以扫子孙所做的那样——他把何利人从以扫子孙面前除灭了，以扫子孙赶出他们，然后取代他们住下来，直到今天。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 10:14; 约书亚记 13:3; 阿摩司书 9:7"> 至于住在各村庄直到加沙的亚瓦人，那些从迦斐托出来的迦斐托人把他们除灭了，然后取代他们住下来。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米书 27:5; 但以理书 4:17; 士师记 11:18–21"> 耶和华说<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="耶和华说——辅助词语。">c</a></sup>：“你们要起身出发，越过亚嫩溪谷。看，我已经把亚摩利人希实本王西宏和他的领土交在你手中了。起来占领吧，向他发动战争！</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 11:25; 出埃及记 15:14–16; 申命记 28:10"> 从今天开始，我要使普天下的万民对你恐惧害怕，他们将听到你的消息就发抖，因你的缘故而震颤。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 10:5–6; 路加福音 10:10–12; 约书亚记 13:18"> 于是我从基底莫旷野派遣使者到希实本王西宏那里，传达和平的话说：</span>
<span className="v" id="v27" data-v="27" data-xref="士师记 11:19; 申命记 2:6; 民数记 21:21–23"> “请让我从你境内经过，我只沿着大道走，不偏离左右。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 20:19"> 你可以按价银卖食物给我吃，也按价银给我水喝，只要让我徒步经过——</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 20:18; 士师记 11:17–18; 申命记 23:3–4"> 就像住在西珥的以扫子孙和住在亚珥的摩押人对待我的那样——直到我过了约旦河，进入我们神耶和华所赐给我们的那地。”</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 21:23; 出埃及记 4:21; 约书亚记 11:19–20"> 但是希实本王西宏不肯让我们从他那里经过，因为你的神耶和华使他灵里刚硬、内心顽固，为要把他交在你手中，就像今日这样。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="申命记 1:8; 申命记 2:24"> 耶和华对我说：“看，我已经把西宏和他的领土交给你了。起来占领吧，去占有他的领土！”</span>
<span className="v" id="v32" data-v="32" data-xref="民数记 21:23–30; 士师记 11:20–23; 诗篇 136:19"> 那时西宏出来，他和他的全军在雅哈兹迎战我们。</span>
<span className="v" id="v33" data-v="33" data-xref="申命记 7:2; 约书亚记 21:44; 申命记 3:2–3"> 耶和华我们的神把他交给我们，我们击杀了他和他的儿子们，以及他的全军。</span>
<span className="v" id="v34" data-v="34" data-xref="申命记 7:2; 撒母耳记上 15:3; 申命记 3:6"> 那时我们攻取了他所有的城镇，把所有城镇的人，包括女人和孩童，全都灭绝了，没有留下一人存活。</span>
<span className="v" id="v35" data-v="35" data-xref="约书亚记 8:27; 申命记 20:14; 民数记 31:9–11"> 只掠夺了牲畜和我们所攻取城镇的财物，归于自己。</span>
<span className="v" id="v36" data-v="36" data-xref="约书亚记 13:9; 申命记 4:48; 申命记 3:12"> 从亚嫩溪谷边的亚罗珥和溪谷中的城，直到基列，没有一座城邑对我们是高不可破的，耶和华我们的神把这一切都交给我们了。</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 21:24; 申命记 3:16; 创世记 32:22"> 只有亚扪人之地，就是雅博河全流域和那山地的城镇，以及耶和华我们神所禁止<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="禁止——原文直译“指示”。">d</a></sup>的一切地方，你没有靠近。</span>
</div>
</div>

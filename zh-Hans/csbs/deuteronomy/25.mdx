<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 17:15; 申命记 1:16–17; 申命记 17:8–9"> 如果人们中间有了争讼，前来受审，审判官就要审断他们，定义人为义，定恶人有罪。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 12:47–48; 马太福音 10:17; 使徒行传 5:40"> 那时，如果那恶人该受鞭打，审判官就要让他趴下，照着他的罪行、以相应的数目在审判官面前鞭打他。</span>
<span className="v" id="v3" data-v="3" data-xref="约伯记 18:3; 雅各书 2:2–3; 路加福音 15:30"> 可以鞭打他四十下，但不能再多，恐怕再多鞭打他，责打超过这数目，你的弟兄就在你眼中受辱了。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="提摩太前书 5:17–18; 哥林多前书 9:9–10; 箴言 12:10"> 牛踹谷的时候，不可笼住它的嘴。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马太福音 22:24; 路加福音 20:28; 马可福音 12:19"> 如果兄弟同住，其中一个死了，而他没有儿子，死者的妻子不可嫁到外面归属别人。她丈夫的兄弟要到她那里去，娶她为妻，对她尽丈夫兄弟的责任。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 21:19; 诗篇 9:5; 诗篇 109:13"> 这妻子所生的头生子要立在那死去兄弟的名下，以免兄弟的名从以色列中抹掉。</span>
<span className="v" id="v7" data-v="7" data-xref="路得记 4:5–6; 路得记 4:1–2"> 但如果那人不愿娶他兄弟的妻子，他兄弟的妻子就要上城门口长老们那里，说：“我丈夫的兄弟不肯为他兄弟在以色列中立名，不愿对我尽丈夫兄弟的责任。”</span>
<span className="v" id="v8" data-v="8" data-xref="路得记 4:6"> 本城的长老们要把那人召来，与他谈话。如果他坚持说不愿意娶她，</span>
<span className="v" id="v9" data-v="9" data-xref="路得记 4:7–8; 民数记 12:14; 以赛亚书 50:6"> 那人兄弟的妻子就要从长老们眼前过去，到他那里脱掉他脚上的鞋子，然后往他脸上吐唾沫，声明说：“不给自己兄弟家立后的人，就要被如此对待！”</span>
<span className="v" id="v10" data-v="10"> 从此，他家<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="家——辅助词语。">a</a></sup>的名就在以色列被称为“脱鞋者之家”。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 2:9; 罗马书 3:8"> 如果有人和他弟兄彼此打架，其中一个人的妻子前来要从攻击者手中解救她丈夫，就伸手抓住对方的私处，</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 19:13; 申命记 19:21; 申命记 7:2"> 你要砍掉她的手，你眼中不可顾惜她。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 11:1; 箴言 16:11; 利未记 19:35–37"> 你袋子里不可有一大一小两样的砝码。</span>
<span className="v" id="v14" data-v="14"> 你家里不可有一大一小双重标准的量斗<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="双重标准的量斗——原文直译“两种伊法”；伊法相当于22公升的谷物量器。">b</a></sup>。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 20:12; 申命记 4:40; 以弗所书 6:3"> 你要有诚实公平的砝码，你要有诚实公平的量斗<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="量斗——原文直译“伊法”；相当于22公升的谷物量器。">c</a></sup>，好让你在你神耶和华所赐给你的土地上日子长久。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 11:1; 启示录 21:27; 申命记 22:5"> 因为凡是做那些事的，凡是行不义的，都是你神耶和华所憎恶的。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及记 17:8–16; 民数记 25:17–18; 民数记 24:20"> 要记得你们出埃及时，亚玛力人在路上是怎样对待你的：</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 3:18; 诗篇 36:1; 箴言 16:6"> 当你疲乏困倦时，他在路上遇到你，从后面击杀所有掉队的人，毫不敬畏神。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 17:14; 撒母耳记上 14:48; 出埃及记 17:16"> 因此，当你的神耶和华使你脱离了四围一切仇敌，你在你的神耶和华赐给你为继业，让你去继承的那地上得享安息时，你必须把亚玛力人的名号从天下抹掉；你不可忘记！</span>
</div>
</div>

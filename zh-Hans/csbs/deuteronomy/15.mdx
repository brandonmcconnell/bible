<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 31:10; 出埃及记 23:10–11; 利未记 25:2–4"> 每七年的最后一年，你要施行豁免。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 7:42; 雅各书 2:13; 路加福音 6:34–38"> 豁免的条例是这样的：所有的债主都要豁免他手中借给邻人的债，不可向他的邻人、他的弟兄追讨，因为耶和华的豁免已经宣告了。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 23:20; 马太福音 17:25–26; 哥林多前书 6:6–7"> 你可以向外邦人追讨，但你弟兄所欠你的，你要放手豁免。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 58:10–11; 箴言 28:27; 箴言 11:24–25"> 不过在你们中间本不会有贫穷人，因为在你的神耶和华所赐给你为继业，让你去继承的那地上，耶和华必定祝福你——</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 28:1–15; 以赛亚书 1:19–20; 约书亚记 1:7"> 你务必留心听从你神耶和华的话，谨守遵行我今天所吩咐你的这一切诫命。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 28:12–13; 路加福音 6:35; 尼希米记 9:27"> 是的，你的神耶和华必照着他所应许你的祝福你，你将借贷给许多民族，自己却不向人借贷，你将管辖许多民族，他们却不会管辖你。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约翰一书 3:16–17; 申命记 15:9; 箴言 21:13"> 但如果在你的神耶和华所赐给你的土地上，在你的某城中，你们中间有一个弟兄是贫穷的，你不可硬着你的心，对你贫穷的弟兄攥着手。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 6:34; 马太福音 5:42"> 你一定要向他大大敞开你的手，他缺什么，就把他所缺的慷慨借给他。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 24:15; 马太福音 20:15; 耶利米书 17:10"> 你要谨慎，免得你心中起了卑劣的念头，说“第七年豁免年临近了”，就恶眼看待你贫穷的弟兄不借给他，以致他因你而向耶和华呼求，你身上就有罪过了。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 22:9; 希伯来书 13:16; 以赛亚书 58:10"> 你要慷慨地借给他；你借给他的时候不要心疼，因为你的神耶和华会因这事的缘故，在你一切工作上以及你手所劳作的一切事上祝福你。</span>
<span className="v" id="v11" data-v="11" data-xref="马可福音 14:7; 马太福音 26:11; 约翰福音 12:8"> 地上总不会断绝穷人，所以我吩咐你说：在你们的地方，你要向你的弟兄，向你那里的困苦人、贫穷人大大敞开你的手。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米书 34:14; 利未记 25:39–41; 出埃及记 21:2–6"> 如果你的同胞——无论希伯来男人还是女人——被卖给你，服事了你六年，到第七年你要让他自由离去。</span>
<span className="v" id="v13" data-v="13" data-xref="玛拉基书 3:5; 耶利米书 22:13; 箴言 3:27–28"> 当你让他自由离去时，不可让他空手离去。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 16:2; 箴言 10:22; 诗篇 68:10"> 你要从你的羊群中、打谷场中、榨酒池中慷慨地给他，要照着你的神耶和华所祝福你的给他。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 16:12; 马太福音 18:32–33; 申命记 5:14–15"> 要记住，你曾在埃及地作过奴隶，而你的神耶和华救赎了你，所以我今天这样吩咐你。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 21:5–6; 诗篇 40:8; 诗篇 40:6"> 但如果那仆人对你说“我不愿离开你”，因为他喜爱你和你的家，他在你那里很好；那时，</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 1:22; 利未记 25:39–42"> 你就拿锥子，把他的耳朵在门上刺透，他就永远成为你的仆人了。对你的女仆，你也要这样做。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 17:7–8; 以赛亚书 16:14; 以赛亚书 21:16"> 但如果你让那仆人自由离去，你不要看着舍不得，因为他已经服事了你六年，应得雇工双倍的工酬。这样，你的神耶和华就会在你所做的一切事上祝福你。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及记 13:2; 出埃及记 13:12; 利未记 27:26"> 你牛群羊群中所有头生的，公的要分别为圣归于耶和华你的神；你不可用你头生的公牛耕耘，也不可给你头生的公羊剪毛。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 12:17; 申命记 14:23; 申命记 12:5–7"> 这些祭物，你和你的家人每年都要在你的神耶和华面前，在耶和华所选择的地方享用。</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 17:1; 玛拉基书 1:7–8; 利未记 22:19–25"> 但如果它身上有残疾，是瘸腿的或瞎眼的，有任何严重的残疾，你不可把它献给耶和华你的神。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 12:21–22; 申命记 12:15–16"> 你可以在自己城中吃，不洁净的人和洁净的人都可以吃，就像吃羚羊和鹿那样。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 12:16; 利未记 7:26; 申命记 12:23"> 只是不可吃它的血，要倒在地上，像倒水一样。</span>
</div>

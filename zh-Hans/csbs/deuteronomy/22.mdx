<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 23:4–5; 以西结书 34:16; 以赛亚书 58:7"> 你看见弟兄的牛或羊走散，不可掩面不顾，必须把它们带回来给你的弟兄。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 7:12; 帖撒罗尼迦前书 4:6"> 如果你弟兄不在你附近，或者你不认识他，你就要把牲畜带回你家中，留在你那里，等到你弟兄来寻找它时，你就还给弟兄。</span>
<span className="v" id="v3" data-v="3"> 你也要同样对待他的驴子、他的衣服，同样对待你弟兄遗失而被你发现的任何东西；你不可掩面不顾。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 6:1–2; 希伯来书 12:12–13; 马太福音 5:44"> 你看见弟兄的驴或牛倒在路上，也不可掩面不顾，必须帮他扶起来。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 11:4–15; 申命记 18:12"> 女人不可穿着男人的服装，男人也不可穿上女人的衣服，因为凡是做这些事的人都是你神耶和华所憎恶的。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="利未记 22:28; 箴言 12:10; 创世记 8:17"> 如果你在路上，在哪棵树上或在地上发现一个鸟窝，里面有幼雏或蛋，而母鸟卧在幼雏或蛋上，你不可把母鸟与雏鸟一起带走。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 4:40; 箴言 22:4"> 你必须放了母鸟，只可把雏鸟或蛋带走，好让你蒙福，日子长久。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 11:2; 以赛亚书 22:1; 出埃及记 21:28–36"> 当你建造新房屋时，要在屋顶上安装围栏，以免有人从上面掉下来，血债就归在你的家。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 19:19; 哥林多后书 11:3; 马太福音 9:16"> 不可在你的葡萄园混类播种，否则你播种的收获和葡萄园的收成都要归于圣所<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="归于圣所——或译作“被没收充公”。">a</a></sup>。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 6:14–16"> 不可使用牛和驴一同耕作。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 19:19"> 不可穿戴羊毛和细麻混纺的衣料。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 23:5; 民数记 15:37–41"> 你所穿的外衣四角要缝上穗子。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 29:21; 创世记 29:31; 以弗所书 5:28–29"> 如果某人娶了妻子，与她同房后却嫌弃她，</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 22:19; 箴言 18:21; 箴言 18:8"> 指责她行为不端，给她带来坏名声，说：“我娶了这女子，亲近了她，却没看到她的处女凭据。”</span>
<span className="v" id="v15" data-v="15"> 那女子的父母就要带上女子的处女凭据，来到城门口本城的长老们那里。</span>
<span className="v" id="v16" data-v="16"> 那女子的父亲要对长老说：“我把女儿嫁给了这人为妻，他竟然嫌弃她。</span>
<span className="v" id="v17" data-v="17"> 看哪，他指责她行为不端，说：‘我没看到你女儿的处女凭据。’然而，这就是我女儿的处女凭据。”然后他们要在本城的长老们面前展开那块布。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 18:21"> 本城的长老们就要把这人带下去管教他，</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 22:29; 马太福音 19:8–9; 申命记 24:1–4"> 并且罚他一百谢克尔<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一百谢克尔——相当于1,140公克。1谢克尔=11.4公克。">b</a></sup>银子，交给女子的父亲，因为他给以色列的处女带来了坏名声。那女子仍然是他的妻子，他终生不能休弃她。</span>
<span className="v" id="v20" data-v="20"> 但如果这控告是真的，那女子没有处女的凭据，</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 13:5; 创世记 34:7; 士师记 20:6"> 他们就要把那女子带到她父家门口，本城的人要用石头砸死她，因为她在父家行淫，在以色列做了丑恶的事。你要把这邪恶从你们中间除尽。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未记 20:10; 以西结书 23:45–47; 约翰福音 8:4–5"> 如果一个男人被发现与有丈夫的女人同寝，他们两个——那与女人同寝的男人和那女人都要被处死。你要把这邪恶从以色列除尽。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 1:18–19; 申命记 20:7"> 如果一个女子，是处女，已经与人订了婚，有个男人在城中遇见她，与她同寝，</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 22:21–22; 申命记 21:14; 哥林多前书 5:13"> 你们就要把他们两个带到本城的城门口，用石头砸死——砸死那女子，是因为她在城中没有呼救；砸死那男人，是因为他玷辱了邻人的妻子。你要把这邪恶从你们中间除尽。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 13:14"> 但如果是一个男人在野外遇见已经订了婚的女子，而那男人强行与她同寝，那么，只要处死那与她同寝的男人，</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 21:22"> 不可对那女子做什么，那女子没有犯该死的罪。正如有人起来攻击邻人，把他杀了那样，这案件也是如此，</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 13:7"> 因为是那男人在野外遇见她，并且这已经订婚的女子呼救了，却没有人拯救她。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 22:16–17"> 如果有一个男人遇见一个女子——是没有订婚的处女，强行与她同寝，被发现了，</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 22:19; 申命记 22:24; 申命记 21:14"> 那与她同寝的男人就要交给那女子的父亲五十谢克尔银子，然后那女子要归他为妻，因为那男人玷辱了她；他终生不能休弃她。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="申命记 27:20; 哥林多前书 5:1; 利未记 18:8"> 人不可娶他父亲的妻妾，不可揭开他父亲的衣襟。</span>
</div>

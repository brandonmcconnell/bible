<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 21:33–35; 申命记 1:4; 申命记 29:7"> 然后我们起身，沿着通往巴珊的路上去。那时巴珊王欧革出来，他和他的全军在伊德赖迎战我们。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 2:10; 历代志下 20:17; 民数记 21:23–25"> 耶和华对我说：“你不要怕他，因为我已经把他和他的全军以及他的领土，都交在你手中了。你要像对付住希实本的亚摩利王西宏一样对付他。”</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 21:35; 约书亚记 13:12; 约书亚记 13:30"> 于是，耶和华我们的神把巴珊王欧革和他的全军也交在我们手中了，我们击杀他，没有给他留下一人存活。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 4:13; 约书亚记 12:4; 约书亚记 13:30–31"> 那时我们攻取了他所有的城镇；在巴珊的欧革王国，就是亚珥歌伯整个地区六十座城，没有一座不被我们夺取的。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 1:28; 民数记 13:28; 希伯来书 11:30"> 这些全都是坚固的城，有高大的城墙，有门有闩；此外还有很多无城墙的村镇。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 2:34; 诗篇 135:10–12; 申命记 2:24"> 我们把所有城镇的人，包括女人和孩童，全都灭绝了，就像对付希实本王西宏那样，把他们灭绝净尽。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 2:35; 约书亚记 8:27; 约书亚记 11:11–14"> 只掠夺了城里所有的牲畜和财物，归于自己。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约书亚记 13:9–12; 约书亚记 12:2–6; 民数记 32:33–42"> 那时，我们夺取了约旦河对岸两个亚摩利王手中的领土，从亚嫩溪谷直到黑门山——</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 5:23; 诗篇 29:6; 以西结书 27:5"> 西顿人称黑门为“西连”，而亚摩利人称它为“示尼珥”。</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 13:31; 约书亚记 13:11–12; 申命记 4:49"> 我们夺取了平原所有的城镇，整个基列和整个巴珊，直到撒迦和伊德赖，都是巴珊的欧革王国的城镇。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 14:5; 耶利米书 49:2; 撒母耳记下 12:26"> 利乏音人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="利乏音人——或译作“巨人”。">a</a></sup>的遗民中，只有巴珊王欧革残留下来了。看哪，他的床是铁床，按人肘算，长九肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="九肘——相当于4.1公尺。1肘=45.7公分。">b</a></sup>，宽四肘<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="四肘——相当于1.8公尺。">c</a></sup>，如今不是还在亚扪人的拉巴吗？</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命记 2:36; 民数记 32:32–38; 约书亚记 13:8–28"> 那时我们占有了这地：从亚嫩溪谷边的亚罗珥起，我把基列山地的一半和其中的城镇给了鲁本人和迦得人；</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 32:39–42; 约书亚记 13:29–32; 历代志上 5:23–26"> 基列其余的土地，以及欧革王国整个巴珊，我给了玛拿西半支派。亚珥歌伯整个地区，包括整个巴珊，都称为利乏音人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="利乏音人——或译作“巨人”。">d</a></sup>之地；</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 32:41; 约书亚记 13:13; 撒母耳记下 3:3"> 玛拿西的子孙睚珥夺取了亚珥歌伯整个地区，直到基述人和玛迦人的边界，他就照着自己的名字称呼这些地方，称巴珊为睚珥镇，直到今天。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 32:39–40; 约书亚记 17:1–3; 约书亚记 22:7"> 我把基列给了玛吉；</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 21:24; 申命记 2:37; 撒母耳记下 24:5"> 至于给鲁本人和迦得人的，是从基列直到亚嫩溪谷，以溪谷中间为边界，直到亚扪人的边界雅博河，</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 12:3; 创世记 14:3; 约书亚记 3:16"> 还有亚拉巴流域，以约旦河为边界，从革尼勒湖<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="革尼勒湖——指加利利海；又称“革尼撒勒湖、太巴列湖”。">e</a></sup>直到亚拉巴海，就是东边毗斯迦山坡下的盐海。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民数记 32:20–24; 约书亚记 4:12–13; 约书亚记 1:12–15"> 那时我吩咐你们说：“你们的神耶和华已经把这地赐给你们了，让你们去继承。你们所有的勇士都要武装起来，在你们弟兄以色列子孙的前面过去；</span>
<span className="v" id="v19" data-v="19"> 只有你们的妻子、孩子以及牲畜——我知道你们有很多牲畜——他们可以留在我所赐给你们的城镇中。</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 22:4; 约书亚记 22:8"> 等到耶和华使你们的弟兄像你们一样得享安息，等他们也占有了耶和华你们神在约旦河对岸赐给他们的土地，那时候你们各人才可以回到我所赐给你们的产业去。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数记 27:18–23; 哥林多后书 12:10; 诗篇 9:10"> 那时我吩咐约书亚说：“你亲眼看到了你们的神耶和华对这两个王所做的一切，耶和华也会同样对付你即将前往之处的所有王国。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 14:14; 申命记 20:4; 申命记 1:30"> 不要怕他们，因为你们的神耶和华是为你们争战的那一位。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 12:8–9"> 那时我向耶和华恳求说：</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 15:11; 申命记 11:2; 诗篇 71:19"> “主耶和华啊，你已经开始向你的仆人显明你的伟大和你大能的手。天上地上有哪个神行事，能像你的作为和大能呢？</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 4:21–22; 以西结书 20:6; 出埃及记 3:8"> 求你让我过去，看看约旦河对岸的那美地，那美好的山地和黎巴嫩。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="申命记 1:37; 申命记 31:2; 历代志上 22:7–9"> 但耶和华因你们的缘故对我动怒，不愿听我。耶和华对我说：“够了，不要再对我说这事了。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 27:12; 申命记 34:1–4; 创世记 13:14–15"> 你上毗斯迦山顶去吧，向西、向北、向南、向东举目，用你的眼睛观望，因为你不能过这约旦河。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 31:3; 申命记 31:7; 申命记 1:38"> 不过你要指派约书亚，要使他坚强、勇敢，因为他要带领这子民过去，他要使他们继承你所观望的那地。”</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 34:6; 申命记 4:46; 民数记 25:3"> 于是我们停留在伯毗珥对面的山谷中。</span>
</div>
</div>

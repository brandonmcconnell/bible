<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 15:21; 玛拉基书 1:8; 申命记 23:18"> 你不可把身上有残疾，有任何缺陷的牛羊，献给耶和华你的神，因为那是你神耶和华所憎恶的。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="士师记 2:20; 何西阿书 8:1; 约书亚记 7:11"> 如果在你们中间，在你神耶和华所赐给你的某城中，发现有男人或女人做了你神耶和华眼中看为恶的事，违背他的约，</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 7:31; 申命记 4:19; 约伯记 31:26–27"> 去服事别的神，向它们下拜，向太阳、月亮或天上的万象下拜，都是我禁止<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="禁止——原文直译“没有指示过”。">a</a></sup>的，</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 7:51; 申命记 13:12–14; 申命记 19:18"> 有人告诉了你，你听说了，就要好好调查。如果确定这事是真的，这可憎之事发生在以色列了，</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 24:14; 约书亚记 7:25; 利未记 24:16"> 你就要把做这恶事的男人或女人带到城门口，用石头砸死那男人或女人。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 35:30; 希伯来书 10:28; 提摩太前书 5:19"> 那判处死刑的人，要凭着两个见证人或三个见证人的口供被处死，不可凭着一个见证人的口供被处死。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 13:9; 哥林多前书 5:13; 申命记 17:12"> 见证人要先动手处死他，然后全体民众要动手。你要把这邪恶从你们中间除尽。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="申命记 12:5; 哈该书 2:11; 申命记 1:17"> 你城中如果有难以裁决的案件，如杀人流血的案件、争讼的案件或打斗的案件，你要起身，上你神耶和华所选择的地方去，</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 44:24; 哈该书 2:11; 玛拉基书 2:7"> 来到利未祭司们和那时在任的审判官那里求问，他们就会把案件的判决告诉你。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 22:2–3"> 你要执行他们在耶和华选择的那地方告诉你的判语，谨守遵行他们所指示你的一切。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 1:7; 申命记 5:32; 罗马书 13:1–6"> 你要执行他们所指示你的条例、他们所告诉你的判决；他们向你宣告的判语，你不可偏离左右。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 15:30; 申命记 13:5; 申命记 18:5"> 如果有人擅自行事，不听从侍立在那里事奉耶和华你神的祭司，或是不听从审判官，那人就要被处死。你要把这邪恶从以色列除尽。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 13:11; 申命记 19:20; 民数记 15:30–31"> 这样，全体民众听见了就会害怕，不再擅自行事了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 8:19–20; 撒母耳记上 12:19; 约书亚记 1:13"> 当你进入你神耶和华所赐给你的那地，占有并住在其中时，如果你说：“我要为自己立一个王，就像周围那些民族一样”，</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 30:21; 历代志上 22:10; 历代志上 12:23"> 你必须立你神耶和华所拣选的人作你的王。你要从你弟兄当中立一个人作你的王，不可让不是你弟兄的外邦人统治你。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 31:1–3; 以西结书 17:15; 申命记 28:68"> 此外，他不可为自己大量增添马匹，更不可为了增添马匹而让子民回埃及去，因为耶和华对你们说过：你们不可再回到那条路上。</span>
<span className="v" id="v17" data-v="17" data-xref="尼希米记 13:26; 马太福音 19:5; 箴言 30:8–9"> 他不可为自己增添很多妃嫔，以免他的心偏离；他也不可为自己大量增添金银。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 31:9; 列王纪下 22:8; 历代志下 34:15"> 当他坐上王位的时候，他要在利未祭司面前，在卷册上<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="在利未祭司面前，在卷册上——或译作“照着利未祭司面前的书卷”。">b</a></sup>为自己抄写一份这律法书的副本。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 1:8; 诗篇 119:97–100; 诗篇 1:2"> 这副本要留在他身边，他一生的日子都要诵读它，好让他学习敬畏耶和华他的神，谨守这律法的一切话语，遵行这些律例。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 5:32; 列王纪上 15:5; 诗篇 131:1–2"> 这样，免得他心里向他的弟兄高傲，免得他或左或右偏离这些诫命，好使他和他子孙在以色列统治王国的日子长久。</span>
</div>

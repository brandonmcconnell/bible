<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="DEU" data-book-slug="deuteronomy" data-book-name="申命记" data-chapter="1" data-verses="46">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 25:1; 约书亚记 22:7; 民数记 33:17–18"> 这是摩西在约旦河对岸的旷野向全体以色列人宣讲的话语，是在帕兰与陀弗、拉班、哈洗录、底撒哈之间，在疏弗对面的亚拉巴宣讲的。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 32:8; 民数记 13:26; 申命记 9:23"> 从何烈山沿着通往西珥山的路，到加低斯-巴尼亚，有十一天的路程<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="的路程——辅助词语。">a</a></sup>。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 33:38; 申命记 4:1–2; 民数记 20:1"> 在第四十年的十一月，当月的第一日，摩西把耶和华指示他要向以色列子孙宣告的一切，都向他们宣告了；</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 21:21–35; 约书亚记 12:2–6; 约书亚记 13:10–12"> 那时他已经击败了住希实本的亚摩利王西宏，以及住亚斯他录和伊德赖的巴珊王欧革。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 4:8; 申命记 32:46; 申命记 31:9"> 在约旦河对岸的摩押地，摩西开始讲说这律法：</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 3:1; 民数记 10:11–13; 出埃及记 19:1–2"> 耶和华我们的神在何烈山吩咐我们说：“你们在这山地已经停留很久了，</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 11:24; 约书亚记 10:40; 阿摩司书 2:9"> 你们要起身出发，往亚摩利人的山地去，前往它邻近的各地，就是亚拉巴、山地、丘陵、南地<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="南地——音译作“内盖夫”。">b</a></sup>和沿海一带迦南人之地，以及黎巴嫩，直到那大河——幼发拉底河。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 15:18; 创世记 12:7; 创世记 26:3–4"> 看，我已经把那地摆在你们面前了，你们进去占有吧，耶和华曾向你们先祖亚伯拉罕、以撒、雅各起誓，要把那地赐给他们和他们的后裔。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 18:18; 民数记 11:17; 民数记 11:11–14"> 那时我告诉你们说：“我不能独自担当你们的事。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 10:22; 出埃及记 32:13; 创世记 22:17"> 你们的神耶和华使你们增多，看哪，你们今天多如天上的星辰。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 115:14; 创世记 22:17; 民数记 6:27"> 愿你们祖先的神耶和华使你们增添到现有的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="现有的——辅助词语。">c</a></sup>千倍，照着他所应许你们的，祝福你们！</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 3:5; 列王纪上 3:7–9; 哥林多后书 2:16"> 但我怎能独自担当你们的琐事、你们的重担和你们的争讼呢？</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 18:21; 使徒行传 1:21–23; 民数记 11:16–17"> 你们要按着你们的支派推荐一些有智慧、有悟性、有见识<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有见识——或译作“被认可”；下同。">d</a></sup>的人，我要立他们作你们的首领。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 当时你们回答我说：“你提出要做的事很好。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命记 16:18; 出埃及记 18:25–26; 以弗所书 4:11"> 于是我选出你们各支派的首领，就是那些有智慧、有见识的人，我立他们作你们的首领，作千夫长、百夫长、五十夫长、十夫长以及各支派的官长。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 7:24; 出埃及记 22:21; 历代志下 19:6–10"> 那时我吩咐你们的审判官说：“你们在你们的弟兄之间听讼，无论是人与他的弟兄之间，还是与寄居者之间，都要公正地施行审判。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 16:19; 出埃及记 18:26; 雅各书 2:9"> 裁决的时候，不可顾及情面；无论是对卑微的还是尊贵的，都要一样听讼。不可惧怕任何人，因为裁决属于神。至于对你们太难的案件，可以带来给我，我会听讼。”</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 12:32; 申命记 4:5; 使徒行传 20:20"> 那时，我把你们应当做的一切事都吩咐你们了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命记 1:2; 申命记 8:15; 耶利米书 2:6"> 于是，我们照着耶和华我们神所指示的，从何烈山起行，沿着通往亚摩利人山地的路，走过你们所看到那大而可怕的整个旷野，来到了加低斯-巴尼亚。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 1:7–8"> 我对你们说：“你们来到了我们神耶和华赐给我们的亚摩利人的山地。</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 1:9; 诗篇 46:1; 民数记 14:8–9"> 看，耶和华你的神把这地摆在你面前了。照着你祖先的神耶和华所吩咐你的，上去占有吧！不要害怕，不要丧胆。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数记 13:1–20"> 你们都前来见我，说：“让我们先派人去，为我们窥探那地，把我们要上去的路和要进入之城的信息带回来给我们。”</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 13:3–33"> 我看这建议好，就从你们中间选出了十二个人，每支派一人。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 13:21–27; 约书亚记 2:1–2"> 他们起身上山地去，来到以实格溪谷，窥探那地。</span>
<span className="v" id="v25" data-v="25"> 然后他们手里拿着那地的一些果实，带下来给我们，并且带回来信息，说：“我们的神耶和华赐给我们的这地是美好的。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="民数记 14:1–4; 使徒行传 7:51; 诗篇 106:24–25"> 你们却不愿意上去，竟然违背了你们的神耶和华的命令。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 9:28; 诗篇 106:25; 民数记 14:3"> 你们在自己的帐篷里抱怨说：“耶和华恨我们，所以把我们从埃及地领了出来，为要把我们交在亚摩利人手中，好除灭我们。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 13:28–33; 申命记 9:1–2; 约书亚记 15:14"> 我们能上哪里去呢？我们的弟兄使我们的心消融，说：‘那民比我们雄伟高大，那些城也雄伟坚固，高得<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="高得——辅助词语。">e</a></sup>顶天。我们在那里还看见了亚衲子孙！’”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 我就对你们说：“不要恐惧，不要怕他们。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 14:14; 尼希米记 4:20; 罗马书 8:31"> 耶和华你们的神，就是走在你们前面的那一位，他会亲自为你们争战，正如他在埃及，在你们眼前为你们所做的一切那样；</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 46:3–4; 使徒行传 13:18; 何西阿书 11:3–4"> 而且你也看见了，在旷野，在你们走过的整个路途中，直到你们来到这地方，你的神耶和华怎样背负了你，就像人背负自己的儿子那样。”</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 106:24; 犹大书 1:5; 希伯来书 3:18–19"> 尽管我说了这些，你们还是不相信耶和华你们的神——</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 10:33; 诗篇 78:14; 尼希米记 9:12"> 是他，一路上走在你们前面，为你们寻找扎营的地方，夜间用火柱、白天用云柱指明你们当走的路。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="民数记 14:22–30; 诗篇 95:11; 以西结书 20:15"> 耶和华听见你们的怨言，就发怒，起誓说：</span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 95:11"> “这邪恶的世代，绝不会有人看到我起誓要赐给你们先祖的美地！</span>
<span className="v" id="v36" data-v="36" data-xref="民数记 14:24; 约书亚记 14:6–14; 民数记 32:12"> 只有耶弗尼的儿子迦勒，他将看到那地，并且我要把他所踏之地赐给他和他的子孙，因为他全心跟从了耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="民数记 20:12; 申命记 4:21; 申命记 34:4"> 因你们的缘故，耶和华也对我发怒，说：“连你也不能进入那地。</span>
<span className="v" id="v38" data-v="38" data-xref="申命记 3:28; 民数记 14:30; 申命记 31:7–8"> 在你面前侍立的嫩的儿子约书亚，他将进入那地。你要鼓励他，因为他将使以色列继承那地。</span>
<span className="v" id="v39" data-v="39" data-xref="以赛亚书 7:15–16; 民数记 14:3; 民数记 14:31"> 还有你们所说将成为掠物的孩童，就是你们那些现在还不知道善恶的儿女，他们将进入那地。我要把那地赐给他们，他们将继承它。</span>
<span className="v" id="v40" data-v="40" data-xref="民数记 14:25"> 至于你们，转回吧，沿着通往红海的路前行往旷野去。”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数记 14:39–45; 箴言 19:3; 民数记 22:34"> 那时你们回答我说：“我们对耶和华犯了罪！我们要照着耶和华我们神所吩咐的一切，上去争战！”然后你们各人佩带兵器，轻率地要上那山地去。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="民数记 14:41–43; 约书亚记 7:8–13; 以赛亚书 59:1–2"> 耶和华对我说：“你告诉他们：不要上去，也不要争战，因为我不与你们同在。不然，你们必败在仇敌面前。”</span>
<span className="v" id="v43" data-v="43" data-xref="民数记 14:44; 以赛亚书 63:10; 使徒行传 7:51"> 我就吩咐了你们，你们却不听从，反而违背耶和华的命令，擅自行动上山地去。</span>
<span className="v" id="v44" data-v="44" data-xref="诗篇 118:12; 民数记 14:45; 民数记 21:3"> 于是住在那山地的亚摩利人出来迎战，像蜂群一样追赶你们，在西珥击溃你们，直到霍尔玛。</span>
<span className="v" id="v45" data-v="45" data-xref="希伯来书 12:17; 诗篇 78:34"> 你们回来，在耶和华面前大哭，但耶和华不垂听你们的声音，不倾听你们。</span>
<span className="v" id="v46" data-v="46" data-xref="民数记 20:1; 民数记 20:22; 士师记 11:16–17"> 你们就在加低斯滞留了许多日子，一直停留在那里。</span>
</div>
</div>

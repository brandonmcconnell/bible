<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 摩西前来对全体以色列人说了以下的话，</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 34:7; 民数记 27:17; 列王纪上 3:7"> 他对他们说：“我现在已经一百二十岁，不能再出入了，耶和华也对我说：‘你不能过这约旦河。’</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 9:3; 申命记 31:23; 申命记 3:28"> 你的神耶和华会亲自在你前面过去，他将从你面前除灭这些民族，你必赶出他们。约书亚会带领你过去，正如耶和华所说的。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 23:28–31; 申命记 2:33; 申命记 3:3–11"> 耶和华将处置他们，像对待他所除灭的亚摩利王西宏和欧革，以及他们的领土那样。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 7:2; 申命记 20:16–17; 出埃及记 23:32–33"> 耶和华会把他们交给你们，你们要照着我所吩咐的一切诫命处置他们。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 1:9; 以弗所书 6:10; 诗篇 27:14"> 你们要坚强、勇敢！不要害怕，不要因他们而恐惧，因为耶和华你的神，他是与你同去的那一位。他必不撇下你，也不离弃你。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命记 3:28; 申命记 31:6; 申命记 1:38"> 然后摩西把约书亚召来，在全体以色列人面前对他说：“你要坚强、勇敢！你必定带领这子民进入耶和华向他们先祖起誓要赐给他们的那地，你必定使他们继承那地。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 33:14; 申命记 31:6; 约书亚记 1:9"> 耶和华是走在你前面的那一位，他将与你同在；他必不撇下你，也不离弃你。你不要害怕，不要丧胆。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数记 4:15; 约书亚记 3:3; 申命记 17:18"> 摩西把这律法写下来，交给抬耶和华约柜的利未人祭司，以及以色列所有的长老。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 23:34–43; 申命记 15:1–2"> 摩西吩咐他们说：“每七年的最后一年，就是所定的豁免年住棚节的时候，</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 23:2; 约书亚记 8:34–35; 申命记 16:16–17"> 当全体以色列人前来，在耶和华所选择的地方朝见你的神耶和华时，你要在全体以色列人面前宣读这律法给他们听。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 4:10; 诗篇 34:11–14; 申命记 6:6–7"> 你要招聚民众，男人、女人、孩童，以及你城里的寄居者，使他们都能听到，使他们学习敬畏耶和华你们的神，谨守遵行这律法的一切话语。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 11:2; 申命记 6:7; 箴言 22:6"> 这样他们那些不知道这律法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这律法——辅助词语。">a</a></sup>的儿女也能听到，并在你们即将过约旦河去拥有的那地上，一生一世都学习敬畏耶和华你的神。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 27:13; 申命记 31:23; 约伯记 2:1"> 耶和华对摩西说：“看哪，你死的日子临近了。你把约书亚召来，一起站在会幕里，我好指派他。”于是摩西和约书亚前来，站在会幕里。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 40:38; 诗篇 99:7; 出埃及记 33:9–10"> 耶和华在会幕里、在云柱中显现，云柱立在会幕入口的上方。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="士师记 10:6; 士师记 10:13; 士师记 2:12"> 耶和华对摩西说：“看哪，你就要与你的列祖一同长眠了。这子民会起来行淫追随外邦神明，就是他们将要进入之地的神明；他们将会离弃我，违背我与他们所立的约。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 14:42; 以赛亚书 8:17; 诗篇 104:29"> 到那日，我的怒气必向他们发作，我会离弃他们，向他们隐藏我的脸。他们将被吞灭，会有许多灾祸和患难临到他们。那时他们会说：‘这些祸患临到我们，难道不是因为我们的神不在我们中间了吗？’</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 31:16–17"> 到那日，我必定因他所做的一切恶事隐藏我的脸，因为他转向了别的神。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 6:7; 申命记 31:21–22; 申命记 31:26"> 现在，你们要写下这首歌，把它教给以色列子孙，把它放到他们口中，好让这首歌成为我对以色列子孙的警诫<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="警诫——或译作“见证”。">b</a></sup>。</span>
<span className="v" id="v20" data-v="20" data-xref="何西阿书 13:6; 申命记 6:10–12; 尼希米记 9:25–26"> 因为我领他们进入我起誓要给他们先祖的那地——流奶与蜜之地，他们吃得饱足，发胖了，就转向别的神去服事它们，而藐视我，违背我的约。</span>
<span className="v" id="v21" data-v="21" data-xref="何西阿书 5:3; 诗篇 139:2; 约翰福音 2:24–25"> 当许多灾祸和患难临到他们时，这首歌必在他们面前作见证，这首歌绝不会从他们后裔的口中被忘掉。是的，在我领他们进入我起誓要给他们的那地以前，我就知道他们今天所怀的意念。”</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 31:19; 申命记 31:9"> 摩西就在那天写下这首歌，教给了以色列子孙。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="申命记 31:7–8; 申命记 31:14; 使徒行传 7:45"> 然后，耶和华指派嫩的儿子约书亚，说：“你要坚强、勇敢！你必定把以色列子孙带进我起誓要给他们的那地，我会亲自与你同在。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="申命记 31:9; 申命记 17:18"> 那时，摩西把这律法的话语从头到尾写在书卷上，写完了，</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 31:9"> 摩西就委派那些抬耶和华约柜的利未人，说：</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 31:19; 列王纪下 22:8–11; 加拉太书 2:19"> “你们把这律法书拿去，放在你们神耶和华的约柜旁边，要留在那里作为对你们的警诫<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="警诫——或译作“见证”。">c</a></sup>。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 32:20; 申命记 9:24; 使徒行传 7:51"> 因为我知道你们是悖逆的，是硬着颈项的。看哪，我今天还活着，与你们在一起，你们尚且悖逆耶和华，更何况我死了以后呢？</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 32:1; 申命记 4:26; 申命记 30:19"> 你们把各支派的长老和官长全都招聚到我这里来，我要把这些话说给他们听，并且请诸天和大地对他们作见证。</span>
<span className="v" id="v29" data-v="29" data-xref="士师记 2:19; 申命记 32:5; 路加福音 21:24"> 我知道，我死了以后，你们必定败坏，偏离我所指示你们的道路。日后必有祸患临到你们，因为你们将做耶和华眼中看为恶的事，以你们手所造的去惹怒他。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="希伯来书 3:2; 申命记 4:5; 约翰福音 12:49"> 然后，摩西把这首歌的歌词从头到尾宣读给以色列全体会众听：</span>
</div>

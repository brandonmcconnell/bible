<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 8:40; 约伯记 7:1; 申命记 4:19"> 你们在你祖先的神耶和华所赐给你去继承的地上，要一生一世谨守遵行以下的律例和法规：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 7:5; 列王纪下 16:4; 民数记 33:51–52"> 你们将赶出的那些民族，他们服事他们神明的任何场所，无论是在高山上、丘陵上，还是在各青翠树下，你们都要彻底毁掉。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 2:2; 撒迦利亚书 13:2; 民数记 33:52"> 你们要拆毁他们的祭坛，打碎他们的神柱，放火烧毁他们的亚舍拉柱，砍倒他们神明的雕像，使那些神明的名号从那地方消亡。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 20:23; 申命记 20:18; 申命记 16:21–22"> 你们不可像他们那样敬拜耶和华你们的神，</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 12:11; 申命记 26:2; 历代志下 7:12"> 而要到你们的神耶和华从各支派中选择的地方去求问，那是他将安置他的名居住的地方。你们要到那里去，</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 15:19–20; 玛拉基书 3:10; 利未记 27:32–33"> 把你们的燔祭、祭物、十一奉献和你们手中的供物，你们的还愿祭和甘心祭，以及你们的牛群羊群中头生的，都带到那里。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 12:18; 利未记 23:40; 申命记 14:26"> 你们和你们的家人也要在那里，在你们的神耶和华面前享用这些，为你们手所劳作的一切而欢乐，因为你的神耶和华祝福了你。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="士师记 21:25; 士师记 17:6; 箴言 21:2"> 你们不可像今天在这里所做的，各人做自己眼中看为正的一切。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 8:56; 诗篇 95:11; 申命记 25:19"> 你们那样做<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="那样做——辅助词语。">a</a></sup>，因为现在还没有进入安息之地，就是耶和华你的神所赐给你的继业之地；</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 33:11; 以西结书 34:28; 申命记 3:27"> 但你们即将过约旦河，住在你们的神耶和华使你们继承的那地，他将使你们得享安息，脱离四围一切仇敌，安然居住，</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 12:5; 申命记 15:20; 申命记 17:8"> 那时你们的神耶和华将选择一个让他的名安居的地方。你们要把我所吩咐你们的一切，就是你们的燔祭、祭物、十一奉献和你们手中的供物，以及你们向耶和华所许的一切上好的还愿祭，都带到那里。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 12:7; 申命记 10:9; 申命记 26:12"> 你们要在你们的神耶和华面前，与你们的儿女、仆婢，以及你们城里的利未人一起欢乐，因为利未人在你们中间没有份，没有继业。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 12:28–32; 列王纪上 15:34; 历代志下 15:17"> 你要谨慎，不可在你自己看中的任何地方献上燔祭，</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 12:11; 哥林多后书 5:19; 申命记 12:5"> 只可在耶和华从你一个支派中选择的地方，在那里献上燔祭，遵行我所吩咐你的一切。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命记 14:5; 申命记 15:22–23; 申命记 14:26"> 不过，你可以照着你的神耶和华所赐的祝福，在你各城中随心所愿地宰杀、吃肉；不洁净的人和洁净的人都可以吃，就像吃羚羊和鹿那样。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 9:4; 申命记 15:23; 申命记 12:23–24"> 只是你们不可吃血，要把血倒在地上，像倒水一样。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 26:14; 申命记 12:6; 申命记 14:22–29"> 你五谷、新酒和新油的十一奉献，还有你牛群羊群中头生的，你所许的任何还愿祭，你的甘心祭以及你手中的供物，都不可在自己的城里吃。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 12:7; 申命记 14:23; 申命记 12:5"> 你只可在你的神耶和华面前，在你的神耶和华所选择的地方吃，并且要与你的儿女、仆婢，以及你城里的利未人一起享用，在你的神耶和华面前为你手所劳作的一切欢乐。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 31:4–21; 尼希米记 10:34–39; 申命记 14:27–29"> 你要谨慎，在你所住的地方永不可撇弃利未人。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命记 19:8; 申命记 11:24; 出埃及记 34:24"> 当你的神耶和华照着他向你所应许的，扩张你的边界时，你心里渴望吃肉说“我要吃肉”，你就可以随心所愿地吃肉。</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 12:5; 列王纪上 14:21; 申命记 16:11"> 如果你的神耶和华所选择安置他名的地方离你很远，你可以照着我所指示你的，从耶和华赐给你的牛羊中宰杀一些，随心所愿在你的城中吃；</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 12:15–16"> 就像吃羚羊和鹿那样，你也照样可以吃它；不洁净的人和洁净的人全都可以吃。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 17:11; 创世记 9:4; 利未记 17:13–14"> 只是你绝不可吃血，因为血就是生命，你不可把生命与肉一起吃下。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 12:16; 申命记 15:23"> 你不可吃血，要倒在地上，像倒水一样。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 11:38; 申命记 4:40; 以赛亚书 3:10"> 你不可吃血，好让你和你的后代子孙蒙福，你是做耶和华眼中看为正的事。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="民数记 18:19; 民数记 5:9–10; 申命记 12:11"> 但你的那些圣物和你的还愿祭，你要带上，到耶和华所选择的地方去。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 1:13; 利未记 17:11; 利未记 1:9"> 你要把你的燔祭，连肉带血，献在你的神耶和华的祭坛上；祭物的血你要倒在你的神耶和华的祭坛上，祭物的肉你可以吃。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 4:40; 约翰福音 15:14; 约翰福音 15:10"> 你要谨守听从我所吩咐你的这一切话，好让你和你的后代子孙永远蒙福，你是做你神耶和华眼中看为好、看为正的事。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约书亚记 23:4; 申命记 19:1; 申命记 9:3"> 你的神耶和华必从你面前，剪除你要去赶出的那些民族。当你赶出他们，住在他们的土地上时，</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 10:2; 以西结书 20:32; 申命记 7:16"> 你要谨慎，不可在他们从你面前被除灭之后，效法他们而陷入圈套；也不可寻求他们的神明，说：“这些民族怎样服事他们的神明，我也要照样做。”</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米书 32:35; 申命记 18:9–10; 列王纪下 17:15–17"> 你不可那样敬拜耶和华你的神，因为他们敬拜他们神明的那一切可憎行为是耶和华所恨恶的，他们甚至把自己的儿女用火烧献给他们的神明。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 4:2; 启示录 22:18–19; 约书亚记 1:7"> 我所吩咐你们的一切话，你们都要谨守遵行，不可添加，也不可删减。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="此节在马索拉文本为13:1。">b</a></sup></span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 10:5; 以西结书 20:11; 利未记 18:5"> 现在，以色列啊，我所教导你们的律例和法规，你们要听从遵行，好使你们存活，进去继承你们祖先的神耶和华赐给你们的那地。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 12:32; 箴言 30:6; 启示录 22:18–19"> 我所吩咐你们的话语，不可在其上添加，也不可从其中删减，好使你们遵守我所吩咐你们的、你们神耶和华的诫命。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 25:1–9; 诗篇 106:28–29; 约书亚记 22:17"> 你们亲眼看见了耶和华在巴力-毗珥所做的事：凡是跟从毗珥的巴力的人，你们的神耶和华都从你们当中除灭了；</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 10:20; 约书亚记 23:8; 约翰福音 6:67–69"> 只有你们这些紧紧跟随耶和华你们神的，今天全都活着。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 28:20; 帖撒罗尼迦前书 4:1–2; 希伯来书 3:5"> 看，我已经按着我的神耶和华指示我的，把律例和法规教导给你们了，好使你们在将要进去占有之地照着遵行。</span>
<span className="v" id="v6" data-v="6" data-xref="约伯记 28:28; 诗篇 111:10; 提摩太后书 3:15"> 你们要谨守遵行，因为这在各民族眼中是你们的智慧和悟性。他们听到这一切律例，就会说：“这大国的民实在是有智慧、有悟性！”</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 145:18; 撒母耳记下 7:23; 诗篇 34:18"> 确实，哪一个大国有神与他们亲近，像我们的神耶和华，在我们每次呼求他时就与我们亲近呢？</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 147:19–20; 罗马书 7:12–14; 诗篇 119:127–128"> 哪一个大国有公义的律例和法规，像我今天在你们面前所立的这一切律法呢？</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命记 6:7; 申命记 11:19; 诗篇 78:3–8"> 你务必谨慎，极力保守你的灵魂，免得忘记你亲眼看到的事，免得那些事在你一生的日子离开你的心。你也要把它们教导给你的子子孙孙。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 19:9; 希伯来书 12:18–19; 出埃及记 19:16"> 那一天你在何烈山，站在你的神耶和华面前，耶和华对我说：“把民众招聚到我这里来，我要让他们听到我的话，好使他们在地上一生一世都学习敬畏我，也教导他们的儿女。”</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 5:23; 出埃及记 19:16–18; 希伯来书 12:18–19"> 于是你们上前来，站在山脚下，山在燃烧，火焰直达天顶，笼罩着黑暗、密云和幽暗。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 4:15; 申命记 5:4; 申命记 5:22"> 耶和华从火焰中对你们说话，你们听到了说话的声音，没有看到形象，只有声音。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 34:28; 出埃及记 31:18; 申命记 9:9–11"> 他向你们宣告了他的约，就是他吩咐你们要遵行的十诫，然后写在两块石版上。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 105:44–45; 以西结书 21:1–23"> 那时耶和华吩咐我，要把律例和法规教导给你们，好使你们在即将过去占有的那地上遵行。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命记 4:12; 以赛亚书 40:18; 哥林多后书 4:4–6"> 所以你们要极力保守自己的灵魂，因为耶和华在何烈山从火焰中对你们说话那天，你们没有看到任何形象。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 17:29; 申命记 5:8; 出埃及记 20:4–5"> 这样就免得你们败坏，为自己制造雕像——任何形象的偶像，男人或女人的样子，</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 1:23"> 地上任何动物的样子，空中任何飞鸟的样子，</span>
<span className="v" id="v18" data-v="18"> 地上任何爬虫的样子，地面之下水中任何鱼类的样子；</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 1:25; 申命记 17:3; 列王纪下 21:3"> 也免得你举目望天，观望日月星辰天上的万象，你就被引诱，向它们下拜，服事它们——你的神耶和华把它们划分给了普天下的万民，</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 8:51; 耶利米书 11:4; 出埃及记 19:5–6"> 耶和华却拣选你们，把你们从埃及从铁熔炉中领出来，作他的继业、他的子民，就像今日这样。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命记 1:37; 民数记 20:12; 诗篇 106:32–33"> 因你们的缘故，耶和华对我发怒，起誓不许我过约旦河，不让我进入你的神耶和华赐给你为继业的那美地。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 3:25; 申命记 3:27; 彼得后书 1:13–15"> 因此我将死在这地，不能过约旦河了，而你们即将过去，占有那美地。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 4:9; 希伯来书 3:12; 约书亚记 23:16"> 你们要谨慎，免得忘记你们的神耶和华与你们所立的约，而为自己制造任何形象的雕像，这是你的神耶和华所禁止<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="禁止——原文直译“指示”。">a</a></sup>你的。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 12:29; 那鸿书 1:6; 申命记 9:3"> 因为你的神耶和华是吞噬的烈火，是嫉愤的神。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="申命记 4:16; 何西阿书 9:9; 哥林多前书 10:22"> 当你们生了孩子，有了孙子，在那地住久了，如果你们败坏，制造任何形象的雕像，做你们神耶和华眼中看为恶的事，惹他恼怒，</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 32:1; 弥迦书 6:2; 耶利米书 22:29"> 我今天请诸天和大地对你们作见证：在你们即将过约旦河去占有的那地上，你们必定很快灭亡！你们在那地上日子不会长久，必定被除灭。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 28:62–64; 利未记 26:33; 以西结书 12:15"> 耶和华会把你们驱散到万民中；在耶和华把你们迁往的列国中，你们将存留下来，人数稀少。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 28:64; 耶利米书 16:13; 申命记 28:36"> 你们将在那里服事人手所造的神明——那些不能看、不能听、不能吃、不能闻的木头和石头。</span>
<span className="v" id="v29" data-v="29" data-xref="诗篇 119:2; 耶利米书 29:12–14; 历代志下 15:4"> 然而，你们会在那里寻求耶和华你们的神；只要你全心、全灵寻求他，你就会寻见。</span>
<span className="v" id="v30" data-v="30" data-xref="约珥书 2:12–13; 耶利米书 23:20; 何西阿书 3:5"> 日后，当你遭遇危难，这一切事临到你时，你就会回转归向耶和华你的神，听从他的话。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 31:8; 诗篇 116:5; 尼希米记 9:31"> 因为你的神耶和华是有怜悯的神，他必不撇下你，也不毁掉你，不会忘记他与你先祖起誓立下的约。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="约伯记 8:8; 马太福音 24:31; 诗篇 44:1"> 你尽管去问，在你之前，起初的那些日子里，自从神在地上创造了人那天起，从天这边到天那边，是否有过这样的大事，或者听说过这样的事？</span>
<span className="v" id="v33" data-v="33" data-xref="士师记 6:22; 申命记 5:24; 出埃及记 33:20"> 是否有哪个民族，听到神从火焰中说话的声音，像你那样听到了还能存活？</span>
<span className="v" id="v34" data-v="34" data-xref="申命记 26:8; 申命记 5:15; 出埃及记 6:6"> 或者有哪位神，曾试图用试炼、神迹、奇事、战争、大能的手、伸出的膀臂和极其可畏的事，去为自己把一个民族从另一个民族中带出来，像你们的神耶和华在埃及、在你眼前为你们所做的那一切呢？</span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 45:18; 撒母耳记上 2:2; 以赛亚书 45:5"> 这些事向你显明，是要你知道：唯独耶和华是神，在他以外，没有另一位。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 19:9; 出埃及记 19:19; 申命记 4:33"> 他从天上让你听到他的声音，为要教导你；他在地上也让你看见他猛烈的火，让你从火焰中听到他的话。</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 10:15; 以赛亚书 63:9; 出埃及记 13:9"> 他因为爱你的列祖，所以拣选他们的后裔，用伟大的能力亲自把你从埃及领了出来，</span>
<span className="v" id="v38" data-v="38" data-xref="申命记 7:1; 申命记 9:1–5; 出埃及记 23:27–28"> 为要从你面前赶出那些比你强大的民族，而把你带进去，把他们的土地赐给你为继业，就像今日这样。</span>
<span className="v" id="v39" data-v="39" data-xref="约书亚记 2:11; 申命记 4:35; 历代志上 29:11"> 所以你今天要知道，要铭记在心：天上地上唯独耶和华是神，没有另一位。</span>
<span className="v" id="v40" data-v="40" data-xref="申命记 6:3; 以弗所书 6:3; 申命记 12:28"> 你要遵守他的律例和诫命，就是我今日所吩咐你的，使你和你的后代子孙蒙福，也使你在你的神耶和华永远赐给你的土地上日子长久。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数记 35:6; 民数记 35:14–15; 约书亚记 20:2–9"> 那时摩西在约旦河东岸划分出三座城，</span>
<span className="v" id="v42" data-v="42" data-xref="希伯来书 6:18; 申命记 19:1–10; 民数记 35:15–28"> 好让那从前没有仇恨、不是故意杀害邻人的凶手，可以逃往那里。他逃到其中的一座城，就可以存活：</span>
<span className="v" id="v43" data-v="43" data-xref="约书亚记 20:8; 列王纪上 4:13; 约书亚记 21:27"> 属于鲁本人的，有平原之地旷野中的比册尔；属于迦得人的，有基列的拉末；属于玛拿西人的，有巴珊的戈兰。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="申命记 27:3; 利未记 27:34; 玛拉基书 4:4"> 这是摩西在以色列子孙面前设立的律法，</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪上 2:3; 申命记 4:1; 诗篇 119:7"> 就是摩西在他们出埃及之后，向以色列子孙宣告的法度、律例和法规。</span>
<span className="v" id="v46" data-v="46" data-xref="申命记 3:29; 申命记 4:47; 申命记 1:4–5"> 那时他们在约旦河对岸，在伯毗珥对面的山谷，那里原是住希实本的亚摩利王西宏的领土，摩西和以色列子孙出埃及之后击杀西宏，</span>
<span className="v" id="v47" data-v="47" data-xref="申命记 3:1–14; 民数记 21:33–35; 申命记 29:7–8"> 占有了他和巴珊王欧革——约旦河东岸两个亚摩利王的领土：</span>
<span className="v" id="v48" data-v="48" data-xref="申命记 3:9; 申命记 2:36; 申命记 3:12"> 从亚嫩溪谷边的亚罗珥，直到西翁山，就是黑门山；</span>
<span className="v" id="v49" data-v="49" data-xref="申命记 3:17; 约书亚记 13:20; 申命记 34:1"> 还有约旦河东岸整个亚拉巴流域，直到毗斯迦山坡下的亚拉巴海。</span>
</div>

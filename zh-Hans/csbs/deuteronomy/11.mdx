<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 6:5; 申命记 10:12; 路加福音 1:74–75"> 因此，你要爱耶和华你的神，终生谨守他的吩咐、律例、法规和诫命。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 8:2–5; 申命记 29:10; 使徒行传 26:22"> 你们今天要知道：这不是对你们的儿女说的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="说的——辅助词语。">a</a></sup>——<br />他们不知道，也没有经历过你们的神耶和华的管教，没有经历过他的伟大，他大能的手和伸出的膀臂；</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 7:19; 申命记 4:34; 诗篇 105:27–45"> 他在埃及人当中向埃及王法老和他的全地所行的神迹奇事，</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 106:11; 出埃及记 14:23–31; 出埃及记 15:19"> 以及他对埃及的军队、马匹和战车所做的，就是当他们追赶你们时，耶和华使红海的水淹没他们，永远<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="永远——原文直译“直到今日”。">b</a></sup>消灭了他们；</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 77:20; 诗篇 106:12–48; 诗篇 78:14–72"> 还有他在旷野中怎样对待你们，直到你们来到这地方；</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 26:9–10; 诗篇 106:17; 民数记 16:1–35"> 还有他怎样处置鲁本人以利押的儿子大坍和亚比兰，那时大地张开口，在全体以色列人中吞灭了他们和他们的家人、他们的帐篷，以及他们身边<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="身边——原文直译“脚前”。">c</a></sup>的一切活物。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 145:4–6; 诗篇 145:12; 诗篇 150:2"> 只有你们，亲眼看到了耶和华所做的一切伟大作为。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以弗所书 6:10; 约书亚记 1:6–7; 以弗所书 3:16"> 所以你们要遵守我今天吩咐你们的一切诫命，好使你们坚强，去占有你们将要过去占有的那地，</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 3:8; 申命记 4:40; 申命记 6:2"> 并且在耶和华向你们先祖起誓要赐给他们和他们后裔的土地——流奶与蜜之地上日子长久。</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亚书 14:18"> 因为你将要进去占有的那地不像你们出来的埃及地，在埃及你播种后还要用脚来浇灌，像在菜园里那样；</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 6:7; 申命记 8:7–9; 诗篇 65:12–13"> 你们即将过去占有的那地，是有山有谷、有天上雨水滋润之地，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 24:6; 诗篇 33:18; 列王纪上 9:3"> 是你的神耶和华眷顾之地，你的神耶和华的眼目从岁首到年终一直看顾它。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命记 10:12; 申命记 4:29; 申命记 6:17"> 到那时，如果你们留心听从我今天吩咐你们的诫命，爱耶和华你们的神，全心、全灵服事他，</span>
<span className="v" id="v14" data-v="14" data-xref="雅各书 5:7; 利未记 26:4; 以西结书 34:26"> 他<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="他——依据七十士译本；马索拉文本作“我”。">d</a></sup>就按时给你们的土地赐下雨水，秋雨和春雨，使你可以收取你的五谷、新酒和新油，</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 104:14; 申命记 6:11; 约珥书 2:19"> 他<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="他——依据七十士译本；马索拉文本作“我”。">e</a></sup>也在田野为你的牲畜供应牧草；你必吃得饱足。</span>
<span className="v" id="v16" data-v="16" data-xref="约伯记 31:27; 希伯来书 3:12; 希伯来书 2:1"> 你们要谨慎，免得你们的心被引诱而偏离，去服事别的神，向它们下拜。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 8:35; 申命记 6:15; 历代志下 6:26"> 那样，耶和华的怒气就会向你们发作，他会使天闭塞，不降雨水，以致土地不供应出产，你们就从耶和华赐给你们的美地上迅速灭亡。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 3:16; 申命记 6:6–9; 箴言 3:1"> 你们要把我这些话铭记在心，铭刻在灵魂中；要把它们系在手上作为标记，绑在额上<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="额上——原文直译“双眼之间”。">f</a></sup>作为标志。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 6:7; 以赛亚书 38:19; 申命记 4:9–10"> 你们也要把这些话教导给你们的儿女，你坐在家里、走在路上，你躺下、起来，都要谈论这些话。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 6:9"> 你也要把它们写在你家的门框上、你的城门上。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 4:10; 箴言 3:2; 箴言 9:11"> 这样你们的日子，你们子孙的日子，就在耶和华向你们先祖起誓要赐给他们的土地上增多，如天地之久。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 6:17; 申命记 11:13; 申命记 10:20"> 如果你们切实谨守我所吩咐你们遵行的这一切诫命，爱耶和华你们的神，走在他的一切道路上，紧紧跟随他，</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 4:38; 申命记 9:1; 申命记 7:1–2"> 耶和华就会从你们面前赶出这些民族，你们必赶出比你们强大的民族。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 14:9; 出埃及记 23:31; 创世记 15:18–21"> 你们脚掌踏上的每一个地方，都将成为你们的；从旷野到黎巴嫩，从幼发拉底大河到西边的海<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="西边的海——指地中海。">g</a></sup>，将成为你们的地界。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 7:24; 出埃及记 23:27; 约书亚记 1:5"> 没有人能在你们面前站立得住，你们的神耶和华会使你们所踏的全地都对你们恐惧害怕，正如他向你们所应许的。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="申命记 30:1; 申命记 30:15–20; 加拉太书 3:10"> 看，我今天把祝福和诅咒摆在你们面前：</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 1:19; 申命记 28:1–14; 以赛亚书 3:10"> 你们如果听从我今天所吩咐的、你们神耶和华的诫命，就必蒙福；</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 28:15–68; 罗马书 2:8–9; 加拉太书 3:10"> 你们如果不听从你们的神耶和华的诫命，偏离我今天所指示你们的道路，去跟从你们不认识的别神，就必受诅咒。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 27:12–26; 约书亚记 8:30–35"> 当你的神耶和华带你来到你将要进去占有的那地时，你要在基利心山上宣告祝福，在以巴录山上宣告诅咒。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 12:6; 士师记 7:1; 约书亚记 4:19"> 这两座山不是在约旦河对岸吗？就在西边日落的方向，亚拉巴的居民迦南人之地上，在吉甲对面、摩利的橡树林附近。</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 1:11; 申命记 9:1; 约书亚记 3:13–17"> 你们即将过约旦河，进去占有耶和华你们神所赐给你们的那地，你们占有了它，住在其中以后，</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 28:20; 申命记 12:32; 帖撒罗尼迦前书 4:1–2"> 要谨守遵行我今天在你们面前设立的一切律例和法规。</span>
</div>
</div>

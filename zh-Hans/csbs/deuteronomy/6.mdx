<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 4:1; 申命记 12:1; 申命记 4:45"> 这是耶和华你们的神所吩咐要教导你们的诫命、律例和法规，好让你们在即将过去占有的那地上遵行，</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 4:40; 申命记 13:4; 出埃及记 20:20"> 好使你和你的子子孙孙一生一世都敬畏耶和华你的神，遵守我所吩咐你的一切律例和诫命，好使你的日子长久。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 22:17; 出埃及记 3:8; 创世记 26:4"> 以色列啊，你要听，要谨守遵行，使你蒙福，使你们在流奶与蜜之地大大增多，正如你祖先的神耶和华向你所应许的。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="马可福音 12:29–32; 以赛亚书 44:6; 提摩太前书 2:5"> 以色列啊，你要听：耶和华是我们的神，耶和华是唯一的！</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 12:30; 马太福音 22:37; 路加福音 10:27"> 你要全心、全灵、全力爱耶和华你的神。</span>
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 3:16; 箴言 7:3; 耶利米书 31:33"> 我今天吩咐你的这些话，你要铭记在心；</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 11:19; 以弗所书 6:4; 诗篇 78:4–6"> 也要勤勉教导给你的儿女，你坐在家里、走在路上，你躺下、起来，都要谈论这些话。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 6:21; 箴言 3:3; 申命记 11:18"> 你要把它们系在手上作为标记，绑在额上<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="额上——原文直译“双眼之间”。">a</a></sup>作为标志。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 11:20; 以赛亚书 30:8; 以赛亚书 57:8"> 你也要把它们写在你家的门框上、你的城门上。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约书亚记 24:13; 诗篇 105:44; 尼希米记 9:25"> 你的神耶和华将领你进入他向你先祖亚伯拉罕、以撒、雅各起誓赐给你的那地：有雄伟美好的城邑，不是你建造的；</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 7:12–18; 申命记 8:10–20; 以西结书 16:10–20"> 有充满各样美物的房屋，不是你装满的；有开凿好的水窖，不是你开凿的；有葡萄园和橄榄园，不是你栽种的。那时你吃得饱足，</span>
<span className="v" id="v12" data-v="12"> 就要谨慎，免得忘记把你从埃及地为奴之家领出来的耶和华。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 4:8; 申命记 10:20; 马太福音 4:10"> 你要敬畏耶和华你的神，唯独服事他，指着他的名起誓。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 25:6; 约翰一书 5:21; 申命记 13:7"> 不可跟从别的神，就是你们周围那些民族的神明，</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 4:24; 出埃及记 20:5; 申命记 7:4"> 因为在你们中间的耶和华你的神是嫉愤的神，恐怕耶和华你的神对你发怒，就把你从这地面上除灭了。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 17:7; 路加福音 4:12; 马太福音 4:7"> 不可试探耶和华你们的神，就像你们曾经在玛撒试探他那样。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 11:22; 诗篇 119:4; 哥林多前书 15:58"> 你们要切实谨守耶和华你们神所吩咐你的诫命、法度和律例。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 4:40; 申命记 12:25; 罗马书 12:2"> 要做耶和华眼中看为正、看为好的事，好让你蒙福，并且进去继承耶和华起誓要给你先祖的那美地，</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 33:52–53; 出埃及记 23:28–30; 士师记 3:1–4"> 把你一切仇敌都从你面前驱逐出去，正如耶和华所应许的。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 13:14; 出埃及记 12:26; 约书亚记 4:6–7"> 日后当你的儿子问你说：“我们的神耶和华吩咐你们的这些法度、律例和法规，是什么意思呢？”</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 6:17–18; 以弗所书 2:11–12; 申命记 15:15"> 你要对你的儿子说：“我们曾在埃及给法老作奴隶，耶和华用大能的手把我们从埃及领了出来。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 4:34; 诗篇 58:10–11; 申命记 7:19"> 耶和华在我们眼前施行了大而可怕的神迹奇事，对付埃及，对付法老和他的全家。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 6:18; 申命记 6:10; 出埃及记 13:5"> 他从那里领我们出来，为要把我们带进他起誓要给我们先祖的土地，把那地赐给我们。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 32:39; 诗篇 41:2; 申命记 10:12–13"> 那时耶和华吩咐我们要遵行这一切律例，敬畏耶和华我们的神，使我们终生得福，让我们得以存活，就像今日这样。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 24:13; 罗马书 10:3; 利未记 18:5"> 如果我们照着耶和华我们神所指示的，在他面前谨守遵行这一切诫命，这就是我们的义了。”</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 21:5; 罗马书 9:8; 加拉太书 3:26"> 你们是你们的神耶和华的儿女，不可为死人割伤自己或剃光你们的额顶<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="额顶——原文直译“双眼之间”。">a</a></sup>，</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 7:6; 利未记 20:26; 出埃及记 19:5–6"> 因为你是归属你的神耶和华的圣洁之民；耶和华从地上万民中拣选了你，成为他宝贵的子民。</span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="以西结书 4:14; 罗马书 14:14; 利未记 20:25"> 你不可吃任何可憎之物。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 11:2–45; 使徒行传 10:14; 列王纪上 4:23"> 可以吃的动物是这些：<br /><span className="pl pl-1">牛、绵羊、山羊、</span><br /></span>
<span className="v" id="v5" data-v="5"> <span className="pl pl-1">鹿、羚羊、狍子、</span><br /><span className="pl pl-1">野山羊、羱羊、瞪羚、</span><br /><span className="pl pl-1">岩羊。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="箴言 18:1; 哥林多后书 6:17; 诗篇 1:1–2"> 动物中，凡是分蹄、裂趾为两瓣蹄并且反刍的动物，都可以吃。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 7:22–23; 提多书 1:16; 提摩太后书 3:5"> 然而反刍的或分蹄、裂趾的动物当中，这些不可以吃：<br /><span className="pl pl-1">骆驼、兔子、岩狸，</span><br /><span className="pl pl-1">虽然反刍，却不分蹄，</span><br /><span className="pl pl-1">所以它们对于你们是不洁净的；</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="利未记 11:26–27; 以赛亚书 66:3; 彼得后书 2:22"> <span className="pl pl-1">猪，虽然分蹄，却不反刍，</span><br /><span className="pl pl-1">所以它对于你们是不洁净的。</span><br />不可吃它们的肉，也不可触碰它们的尸体。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="利未记 11:9–12"> 水中的一切，可以吃的是这些：凡是有鳍有鳞的，都可以吃；</span>
<span className="v" id="v10" data-v="10"> 而凡是无鳍无鳞的，都不可吃，它们对于你们是不洁净的。</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11"> 任何洁净的鸟类，你们都可以吃。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 11:13–19"> 不可吃的是这些：<br /><span className="pl pl-1">老鹰、秃鹫、红头雕、</span><br /></span>
<span className="v" id="v13" data-v="13"> <span className="pl pl-1">鸢鹰、小隼、鹰隼与其类，</span><br /></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">各种乌鸦与其类，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="约伯记 30:29"> <span className="pl pl-1">鸵鸟、夜鹰、海鸥、苍鹰与其类，</span><br /></span>
<span className="v" id="v16" data-v="16"> <span className="pl pl-1">小鸮、猫头鹰、白鸮、</span><br /></span>
<span className="v" id="v17" data-v="17"> <span className="pl pl-1">鹈鹕、鹗、鸬鹚、</span><br /></span>
<span className="v" id="v18" data-v="18"> <span className="pl pl-1">白鹳、鹭鸶与其类，</span><br /><span className="pl pl-1">戴胜和蝙蝠。</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="腓立比书 3:19; 利未记 11:20–23"> 任何有翅膀的昆虫，对于你们都是不洁净的，你们不可吃。</span>
<span className="v" id="v20" data-v="20"> 任何洁净的飞鸟，都可以吃。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及记 23:19; 出埃及记 34:26; 利未记 22:8"> 你们不可吃任何自然死去的动物，只可以给你城里的寄居者吃，或者卖给外邦人，因为你是归属你的神耶和华的圣洁之民。你不可用母羊的奶煮小羊羔。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="尼希米记 10:37; 申命记 12:17; 申命记 26:12–15"> 每一年，你都必须把种子的全部收成，就是田地所出产的，献上十分之一。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 12:5–7; 申命记 4:10; 申命记 12:17–18"> 你要在你的神耶和华面前，在他所选择使他的名安居的地方，吃你的五谷、新酒和新油的十一奉献，以及你牛群羊群中头生的，好让你终生学习敬畏耶和华你的神。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 12:21; 申命记 12:5; 申命记 11:24"> 你的神耶和华祝福你的时候，如果你的神耶和华所选择安置他名的地方离你遥远，路程太长，以致你不能把奉献运过去，</span>
<span className="v" id="v25" data-v="25"> 你可以把奉献换成银子，然后装好银子带在手里，到你的神耶和华所选择的地方去。</span>
<span className="v" id="v26" data-v="26" data-xref="传道书 9:7; 申命记 12:7; 马太福音 21:12"> 然后你可以随心所愿用那银子购买牛羊、淡酒烈酒，或者你想要的各样物品。你和你的家人要在那里，在你的神耶和华面前吃喝、欢乐。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 18:20; 申命记 14:29; 申命记 12:12"> 至于你城里的利未人，你不可撇弃他，因为他在你们中间没有份，没有继业。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="申命记 14:22; 阿摩司书 4:4; 申命记 26:12–15"> 每三年的最后一年，你要把当年全部收成的十分之一都拿出来，存放在你城里。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 15:10; 申命记 14:27; 箴言 19:17"> 这样，在你们中间没有份和继业的利未人，以及你城里的寄居者、孤儿和寡妇，都可以来吃得饱足，好使耶和华你的神在你手中所做的一切工作上祝福你。</span>
</div>

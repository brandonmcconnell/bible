<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 31:3; 使徒行传 13:19; 申命记 4:38"> 当耶和华你的神把你带到你将进去占有的那地，并从你面前赶出许多民族，就是七个比你强盛的民族——赫提人、革迦撒人、亚摩利人、迦南人、比利洗人、希未人、耶布斯人，</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 2:2; 出埃及记 23:32–33; 申命记 20:16–17"> 当耶和华你的神把他们交给你，你击败他们的时候，必须把他们灭绝净尽，不可与他们立约，不可恩待他们。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 11:2; 约书亚记 23:12–13; 出埃及记 34:15–16"> 你不可与他们通婚，不可把你的女儿嫁给他们的儿子，也不可为你的儿子娶他们的女儿。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 6:15; 士师记 2:11; 申命记 4:26"> 因为他们会使你的儿女偏离耶和华<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="耶和华——原文直译“我”。">a</a></sup>不跟随他，而去服事别的神，以致耶和华对你们发怒，很快把你们除灭。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 23:24; 申命记 12:2–3; 出埃及记 34:13"> 相反，你们要这样对待他们：拆毁他们的祭坛，打碎他们的神柱，砍倒他们的亚舍拉柱，用火烧掉他们的雕像，</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 14:2; 出埃及记 19:5–6; 彼得前书 2:9"> 因为你是你的神耶和华的圣洁之民；你的神耶和华从地上万民中拣选了你，成为他宝贵的子民。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命记 10:22; 罗马书 9:11–15; 罗马书 11:6"> 耶和华钟爱你们，拣选你们，不是因为你们比其他民族众多——其实你们在万民中是最少的——</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 20:2; 出埃及记 32:13; 以弗所书 2:4–5"> 而是因为耶和华对你们的爱，因他信守向你们祖先所起的誓。因此耶和华用大能的手把你们领了出来，救赎你们脱离那为奴之家，脱离埃及王法老的手。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 10:23; 提摩太后书 2:13; 帖撒罗尼迦后书 3:3"> 你要知道：唯独你的神耶和华是神，是信实的神，他向那些爱他遵守他诫命的人守约施慈爱，直到千代；</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 59:18; 那鸿书 1:2; 罗马书 12:19"> 而向那些恨他的人，他当面报应他们、消灭他们——他必当面报应那恨他的人，毫不迟延。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 14:15; 申命记 4:1; 申命记 5:32"> 所以我今天吩咐你的诫命、律例和法规，你都要谨守遵行。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命记 28:1–14; 申命记 7:9; 利未记 26:3–13"> 那时，因为你们听从这些法规，谨守遵行，你的神耶和华就向你持守他与你先祖起誓立下的约和他的慈爱。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 14:21; 约翰福音 15:10; 申命记 28:3–5"> 他会爱你，祝福你，使你人数增多。在他向你先祖起誓要赐给你的土地上，他会祝福你腹中的胎儿和你土地的出产——你的五谷、新酒和新油，以及你的新生牛犊和羊羔。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 23:26–33; 申命记 28:4; 诗篇 127:3"> 你必蒙福超过万民；在你们中间不会有不育的男人或不孕的女人，在你的牲畜中也是如此。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 15:26; 诗篇 105:36–37; 利未记 26:3–4"> 耶和华会使一切疾病都远离你；你所知道的埃及各样恶疾，他都不加在你身上，而是会降在所有恨你的人身上。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 23:33; 士师记 8:27; 申命记 13:8"> 你要吞灭你神耶和华交给你的所有民族，你眼中不可顾惜他们；你也不可服事他们的神明，因为这会成为你的陷阱。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民数记 13:32; 民数记 33:53; 申命记 18:21"> 也许你心里想：“这些民族比我众多，我怎能赶出他们？”</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 105:5; 申命记 31:6; 申命记 1:29"> 你不要惧怕他们，要好好回想你的神耶和华对法老和全埃及所做的事，</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 4:34; 尼希米记 9:10–11; 耶利米书 32:20–21"> 你亲眼所见的大试炼，神迹和奇事，以及你的神耶和华领你出来时所用大能的手和伸出的膀臂。你的神耶和华必同样对付你所惧怕面对的各民族。</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 24:12; 出埃及记 23:28–30"> 你的神耶和华还会派出黄蜂到他们中间，直到那些残留的和躲藏起来的都从你面前消灭。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米记 1:5; 申命记 10:17; 尼希米记 9:32"> 你不要因他们而恐惧，因为你的神耶和华在你们中间，他是大而可畏的神。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 23:29–30; 约书亚记 15:63"> 你的神耶和华会把这些民族从你面前一点一点地赶出去；你不能一下子消灭他们，免得田野的走兽增多而危害你。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 8:20; 申命记 2:15; 耶利米书 17:18"> 你的神耶和华会把他们交给你，使他们陷入大骚乱，直到他们被除灭。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 10:8; 约书亚记 23:9; 约书亚记 1:5"> 他会把他们的王交在你手中，你要使他们的名从天下消亡；没有人能在你面前站立得住，直到你把他们除灭了。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 32:20; 历代志上 14:12; 申命记 17:1"> 他们神明的雕像要用火烧掉，不可贪图其上的金银，收取归自己，免得你因此陷入圈套，因为它是你神耶和华所憎恶的。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 13:17; 何西阿书 14:8; 以西结书 11:18"> 你不可把可憎之物带进你家里，免得你像它那样成为当灭之物。你要彻底厌恶它，彻底憎恶它，因为那是当灭之物。</span>
</div>

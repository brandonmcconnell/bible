<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 18:8–9; 申命记 10:9; 哥林多前书 9:13–14"> 利未祭司、利未整个支派在以色列人当中没有份，没有继业，他们要吃耶和华的火祭，那就是他们的继业。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 1:5–6; 诗篇 84:11; 彼得前书 2:5"> 利未人在自己的弟兄当中没有继业；照着耶和华向他所应许的，耶和华就是他的继业。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 7:30–34; 申命记 12:27"> 祭司从民众应得的份是这些：那些祭献牛或羊的人，要把祭物的前腿、腮颊和胃肠给祭司。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米记 12:44–47; 民数记 18:12–24; 历代志下 31:4–10"> 你也要把初熟的五谷、新酒和新油，以及初剪的羊毛给祭司。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 10:8; 民数记 3:10; 出埃及记 28:1–14"> 因为你的神耶和华从你各支派中拣选了利未，要让他和他的子孙终生奉耶和华的名侍立事奉。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 35:2–3; 申命记 12:5; 申命记 16:2"> 如果有利未人从你的某一座城，从他所寄居的以色列任何地方离开，随心所愿来到耶和华所选择的地方，</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 31:2–4"> 他可以像在那里侍立于耶和华面前的利未弟兄们那样，奉他的神耶和华的名事奉。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米记 12:44; 尼希米记 12:47; 历代志下 31:4"> 在他变卖家产的所得以外，他还可以享用与他们同等的份额。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命记 12:29–31; 利未记 18:26–27; 利未记 18:30"> 你进入你神耶和华所赐给你的那地以后，不可效法那些民族的可憎行为。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 19:31; 出埃及记 22:18; 利未记 19:26"> 你们中间不可有人让自己的儿女经火，不可有占卜的、算命的、行法术的、行巫术的、</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 19:31; 撒母耳记上 28:11–14"> 念咒的、招魂的、通灵的、求问死人的。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 18:24; 申命记 9:4; 利未记 18:27"> 因为凡是做这些事的人，都是耶和华所憎恶的；正是因为这些可憎之事，你的神耶和华才要把那些民族从你面前赶出去。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 5:48; 创世记 17:1; 创世记 6:9"> 你要在你的神耶和华面前作纯全人。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 14:16; 申命记 18:10; 创世记 20:6"> 你将要赶出的那些民族是听从算命的和占卜的；至于你，你的神耶和华不允许你这样做。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行传 3:22–23; 使徒行传 7:37; 约翰福音 1:45"> 你的神耶和华将从你们中间，从你的弟兄中为你兴起一位像我一样的先知，你们要听从他。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 20:19; 申命记 5:23–28; 申命记 9:10"> 正如在何烈山集会的日子，你向你的神耶和华所说的一切，那时你请求说：“不要让我再听到我的神耶和华的声音，也不要让我再看到这猛烈的火，免得我死亡。”</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 5:28"> 耶和华就对我说：“他们说的好。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 18:15; 约翰福音 8:28; 约翰福音 12:49–50"> 我将从他们的弟兄当中，为他们兴起一位像你一样的先知。我要把我的话放在他口中，他必把我所吩咐的一切都告诉他们。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 3:22–23; 希伯来书 2:3; 希伯来书 10:26"> 那时，如果有人不听从我的话，就是他奉我名所说的话，我必向这人追讨罪责<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="罪责——辅助词语。">a</a></sup>。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 13:1–5; 耶利米书 27:15; 耶利米书 23:13–15"> 但如果有先知擅自奉我的名，说我没有吩咐他说的话，或者奉别神的名说话，那先知必须被处死。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 4:1–3; 帖撒罗尼迦前书 5:24; 启示录 2:2"> 如果你心里想：‘我们怎么知道那不是耶和华说的话？’</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 18:20; 列王纪下 20:1; 耶利米书 28:1–17"> 那么，当先知奉耶和华的名说话，而这话没有成就，没有应验，这话就不是耶和华说的，是那先知擅自说的，你不必怕他。”</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 12:29; 申命记 6:10; 申命记 7:1–2"> 耶和华你的神必剪除那些民族，耶和华你的神把他们的土地赐给你，而你赶出他们，住在他们的城镇和房屋里，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 21:13; 约书亚记 20:2–7; 申命记 4:41–43"> 那时，你要在你的神耶和华赐给你去拥有的那地境内，为自己划分出三座城。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 57:14; 希伯来书 12:13; 以赛亚书 35:8"> 你要为自己测定距离，把你神耶和华使你继承的领地分为三部分，让任何过失杀人的都可以逃到那里。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="民数记 35:15–24; 申命记 4:42; 以赛亚书 30:33"> 过失杀人者逃到那里得以存活的条例是这样：他不是故意杀他的邻人，从前也没有恨恶过他的邻人，</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 35:25; 箴言 27:12; 列王纪下 6:5–7"> 就比如有人与他的邻人一起进入树林砍柴，他抡起手中的斧头去砍树，结果斧头从斧柄上脱落，击中他的邻人，以致邻人死了。他可以逃到其中一座逃城，得以存活。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 35:12; 撒母耳记下 14:7; 申命记 21:22"> 这样免得报血仇者因为心里的怒火而追赶那凶手，由于距离逃城<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="逃城——辅助词语。">a</a></sup>远，就追上了他，夺取他的性命；其实他不该被判处死刑，毕竟他从前没有恨恶过那人。</span>
<span className="v" id="v7" data-v="7"> 所以我吩咐你说：要为自己划分出三座城。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 12:20; 出埃及记 34:24; 出埃及记 23:31"> 耶和华你的神必照着他向你祖先所起的誓，扩张你的边界，把他所应许要赐给你祖先的土地都赐给你——</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 20:7–8; 申命记 11:22–25; 申命记 12:32"> 我今天吩咐你的这一切诫命，你务必谨守遵行，要爱耶和华你的神，一直走在他的道路上——那时，你要在这三座城以外，再增添三座城，</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 59:7; 箴言 6:17; 马太福音 27:4–5"> 以免无辜人的血流在你神耶和华所赐给你的继业之地上，血债就归在你身上了。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 35:16–21; 申命记 27:24; 创世记 9:6"> 但如果有人恨恶他的邻人，对他设下埋伏，起来攻击他，夺取他的性命，邻人死了，之后这人逃到其中的一座城，</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 2:28–34; 列王纪上 2:5–6"> 他本城的长老们就要派人去，把他从那里带回来，交在报血仇者手中，处死他。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 2:31; 申命记 21:9; 申命记 7:16"> 你眼中不可顾惜他，你要从以色列清除无辜人的血债，使你安好。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命记 27:17; 箴言 22:28; 箴言 23:10"> 你在你神耶和华所赐给你去拥有的那地上，在你所继承的产业上，不可挪移你邻人的地界，那是前人所划定的。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数记 35:30; 申命记 17:6; 哥林多后书 13:1"> 人无论犯了什么罪，都不能只凭一个见证人就定他有过犯或罪恶；要凭着两个见证人的口或者三个见证人的口，才能定案。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="诗篇 27:12; 诗篇 35:11; 出埃及记 23:1–7"> 如果有恶意的见证人起来，指证某人犯法，</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 17:9; 申命记 21:5; 玛拉基书 2:7"> 这两个争讼的人就要站在耶和华面前，站在那时在任的祭司和审判官面前。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 13:14; 申命记 17:4; 历代志下 19:6–7"> 审判官要好好调查，如果那见证人是作假见证，以虚谎指证他的弟兄，</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 19:5; 箴言 19:9; 但以理书 6:24"> 那么，他图谋怎样对待自己的弟兄，你们就怎样对待他。你要把这邪恶从你们中间除尽。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 21:21; 申命记 17:13; 申命记 13:11"> 这样，其余的人听见了就会害怕，再也不会在你们中间做这样的恶事了。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 5:38–39; 出埃及记 21:23–25; 申命记 19:13"> 你眼中不可顾惜他，要让他以命偿命，以眼还眼，以牙还牙，以手还手，以脚还脚。</span>
</div>

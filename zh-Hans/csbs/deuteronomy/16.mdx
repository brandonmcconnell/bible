<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 34:18; 出埃及记 12:2–20; 出埃及记 13:4"> 你要谨守亚笔月，向你的神耶和华守逾越节，因为是在亚笔月，你的神耶和华夜间把你从埃及领了出来。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 12:5; 申命记 12:26; 路加福音 22:15"> 你要在耶和华所选择使他的名安居的地方，从羊群牛群中献上逾越节的祭牲给耶和华你的神。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 12:39; 出埃及记 34:18; 出埃及记 12:19–20"> 你不可把这祭牲与有酵之物同吃，七天都要与无酵饼——苦难的饼同吃，因为你是急匆匆出埃及地的；这样你一生一世就能记住你出埃及地的日子。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 34:25; 出埃及记 12:10; 出埃及记 13:7"> 这七天中，在你的全境内不可看到酵；前一天傍晚献祭的肉，一点也不可留到早晨。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 16:2; 申命记 12:5–6"> 你不能在你的神耶和华所赐给你的任意一座城中献上逾越节的祭牲，</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 12:5; 出埃及记 12:6–9; 民数记 9:11"> 只能在你的神耶和华所选择使他的名安居的地方，在傍晚日落的时候，就是你出埃及的时刻，献上逾越节的祭牲。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 35:13; 出埃及记 12:8–9; 约翰福音 2:23"> 你要在你的神耶和华所选择的地方，把祭牲煮了吃。第二天早晨，你可以起身回家<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="家——或译作“自己的帐篷”。">a</a></sup>。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 13:6–8; 利未记 23:6–8; 利未记 23:36"> 你要六天吃无酵饼；到了第七天，要为你的神耶和华举行严肃集会，什么工作都不可做。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 34:22; 出埃及记 23:16; 使徒行传 2:1"> 你要为自己数算七个七日；从庄稼开镰起，数算七个七日。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 16:2; 利未记 12:8; 玛拉基书 3:10–11"> 然后照着你的神耶和华所祝福你的，献上你手中足量的甘心祭物，向你的神耶和华守七七节。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 12:7; 申命记 12:12; 申命记 12:18"> 你和你的儿女、仆婢，以及你城里的利未人，还有你们中间的寄居者、孤儿和寡妇，都要在你的神耶和华所选择使他的名安居的地方，在你的神耶和华面前欢乐。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 15:15; 耶利米哀歌 3:19–20; 罗马书 6:17–18"> 你要记住，你曾在埃及作过奴隶；你要谨守遵行这些律例。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="出埃及记 23:16; 约翰福音 7:2; 历代志下 5:3"> 当你从打谷场和榨酒池收取了出产以后，你要守七天住棚节。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 8:9–12; 申命记 16:11; 以赛亚书 30:29"> 节期中，你和你的儿女、仆婢，以及你城里的利未人、寄居者、孤儿和寡妇，要一同欢乐。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 23:36–42; 申命记 30:16; 申命记 16:10"> 你要在耶和华所选择的地方，向你的神耶和华守七天节期；因为你的神耶和华会在你一切收成和你手中的一切工作上祝福你，你要尽情欢乐。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="箴言 3:9–10; 诗篇 96:8; 哈该书 1:9"> 一年三次，就是除酵节、七七节和住棚节，你所有的男子都要在耶和华所选择的地方，朝见耶和华你的神。他们不可空手朝见耶和华，</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 9:6–7; 哥林多后书 8:12; 申命记 16:10"> 各人要照着你的神耶和华所赐的祝福，带上力所能及的礼物。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="历代志上 23:4; 出埃及记 18:25–26; 罗马书 13:1–6"> 你要在你的神耶和华所赐给你的各城中，按着你的支派，设立审判官和官长。他们要以公义的裁决为百姓施行审判。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 19:15; 出埃及记 23:2; 箴言 17:23"> 你不可屈枉公正，不可顾及情面，也不可收取贿赂，因为贿赂能使智慧人眼瞎，又能曲解义人的证词。</span>
<span className="v" id="v20" data-v="20" data-xref="腓立比书 4:8; 以西结书 18:9; 以西结书 18:5"> 公义，你一定要追求公义，好使你存活，继承你的神耶和华赐给你的那地。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="历代志下 33:3; 列王纪下 17:16; 出埃及记 34:13"> 你为你的神耶和华修筑的祭坛，旁边不可栽下任何树干作为亚舍拉柱。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 26:1; 出埃及记 20:4; 撒迦利亚书 8:17"> 你也不可竖立你的神耶和华所憎恶的神柱。</span>
</div>

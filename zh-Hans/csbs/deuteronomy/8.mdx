<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 4:1; 申命记 5:32–3; 帖撒罗尼迦前书 4:1–2"> 我今天所吩咐你的一切诫命，你们都要谨守遵行，好使你们存活，人数增多，并且进去占有耶和华起誓要给你们先祖的那地。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各书 1:3; 彼得前书 1:7; 申命记 8:16"> 你要回想，这四十年你的神耶和华在旷野中带你走过的整个路程，他是要磨炼你、试验你，要知道你心里想什么，你是否会遵守他的诫命。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 4:4; 路加福音 4:4; 希伯来书 13:5–6"> 他磨炼你，让你挨饿，然后把你和你祖先都不认识的吗哪赐给你吃，是要你明白：人活着不是单靠食物，而是靠耶和华口里所出的每一句话。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米记 9:21; 申命记 29:5; 马太福音 26:25–30"> 这四十年你身上的衣服没有破，脚也没有肿。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 3:19; 箴言 3:12; 撒母耳记下 7:14"> 你心里要明白：你的神耶和华管教你，就像人管教自己的儿子。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 6:31; 申命记 5:33; 撒母耳记上 12:24"> 你要遵守你的神耶和华的诫命，走在他的道路上，敬畏他。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 11:9–12; 出埃及记 3:8; 以西结书 20:6"> 因为你的神耶和华将要把你带进一个美好之地：那地有溪水，有泉眼和深渊的水，流淌在平原和山地；</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 6:13; 诗篇 147:14; 申命记 32:14"> 那地有小麦、大麦、葡萄树、无花果树和石榴树；那地有橄榄油和蜂蜜；</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 22:14; 申命记 33:25; 约书亚记 22:8"> 你在那地不会缺少食物吃，不会缺乏任何东西；那地的石头是铁，山中可以采铜。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 103:2; 罗马书 14:6; 箴言 3:9"> 当你吃得饱足，你要颂赞耶和华你的神，因为他将那美地赐给了你。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="诗篇 106:21; 何西阿书 2:8–9; 箴言 1:32"> 你要谨慎，免得忘记耶和华你的神，不遵守他的诫命、法规和律例，就是我今天所吩咐你的。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 30:9; 申命记 28:47; 申命记 32:15"> 恐怕你吃得饱足，建造了上好的房屋居住，</span>
<span className="v" id="v13" data-v="13" data-xref="约伯记 1:3; 创世记 13:1–5; 路加福音 12:13–21"> 你的牛羊增多，你的金银增多，属于你的一切都增多，</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 106:21; 哥林多前书 4:7–8; 申命记 8:11"> 你就心里高傲，忘记耶和华你的神——是他把你从埃及地为奴之家领了出来；</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 21:6; 民数记 20:11; 耶利米书 2:6"> 是他带你走过那大而可怕，有毒蛇<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="毒蛇——或译作“火蛇”。">a</a></sup>和蝎子的旷野，走过没有水的干涸之地；是他让泉水从坚硬的磐石中为你流出来；</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 8:3; 雅各书 1:12; 出埃及记 16:15"> 是他在旷野里把你祖先不认识的吗哪赐给你吃，为要磨炼你、试验你，使你最终蒙福。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 9:4; 哥林多前书 4:7; 但以理书 4:30"> 你或许心里想：“是我的力量、我手的能力为自己获取了这财富。”</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:22; 何西阿书 2:8; 申命记 7:8"> 但你要记得耶和华你的神，是他赐给你能力获取财富，好成就他与你先祖起誓立下的约，就像今日这样。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 4:26; 撒母耳记上 12:25; 西番雅书 1:18"> 如果你真忘记了耶和华你的神，而跟从别的神，服事它们，向它们下拜，我今天警诫你们：你们必定灭亡。</span>
<span className="v" id="v20" data-v="20" data-xref="但以理书 9:11–12; 历代志下 36:16–17"> 正如耶和华从你们面前消灭的那些民族，照样，你们也必灭亡，因为你们不听从你们的神耶和华的话。</span>
</div>

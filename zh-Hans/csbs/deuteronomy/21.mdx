<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 26:21; 诗篇 5:6; 箴言 28:17"> 在你神耶和华所赐给你去拥有的那地上，如果发现有人被杀，倒在田野上，却不知道是谁杀的，</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 13:3–4; 申命记 16:18–19"> 你的长老和审判官就要出去，测量从被杀之人的位置<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="的位置——辅助词语。">a</a></sup>到周围城镇的距离。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 19:2; 马太福音 11:28–30; 耶利米书 31:18"> 那距离被杀之人最近的城，城里的长老要取来一头没有耕耘过、没有负过轭的小母牛。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前书 2:21–24; 彼得前书 3:18"> 城里的长老们要把小母牛牵到有水常流、从未耕耘播种过的溪谷里，在溪谷里打断小母牛的脖子。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 23:13; 玛拉基书 2:7; 申命记 10:8"> 然后那些利未人祭司要上前来，因为你的神耶和华拣选了他们来事奉他，奉耶和华的名祝福，要由他们来判决所有的争讼和一切打斗的案件。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 73:13; 诗篇 26:6; 诗篇 51:7"> 那距离被杀之人最近的城中所有的长老，要在那溪谷里，在打断了脖子的小母牛上方洗手，</span>
<span className="v" id="v7" data-v="7" data-xref="约伯记 21:21–23; 约伯记 21:31–34; 撒母耳记下 16:8"> 然后声明说：“我们的手没有流这人的血，我们的眼睛也没有看见这事。</span>
<span className="v" id="v8" data-v="8" data-xref="约拿书 1:14; 列王纪下 24:4; 以西结书 23:24–25"> 耶和华啊，求你为你所救赎的子民以色列免除罪责，不要把无辜人的血债归在你子民以色列中间。”这样，他们就被赎清了杀人流血的罪责。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 19:12–13; 列王纪下 10:30–31; 申命记 13:18"> 你就从你们中间除尽了无辜人的血债，你是做了耶和华眼中看为正的事。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命记 20:10–16; 约书亚记 21:44"> 当你出去与仇敌作战，你的神耶和华把他们交在你手中，你掳走他们为俘虏时，</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 31:10; 创世记 34:3; 创世记 12:14–15"> 如果你在俘虏中看见一个俊美的女子，爱慕她，要娶她为妻，</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 14:9; 民数记 6:9; 以弗所书 4:22"> 你就可以把她带回你家里。她要剃头发，剪指甲，</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 45:10–11; 路加福音 14:26–27"> 从身上脱去被掳时的衣服，住在你家里为她父母哀哭一整个月。此后你可以与她同房，作她的丈夫，她就成为你的妻子了。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 22:29; 创世记 34:2; 申命记 22:19"> 但如果你不喜欢她了，那时你要按着她的意愿让她走，绝对不可拿她卖钱，也不可奴役她，因为你已经玷辱了她。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="创世记 29:33; 创世记 29:20; 创世记 29:18"> 如果某人有两个妻子，一个被宠爱，一个被嫌弃，那被宠爱的和被嫌弃的都为他生了儿子，而长子是那被嫌弃的所生，</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 26:10; 历代志上 5:2; 历代志下 21:3"> 那么，到了让儿子们继承他产业的时候，他不可偏心，把长子的权利给被爱之妻的儿子，不给被嫌之妻的儿子——他头生的儿子。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 49:3; 创世记 25:31–34; 诗篇 105:36"> 他必须承认那被嫌之妻的儿子为长子，从自己的全部产业中给他双倍，因为他是自己强壮时头生的，长子的权利属于他。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未记 19:3; 出埃及记 20:12; 阿摩司书 4:11–12"> 如果某人有一个儿子顽梗悖逆，不听从父母的话，父母管教他，他还是不听从，</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 13:3; 申命记 21:2; 申命记 16:18"> 他的父母就要拉住他，带到本地的城门口，本城的长老们那里。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 23:29–35; 箴言 20:1; 箴言 23:19–21"> 他们要对本城的长老说：“我们这儿子顽梗悖逆，不听从我们的话，贪吃酗酒。”</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 19:19–20; 申命记 13:10–11; 利未记 24:16"> 全城的人就要用石头砸死他。你要把这邪恶从你们中间除尽。这样，全以色列听见了就会害怕。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约翰福音 19:31–38; 使徒行传 26:31; 路加福音 23:33"> 如果某人犯了该判死刑的罪，被处死了，你把他挂在木头上，</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 3:13; 约翰福音 19:31; 哥林多后书 5:21"> 你不可让他的尸体在那木头上过夜，必须当天把他埋葬，因为被挂之人是神所诅咒的，你不可玷污你神耶和华所赐给你为继业的土地。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 11:31; 申命记 4:38; 申命记 1:28"> 以色列啊，你要听：你今天即将过约旦河，进去赶出那些比你强大的民族，他们的城雄伟坚固，高得顶天，</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 13:22; 那鸿书 1:6; 申命记 7:24"> 这民雄伟高大，是你所知道的亚衲子孙，而且你也听说过：“谁能站在亚衲子孙面前？”</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 4:24; 希伯来书 12:29; 罗马书 8:31"> 你今天要知道：你的神耶和华将要如吞噬的烈火在你前面过去，他将亲自除灭他们，亲自在你面前制伏他们。你必赶出他们，很快消灭他们，正如耶和华向你所应许的。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 8:17; 申命记 9:5; 申命记 18:9–14"> 当你的神耶和华把他们从你面前驱逐出去时，你不要心里想：“耶和华把我带进来占有这地，是因着我的义。”其实耶和华把他们从你面前赶出去，是因这些民族的邪恶。</span>
<span className="v" id="v5" data-v="5" data-xref="提多书 3:5; 创世记 17:8; 创世记 26:4"> 你进去占有他们的土地，不是因为你有义，也不是因为你心里正直；而是因为这些民族邪恶，你的神耶和华才把他们从你面前赶出去，为要成就耶和华向你先祖亚伯拉罕、以撒、雅各所起的誓。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 10:16; 使徒行传 7:51; 申命记 31:27"> 所以你要知道：你的神耶和华把这美地赐给你去占有，并不是因为你的义，其实你是硬着颈项的子民。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 16:2; 出埃及记 14:11; 民数记 21:5"> 你要记住，不要忘记你曾在旷野怎样惹怒耶和华你的神。从你们出埃及地的那天起，直到你们来到这地方，你们一直悖逆耶和华。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 106:19–22; 出埃及记 32:16; 出埃及记 32:7–10"> 你们在何烈山惹怒了耶和华，耶和华就对你们发怒，要把你们除灭了。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 34:28; 出埃及记 24:18; 列王纪上 19:8"> 当时我上了山，去领受石版，就是耶和华与你们立约的石版。我留在山上四十昼夜，不吃饭不喝水。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 31:18; 希伯来书 8:10; 申命记 10:4"> 耶和华把两块石版交给了我，是神用手指写成的，上面是耶和华在集会那天，在山上从火焰中对你们所说的一切话。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 9:9; 民数记 10:33; 希伯来书 8:6–10"> 过了四十昼夜，耶和华把那两块石版，就是约版，交给了我。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及记 32:7–8; 申命记 31:29; 士师记 2:17"> 然后耶和华对我说：“起来，赶快从这里下去，因为你从埃及领出来的子民已经败坏了。他们很快就偏离了我所指示他们的道路，为自己铸造偶像。”</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 9:6; 列王纪下 17:14; 申命记 10:16"> 耶和华又告诉我说：“我看见这子民，看哪，他们是硬着颈项的子民！</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 29:20; 出埃及记 32:10–13; 诗篇 9:5"> 任凭我吧，我要除灭他们，从天下抹掉他们的名号！我却要使你成为一个比他们强盛的民族。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及记 19:18; 申命记 5:23; 申命记 4:11"> 我转身从山上下来，山在火焰中燃烧，两块约版在我的两手中。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 32:19; 使徒行传 7:40–41"> 我观看，看哪，你们已经对你们的神耶和华犯罪，为自己造了一个牛犊铸像。你们很快就偏离了耶和华所指示你们的道路！</span>
<span className="v" id="v17" data-v="17"> 于是我举起那两块石版，从两手中甩出去，在你们眼前摔碎了。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 34:28; 申命记 9:9; 诗篇 106:23"> 因着你们犯这一切罪，做耶和华眼中看为恶的事，惹他恼怒，我就像先前那样，俯伏在耶和华面前四十昼夜，不吃饭不喝水。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 10:10; 出埃及记 32:14; 雅各书 5:16–17"> 我实在因耶和华的怒气和怒火而害怕，因为他对你们发怒，要除灭你们；但那一次耶和华又垂听了我。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 32:35; 出埃及记 32:21; 希伯来书 7:26–28"> 耶和华也对亚伦大大发怒，要除灭他，那时我也为亚伦代祷。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 32:20; 以赛亚书 31:7; 以赛亚书 2:18–21"> 我把你们的罪恶之物，就是你们造的牛犊拿过来，用火焚烧，然后打碎彻底碾磨，磨成粉末，把这粉末扔进了山上流下来的溪水里。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数记 11:34; 出埃及记 17:7; 民数记 11:1–5"> 在塔备拉、玛撒、基布罗-哈特瓦，你们继续惹怒耶和华。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 106:24–25; 希伯来书 4:2; 诗篇 78:22"> 耶和华从加低斯-巴尼亚派遣你们，说：“上去占有我所赐给你们的那地”，那时你们也违背了你们的神耶和华的命令，不相信他，不听从他的话。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 31:27; 使徒行传 7:51; 申命记 9:6–7"> 从我认识你们那天起，你们就一直悖逆耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="申命记 9:18; 申命记 9:16"> 那时，我俯伏在耶和华面前四十昼夜；我这样伏下，是因为耶和华说要把你们除灭。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 32:11–13; 提多书 2:14; 诗篇 107:2"> 我向耶和华祷告说：<br />“主耶和华啊，求你不要毁灭你的子民、你的继业，就是凭你的大能所救赎、用大能的手从埃及领出来的。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 14:21; 弥迦书 7:18–19; 撒母耳记上 25:25"> 求你记念你的仆人亚伯拉罕、以撒和雅各；不要追究这子民的顽固，以及他们的邪恶和罪过，</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 14:16; 出埃及记 32:12"> 免得你领我们出来的那地方的人说：‘耶和华因为不能领他们进入所应许之地，又因为他恨恶他们，所以把他们领出来，要在旷野害死他们。’</span>
<span className="v" id="v29" data-v="29" data-xref="尼希米记 1:10; 列王纪上 8:51; 申命记 9:26"> 毕竟他们是你的子民、你的继业，是你以伟大的能力和伸出的膀臂领出来的。”</span>
</div>
</div>

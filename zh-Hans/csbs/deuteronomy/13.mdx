<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 23:25–28; 约翰一书 4:1; 耶利米书 29:8"> <sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="此章在马索拉文本为13:2至13:19。">a</a></sup>如果你们当中有先知或做异梦的人起来，向你预言一个神迹或奇事，</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 13:6; 马太福音 7:22–23; 启示录 13:13–14"> 结果他对你说的神迹或奇事应验了，于是他说：“我们去跟从你不认识的别神，服事它们吧”，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 8:2; 哥林多前书 11:19; 诗篇 66:10"> 你不可听从那先知或那做异梦之人的话，其实你们的神耶和华是在试验你们，想知道你们是否全心、全灵爱耶和华你们的神。</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 1:10; 申命记 10:20; 哥林多前书 6:17"> 你们要跟从耶和华你们的神，敬畏他，遵守他的诫命，听从他的话，服事他，紧紧跟随他。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 5:13; 申命记 18:20; 耶利米书 14:15"> 那先知或那做异梦的人要被处死，因为他说了反叛的话，反叛那领你们出埃及地、救赎你们脱离为奴之家的耶和华你们的神，引诱你偏离你的神耶和华所指示你当走的路。你要把这邪恶从你们中间除尽。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="申命记 17:2–7; 彼得后书 2:1; 以弗所书 4:14"> 如果你的同母兄弟，或者你的儿女、你怀中的妻子、你知心的朋友，暗中怂恿你说：“我们去服事别的神吧”——那是你和你祖先不认识的，</span>
<span className="v" id="v7" data-v="7"> 是从地这边到地那边、远近四围那些民族的神明——</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 19:13; 箴言 1:10; 申命记 7:16"> 你不可答应他，不可听从他，你眼中也不可顾惜他。你不可怜恤、包庇他，</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 7:58; 路加福音 14:26; 马太福音 10:37"> 而必须把他杀了。你要先动手处死他，然后全体民众要动手。</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 7:25; 利未记 24:14–16; 出埃及记 20:2"> 你要用石头砸死他，因为他想引诱你离开耶和华你的神，就是把你从埃及地为奴之家领出来的那一位。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 19:20; 申命记 17:13; 提摩太前书 5:20"> 这样，全以色列都将听到而害怕，你们中间再不会有人做这样的恶事了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="士师记 20:1–17; 约书亚记 22:11–34"> 如果在你的神耶和华赐给你居住的某城，你听说</span>
<span className="v" id="v13" data-v="13" data-xref="约翰一书 2:19; 申命记 13:2; 哥林多后书 6:15"> 你们中间出现一些卑劣之徒，引诱本城的居民说：“我们去服事别的神吧”——那是你们不认识的神——</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 17:4; 以赛亚书 11:3–4; 约翰福音 7:24"> 你就要调查、探听，好好询问。如果确定了这事是真的，有这可憎之事发生在你们中间，</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 22:20; 利未记 27:28; 申命记 7:2"> 你必须用刀击杀那城的居民，把那城和其中的一切灭绝净尽，城里的牲畜也灭绝于刀刃之下。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 49:2; 约书亚记 8:28; 以赛亚书 25:2"> 然后你要把城里的一切财物都聚集到广场中间，把那城和其中的一切财物都放火烧了，归于耶和华你的神为全烧祭。那城要成为永远的废堆，不得重建。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 26:4; 申命记 7:26; 约书亚记 7:26"> 当灭之物中任何东西都不可沾染你的手，好使耶和华收回他猛烈的怒气，向你施怜悯。他必怜悯你，照着他向你祖先所起的誓，使你人数增多，</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 12:28; 马太福音 7:21; 申命记 12:25"> 因为你听从了你的神耶和华的话，遵守了我今天所吩咐你的一切诫命，做了耶和华你的神眼中看为正的事。</span>
</div>
</div>

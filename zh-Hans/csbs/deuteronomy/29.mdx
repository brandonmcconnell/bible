<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 5:2–3; 希伯来书 8:9; 出埃及记 24:2–8"> <sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="此章在马索拉文本为28:69至29:28。">a</a></sup>耶和华在何烈山与以色列子孙立约之外，也在摩押地指示摩西与他们立约，以下是立约的话语。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 19:4; 出埃及记 8:12; 约书亚记 24:5–6"> 摩西召来全体以色列人，对他们说：<br />耶和华在你们眼前，在埃及地对法老和他所有臣仆以及在他全地所做的一切，你们都已经看到了，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 4:32–35; 尼希米记 9:9–11; 申命记 7:18–19"> 就是你们亲眼看到的大试炼，那些极大的神迹和奇事。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 4:18; 以赛亚书 6:9–10; 箴言 20:12"> 但耶和华至今没有赐给你们能明白的心、能看见的眼睛、能听见的耳朵。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 8:4; 尼希米记 9:21; 申命记 8:2"> 四十年之久，我带你们走在旷野，你们身上的衣服没有破，脚上的鞋也没有烂，</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 8:3; 以弗所书 5:18; 哥林多前书 9:25"> 你们没有吃饼，也没有喝淡酒烈酒，这是让你们知道“我耶和华是你们的神”。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 2:24–17; 民数记 32:33–42; 诗篇 135:10–12"> 你们来到这地方的时候，希实本王西宏和巴珊王欧革出来迎战我们，但我们击败了他们，</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 3:12–13; 民数记 32:33"> 并夺取他们的领土，分给了鲁本人、迦得人、玛拿西半支派的人为继业。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 2:3; 申命记 4:6; 路加福音 11:28"> 所以你们要谨守遵行这约上的话语，好让你们所做的一切都通达。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约珥书 2:16–17; 启示录 20:12; 申命记 31:12–13"> 今天你们全都站在你们的神耶和华面前——包括你们众支派的首领，你们的长老和官长，以色列的所有男子，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 12:38; 约书亚记 9:21–27; 出埃及记 12:48–49"> 你们的孩子、妻子，以及在你营中为你砍柴打水的寄居者——</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 15:12–15; 列王纪下 11:17; 申命记 5:2–3"> 为要进入你的神耶和华的约，进入你的神耶和华今天与你所立的誓言，</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 6:7; 创世记 17:7; 申命记 28:9"> 好让他今天确立你作他的子民，而他作你的神，正如他向你所应许的，向你先祖亚伯拉罕、以撒、雅各所起的誓。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 31:31–34; 希伯来书 8:7–12"> 他<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="他——原文直译“我”。">b</a></sup>不仅仅与你们立这约和这誓言；</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 2:39; 哥林多前书 7:14; 耶利米书 50:5"> 他是与今天一同站在我们神耶和华面前的人立约，也与今天没有一同站在这里的人立约。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命记 2:19; 申命记 2:9; 申命记 2:4"> 你们都知道，我们怎样住在埃及地，又怎样从那些民族中间经过；</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 28:36"> 也看见了他们的可憎之物，以及他们中间那些木、石、金、银的偶像。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 12:15; 申命记 11:16–17; 申命记 13:1–15"> 现在恐怕你们中间有人——或男或女，或家族或支派，心思转离耶和华我们的神，去服事那些民族的神明。恐怕你们中间有恶根长出苦毒，</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 7:24; 民数记 15:30; 民数记 15:39"> 有人听见这誓言，心中却暗自庆幸说：“即使我随着顽固的心行事，还是会有平安！”这样湿地和旱地就会一起被摧毁。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 74:1; 诗篇 79:5; 申命记 9:14"> 耶和华绝不愿赦免他，那时耶和华的怒气和妒火必向这人燃起，写在这书卷上的一切诅咒会降在他身上，耶和华必从天下抹掉他的名。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 25:41; 约书亚记 7:1–26; 以西结书 13:9"> 耶和华必照着这律法书上所写圣约的一切诅咒，把他从以色列所有支派中分别出来，使他遭受祸患。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="耶利米书 19:8"> 这样，在你们之后兴起的后代子孙，以及从遥远之地而来的外邦人将会议论，因为他们将看到这地的灾害和耶和华降在这地上的疾病——</span>
<span className="v" id="v23" data-v="23" data-xref="西番雅书 2:9; 耶利米书 17:6; 以赛亚书 34:9"> 遍地都是硫磺、盐碱，是烧毁之地，没有耕种，没有出产，地上不能长出任何植物，就像耶和华在怒气和怒火中覆灭的所多玛、格摩拉、押玛和洗扁那样——</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 22:8–9; 列王纪上 9:8–9; 罗马书 2:5"> 列国都会说：“耶和华为什么如此对待这地呢？这样大发烈怒是为了什么呢？”</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 8:9; 以赛亚书 47:6; 耶利米书 50:7"> 人们会说：“是因为他们离弃了祖先的神耶和华的约，就是他从埃及地把他们领出来时，与他们所立的约；</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 28:64; 士师记 2:12–13; 士师记 5:8"> 而去服事别的神，向他们不认识的、耶和华没有指定给他们的神明下拜。</span>
<span className="v" id="v27" data-v="27" data-xref="但以理书 9:11–14; 申命记 28:15–68; 申命记 27:15–26"> 所以耶和华的怒气向这地发作，使写在这书卷上的一切诅咒都临到这地。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 7:20; 列王纪上 14:15; 诗篇 52:5"> 耶和华在怒气、怒火和极大的震怒中，把他们从自己的土地上拔出来，扔到异国，就像今日这样。”</span>
<span className="v" id="v29" data-v="29" data-xref="但以理书 2:22; 使徒行传 1:7; 罗马书 11:33–34"> 隐秘的事属于耶和华我们的神，显明的事永远属于我们和我们的子孙，好让我们遵行这律法的一切话语。</span>
</div>

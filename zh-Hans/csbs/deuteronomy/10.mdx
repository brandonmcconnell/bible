<span className="v" id="v1" data-v="1" data-xref="出埃及记 34:1–2; 出埃及记 25:10–15; 申命记 10:3–4"> 那时，耶和华对我说：“你要凿出两块石版，与先前一样，然后上山到我这里来；还要做一个木柜。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 8:9; 申命记 10:5; 申命记 4:13"> 我要把你先前摔碎的石版上的话，写在这两块石版上，然后你要把它们放在木柜里。”</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 34:4; 出埃及记 37:1–9; 出埃及记 25:10"> 于是，我用金合欢木做了一个柜，又凿出两块与先前一样的石版，然后手里拿着这两块石版上山去。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 9:10; 出埃及记 34:28; 希伯来书 12:18–19"> 耶和华就把十诫写在这两块石版上，与先前他在集会那天，在山上从火焰中向你们宣告的一样。然后，耶和华把它们交给我。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 34:29; 出埃及记 40:20; 申命记 10:2"> 我转身下了山，把石版放在我做的柜里，石版一直在那里，正如耶和华指示我的。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数记 33:38; 民数记 20:23–28; 民数记 33:30–33"> 之前，以色列子民从比罗-比尼-亚干起行，到莫西洛。亚伦死在那里，就葬在那里，他的儿子以利亚撒接替他作祭司。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 33:32–34"> 然后他们从那里起行到古德格达，又从古德格达来到溪水之地约特瓦塔。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 21:5; 申命记 18:5; 民数记 6:23–26"> 那时耶和华把利未支派分别出来，让他们扛抬耶和华的约柜，侍立在耶和华面前事奉他，并且奉他的名祝福，直到如今。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 44:28; 民数记 18:20–24; 申命记 18:1–2"> 所以利未在他的兄弟们当中没有份，没有继业；照着你的神耶和华向他所应许的，耶和华就是他的继业。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命记 9:18–19; 申命记 9:25; 出埃及记 34:28"> 我像前一次那样，留在山上四十昼夜，这一次耶和华也垂听了我，耶和华不愿毁灭你。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 33:1; 出埃及记 32:34"> 耶和华对我说：“起来，带领这子民前行吧，领他们进去继承我向他们先祖起誓要赐给他们的那地。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="弥迦书 6:8; 申命记 6:5; 路加福音 10:27"> 以色列啊，现在耶和华你的神要求你什么呢？他只要你敬畏耶和华你的神，走在他的一切道路上，爱他，全心、全灵服事耶和华你的神，</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 32:39; 申命记 6:24; 雅各书 1:25"> 遵守我今天所吩咐你的、耶和华的诫命和律例，好让你得福。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 19:5; 诗篇 24:1; 诗篇 115:16"> 看哪，天和天上的天，地和地上的一切，都属于耶和华你的神，</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 4:37; 申命记 7:7–8; 罗马书 9:13–23"> 但耶和华钟爱你的祖先，喜爱他们，从万民中拣选了他们的后裔，就是你们，像今日这样。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 4:4; 申命记 30:6; 利未记 26:41"> 所以你们要给你们心上的包皮行割礼，不要再硬着颈项。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 10:34; 罗马书 2:11; 但以理书 2:47"> 因为耶和华你们的神，他是万神之神、万主之主，是伟大、全能、可畏的神，他不顾及情面，也不收取贿赂；</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 146:9; 诗篇 68:5; 耶利米书 49:11"> 他为孤儿和寡妇施行公正，又关爱寄居者，赐给他们食物和衣服——</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 22:21; 利未记 19:33–34; 路加福音 17:18"> 所以你们要关爱寄居者，因为你们在埃及地也作过寄居者。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 6:13; 申命记 13:4; 路加福音 4:8"> 你要敬畏耶和华你的神，唯独服事他，紧紧跟随他，要指着他的名起誓。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 17:14; 诗篇 106:21–22; 出埃及记 15:2"> 他是你当赞美的；他是你的神，是他为你施行了你亲眼所见的那些大而可畏的事；</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 46:27; 出埃及记 1:5; 创世记 15:5"> 你的祖先共七十人下埃及，而如今你的神耶和华使你多如天上的星辰。</span>

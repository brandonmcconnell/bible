<span className="v" id="v2" data-v="2" data-xref="撒迦利亚书 1:6; 申命记 28:15; 提摩太前书 4:8"> 如果你听从你的神耶和华的吩咐，这一切祝福就会临到你、追随你：</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 144:12–15; 创世记 39:5; 哈该书 2:19"> <span className="pl pl-1">你在城中蒙福，在田间也蒙福。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 10:22; 创世记 49:25; 申命记 7:13"> <span className="pl pl-1">你腹中的胎儿</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="胎儿——原文直译“果实”；本章下同。">a</a></sup><br /><span className="pl pl-1">、土地的出产</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="出产——原文直译“果实”；本章下同。">b</a></sup><br /><span className="pl pl-1">、牲畜的幼仔</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="幼仔——原文直译“果实”；本章下同。">c</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">你的牛犊和羊羔，都蒙福。</span><br /></span>

</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 22:38–41; 利未记 26:7–8; 诗篇 89:23"> 耶和华会使那些起来攻击你的仇敌败在你面前；他们从一条路出来攻击你，却将在你面前从七条路逃跑。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 15:10; 利未记 26:10; 箴言 3:9–10"> 在你的仓库里，以及你手所劳作的一切事上，耶和华都会赐福给你；你的神耶和华必在他赐给你的那地上祝福你。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 19:5–6; 申命记 7:6; 申命记 26:18–19"> 如果你遵守你的神耶和华的诫命，走在他的道路上，耶和华就会照着他向你所起的誓，坚立你作他圣洁的子民。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 7:14; 申命记 11:25; 耶利米书 33:9"> 那时，地上的万民看见你被称为耶和华名下的人，就会惧怕你。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 30:9; 箴言 10:22; 利未记 26:9"> 在耶和华向你先祖起誓要赐给你的土地上，耶和华会使你兴旺，祝福你腹中的胎儿、牲畜的幼仔和土地的出产。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 15:6; 约珥书 2:23–24; 申命记 15:10"> 耶和华会为你敞开诸天他福份的宝库，按时给你的土地赐下雨水，祝福你手中的一切工作。你将借贷给许多民族，自己却不用借。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 28:1; 申命记 4:6–9; 腓立比书 1:27"> 耶和华会使你作头不作尾，居上不居下——只要你听从我今天所吩咐你的话语，谨守遵行你的神耶和华的诫命；</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 30:21; 申命记 5:32; 申命记 11:16"> 我今天所吩咐你们的一切话语，你不可偏离左右，不可去跟从别的神，服事它们。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="玛拉基书 2:2; 申命记 28:2; 申命记 29:20"> 那时，如果你不听从你的神耶和华的吩咐，不谨守遵行我今天所指示你的一切诫命和律例，这一切诅咒就会临到你、追随你：</span>
<span className="v" id="v16" data-v="16" data-xref="玛拉基书 3:9–12; 箴言 3:33; 约珥书 1:4"> <span className="pl pl-1">你在城中受诅咒，在田间也受诅咒。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="哈该书 1:6; 申命记 28:5; 诗篇 69:22"> <span className="pl pl-1">你的篮子和揉面盆受诅咒。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="利未记 26:26; 利未记 26:19–20; 约伯记 18:16–19"> <span className="pl pl-1">你腹中的胎儿、土地的出产，</span><br /><span className="pl pl-1">你的牛犊和羊羔，都受诅咒。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="申命记 28:6; 士师记 5:6–7; 历代志下 15:5"> <span className="pl pl-1">你出也受诅咒，入也受诅咒。</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 66:15; 玛拉基书 2:2; 申命记 4:26"> 因为你行恶离弃了耶和华，耶和华必在你所做的，就是你手所劳作的一切事上，给你降下诅咒、骚乱和责罚，直到你被除灭，很快灭亡。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 26:25; 耶利米书 24:10; 耶利米书 16:4"> 耶和华会使瘟疫紧跟着你，直到他把你从你将要进去拥有的那地上灭绝。</span>
<span className="v" id="v22" data-v="22" data-xref="阿摩司书 4:9; 利未记 26:16; 哈该书 2:17"> 耶和华会用痨病、热病、炎症、酷热、刀剑、枯焦和霉烂打击你，它们将追赶你，直到你灭亡。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 26:19; 耶利米书 14:1–6; 列王纪上 18:2"> 你头上的天将成为铜，你脚下的地将成为铁。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 28:12; 以赛亚书 5:24; 阿摩司书 4:11"> 耶和华会使你地上的雨水成为灰尘和尘土，从天上降在你身上，直到你被除灭。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 30:17; 以西结书 23:46; 耶利米书 24:9"> 耶和华会使你败在你的仇敌面前，你从一条路出来攻击他，却将在他面前从七条路逃跑；你的遭遇<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="遭遇——辅助词语。">d</a></sup>将令地上的万国战兢。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 34:20; 耶利米书 16:4; 耶利米书 7:33"> 你的尸体将给天空的一切飞鸟和地上的走兽作食物，无人吓走它们。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 5:6; 申命记 28:35; 利未记 21:20"> 耶和华会用埃及的疮，用肿瘤、癣和疥疮打击你，都是你不能治愈的。</span>
<span className="v" id="v28" data-v="28" data-xref="帖撒罗尼迦后书 2:9–11; 以赛亚书 19:11–17; 以赛亚书 6:9–10"> 耶和华会用疯狂、瞎眼和心里昏乱打击你；</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 59:10; 约伯记 5:14; 士师记 6:1–6"> 你即使在正午也要摸索，就像瞎眼的在幽暗中摸索一样。你的道路不会顺利，你终生只会受欺压、被抢夺，没有人拯救。</span>
<span className="v" id="v30" data-v="30" data-xref="阿摩司书 5:11; 耶利米书 8:10; 约伯记 31:10"> 你与一个女人订了婚，却会有别的男人与她同睡；你建造了房屋，却不能住在其中；你栽种了葡萄园，却不能享用。</span>
<span className="v" id="v31" data-v="31" data-xref="约伯记 1:14–15; 士师记 6:1"> 你的牛在你眼前被宰杀，你却吃不到它；你的驴从你面前被抢夺，不会归还给你；你的羊被交给你的仇敌，没有人救助你。</span>
<span className="v" id="v32" data-v="32" data-xref="约珥书 3:6; 申命记 28:41; 约伯记 17:5"> 你的儿女会被交给外邦人，你的眼睛终日张望甚至失明，你的手却无能为力。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 5:17; 申命记 28:29–30; 以赛亚书 1:7"> 你土地的出产和你的一切辛苦所得，会被你所不认识的民族吃掉，你终生只会受欺压，被压迫；</span>
<span className="v" id="v34" data-v="34" data-xref="启示录 16:10–11; 申命记 28:68; 以赛亚书 33:14"> 你必因你眼见的景象而发疯。</span>
<span className="v" id="v35" data-v="35" data-xref="申命记 28:27; 以赛亚书 3:24; 以赛亚书 3:17"> 耶和华会打击你，使不能治愈的恶疮临到你膝盖上、大腿上，从脚掌直到头顶。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="耶利米书 16:13; 申命记 4:28; 列王纪下 25:11"> 耶和华会把你和你所立的王带到你和你祖先不认识的国家去，你将要在那里服事别的神——那些木头和石头。</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 25:9; 列王纪上 9:7–8; 耶利米书 24:9"> 你将在耶和华引领你去的万民中，令人惊骇、成为笑柄、被人讽刺。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="哈该书 1:6; 弥迦书 6:15; 约珥书 1:4"> 你在田里撒出去很多种子，收回来的却很少，因为蝗虫会吃掉它。</span>
<span className="v" id="v39" data-v="39" data-xref="以赛亚书 17:10–11; 约珥书 2:2–4; 约拿书 4:7"> 你栽种、耕耘葡萄园，却喝不到葡萄酒，收不到葡萄，因为虫子会吃掉它。</span>
<span className="v" id="v40" data-v="40" data-xref="弥迦书 6:15; 诗篇 23:5; 诗篇 104:15"> 你全境都有橄榄树，却不能用油抹身，因为你的橄榄会未熟而落。</span>
<span className="v" id="v41" data-v="41" data-xref="申命记 28:32; 耶利米哀歌 1:5; 列王纪下 24:14"> 你生了儿女，却不属于你，因为他们将被掳去。</span>
<span className="v" id="v42" data-v="42" data-xref="阿摩司书 7:1–2; 申命记 28:38–39"> 蝗虫会吃光<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="吃光——原文直译“占有”。">e</a></sup>你的一切树木和你土地的出产。</span>
<span className="v" id="v43" data-v="43" data-xref="申命记 28:13; 撒母耳记上 13:19–23; 列王纪下 17:20"> 你们中间的寄居者会升高到你之上，越升越高；你却会降卑，越降越卑微。</span>
<span className="v" id="v44" data-v="44" data-xref="申命记 28:12–13; 耶利米哀歌 1:5"> 他借给你，你却不能借给他；他作头，你却会作尾。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="申命记 28:15; 以赛亚书 1:20; 耶利米书 24:9–10"> 这一切诅咒都会临到你，它们将追赶你，赶上你，直到你被除灭，因为你不听从你的神耶和华的吩咐，不遵守他所指示你的诫命和律例。</span>
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 8:18; 申命记 28:37; 以西结书 14:8"> 这些诅咒会临到你和你的后裔，成为标记和奇迹，直到永远。</span>
<span className="v" id="v47" data-v="47" data-xref="申命记 16:11; 申命记 12:7–12; 尼希米记 9:35–37"> 因为你在一切丰盛中，没有欢心乐意地服事耶和华你的神，</span>
<span className="v" id="v48" data-v="48" data-xref="耶利米书 28:13–14; 耶利米哀歌 5:2–6; 以西结书 4:16–17"> 所以你必在饥饿、干渴、赤身以及一切缺乏中，服事耶和华所派遣攻击你的那些仇敌。耶和华会把铁轭放在你的脖子上，直到把你除灭。</span>
<span className="v" id="v49" data-v="49" data-xref="耶利米哀歌 4:19; 耶利米书 49:22; 耶利米书 48:40"> 耶和华会从远方，从地极带来一个民族，像老鹰那样疾飞攻击你。那民族你听不懂他们的语言，</span>
<span className="v" id="v50" data-v="50" data-xref="以赛亚书 47:6; 历代志下 36:17; 路加福音 21:23–24"> 那民族面貌凶猛，不眷顾老年人，也不恩待少年人。</span>
<span className="v" id="v51" data-v="51" data-xref="申命记 28:33; 以赛亚书 62:8; 利未记 26:26"> 它会吞噬你牲畜的幼仔和土地的出产，直到你被除灭。它不会给你留下五谷、新酒和新油，以及你的牛犊和羊羔，直到把你消灭。</span>
<span className="v" id="v52" data-v="52" data-xref="耶利米书 52:4–7; 以西结书 4:1–8; 马太福音 24:15–16"> 它会把你围困在你的各城里，直到你在全地所依靠的那些高大、坚固的城墙倒塌了；它必在你的神耶和华赐给你的全地上，在你的各城围困你。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="耶利米哀歌 4:10; 耶利米书 19:9; 利未记 26:29"> 你会在仇敌对你的摧残中，在围困和压迫中，吃你亲生儿女<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="亲生儿女——原文直译“腹中的出产”。">f</a></sup>的肉——你神耶和华赐给你的儿女的肉。</span>
<span className="v" id="v54" data-v="54" data-xref="申命记 15:9; 马太福音 20:15; 申命记 13:6"> 你们中间最温柔娇贵的男人，也会恶眼看待他的兄弟、他怀中的妻子、他剩下的儿女，</span>
<span className="v" id="v55" data-v="55" data-xref="耶利米书 34:2; 耶利米书 52:6; 耶利米书 5:10"> 甚至不把他所吃儿女的肉，分一些给他们中的一个；因为在你的各城里，在仇敌对你的摧残中，在围困和压迫中，他没有剩下任何东西。</span>
<span className="v" id="v56" data-v="56" data-xref="申命记 28:54; 以赛亚书 3:16; 耶利米哀歌 4:3–6"> 你们中间温柔娇贵的女人，就是那因娇气、娇弱而不肯尝试把脚掌放在地上的，也会恶眼看待她怀中的丈夫、她的儿子和女儿。</span>
<span className="v" id="v57" data-v="57" data-xref="以赛亚书 49:15; 创世记 49:10"> 甚至她两腿间出来的胎胞和生下的儿女，她也会在你城里，在仇敌对你的摧残中，在围困和压迫中，因缺乏一切而暗中吃掉他们。</span>
</div>
<div className="bp">
<span className="v" id="v58" data-v="58" data-xref="以赛亚书 42:8; 耶利米书 7:9–10; 玛拉基书 1:14"> 如果你不谨守遵行写在这律法书上的一切话语，不敬畏“你的神耶和华”这荣耀可畏的名，</span>
<span className="v" id="v59" data-v="59" data-xref="马可福音 13:19; 申命记 28:46; 但以理书 9:12"> 耶和华就会用奇特的灾害责打你和你的后裔，那是持久严重的灾害和持久恶性的疾病。</span>
<span className="v" id="v60" data-v="60" data-xref="申命记 7:15; 出埃及记 15:26; 申命记 28:27"> 他也会使你所惧怕的埃及一切疫病回到你身上，紧贴着你；</span>
<span className="v" id="v61" data-v="61" data-xref="申命记 4:25–26"> 甚至没有写在这律法书上的各种疾病、各种灾害，耶和华也会使它们降在你身上，直到你被除灭。</span>
<span className="v" id="v62" data-v="62" data-xref="申命记 10:22; 尼希米记 9:23; 申命记 4:27"> 尽管你们多如天上的星辰，剩下的人也会很少，因为你不听从你的神耶和华的吩咐。</span>
<span className="v" id="v63" data-v="63" data-xref="箴言 1:26; 耶利米书 32:41; 申命记 30:9"> 耶和华曾经怎样乐意使你们蒙福，使你们增多，那时，耶和华也会怎样乐意使你们消亡，使你们灭尽；你们必从你进去拥有的土地上被拔出。</span>
<span className="v" id="v64" data-v="64" data-xref="申命记 4:27–28; 利未记 26:33; 耶利米书 16:13"> 耶和华会把你驱散到万民中，从地这边直到地那边；你将在那里服事你和你祖先不认识的别神——那些木头和石头。</span>
<span className="v" id="v65" data-v="65" data-xref="利未记 26:36; 罗马书 11:10; 阿摩司书 9:4"> 在那些民族中，你得不到安宁，没有可以落脚的歇息之处。耶和华会使你在那里心中颤抖、眼睛失明、心灵绝望。</span>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="1TI" data-book-slug="1-timothy" data-book-name="提摩太前书" data-chapter="5" data-verses="25">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 19:32; 彼得前书 5:5–6; 提多书 2:2"> 不要严厉责备年长的人，而要劝他像劝父亲那样；对年轻的人要像对兄弟那样；</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前书 4:12; 马太福音 12:50; 腓立比书 4:8"> 对年长的妇女要像对母亲那样，对年轻的妇女要像对姐妹那样，要怀着完全纯洁的心。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命记 27:19; 使徒行传 6:1; 申命记 10:18"> 要尊重那些真正的寡妇。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 6:1–3; 约翰福音 19:26–27; 马太福音 15:4–6"> 不过一个寡妇如果有儿女或孙儿女，就应当让他们先学会孝敬自己的家人，报答亲恩，因为这在神面前是<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附“美好的、”。">a</a></sup>蒙悦纳的。</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太前书 5:3; 路加福音 2:37; 哥林多前书 7:32"> 那真正的寡妇，无依无靠，已经把盼望寄托于神，日夜不住地祈求祷告；</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 5:5; 启示录 18:7; 路加福音 15:24"> 而那享乐度日的寡妇，虽然活着，却是死的。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前书 4:11; 提多书 2:15; 提摩太后书 4:1"> 你当吩咐这些事，好使她们无可指责。</span>
<span className="v" id="v8" data-v="8" data-xref="加拉太书 6:10; 哥林多后书 12:14; 路加福音 11:11–13"> 如果有人不顾念自己的亲属，尤其是家里的人，他就否定了信仰，比不信的人更坏。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="提摩太前书 3:2; 提摩太前书 5:11; 路加福音 2:36–37"> 应当算入寡妇之列的，不可小于六十岁；只做过一个男人的妻子；</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 6:18; 提多书 3:8; 使徒行传 9:36"> 并且必须有美好行为的名声，就如养育孩子、接待客旅、洗圣徒的脚、帮助受患难的人、追随一切美善的工作。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 5:14; 何西阿书 13:6; 雅各书 5:5"> 至于年轻的寡妇，你要拒绝她们入列<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="她们入列——辅助词语。">b</a></sup>；要知道，当她们情欲冲动而违背基督的时候，就想要结婚；</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 1:6; 雅各书 3:1; 哥林多前书 11:34"> 她们被定罪，是因为她们弃绝了最初的誓言<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="誓言——原文直译“信仰”。">c</a></sup>，</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 20:19; 帖撒罗尼迦后书 3:6–11; 使徒行传 20:30"> 同时她们又学会了懒惰，四处串门；不仅懒惰，还好说闲话，好管闲事，说不该说的话。</span>
<span className="v" id="v14" data-v="14" data-xref="提多书 2:5; 提摩太前书 6:1; 提多书 2:8"> 所以，我希望年轻的寡妇结婚，生养儿女，料理家务，不给反对的人辱骂的机会。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得后书 2:2; 犹大书 1:4–5; 彼得后书 2:20–22"> 实际上，已经有一些人转去随从撒旦了。</span>
<span className="v" id="v16" data-v="16" data-xref="提摩太前书 5:3–5; 提摩太前书 5:8"> 如果一个<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附“男信徒或”。">d</a></sup>女信徒，在亲属中<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="在亲属中——辅助词语。">e</a></sup>有寡妇，她就应该帮助她们，不要让教会承受压力，好使教会能够帮助那些真正的寡妇。</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="希伯来书 13:17; 帖撒罗尼迦前书 5:12–13; 加拉太书 6:6"> 那些好好带领<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="带领——或译作“管理”。">f</a></sup>了信徒<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="信徒——辅助词语。">g</a></sup>的长老，尤其是在传道和教导上劳苦做工的，应该被看为配得加倍的尊重。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 25:4; 哥林多前书 9:14; 哥林多前书 9:7–10"> 原来经上说：<br /><span className="pl pl-1">“牛踹谷的时候，不可笼住它的嘴。”</span><br /><span className="pl pl-1">又说：</span><br /><span className="pl pl-1 woj">“工人配得自己的酬报。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马太福音 18:16; 申命记 19:15; 哥林多后书 13:1"> 除非有两三个见证人，否则你不可受理对长老的控告。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太后书 4:2; 提多书 1:13; 提摩太前书 1:20"> 对那些继续犯罪的，你要当众责备他们，好使其他的人也有所惧怕。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得后书 2:4; 提摩太后书 4:1; 提摩太前书 6:13"> 我在神、基督耶稣<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="基督耶稣——有古抄本作“主耶稣基督”。">h</a></sup>，和蒙拣选的天使面前郑重地劝诫你：遵守这些话要毫无成见，做任何事都不要偏心。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 5:11; 提摩太前书 3:10; 提摩太前书 3:6"> 不要轻易给人按手，也不要在别人的罪孽上有份，要保守自己纯洁。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 104:15; 箴言 31:4–7; 提摩太前书 4:4"> 由于你胃的问题和常患的那些疾病，你今后不要只喝水，要用一点酒<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="酒——就是“葡萄酒”。">i</a></sup>。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太后书 4:10; 使徒行传 8:18; 加拉太书 5:19–21"> 有些人的罪孽是明显的，要先面对审判；而有些人的<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="而有些人的——原文直译“而对有些人，”。">j</a></sup>罪却是随后跟着的。</span>
<span className="v" id="v25" data-v="25" data-xref="箴言 10:9; 路加福音 11:33; 诗篇 37:5–6"> 照样，美好行为也是明显的，即使是那些不明显的，也不能一直隐藏下去。</span>
</div>

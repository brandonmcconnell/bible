<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提多书 1:7; 使徒行传 20:28; 彼得前书 5:2"> “如果有人向往监督的职份，他就是在渴望一份美好的工作。”这话是信实的。</span>
<span className="v" id="v2" data-v="2" data-xref="提多书 1:6–9; 提摩太后书 2:24; 罗马书 12:13"> 所以做监督的必须无可指责，只做一个妇人的丈夫，节制、自律、端庄，乐意款待客旅，善于教导，</span>
<span className="v" id="v3" data-v="3" data-xref="提多书 1:7; 以弗所书 5:18; 提多书 3:2"> 不酗酒、不好斗；<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附“不贪图不正当的利益，”。">a</a></sup>反要谦和，不争吵、不贪财<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="不贪财——原文直译“不爱金钱”。">b</a></sup>，</span>
<span className="v" id="v4" data-v="4" data-xref="提多书 1:6; 创世记 18:19; 提摩太前书 3:12"> 好好带领<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="带领——或译作“管理”。">c</a></sup>自己的家，在一切的事上庄重，使儿女顺服。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 3:13; 以弗所书 5:24; 使徒行传 20:28"> 但如果有人不知道怎么带领<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="带领——或译作“管理”。">d</a></sup>自己的家，他怎么能照顾神的教会呢？</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前书 6:4; 希伯来书 5:12–13; 彼得前书 2:2"> 做监督的不可以是新信徒，免得他自以为是，就落在魔鬼所受的惩罚里；</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 8:21; 提摩太后书 2:26; 歌罗西书 4:5"> 同时，做监督的在外人中也必须有好名声<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="名声——原文直译“见证”。">e</a></sup>，免得受人责骂，落在魔鬼的网罗里。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="腓立比书 1:1; 提摩太前书 5:23; 使徒行传 6:3–6"> 做执事<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="执事——或译作“仆人”。">f</a></sup>的也一样，必须庄重，不一口两舌，不酗酒，不贪图不正当的利益，</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前书 1:19; 约翰二书 1:9–10; 提摩太前书 1:5"> 以清白的良心持守信仰的奥秘；</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 5:22; 提摩太前书 3:13; 提多书 1:6–7"> 并且这些人也当先受考验，如果是无可指责的，才可以做执事。</span>
<span className="v" id="v11" data-v="11" data-xref="提多书 2:3; 提多书 3:2; 提摩太前书 3:2"> 照样，他们的妻子<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="他们的妻子——原文直译“妇女”或“妻子”。">g</a></sup>也必须庄重，不恶意控告人，有节制，在一切事上都忠心。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太前书 3:2; 提摩太前书 3:4–5; 腓立比书 1:1"> 做执事的只可做一个妇人的丈夫，好好带领<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="带领——或译作“管理”。">h</a></sup>儿女和自己的家。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 25:21; 希伯来书 6:10; 使徒行传 21:35"> 因为那好好服事的，就让自己达到<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="达到——原文直译“买来”。">i</a></sup>美好的境地，并且在基督耶稣里的信仰上大有胆量。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 11:34; 腓利门书 1:22; 哥林多后书 1:15–17"> 我把这些事写给你，希望很快到你那里去。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 2:5; 以弗所书 2:21–22; 帖撒罗尼迦前书 1:9"> 就算我耽延了，你也可以知道在神的家里应该怎样行事。这家是永生神的教会，是真理的柱石和根基。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 1:14; 希伯来书 1:3; 马可福音 16:19"> 正如大家所承认的，敬神的奥秘是极大的：<br /><span className="pl pl-1">神</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="神——有古抄本作“那一位”。">j</a></sup><br /><span className="pl pl-1">以肉身显现，</span><br /><span className="pl pl-1">被圣灵证实，</span><br /><span className="pl pl-1">被天使观看，</span><br /><span className="pl pl-1">被传于万邦，</span><br /><span className="pl pl-1">被世人信仰，</span><br /><span className="pl pl-1">被接在荣耀里。</span></span>
</div>
</div>

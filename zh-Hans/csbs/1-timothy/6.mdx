<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="提多书 2:5; 彼得前书 2:17–20; 提多书 2:8–10"> 凡是负轭做奴仆的，应该看自己的主人配受十分尊重，免得神的名和神的教导受到亵渎。</span>
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 4:1; 提摩太前书 4:11; 创世记 16:4–5"> 如果奴仆的主人是信徒，不可因为主人是弟兄就轻看他们；反而倒要服事他们，因为从这样的美事而得益处的，是信徒、是蒙爱的人。 错误的教导与人的贪心<br />你要教导、劝勉这些事。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前书 1:3; 罗马书 16:17; 提摩太前书 1:10"> 如果有人传讲别的教义，不符合我们主耶稣基督的健全话语以及那合乎敬神的教导，</span>
<span className="v" id="v4" data-v="4" data-xref="提摩太后书 2:23; 提摩太后书 3:4; 提摩太前书 3:6"> 那么他就成了自以为是的人，什么都不知道，只对辩论和言词上的争执有病态的嗜好，由此引发嫉妒、纷争、毁谤、恶意的猜疑；</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太后书 3:5; 提多书 1:11; 彼得后书 2:3"> 他在那些理性败坏、丧失真理、以为敬神是得利之道的人中，引发无休止的争吵。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附“你要避开这种人。”">a</a></sup></span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 13:5; 提摩太前书 6:8; 箴言 16:8"> 其实敬神加上知足，才是极大的得利之道。</span>
<span className="v" id="v7" data-v="7" data-xref="约伯记 1:21; 诗篇 49:17; 路加福音 12:20–21"> <span className="pl pl-1">实际上，我们没有带什么到世上来，</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附“明显地，”。">b</a></sup><br /><span className="pl pl-1">也不能带什么去。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 13:5–6; 马太福音 6:11; 马太福音 6:25–33"> <span className="pl pl-1">不过有了吃的、穿的，我们将以此为满足。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约翰一书 2:15–17; 箴言 15:27; 提摩太前书 3:7"> 至于那些想发财的人就会陷入试探、网罗以及很多无知有害的欲望里；这些欲望使人沉溺在败坏和灭亡<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="灭亡——或译作“沉沦”。">c</a></sup>中。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 1:19; 提摩太前书 6:9; 诗篇 32:10"> 要知道，贪爱金钱是万恶之根；有些人恋慕金钱，就被迷惑而离开了信仰，用很多苦痛把自己刺透了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="提摩太后书 2:22; 提摩太后书 3:17; 提摩太前书 4:12"> <span className="pl pl-1">至于你，哦，属神的人哪，你要逃避这些事！</span><br /><span className="pl pl-1">你要追求公义、敬神、信仰、</span><br /><span className="pl pl-1">爱心、忍耐、温柔，</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 5:10; 提摩太前书 1:18; 哥林多前书 9:25–26"> <span className="pl pl-1">要为信仰打那美好的仗，</span><br /><span className="pl pl-1">要抓住永恒的生命。</span><br /><span className="pl pl-1">你正是为此蒙召的，</span><br /><span className="pl pl-1">并且在许多见证人面前</span><br /><span className="pl pl-1">做了美好的告白。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="约翰福音 18:36–37; 马太福音 27:11; 提摩太前书 5:21"> 我在那赐生命给万物的神面前，并在那曾经向本丢彼拉多见证了美好告白的基督耶稣面前吩咐你：</span>
<span className="v" id="v14" data-v="14" data-xref="彼得后书 3:14; 彼得前书 1:7; 帖撒罗尼迦前书 5:23"> 要毫无玷污、无可指责地遵守这命令，直到我们主耶稣基督的显现。</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 19:16; 启示录 17:14; 提摩太前书 1:17"> 在所定的时候<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="所定的时候——原文直译“自己的时候”。">d</a></sup>，他将要显明出来他就是<br /><span className="pl pl-1">那当受称颂的、独一的全能者，</span><br /><span className="pl pl-1">万王之王、万主之主，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="提摩太前书 1:17; 约翰福音 1:18; 约翰一书 1:5"> <span className="pl pl-1">就是那独一不朽的、</span><br /><span className="pl pl-1">住在人所不能靠近的光里，</span><br /><span className="pl pl-1">没有人见过、也没有人能看见的那一位。</span><br /><span className="pl pl-1">愿尊贵和永恒的权能都归于他！</span><br /><span className="pl pl-1">阿们。</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="箴言 11:28; 使徒行传 14:17; 箴言 27:24"> 对那些今世富有的人，你当吩咐他们不可高傲自大，也不可把盼望寄托在靠不住的财富上，而要寄托在神<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="神——有古抄本作“永生的神”。">e</a></sup>身上，神把万物丰丰富富地赐给我们享受。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 13:16; 约翰一书 3:17; 诗篇 37:3"> 你要吩咐他们常行美善，在美好行为上富足，慷慨施舍，乐意分享；</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 6:19–21; 提摩太前书 6:12; 提摩太后书 2:19"> 为着那将要来临的，给自己积存美好的基础，使他们抓住那真正的<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="真正的——有古抄本作“永恒的”。">f</a></sup>生命。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="歌罗西书 2:8; 提摩太后书 2:16; 提摩太后书 1:12–14"> 哦，提摩太呀！你要保守那所受的托付，避开那些不敬神的空谈和假冒知识之名的反对论。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 2:18; 提摩太前书 1:6; 提摩太后书 4:22"> 有些人自称有这些“知识”，就在信仰上偏离了。<br />愿恩典与你们<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="你们——有古抄本作“你”。">g</a></sup>同在！<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附“阿们。”">h</a></sup></span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 9:17; 提摩太前书 2:7; 哥林多前书 9:19"> 我不是自由的吗？我不是使徒吗？我不是看到我们的主耶稣<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="耶稣——有古抄本作“耶稣基督”。">a</a></sup>吗？你们不是我在主里的工作吗？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 12:12; 约翰福音 6:27; 哥林多后书 3:1–3"> 即使我对别人不是使徒，但至少对你们还是使徒，因为你们是我在主里做使徒的印证。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 12:16–19; 哥林多后书 13:3; 哥林多后书 13:10"> 对那些评断我的人，我的辩护是这样的：</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 2:6; 帖撒罗尼迦后书 3:8–9; 路加福音 10:7"> 难道我们没有权利吃喝吗？</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 1:42; 希伯来书 13:4; 马太福音 8:14"> 难道我们没有权利像其他的使徒，像主的弟弟们<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="弟弟们——原文直译“兄弟们”。">b</a></sup>，像矶法那样，也带着信主的妻子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="信主的妻子——原文直译“姐妹妻子”。">c</a></sup>一同往来吗？</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦后书 3:7–9; 使徒行传 13:1–2; 使徒行传 4:36"> 难道只有我和巴拿巴没有不做工的权利吗？</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 27:18; 申命记 20:6; 提摩太后书 2:3–4"> 曾经有谁当兵自备粮饷呢？有谁栽种葡萄园不吃园中的果子呢？有谁牧养羊群不喝羊群的奶呢？</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 8:20; 帖撒罗尼迦前书 4:8; 罗马书 3:31"> 我说这些话，难道是按人的意思吗？律法不也是说这些话吗？</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 25:4; 提摩太前书 5:18; 诗篇 104:27"> 事实上，摩西的律法上记着：“牛踹谷的时候，不可笼住它的嘴。”难道神顾念的是牛吗？</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太后书 2:6; 罗马书 15:4; 罗马书 4:23–24"> 还是特别为我们说的呢？这样写下来，当然是为我们的缘故！因为耕田的应该怀着希望去耕田，打场的应该怀着一同分享粮食<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="粮食——辅助词语。">d</a></sup>的希望去打场。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 15:27; 加拉太书 6:6; 哥林多后书 11:15"> 既然我们为你们播下了属灵的种子，那么，如果我们从你们收取物质上的东西<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="物质上的东西——原文直译“属肉体的事”。">e</a></sup>，这算过份吗？</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 9:15; 哥林多前书 9:18; 哥林多后书 11:12"> 如果别人能从你们那里分享这权利，我们不是更能分享吗？<br />然而，我们并没有用过这权利，反而凡事包容，免得给基督的福音带来阻碍。</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 18:8–20; 民数记 5:9–10; 利未记 6:26"> 难道你们不知道，在圣殿供职的人，都吃圣殿中的食物；侍候祭坛的人，都一同享用祭坛上的供物吗？</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 10:10; 提摩太前书 5:17–18; 哥林多前书 9:4"> 照样，主也吩咐那些传福音的人，靠福音生活。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 2:9; 帖撒罗尼迦后书 3:8; 哥林多前书 9:12"> 但是，这些权利我一个也没有用过。我写这些并不是要人这样对待我，因为我宁愿死，也不愿意任何人使我所夸耀的落了空。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 1:14; 耶利米书 20:9; 歌罗西书 4:17"> 原来，就算我传福音，也没有可夸耀的，因为传福音的需要催逼着我；我如果不传福音，我就有祸了；</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 2:7; 哥林多前书 3:8; 历代志上 28:9"> 如果我自愿做这事，就有报偿；如果我不自愿，这任务<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="任务——或译作“管家的任务”。">f</a></sup>也已经委托给我了。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 11:7–9; 哥林多前书 8:9; 帖撒罗尼迦前书 2:6"> 那么，我的报偿到底是什么呢？就是：我传福音的时候，能免费地提供福音<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="福音——有古抄本作“基督的福音”。">g</a></sup>，好使我不会充分利用在福音工作上属自己的权利。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="加拉太书 5:13; 马太福音 18:15; 雅各书 5:19–20"> 我诚然是自由的，不属于任何人，但我使自己成为所有人的奴仆，为了赢得更多的人。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 16:3; 加拉太书 5:18; 使徒行传 21:20–26"> 对犹太人，我就成为一个像犹太人那样的人，为了赢得犹太人；对律法之下的人，虽然我自己不在律法之下，<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本没有“虽然我自己不在律法之下，”。">h</a></sup>我却成为一个像是在律法之下的人，为了赢得在律法之下的人；</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 2:12; 罗马书 2:14; 加拉太书 3:2"> 对没有律法的人，我就成为一个像是没有律法的人那样，为了赢得没有律法的人——对神，我不是没有律法的，而是在基督的律法之下。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 10:33; 罗马书 15:1; 哥林多前书 9:19"> 对软弱的人，我就成为软弱的人，为了赢得软弱的人。对什么样的人，我就成为什么样的人，一定要拯救一些人。</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太后书 2:10; 马可福音 8:35; 哥林多前书 9:25–27"> 并且我做这一切，都是为了福音的缘故，好使我能成为在福音上一同有份的人。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="腓立比书 3:14; 希伯来书 12:1; 提摩太后书 4:7–8"> 难道你们不知道，赛场上奔跑的人虽然都在跑，但是得奖的只有一个吗？你们也应当这样奔跑，好使你们得着奖赏。</span>
<span className="v" id="v25" data-v="25" data-xref="提摩太后书 2:5; 启示录 2:10; 提摩太后书 4:7–8"> 每一个参加比赛的人，都要在一切事上自制；不过他们这样做是为了得到会朽坏的冠冕，而我们是为了得到不会朽坏的冠冕。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得后书 1:10; 腓立比书 1:21; 提摩太后书 2:5"> 因此，我奔跑不像没有目标的；我斗拳不像打空气的；</span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 8:13; 哥林多前书 9:25; 歌罗西书 3:5"> 然而我不断克制<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="克制——原文直译“痛打”。">i</a></sup>自己的身体，使它服从我，免得我传道给别人，自己反而经不起考验了。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 14:39; 提摩太前书 4:14; 哥林多前书 12:1"> 你们要追求爱，也要渴慕属灵的事<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="属灵的事——或译作“属灵的恩赐”。">a</a></sup>，但更要渴慕做先知传道<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="做先知传道——原文直译“说预言”。">b</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 16:17; 使徒行传 19:6; 使徒行传 10:46"> 原来那说殊言<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="殊言——原文直译“舌头”；传统译法作“方言”。">c</a></sup>的，不是对人说，而是对神说，因为没有人听得懂；他是在灵里讲说各样的奥秘。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 14:12; 提摩太前书 4:13; 犹大书 1:20"> 可是那做先知传道的是对人说，为要造就、鼓励和安慰人。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 14:22; 哥林多前书 14:26; 马可福音 16:17"> 那说殊言的是造就自己，但那做先知传道的是造就教会。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 12:28–30; 哥林多前书 12:10; 马可福音 16:17"> 我虽然希望你们都说殊言，但更希望你们都做先知传道。因为，除非说殊言的能把殊言翻译出来使教会得到造就，否则那做先知传道的就比说殊言的更大了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以弗所书 1:17; 罗马书 6:17; 提摩太后书 3:16"> 所以弟兄们，就算我现在到你们那里去，用殊言说话，但如果不用启示、知识、预言<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="预言——或译作“先知传道”。">d</a></sup>、或教导来对你们说话，那么我对你们有什么益处呢？</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 14:8; 路加福音 7:32; 哥林多前书 13:1"> 甚至是那些没有生命却能发出声音的东西，例如笛子或竖琴，如果发出的音调没有分别，怎么能使人知道所吹所弹的是什么呢？</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 10:9; 以西结书 33:3–6; 耶利米书 4:19"> 实际上，如果号角发出的声音真的不清楚，谁会准备好出战呢？</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 9:26"> 照样，如果你们用舌头说出不可理解的话，那么所说的怎么能使人明白呢？这样，你们就是向空气说话了。</span>
<span className="v" id="v10" data-v="10"> 世界上也许有好多种语言，但没有一种是没有意思的。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 28:2; 罗马书 1:14; 歌罗西书 3:11"> 所以，如果我不明白那语言的意思，那么，对于说话的人，我就是个外族人；对于我，那说话的人也是个外族人。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 14:26; 哥林多前书 14:3–4; 哥林多前书 14:1"> 你们也是这样：既然你们对属灵的事<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="属灵的事——或译作“属灵的恩赐”。">e</a></sup>是热心人，就应当追求造就教会的事，好让你们能丰足有余。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马可福音 11:24; 哥林多前书 12:30; 约翰福音 14:13–14"> 所以，说殊言的人应当祷告，好让自己能翻译出来。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 14:2; 哥林多前书 14:15–16; 哥林多前书 14:19"> 如果我用殊言祷告，是我的灵在祷告，但我的理性却是结不出果子的。</span>
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 3:16; 约翰福音 4:23–24; 以弗所书 6:18"> 那么该怎么办呢？我要用灵祷告，也要用理性祷告；我要用灵歌颂，也要用理性歌颂。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 16:36; 诗篇 106:48; 启示录 5:14"> 否则，如果你用灵祝谢，在场的那些不明白的人，既然不知道你在说什么，怎么能在你感谢的时候说“阿们”呢？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 14:4; 哥林多前书 14:6"> 因为你感谢的固然是好，但别人却没有得造就。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 1:4–6; 哥林多前书 4:7"> 我感谢神，我说殊言比你们所有人都多；</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 14:21–22; 哥林多前书 14:4"> 但是在教会里，为了要教导别人，我宁愿用我的理性说五句话，也不愿用殊言说万句话。</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="彼得前书 2:2; 哥林多前书 13:11; 罗马书 16:19"> 弟兄们，你们在思想上不要做小孩子，但是在恶事上要做婴孩，在思想上要做成熟的人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="成熟的人——或译作“完全的人”。">f</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 28:11–12; 耶利米书 5:15; 申命记 28:49"> 律法书上记着：“主说：<br /><span className="pl pl-1">‘我要藉着说别种语言的人，</span><br /><span className="pl pl-1">藉着别人的嘴唇对这子民说话。</span><br /><span className="pl pl-1">即使这样，他们也不会听我的。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 2:6–12; 马可福音 16:17; 哥林多前书 14:1"> 这样，说殊言不是给信的人做为标记，而是给不信的人；但做先知传道<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="做先知传道——原文直译“说预言”。">g</a></sup>不是给不信的人做为标记，而是给信的人。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 2:13; 使徒行传 26:24; 哥林多前书 11:18"> 所以，如果全教会聚集在一起，大家都说殊言，有不明白殊言的，或不信的人进来，他们难道不会说你们都疯了吗？</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 2:37; 哥林多前书 2:15; 希伯来书 4:12–13"> 但如果大家都做先知传道，有一个不信的或不明白的人进来，他就会因这一切而知罪、受到责问，</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 45:14; 撒迦利亚书 8:23; 诗篇 72:11"> 他心中隐秘的事就会显露出来。这样，他就会把脸伏在地上敬拜神，承认说：“神真的是在你们中间！”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以弗所书 5:19; 罗马书 14:19; 哥林多前书 12:7–10"> 弟兄们，那么该怎么办呢？你们聚集的时候，各人或有诗歌，或有教导，或有启示，或有殊言，或有翻译出来的话语——一切都要为了造就人。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 14:26"> 如果有人说殊言，就应该只有两个人，或最多三个人，而且要轮流说，也要有一个人翻译。</span>
<span className="v" id="v28" data-v="28"> 如果没有翻译的人，他就应当在教会里保持沉默，只对自己和神说话。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 12:10; 帖撒罗尼迦前书 5:19–21; 约翰一书 4:1–3"> 做先知传道的<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="做先知传道的——原文直译“先知”。">h</a></sup>也应该两个人或三个人讲，其他的人应当分辨。</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒罗尼迦前书 5:19–20; 约伯记 33:31–33; 约伯记 32:11"> 如果在坐的人中另有人得了启示，那先讲的就应当保持沉默。</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒罗尼迦前书 5:14; 哥林多前书 14:3; 帖撒罗尼迦前书 5:11"> 因为你们都可以一个一个地做先知传道，好让大家都能学，都得到鼓励。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 4:19–20; 约翰一书 4:1; 撒母耳记上 10:10–13"> 先知的灵是服从先知的，</span>
<span className="v" id="v33" data-v="33" data-xref="雅各书 3:17–18; 哥林多前书 14:40; 帖撒罗尼迦后书 3:16"> 因为神不是混乱的神，而是和平的神。<br />正如在圣徒的各教会那样，</span>
<span className="v" id="v34" data-v="34" data-xref="提摩太前书 2:11–12; 创世记 3:16; 民数记 30:3–13"> 妇女在教会应当保持沉默，因为她们没有获准讲话；就像律法上所说的那样，她们要服从。</span>
<span className="v" id="v35" data-v="35" data-xref="以弗所书 5:12; 彼得前书 3:7; 以弗所书 5:25–27"> 如果她们想请教什么，就应该在家里问自己的丈夫，因为妇女在教会里讲话是可耻的。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 18:1–17; 撒迦利亚书 14:8; 使徒行传 17:15"> 难道神的话语<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="神的话语——或译作“神的道”。">i</a></sup>是从你们出来的吗？难道只是临到你们吗？</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="约翰一书 4:6; 哥林多后书 10:7; 彼得后书 3:2"> 如果有人自以为是做先知传道的<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="做先知传道的——原文直译“先知”。">j</a></sup>，或是属灵的，就应该承认：我写给你们的是主的命令；</span>
<span className="v" id="v38" data-v="38" data-xref="提摩太后书 4:3–4; 何西阿书 4:17; 启示录 22:11–12"> 但如果有人不承认，他也不会被承认。<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="但如果有人不承认，他也不会被承认。——有古抄本作“但如果有人无知，就让他无知吧！”">k</a></sup></span>
<span className="v" id="v39" data-v="39" data-xref="哥林多前书 12:31; 哥林多前书 14:1; 帖撒罗尼迦前书 5:20"> 所以，我的弟兄们，你们要渴慕做先知传道，也不要禁止说殊言。</span>
<span className="v" id="v40" data-v="40" data-xref="歌罗西书 2:5; 提多书 1:5; 哥林多前书 14:26–33"> 然而，一切事都要行得端正，并且要按着秩序行。</span>
</div>
</div>

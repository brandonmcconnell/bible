<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 1:6–12; 彼得前书 5:12; 哥林多前书 15:3–11"> 弟兄们，我要你们明白我先前所传给你们的福音；你们也领受了这福音，并且在这福音上站立得住。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 3:6; 希伯来书 2:1; 希伯来书 3:14"> 如果你们不是毫无理由地相信，而是持守我所传给你们的话语，你们也就会藉着它得救。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得前书 2:24; 加拉太书 1:4; 以赛亚书 53:1–12"> 因为我所传给你们的，其中最重要的，也是我所领受的，就是<br /><span className="pl pl-1">基督照着经上所记的，为我们的罪孽死了，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="何西阿书 6:2; 马太福音 12:40; 诗篇 16:10–11"> <span className="pl pl-1">而且被埋葬了，</span><br /><span className="pl pl-1">又照着经上所记的，在第三天复活了，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 16:14; 哥林多前书 1:12; 约翰福音 1:42"> <span className="pl pl-1">并且向矶法显现，然后向十二使徒</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="使徒——辅助词语。">a</a></sup><br /><span className="pl pl-1">显现，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 28:10; 马可福音 16:7; 使徒行传 13:36"> <span className="pl pl-1">后来一次性地向五百多个弟兄显现，</span><br /><span className="pl pl-1">其中大多数人至今还在，虽然也有些已经睡了；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 24:50; 使徒行传 1:2–12; 路加福音 24:33"> <span className="pl pl-1">后来他向雅各显现，再向所有的使徒显现，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 9:1; 使徒行传 26:16; 使徒行传 22:18"> <span className="pl pl-1">最后也显现给我——这个像是早产婴儿一样的人。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以弗所书 3:7–8; 提摩太前书 1:13–15; 使徒行传 8:3"> 原来我是使徒中最小的，不配被称为使徒，因为我曾经逼迫神的教会。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比书 4:13; 哥林多后书 3:5; 腓立比书 2:13"> 但藉着神的恩典，我成了现在的我，并且神赐给我的恩典没有落空。不但如此，我比任何使徒更加劳苦做工；其实不是我，而是与我同在的神的恩典。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 15:3–4; 哥林多前书 2:2"> 因此无论是我，或是他们，我们都如此传，你们也就如此信了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 26:8; 使徒行传 17:32; 提摩太后书 2:18"> 既然宣讲基督已经从死人中复活了，你们中间怎么还有些人说没有死人复活的事呢？</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 11:25–26; 罗马书 8:11; 帖撒罗尼迦前书 4:14"> 如果没有死人复活的事，基督也就没有复活了。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 15:17; 帖撒罗尼迦前书 4:14; 加拉太书 2:2"> 如果基督没有复活，我们传道就是虚空，你们相信也是虚空。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 2:24; 约伯记 13:7–10; 使徒行传 2:32"> 这样，我们就被看做是神的假见证人，因为我们见证了有关神的事，说神使基督复活了，如果死人真不会复活，神就没有使基督复活；</span>
<span className="v" id="v16" data-v="16"> 就是说，如果死人不会复活，基督也就没有复活了。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 4:25; 彼得前书 1:3; 哥林多前书 15:14"> 如果基督没有复活，你们的信仰就是虚妄的，你们也仍然在自己的罪孽中；</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 4:13–14; 启示录 14:13; 帖撒罗尼迦前书 4:16"> 因此在基督里那些睡了的人也就灭亡了。</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前书 1:21; 启示录 14:13; 提摩太后书 1:12"> 如果我们在基督里的盼望只在于今生<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="如果我们在基督里的盼望只在于今生——或译作“如果我们今生所拥有的一切就是我们在基督里的盼望”。">b</a></sup>，我们就比所有的人更可怜。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 15:23; 使徒行传 26:23; 启示录 1:5"> 但如今，基督已经从死人中复活，成为睡了之人初熟的果子，</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 11:25; 罗马书 5:12–17; 哥林多前书 15:22"> 因为死亡既然是由一个人而来，死人的复活也是由一个人而来。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 5:12–21; 哥林多前书 15:45–49; 约翰福音 5:21–29"> 原来，就像在亚当里所有的人都死了，照样，在基督里所有的人也都将得以复活，</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 26:19; 加拉太书 3:29; 哥林多前书 15:52"> 不过每个人要按着自己的次序：初熟的果子是基督；然后他来临的时候，是那些属于基督的人；</span>
<span className="v" id="v24" data-v="24" data-xref="但以理书 7:27; 但以理书 7:14; 马太福音 28:18"> 再后才是结局。那时候，基督要把国度交给父神；同时，基督要废除一切统治的、掌权的、有势力的，</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 10:12–13; 诗篇 110:1; 马太福音 22:44"> 因为基督必须做王，直到神<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="神——原文直译“他”。">c</a></sup>把所有的敌人都放在他的脚下。</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太后书 1:10; 哥林多前书 15:55; 启示录 21:4"> 最后被废除的仇敌就是死亡，</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 8:6; 希伯来书 2:8; 马太福音 28:18"> 因为“神<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="神——原文直译“他”。">d</a></sup>使万有都服从在基督<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="基督——原文直译“他”。">e</a></sup>的脚下。”当经上<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="经上——原文直译“它”。">f</a></sup>说“万有”都已经服从了他的时候，明显地，使万有服从基督<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="基督——原文直译“他”。">g</a></sup>的那一位是不包括在内的。</span>
<span className="v" id="v28" data-v="28" data-xref="歌罗西书 3:11; 哥林多前书 3:23; 以弗所书 1:23"> 当万有都服从他的时候，子自己也要服从那位使万有都服从他的，这样神就是万有中的万有。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="罗马书 6:3–4; 哥林多前书 15:16; 马太福音 20:22"> 如果不是这样，那些替死人受洗的，将怎么办呢？如果死人根本不会复活，人们为什么还替死人<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="死人——有古抄本作“他们”。">h</a></sup>受洗呢？</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多后书 6:9; 加拉太书 5:11; 哥林多后书 4:7–12"> 我们又为什么要时时刻刻面临危险呢？</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多后书 4:10–11; 罗马书 8:36; 哥林多前书 4:9–13"> 弟兄们，藉着我在我们的主基督耶稣里所拥有的，就是我对你们的夸耀，我肯定地说：我天天都在死！</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 22:13; 以赛亚书 56:12; 路加福音 12:19"> 我在以弗所与野兽搏斗，如果按人的意思来说，对我有什么好处呢？如果死人不会复活，就“让我们吃吃喝喝吧，因为明天我们就要死了。”</span>
<span className="v" id="v33" data-v="33" data-xref="箴言 13:20; 马太福音 24:4; 哥林多前书 5:6"> 你们不要被迷惑了！“结交恶友，败坏善德。”</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 6:5; 罗马书 13:11; 希伯来书 5:11–12"> 你们应当醒悟过来，不继续犯罪；实际上，有些人不认识神。我说这话，是为了使你们羞愧。</span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="以西结书 37:3; 哥林多前书 15:38–53; 罗马书 9:19"> 但是有人会说：“死人怎样复活呢？他们以什么样的身体出现呢？”</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 12:24; 路加福音 11:40; 以弗所书 5:15"> 你这愚妄的人哪！你所种的如果不死，就得不到生命；</span>
<span className="v" id="v37" data-v="37"> 你所种的也不是那将要长成的形体；你所种的不过是一粒赤裸的种子，也许是麦子，或是其他什么。</span>
<span className="v" id="v38" data-v="38" data-xref="哥林多前书 3:7; 以赛亚书 61:11; 马可福音 4:26–29"> 但神照着自己的意愿，给那种子一个形体，并且使每一粒种子各有自己的形体。</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 1:20–26"> 并不是所有的身体都是同样的：人是一个样子，牲畜的身体是另一个样子，鸟的身体又是一个样子，鱼又是另一个样子。</span>
<span className="v" id="v40" data-v="40"> 还有天上的形体，也有地上的形体；但天上形体的光辉是一个样子，地上形体的光辉是另一个样子。</span>
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 24:23; 诗篇 148:3–5; 申命记 4:19"> 太阳的光辉是一个样子，月亮的光辉是另一个样子，星辰的光辉又是一个样子；这星与那星的光辉当然有区别。</span>
<span className="v" id="v42" data-v="42" data-xref="马太福音 13:43; 但以理书 12:3; 罗马书 8:21"> 死人的复活也是这样：<br /><span className="pl pl-1">在衰朽</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="衰朽——或译作“败坏”。">i</a></sup><br /><span className="pl pl-1">中被种下，在不朽中复活；</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="哥林多前书 6:14; 歌罗西书 3:4; 腓立比书 3:20–21"> <span className="pl pl-1">在卑贱中被种下，在荣耀中复活；</span><br /><span className="pl pl-1">在软弱中被种下，在强壮中复活；</span><br /></span>
<span className="v" id="v44" data-v="44" data-xref="哥林多前书 15:50; 路加福音 24:31; 约翰福音 20:19"> <span className="pl pl-1">被种下的是属血气的身体，复活的是属灵的身体。</span><br />既然有属血气的身体，也就有属灵的身体。</span>
<span className="v" id="v45" data-v="45" data-xref="约翰福音 5:21; 创世记 2:7; 罗马书 8:2"> 经上也这样记着：“第一个人亚当成了有生命的人<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有生命的人——原文直译“活的灵”。">j</a></sup>，最后的亚当<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="最后的亚当——指“耶稣基督”。">k</a></sup>成了赐生命的灵。”</span>
<span className="v" id="v46" data-v="46" data-xref="歌罗西书 3:9–10; 罗马书 6:6; 以弗所书 4:22–24"> 不过在先的不是属灵的，而是属血气的；在后的才是属灵的。</span>
<span className="v" id="v47" data-v="47" data-xref="约翰福音 3:31; 创世记 2:7; 创世记 3:19"> <span className="pl pl-1">第一个人是出于地，是属尘土的</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="属尘土的——或译作“尘土造成的”。">l</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">第二个人</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="有古抄本附“是主，”。">m</a></sup><br /><span className="pl pl-1">是出于天。</span><br /></span>
<span className="v" id="v48" data-v="48" data-xref="创世记 5:3; 罗马书 5:12–21; 约翰福音 3:6"> <span className="pl pl-1">属尘土的</span><sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="属尘土的——或译作“尘土造成的”。">n</a></sup><br /><span className="pl pl-1">那个人怎样，那些属尘土的也就怎样；</span><br /><span className="pl pl-1">属天的那一位怎样，那些属天的也就怎样。</span><br /></span>
<span className="v" id="v49" data-v="49" data-xref="罗马书 8:29; 哥林多后书 3:18; 创世记 5:3"> <span className="pl pl-1">就像我们带有了属尘土的</span><sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="属尘土的——或译作“尘土造成的”。">o</a></sup><br /><span className="pl pl-1">那个人的形像，</span><br /><span className="pl pl-1">我们也将带有属天的那一位的形像。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v50" data-v="50" data-xref="约翰福音 3:3–6; 马太福音 16:17; 以弗所书 4:17"> 弟兄们，我要说这一点：血肉之体不能继承神的国，衰朽<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="衰朽——或译作“败坏”。">p</a></sup>的也不能继承不朽的。</span>
<span className="v" id="v51" data-v="51" data-xref="帖撒罗尼迦前书 4:14–17; 腓立比书 3:21; 哥林多前书 15:20"> 看哪，我告诉你们一个奥秘：<br /><span className="pl pl-1">我们并不是都要睡了，而是都要被改变，</span><br /></span>
<span className="v" id="v52" data-v="52" data-xref="帖撒罗尼迦前书 4:16–17; 马太福音 24:31; 约翰福音 5:28"> <span className="pl pl-1">就在一刹那，眨眼之间，在那最后的号角声中。</span><br /><span className="pl pl-1">的确，号角要吹响，死人要复活成为不朽坏的，我们也要被改变；</span><br /></span>
<span className="v" id="v53" data-v="53" data-xref="哥林多后书 5:2–4; 约翰一书 3:2; 罗马书 2:7"> <span className="pl pl-1">因为这会朽坏的，必须穿上不朽坏的；</span><br /><span className="pl pl-1">这会死的，必须穿上不死的。</span><br /></span>
<span className="v" id="v54" data-v="54" data-xref="以赛亚书 25:8; 启示录 20:14; 希伯来书 2:14–15"> <span className="pl pl-1">一旦这会朽坏的穿上那不朽坏的，</span><br /><span className="pl pl-1">这会死的穿上那不死的，</span><br /><span className="pl pl-1">经上所记的话就会应验了：</span><br /><span className="pl pl-1">“死亡被胜利吞灭了！”</span><br /></span>
<span className="v" id="v55" data-v="55" data-xref="何西阿书 13:14; 诗篇 89:48; 使徒行传 2:27"> <span className="pl pl-1">“死亡啊！你的胜利</span><sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="胜利——有古抄本作“毒刺”。">q</a></sup><br /><span className="pl pl-1">在哪里？</span><br /><span className="pl pl-1">死亡啊！你的毒刺在哪里？</span><sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="死亡啊！你的毒刺在哪里？——有古抄本作“坟墓啊！你的胜利在哪里？”">r</a></sup><br /><span className="pl pl-1">”</span><br /></span>
<span className="v" id="v56" data-v="56" data-xref="罗马书 4:15; 加拉太书 3:10–13; 罗马书 7:5–13"> <span className="pl pl-1">死亡的毒刺就是罪，而罪的权势就是律法。</span><br /></span>
<span className="v" id="v57" data-v="57" data-xref="哥林多后书 2:14; 罗马书 8:37; 约翰一书 5:4–5"> <span className="pl pl-1">但感谢神，他藉着我们的主耶稣基督，</span><br /><span className="pl pl-1">赐给我们胜利！</span></span>
</div>
<div className="bp">
<span className="v" id="v58" data-v="58" data-xref="加拉太书 6:9; 历代志下 15:7; 希伯来书 6:10"> 因此，我亲爱的弟兄们，你们要坚定，不可动摇，常常在主的工作中丰足有余，因为你们知道，你们的劳苦在主里不是虚空。</span>
</div>

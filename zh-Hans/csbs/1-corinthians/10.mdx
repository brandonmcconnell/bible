<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="1CO" data-book-slug="1-corinthians" data-book-name="哥林多前书" data-chapter="10" data-verses="33">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 14:29; 尼希米记 9:11–12; 诗篇 78:13–14"> 弟兄们，我不愿意你们不明白：我们的祖先曾经都在那云彩之下，都从那海中经过，</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 3:2–3; 哥林多前书 1:13–16; 出埃及记 14:31"> 并且都在那云里和海里受洗归于摩西。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 8:3; 尼希米记 9:15; 出埃及记 16:35"> 他们都吃了同样的属灵食物，</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 17:6; 约翰福音 7:37; 以赛亚书 48:21"> 也都喝了同样的属灵之水。原来他们所喝的是出于那随着他们的属灵磐石；那磐石就是基督。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 3:17; 犹大书 1:5; 民数记 14:37"> 但是神不喜悦他们中的大多数人，所以他们倒毙在旷野。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="犹大书 1:7; 哥林多前书 10:11; 希伯来书 4:11"> 这些事的发生，是为了我们的鉴戒，好使我们不像他们成为贪恋恶事的人。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 32:6–8; 诗篇 106:19–20; 哥林多前书 6:9"> 你们也不可像他们中的有些人那样，成为拜偶像的，正如经上所记：“民众坐下吃喝，起来玩乐。”</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 25:1–9; 哥林多前书 6:18; 诗篇 106:29"> 我们也不可行淫乱，像他们中的有些人行淫乱，结果一天就倒毙了两万三千人。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 21:5–6; 诗篇 78:18; 希伯来书 3:8–11"> 我们也不可试探基督<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="基督——有古抄本作“主”。">a</a></sup>，像他们中的有些人试探了，结果就被蛇所灭。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 14:2; 民数记 16:41; 民数记 14:37"> 你们也不可抱怨，像他们中的有些人抱怨了，结果就被那毁灭者所灭。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 15:4; 罗马书 13:11; 哥林多前书 9:10"> 这些事发生在他们身上，做为鉴戒；并且被记载下来，是为了警戒我们这些面临万世结局的人。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 11:20; 彼得后书 3:17; 箴言 16:18"> 所以，那自以为站得住的，应该当心，免得跌倒。</span>
<span className="v" id="v13" data-v="13" data-xref="彼得后书 2:9; 提摩太后书 4:18; 帖撒罗尼迦后书 3:3"> 你们所遭受的试探<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="试探——或译作“试炼”。">b</a></sup>，无非是人所遭受的。神是信实的，他不会让你们受试探过于你们所能受的；而且在你们受试探的时候，他会给你们开一条出路，使你们能忍受得住。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="启示录 21:8; 约翰一书 5:21; 彼得前书 2:11"> 所以，我亲爱的各位，你们要逃避拜偶像的事。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 8:1; 帖撒罗尼迦前书 5:21; 哥林多前书 11:13"> 我就像对聪明人在说话；我所说的，你们应当自己判断。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 26:26–28; 哥林多前书 11:23–29; 使徒行传 2:42"> 我们所祝谢的福杯，难道不是在基督之血里的一种契合吗？我们所掰的饼，难道不是在基督身体里的一种契合吗？</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 12:5; 歌罗西书 3:15; 哥林多前书 12:27"> 这是因为饼只有一个，而我们这许多人是一个身体——就是说，我们全都共享这一个饼。</span>
<span className="v" id="v18" data-v="18" data-xref="腓立比书 3:3–5; 加拉太书 6:16; 利未记 7:6"> 你们看世上的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="世上的——原文直译“肉体上的”。">c</a></sup>以色列人吧，难道那些吃祭物的人不是与祭坛有份的人吗？</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 8:4; 哥林多前书 3:7; 哥林多前书 13:2"> 那么，我怎么说呢？难道说祭过偶像的食物算得了什么吗？或说，偶像算得了什么吗？</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 9:20; 诗篇 106:37–39; 申命记 32:16–17"> 不，我是说，外邦人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="外邦人——有古抄本作“他们”。">d</a></sup>所献的祭是献给鬼魔的，不是献给神的；而我不愿意你们成为与鬼魔有份的人。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 6:24; 列王纪上 18:21; 哥林多后书 6:15–17"> 你们不能既喝主的杯，又喝鬼魔的杯；不能既吃主的筵席，又吃鬼魔的筵席。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 32:21; 申命记 32:16; 希伯来书 10:31"> 难道我们要激起主的嫉恨吗？难道我们比他更强吗？</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 6:12; 哥林多前书 8:9; 以弗所书 4:29"> “什么事都可以做”，但不都有益处；“什么事都可以做”，但不都造就人。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 15:1–2; 哥林多前书 10:33; 腓立比书 2:4–5"> 谁都不应当求自己的益处，而应当求别人的益处。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="提摩太前书 4:4; 哥林多前书 8:7; 提多书 1:15"> 肉市上所卖的一切，你们都可以吃；不要为了良心的缘故而问什么，</span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 24:1; 出埃及记 19:5; 诗篇 50:12"> 因为“大地和其中的一切都属于主。”</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 10:25; 路加福音 10:7–8; 哥林多前书 5:9–11"> 如果有不信的人请你们吃饭<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="吃饭——辅助词语。">e</a></sup>，而你们也愿意去，那么，凡是摆在你们面前的都可以吃，不要为了良心的缘故而问什么。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 8:10–13; 哥林多前书 8:7; 哥林多前书 10:26"> 但如果有人对你们说：“这是祭过偶像的食物”，那么，为了那指明这事的人和良心的缘故，你们就不要吃<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附“因为大地和其中的一切都属于主。”">f</a></sup>——</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 9:19; 罗马书 14:15–21; 哥林多前书 8:9–13"> 我说的良心不是你自己的，而是那个人的，因为我的自由何必被别人的良心评断呢？</span>
<span className="v" id="v30" data-v="30" data-xref="罗马书 14:6; 提摩太前书 4:3–4"> 如果我怀着感恩的心领受，难道有什么能使我为所感谢的东西而受到毁谤吗？</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="歌罗西书 3:17; 歌罗西书 3:23; 彼得前书 4:11"> 因此，你们无论或吃、或喝、或做什么，一切都要为神的荣耀而做。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 20:28; 哥林多前书 10:33; 罗马书 14:13"> 无论对犹太人、对外邦人<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="外邦人——原文直译“希腊人”；指“希腊文化区的非犹太人”。">g</a></sup>，或对神的教会，你们都不可成为绊跌物；</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 10:24; 加拉太书 1:10; 哥林多前书 9:19–23"> 要像我那样，也在一切事上使所有的人喜悦——不求自己的益处，而求多人的益处，好让他们都能得救。</span>
</div>
</div>

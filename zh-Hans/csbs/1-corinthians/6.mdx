<span className="v" id="v2" data-v="2" data-xref="马太福音 19:28; 但以理书 7:22; 启示录 20:4"> 难道你们不知道，圣徒将要审判这世界吗？如果连世界都要被你们审判，难道你们还不配审理这些最小的事吗？</span>
<span className="v" id="v3" data-v="3" data-xref="犹大书 1:6; 马太福音 25:41; 哥林多前书 6:4"> 难道你们不知道，我们将要审判天使吗？更何况今生的事呢！</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 5:12; 使徒行传 6:2–4"> 因此，你们如果真有今生的事要审理，难道让被教会所藐视的这些人来审吗？</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 15:34; 哥林多前书 4:14; 雅各书 3:13–18"> 我说这话，是为了使你们羞愧。难道你们中间没有一个智慧人，能在他的弟兄之间分辨是非吗？</span>
<span className="v" id="v6" data-v="6" data-xref="腓立比书 2:14–15; 约翰一书 2:9–11; 约翰一书 3:11–15"> 你们竟然弟兄控告弟兄，而且告到了不信的人面前！</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="罗马书 12:17–19; 箴言 20:22; 彼得前书 2:19–23"> 所以，你们彼此告状，对你们已经是一个全然的失败。你们为什么不情愿受委屈呢？为什么不情愿受亏负呢？</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦前书 4:6; 歌罗西书 3:25; 马可福音 10:19"> 然而你们却委屈人、亏负人，况且这是对你们的弟兄！</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前书 1:9–10; 加拉太书 5:19–21; 以弗所书 5:4–5"> 难道你们不知道，不义的人不会继承神的国吗？不要被迷惑了！无论是淫乱的、拜偶像的、通奸的、做娈童的、同性恋的、</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 5:11; 加拉太书 5:21; 以西结书 22:29"> 偷窃的、贪心的、酗酒的、诽谤人的、勒索人的，都不会继承神的国。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 1:30; 歌罗西书 3:5–7; 哥林多前书 1:2"> 你们有些人过去是这样，但是藉着主耶稣基督的名，藉着我们神的灵，你们已经被洗净了，被分别为圣了，被称为义了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 10:23–33; 哥林多前书 9:27; 希伯来书 12:15–16"> “什么事我都可以做”，但不都有益处；“什么事我都可以做”，但我却不受任何事的辖制。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 6:19; 哥林多前书 3:16; 罗马书 6:12"> “食物是为了肚子，肚子是为了食物”，但神将要把这两样都废除。身体不是为了淫乱，而是为了主；主也是为了身体。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 4:14; 罗马书 8:11; 以弗所书 1:19–20"> 神不但使主复活了，也将藉着自己的大能使我们复活。</span>
<span className="v" id="v15" data-v="15" data-xref="以弗所书 5:30; 罗马书 12:5; 以弗所书 4:15–16"> 难道你们不知道，你们的身体就是基督的肢体吗？因此，我可以拿基督的肢体当做妓女的肢体吗？绝对不可！</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 2:24; 以弗所书 5:31; 马可福音 10:8"> 难道你们不知道，那与妓女结合的，就是与她成为一体了吗？因为经上说：“两个人就成为一体。”</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 17:21–23; 加拉太书 2:20; 哥林多前书 12:13"> 然而，那与主联合的，就是与主成为一灵。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="彼得前书 2:11; 帖撒罗尼迦前书 4:3; 歌罗西书 3:5"> 你们要逃避淫乱。“人所犯的各样罪都在身体以外”，只有那行淫乱的是对自己的身体犯罪。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 3:16; 哥林多后书 6:16; 彼得前书 2:5"> 难道你们不知道，你们的身体就是圣灵的圣所吗？这圣灵住在你们里面，是你们从神领受的。你们不属于自己，</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 7:23; 罗马书 12:1; 彼得前书 2:9"> 因为你们是被重价赎回来的。所以，你们应当用自己的身体荣耀神<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你们应当用自己的身体荣耀神——有古抄本作“你们应当用自己的身体，以及在自己的灵里荣耀神，这原是属于神的”。">a</a></sup>。</span>

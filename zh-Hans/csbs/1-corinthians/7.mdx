<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 7:8; 哥林多前书 7:26–27; 哥林多前书 7:37–38"> 关于你们所写<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附“给我”。">a</a></sup>的事，你们说<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="你们说——辅助词语。">b</a></sup>“男人不碰女人是好事<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="男人不碰女人是好事——或译作“男人不结婚就好”。">c</a></sup>”；</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 5:28; 以弗所书 5:33; 哥林多前书 7:9"> 不过为了避免<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="避免——辅助词语。">d</a></sup>淫乱的事，每个男人都应当有自己的妻子，每个女人也应当有自己的丈夫。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得前书 3:7; 出埃及记 21:10"> 丈夫对妻子应当尽自己的本分，妻子对丈夫也应当如此。</span>
<span className="v" id="v4" data-v="4" data-xref="何西阿书 3:3; 马太福音 19:9; 马可福音 10:11–12"> 妻子对自己的身体没有主权，这主权在丈夫；同样，丈夫对自己的身体也没有主权，这主权在妻子。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 19:15; 约珥书 2:16; 撒迦利亚书 12:12–14"> 夫妻同房<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="同房——辅助词语。">e</a></sup>不可拒绝对方，除非为了有一段时间专心<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附“禁食、”。">f</a></sup>祷告；然后仍要在一起，免得撒旦趁着你们不能自制而试探你们。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 8:8; 哥林多前书 7:25; 哥林多前书 7:12"> 不过我说这话是出于容忍，而不是出于命令。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 19:11–12; 罗马书 12:6; 哥林多前书 9:5"> 我希望所有的人也都像我一样，但是每个人自己都有从神而来的恩赐：有人是这样，有人是那样。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 7:32; 哥林多前书 7:34–35; 哥林多前书 7:26–27"> 我对没有结婚的人和寡妇说，如果他们能像我一样保持现状，对他们来说是好事。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 7:2; 提摩太前书 5:14; 提摩太前书 5:11"> 但如果他们不能自制，就应该结婚，因为结婚总比心如火烧更好。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 5:32; 路加福音 16:18; 马太福音 19:3–9"> 至于对那些已经结婚的人，我吩咐——其实不是我，而是主吩咐：妻子不可离开丈夫；</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 3:1; 哥林多前书 7:10; 以赛亚书 50:1"> 但如果还是离开了，就应当守身不嫁，或者与丈夫和好。丈夫也不可离弃妻子。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 11:17; 哥林多前书 7:6; 哥林多前书 7:25"> 对其余的人，我说——不是主说：如果某个弟兄有不信的妻子，而妻子情愿与他一起生活，他就不可离弃妻子；</span>
<span className="v" id="v13" data-v="13"> 同样，如果妻子有不信的丈夫，而丈夫情愿与她一起生活，她也不可离弃丈夫<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="丈夫——有古抄本作“他”。">g</a></sup>，</span>
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 2:15–16; 提摩太前书 4:5; 提多书 1:15"> 因为那不信的丈夫因着妻子就得以圣洁了；而那不信的妻子也因着丈夫得以圣洁了；否则，你们的儿女就是不洁净的；但如今他们是圣洁的。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 14:19; 哥林多后书 13:11; 雅各书 3:17–18"> 可是如果那不信的一方要离开，就让他离开吧。在这样的事上，那弟兄或姐妹就不受束缚了。不过神召唤了我们<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="我们——有古抄本作“你们”。">h</a></sup>，是要我们和睦。</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前书 3:1–2; 哥林多前书 9:22; 罗马书 11:14"> 做妻子的啊，你到底怎么知道将来是否救你的丈夫呢？做丈夫的啊，你怎么知道将来是否救你的妻子呢？</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 4:17; 罗马书 12:3–8; 哥林多前书 7:24"> 只是当照着主<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="主——有古抄本作“神”。">i</a></sup>所分给每个人的，以及神<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="神——有古抄本作“主”。">j</a></sup>所召唤每个人的去行事。我在各教会中也是这样吩咐的。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 15:5; 使徒行传 15:28; 使徒行传 15:24"> 如果一个人蒙召的时候已经受了割礼<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="一个……已经受了割礼——指“犹太人”。">k</a></sup>，就不应该取消割礼的记号；如果一个人蒙召的时候没有受割礼<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="一个……没有受割礼——指“外邦人”。">l</a></sup>，就不应该受割礼。</span>
<span className="v" id="v19" data-v="19" data-xref="加拉太书 6:15; 加拉太书 5:6; 约翰一书 2:3–4"> 受割礼不重要，不受割礼也不重要，重要的是遵守神的命令。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 7:17; 帖撒罗尼迦前书 4:11; 帖撒罗尼迦后书 3:12"> 每个人在蒙了召唤的时候怎样，他就应当保持怎样。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得前书 2:18–24; 歌罗西书 3:11; 路加福音 10:40–41"> 你蒙召的时候是做奴仆的吗？你不要介意。但如果你真的能成为自由人，还是要把握机会。<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="但如果你真的能成为自由人，还是要把握机会。——或译作“但是即使你有机会成为自由人，也要宁愿充分发挥你作为奴仆的作用。”">m</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:16; 腓利门书 1:16; 歌罗西书 3:22–24"> 要知道，做奴仆时在主里蒙召的，就是主的自由人；同样，做自由人时蒙召的，就是基督的奴仆。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 6:20; 彼得前书 1:18–19; 提多书 2:14"> 你们是被重价赎回来的，不要成为人的奴仆。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 7:20; 歌罗西书 3:23–24; 哥林多前书 7:17"> 弟兄们，你们每个人蒙召的时候怎样，在神面前就应当保持怎样。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="哥林多前书 7:6; 哥林多前书 4:2; 哥林多前书 7:40"> 关于童贞的女子，我没有从主而来的命令，但是我既然蒙主的怜悯成为忠心的人，我就提供意见。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多前书 7:1; 哥林多前书 7:8; 彼得前书 4:17"> 实际上，由于现今的艰难，我认为一个人保持现状是合宜的，这才是好的。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 7:20; 哥林多前书 7:12–14"> 你已经有妻子约束着，就不要寻求摆脱；你没有妻子束缚着<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="没有妻子束缚着——原文直译“被妻子释放”。">n</a></sup>，就不要寻求妻子。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 13:4; 哥林多前书 7:32–36; 哥林多前书 7:26"> 不过你如果还是要结婚，并不是犯罪；童贞女子如果结婚，也不是犯罪。不过这样的人在今生<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="今生——原文直译“肉体上”。">o</a></sup>将要受患难，而我顾惜你们。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰一书 2:17; 哥林多前书 7:31; 罗马书 13:11–12"> 弟兄们，我要说这一点：时候不多了<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="不多了——原文直译“减少了”。">p</a></sup>！从此有妻子的，要像没有妻子的；</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 30:5; 路加福音 6:25; 路加福音 6:21"> 哭泣的，要像没有哭泣的；快乐的，要像没有快乐的；买了东西的，要像没有什么的；</span>
<span className="v" id="v31" data-v="31" data-xref="约翰一书 2:17; 彼得前书 4:7; 雅各书 4:14"> 利用世界的，要像没有充分利用世界的；因为这世界的形态正在消逝。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马太福音 6:25–34; 提摩太前书 5:5; 腓立比书 4:6"> 我希望你们一无挂虑。没有结婚的男人所挂虑的是主的事，是要怎样讨主的喜悦；</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前书 3:7; 歌罗西书 3:19; 以弗所书 5:25–33"> 而结了婚的男人所挂虑的是世界的事，是要怎样讨妻子的喜悦，</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 10:40–42; 哥林多前书 6:20; 路加福音 2:36–37"> 这样他就分心了。未婚女子和童贞女子挂虑主的事，以致身体和心灵都得以圣洁；而结了婚的妇女挂虑世界的事，是要怎样讨丈夫的喜悦。</span>
<span className="v" id="v35" data-v="35" data-xref="哥林多前书 7:33–34; 哥林多前书 7:36; 路加福音 8:14"> 我说这话是为了你们自己的益处，不是要给你们套上牢笼，而是要你们行事合宜，毫无分心地殷勤服事主。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="哥林多前书 7:37; 哥林多前书 7:9; 撒母耳记上 2:33"> 但如果有人认为他对待自己的童贞女儿不合宜，而且女儿也过了花期，事情又该如此行，就当按着自己所愿的去做——他并不是犯罪，应当让两个人结婚。</span>
<span className="v" id="v37" data-v="37"> 但如果一个人自己心里坚定不移，也不出于勉强，又对自己的意愿有主权，并且自己心里已经决定留下自己的童贞女儿，那么他就做得好。</span>
<span className="v" id="v38" data-v="38" data-xref="希伯来书 13:4; 哥林多前书 7:1–2; 哥林多前书 7:8"> 所以，那让自己的童贞女儿结婚的，做得好；那没有让她结婚的，做得更好。<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="-38 或译作“如果有人认为他对待自己的未婚妻不合宜，而且她也过了花期，事情又该如此行，就当按着自己所愿的去做——他并不是犯罪，他们应当结婚。但如果一个人自己心里坚定不移，也不出于勉强，又能控制自己的意志，并且心里已经决定留下自己的未婚妻，那么他就做得好。所以，那与自己的未婚妻结婚的，做得好；那不结婚的，做得更好。”或“如果有人认为自己守童身不合宜，而且他的意愿超过了极限，事情又该如此行，就当按着自己所愿的去做——他并不是犯罪，他们应当结婚。但如果一个人自己心里坚定不移，也不出于勉强，又能控制自己的意志，并且心里已经决定保持自己的童身，那么他就做得好。所以，那结婚的，做得好；那不结婚的，做得更好。”">q</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="罗马书 7:2–3; 哥林多后书 6:14–16; 哥林多前书 7:10"> 丈夫活着的时候，妻子是受约束的<sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="妻子是受约束的——有古抄本作“妻子是被律法约束的”。">r</a></sup>；丈夫如果死了<sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="死了——原文直译“睡了”。">s</a></sup>，妻子就可以自由地嫁给她所愿意的人，只是要嫁给主里的人。</span>
<span className="v" id="v40" data-v="40" data-xref="哥林多前书 7:35; 彼得后书 3:15–16; 哥林多前书 7:8"> 但是照我的意见，如果她能保持现状，就更蒙福了。我想我也有神的灵。</span>
</div>

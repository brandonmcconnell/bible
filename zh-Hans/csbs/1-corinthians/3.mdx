<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 5:13; 哥林多前书 2:14–15; 以弗所书 4:13–14"> 弟兄们，以往我对你们说话，不能把你们当做属灵的，只能当做属肉体的，当做在基督里的小孩子。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 5:11–14; 约翰福音 16:12; 彼得前书 2:2"> 我喂给你们吃的是奶，不是饭，原来你们那时还不能吃饭——其实现在也还是不能，</span>
<span className="v" id="v3" data-v="3" data-xref="雅各书 3:16; 加拉太书 5:15; 提多书 3:3"> 因为你们仍然是属肉体的。既然你们中间有嫉妒、纷争和分裂<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本没有“分裂”。">a</a></sup>，难道你们不就是属肉体的，按人的意思来行事的吗？</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 1:12; 哥林多前书 3:3; 哥林多前书 4:6"> 当有人说：“我是属保罗的”，另有人说：“我是属阿波罗的”时候，难道你们不就是属肉体的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="属肉体的——有古抄本作“人”。">b</a></sup>吗？</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 6:4; 哥林多后书 6:1; 彼得前书 4:10"> 其实阿波罗算什么？保罗算什么？都是仆人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="仆人——或译作“执事”。">c</a></sup>；藉着他们，你们信了，是照着主所赐给每个人的。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 3:9–10; 箴言 11:25; 哥林多后书 10:14–15"> 我栽种了，阿波罗浇灌了，然而使之生长的还是神。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 15:5; 加拉太书 6:3; 诗篇 115:1"> 所以，除了使之生长的神，那栽种的和那浇灌的都算不得什么。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 2:6; 马太福音 16:27; 约翰二书 1:8"> 栽种的和浇灌的都一样，只是将来每个人要照着自己的劳苦得自己的报偿。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 2:5; 以弗所书 2:20–22; 哥林多后书 6:1"> 实际上，我们是神的同工；你们是神的田地，是神的建筑物。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 3:11; 以弗所书 2:20; 罗马书 15:20"> 我照着神赐给我的恩典，像一个有智慧的建筑师，立好了根基，然后别人在上面建造；只是每个人应该当心怎样在上面建造，</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 2:20; 以赛亚书 28:16; 提摩太后书 2:19"> 因为除了那已经立好的根基以外，没有人能立别的；那根基就是耶稣基督。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太后书 4:3; 提摩太后书 3:7; 提摩太后书 2:20"> 如果有人用金、银、宝石，木、草、禾秸在那根基上建造，</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前书 1:7; 哥林多前书 3:14–15; 启示录 20:12"> 每个人的工程将来要显露，因为那日子<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="日子——指“基督再来的日子”。">d</a></sup>要把它显明；原来它要被火显现出来，这火要考验每个人的工程是怎样的。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 3:8; 马太福音 25:21–23; 哥林多前书 4:5"> 如果有人在那根基<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="那根基——辅助词语。">e</a></sup>上面所建造的工程能存留得住，这个人就将得到报偿；</span>
<span className="v" id="v15" data-v="15" data-xref="约翰二书 1:8; 哥林多前书 3:12–13; 犹大书 1:23"> 如果有人的工程被烧掉，他就将受到损失，而他自己却将得救，但是会像从火里经过的那样。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 6:19; 以西结书 36:27; 哥林多后书 6:16"> 你们难道不知道自己就是神的圣所，而且神的灵住在你们里面吗？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 6:18–20; 以西结书 43:12; 民数记 19:20"> 如果有人毁坏<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="毁坏——或译作“败坏”。">f</a></sup>神的圣所，神就要毁坏<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="毁坏——或译作“败坏”。">g</a></sup>这个人，因为神的圣所是圣洁的，这圣所就是你们。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="箴言 3:5; 以赛亚书 5:21; 加拉太书 6:3"> 谁都不可自欺！如果你们中间有人自以为在这个世代中是有智慧的，他就应该变为愚拙，好成为有智慧的，</span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 5:13; 诗篇 141:10; 哥林多前书 1:19–20"> 因为在神看来，这世界的智慧就是愚拙；原来经上记着：“神使智慧人落入自己的诡计中”；</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 94:11; 歌罗西书 2:8; 罗马书 1:21"> 又说：“主知道智慧人的思想是虚妄的。”</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 8:32; 罗马书 8:28; 耶利米书 9:23–24"> 所以谁都不要以人夸耀；要知道，一切都属于你们：</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 4:11–12; 腓立比书 1:21; 哥林多前书 9:19–22"> 无论是保罗、是阿波罗、是矶法、是世界、是生、是死、是现在的事、是将来的事，全都属于你们；</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 3:29; 哥林多前书 11:3; 约翰福音 17:9–10"> 而你们属于基督，基督属于神。</span>
</div>
</div>

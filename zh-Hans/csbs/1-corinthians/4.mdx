<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 4:10; 提多书 1:7; 提摩太前书 3:9"> 这样，人应该把我们看做是基督的仆人、神奥秘之事的管家。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 25:21; 路加福音 12:42; 路加福音 16:10–12"> 在这里，进一步要求管家们的是，各人都要被看做是忠心的。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 7:24; 哥林多前书 2:15; 撒母耳记上 16:7"> 至于我被你们评断，或被人审判，对我都是极小的事。其实连我自己也不评断自己。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 143:2; 约翰一书 3:20–21; 诗篇 130:3"> 我诚然问心无愧，但也并不因此被称为义，原来评断我的是主。</span>
<span className="v" id="v5" data-v="5" data-xref="雅各书 5:7; 哥林多后书 5:10; 哥林多前书 3:13"> 所以时候没有到，在主来临之前，不要评断任何事；主将照亮黑暗中隐秘的事，显明人心里的计划。那时候，称赞将从神那里临到各人。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 12:6; 哥林多后书 11:4; 哥林多后书 12:19"> 弟兄们，我把这些事应用到我和阿波罗身上，是为了你们的缘故，好让你们从我们学到“不要超越经上所记的”，免得你们自我膨胀，抬高这个人，贬低那个人。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 3:27; 彼得前书 4:10; 雅各书 1:17"> 使你与别人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="与别人——辅助词语。">a</a></sup>不同的到底是谁呢？你有什么不是领受的呢？如果真是领受的，你为什么还自夸，好像不是领受的呢？</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 6:25; 箴言 13:7; 哥林多前书 5:6"> 你们已经饱足了，已经富有了，没有我们，自己就做王了！我真希望你们真做王，好让我们也与你们一同做王！</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 10:33; 罗马书 8:36; 哥林多后书 4:8–12"> 其实我在想，神把我们做使徒的列在最后，好像被定死罪的人；原来我们成了给宇宙<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="宇宙——或译作“世界”。">b</a></sup>、天使、世人的一台戏。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 2:3; 使徒行传 26:24; 哥林多前书 3:18"> 我们为基督的缘故是愚拙的，你们在基督里倒是聪明的；我们软弱，你们倒强壮；你们有荣耀，我们倒不受尊重。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 8:35; 哥林多后书 11:23–27; 腓立比书 4:12"> 直到现在这时刻，我们还是又饥又渴，衣不蔽体，被人殴打，居无定所，</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 3:9; 马太福音 5:11; 彼得前书 4:12–14"> 并且亲手劳苦做工。被人辱骂，我们就祝福；被人逼迫，我们就容忍；</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米哀歌 3:45; 使徒行传 22:22"> 受到毁谤，我们就劝导。我们被当做世界的垃圾、万人的渣滓，直到如今。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:11; 哥林多前书 4:15; 约翰三书 1:4"> 我写这些，不是要你们感到羞愧，而是把你们当做我亲爱的儿女来劝诫。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 4:19; 哥林多前书 3:10; 哥林多前书 9:14"> 其实就算你们在基督里有上万的导师<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="导师——或译作“监护人”。">c</a></sup>，却没有很多的父亲，因为是我在基督耶稣里藉着福音生了你们。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 11:1; 帖撒罗尼迦后书 3:9; 腓立比书 3:17"> 所以我劝你们：当效法我。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太前书 1:2; 哥林多前书 16:10; 哥林多前书 7:17"> 为了这缘故，我派提摩太到你们那里去。他是我在主里又亲爱又忠心的儿子，他会使你们想起我在基督耶稣里的行事为人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="行事为人——原文直译“道路”。">d</a></sup>，正如我在各处、各教会中所教导的。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 4:6–8; 哥林多前书 5:2; 哥林多前书 4:21"> 有些人以为我不会到你们那里去，他们就自我膨胀。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多后书 13:1–4; 使徒行传 18:21; 使徒行传 19:21"> 但如果主愿意，我不久就会到你们那里去；那时候，我所要知道的不是那些自我膨胀之人的话语，而是他们的权能，</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 2:4; 帖撒罗尼迦前书 1:5; 哥林多后书 10:4–5"> 因为神的国不在于话语，而在于权能。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 13:2; 哥林多后书 13:10; 帖撒罗尼迦前书 2:7"> 你们要什么呢？要我带着权杖，还是要我带着爱和温柔的心灵到你们那里去呢？</span>
</div>
</div>

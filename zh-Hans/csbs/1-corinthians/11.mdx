<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="1CO" data-book-slug="1-corinthians" data-book-name="哥林多前书" data-chapter="11" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="腓立比书 3:17; 帖撒罗尼迦前书 1:6; 哥林多前书 4:16"> 你们要效法我，就像我效法基督一样。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦后书 2:15; 哥林多前书 4:17; 箴言 31:28–31"> 我称赞你们，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附“弟兄们，”。">a</a></sup>因为你们在一切事上都记念我，并且照着我所传给你们的来持守传统。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 3:16; 歌罗西书 1:18; 歌罗西书 3:18"> 但是我愿你们知道：基督是每一个男人的头，男人是女人的头<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="男人是女人的头——或译作“丈夫是妻子的头”。">b</a></sup>，而神是基督的头。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 15:30; 哥林多前书 12:28; 哥林多前书 12:10"> 凡是男人在祷告或做先知传道<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="做先知传道——原文直译“说预言”。">c</a></sup>的时候，如果蒙着头，就是羞辱自己的头；</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 21:12; 路加福音 2:36; 使徒行传 2:17"> 凡是女人在祷告或做先知传道的时候，如果不蒙着头，就是羞辱自己的头，因为这与头发被剃掉了是同样一件事。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 22:5; 民数记 5:18"> 要知道，女人如果不遮盖自己<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="自己——辅助词语。">d</a></sup>，她就应该连头发也剪掉；但既然女人剪掉头发或剃掉头发是可耻的，她就应该遮盖自己<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="自己——辅助词语。">e</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 11:3; 创世记 5:1; 诗篇 8:6"> 男人本来不应该遮盖着头，因为他是神的形像和荣耀，而女人是男人的荣耀。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太前书 2:13; 创世记 2:21–23"> 原来男人不是由女人而出，女人却是由男人而出；</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 2:18; 创世记 2:23–24; 创世记 2:20"> 并且男人不是为女人而造，女人却是为男人而造。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 24:64–65; 希伯来书 1:14; 马太福音 18:10"> 因此，为了天使的缘故，应该有权柄<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="权柄——传统译法作“权柄的记号”。">f</a></sup>在女人的头之上。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太书 3:28; 哥林多前书 7:10–14; 哥林多前书 12:12–22"> 不过在主里，没有女人就没有男人，没有男人也就没有女人。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 11:36; 哥林多前书 8:6; 希伯来书 1:2–3"> 因为就像女人出于男人，照样，男人也来自女人，而一切都是出于神。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:57; 约翰福音 7:24; 哥林多前书 10:15"> 你们自己判断吧：女人不蒙着头向神祷告是合宜的吗？</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 14:26; 哥林多前书 14:35"> 人的本性不也教导你们：男人如果留长发就是他的羞耻，</span>
<span className="v" id="v15" data-v="15"> 而女人如果留长发就是她的荣耀吗？因为头发是赐给女人当做盖头的。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 7:17; 提摩太前书 6:3–4; 帖撒罗尼迦前书 2:14"> 但如果有人想争辩，我们却没有这样的惯例；神的各教会也没有。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="希伯来书 10:25; 哥林多前书 14:23; 哥林多前书 11:22"> 现在我吩咐以下的事，并不是在称赞你们，因为你们聚集所导致的不是更好，而是更糟。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 3:3; 哥林多前书 1:10–12; 哥林多前书 5:1"> 首先，我听说你们做为一个教会聚集的时候，在你们中间有分裂，我也部分地相信这话。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 2:19; 提多书 3:10; 使徒行传 20:30"> 实际上，你们当中必定也会有结派的事，好让那些经过考验的人在你们中间能显露出来。</span>
<span className="v" id="v20" data-v="20"> 这样说来，你们聚集在一起，所吃的并不是主的晚餐，</span>
<span className="v" id="v21" data-v="21" data-xref="彼得后书 2:13; 犹大书 1:12; 哥林多前书 11:23–25"> 因为你们吃的时候，每个人都争先吃自己的晚餐，甚至有人饿着，有人醉了。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 20:28; 箴言 17:5; 雅各书 2:5–6"> 难道你们没有家，可以在那里吃喝吗？还是你们轻视神的教会，羞辱那些没有什么的人呢？我要对你们怎么说呢？要称赞你们吗？在这事上，我不称赞你们。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 22:19–20; 马太福音 26:26–28; 哥林多前书 11:23–25"> 我当时传授给你们的是我从主所领受的：主耶稣在被出卖的那一夜，拿起饼来，</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 6:53–58; 哥林多前书 11:27–28; 哥林多前书 10:3–4"> 祝谢了，就掰开，说：<span className="woj">“</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附“你们领受吃吧，”。">g</a></sup><span className="woj">这是我的身体，为了你们的缘故</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附“掰开的”。">h</a></sup><span className="woj">；你们应当如此行，为的是记念我。”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 22:20; 希伯来书 9:15–20; 希伯来书 13:20"> 晚餐后，他也照样拿起杯来，说：<span className="woj">“这杯是用我的血所立的新约。你们每逢喝的时候，应当如此行，为的是记念我。”</span></span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 9:28; 启示录 1:7; 约翰福音 14:3"> 你们每逢吃这饼、喝这杯，就是传扬主的死，直到主来。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约翰福音 6:51; 哥林多前书 10:21; 希伯来书 10:29"> 因此无论谁，不合宜地吃主的饼、喝主的杯，就是干犯主的身体、主的血。</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太书 6:4; 哥林多后书 13:5; 耶利米哀歌 3:40"> 这样，一个人应当省察自己，然后才吃这饼、喝这杯。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 11:27; 哥林多前书 11:30; 哥林多前书 11:32–34"> 因为那吃喝的人，如果不分辨主的<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本没有“主的”。">i</a></sup>身体，就是吃喝对自己的惩罚了。</span>
<span className="v" id="v30" data-v="30" data-xref="启示录 3:19; 民数记 20:12; 阿摩司书 3:2"> 为此，你们中间有很多人是软弱的、患病的，甚至有许多人睡着了。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰一书 1:9; 诗篇 32:3–5; 启示录 2:5"> 但如果我们省察自己，就不会受惩罚；</span>
<span className="v" id="v32" data-v="32" data-xref="希伯来书 12:5–11; 诗篇 118:18; 箴言 3:11–12"> 即使我们受惩罚，也是在受主的管教，免得我们和这世界一同被定罪。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 所以我的弟兄们，你们聚集吃的时候，应当彼此等候。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 11:21–22; 哥林多前书 7:17; 哥林多前书 4:19"> 如果有人饿了，就应当在家里吃，免得你们聚集，反导致惩罚。至于其他的事，当我来的时候才吩咐。</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 12:4–11; 哥林多前书 14:37; 哥林多前书 14:1–18"> 弟兄们，我不愿意你们不明白有关属灵的事。</span>
<span className="v" id="v2" data-v="2" data-xref="彼得前书 4:3; 帖撒罗尼迦前书 1:9; 诗篇 115:5"> 你们知道，当你们还是外邦人的时候，是怎样被引诱、被带到那些不能说话的偶像那里的。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰一书 4:2–3; 马太福音 16:16–17; 罗马书 10:9"> 因此我要你们明白：藉着神的灵说话的，没有一个人会说“耶稣该受诅咒”；同样，如果不藉着圣灵，也没有一个人能说：“耶稣是主。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="彼得前书 4:10; 哥林多前书 12:28; 罗马书 12:4–6"> 恩赐虽然有所不同，但圣灵却是同一位；</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 4:11–12; 罗马书 12:6–8; 罗马书 14:8–9"> 服事工作虽然有所不同，但主却是同一位；</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 3:7; 哥林多前书 12:11; 约翰福音 5:17"> 功用虽然有所不同，但在每个人里面运作万事的神却是同一位。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前书 4:10–11; 罗马书 12:6–8; 哥林多前书 14:19"> 不过圣灵显明在每个人的身上，是为了共同的益处，因为：</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 2:6; 哥林多前书 2:6–10; 诗篇 143:10"> <span className="pl pl-1">有人藉着圣灵被赐予了智慧的话语，</span><br /><span className="pl pl-1">又有人藉着同一位圣灵被赐予了知识的话语，</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="雅各书 5:14–15; 哥林多后书 4:13; 以弗所书 2:8"> <span className="pl pl-1">另有人藉着同一位圣灵被赐予了信仰，</span><br /><span className="pl pl-1">又有人藉着这独一的</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="独一的——有古抄本作“同一位”。">a</a></sup><br /><span className="pl pl-1">圣灵被赐予了使人痊愈的恩赐，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 14:39; 约翰一书 4:1; 马可福音 16:17"> <span className="pl pl-1">又有人被赐予了大能的功用</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="大能的功用——或译作“神迹的作用”。">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">又有人被赐予了做先知传道</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="做先知传道——原文直译“说预言”。">c</a></sup><br /><span className="pl pl-1">的恩赐</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="恩赐——辅助词语。">d</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">又有人被赐予了对不同灵的分辨力，</span><br /><span className="pl pl-1">另有人被赐予了各种殊言</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="殊言——原文直译“舌头”；传统译法作“方言”。">e</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">又有人被赐予了翻译殊言的恩赐</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="恩赐——辅助词语。">f</a></sup><br /><span className="pl pl-1">。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 12:4; 希伯来书 2:4; 哥林多后书 10:13"> 然而，这一切都是这同一位圣灵，就是独一的圣灵所运作的；他照着自己的旨意，个别地分给每个人。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="罗马书 12:4–5; 歌罗西书 3:15; 哥林多前书 12:27"> 要知道，正如身体虽然是一个，却有很多部分<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="部分——或译作“肢体”。">g</a></sup>，而身体<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="身体——有古抄本作“一个身体”。">h</a></sup>的各部分虽然有很多，却是一个身体；基督也是如此。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 4:5; 歌罗西书 3:11; 加拉太书 3:28"> 实际上，我们受洗也都是藉着一位圣灵成为一个身体——无论是犹太人或外邦人<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="外邦人——原文直译“希腊人”；指“希腊文化区的非犹太人”。">i</a></sup>，无论是奴隶或自由人——并且我们都是受了一位圣灵的浇灌<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="受了一位圣灵的浇灌——或译作“喝了一位圣灵”。">j</a></sup>。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 12:27–28; 哥林多前书 12:12; 以弗所书 4:25"> 这样，身体也不是只有一个部分，而是有很多部分。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 9:8–15; 列王纪下 14:9"> 如果脚说：“因为我不是手，我就不属于身体”，难道它因此就不属于身体吗？</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 12:3; 哥林多前书 12:22; 腓立比书 2:3"> 如果耳朵说：“因为我不是眼睛，我就不属于身体”，难道它因此就不属于身体吗？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 12:21; 诗篇 139:13–16; 箴言 20:12"> 如果整个身体是个眼睛，那么听觉在哪里呢？如果整个身体是个耳朵，那么嗅觉在哪里呢？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 12:28; 罗马书 12:3; 哥林多前书 12:11"> 所以现在神照着自己的意愿，把各部分一一安置在身体上了。</span>
<span className="v" id="v19" data-v="19"> 如果全都是一个部分，那么身体在哪里呢？</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 12:14; 哥林多前书 12:12"> 但如今，身体的各部分虽然很多，身体却是一个。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以斯拉记 10:1–5; 尼希米记 4:16–21; 约伯记 29:11"> 所以眼睛不能对手说：“我不需要你！”头也不能对两脚说：“我不需要你们！”</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 14:28; 传道书 9:14–15; 传道书 4:9–12"> 相反，身体上那些所谓比较软弱的部分，难道不更是必要的吗？</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 3:21; 创世记 3:7"> 并且身体上那些我们认为不太受尊重的部分，我们加添给它们格外的尊重；这样我们不俊美的部分，就有了格外的俊美。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 3:11; 创世记 2:25"> 至于我们那些俊美的部分，就不需要加添什么<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="加添什么——辅助词语。">k</a></sup>了；而神搭配了身体，把格外的尊重赐给那有缺乏的，</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多后书 13:11; 哥林多前书 1:10–12; 约翰福音 17:21–26"> 免得身体中有分争，好让各部分彼此之间都有同样的关顾。</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 12:15; 加拉太书 6:2; 希伯来书 13:3"> 如果一个部分受苦，所有的部分就一同受苦；如果一个部分得荣耀，所有的部分就一同欢乐。</span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="以弗所书 4:12; 歌罗西书 1:24; 以弗所书 5:30"> 你们就是基督的身体，而且是各个部分中的一个。</span>
<span className="v" id="v28" data-v="28" data-xref="以弗所书 4:11–13; 罗马书 12:6–8; 哥林多前书 12:18"> 在教会中，神所安排的：<br /><span className="pl pl-1">首先是使徒，第二是做先知传道的</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="做先知传道的——原文直译“先知”。">l</a></sup><br /><span className="pl pl-1">，第三是教师，然后是有大能的</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="有大能的——或译作“行神迹的”。">m</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">随后是使人痊愈的恩赐、帮助的恩赐、管理的恩赐、各种殊言的恩赐。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 12:4–11; 哥林多前书 12:14–20"> <span className="pl pl-1">难道都是使徒吗？都是做先知传道的吗？</span><br /><span className="pl pl-1">都是教师吗？都是有大能的</span><sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="有大能的——或译作“行神迹的”。">n</a></sup><br /><span className="pl pl-1">吗？</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前书 12:10"> <span className="pl pl-1">都有使人痊愈的恩赐吗？都说殊言吗？</span><br /><span className="pl pl-1">都翻译殊言吗？</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="哥林多前书 13:1; 哥林多前书 14:39; 马太福音 5:6"> 其实你们要渴慕那些更大的恩赐；而我还要把极其高超的道<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="道——或译作“路”。">o</a></sup>指示给你们。</span>
</div>
</div>

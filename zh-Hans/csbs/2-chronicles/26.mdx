<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 22:1; 马太福音 1:8–9; 历代志下 33:25"> 犹大全体民众选立乌西雅<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="乌西雅——又称“亚撒利雅”；见《列王纪下》14:21。">a</a></sup>，接替他父亲亚玛谢作王，那时他十六岁。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 16:6; 历代志下 25:28; 历代志下 25:23"> 亚玛谢王与列祖长眠之后，乌西雅重建埃拉特，使它回归犹大。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="列王纪下 15:2–3; 阿摩司书 1:1; 何西阿书 1:1"> 乌西雅作王的时候十六岁，在耶路撒冷统治了五十二年。他的母亲名叫耶克利雅，是耶路撒冷人。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 25:2"> 他效法他父亲亚玛谢所做的一切，做耶和华眼中看为正的事。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 15:2; 历代志下 24:2; 历代志上 22:13"> 教导人敬畏神<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="教导人敬畏神——或译作“领悟神的启示”。">b</a></sup>的撒迦利亚在世的时候，乌西雅一直寻求神。在他寻求耶和华的年日里，神使他亨通。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 14:29; 撒母耳记上 5:6; 撒母耳记上 5:1"> 他出去攻打非利士人，拆毁了迦特的城墙、雅比尼的城墙、阿实突的城墙，然后在阿实突附近、在非利士境内建造了几座城。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 21:16; 历代志上 5:20; 历代志下 14:11"> 神帮助他对抗非利士人和住在姑珥巴力的阿拉伯人，以及米乌尼人。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 8:2; 历代志下 17:11; 创世记 19:38"> 亚扪人向乌西雅进贡；他的名声一直传到埃及，因为他变得极其强盛。</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米记 3:13; 历代志下 25:23; 列王纪下 14:13"> 乌西雅在耶路撒冷的角门、谷门和城墙凸角上面都建造塔楼，并加固它们。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 26:18–21; 以赛亚书 29:17; 列王纪下 3:4"> 他在旷野建造守望楼，并开凿了许多水窖，因为他在丘陵和平原上有许多牲畜。他在山区和果园里还有许多农夫和葡萄园丁，他是个喜爱土地的人。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪下 5:2"> 乌西雅有一支善战的军队，按照书记耶伊列和官长玛西雅经手登记的人数，在王的一位将军哈纳尼雅指挥下编队出战。</span>
<span className="v" id="v12" data-v="12"> 各父系的首领——英勇的战士——总数为两千六百人，</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 25:5; 历代志下 14:8; 历代志下 11:1"> 他们手下有善战的军兵三十七万七千五百人，是一支强大力量，帮助王抗击敌军。</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 20:16; 撒母耳记上 17:49"> 乌西雅给全军预备了盾牌、长矛、头盔、铠甲、弓箭和投石器。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 31:4; 马太福音 4:24; 历代志下 2:7"> 他还在耶路撒冷制造了由设计师发明的装置，安放在塔楼和城角上面，用来发射箭矢和大石头。他的名声传到远方，因为他奇妙地得到帮助，强盛了起来。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志下 32:25; 历代志下 25:19; 箴言 16:18"> 乌西雅势力强盛时，就心里高傲，以致败坏。他对他的神耶和华不忠，进入耶和华的圣殿，要在香坛上烧香。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 6:10; 历代志上 26:6; 历代志上 12:28"> 祭司亚撒利雅带着耶和华的祭司八十人跟着他进去，都是英勇的人。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 30:7–8; 民数记 18:7; 耶利米书 13:18"> 他们拦阻乌西雅王，对他说：“乌西雅啊，给耶和华烧香不是你该做的，而是亚伦的子孙祭司们该做的，他们被分别为圣来烧香。请你离开圣所吧！因为你对神不忠，不会从耶和华神那里得到尊荣。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="民数记 12:10; 历代志下 25:16; 列王纪下 5:25–27"> 乌西雅却发怒，那时他手里拿着香炉正要烧香。他正对祭司们发怒时，就在耶和华殿中香坛旁边，在祭司们面前，他的额头上出现了麻风。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 28:22; 以斯帖记 6:12; 利未记 14:34"> 祭司长亚撒利雅和所有的祭司朝他看去，看哪，他额头上长了麻风。他们就急切催他离开，他自己也急着要出去，因为耶和华打击了他。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 13:46; 民数记 12:15; 列王纪下 7:3"> 乌西雅王患了麻风，直到死的日子。他因患了麻风就住在隔离的房子里，与耶和华的殿隔绝。他的儿子约坦接管王室，治理国民。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 1:1; 以赛亚书 6:1; 历代志下 9:29"> 乌西雅其余的事迹，从始至终，都由亚摩斯的儿子先知以赛亚记下来了。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 28:27; 历代志下 21:20; 历代志下 26:18"> 乌西雅与他的列祖长眠，人们把他葬在王陵的田间、与他的列祖在一起，因为他们说：“他是个患麻风的人。”他的儿子约坦接替他作王。</span>
</div>
</div>

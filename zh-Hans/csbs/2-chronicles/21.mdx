<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 22:50; 列王纪下 8:16–17; 历代志下 12:16"> 约沙法与他的列祖长眠，葬在大卫城，与他的列祖在一起；他的儿子约兰接替他作王。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 12:6; 历代志下 23:2; 历代志下 24:5"> 约兰有几个兄弟，就是约沙法的儿子亚撒利雅、耶希业、撒迦利亚、亚撒利雅、米迦勒和示法提雅，这些都是以色列王约沙法的儿子。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 11:23; 申命记 21:15–17; 历代志下 11:5"> 他们的父亲给了他们许多礼物，有金银、珍宝，以及犹大的几座防御城；但把王权交给了约兰，因为他是长子。</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 9:5; 历代志下 21:17; 创世记 4:8"> 约兰执掌他父亲的国权，势力稳固之后，用刀杀了他所有的兄弟，还杀了以色列的一些首领。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪下 8:17–22"> 约兰作王的时候三十二岁，在耶路撒冷统治了八年。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 18:1; 列王纪上 12:28–30; 列王纪下 8:18"> 他走以色列王的道路，像亚哈家所做的那样，因为亚哈的女儿作了他的妻子；他做耶和华眼中看为恶的事。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 11:36; 诗篇 132:17–18; 撒母耳记下 7:12–17"> 但耶和华因着他与大卫所立的约，就不愿毁掉大卫家，而要照着他的应许永远赐给大卫和大卫的子孙一盏灯。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="历代志下 21:10; 历代志下 20:22–23; 创世记 27:40"> 约兰年间，以东反叛脱离犹大的掌控，自己立了一个王。</span>
<span className="v" id="v9" data-v="9"> 约兰就带着他的将领以及所有的战车过去。他夜间起来，攻击那些包围他的以东人和众战车长。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 15:2; 耶利米书 2:13; 历代志下 13:10"> 最终，以东反叛脱离了犹大的权下，直到今日。立拿也在那时反叛脱离约兰的掌控，因为约兰离弃了耶和华他祖先的神。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 20:5; 列王纪上 11:7; 利未记 17:7"> 他还在犹大各山上建造高坛，使耶路撒冷的居民行淫，把犹大人引入歧途。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="历代志下 14:2–5; 历代志下 17:3–4; 列王纪下 2:1"> 于是先知以利亚写信给约兰，说：<br />“你先祖大卫的神耶和华如此说：‘因为你不走你父亲约沙法的道路，也不走犹大王亚撒的道路，</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 21:4; 历代志下 21:11; 列王纪上 16:30–33"> 却走了以色列王的道路，像亚哈家行淫那样，使犹大人和耶路撒冷的居民行淫，并且杀了你父家那些比你好的兄弟，</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 26:21; 出埃及记 20:5; 何西阿书 5:11"> 看哪，耶和华将用极大的灾祸打击你的子民和你的儿子们、妃嫔们，以及你拥有的一切。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 21:18–19; 使徒行传 1:18; 申命记 28:67"> 至于你，你会有严重的病患，是肠道的疾病，你的肠道必因日复一日的病患而脱垂。’”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志下 17:11; 历代志下 33:11; 列王纪上 11:14"> 耶和华激发非利士人以及库实人附近的阿拉伯人的怒气，与约兰作对。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 22:1; 历代志下 22:6; 历代志下 25:23"> 他们就上来攻打犹大，攻破了它，掳走王宫里的一切财物，以及王的儿子们、妃嫔们；除了他最小的儿子约哈斯以外，没有给他留下一个儿子。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="历代志下 21:15; 使徒行传 12:23; 列王纪下 9:29"> 这一切事之后，耶和华打击约兰，使他的肠道患了不治之症。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 16:14; 耶利米书 34:5"> 一天天过去，两年之后，他的肠道因这疾病而脱垂，他就病重而死。他的子民没有为他燃起篝火哀悼<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="哀悼——辅助词语。">a</a></sup>，像为他祖先燃起篝火那样。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="耶利米书 22:18; 历代志下 28:27; 耶利米书 22:28"> 他作王的时候三十二岁，在耶路撒冷统治了八年。他去世无人悼念，人们把他葬在大卫城，但不在君王们的陵墓里。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 29:25; 列王纪上 2:12; 创世记 39:2"> 大卫的儿子所罗门稳固了自己的王权；他的神耶和华与他同在，使他极其尊大。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 28:1; 历代志上 27:1; 历代志下 30:2"> 那时，所罗门召唤全以色列的千夫长、百夫长、审判官，以及全以色列所有的领袖——各父系的首领。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 21:29; 历代志上 16:39; 利未记 1:1"> 然后所罗门与全体会众一同去基遍的高坛，因为那里有耶和华的仆人摩西在旷野所造与神相会的帐幕；</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 6:17; 历代志上 15:25–28; 撒母耳记下 6:2"> 至于神的约柜，大卫已经从基列-耶琳抬上来，放到他所预备的地方，因为他在耶路撒冷为约柜支搭了一个帐篷。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 31:2; 出埃及记 38:1–7; 历代志上 2:19–20"> 耶和华的帐幕前面还有户珥的孙子、乌利的儿子比撒列所造的铜祭坛，所罗门和会众在那里求问耶和华。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 3:4; 列王纪上 8:63; 历代志上 29:21"> 所罗门上到耶和华面前会幕的铜祭坛那里，在祭坛上献了一千只祭牲为燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 7:7–8; 约翰一书 5:14–15; 约翰福音 16:23"> 当天夜里，神向所罗门显现，对他说：“你要我赐给你什么，尽管求吧。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="历代志上 28:5; 以赛亚书 55:3; 撒母耳记下 22:51–1"> 所罗门对神说：“你以极大的慈爱对待我父亲大卫，又使我接替他作王。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 7:12–16; 创世记 13:16; 诗篇 132:11–12"> 耶和华神哪，现在求你成就你对我父亲大卫的应许，因为你已经使我作王，统治多如地上尘沙的子民。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 3:9; 箴言 4:7; 箴言 2:2–6"> 现在求你赐给我智慧和知识，我好带领这子民出入，否则谁能治理你这众多的子民呢？”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="雅各书 3:17; 箴言 23:7; 撒母耳记上 16:7"> 神对所罗门说：“既然你心中有这样的愿望<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="愿望——辅助词语。">a</a></sup>，你不求富贵、资产和荣华，不求除去仇敌的性命，也不求长寿，却为自己求智慧和知识，好治理我使你作王统治的子民，</span>
<span className="v" id="v12" data-v="12" data-xref="雅各书 1:5; 历代志下 9:22; 马太福音 6:33"> 所以智慧和知识必赐给你，我也必赐给你富贵、资产和荣华，在你之前的君王们未曾这样，在你之后的君王们也必不会这样。”</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 1:3; 列王纪上 4:24–25"> 于是所罗门从基遍高坛的会幕前回到耶路撒冷，统治以色列。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王纪上 4:26; 列王纪上 10:26–29; 历代志下 9:25"> 所罗门屯集战车和马兵，有一千四百辆战车、一万两千马兵，都安置在屯车的城镇，以及王所在的耶路撒冷。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 9:27; 以赛亚书 9:10; 列王纪上 10:27–29"> 王使金银在耶路撒冷多如石头，使香柏木像丘陵的西克莫无花果树那样多。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 9:28; 列王纪上 10:28–29"> 所罗门的马匹是埃及和库威出口的，由王的商人按照市价从库威买来。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 10:29"> 他们从埃及进口的战车每辆六百谢克尔<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="六百谢克尔——相当于6.8公斤。1谢克尔=11.4公克。">b</a></sup>银子，进口的马每匹一百五十谢克尔<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一百五十谢克尔——相当于1.7公斤。">c</a></sup>；这些也经由他们出口到赫提人诸王以及亚兰众王那里。</span>
</div>
</div>

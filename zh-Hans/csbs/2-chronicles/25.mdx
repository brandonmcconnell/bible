<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="2CH" data-book-slug="2-chronicles" data-book-name="历代志下" data-chapter="25" data-verses="28">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 14:1–6"> 亚玛谢作王的时候二十五岁，在耶路撒冷统治了二十九年。他的母亲名叫耶赫阿丹，是耶路撒冷人。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 25:14; 雅各书 4:8; 使徒行传 8:21"> 他做耶和华眼中看为正的事，只是没有全心去做。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="历代志下 24:25–26; 列王纪下 14:5–22; 创世记 9:5–6"> 当他的王权稳固后，他就把杀他父王的臣仆都杀掉了。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 24:16; 以西结书 18:20; 列王纪下 14:5–6"> 但他没有处死他们的儿子，是照着摩西的书中律法所记的，耶和华所指示的：“不可因着儿子处死父亲，也不可因着父亲处死儿子；各人只可因自己的罪过被处死。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民数记 1:3; 历代志下 17:14–18; 历代志下 11:1"> 亚玛谢招聚犹大人，按着他们的父家在全犹大和便雅悯设立千夫长和百夫长，又数点他们二十岁以上的，有三十万精兵，能用长矛和盾牌列队出战。</span>
<span className="v" id="v6" data-v="6"> 他还用一百他连得<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一百他连得——相当于3.4公吨；下同。1他连得=34.2公斤。">a</a></sup>银子，从以色列雇用了十万英勇的战士。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志下 19:2; 列王纪上 12:28; 何西阿书 9:13"> 有一个神人来见亚玛谢，说：“王啊，不要让以色列的军队与你同去，因为耶和华不与以色列——任何以法莲人同在。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 14:11; 历代志下 20:6; 腓立比书 4:19"> 你如果一定要去，就奋勇作战吧，神必使你败在仇敌面前！要知道，神有能力帮助人或使人败亡。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="箴言 10:22; 申命记 8:18"> 亚玛谢对神人说：“我付给以色列军的那一百他连得银子怎么办呢？”<br />神人说：“耶和华能赐给你的比这更多。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="列王纪上 12:24; 撒母耳记下 19:43; 箴言 29:22"> 于是亚玛谢解散了从以法莲请来的军队，让他们回自己的地方去。他们就对犹大人非常恼火，在烈怒中回自己的地方去了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪下 14:7; 诗篇 60:1; 撒母耳记下 8:13"> 亚玛谢坚定心志，率领他的军兵到盐谷去，击杀了一万西珥人。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 20:10; 历代志上 20:3; 撒母耳记下 12:31"> 犹大人还活捉了一万人，把他们带到悬崖顶上，从悬崖顶上扔下去，他们全都粉身碎骨了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志下 8:5; 列王纪上 16:29; 列王纪上 9:17"> 但亚玛谢所遣散回去、不许与他同去作战的那队军兵，却侵袭犹大各城，从撒玛利亚直到伯贺仑，击杀了民中的三千人，掠夺了大量财物。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志下 28:23; 申命记 7:25; 申命记 7:5"> 亚玛谢击杀以东人回来后，带来西珥人的神像，立为自己的神，在它们面前下拜，向它们烧香。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 96:5; 历代志下 25:11–12; 历代志下 25:7"> 于是耶和华的怒气向亚玛谢发作，派遣一位先知到他那里，对他说：“这民的神既然不能解救自己的子民脱离你的手，你为什么还寻求它们呢？”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志下 18:20–21; 耶利米书 29:26; 历代志下 18:25"> 先知还在向王说话的时候，王对他说：“我们设立你作王的谋士了吗？住口吧！何必让人击杀你呢？”<br />先知就停住了，只说：“我知道神已经决定要毁灭你了，因为你做了这事，又不听从我的劝告。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王纪下 14:8–14; 历代志下 25:13; 箴言 20:3"> 犹大王亚玛谢经过商议后，就派人去见耶户的孙子、约哈斯的儿子以色列王约阿施，说：“来，让我们战场相见吧！”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="士师记 9:8–15; 列王纪上 4:33; 诗篇 80:13"> 以色列王约阿施就派人去见犹大王亚玛谢，说：“黎巴嫩的蒺藜派人到黎巴嫩的香柏树那里，说：‘把你的女儿嫁给我儿子为妻吧！’然而，却有一只黎巴嫩的野兽经过，把那蒺藜践踏了。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 26:16; 历代志下 32:25; 箴言 18:6"> 你说‘看哪，我击败了以东’，你的心就高傲自大。你现在留在家里吧！何必招惹祸患，使自己和犹大一同败亡呢？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="历代志下 22:7; 列王纪上 12:15; 彼得前书 2:8"> 亚玛谢却不听，因为这是出于神，好把他们交在约阿施手中，因为他们寻求以东的神明。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 6:19–20; 撒母耳记上 6:9; 约书亚记 21:16"> 于是以色列王约阿施上来，与犹大王亚玛谢在犹大的伯示麦对阵。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 4:10; 历代志下 28:5–6; 列王纪上 22:36"> 犹大败在以色列面前，各人逃回自己的帐篷。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 21:17; 尼希米记 8:16; 历代志下 26:9"> 以色列王约阿施在伯示麦捉住了约哈斯的孙子、约阿施的儿子犹大王亚玛谢，把他带到耶路撒冷，又拆毁了耶路撒冷的城墙，从以法莲门直到角门，有四百肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="四百肘——相当于183公尺。1肘=45.7公分。">b</a></sup>。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 26:15; 历代志下 12:9; 列王纪下 14:14"> 约阿施夺取俄别·以东所看管的神殿中所有的金银、所有的器具，以及王宫里的宝物，并掳去人质，然后回撒玛利亚去了。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王纪下 14:17–22"> 约哈斯的儿子以色列王约阿施死后，约阿施的儿子犹大王亚玛谢又活了十五年。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志下 20:34; 列王纪下 14:15"> 亚玛谢其余的事迹，从始至终，看哪，不是都记在《犹大和以色列诸王纪》上吗？</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="历代志下 24:25; 约书亚记 10:31; 列王纪下 14:19"> 自从亚玛谢离弃耶和华之后，有人在耶路撒冷密谋反叛他，他就逃到拉吉，但他们派人追到拉吉，在那里杀了他。</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪下 14:20"> 人们用马把他驮回来，葬在犹大城，与他的列祖在一起。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 21:1–18; 历代志上 3:13; 以赛亚书 3:12"> 玛拿西作王的时候十二岁，在耶路撒冷统治了五十五年。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 28:3; 申命记 18:9; 列王纪下 17:11"> 他做耶和华眼中看为恶的事，效法耶和华在以色列子民面前赶出的那些民族，行可憎之事。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 16:21; 申命记 17:3; 历代志下 31:1"> 他重建了他父亲希西加拆毁的高坛，为巴力设立祭坛，制作亚舍拉柱，并向天上的万象下拜，服事它们。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 7:16; 列王纪上 8:29; 申命记 12:11"> 他在耶和华殿中筑了别的祭坛，关于这殿，耶和华曾指着它说“我的名要永远在耶路撒冷”。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 4:9; 耶利米书 32:34–35; 以西结书 8:7–18"> 他又在耶和华殿的两个院子里为天上的万象筑了祭坛，</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 18:21; 利未记 20:6; 历代志下 28:3"> 在欣嫩子谷使自己的儿女经火，并且算命、行法术、行巫术、招魂、通灵。他做了许多在耶和华眼中看为恶的事，惹他恼怒。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志下 33:4; 历代志下 7:16; 列王纪上 11:13"> 玛拿西甚至把自己雕刻的偶像安置在神的殿中，关于这殿，神曾指着它对大卫和他儿子所罗门说：“我要在这殿中，在我从以色列众支派所拣选的耶路撒冷，永远安置我的名。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 7:10; 申命记 5:31–1; 利未记 8:36"> 只要以色列人谨守遵行我藉着摩西所吩咐他们的一切律法、律例和法规，我就不再使他们的脚离开我指定给你们列祖的这地。”</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 24:3–4; 箴言 29:12; 历代志下 33:2"> 玛拿西使犹大人和耶路撒冷的居民迷失，以致他们作恶超过那些在以色列子民面前被耶和华除灭的民族。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志下 36:15–16; 耶利米书 44:4–5; 撒迦利亚书 1:4"> 耶和华对玛拿西和他的子民说话，他们却不听。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 28:36; 历代志下 36:6; 尼希米记 9:32"> 所以耶和华使亚述王的将领们来攻击他们，用钩子捉住玛拿西，用铜链捆住他，把他带到巴比伦去。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 10:3; 诗篇 50:15; 历代志下 32:26"> 他在危难的时候，恳求他的神耶和华的恩宠，在他祖先的神面前极其谦卑。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 5:20; 但以理书 4:25; 马太福音 7:7–8"> 他向耶和华祷告，耶和华就应允他的祈求，垂听他的恳求，使他回归耶路撒冷，恢复王权。玛拿西这才知道：唯独耶和华是神。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志下 27:3; 列王纪上 1:33; 尼希米记 3:3"> 此后他在大卫城外，从溪谷中的基训西边直到鱼门入口，建造了一道城墙，环绕俄斐勒，并且建得很高。他又在犹大所有坚固的城中指派将领。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="历代志下 33:3–7; 何西阿书 14:1–3; 列王纪下 21:7"> 他还从耶和华殿中除掉了外邦的神明和偶像，也把他在耶和华殿的山上、在耶路撒冷修筑的祭坛全都抛到了城外。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 14:4; 列王纪上 18:30; 历代志下 33:9"> 然后他重新修筑耶和华的祭坛，在其上献平安祭和感谢祭，吩咐犹大人要服事耶和华以色列的神。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 32:12; 列王纪上 22:43; 列王纪下 15:4"> 不过百姓仍旧在高坛献祭，虽然只是献给耶和华他们的神。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="历代志下 33:19; 历代志下 33:12–13; 阿摩司书 7:12"> 玛拿西其余的事迹，还有他向他的神献上的祷告，以及那些先见奉以色列的神耶和华的名向他宣告的话，看哪，这些都记在《以色列诸王纪事》上。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 9:11; 约翰一书 1:9; 但以理书 5:22"> 他的祷告，神怎样应允他的祈求，他谦卑下来之前的一切罪恶和不忠行为，以及他在哪些地方建造高坛、竖立亚舍拉柱和雕像，看哪，都记在《何赛纪事》上。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 1:10; 历代志下 32:33; 列王纪下 21:18–25"> 玛拿西与他的列祖长眠，人们把他葬在他的宫殿院内；他的儿子亚门接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="雅各书 4:13–15; 路加福音 12:19–20; 历代志下 33:1"> 亚门作王的时候二十二岁，在耶路撒冷统治了两年。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 21:20; 以西结书 20:18; 列王纪下 21:1–11"> 他效法他父亲玛拿西的行为，做耶和华眼中看为恶的事。亚门向他父亲玛拿西雕刻的一切偶像献祭，服事它们。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 33:12; 历代志下 33:19; 耶利米书 7:26"> 但他没有像他父亲玛拿西那样，在耶和华面前谦卑下来，反而这亚门不断增加罪过。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="罗马书 11:22; 历代志下 25:27–28; 历代志下 24:25–26"> 他的臣仆密谋反叛他，在他的宫殿里把他杀了。</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 35:31; 历代志下 34:1; 历代志下 36:1"> 那地的民众又把所有密谋反叛亚门王的人都杀了，然后立他的儿子约西亚接替他作王。</span>
</div>
</div>

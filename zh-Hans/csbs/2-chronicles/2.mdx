<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 5:5; 历代志上 22:10; 列王纪上 7:1"> <sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="此章在马索拉文本为1:18至2:17。">a</a></sup>所罗门决定开始为耶和华的名建造殿宇，并为自己建造王宫。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 2:18; 列王纪上 5:15–16"> 于是所罗门数点出七万人作搬运工，八万人在山上作石匠，三千六百人作监工。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="历代志上 14:1; 撒母耳记下 5:11; 列王纪上 5:1–11"> 所罗门派人去见提尔王希兰，说：<br />“你怎样对待我父亲大卫，给他送来香柏木，使他可以为自己建造宫殿居住，请你也照样对待我。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 30:7; 出埃及记 25:30; 历代志下 2:1"> 看哪，我现在要为我神耶和华的名建造殿宇，分别为圣献给他，为要在他面前烧献芬芳香，常摆陈设饼，并在清晨和傍晚、在安息日和新月节、在我们神耶和华所定的各节期献上燔祭，这是以色列永远的定例。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 16:25; 出埃及记 15:11; 诗篇 135:5"> 我要建造的殿宇宏大，因为我们的神伟大，超过一切神明。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 66:1; 历代志下 6:18; 列王纪上 8:27"> 事实上，天和天上的天都无法容纳他，谁能为他建造殿宇呢？我又是谁，竟能为他建造殿宇！我只不过能建造一个在他面前烧香的地方<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="建造一个在他面前烧香的地方——或译作“在他面前烧香”。">b</a></sup>。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 2:13–14; 历代志上 22:15–16; 出埃及记 31:3–5"> 现在，请给我派来一个巧匠——善用金、银、铜、铁，以及紫色、朱红色、蓝色线制作东西，并且精于雕刻工艺；他要与我父亲大卫所预备的、那些同我在犹大和耶路撒冷的巧匠一起工作。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 5:6; 列王纪上 10:11; 历代志下 9:10–11"> 也请你从黎巴嫩送来香柏木、松木和檀香木，因为我知道你的仆人善于砍伐黎巴嫩的树木。看哪，我的仆人会与你的仆人一起工作，</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 9:8; 历代志下 2:5; 历代志下 7:21"> 好为我预备大量的木材，因为我要建造的殿宇宏大奇伟。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 5:11; 以斯拉记 7:22; 罗马书 13:7–8"> 看哪，我会给你的仆人——伐木的工人小麦两万柯珥<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="两万柯珥——相当于4,400,000公升；下同。1柯珥=220公升。">c</a></sup>，大麦两万柯珥，酒两万罢特<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="两万罢特——相当于440,000公升；下同。1罢特=22公升。">d</a></sup>，油两万罢特。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪上 10:9; 历代志下 9:8; 诗篇 72:17"> 于是提尔王希兰写信，送到所罗门那里，说：<br />“耶和华因为爱自己的子民，所以立你作他们的王。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="诗篇 33:6; 彼得前书 1:3; 启示录 4:11"> 希兰又说：<br />“那造了诸天和大地的以色列的神耶和华是当受颂赞的！因他赐给了大卫王一个有智慧的儿子，使他有见识有悟性，能为耶和华建造殿宇，也为自己建造王宫。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 4:16"> 现在我派去户兰阿比<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="户兰阿比——或译作“户兰匠师”。">e</a></sup>，他是一个有悟性的巧匠，</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 2:7; 出埃及记 31:3–4; 列王纪上 7:13–14"> 是但支派中一个妇人的儿子，父亲是提尔人。他善用金、银、铜、铁、石、木料，以及紫色、蓝色、朱红色线和细麻制作东西，又精于各样的雕刻艺术，能设计出交托他的任何图案。他会与你的巧匠和我主你父亲大卫的巧匠一同工作。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 2:10; 列王纪上 5:11"> 现在，也请我主把所说的小麦、大麦、油和酒运送给你的仆人们。</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 19:46; 列王纪上 5:8–9; 以斯拉记 3:7"> 我们会照着你一切所需的，从黎巴嫩砍伐树木，扎成木排从海上给你运到约帕，然后你可以把它们运到耶路撒冷。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="历代志上 22:2; 列王纪上 5:13–16; 历代志下 8:7–8"> 所罗门在他父亲大卫数点人口之后，又数点了以色列地的所有寄居者，共有十五万三千六百人。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 2:2"> 他就安排他们当中的七万人作搬运工，八万人在山上作石匠，三千六百人来监管工人劳动。</span>
</div>
</div>

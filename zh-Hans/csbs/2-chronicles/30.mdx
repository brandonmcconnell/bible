<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="2CH" data-book-slug="2-chronicles" data-book-name="历代志下" data-chapter="30" data-verses="27">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 5:7–8; 历代志下 11:13; 何西阿书 5:4"> 那时希西加派人到全以色列和全犹大，又写信给以法莲人和玛拿西人，要他们到耶路撒冷耶和华的殿来，向以色列的神耶和华守逾越节。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 9:10–11; 历代志上 13:1–3; 历代志下 30:13"> 王和首领们以及在耶路撒冷的全体会众商议了，要在二月守逾越节；</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 29:34; 出埃及记 12:6; 出埃及记 12:18"> 他们不能在正月守节，因为分别为圣的祭司还不够，而且民众还没有聚集到耶路撒冷。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 13:4"> 这事在王眼中和全体会众眼中都看为合宜，</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 20:1; 利未记 23:2; 以斯帖记 8:8–10"> 他们就作出决议，传令全以色列，从比尔-谢巴直到但，要到耶路撒冷向以色列的神耶和华守逾越节，因为他们已经很久没有照着律法所记的守节了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="耶利米书 51:31; 以斯帖记 8:14; 列王纪下 15:19"> 信使们带着王和首领们签发的书信，走遍全以色列和全犹大，照着王的谕令宣告：“以色列子孙哪，你们要回转归向亚伯拉罕、以撒、以色列的神耶和华，好使他也转向你们这些在亚述王手下残留的幸存者。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 29:8; 以西结书 20:13–18; 撒迦利亚书 1:3–4"> 你们不要像你们的祖先和你们的兄弟那样，他们对他们祖先的神耶和华不忠，以致耶和华使他们令人惊骇，正如你们所看见的那样。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 32:9; 历代志下 29:10; 申命记 10:16"> 现在你们不要像你们的祖先那样硬着颈项，而要举手归顺耶和华，进入他的圣所——那永远分别为圣的居所，要服事耶和华你们的神，好使他从你们身上收回他猛烈的怒气。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 55:7; 弥迦书 7:18; 诗篇 86:5"> 如果你们回转归向耶和华，你们的兄弟和你们的儿女就会在掳走他们的人面前蒙怜悯，回归这地；因为你们的神耶和华有恩惠、有怜悯，只要你们回转归向他，他必不会转脸不顾你们。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志下 36:16; 历代志下 30:6; 尼希米记 2:19"> 信使们从这城到那城走遍了以法莲和玛拿西之地，直到西布伦；那里的人却讥笑他们，嘲笑他们。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 30:18; 历代志下 30:21; 历代志下 30:25"> 但在亚设和玛拿西，在西布伦，有一些人谦卑下来，前往耶路撒冷。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 32:39; 耶利米书 24:7; 腓立比书 2:13"> 神的手也在犹大人身上，赐给他们合一的心，去遵行王和首领们按照耶和华的吩咐颁发的谕令。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志下 30:2; 诗篇 84:7"> 到了二月，有许多民众聚集到耶路撒冷守除酵节，成了盛大的集会。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 28:24; 撒母耳记下 15:23; 历代志下 15:16"> 他们起来，除掉耶路撒冷的那些祭坛，也除掉了所有烧香的祭坛，扔进汲沦溪谷。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 29:34; 历代志下 5:11; 出埃及记 19:22"> 二月十四日，他们宰杀了逾越节的羔羊。祭司和利未人感到愧疚，所以使自己分别为圣，然后把燔祭带到耶和华殿中。</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 33:1; 历代志下 35:15; 列王纪下 11:14"> 他们照着神人摩西的律法，按照他们的规定，在自己的位置上侍立，祭司从利未人接过血来洒在祭坛上<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="在祭坛上——辅助词语。">a</a></sup>。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 29:34; 历代志下 35:3–6; 出埃及记 12:6"> 因为会众有许多人还没有使自己分别为圣，所以利未人负责为所有不洁净的人宰杀逾越节的羔羊，好使他们在耶和华面前分别为圣。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 11:28; 雅各书 5:15–16; 但以理书 9:19"> 其实，大部分民众——有许多来自以法莲、玛拿西、以萨迦和西布伦——他们还没洁净自己，就已经不按律法所记的吃了逾越节的羔羊，因此希西加为他们祷告说：“至善的耶和华啊，愿你饶恕他们！</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 19:3; 箴言 23:26; 约伯记 11:13"> 他们都立定心志寻求神——耶和华他们祖先的神，尽管他们没有照圣所的洁净礼行事。”</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 15:26; 雅各书 5:15–16; 诗篇 103:3"> 耶和华垂听了希西加，就医治<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="医治——或译作“赦免”。">b</a></sup>民众。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 12:15; 出埃及记 13:6; 申命记 12:12"> 在耶路撒冷的以色列人极其欢喜地守了七天除酵节，利未人和祭司们每天都用嘹亮的乐器在耶和华面前赞美耶和华。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 32:6; 尼希米记 9:3; 以赛亚书 40:1–2"> 希西加对所有在耶和华的事上明达干练的利未人说宽心的话。这样，他们献上平安祭并称谢耶和华他们祖先的神，吃这节期的筵席共七天。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪上 8:65; 历代志下 7:9"> 全体会众商议，要另外守节七天，于是他们欢欢喜喜地又守了七天。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志下 29:34; 历代志下 35:7–8; 以弗所书 4:8"> 因此犹大王希西加为会众捐出了一千头公牛、七千只羊，首领们为会众捐出了一千头公牛、一万只羊，有许多祭司使自己分别为圣。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 30:11; 历代志下 30:18; 历代志上 16:10–11"> 于是，犹大全体会众、祭司、利未人、从以色列各地来的全体会众、从以色列各地来的寄居者和居住在犹大的人，都欢喜快乐。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志下 7:8–10"> 在耶路撒冷有极大的喜乐，因为自从大卫的儿子以色列王所罗门那时候以来，耶路撒冷从来没有这样做过。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="申命记 26:15; 诗篇 68:5; 民数记 6:23–26"> 那时利未祭司们起来，祝福民众，他们的声音蒙神垂听，他们的祷告达到天上那神圣的居所。</span>
</div>
</div>

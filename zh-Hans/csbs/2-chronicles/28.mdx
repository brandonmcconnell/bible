<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="2CH" data-book-slug="2-chronicles" data-book-name="历代志下" data-chapter="28" data-verses="27">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 3:13; 以赛亚书 1:1; 列王纪下 16:1–20"> 亚哈斯作王的时候二十岁，在耶路撒冷统治了十六年。他没有像他先祖大卫那样，做耶和华眼中看为正的事，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 34:17; 士师记 2:11; 历代志下 22:3–4"> 而是走以色列王的道路，甚至为巴力铸造偶像。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 33:2; 历代志下 33:6; 利未记 18:21"> 他效法耶和华在以色列子民面前赶出的那些民族的可憎行为，在欣嫩子谷烧香，用火焚烧自己的儿女；</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 16:4; 申命记 12:2–3; 利未记 26:30"> 又在高坛上、丘陵上、各青翠树下献祭烧香。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 7:1; 历代志下 24:24; 列王纪下 16:5–6"> 所以耶和华他的神把他交在亚兰王手中；亚兰王击败了他，从他那里掳走了很多人，带到大马士革。<br />亚哈斯又被交在以色列王手中，以色列王向他大行杀戮。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 15:27; 约书亚记 24:20; 耶利米书 15:6"> 利玛利的儿子比加在犹大一天之内杀了十二万人，全都是勇士，因为他们离弃了耶和华他们祖先的神。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 43:15; 创世记 41:43; 以斯帖记 10:3"> 以法莲的勇士泽克利杀了王子玛西雅、宫廷总管亚斯利甘和宰相以利加拿。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 11:4; 申命记 28:25; 申命记 28:41"> 以色列人掳走了他们的兄弟二十万人，包括这些人的妻子、儿女，还从他们那里掠夺了许多财物，把战利品带到撒玛利亚。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 47:6; 以斯拉记 9:6; 启示录 18:5"> 那里有耶和华的一位先知，名叫俄德，他出来迎见回撒玛利亚的军队，对他们说：“看哪，你们祖先的神耶和华对犹大恼怒，把他们交在你们手中，你们竟然怒火滔天杀戮他们。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 25:39–46; 马太福音 7:2–4; 耶利米书 25:29"> 现在你们又想要强迫犹大和耶路撒冷的人作你们的仆婢。你们自己不也在你们的神耶和华面前有罪过吗？</span>
<span className="v" id="v11" data-v="11" data-xref="雅各书 2:13; 以斯拉记 10:14; 马太福音 5:7"> 现在请听我说！你们要把从你们兄弟中掳来的俘虏送回去，因为耶和华猛烈的怒气临到你们了！”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="历代志上 28:1; 耶利米书 26:6"> 于是以法莲人的一些首领，就是约哈南的儿子亚撒利雅、米实列莫的儿子比利迦、沙勒姆的儿子耶希西加和哈德莱的儿子亚玛撒，起来拦阻那些从战场回来的人，</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 32:14; 马太福音 23:32; 约书亚记 22:17–18"> 对他们说：“你们不可把俘虏带到这里来。我们已经在耶和华面前有罪过了，你们还想要增添我们的罪恶和罪过！我们的罪过实在重大，有猛烈的怒气临到以色列了！”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 于是，武装士兵们把俘虏和财物留在众首领和全体会众面前。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 25:21–22; 申命记 34:3; 士师记 1:16"> 以上被指名的那几个人就起来，把俘虏领来，从战利品中拿出衣服给他们所有赤身的人穿上，给他们穿衣穿鞋，给他们吃喝，给他们抹油，又用驴子驮着他们中所有虚弱的人，把他们带到棕榈城耶利哥他们的兄弟身边。然后，他们回撒玛利亚去了。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪下 16:5–7; 以赛亚书 7:17; 以赛亚书 7:1–9"> 那时，亚哈斯王派人去见亚述王<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="王——依据七十士译本；马索拉文本作“众王”。">a</a></sup>，向他求助。</span>
<span className="v" id="v17" data-v="17" data-xref="俄巴底亚书 1:10; 俄巴底亚书 1:13–14; 利未记 26:18"> 因为以东人再次来攻打犹大，掳走民众。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 16:57; 以西结书 16:27; 撒母耳记上 6:9"> 非利士人也抢掠了犹大丘陵和南地<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="南地——音译作“内盖夫”。">b</a></sup>的城镇，攻取了伯示麦、阿雅仑、格德罗，还有梭哥和附属的村镇，亭拿和附属的村镇，瑾琐和附属的村镇，然后住在那里。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 21:2; 约伯记 40:12; 申命记 28:43"> 耶和华由于犹大王<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="犹大王——马索拉文本作“以色列王”。">c</a></sup>亚哈斯的缘故，就降卑犹大，因为亚哈斯使犹大放纵行恶，对耶和华极其不忠。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 15:29; 历代志上 5:26; 以赛亚书 30:16"> 亚述王提革拉·毗列色来到他那里，却苦害他，没有帮助他。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 16:8–9; 列王纪下 18:15–16; 历代志下 12:9"> 虽然亚哈斯搜刮了耶和华的殿、王宫以及首领们的家，敬献给亚述王，但这没有为他带来帮助。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 1:5; 以西结书 21:13; 耶利米书 5:3"> 这亚哈斯王在危难的时候，却更加对耶和华不忠。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 25:14; 耶利米书 44:20–28; 哈巴谷书 1:11"> 他向那些击败他的大马士革人的神明献祭，说：“既然亚兰王的神在帮助亚兰人，我也向它们献祭，它们就会帮助我。”然而它们却使他和全以色列败亡。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="历代志下 29:7; 列王纪下 16:17–18; 历代志下 30:14"> 亚哈斯聚拢神殿中的器皿，把它们都拆毁了，并且关闭耶和华殿的门，然后在耶路撒冷的各个角落为自己建造祭坛。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 28:3"> 他在犹大各城都建造高坛，向别的神烧香，惹怒了耶和华他祖先的神。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王纪下 16:19–20; 历代志下 20:34; 历代志下 27:7–9"> 亚哈斯其余的事迹、从始至终一切的行为，看哪，都记在《犹大和以色列诸王纪》上。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 21:20; 历代志下 24:25; 箴言 10:7"> 亚哈斯与他的列祖长眠，葬在耶路撒冷城中，但没有送进以色列君王们的陵墓；他的儿子希西加接替他作王。</span>
</div>
</div>

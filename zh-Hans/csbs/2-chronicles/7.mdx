<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 18:38; 历代志上 21:26; 利未记 9:23–24"> 所罗门祷告完了，就有火从天上降下，烧尽了燔祭和其他祭物，耶和华的荣耀充满了殿宇。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 15:8; 历代志下 5:14; 出埃及记 24:17"> 祭司们不能进入耶和华的殿，因为耶和华的荣耀充满了耶和华的殿。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 5:13; 历代志下 20:21; 路加福音 1:50"> 当那火降下，耶和华的荣耀临到殿宇时，全体以色列人都看见了，就脸伏于地，在铺石地上俯伏敬拜，称谢耶和华：<br /><span className="pl pl-1">“他是美善的，他的慈爱永远长存！”</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪上 8:62–63"> 王和全体民众在耶和华面前献祭。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 10:22; 以西结书 45:17; 历代志下 30:24"> 所罗门王献上祭物，有两万两千头牛、十二万只羊。这样，王和全体民众为神的殿举行了奉献礼。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 5:12; 历代志上 15:16–21; 历代志下 7:3"> 祭司们都侍立在自己的岗位上，利未人拿着耶和华的乐器——这是大卫王制造的，为要在大卫藉着利未人赞美的时候，用以称谢耶和华：“他的慈爱永远长存！”祭司在对面吹号，全体以色列人都站着。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 8:64–66; 希伯来书 13:10–12; 历代志下 36:14"> 所罗门把耶和华殿前的院子中心分别为圣，在那里献上燔祭和平安祭的脂油，因为他所造的铜祭坛容不下所有燔祭和素祭以及脂油。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="创世记 15:18; 列王纪上 8:65; 尼希米记 8:13–18"> 那时，所罗门和全体以色列人，就是从哈马隘口直到埃及河来的极多的会众，一起守了七天的节期。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 23:36; 列王纪上 8:65; 约珥书 1:14"> 到第八天，他们举行严肃集会。他们已经举行了七天的祭坛奉献礼，又守了七天的节期。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 8:66; 诗篇 100:2; 申命记 12:18"> 七月二十三日，王遣散民众，让各人回自己的帐篷<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="帐篷——或译作“家”。">a</a></sup>。人们因耶和华向大卫和所罗门以及他子民以色列所施的恩惠，就满心欢喜快乐。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪上 9:1–9; 传道书 2:10–11; 历代志下 2:1"> 这样，所罗门建完了耶和华的殿和王宫，所罗门心中想要在耶和华的殿和王宫里做的一切，他都顺利完成了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 17:1; 列王纪上 9:2; 历代志下 7:16"> 夜间，耶和华向所罗门显现，对他说：<br />“我已经垂听了你的祷告，为自己选择了这地方作为献祭的殿宇。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 6:26–28; 申命记 11:17; 启示录 11:6"> 如果我使天闭塞不下雨，或吩咐蚱蜢吞吃这地，或把瘟疫降在我子民中间，</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米哀歌 3:40–41; 雅各书 4:9–10; 以赛亚书 55:6–7"> 这被称为我名下的子民就谦卑、祷告、寻求我的面、转离自己邪恶的道路，那么我必从天上垂听，赦免他们的罪，治好他们的土地。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 3:12; 历代志下 6:40; 尼希米记 1:6"> 现在我必眼睛睁开，侧耳听这地方的祷告。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 7:15; 历代志下 7:12; 历代志下 6:5–6"> 现在我已拣选这殿宇，把它分别为圣，使我的名永远在那里；我的眼、我的心也必终日在那里。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒迦利亚书 3:7; 以西结书 36:27; 列王纪上 11:38"> “至于你，如果你像你父亲大卫所行的那样行走在我面前，遵行我所吩咐你的一切，谨守我的律例和法规，</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 6:16; 耶利米书 33:20–21; 撒母耳记下 7:13–16"> 我就坚立你的王位，正如我与你父亲大卫立约所说的：‘你的子孙中，就不会断绝人管辖以色列。’</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="利未记 26:14; 申命记 28:15; 利未记 26:33–46"> “但如果你们转离，背弃我在你们面前赐下的律例和诫命，去服事别的神，向它们下拜，</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 17:20; 申命记 28:37; 耶利米书 24:9"> 我就把以色列人从我所赐给他们的土地上拔出来，并且把我为我名分别为圣的这殿宇从我面前丢弃，使它在万民中成为笑柄，被人讽刺。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 22:8–9; 耶利米书 16:10–12; 耶利米书 19:8"> 这曾经至高的殿宇，将使每一个经过它的人都震惊，说：‘耶和华为什么这样对待这地和这殿宇呢？’</span>
<span className="v" id="v22" data-v="22" data-xref="但以理书 9:12; 耶利米哀歌 2:16–17; 以西结书 14:23"> 人们会回答：‘因为以色列人离弃了耶和华他们祖先的神，就是把他们从埃及地领出来的那一位，去依附别的神，向它们下拜，服事它们，所以耶和华使这一切祸患临到了他们。’”</span>
</div>
</div>

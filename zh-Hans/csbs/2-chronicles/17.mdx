<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 15:24; 以弗所书 6:10; 马太福音 1:8"> 亚撒的儿子约沙法接替他作王。约沙法稳固势力，对抗以色列。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 15:8; 历代志下 11:5; 历代志下 11:11–12"> 他在犹大所有坚固的城中派驻军队，也在犹大地和他父亲亚撒所攻取的以法莲各城中派遣驻军。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="列王纪下 22:2; 以赛亚书 41:10; 提摩太后书 4:22"> 耶和华与约沙法同在，因为他走他先祖大卫先前的道路。他不寻求巴力，</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 12:28; 路加福音 1:6; 帖撒罗尼迦前书 2:12"> 只寻求他父亲的神，按照神的诫命行事，不效法以色列人的行为。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 18:1; 马太福音 6:33; 诗篇 127:1"> 所以耶和华坚立他手中的王权，全犹大都向约沙法进贡，他就拥有极大的财富和荣耀。</span>
<span className="v" id="v6" data-v="6" data-xref="何西阿书 14:9; 历代志下 15:17; 历代志下 20:33"> 他心中尊崇耶和华的道，而且还从犹大除掉了高坛和亚舍拉柱。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志下 35:3; 尼希米记 8:7–8; 传道书 12:9–10"> 约沙法在位第三年，他派遣大臣本亥伊勒、俄巴底亚、撒迦利亚、拿旦业、米该亚，到犹大各城去教导人。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 7:1–6; 历代志下 19:8; 玛拉基书 2:7"> 与他们同去的有利未人示玛雅、尼坦亚、希巴迪亚、亚撒晖、示米拉莫、约拿单、亚多尼雅、托比亚和驼巴多尼雅，都是利未人；与他们同去的还有祭司以利沙玛和约兰。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 5:46; 罗马书 3:2; 使徒行传 8:40"> 他们在犹大教导人，随身带着耶和华的律法书。他们巡行犹大各城，教导民众。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志下 14:14; 出埃及记 15:14–16; 箴言 16:7"> 犹大四围之地的列国都惧怕耶和华，不与约沙法争战。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 26:8; 历代志下 9:14; 撒母耳记下 8:2"> 一些非利士人给约沙法送来礼物和贡银，阿拉伯人也给他送来牲畜——公绵羊七千七百只、公山羊七千七百只。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="历代志下 8:2–6; 历代志下 14:6–7; 历代志下 32:5"> 约沙法渐渐变得非常强盛。他在犹大各地建造营寨和积货城，</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 27:25–31; 历代志下 26:10–15"> 在犹大各城还有许多工程<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有许多工程——或译作“储备大量物资”。">a</a></sup>。在耶路撒冷驻有英勇的战士，</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 11:1; 创世记 15:5; 民数记 1:18"> 按着他们的父家登记如下，属犹大支派的千夫长有：<br /><span className="pl pl-1">将领阿德纳，带领英勇的战士三十万；</span><br /></span>
<span className="v" id="v15" data-v="15"> <span className="pl pl-1">其次是将领约哈南，带领二十八万人；</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="士师记 5:9; 士师记 5:2; 历代志上 29:9"> <span className="pl pl-1">其次是泽克利的儿子亚玛斯雅，带领英勇的战士二十万，他是甘愿奉献给耶和华的人。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 14:8; 撒母耳记下 1:21–22"> <span className="pl pl-1">出自便雅悯支派的有：</span><br /><span className="pl pl-1">英勇的战士以利雅大，带领持弓执盾的人二十万；</span><br /></span>
<span className="v" id="v18" data-v="18"> <span className="pl pl-1">其次是约撒巴，带领武装队伍十八万。</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="历代志下 17:2; 历代志下 11:12; 历代志下 11:23"> 这些都是事奉王的，不包括王派驻在全犹大各堡垒城的军兵。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 83:5–8; 以赛亚书 16:6; 历代志下 32:1"> 后来摩押人、亚扪人，还有一些米乌尼人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一些米乌尼人——依据七十士译本；马索拉文本作“来自亚扪人的”；参《历代志下》26:7。">a</a></sup>，一同来攻击约沙法，与他争战。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 14:7; 撒母耳记上 23:29; 约书亚记 15:62"> 有人来向约沙法报告说：“有一支大军从海对面的以东<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以东——依据古拉丁文译本以及其他古抄本；马索拉文本作“亚兰”。">b</a></sup>来攻击你，看哪，他们已经在哈洗逊-塔玛尔。”哈洗逊-塔玛尔就是恩盖迪。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理书 9:3; 历代志下 19:3; 撒母耳记上 7:6"> 约沙法就害怕，于是定意寻求耶和华，向全犹大宣告禁食。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 50:15; 诗篇 60:10–12; 诗篇 69:35"> 犹大人聚集起来求助于耶和华，甚至从犹大的各城前来向耶和华求助。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪下 19:15–19; 历代志下 6:12–13; 历代志下 34:31"> 那时，约沙法站在犹大和耶路撒冷的会众当中，在耶和华殿的新院子前面，</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 4:39; 历代志上 29:11–12; 但以理书 4:17"> 说：<br />“我们祖先的神耶和华啊，你不是那一位在天上的神吗？你不是管辖列国列邦的主宰吗？你手中有能力和权柄，没有谁能在你面前站立得住。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 41:8; 雅各书 2:23; 诗篇 44:2"> 我们的神哪，你不是已经从你子民以色列面前赶出这地的居民，把这地永远赐给了你朋友亚伯拉罕的后裔吗？</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 6:10; 历代志下 2:4"> 他们住在其中，并在这里为你的名建造了圣所，说：</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 6:28–30; 历代志下 6:20; 列王纪上 8:33"> ‘如果有祸患临到我们，无论是审判的刀剑，还是瘟疫、饥荒，那时我们站在这殿宇中，在你的面前——因为你的名在这殿宇中——我们在患难中向你哀求，你必垂听，施行拯救。’</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命记 2:19; 申命记 2:4–5; 申命记 2:9"> “现在，你看亚扪、摩押和西珥山的居民——以色列人从埃及地上来的时候，你不允许以色列人侵犯他们，以色列人就从他们旁边绕过去，没有除灭他们——</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 83:3–12; 士师记 11:23–24; 耶利米书 18:20"> 你看他们竟然这样回报我们，要来把我们从你给我们继承的产业之地赶走。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 121:1–2; 诗篇 25:15; 诗篇 141:8"> 我们的神哪，难道你不审判他们吗？我们实在无力面对来攻击我们的这支大军，我们不知道该做什么，我们的眼睛只仰望你。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 10:1; 使徒行传 21:5; 申命记 29:10"> 全体犹大人，连同他们的家属——妻子、儿女，都站在耶和华面前。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 15:1; 历代志下 24:20; 使徒行传 10:31"> 那时，耶和华的灵在会众当中临到了雅哈希身上；雅哈希是撒迦利亚的儿子、比纳雅的孙子、耶伊列的曾孙、玛塔尼亚的玄孙，属于利未人亚萨的后裔。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 32:7–8; 申命记 31:6; 出埃及记 14:13–14"> 雅哈希就说：“全体犹大人、耶路撒冷的居民和约沙法王啊，你们留心听！耶和华对你们如此说：‘你们不要害怕，不要因这大军而丧胆，因为战争的胜败不在于你们，而在于神。</span>
<span className="v" id="v16" data-v="16"> 明天你们就下去迎战他们，看哪，他们正从洗斯的斜坡上来，你们会在耶鲁伊勒旷野对面的溪谷口遇见他们。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 14:13–14; 历代志下 15:2; 以赛亚书 41:10"> 这场仗不用你们打，你们只管站住，站好观看耶和华为你们施行拯救。’犹大和耶路撒冷的人哪，你们不要害怕，不要丧胆，明天就出去到他们面前，耶和华必与你们同在！”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 4:31; 历代志下 7:3; 创世记 24:26"> 约沙法脸伏于地，全体犹大人和耶路撒冷的居民都俯伏在耶和华面前，向耶和华下拜。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 15:16–22; 历代志上 16:42; 历代志上 16:5"> 哥辖子孙中、可拉子孙中的利未人都起来，以高亢的声音赞美耶和华以色列的神。</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="罗马书 8:31; 约翰福音 14:1; 约翰福音 11:40"> 第二天清晨，他们早早起来，出去到提克亚旷野去。他们出去的时候，约沙法站着说：“犹大和耶路撒冷的居民哪，请听我说！要相信耶和华你们的神，你们必坚立；要相信他的先知，你们必得胜！”</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 107:1; 诗篇 106:1; 历代志下 5:13"> 约沙法与民众商议后，就安排人向耶和华歌唱，赞美圣洁威严的那一位<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="赞美圣洁威严的那一位——或译作“穿着圣洁的装束献上赞美”。">c</a></sup>，走在武装士兵的前面说：<br /><span className="pl pl-1">“你们要称谢耶和华，</span><br /><span className="pl pl-1">他的慈爱永远长存！”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 14:20; 以赛亚书 19:2; 以西结书 38:21"> 当他们开始欢呼赞美的时候，耶和华设下伏兵攻击那些入侵犹大的亚扪、摩押和西珥山的居民，他们就被打败了。</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 7:22; 撒母耳记上 14:20; 以西结书 35:2–3"> 亚扪人和摩押人起来攻击西珥山的居民，要把他们灭绝净尽；他们灭绝了西珥的居民之后，又极力<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="极力——原文直译“帮助”。">d</a></sup>自相残杀。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 37:36; 诗篇 110:6; 历代志上 5:22"> 犹大人来到旷野的守望台，向敌军观望，看哪，他们尸横遍地，没有一个幸存者。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 30:19–20; 列王纪下 7:9–16; 民数记 31:15"> 约沙法和他的子民就来掠取财物，那里有大量的装备、衣服<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="衣服——依据一些古抄本；马索拉文本作“尸首”。">e</a></sup>、珍贵物品。他们收拾起来，直到装不下为止。由于财物很多，他们连续掠取了三天。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 17:15; 创世记 32:20; 历代志下 5:9"> 第四天，他们聚集到比拉卡平原，他们就在那里颂赞耶和华。因此他们给那地方起名为比拉卡平原，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="尼希米记 12:43; 希伯来书 6:20; 诗篇 30:1"> 犹大和耶路撒冷的人都回去了，约沙法率领他们欢欢喜喜地回耶路撒冷去，他们因耶和华使他们胜过仇敌而欢喜。</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 14:2–3; 诗篇 57:8; 诗篇 92:3"> 他们伴着里拉琴、竖琴、号筒回到耶路撒冷，进入耶和华的殿。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="历代志下 17:10; 列王纪下 7:6; 出埃及记 23:27"> 当那地的列国听说耶和华战败以色列的仇敌时，他们就惧怕神。</span>
<span className="v" id="v30" data-v="30" data-xref="历代志下 15:15; 历代志下 14:6–7; 撒母耳记下 7:1"> 这样，约沙法国中太平，他的神使他四围安定下来。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪上 22:41–44"> 约沙法作了犹大的王，他作王的时候三十五岁，在耶路撒冷统治了二十五年。他的母亲名叫阿苏巴，是示利希的女儿。</span>
<span className="v" id="v32" data-v="32" data-xref="历代志下 14:2–5; 列王纪上 15:11; 历代志下 14:11–13"> 他走他父亲亚撒的道路，没有偏离；他做耶和华眼中看为正的事。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志下 17:6; 历代志下 19:3; 历代志下 12:14"> 只是高坛还没有除掉，百姓仍旧没有立定心志归向他们祖先的神。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="列王纪上 16:1; 历代志下 19:2; 列王纪上 16:7"> 约沙法其余的事迹，从始至终，看哪，都记在《以色列诸王纪》上哈纳尼的儿子耶户的纪事中。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="列王纪上 22:48–49; 列王纪下 1:2–16"> 后来犹大王约沙法与那做尽坏事的以色列王亚哈谢结盟。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 10:22; 历代志下 9:21; 列王纪上 9:26"> 他们二人联合建造出海的塔尔施船队，在以旬迦别造船。</span>
<span className="v" id="v37" data-v="37" data-xref="箴言 13:20; 历代志下 19:2; 历代志下 9:21"> 那时玛利沙人德达瓦的儿子以利以谢向约沙法预言说：“因为你与亚哈谢结盟，耶和华必拆毁你所建造的。”后来那些船果然被毁坏，不能开往塔尔施去了。</span>
</div>
</div>

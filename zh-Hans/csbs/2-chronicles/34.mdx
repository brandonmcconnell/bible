<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="2CH" data-book-slug="2-chronicles" data-book-name="历代志下" data-chapter="34" data-verses="33">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="西番雅书 1:1; 耶利米书 1:2; 历代志下 33:25"> 约西亚作王的时候八岁，在耶路撒冷统治了三十一年。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 29:2; 约书亚记 1:7; 列王纪下 22:2"> 他做耶和华眼中看为正的事，走他先祖大卫的道路，不偏离左右。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="历代志下 33:22; 历代志下 15:2; 箴言 8:17"> 他在位第八年，他还年少，就开始寻求他先祖大卫的神。到了第十二年，他开始洁净犹大和耶路撒冷，除掉高坛、亚舍拉柱、雕像和铸像。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 32:20; 利未记 26:30; 列王纪下 23:4–6"> 人们在王面前拆毁巴力的祭坛，也砍倒了那些祭坛上高高的香坛，把亚舍拉柱、雕像和铸像打碎并磨碎，撒在向这些偶像献祭之人的坟墓上，</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 13:2; 耶利米书 3:10; 民数记 35:33"> 还把那些祭司的骸骨烧在他们的祭坛上。这样，他洁净了犹大和耶路撒冷。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 13:20–21; 以赛亚书 7:25; 历代志下 30:1"> 他也在玛拿西、以法莲、西缅直到拿弗他利的各城，以及它们四围的荒废之处，</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 31:1; 申命记 9:21; 历代志下 34:1"> 在以色列全地拆毁祭坛，打碎、磨碎亚舍拉柱和雕像，砍倒所有的香坛，然后回耶路撒冷去了。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 8:16; 历代志上 18:15; 耶利米书 29:25"> 约西亚在位第十八年，他洁净了那地和殿宇以后，派遣亚萨利雅的儿子沙番、城主玛西雅，以及约哈斯的儿子史官约亚，去修缮他的神耶和华的殿。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="历代志下 30:18; 历代志下 30:10; 历代志下 35:8"> 于是他们来到大祭司希勒加那里，把那些奉献到神殿的银子交给他，这银子是守门的利未人从玛拿西和以法莲手中，从以色列所有的余剩之民，从全犹大和便雅悯，从耶路撒冷的居民所接收的。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 12:11–12; 以斯拉记 3:7; 列王纪下 22:5–6"> 他们把银子交托在那些监管耶和华殿中工作的人手中，这些人再把银子支付给那些做这工作、在耶和华殿中施工的人，去修复、修缮殿宇。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 33:4–7; 历代志下 33:22"> 他们把银子交给木匠和建筑工，去购买凿好的料石和做连接件的木材，又为犹大列王任由其毁坏的殿宇架上木梁。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王纪下 12:15; 历代志上 23:5; 列王纪下 22:7"> 这些人在工作上行事诚信。利未人米拉利的子孙雅哈和俄巴底亚，以及哥辖的子孙撒迦利亚和米书兰被委任来作监管，还有那些利未人，全都是精通乐器的；</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 4:10; 历代志下 2:18; 耶利米书 8:8"> 他们也管理搬运工，监管做各样工作的所有工人。利未人中也有作书记、官长和门卫的。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="利未记 8:36; 诗篇 1:2; 利未记 10:11"> 当他们把奉献到耶和华殿的银子拿出来时，祭司希勒加发现了藉着摩西所传的耶和华的律法书。</span>
<span className="v" id="v15" data-v="15"> 于是希勒加告诉书记沙番说：“我在耶和华殿中发现了律法书！”希勒加就把书卷交给沙番。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪下 22:9–10; 耶利米书 36:20–21"> 沙番把书卷拿到王那里，回禀王说：“所有交托在你臣仆们手中的事，他们都在办理。</span>
<span className="v" id="v17" data-v="17"> 他们把耶和华殿中的银子倒出来，交在监管的人和工作的人手中了。”</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 119:46; 耶利米书 36:20–21; 申命记 17:19"> 书记沙番接着告诉王说：“祭司希勒加交给我一个书卷。”沙番就在王面前朗读它。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约书亚记 7:6; 申命记 28:3–68; 列王纪下 22:19"> 王听了律法书上的话语，就撕裂衣服。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 22:12; 耶利米书 26:24; 耶利米书 40:9"> 王吩咐希勒加、沙番的儿子亚希甘、米迦的儿子阿布顿、书记沙番，以及王的仆人亚撒雅，说：</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 21:2; 以西结书 14:1–11; 历代志下 28:6"> “关于所发现这书卷上的话语，你们去，为我、为以色列和犹大的余剩者求问耶和华。因为我们的祖先没有谨守耶和华的话语，没有去遵行这书卷上所记的一切，所以耶和华向我们倾泻极大的怒火。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 2:36; 出埃及记 15:20; 列王纪下 22:14"> 于是希勒加和王所派的那些人去见女先知胡勒达，她住在耶路撒冷第二区，是掌管礼服的沙勒姆的妻子；沙勒姆是哈斯拉的孙子、提克瓦的儿子。他们请教胡勒达，</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 37:7–10; 耶利米书 21:3–7; 列王纪下 22:15–20"> 她就对他们说：<br />“以色列的神耶和华如此说：你们告诉那派你们来见我的人，</span>
<span className="v" id="v24" data-v="24" data-xref="历代志下 36:14–20; 约书亚记 23:16; 申命记 28:15–68"> ‘耶和华如此说：看哪，我要使祸患，就是在犹大王面前读的那书卷上所写的一切诅咒，临到这地方和这里的居民身上；</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 7:20; 马可福音 9:43–48; 那鸿书 1:6"> 因为他们离弃我，向别的神烧香，以他们手所造的一切惹怒了我。我的怒火要倾泻在这地方，绝不熄灭。’</span>
<span className="v" id="v26" data-v="26" data-xref="历代志下 34:23; 历代志下 34:21"> 不过，你们要对那派你们来求问耶和华的犹大王如此说：‘关于你所听见的那些话语，以色列的神耶和华如此说：</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 32:26; 以西结书 9:4; 诗篇 34:18"> 你既然听了针对这地方和它居民的那些话语，就心里柔软，在神面前谦卑下来；你在我面前谦卑下来，撕裂衣服、在我面前哀哭，因此我已经垂听了你。这是耶和华的宣告。</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 39:8; 诗篇 37:37; 列王纪上 21:29"> 看哪，我必使你归到你列祖那里，你将平平安安归到你的坟墓里，你不会亲眼看到我要降在这地方和其上居民的一切灾祸。’”<br />他们就回去禀告王。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王纪下 23:1–3; 历代志下 30:2; 马可福音 14:8"> 王派人去，招聚了犹大和耶路撒冷所有的长老。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 24:7; 列王纪下 23:2; 历代志下 34:15"> 然后，王与犹大众人、耶路撒冷的居民、祭司、利未人、全体民众，无论尊卑，都上耶和华的殿去。王就把耶和华殿中发现的约书上一切话语，宣读给他们听。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志下 23:16; 列王纪下 23:3; 列王纪下 11:14"> 王站在自己的位置，在耶和华面前立约，要全心、全灵跟从耶和华，谨守他的诫命、法度和律例，遵行这书卷上所记的圣约之言。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="历代志下 30:12; 耶利米书 3:10; 历代志下 14:4"> 他也让所有在耶路撒冷和便雅悯的人都归入这约。于是耶路撒冷的居民就遵行神的约，他们祖先之神的约。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="历代志下 34:3–7; 约书亚记 24:31; 列王纪下 23:4–20"> 约西亚在以色列人的全境除掉了一切可憎之物，使所有在以色列的人都服事耶和华他们的神。约西亚在世的日子，他们都跟随耶和华他们祖先的神，没有偏离。</span>
</div>
</div>

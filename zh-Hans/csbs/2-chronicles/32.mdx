<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="2CH" data-book-slug="2-chronicles" data-book-name="历代志下" data-chapter="32" data-verses="33">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 18:13–37; 列王纪下 17:6; 历代志下 20:1–2"> 在希西加这些虔诚的行为之后，亚述王西纳基立来入侵犹大，对着那些坚固的城扎营，想要攻破占据它们。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 9:53; 路加福音 9:51; 列王纪下 12:17"> 希西加见西纳基立前来，定意要攻打耶路撒冷，</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 24:6; 箴言 20:18; 箴言 15:22"> 就与他的首领、勇士们商议，要把城外那些水泉堵上，他们都帮助他。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 32:30; 列王纪下 18:9; 列王纪上 19:21"> 许多民众聚集起来，堵上了所有的泉源和从那地穿过的溪流，他们说：“何必让亚述王来找到丰富的水源呢？”</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 25:23; 列王纪上 9:24; 列王纪下 25:4"> 希西加坚定心志，重建所有被拆毁的城墙，加高城楼，又在城外另建一道墙，加固大卫城中的梯垒，并制造大量的兵器和盾牌。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 40:2; 历代志下 30:22; 尼希米记 8:16"> 他又设立军官指挥民众，把他们聚集到他所在的城门口广场上。他鼓励他们说：</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 6:16; 罗马书 8:31; 以弗所书 6:10"> “你们要坚强、勇敢！不要害怕，不要因亚述王和与他一起的整个大军而丧胆，因为与我们一起的比与他们一起的更强大。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 17:5; 历代志下 20:17; 以赛亚书 41:10"> 与他一起的是血肉的膀臂，与我们一起的是耶和华我们的神，他必帮助我们，为我们作战。”民众因犹大王希西加的话而受到鼓舞。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王纪下 18:17; 约书亚记 10:31; 以赛亚书 36:2"> 此后，亚述王西纳基立带着他的全军攻打拉吉的时候，派遣他的臣仆们去耶路撒冷，对犹大王希西加和耶路撒冷的所有犹大人说：</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 18:19; 以赛亚书 36:4"> “亚述王西纳基立如此说：你们困守耶路撒冷，到底是依靠什么呢？</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 27:43; 诗篇 11:1–3; 以赛亚书 36:18"> 希西加说‘我们的神耶和华会解救我们脱离亚述王的手’，这不是在误导你们吗？他是要你们因饥饿和干渴而死。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 31:1; 申命记 12:13–14; 申命记 12:26–27"> 不就是他希西加除掉了耶和华的高坛和祭坛吗？他还吩咐犹大和耶路撒冷的人，说‘你们只可在一个祭坛前敬拜，在上面烧香’。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王纪下 18:33–35; 以赛亚书 44:8–10; 但以理书 4:30"> “难道你们不知道，我和我的列祖对地上各民做了什么？难道地上列国的神真能解救他们的国土脱离我的手吗？</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 10:11–12; 出埃及记 15:9–11; 以赛亚书 42:8"> 我祖先灭绝的那些国家所有的神，哪一位能解救自己的子民脱离我的手呢？难道你们的神能解救你们脱离我的手吗？</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 5:2; 但以理书 3:15; 以赛亚书 36:18"> 现在，不要让希西加欺哄你们了，不要让他这样误导你们。你们不要相信他，因为列国列邦所有的神都不能解救自己的子民脱离我的手和我列祖的手，何况你们的神，更不能解救你们脱离我的手！”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="诗篇 73:9; 约翰福音 15:21; 约伯记 15:25–26"> 西纳基立的臣仆们还说了一些话攻击耶和华神和他的仆人希西加。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 37:14; 列王纪下 19:12; 以赛亚书 37:28–29"> 西纳基立也写信辱骂耶和华以色列的神，攻击他说：<br />“正如地上列国的神不能解救自己的子民脱离我的手，同样，希西加的神也不能解救他的子民脱离我的手。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 17:10; 列王纪下 18:26–28; 撒母耳记上 17:26"> 他们用犹大话向城墙上的耶路撒冷民众大声呼喊，要恐吓他们，使他们惶恐，好攻取那城。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 19:18; 以赛亚书 2:8; 耶利米书 32:30"> 他们谈论耶路撒冷的神，像是谈论人手所造的地上万民的神明。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="诗篇 91:14–15; 以赛亚书 37:14–20; 历代志下 14:11"> 希西加王和亚摩斯的儿子先知以赛亚为此祷告，向天呼求。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 37:36–38; 诗篇 76:5; 诗篇 18:50"> 耶和华就派遣一位天使，除灭了亚述王营地中所有的勇士、首领和将领。于是亚述王满脸耻辱地撤回了本土。当他进入自己神明的庙宇时，他的几个亲生儿子在那里用刀把他杀了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 31:4–5; 诗篇 18:48–50; 帖撒罗尼迦后书 3:5"> 这样，耶和华拯救希西加和耶路撒冷的居民脱离了亚述王西纳基立的手和所有敌人的手，使他们四围安定<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="使他们四围安定——依据七十士译本；马索拉文本作“四围带领他们”。">a</a></sup>。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 17:5; 马太福音 2:11; 历代志下 1:1"> 有许多人把供物带到耶路撒冷献给耶和华，也把珍宝献给犹大王希西加。从此以后，希西加在列国眼中显为尊崇。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 38:1–8; 列王纪下 20:1–11; 以赛亚书 38:21–22"> 在那些日子，希西加患病快要死了，他向耶和华祷告，耶和华应允了他，并赐给他一个预兆。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 24:18; 历代志下 26:16; 历代志下 32:31"> 希西加却没有照着所蒙的恩惠回应耶和华，因为他心里高傲。于是耶和华的震怒临到他，也临到犹大和耶路撒冷。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 26:18–19; 历代志下 34:27–28; 历代志下 33:12"> 希西加知道<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="知道——辅助词语。">b</a></sup>自己心里的高傲，他与耶路撒冷的居民就谦卑下来，所以耶和华的震怒没有在希西加年间临到他们身上。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="历代志上 27:25–31; 历代志下 1:12; 箴言 10:22"> 希西加拥有极大的财富和荣耀，他为自己的金银、宝石、香料、盾牌和各样贵重物品建造库房；</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 7:8; 历代志下 26:10; 列王纪上 4:26"> 为收获的五谷、新酒、新油建造仓房；也为各类牲畜修建厩棚，为羊群修建羊圈。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 29:12; 箴言 10:22; 撒母耳记上 2:7"> 他为自己建造了城镇，他还获得大量的羊群和牛群，因为神赐给他极多的财物。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="列王纪上 1:33; 以赛亚书 22:9–11; 诗篇 1:1–3"> 这希西加截住基训上游的水源，把水往下引到大卫城的西边。希西加所做的一切事都顺利。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 8:2; 箴言 17:3; 创世记 22:1"> 只是当巴比伦众首领派遣使者来查问这地发生的奇事时，神离开他，为要试验他，好知道他心里的一切。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 36:1–22; 列王纪下 18:1–20; 历代志下 31:20–21"> 希西加其余的事迹和他对神的忠诚，看哪，都记在亚摩斯的儿子先知以赛亚的《异象书》上，以及《犹大和以色列诸王纪》上。</span>
<span className="v" id="v33" data-v="33" data-xref="箴言 10:7; 列王纪上 1:21; 历代志下 16:14"> 希西加与他的列祖长眠，人们把他葬在大卫子孙陵墓的山坡上。他死的时候，全体犹大人和耶路撒冷的居民都向他致敬。他的儿子玛拿西接替他作王。</span>
</div>
</div>

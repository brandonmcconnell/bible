<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 12:16; 列王纪上 15:1–8"> 耶罗波安王在位第十八年，亚比雅作犹大的王，</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 11:20; 列王纪上 15:6–7; 士师记 19:16"> 在耶路撒冷统治了三年。他的母亲名叫米该娅，是基比亚人乌列的女儿。<br />亚比雅和耶罗波安之间常有争战。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 26:12–13; 历代志上 21:5; 撒母耳记上 17:1–3"> 亚比雅统率一支军队出战，有四十万精兵，都是善战的勇士；耶罗波安也摆阵迎战，有八十万精兵，都是英勇的战士。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 18:22; 历代志下 15:2; 创世记 10:18"> 亚比雅站在以法莲山地的策玛莲山上，说：“耶罗波安和全体以色列人哪，请听我说！</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 18:19; 利未记 2:13; 马可福音 9:49–50"> 难道你们不知道吗？以色列的神耶和华藉着盐约，把以色列的王权永远赐给了大卫和他的子孙。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 11:26; 列王纪上 12:20; 历代志下 10:19"> 尼八之子耶罗波安原是大卫的儿子所罗门的臣仆，竟然起来背叛他的主人。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 9:4; 历代志下 12:13; 使徒行传 17:5"> 一些无赖和卑劣之徒聚集起来跟随他，对抗所罗门的儿子罗波安，那时罗波安年少心软，不能抗衡他们。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪上 12:28; 历代志下 11:15; 路加福音 19:14"> “现在你们又说要对抗大卫子孙所掌管的耶和华的王国！你们人多势众，并有耶罗波安为你们铸造当作神的那些金牛犊与你们在一起。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 11:14–15; 耶利米书 2:11; 出埃及记 29:35"> 你们不是驱逐了耶和华的祭司，驱逐了亚伦子孙和利未人，像外邦人那样为自己立了祭司吗？任何人带着一头公牛和七只公绵羊来奉献自己，他就可以作那些虚无之神的祭司。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及记 19:5–6; 历代志下 11:16–17; 撒迦利亚书 13:9"> “至于我们，耶和华是我们的神，我们没有离弃他。事奉耶和华的祭司是亚伦的子孙，利未人也在尽职；</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 2:4; 利未记 24:2–9; 出埃及记 29:38"> 每天早晨和傍晚都向耶和华烧献燔祭和芬芳香；在洁净的桌子上有陈设饼；每日傍晚点燃金灯台的灯盏。我们一直遵守我们神耶和华的吩咐，你们却离弃了他。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 5:39; 罗马书 8:31; 民数记 10:8–9"> 看哪，神与我们同在，率领我们，他的祭司要对你们吹响进攻的号筒。以色列子孙哪，不要与耶和华你们祖先的神争战，因为你们不会得胜。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约书亚记 8:4; 约书亚记 8:9; 箴言 21:30"> 那时，耶罗波安派了伏兵绕到他们后面，这样犹大前有以色列军，后有伏兵。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 14:11; 出埃及记 14:10; 约书亚记 8:20"> 犹大人转身一看，自己腹背受敌，他们就呼求耶和华，祭司们也吹响号筒。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 14:12; 约书亚记 11:8; 诗篇 118:4–7"> 于是犹大人呼喊。当犹大人呼喊的时候，神就在亚比雅和犹大人面前打败耶罗波安和全体以色列人。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 16:8; 士师记 11:21; 约书亚记 10:12"> 以色列人在犹大人面前逃跑，神把他们交在犹大人手中。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 28:6; 历代志下 13:3; 历代志下 13:12"> 亚比雅和他的军兵击败了以色列人，是一场极大的杀戮，以色列有五十万精兵被杀倒下。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 5:20; 历代志下 14:11; 那鸿书 1:7"> 那时，以色列人就被制伏了。犹大人获胜是因为依靠耶和华他们祖先的神。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="历代志下 15:8; 约书亚记 15:9; 约书亚记 10:39"> 亚比雅追击耶罗波安，攻取了他的几座城，就是伯特利和附属的村镇，耶沙纳和附属的村镇，以弗仑和附属的村镇。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 25:38; 列王纪上 14:20; 使徒行传 12:23"> 亚比雅年间，耶罗波安不能再维持他的势力。后来耶和华打击他，他就死了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="士师记 9:5; 撒母耳记下 5:12–13; 士师记 10:4"> 亚比雅却强盛起来；他娶了十四个妃嫔，生了二十二个儿子，十六个女儿。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 9:29; 历代志下 12:15; 历代志下 24:27"> 亚比雅其余的事迹和他的言行，都记在《先知易多评传》上。</span>
</div>
</div>

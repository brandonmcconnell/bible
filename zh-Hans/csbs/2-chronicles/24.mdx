<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="2CH" data-book-slug="2-chronicles" data-book-name="历代志下" data-chapter="24" data-verses="27">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 3:11; 列王纪下 11:21–15"> 约阿施作王的时候七岁，在耶路撒冷统治了四十年。他的母亲名叫慈比娅，是比尔-谢巴人。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 26:4–5; 历代志下 25:2; 历代志下 24:17–22"> 祭司耶赫亚达在世的日子，约阿施做耶和华眼中看为正的事。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 24:15; 马太福音 19:4–8; 创世记 4:19"> 耶赫亚达为他娶了两个妻子，生儿养女。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 后来约阿施心中有意要重修耶和华的殿，</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 12:4–7; 历代志下 34:8–9; 历代志下 29:3"> 他招聚祭司和利未人，对他们说：“你们要出去到犹大的各城，向全体以色列人募集银子，用来每年修缮你们神的殿。你们要抓紧办理这事。”<br />利未人却没有抓紧办理。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 30:12–16; 民数记 1:50; 民数记 17:7–8"> 于是王召来祭司长耶赫亚达，问他：“你为什么不督促利未人，把耶和华的仆人摩西和以色列会众为见证会幕所定的税捐，从犹大和耶路撒冷带上来呢？”</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 21:17; 历代志下 28:22–24; 列王纪下 12:4"> 那时，恶妇娅塔利雅的儿子们已经毁坏了神的殿，还把耶和华殿中一切圣物都用于供奉巴力。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="马可福音 12:41; 列王纪下 12:8–9"> 王吩咐，他们就做了一个箱柜，放在耶和华殿门外面，</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 24:6; 马太福音 17:24–27"> 然后他们在犹大和耶路撒冷发出通告，要求把神的仆人摩西在旷野向以色列人所定的税捐带给耶和华。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 2:45–47; 哥林多后书 9:7; 历代志上 29:9"> 所有首领和全体民众都欢欢喜喜带来捐项，投入奉献箱，直到满了。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 12:10–12; 哥林多前书 16:2"> 每当奉献箱经由利未人抬到王所派的监督那里，他们看到银子很多，王的书记和祭司长的专员就来把奉献箱倒空，然后抬回原处。他们每天都是如此行事，这样就收聚了大量的银子。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 5:15; 历代志下 34:9–11"> 王和耶赫亚达把银子交托给耶和华殿中负责服事工作的人，他们就雇用石匠和木匠重修耶和华的殿，还雇用铁匠和铜匠修缮耶和华的殿。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="尼希米记 4:7; 马可福音 13:1–2; 哈该书 2:3"> 于是做工的人开工，修复工作在他们手中顺利进行。他们照着原来的规格恢复神的殿，并且加固它。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 28:2–29; 箴言 27:22; 列王纪下 12:13–14"> 他们完工后，就把剩余的银子带到王和耶赫亚达面前，用于制作耶和华殿中的器皿，就是供奉和献祭用的器皿，以及盘子和金银的器皿。耶赫亚达在世的日子，他们在耶和华殿中不间断地献上燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="创世记 47:9; 历代志上 23:1; 诗篇 90:10"> 耶赫亚达年迈，寿数满足而死，他死的时候一百三十岁。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 6:10; 历代志下 31:20; 尼希米记 13:14"> 人们把他葬在大卫城，与诸王在一起，因为他在以色列为神和神的殿做了美善的事。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="申命记 31:27; 箴言 26:28; 使徒行传 20:29–30"> 耶赫亚达死后，犹大的首领们来朝拜约阿施王，那时王听从他们。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 22:20; 历代志下 19:2; 以弗所书 5:6"> 他们离弃了他们祖先的神耶和华的殿，去服事亚舍拉和那些偶像。因他们的这罪，震怒就临到了犹大和耶路撒冷。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 42:23; 路加福音 20:9–15; 马太福音 13:9"> 耶和华派遣众先知到他们那里，要使他们回转归向耶和华。这些先知警诫他们，他们却不肯听从。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数记 14:41; 耶利米书 5:25; 历代志下 15:1–2"> 那时神的灵临到祭司耶赫亚达的儿子撒迦利亚身上<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="临到……身上——或译作“覆盖”。">a</a></sup>，他站在民众的上方，对他们说：“神如此说：‘你们为什么违背耶和华的诫命，以致不能亨通呢？你们既然离弃了耶和华，他也必离弃你们。’”</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 7:58–59; 尼希米记 9:26; 耶利米书 38:4–6"> 他们就密谋对付他，照着王的命令在耶和华殿的院子里用石头砸死了他。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 9:5; 路加福音 11:51; 启示录 6:9–11"> 约阿施王不记念撒迦利亚的父亲耶赫亚达向他所施的恩慈，杀了他的儿子。撒迦利亚临死的时候说：“愿耶和华察看，愿他追讨！”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪下 12:17–18; 申命记 32:35; 列王纪上 20:22"> 到了年初，亚兰的军队上来攻击约阿施。他们来到犹大和耶路撒冷，杀了民中的众首领，并把所有的战利品都送到大马士革王那里。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志下 22:8; 利未记 26:37; 利未记 26:8"> 亚兰的军队虽然只来了一小队人，耶和华却把庞大的军队交在他们手中，因为犹大人离弃了耶和华他们祖先的神。这样，亚兰人对约阿施施行了审判。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="历代志下 24:21–22; 历代志下 28:27; 历代志下 21:18–20"> 亚兰人离开的时候，留下了受重伤的约阿施，他的臣仆们就密谋反叛，把他杀死在床上，这是因为他流了祭司耶赫亚达儿子的血。约阿施死后，人们把他葬在大卫城，但没有葬在君王们的陵墓里。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王纪下 12:21"> 那密谋反叛他的人是亚扪女子示米押的儿子撒巴德和摩押女子示米利的儿子约撒巴。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 16:11; 历代志下 13:22; 历代志下 24:12"> 有关约阿施的儿子们，以及针对他的许多默示，还有他重修神的殿的事情，看哪，都记在《列王评传》上。他的儿子亚玛谢接替他作王。</span>
</div>
</div>

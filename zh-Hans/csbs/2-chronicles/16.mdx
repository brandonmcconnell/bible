<span className="v" id="v1" data-v="1" data-xref="历代志下 15:9; 历代志下 15:5; 列王纪上 12:27"> 亚撒在位第三十六年，以色列王巴沙上来攻击犹大，修筑了拉玛，不让人与犹大王亚撒往来。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 12:18; 历代志下 28:21; 列王纪下 18:15"> 于是亚撒从耶和华殿的库房和王宫里取出金银，送给住在大马士革的亚兰王本哈达，说：</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 15:4; 历代志下 18:3; 哥林多后书 6:16"> “你我之间立约吧，就像我父亲与你父亲之间那样。看哪，我把金银送给你，请你废除你与以色列王巴沙所立的约，好让他从我这里撤离。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士师记 20:1; 历代志下 17:12; 列王纪上 15:20"> 本哈达听取了亚撒王，就派遣他的将领们到以色列的城镇，攻占了伊永、但、亚贝勒-玛音，以及拿弗他利所有的积货城。</span>
<span className="v" id="v5" data-v="5"> 巴沙听说了，就停止修筑拉玛，终止了他的工程。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 21:17; 约书亚记 15:38; 以赛亚书 10:29"> 于是亚撒王带领全体犹大人，运走巴沙用于修筑拉玛的石头和木材，用来修筑迦巴和米斯巴。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志下 19:2; 列王纪上 16:1; 诗篇 146:3–6"> 那时，先见哈纳尼来见犹大王亚撒，对他说：“由于你依靠亚兰王，没有依靠耶和华你的神，因此亚兰王的军队逃脱了你的手。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 12:3; 历代志下 13:16; 历代志下 16:7"> 难道当初库实人和利比亚人不是有强大的军队，极多的战车和马兵吗？但你依靠耶和华，他就把他们交在了你手中。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 3:12; 箴言 15:3; 耶利米书 16:17"> 要知道，耶和华的眼目遍察全地，要彰显大能帮助那些全心归向他的人。你在这事上做得很愚蠢！从今以后，必有争战伴随你。”</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 18:26; 使徒行传 16:23–24; 撒母耳记下 12:13"> 亚撒就对先见动怒，把他投入牢房，因亚撒为这话对他很愤怒。同时亚撒也逼迫了一些人。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="历代志下 12:15; 历代志下 9:29; 历代志下 35:27"> 亚撒从始至终的事迹，看哪，都记在《犹大和以色列诸王纪》上。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 17:5; 历代志下 28:22; 历代志上 10:14"> 亚撒在位第三十九年，他的双脚患了病，病情越来越严重。但他即使在病中也没有寻求耶和华，只求问医生。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 15:24"> 亚撒与他的列祖长眠，死于他在位第四十一年。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 50:2; 历代志下 21:19; 耶利米书 34:5"> 人们把他葬在大卫城中他为自己开凿的墓穴里，安放在装满了用香膏工艺调制的各种香料的棺架上，并且为哀悼<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="哀悼——辅助词语。">a</a></sup>他燃起了极大的篝火。</span>
</div>

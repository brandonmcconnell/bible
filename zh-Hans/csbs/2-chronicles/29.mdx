<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 18:1–3; 历代志上 3:13; 历代志下 26:5"> 希西加二十五岁作王，在耶路撒冷统治了二十九年。他的母亲名叫娅比雅，是撒迦利亚的女儿。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 34:2; 历代志下 28:1"> 他效法他先祖大卫所做的一切，做耶和华眼中看为正的事。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="历代志下 28:24; 历代志下 29:7; 马太福音 6:33"> 他作王的第一年一月，他打开了耶和华殿的门，并且修缮它们。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 19:2; 尼希米记 3:29; 历代志下 32:6"> 然后他召来祭司和利未人，把他们聚集在东边的广场上，</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 35:6; 哥林多前书 3:16–17; 历代志下 34:3–8"> 对他们说：“利未人哪，请听我说！现在你们要使自己分别为圣，然后把你们祖先的神耶和华的殿也分别为圣，把污秽之物从圣所中除去。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 8:16; 耶利米书 2:27; 但以理书 9:16"> 我们的祖先对神不忠，做我们的神耶和华眼中看为恶的事。他们离弃他，转脸不顾耶和华的居所，背对着它。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 28:24; 利未记 24:2–8; 历代志下 29:3"> 他们还关上门廊的门，熄灭灯盏，不在圣所向以色列的神烧香、献燔祭。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 25:9; 耶利米书 25:18; 耶利米书 29:18"> 所以耶和华的震怒临到犹大和耶路撒冷，使它们的遭遇<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="遭遇——辅助词语。">a</a></sup>令人战兢、令人惊骇、被嗤笑，正如你们亲眼所见的那样。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 28:17; 历代志下 28:5–8; 耶利米哀歌 5:7"> 看哪，我们的祖先倒在刀下，我们的儿女和妻子也因此被掳去。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 50:5; 历代志下 23:16; 以斯拉记 10:3"> 现在我心中有意要与以色列的神耶和华立约，好使他从我们身上收回他猛烈的怒气。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 10:8; 加拉太书 6:7–8; 民数记 8:6–14"> 我的子民哪，现在你们不要懈怠，因为耶和华拣选了你们站在他面前事奉他，给他作侍从、作烧香的人。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="民数记 3:19–20; 历代志上 15:5–7; 民数记 4:2–20"> 于是利未人就起来：<br /><span className="pl pl-1">哥辖的子孙中有亚玛赛的儿子玛哈、</span><br /><span className="pl pl-1">亚撒利雅的儿子约珥，</span><br /><span className="pl pl-1">米拉利的子孙中有阿伯迪的儿子基士、</span><br /><span className="pl pl-1">耶哈利勒的儿子亚撒利雅，</span><br /><span className="pl pl-1">革顺人中有津玛的儿子约亚、</span><br /><span className="pl pl-1">约亚的儿子伊甸，</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 6:39; 历代志上 15:8; 历代志上 15:17"> <span className="pl pl-1">以利撒番的子孙中有示姆利和耶伊列，</span><br /><span className="pl pl-1">亚萨的子孙中有撒迦利亚和玛塔尼亚，</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="历代志上 6:33; 历代志上 25:1; 历代志上 25:6"> <span className="pl pl-1">希幔的子孙中有耶希业和示每，</span><br /><span className="pl pl-1">耶杜顿的子孙中有示玛雅和乌基业；</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="历代志下 30:12; 历代志上 23:28; 历代志下 29:5"> 他们聚集他们的兄弟，都使自己分别为圣了，然后照着王的命令，按照耶和华的吩咐，进去洁净耶和华的殿。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志下 15:16; 马太福音 21:12–13; 马太福音 23:27"> 祭司们进去洁净耶和华的殿，把耶和华圣殿中发现的一切不洁之物都搬到耶和华殿的院子里，然后利未人接过去，带到城外的汲沦溪谷那里。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 12:2–8; 历代志下 3:4; 列王纪上 6:3"> 他们一月一日开始分别为圣的工作，在当月的八日进展到耶和华的门廊前，又用了八天时间使耶和华的殿分别为圣，这样在一月十六日完工了。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="历代志下 4:1; 历代志下 4:7–8; 历代志下 13:11"> 然后，他们进王宫<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="王宫——辅助词语。">b</a></sup>去见希西加王，说：“我们已经把整个耶和华的殿，燔祭坛和附属的一切器具，陈设饼的桌子和附属的一切器具，都洁净了。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 28:24"> 亚哈斯王在位时对神不忠而抛弃的一切器具，我们也预备好了，把它们分别为圣了；看哪，这些都在耶和华的祭坛前面。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约书亚记 6:12; 耶利米书 25:4; 出埃及记 24:4"> 于是希西加王清早起来，招聚城里的众首领，然后上耶和华的殿去。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 4:3–14; 约伯记 42:8; 以西结书 45:23"> 他们牵来七头公牛、七只公绵羊、七只绵羊羔、七只公山羊，要为国家、为圣所、为犹大作赎罪祭；王吩咐作祭司的亚伦子孙把这些献在耶和华的祭坛上。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 4:18; 利未记 8:19; 利未记 8:24"> 他们就宰杀公牛，祭司把血接过来，洒在祭坛上；又宰杀公绵羊，把血洒在祭坛上；又宰杀绵羊羔，把血洒在祭坛上。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 4:15; 利未记 4:24; 利未记 1:4"> 然后把作赎罪祭的公山羊牵到王和会众面前，他们按手在公山羊身上，</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 14:20; 以西结书 45:15; 哥林多后书 5:18–21"> 祭司宰杀了公山羊，把血洒在祭坛上作赎罪祭，为全以色列赎罪，因为王吩咐要为全以色列献上这燔祭和赎罪祭。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="历代志下 8:14; 历代志上 23:5; 撒母耳记下 24:11"> 王又按照先王大卫与他的先见迦得和先知拿单的规定，安排利未人在耶和华殿中奏响铜钹、里拉琴和竖琴，因为这是耶和华藉着他的众先知所规定的。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志上 23:5; 历代志上 15:24; 阿摩司书 6:5"> 这样，利未人拿着大卫的乐器、祭司拿着号筒侍立。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="历代志下 23:18; 诗篇 137:3–4; 历代志下 20:21"> 希西加吩咐把燔祭献在祭坛上。燔祭开始献上时，赞美耶和华的歌声和号筒声也伴随着以色列王大卫的乐器开始响起。</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 5:8–14; 诗篇 89:15; 诗篇 68:24–26"> 全体会众都敬拜，歌唱的歌唱，吹号的吹号，这一切持续到献完了燔祭。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志下 20:18; 历代志上 29:20; 腓立比书 2:10–11"> 献完燔祭，王和所有与他一同在场的人都俯伏敬拜。</span>
<span className="v" id="v30" data-v="30" data-xref="腓立比书 4:4; 诗篇 95:1–2; 历代志上 16:7–36"> 然后，希西加王和众首领吩咐利未人用大卫和先见亚萨的歌词来赞美耶和华。于是他们欢欢喜喜地赞美耶和华，俯身下拜。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="历代志下 13:9; 出埃及记 35:22; 利未记 7:12"> 希西加说：“现在你们已经奉献自己归于耶和华。请上前来，把感谢的祭物带到耶和华殿中。”于是会众把感谢的祭物带来，所有甘心乐意的人都带来了燔祭。</span>
<span className="v" id="v32" data-v="32" data-xref="以斯拉记 6:17; 列王纪上 3:4; 历代志上 29:21"> 会众带来的燔祭数目是公牛七十头，公绵羊一百只，绵羊羔两百只，这一切都作为燔祭归于耶和华；</span>
<span className="v" id="v33" data-v="33"> 还有分别为圣之物，公牛六百头，绵羊三千只。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志下 35:11; 历代志下 30:3; 诗篇 94:15"> 只是祭司太少，不能给所有的燔祭牲剥皮，所以他们的兄弟利未人帮助他们，直到完成了这工作，并且其他祭司都使自己分别为圣了，因为利未人比祭司们更诚心使自己分别为圣。</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 15:5–10; 出埃及记 29:13; 历代志上 16:37–42"> 这大量的燔祭之外，还有平安祭的脂油，以及与燔祭同献的酒祭。<br />这样，耶和华殿中的服事就重新确立了。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 2:41; 帖撒罗尼迦前书 3:8–9; 历代志上 29:9"> 希西加和全体民众都因神为子民确立这事而欢喜，因为这事突然间就实现了。</span>
</div>
</div>

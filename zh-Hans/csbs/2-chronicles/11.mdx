<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 12:21–24; 诗篇 33:10; 诗篇 33:16"> 罗波安回到耶路撒冷，招聚了犹大家和便雅悯家十八万善战的精兵，要与以色列人争战，恢复罗波安的王国。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 12:15; 历代志下 12:5–7; 历代志下 8:14"> 但耶和华的话语临到神人示玛雅，说：</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 17:34; 创世记 49:28; 启示录 7:4–8"> “你要告诉所罗门的儿子犹大王罗波安，以及犹大和便雅悯的全体以色列人，说：</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 50:20; 列王纪上 11:29–38; 历代志下 10:15–16"> ‘耶和华如此说：你们不可上去，不可与你们的兄弟争战。各回自己的家去吧，因为这事出于我。’”<br />于是他们听从耶和华的话，转回不去攻打耶罗波安了。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 8:2–6; 历代志下 14:6–7; 以赛亚书 22:8–11"> 罗波安住在耶路撒冷，他在犹大修筑城镇来设防。</span>
<span className="v" id="v6" data-v="6" data-xref="尼希米记 3:5; 阿摩司书 1:1; 历代志上 4:32"> 他修筑了伯利恒、以坦、提克亚、</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 15:35; 撒母耳记上 22:1; 约书亚记 15:58"> 伯促尔、梭哥、亚杜兰、</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 54:1; 约书亚记 15:24; 撒母耳记上 23:19"> 迦特、玛利沙、西弗、</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 15:39; 约书亚记 15:35; 约书亚记 10:5"> 亚多莱音、拉吉、亚西加、</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 13:22; 约书亚记 15:33; 约书亚记 14:14"> 佐拉、阿雅仑、希伯仑，这些都是在犹大和便雅悯的防御城。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 17:19; 以赛亚书 22:10–11; 历代志下 11:23"> 他巩固了这些防御城，在其中设立将领，储备食物、油和酒，</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 13:22; 历代志下 26:14–15; 历代志下 32:5"> 并在每座城中配备盾牌和长矛，使城极其坚固。这样，犹大和便雅悯就一直属于他。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 全以色列的祭司和利未人从他们四境前来支持罗波安<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="支持罗波安——原文直译“站在罗波安一边”。">a</a></sup>。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 13:9; 民数记 35:2–5; 列王纪上 12:28–33"> 利未人撇下了他们的牧野和地产，来到犹大和耶路撒冷，因为耶罗波安和他的儿子们抛弃了利未人，不让他们作耶和华的祭司。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 12:28; 列王纪上 12:31; 列王纪上 13:33"> 耶罗波安为高坛、山羊神和他铸造的牛犊设立了自己的祭司。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 15:9; 使徒行传 11:23; 诗篇 84:5–7"> 以色列各支派中，那些决心要寻求以色列神耶和华的人，也跟随祭司和利未人来到耶路撒冷，要向他们祖先的神耶和华献祭。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 12:1; 历代志下 1:1–12; 历代志下 7:17–19"> 这样他们巩固了犹大王国，使所罗门的儿子罗波安强盛三年，因为这三年期间他们走大卫和所罗门的道路。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 16:6; 历代志上 27:18; 撒母耳记上 17:13"> 罗波安娶了大卫之子耶利莫的女儿玛哈拉为妻，玛哈拉的母亲<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="玛哈拉的母亲——辅助词语。">b</a></sup>是耶西之子以利押的女儿亚比亥。</span>
<span className="v" id="v19" data-v="19"> 玛哈拉给罗波安生了几个儿子：耶乌施、示玛利雅、扎罕。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 13:2; 历代志下 11:21; 历代志下 12:16"> 在她之后，罗波安又娶了押沙龙的外孙女<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="押沙龙的外孙女——或译作“押沙龙之女”。">c</a></sup>玛迦，玛迦为他生了亚比雅、亚泰、细撒和示罗米。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 8:30; 申命记 17:17; 列王纪上 11:3"> 罗波安喜爱押沙龙的外孙女<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="押沙龙的外孙女——或译作“押沙龙之女”。">d</a></sup>玛迦超过他其他的妃嫔；他娶了十八个妃、六十个嫔，生了二十八个儿子、六十个女儿。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命记 21:15–17; 历代志上 29:1; 历代志上 5:1–2"> 罗波安立玛迦的儿子亚比雅为太子，让他在兄弟中作领袖，因为要立他为王。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 21:3; 创世记 25:6; 路加福音 16:8"> 罗波安行事有智慧，把他的儿子都分散到犹大和便雅悯全地各防御城，并为他们提供大量的粮食，聘娶众多的妻子。</span>
</div>
</div>

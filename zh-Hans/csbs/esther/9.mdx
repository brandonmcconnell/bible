<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="EST" data-book-slug="esther" data-book-name="以斯帖记" data-chapter="9" data-verses="32">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖记 3:13; 以斯帖记 8:12; 诗篇 30:11"> 十二月（亚达月）十三日，王令和他的法令要执行的那一天，就是犹太人的仇敌期待辖制他们的日子，却成为犹太人辖制那些恨他们之人的日子。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯帖记 8:17; 以斯帖记 8:11; 诗篇 71:13"> 犹太人在亚哈随鲁王各省的城市中聚集起来，下手对付那些要谋害他们的人。没有人能在他们面前站立得住，因为各民族都惧怕他们。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 8:36; 以斯帖记 8:5; 但以理书 6:1–2"> 各省所有的首领，以及行政官、省长和办理王事务的人，都支持犹太人，因为他们惧怕末迪凯。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 3:1; 历代志上 11:9; 撒母耳记上 2:30"> 末迪凯在王宫里为大，他的名声传遍各省；末迪凯这人日渐强大。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="诗篇 18:34–40; 诗篇 20:7–8; 诗篇 149:6–9"> 犹太人用刀剑击杀了他们一切的仇敌，杀戮毁灭，任意对待那些恨他们的人。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯帖记 3:15"> 犹太人在苏萨城堡中击杀、消灭了五百人。</span>
<span className="v" id="v7" data-v="7"> 他们也击杀了巴珊达他、达乐分、阿斯帕他、</span>
<span className="v" id="v8" data-v="8"> 坡拉他、阿达利雅、阿利达他、</span>
<span className="v" id="v9" data-v="9"> 帕玛示他、阿利赛、阿利代、瓦业撒他，</span>
<span className="v" id="v10" data-v="10" data-xref="以斯帖记 5:11; 以斯帖记 8:11; 创世记 14:23"> 就是哈米达他的儿子犹太人的敌人哈曼的十个儿子，但没有下手掠夺财物。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 当天在苏萨城堡中被击杀的人数，呈到王的面前。</span>
<span className="v" id="v12" data-v="12" data-xref="以斯帖记 7:2; 以斯帖记 5:6"> 王对王后以斯帖说：“犹太人在苏萨城堡中击杀、消灭了五百人，又杀了哈曼的十个儿子；他们在王的其余各省中，又做了什么呢？现在无论你请求什么，都会赐予你；无论你还求什么，也会被成全。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以斯帖记 8:11; 申命记 21:23; 以斯帖记 9:15"> 以斯帖就说：“如果王认为好，就请王允许苏萨的犹太人明天也照着今天的法令去做，并且把哈曼的十个儿子挂在木架上。”</span>
<span className="v" id="v14" data-v="14"> 王就下令这样做了。于是这法令在苏萨颁布，人们把哈曼的十个儿子挂了起来。</span>
<span className="v" id="v15" data-v="15" data-xref="以斯帖记 8:11; 以斯帖记 9:10; 以斯帖记 9:16"> 亚达月十四日，苏萨的犹太人又聚集起来，在苏萨击杀了三百人，但没有下手掠夺财物。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以斯帖记 8:11; 以斯帖记 9:2; 利未记 26:7–8"> 至于王各省中的其余犹太人，他们也都聚集起来，保护自己的性命，摆脱他们的仇敌<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="摆脱他们的仇敌——原文直译“从他们的仇敌得到解脱”。">a</a></sup>，击杀了七万五千个恨他们的人，但没有下手掠夺财物；</span>
<span className="v" id="v17" data-v="17" data-xref="以斯帖记 9:21; 以斯帖记 9:1; 以斯帖记 8:9"> 这是亚达月十三日的事，而在十四日，他们得享安宁，并且守这日为宴席和喜乐的日子。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以斯帖记 9:21; 以斯帖记 9:1; 以斯帖记 9:15"> 不过，苏萨的犹太人在十三日和十四日聚集杀敌<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="杀敌——辅助词语。">b</a></sup>，而在十五日得享安宁，并且守这日为宴席和喜乐的日子。</span>
<span className="v" id="v19" data-v="19" data-xref="以斯帖记 8:17; 启示录 11:10; 尼希米记 8:10–12"> 因这缘故，住在乡下村镇的犹太人，守亚达月十四日为喜乐、宴席、庆祝的日子，彼此送食物。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命记 31:19–22; 哥林多后书 1:10–11; 诗篇 145:4–12"> 末迪凯记下了这些事，并且把诏书传送给亚哈随鲁王各省远近所有的犹太人，</span>
<span className="v" id="v21" data-v="21"> 吩咐他们：每年都要守亚达月十四日和十五日，</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 30:11; 以赛亚书 14:3; 以斯帖记 9:19"> 因为本月的这两日，是犹太人摆脱他们的仇敌<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="摆脱他们的仇敌——原文直译“从他们的仇敌得到解脱”。">c</a></sup>，从悲哀转为喜乐、从哀恸转为庆祝的日子；他们要守这两日为宴席和喜乐的日子，彼此送食物，也送礼物给穷人。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 于是，犹太人承诺要守他们已经开始守的，也承诺要遵守<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="遵守——辅助词语。">d</a></sup>末迪凯写给他们的。</span>
<span className="v" id="v24" data-v="24" data-xref="以斯帖记 3:5–13; 以斯帖记 9:10"> 事实上，亚甲人哈米达他的儿子哈曼——全体犹太人的敌人，谋划对付犹太人，要消灭他们；他抽了普珥，就是抽签，为要搅乱他们、消灭他们。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 7:16; 诗篇 140:9; 诗篇 141:10"> 然而，这事呈到了王的面前，王就用诏书下令，使哈曼的计策，就是他针对犹太人所谋划的恶事归到他自己头上，王又让人把他和他的儿子们挂在木架上。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯帖记 9:20; 民数记 16:40; 以西结书 39:11"> 因这缘故，犹太人就以普珥的名字，称呼这两日为“普珥”；因这书信中的一切话，又因他们在这事上所看到的，以及在他们身上所发生的事，</span>
<span className="v" id="v27" data-v="27" data-xref="撒迦利亚书 2:11; 以赛亚书 56:6; 以斯帖记 8:17"> 犹太人就为自己和自己的后裔，以及所有归附于他们的人，确立并承诺如下：每年都一定照着文书、照着所定的日期守这两日；</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 13:8–9; 约书亚记 4:7; 诗篇 103:2"> 各省各城、家家户户、世世代代都记念并守这两日，使这些普珥日在犹太人当中绝不废去，使这些事在他们的后裔当中绝不被遗忘。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以斯帖记 9:20; 以斯帖记 2:15; 以斯帖记 8:10"> 于是，亚比亥的女儿王后以斯帖全权给犹太人末迪凯下旨<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="以斯帖全权给犹太人末迪凯下旨——原文直译“以斯帖和犹太人末迪凯全权下旨”。">e</a></sup>，为要确定这第二封有关普珥的书信。</span>
<span className="v" id="v30" data-v="30" data-xref="以斯帖记 1:1; 以斯帖记 8:9; 撒迦利亚书 8:19"> 末迪凯把诏书，就是平安和真诚的话语，传送给亚哈随鲁国中一百二十七个行省的所有犹太人，</span>
<span className="v" id="v31" data-v="31" data-xref="以斯帖记 4:3; 以斯帖记 4:16; 约拿书 3:2–9"> 为要确立所定的日期守这些普珥日，就是照着犹太人末迪凯和王后以斯帖为他们所确立的，也是照着他们为自己和自己的后裔，在禁食、哀哭中所确立的日子。</span>
<span className="v" id="v32" data-v="32" data-xref="以斯帖记 9:26"> 以斯帖的命令确定了这些有关普珥的事，并且被记在史书上。</span>
</div>
</div>

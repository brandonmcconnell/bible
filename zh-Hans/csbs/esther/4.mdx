<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理书 9:3; 以西结书 27:30–31; 撒母耳记下 13:19"> 末迪凯知道了所发生的一切事，就撕裂衣服，披麻蒙灰，出去到城中，大声痛苦地哀叫。</span>
<span className="v" id="v2" data-v="2"> 他来到御门前面就停住，因为以麻布为衣袍的人不可进入御门。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 22:12; 但以理书 9:3; 以赛亚书 58:5"> 那时在各个省，在王令和他的法令所传到的地方，犹太人都大大哀恸；他们禁食、哭泣、哀号，许多人躺在麻布和灰烬上。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="诗篇 77:2; 耶利米书 31:15; 以斯帖记 1:12"> 以斯帖的使女们和太监们前来把这事告诉她。王后极其惊慌，就送衣服给末迪凯穿，要他脱去身上的麻布，他却不接受。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 12:26; 罗马书 12:15; 以斯帖记 1:10"> 以斯帖就召来在她面前侍立的王室太监哈塔革，吩咐他到末迪凯那里去了解这是怎么一回事，又是为了什么缘故。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯帖记 4:3; 以斯帖记 7:2; 以斯帖记 9:12"> 哈塔革就出去，到御门前面的城市广场去见末迪凯。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯帖记 3:2–15"> 末迪凯把自己所遇到的一切事，以及哈曼为要消灭犹太人而答应给国库捐银的确切数目，都告诉了哈塔革。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="传道书 10:4; 约伯记 9:15; 提摩太前书 6:13"> 末迪凯又把一份在苏萨颁布要除灭犹太人的法令文书的副本交给哈塔革，要哈塔革给以斯帖看，向她说明，并吩咐她去见王，向王恳求，在王面前为她的民族求情。</span>
<span className="v" id="v9" data-v="9"> 哈塔革回来，把末迪凯的话告诉了以斯帖。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 以斯帖就吩咐哈塔革回复<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="回复——辅助词语。">a</a></sup>末迪凯，说：</span>
<span className="v" id="v11" data-v="11" data-xref="以斯帖记 5:1–2; 以斯帖记 8:4; 但以理书 2:9"> “王所有的臣仆和王各省的民族都知道：无论男女，如果不被召唤而进入内院去见王，那么给他的只有一条法令，就是被处死；除非王向他伸出金杖，他才得以存活；而我没有被召唤去见王已经有三十天了。”</span>
<span className="v" id="v12" data-v="12"> 于是哈塔革把以斯帖的话告诉了末迪凯。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 24:10–12; 腓立比书 2:30; 约翰福音 12:25"> 末迪凯回复以斯帖，说：“你不要心里想，在所有的犹太人中，你因为在王宫里就能逃脱。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 45:4–8; 撒母耳记上 12:22; 申命记 32:36"> 如果你在这个时候保持沉默，帮助和解救就会从别的地方为犹太人兴起，而你和你的父家将会灭亡。谁知道，你得了王后之位，或许就是为了这样一个时候！”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 以斯帖回复末迪凯，说：</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 20:24; 历代志下 20:3; 约珥书 2:12–17"> “你当去，把所有在苏萨中的犹太人都聚集起来，为我禁食，三天三夜不吃不喝；我和我的使女们也会如此禁食。然后我就去见王，虽然这样不符合法令；我如果因此灭亡，就灭亡吧！”</span>
<span className="v" id="v17" data-v="17"> 于是末迪凯就出去，照着以斯帖所吩咐他的一切去做。</span>
</div>
</div>

</div>

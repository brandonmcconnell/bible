<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="2CO" data-book-slug="2-corinthians" data-book-name="哥林多后书" data-chapter="1" data-verses="24">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太后书 1:1; 腓立比书 1:1; 以弗所书 1:1"> 照着神的旨意做基督耶稣使徒的保罗，以及弟兄提摩太，<br />致那在哥林多属神的教会，以及在全亚该亚省所有的圣徒：</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="罗马书 1:7; 以弗所书 6:23; 腓立比书 1:2"> 愿恩典与平安从神我们的父和主耶稣基督临到你们！</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以弗所书 1:3; 彼得前书 1:3; 罗马书 15:5–6"> 愿颂赞归于神——我们主耶稣基督的父！他是各样怜悯的父、一切安慰的神。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 5:11; 以赛亚书 51:12; 帖撒罗尼迦后书 2:16–17"> 在我们一切的患难中，他安慰我们，使我们自己能用从神所受的安慰去安慰那些在各样患难中的人，</span>
<span className="v" id="v5" data-v="5" data-xref="歌罗西书 1:24; 腓立比书 3:10; 哥林多后书 4:10–11"> 因为基督的苦难怎样充充满满临到我们，藉着基督，我们的安慰也照样充充满满。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太后书 2:10; 哥林多后书 1:4; 哥林多后书 4:15–18"> 我们如果受患难，是为了你们的安慰和救恩；我们如果受安慰，也是为了你们的安慰<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附“救恩”。">a</a></sup>；这安慰有功效，使你们能忍耐与我们所受的同样苦难。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:17–18; 帖撒罗尼迦后书 1:4–7; 雅各书 1:12"> 而且我们对你们的盼望是确定的，因为知道你们怎样在苦难中与我们有份，也怎样在安慰中与我们有份。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 4:7–12; 哥林多前书 15:32; 哥林多前书 4:8"> 弟兄们，我们不愿意你们不明白我们在亚细亚省所遭受的患难：我们所受的压力远远过于我们的承受能力，甚至连活下去的希望也没有了。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 3:5; 希伯来书 11:19; 哥林多后书 4:7"> 然而我们在自己里面已经承受了死亡的判决，好让我们不依靠自己，而依靠那使死人复活的神。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 4:10; 诗篇 34:19; 彼得后书 2:9"> 他救我们脱离了如此致命的危险<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="如此致命的危险——有古抄本作“如此可怕的死亡”。">b</a></sup>，并且将来要救我们——我们盼望他将来还要救我们。</span>
<span className="v" id="v11" data-v="11" data-xref="腓立比书 1:19; 哥林多后书 4:15; 使徒行传 12:5"> 你们也能通过祈祷一同帮助我们，好让许多人因着那临到我们的恩惠<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="恩惠——或译作“恩赐”。">c</a></sup>为我们献上感谢；这恩惠是通过许多人临到我们的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 2:17; 哥林多前书 2:13; 雅各书 3:13–18"> 我们所夸耀的是这一点：我们的良心见证了我们在世上行事为人带着属神的忠实<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="忠实——有古抄本作“圣洁”。">d</a></sup>和真诚，不是靠属肉体的智慧，而是靠神的恩典；对你们更是如此。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 4:2; 腓利门书 1:6; 哥林多后书 13:6"> 其实我们写给你们的，无非是你们能读、能了解的，而且我希望你们能彻底地了解，</span>
<span className="v" id="v14" data-v="14" data-xref="腓立比书 2:16; 哥林多前书 1:8; 帖撒罗尼迦前书 2:19–20"> 就像你们对我们已经有一些了解那样，因为在我们<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本没有“我们”。">e</a></sup>主耶稣的日子<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="日子——指“基督再来的日子”。">f</a></sup>，我们是你们的夸耀，正如你们是我们的夸耀。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 4:19; 罗马书 1:11; 罗马书 15:29"> 藉着这样的确信，我早就打算先到你们那里去，使你们能得到两次的恩典<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="得到两次的恩典——有古抄本作“再得喜乐”。">g</a></sup>：</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 16:5–7; 使徒行传 21:5; 使徒行传 19:21–22"> 就是经过你们那里往马其顿省去，再从马其顿省回到你们那里，然后由你们送我上路去犹太。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 5:37; 雅各书 5:12; 哥林多后书 10:2–3"> 那么，我这样打算，难道就是轻率行事吗？难道我所计划的，是顺着肉体的计划，以致在我忽是忽非吗？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 1:9; 启示录 3:7; 约翰福音 7:28"> 神是信实的，我们向你们传的话语，并没有“是”而又“非”。</span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 13:8; 启示录 1:17; 约翰二书 1:9"> 要知道，藉着我们，就是我、西拉斯和提摩太，在你们中间所传扬的神儿子耶稣基督，并没有“是”而又“非”；相反，在他只有“是”，</span>
<span className="v" id="v20" data-v="20" data-xref="约翰一书 2:24–25; 加拉太书 3:22; 启示录 7:12"> 因为神的一切应许，在基督<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="基督——原文直译“他”。">h</a></sup>里都成为“是”。所以，说“阿们”也是藉着基督<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="基督——原文直译“他”。">i</a></sup>，使荣耀藉着我们归于神。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 2:27; 彼得前书 5:10; 约翰一书 2:20"> 原来将我们与你们在基督里一起确立，并且膏立了我们大家的那一位，就是神。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 4:30; 哥林多后书 5:5; 以弗所书 1:13–14"> 他又在我们身上盖了印，并且赐圣灵在我们心里做为预付凭据<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="预付凭据——或译作“定金”。">j</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="加拉太书 1:20; 哥林多前书 4:21; 罗马书 1:9"> 我求告神为我的灵魂见证：我没有再往哥林多去，是因为顾惜你们。</span>
<span className="v" id="v24" data-v="24" data-xref="彼得前书 5:3; 哥林多前书 15:1; 腓立比书 1:25–26"> 我们并不是要辖制你们的信仰，而是要做你们的同工，使你们喜乐；因为你们已经因信站立得住了。</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 12:11; 哥林多后书 10:12; 哥林多后书 5:12"> 我们又开始推荐自己吗？难道我们像有些人那样，需要给你们推荐信，或向你们要推荐信吗？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 9:1–2; 帖撒罗尼迦前书 1:8; 罗马书 1:8"> 你们就是我们的推荐信，写在我们的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我们的——有古抄本作“你们的”。">a</a></sup>心里，被人人所知道、所诵读；</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 11:19; 耶利米书 31:33; 希伯来书 8:10"> 因为很明显，你们是基督的书信，由我们所经手；不是用墨写的，而是用永生神的灵写的；不是刻在石版上，而是刻在人的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="人的——原文直译“肉体的”。">b</a></sup>心版上。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="腓立比书 1:6; 以弗所书 3:12; 哥林多后书 2:14"> 我们藉着基督，对神有这样的确信，</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 12:9; 腓立比书 4:13; 哥林多前书 15:10"> 并不是说，我们凭自己配得上把什么算做出于自己；而是说，我们之所以配得上是出于神。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 6:63; 罗马书 7:6; 耶利米书 31:31"> 他也使我们能够做新约的仆人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="仆人——或译作“执事”。">c</a></sup>——不属于律法条文，而属于圣灵；因为律法条文带来死亡，而圣灵却赐予生命。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 3:9–11; 罗马书 10:4; 出埃及记 31:18"> 如果，那以条文刻在石版上、属死亡的服事工作尚且带有荣光——以致以色列子民因为摩西脸上那渐渐消失的荣光，不能注视他的脸——</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 3:16; 以弗所书 2:18; 加拉太书 3:14"> 何况那属圣灵的服事工作，难道不更带有荣光吗？</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 3:21–22; 希伯来书 12:18–21; 哥林多后书 5:21"> 因为那带来<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="带来——辅助词语。">d</a></sup>定罪的服事工作尚且有荣光，何况那带来<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="带来——辅助词语。">e</a></sup>称义的服事工作，难道不更充满了荣光吗？</span>
<span className="v" id="v10" data-v="10" data-xref="彼得后书 1:17; 哈该书 2:7–9; 使徒行传 26:13"> 事实上，在这种情况下，那先前有荣光的，因这无限的荣光，就成了没有荣光的。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 5:20–21; 希伯来书 8:13; 希伯来书 7:21–25"> 这样，那渐渐消失的尚且带有荣光，何况这长存的，难道不更带有荣光吗？</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 7:4; 使徒行传 4:13; 腓立比书 1:20"> 因此，我们既然怀有这样的盼望，就大有胆量地行事。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 34:33–35; 希伯来书 10:1–9; 以弗所书 2:14–15"> 我们不像摩西那样，他把帕子蒙在脸上，使以色列子民不能注视那渐渐消失的荣光的结局。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 4:3–4; 使徒行传 26:18; 罗马书 11:25"> 可是，他们的心思刚硬；事实上，直到今天诵读旧约的时候，同样的帕子仍然存在，没有被揭去，因为那帕子只有<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="只有——辅助词语。">f</a></sup>在基督里才被除去。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 13:27–29"> 的确，直到今天，摩西书无论什么时候被诵读，那帕子仍然盖在他们的心上。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 34:34; 以赛亚书 29:18; 以赛亚书 25:7"> 可是一个人什么时候归向主，那帕子就被除掉了。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 8:2; 加拉太书 5:13; 约翰福音 8:32"> 主就是圣灵，主的灵在哪里，哪里就有自由；</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 4:6; 以弗所书 4:22–24; 罗马书 12:2"> 而且脸上的帕子既然被揭去了，我们大家就像镜子返照出<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="就像镜子返照出——或译作“就像从镜子里看见”。">g</a></sup>主的荣光，正在被改变成与主同样的形像，从荣耀归入荣耀，这正是出于主——圣灵。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦后书 3:13; 加拉太书 6:9; 以弗所书 3:13"> 所以，我们既然得了这服事的工作，正如我们蒙了怜悯，我们就不丧胆；</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 2:17; 帖撒罗尼迦前书 2:3–5; 哥林多后书 5:11"> 相反，把那些可耻的隐秘之事弃绝了；不以诡诈行事，也不歪曲神的话语<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="神的话语——或译作“神的道”。">a</a></sup>；反而藉着显明真理，在神面前把自己推荐给每个人的良心。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 3:14; 哥林多前书 1:18; 帖撒罗尼迦后书 2:9–11"> 但如果我们的福音真的被遮盖了，也是在那些正灭亡的人中被遮盖的。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 12:40; 哥林多后书 3:14; 使徒行传 26:18"> 对于他们，这世代的神把这些不信之人的心眼弄瞎了，使他们不能洞察基督荣耀的福音之光。基督就是神的形像。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 1:24; 哥林多前书 1:23; 帖撒罗尼迦前书 2:5–6"> 实际上，我们不是传扬自己，而是传扬主耶稣基督<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="传扬主耶稣基督——或译作“传扬耶稣基督是主”。">b</a></sup>，并且为了耶稣的缘故，我们自己做了你们的奴仆；</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 60:2; 创世记 1:3; 彼得前书 2:9"> 因为那吩咐“要有光从黑暗里照耀出来”的神，已经照耀了我们的心，为要发出神荣耀的知识之光——这光就在耶稣基督的脸上。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 3:5–6; 哥林多后书 5:1; 以弗所书 2:8–9"> 不过我们有这宝物在瓦器里，为要显明这极大的能力是出于神，不是出于我们。</span>
<span className="v" id="v8" data-v="8" data-xref="雅各书 1:2–4; 罗马书 8:35–37; 彼得前书 4:12–14"> 我们处处受患难，却不被压碎；心里困惑，却没有绝望；</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 43:2; 弥迦书 7:8; 诗篇 37:24–25"> 受逼迫，却不被撇弃；被打倒，却没有灭亡。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 6:5; 提摩太后书 2:11; 彼得前书 4:13"> 我们身上总是带着耶稣的死，好让耶稣的生命也在我们身上显明出来。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 15:49; 罗马书 8:36; 诗篇 44:22"> 的确，我们这些活着的人，为了耶稣的缘故，总是被置于死地，好让耶稣的生命也显明在我们这会死的肉体上。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 13:9; 哥林多前书 4:10; 使徒行传 20:24"> 这样，死亡在我们里面做工，而生命却在你们里面做工。</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 116:10; 希伯来书 11:1–40; 哥林多后书 3:12"> 照着经上所记的：“我信，故我说”，我们既然有同一个信仰的灵，我们也就信，所以也就说，</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 4:14; 罗马书 8:11; 犹大书 1:24"> 因为我们知道：使主耶稣复活的那一位，也要使我们与耶稣一同复活<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="也要使我们与耶稣一同复活——有古抄本作“也要使我们藉着耶稣复活”。">c</a></sup>，并且使我们和你们一起站在他面前。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 8:28; 以弗所书 3:20–21; 哥林多后书 9:11–12"> 的确，这一切都是为了你们的缘故，好让恩典藉着更多的人而增多，使感谢充实满溢，归于神的荣耀。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 40:31; 歌罗西书 3:10; 以赛亚书 40:29"> 因此我们不丧胆。即使我们外在的人渐渐衰朽，我们内在的人还是日日被更新。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 8:18; 彼得前书 5:10; 罗马书 5:3–5"> 原来我们这暂时、轻微的患难，正为我们带来极重无比、永恒的荣耀。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 5:7; 罗马书 8:24–25; 希伯来书 11:1"> 我们所注重的不是看得见的，而是看不见的；因为看得见的是暂时的，看不见的却是永恒的。</span>
</div>
</div>

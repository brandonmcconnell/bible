<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 16:9; 哥林多后书 9:2; 哥林多后书 9:4"> 弟兄们，我们要你们明白神在马其顿省各教会中所赐的恩典：</span>
<span className="v" id="v2" data-v="2" data-xref="雅各书 2:5; 箴言 11:25; 哥林多后书 6:10"> 在患难的极大考验中，他们的喜乐之满和贫穷之深都流露出来，归入他们慷慨之心的财富。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 35:29; 出埃及记 35:5; 出埃及记 35:21–22"> 因为我可以见证他们是按着自己的能力，甚至超过了自己的能力，甘心乐意，</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 24:17; 加拉太书 6:10; 哥林多后书 9:1"> 用许多乞求的话，恳请我们在对圣徒的服事<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="服事——或译作“供应”。">a</a></sup>上给与他们恩准和分享的机会<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="的机会——辅助词语。">b</a></sup>；</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 12:1; 罗马书 14:7–9; 历代志下 30:12"> 他们不但照我们所盼望的，而且照着神的旨意，首先把自己献给了主，又献给了我们。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 12:18; 哥林多后书 8:19; 哥林多后书 8:4"> 我们于是劝提多，他怎样开始了这恩惠之事，就当照样在你们那里把它完成；</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 9:8; 彼得后书 1:5–8; 帖撒罗尼迦后书 1:3"> 而且你们怎样在信仰、言语、知识、殷勤和你们对我们的爱心<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="你们对我们的爱心——有些古抄本作“我们对你们的爱心”。">c</a></sup>上都丰足有余，你们也当怎样在这恩惠之事上丰足有余。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 7:6; 约翰一书 3:17–19; 雅各书 2:14–16"> 我说这话不是出于命令，而是要藉着别人的殷勤来考验你们爱的真诚，</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 8:32; 腓立比书 2:6–8; 马太福音 20:28"> 因为你们知道我们主耶稣基督的恩典：他虽然富足<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="虽然富足——指“他成肉身之前的时候”。">d</a></sup>，却为你们成了贫穷<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="他……成了贫穷——指“他成肉身之后的时候”。">e</a></sup>，好使你们藉着他的贫穷可以成为富足。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 6:18–19; 希伯来书 13:16; 哥林多后书 9:2"> 我在这件事上提供意见，因为这对你们是有益处的。从去年开始，你们不仅做了这件事，而且愿意去做，</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 9:2"> 所以现在你们就当完成这事，好使你们怎样有愿做的乐意之心，就怎样以你们所拥有的完成它；</span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 12:42–44; 哥林多后书 9:7; 路加福音 21:1–4"> 因为人如果有乐意之心，就会照着他所拥有的蒙悦纳，并不是照着他所没有的蒙悦纳。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 4:34; 罗马书 15:26–27"> 其实我这样说<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="我这样说——辅助词语。">f</a></sup>不是为了让别人轻松、你们为难，而是为了公平——</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 9:12; 使徒行传 4:34"> 在现今的时刻，你们的富余可以补他们的缺乏，好使将来<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="将来——辅助词语。">g</a></sup>他们的富余也可以补你们的缺乏，这样就公平了。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 16:18; 路加福音 22:35"> 正如经上所记：<br /><span className="pl pl-1">“多收的没有增多，</span><br /><span className="pl pl-1">少收的也没有缺少。”</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="启示录 17:17; 耶利米书 32:40; 哥林多后书 2:13–14"> 感谢神，他为了你们，把同样的殷勤放在提多的心里。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 8:6; 希伯来书 13:22; 哥林多后书 8:10"> 提多一方面接受了我们的鼓励，另一方面自己更是殷勤，自愿到你们那里去。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 12:18; 哥林多后书 8:19; 哥林多前书 7:17"> 我们也打发了一位弟兄与他一起去。这位弟兄在福音工作上受到各教会的称赞；</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 16:3–4; 哥林多后书 4:15; 哥林多后书 9:8"> 不仅如此，他也被各教会选出，与我们一起带着惠赠<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="惠赠——或译作“恩惠之事”。">h</a></sup>同行。我们这服事为的是主自己的荣耀，也为了表明<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="表明——辅助词语。">i</a></sup>我们的乐意之心。</span>
<span className="v" id="v20" data-v="20" data-xref="帖撒罗尼迦前书 5:22; 罗马书 14:16; 以弗所书 5:15"> 我们这样谨慎，免得有人在我们所经手的这丰厚之事<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="丰厚之事——或译作“丰厚的惠赠”。">j</a></sup>上挑剔我们，</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 12:17; 彼得前书 2:12; 腓立比书 4:8"> 因为我们顾念的，不仅是主看为美善，也要人看为美善。</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比书 2:20–22"> 我们还打发了另一位弟兄和他们一起去。我们在很多事上多次验证过这位弟兄是殷勤的，而现在他因为深深地信任你们，就更加殷勤了。</span>
<span className="v" id="v23" data-v="23" data-xref="腓立比书 2:25; 腓利门书 1:17; 哥林多后书 8:6"> 论到提多，他是我的同伴，也是为着你们<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="为着你们——或译作“在你们中间”。">k</a></sup>的同工。至于那两位弟兄<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="那两位弟兄——原文直译“我们的弟兄们”。">l</a></sup>，他们是各教会的使者，是基督的荣耀。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 7:14; 哥林多后书 7:4; 哥林多后书 9:2–4"> 所以，你们要在各教会面前，向他们显出你们爱心的凭证，以及我们所夸耀你们的凭据。</span>
</div>

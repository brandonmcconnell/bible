<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约伯记 19:25–26; 约翰一书 3:2; 彼得后书 1:13–14"> 我们知道，当我们属地的家——这帐篷被拆毁的时候，我们就有从神而来的殿宇<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="殿宇——原文直译“建筑物”。">a</a></sup>，不是人手所造的，而是在天上的永恒的家。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 8:23; 哥林多前书 15:53–54; 哥林多后书 5:3–4"> 实际上，我们就是在这帐篷里呻吟叹息，切切地想穿上我们那从天上而来的居所。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 3:7–11; 启示录 16:15; 启示录 3:18"> 如果真的穿上<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="穿上——有古抄本作“脱下”。">b</a></sup>，我们将来被看见时，就不是赤身的。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 15:53–54; 哥林多后书 5:2; 以赛亚书 25:8"> 原来我们在这帐篷里的人，承受着压力，甚至呻吟叹息；不是因为想要脱下，而是想要穿上，好让这会死的被生命所吞没。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 1:22; 以弗所书 1:13–14; 罗马书 8:23"> 为此而预备我们的就是神；他赐给我们圣灵做为预付凭据<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="预付凭据——或译作“定金”。">c</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 5:1; 腓立比书 3:20–21; 希伯来书 11:13"> 因此我们总是满怀勇气，尽管知道我们还住在这身体里的时候，是与主相离的；</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 11:1–27; 哥林多后书 4:18; 罗马书 8:24–25"> 原来我们行事是藉着信，不是藉着眼见。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比书 1:20–24; 哥林多后书 5:6; 约翰福音 14:3"> 是的，我们满怀勇气，更乐意离开这身体，与主同住。</span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 1:10; 彼得后书 3:14; 罗马书 14:18"> 所以我们立定心志，无论是住在身体里，还是离开身体，都要得主的喜悦，</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 16:27; 启示录 22:12; 以弗所书 6:8"> 因为我们大家都必须站<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="站——原文直译“被显明”。">d</a></sup>在基督的审判台前，好使每个人都为自己藉着身体所做的，或善或恶，领受回报。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="犹大书 1:23; 希伯来书 10:31; 提摩太后书 2:24–26"> 既然如此，我们因为知道敬畏主，就劝导人。我们在神面前是显明的，但我希望在你们的良心里，也是显明的。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 3:1; 哥林多后书 1:14; 加拉太书 6:12–14"> 我们不是再次向你们推荐自己，而是给你们一个夸耀我们的机会，好让你们可以应对那些只凭外貌、不凭内心夸耀的人，</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 11:16–17; 哥林多后书 11:1; 哥林多后书 12:6"> 因为我们如果癫狂，是为了神；如果清醒，是为了你们。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 2:20; 罗马书 14:7–9; 马太福音 10:37–38"> 实际上，基督的爱催逼着我们，因为我们如此判定：既然一个人<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一个人——指“基督”。">e</a></sup>替所有的人死了，所有的人就都死了；</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 14:7–9; 彼得前书 4:2–4; 彼得前书 1:14–15"> 基督替所有的人死了，好让那些活着的人不再为自己活，却为替他们死而复活的基督而活。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 3:11; 腓立比书 3:7–8; 约翰福音 6:63"> 所以，从今以后，我们不按人的标准<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="按人的标准——原文直译“按肉体”。">f</a></sup>看任何人了。虽然我们曾经按人的标准<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="按人的标准——原文直译“按肉体”。">g</a></sup>认识基督，但现在我们不再这样认识他了。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 36:26; 以弗所书 4:22–24; 以赛亚书 43:18–19"> 因此，如果有人在基督里，他就是新造的人<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="他就是新造的人——或译作“有新的创造”。">h</a></sup>；旧的已经过去，看哪，新的已经来临<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="新的已经来临——有古抄本作“一切都变成新的了”。">i</a></sup>。</span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 1:20–21; 哥林多后书 5:19–20; 罗马书 5:10–11"> 这一切都是出于神，他藉着基督<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="基督——有古抄本作“耶稣基督”。">j</a></sup>使我们与他自己和好，并且把这劝人与他<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="劝人与他——辅助词语。">k</a></sup>和好的服事工作赐给了我们。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 43:25; 以赛亚书 44:22; 约翰一书 2:1–2"> 这就是说，在基督里，神使世人与自己和好，不把他们的过犯算在他们的身上，又把这和好的福音<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="福音——原文直译“话语”或“道”。">l</a></sup>托付了我们。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 6:20; 路加福音 14:23; 玛拉基书 2:7"> 因此我们是基督的特使，就像神藉着我们在劝告人——我们代替基督请求说：“与神和好吧！”</span>
<span className="v" id="v21" data-v="21" data-xref="彼得前书 2:22–24; 彼得前书 3:18; 罗马书 5:19"> 神使那位没有罪<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="没有罪——原文直译“不知道罪”。">m</a></sup>的替我们成为罪<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="替我们成为罪——或译作“做我们的赎罪祭”。">n</a></sup>，好使我们在他里面成为神的义。</span>
</div>
</div>

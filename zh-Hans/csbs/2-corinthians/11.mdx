<span className="v" id="v2" data-v="2" data-xref="何西阿书 2:19–20; 以弗所书 5:26–27; 以赛亚书 54:5"> 我以神的热心热爱你们，因为我已经把你们许配给一位丈夫，做为贞洁的童女献给基督。</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 2:8; 加拉太书 1:6; 以弗所书 4:14"> 可是我担心，恐怕你们的思想受到败坏，离开对基督的忠实和贞洁<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本没有“贞洁”。">a</a></sup>，就像蛇用它的诡计欺骗了夏娃那样。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 1:6–8; 哥林多前书 3:11; 提摩太前书 2:5"> 实际上，如果有人真的来传另一个耶稣，不是我们所传过的；或者你们领受另外一个灵，不是你们所领受过的；或者接受另外一个福音，不是你们所接受过的——你们竟然容忍他！</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 12:11–12; 哥林多前书 15:10; 加拉太书 2:6–9"> 实际上，我认为自己没有一点赶不上那些“超级使徒<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="超级使徒——指“那些认为保罗不是真使徒的教会领袖”。">b</a></sup>”。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所书 3:4; 哥林多前书 1:17; 哥林多后书 4:2"> 即使我在言语上没有技巧，但在知识上并不是这样。其实我们在各个方面、在所有的事上都已经向你们显明了这一点。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 12:13; 帖撒罗尼迦前书 2:9; 哥林多后书 10:1"> 我降卑自己，好使你们被高举，因为我把神的福音无偿地传给你们，难道我这样就犯了罪吗？</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比书 4:18; 哥林多后书 11:9; 腓立比书 4:14–16"> 我“掠夺了”别的教会，拿了他们的工价来服事你们。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦后书 3:8–9; 帖撒罗尼迦前书 2:9; 帖撒罗尼迦前书 2:6"> 我在你们那里有缺乏的时候，也没有成为任何人的负担，因为从马其顿省来的弟兄们补足了我的缺乏。在一切事上我都留意，不让自己成为你们的负担，将来也会留意。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 9:1; 罗马书 1:9; 使徒行传 18:12"> 我指着<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="我指着——辅助词语。">c</a></sup>在我里面基督的真理说，在亚该亚地区，谁也不能阻止我如此夸耀。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 12:15; 哥林多后书 6:11–12; 哥林多后书 7:3"> 为什么呢？难道因为我不爱你们吗？神是知道的！</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 9:12; 哥林多前书 5:6; 哥林多后书 5:12"> 我现在所做的，将来还要做，为要断绝那些人的机会——他们想找一个机会，好让别人以为他们所夸耀的与我们一样，</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太书 1:7; 启示录 2:2; 约翰一书 4:1"> 因为这样的人是假使徒，是诡诈的工人，他们装做基督的使徒。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 1:8; 哥林多后书 2:11; 哥林多后书 11:3"> 这并不足为奇，原来撒旦自己也装做光明的天使；</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比书 3:19; 启示录 9:11; 以赛亚书 9:14–15"> 所以，即使他的仆人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="仆人——或译作“执事”。">d</a></sup>把自己装做义的仆人<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="仆人——或译作“执事”。">e</a></sup>，也不足为怪；他们的结局必然照着他们的行为。</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 11:1; 哥林多后书 12:6; 哥林多后书 12:11"> 我再说：谁都不要以为我是愚妄的人！否则，至少该接受我这个像是愚妄的人，好让我也可以稍微自夸。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 7:12; 腓立比书 3:3–6; 哥林多后书 9:4"> 我现在所说的，不是按照主说的，而是像一个愚妄人那样自信夸耀。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 4:10; 哥林多后书 11:21–23; 哥林多后书 10:12–18"> 既然有许多人按人的标准<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="按人的标准——原文直译“按肉体”。">f</a></sup>自夸，我也要自夸了，</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 4:10; 哥林多前书 10:15; 哥林多前书 8:1"> 因为你们做为聪明人，乐意容忍愚妄的人！</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太书 2:4; 加拉太书 4:3; 加拉太书 5:1"> 实际上，就算有人奴役你们，或侵吞你们，或榨取你们，或压制你们，或打你们的脸，你们也能容忍。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 10:10; 哥林多后书 11:17; 哥林多后书 10:1–2"> 说来惭愧，我们倒好像是软弱的。<br />但如果有人在什么事上大胆——我说句愚妄的话——我也大胆！</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比书 3:5; 罗马书 11:1; 罗马书 9:4"> <span className="pl pl-1">他们是希伯来人吗？我也是。</span><br /><span className="pl pl-1">他们是以色列人吗？我也是。</span><br /><span className="pl pl-1">他们是亚伯拉罕的后裔吗？我也是。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 6:4–5; 哥林多后书 1:9–10; 哥林多后书 6:9"> <span className="pl pl-1">他们是基督的仆人</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="仆人——或译作“执事”。">g</a></sup><br /><span className="pl pl-1">吗？</span><br /><span className="pl pl-1">我狂妄地说：我更是！</span><br /><span className="pl pl-1">我受了更多的劳苦，更多的监禁，</span><br /><span className="pl pl-1">更多的鞭打，经常面临死亡，</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="马可福音 13:9; 申命记 25:2–3; 马太福音 10:17"> <span className="pl pl-1">我在犹太人的手中，遭受了五次“四十减一”的鞭打</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="的鞭打——辅助词语。">h</a></sup><br /><span className="pl pl-1">，</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 14:19; 使徒行传 16:37; 希伯来书 11:37"> <span className="pl pl-1">被棍子打过三次，</span><br /><span className="pl pl-1">被石头砸过一次，</span><br /><span className="pl pl-1">遭遇海难</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="遭遇海难——原文直译“船只破坏”。">i</a></sup><br /><span className="pl pl-1">三次，</span><br /><span className="pl pl-1">在深海里度过了一昼一夜；</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 14:5; 使徒行传 17:5; 使徒行传 13:50"> <span className="pl pl-1">我经常行远路，</span><br /><span className="pl pl-1">遭遇江河的危险、强盗的危险、</span><br /><span className="pl pl-1">来自同胞的危险、来自外邦人的危险、</span><br /><span className="pl pl-1">在城里的危险、在旷野中的危险、</span><br /><span className="pl pl-1">在海上的危险、在假弟兄中的危险；</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="腓立比书 4:12; 哥林多后书 6:5; 帖撒罗尼迦前书 2:9"> <span className="pl pl-1">我辛苦劳碌，经常失眠，</span><br /><span className="pl pl-1">又饥又渴，经常缺食，</span><br /><span className="pl pl-1">遭受寒冷，衣不蔽体。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 7:17; 罗马书 15:16; 使徒行传 20:18–35"> 除了这些外在的事，还有对各教会的挂虑，天天压在我身上。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 8:13; 哥林多前书 9:22; 加拉太书 4:8–20"> 有谁软弱，我不软弱呢？有谁被绊倒<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="被绊倒——或译作“被诱犯罪”。">j</a></sup>，我不心如火烧呢？</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多后书 12:5–11; 箴言 25:27; 哥林多前书 2:3"> 如果必须夸耀，我就夸耀自己的那些软弱。</span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 9:5; 以弗所书 1:3; 约翰福音 10:30"> 主耶稣的神与父——永远当受颂赞的那一位，知道我不是在说谎。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 9:24–25; 哥林多后书 11:26"> 在大马士革，阿瑞塔斯王的总督看守了大马士革城，要抓<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="要抓——有古抄本作“想要抓”。">k</a></sup>我，</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 9:25; 撒母耳记上 19:12; 约书亚记 2:18"> 可是我被人用筐子从城墙的窗口缒下来，逃脱了他的手。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 1:12; 哥林多后书 12:7; 约翰一书 5:20"> 夸耀虽然没有益处，但是必须的；我要说到主的异象和启示：</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 22:17; 以西结书 8:1–3; 帖撒罗尼迦前书 4:17"> 我知道一个在基督里的人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一个在基督里的人——指“保罗自己”。">a</a></sup>，他十四年前被提到第三层天上。他是否在身体里，我不知道；是否在身体外，我也不知道；只有神知道。</span>
<span className="v" id="v3" data-v="3"> 不过我知道这样一个人——他是否在身体里，还是在身体外，我都不知道，只有神知道——</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 23:43; 启示录 2:7; 以西结书 31:9"> 他被提到乐园里去，听见了无法描述的话语，是人不可以说出来的。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 11:30; 哥林多前书 2:3; 哥林多后书 12:9–10"> 为这样一个人，我要夸耀，但为我自己，除了有关那些软弱的事以外，我不夸耀。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 11:16; 哥林多后书 11:31; 哥林多后书 12:11"> 其实就算我愿意夸耀，也不算是愚妄的人，因为我会讲真理。可是我要克制，免得有人把我看高了，过于他在我身上所看到的，或是从我所听到的。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 33:55; 士师记 2:3; 历代志下 32:25–26"> 并且为了不让我因这些极大的启示而高抬自己，有一根刺加在我的肉体上，就是撒旦的使者来击打我，免得我高抬自己。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 5:7; 马太福音 26:39–44; 撒母耳记上 15:11"> 为了这事，我三次求主使这根刺<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这根刺——或译作“它”。">b</a></sup>离开我。</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比书 4:13; 哥林多后书 12:10; 以赛亚书 40:29–31"> 但他对我说：<span className="woj">“我的恩典是够你用的，因为我的</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本没有“我的”。">c</a></sup><span className="woj">大能在软弱中得以完全。”</span>因此，我反而极其乐意地夸耀我的那些软弱，好让基督的能力遮盖在我身上。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 12:9; 以弗所书 6:10; 罗马书 5:3"> 所以，为了基督的缘故，我在那些软弱中、凌辱中、艰难中、在逼迫和困苦中，都感到喜悦；因为我什么时候软弱，什么时候就刚强了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 11:5; 哥林多后书 11:1; 哥林多前书 15:8–10"> 我<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附“这样夸耀”。">d</a></sup>成了愚妄的人，是你们逼我的。其实我应该受到你们的推荐，因为即使我一无所是，我也没有一点赶不上那些“超级使徒”。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 15:18–19; 哥林多后书 11:4; 哥林多后书 4:2"> 我在你们中间以极大的忍耐，用神迹、奇事和大能，确实显出了使徒的标记。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 9:12; 哥林多前书 9:6; 哥林多后书 11:7–9"> 除了我自己没有成为你们的负担以外，你们所受的对待，到底有什么不如其他教会呢？请你们饶恕我这点不公平吧！</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="箴言 19:14; 创世记 24:35–36; 哥林多前书 10:33"> 看哪，这是我第三次预备好到你们那里去，而且我不会成为你们的负担，因为我想要的不是你们的东西，而是你们自己。本来，不应该是儿女为父母积蓄财富，而是父母为儿女积蓄财富。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 2:8; 哥林多后书 1:6; 腓立比书 2:17"> 所以为了你们的灵魂，我会极其乐意地付出，甚至完全付出。难道我爱你们越多，就越少得到你们的爱吗？</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦前书 2:5; 哥林多后书 10:2–3; 哥林多后书 12:13"> 不过就算如此，我也没有成为你们的负担——难道我是狡猾的人，用诡计牢笼了你们吗？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 9:5; 哥林多前书 4:17; 列王纪下 5:20–27"> 难道我曾经藉着派到你们那里去的人，对不起你们吗？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 8:6; 罗马书 4:12; 使徒行传 20:33–35"> 我鼓励提多去，又打发那位弟兄与他一起去。难道提多对不起你们吗？我们行事，难道不是同一个心灵吗？难道不是同一个步调吗？</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="罗马书 9:1; 哥林多前书 14:26; 哥林多后书 10:8"> 你们一直以为我们是在向你们申辩吗？我们是在基督里，在神面前说话。各位蒙爱的人哪，这一切都是为了造就你们。</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太书 5:19–21; 彼得前书 2:1; 罗马书 1:29"> 其实我担心，恐怕我来到的时候会发现你们不像我所希望的那样，而你们发现我也不像你们所希望的那样；又恐怕有纷争、嫉妒、暴怒、争竞<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="争竞——或译作“结党”。">e</a></sup>、诽谤、谗言、自大和混乱；</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 13:2; 彼得前书 4:2–3; 歌罗西书 3:5"> 恐怕我来的时候，我的神会使我在你们面前再一次蒙羞<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="蒙羞——原文直译“降卑”。">f</a></sup>，而且因为许多人从前犯了罪，又不肯为他们所行的污秽、淫乱和好色的事而悔改，我就会悲伤。</span>
</div>
</div>

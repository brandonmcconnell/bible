<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 1:23; 哥林多后书 12:20–21; 哥林多后书 13:10"> 所以，我自己这样决定：不再带着忧伤到你们那里去。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 7:8; 哥林多后书 1:14; 哥林多前书 12:26"> 因为如果我使你们忧伤，那么，除了我使他忧伤的那个人，谁能使我欢喜呢？</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 5:10; 哥林多后书 8:22; 腓利门书 1:21"> 我写了那封信<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="那封信——原文直译“这件事”。">a</a></sup>，免得我来的时候，那些本应该使我喜乐的人使我忧伤，因为我深信你们大家以我的喜乐为你们大家的喜乐。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 7:12; 箴言 27:5–6; 利未记 19:17–18"> 我在极大的患难和内心的痛苦中，流了许多泪水写给你们，并不是要使你们忧伤，而是要你们知道我对你们怀有更多的爱。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 5:12–13; 加拉太书 4:12; 箴言 17:25"> 如果有人使人忧伤，他不是使我忧伤，而是在某种程度上使你们大家忧伤——我这样说，免得说得太严重。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 5:4–5; 提摩太前书 5:20; 哥林多后书 7:11"> 这样的人，受了大多数人的那惩罚已经够了。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 4:32; 加拉太书 6:1–2; 歌罗西书 3:13"> 所以，你们反而更要饶恕他、安慰他，免得他被过度的忧伤吞没了。</span>
<span className="v" id="v8" data-v="8" data-xref="犹大书 1:22–23; 加拉太书 6:1–2; 加拉太书 6:10"> 因此，我恳求你们向他证实你们的爱。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 10:6; 腓利门书 1:21; 腓立比书 2:22"> 其实我也为此写了信<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="信——辅助词语。">b</a></sup>，就是要知道你们经过考验的品德：你们是否在一切事上都顺从。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 20:23; 马太福音 18:18; 哥林多后书 5:20"> 你们在任何事上饶恕了谁，我也饶恕谁；实际上，我如果饶恕了什么，我所饶恕的，就是在基督面前为了你们的缘故而饶恕的，</span>
<span className="v" id="v11" data-v="11" data-xref="彼得前书 5:8; 以弗所书 6:11–12; 哥林多后书 11:3"> 免得被撒旦占了上风，因为我们不是不明白它的意图。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 16:8; 使徒行传 14:27; 歌罗西书 4:3"> 我为了基督的福音来到特罗阿斯的时候，虽然主为我开了门，</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 7:5–6; 哥林多后书 12:18; 提多书 1:4"> 我还是灵里不安，因为我没有见到我的弟兄提多。因此我向那里的人告别，往马其顿省去了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以弗所书 5:2; 罗马书 8:37; 哥林多后书 2:15–16"> 但是感谢神！他总是率领我们在基督里夸胜，并且藉着我们，在各地传扬因认识基督<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="基督——原文直译“他”。">c</a></sup>而有的香气。</span>
<span className="v" id="v15" data-v="15" data-xref="以弗所书 5:2; 哥林多前书 1:18; 以西结书 20:41"> 因为在神面前，无论在得救的人中间，还是在灭亡的人中间，我们都是基督的馨香：</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 3:5–6; 约翰福音 9:39; 彼得前书 2:7–8"> 对灭亡的人，我们是死亡的香气以至于死亡；对得救的人，我们是生命的香气以至于生命。对这些事，到底谁配得上呢？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 4:2; 哥林多后书 1:12; 彼得后书 2:1–3"> 实际上，我们不像许多人那样，用神的话语<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="神的话语——或译作“神的道”。">d</a></sup>来做生意；相反，我们是出于真诚、出于神，在神面前、在基督里讲话。</span>
</div>

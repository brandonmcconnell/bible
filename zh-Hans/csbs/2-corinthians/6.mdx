<span className="v" id="v2" data-v="2" data-xref="以赛亚书 49:8; 希伯来书 4:7; 希伯来书 3:13"> 因为他说：<br /><span className="pl pl-1">“在悦纳的时候，我垂听了你；</span><br /><span className="pl pl-1">在拯救的日子，我帮助了你。”</span><br />看哪！现在就是悦纳的时候；看哪！现在就是拯救的日子。</span>

<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="罗马书 14:13; 哥林多前书 9:12; 马太福音 17:27"> 我们不在任何事上给任何人跌倒的借口，免得这服事的工作被人挑剔；</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 12:10; 哥林多后书 4:8; 哥林多后书 11:27"> 反而在一切事上都证明自己是神的仆人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="仆人——或译作“执事”。">b</a></sup>：<br /><span className="pl pl-1">在极大的忍耐中，在各种患难、艰难、困苦中，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 11:23–25; 哥林多后书 11:27; 使徒行传 19:23–34"> <span className="pl pl-1">在鞭打、监禁、混乱中，</span><br /><span className="pl pl-1">在劳苦、失眠、饥饿中，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以弗所书 4:32; 歌罗西书 1:27; 加拉太书 5:22"> <span className="pl pl-1">在纯洁、知识、耐心、仁慈中，</span><br /><span className="pl pl-1">藉着圣灵，在不虚假的爱中，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 4:2; 提摩太后书 2:15; 以弗所书 6:11–20"> <span className="pl pl-1">在真理的话语中，在神的大能中，</span><br /><span className="pl pl-1">藉着右手左手的公义兵器，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 27:63; 彼得前书 4:14; 提摩太前书 4:10"> <span className="pl pl-1">藉着荣耀和羞辱，藉着坏名声和好名声；</span><br /><span className="pl pl-1">像是迷惑人的，却是真诚的；</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 4:10–11; 罗马书 8:36; 哥林多后书 1:8–10"> <span className="pl pl-1">像是人所不知的，却是人所共知的；</span><br /><span className="pl pl-1">像是快要死的，可是看哪，我们是活着的；</span><br /><span className="pl pl-1">像是受惩罚的，却是不被治死；</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 16:22; 哥林多后书 8:9; 启示录 2:9"> <span className="pl pl-1">像是忧伤的，却总是快乐；</span><br /><span className="pl pl-1">像是贫穷的，却使许多人富足；</span><br /><span className="pl pl-1">像是一无所有，却是样样都有。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 7:3–4; 腓立比书 1:8; 诗篇 119:32"> 哥林多人哪，我们对你们，口是坦率的，心是敞开的。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 7:2; 弥迦书 2:7; 腓立比书 1:8"> 你们并不是被我们压制了，而是被自己的情感压制了。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰三书 1:4; 约翰一书 3:18; 帖撒罗尼迦前书 2:11"> 所以你们要同样回报我们——我如同对儿女说——你们也当敞开！</span>
</div>
<div className="bp poetry">

<span className="v" id="v15" data-v="15" data-xref="列王纪上 18:21; 哥林多前书 10:20–21; 约翰一书 5:11–13"> 基督与彼列<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="彼列——指“撒旦”；是魔鬼撒旦的别名。">d</a></sup>有什么相融呢？信的与不信的有什么关系呢？</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 21:3; 出埃及记 29:45; 希伯来书 8:10"> 神的圣所与偶像有什么相同呢？要知道，我们<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="我们——有古抄本作“你们”。">e</a></sup>是永生神的圣所，正如神所说：<br /><span className="pl pl-1">“我将要在他们中间居住，在他们中间往来；</span><br /><span className="pl pl-1">我将要做他们的神，他们将要做我的子民。”</span><br /></span>

<span className="v" id="v18" data-v="18" data-xref="启示录 21:7; 约翰福音 1:12; 撒母耳记下 7:14"> <span className="pl pl-1">“我将要做你们的父亲，</span><br /><span className="pl pl-1">你们将要做我的儿女。</span><br /><span className="pl pl-1">这是主、全能者说的。”</span></span>

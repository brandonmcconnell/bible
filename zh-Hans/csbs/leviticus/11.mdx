<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西和亚伦，对他们说：</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 15:11; 利未记 11:11; 希伯来书 9:10"> “你们要吩咐以色列子民，地上一切动物中，可以吃的活物是这些：</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 2:10; 哥林多后书 6:17; 申命记 6:6–7"> 凡是分蹄、裂趾并且反刍的动物，都可以吃。</span>
<span className="v" id="v4" data-v="4"> 然而反刍的或分蹄的动物当中，这些不可以吃：<br /><span className="pl pl-1">骆驼，虽然反刍，却不分蹄，</span><br /><span className="pl pl-1">所以它对于你们是不洁净的；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 104:18; 箴言 30:26; 马太福音 7:26"> <span className="pl pl-1">岩狸，虽然反刍，却不分蹄，</span><br /><span className="pl pl-1">所以它对于你们是不洁净的；</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="申命记 14:7"> <span className="pl pl-1">兔子，虽然反刍，却不分蹄，</span><br /><span className="pl pl-1">所以它对于你们是不洁净的；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 66:17; 以赛亚书 65:4; 以赛亚书 66:3"> <span className="pl pl-1">猪，虽然分蹄、裂趾，却不反刍，</span><br /><span className="pl pl-1">所以它对于你们是不洁净的。</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 52:11; 歌罗西书 2:16; 希伯来书 9:10"> 不可吃它们的肉，也不可触碰它们的尸体；这些对于你们都是不洁净的。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="加拉太书 5:6; 雅各书 2:18; 使徒行传 20:21"> “水中的一切，可以吃的是这些：无论海里、河里，水中凡是有鳍有鳞的，都可以吃。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 29:27; 利未记 7:18; 诗篇 139:21–22"> 而无论海里、河里，一切水生的群居爬物、一切水里的活物中，凡是无鳍无鳞的，对于你们都是可憎之物。</span>
<span className="v" id="v11" data-v="11"> 这些对于你们是可憎的，你们不可吃它们的肉，并且要憎恶它们的尸体。</span>
<span className="v" id="v12" data-v="12"> 凡是水中无鳍无鳞的，对于你们都是可憎之物。</span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="约伯记 39:27–30; 耶利米书 4:22; 提多书 3:3"> “鸟类中，要憎恶的是这些，你们都不可吃，它们是可憎之物：<br /><span className="pl pl-1">老鹰、秃鹫、红头雕、</span></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">鹞鹰、小隼与其类，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 12:24; 列王纪上 17:6; 箴言 30:17"> <span className="pl pl-1">各种乌鸦与其类，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 34:11–15; 以弗所书 5:7–11; 以弗所书 2:2–3"> <span className="pl pl-1">鸵鸟、夜鹰、海鸥、苍鹰与其类，</span><br /></span>
<span className="v" id="v17" data-v="17"> <span className="pl pl-1">小鸮、鸬鹚、猫头鹰、</span><br /></span>
<span className="v" id="v18" data-v="18"> <span className="pl pl-1">白鸮、鹈鹕、鹗、</span></span>
<span className="v" id="v19" data-v="19"> <br /><span className="pl pl-1">白鹳、鹭鸶与其类，</span><br /><span className="pl pl-1">戴胜和蝙蝠。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="提摩太后书 4:10; 腓立比书 3:18–19; 利未记 11:23"> “凡是用四足行走、有翅膀的昆虫，对于你们都是可憎之物。</span>
<span className="v" id="v21" data-v="21"> 然而，各类用四足行走、有翅膀的昆虫中，脚上有曲腿、在地上跳的那种，你们可以吃。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 3:4; 马可福音 1:6; 出埃及记 10:4–5"> 可以吃的是这些：<br /><span className="pl pl-1">蝗虫与其类，蝻子与其类，</span><br /><span className="pl pl-1">蟋蟀与其类，蚱蜢与其类。</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 但其他各类有四足、有翅膀的昆虫，对于你们都是可憎之物。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 15:33; 以弗所书 2:1–3; 哥林多后书 6:17"> “以上这些会使你们不洁净，凡是触碰它们尸体的人，就不洁净直到傍晚；</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 15:5; 利未记 14:8; 民数记 31:24"> 凡是搬运它们尸体的人，都要洗自己的衣服，并且会不洁净直到傍晚。</span>
<span className="v" id="v26" data-v="26"> 凡是分蹄却不裂趾、不反刍的动物，对于你们都是不洁净的，任何触碰这些动物的人，都会不洁净。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 11:23; 利未记 11:20"> 各类四足行走的活物中，凡是趾行的，对于你们都是不洁净的，任何触碰它们尸体的人，都会不洁净直到傍晚；</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 11:24–25"> 搬运它们尸体的人，要洗自己的衣服，并且会不洁净直到傍晚。这些动物对于你们都是不洁净的。</span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="利未记 11:41–42; 提摩太后书 3:2–5; 诗篇 10:3"> “地上的群居爬物中，对于你们不洁净的是这些：<br /><span className="pl pl-1">鼹鼠，老鼠，蜥蜴与其类，</span><br /></span>
<span className="v" id="v30" data-v="30"> <span className="pl pl-1">壁虎，石龙子，守宫，沙蜥，蝘蜓。</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="利未记 11:24–25; 利未记 11:8"> 这些群居爬物对于你们都是不洁净的。凡是触碰它们死尸的人，都会不洁净直到傍晚。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 15:12; 提多书 3:5; 提多书 2:14"> 这些群居爬物的死尸掉在任何东西上，那东西就会不洁净，无论是木器，或是衣服、皮革、麻袋——任何用途的物件，都要放进水里，它会不洁净直到傍晚，之后就洁净了。</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 6:28; 利未记 15:12; 利未记 14:45"> 这些死尸掉进任何瓦器，瓦器里的东西全都会不洁净，你们要打碎那瓦器。</span>
<span className="v" id="v34" data-v="34" data-xref="提多书 1:15; 箴言 21:4; 箴言 21:27"> 瓦器里的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="瓦器里的——辅助词语。">a</a></sup>水沾上任何可以吃的食物，这食物就会不洁净；沾上任何器皿里任何可以喝的饮物，这饮物也会不洁净。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 15:12; 利未记 6:28; 利未记 11:33"> 这些尸体掉在任何物件上面，这物件就会不洁净，无论是火炉还是灶台，都要拆毁；这些都不洁净，对于你们是不洁净的；</span>
<span className="v" id="v36" data-v="36" data-xref="撒迦利亚书 13:1; 约翰福音 4:14"> 然而泉源或蓄水的水窖，仍是洁净的；但如果有人触碰那里面的尸体，他就会不洁净。</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前书 15:37; 彼得前书 1:23; 约翰一书 5:18"> 这些尸体掉在任何要播种的种子上的时候，那种子仍然是洁净的；</span>
<span className="v" id="v38" data-v="38"> 但如果种子上浇了水，而尸体掉在种子上面，那种子对于你们就是不洁净的。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="利未记 11:40; 利未记 11:24; 利未记 15:7"> “如果一只给你们食用的动物死了，触碰它尸体的人，会不洁净直到傍晚。</span>
<span className="v" id="v40" data-v="40" data-xref="利未记 22:8; 以西结书 44:31; 申命记 14:21"> 吃了这动物尸体的，要洗衣服，并且会不洁净直到傍晚。搬运这动物尸体的，也要洗衣服，并且会不洁净直到傍晚。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="利未记 11:29; 利未记 11:20; 利未记 11:23"> “凡是地上的群居爬物，都是可憎的，都不可吃。</span>
<span className="v" id="v42" data-v="42" data-xref="提多书 1:12; 以赛亚书 65:25; 哥林多后书 11:3"> 地上的各类群居爬物中，凡是肚腹爬行的、四足行走的，甚至多足的，你们都不可吃，因为它们是可憎之物。</span>
<span className="v" id="v43" data-v="43" data-xref="利未记 20:25; 利未记 11:41–42"> 你们不可因任何群居爬物使自己成为可憎的，不可使自己受玷污，或被它们玷污。</span>
<span className="v" id="v44" data-v="44" data-xref="出埃及记 20:2; 彼得前书 1:15–16; 利未记 19:2"> 要知道，我是耶和华你们的神，你们要使自己分别为圣，成为圣洁的，因为我是圣洁的。你们不可因任何地上活动的群居爬物玷污自己。</span>
<span className="v" id="v45" data-v="45" data-xref="利未记 11:44; 出埃及记 20:2; 出埃及记 6:7"> 我是耶和华，是我把你们从埃及地带了上来，为要作你们的神。所以你们要成为圣洁的，因为我是圣洁的。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="利未记 14:54; 利未记 15:32; 以西结书 43:12"> “以上是关于动物、鸟类、水中游动的一切活物和地上爬动的一切活物的条例，</span>
<span className="v" id="v47" data-v="47" data-xref="利未记 10:10; 以西结书 44:23; 罗马书 14:13–23"> 为要分别洁净与不洁净，分别可吃的活物与不可吃的活物。”</span>
</div>
</div>

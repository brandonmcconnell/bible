<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 6:17; 利未记 5:14–7; 利未记 6:25"> “赎愆祭的条例是这样：这祭是至圣的。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 1:5; 利未记 6:25; 利未记 1:11"> 要在宰杀燔祭牲的地方宰杀赎愆祭牲，祭司要把祭牲的血洒在祭坛四壁。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 29:13; 利未记 3:15–16; 诗篇 51:6"> 祭牲的全部脂肪都要献上：肥尾巴，覆盖内脏的脂肪，</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 3:4"> 两个肾脏和肾脏上靠近腰部的脂肪，以及肾脏上方的肝叶，都要取下来。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 1:13; 加拉太书 5:24; 彼得前书 4:1–2"> 祭司要在祭坛上把这些烧献为烟，作为火祭献给耶和华；这是赎愆祭。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 6:29; 民数记 18:9–10; 利未记 2:3"> 祭司家中所有的男丁都可以吃，这祭物必须在神圣的地方吃，这是至圣的。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="利未记 6:25–26; 利未记 14:13; 哥林多前书 9:13"> “赎罪祭像赎愆祭，有同一个条例：祭物要归于那用它行赎罪礼的祭司。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 4:11; 出埃及记 29:14; 罗马书 13:14"> 祭司为人献上燔祭的时候，所献上的燔祭牲的皮要归于那祭司，这是属于他的。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 18:9; 以西结书 44:29; 利未记 2:10"> 所有在炉中烘烤的素祭，所有在煎盘里、在烤盘上制作的素祭，都要归于那献祭的祭司。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 8:14; 出埃及记 16:18"> 所有调了油的或者干的素祭，都要归于亚伦的所有子孙，彼此均分。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="利未记 22:18–21; 以西结书 45:15; 利未记 3:1–17"> “献给耶和华的平安祭的条例是这样：</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 2:4; 民数记 6:15; 彼得前书 2:5"> 如果是为感谢而献，就要与感谢的祭物一起献上调了油的无酵饼，还有抹上油的无酵薄饼，以及细面粉调了油揉拌做成的饼。</span>
<span className="v" id="v13" data-v="13" data-xref="阿摩司书 4:5; 利未记 23:17; 马太福音 13:33"> 要把祭物与有酵饼，连同为感谢所献的平安祭一起献上。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 18:19; 出埃及记 29:27–28; 民数记 18:24–32"> 要从各样祭物的饼中各取一份，作为供物献给耶和华，这份要归于那洒平安祭之血的祭司。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 22:29–30"> 为感谢所献的平安祭肉，要在献祭的当天吃掉，一点也不可留到次日早晨。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="利未记 19:5–8; 申命记 12:6; 诗篇 116:14"> “如果所献的祭物是作还愿祭或甘心祭，要在献上祭物的当天吃；剩下的部分可以第二天吃。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 12:10; 何西阿书 6:2; 哥林多前书 15:4"> 但此后剩下的祭肉，到了第三天就要用火烧掉。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 19:7–8; 利未记 11:41; 民数记 18:27"> 到第三天如果平安祭的肉还是被人吃了，那献祭的人就不蒙悦纳，所献的也无效；这祭肉成了不洁之物，吃了的人要承担自己的罪责。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 11:41; 提多书 1:15; 使徒行传 10:15–16"> “祭肉接触了任何不洁之物，都不可吃，要用火烧掉。除此以外的祭肉，凡是洁净的人都可以吃；</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 15:2–33; 创世记 17:14; 利未记 22:3–7"> 如果有人不洁净，却吃了属于耶和华的平安祭的肉，这人就要从民中被剪除。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 12:1–59; 利未记 11:20; 以西结书 4:14"> 如果有人触碰了任何不洁之物——无论是人的污秽还是不洁净的动物，或是任何不洁净的可憎之物——然后吃了献给耶和华的平安祭的肉，这人也要从民中被剪除。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 耶和华指示摩西说：</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 3:16–17; 利未记 17:6; 撒母耳记上 2:15–17"> “你要吩咐以色列子民：公牛、绵羊或山羊的任何脂肪，你们都不可吃。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 22:31; 利未记 17:15; 利未记 22:8"> 自然死去动物的脂肪，或者被咬死动物的脂肪，可作其他的用途，但你们绝不可吃。</span>
<span className="v" id="v25" data-v="25"> 任何人吃了献给耶和华为火祭的祭牲的脂肪，这吃了的人就要从民中被剪除。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 9:4; 利未记 3:17; 使徒行传 15:20"> 在你们居住的任何地方，你们任何血都不可吃，无论是鸟类的血，还是动物的血。</span>
<span className="v" id="v27" data-v="27" data-xref="希伯来书 10:29; 利未记 7:20–21; 利未记 7:25"> 无论什么人，吃了任何血，这人就要从民中被剪除。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 耶和华指示摩西说：</span>
<span className="v" id="v29" data-v="29" data-xref="歌罗西书 1:20; 约翰一书 1:7; 利未记 3:1–17"> “你要吩咐以色列子民：那向耶和华献上平安祭的人，要从他的平安祭物中取来祭物献给耶和华。</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 6:20; 利未记 3:9; 利未记 3:14"> 他要亲手带来耶和华的火祭；要把脂肪与胸肉一起带来，把胸肉作为摇献祭物在耶和华面前摇一摇。</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 3:5; 利未记 3:11; 利未记 3:16"> 祭司要在祭坛上把脂肪烧献为烟，胸肉归属亚伦和他的子孙。</span>
<span className="v" id="v32" data-v="32" data-xref="民数记 6:20; 利未记 7:34; 利未记 9:21"> 要把你们平安祭物的右腿作为供物归给祭司；</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 26:1–46; 利未记 6:1–30; 利未记 7:3"> 亚伦子孙中献上平安祭的血和脂肪的祭司，要得这右腿作为他的份。</span>
<span className="v" id="v34" data-v="34" data-xref="民数记 18:18–19; 利未记 10:14–15; 出埃及记 29:9"> 因为我已经从以色列子孙的平安祭物中，取了摇献祭的胸肉和供物的大腿，赐给祭司亚伦和他的子孙，作为他们从以色列子孙所得永远的份例。”</span>
<span className="v" id="v35" data-v="35" data-xref="约翰一书 2:20; 约翰一书 2:27; 民数记 18:7–19"> 这是耶和华的火祭中亚伦受膏的份，以及他子孙受膏的份；在摩西把他们献给耶和华作祭司的那天，</span>
<span className="v" id="v36" data-v="36" data-xref="利未记 8:12; 利未记 8:30; 出埃及记 40:13–15"> 就是摩西膏立他们的那天，耶和华指示要从以色列子孙的祭物中赐给他们，作他们世世代代永远的份例。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="出埃及记 29:1; 利未记 1:1–6; 利未记 6:9–18"> 以上是燔祭、素祭、赎罪祭、赎愆祭、圣职祭和平安祭的条例，</span>
<span className="v" id="v38" data-v="38" data-xref="利未记 1:1–2"> 是耶和华在西奈山指示摩西的，那天耶和华在西奈旷野指示以色列子民，要向耶和华献上他们的祭物。</span>
</div>

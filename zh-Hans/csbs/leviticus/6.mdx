<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> <sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="此章在马索拉文本为5:20至6:23。">a</a></sup>耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 3:9; 使徒行传 5:4; 利未记 5:15"> “如果有人犯罪，不忠于耶和华，在所交托的寄存物、抵押物上欺骗邻人，或者抢夺邻人，欺压邻人，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 23:4; 利未记 19:12; 出埃及记 22:9–11"> 或者捡到了失物却否认并且起假誓——在人们常做的任何一件事上犯了罪；</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 18:18; 阿摩司书 3:10; 利未记 5:3–4"> 当他犯罪而有了罪责时，他要归还所抢夺的，或欺压得来的，或交托他的寄存物，或捡到的失物，</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 5:16; 路加福音 19:8; 民数记 5:7–8"> 或起假誓所得到的任何东西。他要全数偿还，并且加上五分之一，在承担罪责的那天都交给物主。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 5:15; 利未记 5:18; 以赛亚书 53:10–11"> 他还要把赎愆祭带给耶和华，就是羊群中一只无瑕疵的公绵羊，或等价的银子，作为赎愆祭交给祭司。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 4:26; 约翰一书 1:9; 约翰一书 2:1–2"> 祭司要在耶和华面前为他赎罪，他所做的任何一件事使他有了罪责，都必得赦免。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 耶和华指示摩西说：</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 6:12–13; 民数记 28:3; 出埃及记 29:38–42"> “你要吩咐亚伦和他的子孙说，这是燔祭的条例：燔祭要一整夜留在祭坛的炉床上直到早晨；祭坛的火要一直燃烧。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 28:39–43; 利未记 16:4; 利未记 1:13"> 祭司要穿上细麻衣袍，贴身穿上细麻裤子，要把祭坛上烧完燔祭的灰烬除掉，放在祭坛旁边。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 4:12; 以西结书 44:19; 希伯来书 13:11–13"> 然后脱下这些衣服，穿上别的衣服，把灰烬带到营地外洁净的地方。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 9:24; 出埃及记 29:38–42; 尼希米记 13:31"> 祭坛上的火要一直燃烧，不可熄灭。祭司要每天早晨在其上添加木柴燃烧，然后摆上燔祭，在其上把平安祭的脂肪烧献为烟。</span>
<span className="v" id="v13" data-v="13"> 火在祭坛上要一直燃烧，不可熄灭。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 15:4; 利未记 2:1–2; 约翰福音 6:32"> “这是素祭的条例：亚伦的子孙要在祭坛前在耶和华面前献上素祭。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 2:2; 利未记 2:9"> 祭司要从素祭中，就是从素祭的细面粉和油中捧出一把，连同素祭上的所有乳香，作为素祭的记念部分在祭坛上烧献为烟，作馨香之气献给耶和华。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 44:29; 利未记 2:3; 利未记 10:12–13"> 亚伦和他子孙要吃剩下的素祭，要做成无酵饼在神圣的地方吃，就是在会幕的院子里吃。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 2:3; 利未记 2:11; 民数记 18:9–10"> 不可带着酵烘烤；这是我从我的火祭中赐给他们的份，是像赎罪祭和赎愆祭一样的至圣物。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 6:29; 民数记 18:10; 哈该书 2:12–14"> 亚伦子孙中所有的男丁都可以吃，这是耶和华的火祭中，给你们世世代代永远的份例；凡是触碰这些火祭的，都会成为圣洁的。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 耶和华指示摩西说：</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 29:2; 出埃及记 16:36; 利未记 2:1–16"> “亚伦和他的子孙，在被膏立的那天要献给耶和华以下祭物：十分之一伊法<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="十分之一伊法——相当于2.2公升。1伊法=22公升。">b</a></sup>的细面粉，作常献的素祭，早晨献一半，傍晚献一半；</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 2:5; 利未记 7:9; 历代志上 9:31"> 要在烤盘上用油揉拌制作，拿来烤好做成碎饼的素祭献上，作馨香之气献给耶和华。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 29:22–25; 以赛亚书 53:10; 利未记 8:21"> 亚伦子孙中接续他作受膏祭司的，要献上这素祭，这是永远的定例，要把它完全烧献给耶和华。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 2:10; 利未记 6:16–17"> 祭司的这一切素祭都是全烧祭，不可以吃。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 耶和华指示摩西说：</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 4:24; 利未记 1:11; 利未记 1:3"> “你要吩咐亚伦和他的子孙说，赎罪祭的条例是这样：要在宰杀燔祭牲的地方，在耶和华面前宰杀赎罪祭牲；这是至圣的。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 10:17–18; 以西结书 44:28–29; 何西阿书 4:8"> 献上赎罪祭的祭司要吃这祭物，要在会幕的院子，就是在神圣的地方吃。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 29:37; 哈该书 2:12; 哥林多后书 7:1"> 凡是触碰这祭物之肉的，都会成为圣洁的。如果有祭物的血溅在衣服上，就要在神圣的地方洗掉那溅上的血。</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 11:33; 利未记 15:12; 希伯来书 9:9–10"> 煮这祭物的瓦器要打碎；如果是用铜器煮的，之后要擦净铜器，用水冲洗。</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 6:25; 利未记 6:17–18; 民数记 18:10"> 祭司家中所有的男丁都可以吃，这是至圣物。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 10:18; 利未记 16:27–28; 希伯来书 13:11"> 任何赎罪祭牲，如果它的血被带进会幕，用来在圣所里赎罪，这赎罪祭牲就不可以吃，要用火把它烧掉。</span>
</div>
</div>

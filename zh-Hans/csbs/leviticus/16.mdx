<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 10:1–2"> 亚伦的两个儿子上前到耶和华面前时死了；他们死后，耶和华对摩西说话。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 30:10; 列王纪上 8:10–12; 希伯来书 10:19–20"> 耶和华对摩西说：“你要吩咐你哥哥亚伦，他不可随时随意进入幔子内的圣所，到见证柜上的施恩座前，以免他死亡，因为我要在施恩座上的云中显现。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="利未记 4:3; 希伯来书 9:24–25; 希伯来书 9:7"> “亚伦要这样进入圣所：他要带一头公牛作赎罪祭，一只公绵羊作燔祭；</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 28:39–43; 以西结书 44:17–18; 出埃及记 30:20"> 要穿上细麻圣袍，贴身穿上细麻裤子，束上细麻腰带，戴上细麻顶冠。这些是圣衣，他要用水洗身，然后穿上它们。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 29:21; 利未记 8:2; 以斯拉记 6:17"> 他还要从以色列会众那里带来两只公山羊作赎罪祭，一只公绵羊作燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="利未记 9:7; 希伯来书 9:7; 希伯来书 7:27"> “亚伦要献上他的赎罪祭公牛，为自己和家人赎罪。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 12:1; 利未记 4:4; 马太福音 16:21"> 然后牵来那两只公山羊，让它们站在会幕入口耶和华面前。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 1:23–26; 约拿书 1:7; 箴言 16:33"> 亚伦要为那两只公山羊抽签，一支签是要归耶和华，一支签是要作除罪羊<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="除罪羊——或译作“离去的羊”；原文音译为“阿撒泻勒”。本章下同。">a</a></sup>。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 4:27–28; 使徒行传 2:23"> 亚伦要把那只抽中签归耶和华的公山羊献为赎罪祭；</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 2:2; 利未记 16:21–22; 希伯来书 9:23–24"> 至于那只抽中签作除罪羊的公山羊，要让它活着站在耶和华面前，用于赎罪，要释放它到旷野作除罪羊。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="利未记 16:6; 希伯来书 7:27; 希伯来书 9:7"> “亚伦要献上他的赎罪祭公牛，为自己和家人赎罪，把那头为自己作赎罪祭的公牛宰杀了，</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 10:1; 出埃及记 30:34–38; 启示录 8:3–4"> 然后拿来香炉，盛满耶和华面前祭坛上的火炭，并且带着一满捧细碎的芬芳香，拿进幔子内。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 25:21; 出埃及记 30:1; 出埃及记 30:7–8"> 他要在耶和华面前把香放在火上，使香的烟云遮掩见证柜上的施恩座，以免他死亡。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 9:25; 利未记 4:5–6; 希伯来书 9:13"> 他要取一些公牛的血，用手指弹洒在施恩座朝东那面，再用手指把一些血向施恩座前面弹洒七次。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="希伯来书 9:7; 希伯来书 2:17; 希伯来书 9:3"> “接着，他要把百姓的那只赎罪祭公山羊宰杀了，把血带进幔子内，要像处理公牛的血那样处理羊的血，把血弹洒在施恩座上和施恩座前面。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 9:22–23; 利未记 16:18; 以西结书 45:18–19"> 他要这样为圣所行赎罪礼，除去以色列子民一切罪恶所带来的污秽和过犯。他也要为会幕照样做，因为会幕安置在他们那里，在他们的污秽当中。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 53:6; 路加福音 1:10; 出埃及记 34:3"> 当亚伦进入圣所行赎罪礼时，任何人都不可留在会幕中，直到他出来。他为自己和家人、为以色列全体会众行了赎罪礼，</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 4:7; 希伯来书 5:7–8; 利未记 16:16"> 之后要出来，到耶和华面前的祭坛那里，为祭坛行赎罪礼。他要取一些公牛的血和公山羊的血，抹在祭坛四围的犄角上，</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 13:1; 以西结书 43:18–22"> 并且用手指把一些血向祭坛弹洒七次。这样，他就洁净了祭坛，使祭坛分别为圣，除去了以色列子民带来的污秽。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="利未记 16:16; 以西结书 45:20; 歌罗西书 1:20"> “亚伦为圣所、会幕和祭坛完成了赎罪礼之后，就要把那只活的公山羊带上来。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 53:6; 哥林多后书 5:21; 以斯拉记 10:1"> 亚伦要双手按在那只活的公山羊头上，在它身上承认以色列子民的一切罪孽和过犯，无论什么罪恶，都归到那只公山羊头上，然后藉着指定的人把它释放到旷野去。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 9:28; 以赛亚书 53:11–12; 约翰福音 1:29"> 这样，那只公山羊背负以色列人的一切罪孽到荒芜之地，那人就要在旷野里把公山羊释放了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以西结书 44:19; 以西结书 42:14; 利未记 16:4"> “然后亚伦要回到会幕，把他进圣所时穿上的那些细麻圣衣脱下，留在那里。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 16:3–5; 希伯来书 10:19–22; 出埃及记 28:4–14"> 他要在神圣的地方用水洗身，穿上他的衣服，然后出来，把自己的燔祭和百姓的燔祭献上，为自己和百姓赎罪。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 29:13; 利未记 4:8–10; 利未记 16:6"> 他要把赎罪祭的脂肪在祭坛上烧献为烟。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 16:10; 希伯来书 7:19; 民数记 19:21"> 那释放除罪羊的人，要洗衣服，用水洗身，之后才可以进入营地。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 4:21; 利未记 6:30; 利未记 4:11–12"> 至于赎罪祭公牛和赎罪祭公山羊，它们的血已经带进了圣所赎罪，它们要被搬运到营地外，皮、肉和粪便都要用火烧掉。</span>
<span className="v" id="v28" data-v="28"> 焚烧这些东西的人也要洗衣服，用水洗身，之后才可以进入营地。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 58:3; 民数记 29:7; 出埃及记 20:10"> “以下是你们永远的律例：每年的七月十日，你们要刻苦己心，无论是本族人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="本族人——原文直译“本地人”。">b</a></sup>还是寄居在你们中间的外人，任何工作都不可做。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 33:8; 诗篇 51:2; 以弗所书 5:26"> 因为在这一天，要为你们行赎罪礼，使你们洁净；你们必须在耶和华面前得洁净，脱离你们一切的罪恶。</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 23:32; 以赛亚书 58:5; 利未记 25:4"> 这是你们完全安息的安息日，你们要刻苦己心；这是永远的律例。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 16:4; 出埃及记 29:29–30; 利未记 4:5"> 那被膏立接续他父亲承接圣职的祭司，要行赎罪礼，他要穿上细麻圣衣，</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 16:16; 利未记 16:24; 利未记 16:6"> 为至圣所行赎罪礼，为会幕和祭坛行赎罪礼，也为祭司和全体会众行赎罪礼。</span>
<span className="v" id="v34" data-v="34" data-xref="希伯来书 9:7; 希伯来书 9:25; 出埃及记 30:10"> 这要作为你们永远的律例，每年一次为以色列子民赎他们一切的罪。”<br />耶和华所指示摩西的，他都遵行了。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 6:7; 利未记 11:44; 以西结书 20:5"> “你要吩咐以色列子民，对他们说：我是耶和华你们的神。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 20:23; 出埃及记 23:24; 彼得前书 4:2–4"> 你们不可效法你们曾居住的埃及地的行为，也不可效法我将带你们去的迦南地的行为；你们不可随从他们的习俗。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 18:2; 利未记 18:26; 以西结书 20:19"> 你们要实行我的法规，谨守遵行我的律例。我是耶和华你们的神。</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 10:5; 以西结书 20:11; 加拉太书 3:12"> 你们要遵守我的律例和法规；人若遵行这些，就必因此而活。我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="利未记 20:17–21; 利未记 18:7–19; 利未记 20:11–12"> “任何人都不可亲近自己的任何血亲，裸露她的下体。我是耶和华。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 20:11; 以西结书 22:10; 利未记 18:8–16"> 你不可裸露你母亲的下体，那是你父亲的下体，她是你的母亲，你不可裸露她的下体。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 20:11; 哥林多前书 5:1; 申命记 27:20"> 也不可裸露你父亲妻妾的下体，那是你父亲的下体。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 20:17; 申命记 27:22; 以西结书 22:11"> 不可裸露你姐妹的下体，无论她是你父亲的女儿还是你母亲的女儿，是家里出生的还是外面出生的。</span>
<span className="v" id="v10" data-v="10"> 不可裸露你孙女或外孙女的下体，因为那是裸露你自己的下体。</span>
<span className="v" id="v11" data-v="11"> 不可裸露你父亲妻妾的女儿的下体，她是你父亲所生的，是你的姐妹。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 20:19; 出埃及记 6:20"> 不可裸露你姑母的下体，她是你父亲的血亲。</span>
<span className="v" id="v13" data-v="13"> 不可裸露你姨母的下体，因为她是你母亲的血亲。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 20:20"> 不可亲近你父亲兄弟的妻子，裸露她的下体<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="不可亲近你父亲兄弟的妻子，裸露她的下体——原文直译“不可裸露你父亲兄弟的下体，不可亲近他的妻子”。">a</a></sup>，她是你的伯母叔母。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 20:12; 创世记 38:26; 以西结书 22:11"> 不可裸露你儿媳的下体，她是你儿子的妻子，你不可裸露她的下体。</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 25:5; 利未记 20:21; 马太福音 22:24"> 不可裸露你兄弟妻子的下体，那是裸露你兄弟的下体。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 20:14; 阿摩司书 2:7; 申命记 27:23"> 不可既裸露一个妇女的下体，又裸露她女儿的下体，也不可娶她的孙女或外孙女，裸露她们的下体；她们是骨肉之亲，你这样做是丑恶的。</span>
<span className="v" id="v18" data-v="18" data-xref="玛拉基书 2:15; 创世记 30:15; 创世记 29:28"> 不可在妻子还活着的时候，又娶她的姐妹裸露她的下体，以致她们成为对头。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="利未记 20:18; 利未记 15:24; 以西结书 22:10"> “不可亲近在经期不洁的妇女，裸露她的下体。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 20:14; 哥林多前书 6:9; 希伯来书 13:4"> 不可与你邻人的妻子行淫，以致玷污自己。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命记 12:31; 利未记 20:2–5; 申命记 18:10"> “不可把你的儿女经火<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="火——辅助词语。">b</a></sup>献给摩洛，不可亵渎你神的名。我是耶和华。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 20:13; 罗马书 1:26–27; 哥林多前书 6:9"> 不可与男人同寝，就像与女人同寝那样；这是可憎的行为。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 22:19; 利未记 20:15–16; 利未记 20:12"> 不可与任何动物交合，以致玷污自己；女人也不可亲近<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="亲近——原文直译“站在……前面”。">c</a></sup>动物与它交合；这是违反天性的事。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="申命记 18:12; 利未记 18:30; 利未记 20:22–23"> “你们不可在这一切事上玷污自己。因为我将要在你们面前驱逐的那些民族，就是在这一切事上玷污了自己，</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 18:28; 利未记 20:22–23; 耶利米书 2:7"> 连那地也被玷污了，所以我追究那地上的罪孽，那地就把其中的居民吐出来。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 18:5; 利未记 17:10; 利未记 18:30"> 你们务必谨守我的律例和法规，无论本族人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="本族人——原文直译“本地人”。">d</a></sup>还是寄居在你们中间的外人，都不可做其中任何一件可憎之事。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 36:14; 利未记 18:24; 申命记 23:18"> 因为在你们之前那地的人，做了这一切可憎之事，地就被玷污了。</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 3:16; 利未记 20:22; 利未记 18:25"> 所以，不可让这地因你们玷污了它而把你们吐出来，就像吐出你们之前的民族那样。</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 20:6; 出埃及记 12:15; 利未记 17:10"> 要知道，任何人做了其中任何一件可憎之事，都必从民中被剪除。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 20:23; 申命记 18:9–12; 利未记 22:9"> 你们要谨守我的吩咐，不再效法你们之前那些人所行的可憎习俗；你们不可因他们的习俗而玷污自己。我是耶和华你们的神。”</span>
</div>
</div>

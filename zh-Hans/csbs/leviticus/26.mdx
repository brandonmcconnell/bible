<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 19:4; 申命记 27:15; 民数记 33:52"> “你们不可为自己制造虚无的偶像，不可为自己竖立雕像或神柱，也不可在你们的地上安放石雕，向它下拜；我是耶和华你们的神。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 19:30"> 你们要谨守我的安息日，要敬畏我的圣所。我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 1:19; 申命记 11:13–15; 申命记 28:1–14"> “如果你们遵从我的律例，谨守遵行我的诫命，</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 8:12; 诗篇 67:6; 利未记 25:21"> 我必按时给你们赐下雨水，使土地供应出产，田野的树木结出果实。</span>
<span className="v" id="v5" data-v="5" data-xref="阿摩司书 9:13; 约珥书 2:26; 约珥书 2:19"> 你们打谷会持续到采收葡萄时，采收葡萄会持续到撒种时。你们必有粮吃得饱足，在自己的地上安然居住。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 35:9; 西番雅书 3:13; 诗篇 147:14"> 我要赐平安在这地上，你们躺卧无人惊吓。我要使恶兽从那地断绝，刀剑必不会经过你们境内。</span>
<span className="v" id="v7" data-v="7"> 你们将追赶仇敌，他们必在你们面前倒在刀下。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 23:10; 申命记 28:7; 申命记 32:30"> 你们将五人追赶百人，百人追赶万人，仇敌必在你们面前倒毙在刀剑之下。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 17:6–7; 尼希米记 9:23; 以西结书 16:62"> “我必眷顾你们，使你们生养增多；我必确立我与你们的约。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 25:22; 列王纪下 19:29; 路加福音 12:17"> 你们还吃着储藏的陈粮，就要为新的而把陈的清除。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 25:8; 启示录 21:3; 出埃及记 29:45"> 我要把我的帐幕安设在你们中间，我的心不会厌恶你们。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 6:16; 耶利米书 30:22; 耶利米书 7:23"> 我要行走在你们中间；我要作你们的神，你们要作我的子民。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 34:27; 利未记 25:38; 诗篇 116:16"> 我是耶和华你们的神：是我把你们从埃及地领了出来，使你们不再作他们的奴隶；是我打碎了你们的轭套，使你们能昂首而行。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命记 28:15–68; 利未记 26:18; 耶利米书 17:27"> “但如果你们不听从我，不遵行这一切诫命，</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 17:15; 申命记 31:16; 撒迦利亚书 7:11–13"> 如果你们厌弃我的律例，如果你们心中厌恶我的法规，不遵行我的一切诫命，而违背我的约，</span>
<span className="v" id="v16" data-v="16" data-xref="约伯记 31:8; 耶利米书 5:17; 弥迦书 6:15"> 我就要如此对付你们：我要指派惶恐临到你们，必有痨病和热病使你们眼睛衰竭、生命耗尽。你们将徒然播种，因为你们的仇敌要吃掉它。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 17:10; 箴言 28:1; 诗篇 53:5"> 我要对你们翻脸，你们将败在仇敌面前，恨你们的人要辖制你们；虽无人追赶，你们也将逃跑。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未记 26:21; 利未记 26:28; 利未记 26:24"> “如果这样你们还不听从我，我就要因你们的罪，加重七倍管教你们。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 28:23; 列王纪上 17:1; 但以理书 4:37"> 我将摧毁你们所夸耀的势力，使你们的天空如铁，土地如铜。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 127:1; 申命记 11:17; 以赛亚书 49:4"> 你们必徒然耗尽力气，你们的土地不供应出产，地上的树木也不结果实。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="利未记 26:18; 利未记 26:27"> “你们如果继续敌对我，不愿意听从我，我必照着你们的罪，加重七倍打击你们。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 14:15; 申命记 32:24; 士师记 5:6"> 我要派出田野的走兽到你们中间，它会使你们丧掉儿女，灭绝你们的牲畜，使你们人数减少，道路荒凉。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="耶利米书 5:3; 耶利米书 2:30; 阿摩司书 4:6–12"> “如果经过这些事，你们还不接受我的管教，继续敌对我，</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 18:26; 撒母耳记下 22:27; 约伯记 9:4"> 我也必继续敌对你们；我甚至要因你们的罪而七倍打击你们。</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 14:12; 以西结书 5:17; 耶利米书 29:17–18"> 我要使刀剑临到你们，因你们背约而施行报复。当你们聚拢到城里，我就降瘟疫在你们中间，你们也必被交在仇敌手中。</span>
<span className="v" id="v26" data-v="26" data-xref="弥迦书 6:14; 以赛亚书 3:1; 诗篇 105:16"> 当我断绝你们的粮食供应时，十个女人将用一个火炉为你们烤饼，然后按定量称了饼返回给你们，你们吃了却吃不饱。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="利未记 26:24; 利未记 26:21"> “如果经过这些事，你们还不听从我，继续敌对我，</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 59:18; 耶利米书 21:5; 以赛亚书 66:15"> 我也在怒火中继续敌对你们，甚至因你们的罪而七倍管教你们。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 5:10; 耶利米哀歌 4:10; 马太福音 24:19"> 你们将要吃自己儿子的肉，也要吃自己女儿的肉。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 23:20; 以赛亚书 27:9; 以西结书 6:13"> 我要拆毁你们的高坛，砍倒你们的香坛，把你们的尸体扔在你们偶像的残骸上；我的心必厌恶你们。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米记 2:3; 耶利米哀歌 1:10; 希伯来书 10:26"> 我要使你们的城镇变成废墟，使你们的众圣所变得荒凉；我也不会再闻你们的馨香之气。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 9:11; 耶利米书 19:8; 耶利米书 18:16"> 我要使那地荒凉，甚至那些来居住在你们地上的仇敌，也会因此而震惊。</span>
<span className="v" id="v33" data-v="33" data-xref="撒迦利亚书 7:14; 以西结书 20:23; 申命记 28:64–66"> 我要把你们分散在列国中，还要拔出刀剑追赶你们。你们的土地将成为荒场，你们的城将变为废墟。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="历代志下 36:21; 利未记 26:43; 利未记 25:2–4"> “这样，当你们在仇敌之地，而这地荒凉的整个期间，这地就可以补休它的安息。那时，这地将得享安息，补休它的安息年。</span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 24:5–6; 罗马书 8:22"> 这地必在它所有荒凉的日子得享安息，是你们在这里居住时，这地在你们的安息年中从来没有享受过的安息。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以西结书 21:7; 以赛亚书 30:17; 利未记 26:17"> “至于你们当中残留的人，我要使他们在仇敌之地心中恐慌，甚至风吹树叶的声音也会追赶他们。他们逃跑如逃避刀剑，虽无人追赶，也会仆倒。</span>
<span className="v" id="v37" data-v="37" data-xref="约书亚记 7:12–13; 士师记 2:14; 耶利米书 37:10"> 虽无人追赶，他们却要像面对刀剑那样彼此绊倒；你们在仇敌面前必站立不住。</span>
<span className="v" id="v38" data-v="38" data-xref="申命记 28:48; 以赛亚书 27:13; 耶利米书 42:17–18"> 你们将在列国中灭亡，仇敌之地会吞灭你们。</span>
<span className="v" id="v39" data-v="39" data-xref="以西结书 4:17; 以西结书 24:23; 以西结书 33:10"> 你们当中残留的人，将在仇敌之地因自己的罪孽而衰亡，也因自己祖先的罪孽随同他们衰亡。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="箴言 28:13; 尼希米记 9:2–5; 约翰一书 1:8–10"> “不过，当他们承认自己的罪孽和他们祖先的罪孽——他们对我不忠，继续敌对我，</span>
<span className="v" id="v41" data-v="41" data-xref="以西结书 44:7; 历代志下 32:26; 历代志下 12:6–7"> 我也继续敌对他们，把他们带到仇敌之地——如果那时他们未受割礼的心谦卑下来，并且偿清了自己的罪债，</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 106:45; 出埃及记 6:5; 以西结书 16:60"> 我必记念我与雅各的约，也记念我与以撒的约、我与亚伯拉罕的约，并且顾念这地。</span>
<span className="v" id="v43" data-v="43" data-xref="罗马书 8:7; 利未记 26:15; 约翰福音 7:7"> 这地因他们而被遗弃，却在荒凉无人的时候补休了安息。他们要偿清自己的罪债，因为他们厌弃我的法规，他们的心厌恶我的律例。</span>
<span className="v" id="v44" data-v="44" data-xref="罗马书 11:2; 尼希米记 9:31; 申命记 4:29–31"> 即使是这样，当他们在仇敌之地时，我也没有厌弃他们，没有厌恶他们，使他们灭绝，没有废除我与他们所立的约，因为我是耶和华他们的神。</span>
<span className="v" id="v45" data-v="45" data-xref="利未记 25:38; 以西结书 20:22; 以西结书 20:9"> 我必为他们的缘故记念先前<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="先前——或译作“先祖”。">a</a></sup>的约，我在列国眼前把他们从埃及地领了出来，为要作他们的神。我是耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="利未记 27:34; 申命记 12:1; 申命记 6:1"> 以上是耶和华在西奈山，在他和以色列子民之间，藉着摩西所立定的律例、法规和训诲。</span>
</div>

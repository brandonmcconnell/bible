<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="阿摩司书 3:7; 利未记 13:1; 利未记 11:1"> 耶和华指示摩西和亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 5:2; 撒母耳记下 3:29; 利未记 22:4"> “你们要吩咐以色列子民，对他们说：凡是身患漏症的人，他就因这漏症不洁净了。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 23:20; 以西结书 16:26; 利未记 12:3"> 他因漏症而不洁净的情况如下：无论身体流出泄漏物，还是身体封闭了泄漏物，这些都使他不洁净。</span>
<span className="v" id="v4" data-v="4" data-xref="提多书 1:15; 以弗所书 5:11; 哥林多前书 15:33"> 漏症患者所躺卧的任何床铺，都不洁净；所坐上的任何物件，也都不洁净。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 11:25; 利未记 16:26; 利未记 17:15"> 触碰他床铺的人，要洗衣服，用水洗身，并且会不洁净直到傍晚。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 4:8; 以赛亚书 1:16"> 坐上那漏症患者所坐物件的人，要洗衣服，用水洗身，并且会不洁净直到傍晚。</span>
<span className="v" id="v7" data-v="7"> 触碰漏症患者身体的人，要洗衣服，用水洗身，并且会不洁净直到傍晚。</span>
<span className="v" id="v8" data-v="8" data-xref="犹大书 1:4; 彼得后书 2:1–3; 以赛亚书 1:16"> 如果漏症患者吐唾沫在一个洁净的人身上，这人就要洗衣服，用水洗身，并且会不洁净直到傍晚。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 31:34"> 漏症患者骑上的任何鞍子，都会不洁净。</span>
<span className="v" id="v10" data-v="10" data-xref="雅各书 4:8; 诗篇 26:6; 利未记 15:8"> 凡是触碰他身下任何东西的人，都会不洁净直到傍晚；拿起这些东西的人，要洗衣服，用水洗身，并且会不洁净直到傍晚。</span>
<span className="v" id="v11" data-v="11"> 漏症患者没有用水洗手而触碰了任何人，这人就要洗衣服，用水洗身，并且会不洁净直到傍晚。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 6:28; 利未记 11:32–33; 哥林多后书 5:1"> 漏症患者所触碰的瓦器要打碎，木器都要用水冲洗。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未记 14:8; 利未记 8:33; 利未记 15:28"> “当漏症患者的漏症得洁净了，他还要为自己得洁净数算七天，然后洗衣服，用活水洗身，这样他就洁净了。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 12:8; 利未记 12:6; 希伯来书 10:10"> 第八天他要带上两只斑鸠或两只雏鸽，来到会幕入口耶和华面前，把它们交给祭司。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 14:30–31; 利未记 4:26; 马太福音 3:17"> 祭司要献上它们，一只作赎罪祭，一只作燔祭。这样，祭司就为这人的漏症，在耶和华面前为他赎了罪。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命记 23:10–11; 利未记 22:4; 利未记 15:5"> “如果一个男人遗精，他要用水洗全身，并且会不洁净直到傍晚。</span>
<span className="v" id="v17" data-v="17"> 任何衣物或皮革沾上了精液，都要用水清洗，并且会不洁净直到傍晚。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 15:5; 帖撒罗尼迦前书 4:3–5; 哥林多前书 6:12"> 如果男人与女人同寝交合，他们要用水洗身，并且会不洁净直到傍晚。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="利未记 12:2; 马太福音 15:19; 马可福音 5:25"> “如果一个女人流液，下体流出的是血，她就有七天的污秽期。凡是触碰她的，都会不洁净直到傍晚。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 15:4–9; 箴言 2:16–19; 箴言 6:35"> 她在经期所躺的任何物件都会不洁净，所坐的任何物件也都会不洁净。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 7:14; 哥林多后书 7:1; 以赛亚书 22:14"> 凡是触碰她床铺的人，都要洗衣服，用水洗身，并且会不洁净直到傍晚。</span>
<span className="v" id="v22" data-v="22"> 凡是触碰她所坐任何物件的人，都要洗衣服，用水洗身，并且会不洁净直到傍晚。</span>
<span className="v" id="v23" data-v="23"> 即使是那床铺上或她所坐物件上的东西，如果有人触碰了，也会不洁净直到傍晚。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 20:18; 彼得前书 2:11; 利未记 18:19"> 如果有男人竟然与那女人同寝，以致女人的污秽沾上了他，他就会不洁净七天，他所躺的床铺也都会不洁净。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马可福音 5:25; 马太福音 9:20; 路加福音 8:43"> “如果一个女人在非经期流血多日，或者过了经期还在流血，她在流出污秽的整个期间就像在经期一样，都是不洁净的。</span>
<span className="v" id="v26" data-v="26"> 她在这漏症的整个期间，所躺的任何床铺，都像经期的床铺那样，是不洁净的；她所坐的任何物件，也都像她经期时那样，是不洁净的。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 15:21; 希伯来书 10:22; 利未记 17:15–16"> 凡是触碰这些东西的人，都会不洁净，要洗衣服，用水洗身，并且会不洁净直到傍晚。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="利未记 15:13–15; 加拉太书 3:13; 以弗所书 1:6–7"> “当她的漏症得洁净了，她还要为自己数算七天，之后她就洁净了。</span>
<span className="v" id="v29" data-v="29"> 第八天她要带上两只斑鸠或两只雏鸽，带到会幕入口给祭司。</span>
<span className="v" id="v30" data-v="30"> 祭司要献上一只作赎罪祭，一只作燔祭。这样，祭司就为她漏症的不洁，在耶和华面前为她赎了罪。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="民数记 19:20; 民数记 19:13; 以西结书 5:11"> “你们要使以色列子民远离这些不洁，以免我在他们中间的帐幕被他们的不洁所玷污，以致他们死亡。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 11:46; 利未记 13:59; 民数记 6:13"> 以上条例适用于漏症患者，遗精而不洁净的男人，</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 15:19; 利未记 20:18; 利未记 15:24–25"> 经期的女人，其他情况流液的男人或女人，以及与不洁期间的女人同寝的男人。”</span>
</div>
</div>

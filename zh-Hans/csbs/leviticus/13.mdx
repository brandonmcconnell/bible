<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="LEV" data-book-slug="leviticus" data-book-name="利未记" data-chapter="13" data-verses="59">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西和亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 24:8; 利未记 14:56; 利未记 14:3"> “如果有人皮肉上出现了丘疹、疥癣或斑点，在他皮肉上出现了麻风病的症状，就要带他到祭司亚伦或他子孙中的一个祭司那里。</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 3:19–20; 使徒行传 20:28; 玛拉基书 2:7"> 祭司要查看他皮肉上的疾患，如果疾患的毛发已经变白，疾患症状已经深入皮肉，这就是麻风病。祭司查看他后，要判定他为不洁净。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 12:15; 哥林多前书 4:5; 提摩太前书 5:24"> 如果他皮肉上的斑点是白色的，症状还没有深入皮肤，毛发也没有变白，祭司就要把患者隔离七天。</span>
<span className="v" id="v5" data-v="5"> 到第七天祭司要查看他，如果据祭司看来疾患止住了，疾患没有在皮肤上扩散，祭司就要把他再隔离七天。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 11:25; 利未记 14:8; 申命记 32:5"> 到第七天祭司要再查看他，如果疾患消退了，疾患没有在皮肤上扩散，祭司就要判定他为洁净，这就是皮疹。他洗衣服，就洁净了。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 38:3; 利未记 13:35–36; 提摩太后书 2:16–17"> 但在祭司查看他而判定洁净之后，如果皮疹在皮肤上又扩散了，他就要再次给祭司查看。</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 15:7–8; 腓立比书 3:18–19; 使徒行传 8:21"> 祭司要查看，如果皮疹在皮肤上确实扩散了，祭司就要判定他为不洁净，这是麻风病。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> “如果有人染上了麻风病，就要带他到祭司那里。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 5:27; 历代志下 26:19–20; 利未记 13:14–15"> 祭司查看，如果皮肤上有白色的丘疹，那里的毛发已经变白，丘疹上出现溃烂的肉，</span>
<span className="v" id="v11" data-v="11"> 这就是他皮肉上的慢性麻风病。祭司要判定他为不洁净，不必隔离观察，他明显是不洁净的。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰一书 1:8–10; 约伯记 42:6; 罗马书 7:14"> 如果麻风在皮肤上蔓延开来，祭司看这些症状，麻风病已经从头到脚覆盖了患者全身的皮肤，</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 9:41; 以赛亚书 64:6"> 祭司查看，发现麻风病确实覆盖了他全身，就要判定患者为洁净；他全身变白，这是洁净的。</span>
<span className="v" id="v14" data-v="14"> 然而，一旦他身上出现溃烂的肉，他就不洁净。</span>
<span className="v" id="v15" data-v="15"> 祭司看到那溃烂的肉，就要判定他为不洁净。这溃烂的肉是不洁净的，这是麻风病。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太书 1:14–16; 罗马书 7:14–24; 腓立比书 3:6–8"> 但如果溃烂的肉复原变白了，他就要去见祭司，</span>
<span className="v" id="v17" data-v="17"> 祭司查看他，如果疾患变白了，祭司就要判定患者为洁净，他是洁净的。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 9:9; 以赛亚书 38:21; 诗篇 38:3–7"> “如果有人身上的皮肤生疮，已经痊愈了，</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 13:24"> 在生疮的地方又起了白色的丘疹或红白色的斑点，他就要给祭司查看。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 5:14; 利未记 13:3; 彼得后书 2:20"> 祭司要查看，如果那症状侵入皮肤，那里的毛发也变白了，祭司就要判定他为不洁净，这是疮中发散的麻风病。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 5:5"> 但如果祭司查看疾患，发现上面没有白毛，症状也没有侵入皮肤，反而消退了，祭司就要把他隔离七天。</span>
<span className="v" id="v22" data-v="22"> 然后，如果症状在皮肤上又扩散了，祭司就要判定他为不洁净，这是麻风病。</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 6:1; 约伯记 34:31–32; 马太福音 26:75"> 如果斑点留在原处没有扩散，这就是疮的疤痕，祭司要判定他为洁净。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 3:24"> “或者，如果有人身上的皮肤被火烫伤，烫伤的瘀肉成为红白色或白色的斑点，</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 13:18–20; 利未记 13:4"> 祭司就要查看，如果斑点上的毛发已经变白，症状已经深入皮肤，这就是烫伤中发散的麻风病，祭司要判定他为不洁净，这是麻风病。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 13:23; 利未记 13:4–5"> 但如果祭司查看，发现斑点上没有白毛，斑点没有侵入皮肤，反而消退了，祭司就要把他隔离七天。</span>
<span className="v" id="v27" data-v="27"> 到第七天，祭司要查看他，如果斑点在皮肤上又扩散了，祭司就要判定他为不洁净，这是麻风病。</span>
<span className="v" id="v28" data-v="28"> 但如果斑点留在原处，没有在皮肤上扩散，反而消退了，这就是烫伤的丘疹，祭司要判定他为洁净，这只是烫伤的疤痕。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 9:15; 马太福音 13:14–15; 哥林多后书 4:3–4"> “无论男女，如果他们头上或下巴上有疾患，</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 13:34–37; 利未记 14:54"> 祭司就要查看这疾患，如果症状深入皮肤，其上还有细弱的黄毛，祭司就要判定这人为不洁净，这是癞癣，是头或下巴上的麻风病。</span>
<span className="v" id="v31" data-v="31"> 但如果祭司查看癞癣的疾患，发现症状没有深入皮肤，不过其上没有黑毛，祭司就要把这癞癣患者隔离七天。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 13:30; 马太福音 23:5; 路加福音 18:9–12"> 到第七天，祭司要查看疾患，如果癞癣没有扩散，其上也没有黄毛，癞癣的症状没有深入皮肤，</span>
<span className="v" id="v33" data-v="33"> 这人就要剃掉须发，但不要刮癞癣处，祭司要把这癞癣患者再隔离七天。</span>
<span className="v" id="v34" data-v="34" data-xref="犹大书 1:22; 约翰一书 4:1; 启示录 2:2"> 到第七天祭司要再查看癞癣，如果癞癣没有在皮肤上扩散，症状没有深入皮肤，祭司就要判定这人为洁净。他洗衣服，就洁净了。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 13:27; 提摩太后书 2:16–17; 利未记 13:7"> 但如果判定他为洁净以后，癞癣在皮肤上又扩散了，</span>
<span className="v" id="v36" data-v="36"> 祭司就要再查看他：如果癞癣已经在皮肤上扩散，祭司就不用搜寻黄毛了，这人是不洁净的；</span>
<span className="v" id="v37" data-v="37"> 如果祭司看见癞癣止住了，其上也长出了黑毛，癞癣就是痊愈了，这人是洁净的，祭司要判定他为洁净。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> “无论男女，如果他们皮肉上出现了很多白色的斑点，</span>
<span className="v" id="v39" data-v="39" data-xref="罗马书 7:22–25; 雅各书 3:2; 传道书 7:20"> 祭司就要查看，如果他们皮肉上的斑点是淡白色的，这就是皮肤上发散的白斑病，这人是洁净的。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="加拉太书 4:13; 罗马书 8:10; 雅歌 5:11"> “如果有人的头顶脱发，这是头顶秃，他是洁净的。</span>
<span className="v" id="v41" data-v="41"> 如果他的头是从前额脱发，这是前额秃，他是洁净的。</span>
<span className="v" id="v42" data-v="42"> 但如果在秃顶上，或秃前额上出现了红白色的疾患，这就是他秃顶或秃前额上发散的麻风病。</span>
<span className="v" id="v43" data-v="43"> 祭司要查看他，如果他秃顶或秃前额上的丘疹是红白色的，像皮肉的麻风病症状一样，</span>
<span className="v" id="v44" data-v="44" data-xref="彼得后书 2:1–2; 马太福音 6:23; 以赛亚书 1:5"> 这人就是患了麻风病，他是不洁净的，祭司必须判定他为不洁净，他头上有了这疾患。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="弥迦书 3:7; 利未记 10:6; 以西结书 24:17"> “身上患了麻风病的人，要撕裂衣服，披散头发，蒙着嘴，喊叫：‘不洁净！不洁净！’</span>
<span className="v" id="v46" data-v="46" data-xref="列王纪下 7:3; 列王纪下 15:5; 历代志下 26:21"> 这疾患在他身上的日子，他都不洁净。他不洁净，就要独自居住，住在营地外。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="犹大书 1:23; 罗马书 13:12; 以西结书 16:16"> “如果衣物上出现了麻风菌斑，无论是在羊毛衣物上或是在细麻衣物上，</span>
<span className="v" id="v48" data-v="48" data-xref="利未记 13:51; 启示录 3:4; 申命记 8:11"> 细麻或羊毛的经纱纬纱上，皮革或任何皮革制品上，</span>
<span className="v" id="v49" data-v="49"> 如果在布料或皮革上、经纱纬纱上、任何皮革制品上，出现绿色或红色的菌斑，这就是麻风菌斑，要给祭司查看。</span>
<span className="v" id="v50" data-v="50" data-xref="以西结书 44:23"> 祭司要查看这菌斑，把有菌斑的物件隔离七天。</span>
<span className="v" id="v51" data-v="51" data-xref="利未记 14:44"> 到第七天祭司要查看，如果菌斑在布料上、经纱纬纱上，或在任何用途的皮革上扩散了，这菌斑就是恶性麻风，物件是不洁净的。</span>
<span className="v" id="v52" data-v="52" data-xref="利未记 11:35; 利未记 11:33; 利未记 14:44–45"> 他要烧掉那染上病菌的衣物，无论那是经纱纬纱，还是羊毛或细麻，或任何皮革制品；因为这是恶性麻风，必须用火烧掉。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53"> “但如果祭司查看，发现菌斑没有在衣物上，经纱纬纱上，或任何皮革制品上扩散，</span>
<span className="v" id="v54" data-v="54"> 祭司就要吩咐把那有菌斑的物件洗净，然后把它再隔离七天。</span>
<span className="v" id="v55" data-v="55" data-xref="以西结书 24:13; 希伯来书 6:4–8; 彼得后书 2:20–22"> 那有菌斑的物件洗净之后，祭司要查看，如果菌斑的外观没有变化，虽然菌斑没有扩散，但那物件还是不洁净，要用火烧掉；这菌斑无论在物件里面还是外面，都是侵蚀性的。</span>
<span className="v" id="v56" data-v="56"> 如果祭司查看，发现洗涤后菌斑消退了，就要把那一处从布料或皮革上、经纱纬纱上撕下来。</span>
<span className="v" id="v57" data-v="57" data-xref="马太福音 22:7; 启示录 21:8; 马太福音 3:12"> 之后，如果菌斑又出现在衣物上、经纱纬纱上，或任何皮革制品上，这是在扩散，你要把那染上病菌的物件用火烧掉。</span>
<span className="v" id="v58" data-v="58" data-xref="列王纪下 5:14; 启示录 1:5; 诗篇 51:2"> 那洗过的衣物、经纱纬纱，或是任何皮革制品，如果菌斑消失了，还要再洗一次，物件就洁净了。</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59"> “以上是麻风菌斑的条例，无论它出现在羊毛或细麻的衣物上，经纱纬纱上，还是在任何皮革制品上，用于判定那物件洁净或不洁净。”</span>
</div>
</div>

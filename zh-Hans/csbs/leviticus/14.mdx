<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 17:14; 路加福音 5:12–14; 马可福音 1:40–44"> “以下是麻风病人洁净之日的条例：他要被带到祭司那里；</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 13:46; 路加福音 7:22; 路加福音 17:15–19"> 祭司要来到营地外，然后祭司查看他，如果麻风病人身上的麻风病已经痊愈了，</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 19:6; 利未记 14:6; 希伯来书 9:19"> 祭司就要吩咐为那求洁净的人取来两只洁净的活鸟，以及香柏木、朱红色线和牛膝草。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 14:50; 希伯来书 2:14; 哥林多后书 5:1"> 祭司要吩咐人在瓦器里的活水上方，宰杀一只鸟。</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 1:5; 撒迦利亚书 13:1; 腓立比书 2:9–11"> 然后，祭司要拿来另一只活鸟，以及香柏木、朱红色线和牛膝草，把这些物品与活鸟一起，蘸在那活水上方被宰杀的鸟血中。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 5:14; 以西结书 36:25; 以赛亚书 52:15"> 祭司要向那脱离麻风病求洁净的人弹洒血七次，判定他为洁净，最后在田野上释放那只活鸟。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 11:25; 民数记 8:7; 彼得前书 3:21"> 那求洁净的人要洗衣服，剃掉身上所有的毛发，用水洗身，这样他就洁净了。之后，他可以进入营地，但必须住在自己的帐篷外七天。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 6:9; 利未记 14:8; 民数记 8:7"> 到了第七天，他要再剃掉身上所有的毛，把他的头发、胡须、眉毛以及全身的毛都剃掉。然后洗衣服，用水洗身，他就洁净了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未记 2:1; 马太福音 8:4; 路加福音 5:14"> “第八天，他要带来两只无瑕疵的公羊羔，一只无瑕疵的一岁母羊羔，以及十分之三伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十分之三伊法——相当于6.6公升。1伊法=22公升。">a</a></sup>调了油的素祭细面粉，还有一罗格<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一罗格——相当于0.3公升；本章下同。">b</a></sup>油。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 5:26–27; 出埃及记 29:1–4; 民数记 8:21"> 举行洁净礼的祭司，要让那求洁净的人带着这些祭物，站在会幕入口耶和华面前。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 29:24; 利未记 6:6–7; 利未记 8:27–29"> 然后祭司要取一只公羊羔，献为赎愆祭，连同那一罗格油，作为摇献祭物在耶和华面前摇一摇。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 29:11; 利未记 1:11; 利未记 4:24"> 他要在宰杀赎罪祭牲和燔祭牲的圣所那里，宰杀那只公羊羔；这赎愆祭牲就像赎罪祭一样，要归于祭司，这是至圣的。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 29:20; 利未记 8:23–24; 哥林多后书 7:1"> 祭司要取一些赎愆祭牲的血，抹在那求洁净的人右耳垂上，以及他右手拇指和右脚拇趾上。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 45:7; 约翰福音 3:34; 约翰一书 2:20"> 祭司要从那一罗格油中取一些，倒在他左手掌里，</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 4:17; 哥林多前书 10:31; 利未记 4:6"> 然后把右手指蘸在左手掌里的油中，用手指把一些油在耶和华面前弹洒七次。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前书 1:2; 以西结书 36:27; 利未记 14:14"> 祭司要把手掌里剩下的一些油，抹在那求洁净的人右耳垂上，以及他右手拇指和右脚拇趾上，就是在抹赎愆祭牲之血的地方；</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 4:26; 哥林多后书 1:21–22; 以弗所书 1:17–18"> 祭司手掌里剩下的油，要抹在那求洁净之人的头上。然后，祭司要在耶和华面前为那人赎罪。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 14:12; 利未记 5:1; 利未记 12:6–8"> 祭司要献上赎罪祭，为那脱离污秽求洁净的人赎罪。随后，他要宰杀燔祭牲，</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 14:10; 以弗所书 5:2; 利未记 14:8"> 祭司要把燔祭和素祭献在祭坛上。这样，祭司为那人赎罪，那人就洁净了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="利未记 5:7; 利未记 12:8; 箴言 17:5"> “如果那人贫困，负担不起这些，他可以取来一只公羊羔作赎愆祭，作为摇献祭物为他赎罪；并取来十分之一伊法<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="十分之一伊法——相当于2.2公升。1伊法=22公升。">c</a></sup>调了油的细面粉作素祭，还有一罗格油，</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 7:16; 以赛亚书 59:11; 耶利米书 48:28"> 以及他负担得起的两只斑鸠或两只雏鸽，一只作赎罪祭，一只作燔祭。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 14:10–11"> 第八天，他要为了得洁净把这些带到会幕入口耶和华面前，带到祭司那里。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 14:12; 利未记 14:10"> 祭司要取来那只赎愆祭羊羔和那一罗格油，作为摇献祭物在耶和华面前摇一摇。</span>
<span className="v" id="v25" data-v="25" data-xref="传道书 5:1; 诗篇 40:6; 利未记 14:14–20"> 宰杀赎愆祭羊羔后，祭司要取一些赎愆祭的血，抹在那求洁净的人右耳垂上，以及他右手拇指和右脚拇趾上。</span>
<span className="v" id="v26" data-v="26"> 祭司要倒一些油在他左手掌里，</span>
<span className="v" id="v27" data-v="27"> 然后用右手指，把左手掌里的一些油在耶和华面前弹洒七次。</span>
<span className="v" id="v28" data-v="28"> 接着，祭司要把手掌里的一些油，抹在那求洁净的人右耳垂上，以及他右手拇指和右脚拇趾上，就在抹赎愆祭牲之血的地方。</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 14:18; 约翰一书 2:1–2; 出埃及记 30:15–16"> 祭司手掌里剩下的油，要抹在那求洁净之人的头上，在耶和华面前为他赎罪。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 14:22; 罗马书 8:3; 利未记 12:8"> 然后他要献上一只负担得起的斑鸠或雏鸽，</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 14:18; 利未记 5:7"> 献上他负担得起的一只作赎罪祭，一只作燔祭，都与素祭一起献上。这样，祭司就在耶和华面前为那求洁净的人赎罪了。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 14:10; 利未记 14:21; 马太福音 11:5"> 这是关于那染上麻风病的人负担不起洁净礼的条例。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 耶和华指示摩西和亚伦说：</span>
<span className="v" id="v34" data-v="34" data-xref="申命记 32:49; 创世记 17:8; 民数记 32:22"> “你们进入我所赐给你们为产业的迦南地后，如果我使你们产业之地的房屋中有了麻风菌斑，</span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 91:10; 申命记 7:26; 撒迦利亚书 5:4"> 那房屋的主人要来告诉祭司，说：‘我房屋里好像有麻风菌斑出现。’</span>
<span className="v" id="v36" data-v="36" data-xref="启示录 18:4; 希伯来书 12:15; 提摩太后书 2:17–18"> 祭司要在过去查看那菌斑之前，吩咐把房屋搬空，免得房屋里的东西全都成为不洁净的。然后祭司要过去查看那房屋。</span>
<span className="v" id="v37" data-v="37" data-xref="利未记 13:42; 利未记 13:3; 利未记 13:19–20"> 祭司查看后，如果发现房屋墙上的菌斑是绿色或红色的霉斑，症状深入墙内，</span>
<span className="v" id="v38" data-v="38" data-xref="利未记 13:50"> 祭司就要从房屋里出来，到门口，封闭房屋七天。</span>
<span className="v" id="v39" data-v="39" data-xref="利未记 13:36; 利未记 13:27; 利未记 13:22"> 到第七天祭司要回来查看，如果菌斑在房屋的墙上扩散了，</span>
<span className="v" id="v40" data-v="40" data-xref="启示录 2:20; 提多书 3:10; 哥林多前书 5:5–6"> 祭司就要吩咐把那些有菌斑的砖石拆掉，扔到城外不洁净的地方；</span>
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 65:4; 启示录 22:15; 马太福音 24:51"> 再把房屋里四面都刮干净，把刮掉的灰泥倒在城外不洁净的地方；</span>
<span className="v" id="v42" data-v="42" data-xref="提摩太后书 2:2; 提摩太前书 5:21–22; 历代志下 17:7–9"> 然后用别的砖石取代原来的砖石，用别的灰泥粉刷房屋。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="耶利米书 6:28–30; 犹大书 1:12; 彼得后书 2:20"> “如果拆掉那些砖石、刮了房屋又粉刷以后，菌斑在房屋里再次发散，</span>
<span className="v" id="v44" data-v="44" data-xref="利未记 13:51–52; 撒迦利亚书 5:4"> 祭司就要进去查看，如果菌斑在房屋里确实扩散了，这就是房屋里的恶性麻风，它是不洁净的。</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪下 10:27; 马太福音 24:2; 列王纪上 9:6–9"> 这房屋就要被拆毁，砖石、木头和房屋的灰泥都要搬运到城外不洁净的地方。</span>
<span className="v" id="v46" data-v="46" data-xref="民数记 19:21–22; 利未记 22:6; 利未记 11:28"> 房屋被封闭的整个期间，进入这房屋的人，会不洁净直到傍晚；</span>
<span className="v" id="v47" data-v="47" data-xref="利未记 14:8–9; 利未记 11:25"> 在这房屋躺卧的人，要洗自己的衣服；在这房屋吃喝的人，也要洗自己的衣服。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="哥林多前书 6:11; 约伯记 5:18; 马可福音 5:29"> “但如果祭司进去查看，发现房屋粉刷以后，菌斑并没有在房屋里扩散，祭司就要判定这房屋为洁净，因为这麻风已经治好了。</span>
<span className="v" id="v49" data-v="49" data-xref="利未记 14:4"> 为了使这房屋得洁净，祭司要取来两只鸟，以及香柏木、朱红色线和牛膝草；</span>
<span className="v" id="v50" data-v="50"> 在瓦器里的活水上方宰杀一只鸟，</span>
<span className="v" id="v51" data-v="51" data-xref="诗篇 51:7"> 然后取来香柏木、牛膝草、朱红色线以及另一只活鸟，蘸在那被宰杀的鸟的血和活水中，向房屋弹洒这血水七次。</span>
<span className="v" id="v52" data-v="52"> 祭司用鸟血、活水、活鸟、香柏木、牛膝草和朱红色线洁净了房屋，</span>
<span className="v" id="v53" data-v="53" data-xref="利未记 14:20; 利未记 14:7"> 然后要把那只活鸟释放到城外的田野上。这样，他为房屋赎罪，房屋就洁净了。</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="利未记 15:32; 利未记 14:32; 利未记 6:9"> “以上条例，适用于各种麻风病、癞癣，</span>
<span className="v" id="v55" data-v="55" data-xref="利未记 13:47–59"> 衣物上或房屋上的麻风，</span>
<span className="v" id="v56" data-v="56" data-xref="利未记 13:2"> 丘疹、疥癣、斑点，</span>
<span className="v" id="v57" data-v="57" data-xref="利未记 10:10; 以西结书 44:23; 耶利米书 15:19"> 用于指示什么时候不洁净、什么时候洁净。这是关于麻风的条例。”</span>
</div>
</div>

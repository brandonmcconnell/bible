<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2"> “你要吩咐亚伦和他的儿子们，以及全体以色列子民，对他们说，以下是耶和华所指示的话：</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 17:8; 利未记 17:15; 申命记 12:5–7"> 凡是以色列家的人，无论是在营地内还是营地外宰杀公牛、绵羊或山羊，</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 10:7; 申命记 12:5–21; 以赛亚书 66:3"> 如果没有把它牵到会幕入口耶和华的帐幕前，作为祭物献给耶和华，这人就要算为有血债。这人杀戮流血，必要从民中被剪除。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 22:9; 列王纪上 14:23; 历代志下 28:4"> 这是为了使以色列子民把他们在野外所献的祭物带来，带到会幕入口耶和华面前交给祭司，作为平安祭献给耶和华。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 18:17; 利未记 3:2; 出埃及记 29:18"> 祭司要把血洒在会幕入口耶和华的祭坛上，然后把脂肪烧献为烟，作馨香之气献给耶和华。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 10:20; 出埃及记 34:15; 申命记 32:17"> 他们绝不可再把祭物献给他们行淫追随的那些山羊神。这是他们世世代代永远的律例。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未记 1:2–3; 利未记 17:4; 利未记 17:10"> “你要对他们说：凡是以色列家的人，或寄居在他们中间的外人，如果在献上燔祭或祭物时，</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 17:4"> 没有把它带到会幕入口献给耶和华，这人就要从民中被剪除。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未记 17:11; 利未记 3:17; 申命记 12:23"> “凡是以色列家的人，或寄居在他们中间的外人，无论吃了什么血，我必对这吃血的人翻脸，把他从民中剪除。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 9:22; 约翰一书 1:7; 罗马书 3:25"> 因为活物<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="活物——原文直译“肉体”；本章下同。">a</a></sup>的生命是在血中；我把血赐给你们，在祭坛上为你们的生命赎罪；血代表生命，用于赎罪。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 12:49"> 所以我对以色列子民说：你们中间任何人都不可吃血，在你们中间寄居的外人也不可吃血。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命记 12:16; 以西结书 24:7; 利未记 7:26"> “凡是以色列子民中的人，或寄居在他们中间的外人，如果猎取了可食用的飞禽走兽作野味，必须把它的血放出来，并且用土掩盖。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 9:4; 申命记 12:23; 利未记 17:11–12"> 因为一切活物的生命就是它的血，血代表它的生命。所以我对以色列子民说：任何活物的血，你们都不可吃；一切活物的生命就是它的血，所有吃血的人都要被剪除。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命记 14:21; 出埃及记 22:31; 利未记 22:8"> “凡是有人吃了自然死去或被咬死的动物，无论他是本族人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="本族人——原文直译“本地人”。">b</a></sup>或是外人，都要洗衣服，用水洗身，并且会不洁净直到傍晚，之后就洁净了。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 5:1; 民数记 19:19–20; 利未记 7:18"> 但如果他不洗衣服，不洗身，他就要承担自己的罪责。”</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 23:4; 利未记 23:37; 民数记 29:39"> “你要吩咐以色列子民，对他们说：以下是我所定的节期，是你们要宣告神圣聚会的耶和华的节期。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="利未记 19:3; 出埃及记 23:12; 出埃及记 35:2–3"> “六天可以做工，但第七天是完全安息的安息日，要有神圣的聚会，任何工作你们都不可做。在你们居住的任何地方，这都是向耶和华守的安息日。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="利未记 23:2; 出埃及记 23:14; 利未记 23:37"> “以下是耶和华所定的节期，你们要在这些所定的节期宣告神圣的聚会。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 5:10; 申命记 16:1–8; 民数记 28:16–17"> 在一月十四日黄昏的时候，是耶和华的逾越节。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 34:18; 申命记 16:8; 出埃及记 12:15–16"> 这月的十五日，是耶和华的除酵节，你们要吃无酵饼七天。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 28:18–25; 利未记 23:8; 利未记 23:21"> 第一天要有神圣的聚会，任何日常工作都不可做。</span>
<span className="v" id="v8" data-v="8"> 你们要连续七天献火祭给耶和华，第七天要有神圣的聚会，任何日常工作都不可做。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 耶和华指示摩西说：</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 34:26; 出埃及记 23:19; 申命记 16:9"> “你要吩咐以色列子民，对他们说：当你们进入我所赐给你们的那地，收割庄稼时，要把一捆初熟的庄稼带到祭司那里。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 29:24; 利未记 10:14; 利未记 9:21"> 祭司要把那禾捆在耶和华面前摇一摇，使你们蒙悦纳，就是在安息日的次日，把它摇一摇。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 10:10–12; 彼得前书 1:19; 利未记 1:10"> 在摇献禾捆那天，你们要献上一只无瑕疵的一岁公羊羔，作为燔祭献给耶和华；</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 2:14–16; 约珥书 1:9; 民数记 28:10"> 同献的素祭是十分之二伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十分之二伊法——相当于4.4公升。1伊法=22公升；本章下同。">a</a></sup>细面粉，用油调和，作为馨香的火祭献给耶和华；还有酒祭，是四分之一欣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="四分之一欣——相当于0.9公升。1欣=3.7公升。">b</a></sup>的酒。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 34:26; 创世记 4:4–5; 利未记 3:17"> 在那一天你们把神的祭物带来之前，无论是饼，还是烤麦子，或是新穗子，你们都不可吃。这是在你们居住的任何地方，你们世世代代永远的律例。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="利未记 23:10–11; 利未记 25:8; 申命记 16:9–10"> “从安息日的次日，就是你们把禾捆带来作摇献祭物那天起，你们要数算整整七个安息日，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 2:1; 民数记 28:26"> 直到第七个安息日的次日，这样数算五十天，再把新的素祭带来献给耶和华。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 23:10; 出埃及记 34:26; 出埃及记 34:22"> 你们要从居住的地方带来两个饼作摇献祭，是用十分之二伊法细面粉、带着酵烘烤的，作初熟之物献给耶和华。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 28:27–31; 利未记 23:12–13; 玛拉基书 1:13–14"> 连同这饼，你们要献上七只无瑕疵的一岁公羊羔，一头公牛，两只公绵羊；这些要作为燔祭，连同素祭、酒祭献给耶和华，作馨香的火祭献给耶和华。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 28:30; 利未记 4:23–28; 利未记 7:11–18"> 然后，你们要献上一只公山羊为赎罪祭，两只一岁的公绵羊为平安祭。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 18:4; 以弗所书 2:14; 民数记 18:8–12"> 祭司要把这些祭物连同初熟之物的饼，与这两只绵羊羔一起，作为摇献祭物在耶和华面前摇一摇。这些是献给耶和华的圣物，归于祭司。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 23:2; 利未记 23:4; 民数记 18:23"> 你们要在同一天宣告聚会；这是你们的神圣聚会，任何日常工作都不可做。这是在你们居住的任何地方，你们世世代代永远的律例。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 24:19–21; 利未记 19:9–10; 以赛亚书 58:10"> 当你们收割地里的庄稼时，不可连田地的边角都收割干净，也不要捡拾所遗落的庄稼，总要留给困苦人和寄居者。我是耶和华你们的神。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和华指示摩西说：</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 15:52; 帖撒罗尼迦前书 4:16; 利未记 25:9"> “你要吩咐以色列子民：七月的第一日，是你们完全安息的日子，要长鸣号角作记念，要有神圣的聚会。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 23:21"> 任何日常工作都不可做；要把火祭献给耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和华指示摩西说：</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 16:29–31; 出埃及记 30:10; 利未记 16:24"> “至于七月的第十日，是赎罪日，你们要有神圣的聚会，刻苦己心，把火祭献给耶和华。</span>
<span className="v" id="v28" data-v="28" data-xref="撒迦利亚书 3:9; 利未记 16:34; 希伯来书 10:10"> 这一天，任何工作都不可做，因为这是赎罪日，要在你们的神耶和华面前为你们赎罪。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 17:14; 民数记 5:2; 利未记 23:27"> 凡是这一天没有刻苦己心的人，都必从民中被剪除。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 20:3; 西番雅书 2:5; 耶利米书 15:7"> 凡是在这一天做任何工作的人，我必把这人从民中除灭。</span>
<span className="v" id="v31" data-v="31"> 任何工作你们都不可做。这是在你们居住的任何地方，你们世世代代永远的律例。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 16:31; 马太福音 11:28–30; 诗篇 69:10–11"> 这是你们完全安息的安息日，你们要刻苦己心。从这月九日傍晚到次日傍晚，你们要守安息日。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 耶和华指示摩西说：</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 7:2; 尼希米记 8:14; 以斯拉记 3:4"> “你要吩咐以色列子民：到七月的十五日，要向耶和华守七天的住棚节。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 23:24–25; 利未记 23:7–8"> 第一天要有神圣的聚会，任何日常工作都不可做。</span>
<span className="v" id="v36" data-v="36" data-xref="尼希米记 8:18; 约翰福音 7:37; 历代志下 7:8–11"> 要连续七天把火祭献给耶和华，第八天要有神圣的聚会，并且把火祭献给耶和华；这是严肃集会，任何日常工作都不可做。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="利未记 23:2; 利未记 23:4; 传道书 3:1"> “以上是耶和华所定的节期，你们要宣告神圣的聚会，要把火祭，就是燔祭和素祭等祭物，连同酒祭，照着每天的份额献给耶和华。</span>
<span className="v" id="v38" data-v="38" data-xref="民数记 29:39; 利未记 19:3; 以斯拉记 2:68–69"> 这些节期，是在耶和华的安息日以外的节期；这些祭物，是在你们献给耶和华的供物、各种还愿祭、各种甘心祭以外的祭物。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出埃及记 23:16; 申命记 16:13; 利未记 23:34"> “每当七月十五日，你们收聚了田地的出产，就要守耶和华的节期七天。第一天是完全安息的日子，第八天也是完全安息的日子。</span>
<span className="v" id="v40" data-v="40" data-xref="腓立比书 4:4; 启示录 7:9; 申命记 16:14–15"> 第一天，你们要拿来华美的树枝——棕榈叶子、茂密树的枝条和溪谷中的柳枝，这样在你们的神耶和华面前欢乐七天。</span>
<span className="v" id="v41" data-v="41" data-xref="民数记 29:12; 尼希米记 8:18"> 你们每年都要向耶和华守这节期七天；这是你们世世代代永远的律例，必须在七月份守这节。</span>
<span className="v" id="v42" data-v="42" data-xref="尼希米记 8:14–17; 创世记 33:17; 民数记 24:5"> 你们要在棚子里住七天，以色列所有的本族人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="本族人——原文直译“本地人”。">c</a></sup>都要住在棚子里，</span>
<span className="v" id="v43" data-v="43" data-xref="申命记 31:10–13; 诗篇 78:5–6; 出埃及记 13:14"> 好让你们世世代代知道：我把以色列子民从埃及地领出来的时候，曾使他们住在棚子里。我是耶和华你们的神。”</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="利未记 23:1–2; 马太福音 18:20; 利未记 21:24"> 于是，摩西向以色列子民宣告了耶和华所定的节期。</span>
</div>
</div>

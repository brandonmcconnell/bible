<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="LEV" data-book-slug="leviticus" data-book-name="利未记" data-chapter="25" data-verses="55">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 1:1; 加拉太书 4:24–25; 出埃及记 19:1"> 耶和华在西奈山指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 36:21; 利未记 26:34–35; 出埃及记 23:10"> “你要吩咐以色列子民，对他们说：当你们进入了我所赐给你们的那地，地要休耕，向耶和华守安息。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 23:10"> 你们可以六年耕种田地，六年修剪葡萄园，收取地里的出产。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 36:21; 利未记 25:20–23; 出埃及记 23:10–11"> 但在第七年，土地要有完全安息的安息年，是向耶和华守的安息年。不可耕种田地，也不可修剪葡萄园；</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 19:29; 以赛亚书 37:30"> 自长的庄稼，不可收割；未修剪的葡萄树，也不可采收。土地要完全安息一年。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 2:44; 出埃及记 23:11; 使徒行传 4:34–35"> 不过，土地在安息年中出产的，可以作你们的食物，给你们和你们的仆婢、雇工，以及居住在你们那里的客居者吃；</span>
<span className="v" id="v7" data-v="7"> 这一切出产，也要给你们的牲畜和地上的走兽吃<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="吃——或译作“作食物”。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未记 23:15; 创世记 2:2"> “你要数算七个安息年，就是七个七年，这样就有了七个安息年的年数，一共四十九年。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 23:24; 利未记 23:27; 帖撒罗尼迦前书 1:8"> 然后在七月十日，你要长鸣号角，要在这赎罪日使号角声响遍全地。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 34:8; 以赛亚书 63:4; 彼得前书 2:16"> 你们要把第五十年分别为圣，在全地向所有的居民宣告自由。这是你们的禧年，你们各人要回归自己的地业，回归自己的家族。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 27:17; 利未记 25:4–5"> 这第五十年是你们的禧年，你们不可耕种，也不可收割自长的庄稼，不可采收未修剪的葡萄树。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 25:6–7"> 因为这是禧年，你们要把它当作神圣的。你们要吃田地自长的。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未记 25:10; 利未记 27:17–24; 民数记 36:4"> “在这禧年，你们各人要回归自己的地业。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 19:13; 利未记 25:17; 撒母耳记上 12:3–4"> 如果你们卖什么东西给邻人，或是从邻人手中买东西，不可彼此亏负。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 27:18–23; 腓立比书 4:5"> 你要按禧年之后的年数向邻人购买，他也要按收成的年数卖给你。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 25:27; 利未记 25:51"> 年数多就提高价格，年数少就降低价格，因为他卖给你的是收成的数量。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 19:14; 利未记 19:32; 利未记 25:43"> 你们不可彼此亏负，要敬畏你们的神；我是耶和华你们的神。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米书 23:6; 申命记 12:10; 箴言 1:33"> “你们要遵行我的律例，谨守遵行我的法规，这样你们就可以在那地安然居住。</span>
<span className="v" id="v19" data-v="19" data-xref="约珥书 2:26; 诗篇 85:12; 利未记 26:5"> 那地必供应出产，使你们吃得饱足，在那里安然居住。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 25:4; 路加福音 12:29; 民数记 11:4"> 如果你们说：‘看哪，第七年不耕种，也不收获出产，我们吃什么呢？’</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 28:8; 箴言 10:22; 哥林多后书 9:10"> 要知道，我必在第六年赐下我的祝福给你们，使土地产出三年的收成。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 19:29; 利未记 26:10; 以赛亚书 37:30"> 这样，第八年你们耕种时，还在吃陈年的出产；直到第九年，那年的出产收进来时，你们还在吃陈年的。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="彼得前书 2:11; 诗篇 39:12; 以西结书 48:14"> “土地不可永久卖断，因为地是我的，你们在我面前是佃户、是寄居的。</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所书 1:7; 利未记 25:51–53; 利未记 25:27"> 你们所得的任何土地，都要允许人有土地的赎回权。</span>
<span className="v" id="v25" data-v="25" data-xref="路得记 2:20; 耶利米书 32:7–8; 路得记 3:12"> 如果你的弟兄贫穷，以致卖了他的一些地产，他那有赎回权的近亲就要来，赎回这弟兄所卖的。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 5:7"> 如果没有谁可为这人赎回地产，但他自己后来手头宽裕了，有了足够的钱来赎回，</span>
<span className="v" id="v27" data-v="27"> 他就要计算卖地的年数，把差额偿还给那与他交易的人，这样他就可以回归自己的地业。</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 35:9–10; 利未记 25:10; 彼得前书 1:4–5"> 但如果他手头没有足够的钱赎回，他所卖的就要留在买主手中，直到禧年。不过到了禧年，那地就要退还，使原主回归自己的地业。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> “如果有人卖了城墙内的住宅，他的赎回权在出售后的一整年有效，这期间他有赎回权。</span>
<span className="v" id="v30" data-v="30"> 如果满了一整年没有赎回，城墙内这栋房屋就要世世代代永久归属那买主，即使到了禧年也不必退还。</span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 49:7–8"> 但村庄的房屋，四围无城墙，所以算为在郊外的地产，这些房屋有赎回权，到了禧年要退还。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="约书亚记 21:1–45; 民数记 35:1–8"> “至于利未人的城镇，就是他们得为业的城，其中的房屋，利未人有永久赎回权。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 18:20–24; 申命记 18:1–2"> 如果有利未人无力赎回，他们得为业的城中所出售的房屋，到了禧年必须退还，因为利未人城里的房屋是他们在以色列子民中的产业。</span>
<span className="v" id="v34" data-v="34" data-xref="利未记 25:23; 使徒行传 4:36–37; 民数记 35:2–5"> 此外，他们城郊的牧野不可出售，因为那是他们永久的产业。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="申命记 15:7–8; 使徒行传 11:29; 利未记 25:25"> “如果你的弟兄贫穷，在你那里无法维持生计<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="无法维持生计——原文直译“手动摇”。">b</a></sup>，你要扶持他，像扶持外人或寄居者那样，让他与你一同生活。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 22:25; 申命记 23:19–20; 以西结书 18:8"> 不可向他收取利息或厚利，你要敬畏你的神，让你的弟兄能与你一同生活。</span>
<span className="v" id="v37" data-v="37"> 你借钱给他，不可收取利息；借粮给他，不可贪图利益。</span>
<span className="v" id="v38" data-v="38" data-xref="利未记 11:45; 民数记 15:41; 出埃及记 20:2"> 我是耶和华你们的神，是我把你们从埃及地领了出来，把迦南地赐给你们，为要作你们的神。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出埃及记 21:2; 列王纪上 9:22; 列王纪下 4:1"> “如果你身边的弟兄贫穷，把自己卖给了你，你不可奴役他，使他做奴隶的工作。</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及记 21:2–3"> 他在你那里，要像雇工、像客居者一样。他要在你那里服事到禧年，</span>
<span className="v" id="v41" data-v="41" data-xref="利未记 25:28; 出埃及记 21:3; 约翰福音 8:32"> 然后他和他的儿女要从你那里离去，回归自己的家族，回归自己祖先的地业。</span>
<span className="v" id="v42" data-v="42" data-xref="利未记 25:55; 罗马书 6:22; 哥林多前书 7:21–23"> 要知道，他们是我的仆人，是我从埃及地领出来的，不可被卖为奴仆。</span>
<span className="v" id="v43" data-v="43" data-xref="歌罗西书 4:1; 利未记 25:46; 出埃及记 1:13–14"> 不可严酷地辖制他，你要敬畏你的神。</span>
<span className="v" id="v44" data-v="44" data-xref="出埃及记 12:44; 诗篇 2:8–9; 以赛亚书 14:1–2"> 那些成为你仆婢的，只能是周围那些民族的人，你要从他们中间买仆婢；</span>
<span className="v" id="v45" data-v="45" data-xref="以赛亚书 56:3–6"> 也或者是住在你们中间的客居者的子孙，你们可以从他们中间买——他们的族人在你们中间，是在你们土地上出生的人。他们可以成为你们的产业。</span>
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 14:2; 利未记 25:43"> 你们可以把他们遗留给后代子孙作为产业继承，可以永久奴役他们。但在你们的弟兄以色列子民中间，不可严酷地辖制彼此。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="雅各书 2:5; 利未记 25:26; 撒母耳记上 2:7–8"> “如果你身边的外人或寄居者手头宽裕，而他那里你的一个弟兄却贫穷，把自己卖给了那外人、寄居者或外人的家族成员，</span>
<span className="v" id="v48" data-v="48" data-xref="尼希米记 5:5; 希伯来书 2:11–13; 利未记 25:35"> 那么他被卖之后，还是有赎身的权利。他任何一个兄弟都可以赎回他，</span>
<span className="v" id="v49" data-v="49" data-xref="利未记 25:26"> 他的叔伯或堂兄弟可以赎回他，他家族中的血亲也可以赎回他；或者他手头宽裕了，也可以赎回自己。</span>
<span className="v" id="v50" data-v="50" data-xref="以赛亚书 16:14; 以赛亚书 21:16; 利未记 25:53"> 赎回者要与买主核算，从卖出的那年开始到禧年为止，赎价要依据这年数，照着他在买主那里作雇工的年日核算。</span>
<span className="v" id="v51" data-v="51"> 如果剩余的年数多，他就要按年数从买价中偿还他的赎价；</span>
<span className="v" id="v52" data-v="52"> 如果到禧年只剩下几年，就要与买主按年数核算，偿还他的赎价。</span>
<span className="v" id="v53" data-v="53" data-xref="利未记 25:46; 利未记 25:43"> 他在买主那里要像长年雇用的工人，你不可眼看着他被买主严酷地辖制。</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及记 21:2–3; 利未记 25:40–41; 以赛亚书 49:9"> 如果他不能以这些方式被赎回，他与他的儿女一起要在禧年自由离去。</span>
<span className="v" id="v55" data-v="55" data-xref="利未记 25:42; 以赛亚书 43:3; 出埃及记 13:3"> 要知道，以色列子民是我的仆人；他们是我从埃及地领出来的仆人。我是耶和华你们的神。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 44:25; 利未记 21:11; 利未记 10:6–7"> 耶和华对摩西说：“你要吩咐作祭司的亚伦子孙，对他们说：不可为民中的死人使自己受玷污，</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦前书 4:13; 利未记 18:6"> 除非那死人是他的骨肉至亲，父母、儿女、兄弟；</span>
<span className="v" id="v3" data-v="3"> 如果他的至亲姐妹是未嫁人的处女，也可以为这姐妹使自己受玷污。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 24:16–17"> 他不可作为家主，为姻亲使自己受玷污<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他不可作为家主，为姻亲使自己受玷污——或译作“他在民中为首，不可使自己受玷污”。">a</a></sup>，被亵渎。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="申命记 14:1; 以西结书 44:20; 利未记 19:27–28"> “祭司不可剃光头发，不可剪掉胡须的边角，也不可割划身体。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 3:11; 利未记 18:21; 彼得前书 2:9"> 他们要成为圣洁的归于神，不可亵渎神的名；因为是他们要献上耶和华的火祭——神的食物，所以他们必须圣洁。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 21:13–14; 以西结书 44:22; 利未记 21:8"> 祭司不可娶妓女或被玷污的女人，也不可娶那被丈夫休了的女人，因为祭司是归神为圣的。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 20:7–8; 利未记 19:2; 利未记 11:44–45"> 你要使祭司分别为圣，因为是他要献上你神的食物；他对于你们应当是圣洁的，因为我耶和华，把你们分别为圣的那一位，是圣洁的。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 38:24; 利未记 19:29; 以西结书 9:6"> 祭司的女儿，如果去卖淫玷污自己，就是在亵渎自己的父亲，必须用火烧死。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未记 10:6–7; 利未记 16:32; 马太福音 26:65"> “弟兄当中作大祭司的，头上被浇了膏油、已经承接圣职穿上圣衣，他不可披散头发，也不可撕裂衣服。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 19:14; 利未记 21:1–2; 民数记 6:7"> 他不可接近任何死人的尸体，即使是为了父母，他也不可使自己受玷污。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 10:7; 出埃及记 29:6–7; 利未记 8:9–12"> 他也不可为死者<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="为死者——辅助词语。">b</a></sup>离开圣所，以免亵渎神的圣所，因为神的受膏圣冠<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="受膏圣冠——或译作“离俗膏油”；参《出埃及记》29:6-7。">c</a></sup>在他头上。我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未记 21:7; 哥林多后书 11:2; 启示录 14:4"> “他要娶处女为妻；</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 21:7; 以西结书 44:22"> 寡妇或被休的妇女，或是被玷污的妓女，这些他都不可娶，只可以娶本族<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="本族——或译作“本民”；本章下同。">d</a></sup>的处女为妻，</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 11:16; 哥林多前书 7:14; 尼希米记 13:23–29"> 以免在本族中亵渎了自己的后裔。我是把他分别为圣的耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 耶和华指示摩西说：</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 65:4; 民数记 16:5; 利未记 10:3"> “你要吩咐亚伦：你世世代代的后裔中，凡是身上有残疾的，都不可近前来献上他的神的食物。</span>
<span className="v" id="v18" data-v="18" data-xref="提摩太前书 3:2–3; 利未记 22:19–25; 提多书 1:7"> 因为凡是身上有残疾的人，都不可近前来献祭，无论那人是瞎眼的还是瘸腿的，或是面目受损的、畸形的，</span>
<span className="v" id="v19" data-v="19"> 或是折手断脚的人、</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 23:1; 以赛亚书 56:3"> 驼背的、侏儒症的、眼睛有毛病的、生癣的、长疥的，睾丸受损的。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 21:6; 利未记 21:8; 利未记 21:17"> 祭司亚伦的后裔中，凡是身上有残疾的人，都不可近前来献上耶和华的火祭；他身上有残疾，不可近前来献上神的食物。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 2:3; 民数记 18:19; 利未记 24:8–9"> 神的食物，无论是至圣的还是圣洁的，他都可以吃，</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 21:12; 以西结书 44:9–14; 出埃及记 30:6–8"> 但他不可进到幔子那里，也不可接近祭坛，因为他有残疾，以免他亵渎了我的圣所。我是把他们分别为圣的耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="提摩太前书 1:18; 玛拉基书 2:1–7; 提摩太后书 2:2"> 于是，摩西把这一切告诉了亚伦和他的儿子们，以及所有的以色列子民。</span>
</div>
</div>

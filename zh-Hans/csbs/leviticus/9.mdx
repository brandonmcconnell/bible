<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="LEV" data-book-slug="leviticus" data-book-name="利未记" data-chapter="9" data-verses="24">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 28:1; 以西结书 43:26–27; 利未记 15:14"> 到了第八天，摩西召来亚伦和他的儿子们，以及以色列的众长老。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 4:3; 希伯来书 10:10–14; 利未记 8:14"> 摩西对亚伦说：“你要为自己取一头公牛犊作赎罪祭，一只公绵羊作燔祭，都必须是无瑕疵的，献在耶和华面前。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 6:17; 启示录 5:9; 提多书 2:14"> 你也要吩咐以色列子民：取一只公山羊作赎罪祭；一头公牛犊和一只绵羊羔，都是一岁的、无瑕疵的，作燔祭；</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 29:43; 以西结书 43:2; 利未记 9:23"> 一头公牛和一只公绵羊作平安祭；都在耶和华面前献上，并且献上调了油的素祭。因为今天耶和华要向你们显现。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="历代志下 5:2–3; 出埃及记 19:17; 尼希米记 8:1"> 于是，他们把摩西所吩咐的都带到会幕前面；全体会众也上前来，站在耶和华面前。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 9:23; 以西结书 43:2; 出埃及记 24:16"> 摩西说：“这是耶和华指示你们要做的事，之后耶和华的荣耀要向你们显现。”</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 5:3; 希伯来书 5:1; 利未记 4:3"> 然后摩西对亚伦说：“你要上前到祭坛那里，照着耶和华所指示的，献上你的赎罪祭和燔祭，为自己和百姓<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="百姓——七十士译本作“家人”。">a</a></sup>赎罪，也献上百姓的祭物，为他们赎罪。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未记 4:1–12; 利未记 1:4–5; 利未记 4:29"> 亚伦就上前到祭坛那里，宰杀那头为自己作赎罪祭的公牛犊。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 4:6–7; 利未记 8:15; 利未记 4:25"> 亚伦的儿子们把血拿来给他，他就把手指蘸到血里，抹在祭坛犄角上，把其余的血倒在祭坛的基座那里；</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 8:16–17; 箴言 23:26; 利未记 3:9–11"> 然后把赎罪祭的脂肪、肾脏和肝叶在祭坛上烧献为烟，都是照着耶和华指示摩西的。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 8:17; 利未记 4:11–12; 利未记 16:27–28"> 至于肉和皮，他在营地外用火烧掉了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以弗所书 5:2; 以弗所书 5:25–27; 利未记 1:1–17"> 亚伦又把燔祭牲宰杀了，亚伦的儿子们把血递给他，他就洒在祭坛的四壁。</span>
<span className="v" id="v13" data-v="13"> 他们把燔祭牲一块一块、连头一起递给他，他就在祭坛上把这些都烧献为烟。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 8:21"> 他也把内脏和腿洗净，连同燔祭在祭坛上烧献为烟。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="利未记 4:27–31; 希伯来书 5:3; 利未记 9:3"> 接着，亚伦献上百姓的祭物。他把为百姓作赎罪祭的公山羊牵来，宰杀了，像先前的一样献为赎罪祭。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 9:12–14; 利未记 8:18–21; 希伯来书 10:1–22"> 又把燔祭带来，也照着规定献上了。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 2:1–2; 约翰福音 6:53; 利未记 9:1"> 然后带来素祭，从其中捧出满满一把，在祭坛上烧献为烟；这是在早晨的燔祭以外献上的。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 1:20; 罗马书 5:1; 以弗所书 2:14–17"> 接着，他把为百姓作平安祭的公牛和公绵羊宰杀了。亚伦的儿子们把血递给他，他就洒在祭坛的四壁。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 3:16; 利未记 9:10; 利未记 3:9"> 至于公牛和公绵羊的脂肪，就是肥尾巴、覆盖内脏的脂肪、肾脏和肝叶，</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 3:14–17; 利未记 7:29–34"> 他们把这些脂肪放在胸肉上面，亚伦就在祭坛上把脂肪烧献为烟。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 7:30–34; 利未记 7:24; 出埃及记 29:24"> 至于胸肉和右腿，亚伦把它们作为摇献祭物在耶和华面前摇一摇，都是照着摩西所吩咐的。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命记 21:5; 路加福音 24:50; 民数记 6:23–27"> 接着，亚伦向民众举起双手，祝福他们。他献上赎罪祭、燔祭和平安祭之后，就下来。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 9:6; 民数记 16:19; 路加福音 1:21–22"> 随后，摩西和亚伦进入会幕。当他们出来祝福了民众，耶和华的荣耀就向全体民众显现。</span>
<span className="v" id="v24" data-v="24" data-xref="士师记 6:21; 列王纪上 18:38–39; 历代志上 21:26"> 有火从耶和华面前出来，吞噬祭坛上的燔祭和脂油。全体民众看见了就高声呼喊，脸伏于地。</span>
</div>
</div>

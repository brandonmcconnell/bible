<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 6:14–18; 利未记 9:17; 以赛亚书 66:20"> “当一个人献上素祭为祭物给耶和华时，他要用细面粉作为祭物，其上要浇油，并加上乳香。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 5:12; 利未记 6:15; 使徒行传 10:4"> 他要把这素祭带到那些作祭司的亚伦子孙那里，祭司要从其中捧出满满一把细面粉和油，连同所有的乳香。然后祭司要把这记念的部分在祭坛上烧献为烟，作馨香的火祭献给耶和华。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 10:12–13; 民数记 18:9; 利未记 21:22"> 素祭中所剩的，归于亚伦和他的子孙，这是耶和华火祭中的至圣物。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及记 29:2; 哥林多前书 5:7–8; 诗篇 22:14"> “当你献上炉中烘烤的素祭为祭物，要用细面粉做成调了油的无酵饼，或抹上油的无酵薄饼。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 6:21; 利未记 7:9"> 如果你以烤盘上的素祭为祭物，就要用细面粉做成调了油的无酵饼，</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 18:1–19; 诗篇 22:1–21; 马可福音 14:1–15"> 把它分成小块，浇上油；这是素祭。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 2:1–2; 利未记 7:9"> 如果你以煎盘上的素祭为祭物，就要用细面粉调油做成。</span>
<span className="v" id="v8" data-v="8"> 你把这样做出的素祭带来献给耶和华，交给祭司，祭司就要把它拿到祭坛前。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 2:2; 腓立比书 4:18; 利未记 6:15"> 祭司要从素祭中取出记念的部分，在祭坛上烧献为烟，作馨香的火祭献给耶和华。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 2:3"> 素祭中所剩的，归于亚伦和他的子孙，这是耶和华火祭中的至圣物。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="加拉太书 5:9; 路加福音 12:1; 出埃及记 23:18"> “你们献给耶和华的任何素祭，都不可带着酵做成；因为任何酵、任何蜂蜜，你们都不可作为火祭烧献给耶和华。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 23:19; 创世记 23:10–11; 出埃及记 22:29"> 它们可以作为初熟之物的祭物献给耶和华，但不可献在祭坛上为馨香之气。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 43:24; 马太福音 5:13; 歌罗西书 4:6"> 所有素祭的祭物，你都要用盐调和。你素祭里不可缺少你的神立约的盐，你所有的祭物都要带着盐献上。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="利未记 23:10; 玛拉基书 1:11; 民数记 28:2"> “如果你献上初熟之物的素祭给耶和华，就要献上用火烘烤的新穗子——脱壳的新谷物，作为你初熟之物的素祭。</span>
<span className="v" id="v15" data-v="15"> 你要给它加上油，放上乳香；这是素祭。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 5:7; 罗马书 8:26–27; 以赛亚书 61:1"> 祭司要把素祭中作为记念的部分，就是其中一些脱壳的谷物和一些油，连同所有的乳香都烧献为烟，献给耶和华作火祭。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 4:6; 以弗所书 5:8–14; 出埃及记 27:20–21"> “你要吩咐以色列子民，把压榨的纯橄榄油拿来给你，用来点灯，使灯持续点燃着。</span>
<span className="v" id="v3" data-v="3"> 亚伦<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="亚伦——有古抄本和古译本作“亚伦和他的儿子们”；参《出埃及记》27:21。">a</a></sup>要在会幕中，在见证柜的幔子外面，从傍晚到早晨，在耶和华面前持续照管灯。这是你们世世代代永远的律例。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 31:8; 出埃及记 37:17–24; 出埃及记 39:37"> 他要在耶和华面前，持续照管纯金灯台上的灯。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及记 25:30; 列王纪上 18:31; 出埃及记 40:23"> “要取细面粉烘烤十二个饼，每个饼用十分之二伊法<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="十分之二伊法——相当于4.4公升。1伊法=22公升。">b</a></sup>面粉；</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 7:48; 出埃及记 25:23–24; 历代志下 4:19"> 然后在耶和华面前的纯金桌子上摆成两排，每排六个饼；</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 2:2; 启示录 8:3–4; 创世记 9:16"> 还要在每排放上纯乳香，作为饼的记念部分，献给耶和华为火祭。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 2:4; 民数记 4:7; 历代志上 9:32"> 每一个安息日都要这样摆上，使陈设饼常在耶和华面前；这是代表以色列子民永远的约。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 8:31; 路加福音 6:4; 马可福音 2:26"> 这饼要归属亚伦和他的儿子们；他们要在神圣的地方吃，因为这是耶和华火祭中的至圣物，是给他们作永远的份例。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民数记 11:4; 出埃及记 12:38"> 有一个以色列妇女的儿子——他父亲是埃及人——他来到以色列人当中。这以色列妇女的儿子和一个以色列人在营中打了起来，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 20:7; 利未记 24:15–16; 出埃及记 3:15"> 这以色列妇女的儿子亵渎圣名，咒骂神，于是人们把他带到摩西那里。他的母亲名叫示罗米，是但支派迪布利的女儿。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 18:15–16; 民数记 15:34; 民数记 27:5"> 人们把他拘押起来，等候耶和华给他们明确的指示。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 耶和华指示摩西说：</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 17:7; 利未记 20:27; 申命记 21:21"> “你把那咒骂神的人带到营地外，让所有听见的人都按手在他头上，然后全体会众要用石头砸死他。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 9:13; 出埃及记 22:28; 利未记 5:1"> 你要吩咐以色列子民说：凡是咒骂神的人，必承担自己的罪过。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 12:31; 雅各书 2:7; 约翰福音 10:33–36"> 亵渎耶和华之名的人，必须被处死，全体会众必须用石头砸死他。无论是外人还是本族人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="本族人——原文直译“本地人”；本章下同。">c</a></sup>，他亵渎圣名，就要被处死。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 9:5–6; 申命记 19:11–12; 申命记 27:24"> “夺取任何人性命的，这人必须被处死。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 24:21; 出埃及记 21:34–36"> 杀死牲畜的，就要对等赔偿，以命偿命。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 5:38; 马太福音 7:2; 申命记 19:21"> 如果有人使他的邻人伤残，他怎样对待人，也要怎样被对待：</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 19:21; 马太福音 5:38; 出埃及记 21:23–25"> 以伤还伤，以眼还眼，以牙还牙。他怎样使人伤残，也要怎样使他伤残。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 24:17–18; 出埃及记 21:33"> 杀死牲畜的，要对等赔偿；杀死人的，要被处死。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 12:49; 民数记 15:15–16; 民数记 9:14"> 你们要有同一个法规，外人怎样，本族人也要怎样。我是耶和华你们的神。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="希伯来书 10:28–29; 希伯来书 2:2–3; 民数记 15:35–36"> 于是，摩西吩咐以色列子民，他们就把那咒骂神的人带到营地外，用石头砸死了。耶和华所指示摩西的，以色列子民都遵行了。</span>
</div>

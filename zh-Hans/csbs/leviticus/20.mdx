<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 21:21; 利未记 18:21; 利未记 20:27"> “你要吩咐以色列子民：凡是把儿女献给摩洛的人，无论他是以色列人还是寄居在以色列的外人，必须被处死，这地的民众要用石头砸死他。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 18:21; 以西结书 5:11; 以西结书 23:38–39"> 我必对那人翻脸，把他从民中剪除，因为他把他的儿女献给摩洛，以致玷污了我的圣所，亵渎了我的圣名。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 17:2–5; 使徒行传 17:30; 列王纪上 20:42"> 当那人把他的儿女献给摩洛时，如果这地的民众对那人闭眼不管，不把他处死，</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 106:39; 何西阿书 2:13; 何西阿书 2:5"> 我就会亲自对那人和他的家族翻脸，把他和所有跟着他行淫追随摩洛的人，从民中剪除。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="利未记 19:31; 以赛亚书 8:19; 利未记 20:27"> “如果有人转向招魂的和通灵的，去行淫追随他们，我必对那人翻脸，把他从民中剪除。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 11:44; 利未记 19:2; 彼得前书 1:15–16"> 你们要使自己分别为圣，要圣洁，因为我是耶和华你们的神。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 31:13; 雅各书 1:22; 帖撒罗尼迦前书 5:23"> 你们要谨守遵行我的律例。我是把你们分别为圣的耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 21:17; 马可福音 7:10; 申命记 27:16"> “凡是诅咒父母的人，必须被处死；他诅咒了自己的父母，他的血债归在自己身上。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 8:4–5; 申命记 22:22–24; 申命记 5:18"> 凡是与别人的妻子通奸的，与邻人的妻子通奸的，这奸夫和淫妇都必须被处死。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 27:20; 申命记 27:23; 阿摩司书 2:7"> 凡是与父亲的妻妾同寝的人，他是裸露父亲的下体，这二人必须被处死，他们的血债归在自己身上。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 18:15; 利未记 18:23; 创世记 38:18"> 凡是与自己儿媳同寝的，这二人必须被处死；他们做了乱伦的事，他们的血债归在自己身上。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 6:9; 利未记 18:22; 犹大书 1:7"> 如果有男人与男人同寝，像与女人同寝那样，这二人是做了可憎之事，必须被处死，他们的血债归在自己身上。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 18:17; 申命记 27:23; 约书亚记 7:15"> 如果有人娶了妻子，又娶她的母亲，这是丑恶的，必须把这三人用火烧死，这样你们中间就不会有丑恶的事。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 18:23; 申命记 27:21; 出埃及记 22:19"> 如果有男人与动物交合，他必须被处死，也要把那动物杀掉。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 21:32; 出埃及记 19:13; 希伯来书 12:20"> 如果有女人亲近任何动物与它交合，必须把那女人和那动物杀掉，他们必须被处死，他们的血债归在自己身上。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 18:9; 申命记 27:22; 以西结书 22:11"> 如果有人娶了自己的姐妹——无论是他父亲的女儿还是他母亲的女儿——他看了姐妹的下体，姐妹也看了他的下体，这是可耻的事，他们必在族人面前被剪除。他裸露了自己姐妹的下体，必须承担自己的罪责。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 15:24; 利未记 18:19; 以西结书 18:6"> 如果有人与经期<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="经期——或译作“血漏”。">a</a></sup>的女人同寝，裸露她的下体，那是裸露她的血源，女人也裸露了自己的血源，他们二人必须从民中被剪除。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 18:6; 利未记 18:12–30; 出埃及记 6:20"> 不可裸露你姨母或姑母的下体；这是裸露自己血亲的下体，他们必须承担自己的罪责。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 18:14; 约伯记 18:19; 路加福音 23:29"> 如果有人与自己的叔母伯母同寝，这是裸露他叔伯的下体，他们必须承担自己的罪过，他们必没有子女而死。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 18:16; 马太福音 14:3–4"> 如果有人娶他兄弟的妻子，这是污秽的事，是裸露他兄弟的下体，他们二人必没有子女。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未记 18:25–28; 以西结书 36:27; 利未记 18:4–5"> “你们要谨守遵行我的一切律例和法规，以免我所领你们去居住的那地把你们吐出来。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 9:5; 利未记 18:24; 利未记 18:30"> 我将从你们面前驱逐的那些民族，你们不可随从他们的习俗；正是因为他们做了这一切，所以我厌恶他们，</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 14:2; 出埃及记 6:8; 申命记 7:6"> 而对你们说：‘你们要占有他们的土地；我要把这流奶与蜜之地赐给你们，让你们继承。’我是耶和华你们的神，把你们从万民中分别出来的那一位。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 14:3–21; 利未记 11:1–47; 使徒行传 10:11–15"> 你们要分别洁净和不洁净的走兽，分别不洁净和洁净的飞禽；不可因我给你们分别为不洁净的走兽、飞禽和地上的一切爬虫，使自己成为可憎的。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前书 1:15–16; 利未记 20:7; 利未记 20:24"> 你们要归于我为圣，因为我耶和华是圣洁的，我已经把你们从万民中分别出来，使你们归于我。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 19:31; 利未记 20:6; 撒母耳记上 28:7–9"> 无论是男人还是女人，如果有谁作招魂的或通灵的，就必须被处死；要用石头砸死他们，他们的血债归在自己身上。”</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 18:21; 申命记 15:19; 利未记 22:32"> “你要吩咐亚伦和他的儿子们，谨慎对待以色列子民所分别为圣归于我的圣物，以免亵渎我的圣名。我是耶和华。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 7:20–21; 民数记 19:13; 诗篇 16:11"> 你要对他们说：你们世世代代所有的后裔中，凡是身上不洁净的人，如果接近了以色列子民所分别为圣归于耶和华的圣物，这人就要从我的面前被剪除。我是耶和华。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 11:39; 利未记 15:2–3; 利未记 15:13–16"> 亚伦后裔中，凡是患麻风病或有漏症的人，在得洁净之前，不可吃圣物。如果有人触碰任何因尸体而不洁净的东西，或有人遗精，</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 11:43–44; 利未记 15:7; 利未记 15:19"> 或有人触碰任何使他不洁净的群居爬物，触碰使他不洁净的人——不管那人有怎样的不洁——</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 15:5; 希伯来书 10:22; 哈该书 2:13"> 如果有人触碰了这些，他就不洁净直到傍晚，除非他用水洗身，否则不可吃圣物。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 21:22; 申命记 18:3–4; 哥林多前书 9:13–14"> 日落时，他就洁净了，之后他可以吃圣物，因为这是他的食物。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 17:15; 出埃及记 22:31; 以西结书 44:31"> 他不可吃自然死去的或被咬死的动物，使自己受玷污。我是耶和华。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 28:43; 民数记 18:22; 民数记 18:32"> 他们要谨守我的吩咐，以免他们因亵渎了圣物，就承担罪过而死。我是把他们分别为圣的耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 12:4; 撒母耳记上 21:6; 出埃及记 29:33"> “祭司家以外的任何人都不可吃圣物，祭司家里的客居者和雇工，也不可吃圣物。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 17:13; 出埃及记 12:44; 民数记 18:11–13"> 但如果是祭司用银子买来的人，这人可以吃圣物；在祭司家里出生的人，也可以吃祭司的食物。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 40:13; 利未记 21:3"> 祭司的女儿如果嫁给祭司家以外的男人，她就不可吃供上的圣物。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 10:14; 创世记 38:11; 民数记 18:11–19"> 但祭司的女儿如果成了寡妇或被休了，而且没有后裔，又像她年幼时那样回到她的父家，就可以吃她父亲的食物；祭司家以外的任何人，都不可吃。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 27:15; 利未记 27:13; 利未记 5:15–19"> 如果有人无意中吃了圣物，就要把圣物加上五分之一，交还给祭司。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 18:32; 利未记 19:8; 以西结书 22:26"> 不可亵渎以色列子民献给耶和华的圣物，</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 22:9; 彼得前书 2:24; 以赛亚书 53:11–12"> 使人们因吃了圣物而承担罪责。要知道，我是把他们分别为圣的耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和华指示摩西说：</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 1:2; 申命记 12:6; 民数记 15:3"> “你要吩咐亚伦和他的儿子们，以及所有的以色列子民，对他们说：凡是以色列家中或以色列中寄居的人，如果要献上他的祭物，无论是还愿祭或是献给耶和华为燔祭的甘心祭，</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 1:10; 利未记 1:3; 以弗所书 5:27"> 都必须是无瑕疵的公牛、公绵羊或公山羊，使你们可蒙悦纳。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 17:1; 玛拉基书 1:8; 申命记 15:21"> 任何身上有残疾的祭牲，你们都不可献上，因为它不能代表你们蒙悦纳。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数记 15:8; 民数记 15:3; 利未记 3:6"> “如果有人从牛群或羊群中带来平安祭物献给耶和华，无论是还特殊的愿或是作甘心祭，都必须是无瑕疵的，才蒙悦纳，它身上不可有任何残疾。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 22:20; 玛拉基书 1:8; 利未记 1:9"> 瞎眼的、骨折的、伤残的、有瘤子的、生癣的、长疥的，这些都不可献给耶和华，不可作为火祭在祭坛上献给耶和华。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 21:18"> 肢体过长或过短的牛羊，可以作甘心祭献上，但作还愿祭，就不会蒙悦纳。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 22:20; 申命记 23:1; 利未记 21:20"> 睾丸被挫伤、压碎、破裂或骟割的，都不可献给耶和华。在你们的地上，不可这样做，</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 21:8; 以斯拉记 6:8–10; 民数记 15:14–16"> 也不可接受外邦人手中任何这样的牲畜，作你们神的食物献上；因为这些身上有损伤、有残疾的，不能代表你们蒙悦纳。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和华指示摩西说：</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 22:30; 利未记 19:23–24; 利未记 22:25"> “刚出生的公牛、绵羊或山羊，当跟着它母亲七天，从第八天开始可以蒙悦纳为祭牲，献给耶和华作火祭。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 22:6–7; 申命记 14:21; 出埃及记 34:26"> 不可在同一天，把牛或羊与它的幼仔一起宰杀了。</span>
<span className="v" id="v29" data-v="29" data-xref="诗篇 116:17; 诗篇 107:22; 阿摩司书 4:5"> 当你们献上感谢祭给耶和华时，要献得使你们可蒙悦纳；</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 7:15–18; 出埃及记 16:19–20; 利未记 19:7"> 要当天吃掉祭物，一点也不可留到次日早晨。我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="申命记 4:40; 利未记 19:37; 民数记 15:40"> “你们要谨守遵行我的诫命。我是耶和华。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 18:21; 路加福音 11:2; 马太福音 6:9"> 你们不可亵渎我的圣名，我在以色列子民中要被尊为圣。我是把你们分别为圣的耶和华，</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 11:45; 出埃及记 6:7; 利未记 25:38"> 是我把你们从埃及地领出来，为要作你们的神。我是耶和华。”</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="LEV" data-book-slug="leviticus" data-book-name="利未记" data-chapter="27" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 6:2; 撒母耳记上 1:28; 士师记 11:30–31"> “你要吩咐以色列子民，对他们说：当一个人向耶和华还特殊的愿，涉及到为人估价，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 30:13; 利未记 27:25; 民数记 18:16"> 你的估价应该是这样：按圣所的谢克尔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="谢克尔——重量单位；后来成为货币单位。1谢克尔=11.4公克。本章下同。">a</a></sup>标准，男子从二十岁到六十岁，估价为五十谢克尔银子；</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 27:9–10; 撒迦利亚书 11:12–13; 马太福音 26:15"> 如果是女人，估价为三十谢克尔。</span>
<span className="v" id="v5" data-v="5"> 如果是从五岁到二十岁，估价为男人二十谢克尔，女人十谢克尔。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 3:40–43; 民数记 18:14–16"> 如果是从一个月到五岁，要给男人估价五谢克尔银子，给女人估价三谢克尔银子。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 90:10"> 如果是六十岁以上，男人的估价是十五谢克尔，而女人是十谢克尔。</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 14:7; 利未记 14:21–22; 路加福音 21:1–4"> 如果他穷得付不起这估价，就要让他站在祭司面前，由祭司估价；祭司要按许愿者能负担的，为他估价。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> “所许的如果是可献给耶和华为祭物的牲畜，他献给耶和华的一切，都要成为神圣的。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 27:15–33; 雅各书 1:8"> 他不可更改，也不可替换，无论是以坏换好，或是以好换坏。如果他还是以牲畜替换了牲畜，那么，原来的和所替换的都要成为神圣的。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="申命记 23:18; 玛拉基书 1:14"> “所许的如果是任何不洁净的牲畜，是不可献给耶和华为祭物的，他就要让那牲畜站在祭司面前，</span>
<span className="v" id="v12" data-v="12"> 由祭司来区分好坏，给出估价；祭司怎样估价，就怎样为准。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 27:19; 利未记 27:15; 利未记 22:14"> 如果他一定要赎回那牲畜，就要在这估价上加五分之一。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 18:14; 利未记 25:29–31; 利未记 27:21"> “如果有人把自己的房屋分别为圣，归于耶和华，要由祭司来区分好坏，给出估价；祭司怎样估价，就怎样定准。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 27:13"> 那把房屋分别为圣的人，如果要赎回自己的房屋，就要在你所估的价银上加五分之一，这样房屋就归属于他。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以西结书 45:11–14; 何西阿书 3:2; 使徒行传 4:34–37"> “如果有人把自己一部分田产分别为圣，归于耶和华，要按那地的撒种量来估价，一贺梅珥<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一贺梅珥——相当于220公升。">b</a></sup>大麦种子为五十谢克尔<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="五十谢克尔——相当于570公克。">c</a></sup>银子。</span>
<span className="v" id="v17" data-v="17"> 如果他是在禧年把田地分别为圣，就要照估价来定准；</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 25:15–16; 利未记 25:51–52; 利未记 25:27"> 但如果他是在禧年之后把田地分别为圣，祭司就要照着下一个禧年之前所剩的年数，给他核算价银，然后从估价中减去。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 27:13"> 那把地分别为圣的人，如果一定要赎回田地，就要在你所估的价银上加五分之一，这样田地就定准归他。</span>
<span className="v" id="v20" data-v="20"> 但如果他不赎回田地，或者把田地卖给了别人，田地就再不能赎回了。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 44:29; 民数记 18:14; 利未记 25:31"> 到了禧年该退还的时候，那块田地要归耶和华为圣，就像永献的田地那样，归于祭司为产业。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未记 25:10; 利未记 25:25"> “如果有人把他所购买、原不属于自己田产的田地，分别为圣归于耶和华，</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 27:18; 利未记 27:12"> 祭司就要为他核算到禧年为止的估价数目，他要当天交付那估价，归耶和华为圣。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 25:28; 利未记 27:20"> 到了禧年，这田地要归还卖主，就是产业之地的原主。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 30:13; 民数记 18:16; 民数记 3:47"> 你所有的估价，都要按圣所的谢克尔标准，二十季拉<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="二十季拉——相当于11.4公克。1季拉=0.57公克。">d</a></sup>为一谢克尔。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 13:2; 出埃及记 13:12–13; 民数记 18:17"> “然而那头生的，就是属于耶和华的头胎牲畜，任何人不可把它分别为圣；无论是牛还是羊，那原是属于耶和华的。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 27:11"> 如果那是不洁净的牲畜，就要按估价赎回，并且在估价上加五分之一；如果不赎回，就要按估价卖了。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约书亚记 6:17–19; 利未记 27:21; 出埃及记 22:20"> “一切永献之物，就是人从他所拥有的一切中永远奉献给耶和华的——无论是人、是牲畜，还是田产——都不可卖掉，也不可赎回。一切永献之物，都是归于耶和华的至圣物。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记上 15:18–23; 民数记 21:2–3"> 一切被永献为当灭之物的人，都不可赎回，他必须被处死。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="马太福音 23:23; 尼希米记 13:12; 创世记 28:22"> “土地的一切出产，无论是地上的谷物，还是树上的果实，十分之一都属于耶和华，要归耶和华为圣。</span>
<span className="v" id="v31" data-v="31"> 如果有人决定要赎回他十一奉献的一部分，他就要在原价上加五分之一。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 33:13; 以西结书 20:37; 弥迦书 7:14"> 一切牛群、羊群的十分之一，就是从杖下经过的每第十只，都要归耶和华为圣。</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 27:10"> 不可查究好坏，不可替换。如果他还是替换了，那么，原来的和替换的都要成为神圣的，并且不可被赎回。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="利未记 26:46; 民数记 1:1; 希伯来书 12:18–25"> 以上是耶和华在西奈山藉着摩西向以色列子民颁布的诫命。</span>
</div>
</div>

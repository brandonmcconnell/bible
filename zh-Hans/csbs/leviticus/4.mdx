<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 19:12; 希伯来书 9:7; 利未记 4:27"> “你要吩咐以色列子民：当一个人无意中犯了罪，做了耶和华诫命中不可做的任何一件事：</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="希伯来书 7:27–28; 利未记 4:14; 利未记 9:2"> “如果是受膏的祭司犯罪，连累百姓有了罪，他就要为自己所犯的罪，把一头无瑕疵的公牛献给耶和华作赎罪祭。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 1:3–4; 但以理书 9:26; 以赛亚书 53:6"> 他要把公牛牵到会幕入口耶和华面前，按手在公牛的头上，在耶和华面前把公牛宰杀了。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 16:14; 民数记 19:4; 利未记 4:16–17"> 受膏的祭司要取一些公牛的血，带进会幕；</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 16:14; 利未记 14:18; 利未记 26:28"> 祭司要把手指蘸到血里，在耶和华面前把一些血对着圣所的幔子弹洒七次；</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 8:15; 利未记 9:9; 利未记 16:18"> 祭司也要在会幕中耶和华面前的香坛犄角上涂一些血，然后把公牛其余的血全都倒在会幕入口的燔祭坛基座那里。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 3:3–5; 利未记 4:26; 利未记 4:31"> 他要取出这赎罪祭公牛的全部脂肪：覆盖内脏的脂肪，内脏上的全部脂肪，</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 3:4"> 两个肾脏和肾脏上靠近腰部的脂肪，以及肾脏上方的肝叶，都要取下来，</span>
<span className="v" id="v10" data-v="10"> 就像从平安祭所献的公牛取出那样。祭司要在燔祭坛上把这些烧献为烟。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 19:5; 出埃及记 29:14; 利未记 9:8–11"> 至于公牛的皮和所有的肉，连同头、腿、内脏和粪便，</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 13:11; 出埃及记 29:14; 利未记 16:27"> 就是公牛其余的一切，都要带到营地外洁净之地倒灰烬的地方，然后在木柴上用火焚烧，在倒灰烬的地方烧掉。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未记 5:17; 利未记 5:2–5; 何西阿书 5:15"> “如果全体以色列会众无意中有过失，会众却对此没有察觉，做了耶和华诫命中不可做的任何一件事，因而有了罪责，</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 4:23; 利未记 4:3; 利未记 4:28"> 一旦他们知道自己在诫命上所犯的罪，就要献上一头公牛作赎罪祭。他们要把牛牵到会幕前面，</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 1:4; 利未记 16:21; 利未记 8:14"> 会众的长老要在耶和华面前按手在公牛的头上，在耶和华面前把公牛宰杀了。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 4:5–12; 希伯来书 9:12–14"> 受膏的祭司要把一些公牛的血带进会幕；</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 4:6–7"> 祭司要用手指蘸一些血，在耶和华面前对着幔子弹洒七次；</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 4:7"> 也要在会幕中耶和华面前的祭坛犄角上涂一些血，然后把其余的血全都倒在会幕入口的燔祭坛基座那里。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 5:6; 利未记 4:26; 民数记 15:25"> 他要取出这公牛的全部脂肪，在祭坛上烧献为烟。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 15:25; 希伯来书 10:10–12; 利未记 12:8"> 他处理这公牛，要像处理赎罪祭所献的公牛那样，同样处理。这样，祭司为他们赎罪，他们就得到赦免。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 16:15; 马太福音 20:28; 哥林多后书 5:21"> 公牛其余的一切<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="其余的一切——辅助词语。">a</a></sup>要带到营地外，像焚烧前一头公牛那样烧掉；这是会众的赎罪祭。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未记 4:2; 利未记 4:13; 民数记 31:13"> “如果一个领袖犯罪，无意中做了他的神耶和华诫命中不可做的任何一件事，因而有了罪责，</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 4:14; 罗马书 8:3; 民数记 7:22"> 一旦他知道自己在诫命上所犯的罪，他就要牵来一只无瑕疵的公山羊为祭物。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 3:13; 利未记 7:2; 利未记 4:3–35"> 他要按手在公山羊的头上，在宰杀燔祭牲的地方，在耶和华面前把它宰杀了；这是赎罪祭。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 4:7; 利未记 4:18; 利未记 4:30"> 祭司要用手指取一些赎罪祭的血，抹在燔祭坛的犄角上，然后把其余的血倒在燔祭坛基座那里。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 4:20; 利未记 4:31; 利未记 4:35"> 他要像烧献平安祭的脂肪那样，在祭坛上把全部的脂肪烧献为烟。这样，祭司为他的罪赎罪，他就得到赦免。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="利未记 4:2; 民数记 15:27; 利未记 4:13"> “如果这地的百姓有一个人无意中犯了罪，做了耶和华诫命中不可做的任何一件事，因而有了罪责，</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 4:23; 利未记 4:3; 利未记 4:32"> 一旦他知道自己所犯的罪，就要为他所犯的罪牵来一只无瑕疵的母山羊为祭物。</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 4:4; 利未记 4:24; 利未记 1:4"> 他要按手在赎罪祭牲的头上，在燔祭的地方宰杀这赎罪祭。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 4:7; 利未记 4:25; 利未记 4:34"> 祭司要用手指取一些血，抹在燔祭坛的犄角上，然后把其余的血全都倒在祭坛的基座那里。</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 4:26; 利未记 4:35; 利未记 1:9"> 他要取出全部的脂肪，就像从平安祭的祭牲上取下脂肪那样。祭司要把这些在祭坛上烧献为烟，作馨香之气献给耶和华。这样，祭司为他赎罪，他就得到赦免。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="利未记 4:28; 彼得前书 3:18; 彼得前书 2:22"> “他如果是带来一只绵羊羔作为赎罪祭，就要带来一只无瑕疵的母羊。</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 4:29–31; 利未记 4:4"> 他要按手在赎罪祭牲的头上，在宰杀燔祭牲的地方把它宰杀作赎罪祭。</span>
<span className="v" id="v34" data-v="34" data-xref="利未记 4:30; 利未记 4:25; 利未记 4:7"> 祭司要用手指取一些赎罪祭的血，抹在燔祭坛的犄角上，然后把其余的血全都倒在祭坛的基座那里。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 4:26; 利未记 4:20; 利未记 14:18"> 他要取出绵羊的全部脂肪，就像从平安祭的祭牲上取下脂肪那样；祭司要把这些与耶和华的火祭一起在祭坛上烧献为烟。这样，祭司为他所犯的罪赎罪，他就得到赦免。</span>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="LEV" data-book-slug="leviticus" data-book-name="利未记" data-chapter="8" data-verses="36">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 28:2–4; 出埃及记 39:41; 希伯来书 7:27"> “你要把亚伦和他的儿子们带来，也带来圣衣、膏油、赎罪祭的公牛、两只公绵羊和一篮子无酵饼，</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 30:13; 使徒行传 2:1; 尼希米记 8:1"> 然后招聚全体会众到会幕入口。”</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 39:26; 出埃及记 39:7; 出埃及记 39:5"> 摩西就照着耶和华指示他的去做。于是会众聚集到会幕入口，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 29:4–37"> 摩西对会众说：“耶和华指示要做以下的事。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 6:11; 以弗所书 5:26; 出埃及记 29:4"> 摩西让亚伦和他的儿子们上前来，用水洗净他们。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 28:4; 以赛亚书 61:10; 加拉太书 3:27"> 然后给亚伦穿上袍子，束上腰带，穿上外袍，套上以弗得，再用精巧的织带束好以弗得，系在他身上。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 2:63; 帖撒罗尼迦前书 5:8; 以赛亚书 59:17"> 再给他戴上胸牌，把乌陵和土明放在胸牌里；</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比书 2:9–11; 撒迦利亚书 6:11–14; 出埃及记 28:36–38"> 最后把顶冠戴在亚伦头上，在顶冠前面安上金牌，就是圣冠。这都是照着耶和华指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及记 40:9–11; 利未记 8:2; 出埃及记 30:23–29"> 摩西拿着膏油，膏抹了帐幕和它里面的一切，使它们分别为圣；</span>
<span className="v" id="v11" data-v="11" data-xref="提多书 3:6; 出埃及记 30:29; 出埃及记 16:19"> 又把一些膏油向祭坛弹洒七次，并膏抹了祭坛和祭坛的一切器具，以及洗濯盆和盆座，使它们分别为圣。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 30:30; 诗篇 133:2; 出埃及记 29:7"> 然后在亚伦头上浇了一些膏油，膏抹他，使他分别为圣。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 29:8–9; 启示录 5:10; 启示录 1:6"> 接着，摩西让亚伦的儿子们上前来，给他们穿上袍子，束上腰带，戴上头巾，都是照着耶和华指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以西结书 43:19; 诗篇 66:15; 彼得前书 3:18"> 摩西把赎罪祭的公牛牵来，亚伦和他的儿子们按手在赎罪祭公牛的头上。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 4:7; 希伯来书 9:18–23; 以西结书 43:19–27"> 宰杀后，摩西取了一些血，用手指抹在祭坛四围的犄角上，洁净祭坛，把其余的血倒在祭坛的基座那里，使祭坛分别为圣，为祭坛行赎罪礼。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 29:13; 利未记 3:3–5; 利未记 4:8–9"> 然后取出内脏上的全部脂肪、肝叶、两个肾脏和肾脏的脂肪，摩西把这些在祭坛上烧献为烟。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 4:11–12; 出埃及记 29:14; 利未记 6:30"> 公牛其余的一切<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="其余的一切——辅助词语。">a</a></sup>——它的皮、肉和粪便，都在营地外用火烧掉了。这都是照着耶和华指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未记 8:2; 利未记 1:4–13; 出埃及记 29:15–18"> 接着，摩西把燔祭的公绵羊牵来，亚伦和他的儿子们按手在公绵羊的头上。</span>
<span className="v" id="v19" data-v="19"> 宰杀后，摩西把血洒在祭坛四壁。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 1:8"> 公绵羊切成了块，摩西就把头、肉块和板油烧献为烟。</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所书 5:2; 出埃及记 29:18; 利未记 1:17"> 用水洗净内脏和腿之后，摩西把整只公绵羊在祭坛上烧献为烟。这是馨香的燔祭，是献给耶和华的火祭，都是照着耶和华指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未记 8:2; 利未记 8:29; 出埃及记 29:19–31"> 接着，摩西牵来第二只公绵羊，就是圣职礼所用的公绵羊，亚伦和他的儿子们按手在公绵羊的头上。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 29:20; 利未记 14:14; 罗马书 12:1"> 宰杀后，摩西取了一些血，抹在亚伦的右耳垂上，以及右手拇指和右脚拇趾上。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 9:18–22"> 又让亚伦的儿子们上前来，摩西把一些血抹在他们的右耳垂上，以及右手拇指和右脚拇趾上，然后摩西把血洒在祭坛四壁。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 3:9; 利未记 3:3–5; 以赛亚书 53:10"> 接着取下了脂肪、肥尾巴、内脏上的全部脂肪、肝叶、两个肾脏和肾脏的脂肪，以及右腿，</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 29:23; 提摩太前书 2:5; 使徒行传 5:12"> 又从耶和华面前的无酵饼篮子中取出一个无酵饼、一个油饼、一个薄饼，放在脂肪和右腿上。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 30:21; 希伯来书 9:14; 出埃及记 29:24–37"> 摩西把这一切放在亚伦手上以及他儿子们的手上，作为摇献祭物在耶和华面前摇一摇。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 29:25; 诗篇 22:13–14; 希伯来书 10:14–22"> 然后，摩西从他们手上把这些接过来，连同燔祭在祭坛上烧献为烟；这些是馨香的圣职祭，是献给耶和华的火祭。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 10:31; 彼得前书 4:11; 利未记 7:30–34"> 摩西又拿起胸肉，作为摇献祭物在耶和华面前摇一摇；这是圣职礼所用的公绵羊中给摩西的份，是照着耶和华指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及记 29:21; 民数记 3:3; 出埃及记 30:30"> 摩西取了一些膏油和祭坛上的血，弹洒在亚伦的身上和衣服上，以及他儿子们的身上和衣服上，使亚伦和他的衣服，以及他儿子们和他们的衣服分别为圣。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及记 29:31–32; 加拉太书 2:20; 撒母耳记上 2:13–17"> 摩西对亚伦和他的儿子们说：“你们要在会幕的入口煮祭肉，在那里吃这肉和圣职祭篮子里的饼，正如我所受的吩咐<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="我所受的吩咐——依据有些古抄本；马索拉文本作“我所吩咐的说”。">b</a></sup>：亚伦和他的儿子们要吃这些。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 29:34; 出埃及记 12:10; 希伯来书 3:13–14"> 剩下的肉和饼，都要用火烧掉。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 29:35; 民数记 19:12; 以西结书 43:25–27"> 七天之内，你们不可走出会幕入口，直到你们圣职礼日期满了的那天为止，因为你们承接圣职需要七天。</span>
<span className="v" id="v34" data-v="34" data-xref="希伯来书 7:27; 希伯来书 7:16; 希伯来书 10:11–12"> 今天所做的，是耶和华吩咐要做的，为你们赎罪。</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 3:7; 申命记 11:1; 列王纪上 2:3"> 七天之内，你们要日夜留在会幕入口，谨守耶和华的要求，以免你们死亡；我是如此受的吩咐。”</span>
<span className="v" id="v36" data-v="36" data-xref="申命记 12:32; 申命记 4:2; 出埃及记 40:16"> 于是亚伦和他的儿子们，遵行了耶和华藉着摩西所指示的一切事。</span>
</div>
</div>

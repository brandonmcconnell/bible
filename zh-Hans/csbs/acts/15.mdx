<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 5:6; 使徒行传 15:5; 利未记 12:3"> 有一些人从犹太下来，教导弟兄们说：“你们如果不按摩西的规矩受割礼，就不能得救。”</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 15:22–23; 使徒行传 15:6–7; 加拉太书 2:1–2"> 保罗、巴拿巴与他们发生了不小的争执和辩论，他们就指定保罗、巴拿巴和其中的另一些人为这争议的问题，上耶路撒冷到使徒们和长老们那里去。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 14:27; 使徒行传 21:5; 哥林多前书 16:11"> 于是教会送他们上路；他们就走遍腓尼基和撒玛利亚地区，详细说明外邦人悔改的事，给所有弟兄们带来了极大的喜乐。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="使徒行传 14:27; 使徒行传 15:12; 使徒行传 15:3"> 来到耶路撒冷，他们受到教会、使徒们和长老们的欢迎，就向大家传讲了神与他们一起做的事。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 5:1–3; 腓立比书 3:5–8; 使徒行传 15:1"> 但法利赛教派中的一些信徒站起来，说：“必须给外邦人行割礼，并吩咐他们遵守摩西的律法。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="箴言 15:22; 希伯来书 13:7; 希伯来书 13:17"> 使徒们和长老们就聚集探讨这件事。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 10:17–18; 加拉太书 2:7–9; 历代志上 28:4–5"> 经过了许多辩论，彼得站起来对他们说：“各位弟兄，你们知道前些时候神在你们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你们——有古抄本作“我们”。">a</a></sup>中间施行拣选，要外邦人藉着我的口听到福音之道，得以相信。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 1:24; 使徒行传 10:47; 使徒行传 14:3"> 于是那洞察人心的神，赐圣灵给他们做了见证，就像为我们做的那样；</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 3:6; 加拉太书 5:6; 使徒行传 10:28"> 又藉着信洁净了他们的心，在我们和他们之间不做什么区别。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 5:1; 马太福音 23:4; 加拉太书 4:9"> 既然如此，你们现在为什么试探神，把我们的祖先和我们都担当不了的轭，放在那些门徒的脖子上呢？</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 3:24; 提多书 3:4–7; 提多书 2:11"> 相反，我们相信：我们得救是藉着主耶稣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="耶稣——有古抄本作“耶稣基督”。">b</a></sup>的恩典，外邦人也是一样。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 14:27; 使徒行传 15:4; 使徒行传 21:19"> 这时，全体会众都静默无声，听巴拿巴和保罗述说神藉着他们在外邦人中所行的神迹和奇事。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 12:17; 加拉太书 2:12; 雅各书 1:1"> 他们讲完以后，雅各就回应说：“各位弟兄，请听我说。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得后书 1:1; 使徒行传 15:7–9; 路加福音 2:31–32"> 西门已经述说了神当初怎样临到<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="临到——或译作“照顾”。">c</a></sup>外邦人，从他们中间选出子民，归入自己的名。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 15:8–12; 使徒行传 13:47"> 连先知们的话也与此相符，正如经上所记：</span>
<span className="v" id="v16" data-v="16" data-xref="阿摩司书 9:11–12; 诗篇 89:35–49; 路加福音 1:31–33"> <span className="pl pl-1">‘此后我将要回来，</span><br /><span className="pl pl-1">重建大卫倒塌的居所</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="居所——原文直译“帐幕”。">d</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">我要重建它的破损之处，把它重新竖立起来。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="撒迦利亚书 2:11; 撒迦利亚书 8:20–23; 以赛亚书 65:1"> <span className="pl pl-1">这样，其余的人，</span><br /><span className="pl pl-1">就是所有被称为我名下的外邦人，</span><br /><span className="pl pl-1">都会寻求主。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 1:4; 以弗所书 3:9; 以赛亚书 46:9–10"> <span className="pl pl-1">这是自古以来，让人知道这些事的主说的。’</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 15:28; 加拉太书 1:7–10; 使徒行传 15:24"> 因此，我判定不可为难那些归向神的外邦人，</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 15:29; 启示录 2:20; 利未记 3:17"> 不过要写信给他们：要远避偶像的污秽，远避淫乱、勒死的动物和血。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 13:15; 使徒行传 13:27; 哥林多后书 3:14–15"> 因为自古以来，在各城里都有人宣讲摩西，每逢安息日在各会堂里都有人诵读他的书<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="他的书——辅助词语。">e</a></sup>。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 15:27; 使徒行传 15:40; 帖撒罗尼迦前书 1:1"> 当时，使徒们、长老们和全教会都认为应该从他们当中拣选几个人，派他们与保罗和巴拿巴一起到安提阿去。被选的是<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="被选的是——辅助词语。">f</a></sup>那称为巴撒巴的犹大和西拉斯，这两个人在弟兄中是领头的。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 23:26; 雅各书 1:1; 加拉太书 1:21"> 他们带去的信这样写着：<br />“做使徒的和年长的弟兄们，问候安提阿、叙利亚省和奇里乞亚省的外邦弟兄们。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="加拉太书 5:12; 加拉太书 5:10; 使徒行传 15:1"> 我们听说从我们这里出去<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本没有“出去”。">g</a></sup>的一些人，用一些话使你们不安，搅扰你们的心灵。<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附“说你们必须受割礼并遵守律法。”">h</a></sup>其实我们没有吩咐他们。</span>
<span className="v" id="v25" data-v="25" data-xref="彼得后书 3:15; 使徒行传 1:14; 使徒行传 15:2"> 我们已达成了一致，认为应该拣选几个人，派他们与我们亲爱的巴拿巴和保罗一起到你们那里去。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 14:19; 使徒行传 9:23–25; 腓立比书 2:29–30"> 这两个人都为我们主耶稣基督的名，已经把自己的生命置之度外。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 15:22; 使徒行传 15:32; 约翰三书 1:13"> 所以我们派了犹大和西拉斯去，他们会亲口报告同样的事，</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 16:13; 启示录 2:24; 马太福音 11:30"> 因为圣灵和我们都认为，除了以下几件必须遵守的事以外，不该把更多的重担加给你们：</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 15:20; 使徒行传 21:25; 启示录 2:14"> 就是要远避祭过偶像的食物，远避血和勒死的动物，远避淫乱。你们如果保守自己远离这些，就做得很好了。<br />祝你们安康！”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行传 16:4; 使徒行传 6:2; 使徒行传 23:33"> 于是这些人被派遣，下<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="下——有古抄本作“去”。">i</a></sup>到安提阿，召集了会众，把信函交给他们。</span>
<span className="v" id="v31" data-v="31" data-xref="加拉太书 2:4–5; 腓立比书 3:3; 加拉太书 5:1"> 读完了信，会众因着那鼓励的话而感到欢喜。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 11:23; 使徒行传 14:22; 使徒行传 13:1"> 犹大和西拉斯自己也是做先知传道的<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="做先知传道的——原文直译“先知”。">j</a></sup>。他们用很多话鼓励弟兄们，坚固他们。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 16:11; 使徒行传 16:36; 希伯来书 11:31"> 两个人住了一段时间，弟兄们就打发他们平平安安地回到差派他们的人<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="差派他们的人——有古抄本作“使徒们”。">k</a></sup>那里去。</span>
<span className="v" id="v34" data-v="34"> 可是西拉斯认为应该留在那里。<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本没有此节。">l</a></sup></span>
<span className="v" id="v35" data-v="35" data-xref="提摩太后书 4:2; 歌罗西书 1:28; 使徒行传 13:1"> 保罗和巴拿巴也住在安提阿，与其他许多人一起教导、传扬主的福音<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="福音——原文直译“话语”或“道”。">m</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行传 14:6; 使徒行传 13:4; 使徒行传 13:51"> 过了几天，保罗对巴拿巴说：“来，让我们回到我们传过主福音<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="福音——原文直译“话语”或“道”。">n</a></sup>的每一个城，探望<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="探望——或译作“照顾”。">o</a></sup>弟兄们，看看他们的情况怎么样<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="看看他们的情况怎么样——原文直译“看看他们现在怎么样”。">p</a></sup>。”</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 12:12; 腓利门书 1:24; 使徒行传 13:5"> 巴拿巴一直想要带那称为马可的约翰一起去。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 13:13; 箴言 25:19; 路加福音 14:27–34"> 但是保罗觉得不该带他一起去，因为他曾在潘菲利亚省离开他们，没有陪他们一起去工作。</span>
<span className="v" id="v39" data-v="39" data-xref="歌罗西书 4:10; 传道书 7:20; 使徒行传 4:36"> 两个人起了激烈的争执，以致彼此分手。巴拿巴带着马可，坐船到塞浦路斯岛去；</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行传 15:22; 使徒行传 14:26; 使徒行传 11:23"> 保罗却选了西拉斯。弟兄们把保罗交托于主<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="主——有古抄本作“神”。">q</a></sup>的恩典之后，他就出发了。</span>
<span className="v" id="v41" data-v="41" data-xref="使徒行传 15:23; 加拉太书 1:21; 使徒行传 15:32"> 保罗走遍叙利亚省和奇里乞亚省，坚固各教会。</span>
</div>
</div>

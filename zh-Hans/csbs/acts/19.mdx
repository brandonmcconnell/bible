<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 18:23–28; 哥林多前书 16:12; 哥林多前书 1:12"> 阿波罗在哥林多的时候，保罗经过内陆地区，来到以弗所城，在那里他遇见一些门徒，</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 7:39; 使徒行传 11:15–17; 加拉太书 3:5"> 问他们：“你们信的时候，是否领受了圣灵？”<br />他们告诉他：“其实我们也没有听说过是否有圣灵。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="使徒行传 18:25; 哥林多前书 12:13; 使徒行传 8:16"> 保罗又问：“那么，你们受的是什么洗呢？”<br />他们说：“是约翰的洗礼。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰福音 1:29–34; 使徒行传 11:16; 使徒行传 1:5"> 保罗说：“约翰所施的是悔改的洗礼，他告诉民众当相信在他以后来的那一位，就是相信耶稣<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="耶稣——有古抄本作“耶稣基督”。">a</a></sup>。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 8:12; 使徒行传 8:16; 罗马书 6:3–4"> 他们听了，就受洗<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="受洗——或译作“受浸”。">b</a></sup>归入了主耶稣的名<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="受洗归入了主耶稣的名——或译作“奉主耶稣的名受了洗”。">c</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 6:6; 使徒行传 2:4; 马可福音 16:17"> 接着，保罗按手在他们身上，圣灵就临到了他们。他们就说起殊言<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="殊言——原文直译“舌头”；传统译法作“方言”。">d</a></sup>，又说预言。</span>
<span className="v" id="v7" data-v="7"> 他们一共约有十二个人。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 28:23; 使徒行传 1:3; 使徒行传 9:20–22"> 保罗进了会堂，放胆传道，一连三个月讲论并劝导人相信那些有关神国的事。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 19:23; 使徒行传 9:2; 使徒行传 18:6–8"> 后来，当有些人心里刚硬、不肯信从，在会众面前诽谤这道<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="道——或译作“路”。">e</a></sup>的时候，保罗就离开他们，把门徒们分别出来，天天在特拉诺斯讲堂里讲论。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 20:31; 提摩太后书 1:15; 使徒行传 16:6"> 这样持续了两年，结果所有住在亚细亚省的人，无论是犹太人或希腊人，都听到了主<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="主——有古抄本作“主耶稣”。">f</a></sup>的福音<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="福音——原文直译“话语”或“道”。">g</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马可福音 16:17–20; 使徒行传 5:12; 罗马书 15:18–19"> 神藉着保罗的手，行了一些不寻常的神迹，</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 5:15; 列王纪下 13:20–21; 马可福音 16:17"> 甚至有人把保罗身上的手巾和围裙拿去，放在病人身上，疾病就从他们身上消退了，邪灵也<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附“从他们身上”。">h</a></sup>出去了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马太福音 12:27; 马可福音 9:38; 路加福音 11:19"> 可是有一些四处游历的犹太驱魔师，向那些有邪灵附身的人，擅自称呼主耶稣的名，说：“我藉着保罗所传的耶稣，吩咐你们出来<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="出来——辅助词语。">i</a></sup>。”</span>
<span className="v" id="v14" data-v="14"> 有一个名叫斯克瓦的犹太祭司长，他的七个儿子都在做这种事。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 16:17–18; 路加福音 4:33–35; 马可福音 1:34"> 邪灵回答他们，说：“耶稣我认识，保罗我也知道！但你们呢？你们是谁？”</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 8:29; 马可福音 5:3–4; 马可福音 5:15"> 有邪灵附身的那个人就跳到他们身上，压制了所有的人<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="所有的人——或译作“两个人” 。">j</a></sup>，胜过了他们，以致他们赤着身带着伤，从那房子逃了出去。</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦后书 1:12; 使徒行传 5:5; 腓立比书 2:9–11"> 所有住在以弗所的犹太人和希腊人，都知道了这件事，恐惧就临到了他们每个人，主耶稣的名因此被尊为大。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 10:10; 诗篇 32:5; 马太福音 3:6"> 而且许多信徒都来，承认并述说自己的所作所为。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 13:8; 出埃及记 32:20; 创世记 35:4"> 又有许多行邪术的人，把他们的书籍拿到一处，当众烧掉。他们估算了那些书的价值，发现共值<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="共值——辅助词语。">k</a></sup>五万个银币<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="五万个银币——原文为“50,000银子”或“50,000银钱”；价值相当于50,000锥克玛。1锥克玛=约1日工资的希腊银币。">l</a></sup>。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 12:24; 使徒行传 6:7; 以赛亚书 55:11"> 这样，主的福音<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="福音——原文直译“话语”或“道”。">m</a></sup>就大有能力地不断扩展<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="扩展——原文直译“生长”。">n</a></sup>，不断得胜。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 20:22; 使徒行传 20:16; 使徒行传 23:11"> 这些事过了以后，保罗受了圣灵的感动决定要经过马其顿省和亚该亚省，到耶路撒冷去。他说：“我到那里以后，也必须去罗马看看。”</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 16:23; 提摩太后书 4:20; 使徒行传 16:3"> 于是他派了提摩太和以拉斯托两个服事他的人到马其顿省去，自己暂时留在亚细亚省。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 19:9; 使徒行传 24:22; 哥林多后书 1:8–10"> 就在这时候，为了这道发生了不小的骚动。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太前书 6:9–10; 使徒行传 16:16; 使徒行传 16:19"> 原来，有一个名叫迪米特斯的银匠，是制造阿蒂米丝女神<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="女神——辅助词语。">o</a></sup>银龛<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="阿蒂米丝女神银龛——原文直译“阿蒂米丝的银龛”。">p</a></sup>的，给工匠们带来不少的生意。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 16:19; 何西阿书 12:7–8; 启示录 18:11–19"> 迪米特斯召集了他们，以及周围同行的工人，说：“各位，你们知道，我们是由这生意发财的。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 17:29; 哥林多前书 8:4; 以赛亚书 44:10–20"> 可是你们看见了也听见了，这个保罗不仅在以弗所也几乎在全亚细亚省，说服、引诱了一大群人，说‘人手所造的不是神’。</span>
<span className="v" id="v27" data-v="27" data-xref="西番雅书 2:11; 提摩太前书 6:5; 马太福音 23:13"> 这样，不仅我们这行业有被轻蔑的危险，连伟大女神阿蒂米丝的庙也要被看为什么都不是，并且这受全亚细亚省和普天下敬拜的女神的威荣，也要被毁灭了。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="启示录 13:4; 启示录 17:13; 使徒行传 16:19–24"> 众人听了，就满腔怒火，喊叫说：“以弗所人伟大的阿蒂米丝！”</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 20:4; 歌罗西书 4:10; 使徒行传 27:2"> 于是满城一片混乱。他们抓住与保罗同来的马其顿人盖尤斯和亚里达古，一齐冲进剧场。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 21:39; 撒母耳记下 18:2–3; 使徒行传 17:22–31"> 保罗虽然想要进到民众当中，但门徒们不让他去。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 19:10; 使徒行传 21:12; 使徒行传 16:6"> 还有一些亚细亚省的官员，是保罗的朋友，也派人劝他不要自己冒险到剧场去。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 21:34; 使徒行传 19:40; 马太福音 11:7–9"> 这时候，有人喊这个、有人喊那个，因为集会的人一片混乱，大多数人不知道为了什么缘故聚集。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 12:17; 提摩太后书 4:14; 提摩太前书 1:20"> 犹太人把亚历山大推到前面的时候，人群中有些人要他说话。亚历山大就挥一下手，想要对民众申辩。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 19:28; 马太福音 6:7; 启示录 13:4"> 可是大家一认出他是犹太人，就同声呼喊：“以弗所人伟大的阿蒂米丝！”大约喊了两个小时。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="帖撒罗尼迦后书 2:10–11; 提摩太前书 4:2; 以弗所书 2:12"> 后来，城里的书记官安抚了民众，说：“各位以弗所人哪，到底有什么人不知道以弗所城是伟大<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="有古抄本附“女神”。">q</a></sup>阿蒂米丝庙和那从天落下的神像的<sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="神像的——辅助词语。">r</a></sup>看守者呢？</span>
<span className="v" id="v36" data-v="36" data-xref="箴言 14:29; 使徒行传 5:35–39; 箴言 25:8"> 所以这些事既然是不能否认的，你们就必须冷静下来，不要做任何妄为的事。</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多后书 6:3; 罗马书 2:22; 使徒行传 25:8"> 你们带来的这些人，既没有偷取庙里的东西，也没有亵渎我们<sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="我们——有古抄本作“你们”。">s</a></sup>的女神。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 13:7; 哥林多前书 6:1; 使徒行传 18:14"> 既然如此，如果迪米特斯和与他一起的工匠们要控告谁，法庭是开着的，省长也在，让他们彼此控告吧！</span>
<span className="v" id="v39" data-v="39"> 但如果你们有什么别的要求，要在合法的集会中解决。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行传 17:5–8; 马太福音 26:5; 使徒行传 20:1"> 关于今天的事，本来没有正当的理由，我们实际上就有被控告为暴乱的危险。我们无法对这次骚动做出交代。”</span>
<span className="v" id="v41" data-v="41" data-xref="传道书 9:17; 诗篇 65:7; 哥林多后书 1:8–10"> 说了这些话，他就遣散了集会的人。</span>
</div>
</div>

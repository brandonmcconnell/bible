<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 10:1–3; 提摩太后书 2:20; 马太福音 13:47–48"> 有一个名叫阿纳尼亚的人，和他的妻子萨菲拉卖掉了财产。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 4:37; 彼得后书 2:14–15; 马太福音 23:5"> 但他从价款中私自留下了一部分，把一部分拿来放在使徒们的脚前；他的妻子也知道这事。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米书 23:24; 以赛亚书 29:15; 约翰福音 13:2"> 彼得就说：“阿纳尼亚，为什么撒旦充满了你的心，使你对圣灵说谎，从田产的价款中私自留下一些呢？</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 5:3; 约书亚记 7:25–26; 列王纪下 5:25–27"> 田产留着没卖<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="没卖——辅助词语。">a</a></sup>的时候，难道不属于你的吗？卖了以后，价款难道不也是由你做主吗？你心里为什么存有这种念头呢？你不是对人说谎，而是对神说谎了。”</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 5:10–11; 使徒行传 2:43; 使徒行传 5:13"> 阿纳尼亚听见这话，就仆倒断了气；所有听到这事的人都大为恐惧。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 19:40; 撒母耳记下 18:17; 申命记 21:23"> 有几个年轻人站起来，把他的尸体<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="的尸体——辅助词语。">b</a></sup>裹好，抬出去埋葬了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 隔了大约三个小时，阿纳尼亚的妻子进来，还不知道所发生的事。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 5:2"> 彼得问她：“告诉我，你们卖田产的钱，是不是这么多？”<br />她说：“是的，就这么多。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 10:9; 使徒行传 5:3–4; 诗篇 95:8–11"> 彼得就对她说：“你们为什么同心试探主的灵呢？看，埋葬你丈夫之人的脚，已经到门口了，他们也要把你抬出去。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 5:5"> 她立刻仆倒在彼得脚前，断了气。那些年轻人进来，看见她死了，也把她抬了出去，埋葬在她丈夫的旁边。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 5:5; 哥林多前书 10:11–12; 使徒行传 19:17"> 全教会和所有听到这些事的人都大为恐惧。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 19:11; 哥林多后书 12:12; 希伯来书 2:4"> 主藉着使徒们的手，在民间行了很多神迹和奇事。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="主藉着使徒们的手，在民间行了很多神迹和奇事。——原文直译“有许多神迹和奇事，藉着使徒们的手，发生在人民中间。”">c</a></sup>信徒们<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="信徒们——原文直译“他们”。">d</a></sup>都同心合意地聚集<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="聚集——辅助词语。">e</a></sup>在所罗门柱廊里。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 2:47; 使徒行传 4:21; 约翰福音 12:42"> 虽然其他的人没有一个敢与他们交往<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="与他们交往——或译作“加入他们”。">f</a></sup>，但民众都尊敬他们。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 2:47; 使徒行传 4:4; 以赛亚书 55:11–13"> 信主的人越发增加，连男带女成群结队。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 14:36; 使徒行传 19:11–12; 约翰福音 14:12"> 人们甚至把病人抬到大街<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="大街——或译作“广场”。">g</a></sup>上来，放在床榻上或垫子上，为要在彼得走过来的时候，至少他的影子可以落在一些人身上。</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 16:17–18; 马可福音 2:3–4; 马太福音 15:30–31"> 还有一群人带着病人和被污灵折磨的人，从耶路撒冷周围的城镇聚集而来，这些人都得了痊愈。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行传 13:45; 使徒行传 7:9; 使徒行传 17:5"> 于是大祭司就采取行动。他和所有与他在一起的人，就是撒都该教派的人，都满腔嫉妒，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 4:3; 路加福音 21:12; 哥林多后书 11:23"> 下手捉拿使徒们，把他们关在公众拘留所里。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 16:26; 诗篇 34:7; 使徒行传 12:7–11"> 但在夜里，主的一位天使打开了监门，领他们出来，说：</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 6:63; 约翰福音 6:68; 约翰一书 5:11–12"> “你们去站在圣殿里，把这生命的话语，都讲给民众听。”</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 8:2; 使徒行传 22:15; 使徒行传 12:18–19"> 他们听从这话，在清晨的时候就进入圣殿教导人。 使徒们再次受审<br />这时，大祭司和与他在一起的人来了，他们召集了议会，就是以色列子民长老的全体议会，然后派人到监狱里，要把使徒们带来。</span>
<span className="v" id="v22" data-v="22"> 但差役们到了监狱里，却找不到他们，就回去报告，</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 2:4; 诗篇 33:10; 但以理书 6:22–24"> 说：“我们看见监狱被关得极其稳妥，卫兵都站在各个门口，可是打开那些门，里面却找不到任何人。”</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 4:1; 使徒行传 5:26; 约翰福音 12:19"> 当<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附“祭司、”。">h</a></sup>圣殿的守卫长<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="守卫长——原文直译“指挥官”或“司令官”或“将军”。">i</a></sup>和祭司长们听到这些话的时候，就对使徒们的事感到困惑，不知道这事会如何发展。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 这时，有人来向他们报告说：“看，你们关在监狱里的那些人，正站在圣殿里教导民众呢！”</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 5:13; 使徒行传 4:21; 马太福音 26:5"> 于是守卫长与差役们一起去把使徒们带来，并没有用暴力，因为怕民众用石头砸他们。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 5:22; 使徒行传 4:7; 路加福音 22:66"> 他们把使徒们带来后，叫他们站在议会当中。大祭司质问他们，</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 27:25; 使徒行传 7:52; 使徒行传 4:10–11"> 说：“我们不是严厉地吩咐你们，不可奉这个人的名教导人吗？可是看哪，你们把你们的教导传遍了耶路撒冷，又想把这个人的血归到我们身上。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行传 4:19; 撒母耳记上 15:24; 马可福音 7:7–9"> 彼得和使徒们回答说：“我们必须顺从神过于顺从人。</span>
<span className="v" id="v30" data-v="30" data-xref="加拉太书 3:13; 彼得前书 2:24; 使徒行传 10:39"> 你们挂在木头上杀害的耶稣，我们祖先的神已经使他复活了。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 24:47; 使徒行传 2:33; 希伯来书 2:10"> 神把这一位高举在自己右边做元首、做救主，为了将悔改的心赐给以色列，使罪得赦免。</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 15:26–27; 希伯来书 2:3–4; 使徒行传 1:8"> 我们就是这些事的见证人。神所赐给那些顺从他之人的圣灵也一同做见证。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="使徒行传 7:54; 使徒行传 2:37; 路加福音 4:28–29"> 议会的人听了，勃然大怒<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="勃然大怒——或译作“心如被刀割”。">j</a></sup>，就想要杀了他们。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 22:3; 路加福音 2:46; 路加福音 5:17"> 但有一个名叫迦玛列的法利赛人，是全体民众所尊敬的律法教师，在议会中站了起来，下令把使徒们<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="使徒们——有古抄本作“这些人”。">k</a></sup>暂时带到外面去，</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 22:26; 耶利米书 26:19; 马太福音 27:19"> 就对大家说：“各位以色列人哪，如何处置这些人，你们应当谨慎。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 8:9; 彼得后书 2:2; 加拉太书 6:3"> 因为这些日子之前，提乌达起来说自己是某某人物，跟从他的人数约有四百。这人被杀了以后，所有信从他的人都四散了，归于无有。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 2:1–2; 诗篇 7:14–15; 马太福音 26:52"> 这人以后，在户口登记期间又有个加利利人犹大起来，拉拢民众<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="民众——有古抄本作“许多民众”。">l</a></sup>跟随他。他也死了，所有信从他的人也都四散了。</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 15:13; 耶利米哀歌 3:37; 以赛亚书 8:9–10"> 现在我告诉你们：不要管这些人，由他们去吧！因为这计划或这行为，如果是出于人，就会被拆毁；</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 21:30; 以赛亚书 46:10; 马太福音 16:18"> 但如果是出于神，你们就不能拆毁他们，恐怕你们反而被看做是与神作对了。”于是议会的人被迦玛列说服了，</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 10:17; 使徒行传 5:28; 使徒行传 4:17–21"> 就叫来使徒们，鞭打了以后，吩咐他们不可再奉耶稣的名讲说，然后把他们释放了。</span>
<span className="v" id="v41" data-v="41" data-xref="雅各书 1:2; 彼得前书 4:13–16; 路加福音 6:22"> 这样使徒们就快快乐乐地离开了议会，因为算是配得上为这名受凌辱。</span>
<span className="v" id="v42" data-v="42" data-xref="使徒行传 2:46; 使徒行传 20:20; 路加福音 21:37"> 他们每天在圣殿和各家各户不住地教导人，传福音说耶稣是基督。</span>
</div>

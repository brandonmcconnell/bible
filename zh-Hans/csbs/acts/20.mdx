<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 7:5; 使徒行传 19:21; 提摩太前书 1:3"> 骚乱平息以后，保罗请门徒们来，鼓励一番，然后与他们告别，就出发往马其顿省去了。</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦前书 2:3; 帖撒罗尼迦前书 4:1; 歌罗西书 1:28"> 他走遍了那些地区，用很多的话鼓励门徒们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="门徒们——原文直译“他们”。">a</a></sup>，就来到希腊，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 20:19; 哥林多后书 11:26; 使徒行传 9:23–24"> 在那里住了三个月。他正要起航往叙利亚省去的时候，犹太人设计了一个针对他的阴谋，他就决定从马其顿省回去。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 19:29; 以弗所书 6:21; 提摩太后书 4:20"> 与他同行<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="同行——有古抄本作“一直同行到亚细亚”。">b</a></sup>的，有庇里亚人普罗斯的儿子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="儿子——辅助词语。">c</a></sup><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本没有“普罗斯的儿子”。">d</a></sup>索巴特，帖撒罗尼迦人亚里达古和西肯多，也有代尔贝人盖尤斯和提摩太，还有亚细亚省人特其库斯和特罗费摩。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 16:8; 使徒行传 16:10–11; 提摩太后书 4:13"> 这些人先走，在特罗阿斯港等我们。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 12:3; 使徒行传 16:12; 出埃及记 23:15"> 过了除酵节的日子，我们从腓立比起航，五天后到了特罗阿斯港见他们，在那里住了七天。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 16:2; 使徒行传 2:42; 约翰福音 20:19"> 在一周的头一天<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一周的头一天——指“星期日”。">e</a></sup>，门徒们<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="门徒们——有古抄本作“我们”。">f</a></sup>聚集掰饼的时候，保罗向他们讲论，因第二天就要离开，于是一直讲到半夜。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 1:13; 路加福音 22:12"> 我们聚集的楼上房间，有许多灯火。</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 13:36; 马太福音 26:40–41; 约拿书 1:5–6"> 有一个名叫犹图克斯的年轻人坐在窗台上，陷入了沉睡。保罗又讲论了很久，犹图克斯在沉睡中从三楼掉了下去，被扶起来的时候，已经死了。</span>
<span className="v" id="v10" data-v="10" data-xref="马可福音 5:39; 马太福音 9:23–24; 列王纪上 17:21–22"> 保罗下去，伏在他身上，抱着他说：“不要慌乱，他的灵魂还在身上！”</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 20:7; 使徒行传 20:9"> 保罗再上去，掰饼吃了，又交谈了许久，直到天亮才出发。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦后书 2:16; 帖撒罗尼迦前书 5:14; 哥林多后书 1:4"> 他们把那活生生的年轻人带走，并且受到了不少的安慰。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马可福音 6:46; 马可福音 1:35; 马可福音 6:31–33"> 我们先上船开往阿索，要在那里接保罗；原来他这样安排，是因为自己要走陆路。</span>
<span className="v" id="v14" data-v="14"> 当他在阿索与我们会合的时候，我们接他上船，来到了米蒂利尼。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太后书 4:20; 使徒行传 20:17"> 我们从那里开船，第二天到达了希俄斯岛的海域，过了一天在萨莫斯岛靠岸，<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附“在特罗古林停留，”。">g</a></sup>再过一天来到米利都。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 16:8; 使徒行传 2:1; 使徒行传 19:21"> 原来保罗已经决定驶过以弗所城，免得在亚细亚省耽延时间，因为他急着赶路，如果有可能，但愿五旬节那一天已经在耶路撒冷了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="提多书 1:5; 使徒行传 11:30; 提摩太前书 5:17"> 保罗从米利都派人到以弗所去，请教会的长老们来。</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 1:5–6; 使徒行传 18:19; 使徒行传 19:1"> 他们来了以后，保罗对他们说：“你们知道，自从我踏进亚细亚省的第一天起，我一直怎样与你们共处——</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 3:24; 哥林多后书 2:4; 罗马书 12:11"> 我在完全的谦卑中、泪水中、以及因犹太人的阴谋而带来的许多试炼中服事主；</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 20:27; 提摩太后书 4:2; 使徒行传 5:42"> 对你们有益的事，在公众场所和各家各户，没有一件我因畏缩而不传讲、不教导给你们；</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 2:38; 使徒行传 11:18; 约翰一书 5:11–13"> 无论对犹太人或希腊人，我都郑重地劝诫他们要向神悔改，相信我们的主耶稣<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="耶稣——有古抄本作“耶稣基督”。">h</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="雅各书 4:14; 哥林多后书 5:14; 彼得后书 1:14"> “看，现在我灵里受到催逼<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="受到催逼——原文直译“被捆绑”。">i</a></sup>，要去耶路撒冷。我不知道在那里将会遇到什么事，</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 9:16; 帖撒罗尼迦前书 3:3; 使徒行传 21:4"> 只知道在各城里圣灵向我郑重地做见证说，有捆锁和患难等着我。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太后书 4:6–8; 哥林多后书 4:1; 哥林多后书 12:10"> 但是我不把自己的生命看为宝贵，为要<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附“怀着喜乐的心”。">j</a></sup>跑尽我该跑的路程<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="跑尽我该跑的路程——原文直译“完成我的赛程”。">k</a></sup>，完成从主耶稣所领受的服事工作，为神恩典的福音郑重地做见证。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行传 28:31; 使徒行传 20:38; 马太福音 4:23"> “我曾在你们中间走遍各地，宣讲神的<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本没有“神的”。">l</a></sup>国，但现在，看哪，我知道你们都不会再见到我的面了！</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 18:6; 以西结书 3:18–21; 以西结书 33:2–9"> 所以我今天向你们见证：对于任何人的灭亡<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="任何人的灭亡——原文直译“任何人的血”。">m</a></sup>，我都是清白的！</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 20:20; 帖撒罗尼迦前书 2:4; 加拉太书 1:7–10"> 因为神的整个计划，我没有一样因畏缩而不传讲给你们。</span>
<span className="v" id="v28" data-v="28" data-xref="彼得前书 5:2–3; 提摩太前书 4:16; 以赛亚书 40:11"> 你们当为自己谨慎，也当为全体羊群谨慎。圣灵把你们放在这羊群里做监督，为要牧养神的<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="神的——有古抄本作“主的”。">n</a></sup>教会，就是他用自己的血所赎来的。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 7:15; 彼得后书 2:1; 约翰福音 10:12"> 我知道在我离开以后，凶恶的豺狼将进入你们中间，不会顾惜羊群。</span>
<span className="v" id="v30" data-v="30" data-xref="提摩太前书 1:19–20; 提摩太后书 4:3–4; 箴言 23:33"> 你们自己当中也会有人起来，讲说一些歪曲的道理，要拉拢门徒跟随他们。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 19:8; 使徒行传 20:19; 使徒行传 19:10"> 所以你们要警醒，记住这三年来，我日夜不住地流着泪水劝诫你们每一个人。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="歌罗西书 1:12; 以弗所书 1:14; 歌罗西书 3:24"> “<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="有古抄本附“弟兄们，”。">o</a></sup>现在我把你们交托给神和他恩典的话语。这话语能造就你们，并且在所有被分别为圣的人中间赐给你们那继业。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多后书 11:9; 哥林多前书 9:12; 哥林多前书 9:18"> 我没有渴望过任何人的金子、银子或衣服。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 18:3; 哥林多前书 4:12; 帖撒罗尼迦后书 3:8–9"> 你们自己也知道，我这双手供应了我和与我在一起之人的需要。</span>
<span className="v" id="v35" data-v="35" data-xref="希伯来书 13:16; 箴言 19:17; 哥林多后书 9:6–12"> 在一切事上，我都给你们做了榜样：必须这样地劳苦做工来扶助软弱的人，并且要记住主耶稣自己说过的话：<span className="woj">‘施比受更加蒙福。’</span>”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行传 21:5; 路加福音 22:41; 腓立比书 4:6"> 保罗说了这些话，就跪下来与大家一起祷告。</span>
<span className="v" id="v37" data-v="37" data-xref="提摩太后书 1:4; 哥林多前书 16:20; 帖撒罗尼迦前书 5:26"> 大家都痛哭起来，搂住保罗的脖子亲吻他。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 15:3; 哥林多前书 16:11; 使徒行传 20:25"> 尤其使他们伤心的，就是他说他们不会再看到他面的那句话。然后他们送他上了船。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太后书 1:5; 提摩太后书 1:2; 哥林多前书 4:17"> 保罗到达代尔贝城，又到了路司得城。当时，那里有一个名叫提摩太的门徒，是一个信主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="主——辅助词语。">a</a></sup>的犹太妇人的儿子，他父亲是希腊人。</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前书 5:10; 提摩太后书 3:15; 使徒行传 14:21"> 路司得和以哥念的弟兄们都赞许他。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 2:3; 哥林多前书 9:20; 加拉太书 5:6"> 保罗想要带他一起去，但为了那些地方的犹太人的缘故，就给他行了割礼，因为大家都知道他父亲是希腊人。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 15:28–29; 使徒行传 15:2; 使徒行传 11:30"> 当他们经过那些城镇的时候，就把耶路撒冷的使徒们和长老们所定的规条，传达给大家遵守。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 9:31; 使徒行传 2:47; 使徒行传 6:7"> 这样，各教会在信仰上得了坚固，人数也天天增加。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 18:23; 使徒行传 16:7; 使徒行传 13:2–4"> 圣灵既然阻止他们在亚细亚省传讲福音<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="福音——原文直译“话语”或“道”。">b</a></sup>，他们就走遍弗里吉亚和加拉太地区。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:9; 腓立比书 1:19; 加拉太书 4:6"> 他们来到密细亚地区的边界，试着要往比提尼亚省去，可是耶稣的灵<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="耶稣的灵——有古抄本作“圣灵”。">c</a></sup>不允许。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 2:12; 提摩太后书 4:13; 使徒行传 16:11"> 他们就经过密细亚地区，下到特罗阿斯港。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 9:10–12; 使徒行传 19:21; 使徒行传 18:5"> 夜里，保罗看见了一个异象：一个马其顿人站着恳求他，说：“请你过来，到马其顿来帮助我们。”</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 2:12–13; 使徒行传 14:7; 使徒行传 16:10–17"> 当保罗看见这异象之后，我们就认定是神<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="神——有古抄本作“主”。">d</a></sup>召唤我们去传福音给他们，于是立刻设法前往马其顿省。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 21:1; 使徒行传 16:8"> 我们从特罗阿斯港开船直航，到萨莫特拉岛，第二天到了奈阿波利斯港，</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦前书 2:2; 腓立比书 1:1; 使徒行传 20:6"> 从那里来到腓立比。那是马其顿省的首要城市，是罗马的<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="罗马的——辅助词语。">e</a></sup>殖民地。我们在这城里住了几天。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 13:14; 歌罗西书 1:23; 使徒行传 17:2"> 安息日那天，我们出了城门，来到河边，想到那里有一个祷告的地方。我们就坐下来，对聚集在那里的妇女们讲道。</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所书 1:17–18; 路加福音 24:45; 以赛亚书 50:5"> 有一个敬拜神的妇人，名叫莉迪娅，是锡亚蒂拉城卖紫色布的商人。她一直在听，主开启她的心窍，使她留心保罗所讲的话。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 11:14; 希伯来书 13:2; 使徒行传 16:33"> 当她和她的家人受了洗之后，她请求我们说：“如果你们判断我是主的信徒<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="信徒——或译作“忠心的人”。">f</a></sup>，请到我家里来住。”于是她极力挽留我们。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="利未记 19:31; 申命记 18:9–11; 以赛亚书 8:19"> 有一次，我们往祷告的地方去，迎面来了一个有占卜邪灵附身的女仆。她用算命为她的主人们带来大量的生意。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 14:6; 彼得前书 2:16; 马可福音 5:7"> 她跟着保罗和我们，喊叫说：“这些人是至高神的奴仆，向你们<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="你们——有古抄本作“我们”。">g</a></sup>传讲救恩的道<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="道——或译作“路”。">h</a></sup>。”</span>
<span className="v" id="v18" data-v="18" data-xref="马可福音 16:17; 路加福音 10:17–19; 使徒行传 3:6"> 她一连几天都这样做。<br />保罗厌烦了，就转过身对那邪灵说：“我奉耶稣基督的名，吩咐你从她身上出来！”那邪灵立刻就出来了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 17:6; 使徒行传 21:30; 使徒行传 8:3"> 女仆的主人们看见他们的生意没有希望了，就揪住保罗和西拉斯，把他们拖到街市<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="街市——或译作“市场”或“大会场”或“公民大会”。">i</a></sup>上去见首领们。</span>
<span className="v" id="v20" data-v="20" data-xref="雅各书 4:4; 约翰福音 15:18–20; 使徒行传 28:22"> 把两个人带到官长们面前，说：“这些人是犹太人，在扰乱我们的城市，</span>
<span className="v" id="v21" data-v="21" data-xref="以斯帖记 3:8; 使徒行传 26:3; 耶利米书 10:3"> 传讲我们罗马人不可以接受、也不能遵守的规矩。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="帖撒罗尼迦前书 2:2; 哥林多后书 6:5; 哥林多后书 11:23–25"> 那群人就一同起来反对保罗和西拉斯。官长们就剥了他们的衣服，下令用棍子打，</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 2:10; 提摩太后书 2:9; 撒母耳记上 23:22–23"> 打了很多棍以后，把他们投进监狱，吩咐狱卒好好地看守。</span>
<span className="v" id="v24" data-v="24" data-xref="约伯记 13:27; 约伯记 33:11; 耶利米书 29:26"> 狱卒领了这样的吩咐，就把他们投进了监狱里的最里层，把他们的两脚铐在木枷上。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="帖撒罗尼迦前书 5:16–18; 诗篇 119:62; 雅各书 1:2"> 约在半夜，保罗和西拉斯祷告、唱诗赞美神，其他的囚犯们都侧耳听着。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 4:31; 使徒行传 5:19; 使徒行传 12:10"> 突然发生了强烈的地震，结果监狱的地基都被摇动，所有的监门立刻打开了，每个囚犯的锁链也都松开了。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 12:19; 马太福音 27:5; 士师记 9:54"> 狱卒醒来，看见监狱的门都开了，以为囚犯们已经逃跑了，就拔出刀来要自杀。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="帖撒罗尼迦前书 5:15; 路加福音 23:34; 路加福音 6:27–28"> 保罗却大声呼唤说：“不要伤害自己，因为我们都在这里！”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="启示录 3:9; 使徒行传 24:25; 以赛亚书 60:14"> 狱卒叫人拿了灯来，就冲进去，战战兢兢地俯伏在保罗和西拉斯面前，</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 2:37; 约翰福音 6:27–29; 以赛亚书 58:9"> 然后领他们出来，说：“先生们，我应该做什么才能得救呢？”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 1:12; 使徒行传 2:38–39; 约翰福音 3:36"> 他们说：“要信靠主耶稣<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="耶稣——有古抄本作“耶稣基督”。">j</a></sup>，你和你一家人就将得救。”</span>
<span className="v" id="v32" data-v="32" data-xref="罗马书 1:16; 歌罗西书 1:27–28; 提摩太前书 1:13–16"> 于是他们把主的福音<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="福音——原文直译“话语”或“道”。">k</a></sup>讲给狱卒和他家里所有的人听。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 1:16; 使徒行传 16:15; 使徒行传 16:25"> 当夜，就在那时刻，狱卒带他们去清洗伤口，然后他和所有的家人立刻受了洗。</span>
<span className="v" id="v34" data-v="34" data-xref="罗马书 15:13; 使徒行传 2:46; 罗马书 5:11"> 他把保罗和西拉斯领到家里，摆上饭食。他和全家人因为信了神，都欢欣跳跃。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="耶利米书 5:22; 诗篇 76:10; 使徒行传 5:40"> 天亮的时候，官长们派刑杖官来说：“把那两个人放了吧！”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行传 15:33; 约翰福音 14:27; 撒母耳记上 1:17"> 狱卒就把这话告诉保罗，说：“官长们派人来，要释放你们。所以现在请你们出来，平平安安地去吧！”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒行传 22:25–29; 诗篇 58:1–2; 马太福音 10:16"> 可是保罗对他们说：“我们是罗马公民，并没有被定罪，他们却当众打我们，把我们投进监狱。现在他们还要悄悄地把我们赶出去吗？当然不行！让他们亲自来领我们出去！”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="使徒行传 22:29; 马太福音 21:46; 马太福音 14:5"> 那些刑杖官把这些话报告给官长们，官长们一听他们是罗马公民，就惧怕了，</span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 8:34; 马可福音 5:17; 但以理书 6:23"> 于是来安抚他们，并且把他们领出来，请求他们离开那城。</span>
<span className="v" id="v40" data-v="40" data-xref="帖撒罗尼迦前书 3:2–3; 使徒行传 16:14; 使徒行传 14:22"> 保罗和西拉斯出了监狱，就到莉迪娅家里去，见了弟兄们，鼓励他们一番，然后离开了。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 9:15; 箴言 1:24; 使徒行传 26:2"> 阿格里帕对保罗说：“你获准为自己说话。”<br />于是保罗伸手开始申辩：</span>
<span className="v" id="v2" data-v="2"> “阿格里帕王啊，关于犹太人控告我的一切事，今天要在您面前申辩，我认为自己是蒙福的，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 6:14; 使徒行传 26:26; 使徒行传 26:7"> 尤其因为您熟悉犹太人一切的规矩和争议的问题，所以我请求您耐心听我说。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="加拉太书 1:13; 提摩太后书 3:10; 腓立比书 3:5"> “事实上，我自幼的为人，从起初在自己的同胞中间，以及在耶路撒冷，所有的犹太人都知道。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 23:6; 使徒行传 22:3; 使徒行传 24:5"> 他们从一开始就已经认识我，如果他们愿意就可以见证：我是按着我们宗教中最严格的教派，过着法利赛人的生活。</span>
<span className="v" id="v6" data-v="6" data-xref="提多书 2:13; 使徒行传 24:15; 使徒行传 28:20"> 现在我站在这里受审，是因为盼望神已经赐给我们祖先的那应许。</span>
<span className="v" id="v7" data-v="7" data-xref="雅各书 1:1; 腓立比书 3:11; 提摩太前书 5:5"> 为了那应许，我们十二个支派日夜热切地事奉神，盼望得到它。王<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="王——有古抄本作“阿格里帕王”。">a</a></sup>啊，我被犹太人控告，就是为了这盼望。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 15:12–20; 使徒行传 4:2; 使徒行传 17:31–32"> 你们为什么判断神使死人复活的事为不可信的呢？</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前书 1:13; 使徒行传 22:8; 腓立比书 3:6"> 事实上，我自己曾经认为必须多做反对拿撒勒人耶稣之名的事，</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 8:3; 使徒行传 9:13–14; 使徒行传 9:21"> 我在耶路撒冷也是这样做的。我不但从祭司长们得了权柄把许多圣徒关进监狱，而且当他们被杀的时候，我也投了一票。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 22:19; 马太福音 10:17; 使徒行传 13:45"> 我在各会堂里，经常用刑逼他们说亵渎的话，又越发恼恨他们，甚至到国外的城市去逼迫他们。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 26:10; 使徒行传 22:5–11; 使徒行传 9:1–8"> “那时我得到祭司长们的授权和委任往大马士革去。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 17:2; 启示录 21:23; 启示录 1:16"> 王啊，约在正午，我在路上的时候，看见一道光，比太阳更明亮，从天上四面照射我和与我同行的人。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 21:40; 使徒行传 22:2; 使徒行传 9:7"> 我们都仆倒在地。我听见有声音用希伯来语对我说<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有声音用希伯来语对我说——有古抄本作“有声音对我说话，用希伯来语说”。">b</a></sup>：<span className="woj">‘扫罗，扫罗！你为什么逼迫我？你脚踢刺棒，是狂妄的。’</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 15:20–21; 马太福音 25:45; 出埃及记 16:8"> “我问：‘主啊，你到底是谁？’<br />“主<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="主——有古抄本作“那一位”。">c</a></sup>说：<span className="woj">‘我就是你所逼迫的耶稣。</span></span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 22:14–15; 以西结书 2:1; 但以理书 10:11"> <span className="woj">你起来，用你的两脚站好！要知道，我向你显现是为这样一个目的</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一个目的——辅助词语。">d</a></sup><span className="woj">：预先指定你做仆人和见证人，就是为你所看见的事，以及我将要显明给你的事做见证人。</span></span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 9:15; 提摩太前书 2:7; 耶利米书 1:19"> <span className="woj">我要从以色列</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="以色列——辅助词语。">e</a></sup><span className="woj">子民和外邦人当中把你救出来。</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附“现在”。">f</a></sup><span className="woj">我差派你到他们那里去，</span></span>
<span className="v" id="v18" data-v="18" data-xref="彼得前书 2:9; 以弗所书 1:18; 以弗所书 5:8"> <span className="woj">为了开启他们的眼睛，使他们从黑暗归向光明，从撒旦的权势下归向神，使他们因着信我，罪得赦免，并且与那些被分别为圣的人同得继业。’</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 50:5; 加拉太书 1:16; 以西结书 2:7–8"> “故此，阿格里帕王啊，我没有悖逆那从天上来的异象。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 3:8; 使徒行传 3:19; 使徒行传 2:38"> 我首先在大马士革，然后在耶路撒冷、犹太全地以及外邦人中，告诫人们要悔改，归向神，行事与悔改的心相称。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 21:30–31; 使徒行传 21:27; 使徒行传 25:3"> 犹太人就是因这缘故，在圣殿里抓住我，想要杀害我。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 24:14; 约翰福音 5:46; 罗马书 3:21"> 然而我蒙了从神而来的帮助，直到今天仍能站立得住，不但向卑微的，还向尊贵的做见证。我所讲的，不外乎先知们和摩西所说的那些将要成就的事，</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 53:1–12; 路加福音 24:26; 歌罗西书 1:18"> 就是基督要受难，要成为第一个从死人中复活的人，要把光传给这子民和外邦人。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 2:13–14; 哥林多前书 1:23; 哥林多前书 4:10"> 保罗这样申辩的时候，菲斯特斯大声说：“保罗，你疯了！你学问太大，使你癫狂了。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行传 23:26; 提多书 1:9; 提多书 2:7–8"> 保罗<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="保罗——有古抄本作“这位”。">g</a></sup>说：“菲斯特斯大人，我没有疯。我说的都是真实、合理的话。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 26:2–3; 使徒行传 2:1–12; 以赛亚书 30:20"> 其实王知道这些事，我才对王放胆直言。我深信这些事没有一件瞒得过王，因为这不是在角落里做的。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 26:22–23"> 阿格里帕王啊，您相信先知吗？我知道您是相信的。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="使徒行传 11:26; 马太福音 10:18; 使徒行传 26:29"> 阿格里帕对保罗说：“你用几句话就要说服我成为<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="成为——有古抄本作“做”。">h</a></sup>基督徒吗？”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以弗所书 6:20; 歌罗西书 1:28; 罗马书 10:1"> 保罗说：“无论话多话少，我向神祈求的，不仅是您，还有今天所有听我讲话的人都能成为像我这样的人，只是不要有这些锁链！”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行传 18:15; 使徒行传 28:22; 使徒行传 25:23"> 于是<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附“他说完这些事，”。">i</a></sup>王和总督，还有百妮基以及与他们坐在一起的人，都站起来了。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 23:29; 使徒行传 23:9; 使徒行传 28:18"> 当离开的时候，彼此谈论说：“这个人没有做任何该死或该被捆锁的事。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行传 28:18; 使徒行传 25:11–12; 使徒行传 25:25"> 阿格里帕对菲斯特斯说：“这个人如果没有向凯撒上诉，早就可以释放了。”</span>
</div>
</div>

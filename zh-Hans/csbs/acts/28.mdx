<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="ACT" data-book-slug="acts" data-book-name="使徒行传" data-chapter="28" data-verses="31">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 27:26; 使徒行传 27:44; 使徒行传 27:39"> 我们获救以后才知道那岛叫做马耳他，</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 1:14; 希伯来书 13:2; 歌罗西书 3:11"> 那里的土人对我们非常友善。因为当时下着雨，又因为天气冷，他们就生了火接待我们大家。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 23:33; 马太福音 12:34; 使徒行传 28:4"> 保罗收集了一捆柴火，放在火堆上的时候，有一条毒蛇因热钻了出来，咬住<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="咬住——或译作“缠住”。">a</a></sup>他的手。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 13:2; 路加福音 13:4; 约翰福音 7:24"> 那些土人一看见那毒蛇悬在他的手上，就彼此说：“这个人一定是个杀人犯！虽然从海里获救了，但天理还是不让他活着。”</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 10:19; 马可福音 16:18; 诗篇 91:13"> 可是保罗把那毒蛇甩在火里，没有受任何伤害。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 12:22; 使徒行传 14:11–13; 马太福音 21:9"> 他们本来以为他快要肿起来，或是突然倒下死去，然而等了很久，看见他没有任何异常，就改变了想法，说他是个神。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 10:40–41; 路加福音 19:6–9; 使徒行传 28:2"> 在那个地方附近，有些田产是岛上首领普布利乌的。他欢迎我们，热情地招待了我们三天。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 9:40; 马可福音 6:5; 雅各书 5:14–16"> 当时，普布利乌的父亲患热病和痢疾，躺在床上<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="在床上——辅助词语。">b</a></sup>。保罗就进去为他祷告，按手在他身上，使他痊愈了。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 5:12; 马可福音 6:54–56; 使徒行传 5:15"> 这么一来，岛上其他有病的人也都来了，并且都得了痊愈。</span>
<span className="v" id="v10" data-v="10" data-xref="帖撒罗尼迦前书 2:6; 腓立比书 4:11–12; 马太福音 6:31–34"> 他们十分尊重我们；开船的时候，还送上所需要的东西。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 27:6; 哥林多前书 8:4; 以赛亚书 45:20"> 过了三个月，我们上了一条亚历山大的船起航。这船是在那海岛过冬的，以“宙斯双子神”为船头雕像。</span>
<span className="v" id="v12" data-v="12"> 我们在叙拉古靠岸，停留了三天，</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 27:13"> 又从那里绕道航行，到达利基翁。过了一天，刮起了南风，第二天我们就到了普特奥利，</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 21:4; 使徒行传 20:6; 使徒行传 19:1"> 在那里找到一些弟兄，受邀请与他们同住了七天。<br />这样，我们来到了罗马。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 13:3; 罗马书 15:24; 出埃及记 4:14"> 那里的弟兄们听说了有关我们的事，赶到阿比乌市场和三馆来迎接我们。保罗见到他们，就感谢神，得了勇气。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 27:3; 使徒行传 24:23; 使徒行传 28:30–31"> 我们进了罗马以后，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附“百夫长把囚犯交给军队司令官。但”。">c</a></sup>保罗获准在一个士兵的看守之下，独自居住。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行传 25:8; 使徒行传 6:14; 使徒行传 25:10"> 第三天，保罗<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="保罗——有古抄本作“他”。">d</a></sup>请犹太人的首领们来。他们聚集了，保罗就对他们说：“各位兄弟，我没有做过任何反对我们民族或先祖规矩的事，却做为囚犯从耶路撒冷被交到罗马人手中。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 26:31–32; 使徒行传 23:29; 使徒行传 22:24–25"> 他们审问我以后，因为没有处死我的任何理由，本来想要释放我。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 26:32; 使徒行传 25:21; 使徒行传 25:10–12"> 但是由于犹太人反对，我被迫向凯撒上诉，并不是有什么事要控告自己的同胞。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 6:20; 提摩太后书 2:9; 使徒行传 26:6–7"> 因这理由，我请你们来见面谈话。其实我是为了以色列所盼望的事，才被这锁链捆锁的。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 54:17; 以赛亚书 41:11; 以赛亚书 50:8"> 他们对保罗说：“我们没有收到从犹太来的有关你的文件。来到这里的同胞<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="同胞——原文直译“兄弟”。">e</a></sup>中，也没有人报告过或说过任何有关你的坏事。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:12; 使徒行传 24:14; 彼得前书 3:16"> 不过我们觉得应该听听你的想法，因为我们确实知道有关这教派的事，它到处遭人反对。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 17:2–3; 使徒行传 19:8; 使徒行传 18:28"> 于是他们和保罗定好了日子，就有更多的人来到他的住所。保罗从早到晚对他们讲解，为神的国郑重地做见证，并且引用摩西的律法和先知书上有关耶稣的事来劝导他们。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 14:4; 使徒行传 17:4–5; 使徒行传 19:8–9"> 对他所说的话，有些人信从了，有些人却不相信。</span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="马太福音 15:7; 彼得后书 1:21; 马可福音 7:6"> 他们彼此不一致，开始散去，保罗就说了一句话：“圣灵藉着先知以赛亚对你们<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="你们——有古抄本作“我们”。">f</a></sup>祖先所说的是对的。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 6:9–10; 以西结书 12:2; 以赛亚书 42:19–20"> 他说：<br /><span className="pl pl-1">‘你去告诉这子民：</span><br /><span className="pl pl-1">你们将听了又听，但绝不会领悟；</span><br /><span className="pl pl-1">你们将看了又看，但绝不会明白；</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 6:10"> <span className="pl pl-1">因为这子民的心麻木了，</span><br /><span className="pl pl-1">他们充耳不闻，眼睛闭着；</span><br /><span className="pl pl-1">免得他们眼睛看见，耳朵听见，心里领悟，</span><br /><span className="pl pl-1">回转过来，我就使他们痊愈。’</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 2:30–32; 使徒行传 26:17–18; 罗马书 3:29–30"> 所以你们应当知道：神的这救恩已经传给了外邦人，他们反倒会听！”</span>
<span className="v" id="v29" data-v="29"> 保罗说完这些话，犹太人就走了，彼此议论纷纷。<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本没有此节。">g</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 保罗在自己租的房子里住了整整两年，所有来到他那里的人，他都欢迎。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 4:29; 以弗所书 6:19–20; 马太福音 4:23"> 他宣讲神的国、教导有关主耶稣基督的事，满有胆量、没有拦阻。</span>
</div>
</div>

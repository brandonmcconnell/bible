<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 2:17; 路加福音 5:4; 撒母耳记上 20:41–42"> 我们与他们惜别以后就开船直航，来到科斯岛。第二天到了罗得岛，又从那里到帕塔拉，</span>
<span className="v" id="v2" data-v="2" data-xref="约拿书 1:3; 使徒行传 11:19; 使徒行传 15:3"> 找到了一条开往腓尼基的船，就上船起航。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 21:16; 使徒行传 4:36; 马太福音 4:24"> 我们望见塞浦路斯岛，驶过的时候它在左边。我们继续向叙利亚省航行，在提尔登陆，因为船要在那里卸货。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 20:22–23; 使徒行传 21:10–12; 使徒行传 20:6–7"> 我们找到了一些门徒，就在那里住了七天。他们藉着圣灵，一直告诉保罗不要上耶路撒冷去。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 20:36; 使徒行传 9:40; 诗篇 95:6"> 那些日子过了以后，我们出发前行，大家与妻子和儿女一起送我们到城外。我们都跪在岸上祷告，</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 19:27; 约翰福音 1:11; 哥林多后书 2:13"> 彼此告别。我们上了船，他们就回自己的家去了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="希伯来书 13:24; 撒母耳记上 10:4; 使徒行传 28:12"> 我们结束了从提尔开始的航程，到达托勒密，就去问候弟兄们，在他们那里住了一天。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 6:5; 使徒行传 8:26–40; 以弗所书 4:11"> 第二天我们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我们——有古抄本作“跟随保罗的人”。">a</a></sup>离开那里，来到凯撒里亚，进了传福音者腓利的家，住在他那里，他是那七位执事<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="执事——辅助词语。">b</a></sup>中的一位。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 2:17; 启示录 2:20; 约珥书 2:28"> 他有四个女儿，都是童贞女，是做先知传道<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="做先知传道——原文直译“说预言”。">c</a></sup>的。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 11:28; 使徒行传 21:4; 使徒行传 20:16"> 我们住了好几天，有一个名叫阿伽布斯的先知从犹太下来了。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 21:33; 耶利米书 13:1–11; 撒母耳记上 15:27–28"> 他来到我们这里，拿起保罗的腰带，把自己的手脚捆起来，说：“圣灵这样说，犹太人在耶路撒冷要如此捆绑这腰带的主人，把他交在外邦人的手中。”</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 16:21–23; 使徒行传 20:22; 使徒行传 21:4"> 我们一听这些话，就和当地的人恳求保罗不要上耶路撒冷去。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 20:24; 腓立比书 2:17; 腓立比书 1:20–21"> 这时候保罗说：“你们为什么哭，使我心碎呢？我为了主耶稣的名，不仅被捆绑，即使死在耶路撒冷，也都预备好了。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 22:42; 马太福音 26:42; 马太福音 26:39"> 我们既然不能说服保罗，就都安静下来，只说：“愿主的旨意成就。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行传 25:1; 使徒行传 25:6; 使徒行传 25:9"> 过了几天，我们收拾行李，上耶路撒冷去。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 16:31; 使徒行传 21:8; 诗篇 92:14"> 凯撒里亚的一些门徒也陪我们一起去，带我们到一个塞浦路斯人纳森家里去作客住宿。他做门徒已经很久了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行传 15:4; 罗马书 15:7; 希伯来书 13:1–2"> 我们到了耶路撒冷，弟兄们很高兴地欢迎我们。</span>
<span className="v" id="v18" data-v="18" data-xref="加拉太书 1:19; 加拉太书 2:9; 使徒行传 15:13"> 第二天，保罗与我们一起去探望雅各，所有的长老也都来了。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 14:27; 使徒行传 1:17; 罗马书 15:18–19"> 保罗问候他们后，一一述说神藉着他的服事，在外邦人中所做的事。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="罗马书 10:2; 加拉太书 1:14; 使徒行传 22:3"> 他们听了就不住地荣耀神<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="神——有古抄本作“主”。">d</a></sup>，又对保罗说：“弟兄，你看犹太人中信主<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="主——辅助词语。">e</a></sup>的人有多少万，而且他们都是对律法热心的人。</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太书 6:12–15; 哥林多前书 9:19–21; 加拉太书 5:1–6"> 他们听到有关你的事，说你教导所有在外邦人中的犹太人离道反教、背弃摩西，叫他们不要给孩子行割礼，也不要按规矩行事。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 15:12; 使徒行传 15:22; 使徒行传 19:32"> 他们一定会听到你来这里了<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="他们一定会听到你来这里了——有古抄本作“他们听到你来了，民众必定会聚集”。">f</a></sup>。那么该怎么办呢？</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 18:18; 民数记 6:2–7"> 你就照我们告诉你的去做吧。我们这里有四个人，他们都许过愿。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 21:26; 使徒行传 24:18; 使徒行传 18:18"> 你带他们去，与他们一起行洁净礼，并且替他们付钱，好让他们剃掉头发。这样，大家就会知道有关你的传闻不是真的，而且你自己也是照着规矩行事、遵守律法的。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 15:29; 使徒行传 15:19–20"> 至于已经相信的外邦人，我们照着决定写了信，要他们远避祭过偶像的食物，远避血和勒死的动物，远避淫乱。<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附“除了这些以外，不要遵守任何这样的事”。">g</a></sup>”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 24:18; 使徒行传 21:24; 民数记 6:13–20"> 于是，第二天保罗带了那四个人，与他们一起行了洁净礼，进了圣殿，宣告洁净期满的日子，直到为他们每一个人的供物都被献上为止。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 26:21; 使徒行传 24:18; 使徒行传 13:50"> 那七天快要结束的时候，从亚细亚省来的一些犹太人看到保罗在圣殿里，就煽动整个人群，下手捉拿他，</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 24:5–6; 使徒行传 21:21; 使徒行传 26:20–21"> 喊叫：“各位以色列人哪，请帮忙！这个人就是那到处教导大家反对我们的民族、律法，反对这地方的！他甚至把希腊人带进圣殿，玷污了这圣地。”</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 20:4; 提摩太后书 4:20; 使徒行传 18:19"> 原来他们曾经看见以弗所人特罗费摩与保罗一起在城里，就以为保罗带他进了圣殿。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行传 26:21; 哥林多后书 11:26; 使徒行传 16:19–22"> 于是全城的人都被煽动了，民众一起跑来，抓住保罗，把他拖出圣殿，殿门立刻关上了。</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多后书 11:23–33; 使徒行传 17:5; 使徒行传 26:9–10"> 在他们想杀保罗的时候，有消息上报到军团的千夫长，说全耶路撒冷都混乱了。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 23:27; 以赛亚书 3:15; 使徒行传 5:40"> 千夫长立即带着士兵和几个百夫长跑下去，到了他们那里。他们一看见千夫长和士兵们，就停止殴打保罗。</span>
<span className="v" id="v33" data-v="33" data-xref="以弗所书 6:20; 使徒行传 21:11; 使徒行传 20:23"> 于是千夫长上前抓住保罗，下令用两条铁链把他捆起来，然后查问他到底是什么人，做了什么事。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 19:32; 使徒行传 23:10; 使徒行传 22:24"> 人群当中，有的喊这个，有的喊那个；千夫长因为骚乱，无法知道真相，就下令把保罗带到营楼里去。</span>
<span className="v" id="v35" data-v="35" data-xref="哈巴谷书 1:2–3; 诗篇 55:9; 诗篇 58:2"> 保罗到了台阶上的时候，由于人群凶猛，士兵们只好把他抬起来走。</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 19:15; 使徒行传 22:22; 路加福音 23:18"> 那一群人跟在后面，喊叫：“除掉他！”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒行传 21:34; 路加福音 21:15; 使徒行传 19:30"> 保罗快要被押进营楼的时候，就对千夫长说：“我是否可以对你说句话？”<br />千夫长说：“你懂希腊语吗？</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 24:26; 使徒行传 5:36–37; 马太福音 5:11"> 你究竟是不是那个前些日子作乱、带领四千个凶徒进入旷野的埃及人呢？”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒行传 22:3; 使徒行传 9:11; 使徒行传 23:27"> 保罗回答说：“我是犹太人，是奇里乞亚省的塔尔苏人，并不是无名之城的公民，请求你准许我向民众说话。”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="使徒行传 12:17; 使徒行传 22:2; 约翰福音 5:2"> 千夫长准许了，保罗就站在台阶上，向民众挥一下手，大家都寂静无声，保罗就用希伯来语呼吁，说：</span>
</div>

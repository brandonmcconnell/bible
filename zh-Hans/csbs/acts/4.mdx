<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 22:4; 使徒行传 6:12; 使徒行传 23:6–9"> 彼得和约翰正向民众讲话的时候，祭司们、圣殿守卫长<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="守卫长——原文直译“指挥官”或“司令官”或“将军”。">a</a></sup>和撒都该人忽然来了。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 17:18; 帖撒罗尼迦前书 4:13–14; 使徒行传 24:14–15"> 这些人非常恼怒，因为使徒们教导民众，藉着耶稣传讲从死人中复活的事。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 5:18; 马太福音 10:16–17; 使徒行传 16:19–24"> 于是他们下手捉拿了彼得和约翰。因为天已经晚了，就把他们关在监里，直到第二天。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 2:41; 哥林多后书 2:14–17; 提摩太后书 2:9–10"> 然而听了这话语的人中，有许多人相信了；男人的数目约有五千。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 4:8; 马太福音 27:1–2; 路加福音 20:1"> 到了第二天，犹太人的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="犹太人的——原文直译“他们的”。">b</a></sup>首领、长老和经文士们都聚集在耶路撒冷。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 3:2; 约翰福音 18:24; 马太福音 26:3"> 大祭司亚纳、该亚法、约翰、亚历山大，以及大祭司家族的人都在那里。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 21:23; 马可福音 11:28; 使徒行传 5:40"> 他们叫彼得和约翰站在中间，质问他们，说：“你们凭着什么能力，以谁的名做这事？”</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="路加福音 12:11–12; 马太福音 10:19–20; 使徒行传 2:4"> 那时，彼得被圣灵充满，对他们说：“民众的首领和<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附“以色列的”。">c</a></sup>长老们，</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 3:15–17; 使徒行传 3:7; 约翰福音 10:32"> 如果我们今天因在一个残疾人身上所行的善事，被查问这个人怎样得到救治，</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 5:29–32; 使徒行传 3:6; 使徒行传 2:36"> 那么，你们大家和所有以色列子民应当知道：这个人健全地站在你们面前，是藉着拿撒勒人耶稣基督的名。这位耶稣基督，你们把他钉上十字架，但是神使他从死人中复活了！</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 118:22–23; 以赛亚书 28:16; 马可福音 12:10–12"> 这一位就是<br /><span className="pl pl-1">‘被你们工匠所藐视的石头，</span><br /><span className="pl pl-1">它已经成了房角的头块石头。’</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约翰福音 14:6; 哥林多前书 3:11; 约翰福音 3:36"> 除他<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="他——辅助词语。">d</a></sup>以外，没有救恩<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="救恩——或译作“拯救”。">e</a></sup>；因为在天下人间，没有赐下别的名，我们必须靠着得救。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 1:27; 约翰福音 7:15; 马太福音 11:25"> 他们看见彼得和约翰的胆量，又了解他们是没有学问的普通人，就感到惊奇，并且了解他们是曾经与耶稣在一起的；</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 19:36; 使徒行传 3:8–12; 使徒行传 4:21"> 又看见那得了痊愈的人和他们一同站着，就无话可说了，</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 26:30–32; 使徒行传 5:34–42; 马太福音 5:22"> 于是命令他们到议会外面去，就彼此商议，</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 21:15; 使徒行传 6:10; 约翰福音 12:18"> 说：“我们该怎么处理这些人呢？藉着他们，确实发生了一个明显的神迹，所有住在耶路撒冷的人都清清楚楚；我们也不能否认。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 5:28; 罗马书 15:18–22; 使徒行传 5:24"> 不过为了避免这事在民间传扬更广，让我们威吓他们<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="让我们威吓他们——有古抄本作“让我们用恐吓的手段来恐吓他们”。">f</a></sup>，不可再奉耶稣的名<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="耶稣的名——原文直译“这个名”。">g</a></sup>对任何人讲话。”</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 5:40; 路加福音 24:46–48; 使徒行传 5:20"> 于是把他们叫来，吩咐他们绝对不可奉耶稣的名讲说或教导人。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 5:29; 出埃及记 1:17; 哥林多前书 10:15"> 可是彼得和约翰回答说：“听从你们过于听从神，在神面前是理所当然的吗？你们自己判断吧！</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 22:15; 耶利米书 20:9; 哥林多前书 9:16–17"> 要知道，我们所看见所听见的，我们不能不说。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 5:26; 马太福音 21:46; 路加福音 22:2"> 官长们又威吓他们一番，为了民众的缘故把他们释放了。官长们找不出任何理由来惩罚他们，因为众人都为所发生的事不住地荣耀神。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 5:5; 使徒行传 9:33; 路加福音 13:11"> 实际上，因神迹而痊愈的那个人已经四十多岁了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 6:14–17; 使徒行传 12:11–12; 诗篇 119:63"> 彼得和约翰被释放了，就回到自己的人那里，把祭司长们和长老们所说的话都告诉他们。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 20:11; 耶利米书 32:17; 尼希米记 9:6"> 他们听了，就同心合意地高声向神说：“主啊，你是造了天、地、海和其中万有的那一位<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="那一位——有古抄本作“神”。">h</a></sup>。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 2:1–6; 使徒行传 1:16; 使徒行传 2:30"> 你曾经藉着圣灵<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本没有“藉着圣灵”。">i</a></sup>，用你的仆人——我们先祖<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本没有“我们先祖”。">j</a></sup>大卫的口说：<br /><span className="pl pl-1">‘列国为什么狂怒骚乱，</span><br /><span className="pl pl-1">众民为什么图谋虚空？</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 2:2; 启示录 17:12–14; 但以理书 9:24"> <span className="pl pl-1">地上的众君王都起来，</span><br /><span className="pl pl-1">首领们也聚集在一起，</span><br /><span className="pl pl-1">抵挡主和他的基督。’</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马太福音 27:2; 使徒行传 4:30; 路加福音 9:22"> “事实上，希律和本丢彼拉多，与外邦人和以色列子民果然在这城里<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="有古抄本没有“在这城里”。">k</a></sup>一同聚集，对付你所膏立的圣仆耶稣，</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 2:23; 以赛亚书 46:10; 创世记 50:20"> 做成了你手和你计划所预定要成就的一切事。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 4:13; 使徒行传 14:3; 腓立比书 1:14"> 主啊，现在求你鉴察<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="鉴察——或译作“注意”。">l</a></sup>他们的威吓，使<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="使……能——原文直译“赐给”。">m</a></sup>你的奴仆们能满有胆量地传讲你的话语。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 4:27; 使徒行传 3:6; 使徒行传 5:12"> 求你伸出你的手，藉着你圣仆耶稣的名，使疾病痊愈，施行神迹和奇事。”</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 21:22; 使徒行传 2:2; 使徒行传 2:4"> 他们祷告完了，聚集的地方就被震动，大家都被圣灵充满，就坦然无惧地传讲神的话语<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="神的话语——或译作“神的道”。">n</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="哥林多前书 1:10; 以弗所书 4:2–6; 彼得前书 3:8"> 于是那一群信徒都同心合意，没有一个人说他所拥有的哪样东西是自己的；相反，他们凡物共有。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 1:16; 使徒行传 1:22; 使徒行传 1:8"> 使徒们大有能力地为主耶稣的复活做见证，并且在他们每个人身上都有极大的恩典。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 2:45; 路加福音 12:33; 路加福音 16:9"> 他们当中没有一个缺乏的人，因为凡是拥有田产或房屋的人，都卖掉了那些东西，把所卖得的钱拿来，</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 5:2; 使徒行传 2:45; 哥林多后书 8:20–21"> 放在使徒们的脚前，按照各人的需要分给每个人。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="加拉太书 2:9; 加拉太书 2:13; 加拉太书 2:1"> 有一个出生在塞浦路斯的利未人约瑟，使徒们称他为巴拿巴——“巴拿巴”翻译出来就是“安慰之子”；</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 5:1–2; 使徒行传 4:34–35; 马太福音 19:29"> 他有一块田地，也卖掉了，把钱拿来放在使徒们的脚前。</span>
</div>
</div>

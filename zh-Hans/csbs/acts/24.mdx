<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 24:11; 使徒行传 23:2; 使徒行传 25:2"> 过了五天，大祭司阿纳尼亚带着一些长老和一个名叫特图罗斯的律师下来，向总督指控保罗。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 29:5; 箴言 26:28; 使徒行传 24:26–27"> 保罗被叫进来，特图罗斯就开始控告，说：“菲利克斯大人！因着您，我们大享和平；因着您的远见，本国也进行了许多改革；</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 23:26; 使徒行传 26:25; 路加福音 1:3"> 我们事事处处满怀感谢地领受。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 11:32"> 但为了不过多地烦扰您，我恳求您，以您的仁慈听我们简短地说。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 28:22; 使徒行传 24:14; 使徒行传 26:5"> 我们发现这个人像瘟疫一样，煽动普天下犹太人暴乱；他又是拿撒勒人教派的一个头目。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 24:12; 使徒行传 21:27–32; 约翰福音 18:31"> 他甚至试图玷污圣殿，我们就把他拘捕了。我们本来想按照我们的律法审判他，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本没有“我们本来想按照我们的律法审判他，”。">a</a></sup></span>
<span className="v" id="v7" data-v="7"> 可是千夫长吕西亚过来，把他从我们手中强行带走，又吩咐原告到您这里来。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本没有此节。">b</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 23:35; 使徒行传 25:15–16; 使徒行传 25:5"> 您亲自审问他，就能了解我们控告他的这一切事了。”</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦前书 2:16; 弥迦书 7:2–3; 诗篇 4:2"> 犹太人也都附和，声称这些事就是如此。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="彼得前书 3:15; 撒母耳记上 2:25; 路加福音 18:2"> 总督点头示意要保罗讲话，保罗就说：“我知道您在本国多年做审判官，所以我乐意为自己申辩。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 24:1; 使徒行传 21:18; 使徒行传 23:11"> 您可以了解，自从我上耶路撒冷去敬拜，到现在不超过十二天。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 25:8; 使徒行传 28:17; 使徒行传 24:18"> 无论在圣殿里，或在会堂里，或在城里，他们都没有看见我和任何人争论，或煽动民众。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 25:7; 彼得前书 3:16"> 他们现在也不能向您证实所控告我的事。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 9:2; 罗马书 3:21; 使徒行传 3:13"> 不过这一点我向您承认：我是按照他们称为‘异端<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="异端——或译作“教派”。">c</a></sup>’的这道<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="道——或译作“路”。">d</a></sup>，如此事奉我先祖的神，因为我相信一切合乎律法书和先知书上所记载的事；</span>
<span className="v" id="v15" data-v="15" data-xref="但以理书 12:2; 约翰福音 5:28–29; 帖撒罗尼迦前书 4:14–16"> 我对神所怀有的盼望也是这些人自己所期望的，就是义人和不义的人<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="义人和不义的人——有古抄本作“死人——无论是义人还是不义的人”。">e</a></sup>将来都要复活。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 23:1; 提摩太前书 1:5; 哥林多后书 4:2"> 因此，在神和人面前，我总是尽力存着无愧的良心。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 2:10; 罗马书 15:25–28; 哥林多前书 16:1–4"> 过了好几年，我回来了，带着给我同胞的施舍，以及供物；</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 26:21; 使徒行传 21:26–30; 使徒行传 24:12"> 正献上供物的时候，他们在圣殿里发现了我，那时我已经行完了洁净礼，既没有人群，也没有骚乱，</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 23:30; 使徒行传 25:16"> 只有一些从亚细亚省来的犹太人——如果对我有什么控告，应该是他们到您面前来控告。</span>
<span className="v" id="v20" data-v="20"> 还是让这些人自己说说，我站在议会前的时候，他们到底查出了我有什么罪行——</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 23:6; 使徒行传 4:2; 使徒行传 26:6–8"> 或者，是为了我站在他们中间喊过这样一句话：‘我今天在你们面前受审，是因为死人复活的事！’”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 24:6; 使徒行传 24:24; 使徒行传 25:26"> 因为菲利克斯比较详尽地了解这道，<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附“听了这些事后”。">f</a></sup>就推托他们，说：“等千夫长吕西亚下来，我再审断有关你们的事。”</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 28:16; 使徒行传 27:3; 箴言 16:7"> 他吩咐百夫长看守保罗<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="保罗——有古抄本作“他”。">g</a></sup>，要宽待他，不要阻止他自己的人来供应他<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附“或到他这里来”。">h</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行传 20:21; 加拉太书 2:16; 马可福音 6:20"> 过了几天，菲利克斯与他的犹太人妻子杜茜拉一起来了。他把保罗叫来，听他讲说对基督耶稣<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="基督耶稣——有古抄本作“基督”。">i</a></sup>的信仰。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 16:8; 彼得前书 3:15; 使徒行传 10:42"> 当保罗讲论关于公义、自制和将来的审判时，菲利克斯感到害怕，就说：“你现在可以回去，我有了时间，就会叫你。”</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太前书 6:9–10; 箴言 17:23; 以赛亚书 56:11"> 同时他也希望保罗送他钱，<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附“这样他就会释放他，”。">j</a></sup>所以经常把他叫来，和他交谈。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行传 25:9; 使徒行传 25:14; 使徒行传 12:3"> 过了两年，波奇乌菲斯特斯接替菲利克斯。菲利克斯想要讨好犹太人，就把保罗留在监狱里。</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 8:3; 提摩太前书 1:13; 加拉太书 1:13"> 扫罗仍然向主的门徒们口吐凶杀威吓的话。他来到大祭司面前，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 19:9; 使徒行传 19:23; 使徒行传 24:14"> 求他发一些信函给大马士革各会堂，准许扫罗如果发现什么人属于这道<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="道——或译作“路”。">a</a></sup>，无论男女，都捆绑起来，带到耶路撒冷。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 26:12–13; 哥林多前书 15:8; 使徒行传 22:6"> 当扫罗赶路，快到大马士革的时候，忽然有光从天上下来，四面照射他。</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 2:8; 创世记 22:11; 罗马书 11:22"> 他仆倒在地上，听见有声音对他说：<span className="woj">“扫罗，扫罗！你为什么逼迫我？”</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="提摩太前书 1:13; 撒母耳记上 3:4–10; 约伯记 9:4"> 他问：“主啊，你到底是谁？”<br />主说：<span className="woj">“我就是你所逼迫的耶稣。</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附“你脚踢刺棒，是狂妄的。”">b</a></sup></span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 22:10; 使徒行传 26:16; 提摩太前书 1:14–16"> <sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附“他又惊恐，又战抖，说：‘主啊！你要我做什么呢？’主对他说：‘……’”">c</a></sup><span className="woj">你起来，进城去！有人会告诉你应该做什么。”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行传 22:9; 但以理书 10:7; 使徒行传 26:13–14"> 与扫罗同行的人都站着，哑口无言，他们虽然听见声音，却看不见任何人。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 22:11; 使徒行传 9:18; 列王纪下 6:17–20"> 扫罗从地上爬起来，睁开眼睛，却什么也看不见。他们牵着他的手，把他带进大马士革。</span>
<span className="v" id="v9" data-v="9" data-xref="约拿书 3:6–8; 以斯帖记 4:16; 历代志下 33:12–13"> 他三天不能看见，不吃也不喝。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 22:1; 使徒行传 10:3; 使徒行传 22:12"> 在大马士革有一个名叫阿纳尼亚的门徒。主在异象中对他说：<span className="woj">“阿纳尼亚！”</span><br />他回答说：“主啊！看哪，我在这里。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 21:39; 使徒行传 22:3; 使徒行传 9:30"> 主就对他说：<span className="woj">“起来，往那叫做‘直’的街上去，在犹大家里找一个名叫扫罗的塔尔苏人。看哪，原来他正在祷告。</span></span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 5:23; 使徒行传 9:10; 使徒行传 9:17–18"> <span className="woj">他在异象中</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本没有“在异象中”。">d</a></sup><span className="woj">看见了一个名叫阿纳尼亚的人，进来按手在他身上，使他重见光明。”</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="提摩太前书 1:13–15; 使徒行传 8:3; 使徒行传 22:19–20"> 阿纳尼亚却回答：“主啊，我听许多人说过有关这个人在耶路撒冷对你的圣徒们所做的种种恶事。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 9:21; 使徒行传 7:59; 提摩太后书 2:22"> 并且，他得到祭司长们的授权来到这里，要捆绑所有求告你名的人。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="加拉太书 1:15–16; 以弗所书 3:7–8; 提摩太后书 4:16–17"> 但是主对他说：<span className="woj">“你去吧！因为这个人是我所拣选的器皿，不但要在外邦人和君王面前，还要在以色列子民面前宣扬</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="宣扬——原文直译“担当”。">e</a></sup><span className="woj">我的名。</span></span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦前书 3:3; 使徒行传 21:11; 哥林多后书 6:4"> <span className="woj">我要指示他，为了我的名他必须受多大的苦害。”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行传 8:17; 使徒行传 6:6; 使徒行传 2:4"> 阿纳尼亚就去了。他进了那家，按手在扫罗身上，说：“扫罗弟兄，在你来的路上向你显现的主耶稣差派我来，使你重见光明，并且被圣灵充满。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 3:14; 使徒行传 22:16; 使徒行传 2:38"> 立刻有像鳞片一样的东西从扫罗的眼睛上掉了下来，他就重见光明了。于是他起来受了洗；</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 26:20; 撒母耳记上 30:12; 加拉太书 1:17"> 吃过饭，体力就恢复了。 扫罗传讲基督<br />扫罗与在大马士革的门徒们住了几天，</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 20:28; 加拉太书 2:20; 约翰一书 4:14–15"> 就立刻在各会堂里传讲耶稣<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="耶稣——有古抄本作“基督”。">f</a></sup>，说这一位就是神的儿子。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 9:13–14; 使徒行传 8:3; 帖撒罗尼迦后书 1:10"> 所有听见的人都十分惊讶，说：“这不就是那个在耶路撒冷残害了那些求告这名的人吗？而且他来到这里，不就是为要捆绑他们，带到祭司长们那里吗？”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 18:5; 以赛亚书 40:29; 路加福音 21:15"> 扫罗反而更加得以刚强，证明这一位就是基督，使住在大马士革的犹太人很狼狈。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="加拉太书 1:17–18; 帖撒罗尼迦前书 2:15–16; 使徒行传 14:19"> 过了许多日子以后，犹太人商议要杀了扫罗，</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 11:32; 使徒行传 25:3; 使徒行传 20:3"> 但他们的阴谋却被扫罗知道了。于是他们就日夜严守着各城门，要杀掉他。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 2:15; 哥林多后书 11:33; 撒母耳记上 19:11–12"> 然而他的门徒们趁夜把他带去，用筐子把他从城墙上缒了下去。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 26:20; 加拉太书 1:17–19; 使徒行传 9:19"> 扫罗来到耶路撒冷，想要和门徒们交往，可是大家都怕他，不相信他成了门徒。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 4:36; 使徒行传 4:29; 使徒行传 4:13"> 但是巴拿巴接纳他，把他带到使徒们那里，并且告诉他们扫罗怎样在路上见到主，主怎样对他说了话，以及他怎样在大马士革奉耶稣的名放胆传道。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 1:21; 民数记 27:16–17; 诗篇 121:8"> 于是扫罗在耶路撒冷与他们一起出入，奉主<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="主——有古抄本作“主耶稣”。">g</a></sup>的名放胆传道。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 6:1; 犹大书 1:9; 使徒行传 11:20"> 他对那些说希腊语的犹太人讲道，与他们辩论；他们却图谋要杀了他。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 11:25; 使徒行传 8:40; 使徒行传 9:11"> 弟兄们知道了这事，就带他下到凯撒里亚，然后送他往塔尔苏去。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="诗篇 111:10; 约翰福音 14:16–18; 以赛亚书 33:6"> 这样，教会在犹太、加利利、撒玛利亚全地得平安、得造就，并且怀着对主的敬畏之心不断地前行，在圣灵的安慰<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="安慰——或译作“鼓励”。">h</a></sup>中不断地增长。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行传 9:13; 使徒行传 8:25; 箴言 2:8"> 有一次，彼得走遍各地的时候，也下到住在利达的圣徒们那里。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 13:16; 约翰福音 5:5; 马可福音 2:3–11"> 在那里，他遇见了一个名叫艾尼亚的人。他是个瘫痪的人，躺在垫子上八年了。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 9:6; 使徒行传 3:12; 使徒行传 3:6"> 彼得对他说：“艾尼亚，耶稣基督使你痊愈。站起来，为你自己整理垫子吧！”艾尼亚立刻就站起来了。</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 11:21; 使徒行传 9:42; 历代志上 5:16"> 于是所有住在利达和沙仑的人看到他，就归向了主。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="提多书 3:8; 提多书 2:7; 历代志下 2:16"> 在约帕有一个女门徒，名叫塔比莎——“塔比莎”翻译出来意思是“羚羊<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="羚羊——音译为“多卡丝”。">i</a></sup>”。她尽做美善工作，常行施舍。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 1:13; 使徒行传 20:8; 约翰福音 11:36–37"> 就在那些日子里，她患病死了。人们清洗了遗体，就放在楼上的房间。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 9:36; 使徒行传 11:26; 使徒行传 9:32"> 利达离约帕不远，门徒们听说彼得在利达，就派了两个人到他那里，恳求他说：“请你来到我们这里，不要耽延！”</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 10:7; 箴言 31:30–31; 帖撒罗尼迦前书 1:3"> 彼得就起身陪他们一起去。到了以后，他们把他领到楼上的房间。所有的寡妇都站在彼得旁边哭，把多卡丝与她们在一起的时候所缝制的衣服和袍子拿给他看。</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 9:25; 马可福音 5:40–42; 路加福音 8:54"> 彼得叫大家都出去，然后跪下祷告，接着转过身对着遗体，说：“塔比莎，你起来！”那妇人就睁开眼睛，看见彼得，而且坐了起来。</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 1:31; 使徒行传 6:1; 创世记 45:26"> 彼得伸手扶她站起来，又叫圣徒们和寡妇们进来，把活过来的多卡丝交给他们。</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 12:44; 约翰福音 12:11; 约翰福音 11:45"> 这事传遍了整个约帕，许多人就信了主。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行传 10:6; 使徒行传 10:32"> 后来，彼得在约帕的一个硝皮匠西门家里住了许多日子。</span>
</div>
</div>

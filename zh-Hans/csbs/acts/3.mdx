<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 55:17; 使徒行传 10:3; 使徒行传 4:13"> 有一次，在下午三点<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="下午三点——原文为“第九时刻”。">a</a></sup>祷告的时候，彼得和约翰上圣殿去。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 14:8; 约翰福音 9:8; 路加福音 16:20"> 一个生来<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="生来——原文直译“从母腹中”。">b</a></sup>瘸腿的被人抬来。他天天被放在那叫“美门”的圣殿门口，为要向进圣殿的人乞讨。</span>
<span className="v" id="v3" data-v="3"> 他看见彼得和约翰正要进入圣殿，就求他们施舍。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 14:9–10; 约翰福音 11:40; 路加福音 4:20"> 彼得和约翰注视着他，彼得说：“你看我们！”</span>
<span className="v" id="v5" data-v="5"> 那人就留意看他们，期待着从他们那里得些什么。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 3:16; 使徒行传 10:38; 使徒行传 4:10"> 彼得却说：“金子银子我都没有，只把我有的给你：奉拿撒勒人耶稣基督的名，起来<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本没有“起来”。">c</a></sup>走路吧！”</span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 1:31; 马可福音 9:27; 使徒行传 9:41"> 彼得抓着他的右手，扶他起来。他的脚和踝骨立刻就健壮了。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 14:10; 以赛亚书 35:6; 诗篇 107:20–22"> 他一跳，站了起来，并且行走，与他们一起进入圣殿，边走边跳，赞美神。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 4:21; 使徒行传 4:16; 路加福音 13:17"> 全体民众都看见他边走边赞美神，</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 3:2; 约翰福音 5:20; 约翰福音 9:3"> 认出他是坐在圣殿的美门口乞讨的那个人，就对发生在他身上的事满心希奇、惊讶。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 5:12; 约翰福音 10:23; 路加福音 8:38"> 那个人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="那个人——有古抄本作“那得了痊愈的瘸腿之人”。">d</a></sup>紧拉着彼得和约翰的时候，全体民众都一起跑向他们，到叫做“所罗门”的柱廊那里，满心惊奇。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 3:5; 约翰福音 3:27–28; 但以理书 2:28–30"> 彼得看见，就对民众说：“各位以色列人哪！你们为什么对这事感到惊奇？为什么注视我们，以为我们是凭着自己的能力或虔诚使这个人走路的呢？</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 22:32; 使徒行传 7:32; 马太福音 27:17–25"> 亚伯拉罕、以撒、雅各的神<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="亚伯拉罕、以撒、雅各的神——原文直译“亚伯拉罕的神、以撒的神、雅各的神”。">e</a></sup>，也就是我们祖先的神，已经荣耀了他的仆人耶稣。你们竟然把他交出去，并且在彼拉多判定要释放他的时候，在彼拉多面前拒绝了他。</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 1:24; 使徒行传 7:52; 彼得前书 3:18"> 你们拒绝了神圣、公义的那一位，而要求释放一个杀人犯给你们。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 2:24; 启示录 21:6; 使徒行传 2:32"> 你们杀害了生命的创始者<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="创始者——或译作“本源”或“元首”。">f</a></sup>，神却使他从死人中复活了！我们就是这事的见证人。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 21:21–22; 使徒行传 4:10; 使徒行传 14:9"> 现在，基于对他名的信心，他的名就使你们所看见所认识的这个人健壮了；这由耶稣而来的信心，使他在你们众人面前完全康复了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 23:34; 使徒行传 13:27; 约翰福音 16:3"> “同胞们<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="同胞们——原文直译“兄弟们”。">g</a></sup>，现在我知道，你们所做的是出于愚昧无知，就像你们的首领那样。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 53:1–12; 使徒行传 26:22–23; 使徒行传 2:23"> 但神藉着众先知的口所预言的，就是基督要受难的事，就这样应验了。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 2:38; 以赛亚书 44:22; 以赛亚书 43:25"> 所以，你们应当悔改，应当回转，使你们的罪孽被抹去，</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 24:30–36; 启示录 19:11–16; 帖撒罗尼迦后书 2:2"> 这样，更新的日子<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="更新的日子——或译作“安舒的日子”。">h</a></sup>就会从主面前来到；并且他要将耶稣，就是预先指定给你们的那位基督差来。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 8:21; 以赛亚书 1:26; 使徒行传 1:11"> 不过天必须留他，直到万有复兴的时候，就是神自古以来藉着圣先知们的口所说的那时候。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 18:15–19; 使徒行传 7:37; 加拉太书 4:4"> 摩西确实<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附“对祖先”。">i</a></sup>说过：<br />‘主——你们的神，将要从你们兄弟中给你们兴起一位先知，像兴起我一样。他对你们所说的一切，你们都要听从。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 18:19; 约翰福音 12:48; 希伯来书 10:28–30"> 所有不听从那位先知的人<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="人——原文直译“灵魂”。">j</a></sup>，都要从民中被全然灭绝。’</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行传 3:21; 路加福音 24:27; 撒母耳记上 3:20"> “其实从撒母耳以来所有的先知，只要说预言<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="说预言——原文直译“说话”。">k</a></sup>，都同样地预告了这些日子。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 22:18; 加拉太书 3:8; 使徒行传 2:39"> 你们是先知们的子孙，也是神与你们<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="你们——有古抄本作“我们”。">l</a></sup>祖先所订立之约的子孙。那时神对亚伯拉罕说：‘藉着你的那位后裔，地上万族都要蒙祝福。’</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 1:21; 使徒行传 3:22; 犹大书 1:24"> 神兴起了他的仆人<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="有古抄本附“耶稣”。">m</a></sup>，差派他先到你们这里来，要你们每个人转离自己的罪行，好祝福你们。”</span>
</div>
</div>

</div>

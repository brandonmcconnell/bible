<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 23:34; 使徒行传 25:5; 使徒行传 8:40"> 菲斯特斯到省里上任第三天，就从凯撒里亚上耶路撒冷去。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 25:15; 箴言 4:16; 使徒行传 24:1"> 祭司长们和犹太人的首领们向菲斯特斯指控保罗，并且恳求菲斯特斯，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 9:24; 使徒行传 23:12–15; 撒母耳记上 23:19–21"> 请他恩准，把保罗叫到耶路撒冷来。他们策划要在路上埋伏杀了保罗。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 24:23"> 于是菲斯特斯说：“保罗正被拘留在凯撒里亚，我自己也很快就要回去。”</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 25:25; 约翰福音 18:29–30; 使徒行传 25:18–19"> 他又说：“所以你们中间有权的人都与我一起下去；如果这个人有什么过错，就当控告他。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 25:17; 使徒行传 25:10; 马太福音 27:19"> 菲斯特斯在他们那里住了不超过十天八天<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="不超过十天八天——有古抄本作“十多天”。">a</a></sup>，就下到凯撒里亚去了。第二天，他坐在审判席上，下令把保罗带上来。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 24:13; 路加福音 23:10; 使徒行传 25:24"> 保罗<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="保罗——原文直译“他”。">b</a></sup>一到，从耶路撒冷下来的那些犹太人就站在他周围，用很多严重的罪状来控告他，可是都不能证实。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 24:12; 使徒行传 28:17; 哥林多后书 1:12"> 保罗申辩说：“无论是对犹太人的律法，或是对圣殿，或是对凯撒，我都没有犯过罪。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 24:27; 使徒行传 12:3; 使徒行传 25:20"> 但菲斯特斯想要讨好犹太人，就问保罗说：“你愿意上耶路撒冷，让我在那里审判这些事吗？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 27:18; 哥林多后书 4:2; 使徒行传 28:18"> 保罗就说：“我已经站在凯撒的审判台前，这里就是我应该受审的地方。我没有亏负过犹太人，就像您也很清楚地了解那样。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 28:19; 使徒行传 26:32; 使徒行传 25:25"> 既然如此，如果我行了什么不义的事，犯了什么该死的罪，就是死我也不拒绝；但如果这些人对我的控告不是真的，那么谁也不能把我交给他们。我向凯撒上诉！”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 19:21; 腓立比书 1:12–14; 腓立比书 1:20"> 菲斯特斯与参议会商量以后，就回答：“你已经向凯撒上诉了，你就将到凯撒那里去！”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 8:40; 使徒行传 26:1; 使徒行传 26:27–28"> 过了几天，阿格里帕王<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="阿格里帕王——指“希律阿格里帕二世”。">c</a></sup>和百妮基到达凯撒里亚，问候菲斯特斯。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 24:27"> 他们在那里住了好几天，菲斯特斯就向阿格里帕王陈述了有关保罗的事，说：“这里有一个人，是菲利克斯留下的囚犯。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 25:1–3; 以斯帖记 3:9; 路加福音 18:3–5"> 我到耶路撒冷去的时候，犹太人的祭司长们和长老们指控他，要求我定他的罪。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 7:51; 申命记 19:17–18; 使徒行传 23:30"> 我回答他们：在被告还没有与原告当面对质，并且对被控罪名还没有获得申辩机会以前，就把被告<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="被告——原文直译“任何人”。">d</a></sup>交出去，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附“以至于死”。">e</a></sup>这不符合罗马人的规矩。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 25:6; 使徒行传 25:10"> 因此，当他们聚集在这里的时候，我没有耽搁，第二天就坐在审判席上，下令把那个人带来。</span>
<span className="v" id="v18" data-v="18"> 那些原告站起来围着他提出来的罪状，并不是我所认为的恶事<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本没有“恶事”。">f</a></sup>。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 23:29; 使徒行传 18:15; 哥林多前书 15:3–4"> 不过他们与他有一些争议的问题，是关于自己宗教的事，以及关于一个叫耶稣的人——这个人已经死了，保罗却声称他还活着。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 25:9"> 我对这些辩论也心里困惑，就问保罗是否愿意上耶路撒冷去，在那里为这些事受审。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 4:16; 路加福音 2:1; 使徒行传 25:10–11"> 可是保罗请求把他留给皇帝审断，我就下令把他留下，等着我送他到凯撒那里去。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 9:15; 马太福音 10:18; 以赛亚书 52:15"> 阿格里帕对菲斯特斯说：“我本来也想亲自听这个人讲说。”<br />菲斯特斯说：“明天你就可以听他讲说。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 26:30; 使徒行传 25:13; 约翰一书 2:16"> 第二天，阿格里帕和百妮基大张声势而来，当他们与几个军官和城里的显要人物一起进了大厅，菲斯特斯一声下令，保罗就被带上来。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 22:22; 使徒行传 25:7; 使徒行传 25:2–3"> 菲斯特斯说：“阿格里帕王和所有在场的各位，你们所看见的这个人，犹太的全体民众为了他，在耶路撒冷和这里向我陈情，喊着说他不应该再活下去。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 23:29; 使徒行传 25:11–12; 路加福音 23:4"> 但是我了解他并没有犯过什么该死的罪，不过他自己既然向皇帝上诉了，我就决定把他解送去。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 26:2–3"> 关于这个人，我没有任何确切的事可以陈奏皇帝。因此我把他带到你们面前，尤其在您阿格里帕王面前，好使审查结束时，我可以有所陈奏，</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 7:51; 箴言 18:13"> 因为我认为，解送囚犯而不指明对他的罪状，是没有道理的。”</span>
</div>
</div>

</div>

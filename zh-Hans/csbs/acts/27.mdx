<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="ACT" data-book-slug="acts" data-book-name="使徒行传" data-chapter="27" data-verses="44">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 25:25; 使徒行传 25:12; 使徒行传 10:1"> 既然决定了我们要坐船往意大利去，他们就把保罗和其他一些囚犯交给皇家军团的一个名叫犹利乌斯的百夫长。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 19:29; 腓利门书 1:24; 歌罗西书 4:10"> 有一条阿德米提的船，要开往亚细亚省沿岸各地，我们就上那船出发了。有一个从帖撒罗尼迦来的马其顿人亚里达古，与我们在一起。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 24:23; 使徒行传 28:16; 使徒行传 27:43"> 第二天，我们在西顿靠岸。犹利乌斯宽待保罗，准许他到朋友那里去接受照顾。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 4:36; 使徒行传 15:39; 使徒行传 13:4"> 我们从那里起航，因为逆风，就沿着塞浦路斯岛的背风岸航行。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 6:9; 使徒行传 13:13; 使徒行传 15:41"> 度过了奇里乞亚省和潘菲利亚省一带的海域，在吕基亚省的每拉登陆。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 28:11; 使徒行传 27:1; 使徒行传 6:9"> 百夫长在那里找到了一条亚历山大的船，要开往意大利去，就安排我们上了那船。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 27:21; 提多书 1:5; 提多书 1:12"> 一连好几天，船航行得很慢，好不容易才到了尼多斯港附近。因为风拦阻我们往前，我们就从撒摩尼岬附近经过，沿着克里特岛的背风岸航行。</span>
<span className="v" id="v8" data-v="8"> 我们沿着它航行，好不容易来到一个叫做“美丽港”的地方；离那里不远，有个城叫做拉塞亚。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数记 29:7; 利未记 23:27–29; 利未记 16:29–31"> 又过了很久，这次航程已经很危险，又因为已经过了禁食日<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="禁食日——指“（犹太人的）赎罪日”。">a</a></sup>，保罗就劝大家，</span>
<span className="v" id="v10" data-v="10" data-xref="但以理书 2:30; 使徒行传 27:20–26; 使徒行传 27:41–44"> 说：“各位，我看这次航程，不仅是货物和船，就是我们的生命财产也将会受到伤害和严重的损失。”</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 33:4; 希伯来书 11:7; 以西结书 3:17–18"> 可是百夫长信任了船长和船主，不信任保罗所说的，</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 107:30; 使徒行传 27:8"> 而且这港口不适合过冬，大多数人就主张从那里开船，或许能够到达菲尼斯过冬。菲尼斯是克里特岛上的一个港口，一面朝西南，一面朝西北。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:55; 雅歌 4:16; 约伯记 37:17"> 这时，南风微微吹起，他们以为正合所愿，就起了锚，沿着克里特岛航行。</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 4:37; 诗篇 107:25–27; 出埃及记 14:21–27"> 但是过了不久，一股叫做“东北风”的飓风，从岛上袭来。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各书 3:4; 使徒行传 27:27"> 船被困住，顶不住风，我们只好任凭船被刮走。</span>
<span className="v" id="v16" data-v="16"> 我们沿着一个叫做克劳达小岛的背风岸行驶的时候，好不容易才控制住救生艇。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 27:29; 使徒行传 27:26; 使徒行传 27:41"> 水手们<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="水手们——原文直译“他们”。">b</a></sup>把救生艇拖上来以后，就用缆绳绕过大船底绑好；又怕在叙尔提斯浅滩上会搁浅，就把锚放低，任船漂流。</span>
<span className="v" id="v18" data-v="18" data-xref="约拿书 1:5; 使徒行传 27:38; 马太福音 16:26"> 我们被暴风猛烈地袭击。第二天，他们开始把货物抛在海里。</span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 2:4; 路加福音 9:24–25; 马可福音 8:35–37"> 第三天，他们又亲手把船上的用具抛出去。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马太福音 24:29; 马太福音 8:24–25; 耶利米书 2:25"> 一连好几天见不到太阳和星星，又有暴风雨催逼着，最后我们连获救的希望都断绝了。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 42:22; 诗篇 107:5–6; 使徒行传 27:7"> 那时，大家已经很久没有吃东西了，保罗站在他们当中说：“哦，各位啊！你们当初应该听我的，不从克里特开船，省得有这样的伤害和损失。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 27:25; 使徒行传 27:36; 哥林多后书 4:8–9"> 只是现在我劝你们振作起来，因为你们当中不会有人失去性命，不过会失去这条船。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 23:11; 罗马书 1:9; 提摩太后书 4:17"> 要知道，我所归属、所事奉的神，他的一位天使昨天晚上站在我身边，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 23:11; 提摩太后书 4:16–17; 马太福音 10:28"> 说：‘保罗，不要怕！你必须站在凯撒面前。看哪，所有与你同船的人，神都赐给你了。’</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 4:20–21; 路加福音 1:45; 民数记 23:19"> 所以请各位振作起来，因为我相信神怎样对我说，事情也会怎样成就。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 28:1; 使徒行传 27:17; 使徒行传 27:29"> 不过我们必须搁浅在一个岛上。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约拿书 1:6; 使徒行传 27:30; 启示录 18:17"> 到了第十四天的晚上，我们在亚得里亚海上飘来飘去。约在半夜，水手们认为已经靠近陆地了，</span>
<span className="v" id="v28" data-v="28"> 就测了水深，发现有三十七公尺<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="三十七公尺——原文为“20欧贵亚”。1欧贵亚=185公分。">c</a></sup>；稍往前行，再测一测，发现有二十七公尺<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="二十七公尺——原文为“15欧贵亚”。1欧贵亚=185公分。">d</a></sup>。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 27:17; 希伯来书 6:19; 申命记 28:67"> 他们担心会撞到礁石，就从船尾抛下四个锚，祈盼着天亮。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行传 27:16; 使徒行传 27:32"> 水手们想离船逃生，就把救生艇放到海里，却假装要从船头抛锚。</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒罗尼迦后书 2:13–14; 诗篇 91:11–12; 耶利米书 29:11–13"> 保罗对百夫长和士兵们说：“这些人如果不留在船上，你们就不能获救。”</span>
<span className="v" id="v32" data-v="32" data-xref="腓立比书 3:7–9; 路加福音 16:8"> 于是士兵们就把救生艇的绳索砍断，由它漂去。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 天快亮的时候<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="天快亮的时候——原文直译“白昼就要来临了”。">e</a></sup>，保罗劝大家用饭，说：“你们一直挨饿等候，什么都不吃，今天是第十四天了。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 10:30; 列王纪上 1:52; 路加福音 21:18"> 所以我劝你们用饭，因为这是关于你们得救的事。要知道，你们中间，没有一个人会失去<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="失去——有古抄本作“掉”。">f</a></sup>一根头发。”</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 15:36; 哥林多前书 10:30–31; 提摩太前书 4:3–4"> 说完这些话，保罗就拿起饼，在大家面前感谢神，然后掰开来，开始吃。</span>
<span className="v" id="v36" data-v="36" data-xref="哥林多后书 1:4–6; 使徒行传 27:22; 诗篇 27:14"> 于是大家受到鼓励，也吃了饭。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 2:41; 罗马书 13:1; 彼得前书 3:20"> 我们在船上的，共有两百七十六个人<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="人——原文直译“灵魂”。">g</a></sup>。</span>
<span className="v" id="v38" data-v="38" data-xref="约拿书 1:5; 马太福音 6:25; 使徒行传 27:18–19"> 大家吃饱了饭，就把麦子扔到海里，减轻船的负荷。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒行传 28:1"> 天亮的时候，他们虽然不认识那地方，却看见一个有沙滩的海湾，就决定尽可能地把船拢进去。</span>
<span className="v" id="v40" data-v="40" data-xref="以赛亚书 33:23; 使徒行传 27:29–30"> 于是他们砍断了锚，把它们丢弃在海里，同时松开舵绳，拉起了前帆，顺着风向岸前进。</span>
<span className="v" id="v41" data-v="41" data-xref="哥林多后书 11:25–26; 以西结书 27:26; 使徒行传 27:26–29"> 但遇到海水夹流的地方，船就搁了浅，船头被卡住，动弹不得，而船尾也开始被波浪的猛力冲散了。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="马可福音 15:15–20; 传道书 9:3; 诗篇 74:20"> 士兵们的计划是要把囚犯杀了，免得有人游泳逃脱。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行传 27:3; 箴言 16:7; 使徒行传 27:11"> 可是百夫长想救保罗，就拦阻了他们的计划，命令会游泳的人跳下船，先到岸上去，</span>
<span className="v" id="v44" data-v="44" data-xref="使徒行传 27:22; 诗篇 107:28–30; 约翰福音 6:39–40"> 其余的人，有的用木板，有的用船上的东西跟着<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="跟着——辅助词语。">h</a></sup>；这样，大家就都获救上岸了。</span>
</div>
</div>

</div>

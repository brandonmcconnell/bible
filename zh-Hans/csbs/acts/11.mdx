<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="ACT" data-book-slug="acts" data-book-name="使徒行传" data-chapter="11" data-verses="30">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 22:27; 玛拉基书 1:11; 以赛亚书 32:15"> 后来，使徒们和在犹太各地的弟兄们听说外邦人也接受了神的话语<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="神的话语——或译作“神的道”。">a</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 10:45; 使徒行传 10:9; 使徒行传 15:1"> 可是当彼得上到耶路撒冷的时候，那些割礼派的人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="割礼派的人——或译作“受割礼的人”。">b</a></sup>却批评他，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 10:28; 加拉太书 2:12; 路加福音 15:2"> 说：“你竟然进到没有受割礼之人的家里，又与他们一起吃饭。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="路加福音 1:3; 使徒行传 14:27; 约书亚记 22:21–31"> 彼得就开始按着次序向他们讲解，说：</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 10:9–32; 使徒行传 9:10; 使徒行传 22:17"> “我在约帕城里祷告的时候，魂游象外，看见一个异象：有一样东西<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="东西——原文直译“容器”。">c</a></sup>从天上降下，好像一块大布，四角捆住<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="捆住——辅助词语。">d</a></sup>，缒到我面前来。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 4:20; 使徒行传 3:4"> 我注目观看它，看见里面有<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="里面有——辅助词语。">e</a></sup>地上的四足动物、野兽、爬行动物和天空的飞鸟；</span>
<span className="v" id="v7" data-v="7"> 那时我也听见有声音对我说：<span className="woj">‘彼得，起来，宰了吃！’</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="罗马书 14:14; 何西阿书 9:3; 哥林多前书 7:14"> 我说：‘主啊，千万不可！因为俗物或不洁净的东西，从来没有入过我的口。’</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 15:9; 希伯来书 9:13–14; 使徒行传 10:34–35"> 那声音第二次从天上传来，说：<span className="woj">‘神所洁净的，你不可当做污秽的。’</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约翰福音 21:17; 民数记 24:10; 哥林多后书 12:8"> 这样一连有三次，然后所有的东西又被收回天上去了。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 4:27; 使徒行传 9:10–12; 出埃及记 4:14"> 正在这时，忽然有三个人站在我们所住的房子面前，他们是从凯撒里亚被派到我这里的。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 8:29; 罗马书 3:22; 帖撒罗尼迦后书 2:2"> 圣灵吩咐我：要陪他们一起去，不要有任何疑惑。当时与我一起去的，还有这六位弟兄。后来我们就进了那人的家。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 10:30–32; 使徒行传 10:3–6; 使徒行传 9:43"> 他告诉我们，他怎样看见一位天使站在他家里说：‘你要派人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本没有“人”。">f</a></sup>到约帕去，请那称为彼得的西门来；</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 16:15; 使徒行传 10:22; 使徒行传 16:31–34"> 他有话要对你说，藉这话你和你全家将要得救。’</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行传 19:6; 使徒行传 10:34–46; 使徒行传 2:2–12"> 我一开始讲话，圣灵就降临在他们身上，就像当初降临在我们身上一样。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 1:5; 马可福音 1:8; 箴言 1:23"> 我就想起了主如此说的话，<span className="woj">‘约翰用水</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="用水——或译作“在水里”。">g</a></sup><span className="woj">施洗</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="施洗——或译作“施浸”。">h</a></sup><span className="woj">，但你们将要受圣灵的洗。’</span></span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 10:47; 罗马书 9:20–26; 但以理书 4:35"> 因此，神如果给了他们这相同的恩赐，就像在我们信靠主耶稣基督的时候也给了我们一样，那么，我是谁呢？难道能拦阻神吗？”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="罗马书 10:12–13; 哥林多后书 7:10; 以西结书 36:26"> 他们听了这些话就安静下来，然后就荣耀神，说：“这样，神把悔改的心也赐给外邦人，使他们得生命。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 4:36; 使徒行传 21:2; 使徒行传 15:3"> 于是那些因司提反的事受患难而四散的信徒<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="信徒——辅助词语。">i</a></sup>，就一直走到腓尼基地区、塞浦路斯岛和安提阿。他们只向犹太人，而不向任何人传讲福音<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="福音——原文直译“话语”或“道”。">j</a></sup>。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 27:32; 使徒行传 13:1; 哥林多前书 1:23–24"> 但其中有一些塞浦路斯人和古利奈人，来到安提阿，也向希腊人讲道，传主耶稣的福音。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:66; 使徒行传 2:47; 使徒行传 5:14"> 主的手与他们同在，有许许多多的人就相信、归向了主。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 9:27; 使徒行传 8:14; 使徒行传 13:1–3"> 这消息传到在耶路撒冷的教会<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="教会——原文直译“教会耳中”。">k</a></sup>，他们就派巴拿巴到安提阿去。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 15:58; 使徒行传 14:22; 使徒行传 13:43"> 巴拿巴到了，看见神的恩典就感到欢喜，鼓励大家要立定心志，继续靠<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="继续靠——或译作“恒久靠”。">l</a></sup>主，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 11:21; 使徒行传 5:14; 使徒行传 9:31"> ——这是因为巴拿巴是个好人，充满圣灵和信仰。于是有一大群人归向<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="归向——原文直译“加添”。">m</a></sup>了主。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 9:11; 使徒行传 9:27; 使徒行传 9:30"> 后来巴拿巴到塔尔苏去找扫罗，</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前书 4:16; 使徒行传 26:28; 彼得前书 4:14"> 找到了，就带他到安提阿来。然后有整整一年，两个人与会众聚在一起，教导了一大群人。门徒们第一次被称为“基督徒”是在安提阿。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行传 13:1; 哥林多前书 12:28; 以弗所书 4:11"> 在那些日子里，有几个做先知传道的<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="做先知传道的——原文直译“先知”。">n</a></sup>从耶路撒冷下到安提阿。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 21:10; 使徒行传 18:2; 路加福音 3:1"> 其中有一个名叫阿伽布斯的站起来，藉着圣灵指明普天下将有大饥荒。这事在凯撒<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="有古抄本没有“凯撒”。">o</a></sup>克劳迪时期果然发生了。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多后书 8:12–14; 加拉太书 2:10; 哥林多后书 8:2–4"> 于是门徒们决定，每个人照着自己的能力来捐献<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="捐献——或译作“供应”。">p</a></sup>，好送到住在犹太的弟兄们那里。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 14:23; 使徒行传 12:25; 使徒行传 15:4"> 他们就这么做了，由巴拿巴和扫罗经手，把所捐献的送到长老们那里。</span>
</div>
</div>

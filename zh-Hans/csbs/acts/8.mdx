<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 22:20; 但以理书 3:16–18; 使徒行传 5:40"> 扫罗也赞同杀害司提反。<br />从那一天开始，有大逼迫临到耶路撒冷的教会。除了使徒以外，他们都分散到犹太和撒玛利亚地区。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 50:10–11; 创世记 23:2; 耶利米书 22:18"> 有些虔诚的人把司提反埋葬了，为他大大地悲伤。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前书 1:13; 加拉太书 1:13; 哥林多前书 15:9"> 扫罗却摧残教会，闯进各家各户，无论男女都拉去关进监狱。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="马太福音 10:23; 使徒行传 11:19; 使徒行传 8:1"> 于是那些分散的人就走遍各地传讲福音<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="福音——原文直译“话语”或“道”。">a</a></sup>。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 6:5; 使徒行传 21:8; 使徒行传 8:35–36"> 腓利下到撒玛利亚的一个城<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="撒马利亚的一个城——有古抄本作“撒马利亚城”。">b</a></sup>，向那里的人传讲基督。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 4:41–42; 历代志下 30:12; 马太福音 20:15–16"> 当众人听见又看见腓利所行的神迹，就同心合意，专心听他所说的话。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 10:1; 使徒行传 14:8–10; 马可福音 16:17–18"> 那时，有许多人被污灵附身，那些污灵大声喊叫着从他们身上出来了；许多瘫痪的和瘸腿的，也得了痊愈。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 13:52; 使徒行传 13:48; 使徒行传 8:39"> 所以那城里，有极大的喜乐。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 13:6; 使徒行传 5:36; 约翰福音 7:18"> 有一个名叫西门的人，自称是个大人物，一向在那城里行邪术，使撒玛利亚的居民十分惊讶。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 31:34; 彼得后书 2:2; 启示录 13:3"> 所有的人，从卑微的到尊贵的，都听从他。他们说：“这个人就是那被称为‘神的大能者’的。”</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 8:9; 加拉太书 3:1; 以赛亚书 44:25"> 他们听从<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="听从——原文直译“注重”。">c</a></sup>他，因为他长期以来用邪术使他们十分惊讶。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 2:38; 使徒行传 1:3; 马太福音 28:19"> 可是腓利传讲有关神国的福音和耶稣基督之名的时候，他们就相信了，无论男女都受了洗，</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 8:6–7; 约翰福音 5:20; 使徒行传 19:11"> 连西门自己也信了。他受洗<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="受洗——或译作“受浸”。">d</a></sup>以后，常常跟着腓利，看见所行出来的神迹和大能，就十分惊讶。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:13; 帖撒罗尼迦前书 3:2; 加拉太书 2:9"> 在耶路撒冷的使徒们听说撒玛利亚人接受了神的话语<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="神的话语——或译作“神的道”。">e</a></sup>，就派彼得和约翰到他们那里去。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 2:38; 约翰福音 16:23–24; 约翰福音 14:13–14"> 两个人下去，就为他们祷告，好使他们领受圣灵，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 2:38; 使徒行传 19:2; 马太福音 28:19"> 因为圣灵还没有降临到他们任何人身上。他们只是受洗归入了主耶稣的名<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="受洗归入了主耶稣的名——或译作“奉主耶稣的名受了洗”。">f</a></sup>。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 19:6; 使徒行传 6:6; 提摩太后书 1:6"> 于是彼得和约翰按手在他们身上，他们就领受了圣灵。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="提摩太前书 6:5; 马太福音 10:8; 列王纪下 8:9"> 西门看见因着使徒们的按手，有圣灵<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="圣灵——有古抄本作“灵”。">g</a></sup>赐下，就拿了钱给他们，</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 14:7–11; 约翰三书 1:9; 约翰福音 5:44"> 说：“请把这权柄也给我，使我按手在谁身上，谁就可以领受圣灵。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="但以理书 5:17; 马太福音 10:8; 使徒行传 2:38"> 彼得对他说：“你的银子和你一起灭亡<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="灭亡——或译作“沉沦”。">h</a></sup>吧！因为你以为神的恩赐可以用钱买到！</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 4:13; 诗篇 36:1; 马太福音 6:22–24"> 你在这件事上无份无关，因为在神面前你的心不正。</span>
<span className="v" id="v22" data-v="22" data-xref="提摩太后书 2:25–26; 但以理书 4:27; 希伯来书 4:12"> 所以你应当为这恶事悔改，向主<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="主——有古抄本作“神”。">i</a></sup>祈求，或许你心中的意念因此被赦免。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 58:6; 箴言 5:22; 约翰福音 8:34"> 因我看出你在苦毒的胆汁中，被不义所捆绑。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出埃及记 8:8; 民数记 21:7; 约伯记 42:8"> 西门回答说：“请你们为我向主祈求，使你们所说的，没有一样临到我。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行传 20:21; 使徒行传 26:22–23; 使徒行传 1:8"> 于是彼得和约翰在那里郑重地做见证，传讲了主的福音<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="福音——原文直译“话语”或“道”。">j</a></sup>，又在撒玛利亚人的许多村庄传福音，就回耶路撒冷去了。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 5:19; 希伯来书 1:14; 列王纪下 1:3"> 有主的一位天使对腓利说：“你起来，顺着那条从耶路撒冷下到加沙的路，往南走。”那里是旷野。</span>
<span className="v" id="v27" data-v="27" data-xref="西番雅书 3:10; 诗篇 68:31; 以赛亚书 56:3–8"> 腓利就起身去了。看哪，有一个埃塞俄比亚人，是个太监，是埃塞俄比亚坎蒂丝女王的大臣，统管她整个国库。他到耶路撒冷去敬拜后，</span>
<span className="v" id="v28" data-v="28" data-xref="歌罗西书 3:16; 以赛亚书 1:1; 使徒行传 28:25"> 在回去的时候，坐在他的马车里诵读先知以赛亚的书。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行传 10:19; 使徒行传 11:12; 使徒行传 20:22–23"> 圣灵对腓利说：“你上前去，贴近那马车走。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 24:44–45; 约翰福音 5:39; 以弗所书 5:17"> 腓利跑过去，听见他正在诵读先知以赛亚的书，就问：“难道你真的明白你所读的吗？”</span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="罗马书 10:14; 诗篇 73:16–17; 以赛亚书 29:18–19"> 太监回答说：“如果没有人指教我，我怎么能明白呢？”他就请腓利上来和他同坐。</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 53:7–8; 彼得前书 2:21–24; 耶利米书 51:40"> 太监诵读的那段经文是这样的：<br /><span className="pl pl-1">“他像羊被牵去宰杀，</span><br /><span className="pl pl-1">又像羊羔在剪毛的人面前默默无声，</span><br /><span className="pl pl-1">他也这样不开口。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 53:12; 以赛亚书 53:8; 撒迦利亚书 13:7"> <span className="pl pl-1">他在屈辱中，公义被夺走了，</span><br /><span className="pl pl-1">谁能述说他的世代呢</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="谁能述说他的世代呢——或译作“谁来述说他的家世呢”。">k</a></sup><br /><span className="pl pl-1">？</span><br /><span className="pl pl-1">因为他的生命从地上被夺走了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马太福音 15:15; 马太福音 13:36; 马太福音 2:2–4"> 太监对腓利说：“请问，先知说的这话是关于谁呢？是关于自己，还是关于别人呢？”</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 24:27; 使徒行传 18:28; 使徒行传 28:23"> 腓利就开口，从这一段经文开始，向他传讲耶稣的福音。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行传 10:47; 约翰福音 3:5; 提多书 3:5–6"> 当他们沿路前行的时候，来到一个有水的地方。太监说：“看哪，有水！有什么能阻止我受洗呢？”</span>
<span className="v" id="v37" data-v="37"> 腓利说：“如果你全心相信就可以受洗。”太监回答说：“我相信耶稣基督是神的儿子。”<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本没有此节。">l</a></sup></span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 4:1; 约翰福音 3:22–23"> 于是他吩咐停下马车，腓利和太监，两个人下到水里，腓利就给他施洗<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="施洗——或译作“施浸”。">m</a></sup>。</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪上 18:12; 列王纪下 2:16; 以西结书 8:3"> 他们从水里上来的时候，主的灵把腓利提走，太监再也看不见他了。太监继续赶路，满心快乐。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行传 21:8; 使徒行传 23:23; 使徒行传 23:33"> 后来，腓利出现在阿佐托。他走遍各个城镇传扬福音，直到他来到凯撒里亚。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 24:9; 约翰福音 15:20; 马太福音 10:17–18"> 大约在此时，希律王下手虐待教会中的一些人，</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:37; 马太福音 20:23; 马太福音 4:21–22"> 用刀杀了约翰的哥哥<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="哥哥——原文直译“兄弟”。">a</a></sup>雅各。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 23:15; 约翰福音 12:43; 使徒行传 24:27"> 他见这事使犹太人高兴，就又去抓彼得；那时正是除酵节期间。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 19:21; 路加福音 22:33; 路加福音 21:12"> 希律抓了彼得，把他关进监狱，交给四班士兵看守，每班四个人，打算在逾越节以后把他提到民众面前审判<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="审判——辅助词语。">b</a></sup>。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 12:26; 帖撒罗尼迦前书 5:17; 雅各书 5:16"> 这样，彼得被拘留在监狱里，教会却为他热切地向神祷告。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 21:33; 希伯来书 13:6; 腓立比书 4:6–7"> 希律要把彼得提出来审判<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="审判——辅助词语。">c</a></sup>的前一夜，彼得被两条铁链捆锁，睡在两个士兵中间，又有一些卫兵在监狱门前看守着。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 5:19; 使徒行传 16:26; 诗篇 146:7"> 忽然主的一位天使站在旁边，牢房里有光照耀。天使拍拍彼得的肋旁，叫醒他，说：“赶快起来！”那些铁链立刻就从彼得的手上掉了下来。</span>
<span className="v" id="v8" data-v="8"> 天使对他说：“束上腰带，穿上鞋子！”他就照着做了。天使又说：“披上外衣，跟着我！”</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 126:1; 希伯来书 11:8; 创世记 45:26"> 彼得就出来跟着走，却不知道天使所做的是真的，以为自己是见了异象。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 5:19; 使徒行传 16:26; 以赛亚书 45:1–2"> 他们经过第一和第二道岗，来到通往城里的铁门前，铁门就自动为他们开了。他们出去，走过一条街，天使立刻离开了他。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="但以理书 6:22; 但以理书 3:28; 彼得后书 2:9"> 这时候，彼得清醒过来，说：“现在我确实知道主派了他的天使来，救我脱离希律的手和犹太民众所期待的一切事。”</span>
<span className="v" id="v12" data-v="12" data-xref="约翰一书 5:14–15; 使徒行传 12:5; 马太福音 18:19–20"> 他明白之后，就到约翰的母亲玛丽亚家去，这约翰又叫马可。有许多人聚集在那里祷告。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 12:16; 路加福音 13:25; 约翰福音 18:16–17"> 彼得敲了外面的门，一个叫罗达的女仆前来应门。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 24:41; 马太福音 28:8"> 她一认出是彼得的声音，就高兴得顾不上打开门，跑进去告诉大家说，彼得站在门外。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="马太福音 18:10; 路加福音 24:11; 马可福音 16:14"> 他们对罗达说：“你疯了！”可是她坚持就是如此。他们不住地说：“那是他的天使。”</span>
<span className="v" id="v16" data-v="16"> 这时，彼得不停地敲门。他们就打开了门，看见是他，都十分惊讶。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行传 21:40; 使徒行传 13:16; 使徒行传 19:33"> 彼得挥一下手叫他们安静，告诉他们主怎样领他出了监狱，又说：“你们把这些事告诉雅各和弟兄们。”然后他就出发，往别的地方去了。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行传 5:22–25; 使徒行传 16:27; 使徒行传 19:23"> 到天亮，士兵们中间起了不小的骚动，不知道彼得出了什么事。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 16:27; 诗篇 37:32–33; 约翰福音 12:10–11"> 希律搜寻彼得，却没有找到，就审问卫兵们，下令把他们处决了。后来希律离开犹太，下到凯撒里亚去，住在那里。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以斯拉记 3:7; 马太福音 11:21–22; 以西结书 27:17"> 当时，希律一直恼恨提尔和西顿的人。所以他们联合起来到王那里去，先说服了王的内臣布拉斯托，然后向王求和，因为他们地区的人是从王的领地<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="领地——辅助词语。">d</a></sup>得粮食的。</span>
<span className="v" id="v21" data-v="21"> 在指定的日子，希律穿上王袍，坐在审判席上，向他们公开演说。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 14:10–13; 启示录 13:4; 犹大书 1:16"> 民众一直喊叫：“这是神的声音，不是人的声音。”</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 115:1; 使徒行传 10:25–26; 帖撒罗尼迦后书 2:4"> 主的一位天使立刻击打希律，因为他没有把荣耀归给神。他被虫咬蚀，就断了气。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 6:7; 使徒行传 19:20; 帖撒罗尼迦后书 3:1"> 于是神的话语<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="神的话语——或译作“神的道”。">e</a></sup>不断扩展<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="扩展——原文直译“生长”。">f</a></sup>，越发广传。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 12:12; 彼得前书 5:13; 使徒行传 15:37"> 巴拿巴和扫罗完成了那服事的工作<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="服事的工作——或译作“供应的事”。">g</a></sup>，就带着那称为马可的约翰，从耶路撒冷回去了<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="从耶路撒冷回去了——有古抄本作“回到耶路撒冷去了”。">h</a></sup>。</span>
</div>
</div>

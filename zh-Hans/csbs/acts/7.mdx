<span className="v" id="v6" data-v="6" data-xref="创世记 15:13; 出埃及记 12:40–41; 加拉太书 3:17"> 神这样说：<br /><span className="pl pl-1">‘他的后裔要在他人之地做寄居的，</span><br /><span className="pl pl-1">那里的人要奴役、虐待他们四百年。</span><br /></span>

</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 39:2; 诗篇 105:17; 以赛亚书 43:2"> “先祖们嫉妒约瑟，把他卖到埃及去。可是神与他同在，</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 3:4; 提摩太后书 4:18; 箴言 2:6"> 救他脱离一切患难，并且使他在埃及王法老面前蒙恩宠、有智慧。法老就委任约瑟做宰相，统管埃及和法老全家。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 41:54–57; 创世记 45:11; 创世记 42:5"> 后来整个埃及<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="埃及——有古抄本作“埃及地”。">a</a></sup>和迦南地区遭遇了饥荒和大灾难，我们的祖先找不到粮食。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 42:1–24; 创世记 43:2"> 雅各听说埃及有粮食，就派我们的祖先去，这是第一次。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 45:1–18; 创世记 46:31–10"> 第二次去的时候，约瑟的身世被他的兄弟们知道了，这样，约瑟的家族就被法老知道了。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 46:26–27; 申命记 10:22; 出埃及记 1:5"> 于是约瑟派人把他的父亲雅各和所有的亲属请来，一共七十五人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="七十五人——《创世记》46:27；《出埃及记》1:5。希伯来原文作“七十人”。">b</a></sup><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="人——原文直译“灵魂”。">c</a></sup>。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 49:33; 出埃及记 1:6; 创世记 46:3–7"> 雅各下到埃及，后来他死了，我们的祖先也死了，</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 24:32; 创世记 23:16; 出埃及记 13:19"> 遗体被带回示剑，安放到亚伯拉罕在示剑用一笔银子从哈莫尔的子孙买来的坟墓里。</span>

<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及记 1:7–12; 使徒行传 7:6; 使徒行传 13:17"> “随着神向亚伯拉罕所宣告<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="宣告——有古抄本作“起誓”。">d</a></sup>的那应许时期临近，以色列子民在埃及兴旺、增多，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 1:8"> 直到另一个不认识约瑟的王起来统治埃及。</span>

<span className="v" id="v20" data-v="20" data-xref="希伯来书 11:23; 出埃及记 2:2–10; 撒母耳记上 16:12"> 就在那时候，摩西出生了。他在神的眼里<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本没有“在神的眼里”。">e</a></sup>十分俊美，在父亲家里被抚养了三个月。</span>

<span className="v" id="v22" data-v="22" data-xref="以赛亚书 19:11; 但以理书 1:17–20; 历代志下 9:22"> 摩西在埃及人的一切智慧上受了教育，说话行事都有能力。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出埃及记 2:11–12; 箴言 21:1; 希伯来书 11:24–26"> “当他满四十岁的时候，心里决定要去探望<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="探望——或译作“照顾”。">f</a></sup>自己的同胞<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="同胞——原文直译“兄弟”。">g</a></sup>以色列子民。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 18:10–11; 使徒行传 7:28; 约翰福音 18:25–27"> 他看见一个同胞<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="同胞——原文直译“人”。">h</a></sup>受欺负，就去卫护他，为那受压迫的人报仇，打死了那个埃及人。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 15:7; 马可福音 9:32; 列王纪下 5:1"> 摩西以为自己的同胞<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="同胞——原文直译“兄弟”。">i</a></sup>会领悟神是藉着他的手拯救他们<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="拯救他们——原文直译“给他们拯救”。">j</a></sup>，但他们却不领悟。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 2:13–15; 箴言 18:19; 约翰一书 3:11–15"> 第二天，一些同胞在争斗，摩西就出来，劝他们和睦，说：‘各位！你们是同胞<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="同胞——原文直译“兄弟”。">k</a></sup>，为什么互相欺负呢？’</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行传 7:35; 路加福音 12:14; 使徒行传 7:54"> “但那欺负同伴<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="同伴——原文直译“邻人”。">l</a></sup>的人把摩西推开，说：<br />‘谁委任你做我们的首领和审判官呢？</span>
<span className="v" id="v28" data-v="28"> 难道你想杀了我，像你昨天杀了那个埃及人一样吗？’</span>

<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="出埃及记 18:2–4; 出埃及记 2:14–22; 出埃及记 4:19–20"> “摩西听了这话就逃跑了，并寄居在米甸地<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="寄居在米甸地——原文直译“成了在米甸地的一个寄居者”。">m</a></sup>，在那里生了两个儿子。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 3:1–2; 使徒行传 7:35; 以赛亚书 43:2"> 过了四十年，在西奈山的旷野，一位天使<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="天使——有古抄本作“主的天使”或“主的使者”。">n</a></sup>在荆棘火焰中向摩西显现。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 3:3–4"> 摩西见了这景象<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="景象——或译作“异象”。">o</a></sup>，感到惊奇。正当他上前要观看的时候，有主的声音说：</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 3:6; 马太福音 22:32; 约伯记 4:14"> ‘我是你祖先的神，就是亚伯拉罕、以撒、雅各的神<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="亚伯拉罕、以撒、雅各的神——有古抄本作“亚伯拉罕的神、以撒的神、雅各的神”。">p</a></sup>。’摩西战战兢兢，不敢观看。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="出埃及记 3:5; 约书亚记 5:15; 传道书 5:1"> “主对他说：<br />‘脱掉你脚上的鞋，因为你站的地方是圣地。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 3:7–10; 出埃及记 4:31; 诗篇 106:44"> 我的子民在埃及的困苦，我确实看见了；他们的呻吟，我也听见了；于是我下来要救他们。现在你来！我要差派你到埃及去。’</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="诗篇 118:22–23; 路加福音 19:14; 诗篇 113:7–8"> “这摩西就是他们拒绝说‘谁委任你做首领和审判官’的那位，神却藉着那在荆棘中向他显现的天使的手，差派他做首领、做救赎者。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 12:41; 出埃及记 14:21; 出埃及记 33:1"> 这个人带领以色列子民出来，在埃及地、在红海，并且在旷野的四十年间，行了奇事和神迹。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="申命记 18:15–19; 使徒行传 3:22–23; 约翰福音 18:37"> “这个人就是摩西，他曾告诉以色列子民：‘神<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="神——有古抄本作“主——你们的神”。">q</a></sup>将要从你们兄弟中给你们兴起一位先知，像兴起我一样。<sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="有古抄本附“你们当听从他。”">r</a></sup>’</span>
<span className="v" id="v38" data-v="38" data-xref="罗马书 3:2; 希伯来书 5:12; 彼得前书 4:11"> 这个人曾在旷野的会众当中，与那在西奈山对他讲话的天使在一起，又和我们的祖先在一起。他接受了生命的话语，把它传给了我们。</span>
<span className="v" id="v39" data-v="39" data-xref="民数记 14:3–4; 民数记 11:5; 尼希米记 9:16–17"> 我们的祖先不肯顺从，反而弃绝了他，甚至在心里转回埃及去，</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及记 32:1; 出埃及记 32:23"> 对亚伦说：<br />‘为我们造一些神明在我们前面引路吧，因为带领我们出埃及地的那个摩西，我们不知道他出了什么事！’</span>
</div>
<div className="bp poetry">
<span className="v" id="v41" data-v="41" data-xref="诗篇 106:19–21; 尼希米记 9:18; 启示录 9:20"> 在那些日子里，他们造了一个牛犊的像，又向那偶像献上祭物，并且为自己手所做的而庆祝。</span>
<span className="v" id="v42" data-v="42" data-xref="阿摩司书 5:25–26; 以西结书 20:39; 耶利米书 19:13"> 神就转身不顾，任凭他们去事奉天上的万象，正如先知书上所记载的：<br /><span className="pl pl-1">‘以色列家呀！</span><br /><span className="pl pl-1">你们在旷野的四十年里献上的牺牲和祭物，</span><br /><span className="pl pl-1">难道是给我的吗？</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="阿摩司书 5:26–27; 出埃及记 20:4–5; 申命记 5:8–9"> <span className="pl pl-1">你们抬起了摩洛的帐幕和你们理番神的星，</span><br /><span className="pl pl-1">就是你们为敬拜而造的像。</span><br /><span className="pl pl-1">因此，我要把你们迁移到巴比伦以外去。’</span></span>

<span className="v" id="v44" data-v="44" data-xref="出埃及记 25:40; 出埃及记 38:21; 希伯来书 8:5"> “我们的祖先在旷野有见证的会幕，是照着对摩西说话的那一位所吩咐的，并按照摩西看到的样式所做成的。</span>
<span className="v" id="v45" data-v="45" data-xref="诗篇 44:2; 约书亚记 18:1; 约书亚记 23:9"> 我们的祖先相继承受了这会幕，并且与约书亚一起把它带进了继业之地，就是神从我们祖先面前赶出的外邦人的地，直到大卫的时代。</span>
<span className="v" id="v46" data-v="46" data-xref="诗篇 132:1–5; 使徒行传 13:22; 撒母耳记下 7:1–5"> 大卫在神面前蒙了恩典，就祈求为雅各的神<sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="雅各的神——有古抄本作“雅各的家”。">s</a></sup>预备<sup className="fn"><a href="#fn-t" id="fnref-t" data-fn="预备——原文直译“寻找”。">t</a></sup>一个居所<sup className="fn"><a href="#fn-u" id="fnref-u" data-fn="居所——原文直译“帐幕”或“会幕”。">u</a></sup>。</span>

<span className="v" id="v48" data-v="48" data-xref="使徒行传 17:24–25; 以赛亚书 66:1–2; 列王纪上 8:27"> 其实至高者并不住在人手所造的殿宇<sup className="fn"><a href="#fn-w" id="fnref-w" data-fn="有古抄本没有“殿宇”。">w</a></sup>里，正如先知所说：</span>
<span className="v" id="v49" data-v="49" data-xref="以赛亚书 66:1; 诗篇 11:4; 约翰福音 4:21"> <span className="pl pl-1">‘主说：“天是我的宝座，</span><br /><span className="pl pl-1">地是我的脚凳。</span><br /><span className="pl pl-1">你们要为我建造什么样的殿宇</span><sup className="fn"><a href="#fn-x" id="fnref-x" data-fn="殿宇——原文直译“家”。">x</a></sup><br /><span className="pl pl-1">呢？</span><br /><span className="pl pl-1">我安息的地方在哪里呢？</span><br /></span>

<span className="v" id="v51" data-v="51" data-xref="申命记 10:16; 以弗所书 4:30; 以赛亚书 63:10"> “你们这些顽固不化、心和耳都未受割礼的人哪，你们总是抗拒圣灵！你们的祖先怎样，你们也怎样。</span>

<span className="v" id="v53" data-v="53" data-xref="希伯来书 2:2; 加拉太书 3:19; 使徒行传 7:38"> 你们领受了藉天使所设立的律法，却不遵守。”</span>
</div>

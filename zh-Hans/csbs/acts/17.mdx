<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="ACT" data-book-slug="acts" data-book-name="使徒行传" data-chapter="17" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 1:1; 腓立比书 4:16; 使徒行传 20:4"> 保罗和西拉斯经过安菲波利斯和阿波罗尼亚，来到帖撒罗尼迦。那里有一个犹太人的会堂。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 9:20; 使徒行传 17:17; 使徒行传 18:4"> 保罗照习惯进了会堂<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="会堂——原文直译“他们那里”。">a</a></sup>，一连三个安息日，引用经文向他们讲论，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 18:28; 使徒行传 9:22; 路加福音 24:32"> 讲解并说明基督必须受难，然后从死人中复活，并且说：“我传给你们的这位耶稣，就是基督。”</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 17:12; 使徒行传 13:43; 使徒行传 14:4"> 他们当中有些人被说服了，就跟从了保罗和西拉斯；不但有一大群敬神的希腊人，还有不少显要的妇女。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="加拉太书 5:26; 使徒行传 17:13; 罗马书 16:21"> 但那些不肯信从的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本没有“不肯信从的”。">b</a></sup>犹太人嫉妒了，就招聚一些市井无赖，成群结伙，扰乱城市。他们闯进耶森的家，搜寻保罗和西拉斯，要把他们带到民众那里。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 24:5; 使徒行传 16:19–21; 使徒行传 28:22"> 可是找不到他们，就把耶森和几位弟兄拉到地方官们那里，喊叫说：“这些搅乱天下的，也来到这里，</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 23:2; 使徒行传 16:21; 约翰福音 19:12"> 耶森竟接待了他们！这些人都违背了凯撒的谕令，说另外有一个王，就是耶稣。”</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 2:3; 约翰福音 11:48"> 民众和地方官们听了这些话就惊慌不安，</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 17:5"> 后来，拿了耶森和其他人的保释金，就把他们释放了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 17:2; 帖撒罗尼迦前书 2:2; 使徒行传 17:13–14"> 弟兄们立刻连夜送保罗和西拉斯往庇里亚城去。两个人一到，就进了犹太人的会堂。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 34:16; 箴言 2:1–5; 约翰福音 5:39"> 这里的人比帖撒罗尼迦的人开明。他们满心乐意地接受这福音<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="福音——原文直译“话语”或“道”。">c</a></sup>，天天查考经文，要看这些事是否如此。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 5:14; 使徒行传 14:1; 使徒行传 13:50"> 这样，他们当中有许多人相信了，包括尊贵的希腊妇女，以及不少男人。</span>
<span className="v" id="v13" data-v="13" data-xref="帖撒罗尼迦前书 2:14–16; 箴言 28:25; 使徒行传 6:12"> 可是当帖撒罗尼迦的犹太人知道保罗又在庇里亚城传扬神的话语<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="神的话语——或译作“神的道”。">d</a></sup>时，就来到那里煽动、搅扰<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本没有“搅扰”。">e</a></sup>民众。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 17:10; 马太福音 10:23; 使徒行传 9:25"> 于是弟兄们立刻送保罗往海<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="海——指“爱琴海”。">f</a></sup>边去，西拉斯和提摩太仍然留在庇里亚。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 18:5; 帖撒罗尼迦前书 3:1; 使徒行传 18:1"> 护送保罗的人一直带他到了雅典，然后领受了要西拉斯和提摩太尽快到他这里来的指示，就回去了。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="诗篇 119:158; 彼得后书 2:7; 诗篇 119:136"> 保罗在雅典等候西拉斯和提摩太的时候，看见满城都是偶像，他灵里被激怒。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 13:16; 使徒行传 14:1–4; 使徒行传 17:2–4"> 于是他在会堂里向犹太人以及那些敬神的人讲论，每天又向在街市上遇见的人讲论。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 1:20–21; 歌罗西书 2:8; 路加福音 11:53"> 有些伊壁鸠鲁派和斯多亚派的哲学家们也与他辩论。<br />有的说：“这胡言乱语的人，究竟想说什么呢？”也有的说：“他看起来是个宣传外国鬼神的人。”这是因为保罗传讲耶稣和复活的福音。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马可福音 1:27; 使徒行传 17:22; 使徒行传 24:24"> 他们就拉住保罗，带他到亚略巴古，问他：“你所讲论的这新教导，我们可以知道吗？</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 1:23; 何西阿书 8:12; 哥林多前书 2:14"> 既然你带来了一些奇怪的事，传到我们耳中，那么我们想知道这些事到底是什么意思。”</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 2:16–17; 歌罗西书 4:5; 以弗所书 5:16"> 原来，所有的雅典人以及在那里作客的外国人，不做别的，只花时间说说听听某个较为新奇的事。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 25:19; 使徒行传 19:35; 使徒行传 17:16"> 于是保罗站在亚略巴古当中说：“各位雅典人哪，我看你们在各方面都非常敬畏鬼神，</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 4:22; 加拉太书 4:8–9; 约翰福音 17:3"> 因为我边走边观察你们所敬拜的，发现一座祭坛上刻着‘献给不认识的神’；那么，我把你们所不认识而敬拜的这一位，现在传讲给你们。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 8:27; 申命记 10:14; 使徒行传 7:48"> 造了宇宙和其中万有的神，这一位既然是天地的主，就不住在人手所造的殿宇里，</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 50:8–13; 创世记 2:7; 以赛亚书 42:5"> 也不受人手的服事，好像缺少什么似的，因为他自己把生命、气息和万有赐给万人。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 32:7–8; 创世记 3:20; 罗马书 5:12–19"> 他从一个人<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="一个人——有古抄本作“一支血脉”。">g</a></sup>造出人类万族，使他们住在整个地面上，预先设定了他们的年限和所住的疆界，</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 23:23–24; 申命记 4:7; 使徒行传 14:17"> 好让他们寻求神<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="神——有古抄本作“主”。">h</a></sup>，或许因此真能摸索而找到他。其实他离我们每一个人并不远，</span>
<span className="v" id="v28" data-v="28" data-xref="约伯记 12:10; 歌罗西书 1:17; 希伯来书 1:3"> 因为我们活着、行动、生存，都在于他，正如你们中间的一些诗人也曾经说过，‘原来我们也是他的后裔。’</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 40:25; 出埃及记 20:4; 诗篇 115:4–8"> 所以我们既然是神的后裔，就不应该认为神性是仿佛用人的手艺和心思所雕刻的金、银、石像。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行传 14:16; 提多书 2:11–12; 路加福音 24:47"> “虽然神并不鉴察那愚昧无知的时代，但如今却吩咐各处所有的人都要悔改，</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 25:31–46; 彼得后书 3:7; 罗马书 2:16"> 因为他已经确立了日子，将要藉着他所设定的一个人，以公义来审判天下的人，并且藉着使他从死人中复活，给万人带来了确据。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行传 17:18; 使徒行传 26:8; 使徒行传 25:19"> 他们听到死人复活的事，虽然有些人嘲笑他，但有些人却说：“关于此事，我们还要再听你说！”</span>
<span className="v" id="v33" data-v="33"> 这样，保罗就从他们中间出去了。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 17:19; 罗马书 11:5–6; 使徒行传 13:48"> 有一些人就跟从了保罗，信了主<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="主——辅助词语。">i</a></sup>。其中包括亚略巴古的议员迪奥尼修、一个名叫达玛丽斯的妇人，以及其他与他们在一起的人。</span>
</div>
</div>

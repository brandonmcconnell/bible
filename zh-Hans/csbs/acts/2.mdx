<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 15:6; 腓立比书 2:2; 使徒行传 1:13–15"> 到了五旬节那天，他们都聚集<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="聚集——有古抄本作“同心合意地”。">a</a></sup>在一起<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="聚集在一起——原文直译“同在一个地方”。">b</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 4:31; 列王纪上 19:11; 诗篇 18:10"> 突然，有响声从天上下来，好像狂风吹过，充满了他们所坐的整个房子，</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 3:11; 约翰福音 1:32–33; 耶利米书 23:29"> 有舌头像火焰那样，向他们显现，分开留<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="留——原文直译“坐落”。">c</a></sup>在他们每一个人身上。</span>
<span className="v" id="v4" data-v="4" data-xref="马可福音 16:17; 使徒行传 13:52; 使徒行传 4:31"> 于是他们都被圣灵充满，就照着圣灵赐给他们的话，开始说出别种语言<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="语言——原文直译“舌头”；传统译法作“方言”；或译作“殊言”。">d</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="路加福音 2:25; 使徒行传 8:2; 歌罗西书 1:23"> 当时，有从天下各国来的虔诚的犹太人，住在耶路撒冷。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 2:3; 哥林多前书 16:9; 使徒行传 2:2"> 这声音一响，有一群人就聚集而来，非常慌乱，因为各个人都听见使徒们<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="使徒们——原文直译“他们”。">e</a></sup>用各个人本地的语言说话。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 2:12; 使徒行传 1:11; 约翰福音 7:52"> 他们又惊讶又诧异，说<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="说——有古抄本作“彼此说”。">f</a></sup>：“看，这些说话的不都是加利利人吗？</span>
<span className="v" id="v8" data-v="8"> 我们怎么会听到我们各自出生地的语言呢？</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 1:1; 使徒行传 18:2; 启示录 1:4"> 我们当中有帕提亚人、米底亚人、埃拦人；也有住在美索不达米亚、犹太和卡帕多细亚、本都和亚细亚、</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 16:6; 撒迦利亚书 8:23; 撒迦利亚书 8:20"> 弗里吉亚和潘菲利亚、埃及和靠近古利奈的利比亚地区的人；还有从罗马来的旅客，</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 12:10; 出埃及记 15:11; 诗篇 78:4"> 包括犹太人和入犹太教的人；克里特人和阿拉伯人。我们都听见他们用我们的语言述说神伟大的作为！”</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 15:26; 使徒行传 17:20; 路加福音 18:36"> 众人又惊讶又困惑，彼此问：“这是什么意思呢？”</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 14:23; 使徒行传 2:15; 撒母耳记上 1:14"> 可是另有些人嘲笑说：“他们被新酒灌醉了！”</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 51:7; 以赛亚书 51:1; 申命记 27:9"> 这时，彼得和其他十一个使徒一同站起来，高声对众人说：“各位犹太人和所有住在耶路撒冷的人哪，你们应当知道这件事，也应当仔细听我的话，</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 5:5–8; 撒母耳记上 1:15; 马太福音 20:3"> 因为这些人不是像你们所想的那样喝醉了，要知道，现在不过是早上九点<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="九点——原文为“第三时刻”。">g</a></sup>。</span>
<span className="v" id="v16" data-v="16" data-xref="约珥书 2:28–32"> 其实这是先知约珥所说的：</span>
<span className="v" id="v17" data-v="17" data-xref="约珥书 2:28–32; 以赛亚书 44:3; 提多书 3:4–6"> <span className="pl pl-1">‘神说，在末后的那些日子里将是这样：</span><br /><span className="pl pl-1">我要把我的灵倾注在所有人身</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="人身——原文直译“肉体”。">h</a></sup><br /><span className="pl pl-1">上，</span><br /><span className="pl pl-1">你们的儿女要说预言</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="说预言——或译作“做先知传道”。">i</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">你们的年轻人要见异象，</span><br /><span className="pl pl-1">你们的老年人要做异梦。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="加拉太书 3:28; 歌罗西书 3:11; 哥林多前书 7:21–22"> <span className="pl pl-1">是的，在那些日子里，</span><br /><span className="pl pl-1">我也要将我的灵倾注</span><br /><span className="pl pl-1">在我的奴仆和婢女们身上，</span><br /><span className="pl pl-1">他们就要说预言。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="约珥书 2:30–31; 西番雅书 1:14–18; 玛拉基书 4:1–6"> <span className="pl pl-1">在天上我要显奇事；</span><br /><span className="pl pl-1">在地上我要行神迹——</span><br /><span className="pl pl-1">有血、有火、有烟雾。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="彼得后书 3:10; 阿摩司书 8:9; 马太福音 24:29"> <span className="pl pl-1">在主那大而显赫的日子来到之前，</span><br /><span className="pl pl-1">太阳要变为黑暗，</span><br /><span className="pl pl-1">月亮要变为血。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 10:12–13; 约珥书 2:32; 诗篇 86:5"> <span className="pl pl-1">那时候，无论谁求告主名，都将得救。’</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="约翰福音 3:2; 约翰福音 14:10–11; 马太福音 12:28"> “各位以色列人哪，请听这些话：拿撒勒人耶稣是神向你们所证实的人；神藉着他在你们中间行了大能、神迹和奇事，正如你们自己所知道的。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 22:22; 使徒行传 4:28; 使徒行传 3:18"> 这一位照着神设定的计划和先见被交出去；你们就藉着外邦人的手<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附“带走”。">j</a></sup>，把他钉上十字架杀了。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 6:14; 彼得前书 1:21; 使徒行传 2:32"> 神却解除了死亡的痛苦，使他复活，因为他本来就不能被死亡辖制。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 16:8–11; 以赛亚书 41:13; 诗篇 62:6"> 事实上，大卫指着他说：<br /><span className="pl pl-1">‘我常常看见主在我面前；</span><br /><span className="pl pl-1">因他在我的右边，</span><br /><span className="pl pl-1">我就不至于摇动。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 16:9; 诗篇 63:5; 诗篇 71:23"> <span className="pl pl-1">为此我内心欢喜，</span><br /><span className="pl pl-1">口舌快乐，</span><br /><span className="pl pl-1">并且我的肉身也要安居在盼望中。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 16:10; 使徒行传 2:31; 启示录 1:18"> <span className="pl pl-1">因为你不会把我的灵魂撇弃在阴间，</span><br /><span className="pl pl-1">也不会让你的圣者经历腐朽。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 16:11; 诗篇 25:4; 诗篇 21:6"> <span className="pl pl-1">你让我明白了生命之道</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="道——或译作“路”。">k</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">使我在你面前充满喜乐。’</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="使徒行传 13:36; 列王纪上 2:10; 使徒行传 7:8–9"> “各位兄弟，关于先祖大卫，我可以明确地告诉你们：他不但死了，也被埋葬了，而且他的坟墓到今天还在我们这里。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 132:11–18; 诗篇 89:3–4; 耶利米书 33:14–15"> 既然大卫是先知，也知道神曾向他起誓说，要从他的后裔中兴起一位<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="要从他的后裔中兴起一位——有古抄本作“要按肉身从他的后裔中兴起基督”。">l</a></sup>坐在他的宝座上，</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 2:27; 诗篇 16:10; 使徒行传 13:35"> 大卫又预先看见了，就讲论基督复活的事，说：<br /><span className="pl pl-1">‘他</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="他——有古抄本作“他的灵魂”。">m</a></sup><br /><span className="pl pl-1">既没有被撇弃在阴间，</span><br /><span className="pl pl-1">他的肉身也没有经历腐朽。’</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="使徒行传 3:15; 使徒行传 1:8; 使徒行传 1:22"> “这位耶稣，神已经使他复活了。我们都是这事的见证人。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 1:4; 使徒行传 5:31; 使徒行传 2:17"> 他被高举在神的右边，从父领受了所应许的圣灵，就将圣灵倾注了下来。这正是你们现在所看见所听见的。</span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 110:1; 马太福音 22:42–45; 希伯来书 1:13"> 大卫并没有升到诸天之上去，可是他说，<br /><span className="pl pl-1">‘主对我主说：</span><br /><span className="pl pl-1">你坐在我的右边，</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="启示录 19:19–3; 罗马书 16:20; 以赛亚书 60:14"> <span className="pl pl-1">等我把你的敌人放在你的脚下做脚凳。’</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行传 5:30–31; 罗马书 14:8–12; 哥林多后书 5:10"> “因此，以色列全家都当确实知道：被你们钉上十字架的这位耶稣，神已经委任他为主、为基督了。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 3:10; 使徒行传 22:10; 希伯来书 4:12–13"> 众人听了这话，觉得扎心，就对彼得和其他的使徒说：“各位兄弟，我们该做什么呢？”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="使徒行传 22:16; 马可福音 16:16; 使徒行传 8:12"> 彼得对他们说：“你们应当悔改，每个人都当奉耶稣基督的名受洗<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="受洗——或译作“受浸”。">n</a></sup>，使你们的罪得赦免，就会领受所赐的圣灵。</span>
<span className="v" id="v39" data-v="39" data-xref="以赛亚书 44:3; 创世记 17:7–8; 罗马书 8:30"> 因为这应许是给你们和你们的儿女，以及所有在远处的人，就是主我们的神所召来的人。”</span>
<span className="v" id="v40" data-v="40" data-xref="腓立比书 2:15; 申命记 32:5; 马太福音 17:17"> 彼得还说许多别的话郑重地做见证，又劝告他们说：“你们从这扭曲的<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="扭曲的——或译作“弯曲的”或“不正直的”。">o</a></sup>世代中得救吧！”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="使徒行传 4:4; 使徒行传 2:47; 使徒行传 16:31–34"> 于是<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="有古抄本附“高兴地”。">p</a></sup>领受他话的人就受了洗；那一天大约增加了三千人<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="人——原文直译“灵魂”。">q</a></sup>。</span>
<span className="v" id="v42" data-v="42" data-xref="希伯来书 10:25; 使徒行传 1:14; 约翰一书 1:3"> 他们在使徒们的教导上，在契合<sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="契合——或译作“沟通”或“分享”。">r</a></sup>、掰饼、祷告之事上恒切专心。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="路加福音 7:16; 约翰福音 14:12; 路加福音 8:37"> 每个人<sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="人——原文直译“灵魂”。">s</a></sup>都起了敬畏之心。使徒们又行了很多奇事和神迹<sup className="fn"><a href="#fn-t" id="fnref-t" data-fn="使徒们又行了很多奇事和神迹——原文直译“有很多奇事和神迹藉着使徒们发生了”。">t</a></sup>。</span>
<span className="v" id="v44" data-v="44" data-xref="使徒行传 4:32; 约翰一书 3:16–18; 哥林多后书 8:14–15"> 所有信了的人都在一起，凡物共有，</span>
<span className="v" id="v45" data-v="45" data-xref="约翰一书 3:17; 提摩太前书 6:18–19; 雅各书 2:14–16"> 他们变卖财产和产业，按照各人的需要分给大家。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒行传 5:42; 使徒行传 20:7; 使徒行传 2:42"> 他们同心合意，不但天天恒切地在圣殿聚集<sup className="fn"><a href="#fn-u" id="fnref-u" data-fn="聚集——辅助词语。">u</a></sup>，还在各家各户掰饼。他们怀着喜乐和诚恳的心用饭，</span>
<span className="v" id="v47" data-v="47" data-xref="使徒行传 16:5; 使徒行传 5:13–14; 使徒行传 2:41"> 赞美神，并且得到全体民众的喜爱。主就在那里<sup className="fn"><a href="#fn-v" id="fnref-v" data-fn="有古抄本没有“在那里”。">v</a></sup>使得救的人与日俱增<sup className="fn"><a href="#fn-w" id="fnref-w" data-fn="有古抄本附“给教会”。">w</a></sup>。</span>
</div>

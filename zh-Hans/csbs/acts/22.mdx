<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 7:2; 使徒行传 28:17; 使徒行传 13:26"> “各位父老兄弟，现在请听我的申辩。”</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 21:40"> 众人听见他用希伯来语向他们呼吁，就更加安静了。保罗说：</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 26:5; 腓立比书 3:5–6; 使徒行传 9:11"> “我是犹太人，出生在奇里乞亚省的塔尔苏，在这城里长大；在迦玛列门下，按照我们先祖的律法受了严格的教育；我对神是热心的人，就像今天你们大家一样。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 22:19–20; 提摩太前书 1:13–15; 使徒行传 26:9–11"> 我曾经逼迫这道的信徒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="的信徒——辅助词语。">a</a></sup>置于死地，无论男女都捆绑起来，关进监狱。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 9:1–2; 路加福音 22:66; 使徒行传 5:21"> 这是大祭司和全长老议会的人都可以为我做见证的。我还从他们那里拿到了给同胞们<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="同胞们——原文直译“兄弟们”。">b</a></sup>的一些信函往大马士革去，要把那里被捆绑的信徒们<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="信徒们——原文直译“人们”。">c</a></sup>，带到耶路撒冷来受刑。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 9:3–8; 使徒行传 26:12–18; 启示录 1:16"> “当我赶路快到大马士革的时候，大约中午，忽然有强烈的光从天上下来，在我周围四面照射。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 2:9; 马太福音 25:45; 创世记 22:11"> 我就仆倒在地上，听见有声音对我说：<span className="woj">‘扫罗，扫罗！你为什么逼迫我？’</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 26:9; 撒母耳记上 8:7; 出埃及记 16:7–8"> “我回答：‘主啊！你到底是谁？’<br />“他说：<span className="woj">‘我就是你所逼迫的拿撒勒人耶稣。’</span></span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 9:7; 但以理书 10:7; 使徒行传 26:13"> 与我在一起的人虽然看到了那光，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附“感到害怕，”。">d</a></sup>却听不懂那对我说话的声音。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 16:30; 使徒行传 22:12–16; 使徒行传 2:37"> “我说：‘主啊！我该做什么呢？’<br />“主对我说：<span className="woj">‘起来，进大马士革城去，在那里你将被告知所指定你做的一切事。’</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 9:8–9; 使徒行传 13:11; 以赛亚书 42:16"> “我因那光的荣耀，什么都看不见了，就被同行的人牵着手，进了大马士革。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 10:22; 使徒行传 6:3; 约翰三书 1:12"> 有一个名叫阿纳尼亚的人，按照律法，是一个虔诚的人，受到所有住在那里的犹太人赞许。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 9:17–18; 腓利门书 1:16"> 他来到我那里，站在旁边对我说：‘扫罗弟兄，你重见光明吧！’就在那一刻，我抬头看见他了。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 1:12; 哥林多前书 15:8; 哥林多前书 9:1"> 他又说：‘我们祖先的神预先指定了你，使你明白他的旨意，看见那位义者，听见他口中传来的声音，</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 23:11; 使徒行传 4:20; 约翰福音 15:27"> 因为你将要做他的见证人，向所有的人见证你所看到的、你所听到的。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 2:38; 使徒行传 2:21; 提多书 3:5"> 现在你还等什么呢？起来，当受洗<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="受洗——或译作“受浸”。">e</a></sup>！求告他<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="他——有古抄本作“主”。">f</a></sup>的名，当洗去你的罪孽！’</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 12:1–4; 使徒行传 10:9–10; 使徒行传 9:26–28"> “后来，我回到耶路撒冷，在圣殿里祷告的时候，魂游象外，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 9:29; 路加福音 21:21; 以西结书 3:6–7"> 看见主对我说：<span className="woj">‘快！赶快离开耶路撒冷，因为他们不会接受你为我做的见证。’</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 22:4; 马太福音 10:17; 使徒行传 8:3"> “我就说：‘主啊，他们知道我曾经到各会堂，把信靠你的人关进监狱，还鞭打他们。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 7:58; 使徒行传 8:1; 罗马书 1:32"> 并且当你的见证人司提反受害<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="受害——辅助词语。">g</a></sup>流血的时候，我自己也站在旁边赞同<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附“对他的处决”。">h</a></sup>，还为那些杀害他的人看守衣服。’</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 9:15; 提摩太前书 2:7; 以弗所书 3:6–8"> “主对我说：<span className="woj">‘去吧！我要派你到遥远的外邦人那里去。’</span>”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 25:24; 使徒行传 21:36; 约翰福音 19:15"> 众人听保罗讲到这句话，就高声说：“这样的人，把他从地上除掉，因为他不该活着！”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 16:13; 使徒行传 26:11; 传道书 10:3"> 他们喊叫，抛着衣服，向空中扬起尘土。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 21:31–32; 使徒行传 21:34; 约翰福音 19:1"> 千夫长下令把保罗押进营楼，吩咐鞭打拷问他，要了解民众是因什么理由向他这样一直喊叫。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 16:37; 使徒行传 25:16; 使徒行传 27:43"> 当士兵们用皮条捆上保罗的时候，他对站在旁边的百夫长说：“你们鞭打一个没有被定罪的罗马公民，可以吗？”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 23:27; 使徒行传 22:29"> 百夫长听了，就来到千夫长面前，报告说：“你要做什么呢？<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="你要做什么呢？——有古抄本作“要注意你所做的事。”">i</a></sup>要知道，这个人是罗马公民。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 千夫长就前来问保罗：“告诉我，你是罗马公民吗？”<br />保罗说：“是的。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 千夫长说：“我花了一大笔钱，才买到了罗马公民权。”<br />保罗说：“我生下来就是。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行传 21:33; 使徒行传 22:24–26; 使徒行传 16:38–39"> 于是那些要拷问他的人，立刻退下了。千夫长既知道他是罗马公民，又因为捆绑了他，就惧怕起来。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行传 23:28; 使徒行传 21:33; 使徒行传 21:11"> 第二天，千夫长想确切知道保罗为什么被犹太人控告，就<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附“从捆锁中”。">j</a></sup>解开他，下令召集祭司长们和全议会的人<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="下令召集祭司长们和全议会的人——有古抄本作“下令要祭司长们和他们全议会的人来”。">k</a></sup>，然后把保罗带来，叫他站在他们面前。</span>
</div>
</div>

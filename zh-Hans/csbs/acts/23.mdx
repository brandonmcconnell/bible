<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="ACT" data-book-slug="acts" data-book-name="使徒行传" data-chapter="23" data-verses="35">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 24:16; 提摩太后书 1:3; 哥林多后书 1:12"> 保罗注视着议会的人，说：“各位兄弟，直到今天，我在神面前，行事为人一向都凭着无愧的良心。”</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 18:22; 使徒行传 24:1; 弥迦书 5:1"> 大祭司阿纳尼亚就命令站在保罗旁边的人，打他的嘴巴。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 25:1–2; 约翰福音 7:51; 马太福音 23:27–28"> 保罗就对他说：“你这粉饰的墙啊，神将要打你！你坐在那里应按照律法审判我，而你却违背律法，下令打我吗？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 站在旁边的人说：“你竟敢辱骂神的大祭司？”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及记 22:28; 传道书 10:20; 犹大书 1:8–9"> 保罗就说：“同胞们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="同胞们——原文直译“兄弟们”。">a</a></sup>，我不知道他是大祭司。的确，经上记着：不可说你民中掌权者的坏话。”</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 24:15; 使徒行传 24:21; 使徒行传 26:5–8"> 保罗知道有一部分人是撒都该人，另一部分是法利赛人，就在议会中喊着：“各位兄弟，我是法利赛人，也是法利赛人的儿子。我现在受审，是与死人复活的盼望有关。”</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 55:9; 约翰福音 7:40–43; 马太福音 10:34"> 他说了这话，法利赛人和撒都该人就起了争执，会众也分裂了。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 20:27; 马太福音 22:23; 马可福音 12:18"> 原来撒都该人说没有复活，没有天使，也没有灵，但法利赛人却承认这一切<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这一切——或译作“这两样”。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 22:7; 使徒行传 22:17–18; 约翰福音 12:29"> 于是他们大大地喧嚷起来。有些法利赛派的经文士们站起来激烈地争辩，说：“我们查不出这个人有什么错<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="错——原文直译“恶”。">c</a></sup>。也许有灵或天使对他说过话呢！<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附“我们不要对抗神。”">d</a></sup>”</span>
<span className="v" id="v10" data-v="10" data-xref="雅各书 1:19; 雅各书 3:14–2; 使徒行传 22:24"> 争执越来越激烈，千夫长担心保罗会被他们撕碎，就命令军队下去，把保罗从他们当中抢出来，带回营楼里。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 18:9; 使徒行传 19:21; 提摩太后书 4:17"> 当夜，主站在保罗旁边，说：<span className="woj">“</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附“保罗，”。">e</a></sup><span className="woj">你要鼓起勇气！你怎样在耶路撒冷郑重地见证有关我的事，也必须照样在罗马做见证。”</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 23:30; 以赛亚书 8:9–10; 使徒行传 23:21"> 天亮了，犹太人就策划了一起阴谋，并且赌咒起誓说，杀掉保罗以前，就不吃不喝。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 16:2; 撒母耳记下 15:31; 撒母耳记下 15:12"> 策划这同谋起誓的有四十多人。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 23:12; 耶利米书 8:12; 以赛亚书 3:9"> 他们来到祭司长们和长老们那里，说：“我们已经赌咒起誓，杀掉保罗以前，就什么都不吃。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 59:7; 诗篇 37:32–33; 箴言 1:16"> 所以你们和议会现在就要告诉千夫长，<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附“明天”。">f</a></sup>把保罗带到你们这里来，假装要更详尽地审查他的事；我们预备好了，要在他到达以前就杀了他。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行传 23:10; 哥林多前书 3:19; 使徒行传 23:32"> 保罗的外甥听见了这埋伏的事，就过来进了营楼告诉保罗。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 22:3; 马太福音 8:8–9; 马太福音 10:16"> 保罗请来了一个百夫长，说：“请带这年轻人到千夫长那里，因为他有事要向他报告。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以弗所书 3:1; 以弗所书 4:1; 使徒行传 28:17"> 于是百夫长就带保罗的外甥到千夫长那里去，说：“囚犯保罗请了我去，求我把这个年轻人带到你这里来，他有事要告诉你。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="耶利米书 31:32; 以斯帖记 9:12; 以斯帖记 7:2"> 千夫长拉着年轻人的手，退到一边，悄悄地问他：“你有什么事要告诉我？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="使徒行传 23:14–15; 使徒行传 23:1; 诗篇 12:2"> 他说：“犹太人已经说好，要请求你明天把保罗带到议会去，假装要更详尽地查问他的事。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 23:12–14; 使徒行传 14:5–6; 哥林多后书 11:26"> 所以请你不要被他们说服，因为他们中的四十多人正埋伏等着他。他们已经赌咒起誓说，杀掉保罗以前，就不吃不喝。现在他们预备好了，正期望你答应。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马可福音 1:44; 约书亚记 2:14"> 千夫长吩咐那年轻人说：“不要对任何人说，你把这些事告诉了我。”于是，就让他走了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 14:25; 使徒行传 23:33; 路加福音 12:38"> 然后千夫长叫来两个百夫长，说：“预备两百名步兵、七十名骑兵、两百名长枪手，晚上九点<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="九点——原文为“第三时刻”。">g</a></sup>出发往凯撒里亚去。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 25:14; 使徒行传 23:26; 使徒行传 24:10"> 也要预备牲口，让保罗骑上，护送到总督菲利克斯那里去。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 他写了一封信函，有这样的内容：</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 15:23; 使徒行传 26:25; 路加福音 1:3"> “克劳迪吕西亚问候总督菲利克斯大人。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行传 22:25–29; 使徒行传 21:31–33; 使徒行传 24:6"> 这个人被犹太人抓住，正要被他们杀害的时候，我带军队到场，得知他是罗马公民，就把他救了出来。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 22:30"> 我想了解犹太人控告他的理由，就带他到他们的议会去。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 26:31; 使徒行传 25:25; 使徒行传 18:15"> 我发现他被控告，与他们律法上的争议问题有关，并没有任何该死或该被捆锁的罪行。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 23:35; 使徒行传 25:16; 使徒行传 25:5–6"> 后来我被告知<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附“藉着犹太人”。">h</a></sup>将有一个针对这个人的阴谋，就立即把他解送到您那里去，又吩咐原告们到您面前去告他。<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附“祝您安康！”">i</a></sup>”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="提摩太后书 2:3–4; 路加福音 7:8; 使徒行传 23:23–24"> 于是士兵们按照命令，把保罗接走，连夜送到安提帕底。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 23:23; 使徒行传 23:10"> 第二天，他们让骑兵带着保罗前行，就回到营楼。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 23:26; 使徒行传 23:23–24; 使徒行传 28:16"> 骑兵进了凯撒里亚，把信函呈给总督，又把保罗带到他面前。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 21:39; 使徒行传 25:1; 但以理书 2:49"> 总督<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本没有“总督”。">j</a></sup>读了信，问保罗是哪一个省的人，知道他是奇里乞亚省的人，</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 23:30; 使徒行传 25:16; 马太福音 27:27"> 就说：“等你的原告们也到了，我会详细地听你的事。”他下令把保罗看守在希律的王府里。</span>
</div>
</div>

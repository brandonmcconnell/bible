<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 1:3; 路加福音 24:19; 马太福音 4:23–24"> 提阿费罗大人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="大人——辅助词语。">a</a></sup>哪，在前一卷书<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="前一卷书——指“《路加福音》”。">b</a></sup>中，我确实写了有关耶稣开始做的和教导的一切事，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 1:9; 约翰福音 20:21; 以赛亚书 59:20–21"> 一直到他藉着圣灵吩咐了他所拣选的使徒们之后，被接升天的那一天为止。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 15:5–7; 使徒行传 13:31; 约翰福音 20:26"> 耶稣受难之后，用很多确据向这些人显明自己是活着的。他在四十天的时间里向他们显现，并且讲说有关神国的事。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="路加福音 24:49; 约翰福音 14:16; 约翰福音 15:26"> 耶稣和他们聚集的时候，吩咐他们说：<span className="woj">“不要离开耶路撒冷，而要等候父所应许的，就是你们从我听到的，</span></span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 3:11; 使徒行传 11:15–16; 路加福音 3:16"> <span className="woj">因为约翰是用水</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="用水——或译作“在水里”。">c</a></sup><span className="woj">施洗</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="施洗——或译作“施浸”。">d</a></sup><span className="woj">，但过不了多少日子，你们就要受圣灵的洗。”</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="路加福音 19:11; 路加福音 17:20; 但以理书 7:27"> 于是聚集的时候，他们就问耶稣说：“主啊！你复兴以色列国，是否在这时候呢？”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 24:36; 帖撒罗尼迦前书 5:1–2; 马可福音 13:32"> 耶稣对他们说：<span className="woj">“父凭着自己的权柄所定的时候和日期，不是你们可以知道的。</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 28:19; 马可福音 16:15; 罗马书 15:19"> <span className="woj">不过圣灵临到你们的时候，你们将得着能力，并且要在耶路撒冷，在犹太和撒玛利亚全地，直到地极，做我的见证人。”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="但以理书 7:13; 路加福音 24:50–51; 马可福音 16:19"> 说了这些话，耶稣就在他们的注视中被接升天，有一朵云彩把他接去，他们就看不见他了。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 24:4; 约翰福音 20:12; 启示录 7:14"> 正当耶稣离去，他们注目望天的时候，忽然有两个身穿白衣的人站在他们旁边，</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 1:7; 帖撒罗尼迦前书 4:16; 马可福音 13:26"> 说：“各位加利利人哪，你们为什么站在这里<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="在这里——辅助词语。">e</a></sup>望着天呢？这位从你们中间被接到天上去的耶稣，将来也要这样回来，就像你们看到他升天那样。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="路加福音 24:52; 马太福音 21:1; 路加福音 24:50"> 于是他们从那叫做“橄榄园”的山上回到耶路撒冷。这山在耶路撒冷附近，有安息日允许走<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="允许走——辅助词语。">f</a></sup>的路程。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 20:8; 路加福音 22:12; 马可福音 14:15"> 他们一进城，就到他们所住的楼上房间。在那里有<br /><span className="pl pl-1">彼得、约翰、</span><br /><span className="pl pl-1">雅各、安得烈，</span><br /><span className="pl pl-1">腓力和多马，</span><br /><span className="pl pl-1">巴多罗迈和马太，</span><br /><span className="pl pl-1">亚勒腓的儿子</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="儿子——辅助词语。">g</a></sup><br /><span className="pl pl-1">雅各、</span><br /><span className="pl pl-1">激进派</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="激进派——或译作“奋锐党”。">h</a></sup><br /><span className="pl pl-1">的西门、雅各的儿子</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="儿子——辅助词语。">i</a></sup><br /><span className="pl pl-1">犹大。</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="使徒行传 6:4; 以弗所书 6:18; 歌罗西书 4:2"> 这些人与一些妇女以及耶稣的母亲玛丽亚、耶稣的兄弟们一起，都同心合意地恒切祷告<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附“祈求”。">j</a></sup>。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 15:6; 使徒行传 21:20; 启示录 3:4"> 就在那些日子里，聚在一起的人约有一百二十名。彼得在弟兄<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="弟兄——有古抄本作“门徒”。">k</a></sup>中间站起来，说：</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 41:9; 约翰福音 13:18; 诗篇 55:12–15"> “各位弟兄，那段经文是必须应验的，就是圣灵藉着大卫的口所预言有关犹大的事。这犹大，领人抓了耶稣；</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 1:25; 马可福音 3:19; 约翰福音 17:12"> 他本来算是我们中间的一个，也在这服事的工作上领受了一份；</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 27:3–10; 马太福音 26:14–15; 诗篇 55:23"> 后来，竟然用这个人不义的酬报买了一块地。犹大一头栽倒在那里，肚腹迸裂，肠子都流出来了。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 2:22; 马太福音 28:15; 使徒行传 21:40"> 所有住在耶路撒冷的人都知道了这件事，因此那块地按着他们的本地语言被称为“哈克达玛”——这意思是“血田”。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 69:25; 诗篇 109:8–15; 使徒行传 1:25"> 因为诗篇上记着：<br /><span className="pl pl-1">‘愿他的住所变为荒场，</span><br /><span className="pl pl-1">没有人住在其中。’ 又说：</span><br /><span className="pl pl-1">‘愿别人得到他监督的职份。’</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约翰福音 15:27; 路加福音 10:1–2; 民数记 27:17"> “所以，这些人中必须有一个人和我们同做耶稣复活的见证人；这人是主耶稣在我们中间出入的所有时间里——就是从约翰的洗礼开始，到耶稣被接升天离开我们的那天为止——一直与我们在一起的。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 15:22; 使徒行传 1:26"> 于是他们推举了两个人，就是那叫巴撒巴，又被称为犹斯托的约瑟，还有马提亚。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记上 16:7; 使徒行传 15:8; 希伯来书 4:13"> 他们就祷告说：“主啊，你洞察每个人的心。求你从这两个人中，指明你所拣选的是哪一位，</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多前书 9:2; 约翰福音 6:70–71; 约翰福音 17:12"> 使他得到这服事和使徒的职份。犹大背弃了这职份，去了自己的地方。”</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 16:8; 约书亚记 18:10; 撒母耳记上 14:41–42"> 接着，他们为这两个人抽签，抽到了马提亚，他就与那十一个使徒同列。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 1:2; 提摩太后书 4:20; 哥林多后书 1:1"> 这些事以后，保罗离开雅典，来到哥林多。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 16:3–4; 哥林多前书 16:19; 提摩太后书 4:19"> 他遇见一个出生在本都省的犹太人，名叫阿奎拉，最近与他的妻子普茜拉从意大利来，因为克劳迪命令所有的犹太人都要离开罗马。保罗来到他们那里，</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 4:12; 帖撒罗尼迦前书 2:9; 哥林多后书 11:9"> 因为与他们同业，就住在他们那里做工。原来他们是以制帐篷为业的。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 5:11; 使徒行传 17:17; 使徒行传 28:23"> 每逢安息日，保罗就在会堂里讲论，劝导犹太人和希腊人。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 5:14; 使徒行传 18:28; 使徒行传 20:21"> 西拉斯和提摩太从马其顿省下来的时候，保罗被这福音<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="福音——原文直译“话语”或“道”。">a</a></sup><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这福音——有古抄本作“圣灵”。">b</a></sup>所催逼，向犹太人郑重地见证耶稣是基督。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 33:4; 撒母耳记下 1:16; 以西结书 33:8–9"> 当他们抗拒、说亵渎话的时候，保罗就抖着衣服对他们说：“你们的血，归在你们自己的头上；我是清白的。从今以后，我要到外邦人那里去。”</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 16:14; 歌罗西书 4:11; 使徒行传 10:2"> 于是他离开那里，进到一个名叫提多犹斯托的人家里。这个人敬拜神，他的家就在会堂隔壁。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 1:13–17; 罗马书 10:14–17; 马可福音 16:15–16"> 会堂主管克里斯普和他全家都信了主，还有许多哥林多人听了以后就信了，并且受了洗。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 23:11; 以弗所书 6:19–20; 使徒行传 27:23–25"> 在夜里，主藉着异象对保罗说：<span className="woj">“不要怕，只管讲！不要沉默不语，</span></span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 12:9; 出埃及记 4:12; 以赛亚书 41:10"> <span className="woj">因为我与你同在，而且没有人会下手伤害你；原来在这城里有许多我的子民。”</span></span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 14:3; 使徒行传 19:10; 使徒行传 20:31"> 保罗在那里住了一年零六个月，在他们当中教导神的话语<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="神的话语——或译作“神的道”。">c</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 13:50; 使徒行传 18:27; 使徒行传 13:7"> 伽利奥任亚该亚省长的时候，犹太人一致起来攻击保罗，把他带到审判台前，</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 25:8; 使徒行传 24:5–6; 使徒行传 6:13"> 说：“他煽动人不按律法敬拜神。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="彼得前书 3:14–15; 使徒行传 25:11; 马可福音 9:19"> 保罗刚要开口，伽利奥就对犹太人说：“哦，各位犹太人哪！如果这真是什么罪行或邪恶的案情，我理当容忍你们。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 23:29; 使徒行传 25:19; 提摩太前书 6:4"> 但争议的问题，如果是关于字句、名称，和有关你们的律法，你们自己看着办吧！我不愿意做这些事的审判者。”</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 12:16; 诗篇 76:10; 罗马书 13:3–4"> 于是把他们从审判台前赶了出去。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 1:1; 阿摩司书 6:6; 使徒行传 17:32"> 大家<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="大家——有古抄本作“希腊人”。">d</a></sup>都抓住会堂主管索提尼，在审判台前殴打他。但伽利奥一概不管这些事。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行传 21:24; 民数记 6:18; 民数记 6:5–9"> 保罗在哥林多<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="在哥林多——辅助词语。">e</a></sup>继续留了许多日子，然后向弟兄们告别，坐船往叙利亚省去；普茜拉和阿奎拉也与他同去。他因为许过愿，就在坚革里港剃了头发。</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所书 1:1; 提摩太前书 1:3; 提摩太后书 1:18"> 他们到达以弗所城，保罗把他们两个人留在那里，自己就进了会堂向犹太人讲论。</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 1:37–38; 哥林多前书 16:12; 使徒行传 20:16"> 他们请求保罗再多住些时候，他没有答应，</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 4:19; 雅各书 4:15; 罗马书 15:32"> 向他们告别，说：“<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附“我必须尽量在耶路撒冷守那即将来临的节日。”">f</a></sup>如果神愿意，我会再回到你们这里来。”就从以弗所起航了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 8:40; 使徒行传 15:4; 使徒行传 23:23"> 保罗在凯撒里亚登陆，上耶路撒冷<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="耶路撒冷——辅助词语。">g</a></sup>去问候教会，然后下安提阿去。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 14:22; 使徒行传 16:6; 使徒行传 15:41"> 住了一段时间，他又离开那里，按着次序走遍加拉太和弗里吉亚地区，坚固所有的门徒。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 4:6; 提多书 3:13; 哥林多前书 3:5–6"> 有一个出生在亚历山大的犹太人，名叫阿波罗，到达了以弗所。他是个有学问的人，在经文方面很强。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 19:3; 罗马书 12:11; 何西阿书 14:9"> 这个人已经在主的道<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="道——或译作“路”。">h</a></sup>上受了教导，灵里火热，并仔细地讲论和教导有关耶稣<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="耶稣——有古抄本作“主”。">i</a></sup>的事，可是他只知道约翰的洗礼。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 18:25; 使徒行传 14:3; 哥林多前书 12:21"> 阿波罗开始在会堂里放胆传道。普茜拉和阿奎拉听了，就接他来，把神的道更详尽地讲解给他听。</span>
<span className="v" id="v27" data-v="27" data-xref="帖撒罗尼迦后书 2:13–14; 雅各书 1:16–18; 彼得前书 1:2–3"> 后来阿波罗想到亚该亚省去，弟兄们就鼓励他，写信请门徒们欢迎他。他到了以后，对那些蒙恩的信徒大有帮助，</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 18:5; 哥林多前书 15:3–4; 使徒行传 9:22"> 因为他当众强有力地驳倒犹太人，用经文证明耶稣是基督。</span>
</div>
</div>

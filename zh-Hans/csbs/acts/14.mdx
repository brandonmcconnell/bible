<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 18:4; 使徒行传 13:51; 使徒行传 13:46"> 有一次在以哥念，保罗和巴拿巴同样进了犹太人的会堂讲道，结果有一大群犹太人和希腊人信了。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 13:50; 使徒行传 21:27–30; 使徒行传 14:19"> 但那些不肯信从的犹太人怂恿外邦人，使他们心里敌视弟兄们。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 2:4; 以弗所书 6:18–20; 使徒行传 20:32"> 于是保罗和巴拿巴就住了很久，靠着主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="靠着主——或译作“为主”。">a</a></sup>放胆传道。主藉着他们的手行了神迹和奇事，见证了他恩典的话语。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 28:24; 使徒行传 14:14; 路加福音 11:21–23"> 以哥念城的民众就分裂了，有的赞同犹太人，有的赞同使徒们。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 14:19; 提摩太后书 3:11; 使徒行传 17:5"> 那时，外邦人和犹太人，与他们的首领们一同企图凌辱<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="凌辱——或译作“攻击”。">b</a></sup>使徒们，要用石头砸死他们。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 14:20–21; 马太福音 10:23; 提摩太后书 3:11"> 两个人知道了，就逃往利考尼亚地区的路司得和代尔贝两个城以及周围地区，</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 14:21; 使徒行传 16:10; 帖撒罗尼迦前书 2:2"> 在那里继续传福音。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 3:2; 约翰福音 9:1–2; 约翰福音 5:3–5"> 在路司得城里坐着一个双脚残废的人，他生来<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="生来——原文直译“从母腹中”。">c</a></sup>就瘸腿，从来没有走过路；</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 3:4; 马太福音 15:28; 马太福音 9:28–29"> 这个人听保罗讲道。保罗注视着他，见他存着信可得救治，</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 35:6; 约翰福音 5:8–9; 约翰福音 14:12"> 就大声说：“你起来，用你的两脚站直！”那个人就跳起来，开始走路了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 28:6; 使徒行传 8:10; 使徒行传 12:22"> 众人看见保罗所做的，就用利考尼亚话高声说：“神明像人那样降临在我们中间了！”</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 19:35"> 他们称巴拿巴为宙斯神，称保罗为赫尔墨斯神，因为保罗是领头说话的人。</span>
<span className="v" id="v13" data-v="13" data-xref="但以理书 2:46; 使徒行传 10:25"> 于是城外宙斯神庙的祭司，牵着几头公牛，带着一些花环，到了城门口，要与众人一起来献祭。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 26:65; 哥林多前书 9:5–6; 列王纪下 5:7"> 巴拿巴和保罗两位使徒听见这事，就撕裂自己的衣服，冲进人群里面，</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 10:26; 哥林多前书 8:4; 雅各书 5:17"> 喊着说：“各位，你们为什么做这些事呢？我们和你们同样是人！我们向你们传福音，是要你们离弃这些虚妄的事，归向永生的神，就是造了天、地、海和其中万有的神。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 17:30; 诗篇 81:12; 罗马书 1:28"> 在过去的各世代，神容忍万民各行其道。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 1:19–20; 约珥书 2:23; 约伯记 5:10"> 其实神并不是没有为自己留下证据，因为他常行美善：从天上赐给你们<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="你们——有古抄本作“我们”。">d</a></sup>雨水和丰收的季节，使你们<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="你们——有古抄本作“我们”。">e</a></sup>食物充足，满心喜乐。”</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 44:16–17; 创世记 19:9; 创世记 11:6"> 两个人说了这些话，好不容易才阻止众人向他们献祭。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多后书 11:25; 提摩太后书 3:11; 使徒行传 13:50–51"> 但有些犹太人从安提阿和以哥念来到，挑唆众人，用石头砸了保罗。他们以为他已经死了，就把他拖到城外。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 1:9–10; 哥林多后书 6:9; 使徒行传 14:6"> 但门徒们围绕他的时候，他站了起来，进到城里。第二天，他与巴拿巴一起离开，前往代尔贝去。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 14:19; 使徒行传 14:1; 使徒行传 13:51"> 保罗和巴拿巴在代尔贝城传了福音，使许多人成为门徒以后，回到路司得、以哥念、安提阿，</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 5:10; 提摩太后书 3:12; 约翰福音 16:33"> 坚固门徒们的心，鼓励他们持守信仰，说：“我们进入神的国，必须经过很多患难。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="提多书 1:5; 使徒行传 11:30; 雅各书 5:14"> 保罗和巴拿巴在各教会为他们选出了长老，祷告和禁食以后，把他们交托给他们所信靠的主。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 13:13–14; 使徒行传 15:38"> 两个人经过皮西迪亚地区，来到潘菲利亚省，</span>
<span className="v" id="v25" data-v="25"> 在佩尔格传了道，就下到阿塔利亚，</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 15:40; 使徒行传 11:19; 哥林多后书 1:12"> 从那里坐船回安提阿。当初，就是在这里，他们被交托在神的恩典中，去从事如今那已完成的工作。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 16:9; 使徒行传 15:12; 歌罗西书 4:3"> 他们到了，就召集教会，传讲了神与他们所做的一切事，以及神怎样为外邦人打开了信仰之门。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 11:26; 使徒行传 15:35"> 两个人在那里与门徒们一起住了不少时候。</span>
</div>
</div>

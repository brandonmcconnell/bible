<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 34:1; 申命记 3:8; 民数记 21:20"> 以色列子民起行，在耶利哥东边约旦河对面的摩押平原扎营。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 11:25; 民数记 21:20–35; 民数记 21:3"> 以色列对亚摩利人所做的一切，西拨的儿子巴勒都看到了。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 15:15; 以赛亚书 23:5; 约书亚记 9:24"> 摩押就非常惧怕这民，因为他们人数众多。摩押因以色列人的缘故而忧心，</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 25:15–18; 民数记 31:8; 民数记 24:17"> 对米甸的长老们说：“恐怕这部族要吃光我们周围的一切，就像牛吃光田野的青草一样。”<br />那时，西拨的儿子巴勒是摩押王。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 23:4; 约书亚记 24:9; 弥迦书 6:5"> 他就派遣使者到他本族人之地大河<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="大河——指幼发拉底河。">a</a></sup>边的佩托尔，去见比珥的儿子巴兰，要召他来，说：“你看，有一个民族从埃及出来，他们遮满了地面，在我对面驻扎。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 24:9; 民数记 23:7–8; 使徒行传 16:16"> 现在请你来，为我诅咒这民族，因为他们比我强大。这样，或许我能够击败他们，把他们从这地驱逐出去。因为我知道，你祝福的人必受祝福，你诅咒的人必受诅咒。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 9:7–8; 弥迦书 3:11; 罗马书 16:18"> 摩押的长老们和米甸的长老们，手里带着占卜的酬金就去了。他们来见巴兰，将巴勒的话告诉了他。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 23:12; 民数记 22:19–20; 耶利米书 12:2"> 巴兰对他们说：“你们今晚在这里过夜吧。我将照着耶和华吩咐我的，回复你们。”于是摩押的首领们就住在巴兰那里。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 20:3; 民数记 22:20; 创世记 16:8"> 神临到巴兰，说：“那些在你这里的人是谁？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 巴兰对神说：“西拨的儿子摩押王巴勒派了人到我这里来，说：</span>
<span className="v" id="v11" data-v="11"> ‘你看，有一个民族从埃及出来，遮满了地面。现在请你来，为我诅咒他们，或许我能击败他们，驱逐他们。’”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命记 23:5; 以弗所书 1:3; 创世记 12:2"> 神对巴兰说：“你不可跟着他们去，不可诅咒那民族，因为他们是蒙祝福的。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命记 23:5; 民数记 22:14"> 巴兰清晨起来，对巴勒的首领们说：“你们回本地去吧，因为耶和华不允许我跟着你们去。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 22:37; 民数记 22:13"> 摩押的首领们就起身，回到巴勒那里，说：“巴兰不愿跟着我们来。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行传 10:7–8; 民数记 22:7–8"> 于是，巴勒再次派遣一批首领，比先前的更多更尊贵。</span>
<span className="v" id="v16" data-v="16"> 他们来到巴兰那里，对他说：“西拨的儿子巴勒如此说：请不要推辞来我这里，</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 24:11; 以斯帖记 5:11; 马太福音 4:8–9"> 我一定使你大得尊荣。无论你告诉我什么，我都会照办。来吧，请为我诅咒这民族。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民数记 24:13; 列王纪上 22:14; 历代志下 18:13"> 巴兰回答巴勒的臣仆，说：“即使巴勒把他满屋的金银都给我，我也不能违背我的神耶和华的吩咐，无论做小事还是大事。</span>
<span className="v" id="v19" data-v="19" data-xref="犹大书 1:11; 彼得后书 2:3; 提摩太前书 6:9–10"> 所以，请你们今晚也住在这里吧，我要知道耶和华还会对我说什么。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数记 23:12; 民数记 24:13; 民数记 23:26"> 夜间，神临到巴兰对他说：“既然这些人来邀请你，你就起来跟着他们去吧，只是你要做我吩咐你的事。”</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 1:15–16"> 于是巴兰清晨起来，备好驴，跟着摩押的首领们去了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及记 4:24; 耶利米哀歌 2:4; 民数记 22:32"> 因巴兰前往，神就怒气发作。耶和华的一位使者站在路上敌对他。当时，巴兰骑在驴上，他的两个仆人跟随着他。</span>
<span className="v" id="v23" data-v="23" data-xref="犹大书 1:11; 彼得后书 2:16; 哥林多前书 1:27–29"> 驴看见耶和华的使者站在路上，手里有拔出的刀，驴就转离那条路，走到田野中。巴兰打驴，要使它转回那条路。</span>
<span className="v" id="v24" data-v="24"> 于是，耶和华的使者站在葡萄园之间的窄路上，这边有围墙，那边也有围墙。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 47:12; 约伯记 5:13–15"> 驴看见耶和华的使者，就挤到墙边，把巴兰的脚也挤到墙边上，巴兰就又打它。</span>
<span className="v" id="v26" data-v="26" data-xref="何西阿书 2:6; 以赛亚书 26:11"> 耶和华的使者再上前去，站到左右都无路可转的狭窄地方。</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 14:16; 雅各书 1:19; 箴言 27:3–4"> 驴看见耶和华的使者，就趴在巴兰身下。巴兰怒气发作，用杖打驴。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="彼得后书 2:16; 路加福音 1:37; 出埃及记 4:11"> 于是耶和华开了驴的口，驴对巴兰说：“我对你做了什么，你竟打我这三次？”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="箴言 12:10; 马太福音 15:19; 箴言 12:16"> 巴兰对驴说：“因为你捉弄我！要是我手里有刀，我现在就宰了你。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="彼得后书 2:16; 哥林多前书 1:27–28"> 驴对巴兰说：“我不就是你至今一直在骑的那头驴吗？我往常对你这样做过吗？”<br />巴兰说：“没有。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="创世记 21:19; 路加福音 24:31; 使徒行传 26:18"> 耶和华打开巴兰的眼睛，他看见耶和华的使者站在路上，手里拿着拔出的刀，他就俯身，脸伏于地。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 28:18; 使徒行传 13:10; 民数记 22:22"> 耶和华的使者对他说：“你为什么这三次打你的驴呢？看哪，我出来敌对你，因为这条路在我面前是邪僻的。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 16:33–35; 民数记 14:37; 列王纪上 13:24–28"> 驴看见我，所以从我面前转开了这三次。如果它不从我面前转开，我早已经把你杀了，只让它存活。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="约伯记 34:31–32; 撒母耳记下 12:13; 撒母耳记上 15:24"> 巴兰对耶和华的使者说：“我有罪了！我实在不知道你站在路上阻挡我。现在如果你不喜悦，我就回去吧。”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="帖撒罗尼迦后书 2:9–12; 以赛亚书 37:26–29; 民数记 22:20–21"> 耶和华的使者对巴兰说：“你跟着这些人去吧，但只可以说我吩咐你的话。”于是巴兰就跟着巴勒的首领们去了。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以赛亚书 16:2; 使徒行传 28:15; 耶利米书 48:20"> 巴勒听见巴兰来了就出去，到摩押的都城迎接他，这城在亚嫩河的边界，在边界线上。</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 24:11; 约翰福音 5:44; 马太福音 4:8–9"> 巴勒对巴兰说：“我不是迫切派人去召你来吗？你为什么不来我这里呢？难道我不会真的使你得尊荣吗？”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="民数记 22:18; 箴言 19:21; 民数记 23:16"> 巴兰对巴勒说：“看，我已经来到你这里了。难道现在我就能擅自说什么吗？神把什么话放在我口中，我就说什么。”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39"> 于是巴兰跟着巴勒去，来到了基列-胡佐。</span>
<span className="v" id="v40" data-v="40" data-xref="民数记 23:14; 箴言 1:16; 民数记 23:2"> 巴勒祭献了牛羊，然后把肉送给巴兰以及与他一起的首领们。</span>
<span className="v" id="v41" data-v="41" data-xref="民数记 23:13; 民数记 25:2–3; 历代志下 11:15"> 到了清晨，巴勒带巴兰登上巴力高原，从那里可以看到以色列民营地的边缘。</span>
</div>
</div>

</div>

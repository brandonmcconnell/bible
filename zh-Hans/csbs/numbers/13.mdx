<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 1:22–25; 民数记 32:8; 民数记 34:18"> “你要派人去探察我赐给以色列子孙的迦南地，按父系支派，每支派差遣一人，都是他们当中的首领。”</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 12:16; 民数记 32:8; 申命记 1:19"> 摩西就按照耶和华的指示，从帕兰旷野派出他们，全都是作以色列子民首领的人。</span>
<span className="v" id="v4" data-v="4"> 以下是他们的名字：<br /><span className="pl pl-1">属鲁本支派的，是扎克尔的儿子沙慕亚；</span><br /></span>
<span className="v" id="v5" data-v="5"> <span className="pl pl-1">属西缅支派的，是何利的儿子沙法；</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="民数记 34:19; 民数记 14:6; 民数记 13:30"> <span className="pl pl-1">属犹大支派的，是耶弗尼的儿子迦勒；</span><br /></span>
<span className="v" id="v7" data-v="7"> <span className="pl pl-1">属以萨迦支派的，是约瑟的儿子以甲；</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 24:13; 民数记 11:28; 民数记 13:16"> <span className="pl pl-1">属以法莲支派的，是嫩的儿子何西阿；</span><br /></span>
<span className="v" id="v9" data-v="9"> <span className="pl pl-1">属便雅悯支派的，是拉弗的儿子帕尔提；</span><br /></span>
<span className="v" id="v10" data-v="10"> <span className="pl pl-1">属西布伦支派的，是索迪的儿子伽迪列；</span><br /></span>
<span className="v" id="v11" data-v="11"> <span className="pl pl-1">属约瑟支派，就是玛拿西支派的，是苏希的儿子迦底；</span><br /></span>
<span className="v" id="v12" data-v="12"> <span className="pl pl-1">属但支派的，是基玛利的儿子亚米利；</span><br /></span>
<span className="v" id="v13" data-v="13"> <span className="pl pl-1">属亚设支派的，是米迦勒的儿子西帖；</span><br /></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">属拿弗他利支派的，是沃夫西的儿子拿比；</span><br /></span>
<span className="v" id="v15" data-v="15"> <span className="pl pl-1">属迦得支派的，是玛基的儿子格乌列。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数记 13:8; 出埃及记 17:9; 民数记 14:6"> 以上就是摩西派去探察那地的人的名字；摩西称嫩的儿子何西阿为约书亚。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="士师记 1:9; 创世记 12:9; 士师记 1:19"> 摩西派他们去探察迦南地，对他们说：“你们前往南地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="南地——音译作“内盖夫”；本章下同。">a</a></sup>那里，然后上到山地去。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 34:14; 出埃及记 3:8"> 你们要察看那地是怎样的：住在那里的民是强是弱、是少是多，</span>
<span className="v" id="v19" data-v="19"> 他们所住的地方是好是坏，他们所住的城是营地是堡垒，</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 31:23; 申命记 31:6–8; 以西结书 34:14"> 那地是肥沃还是贫瘠，那里有树木没有。你们要尽力带一些当地的果实回来。”那时正是葡萄初熟的季节。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数记 20:1; 民数记 33:36; 民数记 27:14"> 于是他们上去探察那地，从寻的旷野直到哈马隘口那里的利合。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 78:12; 诗篇 78:43; 以赛亚书 19:11"> 他们上到南地，来到希伯仑；那里有亚衲人的后裔亚希幔、示筛和塔尔迈，希伯仑比埃及的琐安早建造七年。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 13:24; 民数记 32:9; 申命记 1:24–25"> 他们来到以实格溪谷，从那里砍下一根葡萄枝，上面带着一挂葡萄，由两个人用杠子抬着，还带了一些石榴和无花果。</span>
<span className="v" id="v24" data-v="24"> 以色列人给那地方起名为“以实格溪谷”，因为他们从那里砍下了一挂葡萄。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 34:28; 出埃及记 24:18; 民数记 14:33–34"> 四十天后，他们探察完那地回来了。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="民数记 32:8; 民数记 20:1; 申命记 1:19"> 他们回到帕兰旷野的加低斯，来到摩西和亚伦以及全体以色列会众那里，向他们和全体会众报告，又给他们看那地的果实。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 3:8; 出埃及记 3:17; 出埃及记 13:5"> 他们向摩西讲述，说：“我们到了你派我们去的那地，果然是流奶与蜜之地，这就是那里的果实。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 9:1–2; 申命记 1:28; 民数记 13:33"> 不过住在那地的民强悍，城市极其坚固高大，我们在那里还看见了亚衲人的后裔。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 14:43; 士师记 6:3; 创世记 15:19–21"> 亚玛力人住在南地，赫提人、耶布斯人和亚摩利人住在山地，迦南人住在海边和约旦河沿岸。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="民数记 14:24; 罗马书 8:31; 腓立比书 4:13"> 迦勒让民众在摩西面前安静下来，说：“我们尽管上去，占有那地！我们一定能征服它。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="申命记 1:28; 约书亚记 14:8; 希伯来书 3:19"> 但那些与他一起上去探察<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="探察——辅助词语。">b</a></sup>的人说：“我们不能上去攻打那民，他们实在比我们强大。”</span>
<span className="v" id="v32" data-v="32" data-xref="阿摩司书 2:9; 民数记 14:36–37; 以西结书 36:13–14"> 那些人还向以色列子民散布有关所探察之地的谣言，说：“我们过去探察的那地，是吞没居民之地，而且我们在那里看见的民都是身材高大的人。</span>
<span className="v" id="v33" data-v="33" data-xref="申命记 1:28; 以赛亚书 40:22; 创世记 6:4"> 我们在那里也看见了巨人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="巨人——或译作“伟人”。">c</a></sup>，就是巨人的后裔亚衲子孙。在我们眼中，我们就像是蚱蜢；在他们眼中，我们也是如此。”</span>
</div>
</div>

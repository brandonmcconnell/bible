<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 3:11; 创世记 8:21; 民数记 9:2–3"> “你要吩咐以色列子民，对他们说：你们务必在所定的日期向我献上祭物作馨香之气，作为献给我的火祭食物。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 6:9; 但以理书 11:31; 约翰福音 1:29"> 你要对他们说，献给耶和华的火祭如下： 每日常献的燔祭<br />“两只无瑕疵的一岁公羊羔，作为每天常献的燔祭，</span>
<span className="v" id="v4" data-v="4" data-xref="但以理书 9:21; 列王纪上 18:36; 出埃及记 12:6"> 早晨献一只羊羔，黄昏的时候献另一只羊羔；</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 2:1; 出埃及记 16:36; 出埃及记 29:38–42"> 还有十分之一伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十分之一伊法——相当于2.2公升；本章下同。1伊法＝22公升。">a</a></sup>细面粉，用四分之一欣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="四分之一欣——相当于0.9公升；本章下同。1欣=3.7公升。">b</a></sup>压榨的油调和作素祭。</span>
<span className="v" id="v6" data-v="6" data-xref="阿摩司书 5:25; 利未记 6:9; 诗篇 50:8"> 这常献的燔祭是在西奈山规定的，是献给耶和华的馨香火祭。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 29:42; 民数记 28:14; 以赛亚书 57:6"> 还要为每一只公羊羔同献四分之一欣的酒祭，在圣所中将醇酒的酒祭浇奠给耶和华。</span>
<span className="v" id="v8" data-v="8"> 你要在黄昏的时候献第二只羊羔，像早晨的素祭和酒祭一样献上，作馨香的火祭献给耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 58:13; 诗篇 92:1–4; 启示录 1:10"> “在安息日，要献两只无瑕疵的一岁公羊羔，还有十分之二伊法<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="十分之二伊法——相当于4.4公升；本章下同。1伊法=22公升。">c</a></sup>调了油的细面粉为素祭，以及同献的酒祭。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 46:4–5; 民数记 29:22; 民数记 29:31"> 这是在常献的燔祭和同献的酒祭以外，每个安息日都要献的燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民数记 10:10; 以西结书 46:6; 以斯拉记 3:5"> “在每个月的第一天，你们要向耶和华献上燔祭：两头公牛、一只公绵羊、七只无瑕疵的一岁公羊羔。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 15:4–12; 以西结书 46:5–7; 民数记 29:10"> 为每一头公牛，献上十分之三伊法<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="十分之三伊法——相当于6.6公升；本章下同。1伊法=22公升。">d</a></sup>调了油的细面粉作素祭；为每一只公绵羊，献上十分之二伊法调了油的细面粉作素祭；</span>
<span className="v" id="v13" data-v="13"> 为每一只羊羔，献上十分之一伊法调了油的细面粉作素祭。这是燔祭，作馨香的火祭献给耶和华。</span>
<span className="v" id="v14" data-v="14"> 还有同献的酒祭，每头公牛要二分之一欣<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="二分之一欣——相当于1.9公升。1欣=3.7公升。">e</a></sup>酒，每只公绵羊要三分之一欣<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="三分之一欣——相当于1.2公升。">f</a></sup>酒，每只羊羔要四分之一欣<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="四分之一欣——相当于0.9公升。">g</a></sup>酒。这是一年之中每个月都要献上的新月燔祭。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 28:3; 民数记 28:22; 民数记 15:24"> 除了常献的燔祭和同献的酒祭以外，还要献给耶和华一只公山羊作赎罪祭。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命记 16:1–8; 出埃及记 12:18; 利未记 23:5–8"> “一月十四日是耶和华的逾越节，</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 23:6; 出埃及记 23:15; 出埃及记 13:6"> 这个月的十五日是节期，要吃无酵饼七天。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 12:16; 利未记 23:7–8"> 第一天要有神圣的聚会，任何日常工作都不可做。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 15:21; 以西结书 45:21–25; 民数记 29:8"> 你们要献上两头公牛、一只公绵羊、七只一岁的公羊羔，都必须是无瑕疵的，作为火祭，作为燔祭献给耶和华。</span>
<span className="v" id="v20" data-v="20"> 还有同献的素祭，就是调了油的细面粉：为每头公牛，要献十分之三伊法面粉；为每只公绵羊，要献十分之二伊法面粉；</span>
<span className="v" id="v21" data-v="21"> 至于那七只公羊羔，要为每一只羊羔献十分之一伊法面粉。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 8:3"> 还要献一只赎罪祭公山羊，为你们赎罪。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 28:3; 民数记 28:10"> 除了清晨的燔祭，就是常献的燔祭以外，你们还要献以上这些祭物。</span>
<span className="v" id="v24" data-v="24"> 在常献的燔祭和同献的酒祭以外，一连七天，每天都要这样献上火祭的食物，作馨香之气献给耶和华。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 23:8; 民数记 28:18; 出埃及记 13:6"> 第七天要有神圣的聚会，任何日常工作都不可做。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 23:16; 出埃及记 34:22; 利未记 23:10"> “在初熟之日，当你们在七七节向耶和华献上新的素祭时，要有神圣的聚会，任何日常工作都不可做。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 23:18–19; 民数记 28:11; 民数记 28:19"> 你们要献上两头公牛、一只公绵羊、七只一岁的公羊羔为燔祭，作馨香之气献给耶和华。</span>
<span className="v" id="v28" data-v="28"> 还有同献的素祭，就是调了油的细面粉：为每头公牛，要献十分之三伊法面粉；为每一只公绵羊，要献十分之二伊法面粉；</span>
<span className="v" id="v29" data-v="29"> 至于那七只公羊羔，要为每一只羊羔献十分之一伊法面粉。</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 28:15; 民数记 28:22; 彼得前书 2:24"> 还要献一只公山羊，为你们赎罪。</span>
<span className="v" id="v31" data-v="31" data-xref="民数记 28:19; 民数记 28:3; 玛拉基书 1:13–14"> 你们要在常献的燔祭和同献的素祭以外，献上这些无瑕疵的燔祭和同献的酒祭。</span>
</div>
</div>

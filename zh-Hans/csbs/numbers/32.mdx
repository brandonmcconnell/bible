<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 21:32; 民数记 32:3; 创世记 13:10–11"> 鲁本子孙和迦得子孙有许多牲畜，极其兴旺。他们观看雅谢地和基列地，发现那地方很适合放牧牲畜。</span>
<span className="v" id="v2" data-v="2"> 于是迦得子孙和鲁本子孙前来，对摩西和祭司以利亚撒，以及会众领袖们说：</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 48:34; 以赛亚书 16:8–9; 民数记 32:34–38"> “亚塔罗、迪本、雅谢、宁拉、希实本、以利亚利、谢巴姆、尼波、比稳，</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 21:34; 申命记 2:24–35; 民数记 21:24"> 就是耶和华在以色列会众面前所征服的土地，很适合放牧牲畜，而你的仆人们有许多牲畜。”</span>
<span className="v" id="v5" data-v="5" data-xref="路得记 2:10; 约书亚记 7:7; 耶利米书 31:2"> 他们接着说：“如果我们在你眼前蒙恩，就请把这地分给你的仆人作产业，不要领我们过约旦河。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 13:5; 撒母耳记下 11:11; 腓立比书 2:4"> 摩西对迦得子孙和鲁本子孙说：“难道你们的弟兄去作战，你们却要坐在这里吗？</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 13:27–4; 民数记 32:9; 申命记 1:28"> 你们为什么不过河前往耶和华赐给以色列子孙的土地，以致他们灰心丧胆呢？</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 1:19–25; 民数记 14:2; 民数记 13:2–26"> 我从加低斯-巴尼亚派你们的父辈去察看那地时，他们也这样做过。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 13:23–10; 申命记 1:24–28"> 他们上到以实格溪谷，察看了那地后，却使以色列子民灰心丧胆，不愿进入耶和华赐给他们的土地。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 14:11; 诗篇 95:11; 以西结书 20:15"> 所以在那天，耶和华怒气发作，起誓说：</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 14:28–30; 民数记 14:24; 民数记 26:2"> ‘从埃及上来的二十岁以上的男子，绝不会见到我起誓给亚伯拉罕、以撒、雅各的那地，因为他们没有全心跟从我。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 1:36; 民数记 14:30; 民数记 14:24"> 只有基尼洗人耶弗尼的儿子迦勒和嫩的儿子约书亚例外，因为他们全心跟随耶和华。’</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 10:5; 民数记 14:33–35; 希伯来书 3:16–19"> 耶和华的怒气向以色列发作，使他们在旷野漂泊四十年，直到在耶和华眼前作恶的那整个世代都灭尽了。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 11:48; 诗篇 78:57; 马太福音 23:31–33"> 看哪，你们这罪人的族类，你们起来接续你们的父辈，再次增添耶和华对以色列的猛烈怒气。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 8:11–12; 历代志下 15:2; 历代志下 7:19–22"> 如果你们转离不跟从他，他必再次把以色列撇弃在旷野，那样你们就毁了这整个民族。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="创世记 33:17; 民数记 34:22"> 于是，他们近前来说：“我们是要在这里为我们的牲畜建造围栏，为我们的家属建造城镇。</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 4:12–13; 民数记 32:29–32; 申命记 3:18–20"> 然后我们必武装起来，在以色列子孙前面领先前行，直到把他们带到他们的地方；我们的家属要留在坚固的城里，躲避这地的居民。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 22:1–5"> 在以色列子孙各自继承他们的产业之前，我们绝不回自己的家；</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 13:8; 约书亚记 12:1–6; 民数记 34:15"> 我们也不会在约旦河对岸那一带与大家同分产业，因为我们已经在约旦河东边分得了自己的产业。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约书亚记 4:12–13; 申命记 3:18–20; 约书亚记 1:13–15"> 摩西就对他们说：“如果你们是要这样做，如果你们在耶和华面前武装起来去作战，</span>
<span className="v" id="v21" data-v="21"> 你们所有武装起来的人就要在耶和华面前渡过约旦河，直到耶和华将仇敌从他面前赶出去。</span>
<span className="v" id="v22" data-v="22" data-xref="约书亚记 22:9; 约书亚记 22:4; 申命记 3:20"> 当那地在耶和华面前被征服之后，你们才可以回来。这样你们就对耶和华和以色列尽责了，这地就在耶和华面前成为你们的产业。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 59:12; 箴言 13:21; 创世记 44:16"> 但如果你们不这样做，看哪，你们就对耶和华犯罪了！要知道，你们的罪必找上你们。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 32:16; 民数记 30:2; 民数记 32:34–42"> 你们就为家属建造城镇、为羊群建造围栏吧！但你们口里说出的，一定要实行。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约书亚记 1:13–14"> 迦得子孙和鲁本子孙回答摩西说：“你的仆人们必照着我主所吩咐的去做。</span>
<span className="v" id="v26" data-v="26" data-xref="约书亚记 1:14"> 我们的孩童、妻子，以及我们的牛羊和所有的牲畜，都会留在基列各城。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 4:12; 民数记 32:17; 民数记 12:11"> 但你的仆人们，凡是武装起来的军兵，都会照着我主所吩咐的，在耶和华面前过河去作战。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约书亚记 1:13"> 于是，摩西就为了他们吩咐祭司以利亚撒和嫩的儿子约书亚，以及以色列子孙各支派父系的首领。</span>
<span className="v" id="v29" data-v="29"> 摩西说：“迦得子孙和鲁本子孙，凡是武装起来在耶和华面前去作战的人，如果与你们一同过约旦河，并且那地在你们面前被征服了，你们就要把基列地分给他们作产业。</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 22:19"> 但如果他们不愿武装起来与你们一同过河，他们就要在迦南地与你们同分产业。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31"> 迦得子孙和鲁本子孙回应说：“耶和华所吩咐你仆人们的，我们都必照样遵行。</span>
<span className="v" id="v32" data-v="32"> 我们会武装起来，在耶和华面前过河到迦南地，而我们继承的地业是在约旦河这边。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约书亚记 12:6; 申命记 29:8; 申命记 3:12–17"> 于是，摩西把亚摩利王西宏的王国和巴珊王欧革的王国，就是他们境内的土地连同城镇，以及周围的土地和城镇，都分给了迦得子孙和鲁本子孙，以及约瑟的儿子玛拿西半支派。</span>
<span className="v" id="v34" data-v="34" data-xref="申命记 2:36; 民数记 32:3; 以赛亚书 17:2"> 迦得子孙就建造了迪本、亚塔罗、亚罗珥、</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 32:1; 民数记 32:3"> 亚他录-朔反、雅谢、约比哈、</span>
<span className="v" id="v36" data-v="36" data-xref="民数记 32:3"> 伯宁拉、伯哈兰，都是坚固的城，并建造了牲畜围栏。</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 21:27; 民数记 32:3; 以赛亚书 15:4"> 鲁本子孙建造了希实本、以利亚利、基列亭、</span>
<span className="v" id="v38" data-v="38" data-xref="以赛亚书 46:1; 民数记 32:3; 约书亚记 23:7"> 尼波、巴力梅翁（这些名字是被改的）、西比玛。他们给所建造的城都起了别的名字。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="创世记 50:23; 约书亚记 17:1; 民数记 26:29"> 玛拿西的儿子玛吉的子孙往基列去，攻取那地，把那里的亚摩利人赶了出去。</span>
<span className="v" id="v40" data-v="40" data-xref="约书亚记 17:1; 约书亚记 13:29–31; 申命记 3:13–15"> 于是摩西把基列分给玛拿西的儿子玛吉，他就住在那里。</span>
<span className="v" id="v41" data-v="41" data-xref="申命记 3:14; 士师记 10:4; 约书亚记 13:30"> 玛拿西的儿子睚珥也前去，攻取了亚摩利人的一些村镇，就称它们为睚珥镇。</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 49:11; 撒母耳记下 18:18"> 挪巴也前去，攻取了基纳和附属的村镇，就以自己的名字称基纳为挪巴。</span>
</div>
</div>

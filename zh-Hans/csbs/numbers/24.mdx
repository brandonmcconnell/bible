<span className="v" id="v1" data-v="1" data-xref="民数记 23:3; 民数记 23:23; 民数记 23:28"> 巴兰看到祝福以色列能取悦耶和华，就没有像前几次那样尝试用法术，而是把脸转向旷野。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 19:20; 历代志下 15:1; 撒母耳记上 19:23"> 巴兰举目，看见以色列按各自的支派安居，神的灵就临到他身上。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 22:31; 民数记 24:16; 民数记 23:7"> 他发布谕示，说：<br /><span className="pl pl-1">“这是比珥的儿子巴兰的宣告，</span><br /><span className="pl pl-1">眼睛开启之人的宣告；</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="启示录 1:17; 启示录 1:10; 民数记 12:6"> <span className="pl pl-1">这听到神的话语之人，</span><br /><span className="pl pl-1">看到全能者的异象，</span><br /><span className="pl pl-1">俯伏着，双眼被开启，</span><br /><span className="pl pl-1">他的宣告如下：</span><br /></span>
<span className="v" id="v5" data-v="5"> <span className="pl pl-1">雅各啊，你的帐篷多么美好；</span><br /><span className="pl pl-1">以色列啊，你的帐幕何等华美！</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 1:3; 以赛亚书 58:11; 诗篇 104:16"> <span className="pl pl-1">它们像绵延的溪谷，</span><br /><span className="pl pl-1">像河边的园林；</span><br /><span className="pl pl-1">像耶和华栽种的沉香树，</span><br /><span className="pl pl-1">像水边的香柏树。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 5:12; 历代志上 14:2; 启示录 17:1"> <span className="pl pl-1">露水从他的枝干滴落</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="露水从他的枝干滴落——或译作“水从他的桶里流出”。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">他的根</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="根——或译作“种子”。">b</a></sup><br /><span className="pl pl-1">在水源丰富之地；</span><br /><span className="pl pl-1">他的君王必高过亚甲，</span><br /><span className="pl pl-1">他的王权必被高举。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 45:5; 诗篇 2:9; 民数记 14:9"> <span className="pl pl-1">神把他从埃及领出来，</span><br /><span className="pl pl-1">像野牛的角为他争战</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="争战——辅助词语。">c</a></sup><br /><span className="pl pl-1">。</span><br /><span className="pl pl-1">他必吞噬那些敌对他的国家，</span><br /><span className="pl pl-1">压碎他们的骨头，</span><br /><span className="pl pl-1">用箭射透他们。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="创世记 12:3; 创世记 27:29; 创世记 49:9"> <span className="pl pl-1">他屈身躺卧如公狮和母狮，</span><br /><span className="pl pl-1">谁敢招惹他？</span><br /><span className="pl pl-1">凡祝福你的，必受祝福；</span><br /><span className="pl pl-1">凡诅咒你的，必受诅咒！”</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民数记 23:11; 以西结书 21:14; 以西结书 21:17"> 巴勒就对巴兰发怒，拍掌对巴兰说：“我召你来是为了诅咒我的仇敌，看哪，你竟然祝福了他们这三次！</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 22:17; 民数记 22:37; 希伯来书 11:24–26"> 现在赶紧回你本地去吧！我曾说要使你大得尊荣，看哪，耶和华却阻挡你得尊荣。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数记 22:18; 民数记 22:38"> 巴兰回答巴勒：“我不是告诉过你派来见我的那些使者吗？我说：</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 16:28; 民数记 22:18; 民数记 22:20"> 即使巴勒把他满屋的金银给我，我也不能违背耶和华的吩咐，凭自己的心意做好做歹。耶和华说什么，我就说什么。</span>
<span className="v" id="v14" data-v="14" data-xref="弥迦书 6:5; 启示录 2:14; 创世记 49:1"> 现在，看哪，我将要回我的族人那里去了。请让我告诉你，日后那民族会怎样对待你的子民。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="民数记 24:3–4; 民数记 23:7; 马太福音 13:35"> 于是巴兰发布谕示，说：<br /><span className="pl pl-1">“这是比珥的儿子巴兰的宣告，</span><br /><span className="pl pl-1">眼睛开启之人的宣告；</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="民数记 24:4; 哥林多前书 8:1; 撒母耳记下 23:1–2"> <span className="pl pl-1">这听到神的话语之人，</span><br /><span className="pl pl-1">明白至高者的知识，</span><br /><span className="pl pl-1">看到全能者的异象，</span><br /><span className="pl pl-1">俯伏着，双眼被开启，</span><br /><span className="pl pl-1">他的宣告如下：</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="启示录 22:16; 路加福音 1:32–33; 创世记 49:10"> <span className="pl pl-1">我看见他，却不是现在；</span><br /><span className="pl pl-1">我望见他，却不在近处。</span><br /><span className="pl pl-1">有一颗星从雅各发出，</span><br /><span className="pl pl-1">有一根杖从以色列兴起；</span><br /><span className="pl pl-1">他将击碎摩押的额角，</span><br /><span className="pl pl-1">击溃所有的谢特人</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="击溃所有的谢特人——有古卷作“打破所有谢特人的头颅”；参《耶利米书》48:45。">d</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="阿摩司书 9:12; 创世记 27:29; 撒母耳记下 8:14"> <span className="pl pl-1">以东将成为他的领地，</span><br /><span className="pl pl-1">他的仇敌西珥将被他占领，</span><br /><span className="pl pl-1">以色列必做大能的事。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="创世记 49:10; 弥迦书 5:2; 诗篇 2:1–12"> <span className="pl pl-1">有一位出自雅各的必执掌大权，</span><br /><span className="pl pl-1">他将灭绝城里的幸存者。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 17:14; 士师记 6:3; 历代志上 4:43"> 然后他观看亚玛力，发布谕示说：<br /><span className="pl pl-1">“亚玛力是列国之首，</span><br /><span className="pl pl-1">但他最终归向灭亡。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="创世记 15:19; 士师记 1:16; 约伯记 29:18"> 巴兰又观看基尼人，发布谕示说：<br /><span className="pl pl-1">“你的住处稳固，</span><br /><span className="pl pl-1">你在岩石中筑巢。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 83:8; 创世记 10:22; 以斯拉记 4:2"> <span className="pl pl-1">然而基尼必被烧毁，</span><br /><span className="pl pl-1">最终亚述要把你掳去。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="民数记 23:23; 玛拉基书 3:2; 列王纪下 5:1"> 巴兰又发布谕示，说：<br /><span className="pl pl-1">“有祸了！</span><br /><span className="pl pl-1">神定意如此，谁能存活呢？</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="创世记 10:4; 民数记 24:20; 但以理书 10:20"> <span className="pl pl-1">有船队从基提海岸而来，</span><br /><span className="pl pl-1">要制伏亚述、制伏希伯，</span><br /><span className="pl pl-1">但它也归向灭亡。”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="民数记 31:8; 约书亚记 13:22; 民数记 24:11"> 然后，巴兰起身离开，回本地去，巴勒也上路回去了。</span>
</div>

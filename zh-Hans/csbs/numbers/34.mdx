<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 17:8; 诗篇 105:11; 申命记 1:7–8"> “你要吩咐以色列子民，对他们说：你们进入迦南地之后分得为继业的迦南之地，其边界如下：</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 14:3; 以西结书 47:13; 约书亚记 3:16"> 你们的南端是从寻的旷野起，沿着以东的边境延伸；南面的边界是从盐海的东边开始。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 32:8; 约书亚记 15:3–4; 民数记 13:26"> 边界从阿克拉宾斜坡的南边转过去，经过寻的旷野，抵达加低斯-巴尼亚南边的尽头，然后延伸到哈萨-阿达尔，再经过阿兹蒙。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 15:4; 创世记 15:18; 列王纪上 8:65"> 边界接着从阿兹蒙转到埃及河，终点是大海<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="大海——指地中海；下同。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约书亚记 1:4; 以西结书 47:20; 以西结书 47:15"> 至于你们西面的边界，是大海和海岸线；这就是你们西面的边界。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="民数记 33:37; 民数记 34:6; 民数记 34:3"> 你们北面的边界如下：从大海开始，划界到何珥山。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 13:21; 列王纪下 14:25; 约书亚记 13:5–6"> 又从何珥山划界到哈马隘口，终点是泽达德。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 47:17"> 边界又延伸到基弗仑，终点是哈萨耶楠。这就是你们北面的边界。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 你们东面的边界，要从哈萨耶楠划界到谢法姆。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 23:33; 申命记 3:17; 约书亚记 11:2"> 边界从谢法姆下到阿音东边的利比拉，然后往下，伸展到革尼勒湖<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="革尼勒湖——指加利利海；又称“革尼撒勒湖、太巴列湖”。">b</a></sup>的东侧。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 34:3; 创世记 13:10; 创世记 19:24–26"> 又下到约旦河，终点是盐海。<br />以上就是你们土地四围的边界。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 34:1; 约书亚记 14:1–5"> 于是，摩西吩咐以色列子民说：“这是你们要以抽签的方式来继承的土地，是耶和华指示要分给九个半支派的。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 32:33; 民数记 32:23; 约书亚记 14:2–3"> 因为鲁本支派按父家取得了他们的继业，迦得支派按父家取得了他们的继业，玛拿西半支派也取得了他们的继业，</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 32:32"> 这两个半支派已经在耶利哥对面，约旦河东边日出的方向，取得了他们的继业。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16"> 耶和华指示摩西说：</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 14:1; 约书亚记 19:51; 民数记 13:8"> “以下是要为你们分配地业之人的名字：祭司以利亚撒，嫩的儿子约书亚。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 1:4–16"> 还要从每支派选出一位领袖，来协助分配土地为继业，</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 26:65; 民数记 13:30; 民数记 14:24"> 这些人的名字是：<br /><span className="pl pl-1">耶弗尼的儿子迦勒，</span><br /><span className="pl pl-1">属犹大支派；</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="创世记 49:5"> <span className="pl pl-1">亚米忽的儿子撒母耳，</span><br /><span className="pl pl-1">属西缅支派；</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="创世记 49:27; 诗篇 68:27"> <span className="pl pl-1">基斯伦的儿子伊利达德，</span><br /><span className="pl pl-1">属便雅悯支派；</span><br /></span>
<span className="v" id="v22" data-v="22"> <span className="pl pl-1">约格利的儿子布其，</span><br /><span className="pl pl-1">是但支派的领袖；</span><br /></span>
<span className="v" id="v23" data-v="23"> <span className="pl pl-1">约瑟子孙以弗的儿子哈尼业，</span><br /><span className="pl pl-1">是玛拿西支派的领袖；</span><br /></span>
<span className="v" id="v24" data-v="24"> <span className="pl pl-1">示弗坦的儿子基姆利，</span><br /><span className="pl pl-1">是以法莲支派的领袖；</span><br /></span>
<span className="v" id="v25" data-v="25"> <span className="pl pl-1">帕尔纳克的儿子以利撒番，</span><br /><span className="pl pl-1">是西布伦支派的领袖；</span><br /></span>
<span className="v" id="v26" data-v="26"> <span className="pl pl-1">阿赞的儿子帕尔提业，</span><br /><span className="pl pl-1">是以萨迦支派的领袖；</span><br /></span>
<span className="v" id="v27" data-v="27"> <span className="pl pl-1">示罗米的儿子亚希忽，</span><br /><span className="pl pl-1">是亚设支派的领袖；</span><br /></span>
<span className="v" id="v28" data-v="28"> <span className="pl pl-1">亚米忽的儿子佩达业，</span><br /><span className="pl pl-1">是拿弗他利支派的领袖。</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约书亚记 19:51; 民数记 34:18"> 以上就是耶和华所吩咐，要在迦南地给以色列子孙分配继业的人。”</span>
</div>

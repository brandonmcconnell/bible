<span className="v" id="v2" data-v="2" data-xref="民数记 28:27; 民数记 28:19; 民数记 29:36"> 你们要献一头公牛、一只公绵羊、七只无瑕疵的一岁公羊羔为燔祭，作馨香之气献给耶和华。</span>
<span className="v" id="v3" data-v="3"> 还有同献的素祭，就是调了油的细面粉：为每头公牛，要献十分之三伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十分之三伊法——相当于6.6公升；本章下同。1伊法=22公升。">a</a></sup>面粉；为每只公绵羊，要献十分之二伊法<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="十分之二伊法——相当于4.4公升；本章下同。1伊法=22公升。">b</a></sup>面粉；</span>
<span className="v" id="v4" data-v="4"> 至于那七只公羊羔，要为每只羊羔献十分之一伊法<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="十分之一伊法——相当于2.2公升；本章下同。1伊法＝22公升。">c</a></sup>面粉。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 28:30; 民数记 28:15; 民数记 28:22"> 还要献一只公山羊作赎罪祭，为你们赎罪。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 28:3–8; 民数记 28:11–15; 民数记 29:18"> 你们要在新月燔祭和同献的素祭、常献的燔祭和同献的素祭，以及照着法规同献的酒祭以外，把这些作为馨香的火祭献给耶和华。</span>
</div>

<span className="v" id="v8" data-v="8" data-xref="民数记 28:19; 民数记 29:13; 民数记 29:2"> 你们要献上一头公牛、一只公绵羊、七只一岁的公羊羔，都必须是无瑕疵的，作为馨香的燔祭献给耶和华。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 15:3–12"> 还有同献的素祭，就是调了油的细面粉：为每头公牛，要献十分之三伊法面粉；为每只公绵羊，要献十分之二伊法面粉；</span>
<span className="v" id="v10" data-v="10"> 至于那七只公羊羔，要为每只羊羔献十分之一伊法面粉。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 16:3; 利未记 16:5; 民数记 28:3–8"> 还要献一只公山羊作赎罪祭。这是在赎罪祭、常献的燔祭和同献的素祭，以及同献的酒祭以外的燔祭。</span>
</div>
<div className="bp">

<span className="v" id="v13" data-v="13" data-xref="民数记 28:11; 以斯拉记 3:4; 民数记 29:2"> 你们要献上十三头公牛、两只公绵羊、十四只一岁的公羊羔，都必须是无瑕疵的，作为燔祭，作为馨香的火祭献给耶和华。</span>
<span className="v" id="v14" data-v="14"> 还有同献的素祭，就是调了油的细面粉：十三头公牛，为每头公牛要献十分之三伊法面粉；两只公绵羊，为每一只公绵羊要献十分之二伊法面粉；</span>
<span className="v" id="v15" data-v="15"> 十四只公羊羔，为每一只羊羔要献十分之一伊法面粉。</span>
<span className="v" id="v16" data-v="16"> 还要献一只公山羊作赎罪祭。这是在常献的燔祭和同献的素祭，以及同献的酒祭以外的燔祭。</span>

<span className="v" id="v18" data-v="18" data-xref="民数记 28:7; 民数记 15:4–12; 民数记 28:14"> 还有为公牛、公绵羊和羊羔同献的素祭和酒祭，都要按数目、照法规献上。</span>

<span className="v" id="v21" data-v="21"> 还有为公牛、公绵羊和公羊羔同献的素祭和酒祭，都要按数目、照法规献上。</span>

<span className="v" id="v24" data-v="24"> 还有为公牛、公绵羊和公羊羔同献的素祭和酒祭，都要按数目、照法规献上。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 13:43; 加拉太书 2:5; 加拉太书 6:9"> 还要献一只公山羊作赎罪祭。这是在常献的燔祭和同献的素祭，以及同献的酒祭以外的燔祭。</span>

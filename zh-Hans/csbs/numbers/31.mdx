<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="NUM" data-book-slug="numbers" data-book-name="民数记" data-chapter="31" data-verses="54">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 27:13; 民数记 25:14–18; 启示录 6:10"> “你要向米甸人报以色列人的仇，然后你将归到你的先人那里。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="利未记 26:25; 民数记 25:11; 列王纪下 10:30"> 摩西就吩咐民众：“你们当中要有一些人武装起来去作战，攻打米甸人，向米甸人施行耶和华的报复。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 26:8; 撒母耳记上 14:6; 士师记 7:2"> 以色列所有支派中，每支派要派遣一千人去作战。”</span>
<span className="v" id="v5" data-v="5"> 于是，从以色列千军中选出了一万两千武装起来作战的人，每支派有一千人。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 14:44; 民数记 10:8–9; 历代志下 13:12–15"> 摩西派他们去作战，每支派有一千人。他们和祭司以利亚撒的儿子非尼哈一起去作战，非尼哈手里带着圣所的器具和发令的号角。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="士师记 21:11; 列王纪上 11:15–16; 撒母耳记上 27:9"> 他们就照着耶和华指示摩西的，与米甸人作战，杀死了米甸所有的男子。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 13:21–22; 民数记 25:15; 启示录 2:14"> 在这些被杀的人以外，他们还杀了米甸的王，就是埃维、利肯、苏珥、户珥、利巴五个米甸王，并且用刀杀了比珥的儿子巴兰。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 20:14; 历代志下 28:8–10; 历代志下 28:5"> 以色列人掳走了米甸人的妇女和孩童，还掠夺了他们所有的牛羊牲畜和财物，</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 1:7; 撒母耳记上 30:1; 约书亚记 6:24"> 又用火烧了他们所住的一切城镇，以及他们所有的营寨。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 20:14; 约书亚记 8:2"> 他们把所有的掠物和所有的掳物，连人和牲畜都带走了。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 22:1"> 他们把俘虏、掳物和掠物都带到营地，就在耶利哥东边约旦河对面的摩押平原那里，带给摩西和祭司以利亚撒以及以色列会众。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 5:2; 撒母耳记上 30:21; 民数记 31:12"> 摩西和祭司以利亚撒，以及所有的会众领袖都出去，到营地外面迎接他们。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 13:19; 撒母耳记上 15:13–14; 民数记 31:48"> 然而，摩西对那些从战阵上回来的军官千夫长和百夫长发怒。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 15:3; 耶利米书 48:10; 申命记 2:34"> 摩西对他们说：“你们怎么让所有的女人都存活呢？</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 25:1–9; 彼得后书 2:15; 启示录 2:14"> 看哪，正是她们按照巴兰的计谋，使以色列子民在毗珥的事情上背叛耶和华，以致瘟疫临到了耶和华的会众！</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 21:11–12; 申命记 20:16–18; 申命记 7:2"> 现在，你们要把米甸所有的男孩杀死，也要把所有与男人同床共寝过的女人杀死；</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 21:10–14; 历代志下 28:8–10; 申命记 20:14"> 只有那些不曾与男人同寝过的女孩，可以让她们存活，归于你们。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="民数记 19:11–22; 民数记 5:2; 历代志上 22:8"> “至于你们，要在营地外停留七天。你们和你们的俘虏，所有杀了人的、所有触碰了被杀之人的，都要在第三天和第七天洁净自己。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 19:22; 创世记 35:2; 出埃及记 19:10"> 你们还要洁净每件衣服、每件皮具、每件羊毛织品和每件木器。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数记 30:16"> 祭司以利亚撒对那些作战回来的军人说：“这是耶和华指示摩西的律法条例：</span>
<span className="v" id="v22" data-v="22"> 唯独金、银、铜、铁、锡、铅，</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 19:9; 民数记 19:17; 哥林多前书 3:13"> 这些经得起火烧的东西，你们要使它们经火洁净，但还要用除污秽的水使它们得洁净；至于那些经不起火烧的，要使它们经水洁净。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 11:25; 利未记 15:13; 利未记 14:9"> 第七天，你们洗衣服，就洁净了，然后可以回营地。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 耶和华指示摩西说：</span>
<span className="v" id="v26" data-v="26"> “你和祭司以利亚撒，以及会众各父系的首领，要统计所掳来的掳物——连人带牲畜的数目。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 22:8; 诗篇 68:12; 撒母耳记上 30:24–25"> 你要在那些出征的战士和全体会众之间，同分掳物。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 18:26; 民数记 31:30; 民数记 31:47"> 你还要从出征的战士所得的人、牛、驴和羊中，每五百个取一个，作为贡物献给耶和华。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 29:27; 申命记 12:19; 申命记 12:12"> 你们要从他们那一半中取出这些，作为献给耶和华的供物交给祭司以利亚撒；</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 3:31; 民数记 3:7–8; 民数记 3:25"> 也要从以色列子孙的这一半中，就是从人、牛、驴、羊以及各样牲畜中，每五十个取一个，交给谨守耶和华帐幕职责的利未人。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31"> 摩西和祭司以利亚撒就照耶和华指示摩西的去做。</span>
<span className="v" id="v32" data-v="32"> 那些掳物，就是军兵所掠夺存留下来的掠物有：<br /><span className="pl pl-1">羊六十七万五千只；</span><br /></span>
<span className="v" id="v33" data-v="33"> <span className="pl pl-1">牛七万两千头；</span><br /></span>
<span className="v" id="v34" data-v="34"> <span className="pl pl-1">驴六万一千匹；</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35"> 人口总共三万两千，都是没有与男人同寝过的女人。</span>
</div>
<div className="bp poetry">
<span className="v" id="v36" data-v="36"> 出征的人分得的那一半：<br /><span className="pl pl-1">羊的数目是三十三万七千五百只，</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v37" data-v="37"> 这些羊中归于耶和华的贡物有六百七十五只；</span>
<span className="v" id="v38" data-v="38"> <span className="pl pl-1">牛三万六千头，</span><br /><span className="pl pl-1">其中归于耶和华的贡物有七十二头；</span><br /></span>
<span className="v" id="v39" data-v="39"> <span className="pl pl-1">驴三万零五百匹，</span><br /><span className="pl pl-1">其中归于耶和华的贡物有六十一匹；</span><br /></span>
<span className="v" id="v40" data-v="40"> <span className="pl pl-1">人口一万六千，</span><br /><span className="pl pl-1">其中归于耶和华的贡物有三十二人。</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数记 18:8; 民数记 18:19; 希伯来书 7:9–12"> 摩西把贡物，就是献给耶和华的供物，交给了祭司以利亚撒，正如耶和华所指示摩西的。</span>
</div>
<div className="bp poetry">
<span className="v" id="v42" data-v="42"> 以色列子孙的那一半，是摩西从作战的人取来分给他们的，</span>
<span className="v" id="v43" data-v="43"> 会众的一半有：<br /><span className="pl pl-1">羊三十三万七千五百只，</span><br /></span>
<span className="v" id="v44" data-v="44"> <span className="pl pl-1">牛三万六千头，</span><br /></span>
<span className="v" id="v45" data-v="45"> <span className="pl pl-1">驴三万零五百匹，</span><br /></span>
<span className="v" id="v46" data-v="46"> <span className="pl pl-1">人口一万六千。</span></span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="民数记 31:30; 路加福音 10:1–8; 以赛亚书 56:10–11"> 摩西从以色列子孙的那一半中，无论是人还是牲畜，每五十个抽出一个，交给了谨守耶和华帐幕职责的利未人，正如耶和华所指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48"> 那些率领千军的军官，就是千夫长、百夫长，来到摩西那里，</span>
<span className="v" id="v49" data-v="49" data-xref="约翰福音 18:9; 撒母耳记上 30:18–19; 诗篇 72:14"> 对摩西说：“你的仆人已经统计了我们手下战士的人数，我们没有少一个人。</span>
<span className="v" id="v50" data-v="50" data-xref="出埃及记 30:12; 出埃及记 30:15–16; 诗篇 116:12"> 我们带来了耶和华的祭物，就是各人所获得的金器——臂环、镯子、戒指、耳环、项链，要在耶和华面前为我们赎罪。”</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="民数记 7:2–6"> 摩西和祭司以利亚撒接受了他们的金器，全都是精工的首饰。</span>
<span className="v" id="v52" data-v="52"> 他们献给耶和华为供物的金子，就是千夫长和百夫长献出的，共有一万六千七百五十谢克尔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一万六千七百五十谢克尔——相当于191公斤。1谢克尔=11.4公克。">a</a></sup>；</span>
<span className="v" id="v53" data-v="53" data-xref="申命记 20:14; 民数记 31:32"> 军人们掠夺的，各归自己。</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及记 30:16; 撒迦利亚书 6:14; 使徒行传 10:4"> 摩西和祭司以利亚撒接受了千夫长和百夫长的金子，带进会幕，为以色列子孙在耶和华面前作记念。</span>
</div>
</div>

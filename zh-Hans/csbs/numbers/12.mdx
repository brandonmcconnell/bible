<span className="v" id="v4" data-v="4" data-xref="诗篇 76:9; 民数记 16:16–21"> 那时，耶和华突然对摩西、亚伦和米利暗说：“你们三个人出来，到会幕那里！”他们三个人就出来。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 11:25; 出埃及记 34:5; 诗篇 99:7"> 耶和华在云柱中降临，停留在会幕入口呼唤亚伦和米利暗，他们两个人就上前来。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 3:5; 创世记 31:10–11; 创世记 46:2"> 耶和华说：<br /><span className="pl pl-1">“你们听我说：</span><br /><span className="pl pl-1">如果你们当中有先知，</span><br /><span className="pl pl-1">我耶和华是在异象中向他显现，</span><br /><span className="pl pl-1">在梦中与他说话。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 3:2–6; 约书亚记 1:1; 诗篇 105:26"> <span className="pl pl-1">但我的仆人摩西不一样，</span><br /><span className="pl pl-1">他在我全家是忠诚的，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="申命记 34:10; 哥林多前书 13:12; 出埃及记 33:11"> <span className="pl pl-1">我是与他面对面说话，</span><br /><span className="pl pl-1">清清楚楚，并不用谜语；</span><br /><span className="pl pl-1">他可以看见耶和华的形象。</span><br /><span className="pl pl-1">你们为什么毁谤我的仆人摩西而不害怕呢？”</span></span>

<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 19:19; 撒母耳记下 24:10; 箴言 30:32"> 亚伦就对摩西说：“哦，我主啊，请不要追究我们在愚昧中所犯的罪。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 88:4–5; 哥林多前书 15:8; 提摩太前书 5:6"> 请不要让她像那出母腹时肉已经腐烂一半的死胎那样。”</span>
</div>

</div>

<span className="v" id="v15" data-v="15" data-xref="申命记 24:8–9; 弥迦书 7:8–9; 弥迦书 6:4"> 于是米利暗被隔离在营地外七天；民众没有前行，直到米利暗被带回来。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 11:35; 民数记 33:18; 民数记 10:12"> 之后民众从哈洗录起行，在帕兰旷野扎营。</span>

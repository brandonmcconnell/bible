<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 77:20; 弥迦书 6:4; 出埃及记 12:51"> 以下是以色列子民在摩西和亚伦的指挥下，按队伍出埃及地的行程。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 9:17–23; 申命记 10:11; 民数记 10:6"> 摩西照着耶和华的指示，记下他们每段行程的起点，以下是他们行程的各起点：</span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="出埃及记 14:8; 出埃及记 12:37; 出埃及记 13:4"> 一月十五日，就是逾越节的第二天，以色列子孙从拉美西斯起程，在全体埃及人眼前昂然无惧地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="昂然无惧地——原文直译“高举着手”。">a</a></sup>出来了。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 12:12; 以赛亚书 19:1; 出埃及记 18:11"> 那时埃及人正在埋葬他们的长子，就是耶和华在他们中间所击杀的；耶和华也对他们的神明施行了审判。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 12:37"> 以色列子孙从拉美西斯起程，在疏割扎营。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 13:20"> <span className="pl pl-1">然后从疏割起行，在旷野边缘的伊坦扎营。</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 14:2; 出埃及记 14:9; 民数记 33:8"> 又从伊坦起行，然后转回到巴力洗分前面的比哈希录，在密夺附近扎营。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 15:22–26; 出埃及记 14:21–31"> 然后从比哈希录前面起行，从海里走过，到了旷野；又在伊坦旷野走了三天的路程，在玛拉扎营。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 15:27"> 再从玛拉起行，来到伊利姆，伊利姆有十二股水泉和七十棵棕榈树；他们在那里扎营。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 16:1; 出埃及记 17:1"> <span className="pl pl-1">然后从伊利姆起行，在红海边扎营。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 16:1"> <span className="pl pl-1">又从红海起行，在汛的旷野扎营。</span><br /></span>
<span className="v" id="v12" data-v="12"> <span className="pl pl-1">然后从汛的旷野起行，在多夫卡扎营。</span><br /></span>
<span className="v" id="v13" data-v="13"> <span className="pl pl-1">又从多夫卡起行，在阿卢什扎营。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="出埃及记 17:1–8; 出埃及记 19:2"> 再从阿卢什起行，在利菲迪姆扎营；<br /><span className="pl pl-1">在那里，百姓没有水喝。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 19:1–2; 出埃及记 16:1"> <span className="pl pl-1">从利菲迪姆起行，在西奈旷野扎营。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="民数记 11:34; 民数记 10:11–13; 民数记 10:33"> <span className="pl pl-1">从西奈旷野起行，在基布罗-哈特瓦扎营。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="民数记 11:35"> <span className="pl pl-1">从基布罗-哈特瓦起行，在哈洗录扎营。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="民数记 12:16"> <span className="pl pl-1">从哈洗录起行，在利提玛扎营。</span><br /></span>
<span className="v" id="v19" data-v="19"> <span className="pl pl-1">从利提玛起行，在临门-法勒斯扎营。</span><br /></span>
<span className="v" id="v20" data-v="20"> <span className="pl pl-1">从临门-法勒斯起行，在立拿扎营。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="申命记 1:1"> <span className="pl pl-1">从立拿起行，在利撒扎营。</span><br /></span>
<span className="v" id="v22" data-v="22"> <span className="pl pl-1">从利撒起行，在克希拉塔扎营。</span><br /></span>
<span className="v" id="v23" data-v="23"> <span className="pl pl-1">从克希拉塔起行，在沙斐山扎营。</span><br /></span>
<span className="v" id="v24" data-v="24"> <span className="pl pl-1">从沙斐山起行，在哈拉达扎营。</span><br /></span>
<span className="v" id="v25" data-v="25"> <span className="pl pl-1">从哈拉达起行，在玛克希录扎营。</span><br /></span>
<span className="v" id="v26" data-v="26"> <span className="pl pl-1">从玛克希录起行，在塔哈特扎营。</span><br /></span>
<span className="v" id="v27" data-v="27"> <span className="pl pl-1">从塔哈特起行，在塔拉扎营。</span><br /></span>
<span className="v" id="v28" data-v="28"> <span className="pl pl-1">从塔拉起行，在米特卡扎营。</span><br /></span>
<span className="v" id="v29" data-v="29"> <span className="pl pl-1">从米特卡起行，在哈什莫纳扎营。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="申命记 10:5–6"> <span className="pl pl-1">从哈什莫纳起行，在莫西洛扎营。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="申命记 10:6; 创世记 36:27; 历代志上 1:43"> <span className="pl pl-1">从莫西洛起行，在比尼-亚干扎营。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="申命记 10:7"> <span className="pl pl-1">从比尼-亚干起行，在霍-哈吉加德扎营。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="申命记 10:7"> <span className="pl pl-1">从霍-哈吉加德起行，在约特瓦塔扎营。</span><br /></span>
<span className="v" id="v34" data-v="34"> <span className="pl pl-1">从约特瓦塔起行，在阿博拿扎营。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="申命记 2:8; 列王纪上 9:26; 列王纪上 22:48"> <span className="pl pl-1">从阿博拿起行，在以旬迦别扎营。</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="民数记 20:1; 民数记 27:14; 申命记 32:51"> <span className="pl pl-1">从以旬迦别起行，在寻的旷野，就是加低斯扎营。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v37" data-v="37" data-xref="民数记 21:4; 民数记 20:22–23; 民数记 20:16"> 然后从加低斯起行，在以东地边界的何珥山扎营。</span>
<span className="v" id="v38" data-v="38" data-xref="申命记 10:6; 申命记 32:50; 民数记 20:24–28"> 以色列子孙出埃及地之后，第四十年的五月一日，祭司亚伦按照耶和华的指示上何珥山，然后死在那里。</span>
<span className="v" id="v39" data-v="39"> 亚伦死在何珥山上的时候，一百二十三岁。</span>
<span className="v" id="v40" data-v="40" data-xref="民数记 21:1–9"> 那时，住在迦南地南方<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="南方——音译作“尼革夫”。">b</a></sup>的迦南王阿拉德，听说以色列人来了。</span>
<span className="v" id="v41" data-v="41" data-xref="民数记 21:4"> <span className="pl pl-1">以色列子孙又从何珥山起行，在撒摩拿扎营。</span><br /></span>
<span className="v" id="v42" data-v="42"> <span className="pl pl-1">然后从撒摩拿起行，在普嫩扎营。</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="民数记 21:10"> <span className="pl pl-1">从普嫩起行，在奥伯特扎营。</span><br /></span>
<span className="v" id="v44" data-v="44" data-xref="民数记 21:11"> <span className="pl pl-1">从奥伯特起行，在摩押边界上的伊耶-亚巴琳扎营。</span><br /></span>
<span className="v" id="v45" data-v="45"> <span className="pl pl-1">从伊音</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="伊音——指伊耶-亚巴琳。">c</a></sup><br /><span className="pl pl-1">起行，在迪本-迦得扎营。</span><br /></span>
<span className="v" id="v46" data-v="46" data-xref="耶利米书 48:18; 以西结书 6:14; 以赛亚书 15:2"> <span className="pl pl-1">从迪本-迦得起行，在阿勒蒙-迪布拉泰姆扎营。</span><br /></span>
<span className="v" id="v47" data-v="47" data-xref="申命记 32:49; 申命记 34:1; 民数记 27:12"> <span className="pl pl-1">从阿勒蒙-迪布拉泰姆起行，在尼波对面的亚巴琳山扎营。</span></span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="民数记 22:1"> 从亚巴琳山起行，在耶利哥东边约旦河对面的摩押平原扎营。</span>
<span className="v" id="v49" data-v="49" data-xref="约书亚记 2:1; 约书亚记 13:20; 民数记 25:1–9"> 他们在摩押平原沿着约旦河扎营，从伯耶西莫直到阿贝勒什亭。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="民数记 33:48–49"> 那时，耶和华在耶利哥东边约旦河对面的摩押平原指示摩西说：</span>
<span className="v" id="v51" data-v="51" data-xref="约书亚记 3:17; 申命记 9:1; 申命记 7:1"> “你要吩咐以色列子民，对他们说：当你们过了约旦河，到迦南地时，</span>
<span className="v" id="v52" data-v="52" data-xref="出埃及记 23:24; 利未记 26:1; 申命记 20:16–18"> 要把那地的居民全都从你们面前赶出去，并且毁掉他们所有的雕像，毁掉他们所铸造的一切偶像，拆毁他们所有的高坛。</span>
<span className="v" id="v53" data-v="53" data-xref="申命记 11:31; 诗篇 115:16; 申命记 32:8"> 你们要占有那地，住在其中，因为我已经把那地赐给你们，让你们继承它。</span>
<span className="v" id="v54" data-v="54" data-xref="民数记 26:53–56; 约书亚记 18:11–48; 约书亚记 15:1–12"> 你们要按家族，以抽签的方式分得那地为继业。人多的，多给他们继业；人少的，少给他们继业；签抽到哪里，哪里就归属那人。你们要按你们的父系支派分得继业。</span>
<span className="v" id="v55" data-v="55" data-xref="士师记 2:3; 诗篇 106:34–36; 申命记 7:16"> 但如果你们不把那地的居民从你们面前赶出去，你所留下的那些人必成为你们眼中的刺、肋旁的荆棘，他们会在你们所住的地上扰害你们；</span>
<span className="v" id="v56" data-v="56" data-xref="路加福音 21:23–24; 申命记 28:63; 利未记 20:23"> 而且，我曾怎样计划对待他们，也将怎样对待你们。”</span>
</div>
</div>

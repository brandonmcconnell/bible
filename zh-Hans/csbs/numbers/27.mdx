<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 26:33; 加拉太书 3:28; 历代志上 7:15"> 那时，西罗非哈的女儿们上前来——西罗非哈是希弗的儿子、基列的孙子、玛吉的曾孙、玛拿西的玄孙，属于约瑟儿子玛拿西的家族；他女儿的名字是：玛拉、挪阿、霍格拉、米尔卡、提尔撒——</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 15:33–34; 申命记 17:8–10; 出埃及记 18:19–26"> 她们站在会幕的入口，在摩西、祭司以利亚撒和领袖们，以及全体会众面前说：</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 26:64–65; 以西结书 18:4; 民数记 14:35"> “我们的父亲死在旷野，他不在那些聚众反对耶和华的一伙人当中，不属于可拉同党，而是因自己的罪过死了；他没有儿子。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 17:4; 诗篇 109:13; 出埃及记 32:11"> 为什么因我们的父亲没有儿子，就要把他的名字从他家族中除去呢？求你在我们父亲的兄弟中分给我们一份地业。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="利未记 24:12–13; 约伯记 23:4; 箴言 3:5–6"> 摩西就把她们的案件呈到耶和华面前。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 3:28; 诗篇 68:5–6"> 耶和华告诉摩西说：</span>
<span className="v" id="v7" data-v="7" data-xref="加拉太书 3:28; 耶利米书 49:11; 约书亚记 17:4"> “西罗非哈的女儿们说得对，你一定要在她们父亲的兄弟中分给她们一份可继承的地业，把她们父亲的继业转给她们。</span>
<span className="v" id="v8" data-v="8"> 你还要吩咐以色列子民说：如果一个人死了，并且没有儿子，就要把他的继业转给他的女儿。</span>
<span className="v" id="v9" data-v="9"> 如果他没有女儿，就要把他的继业转给他的兄弟。</span>
<span className="v" id="v10" data-v="10"> 如果他没有兄弟，就要把他的继业转给他父亲的兄弟。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 35:29; 路得记 4:3–6; 耶利米书 32:8"> 如果他父亲也没有兄弟，就要把他的继业给他家族中与他最近的亲属，那人可以拥有这继业。”这要成为以色列子孙的律例法规，正如耶和华所指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数记 33:47–48; 申命记 34:1–4; 申命记 3:23–27"> 耶和华对摩西说：“你到这亚巴琳山上去，观看我赐给以色列子孙的土地。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 10:6; 民数记 31:2; 民数记 20:24–28"> 你观看了那地之后，你也要归到你的先人那里，像你的哥哥亚伦归到先人那里一样。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 1:37; 民数记 20:8–13; 出埃及记 17:7"> 因为在寻的旷野，当会众争闹时，你们违背了我的命令，没有在那水边在他们眼前尊我为圣。”那水就是寻的旷野中的米利巴-加低斯水。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 于是，摩西请求耶和华说：</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 16:22; 耶利米书 3:15; 希伯来书 12:9"> “愿耶和华——那使一切肉体有气息<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="使一切肉体有气息——或译作“赐予全人类气息”。">a</a></sup>的神，指派一个人管理会众，</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 34:5; 马可福音 6:34; 列王纪上 22:17"> 这人要在他们前面出入。他要带领他们出入，以免耶和华的会众像没有牧人的羊群那样。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命记 34:9; 民数记 27:23; 创世记 41:38"> 耶和华就对摩西说：“你把嫩的儿子约书亚带来，他是一个心中有圣灵的人。你要按手在他头上，</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 3:28; 申命记 31:7–8; 申命记 31:23"> 让他站在祭司以利亚撒和全体会众面前，在他们眼前任命他；</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 1:16–18; 撒母耳记上 10:9; 列王纪下 2:9–10"> 并将你的一些尊荣加给他，好让全体以色列会众都听从他。</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 9:14; 撒母耳记上 28:6; 出埃及记 28:30"> 他要站在祭司以利亚撒面前；以利亚撒要在耶和华面前凭借乌陵的裁决为他求问。约书亚和所有与他一起的以色列子民，就是全体会众，都要照着以利亚撒的命令出入。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 摩西就照着耶和华所指示的去做。他把约书亚带来，让他站在祭司以利亚撒和全体会众面前，</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 3:28; 民数记 27:19; 申命记 31:7–8"> 按手在他头上，任命他，正如耶和华藉着摩西所说的。</span>
</div>
</div>

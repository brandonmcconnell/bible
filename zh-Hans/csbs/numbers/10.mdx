<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 1:13; 约珥书 1:14; 诗篇 81:3"> “你要制作两支银号筒，用锤擛工艺制作，用来聚集会众，也用来拔营起行。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 4:5; 约珥书 2:15–16"> 当两支号筒吹响时，全体会众要到你那里，在会幕入口集合；</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 7:2; 出埃及记 18:21; 民数记 1:4–16"> 如果只吹响一支，领袖们，就是以色列千军的首领，要到你那里集合。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民数记 2:3–9; 民数记 10:14; 以赛亚书 58:1"> “当你们吹响警号时，扎营在东面的营队要起行。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 10:18; 民数记 2:10–16"> 当你们第二次吹响警号时，扎营在南面的营队要起行。让会众起程时，要吹响警号，</span>
<span className="v" id="v7" data-v="7" data-xref="约珥书 2:1; 民数记 10:3–4"> 招聚会众时也要吹号，但不要吹警号。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 6:4–16; 民数记 31:6; 历代志上 15:24"> 那些作祭司的亚伦子孙要吹响号筒。这要作为你们世世代代永远的律例。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 10:18; 士师记 2:18; 创世记 8:1"> “当你们在自己的土地上，与扰害你们的敌人作战时，你们要用号筒吹警号。这样，你们就能在你们的神耶和华面前蒙记念，得拯救，脱离你们的仇敌。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 81:3; 帖撒罗尼迦前书 4:16; 哥林多前书 11:24–26"> 在你们喜乐的日子和所定的节期，以及月初，你们要为你们的燔祭和平安祭吹响号筒。这样，它们就使你们在你们的神面前蒙记念。我是耶和华你们的神。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出埃及记 40:17; 民数记 1:1; 民数记 9:11"> 到了第二年的二月二十日，云彩从见证帐幕上方收上去了；</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 21:21; 民数记 12:16; 民数记 9:5"> 以色列子民从西奈旷野起行，一程一程地前行，云彩到帕兰旷野就停住了。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 1:6; 民数记 9:23"> 这是他们第一次按照耶和华藉着摩西所指示的起行。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 2:3–9; 民数记 1:7; 民数记 7:12"> 首先按队伍起行的，是犹大子孙营队的旗帜。统领犹大队伍的，是亚米拿达的儿子拿顺；</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 7:18; 民数记 1:8"> 统领以萨迦支派队伍的，是苏押的儿子拿旦业。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 7:24; 民数记 1:9"> 统领西布伦支派队伍的，是希伦的儿子以利押。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 7:6–8; 民数记 1:51; 希伯来书 12:28"> 然后，帐幕被拆下来，革顺的子孙和米拉利的子孙抬着帐幕起行。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民数记 2:10–16; 民数记 1:5; 民数记 26:5–18"> 接着按队伍起行的，是鲁本营队的旗帜。统领鲁本队伍的，是谢德珥的儿子以利佐；</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 1:6; 民数记 7:36"> 统领西缅支派队伍的，是苏利沙代的儿子谢路米业；</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 1:14; 民数记 2:14; 民数记 7:42"> 统领迦得支派队伍的，是德珥的儿子以利雅萨。</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 10:17; 民数记 7:9; 民数记 4:4–16"> 然后，哥辖人抬着圣物起行，帐幕要在他们到达之前立起来。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数记 2:18–24; 民数记 1:10; 民数记 26:23–41"> 接着按队伍起行的，是以法莲子孙营队的旗帜。统领以法莲队伍的，是亚米忽的儿子以利沙玛；</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 1:10; 民数记 7:54"> 统领玛拿西支派队伍的，是佩达佐的儿子迦玛列；</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 1:11; 民数记 7:60"> 统领便雅悯支派队伍的，是基多尼的儿子亚比但。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约书亚记 6:9; 民数记 1:12; 创世记 49:16–17"> 最后按队伍起行的，是但子孙营队的旗帜，他们作全营的后卫队。统领他们队伍的，是亚米沙代的儿子亚希以谢；</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 1:13; 民数记 7:72"> 统领亚设支派队伍的，是俄兰的儿子帕结；</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 1:15; 民数记 7:78"> 统领拿弗他利支派队伍的，是恩南的儿子亚希拉。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 2:34; 民数记 24:4–5; 哥林多前书 14:33"> 以上是以色列子孙按着队伍的起程次序，他们就这样起行。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="创世记 12:7; 士师记 4:11; 出埃及记 3:1"> 那时，摩西对他岳父米甸人流珥的儿子何巴说：“我们要起行，去耶和华所说‘我要将它赐给你们’的那个地方，请你与我们一起去，我们会厚待你，耶和华已经向以色列应许了福份。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路得记 1:15–17; 诗篇 45:10; 马太福音 21:29"> 何巴回答说：“我不去，我宁愿回我本地本族去。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约伯记 29:15; 加拉太书 6:2; 哥林多前书 12:14–21"> 摩西说：“请不要离开我们，因为你了解旷野扎营的地方，可以作我们的向导<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="向导——原文直译“眼睛”。">a</a></sup>；</span>
<span className="v" id="v32" data-v="32" data-xref="士师记 1:16; 申命记 10:18; 约翰一书 1:3"> 而且如果你与我们一起去，将来耶和华赐下福份，使我们蒙福，我们也必使你一同蒙福。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="申命记 1:33; 出埃及记 3:1; 诗篇 95:11"> 于是，他们离开耶和华的山，前行了三天的路程。这三天的路程中，耶和华的约柜一直在他们前头前行，为他们寻找安歇的地方。</span>
<span className="v" id="v34" data-v="34" data-xref="尼希米记 9:12; 尼希米记 9:19; 诗篇 105:39"> 他们从营地起行，白天总有耶和华的云彩在他们上方。</span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="诗篇 68:1–2; 以赛亚书 17:12–14; 诗篇 132:8"> 每当约柜起行时，摩西就说：<br /><span className="pl pl-1">“耶和华啊，求你起来！</span><br /><span className="pl pl-1">愿你的仇敌四散，</span><br /><span className="pl pl-1">愿那些恨你的人从你面前奔逃！”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v36" data-v="36" data-xref="申命记 1:10; 诗篇 90:13–17; 以赛亚书 63:17"> 每当约柜停下来，他就说：<br /><span className="pl pl-1">“耶和华啊，</span><br /><span className="pl pl-1">求你回到千千万万以色列人当中</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="耶和华啊，求你回到千千万万以色列人当中——或译作“耶和华，以色列的万军啊，求你回来”。">b</a></sup><br /><span className="pl pl-1">！”</span></span>
</div>
</div>

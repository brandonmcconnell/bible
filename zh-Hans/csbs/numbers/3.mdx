<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 6:20; 创世记 10:1; 出埃及记 6:16"> 以下是亚伦和摩西的家系记事，那时耶和华在西奈山向摩西说话。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="出埃及记 6:23; 民数记 26:60; 出埃及记 28:1"> 亚伦儿子们的名字是：长子纳达布，还有亚比户、以利亚撒、以塔玛尔。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 28:41; 利未记 8:30; 利未记 8:12"> 这些是亚伦儿子们的名字，他们是受膏的祭司，摩西使他们承接圣职作祭司。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 10:1–2; 民数记 26:61"> 纳达布和亚比户在西奈旷野向耶和华献上违规的火，就死在耶和华面前；他们没有儿子。以利亚撒和以塔玛尔在父亲亚伦面前<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="面前——或译作“活着时”。">a</a></sup>作祭司。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 耶和华指示摩西说：</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 10:8; 民数记 2:33; 民数记 1:49–53"> “你要让利未支派上前来，侍立在祭司亚伦面前，辅助他。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 1:50; 民数记 8:15; 民数记 8:11"> 他们要在会幕前为亚伦和全体会众谨守职责，做帐幕的服事工作。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 4:33; 民数记 10:17; 以赛亚书 52:11"> 他们也要看管会幕的所有器具，并且为以色列子民谨守职责，做帐幕的服事工作。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 8:19; 民数记 18:6–7; 以弗所书 4:8"> 你要把利未人指派给亚伦和他的儿子们，这是从以色列子孙中特别指派给他们的。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 1:51; 民数记 3:38; 罗马书 12:7"> 你要指派亚伦和他的儿子们谨守他们祭司的职份；接近帐幕的外人，必须被处死。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和华又指示摩西说：</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 3:41; 民数记 8:16; 民数记 18:6"> “看哪，我已经从以色列子孙中拣选了利未人，代替以色列子孙中所有头生的长子，所以利未人要归属我。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 2:23; 出埃及记 13:12; 出埃及记 13:2"> 因为所有头生的都属于我；埃及地所有头生的被我击杀那天，我已经使以色列所有头生的，无论是人还是牲畜，都分别为圣归于我了，他们是属于我的。我是耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 耶和华在西奈旷野指示摩西说：</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 26:62; 马可福音 10:14; 提摩太后书 3:15"> “你要按父家和家族数点利未子孙；所有一个月以上的男性，你都要数点。”</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 3:39; 民数记 4:37; 民数记 4:49"> 摩西就按照耶和华的命令，照着所受的指示数点他们。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 46:11; 出埃及记 6:16–19; 民数记 15:5–23"> 以下是利未儿子们的名字：革顺，哥辖，米拉利。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 6:17; 历代志上 26:1–32; 出埃及记 6:17–19"> 革顺儿子的名字，按家族是立尼、示每。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 6:18; 历代志上 6:18; 历代志上 15:17–21"> 哥辖的儿子，按家族是阿姆兰、以斯哈、希伯伦、乌基业。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 6:19; 历代志上 6:19; 民数记 3:33"> 米拉利的儿子，按家族是玛赫利、穆希。这些是利未人的家族，各按他们的父家。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 属革顺的，有立尼家族和示每家族；这些是革顺的家族。</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 4:38–40"> 他们被数点的，是所有一个月以上男性的数目，被数点的共七千五百人。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 1:53; 民数记 2:17"> 革顺家族要在帐幕后面靠西边扎营，</span>
<span className="v" id="v24" data-v="24"> 革顺人的父家领袖是拉伊勒的儿子以利雅萨。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 25:9; 历代志上 23:32; 历代志上 9:14–33"> 革顺子孙在会幕中负责：帐幕，罩篷，罩篷的顶罩，会幕入口的帘幕，</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 35:18; 出埃及记 38:9–16; 出埃及记 27:9–16"> 院子的帷幔，在帐幕和祭坛四围的院子入口的帘幕，它们的绳子，以及相关的一切工作。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="历代志上 26:23; 民数记 3:19; 历代志上 23:12"> 属哥辖的，有阿姆兰家族、以斯哈家族、希伯伦家族、乌基业家族；这些是哥辖的家族。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 3:31; 民数记 4:35–36; 民数记 3:7"> 所有一个月以上男性的数目，共八千六百<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="八千六百——或译作“八千三百”。">b</a></sup>人；他们要谨守圣所的职责。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 1:53; 民数记 3:23; 民数记 2:10"> 哥辖子孙的家族要在帐幕南边扎营，</span>
<span className="v" id="v30" data-v="30"> 哥辖家族的父家领袖是乌基业的儿子以利撒番。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 36:35–36; 出埃及记 27:1–8; 出埃及记 26:31–33"> 他们负责：约柜，桌子，灯台，祭坛和香坛，事奉用的圣所器具，帘幕，以及相关的一切工作。</span>
<span className="v" id="v32" data-v="32" data-xref="民数记 4:27; 民数记 4:16; 民数记 20:25–28"> 利未人众领袖的主管是祭司亚伦的儿子以利亚撒，他是那些谨守圣所职责之人的监督。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="民数记 3:20; 历代志上 6:19; 历代志上 23:21"> 属米拉利的，有玛贺利家族和穆希家族；这些是米拉利的家族。</span>
<span className="v" id="v34" data-v="34" data-xref="民数记 2:9; 民数记 2:11; 民数记 1:21"> 他们被数点的，所有一个月以上男性的数目，共六千两百人。</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 1:53; 民数记 2:25; 民数记 3:28–29"> 米拉利家族的父家领袖是亚比亥的儿子苏列，他们要在帐幕北边扎营。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 26:32; 出埃及记 26:37; 出埃及记 26:15–29"> 米拉利子孙所负责的是：帐幕的木板，门闩，柱子，底座，帐幕的所有器具，以及相关的一切工作，</span>
<span className="v" id="v37" data-v="37"> 还有院子四围的柱子和它们的底座、橛子、绳子。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="民数记 3:10; 民数记 1:53; 民数记 2:3"> 在帐幕前面朝东，就是在会幕前面日出方向扎营的，是摩西和亚伦以及亚伦的儿子们。他们为圣所和以色列子民谨守职责<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="为圣所和以色列子民谨守职责——或译作“代表以色列子民谨守圣所的职责”。">c</a></sup>。接近帐幕的外人，必须被处死。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="民数记 26:62; 马太福音 7:14; 民数记 4:47–48"> 所有被数点的利未人，就是摩西和亚伦按照耶和华的指示、按家族数点的，所有一个月以上的男性，总共两万两千人。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="民数记 3:15; 路加福音 10:20; 诗篇 87:6"> 耶和华对摩西说：“你要数点以色列子孙中所有一个月以上的头生男性，按名单统计他们。</span>
<span className="v" id="v41" data-v="41" data-xref="民数记 3:12; 民数记 3:45; 民数记 8:16"> 我是耶和华，你要拣选利未人归于我，代替以色列子孙所有头生的；并要用利未人的牲畜，代替以色列子孙所有头生的牲畜。”</span>
<span className="v" id="v42" data-v="42"> 摩西就照着耶和华所指示的，数点以色列子孙中所有头生的。</span>
<span className="v" id="v43" data-v="43" data-xref="民数记 3:39"> 按名单，所有一个月以上的头生男性，被数点的有两万两千两百七十三人。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44"> 耶和华指示摩西说：</span>
<span className="v" id="v45" data-v="45" data-xref="民数记 3:12; 民数记 3:40–41"> “你要拣选利未人，代替以色列子孙中所有头生的；并要用利未人的牲畜，代替以色列子孙的牲畜。利未人要归于我，我是耶和华。</span>
<span className="v" id="v46" data-v="46" data-xref="出埃及记 13:13; 民数记 18:15–16"> 以色列子孙头生的男子比利未人多出了两百七十三人，他们的赎价，</span>
<span className="v" id="v47" data-v="47" data-xref="出埃及记 30:13; 利未记 27:6; 民数记 18:16"> 你要每人收取五谢克尔，按圣所的谢克尔<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="谢克尔——重量单位；后来成为货币单位。1谢克尔=11.4公克。本章下同。">d</a></sup>标准收取，一谢克尔是二十季拉<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="二十季拉——相当于11.4公克。1季拉=0.57公克。">e</a></sup>。</span>
<span className="v" id="v48" data-v="48"> 你要把银子，就是多出来之人的赎价，交给亚伦和他的儿子们。”</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49"> 摩西就在利未人所赎的人以外，向多出来的人收取赎价的银子。</span>
<span className="v" id="v50" data-v="50" data-xref="民数记 3:46–47; 彼得前书 3:18; 马太福音 20:28"> 他从这些以色列子孙的头生子那里收取了银子，按圣所的谢克尔标准，共一千三百七十五谢克尔<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一千三百七十五谢克尔——相当于15.7公斤。1谢克尔=11.4公克。">f</a></sup>。</span>
<span className="v" id="v51" data-v="51" data-xref="民数记 3:48; 民数记 16:15; 撒母耳记上 12:3–4"> 摩西按照耶和华的吩咐，把赎价银子交给了亚伦和他的儿子们，正如耶和华所指示摩西的。</span>
</div>
</div>

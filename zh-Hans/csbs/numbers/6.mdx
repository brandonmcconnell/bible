<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 13:5; 阿摩司书 2:11–12; 罗马书 1:1"> “你要吩咐以色列子民，对他们说：如果有男人或女人许了特殊的愿，就是拿细耳人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="拿细耳人——意思是“分别出来的人”；本章下同。">a</a></sup>的愿，为要离俗归于耶和华，</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:15; 提摩太前书 5:23; 阿摩司书 2:12"> 他就要远离淡酒烈酒，也不可喝淡酒烈酒做的醋。任何葡萄汁，他都不可喝；鲜的或干的葡萄，他也不可吃。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 6:5; 民数记 6:21; 民数记 6:8–9"> 在他离俗的所有日子，凡是葡萄树所出产的，甚至是葡萄籽或葡萄皮的产物，他都不可吃。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 1:11; 士师记 16:17; 士师记 13:5"> “在他许愿离俗的所有日子，他都不可用剃刀剃他的头。他要分别为圣，任由头发变长，直到他离俗归于耶和华的日子满了。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 21:11; 利未记 19:28; 利未记 21:1–3"> 他在离俗归于耶和华的所有日子，都不可接近死人的尸体。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 9:6; 利未记 21:1–2; 利未记 21:10–12"> 即使那是他的父母、兄弟或姐妹，当他们死的时候，他也不可为他们玷污自己，因为离俗归神的标记在他头上。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 6:17–18"> 在他离俗的所有日子，他都是归耶和华为圣的。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数记 6:18; 使徒行传 18:18; 利未记 14:9"> “如果有人突然死在他旁边，以致玷污了他离俗的头，他就要在第七天，在得洁净的日子剃头。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 15:29; 利未记 1:14; 利未记 15:14"> 在第八天，他要把两只斑鸠或两只雏鸽带到会幕入口给祭司。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 14:30–31; 利未记 5:8–10"> 祭司要献一只作赎罪祭，一只作燔祭，为他赎那因尸体而带来的罪污。当天，他要使他的头重新分别为圣，</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 5:6; 马太福音 24:13; 利未记 14:24"> 重新把离俗的日子献给耶和华，并且带来一只一岁的公羊羔作赎愆祭；先前的那些日子失效了，因为他的离俗已经被玷污。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 21:26"> “拿细耳人有以下条例：在他离俗的日子满了那天，要让他来到会幕入口。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 3:6; 利未记 4:32; 利未记 4:2–3"> 他要向耶和华献上他的祭物，一只无瑕疵的一岁公羊羔作燔祭，一只无瑕疵的一岁母羊羔作赎罪祭，一只无瑕疵的公绵羊作平安祭，</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 2:4; 出埃及记 29:2; 民数记 15:10"> 还有一篮子调了油的无酵细面饼和抹了油的无酵薄饼，以及同献的素祭和酒祭。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> “祭司要把这些祭物带到耶和华面前，献上那人的赎罪祭和燔祭，</span>
<span className="v" id="v17" data-v="17"> 并将那只公绵羊连同那一篮子无酵饼献给耶和华作平安祭，还要献上同献的素祭和酒祭。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行传 21:24; 民数记 6:9; 使徒行传 18:18"> “拿细耳人要在会幕入口剃自己离俗的头，把他的离俗头发拿去，放在平安祭下的火中。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 2:15; 利未记 7:30; 出埃及记 29:23–28"> 他剃了自己离俗的头之后，祭司要取出煮过的公绵羊前腿，并从篮子里取出一个无酵饼和一个无酵薄饼，放在这拿细耳人手掌上。</span>
<span className="v" id="v20" data-v="20" data-xref="传道书 9:7; 出埃及记 29:27–28; 民数记 5:25"> 然后祭司要把它们作为摇献祭物，在耶和华面前摇一摇；这些连同摇献祭物的胸肉以及供物的大腿，都是归于祭司的圣物。之后拿细耳人就可以喝酒了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="希伯来书 13:16; 以斯拉记 2:69; 民数记 5:29"> “这是拿细耳人的条例。如果他在离俗许愿之外，还向耶和华许愿献上他所能负担的祭物，他就要在离俗条例之外，也按照所许的愿去做。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22"> 耶和华指示摩西说：</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 21:5; 历代志上 23:13; 创世记 48:20"> “你要吩咐亚伦和他的儿子们，要这样祝福以色列子民，对他们说：</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦前书 5:23; 诗篇 121:4–7; 腓立比书 4:7"> <span className="pl pl-1">愿耶和华祝福你，保守你；</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 80:19; 诗篇 119:135; 诗篇 31:16"> <span className="pl pl-1">愿耶和华使他的脸光照你，恩待你；</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 4:6; 诗篇 29:11; 帖撒罗尼迦后书 3:16"> <span className="pl pl-1">愿耶和华向你显出笑容，赐你平安。</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="历代志下 7:14; 但以理书 9:18–19; 申命记 28:10"> 他们要这样把我的名安置在以色列子民身上，我就祝福他们。”</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 28:38; 希伯来书 13:17; 彼得前书 2:24"> 于是，耶和华对亚伦说：“你和你的儿子们以及你的父家，要一同承担与圣所相关的罪责；你和你的儿子们，要一同承担与你们祭司职份相关的罪责。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 29:34; 民数记 18:4; 以西结书 44:15"> 你还要带你利未支派的弟兄，就是你父系支派的人，与你一同上前事奉。他们要从属你，辅助你。当你和你的儿子们一同在见证会幕前面时，</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 4:15; 民数记 16:40; 民数记 4:19–20"> 他们要为你和整个会幕谨守职责，只是他们不可靠近圣所的器具和祭坛，以免他们和你们都死亡。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 6:19; 民数记 1:51; 民数记 3:10"> 他们要从属你，为帐幕的一切服事谨守会幕的职责；外人不可靠近你们。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及记 27:21; 利未记 24:3; 民数记 16:46"> “你们要谨守圣所的职责和祭坛的职责，以免震怒再临到以色列子孙。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 3:9; 民数记 3:12; 民数记 3:45"> 看哪，我已经从以色列子孙中拣选了你的弟兄利未人，赏赐给你们，献于耶和华做会幕的服事工作。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 15:15–16; 约翰福音 3:27; 民数记 3:10"> 你和你的儿子们要为祭坛和幔子内的一切事务，谨守祭司的职份，做好服事。我把祭司职份作为服事工作赏赐给你们，凡是接近的外人，都要被处死。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未记 6:16; 利未记 7:6; 出埃及记 29:29"> 耶和华又对亚伦说：“看哪，我已经把奉献供物的职责交给了你。至于以色列子孙所有的圣物，我把它们赐给你作受膏的份，也给你的儿子们作永远的份例。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 7:7; 利未记 14:13; 利未记 6:25–26"> 人们带来献给我的至圣物，就是所有的祭物，包括所有的素祭、所有的赎罪祭、所有的赎愆祭，其中没有烧献的要归属你；这些是至圣的，归于你和你的子孙。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 7:6; 利未记 6:29; 利未记 6:16"> 你要把它作为至圣物吃，只有男的才可以吃；你要把它当作神圣的。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="申命记 18:3; 出埃及记 29:27–28; 利未记 10:14"> “以色列子孙奉献的供物，就是他们所有的摇献祭物，也归于你；我把它们赐给你和与你一起的儿女们，作永远的份例，你家里所有洁净的人都可以吃。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 18:4; 出埃及记 23:19; 出埃及记 34:26"> 所有最好的新油、最好的新酒，以及人们献给耶和华的初熟五谷，我也赐给你。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 22:29; 出埃及记 23:19; 弥迦书 7:1"> 他们地里的一切初熟之物，就是他们带来献给耶和华的，都归属你。你家里所有洁净的人都可以吃。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="利未记 27:28; 以西结书 44:29"> “以色列中一切永献之物都归属你。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 34:20; 出埃及记 13:2; 出埃及记 13:12–13"> 他们向耶和华献上的所有头胎的活物，无论是人还是牲畜，都归属你。只是你必须让他们把头生的人赎回，还有头生的不洁净牲畜，也要赎回。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 30:13; 民数记 3:47; 利未记 27:2–7"> 出生一个月以后要赎回的，要照你所估的价，用五谢克尔银子赎回；按圣所的谢克尔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="谢克尔——重量单位；后来成为货币单位。1谢克尔=11.4公克。">a</a></sup>标准，一谢克尔是二十季拉<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="二十季拉——相当于11.4公克。1季拉=0.57公克。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及记 29:16; 申命记 15:19–22; 利未记 3:2–5"> “但是头生的公牛，或头生的绵羊，或头生的山羊，不可赎回；它们是圣物。你要把它们的血洒在祭坛上，把它们的脂肪烧献为火祭，作馨香之气献给耶和华。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 7:31–34; 出埃及记 29:26–28"> 它们的肉要归属你，就像摇献祭物的胸肉和右腿一样归属你。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="历代志下 13:5; 利未记 2:13; 民数记 18:11"> “以色列子孙向耶和华奉上的一切神圣供物，我都赐给你和与你一起的儿女们，作永远的份例。这是你和与你一起的后裔在耶和华面前永远的盐约。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西结书 44:28; 申命记 10:9; 约书亚记 13:33"> 耶和华对亚伦说：“你不可在以色列子孙的土地中分得继业，你在他们中间没有继业的份。在以色列子孙中，我就是你的份，你的产业。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="尼希米记 12:44; 申命记 14:22–29; 尼希米记 10:37"> “至于利未的子孙，看哪，我把以色列中所有出产的十分之一赐给了他们为产业，回报他们所做的会幕服事工作。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 22:9; 民数记 1:51–52; 民数记 3:38"> 以色列子孙不可再靠近会幕，以免他们承担罪过而死。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 3:7; 民数记 18:20; 民数记 18:1"> 利未人要做会幕的服事工作，他们要承担与圣所相关的罪责。这是你们世世代代永远的律例：他们不可在以色列子孙中分得继业。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 18:26; 玛拉基书 3:8–10"> 因为我已经把以色列子孙的十分之一出产，就是他们向耶和华奉上的供物，赐给了利未人作产业。因此我对他们说，他们不可在以色列子孙中分得继业。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 耶和华指示摩西说：</span>
<span className="v" id="v26" data-v="26" data-xref="尼希米记 10:38; 民数记 18:21"> “你要吩咐利未人，对他们说：当你们从以色列子孙获得了我所赐给你们的那十分之一出产为产业，你们要再从那十分之一中奉上十分之一，作为献给耶和华的供物。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 18:30; 申命记 15:14; 列王纪下 6:27"> 这算为你们奉献的供物，就像你们打谷场上的五谷，酒榨中满盈的酒一样。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 6:20–10; 创世记 14:18"> 这样，你们从以色列子孙获得的全部十分之一出产，也要从中奉上耶和华的供物，把这份献给耶和华的供物交给祭司亚伦。</span>
<span className="v" id="v29" data-v="29"> 你们要从你们的一切礼物中，从一切最好的、至圣的部分中，奉上耶和华的各样供物。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="箴言 3:9–10; 创世记 43:11; 马太福音 6:33"> “你要对利未人说：‘当你们从其中把最好的奉献之后，其余的就算为利未人的，就像打谷场的收成和酒榨的收成。</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多前书 9:10–14; 提摩太前书 5:17–18; 路加福音 10:7"> 你们和你们的家人可以在任何地方吃它，因为这是你们的酬报，以回报你们在会幕里的服事。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 19:8; 利未记 22:2; 玛拉基书 1:7"> 当你们把其中最好的奉献之后，你们就不会因它而承担罪过了；你们不可亵渎以色列子孙的圣物，免得你们死亡。”</span>
</div>
</div>

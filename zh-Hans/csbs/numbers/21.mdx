<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 1:16; 民数记 33:40; 约书亚记 12:14"> 迦南的阿拉德王住在南地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="南地——音译作“内盖夫”。">a</a></sup>，听说以色列沿着通往阿塔林的路来了，就攻打以色列，俘虏了他们一些人。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 11:30; 创世记 28:20; 撒母耳记上 1:11"> 以色列向耶和华许愿说：“如果你把这民确实交在我手中，我就把他们的城镇都毁灭净尽。”</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 14:45; 申命记 1:44; 诗篇 10:17"> 耶和华垂听了以色列的祈求，交出迦南人。以色列人把他们和他们的城镇都毁灭净尽，那地方就被起名为“霍尔玛”。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及记 6:9; 士师记 11:18; 民数记 32:7"> 他们离开何珥山，沿着通往红海的路前行，要绕过以东地，民众在路上失去耐心。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 78:19; 民数记 16:13–14; 出埃及记 17:2–3"> 民众攻击神和摩西说：“你们为什么把我们从埃及带上来，使我们死在旷野呢？这里既没有食物，也没有水，我们的心也厌烦了这淡而无味的食物！”</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 10:9; 耶利米书 8:17; 申命记 8:15"> 于是耶和华派出毒蛇<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="毒蛇——或译作“火蛇”；本章下同。">b</a></sup>到民众当中咬他们，以色列死了许多人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行传 8:24; 民数记 11:2; 诗篇 78:34"> 民众来见摩西，说：“我们犯罪了，我们攻击了耶和华和你。求你向耶和华祷告，让蛇离开我们。”于是摩西就为民众祷告。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约翰福音 3:14; 诗篇 106:43–45; 诗篇 145:8"> 耶和华对摩西说：“你要铸造一条毒蛇，挂在旗杆上。凡是被咬的人，一看见它就能存活。”</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 3:14–15; 希伯来书 12:2; 约翰福音 6:40"> 摩西就铸造了一条铜蛇，挂在旗杆上。凡是被蛇咬了的人，只要仰望那铜蛇，就得以存活。</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="民数记 33:43–45"> 以色列子民起行，扎营在奥伯特。</span>
<span className="v" id="v11" data-v="11"> 又从奥伯特起行，扎营在伊耶-亚巴琳，就在摩押东面的旷野。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 2:13–14"> 又从那里起行，扎营在撒烈溪谷。</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 11:18; 民数记 22:36; 以赛亚书 16:2"> 又从那里起行，扎营在亚嫩河对岸。这条河在旷野中，从亚摩利人的边界流出来；亚嫩河就是摩押的边界，位于摩押和亚摩利之间。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 10:13; 撒母耳记下 1:18"> 因此在《耶和华战记》上说：<br /><span className="pl pl-1">“苏法的哇哈伯，亚嫩河的溪谷，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="民数记 21:28; 申命记 2:18; 申命记 2:9"> <span className="pl pl-1">以及往亚珥居住地延伸的溪谷斜坡，</span><br /><span className="pl pl-1">都紧靠摩押的边界。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="民数记 20:8; 以赛亚书 12:3; 以赛亚书 41:17–18"> 他们从那里来到比尔，就是在这井旁，耶和华曾对摩西说：“招聚民众来，我要赐给他们水。”</span>
<span className="v" id="v17" data-v="17" data-xref="雅各书 5:13; 出埃及记 15:1–2; 诗篇 106:12"> 那时以色列唱了这首歌：<br /><span className="pl pl-1">“井啊，涌上水来！</span><br /><span className="pl pl-1">你们要为这井歌唱。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 33:22; 提摩太前书 6:17–18; 雅各书 4:12"> <span className="pl pl-1">这井是首领们所挖的，</span><br /><span className="pl pl-1">是民中的贵族用权杖、用手杖开凿的。”</span><br />然后，他们从旷野来到玛塔纳。</span>
<span className="v" id="v19" data-v="19"> 又从玛塔纳到拿哈列，从拿哈列到巴末，</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 23:28; 民数记 23:14; 申命记 1:5"> 从巴末到摩押境内的山谷，在那里的毗斯迦山顶可以俯看荒漠。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命记 2:26–28; 民数记 20:14–19; 士师记 11:19–21"> 以色列派使者去见亚摩利王西宏，说：</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 20:17"> “请让我们从你境内经过，我们不进入田间和葡萄园，也不喝井里的水。我们只走大道，直到过了你的地界。”</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 11:20; 申命记 29:7–8; 以赛亚书 15:4"> 但西宏不允许以色列经过他的境内。西宏招聚他的全军，出来在旷野迎击以色列。他来到雅哈兹，与以色列交战。</span>
<span className="v" id="v24" data-v="24" data-xref="阿摩司书 2:9; 约书亚记 24:8; 创世记 32:22"> 以色列用刀击杀他，占有了他的领土，从亚嫩河到雅博河，直到亚扪人那里，因为亚扪人的边防稳固。</span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="民数记 32:33–42; 以赛亚书 16:8–9; 耶利米书 48:2"> 以色列夺取了那些城，就住在亚摩利人的所有城镇，包括希实本和它的所有村镇。</span>
<span className="v" id="v26" data-v="26"> 希实本是亚摩利王西宏的都城，西宏曾与摩押先前的王交战，从他手中夺取了他的全地，直到亚嫩河，</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 14:4; 民数记 21:14; 哈巴谷书 2:6"> 因此那些唱歌谣的人说：<br /><span className="pl pl-1">“来希实本吧！</span><br /><span className="pl pl-1">愿西宏的城被建造，得坚立！</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="民数记 21:15; 耶利米书 48:45–46; 以赛亚书 15:1–2"> <span className="pl pl-1">有火从希实本出来，</span><br /><span className="pl pl-1">有火焰从西宏的城发出，</span><br /><span className="pl pl-1">吞噬了摩押的亚珥，</span><br /><span className="pl pl-1">以及亚嫩河的高坛之主。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="士师记 11:24; 列王纪下 23:13; 耶利米书 48:46"> <span className="pl pl-1">摩押啊，你有祸了！</span><br /><span className="pl pl-1">基抹的民哪，你们灭亡了！</span><br /><span className="pl pl-1">基抹任凭自己的儿子逃亡，</span><br /><span className="pl pl-1">任凭女儿被亚摩利王西宏掳去。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 48:18; 以赛亚书 15:2; 耶利米书 48:22"> <span className="pl pl-1">我们射杀了他们，</span><br /><span className="pl pl-1">希实本灭亡了，直到迪本；</span><br /><span className="pl pl-1">我们使它荒凉，</span><br /><span className="pl pl-1">直到挪法，直到米底巴。”</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约书亚记 13:8–12; 民数记 32:33–42; 申命记 3:16–17"> 这样，以色列就住在亚摩利人之地。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 48:32; 民数记 32:1; 民数记 32:35"> 摩西又派人去窥探雅谢，随后攻取雅谢的村镇，赶出了那里的亚摩利人。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约书亚记 13:12; 申命记 1:4; 申命记 29:7"> 然后他们转身，沿着通往巴珊的路上去。巴珊王欧革带着他的全军出来迎战他们，在伊德赖作战。</span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 135:10–11; 约书亚记 8:7; 申命记 3:2–3"> 耶和华对摩西说：“不要怕他，我已经把他和他的全军以及他的领土，都交在你手中了。你要像对待住希实本的亚摩利王西宏那样对待他。”</span>
<span className="v" id="v35" data-v="35" data-xref="申命记 29:7–8; 约书亚记 13:12; 申命记 3:3–17"> 于是他们击杀了欧革和他的儿子们以及他的全军，没有给他留下一人存活，并且占有了他的领土。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 13:21; 出埃及记 15:20; 民数记 33:36"> 一月的时候，以色列全体会众来到寻的旷野，民众就住在加低斯。米利暗死在那里，也葬在那里。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="民数记 16:19; 民数记 16:42; 出埃及记 15:23–24"> 那时，会众没有水了，就聚集起来对抗摩西和亚伦。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 17:2; 民数记 14:1–2; 民数记 16:31–35"> 民众向摩西争闹，开口说：“我们的兄弟在耶和华面前丧命时，还不如让我们也死了！</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 17:3; 诗篇 106:21; 民数记 16:13–14"> 你们为什么把耶和华的会众领到这旷野，使我们和我们的牲畜死在这里呢？</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 16:14; 耶利米书 2:2; 耶利米书 2:6"> 为什么把我们从埃及带上来，领我们到这样恶劣的地方呢？这里没有撒种的地方，没有无花果树、葡萄树、石榴树，也没有水喝。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数记 14:5; 民数记 16:4; 民数记 16:19"> 摩西和亚伦就从会众面前来到会幕的入口，脸伏于地。耶和华的荣耀向他们显现，</span>
<span className="v" id="v7" data-v="7"> 耶和华指示摩西说：</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 4:17; 使徒行传 2:1–4; 启示录 22:17"> “你把那根杖取来，然后你和你哥哥亚伦招聚会众，在他们眼前吩咐岩石流出水来。这样，你就使水从岩石中流出来，给会众和他们的牲畜喝。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数记 17:10"> 于是，摩西照着耶和华指示他的，从耶和华面前取来那根杖。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 106:32–33; 使徒行传 14:9–15; 路加福音 9:54–55"> 摩西和亚伦招聚会众到岩石前面，对他们说：“悖逆的人哪，你们听着！难道我们必须使这岩石给你们流出水吗？”</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 10:4; 出埃及记 17:6; 申命记 8:15"> 摩西举起手，用他的杖击打岩石两次，就有大量的水流出来，会众和他们的牲畜都喝了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命记 1:37; 民数记 27:14; 以西结书 36:23"> 然而，耶和华对摩西和亚伦说：“由于你们没有信我，没有在以色列子民眼前尊我为圣，因此你们不能带领这会众进入我赐给他们的那地。”</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 17:7; 诗篇 95:8; 申命记 33:8"> 这就是“米利巴水”，因以色列子民向耶和华争闹，耶和华就在他们中间显为圣。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="士师记 11:16–17; 申命记 23:7; 俄巴底亚书 1:10–12"> 摩西从加低斯派遣使者去见以东王，说：“你的兄弟以色列如此说：你知道我们所遭遇的一切艰难。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 12:40; 申命记 26:6; 创世记 46:6"> 我们的祖先下到埃及，我们在埃及住了许多日子，埃及人恶待我们和我们的祖先。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 14:19; 出埃及记 23:20; 出埃及记 33:2"> 我们向耶和华呼求，他垂听了我们的呼声，派遣一位使者把我们从埃及带了出来。现在，我们到了你边境的加低斯城。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 2:27; 申命记 2:29; 民数记 21:22–24"> 请让我们从你境内经过；我们不会进入田间或葡萄园，也不喝井里的水。我们只走大道，不偏左右，直到我们过了你的地界。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 以东却答复说：“你不可从我这里经过，否则我会带着刀剑出来迎击你。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命记 2:28; 申命记 2:6; 出埃及记 12:38"> 以色列人对他说：“我们只从大道上过去；如果我们和我们的牲畜喝了你的水，我们会付水钱。我们没有别的要求，只愿让我们徒步经过！”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="士师记 11:17; 阿摩司书 1:11; 创世记 32:6"> 但他回答：“你们不可经过。”以东就带着大军，强势出来迎击以色列。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 11:18; 申命记 2:29; 申命记 2:4–8"> 以东拒绝让以色列经过他的境内，于是以色列转身离开了他。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数记 20:1; 民数记 20:14; 民数记 21:4"> 以色列全体会众从加低斯起行，来到了何珥山。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 33:37"> 在以东地边界的何珥山，耶和华对摩西和亚伦说：</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 25:8; 申命记 32:50; 民数记 31:2"> “亚伦要归到他的先人那里了。他不得进入我赐给以色列子孙的那地，因为你们在米利巴水边违背了我的命令。</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 33:38–39"> 你要带来亚伦和他的儿子以利亚撒，把他们带到何珥山上。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 20:24; 以赛亚书 22:21–22; 希伯来书 7:11"> 你要脱下亚伦的圣衣，给他的儿子以利亚撒穿上。然后，亚伦会归到先人那里，死在山上。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 摩西就照着耶和华所指示的去做，他们在全体会众眼前上了何珥山。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 10:6; 出埃及记 29:29–30; 申命记 34:9"> 摩西脱下亚伦的圣衣，给他的儿子以利亚撒穿上，亚伦就死在山顶上。随后，摩西和以利亚撒从山上下来。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 34:8; 历代志下 35:24–25; 创世记 1:10"> 全体会众看到亚伦去世了，以色列全家就为亚伦哀哭三十天。</span>
</div>
</div>

</div>

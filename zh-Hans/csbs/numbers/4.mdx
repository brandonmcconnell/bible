<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西和亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 3:27; 民数记 3:19"> “你们要按家族和父家，统计利未子孙中哥辖子孙的人数，</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 4:23; 历代志上 23:3–5; 列王纪下 11:4–12"> 就是三十岁以上到五十岁，所有前来供职、在会幕中工作的人数。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="民数记 4:19; 马可福音 13:34; 民数记 4:30"> “哥辖子孙在会幕中有关至圣物的服事工作如下：</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 27:51; 希伯来书 9:3; 出埃及记 40:3"> 当营队起行时，亚伦和他的儿子们要进去，取下帘幕的幔子，用它遮盖见证柜。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 25:13–15; 出埃及记 35:19; 民数记 4:7–8"> 又放上海狮皮<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="海狮皮——原文语义不确定，基本意思是一种精细的皮革；本章下同。">a</a></sup>的顶罩，再铺上纯蓝色的布，然后穿进杠子。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="利未记 24:5–8; 出埃及记 37:10–16; 出埃及记 25:23–30"> “亚伦和他的儿子们要在陈设饼的桌子上铺蓝色的布，其上摆放盘子、勺子、碗和酒祭用的壶，常献的饼也必须在桌上。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 4:6–7; 民数记 4:11–13; 民数记 4:9"> 又在它们上面铺朱红色的布，再用海狮皮的顶罩遮盖，然后穿进杠子。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 25:31–39; 出埃及记 37:17–24; 启示录 1:20–1"> “他们要取来蓝色的布，遮盖灯台和灯台的灯盏、灯剪、灯盘，以及所有的油罐，就是用来盛油的器皿。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 4:12; 民数记 4:6"> 然后把灯台和灯台的所有器具放进海狮皮的顶罩内，放在抬架上。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出埃及记 40:5; 出埃及记 30:1–19; 出埃及记 40:26–27"> “他们要在金祭坛上铺蓝色的布，再用海狮皮的顶罩遮盖，然后穿进杠子。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 9:29; 出埃及记 25:9; 历代志下 4:22"> 他们要把圣所中事奉用的所有器具取来，包在蓝色的布里，再用海狮皮的顶罩遮盖它们，然后放在抬架上。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未记 6:12–13; 出埃及记 39:1; 出埃及记 39:41"> “他们要收去祭坛的灰，然后在祭坛上铺紫色的布。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 4:19; 出埃及记 38:1–7"> 又把祭坛上事奉用的所有器具，就是火盆、叉子、铲子、碗，以及一切祭坛用具，都放在祭坛上；再铺上海狮皮的顶罩，然后穿进杠子。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 6:6–7; 民数记 7:9; 申命记 31:9"> “营队起行的时候，亚伦和他的儿子们把圣物和圣所的所有器具都遮盖完毕，之后哥辖的子孙要进来抬；他们不可触碰圣物，免得死亡。这些就是会幕中哥辖子孙负责扛抬的。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及记 25:6; 利未记 24:2; 出埃及记 30:23–38"> “祭司亚伦的儿子以利亚撒所负责的，是灯油、芬芳香、常献的素祭和膏油，并负责整个帐幕和帐幕里的一切，圣所和圣所内的器具。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和华指示摩西和亚伦说：</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 6:6–7; 民数记 17:10; 民数记 18:5"> “不要让哥辖家族的支系从利未人中被除灭。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 4:15"> 要为他们这样做：当他们接近至圣物的时候，亚伦和他的儿子们要进去，安排他们每个人的服事工作和各人要负责扛抬的；这样他们就可以存活，不致死亡。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 6:19; 出埃及记 19:21; 民数记 4:15"> 他们片刻都不可进去看圣物，免得他们死亡。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 耶和华指示摩西说：</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 3:18; 民数记 3:21; 民数记 3:24"> “你也要按父家和家族，统计革顺子孙的人数，</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 4:3; 提摩太前书 1:18; 哥林多前书 9:7"> 数点三十岁以上到五十岁，所有前来供职、在会幕中做服事的人。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数记 4:19; 民数记 4:31–32; 民数记 4:47"> “革顺家族的服事、扛抬工作如下：</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 3:25–26; 出埃及记 26:14; 民数记 7:5–7"> 他们要抬帐幕的幔帐、会幕和它的顶罩以及覆盖其上的海狮皮顶罩，还有会幕入口的帘幕，</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 35:18; 出埃及记 27:9"> 院子的帷幔，在帐幕和祭坛四围的院子入口的帘幕，它们的绳子，以及服事用的一切器具；所有相关的工作，他们都要去做。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 1:70; 哥林多前书 11:2"> “革顺子孙所有的服事，所有的扛抬和服事工作，都要遵照亚伦和他儿子们的吩咐；他们所有的扛抬工作，你们都要为他们指派相关的职责。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 4:33; 哥林多前书 12:5–6"> 这是革顺子孙各家族在会幕中的服事，是在祭司亚伦的儿子以塔玛尔手下履行的职责。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数记 3:33–35"> “米拉利的子孙，你也要按家族和父家数点他们，</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 4:3; 民数记 4:23; 提摩太后书 2:4"> 数点三十岁以上到五十岁，所有前来供职、做会幕服事工作的人。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="民数记 3:36–37; 出埃及记 26:15; 民数记 7:8–9"> “他们在会幕中的一切服事，要负责的扛抬工作如下：帐幕的木板，门闩，柱子和底座，</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 38:21; 历代志上 9:29; 民数记 3:8"> 院子四围的柱子和它们的底座、橛子、绳子，以及相关的一切器具，相关的一切工作。你们要按名字指派他们负责扛抬的器具。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 4:28; 约书亚记 3:6; 以赛亚书 3:6"> 这是米拉利子孙各家族的服事，是他们在会幕中的各样服事，在祭司亚伦的儿子以塔玛尔手下履行。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> 于是，摩西和亚伦以及会众领袖们按家族和父家，数点哥辖的子孙。</span>
<span className="v" id="v35" data-v="35" data-xref="历代志上 23:24; 民数记 4:23; 历代志上 23:3"> 三十岁以上到五十岁，所有前来供职、在会幕中服事的人，</span>
<span className="v" id="v36" data-v="36"> 按着家族被数点，有两千七百五十人。</span>
<span className="v" id="v37" data-v="37"> 这些就是哥辖家族所有在会幕中服事、被数点的人，摩西和亚伦按照耶和华藉着摩西所指示的，数点了他们。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> 革顺子孙被数点的，是按家族和父家，</span>
<span className="v" id="v39" data-v="39"> 三十岁以上到五十岁，所有前来供职、在会幕中服事的人；</span>
<span className="v" id="v40" data-v="40" data-xref="民数记 3:32"> 他们按家族和父家被数点的，有两千六百三十人。</span>
<span className="v" id="v41" data-v="41"> 这些就是革顺子孙各家族所有在会幕中服事、被数点的人，是摩西和亚伦按照耶和华的指示数点的。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> 米拉利子孙各家族被数点的，是按家族和父家，</span>
<span className="v" id="v43" data-v="43"> 三十岁以上到五十岁，所有前来供职、在会幕中服事的人；</span>
<span className="v" id="v44" data-v="44" data-xref="哥林多前书 10:13; 哥林多后书 12:9–10; 哥林多前书 12:8–12"> 他们按家族被数点的，有三千两百人。</span>
<span className="v" id="v45" data-v="45" data-xref="民数记 4:29"> 这些就是米拉利子孙各家族被数点的人，摩西和亚伦按照耶和华藉着摩西所指示的，数点了他们。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46"> 摩西和亚伦以及以色列众领袖数点利未人，所有被数点的，是按家族和父家，</span>
<span className="v" id="v47" data-v="47" data-xref="哥林多前书 12:4–31; 罗马书 12:6–8; 民数记 4:3"> 三十岁以上到五十岁，所有前来在会幕中做服事工作和扛抬工作的人。</span>
<span className="v" id="v48" data-v="48" data-xref="民数记 3:39; 马太福音 20:16; 马太福音 22:15"> 他们被数点的，总共是八千五百八十人，</span>
<span className="v" id="v49" data-v="49" data-xref="民数记 1:54; 民数记 4:31; 民数记 4:15"> 都是按照耶和华的吩咐，藉着摩西数点的，各人负责自己的服事工作和扛抬工作。摩西照着耶和华所指示他的，数点了他们。</span>
</div>
</div>

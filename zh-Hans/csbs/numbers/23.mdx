<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 23:29; 犹大书 1:11; 出埃及记 27:1–8"> 巴兰对巴勒说：“请在这里为我筑七座祭坛，并在这里为我预备七头公牛、七只公绵羊。”</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 23:14; 民数记 23:30"> 巴勒就照着巴兰所说的做了。巴勒和巴兰在每座祭坛上献一头公牛、一只公绵羊。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 23:15; 创世记 8:20; 创世记 22:2"> 巴兰对巴勒说：“你站在你的燔祭旁边，我要往前去，或许耶和华会临到，接见我。他指示我什么信息，我都会告诉你。”然后，巴兰走到一片光秃的高地。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="民数记 23:16; 以弗所书 2:9; 路加福音 18:12"> 神临到巴兰，巴兰对神说：“我预备了七座祭坛，在每座祭坛上献了一头公牛、一只公绵羊。”</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 18:18; 耶利米书 1:9; 以赛亚书 59:21"> 耶和华就把话放在巴兰的口中，说：“你回巴勒那里去，要如此如此说。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 他回到巴勒那里，看哪，巴勒和摩押全体首领都站在燔祭旁边。</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="申命记 23:4; 民数记 24:3; 民数记 22:5–6"> 巴兰发布谕示，说：<br /><span className="pl pl-1">“巴勒请我从亚兰来，</span><br /><span className="pl pl-1">摩押王请我出东山，他说：</span><br /><span className="pl pl-1">‘来吧，为我诅咒雅各；</span><br /><span className="pl pl-1">来吧，向以色列宣判！’</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="民数记 23:23; 以赛亚书 44:25; 民数记 23:20"> <span className="pl pl-1">神没有诅咒的，我怎么能诅咒？</span><br /><span className="pl pl-1">耶和华没有宣判，我怎么能宣判？</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="申命记 33:28; 申命记 32:8; 出埃及记 33:16"> <span className="pl pl-1">我从岩壁的顶峰观望他，</span><br /><span className="pl pl-1">从山岗上注视他</span><br /><span className="pl pl-1">——看，这独居的民族，</span><br /><span className="pl pl-1">不把自己算在列国之中。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 37:37; 创世记 13:16; 诗篇 116:15"> <span className="pl pl-1">谁能数点雅各的尘沙，</span><br /><span className="pl pl-1">谁能数算以色列的烟尘</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="烟尘——或译作“四分之一”。">a</a></sup><br /><span className="pl pl-1">？</span><br /><span className="pl pl-1">愿我死如正直人的死，</span><br /><span className="pl pl-1">愿我的结局像他一样。”</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="尼希米记 13:2; 民数记 24:10; 民数记 22:17"> 巴勒对巴兰说：“你对我做了什么事！我带你来诅咒我的仇敌，看哪，你却大大祝福他们。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数记 22:38; 民数记 23:20; 民数记 23:26"> 巴兰回答说：“耶和华放在我口中的话，我怎么能不忠实传讲呢？”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="诗篇 109:17; 雅各书 3:9–10; 民数记 22:41"> 巴勒对巴兰说：“来吧，请与我一起到另外一个地方，你可以从那里看到那民族；只会看到他们营地的边缘，不能看见全部。请在那里为我诅咒他们。”</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 46:6; 民数记 23:29; 以赛亚书 1:10–11"> 于是巴勒带巴兰到琐腓野外，毗斯迦山顶上<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="琐腓野外，毗斯迦山顶上——或译作“毗斯迦山顶的守望台”。">b</a></sup>。巴勒筑了七座祭坛，在每座祭坛上献一头公牛、一只公绵羊。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数记 23:3; 民数记 22:8"> 巴兰对巴勒说：“你站在你的燔祭旁边，我要到那边受接见。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数记 23:5; 民数记 24:1; 民数记 22:35"> 耶和华接见巴兰，把话语放在他口中，说：“你回巴勒那里去，要如此如此说。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民数记 23:26; 撒母耳记上 3:17; 耶利米书 37:17"> 巴兰回到巴勒那里，看哪，巴勒站在燔祭旁边，摩押的首领们也与他在一起。巴勒问他：“耶和华说了什么？”</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="士师记 3:20"> 巴兰发布谕示，说：<br /><span className="pl pl-1">“巴勒啊，你起来听着；</span><br /><span className="pl pl-1">西拨的儿子啊，听我说！</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 15:29; 雅各书 1:17; 玛拉基书 3:6"> <span className="pl pl-1">神不是会说谎的人，</span><br /><span className="pl pl-1">也不是会后悔的人类。</span><br /><span className="pl pl-1">难道他说了会不做吗？</span><br /><span className="pl pl-1">他发话了，会不成就吗？</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 10:27–29; 民数记 22:12; 创世记 12:2"> <span className="pl pl-1">看哪，我奉命祝福；</span><br /><span className="pl pl-1">神已经祝福了，</span><br /><span className="pl pl-1">我不能翻转。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 23:4; 马太福音 1:23; 耶利米书 50:20"> <span className="pl pl-1">神使雅各中看不到祸患，</span><br /><span className="pl pl-1">使以色列中看不见苦难。</span><br /><span className="pl pl-1">他的神耶和华与他同在，</span><br /><span className="pl pl-1">欢呼君王的声音在他们中间。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="民数记 24:8; 申命记 33:17; 约伯记 39:9–11"> <span className="pl pl-1">神把他们从埃及领出来，</span><br /><span className="pl pl-1">像野牛的角为他们争战</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="争战——辅助词语。">c</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 10:18–19; 约书亚记 13:22; 加拉太书 1:23–24"> <span className="pl pl-1">实在没有法术对付雅各，</span><br /><span className="pl pl-1">也没有占卜对付以色列，</span><br /><span className="pl pl-1">每当论到雅各，</span><br /><span className="pl pl-1">论到以色列，人都会说：</span><br /><span className="pl pl-1">‘神成就了何等的事啊！’</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="创世记 49:27; 创世记 49:9; 民数记 24:17"> <span className="pl pl-1">看，这民族起来如母狮，</span><br /><span className="pl pl-1">挺身像公狮。</span><br /><span className="pl pl-1">它不吞吃猎物，不喝被杀之人的血，</span><br /><span className="pl pl-1">就绝不躺下。”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="诗篇 2:1–3"> 巴勒对巴兰说：“既然你一点也不诅咒他们，那就一点也不要祝福他们。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 5:29; 民数记 22:18; 使徒行传 4:19–20"> 巴兰回答巴勒说：“我不是告诉过你，耶和华所说的一切我必须遵行吗？”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="罗马书 11:29; 箴言 21:30; 民数记 23:19–20"> 于是巴勒对巴兰说：“来，请让我带你到另外一个地方。或许在神的眼中，你从那里为我诅咒他们是合宜的。”</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 21:20; 诗篇 106:28"> 巴勒就带巴兰到毗珥山顶，在那里可以俯看荒漠。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数记 23:1–2"> 巴兰对巴勒说：“请在这里为我筑七座祭坛，并在这里为我预备七头公牛、七只公绵羊。”</span>

</div>

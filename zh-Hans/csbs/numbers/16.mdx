<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="犹大书 1:11; 申命记 11:6; 出埃及记 6:21"> 以斯哈的儿子可拉，是利未之子哥辖的孙子，他带着鲁本子孙以利押的儿子大坍和亚比兰，以及比勒的儿子奥恩，</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 26:9; 以西结书 23:10; 创世记 6:4"> 起来对抗摩西，随同他们的还有以色列子孙中的两百五十人，都是议会选召出来的会众领袖，是有名望的人。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 106:16; 民数记 14:14; 出埃及记 19:6"> 他们聚集起来对抗摩西和亚伦，说：“你们僭越了！其实全体会众每一个都是圣洁的，耶和华也与他们同在，你们为何高抬自己，站在耶和华的会众之上呢？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="民数记 14:5; 民数记 20:6; 约书亚记 7:6"> 摩西听见了，就脸伏于地。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 65:4; 民数记 17:5; 提摩太后书 2:19"> 他对可拉和可拉的所有同党说：“明天早晨，耶和华会显明谁是属于他的，谁是分别为圣的，他会让那人亲近他，让他所拣选的人亲近他。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 10:1; 民数记 16:46–48; 列王纪上 18:21–23"> 你们要这样做：可拉和可拉的所有同党，你们拿来香炉，</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 16:3; 以弗所书 1:4; 列王纪上 18:17–18"> 明天在耶和华面前，给香炉里盛上火，加上香。那时，耶和华拣选了谁，谁就是分别为圣的。利未的子孙哪，是你们僭越了！”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 摩西又对可拉说：“利未的子孙哪，你们听着！</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 7:13; 申命记 10:8; 以西结书 44:10–11"> 以色列的神将你们从以色列会众当中分别出来，让你们亲近他，做耶和华帐幕的服事工作，并站在会众面前事奉他们，这对你们是小事吗？</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 13:10; 约翰三书 1:9; 民数记 18:7"> 耶和华让你和你所有的弟兄，就是与你一起的利未子孙，都亲近他，现在你们还想谋求祭司的职份吗？</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 16:7–8; 出埃及记 17:2; 民数记 16:3"> 其实，你和你所有的同党聚集起来是在敌对耶和华！亚伦算什么，你们竟然向他发怨言？”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彼得前书 2:13–14; 犹大书 1:8; 箴言 29:9"> 摩西派人去把以利押的儿子大坍和亚比兰召来，他们却说：“我们不过去。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 7:35; 出埃及记 2:14; 民数记 11:5"> 你把我们从流奶与蜜之地带上来，让我们死在旷野，这算小事吗？你还想自立为王统治我们！</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 20:24; 民数记 36:8–10; 民数记 20:5"> 况且，你并没有把我们领到流奶与蜜之地，也没有赐给我们田地和葡萄园为继业。难道你想剜出我们这些人的眼睛吗？我们不过去！”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="创世记 4:4–5; 哥林多后书 7:2; 帖撒罗尼迦前书 2:10"> 摩西就非常恼火，他对耶和华说：“求你不要悦纳他们的供物。我并没有夺走过他们一头驴子，也没有伤害过他们任何一人。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 12:3; 撒母耳记上 12:7; 提摩太后书 2:14"> 摩西对可拉说：“明天你和你的所有同党都要到耶和华面前，你和他们，还有亚伦都要在场。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 12:7"> 你们各自拿来香炉，放上香。他们各人要在耶和华面前呈上自己的香炉，共两百五十个香炉，你和亚伦也要呈上自己的香炉。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 于是他们各自拿来香炉，给香炉里盛上火，加上香，与摩西和亚伦一起站在会幕入口。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 14:10; 民数记 16:42; 出埃及记 16:7"> 可拉把全体会众都招聚到会幕入口，对抗摩西和亚伦。那时，耶和华的荣耀向全体会众显现，</span>
<span className="v" id="v20" data-v="20"> 耶和华指示摩西和亚伦说：</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 16:45; 出埃及记 32:10; 诗篇 73:19"> “你们从这会众当中分离出来，我要一瞬间消灭他们！”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数记 27:16; 撒迦利亚书 12:1; 约伯记 12:10"> 摩西和亚伦就脸伏于地，说：“神哪，使一切肉体有气息<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="使一切肉体有气息——或译作“赐予全人类气息”。">a</a></sup>的神！一个人犯罪，你就对全体会众发怒吗？”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 于是，耶和华指示摩西说：</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 16:21"> “你要吩咐会众说：你们都从可拉、大坍和亚比兰的帐幕周围离开！”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="民数记 11:16–17; 民数记 11:25; 民数记 11:30"> 于是摩西起来，到大坍和亚比兰那里去，以色列的长老们跟随着他。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 52:11; 哥林多后书 6:17; 启示录 18:4"> 他告诉会众说：“你们要远离这些恶人的帐篷，不要碰任何属于他们的东西，免得你们因他们的一切罪恶而被除灭。”</span>
<span className="v" id="v27" data-v="27" data-xref="约伯记 9:4; 以赛亚书 28:14; 约伯记 40:10–11"> 会众就从可拉、大坍、亚比兰的帐篷四围离开了。大坍和亚比兰，还有他们的妻子、儿女和孩童都出来，站在他们的帐篷入口。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约翰福音 6:38; 出埃及记 3:12; 约翰福音 14:11"> 摩西说：“藉着这事，你们必知道，是耶和华派遣了我来做这一切工作，而不是我随从自己的心意做事。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米哀歌 4:22; 列王纪上 22:28; 出埃及记 32:34"> 如果这些人的死如世人的死，他们的遭遇如世人的遭遇，耶和华就没有派遣我。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 55:15; 民数记 16:33; 约伯记 31:3"> 但如果耶和华行一件新事，使地张口吞掉他们和属于他们的一切，使他们活活地下到阴间，你们就明白：这些人确实藐视了耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="诗篇 106:17–18; 民数记 27:3; 申命记 11:6"> 他刚说完这一切话，那些人脚下的土地就裂开了。</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 106:17; 民数记 26:11; 启示录 12:16"> 地张口吞掉他们和他们的家人，以及所有属于可拉的人和财物。</span>
<span className="v" id="v33" data-v="33" data-xref="以西结书 32:18; 以赛亚书 14:9; 诗篇 9:15"> 他们和所有属于他们的，都活活地下到阴间，地掩埋了他们，他们就从会众当中消失了。</span>
<span className="v" id="v34" data-v="34" data-xref="撒迦利亚书 14:5; 以赛亚书 33:3; 启示录 6:15–17"> 因他们的叫声周围所有的以色列人都逃跑了，他们说：“恐怕地要把我们也吞掉了！”</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 26:10; 利未记 10:2; 诗篇 106:18"> 还有火从耶和华那里出来，吞灭了那两百五十个呈上香的人。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36"> <sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="此节至17:13在马索拉文本为17:1至17:28。">b</a></sup>耶和华指示摩西说：</span>
<span className="v" id="v37" data-v="37" data-xref="利未记 27:28; 民数记 16:18; 民数记 16:7"> “你要吩咐祭司亚伦的儿子以利亚撒，让他从燃烧的火中拿起那些香炉，将火撒在远处，因为那些香炉都分别为圣了。</span>
<span className="v" id="v38" data-v="38" data-xref="民数记 26:10; 以西结书 14:8; 彼得后书 2:6"> 至于那些犯罪丧命之人的香炉，要锤成薄片，用来包祭坛，因为这些香炉已经被献在耶和华面前，分别为圣了；它们要给以色列子孙作鉴戒。”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39"> 于是，祭司以利亚撒取来那些被烧死的人所献的铜香炉，人们把香炉锤成薄片，用来包祭坛，</span>
<span className="v" id="v40" data-v="40" data-xref="民数记 3:10; 民数记 18:4–7; 历代志下 26:16–21"> 为以色列子孙作记念，免得那不属于亚伦后裔的外人靠近耶和华面前烧香，以致有可拉和他的同党一样的遭遇。这都是照耶和华藉着摩西所吩咐以利亚撒的。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数记 16:1–7; 诗篇 106:23; 民数记 14:2"> 但第二天，全体以色列会众向摩西和亚伦发怨言，说：“你们杀了耶和华的子民！”</span>
<span className="v" id="v42" data-v="42" data-xref="民数记 16:19; 利未记 9:23; 民数记 20:6"> 正当会众聚集起来对抗摩西和亚伦的时候，他们转向会幕，看哪，云彩遮盖会幕，耶和华的荣耀显现了。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43"> 摩西和亚伦来到会幕前面，</span>
<span className="v" id="v44" data-v="44"> 耶和华指示摩西说：</span>
<span className="v" id="v45" data-v="45" data-xref="民数记 16:21–22; 民数记 16:24; 民数记 20:6"> “你们从这会众当中离开，我要一瞬间消灭他们！”摩西和亚伦就脸伏于地。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="民数记 8:19; 历代志上 27:24; 利未记 10:6"> 摩西对亚伦说：“你拿来香炉，香炉里盛上祭坛的火，加上香，赶快到会众那里去，为他们赎罪，因为有震怒从耶和华面前发出，瘟疫已经开始了。”</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="马太福音 5:44; 申命记 33:10–11; 诗篇 106:29"> 亚伦照着摩西所说的拿来香炉，跑到会众当中。看哪，瘟疫已经在子民中开始了！他就呈上香<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="呈上香——或译作“给香炉放上香”。">c</a></sup>，为子民赎罪。</span>
<span className="v" id="v48" data-v="48" data-xref="撒母耳记下 24:25; 希伯来书 7:24–25; 民数记 16:18"> 他站在死人和活人之间，瘟疫就止住了。</span>
<span className="v" id="v49" data-v="49" data-xref="民数记 25:9; 民数记 16:32–35; 希伯来书 2:1–3"> 除了因可拉事件而死的人以外，死于瘟疫的有一万四千七百人。</span>
<span className="v" id="v50" data-v="50" data-xref="历代志上 21:26–30; 民数记 16:43"> 亚伦回到会幕入口摩西那里，瘟疫已经止住了。</span>
</div>
</div>

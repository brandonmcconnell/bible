<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="NUM" data-book-slug="numbers" data-book-name="民数记" data-chapter="11" data-verses="35">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 21:5; 民数记 16:35; 列王纪下 1:12"> 当时，民众发怨言，恶言上达耶和华耳中。耶和华听见了就怒气发作，耶和华的火在他们中间焚烧，吞噬了营地的边缘。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 21:7; 雅各书 5:16; 民数记 16:45–48"> 民众向摩西哀求，摩西向耶和华祷告，火就熄灭了。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 9:22"> 于是那地方被起名为“塔备拉”，因为耶和华的火曾在他们中间焚烧。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 10:6; 出埃及记 12:38; 诗篇 106:14"> 他们当中一些闲杂人贪图口腹之欲，以致以色列子民也再次哭泣，说：“谁给我们肉吃呢？</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 16:3; 诗篇 17:14; 腓立比书 3:19"> 真想念在埃及能随意吃的鱼、黄瓜、西瓜、韭菜、葱和蒜。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 21:5; 撒母耳记下 13:4"> 现在我们什么胃口都没有了！我们眼前除了吗哪以外，什么都没有。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 16:31; 创世记 2:12; 出埃及记 16:14–15"> 吗哪仿佛芫荽的种子，外观如同珍珠<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="珍珠——或译作“红玉”或“稀罕的香料”。">a</a></sup>。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 16:31; 出埃及记 16:16–18; 出埃及记 16:23"> 民众四处走动，捡拾吗哪，用磨碾碎或用臼捣碎，然后用锅煮了，做成饼，味道就像是纯橄榄油的味道。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 16:13–14; 诗篇 78:23–25; 申命记 32:2"> 夜间露水降在营地上的时候，吗哪也与它一起降下。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="诗篇 78:21; 民数记 16:27; 民数记 14:1–2"> 摩西听见了百姓家家户户在帐篷门口哭，那时耶和华的怒气大大发作，摩西也感到悲苦。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 1:12; 出埃及记 5:22; 耶利米书 15:10"> 摩西对耶和华说：“你为什么恶待你的仆人呢？为什么我不在你眼前蒙恩，以致你把这全体民众的重担放在我身上呢？</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 49:23; 以赛亚书 40:11; 帖撒罗尼迦前书 2:7"> 是我怀上了这全体民众吗？是我生下了他们吗？你竟然吩咐我把他们抱在怀中，像保姆抱吃奶的婴儿那样，带到你起誓要赐给他们先祖的地方。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 15:33; 马可福音 8:4; 约翰福音 6:5–9"> 我从哪里得肉给这全体民众呢？他们竟然对我哭着说：‘给我们肉吃！’</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 18:18; 申命记 1:9–12; 哥林多后书 2:16"> 我不能够独自背负这全体民众，这对我实在太沉重了。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比书 1:20–24; 列王纪上 19:4; 约拿书 4:3"> 如果你要这样对待我，求你现在就杀了我；如果我在你眼前蒙恩，请不要让我看到自己的悲苦。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及记 24:1; 出埃及记 24:9; 申命记 16:18"> 耶和华就对摩西说：“你要从以色列的长老中为我招聚七十个人，就是你所知道的那些民间长老和官长；要把他们带到会幕，与你一同站在那里。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 11:25; 撒母耳记上 10:6; 哥林多前书 12:4–11"> 我要降临，在那里与你说话，并且把你身上的灵分出一些，赐给他们。这样，他们就与你一同背负这民众的重担，免得你独自背负。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 19:10; 使徒行传 7:39; 出埃及记 16:3–7"> “你要对民众说：你们要为明天把自己分别为圣，你们将会有肉吃。因为你们在耶和华耳中哭着说：‘谁给我们肉吃呢？我们在埃及多好！’所以，耶和华就要给你们肉吃了。</span>
<span className="v" id="v19" data-v="19"> 你们不是吃一天两天，也不是五天十天，也不是二十天，</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 106:15; 民数记 21:5; 诗篇 78:27–30"> 而是整整一个月，直到肉从你们鼻孔里出来，让你们恶心<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="让你们恶心——或译作“使你们厌恶它”。">b</a></sup>。因为你们厌弃在你们中间的耶和华，在他面前哭着说：‘我们为什么从埃及出来呢？’”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及记 12:37; 民数记 1:46; 创世记 12:2"> 摩西说：“与我一起的民众，步行的男人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="男人——辅助词语；参《出埃及记》12:37。">c</a></sup>有六十万，你竟然说要给他们肉吃，吃一整个月？</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 15:33; 列王纪下 7:2; 约翰福音 6:9"> 难道把羊群和牛群都给他们宰杀了，就够他们吃吗？或者把海里所有的鱼都给他们聚拢起来，就够他们吃吗？”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 59:1; 以赛亚书 50:2; 创世记 18:14"> 耶和华对摩西说：“难道耶和华的手臂缩短了吗？现在你就要看到我的话是否向你应验。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数记 11:16; 民数记 11:26"> 于是摩西出去，将耶和华的话告诉民众，并从民间的长老中招聚了七十个人，让他们站在会幕周围。</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 11:17; 约珥书 2:28–29; 撒母耳记上 10:10"> 耶和华在云彩中降临，对摩西说话，并把他身上的灵分出一些，赐给七十个长老。当那灵停留在他们身上时，他们就说神言；他们以后再没有说过。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 36:5; 撒母耳记上 20:26; 撒母耳记上 10:22"> 但有两个人留在营中，一个名叫伊利达，另一个名叫米达，那灵也停留在他们身上，他们就在营中说神言；他们也在入选名单中，却没有出去到会幕那里。</span>
<span className="v" id="v27" data-v="27"> 有个年轻人跑来报告摩西说：“伊利达和米达正在营中说神言。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马可福音 9:38–40; 路加福音 9:49–50; 约翰福音 3:26"> 嫩的儿子约书亚——他从年轻时就作摩西的助手<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="助手——或译作“侍从”。">d</a></sup>，他回应说：“我主摩西啊，请阻止他们。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 14:5; 马太福音 9:37–38; 路加福音 10:2"> 摩西对他说：“你为我的缘故起了嫉妒吗？但愿耶和华所有的子民都是先知，愿耶和华把他的灵赐给他们！”</span>
<span className="v" id="v30" data-v="30"> 之后，摩西和以色列的众长老回到了营地。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及记 16:13; 诗篇 105:40; 诗篇 78:26–29"> 有风从耶和华那里刮起，从海上刮来鹌鹑，散落在营地，覆盖营地四围，一边约有一天的路程远，另一边也约有一天的路程远，在地面上高约有两肘<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="两肘——相当于91.4公分。1肘=45.7公分。">e</a></sup>。</span>
<span className="v" id="v32" data-v="32" data-xref="以西结书 45:11; 出埃及记 16:36"> 民众就起来，那一天的整天整夜，以及第二天的整天，他们都在收取鹌鹑，最少的也收取了十贺梅珥<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="十贺梅珥——相当于2,200公升。1贺梅珥=220公升。">f</a></sup>，满满摊放在营地的四围。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="诗篇 78:30–31; 诗篇 106:14–15; 民数记 25:9"> 然而，那肉还在他们的口齿间没有被嚼烂，耶和华的怒气就向民众发作了，耶和华用极重的灾害打击民众。</span>
<span className="v" id="v34" data-v="34" data-xref="申命记 9:22; 哥林多前书 10:6; 民数记 33:16"> 那地方就被起名为“基布罗-哈特瓦”，因为在那里埋葬了那些起贪欲的民众。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="民数记 33:17; 民数记 12:16; 申命记 1:1"> 民众从基布罗-哈特瓦前行到哈洗录，就停留在哈洗录。</span>
</div>
</div>

</div>

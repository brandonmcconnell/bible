<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 25:22; 出埃及记 19:1; 民数记 10:11–12"> 以色列人出埃及地之后，第二年二月一日，耶和华在西奈旷野、在会幕中指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 38:26; 出埃及记 30:12; 民数记 1:18"> “你们要统计全体以色列会众的人数；按着家族、父家，按名单<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="名单——原文直译“人名的数目”；下同。">a</a></sup>，按着他们的人头统计所有的男子。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 30:14; 民数记 14:29; 民数记 33:1"> 你和亚伦要按着队伍，数点以色列二十岁以上所有能出战的。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 1:16; 出埃及记 18:25; 民数记 13:2–15"> 每个支派要有一个人协助你们，都要是父家的首领。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 7:30; 创世记 30:5–20; 创世记 49:1–33"> 这些协助你们的人，名字如下：<br /><span className="pl pl-1">属鲁本支派的，是谢德珥的儿子以利佐。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="民数记 7:36; 民数记 2:12"> <span className="pl pl-1">属西缅支派的，是苏利沙代的儿子谢路米业。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 3:32; 民数记 10:14; 马太福音 1:2–5"> <span className="pl pl-1">属犹大支派的，是亚米拿达的儿子拿顺。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="民数记 7:18; 民数记 10:15; 民数记 2:5"> <span className="pl pl-1">属以萨迦支派的，是苏押的儿子拿旦业。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="民数记 7:24; 民数记 10:16; 民数记 2:7"> <span className="pl pl-1">属西布伦支派的，是希伦的儿子以利押。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="民数记 7:54; 民数记 7:48; 历代志上 7:26–27"> <span className="pl pl-1">约瑟的子孙中，</span><br /><span className="pl pl-1">属以法莲支派的，是亚米忽的儿子以利沙玛；</span><br /><span className="pl pl-1">属玛拿西支派的，是佩达佐的儿子迦玛列。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="民数记 7:60; 民数记 10:24; 民数记 2:22"> <span className="pl pl-1">属便雅悯支派的，是基多尼的儿子亚比但。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="民数记 7:66; 民数记 2:25; 民数记 10:25"> <span className="pl pl-1">属但支派的，是亚米沙代的儿子亚希以谢。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="民数记 7:72; 民数记 10:26; 民数记 2:27"> <span className="pl pl-1">属亚设支派的，是俄兰的儿子帕结。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="民数记 2:14; 民数记 7:42; 民数记 10:20"> <span className="pl pl-1">属迦得支派的，是德珥的儿子以利雅萨。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="民数记 7:78; 民数记 10:27; 民数记 2:29"> <span className="pl pl-1">属拿弗他利支派的，是恩南的儿子亚希拉。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数记 7:2; 出埃及记 18:21; 出埃及记 18:25"> 以上是会众里选召出来的人，都是他们父系支派的领袖，是以色列千军的首领。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 10:3; 启示录 7:4–17; 民数记 1:5–15"> 于是，摩西和亚伦带着这些被指名的人，</span>
<span className="v" id="v18" data-v="18" data-xref="以斯拉记 2:59; 尼希米记 7:61; 希伯来书 7:3"> 在二月一日招聚全体会众，按着家族、父家，按名单，按着他们的人头，登记二十岁以上的男子。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 1:2; 民数记 26:1–2; 撒母耳记下 24:1–10"> 摩西照着耶和华所指示的，在西奈旷野数点了他们。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数记 26:5–7; 民数记 2:10–11; 创世记 46:9"> 以色列的长子鲁本的子孙，他们的谱系：按着家族、父家，按名单，按着他们的人头，二十岁以上所有能出战的男子，</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 26:7; 民数记 2:10–11"> 鲁本支派被数点的，共四万六千五百人。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数记 26:12–14; 创世记 34:25–30; 民数记 2:12–13"> 西缅子孙的谱系：按着家族、父家，按名单数点，按着他们的人头，二十岁以上所有能出战的男子，</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 26:14; 民数记 2:13; 民数记 25:8–9"> 西缅支派被数点的，共五万九千三百人。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数记 26:15–18; 创世记 46:16; 民数记 2:14–15"> 迦得子孙的谱系：按着家族、父家，按名单，二十岁以上所有能出战的男子，</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 26:18; 民数记 2:15"> 迦得支派被数点的，共四万五千六百五十人。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="创世记 29:35; 民数记 26:19–22; 撒母耳记下 24:9"> 犹大子孙的谱系：按着家族、父家，按名单，二十岁以上所有能出战的男子，</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记下 24:9; 民数记 26:22; 历代志下 17:14–16"> 犹大支派被数点的，共七万四千六百人。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="创世记 46:13; 创世记 49:14–15; 创世记 30:18"> 以萨迦子孙的谱系：按着家族、父家，按名单，二十岁以上所有能出战的男子，</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 26:25; 民数记 2:6"> 以萨迦支派被数点的，共五万四千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="民数记 26:26–27; 创世记 49:13; 创世记 30:20"> 西布伦子孙的谱系：按着家族、父家，按名单，二十岁以上所有能出战的男子，</span>
<span className="v" id="v31" data-v="31" data-xref="民数记 26:27; 民数记 2:8"> 西布伦支派被数点的，共五万七千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="民数记 26:35–37; 申命记 33:17; 创世记 46:20"> 约瑟的子孙中，<br />以法莲子孙的谱系：按着家族、父家，按名单，二十岁以上所有能出战的男子，</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 26:37; 申命记 33:17; 民数记 2:19"> 以法莲支派被数点的，共四万零五百人。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="民数记 26:28–34"> 玛拿西子孙的谱系：按着家族、父家，按名单，二十岁以上所有能出战的男子，</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 26:34; 创世记 48:19–20; 民数记 2:21"> 玛拿西支派被数点的，共三万两千两百人。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="创世记 49:27; 创世记 44:20; 启示录 7:8"> 便雅悯子孙的谱系：按着家族、父家，按名单，二十岁以上所有能出战的男子，</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 26:41; 士师记 20:44–46; 历代志下 17:17"> 便雅悯支派被数点的，共三万五千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="创世记 46:23; 创世记 30:5–6; 创世记 49:16–17"> 但子孙的谱系：按着家族、父家，按名单，二十岁以上所有能出战的男子，</span>
<span className="v" id="v39" data-v="39" data-xref="民数记 26:43; 民数记 2:26"> 但支派被数点的，共六万两千七百人。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="创世记 30:12–13; 创世记 46:27; 创世记 49:20"> 亚设子孙的谱系：按着家族、父家，按名单，二十岁以上所有能出战的男子，</span>
<span className="v" id="v41" data-v="41" data-xref="民数记 26:47; 民数记 2:28"> 亚设支派被数点的，共四万一千五百人。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="创世记 49:21; 民数记 26:48–50; 创世记 46:24"> 拿弗他利子孙的谱系：按着家族、父家，按名单，二十岁以上所有能出战的男子，</span>
<span className="v" id="v43" data-v="43" data-xref="民数记 26:50; 民数记 2:30"> 拿弗他利支派被数点的，共五万三千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="民数记 26:64; 民数记 1:2–16"> 以上是被数点的人，是摩西和亚伦以及以色列的众领袖所数点的，领袖有十二人，各人代表自己的父家。</span>
<span className="v" id="v45" data-v="45"> 这些按父家被数点的以色列子孙，都是以色列中二十岁以上所有能出战的男子；</span>
<span className="v" id="v46" data-v="46" data-xref="出埃及记 12:37; 民数记 26:51; 出埃及记 38:26"> 被数点的总共有六十万三千五百五十人。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="民数记 2:33; 民数记 3:1–49; 民数记 26:57–62"> 利未人没有按着他们的父系支派与以色列子孙一起被数点，</span>
<span className="v" id="v48" data-v="48"> 因为耶和华指示摩西说：</span>
<span className="v" id="v49" data-v="49" data-xref="民数记 26:62; 民数记 2:33"> “唯独不可数点利未支派，不可将他们的人数与以色列子孙一起统计。</span>
<span className="v" id="v50" data-v="50" data-xref="出埃及记 38:21; 出埃及记 31:18; 民数记 4:15"> 你要指派利未人管理见证帐幕和其中的所有器具，以及属于帐幕的一切。他们要抬帐幕和帐幕的所有器具，做帐幕的事奉，在帐幕的四围扎营。</span>
<span className="v" id="v51" data-v="51" data-xref="民数记 3:38; 民数记 3:10; 撒母耳记上 6:19"> 起行的时候，利未人要拆卸帐幕；扎营的时候，利未人要立起帐幕。接近帐幕的外人，必须被处死。</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="民数记 2:2; 民数记 2:34; 民数记 10:1–36"> “以色列子孙扎营时，要各按自己的队伍，各归自己的营地，各归自己的旗帜。</span>
<span className="v" id="v53" data-v="53" data-xref="民数记 16:46; 历代志上 23:32; 利未记 10:6"> 至于利未人，要扎营在见证帐幕的四围，以免震怒临到以色列会众；利未人要谨守见证帐幕的职责。”</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="申命记 12:32; 出埃及记 40:16; 出埃及记 39:32"> 以色列子孙就这样做了；耶和华所指示摩西的一切，他们都照着做了。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 23:10; 民数记 15:18; 利未记 25:2"> “你要吩咐以色列子民，对他们说：你们进入了我赐给你们的安居之地后，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 29:18; 创世记 8:21; 腓立比书 4:18"> 向耶和华献上火祭时，无论是燔祭或是别的祭物，无论是为了还特殊的愿，或是作甘心祭，或是作各节期的祭，都要从牛群或羊群中取来，烧献为馨香之气给耶和华。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 29:40; 利未记 23:13; 利未记 6:14"> 那向耶和华献上祭物的人，还要献上十分之一伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十分之一伊法——相当于2.2公升。1伊法=22公升。">a</a></sup>细面粉为素祭，用四分之一欣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="四分之一欣——相当于0.9公升。1欣=3.7公升。">b</a></sup>油调和。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 28:7; 民数记 28:14; 士师记 9:13"> 在燔祭或别的祭物之外，你还要为每只绵羊羔预备四分之一欣的酒作酒祭。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 28:12–14; 民数记 15:4"> 或是为每只公绵羊预备十分之二伊法<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="十分之二伊法——相当于4.4公升。1伊法=22公升。">c</a></sup>细面粉为素祭，用三分之一欣<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="三分之一欣——相当于1.2公升。1欣=3.7公升。">d</a></sup>油调和；</span>
<span className="v" id="v7" data-v="7"> 还要献上三分之一欣的酒作酒祭，烧献为馨香之气给耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未记 3:1; 利未记 7:11–18; 利未记 1:3"> “当你预备一头公牛作燔祭或别的祭物献给耶和华，无论是为了还特殊的愿或是作平安祭，</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 28:14; 民数记 28:12; 利未记 6:14"> 都要与公牛一起献上十分之三伊法<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="十分之三伊法——相当于6.6公升。1伊法=22公升。">e</a></sup>细面粉为素祭，用半欣<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="半欣——相当于1.9公升。1欣=3.7公升。">f</a></sup>油调和。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 15:5; 民数记 6:15"> 还要献上半欣的酒为酒祭，作为馨香的火祭献给耶和华。</span>
<span className="v" id="v11" data-v="11"> 为每头公牛、每只公绵羊、每只绵羊羔或山羊羔，都要这样预备；</span>
<span className="v" id="v12" data-v="12"> 无论为多少牛羊，都要照着它们的数量，这样为每一只祭牲预备。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> “任何本族人<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="本族人——原文直译“本地人”；本章下同。">g</a></sup>向耶和华献上馨香的火祭，都要这样预备。</span>
<span className="v" id="v14" data-v="14"> 如果寄居在你们中间的外人，或世世代代在你们中间的外人，想要向耶和华献上馨香的火祭，那么，你们怎样做，他也要怎样做。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 9:14; 民数记 15:29; 出埃及记 12:49"> 无论是对你们还是对寄居的外人，会众要有同一个律例。这是你们世世代代永远的律例。在耶和华面前，你们怎样，外人也要怎样。</span>
<span className="v" id="v16" data-v="16"> 你们和寄居在你们中间的外人，是同一个条例、同一个规定。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和华指示摩西说：</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 15:2; 申命记 26:1–15"> “你要吩咐以色列子民，对他们说：当你们进入我要带你们去的那地，</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 5:11–12"> 享用那地的出产时，你们要奉上一份供物给耶和华。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 2:14; 出埃及记 34:26; 申命记 26:2–10"> 你们要用初熟五谷的面团做饼，作为供物奉上，就像打谷场的供物一样把它奉上。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 29:28; 民数记 18:26"> 你们世世代代都要从你们初熟五谷的面团中，把一份供物献给耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未记 4:2; 利未记 4:27; 利未记 5:15–17"> “如果你们无意中有了过失，没有遵行耶和华吩咐摩西的这一切诫命，</span>
<span className="v" id="v23" data-v="23"> 就是耶和华藉着摩西所指示你们的一切——从耶和华指示你们的那天起，之后世世代代，</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 4:23; 利未记 4:13–21; 利未记 5:15"> 如果是会众没有察觉而无意中有了过失，全体会众就要献上一头公牛为燔祭，作馨香之气献给耶和华，并按照规定献上同献的素祭和酒祭；还有一只公山羊为赎罪祭。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 4:20; 罗马书 3:25; 希伯来书 2:17"> 祭司要为全体以色列会众赎罪，他们就得赦免，因为这是无意的过失。他们要为自己无意的过失带来祭物，就是献给耶和华的火祭和赎罪祭，带到耶和华面前。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 15:24"> 全体以色列会众和寄居在他们中间的外人，都必得赦免，因为这是全体民众无意的过失。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="利未记 4:27–28; 使徒行传 17:30; 使徒行传 3:17"> “如果是一个人无意中犯了罪，他就要献上一只一岁的母山羊作赎罪祭。</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 4:35"> 祭司要为那无意中过失犯罪的人赎罪；祭司在耶和华面前为他赎罪，他就必得赦免。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 15:15; 利未记 16:29; 利未记 17:15"> 无论是以色列子孙中的本族人，还是寄居在他们中间的外人，你们无意中有过失的人都是同一个条例。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="希伯来书 10:26; 诗篇 19:13; 申命记 1:43"> “但狂妄行事的人，无论是本族人或是外人，那人是在亵渎耶和华，必须从民中被剪除。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 12:9; 箴言 13:13; 以西结书 18:20"> 那人既然藐视耶和华的话语，违背他的诫命，就必须被剪除，他的罪责要归在自己身上。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="出埃及记 35:2–3; 出埃及记 31:14–15; 出埃及记 20:8–10"> 以色列子孙在旷野的时候，人们发现有一个人在安息日捡木柴。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 8:3–20"> 那些发现他在捡木柴的人，就把他带到摩西和亚伦以及全体会众那里。</span>
<span className="v" id="v34" data-v="34" data-xref="利未记 24:12; 民数记 9:8"> 他们把他拘押起来，因为还不明确该怎样处置他。</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 7:58; 出埃及记 31:14–15; 列王纪上 21:13"> 耶和华对摩西说：“那人必须被处死，全体会众要在营地外用石头砸死他。”</span>
<span className="v" id="v36" data-v="36" data-xref="约书亚记 7:25"> 于是全体会众把那人带到营地外，用石头砸死了他，正如耶和华所指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37"> 耶和华指示摩西说：</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 23:5; 申命记 22:12; 马太福音 9:20"> “你要吩咐以色列子民，告诉他们要世世代代在外衣的衣摆上做䍁子，并给衣摆的䍁子加上一根蓝色的细带子。</span>
<span className="v" id="v39" data-v="39" data-xref="诗篇 106:39; 箴言 28:26; 诗篇 73:27"> 你们要这样做䍁子，使你们看见就想起并遵行耶和华的一切诫命，而不随从自己惯于行淫的欲念和眼目；</span>
<span className="v" id="v40" data-v="40" data-xref="罗马书 12:1; 帖撒罗尼迦前书 4:7; 利未记 11:44–45"> 也使你们牢记并遵行我的一切诫命，成为圣洁的，归于你们的神。</span>
<span className="v" id="v41" data-v="41" data-xref="彼得前书 2:9–10; 以西结书 36:25–27; 希伯来书 11:16"> 我是耶和华你们的神，是我把你们从埃及地领了出来，为要作你们的神。我是耶和华你们的神。”</span>
</div>
</div>

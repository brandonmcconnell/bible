<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 25:37; 出埃及记 40:25; 利未记 24:1–2"> “你要吩咐亚伦，对他说：点灯的时候，要让七盏灯照亮灯台的前面。”</span>
<span className="v" id="v3" data-v="3"> 亚伦就这样做了。他照着耶和华所指示摩西的，点燃了灯照亮灯台的前面。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 25:31–40; 出埃及记 25:9; 出埃及记 25:18"> 灯台的工艺是用金子锤擛，从底座到花朵都锤擛成形；摩西照着耶和华所显示给他的样式，做了灯台。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 耶和华指示摩西说：</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 7:1; 雅各书 4:8; 出埃及记 19:15"> “你要从以色列子孙中拣选利未人，为他们举行洁净礼。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 19:13; 民数记 19:7–10; 利未记 8:6"> 你要对他们这样做，使他们得洁净：要把赎罪的水弹洒在他们身上，又让他们用剃刀剃全身，并且洗自己的衣服，这样他们就得洁净了。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未记 2:1; 出埃及记 29:1; 利未记 16:3"> “然后他们要取来一头公牛，还有同献的素祭，就是调了油的细面粉；你也要另外取来一头公牛，作赎罪祭。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 40:12; 利未记 8:3; 出埃及记 29:4–37"> 你要把利未人带到会幕前面，并且招聚全体以色列会众。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 1:4; 使徒行传 6:6; 提摩太前书 4:14"> 当你把利未人带到了耶和华面前，以色列子孙就要按手在利未人身上。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 7:30; 利未记 8:29; 民数记 1:49–53"> 亚伦要从以色列子孙中把利未人作为摇献祭，奉献在耶和华面前，使他们可以做服事耶和华的工作。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 10:4–10; 出埃及记 29:10; 利未记 1:4"> 利未人要按手在两头公牛的头上，一头作赎罪祭，另一头作燔祭，献给耶和华，为利未人赎罪。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 8:21; 民数记 8:11; 罗马书 15:16"> “你要让利未人站在亚伦和他的儿子们面前，把他们作为摇献祭，奉献给耶和华。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 3:45; 玛拉基书 3:17; 民数记 18:6"> 这样，你把利未人从以色列子孙中分别出来，利未人就归属我了。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 8:11; 民数记 8:13; 民数记 3:23–37"> 此后，利未人要进入会幕服事。你要洁净他们，把他们作为摇献祭献上。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 3:12; 民数记 3:45; 民数记 3:9"> 因为他们是从以色列子孙中特定献给我的，我已经拣选了他们，代替以色列子孙中所有的头胎、所有的长子归属我。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 13:2; 路加福音 2:23; 出埃及记 13:12–15"> 以色列子孙中所有头生的，无论是人还是牲畜，都属于我；我在击杀埃及地所有头生的那一天，已经把他们分别为圣归于我。</span>
<span className="v" id="v18" data-v="18"> 但我拣选利未人代替以色列子孙中所有头生的；</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 1:53; 民数记 16:46; 历代志下 26:16–20"> 我从以色列子孙中把利未人作为奉献，赐给亚伦和他的儿子们，在会幕中为以色列子民做服事，并为以色列子民赎罪，免得以色列子民接近圣所时，灾殃临到以色列子民。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 摩西和亚伦以及全体以色列会众就对利未人这样做了；耶和华所指示摩西有关利未人的一切，以色列子民都照样对他们做了。</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 8:7; 民数记 19:19; 民数记 8:15"> 利未人洁净了自己，洗了自己的衣服，亚伦就把他们作为摇献祭，奉献在耶和华面前；亚伦又为他们赎罪，使他们得洁净。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 31:2; 历代志下 35:8–15; 民数记 8:15"> 之后，利未人进去，在亚伦和他的儿子们面前，在会幕中做服事。耶和华所指示摩西有关利未人的一切，他们都照样对利未人做了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和华指示摩西说：</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 4:3; 历代志上 23:3; 民数记 4:23"> “以下是关于利未人的安排：二十五岁以上的要前来，在会幕的服事上供职。</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 4:23; 提摩太后书 4:7"> 到了五十岁，他要退出服事工作，不再服事。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 1:53; 民数记 3:32; 提摩太前书 4:15"> 他可以在会幕中值守，辅助他的弟兄们，但不能做自己的服事。你要这样安排利未人的职责。”</span>
</div>
</div>

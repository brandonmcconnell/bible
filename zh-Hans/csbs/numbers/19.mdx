<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西和亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 22:20–25; 申命记 21:3; 撒母耳记上 6:7"> “以下是耶和华所吩咐的律法条例：你要告诉以色列子民，把一头没有残疾、没有负过轭的无瑕疵红母牛带到你这里。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 4:12; 利未记 4:21; 利未记 16:27"> 你们要把这牛交给祭司以利亚撒，然后领到营地外，在他面前宰杀了。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 4:17; 利未记 4:6; 利未记 16:14"> 祭司以利亚撒要用手指蘸一些母牛的血，向着会幕前面弹洒七次。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 29:14; 利未记 4:11–12; 诗篇 22:14"> 然后这母牛要在他眼前被焚烧，皮、肉、血，连同粪便都要烧掉。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 14:4; 利未记 14:49; 诗篇 51:7"> 祭司要拿来香柏木、牛膝草和朱红色线，扔进焚烧母牛的火中。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 11:25; 利未记 11:40; 民数记 19:8"> 祭司要洗衣服，用水洗身，之后才可以进入营地；祭司会不洁净直到傍晚。</span>
<span className="v" id="v8" data-v="8"> 那焚烧母牛的人，也要用水洗衣服，用水洗身；他会不洁净直到傍晚。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="希伯来书 9:13; 民数记 19:13; 民数记 19:20–21"> “要有一个洁净的人收取那母牛的灰烬，放置在营地外洁净的地方，为以色列会众保存下来，用于调制除污秽的水；这是除罪用的。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 12:49; 民数记 19:7–8; 歌罗西书 3:11"> 那收取母牛灰烬的人要洗衣服，他会不洁净直到傍晚。这要作为以色列子孙和寄居在他们中间的外人永远的律例。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民数记 5:2; 民数记 31:19; 利未记 21:1"> “凡是触碰死尸的人，无论那是谁的尸体，他都会不洁净七天。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 31:19; 启示录 7:14; 利未记 7:17"> 他要在第三天和第七天用那除污秽的水洁净自己，他就得洁净了；如果他在第三天和第七天不洁净自己，他就不得洁净。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 15:31; 利未记 22:3; 利未记 7:20"> 凡是触碰死人尸体的，如果不洁净自己，他就玷污了耶和华的帐幕，这人必须从以色列中被剪除。因为那除污秽的水没有洒在他身上，他仍是不洁净的，他的污秽还在他身上。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> “以下是有人死在帐篷里时的条例：所有进入那帐篷的人或已经在那帐篷里的人，都会不洁净七天。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 14:36; 利未记 11:32; 民数记 31:20"> 帐篷里所有敞口的器皿，就是没有扣上盖子的，都会不洁净。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 31:19; 马太福音 23:27; 路加福音 11:44"> 另外，任何人在田野上触碰被刀剑所杀的，或自然<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="自然——辅助词语。">a</a></sup>死去的，或人的骨头，或坟墓，他也会不洁净七天。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 7:38; 创世记 26:19; 启示录 7:17"> 他们要为不洁净的人取来那赎罪祭牲烧成的灰，放在器皿里，加上活水。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 36:25–27; 希伯来书 9:14; 民数记 19:9"> 要有一个洁净的人拿牛膝草蘸那水，洒在帐篷上、所有器具上以及帐篷里的人身上，也洒在那触碰了人骨头的，或触碰被杀的、自然<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="自然——辅助词语。">b</a></sup>死的，或触碰坟墓的人身上。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约翰一书 1:7; 希伯来书 10:22; 以西结书 36:25"> “洁净的人要在第三天和第七天把那水洒在不洁净的人身上，这样就使他在第七天得洁净；他要洗衣服，用水洗身，到傍晚就洁净了。</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 16:16; 创世记 17:14; 民数记 19:13"> 凡是不洁净的人，如果没有洁净自己，这人就要从会众当中被剪除，因为他玷污了耶和华的圣所；那除污秽的水没有洒在他身上，他就是不洁净的。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 9:13–14; 希伯来书 10:4; 希伯来书 9:10"> 这要作为他们永远的律例。洒这除污秽之水的人，要洗自己的衣服；凡是触碰除污秽之水的人，都会不洁净直到傍晚。</span>
<span className="v" id="v22" data-v="22" data-xref="哈该书 2:13; 利未记 7:19; 马太福音 15:19–20"> 那不洁净的人碰过的任何东西都不洁净，触碰那些东西的人也会不洁净直到傍晚。”</span>
</div>

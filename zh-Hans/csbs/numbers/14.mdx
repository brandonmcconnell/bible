<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="NUM" data-book-slug="numbers" data-book-name="民数记" data-chapter="14" data-verses="45">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 1:45; 民数记 11:1–4"> 全体会众就起来，大声喧嚷，那天夜里，民众都哭泣。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 15:24; 出埃及记 17:3; 民数记 16:41"> 以色列子民都向摩西和亚伦发怨言，全体会众对他们说：“我们还不如死在埃及地，或者死在这旷野！</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 14:31–32; 耶利米书 9:3; 诗篇 78:40"> 耶和华为什么要把我们领到这地，使我们倒在刀下呢？我们的妻子和孩童要成为掠物了！我们回埃及不是更好吗？”</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 7:39; 尼希米记 9:16–17; 申命记 17:16"> 他们又彼此说：“让我们立一个首领，回埃及去吧！”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民数记 16:4; 民数记 16:22; 民数记 16:45"> 摩西和亚伦就在以色列子孙全体会众面前脸伏于地。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 14:30; 民数记 13:30; 民数记 14:38"> 那时，探察那地的人当中，嫩的儿子约书亚和耶弗尼的儿子迦勒撕裂衣服，</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 13:27; 申命记 1:25; 申命记 8:7–9"> 对全体以色列会众说：“我们过去探察的那地，是极其美好的地方。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 22:20; 以赛亚书 62:4; 民数记 13:27"> 如果耶和华喜悦我们，他必把我们带进那地，把那流奶与蜜之地赐给我们；</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 7:18; 罗马书 8:31; 申命记 31:6"> 至于你们，不要背叛耶和华！不要怕那地的民，他们是我们的猎物；他们的保障已经离开他们了，但耶和华与我们同在。你们不要怕他们！”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及记 17:4; 撒母耳记上 30:6; 利未记 9:23"> 但全体会众说要用石头砸死这二人。这时，耶和华的荣耀在会幕中向全体以色列子民显现。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="诗篇 78:32; 诗篇 106:24; 诗篇 78:22"> 耶和华对摩西说：“这子民藐视我，要到什么时候呢？我在他们当中行了这一切神迹，他们还不相信我，要到什么时候呢？</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 32:10; 民数记 25:9; 撒母耳记下 24:12–15"> 我要用瘟疫打击他们，不让他们继承那地，却使你成为一个比他们强大的民族。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="诗篇 106:23; 以西结书 20:9; 申命记 32:27"> 但摩西对耶和华说：“埃及人必听见这事。要知道，你用你的大能将这子民从他们当中带上来，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 15:14; 出埃及记 33:11; 申命记 5:4"> 他们会告诉这地的居民；这些居民也听说了：你耶和华与这子民同在，你耶和华曾被人亲眼看见，你的云彩停留在子民上面，你白天在云柱中、黑夜在火柱中，行走在他们前头。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 6:16"> 你如果把这子民全都<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="全都——原文直译“如同一人”。">a</a></sup>杀掉，那些听过你名声的民族就会议论说：</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 9:28; 约书亚记 7:9; 约书亚记 7:7"> ‘耶和华因为不能领这子民进入他起誓要给他们的那地，所以在旷野把他们宰杀了。’</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 9:6; 马太福音 9:8; 弥迦书 3:8"> “现在，愿我主彰显大能！正如你曾宣告说：</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 34:6–7; 诗篇 145:8; 出埃及记 20:5"> ‘耶和华不轻易发怒，并有丰盛的慈爱；他赦免罪孽和过犯，但绝不会让有罪的免于罪责，而会追究罪责，从父亲到儿子，直到第三代、第四代’，</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 34:9; 诗篇 78:38; 诗篇 106:45"> 求你照着你的大慈爱赦免这子民的罪孽，就像从埃及到如今你一直赦免这子民一样。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="弥迦书 7:18–20; 雅各书 5:16; 诗篇 106:23"> 耶和华说：“我已经照你的祈求赦免了他们。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 72:19; 哈巴谷书 2:14; 以赛亚书 6:3"> 然而我指着我的永生起誓，指着那充满全地的耶和华的荣耀起誓：</span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 19:3; 创世记 31:7; 出埃及记 32:1"> 虽然这些人全都看见过我的荣耀，以及我在埃及、在旷野所行的神迹，他们却试探了我这十次，并没有听从我的话，</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 32:11; 民数记 26:64; 以西结书 20:15"> 所以，他们绝不会见到我所起誓赐给他们先祖的那地，所有藐视我的人都不会见到。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 14:6–9; 约书亚记 14:6–14; 以弗所书 6:6"> 但我的仆人迦勒，因他有与他们不同的灵<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="与他们不同的灵——或译作“不同的心志”。">b</a></sup>，全心跟从我，我要把他带进他曾进去的那地，他的后裔也必继承那地。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 1:40; 民数记 13:29; 诗篇 81:11–13"> 亚玛力人和迦南人住在山间平地，明天你们要转回，沿着通往红海的路往旷野前行。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和华又指示摩西和亚伦说：</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 16:12; 哥林多前书 10:10; 出埃及记 16:28"> “这邪恶的会众，他们向我发怨言要到什么时候呢？以色列子民向我所发的怨言，我都听见了。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 14:21; 希伯来书 3:17; 民数记 14:2"> 你要对他们说，这是耶和华的宣告：我指着我的永生起誓，我必定照着你们在我耳中所说的话对待你们。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 1:45; 哥林多前书 10:5; 希伯来书 3:17"> 你们这些被数点过的，就是二十岁以上所有在名单中的，都将横尸在这旷野中，因为你们向我发怨言。</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 26:65; 民数记 14:38; 申命记 1:36–38"> 除了耶弗尼的儿子迦勒和嫩的儿子约书亚以外，你们绝不会进入我举手起誓要让你们安居其中的那地；</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 1:39; 诗篇 106:24; 民数记 26:64"> 但你们的孩童，就是你们说将成为掠物的，我要带他们进去，他们将得见你们所厌弃的那地。</span>
<span className="v" id="v32" data-v="32" data-xref="哥林多前书 10:5; 民数记 14:29; 希伯来书 3:17"> 至于你们，你们将横尸在这旷野中，</span>
<span className="v" id="v33" data-v="33" data-xref="以西结书 23:35; 民数记 32:13; 申命记 2:14"> 你们的子孙将在旷野游牧四十年，承担你们不忠贞的罪，直到你们全都横尸在旷野中。</span>
<span className="v" id="v34" data-v="34" data-xref="以西结书 4:6; 民数记 13:25; 耶利米书 18:9–10"> 按你们探察那地的天数，共四十天，一天算一年，你们要承担你们的罪责四十年。这样你们就知道敌对我的后果<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="敌对我的后果——或译作“我疏远你们了”。">c</a></sup>。</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 23:19; 哥林多前书 10:5; 希伯来书 3:19"> 我耶和华发了话，就必如此对待这一切聚集起来敌对我的邪恶会众，他们必在这旷野中灭尽，死在这里。”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="民数记 13:31–33; 民数记 13:4–16"> 摩西派去探察那地的人回来后，散布有关那地的谣言，以致全体会众向摩西发怨言，</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前书 10:10; 民数记 16:49; 希伯来书 3:17"> 这些散布那地可怕谣言的人就遭受瘟疫，死在耶和华面前。</span>
<span className="v" id="v38" data-v="38" data-xref="约书亚记 14:6–10; 民数记 26:65"> 这些去探察那地的人当中，只有嫩的儿子约书亚和耶弗尼的儿子迦勒活了下来。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出埃及记 33:4; 马太福音 8:12; 希伯来书 12:17"> 摩西将这些话告诉了全体以色列子民，人们就极其悲恸。</span>
<span className="v" id="v40" data-v="40" data-xref="申命记 1:41; 马太福音 7:21–23; 路加福音 13:25"> 他们清早起来，上到山地高处，说：“我们来了，我们要上耶和华应许的那地方去！我们实在犯了罪。”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="历代志下 24:20; 约伯记 4:9; 耶利米书 2:37"> 摩西说：“你们为什么又要违背耶和华的吩咐呢？这不会成功的。</span>
<span className="v" id="v42" data-v="42" data-xref="申命记 1:42; 约书亚记 7:8; 约书亚记 7:12"> 你们不要上去，以免败在你们仇敌面前，因为耶和华不在你们当中。</span>
<span className="v" id="v43" data-v="43" data-xref="民数记 13:29; 民数记 14:25; 历代志下 15:2"> 亚玛力人和迦南人就在那里，在你们前头，你们必倒在刀下。因为你们既然转离不跟从耶和华，耶和华也必不与你们同在。”</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="申命记 1:43; 撒母耳记上 4:3–11; 民数记 31:6"> 他们却擅自上山地高处去，尽管耶和华的约柜和摩西都没有从营地中出来。</span>
<span className="v" id="v45" data-v="45" data-xref="民数记 21:3; 士师记 1:17; 申命记 1:44"> 于是住在那山地的亚玛力人和迦南人下来击杀他们，击溃他们，直到霍尔玛。</span>
</div>
</div>

</div>

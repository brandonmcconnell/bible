<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 22:1; 民数记 31:12; 民数记 33:50"> 耶和华在耶利哥东边约旦河对面的摩押平原，指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 14:3–4; 以西结书 48:8; 约书亚记 21:2–42"> “你要吩咐以色列子民，让他们从所得的继业中，分给利未人一些城居住，也把这些城周围的牧野给利未人。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 11:14; 约书亚记 21:11; 以西结书 45:2"> 这些城要用来给他们居住，而牧野用来安置他们所拥有的牛羊<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他们所拥有的牛羊——或译作“他们的牛羊、他们的财物”。">a</a></sup>和一切牲畜。</span>
<span className="v" id="v4" data-v="4"> 你们给利未人的那些城郊牧野，要从城墙算起，四围向外一千肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一千肘——相当于457公尺。1肘=45.7公分。">b</a></sup>；</span>
<span className="v" id="v5" data-v="5"> 然后从城外那里测量，向东边两千肘<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="两千肘——相当于914公尺；下同。">c</a></sup>，向南边两千肘，向西边两千肘，向北边两千肘，城要在中间。这是给他们的城郊牧野。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约书亚记 21:13; 约书亚记 21:3; 诗篇 9:9"> “你们给利未人的城，其中要有六座逃城，让过失杀人者可以逃到那里；在六座之外，还要给他们四十二座城。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 21:3–42; 历代志上 6:54–81"> 你们要给利未人的城一共是四十八座城，还包括城郊的牧野。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 26:54; 民数记 33:54; 约书亚记 21:1–42"> 你们从以色列子孙的产业中分给利未人那些城，多的要多给，少的要少给。各支派要根据所得的继业，把一些城分给利未人。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 耶和华指示摩西说：</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 12:9; 申命记 19:1–2; 利未记 14:34"> “你要吩咐以色列子民，对他们说：当你们过了约旦河，到迦南地时，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 21:13; 约书亚记 20:2; 民数记 35:6"> 要为自己选定几座城作逃城，使无意中杀了人的凶手可以逃到那里。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 20:3–6; 申命记 19:6; 约书亚记 20:9"> 这些城要作你们逃避报血仇者的避难所，这样过失杀人者就不至于死，等候站在会众面前受审判。</span>
<span className="v" id="v13" data-v="13"> 你们分给利未人的城，有六座要为你们作逃城：</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 19:8–10; 申命记 4:41–43; 约书亚记 20:7–9"> 在约旦河对岸指定三座城，在迦南地也指定三座城，作为逃城。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 15:16; 加拉太书 3:28; 罗马书 3:29"> 这六座城要给以色列子孙，以及那些外人和寄居在他们中间的人作避难所，好让任何无意中杀了人的可以逃到那里。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="利未记 24:17; 创世记 9:5–6; 申命记 19:11–13"> “但如果有人用铁器打人致死，他就是故意杀人的，这凶手必须被处死。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 21:18"> 如果有人手里拿着可打死人的石头打人致死，他就是故意杀人的，这凶手必须被处死。</span>
<span className="v" id="v18" data-v="18"> 或者有人手里拿着可打死人的木器打人致死，他就是故意杀人的，这凶手必须被处死。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 20:3; 申命记 19:6; 申命记 19:12"> 报血仇的人要亲自把凶手处死，遇见他时，就要处死他。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 21:14; 申命记 19:11; 撒母耳记下 3:27"> 如果有人因仇恨推倒人或故意向人扔东西，致其死亡，</span>
<span className="v" id="v21" data-v="21"> 或者因仇恨动手打人致死，这打死人的必须被处死，他是故意杀人的。报血仇的人遇见凶手时，就要把他处死。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数记 35:11; 出埃及记 21:13; 约书亚记 20:3"> “如果有人毫无仇恨而突然推倒了人，或者并非故意把任何器具扔在人身上，</span>
<span className="v" id="v23" data-v="23"> 或者因没看见而把任何可打死人的石头砸在人身上，致其死亡，他本不是那人的仇敌，也不是谋害那人，</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 20:6; 民数记 35:12"> 会众就要在这凶手和报血仇的人之间，按照这些法规审判。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 29:7; 利未记 4:3; 罗马书 3:24–26"> 会众要从报血仇的人手中救出这过失杀人者，让他回到他曾逃入的逃城。他要住在城中，直到以圣油膏立的大祭司去世。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> “但如果那过失杀人者擅自出了他所逃入的逃城的地界，</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 22:2; 申命记 19:10; 申命记 19:6"> 报血仇的人在逃城地界外遇见那杀人者，把他杀了，报血仇的人并不负血债。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 3:14; 希伯来书 10:26–30; 希伯来书 6:4–8"> 因为那过失杀人者应该留在逃城，直到大祭司去世；大祭司去世以后，他才可以回到他产业之地。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 27:11; 民数记 27:1"> 这要在你们居住的任何地方，作你们世世代代的律例法规。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="希伯来书 10:28; 申命记 19:15; 马太福音 18:16"> “无论谁杀了人，都要凭几个见证人的口来处决凶手；不可只凭一个见证人的指证来处死人。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 19:11–13; 创世记 9:5–6; 诗篇 51:14"> 你们不可接受赎金来保全杀人者的性命，他犯了死罪，必须被处死。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 4:12; 加拉太书 3:10–13; 加拉太书 2:21"> 你们也不可接受那逃入逃城之人的赎金，让他在大祭司去世之前回本地居住。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 11:50–51; 诗篇 106:38; 何西阿书 4:2–3"> “这样，你们就不会玷污你们所在之地，因为血会使地玷污；如果有血流在地上，除非藉着那流人血之人的血，地就无法赎清罪污。</span>
<span className="v" id="v34" data-v="34" data-xref="民数记 5:3; 诗篇 135:21; 启示录 21:27"> 你们不可玷污所住之地，因为我也住在那里，我耶和华就住在以色列子民中间。”</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 21:1; 利未记 13:46; 民数记 12:14"> “你要吩咐以色列子民：把所有患麻风病的、所有患漏症的、所有因接触尸体而不洁净的，都从营里送出去。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 23:14; 利未记 26:11–12; 诗篇 68:18"> 无论男女，都要送出去。你们要把他们送到营地外面，以免玷污了他们的营地，因为我居住在他们中间。”</span>
<span className="v" id="v4" data-v="4"> 以色列子民就这样做，把他们送到营地外面。耶和华所指示摩西的，以色列子民都照着做了。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 耶和华指示摩西说：</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 5:1–4; 利未记 5:14–7"> “你要吩咐以色列子民：如果有男人或女人犯了人常犯的任何罪，以致不忠于耶和华，那人就要承担罪责。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 5:5; 利未记 26:40; 约书亚记 7:19"> 他要承认自己所犯的罪，按全数对他的亏负作出赔偿，并且加上五分之一，交给他所亏负的人。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 6:6–7; 利未记 7:7; 利未记 25:25–26"> 但如果被亏负的人没有近亲为他接受损害赔偿，那么，这损害赔偿以及犯罪之人的赎罪祭公绵羊，都归于耶和华，归给祭司。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 18:3–4; 利未记 7:6–14; 利未记 6:17–18"> 以色列子民带到祭司那里的所有圣物中，凡是供物，都要归给祭司。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 10:13"> 各人的圣物原属于自己，各人献到祭司那里的，要归给祭司。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和华指示摩西说：</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 5:19–20; 箴言 2:16–17"> “你要吩咐以色列子民，对他们说：如果一个人的妻子行为不轨，对丈夫不忠，</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 18:20; 利未记 20:10; 箴言 7:18–19"> 有男人与她同寝交合，但她瞒过了丈夫，隐藏了这事，她使自己受玷污却没有见证人，也没有被捉住——</span>
<span className="v" id="v14" data-v="14" data-xref="雅歌 8:6; 箴言 6:34; 西番雅书 3:8"> 无论是丈夫起了猜忌的心，猜忌妻子，而她确实玷污了自己，或者是丈夫起了猜忌的心，猜忌妻子，而她并没有玷污自己——</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 29:16; 列王纪上 17:18; 利未记 5:11"> 这个人就要把自己的妻子带到祭司那里，并且为她带来祭物，就是十分之一伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十分之一伊法——相当于2.2公升。1伊法＝22公升。">a</a></sup>大麦粉。不可浇上油，也不可加上乳香，因为这是猜忌的素祭，是想起罪孽的反思素祭。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="启示录 2:22–23; 耶利米书 17:10; 希伯来书 13:4"> “祭司要让她上前来，站在耶和华面前。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 30:18; 约翰福音 8:6; 民数记 19:2–9"> 祭司要用瓦器取圣水，还要取一些在帐幕地面上的尘土，放在水中。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 5:4; 民数记 5:22; 启示录 10:9–10"> 祭司要让那女人站在耶和华面前，散开那女人的头发，然后把反思素祭，就是猜忌的素祭，放在她手掌上。祭司要手里端着会带来诅咒的苦水，</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 7:2; 民数记 5:12; 马太福音 26:63"> 让那女人起誓，对她说：‘如果没有别的男人与你同寝，如果你在丈夫权下没有行为不轨受玷污，你就免于这诅咒苦水的罪罚。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 5:12"> 但如果你在丈夫权下行为不轨，与丈夫以外的男人交合，玷污了自己——’</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 6:26; 尼希米记 10:29; 撒母耳记上 14:24"> 这时祭司要让那女人以诅咒的誓言起誓，然后对那女人说：‘当耶和华使你大腿萎缩、肚子肿胀的时候，愿耶和华使你在族人中间成为诅咒和誓语。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 109:18; 诗篇 89:52; 约伯记 31:39–40"> 愿这带来诅咒的水进入你的肚腹，使肚子肿胀、大腿萎缩。’那女人就要说：‘阿们，阿们。’</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 3:19; 诗篇 51:1; 诗篇 51:9"> “祭司要将这些诅咒写在书卷上，把这些字擦抹到苦水里。</span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亚书 5:3–4; 玛拉基书 3:5"> 之后要让那女人喝这带来诅咒的苦水，这诅咒的水就会进入她体内产生痛苦。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 8:27; 民数记 5:18; 民数记 5:15"> 祭司要从那女人手中接过猜忌的素祭，在耶和华面前把这素祭摇一摇，然后带到祭坛那里。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 2:2; 利未记 2:9; 利未记 5:12"> 祭司要从素祭中捧出一把，作为记念部分，在祭坛上烧献为烟，然后让女人喝那水。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米书 42:18; 撒迦利亚书 8:13; 耶利米书 29:18"> “祭司让她喝那水以后：如果她玷污了自己，对她丈夫不忠，这带来诅咒的水就会进到她体内，产生痛苦。她的肚子会肿胀，她的大腿会萎缩，那女人就在族人中间成为诅咒。</span>
<span className="v" id="v28" data-v="28" data-xref="弥迦书 7:7–10; 哥林多后书 4:17; 诗篇 113:9"> 但如果那女人没有使自己受玷污，她是清白的，她就免于罪罚，仍然能怀孕生子。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数记 5:19; 民数记 5:12; 民数记 5:15"> “这就是关于猜忌的条例：如果妻子在丈夫权下行为不轨，玷污了自己，</span>
<span className="v" id="v30" data-v="30"> 或者丈夫起了猜忌的心，猜忌自己的妻子，就要让那女人站在耶和华面前，祭司要对她执行这一切条例。</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 20:10; 罗马书 2:8–9; 以西结书 18:4"> 这样丈夫就免于罪责，那女人却要承担自己的罪责。”</span>
</div>
</div>

</div>

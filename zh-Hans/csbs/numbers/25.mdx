<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 10:8; 民数记 33:49; 约书亚记 2:1"> 以色列住在什亭的时候，民众开始与摩押女子行淫。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 10:20; 出埃及记 20:5; 出埃及记 34:15–16"> 这些女子邀请民众参加她们神明的祭祀，民众吃了祭物，又向她们的神明下拜。</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 22:17; 诗篇 106:28–29; 何西阿书 9:10"> 这样，以色列与毗珥的巴力联合，耶和华的怒气就向以色列发作。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 13:17; 申命记 4:3; 申命记 21:23"> 耶和华对摩西说：“你把民众的首领都带来，在日光之下，在耶和华面前把他们处死示众，好让耶和华的烈怒转离以色列。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及记 18:21; 列王纪上 18:40; 申命记 13:9"> 摩西就对以色列的审判官们说：“你们各人要把你们当中与毗珥的巴力联合的人杀掉。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约珥书 2:17; 民数记 22:4; 耶利米书 36:23"> 摩西和全体以色列会众正在会幕的入口哭泣时，看哪，以色列子民中有一个人前来，在他们眼前把一个米甸女子带到弟兄们那里。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 6:25; 诗篇 106:30; 约书亚记 22:30–31"> 祭司亚伦的孙子、以利亚撒的儿子非尼哈看见了，就从会众当中起身，手拿长矛，</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 16:46–48; 诗篇 106:29–31; 历代志上 21:22"> 跟在那以色列人后面进了帐篷，用长矛把那以色列人和女子两人刺透，一直刺入女子的肚腹。这样，瘟疫就从以色列子民中止住了。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 10:8; 申命记 4:3–4; 民数记 25:4–5"> 当时死于瘟疫的，有两万四千人。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 耶和华指示摩西说：</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 32:21; 诗篇 78:58; 申命记 32:16"> “祭司亚伦的孙子、以利亚撒的儿子非尼哈使我的怒火转离了以色列子民，因为他在他们中间因我的妒火而发热心，使我没有在妒火中灭绝以色列子民。</span>
<span className="v" id="v12" data-v="12" data-xref="玛拉基书 2:4–5; 玛拉基书 3:1; 以赛亚书 54:10"> 因此你要告诉他：看哪，我把我的平安之约赐给他，</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 2:17; 罗马书 10:2–4; 耶利米书 33:22"> 这约将成为他和他后裔永远担任祭司的约，因为他为他的神而嫉愤，为以色列子民赎了罪。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 1:23; 民数记 26:14; 历代志下 19:7"> 那个与米甸女子一同被杀的以色列人，名叫泽姆利，是萨鲁的儿子，是西缅一个宗族的领袖。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 31:8; 约书亚记 13:21; 民数记 25:18"> 那个被杀的米甸女子名叫柯兹比，是苏珥的女儿，苏珥是米甸一个宗族的首领。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 耶和华指示摩西说：</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 31:1–3; 启示录 18:6"> “你要扰害米甸人，击杀他们。</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 2:14; 出埃及记 32:35; 哥林多后书 11:3"> 因为他们以诡计扰害你们，就是在毗珥的事情上，以及他们的姐妹、米甸领袖的女儿柯兹比的事情上行诡诈对付你们；这柯兹比，已经在瘟疫的日子里，因毗珥的事情而被杀。”</span>
</div>

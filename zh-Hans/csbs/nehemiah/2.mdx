<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯拉记 7:1; 尼希米记 1:11; 尼希米记 1:1"> 到了亚达薛西王二十年的尼散月，那时酒摆在王面前，我举起酒呈递给王。我在他面前从来没有过愁容，</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 15:13; 创世记 40:7"> 所以王对我说：“你没有患病，为什么脸上有愁容呢？这一定是你心里愁烦。”<br />我极其害怕，</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 1:3; 但以理书 2:4; 列王纪上 1:31"> 就对王说：“愿王万岁！我脸上怎能不愁烦呢？我祖先坟墓所在之城荒废了，城门也被火吞噬了！”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="腓立比书 4:6; 箴言 3:6; 尼希米记 1:4"> 王问我说：“那么，你想要什么呢？”<br />我就向天上的神祷告，</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 14:22; 路得记 2:13; 以斯帖记 7:3"> 然后对王说：“如果王认为好，如果仆人在你面前蒙恩，就请派遣我到犹大，到我祖先坟墓所在之城去，让我重建那城。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="尼希米记 13:6; 以赛亚书 65:24; 尼希米记 5:14"> 那时王后在王的旁边坐着，王对我说：“你的行程要多久，你什么时候回来？”王看这事为好，就派我去，我也向王承诺了一个日期。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 7:21; 以斯拉记 8:36; 尼希米记 2:9"> 我又对王说：“如果王认为好，请赐给我诏书，吩咐大河<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="大河——指幼发拉底河。">a</a></sup>对岸的省长们准许我通行，直到我进入犹大；</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 7:6; 以赛亚书 66:14; 尼希米记 7:2"> 也赐给看守王室园林的亚萨一份诏书，让他给我木材，好为圣殿旁边堡垒的门、为城墙和我入住的房屋架上木梁。”王准许了我，因我神施恩的手在帮助我。</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉记 8:22"> 于是，我来到大河对岸的省长们那里，把王的诏书交给他们；王还派遣了一些将领和马兵与我同行。</span>
<span className="v" id="v10" data-v="10" data-xref="尼希米记 2:19; 尼希米记 4:7; 尼希米记 13:4"> 但贺伦人叁巴拉和作官的亚扪人托比亚听说了，就因有人来为以色列人谋福利而极其恼恨。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以斯拉记 8:32"> 我来到耶路撒冷，在城里待了三天。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 17:17; 以斯拉记 7:27; 耶利米书 31:33"> 然后，我和跟随我的几个人在夜间起身——我的神使我心中起意要为耶路撒冷做什么事，我并没有告诉任何人；除了我所骑的牲口之外，我也没有带其他牲口——</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 1:3; 尼希米记 2:3; 尼希米记 3:13–14"> 我夜间出了谷门，到龙泉前面，又到粪场门，一路察看耶路撒冷被拆毁的城墙和被火吞噬的城门。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 3:15; 列王纪下 20:20; 历代志下 32:30"> 然后我前行，到泉门，又到王池，但那里没有地方容我所骑的牲口过去。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 15:23; 约翰福音 18:1; 耶利米书 31:38–40"> 于是我当夜沿着溪流上去，一路察看城墙，然后返回，进入谷门，就回来了。</span>
<span className="v" id="v16" data-v="16"> 我去了哪里，做了什么，官长们都不知道；之前我也没有告诉犹太人、祭司、贵族、官长们以及其余参与这工程的人。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 5:14; 尼希米记 1:3; 以赛亚书 35:3–4"> 这时我对他们说：“你们看到了我们所遭受的患难，就是耶路撒冷荒废，城门被火烧毁。来吧，让我们重建耶路撒冷的城墙，使我们不再受羞辱。”</span>
<span className="v" id="v18" data-v="18" data-xref="腓立比书 2:13; 历代志下 32:5; 历代志上 19:13"> 我又告诉他们，我神的手怎样施恩帮助了我，以及王对我说过的话。他们就说：“我们起来建造吧！”于是他们坚强起来，去做这善工。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="尼希米记 6:6; 尼希米记 6:1–2; 诗篇 44:13–14"> 但贺伦人叁巴拉和作官的亚扪人托比亚，以及阿拉伯人革谢姆听说了，就嘲笑我们，轻视我们，并且说：“你们在做什么呢？难道你们要背叛王吗？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="使徒行传 8:21; 以斯拉记 4:3; 诗篇 35:27"> 我回话给他们，对他们说：“天上的神，他会使我们成功。我们是他的仆人，我们要起来建造；至于你们，在耶路撒冷无份、无权利、无渊源。”</span>
</div>
</div>

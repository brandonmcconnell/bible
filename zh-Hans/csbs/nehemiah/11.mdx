<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 48:2; 以赛亚书 52:1; 尼希米记 11:18"> 那时，民众的首领们在耶路撒冷住下来，其余的民众抽签，要从每十人中抽出一人住在圣城耶路撒冷，余下的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="余下的——原文直译“手中的”。">a</a></sup>九人住在各城镇。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 5:9; 哥林多后书 8:16–17; 约伯记 29:13"> 凡是甘愿奉献自己住在耶路撒冷的人，民众都为他们祝福。</span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 2:1; 以斯拉记 2:43; 历代志上 9:1–34"> 以色列人、祭司、利未人、圣殿仆役和所罗门臣仆的子孙，住在犹大的各城镇，各人住在本城自己的地业中。以下是住在耶路撒冷的犹大<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="犹大——辅助词语。">b</a></sup>省众首领，</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 38:29; 马太福音 1:3; 路加福音 3:33"> 以及住在耶路撒冷的一些犹大子孙和便雅悯子孙。<br /><span className="pl pl-1">犹大的子孙有：</span><br />法勒斯的子孙亚塔雅，他是乌西雅的儿子，乌西雅是撒迦利亚的儿子，撒迦利亚是亚玛利雅的儿子，亚玛利雅是示法提雅的儿子，示法提雅是玛勒列的儿子；</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="历代志上 9:5; 尼希米记 3:15; 民数记 26:20"> 还有玛西雅，他是巴录克的儿子，巴录克是科尔霍泽的儿子，科尔霍泽是哈扎雅的儿子，哈扎雅是亚达雅的儿子，亚达雅是约雅立的儿子，约雅立是撒迦利亚的儿子，撒迦利亚是示拉<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="示拉——或译作“示罗人”。">c</a></sup>的子孙。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 住在耶路撒冷的法勒斯子孙，总共四百六十八人，都是勇士。</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="历代志上 9:7–9"> <span className="pl pl-1">便雅悯的子孙有：</span><br />萨鲁，他是米书兰的儿子，米书兰是约耶的儿子，约耶是皮达雅的儿子，皮达雅是科赖雅的儿子，科赖雅是玛西雅的儿子，玛西雅是伊铁勒的儿子，伊铁勒是耶赛亚的儿子；</span>
<span className="v" id="v8" data-v="8"> 在他之后，有迦拜、萨雷。<br />他们共有九百二十八人，</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 9:7"> 泽克利的儿子约珥是他们的督军，哈西努亚的儿子犹大是那城的副长官。</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="历代志上 9:10; 尼希米记 12:6; 尼希米记 12:19"> <span className="pl pl-1">祭司有：</span><br />约雅立的儿子耶达亚；又有雅斤；</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 9:11; 历代志上 6:7–14; 民数记 3:32"> 还有神殿总管西莱雅，他是希勒加的儿子，希勒加是米书兰的儿子，米书兰是撒督的儿子，撒督是米拉约的儿子，米拉约是亚希突的儿子；</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 9:12–13"> 还有他们那些为圣殿做工的兄弟，八百二十二人；<br />还有亚达雅，他是耶罗罕的儿子，耶罗罕是佩拉利雅的儿子，佩拉利雅是阿姆基的儿子，阿姆基是撒迦利亚的儿子，撒迦利亚是帕示户珥的儿子，帕示户珥是玛基雅的儿子；</span>
<span className="v" id="v13" data-v="13"> 还有亚达雅那些作父系首领的兄弟们，两百四十二人；<br />还有亚玛沙伊，他是阿扎列的儿子，阿扎列是阿赫扎伊的儿子，阿赫扎伊是米实列莫的儿子，米实列莫是伊梅尔的儿子；</span>
<span className="v" id="v14" data-v="14"> 还有他们的兄弟们，都是英勇的战士，有一百二十八人，哈基多琳的儿子撒巴迪业是他们的督军。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="历代志上 9:14; 历代志上 9:19"> <span className="pl pl-1">利未人有：</span><br />示玛雅，他是哈述的儿子，哈述是亚斯利甘的儿子，亚斯利甘是哈沙比雅的儿子，哈沙比雅是布尼的儿子；</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 6:2–3; 尼希米记 8:7; 以斯拉记 8:33"> 还有管理神殿外部事务的利未首领沙比泰和约撒巴；</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 9:15; 历代志上 25:1–6; 尼希米记 12:8–9"> 还有祷告时首先献上感谢的领队玛塔尼亚，他是米迦的儿子，米迦是扎布迪的儿子，扎布迪是亚萨的儿子；还有巴克布迦，他是兄弟中的副领队；还有阿布达，他是沙慕亚的儿子，沙慕亚是迦拉的儿子，迦拉是耶杜顿的儿子。</span>
<span className="v" id="v18" data-v="18" data-xref="尼希米记 11:1; 启示录 21:2; 但以理书 9:24"> 在圣城的利未人，总共两百八十四人。</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="尼希米记 7:45; 历代志上 9:17–22; 诗篇 84:10"> <span className="pl pl-1">门卫有：</span><br />阿库布、达门，以及他们那些看守城门的兄弟，一百七十二人。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="尼希米记 11:3"> 其余的以色列人、祭司和利未人，都在犹大的各城镇，各在自己的继业之地。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米记 3:26; 历代志下 27:3; 尼希米记 3:31"> 圣殿仆役住在俄斐勒，由西哈和基斯帕管理这些圣殿仆役。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="尼希米记 12:42; 历代志上 25:1–6; 以斯拉记 8:19"> 在耶路撒冷的利未人的监督是乌基，他是巴尼的儿子，巴尼是哈沙比雅的儿子，哈沙比雅是玛塔尼亚的儿子，玛塔尼亚是米迦的儿子，是亚萨的子孙。亚萨子孙是歌手，也负责神殿的事务；</span>
<span className="v" id="v23" data-v="23" data-xref="以斯拉记 7:20–24; 尼希米记 12:47; 以斯拉记 6:8–9"> 因为王对他们有规定，歌手每天的事务都有确定的条例。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 38:30; 历代志上 18:17; 历代志上 23:28"> 佩塔希雅代表王管理民众的一切事务，他是米示萨别的儿子，是犹大儿子谢拉的子孙。</span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="约书亚记 14:15; 约书亚记 15:21–22"> 至于他们的村庄和郊野：<br /><span className="pl pl-1">犹大子孙中，有些人住在</span><br /><span className="pl pl-1">基列-阿尔巴和附属的村镇、</span><br /><span className="pl pl-1">迪本和附属的村镇，</span><br /><span className="pl pl-1">耶克策勒和附属的村庄，</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="约书亚记 15:26–27; 约书亚记 19:2"> <span className="pl pl-1">耶书亚，莫拉达，伯帕列，</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="创世记 26:33; 约书亚记 15:28; 士师记 20:1"> <span className="pl pl-1">哈萨书尔，比尔-谢巴和附属的村镇，</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 27:6; 约书亚记 15:31"> <span className="pl pl-1">洗革拉，米克纳和附属的村镇，</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 19:41; 约书亚记 15:32–33; 约书亚记 15:35"> <span className="pl pl-1">恩临门，佐拉，雅尔慕，</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 10:3; 约书亚记 15:8; 约书亚记 18:16"> <span className="pl pl-1">撒挪亚、亚杜兰和它们附属的村庄，</span><br /><span className="pl pl-1">拉吉和附属的郊野，亚西加和附属的村镇。</span><br /><span className="pl pl-1">他们支搭帐篷，从比尔-谢巴直到欣嫩子谷。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="创世记 12:8; 约书亚记 8:9; 约书亚记 18:13"> <span className="pl pl-1">便雅悯的子孙所住之地</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="所住之地——辅助词语。">d</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">是从迦巴起，到米克玛，艾雅，</span><br /><span className="pl pl-1">伯特利和附属的村镇，</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="约书亚记 21:18; 以赛亚书 10:30; 撒母耳记上 21:1"> <span className="pl pl-1">亚纳图，挪伯，亚纳尼亚，</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 4:3; 撒母耳记上 7:17; 约书亚记 18:25"> <span className="pl pl-1">哈佐，拉玛，吉塔伊姆，</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记上 13:18"> <span className="pl pl-1">哈迪，策伯伊姆，尼巴拉特，</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="历代志上 8:12; 尼希米记 7:37; 历代志上 4:14"> <span className="pl pl-1">罗德，阿挪，以及匠人谷。</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="约书亚记 21:1–45; 创世记 49:7; 历代志上 6:54–81"> <span className="pl pl-1">犹大地区各班组的一些利未人</span><br /><span className="pl pl-1">住在便雅悯人中间。</span></span>
</div>
</div>

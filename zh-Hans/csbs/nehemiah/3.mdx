<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 12:39; 耶利米书 31:38; 约翰福音 5:2"> 那时，大祭司以利亚实起来，与他的兄弟众祭司建造羊门。他们把它分别为圣，安装门扇；从百楼到哈楠业楼，也都分别为圣了。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米记 7:36; 以斯拉记 2:34; 尼希米记 10:12"> 在他旁边的一段，由耶利哥人建造。在耶利哥人旁边的一段，由伊姆利的儿子扎克尔建造。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="历代志下 33:14; 尼希米记 12:39; 西番雅书 1:10"> 哈西纳的子孙建造鱼门；他们为它架上木梁，安装门扇、门锁和门闩。</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉记 8:33; 尼希米记 3:21; 尼希米记 10:7"> 在他们旁边的一段，由哈克兹的孙子、乌利亚的儿子米利莫修建。在他们旁边的一段，由米示萨别的孙子、比利迦的儿子米书兰修建。在他旁边的一段，由巴纳的儿子撒督修建。</span>
<span className="v" id="v5" data-v="5" data-xref="尼希米记 3:27; 撒母耳记下 14:2; 耶利米书 27:2"> 在他们旁边的一段，由提克亚人修建，不过他们的贵族没有承担他们主的工作。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="尼希米记 12:39"> 帕西亚的儿子耶赫亚达和贝索德雅的儿子米书兰修建古门；他们为它架上木梁，安装门扇、门锁和门闩。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 21:2; 约书亚记 9:3–27; 尼希米记 3:19"> 在他们旁边的一段，由基遍人米拉提和米伦人雅敦修建，他们是大河<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="大河——指幼发拉底河。">a</a></sup>对岸的省长所管辖的基遍和米斯巴的人。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米记 12:38; 尼希米记 3:31–32; 创世记 50:2"> 在他们旁边的一段，由赫尔哈雅的儿子银匠乌基业修建。在他旁边的一段，由调制香膏的匠人哈纳尼雅修建。他们修复耶路撒冷，直到宽墙。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="尼希米记 3:12; 尼希米记 3:17"> 在他们旁边的一段，由户珥的儿子，就是耶路撒冷半个行政区的长官勒法雅修建。</span>
<span className="v" id="v10" data-v="10" data-xref="尼希米记 3:28–30; 尼希米记 10:4; 尼希米记 3:23"> 在他们旁边的一段，由哈路玛的儿子耶达雅在自己家对面修建。在他旁边的一段，由哈沙尼的儿子哈突施修建。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 12:38; 以斯拉记 2:6; 尼希米记 10:14"> 哈琳的儿子玛基雅和帕哈摩押的儿子哈述修建另一段，包括炉楼。</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米记 3:9; 使徒行传 21:8–9; 出埃及记 35:25"> 在他们旁边的一段，由哈罗赫施的儿子，就是耶路撒冷另半个行政区的长官沙勒姆和他的女儿们修建。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="尼希米记 2:13; 约书亚记 15:34; 历代志下 26:9"> 哈嫩和撒挪亚的居民修建谷门；他们建造它，安装门扇、门锁和门闩，又修建一千肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一千肘——相当于457公尺。1肘=45.7公分。">b</a></sup>城墙，直到粪场门。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 6:1; 尼希米记 2:13; 尼希米记 3:12–13"> 利甲的儿子，就是伯哈基琳行政区的长官玛基雅修建粪场门；他建造它，安装门扇、门锁和门闩。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 9:7; 以赛亚书 8:6; 尼希米记 12:37"> 科尔霍泽的儿子，就是米斯巴行政区的长官沙仑修建泉门。他建造泉门，给它封顶，安装门扇、门锁和门闩，又建造王室园子旁边西罗亚池那里的城墙，直到从大卫城伸下来的台阶。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行传 2:29; 尼希米记 3:9; 列王纪下 20:20"> 在他之后的一段，由押布的儿子，就是伯促尔半个行政区的长官尼希米修建，直到大卫的坟墓对面，又到蓄水池，又到勇士之家。</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 15:44; 尼希米记 3:16; 撒母耳记上 23:1–13"> 在他之后的一段，由利未人巴尼的儿子利户姆修建。在他旁边的一段，是由基伊拉半个行政区的长官哈沙比雅为自己的行政区修建。</span>
<span className="v" id="v18" data-v="18"> 在他之后的一段，由他们的兄弟希纳达的儿子宾努伊<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="宾努伊——辅助词语。">c</a></sup>，就是基伊拉另半个行政区的长官巴瓦伊修建。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 26:9; 尼希米记 10:9; 尼希米记 12:8"> 在他旁边的另一段，由耶书亚的儿子，就是米斯巴的首领以谢尔，从城墙凸角的兵器库上坡对面修建。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="尼希米记 3:1; 传道书 9:10; 罗马书 12:11"> 在他之后的另一段，由撒该的儿子巴录克热心修建，从城墙凸角直到大祭司以利亚实的家门口。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米记 7:63; 以斯拉记 2:61"> 在他之后的另一段，由哈克兹的孙子、乌利亚的儿子米利莫修建，从以利亚实的家门口直到以利亚实家的尽头。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米记 12:28; 尼希米记 6:2"> 在他之后的一段，由那些来自周边地区的祭司修建。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="尼希米记 10:2; 尼希米记 8:4; 尼希米记 3:29–30"> 在他们之后的一段，由便雅悯和哈述在自己的家对面修建。在他们之后的一段，由亚纳尼亚的孙子、玛西雅的儿子亚撒利雅在自己的家旁边修建。</span>
<span className="v" id="v24" data-v="24" data-xref="尼希米记 3:19; 尼希米记 3:27; 尼希米记 10:9"> 在他之后的另一段，由希纳达的儿子宾努伊修建，从亚撒利雅的家直到城墙的凸角，又到城角。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 32:2; 耶利米书 37:21; 尼希米记 12:39"> 乌扎伊的儿子帕拉尔是从城墙凸角的对面，以及护卫兵院子旁边、王宫上层凸出来的塔楼那里修建。在他之后的一段，由帕罗示的儿子皮达雅，</span>
<span className="v" id="v26" data-v="26" data-xref="尼希米记 8:1; 尼希米记 11:21; 尼希米记 12:37"> 以及住在俄斐勒的圣殿仆役修建，直到东边的水门对面和凸出来的塔楼那里。</span>
<span className="v" id="v27" data-v="27" data-xref="尼希米记 3:5"> 在他们之后的另一段，由提克亚人修建，从凸出来的大塔楼对面直到俄斐勒的城墙。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="历代志下 23:15; 耶利米书 31:40; 列王纪下 11:16"> 从马门往上，由祭司们各自在自己的家对面修建。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 19:2; 以斯拉记 2:37; 尼希米记 7:40"> 在他们之后的一段，由伊梅尔的儿子撒督在自己的家对面修建。在他之后的一段，由谢喀尼亚的儿子示玛雅修建，他是东门的守卫。</span>
<span className="v" id="v30" data-v="30"> 在他之后的另一段，由示勒米雅的儿子哈纳尼雅和萨勒弗的第六个儿子哈嫩修建。在他们之后的一段，由比利迦的儿子米书兰在自己的房间对面修建。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米记 3:8; 尼希米记 3:32"> 在他之后的一段，由银匠玛基雅修建，直到检阅门对面圣殿仆役和客商的住房那里，又到角楼。</span>
<span className="v" id="v32" data-v="32" data-xref="尼希米记 3:1; 约翰福音 5:2; 尼希米记 12:39"> 在角楼与羊门之间的一段，由银匠们和客商修建。</span>
</div>

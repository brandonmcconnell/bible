<span className="v" id="v11" data-v="11"> <span className="pl pl-1">耶赫亚达生约拿单，约拿单生雅杜亚。</span></span>

<span className="v" id="v23" data-v="23" data-xref="历代志上 9:14–44"> 利未子孙各父系的首领都被记在年代志上，直到以利亚实的儿子约哈南时期。</span>

<span className="v" id="v25" data-v="25" data-xref="历代志上 26:15; 尼希米记 12:8–9; 历代志上 26:12"> 玛塔尼亚、巴克布迦、俄巴底亚、米书兰、达门、阿库布是门卫，是看守各城门旁仓库的守卫。</span>

<span className="v" id="v26" data-v="26" data-xref="尼希米记 8:9; 以斯拉记 7:6; 以斯拉记 7:11"> 以上的人，在约萨达的孙子、耶书亚的儿子约雅金时期，以及省长尼希米和祭司经文士以斯拉时期供职。</span>
</div>

<span className="v" id="v28" data-v="28" data-xref="历代志上 9:16; 历代志上 2:54; 尼希米记 6:2"> 歌手们就从耶路撒冷周边地区，从尼托法人的村庄，</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 10:43; 历代志上 6:60; 以斯拉记 2:24"> 从伯吉甲，从迦巴和阿兹玛维的田野被招聚起来，因为歌手们在耶路撒冷四围建造了自己的村庄。</span>
<span className="v" id="v30" data-v="30" data-xref="约伯记 1:5; 出埃及记 19:10; 历代志下 29:5"> 于是祭司和利未人洁净了自己，又洁净民众，以及城门和城墙。</span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="尼希米记 2:13; 尼希米记 12:38; 历代志上 13:1"> 我把犹大的首领们带到城墙上面，又安排了两大队颂赞队伍。一队在城墙的上面向右边，往粪场门行进。</span>
<span className="v" id="v32" data-v="32"> 走在队伍后面的有何沙雅和一半的犹大首领，</span>
<span className="v" id="v33" data-v="33" data-xref="尼希米记 10:2–7"> <span className="pl pl-1">以及亚撒利雅、以斯拉、米书兰、</span><br /></span>
<span className="v" id="v34" data-v="34"> <span className="pl pl-1">犹大、便雅悯、示玛雅、耶利米。</span><br /></span>

<span className="v" id="v36" data-v="36" data-xref="尼希米记 12:24; 历代志下 8:14; 历代志上 23:5"> <span className="pl pl-1">还有撒迦利亚的兄弟们</span><br /><span className="pl pl-1">示玛雅、阿扎列、米拉莱、</span><br /><span className="pl pl-1">基拉莱、玛艾、拿旦业、</span><br /><span className="pl pl-1">犹大、哈纳尼，</span><br /><span className="pl pl-1">都拿着神人大卫的乐器。</span><br /><span className="pl pl-1">经文士以斯拉走在他们前头。</span></span>

<div className="bp poetry">
<span className="v" id="v40" data-v="40" data-xref="诗篇 42:4; 诗篇 134:1–3; 尼希米记 12:31–32"> 于是这两队颂赞队伍站在神的殿中，我和与我一起的一半官长也在那里；</span>
<span className="v" id="v41" data-v="41"> <span className="pl pl-1">还有众祭司以利亚敬、玛西雅、珉雅悯、米该亚、以利约奈、撒迦利亚、哈纳尼雅，都拿着号筒；</span><br /></span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 81:1; 尼希米记 11:14; 诗篇 100:1–2"> <span className="pl pl-1">还有玛西雅、示玛雅、以利亚撒、</span><br /><span className="pl pl-1">乌基、约哈南、玛基雅、以拦、以谢尔；</span><br /><span className="pl pl-1">歌手们歌唱，伊斯拉希雅作指挥。</span></span>

<span className="v" id="v44" data-v="44" data-xref="尼希米记 13:12–13; 尼希米记 10:37–39; 历代志下 31:11–13"> 当天，一些人受指派管理那些存放供物、初熟果实和十一奉献的库房，要把律法所定祭司和利未人的份从各城的田野收存在其中。犹大人都因这些祭司和侍立的利未人而喜乐，</span>
<span className="v" id="v45" data-v="45" data-xref="历代志上 25:1–26; 历代志下 23:6; 历代志上 23:28"> 祭司和利未人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="祭司和利未人——原文直译“他们”。">a</a></sup>谨守他们的神所赐的职责和洁净的职责；歌手和门卫也谨守大卫和他儿子所罗门的规定，</span>

<span className="v" id="v47" data-v="47" data-xref="民数记 18:21–29; 尼希米记 12:26; 尼希米记 13:10–12"> 这样，在所罗巴伯时期和尼希米时期，全体以色列人一直供应歌手和门卫的份，就是他们每天需用的份额；并且把分别为圣的奉献物给利未人，利未人也把分别为圣的奉献物给亚伦的子孙。</span>

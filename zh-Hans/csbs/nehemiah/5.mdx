<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 5:7; 出埃及记 22:25–27; 哥林多前书 6:6–8"> 那时，民众和他们的妻子向他们的犹太弟兄们发出极大的哀声。</span>
<span className="v" id="v2" data-v="2" data-xref="玛拉基书 2:2; 诗篇 128:2–4; 诗篇 127:3–5"> 有些人说：“我们儿女众多，请让我们得一点粮食吃，活下去吧！”</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 25:35–39; 玛拉基书 3:8–11; 创世记 47:15–25"> 也有些人说：“我们用田地、葡萄园和房屋作抵押，才得一点粮食度过饥荒！”</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉记 4:13; 以斯拉记 4:20; 申命记 28:47–48"> 还有些人说：“我们用田地和葡萄园借了银子给王纳税。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 4:1; 利未记 25:39–43; 以赛亚书 58:7"> 其实，我们的血肉与我们兄弟的血肉同源，我们的儿女与他们的儿女一样，看哪，我们却迫使自己的儿女作仆婢，我们的一些女儿也被强行夺走，我们却无能为力，因我们的田地和葡萄园都归属别人了。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 11:8; 尼希米记 13:25; 以弗所书 4:26"> 我听到他们的哀声和这些话的时候，非常恼火。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 23:19–20; 利未记 25:36; 出埃及记 22:25"> 我心里作了决定，就谴责那些贵族和官长，对他们说：“你们竟然向各自的兄弟放贷取利！”然后，我针对他们召开大会，</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 25:47–49; 哥林多前书 8:11; 马太福音 25:29"> 对他们说：“我们竭尽全力把那些被卖到外邦的犹太弟兄赎回来，而你们竟然卖掉自己的弟兄，卖给了我们自己人！”他们都沉默，无话可说。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 25:36; 撒母耳记下 12:14; 罗马书 2:24"> 我又说：“你们所做的这事不好。你们行事，难道不应该敬畏我们的神，以免受到我们外邦仇敌的羞辱吗？</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 6:1; 出埃及记 22:25–27; 以西结书 18:13"> 我和我的兄弟们、我的下属也在借出银子和粮食给民众。现在让我们都放弃这利息吧！</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 58:6; 利未记 6:4–5; 路加福音 3:8"> 今天就应当把他们的田地、葡萄园、橄榄园和房屋，以及向他们索取的利息——百分之一的银子、五谷、新酒和新油，都归还给他们！”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以斯拉记 10:5; 耶利米书 34:8–10; 马太福音 19:21–22"> 他们回答：“我们必归还，不再向他们索要。我们必这样照着你所说的去做。”<br />于是我把祭司召来，让他们起誓要照着这话去做。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 18:6; 历代志上 16:36; 马太福音 10:14"> 我又抖着我的衣襟说：“凡是不履行这话的人，愿神也这样把他从他的家业、从他的辛苦所得中抖出去！愿他这样被抖出去，一无所有！”<br />全体会众都说：“阿们！”然后赞美耶和华。民众就照着这话去做。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="尼希米记 13:6; 帖撒罗尼迦后书 3:8–9; 哥林多前书 9:4–15"> 此外，从王任命我作犹大地省长的日子起，就是从亚达薛西王二十年，直到三十二年，这十二年来，我和我的兄弟们都没有吃过省长的俸禄。</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米记 5:9; 以赛亚书 50:10; 箴言 16:6"> 在我之前的历任省长使民众的负担沉重，除了征收四十谢克尔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="四十谢克尔——相当于456公克。1谢克尔=11.4公克。">a</a></sup>银子外，还向他们征收粮食和酒，连他们的下属也辖制民众。但我因敬畏神的缘故，不这样做。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太书 6:9; 帖撒罗尼迦前书 2:5–6; 哥林多前书 15:58"> 而且，我还坚持做这城墙的工程，我的下属也都聚集在那里参与这工程，我们也没有购买田地。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王纪上 18:19; 彼得前书 4:9–10; 撒母耳记下 9:7"> 那时一些犹太人和官长们，共一百五十人，还有从周围那些民族来到我们这里的人，都与我一同坐席。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 4:22–23; 诗篇 37:21; 诗篇 37:26"> 每天要准备的，有一头公牛、六只精选的羊和一些飞禽，都是由<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="由——或译作“为”。">b</a></sup>我准备的，每隔十天还有许多各样的酒。虽然如此，我也没有索要过省长的俸禄，因为这些民众承担的工作已经够沉重了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="尼希米记 13:31; 诗篇 106:4; 尼希米记 13:14"> 我的神哪，求你记念我为这些民众所做的一切，恩待我！</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯拉记 7:6; 尼希米记 3:26; 历代志下 34:15"> 那时，全体民众如同一人聚集到水门对面的广场上。他们请经文士以斯拉将耶和华颁布给以色列的摩西律法书带来。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 23:24; 玛拉基书 2:7; 民数记 29:1"> 七月一日，祭司以斯拉将律法书带到会众——男人、女人以及所有能听明白的人面前。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 3:22; 启示录 2:29; 希伯来书 2:1–3"> 他在水门前的广场那里，从天亮到中午，在男人、女人以及那些能明白的人面前，宣读这律法书，全体民众都侧耳倾听。</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉记 10:29; 尼希米记 12:13; 尼希米记 10:20"> 经文士以斯拉站在为这事制作的木台上，他旁边站着的，右边是玛塔提雅、示玛、亚奈雅、乌利亚、希勒加和玛西雅，左边是皮达雅、米沙利、玛基雅、哈书姆、哈示巴达纳、撒迦利亚和米书兰。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 3:20; 列王纪上 8:14; 路加福音 4:16–17"> 以斯拉在全体民众眼前打开书卷，当时他在全体民众的上方。他一打开书卷，全体民众都站了起来。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前书 2:8; 耶利米哀歌 3:41; 出埃及记 4:31"> 以斯拉颂赞耶和华伟大的神，全体民众高举双手回应：“阿们，阿们！”然后俯身，脸伏于地向耶和华下拜。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="尼希米记 9:4; 利未记 10:11; 尼希米记 3:23"> 耶书亚、巴尼、示利比、雅悯、阿库布、沙比泰、霍迪亚、玛西雅、基利达、亚撒利雅、约撒巴、哈南、佩拉雅等利未人，向民众教导律法，民众都站在自己的位置上。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 24:45; 使徒行传 28:23; 路加福音 24:32"> 这些人宣读神的律法书，讲解阐释，使民众明白所诵读的。</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米记 7:65; 尼希米记 7:70; 申命记 12:12"> 省长尼希米和祭司经文士以斯拉，以及那些教导民众律法的利未人，对全体民众说：“今天是你们的神耶和华的圣日，你们不要悲恸，不要哭泣。”这是因为全体民众听见律法上的话语时，都哭了。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 28:7–8; 箴言 17:22; 哥林多后书 12:8–9"> 以斯拉对他们说：“你们去吃美食、喝美酒吧，也分一些给那些无法为自己预备的人，因为今天是我们主的圣日。你们不要忧伤，因为耶和华所赐的喜乐是你们的保障。”</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 13:30"> 利未人也让全体民众平静下来，说：“大家安静！今天是圣日，你们不要忧伤。”</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 119:174; 诗篇 119:111; 诗篇 119:130"> 于是全体民众都去吃喝，也送食物给人，并且举行了盛大的庆祝，因为他们明白了那些教导给他们的内容。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 2:1–6; 箴言 8:33–34; 箴言 12:1"> 第二天，全体民众的父系首领们、祭司和利未人都聚集到经文士以斯拉那里，为要查考律法上的话。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 23:34; 申命记 16:13–15; 利未记 23:40–43"> 他们发现律法上记着：耶和华藉着摩西吩咐以色列子民，要在七月的节期住在棚子里，</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 23:40; 申命记 16:16; 利未记 23:4"> 并要在他们各城和耶路撒冷通告、传令说：“你们要上山去，带回来橄榄树的枝子、野橄榄树的枝子、香桃木的枝子、棕榈树的枝子以及各种茂密树的枝子，搭建棚子，正如律法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="律法——辅助词语。">a</a></sup>上所记的。”</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米记 12:39; 列王纪下 14:13; 尼希米记 12:37"> 于是民众出去，带回来枝子，在自己家屋顶上、院子里，在神殿的庭院里，在水门的广场上，在以法莲门的广场上，各人为自己搭了棚子。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 8:13; 以斯拉记 3:4; 历代志下 7:8–10"> 从流亡之地回归的全体会众都搭了棚子，住在棚子里。自从嫩的儿子约书亚的日子直到这天，以色列子孙都没有这样做过，那时有极大的欢庆。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 29:35; 利未记 23:36; 申命记 31:10–13"> 从第一天到最后一天，以斯拉每天宣读神的律法书。他们守节期七天，然后照着规定在第八天举行了严肃集会。</span>
</div>

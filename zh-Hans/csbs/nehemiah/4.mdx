<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 2:10; 希伯来书 11:36; 诗篇 35:15–16"> <sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="此章在马索拉文本为3:33至4:17。">a</a></sup>那时叁巴拉听说我们在建造城墙，就发怒，非常恼火，并且嘲笑犹太人。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯拉记 4:9–10; 哥林多前书 1:27; 以西结书 37:3–13"> 他在他的兄弟们和撒玛利亚军兵面前议论，说：“这些弱小的犹太人在做什么呢？难道他们要凭自己修复城墙吗？难道他们要献祭吗？他们要在一天之内完工吗？他们要从灰土堆中使那些被烧毁的石头复原吗？”</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 2:19; 列王纪上 20:10; 尼希米记 2:10"> 亚扪人托比亚在他旁边也说：“是啊，他们所建造的石墙，就算一只狐狸上去，也能踩塌！”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="诗篇 79:12; 诗篇 123:3–4; 箴言 3:34"> 我们的神哪，求你垂听，因为我们被藐视！求你使他们的辱骂回到自己头上，使他们成为掠物被掳到外地。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 109:14; 耶利米书 18:23; 诗篇 69:27–28"> 不要遮盖他们的罪孽，不要从你面前抹掉他们的罪，因为他们在建造的人面前挑衅。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="腓立比书 2:13; 尼希米记 6:15; 希伯来书 13:21"> 这样，我们建造城墙，整个城墙都连起来了，并且达到一半的高度，因为民众都用心做工。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="尼希米记 2:10; 尼希米记 4:1; 使徒行传 5:33"> 那时叁巴拉和托比亚，以及阿拉伯人、亚扪人和阿实突人听说耶路撒冷城墙的修复工作还在进行，破口开始被堵上了，他们就非常恼火。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 83:3–11; 以赛亚书 8:9–10; 耶利米书 20:10"> 他们所有人一同密谋，要来攻打耶路撒冷，制造混乱。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 5:8; 使徒行传 4:24–30; 诗篇 50:15"> 于是我们向我们的神祷告，并因他们的缘故派守卫站岗，日夜防备他们。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 11:1–2; 哈该书 1:2; 历代志下 2:18"> 但犹大人说：“搬运工已经筋疲力竭，灰土却还有许多，我们不能继续建造城墙了！”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="帖撒罗尼迦前书 5:2; 使徒行传 23:12; 诗篇 56:6"> 我们的敌人说：“我们要趁着他们还不知道，还没察觉，就进入他们中间杀了他们，使这工程终止。”</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 31:7; 创世记 31:41; 民数记 14:22"> 那时，住在那些人附近的犹太人也十次来告诉我们，他们在策划各种阴谋对付我们<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="他们在策划各种阴谋对付我们——或译作“无论我们转向哪里，他们都会攻击我们”。">b</a></sup>。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 4:17–18; 以弗所书 6:11–20; 雅歌 3:7–8"> 于是我让民众在城墙后面那些低洼的空地站岗，让他们按着家族，带着刀剑、长矛和弓箭站着。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 10:12; 民数记 14:9; 以赛亚书 41:10–14"> 我检阅后，起来对贵族、官长们以及其余的民众说：“不要怕他们。你们当记住我们大而可畏的主，要为你们的兄弟、儿女、妻子和你们的家业争战！”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 17:14; 罗马书 12:11; 约伯记 5:12–13"> 那时，我们的仇敌听说我们知道了这事，神也破坏了他们的计谋。于是我们都回到城墙那里，各自回到自己的工作上。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米记 4:23; 诗篇 101:6; 尼希米记 5:15–16"> 从那天起，我的下属有一半做工，一半装备着长矛、盾牌、弓箭和铠甲；首领们跟在犹大全家后面。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 6:7; 提摩太后书 4:7; 提摩太后书 2:3"> 那些建造城墙的人和背负重物的搬运工，都一手做工，一手握着兵器。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 10:9; 历代志下 13:12–17"> 建造的人各自腰间佩着刀剑建造，吹角的人在我旁边。</span>
<span className="v" id="v19" data-v="19"> 我对贵族、官长们以及其余的民众说：“这工程浩大宽广，我们在城墙上彼此分散得很远。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 14:14; 申命记 1:30; 申命记 20:4"> 你们无论在什么地方听见号角声，都要聚集到我们这里。我们的神必为我们争战。”</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太书 6:9; 歌罗西书 1:29; 哥林多前书 15:58"> 这样我们继续做工，一半的人握着长矛，从天亮的时候直到星辰出现。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米记 11:1–2"> 那时，我还对民众说：“你们各人和你们的下属要在耶路撒冷城中过夜，这样可以夜间守城，白天做工。”</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 9:48; 尼希米记 7:2; 哥林多前书 15:10"> 于是我和我的兄弟们、我的下属，以及跟随我的守卫们，没有一个人脱下衣服，各人喝水时也拿着<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="拿着——辅助词语。">c</a></sup>兵器。</span>
</div>

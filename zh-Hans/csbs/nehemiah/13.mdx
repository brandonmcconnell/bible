<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="NEH" data-book-slug="nehemiah" data-book-name="尼希米记" data-chapter="13" data-verses="31">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 23:3–5; 尼希米记 9:3; 尼希米记 13:23"> 那一天，他们宣读摩西的书给民众听，发现其中记着：亚扪人和摩押人永不可加入神的会众，</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 23:5; 约书亚记 24:9–10; 民数记 23:8–11"> 因为这些人没有带着食物和水迎接以色列子孙，反而雇用巴兰对付他们，诅咒他们——但我们的神使诅咒变成了祝福。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 9:2; 出埃及记 12:38; 民数记 11:4"> 那时，民众听见了这律法，就把所有混杂的族群从以色列中分离出去。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="尼希米记 12:44; 尼希米记 6:17–18; 尼希米记 13:28"> 在这之前，托比亚的亲戚，就是受指派管理我们神殿库房的祭司以利亚实，</span>
<span className="v" id="v5" data-v="5" data-xref="尼希米记 12:44; 历代志下 34:11; 民数记 18:21–24"> 给托比亚准备了一个大房间，那里从前用来存放供物、乳香、器皿，以及按照诫命给利未人、歌手和门卫的五谷、新酒和新油的十一奉献，还有归给祭司的供物。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="尼希米记 5:14; 尼希米记 2:5–6; 马太福音 13:25"> 这一切发生的时候，我不在耶路撒冷，因为巴比伦王亚达薛西三十二年，我回到了王那里。过了一些日子，我向王请假，</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米记 13:5; 马太福音 21:12–13; 耶利米哀歌 1:10"> 又来到耶路撒冷，才知道以利亚实为托比亚所做的恶事，他在神殿的庭院里为托比亚准备了一个房间。</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 11:15–17; 以斯拉记 10:1; 诗篇 69:9"> 这使我非常生气，我就把托比亚的家具全都从房间里扔到外面去了。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 29:5; 历代志下 29:15–19; 尼希米记 12:45"> 我吩咐人洁净了那些房间，又让人把神殿的器皿与供物和乳香都搬回那里。</span>
<span className="v" id="v10" data-v="10" data-xref="尼希米记 10:37; 玛拉基书 3:8; 玛拉基书 1:6–14"> 我还得知利未人的份没有得到供应，以致事奉的利未人和歌手各自离开，到自己的田地去了。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 10:39; 尼希米记 13:17; 尼希米记 13:25"> 我就谴责官长们，说：“为什么神的殿被撇弃呢？”然后我招聚利未人和歌手，让他们回到自己的服事岗位上；</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米记 10:37–39; 玛拉基书 3:10; 尼希米记 12:44"> 全体犹大人也把五谷、新酒和新油的十一奉献带到了库房。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 22:7; 尼希米记 7:2; 尼希米记 12:44"> 我委派祭司示勒米雅、经文士撒督和利未人皮达雅管理库房，他们的助手是哈南，哈南是扎克尔的儿子，扎克尔是玛塔尼亚的儿子；他们被公认是忠实的人，所以让他们来负责给兄弟们分配当得的份。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="诗篇 122:6–9; 尼希米记 13:22; 尼希米记 13:31"> 我的神哪，求你为此记念我，不要抹掉我为神的殿、为神殿的职守所尽的忠诚！</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="尼希米记 10:31; 尼希米记 13:21; 出埃及记 34:21"> 在那些日子里，我在犹大看到安息日有人踹榨酒池，有人搬运谷堆，有人用驴子驮东西，还有人在安息日把酒、葡萄、无花果和各样的货物运到耶路撒冷。我就在他们卖食物的那天警诫他们。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 23:12; 申命记 5:14"> 有些住在那里的提尔人也把鱼和各样的商品运来，在安息日卖给犹大人，而且是在耶路撒冷城内卖的。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="尼希米记 13:11; 尼希米记 13:25; 以赛亚书 1:10"> 于是我谴责犹大的贵族，对他们说：“你们怎么做出这样的恶事，亵渎安息日呢？</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 17:21–23; 耶利米书 44:9; 民数记 32:14"> 从前你们的祖先难道不是如此行事，以致我们的神使这一切祸患临到我们和这城吗？现在你们竟然亵渎安息日，要使烈怒再次临到以色列！”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="利未记 23:32; 出埃及记 31:14–17; 耶利米书 17:19–22"> 于是，在安息日之前，黄昏笼罩耶路撒冷城门时，我吩咐把各城门关上，并且吩咐安息日结束之前不可打开城门。我还派我的一些下属在各城门站岗，不让人在安息日把货物运进来。</span>
<span className="v" id="v20" data-v="20"> 于是，客商和卖各样东西的人有几次留宿在耶路撒冷城外。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 13:3–4; 彼得前书 2:14; 以斯拉记 7:26"> 我就警诫他们，对他们说：“你们为什么留宿在城墙那里呢？如果你们再这样，我就出手对付你们了。”从那时起，他们在安息日就不来了。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米记 12:30; 尼希米记 13:14; 尼希米记 13:31"> 我吩咐利未人要洁净自己，然后来看守各城门，尊安息日为圣。<br />我的神哪，求你也为此记念我，照着你丰盛的慈爱顾惜我！</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以斯拉记 9:1–2; 以斯拉记 10:10; 尼希米记 10:30"> 在那些日子里，我还看到犹太人娶了阿实突、亚扪和摩押的女子，</span>
<span className="v" id="v24" data-v="24" data-xref="西番雅书 3:9"> 他们的儿女有一半说阿实突话，或说各民族的语言，没有人会说犹太话。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 7:3; 尼希米记 13:17; 尼希米记 10:29–30"> 我就谴责他们，诅咒他们，责打他们中的一些人，拔掉他们的胡须，然后让他们指着神起誓，对他们说<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="对他们说——辅助词语。">a</a></sup>：“你们绝不可把你们的女儿嫁给外邦人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="外邦人——原文作“他们”。">b</a></sup>的儿子，也绝不可为你们的儿子、为自己娶他们的女儿。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 11:1–8; 列王纪上 3:13; 传道书 7:26"> 以色列王所罗门难道不是在这样的事上犯罪了吗？在许多国家中没有一个王像他那样，蒙他的神所爱，神也使他作全以色列的王，然而他还是受外邦女子引诱而犯罪了！</span>
<span className="v" id="v27" data-v="27" data-xref="以斯拉记 10:2; 撒母耳记上 30:24"> 难道我们要听任你们行这一切大恶，娶外邦女子，以致对我们的神不忠吗？”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="尼希米记 2:19; 尼希米记 3:1; 尼希米记 12:22"> 大祭司以利亚实的儿子耶赫亚达有一个儿子，是贺伦人叁巴拉的女婿，我把他从我身边赶走了。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="尼希米记 6:14; 民数记 25:12–13; 玛拉基书 2:4–8"> 我的神哪，求你记住他们，因他们玷污了祭司的职份，玷污了有关祭司职份和利未人的约。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="尼希米记 10:30; 尼希米记 12:1–26; 历代志上 23:1–26"> 这样，我洁净他们脱离了外邦人的一切，又为祭司和利未人确立了职责，各尽其职；</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米记 13:14; 尼希米记 13:22; 诗篇 106:4"> 也安排了定期奉献木柴的事，以及初熟之物的事。<br />我的神哪，求你记念我，恩待我！</span>
</div>
</div>

</div>

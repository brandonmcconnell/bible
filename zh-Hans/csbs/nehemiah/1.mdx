<span className="v" id="v1" data-v="1" data-xref="尼希米记 10:1; 撒迦利亚书 7:1; 以斯帖记 1:2"> 哈迦利亚的儿子尼希米的话语： 耶路撒冷的消息<br />亚达薛西王<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="亚达薛西王——辅助词语。">a</a></sup>二十年的基斯流月，我在苏萨城堡中，</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米记 7:2; 以西结书 6:9; 耶利米书 44:14"> 我的一位兄弟哈纳尼与一些人从犹大来，我就询问那些流亡幸存的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="流亡幸存的——或译作“没有被掳走而留下的”。">b</a></sup>犹太人的情况，以及耶路撒冷的情况。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 2:17; 列王纪下 25:10; 尼希米记 7:6"> 他们对我说：“犹大<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="犹大——辅助词语。">c</a></sup>省那些流亡回归的余剩者<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="流亡回归的余剩者——或译作“没有被掳走的余剩者”。">d</a></sup>，处在大患难和羞辱中；耶路撒冷的城墙被拆毁，城门也被火烧毁了。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="但以理书 9:3; 诗篇 137:1; 以斯拉记 10:1"> 我听了这些话，就坐下来哭泣，悲恸了几天，并在天上的神面前禁食祷告。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 20:6; 但以理书 9:4–19; 申命记 7:21"> 我说：“哦，耶和华天上的神，大而可畏的神！你向爱你并遵守你诫命的人守约施慈爱。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理书 9:20; 但以理书 9:4; 诗篇 34:15"> 唯愿你侧耳听、睁眼看，垂听仆人的祷告。我今天在你面前昼夜为你的仆人以色列子民祷告，为以色列子民认罪——我们对你犯了罪，我和我的父家都犯了罪！</span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 9:5–6; 但以理书 9:11; 但以理书 9:13"> 我们实在败坏亏负了你，没有遵守你向你仆人摩西所吩咐的诫命、律例和法规。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 28:64; 申命记 4:25–27; 利未记 26:33–46"> 求你记念你向仆人摩西所吩咐的话，你曾说：‘如果你们不忠，我就把你们驱散到万民中；</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 29:11–14; 申命记 30:2–5; 申命记 4:29–31"> 但如果你们回转归向我，谨守遵行我的诫命，你们那些被驱赶的人就算是在天边，我也会从那里把他们招聚起来，带到我所选择使我的名安居的地方。’</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 9:29; 但以理书 9:15–27; 出埃及记 32:11"> 他们是你的仆人、你的子民，是你以伟大的能力和大能的手救赎出来的。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 1:6; 尼希米记 2:8; 箴言 21:1"> 哦，主啊，唯愿你侧耳听仆人的祷告，也听那些喜爱敬畏你名的仆人们的祷告！今天求你使你的仆人顺利，使我在王<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="王——原文直译“这人”。">e</a></sup>面前蒙怜悯。”<br />那时我是王的司酒长。</span>
</div>

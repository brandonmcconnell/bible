<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 15:1; 以斯拉记 6:16–18; 历代志下 5:6–7"> 他们把神的约柜抬来，安放在大卫为它支搭的帐篷内，然后在神面前献上燔祭和平安祭。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 47:10; 创世记 14:19; 利未记 1:3"> 大卫献完了燔祭和平安祭，就奉耶和华的名祝福民众，</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 8:10; 以西结书 45:17; 历代志下 35:7–8"> 又分给以色列所有的人，无论男女，每人一个饼、一个枣饼、一个葡萄饼。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="历代志上 23:27–32; 诗篇 72:18; 诗篇 103:2"> 大卫指定一些利未人在耶和华的约柜前事奉，来记念、称谢、赞美耶和华以色列的神。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 6:39; 历代志下 29:25; 历代志上 15:16–24"> 为首的是亚萨，其次是撒迦利亚、耶伊列、示米拉莫、耶希业、玛塔提雅、以利押、比纳雅、俄别·以东和耶伊列，他们弹奏里拉琴和竖琴等乐器，而亚萨奏响铜钹。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 13:12; 历代志下 29:26–28; 历代志下 5:12–13"> 比纳雅和雅哈希两位祭司常在神的约柜前吹号。</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 22:1; 诗篇 18:1; 撒母耳记下 23:1–2"> 那一天，大卫首次指定亚萨和他的族兄弟负责称谢耶和华：</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 105:1–15; 以赛亚书 12:4; 列王纪下 19:19"> <span className="pl pl-1">你们当称谢耶和华，呼求他的名，</span><br /><span className="pl pl-1">在万民中传扬他的作为；</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 3:16; 诗篇 96:1–3; 诗篇 98:1–4"> <span className="pl pl-1">当向他歌唱，歌颂他，</span><br /><span className="pl pl-1">谈论他一切的奇妙作为；</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 7:7–8; 耶利米书 29:13; 诗篇 34:2"> <span className="pl pl-1">当以他的圣名夸耀，</span><br /><span className="pl pl-1">愿寻求耶和华的人心里欢喜！</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 27:8–9; 西番雅书 2:2–3; 诗篇 68:35"> <span className="pl pl-1">你们当寻求耶和华和他的力量，</span><br /><span className="pl pl-1">一直寻求他的容面。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 111:4; 诗篇 119:20; 诗篇 103:2"> <span className="pl pl-1">他的仆人以色列的后裔啊，</span><br /><span className="pl pl-1">他所拣选的雅各的子孙哪，</span><br /><span className="pl pl-1">你们当记念他所行的奇妙作为，</span><br /><span className="pl pl-1">记念他的奇事和他口中的法规！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="诗篇 48:10–11; 以赛亚书 26:9; 出埃及记 15:2"> <span className="pl pl-1">他是耶和华我们的神，</span><br /><span className="pl pl-1">他的公正充满全地。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 105:8; 玛拉基书 4:4; 申命记 7:9"> <span className="pl pl-1">他记念自己的约，直到永远；</span><br /><span className="pl pl-1">记念他所吩咐的话，直到千代——</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="创世记 26:3; 创世记 17:2; 创世记 35:11"> <span className="pl pl-1">就是他与亚伯拉罕所立的约，</span><br /><span className="pl pl-1">向以撒所起的誓；</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="创世记 17:7–8; 创世记 35:11–12; 约书亚记 24:11–13"> <span className="pl pl-1">又把这约给雅各立为律例，</span><br /><span className="pl pl-1">给以色列立为永远的约；</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="创世记 13:15; 弥迦书 2:5; 创世记 17:8"> <span className="pl pl-1">他说：“我要把迦南地赐给你，</span><br /><span className="pl pl-1">作为你们分得的继业。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="创世记 34:30; 申命记 7:7; 使徒行传 7:5"> <span className="pl pl-1">那时他们</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他们——原文作“你们”；参《诗篇》105:12。">a</a></sup><br /><span className="pl pl-1">人数稀少，实在很少，</span><br /><span className="pl pl-1">在那地是寄居的；</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="创世记 46:6; 创世记 20:1; 创世记 46:3"> <span className="pl pl-1">他们从这国流浪到那国，</span><br /><span className="pl pl-1">从这邦流浪到那邦。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="创世记 12:17; 创世记 20:3; 出埃及记 7:15–18"> <span className="pl pl-1">他不容任何人欺压他们，</span><br /><span className="pl pl-1">还为他们的缘故责备君王：</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="创世记 20:7; 诗篇 105:15; 创世记 49:8–10"> <span className="pl pl-1">“你们不可碰我的受膏者，</span><br /><span className="pl pl-1">不可恶待我的先知。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="诗篇 96:1–13; 诗篇 71:15; 以赛亚书 51:6–8"> <span className="pl pl-1">全地啊，你们当向耶和华歌唱，</span><br /><span className="pl pl-1">日复一日地传扬他的救恩！</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 12:2–6; 但以理书 4:1–3; 诗篇 22:27"> <span className="pl pl-1">当在列国中讲述他的荣耀，</span><br /><span className="pl pl-1">在万民中讲述他的奇妙作为；</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 89:7; 诗篇 76:7; 诗篇 66:3–5"> <span className="pl pl-1">因耶和华伟大，当受极大的赞美；</span><br /><span className="pl pl-1">他超越一切神明，当受敬畏；</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 102:25; 利未记 19:4; 以赛亚书 42:5"> <span className="pl pl-1">万民的一切神明都是虚无的偶像，</span><br /><span className="pl pl-1">而耶和华造了诸天。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 16:11; 诗篇 96:6; 诗篇 28:7–8"> <span className="pl pl-1">尊荣和威严在他的面前，</span><br /><span className="pl pl-1">力量和喜乐在他的居所。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 15:10; 腓立比书 4:13; 诗篇 100:1–2"> <span className="pl pl-1">万民万族啊，你们当把荣耀和力量</span><br /><span className="pl pl-1">归给耶和华，归给耶和华！</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="诗篇 100:4; 诗篇 96:9; 以赛亚书 6:3"> <span className="pl pl-1">当把耶和华之名的荣耀归给他，</span><br /><span className="pl pl-1">带着供物，来到他的面前。</span><br /><span className="pl pl-1">当向圣洁威严的耶和华下拜；</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 33:9; 诗篇 148:5–6; 希伯来书 1:3"> <span className="pl pl-1">全地啊，你们当在他面前震撼！</span><br /><span className="pl pl-1">是的，世界被确立，不致动摇！</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 96:10; 启示录 19:6; 诗篇 97:1"> <span className="pl pl-1">愿诸天欢喜，愿大地快乐，</span><br /><span className="pl pl-1">愿人们在列国中说：“耶和华作王了！”</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 148:9–10; 以赛亚书 44:23; 诗篇 98:7–8"> <span className="pl pl-1">愿海洋和其中所充满的澎湃如雷，</span><br /><span className="pl pl-1">愿田野和其中的一切都欢庆。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 98:9; 诗篇 96:12–13; 启示录 11:17–18"> <span className="pl pl-1">那时森林中的树木将在耶和华面前欢呼，</span><br /><span className="pl pl-1">因为他来要审判大地。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="诗篇 106:1; 历代志下 7:3; 诗篇 107:1"> <span className="pl pl-1">你们当称谢耶和华，</span><br /><span className="pl pl-1">他是美善的，他的慈爱永远长存！</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 106:47–48; 彼得前书 2:9; 诗篇 14:7"> <span className="pl pl-1">你们要说：</span><br /><span className="pl pl-1">“拯救我们的神哪，求你拯救我们！</span><br /><span className="pl pl-1">求你从列国中招聚我们、解救我们，</span><br /><span className="pl pl-1">好让我们称颂你的圣名，</span><br /><span className="pl pl-1">以赞美你为福乐！”</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 8:15; 诗篇 72:18–19; 列王纪上 8:56"> <span className="pl pl-1">以色列的神耶和华是当受颂赞的，</span><br /><span className="pl pl-1">从永远到永远</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="永远到永远——或译作“亘古到永远”。">b</a></sup><br /><span className="pl pl-1">。</span><br />全体民众都说“阿们”，并且赞美耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="历代志下 8:14; 以斯拉记 3:4; 历代志上 16:4–6"> 大卫安排亚萨和他的族兄弟在耶和华的约柜前，要按着每天的任务，常在约柜前事奉；</span>
<span className="v" id="v38" data-v="38" data-xref="历代志上 26:10; 历代志上 13:14; 历代志上 25:3"> 还有俄别·以东和他的族兄弟六十八人，耶杜顿的儿子俄别·以东以及何萨作门卫。</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪上 3:4; 历代志上 15:11; 历代志下 1:3–4"> 大卫又安排祭司撒督和他的兄弟众祭司在基遍的高坛，在耶和华的帐幕前事奉，</span>
<span className="v" id="v40" data-v="40" data-xref="民数记 28:3–8; 出埃及记 29:38–42; 历代志下 31:3"> 要照着律法所记的一切，就是耶和华所吩咐以色列的，清晨和傍晚在燔祭的祭坛上向耶和华献上常献的燔祭。</span>
<span className="v" id="v41" data-v="41" data-xref="历代志下 5:13; 历代志上 25:1–6; 历代志下 20:21"> 还有希幔、耶杜顿和其余被选出、被指名的人，与他们一起称谢耶和华：“他的慈爱永远长存！”</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 150:3–6; 历代志上 25:6–7; 历代志下 29:25–28"> 希幔、耶杜顿与他们一同用号筒、铜钹等各种乐器发声歌颂神。耶杜顿的子孙守门。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="撒母耳记下 6:19–20; 创世记 18:19; 诗篇 101:2"> 于是全体民众各回各家，大卫也回去为自己的家人祝福。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 46:12; 创世记 38:29; 民数记 26:20–21"> 犹大的子孙是法勒斯、希斯伦、迦米、户珥和朔巴。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="士师记 13:25; 历代志上 2:52–54; 约书亚记 15:33"> 朔巴的儿子利阿亚生雅哈，<br />雅哈生亚户买和拉哈；<br />这些是佐拉人的各家族。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="士师记 15:11; 历代志下 11:6"> 以坦人之祖如下：耶斯列、伊施玛、伊得巴，他们的妹妹名字是哈慈勒珀妮；</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="历代志上 4:18; 历代志上 2:50; 历代志上 4:39"> 毗努伊勒是格多的父亲；<br />以谢尔是户沙的父亲；<br />这些都是伯利恒之祖户珥的子孙。户珥是以法她的长子。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="历代志上 2:24"> 提克亚人之祖亚施户有两个妻子：赫拉和拿拉。</span>
<span className="v" id="v6" data-v="6"> 拿拉生了亚户撒、希弗、提米尼、阿哈示塔利，这些都是拿拉的儿子。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 赫拉的儿子是洗列、琐哈尔和伊提南。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 克兹生了阿诺布、措比巴，以及哈仑之子阿哈黑尔的各家族。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 4:21; 历代志上 7:23; 创世记 35:18"> 雅比斯比他的兄弟们更有尊荣。他母亲给他起名为雅比斯，说：“我在痛苦中生的。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 7:7–11; 诗篇 116:1–4; 箴言 10:22"> 雅比斯呼求以色列的神说：“但愿你大大祝福我，扩大我的边界！愿你的手与我同在，愿你使我脱离祸患，不受伤害！”神成全了他的祈求。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 书哈的兄弟基律生了伊施屯之父米希尔。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 伊施屯生了伯拉法、帕西亚，以及纳哈什城<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="纳哈什城——或译作“珥-纳哈什”。">a</a></sup>之祖提欣纳；这些就是利迦人。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约书亚记 15:17; 士师记 1:13; 士师记 3:9–11"> 基纳斯的儿子是俄陀聂和西莱雅。<br />俄陀聂的儿子是哈塔、</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 11:35; 列王纪下 24:14"> 梅诺泰，梅诺泰生了俄弗拉。<br />西莱雅生了哈拉欣谷<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="哈拉欣谷——或译作“格哈拉欣人”、“匠人谷”。">b</a></sup>之祖约押，他们都是工匠。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数记 13:6; 民数记 14:6–10; 约书亚记 15:13–20"> 耶弗尼之子迦勒的子孙是以路、以拉和拿安，以拉的儿子是基纳斯。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 耶哈利勒的儿子是西弗、西法、提利和亚撒列。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="历代志上 4:19; 历代志上 6:57; 约书亚记 15:50"> 以斯拉的儿子是耶特尔、米列、以弗和雅伦。米列所娶法老的女儿比提娅生了米利暗、沙买和以实提莫之祖益巴，这些是比提娅的儿子；米列的犹大妻子生了格多之祖雅列，梭哥之祖希伯和撒挪亚之祖耶库蒂尔。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 15:44; 撒母耳记上 23:1–13"> 霍迪亚的妻子是娜娢的姐妹，她的儿子是迦米人基伊拉之祖，以及玛迦人以实提莫之祖。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 示门的儿子是暗嫩、林拿、本哈南和提伦。<br />伊示的子孙是泽赫特和便泽赫特。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 38:5; 历代志上 2:3; 民数记 26:20"> 犹大的儿子示拉的子孙是：利迦之祖珥，玛利沙之祖拉阿达，在伯亚实比织造细麻布的各家族。</span>
<span className="v" id="v22" data-v="22"> 还有约敬，克则巴人，在摩押作了主人的约阿施和萨拉，以及雅叔比利恒，这些是古代的记录。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 81:6; 历代志上 4:14"> 他们都是陶匠，是尼塔因和格德拉的居民，他们住在那里为王工作。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="创世记 46:10; 出埃及记 6:15; 民数记 26:12–14"> 西缅的子孙是尼姆利、雅悯、雅立、谢拉和扫罗；</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 扫罗的儿子沙勒姆，沙勒姆的儿子米比衫，米比衫的儿子米施玛。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 米施玛的子孙是米施玛的儿子哈姆列，哈姆列的儿子扎克尔，扎克尔的儿子示每。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="民数记 26:14; 民数记 26:22; 民数记 2:13"> 示每有十六个儿子，六个女儿，但他兄弟们的儿女不多，他们整个家族也不如犹大的子孙那样众多。</span>
<span className="v" id="v28" data-v="28" data-xref="约书亚记 19:2–3; 约书亚记 15:28–29; 约书亚记 19:9"> 他们住在比尔-谢巴、莫拉达、哈萨书尔、</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 19:3–4"> 碧拉、埃曾、托拉德、</span>
<span className="v" id="v30" data-v="30" data-xref="尼希米记 11:28; 约书亚记 19:4–5; 撒母耳记上 30:1"> 彼土利、霍尔玛、洗革拉、</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 19:5–6"> 伯玛克波、哈萨苏撒、伯比利和沙拉音。直到大卫作王，这些都是他们的城，</span>
<span className="v" id="v32" data-v="32" data-xref="约书亚记 19:7"> 包括附属的村庄；还有以坦、阿音、临门、托肯和阿珊五座城，</span>
<span className="v" id="v33" data-v="33" data-xref="约书亚记 19:8"> 以及这些城周围所有的村庄，直到巴力<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="巴力——或译作“巴阿拉”；参《约书亚记》19:8。">c</a></sup>；这些是他们居住的地方。他们也为自己记录家谱：</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> 有米所巴、雅米勒、亚玛谢的儿子约沙、</span>
<span className="v" id="v35" data-v="35"> 约珥、耶户；耶户是约示比的儿子，约示比是西莱雅的儿子，西莱雅是阿希业的儿子。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36"> 还有以利约奈、雅格巴、约朔海、亚撒雅、亚迪业、耶西玛利、比纳雅、</span>
<span className="v" id="v37" data-v="37"> 细撒；细撒是示非的儿子，示非是亚龙的儿子，亚龙是耶达雅的儿子，耶达雅是示姆利的儿子，示姆利是示玛雅的儿子。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="历代志上 5:24; 创世记 6:4"> 这些按名字记下来的，都是他们各家族的领袖；他们的父家繁衍众多。</span>
<span className="v" id="v39" data-v="39" data-xref="历代志上 4:4; 历代志上 4:18; 约书亚记 15:58"> 他们往格多的路口去，直到山谷东边，为自己的羊群寻找草场。</span>
<span className="v" id="v40" data-v="40" data-xref="士师记 18:7–10; 诗篇 105:23; 诗篇 78:51"> 他们找到了肥沃美好的草场，那地也边界宽广，平静安稳，从前住在那里的是含族的人。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 14:28–32; 列王纪下 18:8–12; 历代志上 4:34–38"> 这些按名字记下来的人，在犹大王希西加年间前来，攻击含族人的帐篷和在那里遇见的米乌尼人，把他们灭绝净尽，直到今日；又取代他们住在那里，因为有草场可以牧放他们的羊群。</span>
<span className="v" id="v42" data-v="42" data-xref="创世记 36:8–9; 申命记 1:2"> 这些西缅子孙当中，有五百人往西珥山去，他们的首领是伊示的众子皮拉提、尼利雅、勒法雅和乌基业。</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳记上 30:17; 撒母耳记上 15:7–8; 撒母耳记下 8:12"> 他们击杀了亚玛力人中逃脱的余剩者，就住在那里，直到今日。</span>
</div>
</div>

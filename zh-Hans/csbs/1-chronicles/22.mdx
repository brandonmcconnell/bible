<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 3:1; 历代志上 21:18–28; 创世记 28:17"> 大卫说：“这里是神耶和华的殿，这里是以色列献燔祭的祭坛。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="历代志下 2:17; 列王纪上 9:20–21; 列王纪上 5:17–18"> 大卫吩咐把以色列地的寄居者招聚起来，又安排石匠开凿石头，要用凿好的料石建造神的殿。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 22:14; 历代志上 29:2; 列王纪上 7:47"> 大卫预备了大量的铁，用来制作所有门扇上的钉子和连接件；又预备了铜，多得无法称量；</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 5:6–10; 以斯拉记 3:7; 历代志下 2:3"> 还有无数的香柏木，因为西顿人和提尔人给大卫运来了大量的香柏木。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 3:7; 历代志上 29:1; 约翰福音 3:30"> 大卫想：“我儿子所罗门年少幼嫩，而要为耶和华建造的殿宇必须极其宏伟，名声和荣耀传遍全地。现在我就要为这殿宇<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这殿宇——或译作“他”。">a</a></sup>做准备。”这样大卫在死之前，做了许多的准备。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数记 27:23; 使徒行传 20:25–31; 使徒行传 1:2"> 大卫召来他儿子所罗门，吩咐他要为以色列的神耶和华建造殿宇。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 132:5; 列王纪上 8:16–20; 历代志下 6:7–9"> 大卫对所罗门说：“我儿啊，我一直有心为我神耶和华的名建造殿宇，</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 5:3; 历代志上 28:3; 历代志上 17:4–10"> 只是耶和华的话语临到我说：‘你流了很多人的血，打过许多仗，你不可为我的名建造殿宇，因为你在我面前，在大地上流了很多人的血。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 4:25; 列王纪上 5:4; 列王纪上 4:20"> 看哪，你将生一个儿子，他必成为安息之人，我要使他安定，脱离四围一切仇敌。他的名字要叫所罗门，他在位的日子，我要把和平、安宁赐给以色列。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 1:5; 撒母耳记下 7:13–14; 历代志上 17:12–14"> 他要为我的名建造殿宇，并且他要作我的儿子，我要作他的父亲。我必使他王位坚立，统治以色列直到永远。’</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="历代志上 22:16; 历代志上 28:20; 提摩太后书 4:22"> “我儿啊，现在愿耶和华与你同在，使你顺利建造你的神耶和华的殿，正如他论到你所说的话。</span>
<span className="v" id="v12" data-v="12" data-xref="雅各书 1:5; 箴言 14:8; 列王纪上 3:9–12"> 唯愿耶和华赐给你见识和悟性，这样他委任你统治以色列时，你就会遵守你的神耶和华的律法。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 1:6–9; 历代志上 28:20; 历代志上 28:7"> 那时，如果你谨守遵行耶和华指示摩西给以色列的律例和法规，就必亨通。你要坚强、勇敢！不要害怕，不要丧胆。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志上 22:3; 列王纪下 25:16; 历代志上 29:4–7"> “看哪，我辛苦为耶和华的殿预备了金子十万他连得<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="十万他连得——相当于3,420公吨。1他连得=34.2公斤。">b</a></sup>，银子一百万他连得<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一百万他连得——相当于34,200公吨。">c</a></sup>，铜和铁多得无法称量；我也预备了木材和料石，你还可以增添。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 28:6; 出埃及记 35:32; 列王纪上 7:14"> 此外在你这里有许多工人，石匠，雕刻木头石头的，以及一切能做各样工艺的巧匠，</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 22:11; 腓立比书 4:13; 以弗所书 5:14"> 又有无数的金、银、铜、铁。起来行动吧，愿耶和华与你同在！”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="历代志上 28:1–6; 约翰三书 1:8; 历代志上 29:6"> 大卫又吩咐以色列所有的首领帮助他儿子所罗门，说：</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 22:9; 历代志上 23:25; 撒母耳记下 7:1"> “你们的神耶和华不是与你们同在吗？他不是使你们四围都安定吗？因他已经把这地的居民交在我手中，这地在耶和华面前和他子民面前被征服了。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 28:9; 申命记 4:29; 历代志上 16:11"> 现在你们要立定心志寻求耶和华你们的神，起来建造神耶和华的圣所，好把耶和华的约柜和神的神圣器皿都搬进为耶和华的名所建造的殿宇。”</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="1CH" data-book-slug="1-chronicles" data-book-name="历代志上" data-chapter="15" data-verses="29">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 16:1; 历代志上 17:1–5; 诗篇 132:5"> 大卫在大卫城为自己建造宫殿，又为神的约柜预备地方，为它支搭了一座帐篷。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 10:8; 申命记 31:9; 民数记 18:1–8"> 那时大卫说：“除了利未人以外，没有人可以抬神的约柜，因为耶和华拣选了他们抬耶和华的约柜，并且永远事奉他。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="列王纪上 8:1; 历代志上 13:5; 历代志上 15:1"> 大卫招聚全体以色列人到耶路撒冷，要把耶和华的约柜抬上来放到大卫所预备的地方。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 6:16–22; 历代志上 12:26–28; 历代志上 6:16–30"> 大卫又招聚亚伦的子孙和利未人：</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="历代志上 6:22–24"> 哥辖的子孙中，有首领乌列和他的族兄弟一百二十人；</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 6:29–30"> 米拉利的子孙中，有首领亚撒雅和他的族兄弟两百二十人；</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 15:11; 历代志上 23:8"> 革顺的子孙中，有首领约珥和他的族兄弟一百三十人；</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 6:22"> 以利撒番的子孙中，有首领示玛雅和他的族兄弟两百人；</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 6:18; 历代志上 23:19; 历代志上 26:30–31"> 希伯伦的子孙中，有首领以利业和他的族兄弟八十人；</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 6:18; 历代志上 6:18; 历代志上 23:12"> 乌基业的子孙中，有首领亚米拿达和他的族兄弟一百一十二人。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="历代志上 12:28; 列王纪上 2:35; 撒母耳记上 22:20–23"> 大卫召来撒督和亚比亚特两位祭司，以及利未人乌列、亚撒雅、约珥、示玛雅、以利业和亚米拿达，</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 35:6; 出埃及记 19:14–15; 历代志上 15:14"> 对他们说：“你们是利未人各父系的首领，你们和你们的族兄弟要使自己分别为圣，好把以色列的神耶和华的约柜抬上来放到我所预备的地方。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 6:3; 哥林多前书 14:40; 约翰一书 1:8–10"> 因为上一次你们不在场，我们也没有按照规定求问神，所以耶和华我们的神就对我们发怒。”</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 29:15; 约珥书 2:16–17; 历代志下 29:34"> 于是祭司和利未人使自己分别为圣，为要把以色列的神耶和华的约柜抬上来。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 4:15; 民数记 7:9; 历代志下 5:9"> 利未子孙照着耶和华的话，按摩西所吩咐的，用杠子把神的约柜扛在肩上。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志上 13:8; 历代志下 5:13; 历代志上 16:42"> 大卫吩咐利未人的首领指派他们的族兄弟作歌手，用里拉琴、竖琴、铜钹等各种乐器伴奏，高唱喜乐的歌。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 6:39; 历代志上 6:44; 历代志上 6:33"> 利未人就指派了约珥的儿子希幔和他的族兄弟比利迦的儿子亚萨，以及他们的族兄弟米拉利子孙中古沙雅的儿子伊坦；</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 26:4; 历代志上 26:8; 历代志上 13:14"> 其次是与他们一起的族兄弟：撒迦利亚<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="撒迦利亚——依据七十士译本以及有些古抄本；马索拉文本作“儿子撒迦利亚”。">a</a></sup>、雅阿基业、示米拉莫、耶希业、乌尼、以利押、比纳雅、玛西雅、玛塔提雅、以利斐利户、弥克尼雅，以及门卫俄别·以东和耶伊列。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 25:6; 历代志上 16:5; 历代志上 13:8"> 歌手希幔、亚萨和伊坦要敲响铜钹；</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 46:1–11"> 撒迦利亚、雅基业、示米拉莫、耶希业、乌尼、以利押、玛西雅和比纳雅弹里拉琴，用“少女”曲调<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="用“少女”曲调——或译作“调用阿拉莫特”。">b</a></sup>；</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 10:5; 历代志上 25:6–7; 诗篇 81:1–2"> 玛塔提雅、以利斐利户、弥克尼雅、俄别·以东、耶伊列和阿撒细雅弹竖琴，用“第八”曲调<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="用“第八”曲调——或译作“调用谢米尼特”。">c</a></sup>领奏。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 15:27; 历代志上 15:16; 历代志上 25:7–8"> 克纳尼雅是利未人歌唱的领队，教导人歌唱，因为他精通于此。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 84:10; 列王纪下 22:4; 历代志上 9:21–23"> 比利迦和以利加拿是看守约柜的门卫。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 16:6; 民数记 10:8; 历代志上 15:28"> 祭司示巴尼、约沙法、拿旦业、亚玛赛、撒迦利亚、比纳雅和以利以谢，在神的约柜前吹号。俄别·以东和耶希亚也是看守约柜的门卫。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 6:12–23; 弥迦书 5:2; 腓立比书 3:3"> 于是大卫、以色列的长老们和千夫长们一起前去，欢欢喜喜地把耶和华的约柜从俄别·以东家里抬上来。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 23:29; 历代志上 29:14; 诗篇 66:13–15"> 神帮助那些抬耶和华约柜的利未人，他们就祭献了七头公牛和七只公绵羊。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 2:18; 撒母耳记下 6:14"> 大卫和所有抬约柜的利未人，并歌手和歌手的首领克纳尼雅，都穿着细麻布的外袍，大卫还穿着细麻布的以弗得。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志上 13:8; 历代志上 15:16; 历代志下 5:12–13"> 全体以色列人在欢呼和号角声中，奏响号筒、铜钹、里拉琴和竖琴，把耶和华的约柜抬上来。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 6:20–23; 撒母耳记下 6:16; 申命记 31:26"> 当耶和华的约柜进入大卫城时，扫罗的女儿米甲透过窗户俯看，看见大卫王跳跃欢庆，心里就藐视他。</span>
</div>
</div>

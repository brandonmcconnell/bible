<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 35:22; 创世记 29:32; 创世记 48:15–22"> 以下是以色列的长子鲁本的子孙。鲁本虽然是长子，但他玷污了父亲的床榻，他的长子名份就被转给以色列之子约瑟的两个儿子，所以在家谱记录中没有长子名份。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 2:6; 弥迦书 5:2; 希伯来书 7:14"> 犹大虽然在他兄弟们中强盛，领袖也是从他而出，但长子名份是属于约瑟的。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 46:9; 出埃及记 6:14; 民数记 26:5–9"> 以色列长子鲁本的儿子是<br />哈诺、法路、希斯伦和迦米。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 约珥的子孙是：他的儿子示玛雅，<br />示玛雅的儿子歌革，歌革的儿子示每，</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 示每的儿子米迦，米迦的儿子利阿亚，<br />利阿亚的儿子巴力，</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 5:26; 列王纪下 15:29; 历代志下 28:20"> 巴力的儿子备拉。<br />备拉被亚述王提革拉·毗列色掳走了，他是鲁本支派的领袖。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 5:17"> 备拉的族兄弟，按着自己的家族，照着他们的家系记录，有首领耶伊列、撒迦利亚、</span>
<span className="v" id="v8" data-v="8" data-xref="历代志上 5:4; 民数记 32:34; 民数记 32:38"> 比拉；比拉是亚撒的儿子，亚撒是示玛的儿子，示玛是约珥的儿子。约珥住在亚罗珥，直到尼波和巴力梅翁一带；</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 22:8–9"> 他又到东边居住，一直到幼发拉底河这边旷野的入口，因为他们在基列地的牲畜增多了。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 21:9; 历代志上 5:18–21; 诗篇 83:6"> 扫罗年间，他们与哈格利人作战，哈格利人败在他们手下，他们就住在基列东边全域哈格利人的帐篷中。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约书亚记 13:11; 约书亚记 13:24–28; 申命记 3:10–17"> 迦得的子孙在他们对面，住在巴珊地，直到撒迦。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 他们有首领约珥，副首领沙番，还有雅奈和住在巴珊的沙法。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 按着他们的父家，他们的族兄弟是米迦勒、米书兰、示巴、约赖、雅干、细亚和希伯，共七人。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 这些都是亚比亥的子孙；亚比亥是户利的儿子，<br />户利是耶罗亚的儿子，耶罗亚是基列的儿子，<br />基列是米迦勒的儿子，米迦勒是耶示筛的儿子，<br />耶示筛是耶哈多的儿子，耶哈多是布斯的儿子。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 古尼的孙子、押比叠的儿子亚希，是他们父家的首领。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 27:29; 雅歌 2:1; 以赛亚书 35:2"> 他们住在基列、巴珊和附属的村镇，以及整个沙仑牧野，直到它的尽头。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 14:16; 列王纪下 14:28; 列王纪下 15:32"> 他们全都在犹大王约坦年间和以色列王耶罗波安年间，被记录在家谱中。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民数记 1:3; 约书亚记 4:12–13"> 鲁本、迦得和玛拿西半支派的勇士，那些拿盾牌刀剑、拉弓射箭、受过作战训练的，有四万四千七百六十人，都能列队出战。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 25:15; 历代志上 1:31; 历代志上 5:10"> 他们与哈格利人、伊突人、拿非施人和挪达人作战。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 22:4–5; 诗篇 9:10; 历代志下 18:31"> 他们得到帮助，哈格利人和所有与哈格利人同盟的人都被交在他们手中，因为他们在战争中向神哀求，神就因为他们信靠他而应允了他们的祈求。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 18:13; 民数记 31:35"> 他们掳掠了夏甲人的牲畜，有骆驼五万头、羊二十五万只、驴子两千只；还掳掠了人口十万。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 32:8; 罗马书 8:31; 约书亚记 23:10"> 有许多夏甲人被杀倒下，因为这场战争是出于神。他们就取代夏甲人住下，直到被掳时期。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="申命记 3:8–9; 雅歌 4:8; 诗篇 133:3"> 玛拿西半支派的子孙住在那地，从巴珊直到巴力黑门、示尼珥和黑门山；他们人数众多。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 4:38"> 以下是他们父家的首领：以弗、伊示、以利业、亚斯列、耶利米、赫达维亚、耶赫迪业，都是英勇的战士、有名望的人，是他们父家的首领。</span>
<span className="v" id="v25" data-v="25" data-xref="启示录 17:5; 诗篇 106:34–39; 出埃及记 34:15"> 但他们对祖先的神不忠，行淫追随当地之民的神明，这民是神从他们面前所除灭的。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 15:19; 列王纪下 17:6; 列王纪下 15:29"> 所以，以色列的神触动了亚述王普勒——亚述王提革拉·毗列色的心，他就把鲁本支派、迦得支派和玛拿西半支派的人掳走，带到了哈腊、哈博、哈拉，以及歌散河边，直到今日。</span>
</div>

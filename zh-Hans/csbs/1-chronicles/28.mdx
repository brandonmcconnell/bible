<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 23:2; 历代志上 11:10–47; 历代志上 27:1–34"> 大卫把以色列所有的首领招聚到耶路撒冷，他们是各支派的首领、事奉王的各班组首领、千夫长、百夫长、为王和王子管理一切财物牲畜的官员，还有内臣和勇士们，以及所有英勇的战士。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 99:5; 以赛亚书 66:1; 历代志上 17:1–2"> 大卫王站起来，说：“我的兄弟，我的子民哪，请听我说！我心中有意要为耶和华的约柜、为我们神的脚凳建造一个安息之所，并且我已经预备好要建造，</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 22:8; 历代志上 17:4; 历代志下 6:8–9"> 然而神对我说：‘你不可为我的名建造殿宇，因为你是个战士，曾经流过人的血。’</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 16:1; 历代志上 5:2; 撒母耳记上 16:6–13"> “以色列的神耶和华从我父的全家拣选我，永远作以色列的王。他拣选了犹大作首领，在犹大家拣选我父家，又在我父的儿子中喜悦我，立我作全以色列的王。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 3:1–9; 历代志上 23:1; 历代志上 22:9–10"> 从我所有的儿子中——耶和华实在赐给了我许多儿子——他又拣选我儿子所罗门坐耶和华国度的王位，统治以色列。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 7:13–14; 历代志上 22:9–10; 希伯来书 3:6"> 耶和华对我说：‘是你的儿子所罗门，他将要建造我的殿宇和庭院，因为我已拣选他作我的儿子，我要作他的父亲。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 22:13; 列王纪上 8:61; 列王纪上 6:12–13"> 如果他坚持遵行我的诫命和法规，像今日这样，我就坚立他的王权，直到永远。’</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="申命记 4:1; 申命记 5:32–3; 箴言 2:1–5"> “现在，耶和华的会众全体以色列人都在看，我们的神也在听：你们要谨守并寻求你们神耶和华的一切诫命，好使你们可以继承这美地，并且给你们的后代子孙为继业，直到永远。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="耶利米书 29:13; 雅各书 4:8–11; 马太福音 7:7–8"> “至于你，我儿所罗门哪，当认识你父亲的神，要以完全的心、乐意的灵服事他，因为耶和华鉴察所有人的心，洞察人的每个意念动机。如果你寻求他，他必让你寻见；如果你离弃他，他必永远抛弃你。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 28:6; 提摩太前书 4:16; 历代志上 22:16–19"> 现在你看，耶和华已经拣选你来建造殿宇为圣所，你要坚强行事！”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="历代志上 28:19; 列王纪上 6:3; 出埃及记 25:40"> 大卫把圣殿的设计都交给他儿子所罗门，有门廊、房屋、府库、楼阁、内殿和施恩座圣所。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 26:20; 列王纪上 14:26; 出埃及记 25:40"> 这设计包含他灵里所领受的一切，有耶和华殿的庭院、四围所有的房间、神殿中的库房和存放圣物的库房；</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 9:29; 历代志上 25:1–31; 列王纪上 7:1–51"> 还有祭司和利未人的班组，耶和华殿中的各样服事工作，以及耶和华殿中各样服事器具的规格：</span>
<span className="v" id="v14" data-v="14"> 用于服事的各样金器所需的金子重量；用于服事的各样银器、各样器皿所需的银子重量；</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 25:31–39; 撒迦利亚书 4:11–14; 启示录 1:12–13"> 照着每个灯台的服事用途，每个灯台和它灯盏的重量，金灯台和灯盏所需的金子重量，银灯台和灯盏所需的银子重量；</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 7:48; 历代志下 4:8; 出埃及记 25:23–30"> 按每张桌子计算，陈设饼的桌子所需的金子重量，银桌子所需的银子重量；</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 10:21; 历代志下 4:20–22; 民数记 7:13–14"> 叉子、碗和壶所需的纯金重量；各金碟所需的金子重量；各银碟所需的银子重量；</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 25:18–22; 出埃及记 30:1–10; 诗篇 80:1"> 纯金香坛所需的金子重量；还包括耶和华乘驾的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="耶和华乘驾的——原文直译“战车”；参《撒母耳记下》22:11。">a</a></sup>金基路伯的设计，它展翅遮掩着耶和华的约柜。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="历代志上 28:11–12; 出埃及记 25:40; 以西结书 3:14"> 大卫说：“因耶和华的手在我身上，我明悟了所记录下来的这一切——这设计的所有细节。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="历代志上 22:13; 约书亚记 1:5–9; 以赛亚书 41:10"> 大卫又对他的儿子所罗门说：“你要坚强、勇敢行事！不要害怕，不要丧胆，因为耶和华神——我的神与你同在。他必不撇下你，也不离弃你，直到耶和华殿中服事所需的一切工作全都完成。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 24:1–26; 历代志上 22:17–18; 出埃及记 31:3"> 你看，有各班组的祭司和利未人准备做神殿各样的服事；那些在各样工作上有才能并且甘心乐意的人都在你身边，准备做各样的服事；首领们和所有百姓都听从你的一切指挥。”</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 29:28; 历代志上 28:5; 列王纪上 1:33–39"> 大卫年迈，寿数满足时，立他儿子所罗门为以色列的王。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 24:1; 历代志下 34:29–30; 历代志上 13:1"> 大卫招聚以色列的所有首领，以及祭司和利未人。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 23:24; 民数记 4:2–49"> 三十岁以上的利未人都被数点，按着他们的人头，数目是男丁三万八千。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 19:8; 申命记 16:18; 历代志上 26:29–31"> 其中监管耶和华殿工作的有两万四千人，作官长和审判官的有六千人，</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 29:25–26; 历代志下 8:14; 诗篇 87:7"> 门卫有四千人，那些用大卫所预备的颂赞乐器来赞美耶和华的，有四千人。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="历代志下 8:14; 历代志上 6:1; 历代志上 6:16"> 大卫又按着利未的儿子革顺、哥辖和米拉利的宗族，给他们分配班组。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志上 26:21; 出埃及记 6:17; 历代志上 6:17–20"> 革顺人有拉丹和示每。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="历代志上 6:33–34; 历代志上 15:20–21; 历代志上 15:7"> 拉丹的儿子，长子是耶希业，其次是泽坦和约珥，共三人。</span>
<span className="v" id="v9" data-v="9"> 这些人是拉丹各父系的首领。<br />示每的儿子是示罗米、哈薛和哈兰，共三人。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 示每的子孙是雅哈、细撒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="细撒——依据七十士译本；马索拉文本作“细拿”；参照下一节。">a</a></sup>、耶乌施和比利亚，这四人都是示每的子孙。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 雅哈是长子，细撒是次子；耶乌施和比利亚子孙不多，归为一个父家，同属一个职份。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及记 6:18; 民数记 3:27; 民数记 26:58"> 哥辖的儿子是阿姆兰、以斯哈、希伯伦和乌基业，共四人。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命记 21:5; 出埃及记 6:20; 撒母耳记上 2:28"> 阿姆兰的儿子是亚伦和摩西。<br />亚伦和他的子孙永远被分别出来，为要被分别为至圣的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="为要被分别为至圣的——或译作“为要把至圣之物分别为圣”。">b</a></sup>，在耶和华面前烧香、事奉，奉耶和华的名祝福，直到永远。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 33:1; 诗篇 90:1; 历代志上 26:23–25"> 至于神人摩西，他的子孙被算在利未支派中。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及记 18:3–4; 出埃及记 2:22; 出埃及记 4:20"> 摩西的儿子是革顺和以利以谢。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志上 26:24; 历代志上 25:20; 历代志上 24:20"> 革顺的儿子，有长子谢布业。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="历代志上 26:25"> 以利以谢的儿子，有头生的利哈比雅；以利以谢没有别的儿子，但利哈比雅的儿子却很多。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="历代志上 26:26; 历代志上 24:22"> 以斯哈的儿子，有长子示罗米。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 24:23; 历代志上 15:9; 历代志上 23:12"> 希伯伦的儿子，有长子耶利雅，<br />次子亚玛利雅，三子雅哈希，<br />四子耶咖缅。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 乌基业的儿子，有长子米迦，<br />次子伊示亚。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及记 6:19; 历代志上 6:20; 历代志上 24:26–30"> 米拉利的儿子有玛赫利和穆希，<br />玛赫利的儿子有以利亚撒和基士。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="历代志上 24:28; 民数记 36:6–8"> 以利亚撒死了，他没有儿子，只有女儿，<br />她们的族兄弟——就是基士的众子——娶了她们。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="历代志上 24:30"> 穆希的儿子有玛赫利、伊德和耶利莫，共三人。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数记 10:17; 民数记 10:21; 历代志上 23:3"> 以上按着他们的父家，都是利未的子孙，是各父系的首领，按名单，按着他们的人头数点，都在二十岁以上，为耶和华的殿服事做工。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 132:13–14; 历代志上 22:18; 撒母耳记下 7:11"> 因为大卫说：“以色列的神耶和华已经使他的子民得享安息，他将永远居住在耶路撒冷，</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 4:5; 民数记 7:9; 民数记 4:15"> 利未人也不必再抬帐幕和其中一切用于服事的器具了。”</span>
<span className="v" id="v27" data-v="27" data-xref="历代志上 23:24; 诗篇 72:20; 撒母耳记下 23:1"> 根据大卫临终的吩咐，他们都是二十岁以上被数点的利未子孙。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 35:3–6; 历代志下 31:11; 历代志下 35:11–14"> 他们的职任是协助亚伦子孙做耶和华殿的服事工作，管理庭院和公房，负责洁净一切圣物，从事神殿的各样服事工作；</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 19:35–36; 出埃及记 25:30; 利未记 6:20–23"> 负责陈设饼、素祭的细面粉、无酵薄饼，烤制、揉拌，也负责所有的容量和尺寸；</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 92:1–3; 以斯拉记 3:10–11; 历代志上 9:33"> 每天早晨侍立，称谢赞美耶和华，傍晚也是如此；</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 1:13–14; 民数记 28:1–29; 民数记 10:10"> 也负责向耶和华献上一切燔祭，在安息日、新月节和各节期，按照数目，照着规定，把燔祭常献在耶和华面前。</span>
<span className="v" id="v32" data-v="32" data-xref="民数记 1:53; 民数记 3:38; 民数记 3:6–9"> 他们要谨守会幕的职责、圣所的职责，以及协助他们的族兄弟亚伦子孙的职责，在耶和华的殿服事。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 5:1–16; 历代志上 12:23–40; 士师记 9:2"> 全体以色列人聚集到希伯仑来见大卫，说：“看哪，我们是你的骨肉之亲。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 5:2; 约翰福音 10:4; 诗篇 78:71"> 从前扫罗作王的时候，带领以色列出入的就是你，你的神耶和华也曾对你说：‘你要牧养我的子民以色列，你要作我的子民以色列的领袖。’”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 16:12–13; 撒母耳记上 16:1; 撒母耳记下 5:3"> 以色列的长老们都来到希伯仑见王，大卫在希伯仑，在耶和华面前与他们立约，他们就膏立大卫作以色列的王，正如耶和华藉着撒母耳所传的话。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士师记 1:21; 创世记 15:21; 约书亚记 15:8"> 大卫和以色列全军来到耶路撒冷——就是耶布斯，那地的居民都是耶布斯人。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 5:2; 列王纪上 8:1; 诗篇 87:2"> 耶布斯的居民对大卫说：“你进不到这里来！”然而大卫攻取了锡安的堡垒，就是后来的大卫城。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 8:16; 撒母耳记下 20:23; 撒母耳记下 3:27"> 大卫说：“谁先击杀耶布斯人，他就作元帅，作首领。”洗鲁雅的儿子约押先攻上去，就作了元帅。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志上 11:5; 撒母耳记下 5:7; 诗篇 2:6"> 大卫住在这堡垒里，因此人们称它为“大卫城”。</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 9:6; 列王纪上 11:27; 列王纪下 12:20"> 大卫把城的周围建造起来，从梯垒直到四围城墙；约押修复城其余的部分。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 3:1; 以赛亚书 41:10; 历代志上 9:20"> 大卫越来越强大，因为万军之耶和华与他同在。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志上 11:3; 撒母耳记上 16:1; 历代志上 12:38"> 这些是大卫勇士们的首领，就是与全以色列一同极力拥护他王权的人，他们照着耶和华所应许以色列的，立他为王。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 23:8; 历代志上 27:2; 历代志上 12:18"> 以下是大卫的勇士们的名单：<br />哈克莫尼人雅朔班，是众军官<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="众军官——或译作“三十勇士”。">a</a></sup>之首，他曾挥动长矛，一次击杀了三百人。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="历代志上 27:4; 撒母耳记下 23:17–19; 撒母耳记下 23:23"> 其次是阿赫阿人朵多的儿子以利亚撒，他是三勇士之一。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 23:11–12; 撒母耳记上 17:1"> 从前他与大卫在巴斯达悯，非利士人聚集在那里要打仗，那里有一块长满了大麦的田地。以色列军兵从非利士人面前逃跑，</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 144:10; 列王纪下 5:1; 撒母耳记上 14:23"> 他们却在那块田中站立，守护那块田，击杀非利士人。这样耶和华施行了大拯救。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="历代志上 14:9; 撒母耳记下 5:18; 以赛亚书 17:5"> 有一次，三十个首领中的那三个人下去，到亚杜兰山洞的磐石那里去见大卫。非利士人的军队在利乏音谷扎营。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 10:5; 撒母耳记上 13:4; 撒母耳记上 13:23"> 那时大卫在要塞中，而非利士人的驻军在伯利恒。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 4:14; 以赛亚书 12:3; 撒母耳记下 23:15–16"> 大卫心中渴望，说：“谁能把伯利恒城门旁水窖里的水带来给我喝啊！”</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 21:13; 撒母耳记上 19:5; 使徒行传 20:24"> 那三个人就突破非利士人的防营，从伯利恒城门旁的水窖里打水，提上来，带回大卫那里。但大卫不肯喝，而是把水浇奠在耶和华面前，</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 23:17; 诗篇 72:14; 士师记 9:17"> 说：“我绝不可在我的神面前做这事！我怎么能喝那些冒生命危险之人的血呢？这水是他们冒着生命危险取回来的。”所以大卫不肯喝。这些是三勇士的事迹。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 26:6; 历代志上 2:16; 撒母耳记下 20:6"> 约押的弟弟亚比筛，是三十<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="三十—— 依据古叙利亚文译本；马索拉文本作“三”。">b</a></sup>勇士之首；他曾挥动长矛杀了三百人，所以和那三勇士一样有名。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 15:41; 马太福音 13:8"> 他在三十<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="三十—— 依据古叙利亚文译本；马索拉文本作“三”。">c</a></sup>勇士中倍受尊崇，所以成为他们的首领，只是不及那三勇士。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 23:20–23; 撒母耳记下 8:18; 约书亚记 15:21"> 耶赫亚达的儿子比纳雅，是来自卡布策勒的勇士，有许多事迹。他曾击杀了摩押的两个英雄，也曾在下雪的日子，下到坑里杀了一只狮子。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 17:7; 撒母耳记上 17:4; 申命记 3:11"> 他还击杀了一个身高五肘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="五肘——相当于2.3公尺。1肘=45.7公分。">d</a></sup>的埃及人；这埃及人手中有长矛，比纳雅却拿着棍子下去攻击他，从他手中抢夺了长矛，用那长矛把他杀了。</span>
<span className="v" id="v24" data-v="24"> 这些是耶赫亚达的儿子比纳雅的事迹，他和三勇士一样有名。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 20:23"> 看哪，他在三十勇士中受尊崇，但是不及那三勇士。大卫立他作侍卫长。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="历代志上 27:7; 撒母耳记下 21:19; 撒母耳记下 2:18–23"> 军队中的勇士有：<br />约押的弟弟亚撒晖，<br />伯利恒人朵多的儿子伊勒哈南，</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="撒母耳记下 23:25–26"> 哈律人沙玛，<br />佩罗尼人希利斯，</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="历代志上 27:12; 历代志上 27:9; 撒母耳记下 23:27"> 提克亚人益吉的儿子伊拉，<br />亚拿突人亚比以谢，</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 23:27–28; 历代志上 27:11"> 户沙人西比凯，<br />阿赫阿人伊莱，</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="历代志上 27:13; 历代志上 27:15; 撒母耳记下 23:29"> 尼托法人玛哈莱，<br />尼托法人巴纳的儿子希勒，</span>

<div className="bp">

<div className="bp">

<span className="v" id="v38" data-v="38" data-xref="撒母耳记下 23:36"> 拿单的兄弟约珥，<br />哈格利的儿子弥伯哈，</span>

<span className="v" id="v1" data-v="1" data-xref="历代志下 6:7–9; 历代志上 15:1; 历代志上 17:5"> 大卫住进自己的宫殿以后，对先知拿单说：“你看，我住在香柏木的宫殿里，耶和华的约柜却在帐幕里。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="历代志上 28:2; 哥林多前书 13:9; 撒迦利亚书 8:23"> 拿单对大卫说：“你心里所想的一切，只管去做，因为神与你同在。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="阿摩司书 3:7; 民数记 12:6; 以赛亚书 30:21"> 当天夜里，神的话语临到拿单，说：</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 28:2–3; 以赛亚书 55:8–9; 历代志下 6:8–9"> “你去告诉我的仆人大卫：‘耶和华如此说：不是你要为我建造殿宇居住。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 7:6; 出埃及记 40:2–3; 列王纪上 8:16"> 要知道，从我把以色列人带上来的那天到今天，我从来没有住过殿宇，我一直从这帐幕到那帐幕，从一个住所到另一个住所。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 7:7; 民数记 10:33–36; 哥林多后书 6:16"> 在我与全体以色列人走过的哪一个地方，我何曾对哪一个以色列士师，就是我吩咐要牧养我子民的士师，说过这话：你们怎么不为我建造一座香柏木的殿宇呢？’</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 6:21; 出埃及记 3:1–10; 撒母耳记上 17:15"> “现在，你要对我的仆人大卫这样说：‘万军之耶和华如此说：是我把你从牧场上、从羊群后带出来，作我子民以色列的领袖。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 18:14; 历代志上 17:2; 诗篇 113:7–8"> 在你所去的任何地方，我都与你同在，并且从你面前剪除了你的一切仇敌。我将为你成就大名，如同世上那些伟人的名。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 2:23; 以西结书 28:4; 以弗所书 5:6"> 我必为我的子民以色列选定一个地方，栽植他们，使他们安居在那里，不再受搅扰，也不再像先前那样被不义之人迫害——</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 7:11; 士师记 2:14–18; 出埃及记 1:21"> 从我吩咐士师治理我子民以色列的日子以来，他们一直被迫害。我要制伏你的一切仇敌。<br />“‘我向你宣告：耶和华将为你建立家室。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 132:11; 列王纪上 1:21; 历代志上 28:5"> 当你寿数满足，归到你列祖那里时，我必兴起你的后裔——你亲生的儿子接续你，我也必坚立他的王权。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 5:5; 但以理书 2:44; 以赛亚书 9:7"> 他将为我建造殿宇，我必坚立他的王位，直到永远。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 1:5; 以赛亚书 55:3; 历代志上 17:12"> 我要作他的父亲，他要作我的儿子；我不会使我的慈爱离开他，像离开在你之前的人那样；</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 89:36; 路加福音 1:32–33; 诗篇 72:17"> 我要在我的家和我的国度里永远确立他，他的王位必永远坚立。’”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米书 23:28; 使徒行传 20:27; 撒母耳记下 7:17"> 拿单就把这一切话语，把这整个异象<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="异象——或译作“启示”。">a</a></sup>，如实地告诉了大卫。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 7:18; 创世记 32:10; 以弗所书 3:8"> 于是大卫王进去，坐在耶和华面前，说：“耶和华神哪，我是谁，我的家算什么，你竟带领我到这地步！</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 17:11–15; 腓立比书 2:8–11; 以赛亚书 49:6"> 神哪，这在你眼中还看为小事，你竟又提说仆人家的未来！耶和华神哪，你看待我像一个高贵的人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="你看待我像一个高贵的人——或译作“你向我显明了人都渴望知道的事”。">b</a></sup>。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 21:17; 撒母耳记上 2:30; 撒母耳记下 7:20–24"> 你赐给你仆人荣耀，大卫还能对你说什么呢？你知道你的仆人。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 37:35; 撒母耳记下 7:21; 但以理书 9:17"> 耶和华啊，你为你仆人的缘故，照着自己的心意行了这一切大事，为要显明这一切伟大的事。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 44:6; 耶利米书 10:6–7; 以弗所书 3:20"> “耶和华啊，照着我们耳中所听见的一切，没有像你的，除你以外没有别的神。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 20:9–10; 以赛亚书 63:9; 以赛亚书 48:9"> 世上有哪一国像你的子民以色列呢？神为自己赎回一个民族，为自己立名，行大而可畏的事，在你从埃及救赎的子民面前驱逐了列国。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 19:5–6; 彼得前书 2:9; 罗马书 11:1–12"> 你使你的子民以色列永远作你的子民；耶和华啊，你也作了他们的神。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="诗篇 119:49; 耶利米书 11:5; 路加福音 1:38"> “现在，耶和华啊，你所应许的有关你仆人和他家的话，求你永远确立。求你照着你所应许的行事，</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 6:13; 耶利米书 31:1; 启示录 21:3"> 这样，你的名就永远确立、被尊为大，人必说：‘以色列的神——万军之耶和华，就是以色列的神。’你仆人大卫的家也将在你面前被坚立，</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 9:15; 以西结书 36:37; 诗篇 10:17"> 因为你——我的神哪，是你亲自启示你的仆人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="启示你的仆人——原文直译“开启你仆人的耳朵”。">c</a></sup>，要为他建立家室；所以你的仆人有了勇气在你面前祷告。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 34:6–7; 希伯来书 6:18; 提多书 1:2"> 是的，耶和华啊，你是神，是你向你的仆人应许了这福份。</span>
<span className="v" id="v27" data-v="27" data-xref="以弗所书 1:3; 罗马书 11:29; 诗篇 72:17"> 现在，愿你祝福你仆人的家，使它在你面前永远长存，因为耶和华啊，你所祝福的，必永远蒙福。”</span>
</div>
</div>

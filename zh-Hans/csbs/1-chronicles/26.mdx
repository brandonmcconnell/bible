</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="历代志上 9:21"> 米施利米雅的儿子，<br />有长子撒迦利亚，次子耶迪阿业，<br />三子希巴迪亚，四子亚特尼尔，</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3"> 五子以拦，六子约哈南，<br />七子以利约奈。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="历代志上 16:38; 历代志上 15:24; 历代志上 15:18"> 俄别·以东的儿子，<br />有长子示玛雅，次子约撒巴，<br />三子约亚，四子沙卡尔，<br />五子拿旦业，</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 128:1"> 六子亚米利，<br />七子以萨迦，八子佩乌利太；<br />神实在祝福了俄别·以东。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="历代志上 12:28; 提摩太前书 6:12; 士师记 6:12"> 他儿子示玛雅所生的儿子，都是他们父家的领袖，因为他们是英勇的战士。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 示玛雅的儿子有俄得尼、利法益、俄备得和以利萨巴，以利萨巴的兄弟以利户和西玛迦都是勇士。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 3:6; 彼得前书 4:11; 哥林多前书 12:4–11"> 这些都是俄别·以东的子孙，他们和他们的儿子、族兄弟都是在服事上有能力有才干的人。俄别·以东的子孙共有六十二人。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="历代志上 26:14; 历代志上 26:1"> 米施利米雅的儿子和族兄弟，都是勇士，共十八人。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志上 16:38; 历代志上 5:1–2"> 米拉利子孙何萨的儿子，有长子示姆利——他并不是头生的，但他父亲立他为长子——</span>
<span className="v" id="v11" data-v="11"> 次子希勒加，三子底巴利雅，四子撒迦利亚。何萨的儿子和族兄弟，共有十三个人。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="历代志上 25:8"> 对于这些门卫的班组，作首领的人与他们的族兄弟一样有职责，都在耶和华的殿中事奉。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 25:8; 历代志上 24:31; 历代志上 24:5"> 他们无论尊卑，都按着父家，为各门抽签。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 抽到东门的签是示勒米雅。他儿子撒迦利亚是个有见识的谋士，他们抽签，他的签抽出来是北门。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 25:24; 历代志上 26:17"> 俄别·以东抽到南门，他的儿子们抽到了库房。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米记 12:24; 历代志上 26:10–12; 列王纪上 10:5"> 书皮姆与何萨抽到西门，连同斜坡大道上的沙利基门。<br />守卫与守卫相对而立，</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 8:14; 历代志上 9:24"> 每天看守东门的有六个利未人，看守北门的有四个，看守南门的有四个，看守仓库的是两个、两个轮流。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 23:11"> 看守西边前院的，有四个人在大道上，两个人在前院里。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="民数记 16:11"> 以上都是可拉子孙和米拉利子孙中的门卫班组。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="历代志上 26:22; 历代志上 28:12–19; 历代志上 22:14–16"> 利未人亚希雅管理神殿的库房，以及存放圣物的库房。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 23:7; 历代志上 6:17; 历代志上 29:8"> 拉丹的子孙，就是属于拉丹的革顺人，作拉丹父系首领的是革顺人耶希伊利；</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 23:8; 尼希米记 10:38; 历代志上 26:20"> 耶希伊利的儿子，就是泽坦和他的兄弟约珥，管理耶和华殿中的库房。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="民数记 3:27; 历代志上 23:12; 民数记 3:19"> 阿姆兰家族、以斯哈家族、希伯伦家族和乌基业家族中：</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 24:20; 历代志上 23:15–16"> 摩西的孙子、革顺的儿子谢布业担任库房的总管。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志上 23:17–18; 历代志上 23:15; 出埃及记 18:4"> 谢布业的族兄弟是以利以谢，以利以谢的儿子是利哈比雅，利哈比雅的儿子是耶赛亚，耶赛亚的儿子是约兰，约兰的儿子是泽克利，泽克利的儿子是示罗米；</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 8:11; 历代志上 29:2–9; 历代志上 22:14"> 这示罗米和他的族兄弟们管理所有库房的圣物，就是大卫王、各父系首领、千夫长、百夫长和将领们所分别为圣之物。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 12:14; 约书亚记 6:19; 尼希米记 10:32–34"> 他们把战争中的战利品分别为圣，以备修缮耶和华的殿。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 9:9; 撒母耳记上 17:55; 撒母耳记下 10:9–14"> 先见撒母耳、基士的儿子扫罗、尼珥的儿子押尼珥和洗鲁雅的儿子约押所分别为圣的一切，凡是分别为圣的，都由示罗米和他的族兄弟经手管理。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="历代志上 23:4; 尼希米记 11:16; 历代志下 34:13"> 以斯哈家族有克纳尼雅和他的儿子们担当圣殿以外的工作，作以色列的官长和审判官。</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 27:17; 历代志上 23:19; 历代志上 23:12"> 希伯伦家族有哈沙比雅和他的族兄弟，共一千七百个勇士，在约旦河西岸担当以色列的监管职份，负责耶和华的一切工作和王的服事工作。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 23:19; 约书亚记 21:39; 历代志上 29:27"> 希伯伦家族的耶利雅，按着父家谱系是希伯伦家族的首领；大卫在位第四十年做普查，在基列的雅谢从他们家族中找到一些英勇的战士。</span>
<span className="v" id="v32" data-v="32" data-xref="历代志下 19:11; 历代志上 12:37; 历代志上 23:24"> 耶利雅的族兄弟有两千七百人，都是勇士，是各父系的首领。大卫王指派他们管理鲁本支派、迦得支派和玛拿西半支派中一切有关神的事务和王的事务。</span>
</div>

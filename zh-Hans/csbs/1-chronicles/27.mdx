<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 4:27; 历代志下 26:11–13; 申命记 1:15"> 以下是以色列子孙各父系的首领、千夫长、百夫长，以及在一切事务上事奉王的官长们的数目。各班组在一年中所有的月份按月轮流出入，每个班组有两万四千人。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="历代志上 11:11; 撒母耳记下 23:8"> 一月第一班组是撒巴迪业的儿子雅朔班负责，他的班组有两万四千人。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 26:20; 民数记 10:14; 创世记 49:8–10"> 他是法勒斯的子孙，是一月班组所有将领的首领。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 23:9; 历代志上 11:12"> 二月第二班组是阿赫阿人朵代负责，领袖米克罗也在他班组；他的班组有两万四千人。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="历代志上 18:17; 列王纪上 4:4–5"> 三月第三班组是祭司长耶赫亚达的儿子将领比纳雅负责，他的班组有两万四千人。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 23:20–23; 历代志上 11:22–25; 撒母耳记下 22:20–23"> 这比纳雅是三十勇士之一，管理那三十人，他的儿子暗米萨拔也在他班组。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志上 11:26; 撒母耳记下 23:24; 撒母耳记下 2:18–23"> 四月第四班组是约押的弟弟亚撒晖负责，接续他的是他儿子希巴迪亚；他的班组有两万四千人。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="历代志上 11:27; 撒母耳记下 23:25; 历代志上 26:29"> 五月第五班组是首领伊斯拉人珊合负责，他的班组有两万四千人。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="历代志上 11:28; 撒母耳记下 23:26"> 六月第六班组是提克亚人益吉的儿子伊拉负责，他的班组有两万四千人。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志上 11:27; 撒母耳记下 23:26"> 七月第七班组是以法莲子孙佩罗尼人希利斯负责，他的班组有两万四千人。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 21:18; 历代志上 11:29; 民数记 26:20"> 八月第八班组是谢拉家族的户沙人西比凯负责，他的班组有两万四千人。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="历代志上 11:28; 撒母耳记下 23:27"> 九月第九班组是便雅悯子孙亚拿突人亚比以谢负责，他的班组有两万四千人。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志上 11:30; 撒母耳记下 23:28"> 十月第十班组是谢拉家族的尼托法人玛哈莱负责，他的班组有两万四千人。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志上 11:31; 撒母耳记下 23:30"> 十一月第十一班组是以法莲子孙比拉顿人比纳雅负责，他的班组有两万四千人。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 23:29; 历代志上 4:13; 士师记 3:9"> 十二月第十二班组是俄陀聂家系尼托法人赫尔达伊负责，他的班组有两万四千人。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 以下是以色列各支派的负责人：<br />鲁本支派的领袖，是泽克利的儿子以利以谢；<br />西缅支派，是玛迦的儿子示法提雅；</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="历代志上 26:30; 历代志上 24:31; 历代志上 12:27–28"> 利未支派，是基姆利的儿子哈沙比雅；<br />亚伦子孙，是撒督；</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 16:6; 撒母耳记上 17:29; 撒母耳记上 17:13"> 犹大支派，是大卫的哥哥以利户；<br />以萨迦支派，是米迦勒的儿子欧姆利；</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 西布伦支派，是俄巴底亚的儿子伊施玛雅；<br />拿弗他利支派，是亚斯列的儿子耶利莫；</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 以法莲子孙，是阿撒细雅的儿子何西阿；<br />玛拿西半支派，是皮达雅的儿子约珥；</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳记下 3:27; 撒母耳记上 14:50–51; 撒母耳记下 3:37"> 玛拿西在基列地的那半支派，是撒迦利亚的儿子伊度；<br />便雅悯支派，是押尼珥的儿子雅西业；</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="历代志上 28:1"> 但支派，是耶罗罕的儿子阿扎列。<br />以上是以色列各支派的首领。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="创世记 15:5; 历代志上 21:2–5; 希伯来书 11:12"> 大卫没有统计二十岁以下之人的数目，因为耶和华已经应许，他要使以色列增多，如同天上的星辰。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 21:1–17; 撒母耳记下 24:1–15"> 洗鲁雅的儿子约押曾经开始数点，但因着这事，耶和华的震怒临到了以色列，所以他没有完成，数目也没有记在《大卫王年代志》上。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="历代志下 16:2; 出埃及记 1:11; 历代志下 26:10"> 负责王室库房的是亚迪业的儿子阿兹玛维，<br />负责郊外、城镇、乡村和守望楼那些库房的是乌西雅的儿子约拿单，</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 负责那些在田野做工、耕种土地之人的，是基律的儿子以斯利；</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 负责葡萄园的是拉玛人示每，<br />负责葡萄园中酒库的是实弗米人扎布迪，</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王纪上 10:27; 历代志下 1:15; 列王纪上 4:7"> 负责丘陵上的橄榄园和西克莫无花果树的是基第利人巴勒·哈南，<br />负责油库的是约阿施，</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="历代志上 5:16; 以赛亚书 65:10"> 负责那些牧放在沙仑的牛群的是沙仑人希特赖，<br />负责那些牧放在平原的牛群的是亚第赉的儿子沙法，</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="创世记 47:6; 约伯记 1:3"> 负责骆驼的是以实玛利人阿比勒，<br />负责驴子的是米伦人耶希迪亚，</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="历代志上 5:10"> 负责羊群的是哈格利人雅悉。<br />以上是为大卫王管理财物的官员。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="撒母耳记下 21:21; 撒母耳记下 13:3; 历代志上 11:11"> 大卫的叔叔约拿单作谋士，他是有悟性的人，也是文士。哈克莫尼的儿子耶希业辅导王子们。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 15:12; 撒母耳记下 15:37; 撒母耳记下 15:32"> 亚希多弗也是王的谋士。亚基人户筛是王的朋友。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志上 11:6; 列王纪上 1:7; 历代志上 27:5"> 亚希多弗之后，比纳雅的儿子耶赫亚达和亚比亚特作谋士。约押作王的元帅。</span>
</div>

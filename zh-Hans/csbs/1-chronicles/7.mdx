<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 46:13; 民数记 26:23–24"> 以萨迦的儿子是陀拉、普瓦、雅实布和希姆仑，共四人。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 24:1–9; 历代志上 27:23–24; 历代志上 27:1"> 陀拉的儿子是乌基、勒法雅、耶勒、雅买、易伯散和撒母耳，都是他们父家的首领，是陀拉族谱系中英勇的战士，大卫年间他们的数目有两万两千六百人。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3"> 乌基的儿子是伊斯拉希雅，伊斯拉希雅的儿子是米迦勒、俄巴底亚、约珥和伊示亚，共五人，都是首领。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 12:32"> 按着他们父家的谱系，跟随他们的作战军兵有三万六千人，因为他们的妻儿众多。</span>
<span className="v" id="v5" data-v="5"> 他们的族兄弟，以萨迦所有家族中英勇的战士，按着他们的家谱记录，共有八万七千人。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 46:21; 历代志上 8:1–40; 历代志上 7:10–11"> 便雅悯的儿子是比拉、比结和耶迪阿业，共三人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志下 17:17–18; 历代志上 21:1–5"> 比拉的儿子是伊兹本、乌基、乌基业、耶利莫和以利，共五人，都是他们父家的首领，是英勇的战士。他们记录家谱的，有两万两千零三十四人。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 比结的儿子是细米拉、约阿施、以利以谢、以利约奈、欧姆利、耶利莫、亚比雅、亚纳图和阿勒米特，这都是比结的儿子。</span>
<span className="v" id="v9" data-v="9"> 他们按着各父家首领的谱系记录了家谱，都是英勇的战士，共两万零两百人。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="士师记 3:15–30"> 耶迪阿业的儿子是比勒罕，比勒罕的儿子是耶乌施、便雅悯、以胡德、克拿阿纳、细坦、塔尔施和亚希沙哈。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 17:13–19"> 这些都是耶迪阿业的儿子，是各父系的首领、英勇的战士；他们能上阵出战的，共一万七千两百人。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 26:38–39; 创世记 46:21; 历代志上 7:15"> 此外还有以珥的儿子书皮姆和户皮姆，阿赫尔的儿子户西姆。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 26:48–49; 创世记 30:3–8; 创世记 35:22"> 拿弗他利的儿子是雅赫兹列、古尼、耶则尔、沙勒姆。他们都是碧拉的子孙。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 32:30–42; 士师记 5:14; 申命记 3:13–15"> 玛拿西的儿子是亚斯列，是他的亚兰妾所生的，她还生了基列的父亲玛吉。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 26:33; 民数记 36:1–12; 民数记 27:1–11"> 玛吉娶了一个妻子，是户皮姆和书皮姆的妹妹，名叫玛迦。玛吉有另一系的子孙<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="玛吉……的子孙——辅助词语；参《约书亚记》17:3。">a</a></sup>名叫西罗非哈，西罗非哈只有女儿。</span>
<span className="v" id="v16" data-v="16"> 玛吉的妻子玛迦生了一个儿子，她给他起名为佩雷示；佩雷示的兄弟名叫谢雷示，谢雷示的儿子是乌兰和利肯，</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 12:11"> 乌兰的儿子是比丹。<br />这些是基列的子孙，基列是玛吉的儿子，玛吉是玛拿西的儿子。</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 6:24; 士师记 6:11; 士师记 8:2"> 基列的妹妹哈莫莉克生了伊施赫德、亚比以谢、玛拉。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 谢米达的儿子是阿希扬、示剑、利克希、阿尼安。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数记 26:35–36"> 以法莲的儿子是书提拉，<br />书提拉的儿子是贝列德，<br />贝列德的儿子是塔哈特，<br />塔哈特的儿子是伊拉达，<br />伊拉达的儿子是塔哈特，</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 塔哈特的儿子是撒巴德，<br />撒巴德的儿子是书提拉。<br />以法莲的儿子还有以谢尔和以利亚德，被当地的迦特人杀了，因为他们下去夺取迦特人的牲畜。</span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 2:11; 创世记 37:34"> 他们的父亲以法莲悲恸了许多日子，他的族兄弟都来安慰他。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 23:5"> 后来以法莲与妻子同房，她就怀孕，生了一个儿子，以法莲给儿子起名为比利亚，因为他家里遭了祸患。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 16:3; 约书亚记 16:5; 历代志下 8:5"> 他的女儿是谢伊拉，谢伊拉建造了下伯贺仑和上伯贺仑，以及乌曾-谢伊拉。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 比利亚的儿子是利法和利谢，<br />利谢的儿子是特拉，<br />特拉的儿子是塔罕，</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 塔罕的儿子是拉丹，<br />拉丹的儿子是亚米忽，<br />亚米忽的儿子是以利沙玛，</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="民数记 13:8; 民数记 13:16; 出埃及记 17:9–14"> 以利沙玛的儿子是嫩，<br />嫩的儿子是约书亚。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="创世记 28:19; 约书亚记 16:2–3; 历代志上 6:66–67"> 他们的产业和居住的地方是伯特利和附属的村镇，东边的拿兰，西边的基色和附属的村镇，以及示剑和附属的村镇，直到艾雅和附属的村镇；</span>
<span className="v" id="v29" data-v="29" data-xref="士师记 1:22–29; 撒迦利亚书 12:11; 列王纪下 9:27"> 还有靠近玛拿西子孙边界的伯珊和附属的村镇，特纳克和附属的村镇，米吉多和附属的村镇，多珥和附属的村镇。以色列的儿子约瑟的子孙就住在这些地方。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="创世记 46:17; 民数记 26:44–46"> 亚设的儿子是伊姆纳、伊施瓦、伊施韦和比利亚，还有他们的妹妹西拉。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31"> 比利亚的儿子是希伯和玛结，玛结是比尔仔特的父亲。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 希伯生了雅弗列、朔梅尔、赫坦和他们的妹妹淑雅。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33"> 雅弗列的儿子是琶萨、宾哈勒和阿示瓦，这些是雅弗列的儿子。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> 朔梅尔的儿子是亚希、罗迦、户巴<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="户巴——传统音译作“耶户巴”。">b</a></sup>和亚兰。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35"> 他的兄弟希连的儿子是佐法、伊姆纳、示列斯和亚玛尔。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36"> 佐法的儿子是苏阿赫、哈尼弗、书阿勒、比利、伊姆拉、</span>
<span className="v" id="v37" data-v="37"> 比册尔、赫德、沙玛、希勒沙、益兰、比尔拉。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> 耶特尔的儿子是耶弗尼、皮斯巴和阿拉。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39"> 乌拉的儿子是阿拉赫、哈尼业和利茨亚。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="历代志上 21:1–5; 撒母耳记下 24:1–9"> 这些人都是亚设的子孙，是他们父家的首领，是精选的勇士，在领袖中为首。他们的家谱记录里，能上阵出战的，数目有两万六千人。</span>
</div>
</div>

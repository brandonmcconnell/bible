<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 11:1–2; 撒母耳记下 10:1–19; 撒母耳记上 12:12"> 此后，亚扪人的王纳哈什死了，他的儿子接替他作王。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 23:3–6; 撒母耳记上 30:26; 创世记 19:37–38"> 大卫说：“我要以恩慈对待纳哈什的儿子哈嫩，因为他父亲曾以恩慈对待我。”<br />于是大卫派遣使者为哈嫩丧父的事安慰他。大卫的臣仆来到亚扪人之地见哈嫩，要安慰他，</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 1:23–24; 哥林多前书 13:5–7; 列王纪上 12:8–11"> 但亚扪人的首领们对哈嫩说：“你以为大卫是尊敬你父亲，所以派人来安慰你吗？他的臣仆们来见你，难道不是为了探查、倾覆，为了窥探这地吗？”</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 10:4–5; 以赛亚书 15:2; 马可福音 12:4"> 哈嫩就抓住大卫的臣仆，把他们的胡须剃掉，又把他们的衣服从臀部以下割去一半，然后放他们走。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约书亚记 6:24–26; 马太福音 18:31; 列王纪上 16:34"> 有人来把这些人遭遇的事向大卫报告，大卫就派人去迎接他们，因为这些人受了极大的羞辱。王说：“你们可以住在耶利哥，等胡须长好了再回来。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="历代志上 18:5; 创世记 34:30; 历代志上 18:9"> 亚扪人知道他们被大卫厌恶，哈嫩和亚扪人就派人拿一千他连得<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一千他连得——相当于34.2公吨。1他连得=34.2公斤。">a</a></sup>银子，从美索不达米亚<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="美索不达米亚——原文直译“两河之间的亚兰”。">b</a></sup>、亚兰-玛迦和琐巴雇用战车和马兵。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 21:30; 约书亚记 13:9; 约书亚记 13:16"> 他们雇来了三万两千辆战车，还有玛迦王和他的军兵。这些军兵都来到米底巴前面扎营。亚扪人也从他们各城中聚集，出来作战。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="历代志上 11:6; 历代志上 11:10–47; 撒母耳记下 23:8–39"> 大卫听说了，就派遣约押和全军的勇士出战。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 20:1; 列王纪上 20:24; 以赛亚书 28:6"> 亚扪人出来，在自己的城门口摆开战阵；前来的诸王，他们单独在郊外摆阵。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 10:9–14; 士师记 20:42–43; 约书亚记 8:22"> 约押见自己腹背受敌，就从以色列所有精兵中挑选了一部分，摆阵迎战亚兰人，</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 18:12; 历代志上 11:20; 历代志上 19:9"> 其余的人交在他兄弟亚比筛手下，摆阵迎战亚扪人。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="腓立比书 1:27–28; 尼希米记 4:20; 传道书 4:9–12"> 约押说：“如果亚兰人强过我，你就过来帮助我；如果亚扪人强过你，我就过去帮助你。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 4:14; 诗篇 27:14; 撒母耳记下 10:12"> 要坚强，我们要为我们的人民、为我们神的城镇而坚强！愿耶和华做他眼中看为好的事。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王纪上 20:19–21; 历代志下 13:5–16; 耶利米书 46:15–16"> 于是约押和跟随他的人上前与亚兰人作战，亚兰人从他面前逃跑。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 8:31; 利未记 26:7"> 亚扪人见亚兰人逃跑，也从约押的弟弟亚比筛面前逃跑，逃进城里。于是约押就回耶路撒冷去了。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 10:16; 撒迦利亚书 14:1–3; 弥迦书 4:11–12"> 亚兰人见自己败在以色列人面前，就派遣使者去把大河<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="大河——指幼发拉底河。">c</a></sup>对岸的亚兰人调过来，由哈大底谢的元帅朔法率领他们。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 22:6–7; 历代志上 19:9"> 有人向大卫报告，大卫就招聚以色列全军，过了约旦河，来到亚兰人那里，对着他们摆阵。大卫摆阵迎战亚兰人，亚兰人就与他交战。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 10:18; 诗篇 33:16; 诗篇 18:32"> 亚兰人在以色列人面前逃跑，大卫杀了亚兰的战车兵七千<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="七千——《撒母耳记下》10:18为“七百”。">d</a></sup>、步兵四万，并且杀死了元帅朔法。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 10:19; 约书亚记 9:9–11; 列王纪上 20:1"> 哈大底谢的臣属见自己败在以色列面前，就与大卫讲和，臣服于他。于是亚兰人不敢再帮助亚扪人了。</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="HEB" data-book-slug="hebrews" data-book-name="希伯来书" data-chapter="11" data-verses="40">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 5:7; 哥林多后书 4:18; 罗马书 8:24–25"> 信，是对所盼望的事有把握，对看不见的事有确据。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:39; 希伯来书 11:4"> 古人因着这信曾受到了赞许。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="诗篇 33:6; 彼得后书 3:5; 约翰福音 1:3"> 因着信，我们明白宇宙<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="宇宙——或译作“各世代”。">a</a></sup>是藉着神的话语形成的，从而明白那看得见的事是从看不见的事造出来的。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="希伯来书 12:24; 创世记 4:3–5; 约翰一书 3:11–12"> 因着信，亚伯向神献上的祭物比该隐所献的更好，就藉着信受到了赞许成为义人，因为神赞许他的礼物。他虽然死了，但藉着信仍然说话。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 5:21–24; 犹大书 1:14; 希伯来书 11:6"> 因着信，以诺被接去而没有经历死亡，人也找不到他，因为神把他接去了。原来他被接去以前，已经蒙神喜悦而受到赞许。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 8:17; 耶利米书 29:13–14; 马太福音 6:33"> 没有信，就不可能蒙神喜悦，因为来到神面前的人，必须相信神存在，并且相信他报偿那些寻求他的人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="创世记 6:13–1; 彼得前书 3:20; 以西结书 14:14"> 因着信，挪亚在那还看不见的事上得了神的指示，就动了敬畏的心，建造了一只方舟，以至于他的家人获救。藉着信，他定了世界的罪，自己也继承了从信而来的义。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="创世记 12:1–4; 使徒行传 7:2–4; 马太福音 7:24–25"> 因着信，亚伯拉罕蒙召的时候，就顺从出发，往他将要得为继业的地方去。他出发的时候，还不知道往哪里去。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 12:8; 创世记 13:18; 创世记 13:3"> 因着信，他做为外人客居在应许之地，住在帐幕里，与同一个应许的共同继承人以撒、雅各一样，</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 13:14; 腓立比书 3:20; 希伯来书 12:22"> 因为他等待着那座有根基的城；那城是神所设计、所建造的。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="罗马书 4:20–21; 希伯来书 10:23; 创世记 18:11–14"> 同样因着信，不能生育的撒拉，自己虽然过了年龄，还是领受了怀孕生子的能力，原来她认为向她应许的那一位<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="因着信，不能生育的撒拉……原来她认为向她应许的那一位——或译作“因着信，亚伯拉罕虽然过了年岁——撒拉又不能生育——但是仍然得着了生育的能力，原来亚伯拉罕认为向他应许的那一位”。">b</a></sup>是信实的。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 22:17; 创世记 32:12; 创世记 15:5"> 所以从一个如同已经死了的人，就生出了许多人，像天空的星那样众多，像海边的沙那样无法数算。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 23:4; 诗篇 39:12; 希伯来书 11:27"> 这些人都怀着信仰死去，没有得到那些所应许的，却远远地看见<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附“深信它们”。">c</a></sup>并且欢迎它们，又承认自己在地上是异乡人，是寄居的。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 4:18–7; 希伯来书 11:16; 希伯来书 13:14"> 实际上，说这样话的人，是表明他们在寻求一个家乡。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 24:6–8; 创世记 12:10; 创世记 32:9–11"> 如果他们真是想念自己所离开的地方，他们还有机会回去；</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 13:14; 希伯来书 11:10; 腓立比书 3:20"> 但如今，他们所向往的是一个更美好的，就是在天上的家乡。因此，神被称为“他们的神”并不以为耻；原来他已经为他们预备了一座城。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 22:16; 创世记 22:1–12; 雅各书 2:21–24"> 因着信，亚伯拉罕在受考验的时候，献上了以撒；这位领受了各样应许的人，献上了自己的独生儿子——</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 21:12; 罗马书 9:7; 创世记 17:19"> 关于这儿子，神曾经说过：“从以撒生的，将被称为你的后裔。”</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 4:17–21; 马太福音 9:28; 以弗所书 3:20"> 亚伯拉罕认为，神真的能使人从死人中复活。故此，用比喻来说，他真的从死人中得回了以撒。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 27:27–40; 创世记 28:2–3"> 同样因着信，以撒指着将来的事祝福了雅各和以扫。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 47:31–1; 创世记 48:5–22"> 因着信，雅各临死的时候，祝福了约瑟的每个儿子，又倚着自己的杖头敬拜神。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 13:19; 创世记 50:24–25; 约书亚记 24:32"> 因着信，约瑟临终的时候，提到以色列子民出埃及的事，也为自己的骸骨留下了遗言。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出埃及记 1:22; 出埃及记 1:16; 希伯来书 13:6"> 因着信，摩西出生以后，被父母藏了三个月，原来他们看见孩子俊美；他们不怕王的命令。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 2:10–11; 使徒行传 7:21–24"> 因着信，摩西长大以后，拒绝被称为法老女儿的儿子。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 84:10; 提摩太后书 2:3–10; 约伯记 36:21"> 他宁愿选择与神的子民同受虐待，也不愿享受暂时的罪中之乐。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 10:35; 希伯来书 11:6; 彼得前书 4:14"> 他把为基督受的责骂看做是比埃及的财宝更大的财富，因为他注目那将来的报偿。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="哥林多后书 4:18; 希伯来书 11:13; 希伯来书 11:1"> 因着信，他不怕王的愤怒，离开了埃及，因为他恒心忍耐，如同看见了不可见的那一位。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 12:21–30; 希伯来书 9:19; 希伯来书 12:24"> 因着信，他立<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="立——或译作“守”。">d</a></sup>了逾越节和洒血的礼，免得那毁灭长子<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="长子——原文直译“首生者”。">e</a></sup>的碰以色列人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="以色列人——原文直译“他们”。">f</a></sup>。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 14:13–21; 诗篇 106:9–11; 诗篇 78:13"> 因着信，他们走过了红海，像走过干地那样；埃及人试着这样做，就被吞灭了。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约书亚记 6:3–20; 哥林多后书 10:4–5"> 因着信，他们围绕耶利哥城七天，城墙就倒塌了。</span>
<span className="v" id="v31" data-v="31" data-xref="雅各书 2:25; 约书亚记 6:22–25; 马太福音 1:5"> 因着信，妓女拉合在平安中接纳了侦察的人，没有和那些不肯信从的人一同灭亡。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 16:1; 撒母耳记上 1:20; 撒母耳记上 16:13"> 我还要再说什么呢？如果我一一述说基甸、巴拉克、叁孙、耶弗塔、大卫、撒母耳和先知们的事，时间就不够了。</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 144:1–2; 希伯来书 6:12–15; 希伯来书 10:36"> 他们藉着信，征服了列国，行了公义，获得了那些应许；他们堵住了狮子的口，</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪下 6:16–18; 哥林多后书 12:9–10; 撒母耳记上 17:51–52"> 灭了烈火的威力，逃脱了刀剑的锋刃，从软弱中得以刚强，在战争中得以强大，击败了外国的军队。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪下 4:27–37; 列王纪上 17:22–24; 腓立比书 3:11"> 有些妇女得回了那些从死人中复活的亲人；有些人受酷刑至死也不肯接受释放，为要得到更美好的复活；</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 20:2; 创世记 39:20; 耶利米书 37:15–21"> 另有些人经受了戏弄、鞭打的试炼；还有些人受了捆锁、监禁的试炼；</span>
<span className="v" id="v37" data-v="37" data-xref="历代志下 24:21; 耶利米书 26:23; 列王纪上 19:10"> 他们被石头砸死，被锯成两截，<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附“受到考验，”。">g</a></sup>被刀剑杀死，披着绵羊、山羊的皮四处漂泊，遭受穷困、患难和虐待。</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪上 18:4; 撒母耳记上 22:1; 列王纪上 19:9"> 他们是这世界不配有的。他们在旷野、山岭、岩穴、地洞中漂流无定。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 10:23–24; 希伯来书 11:13; 希伯来书 11:2"> 这些人虽然都藉着信受到了赞许，还是没有领受到所应许的，</span>
<span className="v" id="v40" data-v="40" data-xref="启示录 6:11; 希伯来书 8:6; 希伯来书 10:11–14"> 因为神为我们预备了更美好的事，使他们没有我们，就不能得以完全。</span>
</div>
</div>

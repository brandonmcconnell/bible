<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="HEB" data-book-slug="hebrews" data-book-name="希伯来书" data-chapter="7" data-verses="28">

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="创世记 14:18–20; 诗篇 57:2; 希伯来书 6:20"> 原来这麦基洗德——<br /><span className="pl pl-1">撒冷之王，至高神的祭司，</span><br /><span className="pl pl-1">在亚伯拉罕杀败众王回来的时候，去迎接他、祝福他，</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="民数记 18:21; 诗篇 85:10–11; 撒母耳记上 8:17"> <span className="pl pl-1">亚伯拉罕就从所得来的一切中，把十分之一献给</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="献给——原文直译“分给”。">a</a></sup><br /><span className="pl pl-1">他。</span><br /><span className="pl pl-1">“麦基洗德”翻译出来，首先是“公义之王”，</span><br /><span className="pl pl-1">然后又是“撒冷之王”——这意思是“和平之王”。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 7:17; 希伯来书 7:23–28; 出埃及记 6:20–27"> <span className="pl pl-1">他没有父亲，没有母亲，没有族谱，</span><br /><span className="pl pl-1">没有年岁的开始，也没有生命的终结，</span><br /><span className="pl pl-1">与神的儿子相似，持久做祭司，直到永远。</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="创世记 14:20; 使徒行传 2:29; 使徒行传 7:8–9"> 你们当想一想，这个人多么伟大！连先祖亚伯拉罕也从最好的战利品中把十分之一献给他。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 27:30–33; 历代志下 31:4–6; 民数记 18:21–32"> 虽然利未子孙中那些领受祭司职务的，从亚伯拉罕的后裔<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="后裔——原文直译“腰”。">b</a></sup>中出来，他们还是奉命按照律法向子民，就是自己的同胞<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="同胞——原文直译“兄弟”。">c</a></sup>，收取十分之一。</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 4:13; 希伯来书 7:3–4; 创世记 13:14–17"> 可是，不出于利未世系的那一位，却从亚伯拉罕收取了十分之一，并且祝福了那拥有各样应许的亚伯拉罕。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 30:27; 创世记 48:15–20; 提摩太前书 3:16"> 原来，位分小的从位分大的接受祝福，是毫无争议的事。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 6:20; 希伯来书 5:6; 启示录 1:18"> 在这里，收取十分之一的人们固然都会死去；但在那里，他却被见证说是永生的。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 5:12; 创世记 14:20; 希伯来书 7:4"> 甚至从某种意义上可以说：连那收取十分之一的利未，也藉着亚伯拉罕交纳了十分之一，</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 35:11; 希伯来书 7:5; 创世记 46:26"> 因为麦基洗德迎接亚伯拉罕的时候，利未还在他先祖的身体<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="身体——原文直译“腰”。">d</a></sup>里面。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="希伯来书 8:7; 加拉太书 2:21; 加拉太书 4:9"> 既然如此，如果藉着利未人的祭司职份能达到完全——子民本来在这职份下领受了律法——那么，为什么还需要照着麦基洗德的等级<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="等级——或译作“体系”。">e</a></sup>，而不照着所谓“亚伦的等级”兴起另一位祭司呢？</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 31:31–34; 以赛亚书 66:21; 以西结书 16:61"> 祭司职份被更换，律法也必须有所更换。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 7:11; 希伯来书 7:14; 民数记 17:5"> 其实这些话所论到的那一位是属于别的支派，这支派中从来没有人在祭坛供过职；</span>
<span className="v" id="v14" data-v="14" data-xref="弥迦书 5:2; 以赛亚书 11:1; 路加福音 3:33"> 就是说，我们的主明显是从犹大支派<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="支派——辅助词语。">f</a></sup>兴起的，而对于这个支派，摩西从来没有提到有关祭司<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="祭司——有古抄本作“祭司职份”。">g</a></sup>的事。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="诗篇 110:4; 希伯来书 7:17–21; 希伯来书 7:3"> 如果照着麦基洗德的相同样式另有一位祭司兴起来，那么，这件事就更加明显了。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 1:18; 歌罗西书 2:20; 希伯来书 7:28"> 他成为祭司，不是照着有关肉体条例的法则，而是照着那不能毁灭的生命大能，</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 110:4; 希伯来书 5:6; 希伯来书 7:21"> 因为他被见证说：<br /><span className="pl pl-1">“你是照着麦基洗德的等级</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="等级——或译作“体系”。">h</a></sup><br /><span className="pl pl-1">做祭司，直到永远。”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="罗马书 8:3; 使徒行传 13:39; 加拉太书 4:9"> 原来，一方面，先前的条例因着本身的软弱和无用，就被废弃了，</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 13:39; 希伯来书 4:16; 希伯来书 9:9"> 因为律法没有使任何事物完全；另一方面，一个更美好的盼望却被带来了；藉着这个盼望，我们可以亲近神。</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="民数记 18:7; 希伯来书 5:6; 诗篇 110:4"> 再者，所发生的事并不是没有神的<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="神的——辅助词语。">i</a></sup>誓言保证。就是说，其他人成为祭司是没有誓言保证的，</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 110:4; 希伯来书 7:17; 希伯来书 6:16–18"> 可是耶稣<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="耶稣——原文直译“他”。">j</a></sup>藉着对他说话的那一位是有誓言保证的：<br /><span className="pl pl-1">“主起了誓，不会后悔：</span><br /><span className="pl pl-1">‘你是</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="有古抄本附“照着麦基洗德的等级做”。">k</a></sup><br /><span className="pl pl-1">祭司，直到永远。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 11:25; 创世记 44:32; 希伯来书 8:6–12"> 既然如此，耶稣也就成了更美好之约的保证人。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="尼希米记 12:10–11; 历代志上 6:3–14; 希伯来书 7:8"> 那些以前成为祭司的固然人数众多，因为死亡阻止了他们继续留任，</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 12:34; 希伯来书 7:28; 以赛亚书 9:6–7"> 但由于耶稣永远长存，就拥有永恒不变的祭司职份；</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 8:34; 约翰一书 2:1–2; 提摩太前书 2:5"> 故此，他也能彻底<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="彻底——或译作“永远”。">l</a></sup>拯救那些藉着他来到神面前的人；因为他一直活着，为他们代求。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="哥林多后书 5:21; 希伯来书 4:14–15; 彼得前书 2:22"> 这样一位圣洁、没有邪恶、毫无玷污、与罪人分开、高过诸天的大祭司，对我们实在是合宜的。</span>
<span className="v" id="v27" data-v="27" data-xref="希伯来书 9:28; 希伯来书 9:12; 希伯来书 9:14"> 他不需要像其他大祭司那样天天献祭：先为自己的罪孽，然后为子民；因为当他把自己献上的时候，就一次性地把这事完成了。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 2:10; 希伯来书 7:21; 希伯来书 1:2"> 律法委任的大祭司都有软弱，但在律法以后，誓言保证的话语所委任的儿子，却永远完全。</span>
</div>
</div>

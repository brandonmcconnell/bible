<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="HEB" data-book-slug="hebrews" data-book-name="希伯来书" data-chapter="12" data-verses="29">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太后书 4:7; 哥林多前书 9:24–27; 腓立比书 2:16"> 因此，我们既然有这么一大群见证人，如同云彩围绕着我们，就让我们脱去各样的重担和容易缠累我们的罪，藉着忍耐去跑那摆在我们前面的赛程，</span>
<span className="v" id="v2" data-v="2" data-xref="弥迦书 7:7; 彼得前书 3:18; 彼得前书 2:23–24"> 仰望信仰的创始者和成终者耶稣。他为了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="为了——或译作“替换”。">a</a></sup>那摆在他前面的喜乐，就轻看羞辱，忍受了十字架，如今坐在神宝座的右边。</span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="加拉太书 6:9; 哥林多后书 4:16; 启示录 2:3"> 其实，你们应当仔细地思想耶稣如何忍受了罪人的顶撞，这样你们心里<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="心里——或译作“灵魂”。">b</a></sup>就不会因丧气而疲倦。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 10:13; 启示录 2:13; 希伯来书 10:32–34"> 你们与罪争战，还没有抵抗到流血的地步。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 3:11–12; 约伯记 5:17–18; 启示录 3:19"> 难道你们已经忘记那安慰的话吗？就是他对你们如同对儿女那样讲论的话：<br /><span className="pl pl-1">“我儿，你不可轻看主的管教；</span><br /><span className="pl pl-1">被他责备的时候，也不可丧气。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="启示录 3:19; 箴言 3:12; 诗篇 119:75"> <span className="pl pl-1">因为主所爱的人，主都管教；</span><br /><span className="pl pl-1">他所接纳的每一个儿子，他都鞭打。”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="箴言 19:18; 申命记 8:5; 箴言 13:24"> 对管教的事，你们要忍受；神对待你们，就像对待儿女那样。到底哪一个儿子不受父亲的管教呢？</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 12:6; 彼得前书 5:9–10; 诗篇 73:1"> 大家都有份受管教；你们如果没有受管教，那么，你们就是私生子，不是儿子了。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 16:22; 民数记 27:16; 以赛亚书 42:5"> 再者，我们有肉身的父亲来管教我们，我们尚且敬重他们，何况对这位万灵之父，我们难道不更要服从他而活着吗？</span>
<span className="v" id="v10" data-v="10" data-xref="彼得后书 1:4; 利未记 11:44–45; 提多书 2:14"> 肉身的父亲在短暂的日子里，固然照着自己的意思来管教我们；但万灵之父是为了我们的益处管教我们，好使我们在他的圣洁上有份。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 5:3–5; 哥林多后书 4:17; 希伯来书 12:5–6"> 不过所有的管教，当时虽然不觉得是愉快的事，反觉得是忧伤的事，而后来却为那些由此受到操练的人，结出平安和义行的果子。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 35:3; 希伯来书 12:3; 帖撒罗尼迦前书 5:14"> 因此，你们要把发软的手、发酸的腿伸直吧！</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 4:26–27; 以赛亚书 35:3; 加拉太书 6:1"> 也要为你们的脚把道路修直<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="修直——或译作“修平”。">c</a></sup>，好使瘸腿的不至扭脚<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="扭脚——或译作“偏离”或“被人避开”。">d</a></sup>，反得痊愈。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 7:1; 彼得前书 1:15–16; 帖撒罗尼迦前书 4:7"> 你们要追求与众人和睦，要追求圣洁。任何不圣洁的人，都不能见到主。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 3:12; 申命记 29:18; 加拉太书 5:4"> 你们要谨慎，免得有人亏缺了神的恩典；免得有苦毒的根长起来搅扰你们，使许多人因此被污秽了；</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 25:31–34; 哥林多前书 6:15–20; 启示录 22:15"> 又免得有淫乱的，或像以扫那样不敬神的。以扫为了<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="为了——或译作“替换”。">e</a></sup>一点食物，就把自己长子的名份卖了；</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 1:24–31; 马太福音 25:11–12; 马太福音 7:23"> 你们知道，后来他想继承祝福，却被弃绝了，虽然他流着泪水寻求，还是找不到悔改的机会。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命记 4:11; 出埃及记 24:17; 出埃及记 20:18"> 你们并不是来到了摸得着的山<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本没有“山”。">f</a></sup>、燃烧着的火、阴云、幽暗、风暴、</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 18:16; 哥林多前书 15:52; 申命记 4:12"> 号角的响声和说话的声音面前——那些听见这声音的人，都恳求不要再向他们说话了，</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 19:12–13; 出埃及记 19:16; 加拉太书 3:10"> 因为他们担当不了那吩咐他们的话：“即使是野兽触摸这山，也要用石头砸死<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附“或被标枪刺穿”。">g</a></sup>。”</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 19:16; 申命记 9:19; 以赛亚书 6:3–5"> 那景象实在可怕，连摩西也说：“我非常害怕战兢。”</span>
<span className="v" id="v22" data-v="22" data-xref="加拉太书 4:26; 腓立比书 3:20; 启示录 14:1"> 相反，你们却是来到了锡安山、永生神的城、天上的耶路撒冷面前；来到了千万天使的盛会面前；</span>
<span className="v" id="v23" data-v="23" data-xref="雅各书 1:18; 希伯来书 11:40; 路加福音 10:20"> 来到了长子们<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="长子们——原文直译“首生者们”。">h</a></sup>的教会面前——他们的名字<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="名字——辅助词语。">i</a></sup>已经登记在天上；来到了神面前——他是万人的审判者；来到了义人的灵魂面前——他们得以完全；</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 9:15; 希伯来书 11:28; 希伯来书 11:4"> 来到了耶稣面前——他是新约的中保；来到了所洒的血面前——这血比亚伯的血所述说的更美好。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="希伯来书 8:5; 申命记 30:17; 希伯来书 2:1–3"> 你们要当心，不要拒绝向你们<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="向你们——辅助词语。">j</a></sup>说话的那一位。要知道，那些拒绝了在地上警告他们的，尚且无法逃脱惩罚<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="惩罚——辅助词语。">k</a></sup>，更何况我们背弃从天上警告我们的那一位呢！</span>
<span className="v" id="v26" data-v="26" data-xref="哈该书 2:6–7; 以赛亚书 13:13; 出埃及记 19:18"> 那时候，他的声音震动了大地，但如今他应许说：“我不仅要再一次震动地，而且还要震动天。”</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 7:31; 马太福音 24:35; 彼得后书 3:10–11"> “再一次”这句话表明了那些能够被震动的，就如被造之物，都要被挪去，好使那些不能被震动的可以存留。</span>
<span className="v" id="v28" data-v="28" data-xref="罗马书 12:1–2; 希伯来书 13:15; 但以理书 2:44"> 因此，我们既然在领受一个不能被震动的国度，就让我们怀有感恩的心<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="怀有感恩的心——或译作“持守恩典”。">l</a></sup>，藉此以虔诚和敬畏，照着神所喜悦的<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="照着神所喜悦的——或译作“按蒙喜悦的方式”。">m</a></sup>来事奉他。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 4:24; 申命记 9:3; 希伯来书 10:27"> 要知道，我们的神实在是吞噬的烈火。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太后书 1:9; 腓立比书 3:14; 希伯来书 4:14–15"> 故此，蒙了属天召唤的同伴们，圣洁的弟兄们！你们应该思想我们信仰<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="信仰——辅助词语。">a</a></sup>告白中的使者和大祭司——耶稣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="耶稣——有古抄本作“基督耶稣”。">b</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 12:7; 提摩太前书 3:15; 以弗所书 2:22"> 他对委任他的那一位是忠心的，正如摩西在神的全家也是忠心的。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 3:9; 彼得前书 2:5–7; 撒迦利亚书 6:12–13"> 事实上，这个人被看为比摩西配得更大的荣耀，就像建造房屋的人比房屋本身更有尊荣那样，</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 3:3; 希伯来书 1:2; 以斯帖记 2:10"> 因为每一座房屋都是由人建造的，而建造万有的就是神。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 12:7; 希伯来书 3:2; 出埃及记 14:31"> 摩西是做为仆人，对神的全家忠心，为将被述说的事做见证；</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 6:16; 哥林多前书 3:16; 希伯来书 10:35"> 但基督是做为儿子，忠心管理神的家。如果我们持守所确信的和所夸耀的盼望，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附“坚定地持守到底，”。">c</a></sup>我们就是神的家。</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="诗篇 95:7–11; 希伯来书 3:15; 以赛亚书 55:3"> 因此，就像圣灵所说的：<br /><span className="pl pl-1">“今天，你们如果听见他的声音，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 28:14; 出埃及记 17:7; 撒迦利亚书 7:11–12"> <span className="pl pl-1">就不可硬着你们的心，</span><br /><span className="pl pl-1">如同在那悖逆的时候，也像在那旷野试探的日子。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 7:36; 申命记 4:9; 出埃及记 19:4"> <span className="pl pl-1">在那里，你们的祖先考验我、试探我，</span><br /><span className="pl pl-1">并且看了我的作为四十年之久。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 95:10; 帖撒罗尼迦后书 2:10–12; 诗篇 67:2"> <span className="pl pl-1">所以，我向那世代发怒，说：</span><br /><span className="pl pl-1">‘他们的心总是被迷惑，</span><br /><span className="pl pl-1">他们不认识我的道路’，</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="申命记 1:34–35; 希伯来书 4:3; 民数记 32:10–13"> <span className="pl pl-1">所以，我在自己的震怒中起誓说：</span><br /><span className="pl pl-1">‘他们绝不能进入我的安息。’”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="耶利米书 17:5; 耶利米书 7:24; 耶利米书 17:9"> 弟兄们，你们要当心，免得你们中间有人存着不信的邪恶之心，以致离开永生的神。</span>
<span className="v" id="v13" data-v="13" data-xref="帖撒罗尼迦前书 5:11; 希伯来书 10:24–25; 提摩太后书 4:2"> 只要日子还被称为“今天”，你们就要天天互相鼓励，免得你们当中有人被罪迷惑，心里刚硬。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 3:6; 希伯来书 6:11; 希伯来书 12:10"> 因为我们如果把那起初的确信，坚定地持守到底，我们就成为基督的同伴了。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 3:7–8; 诗篇 95:7; 希伯来书 10:38"> 经上说：<br /><span className="pl pl-1">“今天，你们如果听见他的声音，</span><br /><span className="pl pl-1">就不可硬着你们的心，如同在那悖逆的时候。”</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数记 14:2; 民数记 14:30; 民数记 26:65"> 到底是谁听见却悖逆了呢？难道不是被摩西从埃及带领<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="带领——辅助词语。">d</a></sup>出来的那一切人吗？</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 14:29; 民数记 26:64–65; 民数记 14:32–33"> 神又向谁发怒了四十年之久呢？难道不是那些犯了罪、尸首倒在旷野的人吗？</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 14:30; 希伯来书 4:6; 申命记 1:34–35"> 他又向谁起誓说，他们绝不能进入他的安息呢？难道不是向那些不肯信从的人吗？</span>
<span className="v" id="v19" data-v="19" data-xref="犹大书 1:5; 约翰福音 3:36; 马可福音 16:16"> 这样我们就看出来：他们不能进入，是因不信的缘故。</span>
</div>

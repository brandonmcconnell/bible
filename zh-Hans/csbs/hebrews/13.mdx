<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约翰一书 4:20–1; 彼得前书 3:8; 彼得前书 1:22"> 你们当常存弟兄之爱。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 25:35; 创世记 18:1–3; 彼得前书 4:9"> 不要忘记款待客旅，因为曾经有些人这样做，在无意中就招待了天使。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 25:36; 希伯来书 10:34; 罗马书 12:15"> 你们要顾念那些被囚禁的人，好像与他们一同被囚禁；要记念那些受虐待的人，好像你们自己也是在肉体中受虐待。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 2:24; 箴言 5:15–23; 加拉太书 5:19"> 婚姻当受所有人尊重，床也不可玷污，因为神将要审判淫乱和通奸的人。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 31:8; 约书亚记 1:5; 申命记 31:6"> 你们行事为人不要爱钱财，要以现有的为满足，因为神自己说过：“我绝不撇下你，也绝不离弃你。”</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 118:6–9; 以赛亚书 41:10; 罗马书 8:31"> 所以，我们可以满怀勇气地说：<br /><span className="pl pl-1">“主是我的帮助，</span><br /><span className="pl pl-1">我就不惧怕，</span><br /><span className="pl pl-1">人能把我怎么样呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="帖撒罗尼迦前书 5:12–13; 希伯来书 13:17; 腓立比书 3:17"> 你们当记住那些带领你们、把神的话语<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="神的话语——或译作“神的道”。">a</a></sup>传给你们的人；要仔细观察他们行事为人的结果，效法他们的信仰。</span>
<span className="v" id="v8" data-v="8" data-xref="玛拉基书 3:6; 雅各书 1:17; 启示录 1:8"> 耶稣基督昨天、今天、直到永远，都是一样的。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 4:14; 提摩太前书 6:3–5; 以弗所书 5:6"> 你们不要被各种怪异的教导引入歧途<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引入歧途——有古抄本作“被带走”或“被摇动”。">b</a></sup>，因为人的心靠恩典，不靠食物规定得以确立才是好的；那靠食物规定<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="规定——辅助词语。">c</a></sup>而行事的人，从来没有得到什么益处。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 5:7–8; 哥林多前书 10:20; 哥林多前书 9:13"> 我们有一个祭坛，这坛上的祭物<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="祭物——辅助词语。">d</a></sup>，是那些在会幕中事奉的人没有权利吃的。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 16:27; 出埃及记 29:14; 利未记 9:11"> 原来动物的血由大祭司带进圣所，是为了赎罪，而动物的身体却在营地外面被烧掉；</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 9:12–14; 约翰福音 19:17–18; 使徒行传 7:58"> 所以耶稣为了藉着自己的血使子民分别为圣，也在城门外受难。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 11:26; 彼得前书 4:14–16; 使徒行传 5:41"> 因此，让我们到营地外面他那里去，担当他所受的责骂。</span>
<span className="v" id="v14" data-v="14" data-xref="腓立比书 3:20; 歌罗西书 3:1–3; 希伯来书 11:12–16"> 因为在这里，我们没有长存的城；相反，我们是在寻求那将要来临的城。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 107:21–22; 诗篇 50:14; 罗马书 12:1"> 这样，让我们藉着耶稣，常常以颂赞为祭物献给神，这祭物就是承认他名的嘴唇所结的<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="所结的——辅助词语。">e</a></sup>果子。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦后书 3:13; 加拉太书 6:10; 罗马书 12:13"> 你们不可忘记行善和分享<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="分享——或译作“相契合”。">f</a></sup>，因为这样的祭物是蒙神喜悦的。</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦前书 5:12–13; 提摩太前书 5:17; 希伯来书 13:7"> 你们要信任那些带领你们的人，要服从他们，因为他们做为要交账的人，要为你们的灵魂时刻警醒。你们要让他们能怀着喜乐的心做这事，而不至叹息，因为让他们叹息，对你们并没有益处。</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 5:25; 帖撒罗尼迦后书 3:1; 歌罗西书 4:3"> 请为我们祷告；因为我们深信自己有无愧的良心，愿意在一切事上行事正直。</span>
<span className="v" id="v19" data-v="19" data-xref="腓利门书 1:22; 罗马书 1:10–12; 罗马书 15:31–32"> 我特别请求你们祷告，好让我能快一点回到你们那里。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约翰福音 10:11; 希伯来书 10:22; 诗篇 23:1"> 愿赐平安的神，就是藉着永恒之约的血，把群羊的大牧人我们的主耶稣从死人中领上来的那一位，</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比书 2:13; 帖撒罗尼迦后书 2:17; 腓立比书 4:13"> 在一切美善之事上使你们完备，好遵行他的旨意。愿神藉着耶稣基督，在我们里面行他看为喜悦的事。愿荣耀归于他，直到永永远远！阿们。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="希伯来书 3:1; 彼得前书 5:12; 哥林多后书 6:1"> 弟兄们，我恳求你们容忍我这劝勉的话，因为我只是简略地写信给你们。</span>
<span className="v" id="v23" data-v="23" data-xref="腓利门书 1:1; 帖撒罗尼迦前书 3:2; 提摩太后书 1:8"> 你们要知道，我们的弟兄提摩太已经被释放了。如果他能快一点来，我就与他一起去看你们。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 13:7; 希伯来书 13:17; 使徒行传 18:2"> 请问候所有带领你们的人和所有的圣徒。从意大利来的那些人也问候你们。</span>
<span className="v" id="v25" data-v="25" data-xref="歌罗西书 4:18; 提摩太后书 4:22; 提多书 3:15"> 愿恩典与你们大家同在！<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附“阿们。”">g</a></sup></span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="HEB" data-book-slug="hebrews" data-book-name="希伯来书" data-chapter="9" data-verses="28">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 25:8; 希伯来书 9:10–11; 希伯来书 8:2"> 这样，第一个约<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="约——辅助词语。">a</a></sup>也包括了事奉礼的规定和地上的圣所，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 40:4; 利未记 24:5–8; 出埃及记 26:35"> 因为有预备好的会幕：第一间里有灯台、桌子和陈设饼，这叫做圣所；</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 26:31–33; 出埃及记 40:3; 马太福音 27:51"> 会幕第二层幔子后面，叫做至圣所，</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 17:10; 历代志下 5:10; 出埃及记 40:3"> 里面有金香坛和四周包金的约柜；柜里有盛着吗哪的金罐、亚伦那根发过芽的杖和两块约版；</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 16:2; 民数记 7:89; 出埃及记 25:17–22"> 约柜上方有荣耀的基路伯，遮蔽着施恩座<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="施恩座——或译作“赎罪盖”或“赎罪台”。">b</a></sup>。关于这些，现在就不一一细说了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数记 28:3; 出埃及记 27:21; 路加福音 1:8–11"> 既然这些东西都这样预备好了，祭司们就常常进入第一间会幕行事奉礼。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 16:34; 利未记 5:18; 希伯来书 10:19–20"> 至于第二间会幕，只有大祭司一年进去一次，没有不带着血的；这血是为自己和子民无意中犯的罪所献上的。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 14:6; 希伯来书 3:7; 希伯来书 10:19–22"> 圣灵指明这一点：只要第一间会幕还存在，进入至圣所的道路就还没有显明出来。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 3:21; 希伯来书 5:1; 罗马书 5:14"> 这会幕是现今时代的一个象征，在这里所献上的礼物和祭物，并不能使事奉者的良心得以完全，</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 2:15; 歌罗西书 2:16; 利未记 11:2–47"> 因为这些只是关于饮食和各种洗净礼，是属肉体的规定，一直实施到更新的时候为止。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="希伯来书 9:23–24; 哥林多后书 5:1; 希伯来书 8:1–2"> 不过基督已经来到，做了那些已经发生的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="已经发生的——有古抄本作“将要来临的”。">c</a></sup>美善之事的大祭司，经过了那更大、更完美的会幕。那会幕不是人手所造的；就是说，不属于这被造的世界。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 10:4; 彼得前书 1:18–19; 希伯来书 9:15"> 他也没有藉着山羊和牛犊的血，而是藉着他自己的血，一次性地进入圣所，成就了永恒的救赎。</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 19:2–21; 利未记 16:14–16; 使徒行传 15:9"> 实际上，如果山羊和公牛的血，以及母牛犊的灰，洒在那些污秽的人身上，能使他们分别为圣、肉身洁净，</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 10:22; 彼得前书 1:19; 约翰一书 1:7"> 更何况基督的血呢！基督藉着永恒的圣灵<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="永恒的圣灵——原文直译“永恒的灵”。">d</a></sup>，将自己毫无瑕疵地献给神，他的血难道不能洁净我们<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="我们——有古抄本作“你们”。">e</a></sup>的良心脱离致死的行为，使我们事奉永生的神吗？</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="罗马书 3:24–26; 罗马书 8:30; 罗马书 8:28"> 为此，基督做了新约的中保，藉着死赎清了人在第一个约之下的过犯，好使那些蒙召的人可以得到所应许的永恒继业。</span>
<span className="v" id="v16" data-v="16" data-xref="雅各书 2:10; 哥林多前书 15:22; 罗马书 5:12"> 要知道，遗嘱<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="遗嘱——或译作“约”。">f</a></sup>在哪里生效<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="生效——辅助词语。">g</a></sup>，立遗嘱之人的死亡就必须得到证实。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 48:21; 约翰福音 14:27; 加拉太书 3:15"> 事实上，人死了，遗嘱<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="遗嘱——或译作“约”。">h</a></sup>才能确立，因为立遗嘱之人活着的时候，遗嘱绝对不能生效。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 24:3–8; 希伯来书 9:14; 希伯来书 9:22"> 原来不用血，第一个约也不能成立，</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 24:5–11; 民数记 19:6; 希伯来书 10:4"> 就是说，摩西按照律法向全体民众宣讲了所有的诫命之后，拿了牛犊和山羊<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本没有“和山羊”。">i</a></sup>的血，掺上水，用深红色的羊毛和牛膝草，洒在那书卷上和全体民众身上，</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 24:8; 马太福音 26:28; 希伯来书 13:20"> 说：“这是立约的血，是神吩咐给你们的。”</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 8:15; 利未记 8:19; 出埃及记 29:36"> 然后，他又同样地把血洒在会幕和服事用的所有器皿上。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 17:11; 利未记 6:7; 利未记 4:35"> 按照律法，几乎一切都是用血洁净的；没有流血，就没有赦免。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="彼得前书 1:19–21; 希伯来书 10:4; 希伯来书 9:14"> 既然那些诸天之上事物的模型，必须用这些祭物<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="祭物——辅助词语。">j</a></sup>来洁净，那天上事物的本体就必须用比这些更好的祭物来洁净，</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 12:2; 希伯来书 9:11–12; 希伯来书 9:23"> 因为基督不是进入了人手所造的圣所——那不过是真圣所的象征——而是进入了上天本身，如今替我们显现在神的面前。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 9:12; 希伯来书 9:7; 希伯来书 9:14"> 他也不用再三地将自己献上，像大祭司年年带着牛羊的<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="牛羊的——原文直译“非自己的”。">k</a></sup>血进入圣所那样，</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 9:12; 彼得前书 1:20; 希伯来书 1:2"> 否则，从创世以来，他就必须再三地受难了。但如今，他在万世的末期显现了一次，好藉着献上自己为祭，把罪除掉。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多后书 5:10; 传道书 12:7; 传道书 12:14"> 就如人人注定都有一死，而且死后有审判，</span>
<span className="v" id="v28" data-v="28" data-xref="提多书 2:13; 彼得前书 2:24; 罗马书 6:10"> 照样，基督为了担当众人的罪孽，也被献上一次；将来还要再一次显现，不是为了罪，而是为了使那些热切等待他的人得到救恩。</span>
</div>
</div>

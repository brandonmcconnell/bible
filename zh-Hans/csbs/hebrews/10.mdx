<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="HEB" data-book-slug="hebrews" data-book-name="希伯来书" data-chapter="10" data-verses="39">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 8:5; 希伯来书 9:11; 歌罗西书 2:17"> 既然律法带有那将要来的美好事物的影子，它不是那些事物的本像，就绝不能藉着年年不断地献上同样的祭物，使近前来的人得以完全。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 43:25; 弥迦书 7:19; 诗篇 103:12"> 否则，事奉的人因为一次性地被洁净，不再觉得有罪孽，难道不早就停止献祭了吗？</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 9:7; 出埃及记 30:10; 利未记 23:27–28"> 然而这些祭物使人年年都想起罪孽来，</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 10:11; 以赛亚书 1:11–15; 弥迦书 6:6–8"> 因为公牛和山羊的血，不可能把罪孽除去。</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="诗篇 40:6–8; 以赛亚书 1:11; 以赛亚书 7:14"> 所以，基督进入世界的时候，他说：<br /><span className="pl pl-1">“神哪</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="神哪——辅助词语。">a</a></sup><br /><span className="pl pl-1">，祭物和供物不是你所希望的；</span><br /><span className="pl pl-1">你为我预备了一个身体。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="玛拉基书 1:10; 马太福音 3:17; 诗篇 147:11"> <span className="pl pl-1">燔祭和赎罪祭不是你所喜悦的；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 40:7–8; 约翰福音 4:34; 约翰福音 6:38"> <span className="pl pl-1">于是我说：‘看哪，我来了！</span><br /><span className="pl pl-1">关于我的事，</span><br /><span className="pl pl-1">经卷上已经记载了。</span><br /><span className="pl pl-1">神哪，我来是要遵行你的旨意！’”</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="希伯来书 10:5; 马可福音 12:33"> 上文说：祭物、供物、燔祭和赎罪祭不是你所希望的，也不是你所喜悦的，尽管这些都是照着律法献上的；</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 7:18–19; 希伯来书 12:27–28; 希伯来书 10:7"> 接着又说：“看哪<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="看哪——有古抄本作“看，神哪”。">b</a></sup>，我来了！是要遵行你的旨意！”神废除前者，是为了确立后者。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 10:14; 希伯来书 10:12; 哥林多前书 6:11"> 我们凭着这旨意，藉着耶稣基督身体做供物，就已经一次性地被分别为圣了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="希伯来书 5:1; 民数记 28:3; 希伯来书 10:4"> 所有的祭司天天都站着服事，再三地献上同样的祭物，但这些祭物绝不能把罪孽除掉，</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 1:3; 歌罗西书 3:1; 罗马书 8:34"> 而这一位为赎罪孽献上了一个永远的祭物，就在神的右边坐下了，</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 1:13; 诗篇 110:1; 路加福音 20:43"> 此后一直等候他的敌人被放在他的脚下做脚凳。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 7:25; 希伯来书 10:1; 希伯来书 9:14"> 事实上，他藉着一个供物，使那些被分别为圣的人永远得以完全。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 3:7; 启示录 2:11; 启示录 3:6"> 圣灵也向我们做见证，因为他说过<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="说过——有古抄本作“预先说过”。">c</a></sup>：</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 31:33–34; 希伯来书 8:8–12; 罗马书 11:27"> <span className="pl pl-1">“主说：‘在那些日子以后，</span><br /><span className="pl pl-1">我要与他们订立这样的约：</span><br /><span className="pl pl-1">我要把我的法则放在他们的心上，</span><br /><span className="pl pl-1">刻在他们的意念中。’”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="耶利米书 31:34; 希伯来书 8:12"> 然后又说：<br /><span className="pl pl-1">“我绝不再想起他们的罪孽和他们的罪恶</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="罪恶——原文直译“不法”。">d</a></sup><br /><span className="pl pl-1">。”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="希伯来书 10:2; 希伯来书 10:14"> 所以在哪里这些罪得了赦免，在哪里就不再有赎罪的供物了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以弗所书 2:18; 希伯来书 9:12; 希伯来书 4:16"> 因此，弟兄们，我们藉着耶稣的血，可以坦然无惧地进入至圣所。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 14:6; 约翰福音 10:9; 希伯来书 9:3"> 他为我们开辟了一条又新又活的道路，从幔子经过；这幔子就是他的身体。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 2:17; 希伯来书 4:14–16; 希伯来书 8:1"> 既然我们有一位伟大的祭司管理神的家，</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 36:25; 约翰福音 3:5; 以弗所书 5:26"> 既然我们的心被血<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="血——辅助词语。">e</a></sup>洒过，脱离了罪恶感，身体也被清水洗净了，就让我们怀着真诚的心，以确信不移的信仰近前来；</span>
<span className="v" id="v23" data-v="23" data-xref="帖撒罗尼迦前书 5:24; 哥林多前书 1:9; 帖撒罗尼迦后书 3:3"> 让我们毫不动摇地持守所告白的盼望，因为向我们应许的那一位是信实的；</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦前书 5:11; 约翰一书 3:18; 希伯来书 13:1"> 让我们彼此看顾，好激励爱心和美好的工作。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 2:42; 帖撒罗尼迦前书 5:11; 马太福音 18:20"> 你们不要放弃自己的聚会，像某些人所习惯的那样，而要彼此鼓励；你们既然看见那日子<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="日子——指“基督再来的日子”。">f</a></sup>临近，就更应该这样。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="彼得后书 2:20–22; 希伯来书 6:4–6; 约翰福音 9:41"> 要知道，我们领受了真理的知识以后，如果还故意犯罪，就不再有赎罪的祭物被保留下来；</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 26:11; 希伯来书 2:3; 西番雅书 1:18"> 只保留了对审判的可怕等待，和那将要吞灭敌对者的嫉恨之火。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 2:2; 申命记 19:15; 申命记 17:2–13"> 任何拒绝摩西律法的人，凭两个或三个见证人的见证，就得不到怜悯而死，</span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 6:6; 以弗所书 4:30; 以赛亚书 63:10"> 何况一个人践踏了神的儿子，把那使自己成圣的立约之血看做是俗物，又侮辱了恩典的圣灵，你们想想，这个人难道不该受更厉害的惩罚吗？</span>
<span className="v" id="v30" data-v="30" data-xref="申命记 32:35–36; 罗马书 12:19; 那鸿书 1:2"> 因为我们认识曾说过“报应在我，我将回报<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附“——这是主说的”。">g</a></sup>”的那一位，他又说过“主要审判自己的子民。”</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 10:28; 路加福音 12:5; 希伯来书 12:29"> 落在永生神的手中实在可怕。</span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="希伯来书 6:4; 希伯来书 12:4; 提摩太后书 2:3–13"> 你们要回想原先的日子：当你们蒙了光照以后，忍受了许多痛苦挣扎；</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 4:9; 腓立比书 4:14; 希伯来书 11:36"> 有时候当众受责骂、受患难；有时候陪伴那些受到同样遭遇的人。</span>
<span className="v" id="v34" data-v="34" data-xref="彼得前书 1:4; 提摩太后书 1:16; 马太福音 5:11–12"> 的确，你们不但同情了那些被囚禁的人<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="那些被囚禁的人——有古抄本作“被囚禁的我”。">h</a></sup>，而且当自己所拥有的被夺去时，你们也甘心接受了，因为知道你们在天上<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本没有“在天上”。">i</a></sup>有更好的、长存的产业。</span>
<span className="v" id="v35" data-v="35" data-xref="哥林多前书 15:58; 加拉太书 6:8–10; 希伯来书 3:6"> 所以，不要丢弃你们的确信，这确信带来极大的报偿。</span>
<span className="v" id="v36" data-v="36" data-xref="希伯来书 12:1; 诗篇 37:7; 雅各书 5:7–11"> 其实，你们需要忍耐，好在你们行完神的旨意以后，可以领受所应许的。</span>
<span className="v" id="v37" data-v="37" data-xref="雅各书 5:7–9; 哈巴谷书 2:3–4; 路加福音 18:8"> <span className="pl pl-1">要知道，还有一点点时候，</span><br /><span className="pl pl-1">“要来的那一位就要来临，他不会迟延。</span><br /></span>
<span className="v" id="v38" data-v="38" data-xref="加拉太书 3:11; 哈巴谷书 2:4; 罗马书 1:17"> <span className="pl pl-1">我的义人将因信而活；</span><br /><span className="pl pl-1">如果他退缩，</span><br /><span className="pl pl-1">我的心就不喜悦他。”</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="约翰一书 5:5; 彼得前书 1:5; 马可福音 16:16"> 然而，我们不是退缩以致灭亡<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="灭亡——或译作“沉沦”。">j</a></sup>的人，而是有信仰以致保全灵魂<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="灵魂——或译作“生命”。">k</a></sup>的人。</span>
</div>
</div>

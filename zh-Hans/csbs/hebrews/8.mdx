<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 1:3; 歌罗西书 3:1; 启示录 3:21"> 以上所说的要点是：我们有这样的一位大祭司，已经坐在诸天之上至尊者的宝座右边，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 33:7; 哥林多后书 5:1; 希伯来书 9:23–24"> 他是圣所和真会幕的服事者。这会幕是主所搭建的，不是人所搭建的。</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所书 5:2; 希伯来书 5:1; 希伯来书 9:14"> 每一位大祭司受委任，都是为了献上礼物和祭物；故此，这一位也必须有所献上。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 7:11–15; 希伯来书 5:1; 民数记 17:12–13"> 既然如此，如果他在地上，就不会做祭司，因为地上已经有照着律法献祭物的祭司<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本没有“祭司”。">a</a></sup>。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 25:40; 歌罗西书 2:17; 希伯来书 10:1"> 那些祭司所事奉的，是天上事物的模型和影子，就如摩西将要完成会幕的时候，得了神的指示，说：“你要注意，一切都要按照在山上指示你的样式去造。”</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 7:22; 加拉太书 3:16–21; 希伯来书 12:24"> 但如今，耶稣得了更尊贵的服事工作，就像他也是更美好之约的中保那样；这约建立在各样更美好的应许之上。</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="希伯来书 7:11; 加拉太书 3:21; 希伯来书 7:18"> 原来，如果那第一个约<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="约——辅助词语。">b</a></sup>是无可指责的，就没有寻求第二个约的必要了，</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 31:31–34; 希伯来书 10:16–17; 希伯来书 12:24"> 因为神<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="神——原文直译“他”。">c</a></sup>指责说：<br /><span className="pl pl-1">“看哪，时候就要到了！</span><br /><span className="pl pl-1">主说，我要与以色列家</span><br /><span className="pl pl-1">和犹大家订立新约。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 31:32; 加拉太书 4:24; 马可福音 8:23"> <span className="pl pl-1">这约</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="这约——辅助词语。">d</a></sup><br /><span className="pl pl-1">不像从前我拉着他们祖先的手，</span><br /><span className="pl pl-1">在领他们出埃及地的日子里</span><br /><span className="pl pl-1">与他们所立的约。</span><br /><span className="pl pl-1">因为他们没有持守我的约，</span><br /><span className="pl pl-1">我就不理他们——这是主说的。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 36:26–28; 耶利米书 31:33; 以西结书 11:19–20"> <span className="pl pl-1">主又说，在那些日子以后，</span><br /><span className="pl pl-1">我要与以色列家订立这样的约：</span><br /><span className="pl pl-1">我要把我的法则放在他们的意念中，</span><br /><span className="pl pl-1">刻在他们的心上；</span><br /><span className="pl pl-1">我将要做他们的神，</span><br /><span className="pl pl-1">他们将要做我的子民。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 31:34; 以赛亚书 54:13; 约翰福音 6:45"> <span className="pl pl-1">他们绝不需要教导各自的同胞</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="同胞——有古抄本作“邻人”。">e</a></sup><br /><span className="pl pl-1">、各自的兄弟，说：</span><br /><span className="pl pl-1">‘你要认识主’——</span><br /><span className="pl pl-1">因为他们所有的人，</span><br /><span className="pl pl-1">从卑微的到尊贵的，</span><br /><span className="pl pl-1">都将认识我；</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 10:16–17; 以赛亚书 43:25; 罗马书 11:27"> <span className="pl pl-1">又因为我要宽恕他们的不义，</span><br /><span className="pl pl-1">绝不再想起他们的罪孽</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附“和他们的罪恶”。">f</a></sup><br /><span className="pl pl-1">。”</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 5:17; 希伯来书 7:18–19; 希伯来书 7:11–12"> 当神<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="神——原文直译“他”。">g</a></sup>说到“新约<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="约——辅助词语。">h</a></sup>”，就已经把第一个当做旧的；而那渐渐变旧、渐渐变老的，很快就要消逝了。</span>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="JDG" data-book-slug="judges" data-book-name="士师记" data-chapter="6" data-verses="40">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 9:26–29; 士师记 2:19–20; 士师记 2:13–14"> 以色列子民又做耶和华眼中看为恶的事，耶和华就把他们交在米甸人手中七年。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:38; 撒母耳记上 13:6; 申命记 28:47–48"> 米甸人的手制伏了以色列人。以色列子民因米甸人的缘故，就为自己修筑山洞、洞穴和要塞。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 6:33; 士师记 3:13; 士师记 7:12"> 每当以色列人撒种后，米甸人、亚玛力人和东方人就上来攻打他们，</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 26:16; 申命记 28:51; 弥迦书 6:15"> 对着他们扎营，毁掉地里的农作物，直到加沙，不给以色列人留下一点口粮以及牛羊或驴。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 7:12; 士师记 8:10; 耶利米书 46:23"> 因为他们带着牲畜和帐篷上来，像大量的蝗虫涌上来；他们的人和骆驼无法数算。他们进入那地，毁坏它。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 3:9; 耶利米书 5:17; 诗篇 50:15"> 这样，以色列因米甸人的缘故极其窘迫，以色列子民就向耶和华哀求。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 以色列子民因米甸人而向耶和华哀求时，</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 20:5–32; 以赛亚书 63:9–14; 诗篇 136:10–16"> 耶和华就派遣一位先知到以色列子民那里，对他们说：“以色列的神耶和华如此说：是我把你们从埃及带上来，从为奴之家领出来。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 44:2–3"> 我解救你们脱离埃及人的手，脱离一切压迫你们之人的手，并且把他们从你们面前驱逐出去，把他们的土地赐给了你们。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 10:2; 列王纪下 17:35–39; 耶利米书 9:13"> 我对你们说：‘我是耶和华你们的神，你们不可敬畏<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="敬畏——或译作“敬拜”。">a</a></sup>你们所住之地亚摩利人的神明。’你们却不听从我的话。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约书亚记 17:2; 希伯来书 11:32; 士师记 13:3"> 耶和华的使者前来，坐在俄弗拉的一棵橡树底下，那是亚比以谢人约阿施的橡树。当时约阿施的儿子基甸正在榨酒池里打小麦，为要躲避米甸人。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 1:5; 路加福音 1:28; 士师记 2:18"> 耶和华的使者向基甸显现，对他说：“大能的勇士啊，耶和华与你同在！”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="诗篇 77:7–9; 历代志下 15:2; 以赛亚书 59:1–2"> 基甸对他说：“哦，我主啊，如果耶和华与我们同在，我们为什么还遭遇这一切呢？我们祖先向我们所讲述的他一切奇妙作为在哪里呢？他们说：‘耶和华不是把我们从埃及带上来了吗？’但如今耶和华已经撇弃了我们，把我们交在米甸人手中了！”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="约书亚记 1:5–9; 希伯来书 11:34; 撒母耳记上 12:11"> 耶和华转向基甸，说：“靠着你这力量去吧，拯救以色列脱离米甸人的手。我不是派遣了你吗？”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 9:21; 出埃及记 3:11; 出埃及记 4:10"> 基甸对他说：“哦，我主啊，我凭什么拯救以色列呢？看哪，我的宗族在玛拿西中是最贫弱的，我在我父家又是最小的。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约书亚记 1:5; 出埃及记 3:12; 使徒行传 11:21"> 耶和华对他说：“我必与你同在，你将击败米甸，如同击败一人。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="诗篇 86:17; 出埃及记 33:13; 以赛亚书 7:11"> 基甸又对他说：“如果我在你眼前蒙恩，求你给我一个征兆，证明是你在与我说话。</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 13:15; 创世记 18:3; 创世记 18:5"> 请不要离开这里，等我回来，把供物带来摆在你面前。”<br />耶和华说：“我会留在这里，等你回来。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="创世记 18:6–8; 士师记 13:15–19; 利未记 2:4"> 基甸就去预备了一只小山羊，用一斗<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一斗——原文作“一伊法”。1伊法=22公升。">b</a></sup>面粉做了无酵饼，把肉放在篮子里，把汤盛在小锅里，带到橡树下耶和华的使者那里献上。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="士师记 13:19; 列王纪上 18:33–34"> 神的使者对基甸说：“把肉和无酵饼拿来，放在这磐石上，把汤倒出来。”他就如此做了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="利未记 9:24; 列王纪上 18:38; 历代志下 7:1"> 耶和华的使者伸出手中的杖，杖头一碰到肉和无酵饼，就有火从磐石中出来，吞噬了肉和无酵饼。随后耶和华的使者从他眼前消失了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="创世记 32:30; 出埃及记 33:20; 申命记 5:26"> 于是，基甸看出他是耶和华的使者。基甸说：“唉，主耶和华啊！我竟然面对面看见了耶和华的使者。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="但以理书 10:19; 约翰福音 20:26; 创世记 43:23"> 耶和华对他说：“愿你平安！不要害怕，你不会死。”</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 22:14; 出埃及记 17:15; 士师记 8:32"> 于是基甸在那里为耶和华筑了一座祭坛，称它为“耶和华沙龙”。这祭坛至今还在亚比以谢人的俄弗拉。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及记 34:13; 士师记 3:7; 使徒行传 5:29"> 当天夜里，耶和华对基甸说：“把你父亲的公牛，就是那第二头七岁的公牛牵来；并且拆毁你父亲的巴力祭坛，砍倒祭坛旁的亚舍拉柱。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多前书 14:40; 撒母耳记下 24:18; 哥林多前书 14:33"> 然后在这堡垒顶上，为你的神耶和华筑一座规整的祭坛，把那第二头公牛牵来，用你砍倒的亚舍拉柱作木柴把它献为燔祭。”</span>
<span className="v" id="v27" data-v="27" data-xref="帖撒罗尼迦前书 2:4; 约翰福音 2:5; 申命记 4:1"> 基甸就从他的仆人中选出十个人，照着耶和华吩咐他的去做。但他因为怕他的父家和那城的人，不敢在白天做，就在夜间做了。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 那城的人清早起来，看哪，巴力的祭坛被拆毁，旁边的亚舍拉柱被砍倒，新筑的祭坛上祭献了那第二头公牛。</span>
<span className="v" id="v29" data-v="29"> 他们彼此问：“这是谁做的呢？”他们调查寻问之后，说：“这是约阿施的儿子基甸做的。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行传 26:9; 腓立比书 3:6; 耶利米书 50:38"> 于是那城的人对约阿施说：“把你儿子交出来！他必须死，因为他拆毁了巴力的祭坛，砍倒了祭坛旁的亚舍拉柱。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="耶利米书 10:11; 哥林多前书 8:4; 以弗所书 5:11"> 约阿施对所有起来攻击他的人说：“你们是为巴力辩护吗？你们要救助它吗？谁为它辩护，谁就要在清晨被处死。如果巴力是神，既然有人拆毁了它的祭坛，就让它为自己辩护吧！”</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 12:11; 士师记 7:1; 撒母耳记下 11:21"> 当天约阿施称基甸为耶路巴力，意思说“让巴力与他相争”，因为他拆毁了巴力的祭坛。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约书亚记 17:16; 士师记 6:3; 罗马书 8:35–39"> 那时，所有的米甸人、亚玛力人和东方人聚集在一起，过了约旦河，在耶斯列平原扎营。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="士师记 3:27; 历代志下 24:20; 士师记 3:10"> 耶和华的灵临到基甸身上<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="临到……身上——或译作“覆盖”。">c</a></sup>，于是他吹响号角，亚比以谢人就被召集起来跟随他。</span>
<span className="v" id="v35" data-v="35" data-xref="历代志下 30:6–12; 士师记 4:6"> 他派遣使者到玛拿西全地，玛拿西人也被召集起来跟随他；又派遣使者到亚设、西布伦和拿弗他利，那里的人也上来与他们会合。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="士师记 6:14; 马太福音 16:1; 士师记 6:17–20"> 于是基甸对神说：“如果你要照你所说的，藉着我的手拯救以色列，</span>
<span className="v" id="v37" data-v="37" data-xref="何西阿书 14:5; 马太福音 10:5–6; 马太福音 15:24"> 看哪，我把一团羊毛放在打谷场上，如果唯独羊毛上有露水，而地上都是干的，那么我就知道，你要照你所说的，藉着我的手拯救以色列了。”</span>
<span className="v" id="v38" data-v="38" data-xref="以赛亚书 35:7"> 事情果然如此，基甸第二天早早起来，拧那羊毛，竟从羊毛里挤出露水来，满满一碗。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="创世记 18:32; 以赛亚书 50:2; 诗篇 107:33–35"> 基甸又对神说：“求你不要对我发怒，容我再说这一次：请让我用羊毛再试验一次，这次唯愿羊毛是干的，而地上全是露水。”</span>
<span className="v" id="v40" data-v="40"> 当天夜里，神也如此成就了：唯独羊毛上是干的，而地上全是露水。</span>
</div>
</div>

</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="JDG" data-book-slug="judges" data-book-name="士师记" data-chapter="8" data-verses="35">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 19:41; 士师记 12:1–6; 约伯记 5:2"> 那时，以法莲人对基甸说：“你去攻打米甸人，竟然不召唤我们！你怎么这样对待我们呢？”他们与基甸激烈地争论。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 13:4–7; 腓立比书 2:2–3; 雅各书 3:13–18"> 基甸就对他们说：“我现在所做的，怎么能与你们相比呢？以法莲遗落的葡萄，不是比亚比以谢采收的葡萄更好吗？</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 15:1; 士师记 7:24–25; 约翰福音 4:37"> 神已经把米甸首领俄立和西伊伯交在你们手中了，我能做什么与你们相比呢？”基甸说了这话，以法莲人的怒气就平息了。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="加拉太书 6:9; 哥林多后书 4:16; 撒母耳记上 14:28–29"> 基甸来到约旦河，他和跟随他的三百人过了河，虽然疲乏，仍继续追赶。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 33:17; 诗篇 60:6; 撒母耳记上 25:18"> 基甸对疏割人说：“请拿几块饼给这些跟随我的人吃吧，因为他们疲乏了，我正在追赶米甸王西巴和撒慕拿。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王纪上 20:11; 腓立比书 2:21; 箴言 18:23"> 疏割的首领们回答：“西巴和撒慕拿已经在你手中了吗？居然要我们送饼给你的队伍！”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="士师记 7:15"> 基甸就宣告：“那好！耶和华把西巴和撒慕拿交在我手中的时候，我必用旷野的荆棘和蒺藜抽打你们的身体。”</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 32:30–31; 列王纪上 12:25"> 然后，基甸从那里上到毗努伊勒，对那里的人说同样的话，但毗努伊勒人回应他像疏割人的回应一样。</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 8:17; 列王纪上 22:27–28"> 基甸也向毗努伊勒人宣告说：“我平安回来的时候，必拆毁这座塔楼。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="士师记 7:12; 士师记 20:25; 士师记 20:2"> 那时西巴和撒慕拿在卡克尔，跟随他们的军兵约有一万五千人，是东方人剩下的全部军兵，他们已经有十二万拿刀剑的人倒下了。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 32:35; 民数记 32:42; 士师记 18:27"> 基甸从挪巴和约比哈东面，沿着住帐篷之人的道路上去，在敌营毫无戒备的时候，攻打那营地。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 83:11; 阿摩司书 2:14; 约伯记 12:16–21"> 西巴和撒慕拿就逃跑。基甸追赶他们，捉住了米甸的两个王西巴和撒慕拿，使全军溃乱。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 约阿施的儿子基甸沿着希列斯山坡从战场回来，</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 1:24–25; 撒母耳记上 30:11–15"> 捉住疏割的一个年轻人，讯问他。年轻人给他写下了疏割的首领和长老的名字，共七十七人。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 8:6–7"> 于是，基甸来到疏割人那里，说：“你们曾经羞辱我说：‘西巴和撒慕拿已经在你手中了吗？居然要我们送饼给你那些疲乏的人。’看哪，这就是西巴和撒慕拿！”</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 8:7; 以斯拉记 2:6; 箴言 10:13"> 于是他捉住那城的长老们，并拿来旷野的荆棘和蒺藜，用它们教训了疏割人。</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 8:9; 列王纪上 12:25"> 他又拆毁了毗努伊勒的塔楼，杀了城里的人。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="士师记 4:6; 犹大书 1:16; 诗篇 89:12"> 基甸问西巴和撒慕拿：“你们在他泊山所杀的，是怎样的人？”他们回答：“都像你，个个都像王子的模样。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 基甸说：“他们是我的兄弟，我母亲的儿子。我指着耶和华的永生起誓：要是你们让他们存活，我就不杀你们了。”</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 149:9; 撒母耳记上 15:33; 约书亚记 10:24"> 于是基甸对长子耶特尔说：“起来，把他们杀了！”但那年轻人没有拔出刀来，因为他害怕，他还年轻。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="诗篇 83:11; 士师记 8:26; 以赛亚书 3:18"> 西巴和撒慕拿说：“你自己起来杀我们吧，大丈夫才有力量<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="大丈夫才有力量——或译作“人怎样，力量也怎样”。">a</a></sup>。”基甸就起来，杀了西巴和撒慕拿，并夺去他们骆驼脖子上的月牙圈。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约翰福音 6:15; 士师记 9:8–15; 撒母耳记上 12:12"> 那时，以色列人对基甸说：“你既然救我们脱离米甸人的手，你和你的子子孙孙也管辖我们吧。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 33:22; 撒母耳记上 12:12; 撒母耳记上 10:19"> 但基甸对他们说：“我不管辖你们，我的儿子也不管辖你们；耶和华会管辖你们。”</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 25:13; 创世记 37:25; 创世记 37:28"> 基甸又对他们说：“我有一件事求你们，请你们各人把夺来的耳环给我一个。”原来敌军是以实玛利人，都戴金耳环。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 他们说：“我们乐意给你。”于是他们铺开外衣，各人把夺来的耳环扔在上面。</span>
<span className="v" id="v26" data-v="26" data-xref="启示录 18:16; 约翰福音 19:2; 启示录 18:12"> 基甸要来的金耳环，其金子的重量是一千七百谢克尔<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一千七百谢克尔——相当于19.4公斤。1谢克尔=11.4公克。">b</a></sup>；此外，还有米甸王身上的月牙圈、耳坠和紫色衣服，以及骆驼脖子上的项圈。</span>
<span className="v" id="v27" data-v="27" data-xref="士师记 17:5; 士师记 18:14; 诗篇 106:39"> 基甸用这些制作了一个以弗得，放在本城俄弗拉。全以色列都在那里行淫追随这以弗得，这成了基甸和他家的陷阱。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="士师记 5:31; 士师记 3:11; 士师记 3:30"> 这样，米甸人在以色列人面前被制伏，再也不能抬头。在基甸的年日，国中太平四十年。</span>
<span className="v" id="v29" data-v="29" data-xref="士师记 6:32; 士师记 7:1; 撒母耳记上 12:11"> 约阿施的儿子耶路巴力回去，住在自己家里。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="士师记 9:5; 士师记 9:2; 列王纪上 11:3"> 基甸有七十个儿子，都是他亲生的，因为他有许多妻子。</span>
<span className="v" id="v31" data-v="31" data-xref="士师记 9:18; 创世记 22:24; 创世记 16:15"> 他在示剑的妾也为他生了一个儿子，基甸给这儿子取名为亚比米勒。</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 25:8; 士师记 6:24; 约伯记 5:26"> 约阿施的儿子基甸尽享天年而死，葬在亚比以谢族的俄弗拉，在他父亲约阿施的坟墓里。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="士师记 9:46; 士师记 2:19; 士师记 9:4"> 基甸死后，以色列子民又转去行淫追随巴力，奉巴力比利土为他们的神。</span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 78:42; 诗篇 106:21; 诗篇 78:11"> 以色列子民不记念耶和华他们的神，就是解救他们脱离四围一切仇敌之手的那一位；</span>
<span className="v" id="v35" data-v="35" data-xref="传道书 9:14–15; 士师记 9:5; 士师记 9:16–19"> 也不照着耶路巴力——基甸向以色列所施的一切恩惠，以恩慈对待他的家。</span>
</div>
</div>

</div>

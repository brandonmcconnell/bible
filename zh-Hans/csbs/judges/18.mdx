<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 17:6; 士师记 19:1; 士师记 1:34"> 在那些日子，以色列没有王；那时但支派还在为自己寻找可安居的继业之地，因为直到那时，他们还没有在以色列众支派当中分得继业。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 13:25; 约书亚记 2:1; 士师记 18:11"> 但支派的人从他们家族各群体中，从佐拉和以实陶派遣了五个人，都是勇士，要去窥视探查那地。他们吩咐这五人：“你们去探查那地。”<br />这些人来到以法莲山地，到了米迦的家，就在那里过夜。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 12:6; 创世记 27:22; 马太福音 26:73"> 当时他们靠近米迦的家，认出那年轻利未人的声音，就进到里面去。他们问他：“谁带你到这里来的？你在这里做什么？你在这里得了什么？”</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 17:10; 以西结书 13:19; 箴言 28:21"> 他就告诉他们米迦如此如此对待自己，说：“他雇用了我，我作他的祭司。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 8:10; 以赛亚书 30:1; 列王纪上 22:5"> 他们对他说：“请你求问神，好让我们知道我们的行程是否会顺利。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王纪上 22:6; 列王纪上 22:15; 诗篇 33:18"> 这祭司对他们说：“平安地去吧，耶和华必看顾你们的行程<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="耶和华必看顾你们的行程——原文直译“你们行走的路必在耶和华面前”。">a</a></sup>。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约书亚记 19:47; 士师记 18:27–28; 撒母耳记上 3:13"> 五人继续前行，来到拉伊，看见住在拉伊的人像西顿人那样安然居住，平静安稳。他们在那地没有人辖制欺负他们<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="没有人辖制欺负他们——或译作“一无所缺，物产丰富”。">b</a></sup>。他们离西顿人很远，与其他人也没有往来。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="士师记 18:11; 士师记 18:2; 士师记 13:2"> 五人回到佐拉和以实陶他们的兄弟们那里，兄弟们问他们：“情况怎样呢？”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约书亚记 2:23–24; 民数记 13:30; 约书亚记 18:3"> 他们说：“起来，我们上去攻打那些人吧。我们察看了那地，发现那里实在美好。你们还静默吗？不要犹豫，去吧，进去占领那地！</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 18:27; 士师记 18:7; 申命记 2:29"> 当你们进去，会来到安稳的民那里，边界宽广的土地上。神已经把它交在你们手中了，那里不缺地上的任何物产。”</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 18:16"> 于是但家族中，佐拉和以实陶有六百人佩带兵器，从那里出发了。</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 13:25; 约书亚记 15:60; 历代志下 1:4"> 他们上去，在犹大的基列-耶琳扎营。因此那地方被称为玛哈尼但<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="玛哈尼但——或译作“但的营地”。">c</a></sup>，直到今日；看哪，就在基列-耶琳的西边。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 24:30; 士师记 19:1; 士师记 18:2–3"> 他们从那里过去，到以法莲山地，来到米迦的家。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="士师记 17:5; 士师记 18:3–4; 撒母耳记上 14:28"> 先前窥探拉伊地的那五个人告诉兄弟们，说：“你们知道吗，这家有以弗得、家族神像、雕像和铸像。现在你们应当知道该做什么了。”</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 43:27; 撒母耳记上 17:22; 约翰福音 14:27"> 他们就转往那里去，来到米迦的家那年轻利未人的住处，向他问安。</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 18:11"> 但支派的那六百人，都佩带兵器站在大门口。</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 18:14; 士师记 17:4–5; 士师记 18:2"> 先前窥探那地的五个人上前去，进到里面拿走了雕像、以弗得、家族神像和铸像。祭司和那些佩带兵器的六百人，都站在大门口。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 五人进入米迦的家里拿走雕像、以弗得、家族神像和铸像时，祭司问他们：“你们在做什么？”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约伯记 29:9; 约伯记 21:5; 士师记 17:10"> 他们对他说：“捂住你的嘴，不要作声。跟我们一起走吧，作我们的父、我们的祭司。你是作一人一家的祭司好呢，还是作以色列一个支派、一个家族的祭司好呢？”</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 56:11; 以西结书 13:19; 箴言 30:15"> 这祭司心里高兴，就拿着以弗得、家族神像和雕像，加入了这些民众。</span>
<span className="v" id="v21" data-v="21"> 他们转身离去，安排家属、牲畜和贵重物品走在队伍的前面。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 他们从米迦的家走远后，米迦的家附近的邻居被召集起来，追上了但支派的人。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 114:5; 撒母耳记下 14:5; 撒母耳记上 11:5"> 他们呼叫但支派的人，那些人转身对米迦说：“你召集人要做什么？”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哈巴谷书 2:18–19; 以赛亚书 44:18–20; 诗篇 115:8"> 米迦说：“你们拿走了我造的神像，带走了我的祭司，我还剩什么呢？你们怎么还问我‘你要做什么’？”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约伯记 27:2; 约伯记 3:5; 撒母耳记上 30:6"> 但支派的人对米迦说：“不要再让我们听见你的声音，恐怕有暴躁的人攻击你们，你和你的全家就丧命了！”</span>
<span className="v" id="v26" data-v="26"> 于是但支派的人继续赶路；米迦见他们比自己强大，就转身回家去了。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约书亚记 19:47; 士师记 18:7; 士师记 18:10"> 他们带着米迦制造的神像和米迦的祭司，来到拉伊，到了平静安稳的民那里。他们用刀击杀那里的人，放火烧毁了那城。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 10:6; 士师记 18:7; 民数记 13:21"> 没有人解救那城，因为它离西顿很远，他们又与其他人没有来往。这城在平原中靠近伯利合，但支派的人重建了这座城，住在其中。</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 19:47; 创世记 14:14; 列王纪上 15:20"> 他们以自己的祖先、以色列所生之子但的名字，给这城起名为但；拉伊是这城原先的名字。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 4:10–11; 士师记 13:1; 士师记 17:5"> 但支派的人把那雕像为自己竖立起来；摩西<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="摩西——依据七十士译本；马索拉文本作“玛拿西”。">d</a></sup>的孙子、革顺的儿子约拿单作祭司，他和他的子孙作但支派的祭司直到那地被掳之日。</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 18:1; 撒母耳记上 1:3; 士师记 19:18"> 神的居所在示罗的日子里，但支派的人一直为自己竖立着米迦所造的雕像。</span>
</div>
</div>

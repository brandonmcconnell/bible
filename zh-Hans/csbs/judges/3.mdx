<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 2:21–22; 申命记 7:22; 箴言 17:3"> 以下是耶和华留下的那些民族，为要藉着他们试验所有未曾经历过迦南任何战事的以色列人，</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 3:5; 创世记 3:7; 哥林多前书 9:26–27"> 特意让以色列的子孙后代，特意让以前没有经历过的人去经历战事，教导他们作战。</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 13:3; 约书亚记 13:5; 士师记 10:7"> 所留下的有：非利士的五个首领；所有的迦南人；西顿人；从巴力黑门山直到哈马隘口住在黎巴嫩山地的希未人。</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 3:1; 士师记 2:22; 出埃及记 15:25"> 这是为要藉着他们试验以色列人，要知道他们是否会听从耶和华藉着摩西所指示他们祖先的诫命。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 106:34–38; 创世记 10:15–18; 出埃及记 3:8"> 然而，以色列子民住在迦南人、赫提人、亚摩利人、比利洗人、希未人和耶布斯人中间，</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 7:3–4; 出埃及记 34:16; 列王纪上 11:1–5"> 娶他们的女儿为妻，又把自己的女儿嫁给他们的儿子，并且服事他们的神明。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 34:13; 列王纪下 23:6; 列王纪上 18:19"> 以色列子民做耶和华眼中看为恶的事，忘记了耶和华他们的神，而服事巴力和亚舍拉。</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 2:14; 哈巴谷书 3:7; 士师记 4:9"> 于是耶和华对以色列发怒，把他们交于<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="交于——原文直译“卖到”。">a</a></sup>美索不达米亚<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="美索不达米亚——原文直译“两河之间的亚兰”。">b</a></sup>王古珊·利萨田手中。以色列子民服事了古珊·利萨田八年。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="士师记 3:15; 士师记 1:13; 诗篇 22:5"> 以色列子民向耶和华哀求，耶和华就为以色列子民兴起一位拯救者来救他们，就是迦勒的弟弟、基纳斯的儿子俄陀聂。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 13:25; 撒母耳记上 11:6; 士师记 14:19"> 耶和华的灵临到俄陀聂身上，他就作了以色列的士师。他出去作战，耶和华把亚兰王古珊·利萨田交在他手中，他的手就制伏了古珊·利萨田。</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 5:31; 士师记 8:28; 约书亚记 11:23"> 于是国中太平了四十年，后来基纳斯的儿子俄陀聂死了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 12:9; 士师记 2:19; 士师记 2:14"> 以色列子民又做耶和华眼中看为恶的事。于是耶和华使摩押王伊矶伦强盛，压制以色列，因为他们做了耶和华眼中看为恶的事。</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 1:16; 申命记 34:3; 士师记 5:14"> 伊矶伦把亚扪人和亚玛力人招聚到他那里，来攻打以色列，占据了棕榈城。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 28:47–48; 申命记 28:40; 利未记 26:23–25"> 以色列子民服事了摩押王伊矶伦十八年。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士师记 3:9; 诗篇 78:34; 以赛亚书 36:16"> 以色列子民向耶和华哀求，耶和华就为他们兴起一位拯救者，便雅悯人基拉的儿子以胡德，他是一个惯用左手的人。那时，以色列子民委托他呈送贡物给摩押王伊矶伦。</span>
<span className="v" id="v16" data-v="16" data-xref="雅歌 3:8; 启示录 2:12; 诗篇 149:6"> 以胡德为自己打造了一把一肘<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一肘——相当于45.7公分。">c</a></sup>长的双刃刀，绑在右大腿上衣袍里面。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 34:20; 约伯记 15:27; 耶利米书 50:11"> 他把贡物献给摩押王伊矶伦，伊矶伦是一个很肥胖的人。</span>
<span className="v" id="v18" data-v="18"> 以胡德献完贡物以后，把抬贡物的人打发走了，</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 4:20; 士师记 3:20; 使徒行传 23:18–19"> 他自己却从吉甲附近的雕像群那里返回，说：“王啊，我有机密的事要向你禀报。”王说：“先不要开口<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="先不要开口——原文直译“安静”。">d</a></sup>！”他旁边侍立的人都退了出去，</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 10:7; 阿摩司书 3:15; 诗篇 29:1"> 以胡德来到王那里，王正独自坐在凉爽的阁楼里。以胡德说：“我有神的话要向你禀报。”王就从宝座上起身。</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亚书 13:3; 约伯记 20:25; 撒母耳记上 15:33"> 以胡德伸出左手，从右腿上拔出刀来，刺进王的肚子，</span>
<span className="v" id="v22" data-v="22"> 连刀柄也随着刀锋刺了进去；肥肉裹住了刀锋，因此以胡德没有把刀从王的肚子里拔出；王的粪便都流了出来。</span>
<span className="v" id="v23" data-v="23"> 以胡德出来到走廊上，他把阁楼的门从里面关上，锁住了。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒母耳记上 24:3"> 以胡德出去之后，王的臣仆们来了，他们观看，发现阁楼的门锁住了，就想：“王一定是在凉爽的里间解手。”</span>
<span className="v" id="v25" data-v="25"> 他们一直等候，直到觉得尴尬，但王还是没有打开阁楼的门。他们就拿钥匙开门，看哪，主人已经倒在地上死了。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 在他们耽延的时候，以胡德已经逃离了。他经过雕像群那里，逃往西伊拉。</span>
<span className="v" id="v27" data-v="27" data-xref="士师记 6:34; 撒母耳记上 13:3; 士师记 5:14"> 到了那里，他就在以法莲山地吹响号角。以色列人与他一同下山，他在他们前面。</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 12:5; 士师记 7:9; 士师记 7:15"> 以胡德对他们说：“你们紧跟着我，耶和华已经把你们的仇敌摩押人交在你们手中了！”他们随着他下去，占据通往摩押的约旦河渡口，不允许一人过去。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 32:15; 士师记 3:17; 诗篇 17:10"> 那时，他们击杀了大约一万摩押人，都是强壮的勇士，没有一人逃脱。</span>
<span className="v" id="v30" data-v="30" data-xref="士师记 3:11; 士师记 5:31"> 那一天，摩押被制伏在以色列手下，于是国中太平了八十年。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="士师记 5:6; 哥林多前书 1:17; 撒母耳记上 17:50"> 以胡德之后，有亚拿的儿子沙姆伽尔兴起，他用赶牛棒击杀了六百个非利士人，他也拯救了以色列。</span>
</div>
</div>

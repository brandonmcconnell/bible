<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 5:3; 士师记 3:12; 士师记 3:7"> 以胡德死后，以色列子民又做耶和华眼中看为恶的事。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 11:1; 士师记 4:16; 士师记 4:13"> 于是耶和华把他们交于<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="交于——原文直译“卖到”。">a</a></sup>迦南王耶宾手中；耶宾在哈佐作王，他的元帅是西西拉，住在哈罗谢-哈格因。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 1:19; 诗篇 106:42; 士师记 3:9"> 那时，以色列子民呼求耶和华，因为耶宾有九百辆铁战车，他残暴压迫以色列子民二十年。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及记 15:20; 路加福音 2:36; 列王纪下 22:14"> 那时，女先知底波拉作以色列的士师，她是拉比多的妻子。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 18:19; 耶利米书 31:15; 出埃及记 18:26"> 她常坐在以法莲山地拉玛和伯特利之间的底波拉棕榈树下，以色列子民都上她那里去寻求判断。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 13:47; 士师记 8:18; 希伯来书 11:32"> 底波拉派人从拿弗他利的基低斯把亚比挪安的儿子巴拉克召来，对他说：“以色列的神耶和华已经吩咐说：你去，带领拿弗他利人和西布伦人一万人，前往他泊山。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 18:40; 以西结书 38:10–16; 诗篇 83:9–10"> 我会把耶宾的元帅西西拉和他的战车、大军引领到基顺河，到你那里；我必把他交在你手中。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 4:10–14; 马太福音 14:30–31"> 巴拉克对她说：“如果你与我同去，我就去；如果你不与我同去，我就不去。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="士师记 2:14; 撒母耳记上 2:30; 士师记 4:17–22"> 底波拉说：“我一定与你同去，不过你这次的行程将得不到荣耀，因为耶和华要把西西拉交于<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="交于——原文直译“卖到”。">b</a></sup>一个妇女手中。”底波拉就起来，与巴拉克一同前往基低斯。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 5:18; 士师记 5:15; 士师记 4:14"> 巴拉克召集西布伦人和拿弗他利人到基低斯，有一万人跟随他上去，底波拉也与他一同上去。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="士师记 1:16; 约书亚记 19:33; 民数记 10:29"> 那时，基尼人希伯离开了摩西内兄<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="内兄——或译作“岳父”或“姻亲”；参《民数记》10:29。">c</a></sup>何巴的子孙基尼族人，在基低斯附近的撒拿音橡树那里支搭帐篷。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="诗篇 89:12; 耶利米书 46:18; 约书亚记 19:12"> 有人告诉西西拉，亚比挪安的儿子巴拉克上了他泊山。</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 4:2–3; 士师记 4:7"> 西西拉就召聚他所有的战车，共九百辆铁战车，还有与他一起的所有军兵，从哈罗谢-哈格因来到基顺河。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 9:3; 撒母耳记下 5:24; 以赛亚书 52:12"> 底波拉对巴拉克说：“起来！今天就是耶和华把西西拉交在你手中的日子。耶和华不是已经在你前面出战了吗？”巴拉克就和跟随他的一万人下了他泊山。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约书亚记 10:10; 诗篇 83:9–10; 士师记 5:20–21"> 耶和华用刀剑使西西拉和所有的战车、军兵在巴拉克面前溃乱。西西拉下了战车，徒步逃走。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 2:12; 利未记 26:7–8; 雅各书 2:13"> 巴拉克追赶战车和军兵，直到哈罗谢-哈格因。西西拉的全军倒在刀刃之下，一个也没有剩下。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="诗篇 69:22; 以赛亚书 57:21; 阿摩司书 5:19–20"> 西西拉徒步逃走，到了基尼人希伯的妻子雅亿的帐篷那里，因为哈佐王耶宾和基尼人希伯一家和睦相处。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 6:19"> 雅亿出去迎接西西拉，对他说：“请我主过来，到我这里来，不要害怕。”西西拉就到她那里，进了她的帐篷。雅亿用毯子盖住他。</span>
<span className="v" id="v19" data-v="19" data-xref="士师记 5:25–26; 创世记 24:43; 以赛亚书 41:17"> 西西拉对她说：“我口渴了，请给我一点水喝。”雅亿打开皮囊，给他奶喝，又盖住他。</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 2:3–5; 撒母耳记下 17:20"> 西西拉对雅亿说：“你站在帐篷入口，如果有人来问你说这里有没有人，你就说没有。”</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 5:26–27; 哥林多前书 1:27; 士师记 3:21"> 西西拉疲乏了，就沉沉入睡，这时希伯的妻子雅亿取了一个帐篷橛子，手中拿着铁锤，悄悄来到西西拉身旁，把橛子钉进他的鬓角，穿透到地里。西西拉就死了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 17:10–15; 撒母耳记下 17:3"> 这时，巴拉克追赶西西拉，雅亿出去迎接他，对他说：“来，我给你看你正在找的人。”巴拉克进去，看见西西拉倒在那里死了，橛子还在他的鬓角里。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="尼希米记 9:24; 诗篇 18:47; 诗篇 18:39"> 这一天，神在以色列子民面前制伏了迦南王耶宾。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记上 3:12"> 以色列人的手对迦南王耶宾越来越强硬，最终把迦南王耶宾剪除了。</span>
</div>
</div>

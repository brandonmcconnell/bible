<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 8:31; 诗篇 83:2–4; 撒母耳记下 15:6"> 耶路巴力的儿子亚比米勒到示剑去见他的舅舅们，与他们和他外祖父的全家商议，说：</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 29:14; 士师记 8:30; 希伯来书 2:14"> “请问问所有的示剑人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="示剑人——原文直译“示剑的主人”；本章下同。">a</a></sup>：‘你们觉得哪一样好：让耶路巴力的儿子七十人都管辖你们，还是让一个人管辖你们？’你们要记得，我是你们的骨肉之亲。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 29:15; 诗篇 10:3; 箴言 1:11–14"> 他的舅舅们把他这些话都说给所有的示剑人听，他们的心就倾向亚比米勒，因为他们想：“亚比米勒是我们的兄弟。”</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 8:33; 使徒行传 17:5; 历代志下 13:7"> 他们从巴力比利土的庙宇拿出七十锭银子给了亚比米勒，亚比米勒用这些银子雇用了一些无赖和流氓，他们就跟随他。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 11:1–2; 历代志下 21:4; 士师记 6:24"> 然后他来到俄弗拉，到他的父家，在一块磐石上把自己的兄弟，就是耶路巴力的七十个儿子都杀了，只剩下耶路巴力最小的儿子约坦，因为他躲藏了。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 5:9; 列王纪上 12:20; 列王纪下 12:20"> 所有的示剑人和所有的伯米罗人聚集起来，到示剑的橡树神柱旁，立亚比米勒为王。</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="申命记 11:29; 约翰福音 4:20; 申命记 27:12"> 有人告诉了约坦，他就去站在基利心山顶上，放声呼喊，对他们说：<br /><span className="pl pl-1">“示剑的主人哪，你们听我说，</span><br /><span className="pl pl-1">愿神也垂听你们！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="士师记 8:22–23; 但以理书 4:10–18; 列王纪下 14:9"> <span className="pl pl-1">有一天，树木们执意要去膏立一个王统治他们。</span><br /><span className="pl pl-1">他们对橄榄树说：‘你作王统治我们吧。’</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="利未记 2:1; 出埃及记 29:7; 使徒行传 4:27"> <span className="pl pl-1">但橄榄树回答他们：</span><br /><span className="pl pl-1">‘难道我要停止出产那让神和人得尊荣的油，</span><br /><span className="pl pl-1">而去飘摇在众树之上吗？’</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10"> <span className="pl pl-1">树木们又对无花果树说：</span><br /><span className="pl pl-1">‘你来作王统治我们吧。’</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 13:6–7"> <span className="pl pl-1">但无花果树回答他们：</span><br /><span className="pl pl-1">‘难道我要停止出产甜美的果实，</span><br /><span className="pl pl-1">而去飘摇在众树之上吗？’</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12"> <span className="pl pl-1">树木们又对葡萄树说：</span><br /><span className="pl pl-1">‘你来作王统治我们吧。’</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 104:15; 传道书 10:19; 民数记 15:5"> <span className="pl pl-1">但葡萄树回答他们：</span><br /><span className="pl pl-1">‘难道我要停止出产让神和人喜乐的新酒，</span><br /><span className="pl pl-1">而去飘摇在众树之上吗？’</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="列王纪下 14:9"> <span className="pl pl-1">于是所有的树木对荆棘说：</span><br /><span className="pl pl-1">‘你来作王统治我们吧。’</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 30:2; 士师记 9:20; 何西阿书 14:7"> <span className="pl pl-1">荆棘回答树木们：</span><br /><span className="pl pl-1">‘你们如果真诚地膏立我作王统治你们，</span><br /><span className="pl pl-1">就来投靠在我的影子下吧！</span><br /><span className="pl pl-1">否则，就愿火从荆棘里出来，</span><br /><span className="pl pl-1">吞噬黎巴嫩的香柏树。’</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="士师记 8:35"> “现在，如果你们立亚比米勒为王是真诚无伪地行事，如果你们是善待耶路巴力和他的家，如果你们是照着他应得的对待他——</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 16:4; 罗马书 5:8; 启示录 12:11"> 要知道，从前我父亲为你们争战，舍命不顾，解救你们脱离了米甸人的手，</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 9:5–6; 士师记 8:30–31; 士师记 9:14"> 今天你们却起来攻击我父亲的家，在一块磐石上杀死了他的七十个儿子，而立他婢女之子亚比米勒为示剑人的王，因‘他是你们的兄弟’——</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 8:6; 雅各书 4:16; 腓立比书 3:3"> 今天如果你们是真诚无伪地对待耶路巴力和他的家，你们就因亚比米勒而欢喜吧，也愿他因你们而欢喜。</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 9:15; 士师记 9:56–57; 历代志下 20:22–23"> 否则，就愿火从亚比米勒发出，吞噬示剑人和伯米罗人；也愿火从示剑人和伯米罗人发出，吞噬亚比米勒！”</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 21:16; 撒母耳记下 20:14; 约书亚记 19:8"> 随后约坦就逃跑，逃到了比尔，住在那里，躲避他的兄弟亚比米勒。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 亚比米勒统管治理以色列三年。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 33:1; 以赛亚书 19:14; 以赛亚书 19:2"> 那时，神使搅扰之灵来到亚比米勒和示剑人之间，示剑人就背弃了亚比米勒。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 2:32; 诗篇 7:16; 以斯帖记 9:25"> 这是为要耶路巴力七十个儿子被害的报应临到，使他们的血债归在那杀害他们的人——他们的兄弟亚比米勒身上，也归到那些帮助亚比米勒去杀害自己兄弟的示剑人身上。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 8:12–13; 箴言 1:11–12; 约书亚记 8:4"> 示剑人在山顶对亚比米勒设下埋伏，并且抢夺所有从他们那条路经过的人。有人把这事告诉了亚比米勒。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="创世记 13:8; 创世记 19:7"> 那时伊别德的儿子迦勒和他的兄弟们前来，路过示剑，示剑人都信任他。</span>
<span className="v" id="v27" data-v="27" data-xref="士师记 9:4; 士师记 9:46; 诗篇 109:17"> 他们出去到田间，摘取葡萄园的葡萄踹酒，举行庆典；然后进入他们神明的庙宇吃喝，并且诅咒亚比米勒。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 34:2; 创世记 34:6; 撒母耳记上 25:10"> 伊别德的儿子迦勒说：“亚比米勒是谁，我们示剑人竟然要服事他？亚比米勒不是耶路巴力的儿子吗？他的帮手不是西布勒吗？你们当服事示剑之父哈莫尔的后人！我们为什么要服事亚比米勒呢？</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 15:4; 撒母耳记下 2:14–17; 以赛亚书 36:8–9"> 但愿这民归在我手下，我就除掉亚比米勒，我要对亚比米勒说：‘增派你的军队出来吧！’”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 城主西布勒听到伊别德的儿子迦勒的话，就发怒，</span>
<span className="v" id="v31" data-v="31"> 暗中派遣使者到亚比米勒那里，说：“看哪，伊别德的儿子迦勒和他的兄弟们来到了示剑，他们在煽动那城的人反对你。</span>
<span className="v" id="v32" data-v="32" data-xref="罗马书 3:15; 诗篇 36:4; 箴言 1:11–16"> 现在，你和跟随你的军兵要在夜间动身，埋伏在田野，</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记上 10:7; 传道书 9:10; 利未记 25:26"> 到清晨太阳升起的时候，你就早早起来冲向那城。看哪，当迦勒和跟随他的人出来攻击你时，你就全力<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="全力——原文直译“照着手上所有的”。">b</a></sup>对付他吧。”</span>
<span className="v" id="v34" data-v="34"> 于是亚比米勒和所有跟随他的军兵夜间动身，分成四队，对示剑设下埋伏。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35"> 当伊别德的儿子迦勒出来站在城门口的时候，亚比米勒和跟随他的人就从埋伏的地方起来。</span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 8:24; 以西结书 7:7"> 迦勒看见那些人，就对西布勒说：“看哪，有人正从山顶下来！”西布勒却对他说：“你把山的影子看成人了。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="申命记 18:14"> 迦勒又再次发话说：“看哪，有人正从山腰<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="山腰——或译作“中心地带”。">c</a></sup>下来，还有一队人正从‘算命者橡树’的方向前来。”</span>
<span className="v" id="v38" data-v="38" data-xref="士师记 9:28–29; 列王纪下 14:8–14; 撒母耳记下 2:26–27"> 西布勒就对他说：“你曾经说过：‘亚比米勒是谁，我们竟然要服事他。’现在你所夸口的在哪里呢？这不是你所藐视的人吗？现在请你出去，与他们争战吧！”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39"> 于是迦勒率领示剑人出去，与亚比米勒争战。</span>
<span className="v" id="v40" data-v="40" data-xref="列王纪上 20:18–21; 列王纪上 20:30"> 结果亚比米勒追击迦勒，迦勒从他面前逃跑，有许多人受伤仆倒，一直到城门口。</span>
<span className="v" id="v41" data-v="41" data-xref="士师记 9:28; 士师记 9:30"> 之后，亚比米勒住在亚鲁玛，西布勒赶走迦勒和他的兄弟们，不让他们住在示剑。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> 第二天，示剑人出去到田野，有人报告了亚比米勒。</span>
<span className="v" id="v43" data-v="43"> 他就带领军兵，分成三队，埋伏在田野。他观看，看见有人从城里出来，他就起来击杀他们。</span>
<span className="v" id="v44" data-v="44" data-xref="加拉太书 5:15; 士师记 9:15; 士师记 9:20"> 亚比米勒和跟随他的一队人冲上去，守在城门口，另有两队人冲向所有在田野中的人，击杀他们。</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪下 3:25; 申命记 29:23; 雅各书 2:13"> 亚比米勒一整天攻打那城，攻取了它，杀了城里的人。他还拆毁那城，并且撒上盐。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="士师记 8:33; 士师记 9:4; 列王纪上 8:26"> 示剑楼所有的人都听说了，就进入伊勒比利特庙宇的地下室。</span>
<span className="v" id="v47" data-v="47"> 有人报告亚比米勒说，示剑楼所有的人都聚集在一处，</span>
<span className="v" id="v48" data-v="48" data-xref="诗篇 68:14; 箴言 1:11–12; 士师记 7:17–18"> 于是亚比米勒和跟随他的所有军兵上到撒门山。亚比米勒手拿斧头，砍下一根树枝，举起来扛在肩上，然后吩咐跟随他的军兵：“你们看我怎么做，也赶快照样做！”</span>
<span className="v" id="v49" data-v="49" data-xref="加拉太书 5:15; 雅各书 3:16; 士师记 9:20"> 于是所有军兵也各自砍下一根树枝，跟随亚比米勒，把树枝堆在地下室上面，然后放火烧毁地下室。这样，示剑楼的人也都死了，男人和女人约有一千人。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50"> 接着亚比米勒前往提贝斯，对着提贝斯扎营，攻取了它。</span>
<span className="v" id="v51" data-v="51"> 城中有一座坚固的塔楼，那城所有的人，无论男女都逃到那里，把自己关在里面，上到塔楼的屋顶。</span>
<span className="v" id="v52" data-v="52" data-xref="士师记 9:48–49; 列王纪下 14:10; 列王纪下 15:16"> 亚比米勒来到塔楼那里，攻打它。他接近塔楼门口，要放火烧毁它。</span>
<span className="v" id="v53" data-v="53" data-xref="撒母耳记下 11:21; 约伯记 31:3; 耶利米书 49:20"> 这时有一个女人把一块磨石扔到亚比米勒头上，砸破了他的头颅。</span>
<span className="v" id="v54" data-v="54" data-xref="撒母耳记上 31:4–5"> 他赶快呼唤替他拿兵器的年轻人，对他说：“拔出你的刀来，把我杀了！免得人们论到我说：‘一个女人杀了他。’”于是那年轻人把他刺死了。</span>
<span className="v" id="v55" data-v="55" data-xref="撒母耳记下 18:16; 撒母耳记下 20:21–22; 列王纪上 22:35–36"> 以色列人看到亚比米勒死了，就各回自己的地方去了。</span>
</div>
<div className="bp">
<span className="v" id="v56" data-v="56" data-xref="诗篇 94:23; 士师记 9:24; 箴言 5:22"> 这样，神报应了亚比米勒的恶行，就是他对父亲作恶，杀了自己的七十个兄弟。</span>
<span className="v" id="v57" data-v="57" data-xref="士师记 9:20; 约书亚记 6:26; 列王纪上 16:34"> 神也使示剑人的一切恶行报应到他们自己头上，耶路巴力的儿子约坦的诅咒临到了他们身上。</span>
</div>
</div>

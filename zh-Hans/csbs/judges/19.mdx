<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 18:1; 士师记 17:8; 玛拉基书 2:15"> 在以色列没有王的那些日子，有一个利未人寄居在以法莲山地深处，他从犹大的伯利恒娶了一个女子为妾。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 16:28; 申命记 22:21; 利未记 21:9"> 他的妾厌恶他<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="厌恶他——七十士译本作“对他恼怒”；马索拉文本作“背叛他行淫”。">a</a></sup>，离开他回到犹大伯利恒她的父家，留在那里四个月。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 34:3; 创世记 50:21; 利未记 19:17"> 她丈夫带着一个仆人和两头驴起程去找她，为要对她说宽心的话，让她回来。那女子把丈夫带进父家，父亲看见他，就高兴地迎接他。</span>
<span className="v" id="v4" data-v="4"> 他的岳父，就是那女子的父亲挽留他，他就在岳父那里住了三天。他们又吃又喝，在那里留宿。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="士师记 19:8; 创世记 18:5; 诗篇 104:15"> 到了第四天，他们清早起来，那人起身要离去，女子的父亲对女婿说：“你吃点饼补充一下精力，然后再走吧。”</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 19:9; 士师记 16:25; 路得记 3:7"> 于是他们两人又坐下来，一同吃喝。女子的父亲对那人说：“请你再过一夜吧，让你心里畅快！”</span>
<span className="v" id="v7" data-v="7"> 那人起身要走，但他岳父再三劝说，他就又在那里过了一夜。</span>
<span className="v" id="v8" data-v="8"> 第五天他清早起来要走，女子的父亲又说：“你补充一下精力，等到下午再走吧。”于是他们两人又一起吃饭。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 27:1; 路加福音 24:29; 雅各书 4:13–14"> 然后那人带着他的妾和仆人起身要走，他的岳父——女子的父亲又对他说：“你看，天快要黑了，再过一夜吧。看哪，天晚了，就在这里过夜吧，让你心里畅快，明天清早起来再上路回家<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="家——或译作“自己的帐篷”。">b</a></sup>。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约书亚记 15:63; 约书亚记 15:8; 士师记 1:8"> 可是那人不愿再过一夜了，就给两头驴备好鞍，带着他的妾起身离去。他来到耶布斯对面，耶布斯就是耶路撒冷。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 5:6; 士师记 1:21; 士师记 19:10"> 他们临近耶布斯的时候，天已经很晚了，仆人就对主人说：“让我们去，前往这耶布斯人的城，在那里过夜吧。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 主人对他说：“我们不要进外邦人的城，那不是以色列人的地方；我们要前往基比亚。”</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 10:26; 何西阿书 5:8; 以赛亚书 10:29"> 主人又对仆人说：“走吧，我们赶到基比亚或拉玛，在其中一个地方过夜。”</span>
<span className="v" id="v14" data-v="14"> 他们就继续往前走，临近便雅悯的基比亚时，已经日落了。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 19:18; 马太福音 25:35; 马太福音 25:43"> 于是他们前往那里去，要在基比亚过夜。他们来到城中的广场坐下，却没有人接待他们到家里过夜。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="士师记 19:1; 诗篇 104:23; 创世记 3:19"> 看哪，有一个老人傍晚从田间劳作回来，他是以法莲山地的人，寄居在基比亚；那里是便雅悯人的地方。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 32:17; 创世记 16:8"> 老人举目看见城中广场上那个客旅，就问他说：“你从哪里来，要往哪里去呢？”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="士师记 18:31; 约翰福音 15:6; 撒母耳记上 1:7"> 那人回答：“我们是过路的，从犹大的伯利恒到以法莲山地的深处去，我原是那里的人。我去了犹大的伯利恒，现在要回我的家乡<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="现在要回我的家乡——依据七十士译本；马索拉文本作“现在要去耶和华的家”，指的是“伯特利”。">c</a></sup>，可是这里没有人接待我到家里去。</span>
<span className="v" id="v19" data-v="19"> 其实我们有干草和饲料喂我们的驴，你仆人我和你的这女仆，以及随行的年轻人也有饼和酒；我们什么都不缺。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="士师记 6:23; 雅各书 2:15–16; 希伯来书 13:2"> 老人说：“愿你平安！你有什么需要，只管让我来承担，可不要在广场上过夜。”</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 43:24; 创世记 18:4; 路加福音 7:44"> 于是老人把他们带回家，给驴拌了饲料，他们也洗了脚，然后吃喝。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 19:4–5; 哥林多前书 6:9; 士师记 20:5"> 他们正心里畅快的时候，看哪，城里的卑劣之徒围住了房屋，拥挤着撞门<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="拥挤着撞门——或译作“不断拍门”。">d</a></sup>，对那老家主说：“把来到你家的人带出来，我们要与他交合。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="创世记 34:7; 撒母耳记下 13:12; 士师记 20:6"> 家主出来见他们，对他们说：“不要这样，我的兄弟们，请不要作恶。既然这人已经进了我的家，就请你们不要做这丑恶的事。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 19:8; 申命记 21:14; 创世记 34:2"> 看哪，我有个女儿还是处女，还有这人的妾，我把她们带出来吧，你们可以玷辱她们，随意对待她们<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="随意对待她们——原文直译“对她们做你们眼中看为好的”。">e</a></sup>，只是不可对这人做如此丑恶的事。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="何西阿书 10:9; 何西阿书 9:9; 何西阿书 7:4–7"> 可是那些人不愿听他的。那人就拉住自己的妾，推到外面给了他们。他们与她交合，整夜凌辱她，直到早晨天亮的时候，才放她走。</span>
<span className="v" id="v26" data-v="26" data-xref="士师记 19:3; 创世记 18:12; 彼得前书 3:6"> 天快亮的时候，那女人回来，倒在她丈夫留宿的老人家门口，直到天亮。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 她丈夫清早起来，打开房门出去，要继续赶路，却发现那女人——他的妾倒在房门口，双手搭在门槛上。</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 20:5; 列王纪上 18:29"> 丈夫对她说：“起来，我们走吧！”可是没有回应。于是那人把她驮在驴背上，动身回本地去了。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="士师记 20:6–7; 撒母耳记上 11:7; 罗马书 10:2"> 回到家里，他拿来刀，扶住他的妾，把她的尸体切成十二块，送到以色列全境。</span>
<span className="v" id="v30" data-v="30" data-xref="士师记 20:7; 箴言 13:10; 何西阿书 9:9"> 所有看见的人都说：“以色列子孙从埃及地上来的那天起，直到今天，从来没有发生过、也没有见到过这样的事。大家要考虑、商议，对此表态。”</span>
</div>
</div>

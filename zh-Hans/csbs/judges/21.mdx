<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 20:1; 马可福音 6:23; 使徒行传 23:12"> 以色列人曾在米斯巴起誓说：“我们当中谁也不可把女儿嫁给便雅悯人为妻。”</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 20:26; 士师记 20:18; 撒母耳记上 30:4"> 所以民众来到伯特利，坐在神面前直到傍晚。他们放声大哭，</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 74:1; 约书亚记 7:7–9; 以赛亚书 63:17"> 说：“以色列的神耶和华啊！为什么在以色列发生这样的事呢？今天以色列竟然少了一个支派。”</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 24:25; 列王纪上 8:64; 诗篇 78:34–35"> 第二天，民众清早起来，在那里筑了一座祭坛，献上燔祭和平安祭。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 5:23; 士师记 21:18; 士师记 21:1"> 那时，以色列人问：“以色列各支派中，谁没有到耶和华面前来参加集会？”原来他们针对没有上米斯巴到耶和华面前来的人，曾严厉起誓说：“那人必须被处死。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="士师记 21:15; 士师记 20:23; 路加福音 19:41–42"> 以色列人为他们的兄弟便雅悯难过，说：“如今以色列中有一个支派被砍掉了！</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 21:1; 士师记 21:18; 撒母耳记上 14:28–29"> 我们怎样才能使他们剩下的人有妻子呢？我们已经指着耶和华起了誓，不把我们的女儿嫁给便雅悯人为妻。”</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 31:11–13; 撒母耳记上 11:1–3; 撒母耳记下 2:5–6"> 他们就问：“以色列支派中谁没有上米斯巴，到耶和华面前来呢？”结果发现基列-雅比没有一个人到营地来参加集会。</span>
<span className="v" id="v9" data-v="9"> 他们数点民众，发现基列-雅比的居民没有一个人在场。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="士师记 5:23; 士师记 21:5; 撒母耳记上 11:7"> 于是会众从勇士中派出一万两千人，吩咐他们说：“你们去，用刀击杀基列-雅比的居民，包括女人和孩童。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 31:17–18; 申命记 2:34"> 你们要这样做：把所有的男人，以及所有与男人同房过的女人，都灭绝净尽。”</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 18:1; 耶利米书 7:12; 诗篇 78:60"> 他们在基列-雅比的居民中，找到四百个年轻处女，都是没有与男人同房过的。他们就把这些处女带到迦南地的示罗营地。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="士师记 20:47; 申命记 20:10; 以弗所书 2:17"> 全体会众派人去，到临门岩石那里与便雅悯人商谈，向他们提议和好，</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 21:12; 哥林多前书 7:2; 士师记 20:47"> 便雅悯人就在那时回来了。以色列人把存活的基列-雅比女子给了便雅悯人为妻，却发现不够分给他们所有人。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士师记 21:6; 历代志上 15:13; 以赛亚书 58:12"> 人们为便雅悯人难过，因为耶和华使以色列众支派有了破口。</span>
<span className="v" id="v16" data-v="16"> 会众的长老们说：“便雅悯的女子都灭绝了，我们怎样才能使剩下的人有妻子呢？”</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 26:55; 民数记 36:7"> 他们又说：“便雅悯的幸存者必须有继承产业的，免得以色列中一个支派被抹掉。</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 21:1; 士师记 11:35"> 可是我们又不能把自己的女儿嫁给他们为妻。”因为以色列人已经起誓说，把女儿嫁给便雅悯人的必受诅咒。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 16:10; 申命记 16:1; 申命记 16:13"> 他们就说：“看哪，示罗每年都有耶和华的节期。”示罗在伯特利以北，伯特利至示剑的大道东边，利波拿的南边。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 于是他们吩咐便雅悯人说：“你们去埋伏在葡萄园里，</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 11:34; 出埃及记 15:20; 传道书 3:4"> 你们看着，一见示罗的女子出来绕着圈跳舞，你们就从葡萄园出来，各自抢走一个示罗女子为妻，带回便雅悯地去。</span>
<span className="v" id="v22" data-v="22" data-xref="士师记 21:1; 士师记 21:18; 士师记 21:14"> 当他们的父亲或兄弟来与我们争论的时候，我们会对他们说：‘请看在我们的情面上恩待他们吧，因为我们在战争中没有使他们每个人都娶到妻子。何况不是你们自己把女儿嫁给了他们，不然你们现在就要承担罪责了。’”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="士师记 20:48"> 便雅悯人就照着去做了。他们按着自己的人数，把他们抢夺的跳舞女子娶来为妻，然后回自己的继业去，重建城镇，住在其中。</span>
<span className="v" id="v24" data-v="24"> 那时，以色列人也离开那里，各归自己的支派和家族，各回自己的继业去了。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="申命记 12:8; 士师记 17:6; 箴言 3:5"> 在那些日子，以色列没有王，各人做自己眼中看为正的事。</span>
</div>
</div>

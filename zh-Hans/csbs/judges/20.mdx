<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 11:11; 撒母耳记上 3:20; 撒母耳记上 10:17"> 于是全体以色列人出动，从但直到比尔-谢巴，还有基列地，会众如同一人聚集到米斯巴，到耶和华面前。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 8:10; 士师记 20:17; 士师记 20:15"> 以色列众支派全体民众的首领，都站在神子民的集会里，拿刀剑的步兵共有四十万。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 19:22–27; 路加福音 14:31–32; 路加福音 12:58–59"> 以色列人上到米斯巴，便雅悯人也听说了。<br />以色列人说：“请说，这件恶事是怎么发生的？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士师记 19:15–28"> 那利未人，就是被杀的妇人的丈夫，回答说：“我和我的妾来到便雅悯的基比亚过夜。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 19:22; 士师记 19:25–26; 创世记 19:4–8"> 基比亚的居民起来攻击我，夜间包围我的住处，想要杀我，随后把我的妾玷辱致死了。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 19:29; 约书亚记 7:15; 士师记 19:23"> 于是我扶住我的妾，把尸体切成块，送到以色列得为继业的全境，因为基比亚人在以色列做了淫秽丑恶的事。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 19:30; 哥林多前书 5:6; 哥林多前书 5:10–12"> 现在，你们全体以色列人哪，请你们表态，给出建议吧！”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="传道书 9:10; 士师记 20:1; 箴言 21:3"> 那时，全体民众起来如同一人，说：“我们每个人都不回自己的帐篷，不回自己的家。</span>
<span className="v" id="v9" data-v="9" data-xref="约拿书 1:7; 尼希米记 11:1; 约书亚记 14:2"> 我们现在要这样行事来对付基比亚：按着所抽的签，上去攻打他们；</span>
<span className="v" id="v10" data-v="10"> 在以色列各支派中，每一百人选十人，每一千人选一百人，每一万人选一千人，为军兵运送食物，等军兵来到便雅悯的基比亚，就照着他们在以色列所做的一切丑恶之事处置他们。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 于是以色列众人团结如同一人，聚集起来要攻击那城。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 13:14; 申命记 20:10; 罗马书 12:18"> 以色列众支派打发人到便雅悯支派各地，说：“你们中间为什么有这样的恶事呢？</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 17:12; 申命记 13:13; 士师记 19:22"> 现在，你们要把基比亚的那些卑劣之徒交出来，让我们把他们处死，从以色列清除邪恶。”但便雅悯人不愿听从他们兄弟以色列人的话。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 20:20; 约伯记 15:25–26; 民数记 21:23"> 便雅悯人从各城聚集到基比亚，要出去与以色列人作战。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 26:41; 士师记 20:25; 民数记 1:37"> 那一天，各城被调集来的便雅悯人，有两万六千拿刀剑的，此外被调集的还有基比亚居民七百精兵。</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 3:15; 历代志上 12:2; 撒母耳记上 17:49–50"> 这全军当中，七百精兵都是惯用左手的，全都能用投石索甩石，毫发不差。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民数记 1:46; 历代志下 17:14–18; 民数记 26:51"> 便雅悯人之外的以色列人，调集了四十万拿刀剑的，都是战士。</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 20:23; 士师记 20:26–27; 民数记 27:21"> 以色列人起来，上伯特利去求问神，说：“我们当中，谁先上去与便雅悯人作战呢？”<br />耶和华说：“犹大先上去。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约书亚记 7:16; 约书亚记 3:1; 约书亚记 6:12"> 以色列人清早起来，对着基比亚扎营。</span>
<span className="v" id="v20" data-v="20"> 以色列人出去，要与便雅悯人作战。以色列人在基比亚对面摆阵迎战，</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 20:25; 诗篇 73:18–19; 历代志下 28:10"> 便雅悯人就从基比亚出来，当天把两万两千以色列人击杀在地。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 64:5; 士师记 20:17; 撒母耳记上 30:6"> 以色列军兵坚定心志，在第一天摆阵的地方再次摆开战阵。</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 20:26–27; 诗篇 78:34–36; 约书亚记 7:6"> 以色列人上前来，在耶和华面前哀哭，直到傍晚，他们求问耶和华说：“我们可以再过去与我们的兄弟便雅悯人作战吗？”<br />耶和华说：“上去攻击他们吧。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 第二天，以色列人又上前去攻打便雅悯人。</span>
<span className="v" id="v25" data-v="25" data-xref="士师记 20:21; 创世记 18:25; 罗马书 2:5"> 便雅悯人也在第二天从基比亚出来迎战，又把以色列人一万八千人击杀在地，都是拿刀剑的。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="士师记 20:23; 约珥书 2:12–18; 士师记 20:18"> 于是，全体以色列人，全体军兵，都上到伯特利，坐在耶和华面前哀哭。那一天他们禁食直到傍晚，又在耶和华面前献上燔祭和平安祭，</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 18:1; 士师记 20:18; 撒母耳记上 4:3–4"> 然后以色列人求问耶和华。那些日子里，神的约柜是在伯特利，</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 7:9; 约书亚记 24:33; 申命记 18:5"> 亚伦的孙子、以利亚撒的儿子非尼哈当时侍立在约柜前。以色列人求问说：“我们应该再去攻打我们的兄弟便雅悯人呢，还是不要去呢？”<br />耶和华说：“上去吧，明天我必把他们交在你们手中。”</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 8:4; 撒母耳记下 5:23; 士师记 20:34"> 以色列人就在基比亚四围设下埋伏。</span>
<span className="v" id="v30" data-v="30"> 第三天，以色列人又上去攻打便雅悯人，像前几次那样在基比亚对面摆阵。</span>
<span className="v" id="v31" data-v="31" data-xref="士师记 19:13–14; 约书亚记 7:5; 以赛亚书 10:29"> 便雅悯人出来迎战，被引诱出城。他们在两条大道上，一条通往伯特利、一条通往基比亚，开始像前两次那样击杀以色列人，在田野杀了大约三十个人。</span>
<span className="v" id="v32" data-v="32" data-xref="约书亚记 8:15–16"> 便雅悯人想：“他们必像先前那样败在我们面前。”其实以色列人想的是：“我们要逃跑，引诱他们出城到大道上。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约书亚记 8:18–22"> 这样，以色列所有军兵从自己的位置起来，在巴力塔玛摆阵；以色列的伏兵也从基比亚西面，从自己的位置冲上来。</span>
<span className="v" id="v34" data-v="34" data-xref="约书亚记 8:14; 以赛亚书 47:11; 约伯记 21:13"> 全以色列中的一万精兵，从正面进攻基比亚，战斗很激烈。便雅悯人并不知道，祸患已经临近他们了。</span>
<span className="v" id="v35" data-v="35" data-xref="约伯记 20:5; 士师记 20:15; 士师记 20:44–46"> 耶和华在以色列面前打败了便雅悯人；那一天，以色列人消灭了两万五千一百便雅悯人，都是拿刀剑的。</span>
<span className="v" id="v36" data-v="36" data-xref="约书亚记 8:15–29"> 便雅悯人这才知道自己被打败了。<br />以色列人在便雅悯人面前退出阵地，是因为他们信赖那些在基比亚对面设下的伏兵。</span>
<span className="v" id="v37" data-v="37" data-xref="约书亚记 8:19; 约书亚记 6:5; 出埃及记 19:13"> 这时伏兵急速冲进基比亚，伏兵扩散开，用刀击杀全城。</span>
<span className="v" id="v38" data-v="38" data-xref="约书亚记 8:20; 创世记 17:21; 列王纪下 4:16"> 以色列人事先与伏兵有约定：伏兵在城内升起烽火浓烟，</span>
<span className="v" id="v39" data-v="39" data-xref="士师记 20:32"> 以色列人就返回战场。便雅悯人一开始击杀了大约三十个以色列人，就说：“他们将要像先前的战斗那样，彻底败在我们面前了。”</span>
<span className="v" id="v40" data-v="40" data-xref="约书亚记 8:20; 启示录 19:3; 创世记 19:28"> 然而，烽火的烟柱从城内开始上腾，便雅悯人回头一看，全城烟气冲天，</span>
<span className="v" id="v41" data-v="41" data-xref="彼得后书 2:12; 路加福音 21:26; 启示录 6:15–17"> 以色列人又返回来了，便雅悯人就惶恐，因为看出祸患临近他们了。</span>
<span className="v" id="v42" data-v="42" data-xref="约书亚记 8:15; 何西阿书 9:9; 耶利米哀歌 1:3"> 他们在以色列人面前转身逃往旷野，却被紧紧追击<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="却被紧紧追击——原文直译“战斗却紧随他们”。">a</a></sup>，从各城出来的人也夹攻消灭他们。</span>
<span className="v" id="v43" data-v="43" data-xref="约书亚记 8:20–22"> 以色列人包围便雅悯人，追赶他们，从挪哈<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="追赶他们，从挪哈——或译作“不停歇地追赶他们”。">b</a></sup>直到东边的基比亚对面，践踏他们。</span>
<span className="v" id="v44" data-v="44"> 便雅悯人中倒下的有一万八千人，全都是勇士。</span>
<span className="v" id="v45" data-v="45" data-xref="约书亚记 15:32; 士师记 21:13; 撒迦利亚书 14:10"> 其余的人转身逃往旷野，到临门岩石去。以色列人在大道上除掉了他们五千人，并追击他们直到基顿，又击杀了两千人。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="士师记 20:35; 士师记 20:15"> 那一天，便雅悯人中总共倒下了两万五千个拿刀剑的人，全都是勇士。</span>
<span className="v" id="v47" data-v="47" data-xref="以赛亚书 1:9; 诗篇 103:9–10; 哈巴谷书 3:2"> 有六百人转身逃往旷野，到临门岩石去，在临门岩石那里停留了四个月。</span>
<span className="v" id="v48" data-v="48" data-xref="申命记 13:15–17; 历代志下 25:13; 历代志下 28:6–9"> 以色列人回到便雅悯人那里，用刀击杀他们，击杀全城包括牲畜以及所遇到的一切，又放火烧毁他们的所有城镇。</span>
</div>
</div>

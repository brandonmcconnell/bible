<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 11:32; 士师记 6:12; 列王纪下 5:1"> 基列人耶弗塔是个英勇的战士，是一个妓女的儿子，基列与这妓女生了耶弗塔。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 12:10; 箴言 2:16; 申命记 23:2"> 基列的妻子也给基列生了儿子，这些儿子们长大了，就赶走耶弗塔，说：“你不可在我们父亲的家继承产业，因为你是外女的儿子。”</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 9:4; 撒母耳记上 22:2; 撒母耳记下 10:8"> 于是，耶弗塔从他的兄弟们面前逃走，住在陀伯地。有一些无赖聚集到耶弗塔那里，与他一同出入。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士师记 10:9"> 过了一些日子，亚扪人与以色列争战。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 118:22–23; 使徒行传 7:35–39; 哥林多前书 1:27–29"> 当亚扪人与以色列争战的时候，基列的长老们去请耶弗塔从陀伯地回来。</span>
<span className="v" id="v6" data-v="6"> 他们对耶弗塔说：“你来作我们的统帅吧，我们好与亚扪人争战。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="启示录 3:9; 创世记 45:4–5; 以赛亚书 60:14"> 耶弗塔回答基列的长老们：“你们不是恨我吗？你们把我从我父家赶走了，为什么现在危难临到你们，就来找我呢？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="士师记 10:18; 列王纪上 13:6; 出埃及记 10:17"> 基列的长老们对耶弗塔说：“我们现在回来找你，就是要你与我们同去，与亚扪人争战，你可以作我们基列所有居民的领袖。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数记 32:20–29"> 耶弗塔对基列的长老们说：“如果你们请我回去攻打亚扪人，而耶和华把他们交给我，那我就作你们的领袖。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 42:5; 创世记 31:50; 耶利米书 29:23"> 基列的长老们回答耶弗塔：“有耶和华在我们之间作证：我们一定照着你的话这样做。”</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 10:17; 撒母耳记上 10:17; 士师记 20:1"> 于是耶弗塔与基列的长老们同去，民众就立耶弗塔为他们的领袖和统帅。耶弗塔在米斯巴将他那些话全都在耶和华面前述说了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命记 2:26; 马太福音 18:15–16; 箴言 25:8–9"> 耶弗塔派遣使者去见亚扪人的王，说：“我与你有什么相干，你竟然来我这里，侵犯我的国土呢？”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 32:22; 民数记 21:24–26; 申命记 2:37"> 亚扪人的王回答耶弗塔的使者们：“因为以色列从埃及上来的时候，夺取了我的土地，从亚嫩河直到雅博河、约旦河。所以现在，你要和平归还这些土地。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="彼得前书 3:11; 罗马书 12:18; 希伯来书 12:14"> 耶弗塔再次派遣使者去见亚扪人的王，</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 2:19; 申命记 2:9; 民数记 21:27–30"> 对他说：“耶弗塔如此说：以色列并没有夺取摩押地或亚扪人之地。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 14:25; 申命记 1:40; 民数记 20:1"> 因为以色列从埃及上来的时候，走过旷野到红海，然后来到加低斯，</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 20:14–21; 申命记 2:4–9; 民数记 20:1"> 以色列派遣使者去见以东王，说：‘请让我们从你境内经过。’但以东王不听。他们又派人去见摩押王，摩押王也不答应。于是以色列就留在加低斯。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命记 2:1–8; 民数记 22:36; 民数记 21:4–13"> “后来他们经过旷野，绕过以东地和摩押地，来到摩押地的东边，在亚嫩河对岸扎营。他们并没有进入摩押境内，因为亚嫩河是摩押的边界。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="民数记 21:21–35; 申命记 2:26–36; 申命记 3:1–17"> “以色列又派遣使者去见亚摩利王，就是希实本王西宏，以色列对他说：‘请让我们从你境内经过，到我们的地方去。’</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 13:15–32; 民数记 21:23–25; 诗篇 136:17–21"> 但西宏不信任以色列，不让他们从他境内经过。西宏还招聚他的全军，在雅哈兹扎营，与以色列作战。</span>
<span className="v" id="v21" data-v="21"> 以色列的神耶和华把西宏和他的全军交在以色列手中，以色列击败他们，占有了那地居民亚摩利人的全地。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 2:36"> 这样，他们占有了亚摩利人的全境，从亚嫩河直到雅博河，从旷野直到约旦河。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> “现在，以色列的神耶和华已经把亚摩利人从他子民以色列面前赶出去了，你竟然要占有这地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="竟然要占有这地——或译作“却要赶出以色列”。">a</a></sup>吗？</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 21:29; 诗篇 78:55; 弥迦书 4:5"> 你不是占有了你的神基抹让你占有的土地吗？我们也占有我们的神耶和华让我们占有的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="让我们占有的——或译作“从我们面前赶出之人的”。">b</a></sup>一切。</span>
<span className="v" id="v25" data-v="25" data-xref="弥迦书 6:5; 约书亚记 24:9–10; 申命记 23:3–4"> 现在，难道你比西拨的儿子摩押王巴勒还强吗？难道他与以色列争论过，或者与他们争战过吗？</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 2:36; 约书亚记 12:5; 士师记 10:8"> 以色列住在希实本和附属的村镇，亚罗珥和附属的村镇，以及亚嫩河沿岸所有的城镇，已经三百年了，那时候你们为什么不收回呢？</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 24:15; 创世记 16:5; 撒母耳记上 24:12"> 我并没有得罪你，你却侵犯我，要与我争战。愿审判者耶和华今天在以色列人和亚扪人之间施行审判！”</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪下 14:11; 箴言 16:18"> 但亚扪人的王不听耶弗塔向他传达的话。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数记 11:25; 士师记 3:10; 士师记 13:25"> 于是耶和华的灵临到耶弗塔身上，他就穿过基列和玛拿西，又穿过基列的米斯巴，然后从基列的米斯巴过去，到亚扪人那里。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 28:20; 撒母耳记上 1:11; 传道书 5:1–2"> 耶弗塔向耶和华许了一个愿，说：“如果你确实把亚扪人交在我手中，</span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 66:13–14; 利未记 27:28–29; 撒母耳记上 1:28"> 当我从亚扪人那里平安回来时，谁先从我家门出来迎接我，谁就归给耶和华，我必把他献上作为燔祭。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="士师记 1:4; 士师记 2:18; 士师记 3:10"> 于是耶弗塔过去，到亚扪人那里与他们交战，耶和华就把亚扪人交在他手中。</span>
<span className="v" id="v33" data-v="33" data-xref="以西结书 27:17; 申命记 2:36"> 他击杀他们，从亚罗珥到米尼特隘口二十座城，直到亚贝勒-基拉明，那是一场极大的杀戮。这样，亚扪人在以色列子民面前被制伏了。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="耶利米书 31:4; 出埃及记 15:20; 士师记 10:17"> 耶弗塔回到米斯巴自己的家，看哪，他的女儿拿着铃鼓跳舞出来迎接他；耶弗塔只有这个独生女，没有别的儿女。</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 14:7–9; 创世记 37:29–30; 创世记 42:36–38"> 耶弗塔看见女儿，就撕裂衣服，说：“唉，我的女儿啊！你让我愁苦至极，你给我带来了困扰。我已经向耶和华开了口，不能收回啊！”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="撒母耳记下 18:19; 腓立比书 2:30; 罗马书 16:4"> 他女儿对他说：“父亲啊，你已经向耶和华开了口，耶和华已经在你仇敌亚扪人身上为你报仇，你就照着你说出的话对待我吧。”</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 1:25; 撒母耳记上 1:6"> 她又对父亲说：“愿你准许我这件事：请宽限我两个月，让我与我的女伴们到山里去，为我终身不嫁而哀哭。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> 耶弗塔说：“你去吧”，就让她离开两个月。她与她的女伴们到山里，为她终身不嫁而哀哭。</span>
<span className="v" id="v39" data-v="39" data-xref="以赛亚书 66:3; 士师记 11:31; 利未记 27:28–29"> 过了两个月，她回到父亲那里，父亲照着所许的愿对待她，她就终身没有亲近男人。于是在以色列有一个习俗：</span>
<span className="v" id="v40" data-v="40" data-xref="列王纪上 9:25; 士师记 5:11"> 以色列的女子每年都会去纪念基列人耶弗塔的女儿，每年有四天。</span>
</div>
</div>

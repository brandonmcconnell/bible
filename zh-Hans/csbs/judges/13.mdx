<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 12:9; 士师记 6:1; 罗马书 2:6"> 以色列子民又做耶和华眼中看为恶的事，耶和华就把他们交在非利士人手中四十年。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 19:41; 路加福音 1:7; 约书亚记 15:33"> 有一个但家族的佐拉人，名叫玛挪亚，他妻子不能生育，没有孩子。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:13; 路加福音 1:11; 士师记 6:11–12"> 耶和华的使者向那妇人显现，对她说：“看哪，你向来不能生育、没有孩子，现在你必怀孕，生一个儿子。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 1:15; 士师记 13:14; 民数记 6:2–3"> 因此你要谨慎，淡酒烈酒都不可喝，任何不洁净的食物也不可吃。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 6:5; 撒母耳记上 1:11; 历代志上 18:1"> 看哪，你必怀孕，生一个儿子。绝不可在他头上用剃刀，因为这孩子从母腹中就要归于神作拿细耳人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="拿细耳人——意思是“分别出来的人”；本章下同。">a</a></sup>。他将起来拯救以色列脱离非利士人的手。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="士师记 13:17–18; 撒母耳记上 9:6; 马太福音 28:3–4"> 那妇人就回去，告诉丈夫说：“有一位神人到我这里来了，他的容貌好像神使者的容貌，极其可畏。我没有问他从哪里来，他也没有把他的名告诉我。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 13:4"> 他对我说：‘看哪，你必怀孕，生一个儿子。所以，淡酒烈酒你都不可喝，任何不洁净的食物也不可吃，因为这孩子从母腹中直到死的那天，都要归于神作拿细耳人。’”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 9:6; 约伯记 34:32; 箴言 3:5–6"> 玛挪亚向耶和华祈求，说：“哦，主啊，请让你所派遣的神人再到我们这里来，指示我们对这将要出生的孩子该怎样做。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="诗篇 65:2; 马太福音 7:7–11"> 神垂听了玛挪亚的话。于是神的使者再次来到妇人那里，当时她正坐在田间，她丈夫玛挪亚没有与她在一起。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 4:28–29; 约翰福音 1:41–42"> 那妇人赶快跑去告诉丈夫，说：“看哪，那天到我这里来的人又向我显现了。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 玛挪亚就起身，跟着妻子去了。他来到那人面前，问他：“对这妇人说话的人就是你吗？”<br />他说：“是我。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="箴言 22:6; 以弗所书 6:4; 创世记 18:19"> 玛挪亚说：“现在，愿你的话应验！关于这孩子和他的工作，有什么规定呢？”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 耶和华的使者对玛挪亚说：“我对这妇人所说的一切，她都要遵守。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 2:5; 士师记 13:4; 帖撒罗尼迦后书 3:4"> 葡萄树所出产的一切，她都不可吃；淡酒烈酒她都不可喝；各样不洁净的食物，她都不可吃。我所吩咐她的一切，她都要遵守。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士师记 6:18–19; 创世记 18:3–5; 士师记 13:3"> 玛挪亚对耶和华的使者说：“请容我们挽留你，为你预备一只小山羊。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="士师记 13:23; 士师记 6:20; 士师记 6:26"> 但耶和华的使者对玛挪亚说：“你就算挽留我，我也不会吃你的食物。你如果要预备燔祭，就把它献给耶和华吧。”原来玛挪亚不知道那人是耶和华的使者。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 32:29"> 玛挪亚对耶和华的使者说：“你的名怎么称呼？到你的话应验时，我们好尊崇你。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="创世记 32:29; 以赛亚书 9:6; 士师记 13:6"> 耶和华的使者回答他：“你何必问我的名呢？我的名是奇妙的。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="士师记 6:19–21; 列王纪上 18:30–38"> 玛挪亚取来一只小山羊和一些素祭，在磐石上献给耶和华。于是发生了一件奇妙的事，玛挪亚和他的妻子一直看着，</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 9:24; 历代志上 21:16; 列王纪下 2:11"> 当火焰从祭坛升上天的时候，耶和华的使者也随着祭坛的火焰升上去了。玛挪亚和他的妻子看见，就脸伏于地。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 6:22; 何西阿书 12:4–5; 士师记 13:16"> 耶和华的使者再也没有向玛挪亚和他的妻子显现了。这时，玛挪亚才知道那人是耶和华的使者。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="创世记 32:30; 申命记 5:26; 约翰福音 1:18"> 玛挪亚就对他的妻子说：“我们必定死，因为我们看见了神。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="诗篇 25:14; 哥林多前书 12:21; 约翰福音 15:15"> 但他的妻子对他说：“耶和华如果想杀我们，就不会从我们手中接受燔祭和素祭了，也不会向我们显示这一切，不会在这个时候告知我们这些事。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 1:80; 撒母耳记上 3:19; 希伯来书 11:32"> 后来那妇人生了一个儿子，给他起名为叁孙。孩子渐渐长大，耶和华祝福了他。</span>
<span className="v" id="v25" data-v="25" data-xref="士师记 3:10; 约书亚记 15:33; 约翰福音 3:34"> 在佐拉和以实陶之间的玛哈尼但，耶和华的灵开始催动叁孙。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 20:18; 民数记 27:21; 士师记 20:28"> 约书亚死了以后，以色列子民求问耶和华说：“我们当中，谁先上去攻打迦南人，与他们争战呢？”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="启示录 5:5; 希伯来书 7:14; 民数记 2:3"> 耶和华说：“犹大先上去。看哪，我已经把那地交在他手中了。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 10:11; 约书亚记 19:1; 士师记 1:17"> 犹大对他的兄弟西缅说：“请与我一同上去，到我抽签所得之地，与迦南人争战。以后我也与你一同到你抽签所得之地去。”西缅就与他一同去了。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 11:8; 出埃及记 23:28–29; 约书亚记 11:6–8"> 犹大上去，耶和华把迦南人和比利洗人交在他们手中，他们在贝泽克击杀了一万人。</span>
<span className="v" id="v5" data-v="5"> 他们在贝泽克遇见阿多尼·贝泽克，与他争战，击败了迦南人和比利洗人。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 阿多尼·贝泽克逃跑，他们追赶他，抓住了他，砍掉了他手脚的拇指。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 15:33; 启示录 13:10; 路加福音 6:37–38"> 阿多尼·贝泽克说：“从前有七十个王，被我砍掉了手脚的拇指，在我桌子底下捡吃的。现在神照着我所做的，如此回报我了。”他们把他带到耶路撒冷，他就死在那里。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约书亚记 15:63; 士师记 1:21"> 犹大子孙攻打耶路撒冷，攻取了它，用刀击杀城里的人，又放火烧了那城。</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 15:13–20; 约书亚记 11:21; 约书亚记 10:36"> 之后，犹大子孙下去，与住在山地、南地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="南地——音译作“内盖夫”；本章下同。">a</a></sup>和丘陵地带的迦南人争战。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 13:22; 约书亚记 14:15; 耶利米书 9:23"> 犹大又去攻打住在希伯仑的迦南人，击杀了示筛、亚希幔和塔尔迈；希伯仑从前名叫基列-阿尔巴。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 15:15; 约书亚记 10:38–39"> 他们又从那里去攻打底璧的居民，底璧从前名叫基列西弗。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约书亚记 15:16–17; 撒母耳记上 17:25; 撒母耳记上 18:23"> 迦勒说：“谁攻打基列西弗，攻取那城，我就把女儿娅撒嫁给他为妻。”</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 3:9"> 迦勒的弟弟基纳斯的儿子俄陀聂攻取了那城，迦勒就把女儿娅撒嫁给他为妻。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 15:18–19"> 娅撒出嫁的时候，鼓动丈夫从她父亲那里求一块田。她下了驴，迦勒问她：“你有什么事呢？”</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 25:18; 哥林多后书 9:5; 彼得前书 3:9"> 她就对父亲说：“求你给我一个祝福：你既然把南地给了我，请你把水泉也给我。”于是迦勒把上泉和下泉都给了她。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数记 10:29–32; 士师记 4:11; 撒母耳记上 15:6"> 摩西的内兄<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="内兄——或译作“岳父”或“姻亲”；参《士师记》4:11《民数记》10:29。">b</a></sup>是基尼人，他的子孙与犹大子孙一起离开棕榈城，上到阿拉德南地的犹大旷野，去与那里的人住在一起。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民数记 21:3; 士师记 1:3; 约书亚记 19:4"> 犹大与他们的兄弟西缅同去，击杀住在洗法的迦南人，灭绝了那城。他们就给那城起名为霍尔玛。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 11:22; 士师记 3:3; 约书亚记 15:45–47"> 犹大也攻取了加沙和它的四境，阿实基伦和它的四境，以革伦和它的四境。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 41:10; 士师记 1:2; 诗篇 60:12"> 耶和华与犹大同在，犹大就占领了山地，然而犹大不能赶出平原的居民，因为他们有铁战车。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="士师记 1:10; 约书亚记 15:13–14; 民数记 14:24"> 以色列人照着摩西的吩咐，把希伯仑给了迦勒，迦勒从那里赶出了三支亚衲子孙。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约书亚记 15:63; 士师记 19:10–12; 士师记 1:8"> 便雅悯人没有把住在耶路撒冷的耶布斯人赶出去，所以耶布斯人与便雅悯人一起住在耶路撒冷，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="士师记 1:19; 列王纪下 18:7; 民数记 1:32"> 约瑟家也上去攻打伯特利，耶和华与他们同在。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 28:19; 创世记 35:6; 创世记 48:3"> 约瑟家探察伯特利，这城从前名叫路斯；</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 2:12–14; 撒母耳记上 30:15"> 探子看见一个人从城里出来，就对他说：“请指给我们进城的路，我们必以恩慈对待你。”</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 6:22–25"> 那人指给他们进城的路，他们就用刀击杀城里的人，但放走了那人和他的全家。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 7:6; 历代志下 1:17"> 那人前往赫提人之地，建造了一座城，又给那城起名为路斯，至今还是这名。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约书亚记 17:11–13; 耶利米书 48:10; 诗篇 106:34–35"> 玛拿西没有赶出伯珊和附属村镇的居民，特纳克和附属村镇的居民，多珥和附属村镇的居民，以伯莲和附属村镇的居民，米吉多和附属村镇的居民；迦南人坚持住在这地。</span>
<span className="v" id="v28" data-v="28"> 以色列强盛的时候，就使迦南人服苦役，没有完全赶出他们。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约书亚记 16:10; 列王纪上 9:16"> 以法莲没有把住在基色的迦南人赶出去，于是迦南人住在基色，在以法莲人当中。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约书亚记 19:15"> 西布伦没有把基伦的居民和拿哈拉的居民赶出去，于是迦南人住在西布伦人当中，成了服苦役的人。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约书亚记 19:24–30"> 亚设没有赶出阿科的居民和西顿的居民，以及阿赫拉、阿克济、赫勒巴、阿费克和利合的居民。</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 106:34–35"> 于是亚设人住在那地的居民迦南人当中，因为他们没有赶出迦南人。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约书亚记 19:32–38; 士师记 1:30; 诗篇 18:24"> 拿弗他利没有把伯示麦的居民和伯亚纳的居民赶出去，所以拿弗他利人住在那地的居民迦南人当中，但伯示麦和伯亚纳的居民成了为他们服苦役的人。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="约书亚记 19:47; 士师记 18:1"> 亚摩利人把但子孙压制在山地，不让他们下到平原来。</span>
<span className="v" id="v35" data-v="35" data-xref="约书亚记 19:42; 士师记 12:12; 约书亚记 10:12"> 亚摩利人坚持住在希列斯山、阿雅仑和沙勒宾，当约瑟家的势力强盛的时候，他们就成了服苦役的人。</span>
<span className="v" id="v36" data-v="36" data-xref="民数记 34:4; 约书亚记 15:2–3"> 亚摩利人的边界从阿克拉宾斜坡起，从西拉往上延伸。</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 15:10; 约书亚记 19:43; 约翰一书 2:16"> 叁孙下到亭拿，在那里见到一个女子，是非利士人的女儿。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 34:4; 创世记 21:21; 创世记 24:2–3"> 叁孙回去告诉父母，说：“我在亭拿见到一个女子，是非利士人的女儿，现在请你们把她给我娶来为妻。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="士师记 15:18; 撒母耳记上 17:36; 撒母耳记上 14:6"> 他的父母对他说：“难道我们族兄弟的女儿中，或者所有的族人中没有女子吗？你竟然要到未受割礼的非利士人那里娶妻。”<br />叁孙对父亲说：“请把她给我娶来，因为在我眼中，就她合适。”</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 11:20; 诗篇 115:3; 士师记 13:1"> 他的父母不明白这是出于耶和华，耶和华在寻找时机攻击非利士人。在那段时期，非利士人辖制着以色列。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 叁孙与父母一起下亭拿去，来到了亭拿的葡萄园。忽然有一只少壮狮子吼叫着向他扑过来，</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 3:10; 士师记 13:25; 撒母耳记上 11:6"> 耶和华的灵大大临到他，他就赤手空拳撕裂了狮子，如同撕裂小山羊。他没有把所做的事告诉父母。</span>
<span className="v" id="v7" data-v="7"> 叁孙下去与那女子说话，在叁孙眼中她很合适。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="马太福音 1:20; 创世记 29:21"> 过了一些日子，叁孙回去迎娶那女子。他转往路旁去看那狮子的尸体，发现狮子的尸体里有一群蜜蜂，还有蜂蜜。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 14:25–30; 箴言 25:15"> 他取了一些蜂蜜在手掌里，然后继续走，边走边吃。他走到父母那里，把蜂蜜给了他们，他们也吃了，但他没有告诉他们蜂蜜是从狮子的尸体里取来的。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 29:22; 启示录 19:9; 以斯帖记 1:7–22"> 于是，叁孙的父亲下去见那女子，叁孙就照着青年人的惯例，在那里摆设了宴席。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 9:15; 撒母耳记上 16:6; 撒母耳记上 10:23"> 那里的人看见叁孙，就安排了三十个伙伴陪同他。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王纪上 10:1; 以西结书 17:2; 创世记 45:22"> 叁孙对他们说：“现在让我给你们出一个谜语吧，如果你们在七天宴席期间能向我解答，我就给你们三十件细麻衣和三十套服装。</span>
<span className="v" id="v13" data-v="13"> 如果你们不能向我解答，你们就给我三十件细麻衣和三十套服装。”<br />他们对他说：“请你出谜语吧，让我们听听。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="雅各书 1:2–4; 列王纪上 17:6; 罗马书 8:37"> 叁孙就对他们说：<br /><span className="pl pl-1">“吃的出于吃者，</span><br /><span className="pl pl-1">甜的出于强者。”</span><br />三天他们都不能解答那谜语。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 16:5; 士师记 15:6; 箴言 6:26"> 这样，到了第七天，他们对叁孙的妻子说：“你要引诱你的丈夫，让他向我们解答这谜语，否则我们就放火烧了你和你的父家。你们邀请我们，难道是要抢夺我们，不是吧？”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="士师记 16:15; 创世记 2:24"> 叁孙的妻子就对丈夫哭闹，说：“你一定是恨我，并不爱我！你出谜语给我的族人，却不给我解答。”<br />叁孙对她说：“看哪，我连父母都没有告诉，怎能告诉你呢？”</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="士师记 16:16; 约伯记 2:9; 士师记 16:13"> 七天宴席期间，她一直对叁孙哭闹。这样，到了第七天，因她催逼，叁孙就告诉了她。于是，她去向自己的族人解答了那谜语。</span>
<span className="v" id="v18" data-v="18"> 在第七天日落之前，那城的人对叁孙说：<br /><span className="pl pl-1">“有什么比蜂蜜更甜？</span><br /><span className="pl pl-1">有什么比狮子更强？”</span><br />叁孙对他们说：<br /><span className="pl pl-1">“要不是用我的小母牛耕作，</span><br /><span className="pl pl-1">你们绝猜不出我的谜语。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 11:6; 士师记 3:10; 士师记 13:25"> 耶和华的灵大大临到叁孙，他就下到阿实基伦，击杀了三十个人，夺走他们的服装，把那些服装给了解答谜语的人，然后怒气发作，回他父家去了。</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 15:2; 约翰福音 3:29; 诗篇 55:12–13"> 之后，叁孙的妻子归给了陪同叁孙的一个伙伴。</span>
</div>
</div>

<span className="v" id="v1" data-v="1"> 约伯回答说：</span>
<span className="v" id="v2" data-v="2" data-xref="约伯记 4:17; 罗马书 3:20; 约伯记 25:4"> <span className="pl pl-1">“我知道事情确实如此，</span><br /><span className="pl pl-1">世人怎能在神面前显为义呢？</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="约伯记 10:2; 约伯记 40:2; 以赛亚书 57:15–16"> <span className="pl pl-1">人如果想与神争论，</span><br /><span className="pl pl-1">千次回答不了一次。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="约伯记 36:5; 罗马书 11:33; 以弗所书 3:20"> <span className="pl pl-1">神心里有智慧，能力强大，</span><br /><span className="pl pl-1">谁能对抗他还平安无事呢？</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 27:51; 路加福音 21:11; 哈巴谷书 3:10"> <span className="pl pl-1">他使群山移开，山却不知道：</span><br /><span className="pl pl-1">他在怒气中把它们倾覆。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="哈该书 2:6; 希伯来书 12:26; 诗篇 75:3"> <span className="pl pl-1">他使大地颤抖离开原处，</span><br /><span className="pl pl-1">地的基柱就摇撼。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 13:10; 阿摩司书 8:9; 路加福音 21:25–26"> <span className="pl pl-1">他一下令，太阳就不显现，</span><br /><span className="pl pl-1">他还封印星辰；</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 44:24; 以赛亚书 40:22; 诗篇 104:2–3"> <span className="pl pl-1">他独自铺展诸天，</span><br /><span className="pl pl-1">踏行海浪之上；</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司书 5:8; 创世记 1:16; 约伯记 38:31–41"> <span className="pl pl-1">他造北斗、参星和昴星，</span><br /><span className="pl pl-1">以及南方的星宿；</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="约伯记 5:9; 诗篇 72:18; 以弗所书 3:20"> <span className="pl pl-1">他行大事无法测度，</span><br /><span className="pl pl-1">行奇事无法数算。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 23:8–9; 约伯记 35:14; 诗篇 77:19"> <span className="pl pl-1">看哪，他从我旁边经过，我却看不见；</span><br /><span className="pl pl-1">他掠过，我也不察觉。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 45:9; 约伯记 11:10; 约伯记 23:13"> <span className="pl pl-1">他夺去时，谁能阻拦他？</span><br /><span className="pl pl-1">谁能对他说：‘你在做什么？’</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 89:10; 约伯记 26:12; 以赛亚书 30:7"> <span className="pl pl-1">神必不收回他的怒气，</span><br /><span className="pl pl-1">拉哈伯的帮助者们必屈身在他脚下。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="列王纪上 8:27; 约伯记 9:3; 约伯记 4:19"> <span className="pl pl-1">所以，我怎么敢反驳他呢？</span><br /><span className="pl pl-1">我怎么敢挑选言词与他辩论？</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="约伯记 10:15; 约伯记 8:5; 约伯记 10:2"> <span className="pl pl-1">即使我是对的，也不敢反驳，</span><br /><span className="pl pl-1">只能向我的审判者恳求。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="约伯记 29:24; 出埃及记 6:9; 诗篇 66:18–20"> <span className="pl pl-1">即使我呼喊了，并且他回应我，</span><br /><span className="pl pl-1">我也不相信他会倾听我的声音。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="约伯记 16:14; 约伯记 2:3; 约伯记 34:6"> <span className="pl pl-1">他用暴风摧残我，</span><br /><span className="pl pl-1">无故增多我的创伤。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="约伯记 7:19; 耶利米哀歌 3:15; 诗篇 88:15–18"> <span className="pl pl-1">他不允许我喘一口气，</span><br /><span className="pl pl-1">而是让我吃尽苦头。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 9:32–33; 约伯记 9:4; 哥林多前书 1:25"> <span className="pl pl-1">如果论能力，看，他多么强大！</span><br /><span className="pl pl-1">如果论审判，他说</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他说——辅助词语。">a</a></sup><br /><span className="pl pl-1">：‘谁能传唤我？’</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="约伯记 15:5–6; 腓立比书 3:12–15; 诗篇 143:2"> <span className="pl pl-1">即使我是对的，</span><br /><span className="pl pl-1">我开口就使我被定为有罪；</span><br /><span className="pl pl-1">即使我是纯全的，</span><br /><span className="pl pl-1">我开口就使我成为悖谬的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="约伯记 1:1; 诗篇 139:23–24; 箴言 28:26"> <span className="pl pl-1">我是纯全的，</span><br /><span className="pl pl-1">但我不顾</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="顾——或译作“认识”。">b</a></sup><br /><span className="pl pl-1">我自己了，</span><br /><span className="pl pl-1">我厌弃我的性命。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="传道书 9:1–3; 路加福音 13:2–4; 约伯记 10:8"> <span className="pl pl-1">反正都一样！因此我说：</span><br /><span className="pl pl-1">‘纯全人和恶人，他都要灭绝。’</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="约伯记 24:12; 约伯记 1:13–19; 约伯记 4:7"> <span className="pl pl-1">如果突来横祸使人死亡，</span><br /><span className="pl pl-1">他就嘲笑清正的人的遭遇。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="约伯记 10:3; 耶利米书 12:1–2; 诗篇 73:3–7"> <span className="pl pl-1">世界被交在恶人手中，</span><br /><span className="pl pl-1">他遮蔽了审判官们的脸——</span><br /><span className="pl pl-1">如果不是他，还能是谁呢？</span></span>

<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="约伯记 7:6–7; 雅各书 4:14; 诗篇 90:9–10"> <span className="pl pl-1">我的年日比信使更快，</span><br /><span className="pl pl-1">飞逝而去，不见福乐。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="哈巴谷书 1:8; 以赛亚书 18:2; 约伯记 39:27–30"> <span className="pl pl-1">我的年日如芦苇舟掠过，</span><br /><span className="pl pl-1">如鹰向猎物疾飞。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="约伯记 7:13; 耶利米书 8:18; 约伯记 7:11"> <span className="pl pl-1">如果我说‘我要忘记我的苦情，</span><br /><span className="pl pl-1">除去我的愁容，得以欢愉’，</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 119:120; 诗篇 88:15–16; 约伯记 21:6"> <span className="pl pl-1">我就因我所有的愁苦而惧怕，</span><br /><span className="pl pl-1">我知道你不会让我免于罪罚。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="约伯记 10:7; 约伯记 21:27; 约伯记 10:14–17"> <span className="pl pl-1">既然我被定为有罪，</span><br /><span className="pl pl-1">我何必这样徒劳呢？</span><br /></span>

<div className="bp poetry">

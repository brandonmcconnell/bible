<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 约伯回答耶和华，说：</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 19:26; 马可福音 10:27; 创世记 18:14"> <span className="pl pl-1">“我知道你凡事都能做，</span><br /><span className="pl pl-1">你的计划无可拦阻。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 131:1; 诗篇 139:6; 约伯记 38:2"> <span className="pl pl-1">你问</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你问——辅助词语。">a</a></sup><br /><span className="pl pl-1">是谁用无知隐藏你的旨意，</span><br /><span className="pl pl-1">确实，我述说了我不明白的事，</span><br /><span className="pl pl-1">这些对我太过奇妙，我无法领悟。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="约伯记 40:7; 约伯记 38:3; 创世记 18:30–32"> <span className="pl pl-1">你说</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="你说——辅助词语。">b</a></sup><br /><span className="pl pl-1">‘请听我说话，</span><br /><span className="pl pl-1">我问你，你来指示我！’</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 1:17–18; 罗马书 10:17; 约翰福音 12:45"> <span className="pl pl-1">我从前风闻有你，</span><br /><span className="pl pl-1">现在却亲眼看见你。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以斯拉记 9:6; 提摩太前书 1:13–16; 雅各书 4:7–10"> <span className="pl pl-1">因此我厌弃自己，</span><br /><span className="pl pl-1">在尘土和灰烬中懊悔！”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约伯记 11:5–6; 约伯记 32:2–3; 约伯记 32:5"> 耶和华对约伯说了这些话以后，又对提幔人以利法说：“我向你和你的两个朋友发怒，因为你们没有正确地讲论我，不像我的仆人约伯说的那样。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 23:1; 雅各书 5:16; 诗篇 103:10"> 现在，你们要带七头公牛、七只公绵羊，到我仆人约伯那里去，为自己献上燔祭。我的仆人约伯会为你们祷告，我必悦纳他，不按你们的愚顽对待你们。因为你们没有正确地讲论我，不像我的仆人约伯说的那样。”</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 11:8; 使徒行传 9:6; 使徒行传 10:33"> 于是提幔人以利法、书亚人比勒达和拿玛人佐法尔就去，照着耶和华吩咐他们的做了。耶和华就悦纳约伯。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命记 30:3; 约伯记 8:6–7; 箴言 22:4"> 约伯为他的朋友祷告后，耶和华恢复了约伯的家业，并且耶和华使约伯所拥有的一切加倍增添。</span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 2:11; 约伯记 19:13–14; 箴言 16:7"> 约伯所有的兄弟姐妹以及所有以前认识他的人，都来看他，并在他家里与他一同吃饭。他们劝慰他，因耶和华降给他的一切灾祸而安慰他。每人还送给他一份银钱和一个金环。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约伯记 8:7; 传道书 7:8; 箴言 10:22"> 这样，耶和华后来赐福给约伯的比先前更多：他有一万四千只羊，六千匹骆驼，一千对牛和一千头母驴。</span>
<span className="v" id="v13" data-v="13" data-xref="约伯记 1:2; 诗篇 107:41; 诗篇 127:3"> 他又有了七个儿子，三个女儿。</span>
<span className="v" id="v14" data-v="14"> 他给第一个女儿起名为耶美玛，第二个女儿起名为克希娅，第三个女儿起名为卡莲哈朴。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 27:7; 诗篇 144:12; 使徒行传 7:20"> 全地都找不到像约伯的女儿那样美貌的女子，而且她们的父亲使她们与兄弟们同分继业。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="箴言 17:6; 诗篇 128:6; 创世记 50:23"> 这事以后，约伯又活了一百四十年，得见他的儿孙，直到四代。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 25:8; 创世记 15:15; 约伯记 5:26"> 约伯年迈，寿数满足而死。</span>
</div>
</div>

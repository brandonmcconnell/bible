<span className="v" id="v2" data-v="2" data-xref="启示录 16:15; 彼得后书 3:10; 马太福音 24:42–44"> 因为你们自己明确地知道，主的日子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="日子——指“基督再来的日子”。">a</a></sup>来临，就像夜里的贼来临那样。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 21:34–35; 马太福音 24:37–39; 路加福音 17:26–30"> 当人们正说“和平”、“安全”的时候，毁灭那时就突然临到他们，就像孕妇的临产阵痛那样，他们绝不能逃脱。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰一书 2:8; 彼得后书 3:10; 申命记 19:6"> 不过弟兄们，你们不是在黑暗里，以致那日子像贼一样抓住你们。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 5:8; 使徒行传 26:18; 约翰福音 12:36"> 因为你们都是光明的儿女，白昼的儿女。我们不属于黑夜，也不属于黑暗。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前书 1:13; 马太福音 24:42; 路加福音 22:46"> 由此可见，我们不要像其他人那样睡着了，而要警醒、谨慎。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 13:13; 哥林多前书 15:34; 彼得后书 2:13"> 因为睡觉的人是在夜里睡，醉酒的人是在夜里醉。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 13:12–13; 以弗所书 6:11; 彼得前书 1:13"> 但我们既然属于白昼，就让我们谨慎，以信与爱做为护胸甲穿上，以救恩的盼望做为头盔戴上。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦前书 1:10; 彼得前书 2:10; 提摩太后书 2:10"> 因为神不是预定我们到震怒里面，而是预定我们藉着我们的主耶稣基督获得救恩。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 14:8–9; 彼得前书 3:18; 罗马书 8:34"> 基督替我们死，为要使我们无论是醒着还是睡着，都与他一同活着。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 4:29; 希伯来书 10:25; 罗马书 15:2"> 因此，你们要彼此鼓励，互相造就，就像你们现在所做的那样。</span>
</div>

<span className="v" id="v14" data-v="14" data-xref="提摩太后书 4:2; 罗马书 14:1; 使徒行传 20:35"> 弟兄们，我们劝你们：要劝诫懒散的人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="懒散的人——或译作“不守规矩的人”。">c</a></sup>，安慰胆怯的人，扶助软弱的人，对所有的人都要恒久忍耐。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 3:9; 加拉太书 6:10; 利未记 19:18"> 你们要注意，谁都不要以恶报恶；相反，无论是彼此之间，还是对待众人，总要追求美善。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 12:12; 腓立比书 4:4; 马太福音 5:12"> <span className="pl pl-1">要常常欢喜，</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 12:12; 歌罗西书 4:2; 以弗所书 6:18"> <span className="pl pl-1">不住地祷告，</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 5:20; 腓立比书 4:6; 歌罗西书 3:17"> <span className="pl pl-1">凡事感谢；</span><br /><span className="pl pl-1">因为这是神在基督耶稣里对你们的旨意。</span><br /></span>

<span className="v" id="v21" data-v="21" data-xref="约翰一书 4:1; 罗马书 12:2; 以弗所书 5:10"> <span className="pl pl-1">却要凡事分辨，</span><br /><span className="pl pl-1">要持守美善，</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="哥林多后书 6:3; 腓立比书 4:8; 哥林多前书 10:31–33"> <span className="pl pl-1">连一切恶的样式都要远避。</span></span>
</div>

<span className="v" id="v23" data-v="23" data-xref="犹大书 1:24; 希伯来书 4:12; 哥林多前书 1:8–9"> 愿赐平安的神亲自使你们完全分别为圣。愿你们的灵、魂、体，在我们的主耶稣基督来临的时候，全然得蒙保守、无可指责。</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦后书 3:3; 民数记 23:19; 哥林多前书 1:9"> 召唤你们的那一位是信实的，他将成就这事。</span>

<span className="v" id="v26" data-v="26" data-xref="罗马书 16:16; 哥林多前书 16:20"> 你们要用圣洁的亲吻礼问候所有的弟兄。</span>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="JHN" data-book-slug="john" data-book-name="约翰福音" data-chapter="3" data-verses="36">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 19:39; 约翰福音 7:47–50; 约翰福音 3:10"> 有一个人，属于法利赛人，名叫尼克迪莫，是犹太人的一位首领。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 5:36; 使徒行传 10:38; 使徒行传 2:22"> 他夜里来到耶稣那里，说：“拉比，我们知道你是从神那里来的老师，因为你所行的这些神迹，如果没有神的同在，没有人能做得到。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 5:17; 约翰福音 3:5–6; 彼得前书 1:23–25"> 耶稣回答说：<span className="woj">“我确确实实地告诉你：一个人如果不重生</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="重生——或译作“由上天而生”。">a</a></sup><span className="woj">，就不能见神的国。”</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 2:14; 哥林多前书 1:18; 约翰福音 3:3"> 尼克迪莫问：“人老了，怎么能出生呢？他难道能再进母腹又出生吗？”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以西结书 36:25–27; 以弗所书 5:26; 使徒行传 2:38"> 耶稣回答：<span className="woj">“我确确实实地告诉你：一个人如果不是由水和圣灵所生的，就不能进入神的国。</span></span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 5:16–21; 以西结书 36:26–27; 罗马书 8:4–9"> <span className="woj">由肉体所生的，就是肉体；由圣灵所生的，就是灵。</span></span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 3:3; 以弗所书 4:22–24; 罗马书 12:1–2"> <span className="woj">我说‘你们必须重生</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="重生——或译作“由上天而生”。">b</a></sup><span className="woj">’，你不要感到惊奇。</span></span>
<span className="v" id="v8" data-v="8" data-xref="传道书 11:4–5; 哥林多前书 2:11; 使徒行传 2:2"> <span className="woj">风</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="风——或译作“灵”或“圣灵”。">c</a></sup><span className="woj">随意而吹，你听见风声，却不知道它从哪里来，往哪里去。所有由圣灵所生的，也是这样。”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约翰福音 6:60; 路加福音 1:34; 以赛亚书 42:16"> 尼克迪莫又问：“怎么能有这些事呢？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 22:29; 耶利米书 8:8–9; 以西结书 11:19"> 耶稣回答说：<span className="woj">“你是以色列的老师，还不明白这些事吗？</span></span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 8:38; 约翰一书 5:6–12; 约翰福音 12:49"> <span className="woj">我确确实实地告诉你：我们讲论我们所知道的，我们见证我们所看到的，而你们却不接受我们的见证。</span></span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 3:1–2; 哥林多前书 2:7–9; 希伯来书 5:11"> <span className="woj">我告诉你们地上的事，你们尚且不信，如果我告诉你们天上的事，你们怎么会信呢？</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 30:4; 约翰福音 6:38; 使徒行传 2:34"> <span className="woj">除了从天上降下来的人子，</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附“就是在天上的那一位，”。">d</a></sup><span className="woj">没有人升过天。</span></span>
<span className="v" id="v14" data-v="14" data-xref="民数记 21:7–9; 约翰福音 8:28; 约翰福音 12:32–34"> <span className="woj">摩西在旷野怎样把铜蛇举起，人子也必须照样被举起来，</span></span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 3:16; 约翰福音 6:40; 约翰福音 12:44–46"> <span className="woj">好使所有相信他的人</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附“不至于灭亡，反而”。">e</a></sup><span className="woj">，都得到永恒的生命。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="罗马书 5:8; 约翰一书 4:9–10; 约翰福音 3:15"> <span className="woj">“神爱世人，甚至赐下他的独生子，好让所有信他的人不至于灭亡，反得永恒的生命，</span></span>
<span className="v" id="v17" data-v="17" data-xref="约翰一书 4:14; 路加福音 19:10; 约翰福音 12:47–48"> <span className="woj">因为神差派他的</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本没有“他的”。">f</a></sup><span className="woj">儿子来到世上，不是为了定世人的罪，而是为了世人藉着他得救。</span></span>
<span className="v" id="v18" data-v="18" data-xref="马可福音 16:16; 约翰一书 5:10; 罗马书 8:1"> <span className="woj">信他的人，不被定罪；不信的人，已经被定罪了，因为他不信神独生子的名。</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约翰福音 8:12; 帖撒罗尼迦后书 2:12; 约翰福音 9:39–41"> <span className="woj">“所定的罪是这样的：光来到了世界，人们却因自己的行为邪恶，不喜爱光，反喜爱黑暗。</span></span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 5:11–13; 约翰福音 7:7; 约伯记 24:13–17"> <span className="woj">事实上，所有作恶的人，都憎恨光，不来到光那里，免得自己的行为被揭露出来；</span></span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 1:6; 诗篇 139:23–24; 约翰三书 1:11"> <span className="woj">但行真理的人，却来到光那里，为了显明自己所做的是在神里面被做成的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约翰福音 4:1–3; 约翰福音 3:26; 约翰福音 2:13"> 这些事以后，耶稣和他的门徒们来到犹太地区，住在那里，并且给人施洗。</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 1:4–5; 以西结书 43:2; 马太福音 3:5–6"> 约翰也在撒令附近的艾嫩施洗，因为那里水多。众人纷纷而来受洗。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 4:12; 马太福音 14:3; 马可福音 6:17"> 原来，约翰那时候还没有被投进监狱。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 2:6; 马太福音 3:11; 希伯来书 6:2"> 约翰的门徒们与一个<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="一个——有古抄本作“一些”。">g</a></sup>犹太人，为了洁净礼起了辩论。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 1:7; 约翰福音 1:15; 约翰福音 12:19"> 他们就到约翰那里，对他说：“拉比，你看，以前与你在约旦河对岸的，就是你所见证的那一位，他也在施洗，而且大家都到他那里去了。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="雅各书 1:17; 哥林多前书 4:7; 哥林多前书 15:10"> 约翰回答说：“如果不是从天上赐下的，人就不能得到什么。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 1:20; 约翰福音 1:23; 马太福音 3:11–12"> 你们自己可以为我见证：我曾经说过‘我不是基督，而是奉差派在他前面的。’</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 9:15; 何西阿书 2:19; 以赛亚书 54:5"> 迎娶新娘的是新郎。新郎的朋友站在那里，听到新郎的声音，就欢喜快乐。这样，我这喜乐得以满足了。</span>
<span className="v" id="v30" data-v="30" data-xref="歌罗西书 1:18; 诗篇 72:17–19; 希伯来书 3:2–6"> 他必兴旺，我必衰微。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 8:23; 马太福音 28:18; 罗马书 9:5"> 那从上面来的，是在万有之上；那从地而出的，属于地，而且所说的也属于地。那从天上来的，是在万有之上，</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 3:11; 约翰福音 15:15; 约翰福音 1:11"> 他见证他所看到的、他所听到的，可是没有人接受他的见证。</span>
<span className="v" id="v33" data-v="33" data-xref="希伯来书 6:17; 以弗所书 1:13; 提多书 1:1–2"> 那接受他见证的人，就印证了神是真实的。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 10:38; 马太福音 12:18; 约翰福音 15:26"> 神所差派的那一位，就说神的话语，因为神不靠着量度赐下圣灵。</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 28:18; 约翰福音 5:22; 约翰福音 5:20"> 父爱子，把一切都交在他手里了。</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 5:24; 约翰福音 1:12; 帖撒罗尼迦前书 5:9"> 信从子的人，就有永恒的生命；但是不肯信从子的人，见不到生命，而且神的震怒也停留在他身上。</span>
</div>
</div>

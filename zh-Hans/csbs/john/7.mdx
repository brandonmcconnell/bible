<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="JHN" data-book-slug="john" data-book-name="约翰福音" data-chapter="7" data-verses="53">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 5:16–18; 约翰福音 4:3; 马太福音 21:38"> 这些事以后，耶稣走遍加利利。原来他不愿意在犹太地区往来，因为那些犹太人想要杀害他。</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亚书 14:16–19; 申命记 16:13–16; 出埃及记 23:16–17"> 犹太人的住棚节快到了，</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 12:46; 约翰福音 7:5; 路加福音 8:19"> 耶稣的弟弟们对他说：“你离开这里到犹太去吧，好让你的门徒们也能看到你所做的事。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 18:20; 箴言 18:1–2; 马太福音 23:5"> 因为人不会又想要出名，又在隐秘中做事。你既然要做这些事，就把自己显明给世人看吧！”</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 3:21; 约翰福音 1:11–13; 弥迦书 7:5–6"> 原来连他的弟弟们也不信他。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约翰福音 7:8; 约翰福音 2:4; 约翰福音 7:30"> 耶稣对他们说：<span className="woj">“我的时候还没有来到，而你们的时候随时都方便。</span></span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 15:18–19; 约翰福音 3:19; 加拉太书 4:16"> <span className="woj">世界不能恨你们，却是恨我，因为我见证世界的行为是邪恶的。</span></span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 7:6; 约翰福音 8:20; 约翰福音 7:30"> <span className="woj">你们上去过节吧，我现在不</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="现在不——有古抄本作“不”。">a</a></sup><span className="woj">上去，因为我的时候还没有到。”</span></span>
<span className="v" id="v9" data-v="9"> 说了这些话，耶稣仍然留在加利利地区。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="阿摩司书 5:13; 马太福音 10:16; 以赛亚书 42:2–3"> 不过当他的弟弟们上去过节以后，他也上去了，但没有公开，像是悄悄去的。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 11:56"> 节日期间，那些犹太人搜寻耶稣，说：“那个人在哪里？”</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 7:40–43; 约翰福音 9:16; 约翰福音 7:32"> 人群中有许多人对他议论纷纷；有的说：“他是好人。”也有的说：“不，他是迷惑民众的。”</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 9:22; 约翰福音 19:38; 约翰福音 20:19"> 只是没有人公开地讲论他的事，因为怕那些犹太人。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="约翰福音 7:28; 路加福音 19:47; 约翰福音 7:37"> 可是住棚节已经过了一半，耶稣上圣殿去，开始教导人。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 4:22; 马太福音 7:28–29; 马太福音 13:54"> 那些犹太人感到惊奇，说：“这个人没学过，怎么懂得经文呢？”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰福音 14:10; 约翰福音 14:24; 约翰福音 17:8"> 耶稣回答他们，说：<span className="woj">“我的教导不是我自己的，而是那派我来者的。</span></span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 8:31–32; 约翰福音 8:43; 耶利米书 31:33–34"> <span className="woj">人如果愿意遵行神的旨意，就会明白这教导究竟是从神而来的，还是我凭自己而讲的。</span></span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 5:41; 哥林多前书 10:31–33; 约翰福音 13:31–32"> <span className="woj">凭自己讲话的人，是寻求自己的荣耀；但是，寻求那派他来者之荣耀的，他才是真实的，在他里面没有不义。</span></span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 1:17; 约翰福音 11:53; 马太福音 12:14"> <span className="woj">摩西不是把律法传给你们了吗？你们当中却没有一个人遵行这律法。你们为什么想要杀我呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约翰福音 10:20; 约翰福音 8:48; 约翰福音 8:52"> 众人回答：“你有鬼魔附身！谁想要杀你？”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约翰福音 7:23; 约翰福音 5:2–11"> 耶稣对他们说：<span className="woj">“我做了一件事，你们都感到惊奇。</span></span>
<span className="v" id="v22" data-v="22" data-xref="利未记 12:3; 创世记 17:10–14; 罗马书 4:9–11"> <span className="woj">摩西把割礼传给你们，你们就在安息日给人施行割礼——其实割礼不是从摩西开始的，而是从祖先开始的。</span></span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 12:5; 约翰福音 5:14–16; 马太福音 12:2"> <span className="woj">既然人在安息日受割礼，是为了不违犯摩西的律法；那么，因为我在安息日使一个人完全康复，你们就对我生气吗？</span></span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 11:3–4; 雅各书 2:9; 约翰福音 8:15"> <span className="woj">不要按着外表做判断，而要按着公义做判断。”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 7:10–11"> 有些耶路撒冷的人说：“这不是他们想要杀的那个人吗？</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太后书 1:7–8; 约翰福音 7:48; 约翰福音 12:42"> 看，他还在公开讲话，他们也没有对他说什么。难道首领们真的认为这个人就是<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就是——有古抄本作“真是”。">b</a></sup>基督吗？</span>
<span className="v" id="v27" data-v="27" data-xref="弥迦书 5:2; 约翰福音 7:41–42; 约翰福音 6:42"> 可是，基督出现的时候，没有人会知道他从哪里来；而这个人，我们却很清楚他是从哪里来的。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约翰福音 8:42; 约翰福音 8:19; 约翰福音 8:26"> 耶稣在圣殿里教导人，呼喊说：<span className="woj">“你们认识我，也知道我是从哪里来的。其实我不是凭自己而来的；派我来的那一位是真实的，你们却不认识他；</span></span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 8:55; 马太福音 11:27; 约翰福音 17:18"> <span className="woj">而我认识他，因为我是从他而来，也是他差派了我。”</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约翰福音 8:20; 约翰福音 10:39; 约翰福音 7:6"> 因此他们想要抓耶稣，只是没有人下手，因为他的时候还没有到。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 12:42; 马太福音 12:23; 约翰福音 10:41–42"> 但是人群中有许多人信了耶稣，他们说：“基督来的时候，难道会比这个人行更多的神迹吗？”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="约翰福音 18:3; 路加福音 22:52–53; 约翰福音 11:47–48"> 法利赛人听到了众人私下议论耶稣的这些事。于是祭司长们和法利赛人就派差役们去抓他。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约翰福音 16:5; 约翰福音 13:33; 马可福音 16:19"> 耶稣说：<span className="woj">“我与你们在一起的时候不多了，我要回到派我来的那一位面前。</span></span>
<span className="v" id="v34" data-v="34" data-xref="箴言 1:24–31; 约翰福音 13:33–36; 约翰福音 14:6"> <span className="woj">你们将要寻找我，却找不到；我所在的地方，你们不能去。”</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="雅各书 1:1; 以赛亚书 11:12; 西番雅书 3:10"> 那些犹太人彼此问：“这个人要到哪里去，让我们找不到他呢？难道他要往散居在希腊人中的犹太侨民那里，去教导希腊人吗？</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 3:9; 约翰福音 7:34; 约翰福音 12:34"> 他所说的<span className="woj">‘你们将要寻找我，却找不到；我所在的地方，你们不能去’</span>，这话是什么意思呢？”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="以赛亚书 55:1; 约翰福音 4:14; 约翰福音 6:35"> 节期的最后一天，也是最盛大的日子，耶稣站起来呼喊说：<span className="woj">“如果有人渴了，就到我这里</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本没有“到我这里”。">c</a></sup><span className="woj">来喝吧！</span></span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 4:14; 以赛亚书 44:3; 以赛亚书 58:11"> <span className="woj">信我的人，就如经上所说的，从他的腹中将要涌流出活水的江河。”</span></span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 2:17; 约珥书 2:28; 约翰福音 14:16–17"> 耶稣这话是指着信他的人所要领受的圣灵而说的。当时，圣灵<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="圣灵——有古抄本作“灵”。">d</a></sup>还没有临到<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="临到——有古抄本作“赐下来”。">e</a></sup>，因为耶稣还没有得荣耀。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="马太福音 21:11; 约翰福音 1:21; 约翰福音 6:14"> 众人听了这话，有些<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有些——有古抄本作“许多”。">f</a></sup>人说：“这个人确实是那位先知！”</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 7:52; 约翰福音 1:46; 约翰福音 1:49"> 另有的说：“这个人就是基督。”还有的却说：“难道基督会出自加利利吗？</span>
<span className="v" id="v42" data-v="42" data-xref="弥迦书 5:2; 马太福音 2:5; 路加福音 2:4"> 经上不是说，基督是大卫的后裔，是出自大卫的故乡伯利恒吗？”</span>
<span className="v" id="v43" data-v="43" data-xref="约翰福音 9:16; 约翰福音 10:19; 约翰福音 7:12"> 于是众人因耶稣就产生了分裂；</span>
<span className="v" id="v44" data-v="44" data-xref="约翰福音 7:30; 使徒行传 23:11; 约翰福音 8:20"> 其中有些人想要抓他，可是没有人下手。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="约翰福音 7:32; 使徒行传 5:21–27"> 差役们回到祭司长们和法利赛人那里。那些人问：“为什么没有把他带来？”</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="马太福音 7:28–29; 路加福音 4:22; 约翰福音 7:26"> 差役们回答：“从来没有人像这个人<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本没有“像这个人”。">g</a></sup>那样讲话！”</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="约翰福音 7:12; 哥林多后书 6:8; 列王纪下 18:32"> 法利赛人说：“难道你们也被迷惑了吗？</span>
<span className="v" id="v48" data-v="48" data-xref="约翰福音 12:42; 哥林多前书 1:20; 哥林多前书 2:8"> 难道首领或法利赛人中有信他的吗？</span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前书 1:20–21; 约翰福音 9:40; 约翰福音 9:34"> 这不懂律法的民众是被诅咒的！”</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="约翰福音 19:39; 约翰福音 3:1–2"> 他们当中有一个人，就是原先<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="原先——有古抄本作“夜里”。">h</a></sup>来到耶稣那里的尼克迪莫，对他们说：</span>
<span className="v" id="v51" data-v="51" data-xref="箴言 18:13; 申命记 1:17; 申命记 19:15–19"> “如果不先听本人的口供，并且了解他做了什么，我们的律法就定不了他的罪，难道不是吗？”</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="约翰福音 7:41; 约翰福音 1:46; 以赛亚书 9:1–2"> 他们回答说：“你也不会是加利利人吧？你去查一查看，先知是不会从加利利兴起的！”</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="诗篇 33:10; 约伯记 5:12–13; 诗篇 76:10"> 然后他们每个人都回家去了。</span>
</div>
</div>

<span className="v" id="v1" data-v="1" data-xref="耶利米书 2:21; 以赛亚书 27:2–3; 哥林多前书 3:9"> <span className="woj">“我就是真葡萄树，我父是园丁。</span></span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 3:10; 希伯来书 12:10–11; 马太福音 15:13"> <span className="woj">所有属于我</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="属于我——原文直译“在我里面”。">a</a></sup><span className="woj">而不结果子的枝条，他就除掉；而所有结果子的，他就修剪干净，好让它结出更多的果子。</span></span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 17:17; 以弗所书 5:26; 彼得前书 1:22"> <span className="woj">藉着我给你们讲的话语，你们已经干净了。</span></span>
<span className="v" id="v4" data-v="4" data-xref="约翰一书 2:6; 加拉太书 2:20; 约翰福音 8:31"> <span className="woj">你们当住在我里面，我就住在你们里面。枝条如果不留在葡萄树上，就不能由自己结出果子；照样，你们如果不住在我里面，你们也是如此。</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="腓立比书 4:13; 歌罗西书 1:10; 约翰福音 15:16"> <span className="woj">“我就是葡萄树，你们是枝条。那住在我里面、我也在他里面的，他才结出很多果子，因为没有我，你们什么也不能做。</span></span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 7:19; 希伯来书 6:7–8; 马太福音 13:41"> <span className="woj">一个人如果不住在我里面，就像枝条被丢在外面枯干了，然后被收集扔进火里焚烧。</span></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 37:4; 约翰一书 5:14; 约翰福音 14:13"> <span className="woj">你们如果住在我里面，而我的话也住在你们里面，那么，凡是你们所愿的，当祈求，就将为你们成就。</span></span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 8:31; 马太福音 5:16; 腓立比书 1:11"> <span className="woj">你们结出很多果子，就表明是我的门徒了；从这一点我父也就得荣耀。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约翰福音 17:23–24; 约翰福音 17:26; 约翰一书 2:28"> <span className="woj">“正如父爱我，我也爱你们。你们当住在我的爱里。</span></span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 14:15; 约翰一书 5:3; 约翰一书 3:21–24"> <span className="woj">如果你们遵守我的命令，就会住在我的爱里；就像我遵守了我父的命令，住在他的爱里那样。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约翰福音 17:13; 罗马书 15:13; 约翰福音 16:24"> <span className="woj">“我把这些事告诉了你们，是要我的喜乐在</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="在——有古抄本作“住在”。">b</a></sup><span className="woj">你们里面，并且使你们的喜乐得以满足。</span></span>
<span className="v" id="v12" data-v="12" data-xref="约翰一书 4:21; 彼得前书 4:8; 约翰福音 13:34"> <span className="woj">这是我的命令：你们要彼此相爱，就像我爱了你们那样。</span></span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 10:11; 以弗所书 5:2; 罗马书 5:6–8"> <span className="woj">一个人为他的朋友舍弃自己的生命，人的爱没有比这更大的了。</span></span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 12:50; 约翰一书 5:3; 雅各书 2:23"> <span className="woj">你们如果遵行我所吩咐的事，你们就是我的朋友了。</span></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 25:14; 哥林多前书 2:9–12; 马太福音 13:11"> <span className="woj">我不再称你们为奴仆，因为奴仆不知道主人所做的事。我却称你们为朋友，因为我把从我父所听到的一切，都让你们明白了。</span></span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 15:19; 耶利米书 1:5–7; 以弗所书 2:10"> <span className="woj">不是你们拣选了我，而是我拣选了你们，并指派了你们，好使你们去，让你们结出果子，而且使你们的果子长存。这样，你们奉我的名无论向父求什么，他就会赐给你们。</span></span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 15:12; 约翰一书 3:14–17; 彼得前书 2:17"> <span className="woj">我将这些事吩咐你们，是要让你们彼此相爱。</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰一书 3:13; 约翰福音 7:7; 马可福音 13:13"> <span className="woj">“这世界如果恨你们，你们应当知道，世界在恨你们之前已经恨我了。</span></span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 4:4–5; 约翰福音 17:14–16; 以弗所书 1:4–11"> <span className="woj">如果你们属于这世界，世界会把你们做为属自己的来爱；但是，因为你们不属于这世界，而是我从世界中拣选了你们，所以世界就恨你们。</span></span>
<span className="v" id="v20" data-v="20" data-xref="提摩太后书 3:12; 约翰福音 13:16; 马太福音 10:24"> <span className="woj">你们当记住我对你们说过的话：“没有一个奴仆大过他的主人。”他们既然逼迫了我，也会逼迫你们；如果他们遵守了我的话，也就会遵守你们的话。</span></span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 10:22; 约翰福音 16:3; 马太福音 10:18"> <span className="woj">但是，因我名的缘故，他们会对你们做这一切事，因为他们不认识派我来的那一位。</span></span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 9:41; 雅各书 4:17; 使徒行传 17:30"> <span className="woj">如果我没有来，也没有教导他们，他们就没有罪；但如今，他们的罪无可推诿了。</span></span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 8:40–42; 约翰二书 1:9; 约翰一书 2:23"> <span className="woj">恨我的，也恨我的父。</span></span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 5:36; 约翰福音 14:9; 约翰福音 7:31"> <span className="woj">如果我没有在他们当中做别人从未做过的事，他们就没有罪；但如今他们虽然看到了，还是恨我和我的父。</span></span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 109:3; 诗篇 69:4; 诗篇 35:19"> <span className="woj">不过这是为要应验他们律法上所记载的话：‘他们无缘无故地恨我。’</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="约翰福音 14:26; 约翰福音 14:16–17; 约翰福音 16:13–15"> <span className="woj">“我将从父那里派遣慰助者来，他就是从父而来的真理的灵。他来的时候，将为我做见证。</span></span>
<span className="v" id="v27" data-v="27" data-xref="约翰一书 4:14; 约翰福音 21:24; 使徒行传 10:39–42"> <span className="woj">并且你们也要做见证，因为你们从一开始就与我在一起。</span></span>
</div>

<div className="bp">

<span className="v" id="v10" data-v="10" data-xref="约翰福音 5:19; 约翰福音 10:38; 约翰福音 10:30"> <span className="woj">难道你不相信我就在父里面，父也在我里面吗？我对你们说的话，不是凭自己说的，而是住在我里面的父，在做他的工作。</span></span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 10:38; 约翰福音 10:25; 约翰福音 5:36"> <span className="woj">你们当相信我：我在父里面，父也在我里面。即使不信，也当因我所做的事而相信</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附“我”。">a</a></sup><span className="woj">。</span></span>

<span className="v" id="v14" data-v="14"> <span className="woj">如果你们奉我的名向我</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本没有“向我”。">b</a></sup><span className="woj">求什么，我将成就。</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本没有此节。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰一书 2:3–5; 约翰一书 5:2–3; 约翰福音 14:21–24"> <span className="woj">“你们如果爱我，就会遵守我的命令。</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="就会遵守我的命令。——有古抄本作“就应当遵守我的命令。”">d</a></sup></span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 14:26; 约翰福音 15:26; 约翰福音 16:7–15"> <span className="woj">我也要向父祈求，他就将赐给你们另一位慰助者，让他与你们在</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="在——有古抄本作“住在”。">e</a></sup><span className="woj">一起，直到永远。</span></span>

<span className="v" id="v18" data-v="18" data-xref="约翰福音 14:3; 诗篇 23:4; 马太福音 18:20"> <span className="woj">我不会撇下你们为孤儿，我要回到你们这里来。</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约翰福音 16:16; 约翰福音 7:33; 希伯来书 7:25"> <span className="woj">“再过一会儿，世人不再看到我了，而你们将看到我。因为我活着，你们也将活着。</span></span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 15:5–7; 加拉太书 2:20; 约翰福音 17:21–23"> <span className="woj">在那一天，你们就会明白：我在我父里面，你们在我里面，我也在你们里面。</span></span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 14:15; 约翰一书 5:3; 约翰一书 2:5"> <span className="woj">那领受我命令并遵守的人，就是爱我的。爱我的会蒙我父所爱，我也会爱他，并且会向他显明我自己。”</span></span>
</div>

</div>
<div className="bp">

</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 17:6–8; 约翰福音 13:19; 约翰福音 16:12"> <span className="woj">“我还与你们在一起的时候，已经把这些事告诉了你们。</span></span>

</div>

<span className="v" id="v28" data-v="28" data-xref="约翰福音 10:29–30; 哥林多前书 15:24–28; 哥林多前书 11:3"> <span className="woj">你们听过我对你们说：‘我去了，还要回到你们这里来。’如果你们爱我，就会为了我到父那里去而感到欢喜。这是因为父比我更大。</span></span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 13:19; 约翰福音 16:4–31; 马太福音 24:24–25"> <span className="woj">如今，在事情发生以前我已经告诉你们了，好让你们在事情发生的时候能相信。</span></span>

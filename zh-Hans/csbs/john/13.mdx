<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 12:23; 约翰一书 4:19; 约翰福音 13:34"> 逾越节前，耶稣知道他离开这世界回到父那里去的时候到了。他一直爱世界上那些属自己的人，并且爱他们到底。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="雅各书 1:13–17; 使徒行传 5:3; 约翰福音 13:26–27"> 晚餐的时候，魔鬼已经把出卖耶稣的念头放在加略人西门的儿子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="儿子——辅助词语。">a</a></sup>犹大的心里。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 3:35; 马太福音 11:27; 希伯来书 1:2"> 耶稣知道父把一切交在自己手里，并且知道自己是从神那里来，又要回到神那里去。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 22:27; 哥林多后书 8:9; 路加福音 12:37"> 他从席位上起身，脱了外衣，拿起一条布巾束在自己腰上，</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 7:44; 诗篇 51:2; 创世记 18:4"> 然后把水倒进盆里，开始洗门徒们的脚，又用束在腰上的布巾擦干。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="马太福音 3:11–14; 约翰福音 1:27; 路加福音 5:8"> 他来到西门彼得面前，彼得对他说：“主啊，你洗我的脚吗？”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="但以理书 12:8; 约翰福音 12:16; 约翰福音 14:26"> 耶稣回答说：<span className="woj">“我所做的，你现在不理解，不过事后就会明白。”</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西结书 36:25; 使徒行传 22:16; 提多书 3:5"> 彼得说：“你绝不可洗我的脚，永远不可！”<br />耶稣说：<span className="woj">“如果我不洗你，你就与我没有份了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="诗篇 51:7; 诗篇 51:2; 彼得前书 3:21"> 西门彼得说：“主啊！不单我的脚，连我的手、我的头也要洗！”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约翰福音 15:3; 哥林多后书 7:1; 哥林多后书 5:17"> 耶稣说：<span className="woj">“洗过澡的人，除了脚以外，没有需要洗的；他是完全干净的。你们是干净的，但不是每个人都干净。”</span></span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 13:26; 约翰福音 13:2; 约翰福音 13:21"> 原来，耶稣知道要出卖他的是谁，所以说<span className="woj">“你们不是每个人都干净。”</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约翰福音 13:7; 约翰福音 13:4; 以西结书 24:24"> 耶稣洗完了他们的脚以后，穿上外衣，又坐下来，对他们说：<span className="woj">“你们明白我为你们做的事吗？</span></span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 6:46; 哥林多前书 12:3; 约翰福音 11:28"> <span className="woj">你们叫我‘老师’，称呼我‘主’。你们说得对，因为我就是那一位。</span></span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 5:5; 使徒行传 20:35; 罗马书 12:16"> <span className="woj">因此，如果我——你们的主、你们的老师，还洗你们的脚，那么你们也应该彼此洗脚。</span></span>
<span className="v" id="v15" data-v="15" data-xref="约翰一书 2:6; 马太福音 11:29; 彼得前书 3:17–18"> <span className="woj">事实上，我给你们做了榜样，好让你们也照着我为你们所做的去做。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 6:40; 约翰福音 15:20; 马太福音 10:24–25"> <span className="woj">“我确确实实地告诉你们：没有一个奴仆大过他的主人，也没有一个被派的大过派他的人。</span></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 11:28; 雅各书 4:17; 雅各书 1:25"> <span className="woj">你们既然明白这些事，如果去做，就蒙福了。</span></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 41:9; 马太福音 26:23; 约翰福音 17:12"> <span className="woj">我不是针对你们每个人而说的。我了解我所拣选的每个人，但这是为要应验经上的话：‘那吃我饼的人</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="那吃我饼的人——有古抄本作“与我一同吃饼的人”。">b</a></sup><span className="woj">，竟抬脚踢</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="踢——原文直译“对付”。">c</a></sup><span className="woj">我。’</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 43:10; 约翰福音 14:29; 约翰福音 16:4"> <span className="woj">“如今，在事情发生以前，我先告诉你们，好让你们在事情发生的时候，能相信我就是那一位。</span></span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:16; 路加福音 9:48; 马太福音 25:40"> <span className="woj">我确确实实地告诉你们：那接受我所派的人，就是接受我；接受我的，就是接受派我来的那一位。”</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约翰福音 13:18; 马太福音 26:21; 马可福音 14:18"> 说完这些话，耶稣灵里烦扰，就指名说：<span className="woj">“我确确实实地告诉你们：你们当中有一个人要出卖我。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 22:23; 马太福音 26:22; 马可福音 14:19"> 门徒彼此相看，不知道耶稣说的是谁。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 19:26; 约翰福音 21:7; 约翰福音 21:20"> 他的门徒当中，有一个挨着耶稣坐着<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="挨着耶稣坐着——原文直译“坐在耶稣胸前”。">d</a></sup>，是耶稣所爱的。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 12:17; 路加福音 1:22; 使徒行传 13:16"> 西门彼得就向他点头示意，要他问耶稣所讲的人到底是谁。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 21:20; 创世记 44:4–12; 以斯帖记 7:5"> 于是那门徒贴近耶稣<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="贴近耶稣——原文直译“贴近耶稣的胸膛”。">e</a></sup>，问他：“主啊，是谁呢？”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 26:23; 约翰福音 13:30; 马可福音 14:19–20"> 耶稣回答：<span className="woj">“我蘸一块饼给谁，就是谁。”</span>接着，他蘸了一块饼拿给加略人西门的儿子<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="儿子——辅助词语。">f</a></sup>犹大。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 22:3; 约翰福音 13:2; 传道书 9:3"> 犹大一接那块饼，撒旦就进了他里面。于是耶稣对他说：<span className="woj">“你要做的，就快一点做吧。”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 在座的人，没有一个明白耶稣为什么对他说这话。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 12:5–6; 约翰福音 13:1; 以弗所书 4:28"> 因为犹大管钱包，有些人以为耶稣对他说，去买我们过节需要的东西，或是要他给穷人什么东西。</span>
<span className="v" id="v30" data-v="30" data-xref="以赛亚书 59:7; 约伯记 24:13–15; 箴言 4:16"> 犹大接了那块饼，就立刻出去。那时候是夜间了。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 14:13; 彼得前书 4:11; 约翰福音 7:39"> 犹大出去以后，耶稣就说：<span className="woj">“现在人子得了荣耀，神藉着人子也得了荣耀。</span></span>
<span className="v" id="v32" data-v="32" data-xref="启示录 22:1; 以赛亚书 53:10–12; 约翰福音 17:4–6"> <span className="woj">神既然藉着人子得了荣耀，</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本没有“神既然藉着人子得了荣耀，”。">g</a></sup><span className="woj">神也将藉着自己荣耀人子，而且立刻就要荣耀他。</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约翰福音 7:33–34; 约翰福音 8:21–24; 约翰福音 16:16–22"> <span className="woj">“孩子们哪，我与你们在一起的时候不多了。你们将寻找我，而且就像我曾经告诉过那些犹太人一样，现在我也告诉你们：我去的地方，你们不能去。</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="以弗所书 5:2; 利未记 19:18; 约翰福音 15:17"> <span className="woj">“我给你们一条新的命令：就是要你们彼此相爱，就如我爱你们，为要使你们也彼此相爱。</span></span>
<span className="v" id="v35" data-v="35" data-xref="约翰一书 4:20–21; 约翰一书 3:10–14; 约翰一书 2:10"> <span className="woj">如果你们彼此之间有了爱，众人从这一点就会知道你们是我的门徒了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="彼得后书 1:14; 约翰福音 13:33; 约翰福音 21:21–22"> 西门彼得问：“主啊，你要到哪里去呢？”<br />耶稣回答：<span className="woj">“我去的地方，你现在不能跟着去，但以后会跟着去。”</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒行传 21:13; 使徒行传 20:24; 马可福音 14:27–31"> 彼得说：“主啊，为什么我现在就不能跟随你呢？为了你，我愿意舍弃自己的生命！”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="路加福音 22:34; 马太福音 26:34; 马可福音 14:30"> 耶稣回答：<span className="woj">“你愿意为我舍命吗？我确确实实地告诉你：鸡叫以前，你必定三次不认我。</span></span>
</div>
</div>

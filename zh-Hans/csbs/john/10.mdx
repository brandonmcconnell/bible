<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 7:15; 约翰福音 10:8–10; 罗马书 16:18"> <span className="woj">“我确确实实地告诉你们：那不从门进入羊圈，却从别处爬进去的人，是贼、是强盗。</span></span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 10:14; 使徒行传 20:28; 彼得前书 5:4"> <span className="woj">那从门进去的，才是羊的牧人。</span></span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 34:11–16; 提摩太后书 2:19; 约翰福音 10:4"> <span className="woj">看门的就给他开门，羊也听他的声音。他一一提名呼唤自己的羊，带领它们出去。</span></span>
<span className="v" id="v4" data-v="4" data-xref="申命记 1:30; 约翰福音 10:16; 约翰福音 12:26"> <span className="woj">他把自己所有</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本没有“所有”。">a</a></sup><span className="woj">的羊</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本没有“羊”。">b</a></sup><span className="woj">带出去的时候，走在它们的前面。羊因为认得他的声音，就跟着他去。</span></span>
<span className="v" id="v5" data-v="5" data-xref="约翰一书 4:5–6; 歌罗西书 2:6–10; 马可福音 4:24"> <span className="woj">羊绝不会跟着陌生人，反而会逃避，因为不认得他的声音。”</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 56:11; 诗篇 82:5; 箴言 28:5"> 耶稣对他们说了这个比喻，他们却不明白他说的是什么。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约翰福音 14:6; 以弗所书 2:18; 约翰福音 10:1"> 因此耶稣又说：<span className="woj">“我确确实实地告诉你们：我就是羊的门。</span></span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 34:2; 耶利米书 23:1; 约翰福音 10:1"> <span className="woj">所有在我以前来的，是贼、是强盗，因此羊没有听从他们。</span></span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 14:6; 以弗所书 2:18; 约翰福音 10:7"> <span className="woj">我就是门。人如果通过我进来，就将得救，而且进进出出，将找到牧草。</span></span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 19:10; 约翰福音 6:51; 约翰福音 12:47"> <span className="woj">盗贼来，无非是要偷窃、宰杀、毁灭；而我来是要他们得生命，并且得的更丰盛。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约翰福音 10:14–15; 诗篇 23:1; 约翰福音 15:13"> <span className="woj">“我就是好牧人。好牧人为羊舍弃自己的生命；</span></span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 20:29; 撒迦利亚书 11:16–17; 以西结书 34:2–6"> <span className="woj">那雇来的不是牧人，羊也不是自己的，他看见狼来了，撇下羊就逃。这样，狼就抢夺羊，把它们驱散了。</span></span>
<span className="v" id="v13" data-v="13" data-xref="腓立比书 2:20; 约翰福音 12:6; 使徒行传 18:17"> <sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附“那雇来的会逃跑，”。">c</a></sup><span className="woj">这是因为那人是雇来的，并不顾念羊的事。</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="约翰福音 10:27; 约翰福音 10:11; 提摩太后书 2:19"> <span className="woj">“我就是好牧人。我认识那属于我的，那属于我的也认识我，</span></span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 1:4; 约翰福音 10:11; 以赛亚书 53:10"> <span className="woj">就像父认识我，我也认识父那样，而且我为羊舍弃自己的生命。</span></span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 56:8; 约翰福音 11:52; 彼得前书 2:25"> <span className="woj">我另外有羊，不是这圈里的。我必须把他们带来，他们会听我的声音，并且合成一群，同归一个牧人。</span></span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 10:18; 约翰福音 10:11; 希伯来书 2:9"> <span className="woj">父之所以爱我，是因为我舍弃自己的生命，好把它再取回来。</span></span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 2:9; 提多书 2:14; 约翰福音 2:19–21"> <span className="woj">没有人夺去我的生命，是我自愿舍弃的。我有权柄舍弃生命，也有权柄再把它取回来。这命令，我已经从我父领受了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约翰福音 9:16; 哥林多前书 3:3; 约翰福音 7:40–43"> 因这些话，犹太人中又产生了分裂。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 7:20; 马可福音 3:21; 约翰福音 8:47–48"> 其中有许多人说：“他有鬼魔附身，发疯了！何必听他的呢？”</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 4:11; 以赛亚书 35:5–6; 诗篇 94:9"> 另有些人说：“这些话不是有鬼魔附身的人说的！鬼魔难道能开瞎子的眼睛吗？”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 在耶路撒冷，当时正是献殿节。那时候是冬天。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 5:12; 使徒行传 3:11"> 耶稣正在圣殿的所罗门柱廊上走着，</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 22:67–70; 约翰福音 1:19; 约翰福音 8:25"> 犹太人围住了他，说：“你还让我们猜疑多久呢？如果你是基督，就明确地告诉我们吧！”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 10:38; 约翰福音 8:58; 约翰福音 14:11"> 耶稣回答：<span className="woj">“我告诉过你们，你们却不相信。我奉我父的名所行的这些事为我做见证；</span></span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 8:47; 哥林多后书 4:3–4; 约翰福音 12:37–40"> <span className="woj">可是你们不信，因为</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附“就像我告诉过你们那样，”。">d</a></sup><span className="woj">你们不是我的羊。</span></span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 10:16; 约翰福音 10:14; 启示录 3:20"> <span className="woj">我的羊听我的声音，我也认识他们，他们也跟着我；</span></span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 6:39–40; 约翰福音 6:37; 约翰福音 3:15–16"> <span className="woj">并且我赐给他们永恒的生命，他们绝不会灭亡，直到永远。谁也不能把他们从我手中夺走。</span></span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 6:37; 约翰福音 17:2; 约翰福音 17:9"> <span className="woj">我父，就是把他们</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="把他们——辅助词语。">e</a></sup><span className="woj">赐给我的那一位，他比一切更大。谁也不能把他们从我</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本没有“我”。">f</a></sup><span className="woj">父的手中夺走。</span></span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 1:1–2; 约翰福音 14:9; 约翰福音 17:21–23"> <span className="woj">我与父是一体的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 5:18; 约翰福音 8:59; 撒母耳记上 30:6"> 犹太人又拿起石头要砸死他。</span>
<span className="v" id="v32" data-v="32" data-xref="约翰一书 3:12; 约翰福音 5:36; 诗篇 35:12"> 耶稣对他们说：<span className="woj">“我把很多从父而来的美好之事显给你们看了，你们是为哪一件要用石头砸死我呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约翰福音 5:18; 利未记 24:16; 约翰福音 10:30"> 他们回答：“我们不会为了什么美好之事用石头砸死你，而是为了你说亵渎的话！因为你不过是人，竟然把自己当做神！”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="诗篇 82:6–7; 出埃及记 7:1; 诗篇 82:1"> 耶稣对他们说：<span className="woj">“你们的</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本没有“你们的”。">g</a></sup><span className="woj">律法上不是写道‘我说你们是神’吗？</span></span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 24:35; 罗马书 13:1; 路加福音 16:17"> <span className="woj">而经上的话是不能废除的。神既然称那些承受他话语</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="话语——或译作“道”。">h</a></sup><span className="woj">的人为神，</span></span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 5:17–18; 约翰福音 3:17; 耶利米书 1:5"> <span className="woj">那么，难道因为我说了‘我是神的儿子’，你们就对父所分别为圣、并差派到世上来的那一位说‘你说了亵渎的话’吗？</span></span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 15:24; 约翰福音 10:25; 约翰福音 12:37–40"> <span className="woj">如果我没有做我父的事，你们就不该相信我；</span></span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 14:20; 约翰福音 10:25; 约翰福音 10:30"> <span className="woj">但如果我做了，你们即使不相信我，也该相信这些事。这样，你们就会知道并体会</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="体会——有古抄本作“相信”。">i</a></sup><span className="woj">父在我里面，我也在父</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="父——有古抄本作“他”。">j</a></sup><span className="woj">里面。”</span></span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 7:30; 约翰福音 8:59; 约翰福音 7:44"> 于是他们又试图抓耶稣，他却从他们的手中脱离出来。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="约翰福音 1:28; 约翰福音 11:54; 约翰福音 7:1"> 耶稣又前往约旦河对岸，到约翰当初施洗的地方，住在那里。</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 1:33–34; 约翰福音 1:29–30; 马可福音 1:37"> 有许多人来到他那里，说：“虽然约翰没有行过神迹，但约翰所说的有关这个人的事，都是真的。”</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 4:41; 约翰福音 2:23; 约翰福音 7:31"> 于是有许多人在那里信了耶稣。</span>
</div>
</div>

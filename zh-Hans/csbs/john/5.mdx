<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 16:16; 出埃及记 23:14–17; 出埃及记 34:23"> 这些事以后，犹太人的一个节日到了，耶稣就上耶路撒冷去。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米记 12:39; 尼希米记 3:1; 尼希米记 3:32"> 在耶路撒冷的羊门附近有一个池子，希伯来语<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="希伯来语——或译作“亚兰语”。">a</a></sup>叫做“贝示达<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="贝示达——有古抄本作“贝特扎塔”；或译作“贝特斯达”或“毕士大”。">b</a></sup>”，那里有五道柱廊。</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 3:1–4; 路加福音 7:22; 马太福音 15:30"> 柱廊里躺着一群患病的，有瞎眼的、瘸腿的、瘫痪的。他们正等着池水动起来，</span>
<span className="v" id="v4" data-v="4"> 因为主的天使按时下到池子里搅动池水。每次水动起来时，第一个下到池子里的人，无论患什么病都会痊愈。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="-4 有古抄本没有“他们正等着……痊愈。”">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 3:2; 路加福音 8:43; 马可福音 9:21"> 那里有一个人，病了三十八年。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 18:41; 希伯来书 4:15; 希伯来书 4:13"> 耶稣见这个人躺在那里，知道他已经病了很久，就问他：<span className="woj">“你想痊愈吗？”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="诗篇 72:12; 申命记 32:36; 哥林多前书 9:24"> 那个病人回答：“先生，池水被搅动的时候，没有人把我放进池子里；而正当我要下去的时候，别人总比我先下去。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 5:24; 马太福音 9:6; 马可福音 2:11"> 耶稣对他说：<span className="woj">“起来，拿起你的垫子走路吧！”</span></span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 3:7–8; 约翰福音 9:14; 马可福音 3:2–4"> 那个人立刻痊愈了，就拿起他的垫子开始走路。<br />那天是安息日，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 17:21; 路加福音 6:2; 约翰福音 9:16"> 所以那些犹太人对那得了痊愈的人说：“今天是安息日，你拿着垫子是不可以的！”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马可福音 2:9–11; 约翰福音 9:16"> 他就回答：“是那个使我痊愈的人对我说‘拿起你的垫子走路吧。’”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 21:23; 士师记 6:29; 罗马书 10:2"> 他们问：“对你说‘拿起<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附“你的”。">d</a></sup>垫子走路’的那个人是谁？”</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 4:30; 路加福音 24:31; 约翰福音 8:59"> 那得了痊愈的人并不知道他是谁，因为那里有一群人，而耶稣已经抽身离去了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="约翰福音 8:11; 利未记 26:23–24; 诗篇 118:18"> 这些事以后，耶稣在圣殿里找到他，对他说：<span className="woj">“看，你已经痊愈了。不要再犯罪，免得更严重的事临到你。”</span></span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 9:11–12; 约翰福音 4:29; 约翰福音 9:25"> 那个人就去向那些犹太人报告说，使他痊愈的是耶稣。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰福音 10:39; 约翰福音 7:19–20; 马可福音 3:6"> 那些犹太人之所以逼迫耶稣，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附“想要杀他，”。">e</a></sup>是因为他在安息日做这些事。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 9:4; 约翰福音 14:10; 歌罗西书 1:16"> 耶稣却对他们说：<span className="woj">“直到如今，我父在做工，我也在做工。”</span></span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 10:30; 约翰福音 10:33; 约翰福音 19:7"> 为此，那些犹太人更想要杀他，因为他不仅干犯了安息日，还称神是他的父，把自己当做与神同等的。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约翰福音 12:49; 约翰福音 8:28; 约翰福音 14:10"> 耶稣对他们说：<span className="woj">“我确确实实地告诉你们：子凭着自己什么也不能做，只有看见父所做的，子才能做，因为父所做的事，子也同样地做。</span></span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 3:35; 马太福音 3:17; 约翰福音 17:26"> <span className="woj">原来，父喜爱子，把自己所做的一切都给他看，还要把比这些更大的事给他看，使你们感到惊奇。</span></span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 8:11; 申命记 32:39; 约翰福音 11:25"> <span className="woj">因为父怎样使死人复活，赐他们生命，子也照样按自己的意愿赐人生命。</span></span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 5:27; 使徒行传 17:31; 哥林多后书 5:10"> <span className="woj">事实上，父并不审判任何人，而把一切审判的事都交给了子，</span></span>
<span className="v" id="v23" data-v="23" data-xref="约翰一书 2:23; 路加福音 10:16; 马太福音 11:27"> <span className="woj">好使所有的人都尊重子，就像尊重父那样。不尊重子的，就是不尊重派他来的父。</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约翰福音 3:36; 约翰福音 6:40; 约翰一书 5:11–13"> <span className="woj">“我确确实实地告诉你们：谁听我的话，又相信派我来的那一位，谁就有永恒的生命。他不但不被定罪，而且已经出死入生了。</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 5:28; 以弗所书 5:14; 以弗所书 2:5"> <span className="woj">“我确确实实地告诉你们：时候就要到了，现在就是了！当死人听见神儿子的声音时，听到的人就将活了。</span></span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 11:26; 约翰福音 1:4; 出埃及记 3:14"> <span className="woj">原来，父怎样在自己里面有生命，也照样使子在自己里面有生命；</span></span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 10:42; 约翰福音 5:22; 使徒行传 17:31"> <span className="woj">并且把审判的权柄交给了他，因为他是人子。</span></span>
<span className="v" id="v28" data-v="28" data-xref="启示录 20:12; 帖撒罗尼迦前书 4:14–17; 以赛亚书 26:19"> <span className="woj">你们不要为此感到惊奇：时候就要到了！那时所有在坟墓里的人，都会听到他的声音，</span></span>
<span className="v" id="v29" data-v="29" data-xref="但以理书 12:2–3; 罗马书 2:6–10; 使徒行传 24:15"> <span className="woj">并且要出来——行善的人复活得生命，作恶的人复活被定罪。</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约翰福音 6:38; 约翰福音 5:19; 约翰福音 4:34"> <span className="woj">“我凭自己什么也不能做。我怎么听见，就怎么审判，而且我的审判是公义的，因为我不求自己的意思，而求那派我来者</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附“——父”。">f</a></sup><span className="woj">的意思。</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="箴言 27:2; 约翰福音 8:54; 启示录 3:14"> <span className="woj">“如果我为自己做见证，我的见证就无效</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="无效——原文直译“不真实”。">g</a></sup><span className="woj">。</span></span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 1:33; 约翰福音 12:28–30; 约翰福音 5:36–37"> <span className="woj">为我做见证的另有一位，并且我知道，他为我做的见证是有效</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有效——原文直译“真实”。">h</a></sup><span className="woj">的。</span></span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 1:29–34; 约翰福音 3:26–36; 约翰福音 1:15–27"> <span className="woj">你们曾经派人到约翰那里，他为真理做了见证。</span></span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 19:41–42; 约翰福音 20:31; 约翰一书 5:9"> <span className="woj">其实我所接受的见证不是从人来的。不过我说这些话，是为了要你们得救。</span></span>
<span className="v" id="v35" data-v="35" data-xref="彼得后书 1:19; 约翰福音 1:7–8; 马太福音 11:11"> <span className="woj">约翰是一盏燃烧发光的灯，你们情愿在他的光里快乐一时。</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="约翰福音 10:25; 约翰福音 10:37–38; 约翰福音 15:24"> <span className="woj">“我有比约翰更大的见证，因为父交给我工作要我去完成。我现在做的这些工作正为我见证：就是父差派了我。</span></span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 8:18; 约翰福音 1:18; 马太福音 3:17"> <span className="woj">派我来的父也亲自为我做了见证。你们从来没有听到他的声音，也没有看到他的相貌，</span></span>
<span className="v" id="v38" data-v="38" data-xref="约翰一书 2:14; 申命记 6:6–9; 约翰福音 12:44–48"> <span className="woj">更没有把他的话语</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="话语——或译作“道”。">i</a></sup><span className="woj">存在你们里面，因为你们不信他所派来的那一位。</span></span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 24:27; 路加福音 24:44; 彼得后书 1:19–21"> <span className="woj">你们查考经文，因你们以为从中可以得到永恒的生命。其实这经文就是为我做见证的。</span></span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 3:19; 约翰福音 1:11; 诗篇 81:11"> <span className="woj">可是你们不肯到我这里来得生命。</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="约翰福音 7:18; 约翰福音 5:34; 帖撒罗尼迦前书 2:6"> <span className="woj">“我不接受从人而来的荣耀。</span></span>
<span className="v" id="v42" data-v="42" data-xref="约翰一书 4:20; 约翰一书 3:17; 约翰福音 2:25"> <span className="woj">不过我了解你们，你们里面没有属神的爱。</span></span>
<span className="v" id="v43" data-v="43" data-xref="约翰福音 10:25; 马太福音 24:5; 约翰福音 17:4–6"> <span className="woj">我奉我父的名来了，你们却不接受我；如果有别人奉自己的名而来，你们倒会接受他。</span></span>
<span className="v" id="v44" data-v="44" data-xref="约翰福音 12:43; 罗马书 2:29; 腓立比书 2:3"> <span className="woj">你们彼此接受荣耀，却不寻求从独一的神而来的荣耀，那怎么能信呢？</span></span>
<span className="v" id="v45" data-v="45" data-xref="罗马书 3:19–20; 加拉太书 3:10; 哥林多后书 3:7–11"> <span className="woj">不要以为我将要在父面前控告你们，有一位控告你们的，就是你们所仰赖的摩西。</span></span>
<span className="v" id="v46" data-v="46" data-xref="申命记 18:15; 申命记 18:18–19; 约翰福音 1:45"> <span className="woj">事实上，如果你们信摩西，就会信我，因为他写了关于我的事；</span></span>
<span className="v" id="v47" data-v="47" data-xref="路加福音 16:31; 路加福音 16:29"> <span className="woj">如果你们不相信他所写的，又怎么会相信我的话呢？”</span></span>
</div>

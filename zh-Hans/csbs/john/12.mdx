<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 14:3–8; 约翰福音 11:1; 路加福音 24:50"> 逾越节前六天，耶稣来到<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附“曾经死过的”。">a</a></sup>拉撒路所在的伯大尼，就是他使拉撒路从死人中复活的地方。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 22:27; 路加福音 10:38–42; 启示录 3:20"> 有些人在那里为耶稣预备晚餐，玛妲正伺候着。拉撒路也在与耶稣坐席的人当中。</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 14:3–9; 约翰福音 11:2; 路加福音 10:38–39"> 这时候，玛丽亚拿了一斤<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一斤——原文为“1力揣”；或译作“1磅”。力揣=罗马磅；1力揣=0.34公斤。">b</a></sup>极其贵重的纯哪哒香液，膏抹耶稣的脚，又用自己的头发擦干，屋子里就充满了香液的气味。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="马太福音 10:4; 撒母耳记上 17:28–29; 约翰福音 13:2"> 他的一个门徒，就是后来要出卖耶稣的那个加略人犹大却说：</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 18:22; 路加福音 12:33; 马可福音 14:4–5"> “为什么不把这香液卖三百个银币<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="三百个银币——原文为“300得拿利”。1得拿利=约1日工资的罗马银币。">c</a></sup>去分给穷人呢？”</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 13:29; 诗篇 50:16–20; 雅各书 2:6"> 他说这话，并不是因为顾念穷人，而是因为他是个贼。他管钱包，常常拿走其中所存的。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 26:12; 马可福音 14:6; 马太福音 27:57–60"> 耶稣说：<span className="woj">“由她吧！她是为我安葬的日子而保存的。</span></span>
<span className="v" id="v8" data-v="8" data-xref="申命记 15:11; 马可福音 14:7; 马太福音 26:11"> <span className="woj">要知道，你们总是有穷人与你们在一起，但你们不总是有我。”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 4:14; 约翰福音 11:43–45; 使徒行传 3:10–11"> 有一大群犹太人知道耶稣在那里，就来了。他们不仅是为了耶稣的缘故，也是为了看拉撒路，就是耶稣使他从死人中复活的那个人。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 16:31; 马太福音 2:16; 约翰福音 11:47–53"> 于是祭司长们就商议，连拉撒路也要杀掉，</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 11:45; 约翰福音 12:18; 使徒行传 13:45"> 因为有许多犹太人为了拉撒路的缘故，离开他们，信了耶稣。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="马可福音 11:7–10; 马太福音 21:4–9; 路加福音 19:35–38"> 第二天，一大群上来过节的人听说耶稣要来到耶路撒冷，</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 118:25–26; 启示录 15:3; 马太福音 21:9–11"> 就拿着棕榈树枝出去迎接他，欢呼说：<br /><span className="pl pl-1">“和散那！</span><br /><span className="pl pl-1">奉主名而来的那一位，</span><br /><span className="pl pl-1">以色列的王啊，</span><br /><span className="pl pl-1">是蒙祝福的！”</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒迦利亚书 9:9; 马可福音 11:1–7; 马太福音 21:1–7"> 耶稣找来一头驴驹，骑在上面，正如经上所记：</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 9:9; 以赛亚书 62:11; 西番雅书 3:16–17"> “锡安的女儿啊，不要怕！看哪，你的王骑着驴驹来了！”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰福音 2:22; 约翰福音 14:26; 约翰福音 7:39"> 耶稣的门徒们当初不明白这些事，等到耶稣得了荣耀以后，才想起这些话是指着他写的，人们果然向他做了这些事。</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 1:2; 约翰一书 5:9–12; 约翰福音 19:35"> 当耶稣呼唤拉撒路从坟墓中出来，使他从死人中复活的时候，那些与耶稣在一起的众人就见证了这件事。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 12:11"> 众人之所以也去迎接他，是因为他们听说他行了这神迹。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 17:6; 诗篇 22:27; 约翰一书 2:2"> 于是法利赛人互相说：“可见你们真没用！看，这世界都跟随他去了。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约翰福音 7:35; 以赛亚书 11:10; 使徒行传 17:4"> 当时，上来过节敬拜的人中，有一些希腊人。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 2:2; 路加福音 19:2–4; 约翰福音 6:40"> 这些人来到加利利的伯赛达人腓力那里，求他说：“先生，我们想见耶稣。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马可福音 10:13–14; 路加福音 9:49–50; 约翰福音 1:40–41"> 腓力去告诉安得烈，安得烈和腓力就去告诉耶稣。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 13:31–32; 约翰福音 17:1–5; 以赛亚书 60:9"> 耶稣回答他们，说：<span className="woj">“人子得荣耀的时候到了！</span></span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 15:36–38; 以赛亚书 53:10–12; 希伯来书 2:9–10"> <span className="woj">我确确实实地告诉你们：一粒麦子如果不落在地里死去，它仍然是一粒；如果死了，就结出很多子粒</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="子粒——或译作“果实”。">d</a></sup><span className="woj">来。</span></span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 10:39; 路加福音 9:23–24; 马可福音 8:35"> <span className="woj">爱惜自己生命的，就失去生命；在这世上恨恶自己生命的，将保全生命到永生。</span></span>
<span className="v" id="v26" data-v="26" data-xref="歌罗西书 3:24; 加拉太书 1:10; 撒母耳记上 2:30"> <span className="woj">一个人如果要服事我，就当跟从我；我在哪里，我的仆人也将要在哪里。如果有人服事我，父将尊重他。</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约翰福音 12:23; 希伯来书 5:7; 马太福音 26:42"> <span className="woj">“现在我的灵魂烦扰。我该说什么呢？说‘父啊，救我脱离这时刻’吗？但我正是为了这时刻而来的。</span></span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 13:31–32; 马太福音 26:42; 启示录 5:9–14"> <span className="woj">父啊，愿你荣耀你的名</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="名——有古抄本作“儿子”。">e</a></sup><span className="woj">！”</span><br />这时候，有声音从天上传来：“我已经荣耀了我的名，还要再荣耀！”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约伯记 37:2–5; 启示录 6:1; 启示录 14:2"> 站在那里的众人听见了，就说：“打雷了。”另有人说：“是天使在对他说话。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约翰福音 11:42; 约翰福音 11:15; 约翰福音 5:34"> 耶稣就回答说：<span className="woj">“这声音不是为我，而是为你们来的。</span></span>
<span className="v" id="v31" data-v="31" data-xref="哥林多后书 4:4; 约翰一书 5:19; 约翰一书 3:8"> <span className="woj">现在，是这世界受审判的时候了；现在，世界的那掌权者要被赶出去了。</span></span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 3:14; 约翰福音 8:28; 彼得前书 2:24"> <span className="woj">至于我，当我从地上被举起来的时候，就会吸引所有的人归向我。”</span></span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 18:32; 约翰福音 21:19"> 耶稣说这话是指自己将要怎样死。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="以西结书 37:24–25; 以赛亚书 9:7; 但以理书 7:14"> 众人回答他：“我们从律法中听到，基督是永远长存的。你怎么说‘人子必须被举起来’呢？这‘人子’到底是谁？”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="约翰福音 12:46; 约翰福音 16:16; 以弗所书 5:8"> 耶稣说：<span className="woj">“光在你们当中的时候不多了。要趁着有光的时候行走，免得黑暗抓住你们！因为在黑暗里行走的人，不知道自己往哪里去。</span></span>
<span className="v" id="v36" data-v="36" data-xref="以弗所书 5:8; 约翰福音 8:59; 使徒行传 13:47–48"> <span className="woj">你们要趁着有光的时候信这光，好使你们成为光明的儿女。”</span>耶稣说了这些话，就离开他们被隐藏了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v37" data-v="37" data-xref="路加福音 16:31; 约翰福音 1:11; 约翰福音 15:24"> 耶稣虽然在他们面前行了这么多神迹，他们仍然不信他。</span>
<span className="v" id="v38" data-v="38" data-xref="以赛亚书 53:1; 罗马书 10:16; 罗马书 10:20"> 这是为要应验先知以赛亚所说的话：<br /><span className="pl pl-1">“主啊，我们所传的，有谁相信了？</span><br /><span className="pl pl-1">主的膀臂</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="膀臂——意义为“大能”。">f</a></sup><br /><span className="pl pl-1">，向谁显示了？”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v39" data-v="39" data-xref="约翰福音 10:38; 约翰福音 5:44; 彼得后书 2:14"> 他们之所以不能相信，是因为以赛亚又说过：</span>
<span className="v" id="v40" data-v="40" data-xref="以赛亚书 6:10; 马太福音 13:13–15; 路加福音 8:10"> <span className="pl pl-1">“神使他们瞎了眼，</span><br /><span className="pl pl-1">硬了心，</span><br /><span className="pl pl-1">免得他们眼睛看见，</span><br /><span className="pl pl-1">心里明白，</span><br /><span className="pl pl-1">回转过来，</span><br /><span className="pl pl-1">我就使他们痊愈。”</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 6:1–5; 以赛亚书 6:9–10; 约翰福音 1:14"> 以赛亚说了这些话，是因为看见了耶稣的荣耀<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="是因为看见了耶稣的荣耀——有古抄本作“是在他看见了耶稣的荣耀的时候”。">g</a></sup>，就讲论他的事。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="约翰福音 9:22; 约翰福音 7:13; 以赛亚书 51:7"> 不过甚至是首领当中也有许多信耶稣的。但是为了法利赛人的缘故，他们不敢承认，免得被赶出会堂，</span>
<span className="v" id="v43" data-v="43" data-xref="约翰福音 5:44; 马太福音 23:5–7; 约翰福音 5:41"> 这是因为他们喜爱人的荣耀，胜过喜爱神的荣耀。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="马太福音 10:40; 约翰福音 13:20; 约翰福音 5:24"> 耶稣喊着说：<span className="woj">“信我的人，不是信我，而是信派我来的那一位。</span></span>
<span className="v" id="v45" data-v="45" data-xref="约翰福音 14:9–10; 哥林多后书 4:6; 歌罗西书 1:15"> <span className="woj">谁看见我，就是看见派我来的那一位。</span></span>
<span className="v" id="v46" data-v="46" data-xref="约翰福音 8:12; 诗篇 36:9; 约翰福音 9:5"> <span className="woj">我就是光。我来到世上，好让所有信我的人不住在黑暗里。</span></span>
<span className="v" id="v47" data-v="47" data-xref="约翰福音 3:17; 约翰福音 8:15–16; 约翰福音 12:48"> <span className="woj">如果有人听了我的话却不遵守</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="遵守——有古抄本作“相信”。">h</a></sup><span className="woj">，我不定他的罪；因为我来，不是为了定世人的罪，而是为了拯救世人。</span></span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 10:16; 希伯来书 9:27–28; 罗马书 2:16"> <span className="woj">拒绝我，又不接受我话的人，自有定他罪的：我所讲的话语，在末日要定他的罪。</span></span>
<span className="v" id="v49" data-v="49" data-xref="约翰福音 14:10; 约翰福音 8:26; 约翰福音 5:30"> <span className="woj">这是因为我没有凭自己讲话，而是派我来的父给了我命令，要我说什么和讲什么。</span></span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 17:3; 约翰福音 6:68; 约翰一书 5:20"> <span className="woj">我知道他的命令就是永恒的生命。所以我所讲的，正是照着父所告诉我的来讲的。”</span></span>
</div>

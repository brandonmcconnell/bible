<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 3:26; 约翰福音 3:22; 哥林多后书 4:5"> 耶稣<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="耶稣——有古抄本作“主”。">a</a></sup>知道，法利赛人听说他收门徒和施洗比约翰更多。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 10:48; 哥林多前书 1:13–17"> 其实不是耶稣亲自施洗，而是他的门徒们施洗。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 10:23; 约翰福音 10:40; 约翰福音 2:11"> 于是耶稣离开犹太地区，又前往加利利地区。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 17:11; 路加福音 2:49; 路加福音 9:51–52"> 但他定要经过撒玛利亚，</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 24:32; 创世记 33:19; 创世记 48:22"> 这样就来到了撒玛利亚的一个城，叫叙加。这城靠近雅各给他儿子约瑟的那块地，</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 4:15; 希伯来书 2:17; 马太福音 8:24"> 雅各井就在那里。耶稣因旅途劳累，就坐在井边。那时大约是中午十二点<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="中午十二点——原文为“第六时刻”。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 10:42; 列王纪上 17:10; 创世记 24:43"> 有一个撒玛利亚妇人来打水。耶稣对她说：<span className="woj">“请给我一点水喝。”</span></span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 9:13; 约翰福音 4:39; 约翰福音 4:5"> 那时，他的门徒们进城买食物去了。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 10:28; 马太福音 10:5; 列王纪下 17:24–41"> 撒玛利亚妇人对他说：“你是犹太人，怎么向我一个撒玛利亚妇人要水喝呢？”原来犹太人不和撒玛利亚人来往。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本没有“原来犹太人不和撒马利亚人来往。”">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约翰福音 4:14; 启示录 7:17; 约翰福音 7:37–39"> 耶稣回答她，说：<span className="woj">“如果你明白神的恩赐，也知道是谁对你说‘给我一点水喝’，你早就求他了，他也把活水给你了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 2:14; 约翰福音 3:4"> 妇人问：“先生，你没有打水的器具，井又深，你从哪里得来那活水呢？</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 4:6; 约翰福音 8:53; 马太福音 12:42"> 难道你比我们的先祖雅各更大吗？他给我们留下了这口井。他自己、他的子孙、他的牲畜都喝这井里的水！”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约翰福音 6:27; 以赛亚书 65:13–14; 路加福音 16:24"> 耶稣回答说：<span className="woj">“所有喝这水的人，还会再渴。</span></span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 7:38–39; 约翰福音 6:35; 以赛亚书 49:10"> <span className="woj">但如果有人喝了我给他的水，就绝不干渴，直到永远。不但如此，我给他的水将要在他里面成为泉源，一直涌流到永恒的生命。”</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 6:34; 罗马书 8:5; 诗篇 4:6"> 妇人说：“先生，请给我那水，使我不渴，我也不用到这里来打水了。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="希伯来书 4:13; 启示录 2:23; 约翰福音 4:18"> 耶稣说：<span className="woj">“去叫你的丈夫，再回到这里来。”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 妇人回答说：“我没有丈夫。”<br />耶稣说：<span className="woj">“你说你没有丈夫，这话没错。</span></span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 3:20; 哥林多前书 7:10–11; 罗马书 7:3"> <span className="woj">其实你已经有过五个丈夫，你现在有的，不是你的丈夫。你说的是真的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 7:39; 约翰福音 6:14; 约翰福音 9:17"> 妇人对他说：“先生，我看出你是先知！</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 12:6–7; 申命记 27:12; 申命记 11:29"> 我们的祖先在这山上敬拜，而你们却说敬拜的地方必须在耶路撒冷。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="提摩太前书 2:8; 玛拉基书 1:11; 约翰福音 4:23"> 耶稣说：<span className="woj">“妇人，你当相信我，时候就要到了！那时你们敬拜父，既不在这山上，也不在耶路撒冷。</span></span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 17:23; 以赛亚书 2:3; 罗马书 9:4–5"> <span className="woj">你们敬拜你们所不认识的；我们却敬拜我们所认识的，因为救恩是出自犹太人的。</span></span>
<span className="v" id="v23" data-v="23" data-xref="腓立比书 3:3; 约翰福音 5:25; 马太福音 15:7–9"> <span className="woj">然而，时候就要到了，现在就是了！那时真正敬拜的人，要在灵里和真理中敬拜父，因为父就是想要这样的人来敬拜他。</span></span>
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 3:17; 马太福音 15:8–9; 腓立比书 3:3"> <span className="woj">神是灵，敬拜他的人必须在灵里和真理中敬拜。”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 1:49; 但以理书 9:24–26; 约翰福音 1:41–42"> 妇人说：“我知道那称为基督的弥赛亚要来。他来的时候，就会把一切都传讲给我们。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="约翰福音 8:24; 马可福音 14:61–62; 罗马书 10:20–21"> 耶稣说：<span className="woj">“这和你说话的我，就是那一位。”</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 7:39; 约翰福音 4:8–9"> 正在这时，他的门徒们回来了。他们见耶稣与一个妇人一同说话，就感到惊奇。只是没有人问“你想要什么？”或“你为什么与她说话？”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约翰福音 4:7; 路加福音 24:33; 马可福音 16:8–10"> 那妇人放下她的水罐，回到城里告诉人们说：</span>
<span className="v" id="v29" data-v="29" data-xref="启示录 22:17; 哥林多前书 14:24–25; 约翰福音 4:25"> “你们来看！有个人把我过去所做的一切都说了出来，这个人会不会就是基督呢？”</span>
<span className="v" id="v30" data-v="30" data-xref="罗马书 5:20; 使徒行传 8:5–8; 路加福音 17:16–18"> 大家就出城，来到耶稣那里。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 1:38; 创世记 24:33; 使徒行传 16:30–34"> 这其间，门徒们劝耶稣说：“拉比，请吃。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="约伯记 23:12; 诗篇 119:103; 约翰福音 4:34"> 但耶稣说：<span className="woj">“我有食物吃，是你们所不知道的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 16:6–11; 路加福音 9:45"> 门徒彼此问：“难道有人拿东西来给他吃了吗？”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="约翰福音 6:38; 约翰福音 5:30; 约伯记 23:12"> 耶稣对他们说：<span className="woj">“我的食物就是遵行那派我来者的旨意，并且完成他的工作。</span></span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 10:2–3; 马太福音 9:37–38; 约翰福音 4:30"> <span className="woj">你们不是说‘收割的季节还有四个月才到’吗？看哪，我告诉你们：举目向田里观望，庄稼已经成熟</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="成熟——原文直译“白了”。">d</a></sup><span className="woj">，可以收割了！</span></span>
<span className="v" id="v36" data-v="36" data-xref="雅各书 5:19–20; 罗马书 1:13; 哥林多前书 3:5–9"> <span className="woj">收割的人得酬报，收集果实归入永恒的生命，好使撒种的和收割的一同快乐。</span></span>
<span className="v" id="v37" data-v="37" data-xref="弥迦书 6:15; 约伯记 31:8; 路加福音 19:21"> <span className="woj">实际上，这样的说法是真实的：‘一人撒种，另一个人收割。’</span></span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 1:7; 历代志下 36:15; 使徒行传 10:42–43"> <span className="woj">我派你们去收你们未曾劳苦的；别人劳苦了，你们也进入了他们的劳苦中。”</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="约翰福音 4:29; 约翰福音 4:5; 约翰福音 10:41–42"> 当时，那城里有许多撒玛利亚人信了耶稣。这是因为那妇人见证说：“他把我过去所做的一切都说了出来。”</span>
<span className="v" id="v40" data-v="40" data-xref="启示录 3:20; 使徒行传 16:15; 路加福音 24:29"> 这样，撒玛利亚人来到耶稣那里的时候，请求他住在他们那里。于是耶稣在那里住了两天。</span>
<span className="v" id="v41" data-v="41" data-xref="哥林多前书 2:4–5; 使徒行传 1:8; 使徒行传 8:12"> 后来，因着耶稣的话，信的人就更多了。</span>
<span className="v" id="v42" data-v="42" data-xref="约翰一书 4:14; 约翰福音 1:29; 约翰一书 5:20"> 他们告诉那妇人说：“现在我们信，不再是因为你的话，而是因为我们亲耳听到了，并且知道这一位真是世界的救主<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附“——基督”。">e</a></sup>。”</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="马太福音 4:13; 罗马书 15:8; 马可福音 7:27–28"> 两天后，耶稣离开了那里，前往加利利地区。</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 13:57; 路加福音 4:24; 马可福音 6:4"> 他曾亲自见证说，先知在自己的家乡得不到尊敬。</span>
<span className="v" id="v45" data-v="45" data-xref="约翰福音 2:23; 约翰福音 2:13–16; 申命记 16:16"> 当耶稣来到加利利地区，加利利人就接受他，因为他们也曾经上耶路撒冷去过节，看到耶稣节日期间在那里所行的一切事。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="约翰福音 2:1–11; 路加福音 7:2; 何西阿书 5:15"> 耶稣又来到加利利的迦拿，就是他把水变成酒的地方。有一个大臣，他的儿子在迦百农患了病。</span>
<span className="v" id="v47" data-v="47" data-xref="约翰福音 4:3; 约翰福音 11:21; 约翰福音 11:32"> 这个人听说耶稣从犹太来到加利利，就到耶稣那里去，请求他下去治愈他的儿子，因为他的儿子快要死了。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="约翰福音 20:29; 希伯来书 2:4; 哥林多前书 1:22"> 耶稣对他说：<span className="woj">“你们如果没有看见神迹和奇事，你们就绝不会信！”</span></span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="马可福音 5:23; 诗篇 88:10–12; 诗篇 40:17"> 那大臣对耶稣说：“先生，求你在我的孩子还没有死之前下来吧！”</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="马太福音 8:13; 马可福音 7:29–30; 罗马书 4:20–21"> 耶稣对他说：<span className="woj">“你回去吧，你的儿子活了！”</span>那人相信耶稣的话，就回去了。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="列王纪上 17:23; 约翰福音 4:50; 约翰福音 4:53"> 他正下去的时候，他的奴仆们迎着他来<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附“报告”。">f</a></sup>，告诉他孩子活了。</span>
<span className="v" id="v52" data-v="52"> 他就问孩子好转的时间，他们说：“昨天下午一点<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="下午一点——原文为“第七时刻”。">g</a></sup>，烧就退了。”</span>
<span className="v" id="v53" data-v="53" data-xref="诗篇 107:20; 路加福音 19:9; 使徒行传 16:34"> 这位父亲就知道，那正是耶稣说<span className="woj">“你的儿子活了”</span>的时间。于是他自己和全家人都信了。</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="约翰福音 4:45; 约翰福音 2:1–11"> 这是耶稣从犹太回到加利利以后所行的第二件神迹。</span>
</div>
</div>

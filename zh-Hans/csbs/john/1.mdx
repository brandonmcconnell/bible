<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="创世记 1:1; 约翰福音 17:5; 启示录 19:13"> <span className="pl pl-1">太初有道，</span><br /><span className="pl pl-1">道与神同在，</span><br /><span className="pl pl-1">道就是神。</span><br /></span>
<span className="v" id="v2" data-v="2"> <span className="pl pl-1">这道太初与神同在。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 1:16–17; 哥林多前书 8:6; 启示录 4:11"> <span className="pl pl-1">万有是藉着他而成的；</span><br /><span className="pl pl-1">凡所成的，</span><br /><span className="pl pl-1">没有一样不是藉着他而成的。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 8:12; 约翰福音 12:46; 约翰福音 5:26"> <span className="pl pl-1">生命在他里面，</span><br /><span className="pl pl-1">这生命就是人的光。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 3:19–20; 约翰福音 12:36–40; 哥林多前书 2:14"> <span className="pl pl-1">这光在黑暗中照耀，</span><br /><span className="pl pl-1">黑暗却没有胜过</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="胜过——或译作“领会”或“掌握”或“接受”。">a</a></sup><br /><span className="pl pl-1">这光。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="玛拉基书 3:1; 约翰福音 3:28; 以赛亚书 40:3–5"> <span className="pl pl-1">有一个人受神的差派而来，</span><br /><span className="pl pl-1">他名叫约翰。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 19:4; 约翰福音 1:36; 约翰福音 5:33–35"> <span className="pl pl-1">他为见证而来，</span><br /><span className="pl pl-1">是要为这光做见证，</span><br /><span className="pl pl-1">好让人都藉着他相信。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 1:20; 约翰福音 3:28; 使徒行传 19:4"> <span className="pl pl-1">他不是这光，</span><br /><span className="pl pl-1">而是要为这光做见证。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 12:46; 约翰福音 1:4; 约翰一书 2:8"> <span className="pl pl-1">这光是真光，</span><br /><span className="pl pl-1">来到这世界照亮每个人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="约翰福音 17:25; 约翰一书 3:1; 哥林多前书 2:8"> <span className="pl pl-1">他在这世界，</span><br /><span className="pl pl-1">世界也是藉着他而成的，</span><br /><span className="pl pl-1">世界却不认识他。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:14; 以赛亚书 53:2–3; 约翰福音 3:32"> <span className="pl pl-1">他来到自己的地方，</span><br /><span className="pl pl-1">自己的人却不接受他。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 3:26; 罗马书 8:14; 约翰一书 3:1"> <span className="pl pl-1">但是所有接受他的，</span><br /><span className="pl pl-1">就是信他名的人，</span><br /><span className="pl pl-1">他就赐给他们权柄成为神的儿女。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="约翰一书 3:9; 雅各书 1:18; 彼得前书 1:23"> <span className="pl pl-1">他们不是由血缘、</span><br /><span className="pl pl-1">或肉体的意愿、</span><br /><span className="pl pl-1">或人的意志所生的，</span><br /><span className="pl pl-1">而是由神所生的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="约翰一书 4:9; 提摩太前书 3:16; 以赛亚书 40:5"> <span className="pl pl-1">道成了肉身，</span><br /><span className="pl pl-1">居住在我们中间。</span><br /><span className="pl pl-1">我们看到了他的荣耀，</span><br /><span className="pl pl-1">正是从父而来的独生子的荣耀，</span><br /><span className="pl pl-1">充满了恩典和真理。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 3:11; 歌罗西书 1:17; 路加福音 3:16"> <span className="pl pl-1">约翰为他做见证，呼喊说：</span><br /><span className="pl pl-1">“这一位就是我曾说过的，</span><br /><span className="pl pl-1">‘那在我之后来的，已成为在我前面的，</span><br /><span className="pl pl-1">因为他在我之前就已经存在。’”</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 1:19; 罗马书 5:2; 以弗所书 2:5–10"> <span className="pl pl-1">原来从他的丰盛完美中，</span><br /><span className="pl pl-1">我们都领受了恩典，而且恩上加恩。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 6:14; 约翰福音 14:6; 罗马书 3:19–26"> <span className="pl pl-1">因为律法是藉着摩西赐下的，</span><br /><span className="pl pl-1">恩典和真理是藉着耶稣基督而来的。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 1:15; 约翰福音 6:46; 马太福音 11:27"> <span className="pl pl-1">从来没有人看见神，</span><br /><span className="pl pl-1">只有在父怀里的那位独生子——神，</span><br /><span className="pl pl-1">他将神表明了出来。</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 3:15–18; 约翰福音 10:24; 使徒行传 19:4"> 以下是约翰的见证。那时候，耶路撒冷的那些犹太人派了一些祭司和利未人到约翰那里去问他：“你是谁？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马可福音 1:7–8; 马太福音 3:11–12; 约翰福音 3:28–36"> 他就承认，并毫不否认地告白：“我不是基督。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="玛拉基书 4:5; 申命记 18:15–18; 马太福音 11:14"> 他们又问：“那么你是谁呢？是以利亚吗？”<br />他说：“我不是。”<br />“是那位先知<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="那位先知——《申命记》18:15。">b</a></sup>吗？”<br />他回答：“不是。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 24:13"> 于是他们问：“你到底是谁？好让我们给那些派我们来的人一个答复。你自己说，你是什么人？”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 40:3–5; 马可福音 1:3; 马太福音 3:3"> 约翰说：“正如先知以赛亚所说的，我就是在旷野里呼喊的声音：‘你们当修直<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="修直——或译作“修平”。">c</a></sup>主的道<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="道——或译作“路”。">d</a></sup>。’”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 11:53; 马太福音 23:13–15; 路加福音 11:39–44"> 那些被派来的人属于法利赛人，</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 18:18; 申命记 18:15; 约翰福音 1:20–22"> 他们又问约翰：“你既不是基督，又不是以利亚，也不是那位先知，那么，你为什么施洗呢？”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="约翰福音 1:10–11; 路加福音 3:16; 使徒行传 1:5"> 约翰回答说：“我用水<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="用水——或译作“在水里”。">e</a></sup>施洗，但有一位站在你们中间，是你们不认识的，</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 1:30; 马可福音 1:7; 马太福音 3:11"> 他是那在我之后来的，<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附“已成为在我前面的，”。">f</a></sup>我就是为他解鞋带也不配。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约翰福音 10:40; 约翰福音 3:23; 士师记 7:24"> 这些事发生在约旦河对岸的伯大尼<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="伯大尼——有古抄本作“伯达巴拉”。">g</a></sup>，就是约翰施洗的地方。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 53:7; 约翰一书 2:2; 约翰一书 3:5"> 第二天，约翰看见耶稣向他走来，就说：“看哪，神的羔羊，除去世人罪孽的！</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 1:27; 约翰福音 1:15; 路加福音 3:16"> 这一位就是我所说的‘那在我之后来的人，已成为在我前面的，因为在我之前他就存在了。’</span>
<span className="v" id="v31" data-v="31" data-xref="玛拉基书 3:1; 路加福音 1:17; 玛拉基书 4:2–5"> 我以前也不认识他，但为了让他向以色列显明，所以我来用水施洗。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马可福音 1:10; 路加福音 3:22; 马太福音 3:16"> 约翰又见证说：“我看到圣灵好像鸽子从天上降临，停留在他身上。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 1:5; 马太福音 3:11; 路加福音 3:16"> 我以前也不认识他，可是那派我用水施洗的对我说：‘如果你看见圣灵降临在谁身上，又停留在谁身上，谁就是用圣灵施洗的那一位。’</span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 2:7; 约翰福音 1:49; 诗篇 89:26–27"> 我看到了，就见证：这一位就是神的儿子<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="神的儿子——有古抄本作“神所拣选的”。">h</a></sup>。”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="约翰福音 3:25–26; 玛拉基书 3:16"> 过了一天，约翰和他的两个门徒又站在那里。</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 1:29; 彼得前书 1:19–20; 以赛亚书 65:1–2"> 约翰看着耶稣走过，就说：“看哪，神的羔羊！”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="罗马书 10:17; 约翰福音 1:43; 撒迦利亚书 8:21"> 那两个门徒听他说话，就跟从了耶稣。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 18:7; 约翰福音 3:2; 约翰福音 1:49"> 耶稣转过身来，看到他们跟着走，就问：<span className="woj">“你们寻找什么呢？”</span><br />他们对耶稣说：“拉比，你住在哪里呢？”——“拉比”翻译出来意思是“老师”。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 24:29; 马太福音 11:28–30; 约翰福音 6:37"> 耶稣说：<span className="woj">“你们来看吧！”</span>他们去了，看见耶稣住的地方，那天就住在他那里。那时大约是下午四点<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="下午四点——原文为“第十时刻”。">i</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="马可福音 1:16–20; 马太福音 4:18–22; 约翰福音 1:40–42"> 听见了约翰的话而跟从耶稣的两个人中，有一个是西门彼得的弟弟安得烈。</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 4:25; 约翰福音 1:45; 诗篇 89:20"> 安得烈先去找自己的哥哥<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="哥哥——原文直译“兄弟”。">j</a></sup>西门，对他说：“我们找到了弥赛亚。”——“弥赛亚”翻译出来就是“基督”。</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 21:15–17; 哥林多前书 3:22; 哥林多前书 15:5"> 他就带西门到耶稣那里。<br />耶稣注视着他，说：<span className="woj">“你是约翰</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="约翰——有古抄本作“约拿”。">k</a></sup><span className="woj">的儿子西门，你将被称为矶法。”</span>——“矶法”翻译出来就是“彼得<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="彼得——意思为“石头”。">l</a></sup>”。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="马太福音 9:9; 约翰福音 14:8; 以赛亚书 65:1"> 又过了一天，耶稣决定前往加利利地区。他找到腓力，对他说：<span className="woj">“你跟从我！”</span></span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="约翰福音 12:21; 马太福音 11:21; 马可福音 8:22"> 腓力来自伯赛达，与安得烈和彼得同乡。</span>
<span className="v" id="v45" data-v="45" data-xref="申命记 18:18–22; 路加福音 24:27; 弥迦书 5:2"> 腓力找到拿旦业<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="拿旦业——一般认为，此人与其他福音书和《使徒行传》中的巴多罗迈是同一个人。">m</a></sup>，对他说：“我们发现了摩西在律法上所写的，和先知们所记的那一位。他就是约瑟的儿子，拿撒勒人耶稣。”</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="约翰福音 7:52; 约翰福音 7:41–42; 约翰福音 4:29"> 拿旦业对他说：“拿撒勒还能出什么好的吗？”<br />腓力说：“你来看吧！”</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="启示录 14:5; 诗篇 32:2; 诗篇 73:1"> 耶稣看见拿旦业向他走来，就指着他说：<span className="woj">“看，一个真正的以色列人！他里面没有诡诈。”</span></span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="以赛亚书 65:24; 约翰福音 2:25; 诗篇 139:1–2"> 拿旦业对耶稣说：“你怎么知道我呢？”<br />耶稣回答说：<span className="woj">“腓力叫你以前，你还在无花果树下，我就看见你了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="西番雅书 3:15; 撒迦利亚书 9:9; 马太福音 27:42"> 拿旦业说：“拉比，你是神的儿子，你是以色列的王！”</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="约翰福音 11:40; 约翰福音 20:29; 路加福音 1:45"> 耶稣对他说：<span className="woj">“因为我说‘我看见你在无花果树下’，你就信吗？你将会看到比这更大的事。”</span></span>
<span className="v" id="v51" data-v="51" data-xref="创世记 28:12; 使徒行传 7:56; 路加福音 22:43"> 耶稣又对他说：<span className="woj">“我确确实实地告诉你们：你们将会看见天敞开了，神的天使们在人子上头，上去下来。”</span></span>
</div>

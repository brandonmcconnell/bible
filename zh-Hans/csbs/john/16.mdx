<span className="v" id="v2" data-v="2" data-xref="约翰福音 9:22; 使徒行传 26:9–11; 罗马书 10:2–3"> <span className="woj">他们将要把你们赶出会堂。不但如此，时候就要到了！那杀你们的人，都会以为自己是在事奉神</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以为自己是在事奉神——原文直译“以为是献上事奉给神”。">b</a></sup><span className="woj">。</span></span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 15:21; 约翰福音 17:25; 约翰福音 8:55"> <span className="woj">他们做这些事，是因为不认识父，也不认识我。</span></span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 14:29; 马可福音 13:23; 约翰福音 17:12–13"> <span className="woj">不过我把这些事告诉了你们，是为了当事情发生的时候，你们会记起我对你们说过了。我当初没有告诉你们这些事，是因为我一直与你们在一起。</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 13:36; 约翰福音 7:33; 约翰福音 16:28"> <span className="woj">“现在我要回到派我来的那一位面前，你们当中却没有人问我：‘你要到哪里去？’</span></span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 14:1; 约翰福音 16:20–22; 路加福音 24:17"> <span className="woj">只因为我对你们说了这些话，你们心里就充满了忧伤。</span></span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 14:26; 约翰福音 14:16–17; 约翰福音 15:26"> <span className="woj">但我把真相告诉你们：我离去对你们是有益处的，因为我如果不去，慰助者就不会到你们这里来；如果我去了，我就会派遣他到你们这里来。</span></span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 2:37; 犹大书 1:15; 撒迦利亚书 12:10"> <span className="woj">他来了，要在关于罪、关于义、关于审判的事上，使世界知罪。</span></span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 15:22–25; 约翰福音 8:23–24; 约翰福音 12:47–48"> <span className="woj">关于罪，是因为世界不信我；</span></span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 5:21; 彼得前书 3:18; 罗马书 10:3–4"> <span className="woj">关于义，是因为我到父那里去，而你们不再看到我了；</span></span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 12:31; 约翰一书 3:8; 希伯来书 2:14"> <span className="woj">关于审判，是因为世界的那掌权者已经被定罪了。</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马可福音 4:33; 约翰福音 15:15; 哥林多前书 3:1–2"> <span className="woj">“我还有很多事要告诉你们，可是你们现在担当不了，</span></span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 14:26; 哥林多前书 2:10–13; 约翰福音 14:17"> <span className="woj">不过当那位真理的灵来了，他就会引导你们进入一切真理</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引导你们进入一切真理——有古抄本作“在一切真理中引导你们”。">c</a></sup><span className="woj">。那时，他不会凭着自己说话，只把所听到的说出来，并且把那些就要来的事传讲给你们。</span></span>
<span className="v" id="v14" data-v="14" data-xref="约翰一书 4:13–14; 哥林多后书 3:14–18; 约翰福音 15:26"> <span className="woj">他将荣耀我，因为他将从我领受，并传讲给你们。</span></span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 17:10; 马太福音 11:27; 约翰福音 3:35"> <span className="woj">父所拥有的一切，都是我的。所以我说，圣灵将从我领受，并传讲给你们。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰福音 7:33; 使徒行传 1:3; 约翰福音 14:18–24"> <span className="woj">“过一会儿，你们就不再看到我了；再过一会儿，你们又将见到我</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附“因为我要到父那里去”。">d</a></sup><span className="woj">。”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 16:16; 马可福音 9:32; 约翰福音 16:5"> 于是他的门徒当中有的彼此问：“他对我们说<span className="woj">‘过一会儿，你们就看不到我了；再过一会儿，你们又将见到我’</span>，还说<span className="woj">‘是因为我要到父那里去’</span>，这是什么意思呢？”</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 24:25; 马太福音 16:9–11; 希伯来书 5:12"> 他们又说：“他说的<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本没有“他说的”。">e</a></sup><span className="woj">‘过一会儿’</span>是什么意思呢？我们不明白他在说什么。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约翰福音 16:30; 约翰福音 16:16; 约翰福音 14:19"> 耶稣知道他们想要问他，就对他们说：<span className="woj">“我刚才说‘过一会儿，你们就看不到我了；再过一会儿，你们又将见到我’，你们就为了这话彼此议论吗？</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="雅各书 1:2; 马太福音 5:4; 诗篇 126:5–6"> <span className="woj">“我确确实实地告诉你们：你们将会痛哭、哀号，这世界反而会喜乐；你们将会忧伤，然而你们的忧伤要变成喜乐。</span></span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 113:9; 以赛亚书 13:8; 帖撒罗尼迦前书 5:3"> <span className="woj">妇人生产的时候会有忧虑，因为她的时候到了；但是生了孩子以后，她就因着有人出生到世上的喜乐，而不再记住那痛苦了。</span></span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 1:8; 使徒行传 13:52; 约翰福音 16:6"> <span className="woj">这样，你们现在虽然也有忧虑，但是我会再见到你们，你们心里将喜乐，并且没有人能夺去你们的喜乐。</span></span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 15:7; 约翰福音 14:13–14; 马太福音 21:22"> <span className="woj">在那一天，你们什么也不会问我了。</span><br /><span className="woj">“我确确实实地告诉你们：你们奉我的名无论向父求什么，他都将赐给你们。</span></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 7:7–8; 雅各书 4:2–3; 约翰福音 15:11"> <span className="woj">直到如今，你们没有奉我的名求过什么。你们祈求吧！就会得到，好使你们的喜乐得以满足。</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 16:12; 马可福音 4:13; 马太福音 13:34–35"> <span className="woj">“我用比喻对你们说了这些话。但是时候就要到了！那时我不再用比喻对你们说话，而是要明确地告诉你们有关父的事。</span></span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 8:34; 约翰福音 17:24; 约翰福音 17:19"> <span className="woj">在那一天，你们会奉我的名祈求，而且我并不是说我要替你们向父祈求。</span></span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 14:21; 约翰福音 14:23; 约翰福音 17:23"> <span className="woj">要知道，父自己爱你们，因为你们已经爱我，并且相信我是从神</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="神——有古抄本作“父”。">f</a></sup><span className="woj">而来的。</span></span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 13:1; 约翰福音 13:3; 约翰福音 8:14"> <span className="woj">我从父而出，来到这世界；又要离开这世界，到父那里去。”</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约翰福音 16:25"> 他的门徒们说：“看，如今你说得明明白白，而不说比喻了。</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 21:17; 约翰福音 17:8; 约翰福音 16:17"> 现在我们已经明白你知道一切，也不需要任何人问你，从这一点我们就相信你是从神而来的。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 9:44–45; 约翰福音 13:38"> 耶稣对他们说：<span className="woj">“你们现在相信吗？</span></span>
<span className="v" id="v32" data-v="32" data-xref="撒迦利亚书 13:7; 马太福音 26:31; 约翰福音 8:29"> <span className="woj">看哪，时候就要到了，而且已经到了！你们要被驱散，每个人到自己的地方，留下我一个人。其实我不是独自一人，因为父与我同在。</span></span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 14:27; 约翰一书 5:4; 帖撒罗尼迦后书 3:16"> <span className="woj">我把这些事告诉了你们，好让你们在我里面有平安。在世上你们有患难，然而你们要鼓起勇气！我已经胜过了这世界。”</span></span>
</div>

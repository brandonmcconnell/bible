<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 62:4; 历代志下 32:33–9; 马太福音 1:10"> 玛拿西作王的时候十二岁，在耶路撒冷统治了五十五年。他的母亲名叫赫菲茨巴。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 12:31; 历代志下 36:14; 历代志下 33:2–4"> 他做耶和华眼中看为恶的事，效法耶和华在以色列子民面前赶出的那些民族，行可憎之事。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 18:4; 列王纪下 17:16; 申命记 17:3"> 他重建了他父亲希西加毁掉的高坛，像以色列王亚哈所做的那样，为巴力设立祭坛，制作亚舍拉柱，并向天上的万象下拜，服事它们。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 8:29; 撒母耳记下 7:13; 耶利米书 32:34"> 他在耶和华殿中筑了别的祭坛，关于这殿，耶和华曾指着它说“我要在耶路撒冷安置我的名”。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 7:12; 列王纪下 23:4; 列王纪下 23:12"> 他又在耶和华殿的两个院子里为天上的万象筑了祭坛，</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 17:17; 利未记 19:31; 利未记 18:21"> 他使自己的儿子经火，并且算命、行法术、招魂、通灵。他做了许多在耶和华眼中看为恶的事，惹他恼怒。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志下 7:16; 列王纪上 9:3; 撒母耳记下 7:13"> 玛拿西甚至把自己制作的亚舍拉雕像立在圣殿中，而这殿宇，耶和华曾指着它对大卫和他儿子所罗门说：“我要在这殿宇中，在我从以色列众支派所选择的耶路撒冷，永远安置我的名。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 7:10; 申命记 5:28–29; 诗篇 81:11–16"> 只要他们谨守遵行我所吩咐他们的一切，遵行我的仆人摩西所吩咐他们的一切律法，我就不再使以色列的脚流荡，离开我所赐给他们祖先的这地。”</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 29:12; 尼希米记 9:26; 列王纪上 14:16"> 但他们没有听从。玛拿西使他们迷失，以致作恶超过那些在以色列子民面前被耶和华除灭的民族。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 23:34–37; 历代志下 33:10; 历代志下 36:15"> 耶和华藉着他的仆人众先知宣告说：</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 24:3–4; 列王纪上 21:26; 列王纪下 21:9"> “因为犹大王玛拿西做了这些可憎之事，作恶超过他之前的亚摩利人所做的一切，又使犹大拜偶像而陷入罪恶，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 19:3; 撒母耳记上 3:11; 但以理书 9:12"> 因此以色列的神耶和华如此说：‘看哪，我要使祸患临到耶路撒冷和犹大，使所有听见这事的人都会双耳震响。</span>
<span className="v" id="v13" data-v="13" data-xref="阿摩司书 7:7–8; 耶利米哀歌 2:8; 以赛亚书 34:11"> 我要把撒玛利亚的准绳和亚哈家的铅垂线拉在耶路撒冷之上，我要把耶路撒冷擦干净，就像人擦盘子，擦完后把它翻过来。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 23:33; 列王纪下 19:4; 诗篇 89:38–45"> 我要撇弃我继业的余剩之民，把他们交在仇敌手中，他们必成为所有仇敌的掠物和掳物。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 20:30; 申命记 31:27; 以西结书 20:21"> 因为他们做我眼中看为恶的事，从他们的祖先出埃及那天起直到今日，他们一直惹怒我。’”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数记 35:33; 历代志下 33:9; 列王纪下 21:11"> 玛拿西使犹大犯罪、去做耶和华眼中看为恶的事，此外他还流了很多无辜人的血，以致这血从这边到那边充满了耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王纪下 20:20–21; 历代志下 33:1–20"> 玛拿西其余的事迹和他所做的一切，以及他所犯的罪，不是都记在《犹大诸王年代志》上吗？</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 33:20; 列王纪下 21:26; 历代志下 32:33"> 玛拿西与他的列祖长眠，葬在他宫殿的园子，就是乌撒的园子里；他的儿子亚门接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="历代志下 33:21–23; 列王纪上 22:51; 历代志上 3:14"> 亚门作王的时候二十二岁，在耶路撒冷统治了两年。他的母亲名叫米淑利梅，是哈鲁斯的女儿，来自约提巴。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 23:32; 列王纪下 21:11; 使徒行传 7:51"> 亚门效法他父亲玛拿西的行为，做耶和华眼中看为恶的事。</span>
<span className="v" id="v21" data-v="21"> 他走他父亲所走的一切道路，服事他父亲所服事的偶像，向它们下拜。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 22:17; 列王纪上 11:33; 历代志上 28:9"> 他离弃了耶和华他祖先的神，没有遵行耶和华的道。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪下 12:20; 列王纪下 14:19; 历代志下 33:24–25"> 亚门的臣仆密谋反叛他，在他的宫殿里把王杀了。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪下 14:5; 列王纪下 11:17; 列王纪下 14:21"> 那地的民众又把所有密谋反叛亚门王的人都杀了，然后立他的儿子约西亚接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王纪下 20:20; 列王纪下 21:17"> 亚门所做的其余事迹，不是都记在《犹大诸王年代志》上吗？</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 21:18; 马太福音 1:10; 列王纪上 13:5"> 他被葬在乌撒的园子中自己的坟墓里，他的儿子约西亚接替他作王。</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="2KI" data-book-slug="2-kings" data-book-name="列王纪下" data-chapter="17" data-verses="41">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 15:30"> 犹大王亚哈斯在位第十二年，以拉的儿子何西阿在撒玛利亚作以色列的王，统治了九年。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 3:2; 列王纪下 13:11; 历代志下 30:5–11"> 他做耶和华眼中看为恶的事，只不过没有像他之前的那些以色列王。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="何西阿书 10:14; 列王纪下 15:19; 列王纪下 19:36–37"> 亚述王撒缦以色上来攻打何西阿，何西阿就臣服于他，向他进贡。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 18:21; 列王纪下 24:20; 以西结书 17:13–19"> 后来亚述王发现了何西阿的阴谋，就是他派遣使者去见埃及王梭，不再每年向亚述王进贡。于是亚述王把他关押起来，囚禁在牢房里。</span>
<span className="v" id="v5" data-v="5" data-xref="何西阿书 13:16; 列王纪下 25:1–3; 列王纪下 18:9"> 亚述王还入侵以色列全地，上来攻打撒玛利亚，围困这城三年。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="历代志上 5:26; 何西阿书 13:16; 申命记 28:64"> 何西阿在位第九年，亚述王攻取了撒玛利亚。他把以色列人掳到亚述，安置在哈腊，歌散河流域的哈博，以及米底亚<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="米底亚——原文作“玛代”。">a</a></sup>的城镇。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约书亚记 23:16; 诗篇 106:35–41; 尼希米记 9:26"> 这是因为以色列子民犯罪，得罪了耶和华他们的神——就是从埃及地和埃及王法老手下把他们带上来的那一位，而去敬畏别的神，</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 18:3; 列王纪下 16:3; 申命记 18:9"> 随从耶和华在以色列子民面前赶出的那些民族的习俗，以及以色列诸王所推行的习俗。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 18:8; 约伯记 31:27; 申命记 13:6"> 以色列子民暗中对他们的神耶和华做了不义的事，在他们所有的城镇，从守望楼到堡垒城，为自己建造了高坛。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 14:23; 弥迦书 5:14; 出埃及记 34:13"> 他们在各高丘上、各青翠树下，为自己竖立神柱和亚舍拉柱。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 28:25; 列王纪下 21:6; 耶利米书 44:17"> 他们像耶和华在他们面前驱逐的那些国民一样，在所有的高坛烧香，并且做恶事来惹怒耶和华。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 12:4; 出埃及记 20:3–5; 申命记 4:23–25"> 他们服事偶像，尽管耶和华吩咐过他们不可做这样的事。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 35:15; 撒母耳记上 9:9; 耶利米书 18:11"> 所以，耶和华藉着众先知、众先见警诫以色列和犹大，说：“你们要转离自己邪恶的道路，谨守我的诫命、律例，遵行我的一切律法，这律法是我所吩咐你们祖先，又藉着我的仆人众先知传给你们的。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命记 31:27; 使徒行传 7:51; 诗篇 106:24"> 他们却不听从，反而像他们的祖先一样硬着颈项，不信靠耶和华他们的神。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 12:30–31; 申命记 32:21; 罗马书 1:21–23"> 他们厌弃耶和华的定例和他与他们祖先所立的约，厌弃他对他们的警诫。他们随从虚无的神明，以致自己也变得虚妄；又随从周围的那些民族，就是耶和华所吩咐他们不可效法的外邦人。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪上 14:23; 列王纪上 16:31; 列王纪上 14:15"> 他们离弃了他们的神耶和华的一切诫命，为自己造了两个牛犊的铸像，制作了亚舍拉柱，向天上的万象下拜，服事巴力。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 21:6; 列王纪下 16:3; 申命记 18:10–12"> 他们使自己的儿女经火，并且占卜、行法术，出卖自己去做耶和华眼中看为恶的事，惹怒他。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王纪上 12:20; 列王纪上 11:13; 何西阿书 11:12"> 于是耶和华对以色列大大发怒，把他们从自己面前驱逐，唯有犹大支派被留下。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 16:3; 列王纪上 14:22–23; 以西结书 16:51–52"> 然而，连犹大也不遵守他们神耶和华的诫命，而是随从以色列所推行的习俗。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 15:29; 耶利米书 6:30; 列王纪下 13:3"> 于是耶和华厌弃了以色列的所有后裔，苦待他们，把他们交在抢掠者的手中，最终把他们从自己面前赶走了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王纪上 11:11; 列王纪上 11:31; 列王纪上 14:16"> 耶和华把以色列从大卫家撕去之后，人们立了尼八之子耶罗波安为王。耶罗波安却引诱以色列不跟从耶和华，使他们犯了大罪。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 3:3; 列王纪下 13:6; 列王纪下 13:11"> 以色列子民随从耶罗波安所行的一切罪恶，总不离开，</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 17:6; 列王纪下 17:13; 列王纪下 17:20"> 直到耶和华把以色列从自己面前驱逐，正如藉着他的仆人众先知所宣告的。这样以色列人就从自己的国土被掳到亚述，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王纪下 18:34; 列王纪下 17:30–31; 马太福音 10:5"> 亚述王从巴比伦、古它、阿瓦、哈马和西法瓦音迁移人过来，安置在撒玛利亚的城镇，取代以色列子民。这些人就占有了撒玛利亚，住在它的城镇。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 17:32; 列王纪下 17:34; 列王纪下 17:41"> 这些人开始在那里居住时，不敬畏耶和华，耶和华就派遣狮子到他们中间，咬死他们中间的一些人。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 17:27; 撒母耳记上 8:9; 阿摩司书 8:14"> 有人禀告亚述王，说：“你所迁徙并安置在撒玛利亚城镇的那些国民，不知道当地之神的规矩，神就派遣狮子到他们中间。看哪，狮子把他们咬死了，因为他们不知道当地之神的规矩。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="士师记 17:13; 列王纪上 12:31; 列王纪上 13:2"> 亚述王就吩咐说：“派去一个从那地掳来的祭司，让他去住在那里，指教他们当地之神的规矩。”</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪上 12:29–32; 以赛亚书 29:13; 马太福音 15:14"> 于是有一个从撒玛利亚被掳去的祭司回来住在伯特利，指教他们如何敬畏耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王纪上 12:31; 弥迦书 4:5; 列王纪上 13:32"> 可是各国各族的人仍然制造自己的神像，放在撒玛利亚人建造的高坛庙宇里；各国各族的人在所住的城镇都这样做。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 17:24"> 巴比伦人制造疏割比讷，古它人制造匿甲，哈马人制造亚示玛，</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 17:24; 列王纪下 17:17; 列王纪下 19:37"> 亚瓦人制造尼布哈兹和塔珥塔克，西法瓦音人把儿女用火焚烧给西法瓦音的神亚得米勒和亚拿米勒。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 12:31; 列王纪下 17:29; 列王纪上 13:33"> 他们既畏惧耶和华，又从他们各类的人中为自己设立高坛的祭司，在高坛庙宇里为他们服事。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪下 17:41; 路加福音 16:13; 马太福音 6:24"> 他们又畏惧耶和华，又照着被迁徙之前本国的习俗来敬拜他们的神明。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="创世记 32:28; 创世记 35:10; 列王纪下 17:27–28"> 这些人至今还是照着先前的习俗去行。他们不敬畏耶和华，也不遵行律例和法规，就是耶和华所吩咐雅各子孙的律法和诫命——这雅各，耶和华给他取名为以色列。</span>
<span className="v" id="v35" data-v="35" data-xref="士师记 6:10; 约书亚记 23:16; 约书亚记 23:7"> 耶和华曾与他们立约，吩咐他们说：“你们不可敬畏别的神，不可向它们下拜，不可服事它们，不可向它们献祭。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 6:6; 申命记 6:13; 利未记 19:32"> 只有耶和华，就是以伟大的能力和伸出的膀臂把你们从埃及地带上来的那一位，你们要敬畏他，向他下拜，向他献祭。</span>
<span className="v" id="v37" data-v="37" data-xref="利未记 19:37; 申命记 5:31–2; 申命记 4:44–45"> 他为你们写下的律例、法规、律法、诫命，你们要终身谨守遵行，不可敬畏别的神。</span>
<span className="v" id="v38" data-v="38" data-xref="申命记 4:23; 申命记 6:12; 申命记 8:14–18"> 你们不可忘记我与你们所立的约，不可敬畏别的神。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 1:74–75; 撒母耳记上 12:24; 马太福音 10:28"> 你们只要敬畏耶和华你们的神，他就会解救你们脱离一切仇敌的手。”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="申命记 4:28; 列王纪下 17:8; 耶利米书 13:23"> 然而，这些人没有听从，还是照着他们先前的习俗去行。</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 6:24; 西番雅书 1:5; 列王纪上 18:21"> 这些民族既畏惧耶和华，又敬拜他们的偶像。这些人的孩子、他们的子子孙孙也都这样，他们祖先怎样做，他们也怎样做，直到今日。</span>
</div>
</div>

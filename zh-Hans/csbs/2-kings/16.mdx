<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 1:1; 以赛亚书 7:1; 列王纪下 15:38"> 利玛利的儿子比加在位第十七年，犹大王约坦的儿子亚哈斯作王。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 28:1–4; 列王纪下 15:34; 列王纪上 11:4–8"> 亚哈斯作王的时候二十岁，在耶路撒冷统治了十六年。他没有像他先祖大卫那样，做他的神耶和华眼中看为正的事，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 12:31; 利未记 18:21; 列王纪下 21:2"> 而是走以色列王的道路，甚至效法耶和华在以色列子民面前赶出的那些民族的可憎行为，使自己的儿子经火，</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 12:2; 列王纪上 14:23; 耶利米书 17:2"> 又在高坛上、丘陵上、各青翠树下献祭烧香。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪下 15:37; 以赛亚书 9:6–7; 以赛亚书 8:9–10"> 于是，亚兰王利汛会同利玛利的儿子以色列王比加上来攻打耶路撒冷。他们围困亚哈斯，却不能战胜。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 14:22; 申命记 2:8; 列王纪上 9:26"> 那时，亚兰王利汛把埃拉特收归亚兰，将犹大人从埃拉特赶走。以东人就来到埃拉特，住在那里，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王纪下 15:29; 耶利米哀歌 4:17; 何西阿书 14:3"> 亚哈斯派遣使者去见亚述王提革拉·毗列色，说：“我是你的仆人、你的儿子。求你上来，救我脱离那起来攻击我的亚兰王和以色列王。”</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪下 12:17–18; 历代志下 28:20–21; 历代志下 16:2"> 亚哈斯把耶和华殿中和王宫库房里的金银都拿去，送给亚述王作礼物。</span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司书 9:7; 以赛亚书 22:6; 阿摩司书 1:3–5"> 亚述王答应了亚哈斯，亚述王就上去攻打大马士革，攻取了那城。他把城里的人掳到吉珥，把利汛杀了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="罗马书 12:2; 以西结书 23:16–17; 以赛亚书 8:2"> 亚哈斯王去大马士革会见亚述王提革拉·毗列色。亚哈斯王看到了大马士革的祭坛，就把祭坛的图样以及详细构造的设计图，送到祭司乌利亚那里。</span>
<span className="v" id="v11" data-v="11" data-xref="何西阿书 4:6; 历代志下 26:17–18; 何西阿书 5:11"> 祭司乌利亚完全照着亚哈斯王从大马士革送来的图样，筑了一座祭坛。这样，祭司乌利亚在亚哈斯王从大马士革回来之前，就完工了。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 26:16–19; 历代志下 28:25; 列王纪上 13:1"> 王从大马士革回来，看见了那祭坛，王就上前来，在祭坛上献祭。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 1:1–3"> 他烧献燔祭和素祭，浇奠了酒祭，把平安祭的血洒在祭坛上。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 4:1; 出埃及记 40:6; 出埃及记 40:29"> 至于耶和华面前的铜祭坛，他把它从耶和华殿和新祭坛之间，从殿宇前面搬走了，放在新祭坛<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="新祭坛——原文直译“那祭坛”。">a</a></sup>的北边。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及记 29:39–41; 列王纪上 8:64; 历代志下 29:21–24"> 亚哈斯王吩咐祭司乌利亚说：“你要在我的大祭坛上烧献清晨的燔祭、傍晚的素祭，王的燔祭和素祭，所有国民的燔祭、素祭和酒祭；一切燔祭的血和祭物的血都要洒在它上面。至于铜祭坛，那是给我求问用的。”</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 4:19; 使徒行传 5:29; 犹大书 1:11"> 祭司乌利亚就照着亚哈斯王所吩咐的一切做了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="历代志下 4:14–15; 耶利米书 52:20; 历代志下 28:24"> 亚哈斯王拆掉铜盆底座的镶板，把盆从底座上取下来；又把铜海从底下的铜牛上拿下来，放在铺石地上。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 11:5; 列王纪上 10:5; 以西结书 46:2"> 他还为了亚述王的缘故，把耶和华殿中为安息日建造的廊子，以及王从外面进殿的入口，都从耶和华的殿拆除了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王纪下 15:36; 历代志下 28:26; 列王纪下 20:20–21"> 亚哈斯所做的其余事迹，不是都记在《犹大诸王年代志》上吗？</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 1:9; 以赛亚书 1:1; 历代志上 3:13"> 亚哈斯与他的列祖长眠，葬在大卫城，与他的列祖在一起；他的儿子希西加接替他作王。</span>
</div>
</div>

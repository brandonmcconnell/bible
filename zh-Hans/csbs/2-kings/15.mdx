<span className="v" id="v2" data-v="2" data-xref="历代志下 26:3–4"> 他作王的时候十六岁，在耶路撒冷统治了五十二年。他的母亲名叫耶克利雅，是耶路撒冷人。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 14:3–4; 列王纪下 12:2–3; 历代志下 26:4"> 他效法他父亲亚玛谢所做的一切，做耶和华眼中看为正的事。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 15:35; 列王纪下 14:4; 列王纪下 12:3"> 只是那些高坛还没有除掉，百姓仍旧在高坛献祭烧香。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="利未记 13:46; 民数记 12:14; 列王纪下 7:3"> 耶和华打击王，他就患了麻风，直到死的日子；他住在隔离的房子里。王的儿子约坦接管王室，治理国民。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="历代志下 26:5–15; 列王纪下 14:18"> 亚撒利雅其余的事迹和他所做的一切，不是都记在《犹大诸王年代志》上吗？</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 26:23; 以赛亚书 6:1"> 亚撒利雅与他的列祖长眠，人们把他葬在大卫城，与他的列祖在一起；他的儿子约坦接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪下 14:16–17; 列王纪下 14:29–1; 列王纪下 14:21"> 犹大王亚撒利雅在位第三十八年，耶罗波安的儿子撒迦利亚在撒玛利亚作以色列的王，统治了六个月。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 14:24; 列王纪下 13:2; 列王纪下 13:11"> 他效法他列祖的行为，做耶和华眼中看为恶的事，不离开尼八之子耶罗波安使以色列所犯的罪恶。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="列王纪上 15:28; 列王纪下 15:14; 列王纪下 9:24"> 雅比的儿子沙勒姆密谋反叛撒迦利亚，当众<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="当众——或译作“在以伯莲”。">a</a></sup>攻击他，把他杀了，接替他作王。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 14:28"> 撒迦利亚其余的事迹，看哪，都记在《以色列诸王年代志》上。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 10:30; 马可福音 13:31; 列王纪下 13:13"> 耶和华曾对耶户说“你子孙四代都必坐以色列的王位”，这话就如此成就了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王纪下 15:1; 马太福音 1:8–9; 列王纪下 15:8"> 犹大王亚撒利雅<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="亚撒利雅——原文是别名“乌西雅”；见《历代志下》26:1。">b</a></sup>在位第三十九年，雅比的儿子沙勒姆作王，在撒玛利亚统治了一个月。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 14:17; 列王纪上 16:17; 列王纪上 16:15"> 迦底的儿子米纳恒从提尔撒上来，来到撒玛利亚。他在撒玛利亚攻击雅比的儿子沙勒姆，把他杀了，接替他作王。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 14:19; 列王纪上 14:29; 列王纪下 15:11"> 沙勒姆其余的事迹，包括他谋反的事，看哪，都记在《以色列诸王年代志》上。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪下 8:12; 列王纪上 4:24; 何西阿书 13:16"> 那时米纳恒从提尔撒出发，攻打提弗萨和城中所有的人，以及提弗萨的四境，因为他们没有打开城门，他就屠杀他们，剖开所有的孕妇。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 犹大王亚撒利雅在位第三十九年，迦底的儿子米纳恒在撒玛利亚作以色列的王，统治了十年。</span>
<span className="v" id="v18" data-v="18"> 他做耶和华眼中看为恶的事，一生的日子不离开尼八之子耶罗波安使以色列所犯的罪恶。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王纪下 14:5; 历代志上 5:25–26; 列王纪下 18:16"> 亚述王普勒侵入这地，米纳恒就给了普勒一千他连得<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一千他连得——相当于34.2公吨。1他连得=34.2公斤。">c</a></sup>银子，为要普勒帮助他巩固手中的王权。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 18:14–17; 列王纪下 23:35; 列王纪下 17:3–4"> 米纳恒向以色列所有富豪征收银子，每人五十谢克尔<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="五十谢克尔——相当于570公克。1谢克尔=11.4公克。">d</a></sup>银子，交纳给亚述王。于是亚述王回去，不在这地停留了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 米纳恒其余的事迹和他所做的一切，不是都记在《以色列诸王年代志》上吗？</span>
<span className="v" id="v22" data-v="22"> 米纳恒与他的列祖长眠，他的儿子佩卡希亚接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪上 15:25; 列王纪上 22:51; 约伯记 20:5"> 犹大王亚撒利雅在位第五十年，米纳恒的儿子佩卡希亚在撒玛利亚作以色列的王，统治了两年。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪下 15:9; 列王纪下 15:18"> 他做耶和华眼中看为恶的事，不离开尼八之子耶罗波安使以色列所犯的罪恶。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="历代志下 28:6; 列王纪下 9:14; 列王纪上 16:9"> 他的军官利玛利的儿子比加密谋反叛他，与亚珥歌伯、亚利耶，以及跟随比加的五十个基列人一起，在撒玛利亚王宫的城堡里攻击他，把他杀了，接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 佩卡希亚其余的事迹和他所做的一切，看哪，都记在《以色列诸王年代志》上。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 7:4; 以赛亚书 7:1; 列王纪下 15:23"> 犹大王亚撒利雅在位第五十二年，利玛利的儿子比加在撒玛利亚作以色列的王，统治了二十年。</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪下 15:18; 列王纪下 13:6; 列王纪下 15:9"> 他做耶和华眼中看为恶的事，不离开尼八之子耶罗波安使以色列所犯的罪恶。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="历代志上 5:26; 列王纪下 17:6; 列王纪下 16:7"> 以色列王比加年间，亚述王提革拉·毗列色前来夺取了伊永、亚贝勒-伯玛迦、雅挪哈、基低斯、哈佐、基列、加利利，就是拿弗他利全地，并把那里的人掳到亚述去了。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="列王纪下 17:1; 历代志下 28:4–6; 列王纪下 16:1"> 乌西雅的儿子约坦在位第二十年，以拉的儿子何西阿密谋反叛利玛利的儿子比加，攻击他，把他杀了，接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31"> 比加其余的事迹和他所做的一切，看哪，都记在《以色列诸王年代志》上。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="历代志上 3:12; 列王纪下 15:7; 历代志下 27:1–9"> 利玛利的儿子以色列王比加在位第二年，犹大王乌西雅的儿子约坦作王。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志下 27:1"> 他作王的时候二十五岁，在耶路撒冷统治了十六年。他的母亲名叫耶路莎，是撒督的女儿。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志下 26:4–5; 列王纪下 15:3–4; 历代志下 27:2"> 约坦效法他父亲乌西雅所做的一切，做耶和华眼中看为正的事。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪下 12:3; 历代志下 23:20; 历代志下 27:3–9"> 只是那些高坛还没有除掉，百姓仍旧在高坛献祭烧香。<br />约坦修筑了耶和华殿的上门。</span>
<span className="v" id="v36" data-v="36" data-xref="历代志下 27:4–9; 列王纪下 15:6–7"> 约坦其余的事迹和他所做的，不是都记在《犹大诸王年代志》上吗？</span>
<span className="v" id="v37" data-v="37" data-xref="列王纪下 16:5; 以赛亚书 7:1; 路加福音 21:28"> 在那些日子，耶和华开始派遣亚兰王利汛和利玛利的儿子比加来进攻犹大。</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪上 14:20; 列王纪上 14:31; 列王纪下 16:1"> 约坦与他的列祖长眠，葬在先祖大卫的城，与他的列祖在一起；他的儿子亚哈斯接替他作王。</span>
</div>

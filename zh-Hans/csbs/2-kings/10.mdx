<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 8:30; 列王纪上 13:32; 列王纪上 21:8–14"> 那时，亚哈的七十个儿子在撒玛利亚。耶户写信送到撒玛利亚，给耶斯列的首领、长老们以及亚哈子女的监护人，说：</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="列王纪下 5:6"> “如今，这封书信到达你们那里时，既然你们有主人的儿子与你们在一起，又有车马、堡垒城和兵器，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 2:8–9; 列王纪上 12:20–21; 撒母耳记下 2:12–17"> 就请你们选出主人的儿子中最优秀最合适的，立他坐他父亲的王位，然后你们为主人的家争战吧！”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 9:24; 列王纪下 9:27; 以赛亚书 27:4"> 他们却极其害怕，说：“看哪，两个王在这人面前都站立不住，我们怎么能站立得住呢？”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪上 20:32; 列王纪上 20:4; 约书亚记 9:11"> 于是宫廷总管、城里的官长、长老们和亚哈儿女的监护人就派人去见耶户，说：“我们是你的仆人，你吩咐我们什么，我们都会去做，我们不立谁为王。你看怎样好就怎样做吧！”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="启示录 2:20–23; 申命记 5:9; 民数记 25:4"> 耶户就给他们写了第二封信，说：<br />“你们如果归属我、听从我的吩咐，就要把你们主人所有儿子的头颅带来，明天这时候到耶斯列来见我。”<br />当时，众王子七十人与城中那些抚养他们的大臣在一起。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 21:21; 列王纪下 11:1; 列王纪下 10:9"> 当书信到达他们那里时，他们就抓住那些王子，把七十个人都杀了。然后把他们的头颅放进筐子里，送到耶斯列耶户那里。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 21:23; 撒母耳记下 11:18–21; 马可福音 6:28"> 有一个使者来向耶户报告说：“他们把那些王子的头颅带来了。”耶户说：“把这些头颅分成两堆放在城门口，直到明天早晨。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王纪下 9:14–24; 以赛亚书 5:3; 何西阿书 1:4"> 到了早晨，耶户出去站着，对全体民众说：“你们是清白的，看哪，是我密谋反叛我的主人，把他杀了；但这些人都是谁杀的呢？</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 21:29; 列王纪上 21:19; 列王纪下 9:7–10"> 现在你们当知道：耶和华的话语——耶和华指着亚哈家所说的，一句也不落空；耶和华已经成就了藉着他仆人以利亚所宣告的话。”</span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 18:19; 列王纪上 18:19; 列王纪上 22:6"> 这样，耶户击杀了亚哈家在耶斯列所有剩下的人、他所有的大臣、亲密的朋友和他的祭司，没有留下一人存活。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 耶户起身往撒玛利亚去。路过牧羊人的伯艾吉时，</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 8:29; 列王纪下 8:24; 历代志下 21:17"> 耶户遇见了犹大王亚哈谢的族兄弟们。他问：“你们是谁？”<br />他们回答：“我们是亚哈谢的族兄弟，下来要向王的家人和太后的家人问安。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志下 22:10; 列王纪下 10:6; 列王纪下 10:10–11"> 耶户吩咐：“活捉他们！”他的部下就活捉了他们，在伯艾吉的水窖旁边把他们杀了，共四十二人，一个也没有留下。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米书 35:14–19; 以斯拉记 10:19; 以西结书 17:18"> 耶户从那里前行，遇见了利甲的儿子约拿达前来迎接他。耶户向他问安，说：“你的心是否真诚，就像我的心对你的心那样？”<br />约拿达回答：“是。”<br />耶户说：“既然是，就请递出你的手。”<br />约拿达递出手，耶户就把他拉上战车。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 19:10; 马太福音 6:5; 列王纪下 10:31"> 耶户说：“跟我一起去，看看我对耶和华的热心！”于是耶户让约拿达乘上了自己的战车。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 9:8; 历代志下 22:8; 玛拉基书 4:1"> 耶户来到撒玛利亚，击杀了其余在撒玛利亚所有属亚哈的人，直到灭尽了，正如耶和华向以利亚所宣告的话。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王纪上 16:31–32; 列王纪下 3:2; 罗马书 3:8"> 耶户招聚全体民众，对他们说：“亚哈服事巴力还不够热心，耶户要更加热心服事。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 22:6; 列王纪上 18:19; 哥林多后书 11:3"> 现在，你们要把巴力的所有先知、所有服事巴力的人和巴力的所有祭司都召集到我这里来，一个都不能缺，因为我要给巴力举行一个盛大的祭祀；任何缺席者都不得存活。”原来耶户是在用诡计，为要消灭服事巴力的人。</span>
<span className="v" id="v20" data-v="20" data-xref="约珥书 1:14; 出埃及记 32:5; 列王纪上 18:19–20"> 耶户又说：“要为巴力举行一个严肃圣会！”于是他们发出通告。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王纪上 16:32; 列王纪下 11:18; 约珥书 3:2"> 耶户派人走遍全以色列，所有服事巴力的人都来了，没有一个留下不来的。人们进入巴力的庙宇，巴力的庙宇从这头到那头都挤满了人。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 28:2; 马太福音 22:11–12"> 耶户对掌管礼服的人说：“把衣袍给所有服事巴力的人拿出来。”他就把服装给他们拿出来。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 13:30; 马太福音 25:32–33; 马太福音 13:41"> 耶户与利甲的儿子约拿达进入巴力的庙宇，耶户对服事巴力的人说：“搜寻看看，你们这里不许有耶和华的仆人与你们在一起，只能有那些服事巴力的人在场。”</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 20:30–42"> 这样，他们进去献上祭物和燔祭。<br />耶户在外面提前安排了八十人，说：“我交在你们手中的人，谁让其中逃脱一个，谁就要以命抵命。”</span>
<span className="v" id="v25" data-v="25" data-xref="启示录 16:6–7; 以西结书 22:21–22; 列王纪上 18:40"> 献完了燔祭，耶户就吩咐护卫兵和军官们：“进去击杀他们，不要让任何人逃出来！”护卫兵和军官们就用刀把他们杀了扔出去，然后进到巴力庙宇的内殿，</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 14:23; 列王纪下 3:2; 列王纪下 19:18"> 把巴力庙宇里的神柱都搬出去烧毁了。</span>
<span className="v" id="v27" data-v="27" data-xref="但以理书 3:29; 以斯拉记 6:11; 但以理书 2:5"> 他们拆毁巴力的神柱，又拆毁巴力的庙宇，用作厕所，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 这样，耶户从以色列中除灭了巴力。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪上 12:28–30; 列王纪上 14:16; 列王纪上 13:33–34"> 只是耶户没有离弃尼八之子耶罗波安使以色列所犯的罪恶，就是敬拜伯特利和但的金牛犊。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 10:35; 列王纪下 13:1; 列王纪下 13:10"> 耶和华对耶户说：“因为你做我眼中看为正的事，做得很好，照着我心里的一切处置了亚哈家，所以你子孙四代都必坐以色列的王位。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪下 10:29; 箴言 4:23; 希伯来书 2:1"> 然而，耶户没有全心谨守遵行以色列的神耶和华的律法，没有离开耶罗波安使以色列所犯的罪恶。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="列王纪下 8:12; 列王纪上 19:17; 列王纪下 13:22"> 在那些日子，耶和华开始切割以色列。哈薛在以色列境内各处击败他们，</span>
<span className="v" id="v33" data-v="33" data-xref="阿摩司书 1:3–4; 申命记 2:36; 约书亚记 13:9–12"> 遍及约旦河东的基列地——迦得人、鲁本人和玛拿西人之地——从靠近亚嫩溪谷的亚罗珥，直到基列和巴珊。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="列王纪上 11:41; 列王纪上 14:29; 列王纪上 14:19"> 耶户其余的事迹和他所做的一切，以及他的所有武力，不是都记在《以色列诸王年代志》上吗？</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 14:20; 列王纪上 14:31; 列王纪上 1:21"> 耶户与他的列祖长眠，人们把他葬在撒玛利亚；他的儿子约哈斯接替他作王。</span>
<span className="v" id="v36" data-v="36"> 耶户在撒玛利亚统治以色列的日子共二十八年。</span>
</div>
</div>

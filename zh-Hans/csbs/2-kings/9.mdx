<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 10:1; 列王纪下 4:29; 列王纪上 1:39"> 先知以利沙叫来先知团契的一个门徒，对他说：“你束上腰，手中拿着这瓶膏油，到拉末-基列去。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 9:5; 列王纪上 19:16–17; 列王纪下 9:11"> 到了那里，你要找宁示的孙子、约沙法的儿子耶户。你去请他从他兄弟们当中起来，把他带到内室。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 19:16; 出埃及记 29:7; 撒母耳记上 16:2"> 然后拿这瓶膏油浇在他头上，说：‘耶和华如此说：我膏立你为以色列的王。’然后开门就跑，不要耽延。”</span>
<span className="v" id="v4" data-v="4"> 于是那年轻的先知就往拉末-基列去了。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="士师记 3:19"> 他到了那里，看哪，将领们都坐着。他说：“我有话带给你，长官。”<br />耶户问：“是给我们当中哪一位呢？”<br />他回答：“给你，长官。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="历代志下 22:7; 列王纪上 19:16; 列王纪下 9:3"> 耶户就起来，进了屋子。那年轻人把膏油浇在耶户头上，对他说：“以色列的神耶和华如此说：<br />‘我已经膏立你为王治理耶和华的子民以色列。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 21:15; 列王纪上 18:4; 申命记 32:43"> 你要击杀你主人亚哈的全家，好让我向耶洗别施行报复，因她下手流了我仆人众先知的血，耶和华众仆人的血。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 25:22; 申命记 32:36; 列王纪下 14:26"> <span className="pl pl-1">亚哈全家都必灭亡；</span><br /><span className="pl pl-1">以色列中凡属亚哈的男丁</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="男丁——原文直译“对着墙撒尿的”。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">无论是为奴的还是自由的，</span><br /><span className="pl pl-1">我都必剪除。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 15:29; 列王纪上 21:22; 列王纪上 14:10–11"> <span className="pl pl-1">我要使亚哈家</span><br /><span className="pl pl-1">像尼八之子耶罗波安的家，</span><br /><span className="pl pl-1">又像亚希雅的儿子巴沙的家那样。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 21:23; 列王纪下 9:35–36; 列王纪下 9:3"> <span className="pl pl-1">至于耶洗别，</span><br /><span className="pl pl-1">狗必在耶斯列的地界内吃掉她，</span><br /><span className="pl pl-1">无人埋葬。’”</span><br />然后，他开门就跑了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米书 29:26; 使徒行传 26:24; 何西阿书 9:7"> 耶户出来，回到他主人的臣仆们那里。他们问他：“一切平安吗？这疯子为什么来见你呢？”<br />他回答：“你们都了解这个人和他的胡话。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 他们说：“你糊弄人，请告诉我们吧！”<br />他就说：“那人说这说那，还告诉我：‘耶和华如此说：我膏立你为以色列的王。’”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马可福音 11:7–8; 列王纪上 1:39; 列王纪上 1:34"> 他们就急忙各自脱下外衣铺在耶户脚前的台阶上，随后吹响号角，说：“耶户作王了！”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王纪下 8:28; 列王纪上 22:3; 列王纪上 16:16"> 这样，宁示的孙子、约沙法的儿子耶户密谋反叛了约兰。当时约兰和全体以色列人正驻守在拉末-基列，抵抗亚兰王哈薛。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 8:29; 撒母耳记上 27:9–11; 历代志下 22:6"> 后来约兰王回来，在耶斯列疗伤，他与亚兰王哈薛交战时被亚兰人打伤了。耶户说：“如果你们有心让我作王<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="让我作王——辅助词语。">b</a></sup>，就不要让任何人逃脱出城，去耶斯列报信。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志下 22:6–7; 列王纪下 8:28–29"> 随后耶户乘上战车往耶斯列去，因为约兰正在那里卧床养伤。那时犹大王亚哈谢已经下去看望他。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 16:4; 以西结书 33:2–9; 列王纪下 7:14"> 守望的人站在耶斯列的塔楼上，看见耶户一群人来了，就说：“我看见有一群人！”<br />约兰说：“叫来一个骑兵，派去迎见他们，询问是否平安。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王纪下 9:19; 列王纪下 9:22; 耶利米书 16:5"> 骑兵就去迎见耶户，说：“王如此说：平安吗？”<br />耶户说：“是否平安，与你有什么相干？跟到我后面去！”<br />守望的人报告说：“派去的人到了他们那里，但没有回来。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 王又派第二个骑兵去。他来到他们那里，说：“王如此说：平安吗？”<br />耶户说：“是否平安，与你有什么相干？跟到我后面去！”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳记下 18:27; 列王纪上 19:17; 传道书 9:10"> 守望的人报告说：“派去的人到了他们那里，但没有回来。那驾车的像是宁示的孙子耶户的驾车风格，驾得很疯狂。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王纪上 21:1–7; 历代志下 22:7; 弥迦书 1:13"> 于是约兰吩咐：“备车！”有人就备好他的战车。以色列王约兰和犹大王亚哈谢各乘自己的战车出发，出去迎见耶户，在耶斯列人拿伯的那块田地遇见了他。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 21:13; 那鸿书 3:4; 列王纪上 16:30–33"> 约兰看见耶户，就说：“耶户，平安吗？”<br />耶户回答说：“你母亲耶洗别的淫行和法术如此泛滥，怎么会有平安呢？”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪下 11:14; 历代志下 23:13"> 约兰急忙调头逃走，对亚哈谢说：“亚哈谢啊，他谋反了！”</span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="列王纪上 22:34; 箴言 21:30; 帖撒罗尼迦前书 5:3"> 耶户拉满弓，射中了约兰两臂正中间，一箭穿心，他就瘫倒在战车里。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 21:19; 列王纪上 21:24–29; 以赛亚书 13:1"> 耶户对他的军官毕甲说：“把他抬走扔到耶斯列人拿伯的那块田地里。你当记得，你我一同驾车跟随他父亲亚哈时，耶和华曾向亚哈发出了这默示：</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 21:19; 申命记 5:9; 历代志下 25:4"> <span className="pl pl-1">‘昨夜我确实看见了拿伯的血和他儿子们的血</span><br /><span className="pl pl-2">——这是耶和华的宣告；</span><br /><span className="pl pl-1">我必在那块田地上报应你</span><br /><span className="pl pl-2">——这是耶和华的宣告。’</span><br />现在你就照着耶和华的话，把他抬走扔到那块田地里吧。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="士师记 1:27; 约书亚记 17:11; 列王纪下 8:29"> 犹大王亚哈谢看见这一切，就往伯哈干的方向逃走。耶户追赶他说：“把他也杀了！”于是在靠近以伯莲的古珥山坡上，有人把他射伤在战车上。他逃到米吉多，死在那里。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 35:24; 列王纪下 23:30; 列王纪下 12:21"> 他的臣仆们用车把他运送到耶路撒冷，葬在大卫城他的坟墓里，与他的列祖在一起。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志下 21:18–19; 历代志下 22:1–2; 列王纪下 8:24–25"> 亚哈的儿子约兰在位第十一年，亚哈谢作犹大的王。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米书 4:30; 以西结书 23:40; 以西结书 24:17"> 耶户来到耶斯列，耶洗别听说了，就画眉梳头，从窗户俯看。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪上 16:9–20"> 耶户进了城门，耶洗别说：“你这弑主的泽姆利啊，平安吗？”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以斯帖记 2:15; 出埃及记 32:26; 历代志下 11:12"> 耶户抬头对着窗户，说：“有谁听我的？有谁？”两三个太监向他俯看。</span>
<span className="v" id="v33" data-v="33" data-xref="弥迦书 7:10; 耶利米哀歌 1:15; 以赛亚书 25:10"> 耶户说：“把她扔下来！”他们就把她扔下去，她的血喷溅到墙上和马身上，耶户从她上面轧过去。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="列王纪上 16:31; 列王纪上 21:25; 以赛亚书 65:15"> 耶户进去，又吃又喝，然后说：“去看看这受诅咒的女人，把她埋葬了，她毕竟是王的女儿。”</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 12:23; 以赛亚书 14:18–20; 约伯记 31:3"> 他们就去埋葬她，却发现除了头骨和手脚以外，什么都没有了。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 21:23; 利未记 8:36; 列王纪下 14:25"> 他们回去报告耶户，耶户说：“这应验了耶和华藉着他的仆人提斯比人以利亚所宣告的话：‘狗必在耶斯列地界内吃掉耶洗别的肉。</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 8:2; 诗篇 83:10; 耶利米书 16:4"> 耶洗别的尸体必在耶斯列地界内如同地上的粪土，以致没有人能说：这就是耶洗别。’”</span>
</div>
</div>

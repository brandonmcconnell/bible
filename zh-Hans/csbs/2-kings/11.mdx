<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 41:1; 列王纪下 25:25; 历代志下 22:10–12"> 亚哈谢的母亲娅塔利雅见自己的儿子死了，就动手消灭所有的王室后裔。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 33:26; 耶利米书 35:2; 以赛亚书 7:6–7"> 但约兰王的女儿、亚哈谢的妹妹约示巴带走了亚哈谢的儿子约阿施，从即将被处死的王子们当中偷走他，然后把他和他的乳母一起安置在一间卧室里。这样，他们把约阿施藏了起来，躲避娅塔利雅，他就没有被处死。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 12:8; 历代志下 22:12; 玛拉基书 3:15"> 约阿施与他的乳母在耶和华的殿中躲藏了六年，那时娅塔利雅统治那地。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 11:19; 列王纪下 11:9; 列王纪下 11:17"> 到了第七年，耶赫亚达派人去把迦利人的百夫长和护卫兵的百夫长请来，带到耶和华的殿来见他。他就与他们结盟，让他们在耶和华殿中起誓，然后使他们见到王子。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 9:25; 以西结书 44:2–3; 历代志上 23:32"> 他吩咐他们说：“你们要这样做：你们安息日当班的人，三分之一要值守王宫，</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 23:4–5; 历代志上 26:13–19"> 三分之一值守在根基门<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="根基门——或译作“苏珥门”；参《历代志下》23:5。">a</a></sup>，三分之一值守在护卫兵院的后门；你们要轮流值守圣殿。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志下 23:6; 列王纪下 11:5"> “你们所有在安息日休班的两班人，都要为王值守在耶和华的殿。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 27:17; 历代志下 23:7; 列王纪上 2:28–31"> 你们要各自手拿兵器围绕着王，靠近列队的人必被处死。王出入的时候，你们必须紧随着王。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="历代志下 23:8; 列王纪下 11:4; 历代志上 26:26"> 于是众百夫长就照着祭司耶赫亚达所吩咐的一切去做，各自带领部下，无论是安息日当班的还是安息日休班的，来到祭司耶赫亚达那里。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 8:7; 历代志上 18:7; 历代志下 5:1"> 祭司把耶和华殿中大卫王的那些长矛和盾牌交给众百夫长，</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 11:8; 以西结书 8:16; 列王纪下 11:10"> 然后让护卫兵各自手拿兵器，从殿宇右侧到殿宇左侧，对着祭坛和殿宇，侍立在王子<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="王子——原文直译“王”。">b</a></sup>的周围。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及记 25:16; 撒母耳记上 10:24; 列王纪上 1:39"> 耶赫亚达把王子领出来，给他戴上冠冕，把律法书交给他，立他为王。他们膏抹了他，然后众人拍手鼓掌说：“愿王万岁！”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志下 23:12–15"> 娅塔利雅听见护卫兵和民众的声音，就来到耶和华殿中民众那里。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 34:31; 列王纪下 23:3; 列王纪下 9:23"> 她观看，看哪，王按照惯例站在柱子旁边，将领们和吹号手在王身边，这地所有的民众在欢乐、吹号。娅塔利雅就撕裂衣服，喊叫：“谋反了！谋反了！”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西结书 9:7; 历代志下 23:14; 历代志下 23:9"> 祭司耶赫亚达吩咐率领军队的众百夫长，对他们说：“把她从队列之间赶出去，把跟随她的人都用刀杀了！”因为祭司说不可在耶和华殿中处死她。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 9:6; 历代志下 23:15; 马太福音 7:2"> 他们就下手抓住她，她到了王宫马门入口处，在那里被处死了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 5:3; 历代志下 15:12–14; 历代志下 34:31"> 此后，耶赫亚达使王和民众与耶和华立约，要作耶和华的子民；又使王与民众立约。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 12:3; 列王纪下 10:26; 列王纪上 18:40"> 于是这地所有的民众来到巴力的庙宇，把它拆毁，彻底打碎其中的祭坛和偶像，并且在祭坛前杀了巴力的祭司玛坦。<br />祭司耶赫亚达为耶和华的殿安排了监管的人，</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 17:25; 耶利米书 22:4; 历代志下 23:19"> 然后他带领百夫长、迦利人、护卫兵以及这地的所有民众，请王从耶和华的殿下来，穿过护卫兵院的门进入王宫，王就坐上了王位。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 11:10; 箴言 29:2; 列王纪下 11:14"> 于是这地所有的民众都欢喜，城中也平静，因为他们在王宫把娅塔利雅用刀杀了。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志下 24:1–14; 列王纪下 22:1; 列王纪下 11:4"> 约阿施作王的时候七岁。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="此节在马索拉文本为12:1。">c</a></sup></span>
</div>
</div>

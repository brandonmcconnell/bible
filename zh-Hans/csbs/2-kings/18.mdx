<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="2KI" data-book-slug="2-kings" data-book-name="列王纪下" data-chapter="18" data-verses="37">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 28:27–1; 马太福音 1:9–10; 历代志上 3:13"> 以拉的儿子以色列王何西阿在位第三年，犹大王亚哈斯的儿子希西加作王。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 29:1–2"> 他作王的时候二十五岁，在耶路撒冷统治了二十九年。他的母亲名叫娅比，是撒迦利亚的女儿。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 20:3; 列王纪上 11:4; 历代志下 31:20–21"> 他效法他的先祖大卫所做的一切，做耶和华眼中看为正的事。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 31:1; 民数记 21:8–9; 列王纪下 18:22"> 他除掉高坛，打碎神柱，砍倒亚舍拉柱，还打碎了摩西制作的铜蛇，以色列子民直到那时候一直向这铜蛇烧香，称它为“内胡什坦”。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪下 23:25; 列王纪下 19:10; 马太福音 27:43"> 他依靠耶和华以色列的神，在他之后、在他之前所有的犹大王中没有一个能与他相比的。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 23:8; 申命记 10:20; 约翰福音 14:15"> 他紧紧跟随耶和华，没有偏离不跟随他，而是遵守耶和华所指示摩西的诫命。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:31; 创世记 39:2–3; 列王纪下 16:7"> 耶和华与他同在，他无论往哪里去都通达。他背叛了亚述王，不再臣服于他。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 14:29; 列王纪下 17:9; 历代志下 28:18"> 希西加击败非利士人，直到加沙，攻取了它境内的守望楼以及堡垒城。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="何西阿书 10:14; 列王纪下 17:3–23; 列王纪下 18:1"> 到了希西加王第四年，就是以拉的儿子以色列王何西阿第七年，亚述王撒缦以色上来攻打撒玛利亚，围困它。</span>
<span className="v" id="v10" data-v="10" data-xref="阿摩司书 6:7; 阿摩司书 9:1–4; 弥迦书 1:6–9"> 过了三年，它被攻取。希西加在位第六年，就是以色列王何西阿九年，撒玛利亚被攻取了。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 5:26; 列王纪下 17:6; 以赛亚书 37:12"> 亚述王把以色列人掳到亚述，安置在哈腊，歌散河流域的哈博，以及米底亚<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="米底亚——原文作“玛代”。">a</a></sup>的城镇。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 4:17; 彼得前书 2:8; 弥迦书 3:4"> 这是因他们没有听从他们的神耶和华的话，违背他的约；他们对耶和华的仆人摩西所吩咐的一切，既不听从，也不遵行。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 36:1–22; 历代志下 32:1–23; 以赛亚书 7:17–25"> 希西加王十四年，亚述王西纳基立上来攻打犹大所有坚固的城，攻取了它们。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 18:7; 路加福音 14:32; 列王纪上 20:4"> 犹大王希西加派人到拉吉去见亚述王，说：“我错了，求你从我这里撤离吧！你对我的处置，我都接受。”于是亚述王向犹大王希西加索要三百他连得<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="三百他连得——相当于10.3公吨。1他连得=34.2公斤。">b</a></sup>银子、三十他连得<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="三十他连得——相当于1公吨。">c</a></sup>金子。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 16:8; 列王纪上 15:18–19; 列王纪下 12:18"> 希西加就把耶和华殿中和王宫库房里所有的银子都交出来。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 29:3; 列王纪上 6:31–35"> 那时，希西加把耶和华圣殿的门上和柱子上的金子<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="金子——辅助词语。">d</a></sup>拆下来，交给了亚述王，都是犹大王希西加原来贴在其上的。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 20:1; 列王纪下 20:20; 以赛亚书 7:3"> 但亚述王还是派遣元帅、参谋长、将军<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="元帅、参谋长、将军——音译作“塔珥坦、拉伯撒利、拉伯沙基”；都是亚述高级官员的头衔。">e</a></sup>率领大军，从拉吉往耶路撒冷，到希西加王那里去。他们就上来，到了耶路撒冷。他们上来后，前来站在上池的沟渠旁，通往漂布场的大道上。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 19:2; 以赛亚书 36:3; 撒母耳记下 8:16–17"> 他们呼叫王，于是希勒加的儿子宫廷总管以利亚敬，书记舍伯纳，以及亚萨的儿子史官约亚，都出来到他们那里。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 36:4; 列王纪下 19:10; 以赛亚书 10:8–14"> 将军对他们说：<br />“请你们告诉希西加，亚述大王如此说：你所依靠的算什么依靠？</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 21:30–31"> 你说你有作战的谋略和实力，但那只是嘴上的空谈！你现在依靠谁，竟敢背叛我！</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 30:7; 以西结书 29:6–7; 以赛亚书 30:2–3"> 现在看哪，你依靠的埃及是压裂的芦苇杖；如果有人倚靠它，它就会扎入那人的手掌，把手掌刺透。埃及王法老对所有依靠他的人都是这样。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 31:1; 列王纪下 18:4–5; 马太福音 27:43"> 你们也许会对我说‘我们依靠耶和华我们的神’，但希西加除掉了这神的高坛和祭坛，还对犹大和耶路撒冷的人说‘你们当在耶路撒冷这祭坛前敬拜！’难道耶和华不就是这神吗？</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 17:42; 列王纪上 20:10; 尼希米记 4:2–5"> 现在你可以与我主亚述王下一个赌注：你那边如果能给出相应的骑士，我就给你两千匹马；</span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 10:8; 申命记 17:16; 以赛亚书 36:6"> 如果不能，你怎能击退我主的臣仆中至小的一个军官呢？你竟敢依靠埃及的战车和马兵！</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 19:6; 以赛亚书 10:5–6; 列王纪下 19:22–37"> 现在，我上来攻打这地方，要把它毁灭，难道不是出于耶和华吗？是耶和华对我说‘你要上去攻打这地，把它毁灭！’”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以斯拉记 4:7; 但以理书 2:4; 以赛亚书 36:11–12"> 希勒加的儿子以利亚敬、舍伯纳、约亚对将军说：“求你用亚兰语对仆人们说话，因为我们听得懂；不要用犹大话对我们说话，免得达到城墙上众人的耳中。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="诗篇 73:8; 耶利米哀歌 4:5; 以西结书 4:15"> 将军却对他们说：“难道我的主人派我来，只对你和你的主人说这些话吗？不也对那些坐在城墙上，将与你们一同吃自己粪、喝自己尿的人说话吗？”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 36:13–18; 以赛亚书 10:8–13; 以西结书 29:3"> 然后，将军站着用犹大话大声呼喊，宣告说：<br />“你们要听亚述大王的话！</span>
<span className="v" id="v29" data-v="29" data-xref="历代志下 32:15; 帖撒罗尼迦后书 2:8; 历代志下 32:11"> 王如此说：‘不要让希西加欺哄你们，因为他不能解救你们脱离王的手；</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 125:1–2; 路加福音 23:35; 列王纪下 19:32–34"> 也不要让希西加说服你们依靠耶和华，因为他会说：耶和华必定解救我们，这城必不落入亚述王手中。’</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪上 4:25; 列王纪上 4:20; 撒迦利亚书 3:10"> “你们不要听希西加的话，因为亚述王如此说：‘你们要与我和好，出来向我投降，各人就可以吃自己葡萄树和无花果树的果实，喝自己水窖里的水；</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 8:7–9; 出埃及记 3:8; 申命记 11:12"> 以后我会来，把你们带到一个地方，与你们本土一样，是一个有五谷和新酒的地方，一个有粮食和葡萄园的地方，有橄榄油和蜂蜜的地方，好使你们存活，不至于死。不要听希西加，因为他误导你们，说：耶和华必解救我们。</span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 10:10–11; 列王纪下 19:12–13; 历代志下 32:19"> 列国的神明中，有哪一个曾真正解救自己的国土脱离亚述王的手呢？</span>
<span className="v" id="v34" data-v="34" data-xref="以赛亚书 10:9; 列王纪下 17:23–33; 耶利米书 49:23"> 哈马和阿尔帕的神在哪里呢？西法瓦音、希拿和伊瓦的神在哪里呢？难道他们曾解救撒玛利亚脱离我的手吗？</span>
<span className="v" id="v35" data-v="35" data-xref="但以理书 3:15; 以赛亚书 10:15; 出埃及记 5:2"> 这些国所有的神明中，有哪一个曾解救自己的国土脱离我的手呢？难道耶和华会解救耶路撒冷脱离我的手吗？’”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="阿摩司书 5:13; 箴言 9:7; 马太福音 7:6"> 众人都默不作声，一句也不回应，因为希西加王有令说：“不许回应他。”</span>
<span className="v" id="v37" data-v="37" data-xref="列王纪下 22:11; 创世记 37:29; 列王纪下 5:7"> 希勒加的儿子宫廷总管以利亚敬，书记舍伯纳，以及亚萨的儿子史官约亚，都撕裂衣服来到希西加那里，把将军的话告诉了他。</span>
</div>
</div>

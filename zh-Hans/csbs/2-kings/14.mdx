<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="2KI" data-book-slug="2-kings" data-book-name="列王纪下" data-chapter="14" data-verses="29">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 13:10; 历代志下 25:1–4; 列王纪下 14:15"> 约哈斯的儿子以色列王约阿施在位第二年，犹大王约阿施的儿子亚玛谢作王。</span>
<span className="v" id="v2" data-v="2"> 他作王的时候二十五岁，在耶路撒冷统治了二十九年。他的母亲名叫耶赫阿丹，是耶路撒冷人。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 25:2–3; 撒迦利亚书 1:4–6; 列王纪上 11:4"> 他做耶和华眼中看为正的事，只是不如他的先祖大卫；他效法他父亲约阿施所做的一切。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 12:3; 列王纪下 16:4; 列王纪下 15:35"> 只是那些高坛还没有除掉，百姓仍旧在高坛献祭烧香。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="历代志下 25:3–4; 列王纪下 12:20–21; 民数记 35:33"> 当他手中的王权稳固后，他就把杀他父王的臣仆都杀掉了。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 24:16; 以西结书 18:20; 以西结书 18:4"> 但他没有处死那些凶手的儿子，是照着摩西律法书上所记的，耶和华所指示的：“不可因着儿子处死父亲，也不可因着父亲处死儿子；各人只可因自己的罪过被处死。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 8:13; 历代志上 18:12; 约书亚记 15:38"> 他在盐谷击杀了一万以东人，又出战攻取了西拉，给它起名为约克帖，直到今日。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 25:17–24; 撒母耳记下 2:14–17; 列王纪下 14:11"> 此后亚玛谢派遣使者去见耶户的孙子、约哈斯的儿子以色列王约阿施，说：“来，让我们战场相见吧！”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="士师记 9:8–15; 列王纪上 4:33; 历代志下 33:11"> 以色列王约阿施就派人去见犹大王亚玛谢，说：“黎巴嫩的蒺藜派人到黎巴嫩的香柏树那里，说：‘把你的女儿嫁给我儿子为妻吧！’然而，有一只黎巴嫩的野兽经过，把那蒺藜践踏了。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 26:16; 申命记 8:14; 历代志下 32:25"> 你确实击败了以东，你的心就高傲了。你自高自大吧，但请留在家里！何必招惹祸患，使自己和犹大一同败亡呢？”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约书亚记 19:38; 历代志下 25:16; 约书亚记 15:10"> 亚玛谢却不听。于是以色列王约阿施上来，与犹大王亚玛谢在犹大的伯示麦对阵。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 18:17; 撒母耳记上 4:10; 列王纪上 22:36"> 犹大败在以色列面前，各人逃回自己的帐篷。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 8:16; 尼希米记 12:39; 撒迦利亚书 14:10"> 以色列王约阿施在伯示麦捉住了亚哈谢的孙子、约阿施的儿子犹大王亚玛谢，然后来到耶路撒冷，拆毁了耶路撒冷的城墙，从以法莲门直到角门，有四百肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="四百肘——相当于183公尺。1肘=45.7公分。">a</a></sup>。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 14:26; 列王纪上 7:51; 列王纪上 15:18"> 约阿施夺取耶和华殿中和王宫库房里所有的金银、所有的器具，并带走人质，然后回撒玛利亚去了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王纪下 13:12–13; 列王纪上 14:19–20; 列王纪下 10:34–35"> 约阿施其余的事迹，他的作为，他的武力，以及他与犹大王亚玛谢的争战，不是都记在《以色列诸王年代志》上吗？</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 13:9; 列王纪下 13:13; 列王纪上 1:21"> 约阿施与他的列祖长眠，葬在撒玛利亚，与以色列诸王在一起；他的儿子耶罗波安接替他作王。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="历代志下 25:25–28; 列王纪下 13:10; 列王纪下 14:23"> 约哈斯的儿子以色列王约阿施死后，约阿施的儿子犹大王亚玛谢又活了十五年。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 11:41; 列王纪上 14:29; 列王纪下 13:8"> 亚玛谢其余的事迹，不是都记在《犹大诸王年代志》上吗？</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 10:31; 列王纪下 15:25; 列王纪下 12:20–21"> 有人在耶路撒冷密谋反叛他，他就逃到拉吉，但他们派人追到拉吉，在那里杀了他。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 9:28; 列王纪下 12:21; 历代志下 33:20"> 人们用马把他驮回来，葬在耶路撒冷的大卫城，与他的列祖在一起。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王纪下 21:24; 马太福音 1:8–9; 列王纪下 15:13"> 犹大全体民众选立亚撒利雅<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="亚撒利雅——又称“乌西雅”；见《历代志下》26:1。">b</a></sup>，接替他父亲亚玛谢作王，那时他十六岁。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 16:6; 列王纪上 9:26; 申命记 2:8"> 亚玛谢王与列祖长眠之后，亚撒利雅重建埃拉特，使它回归犹大。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="何西阿书 1:1; 阿摩司书 7:9–11; 阿摩司书 1:1"> 约阿施的儿子犹大王亚玛谢在位第十五年，以色列王约阿施的儿子耶罗波安在撒玛利亚作王，统治了四十一年。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪下 13:6; 列王纪下 13:11; 创世记 38:7"> 他做耶和华眼中看为恶的事，不离开尼八之子耶罗波安使以色列所犯的一切罪恶。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="申命记 3:17; 马太福音 12:39–40; 约书亚记 19:13"> 他收复以色列的边界，从哈马隘口直到亚拉巴海，正如以色列的神耶和华藉着他的仆人——迦特希弗人亚米太的儿子先知约拿所宣告的话。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 32:36; 出埃及记 3:7; 列王纪下 13:4"> 因为耶和华看见了以色列的苦难，无论是为奴的还是自由的，都极其悲惨，也没有人帮助以色列。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 13:23; 列王纪下 13:5; 罗马书 11:2–12"> 其实耶和华并没有说要把以色列的名号从天下抹掉，所以他藉着约阿施的儿子耶罗波安的手拯救了他们。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王纪上 11:24; 历代志上 18:5–6; 撒母耳记下 8:6"> 耶罗波安其余的事迹和他所做的一切，以及他的武力和争战，他怎样把犹大时期拥有的大马士革和哈马收回归于以色列，不是都记在《以色列诸王年代志》上吗？</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪下 15:8"> 耶罗波安与他的列祖以色列诸王长眠，他的儿子撒迦利亚接替他作王。</span>
</div>
</div>

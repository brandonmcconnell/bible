<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="2KI" data-book-slug="2-kings" data-book-name="列王纪下" data-chapter="23" data-verses="37">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 34:29–33; 历代志下 30:2; 申命记 31:28"> 王派人去，招聚了犹大和耶路撒冷所有的长老到他那里。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 22:8; 申命记 31:10–13; 启示录 20:12"> 然后，王与犹大众人、全耶路撒冷的居民、祭司、先知、全体民众，无论尊卑，都一起上耶和华的殿去。王就把耶和华殿中发现的约书上一切话语，宣读给他们听。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 11:14; 列王纪下 11:17; 申命记 13:4"> 王站在柱子旁边，在耶和华面前立约，要全心、全灵跟从耶和华，遵守他的诫命、法度和律例，履行这书卷上所记的圣约之言。全体民众也都归入这约。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 21:3; 列王纪下 21:7; 历代志下 33:3"> 王吩咐大祭司希勒加、副祭司们以及门卫，把那些为巴力、亚舍拉和天上的万象所造的一切器具从耶和华圣殿中搬出去，在耶路撒冷外面汲沦溪谷的田野焚烧了，然后把灰烬运到伯特利。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 44:17–19; 列王纪下 21:3–4; 何西阿书 10:5"> 他还驱除犹大列王所指派的那些服事偶像的祭司，就是在犹大各城的高坛和耶路撒冷四周烧香的祭司，并且驱除那些向巴力、太阳、月亮、星辰和天上万象烧香的人。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 34:4; 列王纪下 23:15; 列王纪上 14:23"> 他把亚舍拉柱从耶和华的殿搬出去，带到耶路撒冷外面的汲沦溪谷，在汲沦溪谷焚烧了，磨碎成灰，然后把灰撒在平民的坟墓上。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 15:12; 以西结书 16:16; 列王纪上 14:24"> 他拆毁了耶和华殿中男庙妓的房屋，那里也是妇女们为亚舍拉编织帐幔的地方。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪上 15:22; 约书亚记 21:17; 列王纪上 19:3"> 他从犹大各城把那些祭司全召来，将祭司们烧香的高坛都玷污了，从迦巴直到比尔-谢巴。他也拆毁了城门口的高坛，就在城主约书亚的城门入口处、城门的左边。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 44:10–14; 撒母耳记上 2:36; 玛拉基书 2:8–9"> 然而，那些高坛的祭司没有上耶路撒冷耶和华的祭坛，只是与兄弟们一起吃了无酵饼。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 30:33; 耶利米书 19:6; 利未记 18:21"> 他还把欣嫩子谷的陀斐特玷污了，以免有人使儿女经火献给摩洛。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 8:16; 申命记 4:19; 历代志下 14:5"> 他从耶和华殿的入口、前院中内臣拿单米勒的房间旁边，除掉了犹大列王献给太阳的马匹，用火焚烧了太阳战车。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王纪下 21:5; 西番雅书 1:5; 耶利米书 19:13"> 犹大列王在亚哈斯楼阁屋顶上所筑的祭坛，以及玛拿西在耶和华的殿两个院子内所筑的祭坛，约西亚王都拆毁捣碎了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="捣碎了——或译作“从那里除去了”。">a</a></sup>，把碎屑扔进汲沦溪谷。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 11:7; 列王纪上 11:5; 民数记 21:29"> 王还把耶路撒冷东边邪僻山南面的高坛玷污了，这些都是从前以色列王所罗门为西顿人的可憎偶像亚斯她录、摩押人的可憎偶像基抹、亚扪人的可憎偶像米勒公所建造的。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 7:5; 出埃及记 23:24; 列王纪下 23:16"> 他打碎神柱，砍倒亚舍拉柱，使那些地方布满了人的骸骨。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王纪下 23:6; 列王纪上 14:16; 列王纪上 21:22"> 此外还有伯特利的祭坛，以及尼八之子耶罗波安所建造使以色列犯罪的高坛，王也把这祭坛和高坛拆毁了。他烧毁高坛，把残余磨碎成灰，并烧毁亚舍拉柱。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 13:1–2; 列王纪上 13:32; 约翰福音 10:35"> 约西亚回头，看见山上的那些坟墓，就派人从坟墓里取出骸骨，在祭坛上焚烧，玷污了祭坛，正如从前神人预言这些事情时所宣告的耶和华的话语。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 13:1; 列王纪上 13:30–31"> 王问：“我看见的这石碑是谁的？”<br />那城的人告诉王：“这是以前那位从犹大来的神人的坟墓，他曾宣告了你现在向伯特利的祭坛所做的这些事。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王纪上 13:31; 列王纪上 13:1–22"> 王说：“让他安息吧！不要让人惊动他的骸骨。”于是他们保全了他的骸骨，以及从撒玛利亚来的那位先知的骸骨。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="历代志下 34:6–7; 列王纪下 17:9; 以西结书 8:17–18"> 从前以色列诸王在撒玛利亚各城建造高坛庙宇，以致惹怒耶和华，约西亚也把它们全都除掉了。他照着在伯特利的一切处理方式，处理它们。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 11:18; 历代志下 34:5; 出埃及记 22:20"> 他把那里所有的高坛祭司都斩杀<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="斩杀——或译作“祭献”。">b</a></sup>在祭坛上，并在祭坛上焚烧人的骸骨。之后，他回耶路撒冷去了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命记 16:1–8; 民数记 9:2–5; 历代志下 35:1–19"> 王吩咐全体民众说：“你们要照着这约书上所记的，向你们的神耶和华守逾越节。”</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 30:1–3; 历代志下 30:13–20; 历代志下 35:3–19"> 从士师治理以色列的日子，到以色列和犹大列王的整个时期，实在没有守过像这样的逾越节；</span>
<span className="v" id="v23" data-v="23"> 只有约西亚王第十八年，在耶路撒冷向耶和华守了这样的逾越节。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="利未记 19:31; 列王纪下 21:6; 创世记 31:19"> 此外，在犹大地和耶路撒冷所见的招魂者、通灵者、家族神像、偶像，以及一切可憎之物，约西亚也都清除了，为要履行祭司希勒加在耶和华殿中发现的书卷上所记律法的话语。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 18:5; 耶利米书 29:13; 申命记 6:5"> 在他以前从来没有一个王像他那样照着摩西的全部律法，全心、全灵、全力回转归向耶和华，在他之后也没有兴起一个像他那样的。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王纪下 21:11–13; 列王纪下 24:4; 耶利米书 3:7–10"> 然而，因着玛拿西惹怒耶和华的种种挑衅行为，耶和华还是没有收回他向犹大所发的极其猛烈的怒气。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 18:11; 列王纪下 21:13; 列王纪下 21:4"> 耶和华说：“我要像驱逐以色列那样，也把犹大从我面前驱逐了。我要弃绝我所选择的这城耶路撒冷，以及我曾说‘我的名必常在那里’的这殿宇。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王纪下 20:20"> 约西亚其余的事迹和他所做的一切，不是都记在《犹大诸王年代志》上吗？</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 46:2; 历代志下 35:20–24; 士师记 5:19"> 约西亚年间，埃及王法老尼科上来攻打幼发拉底河那里的亚述王，约西亚王去迎战他。法老在米吉多见到约西亚时，把他杀了。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 9:28; 历代志下 36:1–4; 列王纪下 21:24"> 他的臣仆用车把他的尸体从米吉多运走，带回耶路撒冷，葬在他的坟墓里。那地的民众选择约西亚的儿子约哈斯，膏抹了他，立他为王接替他父亲。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="历代志上 3:15; 列王纪下 24:18; 耶利米书 22:11"> 约哈斯作王的时候二十三岁，在耶路撒冷统治了三个月。他的母亲名叫哈慕她勒，是立拿人耶利米的女儿。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪下 21:2–7; 列王纪下 21:21–22"> 他效法他的祖先所做的一切，做耶和华眼中看为恶的事。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪上 8:65; 列王纪下 25:6; 耶利米书 39:5–6"> 法老尼科把他囚禁在哈马地的利比拉，不让他在耶路撒冷作王，并且罚了犹大国一百他连得<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一百他连得——相当于3.4公吨。">c</a></sup>银子、一他连得<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一他连得——相当于34.2公斤。">d</a></sup>金子。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="以西结书 19:3–4; 列王纪下 24:17; 历代志上 3:15"> 法老尼科立约西亚的儿子以利亚敬为王接替他父亲约西亚，把他的名字改为约雅敬。然后尼科带走约哈斯，把他带到埃及去了，后来他死在那里。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪下 23:33; 列王纪下 15:19–20"> 约雅敬向法老上交金银，但他为了按照法老的要求上交银子，就向本国摊派。他照着自己给各人的估价，向国民索取金银，为要上交给法老尼科。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="历代志下 36:5; 耶利米书 26:1; 历代志上 3:15"> 约雅敬作王的时候二十五岁，在耶路撒冷统治了十一年。他的母亲名叫泽布达，是鲁玛人皮达雅的女儿。</span>
<span className="v" id="v37" data-v="37" data-xref="历代志下 33:22–23; 以西结书 19:5–9; 耶利米书 36:31"> 约雅敬效法他祖先所做的一切，做耶和华眼中看为恶的事。</span>
</div>
</div>

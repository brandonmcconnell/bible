<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以弗所书 4:31; 雅各书 1:21; 雅各书 4:11"> 所以，你们要脱去一切恶毒、一切诡诈、伪善、嫉妒，以及一切的诽谤，</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 5:12–13; 以弗所书 4:15; 彼得后书 3:18"> 要像刚出生的婴孩一样，爱慕那纯净的话语之奶，好使你们藉着它成长，以至于救恩<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本没有“以至于救恩”。">a</a></sup>，</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 34:8; 希伯来书 6:5–6; 诗篇 63:5"> 因为你们尝过主仁慈的滋味。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 118:22–23; 使徒行传 4:11–12; 彼得前书 2:7"> 你们来到那活石面前——他虽然被人弃绝，却是神所拣选、所珍贵的——</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 2:20–22; 彼得前书 2:9; 哥林多前书 3:9"> 你们也就像活石，被建造成一座属灵的殿宇<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="殿宇——原文直译“家”。">b</a></sup>，进入圣洁的祭司体系，好藉着耶稣基督献上蒙神悦纳的属灵祭物，</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 28:16; 罗马书 9:32–33; 彼得前书 2:4"> 因为经上记着：<br /><span className="pl pl-1">“看哪，我在锡安放一块</span><br /><span className="pl pl-1">蒙拣选的、珍贵的房角石，</span><br /><span className="pl pl-1">信靠他的人绝不至于蒙羞。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="诗篇 118:22–23; 马可福音 12:10–11; 使徒行传 4:11–12"> 这样，对你们信的人来说，他是尊贵的；但是对那些不信的人来说，却是<br /><span className="pl pl-1">“工匠所弃绝的石头，</span><br /><span className="pl pl-1">它已经成了房角的头块石头。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 8:14; 哥林多前书 1:23; 罗马书 9:32–33"> 并且是<br /><span className="pl pl-1">“一块绊脚的石头，</span><br /><span className="pl pl-1">使人绊倒的磐石。”</span><br />他们绊倒是因为不肯信从这话语，而这也是被预定的。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 19:5–6; 申命记 7:6; 启示录 1:6"> <span className="pl pl-1">但你们属于蒙拣选的族类、君王的祭司体系、</span><br /><span className="pl pl-1">圣洁的国度 ，是属神的</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="属神的——原文直译“所获得的”或“财产的”。">c</a></sup><br /><span className="pl pl-1">子民 ；</span><br /><span className="pl pl-1">为要使你们宣扬曾召唤你们的那一位的美德——</span><br /><span className="pl pl-1">他召唤你们出黑暗，入他奇妙的光明。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="何西阿书 2:23; 希伯来书 4:16; 何西阿书 1:9–10"> <span className="pl pl-1">你们从前不是子民，</span><br /><span className="pl pl-1">但如今却是神的子民；</span><br /><span className="pl pl-1">从前没有蒙怜悯，</span><br /><span className="pl pl-1">但如今却蒙了怜悯。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约翰一书 2:15–17; 加拉太书 5:24; 彼得前书 4:2"> 各位蒙爱的人哪，我劝你们：做为过客和寄居的，要远避那与你们灵魂争战的肉体欲望。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 3:16; 马太福音 5:16; 提多书 2:7–8"> 你们在外邦人中，要有良好的品行；这样，当他们诽谤你们是作恶之人的时候，因看到你们美好的行为，就在神<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="神——辅助词语。">d</a></sup>临到<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="临到——或译作“探望”。">e</a></sup>的日子荣耀神。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="提多书 3:1; 罗马书 13:1–7; 提摩太前书 2:1–2"> 为了主的缘故，你们要服从人的一切制度；无论是在上的君王，</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 13:3–4"> 或是他所委派来惩恶赏善的那些官员<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="官员——或译作“总督”。">f</a></sup>；</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 3:17; 提多书 2:8; 马太福音 7:26"> 因为神的旨意就是要你们藉着行善，堵住那些愚妄人无知的口。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太书 5:13; 罗马书 6:22; 罗马书 6:18"> 做为自由人，你们不可拿自由当做恶事的借口，却要做神的奴仆。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 24:21; 罗马书 12:10; 罗马书 13:7"> 你们应当尊重所有的人，爱弟兄姐妹，敬畏神，尊重君王。</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="提多书 2:9–10; 以弗所书 6:5–7; 歌罗西书 3:22–25"> 你们做家仆的，应当以完全敬畏的心服从主人；不仅要服从善良温和的，就是乖僻的，也要服从。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 5:10–12; 彼得前书 3:14–17; 彼得前书 2:20"> 因为人如果为了在神面前良心的缘故，在不公正的苦害中忍受忧患，这是可称赞的；</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前书 2:19; 彼得前书 3:17; 马太福音 5:10–12"> 就是说，如果你们因犯罪受责打而忍耐，有什么可称赞的呢？但如果你们因行善受苦害而忍耐，这在神看来是可称赞的。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 2:6; 马太福音 16:24; 约翰福音 13:15"> <span className="pl pl-1">原来你们是为此蒙召的，</span><br /><span className="pl pl-1">因为基督也为你们受了苦害，</span><br /><span className="pl pl-1">给你们留下了榜样，</span><br /><span className="pl pl-1">好让你们追随他的脚踪。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 53:9; 哥林多后书 5:21; 希伯来书 4:15"> <span className="pl pl-1">他没有犯过罪，</span><br /><span className="pl pl-1">在他口中也找不出诡诈；</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 53:7; 彼得前书 4:19; 希伯来书 12:3"> <span className="pl pl-1">他被辱骂的时候，不还口；</span><br /><span className="pl pl-1">受苦害的时候，不说威吓的话，</span><br /><span className="pl pl-1">而是把自己交托给以公义施行审判的那一位。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 53:4–6; 马太福音 8:17; 罗马书 6:11"> <span className="pl pl-1">他在木头上，以自己的身体亲自担当了我们的罪孽，</span><br /><span className="pl pl-1">好使我们既然向罪而死，</span><br /><span className="pl pl-1">就能向义而活；</span><br /><span className="pl pl-1">因他受的鞭伤，你们得了痊愈。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 53:6; 以西结书 34:6; 路加福音 15:4–6"> <span className="pl pl-1">要知道，你们从前像是迷失的羊，</span><br /><span className="pl pl-1">但现在却回到了</span><br /><span className="pl pl-1">你们灵魂</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="灵魂——或译作“生命”。">g</a></sup><br /><span className="pl pl-1">的牧人和监督的身旁。</span></span>
</div>

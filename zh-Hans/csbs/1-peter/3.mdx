<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 3:18; 以弗所书 5:33; 以弗所书 5:22–24"> 同样，你们做妻子的，要服从自己的丈夫。这样，即使有不肯信从这话语的丈夫，他们也会被感化<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="被感化——原文直译“被赢得”。">a</a></sup>过来，不是因着妻子的话语，而是因着妻子的品行，</span>
<span className="v" id="v2" data-v="2" data-xref="彼得前书 2:12; 彼得前书 1:15; 腓立比书 1:27"> 因为看见了你们怀有敬畏之心的贞洁品行。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前书 2:9–10; 罗马书 12:2; 以赛亚书 3:18–24"> 你们的美丽之处不应该是外在的，如编头发、戴金饰、穿华服，</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 3:12; 撒母耳记上 16:7; 罗马书 2:29"> 而应该是心里面内在的人，带着不朽坏的品性<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="品性——辅助词语。">b</a></sup>，出于谦和、安静的灵；这在神面前是极其贵重的。</span>
<span className="v" id="v5" data-v="5" data-xref="提多书 2:3–4; 提摩太前书 5:5; 路加福音 2:37"> 实际上，从前盼望神的那些圣洁妇女，也是这样装饰自己，服从自己丈夫的；</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 18:12; 罗马书 9:7–9; 以赛亚书 57:11"> 就像撒拉顺从亚伯拉罕，称他为主那样；当你们行善而不怕任何惊扰的时候，就成为撒拉的儿女了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歌罗西书 3:19; 创世记 2:23–24; 马太福音 19:3–9"> 同样，你们做丈夫的，要按情理与妻子同住，将女性当做比较软弱的器皿而尊重她们，也当做是生命之恩的共同继承人。这样，你们的祷告就不会受拦阻。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="罗马书 12:10; 以弗所书 4:31–2; 彼得前书 1:22"> 总而言之，你们大家都要心思一致，互相同情，相爱如弟兄，心存怜悯，满有谦卑<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="满有谦卑——有古抄本作“待人友善”。">c</a></sup>。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 20:22; 罗马书 12:17; 罗马书 12:14"> 不要以恶报恶，以辱骂还辱骂，反要祝福，因为<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附“你们知道”。">d</a></sup>你们是为此蒙召的，好使你们继承祝福。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 34:12–16; 雅各书 1:26; 彼得前书 2:1"> <span className="pl pl-1">要知道，“那愿意爱惜生命、</span><br /><span className="pl pl-1">愿意见到好日子的人，</span><br /><span className="pl pl-1">要停止舌头出恶言，</span><br /><span className="pl pl-1">不让嘴唇说诡诈的话；</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 5:9; 诗篇 34:14; 希伯来书 12:14"> <span className="pl pl-1">要远离邪恶，要行美善，</span><br /><span className="pl pl-1">要寻求和睦，要竭力追求；</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 34:15–16; 约翰福音 9:31; 箴言 15:29"> <span className="pl pl-1">因为主的眼睛看顾义人，</span><br /><span className="pl pl-1">主的耳朵垂听他们的祈祷；</span><br /><span className="pl pl-1">但主的脸却敌对作恶的人。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="箴言 16:7; 罗马书 8:28; 帖撒罗尼迦前书 5:15"> 如果你们是为美善而热心<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="为美善而热心——有古抄本作“效法美善”。">e</a></sup>的人，谁会伤害你们呢？</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 10:28; 彼得前书 2:19–20; 马太福音 5:10–12"> 然而，即使你们为义受苦，也是蒙福的。不要怕他们所惧怕的<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="他们所惧怕的——或译作“他们的恐吓”。">f</a></sup>，也不要惊慌不安，</span>
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 4:6; 提摩太后书 2:25–26; 路加福音 21:14–15"> 只要你们心里尊主基督<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="基督——有古抄本作“——神”。">g</a></sup>为圣，无论谁要你们对你们里面的盼望做个交代，你们都要随时预备好答复他；</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前书 2:12; 希伯来书 13:18; 彼得前书 2:15"> 不过要以温柔、敬畏的心答复，并且持守无愧的良心，以致谁诋毁你们在基督里的良好品行，谁就要在你们受到诽谤的事上蒙羞。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前书 3:14; 彼得前书 4:19; 马太福音 26:39"> 要知道，即使神的旨意要你们因行善而受苦，也比因作恶而受苦更好，</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 9:28; 希伯来书 9:26; 哥林多后书 5:21"> <span className="pl pl-1">因为基督也曾一次为了赎罪而受苦</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="为了赎罪而受苦——有古抄本作“为了赎我们的罪而死”或“为我们的罪孽死了”或“为你们的罪孽死了”。">h</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">就是义的代替不义的，</span><br /><span className="pl pl-1">为要把你们</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="你们——有古抄本作“我们”。">i</a></sup><br /><span className="pl pl-1">带到神的面前。</span><br /><span className="pl pl-1">照着肉身说，基督固然被处死了；</span><br /><span className="pl pl-1">但照着灵说，他却得以复活了。</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="彼得前书 4:6; 以赛亚书 61:1; 以赛亚书 42:7"> 藉着灵，他也曾去传道给那些被监禁的灵魂，</span>
<span className="v" id="v20" data-v="20" data-xref="希伯来书 11:7; 彼得后书 2:5; 创世记 6:3"> 就是从前在挪亚建造方舟的那些日子里，在神耐心等待的时候那些不肯信从的灵魂。当时进入方舟，藉着水获救的人很少，只有八个人<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="人——原文直译“灵魂”。">j</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="马可福音 16:16; 以西结书 36:25–26; 使徒行传 2:38"> 这水所象征的洗礼，如今也藉着耶稣基督的复活拯救你们<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="你们——有古抄本作“我们”。">k</a></sup>，不是清除肉体的污秽，而是向神恳求<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="恳求——或译作“宣誓”。">l</a></sup>无愧的良心。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 9:24; 希伯来书 12:2; 希伯来书 10:12"> 耶稣基督已经升天，就在神的右边，天使们、掌权的、有势力的，都服从了他。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="雅各书 1:1; 使徒行传 2:5–11; 希伯来书 11:13"> 耶稣基督的使徒彼得，<br />致那些蒙拣选，分散在本都、加拉太、卡帕多细亚、亚细亚、比提尼亚寄居的人，</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦后书 2:13; 以弗所书 1:4–5; 希伯来书 12:24"> 就是按照父神的预知，藉着圣灵分别为圣，以致顺从耶稣基督，又蒙他宝血所洒的人：<br />愿恩典与平安多多地加给你们！</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="彼得前书 1:23; 约翰一书 5:4; 罗马书 15:13"> 愿颂赞归于神——我们主耶稣基督的父！他照着自己极大的怜悯，藉着耶稣基督从死人中的复活，使我们重生，得着永生的盼望，</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 21:27; 希伯来书 9:15; 彼得前书 5:4"> 得着不会朽坏、不会玷污、不会衰残、保存<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="保存——原文直译“为你们保存”。">a</a></sup>在天上的继业；</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 1:6; 以弗所书 2:8; 帖撒罗尼迦后书 2:13–14"> 你们藉着信，在神的大能中蒙保守，以至于那预备好要在末世显现的救恩。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 1:2; 彼得前书 5:10; 罗马书 12:12"> 为此，你们欢欣跳跃，但如今必须在种种试炼中暂时忧伤，</span>
<span className="v" id="v7" data-v="7" data-xref="约伯记 23:10; 以赛亚书 48:10; 彼得前书 4:12"> 好让你们的信仰经过考验，就比那被火炼过仍然会朽坏的金子更加宝贵，能在耶稣基督显现的时候，被看为是可以得着称赞、荣耀和尊贵的。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 20:29; 哥林多后书 5:7; 罗马书 15:13"> 你们虽然没有见过他，却爱他；虽然如今看不到他，却信他，并且怀着无法描述、充满荣耀的喜乐而欢欣跳跃，</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 6:22; 雅各书 1:21; 希伯来书 11:13"> 因为你们正在领受你们信仰的结果，就是灵魂的救恩。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 13:17; 路加福音 10:24; 路加福音 24:25–27"> 关于这救恩，那些预言你们要得着这恩典的先知，曾经寻求过，详细查考过。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 52:13–14; 彼得后书 1:21; 路加福音 24:25–27"> 他们查考了自己里面基督之灵，当他预言有关基督的苦难和此后的荣耀时，究竟指明的是什么时候、或什么样的情况。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 15:26; 哥林多前书 2:10; 以弗所书 3:10"> 他们蒙了启示，知道所服事的这一切，不是为自己，而是为你们。如今，这些事藉着从天上派来的圣灵，通过那些向你们传福音的人，传讲给了你们；对于这些事，天使们也渴望能详细察看。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="彼得前书 5:8; 路加福音 12:35; 彼得前书 4:7"> 因此，你们要约束自己的意念<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="约束自己的意念——原文直译“束上自己意念的腰带”。">b</a></sup>，要谨慎，要把盼望完全寄托在耶稣基督显现时带给你们的恩典上。</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 12:2; 提多书 3:3–5; 彼得前书 4:2–3"> 做为顺从的儿女，不可效法你们原先愚昧无知时的那些欲望；</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 5:48; 哥林多后书 7:1; 希伯来书 12:14"> 相反，正如召唤你们的那一位是圣洁的，你们在一切行为上也当成为圣洁的，</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 11:44; 利未记 19:2; 利未记 20:7"> 因为经上记着：“你们当成为圣洁的，因为我是圣洁的。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行传 10:34–35; 历代志下 19:7; 马太福音 6:9"> 你们既然称不偏待人、只按每个人的行为施行审判的那一位为父，就应当怀着敬畏的心，过你们寄居的日子，</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 6:20; 提多书 2:14; 诗篇 49:7–8"> 因为你们知道，你们被救赎，脱离祖先所传下来的虚妄行为，不是凭着会朽坏的东西，如银子或金子，</span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 1:7; 彼得前书 2:22–24; 约翰福音 1:29"> 而是凭着那像羔羊一样毫无瑕疵、毫无玷污的基督宝血。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 1:4; 提摩太后书 1:9–10; 希伯来书 9:26"> 基督在创世以前就已经被神<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="神——辅助词语。">c</a></sup>预先知道，又在这末后的时代为你们的缘故显明出来。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 2:24; 希伯来书 2:9; 约翰福音 12:44"> 藉着基督<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="基督——原文直译“他”。">d</a></sup>，你们信靠那使他从死人中复活、又赐他荣耀的神，以致你们的信仰和盼望也都在于神。</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="提摩太前书 1:5; 希伯来书 13:1; 罗马书 12:9–10"> 你们既然藉着顺从真理，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附“藉着圣灵”。">e</a></sup>使自己的灵魂<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="灵魂——或译作“生命”。">f</a></sup>纯洁，以致有了不虚假的弟兄之爱，就应当以洁净的心<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="以洁净的心——有古抄本作“从心里”。">g</a></sup>，彼此热切地相爱。</span>
<span className="v" id="v23" data-v="23" data-xref="彼得前书 1:3; 希伯来书 4:12; 约翰福音 1:13"> 你们得以重生，不是出于会朽坏的种子，而是出于不朽坏的种子，是藉着神永活长存的话语，</span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 40:6–8; 诗篇 103:15; 雅各书 4:14"> 因为，<br /><span className="pl pl-1">“所有的人</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="人——原文直译“肉体”。">h</a></sup><br /><span className="pl pl-1">都像草一样，</span><br /><span className="pl pl-1">他们的一切荣耀就像草上的花；</span><br /><span className="pl pl-1">草会枯干，花会凋谢，</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 40:8; 马太福音 5:18; 诗篇 119:89"> <span className="pl pl-1">但主的话却永远长存。”</span><br />所传给你们的福音就是这话。</span>
</div>
</div>

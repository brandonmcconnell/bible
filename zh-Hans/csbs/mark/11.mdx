<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 21:1–11; 约翰福音 12:14–19; 路加福音 19:29–40"> 当耶稣和门徒们临近耶路撒冷，到橄榄山附近的伯法其和伯大尼的时候，耶稣派了他的两个门徒，</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 21:2–3; 路加福音 19:30–31"> 对他们说：<span className="woj">“你们到对面的村子里去。你们一进村，就会发现一头驴驹拴在那里，是从来没有人骑过的。你们把它解开牵过来。</span></span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 10:36; 马可福音 14:15; 诗篇 110:3"> <span className="woj">如果有人问你们为什么这么做，你们就说‘主需要它</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="主需要它——或译作“它的主人有需要”。">a</a></sup><span className="woj">，会很快把它送回这里来的。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="马太福音 26:19; 路加福音 19:32–34; 马太福音 21:6–7"> 两个门徒去了，果然发现一头驴驹拴在岔路口一个门外，他们就解开驴驹。</span>
<span className="v" id="v5" data-v="5"> 站在那里的一些人问：“你们解开驴驹做什么呢？”</span>
<span className="v" id="v6" data-v="6"> 他们就照着耶稣所吩咐的回答，那些人就让他们牵走<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="牵走——辅助词语。">b</a></sup>了。</span>
<span className="v" id="v7" data-v="7" data-xref="撒迦利亚书 9:9; 路加福音 19:35–36; 马太福音 21:7–8"> 他们牵着驴驹到耶稣那里，把自己的外衣垫在驴驹上，耶稣就骑了上去。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="利未记 23:40"> 许多人把自己的外衣铺在路上，也有人从田野里<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="从田野里——有古抄本作“从树上”。">c</a></sup>砍来树枝铺在路上<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本没有“铺在路上”。">d</a></sup>。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 118:25–26; 马太福音 21:9; 马太福音 23:39"> 前行后随的人都呼喊：<br /><span className="pl pl-1">“和散那！</span><br /><span className="pl pl-1">奉主名而来的那一位——是蒙祝福的！</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 37:24–25; 路加福音 2:14; 路加福音 19:38–40"> <span className="pl pl-1">那</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附“奉主名”。">e</a></sup><br /><span className="pl pl-1">将要来的，我们先祖大卫的国度——是蒙祝福的！</span><br /><span className="pl pl-1">在至高之处——和散那！”</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约翰福音 8:1–2; 路加福音 19:41–45; 路加福音 21:37–38"> 耶稣进了耶路撒冷，来到圣殿，环视周围的一切。天已经晚了，他就与十二使徒<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="使徒——辅助词语。">f</a></sup>一同离开，往伯大尼去了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 21:18–22; 马太福音 4:2; 约翰福音 19:28"> 第二天，当他们离开伯大尼的时候，耶稣饿了。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 21:19; 路加福音 13:6–9; 以赛亚书 5:7"> 他远远地看见一棵长满叶子的无花果树，就上前去，要看看树上是否有什么。他来到树下，除了叶子什么也找不到，因为不是结无花果的季节。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 21:19; 马太福音 7:19; 马太福音 3:10"> 于是他对那棵树说：<span className="woj">“永远不再有任何人吃到你的果子了！”</span>他的门徒都听见了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 2:13–17; 马太福音 21:12–16; 路加福音 19:45–47"> 他们来到耶路撒冷。耶稣进了圣殿，开始把那些在圣殿里做买卖的人赶出去。他推翻了兑换银币之人的桌子和卖鸽子之人的凳子，</span>
<span className="v" id="v16" data-v="16"> 也不准任何人搬运东西穿过圣殿。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 56:7; 耶利米书 7:11; 路加福音 19:46"> 耶稣教导他们说：<span className="woj">“经上不是记着‘我的殿将被称为万国祷告的殿’吗？而你们却使它成为贼窝了！”</span></span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 7:28; 马可福音 12:12; 马可福音 14:1–2"> 祭司长们和经文士们听了，就图谋怎样来除灭耶稣。原来他们怕耶稣，因为众人都对他的教导惊叹不已。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 21:37; 马可福音 11:11; 约翰福音 12:36"> 到了傍晚的时候，耶稣和门徒们就到城外去。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马太福音 15:13; 马可福音 11:14; 约翰福音 15:6"> 清晨，他们路过那棵无花果树的时候，看见它连根都枯萎了。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 3:33; 马太福音 23:7; 马太福音 25:41"> 彼得想起来就对耶稣说：“拉比，你看！你所诅咒的无花果树枯萎了！”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="诗篇 62:8; 约翰福音 14:1; 马可福音 9:23"> 耶稣对他们说：<span className="woj">“你们当对神有信心。</span></span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 17:20; 约翰福音 15:7; 马太福音 21:21"> <span className="woj">我确实地告诉你们：无论谁对这座山说‘愿你被挪开，被丢进海里去！’只要他心里不疑惑，相信自己所说的会成就，事情</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="事情——有古抄本作“凡是他所说的事情”。">g</a></sup><span className="woj">就将为他成就。</span></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 21:22; 约翰一书 5:14–15; 约翰一书 3:22"> <span className="woj">所以，我告诉你们：凡是你们所祷告和祈求的，当相信已经得着了</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="已经得着了——有古抄本作“将得到”。">h</a></sup><span className="woj">。这样，事情就将为你们成就。</span></span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 6:14–15; 歌罗西书 3:13; 以弗所书 4:32"> <span className="woj">当你们站着祷告的时候，如果向什么人怀怨，就要饶恕他。这样，你们在天上的父也会饶恕你们的过犯。</span></span>
<span className="v" id="v26" data-v="26"> <span className="woj">你们如果不饶恕别人，你们在天上的父也不会饶恕你们的过犯。</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本没有此节。">i</a></sup><span className="woj">”</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 20:1–8; 马太福音 21:23–27; 诗篇 2:1–5"> 他们又来到耶路撒冷。当耶稣在圣殿里行走的时候，祭司长们、经文士们和长老们来到他那里。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 2:14; 使徒行传 7:38–39; 民数记 16:3"> 他们问：“你凭什么权柄做这些事？谁给你这权柄，让你做这些事？”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 20:3–8; 马太福音 21:24; 以赛亚书 52:13"> 耶稣对他们说：<span className="woj">“我要问你们一个问题，你们回答我，我就告诉你们我凭什么权柄做这些事。</span></span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 3:1–20; 约翰福音 3:25–36; 马可福音 1:1–11"> <span className="woj">约翰的洗礼是来自天上，还是来自人间呢？你们回答我！”</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 1:29; 约翰福音 1:34; 马太福音 21:31–32"> 他们就彼此讨论，说：“如果我们说‘是来自天上’，他就会问‘那么你们为什么不相信他呢？’</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 21:46; 马可福音 12:12; 马太福音 14:5"> 可是我们能说‘是来自人间’吗？”原来他们怕民众，因为大家都认为约翰的确是先知。</span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 6:9–10; 哥林多后书 4:3–4; 帖撒罗尼迦后书 2:10–12"> 于是他们回答耶稣，说：“我们不知道。”<br />耶稣就对他们说：<span className="woj">“我也不告诉你们我凭什么权柄做这些事。”</span></span>
</div>
</div>

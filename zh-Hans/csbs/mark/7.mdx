<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 15:1–20; 马可福音 3:22; 路加福音 5:17"> 有些法利赛人和一些从耶路撒冷来的经文士聚集到耶稣那里。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 10:28; 马太福音 7:3–5; 罗马书 14:14"> 他们看见耶稣的一些门徒用不洁净的手，就是没有洗过的手吃饭<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="饭——原文直译“饼”。">a</a></sup><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附“就指责他们”。">b</a></sup>。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 1:14; 马可福音 7:13; 歌罗西书 2:8"> 原来，法利赛人和所有的犹太人都拘守古人的传统：如果不按规矩<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="按规矩——或译作“仔细地”。">c</a></sup>洗手就不吃饭；</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 9:10; 马太福音 23:25; 路加福音 11:38–39"> 他们从街市上回来，如果不行洗净礼，也就不吃饭；他们还有很多其他的传统要拘守，例如洗杯子、瓶子、铜器，甚至床<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本没有“甚至床”。">d</a></sup>等。</span>
<span className="v" id="v5" data-v="5" data-xref="帖撒罗尼迦后书 3:6; 使徒行传 21:21; 马太福音 15:2"> 于是，法利赛人和经文士就问耶稣：“你的门徒们为什么不照着古人的传统行事，用不洁净的<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="不洁净的——有古抄本作“没有洗过的”。">e</a></sup>手吃饭<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="饭——原文直译“饼”。">f</a></sup>呢？”</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 29:13; 提多书 1:16; 马太福音 15:7–9"> 耶稣对他们说：<span className="woj">“以赛亚指着你们这些伪善的人所说的预言是对的，正如经上所记：</span><br /><span className="pl pl-1 woj">‘这子民用嘴唇尊重我，</span><br /><span className="pl pl-1 woj">他们的心却远离我。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 29:13; 马太福音 15:9; 雅各书 1:26"> <span className="pl pl-1 woj">他们敬拜我也是徒然的，</span><br /><span className="pl pl-1 woj">因为他们把人的规条当做教义教导人</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="他们把人的规条当做教义教导人——或译作“他们教导的教义是人的规条”。">g</a></sup><br /><span className="pl pl-1 woj">。’</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="马可福音 7:3–4; 以赛亚书 1:12"> <span className="woj">你们离弃了神的命令，而拘守人的传统</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附“例如洗瓶子、杯子，还做很多其他类似这样的事”。">h</a></sup><span className="woj">。”</span></span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 44:16–17; 加拉太书 2:21; 以赛亚书 29:13"> 耶稣又对他们说：<span className="woj">“你们为了要守住你们的传统，竟然弃绝了神的命令！</span></span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 21:17; 出埃及记 20:12; 申命记 5:16"> <span className="woj">摩西吩咐过</span><br /><span className="pl pl-1 woj">‘你要孝敬你的父母’</span><br /><span className="pl pl-1 woj">，又说</span><br /><span className="pl pl-1 woj">‘咒骂父亲或母亲的人，必须处死。’</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马太福音 23:18; 提摩太前书 5:4–8; 马太福音 15:5"> <span className="woj">你们却说‘如果一个人对父亲或母亲说：我本该给你的，已经做了“各尔板”</span>——这意思是“圣殿奉献”，</span>
<span className="v" id="v12" data-v="12"> <span className="woj">就准许这个人可以不再为父母做什么了。’</span></span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 7:9; 提多书 1:14; 马太福音 5:17–20"> <span className="woj">这样，你们就藉着所继承的传统，废弃了神的话语</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="神的话语——或译作“神的道”。">i</a></sup><span className="woj">。你们还做很多类似这样的事。”</span></span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 15:10; 以赛亚书 6:9; 箴言 8:5"> 耶稣又<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本没有“又”。">j</a></sup>召来众人，对他们说：<span className="woj">“你们每个人都当听我说，也当领悟：</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 4:23; 利未记 11:42–47; 提多书 1:15"> <span className="woj">从人外面进到他里面的，没有一样能使人</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="人——原文直译“他”。">k</a></sup><span className="woj">污秽；相反，从人里面出来的，才会使人污秽。</span></span>
<span className="v" id="v16" data-v="16"> <span className="woj">凡是有耳可听的，就应当听！</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本没有此节。">l</a></sup><span className="woj">”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 15:15; 马太福音 13:36; 马可福音 9:28"> 耶稣离开人群，一进了房子，他的门徒们就问他这比喻的意思。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 15:16–17; 希伯来书 5:11; 以赛亚书 28:9–10"> 耶稣说：<span className="woj">“你们也是这样无知吗？你们难道不明白一切从外面进到人里面的，不能使人污秽吗？</span></span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 15:17; 哥林多前书 6:13; 歌罗西书 2:21–22"> <span className="woj">因为这些东西不是进到人的心里，而是进入肚子，然后排到厕所里去。”</span>耶稣这样就使一切食物都洁净。</span>
<span className="v" id="v20" data-v="20" data-xref="雅各书 3:6; 雅各书 1:14–15; 雅各书 4:1"> 他接着说：<span className="woj">“从人里面出来的，那才使人污秽。</span></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 17:9; 罗马书 8:7–8; 雅各书 4:1–3"> <span className="woj">因为从里面，就是从人心里发出种种恶念：淫乱、偷窃、杀人、</span></span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 20:15; 马太福音 6:23; 彼得前书 2:15"> <span className="woj">通奸、贪心、恶意、欺诈、好色、嫉妒、毁谤、骄傲、愚妄，</span></span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 7:15; 提多书 1:15; 哥林多前书 3:17"> <span className="woj">这一切邪恶都是从人里面出来的，而且使人污秽。”</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="马太福音 15:21–28; 马太福音 11:21; 以西结书 28:2"> 耶稣起身离开那地方到提尔和西顿<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="有古抄本没有“和西顿”。">m</a></sup>地区。他进了一户人家，本来不愿意任何人知道，却还是不能避开众人。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 15:22; 马可福音 9:17–23; 使徒行传 10:25–26"> 有一个妇人，她的女儿有污灵附着。这妇人一听说耶稣的事，就赶来俯伏在他的脚前。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 15:22; 以赛亚书 49:12; 加拉太书 3:28"> 这妇人是希腊人，出生在叙利亚的腓尼基。她请求耶稣把鬼魔从她女儿身上赶出去。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 15:23–28; 马太福音 7:6; 使徒行传 22:21"> 耶稣对她说：<span className="woj">“应该先让儿女吃饱，因为拿儿女的饼扔给小狗，是不合宜的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="罗马书 10:12; 罗马书 3:29; 使徒行传 11:17–18"> 妇人回答说：“主啊<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="主啊——有古抄本作“是的，主啊”。">n</a></sup>！连桌子底下的小狗，也吃得到孩子们的碎渣！”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 66:2; 马太福音 5:3; 约翰一书 3:8"> 耶稣对她说：<span className="woj">“凭你这句话，你可以回去了。鬼魔已经离开了你的女儿。”</span></span>
<span className="v" id="v30" data-v="30" data-xref="约翰一书 3:8; 约翰福音 4:50–52"> 妇人回到家，发现孩子<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="孩子——有古抄本作“女儿”。">o</a></sup>躺在床上，鬼魔已经离去了。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马可福音 5:20; 马太福音 15:29–31; 马太福音 4:25"> 耶稣离开提尔地区，经过西顿，从德卡波利斯境内又来到加利利湖<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="湖——原文直译“海”。">p</a></sup>边。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 11:14; 马可福音 5:23; 马太福音 9:32–33"> 有人把一个又聋又哑的人带到耶稣面前，恳求耶稣按手在他身上。</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 8:23; 约翰福音 9:6–7; 马可福音 5:40"> 耶稣把他从人群中单独带到一边去，用指头伸进他的耳朵，吐唾沫来抹他的舌头，</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 11:41; 马可福音 5:41; 马可福音 6:41"> 然后望天嘘了一口气，对他说：<span className="woj">“以法达</span><sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="以法达——亚兰文词语的音译。">q</a></sup><span className="woj">！”</span>——这意思是<span className="woj">“开了吧”。</span></span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 35:5–6; 诗篇 33:9; 马可福音 2:12"> 他的耳朵立刻开了，舌结也解了，说话也清楚了。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 8:4; 马可福音 8:26; 马可福音 3:12"> 耶稣吩咐他们不要告诉任何人。但是，他越是吩咐，他们越是大大传扬。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="马可福音 6:51; 马可福音 5:42; 出埃及记 4:10–11"> 人们极其惊讶，说：“他所做的一切都好！他甚至使聋子听见，使哑巴说话。”</span>
</div>
</div>

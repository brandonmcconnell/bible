<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 23:56–12; 约翰福音 20:1–10; 马太福音 28:1–10"> 安息日一过，茉大拉的玛丽亚、雅各的母亲<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="母亲——辅助词语。">a</a></sup>玛丽亚和莎罗美就买了香料，要去膏抹耶稣。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 20:1; 路加福音 24:1; 马太福音 28:1"> 在一周的头一天<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一周的头一天——指“星期日”。">b</a></sup>，一大清早，太阳刚出来，她们就来到墓穴那里。</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 15:46–47; 马太福音 27:60–66"> 她们互相说：“谁能替我们滚开墓穴口的石头呢？”</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 28:2–4; 路加福音 24:2; 约翰福音 20:1"> 原来那块石头非常大。可是她们抬头一看，见石头已经被滚开了。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 20:11–12; 路加福音 24:3–5; 约翰福音 20:8"> 她们进了墓穴，看见一个年轻人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一个年轻人——在《马太福音》28:2，这个年轻人是一位天使。">c</a></sup>身穿白袍坐在右边，就大吃一惊。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="启示录 1:17–18; 哥林多前书 15:3–7; 路加福音 24:46"> 那年轻人对她们说：“不要惊慌！你们是在寻找被钉十字架的拿撒勒人耶稣，他已经复活<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="复活——原文直译“被复活”；指“神使耶稣复活”。">d</a></sup>了，不在这里。看，这就是他们安放他的地方。</span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 14:28; 马太福音 26:32; 马太福音 28:10"> 你们去，告诉他的门徒们和彼得：‘他要在你们之前到加利利去。在那里，你们将见到他，正如他告诉过你们的。’”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 24:22–24; 路加福音 24:9–11; 马可福音 16:5–6"> 她们浑身颤抖、惊慌失措，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附“赶快”。">e</a></sup>从墓穴出来就逃跑了。她们因为感到惧怕，什么也没有对任何人说。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约翰福音 20:14–19; 路加福音 8:2; 约翰福音 20:12"> 在一周头一天<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一周头一天——指“星期日”。">f</a></sup>的清晨，耶稣复活以后，首先向茉大拉的玛丽亚显现。耶稣曾经从她身上赶出了七个鬼魔。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 20:18; 路加福音 24:17; 约翰福音 16:6"> 她去告诉那些向来与耶稣在一起的人，他们正在悲伤、哀哭。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 24:11; 马可福音 16:13–14; 马可福音 9:19"> 他们听见耶稣活了，又被玛丽亚看到了，却是不相信。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 24:13–32; 约翰福音 21:14; 约翰福音 21:1"> 这些事以后，门徒中有两个人往乡下去。在路上，耶稣以另一种形像向他们显现。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 20:25; 路加福音 24:33–35; 约翰福音 20:8"> 他们去告诉其他的门徒，那些门徒也不相信他们。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 15:5; 路加福音 24:36–43; 希伯来书 3:7–8"> 后来那十一个使徒吃饭的时候，耶稣向他们显现，并斥责他们的不信和心里刚硬，因为他们不相信那些在他复活后看到他的人。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 28:19; 马可福音 13:10; 使徒行传 1:8"> 耶稣对他们说：<span className="woj">“你们要到全世界去，向万人</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="万人——原文直译“一切被造之物”。">g</a></sup><span className="woj">传福音。</span></span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 11:25–26; 约翰福音 3:36; 罗马书 10:9–14"> <span className="woj">信而受洗</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="受洗——或译作“受浸”。">h</a></sup><span className="woj">的人，将会得救；不信的人，将被定罪。</span></span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 5:16; 哥林多前书 12:28; 使徒行传 8:7"> <span className="woj">这些神迹将伴随着信的人：他们将奉我的名驱赶鬼魔；说各种新的语言</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="语言——原文直译“舌头”；传统译法作“方言”；或译作“殊言”。">i</a></sup><span className="woj">；</span></span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 10:19; 雅各书 5:14–15; 使徒行传 28:3–6"> <sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附“用手”。">j</a></sup><span className="woj">对付</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="对付——或译作“拿走”。">k</a></sup><span className="woj">蛇类；即使喝了致命的东西也绝不受害；按手在病人身上，病人就将痊愈。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="彼得前书 3:22; 希伯来书 1:3; 希伯来书 12:2"> 这样，主耶稣<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="主耶稣——有古抄本作“主”。">l</a></sup>对他们说完话以后，就被接到天上，坐在神的右边。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 2:4–5; 使徒行传 14:3; 罗马书 15:19"> 门徒们就出去，到处传道。主与他们一同工作，并且藉着伴随的神迹证实这话语。<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="有古抄本没有9-20节。">m</a></sup><sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="有古抄本附“阿们。”">n</a></sup></span>

</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="路加福音 21:6; 马太福音 24:2; 列王纪上 9:7–8"> 耶稣对他说：<span className="woj">“你在看这些雄伟的建筑吗？这里将绝不会有一块石头留在另一块石头上而不被拆下。”</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马太福音 21:1; 马可福音 4:34; 马可福音 14:33"> 耶稣在橄榄山上，面对圣殿坐着。彼得、雅各、约翰和安得烈悄悄地问他：</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 1:6–7; 马太福音 24:3; 但以理书 12:6"> “请告诉我们，这些事什么时候会发生呢？这一切将要成就的时候，会有什么预兆呢？”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歌罗西书 2:8; 以弗所书 5:6; 耶利米书 29:8"> 耶稣就开始对他们说：<span className="woj">“你们要当心，免得有人迷惑你们。</span></span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 13:22; 耶利米书 23:21–25; 约翰福音 8:24"> <span className="woj">许多人会以我的名而来，声称‘我就是那一位</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我就是那一位——原文直译“我就是”或“我永在”。">a</a></sup><span className="woj">’，并且会迷惑许多人。</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 21:9–11; 约翰福音 14:27; 马太福音 24:6–7"> <span className="woj">当你们听见战争和战争消息的时候，不可惊慌。这些事必须发生，不过结局还没有到。</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 24:8; 以赛亚书 37:3; 诗篇 48:6"> <span className="woj">一个民族要起来反对另一个民族，一个国家要起来反对另一个国家；到处都会有地震和饥荒</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附“和动乱”。">b</a></sup><span className="woj">。这些都像临产阵痛的开始。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马太福音 10:17–18; 约翰福音 16:2; 腓立比书 1:29"> <span className="woj">“你们自己要当心。他们将要把你们送交议会；你们会在会堂里受鞭打。为我的缘故，你们将站在总督和君王面前，好对他们做见证。</span></span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 24:14; 歌罗西书 1:23; 罗马书 10:18"> <span className="woj">然而，福音必须先传给万国。</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 21:14–15; 路加福音 12:11–12; 马太福音 10:19–21"> <span className="woj">当他们把你们交出去、带走的时候，不要预先忧虑</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附“或考虑”。">c</a></sup><span className="woj">说什么。到时候，你们被赐予什么话，就说什么话，因为说话的不是你们自己，而是圣灵。</span></span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 10:21; 路加福音 12:52–53; 路加福音 21:16"> <span className="woj">兄弟将要把兄弟出卖，置于死地；父亲对孩子也会这样。儿女会起来与父母作对，并且害死他们。</span></span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 15:18–19; 马太福音 10:22; 马太福音 24:13"> <span className="woj">为了我的名，你们将被所有的人憎恨，但是忍耐到底的，这个人将会得救。</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="但以理书 9:27; 但以理书 12:11; 但以理书 11:31"> <span className="woj">“当你们看见</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附“先知但以理所说的”。">d</a></sup><span className="woj">‘那带来毁灭的亵渎者</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="亵渎者——或译作“亵渎之物”。">e</a></sup><span className="woj">’</span><span className="woj">站在不该站的地方时</span>——读者应当思考——<span className="woj">那时，在犹太的人应当逃到山里；</span></span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 17:31–33; 希伯来书 11:7; 腓立比书 3:7–8"> <span className="woj">在屋顶上的人，不要下来</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附“到屋子里去”。">f</a></sup><span className="woj">，也不要进屋子里去拿什么东西；</span></span>
<span className="v" id="v16" data-v="16"> <span className="woj">在田里的人，不要转回到背后的事上，去拿自己的衣服。</span></span>
<span className="v" id="v17" data-v="17" data-xref="耶利米哀歌 4:10; 路加福音 23:29; 何西阿书 9:14"> <span className="woj">在那些日子里，孕妇和哺乳的女人有祸了！</span></span>
<span className="v" id="v18" data-v="18"> <span className="woj">你们要祷告，好让这事</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="这事——有古抄本作“你们逃难的时候”。">g</a></sup><span className="woj">不在冬天发生，</span></span>
<span className="v" id="v19" data-v="19" data-xref="但以理书 12:1; 约珥书 2:2; 马太福音 24:21"> <span className="woj">因为在那些日子里将有患难。这样的患难从神创世之初直到如今，从来没有发生过，也绝不再发生。</span></span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 24:22; 撒迦利亚书 13:8–9; 以赛亚书 65:8–9"> <span className="woj">如果不是主减少了那些日子，就没有一个人</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="人——原文直译“肉体”。">h</a></sup><span className="woj">能得救。然而，为了那些蒙拣选的人，就是他所拣选的，他减少了那些日子。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 21:8; 马太福音 24:23–25; 马太福音 24:5"> <span className="woj">“那时候，如果有人对你们说‘看哪，基督在这里！’‘看哪，他在那里！’你们不要相信。</span></span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 24:24; 帖撒罗尼迦后书 2:8–14; 马可福音 13:6"> <span className="woj">因为假基督们和假先知们会出现，行神迹和奇事，如果有可能，甚至迷惑那些蒙拣选的人。</span></span>
<span className="v" id="v23" data-v="23" data-xref="彼得后书 3:17; 马可福音 13:5; 约翰福音 14:29"> <span className="woj">所以你们要当心。我已经预先把一切都告诉你们了。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 13:10; 使徒行传 2:19–20; 启示录 6:12–14"> <span className="woj">“在那些日子里，随着那患难，</span><br /><span className="pl pl-1 woj">‘太阳就要变黑，</span><br /><span className="pl pl-1 woj">月亮也不发光，</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 34:4; 启示录 6:13"> <span className="pl pl-1 woj">星辰要从天上坠落，</span><br /><span className="pl pl-1 woj">诸天之上的各势力也将被震动。’</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="启示录 1:7; 马太福音 16:27; 马太福音 24:30"> <span className="woj">那时候，人们将要看见人子带着极大的权能和荣耀，在云彩中来临。</span></span>
<span className="v" id="v27" data-v="27" data-xref="撒迦利亚书 2:6; 马太福音 24:31; 申命记 30:4"> <span className="woj">他要差派天使们，并且从四方，从地极到天边，召集他所拣选的人。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 21:29–31; 马太福音 24:32–33"> <span className="woj">“你们要从无花果树那里学个比喻：当无花果树的枝子发嫩长出叶子的时候，你们就知道夏天快到了。</span></span>
<span className="v" id="v29" data-v="29" data-xref="彼得前书 4:17–18; 雅各书 5:9; 以西结书 12:25–28"> <span className="woj">照样，当你们看见这些事发生的时候，你们应当知道：人子</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="人子——原文直译“他”或“它”；可指“人子”，也可指“那时刻”。">i</a></sup><span className="woj">快到了，就在门口了。</span></span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 24:34; 路加福音 21:32; 马太福音 16:28"> <span className="woj">我确实地告诉你们：在这一切事发生之前，这世代绝不会过去。</span></span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 40:8; 以赛亚书 51:6; 马太福音 24:35"> <span className="woj">天和地将要消逝，但是我的话绝不会消逝。</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行传 1:7; 马太福音 24:36–42; 马太福音 25:13"> <span className="woj">“至于那日子或那时刻，没有人知道，连天上的天使们也不知道，子也不知道，唯有父知道。</span></span>
<span className="v" id="v33" data-v="33" data-xref="以弗所书 6:18; 路加福音 12:40; 罗马书 13:11–12"> <span className="woj">你们要当心，要警醒</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附“要祷告”。">j</a></sup><span className="woj">；因为你们不知道那时刻是什么时候。</span></span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 25:14–30; 约翰福音 10:3; 路加福音 12:36–40"> <span className="woj">这就像一个人出外旅行，离开了家，把权柄交给了他的奴仆们，又把工作分给了每个人，他吩咐看门的人要警醒。</span></span>
<span className="v" id="v35" data-v="35" data-xref="马可福音 13:33; 马太福音 24:42; 马太福音 24:44"> <span className="woj">所以你们要警醒，因为你们不知道这家的主人什么时候回来，或傍晚，或半夜，或鸡叫时，或凌晨；</span></span>
<span className="v" id="v36" data-v="36" data-xref="帖撒罗尼迦前书 5:6–7; 罗马书 13:11–14; 马太福音 24:48–51"> <span className="woj">免得他忽然回来，看见你们在睡觉。</span></span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 13:33; 路加福音 12:41–46; 马可福音 13:35"> <span className="woj">我对你们说的，也对所有的人说：你们要警醒！”</span></span>
</div>

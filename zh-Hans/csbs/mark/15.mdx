<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 27:1–2; 路加福音 23:1–5; 路加福音 22:66"> 一到清晨，祭司长们就与长老们、经文士们以及全议会的人商议对策，然后把耶稣捆起来带走，交给彼拉多。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="马太福音 2:2; 马太福音 27:11–14; 提摩太前书 6:13"> 彼拉多问他：“你是犹太人的王吗？”<br />耶稣回答他，说：<span className="woj">“是你说的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 53:7; 马可福音 15:5; 约翰福音 18:29–31"> 祭司长们控告了耶稣很多事<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附“但是他什么都不回答”。">a</a></sup>。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 19:10; 马太福音 27:13; 马太福音 26:62"> 所以彼拉多又问他，说：“你什么都不回应吗？你看，他们控告你这么多的事。”</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 53:7; 撒迦利亚书 3:8; 诗篇 71:7"> 可是，耶稣仍然什么也不回答，以致彼拉多感到惊奇。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约翰福音 18:39–40; 使徒行传 25:9; 使徒行传 24:27"> 每逢这节日<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="节日——指“逾越节”。">b</a></sup>，彼拉多都会给民众释放一个他们所要求的囚犯。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 23:18–19; 马太福音 27:16; 路加福音 23:25"> 那时，有一个叫巴拉巴的，和一同叛乱的人被关在牢里，他们在暴乱中杀过人。</span>
<span className="v" id="v8" data-v="8"> 众人就上前去<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="上前去——有古抄本作“高喊”。">c</a></sup>，开始要求彼拉多按照他的惯例给他们办。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 19:14–16; 约翰福音 19:4–5; 约翰福音 18:39"> 彼拉多问他们，说：“你们要我给你们释放这犹太人的王吗？”</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 27:4; 提多书 3:3; 创世记 4:4–6"> 其实彼拉多知道祭司长们是出于嫉妒才把耶稣交给他的。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 3:14; 约翰福音 18:40; 何西阿书 5:1"> 但是，祭司长们煽动众人，宁愿要彼拉多给他们释放巴拉巴。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米书 23:5–6; 以赛亚书 9:6–7; 撒迦利亚书 9:9"> 彼拉多又问他们，说：“那么，你们要我怎么处理你们称为犹太人之王的那一位呢？”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 他们再次喊叫：“把他钉上十字架！”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 23:41; 路加福音 23:23–24; 以赛亚书 53:3"> 彼拉多对他们说：“他到底做了什么恶事呢？”<br />但他们却越发喊叫：“把他钉上十字架！”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 19:1; 马太福音 27:26; 以赛亚书 50:6"> 彼拉多想要讨好众人，就给他们释放了巴拉巴，然后将耶稣鞭打<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="鞭打——罗马式鞭打使用的鞭子是带有碎骨头或金属尖钩的皮条，抽打时使人皮开肉绽，非常残酷。">d</a></sup>了，把他交出去钉上十字架。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰福音 19:9; 马太福音 27:27–31; 约翰福音 18:28"> 士兵们把耶稣带进大院，那里就是总督府，并召集了全队士兵。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 27:28–30; 约翰福音 19:2–5; 路加福音 23:11"> 他们给他穿上紫色袍子，套上用荆棘编的冠冕，</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 27:42–43; 马可福音 15:2; 创世记 37:10"> 然后开始向他致敬说：“万岁，犹太人的王！”</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 14:65; 以赛亚书 53:3–5; 路加福音 23:11"> 他们用芦苇打他的头，向他吐唾沫，又跪下来拜他。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 19:16; 马太福音 27:31"> 他们戏弄完了，就脱下他紫色袍子，给他穿上他自己的衣服，然后带他出去，要把他钉上十字架。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马太福音 27:32; 路加福音 23:26; 罗马书 16:13"> 有一个古利奈人西门，是亚历山大和鲁弗斯的父亲，正从乡下来，经过那里。他们就强迫他来背耶稣的十字架。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 27:33–44; 约翰福音 19:17–27; 路加福音 23:27–38"> 他们把耶稣带到一个叫各各他的地方——“各各他”翻译出来就是“骷髅地”；</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 27:34; 约翰福音 19:28–30; 路加福音 23:36"> 然后把调了没药的酒给耶稣，但他不接受。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 23:34; 约翰福音 19:23–24; 马太福音 27:35–36"> 于是，他们把耶稣钉上十字架，又分他的衣服，抽签看谁得什么。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 19:14; 马可福音 15:33; 马太福音 27:45"> 在上午九点<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="上午九点——原文为“第三时刻”。">e</a></sup>，他们把耶稣钉上了十字架。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 27:37; 马太福音 2:2; 约翰福音 19:18–22"> 他的罪状牌上写的是：“犹太人的王。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 23:32–33; 马太福音 27:38; 约翰福音 19:18"> 同时，他们把两个强盗与耶稣一起钉上十字架，一个在右边，一个在左边。</span>
<span className="v" id="v28" data-v="28"> 这就应验了经上所说的：“他被列在不法之徒当中。”<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本没有此节。">f</a></sup></span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 14:58; 诗篇 109:25; 耶利米哀歌 1:12"> 那些路过的人辱骂耶稣，摇着头，说：“咳！你这个要拆毁圣所、三天内又建起来的人哪，</span>
<span className="v" id="v30" data-v="30"> 从十字架上下来，救救你自己吧！”</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 12:23–24; 马太福音 27:41–43; 路加福音 23:35–37"> 同样，祭司长们也与经文士们一起嘲笑，相互说：“他救了别人，却不能救自己！</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 27:44; 路加福音 23:39–43; 撒迦利亚书 9:9"> 这个基督，以色列的王，现在让他从十字架上下来吧，好让我们看了就相信！”与耶稣一起被钉十字架的人也责骂他。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 27:45; 路加福音 23:44–45; 阿摩司书 8:9–10"> 到了中午十二点<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="中午十二点——原文为“第六时刻”。">g</a></sup>，黑暗笼罩了整个大地，一直到下午三点<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="下午三点——原文为“第九时刻”。">h</a></sup>。</span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 22:1; 马太福音 27:46; 希伯来书 5:7"> 下午三点，耶稣大声呼喊：<span className="woj">“以罗伊，以罗伊！拉玛撒巴克达尼？</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="以罗伊，以罗伊！拉玛撒巴克达尼？——亚兰文词语的音译。">i</a></sup><span className="woj">”</span>——这翻译出来就是<span className="woj">“我的神，我的神！你为什么离弃我？”</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 27:47–49; 马可福音 9:11–13; 马太福音 17:11–13"> 站在旁边的一些人听见了，就说：“看，他在呼唤以利亚呢！”</span>
<span className="v" id="v36" data-v="36" data-xref="诗篇 69:21; 马可福音 15:23; 约翰福音 19:28–30"> 有一个人跑过去，用海绵蘸满了酸酒，套在芦苇上，要给他喝，然后说：“等着吧，我们看以利亚会不会来把他放下来。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="约翰福音 19:30; 路加福音 23:46; 马太福音 27:50"> 耶稣大叫一声，就断了气。</span>
<span className="v" id="v38" data-v="38" data-xref="希伯来书 10:19–23; 路加福音 23:45; 希伯来书 9:3–12"> 同时，圣所里的幔子从上到下裂成两半。</span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 27:54; 路加福音 23:47–48; 马太福音 27:43"> 站在耶稣对面的百夫长，看见他这样<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附“喊叫着”。">j</a></sup>断了气，就说：“这个人真是神的儿子！”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="路加福音 23:49; 路加福音 8:2–3; 马太福音 27:55–56"> 还有一些妇女从远处观看，其中有茉大拉的玛丽亚、小雅各和约西的母亲玛丽亚，以及莎罗美。</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 8:2–3; 马太福音 27:55–56"> 她们就是耶稣在加利利的时候，跟随他并服事他的人；还有许多别的跟耶稣一同上耶路撒冷的妇女。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="路加福音 23:50–56; 约翰福音 19:38–42; 约翰福音 19:31"> 因为那天是预备日，也就是安息日的前一天，所以到了傍晚，</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 2:38; 路加福音 2:25; 路加福音 23:51"> 亚利马太的约瑟来了，鼓起勇气去向彼拉多请求要耶稣的遗体。约瑟是犹太议会中一位受人尊敬的议员，他也期待着神的国。</span>
<span className="v" id="v44" data-v="44" data-xref="约翰福音 19:31–37"> 彼拉多听见耶稣已经死了就感到惊奇，于是叫来了百夫长，问他耶稣是否已经死了<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="已经死了——有古抄本作“死了很久了”。">k</a></sup>。</span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 27:58; 约翰福音 19:38; 马可福音 15:39"> 他向百夫长了解情况<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="情况——辅助词语。">l</a></sup>后，就把遗体<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="遗体——有古抄本作“身体”。">m</a></sup>给了约瑟。</span>
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 53:9; 马太福音 27:59–60; 以赛亚书 22:16"> 于是，约瑟买了细麻布，把遗体取下来，用细麻布包好，安放在一座岩石凿成的墓穴里，又滚来一块石头，堵住墓穴口。</span>
<span className="v" id="v47" data-v="47" data-xref="马可福音 15:40; 马可福音 16:1; 路加福音 23:55–2"> 茉大拉的玛丽亚和约西的母亲<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="母亲——辅助词语。">n</a></sup>玛丽亚，都看到了安放耶稣的地方。</span>
</div>

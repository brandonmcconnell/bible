<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 5:1–3; 马可福音 2:13; 路加福音 8:4–10"> 又一次，耶稣开始在湖<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="湖——原文直译“海”；指“加利利湖（海）”。">a</a></sup>边教导人。有一大群人聚集到他那里，所以他上了湖中的一条船坐下来。众人都在岸边，面对湖站着。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 13:34–35; 马可福音 3:23; 马可福音 4:11"> 耶稣用比喻教导他们很多事，在教导时对他们说：</span>
<span className="v" id="v3" data-v="3" data-xref="雅各书 2:5; 马太福音 13:26; 马可福音 4:26–29"> <span className="woj">“你们当听好：看哪，有一个撒种的出去撒种。</span></span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 13:19; 马可福音 4:15; 马太福音 13:4"> <span className="woj">他撒的时候，有的种子落在路边，</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附“天空的”。">b</a></sup><span className="woj">飞鸟来了，就把它吃掉了。</span></span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 36:26; 路加福音 8:6; 路加福音 8:13"> <span className="woj">另有落在岩石地上的，那里没有多少泥土，它立刻就发芽了，因为土不深；</span></span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 1:11; 耶利米书 17:5–8; 约拿书 4:8"> <span className="woj">当太阳升起，它被暴晒，就枯萎了，因为没有根。</span></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 4:3; 路加福音 8:14; 创世记 3:17–18"> <span className="woj">另有落进荆棘丛里的，荆棘长起来把它挤住，它就结不出果实了。</span></span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 15:5; 歌罗西书 1:6; 马可福音 4:20"> <span className="woj">可是另有落进好土壤里的，就发芽、生长，不断地结出果实，结出的有三十倍的、有六十倍的、有一百倍的。”</span></span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 11:15; 马可福音 4:23–24; 启示录 3:22"> 耶稣说：<span className="woj">“凡是有耳可听的，就应当听！”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="马太福音 13:10–17; 马可福音 4:34; 箴言 13:20"> 耶稣独自一人的时候，跟随他的人与十二使徒<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="使徒——辅助词语。">c</a></sup>一起问他这些比喻的意思。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 11:25; 路加福音 8:10; 约翰一书 5:20"> 耶稣对他们说：<span className="woj">“神国的奥秘已经赐给你们了</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="赐给你们了——有古抄本作“赐下来让你们知道”。">d</a></sup><span className="woj">，但是对外人，一切都是用比喻的。</span></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 6:9–10; 以赛亚书 44:18; 马太福音 13:14–15"> <span className="woj">这是为要使</span><br /><span className="pl pl-1 woj">‘他们看了又看，却不明白，</span><br /><span className="pl pl-1 woj">听了又听，却不领悟，</span><br /><span className="pl pl-1 woj">免得他们回转过来，</span><br /><span className="pl pl-1 woj">就</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附“罪”。">e</a></sup><br /><span className="pl pl-1 woj">被赦免。’</span><br /><span className="pl pl-1 woj">”</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="启示录 3:19; 马太福音 13:51–52; 马可福音 7:17–18"> 耶稣对他们说：<span className="woj">“你们不明白这个比喻，又怎么能领会所有的比喻呢？</span></span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 8:4; 马太福音 13:19; 马太福音 13:37"> <span className="woj">撒种的人所撒的是话语。</span></span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 5:8; 马太福音 13:19; 哥林多后书 2:11"> <span className="woj">那被撒上话语的‘路边之地’是这样一些人：他们听了话语以后，撒旦就立刻来把那撒在他们心里</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="在他们心里——有古抄本作“在他们里面”。">f</a></sup><span className="woj">的话语夺走。</span></span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 6:20; 路加福音 8:13; 马太福音 13:20–21"> <sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附“同样，”。">g</a></sup><span className="woj">那被撒上话语的‘岩石地’是这样一些人：他们一旦听了这话语，就立刻怀着喜乐的心接受了它；</span></span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 11:6; 帖撒罗尼迦前书 3:3–5; 马太福音 12:31"> <span className="woj">可是他们里面没有根而不能持久，一旦为这话语受患难或逼迫，他们立刻就放弃</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="放弃——原文直译“绊倒”。">h</a></sup><span className="woj">了。</span></span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 8:14; 耶利米书 4:3; 马太福音 13:22"> <span className="woj">那被撒进话语的‘荆棘丛’是另外一些人，那些人是这样的：他们听了这话语，</span></span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 2:15–17; 提摩太前书 6:9–10; 提摩太前书 6:17"> <span className="woj">但今世的各种忧虑、财富的迷惑，以及其他各种欲望纷纷进来把这话语挤住了，他就成了不结果实的。</span></span>
<span className="v" id="v20" data-v="20" data-xref="歌罗西书 1:10; 路加福音 8:15; 约翰福音 15:4–5"> <span className="woj">而那被撒上话语的‘好土壤’是这样的人：他们听了这话语就接受，并且结出果实来，有三十倍的，有六十倍的，也有一百倍的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马太福音 5:15; 路加福音 11:33; 路加福音 8:16"> 耶稣又对他们说：<span className="woj">“油灯拿进来，难道是为了放在斗</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="斗——指“一种度量谷物的量器”；容量约为9升。">i</a></sup><span className="woj">底下，或床底下吗？不是为了放在灯台上吗？</span></span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 8:17; 传道书 12:14; 马太福音 10:26–27"> <span className="woj">这样，就算是隐秘的事，也没有不显明出来的；即使是隐藏的事，也没有不显露出来的。</span></span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 4:9; 马太福音 11:15; 启示录 2:29"> <span className="woj">凡是有耳可听的，就应当听！”</span></span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 2:1; 路加福音 8:18; 马太福音 7:2"> 耶稣又说：<span className="woj">“你们要留心所听到的。你们用什么量器</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="量器——或译作“尺度”或“标准”。">j</a></sup><span className="woj">来衡量，也会同样地被衡量，而且还将加添给你们</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="你们——有古抄本作“你们这些正在听的人”。">k</a></sup><span className="woj">；</span></span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 13:12; 路加福音 8:18; 马太福音 25:28–29"> <span className="woj">因为凡是有的，还要赐给他；凡是没有的，连他有的也将从他那里被拿走。”</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 13:24; 哥林多前书 3:6–9; 路加福音 8:11"> 耶稣又说：<span className="woj">“神的国就像这样：有人在地上撒了种子，</span></span>
<span className="v" id="v27" data-v="27" data-xref="传道书 11:5; 帖撒罗尼迦后书 1:3; 哥林多前书 15:37–38"> <span className="woj">黑夜白昼，或睡或起，他却不知道那种子怎样发芽和长大。</span></span>
<span className="v" id="v28" data-v="28" data-xref="马可福音 4:31–32; 何西阿书 6:3; 腓立比书 1:9–11"> <span className="woj">大地自然长出五谷</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="长出五谷——原文直译“结出果实”。">l</a></sup><span className="woj">——先长苗，再吐穗，然后穗上结出饱满的子粒。</span></span>
<span className="v" id="v29" data-v="29" data-xref="约珥书 3:13; 马太福音 13:30; 马太福音 13:40–43"> <span className="woj">当果实成熟的时候，他立刻伸出镰刀，因为收割的季节到了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="马太福音 13:31–32; 路加福音 13:18–21; 耶利米哀歌 2:13"> 耶稣又说：<span className="woj">“我们把神的国比做什么呢？用什么比喻来表明</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="表明——或译作“描述”；有古抄本作“比做”。">m</a></sup><span className="woj">它呢？</span></span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 19:20; 路加福音 13:18–19; 但以理书 2:44–45"> <span className="woj">它好像一粒芥菜种子，被种入地里的时候，比地上所有的种子更小，</span></span>
<span className="v" id="v32" data-v="32" data-xref="但以理书 4:20–22; 但以理书 4:10–14; 以西结书 31:3–10"> <span className="woj">可是被种下去以后，它就长起来，长得比所有蔬菜更大，并且长出大枝子，以致天空的飞鸟能在它的荫下搭窝。”</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 13:34–35; 约翰福音 16:12; 希伯来书 5:11–14"> 耶稣照着他们所能听的，用许多这样的比喻，向他们讲道。</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 16:25; 马可福音 4:10; 马太福音 15:15–20"> 他向众人讲话，没有不用比喻的。可是，他却单独给自己的门徒们解释一切。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 8:18; 路加福音 8:22; 路加福音 8:25"> 那天晚上，耶稣对门徒们说：<span className="woj">“我们渡到对岸去吧。”</span></span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 3:9; 马可福音 4:1; 马可福音 5:2"> 门徒离开众人，耶稣仍然在船上，他们就把他一同带去；也有别的船<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="船——有古抄本作“小船”。">n</a></sup>与他同行。</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 8:23–24; 约伯记 1:19; 路加福音 8:22–23"> 这时候，起了大风暴，以致波浪打进船里，船几乎灌满了水。</span>
<span className="v" id="v38" data-v="38" data-xref="彼得前书 5:7; 希伯来书 4:15; 以赛亚书 54:6–8"> 耶稣却在船尾靠着枕头睡着了。门徒们叫醒他，说：“老师！我们没命了，你不管吗？”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="诗篇 107:29; 诗篇 89:9; 诗篇 65:7"> 耶稣就起来，斥责了风，对浪<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="浪——或译作“湖”；原文直译“海”。">o</a></sup>说：<span className="woj">“不许做声！平静下来！”</span>于是风就停了，湖面就变得一片平静。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 8:25; 马太福音 8:26; 马太福音 14:31"> 耶稣对门徒们说：<span className="woj">“为什么胆怯呢？你们还没有信吗？”</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 8:25; 约伯记 38:11; 诗篇 89:7"> 门徒们就大为惊恐，彼此说：“这个人究竟是谁？连风和浪也听从他！”</span>
</div>

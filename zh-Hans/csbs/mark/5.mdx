<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 8:26–39; 马太福音 8:28–34; 马可福音 4:35"> 他们来到湖<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="湖——原文直译“海”；指“加利利湖（海）”。">a</a></sup>的对岸，进了格拉森<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="格拉森——有古抄本作“格达拉”。">b</a></sup>人的地方。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 1:23; 以赛亚书 65:4; 马可福音 5:8"> 耶稣刚下船，就有一个被污灵附身的人，从墓地迎着他来。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 65:4; 路加福音 8:29; 但以理书 4:32–33"> 这个人住在墓地里，没有人能捆住他，就是用铁链也不行。</span>
<span className="v" id="v4" data-v="4" data-xref="雅各书 3:7–8"> 他经常被脚镣和铁链捆起来，然而他总是挣断铁链、打碎脚镣。没有人能制伏他。</span>
<span className="v" id="v5" data-v="5" data-xref="约伯记 2:7–8; 列王纪上 18:28; 约翰福音 8:44"> 不管黑夜白昼，他常常在墓地和山上喊叫，又用石头砍自己。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="雅各书 2:19; 诗篇 66:3; 路加福音 4:41"> 他远远地看见耶稣，就跑过去，向他下拜，</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 8:29; 使徒行传 16:17; 马太福音 26:63"> 大声喊叫说：“至高神的儿子耶稣，我与你有什么关系？我藉着神恳求你，不要折磨我！”</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 1:25; 马可福音 9:25–26; 使徒行传 16:18"> 这是因为耶稣对他说：<span className="woj">“你出来，污灵！离开这个人！”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 8:30; 马可福音 5:15; 马太福音 26:53"> 耶稣问他：<span className="woj">“你叫什么名字？”</span><br />他回答说：“我名叫‘军团’，因为我们众多。”</span>
<span className="v" id="v10" data-v="10" data-xref="马可福音 3:22; 马可福音 5:13"> 他一再央求耶稣不要把它们赶出那个地方。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="利未记 11:7–8; 以赛亚书 65:4; 以赛亚书 66:3"> 当时，那里有一大群猪正在附近的山上吃食。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 2:11; 约伯记 1:10–12; 路加福音 22:31–32"> 那些污灵<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="那些污灵——原文直译“它们”；有古抄本作“所有的鬼魔”。">c</a></sup>就央求耶稣，说：“求你打发我们到猪群里，好让我们进入猪里面去吧！”</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 22:22; 彼得前书 3:22; 约伯记 2:6"> 耶稣<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附“立刻”。">d</a></sup>准许了它们，污灵就出来，进入猪里面。那群猪约有两千头，它们从山崖冲到湖里，在湖里淹死了。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 8:34; 马太福音 8:33"> 那些放猪的人就逃跑了，去把这事传到城里城外。于是人们就来<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="来——有古抄本作“出来”。">e</a></sup>看发生了什么事。</span>
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 1:13; 提摩太后书 1:7; 撒母耳记上 6:20–21"> 他们来到耶稣那里，看见那曾经有鬼魔附身的，就是被‘军团’所附的那个人，穿着衣服，神志清醒地坐着，他们就惧怕起来。</span>
<span className="v" id="v16" data-v="16"> 那些看见的人，把发生在有鬼魔附身的人身上和有关猪群的事，都告诉了大家。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 8:34; 马可福音 1:24; 路加福音 8:37"> 他们就开始央求耶稣离开他们的地区。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 8:38–39; 腓立比书 1:23–24; 马可福音 5:17"> 耶稣上船的时候，那曾被鬼魔附身的人恳求他，要与他在一起。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 66:16; 约翰福音 4:29; 以赛亚书 38:9–20"> 耶稣没有答应，却对他说：<span className="woj">“你回家去吧，到你的亲友那里，告诉他们主为你做了什么，以及他怎样怜悯你。”</span></span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 7:31; 马太福音 4:25"> 于是那个人离开了，开始在德卡波利斯地区传扬耶稣为他做了什么样的事。众人都感到惊奇。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马太福音 9:1; 马可福音 4:1; 路加福音 8:40"> 耶稣又上船渡到对岸。有一大群人聚集到他那里，他就留在湖边。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 13:14; 使徒行传 18:8; 马可福音 5:35–36"> 这时候，来了一个名叫睚鲁的会堂主管。他一见到耶稣，就俯伏在耶稣脚前，</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 13:13; 路加福音 4:40; 马可福音 16:18"> 迫切地恳求他，说：“我的小女儿快要死了。求你来按手在她身上，好让她得救治，能活下去。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="马可福音 5:31; 马可福音 3:20; 路加福音 7:6"> 耶稣就与他一起去，有一大群人跟随耶稣，并拥挤他。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 15:25–27; 路加福音 8:43–44; 马太福音 9:20–22"> 有一个妇人，患了十二年的血漏病。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 30:12–13; 耶利米书 8:22; 诗篇 108:12"> 她在许多医生手里受了很多苦，花尽了她所有的一切，没有任何效果，反而倒变得更严重了。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 19:12; 马太福音 14:36; 使徒行传 5:15"> 她听说了耶稣的事，就夹在人群中，从后面摸了一下耶稣的衣服，</span>
<span className="v" id="v28" data-v="28"> 原来她想：“只要我摸到他的衣服，就会得救治。”</span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 5:34; 诗篇 30:2; 马可福音 3:10"> 立刻，她的血漏就止住了，她也感觉到身体从病痛中痊愈了。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 6:19; 路加福音 8:46; 路加福音 5:17"> 耶稣自己里面立刻知道有能力从他而出，就在人群中转过身来，问：<span className="woj">“谁摸了我的衣服？”</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 8:45; 路加福音 9:12"> 他的门徒们对他说：“你看这群人拥挤着你，你还问‘谁摸了我’吗？”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 可是耶稣环视周围，要知道是谁做了这事。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 8:47; 路加福音 1:29; 路加福音 1:12"> 那妇人知道发生在自己身上的事，就惧怕起来，战战兢兢地上前俯伏在耶稣面前，把真实情况全告诉了他。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 8:48; 马太福音 9:22; 路加福音 7:50"> 耶稣对她说：<span className="woj">“女儿，你的信救了你，平平安安地去吧。你从病痛中痊愈了吧！”</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="路加福音 8:49; 约翰福音 11:39; 马可福音 5:22"> 耶稣还在说话的时候，有些人从会堂主管的家里来，对睚鲁<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="对睚鲁——辅助词语。">f</a></sup>说：“你的女儿已经死了，何必再麻烦老师呢？”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="路加福音 8:50; 马太福音 9:28–29; 约翰福音 11:40"> 耶稣却当做没听见他们所说的话，对会堂主管说<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="耶稣却当做没听见他们所说的话，对……说——有古抄本作“耶稣听见他们所说的话，就立刻对……说”。">g</a></sup>：<span className="woj">“不要怕，只要信！”</span></span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 9:40; 马可福音 14:33; 哥林多后书 13:1"> 然后他除了彼得、雅各和雅各的弟弟<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="弟弟——原文直译“兄弟”。">h</a></sup>约翰以外，不准别的人跟着。</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 9:23–24; 路加福音 8:52–53; 马可福音 5:22"> 他们来到会堂主管的家里，耶稣看见一片混乱，有人哭泣，有人哀号。</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 20:10; 帖撒罗尼迦前书 5:10; 帖撒罗尼迦前书 4:13–14"> 耶稣进去对他们说：<span className="woj">“为什么慌乱哭泣呢？孩子不是死了，而是睡了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="尼希米记 2:19; 列王纪下 4:33; 马太福音 9:24–25"> 他们就讥笑耶稣。耶稣把他们都赶出去，只带着孩子的父母和一起来的人，进入孩子所在的地方<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="孩子所在的地方——有古抄本作“孩子躺着的地方”。">i</a></sup>。</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 1:31; 路加福音 7:14–15; 路加福音 8:54–55"> 他握着孩子的手，对她说：<span className="woj">“塔利达，库莫！</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="塔利达，库莫！——亚兰文词语的音译。">j</a></sup><span className="woj">”</span>——这翻译出来就是<span className="woj">“小女孩，我吩咐你起来！”</span></span>
<span className="v" id="v42" data-v="42" data-xref="马可福音 4:41; 使徒行传 3:10–13; 马可福音 7:37"> 那女孩随即起来，开始走动。她那时十二岁。大家立刻目瞪口呆，大为惊讶。</span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 8:4; 马太福音 9:30; 马可福音 1:43"> 耶稣郑重地吩咐他们，不要让任何人知道这事，又吩咐给孩子吃东西。</span>
</div>

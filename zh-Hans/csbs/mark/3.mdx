<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 12:9–14; 路加福音 6:6–11; 马可福音 1:21"> 耶稣又进了会堂。那里有个人，他的一只手枯萎了。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 37:32; 路加福音 14:1; 路加福音 6:7"> 有些人就密切注意耶稣会不会在安息日使那个人痊愈，这是为要控告耶稣。</span>
<span className="v" id="v3" data-v="3" data-xref="腓立比书 1:28–30; 以赛亚书 42:4; 路加福音 6:8"> 耶稣对那手枯萎的人说：<span className="woj">“起来，站到中间来！”</span></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 6:9; 马太福音 12:10–12; 何西阿书 6:6"> 耶稣问他们：<span className="woj">“在安息日可以行善还是作恶，救命还是害命？”</span>他们却不做声。</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 6:10; 以弗所书 4:18; 罗马书 11:25"> 耶稣愤怒地环视他们，又为他们心里刚硬而忧伤，就对那个人说：<span className="woj">“伸出手来！”</span>他一伸出来，手就复原了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附“和另一只一样健全”。">a</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 22:16; 马可福音 12:13; 马太福音 12:14"> 那些法利赛人就出去，立刻与希律党的人一起商议怎样对付耶稣，好除灭他。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 4:25; 路加福音 6:17; 马太福音 12:15"> 耶稣与他的门徒们退到湖<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="湖——原文直译“海”；指“加利利湖（海）”。">b</a></sup>边，有一大群从加利利来的人跟随他；还有来自犹太、</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 35:15; 以赛亚书 34:5; 马太福音 11:21"> 耶路撒冷、以杜迈亚、约旦河对岸，以及提尔和西顿周围的一大群人来到他那里，因为他们听说了耶稣所做的事。</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 5:30; 约翰福音 6:15"> 由于人多，耶稣就吩咐他的门徒为他预备一条小船，免得众人拥挤他。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 14:36; 马可福音 6:56; 马太福音 4:23"> 因为他使许多人痊愈，所以有病痛的人都向他挤过来，想要摸到他。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 4:41; 马可福音 1:23–24; 路加福音 8:28"> 污灵每当见到耶稣，就俯伏在他面前，喊叫说：“你是神的儿子！”</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 12:16; 马可福音 1:25; 马可福音 1:34"> 可是，耶稣严厉地斥责它们不要把他传扬出去。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:1; 路加福音 6:12–16; 马太福音 10:1–4"> 耶稣上了山，召来那些他想要的人，他们就来到他那里。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 1:8; 路加福音 9:1–6; 约翰福音 15:16"> 于是，耶稣委任了十二个人，称他们为使徒<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本没有“称他们为使徒”。">c</a></sup>，是要他们常与他在一起，并要差派他们出去传道，</span>
<span className="v" id="v15" data-v="15"> 又使他们有权柄<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附“使疾病痊愈、”。">d</a></sup>驱赶鬼魔。</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="约翰福音 1:42; 使徒行传 1:13; 马太福音 16:16–18"> 这样，他委任了十二使徒<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本没有“这样，他委任了十二使徒”。">e</a></sup>：<br /><span className="pl pl-1">西门——耶稣给他起名叫彼得；</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 4:12; 马可福音 14:33; 耶利米书 23:29"> <span className="pl pl-1">西庇太的儿子雅各，</span><br /><span className="pl pl-1">雅各的弟弟</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="弟弟——原文直译“兄弟”。">f</a></sup><br /><span className="pl pl-1">约翰</span><br /><span className="pl pl-1">——耶稣给他们起名叫“波阿内格”——</span><br /><span className="pl pl-1">这意思是“雷霆之子”；</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 1:13; 马可福音 2:14; 马太福音 9:9"> <span className="pl pl-1">又有安得烈，</span><br /><span className="pl pl-1">腓力和巴多罗迈，</span><br /><span className="pl pl-1">马太和多马，</span><br /><span className="pl pl-1">亚勒腓的儿子雅各和达太，</span><br /><span className="pl pl-1">激进派</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="激进派——或译作“奋锐党”。">g</a></sup><br /><span className="pl pl-1">的西门，</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 6:71; 约翰福音 13:2; 使徒行传 1:16–25"> <span className="pl pl-1">还有那出卖耶稣的加略人犹大。</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马可福音 6:31; 约翰福音 4:31–34; 马可福音 9:28"> 耶稣进了房子，人群又聚集而来，以致他和门徒们连饭<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="饭——原文直译“饼”。">h</a></sup>都不能吃。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 26:24; 约翰福音 10:20; 马可福音 3:31"> 耶稣的亲属听说了，就来制止他，因为有人<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有人——原文直译“他们”。">i</a></sup>说他发疯了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马太福音 15:1; 马太福音 10:25; 马太福音 9:34"> 从耶路撒冷下来的一些经文士说：“他有别西卜附身，他是靠鬼魔的王驱赶鬼魔的。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 11:17–23; 马太福音 12:25–30; 马太福音 13:34"> 耶稣把他们召来，用比喻对他们说：<span className="woj">“撒旦怎么能够驱赶撒旦呢？</span></span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亚书 11:14; 以赛亚书 19:2–3; 撒母耳记下 20:6"> <span className="woj">一个国家如果自相纷争，这个国家就站立不住；</span></span>
<span className="v" id="v25" data-v="25" data-xref="雅各书 3:16; 诗篇 133:1; 加拉太书 5:15"> <span className="woj">一个家庭如果自相纷争，这个家庭就站立不住；</span></span>
<span className="v" id="v26" data-v="26"> <span className="woj">撒旦如果起来反对自己而纷争，他不但站立不住，而且要完了。</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 49:24–26; 马太福音 12:29; 路加福音 11:21–23"> <span className="woj">“没有人能进入一个壮士的家抢夺他的东西，如果不先把那壮士捆住，就不能抢夺他的家。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 12:10; 马太福音 12:31–32; 约翰一书 5:16"> <span className="woj">我确实地告诉你们：人类</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="人类——原文直译“人的子孙”。">j</a></sup><span className="woj">的一切罪和亵渎的话，无论怎样亵渎，都能被赦免。</span></span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 12:31–32; 路加福音 12:10; 帖撒罗尼迦后书 1:9"> <span className="woj">但如果有人亵渎圣灵，他永远得不到赦免，而且必担当永远的罪</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="担当永远的罪——有古抄本作“遭受永远的审判”。">k</a></sup><span className="woj">。”</span></span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 10:20; 马可福音 3:22"> 这话是因为他们说：“他有污灵附身。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 8:19–21; 马太福音 12:46–50"> 后来，耶稣的母亲和弟弟们来了，站在外面，派人去叫耶稣。</span>
<span className="v" id="v32" data-v="32"> 有一群人正围着耶稣坐着，他们对他说：“看，你母亲和弟弟妹妹们<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="妹妹们——原文直译“姐妹们”。">l</a></sup><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="有古抄本没有“妹妹们”。">m</a></sup>在外面找你。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马可福音 3:21; 申命记 33:9; 马可福音 6:3"> 耶稣回答他们，说：<span className="woj">“我的母亲、我的弟兄是谁呢？”</span></span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 12:49–50; 路加福音 11:27–28; 罗马书 8:29"> 他环视坐在他周围的人，说：<span className="woj">“看，我的母亲、我的弟兄！</span></span>
<span className="v" id="v35" data-v="35" data-xref="约翰一书 2:17; 马太福音 7:21; 约翰一书 3:22–23"> <span className="woj">因为凡是遵行神旨意的人，他才是我的弟兄、姐妹和母亲。”</span></span>
</div>
</div>

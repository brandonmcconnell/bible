<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="MRK" data-book-slug="mark" data-book-name="马可福音" data-chapter="8" data-verses="38">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 15:32–39; 马可福音 6:34–44"> 在那些日子里，又一次，有一大群人，他们没有什么东西吃。耶稣召来门徒们，对他们说：</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 9:36; 弥迦书 7:19; 诗篇 103:13"> <span className="woj">“我怜悯这群人，因为他们与我在一起已经三天了，也没有什么东西吃。</span></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 40:31; 士师记 8:4–6; 撒母耳记上 30:10–12"> <span className="woj">如果我让他们饿着肚子回家，他们会在路上晕倒，因为有些人从远处而来。”</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 4:42–44; 列王纪下 7:2; 马可福音 6:52"> 他的门徒们回答：“在这旷野，从哪里能得食物让这些人吃饱呢？”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马太福音 14:15–17; 马太福音 15:34; 路加福音 9:13"> 耶稣问他们：<span className="woj">“你们有多少饼呢？”</span><br />他们回答说：“七个。”</span>
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 3:17; 马太福音 15:35–36; 约翰福音 6:10–11"> 耶稣就吩咐众人坐在地上，于是拿起这七个饼，祝谢以后，掰开，不断递给他的门徒们，让他们分发。门徒们就分给众人；</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 14:19; 约翰福音 21:5; 路加福音 24:41–42"> 他们还有几条小鱼，耶稣祝福了，就吩咐把它们也分给众人。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪下 4:42–44; 诗篇 145:16; 马太福音 16:10"> 他们吃了，并且吃饱了。然后，他们把剩下的碎块收拾起来，装满了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="装满了——辅助词语。">a</a></sup>七个筐子。</span>
<span className="v" id="v9" data-v="9"> 当时约有四千人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="约有四千人——有古抄本作“吃的人约有四千”。">b</a></sup>。耶稣遣散了他们，</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 15:39"> 随即与他的门徒们一起上船，来到达玛努达<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="达玛努达——有古抄本作“茉加丹”或“茉大拉”。">c</a></sup>地区。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 10:9; 马太福音 12:38; 申命记 6:16"> 有些法利赛人出来，开始和耶稣辩论。他们试探耶稣，向他要求一个从天上来的神迹。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 12:39–40; 马可福音 7:34; 马太福音 16:4"> 耶稣灵里深深地叹息，就说：<span className="woj">“这世代为什么在寻求神迹呢？我确实地告诉你们：绝不会有神迹赐给这世代。”</span></span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 12:36; 使徒行传 13:45–46; 诗篇 81:12"> 于是他就离开他们，又上船往对岸去。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 16:5"> 门徒们忘了带饼，船上除了一个饼，再没有别的了。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 5:6–8; 马太福音 16:6; 马太福音 16:11–12"> 耶稣吩咐他们说：<span className="woj">“你们要注意，要当心法利赛人的酵母和希律的酵母。”</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 9:46; 路加福音 20:5; 马太福音 16:7–8"> 门徒们因为没有饼，就彼此讨论。</span>
<span className="v" id="v17" data-v="17" data-xref="马可福音 6:52; 以赛亚书 63:17; 马可福音 2:8"> 耶稣知道了，就问他们：<span className="woj">“你们为什么讨论没有饼的事呢？你们还不明白，还不领悟，还是硬着心吗？</span></span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 28:26–27; 马太福音 13:14–15; 耶利米书 5:21"> <span className="woj">你们有眼睛却看不见，有耳朵却听不见吗？难道不记得吗？</span></span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 9:12–17; 马太福音 14:17–21; 约翰福音 6:5–13"> <span className="woj">当我掰开那五个饼给五千人的时候，你们收拾的碎块装满了几个篮子呢？”</span><br />门徒们回答说：“十二个。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马太福音 15:34–38; 马可福音 8:1–9"> <span className="woj">“那七个饼给四千人的时候，你们收拾的碎块装满了几个筐子呢？”</span><br />门徒们回答说：“七个。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马可福音 6:52; 马太福音 16:11–12; 马可福音 8:12"> 耶稣对他们说：<span className="woj">“你们还不领悟吗？”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马太福音 11:21; 马可福音 6:45; 路加福音 10:13"> 他们来到伯赛达，有人带来一个瞎眼的，恳求耶稣摸他。</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 7:33; 约翰福音 9:6–7; 马可福音 5:23"> 耶稣牵着瞎眼之人的手，领他到村子外面，吐唾沫在他的眼睛上，按手在他身上，问他：<span className="woj">“你是否看见什么？”</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 32:3; 以赛亚书 29:18; 哥林多前书 13:9–12"> 他抬头一看，说：“我看见一些人！看起来好像树在走路！”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="彼得前书 2:9; 彼得后书 3:18; 箴言 4:18"> 然后耶稣又按手在他的眼睛上，他就看得清清楚楚了。他痊愈了，就清楚地看见了一切。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 8:4; 马可福音 8:23; 马可福音 5:43"> 耶稣叫他回家，并说：<span className="woj">“不要进这村子</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附“也不要告诉村子里的任何人”。">d</a></sup><span className="woj">。”</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马太福音 16:13–20; 路加福音 9:18–20"> 耶稣和他的门徒们往凯撒里亚菲利彼的那些村庄去。在路上，耶稣问他的门徒们，说：<span className="woj">“人们说我是谁？”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约翰福音 1:21; 马太福音 14:2; 玛拉基书 4:5"> 他们回答他，说：“是施洗者<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="施洗者——或译作“施浸者”。">e</a></sup>约翰，有的说是以利亚，也有的说是先知中的一位。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约翰一书 4:15; 马太福音 16:15–16; 约翰一书 5:1"> 耶稣又问他们：<span className="woj">“那么你们呢？你们说我是谁？”</span><br />彼得回答说：“你是基督！”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 9:21; 马太福音 16:20; 马可福音 9:9"> 耶稣就告诫他们不要把有关他的事告诉任何人。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马可福音 10:33–34; 约翰福音 2:19; 路加福音 24:26"> 耶稣开始教导他们说：<span className="woj">“人子必须受很多苦害，被长老们、祭司长们和经文士们弃绝，并且被杀，然后在第三天要复活。”</span></span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 16:22; 约翰福音 16:25; 约翰福音 16:29"> 耶稣公开地讲这些事，彼得把耶稣拉到一边，开始劝阻他。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 4:10; 腓立比书 3:19; 约翰一书 2:15"> 但耶稣转过身，看了看他的门徒们，就斥责彼得，说：<span className="woj">“撒旦，退到我后面去！因为你不是思想神的事，而是思想人的事。”</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马太福音 10:38; 路加福音 14:26–27; 约翰福音 10:27"> 于是，耶稣把众人和他的门徒们一起召来，对他们说：<span className="woj">“如果有人想要跟从我，他就当舍弃自己，背起自己的十字架，然后跟从我。</span></span>
<span className="v" id="v35" data-v="35" data-xref="提摩太后书 2:11–13; 哥林多前书 9:23; 路加福音 17:33"> <span className="woj">因为凡想要保全</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="保全——原文直译“救”。">f</a></sup><span className="woj">自己生命的，将失去生命；凡为我和福音的缘故失去自己生命的，将保全</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="保全——原文直译“救”。">g</a></sup><span className="woj">生命。</span></span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 16:26; 路加福音 9:25; 诗篇 49:17"> <span className="woj">一个人就是赚得了全世界，却赔上了自己的生命</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="生命——或译作“灵魂”。">h</a></sup><span className="woj">，到底有什么益处呢？</span></span>
<span className="v" id="v37" data-v="37" data-xref="诗篇 49:7–8; 彼得前书 1:18–19"> <span className="woj">人到底能拿什么来换回自己的生命</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="生命——或译作“灵魂”。">i</a></sup><span className="woj">呢？</span></span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 12:8–9; 罗马书 1:16; 约翰一书 2:23"> <span className="woj">在这淫乱、罪恶的世代，一个人如果以我和我的话为耻，当人子在他父的荣耀中，与圣天使们一起来临的时候，也要以这个人为耻。”</span></span>
</div>
</div>

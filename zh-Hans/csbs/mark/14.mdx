<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 22:1–2; 出埃及记 12:6–20; 约翰福音 13:1"> 过两天就是逾越节和除酵节了。祭司长们和经文士们在图谋怎样用诡计拘捕耶稣，把他杀掉。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 7:40; 箴言 21:30; 约翰福音 12:19"> 不过他们说：“不可在节日期间，免得民众发生骚乱。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="路加福音 7:37–39; 约翰福音 12:1–8; 约翰福音 11:2"> 耶稣在伯大尼，在麻风病人西门家里坐席的时候，有一个女人拿着一个玉瓶进来。瓶里盛着<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="瓶里盛着——辅助词语。">a</a></sup>极其贵重的纯哪哒香液。她打破玉瓶，把香液浇在耶稣的头上。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 12:4–5; 马太福音 26:8–9; 玛拉基书 1:12–13"> 有些人心里很不满，说：“为什么要这样浪费香液呢？</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 13:29; 以弗所书 4:28; 哥林多前书 10:10"> 这香液本来可以卖三百多个银币<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="三百多个银币——原文为“300多得拿利”。1得拿利=约1日工资的罗马银币。">b</a></sup>，分给穷人。”他们就责备那女人。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="提多书 3:14; 希伯来书 10:24; 希伯来书 13:21"> 耶稣说：<span className="woj">“由她吧！你们为什么为难她呢？她为我做了一件美好的事。</span></span>
<span className="v" id="v7" data-v="7" data-xref="申命记 15:11; 马太福音 26:11; 雅各书 2:14–16"> <span className="woj">要知道，你们总是有穷人与你们在一起，只要你们愿意，随时可以为他们做好事。但你们不总是有我。</span></span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 8:12; 约翰福音 12:7; 马可福音 15:42–1"> <span className="woj">她尽她所能的做了。她是为我的安葬，预先膏抹了我的身体。</span></span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 26:12–13; 马可福音 16:15; 马太福音 24:14"> <span className="woj">我确实地告诉你们：在全世界，福音无论传到什么地方，这女人所做的事也将被述说，做为对她的记念。”</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="路加福音 22:3–6; 马太福音 26:14–16; 约翰福音 13:2"> 那时候，加略人犹大，就是十二使徒<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="使徒——辅助词语。">c</a></sup>中的一个，到祭司长们那里去，要把耶稣交给他们。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 6:10; 何西阿书 7:3; 犹大书 1:11"> 他们听了就欢喜，并且许诺给他银钱。于是犹大就图谋怎样找机会把耶稣交出去。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及记 12:6; 出埃及记 12:18; 马太福音 26:17–19"> 除酵节的第一日，就是人们宰杀逾越节羔羊的那一天，耶稣的门徒们问他：“你要我们到哪里去预备，好让你吃逾越节的晚餐呢？”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 22:10–13; 马太福音 26:18–19; 路加福音 19:30–33"> 于是耶稣差派了他的两个门徒，对他们说：<span className="woj">“你们进城去，会有一个人提着一罐水迎面而来，你们就跟着他。</span></span>
<span className="v" id="v14" data-v="14" data-xref="启示录 3:20; 马可福音 11:3; 约翰福音 13:13"> <span className="woj">他进哪一家，你们就对那家的主人说：‘老师问：我的客房，就是我与我的门徒们一起吃逾越节晚餐的客房在哪里呢？’</span></span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 1:13; 诗篇 110:3; 箴言 21:1–2"> <span className="woj">他会给你们看楼上一间预备好的大房间。你们就在那里为我们预备吧。”</span></span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 16:4; 路加福音 22:13; 路加福音 22:35"> 两个门徒出去，进了城，所看到的正如耶稣对他们所说的。他们就预备了逾越节的晚餐。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 22:14; 约翰福音 13:21–26; 马太福音 26:20–24"> 到了晚上，耶稣与十二使徒一起来了。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 41:9; 约翰福音 6:47; 约翰福音 6:70"> 他们坐着吃饭的时候，耶稣说：<span className="woj">“我确实地告诉你们：你们当中有一个人要出卖我，他正与我一起吃饭。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 22:21–23; 马太福音 26:22; 约翰福音 13:22"> 他们开始感到忧伤，就一个接一个地问耶稣：“不会是我吧？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约翰福音 13:26; 马太福音 26:23; 约翰福音 6:71"> 耶稣对他们说：<span className="woj">“是你们十二使徒中的一个。他正与我一同在盘子里蘸饼。</span></span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 26:24–25; 以赛亚书 53:1–12; 约翰福音 19:28"> <span className="woj">人子确实要离去，正如经上指着他所写的，但是出卖人子的那个人有祸了。对他来说，没有出生倒好。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马太福音 26:26–29; 马可福音 14:24; 哥林多前书 10:16–17"> 在他们吃的时候，耶稣拿起饼来，祝福了，就掰开，递给门徒们，说：<span className="woj">“你们领受</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附“吃”。">d</a></sup><span className="woj">吧，这是我的身体。”</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马可福音 14:22; 马太福音 26:27; 哥林多前书 10:16"> 接着，他拿起杯来，祝谢了，递给门徒们。他们都喝了。</span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亚书 9:11; 出埃及记 24:8; 启示录 7:9–17"> 耶稣对他们说：<span className="woj">“这是我的血，是为立约</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="约——有古抄本作“新约”。">e</a></sup><span className="woj">的，为许多人所流的。</span></span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 26:29; 诗篇 104:15; 路加福音 22:16–18"> <span className="woj">我确实地告诉你们：我绝不再喝这葡萄汁</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="葡萄汁——或译作“葡萄酒”；原文直译“葡萄树的产品”。">f</a></sup><span className="woj">，直到我在神的国里喝新的那一天。”</span></span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 26:30; 路加福音 22:39; 使徒行传 16:25"> 他们唱了赞美诗<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="赞美诗——那时代的逾越节晚餐时、晚餐后，所唱的赞美诗是《诗篇》113-118篇。">g</a></sup>，就出来，往橄榄山去了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="撒迦利亚书 13:7; 约翰福音 16:32; 马太福音 26:31"> 耶稣对他们说：<span className="woj">“你们都将被绊倒</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="你们都将被绊倒——有古抄本作“今天晚上，你们都将因我被绊倒”。">h</a></sup><span className="woj">，因为经上记着：</span><br /><span className="pl pl-1 woj">‘我将击打牧人，</span><br /><span className="pl pl-1 woj">羊群就被分散。’</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马太福音 28:16; 马可福音 16:7; 马太福音 28:7"> <span className="woj">但是我复活以后，要在你们之前到加利利去。”</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马太福音 26:33–35; 路加福音 22:33–34; 约翰福音 13:36–38"> 彼得对耶稣说：“即使所有的人被绊倒<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="被绊倒——或译作“放弃信仰”。">i</a></sup>，我还是不会。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约翰福音 13:38; 马可福音 14:66–72; 创世记 1:5"> 可是耶稣对他说：<span className="woj">“我确实地告诉你：今天，就在今夜，鸡叫两遍以前，你会三次不认我。”</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及记 19:8; 约翰福音 13:37; 箴言 16:18"> 彼得却坚决<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="坚决——有古抄本作“更加坚决”。">j</a></sup>地说：“就算我必须与你同死，我也绝不会不认你。”所有的门徒也都这么说。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马可福音 14:36; 马可福音 14:39; 诗篇 18:5–6"> 他们来到一个名叫客西马尼的地方。耶稣对他的门徒们说：<span className="woj">“我祷告的时候，你们坐在这里。”</span></span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 22:44; 希伯来书 5:7; 马可福音 5:37"> 他带了彼得、雅各和约翰一起去。这时候，他开始忧惧起来，极其难过，</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 12:27; 马可福音 13:35–37; 彼得前书 5:8"> 对他们说：<span className="woj">“我的灵魂很忧伤，几乎要死。你们留在这里，要警醒。”</span></span>
<span className="v" id="v35" data-v="35" data-xref="马可福音 14:41; 申命记 9:18; 希伯来书 5:7"> 耶稣稍往前走，俯伏在地，祷告说，如果有可能，让那时刻离开他。</span>
<span className="v" id="v36" data-v="36" data-xref="加拉太书 4:6; 罗马书 8:15–16; 约翰福音 5:30"> 他说：<span className="woj">“阿爸！父啊！在你，没有不可能的事，请把这杯从我这里拿走吧！但不要照我的意愿，而要照你的意愿。”</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="马太福音 26:40; 马可福音 14:29–31; 希伯来书 12:3"> 耶稣回来，看见他们睡着了，就对彼得说：<span className="woj">“西门，你睡着了？难道你不能警醒一个小时吗？</span></span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 26:41; 马太福音 24:42; 路加福音 21:36"> <span className="woj">要警醒祷告，免得陷入试探。你们心灵虽然愿意，肉体却是软弱的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="马太福音 26:42–44; 哥林多后书 12:8; 马太福音 6:7"> 耶稣又去祷告，说了同样的话。</span>
<span className="v" id="v40" data-v="40" data-xref="马可福音 9:33–34; 罗马书 3:19; 创世记 44:16"> 他又回来，看见他们在睡觉，因为他们的眼皮发沉，也不知道要回答耶稣什么。</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 14:35; 马可福音 9:31; 约翰福音 17:1"> 耶稣第三次回来，对他们说：<span className="woj">“你们还在睡觉、休息吗？已经够了，时候到了！看哪，人子被交在</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="被交在——或译作“被出卖到”。">k</a></sup><span className="woj">罪人的手里了。</span></span>
<span className="v" id="v42" data-v="42" data-xref="马太福音 26:46; 约翰福音 18:1–2"> <span className="woj">起来，我们走吧！看，那出卖我的人快到了！”</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="约翰福音 18:3–11; 路加福音 22:47–53; 马太福音 26:47–56"> 耶稣还在说话的时候，忽然十二使徒之一的犹大来了。有一群人拿着刀剑和棍棒与他一起来，他们是祭司长们、经文士们和长老们所派来的。</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 26:48–50; 箴言 27:6; 诗篇 55:20–21"> 那出卖耶稣的人已经和他们定了一个暗号，说：“我如果亲吻谁，谁就是那个人。你们把他抓住，小心地带走。”</span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 23:7–10; 玛拉基书 1:6; 马可福音 12:14"> 犹大一到，就上前对耶稣说：“拉比！”然后亲吻了他。</span>
<span className="v" id="v46" data-v="46" data-xref="约翰福音 18:12; 耶利米哀歌 4:20; 使徒行传 2:23"> 他们就下手拘捕了耶稣。</span>
<span className="v" id="v47" data-v="47" data-xref="约翰福音 18:10–11; 马太福音 26:51–54; 路加福音 22:49–51"> 站在旁边的一个门徒拔出刀来，向大祭司的奴仆砍去，削掉了他的一个耳朵。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="路加福音 22:52–53; 撒母耳记上 26:18; 撒母耳记上 24:14–15"> 耶稣对他们说：<span className="woj">“你们带着刀剑和棍棒出来抓我，就像对付强盗那样吗？</span></span>
<span className="v" id="v49" data-v="49" data-xref="约翰福音 18:20; 约翰福音 8:2; 路加福音 22:37"> <span className="woj">我天天在圣殿里教导人，和你们在一起，而你们不抓我。不过这是为要应验那些经文。”</span></span>
<span className="v" id="v50" data-v="50" data-xref="马可福音 14:27; 约翰福音 16:32; 诗篇 88:18"> 这时候，所有的门徒都离开他逃跑了。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51"> 有一个年轻人，赤身披上一块细麻布，跟在耶稣后面。那些人<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="那些人——有古抄本作“一些年轻人”。">l</a></sup>就抓住他，</span>
<span className="v" id="v52" data-v="52" data-xref="马可福音 13:14–16; 创世记 39:12; 约伯记 2:4"> 可是他却丢下麻布，赤着身子逃跑了。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="马太福音 26:57–68; 约翰福音 18:12–14; 路加福音 22:54–62"> 他们把耶稣带到大祭司那里。所有的祭司长、长老和经文士都聚在一起。</span>
<span className="v" id="v54" data-v="54" data-xref="约翰福音 18:18; 马太福音 26:3; 约翰福音 18:25"> 彼得远远地跟着耶稣，直到进了大祭司的院子里。他与差役们一起坐在火边取暖。</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="彼得前书 3:16–18; 马太福音 26:59–60; 马太福音 5:22"> 当时，祭司长们和全议会的人为了要处死耶稣，都在寻找证据来控告他。可是他们找不出什么。</span>
<span className="v" id="v56" data-v="56"> 许多人做伪证诬告他，可是这些证词互相矛盾。</span>
<span className="v" id="v57" data-v="57" data-xref="使徒行传 6:13–14; 马太福音 26:60–61; 约翰福音 2:18–21"> 有一些人站起来做伪证控告他，说：</span>
<span className="v" id="v58" data-v="58" data-xref="约翰福音 2:19; 希伯来书 9:11; 哥林多后书 5:1"> “我们听他说过‘我要拆毁这座人手所造的圣所，三天内另建一座不是人手所造的。’”</span>
<span className="v" id="v59" data-v="59"> 可是他们这个证词也是互相矛盾的。</span>
</div>
<div className="bp">
<span className="v" id="v60" data-v="60" data-xref="约翰福音 19:9–10; 马太福音 26:62–63; 马可福音 15:3–5"> 于是大祭司就起来站到中间问耶稣，说：“对这些人控告你的事，你什么都不回应吗？”</span>

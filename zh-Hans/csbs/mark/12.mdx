<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 5:1–4; 马可福音 13:34; 雅歌 8:11–12"> 耶稣开始用比喻对他们说：<span className="woj">“有一个人栽种了一个葡萄园，四面围上篱笆，挖了一个榨酒池，盖了一座守望楼，然后把葡萄园租给一些农夫，就出外旅行。</span></span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 15:1–8; 希伯来书 1:1; 耶利米书 44:4"> <span className="woj">到了收获的</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="收获的——辅助词语。">a</a></sup><span className="woj">季节，他就派了一个奴仆到那些农夫那里去，好从他们收取葡萄园的果子。</span></span>
<span className="v" id="v3" data-v="3" data-xref="帖撒罗尼迦前书 2:15; 尼希米记 9:26; 耶利米书 29:26"> <span className="woj">但他们抓住那奴仆，打了他，叫他空手回去。</span></span>
<span className="v" id="v4" data-v="4"> <span className="woj">园主又派另一个奴仆到他们那里去。那些农夫</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附“用石头砸他，”。">b</a></sup><span className="woj">打伤了他的头，并且侮辱他</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附“把他赶了回去”。">c</a></sup><span className="woj">。</span></span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 22:6; 马太福音 23:37; 尼希米记 9:30"> <span className="woj">园主再派另一个去，他们把他杀了。另派了许多去，有的被打，有的被杀。</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="希伯来书 1:1–2; 马太福音 3:17; 约翰福音 1:34"> <span className="woj">“那园主还有一位——是他的爱子。最后他差派儿子到他们那里，说：‘他们一定会尊重我的儿子。’</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="创世记 37:20; 马太福音 2:16; 使徒行传 2:23"> <span className="woj">“可是那些农夫彼此说：‘这是继承人。来，我们把他杀了，那继业就归我们了。’</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 21:39; 路加福音 20:15; 马太福音 21:33"> <span className="woj">于是他们抓住他，把他杀了，并扔出葡萄园外。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="罗马书 10:20–12; 马太福音 21:43; 路加福音 19:27"> <span className="woj">“那么，葡萄园的主人会做什么呢？他会来除灭那些农夫，把葡萄园交给别人。</span></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 118:22–23; 彼得前书 2:7–8; 以赛亚书 28:16"> <span className="woj">你们难道也没有读过这段经文吗？</span><br /><span className="pl pl-1 woj">‘工匠所弃绝的石头，</span><br /><span className="pl pl-1 woj">它已经成了房角的头块石头；</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 118:23; 使徒行传 3:12–16; 哈巴谷书 1:5"> <span className="pl pl-1 woj">这是主所成就的，</span><br /><span className="pl pl-1 woj">在我们眼中实在奇妙！’</span><br /><span className="pl pl-1 woj">”</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马可福音 11:18; 马太福音 22:22; 约翰福音 7:44"> 祭司长们、律法师们和长老们知道这比喻是针对他们而说的，就想拘捕耶稣。可是他们怕民众，于是离开耶稣走了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 20:20–26; 路加福音 11:54; 马可福音 3:6"> 后来，他们派了一些法利赛人和希律党的人到耶稣那里，要找话柄来陷害他。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:4; 路加福音 20:22; 约翰福音 7:18"> 那些人来对耶稣说：“老师，我们知道你是真诚的。你不顾忌任何人，因为你不看人的情面，而是按真理教导神的道<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="道——或译作“路”。">d</a></sup>。请问，向凯撒纳税，可以不可以呢？我们该交还是不该交呢？”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西结书 17:2; 启示录 2:23; 马可福音 10:2"> 耶稣看出他们的假意，就对他们说：<span className="woj">“你们为什么试探我呢？拿一个银币</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="银币——原文为“得拿利”。1得拿利=约1日工资的罗马银币。">e</a></sup><span className="woj">来给我看。”</span></span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 20:24–26; 启示录 3:12; 马太福音 22:19–22"> 他们就拿来了。耶稣问他们：<span className="woj">“这是谁的像和名号？”</span><br />他们回答说：“是凯撒的。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 13:7; 彼得前书 2:17; 哥林多后书 5:14–15"> 耶稣对他们说：<span className="woj">“凯撒的归给凯撒；神的归给神。”</span>这使他们感到惊奇。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 22:23–33; 使徒行传 4:1–2; 使徒行传 23:6–9"> 接着，撒都该人来到耶稣那里，他们一向说没有复活的事。他们问耶稣，说：</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 25:5–10; 路得记 4:5; 路得记 1:11–13"> “老师，摩西为我们写道：如果一个人的兄弟死了，撇下妻子而没有留下孩子，他就应该娶这妇人，为兄弟留后裔。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 22:25–28; 路加福音 20:29–33"> 曾经有兄弟七人，第一个娶了妻子，死去了，没有留下后裔。</span>
<span className="v" id="v21" data-v="21"> 第二个娶了这寡妇，也死了，没有留下后裔。第三个也一样。</span>
<span className="v" id="v22" data-v="22"> 结果，兄弟七个都<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附“娶过她，而”。">f</a></sup>没有留下后裔。到了最后，这妇人也死了。</span>
<span className="v" id="v23" data-v="23"> 既然这七个人都娶过她为妻，在复活的时候，当他们复活了<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本没有“当他们复活以后”。">g</a></sup>，她将是谁的妻子呢？”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约翰福音 20:9; 提摩太后书 3:15–17; 马太福音 22:29"> 耶稣说：<span className="woj">“你们之所以错了，不就是因为你们不明白经上的话，也不明白神的大能吗？</span></span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 20:35–36; 马太福音 22:30; 约翰一书 3:2"> <span className="woj">当人从死人中复活以后，他们既不娶也不嫁，而是像诸天之上的天使一样。</span></span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 3:2–6; 路加福音 20:37; 创世记 17:7–8"> <span className="woj">关于死人复活的事，你们难道没有读过摩西书‘荆棘篇’上，神怎样对摩西说的吗？神说‘我是亚伯拉罕的神、以撒的神、雅各的神。’</span></span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 14:9; 罗马书 4:17; 马可福音 12:24"> <span className="woj">神不是死人的神，而是活人的神</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本没有“神”。">h</a></sup><span className="woj">。你们完全错了！”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马太福音 22:34–40; 路加福音 10:25–28; 路加福音 20:39"> 有一个经文士前来，听见他们辩论，见耶稣回答得好，就问耶稣：“所有的诫命中，哪一条是最重要的呢？”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="申命记 6:4; 路加福音 10:27; 加拉太书 3:20"> 耶稣回答：<span className="woj">“</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附“所有诫命中”。">i</a></sup><span className="woj">最重要的是：</span><br /><span className="woj">‘以色列啊，你当听好！主——我们的神，是独一的主。</span></span>
<span className="v" id="v30" data-v="30" data-xref="申命记 6:5"> <span className="woj">你要以全心、全灵、全意、全力爱主——你的神。’</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附“这是最重要的诫命。”">j</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="罗马书 13:8–9; 马太福音 22:39; 利未记 19:18"> <span className="woj">“其次就是‘要爱邻如己。’</span><span className="woj">没有别的诫命比这两条更大的了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="申命记 4:39; 申命记 4:35; 以赛亚书 46:9"> 那经文士就对耶稣说：“不错，老师，你真的讲了：神只有一位，除他以外没有别的神。</span>
<span className="v" id="v33" data-v="33" data-xref="何西阿书 6:6; 弥迦书 6:6–8; 撒母耳记上 15:22"> 以全心、全智、<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="有古抄本附“全灵、”。">k</a></sup>全力来爱神，并且要爱邻如己，这是比所有的燔祭和各种祭祀都重要的。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="歌罗西书 4:6; 路加福音 20:40; 马太福音 22:46"> 耶稣见他回答得有智慧，就对他说：<span className="woj">“你离神的国不远了。”</span>于是，没有人敢再质问耶稣了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="路加福音 20:41–44; 马太福音 22:41–45; 马太福音 26:55"> 耶稣在圣殿里教导人的时候问：<span className="woj">“经文士们怎么说基督是大卫的后裔呢？</span></span>
<span className="v" id="v36" data-v="36" data-xref="诗篇 110:1; 希伯来书 1:13; 马太福音 22:43–45"> <span className="woj">大卫藉着圣灵，自己说过：</span><br /><span className="pl pl-1 woj">‘主对我主说：</span><br /><span className="pl pl-1 woj">你坐在我的右边，</span><br /><span className="pl pl-1 woj">等我把你的敌人放在你的脚下</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本附“做脚凳”。">l</a></sup><br /><span className="pl pl-1 woj">。’</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="罗马书 1:3–4; 马太福音 11:25; 马太福音 1:23"> <span className="woj">大卫自己称基督为‘主’，基督又怎么会是大卫的后裔呢？”</span>那一大群人都乐意听耶稣讲说。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="马太福音 23:1–7; 路加福音 20:45–47; 路加福音 11:43"> 耶稣在他的教导中说：<span className="woj">“你们要当心经文士们。他们喜欢穿着长袍走来走去，喜欢街市上的致敬问候，</span></span>
<span className="v" id="v39" data-v="39" data-xref="雅各书 2:2–3"> <span className="woj">又喜欢会堂里的首位、宴席中的上座。</span></span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 23:13; 路加福音 20:47; 马太福音 23:33"> <span className="woj">他们侵吞寡妇的家产，又假意做很长的祷告。这些人将受到更重的惩罚</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="惩罚——或译作“审判”。">m</a></sup><span className="woj">。”</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 21:1–4; 列王纪下 12:9; 约翰福音 8:20"> 耶稣面对奉献箱坐着，看众人怎样把钱投入奉献箱里。许多富有的人投进了很多钱。</span>
<span className="v" id="v42" data-v="42"> 有一个穷寡妇来，投进两个小钱<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="两个小钱——原文为“2雷普顿”。1雷普顿=约1/128日工资的希腊小铜币。">n</a></sup>，值一个铜币<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="铜币——原文为“柯锥特”。1柯锥特=约1/64日工资的罗马铜币。">o</a></sup>。</span>
<span className="v" id="v43" data-v="43" data-xref="哥林多后书 9:6–8; 哥林多后书 8:2; 使徒行传 11:29"> 耶稣把他的门徒们召来，对他们说：<span className="woj">“我确实地告诉你们：这穷寡妇所投入奉献箱的，比所有的人投的更多。</span></span>
<span className="v" id="v44" data-v="44" data-xref="哥林多后书 8:2–3; 约翰一书 3:17; 以斯拉记 2:68–69"> <span className="woj">因为大家是从自己的富余中拿出来投进去；而这寡妇是从自己的缺乏中，把她所拥有的一切，就是她全部的养生费用都投进去了。”</span></span>
</div>

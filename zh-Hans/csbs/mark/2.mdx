<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 4:47; 路加福音 5:18; 路加福音 18:35–38"> 过了些日子，耶稣又进了迦百农。人们听说他在房子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="房子——或译作“家”。">a</a></sup>里，</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 2:13; 马可福音 1:45; 诗篇 40:9"> 许多人就聚集，甚至连门前都没有空处了。于是耶稣就向他们讲道。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 5:18–26; 马太福音 9:1–8; 马太福音 4:24"> 这时候，一些人带了一个瘫痪的人来到耶稣那里，是被四个人抬来的；</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 5:19; 申命记 22:8"> 但由于人多，无法抬到耶稣面前<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="抬到耶稣面前——有古抄本作“靠近他（耶稣）”。">b</a></sup>，他们就把耶稣上方的屋顶拆了。拆通之后，就把躺在垫子上那瘫痪的人缒了下去。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马太福音 9:2; 雅各书 5:15; 马可福音 2:9–10"> 耶稣看见他们的信心，就对瘫痪的人说：<span className="woj">“孩子，你的罪孽被赦免了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="路加福音 5:21–22; 马可福音 8:17; 哥林多后书 10:5"> 可是，有一些经文士坐在那里，心里想：</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 43:25; 路加福音 5:21; 弥迦书 7:18"> “这个人怎么这样说话呢？他说亵渎的话！除了神一位之外，谁能赦免罪呢？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="诗篇 139:2; 使徒行传 8:22; 路加福音 5:22"> 耶稣灵里立刻知道他们心里这样想，就对他们说：<span className="woj">“你们心里为什么想这些事呢？</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 5:22–25; 马太福音 9:5"> <span className="woj">对这瘫痪的人说‘你的罪孽被赦免了’，或说‘你起来，拿起垫子走路’，哪一样更容易呢？</span></span>
<span className="v" id="v10" data-v="10" data-xref="但以理书 7:13–14; 马太福音 9:6–8; 约翰福音 5:20–27"> <span className="woj">不过为要使你们知道人子在地上有赦免罪的权柄——”</span>耶稣就对瘫痪的人说：</span>
<span className="v" id="v11" data-v="11" data-xref="马可福音 1:41; 约翰福音 5:8–10; 约翰福音 6:63"> <span className="woj">“我吩咐你：起来，拿起你的垫子，回家去吧！”</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 9:33; 马太福音 9:8; 路加福音 7:16"> 那个人就立刻起来，拿起垫子在大家面前出去了。结果大家都惊讶，就荣耀神，说：“我们从来没有见过这样的事。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马可福音 4:1; 箴言 1:20–22; 路加福音 19:48"> 后来，耶稣又出去，到了加利利湖<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="湖——原文直译“海”。">c</a></sup>边。众人都来到他那里，他就教导他们。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 5:27–32; 路加福音 6:15; 马太福音 9:9–13"> 耶稣往前走，看见亚勒腓的儿子利未<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="利未——就是“马太”。">d</a></sup>在税关坐着。耶稣对他说：<span className="woj">“你跟从我！”</span>利未就站起来，跟从了耶稣。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 15:1; 路加福音 5:29–30; 马太福音 9:10–11"> 耶稣在利未家里坐席的时候，许多税吏和罪人与耶稣及他的门徒们一同坐席，因为有许多这样的人也跟随了耶稣。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:10; 路加福音 19:7; 路加福音 18:11"> 有些法利赛派的经文士<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有些法利赛派的经文士——有古抄本作“有些经文士和法利赛人”。">e</a></sup>见耶稣与罪人和税吏一起吃饭，就对耶稣的门徒们说：“他怎么与那些税吏和罪人一起吃饭<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="吃饭——有古抄本作“吃喝”。">f</a></sup>呢？”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 9:12–13; 路加福音 15:7; 路加福音 5:31–32"> 耶稣听见了，就对他们说：<span className="woj">“健康的人不需要医生，有病的人才需要。我来不是要召唤义人，而是要召唤罪人</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附“来悔改”。">g</a></sup><span className="woj">。”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 18:12; 马太福音 6:18; 马太福音 9:14–17"> 约翰的门徒们和法利赛人<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="法利赛人——有古抄本作“法利赛人的门徒们”。">h</a></sup>正禁食的时候，有些人来问耶稣：“为什么约翰的门徒们和法利赛人的门徒们都禁食，而你的门徒们却不禁食呢？”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马太福音 25:1–10; 创世记 29:22; 士师记 14:10–11"> 耶稣对他们说：<span className="woj">“新郎与宾客</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="宾客——或译作“伴郎”；原文直译“新房之子”。">i</a></sup><span className="woj">在一起的时候，难道宾客能禁食吗？只要他们与新郎在一起，他们就不能禁食。</span></span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 17:22; 启示录 21:9; 以赛亚书 54:5"> <span className="woj">可是日子将要来到：当新郎从他们中间被带走的时候，他们那时——在那一天就要禁食了。</span></span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 9:16; 哥林多前书 10:13; 以赛亚书 57:16"> <span className="woj">没有人把没缩过水的布块补在旧衣服上。否则所补上的新布会扯坏旧衣服，造成更大的裂口。</span></span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 9:17; 诗篇 119:83; 路加福音 5:37–38"> <span className="woj">同样，也没有人把新酒装在旧皮袋里，否则酒</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="酒——有古抄本作“新酒”。">j</a></sup><span className="woj">会胀破皮袋，酒和皮袋都糟蹋了</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="酒和皮袋都糟蹋了——有古抄本作“酒会流出来，皮袋也会糟蹋了”。">k</a></sup><span className="woj">。因此，新酒必须装</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本没有“必须装”。">l</a></sup><span className="woj">在新皮袋里。”</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 12:1–8; 申命记 23:24–25; 路加福音 6:1–5"> 有一次在安息日，耶稣从麦田经过，他的门徒们开始边走边摘麦穗。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 20:10; 希伯来书 12:3; 马太福音 12:2"> 有些法利赛人对耶稣说：“你看，他们为什么做安息日不可以做的事呢？”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 21:3–6; 路加福音 10:26; 马太福音 22:31"> 耶稣对他们说：<span className="woj">“大卫和那些与他在一起的人饥饿缺乏时所做的事，难道你们从来没有读过吗？</span></span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 8:17; 利未记 24:5–9; 撒母耳记上 21:1"> <span className="woj">在亚比亚特任大祭司的时候，他难道不是进了神的殿</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="殿——原文直译“家”。">m</a></sup><span className="woj">，吃了陈设饼，还分给与他在一起的人吗？这饼除了祭司，谁都不可以吃。”</span></span>
<span className="v" id="v27" data-v="27" data-xref="歌罗西书 2:16; 路加福音 6:9; 申命记 5:14"> 接着，耶稣对他们说：<span className="woj">“安息日是为人而存在的，人不是为安息日而存在的。</span></span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 12:8; 启示录 1:10; 约翰福音 5:17"> <span className="woj">所以，人子是主，也是安息日的主。”</span></span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 4:16–30; 马太福音 13:54–58; 马太福音 2:23"> 耶稣离开那地方，来到自己的家乡，他的门徒们也跟着他。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 7:15; 约翰福音 6:42; 使徒行传 4:13–14"> 到了安息日，他开始在会堂里教导人。许多人听了就惊叹不已，说：“这个人从哪里得来这些呢？赐给这个人的到底是什么样的智慧？藉着他的手所行出来的到底是怎么样的神迹？</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 12:46; 马太福音 13:55–57; 约翰福音 6:42"> 这不就是那木匠吗？不就是玛丽亚的儿子，雅各、约西、犹大和西门的哥哥<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="哥哥——原文直译“兄弟”。">a</a></sup>吗？他的妹妹们<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="妹妹们——原文直译“姐妹们”。">b</a></sup>不也和我们在这里吗？”这样，他们就对耶稣很反感<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="对耶稣很反感——原文直译“因耶稣被绊倒”。">c</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰福音 4:44; 路加福音 4:24; 马太福音 13:57"> 耶稣对他们说：<span className="woj">“先知除了在本乡、本族、本家以外，没有不受尊重的。”</span></span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 13:58; 马可福音 9:23; 马可福音 5:23"> 所以，耶稣无法在那里行什么神迹，只是按手在几个病人身上，使他们痊愈。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 9:35; 马太福音 8:10; 路加福音 13:22"> 因为他们的不信，耶稣十分感慨。 差派十二使徒<br />于是，他就走遍各村庄四处教导人。</span>
<span className="v" id="v7" data-v="7" data-xref="传道书 4:9–10; 路加福音 10:17–20; 马太福音 10:1–5"> 耶稣召来十二使徒<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="使徒——辅助词语。">d</a></sup>，开始差派他们两个两个地出去，赐给他们权柄胜过污灵，</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 9:3; 马太福音 10:9–10; 路加福音 10:4"> 并且吩咐他们说：<span className="woj">“在路上除了手杖什么都不要带。不要带食物，不要带行囊，腰包里也不要带钱。</span></span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 12:8; 以弗所书 6:15"> <span className="woj">要穿上鞋子。不要穿两件衣服</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="衣服——或译作“衬袍”。">e</a></sup><span className="woj">。”</span></span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 10:7–8; 路加福音 9:4; 马太福音 10:11–13"> 他又对他们说：<span className="woj">“无论在哪里，你们进了一家，就要住在哪里，直到离开那地方。</span></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 10:14–15; 使徒行传 18:6; 路加福音 10:10–15"> <span className="woj">如果有什么地方的人不接受你们，也不听你们，你们离开那里的时候，要把脚底的尘土跺掉，做为对他们的见证。</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附“我确实地告诉你们：在那审判的日子，所多玛和格摩拉所受的，将要比那城还容易受呢！”">f</a></sup><span className="woj">”</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 4:17; 路加福音 13:3; 使徒行传 20:21"> 使徒们就出去宣讲道：人人都当悔改。</span>
<span className="v" id="v13" data-v="13" data-xref="雅各书 5:14–15; 马可福音 6:7; 路加福音 10:17"> 他们驱赶了很多鬼魔，又用油来膏抹许多病人，使他们痊愈。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 9:7–9; 马可福音 6:14–29; 路加福音 23:7–12"> 耶稣的名声被传扬出去，希律王也听见了。有些人<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有些人——有古抄本作“他”。">g</a></sup>说：“施洗者<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="施洗者——或译作“施浸者”。">h</a></sup>约翰从死人中复活了，所以这些能力在他里面做工。”</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 16:14; 玛拉基书 4:5; 马太福音 21:11"> 也有些人说：“他是以利亚。”还有些人说：“他是个先知，像古代<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="古代——辅助词语。">i</a></sup>先知中的一位。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="启示录 11:10–13; 马太福音 27:4; 路加福音 9:9"> 但希律听了却说：“是被我砍了头的约翰！这个人<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附“从死人中”。">j</a></sup>复活了！”</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 3:19–20; 马太福音 11:2; 路加福音 3:1"> 原来，希律为了他弟弟<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="弟弟——原文直译“兄弟”。">k</a></sup>菲利普的妻子希罗迪娅的缘故，曾经派人去拘捕约翰，把他捆锁在监狱里。希律娶了这个女人，</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 20:21; 利未记 18:16; 列王纪上 22:14"> 而约翰一直对希律说：“你占有自己兄弟的妻子是不可以的。”</span>
<span className="v" id="v19" data-v="19" data-xref="传道书 7:9; 以弗所书 4:26–27; 创世记 39:17–20"> 所以希罗迪娅对约翰怀恨在心，想要杀他，只是不能。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 21:26; 马太福音 14:5; 历代志下 24:15–22"> 这是因为希律敬畏约翰，知道他是义人，是圣人，所以保护着他。希律听约翰讲说的时候，虽然心里十分困惑<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="心里十分困惑——有古抄本作“做了许多事”。">l</a></sup>，还是乐意听他的。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以斯帖记 2:18; 创世记 40:20; 彼得前书 4:3"> 可是时机来了。希律在自己生日那天预备宴席，招待他的大臣和军官们，以及加利利的首领们。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯帖记 1:10–12; 马太福音 14:6; 但以理书 5:2"> 希罗迪娅的女儿<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="希罗迪娅的女儿——有古抄本作“他的女儿希罗迪娅”。">m</a></sup>进来跳舞，使希律和一同坐席的人都非常喜悦。王就对女孩说：“你无论想要什么，向我求，我就会给你。”</span>
<span className="v" id="v23" data-v="23" data-xref="以斯帖记 7:2; 以斯帖记 5:3; 以斯帖记 5:6"> 并且对她郑重地起誓：“你无论向我求什么，即使是我国家的一半，我也会给你！”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约伯记 31:31; 以西结书 19:2–3; 创世记 27:8–11"> 于是女孩出去问她母亲说：“我应该要什么呢？”<br />她母亲说：“要施洗者<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="施洗者——或译作“施浸者”。">n</a></sup>约翰的头！”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="罗马书 3:15; 民数记 7:19–89; 民数记 7:13"> 女孩随即赶快进到王那里，要求说：“我愿王立即把施洗者<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="施洗者——或译作“施浸者”。">o</a></sup>约翰的头放在盘子里给我。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 27:24–25; 马太福音 14:9; 马太福音 27:3–5"> 王就变得很忧愁，但因所起的誓，又因坐席的人，就不好拒绝她。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 14:10–11"> 于是王立刻派了刽子手，命令把约翰的头拿来。刽子手就去，在监狱里砍下了约翰的头，</span>
<span className="v" id="v28" data-v="28"> 把他的头放在盘子上，端给女孩，女孩就把它交给了母亲。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 14:12; 历代志下 24:16; 马太福音 27:57–60"> 约翰的门徒们听到了，就来把他的遗体领去，安放在坟墓里。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 9:10; 路加福音 10:17; 马太福音 10:2"> 使徒们聚集到耶稣那里，把他们所做的和教导的一切告诉了他。</span>
<span className="v" id="v31" data-v="31" data-xref="马可福音 3:20; 约翰福音 6:1; 马可福音 1:45"> 耶稣对他们说：<span className="woj">“来，你们自己单独到一个荒僻的地方休息一会儿吧。”</span>这是因为来往的人多，他们连吃饭的时间也没有。</span>
<span className="v" id="v32" data-v="32" data-xref="马可福音 8:2–9; 马可福音 6:45; 马可福音 4:36"> 于是他们悄悄地坐船出发，往一个荒僻的地方去。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 6:2; 马太福音 15:29–31; 马可福音 6:54–55"> 可是众人<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="有古抄本没有“众人”。">p</a></sup>看见他们离开了，并且有许多人认出他们<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="他们——有古抄本作“他”。">q</a></sup>，就从各城镇一起徒步赶往那里，而且比他们先到了<sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="有古抄本附“并聚集到他那里”。">r</a></sup>。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 9:36; 路加福音 9:11; 民数记 27:17"> 耶稣下了船，看见一大群人，就对他们动了怜悯之心，因为他们像羊没有牧人那样。耶稣就开始教导他们很多事。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="约翰福音 6:5–15; 路加福音 9:12–17; 马太福音 14:15–21"> 天已经晚了，他的门徒们来到耶稣面前，说：“这是个荒僻的地方，而且天已经晚了。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 15:23; 马可福音 3:21; 马可福音 5:31"> 请遣散大家，好让他们到周围的田舍和村庄去，为自己买些东西吃<sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="为自己买些东西吃——有古抄本作“为自己买些饼，因为他们没有东西吃”。">s</a></sup>。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="列王纪下 4:42–44; 马太福音 15:32–33; 马可福音 8:2–3"> 但耶稣回答他们，说：<span className="woj">“你们给他们吃的吧。”</span><br />门徒们说：“要我们去买两百个银币<sup className="fn"><a href="#fn-t" id="fnref-t" data-fn="两百个银币——原文为“200得拿利”。1得拿利=约1日工资的罗马银币。">t</a></sup>的饼给他们吃吗？”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="马太福音 15:34; 马可福音 8:5; 约翰福音 6:9"> 耶稣问他们：<span className="woj">“你们有多少饼呢？去看看。”</span><br />他们察看后，就说：“有五个，还有两条鱼。”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="哥林多前书 14:40; 哥林多前书 14:33; 马太福音 15:35"> 耶稣吩咐他们，叫众人一组一组地坐在青草地上。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 9:14–15"> 众人就一群一群地坐了下来，有的一百人，有的五十人。</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 14:19; 马可福音 7:34; 路加福音 9:16"> 耶稣拿起这五个饼和两条鱼，抬头望天，祝福了，然后把饼掰开，不断递给他的门徒们，让他们分给众人。他把两条鱼也分给大家。</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 9:17; 马可福音 8:8–9; 马太福音 15:37–38"> 大家都吃了，并且吃饱了。</span>
<span className="v" id="v43" data-v="43" data-xref="马可福音 8:19–20"> 他们把饼和鱼的碎块收拾起来，装满了十二个篮子。</span>
<span className="v" id="v44" data-v="44"> 吃饼的人，男人就有五千。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="马太福音 14:22–33; 约翰福音 6:15–21; 马可福音 6:32"> 耶稣随即催促他的门徒们上船，要他们先往对岸的伯赛达去；这期间，他自己遣散了人群。</span>
<span className="v" id="v46" data-v="46" data-xref="马可福音 1:35; 马太福音 6:6; 路加福音 6:12"> 他告别了他们，就上山去祷告。</span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 14:23; 约翰福音 6:16–17"> 到了晚上，船在湖<sup className="fn"><a href="#fn-u" id="fnref-u" data-fn="湖——原文直译“海”；指“加利利湖（海）”。">u</a></sup>中，只有耶稣一个人在岸上。</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 24:28; 路加福音 12:38; 约伯记 9:8"> 他看见门徒们由于逆风，划船非常艰苦。天快亮的时候<sup className="fn"><a href="#fn-v" id="fnref-v" data-fn="天快亮的时候——原文直译“夜里四更天”；指“早晨三点至六点之间”。">v</a></sup>，耶稣在湖面上行走，向他们而去，想要从他们旁边走过去。</span>
<span className="v" id="v49" data-v="49" data-xref="马太福音 14:25–26; 路加福音 24:37; 约伯记 9:8"> 门徒们看见耶稣在湖面上行走，以为是幽灵，于是喊叫起来，</span>
<span className="v" id="v50" data-v="50" data-xref="马太福音 14:27; 约翰福音 6:19–20; 以赛亚书 43:2"> 因为他们都看见了他，就惊慌不安。耶稣立刻与他们讲话，对他们说：<span className="woj">“鼓起勇气吧！是我，不要怕。”</span></span>
<span className="v" id="v51" data-v="51" data-xref="诗篇 93:3–4; 马可福音 4:39; 约翰福音 6:21"> 接着，耶稣上了船和他们在一起。这时候风就停了。门徒们心里感到极其惊讶<sup className="fn"><a href="#fn-w" id="fnref-w" data-fn="有古抄本附“又诧异”。">w</a></sup>，</span>
<span className="v" id="v52" data-v="52" data-xref="马可福音 8:17–21; 路加福音 24:25; 以赛亚书 63:17"> 因为他们不领悟分<sup className="fn"><a href="#fn-x" id="fnref-x" data-fn="分——辅助词语。">x</a></sup>饼的事，他们还是硬着心。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="马太福音 14:34–36; 约翰福音 6:24–25; 路加福音 5:1"> 他们渡过去，到革尼撒勒上岸，把船拴好。</span>
<span className="v" id="v54" data-v="54" data-xref="诗篇 9:10; 腓立比书 3:10"> 一下船，众人就认出了耶稣。</span>
<span className="v" id="v55" data-v="55" data-xref="马太福音 4:24; 马可福音 2:1–3; 马可福音 3:7–11"> 人们跑遍那整个地区，听到耶稣在哪里，就把有病的人用垫子抬到哪里。</span>
<span className="v" id="v56" data-v="56" data-xref="马太福音 9:20; 路加福音 6:19; 民数记 15:38–39"> 无论耶稣进到哪里，或村庄、或城镇、或乡下，人们就把病人放在街市上，恳求耶稣只要让他们摸一下他的衣服穗子。凡是摸着的人，都得了救治。</span>
</div>

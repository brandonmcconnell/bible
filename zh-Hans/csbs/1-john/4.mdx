<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="1JN" data-book-slug="1-john" data-book-name="约翰一书" data-chapter="4" data-verses="21">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 5:21; 彼得后书 2:1; 提摩太前书 4:1"> 各位蒙爱的人哪，你们不要每一个灵都相信，而要分辨这些灵是否出于神，因为有许多假先知已经在世上出现了。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="约翰福音 1:14; 哥林多前书 12:3; 提摩太前书 3:16"> 你们从这一点就认出神的灵：任何灵承认耶稣基督是以肉身而来的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="耶稣基督是以肉身而来的——或译作“耶稣是以肉身而来的基督”。">a</a></sup>，这灵就是出于神；</span>
<span className="v" id="v3" data-v="3" data-xref="约翰一书 2:22; 约翰二书 1:7; 约翰一书 2:18"> 任何灵不承认耶稣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="耶稣——有古抄本作“耶稣基督是以肉身而来”。">b</a></sup>的，这灵就不是出于神，而是那敌基督者的灵。你们听说过这灵要来，而它现在已经在世上了。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="罗马书 8:31; 约翰一书 5:4; 罗马书 8:37"> 孩子们哪，你们属于神，而且你们已经胜过了假先知们<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="假先知们——原文直译“他们”。">c</a></sup>，因为那在你们里面的，比那在世界上的更大。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 8:23; 彼得后书 2:2–3; 约翰福音 17:14"> 他们属于世界，所以他们说的属于世界，而世界也听从他们。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 14:17; 约翰福音 10:27; 哥林多前书 2:12–14"> 我们属于神，那认识神的，就听从我们；那不属于神的，就不听从我们。由此，我们就认出真理的灵和迷惑人的灵。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约翰一书 4:20–1; 约翰一书 4:8; 彼得前书 1:22"> 各位蒙爱的人哪，让我们彼此相爱，因为爱是出于神的。凡是有爱的，都由神所生，并且认识神；</span>
<span className="v" id="v8" data-v="8" data-xref="约翰一书 4:16; 诗篇 86:15; 哥林多后书 13:11"> 那没有爱的，就不认识神，因为神就是爱。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 3:16; 约翰一书 5:11; 罗马书 8:32"> 神差派了自己的独生子到世上来，好使我们能藉着他而活；如此，属神的爱就在我们里面显明了。</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 2:4–5; 罗马书 5:8–10; 约翰一书 4:19"> 并不是我们爱了神，而是神爱了我们，差派他的儿子来，为我们的罪孽做了平息祭<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="平息祭——或译作“挽回祭”。">d</a></sup>——在这里就是爱了。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 15:12–13; 歌罗西书 3:13; 约翰福音 13:34"> 各位蒙爱的人哪，既然神如此爱我们，我们也应该彼此相爱。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 1:18; 约翰一书 2:5; 约翰一书 4:17–18"> 从来没有人见过神；如果我们彼此相爱，神就住在我们里面，他的爱也就在我们里面得以完全。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以弗所书 2:20–22; 约翰一书 3:24; 哥林多前书 3:16–17"> 我们从这一点知道：我们住在他里面，而他也住在我们里面，是因为神把他的灵赐给了我们；</span>
<span className="v" id="v14" data-v="14" data-xref="约翰一书 4:10; 约翰福音 3:16–17; 约翰福音 4:42"> 我们已经见过，并且现在见证：父差派子做世界的救主，</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 10:9; 约翰一书 5:5; 马太福音 10:32"> 凡是承认耶稣是神儿子的，神就住在他里面，他也住在神里面。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰一书 3:24; 诗篇 36:7–9; 约翰一书 3:1"> 这样，我们已经认识并相信了神对我们所怀的爱。神就是爱；那住在爱里面的，就住在神里面，神也住<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本没有“住”。">e</a></sup>在他里面。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰一书 4:12; 约翰一书 2:28; 罗马书 8:29"> 从这一点，爱在我们里面得以完全，使我们在审判的日子可以坦然无惧，因为基督<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="基督——原文直译“那一位”。">f</a></sup>怎样，我们在这世上也怎样。</span>
<span className="v" id="v18" data-v="18" data-xref="提摩太后书 1:7; 罗马书 8:15; 约翰一书 4:12"> 爱里没有惧怕；相反，完美的爱能除去惧怕，因为惧怕带有惩罚；而那惧怕的，在爱里没有得以完全。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 4:10; 约翰福音 3:16; 约翰福音 15:16"> 我们爱<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附“他”。">g</a></sup>，是因为他先爱了我们。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约翰一书 3:17; 约翰一书 2:9; 约翰一书 4:12"> 如果有人说“我爱神”，却恨自己的弟兄，他就是说谎者，因为一个人不爱自己所看到的弟兄，就不能爱没有看到的神。<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="就不能爱没有看到的神。——有古抄本作“怎么能够爱没有看到的神呢？”">h</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 22:37–39; 利未记 19:18; 约翰一书 3:11"> 这是我们从基督<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="基督——原文直译“他”。">i</a></sup>所领受的命令：爱神的，也要爱自己的弟兄。</span>
</div>
</div>

</div>

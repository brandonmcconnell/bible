<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太前书 2:5; 罗马书 8:34; 约翰福音 14:6"> 我的孩子们哪，我把这些事写给你们，免得你们犯罪。但如果有人犯了罪，在父那里我们有一位辩护者，就是那义者耶稣基督。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 4:14; 彼得前书 3:18; 约翰一书 4:10"> 他自己为我们的罪孽做了平息祭<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="平息祭——或译作“挽回祭”。">a</a></sup>，不仅是为我们的罪，也是为全世界的罪。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="约翰福音 14:15; 约翰福音 15:10; 路加福音 6:46"> 如果我们遵守基督<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="基督——原文直译“他”。">b</a></sup>的命令，从这一点我们就知道我们已经认识他。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰一书 1:6; 提多书 1:16; 雅各书 2:14–16"> 那说“我已经认识他”，却不遵守他命令的，就是说谎者，真理也不在这个人里面；</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 14:23; 约翰福音 14:21; 约翰一书 4:12–13"> 但如果有人遵守他的话语，属神的爱就确实在这个人里面得以完全了；从这一点我们就知道我们是在他里面。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前书 2:21; 约翰福音 13:15; 哥林多前书 11:1"> 那说自己住在他里面的，自己也应该按基督<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="基督——原文直译“他”。">c</a></sup>所行的照样去行。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约翰一书 3:11; 利未记 19:18; 马可福音 12:29–34"> 各位蒙爱的人哪<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="各位蒙爱的人哪——有古抄本作“弟兄们”。">d</a></sup>，我写给你们的不是一条新命令，而是你们从起初就有的旧命令；这条旧命令就是你们<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附“从起初”。">e</a></sup>所听过的那话<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="话——或译作“道”。">f</a></sup>。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 5:8; 罗马书 13:12; 约翰福音 13:34"> 另一方面，我写给你们的也是一条新命令；这命令在他、在你们，都是真实的，因为黑暗正在消逝，真光已经在照耀。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约翰一书 4:20; 约翰一书 2:11; 约翰一书 3:13–17"> 那说自己在光里却恨自己弟兄的，至今还在黑暗里；</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 3:14; 罗马书 9:32–33; 罗马书 14:13"> 那爱自己弟兄的，就住在光里，而且在他里面<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="在他里面——或译作“在光里面”。">g</a></sup>没有什么绊脚的事；</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 12:35; 提多书 3:3; 约翰一书 1:6"> 但那恨自己弟兄的，就是在黑暗里，并且在黑暗里行走，也不知道自己往哪里去，因为黑暗使他的眼睛瞎了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 10:43; 使徒行传 13:38; 以弗所书 1:7"> <span className="pl pl-1">孩子们哪，我写信给你们，</span><br /><span className="pl pl-1">因为你们的罪孽藉着基督</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="基督——原文直译“他”。">h</a></sup><br /><span className="pl pl-1">的名已经被赦免了；</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 14:7; 约翰一书 2:14; 路加福音 10:22"> <span className="pl pl-1">父老们哪，我写信给你们，</span><br /><span className="pl pl-1">因为你们已经认识了从太初就有的那一位；</span><br /><span className="pl pl-1">年轻人哪，我写信给你们，</span><br /><span className="pl pl-1">因为你们已经胜过了那恶者。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 119:11; 约翰一书 2:13; 歌罗西书 3:16"> <span className="pl pl-1">孩子们哪，我写了信给你们，</span><br /><span className="pl pl-1">因为你们已经认识了父；</span><br /><span className="pl pl-1">父老们哪，我写了信给你们，</span><br /><span className="pl pl-1">因为你们已经认识了从太初就有的那一位；</span><br /><span className="pl pl-1">年轻人哪，我写了信给你们，</span><br /><span className="pl pl-1">因为你们是强壮的，</span><br /><span className="pl pl-1">神的话语</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="神的话语——或译作“神的道”。">i</a></sup><br /><span className="pl pl-1">住在你们里面，</span><br /><span className="pl pl-1">你们也已经胜过了那恶者。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="雅各书 4:4; 罗马书 12:2; 马太福音 6:24"> 你们不要爱世界，也不要爱世界上的事物。如果有人爱世界，父的爱<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="父的爱——或译作“对父的爱”或“属父的爱”。">j</a></sup>就不在他里面了。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 13:14; 加拉太书 5:17; 诗篇 119:36–37"> 原来世界上一切肉体的欲望、眼目的欲望、今生的骄傲，都不是出于父，而是出于世界的。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 24:35; 罗马书 12:2; 哥林多前书 7:31"> 世界和属世的欲望正在消逝；但那遵行神旨意的，却永远长存。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰一书 4:3; 约翰二书 1:7; 马太福音 24:24"> 孩子们哪，现在是末后的时期了。正如你们听说过敌基督的要来，现在确实已经有许多敌基督的出现了；故此我们知道，现在是末后的时期了。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 20:30; 哥林多前书 11:19; 路加福音 8:13"> 他们从我们中间出去，但他们本来就不属于我们，因为他们如果属于我们，就会留下与我们在一起；不过这样就显明出，他们都不属于我们。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约翰福音 14:26; 约翰一书 2:27; 哥林多后书 1:21–22"> 至于你们，你们从那位圣者领受了恩膏，并且你们大家都已经知道了这事<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="大家都已经知道了这事——有古抄本作“已经知道了这一切事”。">k</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得后书 1:12; 犹大书 1:5; 箴言 1:5"> 我写了信给你们，不是因为你们不认识真理，而是因为你们已经认识了真理，又因为一切虚假都不是出于真理。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰二书 1:7; 约翰一书 4:3; 约翰一书 2:18"> 谁是说谎者呢？难道不是那否认耶稣是基督的吗？那否认父和子的，这个人就是敌基督的。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰一书 4:15; 约翰福音 8:19; 约翰福音 5:23"> 所有否认子的，就没有父；那承认子的，连父也有了。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约翰福音 14:23; 约翰福音 15:9–10; 约翰一书 4:13"> 你们应当使那从起初所听到的，住在你们里面。如果那从起初所听到的住在你们里面，你们就会住在子里面，也住在父里面。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 10:28; 提多书 3:7; 犹大书 1:21"> 这就是那应许，是他所应许我们的，就是永恒的生命。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得后书 2:1–3; 约翰二书 1:7; 使徒行传 20:29–30"> 我写给你们的这些，是关于迷惑你们之人的。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约翰福音 14:26; 约翰一书 2:20–21; 哥林多前书 2:13"> 至于你们，你们从那一位所领受的恩膏住在你们里面，这样你们就不需要人来教导你们。其实，就像他的恩膏在一切事上所教导你们的——是真实的，不是虚假的——又像他曾经所教导的，你们要住在他里面。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约翰一书 4:17; 马可福音 8:38; 约翰一书 3:2"> 如今，孩子们哪，你们当住在他里面，好使他显现的时候，我们可以坦然无惧，他来临的时候，我们可以在他面前不至于蒙羞。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 3:3–5; 约翰一书 3:7; 约翰一书 5:1"> 你们如果知道他是公义的，也就知道所有行义的人，都是由他所生的。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 1:12; 加拉太书 3:26; 哥林多后书 6:18"> 你们看，父所赐给我们的是何等的爱，为要使我们被称为“神的儿女”，而我们就是神的儿女<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本没有“而我们就是神的儿女”。">a</a></sup>。世人之所以不认识我们，是因为不认识父<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="父——原文直译“他”。">b</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比书 3:21; 歌罗西书 3:4; 哥林多前书 13:12"> 各位蒙爱的人哪，现在我们是神的儿女，将来会怎样，尚未显明。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附“但”。">c</a></sup>我们已经知道的是：基督<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="基督——原文直译“他”。">d</a></sup>显现的时候，我们就会像他，因为我们将看见他的本相。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 7:1; 约翰一书 2:6; 彼得后书 3:14"> 每一个对基督<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="基督——原文直译“他”。">e</a></sup>怀有这盼望的，都会使自己纯洁，正如基督<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="基督——原文直译“那一位”。">f</a></sup>是纯洁的。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰一书 5:17; 罗马书 3:20; 罗马书 4:15"> 凡是犯罪的，也是行恶<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="恶——原文直译“不法”。">g</a></sup>的；罪就是恶<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="恶——原文直译“不法”。">h</a></sup>。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 5:21; 希伯来书 9:28; 彼得前书 3:18"> 你们知道，基督<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="基督——原文直译“那一位”。">i</a></sup>曾经显现，是为了除去罪孽<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="罪孽——有古抄本作“我们的罪孽”。">j</a></sup>；在他里面并没有罪。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰三书 1:11; 约翰一书 2:4; 约翰一书 3:9"> 凡是住在基督<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="基督——原文直译“他”。">k</a></sup>里面的，就不继续犯罪；凡是继续犯罪的，就未曾看到他，也未曾认识他。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约翰一书 2:29; 彼得前书 1:15–16; 罗马书 2:13"> 孩子们哪，不要让任何人迷惑你们。行义的人是公义的，正如基督<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="基督——原文直译“那一位”。">l</a></sup>是公义的。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 2:14; 约翰福音 8:44; 歌罗西书 2:15"> 继续犯罪的人属于魔鬼，因为魔鬼从起初就一直犯罪。为此，神的儿子显现了，是为了废除魔鬼的作为。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 5:18; 彼得前书 1:23; 约翰福音 1:13"> 凡是由神所生的，不继续犯罪，因为神的种子住在他里面；他也不能继续犯罪，因为他是由神所生的。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 4:8; 约翰三书 1:11; 路加福音 6:35"> 从这一点，谁是神的儿女，谁是魔鬼的儿女就清清楚楚了。 爱的命令<br />凡是不行公义的，就不属于神；不爱自己弟兄的，也不属于神。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 15:12; 约翰二书 1:5; 约翰一书 4:7"> 因为你们从起初所听见的信息是这样的：我们要彼此相爱。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 11:4; 创世记 4:4–15; 箴言 29:27"> 不要像该隐，他属于那恶者，杀了自己的弟弟<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="弟弟——原文直译“兄弟”。">m</a></sup>。他为什么杀弟弟呢？因为他自己的行为是恶的，而他弟弟的行为是义的。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 15:18–19; 约翰福音 17:14; 路加福音 21:17"> 弟兄们，如果世界恨你们，不要感到惊奇。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 13:35; 约翰一书 5:2; 约翰一书 4:20–21"> 我们知道，因为我们爱弟兄，我们就已经出死入生了；那不爱弟兄的，就住在死亡中。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 5:21–22; 箴言 26:24–26; 启示录 21:8"> 凡是恨自己弟兄的，就是杀人的，而你们知道：凡是杀人的，就没有永恒的生命住在他里面。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰一书 4:9–11; 以弗所书 5:2; 约翰福音 13:34"> 我们从这一点就知道了爱：基督<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="基督——原文直译“那一位”。">n</a></sup>为我们舍弃了自己的生命，我们也应该为弟兄舍弃生命。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 13:16; 以赛亚书 58:7–10; 申命记 15:7–11"> 但如果有人拥有世界的财产，看见自己的弟兄有需要，却封闭情感，那么，属神的爱怎么能住在他里面呢？</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="雅各书 2:15–16; 罗马书 12:9; 彼得前书 1:22"> 孩子们哪，让我们不在语言或口头上相爱，而在行为和真理中相爱，</span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 10:22; 约翰一书 3:21; 希伯来书 6:10–11"> 从这一点我们就会知道我们属于真理。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 139:1–4; 耶利米书 17:10; 希伯来书 4:13"> 就算我们的心责备自己，我们在神面前也可以安心，因为神比我们的心更大，并且他知道一切。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约翰一书 2:28; 希伯来书 4:16; 哥林多后书 1:12"> 各位蒙爱的人哪，如果我们的心不责备我们，我们在神面前就可以坦然无惧，</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 15:7; 约翰福音 9:31; 约翰一书 5:14"> 这样，凡是我们所求的，就会从他得着；因为我们遵守他的命令，行他看为可喜悦的事。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 6:29; 约翰福音 13:34; 彼得前书 1:22"> 而神的命令是这样的：我们要信他儿子耶稣基督的名，并且照着他所赐给我们的命令彼此相爱。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 3:16; 约翰一书 4:15–16; 约翰一书 4:12–13"> 遵守神<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="神——原文直译“他”。">o</a></sup>命令的，就住在神<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="神——原文直译“他”。">p</a></sup>里面，神<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="神——原文直译“他”。">q</a></sup>也住在他里面；而且我们从这一点就知道神<sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="神——原文直译“他”。">r</a></sup>住在我们里面，是藉着他所赐给我们的圣灵。</span>
</div>
</div>

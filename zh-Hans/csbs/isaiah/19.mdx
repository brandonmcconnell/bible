<span className="v" id="v2" data-v="2" data-xref="士师记 7:22; 撒母耳记上 14:20; 马太福音 10:36"> <span className="pl pl-1">“我要激起埃及人敌对埃及人，</span><br /><span className="pl pl-1">各人攻击自己的兄弟，</span><br /><span className="pl pl-1">各人攻击自己的邻舍，</span><br /><span className="pl pl-1">城攻击城，国攻击国。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 8:19; 但以理书 2:2; 历代志上 10:13"> <span className="pl pl-1">埃及人必失魂落魄</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="埃及人必失魂落魄——原文直译“埃及人的灵必在自己里面被清空”。">b</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">我要使他们的计划混乱。</span><br /><span className="pl pl-1">他们必求问偶像、阴魂、招魂的和通灵的；</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 20:4; 耶利米书 46:26; 以西结书 29:19"> <span className="pl pl-1">我要把埃及交在严酷的主人手中，</span><br /><span className="pl pl-1">凶猛的君王必管辖他们。”</span><br /><span className="pl pl-1">这是主万军之耶和华的宣告。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="耶利米书 51:36; 以西结书 30:12; 撒迦利亚书 14:18"> <span className="pl pl-1">海里的水必枯干，</span><br /><span className="pl pl-1">大河必干涸枯竭，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 37:25; 出埃及记 7:18; 列王纪下 19:24"> <span className="pl pl-1">河道必发臭，</span><br /><span className="pl pl-1">埃及的河流必消减而干涸；</span><br /><span className="pl pl-1">芦苇和芦荻必衰残，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 32:20; 约珥书 1:17–18; 以赛亚书 23:3"> <span className="pl pl-1">尼罗河边、尼罗河口的蒲草</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="蒲草——或译作“不毛之地”。">c</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">以及沿着尼罗河所种的田都必枯竭，</span><br /><span className="pl pl-1">被风吹去，不复存在。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 47:10; 哈巴谷书 1:15; 民数记 11:5"> <span className="pl pl-1">渔夫必哀哭，</span><br /><span className="pl pl-1">尼罗河上所有垂钓的必悲恸，</span><br /><span className="pl pl-1">水面上撒网的也必沮丧。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 27:7; 箴言 7:16; 列王纪上 10:28"> <span className="pl pl-1">绩麻的和织白布的都必蒙羞，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="申命记 11:10; 出埃及记 7:19; 出埃及记 8:5"> <span className="pl pl-1">埃及的栋梁</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="栋梁——或译作“纺织的人”。">d</a></sup><br /><span className="pl pl-1">必被压碎，</span><br /><span className="pl pl-1">所有的雇工都必心里悲痛。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="民数记 13:22; 使徒行传 7:22; 列王纪上 4:30"> <span className="pl pl-1">琐安的首领们极其愚妄，</span><br /><span className="pl pl-1">法老最智慧的谋士们所出的谋略都是愚拙！</span><br /><span className="pl pl-1">你们怎么能对法老说</span><br /><span className="pl pl-1">“我是智慧人的子孙，</span><br /><span className="pl pl-1">是古代君王的后裔”？</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 1:20; 以赛亚书 14:24; 士师记 9:38"> <span className="pl pl-1">你的智慧人在哪里呢？</span><br /><span className="pl pl-1">让他们告诉你吧，</span><br /><span className="pl pl-1">让他们去明白万军之耶和华对埃及所策划的！</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 30:13; 耶利米书 2:16; 耶利米书 46:14"> <span className="pl pl-1">琐安的首领们愚昧，</span><br /><span className="pl pl-1">挪弗</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="挪弗——希腊语音译为“孟菲斯”。">e</a></sup><br /><span className="pl pl-1">的首领们被欺哄；</span><br /><span className="pl pl-1">埃及众支派中当房角石的，使埃及人迷失。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦后书 2:11; 列王纪上 22:20–23; 以西结书 14:7–9"> <span className="pl pl-1">耶和华在埃及中掺入了歪谬的灵，</span><br /><span className="pl pl-1">首领们就使埃及在一切所做的事上都迷失，</span><br /><span className="pl pl-1">好像醉酒的人呕吐时摇晃迷糊。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 9:14–15; 帖撒罗尼迦前书 4:11–12; 箴言 14:23"> <span className="pl pl-1">无论是头是尾，是棕枝是芦苇，</span><br /><span className="pl pl-1">都不能为埃及成就什么。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米书 51:30; 那鸿书 3:13; 以赛亚书 11:15"> 到那日，埃及人必像妇女一样，必因万军之耶和华挥手攻击他们而战兢惧怕。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 14:24; 但以理书 4:35; 以西结书 29:6–7"> 犹大地必使埃及恐惧——犹大地一被提起，任何人都会惧怕，因为这是万军之耶和华向埃及所策划的谋略。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="西番雅书 3:9; 撒迦利亚书 2:11; 以赛亚书 19:21"> 到那日，在埃及地必有五座城说迦南通用语<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="通用语——原文直译“嘴唇”；或译作“语言”。">f</a></sup>，并向万军之耶和华起誓，其中一座称为“太阳城<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="太阳城——或译作“灭亡城”。">g</a></sup>”。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="创世记 28:18; 约书亚记 22:10; 约书亚记 22:26"> 到那日，在埃及地当中必有一座为耶和华而立的祭坛；在埃及的边界附近必有一根为耶和华而立的石柱。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 50:15; 提多书 2:13; 以赛亚书 45:21–22"> 这都在埃及地作万军之耶和华的标记和见证。埃及人因受人压迫向耶和华呼求时，他就派遣一位拯救者、维护者来解救他们。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 11:9; 玛拉基书 1:11; 约翰福音 17:3"> 这样，耶和华就把自己向埃及显明。到那日，埃及人必认识耶和华，他们必用祭物和供物来敬拜他，向耶和华许愿、还愿。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 32:39; 希伯来书 12:11; 何西阿书 14:1"> 耶和华必击打埃及，击打后又医治。这样，埃及人就回转归向耶和华；而耶和华必应允他们的祈求，医治他们。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 11:16; 以弗所书 2:18–22; 以赛亚书 35:8–10"> 到那日，必有一条大道从埃及通往亚述；亚述人到埃及来，埃及人也到亚述去；埃及人与亚述人一同敬拜耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 65:8; 创世记 12:2; 加拉太书 3:14"> 到那日，以色列将与埃及、亚述一同，三者都成为地上的祝福；</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 29:23; 何西阿书 2:23; 罗马书 9:24–25"> 万军之耶和华祝福他们，说：“埃及我的百姓，亚述我手的作为，以色列我的继业，都是蒙福的！”</span>
</div>

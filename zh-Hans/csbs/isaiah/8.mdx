<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="何西阿书 1:3–9; 士师记 4:4; 以赛亚书 7:13–14"> 后来我与女先知<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="女先知——就是以赛亚的妻子。">c</a></sup>亲近，她就怀孕，生了一个儿子。耶和华对我说：“你要给他起名为玛黑珥·萨拉勒·哈施·罢斯，</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 9:11; 列王纪下 16:9; 申命记 1:39"> 因为在这孩子知道叫爸爸妈妈之前，大马士革的财富和撒玛利亚的掠物都要被搬到亚述王面前。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 7:10"> 耶和华又告诉我说：</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 9:7; 尼希米记 3:15; 以赛亚书 7:6"> <span className="pl pl-1">“因为这子民厌弃西罗亚缓慢的流水，</span><br /><span className="pl pl-1">却喜悦利汛和利玛利的儿子；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 17:12–13; 创世记 6:17; 以赛亚书 7:17"> <span className="pl pl-1">因此，看哪，主必使幼发拉底河强盛的大水，</span><br /><span className="pl pl-1">就是亚述王和他所有的威势，</span><br /><span className="pl pl-1">上涨淹没他们，</span><br /><span className="pl pl-1">又上涨淹没一切水道，</span><br /><span className="pl pl-1">漫过所有的河岸；</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 7:14; 以赛亚书 30:28; 马太福音 1:23"> <span className="pl pl-1">然后涌入犹大，</span><br /><span className="pl pl-1">漫溢泛滥，高达颈项！</span><br /><span className="pl pl-1">他展开的翅膀，遍满你广阔的土地，</span><br /><span className="pl pl-1">以马内利啊！</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="他展开的翅膀，遍满你广阔的土地，以马内利啊！——或译作“但神与我们同在，他展开的翅膀，遍满你广阔的土地。”">d</a></sup><br /><span className="pl pl-1">”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 14:5–6; 箴言 11:21; 诗篇 37:14–15"> <span className="pl pl-1">万民哪，你们必被打破</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="你们必被打破——或译作“你们联合吧”。">e</a></sup><br /><span className="pl pl-1">，必被击碎！</span><br /><span className="pl pl-1">远方的众人哪，当倾听！</span><br /><span className="pl pl-1">你们束腰吧，必定被击碎；</span><br /><span className="pl pl-1">你们束腰吧，必定被击碎！</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米哀歌 3:37; 罗马书 8:31; 约伯记 5:12"> <span className="pl pl-1">你们谋划吧，必定遭挫败；</span><br /><span className="pl pl-1">你们下令吧，必定不成立！</span><br /><span className="pl pl-1">因为神与我们同在。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="以西结书 3:14; 箴言 1:15; 耶利米书 15:19"> 耶和华把大能的手放在我身上对我说话<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="耶和华把大能的手放在我身上对我说话——原文直译“耶和华以大能的手对我说话”。">f</a></sup>，警诫我不要走这子民所走的路；他如此说：</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 3:14–15; 路加福音 21:9; 诗篇 53:5"> <span className="pl pl-1">“凡这子民所称为阴谋的，</span><br /><span className="pl pl-1">你们不要称为阴谋；</span><br /><span className="pl pl-1">他们所怕的，</span><br /><span className="pl pl-1">你们不要害怕，也不要畏惧。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:5; 以赛亚书 26:3–4; 启示录 15:4"> <span className="pl pl-1">万军之耶和华是你们要尊为圣的，</span><br /><span className="pl pl-1">他才是你们要怕的，也是你们要畏惧的。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 2:8; 罗马书 9:32–33; 以赛亚书 28:16"> <span className="pl pl-1">他必作圣所，</span><br /><span className="pl pl-1">而向以色列两家却作绊脚石和绊倒人的磐石，</span><br /><span className="pl pl-1">向耶路撒冷的居民作网罗和陷阱。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 21:44; 路加福音 20:17–18; 以赛亚书 28:13"> <span className="pl pl-1">许多人将在石头上绊跌、</span><br /><span className="pl pl-1">仆倒、破碎，</span><br /><span className="pl pl-1">陷入圈套被缠住。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="但以理书 12:4; 希伯来书 3:5; 马可福音 4:10–11"> <span className="pl pl-1">你要收起</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="收起——原文直译“绑起”。">g</a></sup><br /><span className="pl pl-1">诫命，</span><br /><span className="pl pl-1">在我的门徒中封住训诲。</span><br /></span>

</div>
<div className="bp">

<span className="v" id="v20" data-v="20" data-xref="彼得后书 1:19; 提摩太后书 3:15–17; 以赛亚书 30:8–11"> 当求问神的<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="神的——辅助词语。">h</a></sup>训诲和诫命！如果他们不按照这准则说话，他们就没有曙光。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 9:20; 箴言 19:3; 耶利米哀歌 4:4–5"> 他们必经过这地，遭困苦，受饥饿。他们饥饿的时候就发怒，仰面朝天，诅咒自己的君王和自己的神；</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 5:30; 马太福音 22:13; 耶利米书 13:16"> 他们向大地观看，看哪，尽是患难、黑暗、幽暗痛苦！他们必被赶入漆黑之中！</span>

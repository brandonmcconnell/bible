<span className="v" id="v1" data-v="1" data-xref="列王纪下 19:1–37; 以斯拉记 9:5; 以赛亚书 36:22–38"> 希西加王听了就撕裂衣服，披上麻布，进入耶和华的殿。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 1:1; 列王纪下 18:18; 以赛亚书 36:3"> 他派遣宫廷总管以利亚敬、书记舍伯纳和祭司中年长的，个个披上麻布，到亚摩斯的儿子先知以赛亚那里。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 66:9; 何西阿书 13:13; 以赛亚书 26:17–18"> 他们对他说：“希西加如此说：‘今天是一个患难、责罚、耻辱的日子；因为婴孩已经临盆，我们却没有力气生下来。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 1:9; 以赛亚书 36:20; 以赛亚书 10:22"> 将军的主人亚述王派他来辱骂永生的神，或许你的神耶和华听见了他的话，就会斥责所听见的那些话。因此，求你为幸存的余剩之民献上祷告。’”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 当希西加王的臣仆来到以赛亚那里时，</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 7:4; 以赛亚书 35:4; 马可福音 5:36"> 以赛亚对他们说：“你们要这样告诉你们的主人：‘耶和华如此说：你不要因为听见亚述王的仆人们亵渎我的话而害怕。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 31:8–9; 历代志下 32:21; 以赛亚书 33:10–12"> 看哪！我要把一个灵放入亚述王里面，让他一听见传来的风声就返回本土；我必使他在那里倒在刀下。’”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约书亚记 10:29; 民数记 33:20–21; 列王纪下 19:8–9"> 将军听到亚述王已拔营离开拉吉，就撤退了，与正在攻打立拿的亚述王会合。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 18:1; 以赛亚书 20:5; 以赛亚书 37:7"> 亚述王听到了有关库实王特哈加出来要与自己争战的消息。他一听到，就派遣使者们到希西加那里，并吩咐使者们：</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 36:15; 列王纪下 18:5; 马太福音 27:43"> “你们要对犹大王希西加这样说：‘不要让你所依靠的神欺哄你，说：耶路撒冷必不落入亚述王的手中。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 36:18–20; 列王纪下 18:33–35; 以赛亚书 14:17"> 看哪！你必定听说过亚述列王向各国所行的，就是把它们灭绝净尽；难道只有你能得解救吗？</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 11:31; 列王纪下 17:6; 列王纪下 18:11"> 我祖先所毁灭的，有歌散、哈兰和利色，还有在提拉撒的伊甸子孙，那些国的神明解救他们了吗？</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 19:13; 列王纪下 17:24; 以赛亚书 36:19"> 哈马的王、阿尔帕的王，拉伊尔、西法瓦音<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="拉伊尔、西法瓦音——传统译法作“西法瓦音城”。">a</a></sup>、希拿、伊瓦的众王，如今都在哪里呢？’”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王纪下 19:14; 诗篇 123:1–4; 约珥书 2:17–20"> 希西加从使者们手里接过书信，读完了，就上耶和华的殿，在耶和华面前展开书信。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 7:8–9; 但以理书 9:3–4; 雅各书 5:13"> 希西加向耶和华祷告，说：</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 25:22; 诗篇 99:1; 诗篇 86:10"> “坐在基路伯之上的万军之耶和华，以色列的神哪！你——唯独你是地上万国的神，是你造了诸天和大地。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 6:40; 诗篇 17:6; 以赛亚书 37:4"> 耶和华啊，求你侧耳听！耶和华啊，求你睁眼看！听听西纳基立派人来辱骂永生神的一切话！</span>
<span className="v" id="v18" data-v="18" data-xref="那鸿书 2:11–12; 列王纪下 15:29; 列王纪下 17:6"> 耶和华啊，亚述列王确实使各国和它们的国土荒废，</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 44:9–10; 耶利米书 10:11; 何西阿书 8:6"> 又把它们的神像扔进火中；那些神像之所以被灭绝，是因为它们不是神，只不过是人手所造的，是用木头、石头造的！</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 46:10; 列王纪上 18:36–37; 诗篇 83:17–18"> 耶和华我们的神哪，现在求你拯救我们脱离亚述王的手，使地上万国都知道，你——唯独你是耶和华<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="你是耶和华——死海古卷作“耶和华是神”；参《列王纪下》19:19。">b</a></sup>！”</span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 58:9; 以赛亚书 38:3–6; 使徒行传 4:31"> 亚摩斯的儿子以赛亚就派人到希西加那里，说：“以色列的神耶和华如此说：‘你为亚述王西纳基立的事向我祷告，因此，</span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 16:4; 耶利米哀歌 2:13; 以赛亚书 1:8"> 以下是耶和华针对西纳基立说的话：<br /><span className="pl pl-1">少女锡安藐视你、嘲笑你，</span><br /><span className="pl pl-1">女子耶路撒冷在你背后摇头。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 39:7; 但以理书 5:20–23; 以赛亚书 17:7"> <span className="pl pl-1">你辱骂谁、亵渎谁呢？</span><br /><span className="pl pl-1">你扬起声音、高举眼目是针对谁呢？</span><br /><span className="pl pl-1">是针对以色列的圣者！</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 14:8; 以赛亚书 10:18; 出埃及记 15:9"> <span className="pl pl-1">你藉着你的臣仆辱骂主</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="主——有古抄本作“耶和华”；马索拉文本作“我主”；参《列王纪下》19:23。">c</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">你又说：我带着众多的战车，</span><br /><span className="pl pl-1">上到群山的高峰和黎巴嫩的极深之处；</span><br /><span className="pl pl-1">我砍伐黎巴嫩最高的香柏树和最好的松树，</span><br /><span className="pl pl-1">来到它的极高之处和最茂密的森林；</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 20:10; 以赛亚书 36:12; 列王纪下 19:23–24"> <span className="pl pl-1">我挖井喝了水</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="我挖井喝了水——死海古卷作“我挖井喝了外族人的水”。">d</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">我的脚掌踏干了埃及一切的河流。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 4:27–28; 使徒行传 2:23; 彼得前书 2:8"> <span className="pl pl-1">我从远古以来所立的，</span><br /><span className="pl pl-1">在太初的日子所定的，</span><br /><span className="pl pl-1">难道你没有听过吗？</span><br /><span className="pl pl-1">现在我使它应验了，</span><br /><span className="pl pl-1">就是让你把坚固的城变为荒废的石堆——</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 129:6; 诗篇 37:2; 彼得前书 1:24"> <span className="pl pl-1">那时城中的居民软弱无力，惊惶羞愧，</span><br /><span className="pl pl-1">像田间蔬草、青绿嫩草，</span><br /><span className="pl pl-1">像被东风吹焦的屋顶上的草</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="像被东风吹焦的屋顶上的草——依据死海古卷；马索拉文本作“像屋顶上的草、没有长成的田园”。">e</a></sup><br /><span className="pl pl-1">。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="启示录 2:13; 诗篇 139:1–11; 耶利米书 23:23–24"> <span className="pl pl-1">你或坐或出或入</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="你或坐或出或入——死海古卷作“你起你坐，你出你入”。">f</a></sup><br /><span className="pl pl-1">，我都知道；</span><br /><span className="pl pl-1">我也知道你对我发怒。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 38:4; 以赛亚书 30:28; 以赛亚书 37:34"> <span className="pl pl-1">因为你对我发怒，</span><br /><span className="pl pl-1">你的骄奢安逸上达我的耳中，</span><br /><span className="pl pl-1">所以我要把钩子放进你的鼻孔，</span><br /><span className="pl pl-1">把嚼环放入你的嘴里，</span><br /><span className="pl pl-1">我必使你从原路返回。</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="列王纪下 19:29; 利未记 25:4–5; 列王纪上 13:3–5"> “‘希西加啊，以下是给你的征兆：今年你们会吃自生的，第二年你们会吃自长的，而第三年你们将播种、收割，栽种葡萄园，吃园中的果实。</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 27:6; 列王纪下 19:30–31; 诗篇 80:9"> 犹大家残留的幸存者将再次往下扎根，向上结果；</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 9:7; 列王纪下 19:31; 以赛亚书 59:17"> 必有余剩之民从耶路撒冷而出，必有幸存者从锡安山而来。万军之耶和华的热心必成就这事。’</span>
</div>
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 17:12; 以赛亚书 10:32–34; 以赛亚书 17:14"> “因此，耶和华论到亚述王如此说：<br /><span className="pl pl-1">‘他必不进入这城，</span><br /><span className="pl pl-1">也不在这里射箭；</span><br /><span className="pl pl-1">他必不拿着盾牌兵临城下，</span><br /><span className="pl pl-1">也不筑起土垒攻城；</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="以赛亚书 37:29; 箴言 21:30"> <span className="pl pl-1">他必从原路返回，</span><br /><span className="pl pl-1">也不进入这城。</span><br /><span className="pl pl-1">这是耶和华的宣告。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="列王纪下 20:6; 以赛亚书 38:6; 以赛亚书 31:5"> <span className="pl pl-1">我必为自己的缘故和我仆人大卫的缘故，</span><br /><span className="pl pl-1">保护拯救这城。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以赛亚书 10:12; 列王纪下 19:35; 以赛亚书 10:33–34"> 于是耶和华的使者出去，在亚述的营中击杀了十八万五千人；清早人们起来，看哪，所见的都是死尸！</span>
<span className="v" id="v37" data-v="37" data-xref="约拿书 1:2; 约拿书 3:3; 创世记 10:11–12"> 亚述王西纳基立就拔营回去，住在尼尼微。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="创世记 8:4; 耶利米书 51:27; 以斯拉记 4:2"> 有一天，西纳基立在自己的神尼斯洛的庙里下拜，他的儿子亚得米勒和沙利色用刀杀了他，然后逃到亚拉腊地。他的儿子以撒哈顿接替他作王。</span>

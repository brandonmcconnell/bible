<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 38:1–8; 历代志下 32:24; 列王纪下 20:1–11"> 在那些日子，希西加患病快要死了。亚摩斯的儿子先知以赛亚来到他那里，对他说：“耶和华如此说：‘你要安排好你的家事，因为你将要死，不能存活了。’”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="马太福音 6:6; 诗篇 91:15; 列王纪上 8:30"> 希西加就转脸对着墙，向耶和华祷告，</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 5:7; 诗篇 18:20–27; 希伯来书 6:10"> 说：“哦，耶和华啊，求你记念我在你面前怎样以诚实和完全的心行事，又做你眼中看为善的事！”然后，希西加就痛哭起来。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 那时，耶和华的话语临到以赛亚，说：</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 34:5–6; 约翰一书 5:14–15; 启示录 7:17"> “你去告诉希西加：‘你先祖大卫的神耶和华如此说：我听到了你的祷告，看见了你的眼泪。看哪！我必在你的寿数上增添十五年。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 37:35; 以赛亚书 31:4–5; 以赛亚书 12:6"> 我必解救你和这城脱离亚述王的手；我必保护这城。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 6:37–39; 以赛亚书 37:30; 以赛亚书 7:11–14"> 以下是我<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我——辅助词语；本节下同。">a</a></sup>耶和华给你的征兆来证明我耶和华必成就所说的这事：</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪下 20:9–11; 约书亚记 10:12–14; 马太福音 16:1"> 看哪！我要使亚哈斯的日晷上前进的日影向后退十个刻度。’”于是日晷上前进的日影，果然向后退了十个刻度。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="诗篇 18:1; 出埃及记 15:1–21; 约伯记 5:18"> 犹大王希西加患病痊愈后，写了一首诗：</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 102:24; 哥林多后书 1:9; 诗篇 107:18"> <span className="pl pl-1">“我曾说：我如日中天就要进入阴间之门；</span><br /><span className="pl pl-1">我余剩的岁月竟被剥夺！</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 27:13; 诗篇 116:8–9; 诗篇 31:22"> <span className="pl pl-1">我曾说：我必不得见耶和华，</span><br /><span className="pl pl-1">必不得见在活人之地的耶和华！</span><br /><span className="pl pl-1">我再也不会见到世上居民中的任何人。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 73:14; 哥林多后书 5:1; 希伯来书 1:12"> <span className="pl pl-1">我的住处好像牧人的帐篷，被拔出、挪走；</span><br /><span className="pl pl-1">我卷起我的性命，像织布的卷布那样；</span><br /><span className="pl pl-1">他把我从织布机上剪断，</span><br /><span className="pl pl-1">一日之间，他</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="他——原文直译“你”。">b</a></sup><br /><span className="pl pl-1">使我丧命。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 51:8; 但以理书 6:24; 诗篇 50:22"> <span className="pl pl-1">我不断呼救</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="我不断呼救——或译作“我使自己平稳”。">c</a></sup><br /><span className="pl pl-1">，直到早晨；</span><br /><span className="pl pl-1">他像狮子折断我所有的骨头，</span><br /><span className="pl pl-1">一日之间，他</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="他——原文直译“你”。">d</a></sup><br /><span className="pl pl-1">使我丧命。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 59:11; 诗篇 69:3; 诗篇 123:1–4"> <span className="pl pl-1">我像燕子呢喃，像白鹤啼叫，</span><br /><span className="pl pl-1">又像鸽子哀鸣。</span><br /><span className="pl pl-1">我的眼睛因仰望高处而衰弱；</span><br /><span className="pl pl-1">主啊！我受欺压，</span><br /><span className="pl pl-1">求你作我的保障。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="列王纪上 21:27; 约伯记 7:11; 约伯记 10:1"> <span className="pl pl-1">我还能说什么呢？</span><br /><span className="pl pl-1">他对我说过的，他已亲自做了。</span><br /><span className="pl pl-1">我因心灵愁苦，</span><br /><span className="pl pl-1">要谨慎地</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="谨慎地——或译作“慢慢地”。">e</a></sup><br /><span className="pl pl-1">度过我所有的年日。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 12:10–11; 哥林多前书 11:32; 诗篇 119:25"> <span className="pl pl-1">主啊！人存活靠着这些；</span><br /><span className="pl pl-1">我灵魂的生命也在所有这些之中。</span><br /><span className="pl pl-1">求你使我复原，使我存活。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 43:25; 弥迦书 7:18–19; 约拿书 2:6"> <span className="pl pl-1">看哪！我受尽苦痛，是对我有益的；</span><br /><span className="pl pl-1">是你在爱中保全我的灵魂脱离灭亡之坑，</span><br /><span className="pl pl-1">是你把我的一切罪都抛在你的背后。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="传道书 9:10; 诗篇 30:9; 诗篇 6:5"> <span className="pl pl-1">阴间不会称颂你，死亡不会赞美你，</span><br /><span className="pl pl-1">下阴坑的人也不会盼望你的信实；</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="申命记 6:7; 诗篇 119:175; 诗篇 78:3–6"> <span className="pl pl-1">唯独活人——活着的人才会称颂你，像我今日这样；</span><br /><span className="pl pl-1">作父亲的才会使儿女认识你的信实。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 116:2; 诗篇 150:4; 诗篇 145:2"> <span className="pl pl-1">耶和华必拯救我；</span><br /><span className="pl pl-1">我们一生一世都要在耶和华的殿中，</span><br /><span className="pl pl-1">弹奏丝弦的乐器。”</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王纪下 20:7–8; 马可福音 7:33; 约翰福音 9:6"> ——而此前，以赛亚曾说：“拿一块无花果饼来，敷在疮上，王就必痊愈！”</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 118:18–19; 列王纪下 20:8; 约翰福音 5:14"> 希西加却问：“有什么征兆来证明我会上耶和华的殿呢？”</span>
</div>
</div>

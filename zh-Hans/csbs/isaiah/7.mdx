<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 15:37; 列王纪下 16:1; 以赛亚书 1:1"> 乌西雅的孙子、约坦的儿子犹大王亚哈斯年间，亚兰王利汛会同利玛利的儿子以色列王比加上来攻打耶路撒冷，却不能攻下。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 8:12; 以赛亚书 7:13; 以赛亚书 9:9"> 有人向大卫家报告说：“亚兰已经与以法莲结盟了。”王的心和他子民的心就摇动，好像林中的树随风摇动。</span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="列王纪下 18:17; 以赛亚书 36:2; 罗马书 9:27"> 耶和华对以赛亚说：“现在你和你的儿子施亚·雅实布出去，在上池的沟渠尽头，通往漂布场的大道上迎见亚哈斯，</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 35:4; 耶利米哀歌 3:26; 申命记 20:3"> 对他说：‘你要谨慎，保持镇静，不要因亚兰王利汛和利玛利的儿子发烈怒而害怕，也不要因这两个冒烟的火把残头而心里胆怯。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 83:3–4; 撒迦利亚书 1:15; 诗篇 2:2"> 尽管亚兰王和以法莲王利玛利的儿子策划恶事要害你，说：</span>
<span className="v" id="v6" data-v="6"> “让我们上去攻击犹大，恐吓它，攻破它归我们，并在其中立塔比勒的儿子为王”，</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 8:10; 耶利米哀歌 3:37; 以赛亚书 46:10–11"> 但主耶和华如此说：<br /><span className="pl pl-1">这事必立不住，也不会得逞，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 17:1–3; 创世记 14:15; 撒母耳记下 8:6"> <span className="pl pl-1">因为亚兰之首不过是大马士革，</span><br /><span className="pl pl-1">大马士革之首不过是利汛；</span><br /><span className="pl pl-1">至于以法莲，六十五年之内必被击碎，</span><br /><span className="pl pl-1">不再成为一个民族；</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 11:6; 罗马书 11:20; 历代志下 20:20"> <span className="pl pl-1">以法莲之首不过是撒玛利亚，</span><br /><span className="pl pl-1">撒玛利亚之首不过是利玛利的儿子。</span><br /><span className="pl pl-1">你们如果不相信，</span><br /><span className="pl pl-1">就一定不能坚立。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 8:5; 以赛亚书 1:5; 以赛亚书 10:20"> 耶和华又吩咐亚哈斯说：</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 37:30; 以赛亚书 38:7–8; 以赛亚书 38:22"> “你为自己向你的神耶和华求一个征兆吧——或往深求，深如阴间，或往高求，高如上天。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西结书 33:31; 历代志下 28:22; 玛拉基书 3:15"> 但亚哈斯说：“我不求，我不试探耶和华。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 43:24; 以赛亚书 63:10; 以西结书 34:18"> 于是以赛亚说：“大卫家啊，你们要听！难道你们使人厌倦还不够，又要使我的神厌倦吗？</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 1:23; 以赛亚书 9:6; 路加福音 1:31"> 因此主要亲自给你们一个征兆：看哪！必有童贞女怀孕，她要生一个儿子，并称他的名为以马内利。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 7:22; 阿摩司书 5:15; 马太福音 3:4"> 到他懂得弃恶择善的时候，他必吃乳酪与蜂蜜。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 8:4; 申命记 1:39; 以赛亚书 9:11"> 因为在这孩子知道弃恶择善之前，你所忧心的那两个王的土地必被遗弃。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 8:7–8; 以赛亚书 10:5–6; 历代志下 28:19–21"> 耶和华必使亚述王攻击<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="攻击——辅助词语。">a</a></sup>的日子临到你、你的子民和你的父家；这是自从以法莲脱离犹大以来未曾有过的日子。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 5:26; 约书亚记 24:12; 申命记 1:44"> <span className="pl pl-1">“到那日，</span><br /><span className="pl pl-1">耶和华必发出哨声，</span><br /><span className="pl pl-1">召来埃及江河源头的苍蝇和亚述地的刺蜂。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 2:19; 耶利米书 16:16; 以赛亚书 2:21"> <span className="pl pl-1">它们全都会飞来，</span><br /><span className="pl pl-1">停落在深谷中、岩石缝里、</span><br /><span className="pl pl-1">所有的荆棘丛中、所有的草场上。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 8:7; 以西结书 29:18; 以赛亚书 10:15"> <span className="pl pl-1">“到那日，</span><br /><span className="pl pl-1">主必雇用幼发拉底河对岸的剃刀——亚述王，</span><br /><span className="pl pl-1">剃光你们的头发和脚毛，</span><br /><span className="pl pl-1">也刮掉你们的胡须。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 5:17; 耶利米书 39:10; 以赛亚书 37:30"> <span className="pl pl-1">“到那日，</span><br /><span className="pl pl-1">一个人只能养活一头小母牛和两只母羊。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 7:15; 马太福音 3:4; 撒母耳记下 17:29"> <span className="pl pl-1">因为产的奶很多，他就以乳酪为食；</span><br /><span className="pl pl-1">这地上所有剩下的人都将以乳酪和蜂蜜为食。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 5:6; 雅歌 8:11–12; 马太福音 21:33"> <span className="pl pl-1">“到那日，</span><br /><span className="pl pl-1">所有种过一千棵葡萄树、</span><br /><span className="pl pl-1">值一千锭银子的地方，</span><br /><span className="pl pl-1">都必成为荆棘和蒺藜之地。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="创世记 27:3"> <span className="pl pl-1">人到那里去，就必带弓和箭，</span><br /><span className="pl pl-1">因为遍地都是荆棘和蒺藜。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 7:21–22; 以赛亚书 13:20–22; 以赛亚书 5:17"> <span className="pl pl-1">所有被锄头翻耕过的山地，</span><br /><span className="pl pl-1">你都不会上去，</span><br /><span className="pl pl-1">因为你惧怕荆棘和蒺藜；</span><br /><span className="pl pl-1">那里必成为放牛之地、羊群践踏之处。”</span></span>
</div>

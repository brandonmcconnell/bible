<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="ISA" data-book-slug="isaiah" data-book-name="以赛亚书" data-chapter="36" data-verses="22">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 32:1; 列王纪下 18:13; 列王纪下 18:17"> 希西加王十四年，亚述王西纳基立上来攻击犹大所有的坚固城，并攻取了它们。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 32:9–23; 以赛亚书 7:3; 列王纪下 18:17–37"> 亚述王派遣将军<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="将军——音译作“拉伯沙基”；是亚述高级官员的头衔。">a</a></sup>率领大军，从拉吉往耶路撒冷，到希西加王那里去。将军站在上池的沟渠旁，通往漂布场的大道上。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 8:16–17; 以赛亚书 22:15–21; 撒母耳记下 20:24–25"> 那时，希勒加的儿子宫廷总管以利亚敬，书记舍伯纳，以及亚萨的儿子史官约亚，都出来到他那里。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 18:19–37; 犹大书 1:16; 箴言 16:18"> 将军对他们说：<br />“请你们告诉希西加，大王亚述王如此说：你所依靠的算什么依靠？</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 18:7; 耶利米书 52:3; 箴言 21:30–31"> 你<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="你——马索拉文本作“我”。">b</a></sup>说你有作战的谋略和实力，但那只是嘴上的空谈！你现在依靠谁，竟敢背叛我！</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 29:6–7; 耶利米书 37:5–8; 列王纪下 18:21"> 看哪！你依靠的埃及是压裂的芦苇杖；如果有人倚靠它，它就会扎入那人的手掌，把手掌刺透。埃及王法老对所有依靠他的人都是这样。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 18:4–5; 诗篇 42:10–11; 诗篇 42:5"> 你也许会对我说‘我们依靠耶和华我们的神’，但希西加除掉了这神的高坛和祭坛，却还对犹大和耶路撒冷的人说‘你们当在这祭坛前敬拜！’难道耶和华不就是这神吗？</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 17:40–43; 列王纪上 20:10; 尼希米记 4:2–5"> “现在你可以与我主亚述王下一个赌注：你那边如果能给出相应的骑士，我就给你两千匹马；</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 10:8; 以赛亚书 30:16–17; 以赛亚书 36:6"> 如果不能，你怎能击退我主的臣仆中至小的一个军官呢？你竟敢依靠埃及的战车和马兵！</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 18:25; 以赛亚书 10:5–7; 列王纪上 13:18"> 现在，我上来攻打这地，要把它毁灭，难道不是出于耶和华吗？是耶和华对我说‘你要上去攻打这地，把它毁灭！’”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以斯拉记 4:7; 但以理书 2:4; 列王纪下 18:26–27"> 以利亚敬、舍伯纳、约亚对将军说：“求你用亚兰语对仆人们说话，因为我们听得懂；不要用犹大话对我们说话，免得达到城墙上众人的耳中。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王纪下 18:27; 利未记 26:29; 耶利米哀歌 4:9–10"> 将军却说：“难道我的主人派我来，只对你和你的主人说这些话吗？不也对那些坐在城墙上，将与你们一同吃自己粪、喝自己尿的人说话吗？”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志下 32:18; 诗篇 73:8–9; 列王纪下 18:28–32"> 然后，将军站着用犹大话大声呼喊，说：<br />“你们要听大王亚述王的话！</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦后书 2:4; 启示录 13:5–6; 但以理书 6:20"> 王如此说：‘不要让希西加欺哄你们，因为他不能解救你们；</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 37:23–24; 马太福音 27:43; 诗篇 71:9–11"> 也不要让希西加说服你们依靠耶和华，因为他会说：耶和华必定解救我们，这城必不落入亚述王手中。’</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪上 4:25; 撒迦利亚书 3:10; 弥迦书 4:4"> “你们不要听希西加的话，因为亚述王如此说：‘你们要与我和好，出来向我投降<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="出来向我投降——原文直译“出来到我这里”。">c</a></sup>，各人就可以吃自己葡萄树和无花果树的果实，喝自己水窖里的水；</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 18:32; 申命记 8:7–9; 约伯记 20:17"> 以后我会来，把你们带到一个与你们本土一样的地方，一个有五谷和新酒的地方，一个有粮食和葡萄园的地方。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 37:17–18; 以赛亚书 36:15; 以赛亚书 37:10"> 不要让希西加误导你们，说：耶和华必解救我们。列国的神明中，有哪一个曾解救自己的国土脱离亚述王的手呢？</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 10:9–11; 耶利米书 49:23; 撒母耳记下 8:9"> 哈马和阿尔帕的神在哪里呢？西法瓦音的神在哪里呢？难道他们曾解救撒玛利亚脱离我的手吗？</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 50:21; 历代志下 32:19; 以赛亚书 37:23–29"> 这些国所有的神明中，有哪一个曾解救自己的国土脱离我的手呢？难道耶和华会解救耶路撒冷脱离我的手吗？’”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="箴言 26:4; 诗篇 38:13–15; 马太福音 7:6"> 众人都默不作声，一句也不回应，因为希西加王有令说：“不许回应他。”</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 36:3; 以赛亚书 33:7; 马太福音 26:65"> 希勒加的儿子宫廷总管以利亚敬，书记舍伯纳，以及亚萨的儿子史官约亚，都撕裂衣服来到希西加那里，把将军的话告诉了他。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 2:1; 历代志上 6:4–14; 以斯拉记 7:21"> 这些事以后，波斯王亚达薛西在位时，以斯拉回来了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="回来了——辅助词语。">a</a></sup>——他是西莱雅的儿子，西莱雅是亚撒利雅的儿子，亚撒利雅是希勒加的儿子，</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 2:35; 撒母耳记下 8:17"> 希勒加是沙勒姆的儿子，沙勒姆是撒督的儿子，撒督是亚希突的儿子，</span>
<span className="v" id="v3" data-v="3"> 亚希突是亚玛利雅的儿子，亚玛利雅是亚撒利雅的儿子，亚撒利雅是米拉约的儿子，</span>
<span className="v" id="v4" data-v="4"> 米拉约是西拉希雅的儿子，西拉希雅是乌基的儿子，乌基是布其的儿子，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 6:25; 历代志下 26:20; 历代志上 6:4"> 布其是亚比书的儿子，亚比书是非尼哈的儿子，非尼哈是以利亚撒的儿子，以利亚撒是大祭司亚伦的儿子。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯拉记 8:22; 以斯拉记 7:28; 以斯拉记 8:31"> 这以斯拉从巴比伦上来，他是经文士，精通以色列的神耶和华所赐下的摩西律法。王准许了他所求的一切，因为他的神耶和华的手帮助他。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 8:1–20; 历代志上 6:31–48; 历代志上 9:17–27"> 这样，在亚达薛西王第七年，一些以色列人、祭司、利未人、歌手、门卫和圣殿仆役，上耶路撒冷去。</span>
<span className="v" id="v8" data-v="8"> 亚达薛西<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="亚达薛西——辅助词语。">b</a></sup>王第七年的五月，以斯拉来到了耶路撒冷。</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉记 7:6; 尼希米记 2:8; 尼希米记 2:18"> 他在一月一日从巴比伦起程上行，五月一日就来到耶路撒冷，是因他的神施恩的手帮助他。</span>
<span className="v" id="v10" data-v="10" data-xref="玛拉基书 2:7; 提摩太后书 4:2; 马太福音 7:24"> 因为以斯拉立定了心志，要研读并遵行耶和华的律法，并在以色列人中教导这些律例和法规。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以斯拉记 5:6; 以斯拉记 7:6; 马太福音 23:2"> 亚达薛西王将公文的副本交给了以斯拉，他是祭司，是经文士，精通耶和华的诫命和赐给以色列的律例。公文副本如下：</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="但以理书 2:37; 以西结书 26:7; 以斯拉记 4:17"> “王中之王亚达薛西致祭司以斯拉，那精通<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="精通——辅助词语。">c</a></sup>天上之神法令的经文士……<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="省略号——原文语义不明；或译作“愿你平安”。">d</a></sup><br />现在</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 6:1; 诗篇 148:6; 历代志下 30:5"> 我下令：在我国中的以色列民以及他们的祭司和利未人，凡是甘愿奉献自己去耶路撒冷的，都可以与你一起去。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖记 1:14; 以斯拉记 7:25–26; 以斯拉记 7:28"> 既然你从王和七位内阁大臣面前受了差派，照着你的神交托给你的法令去调查犹大和耶路撒冷的情况，</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 135:21; 历代志下 6:2; 以斯拉记 6:12"> 并且带去王和内阁大臣们甘愿奉献给住在耶路撒冷的以色列之神的金银，</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 29:6; 以斯拉记 1:4; 历代志上 29:9"> 还有你在巴比伦全省得到的一切金银，以及民众和祭司们甘愿奉献给耶路撒冷他们神殿宇的奉献物，</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 12:5–11; 民数记 15:4–13; 以斯拉记 6:9–10"> 那么，这些银子要专用于购买公牛、公绵羊、公羊羔，以及同献的素祭和酒祭，你要在耶路撒冷你们神殿的祭坛上把它们献上。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 22:7; 以弗所书 5:17; 列王纪下 12:15"> 其余的金银，你和你的兄弟们看怎样好，就怎样用，要照着你们神的旨意去做。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 3:17; 以斯拉记 8:33–34; 历代志下 32:19"> 至于那些交给你，在你神的殿中事奉用的器皿，你要完全交付在耶路撒冷的神面前。</span>
<span className="v" id="v20" data-v="20" data-xref="以斯拉记 6:4; 以斯拉记 6:8–18"> 你神的殿由你负责的其余需用，你可以从王的府库里支取。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以斯拉记 4:16; 以斯拉记 7:6; 以斯拉记 7:10–13"> 我亚达薛西王向幼发拉底河对岸地区所有的司库官下令：那精通<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="精通——辅助词语。">e</a></sup>天上之神法令的经文士，祭司以斯拉，他向你们要求的一切，你们都要认真照办；</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 16:6–7; 利未记 2:13; 以西结书 45:14"> 银子上限一百他连得<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一百他连得——相当于3.4公吨。1他连得=34.2公斤。">f</a></sup>，小麦上限一百柯珥<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="一百柯珥——相当于22,000公升。1柯珥=220公升。">g</a></sup>，酒上限一百罢特<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="一百罢特——相当于2,200公升；下同。1罢特=22公升。">h</a></sup>，油上限一百罢特，盐不用记数。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 119:4; 以斯拉记 7:18; 以斯拉记 6:10–12"> 凡是天上之神所命令的，都要为天上之神的殿尽心执行。何必让震怒临到王和王子们的国土呢？</span>
<span className="v" id="v24" data-v="24" data-xref="以斯拉记 7:7; 以斯拉记 4:13; 以斯拉记 2:36–55"> 你们还要知道：对于所有的祭司、利未人、歌手、门卫、圣殿仆役，以及在神的这殿宇事奉的人，你们都无权向他们征收税捐、贡物和路税。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以斯拉记 7:10; 申命记 16:18; 雅各书 1:5"> 至于你以斯拉，你要照着你的神赐予你的智慧，指派那些明白你神的法令的人作司法官和审判官，让他们治理幼发拉底河对岸地区的所有百姓；你们也要教导那些不明白法令的人。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯拉记 6:11; 申命记 13:1–18; 利未记 20:1–27"> 任何人不遵行你神的法令和王的法令，他就要受到严厉的审判：或处死，或放逐，或没收财产，或囚禁。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以斯拉记 6:22; 启示录 17:17; 以赛亚书 60:13"> 我们祖先的神耶和华是当受颂赞的！他把这样的意念放在王的心中，为要使耶路撒冷耶和华的圣殿得荣耀。</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太后书 4:17–18; 以斯拉记 5:5; 创世记 32:28"> 他还在王和王的内阁大臣面前，以及王的所有高官面前向我施慈爱。这样，因着我神耶和华的手帮助我，我就坚强，从以色列人中招聚首领们，与我一同上去。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯拉记 7:7; 以斯拉记 2:62; 历代志上 9:1"> 亚达薛西王在位时，与我一同从巴比伦上来的人，他们各父系的首领和家谱记录如下：</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="历代志上 3:22; 历代志上 3:1; 历代志上 6:3–15"> 非尼哈的子孙，有革顺；<br />以塔玛尔的子孙，有但以理；<br />大卫的子孙，有哈突施，</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 2:3; 尼希米记 10:14; 尼希米记 7:8"> 属于谢喀尼亚的后裔；<br />帕罗示的子孙，有撒迦利亚，以及与他一起记录在家谱中的男子一百五十人；</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以斯拉记 2:6; 尼希米记 10:14; 尼希米记 7:11"> 帕哈摩押的子孙，有西拉希雅的儿子以利约奈，以及与他一起的男子两百人；</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 萨图<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="萨图——依据七十士译本；马索拉文本此处缺失名字。">a</a></sup>的子孙，有雅哈希的儿子谢喀尼亚，以及与他一起的男子三百人；</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以斯拉记 2:15; 尼希米记 10:16; 尼希米记 7:20"> 阿丁的子孙，有约拿单的儿子伊别德，以及与他一起的男子五十人；</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 2:31; 尼希米记 7:34; 以斯拉记 2:7"> 以拦的子孙，有亚塔利雅的儿子耶赛亚，以及与他一起的男子七十人；</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="尼希米记 11:4; 以斯拉记 2:4; 尼希米记 7:9"> 示法提雅的子孙，有米迦勒的儿子希巴迪亚，以及与他一起的男子八十人；</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="尼希米记 7:11; 以斯拉记 2:6"> 约押的子孙，有耶希业的儿子俄巴底亚，以及与他一起的男子两百一十八人；</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 巴尼<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="巴尼——依据七十士译本；马索拉文本此处缺失名字。">b</a></sup>的子孙，有约细斐的儿子示罗米，以及与他一起的男子一百六十人；</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以斯拉记 10:28; 尼希米记 7:16; 以斯拉记 2:11"> 比巴伊的子孙，有比巴伊的儿子撒迦利亚，以及与他一起的男子二十八人；</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以斯拉记 2:12; 尼希米记 7:17"> 阿兹伽德的子孙，有哈卡坦的儿子约哈南，以及与他一起的男子一百一十人；</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 2:13; 尼希米记 7:18"> 亚多尼卡姆的子孙是随后来的，他们的名字是以利菲列、耶乌利、示玛雅，与他们一起的男子有六十人；</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="尼希米记 10:12; 以斯拉记 2:14; 尼希米记 7:19"> 比格瓦伊的子孙，有乌塔伊和扎克尔，以及与他们一起的男子七十人。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以斯拉记 8:21; 以斯拉记 8:31; 以斯拉记 7:7"> 我把他们聚集到流向亚哈瓦的那条河边，我们在那里扎营三天。我在民众和祭司中仔细查找，却在那里没有找到一个利未子孙。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 2:6; 以斯拉记 8:18; 以斯拉记 10:39"> 于是我派遣以利以谢、亚利伊勒、示玛雅、以利拿单、雅立、以利拿单、拿单、撒迦利亚和米书兰这些首领，以及教师约雅立和以利拿单。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯拉记 2:43; 出埃及记 4:15; 民数记 8:22–26"> 我吩咐他们去见卡西非亚地区的首领易多，并交代他们要对易多和他在卡西非亚地区作圣殿仆役的兄弟们说什么话，好为我们神的殿带回来一些事奉的人。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 3:15; 以斯拉记 7:28; 尼希米记 2:8"> 因着我们的神施恩的手帮助我们，他们就从以色列之子利未的孙子玛赫利的后裔中，给我们带回来一个明达人示利比，以及他的儿子们和兄弟们十八人；</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 6:1; 历代志上 6:16; 尼希米记 10:11"> 还有哈沙比雅，并与他一起的米拉利子孙耶赛亚，以及他的兄弟们和他们的儿子二十人；</span>
<span className="v" id="v20" data-v="20" data-xref="以斯拉记 2:43; 以斯拉记 7:7; 历代志上 9:2"> 还有一些圣殿仆役，是大卫和首领们从前所委派服事利未人的圣殿仆役的子孙<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="的子孙——辅助词语。">c</a></sup>，共有两百二十人。他们全都被列入了名单。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="历代志下 20:3; 约珥书 1:14; 撒母耳记上 7:6"> 那时我在亚哈瓦河边宣告禁食，要在我们的神面前谦卑下来，为我们和我们的家属以及我们所拥有的一切，向神祈求平安的行程。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 3:12; 诗篇 33:18–19; 历代志下 16:9"> 我羞于求王派出军队和马兵帮助我们对付路上的敌人，因为我们已经告诉王说：“我们神施恩的手必帮助所有寻求他的人，他的大能和怒气必攻击所有离弃他的人。”</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 29:12–13; 马太福音 7:7–8; 以斯拉记 8:31"> 我们为此禁食，向我们的神祈求，他就应允了我们的祈求。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以斯拉记 8:18–19"> 我从祭司首领中分别出来十二个人，就是示利比、哈沙比雅，以及他们兄弟中与他们同工的十个人。</span>
<span className="v" id="v25" data-v="25" data-xref="以斯拉记 8:33; 以斯拉记 7:14–16; 以斯拉记 1:8"> 我把那些金银和器皿，就是王和内阁大臣们、首领们以及所有在巴比伦的以色列人献给我们神殿的供物，都称了交给他们。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯拉记 1:9–11"> 我称出来交到他们手中的，有：银子六百五十他连得<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="六百五十他连得——相当于22.2公吨。1他连得=34.2公斤。">d</a></sup>，银器一百他连得<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一百他连得——相当于3.4公吨；下同。">e</a></sup>，金子一百他连得；</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米哀歌 4:2"> 金碟二十个，值一千达利克<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一千达利克——相当于8.4公斤金子。1达利克金币=8.4公克。">f</a></sup>；抛光的上等铜器两个，珍贵如金。</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 22:2–3; 利未记 21:6–8; 历代志上 23:28"> 那时，我对他们说：“你们是归于耶和华为圣的，这些器皿也是神圣的，这些金银是甘心奉献物，归于耶和华你们祖先的神。</span>
<span className="v" id="v29" data-v="29" data-xref="以斯拉记 8:33–34; 马可福音 13:34–35; 历代志上 26:20–26"> 你们当警醒看守，直到你们在耶路撒冷耶和华殿的库房，在祭司和利未人的首领们以及以色列各父系首领面前，把它们都过了秤。”</span>
<span className="v" id="v30" data-v="30" data-xref="以斯拉记 8:22; 历代志上 29:2–3; 以赛亚书 60:13"> 于是祭司和利未人接收了这些称量过的金银和器皿，要带到耶路撒冷我们神的殿。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="以斯拉记 8:21–22; 以斯拉记 7:9; 以斯拉记 8:15"> 一月十二日，我们从亚哈瓦河边起程，往耶路撒冷去。我们神的手帮助了我们，保守我们避开敌人和路上埋伏之人的手。</span>
<span className="v" id="v32" data-v="32" data-xref="尼希米记 2:11; 以斯拉记 7:8–9"> 我们来到耶路撒冷，在那里歇息了三天。</span>
<span className="v" id="v33" data-v="33" data-xref="尼希米记 3:4; 尼希米记 3:21; 以斯拉记 8:30"> 第四天，在我们神的殿中，我们把金银和器皿过了秤，然后交到祭司乌利亚的儿子米利莫手中，与他同工的有非尼哈的儿子以利亚撒，还有利未人耶书亚的儿子约撒巴和宾努伊的儿子挪亚迪。</span>
<span className="v" id="v34" data-v="34"> 这一切都核对了数目和重量，重量全都在当时记下来了。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="以斯拉记 6:17; 历代志下 29:31–32; 诗篇 66:10–15"> 从流亡之地回归的那些掳民，向以色列的神献上了燔祭：为全体以色列人献上公牛十二头，公绵羊九十六只，公羊羔七十七只，赎罪祭公山羊十二只；这都是献给耶和华的燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以斯拉记 7:21–24; 以斯拉记 4:7–23; 以斯拉记 6:13"> 他们也把王的法令交给王的行政官们和大河<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="大河——指幼发拉底河。">g</a></sup>对岸的省长们，这些人就资助以色列民和神的殿。</span>
</div>

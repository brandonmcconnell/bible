<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯拉记 5:17; 箴言 25:2; 以斯拉记 4:15"> 于是大流士王下令，在巴比伦存放案卷的档案库里调查。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 17:6"> 在米底亚<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="米底亚——原文作“玛代”。">a</a></sup>省的亚马塔城堡中，他们找到一个书卷，其中这样写着：<br />“记事：</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 36:22–4; 启示录 21:16; 以西结书 41:13–15"> 居鲁士王元年，居鲁士王下令：关于在耶路撒冷的神殿，要重建这殿宇作为献祭的地方，并且立定它的根基。这殿宇要高六十肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="六十肘——相当于27.4公尺；下同。1肘=45.7公分。">b</a></sup>，宽六十肘，</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 6:36; 诗篇 68:29; 以赛亚书 49:23"> 有三层大石头和一层新木料；经费由王室提供。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 5:2; 以斯拉记 5:14; 历代志下 36:6–7"> 至于神殿的金银器皿，就是尼布甲尼撒从耶路撒冷的圣殿中取走带到巴比伦的，也要带回去，送到耶路撒冷圣殿中，各归原处，存放在神的殿中。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以斯拉记 5:3; 罗马书 8:31; 箴言 21:30"> 于是王下令<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="于是王下令——辅助词语。">c</a></sup>：<br />“现在，幼发拉底河对岸地区的省长达奈、示塔·波斯奈和你们的同僚，就是在幼发拉底河对岸地区的官员们，你们当远离那里。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 5:38–39"> 不要干涉这座神殿的工程，要让犹太人的省长和犹太人的长老们在原处重建这座神殿。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 6:4; 哈该书 2:8; 以斯拉记 7:15–22"> 我下令指示你们怎样协助这些犹太人的长老重建这座神殿：要从王的财政，就是幼发拉底河对岸地区的税捐中，提供充足的经费给这些人，以免停工。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 1:10; 诗篇 50:9–13; 马可福音 9:49"> 他们所需要的任何东西，无论是献给天上的神作燔祭的公牛犊、公绵羊和公羊羔，还是小麦、盐、酒和油，都要照着耶路撒冷的祭司们的吩咐，每天提供给他们，不可疏忽。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 29:7; 以斯拉记 7:23; 提摩太前书 2:1–2"> 这样，他们可以向天上的神献上馨香之祭，并为王和王子们的福寿祷告。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="但以理书 3:29; 以斯拉记 7:26; 但以理书 2:5"> 我还下令：任何人更改这谕旨，就要从他的房屋上拆出一根梁木，把他举起来钉在上面，他的家必因此成为废堆。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 9:3; 申命记 12:5; 申命记 12:11"> 任何君王或臣民，如果擅自更改这谕旨<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="擅自更改这谕旨——原文直译“伸手更改”。">d</a></sup>，毁坏耶路撒冷的这座神殿，就愿那使自己的名安居其中的神灭绝他！我大流士已经下令，必须认真执行。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 4:9; 以斯拉记 6:6; 约伯记 5:12–13"> 这样，幼发拉底河对岸地区的省长达奈、示塔·波斯奈和他们的同僚，就遵照大流士王下达的命令<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="命令——辅助词语。">e</a></sup>，认真执行。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯拉记 7:1; 以斯拉记 5:13; 以斯拉记 4:24–2"> 犹太人的长老们也在先知哈该和易多的孙子撒迦利亚的神言鼓励下，继续建造，进展顺利。他们照着以色列的神的命令，照着居鲁士、大流士、波斯王亚达薛西的命令，建造并完成了。</span>
<span className="v" id="v15" data-v="15" data-xref="以斯帖记 3:7; 以斯帖记 9:21; 以斯帖记 9:1"> 在大流士王执政的第六年，亚达月的第三日，这圣殿完工了。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志下 7:5; 列王纪上 8:63; 约翰福音 10:22"> 以色列人，包括祭司、利未人和其余的回归掳民，就欢欢喜喜地为这座神殿举行奉献礼。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯拉记 8:35; 启示录 7:4–8; 历代志下 29:21–23"> 他们为这座神殿的奉献礼献上一百头公牛、两百只公绵羊、四百只公羊羔；又按着以色列支派的数目，献上十二只公山羊，作为全以色列的赎罪祭。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 3:6; 历代志上 24:1; 历代志下 35:4–5"> 他们还照着摩西的书上所记的，指派祭司和利未人按照班组班次，在耶路撒冷服事神。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及记 12:6–36; 历代志下 30:1–27; 约书亚记 5:10"> 一月十四日，回归的掳民守逾越节。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 35:11; 希伯来书 7:27; 历代志下 29:34"> 那时祭司和利未人同心合一洁净自己，他们全都洁净了，就为所有回归的掳民、他们的兄弟众祭司，以及他们自己，宰杀了逾越节的羔羊。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯拉记 9:11; 哥林多后书 7:1; 以赛亚书 52:11"> 吃羔羊<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="羔羊——辅助词语。">f</a></sup>的人有从流亡之地回归的以色列子孙，也有归附以色列的当地人，这些人从外邦人的污秽中分别出来，为要寻求耶和华以色列的神。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯拉记 1:1; 历代志下 30:21; 箴言 21:1"> 他们欢欢喜喜地守了七天除酵节，因为耶和华使他们欢喜；他使亚述王的心转向他们，在以色列神的神殿工程上扶持他们的手。</span>
</div>
</div>

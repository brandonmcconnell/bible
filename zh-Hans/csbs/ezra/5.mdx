<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒迦利亚书 4:6–10; 哈该书 1:1; 撒迦利亚书 1:1–21"> 那时有两位先知，就是先知哈该和易多的孙子撒迦利亚，奉那差遣他们的以色列神的名，说神言鼓励那些在犹大和耶路撒冷的犹太人。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯拉记 3:2; 以斯拉记 6:14; 撒迦利亚书 3:1–4"> 于是撒拉铁的儿子所罗巴伯和约萨达的儿子耶书亚起来，开始重建耶路撒冷的神殿；神的众先知与他们在一起，扶持他们。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 6:6; 以斯拉记 6:13; 以斯拉记 5:9"> 当时，幼发拉底河对岸地区的省长达奈，还有示塔·波斯奈和他们的同僚，来到犹太人那里，对他们这样说：“谁下令让你们重建这殿宇，完成这建筑的？”</span>
<span className="v" id="v4" data-v="4"> 又问他们：“重建这建筑的那些人叫什么名字？”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="此节依据七十士译本和有些古抄本；马索拉文本作“我们如实告诉了他们，重建这建筑的那些人叫什么名字。”">a</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 33:18; 以斯拉记 7:6; 以斯拉记 7:28"> 然而，神的眼目一直看顾犹太人的长老们，那些人就没有让他们停工，而是等待报告送交大流士后，得到相关的回复公函。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以斯拉记 4:9; 以斯拉记 4:11; 以斯拉记 6:6"> 幼发拉底河对岸地区的省长达奈，还有示塔·波斯奈和他的同僚，就是在幼发拉底河对岸地区的官员们，向大流士王呈送奏章副本。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 4:17; 但以理书 6:21; 帖撒罗尼迦后书 3:16"> 他们呈送给王的报告，其中这样写着：<br />“致大流士王：<br />愿王万事平安！</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="尼希米记 7:6; 马可福音 13:1–2; 但以理书 3:26"> 愿王知道，我们前往犹大省，到了伟大之神的殿。那殿正在用巨大的块石重建，梁木也安置在墙中；这工作得到认真执行，在他们手中进展顺利。</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉记 5:3–4"> 我们就问这些长老，对他们这样说：‘谁下令让你们重建这殿宇，完成这建筑的？’</span>
<span className="v" id="v10" data-v="10"> 我们还问了他们的名字，要把那些为首之人的名字写下来，禀告王。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="罗马书 6:16; 约拿书 1:9; 使徒行传 27:23"> 那些人这样答复我们说：<br />‘我们是天地之神的仆人，正在重建这多年前所建造的殿宇。这是一位伟大的以色列王所建造并完成的，</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 36:16–17; 但以理书 9:5; 列王纪下 24:2"> 只是因为我们的祖先惹天上的神震怒，神就把他们交在迦勒底人巴比伦王尼布甲尼撒手中，尼布甲尼撒王拆毁了这殿宇，并把民众迁移到巴比伦。</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 6:3–5; 以赛亚书 44:28–1; 以斯拉记 1:1–8"> 然而巴比伦王居鲁士元年，居鲁士王下令重建这座神殿。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯拉记 6:5; 但以理书 5:2–3; 以斯拉记 5:16"> 而且神殿的金银器皿，就是尼布甲尼撒从耶路撒冷的圣殿中取走带到巴比伦殿宇的，居鲁士王也从巴比伦的殿宇中拿出来，交给了王所设立的省长，名叫设巴萨。</span>
<span className="v" id="v15" data-v="15" data-xref="以斯拉记 6:3; 以斯拉记 1:2; 以斯拉记 3:3"> 王吩咐设巴萨把这些器皿带上去，存放在耶路撒冷的圣殿里，并在原处重建神的殿。</span>
<span className="v" id="v16" data-v="16" data-xref="以斯拉记 3:10; 以斯拉记 6:15; 以斯拉记 3:8"> 于是这设巴萨前来，立定了耶路撒冷神殿的根基。从那时直到如今，神的殿一直在建造，但没有完工。’</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以斯拉记 4:15; 箴言 25:2; 以斯拉记 6:1–5"> 现在如果王认为好，就请在巴比伦王室案卷的库房里调查，看居鲁士王是否曾下令重建耶路撒冷这座神殿。然后请王下达关于这事的旨意给我们。”</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 22:9–10; 以斯拉记 1:11; 以斯拉记 10:16"> 犹大和便雅悯的敌人听说那些回归的掳民在为以色列的神耶和华重建圣殿，</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 19:37; 列王纪下 17:24; 加拉太书 2:4"> 就来见所罗巴伯和各父系的首领，对他们说：“让我们与你们一同建造吧！我们也像你们一样寻求你们的神，从亚述王以撒哈顿把我们迁到这里的日子以来，我们一直都向你们的神献祭。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="尼希米记 2:20; 马太福音 10:16; 历代志下 36:22–3"> 但所罗巴伯和耶书亚以及以色列其余的父系首领对他们说：“我们为我们的神建造殿宇，与你们无关；我们是照着波斯的王——居鲁士王所吩咐的，要自己为以色列的神耶和华建造。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以斯拉记 3:3; 尼希米记 6:9; 耶利米书 38:4"> 于是，当地的人就使犹大民众的手发软，阻挠他们建造，</span>
<span className="v" id="v5" data-v="5" data-xref="那鸿书 1:11; 以斯拉记 5:5–18; 诗篇 2:1–2"> 还收买官员来反对他们，破坏他们的工程计划。在波斯王居鲁士所有的日子里，一直到波斯王大流士在位时，都是这样。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以斯帖记 1:1; 但以理书 9:1; 使徒行传 24:5–9"> 亚哈随鲁王在位初期，那些人写了一封控告信，指控犹大和耶路撒冷的居民。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 18:26; 但以理书 2:4; 以赛亚书 36:11"> 亚达薛西年间，比施兰、米特利达、塔别以及他们其余的同僚，上书波斯王亚达薛西，公文的文书是用亚兰语写下、用亚兰语转述的。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 4:9; 撒母耳记下 8:17; 撒母耳记下 20:25"> 行政长官利户姆和书记希姆沙伊也给亚达薛西王写了一封指控耶路撒冷的奏章：</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以斯拉记 5:6; 以斯拉记 6:6; 列王纪下 17:24"> “谨有行政长官利户姆、书记希姆沙伊和他们其余的同僚，司法官、行政官员、各级官员，波斯人、乌鲁克人、巴比伦人、苏萨人——就是以拦人，</span>
<span className="v" id="v10" data-v="10" data-xref="以斯拉记 4:17; 以斯拉记 4:11; 以斯拉记 7:12"> 以及其余的民族，就是被伟大尊贵的亚斯纳巴迁移，安置在撒玛利亚城和幼发拉底河对岸其余地区的民族，现在</span>
<span className="v" id="v11" data-v="11"> 有呈送给王的奏章副本如下：<br />致亚达薛西王，<br />我们是<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我们是——辅助词语。">a</a></sup>你的臣民，是幼发拉底河对岸地区的人。现在</span>
<span className="v" id="v12" data-v="12" data-xref="以斯拉记 5:9; 历代志下 36:13; 以斯拉记 5:3"> 愿王知道，从王那里上到我们这里的犹太人，已经到了耶路撒冷，正在重建这座邪恶、反叛的城，就要建好城墙，打好根基了。</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 7:24; 罗马书 13:6–7; 尼希米记 5:4"> 如今愿王知道，如果这城被重建，城墙被建好，他们就不会交纳税捐、贡物和路税了，王的财政收入就会受损。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 19:12–15; 以西结书 33:31; 约翰福音 12:5–6"> 如今我们既然吃宫廷的盐，就不应该看着王蒙受亏损<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="蒙受亏损——原文直译“蒙羞”。">b</a></sup>，因此我们上奏禀告，</span>
<span className="v" id="v15" data-v="15" data-xref="以斯拉记 4:12; 以斯帖记 3:5–8; 列王纪下 24:20–1"> 请王调查先王的记事档案，从记事档案中查找，就会明白这城是反叛之城，曾使君王和各省受损。从久远的日子以来，这城就常常发生叛乱，因此才被摧毁。</span>
<span className="v" id="v16" data-v="16" data-xref="以斯拉记 4:20; 列王纪上 4:24; 撒母耳记下 8:3"> 我们禀告王：如果这城被重建，城墙被建好，那么王在幼发拉底河对岸地区必将一无所有。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 1:7; 以斯拉记 5:7; 以斯拉记 4:9–11"> 王就发谕旨给行政长官利户姆、书记希姆沙伊和他们其余的同僚，就是住在撒玛利亚和幼发拉底河对岸其余地区的人：<br />“愿你们平安！<br />现在</span>
<span className="v" id="v18" data-v="18" data-xref="尼希米记 8:8"> 你们呈送来的公函，已经在我面前清楚地诵读了。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 18:7; 箴言 25:2; 申命记 13:14"> 我已下令调查，查出这城从久远的日子以来就常常背叛王，发生造反和叛乱的事。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 15:18; 列王纪上 4:21; 历代志上 18:3"> 从前有强势的君王管理耶路撒冷，有掌权者治理整个幼发拉底河对岸地区，那时税捐、贡物和路税都交给了他们。</span>
<span className="v" id="v21" data-v="21"> 现在你们要命令这些人停工；我若不下令，这城就不可重建。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯帖记 7:3–4; 以斯帖记 3:8–9; 以斯拉记 4:13"> 你们当谨慎，做这件事不可疏忽。何必让损害增加，使王受亏损呢？”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="罗马书 3:15; 弥迦书 2:1; 以斯拉记 4:17"> 亚达薛西王的公函副本在利户姆、书记希姆沙伊和他们的同僚面前诵读后，他们就急忙前往耶路撒冷，到犹太人那里去，以强权和武力使他们停工。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哈该书 1:15; 尼希米记 6:9; 以斯拉记 5:5"> 这样，耶路撒冷的神殿工程就停工了，一直停工到波斯王大流士执政的第二年。</span>
</div>
</div>

</div>

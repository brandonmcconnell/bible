<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 4:32; 利未记 23:24; 哥林多前书 1:10"> 到了七月，以色列子民都在各自的城中了。那时，民众如同一人聚集到耶路撒冷。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 3:17; 以斯拉记 2:2; 哈该书 1:1"> 约萨达的儿子耶书亚和他的兄弟众祭司，以及撒拉铁的儿子所罗巴伯和他的兄弟们，就起来重建以色列神的祭坛，要照着神人摩西的律法上所记的，在祭坛上献燔祭。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 4:4; 民数记 28:2–8; 以斯拉记 8:21–22"> 虽然各地的民众恐吓他们，他们还是在原来的基座上修筑了祭坛，在祭坛上向耶和华献燔祭，就是清晨和傍晚的燔祭。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米记 8:14–17; 民数记 29:12–38; 出埃及记 23:16"> 他们照着律法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="律法——辅助词语。">a</a></sup>上所记的守住棚节，每天按照规定的份额、照着数目献上当天的燔祭。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 29:39; 民数记 28:19; 出埃及记 29:38–42"> 之后，他们献上常献的燔祭、新月节的祭物、耶和华神圣节期的所有祭物，以及甘愿奉献给耶和华的一切甘心祭。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 从七月一日起，他们开始向耶和华献上燔祭，那时耶和华的圣殿还没有奠定根基。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 5:6; 使徒行传 9:36; 使徒行传 12:20"> 他们又照着波斯王居鲁士给他们的许可，把银子交给石匠和木匠，又把食物、酒和油交给西顿人和提尔人，好让他们把香柏木从黎巴嫩经海上运到约帕。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 4:3; 历代志上 23:4; 历代志上 23:24–32"> 他们来到耶路撒冷的神的殿之后，在第二年的二月，撒拉铁的儿子所罗巴伯、约萨达的儿子耶书亚，还有他们其余的兄弟——那些祭司和利未人，以及掳民中所有归回耶路撒冷的人，就开始动工。他们安排二十岁以上的利未人来监管耶和华殿的工程。</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉记 2:40; 以斯拉记 3:8; 尼希米记 7:43"> 于是，赫达维亚<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="赫达维亚——或音译“耶胡达、犹大”；参《以斯拉记》2:40。">b</a></sup>的后裔耶书亚和他的儿子们、兄弟们以及卡米尔和他的儿子们，还有利未人希纳达的子孙、兄弟们，一同合作监管那些在神的殿工作的人。</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="历代志上 25:1–7; 历代志上 15:27; 历代志上 16:37"> 当工匠们奠定耶和华圣殿的根基时，祭司们穿着礼服、拿着号筒，利未人亚萨的子孙拿着大钹，他们都照着以色列王大卫的规定站立着，赞美耶和华。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 16:34; 诗篇 106:1; 诗篇 107:1"> 他们赞美称谢耶和华，歌唱说：<br /><span className="pl pl-1">“他是美善的，</span><br /><span className="pl pl-1">他对以色列的慈爱永远长存！”</span><br />他们赞美耶和华的时候，全体民众大声呼喊，因为耶和华殿的根基奠定了。</span>
<span className="v" id="v12" data-v="12" data-xref="哈该书 2:3; 马太福音 13:31–32; 以赛亚书 60:22"> 有许多祭司、利未人和父系首领，就是那些见过先前殿宇的长老们，如今亲眼看见这殿的根基奠定了，就放声大哭，也有许多人扬声欢呼庆祝。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 19:37–40; 撒母耳记上 4:5; 尼希米记 12:43"> 人们甚至无法分辨欢呼庆祝的声音和哭号的声音，因为民众大声呼喊，声音一直传到远处。</span>
</div>

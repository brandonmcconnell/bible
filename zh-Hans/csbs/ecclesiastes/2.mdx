<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:19; 传道书 8:15; 雅各书 5:5"> 我对自己说：“来吧，我要用享乐试验你，让你看看有什么好处！”看哪，这也是虚空！</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 14:13; 传道书 7:2–6; 彼得前书 4:2–4"> 论到欢笑，我说：“这是发狂”；论到享乐，我说：“这有什么用呢？”</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 20:1; 传道书 1:17; 箴言 31:4–5"> 我的心以智慧引领我的同时，我心里探察如何用酒使我的肉体畅快并保持愚昧状，直到我看清世人一生可数的日子里，在天下做什么才有益处。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪上 7:1–12; 历代志下 8:11; 历代志下 26:10"> 我扩建工程，为自己建造房屋，种植葡萄园；</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 17:27–29; 雅歌 4:12–1; 耶利米书 39:4"> 我为自己造了庭园和园林，在其中栽种各样的果树；</span>
<span className="v" id="v6" data-v="6" data-xref="尼希米记 2:14; 诗篇 1:3; 耶利米书 17:8"> 我为自己造了蓄水池，用以浇灌长满树木的林子；</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 3:4; 创世记 15:3; 列王纪上 4:23"> 我买下了男仆和婢女，我也有生在我家里的奴仆；我还拥有大量的牛群和羊群，超过我之前在耶路撒冷的所有人；</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 10:10; 列王纪上 9:28; 撒母耳记下 19:35"> 我又为自己积聚金银，还有来自君王们和各省的珍宝。我也为自己招纳了男女歌手，以及许多的妃嫔，都是世人引以为乐的。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 29:25; 传道书 1:16; 列王纪上 10:23"> 于是我日渐昌大，超越了我之前在耶路撒冷的所有人，而我的智慧仍然与我同在。</span>
<span className="v" id="v10" data-v="10" data-xref="传道书 9:9; 传道书 5:18; 传道书 3:22"> 我的眼目所追求的一切，我都不禁止；我的心所欢喜的一切，我都不拒绝；因为我的心在我一切的劳苦中欢喜——这就是我在一切劳苦中所得的份。</span>
<span className="v" id="v11" data-v="11" data-xref="传道书 1:14; 约翰一书 2:16–17; 传道书 1:3"> 但当我回顾我手所做的一切事，以及我劳苦所做的工，看哪，全是虚空，全是捕风！在日光之下毫无益处。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="传道书 1:17; 传道书 7:25; 传道书 1:9–10"> 我转眼去看智慧、狂妄和愚昧。那在王之后来的人，到底能做什么呢？不过是先前所做过的而已。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 5:8; 传道书 7:11–12; 马太福音 6:23"> 这样我就看到：智慧胜过愚昧，就像光明胜过黑暗。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 49:10; 箴言 17:24; 传道书 9:11"> <span className="pl pl-1">智慧人看得见他的道路</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="智慧人看得见他的道路——原文直译“智慧人的眼睛在头上”。">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">愚昧人却在黑暗中行走。</span><br />不过我也明白，同样的命运会临到他们这两种人。</span>
<span className="v" id="v15" data-v="15" data-xref="传道书 6:8; 传道书 1:14; 传道书 1:2"> 于是我心里说：“既然愚昧人的命运也照样会临到我，那么我为什么要更有智慧呢？”我心里就说：“这也是虚空！”</span>
<span className="v" id="v16" data-v="16" data-xref="传道书 1:11; 传道书 9:5; 诗篇 88:12"> 因为智慧人与愚昧人一样，不会被永远记念；在将要来的日子，一切都会被忘掉。智慧人怎么像愚昧人一样死亡呢？</span>
<span className="v" id="v17" data-v="17" data-xref="传道书 2:11; 约拿书 4:8; 传道书 4:2"> 于是我恨恶生命，因为在日光之下所做的事，对我都是悲苦。是的，全是虚空，全是捕风！</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="诗篇 39:6; 诗篇 49:10; 路加福音 16:27–28"> 我恨恶自己一切的劳苦，就是我在日光之下的劳碌所为，因为我必把劳苦所得留给在我之后来的人。</span>
<span className="v" id="v19" data-v="19" data-xref="雅各书 3:17; 传道书 3:22; 传道书 9:13"> 那人是智慧是愚笨，谁知道呢？他却要掌管我劳苦所得的一切，就是我在日光之下用智慧得来的。这也是虚空！</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 43:14; 约伯记 17:11–15; 哥林多后书 1:8–10"> 于是我回顾我在日光之下劳苦所做的一切工，就心感绝望；</span>
<span className="v" id="v21" data-v="21" data-xref="传道书 2:17–18; 历代志下 31:20–21; 历代志下 34:2"> 因为一个人用智慧、知识和技能劳苦工作，却把自己所得的份给了那未曾劳苦的人。这也是虚空，也是极大的悲苦！</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 127:2; 传道书 1:3; 腓立比书 4:6"> 人一切的劳苦和他心里的追求，就是他在日光之下的劳碌所为，到底能为自己成就什么呢？</span>
<span className="v" id="v23" data-v="23" data-xref="约伯记 14:1; 约伯记 5:7; 诗篇 6:6–7"> 其实他一生的日子都是痛苦，他的事务都是烦恼，他的心甚至在夜间也不得安息。这也是虚空！</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="传道书 3:22; 传道书 8:15; 提摩太前书 6:17"> 对人而言，没有什么比吃喝并在劳苦中找到快乐更好的了！在我看，这也是出于神的手；</span>
<span className="v" id="v25" data-v="25" data-xref="传道书 2:1–12; 列王纪上 4:21–24"> 因为离了他<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="他——马索拉文本作“我”。">b</a></sup>，谁能吃喝，谁能享受呢？</span>
<span className="v" id="v26" data-v="26" data-xref="箴言 13:22; 约伯记 27:16–17; 箴言 28:8"> 原来神把智慧、知识和喜乐赐给他所喜悦的人；至于罪人，神加给他们担子，让他们去收取、积聚，好给神所喜悦的人。这也是虚空，也是捕风！</span>
</div>

<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="传道书 1:3; 传道书 5:16; 箴言 14:23"> 做事的人如此劳苦，有什么益处呢？</span>
<span className="v" id="v10" data-v="10" data-xref="传道书 1:13–14; 创世记 3:19; 传道书 2:26"> 我看到神加给世人担子，让他们在其中操劳。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 11:33; 罗马书 1:19–20; 约伯记 11:7"> 神使万物各按其时成为美好，又把永恒放在人的心里。虽然如此，神从始至终所做的事，人却无法查明。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 37:3; 传道书 3:22; 提摩太前书 6:18"> 我知道：人一生中没有什么比喜乐和行善更好的；</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 128:2; 传道书 9:7; 传道书 2:24"> 并且，人人吃喝，在一切的劳苦中享受好处——这也是神的恩赐。</span>
<span className="v" id="v14" data-v="14" data-xref="雅各书 1:17; 诗篇 33:11; 罗马书 11:36"> 我知道：神所做的一切，都必永存，无可增添，无可减少；神这样做，是要人在他面前心存敬畏。</span>
<span className="v" id="v15" data-v="15" data-xref="传道书 1:9–10; 传道书 6:10"> 现在有的，早已经有过；将要有的，也早已经有过；因为神使已过的事重复再现<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="神使已过的事重复再现——原文直译“神寻回已过的事”。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="传道书 4:1; 传道书 5:8; 诗篇 94:21–22"> 我还看到在日光之下，在审判的地方有奸恶，在公义的地方也有奸恶。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 5:10; 传道书 12:14; 马太福音 16:27"> 我心里说：“义人和恶人，神都会审判；因为在他那里，万事万务都有定时。”</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 73:22; 诗篇 49:12; 希伯来书 9:27"> 至于世人，我心里说：“神在考验他们，要让他们看见自己像兽类一样”；</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 49:12; 诗篇 49:20; 诗篇 89:47–48"> 因为世人的命运和兽的命运都一样：这个会死，那个也一样会死，他们都有一样的气息，人不比兽优越。这全是虚空！</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 3:19; 约伯记 34:15; 传道书 12:7"> 他们都同归一处，都出于尘土，也都归于尘土。</span>
<span className="v" id="v21" data-v="21" data-xref="传道书 12:7; 约翰福音 14:3; 哥林多后书 5:1"> 谁知道人的灵是否往上升，兽的灵是否往下降入地里呢？</span>
<span className="v" id="v22" data-v="22" data-xref="传道书 2:24; 传道书 3:11–12; 传道书 10:14"> 因此我看到：没有什么比人在自己所做的事上自得其乐更好，因为这是他的份。谁能带他去看在他之后所发生的事呢？</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="雅各书 1:19; 希伯来书 12:28–29; 箴言 15:8"> 你去神的殿时，要谨慎脚步；近前听，胜过像愚昧人那样献上祭物，因为愚昧人不知道自己在作恶。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 6:7; 箴言 10:19; 以赛亚书 55:9"> 在神面前不要冒失开口，也不要心急发言，因为神在天上，你在地上，所以你要少言寡语。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 15:2; 箴言 10:19; 传道书 10:12–14"> 要知道，梦来自事务繁多，愚昧的声音来自多言多语。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 30:2; 申命记 23:21–23; 诗篇 76:11"> 你向神许了愿，偿还不可迟延，因为神不喜欢愚昧人；你所许的愿应当偿还。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 5:4; 申命记 23:22; 箴言 20:25"> 不许愿，好过许了愿却不偿还。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 1:26; 约翰二书 1:8; 雅各书 3:2"> 不要任你的口使自己犯罪，也不要在使者面前说所许的愿是个失误。为什么要使神因你的话而发怒，摧毁你手中的工作呢？</span>
<span className="v" id="v7" data-v="7" data-xref="传道书 12:13; 马太福音 12:36; 传道书 8:12"> 多梦多语带来更多的虚空<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="多梦多语带来更多的虚空——原文直译 “多梦带来更多的虚空和话语”。">a</a></sup>；因此你当敬畏神。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="诗篇 12:5; 传道书 4:1; 传道书 3:16"> 如果你在某一省中看到穷人受欺压，公正和公义被夺去，不要因此感到惊奇，因为高位者之上有更高的在保护<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="保护——或译作“鉴察”；本节下同。">b</a></sup>他，在他们之上还有更高的保护他们。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 4:7–23; 诗篇 115:16; 创世记 1:29–30"> 各人都从这块地得好处，甚至君王也藉着这块地得益处。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 6:10; 马太福音 6:24; 路加福音 12:15"> 贪爱银子的不会因银子满足，贪爱财富的也不会因利益满足。这也是虚空！</span>
<span className="v" id="v11" data-v="11" data-xref="约翰一书 2:16; 哈巴谷书 2:13; 诗篇 119:36–37"> 财物增加，吃用的人也增加，而主人除了眼看以外，还有什么益处呢？</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 3:24; 诗篇 4:8; 耶利米书 31:26"> 劳力的人无论吃多吃少，都睡得甜美；富有人的丰足，却不容他安睡。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="传道书 6:1–2; 路加福音 18:22–23; 创世记 19:14"> 我看到在日光之下有一件令人痛心的悲苦之事：财主所积存的财富导致了他的悲苦，</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 6:19–20; 哈该书 2:16–17; 箴言 23:5"> 那财富也在悲苦的事中消亡了；所以当他生儿子的时候，自己的手中却一无所有。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 49:17; 约伯记 1:21; 提摩太前书 6:7"> 他从母腹中怎样赤身而来，也必怎样赤身而去，就像他来的那样；至于他的劳苦所得，他的手分毫不能带走——</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 11:29; 传道书 1:3; 约翰福音 6:27"> 这也是一件令人痛心的悲苦之事，就是他来的时候怎样，去的时候也怎样；他为风劳苦，对他有什么益处呢？</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 127:2; 以西结书 4:16–17; 诗篇 90:7–11"> 并且他一生的日子都在黑暗中吃喝，多有烦恼、疾病和怒气。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="传道书 2:24; 传道书 3:12–13; 传道书 3:22"> 看哪，我所见为善为美的，就是人在神所赐给他一生可数的日子里吃喝，享受他在日光之下劳苦所得的一切好处，因为这是他的份。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 8:18; 传道书 3:13; 传道书 6:2"> 而且，对每个蒙神赐予富贵资产的人，神也使他能享用，并领受他的份，在自己的劳苦中欢喜——这就是神的恩赐。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 65:21–24; 以赛亚书 65:13–14; 诗篇 37:16"> 他并不多思考自己一生的日子，因为神以喜乐充满他的心。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 32:6–7; 创世记 27:41–42; 创世记 32:16"> 雅各举目观看，看哪，以扫来了，还有四百人与他在一起！雅各就把孩子们分别交给莉亚、拉结和两个婢女。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 29:30; 创世记 30:22–24; 创世记 37:3"> 他把两个婢女和她们的孩子们安排在前面，莉亚和她的孩子们在其后，拉结和约瑟在最后；</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 42:6; 路加福音 14:11; 创世记 18:2"> 而他自己在他们前面先过去，七次俯伏于地，直到临近他哥哥。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="创世记 45:14–15; 诗篇 34:4; 路加福音 15:20"> 以扫跑来迎接他，拥抱他，伏在他的脖子上亲吻他；他们两人都哭了。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 127:3; 以赛亚书 8:18; 创世记 48:9"> 以扫举目，看见女人们和孩子们，就说：“这些与你在一起的是谁呢？”<br />雅各说：“这些孩子是神施恩赐给你仆人的。”</span>
<span className="v" id="v6" data-v="6"> 于是两个婢女和她们的孩子们就上前下拜，</span>
<span className="v" id="v7" data-v="7"> 接着莉亚和她的孩子们也上前下拜，最后约瑟和拉结也上前下拜。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="创世记 32:5; 创世记 39:5; 创世记 32:13–20"> 以扫说：“我所遇见的这一整队，是什么意思呢？”<br />雅各说：“是为了在我主眼前蒙恩。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 27:39; 腓利门书 1:7; 创世记 27:41"> 以扫说：“弟弟，我已经有很多了，你把你的留给自己吧！”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约伯记 33:26; 启示录 22:4; 创世记 32:30"> 雅各说：“不，如果我在你眼前蒙恩，就请你从我手中收下礼物；因为我见了你的面，就像见了神的面，而你也悦纳了我。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 25:27; 腓立比书 4:18; 创世记 30:43"> 请你收下我带给你的礼物<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="礼物——原文直译“祝福”。">a</a></sup>吧！因为神恩待我，我什么都有了。”雅各再三劝说，他才收下。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 以扫说：“让我们起程前行，我走在你前面。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 40:11; 以西结书 34:15–16; 以西结书 34:23–25"> 雅各对他说：“我主知道：孩子们年幼娇嫩；还有正哺乳的牛羊需要我照管，只要催逼一天，整群牲畜就都死了。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 32:3; 以赛亚书 40:11; 罗马书 15:1"> 请我主在仆人前面先过去；我要按着面前牲畜的速度和孩子们的速度，慢慢领他们走，一直走到西珥我主那里。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路得记 2:13; 创世记 47:25; 创世记 34:11"> 以扫就说：“让我把一些跟随我的人留在你这里吧。”<br />雅各却说：“何必如此呢？愿我在我主眼前蒙恩。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 于是以扫当天就上路回西珥了。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 60:6; 约书亚记 13:27; 士师记 8:5"> 雅各却起程往疏割去，为自己建造了房屋，为他的牲畜搭了棚子；因此他给那地方起名为疏割。</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 9:1; 使徒行传 7:16; 约书亚记 24:1"> 雅各从帕旦-亚兰回来的时候，平安地来到迦南地的示剑城，在城的对面支搭帐篷。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 7:16; 约翰福音 4:5; 约书亚记 24:32"> 他用一百个银钱，从示剑的父亲哈莫尔的儿子们手中买下了这块支搭帐篷的田地。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 35:7; 创世记 21:33; 创世记 32:28"> 在那里雅各立了一座祭坛，称它为伊利-伊罗伊-以色列<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="伊利-伊罗伊-以色列——意思是“神——以色列的神”。">b</a></sup>。</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 41:10; 诗篇 119:114; 诗篇 84:11"> 这些事以后，在异象中，耶和华的话语临到亚伯兰，说：<br /><span className="pl pl-1">“亚伯兰哪，你不要害怕！</span><br /><span className="pl pl-1">我是你的盾牌，</span><br /><span className="pl pl-1">你的赏报将极其大。”</span></span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="创世记 25:21; 使徒行传 7:5; 创世记 12:1–3"> 亚伯兰说：“主耶和华啊，你要赐给我什么呢？我一直没有孩子，我家业的继承人是大马士革人以利以谢。”</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 14:14; 箴言 29:21; 传道书 2:7"> 亚伯兰又说：“看哪，既然你没有赐给我后裔，那生在<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="生在——辅助词语。">a</a></sup>我家里的就是我的继承人了。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="创世记 17:16; 加拉太书 4:28; 撒母耳记下 7:12"> 耶和华的话语又临到他，说：“这人不会是你的继承人，只有你亲生的，才会是你的继承人。”</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 11:12; 罗马书 4:18; 申命记 1:10"> 耶和华把他带到外面，说：“你向天观看，如果你能数清星辰，就去数吧！”又对他说：“你的后裔也必如此众多<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="众多——辅助词语。">b</a></sup>。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="雅各书 2:23; 加拉太书 3:6–14; 罗马书 4:9"> 亚伯兰信耶和华，耶和华就以此算为他的义。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="创世记 12:1; 使徒行传 7:2–4; 罗马书 4:13"> 耶和华对他说：“我是耶和华，我把你从迦勒底的吾珥领出来，为要将这地赐给你，使你拥有它。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 1:18; 路加福音 1:34; 以赛亚书 7:11"> 亚伯兰说：“主耶和华啊，我怎能知道我会拥有这地呢？”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 2:24; 利未记 14:30; 利未记 14:22"> 耶和华就对他说：“你为我取来一头三岁的小母牛、一只三岁的母山羊、一只三岁的公绵羊、一只斑鸠和一只雏鸽。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 34:18–19; 利未记 1:17; 创世记 15:17"> 他就为耶和华取来这一切，把每样都从中间剖开，一半对着另一半摆列，但没有把鸟剖开。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 13:4; 诗篇 119:13; 以西结书 17:3"> 有猛禽飞落在这些尸体上，亚伯兰就赶走它们。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 2:21; 约伯记 33:15; 但以理书 10:8–9"> 日落的时候，亚伯兰陷入沉睡。看哪，有大而恐怖的黑暗落在他身上！</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 7:6–7; 出埃及记 1:11; 出埃及记 12:40–41"> 耶和华对亚伯兰说：“你要确切知道：你的后裔将在不属于自己的地上寄居，并服事那地的人；那地的人将苦待他们四百年。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 9:9–11; 出埃及记 6:5–6; 出埃及记 12:32–38"> 但我将审判他们所服事的那个国家；之后他们将带着大量的财物出来。</span>
<span className="v" id="v15" data-v="15" data-xref="约伯记 5:26; 创世记 25:7–9; 历代志下 34:28"> 至于你，你必平平安安地归到你祖先那里，你必尽享天年，才被安葬。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 21:26; 但以理书 8:23; 出埃及记 12:40"> 他们到第四代才会回到这里，因为亚摩利人的罪孽还没有满盈。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="耶利米书 34:18–19; 士师记 6:21; 耶利米书 11:4"> 日落天黑的时候，看哪，有冒烟的火炉和燃烧的火把在这些肉块之间经过！</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 1:3–4; 创世记 12:7; 创世记 24:7"> 就在那一天，耶和华与亚伯兰立约，说：“我已经把这地赐给你的后裔，从埃及河直到幼发拉底大河，</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 24:21–22"> 就是基尼人、基尼洗人、甲摩尼人、</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 17:5; 创世记 14:5"> 赫提人、比利洗人、利乏音人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="利乏音人——或译作“巨人”。">c</a></sup>、</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 10:15–19; 出埃及记 23:23–28; 申命记 7:1"> 亚摩利人、迦南人、革迦撒人、耶布斯人之地<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="之地——辅助词语。">d</a></sup>。”</span>
</div>
</div>

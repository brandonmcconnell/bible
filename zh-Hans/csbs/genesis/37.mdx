<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 17:8; 创世记 23:4; 创世记 36:7"> 雅各住在他父亲的寄居之地，就是迦南地；</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 35:25–26; 创世记 35:22; 撒母耳记上 2:22–24"> 以下是雅各的家系记事。<br />约瑟十七岁时与哥哥们一同放牧羊群。他还是个少年人，常与父亲的两个妾碧拉和悉帕的儿子们在一起<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他还是个少年人，常与父亲的两个妾碧拉和悉帕的儿子们在一起——或译作“他给父亲的两个妾碧拉和悉帕的儿子们当小帮手”。">a</a></sup>，也常把他们的不是之处报给父亲。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="约翰福音 3:35; 创世记 37:32; 撒母耳记下 13:18"> 以色列爱约瑟胜过其他的儿子，因为约瑟是他年老时生的儿子；他为约瑟做了一件彩色的袍子。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 27:41; 约翰一书 3:12; 约翰一书 4:20"> 约瑟的哥哥们看见父亲爱约瑟胜过他所有的兄弟，就恨约瑟，不能与他和气地说话。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 28:12; 创世记 42:9; 约翰福音 17:14"> 约瑟做了一个梦，告诉了他的哥哥们，他们就更加恨他。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 44:18; 士师记 9:7"> 约瑟对他们说：“你们听听我所做的这个梦：</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 44:14; 创世记 42:6; 创世记 43:26"> 看哪，我们正在田间绑禾捆；看哪，我的禾捆起来立着，你们的禾捆都围着我的禾捆下拜！”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 10:27; 使徒行传 7:35; 希伯来书 10:29"> 他的哥哥们就对他说：“难道你真要作我们的王，真要管辖我们吗？”他们就因他的梦和他的话更加恨他。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 7:9–14; 创世记 37:7; 但以理书 8:10"> 后来约瑟又做了另一个梦，也把这梦向哥哥们讲述了。他说：“看哪，我又做了一个梦！看哪，太阳、月亮和十一颗星星都向我下拜！”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 27:29; 腓立比书 2:10–11; 以赛亚书 60:14"> 约瑟把梦向父亲和哥哥们讲述了，父亲就斥责他说：“你做的这是什么梦呢？难道我和你母亲、你哥哥们真要来俯伏于地，向你下拜吗？”</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 7:9; 路加福音 2:19; 路加福音 2:51"> 他的哥哥们都嫉妒他，他父亲却把这话存在心里。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 37:1; 创世记 33:18; 创世记 34:25–31"> 后来约瑟的哥哥们去示剑放牧他们父亲的羊群。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 6:1–3; 撒母耳记上 3:8; 撒母耳记上 3:16"> 以色列对约瑟说：“你哥哥们不正在示剑放牧吗？你来，我要派你到他们那里去。”<br />约瑟对他说：“我在这里！”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="创世记 35:27; 路加福音 19:42; 诗篇 125:5"> 以色列对他说：“你去看看你哥哥们是否平安，羊群是否平安，然后回来告诉我。”于是他打发约瑟出希伯仑谷，约瑟就往示剑去了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 4:27; 士师记 4:22; 创世记 21:14"> 有人遇见他，看哪，他正在田野中徘徊。那人就问他：“你在找什么？”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:10; 雅歌 1:7"> 他说：“我在找我哥哥们。请告诉我，他们在哪里放牧？”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王纪下 6:13"> 那人说：“他们已经离开了这里；我听见他们说：‘让我们往多坍去吧！’”约瑟就去追哥哥们，在多坍找到了他们。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行传 23:12; 诗篇 37:12; 诗篇 37:32"> 他们从远处看见了他。在他靠近之前，他们就图谋要置他于死地。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 28:12; 创世记 37:11; 创世记 37:5"> 他们彼此说：“看哪，那个做梦的来了！</span>
<span className="v" id="v20" data-v="20" data-xref="提多书 3:3; 箴言 27:4; 马太福音 2:2–16"> 来吧！我们把他杀了，扔到一个坑里，然后说有恶兽把他吃掉了；我们倒要看看他的梦将来会怎样！”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 42:22; 创世记 35:22; 约书亚记 10:28"> 鲁本听见后，要救约瑟脱离他们的手，就说：“我们不可夺取他的性命。”</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 22:12; 申命记 13:9; 创世记 42:22"> 又对他们说：“不可杀人流血！可以把他扔进这旷野的坑里，只是不可向他下手。”鲁本这样说，是要救约瑟脱离他们的手，把他带回父亲那里。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="创世记 37:3; 马太福音 27:28; 创世记 42:21"> 约瑟来到哥哥们那里，他们就剥去了他的袍子，就是他身上的那件彩色袍子；</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 38:6; 诗篇 130:1–2; 撒迦利亚书 9:11"> 然后抓住他，把他扔进坑里。那坑是空的，里面没有水。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 37:28; 创世记 43:11; 耶利米书 8:22"> 他们坐下来吃饭，举目观看，看哪，有一支以实玛利人的商队正从基列来！他们的骆驼驮着香料、乳香和没药，要带下埃及去。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="创世记 37:20; 创世记 4:10; 创世记 25:32"> 犹大对他的兄弟们说：“如果我们杀了自己的兄弟，掩盖他的血，有什么好处呢？</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 16:26; 创世记 42:21; 撒母耳记上 18:17"> 来，让我们把他卖给以实玛利人吧！不可向他下手，因为他是我们的兄弟，我们的骨肉。”他的兄弟们就听从了他。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 7:9; 诗篇 105:17; 创世记 45:4–5"> 于是，那些米甸商人经过的时候，哥哥们就把约瑟从坑里拉上来，以二十块的价银把他卖给以实玛利人；那些人就把约瑟带往埃及去了。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约伯记 1:20; 创世记 37:34; 创世记 44:13"> 鲁本回到那坑，见约瑟不在坑里，就撕裂衣服，</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 42:13; 耶利米书 31:15; 创世记 42:32"> 回到他的兄弟们那里，说：“那孩子不在了，而我该何去何从？”</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 37:23; 箴言 28:13; 创世记 37:3"> 他们拿来约瑟的袍子，宰杀了一只公山羊，把袍子蘸在血里；</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 15:30; 创世记 37:3; 创世记 44:20–23"> 然后派人把彩色的袍子带到他们父亲那里，说：“我们找到了这个，请你认一认，是不是你儿子的袍子？”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="创世记 37:20; 创世记 44:28; 约翰福音 13:7"> 雅各认出了那袍子，就说：“这是我儿子的袍子。恶兽把他吃掉了；约瑟一定被撕碎了！”</span>
<span className="v" id="v34" data-v="34" data-xref="创世记 37:29; 撒母耳记下 3:31; 诗篇 69:11"> 雅各就撕裂衣服，把麻布束在腰上，为他儿子悲恸了许多日子。</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 42:38; 约伯记 2:11; 撒母耳记下 12:17"> 他所有的儿女都起来安慰他，他却不肯受安慰，说：“我一定会悲哀地下阴间，到我儿子那里。”约瑟的父亲就为约瑟哀哭。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="创世记 40:4; 创世记 37:28; 列王纪下 25:8"> 后来，那些米甸人把约瑟卖到埃及，卖给了法老的一个内臣，护卫长波提乏。</span>
</div>
</div>

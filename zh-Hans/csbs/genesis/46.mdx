<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 28:13; 创世记 26:22–25; 创世记 28:10"> 以色列带着一切属于他的起程了。他来到比尔-谢巴，向他父亲以撒的神献上祭物。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 15:1; 约伯记 33:14–15; 约伯记 4:13"> 神藉着夜间的异象对以色列说：“雅各！雅各！”<br />他说：“我在这里！”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 12:2; 申命记 26:5; 以赛亚书 43:1–2"> 神说：“我是神，是你父亲的神。你不要害怕下埃及去，因为我必使你在那里成为强大的民族。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 3:8; 创世记 28:15; 创世记 48:21"> 我要亲自与你一同下埃及去，也必定把你带上来。约瑟要亲手合上你的眼。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 45:21; 创世记 45:19; 创世记 45:27"> 雅各就从比尔-谢巴起程。以色列的儿子们让他们的父亲雅各，以及他们的孩童和妻子坐上了法老送来的车辆。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 24:4; 以赛亚书 52:4; 使徒行传 7:15"> 他们还带上牲畜和在迦南地所积蓄的财物。于是雅各和他所有的子孙都一同来到埃及。</span>
<span className="v" id="v7" data-v="7"> 这样，雅各带着他的儿子、孙子、女儿、孙女，他所有的子孙，一同来到了埃及。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 1:1–5; 申命记 33:6; 历代志上 2:1–55"> 雅各和他的子孙——来到埃及的以色列人——他们的名字如下：<br /><span className="pl pl-1">雅各的长子鲁本，</span><br /></span>
<span className="v" id="v9" data-v="9"> <span className="pl pl-1">鲁本的儿子哈诺、法路、希斯伦、迦米；</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 6:15; 创世记 29:33; 创世记 28:1"> <span className="pl pl-1">西缅的儿子耶姆利、雅悯、阿辖、雅斤、琐哈尔，以及扫罗——迦南女子的儿子；</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="创世记 29:34; 历代志上 6:16; 民数记 8:1–26"> <span className="pl pl-1">利未的儿子革顺、哥辖、米拉利；</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 4:21; 创世记 38:10; 创世记 29:35"> <span className="pl pl-1">犹大的儿子珥、俄南、示拉、法勒斯、谢拉，其中珥和俄南在迦南地死了，而法勒斯的儿子是希斯伦、哈姆勒；</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 12:32; 创世记 35:23; 创世记 30:14–18"> <span className="pl pl-1">以萨迦的儿子陀拉、普瓦、约伯、希姆仑；</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="申命记 33:18–19; 民数记 26:26–27; 民数记 1:30–31"> <span className="pl pl-1">西布伦的儿子西列德、埃隆、雅赫列</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="创世记 29:32–35; 创世记 30:17–21; 创世记 34:1–31"> <span className="pl pl-1">——以上是莉亚在帕旦-亚兰为雅各所生的儿孙，不包括女儿狄娜，子孙共有三十三人——</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="民数记 26:15–17; 创世记 30:11; 民数记 1:24–25"> <span className="pl pl-1">迦得的儿子济非云、哈基、书尼、伊兹本、伊利、阿罗迪、阿尔耶利；</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="创世记 49:20; 创世记 30:13; 民数记 1:13"> <span className="pl pl-1">亚设的儿子伊姆纳、伊施瓦、伊施韦、比利亚，还有他们的妹妹西拉，其中比利亚的儿子是希伯、玛结</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="创世记 29:24; 创世记 35:26; 创世记 30:9–13"> <span className="pl pl-1">——以上是悉帕的子孙，悉帕是拉班给他女儿莉亚的婢女</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="婢女——辅助词语。">a</a></sup><br /><span className="pl pl-1">，悉帕为雅各生了这些人，共有十六人——</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="创世记 44:27; 创世记 29:18; 创世记 35:24"> <span className="pl pl-1">雅各的妻子拉结的儿子约瑟、便雅悯；</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="创世记 41:50–52; 创世记 41:45; 申命记 33:13–17"> <span className="pl pl-1">玛拿西和以法莲是安城的祭司波提·非拉的女儿娅希纳在埃及地为约瑟所生的；</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 7:6–12; 历代志上 8:1–7; 民数记 26:38–40"> <span className="pl pl-1">便雅悯的儿子比拉、比结、阿实别、基拉、奈曼、伊希、罗实、慕皮姆、户皮姆、阿尔德</span><br /></span>
<span className="v" id="v22" data-v="22"> <span className="pl pl-1">——以上是拉结为雅各所生的儿孙，共有十四人——</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="民数记 1:38–39; 创世记 49:16–17; 民数记 1:12"> <span className="pl pl-1">但的儿子户西姆；</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 7:13; 民数记 1:42–43; 创世记 35:25"> <span className="pl pl-1">拿弗他利的儿子雅赫兹列、古尼、耶则尔、谢勒姆</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="创世记 29:29; 创世记 35:25; 创世记 30:3–8"> <span className="pl pl-1">——以上是碧拉的儿孙，碧拉是拉班给他女儿拉结的婢女</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="婢女——辅助词语。">b</a></sup><br /><span className="pl pl-1">，碧拉为雅各生了这些人，共有七人。</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 1:5; 创世记 35:11; 士师记 8:30"> 所有雅各的直系子孙，不包括他的儿媳们，来到埃及的共有六十六人；</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 10:22; 使徒行传 7:14; 出埃及记 1:5"> 另有约瑟在埃及所生的两个儿子，雅各家先后来到埃及的总共有七十人。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="创世记 45:10; 创世记 44:16–34; 创世记 49:8"> 雅各打发犹大先到约瑟那里，请约瑟指示前往歌珊的路<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="的路——辅助词语。">c</a></sup>。他们就这样来到了歌珊地。</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 15:20; 创世记 45:14–15; 创世记 33:4"> 约瑟备好座车，上到歌珊去迎接他的父亲以色列。他一到父亲的面前，就伏在父亲的脖子上，在父亲的脖子上哭了很久。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 2:29–30; 创世记 45:28"> 以色列对约瑟说：“既然我看见你的面，知道你还活着，现在我就是死也甘心。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="创世记 47:1–3; 希伯来书 2:11; 使徒行传 18:3"> 约瑟对他的兄弟们和他的父家说：“我要上到法老那里禀告说：‘我在迦南地的兄弟们和我的父家都来到了我这里。</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 47:3; 列王纪上 9:27; 列王纪上 18:5–6"> 这些人是牧羊的，是牧养牲畜的人；他们把羊群、牛群和一切属于他们的都带来了。’</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 46:32; 创世记 47:2–4; 约拿书 1:8"> 当法老召见你们并问你们：‘你们以什么为业呢？’</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 8:26; 创世记 43:32; 创世记 46:32"> 你们就要回答：‘你仆人们从年幼时直到现在，都是牧养牲畜的人，我们祖祖辈辈都一样。’这样你们就可以住在歌珊地，因为所有牧羊的都是埃及人所憎恶的。”</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 18:15; 使徒行传 10:41; 创世记 43:30–31"> 约瑟在所有侍立左右的人面前，再也克制不住自己，大声喊：“所有人都离开我出去！”当约瑟向兄弟们表明自己是谁时，没有人站在他身边。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 46:29; 使徒行传 20:37; 民数记 14:1"> 他就放声大哭；埃及人听到了，法老一家也听到了这事。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 7:13; 使徒行传 9:5; 撒迦利亚书 12:10"> 约瑟对他的兄弟们说：“我是约瑟！我的父亲还活着吗？”他的兄弟们却不能回答他，因为他们在他面前都很惶恐。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="创世记 37:28; 马太福音 14:27; 创世记 50:18"> 约瑟对他的兄弟们说：“请你们靠近我一些！”他们就靠近一些。他说：“我是你们的兄弟约瑟，就是被你们卖到埃及的约瑟。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 50:20; 使徒行传 7:9–15; 创世记 45:7–8"> 现在，不要因你们把我卖到这里而自忧自恨；要知道，是神在你们之前派遣了我，为要拯救生命。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 47:23; 创世记 41:54; 创世记 41:56"> 如今，这地已经有两年的饥荒，还会有五年既没有耕种，也没有收成。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 44:4; 使徒行传 7:35; 诗篇 18:50"> 神在你们之前派遣了我，为要在地上给你们存留余种，并要大施解救，使你们得以存活<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="并要大施解救，使你们得以存活——或译作“使你们有众多的幸存者活下来”。">a</a></sup>。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 15:16; 罗马书 9:16; 约翰福音 19:11"> 这样看来，派遣我到这里来的，不是你们，而是神。他立我作法老之父，作他全家之主，又作埃及全地的管辖者。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 45:19–20; 创世记 45:13"> “你们赶快上到我父亲那里去，对他说：‘你的儿子约瑟这样说：“神立我作了全埃及的主；请你下到我这里来，不要耽延。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 9:26; 出埃及记 8:22; 创世记 46:34–6"> 你和你的众儿孙、你的羊群、牛群，以及一切属于你的，都可以住在歌珊地，在我的附近。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 47:12; 创世记 47:6; 马太福音 15:5–6"> 我要在那里供应你，免得你和你的家人，以及一切属于你的，都陷入穷困，因为还会有五年的饥荒。”’</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 42:23; 路加福音 24:39; 约翰福音 20:27"> 看哪，你们的眼睛和我弟弟便雅悯的眼睛都看见了，是我在亲口对你们说话。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 7:14; 启示录 21:23; 彼得前书 1:10–12"> 你们要把我在埃及的一切尊荣，以及你们所看见的一切，都告诉我的父亲；赶快请我父亲下到这里来。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="创世记 33:4; 创世记 29:11; 创世记 46:29"> 然后约瑟就伏在他弟弟便雅悯的脖子上哭泣，便雅悯也在约瑟的脖子上哭泣。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 15:20; 撒母耳记上 10:1; 诗篇 77:4"> 约瑟又亲吻了所有的兄弟，在他们身上哭泣。此后，他的兄弟们就与他交谈。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="创世记 41:33; 以斯帖记 1:21; 创世记 20:15"> 约瑟的兄弟们到来的消息传到法老的宫殿里；这在法老和他的臣仆眼中都看为好。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 42:25–26; 创世记 44:1–2"> 法老对约瑟说：“你要对你的兄弟们说，‘当这样做：把牲畜驮好，回到迦南地去；</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 27:28; 民数记 18:12; 创世记 47:6"> 带上你们的父亲和你们的家人，到我这里来；我要把埃及地的美物赐给你们，你们也要吃这地上最好的。’</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 46:5; 创世记 45:27; 创世记 31:17–18"> 现在你要受命去说：‘当这样做：从埃及地带上车辆，给你们的孩童和妻子坐，并且带着你们的父亲一起来。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 1:19; 路加福音 17:31; 申命记 7:16"> 你们的眼目不要顾惜你们的家什，因为埃及全地的美物都是你们的。’”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 45:19; 以西结书 23:24; 耶利米哀歌 1:18"> 以色列的儿子们就这样做了。约瑟照着法老的吩咐，给了他们车辆和路上用的食物，</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 43:34; 列王纪下 5:5; 士师记 14:12"> 又给了每个哥哥一人一套更换的衣服，却给了便雅悯三百锭银子和五套服装；</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 24:10; 出埃及记 16:3; 创世记 43:11"> 约瑟送给他父亲公驴十头，驮着埃及的美物；母驴十头，驮着谷物、饼，以及他父亲路上用的食物。</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦前书 5:13; 诗篇 133:1–3; 创世记 42:21–22"> 于是，约瑟打发他的兄弟们走；他们离开的时候，约瑟对他们说：“你们在路上不要争吵。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 他们就从埃及上去，来到迦南地他们的父亲雅各那里。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 44:28; 创世记 37:35; 路加福音 24:34"> 他们告诉他说：“约瑟还活着，而且作了埃及全地的管辖者。”雅各的心惊呆了，因为他简直不能相信他们。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 85:6; 以赛亚书 57:15; 创世记 45:19"> 他们就把约瑟对他们所说的一切话都告诉了他。当他们的父亲雅各看见约瑟派来接他的车辆时，他的灵就苏醒了。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 2:28–30; 约翰福音 16:21–22; 创世记 46:30"> 以色列说：“好，我的儿子约瑟还活着！在我死之前，我要去见他。”</span>
</div>
</div>

</div>

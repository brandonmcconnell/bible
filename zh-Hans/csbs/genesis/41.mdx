<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 20:3; 创世记 29:14; 出埃及记 4:9"> 过了整整两年，法老做了一个梦，梦见自己正站在尼罗河边。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 19:6"> 看哪！有七头健美肥壮的母牛从尼罗河里上来，在芦苇中吃草。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 41:20–21; 创世记 41:4"> 看哪！随后又有七头丑陋瘦弱的母牛从尼罗河里上来，站在河岸上那些母牛旁边。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 3:15"> 这些丑陋瘦弱的母牛竟吃掉了那七头健美肥壮的母牛。法老就醒过来了。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 32:14"> 然后他又睡着，做了第二个梦。看哪！有七个丰硕美好的穗子在一根秆上长起来。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 17:10; 何西阿书 13:15; 以西结书 19:12"> 看哪！随后又长出七个被东风吹焦的细弱穗子。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 37:5; 创世记 20:3"> 这些细弱的穗子竟吞掉了那七个丰硕饱满的穗子。法老就醒过来了。看哪，原来又是一个梦！</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="但以理书 4:7; 出埃及记 7:22; 马太福音 2:1"> 到了早晨，法老灵里烦乱，就派人召来了埃及所有的术士和智慧人。法老向他们讲述了他的梦，但没有人能为法老解梦。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 40:14; 创世记 40:23; 创世记 40:1–3"> 那时司酒长对法老说：“我今天想起了我的罪过。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 39:20; 创世记 40:2–3; 创世记 37:36"> 法老曾对臣仆发怒，把我和司膳长关在护卫长府中的牢里。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 40:5–8"> 在同一夜，我和他都做了梦，各梦各有其解。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 40:12–19; 创世记 37:36; 创世记 39:1"> 在那里有一个希伯来少年与我们在一起，是护卫长的奴仆。我们把梦向他讲述，他就照着我们各自的梦分别为我们解梦。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 43:3; 创世记 40:20–22; 创世记 40:12"> 后来，事情正是像他给我们解释的那样发生了：法老使我官复原位，却把司膳长挂了起来。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="但以理书 2:25; 诗篇 113:7–8; 诗篇 105:19–22"> 于是法老派人去召约瑟，他们就急忙把他从地牢里带出来。他剃头刮脸，更换衣服，来到法老面前。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理书 5:16; 但以理书 5:12; 诗篇 25:14"> 法老对约瑟说：“我做了一个梦，但无人能解。我听人说，你听了梦就能解。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 3:5; 创世记 40:8; 但以理书 2:47"> 约瑟就回答法老，说：“不是我，是神要回应法老，关乎法老的平安。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 法老对约瑟说：“在梦里，看哪！我正站在尼罗河岸。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 24:8; 耶利米书 24:1–3; 耶利米书 24:5"> 看哪！有七头肥壮健美的母牛从尼罗河里上来，在芦苇中吃草。</span>
<span className="v" id="v19" data-v="19"> 看哪！随后又有七头衰弱、干瘦、甚丑的母牛上来；我在埃及全地没有见过像它们那样丑的。</span>
<span className="v" id="v20" data-v="20"> 这些干瘦丑陋的母牛竟吃掉了先前那七头肥壮的母牛；</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 3:3; 诗篇 37:19; 启示录 10:9–10"> 虽然吃进了肚子，却看不出已经吃进去了，因为它们丑陋的样子仍与先前一样。我就醒了。</span>
<span className="v" id="v22" data-v="22"> 在梦里我又观看，看哪！有七个饱满美好的穗子在一根秆上长起来。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 129:6–7; 何西阿书 13:15; 列王纪下 19:26"> 看哪！随后又长出七个被东风吹焦的细弱枯槁的穗子。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理书 4:7; 创世记 41:8; 出埃及记 8:19"> 这些细弱的穗子竟吞掉了那七个美好的穗子。我告诉了术士们，但无人能给我解释。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="但以理书 2:45; 启示录 4:1; 以弗所书 1:17"> 约瑟就对法老说：“法老的两个梦原是一个，神已经把所要做的事告诉法老了。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 41:47; 创世记 41:2; 创世记 41:53"> 七头美好的母牛是七年，而七个美好的穗子也是七年。两个梦原是一个。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 8:1; 撒母耳记下 24:19"> 那随后上来的七头干瘦丑陋的母牛是七年，那七个被东风吹焦的空瘪穗子也是七年，都是七个荒年。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="创世记 41:25; 创世记 41:16"> “这就是我对法老说的：神已经把所要做的事向法老显明了。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 41:26; 创世记 41:46–47; 创世记 41:49"> 看哪！七个大丰年必临到埃及全地；</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 47:13; 创世记 41:54; 雅各书 5:17"> 随后七个荒年就来临，埃及地先前一切的丰收将被遗忘，饥荒必毁灭这地。</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 24:20; 撒母耳记上 5:6"> 那地先前的丰收一点也看不出来，因为随后而来的饥荒极其严重。</span>
<span className="v" id="v32" data-v="32" data-xref="民数记 23:19; 以赛亚书 46:10–11; 以赛亚书 14:24–27"> 至于同一个梦向法老重复了两次，是因为这事已被神命定，神必快速实施。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="创世记 41:39; 使徒行传 6:3; 申命记 1:13"> “现在，请法老选一个有悟性有智慧的人，委任他管理埃及地。</span>
<span className="v" id="v34" data-v="34" data-xref="箴言 22:3; 路加福音 16:5; 箴言 6:6–8"> 请法老付诸实施，指派监督们管理这地，在七个丰年中，征收埃及地收成的五分之一。</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 45:6–7; 创世记 41:56; 出埃及记 4:13"> 让他们收集将来丰年中的一切余粮，把谷物积蓄在法老手下<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="把谷物积蓄在法老手下——或译作“由法老授权积蓄谷物”。">a</a></sup>，作为各城的粮食，妥善保管。</span>
<span className="v" id="v36" data-v="36" data-xref="创世记 47:13–25"> 这些粮食是为了将临到埃及地的七个荒年而储备的，免得这地被饥荒所灭。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒行传 7:10; 列王纪上 21:2; 撒母耳记下 3:36"> 这提议在法老和他所有臣仆的眼中都看为好。</span>
<span className="v" id="v38" data-v="38" data-xref="约伯记 32:8; 但以理书 5:14; 民数记 27:18"> 法老对他的臣仆说：“像他这样的人，有神的灵在他里面，我们还能找得到吗？”</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 41:33; 创世记 41:28; 创世记 41:25"> 于是法老对约瑟说：“既然神把这一切都向你显明了，就没有像你这样有悟性有智慧的人了。</span>
<span className="v" id="v40" data-v="40" data-xref="箴言 22:29; 使徒行传 7:10; 诗篇 105:21–22"> 你要管理我的家；我所有的子民都要顺从你的话；只有在宝座上的我比你大。”</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 28:18; 腓立比书 2:9–11; 创世记 42:6"> 法老又对约瑟说：“你看，我已经委派你管理埃及全地。”</span>
<span className="v" id="v42" data-v="42" data-xref="但以理书 5:29; 但以理书 5:7; 以斯帖记 3:10"> 然后法老从自己手上取下印戒，戴在约瑟手上，给他穿上细麻衣，把金链戴在他的脖子上；</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行传 7:10; 创世记 45:8; 创世记 45:26"> 又让约瑟乘自己的副车，喝道的在约瑟前面向人呼喊：“跪下！”这样，法老委派他管理埃及全地。</span>
<span className="v" id="v44" data-v="44" data-xref="诗篇 105:22; 出埃及记 11:7"> 法老对约瑟说：“我是法老，但在埃及全地，没有你的许可<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="的许可——辅助词语。">b</a></sup>，谁也不能擅自行事<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="擅自行事——原文直译“抬手抬脚”。">c</a></sup>。”</span>
<span className="v" id="v45" data-v="45" data-xref="创世记 46:20; 以西结书 30:17; 出埃及记 2:16"> 法老给约瑟起名为撒发那特·巴内亚，又把安城祭司波提·非拉的女儿娅希纳给他为妻。约瑟就出去管理埃及地。</span>
<span className="v" id="v46" data-v="46" data-xref="但以理书 1:19; 列王纪上 12:6; 撒母耳记上 16:21"> 约瑟侍立在埃及王法老面前的时候，年三十岁。约瑟从法老面前出去，遍行埃及全地。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="创世记 26:12; 诗篇 72:16"> 在那七个丰年中，地的出产极其丰盛，</span>
<span className="v" id="v48" data-v="48" data-xref="创世记 41:34–36; 创世记 47:21"> 约瑟把临到埃及地那七年的一切余粮都收集起来，把它们存放在各城中；各城周围田地的余粮，他都存放在该城中。</span>
<span className="v" id="v49" data-v="49" data-xref="诗篇 78:27; 士师记 6:5; 创世记 22:17"> 约瑟积蓄的谷物极其多，如海沙那样，实在无法数算，以致他停止了计量。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="创世记 46:20; 创世记 48:5; 撒母耳记下 8:18"> 荒年未到以前，安城的祭司波提·非拉的女儿娅希纳为约瑟生了两个儿子。</span>
<span className="v" id="v51" data-v="51" data-xref="诗篇 30:5; 箴言 31:7; 申命记 33:17"> 约瑟给长子起名为玛拿西，因为他说<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="他说——辅助词语。">d</a></sup>：“神使我忘了我一切的苦难和我父的全家。”</span>
<span className="v" id="v52" data-v="52" data-xref="创世记 49:22; 创世记 50:23; 创世记 17:6"> 他给第二个儿子起名为以法莲，因为他说<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="他说——辅助词语。">e</a></sup>：“神使我在受苦之地繁盛。”</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="创世记 41:29–31; 诗篇 73:20; 路加福音 16:25"> 埃及地的七个丰年一结束，</span>
<span className="v" id="v54" data-v="54" data-xref="创世记 45:11; 使徒行传 7:11; 诗篇 105:16"> 七个荒年就随着来了，正如约瑟所说的。各地都有饥荒，但埃及全地还有粮食。</span>
<span className="v" id="v55" data-v="55" data-xref="马太福音 17:5; 马太福音 3:17; 耶利米书 14:1–6"> 当埃及全地也有饥荒时，百姓就向法老哀求粮食。法老对所有的埃及人说：“你们到约瑟那里去，他对你们怎么说，你们就怎么做。”</span>
<span className="v" id="v56" data-v="56" data-xref="创世记 42:6; 撒迦利亚书 5:3; 路加福音 21:35"> 那时饥荒遍及了整个地面。约瑟打开了各处的粮仓，售粮给埃及人，因为埃及地的饥荒非常严重。</span>
<span className="v" id="v57" data-v="57" data-xref="创世记 41:54; 创世记 42:5; 创世记 41:56"> 各地的人都来到埃及，向约瑟买粮，因为各地的饥荒都非常严重。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以弗所书 4:24; 歌罗西书 3:10; 创世记 1:26–27"> 以下是亚当谱系的记录：<br />在神创造人的日子，神按着自己的样式造人；</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 19:4; 马可福音 10:6; 创世记 2:23"> 神创造了男人和女人；在他们被创造的日子，神祝福他们，给他们起名为“人”。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 4:25; 约伯记 25:4; 诗篇 51:5"> 亚当活到一百三十岁时，生了一个儿子，样式和形象与自己相似；给他起名为塞特。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 1:1–3; 路加福音 3:36–38; 创世记 5:26"> 亚当生了塞特之后，他的年日又有八百年，并且生了其他的儿女。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 5:8; 创世记 5:11; 创世记 3:19"> 这样亚当一生活了九百三十年，然后他死了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 4:26"> 塞特活到一百零五岁时，生了以挪士。</span>
<span className="v" id="v7" data-v="7"> 塞特生了以挪士之后，又活了八百零七年，并且生了其他的儿女。</span>
<span className="v" id="v8" data-v="8"> 这样塞特一生活了九百一十二年，然后他死了。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 3:37; 历代志上 1:2"> 以挪士活到九十岁时，生了该南。</span>
<span className="v" id="v10" data-v="10"> 以挪士生了该南之后，又活了八百一十五年，并且生了其他的儿女。</span>
<span className="v" id="v11" data-v="11"> 这样以挪士一生活了九百零五年，然后他死了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="路加福音 3:37"> 该南活到七十岁时，生了玛勒列。</span>
<span className="v" id="v13" data-v="13"> 该南生了玛勒列之后，又活了八百四十年，并且生了其他的儿女。</span>
<span className="v" id="v14" data-v="14"> 这样该南一生活了九百一十年，然后他死了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="历代志上 1:2"> 玛勒列活到六十五岁时，生了雅列。</span>
<span className="v" id="v16" data-v="16"> 玛勒列生了雅列之后，又活了八百三十年，并且生了其他的儿女。</span>
<span className="v" id="v17" data-v="17"> 这样玛勒列一生活了八百九十五年，然后他死了。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="创世记 4:17; 历代志上 1:3; 犹大书 1:14–15"> 雅列活到一百六十二岁时，生了以诺。</span>
<span className="v" id="v19" data-v="19"> 雅列生了以诺之后，又活了八百年，并且生了其他的儿女。</span>
<span className="v" id="v20" data-v="20"> 这样雅列一生活了九百六十二年，然后他死了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 3:37"> 以诺活到六十五岁时，生了玛土撒拉。</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒罗尼迦前书 2:12; 创世记 17:1; 创世记 6:9"> 以诺生了玛土撒拉之后，与神同行三百年，并且生了其他的儿女。</span>
<span className="v" id="v23" data-v="23"> 这样以诺一生活了三百六十五年。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 11:5–6; 约翰一书 1:7; 创世记 5:22"> 以诺与神同行；后来他不在地上<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="地上——辅助词语。">a</a></sup>了，因为神把他接去。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 4:18"> 玛土撒拉活到一百八十七岁时，生了拉麦。</span>
<span className="v" id="v26" data-v="26"> 玛土撒拉生了拉麦之后，又活了七百八十二年，并且生了其他的儿女。</span>
<span className="v" id="v27" data-v="27"> 这样玛土撒拉一生活了九百六十九年，然后他死了。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 拉麦活到一百八十二岁时，生了一个儿子，</span>
<span className="v" id="v29" data-v="29" data-xref="彼得后书 2:5; 希伯来书 11:7; 马太福音 24:37"> 给他起名为挪亚，说：“这儿子将安慰我们，使我们脱离我们的苦工和手中的辛苦——这是因为耶和华诅咒了这地。”</span>
<span className="v" id="v30" data-v="30"> 拉麦生了挪亚之后，又活了五百九十五年，并且生了其他的儿女。</span>
<span className="v" id="v31" data-v="31"> 这样拉麦一生活了七百七十七年，然后他死了。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="创世记 6:10; 创世记 10:21; 创世记 9:18–19"> 挪亚五百岁时，生了闪、含、雅弗。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 1:32–33; 创世记 23:1–2; 创世记 28:1"> 亚伯拉罕又娶了一个妻子，名叫基土拉。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 1:32–33; 民数记 25:17–18; 约伯记 2:11"> 基土拉为他生了新兰、约珊、米但、米甸、伊施巴和书亚。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 25:13; 耶利米书 49:8; 以西结书 27:20"> 约珊生了示巴和底但。底但的子孙就是亚书利人、利杜史人和利乌米人。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 60:6"> 米甸的儿子是以法、以弗、哈诺、亚比大和以勒大。以上全都是基土拉的子孙。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 24:36; 希伯来书 1:2; 加拉太书 3:29"> 亚伯拉罕把自己所拥有的一切都给了以撒。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 21:14; 士师记 6:3; 使徒行传 14:17"> 至于亚伯拉罕众妾的儿子，亚伯拉罕也给了他们礼物，在自己还活着的时候，就打发他们离开他的儿子以撒往东，到东方之地去。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="创世记 12:4"> 亚伯拉罕一生所活的年日有一百七十五年。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 35:28–29; 创世记 15:15; 历代志上 29:28"> 亚伯拉罕尽享天年，寿高年迈，气绝而死，归到他的先人那里。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 50:13; 创世记 35:29; 创世记 49:29–30"> 他的儿子以撒和以实玛利把他葬在幔利对面、赫提人琐哈尔的儿子以弗仑田中的麦比拉洞穴里；</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 23:16; 创世记 49:31"> 那块地是亚伯拉罕从赫提的子孙那里买来的。亚伯拉罕和他的妻子撒拉都葬在那里。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 22:17; 创世记 16:14; 创世记 24:62"> 亚伯拉罕死了以后，神祝福他的儿子以撒；以撒在比珥-拉海-罗伊附近住下。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="诗篇 83:6; 创世记 17:20; 创世记 21:13"> 以下是亚伯拉罕的儿子以实玛利的家系记事：以实玛利是撒拉的婢女埃及人夏甲为亚伯拉罕所生的。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 1:29–31; 以赛亚书 60:7; 雅歌 1:5"> 以实玛利的儿子，按着他们的家系，名字如下：以实玛利的长子是尼拜约，然后是基达、亚德别、米比衫、</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 21:11; 以赛亚书 21:16"> 米施玛、度玛、玛撒、</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 5:19; 约伯记 2:11"> 哈达、提玛、伊突、拿非施和基底玛。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 17:20; 创世记 17:23"> 这些是以实玛利的儿子，他们的名字就成了自己村庄和营寨的名字，他们也成了十二个部族的族长。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 15:15; 创世记 25:7–8"> 以实玛利一生的年岁是一百三十七岁。他气绝而死，归到他的先人那里。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 16:12; 创世记 20:1; 列王纪下 23:29"> 他子孙的居住之地从哈腓拉到书珥，书珥在埃及对面、通往亚述方向的路上；以实玛利与他所有兄弟对立而居。</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="马太福音 1:2; 路加福音 3:34; 使徒行传 7:8"> 以下是亚伯拉罕的儿子以撒的家系记事：亚伯拉罕生以撒。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 24:29; 创世记 24:67; 创世记 22:23"> 以撒娶莉百加为妻的时候正四十岁；莉百加是帕旦-亚兰地的亚兰人彼土利的女儿，是亚兰人拉班的妹妹。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:13; 以赛亚书 58:9; 以斯拉记 8:23"> 以撒因妻子不能生育就为她向耶和华祈求。耶和华应允了他的祈求，他的妻子莉百加就怀了孕。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 9:9; 撒母耳记上 28:6; 撒母耳记上 30:8"> 两个胎儿在她里面彼此挤压<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="挤压——或译作“相争”。">a</a></sup>，她就说：“这样的话，为什么这事发生在我身上呢？”于是她去求问耶和华。</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 9:10–13; 创世记 27:40; 创世记 27:29"> 耶和华对她说：<br /><span className="pl pl-1">“两国在你的腹中，</span><br /><span className="pl pl-1">两族将从你里面分出来；</span><br /><span className="pl pl-1">一族要比另一族强，</span><br /><span className="pl pl-1">将来大的要服事小的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 到了生产的日子，看哪，莉百加腹中果然是双胞胎！</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 27:11; 创世记 27:16; 创世记 27:23"> 第一个出来的身体通红，遍体是毛，如同毛皮衣；于是给他起名为以扫。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 27:36; 何西阿书 12:3; 创世记 38:28–30"> 随后，弟弟也出来了，他的一只手抓住以扫的脚跟；于是给他起名为雅各。莉百加生他们的时候，以撒正六十岁。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="希伯来书 11:9; 创世记 21:20; 创世记 10:9"> 两个孩子渐渐长大，以扫成为一个打猎能手，常在田野；而雅各是一个安静的人，常在帐篷里。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 27:19; 创世记 27:31; 创世记 27:4"> 以撒爱以扫，因为爱吃野味，而莉百加却爱雅各。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="箴言 13:25; 以赛亚书 40:30–31; 撒母耳记上 14:28"> 有一天，雅各熬好了汤；这时以扫从田野回来，筋疲力尽。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 36:1; 出埃及记 15:15; 创世记 36:9"> 以扫就对雅各说：“请你让我喝一些红汤，就这红汤；我已筋疲力尽了！”因此他的名字又称为以东。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31"> 雅各就说：“你现在就把长子的名份卖给我！”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="玛拉基书 3:14; 约伯记 21:15; 约伯记 22:17"> 以扫说：“看哪，我都快死了，这长子的名份对我还有什么用呢？”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="希伯来书 12:16; 创世记 27:36; 希伯来书 6:16"> 雅各说：“你现在就向我起誓！”以扫就向他起誓，把自己长子的名份卖给了雅各。</span>
<span className="v" id="v34" data-v="34" data-xref="腓立比书 3:18–19; 希伯来书 12:16–17; 哥林多前书 15:32"> 于是雅各把饼和豆汤给了以扫；以扫吃喝完，就起来走了。以扫就这样轻视了长子的名份。</span>
</div>
</div>

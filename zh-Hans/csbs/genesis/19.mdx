<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="GEN" data-book-slug="genesis" data-book-name="创世记" data-chapter="19" data-verses="38">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 18:22; 创世记 18:1–5; 希伯来书 13:2"> 那两位天使在傍晚来到所多玛；当时罗得正坐在所多玛城门口。罗得一见他们，就起身迎接，脸伏于地下拜，</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 18:4; 路加福音 24:28–29; 希伯来书 13:2"> 说：“我主啊，请转往你们的仆人家里过夜，洗洗你们的脚，清早起来再上路。”<br />他们却说：“不，我们就在广场上过夜。”</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 18:6–8; 士师记 6:19; 撒母耳记上 28:24"> 但罗得极力劝说他们，他们才转往他那里，进了他的家。罗得为他们预备宴席，烤了无酵饼，他们就吃了。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="创世记 13:13; 箴言 4:16; 出埃及记 23:2"> 他们还没有躺下睡觉，那城里的人，就是所多玛的男人，无论老少，所有人都从各处来围住了罗得的屋子。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 19:22; 以赛亚书 3:9; 犹大书 1:7"> 他们向罗得呼叫，说：“今夜到你这里来的那些男人在哪里呢？把他们给我们带出来，好让我们与他们同寝！”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="士师记 19:23"> 罗得就出去，到门口众人那里，并把身后的门关上，</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 6:9–11; 士师记 19:23; 利未记 20:13"> 说：“我的兄弟们，请你们不要这样作恶。</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 19:24; 创世记 19:31–38; 士师记 9:15"> 看哪，我有两个女儿，还没有与男人同寝，容我把她们带出来给你们，你们看怎样好，就怎样对待她们吧。只是不要对这两个人做什么，因为他们来到了我屋檐的荫庇下。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 2:14; 彼得后书 2:7–8; 创世记 13:12"> 但他们说：“滚开！”又说：“这人来寄居，竟然把自己当成审判官了！我们要恶待你，比恶待他们更厉害。”于是他们极力推挤罗得，上前要破门而入。</span>
<span className="v" id="v10" data-v="10"> 那两个人就伸出手，把罗得拉进屋内他们那里，并把门关上。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 6:18; 使徒行传 13:11; 申命记 28:28–29"> 他们又打击屋门口的那些人，使他们无论老少都眼目失明，以致他们找不到门<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="找不到门——原文直译“找门找得疲惫不堪”。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 7:1; 彼得后书 2:7; 启示录 18:4"> 那两个人对罗得说：“你在这里还有什么人吗？比如你的女婿、儿女，或是城中任何属于你的人，你都要从这地方带出去，</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 18:20; 马太福音 13:49–50; 犹大书 1:7"> 因为我们就要毁灭这地方了；要知道，控告他们的呼声在耶和华面前极大，耶和华就派我们来毁灭这城。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 16:21; 耶利米书 51:6; 民数记 16:45"> 罗得就出去，告诉将要娶他女儿的女婿们说：“起来！离开这地方，因为耶和华就要毁灭这城了！”但在他们的眼中，他像是在开玩笑。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数记 16:24–27; 启示录 18:4; 创世记 19:22"> 天亮的时候，天使们催促罗得说：“起来！带着你的妻子和你在这里的两个女儿离开，免得你因这城的罪孽被一同除灭。”</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 9:15–16; 提多书 3:5; 约翰福音 6:44"> 罗得还在犹豫，那两个人因耶和华怜恤罗得就抓住他的手，以及他妻子和两个女儿的手，把他们领出来，安置在城外面。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 24:16–18; 路加福音 9:62; 腓立比书 3:13–14"> 那两个人把他们领到外面以后，其中一位说：“逃命吧！不要向后看，也不要在周边地区的任何一处停留；要逃到山上，免得你被除灭。”</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 13:6–8; 使徒行传 10:14; 创世记 32:26"> 罗得对他们说：“我主啊，请不要这样。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 27:1; 诗篇 103:1–22; 提摩太前书 1:14–16"> 看哪，你的仆人在你眼前已经蒙了恩，你向我大施慈爱，使我的性命得以存活。不过，我不能逃到山上；恐怕这灾祸追上我，我就死了。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 119:175; 箴言 3:5–7; 创世记 19:30"> 看哪，这城足够近，我能逃到那里，而且它只是个小地方——它不是一个小地方吗？请让我逃到那里去，使我的性命得以存活。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="诗篇 145:19; 诗篇 34:15; 诗篇 102:17"> 天使对他说：“看哪，这事我也答应你，不会倾覆你所说的这城。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 13:10; 创世记 14:2; 创世记 32:25–28"> 你赶快逃到那里，因为你到达那里之前，我什么也不能做。”因此那城名叫琐珥。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 罗得到达琐珥的时候，太阳已经升出地面。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 29:23; 以赛亚书 13:19; 阿摩司书 4:11"> 那时，耶和华就使硫磺与火从天而降，从耶和华那里降在所多玛和格摩拉，</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 107:34; 创世记 14:3; 创世记 13:10"> 使那些城和整个周边地区，连同各城所有的居民和地上生长的都遭覆灭。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 17:31–32; 创世记 19:17; 箴言 14:14"> 罗得的妻子在后面回头一望，就变成了一根盐柱。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="哈巴谷书 2:1; 诗篇 5:3; 希伯来书 2:1"> 亚伯拉罕清早起来，到了他曾在耶和华面前站立的地方。</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 18:9; 启示录 9:2; 启示录 21:8"> 他俯看所多玛和格摩拉，以及周边地区的整个地面；看哪，只见那地有烟上腾，像窑炉的烟那样！</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 8:1; 申命记 9:5; 创世记 18:23–33"> 当神毁灭周边地区的众城、倾覆罗得住过的各城时，神记念亚伯拉罕，将罗得从覆灭中带出来。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="创世记 19:19; 以赛亚书 15:5; 雅各书 1:8"> 罗得因为怕住在琐珥，就与两个女儿离开琐珥上了山，住在山上。他和两个女儿住在一个洞穴里。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 25:5; 以赛亚书 4:1; 创世记 16:2"> 大女儿对小女儿说：“我们的父亲老了，这地又没有男人照着世上的常理与我们同房。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 18:6–7; 创世记 11:3; 创世记 9:21"> 来吧！让我们给父亲喝酒，然后与他同睡，好藉着我们的父亲存留后裔！”</span>
<span className="v" id="v33" data-v="33" data-xref="哈巴谷书 2:15–16; 箴言 23:29–35; 箴言 20:1"> 于是那天夜里她们给父亲喝酒，然后大女儿进去，与父亲同睡。她什么时候躺下，什么时候起来，父亲都不知道。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="耶利米书 8:12; 耶利米书 6:15; 以赛亚书 3:9"> 第二天，大女儿对小女儿说：“看哪，昨夜我与父亲同睡了！今夜我们再给他喝酒，然后你进去与他同睡，好藉着我们的父亲存留后裔！”</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 24:16; 诗篇 8:4; 彼得前书 4:7"> 那天夜里她们又给父亲喝酒，然后小女儿起来，与他同睡。她什么时候躺下，什么时候起来，父亲都不知道。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="哈巴谷书 2:15; 士师记 1:7; 马太福音 7:2"> 这样，罗得的两个女儿都藉着她们的父亲怀了孕。</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 2:9; 列王纪下 3:1–27; 民数记 21:29"> 大女儿生了一个儿子，给他起名为摩押，他就是今天摩押人的始祖。</span>
<span className="v" id="v38" data-v="38" data-xref="申命记 2:19; 士师记 10:6–40; 诗篇 83:4–8"> 至于小女儿，她也生了一个儿子，给他起名为便亚米，他就是今天亚扪子孙的始祖。</span>
</div>
</div>

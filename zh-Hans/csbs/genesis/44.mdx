<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 42:25; 创世记 43:16; 创世记 24:2"> 约瑟吩咐管家说：“给他们的袋子装满粮食，他们能带多少就装多少，并且把各人的银子放在各自的袋子口。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 8:8; 创世记 42:20; 申命记 8:16"> 然后把我的杯子——那只银杯，放在最小兄弟的袋子口，连同他买粮的银子都放进去。”管家就照着约瑟所说的话去做了。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3"> 早晨天一亮，那些人和他们的驴子都被打发走了。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 10:32; 诗篇 35:12; 箴言 17:13"> 他们刚出城，走了不远，约瑟就对管家说：“起来，追赶那些人！追上后就对他们说：‘你们为什么以恶报善呢？</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 30:27; 利未记 19:26; 列王纪下 21:6"> 这不是我主人喝酒的杯子吗？要知道，我主人必定会用它来占卜。你们这样做就是作恶了！’”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 管家就追上了他们，向他们说了这些话。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 38:16–18; 创世记 37:18–32; 列王纪下 8:13"> 他们对他说：“我主为什么说这样的话呢？你的仆人们绝不会做这样的事。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 43:12; 创世记 42:35; 罗马书 13:9"> 看哪，我们先前在袋子口发现的银子，尚且从迦南地带回来给你，我们又怎么会从你主人的家偷窃金银呢？</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 31:32; 诗篇 7:3–5; 约伯记 31:38–40"> 从你哪个仆人那里找到杯子，他就要死，而且我们其余的人就都作我主的奴仆。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及记 22:3; 创世记 44:17; 创世记 44:33"> 管家说：“那么就照着你们的话做吧！只是从谁那里找到杯子，谁就作我的奴仆，而你们其余的人都没有罪。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 于是他们急忙把自己的袋子卸在地上，各人都打开自己的袋子。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 44:26–32; 创世记 42:36–38; 创世记 43:14"> 管家就搜查，从年长的开始，到最小的为止；结果，那杯子在便雅悯的袋子里找到了。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 1:11; 创世记 37:29–34; 撒母耳记下 1:2"> 他们就撕裂衣服，各人把东西驮在驴上，又回到城里。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="创世记 50:18; 创世记 43:25; 创世记 43:16"> 当犹大和他的兄弟们来到约瑟家时，约瑟还在那里，他们就在他面前俯伏于地。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 4:10; 创世记 21:26; 创世记 3:13"> 约瑟对他们说：“你们做的这是什么事呢？难道你们不知道像我这样的人必定会占卜吗？”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="创世记 44:9; 但以理书 9:7; 民数记 32:23"> 犹大说：“我们能对我主说什么呢？我们还能说什么呢？我们怎能证明自己无辜呢？神找出了你仆人们的罪孽。看哪，无论是我们还是从他手中找到杯子的那个人，现在都是我主的奴仆了！”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="箴言 17:15; 撒母耳记下 23:3; 创世记 18:25"> 可是约瑟说：“我绝不能这样做！在谁手中找到杯子，谁就必作我的奴仆。至于你们其余的人，平平安安地上到你们父亲那里去吧！”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 32:22; 创世记 41:40; 创世记 18:30"> 犹大靠近约瑟，说：“哦，我主啊，你就像法老一样，求你让仆人说句话给我主听，不要让你的怒气向仆人发作。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 43:7; 创世记 43:29; 创世记 42:7–10"> 我主曾问仆人们说：‘你们还有父亲或其他兄弟吗？’</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 37:3; 创世记 42:38; 路加福音 7:12"> 我们回答我主：‘我们还有年老的父亲和最小的弟弟，他是父亲年老时生的孩子，他的哥哥死了，他是他母亲留下来唯一的孩子，所以父亲很疼爱他。’</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 42:15; 创世记 42:20; 阿摩司书 9:4"> 你就对仆人们说：‘把他带下来到我这里，我要亲眼看看他。’</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 44:30; 创世记 42:38"> 我们对我主说：‘那少年不能离开他父亲；如果离开了，他父亲就会死。’</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 43:5; 创世记 43:3; 创世记 42:15–20"> 但你对仆人们说：‘要是你们最小的弟弟不与你们一起下来，你们就再也不得见我的面。’</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="创世记 42:29–34"> “我们上到你仆人我父亲那里去的时候，就把我主的话告诉了他。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 43:2; 创世记 43:5"> 后来，我们的父亲说：‘你们再回去为我们买些粮食来。’</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 11:7; 创世记 43:4–5"> 我们就说：‘我们不能下去。要是我们最小的弟弟与我们同去，我们才下去；因为要是最小的弟弟不与我们同去的话，我们就不能见那人的面。’</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 46:19; 创世记 35:16–18; 创世记 30:22–25"> 你仆人我父亲对我们说：‘你们知道我的妻子为我生了两个儿子。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 37:33; 创世记 37:13–14; 创世记 42:36"> 一个已经离我而去了，我想他必定是被野兽撕碎了；直到现在，我再也没有见过他。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 42:38; 创世记 43:14; 申命记 31:17"> 如果你们再把这个从我面前带走，要是有灾祸临到他，你们就使白发苍苍的我悲悲惨惨地下阴间去了。’</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 18:1; 撒母耳记下 18:33; 创世记 44:31"> “现在如果我回到你仆人我父亲那里，而那少年没有与我们在一起，既然我父亲的命与那少年的命相连，</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 44:29; 创世记 37:35; 哥林多后书 7:10"> 我父亲见那少年不在了，就必会死。这样，你仆人们就使你仆人我们的父亲，一个白发苍苍的老人，悲悲惨惨地下阴间去了。</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 43:8–9; 创世记 43:16"> 你的仆人曾经为了那少年的缘故向父亲担保，说：‘如果我不把他带回来给你，我就在父亲面前终身担罪。’</span>
<span className="v" id="v33" data-v="33" data-xref="约翰一书 3:16; 出埃及记 32:32; 希伯来书 7:22"> 现在，请你把仆人留下，代替那少年作我主的奴仆，让那少年与他的哥哥们一同上去。</span>
<span className="v" id="v34" data-v="34" data-xref="以斯帖记 8:6; 诗篇 116:3; 诗篇 119:143"> 因为如果那少年没有与我在一起，我怎能上到我父亲那里去呢？恐怕我看见祸患临到我父亲。”</span>
</div>
</div>

</div>

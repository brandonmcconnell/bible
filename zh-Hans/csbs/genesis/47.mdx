<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="GEN" data-book-slug="genesis" data-book-name="创世记" data-chapter="47" data-verses="31">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 45:10; 创世记 46:31; 创世记 46:28"> 约瑟去禀告法老说：“我的父亲和我的兄弟们带着羊群、牛群和一切属于他们的，从迦南地来了，现在他们就在歌珊地。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="使徒行传 7:13; 歌罗西书 1:28; 犹大书 1:24"> 约瑟从他兄弟中挑了五个人，引见他们来到法老面前。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 46:33–34; 帖撒罗尼迦后书 3:10; 创世记 4:2"> 法老问约瑟的兄弟们：“你们以什么为业呢？”<br />他们回答法老：“你仆人们是牧羊的，我们祖祖辈辈都一样。”</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 46:34; 创世记 15:13; 申命记 26:5"> 他们又对法老说：“我们来是要在这地寄居，因为迦南地的饥荒严重，你仆人们的羊群没有草场了；现在求你容许仆人们住在歌珊地。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 法老对约瑟说：“你的父亲和兄弟们到你这里来了；</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 18:21; 箴言 22:29; 创世记 47:11"> 埃及地都在你面前，就让你的父亲和兄弟们在最好的地安置下来，他们可以住在歌珊地。你如果知道他们中间有才能的人，就安排他们看管我的牲畜。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="创世记 47:10; 撒母耳记下 8:10; 撒母耳记上 2:20"> 约瑟又把他父亲雅各带进来，让他站在法老面前，雅各就为法老祝福。</span>
<span className="v" id="v8" data-v="8"> 法老问雅各：“你多大岁数了？”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="诗篇 39:12; 诗篇 39:5; 约伯记 14:1"> 雅各回答法老：“我在世寄居的年日有一百三十年了；我一生的年日又少又苦，不及我祖先在世寄居的年日。”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 47:7; 诗篇 129:8; 希伯来书 7:7"> 雅各又为法老祝福，就从法老面前出去了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="创世记 47:6; 出埃及记 1:11; 出埃及记 12:37"> 约瑟照着法老的吩咐让他的父亲和兄弟们安置下来，在埃及地赐给他们产业，就是拉美西斯境内最好的土地。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 45:11; 提摩太前书 5:8; 创世记 47:1"> 约瑟按孩童的人数，供应粮食给他的父亲、他的兄弟们以及他父亲的全家。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 7:11; 列王纪上 18:5; 耶利米哀歌 4:9"> 当时全地都没有粮食，因为饥荒极其严重；埃及地和迦南地都因饥荒的缘故而衰竭。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 41:56; 路加福音 16:10–12; 路加福音 16:1–2"> 约瑟收聚了埃及地和迦南地能找到的所有银子，就是众人用来买粮的银子；约瑟把那些银子都交到法老家。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 8:8; 诗篇 37:3; 马太福音 6:11"> 当埃及地和迦南地的银子用尽之后，所有的埃及人都来到约瑟那里，说：“求你给我们粮食吧！难道银子用完了，我们就要死在你面前吗？”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 4:5; 但以理书 6:5–7; 哥林多前书 10:32"> 约瑟说：“如果银子用完了，可以把你们的牲畜带来。我就给你们粮食<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="粮食——辅助词语。">a</a></sup>，来换你们的牲畜。”</span>
<span className="v" id="v17" data-v="17" data-xref="约伯记 2:4; 出埃及记 9:3; 以赛亚书 31:1"> 于是，他们把牲畜带到约瑟那里，约瑟就给他们粮食，来换他们的马匹、羊群、牛群和驴。那一年，约瑟就给他们提供粮食，换了他们所有的牲畜。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王纪下 6:26; 耶利米书 38:9"> 那一年过后，次年他们又来到约瑟那里，对他说：“不瞒我主，我们的银子用尽了，牲畜也归了我主；除了我们的身体和土地以外，我们在我主面前一无所剩。</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米记 5:2–3; 约伯记 2:4; 耶利米哀歌 1:11"> 难道我们和我们的土地要在你眼前消亡吗？求你用粮食买我们和我们的土地，我们连人带地都必成为法老的奴仆；又求你给我们种子，使我们得以存活，不至于死，地也不至于荒芜。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 于是，约瑟为法老买了埃及所有的土地，因为饥荒重压埃及人，他们各人都卖了自己的田地。这样，埃及全地都成为法老的了；</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 41:48"> 至于百姓，约瑟从埃及边界一端到另一端都使他们成了奴隶<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="成了奴隶——依据七十士译本；马索拉文本作“迁到城里”。">b</a></sup>。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯拉记 7:24; 尼希米记 13:10; 帖撒罗尼迦后书 3:10"> 只有祭司的土地，约瑟没有买，因为祭司有从法老而来的份例；他们可以吃法老所给的份例，所以不用卖自己的土地。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="诗篇 112:5; 诗篇 41:1; 传道书 11:6"> 约瑟对百姓说：“看哪，我今日为法老买了你们和你们的土地。看，这些是给你们的种子，你们可以种地了。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 41:34; 诗篇 41:1; 诗篇 112:5"> 到了收获的时候，你们要把收成的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="收成的——辅助词语。">c</a></sup>五分之一交给法老，五分之四归你们自己，作为田里的种子以及你们、你们家人和孩童的食物。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 33:15; 箴言 11:26–27; 创世记 18:3"> 他们说：“你使我们存活了；愿我们在我主眼前蒙恩，我们必作法老的奴仆。”</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 47:22; 以西结书 7:24"> 于是约瑟为埃及的土地立下定例，直到今日还有效，就是地上收成的五分之一归法老；唯独祭司的土地不归法老。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="创世记 46:3; 出埃及记 1:7; 使徒行传 7:17"> 以色列人住在埃及的歌珊地。他们在那里置了产业，并且繁衍，大大增多。</span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 90:10; 创世记 47:8–9; 创世记 37:2"> 雅各又在埃及地活了十七年；他一生的年日有一百四十七年。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 31:14; 创世记 24:49; 创世记 24:2"> 以色列死的日子临近了，就叫来他儿子约瑟，对他说：“如果我在你眼前蒙恩，请你把手放在我大腿底下，以恩慈和真诚对待我，请你不要把我葬在埃及。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 49:29–32; 创世记 23:19; 创世记 25:9"> 我与我祖先长眠的时候，你要把我带出埃及，把我葬在他们的安葬之地。”<br />约瑟说：“我必照着你的吩咐去做。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪上 1:47; 希伯来书 11:21; 创世记 24:3"> 雅各说：“你要向我起誓。”约瑟就向他起誓。于是以色列就在床头敬拜<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="敬拜——原文直译“下拜”。">d</a></sup>。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 17:17"> 撒拉活了一百二十七岁，这是撒拉一生的年岁。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 23:19; 创世记 13:18; 历代志上 6:57"> 撒拉死在迦南地的基列-阿尔巴，就是希伯仑；亚伯拉罕前来为撒拉哀恸哭泣。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 10:15; 创世记 23:7; 撒母耳记上 26:6"> 然后亚伯拉罕从死者身旁起来，对赫提的子孙说：</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 29:15; 希伯来书 11:9; 创世记 17:8"> “我在你们中间是外人，是寄居的；请把你们中间的一块地产给我作坟地，好让我把死者从我身旁移去安葬。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 赫提的子孙回应亚伯拉罕，说：</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 24:35; 创世记 14:14; 出埃及记 32:22"> “我主啊，请听我们说！你在我们中间是尊贵的领袖<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="尊贵的领袖——或译作“神的宠臣”。">a</a></sup>，请在我们最好的坟地安葬你的死者吧！我们中没有一个人会阻止你在他的坟地安葬你的死者。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="希伯来书 12:14; 创世记 19:1; 箴言 18:24"> 亚伯拉罕就起来，向那地的民众赫提的子孙下拜，</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 25:9; 约翰一书 2:1–2; 列王纪上 2:17"> 对他们说：“如果你们有心让我把死者从我身旁移去安葬，就听我说，为我请求琐哈尔的儿子以弗仑，</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 13:8; 罗马书 12:17"> 把他田边的麦比拉洞穴卖给我，并按足价在你们面前卖给我，作为我拥有的坟地。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 34:20; 创世记 34:24; 创世记 23:18"> 当时以弗仑正坐在赫提的子孙中间。赫提人以弗仑就回应亚伯拉罕，当着所有来到城门口的赫提子孙的面<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="面——原文直译“耳朵”。">b</a></sup>，说：</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:24; 以赛亚书 32:8; 申命记 19:15"> “不，我主啊，请听我说！我把这块田地送给你，其中的洞穴也送给你。我在我族人眼前把它送给你；你安葬你的死者吧！”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 23:7; 创世记 18:2; 创世记 19:1"> 亚伯拉罕就在那地的民众面前下拜，</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 13:8; 撒母耳记下 24:24; 创世记 14:22–23"> 然后当着那地民众的面<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="面——原文直译“耳朵”。">c</a></sup>，对以弗仑说：“如果你愿意，就请听我说！我要把这块田地的价银付给你，请你收下，好让我在那里安葬我的死者。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 以弗仑回应亚伯拉罕，说：</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 45:12; 出埃及记 30:13; 出埃及记 30:15"> “我主啊，请听我说！四百谢克尔<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="四百谢克尔——相当于4.6公斤；下同。1谢克尔=11.4公克。">d</a></sup>银子的这块地，在你我之间算什么呢？你安葬你的死者吧！”</span>
<span className="v" id="v16" data-v="16" data-xref="撒迦利亚书 11:12; 耶利米书 32:9; 出埃及记 30:13"> 亚伯拉罕听了，就照以弗仑在赫提子孙面前<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="面前——原文直译“耳朵”。">e</a></sup>所说的价银，给他称了四百谢克尔商用的银子。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 25:9; 创世记 50:13; 创世记 23:20"> 这样，以弗仑的那块田地，就是幔利对面在麦比拉的田地，包括其中的洞穴和地界内所有的树木，</span>
<span className="v" id="v18" data-v="18" data-xref="路得记 4:1; 耶利米书 32:12; 创世记 34:20"> 在所有来到城门口的赫提子孙眼前，转给亚伯拉罕作他的财产。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 50:13; 传道书 12:7; 传道书 12:5"> 此后亚伯拉罕把他的妻子撒拉葬在迦南地，幔利对面、麦比拉田中的洞穴里；幔利就是希伯仑。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 32:10–14; 路得记 4:7–10; 创世记 49:31–32"> 于是那块田地和其中的洞穴，由赫提的子孙转给了亚伯拉罕，作为他拥有的坟地。</span>
</div>
</div>

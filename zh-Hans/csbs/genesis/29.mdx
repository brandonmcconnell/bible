<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 6:3; 士师记 6:33; 何西阿书 12:12"> 雅各继续他的行程，来到东方人之地。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 4:14; 以赛亚书 49:10; 约翰福音 4:6"> 他观看，看哪，田野中有一口井！看哪，有三群羊卧在井旁，因为那口井是供给羊群饮水的。井口上有一块大石头；</span>
<span className="v" id="v3" data-v="3"> 只有当所有羊群聚拢在那里时，牧人们才会把那块石头从井口上滚开，给羊群饮水，然后再把那块石头放回井口的原处。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="创世记 28:10; 创世记 27:43; 使徒行传 7:2"> 雅各问牧人们：“我的兄弟们，你们从哪里来？”<br />他们说：“我们从哈兰来。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 24:24; 创世记 24:29; 创世记 31:53"> 他问他们：“你们认识拿鹤的孙子拉班吗？”<br />他们说：“我们认识。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 20:9; 创世记 37:14; 出埃及记 18:7"> 雅各接着问他们：“他平安吗？”<br />他们说：“平安。看哪，他女儿拉结与羊群一同来了！”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以弗所书 5:16; 加拉太书 6:9–10"> 雅各说：“看哪，现在日头还高，不是聚拢牲畜的时候；你们给羊群饮了水就去放牧吧！”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="马可福音 16:3; 路加福音 24:2; 创世记 34:14"> 他们说：“我们不能这么做！要到所有的羊群都聚拢，石头从井口挪开后，我们才能给羊群饮水。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 2:21; 雅歌 1:7–8; 出埃及记 2:15–16"> 雅各正与他们说话时，拉结带着她父亲的羊群来了，因为她是牧羊女。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 2:17"> 雅各看见他舅舅拉班的女儿拉结和他舅舅拉班的羊群，就过去把石头从井口上滚开，给他舅舅拉班的羊群饮水。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 33:4; 创世记 45:14–15; 创世记 45:2"> 雅各亲吻了拉结，就放声大哭。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 24:28; 创世记 13:8; 创世记 14:14–16"> 雅各告诉拉结，自己是她父亲的外甥，是莉百加的儿子。拉结就跑去告诉她父亲。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 24:29; 使徒行传 20:37; 罗马书 16:16"> 拉班一听见他外甥雅各的消息，就跑去迎接他、拥抱他、亲吻他，然后把他带回自己的家里。雅各就向拉班讲述了一切的经过。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 19:12–13; 创世记 2:23; 士师记 9:2"> 拉班对他说：“你实在是我的骨肉。”<br />雅各就与他同住了一个月。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 30:28; 创世记 31:7"> 拉班对雅各说：“难道因为你是我的亲人，就要让你无偿地服事我吗？告诉我吧，你要什么工酬？”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路得记 4:11; 创世记 49:31; 创世记 31:4"> 拉班有两个女儿，大的名叫莉亚，小的名叫拉结。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 12:11; 创世记 46:19–22; 创世记 24:16"> 莉亚目光呆滞<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="呆滞——或译作“温柔”。">a</a></sup>，拉结身材秀美、容貌秀丽。</span>
<span className="v" id="v18" data-v="18" data-xref="何西阿书 12:12; 出埃及记 22:16–17; 创世记 34:12"> 雅各爱拉结，就说：“我愿意为你的小女儿拉结服事你七年。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 6:11; 以赛亚书 6:5; 诗篇 12:2"> 拉班说：“我把她交给你，比交给别人更好；你就与我一起住吧。”</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 13:7; 以弗所书 5:2; 何西阿书 12:12"> 于是雅各为拉结的缘故服事了七年；因他对拉结的爱，在他眼中看这七年如同几天。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="士师记 15:1; 创世记 29:20; 创世记 4:1"> 雅各对拉班说：“日期满了，求你把我的妻子给我，好让我与她同房。”</span>
<span className="v" id="v22" data-v="22" data-xref="启示录 19:9; 路得记 4:10–13; 士师记 14:10–18"> 拉班就招聚了那地方所有的人，摆设宴席。</span>
<span className="v" id="v23" data-v="23" data-xref="弥迦书 7:5; 创世记 38:14–15; 创世记 24:65"> 到了傍晚，拉班把自己的女儿莉亚带来给雅各，雅各就与她同房。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 16:1; 创世记 30:9–12; 创世记 46:18"> 拉班又把自己的婢女悉帕给女儿莉亚作婢女。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马太福音 7:2; 箴言 11:31; 哥林多前书 3:13"> 到了早晨，看哪，她是莉亚！雅各就对拉班说：“你对我做的这是什么呢？我服事你，难道不是为了拉结吗？你为什么欺骗我？”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 拉班就说：“大女儿出嫁<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="出嫁——辅助词语。">b</a></sup>前先把小女儿给人，在我们这地方不这么做。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 18:18; 士师记 14:12; 创世记 2:2–3"> 过完大女儿的新婚周，我们就把小女儿也给你，来换取你对我另外七年的服事。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 雅各就这样做，过完了莉亚的新婚周。然后，拉班把自己的女儿拉结给了雅各为妻。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 35:22; 创世记 29:24; 创世记 30:3–8"> 拉班又把自己的婢女碧拉给女儿拉结作婢女。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 31:41; 创世记 29:20; 创世记 31:15"> 雅各也与拉结同房，并且爱拉结胜过爱莉亚。他又服事了拉班另外七年。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒母耳记上 2:21; 马太福音 10:37; 申命记 21:15"> 耶和华见莉亚被嫌弃<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="嫌弃——或译作“恨”。">c</a></sup>，就使她能生育<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="使她能生育——原文直译“开了她的胎”。">d</a></sup>；拉结却不能生育。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 26:7; 出埃及记 4:31; 出埃及记 3:7"> 莉亚怀孕，生了一个儿子，给他起名为鲁本，因为她说：“耶和华看见了我的苦情；现在我的丈夫一定会爱我。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="创世记 34:25; 创世记 49:5–6; 创世记 34:30"> 她又怀孕，生了一个儿子，就说：“耶和华因为听见我被嫌弃，所以又赐给我这个儿子。”于是给孩子起名为西缅。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="出埃及记 32:26–29; 创世记 49:5–7; 创世记 46:11"> 她又怀孕，生了一个儿子，就说：“这次我丈夫必与我结合，因为我为他生了三个儿子。”因此给这孩子起名为利未。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 1:2; 历代志上 5:2; 创世记 49:8–12"> 她又怀孕，生了一个儿子，就说：“这次我要称谢耶和华。”因此给孩子起名为犹大。然后她停止了生育。</span>
</div>
</div>

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="创世记 9:7; 创世记 1:28; 创世记 8:17"> 神祝福挪亚和他的儿子们，对他们说：“你们要繁衍增多，充满大地。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 8:4–8; 创世记 1:28; 雅各书 3:7"> 地上的一切走兽、天空的一切飞鸟、地上的一切爬虫、海里的一切鱼类，都会畏惧你们、害怕你们；这一切都交在你们手中了。</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 14:14; 歌罗西书 2:21–22; 哥林多前书 10:31"> 凡是有生命的动物，都可以作你们的食物；我把这一切赐给了你们，就像我把绿色植物赐给你们一样。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 12:23; 申命记 15:23; 申命记 12:16"> 只是带着生命之血的肉，你们不可吃。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 21:28–29; 出埃及记 21:12; 创世记 4:9–10"> 至于你们的生命之血，我必为你们追讨：我要向走兽追讨；我也要向人，甚至向各人的兄弟追讨人命。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 24:17; 马太福音 26:52; 启示录 13:10"> <span className="pl pl-1">那杀人流血的，</span><br /><span className="pl pl-1">他必被杀流血，</span><br /><span className="pl pl-1">因为神是按照自己的形象造人的。</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="创世记 1:28; 创世记 9:1; 创世记 9:19"> 你们要繁衍增多，充满大地，在其上增多。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 接着神告诉挪亚以及与他一起的儿子们说：</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 6:18; 以赛亚书 54:9–10; 罗马书 1:3"> “看哪，我要与你们以及你们的后裔确立我的约；</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 8:1; 创世记 9:15–16; 诗篇 36:5–6"> 并与所有和你们在一起的活物，包括飞鸟、牲畜和地上的一切走兽，就是与所有从方舟里出来的地上活物立约。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 54:9; 创世记 8:21–22; 创世记 7:21–23"> 我要与你们确立我的约：一切有血肉的，都不再被洪水灭绝；洪水不再毁灭全地。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 17:11; 马太福音 26:26–28; 出埃及记 12:13"> 神又说：“以下是我与你们以及同你们在一起的各样活物所立之约的标记——直到未来所有的世代：</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 1:28; 启示录 4:3; 启示录 10:1"> 我把我的彩虹放在云中，它就是我与大地立约的标记。</span>
<span className="v" id="v14" data-v="14"> 当我聚起云遮盖大地时，彩虹会出现在云中，</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 7:9; 以西结书 16:60; 以赛亚书 54:8–10"> 我就会记念我与你们以及一切有血肉的活物所立的约，水就不再成为洪水，来毁灭一切有血肉的。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 54:8–10; 耶利米书 32:40; 撒母耳记下 23:5"> 当彩虹出现在云中，我就会看到，就会记念我<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我——原文直译“神”。">a</a></sup>与地上一切有血肉的活物所立的永远之约。”</span>
<span className="v" id="v17" data-v="17"> 神对挪亚说：“这就是我与地上一切有血肉的所立之约的标记。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="创世记 10:1; 创世记 10:6; 创世记 9:25–27"> 挪亚的儿子，从方舟出来的，就是闪、含、雅弗；含是迦南的父亲。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 1:4–28; 创世记 8:17; 创世记 5:32"> 这三人是挪亚的儿子，全地的人都是从他们分散出来的。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命记 20:6; 箴言 10:11; 以赛亚书 28:24–26"> 挪亚开始作农夫<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="农夫——原文直译“土地的人”。">b</a></sup>，种植了一个葡萄园。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 20:1; 哈巴谷书 2:15–16; 箴言 23:31–32"> 他喝了葡萄酒，就醉了，在自己的帐篷中赤身露体。</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 30:17; 加拉太书 6:1; 马太福音 18:15"> 迦南的父亲含，看见自己父亲的下体，就去告诉他在外面的两个兄弟。</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 6:1; 出埃及记 20:12; 提摩太前书 5:17"> 于是闪和雅弗拿了一件外衣，搭在他们两人的肩膀上，倒退着进去遮盖他们父亲的下体；他们背着脸，就没有看见他们父亲的下体。</span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24"> 挪亚酒醒以后，知道了小儿子向他所做的事，</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 9:23; 申命记 27:16; 士师记 1:28–30"> 就说：<br /><span className="pl pl-1">“迦南是受诅咒的！</span><br /><span className="pl pl-1">他必作自己兄弟们奴仆的奴仆。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="诗篇 144:15; 创世记 12:1–3; 路加福音 3:23–36"> 又说：<br /><span className="pl pl-1">“耶和华——闪的神是当受颂赞的！</span><br /><span className="pl pl-1">愿迦南作闪的奴仆。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 11:12; 罗马书 15:12; 希伯来书 11:9–10"> <span className="pl pl-1">愿神使雅弗扩张，</span><br /><span className="pl pl-1">使他住在闪的帐篷中；</span><br /><span className="pl pl-1">愿迦南作雅弗的奴仆。”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 洪水之后，挪亚又活了三百五十年。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 5:27; 诗篇 90:10; 创世记 5:32"> 这样挪亚一生活了九百五十年，然后他死了。</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="GEN" data-book-slug="genesis" data-book-name="创世记" data-chapter="21" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 12:6; 创世记 18:10; 创世记 18:14"> 耶和华照着他所说的眷顾了撒拉，照着他所应许的为撒拉成就了。</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太书 4:22; 希伯来书 11:11; 创世记 18:10"> 撒拉怀了孕，到了神对亚伯拉罕说的那个所定的日期，在亚伯拉罕年老的时候，为他生了一个儿子。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 17:19; 罗马书 9:7; 创世记 21:6"> 亚伯拉罕给撒拉为他所生的儿子，起名为以撒。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 7:8; 申命记 12:32; 约翰福音 7:22–23"> 亚伯拉罕在儿子以撒生下来的第八天，照着神所吩咐的，给他行了割礼。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 17:17; 罗马书 4:19; 创世记 17:1"> 他儿子以撒出生的时候，亚伯拉罕正一百岁。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="诗篇 126:2; 以赛亚书 54:1; 创世记 17:17"> 撒拉说：“神使我欢笑，所有听见的人也必与我一同欢笑。”</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 18:11–12; 以赛亚书 66:8; 帖撒罗尼迦后书 1:10"> 她又说：“当年会有人对亚伯拉罕说‘撒拉将乳养孩子’吗？我竟然在他年老的时候，为他生了一个儿子。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 1:22; 何西阿书 1:8; 创世记 40:20"> 孩子长大了，断了奶。在以撒断奶的那一天，亚伯拉罕摆设了盛大的宴席。</span>
<span className="v" id="v9" data-v="9" data-xref="加拉太书 4:29; 创世记 16:15; 加拉太书 4:22"> 撒拉看见埃及人夏甲为亚伯拉罕所生的儿子在一边嘲笑<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="在一边嘲笑——七十士译本作“与自己的儿子以撒一起玩耍”。">a</a></sup>，</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 8:35; 约翰一书 2:19; 加拉太书 4:22–31"> 就对亚伯拉罕说：“你要把这女仆和她的儿子赶出去，因为这女仆的儿子不可与我的儿子以撒一同作继承人。”</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 12:11; 创世记 17:18; 马太福音 10:37"> 由于这事关乎他的儿子，亚伯拉罕就极其愁烦。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 11:18; 罗马书 9:7–8; 创世记 17:19"> 神对亚伯拉罕说：“不要因这少年和你的女仆而愁烦。撒拉对你说的一切，你都要听从，因为从以撒而出的，才被称为你的后裔。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 16:10; 创世记 17:20; 创世记 21:18"> 至于这女仆的儿子，我也会使他成为一国，因为他是你的后裔。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="传道书 9:10; 诗篇 119:60; 创世记 16:7"> 于是亚伯拉罕清早起来，拿了饼和一皮袋水，交给夏甲，放在她的肩膀上，又把孩子交给了她，然后送她走。她就走了，在比尔-谢巴旷野中漂流。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 3:9; 诗篇 63:1; 耶利米书 14:3"> 皮袋里的水喝完了，夏甲就把孩子撇在一丛灌木底下，</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 49:15; 创世记 29:11; 撒母耳记上 24:16"> 然后走开，坐在对面大约一箭远的地方，因为她想：“我不忍心看这孩子死去。”她坐在对面，放声大哭。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 16:11; 诗篇 50:15; 出埃及记 3:7"> 神听见那少年的哭声，神的使者就从天上向夏甲呼唤，对她说：“夏甲，你怎么了？不要害怕，因为神已经听见了那少年在那里的哭声。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 21:13; 创世记 16:10; 创世记 17:20"> 起来！扶起这少年，用手扶持他，因为我要使他成为一个强大的民族。”</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 22:31; 列王纪下 6:17–20; 以赛亚书 35:5–6"> 神打开了夏甲的眼睛，她就看见一口水井，于是走过去把皮袋倒满了水，给那少年喝。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 28:15; 创世记 39:21; 创世记 16:12"> 神与那少年同在；他渐渐长大，住在旷野中，成了射箭能手。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 26:34–35; 创世记 24:3–4; 民数记 12:16"> 他住在帕兰旷野，他母亲从埃及地为他娶了妻子。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约书亚记 3:7; 创世记 26:26; 创世记 26:28"> 在那段时期，亚比米勒和他军队的首领非革对亚伯拉罕说：“在你所做的一切事上，神都与你同在。</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 2:12; 创世记 20:14; 希伯来书 6:16"> 现在，请你在这里指着神向我起誓，你绝不以诡诈对待我，以及我的子孙后裔；我怎样以恩慈对待你，你也要怎样对待我和你所寄居的这地。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="希伯来书 6:16; 创世记 14:13; 罗马书 12:18"> 亚伯拉罕说：“我愿意起誓。”</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 26:15–22; 创世记 29:8; 箴言 25:9"> 同时，亚伯拉罕因亚比米勒的仆人们抢占了一口水井，指责了亚比米勒。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="创世记 13:7; 列王纪下 5:20–24"> 亚比米勒说：“我不知道谁做了这事，你也没有告诉过我，我今天才听到。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="创世记 14:22–23; 以赛亚书 32:8; 罗马书 1:31"> 于是亚伯拉罕牵来牛羊，送给亚比米勒，他们两人就立了约。</span>
<span className="v" id="v28" data-v="28"> 亚伯拉罕又从羊群中分出七只母羊羔另放一处。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记上 15:14; 创世记 33:8; 出埃及记 12:26"> 亚比米勒问亚伯拉罕：“你分出来另放一处的这七只母羊羔，是作什么的呢？”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="创世记 31:52; 约书亚记 24:27; 约书亚记 22:27–28"> 亚伯拉罕说：“你要从我手中接受这七只母羊羔，作我挖这口井的见证。”</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 26:33; 创世记 21:14; 列王纪上 4:25"> 因此那地方被称为比尔-谢巴，因为他们两人在那里起了誓。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 13:17; 创世记 21:27; 士师记 13:1"> 这样他们在比尔-谢巴立了约，然后亚比米勒和他军队的首领非革就起身，回到非利士人之地。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="提摩太前书 1:17; 以赛亚书 40:28; 诗篇 90:2"> 亚伯拉罕在比尔-谢巴栽种了一棵柽柳树，在那里呼求永恒之神耶和华的名。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志上 29:15; 彼得前书 2:11; 希伯来书 11:9"> 亚伯拉罕在非利士人之地寄居了许多日子。</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 11:17; 雅各书 2:21; 申命记 8:2"> 这些事以后，神试验亚伯拉罕，对他说：“亚伯拉罕！”<br />他说：“我在这里！”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="约翰福音 3:16; 罗马书 8:32; 希伯来书 11:17"> 神说：“带上你的儿子，就是你所爱的独生子以撒，往摩利亚地去；在我将要指示你的山上，把他献为燔祭。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="诗篇 119:60; 马太福音 10:37; 路加福音 14:26"> 亚伯拉罕清早起来，给自己的驴子备好鞍，带上他的两个仆人和他的儿子以撒。他劈好了燔祭用的木柴，就起身往神指示他的地方去。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 13:32; 马太福音 17:23; 何西阿书 6:2"> 到了第三天，亚伯拉罕举目，从远处看见了那地方。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 11:19; 希伯来书 12:1"> 亚伯拉罕对他的仆人们说：“你们和驴子留在这里吧，我和这少年要到那里去敬拜<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="敬拜——原文直译“下拜”。">a</a></sup>，然后再回到你们这里来。”</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 19:17; 彼得前书 2:24; 以赛亚书 53:6"> 亚伯拉罕拿起燔祭用的木柴，放在他儿子以撒身上，自己手中拿着火和刀；他们两人就一同前行。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:15; 马太福音 26:39; 创世记 8:20"> 以撒对父亲亚伯拉罕说：“父亲哪！”<br />亚伯拉罕说：“我儿啊，我在这里！”<br />以撒说：“看哪，火和木柴都有了，但燔祭用的羔羊在哪里呢？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约翰福音 1:36; 约翰福音 1:29; 启示录 5:12"> 亚伯拉罕说：“我儿啊，神必亲自预备燔祭用的羔羊！”他们两人就一同前行。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="雅各书 2:21; 希伯来书 11:17–19; 腓立比书 2:7–8"> 他们来到神所指示他的地方，亚伯拉罕在那里筑了一座祭坛，摆好木柴，然后捆绑了他的儿子以撒，把他放在祭坛的木柴上。</span>
<span className="v" id="v10" data-v="10" data-xref="雅各书 2:21–23; 希伯来书 11:17–19; 以赛亚书 53:6–12"> 亚伯拉罕就伸手拿刀，要宰杀自己的儿子。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="创世记 21:17; 出埃及记 3:4; 创世记 16:9–10"> 这时耶和华的使者从天上向他呼唤，说：“亚伯拉罕！亚伯拉罕！”<br />他说：“我在这里！”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="雅各书 2:21–22; 雅各书 2:18; 撒母耳记上 15:22"> 使者说：“不可向这少年下手，什么也不可对他做！现在我知道你是敬畏神的，因为你没有把你的儿子，就是你的独生子，留下不给我。”</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 10:13; 诗篇 40:6–8; 哥林多后书 1:9–10"> 亚伯拉罕举目观看，看哪，身后有一只公绵羊，犄角被灌木丛缠住了！亚伯拉罕就走过去，取了那只公绵羊，代替自己的儿子献为燔祭。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 22:13; 出埃及记 17:15; 创世记 22:8"> 亚伯拉罕给那地方起名为“耶和华以勒”；因此直到今日，人们还说：“在耶和华的山上必有预备<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="必有预备——或译作“他会显现”。">b</a></sup>。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 耶和华的使者第二次从天上向亚伯拉罕呼唤，</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 6:13–14; 路加福音 1:73; 诗篇 105:9"> 说：“耶和华宣告：我指着自己起誓，你既然做了这事，没有留下你的儿子，就是你的独生子，</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 15:5; 创世记 24:60; 耶利米书 33:22"> 我必定大大祝福你，使你的后裔大大增多，如同天上的星、海边的沙；你的后裔必占有仇敌的城门。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 3:25; 创世记 12:3; 加拉太书 3:16"> 地上万国都必因你的后裔而蒙福，因为你听从了我的话。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="创世记 21:31; 士师记 20:1; 约书亚记 15:28"> 然后亚伯拉罕回到他的仆人们那里，他们就起身一同往比尔-谢巴去。亚伯拉罕住在比尔-谢巴。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 11:29; 创世记 24:24; 箴言 25:25"> 这些事以后，有人告诉亚伯拉罕说：“看哪，米尔卡为你兄弟拿鹤生了儿子：</span>
<span className="v" id="v21" data-v="21" data-xref="约伯记 1:1; 约伯记 32:2; 诗篇 60:1–12"> 长子是乌斯，他的弟弟是布斯和亚兰的父亲基姆利，</span>
<span className="v" id="v22" data-v="22"> 还有基瑟德、哈琐、皮珥达、益拉和彼土利。”</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 24:15; 创世记 28:5; 创世记 24:51"> 彼土利生了莉百加。米尔卡为亚伯拉罕的兄弟拿鹤生了这八个儿子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="儿子——辅助词语。">c</a></sup>。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 16:3; 创世记 25:6; 箴言 15:25"> 拿鹤的妾名叫琉玛，她生了特巴、迦含、塔哈斯和玛迦。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 11:3; 哥林多后书 11:14; 启示录 12:9"> 在耶和华神所造的田野各样活物中，蛇是最狡猾的。它对女人说：“难道神真说过，你们不可吃这园子中任何树上的果实吗？”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="诗篇 58:4"> 女人对蛇说：“园子中树上的果实，我们可以吃，</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 2:16–17; 哥林多后书 6:17; 出埃及记 19:12–13"> 只有园子中间那棵树上的果实，神说过‘你们不可吃，也不可碰，免得你们死。’”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰福音 8:44; 哥林多后书 11:3; 提摩太前书 2:14"> 蛇却对女人说：“你们不一定死，</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 28:2; 帖撒罗尼迦后书 2:4; 哥林多后书 11:13–15"> 因为神知道：你们吃那果实的日子，眼睛就开了，你们就会像神一样知道善恶。”</span>
<span className="v" id="v6" data-v="6" data-xref="约翰一书 2:16; 雅各书 1:14–15; 提摩太前书 2:14"> 女人见那棵树的果实<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="的果实——辅助词语。">a</a></sup>好作食物，又悦人眼目，并且因使人有智慧而令人喜爱，就摘下果实吃了，又给了与她在一起的丈夫，她丈夫也吃了。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 59:6; 创世记 2:25; 创世记 3:5"> 于是他们两人的眼睛开了，知道自己是赤身的，就把无花果树的叶子缝合起来，为自己做了腰上的遮盖。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="耶利米书 23:24; 箴言 15:3; 希伯来书 4:13"> 天起凉风的时候，那人和他的妻子听见耶和华神在园子里行走的声音，就躲藏在园子的树木中，避开耶和华神的面。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 4:9; 创世记 16:8; 创世记 18:20–21"> 耶和华神呼唤那人，对他说：“你在哪里？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 2:25; 诗篇 119:120; 以赛亚书 47:3"> 那人说：“我在园子里听见你的声音就害怕，因为我是赤身的；于是我躲藏了。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="罗马书 3:20; 创世记 4:10; 诗篇 50:21"> 耶和华说：“谁告诉你，你是赤身的呢？难道你吃了我吩咐你‘不可吃’的那棵树的果实<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="的果实——辅助词语。">b</a></sup>吗？”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="箴言 28:13; 雅各书 1:13–15; 约伯记 31:33"> 那人说：“你赐给我那与我在一起的女人——她把那棵树上的果实给了我，我就吃了。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 11:3; 提摩太前书 2:14; 创世记 4:10–12"> 耶和华神对女人说：“你做的这是什么呢？”女人说：“那蛇引诱了我，我就吃了。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="弥迦书 7:17; 以赛亚书 65:25; 诗篇 72:9"> 耶和华神就对蛇说：<br /><span className="pl pl-1">“因为你做了这事，</span><br /><span className="pl pl-1">你必受诅咒，比一切的牲畜和田野一切的走兽更甚。</span><br /><span className="pl pl-1">你必用肚腹行走，</span><br /><span className="pl pl-1">你一生所有的日子都必吃土。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 16:20; 约翰一书 3:8; 启示录 12:17"> <span className="pl pl-1">我要把仇恨放在你和女人之间，</span><br /><span className="pl pl-1">放在你的后裔和女人的后裔之间；</span><br /><span className="pl pl-1">女人的后裔要重创你的头，</span><br /><span className="pl pl-1">而你要重创他的脚跟。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="提多书 2:5; 歌罗西书 3:18; 哥林多前书 11:3"> 神对女人说：<br /><span className="pl pl-1">“我要大大增加你怀胎的辛苦，</span><br /><span className="pl pl-1">你必在痛苦中生孩子。</span><br /><span className="pl pl-1">你必恋慕你的丈夫，</span><br /><span className="pl pl-1">而他必管辖你。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="罗马书 8:20–22; 创世记 5:29; 以赛亚书 24:5–6"> 神又对亚当说：<br /><span className="pl pl-1">“因为你听从了你妻子的话，</span><br /><span className="pl pl-1">吃了我吩咐你‘不可吃’的那棵树的果实</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="的果实——辅助词语。">c</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">土地就因你的缘故受诅咒；</span><br /><span className="pl pl-1">你一生所有的日子都必辛苦，</span><br /><span className="pl pl-1">才能从土地得吃的。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 13:7; 约伯记 5:5; 以赛亚书 7:23"> <span className="pl pl-1">土地将给你长出荆棘和蒺藜；</span><br /><span className="pl pl-1">你也必吃田间的蔬草。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="传道书 12:7; 约伯记 34:15; 诗篇 104:29"> <span className="pl pl-1">你必汗流满面才有饭吃，</span><br /><span className="pl pl-1">直到你归回土地，</span><br /><span className="pl pl-1">因为你是从那里取出来的。</span><br /><span className="pl pl-1">你本是尘土，</span><br /><span className="pl pl-1">就要归回尘土。”</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 2:23; 马太福音 1:23; 创世记 5:29"> 那人给他妻子起名为夏娃，因为她是众生之母。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 61:10; 哥林多后书 5:21; 哥林多后书 5:2–3"> 耶和华神为亚当和他的妻子做了皮子衣服，给他们穿上。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="启示录 2:7; 启示录 22:14; 箴言 3:18"> 耶和华神说：“看哪，那人已经与我们相似<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="与我们相似——原文直译“像我们中的一个”。">d</a></sup>，知道善恶；现在恐怕他又伸出手，取生命树的果实来吃，那样他就会永远活着。”</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 4:2; 创世记 3:19; 创世记 4:12"> 于是耶和华神就把他赶出伊甸园，去耕耘土地——他本是从那里取出来的。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 1:7; 诗篇 104:4; 出埃及记 25:18–22"> 耶和华神驱逐了那人，又在伊甸园的东边安置了基路伯和四周旋转的火焰之剑，来看守通往<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="通往——辅助词语。">e</a></sup>生命树的道路。</span>
</div>

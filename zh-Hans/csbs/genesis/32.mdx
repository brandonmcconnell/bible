<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="GEN" data-book-slug="genesis" data-book-name="创世记" data-chapter="32" data-verses="32">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 91:11; 诗篇 34:7; 希伯来书 1:4"> 雅各继续他的行程。神的使者们与他相遇。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 2:8; 约书亚记 5:14; 约书亚记 21:38"> 雅各看见他们就说：“这是神的营地。”于是给那地方起名为玛哈念。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 25:30; 约书亚记 24:4; 申命记 2:5"> 雅各派遣使者们在他前面，到以东境内的西珥地，去他哥哥以扫那里。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前书 3:6; 路加福音 14:11; 创世记 33:8"> 雅各吩咐他们说：“你们要对我主以扫这样说：‘你的仆人雅各如此说：我在拉班那里寄居，滞留到现在。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 33:8; 创世记 33:15; 创世记 33:11"> 我有牛、驴、羊群、男仆和婢女；我派人来告诉我主，为要在你眼前蒙恩。’”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 33:1; 创世记 32:8; 创世记 32:11"> 使者们回到雅各那里，说：“我们到了你哥哥以扫那里，他正迎着你来，与他一起的还有四百人。”</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 35:3; 哥林多后书 1:8–10; 出埃及记 14:10"> 于是雅各极其害怕而且焦虑，就把与他一起的人，羊群、牛群和骆驼，分成两队。</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 10:16; 创世记 33:1–3"> 他想：“如果以扫来击杀一队，剩下的一队还可以逃脱。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 31:42; 诗篇 34:4–6; 创世记 31:3"> 雅各说：“我祖父亚伯拉罕的神，我父亲以撒的神耶和华啊，你曾对我说：‘回到你的本土本族，我必厚待你。’</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 18:35; 创世记 24:27; 撒母耳记下 7:18"> 你向你仆人所施的一切慈爱和信实，我一点也不配。我先前只带着一根杖过这约旦河，如今我却拥有这两队了。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 59:1–2; 箴言 18:19; 马太福音 6:13"> 求你救我脱离我哥哥以扫的手，因为我惧怕他，恐怕他来击杀我，连母亲和孩子也一同击杀。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 28:13–15; 希伯来书 6:17; 提多书 1:2"> 但你说过：‘我必定厚待你，使你的后裔如海沙那样，多得无法数清。’”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 18:16; 创世记 43:11; 箴言 19:6"> 那天晚上，雅各就在那里过夜。他从自己所拥有的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="自己所拥有的——原文直译“手上带来的”。">a</a></sup>东西中，选出给哥哥以扫的礼物：</span>
<span className="v" id="v14" data-v="14" data-xref="约伯记 1:3; 申命记 8:18; 约伯记 42:12"> 母山羊两百只，公山羊二十只，母绵羊两百只，公绵羊二十只，</span>
<span className="v" id="v15" data-v="15"> 哺乳的骆驼三十头和它们的幼仔，母牛四十头，公牛十头，母驴二十头，公驴十头；</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 33:8–9; 创世记 32:20; 箴言 2:11"> 分成一群一群的，交在仆人们手中，对他们说：“你们要在我前面先过去，使群和群之间保持一段距离。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 33:3"> 他吩咐领头的仆人说：“我哥哥以扫遇见你的时候，如果问你：‘你的主人是谁？你要到哪里去？在你前面的这些牲畜是谁的？’</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 32:4–5"> 你就回答：‘是你仆人雅各的，是送给我主以扫的礼物。看哪，他自己也在我们后面。’”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 他又吩咐第二个、第三个和所有跟在各群后面的仆人，说：“你们遇见以扫的时候，也要这样对他说，</span>
<span className="v" id="v20" data-v="20" data-xref="约伯记 42:8–9; 箴言 21:14; 创世记 43:11"> 并强调说：‘看哪，你的仆人雅各在我们后面。’”因为雅各想：“我先藉着在我前面先送去的礼物与他和解，然后再与他见面，或许他会接纳我。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 于是那些礼物在雅各前面先送了过去；而他那天晚上却在营中留宿。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 3:16; 申命记 2:37; 提摩太前书 5:8"> 他夜间起来，带着他的两个妻子、两个婢女和十一个孩子，过了雅博渡口。</span>
<span className="v" id="v23" data-v="23"> 他带着他们，先送他们过河，又把所拥有的一切也都送了过去。</span>
<span className="v" id="v24" data-v="24" data-xref="何西阿书 12:3–5; 以弗所书 6:12; 路加福音 13:24"> 最后雅各独自留下。 雅各与神较力<br />那夜，有一个人与雅各摔跤，直到天亮。</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多后书 12:7–9; 何西阿书 12:3–4; 马太福音 26:41"> 那人见自己胜不过他，就碰了他的大腿窝；于是雅各与那人摔跤的时候，大腿窝就脱臼了。</span>
<span className="v" id="v26" data-v="26" data-xref="何西阿书 12:4; 诗篇 115:12–13; 哥林多后书 12:8–9"> 那人说：“天亮了，让我走吧！”<br />雅各说：“你不祝福我，我就不让你走。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 那人问他：“你叫什么名字？”<br />他回答：“雅各。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="启示录 2:17; 创世记 35:10; 以赛亚书 62:2–4"> 那人说：“你的名字不要再叫雅各，而要叫以色列，因为你已经与神与人较力，并且得胜了。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 9:6; 士师记 13:16–18; 约伯记 11:7"> 雅各问他说：“请把你的名字告诉我。”<br />那人说：“为什么要问我的名字呢？”他就在那里祝福了雅各。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及记 24:10–11; 民数记 12:8; 以赛亚书 6:5"> 雅各就给那地方起名为毗努伊勒，因为他说：“我面对面看见了神，但我的性命得以保全。”</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多后书 12:7; 创世记 19:15; 士师记 8:8"> 雅各过毗努伊勒的时候，太阳初升，照在他身上。他因大腿的伤就一瘸一拐。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 5:5"> 因此直到今日，以色列子孙不吃大腿窝上的腱子筋，因为那人碰了雅各大腿窝上的腱子筋。</span>
</div>
</div>

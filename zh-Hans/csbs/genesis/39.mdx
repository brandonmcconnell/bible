<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 37:28; 诗篇 105:17; 创世记 37:36"> 约瑟被带下埃及。有一个埃及人，是法老的内臣、护卫长波提乏，从那些带约瑟下来的以实玛利人手中买了他。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 18:14; 诗篇 91:15; 耶利米书 15:20"> 耶和华与约瑟同在，他就成为事事顺利的人。他住在他埃及主人的家中。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 1:3; 创世记 30:27; 马太福音 5:16"> 他主人见耶和华与他同在，又见耶和华使他手上所做的一切都顺利；</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 39:21–22; 箴言 27:18; 创世记 19:19"> 约瑟就在他主人的眼前蒙恩，事奉他的主人。他主人指派他管理自己的家，把自己所拥有的一切都交在他的手中。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 30:27; 撒母耳记下 6:11–12; 使徒行传 27:24"> 自从波提乏指派约瑟管理家和所拥有的一切，耶和华就因约瑟的缘故祝福了那埃及人的家；无论在家里或在田间，他所拥有的一切都蒙耶和华的祝福。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 16:12; 路加福音 19:17; 箴言 31:11"> 他把自己所拥有的一切都交托在约瑟的手中；有约瑟在，他除了自己吃的饭以外，什么事都不理会。<br />约瑟有着健美的身材、俊美的容貌。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 13:11; 以西结书 16:34; 彼得后书 2:14"> 这些事以后，约瑟主人的妻子看上了约瑟<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="看上了约瑟——原文直译“向约瑟抬起她的眼睛”。">a</a></sup>，对他说：“与我同睡吧！”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="箴言 23:26–28; 箴言 22:14; 箴言 9:13–18"> 但约瑟拒绝了，对他主人的妻子说：“看哪，有我在，我主人对家中的什么事都不理会，他把自己所拥有的一切都交在我的手中。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 12:13; 创世记 20:6; 创世记 42:18"> 在这家里没有比我大的；除你以外，他没有留下一样不给我，因你是他的妻子。我怎能行此大恶对神犯罪呢？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="彼得前书 2:11; 创世记 39:8; 帖撒罗尼迦前书 5:22"> 她天天对约瑟这样说，约瑟却不听从她，不与她同睡，也不与她在一起。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 5:12; 以弗所书 5:3; 玛拉基书 3:5"> 有一天，约瑟进屋去做事，没有一个家仆在屋里；</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太后书 2:22; 箴言 7:13–27; 传道书 7:26"> 主人的妻子就抓住约瑟的衣服，说：“与我同睡吧！”但约瑟把自己的衣服撇在她手中，逃到外面去了。</span>
<span className="v" id="v13" data-v="13"> 她见约瑟把衣服撇在她手中逃到了外面，</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 10:21; 彼得前书 2:20; 诗篇 35:11"> 就把家里的人叫来，对他们说：“你们看，我丈夫带给我们的希伯来人要戏弄我们。他到我这里来，要与我同睡，我就大声呼喊。</span>
<span className="v" id="v15" data-v="15"> 他听见我放声呼喊，就把自己的衣服撇在我身边，逃到外面去了。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="诗篇 37:32; 耶利米书 4:22; 耶利米书 9:3–5"> 她把约瑟的衣服放在自己身边，等到约瑟的主人回家，</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 23:1; 列王纪上 18:17; 诗篇 37:14"> 也用这些话<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这些话——或译作“类似的话”。">b</a></sup>对他说：“你带给我们的那个希伯来奴仆，到我这里来要戏弄我。</span>
<span className="v" id="v18" data-v="18"> 当我放声呼喊时，他就把自己的衣服撇在我身边，逃到外面去了。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="创世记 4:5–6; 箴言 18:17; 箴言 6:34–35"> 约瑟的主人听了妻子对他说的话“你的奴仆对我做了这样的事”，他就怒气发作。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 40:15; 提摩太后书 2:9; 诗篇 105:18–19"> 于是约瑟的主人把约瑟拿下，关进监狱，就是王的囚犯被囚的地方。约瑟就在那里坐牢。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及记 3:21; 以赛亚书 41:10; 彼得前书 3:17"> 然而，耶和华与约瑟同在，向他施慈爱，使他在监狱长的眼前蒙恩。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 40:3–4; 创世记 39:4; 撒母耳记上 2:30"> 监狱长就把监狱里所有的囚犯都交在约瑟手下；狱中要办的一切事，都由约瑟处理。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 43:2; 创世记 39:2–3; 诗篇 1:3"> 监狱长对约瑟手中的一切事都不查看，因耶和华与他同在，耶和华使他所做的都顺利。</span>
</div>
</div>

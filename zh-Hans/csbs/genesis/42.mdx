<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="GEN" data-book-slug="genesis" data-book-name="创世记" data-chapter="42" data-verses="38">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 7:12; 约书亚记 7:10; 列王纪下 8:3–4"> 雅各见埃及有粮，就对儿子们说：“你们为什么彼此干瞪眼呢？”</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 43:8; 创世记 45:9; 创世记 43:2"> 他又说：“看哪，我听说埃及有粮。你们当下到那里去，从那里为我们买粮，使我们得以存活，不至于死。”</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 42:5; 创世记 42:13"> 于是约瑟的十个哥哥就下去，要从埃及买粮。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 42:38; 创世记 43:29; 创世记 11:4"> 但雅各没有打发约瑟的弟弟便雅悯与哥哥们同去，因为雅各说：“恐怕有灾祸临到他。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 41:57; 使徒行传 7:11; 创世记 12:10"> 这样，以色列的儿子们夹杂在前来的人群中也来买粮，因为迦南地也有饥荒。</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 3:9; 创世记 37:7–10; 创世记 41:40–41"> 那时，埃及的掌权者是约瑟，他卖粮给那地所有的人。约瑟的哥哥们来了，脸伏于地向他下拜。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 42:30; 创世记 42:14–17; 马太福音 15:23–26"> 约瑟一看见自己的哥哥们，就认出了他们，却对他们装作陌生人，向他们说严厉的话，问道：“你们从哪里来？”<br />他们回答：“我们是从迦南地来，是来买粮的。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="创世记 37:2; 约翰福音 20:14; 路加福音 24:16"> 约瑟认出了他的哥哥们，他们却没有认出他。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 37:5–9; 出埃及记 32:35; 约书亚记 2:1"> 约瑟想起从前做过的那些关于他们的梦，就对他们说：“你们是奸细，是来窥探本地虚实的。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 37:8; 撒母耳记上 26:17; 创世记 27:37"> 他们对他说：“不是啊，我主！你的仆人们实在是来买粮的。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 42:19; 哥林多后书 6:4; 约翰福音 7:18"> 我们全都是同一个人的儿子，我们是诚实人，你的仆人们不是奸细！”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 约瑟却对他们说：“不，你们实在是为了窥探本地的虚实而来。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 37:30; 创世记 42:32; 创世记 44:20"> 他们说：“你的仆人们本是兄弟十二人，都是迦南地同一个人的儿子。看哪，最小的那个现在与我们的父亲在一起，还有一个已经不在了。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 15:21–28; 约伯记 13:24; 创世记 42:9–11"> 约瑟对他们说：“我已经说了，你们就是奸细。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 17:55; 耶利米书 5:7; 创世记 42:16"> 用这种方法你们就被察验出来了：让你们最小的弟弟到我这里来，否则我指着法老的生命起誓，你们绝不能离开这地方！</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 42:11"> 你们要打发你们中间的一个人，让他把你们的弟弟带来，而你们其余的人都要被囚禁；这样就可以察验你们的话是不是真的。如果不是，我指着法老的生命起誓，你们就一定是奸细。”</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 40:4; 希伯来书 12:10; 创世记 40:7"> 于是约瑟把他们一起关在监牢里三天。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未记 25:43; 尼希米记 5:15; 路加福音 18:2"> 第三天，约瑟对他们说：“我是敬畏神的，你们这样做就可以活命：</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 45:23; 以赛亚书 42:7; 创世记 40:3"> 如果你们是诚实人，就让你们的一个兄弟囚禁在牢里；你们其余的人可以走了，把粮食带给饥饿的家人吧！</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 44:23; 创世记 43:5; 创世记 42:34"> 然后把你们最小的弟弟带到我这里来；这样，你们的话就得到证实，你们就不至于死。”于是他们就照着去做了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="何西阿书 5:15; 马可福音 9:43–45; 创世记 37:23–28"> 他们彼此说：“我们在弟弟的事上实在有罪。他恳求我们的时候，我们见他心中苦楚，却不肯听，所以现在这苦楚临到我们了。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="历代志下 24:22; 诗篇 9:12; 列王纪上 2:32"> 鲁本就回应他们，说：“我不是对你们说过：‘不要对那孩子犯罪’吗？可是你们不肯听；看哪，他的血债现在来追讨了！”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 5:20; 约翰福音 16:13–14"> 他们并不知道约瑟是能听懂的，因为他们和约瑟之间有人传译。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 43:30; 犹大书 1:22–23; 希伯来书 4:15"> 约瑟转身离开他们，哭了一场，又回来与他们说话，并从他们那里挑出西缅，在他们眼前把他捆绑起来。</span>
<span className="v" id="v25" data-v="25" data-xref="彼得前书 3:9; 罗马书 12:17–21; 创世记 45:21"> 约瑟吩咐人把粮食装满他们的容器，并且把他们各人的银子放回各自的袋子，又送给他们路上所需的食物。一切就照着办了。</span>
<span className="v" id="v26" data-v="26"> 他们把粮食驮在驴子上，离开那里走了。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="出埃及记 4:24; 路加福音 2:7; 路加福音 10:34"> 到了一处住宿的地方，其中一个人打开自己的袋子，要拿饲料喂驴，却看见了自己的银子，看哪，就在袋子口！</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 45:7; 耶利米哀歌 3:37; 创世记 42:36"> 他就对兄弟们说：“我的银子被还回来了，看哪，就在我的袋子里！”他们的心都快跳出来了，彼此战战兢兢地说：“神对我们做的这是什么呢？”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 他们回到迦南地，到了父亲雅各那里，把他们遇到的一切事都告诉了他说：</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 42:7"> “那地的主人向我们说严厉的话，把我们当作窥探那地的人。</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 42:11"> 我们对他说：‘我们是诚实人，不是奸细。</span>
<span className="v" id="v32" data-v="32"> 我们本是兄弟十二人，都是一个父亲的儿子；有一个已经不在了，最小的那个现在与我们的父亲在迦南地。’</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 42:19–20; 创世记 42:15"> 那地的主人对我们说：‘我通过以下的方法就知道你们是不是诚实人：把你们兄弟中的一个留在我这里，你们其余的人可以走了，把粮食带给饥饿的家人；</span>
<span className="v" id="v34" data-v="34" data-xref="创世记 34:10; 创世记 34:21; 列王纪上 10:15"> 然后把你们最小的弟弟带到我这里来。这样我就知道你们不是奸细，而是诚实人了。我会把你们的兄弟交还给你们，你们也可以在这地做买卖。’”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="创世记 43:21; 创世记 43:12; 创世记 43:15"> 后来他们倒空自己的袋子，看哪，各人的银囊都在自己的袋子里！他们和父亲看见银囊就都害怕。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="创世记 43:14; 罗马书 8:31; 以赛亚书 27:9"> 他们的父亲雅各对他们说：“你们使我丧失了儿子：约瑟不在了，西缅也不在了；你们又要把便雅悯带走，这一切都是冲着我来的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="都是冲着我来的——或译作“都临到我身上了”。">a</a></sup>！”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="创世记 46:9; 弥迦书 6:7; 创世记 43:9"> 鲁本告诉他父亲说：“如果我不把便雅悯带回来给你，你就可以杀死我的两个儿子。只管把便雅悯交在我的手中吧，我必把他带回来给你！”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="创世记 37:35; 创世记 42:4; 创世记 37:33"> 但雅各说：“我的儿子不可与你们一同下去，因为他哥哥死了，只剩下他。如果在你们所行的路上有灾祸临到他，你们就使白发苍苍的我悲悲惨惨地下阴间去了！”</span>
</div>
</div>

</div>

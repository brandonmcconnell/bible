<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 12:10; 创世记 25:11; 创世记 21:22–32"> 在亚伯拉罕日子里的那次饥荒以外，那地又有了饥荒。于是以撒就往基拉耳去，到了非利士人的王亚比米勒那里。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 12:7; 诗篇 37:3; 创世记 17:1"> 耶和华向以撒显现，说：“你不要继续下埃及去，要住在我指示你的地方。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 28:15; 诗篇 105:9; 创世记 17:8"> 你要寄居在这地，我必与你同在，并祝福你，因为我必把所有这些地都赐给你和你的后裔；我必确立我向你父亲亚伯拉罕所起的誓。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 3:25; 创世记 15:5; 创世记 22:17–18"> 我必使你的后裔增多，如同天上的星辰，我必把所有这些地都赐给你的后裔；地上万国都必因你的后裔而蒙福，</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 7:24; 创世记 22:18; 创世记 22:16"> 因为亚伯拉罕听从我的话，遵守我的吩咐、诫命、律例和训诲。”</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 20:1"> 这样，以撒就在基拉耳住下了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="箴言 29:25; 创世记 12:13; 创世记 20:2"> 每当那地方的人问起他的妻子，他就说：“她是我的妹妹。”原来他害怕说“她是我的妻子”；他想：“恐怕这地方的人会因莉百加的缘故杀我”，因为莉百加容貌美丽。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 62:5; 箴言 5:18–19; 箴言 7:6"> 他在那里住了很长的一段日子。有一天，非利士人的王亚比米勒透过窗户观望，看哪，以撒正在与他的妻子莉百加亲热！</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 亚比米勒就召来了以撒，说：“看哪，她确实是你的妻子！你怎么说‘她是我的妹妹’呢？”<br />以撒对他说：“因为我想‘恐怕我会因她的缘故而死。’”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 20:9–10; 创世记 12:18–19"> 亚比米勒说：“你对我们做的这是什么呢？民中有人差一点就与你的妻子同睡了，而你也差一点使罪责临到我们了。”</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 105:15; 创世记 20:6; 箴言 6:29"> 于是亚比米勒吩咐全体民众说：“凡碰这人或他妻子的，必须被处死。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马可福音 4:8; 创世记 24:1; 创世记 26:3"> 以撒在那地耕种，那一年收获百倍；耶和华祝福了他，</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 112:3; 箴言 10:22; 创世记 24:35"> 他就昌大起来，日渐强大，变得非常昌盛。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 37:11; 创世记 13:2; 箴言 27:4"> 他拥有羊群、牛群和许多仆婢，非利士人就嫉妒他。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 21:30; 创世记 21:25"> 他父亲亚伯拉罕在世的时候，他父亲的仆人们所挖的井，全被非利士人堵上了，填满了土。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 1:9"> 亚比米勒对以撒说：“从我们这里离开吧！因为你比我们强盛得多。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 以撒就离开那里，在基拉耳溪谷扎营，住了下来。</span>
<span className="v" id="v18" data-v="18" data-xref="撒迦利亚书 13:2; 何西阿书 2:17; 民数记 32:38"> 以撒重新挖开了他父亲亚伯拉罕在世的时候所挖的水井——它们在亚伯拉罕死后都被非利士人堵上了。以撒仍照着他父亲为井所起的名字称呼它们。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 4:10–11; 约翰福音 7:38; 雅歌 4:15"> 以撒的仆人们又在溪谷中挖井，在那里发现一口活水井。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 21:25"> 基拉耳的牧人们与以撒的牧人们争论，说：“这水是我们的。”以撒就给这口井起名为埃色，因为他们与他相争。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯拉记 4:6"> 后来以撒的仆人们挖了另一口井，他们又为那口井争论；以撒就给那口井起名为西提拿。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 17:6; 出埃及记 1:7; 诗篇 118:5"> 于是以撒从那里迁移，又挖了一口井。这次，他们没有为井争论；以撒就给它起名为利河伯，因为他说：“如今耶和华给了我们宽阔的地方<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="地方——辅助词语。">a</a></sup>，我们必在此地繁盛。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="士师记 20:1; 创世记 21:31; 创世记 46:1"> 以撒从那里上比尔-谢巴去。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 15:1; 出埃及记 3:6; 以赛亚书 43:1–2"> 那天夜里，耶和华向他显现，说：“我是你父亲亚伯拉罕的神；你不要害怕，因为我与你同在。我要因我仆人亚伯拉罕的缘故祝福你，并使你的后裔增多。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 13:18; 诗篇 116:17; 创世记 12:7–8"> 以撒就在那里筑了一座祭坛，呼求耶和华的名，并且在那里支搭帐篷。以撒的仆人们也在那里挖了一口井。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="创世记 21:22–32; 创世记 20:3"> 亚比米勒和他的谋士<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="谋士——或译作“朋友”。">b</a></sup>亚户撒，以及他军队的首领非革，从基拉耳来到以撒那里。</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 26:16; 士师记 11:7; 使徒行传 7:14"> 以撒对他们说：“你们既然恨我，从你们中间赶我走，为什么还来到我这里呢？”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="创世记 21:22–23; 以赛亚书 45:14; 以赛亚书 61:9"> 他们说：“我们确实看见耶和华与你同在，就想我们之间应该有一个誓约，就在你和我们之间。让我们与你立约：</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 24:31; 创世记 21:22; 创世记 22:17"> 你不可加害我们，正如我们没有碰过你，只是善待你，并且送你平平安安地走。你现在是蒙耶和华祝福的。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="创世记 19:3; 罗马书 12:18; 希伯来书 12:14"> 于是以撒为他们摆设宴席，他们就一起吃喝。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记上 20:16–17; 希伯来书 6:16; 创世记 25:33"> 他们清早起来，彼此起誓；然后以撒送他们走，他们就平平安安地离开他去了。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 10:4; 箴言 13:4; 箴言 2:4–5"> 那一天，以撒的仆人们来，把挖井的情况告诉他说：“我们找到水了。”</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 21:31; 创世记 26:28"> 他就称呼那口井为谢巴；因此那城名叫比尔-谢巴，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="创世记 36:2; 创世记 36:13; 出埃及记 34:16"> 以扫四十岁的时候，娶了赫提人贝尔里的女儿犹迪斯与赫提人埃隆的女儿巴丝玛为妻。</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 27:46–2; 创世记 28:8; 创世记 6:2"> 她们使以撒和莉百加灵里痛楚。</span>
</div>
</div>

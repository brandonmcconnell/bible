<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="GEN" data-book-slug="genesis" data-book-name="创世记" data-chapter="50" data-verses="26">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 46:4; 申命记 6:7–8; 使徒行传 8:2"> 约瑟伏在他父亲的脸上哀哭、亲吻。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 50:26; 历代志下 16:14; 约翰福音 19:39–40"> 约瑟吩咐仆人中那些作医生的，用香料包殓他的父亲。医生就用香料包殓了以色列。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 20:29; 申命记 34:8; 创世记 50:10"> 这需要四十天，因为这是用香料包殓尸体所需要的时间。埃及人为以色列哀哭了七十天。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="创世记 18:3; 以斯帖记 4:2"> 为他哀哭的日子过了，约瑟对法老家中的人说：“如果我在你们眼前蒙恩，请你们上报法老说：</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 16:14; 以赛亚书 22:16; 马太福音 27:60"> ‘我父亲曾经要我起誓，说：“看哪，我就要死了；你要把我葬在迦南地，葬在我为自己开凿的坟墓里。”现在求你让我上去，安葬我的父亲，然后我就回来。’”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 48:21"> 法老说：“你上去吧，照着你父亲让你起的誓，安葬你的父亲。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="创世记 14:16"> 于是约瑟上去安葬他的父亲。与他一同上去的，包括法老所有的臣仆，法老家中的长老，埃及地所有的长老，</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 32:24–27; 出埃及记 10:26; 出埃及记 10:8–9"> 还有约瑟的全家，他的兄弟们，以及他父亲的家属；只有他们的孩童和羊群、牛群留在歌珊地；</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 14:28; 列王纪下 18:24; 雅歌 1:9"> 与他一同上去的，还有车辆和马兵。那是非常庞大的一队。</span>
<span className="v" id="v10" data-v="10" data-xref="约伯记 2:13; 使徒行传 8:2; 撒母耳记下 1:17"> 他们来到约旦河对岸的亚达禾场，就在那里大大哀哭，哭得极其沉痛。约瑟为他父亲举哀七天。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 10:15–19; 创世记 24:6; 申命记 11:30"> 那地的居民迦南人看见亚达禾场上的哀悼，就说：“这是埃及人的一场沉痛的哀悼。”因此约旦河对岸那地方名叫亚伯-麦西。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 7:16; 创世记 49:29–32; 以弗所书 6:1"> 这样，雅各的儿子们就照着父亲吩咐他们的为他去做：</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 49:29–31; 创世记 23:16–18; 使徒行传 7:16"> 他们把他运到迦南地，葬在幔利对面的麦比拉田间的洞穴里。那田是亚伯拉罕向赫提人以弗仑买来的，作为他拥有的坟地。</span>
<span className="v" id="v14" data-v="14"> 约瑟安葬了他的父亲之后，就和他的兄弟们以及所有与他一同上来安葬他父亲的人，回埃及去了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="箴言 28:1; 创世记 42:21–22; 诗篇 53:5"> 约瑟的哥哥们见父亲死了，就说：“也许约瑟仍然记恨我们，会因着我们从前对他所做的一切恶，十足地报复我们。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="箴言 29:25"> 他们就打发人去约瑟那里，说：“在你父亲死之前，他曾吩咐说：</span>
<span className="v" id="v17" data-v="17" data-xref="以弗所书 4:32; 马太福音 6:14–15; 创世记 45:8"> ‘你们要对约瑟这样说：从前你哥哥们恶待你，求你饶恕他们的过犯和罪恶。’现在求你饶恕你父亲之神的仆人们的过犯。”他们对约瑟说这话时，约瑟就哭了。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 37:7–11; 创世记 42:6; 创世记 45:3"> 随后他的哥哥们也来，俯伏在他面前，说：“看哪，我们是你的奴仆！”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="罗马书 12:19; 创世记 45:5; 创世记 30:2"> 约瑟对他们说：“你们不要害怕，难道我能代替神吗？</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 8:28; 诗篇 119:71; 创世记 45:5–8"> 从前你们有意要害我，但神在其中有他的美意，为要成就今日这样的结果，使许多人得以存活。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 47:12; 彼得前书 3:9; 创世记 45:10–11"> 现在，你们不要害怕，我必供应你们和你们的孩童。”于是约瑟安慰他们，对他们说宽心的话。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 约瑟和他的父家都住在埃及。约瑟活了一百一十岁。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 32:39; 创世记 30:3; 约伯记 42:16"> 约瑟得见以法莲的第三代子孙。玛拿西的儿子玛吉的众子，生下来就归于约瑟膝下<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="生下来就归于约瑟膝下——原文直译“也生在约瑟的膝上”。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出埃及记 3:16–17; 创世记 35:12; 创世记 26:3"> 约瑟对他的兄弟们说：“我就要死了，但神必定眷顾你们，也必领你们从这地上去，进入他起誓给亚伯拉罕、以撒、雅各的那地。”</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 13:19; 约书亚记 24:32; 创世记 47:29–31"> 约瑟就让以色列的子孙起誓，对他们说：“神必定眷顾你们，而你们要把我的骸骨从这里带上去。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="创世记 50:2–3; 创世记 47:9; 约书亚记 24:29"> 约瑟死了，享年一百一十岁。人们用香料把他包殓了，安放在棺材里，安置在埃及。</span>
</div>
</div>

</div>

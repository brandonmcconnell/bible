<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 30:22; 创世记 19:29; 诗篇 136:23"> 神记念挪亚以及与他一起在方舟里的所有活物和牲畜。神使风吹过大地，水就开始退落。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 7:11; 马太福音 8:26–27; 箴言 8:28"> 深渊的泉源和天上的窗户都关闭了，从天而降的大雨也止住了。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 7:24; 创世记 7:11"> 水从地上渐渐回落；过了一百五十天，水就大大减退了。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 19:37; 耶利米书 51:27; 以赛亚书 37:38"> 七月十七日，方舟停留在亚拉腊山上。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 7:11"> 水继续减退，直到十月。十月一日，众山顶都显露出来了。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 6:16; 但以理书 6:10"> 过了四十天，挪亚打开他所造方舟的窗户，</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 147:9; 列王纪上 17:6; 列王纪上 17:4"> 放出了一只乌鸦。乌鸦不断地飞去飞回，直到地上的水都干了。</span>
<span className="v" id="v8" data-v="8" data-xref="雅歌 2:14; 雅歌 1:15; 马太福音 10:16"> 他又从他那里放出一只鸽子，要看看水是否从地面上消退了。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 11:28; 诗篇 116:7; 申命记 28:65"> 但鸽子找不到可以落脚的歇息之处，又回到方舟挪亚那里，因为整个地面上都是水。挪亚伸出手，把鸽子接过来，带进方舟自己那里。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 7:4; 创世记 7:10; 创世记 8:12"> 他又等了七天，再次把鸽子从方舟放出去。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 8:15; 撒迦利亚书 4:12–14; 罗马书 10:15"> 傍晚时分，鸽子回到他那里；看哪，鸽子嘴里有一片新拧下的橄榄叶子！挪亚就知道水已经从地上消退了。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 25:9; 以赛亚书 30:18; 创世记 8:10"> 他另外又等了七天，又把鸽子放出去，鸽子就再也没有回到他那里了。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 7:11"> 挪亚六百零一岁那年的一月一日，水从地上退干。挪亚移开方舟的顶盖观看，看哪，地面干了！</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 7:13–14; 创世记 7:11"> 到了二月二十七日，大地完全干了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 于是神吩咐挪亚说：</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 7:13; 诗篇 121:8; 诗篇 91:11"> “你与你的妻子、儿子们和儿媳们，一起从方舟出来吧！</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 1:22; 创世记 9:1; 耶利米书 31:27–28"> 你要带出所有与你在一起的活物，就是一切有血肉的，包括飞鸟、走兽和地上活动的一切爬虫，好让它们充满大地，繁衍增多。”</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 121:8"> 于是挪亚与他的儿子们、他的妻子和儿媳们一起出来了；</span>
<span className="v" id="v19" data-v="19"> 一切走兽、爬虫和飞鸟，地上活动的一切，都按着它们的族类，也从方舟出来了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="希伯来书 13:15–16; 罗马书 12:1; 创世记 22:9"> 挪亚为耶和华筑了一座祭坛，并拿各样洁净的牲畜和各样洁净的飞鸟，在祭坛上献为燔祭。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 2:15; 以弗所书 5:2; 以赛亚书 54:9–10"> 耶和华闻到了那馨香之气，就心里说：“我绝不再因人的缘故诅咒这地，尽管人从年幼时就心怀邪恶；我也绝不再像我曾做的，毁灭所有的活物。</span>
<span className="v" id="v22" data-v="22" data-xref="雅各书 5:7; 诗篇 74:16–17; 耶利米书 5:24"> <span className="pl pl-1">只要大地还存留，</span><br /><span className="pl pl-1">稼穑、寒暑、冬夏、昼夜</span><br /><span className="pl pl-1">就不会停息。”</span></span>
</div>

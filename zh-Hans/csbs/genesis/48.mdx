<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 41:50–52; 创世记 46:20; 诗篇 128:6"> 这些事以后，有人告诉约瑟：“看哪，你的父亲病了！”他就带着两个儿子玛拿西和以法莲一同去探望<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="探望——辅助词语。">a</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 6:10; 撒母耳记上 23:16; 申命记 3:28"> 又有人告诉雅各说：“看哪，你的儿子约瑟到你这里来了！”以色列就竭尽全力，在床榻上坐起。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 35:9–12; 出埃及记 6:3; 创世记 28:3"> 雅各对约瑟说：“全能的神曾在迦南地的路斯向我显现，并祝福了我，</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 17:8; 创世记 35:11; 创世记 26:4"> 对我说：‘看哪，我要使你繁衍增多，成为万族之族；又要把这地赐给你的后裔作永远的产业。’</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 41:50–52; 约书亚记 14:4; 创世记 46:20"> 我来到埃及你这里之前，你在埃及地所生的以法莲和玛拿西这两个儿子，现在是我的了，就像鲁本和西缅是我的一样；</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 14:4"> 而你在他们以后所生的孩子就是你的，在他们继业的事上，被算在这两个哥哥的名下。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 35:16–19; 马太福音 2:18; 创世记 35:9"> 至于我，从帕旦回来的时候，我很不幸，拉结死在迦南地的路上，离以法他还有一段路程；我把她就地埋葬在通往以法他的路旁。”以法他就是伯利恒。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 以色列看见约瑟的儿子们，就说：“他们是谁呢？”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 27:4; 创世记 33:5; 希伯来书 11:21"> 约瑟对他父亲说：“他们是我的儿子，是神在这里赐给我的。”<br />以色列说：“把他们带到我这里，好让我祝福他们。”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 27:1; 创世记 27:27; 撒母耳记上 3:2"> 以色列的眼睛因年老昏花，不能看见。约瑟就让他们靠近他；他就亲吻他们，拥抱他们。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 3:20; 创世记 45:26; 创世记 42:36"> 以色列对约瑟说：“我没有想到能见你的面，看哪，连你的后裔，神都让我见到了！”</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 42:6; 利未记 19:32; 创世记 19:1"> 约瑟把他们从以色列的膝盖挪开，自己脸伏于地下拜。</span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13"> 然后约瑟领着他们两个靠近以色列：以法莲在他的右手，对着以色列的左手；玛拿西在他的左手，对着以色列的右手。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 41:51; 诗篇 118:16; 马太福音 19:15"> 以色列却伸出右手，按在次子以法莲的头上；又交叉着伸出左手，按在玛拿西的头上；实际上玛拿西才是长子。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 17:1; 歌罗西书 2:6; 以赛亚书 33:16"> 以色列祝福约瑟说：<br /><span className="pl pl-1">“愿我祖父亚伯拉罕和我父以撒所跟随的神，</span><br /><span className="pl pl-1">就是牧养我一生直到今日的神，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 34:22; 创世记 49:22; 创世记 48:5"> <span className="pl pl-1">也是救赎我脱离一切祸患的那一位</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="那一位——原文直译“使者”。">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">祝福这两个孩子！</span><br /><span className="pl pl-1">愿我的名，我祖父亚伯拉罕和我父以撒的名，藉着他们得以流传；</span><br /><span className="pl pl-1">愿他们在地上生养众多。”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 48:14; 罗马书 9:7–8; 历代志上 21:7"> 约瑟见父亲把右手按在以法莲的头上，就觉得不对，于是抓着父亲的手，要从以法莲的头上移到玛拿西的头上。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 19:18; 创世记 29:26; 创世记 43:33"> 约瑟对他父亲说：“我的父亲哪，这样不对！这一个才是长子，你要把右手放在他的头上。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="申命记 33:17; 民数记 1:33–35; 创世记 25:28"> 他父亲却拒绝他，说：“我知道，我儿，我知道！他也要成为一族，也必昌大；只是他的弟弟将来比他还要昌大，他弟弟的后裔必成为多国。”</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 24:60; 路得记 4:11–12; 创世记 28:3"> 以色列当天就祝福他们，说：<br /><span className="pl pl-1">“以色列人要用你们的名</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="的名——辅助词语。">c</a></sup><br /><span className="pl pl-1">说祝福的话：</span><br /><span className="pl pl-1">‘愿神使你像以法莲和玛拿西一样。’”</span><br />这样他把以法莲立在玛拿西之先。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 50:24; 创世记 46:4; 创世记 28:15"> 以色列对约瑟说：“看哪，我就要死了！但神必与你们同在，把你们带回到你们祖先之地。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 4:5; 约书亚记 24:32; 历代志上 5:2"> 我还要使你比众兄弟多得一块山地，就是我曾经用刀用弓从亚摩利人手中夺过来的。”</span>
</div>
</div>

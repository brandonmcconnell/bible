<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 30:21; 耶利米书 2:36; 创世记 30:13"> 莉亚为雅各所生的女儿狄娜出去，要见那地的女子。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 5:28; 约伯记 31:1; 约伯记 31:9"> 那地的族长希未人哈莫尔的儿子示剑看见她，就抓住她，与她同睡，玷辱了她。</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿书 2:14; 以赛亚书 40:2; 历代志下 30:22"> 示剑的心迷恋雅各的女儿狄娜，他爱那少女，对她说宽心的话。</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 14:2; 撒母耳记下 13:13; 创世记 21:21"> 示剑告诉他父亲哈莫尔说：“求你给我聘娶这个女孩为妻。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 13:22; 利未记 10:3; 撒母耳记上 10:27"> 雅各听到示剑玷污了他的女儿狄娜，那时他的儿子们还在田野与他的牲畜在一起，雅各就闭口不言，等他们回来。</span>
<span className="v" id="v6" data-v="6"> 示剑的父亲哈莫尔出来，到雅各那里，要与他商议。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 7:15; 士师记 20:6; 申命记 22:21"> 雅各的儿子们一听到妹妹的事，就从田野回来，个个痛心，非常恼火，因为示剑对以色列家做了丑恶的事，与雅各的女儿同睡——这样的事本就不应该做。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪上 11:2; 诗篇 119:20; 诗篇 84:2"> 哈莫尔与他们商议，说：“我儿子示剑的心爱慕你们家的女儿。请你们把她给我的儿子为妻吧。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 7:3; 创世记 26:34–35; 创世记 19:14"> 你们与我们通婚吧：你们的女儿，嫁给我们；我们的女儿，你们也可以娶。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 20:15; 创世记 47:27; 创世记 42:34"> 这样，你们可以与我们一起居住；这地就在你们面前，住在这里做买卖，置产业吧！”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="创世记 33:15; 创世记 18:3"> 接着示剑对狄娜的父亲和她的兄弟们说：“愿我在你们眼前蒙恩，无论你们向我索要什么，我都会给。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 22:16–17; 申命记 22:28–29; 撒母耳记上 18:25–27"> 你们尽管向我多多索要聘金和礼物，我都会照着你们所说的给，只求你们把这少女给我为妻。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 25:27–34; 以赛亚书 59:13; 约伯记 13:4"> 雅各的儿子们因示剑玷污了他们的妹妹狄娜，就用欺诈的话回答示剑和他父亲哈莫尔，</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 23:1–39; 撒母耳记下 15:7; 创世记 17:11"> 对他们说：“把我们的妹妹交给一个未受割礼的人，我们不能做这样的事，因为这对我们是一种羞辱。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 4:12"> 只有在一个条件下，我们才答应你们，就是你们当中所有的男子都要像我们一样受割礼。</span>
<span className="v" id="v16" data-v="16"> 这样，我们就把女儿们嫁给你们，也娶你们的女儿们，并与你们一起居住，成为一族。</span>
<span className="v" id="v17" data-v="17"> 如果你们不肯听从我们受割礼，我们就要把我们家的女儿带走。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 他们的说法在哈莫尔和哈莫尔的儿子示剑的眼中都看为好。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 17:12; 使徒行传 13:50; 撒母耳记上 22:14"> 那年轻人毫不迟延地去做这事，因为他很喜欢雅各的女儿。他在他父亲的全家中最受人尊重。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路得记 4:1; 箴言 31:23; 阿摩司书 5:12"> 于是哈莫尔和他儿子示剑来到城门口，告诉城里的人说：</span>
<span className="v" id="v21" data-v="21"> “这些人与我们和平相处，就让他们在这地居住，在这里做买卖吧。看哪，这地足够宽广，可以容下他们。我们可以娶他们的女儿为妻，也可以把我们的女儿嫁给他们。</span>
<span className="v" id="v22" data-v="22"> 但是只有在一个条件下，这些人才会答应与我们一起居住，成为一族，就是我们当中所有的男子都要受割礼，像他们一样受割礼。</span>
<span className="v" id="v23" data-v="23" data-xref="箴言 1:12–13; 约翰福音 6:26–27; 约翰福音 2:16"> 这样，他们的牲畜、财产和各样动物，难道不就都成为我们的吗？只要我们答应他们，他们就与我们一起居住。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="创世记 23:10; 哥林多前书 7:19; 以赛亚书 1:10–16"> 所有从城门口出入的人，都听了哈莫尔和他儿子示剑的话；于是所有从城门口出入的男子，都受了割礼。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 49:5–7; 创世记 29:33–34; 民数记 31:7"> 到了第三天，当他们正疼痛的时候，雅各的两个儿子，就是狄娜的哥哥西缅和利未，各拿刀剑，在全城毫无戒备的时候进去，把所有的男子都杀了。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 2:26; 申命记 32:42; 以赛亚书 31:8"> 又用刀剑杀了哈莫尔和他的儿子示剑，然后把狄娜从示剑家里带走了。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 7:13; 约书亚记 7:21; 出埃及记 2:14"> 雅各的儿子们因那城的人玷污了他们的妹妹，就来到被杀的人那里，掠夺那城，</span>
<span className="v" id="v28" data-v="28" data-xref="约伯记 1:15–16; 申命记 8:17–18; 约伯记 20:5"> 夺取了他们的羊群、牛群和驴子，以及城中和田间的一切；</span>
<span className="v" id="v29" data-v="29"> 又掳走、掠夺了他们所有的财富、孩童、妇女，以及房屋里的一切。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="诗篇 105:12; 约书亚记 7:25; 出埃及记 5:21"> 雅各对西缅和利未说：“你们给我带来了祸患，使我在这地的居民，就是在迦南人和比利洗人中间，有了臭名。我的人数稀少，如果他们聚集起来对付我、攻击我，我和我家就会被除灭。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="箴言 6:34; 创世记 34:13; 创世记 49:7"> 他们却说：“难道他可以把我们的妹妹像妓女一样对待吗？”</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 1:28"> 当时，人在地面上开始增多，生了很多女儿，</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 82:6–7; 约翰一书 2:16; 彼得后书 2:14"> 神的儿子们看到人的女儿们美丽，就从中任意挑选，为自己娶来为妻。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 9:30; 以赛亚书 63:10; 耶利米书 11:11"> 耶和华就说：“我的灵不会永远住在人里面<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="住在人里面——原文直译“在人里面审断”。">a</a></sup>，因人是血肉之躯；他的年日只可以到一百二十年。”</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 13:33; 撒母耳记下 21:15–22; 撒母耳记上 17:4"> 在那些日子和后来的日子，有巨人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="巨人——或译作“伟人”。">b</a></sup>在地上；当时神的儿子们与人的女儿们结合生子；他们是古时的勇士、有名的人物。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马太福音 15:19; 罗马书 1:28–31; 马可福音 7:21–23"> 耶和华看到人在地上罪恶深重，而且人心里的每个意念动机终日都是邪恶的。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 63:10; 撒母耳记上 15:11; 以弗所书 4:30"> 耶和华就后悔在地上造了人，心中忧伤。</span>
<span className="v" id="v7" data-v="7" data-xref="西番雅书 1:3; 诗篇 37:20; 耶利米书 12:3–4"> 耶和华说：“我要把我所创造的人，连同走兽、爬虫和天空的飞鸟，都从地面上抹掉，因为我后悔造了他们。”</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 19:19; 希伯来书 4:16; 路加福音 1:30"> 唯有挪亚在耶和华眼前蒙恩。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 1:6; 希伯来书 11:7; 彼得后书 2:5"> 以下是挪亚的家系记事：挪亚是个义人，在他的世代中是个纯全人；挪亚与神同行。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 5:32"> 挪亚生了三个儿子：闪、含、雅弗。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以西结书 8:17; 何西阿书 4:1–2; 哈巴谷书 2:8"> 那时大地在神面前败坏了，地上充满恶行。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 53:2–3; 箴言 15:3; 诗篇 14:1–3"> 神观看大地，看哪，它已经败坏了，一切有血肉的，在地上的行为都败坏了！</span>
<span className="v" id="v13" data-v="13" data-xref="何西阿书 4:1–2; 彼得前书 4:7; 以西结书 7:2–6"> 神对挪亚说：“一切有血肉的，结局已经来到我面前，因为他们使大地充满了恶行；看哪，我要把他们与这地一起毁灭！</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="彼得前书 3:20; 路加福音 17:27; 马太福音 24:38"> “你当为自己造一艘松柏<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="松柏——或译作“歌斐”。">c</a></sup>木的方舟，要给方舟造舱房，方舟里外都要涂上沥青。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 3:11; 创世记 7:20"> 你要这样造方舟：方舟长三百肘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="三百肘——相当于137.1公尺。1肘=45.7公分。">d</a></sup>，宽五十肘<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="五十肘——相当于22.9公尺。">e</a></sup>，高三十肘<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="三十肘——相当于13.7公尺。">f</a></sup>。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 8:6; 创世记 7:16; 以西结书 41:16"> 你要为方舟造一个天窗，在离顶部一肘<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="一肘——相当于45.7公分。">g</a></sup>处造好；方舟的门要设在侧面。方舟要造成上、中、下三层。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 7:4; 彼得后书 2:5; 创世记 7:21–23"> “看哪，我要使大洪水临到地上，要毁灭天下一切有生命气息的活物，地上的一切都将断气！</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 11:7; 创世记 7:7; 创世记 17:7"> 但我要与你确立我的约；你与你的儿子们、你的妻子和儿媳们要一起进入方舟。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 7:15–16; 创世记 7:8–9; 创世记 8:17"> 你要将一切活物、一切有血肉的，每样一对，公母成双，带进方舟，好使它们与你一起得以存活。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 10:11–12; 创世记 2:19; 创世记 7:8–16"> 飞鸟各从其类，走兽各从其类，地上一切爬虫各从其类，每样一对，都要来到你这里，好得以存活。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 1:29–30; 诗篇 145:16; 诗篇 136:25"> 你要从各样可吃的食物中都带上一些，收聚在你这里，作为你和它们的食物。”</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 40:16; 约翰福音 15:14; 马太福音 7:24–27"> 挪亚就这样做了；神所吩咐他的一切，他都照着做了。</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="GEN" data-book-slug="genesis" data-book-name="创世记" data-chapter="31" data-verses="55">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="传道书 4:4; 诗篇 49:16–17; 约伯记 31:31"> 雅各听见拉班儿子们说：“雅各夺取了我们父亲的一切，他从我们父亲所拥有的获得了这一切财富。”</span>
<span className="v" id="v2" data-v="2" data-xref="但以理书 3:19; 撒母耳记上 18:9–11; 创世记 4:5"> 雅各注意到拉班的脸色，看哪，对自己已经不如从前了！</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 28:15; 创世记 32:9; 希伯来书 13:5"> 耶和华对雅各说：“你当回到你祖先之地，回到你的本族，我必与你同在。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 雅各就派人去叫拉结和莉亚到田间的羊群那里，</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 31:2–3; 创世记 31:53; 创世记 48:15"> 对她们说：“我注意到你们父亲的脸色，对我已经不如从前了；但我父亲的神一直与我同在。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 30:29; 以弗所书 6:5–8; 提多书 2:9–10"> 你们知道：我尽了我的全力服事你们的父亲。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 37:28; 创世记 31:29; 民数记 14:22"> 你们的父亲却愚弄我，十次更改了我的工酬；但神不允许他伤害我。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 30:32"> 如果他说：‘羊中有点的是你的工酬’，群羊就都生有点的；如果他说：‘羊中有纹的是你的工酬’，群羊就都生有纹的。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 31:1; 创世记 31:16; 箴言 13:22"> 神就这样把你们父亲的牲畜拿走，赐给了我。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命记 13:1; 创世记 30:39; 创世记 20:6"> “在群羊的交配期，我在梦中举目观看，看哪，那些与母羊交配的公羊<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="那些与母羊交配的公羊——原文直译“那些爬上母羊的公羊”。">a</a></sup>，都是有纹、有点、有花斑的！</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 58:9; 创世记 31:13; 撒母耳记上 3:6"> 在那梦中，神的使者对我说：‘雅各！’我说：‘我在这里！’</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 3:7; 申命记 24:15; 创世记 31:42"> 他说：‘你要举目，观看所有与母羊交配的公羊<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="所有与母羊交配的公羊——原文直译“所有爬上母羊的公羊”。">b</a></sup>，都是有纹、有点、有花斑的；这是因我看见了拉班对你所做的一切。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 31:3; 创世记 32:9; 创世记 28:12–22"> 我是伯特利的神，你曾在那里膏抹了石柱，又在那里向我许了愿。现在，你要起来，离开这地，回到你本族之地！’”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路得记 4:11; 创世记 2:24; 创世记 29:24"> 拉结和莉亚就回应他，说：“在我们的父家，难道还有属于我们的份和继业吗？</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 29:15–20; 创世记 31:41; 创世记 29:27–30"> 我们不是被他看作外人吗？因为他把我们卖了，竟然彻底吞噬了我们的身价！</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 30:35–1; 创世记 31:9; 诗篇 45:10"> 神从我们父亲那里所拿走的一切财物，都属于我们和我们的儿女。现在，神所吩咐你的一切，你只管去做。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 30:17; 创世记 24:61; 创世记 24:10"> 雅各就起来让他的儿女和妻子们都骑上了骆驼。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 27:1–2; 创世记 27:41; 创世记 35:27–29"> 又带着他积聚的一切财物和他所有的牲畜，就是他在帕旦-亚兰所积聚、拥有的牲畜，往迦南地，到他父亲以撒那里。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 19:13; 创世记 31:30; 何西阿书 3:4"> 当时拉班去剪羊毛，拉结就偷了她父亲的家族神像。</span>
<span className="v" id="v20" data-v="20"> 雅各欺瞒亚兰人拉班，没有告诉他自己要逃走。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 12:17; 创世记 37:25; 创世记 46:28"> 雅各就这样带着一切属于他的逃走了；他起身，渡过大河<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="大河——指幼发拉底河。">c</a></sup>，面向基列山而去。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约伯记 5:12–13; 创世记 30:36; 出埃及记 14:5–31"> 到了第三天，有人告诉拉班：雅各逃走了。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 13:8; 创世记 24:27; 出埃及记 2:11"> 拉班就带着自己的兄弟们追赶雅各，追了七天的路程，在基列山追上了他。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 24:50; 创世记 31:29; 创世记 20:3"> 神藉着夜间的一个梦来到亚兰人拉班那里，对他说：“你要小心，不可与雅各说好说歹。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 12:8; 创世记 33:18; 希伯来书 11:9"> 拉班追上了雅各。当时雅各在山上搭起了帐篷，拉班和他的兄弟们也在基列山上搭起了帐篷。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记上 30:2; 创世记 12:18; 创世记 20:9–10"> 拉班对雅各说：“你做了什么呢？你欺瞒我，又把我的女儿们像刀剑下的俘虏那样带走。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 15:20; 箴言 26:23–26; 创世记 31:3–5"> 你为什么偷偷逃走，欺瞒我，不告诉我？不然，我可以唱歌、摇铃鼓、弹竖琴来欢送你。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 31:55; 路得记 1:14; 使徒行传 20:37"> 你又不容我亲吻我的外孙和女儿；你这样做真愚蠢！</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 31:53; 创世记 31:42; 创世记 31:24"> 我手中虽有能力加害于你们，但你父亲的神昨夜对我说：‘你要小心，不可与雅各说好说歹。’</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 10:11; 创世记 31:19; 士师记 18:24"> 现在，你因为切切思念你的父家，一定要走，但为什么偷了我的神像呢？”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="箴言 29:25; 创世记 31:26–27; 创世记 20:11"> 雅各就回应拉班，说：“因为我害怕，我想你可能会从我这里夺去你的女儿们。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 12:3–5; 创世记 31:30; 创世记 31:19"> 至于你的神像，你在谁那里找到，谁就不得存活。请你在我们众兄弟面前，指认我的东西中有什么是你的，然后把它拿去！”原来雅各并不知道拉结偷了家族神像。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="创世记 24:67; 创世记 24:28"> 于是拉班进入雅各的帐篷、莉亚的帐篷和两个女仆的帐篷，却没有找到什么；他从莉亚的帐篷出来，进入拉结的帐篷。</span>
<span className="v" id="v34" data-v="34" data-xref="创世记 31:19; 创世记 31:17"> 拉结拿了家族神像，把它们放在骆驼的鞍子下，自己坐在上面。拉班摸遍了整个帐篷，也没有找到。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="利未记 19:32; 出埃及记 20:12; 彼得前书 2:18"> 拉结对她父亲说：“请我主不要恼火，我不能在你面前起来，因为我正有月事。”拉班搜来搜去，却没有找到家族神像。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以弗所书 4:26; 创世记 49:7; 民数记 16:15"> 于是雅各就恼火，与拉班争论。雅各对拉班说：“我有什么过犯，有什么罪，让你对我穷追不舍呢？</span>
<span className="v" id="v37" data-v="37" data-xref="彼得前书 2:12; 哥林多前书 6:4–5; 撒母耳记上 12:3–4"> 你摸遍了我所有的东西，找到你家的什么东西了吗？摆出来啊！放在你我的众兄弟面前，让他们在你我二人之间评评理！</span>
<span className="v" id="v38" data-v="38" data-xref="创世记 30:27; 申命记 28:4; 以西结书 34:2–4"> 这二十年来，我与你在一起；你的母绵羊、母山羊没有掉过胎；你羊群中的公绵羊，我也没有吃过。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及记 22:31; 出埃及记 22:10–13; 利未记 22:8"> 被野兽咬死的，我没有带来给你，是我自己赔上的；无论是白天被偷的，还是夜间被偷的，你都从我手中索要。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 2:8; 出埃及记 2:19–22; 彼得前书 5:2–4"> 我常常这样：白天受尽炎热，夜间受尽寒霜，不得合眼睡觉。</span>
<span className="v" id="v41" data-v="41" data-xref="创世记 31:7; 哥林多前书 15:10; 哥林多后书 11:26"> 这二十年来，我在你家里，为你的两个女儿服事了你十四年，为你的羊群服事了你六年；你还十次更改了我的工酬。</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 31:7; 创世记 31:53; 以赛亚书 8:13"> 要不是我父亲的神，亚伯拉罕的神，以撒所敬畏的那一位与我同在，你现在一定会打发我空手而去。神看到我的苦情和我手上的辛劳，就在昨夜责备了你。”</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43"> 拉班回应雅各，说：“女儿们都是我的女儿，孩子们都是我的孩子，羊群也是我的羊群，你所看见的一切都是我的。我今天能为<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="为——或译作“对”。">d</a></sup>我的女儿们和她们所生的孩子做些什么呢？</span>
<span className="v" id="v44" data-v="44" data-xref="创世记 31:52; 约书亚记 24:25–27; 约书亚记 22:27"> 来吧，现在让你我二人立约，作你我之间的见证。”</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="创世记 28:18–22"> 雅各就拿了一块石头，把它立起来作石柱。</span>
<span className="v" id="v46" data-v="46" data-xref="传道书 3:5; 创世记 31:23; 创世记 31:54"> 接着雅各对他的兄弟们说：“你们去捡石头。”他们就把石头拿来，堆成石堆，然后就在石堆旁边吃喝。</span>
<span className="v" id="v47" data-v="47" data-xref="希伯来书 12:1"> 拉班称那石堆为伊迦尔-撒哈杜他<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="伊迦尔-撒哈杜他——亚兰文词语；意思是“作为见证的石堆”。">e</a></sup>，雅各却称它为迦累得<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="迦累得——希伯来文词语；意思是“作为见证的石堆”。">f</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="约书亚记 24:27; 约书亚记 13:8–9; 创世记 31:23"> 拉班说：“今天，这石堆就是你我之间的见证。”因此，这石堆名叫迦累得，</span>
<span className="v" id="v49" data-v="49" data-xref="士师记 11:29; 士师记 10:17; 撒母耳记上 7:5–6"> 又叫米斯巴，因为拉班说：“当我们彼此远离了对方的视线之后，愿耶和华在你我中间守望。</span>
<span className="v" id="v50" data-v="50" data-xref="耶利米书 42:5; 耶利米书 29:23; 弥迦书 1:2"> 如果你苦待我的女儿们，或者在我的女儿之外，又娶了妻子；就算没有人与我们各人在一起，看吧，神就是你我之间的见证。”</span>
<span className="v" id="v51" data-v="51"> 拉班对雅各说：“看哪，这石堆！看哪，这石柱！是我在你我之间放置的；</span>
<span className="v" id="v52" data-v="52" data-xref="创世记 31:48; 创世记 31:44–45"> 这石堆就是见证，这石柱就是见证：我必不越过这石堆去害你，你也绝不可越过这石堆和这石柱来害我。</span>
<span className="v" id="v53" data-v="53" data-xref="创世记 31:42; 创世记 16:5; 约书亚记 24:2"> 愿亚伯拉罕的神和拿鹤的神，就是他们父亲的神，在你我之间做判断。”雅各就指着他父亲以撒所敬畏的那一位起誓。</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及记 18:12; 创世记 37:25; 创世记 26:30"> 于是雅各在山上献祭，又叫他的兄弟们来吃饭。他们吃了饭，就在山上过夜。</span>
<span className="v" id="v55" data-v="55" data-xref="创世记 31:28; 申命记 23:5; 创世记 18:33"> 拉班清早起来，亲吻他的外孙和女儿，并祝福了他们。然后拉班离开那里，回自己的地方去了。</span>
</div>
</div>

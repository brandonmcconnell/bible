<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="GEN" data-book-slug="genesis" data-book-name="创世记" data-chapter="14" data-verses="24">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 10:10; 创世记 10:22; 以赛亚书 37:12"> 在暗拉非作示拿王、阿约克作以拉撒王、基大劳玛作以拦王、提达作戈印王的日子里，</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 13:10; 申命记 29:23; 创世记 10:19"> 他们与所多玛王比拉、格摩拉王比沙、押玛王示纳、洗扁王善以别、比拉王作战；比拉就是琐珥。</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 3:16; 申命记 3:17; 民数记 34:12"> 这五王都在西订谷会合；西订谷就是盐海。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="创世记 9:25–26; 以西结书 17:15"> 这五王曾经服事了基大劳玛十二年，但在第十三年背叛了。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 3:11; 创世记 15:20; 申命记 1:4"> 第十四年，基大劳玛和同盟的王都来了，在亚特律-加宁击败了利乏音人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="利乏音人——或译作“巨人”。">a</a></sup>，在哈麦击败了苏西人，在沙微-基列亭击败了以米人，</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 2:22; 申命记 2:12; 创世记 21:21"> 在何利人的西珥山击败了何利人，一直打到靠近旷野的伊勒-帕兰。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 20:2; 创世记 16:14; 创世记 20:1"> 然后他们返回，来到恩米示帕，就是加低斯，征服了亚玛力人的全境，击败了住在哈洗逊-塔玛尔的亚摩利人。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="创世记 19:22; 创世记 13:10; 创世记 19:20"> 于是所多玛王、格摩拉王、押玛王、洗扁王和比拉王，就是琐珥王都出来，在西订谷摆阵与他们作战，</span>
<span className="v" id="v9" data-v="9"> 就是与以拦王基大劳玛、戈印王提达、示拿王暗拉非、以拉撒王阿约克作战；这就是四王对五王。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 19:17; 创世记 19:30; 以赛亚书 24:18"> 西订谷有许多沥青坑；所多玛王和格摩拉王逃跑时，掉进坑里，其余的人都往山里逃跑。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 14:21; 创世记 14:16; 申命记 28:31"> 那四王把所多玛和格摩拉一切的财物以及他们所有的粮食都掳掠而去。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 12:5; 创世记 11:27; 启示录 3:19"> 他们也把亚伯兰兄弟的儿子罗得和他的财物掳掠而去。当时罗得正住在所多玛。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 13:18; 创世记 14:24; 创世记 40:15"> 有一个逃脱的人来告诉希伯来人亚伯兰，那时他正居住在亚摩利人幔利的橡树那里；幔利是以实格和阿内尔的兄弟，他们是亚伯兰的盟友。</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 18:29; 创世记 15:3; 创世记 17:27"> 亚伯兰听说他的侄子<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="侄子——原文直译“兄弟”。">b</a></sup>被掳走了，就出动家里生养的、训练有素的家丁三百一十八人，一直追到但。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 9:2; 诗篇 112:5; 列王纪上 15:18"> 他和他的仆人们在夜间兵分几路，击败敌人，又追赶他们，直到大马士革北面的赫巴。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 30:18–19; 撒母耳记上 30:8; 创世记 12:2"> 他把一切的财物都夺了回来，也把他的侄子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="侄子——原文直译“兄弟”。">c</a></sup>罗得和罗得的财物，以及妇女和民众都夺了回来。</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 18:18; 箴言 19:4; 希伯来书 7:1"> 亚伯兰击败基大劳玛及其同盟的王回来之后，所多玛王就出来，在沙微谷迎接他；沙微谷就是帝王谷。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 6:20–3; 诗篇 110:4; 希伯来书 5:6"> 又有撒冷王麦基洗德带着饼和酒出来；他是至高神的祭司。</span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 7:6–7; 创世记 14:22; 诗篇 24:1"> 他祝福亚伯兰，说：<br /><span className="pl pl-1">“愿至高神、天地的主宰祝福亚伯兰！</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="创世记 28:22; 希伯来书 7:4–9; 玛拉基书 3:10"> <span className="pl pl-1">至高神是当受颂赞的！</span><br /><span className="pl pl-1">他把你的敌人交在你的手中。”</span><br />亚伯兰就把所有的十分之一献给他。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 所多玛王对亚伯兰说：“人，你交给我；财物，你自己拿去吧。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="但以理书 12:7; 但以理书 4:34; 申命记 32:40"> 但亚伯兰对所多玛王说：“我曾经向耶和华至高神、天地的主宰举手起誓<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="起誓——辅助词语。">d</a></sup>：</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 5:16; 哥林多后书 11:9–12; 以斯帖记 9:15–16"> 任何属于你的东西，就是一根线、一根鞋带，我也绝不会拿，以免你说：‘是我使亚伯兰富有。’</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 14:13; 箴言 3:27; 马太福音 7:12"> 除了我仆人们所吃的以及同行的阿内尔、以实格和幔利所应得的份，我什么都不要；让他们拿去所应得的份吧。”</span>
</div>
</div>

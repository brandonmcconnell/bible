<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 3:2; 创世记 48:10; 创世记 25:23–25"> 以撒年老的时候，眼睛衰弱<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="衰弱——或译作“暗淡”。">a</a></sup>，以致不能看见，就把他的大儿子以扫叫来，说：“我儿啊！”<br />以扫说：“我在这里！”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="雅各书 4:14; 传道书 9:10; 箴言 27:1"> 他说：“看哪，我已经老了，不知道哪一天会死。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 25:27–28; 创世记 10:9; 哥林多前书 6:12"> 现在拿上你的猎具，箭囊和弓，到田野去为我打些野味。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 11:20; 创世记 48:9; 创世记 49:28"> 你要照我所喜爱的，为我做成美食，拿来给我吃，好让我在死之前祝福你。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 以撒对他儿子以扫说话时，莉百加也在听。在以扫去田野猎取野味的时候，</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 25:28"> 莉百加对她儿子雅各说：“看哪，我听到你父亲对你哥哥以扫说：</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 6:26; 撒母耳记上 24:19; 申命记 33:1"> ‘你把野味带回来，做成美食给我吃，好让我在死之前，在耶和华面前祝福你。’</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 6:1; 创世记 27:13; 使徒行传 5:29"> 我儿啊，你现在当按着我吩咐你的，听我的话——</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 13:15; 撒母耳记上 16:20"> 到羊群中去，从那里给我牵两只上好的小山羊来，让我照你父亲所喜爱的，为他做成美食；</span>
<span className="v" id="v10" data-v="10"> 然后你拿去给你父亲吃，好让他在死之前祝福你。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="创世记 25:25"> 雅各对他母亲莉百加说：“看哪，我哥哥以扫多毛，而我皮肤光滑。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 27:18; 创世记 25:27; 玛拉基书 1:14"> 要是我父亲摸我，那我在他眼中看起来就像骗子，我也就给自己带来诅咒，而不是祝福了。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马太福音 27:25; 撒母耳记上 25:24; 撒母耳记下 14:9"> 但他母亲对他说：“我儿啊，愿你的诅咒归于我！你只管听我的话；去吧，把小山羊牵给我。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="创世记 27:9; 箴言 23:2–3; 创世记 25:28"> 他就去，把小山羊牵来，带给他母亲。他母亲就照他父亲所喜爱的做成美食。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 27:27; 路加福音 20:46; 路加福音 15:22"> 莉百加拿了大儿子以扫在家里最好的衣服，给小儿子雅各穿上；</span>
<span className="v" id="v16" data-v="16"> 又用小山羊的皮，包在雅各手上和他脖子上的光滑处；</span>
<span className="v" id="v17" data-v="17"> 然后把自己做好的美食和饼，交在她儿子雅各的手中。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 雅各来到他父亲那里，说：“我父啊！”<br />以撒说：“我在这里！我儿啊，你是谁呢？”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 28:15; 马太福音 26:70–74; 撒迦利亚书 13:3–4"> 雅各对他父亲说：“我是你的长子以扫，我已照着你吩咐我的去做了。请坐起来，吃我的野味，好为我祝福。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 20:7; 约伯记 13:7; 创世记 24:12"> 以撒对他儿子说：“我儿啊，你怎么这样快就打到了呢？”雅各回答：“因为耶和华你的神成全了我。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="雅各书 4:8; 以赛亚书 57:19; 创世记 27:12"> 以撒对雅各说：“我儿啊，靠近我，让我摸摸你，你真是我儿子以扫吗？”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 雅各就靠近他父亲以撒。以撒摸着他，说：“声音是雅各的声音，手却是以扫的手。”</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 27:16; 希伯来书 11:20; 罗马书 9:11–12"> 以撒没有认出他来，因为他的手像他哥哥以扫的手那样多毛。于是以撒就要祝福他，</span>
<span className="v" id="v24" data-v="24" data-xref="歌罗西书 3:9; 以弗所书 4:25; 箴言 12:22"> 又问：“你真是我儿子以扫吗？”<br />他说：“我是。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 27:4"> 以撒说：“把野味拿近一点，让我吃我儿子的野味，好为你祝福。”雅各就拿给他，他就吃了；又递酒给他，他也喝了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26"> 他父亲以撒对他说：“我儿啊，靠近一点亲吻我。”</span>
<span className="v" id="v27" data-v="27" data-xref="希伯来书 6:7; 诗篇 65:10; 希伯来书 11:20"> 雅各就靠近亲吻了父亲；以撒闻到雅各衣服的气味，就祝福他，说：<br /><span className="pl pl-1">“啊，我儿子的气味就像耶和华所祝福的田野的气味！</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="申命记 33:28; 申命记 33:13; 诗篇 133:3"> <span className="pl pl-1">愿神赐给你天上的甘露，</span><br /><span className="pl pl-1">地上的丰饶，</span><br /><span className="pl pl-1">以及丰盛的五谷和新酒。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="创世记 12:3; 民数记 24:9; 以赛亚书 49:23"> <span className="pl pl-1">愿万民服事你，</span><br /><span className="pl pl-1">万族向你下拜；</span><br /><span className="pl pl-1">愿你成为你兄弟们的主人，</span><br /><span className="pl pl-1">你母亲的儿子们向你下拜。</span><br /><span className="pl pl-1">诅咒你的人，愿他受诅咒；</span><br /><span className="pl pl-1">祝福你的人，愿他蒙祝福。”</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 以撒祝福完雅各，雅各刚从父亲以撒面前离去，他哥哥以扫就打猎回来了。</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 27:4"> 以扫也做了美食，拿给他父亲，对父亲说：“我父啊，请起来，吃你儿子的野味，好为我祝福。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="创世记 27:18"> 他父亲以撒对他说：“你是谁呢？”<br />他说：“我是你的儿子，你的长子以扫。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="创世记 28:3–4; 罗马书 11:29; 以弗所书 1:3"> 以撒就大大战兢，说：“是谁打了野味，刚刚拿给我呢？在你来之前，我已经全吃了；我也祝福了那人，他将来必蒙祝福。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="希伯来书 12:17; 箴言 1:31; 撒母耳记上 30:4"> 以扫听了他父亲的话，就极其痛苦地号啕大哭，对父亲说：“我父啊，祝福我，也祝福我吧！”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="帖撒罗尼迦前书 4:6; 约伯记 13:7; 玛拉基书 2:10"> 以撒说：“你弟弟心怀诡计地前来，已经夺取了你的祝福。”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="创世记 25:26; 约翰福音 1:47; 创世记 32:28"> 以扫说：“他名叫雅各不是名副其实吗？他两次都欺骗了<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="欺骗了——或译作“抓取了”。">b</a></sup>我：他先夺取了我长子的名份，看哪，他现在又夺取了我的祝福！”以扫又说：“难道你没有留下什么祝福给我吗？”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="撒母耳记下 8:14; 创世记 27:28–29; 创世记 25:23"> 以撒就回答以扫，说：“看哪，我已经立他为你的主人，又把他所有的兄弟给他为仆人，并把五谷和新酒供给了他。我儿啊，现在我还能为你做什么呢？”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="希伯来书 12:17; 创世记 27:34; 以赛亚书 65:14"> 以扫对他父亲说：“我父啊，难道你只有这一个祝福吗？我父啊，求你也祝福我！”以扫就放声大哭。</span>
</div>
<div className="bp poetry">
<span className="v" id="v39" data-v="39" data-xref="创世记 27:28; 希伯来书 11:20; 约书亚记 24:4"> 他父亲以撒回答他，说：<br /><span className="pl pl-1">“看哪，你居住之处必远离地上的丰饶，</span><br /><span className="pl pl-1">远离天上的甘露。</span><br /></span>
<span className="v" id="v40" data-v="40" data-xref="列王纪下 8:20–22; 创世记 25:23; 历代志下 25:11–12"> <span className="pl pl-1">你必靠着你的刀剑生存，</span><br /><span className="pl pl-1">也必服事你的弟弟；</span><br /><span className="pl pl-1">到了你奋起反抗的时候，</span><br /><span className="pl pl-1">你必从颈项上挣脱他的轭。”</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="约翰一书 3:12–15; 创世记 37:4; 创世记 50:3–4"> 以扫因父亲祝福了雅各，就记恨雅各。以扫对自己说：“为父亲举哀的日子临近了，之后我就要杀死弟弟雅各。”</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="创世记 37:18–20; 撒母耳记上 30:5; 创世记 42:21–22"> 当大儿子以扫的话传到莉百加那里，她就派人把小儿子雅各叫来，说：“看哪，你哥哥以扫想要杀你泄恨！</span>
<span className="v" id="v43" data-v="43" data-xref="创世记 27:8; 创世记 11:31; 创世记 27:13"> 我儿啊，现在你当听我的话；起来！逃往哈兰，到我哥哥拉班那里去，</span>
<span className="v" id="v44" data-v="44" data-xref="创世记 31:38; 创世记 31:41"> 与他一同住些日子，直到你哥哥的怒火消退了——</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 19:21; 创世记 4:8–16; 创世记 9:5–6"> 等到你哥哥对你的怒气转消了，忘记你对他所做的事，那时我就会派人把你从那里接回来。我为什么在一天之内要丧失你们两个呢？”</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="创世记 24:3; 创世记 26:34–35; 创世记 28:8"> 莉百加对以撒说：“因这些赫提的女子，我连活着都厌烦了。如果雅各也从这地的女子中，娶了像这样的赫提女子为妻，我活着还有什么意义呢？”</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 2:4; 创世记 9:7; 创世记 5:1"> 以下是挪亚的儿子闪、含、雅弗的谱系：<br />洪水之后，他们都生了儿子。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="以西结书 38:2; 以西结书 38:6; 启示录 20:8"> 雅弗的儿子是格梅尔、玛格、玛代、雅完、图巴、米设、提拉。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 27:14; 耶利米书 51:27"> 格梅尔的儿子是阿实基拿、利法特、陀伽玛。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理书 11:30; 以赛亚书 23:12; 民数记 24:24"> 雅完的儿子是以利沙、塔尔施、基提、罗单。</span>
<span className="v" id="v5" data-v="5" data-xref="西番雅书 2:11; 以赛亚书 42:4; 耶利米书 2:10"> 沿海列国的人是从这些人分散到自己地方的，各按自己的语言、自己的宗族、自己的民族。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="历代志上 1:8–16; 以西结书 27:10; 诗篇 105:23"> 含的儿子是库实、麦西、普特、迦南。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 27:22; 以西结书 27:15; 以赛亚书 21:13"> 库实的儿子是西拔、哈腓拉、撒弗他、拉玛、撒弗提迦。拉玛的儿子是示巴、底但。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="弥迦书 5:6"> 库实又生了宁录；宁录是地上第一个强人。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 28:22; 创世记 6:11; 创世记 25:27"> 他在耶和华面前是个强大的猎手，因此有话说：“像宁录那样，在耶和华面前是个强大的猎手。”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 11:9; 创世记 11:2; 创世记 14:1"> 他的王国起始于示拿地的巴别<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="巴别——就是巴比伦。">a</a></sup>、乌鲁克、阿卡德、卡勒尼。</span>
<span className="v" id="v11" data-v="11" data-xref="弥迦书 5:6; 诗篇 83:8; 那鸿书 1:1"> 他从那地出来，往亚述去，建造了尼尼微、利河伯-以珥、迦拉，</span>
<span className="v" id="v12" data-v="12"> 以及在尼尼微和迦拉之间的利鲜，它是一座大城<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="大城——或指“迦拉”。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志上 1:11–12; 耶利米书 46:9; 以西结书 30:5"> 麦西生了吕底亚人、亚拿米人、利哈比人、拿弗土希人、</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 47:4; 历代志上 1:12; 申命记 2:23"> 帕斯鲁细人、迦斯路希人、迦斐托人；非利士人源于迦斯路希人。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数记 34:2–15; 出埃及记 34:11; 创世记 23:3"> 迦南生了长子西顿，又生了赫提，</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 24:18; 士师记 1:21; 撒迦利亚书 9:7"> 接着是耶布斯人、亚摩利人、革迦撒人、</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 34:2"> 希未人、亚基人、西尼人、</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 18:22; 撒母耳记下 8:9; 以西结书 27:8"> 亚瓦底人、洗玛利人、哈马人。后来迦南的各宗族就分散了。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 14:2; 创世记 19:24–25; 约书亚记 12:7–8"> 迦南的边界从西顿延伸到基拉耳，直到加沙；又延伸到所多玛、格摩拉、押玛、洗扁，直到拉沙。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 10:6; 创世记 11:1–9"> 以上是含的子孙，各按自己的宗族、自己的语言、自己的地方、自己的民族。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数记 24:24; 创世记 11:10–26"> 闪也生了儿子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="儿子——辅助词语。">c</a></sup>；闪是希伯所有子孙的祖先，是雅弗的哥哥。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 66:19; 耶利米书 25:25; 创世记 14:1–9"> 闪的儿子是以拦、亚述、亚法撒、吕底亚、亚兰。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约伯记 1:1; 耶利米书 25:20"> 亚兰的儿子是乌斯、户勒、基帖、玛施。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 3:35; 创世记 11:12–15"> 亚法撒生了沙拉，沙拉生了希伯。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志上 1:19; 创世记 10:32; 申命记 32:8"> 希伯生了两个儿子，一个名叫法勒，因为在他的日子里，地上的人分开了；法勒的兄弟名叫约坍。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志上 1:20–28"> 约坍生了亚摩达、沙列、哈萨玛非、耶拉、</span>
<span className="v" id="v27" data-v="27" data-xref="历代志上 1:20–28"> 哈多兰、乌萨、德拉、</span>
<span className="v" id="v28" data-v="28" data-xref="历代志上 1:20–28; 列王纪上 10:1; 创世记 25:3"> 俄巴路、亚比玛利、示巴、</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪上 9:28; 历代志上 9:13; 创世记 2:11"> 俄斐、哈腓拉、约巴。这些全都是约坍的儿子。</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 23:7"> 他们居住的地方从米沙延伸到东方的山地悉法。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="创世记 10:5; 创世记 10:20; 使徒行传 17:26"> 以上是闪的子孙，各按自己的宗族、自己的语言、自己的地方、自己的民族。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="创世记 9:19; 使徒行传 17:26; 创世记 10:1"> 这些就是挪亚子孙的宗族，各按自己的家系、自己的民族。洪水之后，地上的万国都是从他们分散出来的。</span>
</div>
</div>

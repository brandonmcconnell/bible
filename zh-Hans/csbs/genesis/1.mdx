<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 1:1–3; 希伯来书 11:3; 以赛亚书 45:18"> 起初，神创造诸天和大地。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="耶利米书 4:23; 诗篇 104:30; 以赛亚书 45:18"> 那时大地空虚混沌，黑暗在渊面上，神的灵运行在水面上。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 4:6; 约翰福音 1:5; 以赛亚书 45:7"> 神说：“要有光”，就有了光。</span>
<span className="v" id="v4" data-v="4" data-xref="传道书 2:13; 创世记 1:18; 传道书 11:7"> 神看光是好的。神把光和黑暗分开，</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 74:16; 以赛亚书 45:7; 帖撒罗尼迦前书 5:5"> 神称光为“昼”，称黑暗为“夜”。有晚上，有早晨；这是第一日。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="耶利米书 51:15; 诗篇 33:6; 约伯记 37:18"> 神说：“让众水之间有穹苍，把水和水分开。”</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 8:28–29; 诗篇 148:4; 马太福音 8:27"> 神就造了穹苍，把穹苍以下的水和穹苍以上的水分开。事情就如此成就了。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 1:5; 创世记 1:19; 创世记 1:10"> 神称穹苍为“天”。有晚上，有早晨；这是第二日。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="彼得后书 3:5; 约拿书 1:9; 耶利米书 5:22"> 神说：“让天底下的水聚集到一处，让干处显现。”事情就如此成就了。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 32:4; 诗篇 104:31; 创世记 1:4"> 神称干处为“地”，称水的聚集之处为“海”。神看这是好的。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 104:14–17; 希伯来书 6:7; 诗篇 147:8"> 神说：“让地长出植物——结种子的蔬草和结果实的果树，各从其类，地上的果实中都有种子。”事情就如此成就了。</span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 4:28; 以赛亚书 55:10–11; 马太福音 13:24–26"> 地就生出了植物——结种子的蔬草，各从其类；还有结果实、果实中有种子的树，各从其类。神看这是好的。</span>
<span className="v" id="v13" data-v="13"> 有晚上，有早晨；这是第三日。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="诗篇 104:19–20; 申命记 4:19; 耶利米书 31:35"> 神说：“让天上的穹苍中有光体来分昼夜，让它们成为标记来定节令、日子和年岁；</span>
<span className="v" id="v15" data-v="15"> 让它们在天上穹苍中发光来照亮大地。”事情就如此成就了。</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 136:7–9; 申命记 4:19; 诗篇 8:3"> 神造了两个大光体：大的管昼，小的管夜，又造了星辰；</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 8:3; 诗篇 8:1; 约伯记 38:12"> 神把它们安置在天上的穹苍中来照亮大地，</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 31:35; 诗篇 19:6"> 分管昼与夜，并分开光与黑暗。神看这是好的。</span>
<span className="v" id="v19" data-v="19"> 有晚上，有早晨；这是第四日。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 2:19; 诗篇 104:24–25; 列王纪上 4:33"> 神说：“让水中繁衍成群的活物，让飞鸟在大地之上、在天上的穹苍中飞翔。”</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 104:24–26; 创世记 1:25; 创世记 8:19"> 神就创造了海中的巨兽和水中群聚、游动的各样活物，各从其类；又创造了各样有翅膀的飞鸟，各从其类。神看这是好的。</span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 40:15; 创世记 8:17; 诗篇 107:38"> 神祝福它们说：“要繁衍增多、充满海洋，也让飞鸟在大地上增多。”</span>
<span className="v" id="v23" data-v="23"> 有晚上，有早晨；这是第五日。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="诗篇 50:9–10; 创世记 6:20; 创世记 8:19"> 神说：“让地上生出活物，各从其类：牲畜、爬虫和地上的走兽，都各从其类。”事情就如此成就了。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 27:5; 约伯记 12:8–10; 创世记 2:19–20"> 于是神造了地上的走兽，各从其类；又造牲畜，各从其类；并地上一切的爬虫，各从其类。神看这是好的。</span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="歌罗西书 3:10; 以弗所书 4:24; 诗篇 8:4–8"> 神说：“让我们照着我们的形象、按着我们的样式造人；让他们管理海里的鱼、天空的飞鸟、地上的走兽，以及全地和其上活动的一切爬虫。”</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 19:4; 以弗所书 2:10; 创世记 5:1–2"> <span className="pl pl-1">于是，神照着自己的形象创造人，</span><br /><span className="pl pl-1">照着神的形象创造了人，</span><br /><span className="pl pl-1">他创造了男人和女人。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="创世记 9:1; 创世记 9:7; 利未记 26:9"> 神祝福他们，又对他们说：“要繁衍增多，充满大地，并要制伏这地；也要管理海里的鱼、天空的飞鸟，以及在地上爬行的一切活物。”</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 9:3; 诗篇 104:14–15; 诗篇 145:15–16"> 神说：“看哪，我把全地上一切结种子的蔬草和一切果实中带种子的树，都赐给你们；这些都可作为你们的食物。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 104:14; 诗篇 145:15–16; 诗篇 147:9"> 至于地上的一切走兽、天空的一切飞鸟和在地上爬行的一切有气息的活物，我把各样绿色植物都赐给它们作食物。”事情就如此成就了。</span>
<span className="v" id="v31" data-v="31" data-xref="提摩太前书 4:4; 诗篇 104:24; 诗篇 19:1–2"> 神看着他所造的一切，看哪，都非常好！有晚上，有早晨；这是第六日。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约伯记 5:2; 创世记 29:31; 创世记 37:11"> 拉结见自己没有为雅各生孩子，就嫉妒她的姐姐，对雅各说：“你给我孩子！不然我就死了。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="创世记 16:2; 诗篇 127:3; 列王纪下 5:7"> 雅各的怒气就向拉结发作，说：“我难道能代替神吗？是他不让你腹中有胎儿。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 50:23; 约伯记 3:12; 路得记 4:11"> 拉结就说：“我的女仆碧拉在这里，你与她同房，使她生孩子归于我膝下<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="生孩子归于我膝下——原文直译“生在我的膝上”。">a</a></sup>，好让我藉着她立后<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="立后——原文直译“被建立”。">b</a></sup>。”</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 35:22; 创世记 21:10; 撒母耳记下 12:11"> 于是拉结把她的婢女碧拉给雅各作妾，雅各就与她同房。</span>
<span className="v" id="v5" data-v="5"> 碧拉怀孕，为雅各生了一个儿子。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米哀歌 3:59; 诗篇 35:24; 诗篇 43:1"> 拉结说：“神为我伸了冤，他确实垂听我的声音，赐给了我一个儿子。”因此给孩子起名为但。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 拉结的婢女碧拉又怀孕，为雅各生了第二个儿子。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 32:24–25; 创世记 23:6; 创世记 49:21"> 拉结就说：“我与姐姐大大地相争，并且得胜了。”于是给孩子起名为拿弗他利。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 30:4; 创世记 30:17; 创世记 29:35"> 莉亚见自己停止了生育，就把自己的婢女悉帕带来给雅各作妾。</span>
<span className="v" id="v10" data-v="10"> 莉亚的婢女悉帕也为雅各生了一个儿子。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 49:19; 以赛亚书 65:11; 创世记 35:26"> 莉亚就说：“幸运来临！”于是给孩子起名为迦得。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 后来莉亚的婢女悉帕又为雅各生了第二个儿子。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 1:48; 箴言 31:28; 雅歌 6:9"> 莉亚说：“我真有福啊！众女子都会称我有福。”于是给孩子起名为亚设。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="雅歌 7:13; 创世记 25:30"> 在收割小麦的日子里，鲁本出去，在田野中找到一些风茄，就把它们带回来给他母亲莉亚。拉结对莉亚说：“请把你儿子的风茄给我一些。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数记 16:13; 哥林多前书 4:3; 民数记 16:9–10"> 莉亚对她说：“难道你夺取了我丈夫还不够，又要夺取我儿子的风茄吗？”<br />拉结说：“那好，为了换取你儿子的风茄，今夜他可以与你同睡。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 到了傍晚，雅各从田野回来的时候，莉亚就出来迎接他，说：“你要与我同房，因为我用我儿子的风茄着着实实雇下了你。”那一夜，雅各就与她同睡。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 30:6; 创世记 30:22; 出埃及记 3:7"> 神听允了莉亚，她就怀孕，为雅各生了第五个儿子。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 49:14–15; 申命记 33:18; 创世记 46:13"> 莉亚说：“神给了我赏报，因为我把自己的婢女给了我的丈夫。”于是给孩子起名为以萨迦。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 莉亚又怀孕，为雅各生了第六个儿子。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 35:23; 马太福音 4:13; 创世记 49:13"> 莉亚说：“神赐给了我美好的礼物，这次我丈夫必重视我<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="必重视我——或译作“必与我同住”。">c</a></sup>，因为我为他生了六个儿子。”于是给孩子起名为西布伦。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 34:1–3; 创世记 34:26; 创世记 46:15"> 后来莉亚生了一个女儿，给她起名为狄娜。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="创世记 29:31; 诗篇 113:9; 诗篇 127:3"> 神也记念拉结，听允了她，使她能生育<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="使她能生育——原文直译“开了她的胎”。">d</a></sup>。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 1:25; 创世记 29:31; 路加福音 1:27"> 拉结怀孕，生了一个儿子，就说：“神除去了我的羞辱。”</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 49:22–26; 创世记 35:24; 创世记 37:2"> 于是给孩子起名为约瑟，说：“愿耶和华再给我增添一个儿子。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 24:54; 创世记 24:56; 创世记 28:15"> 拉结生了约瑟以后，雅各就对拉班说：“请打发我走吧，让我回到自己的地方、自己的故土！</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 29:30; 何西阿书 12:12; 创世记 31:26"> 请把我的妻子们和孩子们给我——为了他们，我服事了你；让我走吧！我怎样服事你，你是知道的。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路得记 2:13; 使徒行传 7:10; 以赛亚书 61:9"> 拉班对他说：“如果我在你眼前蒙恩，就请留下<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="就请留下——辅助词语。">e</a></sup>；我占卜得知，耶和华是因你的缘故才祝福我的。”</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 29:15; 创世记 29:19"> 又说：“请你定你的工酬吧，我必给你。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="创世记 31:6; 创世记 31:38–40; 彼得前书 2:18"> 雅各就对他说：“我怎样服事你，你的牲畜在我这里怎样，你是知道的。</span>
<span className="v" id="v30" data-v="30" data-xref="提摩太前书 5:8; 哥林多后书 12:14; 申命记 11:10"> 其实在我来之前，你拥有的很少，后来却大大增多了；耶和华随着我的脚踪祝福了你；而如今，我什么时候才能为自己的家做点事呢？”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 21:4–6; 希伯来书 13:5; 诗篇 118:8"> 拉班说：“我该给你什么呢？”<br />雅各说：“你什么也不必给我；只要你答应我一件事<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="答应我一件事——原文直译“为我做一件事”。">f</a></sup>，我就继续放牧、看守你的羊群。</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 31:8; 创世记 31:10; 创世记 30:35"> 请让我今天走遍你的羊群，从中挑出全部有点、有斑的羊，绵羊羔中全部黑色的，山羊中有斑、有点的，作为我的工酬。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 13:14; 撒母耳记下 22:21; 撒母耳记上 26:23"> 日后你来查看我所得的工酬时，要是我这里的山羊中有任何一只不是有点、有斑的，绵羊羔中有任何一只不是黑色的，就算是我偷来的。这样我的公义就为我辩护了。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 7:7; 民数记 22:29; 哥林多前书 14:5"> 拉班说：“好，就照着你说的！”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="创世记 31:9"> 然而就在那一天，拉班挑出了有纹、有斑的公山羊，以及全部有点、有斑和掺杂白色的母山羊，还有全部黑色的绵羊羔，都交在自己儿子们的手中；</span>
<span className="v" id="v36" data-v="36"> 又使自己和雅各之间相距三天的路程。雅各就放牧拉班其余的羊群。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="创世记 31:9–13; 以西结书 31:8"> 雅各拿杨树、杏树和枫树的嫩枝，剥出白色条纹，使枝子露出白色部分。</span>
<span className="v" id="v38" data-v="38"> 然后他把剥好的枝子插在水槽——羊群来喝水的槽里，对着羊群。羊来喝水的时候，彼此交配。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及记 12:35–36; 创世记 31:9–12; 创世记 31:40"> 羊在枝子前面交配，就生下有纹、有点、有斑的。</span>
<span className="v" id="v40" data-v="40"> 雅各就把绵羊羔分出来，又使羊群面向拉班羊群中有纹的和全部黑色的；他把自己的羊群另放一处，不放在拉班的羊群中。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41"> 每当比较肥壮的羊交配时，雅各就把枝子插在水槽里，就在羊的眼前，使它们在枝子那里交配。</span>
<span className="v" id="v42" data-v="42"> 而当瘦弱的羊交配的时候，他就不插枝子。这样，瘦弱的就归拉班，肥壮的就归雅各。</span>
<span className="v" id="v43" data-v="43" data-xref="创世记 24:35; 创世记 30:30; 创世记 26:13–14"> 于是雅各变得极其昌盛，拥有许多羊群、婢女、男仆、骆驼和驴子。</span>
</div>
</div>

</div>

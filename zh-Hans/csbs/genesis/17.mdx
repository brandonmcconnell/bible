<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="腓立比书 4:13; 以弗所书 3:20; 路加福音 1:6"> 亚伯兰九十九岁时，耶和华向亚伯兰显现，对他说：“我是全能的神，你当行在我面前，作纯全人。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 17:4–6; 创世记 12:2; 诗篇 105:8–11"> 我要在你我之间立约，我要使你的后裔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="的后裔——辅助词语。">a</a></sup>大大增多。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="士师记 13:20; 创世记 17:17; 民数记 16:45"> 亚伯兰脸伏于地；神又对他说：</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 35:11; 加拉太书 3:28–29; 创世记 12:2"> “看哪，我的约是与你立的，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="我的约是与你立的，——或译作“以下是我与你所立的约：”。">b</a></sup>你将成为多国之父！</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 1:21–23; 尼希米记 9:7; 创世记 17:15"> 你的名字不再叫亚伯兰，而要叫亚伯拉罕，因为我已立你为多国之父。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 17:4; 马太福音 1:6–17; 创世记 35:11"> 我要使你大大繁衍，多国因你而立，多王从你而出。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 9:7–9; 使徒行传 2:39; 创世记 26:24"> 我要与你以及你世世代代的后裔确立我的约，作为永远的约，我要成为你和你后裔的神。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 26:12; 诗篇 105:11; 出埃及记 6:7"> 我必把你现在的寄居之地，就是迦南全地，赐给你和你的后裔作永远的产业；我也必作他们的神。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 56:4–5; 诗篇 25:10; 诗篇 103:18"> 神接着对亚伯拉罕说：“至于你，你要遵守我的约，你和你的后裔世世代代都要如此。</span>
<span className="v" id="v10" data-v="10" data-xref="歌罗西书 2:11–12; 罗马书 4:9–11; 使徒行传 7:8"> 你们中所有的男子都要受割礼，这就是我与你以及你的后裔所立的约，是你们当遵守的。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 4:11; 使徒行传 7:8; 申命记 10:16"> 你们要割去肉体上的包皮，这就是我与你们立约的标记。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 12:3; 路加福音 2:21; 出埃及记 12:48–49"> 你们世世代代所有的男子，无论是家里出生的，还是用银子从不属于你后裔的外邦人那里买来的，在八天大的时候都要受割礼。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 12:44; 创世记 37:36; 尼希米记 5:8"> 你家里出生的和你用银子买来的，都必须受割礼；这样我的约就在你们肉体上成为永远的约。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 4:24–26; 民数记 15:30–31; 出埃及记 12:19"> 至于不受割礼的男子，就是肉体上的包皮没有被割去的，那人要从民中被剪除，因他违背了我的约。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 12:25; 创世记 32:28; 创世记 17:5"> 神对亚伯拉罕说：“至于你的妻子撒莱，你不要再叫她撒莱，她的名字要叫撒拉。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 35:11; 创世记 17:6; 以赛亚书 49:23"> 我要祝福她，也要藉着她赐给你一个儿子。我要祝福她，她将成为多国之母<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="之母——辅助词语。">c</a></sup>，万族的君王要从她而出。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="启示录 11:16; 创世记 21:6; 创世记 18:12"> 亚伯拉罕就脸伏于地笑了，心里说：“难道一百岁的人还能生孩子吗？就是撒拉也已经九十岁了，还能生育吗？”</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 2:39; 诗篇 41:12; 诗篇 4:6"> 亚伯拉罕对神说：“但愿以实玛利活在你面前。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 1:13–20; 创世记 21:2–3; 列王纪下 4:16–17"> 神说：“不，你的妻子撒拉将为你生一个儿子，你要给他起名为以撒。我要与他确立我的约，作为他后裔永远的约。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 21:18; 创世记 21:13; 创世记 25:12–18"> 至于以实玛利，我也听允你了，看哪，我也要祝福他！我要使他繁衍，大大增多。他将生十二个族长，我必使他成为一个大国。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 21:2–3; 创世记 26:2–5; 加拉太书 3:29"> 而我的约，我要与以撒确立。这以撒，就是撒拉要在明年所定的日期为你生的儿子。”</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 18:33; 创世记 35:9–15; 士师记 6:21"> 神与亚伯拉罕说完了话，就从亚伯拉罕面前上升而去。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="诗篇 119:60; 创世记 18:19; 创世记 17:10–14"> 于是就在那一天，亚伯拉罕照着神向他所说的，叫来他的儿子以实玛利和家中所有的男子，无论是在他家里出生的，还是用银子买来的，都割去了他们肉体上的包皮。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 4:11; 创世记 17:17; 罗马书 4:19–20"> 亚伯拉罕割去肉体上的包皮时年九十九岁；</span>
<span className="v" id="v25" data-v="25"> 他的儿子以实玛利割去肉体上的包皮时年十三岁。</span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 119:60; 创世记 22:3–4; 创世记 12:4"> 就在那一天，亚伯拉罕和他儿子以实玛利都受了割礼。</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 18:19"> 他家里所有的男人，无论是家里出生的，还是用银子从外邦人那里买来的，都与他一起受了割礼。</span>
</div>
</div>

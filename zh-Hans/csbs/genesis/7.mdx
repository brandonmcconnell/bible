<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 24:37–39; 彼得后书 2:5–9; 创世记 6:9"> 耶和华对挪亚说：“你和你的全家都要进入方舟，因为在这世代中，我看到唯有你在我面前是义人。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 8:20; 利未记 10:10; 利未记 11:1–47"> 你要从所有洁净的走兽中各带七公七母，从不洁净的走兽中各带一公一母，</span>
<span className="v" id="v3" data-v="3"> 从天空的飞鸟中各带七公七母，好使它们的种类在全地上存留；</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 6:13; 创世记 7:12; 创世记 7:17"> 因为再过七天，我就要降雨在地上四十昼夜，把我所造的一切活物都从地面上抹掉。”</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 6:22; 路加福音 8:21; 出埃及记 39:32"> 挪亚就照着耶和华吩咐他的一切做了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 5:32; 创世记 8:13"> 大洪水临到地上的时候，挪亚正六百岁。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 17:27; 创世记 6:18; 马太福音 24:38"> 挪亚与他的儿子们、他的妻子和儿媳们一起进入方舟，躲避大洪水。</span>
<span className="v" id="v8" data-v="8"> 洁净的走兽和不洁净的走兽，飞鸟和地上的一切爬虫，</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 7:16; 创世记 2:19; 耶利米书 8:7"> 都公母成双，一对一对来到挪亚那里，也进入方舟，正如神所吩咐挪亚的话。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 6:17; 创世记 7:4; 路加福音 17:27"> 那七天一过，大洪水就临到地上了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="创世记 8:2; 玛拉基书 3:10; 箴言 8:28–29"> 挪亚六百岁那年的二月十七日，就在那一天，巨大深渊的泉源都裂开了，天上的窗户也敞开了——</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 7:4; 马太福音 4:2; 创世记 7:17"> 大雨降在地上四十昼夜——</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 6:18; 创世记 7:1; 创世记 6:10"> 就在那一天，挪亚与他的儿子闪、含、雅弗，以及他的妻子和三个儿媳一起进入方舟；</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 7:8–9; 创世记 7:2–3"> 与他们一起的，还有一切走兽，各从其类；一切牲畜，各从其类；地上活动的一切爬虫，各从其类；一切飞禽，就是一切有翅膀的鸟，各从其类。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 6:19–20; 以赛亚书 11:6"> 这样，一切有生命气息的，就是有血肉的，都一对一对到挪亚那里，进入方舟。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 25:10; 路加福音 13:25; 诗篇 91:1–10"> 各样有血肉的，都是公母成双进去的，是照着神所吩咐挪亚的话进去的。然后耶和华在挪亚后面关上了门。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 7:4; 创世记 7:12"> 洪水在地上持续了四十天，水不断上涨，把方舟托起，方舟就从地上浮了起来。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 14:28; 诗篇 69:15; 约伯记 22:16"> 水势强盛，在地上大大上涨，方舟在水面上漂行。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 104:6–9; 诗篇 46:2–3; 彼得后书 3:6"> 水势在地上极其强盛，普天下所有的高山都被淹没了。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 3:23; 诗篇 104:6"> 水势继续强盛，高出群山十五肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十五肘——相当于6.9公尺。1肘=45.7公分。">a</a></sup>，群山都被淹没了。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 6:13; 创世记 7:4; 创世记 6:17"> 一切有血肉、在地上活动的，就是飞鸟、牲畜、走兽和地上的各样群居爬物，以及所有的人都断了气。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 2:7; 创世记 6:17"> 在陆地上一切鼻孔里有生命气息的都死了。</span>
<span className="v" id="v23" data-v="23" data-xref="彼得后书 2:5; 彼得前书 3:20; 希伯来书 11:7"> 这样，神抹掉了地面上的一切活物——无论是人，还是走兽、爬虫和天空的飞鸟，都从地上抹掉了；只留下挪亚和那些与他一起在方舟里的。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 8:3–4"> 水势强盛，在地上共一百五十天。</span>
</div>
</div>

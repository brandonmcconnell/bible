<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 2:6; 西番雅书 3:9; 以赛亚书 19:18"> 当初全地只有一种语言、一种话语。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 10:10; 但以理书 1:2; 创世记 14:1"> 人们向东方迁移<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="向东方迁移——或译作“从东方出发”。">a</a></sup>，在示拿地发现了一块平原，就在那里住下。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 14:10; 出埃及记 1:14; 出埃及记 2:3"> 他们彼此说：“来吧！让我们做砖，用火烧透。”于是他们就用砖代替石头，用沥青代替灰泥。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 1:28; 约翰福音 5:44; 路加福音 1:51"> 他们又说：“来吧！让我们为自己建造一座城和一座塔，塔顶通天，好为自己立名，免得我们分散在整个地面上。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 18:21; 诗篇 33:13–14; 约翰福音 3:13"> 耶和华降临，要看世人建造的城和塔。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 2:1–4; 创世记 3:22; 创世记 11:1"> 耶和华说：“看哪，他们是一族，又说一样的语言，而且一开始就做这样的事，此后他们决意做任何事，就没有做不成的！</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 33:10; 诗篇 55:9; 约伯记 5:12–13"> 来吧！让我们下去，在那里把他们的语言变乱，使他们彼此听不懂对方的语言。”</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 1:51; 申命记 32:8; 创世记 10:25"> 于是耶和华把他们从那里分散到整个地面上，他们就停止建造那城。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 10:10; 创世记 10:5; 创世记 10:20"> 因此那城名叫巴别<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="巴别——就是巴比伦。">b</a></sup>，因为在那里耶和华变乱了全地人的语言，又从那里把他们分散到整个地面上。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志上 1:17–27; 创世记 10:21–22; 路加福音 3:34–36"> 以下是闪的谱系：洪水之后两年，闪一百岁时，生了亚法撒。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 9:7; 诗篇 144:12; 创世记 1:28"> 闪生了亚法撒之后，又活了五百年，并且生了其他的儿女。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 3:36"> 亚法撒活到三十五岁时，生了沙拉。</span>
<span className="v" id="v13" data-v="13"> 亚法撒生了沙拉之后，又活了四百零三年，并且生了其他的儿女。</span>
<span className="v" id="v14" data-v="14"> 沙拉活到三十岁时，生了希伯。</span>
<span className="v" id="v15" data-v="15"> 沙拉生了希伯之后，又活了四百零三年，并且生了其他的儿女。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 10:21; 历代志上 1:19; 民数记 24:24"> 希伯活到三十四岁时，生了法勒。</span>
<span className="v" id="v17" data-v="17"> 希伯生了法勒之后，又活了四百三十年，并且生了其他的儿女。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 3:35"> 法勒活到三十岁时，生了拉吴。</span>
<span className="v" id="v19" data-v="19"> 法勒生了拉吴之后，又活了两百零九年，并且生了其他的儿女。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 3:35"> 拉吴活到三十二岁时，生了西鹿。</span>
<span className="v" id="v21" data-v="21"> 拉吴生了西鹿之后，又活了两百零七年，并且生了其他的儿女。</span>
<span className="v" id="v22" data-v="22" data-xref="约书亚记 24:2"> 西鹿活到三十岁时，生了拿鹤。</span>
<span className="v" id="v23" data-v="23"> 西鹿生了拿鹤之后，又活了两百年，并且生了其他的儿女。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 3:34; 约书亚记 24:2"> 拿鹤活到二十九岁时，生了塔拉。</span>
<span className="v" id="v25" data-v="25"> 拿鹤生了塔拉之后，又活了一百一十九年，并且生了其他的儿女。</span>
<span className="v" id="v26" data-v="26" data-xref="约书亚记 24:2; 历代志上 1:26–27; 创世记 22:20–24"> 塔拉活到七十岁时，生了亚伯兰、拿鹤和哈兰。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="创世记 12:4; 创世记 14:12; 创世记 11:31"> 以下是塔拉的谱系：塔拉生了亚伯兰、拿鹤、哈兰；哈兰生了罗得。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 15:7; 尼希米记 9:7; 使徒行传 7:2–4"> 哈兰在他父亲塔拉之前，死在他本族之地，就是迦勒底的吾珥。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 17:15; 创世记 22:20; 创世记 24:15"> 亚伯兰和拿鹤各为自己娶了妻子。亚伯兰的妻子名叫撒莱，拿鹤的妻子名叫米尔卡，她是哈兰的女儿；哈兰是米尔卡的父亲，也是伊斯卡的父亲。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 29:31; 创世记 21:1–2; 路加福音 1:7"> 撒莱不能生育，没有孩子。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="尼希米记 9:7; 使徒行传 7:2–4; 创世记 24:10"> 塔拉带着他的儿子亚伯兰和他的孙子，就是哈兰的儿子罗得，也带着他的儿媳妇——他儿子亚伯兰的妻子撒莱，一同从迦勒底的吾珥出来，要往迦南地去。他们来到哈兰的时候，就在那里住下了。</span>
<span className="v" id="v32" data-v="32"> 塔拉的年日有两百零五年，然后死在哈兰。</span>
</div>
</div>

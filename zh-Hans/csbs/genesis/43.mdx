<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="GEN" data-book-slug="genesis" data-book-name="创世记" data-chapter="43" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 12:10; 使徒行传 7:11–13; 耶利米哀歌 5:10"> 那地的饥荒仍然很严重。</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前书 6:6–8; 箴言 16:18; 箴言 15:16"> 他们从埃及带回来的粮食吃完后，他们的父亲就对他们说：“你们再去为我们买些粮食来。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 44:23; 创世记 43:5; 撒母耳记下 3:13"> 犹大对他说：“那人严厉地告诫我们，‘要是你们的弟弟不与你们一起来，你们就不得见我的面。’</span>
<span className="v" id="v4" data-v="4"> 如果你打发我们的弟弟与我们一起去，我们就下去为你买粮食；</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 20:12; 创世记 44:26; 创世记 42:38"> 但如果你不打发他去，我们就不下去，因为那人对我们说：‘要是你们的弟弟不与你们一起来，你们就不得见我的面。’”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 以色列说：“你们为什么这样害我，要告诉那人你们还有一个弟弟呢？”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="创世记 43:3; 创世记 42:13; 创世记 43:27"> 他们说：“那人详细问到我们和我们的亲属，说：‘你们的父亲还活着吗？你们还有兄弟吗？’我们就照着他所问的告诉他。我们怎么知道他会说‘把你们的弟弟带下来’呢？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="创世记 42:2; 申命记 33:6; 创世记 45:19"> 犹大对他父亲以色列说：“请打发那少年与我同去，我们就立刻起身前往，好使我们和你，以及我们的孩童都得以存活，不至于死。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 42:37; 腓利门书 1:18–19; 希伯来书 7:22"> 我亲自为此担保，你可以从我手中追讨责任。如果我不把他带回来，让他站在你面前，我就在你面前终身担罪。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 19:16"> 其实要不是我们耽延，现在已经来回两次了。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="创世记 37:25; 耶利米书 8:22; 以西结书 27:17"> 他们的父亲以色列对他们说：“如果必须如此，你们就这样做：把本地土产中最好的乳香、蜂蜜、香料、没药、开心果、杏仁各取一点，放在容器里，带下去给那人作礼物。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 42:25; 创世记 42:35; 帖撒罗尼迦前书 4:6"> 你们手中要拿上双倍的银子，亲手带回那归还在你们袋子口的银子，那或许是个失误。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 42:38"> 现在带上你们的弟弟，立刻起身，回到他那里吧！</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖记 4:16; 创世记 17:1; 使徒行传 21:14"> 愿全能的神使你们在那人面前蒙怜悯，好让他可以把你们那个兄弟和便雅悯都交还给你们。至于我，如果要丧失儿子，就丧失吧！”</span>
<span className="v" id="v15" data-v="15"> 于是他们带着这些礼物，手中拿上双倍的银子，并带上便雅悯，起身下到埃及，站在了约瑟面前。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="创世记 44:1; 创世记 43:19; 创世记 24:2–10"> 约瑟看见便雅悯与他们在一起，就对自己的管家说：“把这些人带到家里。宰杀牲畜，预备宴席<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="宴席——辅助词语。">a</a></sup>，因为这些人中午将与我一起吃饭。”</span>
<span className="v" id="v17" data-v="17"> 那人就照着约瑟所说的做，把这些人带到约瑟家里。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="创世记 42:35; 罗马书 7:8; 创世记 42:21"> 这些人因为被带到约瑟家里就害怕，说：“头一次银子归还在我们的袋子里，我们现在被带进来必定是为了这个缘故；他想向我们下手，袭击我们，抓我们作奴仆，夺我们的驴子。”</span>
<span className="v" id="v19" data-v="19"> 他们就靠近约瑟的管家，在屋门口与他说话。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 42:3; 创世记 42:10; 创世记 42:27"> 他们说：“哦，我主啊，头一次我们真是下来买粮的。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 43:12; 创世记 42:27–35; 罗马书 13:8"> 当我们来到一处住宿的地方，打开自己的袋子，看哪，各人的银子都在自己的袋子口，重量分文不少。现在我们手上带着这些银子回来了。</span>
<span className="v" id="v22" data-v="22"> 我们手上又带了另外的银子下来买粮。我们不知道头一次是谁把银子放在我们的袋子里。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约翰福音 20:26; 创世记 42:24; 约翰福音 14:27"> 管家说：“你们请放心<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="你们请放心——原文直译“平安归你们”。">b</a></sup>，不要害怕。是你们的神，你们父亲的神赐你们财宝，放在你们的袋子里。你们的银子我早已收到了。”然后他把西缅带出来交给他们。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 18:4; 创世记 24:32; 路加福音 7:44"> 那人就把这些人带到约瑟家里，给他们水洗脚；又给他们的驴子饲料。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 43:11; 创世记 43:16"> 他们听说他们要在那里吃饭，就预备好礼物，等候约瑟中午到来。</span>
<span className="v" id="v26" data-v="26" data-xref="腓立比书 2:10–11; 创世记 27:29; 创世记 42:6"> 约瑟到了家，他们就把手中的礼物带进屋里给他，并俯伏于地，向他下拜。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="创世记 42:13; 撒母耳记上 25:5; 撒母耳记上 17:22"> 约瑟向他们问安，又说：“你们的父亲，就是你们说的那位老人家平安吗？他还健在吗？”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="创世记 37:7; 创世记 43:26; 撒母耳记下 14:4"> 他们说：“你的仆人、我们的父亲平安，他还健在。”然后他们又俯身下拜。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="创世记 42:13; 民数记 6:25; 创世记 30:22–24"> 约瑟举目看见他同母的弟弟便雅悯，就问：“这就是你们向我说的那个最小的弟弟吗？”然后他说：“我儿啊，愿神恩待你。”</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 42:24; 耶利米书 31:20; 列王纪上 3:26"> 约瑟的爱弟之情升腾，他就急忙找个地方去哭。于是他进到自己的内室，在那里哭了一场。</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 45:1; 彼得前书 3:10; 以赛亚书 42:14"> 他洗了脸出来，克制住自己，说：“摆饭吧！”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="创世记 46:34; 出埃及记 8:26; 创世记 43:16"> 他们就为约瑟单独摆了饭，为那些人另摆了一席，也为那些与约瑟一起吃饭的埃及人又摆了一席，因为埃及人不能与希伯来人同席吃饭；那是埃及人所憎恶的。</span>
<span className="v" id="v33" data-v="33"> 他们被领到各自的座位上，从长子到幼子，照着长幼次序坐在约瑟面前。他们彼此对望<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="对望——辅助词语。">c</a></sup>，感到惊奇。</span>
<span className="v" id="v34" data-v="34" data-xref="创世记 45:22; 撒母耳记下 11:8; 撒母耳记上 1:5"> 约瑟把自己面前的食物分给他们，但便雅悯分到的是其他人的五倍<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="是其他人的五倍——或译作“比其他人多五倍”。">d</a></sup>。他们与约瑟一同宴乐畅饮。</span>
</div>
</div>

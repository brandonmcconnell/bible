<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 31:13; 何西阿书 12:4; 诗篇 91:15"> 神对雅各说：“起来，上伯特利去，住在那里；你要在那里造一座祭坛给神——他是你逃避你哥哥以扫的时候曾向你显现的那一位。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="出埃及记 19:14; 出埃及记 19:10; 以西结书 18:31"> 雅各就对他的家人以及所有与他在一起的人说：“你们要除掉你们中间的外邦神像，并要洁净自己，更换你们的衣服。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 43:2; 创世记 32:7; 创世记 31:3"> 让我们起来，上伯特利去，在那里我要造一座祭坛给神；他就是在我患难的日子回应我，在我所行的路上与我同行的那一位。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士师记 9:6; 申命记 7:25; 出埃及记 32:20"> 于是他们把自己手中所有的外邦神像和自己耳朵上的环子都交给雅各；雅各把它们埋藏在示剑附近的橡树底下。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 23:27; 历代志下 17:10; 约书亚记 5:1"> 然后他们起程了。神使周围城邑的人都感到恐惧，因此他们就不追赶雅各的儿子们。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 28:19; 创世记 28:22; 创世记 12:8"> 这样，雅各和所有与他一起的人都来到迦南地的路斯，就是伯特利。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 35:3; 创世记 35:1; 创世记 28:13"> 他在那里筑了一座祭坛，称那地方为伊利-伯特利，因为他逃避他哥哥的时候，神曾在那里向他显现。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="创世记 24:59; 撒母耳记上 31:13; 士师记 2:5"> 莉百加的乳母底波拉死了，埋葬在伯特利下边的橡树底下，所以雅各给那棵树起名为亚伦-巴古。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="创世记 35:1; 创世记 18:1; 创世记 26:2"> 自雅各从帕旦-亚兰回来后，神再次向他显现，祝福了他。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 17:5; 创世记 32:27–28; 创世记 17:15"> 神对他说：<br /><span className="pl pl-1">“你的名字是雅各，</span><br /><span className="pl pl-1">但今后不要再叫雅各了，</span><br /><span className="pl pl-1">你的名字要叫以色列。”</span><br />这样，神就给他起名为以色列。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 17:1; 创世记 9:1; 创世记 22:17"> 神又对他说：<br /><span className="pl pl-1">“我是全能的神；</span><br /><span className="pl pl-1">你要繁衍增多；</span><br /><span className="pl pl-1">必有一国和众邦之国从你而来，</span><br /><span className="pl pl-1">众君王也必从你生出。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="创世记 12:7; 创世记 28:13; 创世记 26:3–4"> <span className="pl pl-1">我所赐给亚伯拉罕和以撒的土地，我必赐给你；</span><br /><span className="pl pl-1">我也要把这地赐给你的后裔。”</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 17:22; 创世记 18:33; 士师记 6:21"> 然后神就从那与雅各说话的地方上升而去，离开了他。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="创世记 28:18–19; 撒母耳记上 7:12; 出埃及记 17:15"> 雅各在神与他说话的地方立了一根柱子作为石碑，在上面浇奠了酒祭，又浇了油。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 28:19"> 雅各给神与他说话的那地方起名为伯特利。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="弥迦书 5:2; 创世记 48:7; 列王纪下 5:19"> 他们从伯特利起程，离以法他还有一段路程的时候，拉结临产了，而且是难产。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 30:24; 撒母耳记上 4:19–21"> 在她难产的时候，接生婆对她说：“不要害怕，你这次又要有一个儿子了！”</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 12:20; 使徒行传 7:59; 路加福音 23:46"> 她的灵魂快要出窍，她快死的时候，给儿子起名为便俄尼<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="便俄尼——意思是“在我患难中的儿子”。">a</a></sup>，他父亲却称他为便雅悯<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="便雅悯——意思是“右手的儿子”。">b</a></sup>。</span>
<span className="v" id="v19" data-v="19" data-xref="弥迦书 5:2; 创世记 48:7; 路得记 4:11"> 拉结死了，埋葬在通往以法他的路上；以法他就是伯利恒。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 10:2; 创世记 35:14; 撒母耳记下 18:17–18"> 雅各在她的坟墓上立了一根石柱，这就是拉结的墓碑，直到今日。</span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="弥迦书 4:8; 路加福音 2:8"> 以色列又起程前行，在伊德高台的那一边支搭帐篷。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 5:1; 利未记 18:8; 撒母耳记下 20:3"> 以色列在那地居住的时候，鲁本去与他父亲的小妾碧拉同睡；以色列也听到了这事。<br />雅各有十二个儿子：</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 30:18–20; 创世记 46:8–15; 创世记 29:32–35"> <span className="pl pl-1">莉亚的儿子是雅各的长子鲁本，</span><br /><span className="pl pl-1">还有西缅、利未、犹大、</span><br /><span className="pl pl-1">以萨迦和西布伦。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="创世记 30:22–24; 创世记 46:19–22; 创世记 35:16–18"> <span className="pl pl-1">拉结的儿子是约瑟和便雅悯。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="创世记 46:23–25; 创世记 37:2; 创世记 30:4–8"> <span className="pl pl-1">拉结的婢女碧拉的儿子是但和拿弗他利。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="创世记 30:9–13; 创世记 46:16–18; 创世记 25:20"> <span className="pl pl-1">莉亚的婢女悉帕的儿子是迦得和亚设。</span><br />以上是雅各的儿子，是他在帕旦-亚兰生的。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="创世记 13:18; 创世记 23:19; 创世记 18:1"> 雅各来到他父亲以撒那里，到了基列-阿尔巴的幔利，就是亚伯拉罕和以撒寄居的地方；基列-阿尔巴就是希伯仑。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 25:7; 创世记 50:26; 创世记 47:28"> 以撒的年日有一百八十年。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 15:15; 创世记 49:33; 创世记 49:31"> 以撒年迈，寿数满足，气绝而死，归到他的先人那里。他的儿子以扫和雅各把他安葬了。</span>
</div>
</div>

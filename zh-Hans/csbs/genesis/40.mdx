<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 40:13; 创世记 39:20–23; 以斯帖记 6:1"> 这些事以后，埃及王的司酒长和司膳长得罪了他们的主埃及王。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 16:14; 箴言 19:12; 诗篇 76:10"> 法老就对司酒长和司膳长这两个内臣发怒，</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 39:20; 创世记 39:23"> 把他们关到护卫长府中的牢里，就是约瑟被囚的监狱。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 39:1; 诗篇 37:5; 创世记 37:36"> 护卫长指派约瑟与他们在一起，约瑟就事奉他们；他们在牢里过了一些日子。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 41:11; 创世记 40:8; 创世记 37:5–10"> 他们两人，就是被囚在监狱里的埃及王的司酒长和司膳长，在同一夜都做了梦，各有各的梦，各梦各有其解。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 41:8; 但以理书 2:1–3; 创世记 40:8"> 到了早晨，约瑟来到他们那里，看见他们忧闷不安。</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米记 2:2; 撒母耳记上 1:8; 路加福音 24:17"> 他就问法老的内臣，就是与他一同关在主人府中牢里的那两人，说：“你们今天为什么面带愁容呢？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="但以理书 2:47; 创世记 41:15–16; 但以理书 2:28"> 他们对他说：“我们各做了一梦，但无人能解。”<br />约瑟就对他们说：“解梦难道不在于神吗？请给我讲述一下吧。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="士师记 7:13–15; 创世记 37:5–10; 但以理书 4:8"> 司酒长就向约瑟讲述他的梦，说：“在我的梦中，看哪，有一棵葡萄树在我面前！</span>
<span className="v" id="v10" data-v="10"> 葡萄树上有三根枝子，树上发了芽，开了花，一串串的葡萄都成熟了。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 1:11–1; 列王纪上 10:5; 历代志下 9:4"> 法老的杯子在我的手中，我就拿了葡萄挤到法老的杯子里，然后把杯子递在法老的手掌中。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 41:12; 士师记 7:14; 创世记 41:25–26"> 约瑟对他说：“梦的解释是这样的：三根枝子就是三天。</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 3:3; 耶利米书 52:31; 列王纪下 25:27"> 三天之内，法老要抬起你的头，使你官复原位；你仍会把法老的杯子递在他的手中，照着你先前作司酒长时的惯例。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 2:12; 路加福音 23:42; 撒母耳记上 20:14–15"> 当你境遇好转的时候，求你记念我，以恩慈对待我，在法老面前提起我，把我救出这监牢。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 3:17–18; 创世记 39:20; 提摩太前书 1:10"> 因为我实在是从希伯来人之地被拐来的，就是在这里我也没做过什么事，致使他们把我关在这地牢里。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="创世记 40:1–2"> 司膳长见约瑟解得好，就对他说：“我也做了一个梦，在梦中，看哪，有三个装饼的篮子在我头上！</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 49:20; 历代志上 12:20"> 最上面的篮子里，有为法老烤的各样食物，但飞鸟却从我头上的篮子里吃那些食物。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="创世记 40:12; 创世记 41:26; 哥林多前书 11:24"> 约瑟就回应说：“梦的解释是这样的：三个篮子就是三天。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 40:22; 使徒行传 20:27; 撒母耳记下 21:6"> 三天之内，法老要抬起你的头，从你身上取下，把你挂在木头上，飞鸟将要吃你身上的肉。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 40:19; 创世记 40:13; 马太福音 14:6"> 到了第三天，正是法老的生日，他为所有的臣仆摆设宴席，并在他们面前抬起了司酒长和司膳长的头。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 40:13; 尼希米记 2:1"> 他使司酒长官复原职，司酒长就仍旧把杯子递在法老的手掌中；</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 40:19; 创世记 41:16; 但以理书 2:30"> 法老却把司膳长挂了起来，就像约瑟给他们解释的那样。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 31:12; 约伯记 19:14; 诗篇 105:19"> 至于司酒长，却没有记念约瑟，竟把他忘掉了。</span>
</div>
</div>

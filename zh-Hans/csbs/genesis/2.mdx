<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 31:17; 出埃及记 20:11; 诗篇 33:6"> 诸天、大地及其万象就这样造成了。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 4:4; 出埃及记 31:17; 申命记 5:14"> 到第七日，神已经完成了他所做的工，就在第七日安息了，歇了他所做的一切工。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 20:12; 马可福音 2:27; 利未记 23:3"> 神就祝福第七日，把它分别为圣，因为在这日，神安息了，歇了他所做的一切创造之工。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="创世记 5:1; 启示录 1:8; 创世记 1:4"> 诸天和大地被造的来历是这样的：在耶和华神造大地和诸天的日子，</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 3:23; 希伯来书 6:7; 约伯记 5:10"> 田野的灌木还没有出现在地上，田间的蔬草也还没有长出，因为耶和华神没有降雨在地上，也没有人耕耘土地；</span>
<span className="v" id="v6" data-v="6"> 但有雾气从大地升腾，滋润整个地面。</span>
<span className="v" id="v7" data-v="7" data-xref="传道书 12:7; 约伯记 33:4; 哥林多前书 15:45"> 耶和华神用地上的尘土塑造人，把生命的气息吹入他的鼻孔，那人就成了有生命的人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有生命的人——传统译法作“有灵的活人”。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西结书 28:13; 创世记 3:24; 创世记 13:10"> 耶和华神在东方的伊甸栽种了一个园子，把所塑造的那人安置在那里。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 3:22; 启示录 2:7; 启示录 22:14"> 耶和华神使各样的树从地里长出来，令人眼目喜爱，果实<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="果实——辅助词语。">b</a></sup>好作食物；在园子的中间有生命树和分辨善恶树。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="启示录 22:1; 诗篇 46:4"> 有一条河从伊甸流出来，浇灌那园子；又从那里分开，成为四条河<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="河——辅助词语。">c</a></sup>的源头。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 25:18; 创世记 10:29; 撒母耳记上 15:7"> 第一条名叫比逊，它围绕着哈腓拉全地，在那里有金子，</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 28:20; 民数记 11:7; 以西结书 28:13"> 那地的金子是上好的，在那里还有珍珠<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="珍珠——或译作“红玉”或“稀罕的香料”。">d</a></sup>和红玛瑙石。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 10:6; 以赛亚书 11:11"> 第二条河名叫基训，它围绕着库实全地。</span>
<span className="v" id="v14" data-v="14" data-xref="但以理书 10:4; 创世记 15:18; 申命记 1:7"> 第三条河名叫底格里斯，它流过亚述东边。第四条河是幼发拉底。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="诗篇 128:2; 创世记 2:8; 以弗所书 4:28"> 耶和华神把那人带来，安置在伊甸园中，让他耕耘和看守那园子。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 15:22; 提摩太前书 4:4; 提摩太前书 6:17"> 耶和华神吩咐那人说：“园子中各样树上的果实，你都可以随意吃；</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 6:23; 雅各书 1:15; 创世记 3:19"> 只是分辨善恶树上的果实，你不可吃，因为在吃的日子，你必定死。”</span>
<span className="v" id="v18" data-v="18" data-xref="传道书 4:9–12; 哥林多前书 11:7–12; 箴言 18:22"> 耶和华神又说：“那人孤身不好，我要为他造一个合适的帮助者。”</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 8:4–8; 创世记 1:28; 创世记 9:2"> 耶和华神用土塑造了田野各样走兽和天空各样飞鸟，把它们带到那人面前，看他怎么称呼它们。他怎么称呼每样活物，那就成了它的名字。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 2:18"> 那人给各样的牲畜、天空的飞鸟和田野的各样走兽都起了名。至于给亚当的那合适的帮助者，却没有找到。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 15:12; 约伯记 4:13; 撒母耳记上 26:12"> 耶和华神使那人陷入沉睡，那人就睡着了；神取出他的一根肋骨，又在原处把肉合起来。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 11:8–9; 提摩太前书 2:13; 希伯来书 13:4"> 然后耶和华神用那人身上所取的肋骨，造出一个女人，并把她带到那人面前。</span>
<span className="v" id="v23" data-v="23" data-xref="以弗所书 5:28–30; 哥林多前书 11:8–9; 撒母耳记下 5:1"> 那人说：<br /><span className="pl pl-1">“这才是我骨中的骨、</span><br /><span className="pl pl-1">肉中的肉！</span><br /><span className="pl pl-1">她当被称为‘女人’，</span><br /><span className="pl pl-1">因为她是从男人身上取出来的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="马太福音 19:3–9; 以弗所书 5:28–31; 马可福音 10:6–12"> 因此人将离开父母，与妻子结合，二人就成为一体。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 3:7; 创世记 3:10–11; 罗马书 10:11"> 当时那人和他的妻子都是赤身的，彼此也不觉得羞耻。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 28:3–4; 创世记 24:3; 创世记 27:46"> 以撒叫来雅各，祝福了他，又吩咐他说：“你不要从迦南的女子中娶妻。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 25:20; 何西阿书 12:12; 创世记 24:50"> 起来，往帕旦-亚兰去，到你外祖父彼土利的家，你要在那里从你舅舅拉班的女儿中为自己娶妻。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 48:3; 创世记 35:11; 创世记 1:28"> 愿全能的神祝福你，使你繁衍增多，成为万族之族。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 3:14; 创世记 12:7; 以弗所书 1:3"> 愿神把亚伯拉罕所得的祝福赐给你和你的后裔，使你拥有你所寄居之地，就是神所赐给亚伯拉罕的。”</span>
<span className="v" id="v5" data-v="5"> 于是以撒打发雅各前往帕旦-亚兰，到亚兰人彼土利的儿子拉班那里。拉班是雅各和以扫的母亲莉百加的哥哥。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 27:33; 创世记 28:1"> 以扫看见以撒祝福了雅各，又打发他去帕旦-亚兰那里娶妻；并见以撒祝福雅各时，吩咐他说：“你不要从迦南的女子中娶妻”；</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 6:1; 以弗所书 6:3; 歌罗西书 3:20"> 又见雅各听从了父母，往帕旦-亚兰去了；</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 24:3; 创世记 26:34–35; 撒母耳记上 8:6"> 以扫就看出迦南的女子在他父亲以撒眼中看为恶。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 36:3; 创世记 36:18; 创世记 36:13"> 于是以扫到以实玛利那里去，在两个妻子以外，又娶了玛哈拉为妻。玛哈拉是亚伯拉罕的儿子以实玛利的女儿，是尼拜约的妹妹。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 7:2; 创世记 11:31; 创世记 32:10"> 雅各离开比尔-谢巴，往哈兰去。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 8:20; 创世记 28:18; 创世记 31:46"> 他到了一个地方，因为日落了，就在那里过夜。他就地拿了一块石头，放在自己头底下，就在那地方躺下睡了。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 1:51; 民数记 12:6; 创世记 32:1–2"> 他做了一个梦：看哪，有一个梯子立在地上，它的顶端直通到天！看哪，梯子上，神的使者们上下往来！</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 13:15; 创世记 48:3; 创世记 35:12"> 看哪，耶和华站在梯子上方，说：“我是耶和华，你父亲亚伯拉罕的神、以撒的神。我必把你现在躺卧之地，赐给你和你的后裔。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 12:3; 使徒行传 3:25; 创世记 18:18"> 你的后裔必如同地上的尘土；你必向东南西北扩展；地上万族都必因你和你的后裔而蒙福。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 1:5; 以赛亚书 41:10; 耶利米书 1:19"> 看哪，我与你同在！你无论往哪里去，我都会保守你，并且要把你带回这地。我必不离弃你，直到成就了我对你所说的。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约书亚记 5:15; 出埃及记 3:5; 出埃及记 15:11"> 雅各从睡眠中醒过来，说：“耶和华确实在这地方，我竟然不知道！”</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太前书 3:15; 创世记 35:1–13; 传道书 5:1"> 他就害怕起来，说：“这地方真可畏！这里一定是神的殿，天的门。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="创世记 35:14; 创世记 31:45; 创世记 31:13"> 雅各清早起来，拿起放在他头底下的那块石头，立作石柱，在它上头浇了油。</span>
<span className="v" id="v19" data-v="19" data-xref="何西阿书 12:4–5; 创世记 35:1; 创世记 48:3"> 他就给那地方起名为伯特利；不过那城先前名叫路斯。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太前书 6:8; 撒母耳记下 15:8; 创世记 31:13"> 然后雅各许了一个愿说：“如果耶和华<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="耶和华——原文直译“神”。">a</a></sup>与我同在，在我所行的这路上保守我，又赐给我粮食吃、衣服穿，</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 11:31; 申命记 26:17; 撒母耳记下 19:24"> 并让我平平安安地回到我的父家，那么耶和华就是我的神。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 35:7; 创世记 14:20; 申命记 14:22–23"> 我立作石柱的这块石头将成为神的殿；凡你所赐给我的，我必把十分之一献给你。”</span>
</div>
</div>

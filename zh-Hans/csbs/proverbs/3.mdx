<span className="v" id="v3" data-v="3" data-xref="箴言 7:3; 哥林多后书 3:3; 希伯来书 10:16"> <span className="pl pl-1">不要让慈爱和信实离开你，</span><br /><span className="pl pl-1">要把它们系在你的颈项上，</span><br /><span className="pl pl-1">刻在你的心版上；</span><br /></span>

<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="诗篇 37:5; 耶利米书 17:7–8; 箴言 28:26"> <span className="pl pl-1">你要全心依靠耶和华，</span><br /><span className="pl pl-1">不要依赖自己的悟性；</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 16:3; 诗篇 32:8; 腓立比书 4:6"> <span className="pl pl-1">在你一切的道路上，都要认定他，</span><br /><span className="pl pl-1">他就会修直你的路。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="约伯记 28:28; 罗马书 12:16; 箴言 26:12"> <span className="pl pl-1">不要自以为</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="自以为——原文直译“在你眼中”。">a</a></sup><br /><span className="pl pl-1">有智慧，</span><br /><span className="pl pl-1">要敬畏耶和华，远离恶事；</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 4:22; 诗篇 147:3; 箴言 16:24"> <span className="pl pl-1">这样健康就临到你的身上</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="身上——原文直译“肚脐”。">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">你的骨头就得到滋养。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="申命记 26:2–15; 哥林多前书 16:2; 出埃及记 23:19"> <span className="pl pl-1">你当以你的财物，以一切初熟的收成，</span><br /><span className="pl pl-1">荣耀耶和华；</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 19:17; 申命记 28:8; 箴言 22:9"> <span className="pl pl-1">这样，你的仓库必充满，丰丰足足，</span><br /><span className="pl pl-1">你的榨酒池也必溢出新酒。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 5:17; 启示录 3:19; 希伯来书 12:5–12"> <span className="pl pl-1">我儿啊，不可厌弃耶和华的管教，</span><br /><span className="pl pl-1">也不可厌恶他的责备！</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="申命记 8:5; 启示录 3:19; 箴言 29:17"> <span className="pl pl-1">因为耶和华责备他所爱的，</span><br /><span className="pl pl-1">正如父亲责备他所喜悦的儿子。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="箴言 8:32–35; 箴言 4:5–9; 传道书 9:15–18"> <span className="pl pl-1">那找到智慧、获得聪慧的人，</span><br /><span className="pl pl-1">是蒙福的！</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 16:16; 箴言 8:19; 约伯记 28:13–19"> <span className="pl pl-1">因为智慧的盈利好过银子，</span><br /><span className="pl pl-1">她的收益胜过金子；</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 8:11; 约伯记 28:18; 诗篇 73:25–26"> <span className="pl pl-1">她比红宝石更宝贵，</span><br /><span className="pl pl-1">你喜悦的一切都无法与她相比；</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 3:2; 哥林多后书 6:10; 箴言 22:4"> <span className="pl pl-1">她的右手有长寿，</span><br /><span className="pl pl-1">左手有财富和尊荣；</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 1:79; 以赛亚书 26:3; 腓立比书 4:8–9"> <span className="pl pl-1">她的道路是恩慈的道路，</span><br /><span className="pl pl-1">她的路径全是平安；</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 11:30; 启示录 2:7; 箴言 15:4"> <span className="pl pl-1">对于持守她的，她就是生命树；</span><br /><span className="pl pl-1">持定她的人被称为有福。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="诗篇 104:24; 耶利米书 10:12; 约翰福音 1:3"> <span className="pl pl-1">耶和华藉着智慧奠定大地的根基，</span><br /><span className="pl pl-1">藉着聪慧确立诸天；</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="创世记 7:11; 诗篇 65:9–12; 约伯记 36:27–28"> <span className="pl pl-1">藉着他的知识，深渊就裂开，</span><br /><span className="pl pl-1">云朵也滴下甘露。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 1:8; 申命记 6:6–9; 申命记 32:46–47"> <span className="pl pl-1">我儿啊，你要谨守真知和谋略，</span><br /><span className="pl pl-1">不要让它们离开你的眼目！</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 4:22; 箴言 1:9; 以赛亚书 38:16"> <span className="pl pl-1">对于你的灵魂，它们就是生命；</span><br /><span className="pl pl-1">它们也是你颈项上的美饰</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="美饰——原文直译“恩惠”。">c</a></sup><br /><span className="pl pl-1">。</span><br /></span>

<span className="v" id="v24" data-v="24" data-xref="诗篇 3:5; 诗篇 4:8; 箴言 6:22"> <span className="pl pl-1">你躺下时，也不会惧怕；</span><br /><span className="pl pl-1">你躺下，就睡得甜美。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 41:10–14; 诗篇 112:7; 彼得前书 3:14"> <span className="pl pl-1">突来的恐怖，你不必害怕；</span><br /><span className="pl pl-1">恶人遭毁灭时，你也不必担心。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 91:3; 撒母耳记上 2:9; 箴言 14:26"> <span className="pl pl-1">因为耶和华是你的依靠</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="是你的依靠——或译作“要在你身旁”。">d</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">他保守你的脚不陷入网罗。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="加拉太书 6:10; 雅各书 2:15–16; 罗马书 13:7"> <span className="pl pl-1">当你的手有能力做好事时，</span><br /><span className="pl pl-1">不要有所保留，不给应得的人；</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="利未记 19:13; 申命记 24:12–15; 哥林多后书 8:11"> <span className="pl pl-1">当你那里有邻人所求的</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="所求的——辅助词语。">e</a></sup><br /><span className="pl pl-1">，不可对他说：</span><br /><span className="pl pl-1">“走吧，明天再来，我才给你。”</span><br /></span>

<span className="v" id="v33" data-v="33" data-xref="诗篇 37:22; 利未记 26:14–46; 约伯记 8:6–7"> <span className="pl pl-1">耶和华的诅咒在恶人的家，</span><br /><span className="pl pl-1">而他祝福义人的居所；</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="雅各书 4:6; 彼得前书 5:5; 诗篇 138:6"> <span className="pl pl-1">他讥讽那些讥讽者，</span><br /><span className="pl pl-1">把恩惠赐给卑微人。</span><br /></span>

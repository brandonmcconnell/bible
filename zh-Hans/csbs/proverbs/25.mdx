<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 1:1; 列王纪上 4:32; 弥迦书 1:1"> 以下也是所罗门的箴言，是犹大王希西加的人所抄录的：</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="申命记 29:29; 罗马书 11:33–34; 约伯记 11:7–8"> <span className="pl pl-1">隐藏事情，是神的荣耀；</span><br /><span className="pl pl-1">探查事情，是君王的荣耀。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 55:9; 诗篇 103:11; 列王纪上 4:29"> <span className="pl pl-1">如天之高，如地之深，</span><br /><span className="pl pl-1">君王之心也无法测度。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="提摩太后书 2:20–21; 以西结书 22:18; 箴言 17:3"> <span className="pl pl-1">除掉银子中的渣滓，</span><br /><span className="pl pl-1">炼银者就造出器皿；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 16:12; 箴言 20:8; 诗篇 101:7–8"> <span className="pl pl-1">除掉王面前的恶人，</span><br /><span className="pl pl-1">王的宝座就藉着公义而坚立。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="箴言 27:2; 箴言 25:27; 箴言 16:19"> <span className="pl pl-1">你不要在王面前妄自尊大，</span><br /><span className="pl pl-1">也不要站在大人物的位上；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 14:7–11; 路加福音 18:14; 彼得前书 5:5"> <span className="pl pl-1">因为让人对你说“上到这里来吧”，</span><br /><span className="pl pl-1">好过在你所见的权贵面前被降卑。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="马太福音 5:25; 箴言 17:14; 箴言 18:6"> <span className="pl pl-1">不可急于出去与人争讼；</span><br /><span className="pl pl-1">否则你的邻人羞辱你时，</span><br /><span className="pl pl-1">你最后要怎么做呢？</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 18:5–17; 箴言 11:13; 箴言 20:19"> <span className="pl pl-1">有了争讼，可以与邻人争辩，</span><br /><span className="pl pl-1">但不要暴露他人的秘密，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 119:39"> <span className="pl pl-1">免得听见的人辱骂你，</span><br /><span className="pl pl-1">你的恶名就不会离开你。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="箴言 15:23; 以赛亚书 50:4; 传道书 12:10"> <span className="pl pl-1">话说得合宜，</span><br /><span className="pl pl-1">就如金苹果镶在银器上。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 141:5; 箴言 15:31–32; 箴言 15:5"> <span className="pl pl-1">在听从者的耳中，</span><br /><span className="pl pl-1">智慧的责备就如金环和黄金首饰。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="箴言 13:17; 箴言 25:25; 腓立比书 2:25–30"> <span className="pl pl-1">忠实的信使对于派遣他的人，</span><br /><span className="pl pl-1">如同收割日子里冰雪的清凉，</span><br /><span className="pl pl-1">使主人的心舒畅</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="使主人的心舒畅——或译作“使主人的灵魂苏醒”。">a</a></sup><br /><span className="pl pl-1">。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="箴言 20:6; 路加福音 14:11; 彼得后书 2:15–19"> <span className="pl pl-1">为没送的礼物夸耀，</span><br /><span className="pl pl-1">就如有云有风却无雨。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 15:1; 传道书 10:4; 箴言 16:14"> <span className="pl pl-1">藉着恒久忍耐，能说服统领；</span><br /><span className="pl pl-1">温和的舌头，能折断骨头。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 25:27; 以弗所书 5:18; 箴言 24:13–14"> <span className="pl pl-1">你找到蜂蜜，吃够就好</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就好——辅助词语。">b</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">免得你过饱，把它吐出来。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="创世记 19:2–3; 士师记 19:18–21; 罗马书 15:24"> <span className="pl pl-1">你的脚要少进邻人的家，</span><br /><span className="pl pl-1">免得他厌烦你、恨恶你。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="诗篇 57:4; 箴言 12:18; 雅各书 3:6"> <span className="pl pl-1">作假见证指证自己邻人的，</span><br /><span className="pl pl-1">就像大锤、刀剑和利箭。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 36:6; 以西结书 29:6–7; 约伯记 6:14–20"> <span className="pl pl-1">在患难的日子里依赖背信者，</span><br /><span className="pl pl-1">就如依赖坏的牙齿、颤抖的脚。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="罗马书 12:15; 传道书 3:4; 以赛亚书 58:7"> <span className="pl pl-1">对着悲伤的心灵唱歌，</span><br /><span className="pl pl-1">就像冷天脱衣服，</span><br /><span className="pl pl-1">又像碱上倒醋。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="罗马书 12:20–21; 马太福音 5:44; 出埃及记 23:4–5"> <span className="pl pl-1">如果你的仇敌饿了，你当给他食物吃；</span><br /><span className="pl pl-1">如果他渴了，你当给他水喝；</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 16:12; 马太福音 10:13; 哥林多前书 15:18"> <span className="pl pl-1">你这样做</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="这样做——辅助词语。">c</a></sup><br /><span className="pl pl-1">，就如把火炭堆在他的头上，</span><br /><span className="pl pl-1">耶和华也必回报你。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="约伯记 37:22; 诗篇 15:3; 罗马书 1:30"> <span className="pl pl-1">北风带来大雨，</span><br /><span className="pl pl-1">暗中毁谤的口舌带来怒容。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 21:19; 箴言 21:9; 箴言 27:15–16"> <span className="pl pl-1">宁可住在屋顶的一角，</span><br /><span className="pl pl-1">也好过与争吵的妻子</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="妻子——或译作“女人”。">d</a></sup><br /><span className="pl pl-1">同住一屋。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 15:30; 罗马书 10:15; 诗篇 63:1"> <span className="pl pl-1">来自遥远之地的好消息，</span><br /><span className="pl pl-1">就如凉水滋润</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="滋润——辅助词语。">e</a></sup><br /><span className="pl pl-1">疲乏的心灵。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 34:18–19; 撒母耳记上 22:14–18; 帖撒罗尼迦前书 2:15"> <span className="pl pl-1">义人在恶人面前动摇，</span><br /><span className="pl pl-1">就如被践踏的泉源，受污染的水泉。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 5:44; 箴言 27:2; 腓立比书 2:3"> <span className="pl pl-1">吃蜂蜜过多不好；</span><br /><span className="pl pl-1">刻意追求自己的荣耀，也不荣耀。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="箴言 16:32; 箴言 22:24; 历代志下 32:5"> <span className="pl pl-1">人不控制自己的心灵，</span><br /><span className="pl pl-1">就如毁坏的城没有城墙。</span></span>
</div>

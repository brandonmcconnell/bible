<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="使徒行传 7:8; 希伯来书 11:17–18; 创世记 46:8–27"> <span className="pl pl-1">亚伯拉罕生以撒，</span><br /><span className="pl pl-1">以撒生雅各，</span><br /><span className="pl pl-1">雅各生犹大和他的兄弟们，</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="创世记 46:12; 创世记 38:29–30; 历代志上 4:1"> <span className="pl pl-1">犹大与塔玛尔生法勒斯和谢拉，</span><br /><span className="pl pl-1">法勒斯生希斯伦，</span><br /><span className="pl pl-1">希斯伦生亚兰，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 2:10–12; 民数记 7:12; 民数记 2:3"> <span className="pl pl-1">亚兰生亚米拿达，</span><br /><span className="pl pl-1">亚米拿达生拿顺，</span><br /><span className="pl pl-1">拿顺生撒门，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 11:31; 路得记 1:16–17; 雅各书 2:25"> <span className="pl pl-1">撒门与拉合生波阿斯，</span><br /><span className="pl pl-1">波阿斯与路得生俄备得，</span><br /><span className="pl pl-1">俄备得生耶西，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 15:5; 撒母耳记上 17:12; 撒母耳记下 12:24–25"> <span className="pl pl-1">耶西生大卫王。</span><br />从大卫到迁徙巴比伦<br /><span className="pl pl-1">大卫</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="大卫——有古抄本作“大卫王”。">a</a></sup><br /><span className="pl pl-1">与乌利亚的妻子生所罗门，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 14:1–15; 列王纪上 14:31; 列王纪上 11:43–24"> <span className="pl pl-1">所罗门生罗波安，</span><br /><span className="pl pl-1">罗波安生亚比雅，</span><br /><span className="pl pl-1">亚比雅生亚撒，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="历代志上 3:11; 历代志下 26:1–23; 列王纪下 8:16"> <span className="pl pl-1">亚撒生约沙法，</span><br /><span className="pl pl-1">约沙法生约兰，</span><br /><span className="pl pl-1">约兰生乌西雅，</span><br /></span>

<span className="v" id="v15" data-v="15"> <span className="pl pl-1">以律生以利亚撒，</span><br /><span className="pl pl-1">以利亚撒生玛坦，</span><br /><span className="pl pl-1">玛坦生雅各，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 27:17; 约翰福音 4:25; 路加福音 3:23"> <span className="pl pl-1">雅各生约瑟，就是玛丽亚的丈夫，</span><br /><span className="pl pl-1">那称为基督的耶稣是由玛丽亚所生的。</span></span>

<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 1:11–12; 列王纪下 24:14; 马太福音 11:2"> 这样，从亚伯拉罕到大卫的各世代，一共有十四代；从大卫到被迫迁徙巴比伦的时候，也有十四代；从被迫迁徙巴比伦的时候到基督，又有十四代。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="加拉太书 4:4–5; 路加福音 1:27–38; 约伯记 14:4"> 耶稣基督的诞生是这样的：耶稣的母亲玛丽亚已经许配给约瑟，在他们成婚<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="成婚——或译作“同居”；原文直译“聚在一起”。">b</a></sup>以前，玛丽亚就由圣灵怀了孕。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 22:21–24; 申命记 24:1–4; 约翰福音 8:4–5"> 她的丈夫约瑟是个义人，不愿意公开羞辱她，想要暗中把她休了。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="箴言 3:5–6; 路加福音 1:19; 马太福音 1:18"> 约瑟思考这些事以后，忽然主的一位天使在约瑟梦中显现，说：“大卫的后裔约瑟，不要怕迎娶玛丽亚做你的妻子，因为她里面所怀的是由圣灵而来的。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 13:23; 使徒行传 4:12; 约翰福音 1:29"> 玛丽亚将要生一个儿子，你要给他起名叫耶稣，因为他将要把自己的子民从他们的罪孽中拯救出来。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="路加福音 24:44; 马太福音 2:23; 列王纪上 8:15"> 不过这整个事的发生，是为要应验主藉着先知所说的话：</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 7:14; 以赛亚书 9:6–7; 诗篇 46:11"> <span className="pl pl-1">“看哪，那童贞女要怀孕，她要生一个儿子，</span><br /><span className="pl pl-1">人们将称他的名为以马内利。” ——</span><br />“以马内利”翻译出来就是“神与我们同在”。</span>

<span className="v" id="v25" data-v="25" data-xref="路加福音 2:21; 出埃及记 13:2; 马太福音 1:21"> 只是在她生儿子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="儿子——有古抄本作“头胎儿子”。">c</a></sup>以前，一直没有与她同房。约瑟给孩子起名叫耶稣。</span>

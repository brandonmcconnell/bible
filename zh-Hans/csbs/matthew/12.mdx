<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 23:25; 马可福音 2:23–28; 路加福音 6:1–5"> 在安息日那天，耶稣从麦田经过。他的门徒们饿了，就开始摘麦穗吃。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 12:10; 约翰福音 7:21–24; 路加福音 14:3"> 有些法利赛人看见了，就对耶稣说：“你看，你的门徒们做了在安息日不可以做的事。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 21:3–6; 路加福音 6:3; 马可福音 2:25–26"> 耶稣对他们说：<span className="woj">“大卫和那些与他在一起的人饥饿时所做的事，你们难道没有读过吗？</span></span>
<span className="v" id="v4" data-v="4" data-xref="利未记 24:5–9; 出埃及记 25:30; 利未记 8:31"> <span className="woj">他不是进了神的殿</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="殿——原文直译“家”。">a</a></sup><span className="woj">，和他们吃了</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="和他们吃了——有古抄本作“吃了”。">b</a></sup><span className="woj">陈设饼吗？这饼是他和那些与他在一起的人不可以吃的，唯有祭司才可以吃。</span></span>
<span className="v" id="v5" data-v="5" data-xref="民数记 28:9–10; 约翰福音 7:22–23; 尼希米记 13:17"> <span className="woj">再者，你们难道没有在律法书上读过：当安息日，祭司们在圣殿里触犯了安息日，也是无罪的吗？</span></span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 12:41–42; 历代志下 6:18; 彼得前书 2:4–5"> <span className="woj">但是我告诉你们：比圣殿更大的就在这里！</span></span>
<span className="v" id="v7" data-v="7" data-xref="何西阿书 6:6; 马太福音 9:13; 弥迦书 6:6–8"> <span className="woj">你们如果明白‘我要的是怜悯，而不是祭祀’这话是什么意思，就不会把无罪的定为有罪了。</span></span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 2:28; 路加福音 6:5; 约翰福音 5:17–23"> <span className="woj">因为人子是安息日的主。”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马可福音 3:1–6; 路加福音 6:6–11"> 耶稣离开那地方，进了他们的会堂。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 13:14; 约翰福音 9:16; 约翰福音 8:6"> 看哪，有个一只手枯萎的人。有些人就问耶稣，说：“在安息日使人痊愈，是否可以呢？”这是为要控告耶稣。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="申命记 22:4; 路加福音 14:5; 路加福音 13:15–17"> 耶稣对他们说：<span className="woj">“你们当中有哪一个人，如果他有一只羊在安息日掉进坑里，他不会抓住羊，把它拉上来呢？</span></span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 6:26; 路加福音 6:9; 马可福音 3:4"> <span className="woj">人比羊重要多了！所以，在安息日做好事是可以的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 13:13; 使徒行传 3:7–8"> 于是耶稣对那个人说：<span className="woj">“伸出你的手！”</span>他一伸出来，手就复原了，和另一只一样健全。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 11:53; 约翰福音 10:39; 马可福音 3:6"> 那些法利赛人就出去，商议怎样对付耶稣，好除灭他。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="马可福音 3:7–12; 马太福音 10:23; 马太福音 19:2"> 耶稣知道了，就离开那里。有一大群人跟随他，耶稣使他们都痊愈了，</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 8:4; 马太福音 9:30; 马太福音 17:9"> 并且告诫他们不要把他传扬出去。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 42:1–4; 以赛亚书 42:9; 马太福音 13:35"> 这是为要应验那藉着先知以赛亚所说的话：</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 42:1; 路加福音 4:18; 使徒行传 10:38"> <span className="pl pl-1">“看哪，我所拣选的仆人，</span><br /><span className="pl pl-1">我所爱的，心所喜悦的。</span><br /><span className="pl pl-1">我要把我的灵赐给他，</span><br /><span className="pl pl-1">他要向外邦人宣扬审判的事。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 11:29; 约翰福音 18:36–38; 提摩太后书 2:24–25"> <span className="pl pl-1">他不争竞、不喧嚷，</span><br /><span className="pl pl-1">大街</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="大街——或译作“广场”。">c</a></sup><br /><span className="pl pl-1">上也没有人听见他的声音。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 42:3–4; 以西结书 34:16; 以赛亚书 61:1–3"> <span className="pl pl-1">压伤的芦苇，他不折断；</span><br /><span className="pl pl-1">将熄的灯火，他不吹灭，</span><br /><span className="pl pl-1">直到他使公义得胜，</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 11:10; 罗马书 15:12–13; 以赛亚书 42:4"> <span className="pl pl-1">外邦人将要仰望他的名。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 11:14–15; 马可福音 7:35–37; 以赛亚书 29:18"> 那时，一个有鬼魔附身、又瞎又哑的人被带到耶稣那里。耶稣使他痊愈，那哑巴就能说话，也能看见了。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 9:27; 约翰福音 4:29; 马太福音 22:42–43"> 众人都十分惊讶，说：“难道这个人就是‘大卫的后裔’？”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="马可福音 3:22; 马太福音 9:34; 路加福音 11:15"> 但法利赛人听见了却说：“这个人如果不是靠着鬼魔的王别西卜，就不能驱赶鬼魔！”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="加拉太书 5:15; 耶利米书 17:10; 马太福音 9:4"> 耶稣知道他们的想法，就对他们说：<span className="woj">“任何一个国家，如果自相纷争就成为荒芜；任何一个城或家庭，如果自相纷争就站立不住。</span></span>
<span className="v" id="v26" data-v="26" data-xref="歌罗西书 1:13; 启示录 20:2–3; 约翰一书 5:19"> <span className="woj">如果撒旦驱赶撒旦，就是自相纷争，它的国怎么能站立得住呢？</span></span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 19:13–16; 马可福音 9:38–39; 路加福音 9:49–50"> <span className="woj">如果我是靠别西卜驱赶鬼魔，那么，你们的子弟是靠谁驱赶鬼魔呢？为此，你们的子弟就将要成为你们的审判者了。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 11:20; 但以理书 7:14; 马太福音 6:33"> <span className="woj">然而，如果我藉着神的灵驱赶鬼魔，那么，神的国就已经临到你们了。</span></span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 49:24; 马可福音 3:27; 路加福音 11:21–22"> <span className="woj">人怎么能进入一个壮士的家抢夺他的东西呢？如果不先把那壮士捆住，就不能抢夺他的家。</span></span>
<span className="v" id="v30" data-v="30" data-xref="马可福音 9:40; 路加福音 11:23; 约书亚记 24:15"> <span className="woj">不与我在一起的，就是在反对我；不与我一起收集的，就是在拆散。</span></span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 12:10; 马可福音 3:28–30; 希伯来书 10:29"> <span className="woj">为此，我告诉你们：人一切的罪和亵渎的话都能被赦免，但亵渎圣灵却不能被赦免。</span></span>
<span className="v" id="v32" data-v="32" data-xref="马可福音 3:29; 希伯来书 10:26–29; 希伯来书 6:4–6"> <span className="woj">凡是说话抵挡人子的，还能被赦免；但如果有人说话抵挡圣灵，无论在这世代，或在将要来的世代，都不能被赦免。</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 6:43–44; 马太福音 7:16–20; 雅各书 4:8"> <span className="woj">“你们让一棵树好，它的果子就好；你们让一棵树坏，它的果子就坏；这样，一棵树是凭着果子被认出来。</span></span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 6:45; 马太福音 15:18; 以弗所书 4:29"> <span className="woj">你们这些毒蛇的子孙！你们做为恶人，怎么能说出善的来呢？因为心里所充满的，口里就说出来。</span></span>
<span className="v" id="v35" data-v="35" data-xref="箴言 15:4; 歌罗西书 4:6; 箴言 15:28"> <span className="woj">好人从他心里</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本没有“他心里”。">d</a></sup><span className="woj">所存的善，发出善来；坏人从他心里所存的恶，发出恶来。</span></span>
<span className="v" id="v36" data-v="36" data-xref="传道书 12:14; 罗马书 2:16; 启示录 20:12"> <span className="woj">我告诉你们：人所说的每一句无益的话，在那审判的日子，句句都要做出交代，</span></span>
<span className="v" id="v37" data-v="37" data-xref="箴言 13:3; 雅各书 2:21–25"> <span className="woj">因为凭你的话，你将被称为义；也凭你的话，你将被定有罪。”</span></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="哥林多前书 1:22; 马可福音 8:11–12; 路加福音 11:16"> 当时，有一些经文士和法利赛人对耶稣说：“老师，我们希望你显个神迹给我们看。”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="马太福音 16:4; 路加福音 11:29–32; 马可福音 8:38"> 耶稣回答他们，说：<span className="woj">“一个邪恶、淫乱的世代会寻求神迹；可是除了先知约拿的神迹以外，不会有神迹赐给它了。</span></span>
<span className="v" id="v40" data-v="40" data-xref="约拿书 1:17; 马太福音 27:63–64; 马太福音 16:21"> <span className="woj">就是说，正如约拿在大鱼的肚子里三天三夜，人子也照样将要在地心三天三夜。</span></span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 12:42; 希伯来书 11:7; 马太福音 12:6"> <span className="woj">在审判的时候，尼尼微人将要与这世代一起复活</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="复活——或译作“起来”。">e</a></sup><span className="woj">，并且要定这世代的罪，因为尼尼微人因着约拿的传道就悔改了。看，比约拿更大的就在这里！</span></span>
<span className="v" id="v42" data-v="42" data-xref="列王纪上 10:1–13; 历代志下 9:1–12; 希伯来书 1:2–4"> <span className="woj">在审判的时候，南方的女王</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="南方的女王——指“示巴女王”。">f</a></sup><span className="woj">将要与这世代一起复活</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="复活——或译作“起来”。">g</a></sup><span className="woj">，并且要定这世代的罪，因为她从极远的地方来，要听所罗门智慧的话语。看，比所罗门更大的就在这里！</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="路加福音 11:24–26; 路加福音 8:28–32; 马太福音 8:29"> <span className="woj">“有个污灵从一个人身上出来以后，走遍无水之地，寻找安歇的地方，却找不到，</span></span>
<span className="v" id="v44" data-v="44" data-xref="约翰一书 4:4; 启示录 13:8–9; 犹大书 1:4–5"> <span className="woj">就说：‘我要回到我离开的那屋里去。’于是它回去，发现那里空着，已被打扫干净，摆设整齐，</span></span>
<span className="v" id="v45" data-v="45" data-xref="路加福音 11:26; 马可福音 5:9; 希伯来书 6:4–8"> <span className="woj">就去带了另外七个比自己更邪恶的灵，进去住在那里。那个人最后的情况就比先前更坏了。这邪恶的世代也将是这样。”</span></span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="马太福音 13:55; 约翰福音 2:12; 约翰福音 7:3"> 耶稣正在向人群讲话，这时候他的母亲和弟弟们<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="弟弟们——原文直译“兄弟们”。">h</a></sup>站在外面，想要和他说话。</span>
<span className="v" id="v47" data-v="47"> 有人告诉他：“看，你母亲和弟弟们站在外面，想和你说话。”<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本没有此节。">i</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="马可福音 3:32–33; 马太福音 10:37; 路加福音 2:52"> 耶稣回答那对他说话的人，说：<span className="woj">“我的母亲是谁呢？我的弟兄是谁呢？”</span></span>
<span className="v" id="v49" data-v="49" data-xref="马可福音 3:34; 约翰福音 17:8–9; 约翰福音 20:17–20"> 他就伸手指着他的门徒们，说：<span className="woj">“看，我的母亲、我的弟兄！</span></span>
<span className="v" id="v50" data-v="50" data-xref="路加福音 8:21; 马可福音 3:35; 约翰福音 15:14"> <span className="woj">因为凡是遵行我天父旨意的人，他才是我的弟兄、姐妹和母亲。”</span></span>
</div>

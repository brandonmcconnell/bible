<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 8:4–10; 马太福音 13:1–15; 马可福音 4:1–12"> 那一天，耶稣从屋子里出来，在湖<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="湖——原文直译“海”；指“加利利湖（海）”。">a</a></sup>边坐下。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 5:3; 马太福音 4:25; 马可福音 4:1"> 有一大群人聚集到他那里，所以他上了一条船坐下来。众人都站在岸边。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马可福音 4:2–9; 马可福音 4:13; 诗篇 78:2"> 耶稣用比喻对他们讲了很多事。他说：<span className="woj">“看哪，有一个撒种的出去撒种。</span></span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 13:18–19"> <span className="woj">他撒的时候，有些种子落在路边，飞鸟来把它们吃掉了。</span></span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 11:19; 以西结书 36:26; 撒迦利亚书 7:12"> <span className="woj">有些落在岩石地上，那里没有多少泥土，它们立刻就发芽了，因为土不深；</span></span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 13:21; 雅各书 1:11–12; 歌罗西书 1:23"> <span className="woj">当太阳升起，它们被暴晒，就枯萎了，因为没有根。</span></span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 4:18–19; 耶利米书 4:3–4; 创世记 3:18"> <span className="woj">有些落进荆棘丛里，荆棘长起来，就把它们挤住了。</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 13:23; 路加福音 8:15; 创世记 26:12"> <span className="woj">但是另有落在好土壤上的，就不断地结出果实来，有一百倍的，有六十倍的，有三十倍的。</span></span>
<span className="v" id="v9" data-v="9" data-xref="启示录 2:11; 马太福音 11:15; 启示录 2:7"> <span className="woj">凡是有耳的</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有耳的——有古抄本作“有耳可听的”。">b</a></sup><span className="woj">，就应当听！”</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马可福音 4:33–34; 马可福音 4:10"> 门徒们上前来，问耶稣：“你对他们讲话，为什么用比喻呢？”</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 2:9–10; 哥林多前书 2:14; 马太福音 19:11"> 耶稣回答他们，说：<span className="woj">“天国的奥秘已经赐下来让你们知道，而没有赐给那些人；</span></span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 25:29; 马可福音 4:24–25; 路加福音 8:18"> <span className="woj">因为凡是有的，还要赐给他，使他丰足有余；凡是没有的，连他有的也将从他那里被拿走。</span></span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 12:2; 耶利米书 5:21; 以赛亚书 42:18–20"> <span className="woj">我之所以用比喻对他们说，是因为他们虽然看了，却看不见；听了，却听不进，也不领悟。</span></span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 6:9–10; 以西结书 12:2; 哥林多后书 3:14"> <span className="woj">在他们身上，正应验了以赛亚的预言，他说：</span><br /><span className="pl pl-1 woj">‘你们将听了又听，但绝不会领悟；</span><br /><span className="pl pl-1 woj">你们将看了又看，但绝不会明白；</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 6:10; 马可福音 4:12; 撒迦利亚书 7:11"> <span className="pl pl-1 woj">因为这子民的心麻木了，</span><br /><span className="pl pl-1 woj">他们充耳不闻，眼睛闭着；</span><br /><span className="pl pl-1 woj">免得他们眼睛看见，耳朵听见，心里领悟，</span><br /><span className="pl pl-1 woj">回转过来，我就使他们痊愈。’</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 10:23–24; 以弗所书 1:17–18; 马太福音 16:17"> <span className="woj">“但你们的眼睛是蒙福的，因为看见了；你们的耳朵是蒙福的，因为听见了。</span></span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 8:56; 希伯来书 11:13; 彼得前书 1:10–12"> <span className="woj">我确实地告诉你们：曾经有许多先知和义人渴望看你们所看见的，却没有看到；渴望听你们所听见的，却没有听到。</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 13:11–12; 路加福音 8:11–15; 马可福音 4:13–20"> <span className="woj">“所以，你们应当听这撒种的比喻：</span></span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 8:11–15; 马太福音 13:38; 希伯来书 2:1"> <span className="woj">无论谁听了天国的话语而不领悟，那恶者就来，把那撒在他心里的夺走；这就是那被撒上种子的‘路边之地’。</span></span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 33:31–32; 诗篇 106:12–13; 约翰福音 5:35"> <span className="woj">那被撒上种子的‘岩石地’是这样的人：他听了这话语，立刻怀着喜乐的心接受了它；</span></span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 11:6; 彼得后书 1:8–9; 以弗所书 3:17"> <span className="woj">只是他里面没有根而不能持久，一旦为这话语受患难或逼迫，他立刻就放弃</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="放弃——原文直译“绊倒”。">c</a></sup><span className="woj">了。</span></span>
<span className="v" id="v22" data-v="22" data-xref="提摩太前书 6:17; 路加福音 8:14; 提摩太前书 6:9–10"> <span className="woj">那被撒进种子的‘荆棘丛’是这样的人：他听了这话语，但今世的忧虑和财富的迷惑把话语挤住了，他就成了不结果实的。</span></span>
<span className="v" id="v23" data-v="23" data-xref="腓立比书 1:11; 马太福音 12:33; 约翰福音 15:16"> <span className="woj">那被撒上种子的‘好土壤’是这样的人：他听了这话语，就领悟了，必然结出果实来，结出的有一百倍的、有六十倍的、有三十倍的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="马太福音 25:1; 马太福音 13:47; 马太福音 20:1"> 耶稣对他们讲了另一个比喻说：<span className="woj">“天国好比一个人把好种子撒在自己的田里。</span></span>
<span className="v" id="v25" data-v="25" data-xref="彼得前书 5:8; 彼得后书 2:1; 使徒行传 20:30–31"> <span className="woj">但是当人们睡觉的时候，他的仇敌来把稗子撒在麦子中间，然后离开了。</span></span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 4:26–29"> <span className="woj">到了麦苗长大结穗的时候，稗子也显出来了。</span></span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 16:17; 哥林多后书 6:1; 哥林多后书 5:18–20"> <span className="woj">奴仆前来问那家的主人，说：‘主人，你不是把好种子撒在你的田里吗？从哪里来的这些稗子呢？’</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 5:3–7; 帖撒罗尼迦前书 5:14; 路加福音 9:49–54"> <span className="woj">“主人告诉他们：‘这是仇敌做的。’</span><br /><span className="woj">“奴仆问：‘那么，你要我们去把稗子拔掉吗？’</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> <span className="woj">“主人说：‘不，免得你们把稗子拔掉的时候，也把麦子一同连根拔出来。</span></span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 3:12; 提摩太前书 5:24; 哥林多前书 4:5"> <span className="woj">让两样一起长吧，直到收割的季节。在收割的时候，我要吩咐收割的人先把稗子拔掉，把它们绑成一捆一捆的好去烧掉，然后把麦子收进我的仓库里。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 13:18–19; 马太福音 17:20; 马可福音 4:30–32"> 耶稣对他们讲了另一个比喻说：<span className="woj">“天国好比一粒芥菜种子，有人拿去种在他的田里。</span></span>
<span className="v" id="v32" data-v="32" data-xref="以西结书 31:6; 但以理书 4:12; 以西结书 17:23–24"> <span className="woj">它虽然比所有的种子更小，长大以后，却比各种蔬菜更大，成了一棵树，结果天空的飞鸟来了，在它的枝子上搭窝。”</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="加拉太书 5:9; 哥林多前书 5:6–7; 路加福音 13:21"> 耶稣又对他们讲了另一个比喻：<span className="woj">“天国好比酵母，一个妇人拿去拌在</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="拌在——原文直译“藏在”。">d</a></sup><span className="woj">三斗</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="三斗——原文为“3撒顿”；容量约为22公升。1撒顿=7.3公升。">e</a></sup><span className="woj">面里，直到整团面都发了酵。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="马可福音 4:33–34; 约翰福音 16:25; 马太福音 13:13"> 耶稣用比喻向人群讲了这一切；他向他们讲话，没有不用比喻的。</span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 78:2; 以弗所书 3:9; 彼得前书 1:20–21"> 这是为要应验那藉着先知所说的话：<br /><span className="pl pl-1">“我要开口，</span><br /><span className="pl pl-1">用比喻说出创世以来被隐藏的事。”</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="约翰福音 16:17–20; 马太福音 13:11; 马太福音 9:28"> 然后，耶稣离开了人群，进了屋子。他的门徒们上前来，说：“请给我们解释一下田里稗子的比喻。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="哥林多前书 3:5–7; 马太福音 13:41; 路加福音 10:16"> 耶稣回答说：<span className="woj">“那撒好种子的是人子。</span></span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 8:44; 腓立比书 3:18–19; 使徒行传 13:10"> <span className="woj">田地是这世界，这些好种子就是天国的儿女，稗子是那恶者的儿女，</span></span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 13:49; 启示录 14:15–19; 马太福音 25:31"> <span className="woj">撒稗子的仇敌是魔鬼，收割的季节是世代的终结，收割的人是天使。</span></span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 13:39"> <span className="woj">就像稗子被拔出来用火烧掉，在这世代的终结也将是这样。</span></span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 24:31; 马太福音 18:7; 彼得后书 2:1–2"> <span className="woj">人子要差派他的天使们，从他的国度里挑出来所有绊脚的和作恶</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="恶——原文直译“不法”。">f</a></sup><span className="woj">的，</span></span>
<span className="v" id="v42" data-v="42" data-xref="马太福音 13:50; 路加福音 16:23–24; 马太福音 8:12"> <span className="woj">把他们丢进火炉里。在那里将有哀哭和切齿。</span></span>
<span className="v" id="v43" data-v="43" data-xref="但以理书 12:3; 马太福音 11:15; 路加福音 12:32"> <span className="woj">那时，义人会在他们父的国度里像太阳一样发光。凡是有耳的</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有耳的——有古抄本作“有耳可听的”。">g</a></sup><span className="woj">，就应当听！</span></span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="箴言 2:2–5; 歌罗西书 2:3; 腓立比书 3:7–9"> <span className="woj">“天国好比被藏在田里的财宝。有人发现了，就把它再藏起来，然后高高兴兴地去卖掉他所拥有的一切，买下了那块地。</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="箴言 3:13–18; 马太福音 16:26; 马太福音 13:24"> <span className="woj">“天国又好比一个商人寻找精美的珍珠。</span></span>
<span className="v" id="v46" data-v="46" data-xref="以弗所书 3:8; 路加福音 18:28–30; 箴言 2:4"> <span className="woj">当他发现了一颗极其贵重的珍珠，就去卖掉他所拥有的一切，买下了那颗珍珠。</span></span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="约翰福音 15:6; 提摩太后书 3:2–5; 马太福音 22:9–10"> <span className="woj">“天国又好比一张渔网撒在海里，网到了各种鱼类。</span></span>
<span className="v" id="v48" data-v="48" data-xref="马太福音 13:30; 马太福音 13:40–43; 马太福音 3:12"> <span className="woj">网一满了，渔夫们就把它拉上岸来，然后坐下，把好的收进筐里，把坏的丢在外面。</span></span>
<span className="v" id="v49" data-v="49" data-xref="启示录 20:12–15; 马太福音 24:31; 马太福音 13:39"> <span className="woj">在这世代的终结也将是这样。天使们要出去，把恶人从义人中分别出来，</span></span>
<span className="v" id="v50" data-v="50" data-xref="马太福音 13:42; 马太福音 8:12; 启示录 14:10–11"> <span className="woj">丢进火炉里。在那里将有哀哭和切齿。”</span></span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="马太福音 13:19; 马太福音 13:11; 马可福音 4:34"> 耶稣问他们<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本没有“耶稣问他们”。">h</a></sup>：<span className="woj">“这一切你们都领悟了吗？”</span><br />他们说：“是的，领悟了<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="领悟了——辅助词语。">i</a></sup>。”</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="约翰一书 2:7–8; 提摩太后书 3:16–17; 提多书 1:9"> 耶稣对他们说：<span className="woj">“为此，凡是成为天国门徒的经文士，就好比一家的主人，从他的宝库里拿出新的和旧的东西来。”</span></span>
<span className="v" id="v53" data-v="53" data-xref="马太福音 7:28; 马可福音 4:33–35"> 当耶稣讲完了这些比喻，就离开了那地方。</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="马太福音 7:28; 约翰福音 7:15–16; 马可福音 6:1–6"> 他来到自己的家乡，在他们的会堂里教导人，以致他们惊叹不已，说：“这个人的这种智慧和能力是从哪里来的呢？</span>
<span className="v" id="v55" data-v="55" data-xref="约翰福音 6:42; 马可福音 6:3; 路加福音 3:23"> 这不就是那木匠的儿子吗？他的母亲不是叫玛丽亚吗？他的弟弟们<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="弟弟们——原文直译“兄弟们”。">j</a></sup>不是雅各、约西<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="约西——有古抄本作“约瑟”。">k</a></sup>、西门和犹大吗？</span>
<span className="v" id="v56" data-v="56"> 他的妹妹们<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="妹妹们——原文直译“姐妹们”。">l</a></sup>不是都和我们在一起的吗？那么，他这一切是从哪里来的呢？”</span>
<span className="v" id="v57" data-v="57" data-xref="约翰福音 4:44; 马太福音 11:6; 路加福音 4:24"> 这样，他们就对耶稣很反感<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="对耶稣很反感——原文直译“因耶稣被绊倒”。">m</a></sup>。<br />耶稣对他们说：<span className="woj">“先知除了在本乡、本家以外，没有不受尊重的。”</span></span>
<span className="v" id="v58" data-v="58" data-xref="马可福音 6:5–6; 罗马书 11:20; 希伯来书 3:12–19"> 因为他们的不信，耶稣在那里就没有行很多神迹。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 61:1–3; 使徒行传 10:38; 路加福音 8:1"> 当耶稣吩咐完了他的十二个门徒，就离开了那里，到各城镇去传道、教导人。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 6:17; 马太福音 14:3; 马太福音 9:14"> 约翰在监狱里听说了基督所做的事，就派自己的几个<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="几个——有古抄本作“两个”。">a</a></sup>门徒去</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 11:27; 玛拉基书 3:1; 申命记 18:15–18"> 问耶稣：“将要来的那一位就是你吗？还是我们应该等候别人呢？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 耶稣回答他们，说：<span className="woj">“你们去把所听见、所看见的告诉约翰，</span></span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 35:4–6; 以赛亚书 61:1–3; 路加福音 4:18"> <span className="woj">就是：瞎眼的得以看见，瘸腿的行走，麻风病人被洁净，耳聋的听见，死人得以复活，穷人得以听到福音。</span></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 8:14–15; 哥林多前书 2:14; 马太福音 26:31"> <span className="woj">凡不因我被绊倒</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="被绊倒——或译作“放弃信仰”。">b</a></sup><span className="woj">的人，就蒙福了。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="雅各书 1:6; 约翰福音 5:35; 马可福音 1:3–5"> 约翰的门徒们走了，耶稣就开始对众人谈论约翰，说：<span className="woj">“你们曾经到旷野去，是要观看什么呢？一根被风吹动的芦苇吗？</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 3:4; 列王纪下 1:8; 撒迦利亚书 13:4"> <span className="woj">你们出去，究竟是要看什么呢？一个身穿细软衣服的人吗？看哪，那些穿细软衣服的人在王宫里。</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 1:76; 马太福音 14:5; 马太福音 21:24–26"> <span className="woj">你们出去，究竟是要看什么呢？一位先知吗？是的，我告诉你们：他比先知还大。</span></span>
<span className="v" id="v10" data-v="10" data-xref="玛拉基书 3:1; 以赛亚书 40:3; 玛拉基书 4:5"> <span className="woj">他就是经上记载的那个人：</span><br /><span className="pl pl-1 woj">‘看哪，我要差派我的使者在你前头，</span><br /><span className="pl pl-1 woj">他要在你之前预备你的道</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="道——或译作“路”。">c</a></sup><br /><span className="pl pl-1 woj">。’</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路加福音 7:28; 以弗所书 3:8; 马太福音 3:11"> <span className="woj">“我确实地告诉你们：在女人所生的人中，没有出现过一个比施洗者</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="施洗者——或译作“施浸者”。">d</a></sup><span className="woj">约翰更大的；然而在天国里，再小的也比约翰更大。</span></span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 16:16; 路加福音 13:24; 以弗所书 6:11–13"> <span className="woj">从施洗者</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="施洗者——或译作“施浸者”。">e</a></sup><span className="woj">约翰的日子到现在，天国是努力争取的，努力争取的人就得着它。</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="天国是努力争取的，努力争取的人就得着它。——或译作“天国受到强烈的攻击，强者夺取它。”">f</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 5:17–18; 罗马书 3:21; 使徒行传 13:27"> <span className="woj">在约翰之前，所有的先知和律法都说预言。</span></span>
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 4:5; 马太福音 17:10–13; 马可福音 9:11–13"> <span className="woj">如果你们愿意接受，约翰就是那位要来的以利亚。</span></span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 8:8; 马太福音 13:9; 马可福音 4:23"> <span className="woj">凡是有耳的</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有耳的——有古抄本作“有耳可听的”。">g</a></sup><span className="woj">，就应当听！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="路加福音 7:31–35; 马太福音 12:34; 马太福音 23:36"> <span className="woj">“我要把这世代比做什么呢？它就好比孩子们坐在街市上呼叫别的孩子，</span></span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 28:9–13; 以赛亚书 30:29; 耶利米书 9:17–20"> <span className="woj">说：</span><br /><span className="pl pl-1 woj">‘我们为你们吹笛，</span><br /><span className="pl pl-1 woj">你们却不跳舞；</span><br /><span className="pl pl-1 woj">我们唱哀歌，</span><br /><span className="pl pl-1 woj">你们也不捶胸。’</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 1:15; 马太福音 3:4; 约翰福音 10:20"> <span className="woj">“因为约翰来了，不吃也不喝，他们就说：‘他有鬼魔附身！’</span></span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 9:10–11; 路加福音 15:1–2; 路加福音 19:7"> <span className="woj">人子来了，也吃也喝，他们就说：‘看，这个贪食好酒的人！税吏和罪人的朋友！’然而，智慧是凭着智慧的行为</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="行为——有古抄本作“儿女”。">h</a></sup><span className="woj">被证明为义的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:13–15; 耶利米书 8:6; 提摩太后书 2:25–26"> 接着，耶稣开始斥责那些他曾经在其中行了许多神迹的城市，因为那里的人不肯悔改：</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 3:6–7; 使徒行传 12:20; 路加福音 9:10"> <span className="woj">“哥拉汛哪，你有祸了！伯赛达呀，你有祸了！因为在你们当中行过的神迹，如果行在提尔和西顿，那里的人早就会披麻蒙灰悔改了。</span></span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 11:24; 马太福音 10:15; 希伯来书 10:26–31"> <span className="woj">不过我告诉你们：在那审判的日子，提尔和西顿所受的，将要比你们还容易受呢！</span></span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 14:13–15; 约翰福音 4:46–54; 创世记 13:13"> <span className="woj">而你——迦百农啊，你将被高举到天上吗？不，你将下到阴间。因为在你中间行过的神迹，如果行在所多玛，它就会存留到今天。</span></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 10:15; 马太福音 11:22; 马可福音 6:11"> <span className="woj">不过我告诉你们：在那审判的日子，所多玛之地所受的，将要比你还容易受呢！”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马太福音 21:16; 诗篇 8:2; 马太福音 16:17"> 那时候，耶稣说：<span className="woj">“父啊，天地的主，我赞美</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="赞美——或译作“感谢”。">i</a></sup><span className="woj">你，因为你把这些事向有智慧的和有学问的人隐藏起来，而向小孩子们显明出来。</span></span>
<span className="v" id="v26" data-v="26" data-xref="提摩太后书 1:9; 以弗所书 1:11; 约伯记 33:13"> <span className="woj">是的，父啊！因为这正是你的美意。</span></span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 14:6–9; 马太福音 28:18; 路加福音 10:22"> <span className="woj">我父把一切都交给了我。除了父，没有人认识子；除了子和子所愿意启示的人，也没有人认识父。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马太福音 11:29; 约翰福音 7:37; 约翰福音 6:37"> <span className="woj">“所有劳苦和背负重担的人哪，到我这里来吧！我将使你们得到安息。</span></span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 6:16; 约翰一书 2:6; 腓立比书 2:7–8"> <span className="woj">你们当负起我的轭，向我学，因为我心地柔和、谦卑。这样，你们就将寻得灵魂的安息。</span></span>
<span className="v" id="v30" data-v="30" data-xref="约翰一书 5:3; 约翰福音 16:33; 腓立比书 4:13"> <span className="woj">要知道，我的轭是容易负的，我的担子是轻省的。”</span></span>
</div>
</div>

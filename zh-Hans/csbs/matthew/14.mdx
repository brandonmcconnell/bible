<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 3:1; 马可福音 8:15; 路加福音 9:7–9"> 那时候，分封王希律听到耶稣的消息，</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 16:14; 约翰福音 10:41; 马可福音 8:28"> 就对他的臣仆说：“这个人是施洗者<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="施洗者——或译作“施浸者”。">a</a></sup>约翰从死人中复活了！所以这些能力在他里面做工。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马可福音 6:17; 路加福音 3:19–20; 马太福音 4:12"> 原来，希律为了他弟弟<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="弟弟——原文直译“兄弟”。">b</a></sup>菲利普的妻子希罗迪娅的缘故，拘捕了约翰，把他捆起来关进监狱。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 20:21; 利未记 18:16; 马可福音 6:18"> 这是因为约翰一直对他说：“你占有这妇人是不可以的。”</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 21:26; 马太福音 11:9; 马可福音 6:19–20"> 希律想要杀约翰，可是怕民众，因为他们认为约翰是先知。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="马可福音 6:21–23; 创世记 40:20; 何西阿书 1:5–6"> 到了希律生日的时候，希罗迪娅的女儿在众人面前跳舞，使希律非常喜悦，</span>
<span className="v" id="v7" data-v="7" data-xref="以斯帖记 5:3; 以斯帖记 5:6; 以斯帖记 7:2"> 故此王就起誓承诺，无论她求什么都给她。</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 6:24; 箴言 29:10; 箴言 1:16"> 女儿受母亲的指使，就说：“请把施洗者<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="施洗者——或译作“施浸者”。">c</a></sup>约翰的头放在盘子里给我。”</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 19:12–16; 撒母耳记上 14:28; 马可福音 6:26"> 王就忧忧愁愁，但因所起的誓，又因一同坐席的人，就下令给她。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 17:12; 马太福音 21:35–36; 路加福音 9:9"> 于是派人去，在监狱里砍下了约翰的头，</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 16:6; 创世记 49:7; 以西结书 16:3–4"> 把他的头放在盘子上，端给女孩，女孩就拿去给她母亲。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 8:2; 马太福音 27:58–61"> 后来，约翰的门徒们前来把遗体领去埋葬了，又去告诉耶稣。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:10–17; 马太福音 14:1–2; 马可福音 6:30–44"> 耶稣听了这事，就上船离开那里，独自到一个荒僻的地方去。众人听到了，就从各城镇徒步来跟随他。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 4:15; 马太福音 9:36; 希伯来书 2:17"> 耶稣下了船，看见一大群人，就对他们动了怜悯之心，使其中的病人痊愈。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="马太福音 15:23; 马可福音 8:3; 马可福音 6:35–36"> 黄昏的时候，门徒们来到耶稣面前，说：“这是个荒僻的地方，而且天已经晚了。请遣散人群，好让他们到村庄去为自己买些食物。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪下 4:42–44; 哥林多后书 8:2–3; 传道书 11:2"> 但耶稣说：<span className="woj">“他们不需要离开，你们给他们吃的吧。”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 15:33–34; 马可福音 6:37–38; 路加福音 9:13"> 门徒们对耶稣说：“我们这里除了五个饼和两条鱼，就没有什么了。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 耶稣说：<span className="woj">“拿到我这里来。”</span></span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 8:6–7; 路加福音 24:30; 撒母耳记上 9:13"> 于是耶稣吩咐众人坐在草地上，就拿起这五个饼和两条鱼，抬头望天，祝福了，然后掰开饼，递给门徒们，他们又分给众人。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 16:12; 马可福音 6:42–44; 马太福音 16:8–10"> 大家都吃了，并且吃饱了。他们把剩下的碎块收拾起来，装满了十二个篮子。</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比书 4:19; 哥林多后书 9:8–11; 使徒行传 4:4"> 吃的人，不算妇女和孩子，约有五千。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马可福音 6:45–51; 约翰福音 6:15–21; 马太福音 15:39"> 耶稣立刻催促门徒们上船，要他们先往对岸去；这期间，他自己遣散了人群。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 6:12; 马可福音 6:46; 马太福音 26:36"> 他遣散了人群以后，就独自上山去祷告。到了晚上，只有他一个人在那里。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 6:18; 马可福音 6:48; 马太福音 8:24"> 那时，船已经离岸有几百公尺<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="几百公尺——原文为“几视距”。1视距=185公尺。">d</a></sup><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="离岸有几百公尺——有古抄本作“在湖中”。">e</a></sup>，由于逆风，被波浪冲击。</span>
<span className="v" id="v25" data-v="25" data-xref="约伯记 9:8; 约翰福音 6:19; 马可福音 6:48"> 天快亮的时候<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="天快亮的时候——原文直译“夜里四更天”；指“早晨三点至六点之间”。">f</a></sup>，耶稣在湖<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="湖——原文直译“海”；指“加利利湖（海）”。">g</a></sup>面上行走，向他们而去。</span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 6:49–50; 启示录 1:17; 路加福音 1:11–12"> 门徒们看见耶稣在湖面上行走，就惊慌不安，说：“是幽灵！”他们害怕得喊叫起来。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行传 23:11; 启示录 1:17–18; 约翰福音 16:33"> 耶稣立刻对他们说：<span className="woj">“鼓起勇气吧！是我，不要怕。”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约翰福音 6:68; 罗马书 12:3; 马太福音 26:33–35"> 彼得对他说：“主啊，如果是你，请吩咐我，从水面上走到你那里去。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="腓立比书 4:13; 马可福音 9:23; 使徒行传 3:16"> 耶稣说：<span className="woj">“你来吧！”</span><br />彼得就从船上下去，在水面上行走向耶稣那里去。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米哀歌 3:54–57; 提摩太后书 4:16–17; 马可福音 14:38"> 但是，他一看到风极大<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本没有“极大”。">h</a></sup>，就惧怕起来，开始往下沉，于是呼叫说：“主啊，救救我！”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="雅各书 1:6–8; 诗篇 138:7; 创世记 22:14"> 耶稣立刻伸手拉住他，说：<span className="woj">“小信的人哪，你为什么疑惑呢？”</span></span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 107:29–30; 马可福音 4:41; 约翰福音 6:21"> 他们一上船，风就停了。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 11:27; 诗篇 2:7; 罗马书 1:4"> 船上的人都<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附“来”。">i</a></sup>拜耶稣，说：“你真是神的儿子！”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马可福音 6:53–56; 路加福音 5:1; 约翰福音 6:24–25"> 他们渡过去，到革尼撒勒上岸。</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 4:24–25; 马可福音 6:55; 马可福音 1:28–34"> 那里的人一认出是耶稣，就派人到周围整个地区，把所有患病的都带到耶稣那里，</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 6:19; 马可福音 3:10; 出埃及记 28:33–43"> 恳求耶稣只要让他们摸一下他的衣服穗子。凡是摸着的人，都得了救治。</span>
</div>
</div>

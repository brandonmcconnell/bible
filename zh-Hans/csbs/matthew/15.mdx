<span className="v" id="v3" data-v="3" data-xref="歌罗西书 2:23; 提多书 1:14; 歌罗西书 2:8"> 耶稣回答他们，说：<span className="woj">“你们为什么为了你们的传统而违犯神的命令呢？</span></span>

<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="马可福音 7:10–13; 使徒行传 5:29; 马太福音 23:16–18"> <span className="woj">你们却说‘如果有人对父亲或母亲说：我本该给你的已经做了圣殿奉献，</span></span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前书 5:8; 耶利米书 8:8; 马可福音 7:13"> <span className="woj">他就可以完全不孝敬父母</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="父母——有古抄本作“父亲”。">b</a></sup><span className="woj">。’这样，为了你们的传统，你们就废弃了神的话语</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="神的话语——或译作“神的道”。">c</a></sup><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="话语——有古抄本作“命令”。">d</a></sup><span className="woj">。</span></span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 7:6; 马太福音 23:23–29; 使徒行传 28:25–27"> <span className="woj">你们这些伪善的人哪！以赛亚指着你们所说的预言是对的，他说：</span></span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 29:13; 以西结书 33:31; 使徒行传 8:21"> <span className="pl pl-1 woj">‘这子民</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附“用口亲近我，”。">e</a></sup><br /><span className="pl pl-1 woj">用嘴唇尊重我，</span><br /><span className="pl pl-1 woj">他们的心却远离我。</span><br /></span>

<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马可福音 7:14–15; 路加福音 20:45–47; 路加福音 24:45"> 耶稣召来众人，对他们说：<span className="woj">“你们当听，也当领悟：</span></span>

</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王纪上 22:13–14; 哥林多前书 10:32–33; 加拉太书 2:5"> 那时，门徒们前来对他说：“法利赛人听了这话很反感<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="很反感——原文直译“被绊倒了”。">g</a></sup>，你知道吗？”</span>

<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约翰福音 15:2; 以赛亚书 60:21; 约翰福音 15:6"> 耶稣回答说：<span className="woj">“凡不是我天父所栽种的，都将被连根拔起。</span></span>

</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="马太福音 13:36; 马可福音 4:34; 约翰福音 16:29"> 彼得对耶稣说：“请把这个比喻解释给我们听。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马太福音 16:9; 马可福音 7:18; 马可福音 9:32"> 耶稣说：<span className="woj">“到如今，你们也无知吗？</span></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 6:45; 哥林多前书 6:13; 马太福音 7:19–20"> <span className="woj">你们难道不明白：一切进入口里的，要进到肚子，然后被排到厕所；</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 15:28; 马太福音 12:34; 雅各书 3:6–10"> <span className="woj">而从口里出来的，是由心里发出的，这些才使人污秽。</span></span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 7:21–23; 加拉太书 5:19–21; 耶利米书 17:9"> <span className="woj">因为从心里发出种种恶念：杀人、通奸、淫乱、偷窃、做伪证、毁谤，</span></span>

<span className="v" id="v22" data-v="22" data-xref="马太福音 9:27; 马可福音 7:25–26; 马太福音 17:15"> 这时候，忽然来了一个住在那地区的迦南妇人，她呼叫说：“主啊，大卫的后裔<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="大卫的后裔——或译作“大卫之子”。">i</a></sup>，可怜我吧！我的女儿有鬼魔附身，痛苦万分。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 14:15; 马可福音 10:47–48; 耶利米哀歌 3:8"> 耶稣一句话也不回应，他的门徒们上前来求他，说：“这妇人一直跟在我们后面喊叫，请让她走吧。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="马太福音 10:5–6; 罗马书 15:8; 耶利米书 50:6–7"> 耶稣回答说：<span className="woj">“我奉差派，只到以色列家迷失的羊那里去。”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 32:26; 马太福音 20:31; 马太福音 14:33"> 那妇人来拜他，说：“主啊，求你帮助我！”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马可福音 7:27–28; 马太福音 7:6; 腓立比书 3:2"> 耶稣回答说：<span className="woj">“拿儿女的饼扔给小狗，是不合宜的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以弗所书 3:8; 路加福音 16:21; 约伯记 40:4–5"> 妇人说：“是的，主啊！不过连小狗也吃得到主人桌子上掉下来的碎渣！”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马可福音 9:23–24; 马太福音 8:13; 诗篇 145:19"> 于是耶稣回答她，说：<span className="woj">“哦，妇人哪，你这信心</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="信心——指“对耶稣基督的信心”。">j</a></sup><span className="woj">是大的！照你所愿的，给你成全吧。”</span>从那一刻起，她的女儿就痊愈了。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马太福音 4:18; 约翰福音 6:1; 马太福音 5:1"> 耶稣离开那地方，来到加利利湖<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="湖——原文直译“海”。">k</a></sup>边，上了山坐在那里。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 6:17–19; 使徒行传 5:15–16; 马太福音 14:35–36"> 有一大群人来到他面前，带着瘸腿的、瞎眼的、残疾的、聋哑的还有许多其他人，把他们放在耶稣脚前；耶稣就使他们痊愈了。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 9:8; 路加福音 18:43; 路加福音 17:15–18"> 结果众人看见聋哑的说话，残疾的康复，瘸腿的行走，瞎眼的看见，都感到惊奇，就荣耀以色列的神。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行传 27:33; 路加福音 12:29–30; 马太福音 9:36"> 耶稣召来他的门徒们，说：<span className="woj">“我怜悯这群人，因为他们与我在一起已经三天了，也没有什么东西吃。我不愿意让他们饿着肚子回去，恐怕他们在路上晕倒。”</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马可福音 6:37; 马太福音 14:15; 马可福音 8:4–5"> 门徒们说：“我们在旷野，从哪里得这么多的食物让这么大一群人吃饱呢？”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马太福音 16:9–10; 路加福音 24:41–42; 约翰福音 21:9–10"> 耶稣问他们：<span className="woj">“你们有多少饼？”</span><br />他们回答说：“七个，还有几条小鱼。”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="路加福音 9:14–16; 马可福音 6:39–40; 约翰福音 6:10"> 耶稣就吩咐众人坐在地上，</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 22:19; 罗马书 14:6; 约翰福音 6:11"> 于是拿起这七个饼和几条小鱼，祝谢以后，掰开，不断递给门徒们，他们又分给众人。</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 8:19–21; 马太福音 16:9–10; 马太福音 15:33"> 大家都吃了，并且吃饱了。然后，他们把剩下的碎块收拾起来，装满了七个筐子。</span>
<span className="v" id="v38" data-v="38"> 吃的人，不算妇女和孩子，就有四千。</span>
<span className="v" id="v39" data-v="39" data-xref="马可福音 8:10; 马太福音 14:22"> 耶稣遣散了人群以后，就上了船，来到茉加丹<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="茉加丹——有古抄本作“茉大拉”。">l</a></sup>地区。</span>

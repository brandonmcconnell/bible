<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 11:16; 马太福音 16:6; 使徒行传 4:1"> 有些法利赛人和撒都该人前来试探耶稣，要求他把一个从天上来的神迹显给他们看。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="路加福音 12:54–56"> 耶稣回答他们，说：<span className="woj">“黄昏的时候你们说：‘天要晴了，因为天色通红’；</span></span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 12:56; 历代志上 12:32; 马太福音 11:5"> <span className="woj">清晨的时候你们说：‘今天会有风雨，因为天色通红又变得阴沉。’</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附“你们这些伪善的人！”">a</a></sup><span className="woj">你们能分辨天象，却不能分辨时代的征兆。</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="-3 有古抄本没有“黄昏……征兆。”">b</a></sup></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 11:29–30; 马太福音 12:39–40; 约拿书 1:17"> <span className="woj">一个邪恶、淫乱的世代会寻求神迹，可是除了</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附“先知”。">c</a></sup><span className="woj">约拿的神迹以外，不会有神迹赐给它了。”</span>然后耶稣就离开他们走了。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马可福音 8:13–14; 马太福音 15:39"> 门徒们到了对岸，忘了带饼。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="路加福音 12:1; 加拉太书 5:9; 马太福音 16:12"> 耶稣对他们说：<span className="woj">“你们要注意，要提防法利赛人和撒都该人的酵母。”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马可福音 8:16–18; 马太福音 15:16–18; 使徒行传 10:14"> 门徒们就彼此讨论说：“这是因为我们没有带饼吧。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="马太福音 6:30; 马太福音 14:31; 马太福音 8:26"> 耶稣知道了，就说：<span className="woj">“小信的人哪，你们为什么彼此讨论没有带</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本没有“带”。">d</a></sup><span className="woj">饼的事呢？</span></span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 14:17–21; 约翰福音 6:9–13; 路加福音 9:13–17"> <span className="woj">你们还不明白吗？难道不记得那五个饼给五千人，你们收拾了几个篮子的碎块</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="的碎块——辅助词语。">e</a></sup><span className="woj">吗？</span></span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 15:34–38; 马可福音 8:17–21; 马可福音 8:5–9"> <span className="woj">也不记得那七个饼给四千人，你们收拾了几个筐子的碎块</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="的碎块——辅助词语。">f</a></sup><span className="woj">吗？</span></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 16:6; 路加福音 12:56; 马可福音 8:21"> <span className="woj">你们怎么不明白，我对你们说的不是饼的事，而是要你们提防法利赛人和撒都该人的酵母呢？”</span></span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 5:20; 使徒行传 23:8; 马太福音 15:4–9"> 门徒们这才领悟耶稣所说的不是要他们提防饼的酵母，而是要他们提防法利赛人和撒都该人的教导。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:18–20; 马可福音 8:27–29; 但以理书 7:13"> 耶稣来到凯撒里亚菲利彼地区，就问他的门徒们，说：<span className="woj">“人们说</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附“我”。">g</a></sup><span className="woj">人子是谁？”</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马可福音 6:15; 马太福音 14:2; 玛拉基书 4:5"> 他们回答说：“有的说是施洗者<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="施洗者——或译作“施浸者”。">h</a></sup>约翰，有的说是以利亚，另有的说是耶利米或是先知中的一位。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 9:20; 马太福音 13:11; 马可福音 8:29"> 耶稣问他们：<span className="woj">“那么你们呢？你们说我是谁？”</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马太福音 14:33; 约翰福音 11:27; 约翰一书 4:15"> 西门彼得回答说：“你是基督，是永生神的儿子！”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 6:45; 以弗所书 1:17–18; 马太福音 11:25–27"> 耶稣对他说：<span className="woj">“约拿的儿子西门，你是蒙福的，因为这不是任何人</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="任何人——原文直译“血和肉”。">i</a></sup><span className="woj">启示你的，而是我在天上的父启示你的。</span></span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 2:19–22; 哥林多前书 3:9–11; 以赛亚书 28:16"> <span className="woj">我还告诉你：你是彼得，我要在这磐石上建立我的教会，阴间的门</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="门——或译作“势力”。">j</a></sup><span className="woj">不能胜过它。</span></span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 18:18; 以赛亚书 22:22; 启示录 1:18"> <span className="woj">我要把天国的钥匙赐给你，你在地上所捆绑的，在天上将是已经被捆绑了的；你在地上所释放的，在天上将是被释放了的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马可福音 8:30; 路加福音 9:21; 约翰福音 1:41"> 接着耶稣吩咐门徒们，不要对任何人说他就是基督。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 24:6–7; 马太福音 20:17–19; 马太福音 17:22–23"> 从那时候起，耶稣开始向他的门徒们指示他必须到耶路撒冷去，经受长老们、祭司长们和经文士们的很多苦害，并且被杀，然后在第三天要复活。</span>
<span className="v" id="v22" data-v="22" data-xref="马可福音 8:32; 约翰福音 13:6–8; 马太福音 16:16–17"> 彼得把耶稣拉到一边，开始劝阻他，说：“主啊，千万不可，这事绝不能临到你身上。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="罗马书 8:5–8; 歌罗西书 3:2; 腓立比书 3:19"> 但耶稣转身对彼得说：<span className="woj">“撒旦，退到我后面去！你是我的绊脚石，因为你不是思想神的事，而是思想人的事。”</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="马太福音 10:38; 路加福音 14:27; 彼得前书 4:1–2"> 于是，耶稣对他的门徒们说：<span className="woj">“如果有人想要来跟从我，他就当舍弃自己，背起自己的十字架，然后跟从我。</span></span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 10:39; 马可福音 8:35; 启示录 12:11"> <span className="woj">因为凡想要保全</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="保全——原文直译“救”。">k</a></sup><span className="woj">自己生命的，将失去生命；凡为我的缘故失去自己生命的，将寻得生命。</span></span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 8:36–37; 约伯记 27:8; 路加福音 9:25"> <span className="woj">一个人就是赚得了全世界，却赔上了自己的生命</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="生命——或译作“灵魂”。">l</a></sup><span className="woj">，到底有什么益处呢？人还能拿什么来换回自己的生命呢？</span></span>
<span className="v" id="v27" data-v="27" data-xref="哥林多后书 5:10; 诗篇 62:12; 罗马书 2:6"> <span className="woj">人子将要在他父的荣耀中，与他的天使们一起来临。那时候，他要按照各人的所作所为回报每个人。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 9:27; 马可福音 9:1; 约翰福音 8:52"> <span className="woj">我确实地告诉你们：站在这里的有些人，在还没有尝到死的滋味之前，必定见到人子在他的国度中来临。”</span></span>
</div>
</div>

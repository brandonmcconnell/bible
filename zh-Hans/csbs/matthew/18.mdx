<span className="v" id="v4" data-v="4" data-xref="雅各书 4:10; 路加福音 14:11; 马可福音 10:43"> <span className="woj">所以，谁像这小孩子自我降卑，谁在天国里就更大。</span></span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 25:40; 马可福音 9:37; 约翰福音 13:20"> <span className="woj">无论谁奉我的名接受这样一个小孩子，就是接受我。</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="马可福音 9:42; 路加福音 17:1–2; 马太福音 18:10"> <span className="woj">“但无论谁使信我的这些卑微人中的一个绊倒，对那人来说，倒不如脖子上被拴上大磨石</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="大磨石——原文直译“驴拉的磨石”。">b</a></sup><span className="woj">，沉到深海里。</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 17:1; 哥林多前书 11:19; 马太福音 26:24"> <span className="woj">这世界有祸了，因为有使人绊脚的事；要知道，那些使人绊脚的事必然出现，不过使它出现的人有祸了。</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 5:29–30; 腓立比书 3:8–9; 罗马书 13:12"> <span className="woj">如果你的一只手或一只脚使你绊倒，就把它砍下来丢掉！对你来说，缺一只手或缺一只脚进入永生</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="永生——原文直译“生命”。">c</a></sup><span className="woj">，要比手脚双全被丢进永远的火里好多了。</span></span>

</div>

<span className="v" id="v11" data-v="11"> <span className="woj">要知道人子来，是为了拯救迷失的人。</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本没有此节。">e</a></sup></span>

<span className="v" id="v13" data-v="13" data-xref="西番雅书 3:17; 路加福音 15:5–10; 雅各书 2:13"> <span className="woj">如果找到了，我确实地告诉你们：他为这一只羊欢喜，会比为那九十九只没有迷失的羊更欢喜。</span></span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 17:12; 约翰福音 6:39–40; 彼得后书 3:9"> <span className="woj">照样，你们</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="你们——有古抄本作“我”。">f</a></sup><span className="woj">在天上的父也不愿意失去这些卑微人中的一个。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="利未记 19:17; 路加福音 17:3–4; 加拉太书 6:1"> <span className="woj">“如果你的弟兄对你</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本没有“对你”。">g</a></sup><span className="woj">犯了罪，你就要去，只在你和他之间责备他。如果他听你的，你就赢得了你的弟兄；</span></span>

<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦后书 3:6; 哥林多前书 5:9–7; 帖撒罗尼迦后书 3:14–15"> <span className="woj">如果他不听他们的，就告诉教会；如果他连教会也不听，就应当把他看做像外邦人或税吏一样。</span></span>

<span className="v" id="v19" data-v="19" data-xref="马太福音 7:7; 约翰一书 5:14–16; 马可福音 11:24"> <span className="woj">我再确实地告诉你们：如果你们当中有两个人，在地上同心地为任何事祈求，我在天上的父就会为你们成全；</span></span>

<span className="v" id="v25" data-v="25" data-xref="列王纪下 4:1; 尼希米记 5:5; 路加福音 7:42"> <span className="woj">因为那奴仆没有可偿还的，主人就下令把他和他的妻子儿女，以及他所拥有的一切都卖掉来偿还。</span></span>

<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 18:29; 路加福音 7:43; 马太福音 8:2"> <span className="woj">“那奴仆就俯伏拜他，说：‘</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附“主啊！”">j</a></sup><span className="woj">请宽容我吧，将来我会把一切偿还给你。’</span></span>

<div className="bp">

<span className="v" id="v32" data-v="32" data-xref="路加福音 19:22; 马太福音 25:26; 罗马书 3:19"> <span className="woj">“于是主人把那奴仆叫来，对他说：‘你这恶奴！因为你求我，我就免了你所有的债。</span></span>

<span className="v" id="v34" data-v="34" data-xref="马太福音 5:25–26; 雅各书 2:13; 路加福音 12:58–59"> <span className="woj">主人就发怒，把他交给掌刑官，直到他能还清所欠的一切债。</span></span>

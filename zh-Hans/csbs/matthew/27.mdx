<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 15:1; 约翰福音 18:28; 弥迦书 2:1"> 到了清晨，所有的祭司长和民间的长老商议对付耶稣，为要处死他。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 20:19; 使徒行传 3:13; 提摩太前书 6:13"> 他们把耶稣捆起来带走，交给总督彼拉多。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 7:10; 路加福音 22:47–48; 约伯记 20:15–29"> 这时候，那出卖耶稣的犹大看见耶稣被定了死罪，就后悔，去把三十个银钱退还给祭司长们和长老们，</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 15:30; 提多书 1:16; 使徒行传 18:15–17"> 说：“我出卖了无辜人的血，我有罪了。”<br />但是他们说：“这与我们有什么关系？你自己看着办吧！”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 1:18–19; 撒母耳记下 17:23; 列王纪上 16:18"> 犹大把银钱丢在圣所里就退了出来，去上吊自杀了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="路加福音 6:7–9; 申命记 23:18; 以赛亚书 61:8"> 祭司长们捡起银钱，说：“这既然是血钱，不可以放到圣殿奉献里。”</span>
<span className="v" id="v7" data-v="7"> 他们商议之后，就用那钱买了陶匠的一块地，做为外国人的坟地。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 1:19; 马太福音 28:15; 约书亚记 4:9"> 因此，那块地就被称为“血田”，直到今天。</span>
<span className="v" id="v9" data-v="9" data-xref="撒迦利亚书 11:12–13; 马太福音 1:22; 利未记 27:2–7"> 这就应验了藉着先知耶利米所说的话：<br />“他们拿了那三十个银钱，就是那人被定的价钱，是以色列子民所定的；</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亚书 11:13"> 他们用这钱买了陶匠的那块地，正如主所指示我的。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路加福音 23:2–3; 马可福音 15:2–5; 马太福音 26:25"> 耶稣站在总督面前，总督问他，说：“你是犹太人的王吗？”<br />耶稣说：<span className="woj">“是你说的。”</span></span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 26:63; 以赛亚书 53:7; 马太福音 27:14"> 可是当他被祭司长们和长老们控告的时候，什么都不回应。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马太福音 26:62; 约翰福音 18:35; 使徒行传 22:24"> 彼拉多对他说：“他们控告你这么多的事，你没有听见吗？”</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 8:18; 诗篇 71:7; 哥林多前书 4:9"> 耶稣连一句话也不回答，以致总督感到非常惊奇。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 18:38–40; 路加福音 23:16; 约翰福音 19:16"> 每逢这节日，总督会照惯例，给民众释放一个他们所要的囚犯。</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 15:7; 使徒行传 3:14; 路加福音 23:25"> 那时有一个出名的囚犯，叫巴拉巴。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 19:15; 列王纪上 18:21; 马可福音 15:9–12"> 当民众聚集的时候，彼拉多问他们：“你们要我给你们释放哪一个呢？是巴拉巴，还是那称为基督的耶稣？”</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 27:4; 使徒行传 5:17; 马可福音 15:10"> 其实彼拉多知道他们是出于嫉妒才把耶稣交给他的。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 9:9; 箴言 29:1; 马太福音 27:24"> 彼拉多正坐在审判席上，他的妻子派人到他那里说：“这义人的事，你什么也不要管。要知道，我今天因他的缘故，在梦中受了很多苦。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="使徒行传 3:14–15; 约翰福音 19:15–16; 约翰福音 18:40"> 祭司长们和长老们挑唆众人，叫他们要巴拉巴，而除灭耶稣。</span>
<span className="v" id="v21" data-v="21"> 总督问他们，说：“这两个人中，你们要我给你们释放哪一个呢？”<br />他们回答说：“巴拉巴！”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 53:2–3; 以赛亚书 49:7; 使徒行传 13:38"> 彼拉多对他们说：“那么，我该怎么处理这称为基督的耶稣呢？”<br />他们都说：“把他钉上十字架！”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="创世记 37:18–19; 使徒行传 7:57; 使徒行传 23:12–15"> 彼拉多说：“他到底做了什么恶事呢？”但他们却越发喊叫说：“把他钉上十字架！”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="马太福音 27:4; 诗篇 26:6; 哥林多后书 5:21"> 彼拉多知道自己无济于事，反而骚乱倒要发生，就拿水在众人面前洗手，说：“流这人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这人——有古抄本作“这义人”。">a</a></sup>的血，罪不在我，你们自己看着办吧！”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约书亚记 2:19; 使徒行传 5:28; 使徒行传 7:52"> 全体民众都回答说：“他的血归在我们和我们儿女的身上！”</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 53:5; 约翰福音 19:1; 马可福音 15:15"> 于是彼拉多给他们释放了巴拉巴，然后将耶稣鞭打<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="鞭打——罗马式鞭打使用的鞭子是带有碎骨头或金属尖钩的皮条，抽打时使人皮开肉绽，非常残酷。">b</a></sup>了，把他交出去钉上十字架。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约翰福音 18:28; 约翰福音 18:33; 使徒行传 10:1"> 那时，总督的士兵们把耶稣带进总督府，召集了全队士兵在他周围。</span>
<span className="v" id="v28" data-v="28" data-xref="马可福音 15:17; 约翰福音 19:2–5; 路加福音 23:11"> 他们剥下耶稣的衣服，给他套上一件深红色的袍子，</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 53:3; 马太福音 20:19; 诗篇 69:19–20"> 用荆棘编了冠冕，戴在他的头上，又把一根芦苇放在他的右手里，然后跪在他面前，戏弄他说：“万岁，犹太人的王！”</span>
<span className="v" id="v30" data-v="30" data-xref="以赛亚书 50:6; 马太福音 26:67; 以赛亚书 53:7"> 接着向他吐唾沫，拿芦苇打他的头。</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 53:7; 列王纪上 21:13; 列王纪上 21:10"> 他们戏弄完了，就脱下他深红色的袍子，给他穿上他自己的衣服，然后把他带走，要钉上十字架。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马可福音 15:21; 马太福音 16:24; 路加福音 23:26"> 他们出去的时候，遇见一个名叫西门的古利奈人，就强迫这个人来背耶稣的十字架。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 19:17–19; 马可福音 15:22–32; 马可福音 15:34"> 他们来到一个地方，叫“各各他”——这意思是“骷髅地”；</span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 69:21; 马可福音 15:23; 马太福音 27:48"> 他们把胆汁调和的酒<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="酒——有古抄本作“酸酒”。">c</a></sup>给耶稣喝。耶稣尝了，不肯喝。</span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 22:18; 马可福音 15:24–32; 路加福音 23:34"> 他们把耶稣钉上十字架以后，抽签分了他的衣服，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附“这是为要应验那藉着先知所说的话：‘他们分了我的衣服，又为我的衣裳抽签。’”">d</a></sup></span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 27:54; 马可福音 15:44; 马可福音 15:39"> 然后坐在那里看守着他，</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 23:38; 约翰福音 19:19–22; 马可福音 15:26"> 又在他的头上方，安了他的罪状牌，上面写道：“这是耶稣，犹太人的王。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="约翰福音 19:18; 路加福音 23:39–43; 以赛亚书 53:12"> 那时，有两个强盗与耶稣一起被钉十字架，一个在右边，一个在左边。</span>
<span className="v" id="v39" data-v="39" data-xref="诗篇 109:25; 耶利米哀歌 1:12; 诗篇 69:7–12"> 那些路过的人辱骂耶稣，摇着头，</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 26:61; 马太福音 4:6; 马太福音 4:3"> 说：“你这个要拆毁圣所、三天内又建起来的人哪，救救你自己吧！你如果是神的儿子，就从十字架上下来吧！”</span>
<span className="v" id="v41" data-v="41" data-xref="诗篇 35:26; 以赛亚书 28:22; 诗篇 22:12–13"> 同样，祭司长们也与经文士们和长老们<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附“和法利赛人”。">e</a></sup>一起嘲笑，说：</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 1:49; 马太福音 27:37; 使徒行传 4:14"> “他救了别人，却不能救自己！他是<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="他是——有古抄本作“如果他是”。">f</a></sup>以色列的王！现在让他从十字架上下来吧，这样我们就信靠他！</span>
<span className="v" id="v43" data-v="43" data-xref="诗篇 22:8; 约翰福音 10:36; 以赛亚书 37:10"> 他依靠神，如果神喜悦他，就让神现在救他吧！因为他说过‘我是神的儿子。’”</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 27:38; 马可福音 15:32; 路加福音 23:39–43"> 与耶稣一起被钉十字架的强盗也同样地责骂他。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="阿摩司书 8:9; 马可福音 15:33–34; 路加福音 23:44–45"> 从中午十二点<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="中午十二点——原文为“第六时刻”。">g</a></sup>起，黑暗笼罩了整个大地，一直到下午三点<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="下午三点——原文为“第九时刻”。">h</a></sup>。</span>
<span className="v" id="v46" data-v="46" data-xref="诗篇 22:1; 希伯来书 5:7; 以赛亚书 53:10"> 下午三点左右，耶稣大声呼叫：<span className="woj">“以利，以利！拉玛撒巴克达尼？</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="以利，以利！拉玛撒巴克达尼？——希伯来文词语的音译。">i</a></sup><span className="woj">”</span>——这意思是：<span className="woj">“我的神，我的神！你为什么离弃我？”</span></span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="玛拉基书 4:5; 马可福音 15:35–36; 马太福音 11:14"> 站在那里的一些人听见了，就说：“这个人在呼唤以利亚呢！”</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="诗篇 69:21; 马太福音 27:34; 路加福音 23:36"> 其中有一个人立刻跑去，拿了海绵蘸满了酸酒，套在芦苇上，要给他喝。</span>
<span className="v" id="v49" data-v="49"> 其他的人说：“等着吧，我们看以利亚会不会来救他。”</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="约翰福音 19:30; 以赛亚书 53:9–12; 诗篇 22:14–15"> 耶稣又大喊一声，就交出了灵魂。</span>
<span className="v" id="v51" data-v="51" data-xref="希伯来书 10:19–22; 马可福音 15:38; 希伯来书 6:19"> 忽然，圣所里的幔子从上到下裂成两半。大地震动，岩石裂开。</span>
<span className="v" id="v52" data-v="52" data-xref="以赛亚书 26:19; 帖撒罗尼迦前书 4:14; 哥林多前书 15:20"> 坟墓也开了，许多已睡了的圣徒的身体复活了。</span>
<span className="v" id="v53" data-v="53" data-xref="启示录 11:2; 以赛亚书 48:2; 启示录 21:2"> 耶稣复活以后，他们从坟墓里出来，进了圣城，向许多人显现。</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="马太福音 27:36; 马可福音 15:39; 马太福音 27:43"> 百夫长和那些与他一起看守耶稣的人，看见地震和所发生的事，就极其惧怕，说：“这个人真是神的儿子！”</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="路加福音 8:2–3; 路加福音 23:48–49; 约翰福音 19:25–27"> 那里有许多妇女从远处观看，她们从加利利开始就跟随耶稣，服事他。</span>
<span className="v" id="v56" data-v="56" data-xref="约翰福音 19:25; 马可福音 15:47–1; 马太福音 28:1"> 其中有茉大拉的玛丽亚、雅各和约西<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="约西——有古抄本作“约瑟”。">j</a></sup>的母亲玛丽亚，以及西庇太儿子们的母亲。</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="约翰福音 19:38–42; 马可福音 15:42–47; 路加福音 23:50–56"> 到了傍晚，来了一个亚利马太的财主，名叫约瑟，他自己也是耶稣的门徒。</span>
<span className="v" id="v58" data-v="58" data-xref="路加福音 23:52–53; 马可福音 15:44–46"> 他来到彼拉多面前，请求要耶稣的遗体，彼拉多就下令给他。</span>
<span className="v" id="v59" data-v="59"> 约瑟领了耶稣的遗体，用洁白的细麻布裹好，</span>
<span className="v" id="v60" data-v="60" data-xref="以赛亚书 53:9; 马太福音 28:2; 马太福音 27:66"> 安放在自己的新墓穴里，这墓穴是他凿在岩石里的。他又滚来一块大石头，堵住墓穴口，就离开了。</span>
<span className="v" id="v61" data-v="61" data-xref="马太福音 28:1; 马太福音 27:56"> 茉大拉的玛丽亚和另一个玛丽亚在那里，对着坟墓坐着。</span>
</div>
<div className="bp">
<span className="v" id="v62" data-v="62" data-xref="马可福音 15:42; 约翰福音 19:14; 约翰福音 19:42"> 第二天，就是预备日的后一天，祭司长们和法利赛人在彼拉多那里聚集，</span>
<span className="v" id="v63" data-v="63" data-xref="路加福音 9:22; 马太福音 16:21; 约翰福音 2:19"> 说：“大人，我们想起当那个迷惑人的还活着时曾经说过：‘在第三天我要复活。’</span>
<span className="v" id="v64" data-v="64" data-xref="马太福音 28:13; 马太福音 12:45"> 所以，请你下令严密看守那坟墓，一直到第三天，免得他的门徒们<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="有古抄本附“夜里”。">k</a></sup>来把他偷走，然后对民众说他从死人中复活了，这样，那最后的迷惑就要比先前的更厉害了。”</span>
</div>

<span className="v" id="v2" data-v="2" data-xref="路加福音 19:30–32; 马可福音 11:2–3; 约翰福音 2:5–8"> 对他们说：<span className="woj">“你们到对面的村子里去，会立刻发现一头驴拴在那里，还有一头驴驹与它在一起。把它们解开，牵来给我。</span></span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 8:1–2; 使徒行传 17:25; 哥林多后书 8:9"> <span className="woj">如果有人对你们说什么，你们就说‘主需要它们，会很快把它们送来的。’”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 9:9; 约翰福音 12:15; 马太福音 1:22"> 这件事发生，是为要应验那藉着先知所说的话：</span>
<span className="v" id="v5" data-v="5" data-xref="撒迦利亚书 9:9–10; 以赛亚书 62:11; 以赛亚书 12:6"> <span className="pl pl-1">“要对锡安的女儿说</span><br /><span className="pl pl-1">‘看哪，你的王来到你这里，</span><br /><span className="pl pl-1">是谦和的，骑着驴——</span><br /><span className="pl pl-1">一头小驴，就是驴的驹子。’”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 39:43; 约翰福音 15:14; 出埃及记 40:16"> 两个门徒就去，照着耶稣所吩咐的做了。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 9:13; 马可福音 11:4–8; 路加福音 19:32–35"> 他们牵来了驴和驴驹，把外衣搭在它们背上，耶稣就坐在上面。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪下 9:13; 约翰福音 12:13; 利未记 23:40"> 有一大群人把自己的外衣铺在路上，也有人从树上砍下枝子铺在路上。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 118:24–26; 路加福音 2:14; 约翰福音 12:13–15"> 前行后随的人群呼喊说：<br /><span className="pl pl-1">“和散那归于大卫的后裔！</span><br /><span className="pl pl-1">奉主名而来的那一位——</span><br /><span className="pl pl-1">是蒙祝福的！</span><br /><span className="pl pl-1">在至高之处——和散那！”</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 9:5; 路得记 1:19; 约翰福音 12:16–19"> 耶稣进了耶路撒冷，全城都轰动了，人们问：“这个人是谁？”</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 6:14; 路加福音 7:16; 约翰福音 7:40"> 众人说：“这就是从加利利的拿撒勒来的先知耶稣。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约翰福音 2:14–17; 路加福音 19:45–47; 马可福音 11:15–18"> 耶稣进了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附“神的”。">a</a></sup>圣殿，把所有在圣殿里做买卖的人都赶了出去。他推翻了兑换银币之人的桌子和卖鸽子之人的凳子，</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 7:11; 以赛亚书 56:7; 路加福音 19:46"> 对他们说：<span className="woj">“经上记着：‘我的殿将被称为祷告的殿’，而你们却使它成为贼窝了！”</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="使徒行传 3:1–9; 使徒行传 10:38; 马太福音 11:4–5"> 耶稣在圣殿里，一些瞎眼的和瘸腿的来到他面前，耶稣就使他们痊愈了。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 21:9; 路加福音 19:39–40; 以赛亚书 26:11"> 祭司长们和经文士们看见耶稣所行的神迹，又见孩子们在圣殿里呼喊说：“和散那归于大卫的后裔”，就很生气。</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 8:2; 马太福音 11:25; 路加福音 19:39–40"> 他们问耶稣：“你听见这些小孩在说什么吗？”<br />耶稣回答他们，说：<span className="woj">“是的，听见了</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="听见了——辅助词语。">b</a></sup><span className="woj">。难道你们从来没有读过‘从孩子和吃奶婴儿的口中，你预备了赞美’这话吗？”</span></span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 11:18; 马可福音 11:11; 路加福音 24:50"> 然后，耶稣离开他们，出城到伯大尼去，在那里过夜。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 4:2; 希伯来书 4:15; 马太福音 12:1"> 清晨，回城的时候，耶稣饿了。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 15:6; 马可福音 11:14; 提多书 1:16"> 他看见路边有一棵无花果树，就上前去，可是树上除了叶子，什么也找不到。于是他对那棵树说：<span className="woj">“你永远不会再结果子了！”</span>那棵无花果树立刻就枯萎了。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 40:6–8; 马可福音 11:20–21; 雅各书 1:10–11"> 门徒们看见了，感到惊奇，说：“这棵无花果树怎么立刻枯萎了呢？”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="雅各书 1:6; 马太福音 17:20; 马可福音 11:22–23"> 耶稣回答他们，说：<span className="woj">“我确实地告诉你们：你们如果存着信而不疑惑，不仅能做我对这无花果树所做的，即使对这座山说‘愿你被挪开，被丢进海里去！’事情也将成就。</span></span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 7:7; 约翰一书 5:14–15; 马可福音 11:24"> <span className="woj">你们在祷告中无论求什么，只要信，就必得着。”</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 4:7; 马可福音 11:27–33; 历代志上 24:1–19"> 耶稣进了圣殿，正教导人的时候，祭司长们和民间的长老们前来问他：“你凭什么权柄做这些事？是谁给你这权柄的？”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 6:9; 歌罗西书 4:6; 马太福音 10:16"> 耶稣回答他们，说：<span className="woj">“我也要问你们一个问题，如果你们回答我，我就告诉你们我凭什么权柄做这些事。</span></span>
<span className="v" id="v25" data-v="25" data-xref="约翰一书 3:20; 马可福音 1:1–11; 约翰福音 3:18"> <span className="woj">约翰的洗礼是从哪里来的？是来自天上，还是来自人间呢？”</span><br />他们就彼此讨论，说：“如果我们说‘是来自天上’，他就会问我们‘那么你们为什么不相信他呢？’</span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 6:20; 马太福音 14:5; 约翰福音 5:35"> 但如果说‘是来自人间’——我们又怕民众，因为大家都认为约翰是先知。”</span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 1:18–22; 帖撒罗尼迦后书 2:9–10; 路加福音 20:7–8"> 于是他们回答耶稣，说：“我们不知道。”<br />耶稣就对他们说：<span className="woj">“我也不告诉你们我凭什么权柄做这些事。”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 15:58; 马太福音 20:1; 哥林多前书 10:15"> <span className="woj">“这件事你们怎么看？一个人有两个儿子，他前来对大儿子说：‘孩子，你今天到葡萄园去做工吧。’</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以西结书 18:28–32; 马太福音 3:2–8; 以赛亚书 55:6–7"> <span className="woj">“大儿子回答说：‘我不愿意去。’可是后来他悔改，就去了。</span></span>
<span className="v" id="v30" data-v="30" data-xref="提多书 1:16; 以西结书 33:31; 马太福音 23:3"> <span className="woj">父亲前来对小儿子也说同样的话。</span><br /><span className="woj">“小儿子回答说：‘主啊，我去。’可是他没有去。</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 7:29; 路加福音 7:37–50; 马太福音 7:21"> <span className="woj">“这两个儿子中，哪一个遵行父亲的意愿呢？”</span><br />他们回答说：“大儿子。”<br />耶稣说：<span className="woj">“我确实地告诉你们：税吏和妓女要在你们的前面进神的国，</span></span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 7:37–50; 撒迦利亚书 7:11–12; 路加福音 7:29–30"> <span className="woj">因为约翰来到你们这里指明义的道路，你们不相信他，而那些税吏和妓女们却相信了他。你们虽然看见了，后来还是没有悔改去相信他。</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 5:1–4; 马可福音 12:1–12; 路加福音 20:9–19"> <span className="woj">“你们当听另一个比喻：有一个人，是一家的主人，他栽种了一个葡萄园，四面围上篱笆，里面挖了一个榨酒池，盖了一座守望楼，然后把葡萄园租给一些农夫，就出外旅行。</span></span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 20:10–19; 以赛亚书 5:4; 撒迦利亚书 1:3–6"> <span className="woj">当收果子的季节近了，主人就派了奴仆们到那些农夫那里去收取他的果子。</span></span>
<span className="v" id="v35" data-v="35" data-xref="历代志下 36:15–16; 马太福音 5:12; 希伯来书 11:36–37"> <span className="woj">但那些农夫抓住他的奴仆，打了一个，杀了一个，还用石头砸死一个。</span></span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 22:4"> <span className="woj">主人又派别的奴仆去，比先前的更多，那些农夫也照样对待他们。</span></span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 3:16; 约翰福音 3:35–36; 西番雅书 3:7"> <span className="woj">后来他差派自己的儿子到他们那里，说：‘他们一定会尊重我的儿子。’</span></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="路加福音 20:14; 创世记 37:18–20; 马可福音 12:7–8"> <span className="woj">“可是那些农夫看见他的儿子，就彼此说：‘这是继承人。来，我们把他杀了，占有他的继业！’</span></span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 2:23; 雅各书 5:6; 路加福音 22:52–54"> <span className="woj">于是他们抓住他，把他扔出葡萄园外，杀了。</span></span>
<span className="v" id="v40" data-v="40" data-xref="希伯来书 10:29; 马可福音 12:9; 路加福音 20:15–16"> <span className="woj">那么，葡萄园的主人回来的时候，会怎么对待那些农夫呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="使徒行传 18:6; 马太福音 21:43; 使徒行传 28:28"> 他们回答说：“他会狠狠地除灭那些恶人，把葡萄园另租给按时交果子的农夫们。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v42" data-v="42" data-xref="诗篇 118:22–23; 以赛亚书 28:16; 使徒行传 4:11"> 耶稣对他们说：<span className="woj">“难道你们从来没有读过这段经文吗？</span><br /><span className="pl pl-1 woj">‘工匠所弃绝的石头，</span><br /><span className="pl pl-1 woj">它已经成了房角的头块石头；</span><br /><span className="pl pl-1 woj">这是主所成就的，</span><br /><span className="pl pl-1 woj">在我们眼中实在奇妙！’</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="马太福音 21:41; 马太福音 8:11–12; 彼得前书 2:9"> <span className="woj">为此，我告诉你们：神的国要从你们中间被夺走，赐给那结神国果子的人。</span></span>
<span className="v" id="v44" data-v="44" data-xref="以赛亚书 8:14–15; 彼得前书 2:8; 但以理书 2:34–35"> <span className="woj">那跌落在这石头上的人，就将被破碎；这石头落在谁的身上，就会把谁砸得稀烂。”</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本没有此节。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="路加福音 20:19; 路加福音 11:45; 马太福音 12:12"> 祭司长们和法利赛人听了耶稣的这些比喻，知道他是针对他们而说的，</span>
<span className="v" id="v46" data-v="46" data-xref="马太福音 21:11; 马太福音 21:26; 路加福音 7:16"> 就想拘捕他，可是怕民众，因为他们都认为耶稣是先知。</span>

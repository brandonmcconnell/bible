<span className="v" id="v1" data-v="1" data-xref="马太福音 20:1–16; 马太福音 12:43–45; 路加福音 14:16"> 耶稣又用比喻对他们说：</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 19:7–9; 马太福音 13:24; 以弗所书 5:24–32"> <span className="woj">“天国好比一个君王，为自己的儿子预备婚宴。</span></span>
<span className="v" id="v3" data-v="3" data-xref="启示录 22:17; 约翰福音 5:40; 路加福音 14:15–17"> <span className="woj">他派了奴仆们去叫那些被邀请的人前来赴宴，可是他们不肯来。</span></span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 13:46; 马太福音 21:36; 约翰福音 6:50–57"> <span className="woj">王又派了别的奴仆，说：‘你们去对那些被邀请的人说，看哪，我的午餐我已经预备好了，公牛和肥畜已经宰杀了，一切都预备好了，请你们来赴婚宴。’</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="希伯来书 2:3; 路加福音 14:18–20; 约翰一书 2:15–16"> <span className="woj">“但那些人不理，就走开了，有的到自己的田里去，有的做自己的生意去。</span></span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 15:19–20; 约翰福音 16:2–3; 使徒行传 7:51–57"> <span className="woj">其余的竟抓住王的奴仆们，凌辱他们，并且把他们杀了。</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 19:27; 彼得前书 4:17–18; 路加福音 21:24"> <span className="woj">王</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附“听了”。">a</a></sup><span className="woj">就发怒，派军兵除灭那些凶手，烧毁了他们的城。</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦后书 1:5; 使徒行传 13:46; 启示录 3:4"> <span className="woj">“然后对奴仆们说：‘婚宴预备好了，但那些被邀请的人不配。</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 14:21–24; 箴言 1:20–23; 马可福音 16:15–16"> <span className="woj">所以你们要到大街小巷去，把所见到的人都请来赴宴。’</span></span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 6:9–11; 启示录 19:6–9; 哥林多后书 12:21"> <span className="woj">那些奴仆就出去，到大街上，把所见到的，无论好人坏人都召集起来，婚宴上就坐满了宾客。</span></span>
<span className="v" id="v11" data-v="11" data-xref="启示录 3:4–5; 启示录 19:8; 希伯来书 4:12–13"> <span className="woj">王进来会见宾客，发现有一个人没有穿婚宴的礼服，</span></span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 2:9; 约伯记 5:16; 马太福音 20:13"> <span className="woj">就对他说：‘朋友，你进到这里来怎么没有穿婚宴的礼服呢？’那个人哑口无言。</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马太福音 8:12; 马太福音 25:30; 马太福音 24:51"> <span className="woj">“于是王吩咐仆人们：‘把他的手脚捆起来，</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附“带去”。">b</a></sup><span className="woj">丢到外面的黑暗里去！在那里将有哀哭和切齿。’</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="彼得后书 1:10; 路加福音 13:23–24; 马太福音 7:13–14"> <span className="woj">“要知道，蒙召唤的人多，而蒙拣选的人少。”</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 20:20–26; 马可福音 12:13–17; 诗篇 2:2"> 法利赛人就去商议，怎样找耶稣的话柄来陷害他。</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 3:6; 马可福音 8:15; 马可福音 12:14"> 他们派了自己的门徒们与希律党的人一同去见耶稣，说：“老师，我们知道你是真诚的，并且按真理教导神的道<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="道——或译作“路”。">c</a></sup>。你不顾忌任何人，因为你不看人的情面。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 2:1; 罗马书 13:6–7; 马太福音 17:25"> 请告诉我们，你认为向凯撒纳税，可以不可以呢？”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰福音 8:6; 路加福音 5:22; 约翰福音 2:25"> 耶稣看出他们的恶意，就说：<span className="woj">“你们这些伪善的人！为什么试探我呢？</span></span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 20:2; 启示录 6:6; 马太福音 18:28"> <span className="woj">拿一个纳税的钱币给我看。”</span>他们就拿来了一个银币<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="银币——原文为“得拿利”。1得拿利=约1日工资的罗马银币。">d</a></sup>给他。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 20:24"> 耶稣问他们：<span className="woj">“这是谁的像和名号？”</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="罗马书 13:7; 箴言 24:21; 使徒行传 4:19"> 他们回答说：“是凯撒的。”<br />耶稣对他们说：<span className="woj">“那么，凯撒的归给凯撒；神的归给神。”</span></span>
<span className="v" id="v22" data-v="22" data-xref="马可福音 12:12; 马太福音 22:46; 路加福音 20:25–26"> 他们听了，感到惊奇，就离开耶稣走了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 4:1; 马可福音 12:18–27; 使徒行传 23:6–8"> 在那一天，撒都该人来到耶稣那里，他们一向说没有复活的事。他们问耶稣，</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 25:5–10; 路加福音 20:28; 路得记 1:11"> 说：“老师，摩西说：如果一个人死了，没有儿女，他的一个兄弟就要娶他的妻子，为他兄弟留后裔。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 20:29–33; 马可福音 12:19–23; 希伯来书 9:27"> 我们这里曾经有兄弟七人，第一个结了婚，死了，没有后裔，留下妻子给他的一个兄弟。</span>
<span className="v" id="v26" data-v="26"> 第二个、第三个、一直到第七个，都是如此。</span>
<span className="v" id="v27" data-v="27"> 到了最后，这妇人也死了。</span>
<span className="v" id="v28" data-v="28"> 既然他们都娶过她，那么，在复活的时候，她将是这七个人中哪一个的妻子呢？”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约翰福音 20:9; 罗马书 15:4; 路加福音 1:37"> 耶稣回答说：<span className="woj">“你们错了，因为你们不明白经上的话，也不明白神的大能。</span></span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 20:34–36; 马可福音 12:24–25; 马太福音 24:38"> <span className="woj">复活的时候，人既不娶也不嫁，而是像天上的</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附“神的”。">e</a></sup><span className="woj">天使一样。</span></span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 12:3; 马太福音 21:16; 马太福音 21:42"> <span className="woj">关于死人复活的事，你们难道没有读过神对你们所说的话吗？神说</span></span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 3:6; 马可福音 12:26–27; 路加福音 20:37–38"> <span className="woj">‘我是亚伯拉罕的神、以撒的神、雅各的神。’神不是死人的神，而是活人的神。”</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马可福音 12:17; 马可福音 6:2; 约翰福音 7:46"> 众人听了这话，对他的教导惊叹不已。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马可福音 12:28–31; 马太福音 25:3–5; 马太福音 12:14"> 法利赛人听说耶稣使撒都该人哑口无言，就聚集在一起。</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 7:30; 路加福音 10:25–37; 路加福音 11:52"> 他们当中有一个是律法师，<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本没有“是律法师，”。">f</a></sup>来试探耶稣，问他：</span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 12:28–33; 马太福音 5:19–20; 路加福音 11:42"> “老师，律法中最大的诫命是哪一条呢？”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="马可福音 12:29–30; 路加福音 10:27; 申命记 6:5"> 耶稣对他说：<span className="woj">“‘你要以全心、全灵、全意爱主——你的神’，</span></span>
<span className="v" id="v38" data-v="38"> <span className="woj">这是最大的，也是最重要的诫命。</span></span>
<span className="v" id="v39" data-v="39" data-xref="马可福音 12:31; 路加福音 10:27–37; 利未记 19:18"> <span className="woj">其次的也和它类似，‘要爱邻如己。’</span></span>
<span className="v" id="v40" data-v="40" data-xref="罗马书 13:9; 马太福音 7:12; 约翰一书 4:19–21"> <span className="woj">全部律法和先知书都是以这两条诫命为依据的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 20:41–44; 马可福音 12:35–37; 马太福音 22:34"> 法利赛人聚集在一起的时候，耶稣问他们</span>
<span className="v" id="v42" data-v="42" data-xref="耶利米书 23:5–6; 约翰福音 6:68–69; 马太福音 16:13–17"> 说：<span className="woj">“关于基督，你们怎么看？他是谁的后裔呢？”</span><br />他们说：“是大卫的后裔。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v43" data-v="43" data-xref="撒母耳记下 23:2; 启示录 4:2; 马可福音 12:36"> 耶稣问他们：<span className="woj">“那么，大卫藉着圣灵，怎么还称他为‘主’呢？大卫说：</span></span>
<span className="v" id="v44" data-v="44" data-xref="诗篇 110:1; 希伯来书 1:13; 使徒行传 2:34–35"> <span className="pl pl-1 woj">‘主对我主说：</span><br /><span className="pl pl-1 woj">你坐在我的右边，</span><br /><span className="pl pl-1 woj">等我把你的敌人放在你的脚下</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附“做脚凳”。">g</a></sup><br /><span className="pl pl-1 woj">。’</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="罗马书 1:3–4; 启示录 22:16; 约翰福音 8:58"> <span className="woj">“因此，大卫如果称基督为‘主’，基督怎么会是大卫的后裔呢？”</span></span>
<span className="v" id="v46" data-v="46" data-xref="马可福音 12:34; 路加福音 20:40; 路加福音 14:6"> 没有人能回答他一句话。从那天起，再也没有人敢质问耶稣了。</span>
</div>

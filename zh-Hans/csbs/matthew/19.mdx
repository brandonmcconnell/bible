<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 10:40; 马太福音 19:1–9; 马太福音 7:28"> 当耶稣讲完了这些话，就离开加利利，来到约旦河对岸的犹太地区。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 12:15; 马可福音 6:55–56; 马太福音 15:30–31"> 有一大群人跟随他，他就在那里使他们痊愈。</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 10:2; 希伯来书 3:9; 马太福音 16:1"> 有些法利赛人前来试探耶稣，说：“无论出于什么缘故，人是否可以休妻呢？”</span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="创世记 2:23; 创世记 1:27; 创世记 5:2"> 耶稣回答说：<span className="woj">“你们难道没有读过吗？造物主从起初就把人造成男的和女的。</span></span>
<span className="v" id="v5" data-v="5" data-xref="创世记 2:21–24; 哥林多前书 7:4; 哥林多前书 7:2"> <span className="woj">并且说：</span><br /><span className="pl pl-1 woj">‘为这缘故，人将离开父母，</span><br /><span className="pl pl-1 woj">与妻子结合，</span><br /><span className="pl pl-1 woj">两个人就成为一体。’</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="希伯来书 13:4; 马可福音 10:9; 哥林多前书 7:10–14"> <span className="woj">这样，夫妻不再是两个人，而是一体了。因此，神所配合的，人不可分开。”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命记 24:1–4; 马太福音 5:31; 马可福音 10:4"> 他们问耶稣：“那么，为什么摩西吩咐说，给一份休书，就可以休妻呢？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="玛拉基书 2:13–14; 创世记 2:24; 马可福音 10:5"> 耶稣对他们说：<span className="woj">“摩西因着你们的心里刚硬，才准许你们休妻，但并不是从起初就这样的。</span></span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 5:32; 路加福音 16:18; 哥林多前书 7:39"> <span className="woj">我告诉你们：如果有人不是由于淫乱的缘故而休妻，另娶别人，就是犯通奸罪。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附“此外，凡是娶了被休的女人的，也是犯通奸罪。”">a</a></sup><span className="woj">”</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 7:32–35; 箴言 19:13–14; 箴言 21:19"> 他的门徒们对耶稣说：“如果丈夫与妻子的关系是这样，结婚就没有益处了。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 7:17; 哥林多前书 7:35; 哥林多前书 7:7–9"> 耶稣就对他们说：<span className="woj">“这话不是所有人都能接受的，只有谁被赐予了</span>，<span className="woj">谁才能接受：</span></span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 7:32–38; 哥林多前书 9:5; 以赛亚书 56:3–4"> <span className="woj">就是说，有些独身者</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="独身者——原文直译“阉人”。">b</a></sup><span className="woj">是生来</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="生来——原文直译“从母腹中生下来”。">c</a></sup><span className="woj">如此的；有些独身者是别人使他们成为独身的</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="成为独身的——原文直译“阉割”。">d</a></sup><span className="woj">；还有些独身者是为了天国的缘故自己成为独身的。谁能接受，就接受吧。”</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马可福音 10:13–16; 路加福音 18:15–17; 马太福音 18:2–5"> 那时，有一些小孩子被带到耶稣那里，好让耶稣按手在他们身上，给他们祷告。门徒们却责备那些人。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 18:3; 路加福音 18:16–17; 哥林多前书 14:20"> 耶稣就说：<span className="woj">“让小孩子到我这里来，不要阻止他们，因为天国正属于这样的人。”</span></span>
<span className="v" id="v15" data-v="15" data-xref="马可福音 10:16; 提摩太后书 3:15; 哥林多前书 7:14"> 于是，耶稣按手在他们身上，然后离开那地方。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马可福音 10:17–30; 约翰福音 3:15; 犹大书 1:21"> 看哪，有一个人上前来对耶稣说：“老师<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="老师——有古抄本作“良善的老师”。">e</a></sup>，我该做什么良善的事，才能得到永恒的生命呢？”</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="利未记 18:5; 路加福音 10:26–28; 加拉太书 3:11–13"> 耶稣对他说：<span className="woj">“你为什么问我有关良善的事呢？只有一位是良善的</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="你为什么问我有关良善的事呢？只有一位是良善的——有古抄本作“你为什么称我是良善的呢？除了神一位之外，没有一个是良善的”。">f</a></sup><span className="woj">。如果你想进入永生</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="永生——原文直译“生命”。">g</a></sup><span className="woj">，就应该遵守诫命。”</span></span>
<span className="v" id="v18" data-v="18" data-xref="申命记 5:16–21; 出埃及记 20:12–17; 马可福音 10:19"> 那个人就问：“哪些诫命呢？”<br />耶稣回答说：<br /><span className="pl pl-1 woj">“不可杀人、</span><br /><span className="pl pl-1 woj">不可通奸、</span><br /><span className="pl pl-1 woj">不可偷窃、</span><br /><span className="pl pl-1 woj">不可做伪证、</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="利未记 19:18; 出埃及记 20:12; 马太福音 22:39"> <span className="pl pl-1 woj">要孝敬父母、</span><br /><span className="pl pl-1 woj">要爱邻如己。”</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="加拉太书 3:24; 马可福音 10:20–21; 腓立比书 3:6"> 那年轻人对耶稣说：“这一切<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附“我从小”。">h</a></sup>我都遵守了，我还缺少什么呢？”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马可福音 10:21; 路加福音 18:22; 路加福音 12:33"> 耶稣对他说：<span className="woj">“如果你想要成为完全的，就当去卖掉你所拥有的，分给穷人，这样你将有财宝在天上；然后你来跟从我。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马太福音 6:24; 以西结书 33:31; 马太福音 13:22"> 那年轻人听了这话，就忧忧愁愁地走开了，因为他有很多财产。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="提摩太前书 6:9–10; 马太福音 13:22; 马可福音 10:23"> 耶稣对他的门徒们说：<span className="woj">“我确实地告诉你们：富有的人进入天国会很困难。</span></span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 5:44; 路加福音 18:25; 马可福音 10:24–25"> <span className="woj">我再告诉你们：骆驼穿过针眼，比富有的人进入神的国更容易呢！”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="罗马书 10:13; 马太福音 24:22; 罗马书 11:5–7"> 门徒们听了这话，极其惊讶，就说：“究竟谁能得救呢？”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="耶利米书 32:27; 路加福音 1:37; 约伯记 42:2"> 耶稣注视着他们，说：<span className="woj">“在人，这是不可能的；但是在神，凡事都可能。”</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="腓立比书 3:8; 路加福音 18:28; 路加福音 5:11"> 这时候，彼得对耶稣说：“看，我们舍弃一切跟从了你，我们将来究竟会怎么样呢？”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 22:28–30; 哥林多前书 6:2–3; 马太福音 25:31"> 耶稣对他们说：<span className="woj">“我确实地告诉你们：在新的世界里，当人子坐在他荣耀宝座上的时候，你们这些跟从我的人也要坐在十二个宝座上，审判以色列的十二个支派。</span></span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 18:29–30; 马可福音 10:29–30; 腓立比书 3:8"> <span className="woj">凡是为我名的缘故而舍弃房屋，或兄弟，或姐妹，或父亲，或母亲，</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附“或妻子，”。">i</a></sup><span className="woj">或儿女，或田产的人，都将得到百倍，并且继承永恒的生命。</span></span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 20:16; 路加福音 13:30; 马可福音 10:31"> <span className="woj">不过许多在前的，将要在后；许多在后的，将要在前。</span></span>
</div>
</div>

<span className="v" id="v1" data-v="1" data-xref="马可福音 16:1–8; 约翰福音 20:1–10; 马太福音 27:56"> 过了安息日，在一周的头一天<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一周的头一天——指“星期日”。">a</a></sup>，黎明的时候，茉大拉的玛丽亚和另一个玛丽亚来看坟墓。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 16:26; 约翰福音 20:12–13; 马可福音 16:3–5"> 忽然发生了强烈的地震，主的一位天使从天上降下来，上前把那石头<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附“从门口”。">b</a></sup>滚开，坐在上面。</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 9:3; 使徒行传 1:10; 马可福音 16:5"> 他的容貌像闪电，衣服洁白如雪。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 1:17; 但以理书 10:7; 马太福音 27:65–66"> 看守的卫兵们因怕天使就浑身发抖，变得像死人那样。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="启示录 1:17–18; 希伯来书 1:14; 以赛亚书 41:10"> 天使对妇女们说：“你们不要怕！我知道你们是在寻找被钉十字架的耶稣。</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 16:6; 马太福音 12:40; 路加福音 24:6–8"> 他不在这里，因为他已经复活<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="复活——原文直译“被复活”；指“神使耶稣复活”。">c</a></sup>了，正如他所说过的。你们来看安放他<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="他——有古抄本作“主”。">d</a></sup>的地方。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 26:32; 路加福音 24:22–24; 马太福音 28:10"> 赶快去告诉他的门徒们：‘他从死人中复活了。看哪，他要在你们之前到加利利去。在那里，你们将见到他。’看哪，我已经告诉你们了！”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="诗篇 2:11; 马可福音 16:8; 路加福音 24:36–41"> 她们立即离开墓穴，又惧怕，又大大欢喜，跑去告诉耶稣的门徒们。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 28:17; 约翰福音 20:14–17; 马太福音 14:33"> 这时候<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="这时候——有古抄本作“正当她们要去告诉门徒们的时候”。">e</a></sup>，忽然耶稣迎面而来，说：<span className="woj">“愿你们欢喜！”</span>她们就上前来抱住他的脚拜他。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 8:29; 约翰福音 20:17; 马太福音 28:7"> 耶稣对她们说：<span className="woj">“不要怕！去告诉我的弟兄们，要他们到加利利去。在那里，他们将见到我。”</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马太福音 27:65–66; 马太福音 28:4"> 她们离去的时候，正好有一些卫兵进了城，把所发生的事都报告给祭司长们。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 26:3–4; 使徒行传 4:5–22; 马太福音 27:1–2"> 祭司长们就与长老们一起聚集商议，给了士兵们许多银钱，</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 26:64"> 说：“你们要说：‘他的门徒们夜里来，趁我们睡着的时候，把他偷走了。’</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 27:2; 使徒行传 12:19"> 如果这事被总督听见了，我们会说服他，保证你们无事。”</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太前书 6:10; 马太福音 27:8; 马太福音 26:15"> 士兵们收了银钱，就照所指示的去做。于是这说法就流传在犹太人当中，直到今天。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马太福音 26:32; 马太福音 28:10; 马太福音 28:7"> 十一个门徒往加利利去，到了耶稣给他们指定的那座山上。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 45:11; 诗篇 2:12; 约翰福音 5:23"> 他们看见耶稣，就拜他，不过还有人疑惑。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 3:35; 彼得前书 3:22; 马太福音 11:27"> 耶稣前来，对他们说：<span className="woj">“天上和地上所有的权柄都赐给我了。</span></span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 16:15–16; 使徒行传 2:38–39; 使徒行传 1:8"> <span className="woj">所以你们要去，使万民成为我的门徒；奉父、子、圣灵的名给他们施洗</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="奉父、子、圣灵的名给他们施洗——或译作“给他们施洗归入父、子、圣灵的名”。">f</a></sup><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="施洗——或译作“施浸”。">g</a></sup><span className="woj">；</span></span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 41:10; 约书亚记 1:5; 使徒行传 18:9–10"> <span className="woj">凡我所吩咐你们的，都教导他们遵守。看哪，我就天天都与你们同在，直到这世代的终结。”</span></span>
</div>

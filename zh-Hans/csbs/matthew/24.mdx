<span className="v" id="v2" data-v="2" data-xref="路加福音 19:44; 耶利米书 26:18; 弥迦书 3:12"> 耶稣回应说：<span className="woj">“你们不是看见了这一切吗？我确实地告诉你们：这里将绝不会有一块石头留在另一块石头上而不被拆下。”</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马可福音 13:3–4; 使徒行传 1:7; 帖撒罗尼迦前书 5:1–11"> 耶稣在橄榄山上坐着，门徒们悄悄地前来问他：“请告诉我们，这些事什么时候会发生呢？你的来临和这世代的终结会有什么预兆呢？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰一书 4:1; 耶利米书 29:8; 帖撒罗尼迦后书 2:3"> 耶稣回答他们，说：<span className="woj">“你们要当心，免得有人迷惑你们。</span></span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 24:11; 马太福音 24:24; 耶利米书 14:14"> <span className="woj">因为许多人会以我的名而来，声称‘我是基督’，并且会迷惑许多人。</span></span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 13:7–8; 路加福音 21:9; 彼得前书 3:14–15"> <span className="woj">你们也将会听见战争和战争的消息。要注意，不可惊慌，因为这些事必须发生，不过结局还没有到。</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 21:11; 启示录 6:8; 以赛亚书 19:2"> <span className="woj">一个民族要起来反对另一个民族，一个国家要起来反对另一个国家；到处都会有饥荒</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附“瘟疫”。">a</a></sup><span className="woj">和地震。</span></span>
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦前书 5:3; 彼得前书 4:17–18; 申命记 28:59"> <span className="woj">这些都像临产阵痛的开始。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约翰福音 16:2; 约翰福音 15:19–20; 路加福音 21:16–17"> <span className="woj">“那时，他们将要出卖你们，使你们受患难，甚至杀害你们。为了我的名，你们将被万民憎恨。</span></span>
<span className="v" id="v10" data-v="10" data-xref="弥迦书 7:5–6; 路加福音 21:16; 马太福音 11:6"> <span className="woj">那时，许多人将被绊倒</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="被绊倒——或译作“放弃信仰”。">b</a></sup><span className="woj">，彼此出卖，彼此憎恨；</span></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 24:24; 马太福音 7:15; 马太福音 24:5"> <span className="woj">并且会有许多假先知起来，迷惑许多人；</span></span>
<span className="v" id="v12" data-v="12" data-xref="启示录 2:4–5; 雅各书 4:1–4; 启示录 3:15"> <span className="woj">由于罪恶</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="罪恶——原文直译“不法”。">c</a></sup><span className="woj">增多，许多人的爱心就会冷淡。</span></span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 10:22; 马可福音 13:13; 启示录 2:10"> <span className="woj">但是忍耐到底的，这个人将会得救。</span></span>
<span className="v" id="v14" data-v="14" data-xref="启示录 14:6; 罗马书 10:18; 罗马书 16:25–26"> <span className="woj">这天国的福音将被传遍天下，好对万国做见证，然后结局才会到来。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理书 9:27; 但以理书 12:11; 马可福音 13:14"> <span className="woj">“当你们看见藉着先知但以理所说的‘那带来毁灭的亵渎者</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="亵渎者——或译作“亵渎之物”。">d</a></sup><span className="woj">’</span><span className="woj">站在圣地的时候</span>——读者应当思考——</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 19:15–17; 路加福音 21:21–22; 希伯来书 11:7"> <span className="woj">那时，在犹太的人应当逃到山里；</span></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 17:31–33; 马可福音 13:15–16; 马太福音 10:27"> <span className="woj">在屋顶上的人，不要下来拿屋子里的东西；</span></span>
<span className="v" id="v18" data-v="18"> <span className="woj">在田里的人，不要返回去拿自己的衣服。</span></span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 23:29–30; 申命记 28:53–56; 路加福音 21:23"> <span className="woj">在那些日子里，孕妇和哺乳的女人有祸了！</span></span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 16:29; 使徒行传 1:12"> <span className="woj">你们要祷告，好让你们逃难的时候不在冬天，也不在安息日。</span></span>
<span className="v" id="v21" data-v="21" data-xref="但以理书 12:1; 约珥书 2:2; 玛拉基书 4:1"> <span className="woj">因为那时将有大患难。这样的患难从世界开始直到如今，从来没有发生过，也绝不再发生。</span></span>
<span className="v" id="v22" data-v="22" data-xref="马可福音 13:20; 提摩太后书 2:10; 马太福音 24:31"> <span className="woj">如果那些日子不被减少，就没有一个人</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="人——原文直译“肉体”。">e</a></sup><span className="woj">能得救。可是为了那些蒙拣选的人，那些日子将被减少。</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 21:8; 路加福音 17:23–24; 申命记 13:1–3"> <span className="woj">“那时候，如果有人对你们说‘看哪，基督在这里！’或‘他在那里！’你们不要相信。</span></span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦后书 2:9–11; 马可福音 13:22; 启示录 13:13–14"> <span className="woj">因为假基督们和假先知们会出现，行大神迹和奇事，如果有可能，甚至迷惑那些蒙拣选的人。</span></span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 16:1; 路加福音 21:13; 以赛亚书 48:5–6"> <span className="woj">看哪，我已经预先告诉你们了！</span></span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 3:2–3; 以赛亚书 40:3; 马太福音 3:1"> <span className="woj">所以，如果有人对你们说‘看哪，基督在旷野里！’你们不要出去；有人说：‘看哪，他在内室里！’你们也不要相信；</span></span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 17:24–37; 撒迦利亚书 9:14; 约伯记 37:3"> <span className="woj">因为就像闪电从东边发出，直照到西边，人子的来临也将要这样。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 17:37; 约伯记 39:27–30; 申命记 28:49"> <span className="woj">尸体在哪里，秃鹰就聚集在哪里。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="阿摩司书 8:9; 约珥书 3:15; 以赛亚书 13:10"> <span className="woj">“那些日子的患难一过去，</span><br /><span className="pl pl-1 woj">‘太阳就要变黑，</span><br /><span className="pl pl-1 woj">月亮也不发光，</span><br /><span className="pl pl-1 woj">星辰要从天上坠落，</span><br /><span className="pl pl-1 woj">诸天的各势力也将被震动。’</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="启示录 1:7; 但以理书 7:13; 路加福音 21:27"> <span className="woj">“那时候，人子的征兆将要显现在天上，地上的万族都要捶胸哀哭。他们将要看见人子带着极大的权能和荣耀，在天上的云彩中来临。</span></span>
<span className="v" id="v31" data-v="31" data-xref="帖撒罗尼迦前书 4:16; 马可福音 13:27; 以赛亚书 27:13"> <span className="woj">在嘹亮的号角声中，他要差派他的天使们从四方，从天这边到天那边，召集他所拣选的人。</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马可福音 13:28–29; 路加福音 21:29–30"> <span className="woj">“你们要从无花果树那里学个比喻：当无花果树的枝子发嫩长出叶子的时候，你们就知道夏天快到了。</span></span>
<span className="v" id="v33" data-v="33" data-xref="雅各书 5:9; 希伯来书 10:37; 以西结书 7:2–14"> <span className="woj">照样，当你们看见这一切的时候，你们就知道人子</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="人子——原文直译“他”或“它”；可指“人子”，也可指“那时刻”。">f</a></sup><span className="woj">快到了，就在门口了。</span></span>
<span className="v" id="v34" data-v="34" data-xref="马可福音 13:30–31; 路加福音 21:32–33; 马太福音 16:28"> <span className="woj">我确实地告诉你们：在这一切事发生之前，这世代绝不会过去。</span></span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 40:8; 彼得前书 1:25; 民数记 23:19"> <span className="woj">天和地将要消逝，但是我的话绝不会消逝。</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="马可福音 13:32; 使徒行传 1:7; 马太福音 24:44"> <span className="woj">“至于那日子和那时刻，没有人知道，连诸天之上的天使们也不知道，子也不知道，</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本没有“子也不知道，”。">g</a></sup><span className="woj">唯有父知道。</span></span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 17:26–27; 创世记 6:1–7; 彼得后书 2:5"> <span className="woj">挪亚的那些日子怎样，人子的来临也将要怎样。</span></span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 17:26–28; 罗马书 13:13–14; 路加福音 14:18–20"> <span className="woj">在洪水以前的那些日子里，人们继续吃、喝、嫁、娶，直到挪亚进方舟的那一天。</span></span>

<span className="v" id="v41" data-v="41" data-xref="出埃及记 11:5; 以赛亚书 47:2; 路加福音 17:35"> <span className="woj">两个女人在磨石那里推磨，一个被接去，一个被留下。</span></span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 21:36; 帖撒罗尼迦前书 5:6; 马太福音 25:13"> <span className="woj">所以你们要警醒，因为你们不知道你们的主哪一天</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="哪一天——有古抄本作“什么时候”。">h</a></sup><span className="woj">回来。</span></span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 12:39; 马太福音 24:44; 帖撒罗尼迦前书 5:2–6"> <span className="woj">不过你们应当知道这一点：一家的主人如果知道贼什么时刻</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="时刻——原文直译“更次”。">i</a></sup><span className="woj">来，他就会警醒，不让他的房子被人钻进。</span></span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 25:10; 马太福音 24:42; 马太福音 25:13"> <span className="woj">你们为了这缘故也应当做好准备，因为在你们意想不到的时候，人子就来了。</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="马太福音 25:21; 马太福音 25:23; 哥林多前书 4:1–2"> <span className="woj">“究竟谁是那又忠心又聪明的奴仆——受主人委任统管他家里的人、按时给他们分粮的人呢？</span></span>
<span className="v" id="v46" data-v="46" data-xref="启示录 16:15; 路加福音 12:43; 路加福音 12:37"> <span className="woj">主人回来的时候，看见哪个奴仆这样做，那个奴仆就蒙福了。</span></span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 25:23; 马太福音 25:21; 路加福音 12:37"> <span className="woj">我确实地告诉你们：主人会委任他统管自己所拥有的一切。</span></span>
<span className="v" id="v48" data-v="48" data-xref="马太福音 18:32; 以赛亚书 32:6; 路加福音 12:45"> <span className="woj">但如果这恶奴心里说‘我的主人会迟延回来</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本没有“回来”。">j</a></sup><span className="woj">’，</span></span>

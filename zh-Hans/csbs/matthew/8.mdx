<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="MAT" data-book-slug="matthew" data-book-name="马太福音" data-chapter="8" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 8:18; 马太福音 4:25–1; 路加福音 5:15"> 耶稣从山上下来，有一大群人跟随他。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 15:25; 路加福音 17:12–19; 马太福音 18:26"> 这时候，忽然有一个麻风病人前来拜他，说：“主啊，如果你愿意，你就能洁净我。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="路加福音 5:13; 诗篇 33:9; 列王纪下 5:14"> 耶稣伸出手来摸他，说：<span className="woj">“我愿意，你洁净了吧！”</span>那人的麻风病立刻就被洁净了。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 14:2–32; 路加福音 5:14; 路加福音 17:14"> 耶稣对他说：<span className="woj">“你要注意，不可告诉任何人，只要去把自己给祭司看，并且献上摩西所吩咐的祭物，好对他们做见证。”</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="路加福音 7:1–10; 使徒行传 27:43; 使徒行传 10:1–33"> 耶稣进了迦百农，有个百夫长前来恳求他，</span>
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 4:1; 马太福音 4:24; 使徒行传 9:33"> 说：“主啊，我的仆人瘫痪了，躺在家里，受剧烈的折磨。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 9:18–19; 路加福音 7:6; 马可福音 5:23–24"> 耶稣对他说：<span className="woj">“我去使他痊愈。”</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="诗篇 107:20; 路加福音 7:6–7; 诗篇 33:9"> 百夫长回答说：“主啊，我实在不配请你进我家。其实只要你说一句话，我的仆人就会痊愈的。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 4:35–36; 提多书 2:9; 歌罗西书 3:22"> 事实上，我也在人的权下，也有士兵在我之下。我对这个说‘去’，他就去；对那个说‘来’，他就来；对我的奴仆说‘做这事’，他就去做。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 15:28; 路加福音 7:9; 马可福音 6:6"> 耶稣听了，十分感慨，对跟随他的人说：<span className="woj">“我确实地告诉你们：在以色列我没有见过有这么大信心</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="信心——指“对耶稣的信心”。">a</a></sup><span className="woj">的人。</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 13:28–29; 以弗所书 3:6; 加拉太书 3:28–29"> <span className="woj">我告诉你们：将有许多人从东从西而来，在天国里与亚伯拉罕、以撒、雅各一同坐席。</span></span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 25:30; 路加福音 13:28; 马太福音 21:43"> <span className="woj">但那些‘天国的儿女’，却将被丢在外面的黑暗里。在那里将有哀哭和切齿。”</span></span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 9:29–30; 马可福音 9:23; 约翰福音 4:50"> 于是耶稣对那百夫长说：<span className="woj">“回去吧，照着你所信的，给你成全吧！”</span>他的仆人就在那一刻痊愈了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="路加福音 4:38–41; 马可福音 1:29–34; 哥林多前书 9:5"> 耶稣来到彼得家，看见彼得的岳母正发烧躺着。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 13:21; 路加福音 4:38–39; 路加福音 8:54"> 耶稣一摸她的手，烧就退了。于是她就起来服事耶稣。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 15:26; 马太福音 14:14; 马可福音 1:32–34"> 到了傍晚，人们把许多有鬼魔附身的人带到耶稣那里。耶稣话语一出就把那些邪灵都赶了出去，并且使所有患病的人痊愈了。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 53:4; 彼得前书 2:24; 马太福音 1:22"> 这样，那藉着先知以赛亚所说的话就应验了：<br /><span className="pl pl-1">“他亲自代替了我们的软弱，</span><br /><span className="pl pl-1">担当了我们的疾病。”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 4:42–43; 路加福音 8:22; 马可福音 4:35"> 耶稣看见一群人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一群人——有古抄本作“一大群人”。">b</a></sup>围着他，就吩咐渡到对岸去。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 22:33–34; 约翰福音 13:36–38; 路加福音 14:25–27"> 有一个经文士前来对他说：“老师，无论你到哪里去，我都要跟从你。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="诗篇 84:3; 路加福音 2:7; 以赛亚书 53:2–3"> 耶稣对他说：<span className="woj">“狐狸有洞，天空的飞鸟有窝，人子却没有枕头的地方。”</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 9:59–62; 利未记 21:11–12; 民数记 6:6–7"> 耶稣的另一个门徒对他说：“主啊，请准许我先去埋葬我的父亲。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 2:13; 路加福音 15:32; 以弗所书 5:14"> 但是耶稣对他说：<span className="woj">“你跟从我，让死人去埋葬他们的死人吧。”</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 8:22–25; 马可福音 4:36–41; 马太福音 9:1"> 耶稣上了船，他的门徒们跟着他。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 8:23; 诗篇 107:23–27; 马可福音 4:37–38"> 这时候，忽然湖<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="湖——原文直译“海”；指“加利利湖（海）”。">c</a></sup>上起了大风暴，以致波浪盖过了船，耶稣却睡着了。</span>
<span className="v" id="v25" data-v="25" data-xref="约拿书 1:6; 历代志下 14:11; 马可福音 4:38–39"> 门徒们上前来叫醒他，说：“主啊，救救我们，我们没命了！”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 41:10–14; 诗篇 65:7; 诗篇 107:28–30"> 耶稣对他们说：<span className="woj">“为什么胆怯呢？你们这些小信的人哪！”</span>耶稣就起来，斥责风和浪<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="浪——或译作“湖”；原文直译“海”。">d</a></sup>，湖面就变得一片平静。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马可福音 7:37; 马可福音 6:51; 马太福音 14:33"> 他们都感到惊奇，说：“这个人究竟是什么人？连风和浪<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="浪——或译作“湖”；原文直译“海”。">e</a></sup>也听从他！”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 8:26–39; 马可福音 5:1–20; 使徒行传 10:38"> 耶稣来到对岸格达拉<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="格达拉——有古抄本作“格拉森”。">f</a></sup>人的地方，两个有鬼魔附身的人，从墓地迎着他出来。他们非常凶猛，以致没有人能从那条路经过。</span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 1:24; 路加福音 4:34; 雅各书 2:19"> 忽然，他们喊叫说：“神的儿子<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附“耶稣”。">g</a></sup>啊，我们与你有什么关系？时候来到之前，你就来这里折磨我们吗？”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="申命记 14:8; 利未记 11:7; 马可福音 5:11"> 当时，离他们很远的地方，有一大群猪正在吃食。</span>
<span className="v" id="v31" data-v="31" data-xref="启示录 20:1–2; 路加福音 8:30–33; 马可福音 5:12"> 那些鬼魔就央求耶稣，说：“如果你要把我们赶出去，就叫我们进入这群猪里面去吧。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马可福音 5:13; 使徒行传 2:23; 启示录 20:7"> 耶稣对它们说：<span className="woj">“去吧！”</span>它们就出来，进入猪<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附“群”。">h</a></sup>里面去了。忽然，那整群猪<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本没有“猪”。">i</a></sup>从山崖冲到湖里，在水里淹<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="淹——辅助词语。">j</a></sup>死了。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 8:34–36; 马可福音 5:14–16; 使徒行传 19:15–17"> 那些放猪的人就逃跑，进城去传报了这一切事，包括鬼魔附身之人的事。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 16:39; 路加福音 8:37–39; 路加福音 5:8"> 看哪，全城的人都出来看耶稣，见了耶稣以后，就央求他离开他们的地区。</span>
</div>
</div>

</div>
<div className="bp">

<span className="v" id="v7" data-v="7" data-xref="使徒行传 28:31; 马太福音 3:2; 路加福音 9:60"> <span className="woj">你们去的时候，要传讲说‘天国近了。’</span></span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 3:6; 路加福音 10:9; 使徒行传 4:30"> <span className="woj">要使病人痊愈，使死人复活，使麻风病人洁净，把鬼魔赶出去。你们无偿地得来，也要无偿地给与。</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 22:35; 路加福音 9:3–5; 路加福音 10:4–12"> <span className="woj">腰包里不要带金银或铜钱。</span></span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 10:7–12; 提摩太前书 5:17–18; 哥林多前书 9:4–14"> <span className="woj">在路上不要带行囊，不要带两件衣服</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="衣服——或译作“衬袍”。">c</a></sup><span className="woj">，也不要带鞋子和手杖，因为工人配得自己的食物。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路加福音 10:7–8; 约伯记 31:32; 士师记 19:16–21"> <span className="woj">“你们无论进哪个城镇或乡村，要查问其中配得的人，就住在他那里，直到你们离去。</span></span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 25:6; 路加福音 10:5–6; 使徒行传 10:36"> <span className="woj">你们进了他家，要祝那家平安。</span></span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 10:6; 诗篇 35:13; 哥林多后书 2:16"> <span className="woj">如果那一家是配得的，你们的平安就临到那一家；如果那家是不配得的，你们的平安就归回你们。</span></span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 10:10–11; 使徒行传 18:6; 尼希米记 5:13"> <span className="woj">如果有人不接受你们，也不听你们的话语，你们离开那家那城的时候，要把脚上的尘土跺掉。</span></span>
<span className="v" id="v15" data-v="15" data-xref="彼得后书 2:6; 约翰一书 4:17; 约翰福音 15:22–24"> <span className="woj">我确实地告诉你们：在那审判的日子，所多玛和格摩拉之地所受的，将要比那城还容易受呢！</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 10:3; 腓立比书 2:15; 哥林多前书 14:20"> <span className="woj">“看哪，我差派你们出去，就像把羊送进狼群中，所以你们要像蛇那样聪明，像鸽子那样纯洁。</span></span>
<span className="v" id="v17" data-v="17" data-xref="马可福音 13:9; 马太福音 23:34; 使徒行传 26:11"> <span className="woj">你们要提防人们，因为他们将要把你们送交议会，并且在他们的会堂里鞭打你们。</span></span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 5:25–27; 马太福音 8:4; 诗篇 2:1–6"> <span className="woj">为我的缘故，你们将被带到总督和君王面前，好对他们和外邦人做见证。</span></span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 4:12; 马可福音 13:11–13; 提摩太后书 4:17"> <span className="woj">当他们把你们交出去的时候，不要忧虑怎样说或说什么。到时候，你们就会被赐予该说的话，</span></span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 21:15; 使徒行传 6:10; 路加福音 12:12"> <span className="woj">因为说话的不是你们自己，而是你们父的灵在你们里面说话。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 21:16–17; 弥迦书 7:5–6; 马可福音 13:12–13"> <span className="woj">“兄弟将要把兄弟出卖，置于死地；父亲对孩子也会这样。儿女会起来与父母作对，并且害死他们。</span></span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 24:13; 雅各书 1:12; 启示录 2:10"> <span className="woj">为了我的名，你们将被所有的人憎恨，但是忍耐到底的，这个人将会得救。</span></span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 16:28; 使徒行传 8:1; 马可福音 13:26"> <span className="woj">他们在这城逼迫你们，你们就逃到别的城去。我确实地告诉你们：在你们走遍以色列的城镇之前，人子必定来临。</span></span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 15:20; 路加福音 6:40; 约翰福音 13:16"> <span className="woj">学生不高于他的老师，奴仆也不高于他的主人。</span></span>

</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 8:17; 马可福音 4:22; 耶利米书 1:8"> <span className="woj">“所以不要怕他们，因为被遮盖的事没有将不被显露出来的，隐秘的事也没有将不被知道的。</span></span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 5:20; 约翰福音 16:13; 约翰福音 16:1"> <span className="woj">我在暗中告诉你们的，你们要在明处说出来；你们在耳边听到的，要在屋顶上宣扬出去。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 12:4–5; 以赛亚书 8:12–13; 启示录 2:10"> <span className="woj">你们不要怕那些能杀死身体却不能杀死灵魂的；反而倒要惧怕那位能把灵魂和身体都毁灭在地狱里的。</span></span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 12:6–7; 诗篇 104:27–30"> <span className="woj">两只麻雀不是卖一个小钱</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="小钱——原文为“阿撒利”。1阿撒利=约1/16日工资的罗马铜币。">d</a></sup><span className="woj">吗？但如果没有你们父的允许</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="允许——辅助词语。">e</a></sup><span className="woj">，一只也不会掉在地上。</span></span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 12:7; 撒母耳记上 14:45; 使徒行传 27:34"> <span className="woj">至于你们，就是每一根头发也都被数过了。</span></span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 12:24; 诗篇 8:5; 马太福音 6:26"> <span className="woj">所以不要怕！你们比一大群麻雀还重要。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="启示录 3:5; 罗马书 10:9–10; 路加福音 12:8–9"> <span className="woj">“凡是在人面前承认我的，我在我天上的父面前也将承认他；</span></span>
<span className="v" id="v33" data-v="33" data-xref="提摩太后书 2:12; 路加福音 9:26; 路加福音 12:9"> <span className="woj">但无论谁在人面前不认我，我在我天上的父面前也将不认他。</span></span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 12:49–53; 使徒行传 14:4; 使徒行传 13:45–50"> <span className="woj">不要以为我来了，是给地上带来和平。我来并不是带来和平，而是刀剑，</span></span>
<span className="v" id="v35" data-v="35" data-xref="弥迦书 7:5–6; 马太福音 10:21; 路加福音 21:16"> <span className="woj">因为我来就是为了：</span><br /><span className="pl pl-1 woj">使‘人与父亲对立，</span><br /><span className="pl pl-1 woj">女儿与母亲对立，</span><br /><span className="pl pl-1 woj">媳妇与婆婆对立，</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="弥迦书 7:6; 耶利米书 12:6; 诗篇 41:9"> <span className="pl pl-1 woj">这样，一个人的敌人</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="敌人——或译作“反对者”。">f</a></sup><br /><span className="pl pl-1 woj">，</span><br /><span className="pl pl-1 woj">就是自己家里的人。’</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 14:26; 马太福音 22:37; 腓立比书 3:7–9"> <span className="woj">“那爱父亲或母亲过于爱我的，不配属于我；那爱儿子或女儿过于爱我的，不配属于我；</span></span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 14:27; 马可福音 8:34; 马太福音 16:24"> <span className="woj">不背起自己的十字架来跟从我的，也不配属于我。</span></span>

<span className="v" id="v2" data-v="2" data-xref="雅各书 2:13; 马可福音 4:24; 路加福音 6:38"> <span className="woj">因为，你们用什么标准来评断，也会同样地被评断；你们用什么量器</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="量器——或译作“尺度”或“标准”。">a</a></sup><span className="woj">来衡量，也会同样地被衡量。</span></span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 8:7–9; 加拉太书 6:1; 路加福音 6:41–42"> <span className="woj">你为什么看见你弟兄眼里的木屑，却不想自己眼里的梁木呢？</span></span>
<span className="v" id="v4" data-v="4"> <span className="woj">又怎么能对你弟兄说‘让我除掉你眼里的木屑’呢？看哪，你自己眼里还有梁木呢！</span></span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 6:42; 诗篇 51:9–13; 马太福音 23:13–28"> <span className="woj">你这伪善的人！先除掉你自己眼里的梁木，然后你才能看得清楚，好除掉你弟兄眼里的木屑。</span></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 9:7–8; 箴言 23:9; 马太福音 10:14–15"> <span className="woj">不要把神圣之物丢给狗，也不要把你们的珍珠丢在猪面前，免得它们用脚把这些践踏了，然后转身撕咬你们。</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 21:22; 约翰一书 3:22; 约翰福音 15:7"> <span className="woj">“不断祈求吧，就会给你们；不断寻找吧，就会找到；不断敲门吧，就会为你们开门。</span></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 81:10; 诗篇 81:16; 路加福音 23:42–43"> <span className="woj">因为凡祈求的，就得到；寻找的，就找到；敲门的，就为他开门。</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 11:11–13"> <span className="woj">你们当中有哪个人，儿子要饼，却给他石头呢？</span></span>
<span className="v" id="v10" data-v="10"> <span className="woj">儿子要鱼，却给他蛇呢？</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 11:11–13; 雅各书 1:17; 罗马书 8:32"> <span className="woj">所以，如果你们做为恶人也知道把好的东西给自己的儿女，更何况你们在天上的父要把美好的赐给求他的人呢！</span></span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 6:31; 罗马书 13:8–10; 加拉太书 5:13–14"> <span className="woj">因此在任何事上，你们希望别人怎样对待你们，你们也应当怎样对待别人。要知道，这就是律法和先知</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="先知——或译作“先知书”。">b</a></sup><span className="woj">的教导</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="的教导——辅助词语。">c</a></sup><span className="woj">。</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 13:24–25; 箴言 16:25; 约翰福音 14:6"> <span className="woj">“你们要从窄门进去；因为那通向灭亡</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="灭亡——或译作“沉沦”。">d</a></sup><span className="woj">的门是大的，那条路是宽的，从那里进去的人也多；</span></span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 13:23–30; 马太福音 22:14; 马太福音 16:24–25"> <span className="woj">然而，那通向永生</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="永生——原文直译“生命”。">e</a></sup><span className="woj">的门是多么小，路是多么窄，找到它的人是多么少。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰一书 4:1; 彼得后书 2:1–3; 马太福音 24:11"> <span className="woj">“你们要提防假先知。他们披着羊皮来到你们这里，里面却是凶残的狼。</span></span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 6:43–45; 马太福音 12:33; 雅各书 3:12"> <span className="woj">凭着他们的果子，你们就能认出他们来。难道从荆棘上能收葡萄，从蒺藜中能收无花果吗？</span></span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 12:33–35; 加拉太书 5:22–24; 以弗所书 5:9"> <span className="woj">同样，好树都结好果子，坏树就结坏果子；</span></span>
<span className="v" id="v18" data-v="18" data-xref="加拉太书 5:17; 约翰一书 3:9–10"> <span className="woj">好树不能结坏果子，坏树也不能结好果子。</span></span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 3:10; 希伯来书 6:8; 约翰福音 15:2–6"> <span className="woj">所有不结好果子的树都要被砍下来，被丢进火里。</span></span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 7:16; 使徒行传 5:38"> <span className="woj">因此凭着他们的果子，你们就能认出他们来。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="罗马书 2:13; 路加福音 6:46; 雅各书 1:22"> <span className="woj">“不是每一个称呼我‘主啊，主啊’的人，都能进入天国；只有遵行我天父旨意的人，才能进去。</span></span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 13:25–27; 哥林多前书 13:1–2; 玛拉基书 3:17–18"> <span className="woj">在那一天，有许多人会对我说：‘主啊，主啊，我们不是奉你的名做先知传道</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="做先知传道——原文直译“说预言”。">f</a></sup><span className="woj">，奉你的名驱赶鬼魔，奉你的名行了很多神迹吗？’</span></span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 25:41; 诗篇 6:8; 路加福音 13:25"> <span className="woj">那时候，我要向他们宣告：‘我从来不认识你们。离开我，你们这些作恶</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="恶——原文直译“不法”。">g</a></sup><span className="woj">的人！’</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 6:47–49; 约翰福音 13:17; 哥林多前书 3:10–11"> <span className="woj">“因此，凡是听了我这些话而实行的人，就好比一个聪明的人把自己的房子建在磐石上。</span></span>
<span className="v" id="v25" data-v="25" data-xref="雅各书 1:12; 诗篇 125:1–2; 彼得前书 1:7"> <span className="woj">大雨降下，急流冲来，狂风刮起，撞击那房子，房子却没有倒塌，因为它在磐石上立定根基。</span></span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 8:9; 路加福音 6:49; 雅各书 2:20"> <span className="woj">可是，凡是听了我这些话而不实行的人，就好比一个愚拙的人把自己的房子建在沙滩上。</span></span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 13:19–22; 彼得后书 2:20–22; 哥林多前书 3:13"> <span className="woj">大雨降下，急流冲来，狂风刮起，撞击那房子，房子就倒塌了，并且倒塌得非常厉害。”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 4:32; 马可福音 1:22; 约翰福音 7:46"> 当耶稣讲完了这些话，众人都对他的教导惊叹不已，</span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 4:12–13; 路加福音 20:8; 申命记 18:18–19"> 因为耶稣教导他们，就像有权柄的人，不像他们的经文士们。</span>
</div>

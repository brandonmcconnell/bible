<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 4:13; 路加福音 8:37; 马太福音 8:18"> 耶稣上了船，渡过去，来到自己的城里。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 2:1–12; 路加福音 5:18–26; 耶利米书 31:33–34"> 这时候，有几个人把一个躺在床榻上瘫痪的人抬到他面前。耶稣看见他们的信心，就对瘫痪的人说：<span className="woj">“孩子，鼓起勇气吧！你的罪孽被赦免了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马太福音 26:65; 路加福音 5:21; 利未记 24:16"> 但这时候，有些经文士心里说：“这个人说亵渎的话！”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="路加福音 6:8; 马太福音 12:25; 启示录 2:23"> 耶稣知道他们的想法，就说：<span className="woj">“你们心里为什么怀着恶念呢？</span></span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 5:8–14; 马可福音 2:9–12; 使徒行传 3:16"> <span className="woj">或说‘你的罪孽被赦免了’，或说‘你起来走路’，到底哪一样更容易呢？</span></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 43:25; 马太福音 9:5; 约翰福音 20:21–23"> <span className="woj">不过为要使你们知道人子在地上有赦免罪的权柄——”</span>于是他对瘫痪的人说：<span className="woj">“起来，拿起你的床榻，回家去吧！”</span></span>
<span className="v" id="v7" data-v="7"> 那个人就起来，回家去了。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 7:16; 马太福音 15:31; 使徒行传 4:21"> 众人看见就起了敬畏之心<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="起了敬畏之心——有古抄本作“十分惊奇”。">a</a></sup>，就荣耀神，因为他赐给人这样的权柄。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 5:27–38; 马可福音 2:14–22; 路加福音 19:2–10"> 耶稣从那里往前走，看见一个叫马太的人在税关坐着。耶稣对他说：<span className="woj">“你跟从我！”</span>马太就站起来，跟从了耶稣。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 1:13–16; 路加福音 5:29–32; 马可福音 2:15–17"> 耶稣在屋子里坐席，这时候来了许多税吏和罪人，与耶稣和他的门徒们一同坐席。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 11:19; 路加福音 5:30; 马可福音 2:16"> 有些法利赛人看见了，就对耶稣的门徒们说：“你们的老师为什么与那些税吏和罪人一起吃饭呢？”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="路加福音 5:31; 启示录 3:17–18; 马可福音 2:17"> 耶稣听见了就说：<span className="woj">“健康的人不需要医生，有病的人才需要。</span></span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 2:17; 路加福音 19:10; 何西阿书 6:6"> <span className="woj">你们去学‘我要的是怜悯，而不是祭祀’这话是什么意思吧！我来不是要召唤义人，而是要召唤罪人</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附“来悔改”。">b</a></sup><span className="woj">。”</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 5:33–39; 马可福音 2:18–22; 马太福音 6:16"> 随后，约翰的门徒们前来问耶稣：“为什么我们和法利赛人经常<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本没有“经常”。">c</a></sup>禁食，而你的门徒们却不禁食呢？”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="启示录 19:9; 约翰福音 3:29; 启示录 21:2"> 耶稣对他们说：<span className="woj">“新郎与宾客</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="宾客——或译作“伴郎”；原文直译“新房之子”。">d</a></sup><span className="woj">在一起的时候，难道宾客能悲伤吗？可是日子将要来到：当新郎从他们中间被带走的时候，他们那时就要禁食了。</span></span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 3:1–2; 约翰福音 16:12; 诗篇 125:3"> <span className="woj">没有人把没缩过水的布块补在旧衣服上，因为所补上的布块会扯坏衣服，造成更大的裂口。</span></span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 9:4; 约伯记 32:19; 诗篇 119:83"> <span className="woj">也没有人把新酒装在旧皮袋里，否则皮袋会胀破，酒会流出来，皮袋也被糟蹋了；相反，他们是把新酒装在新皮袋里，这样两者都保全了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 8:41–56; 马可福音 5:22–43; 马太福音 8:2"> 耶稣正对他们讲这些事的时候，忽然有一个会堂<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="会堂——辅助词语。">e</a></sup>主管来拜他，说：“我的女儿刚才死了，求你来按手在她身上，她就会活了。”</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 10:38; 加拉太书 6:9–10; 马太福音 8:7"> 于是耶稣起身跟着他去，他的门徒们也跟着去了。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 8:43–56; 马太福音 14:36; 马可福音 6:56"> 这时候，忽然有一个患血漏十二年的女人，从耶稣后面过来，摸了一下耶稣的衣服穗子，</span>
<span className="v" id="v21" data-v="21" data-xref="马可福音 5:26–33; 路加福音 8:45–47; 使徒行传 19:12"> 原来她心里想：“只要我摸到他的衣服，就会得救治。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 7:50; 马太福音 15:28; 马太福音 9:2"> 耶稣转过身来看着她，说：<span className="woj">“女儿，鼓起勇气吧！你的信救了你。”</span>从那一刻起，那个女人就得了救治。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="历代志下 35:25; 马可福音 5:35–40; 路加福音 8:49–51"> 耶稣来到那会堂<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="会堂——辅助词语。">f</a></sup>主管的家，看见吹笛的人和慌乱的人群，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 20:10; 约翰福音 11:11–13; 马太福音 27:39–43"> 就说：<span className="woj">“你们退去吧！这女孩不是死了，而是睡了。”</span>他们就讥笑他。</span>
<span className="v" id="v25" data-v="25" data-xref="马可福音 9:27; 马可福音 5:41; 路加福音 8:54"> 那群人被赶出去以后，耶稣进去，握着女孩的手，那女孩就起来了。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 4:24; 马太福音 14:1–2; 马可福音 1:45"> 于是，这消息传遍了那整个地区。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马太福音 15:22; 马太福音 20:30–31; 马可福音 10:46–48"> 耶稣从那里往前走，有两个瞎眼的跟着他，呼叫说：“大卫的后裔，可怜我们吧！”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马可福音 9:23–24; 马太福音 13:58; 马太福音 8:2"> 耶稣进了屋子，那两个瞎眼的来到他面前。耶稣问他们：<span className="woj">“你们相信我能做这件事吗？”</span><br />他们回答说：“主啊，是的，我们信<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="我们信——辅助词语。">g</a></sup>。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马太福音 15:28; 马可福音 10:52; 马太福音 8:13"> 于是耶稣摸他们的眼睛，说：<span className="woj">“照着你们所信的，给你们成全吧。”</span></span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 8:4; 路加福音 5:14; 马太福音 17:9"> 他们的眼睛就开了。耶稣严厉地告诫他们：<span className="woj">“你们要注意，不可让任何人知道。”</span></span>
<span className="v" id="v31" data-v="31" data-xref="马可福音 7:36; 马太福音 9:26; 马可福音 1:44–45"> 但他们一出去，就把耶稣的消息传遍了那整个地区。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马太福音 4:24; 马太福音 12:22–24; 路加福音 11:14"> 两个人离去了。这时候有几个人把一个有鬼魔附身的哑巴带到耶稣那里。</span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 35:6; 马可福音 7:32–37; 出埃及记 4:11–12"> 鬼魔一被赶出去，哑巴就说出话来。众人都感到惊奇，他们说：“这样的事，在以色列从来没有见过。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="路加福音 11:15; 马可福音 3:22; 马太福音 12:23–24"> 但法利赛人却说：“他是靠鬼魔的王驱赶鬼魔的。”<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本没有此节。">h</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 4:23–24; 使徒行传 10:38; 马可福音 6:56"> 耶稣走遍各个城镇乡村，在他们的会堂里教导人，传天国的福音，并且使<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附“民中”。">i</a></sup>各样的疾病和各样的症状痊愈。</span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 6:34; 民数记 27:17; 耶利米书 50:6"> 耶稣看见众人，就对他们动了怜悯之心，因为他们困苦流离，像羊没有牧人那样。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 10:2; 马可福音 16:15; 哥林多前书 3:9"> 于是他对自己的门徒们说：<span className="woj">“收割的工作</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="收割的工作——或译作“庄稼”。">j</a></sup><span className="woj">多，而工人少。</span></span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 10:1–2; 耶利米书 3:15; 帖撒罗尼迦后书 3:1"> <span className="woj">所以你们要祈求收割</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="收割——或译作“庄稼”。">k</a></sup><span className="woj">的主催促工人参与他的收割工作</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="参与他的收割工作——或译作“收他的庄稼”。">l</a></sup><span className="woj">。”</span></span>
</div>
</div>

<span className="v" id="v1" data-v="1" data-xref="路加福音 12:1; 路加福音 20:45–46; 马太福音 15:10–20"> 那时，耶稣对众人和自己的门徒们说：</span>

<span className="v" id="v3" data-v="3" data-xref="提摩太后书 3:5; 提多书 1:16; 罗马书 2:19–24"> <span className="woj">所以，他们所吩咐你们的，你们都要去做，也要遵守；但是不要效法他们的行为，因为他们说而不做。</span></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 11:46; 使徒行传 15:10; 加拉太书 6:13"> <span className="woj">他们把沉重难挑的</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本没有“难挑的”。">a</a></sup><span className="woj">担子捆起来，放在人们肩上，但自己却连一根指头也不肯动它们一下。</span></span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 6:1–16; 约翰福音 12:43; 腓立比书 2:3"> <span className="woj">他们所做的一切事，都是为了给人看：他们把自己的经文盒加宽，把衣服的</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本没有“衣服的”。">b</a></sup><span className="woj">穗子加长；</span></span>
<span className="v" id="v6" data-v="6" data-xref="约翰三书 1:9; 路加福音 11:43–54; 马可福音 12:38–39"> <span className="woj">他们喜爱宴席中的上座和会堂里的首位，</span></span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 1:38; 约翰福音 1:49; 约翰福音 3:26"> <span className="woj">喜爱街市上的致敬问候，又喜爱被人们称为‘老师</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="老师——或译作“拉比”。">c</a></sup><span className="woj">’。</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="雅各书 3:1; 哥林多前书 1:12–13; 彼得前书 5:3"> <span className="woj">“但你们不可被称为‘老师</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="老师——或译作“拉比”。">d</a></sup><span className="woj">’，因为你们的老师只有一位，</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附“就是基督，”。">e</a></sup><span className="woj">而你们都是弟兄。</span></span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 3:1; 希伯来书 12:9; 玛拉基书 1:6"> <span className="woj">不要称地上的任何人为‘父’，因为你们的父只有一位，就是天父。</span></span>
<span className="v" id="v10" data-v="10"> <span className="woj">你们也不要被人称为‘主人’，因为你们的主人只有一位，就是基督。</span></span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 9:19; 加拉太书 5:13; 约翰福音 13:14–15"> <span className="woj">你们当中谁更大，谁就该做你们的仆人，</span></span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 5:5; 雅各书 4:6; 箴言 29:23"> <span className="woj">因为凡是自我高举的都会被降卑，而自我降卑的都会被高举。</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 11:52; 马太福音 23:29; 马太福音 23:23"> <span className="woj">“经文士和法利赛人哪，你们这些伪善的人有祸了！因为你们在人的面前封闭了天国。你们自己不进去，也不让正要进的人进去。</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> <span className="woj">“经文士和法利赛人哪，你们这些伪善的人有祸了！因为你们侵吞寡妇的家产，又假意做很长的祷告。因此，你们将受到更重的惩罚。</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本没有此节。">f</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以弗所书 2:3; 使徒行传 13:10; 使徒行传 13:43"> <span className="woj">“经文士和法利赛人哪，你们这些伪善的人有祸了！因为你们为了使一个人入教，走遍海洋和陆地，一旦那人成了教徒</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="教徒——辅助词语。">g</a></sup><span className="woj">，你们就使他成为比你们加倍坏的地狱之子。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马太福音 15:14; 马太福音 5:33–35; 雅各书 5:12"> <span className="woj">“你们这些瞎眼的领路人有祸了！你们说：‘如果有人指着圣所起誓，算不得什么；但如果有人指着圣所里的金子起誓，就必须遵守。’</span></span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 23:19; 民数记 16:38–39; 诗篇 94:8"> <span className="woj">你们这些又愚拙又瞎眼的人哪，到底哪一样更重要呢？是金子，还是使金子成圣的圣所呢？</span></span>
<span className="v" id="v18" data-v="18"> <span className="woj">你们还说：‘如果有人指着祭坛起誓，算不得什么；但如果有人指着祭坛上的祭物起誓，就必须遵守。’</span></span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 29:37; 出埃及记 30:29"> <span className="woj">你们这些</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本附“愚拙又”。">h</a></sup><span className="woj">瞎眼的人哪，到底哪一样更重要呢？是祭物，还是使祭物成圣的祭坛呢？</span></span>
<span className="v" id="v20" data-v="20"> <span className="woj">所以，指着祭坛起誓的，就是指着祭坛和祭坛上的一切起誓；</span></span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 26:8; 列王纪上 8:13; 历代志下 6:2"> <span className="woj">指着圣所起誓的，就是指着圣所和住在里面的那一位起誓；</span></span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 5:34; 诗篇 11:4; 以赛亚书 66:1"> <span className="woj">指着天起誓的，就是指着神的宝座和坐在宝座上的那一位起誓。</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 11:42; 弥迦书 6:8; 何西阿书 6:6"> <span className="woj">“经文士和法利赛人哪，你们这些伪善的人有祸了！因为你们奉献薄荷、莳萝、香芹的十分之一，却放弃了律法上更重要的：就是公义、怜悯、信实。这些才是你们应该做的，至于前者也不可放弃。</span></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 19:24; 马太福音 27:6–8; 马太福音 15:2–6"> <span className="woj">你们这些瞎眼的领路人哪，你们滤掉蠓虫，却吞下骆驼！</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 11:39–40; 马太福音 15:19–20; 马可福音 7:4–13"> <span className="woj">“经文士和法利赛人哪，你们这些伪善的人有祸了！因为你们洗净杯子、盘子的外面，里面却盛满了贪心和放纵。</span></span>
<span className="v" id="v26" data-v="26" data-xref="哥林多后书 7:1; 雅各书 4:8; 希伯来书 10:22"> <span className="woj">你这瞎眼的法利赛人哪！当先洗净杯子</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附“盘子”。">i</a></sup><span className="woj">的里面，好使外面也洁净。</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 11:44; 使徒行传 23:3; 民数记 19:16"> <span className="woj">“经文士和法利赛人哪，你们这些伪善的人有祸了！因为你们好像粉饰的坟墓，外面固然显得美丽，里面却装满了死人骨头和一切污秽。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 16:15; 诗篇 51:6; 马太福音 23:5"> <span className="woj">你们也是这样，你们外面对人显出公义，里面却充满了伪善和罪恶</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="罪恶——原文直译“不法”。">j</a></sup><span className="woj">。</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 11:47–48; 使徒行传 2:29"> <span className="woj">“经文士和法利赛人哪，你们这些伪善的人有祸了！因为你们建造先知的坟墓，装饰义人的墓碑，</span></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 2:30; 马太福音 23:34–35; 马太福音 21:35–36"> <span className="woj">说：‘如果我们活在我们祖先的时代，我们就不会与他们合伙流先知们的血。’</span></span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 7:51–52; 帖撒罗尼迦前书 2:15–16; 约书亚记 24:22"> <span className="woj">这样，你们就见证了自己是杀害先知们的那些人的后代。</span></span>
<span className="v" id="v32" data-v="32" data-xref="创世记 15:16; 民数记 32:14; 帖撒罗尼迦前书 2:16"> <span className="woj">你们去充满你们祖先的恶贯吧！</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 3:7; 马太福音 12:34; 马太福音 5:22"> <span className="woj">“你们这些蛇类，这些毒蛇的子孙！你们怎么能逃避地狱的惩罚呢？</span></span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 10:16–17; 马太福音 13:52; 歌罗西书 1:28"> <span className="woj">看，我为此差派先知、智者、经师到你们这里来；有些你们要杀害、要钉上十字架，有些要在会堂里鞭打，从一个城追逼到另一个城。</span></span>
<span className="v" id="v35" data-v="35" data-xref="历代志下 24:20–22; 撒迦利亚书 1:1; 希伯来书 11:4"> <span className="woj">所以，从义人亚伯的血起，直到你们在圣所和祭坛之间所杀的巴拉加的儿子撒迦利亚的血为止，在地上所流的义人的血都要归在你们身上。</span></span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 10:23; 马太福音 24:34; 马可福音 13:30–31"> <span className="woj">我确实地告诉你们：这一切都要临到这世代。</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 13:34–35; 路得记 2:12; 诗篇 91:4"> <span className="woj">“耶路撒冷啊，耶路撒冷！这城杀害先知们，又用石头砸死被差到她这里的人！我多次想聚集你的儿女，像母鸡把自己的小鸡聚集在翅膀下，可是你们不愿意！</span></span>
<span className="v" id="v38" data-v="38" data-xref="耶利米书 22:5; 路加福音 13:35; 路加福音 21:24"> <span className="woj">看哪，你们的家</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="家——或译作“殿”；指“圣殿”。参《耶利米书》12:7；22:5。">k</a></sup><span className="woj">要被废弃成为荒场。</span></span>
<span className="v" id="v39" data-v="39" data-xref="诗篇 118:26; 马太福音 21:9; 罗马书 11:25"> <span className="woj">我告诉你们：今后你们绝不会再见到我了，直到你们说：‘奉主名而来的那一位，是蒙祝福的。’”</span></span>

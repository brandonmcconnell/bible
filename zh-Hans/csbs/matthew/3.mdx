<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 40:3–6; 约翰福音 1:6–8; 路加福音 1:76"> 在那些日子里，施洗者<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="施洗者——或译作“施浸者”。">a</a></sup>约翰来了，在犹太的旷野传道，</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 4:17; 马可福音 1:15; 但以理书 2:44"> 说：“你们应当悔改，因为天国近了。”</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 40:3; 玛拉基书 3:1; 约翰福音 1:23"> 这约翰就是藉着先知以赛亚所说的那个人。以赛亚说：<br /><span className="pl pl-1">“在旷野有声音呼喊着：</span><br /><span className="pl pl-1">‘你们当预备主的道，</span><br /><span className="pl pl-1">当修直</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="修直——或译作“修平”。">b</a></sup><br /><span className="pl pl-1">他的路！’”</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 1:8; 撒迦利亚书 13:4; 马可福音 1:6"> 约翰穿着骆驼毛做的衣服，腰束皮带。他的食物是蝗虫和野蜜。</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 1:5; 路加福音 3:7; 约翰福音 3:23"> 那时，耶路撒冷、全犹太地区和整个约旦河一带的人，都出来到他那里，</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 19:18; 马太福音 3:13–16; 使徒行传 2:38–41"> 承认自己的罪孽，在约旦河里受他的洗礼。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 12:34; 帖撒罗尼迦前书 1:10; 罗马书 5:9"> 约翰看见许多法利赛人和撒都该人也来要受他的洗礼，就对他们说：“你们这些毒蛇的子孙！谁指示你们逃避那将要来临的震怒呢？</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 3:8; 使徒行传 26:20; 彼得后书 1:4–8"> 你们应当结出果子，与悔改的心相称！</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 3:8; 罗马书 9:7–8; 加拉太书 3:27–29"> 你们不要心里想‘我们有亚伯拉罕为先祖。’我告诉你们：神能从这些石头中给亚伯拉罕兴起儿女来。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 15:6; 路加福音 3:9; 马太福音 7:19"> 现在斧子已经放在树根上，所有不结好果子的树都要被砍下来，被丢进火里。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 4:4; 路加福音 3:16; 使徒行传 1:5"> “我用水<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="用水——或译作“在水里”。">c</a></sup>给你们施洗，是为了你们的<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="你们的——辅助词语。">d</a></sup>悔改。但在我之后来的那一位，是比我更强有力的，我就是为他提鞋子也不配。他要用圣灵和火给你们施洗。</span>
<span className="v" id="v12" data-v="12" data-xref="玛拉基书 4:1; 马太福音 13:30; 路加福音 3:17"> 他手里拿着扬谷的锨，要扬净他的打谷场，把他的麦子收进仓库，却把糠秕用不灭的火烧掉。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约翰福音 1:32–34; 马太福音 2:22; 马可福音 1:9–11"> 那时，耶稣从加利利来到约旦河，到了约翰那里，要受他的洗礼。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 3:3–7; 使徒行传 1:5–8; 约翰福音 13:6–8"> 约翰想要阻止他，说：“我需要受你的洗礼，你反而到我这里来吗？”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 4:34; 约翰福音 15:10; 诗篇 40:7–8"> 耶稣回答他，说：<span className="woj">“现在你就答应吧，因为我们如此成全一切的义，是合宜的。”</span>于是约翰答应了他。</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 11:2; 马可福音 1:10; 路加福音 3:21–22"> 耶稣受了洗，一从水里上来，看哪，诸天就为他<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本没有“为他”。">e</a></sup>开了，他看见神的灵好像鸽子降下，临到他身上。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 42:1; 诗篇 2:7; 马太福音 17:5"> 这时候，忽然有声音从诸天传来，说：<br /><span className="pl pl-1">“这是我的爱子，</span><br /><span className="pl pl-1">我所喜悦的。”</span></span>
</div>
</div>

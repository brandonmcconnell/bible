<span className="v" id="v2" data-v="2" data-xref="申命记 9:18; 出埃及记 34:28; 列王纪上 19:8"> 耶稣禁食了四十昼夜，后来就饿了。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 3:1–5; 帖撒罗尼迦前书 3:5; 民数记 11:4–6"> 那试探者前来对他说：“你如果是神的儿子，就吩咐这些石头变成食物吧！”</span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="申命记 8:3; 路加福音 4:4; 约翰福音 6:63"> 耶稣回答说：<span className="woj">“经上记着：</span><br /><span className="pl pl-1 woj">‘人活着不是单靠食物，</span><br /><span className="pl pl-1 woj">而是靠神口里所出的每一句话。’</span><br /><span className="pl pl-1 woj">”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="路加福音 4:9; 马太福音 27:53; 启示录 11:2"> 接着，魔鬼带他到圣城，让他站在圣殿的顶端，</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 91:11–12; 希伯来书 1:14; 诗篇 34:7"> 对他说：“你如果是神的儿子，就跳下去吧！因为经上记着：<br /><span className="pl pl-1">‘他会为你吩咐他的天使；</span><br /><span className="pl pl-1">他们会用手托住你，</span><br /><span className="pl pl-1">免得你的脚撞在石头上。’ ”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命记 6:16; 哥林多前书 10:9; 诗篇 78:18"> 耶稣对他说：<span className="woj">“经上又记着：‘不可试探主——你的神。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约翰一书 2:15–16; 启示录 11:15; 诗篇 49:16–17"> 接着，魔鬼带耶稣上了一座很高的山，给他看世界万国和万国的荣耀，</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 4:4; 但以理书 5:18–19; 约翰福音 16:11"> 对他说：“你如果俯伏拜我，我就把这一切都给你。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="申命记 6:13–14; 申命记 10:20; 约书亚记 24:14"> 耶稣对他说：<span className="woj">“撒旦，退去</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="退去——有古抄本作“退到我后面去”。">a</a></sup><span className="woj">！因为经上记着：</span><br /><span className="pl pl-1 woj">‘要敬拜主——你的神，</span><br /><span className="pl pl-1 woj">唯独事奉他。’</span><br /><span className="pl pl-1 woj">”</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马太福音 26:53; 希伯来书 1:14; 路加福音 22:43"> 于是，魔鬼离开了耶稣。看哪，有天使们前来伺候他。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="马可福音 1:14; 路加福音 3:20; 马太福音 14:3"> 耶稣听说约翰被逮捕了，就退到加利利地区。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 4:46; 马可福音 1:21; 马太福音 11:23"> 后来，他离开拿撒勒，来到西布伦和拿弗他利境内，住在湖边的迦百农。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 9:1–2; 马太福音 2:23; 路加福音 24:44"> 这是为要应验那藉着先知以赛亚所说的话：</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 9:1; 列王纪下 15:29; 约书亚记 21:32"> <span className="pl pl-1">“西布伦地、拿弗他利地，</span><br /><span className="pl pl-1">沿湖</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="湖——原文直译“海”；指“加利利湖（海）”。">b</a></sup><br /><span className="pl pl-1">的路，约旦河的对岸，</span><br /><span className="pl pl-1">外邦人的加利利——</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 9:2; 以赛亚书 42:6–7; 以赛亚书 60:1–3"> <span className="pl pl-1">那坐在黑暗中的民众</span><br /><span className="pl pl-1">看到了大光；</span><br /><span className="pl pl-1">那坐在死亡之地和死亡阴影中的人们，</span><br /><span className="pl pl-1">曙光为他们升起。”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 3:2; 使徒行传 2:38; 马可福音 1:14–15"> 从那时候起，耶稣开始传道，说：<span className="woj">“你们应当悔改，因为天国近了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰福音 1:40–42; 马太福音 10:2; 路加福音 6:14"> 耶稣在加利利湖边行走，看见兄弟两个人，就是那叫彼得的西门和他弟弟<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="弟弟——原文直译“兄弟”。">c</a></sup>安得烈，正在湖里撒网；他们本来是渔夫。</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 1:17–18; 约翰福音 12:26; 马太福音 16:24"> 耶稣就对他们说：<span className="woj">“来跟从我！我将要使你们成为得人的渔夫。”</span></span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 10:28–31; 马太福音 19:27; 路加福音 18:28–30"> 他们立刻舍弃渔网，跟从了耶稣。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马可福音 1:19–20; 马太福音 10:2; 马可福音 3:17"> 耶稣从那里往前走，看见另外两个兄弟，就是西庇太的儿子雅各和他弟弟约翰，正在船上与他们的父亲西庇太一起修补渔网。耶稣就召唤他们，</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 10:37; 路加福音 9:59–60; 申命记 33:9–10"> 他们立刻舍弃了船，告别他们的父亲，跟从了耶稣。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 9:35; 马可福音 1:39; 使徒行传 10:38"> 耶稣走遍全加利利，在他们的会堂里教导人，传天国的福音，并且使民中各样的疾病和各样的症状痊愈。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 8:6; 马太福音 17:15; 路加福音 5:15"> 他的消息就在全叙利亚省传开了。人们把所有的病人，就是患各种疾病的、受疼痛折磨的、有鬼魔附身的、癫痫的、瘫痪的，都带到耶稣那里。耶稣就使他们痊愈。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 6:17; 马可福音 5:20; 马可福音 3:7–8"> 于是有一大群人从加利利、德卡波利斯、耶路撒冷、犹太和约旦河对岸来，跟随耶稣。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="弥迦书 5:2; 约翰福音 7:42; 路加福音 2:4–7"> 在希律王的那些日子里，耶稣诞生在犹太的伯利恒。当时，有几个博士从东方来到耶路撒冷。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 24:17; 耶利米书 23:5; 启示录 22:16"> 他们问：“生下来做犹太人之王的那一位在哪里？我们在东方看见了他的星，就来了要朝拜他。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="使徒行传 17:6–7; 约翰福音 11:47–48; 马太福音 23:37"> 希律王听说了，就惊慌不安，全耶路撒冷的人也与他一起不安。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 21:23; 马太福音 7:29; 使徒行传 6:12"> 希律就召集了所有的祭司长和民间的经文士，向他们询问基督诞生在哪里。</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 7:42; 路得记 1:1; 撒母耳记上 16:1"> 他们对希律说：“在犹太的伯利恒，因为藉着先知有这样的记载：</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 34:23–25; 弥迦书 5:2; 以赛亚书 9:6–7"> <span className="pl pl-1">‘犹大之地伯利恒啊！</span><br /><span className="pl pl-1">你在犹大的首要城乡</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="首要城乡——原文直译“总督”。">a</a></sup><br /><span className="pl pl-1">中，绝不是最小的，</span><br /><span className="pl pl-1">因为将来有一位领袖要从你那里出来，</span><br /><span className="pl pl-1">他要牧养我的子民以色列。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 1:10; 撒母耳记上 18:21; 诗篇 55:21"> 于是，希律暗暗地召见了那几个博士，向他们仔细询问那颗星出现的时间，</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 3:19–20; 耶利米书 41:5–7; 路加福音 20:20–21"> 然后打发他们前往伯利恒，说：“你们去仔细查问有关那孩子的事，一旦查出来了就向我报告，好让我也去拜他。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马太福音 2:2; 箴言 8:17; 诗篇 25:12"> 他们听了王的话就去了。看哪，他们在东方看见的那颗星在前面引导他们，直到那孩子所在的地方，就在上头停住了。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 105:3; 路加福音 2:20; 路加福音 2:10"> 他们看见那颗星，极其欢喜快乐。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 60:6; 诗篇 72:10; 路加福音 2:16"> 他们进了屋子，看见那孩子与他的母亲玛丽亚在一起，就俯伏拜那孩子，然后打开他们的宝盒，把黄金、乳香和没药做为礼物献给他。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 2:22; 马太福音 2:19; 马太福音 2:13"> 他们在梦中得了神的指示不要回到希律那里去，就从另一条路回到自己的家乡去了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 10:7; 使徒行传 5:19; 马太福音 1:20"> 那些博士离开以后，忽然主的一位天使在约瑟梦中显现，说：“起来，带着孩子和他的母亲逃往埃及，留在那里，直到我再指示你，因为希律要搜寻这孩子并杀害他。”</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 2:20–21; 使徒行传 26:21; 马太福音 1:24"> 约瑟就起来，连夜带着孩子和他的母亲逃往埃及，</span>
<span className="v" id="v15" data-v="15" data-xref="何西阿书 11:1; 出埃及记 4:22; 民数记 24:8"> 住在那里，直到希律死了。这是为要应验主藉着先知所说的话：“我从埃及召我的儿子出来。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 59:7; 箴言 28:15; 士师记 16:10"> 希律发现自己受了博士们的愚弄，就十分恼怒。于是，他按照从博士们那里所询问到的时间，派人把伯利恒城里和周围各个地区内两岁以下的男孩，全都杀了。</span>
<span className="v" id="v17" data-v="17"> 这就应验了藉着先知耶利米所说的话：</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 31:15; 耶利米书 9:17–21; 耶利米书 4:31"> <span className="pl pl-1">“从拉玛听见了声音，</span><br /><span className="pl pl-1">是哀哭</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="哀哭——有古抄本作“悲叹和哀哭”。">b</a></sup><br /><span className="pl pl-1">和极其伤痛的声音，</span><br /><span className="pl pl-1">是拉结为她的儿女哀哭，</span><br /><span className="pl pl-1">不肯接受安慰，</span><br /><span className="pl pl-1">因为他们不在了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马太福音 1:20; 但以理书 8:25; 马太福音 2:12–13"> 希律死了以后，在埃及，忽然主的一位天使在约瑟梦中显现，</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 4:19; 列王纪上 12:1–3; 马太福音 2:13"> 说：“起来，带着孩子和他的母亲回以色列地去，因为那些追索这孩子性命的人已经死了。”</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 11:8; 创世记 6:22"> 约瑟就起来，带着孩子和他的母亲进了以色列地。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 48:17–18; 路加福音 2:39; 约翰福音 7:52"> 但是，听说亚基劳接续他父亲希律做了犹太王，约瑟就怕往那里去，而且他在梦中得了神的指示，就退到加利利地区，</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 13:5; 约翰福音 1:45–46; 马可福音 1:24"> 来到一个叫拿撒勒的镇，住了下来。这是为要应验那藉着先知们所说的话：“他将被称为拿撒勒人。”</span>
</div>
</div>

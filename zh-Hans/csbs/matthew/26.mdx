<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="马可福音 14:3–9; 路加福音 7:37–39; 约翰福音 12:1–8"> 耶稣在伯大尼，在麻风病人西门家里的时候，</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 12:2–3; 路加福音 7:46; 路加福音 7:37–38"> 有一个女人拿着一个盛了极其贵重香液的玉瓶上前来，在耶稣坐席的时候，把香液浇在他的头上。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 12:4–6; 马可福音 14:4; 出埃及记 5:17"> 门徒们看见了就很不满，说：“为什么这样浪费？</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 12:5–6; 马可福音 14:5; 约书亚记 7:20–21"> 这香液<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本没有“香液”。">b</a></sup>本来可以卖很多钱，分给穷人。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="提多书 3:8; 希伯来书 13:21; 提摩太前书 5:10"> 耶稣知道了，就对他们说：<span className="woj">“你们为什么为难这妇人呢？她为我做了一件美好的事。</span></span>

<span className="v" id="v13" data-v="13" data-xref="马可福音 14:9; 马太福音 24:14; 诗篇 112:6"> <span className="woj">我确实地告诉你们：在全世界，福音无论传到什么地方，这女人所做的事也将被述说，做为对她的记念。”</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 22:3–6; 马太福音 10:4; 马可福音 14:10–11"> 那时候，十二使徒<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="使徒——辅助词语。">c</a></sup>中的一个，就是那称为加略人犹大的，到祭司长们那里去，</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 11:12–13; 创世记 37:26–28; 出埃及记 21:32"> 说：“如果我把他交给你们，你们愿意给我什么？”他们就约定给他三十个银钱。</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 14:11; 路加福音 22:6"> 从那时候起，犹大就开始找机会要把耶稣交出去。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 22:7–13; 马可福音 14:12–16; 出埃及记 12:18–20"> 除酵节的第一日，门徒们前来问耶稣：“你要我们到哪里去预备，好让你吃逾越节的晚餐呢？”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马可福音 14:13–16; 约翰福音 7:6; 约翰福音 17:1"> 耶稣说：<span className="woj">“你们进城去，到某人那里，告诉他：‘老师说，我的时候快到了。我要在你那里与我的门徒们一起守逾越节。’”</span></span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 2:5; 约翰福音 15:14; 马太福音 21:6"> 门徒们就依照耶稣所吩咐的去做，预备了逾越节的晚餐。</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 14:17–21; 约翰福音 13:21; 路加福音 22:14–16"> 到了晚上，耶稣与十二使徒一同坐席。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 13:21; 希伯来书 4:13; 约翰福音 6:70–71"> 在他们吃的时候，耶稣说：<span className="woj">“我确实地告诉你们：你们当中有一个人要出卖我。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约翰福音 13:22–25; 路加福音 22:23; 马可福音 14:19–20"> 他们极其忧伤，就一个一个地开始问耶稣：“主啊，不会是我吧？”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约翰福音 13:18; 诗篇 41:9; 约翰福音 13:26–28"> 耶稣回答说：<span className="woj">“那与我一同把手蘸在盘子里的，就是要出卖我的人。</span></span>

</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马太福音 26:64; 马太福音 27:11; 路加福音 22:70"> 那出卖耶稣的犹大应声说：“拉比，不会是我吧？”<br />耶稣对他说：<span className="woj">“你已经说了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="哥林多前书 11:23–29; 路加福音 22:18–20; 哥林多前书 10:16–17"> 在他们吃的时候，耶稣拿起饼来，祝福了，就掰开，递给门徒们，说：<span className="woj">“你们领受吃吧，这是我的身体。”</span></span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 25:6; 哥林多前书 10:16; 诗篇 116:13"> 接着，他拿起杯来，祝谢了，递给他们，说：<span className="woj">“你们都来喝，</span></span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 10:4–14; 希伯来书 9:14–22; 利未记 17:11"> <span className="woj">因为这是我的血，是为立约</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="约——有古抄本作“新约”。">d</a></sup><span className="woj">的，为许多人所流的，使罪得赦免。</span></span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 12:2; 启示录 7:17; 马可福音 14:25"> <span className="woj">我告诉你们：从今以后我绝不喝这葡萄汁</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="葡萄汁——或译作“葡萄酒”；原文直译“葡萄树的产品”。">e</a></sup><span className="woj">，直到我在我父的国里与你们一起喝新的那一天。”</span></span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 21:1; 以弗所书 5:19–20; 路加福音 22:39"> 他们唱了赞美诗<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="赞美诗——那时代的逾越节晚餐时、晚餐后，所唱的赞美诗是《诗篇》113-118篇。">f</a></sup>，就出来，往橄榄山去了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="撒迦利亚书 13:7; 马可福音 14:27–28; 约翰福音 16:32"> 那时，耶稣对他们说：<span className="woj">“今天晚上，你们都将因我被绊倒，因为经上记着：</span><br /><span className="pl pl-1 woj">‘我将击打牧人，</span><br /><span className="pl pl-1 woj">群羊就被分散。’</span></span>

<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马太福音 28:10; 路加福音 18:33–34; 马太福音 28:16"> <span className="woj">但是我复活以后，要在你们之前到加利利去。”</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 22:33; 约翰福音 13:36–38; 箴言 28:25–26"> 彼得对耶稣说：“即使所有的人因你被绊倒，我也绝不会被绊倒。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="约翰福音 13:38; 路加福音 22:34; 马太福音 26:75"> 耶稣对他说：<span className="woj">“我确实地告诉你：今天晚上鸡叫以前，你会三次不认我。”</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="罗马书 11:20; 约翰福音 13:37; 箴言 29:23"> 彼得对耶稣说：“即使我必须与你同死，我也绝不会不认你。”所有的门徒也都如此说。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="马可福音 14:32–42; 马太福音 26:42; 路加福音 22:39–46"> 随后，耶稣与他们来到一个叫客西马尼的地方。耶稣对门徒们说：<span className="woj">“我走开在那里祷告的时候，你们坐在这里。”</span></span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 4:21; 马太福音 17:1; 马可福音 5:37"> 他带了彼得和西庇太的两个儿子一起去，开始感到忧虑，极其难过，</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 12:27; 彼得前书 3:18; 彼得前书 2:24"> 就对他们说：<span className="woj">“我的灵魂很忧伤，几乎要死。你们留在这里，与我一同警醒。”</span></span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 6:38; 腓立比书 2:8; 路加福音 22:41–42"> 耶稣稍往前走，把脸伏在地上祷告说：<span className="woj">“我父啊，如果有可能，让这杯离开我吧！但不要照我的意愿，而要照你的意愿。”</span></span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="马可福音 14:37; 路加福音 22:45; 马太福音 26:43"> 耶稣回到门徒们那里，看见他们睡着了，就对彼得说：<span className="woj">“你们怎么就不能与我一同警醒一个小时呢？</span></span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 14:38; 路加福音 22:46; 以弗所书 6:18"> <span className="woj">要警醒祷告，免得陷入试探。你们心灵虽然愿意，肉体却是软弱的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="马太福音 26:39; 马可福音 14:39–40; 希伯来书 4:15"> 耶稣第二次又去祷告说：<span className="woj">“我父啊，如果这杯不能离开我</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本没有“我”。">g</a></sup><span className="woj">，一定要我喝下，那就愿你的旨意成就！”</span></span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 9:32; 罗马书 13:1; 箴言 23:34"> 他又回来，看见他们在睡觉，因为他们的眼皮发沉。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="哥林多后书 12:8; 路加福音 18:1; 马太福音 6:7"> 耶稣又离开他们，第三次去祷告，又说了同样的话。</span>
<span className="v" id="v45" data-v="45" data-xref="约翰福音 13:1; 约翰福音 12:27; 马可福音 14:41–42"> 然后，他回到门徒们那里，对他们说：<span className="woj">“你们还在睡觉、休息吗？看哪，时候快到了！人子被交在</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="被交在——或译作“被出卖到”。">h</a></sup><span className="woj">罪人的手里了。</span></span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 9:51; 约翰福音 14:31; 撒母耳记上 17:48"> <span className="woj">起来，我们走吧！看，那出卖我的人快到了！”</span></span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="使徒行传 1:16; 马太福音 26:55; 马可福音 14:43–50"> 耶稣还在说话的时候，忽然十二使徒之一的犹大来了。有一大群人拿着刀剑和棍棒与他一起来，他们是祭司长们和民间的长老们所派来的。</span>
<span className="v" id="v48" data-v="48" data-xref="诗篇 55:20–21; 诗篇 28:3; 撒母耳记下 3:27"> 那出卖耶稣的人已经和他们定了一个暗号，说：“我如果亲吻谁，谁就是那个人。你们把他抓住。”</span>
<span className="v" id="v49" data-v="49" data-xref="马太福音 26:25; 帖撒罗尼迦前书 5:26; 箴言 27:6"> 犹大立刻上前来对耶稣说：“拉比，愿你欢喜！”然后亲吻了他。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="马太福音 20:13; 马太福音 22:12; 诗篇 41:9"> 耶稣对他说：<span className="woj">“朋友，你为什么来到这里？”</span><br />于是，那些人上前来，下手拘捕了耶稣。</span>
<span className="v" id="v51" data-v="51" data-xref="约翰福音 18:36; 马可福音 14:47; 哥林多后书 10:4"> 这时候，忽然有一个与耶稣在一起的人伸手拔出刀来，向大祭司的奴仆砍去，削掉了他的一个耳朵。</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="启示录 13:10; 创世记 9:6; 罗马书 12:19"> 耶稣就对他说：<span className="woj">“把你的刀收回原处！因为凡动刀的，必死在刀下。</span></span>
<span className="v" id="v53" data-v="53" data-xref="列王纪下 6:17; 马太福音 4:11; 但以理书 7:10"> <span className="woj">难道你想我不能求我父，现在就为我派来十二个军团以上的天使吗？</span></span>
<span className="v" id="v54" data-v="54" data-xref="撒迦利亚书 13:7; 马太福音 26:24; 使徒行传 1:16"> <span className="woj">如果这样，‘事情必须如此发生’的经文怎么应验呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="马可福音 12:35; 约翰福音 8:2; 路加福音 22:52–53"> 这时候，耶稣对那群人说：<span className="woj">“你们带着刀剑和棍棒出来抓我，就像对付强盗那样吗？我天天坐在圣殿里教导人，你们并没有抓我。</span></span>
<span className="v" id="v56" data-v="56" data-xref="撒迦利亚书 13:7; 约翰福音 16:32; 马可福音 14:50–52"> <span className="woj">不过这整个事的发生，是为要应验先知书的那些经文。”</span>这时候，所有的门徒都离开他，逃跑了。</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="马太福音 26:3; 马可福音 14:53–65; 诗篇 56:5–6"> 拘捕耶稣的人把他带到大祭司该亚法那里。经文士们和长老们已经聚集在那里了。</span>
<span className="v" id="v58" data-v="58" data-xref="约翰福音 7:32; 约翰福音 18:15–16; 约翰福音 18:25"> 彼得远远地跟着耶稣，一直到大祭司的院子。他进到里面，与差役们坐在一起，想看看结果如何。</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="使徒行传 6:11–13; 申命记 19:16–21; 马可福音 14:55–56"> 当时，祭司长们<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附“长老们”。">i</a></sup>和全议会的人为了要处死耶稣，都在寻找伪证来控告他。</span>
<span className="v" id="v60" data-v="60" data-xref="申命记 19:15; 诗篇 35:11; 诗篇 27:12"> 虽然有许多假见证人上前来，可是他们找不出什么。后来有两个人<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="两个人——有古抄本作“两个假见证人”。">j</a></sup>上前来，</span>
<span className="v" id="v61" data-v="61" data-xref="约翰福音 2:19–21; 马太福音 27:40; 马可福音 15:29"> 说：“这个人说过：‘我能拆毁神的圣所，三天内又建起来。’”</span>

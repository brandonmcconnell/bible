<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得后书 3:3; 提摩太后书 4:3; 提摩太前书 4:1–3"> 你应当知道这一点：在末后的日子里，将有艰难的时候来到；</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比书 2:21; 罗马书 1:29–31; 犹大书 1:16"> 因为人们将会爱自己、爱钱财，又自夸、又骄傲，亵渎神、悖逆父母、忘恩负义、毫不圣洁、</span>
<span className="v" id="v3" data-v="3" data-xref="犹大书 1:18; 罗马书 1:31; 马太福音 10:21"> 没有亲情、不肯和解、恶意控告、不能自制、残忍凶暴、不爱良善、</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比书 3:18–19; 提摩太前书 3:6; 犹大书 1:4"> 背叛出卖、任意妄为、自以为是，爱享乐过于爱神，</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 29:13; 提多书 1:16; 马太福音 23:27–28"> 有敬神的外表，却否定敬神的实质<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="实质——原文直译“能力”。">a</a></sup>；这样的人你要避开。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="犹大书 1:4; 彼得后书 3:17; 提多书 3:3"> 他们当中有些人溜进别人家里，虏获无知的妇女。这些妇女被罪孽压制，被各种欲望牵引，</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太后书 4:3–4; 以弗所书 4:14; 提摩太前书 2:4"> 虽然一直学习，却始终不能达到到真理的知识当中。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 13:8–11; 启示录 2:20; 提摩太前书 6:5"> 扬尼和扬布列怎样抵挡摩西，这些人也照样抵挡真理；他们理性败坏，在信仰上经不起考验。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太后书 3:8; 出埃及记 7:12; 耶利米书 28:15–17"> 然而，他们不能再进一步了，因为他们的无知会在众人面前显露出来，就像那两个人一样。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 6:11; 提多书 2:7; 彼得后书 1:5–7"> 至于你，你跟从了我的教导、品行、心意、信仰、宽容、爱心、忍耐，</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 34:19; 使徒行传 14:5–6; 哥林多后书 11:23–28"> 以及我在安提阿、以哥念、路司得所遭受的逼迫和苦难——我忍受了何等的逼迫啊！可是主救我脱离了这一切。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 3:14; 彼得前书 4:12–16; 彼得前书 2:20–21"> 其实，所有想要在基督耶稣里过敬神生活的，也都会受到逼迫；</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太前书 4:1; 彼得后书 2:20; 提多书 3:3"> 而恶人和迷惑人的会越来越坏，他们迷惑人，自己也被迷惑。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:13; 提摩太后书 2:2; 提摩太后书 1:13"> 至于你，你当持守所学到、所确信的，因为你知道是从哪些人学的；</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 119:98–99; 路加福音 24:45; 箴言 22:6"> 并且你从年幼就知道了圣经，这圣经能使你有智慧，藉着在基督耶稣里的信仰，以至于救恩。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 15:4; 希伯来书 4:12; 彼得后书 1:19–21"> 圣经都是神所默示的，对于教导、责备、规正、在义中的训练都是有益处的，</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太后书 2:21; 以弗所书 2:10; 哥林多后书 9:8"> 要使属神的人完备，为一切美善的工作，装备齐全。</span>
</div>
</div>

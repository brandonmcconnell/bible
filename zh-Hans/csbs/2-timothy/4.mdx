<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 10:42; 提摩太后书 4:8; 提摩太前书 5:21"> 我在神、基督耶稣<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="基督耶稣——有古抄本作“主耶稣基督”。">a</a></sup>面前，就是将要审判活人、死人的那一位面前，藉着他的显现和他的国度郑重地劝诫你：</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦前书 5:14; 提摩太前书 4:15–16; 提多书 2:15"> 你要传福音<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="福音——原文直译“话语”或“道”。">b</a></sup>，无论得时不得时，总要坚持；要以极大的耐心和各样的教导责备人、告诫人、鼓励人，</span>
<span className="v" id="v3" data-v="3" data-xref="彼得后书 2:1–3; 提摩太后书 3:1–6; 提摩太前书 4:1–3"> 因为时候将到，人们容忍不了健全的教义，反要顺着自己的欲望，为自己的耳朵能被呵痒得舒服，去召聚许多教师。</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 7:11; 提摩太前书 1:4; 使徒行传 7:57"> 他们将掩耳不听真理，却转向编造的故事。</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太后书 1:8; 彼得前书 1:13; 提摩太后书 2:3"> 至于你，要在一切事上谨慎，忍受苦难，做传福音者的工作，完成你的服事。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="腓立比书 1:23; 腓立比书 2:17; 彼得后书 1:14–15"> 事实上，我已经在被浇奠了；我离开世界<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="世界——辅助词语。">c</a></sup>的时候已经临到了。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前书 6:12; 哥林多前书 9:24–27; 希伯来书 12:1–2"> 那美好的仗，我已经打过了；该跑的路程，我已经跑尽了<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="该跑的路程，我已经跑尽了——原文直译“那赛程，我已经完成了”。">d</a></sup>；当守的<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="当守的——辅助词语。">e</a></sup>信仰，我已经持守了。<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="那美好的仗，我已经打过了；该跑的路程，我已经跑尽了；当守的信仰，我已经持守了。——或译作“我已打了那美好的仗，跑完了这路程，守住了这信仰。”">f</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="雅各书 1:12; 启示录 2:10; 彼得前书 5:4"> 此后，有那公义的冠冕为我存留，就是主——公义的审判者要在那一天回报给我的；不仅给我，也要给所有爱慕他显现的人。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="提摩太后书 1:4; 提摩太后书 4:21"> 你要尽快到我这里来，</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 2:15–16; 提摩太后书 1:15; 歌罗西书 4:14–15"> 因为迪马斯爱上了现今的世代，就离弃我到帖撒罗尼迦去了；克勒斯克到加拉太<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="加拉太——有古抄本作“高卢”。">g</a></sup>去，提多到达尔马提亚去了，</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 12:12; 腓利门书 1:24; 使徒行传 12:25"> 只有路加与我在一起。你要接上马可，带他一起来，因为他在服事工作上对我很有帮助。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 6:21; 使徒行传 20:4; 提多书 3:12"> 我派特其库斯到以弗所去了。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 4:11; 哥林多后书 11:27; 使徒行传 16:11"> 你来的时候，要把我在特罗阿斯时留在卡尔坡家里的那件外衣带来，还有那些书卷，尤其是那些羊皮卷，也要带来。</span>
<span className="v" id="v14" data-v="14" data-xref="提摩太前书 1:20; 帖撒罗尼迦后书 1:6; 诗篇 28:4"> 铜匠亚历山大对我做了很多恶事；主将照着他的行为回报他。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太后书 3:8; 腓立比书 3:2; 马太福音 10:16–17"> 你也要提防他，因为他极力抵挡我们的话。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行传 7:60; 约翰福音 16:32; 马可福音 14:50"> 我第一次为自己辩护的时候，没有一个人来支持我，大家都离弃了我；愿这事不算在他们身上。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前书 5:8; 腓立比书 1:12–14; 撒母耳记上 17:37"> 但是主站在我身边，使我刚强，为要藉着我使传道得以完成，让所有外邦人都能听见；我也从狮子口里被救了出来。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 121:7; 帖撒罗尼迦后书 3:3; 犹大书 1:24–25"> 主将会救我脱离一切凶恶之事，并且救我进入他属天的国度。愿荣耀归于他，直到永永远远！阿们。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 18:2; 哥林多前书 16:19; 罗马书 16:3–4"> 请问候普茜拉和阿奎拉，还有奥尼斯弗罗的家人。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 20:4; 使徒行传 19:22; 腓立比书 2:26–27"> 以拉斯托在哥林多住下了；特罗费摩患了病，我就留他在米利都。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 4:9; 腓立比书 4:22; 约翰三书 1:14"> 你要在冬天以前尽快赶来。犹布罗斯、普迪斯、利诺斯、克劳迪娅，以及所有的弟兄都问候你。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="腓利门书 1:25; 加拉太书 6:18; 歌罗西书 4:18"> 愿主<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="主——有古抄本作“主耶稣基督”。">h</a></sup>与你的灵同在。愿恩典与你们同在！<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附“阿们。”">i</a></sup></span>
</div>
</div>

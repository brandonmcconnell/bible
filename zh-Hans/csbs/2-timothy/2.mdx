<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 12:9–10; 以弗所书 6:10; 提摩太后书 1:7"> 所以我的儿子啊，你要藉着在基督耶稣里的恩典得以刚强。</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太后书 1:13–14; 提摩太前书 4:6; 提摩太前书 6:12"> 你要把那些在许多见证人面前<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="在许多见证人面前——或译作“藉着许多见证人”。">a</a></sup>从我所听见的，交托给那些忠心可靠、又有能力教导别人的人。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="希伯来书 12:2–3; 雅各书 1:12; 提摩太后书 4:5"> 做为基督耶稣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="基督耶稣——有古抄本作“耶稣基督”。">b</a></sup>的好士兵，你要与我<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="与我——辅助词语。">c</a></sup>同受苦难。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 2:4; 路加福音 8:14; 彼得后书 2:20"> 凡是当兵的，没有一个会让日常事务纠缠自己，这是为要使那招兵的人喜悦。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 9:24–27; 启示录 3:11; 提摩太后书 4:7–8"> 同样，如果有人要参加竞赛，除非按着规矩去竞赛，否则就不能得冠冕。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 10:36; 哥林多前书 9:7–11; 哥林多前书 3:6–9"> 劳苦做工的农夫，应该先享受果实。</span>
<span className="v" id="v7" data-v="7" data-xref="雅各书 1:5; 约翰一书 5:20; 路加福音 24:45"> 你要思考我所说的话，主会在一切事上赐给你悟性。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 2:24; 罗马书 2:16; 哥林多前书 15:11–20"> 你当记住那从死人中复活的耶稣基督，照着我的福音，他出自大卫的后裔。</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比书 1:7; 使徒行传 28:31; 提摩太后书 1:8"> 我为这福音受苦，甚至像罪犯一样被捆绑；然而神的话语<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="神的话语——或译作“神的道”。">d</a></sup>是不受捆绑的。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前书 5:10; 歌罗西书 1:24; 提摩太后书 2:3"> 所以，我为了那些蒙拣选的人忍受一切，好让他们也能得到那在基督耶稣里的救恩和永恒的荣耀。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 6:8; 歌罗西书 3:3–4; 罗马书 6:5"> 以下的话是信实的：<br /><span className="pl pl-1">我们如果与基督一同死了，就将与他一同活着；</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 8:17; 马太福音 10:33; 启示录 20:4"> <span className="pl pl-1">我们如果忍耐，就将与他一同做王；</span><br /><span className="pl pl-1">我们如果不认他，他也将不认我们。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="民数记 23:19; 罗马书 3:3; 帖撒罗尼迦后书 3:3"> <span className="pl pl-1">我们如果不信实，他仍然是信实的，</span><br /><span className="pl pl-1">因为他不能否定自己。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="提多书 3:9–11; 提摩太后书 2:23; 提摩太后书 4:1"> 你要提醒他们这些事，在神<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="神——有古抄本作“主”。">e</a></sup>面前郑重地劝诫他们：不可在言词上争执，那是毫无益处的，只会败坏听见的人。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 2:4; 彼得后书 1:10; 提摩太前书 4:6"> 你要努力地向神显明自己是经过考验的，是无愧的工人，能正确分解真理的话语。</span>
<span className="v" id="v16" data-v="16" data-xref="提多书 3:9; 提摩太前书 6:20; 提摩太后书 2:14"> 至于那些不敬神的空谈，你们要避免，因为说这些话的人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="说这些话的人——或译作“这些空谈”。">f</a></sup>将导致更多不敬神的事；</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太前书 1:20; 那鸿书 3:15; 雅各书 5:3"> 他们的话像毒瘤那样将会扩散。这些人中间有希米奈奥和菲利特斯，</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 15:12; 提摩太前书 1:19; 希伯来书 3:10"> 他们偏离了那有关真理的事，称复活为已经过去的事，结果推翻了一些人的信仰。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 10:14; 哥林多前书 8:3; 那鸿书 1:7"> 不过神坚固的根基始终确立，上面有这样的印记：<br /><span className="pl pl-1">“主认识那些属于自己的人” 还有</span><br /><span className="pl pl-1">“所有称呼主</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="主——有古抄本作“基督”。">g</a></sup><br /><span className="pl pl-1">名的人都要离开不义”。</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="罗马书 9:21–23; 彼得前书 2:5; 提摩太前书 3:15"> 在大户人家，不仅有金器、银器，也有木器、瓦器；虽然有的为了贵重的用处<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="用处——辅助词语。">h</a></sup>，但有的却为了卑贱的用处<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="用处——辅助词语。">i</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 3:17; 以弗所书 2:10; 哥林多后书 7:1"> 所以，如果有人洁净自己脱离卑贱的事，他就会成为贵重的器皿，被分别为圣，对主人有用，而且是为着一切美善的工作所预备好的。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:11; 彼得前书 3:11; 哥林多前书 6:18"> 所以你要逃避年轻人的欲望；要与那些以洁净的心求告主的人一同追求公义、信仰、爱心、和平；</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太后书 2:14; 提多书 3:9; 提摩太前书 4:7"> 要拒绝愚拙无知的辩论，因为你知道这些只会引起争斗，</span>
<span className="v" id="v24" data-v="24" data-xref="提多书 3:2; 雅各书 1:19–20; 提摩太前书 3:2–3"> 而主的奴仆不应该争斗；相反，要温和地对待所有的人，善于教导，忍受恶待，</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 11:18; 加拉太书 6:1; 提摩太前书 2:4"> 温柔地管教那些反对的人；或许神会赐给这些人悔改的心，到真理的知识当中。</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太前书 3:7; 以赛亚书 49:25–26; 诗篇 124:7"> 这样，那些被魔鬼掳去、随从魔鬼意思的人，就能醒悟过来，脱离魔鬼的网罗。</span>
</div>
</div>

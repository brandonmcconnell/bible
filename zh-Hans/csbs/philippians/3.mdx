<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 5:11; 腓立比书 4:4; 雅各书 1:2"> 此外，我的弟兄们，你们要在主里欢喜。<br />我把同样的话写给你们，一方面对我不是麻烦，另一方面对你们是一种保护。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 11:13; 提多书 1:16; 启示录 22:15"> 你们要当心那些犬类，当心那些作恶的工人，当心那些妄割身体的人。</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 2:11; 申命记 30:6; 罗马书 7:6"> 实际上，我们才是受过割礼的人，就是藉着神的灵事奉，在基督耶稣里夸耀，不依靠肉体的人。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 11:18–22"> 其实我也可以依靠肉体；如果另外有人自以为可以依靠肉体，我就更可以了。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 11:22; 罗马书 11:1; 使徒行传 23:6"> 我出生<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我出生——辅助词语。">a</a></sup>第八天受了割礼；我属于以色列族、便雅悯支派，是希伯来人所生的希伯来人；按照律法说，我是法利赛人；</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 1:13–14; 使徒行传 8:3; 使徒行传 26:9–10"> 按照热心说，我曾经逼迫教会；按照律法上的义说，我是无可指责的。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="路加福音 14:33; 马太福音 16:26; 马太福音 13:44–46"> 然而，以前对我有益的事，现在因基督的缘故，我已经把这些事看做是损失。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 9:23–24; 罗马书 8:18; 腓立比书 3:7"> 不但如此，我甚至把一切都看做是损失，因为我把认识我主基督耶稣看为是至高无上的。我为基督耶稣损失了一切，而且把一切都看做是粪土，为要赢得基督，</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 5:21; 哥林多前书 1:30; 加拉太书 2:16"> 并且要被认定在他里面——不是拥有那本于律法的自己的义，而是拥有那藉着信基督而来的义，就是来自神、基于信的义；</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 2:20; 罗马书 8:17; 彼得前书 4:1–2"> 并且为要认识基督和他复活的大能，要在他的苦难里相契合<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="相契合——或译作“沟通”或“分享”。">b</a></sup>，效法他的死，</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 20:35–36; 启示录 20:5; 使徒行传 23:6"> 或许我能得以从死人中复活。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="提摩太前书 6:11–12; 彼得后书 1:5–8; 诗篇 138:8"> 这并不是说我已经得到了，或已经得以完全了，而是说我在竭力追求，或许我真的可以得着<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="得着——原文直译“抓住”。">c</a></sup>；为此我也被基督耶稣得着<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="得着——原文直译“抓住”。">d</a></sup>了。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:62; 希伯来书 12:1–2; 腓立比书 3:12"> 弟兄们，我不认为自己已经得着<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="得着——原文直译“抓住”。">e</a></sup>了；但是我有一件事：就是忘记背后，争取前面的，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 9:24; 彼得前书 5:10; 启示录 3:21"> 向着目标竭力追求，为了得到<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="得到——辅助词语。">f</a></sup>那在基督耶稣里、神至高召唤的奖赏。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 7:17; 雅各书 1:4–5; 箴言 2:3–6"> 因此，让我们所有成熟的人<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="成熟的人——或译作“完全的人”。">g</a></sup>都这样思想。如果你们有什么不同的思想，神也会把这事启示给你们。</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 2:6; 启示录 3:3; 启示录 2:4–5"> 不过我们达到了什么标准<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本没有“标准”。">h</a></sup>，就让我们照着什么标准行走<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本附“照着什么思想行走”。">i</a></sup>。</span>
<span className="v" id="v17" data-v="17" data-xref="腓立比书 4:9; 哥林多前书 4:16; 彼得前书 5:3"> 弟兄们，你们要一同效法我，也要留心看那些像你们一样，以我们为榜样行事的人。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 4:17; 以赛亚书 8:11; 加拉太书 6:12"> 其实我过去再三地告诉你们，而现在又流着眼泪告诉你们：有许多人的行事为人，是基督十字架的仇敌。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 16:18; 罗马书 8:5–7; 彼得后书 2:3"> 他们的结局就是灭亡<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="灭亡——或译作“沉沦”。">j</a></sup>；他们的神就是自己的私欲<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="私欲——原文直译“肚腹”。">k</a></sup>；他们的荣耀在自己的羞耻之中；他们所思想的都是地上的事。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 2:19; 歌罗西书 3:1–3; 哥林多后书 4:18–1"> 然而，我们的国籍在天上；我们也热切等待着救主——主耶稣基督从那里降临。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 3:2; 歌罗西书 3:4; 哥林多前书 15:42–56"> 他将照着那能使万有都服从他的力量，改变我们这卑贱的身体，要<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本附“使它成为”。">l</a></sup>与他那荣耀的身体相似。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 1:1; 使徒行传 16:12–15; 罗马书 1:1"> 基督耶稣的奴仆保罗和提摩太，<br />致住在腓立比，在基督耶稣里的所有圣徒，包括各位监督和执事<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="执事——或译作“仆人”。">a</a></sup>：</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="罗马书 1:7; 哥林多后书 1:2; 彼得前书 1:2"> 愿恩典与平安从神我们的父和主耶稣基督临到你们！</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 1:4; 帖撒罗尼迦前书 1:2–3; 腓利门书 1:4–5"> 每当想到你们，我就感谢我的神；</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 1:2; 罗马书 1:9; 约翰二书 1:4"> 每次为你们大家祈祷的时候，我总是怀着喜乐的心祈祷，</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 4:14–15; 腓立比书 1:7; 希伯来书 3:14"> 因你们从第一天到如今，一直在福音工作上相契合<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="相契合——或译作“沟通”或“分享”。">b</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦前书 5:23–24; 腓立比书 2:13; 以弗所书 4:12"> 我正是深信这一点：就是在你们里面开始了美善工作的那一位，将会完成这工作，直到基督耶稣的日子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="日子——指“基督再来的日子”。">c</a></sup>。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 7:3; 腓立比书 1:5; 歌罗西书 4:18"> 我理当这样思念你们大家，因为你们常把我放在心上<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="你们常把我放在心上——或译作“我常把你们放在心上”。">d</a></sup>；无论我是在捆锁当中，还是在为福音辩护或做见证的时候，你们都是在恩典上与我一同有份。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比书 4:1; 罗马书 1:9; 提摩太后书 1:4"> 实际上，神可以为我见证：我是怎样以基督耶稣的情感，切切地想念你们大家的。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦前书 3:12; 歌罗西书 1:9; 彼得后书 1:5–6"> 我是这样祷告的：愿你们的爱心能在真正的知识和一切分辨力上，越来越丰足有余，</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 12:2; 帖撒罗尼迦前书 3:13; 帖撒罗尼迦前书 5:23"> 使你们能分辨是非<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="是非——或译作“那些更重要的事”。">e</a></sup>，好在基督的日子里是纯洁、无可指责的，</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 12:11; 约翰福音 15:8; 约翰福音 15:4–5"> 并且充满了那藉着耶稣基督而来的义行果子，归于神的荣耀和称赞。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="提摩太后书 2:9; 罗马书 8:28; 使徒行传 11:19–21"> 弟兄们，我愿你们知道，我的遭遇反而促进了福音的进展，</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太后书 2:9; 以弗所书 3:1; 腓立比书 1:7"> 以致整个王宫卫队<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="王宫卫队——原文直译“总督府”。">f</a></sup>和所有其余的人，都清楚我是为基督的缘故被捆锁的；</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所书 6:19–20; 帖撒罗尼迦前书 2:2; 路加福音 1:74"> 并且大多数的弟兄因着我所受的捆锁，就在主里深信不疑、无所惧怕，更加大胆地传讲这话语<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="这话语——有古抄本作“神的话语”。">g</a></sup>。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 16:17–18; 腓立比书 2:3; 哥林多后书 11:13"> 有些人传扬基督固然是出于嫉妒和纷争，但也有些人是出于好意。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 2:17; 哥林多后书 4:1–2; 诗篇 69:26"> 后者是出于爱，知道我是为辩护福音而受委派的；<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本作第17节。">h</a></sup></span>
<span className="v" id="v17" data-v="17" data-xref="提摩太后书 1:11–12; 腓立比书 2:3; 腓立比书 1:7"> 前者传讲基督是出于争竞<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="争竞——或译作“结党”。">i</a></sup>，不是出于真诚，想要在我的捆锁中，增加<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="增加——有古抄本作“唤起”。">j</a></sup>我的患难。<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="有古抄本作第16节。">k</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 9:50; 马可福音 9:38–40; 哥林多前书 15:11"> 这到底有什么关系呢？只是在各种方法中，无论是假意还是真心，基督都被传开了；我为此就欢喜，并且还要欢喜，</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 8:28; 使徒行传 16:7; 哥林多后书 1:11"> 因为我知道，藉着你们的祈祷和耶稣基督之灵的帮助，事情将为我转变以致我获救。</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前书 4:16; 哥林多前书 6:20; 以赛亚书 54:4"> 我的热切盼望和期待是：我在任何事上都将不至于蒙羞；而现在也能像往常一样，无论藉着生，还是藉着死，总要满有胆量地让基督在我身上被尊为大。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="加拉太书 2:20; 哥林多后书 5:8; 哥林多后书 5:1"> 因为对我来说，活着就是基督，死去就有益处。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 4:2; 加拉太书 2:20; 腓立比书 1:24"> 但如果我继续活在世上<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="在世上——原文直译“在肉身中”。">l</a></sup>，这就使我有工作的成果<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="成果——原文直译“果子”。">m</a></sup>，于是我不明白该怎样选择了。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 5:8; 诗篇 17:15; 启示录 14:13"> 我正处在两难之间：我渴望离世与基督在一起，因为这是好得无比的；</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 16:7; 腓立比书 1:22; 腓立比书 1:25–26"> 可是为了你们的缘故，我更需要留在世上<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="在世上——原文直译“在肉身中”。">n</a></sup>。</span>
<span className="v" id="v25" data-v="25" data-xref="腓立比书 2:24; 哥林多后书 1:24; 以弗所书 4:11–13"> 既然我深信这一点，就知道我会活下去<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="活下去——原文直译“留下来”。">o</a></sup>，并且将继续和你们大家在一起，好使你们在信仰上有长进、有喜乐。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多后书 1:14; 哥林多后书 5:12; 腓立比书 3:3"> 以致因着我再次到你们那里去，你们在基督耶稣里，对我的夸耀能充实满溢。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以弗所书 4:1; 哥林多前书 16:13–14; 哥林多前书 1:10"> 只是你们行事为人<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="行事为人——原文直译“像好公民那样生活”。">p</a></sup>要配得上基督的福音，好让我无论是来见你们，还是不在你们那里的时候，都可以听到有关你们的事，就是你们怀有一个心志站立得稳，同心合意地为福音的信仰一起奋战；</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太后书 1:7–8; 帖撒罗尼迦后书 1:5–6; 马太福音 10:28"> 在任何事上都不被反对你们的人吓倒——这对他们是灭亡<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="灭亡——或译作“沉沦”。">q</a></sup>的证明，而对你们却是得救的证明，并且这是出于神。</span>
<span className="v" id="v29" data-v="29" data-xref="雅各书 1:2; 彼得前书 4:13; 使徒行传 5:41"> 原来你们为基督所蒙的恩是：不仅要信基督，而且还要为他受苦，</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒罗尼迦前书 2:2; 使徒行传 16:19–40; 提摩太后书 4:7"> 去经历你们在我身上所看到、现在又听到的那同样的争战。</span>
</div>
</div>

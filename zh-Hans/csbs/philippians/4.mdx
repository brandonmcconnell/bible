<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="腓立比书 1:27; 哥林多前书 16:13; 诗篇 27:14"> 因此，我所爱的、所想念的弟兄们，我的喜乐、我的冠冕哪！各位蒙爱的人，你们当如此在主里站立得稳！</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 12:14; 哥林多前书 1:10; 马可福音 9:50"> 我恳求犹迪娅，也恳求辛图柯，要在主里同心合意。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 3:5; 启示录 13:8; 路加福音 10:20"> 是的，我真诚的同伴<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="同伴——原文直译“同负一轭的”。">a</a></sup>哪！我也请求你帮助她们两位<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="两位——辅助词语。">b</a></sup>。她们在福音工作上曾经与我、克莱门斯，和我的其他同工们一起奋战，这些人的名字都在生命册上。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 5:16–18; 罗马书 12:12; 雅各书 1:2–4"> 你们要在主里常常欢喜。我再说，你们要欢喜！</span>
<span className="v" id="v5" data-v="5" data-xref="雅各书 5:8–9; 马太福音 6:25; 提多书 3:2"> 要让所有人知道你们的谦和。主快到了！</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 3:5–6; 彼得前书 5:7; 马太福音 6:25–33"> 在任何事上都不要忧虑；然而要在一切事上，藉着祷告和祈求，以感谢的心把你们所求的告诉神。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 14:27; 以赛亚书 26:3; 帖撒罗尼迦后书 3:16"> 这样，神的平安——那高过一切理性的平安，就会在基督耶稣里保守你们的心、你们的意念。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="雅各书 3:17; 提多书 2:7; 罗马书 12:9–21"> 最后，弟兄们，凡是真实的、庄重的、公义的、纯洁的、可羡慕的、高尚的，如果有什么美德，如果有什么可称赞的，这些事你们就当思想；</span>
<span className="v" id="v9" data-v="9" data-xref="雅各书 1:22; 腓立比书 3:17; 帖撒罗尼迦前书 4:1–8"> 凡是你们在我身上所学到的、所领受的、所听到的、所看到的，这些事你们就当实行。这样，赐平安的神就会与你们同在。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 11:9; 加拉太书 6:6; 哥林多后书 7:6–7"> 我在主里极其欢喜，因为现在你们终于又萌发了思念我的心。其实你们一直在思念我，只是没有机会表达<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="表达——辅助词语。">c</a></sup>。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 6:6–9; 希伯来书 13:5–6; 马太福音 6:31–34"> 我这样说，并不是因为我缺少什么；事实上，我已经学会了在任何情况下都知足。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 11:29; 哥林多后书 12:7–10; 哥林多后书 11:27"> 我知道怎样处卑贱，也知道怎样处丰富；在一切事上，在一切情况下，或饱足、或饥饿，或丰富、或缺乏，我都得了秘诀。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 41:10; 哥林多后书 12:9–10; 歌罗西书 1:11"> 藉着使我刚强的那一位<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附“——基督”。">d</a></sup>，我一切都能。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 13:16; 腓立比书 1:7; 希伯来书 10:34"> 不过你们分担了我的患难，做得很好。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="腓立比书 1:5; 哥林多后书 11:8–12; 使徒行传 16:40–5"> 腓立比人哪，你们也知道，在福音工作的开始，我离开马其顿省的时候，在供给和领受的事上，除了你们以外，没有别的教会与我分享。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦前书 2:9; 使徒行传 17:1; 帖撒罗尼迦前书 2:18"> 就是我在帖撒罗尼迦的时候，你们甚至也一再地把我所需要的送来。</span>
<span className="v" id="v17" data-v="17" data-xref="提多书 3:14; 希伯来书 6:10; 哥林多后书 9:9–13"> 我并不是求什么供应，而是求你们的果子增多，归在你们的账上。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 13:16; 腓立比书 4:12; 哥林多后书 9:12"> 如今我一切都得到了，并且丰足有余。我已经得以满足了，因为我从以帕弗迪托接受了来自你们的东西；那是馨香的气味，是神所悦纳、所喜悦的祭物。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多后书 9:8–11; 诗篇 84:11; 彼得前书 5:10"> 我的神将按照他荣耀的丰盛，在基督耶稣里满足你们一切的需要。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 11:36; 诗篇 115:1; 启示录 14:7"> 愿荣耀归于神我们的父，直到永永远远！阿们。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="加拉太书 1:2; 腓利门书 1:23–24; 歌罗西书 4:10–14"> 请问候在基督耶稣里的每一位圣徒。与我在一起的弟兄们都问候你们；</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比书 1:13; 哥林多后书 13:13; 罗马书 16:16"> 所有的圣徒，尤其是来自凯撒宫里的人<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="凯撒宫里的人——或译作“凯撒家族的人”。">e</a></sup>，也都问候你们。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 13:14; 罗马书 16:20; 罗马书 16:23"> 愿主耶稣基督的恩典与你们的灵<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="你们的灵——有古抄本作“你们大家”。">f</a></sup>同在！<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附“阿们。”">g</a></sup></span>
</div>

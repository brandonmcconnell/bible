<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 3:12; 约翰一书 4:12; 约翰一书 4:7–8"> 所以，你们如果在基督里有任何鼓励、任何爱的安慰、任何圣灵里的契合<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="契合——或译作“沟通”或“分享”。">a</a></sup>、任何情感和怜悯，</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 12:16; 彼得前书 3:8–9; 哥林多前书 1:10"> 你们就要同心合意——爱心一致、灵里一致、意念一致，好使我的喜乐得以满足。</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 12:10; 加拉太书 5:26; 以弗所书 5:21"> 做任何事都不要出于争竞<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="争竞——或译作“结党”。">b</a></sup>，也不可出于虚荣，而要以谦卑的心，各人看别人比自己强；</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 10:24; 罗马书 15:1; 雅各书 2:8"> 每个人不要只注重自己的事，也要注重别人的事。</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="约翰一书 2:6; 马太福音 11:29; 彼得前书 2:21"> 你们应当有这样的意念，这也是基督耶稣的意念。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 5:18; 哥林多后书 4:4; 希伯来书 1:3"> <span className="pl pl-1">虽然他就是神本体的存在，</span><br /><span className="pl pl-1">却不把与神同等看做是一件要强抓不放的事，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 8:9; 马太福音 20:28; 约翰福音 1:14"> <span className="pl pl-1">反而倒空自己，</span><br /><span className="pl pl-1">取了奴仆的形像，成为人的样式，</span><br /><span className="pl pl-1">以人的形态出现，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 10:18; 希伯来书 12:2; 罗马书 5:19"> <span className="pl pl-1">降卑自己，顺从至死，</span><br /><span className="pl pl-1">甚至死在十字架上！</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="启示录 19:16; 马太福音 28:18; 彼得前书 3:22"> <span className="pl pl-1">因此神使他升为至高，</span><br /><span className="pl pl-1">赐给他那超越万名之上的名，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 45:23–25; 马太福音 28:18; 启示录 5:13–14"> <span className="pl pl-1">好使天上、地上和地底下的一切，</span><br /><span className="pl pl-1">因耶稣的名都屈膝，</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="约翰一书 4:15; 罗马书 14:11; 约翰福音 13:13"> <span className="pl pl-1">万口为了父神的荣耀</span><br /><span className="pl pl-1">要承认耶稣基督是主。</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彼得后书 1:5–10; 路加福音 13:23–24; 哥林多前书 15:58"> 因此，我亲爱的各位，既然你们一直是顺从的——不仅我在的时候如此，现今我不在的时候更加顺从——就当怀着敬畏和战兢的心，把你们的救恩行出来，</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 13:21; 哥林多后书 3:5; 提摩太后书 1:9"> 因为是神在你们里面运作，使你们愿意并且能行出他的美意。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 4:9; 哥林多前书 10:10; 腓立比书 2:3"> 做任何事都不要抱怨或争论<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="争论——或译作“算计”。">c</a></sup>，</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 5:14–16; 彼得前书 2:12; 马太福音 5:45"> 好使你们成为无可指责、纯洁无伪的人，在这扭曲、败坏的世代中，做神毫无瑕疵的儿女；在这世代中，要像星星的光辉一样照耀在世上。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 9:26; 加拉太书 2:2; 约翰一书 1:1"> 你们要持守生命的话语，好让我在基督的日子<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="日子——指“基督再来的日子”。">d</a></sup>里可以夸耀我所奔跑的没有落空，我所劳苦的也没有落空。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太后书 4:6; 罗马书 15:16; 希伯来书 13:15–16"> 然而，即使我被做为奠祭，浇在你们信仰的祭物和服事上，我也欢喜，并且和你们大家一同欢喜；</span>
<span className="v" id="v18" data-v="18" data-xref="雅各书 1:2–4; 腓立比书 4:4; 腓立比书 3:1"> 你们也应该照样欢喜，并且与我一同欢喜。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 4:17; 帖撒罗尼迦前书 3:6–8; 帖撒罗尼迦前书 3:2"> 我在主耶稣里，希望不久能派提摩太到你们那里去，好让我也知道有关你们的事，可以心情愉快。</span>
<span className="v" id="v20" data-v="20" data-xref="腓立比书 2:2; 哥林多前书 16:10; 腓立比书 2:22"> 实际上，我没有别的人与我同心，真正地挂虑你们的事；</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 10:24; 马太福音 16:24; 腓立比书 2:4"> 因为大家都寻求自己的事，不寻求耶稣基督的事。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 4:17; 哥林多后书 2:9; 提摩太后书 1:2"> 但是，你们是知道提摩太那经过考验的品德。因为他在福音工作上与我一起服事<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="服事——原文直译“做奴仆”。">e</a></sup>，就像儿子与父亲那样。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 22:3; 腓立比书 2:19"> 所以我希望，一旦知道我的事有什么结局<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有什么结局——辅助词语。">f</a></sup>，就立即派他去。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰三书 1:14; 腓利门书 1:22; 腓立比书 1:25–26"> 不过我在主里深信，我自己不久也会去的。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="腓立比书 4:18; 腓利门书 1:1–2; 腓立比书 4:3"> 然而，我认为必须派以帕弗迪托到你们那里去；他是我的弟兄、同工、战友，也是你们的使者，是为我的需要而来的服事者，</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 12:15; 箴言 12:25; 以弗所书 3:13"> 因为他一直切切地想念你们大家，并且因你们听说他患了病，他就极其难过。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 34:19; 腓立比书 2:30; 诗篇 103:3–4"> 事实上，他虽然患了病几乎死去，可是神怜悯了他；不仅怜悯他，也怜悯了我，免得我忧上加忧。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 16:22; 提摩太后书 1:4; 腓立比书 2:26–27"> 所以，我就更迫切地派他去，好让你们见到他，能够再次欢喜，而我也可以少些挂虑。</span>
<span className="v" id="v29" data-v="29" data-xref="帖撒罗尼迦前书 5:12; 哥林多前书 16:18; 提摩太前书 5:17"> 因此，你们要在主里满怀喜乐地欢迎他，也要敬重这样的人，</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前书 16:17; 使徒行传 20:24; 腓立比书 4:10"> 因为他为了基督的工作，几乎至死，冒了生命的危险，为要弥补你们服事我的缺乏。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 4:2; 罗马书 12:12; 帖撒罗尼迦前书 5:17"> 耶稣对他们讲了一个比喻，说他们必须常常祷告，不要丧胆。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 29:7; 诗篇 8:1–4; 路加福音 18:4"> 他说：<span className="woj">“某城里有一个审判官，他既不敬畏神，也不尊重人。</span></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 1:17; 耶利米书 5:28; 申命记 27:19"> <span className="woj">那城里有一个寡妇，经常到他那里去，说：‘请为我向我的对头讨个公道。’</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="希伯来书 4:12–13; 路加福音 16:3; 路加福音 12:17"> <span className="woj">“法官一直不肯，但是后来心里说：‘即使我不敬畏神，也不尊重人，</span></span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 11:8; 路加福音 18:39; 士师记 16:16"> <span className="woj">还是因为这寡妇不断地烦扰我，我就为她讨个公道，免得她一直来，到最后使我疲惫不堪！’”</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="路加福音 7:13"> 主接着说：<span className="woj">“你们当听这个不公义的审判官所说的！</span></span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 10:35–37; 彼得后书 3:9; 路加福音 11:13"> <span className="woj">难道神绝不会给那些他所拣选、日夜向他呼求的人主持公道吗？难道神会耽误帮助</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="帮助——辅助词语。">a</a></sup><span className="woj">他们吗？</span></span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 10:23–26; 彼得后书 3:8–9; 马太福音 24:9–13"> <span className="woj">我告诉你们：他会很快地给他们主持公道。不过人子回来的时候，难道在地上能找到这样的信仰吗？”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 16:15; 箴言 30:12; 以赛亚书 65:5"> 耶稣还对某些自以为义而藐视其他人的，讲了这个比喻：</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 21:31–32; 列王纪上 8:30; 列王纪下 20:5"> <span className="woj">“有两个人上圣殿去祷告。一个是法利赛人，另一个是税吏。</span></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 6:5; 以赛亚书 65:5; 启示录 3:17"> <span className="woj">那法利赛人站着，向自己祷告这些话</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="那法利赛人站着，向自己祷告这些话——或译作“那法利赛人独自站着，这样祷告说”。">b</a></sup><span className="woj">：‘神哪，我感谢你，因为我不像其他人那样：勒索、不义、通奸，也不像这个税吏。</span></span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 11:42; 马太福音 23:23–24; 马太福音 9:14"> <span className="woj">我一周禁食两次，并奉献我所有收入的十分之一。’</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 9:6; 约翰一书 1:8–10; 提摩太前书 1:15"> <span className="woj">“那税吏却远远地站着，甚至不敢举目望天，可是捶着胸说：‘神哪，你宽恕我这个罪人吧！’</span></span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 14:11; 路加福音 16:15; 雅各书 4:10"> <span className="woj">我告诉你们：下去回家时已经被称为义的是这个税吏，而不是那个法利赛人。因为每一个自我高举的都会被降卑；而自我降卑的都会被高举。”</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="马可福音 10:13–16; 马太福音 19:13–15; 撒母耳记上 1:24"> 有些人把婴孩也带到耶稣那里，好让耶稣摸他们一下。门徒们看见了却责备那些人。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 18:3–4; 哥林多前书 14:20; 哥林多前书 7:14"> 但耶稣把他们叫过来，说：<span className="woj">“让小孩子到我这里来，不要阻止他们，因为神的国正属于这样的人。</span></span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 18:3; 马可福音 10:15; 诗篇 131:1–2"> <span className="woj">我确实地告诉你们：无论谁不像小孩子一样接受神的国，就绝不能进去。”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马可福音 10:17–31; 使徒行传 16:30; 马太福音 19:16–30"> 有一个首领问耶稣，说：“良善的老师，我该做什么才会继承永恒的生命呢？”</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="约伯记 15:14–16; 雅各书 1:17; 希伯来书 7:26"> 耶稣对他说：<span className="woj">“你为什么称我是良善的呢？除了神一位之外，没有一个是良善的。</span></span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 20:12–17; 申命记 5:16–21; 罗马书 13:9"> <span className="woj">你是知道这些诫命的：</span><br /><span className="pl pl-1 woj">‘不可通奸、</span><br /><span className="pl pl-1 woj">不可杀人、</span><br /><span className="pl pl-1 woj">不可偷窃、</span><br /><span className="pl pl-1 woj">不可做伪证、</span><br /><span className="pl pl-1 woj">要孝敬父母。’</span><br /><span className="pl pl-1 woj">”</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="腓立比书 3:6; 罗马书 10:2–3; 马可福音 10:20–21"> 那个人说：“这一切我从年少就遵守了。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 12:33; 提摩太前书 6:18–19; 马太福音 19:21"> 耶稣听了就对他说：<span className="woj">“你还缺少一件：把你所拥有的一切都卖掉，分给穷人，这样你将有财宝在天上；然后你来跟从我。”</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以西结书 33:31; 约翰一书 2:15; 约伯记 31:24–25"> 那个人听了这些话就变得很忧愁，因为他极其富有。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="箴言 30:9; 雅各书 2:5–7; 马可福音 10:23–27"> 耶稣看见他变得很忧愁<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本没有“变得很忧愁”。">c</a></sup>，就说：<span className="woj">“有钱财的人进入神的国，是多么困难！</span></span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 23:24"> <span className="woj">骆驼穿过针眼，比富有的人进入神的国更容易呢！”</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 13:23"> 听见的人就说：“那么，谁能得救呢？”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米书 32:17; 马太福音 19:26; 路加福音 1:37"> 耶稣说：<span className="woj">“在人不可能的事，在神都是可能的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马可福音 10:28; 腓立比书 3:7; 马太福音 19:27"> 彼得说：“看，我们舍弃自己所拥有的<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="自己所拥有的——有古抄本作“一切”。">d</a></sup>，跟从了你！”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马可福音 10:29–31; 马太福音 10:37–39; 路加福音 14:26–28"> 耶稣对他们说：<span className="woj">“我确实地告诉你们：没有谁为神国的缘故舍弃房屋，或妻子，或兄弟，或父母，或儿女，</span></span>
<span className="v" id="v30" data-v="30" data-xref="希伯来书 13:5–6; 约伯记 42:10; 启示录 2:17"> <span className="woj">而不会在今世得到许多倍，在来世得到永恒生命的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马太福音 20:17–19; 以赛亚书 53:1–12; 诗篇 22:1–31"> 耶稣把十二使徒<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="使徒——辅助词语。">e</a></sup>带到一边，对他们说：<span className="woj">“看，我们现在上耶路撒冷去，那藉着先知们所写的一切有关人子的事，都要成就。</span></span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 23:11; 以赛亚书 50:6; 以赛亚书 53:3"> <span className="woj">要知道，他将被交给外邦人，被戏弄、受凌辱、被人吐唾沫；</span></span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 15:3–4; 路加福音 24:7; 马太福音 27:63"> <span className="woj">他们要鞭打他，并杀害他；然后在第三天，他要复活。”</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="路加福音 9:45; 马可福音 9:32; 路加福音 24:25"> 但门徒们一点也不领悟这些话。这话对他们是隐藏的，他们不知道他在说什么。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 20:29–34; 马可福音 10:46–52; 路加福音 16:20–21"> 耶稣快到耶利哥的时候，有一个瞎眼的坐在路边乞讨。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 21:10–11; 路加福音 15:26"> 他听见人群经过那里，就问到底是什么事。</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 2:23; 约翰福音 19:19; 约翰福音 12:35–36"> 有人告诉他：“拿撒勒人耶稣经过这里。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="马太福音 9:27; 路加福音 18:39; 马太福音 15:22"> 他就呼喊说：“耶稣啊，大卫的后裔<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="大卫的后裔——或译作“大卫之子”。">f</a></sup>，可怜我吧！”</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 32:26–28; 诗篇 141:1; 路加福音 18:15"> 走在前头的人就责备他，要他安静。可是，他却更加大声呼叫：“大卫的后裔<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="大卫的后裔——或译作“大卫之子”。">g</a></sup>，可怜我吧！”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="马太福音 20:31–34; 马可福音 10:48–52"> 耶稣就停住，吩咐把他带到他面前来；那人走近了，耶稣就问他：</span>
<span className="v" id="v41" data-v="41" data-xref="列王纪上 3:5–15; 马太福音 20:21–22; 腓立比书 4:6"> <span className="woj">“你要我为你做什么呢？”</span><br />他说：“主啊，我要重见光明！”</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="马太福音 8:3; 路加福音 8:48; 路加福音 17:19"> 耶稣对他说：<span className="woj">“你重见光明吧！你的信救了你。”</span></span>
<span className="v" id="v43" data-v="43" data-xref="诗篇 146:8; 帖撒罗尼迦后书 1:10–12; 以赛亚书 43:21"> 他立刻重见光明，于是跟随耶稣，一路上荣耀神。民众都看到了，就赞美神。</span>
</div>
</div>

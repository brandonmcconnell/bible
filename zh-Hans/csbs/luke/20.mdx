<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 21:23–27; 路加福音 19:47–48; 使徒行传 6:12"> 就在那些日子里，有一天耶稣在圣殿里教导民众、传福音的时候，祭司长们、经文士们和长老们一起上前来，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 2:14; 马可福音 11:28–33; 约翰福音 2:18"> 对他说：“请告诉我们：你凭什么权柄做这些事？是谁给你这权柄的？”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马太福音 15:2–3; 路加福音 22:68; 歌罗西书 4:6"> 耶稣回答他们，说：<span className="woj">“我也要问你们一个问题，你们告诉我：</span></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 15:18; 马太福音 11:7–19; 马太福音 17:11–12"> <span className="woj">约翰的洗礼是来自天上，还是来自人间呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 1:34; 约翰福音 1:15–18; 约翰福音 1:30"> 他们就彼此商量，说：“如果我们说‘是来自天上’，他就会问‘你们为什么不相信他呢？’</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 21:26; 马太福音 11:9; 约翰福音 10:41"> 但如果说‘是来自人间’，那么民众都会用石头砸我们，因为他们深信约翰是先知。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 29:14; 彼得后书 3:3; 以赛亚书 41:28"> 于是他们回答：“不知道是从哪里来的。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="箴言 26:4–5; 马太福音 21:27; 马可福音 11:33"> 耶稣就对他们说：<span className="woj">“我也不告诉你们我凭什么权柄做这些事。”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马太福音 21:33–46; 马可福音 12:1–12; 以赛亚书 5:1–7"> 接着，耶稣开始对民众讲这个比喻：<span className="woj">“有一个人栽种了一个葡萄园，把它租给一些农夫，然后就出外旅行，去了许久。</span></span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 36:15–16; 尼希米记 9:26; 马太福音 21:34–36"> <span className="woj">到了收获的</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="收获的——辅助词语。">a</a></sup><span className="woj">季节，他就派了一个奴仆到那些农夫那里去，好让他们从葡萄园的果子中把当纳的</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="当纳的——辅助词语。">b</a></sup><span className="woj">交给他。但那些农夫打了他，叫他空手回去。</span></span>
<span className="v" id="v11" data-v="11" data-xref="何西阿书 10:1; 希伯来书 11:36–37; 帖撒罗尼迦前书 2:2"> <span className="woj">园主又派另一个奴仆去，可是他们把那个人也打了，并且侮辱他，叫他空手回去。</span></span>
<span className="v" id="v12" data-v="12"> <span className="woj">于是，他又派了第三个人去，他们又把这个人打伤，赶了出去。</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马太福音 3:17; 约翰福音 3:16–17; 耶利米书 36:7"> <span className="woj">“葡萄园的主人就说：‘我该做什么呢？我要派遣我的爱子，或许他们</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附“看见”。">c</a></sup><span className="woj">会尊重他。’</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="罗马书 8:17; 希伯来书 1:2; 使徒行传 2:23"> <span className="woj">“可是那些农夫看见他，就彼此讨论说：‘这是继承人。</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附“来，”。">d</a></sup><span className="woj">我们把他杀了，那继业就成为我们的了。’</span></span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 13:12; 马可福音 12:6–9; 马太福音 21:37–40"> <span className="woj">于是他们把他扔出葡萄园外，杀了。</span><br /><span className="woj">“那么，葡萄园的主人会怎么对待他们呢？</span></span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:27; 使徒行传 13:46; 马太福音 21:41"> <span className="woj">他会来除灭这些农夫，把葡萄园交给别人。”</span><br />大家听了就说：“绝不可有这样的事！”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="诗篇 118:22; 以赛亚书 28:16; 使徒行传 4:11"> 耶稣注视着他们，说：<span className="woj">“那么，经上记的‘工匠所弃绝的石头，它已经成了房角的头块石头’这话是什么意思呢？</span></span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 8:14–15; 撒迦利亚书 12:3; 但以理书 2:44–45"> <span className="woj">所有跌落在那石头上的，就将被破碎；那石头落在谁的身上，就会把谁砸得稀烂。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 19:47–48; 路加福音 20:14; 马太福音 21:45–46"> 经文士和祭司长们知道这个比喻是针对他们而说的，当时就想下手捉拿耶稣，可是又怕民众。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 11:54; 马太福音 22:15–22; 马太福音 27:2"> 于是，他们密切注意，派了一些奸细装做好人，要抓耶稣的话柄，好把他交在总督的管理和权柄之下。</span>
<span className="v" id="v21" data-v="21" data-xref="帖撒罗尼迦前书 2:4–5; 马太福音 26:49–50; 马太福音 22:16"> 那些奸细问耶稣，说：“老师，我们知道你所说所教导的都是对的，你也不顾人的情面，而是按真理教导神的道<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="道——或译作“路”。">e</a></sup>。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米记 9:37; 马可福音 12:14–17; 使徒行传 5:37"> 请问：我们向凯撒纳税，可以不可以呢？”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 22:18; 哥林多前书 3:19; 路加福音 5:22"> 耶稣看出他们的诡诈，就对他们说：<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附“你们为什么试探我呢？”">f</a></sup></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 18:28; 使徒行传 11:28; 使徒行传 26:32"> <span className="woj">“拿一个银币</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="银币——原文为“得拿利”。1得拿利=约1日工资的罗马银币。">g</a></sup><span className="woj">给我看。这上面是谁的像和名号？”</span><br />他们说：“是凯撒的。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="罗马书 13:6–7; 马可福音 12:17; 彼得前书 2:13–17"> 耶稣对他们说：<span className="woj">“因此，凯撒的归给凯撒；神的归给神。”</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 20:20; 箴言 26:4–5; 提多书 1:10"> 他们在民众面前抓不到耶稣的话柄，又对他的答复感到惊奇，就哑口无言了。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行传 4:1–2; 哥林多前书 15:12; 马可福音 12:18–27"> 撒都该人来到耶稣那里，他们一向说没有复活的事。他们问耶稣，</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 25:5–10; 创世记 38:8; 创世记 38:11"> 说：“老师，摩西为我们写道：如果一个人的兄弟死了，留下妻子而没有孩子，他就应该娶这妇人，为他兄弟留后裔。</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 20:20; 耶利米书 22:30"> 曾经有兄弟七人，第一个娶了妻子，没有孩子就死了。</span>
<span className="v" id="v30" data-v="30"> 第二个、<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="第二个、——有古抄本作“第二个娶她为妻，也没有孩子就死了；”。">h</a></sup></span>
<span className="v" id="v31" data-v="31"> 第三个也娶了她；七个人都是这样，没有留下儿女就死了。</span>
<span className="v" id="v32" data-v="32" data-xref="传道书 1:4; 传道书 9:5; 希伯来书 9:27"> 后来这妇人也死了。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 22:24–28; 马可福音 12:19–23"> 既然这七个人都娶过她为妻，那么，在复活的时候，这妇人是谁的妻子呢？”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="路加福音 16:8; 路加福音 17:27; 希伯来书 13:4"> 耶稣对他们说：<span className="woj">“这世代的儿女又娶又嫁；</span></span>
<span className="v" id="v35" data-v="35" data-xref="帖撒罗尼迦后书 1:5; 约翰福音 5:29; 但以理书 12:2–3"> <span className="woj">但那些算是配得上承受那世代，又配得上从死人中复活的人，既不娶也不嫁。</span></span>
<span className="v" id="v36" data-v="36" data-xref="启示录 21:4; 腓立比书 3:21; 马太福音 22:30"> <span className="woj">事实上，他们再也不会死，因为就与天使一样；他们既然是复活的儿女，就是神的儿女了。</span></span>
<span className="v" id="v37" data-v="37" data-xref="出埃及记 3:2–6; 马可福音 12:26–27; 使徒行传 7:30–32"> <span className="woj">至于死人复活的事，摩西在‘荆棘篇’上也指明了，正如称主是‘亚伯拉罕的神、以撒的神、雅各的神。’</span></span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 11:25–26; 歌罗西书 3:3–4; 罗马书 6:10–11"> <span className="woj">所以神不是死人的神，而是活人的神；在神，人都是活着的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒行传 23:9; 马可福音 12:28–34; 马太福音 22:34–40"> 有一些经文士应声说：“老师，你说得好。”</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 22:46; 马可福音 12:34; 箴言 26:5"> 从此他们再也不敢质问他什么了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v41" data-v="41" data-xref="马可福音 12:35–37; 马太福音 1:1; 马太福音 22:41–45"> 耶稣对他们说：<span className="woj">“人怎么说基督是大卫的后裔呢？</span></span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 110:1; 使徒行传 2:34–35; 希伯来书 1:13"> <span className="woj">大卫自己在诗篇里说：</span><br /><span className="pl pl-1 woj">‘主对我主说：</span><br /><span className="pl pl-1 woj">你坐在我的右边，</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 19:27; 诗篇 110:1; 启示录 19:14–21"> <span className="pl pl-1 woj">等我把你的敌人放在你的脚下做脚凳。’</span></span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="启示录 22:16; 路加福音 1:31–35; 马太福音 1:23"> <span className="woj">大卫既然称基督为‘主’，基督又怎么会是大卫的后裔呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="马太福音 15:10; 马可福音 12:38–39; 马可福音 8:34"> 全体民众正在听的时候，耶稣对他的门徒说：</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 11:43; 马可福音 12:38–39; 路加福音 14:7"> <span className="woj">“你们要提防经文士。他们喜欢穿着长袍走来走去，喜爱街市上的致敬问候，又喜爱会堂里的首位、宴席中的上座。</span></span>
<span className="v" id="v47" data-v="47" data-xref="马可福音 12:40; 雅各书 3:1; 提多书 1:16"> <span className="woj">他们侵吞寡妇的家产，又假意做很长的祷告。这些人将受到更重的惩罚</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="惩罚——或译作“审判”。">i</a></sup><span className="woj">。”</span></span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 4:17–18; 耶利米哀歌 2:20; 以西结书 9:5–7"> 正在那时候，有些人前来告诉耶稣有关加利利人的事，就是彼拉多把加利利人的血与他们的祭物混在一起的事。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 9:2; 使徒行传 28:4; 约伯记 22:5–16"> 耶稣<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="耶稣——有古抄本作“他”。">a</a></sup>回答他们，说：<span className="woj">“你们以为这些加利利人如此受害，是因为他们比其他</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="其他——辅助词语。">b</a></sup><span className="woj">所有加利利人更有罪吗？</span></span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 3:19; 马太福音 3:2; 使徒行传 2:38–40"> <span className="woj">不是的。我告诉你们：你们如果不悔改，都会同样地灭亡。</span></span>
<span className="v" id="v4" data-v="4" data-xref="尼希米记 3:15; 约伯记 1:19; 约翰福音 9:11"> <span className="woj">或者，西罗亚楼倒塌压死的那十八个人，你们以为他们比所有住在耶路撒冷的人更有罪吗？</span></span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 18:30; 路加福音 13:3; 以赛亚书 28:10–13"> <span className="woj">不是的。我告诉你们：你们如果不悔改，都会同样灭亡。”</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约翰福音 15:16; 以赛亚书 5:1–4; 加拉太书 5:22"> 于是耶稣讲了这个比喻：<span className="woj">“一个人有一棵无花果树栽在自己的葡萄园里。当他过来，在那树上找果子时，却找不到，</span></span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 7:19; 路加福音 3:9; 约翰福音 15:6"> <span className="woj">就对园丁说：‘你看，一连三年，我在这无花果树上找果子，都找不到。把它砍了吧！何必让它白占土地？’</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="彼得后书 3:9; 约珥书 2:17; 罗马书 10:1"> <span className="woj">“但是园丁回答，对他说：‘主人，今年再留着它吧。等我在它周围挖掘，施些粪肥，</span></span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 15:2; 帖撒罗尼迦前书 2:15; 希伯来书 6:8"> <span className="woj">或许它来年真会结出果子，否则，你就砍了它。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 4:23; 路加福音 4:44; 路加福音 4:15–16"> 在安息日，耶稣在一个会堂里教导人，</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 8:2; 路加福音 8:27; 路加福音 13:16"> 看哪，有一个妇人，被邪灵附身病了十八年，一直弯着腰，完全直不起身来。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 107:20; 马太福音 8:16; 路加福音 6:8–10"> 耶稣看见她，就招呼她，对她说：<span className="woj">“妇人，你已经从你的疾病中被释放了！”</span></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 107:20–22; 马可福音 16:18; 马可福音 5:23"> 然后耶稣按手在她身上，她的腰立刻直了，她就不住地荣耀神。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及记 20:9; 马太福音 12:2; 约翰福音 9:14–16"> 因为耶稣在安息日使人痊愈，会堂主管就很生气，对那群人说：“应该做工的日子有六天，所以你们在那些日子来得痊愈吧！但不要在安息日这一天。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 14:5; 约翰福音 7:21–24; 使徒行传 13:9–10"> 主回答他，说：<span className="woj">“你们这些伪善的人！难道你们每个人在安息日，不也是把自己的牛或驴从槽边解开，牵去饮水吗？</span></span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 2:27; 提摩太后书 2:26; 路加福音 19:9"> <span className="woj">何况这妇人，做为亚伯拉罕的子孙</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="子孙——原文直译“女儿”。">c</a></sup><span className="woj">，被撒旦所捆绑竟然有十八年，难道不应该在安息日这一天从捆锁中被释放吗？”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="彼得前书 3:16; 诗篇 132:18; 以赛亚书 45:24"> 耶稣说了这些话，所有反对他的人都感到蒙羞，可是众人都因他所行的一切荣耀的事而感到欢喜。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马可福音 4:30–34; 路加福音 17:21; 马太福音 13:31–32"> 于是耶稣说：<span className="woj">“神的国好比什么呢？我要把它比做什么呢？</span></span>
<span className="v" id="v19" data-v="19" data-xref="但以理书 4:12; 但以理书 4:21; 但以理书 2:44–45"> <span className="woj">它好比一粒芥菜种子，有人拿去种在自己的园子里，种子长大，成了一棵树</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="树——有古抄本作“大树”。">d</a></sup><span className="woj">，天空的飞鸟也在它的枝子上搭窝。”</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 耶稣又说：<span className="woj">“我要把神的国比做什么呢？</span></span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 13:33; 哥林多前书 5:6; 帖撒罗尼迦前书 5:23–24"> <span className="woj">它好比酵母，一个妇人拿去拌在</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="拌在——原文直译“藏在”。">e</a></sup><span className="woj">三斗</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="三斗——原文为“3撒顿”；容量约为22公升。1撒顿=7.3公升。">f</a></sup><span className="woj">面里，直到整团面都发了酵。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 9:51; 马太福音 9:35; 马可福音 10:32–34"> 耶稣走遍许多城镇、乡村教导人，并继续往耶路撒冷前行。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 7:14; 马太福音 22:14; 约翰福音 21:21–22"> 有一个人问他：“主啊，得救的人很少吗？”<br />耶稣对他们说：</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 7:13–14; 彼得后书 1:10; 哥林多前书 9:24–27"> <span className="woj">“你们要为进窄门而争战，因为我告诉你们：将有许多人想要进去，却是不能。</span></span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 25:10–12; 路加福音 13:27; 马太福音 7:21–23"> <span className="woj">等到那家的主人起来关了门，你们才开始站在外面敲门，说：‘主啊，请给我们开门！’主人就会回答你们，说：‘我不知道你们是从哪里来的。’</span></span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 58:2; 提多书 1:16; 提摩太后书 3:5"> <span className="woj">那时你们就开始说：‘我们曾经在你面前吃过、喝过，你也曾经在我们的大街</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="大街——或译作“广场”。">g</a></sup><span className="woj">上教导过！’</span></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 6:8; 马太福音 25:41; 马太福音 7:22–23"> <span className="woj">他要对你们说：‘我不知道你们是从哪里来的。离开我，你们所有不义的工人！’</span></span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 8:11–12; 马太福音 22:13; 马太福音 25:30"> <span className="woj">当你们看见亚伯拉罕、以撒、雅各和所有的先知在神的国里，而你们却被丢在外面的时候，在那里将有哀哭和切齿。</span></span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 43:6; 以赛亚书 66:18–20; 以赛亚书 49:6"> <span className="woj">人们将从东、西、南、北而来，在神的国里坐席。</span></span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 19:30; 马可福音 10:31; 马太福音 20:16"> <span className="woj">看哪，有些在后的，将要在前；有些在前的，将要在后。”</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="尼希米记 6:9–11; 诗篇 11:1–2; 马太福音 14:1"> 就在这时候<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="这时候——原文直译“同一时候”。">h</a></sup><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="时候——有古抄本作“天”。">i</a></sup>，有一些法利赛人前来对耶稣说：“你离开吧，从这里走开！因为希律想要杀你。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="希伯来书 2:10; 希伯来书 5:9; 约翰福音 17:4–5"> 耶稣对他们说：<span className="woj">“你们去告诉那狐狸：看哪！今天明天我驱赶鬼魔、治愈疾病，然后在第三天，我的事就得以完成了。</span></span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 9:53; 马太福音 21:11; 使徒行传 13:27"> <span className="woj">不过今天、明天、后天，我必须往前走，因为先知不能在耶路撒冷之外被杀！</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马太福音 23:37–39; 申命记 32:11–12; 使徒行传 7:52"> <span className="woj">“耶路撒冷啊，耶路撒冷！这城杀害先知们，又用石头砸死被差到她这里的人！我多次想聚集你的儿女，像母鸡把自己的小鸡聚集在翅膀下，可是你们不愿意！</span></span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 118:26; 马可福音 11:9–10; 马太福音 21:9"> <span className="woj">看哪，你们的家</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="家——或译作“殿”；指“圣殿”。参《耶利米书》12:7；22:5。">j</a></sup><span className="woj">要被废弃</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="有古抄本附“成为荒场”。">k</a></sup><span className="woj">。我</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本附“确实地”。">l</a></sup><span className="woj">告诉你们：你们绝不会再见到我了，直到那日子来临，就是你们说‘奉主名而来的那一位是蒙祝福的’那时候。”</span></span>
</div>

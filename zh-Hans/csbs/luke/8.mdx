<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 4:23; 罗马书 10:15; 马太福音 9:35"> 不久以后，耶稣走遍各个城镇乡村，讲道、传神国的福音。与他在一起的有十二使徒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="使徒——辅助词语。">a</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 16:9; 马太福音 27:55–56; 马可福音 15:40–41"> 还有一些从邪灵和疾病中被解脱出来<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="被解脱出来——辅助词语。">b</a></sup>、得了痊愈的妇女，其中有那称为茉大拉的玛丽亚，从她身上曾经有七个鬼魔被赶出来，</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 4:46–53; 哥林多后书 8:9; 使徒行传 9:36–39"> 又有希律的管家苦撒的妻子约亚娜，以及苏珊娜和许多别的妇女，她们都用自己所拥有的来服事耶稣和门徒们<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="耶稣和门徒们——原文直译“他们”；有古抄本作“他”。">c</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="马可福音 4:1–9; 马太福音 13:2–9"> 那时，有一大群人聚集，又有人从各城镇来到耶稣那里，耶稣就用比喻说：</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 2:1; 雅各书 1:23–24; 马可福音 4:15"> <span className="woj">“有一个撒种的出去撒种。他撒的时候，有的种子落在路边，被人践踏，天空的飞鸟也把它吃掉了。</span></span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 3:7–8; 路加福音 8:13; 马可福音 4:5–6"> <span className="woj">有的落在岩石上，一长出来就枯萎了，因为得不到水份。</span></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 4:3; 路加福音 8:14; 路加福音 21:34"> <span className="woj">有的落进荆棘丛里，荆棘与它一起生长，把它挤住了。</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 11:15; 启示录 2:11; 启示录 2:7"> <span className="woj">但另有落进好土壤里的，长起来，结出百倍的果实。”</span>耶稣讲完这些话，就大声说：<span className="woj">“凡是有耳可听的，就应当听！”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="马可福音 4:10; 马太福音 13:10; 马太福音 13:18"> 耶稣的门徒们问他这比喻到底是什么意思。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 6:9; 马可福音 4:11; 马太福音 11:25"> 他说：<span className="woj">“神国的奥秘已经赐下来让你们知道，但是对其他的人就用比喻。这是为要使</span><br /><span className="pl pl-1 woj">‘他们看，却看不见；</span><br /><span className="pl pl-1 woj">听，却不领悟。’</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马太福音 13:19; 马可福音 4:14–20; 雅各书 1:21"> <span className="woj">“原来，这个比喻是这样的。那种子就是神的话语</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="神的话语——或译作“神的道”。">d</a></sup><span className="woj">。</span></span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦后书 2:9–14; 启示录 12:9; 雅各书 1:23–24"> <span className="woj">那‘路边之地’，是这样的人：他们听了这话语，然后魔鬼就来，从他们心里把话语夺走，免得他们信而得救。</span></span>
<span className="v" id="v13" data-v="13" data-xref="何西阿书 6:4; 约翰福音 5:35; 箴言 12:12"> <span className="woj">那‘岩石’，是这样的人：他们一旦听了，就怀着喜乐的心接受了这话语；可是这些人没有根，他们暂时相信，而在试炼的时候，就离开信仰</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="离开信仰——或译作“背弃”。">e</a></sup><span className="woj">了。</span></span>
<span className="v" id="v14" data-v="14" data-xref="约翰一书 2:15–17; 提摩太前书 6:9–10; 提摩太前书 6:17"> <span className="woj">种子落在其中的那‘荆棘丛’，是这样的人：他们听了，却走自己的路</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="自己的路——辅助词语。">f</a></sup><span className="woj">，被今生的忧虑、财富和享乐挤住了，结不出成熟的果实。</span></span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 10:36; 加拉太书 5:22–26; 歌罗西书 1:10"> <span className="woj">那‘好土壤’，是这样的人：他们听了这话语，以诚实美善的心持守它，并且在忍耐中结出果实。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 11:33; 马太福音 5:15–16; 马可福音 4:21–22"> <span className="woj">“没有人点上油灯，用器皿盖住或放在床底下，而是放在灯台上，好让进来的人能看见光。</span></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 12:2–3; 马太福音 10:26; 马可福音 4:22"> <span className="woj">隐秘的事没有不显露的，隐藏的事绝没有不被知道、不显露出来的。</span></span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 13:12; 路加福音 19:26; 马可福音 4:23–25"> <span className="woj">所以，你们要留心怎样去听；因为凡是有的，还要赐给他；凡是没有的，连他自以为有的也将从他那里被拿走。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马太福音 12:46–50; 马可福音 3:31–35; 马可福音 3:21"> 耶稣的母亲和弟弟们<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="弟弟们——原文直译“兄弟们”。">g</a></sup>来到他那里，可是由于人多，不能靠近他。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 1:14; 马可福音 6:3; 马太福音 13:55–56"> 有人告诉他：“你母亲和弟弟们站在外面，想要见你。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 11:27–28; 雅各书 1:22; 约翰福音 13:17"> 耶稣回答他们，说：<span className="woj">“我的母亲、我的弟兄，是那些听神的话语</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="神的话语——或译作“神的道”。">h</a></sup><span className="woj">而遵行的人。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马太福音 8:23–27; 马可福音 4:35–41; 马可福音 6:45"> 就在那些日子里，有一天耶稣和他的门徒们上了船，耶稣对他们说：<span className="woj">“我们渡到湖对岸去吧。”</span>他们就出发了。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 93:3–4; 诗篇 124:2–4; 诗篇 148:8"> 船行的时候，耶稣睡着了。这时候，暴风降临到湖上，他们不断地被水浸灌，情况危险。</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 107:25–29; 路加福音 4:39; 诗篇 104:6–9"> 门徒们上前来叫醒耶稣，说：“老师，老师，我们没命了！”耶稣就起来，斥责风和浪，风浪就止息，湖面就变得平静。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 8:26; 箴言 30:4; 马可福音 4:40–41"> 耶稣对他们说：<span className="woj">“你们的信仰在哪里？”</span><br />他们又惧怕，又惊奇，彼此说：“这个人究竟是谁？他竟然命令风和水，连风和水也听从他！”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马可福音 5:1–20; 马太福音 8:28–34"> 他们行船到了格拉森<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="格拉森——有古抄本作“格达拉”。">i</a></sup>人的地方，就是加利利的对岸。</span>
<span className="v" id="v27" data-v="27" data-xref="马可福音 5:2–5; 撒母耳记上 19:24; 民数记 19:16"> 耶稣刚上岸，那城里一个有鬼魔附身的人就迎面而来。这个人已经很长时间不穿衣服，不住在家里，而住在墓地里。</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 8:29; 彼得后书 2:4; 马可福音 5:6–8"> 他一看见耶稣，就喊叫起来，俯伏在耶稣面前，大声说：“至高神的儿子耶稣，我与你有什么关系？求求你不要折磨我！”</span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 5:3–5; 路加福音 9:39; 提摩太后书 2:25–26"> 这是因为耶稣吩咐污灵从那个人身上出来。原来污灵曾多次抓住那个人，虽然他被铁链和脚镣捆锁，被看守着，可是他挣断锁链，被鬼魔驱逐到旷野去。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="马太福音 26:53; 路加福音 8:2; 马太福音 8:29"> 耶稣问他：<span className="woj">“你叫什么名字？”</span><br />他回答说：“军团。”因为有许多鬼魔进到他里面。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 25:41; 腓立比书 2:10–11; 约伯记 2:5"> 那些鬼魔央求耶稣不要命令它们进无底坑去。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 65:4; 以赛亚书 66:3; 启示录 20:7"> 当时，那里有一大群猪正在山上吃食。那些鬼魔就央求耶稣准许它们进入那些猪里，耶稣准许了它们。</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前书 5:8; 约翰福音 8:44; 路加福音 8:22–23"> 鬼魔就从那个人身上出来，进入猪里面。于是那群猪从山崖冲到湖里淹死了。</span>
<span className="v" id="v34" data-v="34" data-xref="马可福音 5:14; 马太福音 8:33; 马太福音 28:11"> 那些放猪的人看见所发生的事，就逃跑了，去<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本没有“去”。">j</a></sup>把这事传到城里城外。</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 10:39; 使徒行传 22:3; 约翰一书 3:8"> 人们就出来，要看所发生的事，他们来到耶稣那里，看见鬼魔所离开的那人，穿着衣服，神志清醒地坐在耶稣脚前，他们就惧怕起来。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 4:24"> 那些看见的人，就告诉大家被鬼魔附身的人怎样得到救治。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 16:39; 路加福音 8:28; 路加福音 10:10–11"> 格拉森<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="格拉森——有古抄本作“格达拉”。">k</a></sup>一带的全体民众请求耶稣离开他们，因为他们十分惧怕。耶稣就上船回去了。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="使徒行传 9:13–16; 马可福音 5:18–20; 诗篇 145:3–12"> 鬼魔所离开的那人央求耶稣，要和他在一起，但耶稣<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="耶稣——有古抄本作“他”。">l</a></sup>让他走，说：</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 17:15–18; 提摩太前书 5:8; 申命记 10:21"> <span className="woj">“你回家去吧，述说神为你做了什么。”</span>于是他就离开了，在全城里传扬耶稣为他做了什么样的事<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="什么样的事——或译作“多么大的事”。">m</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="马太福音 9:1; 马可福音 5:21; 马可福音 6:20"> 耶稣回来的时候，一群人来欢迎他，原来大家一直在等候他。</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 5:22–43; 路加福音 13:14; 使徒行传 18:8"> 这时候，来了一个名叫睚鲁的人，他是一个会堂主管。他俯伏在耶稣脚前，恳求耶稣到他家里去，</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 7:12; 路加福音 8:45; 约伯记 1:18–19"> 因为他有一个约十二岁的独生女儿，快要死了。<br />耶稣去的时候，人群拥挤着他。</span>
<span className="v" id="v43" data-v="43" data-xref="马可福音 5:25–26; 马太福音 9:20–22; 利未记 15:25–33"> 有一个妇人，患了十二年的血漏病，在医生那里花尽了她所有的养生费用，<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="有古抄本没有“在医生那里花尽了她所有的养生费用，”。">n</a></sup>却没有一个人能使她痊愈。</span>
<span className="v" id="v44" data-v="44" data-xref="马可福音 5:27–28; 申命记 22:12; 使徒行传 19:12"> 她从耶稣后面过来，摸了一下耶稣的衣服穗子，立刻，她的血漏就止住了。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="马可福音 5:30–32; 路加福音 9:13; 路加福音 5:5"> 耶稣说：<span className="woj">“谁摸了我？”</span><br />大家都否认。彼得<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="有古抄本附“和与他在一起的人”。">o</a></sup>就说：“老师，人群正围着拥挤你呢！<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="有古抄本附“你还问‘谁摸了我’吗？”">p</a></sup>”</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="路加福音 6:19; 路加福音 5:17; 彼得前书 2:9"> 但是耶稣说：<span className="woj">“有人摸了我，因为我知道有能力从我身上出去了。”</span></span>
<span className="v" id="v47" data-v="47" data-xref="马可福音 5:33; 路加福音 17:15–16; 哥林多前书 2:3"> 那妇人知道瞒不过了，就战战兢兢地上前俯伏在耶稣面前，在全体民众面前说出她是因什么理由摸了耶稣，以及怎样立刻得了痊愈。</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 7:50; 马太福音 9:22; 希伯来书 4:2"> 耶稣对她说：<span className="woj">“女儿，</span><sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="有古抄本附“鼓起勇气吧！”">q</a></sup><span className="woj">你的信救了你，平平安安地去吧。”</span></span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="马可福音 5:35–43; 以赛亚书 7:12; 路加福音 7:6"> 耶稣还在说话的时候，有人从会堂主管的家<sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="家——辅助词语。">r</a></sup>来，对睚鲁<sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="对睚鲁——辅助词语；有古抄本作“对他”。">s</a></sup>说：“你的女儿已经死了，不要再麻烦老师了。”</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="约翰福音 11:40; 约翰福音 11:25; 马可福音 5:36"> 耶稣听了，就对睚鲁说：<span className="woj">“不要怕，只要信！她就会得救治。”</span></span>
<span className="v" id="v51" data-v="51" data-xref="马可福音 14:33; 马太福音 6:5–6; 列王纪上 17:19–23"> 耶稣来到他的家，除了彼得、约翰、雅各和孩子的父母以外，不准任何人与他一起进去。</span>
<span className="v" id="v52" data-v="52" data-xref="路加福音 23:27; 约翰福音 11:4; 撒迦利亚书 12:10"> 大家都在为那女孩捶胸哀哭。耶稣说：<span className="woj">“不要哭！她不是死了，而是睡了。”</span></span>
</div>
<div className="bp">

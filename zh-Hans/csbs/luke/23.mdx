<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 27:1–2; 马太福音 27:11–14; 路加福音 22:66"> 于是他们全体民众就起来，把耶稣带到彼拉多面前，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 17:6–7; 约翰福音 19:12; 路加福音 23:14"> 开始控告耶稣，说：“我们发现这个人在败坏我们的同胞，阻止纳税给凯撒，还自称是基督、是王。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="约翰福音 1:49; 提摩太前书 6:13; 路加福音 22:70"> 彼拉多问耶稣：“你是犹太人的王吗？”<br />耶稣回答说：<span className="woj">“是你说的。”</span></span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 18:38; 路加福音 23:14–15; 路加福音 23:22"> 彼拉多对祭司长们和众人说：“我查不出这个人有什么罪。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马可福音 1:14; 约翰福音 1:43; 约翰福音 2:11"> 他们却更加坚持说：“他在犹太全地教导、煽动民众，从加利利开始，一直到这里。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 5:37; 路加福音 13:1"> 彼拉多听了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="听了——有古抄本作“听到加利利”。">a</a></sup>，就问：“这人是不是加利利人？”</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 3:1; 路加福音 13:31; 马太福音 14:1"> 当他了解耶稣属于希律管辖，就把他送到希律那里。在那些日子里，希律正好也在耶路撒冷。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 9:7–9; 马太福音 14:1; 马可福音 6:14"> 希律见到耶稣就极其欢喜，因为他听说过耶稣的事，早就想要见他，一直希望看他行个神迹。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 27:14; 马太福音 7:6; 彼得前书 2:23"> 于是他问了耶稣许多话，但是耶稣什么都不回答。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 11:53; 路加福音 23:14–15; 路加福音 23:5"> 祭司长们和经文士们都站在那里，极力控告他。</span>
<span className="v" id="v11" data-v="11" data-xref="马可福音 15:16–20; 马太福音 27:27–30; 诗篇 69:19–20"> 希律和他的军兵就藐视耶稣，戏弄他，给他披上华丽的衣服，然后把他送回彼拉多那里。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 4:27; 启示录 17:13–14; 诗篇 83:4–6"> 在这一天，希律和彼拉多竟互相成了朋友；原来他们两个人一向是彼此有仇的。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马可福音 15:14; 马太福音 27:21–23; 约翰福音 18:38"> 彼拉多召集了祭司长们、首领们和民众，</span>
<span className="v" id="v14" data-v="14" data-xref="但以理书 6:4; 希伯来书 7:26; 路加福音 23:1–2"> 对他们说：“你们把这个人带到我这里来，说他是误导民众造反的。看，我已经当着你们的面审问了他，在他身上却一点也查不出你们所控告的罪。</span>
<span className="v" id="v15" data-v="15"> 其实希律也查不出来，所以把他送回给我们。看，他没有做过什么该死的事。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 27:26; 路加福音 23:22; 马可福音 15:15"> 因此，惩罚了以后，我要释放他。”</span>
<span className="v" id="v17" data-v="17"> 每逢这节日，总督必须给他们释放一个囚犯。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本没有此节。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行传 21:36; 使徒行传 3:14; 使徒行传 22:22"> 他们却一齐喊叫说：“除掉这个人！给我们释放巴拉巴！”</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 3:14; 路加福音 23:5; 路加福音 23:2"> 这巴拉巴是因为在城里发生的一个暴乱和杀人案，被投进监狱的。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马可福音 15:15; 马太福音 14:8–9; 马太福音 27:19"> 彼拉多想要释放耶稣，就再次向他们呼吁。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 27:22–25; 马可福音 15:13; 约翰福音 19:15"> 但他们却一直喊叫说：“钉上十字架！把他钉上十字架！”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 23:14; 路加福音 23:20; 彼得前书 3:18"> 彼拉多第三次对他们说：“这个人到底做了什么恶事呢？我查不出他有什么该死的罪。所以，惩罚了以后，我要释放他！”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒迦利亚书 11:8; 诗篇 57:4; 诗篇 22:12–13"> 他们催逼彼拉多，大声要求把耶稣钉上十字架，他们<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附“和祭司长们”。">c</a></sup>的喊声终于<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="终于——辅助词语。">d</a></sup>得胜了。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 27:26; 出埃及记 23:2; 箴言 17:15"> 于是，彼拉多决定成全他们所求的，</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 3:14; 马可福音 15:6–7; 马可福音 15:15"> 释放了他们所要的那个因暴乱和杀人被投进监狱的人，却随他们的意思，把耶稣交出去。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 27:32–44; 马可福音 15:21–32; 使徒行传 6:9"> 他们把耶稣带走的时候，抓了一个从乡下来的古利奈人西门，把十字架放在他身上，要他背着，跟在耶稣后面。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 8:52; 路加福音 8:2; 马可福音 15:40"> 有一大群人跟着耶稣，其中有些妇女为他捶胸哀哭。</span>
<span className="v" id="v28" data-v="28" data-xref="雅歌 8:4; 雅歌 5:8; 雅歌 1:5"> 耶稣转过身来，对她们说：<span className="woj">“耶路撒冷的女儿啊，不要为我哭，而要为你们自己、为你们的儿女哭！</span></span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 24:19; 路加福音 21:23–24; 马可福音 13:17–19"> <span className="woj">看，日子将要来到，那时人们会说：‘不能生育、没有怀过胎和没有乳养过婴儿的，是蒙福的！’</span></span>
<span className="v" id="v30" data-v="30" data-xref="启示录 6:16; 何西阿书 10:8; 以赛亚书 2:19"> <span className="woj">那时人们将开始对山岭说：‘倒在我们身上吧！’对丘陵说：‘遮盖我们吧！’</span></span>
<span className="v" id="v31" data-v="31" data-xref="彼得前书 4:17–18; 约翰福音 15:6; 箴言 11:31"> <span className="woj">他们在树木青绿的时候尚且做这些事，那么在它枯萎的时候，还会发生什么呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马可福音 15:27; 以赛亚书 53:12; 马太福音 27:38"> 另有两个囚犯也和耶稣一起被带去处死。</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 15:22–23; 约翰福音 19:17–18; 约翰福音 18:32"> 当他们来到一个地方，叫做“骷髅”，就在那里把耶稣钉上十字架，又钉了那两个囚犯，一个在右边，一个在左边。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 5:44; 使徒行传 7:60; 彼得前书 3:9"> 那时，耶稣说：<span className="woj">“父啊，赦免他们！因为他们不知道自己在做什么。”</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本没有“耶稣说：‘父啊，赦免他们！因为他们不知道自己在做什么。’”">e</a></sup>士兵们<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="士兵们——原文直译“他们”。">f</a></sup>抽签分了他的衣服。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="诗篇 22:17; 以赛亚书 42:1; 彼得前书 2:4"> 民众站着观看。首领们也讥笑，说：“他救了别人！如果这个人是神的基督，是蒙拣选的那一位，让他救自己吧！”</span>
<span className="v" id="v36" data-v="36" data-xref="诗篇 69:21; 马太福音 27:48; 马太福音 27:34"> 士兵们也上前来戏弄他，给他献上酸酒，</span>
<span className="v" id="v37" data-v="37"> 说：“你如果是犹太人的王，救救你自己吧！”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="马可福音 15:26; 马太福音 27:37; 约翰福音 19:19–22"> 在耶稣的上方有一个牌子<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附“用希腊文、拉丁文和希伯来文写道”。">g</a></sup>：“这是犹太人的王。”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="马太福音 27:44; 马可福音 15:32; 路加福音 23:35"> 被悬挂的两个囚犯中，有一个辱骂他说：“你不是基督吗？救救你自己，也救救我们吧！”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="以弗所书 5:11; 路加福音 12:5; 启示录 15:4"> 另一个就应声斥责他，说：“你既然同样受惩罚，还不怕神吗？</span>
<span className="v" id="v41" data-v="41" data-xref="利未记 26:40–41; 以斯拉记 9:13; 彼得前书 1:19"> 我们受刑<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="受刑——辅助词语。">h</a></sup>理所应当，因为我们所受的与我们所做的相称。但这个人却没有做过什么坏事。”</span>
<span className="v" id="v42" data-v="42" data-xref="罗马书 10:9–14; 使徒行传 16:31; 约翰一书 5:11–13"> 他接着说：“耶稣啊，<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="他接着说：“耶稣啊……”——或译作“他对耶稣说：‘……’”">i</a></sup><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本附“主啊，”。">j</a></sup>你进了你国度的时候，求你记念我。”</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="启示录 2:7; 诗篇 50:15; 提摩太前书 1:15–16"> 耶稣<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="耶稣——有古抄本作“他”。">k</a></sup>对他说：<span className="woj">“我确实地告诉你：今天你要与我一起在乐园里了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="马太福音 27:45; 马可福音 15:33–34; 阿摩司书 8:9"> 那时大约是中午十二点<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="中午十二点——原文为“第六时刻”。">l</a></sup>，黑暗笼罩了整个大地，一直到下午三点<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="下午三点——原文为“第九时刻”。">m</a></sup>。</span>
<span className="v" id="v45" data-v="45" data-xref="希伯来书 10:19–22; 马太福音 27:51; 希伯来书 9:3–8"> 太阳失去了光<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="失去了光——有古抄本作“变黑”。">n</a></sup>，同时，圣所里的幔子裂成两半。</span>
<span className="v" id="v46" data-v="46" data-xref="诗篇 31:5; 使徒行传 7:59; 约翰福音 19:30"> 耶稣大声呼唤：<span className="woj">“父啊，我把我的灵魂交托在你手中。”</span>说完这话，就断了气。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="马太福音 27:54; 马可福音 15:39; 路加福音 23:41"> 百夫长看见所发生的事，就不住地荣耀神，说：“这个人的确是义人。”</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 18:13; 使徒行传 2:37; 耶利米书 31:19"> 所有聚集见这场面的众人，看到所发生的事，都捶着胸回去了。</span>
<span className="v" id="v49" data-v="49" data-xref="路加福音 8:2; 诗篇 38:11; 路加福音 23:55"> 所有熟悉耶稣的人，包括那些从加利利一直跟着他来的妇女，都站在远处看这些事。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="约翰福音 19:38–42; 使徒行传 11:24; 使徒行传 10:22"> 当时，有一个名叫约瑟的人，是犹太议会中的议员，为人公义良善。</span>
<span className="v" id="v51" data-v="51" data-xref="路加福音 2:25; 路加福音 2:38; 以赛亚书 8:12"> 这个人并没有赞同他们的计划和行为；他是犹太的亚利马太城的人，一直期待着神的国。</span>
<span className="v" id="v52" data-v="52" data-xref="约翰福音 19:38–42"> 他来到彼拉多面前，请求要耶稣的遗体。</span>
<span className="v" id="v53" data-v="53" data-xref="马太福音 27:59–60; 以赛亚书 53:9; 马可福音 15:46"> 他把遗体取下来，用细麻布裹好，安放在一座岩石凿成的墓穴里，那里从来没有安放过人。</span>
<span className="v" id="v54" data-v="54" data-xref="马太福音 27:62; 约翰福音 19:31; 马可福音 15:42"> 那天是预备日，安息日快要到了<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="快要到了——原文直译“黎明的时候”。">o</a></sup>。</span>
<span className="v" id="v55" data-v="55" data-xref="路加福音 23:49; 马太福音 27:61; 马可福音 15:47"> 那些从加利利陪耶稣一起来的妇女跟在后面。她们看到了那墓穴，也看到了耶稣的遗体怎样被安放，</span>
<span className="v" id="v56" data-v="56" data-xref="路加福音 24:1; 马可福音 16:1; 申命记 5:14"> 就回去预备香料和香液。不过在安息日，她们还是按照诫命休息了。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 1:16–20; 马太福音 4:18–22; 马可福音 3:9"> 有一次，当人群拥挤着耶稣，听神的话语<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="神的话语——或译作“神的道”。">a</a></sup>的时候，他正站在革尼撒勒湖<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="革尼撒勒湖——就是“加利利湖”。">b</a></sup>边。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 1:19; 马太福音 4:21"> 他看见湖边停着两条船，渔夫们下了船，正在洗网。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 4:18; 马太福音 13:1–2; 约翰福音 1:41–42"> 有一条船是西门的，耶稣上去，请他把船划出去，稍微离岸。耶稣就坐下来，从船上教导众人。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰福音 21:6; 马太福音 17:27"> 讲完了以后，他对西门说：<span className="woj">“把船划到水深的地方，下网捕鱼吧。”</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 2:5; 约翰福音 15:14; 路加福音 6:46–48"> 西门回答说：“老师，我们劳碌了一整夜，什么也没有捕到。不过按照你的话，我就下网吧。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 15:58; 约翰福音 21:6–11; 传道书 11:6"> 他们这样做了，网住了一大群鱼，渔网几乎要撑破。</span>
<span className="v" id="v7" data-v="7" data-xref="加拉太书 6:2; 腓立比书 4:3; 使徒行传 11:25"> 他们就招呼另一条船上的伙伴来帮忙；他们过来，装满了两条船，甚至两条船都几乎要沉下去了。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 6:5; 约伯记 42:5–6; 启示录 1:17"> 西门彼得看见，就俯伏在耶稣脚<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="脚——原文直译“膝”。">c</a></sup>前，说：“主啊，离开我吧，因为我是个罪人！”</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 4:32; 诗篇 8:8; 马可福音 9:6"> 那时，他和所有与他一起的人，都对这一网捕到的鱼惊讶不已。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 4:19; 马太福音 13:47; 以西结书 47:9–10"> 西门的伙伴，就是西庇太的儿子雅各和约翰，也同样惊讶。<br />耶稣对西门说：<span className="woj">“不要怕！从今以后，你将得人了</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="你将得人了——原文直译“你将是一个捕人的人”。">d</a></sup><span className="woj">。”</span></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 4:20; 路加福音 5:28; 马太福音 19:27"> 他们把两条船靠了岸，舍弃一切跟从了耶稣。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="诗篇 50:15; 路加福音 17:16; 马太福音 8:2–4"> 有一次，耶稣在一个城里，忽然有个浑身长满麻风的人，看见耶稣就把脸伏在地上，央求他说：“主啊，如果你愿意，你就能洁净我。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马太福音 9:29–30; 约翰福音 4:50–53; 何西阿书 14:4"> 耶稣伸出手来摸他，说：<span className="woj">“我愿意，你洁净了吧！”</span>麻风病立刻离开了他。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 14:2–32; 路加福音 17:14; 马可福音 1:44"> 耶稣吩咐他不要告诉任何人，说：<span className="woj">“只要去把自己给祭司看，并且为了你的洁净，照着摩西所吩咐的去献上祭物，好对他们做见证。”</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="马太福音 15:30–31; 路加福音 12:1; 马可福音 1:45–2"> 耶稣的消息反而越发传开了。有一大群人聚集而来，听他传道<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="他传道——辅助词语。">e</a></sup>，也要他们的病得痊愈。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 6:12; 马可福音 1:35–36; 马太福音 14:23"> 耶稣却常常退到旷野去祷告。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 6:19; 路加福音 8:46; 马太福音 11:5"> 就在那些日子里，有一天耶稣在教导人的时候，也有些法利赛人和律法教师坐在那里，他们是从加利利和犹太地区的各村庄，以及耶路撒冷来的。主的大能与耶稣同在，使他能医病。</span>
<span className="v" id="v18" data-v="18" data-xref="马可福音 2:3–12; 马太福音 9:2–8; 约翰福音 5:5–6"> 这时候，有几个人用床榻抬来一个瘫痪的人，想把他带进去放在耶稣面前。</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 2:4; 马太福音 10:27; 马太福音 24:17"> 但由于人多，他们没有办法<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="没有办法——原文直译“找不到办法”。">f</a></sup>把他带进去，就爬上屋顶，从屋瓦中间把他和床榻一起缒到众人当中，正在耶稣面前。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="使徒行传 14:9; 马太福音 9:2; 马可福音 2:5"> 耶稣看见他们的信心，就对瘫痪的人说：<span className="woj">“朋友</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="朋友——原文直译“人哪”。">g</a></sup><span className="woj">，你的罪孽已经被赦免了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 43:25; 马可福音 2:6–7; 路加福音 7:49"> 那些经文士和法利赛人就开始想：“这个人是谁？竟说亵渎的话。除了神一位之外，谁能赦免罪呢？”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 24:38; 以赛亚书 66:18; 诗篇 139:2"> 耶稣知道他们的意念，就对他们说：<span className="woj">“你们心里为什么这样想呢？</span></span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 2:9; 马太福音 9:5"> <span className="woj">或说‘你的罪孽已经被赦免了’，或说‘你起来走路’，哪一样更容易呢？</span></span>
<span className="v" id="v24" data-v="24" data-xref="启示录 1:13; 以赛亚书 53:11; 路加福音 8:54"> <span className="woj">不过为要使你们知道人子在地上有赦免罪的权柄——”</span>耶稣就对瘫痪的人说：<span className="woj">“我吩咐你：起来，拿起你的床榻，回家去吧！”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 9:24; 路加福音 5:13; 诗篇 107:20–22"> 那个人立刻在大家面前站了起来，拿起他所躺的床榻回家去，一路上荣耀神。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 9:8; 马太福音 12:23; 路加福音 7:16"> 于是大家都惊讶不已，就不住地荣耀神，并且满怀敬畏之心说：“我们今天看到奇妙的事了！”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马可福音 2:13–22; 马太福音 9:9–17; 约翰福音 1:43"> 这些事以后，耶稣出去，看到一个名叫利未<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="利未——就是“马太”。">h</a></sup>的税吏，在税关坐着。耶稣对他说：<span className="woj">“你跟从我！”</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 5:11; 马太福音 19:22–27; 列王纪上 19:19–21"> 利未就撇下一切，站起来跟从了耶稣。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马可福音 2:15; 路加福音 15:1; 哥林多前书 10:27"> 利未在自己家里为耶稣预备盛大的宴席，有一大群税吏和其他人与他们一同坐席。</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 21:28–32; 路加福音 5:17; 马可福音 7:3"> 法利赛人和他们的经文士就向耶稣的门徒们抱怨，说：“你们为什么与那些税吏和罪人一起吃喝呢？”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马可福音 2:17; 马太福音 9:12–13; 耶利米书 8:22"> 耶稣对他们说：<span className="woj">“健康的人不需要医生，有病的人才需要。</span></span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 19:10; 路加福音 15:10; 提摩太前书 1:15–16"> <span className="woj">我来不是要召唤义人，而是要召唤罪人来悔改。”</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 9:14–17; 马可福音 2:18–22; 约翰福音 3:25"> 他们对耶稣说：“约翰的门徒们经常禁食、祈祷，法利赛人的门徒们也是如此，而你的门徒们却又吃又喝。<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="约翰的门徒们……又吃又喝。——有古抄本作“为什么约翰的门徒们……又吃又喝呢？”">i</a></sup>”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="约翰福音 3:29; 哥林多后书 11:2; 以赛亚书 54:5"> 耶稣对他们说：<span className="woj">“新郎与宾客</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="宾客——或译作“伴郎”；原文直译“新房之子”。">j</a></sup><span className="woj">在一起的时候，难道你们能叫宾客禁食吗？</span></span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 17:22; 使徒行传 14:23; 使徒行传 3:21"> <span className="woj">可是日子将要来到：当新郎从他们中间被带走的时候，他们那时——在那些日子里就要禁食了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="马太福音 9:16–17; 马可福音 2:21–22; 哥林多后书 6:16"> 耶稣又对他们讲了一个比喻：<span className="woj">“没有人从新衣服上撕下一块布来缝在旧衣服上，否则，他不但撕破了新衣服，而且来自新衣服的那块布与旧衣服不相称。</span></span>
<span className="v" id="v37" data-v="37" data-xref="约书亚记 9:13; 诗篇 119:83; 约书亚记 9:4"> <span className="woj">也没有人把新酒装在旧皮袋里，否则新酒会胀破旧皮袋，酒会流出来，皮袋也会糟蹋了。</span></span>
<span className="v" id="v38" data-v="38" data-xref="希伯来书 8:8–13; 哥林多后书 5:17; 以西结书 36:26"> <span className="woj">因此，新酒必须装在新皮袋里。</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="有古抄本附“这样两者都保全了。”">k</a></sup></span>
<span className="v" id="v39" data-v="39" data-xref="希伯来书 11:39; 马可福音 7:7–13; 耶利米书 6:16"> <span className="woj">没有人喝了陈酒以后想喝新酒，因为他总说：‘还是陈酒好</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="好——有古抄本作“更好”。">l</a></sup><span className="woj">。’”</span></span>
</div>
</div>

<span className="v" id="v2" data-v="2" data-xref="马可福音 12:42"> 又见一个穷寡妇投进两个小钱<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="两个小钱——原文为“2雷普顿”。1雷普顿=约1/128日工资的希腊小铜币。">a</a></sup>。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 8:12; 使徒行传 10:34; 哥林多后书 8:2–3"> 于是他说：<span className="woj">“我确实地告诉你们：这穷寡妇所投的，比所有的人更多。</span></span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 2:44–45; 路加福音 15:12; 使徒行传 4:34"> <span className="woj">因为那些人都是从自己的富余中拿出来，当做奉献</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="奉献——有古抄本作“给神的奉献”。">b</a></sup><span className="woj">来投入；而这寡妇是从自己的缺乏中，把她拥有的养生费用全都投进去了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 2:20; 马太福音 24:1–51; 马可福音 13:1–37"> 有些人谈论到圣殿，说它是用精美的石头和供奉的礼物装饰的。耶稣就说：</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 24:2; 马可福音 13:2; 耶利米哀歌 5:18"> <span className="woj">“你们现在所看见的这些，当那些日子来到的时候，将不会有一块石头留在另一块石头上而不被拆下。”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行传 1:6–7; 马可福音 13:14; 马可福音 13:3–4"> 他们就问耶稣，说：“老师，那么，这些事什么时候会发生呢？这些事将要发生的时候，会有什么预兆呢？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约翰一书 4:1; 马可福音 13:5–6; 以弗所书 5:6"> 耶稣说：<span className="woj">“你们要当心，免得被迷惑，因为许多人会以我的名而来，声称‘我就是那一位</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="我就是那一位——原文直译“我就是”或“我永在”。">c</a></sup><span className="woj">’，又说‘时候快到了。’你们不要跟从他们。</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 21:28; 马太福音 24:6–8; 马可福音 13:7–8"> <span className="woj">当你们听见有战争和混乱的时候，不可惊慌，因为这些事必须先发生，不过结局不会立刻就到。”</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 2:19–20; 马可福音 13:8; 历代志下 15:5–6"> 耶稣接着对他们说：<span className="woj">“一个民族要起来反对另一个民族，一个国家要起来反对另一个国家；</span></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 24:29–30; 路加福音 21:25–27"> <span className="woj">到处都会有大地震、饥荒和瘟疫；会有恐怖的景象和天上来的大征兆。</span></span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 4:12–14; 使徒行传 5:40; 使徒行传 22:30"> <span className="woj">不过在所有这些事以前，他们将对你们下手，逼迫你们，把你们送交会堂，送进监狱；为我名的缘故，你们将被带到君王和总督面前。</span></span>
<span className="v" id="v13" data-v="13" data-xref="腓立比书 1:12; 腓立比书 1:28; 帖撒罗尼迦后书 1:5"> <span className="woj">但这却要成为你们做见证的机会。</span></span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 12:11–12; 马可福音 13:11; 马太福音 10:19–20"> <span className="woj">所以你们应当心里镇定，不用预先思虑怎样申辩。</span></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 1:9; 以弗所书 6:19; 路加福音 12:12"> <span className="woj">因为我将赐给你们口才和智慧，是所有反对你们的人都不能抵挡、不能驳倒的。</span></span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 12:53; 启示录 6:9; 弥迦书 7:5–6"> <span className="woj">你们甚至将被父母、兄弟、亲戚和朋友出卖，他们还会害死你们当中的一些人。</span></span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 15:19; 路加福音 6:22; 约翰福音 15:21"> <span className="woj">为了我的名，你们将被所有的人憎恨，</span></span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 10:30; 撒母耳记上 14:45; 路加福音 12:7"> <span className="woj">可是你们连一根头发也绝不会失去。</span></span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 10:36; 马太福音 10:22; 雅各书 1:3"> <span className="woj">你们当在你们的忍耐中获得自己的生命</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="生命——或译作“灵魂”。">d</a></sup><span className="woj">。</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="你们当在忍耐中获得自己的生命。——或译作“你们当靠忍耐获得自己的生命。”">e</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 19:43; 但以理书 9:27; 马可福音 13:14"> <span className="woj">“当你们看见耶路撒冷被军队包围的时候，你们那时就应当知道它的毁灭近了。</span></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 6:1; 创世记 19:17; 路加福音 17:31–33"> <span className="woj">那时，在犹太的人应当逃到山里；在城</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="城——原文直译“她”，指“耶路撒冷”。">f</a></sup><span className="woj">里的人应当出来；在乡下的人不要进城；</span></span>
<span className="v" id="v22" data-v="22" data-xref="何西阿书 9:7; 以赛亚书 65:12–16; 以赛亚书 63:4"> <span className="woj">因为这是报应的日子，为要应验经上所记载的一切。</span></span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 13:17; 马太福音 24:19; 路加福音 23:29"> <span className="woj">在那些日子里，孕妇和哺乳的女人有祸了！因为将有大苦难临到这地</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="这地——或译作“地上”或“大地”。">g</a></sup><span className="woj">，也有震怒临到这民</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="这民——或译作“人们”或“子民”或“这个民族”。">h</a></sup><span className="woj">。</span></span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 11:25; 启示录 11:2; 以赛亚书 63:18"> <span className="woj">他们将倒在刀口下，被掳到各国去。耶路撒冷将要被外邦人践踏，直到外邦人的日期满了。</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 13:10; 约珥书 2:30–31; 启示录 6:12–14"> <span className="woj">“在太阳、月亮和星辰中将有征兆出现</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="出现——辅助词语。">i</a></sup><span className="woj">；在地上，因海洋的咆哮和翻腾，列国的人就惊慌失措，陷入困惑混乱之中；</span></span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 24:29; 申命记 28:65–67; 彼得后书 3:10–12"> <span className="woj">人们预料到将要临到世界的事，就吓得魂不附体；因为诸天的各势力都将被震动。</span></span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 24:30; 启示录 1:7; 马可福音 13:26"> <span className="woj">那时候，人们将要看见人子带着极大的权能和荣耀，在云彩中来临。</span></span>
<span className="v" id="v28" data-v="28" data-xref="罗马书 8:23; 以赛亚书 60:1–2; 以弗所书 4:30"> <span className="woj">这些事一开始发生，你们就当挺起身、抬起头，因为你们的救赎近了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马太福音 24:32–35; 马可福音 13:28–30"> 耶稣又给他们讲了一个比喻：<span className="woj">“你们看无花果树和其他</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="其他——辅助词语。">j</a></sup><span className="woj">所有的树，</span></span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 12:57"> <span className="woj">当它们长出叶子</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="叶子——辅助词语。">k</a></sup><span className="woj">的时候，你们一看就知道夏天已经快到了。</span></span>
<span className="v" id="v31" data-v="31" data-xref="雅各书 5:9; 希伯来书 10:37; 彼得前书 4:7"> <span className="woj">照样，当你们看见这些事发生的时候，你们应当知道：神的国快到了。</span></span>
<span className="v" id="v32" data-v="32" data-xref="马可福音 13:30; 马太福音 24:34; 马太福音 23:36"> <span className="woj">我确实地告诉你们：在这一切事发生之前，这世代绝不会过去。</span></span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 40:8; 马可福音 13:31; 马太福音 24:35"> <span className="woj">天和地将要消逝，但是我的话绝不会消逝。</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马可福音 4:19; 路加福音 12:45–46; 路加福音 12:40"> <span className="woj">“你们要谨慎自守，免得你们的心因宴乐</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="宴乐——或译作“放荡”。">l</a></sup><span className="woj">、醉酒和今生的忧虑变得迟钝，那日子就会像网罗一样突然临到你们，</span></span>
<span className="v" id="v35" data-v="35" data-xref="启示录 16:15; 诗篇 11:6; 耶利米书 48:43–44"> <span className="woj">因为那日子将要临到所有住在全地面上的人。</span></span>
<span className="v" id="v36" data-v="36" data-xref="约翰一书 2:28; 马太福音 25:13; 彼得前书 5:8"> <span className="woj">你们要时刻警醒、祷告，使你们能够</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="能够——有古抄本作“被算为配得上”。">m</a></sup><span className="woj">逃避这一切将要发生的事，好站立在人子面前。”</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 22:39; 马可福音 11:19; 马太福音 21:17"> 耶稣白天在圣殿里教导人，夜间出去到那叫做“橄榄园”的山里过夜。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 8:1–2"> 全体民众清早起来上圣殿，到耶稣那里听他讲说。</span>
</div>

<span className="v" id="v2" data-v="2" data-xref="马太福音 9:36–38; 约翰福音 4:35–38; 哥林多前书 3:6–9"> 耶稣对他们说：<span className="woj">“收割的工作</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="收割的工作——或译作“庄稼”。">b</a></sup><span className="woj">多，而工人少。所以你们要祈求收割</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="收割——或译作“庄稼”。">c</a></sup><span className="woj">的主催促工人参与他的收割工作</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="参与他的收割工作——或译作“收他的庄稼”。">d</a></sup><span className="woj">。</span></span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 10:16; 使徒行传 20:29; 以西结书 2:3–6"> <span className="woj">你们去吧！看哪，我差派你们出去，就像把羊羔送进狼群中。</span></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 22:35; 列王纪下 4:29; 路加福音 10:4–12"> <span className="woj">你们不要带钱包，不要带行囊，不要带鞋子，在路上也不要问候任何人。</span></span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 25:6; 马太福音 10:12–13; 以赛亚书 57:19"> <span className="woj">你们无论进哪一家，首先要说‘愿这一家平安。’</span></span>
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦后书 3:16; 哥林多后书 2:15–16; 以弗所书 5:6"> <span className="woj">如果那里有平安之子，你们的平安就会临到他；否则，那平安就归回你们。</span></span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前书 5:17–18; 马太福音 10:10–11; 加拉太书 6:6"> <span className="woj">你们当住在那一家，吃喝他们所供给的，因为工人配得自己的酬报。不要从这家搬到那家。</span></span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 10:27; 马太福音 10:40; 路加福音 10:10"> <span className="woj">无论进哪一个城，如果人们接受你们，给你们摆上什么，你们就吃什么。</span></span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 3:2; 约翰福音 3:5; 路加福音 10:11"> <span className="woj">你们要使那城里的病人痊愈，并且要对他们说‘神的国临近你们了。’</span></span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 18:6; 马太福音 10:14; 使徒行传 13:51"> <span className="woj">无论进哪一个城，如果人们不接受你们，你们就到大街</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="大街——或译作“广场”。">e</a></sup><span className="woj">上去，说</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 10:9; 使徒行传 13:51; 使徒行传 13:26"> <span className="woj">‘连那沾在我们脚上</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本没有“脚上”。">f</a></sup><span className="woj">的你们城里的尘土，我们也要当着你们擦掉，不过你们应当知道：神的国近了</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="近了——有古抄本作“临近你们了”。">g</a></sup><span className="woj">。’</span></span>

</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 23:1–18; 约珥书 3:4–8; 以西结书 26:1–26"> <span className="woj">“哥拉汛哪，你有祸了！伯赛达呀，你有祸了！因为在你们当中行过的神迹，如果行在提尔和西顿，那里的人早就会披麻蒙灰，坐在地上悔改了。</span></span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 15:22–25; 罗马书 2:1; 路加福音 12:47–48"> <span className="woj">不过在审判的时候，提尔和西顿所受的，将要比你们还容易受呢！</span></span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 14:13–15; 马太福音 4:13; 路加福音 13:28"> <span className="woj">而你——迦百农啊，你将被高举到天上吗？不，你将下到阴间。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰福音 13:20; 马太福音 10:40; 帖撒罗尼迦前书 4:8"> <span className="woj">“听从你们的，就是听从我；拒绝你们的，就是拒绝我；拒绝我的，就是拒绝差派我来的那一位。”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 16:20; 马可福音 16:17; 路加福音 9:1"> 那七十<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="七十——有古抄本作“七十二”。">h</a></sup>个人怀着喜乐的心回来，说：“主啊，奉你的名，连鬼魔也服从了我们。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="启示录 12:7–9; 以赛亚书 14:12; 启示录 9:1"> 耶稣对他们说：<span className="woj">“我看见撒旦像闪电一样从天上坠落。</span></span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 91:13; 马可福音 16:18; 罗马书 16:20"> <span className="woj">看，我已经给了你们权柄去践踏蛇和蝎子，又胜过仇敌一切的势力，绝不会有什么能伤害你们了。</span></span>
<span className="v" id="v20" data-v="20" data-xref="启示录 20:15; 启示录 20:12; 希伯来书 12:23"> <span className="woj">但不要因为邪灵服从了你们就欢喜，要因为你们的名字已经被记录在天上而欢喜。”</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 4:3; 马太福音 13:11–16; 马太福音 11:25–27"> 那时候，耶稣<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="耶稣——有古抄本作“他”。">i</a></sup>受了圣灵的感动就快乐，说：<span className="woj">“父啊，天地的主，我赞美</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="赞美——或译作“感谢”。">j</a></sup><span className="woj">你，因为你把这些事向有智慧的和有学问的人隐藏起来，而向小孩子们显明出来。是的，父啊！因为这正是你的美意。”</span></span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 11:27; 约翰福音 1:18; 约翰福音 6:44–46"> <span className="woj">“我父把一切都交给了我。除了父，没有人知道子是谁；除了子和子所愿意启示的人，也没有人知道父是谁。”</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 13:16–17"> 耶稣转过身来，悄悄地对门徒们说：<span className="woj">“看见你们所看见的，那眼睛是蒙福的！</span></span>

</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马太福音 22:34–39; 路加福音 18:18; 马太福音 19:16–19"> 这时候，忽然有一个律法师站起来试探耶稣，说：“老师，我该做什么才会继承永恒的生命呢？”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="罗马书 10:5; 以赛亚书 8:20; 加拉太书 3:21–22"> 耶稣对他说：<span className="woj">“律法上是怎么写的？你是怎么读的呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马可福音 12:30–31; 马太福音 22:37–40; 申命记 6:5"> 他回答说：<br />“你要以全心、全灵、全力、全意爱主——你的神，并且要爱邻如己。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以西结书 20:11; 利未记 18:5; 马太福音 19:17"> 耶稣说：<span className="woj">“你回答得对。你这样去做，就将活着。”</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 16:15; 罗马书 4:2; 利未记 19:34"> 那个人却要显示自己为义，就对耶稣说：“那么，谁是我的邻人呢？”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="诗篇 88:4; 路加福音 18:31; 耶利米哀歌 2:12"> 耶稣回答说：<span className="woj">“有一个人从耶路撒冷下到耶利哥去，途中</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="途中——辅助词语。">k</a></sup><span className="woj">遇到强盗。他们剥去他的衣服，把他打得半死，丢下他走了。</span></span>
<span className="v" id="v31" data-v="31" data-xref="约翰一书 3:16–18; 诗篇 69:20; 耶利米书 5:31"> <span className="woj">恰好有一个祭司从那条路下来，看见他，就从另一边走了过去。</span></span>
<span className="v" id="v32" data-v="32" data-xref="箴言 27:10; 使徒行传 18:17; 诗篇 109:25"> <span className="woj">有一个利未人也正好来到那地方，看见他，也同样地从另一边走了过去。</span></span>
<span className="v" id="v33" data-v="33" data-xref="列王纪上 8:50; 耶利米书 38:7–13; 路加福音 7:13"> <span className="woj">可是，有一个撒玛利亚人行路来到他那里，看见他，就动了怜悯之心，</span></span>
<span className="v" id="v34" data-v="34" data-xref="罗马书 12:20; 诗篇 147:3; 帖撒罗尼迦前书 5:15"> <span className="woj">上前来，在他的伤处倒上油和酒，包扎好，然后把他扶上自己的牲口，带到旅店里照顾他。</span></span>
<span className="v" id="v35" data-v="35" data-xref="箴言 19:17; 路加福音 14:13; 罗马书 16:23"> <span className="woj">第二天</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本附“离开的时候”。">l</a></sup><span className="woj">，他拿出两个银币</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="两个银币——原文为“2得拿利”。1得拿利=约1日工资的罗马银币。">m</a></sup><span className="woj">交给店家，说‘请你照顾他，一切额外的费用，我回来的时候将还给你。’</span></span>

<span className="v" id="v36" data-v="36" data-xref="路加福音 7:42; 马太福音 21:28–31; 马太福音 17:25"> <span className="woj">“你认为，这三个人中，哪一个是落在强盗手中那人的邻人呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="约翰一书 3:16–18; 弥迦书 6:8; 彼得前书 2:21"> 律法师说：“是那个怜悯他的人。”<br />耶稣对他说：<span className="woj">“你去如此做吧。”</span></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="约翰福音 11:19–20; 约翰福音 11:1–5; 约翰福音 12:1–3"> 他们继续前行，耶稣进了一个村子，有一个名叫玛妲的女人接待他<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="接待他——有古抄本作“接他到自己家里”。">n</a></sup>。</span>

<span className="v" id="v40" data-v="40" data-xref="约翰福音 6:27; 路加福音 12:29; 马太福音 14:15"> 玛妲为了很多伺候的事就心里烦乱，上前来说：“主啊，我妹妹丢下我一个人伺候，你不管吗？请叫她来帮我的忙吧。”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="腓立比书 4:6; 路加福音 21:34; 马太福音 6:25–34"> 主<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="主——有古抄本作“耶稣”。">q</a></sup>回答她，说：<span className="woj">“玛妲，玛妲，你为很多事忧虑、烦恼，</span></span>

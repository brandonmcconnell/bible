<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太前书 1:15; 马太福音 9:10–13; 路加福音 5:29–32"> 当时，税吏和罪人都接近耶稣，听他讲说。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 9:11; 路加福音 19:7; 路加福音 7:39"> 法利赛人和经文士抱怨，说：“这个人欢迎罪人，又与他们一起吃饭。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3"> 于是耶稣对他们讲了这个比喻：</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 34:16; 以西结书 34:11–12; 马太福音 18:12–14"> <span className="woj">“你们当中的哪一个人拥有一百只羊，而丢失其中的一只，就不会把九十九只留在旷野，去找那一只丢失的，直到找到了它呢？</span></span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 12:2; 路加福音 19:9; 以赛亚书 46:3–4"> <span className="woj">一旦找到了，他就快快乐乐地扛在自己的肩上，</span></span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 15:10; 路加福音 15:24; 彼得前书 2:25"> <span className="woj">回到家里请朋友和邻居来，对他们说：‘你们与我一同欢乐吧，因为我找到了那只丢失的羊。’</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 5:32; 路加福音 15:10; 路加福音 15:32"> <span className="woj">我告诉你们：同样，一个罪人的悔改，比九十九个不需要悔改的义人，会让天上更有喜乐。</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 19:10; 以西结书 34:12; 约翰福音 10:16"> <span className="woj">“或者，如果一个妇人有十个银币</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十个银币——原文为“10锥克玛”。1锥克玛=约1日工资的希腊银币。">a</a></sup><span className="woj">，丢失了一个，难道她不点上油灯，打扫屋子，仔细寻找，直到找到了它吗？</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 15:6–7"> <span className="woj">一旦找到了，她就会请朋友和邻居来，说：‘你们与我一同欢乐吧，因为我找到了那个丢失的银币</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="银币——原文为“锥克玛”。1锥克玛=约1日工资的希腊银币。">b</a></sup><span className="woj">。’</span></span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 15:7; 哥林多后书 7:10; 以西结书 33:11"> <span className="woj">同样，我告诉你们：一个罪人的悔改，会让神的天使们面前有喜乐。”</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马太福音 21:23–31"> 耶稣又说：<span className="woj">“某人有两个儿子。</span></span>
<span className="v" id="v12" data-v="12" data-xref="申命记 21:16–17; 马可福音 12:44; 路加福音 15:30"> <span className="woj">小儿子对父亲说：‘父亲，请把我应得的那份家产给我。’父亲就把财产分给两个儿子。</span></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 29:3; 耶利米书 2:5; 箴言 21:17"> <span className="woj">没过几天，那小儿子就收拾了一切，往一个遥远的地方去旅行了。他在那里过着放荡的生活，挥霍他的钱财。</span></span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 33:11; 阿摩司书 8:9–12; 何西阿书 2:9–14"> <span className="woj">当他花尽了自己的一切，那地方又发生了严重的饥荒，他就开始穷困起来。</span></span>
<span className="v" id="v15" data-v="15" data-xref="提多书 3:3; 提摩太后书 2:25–26; 以赛亚书 1:5"> <span className="woj">于是他去投靠当地的一个居民，那人打发他到自己的田里去放猪。</span></span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 6:19–21; 耶利米哀歌 4:5; 何西阿书 12:1"> <span className="woj">他就是渴望拿猪吃的豆荚来充饥</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="充饥——有古抄本作“填自己的肚子”。">c</a></sup><span className="woj">，也没有人给他。</span></span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 18:28; 以弗所书 2:4–5; 路加福音 15:18–19"> <span className="woj">可是他醒悟过来的时候，就说：‘我父亲那么多的雇工都食物充足，我却要在这里饿死</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="饿死——或译作“因饥荒丧命”。">d</a></sup><span className="woj">吗？</span></span>
<span className="v" id="v18" data-v="18" data-xref="耶利米哀歌 3:40; 约翰一书 1:8–10; 路加福音 15:21"> <span className="woj">我要起来，到我父亲那里去，对他说：‘父亲，我对天犯了罪，也在你面前犯了罪。</span></span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 42:6; 路加福音 5:8; 诗篇 84:10"> <span className="woj">我再也不配称为你的儿子，请把我当做你的一个雇工吧。’</span></span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 103:10–13; 诗篇 86:5; 诗篇 86:15"> <span className="woj">于是他起来往自己的父亲那里去。他离得还远的时候，他父亲就看到他，动了怜悯之心，跑上去搂住他的脖子亲吻他。</span></span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 51:4; 路加福音 15:18–19; 耶利米书 3:13"> <span className="woj">儿子说：‘父亲，我对天犯了罪，也在你面前犯了罪。我再也不配称为你的儿子。’</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="创世记 41:42; 以斯帖记 8:2; 启示录 6:11"> <span className="woj">“父亲却对奴仆们说：‘赶快</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本没有“赶快”。">e</a></sup><span className="woj">把那最好的袍子拿来给他穿上，把戒指戴在他手上，把鞋子穿在他脚上，</span></span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 25:6; 马太福音 22:2–14; 诗篇 63:5"> <span className="woj">把那只养肥的牛犊牵来宰杀了，让我们吃喝、庆祝吧！</span></span>
<span className="v" id="v24" data-v="24" data-xref="以弗所书 2:5; 以西结书 34:16; 路加福音 19:10"> <span className="woj">因为我这个儿子是死而复生、失而复得的。’于是他们开始庆祝。</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="诗篇 150:4; 耶利米书 31:4; 路加福音 15:11–12"> <span className="woj">“那时，大儿子正在田里。当他往回走，快到家的时候，听见音乐和跳舞的声音，</span></span>
<span className="v" id="v26" data-v="26"> <span className="woj">就叫来一个仆人，问这些到底是什么事。</span></span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 9:17; 腓利门书 1:16; 使徒行传 22:13"> <span className="woj">仆人对他说：‘你弟弟</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="弟弟——原文直译“兄弟”。">f</a></sup><span className="woj">回来了。你父亲因他平安无恙地回来，就宰杀了那只养肥的牛犊。’</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约拿书 4:9; 撒母耳记上 18:8; 约拿书 4:1–4"> <span className="woj">“大儿子发怒，不肯进去，他父亲就出来劝</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="劝——或译作“安慰”。">g</a></sup><span className="woj">他。</span></span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 18:11–12; 撒迦利亚书 7:3; 以赛亚书 65:5"> <span className="woj">他回答父亲，说：‘你看，我服事你这么多年，从来没有违背过你的命令，可是你从来没有给过我一只小山羊，好让我与朋友们一同庆祝。</span></span>
<span className="v" id="v30" data-v="30" data-xref="箴言 29:3; 路加福音 15:12–13; 路加福音 15:32"> <span className="woj">而你这个儿子，这个与妓女们一起吞尽了你财产的，他一来了，你就为他宰杀了养肥的牛犊！’</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马可福音 7:27–28; 罗马书 9:4; 罗马书 11:1"> <span className="woj">“父亲对他说：‘孩子啊，你一直与我在一起，我的一切都是你的。</span></span>
<span className="v" id="v32" data-v="32" data-xref="以弗所书 2:1–10; 路加福音 15:24; 以赛亚书 35:10"> <span className="woj">现在，我们应该庆祝、欢喜，因为你这个弟弟是死而复生、失而复得的。’”</span></span>
</div>
</div>

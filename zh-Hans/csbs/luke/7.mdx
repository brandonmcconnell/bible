<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 8:5–13; 路加福音 7:1–10; 马太福音 7:28–29"> 当耶稣向民众<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="向民众——原文直译“向民众耳中”。">a</a></sup>说完了这一切话<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这一切话——原文直译“他所有的话”。">b</a></sup>，就进了迦百农。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 5:2–3; 创世记 24:27; 约翰福音 4:46–47"> 有个百夫长所重视的奴仆病得快要死了。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 8:5; 约翰福音 4:47; 路加福音 9:38"> 百夫长听说了耶稣的事，就托几个犹太人的长老到耶稣那里，求耶稣来救他的奴仆。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 3:4; 马太福音 10:11; 路加福音 7:6–7"> 他们来到耶稣那里，殷切地求他说：“这人配得你的帮助，</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 2:11–12; 历代志上 29:3–9; 列王纪上 5:1"> 因为他爱我们的同胞，还为我们建了会堂。”</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 5:24; 创世记 32:10; 雅各书 4:6"> 于是耶稣与他们一起去了。当耶稣离他家不远的时候，百夫长又托了几个朋友来对耶稣说：“主啊，不用麻烦了，我实在不配请你进我家，</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 107:20; 诗篇 33:9; 路加福音 4:36"> 我自己也觉得不配到你那里去。只要你说一句话，我的仆人就会痊愈的。</span>
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 3:22; 使徒行传 23:17; 使徒行传 22:25–26"> 事实上，我也被放在人的权下，也有士兵在我之下。我对这个说‘去’，他就去；对那个说‘来’，他就来；对我的奴仆说‘做这事’，他就去做。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马太福音 15:28; 罗马书 3:1–3; 马太福音 8:10"> 耶稣听了这些话，十分感慨，转过身来对跟随他的那群人说：<span className="woj">“我告诉你们：在以色列我没有见过这么大的信心</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="信心——指“对耶稣的信心”。">c</a></sup><span className="woj">。”</span></span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 4:50–53; 马太福音 8:13; 马太福音 15:28"> 那些受托的人回到家里时，发现那<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附“患病的”。">d</a></sup>奴仆已经痊愈了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 10:38"> 第二天，耶稣往一个叫做拿因的城去，他的<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附“许多”。">e</a></sup>门徒们和一大群人也与他同行。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 8:42; 路加福音 8:52; 列王纪上 17:9"> 当他接近城门口的时候，看哪，有一个死人被抬出来了。这人是独生儿子，他的母亲又是寡妇。一大群城里的人陪着她。</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 103:13; 以赛亚书 63:9; 诗篇 86:15"> 主看见那寡妇，就对她动了怜悯之心，向她说：<span className="woj">“不要哭了！”</span></span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 5:25; 约翰福音 11:43–44; 使徒行传 9:40–41"> 于是耶稣上前去，按着棺架，抬棺架的人就停住了。耶稣说：<span className="woj">“年轻人，我吩咐你起来！”</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王纪下 13:21; 列王纪下 4:32–37; 列王纪上 17:23–24"> 那死人就坐了起来，开始说话。耶稣把他交给他的母亲。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 9:8; 路加福音 7:39; 路加福音 1:68"> 每个人敬畏不已，就不住地荣耀神，说：“我们中间兴起了一位伟大的先知！”又说：“神临到<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="临到——或译作“照顾”。">f</a></sup>他的子民了！”</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 4:24; 马可福音 6:14; 马太福音 9:26"> 于是有关耶稣的这消息传遍了整个犹太和周围所有的地区。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰福音 3:26; 马太福音 11:2–19"> 约翰的门徒们把这一切事都告诉了约翰。他就叫来他的两个门徒，</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 9:6–7; 约翰福音 4:25; 创世记 22:18"> 派他们到主<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="主——有古抄本作“耶稣”。">g</a></sup>那里去问：“将要来的那一位就是你吗？还是我们应该等候另一位呢？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 7:19"> 那两个人来到耶稣那里，说：“施洗者<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="施洗者——或译作“施浸者”。">h</a></sup>约翰派我们来问你：‘将要来的那一位就是你吗？还是我们应该等候另一位呢？’”</span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="马可福音 3:10; 诗篇 90:7–9; 希伯来书 12:6"> 就在那<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="那——有古抄本作“同一个”。">i</a></sup>时候，耶稣治愈了许多有疾病的、有苦痛的、被邪灵附着的人，又施恩给许多瞎眼的使他们能看见。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 35:5–6; 以赛亚书 61:1–3; 路加福音 4:18"> 于是耶稣<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="耶稣——有古抄本作“他”。">j</a></sup>回答那两个人，说：<span className="woj">“你们去把所看见、所听见的告诉约翰，就是：瞎眼的得以看见，瘸腿的行走，麻风病人被洁净，耳聋的听见，死人得以复活，穷人得以听到福音。</span></span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 11:6; 彼得前书 2:7–8; 罗马书 9:32–33"> <span className="woj">凡不因我被绊倒</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="被绊倒——或译作“放弃信仰”。">k</a></sup><span className="woj">的人，就蒙福了。”</span></span>
<span className="v" id="v24" data-v="24" data-xref="以弗所书 4:14; 约翰福音 1:23; 路加福音 1:80"> 约翰的使者离开了，耶稣就开始对众人谈起约翰，说：<span className="woj">“你们曾经到旷野去，是要观看什么呢？一根被风吹动的芦苇吗？</span></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 59:17; 以斯帖记 8:15; 以斯帖记 1:3"> <span className="woj">你们出去，究竟是要看什么呢？一个身穿细软衣服的人吗？看哪，那些穿华丽衣服、生活放荡的人在王宫里。</span></span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 1:76; 约翰福音 5:35; 路加福音 20:6"> <span className="woj">你们出去，究竟是要看什么呢？一位先知吗？是的，我告诉你们：他比先知还大。</span></span>
<span className="v" id="v27" data-v="27" data-xref="玛拉基书 3:1; 路加福音 1:76; 马可福音 1:2"> <span className="woj">他就是经上记载的那个人：</span><br /><span className="pl pl-1 woj">‘看哪，我要差派我的使者在你前头，</span><br /><span className="pl pl-1 woj">他要在你之前预备你的道</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="道——或译作“路”。">l</a></sup><br /><span className="pl pl-1 woj">。’</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马太福音 13:16–17; 马太福音 11:11; 歌罗西书 1:25–27"> <span className="woj">“我告诉你们：在女人所生的人中，没有一个</span><sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="有古抄本附“先知”。">m</a></sup><span className="woj">比约翰</span><sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="约翰——有古抄本作“施洗者约翰”。">n</a></sup><span className="woj">更大的；然而在神的国里，再小的也比约翰更大。”</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 3:12; 路加福音 7:35; 使徒行传 18:25"> 所有已经受过约翰洗礼的民众和税吏，听了这话，都承认神是义的；</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 13:34; 哥林多后书 6:1; 马太福音 22:35"> 而没有受过他洗礼的法利赛人和律法师们，就弃绝了神对他们的计划。</span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="马太福音 11:16–19; 耶利米哀歌 2:13; 马可福音 4:30"> 主又说：<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="有古抄本没有“主又说：”。">o</a></sup><span className="woj">“我要把这世代的人比做什么呢？他们好比什么呢？</span></span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 11:16–19; 耶利米书 5:3–5; 箴言 17:16"> <span className="woj">他们就好比：孩子们坐在街市上，彼此呼叫，说：</span><br /><span className="pl pl-1 woj">‘我们为你们吹笛，</span><br /><span className="pl pl-1 woj">你们却不跳舞；</span><br /><span className="pl pl-1 woj">我们唱哀歌，</span><br /><span className="pl pl-1 woj">你们也不哭泣。’</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 1:15; 马可福音 1:6; 约翰福音 8:52"> <span className="woj">“因为施洗者</span><sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="施洗者——或译作“施浸者”。">p</a></sup><span className="woj">约翰来了，不吃饼，也不喝酒，你们就说：‘他有鬼魔附身！’</span></span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 15:2; 路加福音 7:36; 约翰福音 12:2"> <span className="woj">人子来了，也吃也喝，你们就说：‘看，这个贪食好酒的人！税吏和罪人的朋友！’</span></span>
<span className="v" id="v35" data-v="35" data-xref="箴言 8:32–36; 马太福音 11:19; 何西阿书 14:9"> <span className="woj">然而，智慧是凭着智慧的众儿女被证明为义的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="马可福音 14:3–9; 马太福音 26:5–6; 路加福音 14:1"> 有一个法利赛人请耶稣与他一起吃饭，耶稣就进到那法利赛人的家里坐席。</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 14:3–9; 马太福音 26:6–13; 马太福音 21:31"> 当时，城里有一个女人，是个罪人，她知道耶稣在那法利赛人家里坐席，就拿着一个盛了香液的玉瓶来。</span>
<span className="v" id="v38" data-v="38" data-xref="诗篇 126:5–6; 诗篇 51:17; 创世记 18:4"> 她站在耶稣后面，在他的脚边哭泣，开始用泪水沾湿耶稣的脚，再用自己的头发擦干，又亲吻他的脚，用香液膏抹。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 7:16; 路加福音 15:2; 马可福音 7:21"> 那邀请耶稣的法利赛人看见了，心里说：“这个人如果是先知，就会知道摸他的是谁，是个什么样的女人，因为她是个罪人。”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="约翰福音 16:19; 路加福音 5:31; 以西结书 33:31"> 耶稣对他说：<span className="woj">“西门，我有话要对你说。”</span><br />西门说：“老师，请说。”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 7:47; 罗马书 5:20; 马太福音 18:28"> <span className="woj">“有一个债主有两个欠债人。一个欠五百个银币</span><sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="五百个银币——原文为“500得拿利”。1得拿利=约1日工资的罗马银币。">q</a></sup><span className="woj">，另一个欠五十个银币。</span></span>
<span className="v" id="v42" data-v="42" data-xref="但以理书 9:18–19; 歌罗西书 3:13; 罗马书 3:24"> <span className="woj">他们无力偿还，债主就免了他们两个人的债。那么，你说</span><sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="有古抄本没有“你说”。">r</a></sup><span className="woj">他们哪一个会更爱那债主呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="诗篇 116:16–18; 提摩太前书 1:13–16; 路加福音 7:47"> 西门回答说：“我想是债主免债更多的那一个。”<br />耶稣说：<span className="woj">“你判断得对。”</span></span>
<span className="v" id="v44" data-v="44" data-xref="提摩太前书 5:10; 士师记 19:21; 创世记 18:4"> 于是，他转向那女人，对西门说：<span className="woj">“你看见这个女人吗？我进了你的家，你没有给我水洗脚，但她却用泪水沾湿我的脚，又用她的头发擦干。</span></span>
<span className="v" id="v45" data-v="45" data-xref="撒母耳记下 15:5; 撒母耳记下 19:39; 罗马书 16:16"> <span className="woj">你没有向我行亲吻礼，而她从我进来的时候起，就不停地亲我的脚。</span></span>
<span className="v" id="v46" data-v="46" data-xref="诗篇 23:5; 传道书 9:8; 马太福音 6:17"> <span className="woj">你没有用油来膏抹我的头，她却用香液膏抹我的脚。</span></span>
<span className="v" id="v47" data-v="47" data-xref="约翰一书 4:19; 约翰一书 3:18; 以赛亚书 1:18"> <span className="woj">故此，我告诉你：她的罪孽被赦免得多，所以</span><sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="所以——或译作“因为”。">s</a></sup><span className="woj">她爱得多；而那被赦免少的，就爱得少。”</span></span>
<span className="v" id="v48" data-v="48" data-xref="马太福音 9:2; 马可福音 2:5; 路加福音 5:20"> 接着，耶稣对那女人说：<span className="woj">“你的罪孽已经被赦免了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="路加福音 5:20–21; 马太福音 9:3; 马可福音 2:7"> 那些与他一同坐席的人就心里想：“这个人是谁，竟然赦免罪？”</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="马可福音 5:34; 路加福音 8:48; 路加福音 18:42"> 但耶稣对那女人说：<span className="woj">“你的信救了你，平平安安地去吧。”</span></span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 1:1–3; 彼得后书 1:16–19; 约翰福音 20:31"> 提阿费罗大人哪，既然有许多人着手编录关于在我们中间所成就的事，</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 15:27; 使徒行传 26:16; 希伯来书 2:3"> 就是照着从起初以来的目击者和做福音<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="福音——原文直译“话语”或“道”。">a</a></sup>仆人的那些人所传给我们的，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 1:1; 使徒行传 26:25; 使徒行传 11:4"> 我也已经从头仔细地追踪了这一切，我就认为应该按着次序写给您，</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 20:31; 使徒行传 18:25; 哥林多前书 14:19"> 好让您了解到您所领受的话语都是确实的。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="历代志上 24:10; 马太福音 2:1; 尼希米记 12:4"> 在犹太王希律的那些日子里，有一个祭司名叫撒迦利亚，属于亚比雅班组。他的妻子也是亚伦的子孙<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="子孙——原文直译“女儿”。">b</a></sup>，名叫伊莉莎白。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 7:1; 创世记 17:1; 腓立比书 2:15"> 他们两个人在神面前都是义人，遵行主的一切诫命和公义规定，无可指责。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 11:11; 创世记 18:11; 撒母耳记上 1:2"> 可是他们没有孩子，因为伊莉莎白不能生育，两个人又都上了年纪。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="历代志下 8:14; 历代志上 24:19; 历代志下 31:2"> 有一次，当撒迦利亚的班组轮值的时候，撒迦利亚在神面前履行祭司的职务，</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 29:11; 出埃及记 30:7–8; 历代志上 23:13"> 照着祭司职务的规矩，抽中了签就进入主的圣所烧香。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 16:17; 启示录 8:3; 希伯来书 4:14"> 烧香的时候，全体民众都在外面祷告。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 40:26–27; 使徒行传 10:3–4; 士师记 13:3"> 有主的一位天使站在香坛的右边向他显现。</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 13:22; 士师记 6:22; 路加福音 2:9–10"> 撒迦利亚看见后，就惊慌不安，恐惧就临到了他。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 2:21; 使徒行传 10:31; 创世记 25:21"> 天使对他说：<br /><span className="pl pl-1">“撒迦利亚，不要怕，</span><br /><span className="pl pl-1">因为你的祈祷已蒙垂听。</span><br /><span className="pl pl-1">你的妻子伊莉莎白要为你生一个儿子，</span><br /><span className="pl pl-1">你要给他起名叫约翰。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 1:58; 箴言 23:24; 创世记 21:6"> <span className="pl pl-1">他将使你欢喜、快乐，</span><br /><span className="pl pl-1">许多人也会因他的诞生而欢欣，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 1:5; 民数记 6:2–4; 路加福音 7:33"> <span className="pl pl-1">因为他将要在主面前为大。</span><br /><span className="pl pl-1">淡酒和烈酒他绝不能喝，</span><br /><span className="pl pl-1">还在母腹中的时候，</span><br /><span className="pl pl-1">他就会被圣灵充满。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 40:3–5; 马太福音 21:32; 玛拉基书 3:1"> <span className="pl pl-1">他将使许多以色列子民</span><br /><span className="pl pl-1">归向主——他们的神。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="玛拉基书 4:5–6; 马太福音 11:14; 路加福音 1:76"> <span className="pl pl-1">他将藉着以利亚的灵和能力，</span><br /><span className="pl pl-1">在主的面前先行，</span><br /><span className="pl pl-1">使父亲的心</span><br /><span className="pl pl-1">转向儿女，</span><br /><span className="pl pl-1">使悖逆的人</span><br /><span className="pl pl-1">转向义人的智慧，</span><br /><span className="pl pl-1">好为主准备一群预备好了的子民。”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 38:22; 创世记 17:17; 路加福音 1:7"> 撒迦利亚对天使说：“我凭着什么能知道这事呢？我是个老人，我的妻子也上了年纪。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 1:26; 马太福音 18:10; 但以理书 9:21–23"> 天使回答他，说：“我是站在神面前的加百列，奉差派来对你说话，向你传达这些好消息。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 3:26; 以西结书 24:27; 路加福音 1:22"> 看哪，你要成为哑巴，不能说话，一直到这些事成就的日子，因为你不相信我的话！到了时候，我的话就会应验。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数记 6:23–27"> 民众等候着撒迦利亚，对他在圣所里的迟延不出感到惊奇。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 1:62; 约翰福音 13:24; 使徒行传 21:40"> 当他出来不能和他们说话的时候，他们才了解他在圣所里看到了异象。撒迦利亚一直向他们打手势，却始终不能说话。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 9:25; 列王纪下 11:5–7"> 他服事的日子满了以后，就回家去了。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 这些日子以后，他的妻子伊莉莎白怀了孕，隐居了五个月。她说：</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 30:22–23; 以赛亚书 54:1–4; 创世记 21:1–2"> “为了除去我在人间的耻辱，主在这些眷顾的日子里，这样看待了我。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="马太福音 2:23; 路加福音 1:19; 约翰福音 7:41"> 在第六个月，天使加百列从神那里奉差派，去加利利一个叫拿撒勒的城，</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 1:18; 以赛亚书 7:14; 马太福音 1:16"> 到一个童贞女那里。这童贞女名叫玛丽亚，已经许配给大卫家族一个名叫约瑟的人。</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 6:12; 但以理书 10:19; 路加福音 1:30"> 天使<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="天使——有古抄本作“他”。">c</a></sup>来到她面前，说：“蒙大恩的女子，愿你欢喜，主与你同在！<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附“你在妇女中是蒙祝福的！”">d</a></sup>”</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 10:17; 路加福音 1:12; 使徒行传 10:4"> 玛丽亚因这话就惊慌不安，思索这问候到底是什么意思。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 1:13; 罗马书 8:31; 路加福音 12:32"> 天使对她说：<br /><span className="pl pl-1">“玛丽亚，不要怕，</span><br /><span className="pl pl-1">因为你在神面前蒙恩了。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 7:14; 马太福音 1:21; 马太福音 1:25"> <span className="pl pl-1">看哪，你将要怀孕生一个儿子，</span><br /><span className="pl pl-1">你要给他起名叫耶稣。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 9:6–7; 以赛亚书 16:5; 撒母耳记下 7:11–13"> <span className="pl pl-1">他将要为大，</span><br /><span className="pl pl-1">被称为至高者的儿子；</span><br /><span className="pl pl-1">主、神要把他先祖大卫的王位赐给他。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="但以理书 2:44; 希伯来书 1:8; 但以理书 7:13–14"> <span className="pl pl-1">他要做王统管雅各家，直到永远，</span><br /><span className="pl pl-1">他的国度没有穷尽。”</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="士师记 13:8–12; 使徒行传 9:6"> 玛丽亚对天使说：“我既然没有出嫁<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="没有出嫁——原文直译“没有亲近男人”。">e</a></sup>，怎么会有这事呢？”</span>
</div>
<div className="bp poetry">
<span className="v" id="v35" data-v="35" data-xref="马太福音 1:18; 约翰福音 1:49; 马太福音 1:20"> 天使回答她，说：<br /><span className="pl pl-1">“圣灵将要临到你，</span><br /><span className="pl pl-1">至高者的大能要荫庇你，</span><br /><span className="pl pl-1">因此，那要诞生的圣者</span><br /><span className="pl pl-1">将被称为神的儿子。</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36"> 你看，你的亲戚伊莉莎白虽然年老，也怀了男胎；那被称为不能生育的，现在已有六个月的身孕<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="的身孕——辅助词语。">f</a></sup>了。</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 19:26; 耶利米书 32:27; 马可福音 10:27"> 因为在神没有什么事是不可能的。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="罗马书 4:20–21; 诗篇 119:38; 诗篇 116:16"> 玛丽亚说：“看哪，我是主的婢女，愿这事照着你的话成就在我身上。”于是天使离开了她。</span>
</div>
<div className="bp poetry">
<span className="v" id="v39" data-v="39" data-xref="路加福音 1:65; 约书亚记 15:48–59; 约书亚记 10:40"> 就在那些日子里，玛丽亚起身到山区去，赶往犹大的一个城，</span>
<span className="v" id="v40" data-v="40"> 进了撒迦利亚的家，问候伊莉莎白。</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 1:67; 使徒行传 4:8; 路加福音 1:44"> 伊莉莎白一听到玛丽亚的问候，胎儿就在她的腹中跳动，伊莉莎白也被圣灵充满，</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 1:28; 士师记 5:24; 创世记 22:18"> 大声呼喊说：<br /><span className="pl pl-1">“你在妇女中是蒙祝福的，</span><br /><span className="pl pl-1">你腹中的胎儿</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="胎儿——原文直译“果实”。">g</a></sup><br /><span className="pl pl-1">也是蒙祝福的！</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="约翰福音 20:28; 约翰福音 13:13; 路加福音 2:11"> 我主的母亲竟然到我这里来，这事怎么会临到我呢？</span>
<span className="v" id="v44" data-v="44"> 看哪，原来你问候的声音一传入我的耳朵，胎儿就在我的腹中欢喜跳跃。</span>
<span className="v" id="v45" data-v="45" data-xref="约翰福音 20:29; 约翰福音 11:40; 路加福音 11:27–28"> 这相信的女子是蒙福的，因为主对她说的话都会实现。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v46" data-v="46" data-xref="撒母耳记上 2:1–10; 诗篇 34:2–3; 诗篇 35:9"> 玛丽亚说：<br /><span className="pl pl-1">“我的心尊主为大，</span><br /></span>
<span className="v" id="v47" data-v="47" data-xref="诗篇 35:9; 提摩太前书 2:3; 哈巴谷书 3:18"> <span className="pl pl-1">我的灵以神我的救主为乐，</span><br /></span>
<span className="v" id="v48" data-v="48" data-xref="诗篇 138:6; 玛拉基书 3:12; 哥林多前书 1:26–28"> <span className="pl pl-1">因为他看顾他婢女的卑微。</span><br /><span className="pl pl-1">看哪，从今以后，</span><br /><span className="pl pl-1">世世代代都要称我有福，</span><br /></span>
<span className="v" id="v49" data-v="49" data-xref="诗篇 126:2–3; 诗篇 111:9; 以弗所书 3:20"> <span className="pl pl-1">因为那全能者</span><br /><span className="pl pl-1">为我行了大事；</span><br /><span className="pl pl-1">他的名是神圣的。</span><br /></span>
<span className="v" id="v50" data-v="50" data-xref="诗篇 103:17–18; 出埃及记 20:6; 创世记 17:7"> <span className="pl pl-1">他的怜悯，</span><br /><span className="pl pl-1">世世代代临到敬畏他的人。</span><br /></span>
<span className="v" id="v51" data-v="51" data-xref="诗篇 98:1; 以赛亚书 52:10; 撒母耳记上 2:3–4"> <span className="pl pl-1">他用膀臂施展大能，</span><br /><span className="pl pl-1">驱散那些心思意念骄傲的人。</span><br /></span>
<span className="v" id="v52" data-v="52" data-xref="以西结书 17:24; 雅各书 4:10; 诗篇 107:40–41"> <span className="pl pl-1">他把权能者从高位上拉下，</span><br /><span className="pl pl-1">又把卑微的人</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="卑微的人——或译作“谦卑的人”。">h</a></sup><br /><span className="pl pl-1">高举。</span><br /></span>
<span className="v" id="v53" data-v="53" data-xref="诗篇 107:8–9; 路加福音 6:21; 诗篇 34:10"> <span className="pl pl-1">他用美物满足饥饿的人，</span><br /><span className="pl pl-1">让富有的人空手而去。</span><br /></span>
<span className="v" id="v54" data-v="54" data-xref="诗篇 98:3; 弥迦书 7:20; 以赛亚书 44:21"> <span className="pl pl-1">他扶助他的仆人以色列，</span><br /><span className="pl pl-1">不忘怜悯，</span><br /></span>
<span className="v" id="v55" data-v="55" data-xref="诗篇 105:6–10; 创世记 17:19; 诗篇 132:11–17"> <span className="pl pl-1">正如他对我们祖先，</span><br /><span className="pl pl-1">对亚伯拉罕和他的后裔所说的，直到永远。”</span></span>
</div>
<div className="bp">
<span className="v" id="v56" data-v="56"> 玛丽亚与伊莉莎白一起住了大约三个月，就回家去了。</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="路加福音 1:13; 创世记 21:2–3; 路加福音 2:6–7"> 伊莉莎白产期到了，生了一个儿子。</span>
<span className="v" id="v58" data-v="58" data-xref="路加福音 1:25; 路加福音 1:14; 罗马书 12:15"> 她的邻居和亲戚听说主向她大施怜悯，就与她一同欢乐。</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="创世记 17:12; 利未记 12:3; 腓立比书 3:5"> 到了第八天，他们来给孩子行割礼，要按照他父亲的名字叫他撒迦利亚。</span>
<span className="v" id="v60" data-v="60" data-xref="路加福音 1:13; 撒母耳记下 12:25; 路加福音 1:63"> 可是孩子的母亲应声说：“不！他要被称为约翰。”</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61"> 他们对她说：“你的亲族中没有叫这名字的。”</span>
<span className="v" id="v62" data-v="62" data-xref="路加福音 1:22"> 于是他们向孩子的父亲打手势，到底他愿意叫他什么名字。</span>
<span className="v" id="v63" data-v="63" data-xref="路加福音 1:60; 以赛亚书 30:8; 路加福音 1:13"> 撒迦利亚要了一块写字板，写上：“他的名字是约翰。”大家都感到惊奇。</span>
<span className="v" id="v64" data-v="64" data-xref="路加福音 1:20; 出埃及记 4:15–16; 以西结书 33:22"> 撒迦利亚的口立刻开了，舌头也松了，就说出话来，颂赞神。</span>
<span className="v" id="v65" data-v="65" data-xref="路加福音 1:39; 使徒行传 5:11; 路加福音 7:16"> 于是住在他们周围的人都感到惧怕，整个犹太山区的人也都在谈论这一切事。</span>
<span className="v" id="v66" data-v="66" data-xref="使徒行传 11:21; 路加福音 2:19; 路加福音 2:51"> 所有听见的人都把这一切存在心里，说：“这孩子将来究竟会怎么样呢？”因为显然有主的手与他同在。</span>
</div>

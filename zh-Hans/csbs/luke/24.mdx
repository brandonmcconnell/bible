<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 20:1–2; 马可福音 16:1–8; 马太福音 28:1–8"> 在一周的头一天<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一周的头一天——指“星期日”。">a</a></sup>，一大清早，妇女们<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="妇女们——原文直译“她们”。">b</a></sup>带着预备好的香料来到墓穴那里，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附“还有一些人和她们在一起。”">c</a></sup></span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 16:3–4; 马太福音 27:60–66; 马可福音 15:46–47"> 发现那石头已经从墓穴被滚开了。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 24:23; 约翰福音 20:6–7; 马太福音 16:5"> 她们就进去，却找不到主耶稣的遗体。</span>
<span className="v" id="v4" data-v="4" data-xref="马可福音 16:5; 约翰福音 20:11–12; 使徒行传 1:10"> 她们正为这件事心里困惑的时候，忽然有两个人，身穿闪闪发光的衣服，站在她们旁边。</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 16:5–6; 马太福音 28:3–5; 启示录 1:18"> 妇女们吓得把脸伏在地上。<br />那两个人对她们说：“你们为什么在死人中寻找活人呢？</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 17:22–23; 路加福音 9:22; 马可福音 8:31"> 他不在这里，已经复活<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="复活——原文直译“被复活”；指“神使耶稣复活”。">d</a></sup>了！你们当想起他还在加利利的时候怎样告诉你们，</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 16:21"> 说<span className="woj">‘人子必须被交在</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="被交在——或译作“被出卖到”。">e</a></sup><span className="woj">罪人手中，被钉十字架，然后在第三天复活。’”</span></span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 12:16; 约翰福音 14:26; 约翰福音 2:19–22"> 她们就想起耶稣的话来。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 24:22–24; 马可福音 16:7–8; 马太福音 28:7–8"> 于是从墓穴回去，把这一切都告诉了那十一个使徒和所有其他的人。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 27:56; 约翰福音 20:11–18; 路加福音 8:2–3"> 告诉使徒们这些事的，是茉大拉的玛丽亚、约亚娜、雅各的母亲<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="母亲——辅助词语。">f</a></sup>玛丽亚，还有其余和她们在一起的妇女。</span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 9:16; 马可福音 16:11; 创世记 19:14"> 可是这些话在使徒们看来似乎是胡说，他们就不相信妇女们。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 20:3–10"> 但彼得却起来，跑到了墓穴。他弯腰去看，只看见那细麻布条<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="有古抄本附“放在那里”。">g</a></sup>。于是他就回去了，对所发生的事感到惊奇。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 24:18; 马可福音 16:12–13"> 正好在同一天，门徒中有两个人往一个村子去；这村子名叫以马忤斯，离耶路撒冷约有十一公里<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="十一公里——原文为“60视距”。1视距=185公尺。">h</a></sup>。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 6:45; 申命记 6:7; 玛拉基书 3:6"> 他们彼此谈论着所发生的这一切事。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 18:20; 约翰福音 14:18–19; 路加福音 24:36"> 在他们交谈讨论的时候，耶稣亲自走近他们，与他们同行，</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 20:14; 约翰福音 21:4; 路加福音 24:31"> 但是他们的眼睛被遮蔽了，认不出他来。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 16:20–22; 约翰福音 16:6; 以西结书 9:4–6"> 耶稣问他们：<span className="woj">“你们一路上彼此谈论的这些，到底是什么事呢？”</span>他们就停住<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="有古抄本没有“停住”。">i</a></sup>，面带愁容。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰福音 19:25"> 其中一个名叫克利奥帕的回答耶稣，说：“你在耶路撒冷作客，难道只有你还不知道这几天在那里所发生的事吗？”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马太福音 21:11; 使徒行传 7:22; 约翰福音 4:19"> 耶稣问他们：<span className="woj">“什么事呢？”</span><br />他们对他说：“就是有关拿撒勒人耶稣的事。这个人是一位先知，在神和全体民众面前说话行事都有能力。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 3:13–15; 使徒行传 4:8–10; 路加福音 23:13"> 我们的祭司长们和首领们竟把他交出去，判了死罪，钉上十字架。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:68; 彼得前书 1:18–19; 路加福音 2:38"> 不过我们一直希望他就是要救赎以色列的那一位。不但如此，从这些事发生到今天<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本没有“今天”。">j</a></sup>，已经是第三天了。</span>
<span className="v" id="v22" data-v="22" data-xref="马可福音 16:9–10; 马太福音 28:7–8; 约翰福音 20:1–2"> 还有，我们中间有些妇女也使我们惊讶：她们清早到了墓穴，</span>
<span className="v" id="v23" data-v="23"> 却找不到他的遗体，回来还说她们看到了天使的异象，而天使说耶稣还活着。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 24:12; 约翰福音 20:1–10"> 后来，与我们在一起的一些人，到墓穴那里去，发现一切就像妇女们所说的那样。只是他们没有看见耶稣。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马可福音 7:18; 马可福音 9:19; 希伯来书 5:11–12"> 耶稣对他们说：<span className="woj">“唉，你们这些无知的人哪！对于信靠先知们所说的一切话，你们的心太迟钝了！</span></span>
<span className="v" id="v26" data-v="26" data-xref="彼得前书 1:11; 以赛亚书 53:1–12; 撒迦利亚书 13:7"> <span className="woj">基督不是必须这样受难，然后才进入他的荣耀吗？”</span></span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 7:14; 路加福音 24:44; 申命记 18:15"> 于是耶稣从摩西和所有的先知开始，向他们解释了经上一切关于自己的话。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马可福音 6:48; 创世记 19:2; 创世记 32:26"> 他们快到要去的村子了，耶稣好像还要往前走。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪下 4:8; 路加福音 14:23; 创世记 19:3"> 他们就极力挽留他，说：“时候晚了，太阳已经平西了，请与我们一起住下吧！”耶稣就进去，与他们一起住下。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="马太福音 14:19; 路加福音 24:35; 马太福音 15:36"> 当耶稣与他们一同坐席的时候，他拿起饼来，祝福了，然后掰开递给他们。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 24:16; 约翰福音 8:59; 路加福音 4:30"> 那时他们的眼睛就开了，这才认出他来，而耶稣从他们眼前消失了。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 24:45; 耶利米书 23:29; 希伯来书 4:12"> 他们彼此说：“在路上他对我们说话，为我们讲解经文的时候，我们心里不是在燃烧吗？”</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 16:13; 约翰福音 20:19–26; 使徒行传 1:14"> 他们就立刻起身，回耶路撒冷去，见到那十一个使徒和与他们聚集在一起的人，</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 15:5; 马可福音 16:7; 路加福音 22:54–62"> 大家都在说：“主真的复活了，并且已经向西门显现了！”</span>
<span className="v" id="v35" data-v="35" data-xref="马可福音 16:12–13; 使徒行传 2:42; 路加福音 24:30–31"> 两个人就把在路上所发生的，以及耶稣掰饼的时候怎样被他们认出来的事，都述说了一遍。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="帖撒罗尼迦后书 3:16; 以赛亚书 57:18; 马可福音 16:14"> 在他们说这些话的时候，耶稣<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="耶稣——有古抄本作“他”。">k</a></sup>亲自站在他们当中，对他们说：<span className="woj">“愿你们平安！”</span><sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="有古抄本没有“对他们说：‘愿你们平安！’”">l</a></sup></span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳记上 28:13; 马太福音 14:26–27; 约伯记 4:14–16"> 他们就惊慌，感到害怕，以为看到了幽灵。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米书 4:14; 希伯来书 4:13; 但以理书 4:19"> 耶稣对他们说：<span className="woj">“你们为什么惊慌不安？为什么心里起疑惑呢？</span></span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 20:27; 约翰一书 1:1; 传道书 12:7"> <span className="woj">你们看我的手、我的脚，确实是我。摸我看看！幽灵没有骨，也没有肉，你们看，我是有的。”</span></span>
<span className="v" id="v40" data-v="40"> 说了这话，他就把手和脚给他们看。<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="有古抄本没有此节。">m</a></sup></span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 21:5; 诗篇 126:1–2; 创世记 45:26–28"> 他们又惊又喜，还不敢相信的时候，耶稣对他们说：<span className="woj">“你们这里有什么吃的吗？”</span></span>
<span className="v" id="v42" data-v="42"> 他们递给他一片烤鱼<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="烤鱼——有古抄本作“烤鱼和蜂蜜”。">n</a></sup>，</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行传 10:41"> 他拿过来，当着他们的面吃了。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="撒迦利亚书 12:10; 路加福音 24:26–27; 撒迦利亚书 9:9"> 耶稣对他们说：<span className="woj">“这就是我还与你们在一起的时候，对你们说过的话：摩西的律法、先知书和诗篇上所记的有关我的一切事，都必须应验。”</span></span>
<span className="v" id="v45" data-v="45" data-xref="使徒行传 16:14; 约翰一书 5:20; 诗篇 119:18"> 于是耶稣开启他们的理性，使他们能领悟经上的话，</span>
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 53:2–12; 以赛亚书 50:6; 路加福音 24:44"> 又对他们说：<span className="woj">“经上这样记着：基督必须</span><sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="有古抄本没有“必须”。">o</a></sup><span className="woj">受难，然后在第三天从死人中复活，</span></span>
<span className="v" id="v47" data-v="47" data-xref="使徒行传 5:31; 以赛亚书 49:6; 使徒行传 2:38"> <span className="woj">并且人要奉他的名宣讲为罪得赦免的悔改</span><sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="为罪得赦免的悔改——有古抄本作“悔改和罪得赦免的道”。">p</a></sup><span className="woj">，从耶路撒冷开始，直到万国。</span></span>
<span className="v" id="v48" data-v="48" data-xref="使徒行传 1:8; 使徒行传 2:32; 使徒行传 13:31"> <span className="woj">你们就是这些事的见证人。</span></span>
<span className="v" id="v49" data-v="49" data-xref="使徒行传 1:8; 使徒行传 1:4; 约珥书 2:28–32"> <span className="woj">看哪！我要将我父所应许的差派到你们那里</span><sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="到你们那里——原文直译“在你们身上”。">q</a></sup><span className="woj">。不过你们要留在城</span><sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="城——有古抄本作“耶路撒冷城”。">r</a></sup><span className="woj">里，直到领受</span><sup className="fn"><a href="#fn-s" id="fnref-s" data-fn="领受——原文直译“穿上”。">s</a></sup><span className="woj">了从上面</span><sup className="fn"><a href="#fn-t" id="fnref-t" data-fn="上面——原文直译“高处”。">t</a></sup><span className="woj">来的能力。”</span></span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="使徒行传 1:12; 马太福音 21:17; 马可福音 11:1"> 耶稣领他们出去，到了伯大尼附近，就举起双手祝福他们。</span>
<span className="v" id="v51" data-v="51" data-xref="使徒行传 1:9; 马可福音 16:19; 列王纪下 2:11"> 他在祝福的时候离开他们，被接到天上去了<sup className="fn"><a href="#fn-u" id="fnref-u" data-fn="有古抄本没有“被接到天上去了”。">u</a></sup>。</span>
<span className="v" id="v52" data-v="52" data-xref="马太福音 28:9; 约翰福音 16:22; 诗篇 30:11"> 他们就敬拜他<sup className="fn"><a href="#fn-v" id="fnref-v" data-fn="有古抄本没有“敬拜他”。">v</a></sup>，怀着极大的喜乐回耶路撒冷去，</span>
<span className="v" id="v53" data-v="53" data-xref="马可福音 16:20; 使徒行传 2:46–47; 使徒行传 5:41–42"> 常常在圣殿里颂赞<sup className="fn"><a href="#fn-w" id="fnref-w" data-fn="颂赞——有古抄本作“赞美和称颂”。">w</a></sup>神。<sup className="fn"><a href="#fn-x" id="fnref-x" data-fn="有古抄本附“阿们。”">x</a></sup></span>

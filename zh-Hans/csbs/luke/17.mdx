<span className="v" id="v2" data-v="2" data-xref="马可福音 9:42; 马太福音 18:14; 马太福音 18:3–6"> <span className="woj">对他来说，就算脖子上拴着大磨石</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="大磨石——原文直译“磨坊的磨石”；有古抄本作“驴拉的磨石”。">b</a></sup><span className="woj">，被丢到海里，也比他使这些卑微人中的一个绊倒更好。</span></span>
<span className="v" id="v3" data-v="3" data-xref="利未记 19:17; 马太福音 18:21; 马太福音 18:15–17"> <span className="woj">你们要谨慎！如果你的弟兄</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本附“对你”。">c</a></sup><span className="woj">犯了罪，就告诫他；如果他悔改，就饶恕他。</span></span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 3:12–13; 马太福音 18:21–22; 罗马书 12:20"> <span className="woj">如果他一天七次对你犯了罪，又</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有古抄本附“一天”。">d</a></sup><span className="woj">七次回转过来，对你说：‘我悔改！’你要饶恕他。”</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马可福音 9:24; 希伯来书 12:2; 腓立比书 4:13"> 使徒们对主说：“请你加添我们的信心<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="信心——指“对耶稣基督的信心”。">e</a></sup>。”</span>

</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 12:11; 路加福音 13:15; 路加福音 14:5"> <span className="woj">“你们当中谁有奴仆耕田或放羊，从田里回来的时候，会对奴仆说‘立刻过来，坐下吃饭’呢？</span></span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 12:37; 创世记 43:16; 撒母耳记下 12:20"> <span className="woj">他难道不会对奴仆说‘你预备我所要吃的晚餐，束上腰带伺候我，等我吃喝完了，你才要吃喝’吗？</span></span>
<span className="v" id="v9" data-v="9"> <span className="woj">奴仆做了所吩咐的事，难道主人要向奴仆怀有感恩的心吗？</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本附“我认为不会。”">f</a></sup></span>

</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路加福音 9:51–52; 约翰福音 4:3–4"> 耶稣往耶路撒冷去的时候，经过撒玛利亚和加利利的中间地带。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 13:45–46; 路加福音 5:12; 列王纪下 7:3"> 他进了一个村子，有十个麻风病人见到他，远远地站着，</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 15:22; 马太福音 20:30–31; 马太福音 9:27"> 大声说：“耶稣啊，老师啊，可怜我们吧！”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 5:14; 利未记 13:1–46; 列王纪下 5:14"> 耶稣看见了，就对他们说：<span className="woj">“你们去，让祭司检查你们吧！”</span>结果在他们去的时候，就被洁净了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="诗篇 30:11–12; 诗篇 103:1–4; 诗篇 118:18–19"> 其中有一个人看见自己得了痊愈，就回来大声地荣耀神，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 8:5–25; 马太福音 10:5; 启示录 19:10"> 并且把脸伏在耶稣脚前，感谢他。这人是个撒玛利亚人。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 1:21; 诗篇 106:13; 创世记 3:9"> 耶稣回答说：<span className="woj">“被洁净的不是有十个人吗？另外九个在哪里呢？</span></span>

<span className="v" id="v19" data-v="19" data-xref="路加福音 7:50; 路加福音 8:48; 马可福音 10:52"> 然后耶稣对他说：<span className="woj">“起来，走吧！你的信救了你。”</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约翰福音 18:36; 路加福音 19:11; 但以理书 2:44"> 有一次，法利赛人问耶稣：“神的国什么时候到来呢？”耶稣回答说：<span className="woj">“神国的到来，不是眼所能见的。</span></span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 12:28; 罗马书 14:17; 马可福音 13:21"> <span className="woj">没有人能说‘看，在这里！’或‘在那里！’因为看哪，神的国就在你们中间</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="在你们中间——或译作“在你们心里”。">g</a></sup><span className="woj">。”</span></span>

<span className="v" id="v23" data-v="23" data-xref="路加福音 21:8; 马太福音 24:23–26; 路加福音 17:21"> <span className="woj">他们会告诉你们‘看，在那里！’或‘看，在这里！’你们不要出去，也不要追随他们；</span></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 24:27; 马太福音 24:30; 玛拉基书 4:1–2"> <span className="woj">因为就像闪电一闪，从天这边照耀到天那边，人子在他的日子</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="有古抄本没有“在他的日子”。">h</a></sup><span className="woj">也将要这样。</span></span>

</div>

<span className="v" id="v26" data-v="26" data-xref="马太福音 24:37–39; 路加福音 17:24; 创世记 7:7–23"> <span className="woj">“在挪亚的那些日子里发生的怎样，在人子的那些日子里也将要怎样：</span></span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 12:19–20; 帖撒罗尼迦前书 5:1–3; 路加福音 16:19–23"> <span className="woj">人们继续吃、喝、嫁、娶，直到挪亚进方舟的那一天，洪水到来，把一切都毁灭了。</span></span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 16:49–50; 创世记 18:20–21; 雅各书 5:1–5"> <span className="woj">同样，就像在罗得的那些日子里发生的那样：人们继续吃喝、买卖、耕种、建造，</span></span>

<span className="v" id="v32" data-v="32" data-xref="创世记 19:26; 希伯来书 10:38–39; 彼得后书 2:18–22"> <span className="woj">你们当记得罗得的妻子！</span></span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 8:35–37; 马太福音 10:39; 约翰福音 12:25"> <span className="woj">凡想要保全</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="保全——原文直译“买来”；有古抄本作“救”。">i</a></sup><span className="woj">自己生命的，将失去生命；凡失去自己生命的，将保存生命。</span></span>

<span className="v" id="v36" data-v="36"> <span className="woj">两个人在田里，一个会被接去，另一个会被留下。</span><sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="有古抄本没有此节。">j</a></sup><span className="woj">”</span></span>

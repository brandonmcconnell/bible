<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 3:1; 马太福音 24:14; 使徒行传 25:21"> 就在那些日子里，凯撒奥古斯都颁布谕令，要普天下的人都登记户口<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="户口——辅助词语。">a</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 3:1; 马太福音 4:24; 使徒行传 26:30"> 这是头一次户口登记，在居里尼乌斯任叙利亚总督的时候进行的。</span>
<span className="v" id="v3" data-v="3"> 于是众人都各回自己的城镇去登记。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="弥迦书 5:2; 约翰福音 7:42; 撒母耳记上 16:1"> 约瑟也从加利利的拿撒勒城上犹太去，到了那叫做伯利恒的大卫之城，因为他是大卫一家一族的人。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 22:22–27; 马太福音 1:18–19"> 他和已经许配给他<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附“做妻子”。">b</a></sup>、怀有身孕的玛丽亚一起去登记。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 33:11; 启示录 12:1–5; 弥迦书 5:2"> 他们在伯利恒的时候，玛丽亚的产期到了，</span>
<span className="v" id="v7" data-v="7" data-xref="加拉太书 4:4; 哥林多后书 8:9; 以赛亚书 53:2–3"> 就生了她的头胎儿子。她用布把他包起来放在马槽里，因为客店里没有地方给他们。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="创世记 31:39–40; 诗篇 78:70–71; 撒母耳记上 17:34–35"> 当时在同一个地区，有些牧人露宿在野地里，夜间守更看守羊群。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 60:1; 哥林多后书 3:18; 列王纪上 8:11"> 这时候，主的一位天使站在他们旁边<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="站在他们旁边——或译作“向他们显现”。">c</a></sup>，主的荣光四面照射他们，他们就大为惊恐。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 40:9; 以赛亚书 61:1; 以赛亚书 52:7"> 那位天使对他们说：“不要怕！因为看哪，我传给你们一个大喜的信息，是要给万民的。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 9:6; 马太福音 1:21; 使徒行传 2:36"> 今天，在大卫的城里，为你们诞生了一位救主，他就是主基督。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 7:14; 以赛亚书 53:1–2; 以赛亚书 7:11"> 你们会看见一个婴孩，用布包着，躺在马槽里；这就是给你们的标记。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="诗篇 103:20–21; 启示录 5:11; 诗篇 148:2"> 忽然有一大队天军出现，与那位天使一起赞美神，说：</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 5:1; 路加福音 19:38; 歌罗西书 1:20"> <span className="pl pl-1">“在至高之处，荣耀归于神！</span><br /><span className="pl pl-1">在地上，平安</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="平安——或译作“和平”。">d</a></sup><br /><span className="pl pl-1">临到他所喜悦的人！”</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="彼得前书 3:22; 马太福音 2:1–2; 马太福音 2:9–11"> 天使们离开他们往天上去了，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附“而那些人——”。">e</a></sup>牧人就彼此说：“来，我们到伯利恒去，看看这件已成就的事，就是主让我们明白的事！”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:32; 路加福音 2:12; 路加福音 2:7"> 于是他们急忙赶去，找到了玛丽亚、约瑟和那躺在马槽里的婴孩。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 66:16; 路加福音 8:39; 诗篇 71:17–18"> 他们看见以后，就把天使告诉他们有关这孩子的话传开了。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 2:47; 路加福音 4:36; 路加福音 1:65–66"> 所有听见的人，对那些牧人告诉他们的事，都感到惊奇。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 2:51; 路加福音 1:66; 箴言 4:4"> 玛丽亚却把这一切事存在心里，反复思想。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 106:48; 以赛亚书 29:19; 使徒行传 11:18"> 那些牧人因为所见所闻的一切正如天使向他们所说的，就荣耀、赞美神，于是回去了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:31; 创世记 17:12; 加拉太书 4:4–5"> 满了八天，为孩子行割礼的时候，他们就给他起名叫耶稣。这名字是他在母<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="母——辅助词语。">f</a></sup>腹成胎以前天使所起的。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 12:1–8"> 按照摩西的律法，洁净的日子满了以后，约瑟和玛丽亚领着孩子上耶路撒冷去，要把他献给主。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 13:2; 出埃及记 22:29; 民数记 3:13"> 正如主的律法上所记载的：“所有头胎的男孩都将被称为圣归给主；”</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 12:6–8; 利未记 12:2; 哥林多后书 8:9"> 并按照主的律法上所说的，献上了“一对斑鸠或两只雏鸽”为祭物。</span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 25:9; 路加福音 2:38; 路加福音 1:6"> 看哪，在耶路撒冷有一个名叫西缅的人。这个人又公义又虔诚，一直期待着以色列得蒙安慰；圣灵也在他身上。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 8:51; 希伯来书 11:5; 路加福音 9:27"> 他得了圣灵的启示：自己在经历死亡<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="经历死亡——原文直译“见到死亡”。">g</a></sup>以前会看见主的基督。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 4:1; 路加福音 2:41; 路加福音 2:51"> 他受了圣灵的感动，来到圣殿。这时候，耶稣的父母抱着孩子进来，要按照律法的规矩为他办事。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 1:64; 路加福音 2:20; 路加福音 2:13–14"> 西缅把孩子抱在怀里，颂赞神说：</span>
<span className="v" id="v29" data-v="29" data-xref="启示录 14:13; 创世记 15:15; 腓立比书 1:23"> <span className="pl pl-1">“主啊，</span><br /><span className="pl pl-1">现在可以照你的话，</span><br /><span className="pl pl-1">让你的奴仆平平安安地离去，</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="以赛亚书 49:6; 路加福音 2:10–11; 路加福音 3:6"> <span className="pl pl-1">因为我的眼睛已经看见你的救恩，</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 62:1–2; 以赛亚书 42:1–4; 诗篇 98:2–3"> <span className="pl pl-1">就是你为万民</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="为万民——原文直译“在万民面前”。">h</a></sup><br /><span className="pl pl-1">所预备的：</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 60:1–3; 以赛亚书 49:6; 使徒行传 26:23"> <span className="pl pl-1">他是启示外邦人的光，</span><br /><span className="pl pl-1">是你子民以色列的荣耀。”</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 1:65–66; 以赛亚书 8:18; 路加福音 2:48"> 他的父母<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="他的父母——有古抄本作“约瑟和孩子的母亲”。">i</a></sup>对这些关于孩子的话，感到惊奇。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 1:23; 彼得前书 2:7–8; 以赛亚书 8:14–15"> 西缅祝福他们，并对孩子的母亲玛丽亚说：“看哪，这孩子注定要使以色列中许多人跌倒、许多人兴起，并要成为一个遭受反对的标记<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="遭受反对的标记——或译作“被攻击的对象”。">j</a></sup>，</span>
<span className="v" id="v35" data-v="35" data-xref="申命记 8:2; 哥林多前书 11:19; 马太福音 12:24–35"> 这样，许多人的心思意念将被显露出来；你自己的灵魂也要被剑刺透。”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="出埃及记 15:20; 创世记 30:13; 使徒行传 21:9"> 有一个女先知安娜，是亚设支派法努埃的女儿。她已经上了年纪，是出嫁以后与丈夫生活了七年的，</span>
<span className="v" id="v37" data-v="37" data-xref="提摩太前书 5:5; 诗篇 23:6; 使徒行传 14:23"> 后来守寡了，现在已经<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="现在已经——有古抄本作“约”。">k</a></sup>八十四岁。她从不离开圣殿，禁食祈祷，日夜事奉神。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 2:25; 哥林多后书 9:15; 马可福音 15:43"> 就在这时候，她也上前来赞颂神<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="神——有古抄本作“主”。">l</a></sup>，向所有期待着耶路撒冷得救赎的人<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="期待着耶路撒冷得救赎的人——有古抄本作“在耶路撒冷期待救赎的人们”。">m</a></sup>讲说这孩子的事。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 2:4; 加拉太书 4:4–5; 申命记 12:32"> 约瑟和玛丽亚按照主的律法办完了一切事以后，就返回加利利，到自己的城拿撒勒去了。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 2:52; 路加福音 1:80; 以赛亚书 11:1–5"> 那孩子渐渐长大，坚强<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="坚强——有古抄本作“灵里坚强”。">n</a></sup>而充满智慧，并且有神的恩典在他身上。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="出埃及记 12:14; 民数记 28:16; 申命记 12:18"> 每年逾越节，耶稣的父母都上耶路撒冷去。</span>
<span className="v" id="v42" data-v="42"> 当耶稣十二岁的时候，他们按照节日的规矩上去<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="上去——有古抄本作“上耶路撒冷去”。">o</a></sup>。</span>
<span className="v" id="v43" data-v="43" data-xref="历代志下 30:21–23; 出埃及记 12:15; 历代志下 25:17"> 守完了节期，他们回去的时候，孩童耶稣仍然留在耶路撒冷，他的父母<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="他的父母——有古抄本作“约瑟和孩子的母亲”。">p</a></sup>却不知道，</span>
<span className="v" id="v44" data-v="44" data-xref="诗篇 122:1–4; 以赛亚书 2:3; 诗篇 42:4"> 以为他在同行的人群中。他们走了一天的路，才开始在亲戚和熟人中找他。</span>
<span className="v" id="v45" data-v="45"> 他们找不到他，就回到耶路撒冷去找。</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 5:17; 以赛亚书 49:1–2; 以赛亚书 50:4"> 到了第三天，他们发现耶稣在圣殿里，坐在教师们当中，一边听，一边问。</span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 7:28; 路加福音 4:32; 诗篇 119:99"> 所有听他讲说的人，都对他的悟性和对答十分惊讶。</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 2:49; 马太福音 12:46; 路加福音 3:23"> 他的父母看见他，感到吃惊，他的母亲就对他说：“孩子啊，为什么对我们这样做呢？你看，你父亲和我一直在焦急地找你呢！”</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="约翰福音 6:38; 约翰福音 8:29; 玛拉基书 3:1"> 耶稣对他们说：<span className="woj">“你们为什么找我呢？难道不知道我必须在我父的家里</span><sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="在我父的家里——或译作“从事于我父的事”。">q</a></sup><span className="woj">吗？”</span></span>
<span className="v" id="v50" data-v="50" data-xref="路加福音 18:34; 路加福音 9:45; 马可福音 9:32"> 可是他们没有领悟他对他们说的话。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="路加福音 2:19; 但以理书 7:28; 创世记 37:11"> 于是耶稣与他们一起下去，回到拿撒勒，一直服从他们。他的母亲把这一切事都珍藏在心里。</span>
<span className="v" id="v52" data-v="52" data-xref="路加福音 2:40; 箴言 3:3–4; 撒母耳记上 2:26"> 耶稣的智慧和身量，以及神和人对他的喜爱<sup className="fn"><a href="#fn-r" id="fnref-r" data-fn="神和人对他的喜爱——或译作“在神和人面前的喜爱”。">r</a></sup>，都不断增长。</span>
</div>
</div>

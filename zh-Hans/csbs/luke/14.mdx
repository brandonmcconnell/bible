<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 3:2; 路加福音 20:20; 诗篇 62:4"> 有一个安息日，耶稣到一个法利赛人的首领家里去吃饭<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="饭——原文直译“饼”。">a</a></sup>，他们密切注意着耶稣。</span>
<span className="v" id="v2" data-v="2"> 当时，有一个患水肿病的人在他面前。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 12:10; 马可福音 3:4; 路加福音 13:14–16"> 于是耶稣问律法师们和法利赛人，说：<span className="woj">“在安息日使人痊愈，可以不可以？”</span></span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 22:46; 马太福音 21:25–27"> 他们都安静下来。耶稣就扶着那人，使他痊愈，让他走了。</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 13:15; 出埃及记 23:4–5; 马太福音 12:11–12"> 然后耶稣对他们说：<span className="woj">“你们当中谁有儿子</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="儿子——有古抄本作“驴”。">b</a></sup><span className="woj">或牛在安息日这一天掉到井里，而不立刻把他拉上来呢？”</span></span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 20:40; 路加福音 21:15; 使徒行传 6:10"> 他们对这些话不能答辩。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="腓立比书 2:3; 路加福音 11:43; 马太福音 23:6"> 耶稣留意到被邀请的人怎样在那里挑选上座，就对他们讲了一个比喻说：</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 25:6–7"> <span className="woj">“你被人邀请赴婚宴的时候，不要坐在上座，恐怕有比你更尊贵的人也被邀请，</span></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 16:18; 箴言 11:2; 箴言 3:35"> <span className="woj">那邀请你们</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="你们——原文直译“你和他”。">c</a></sup><span className="woj">的会来对你说：‘请让座给这一位！’那时候，你就要羞惭地去坐末位了。</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="箴言 25:6–7; 箴言 15:33; 撒母耳记上 15:17"> <span className="woj">“你被邀请的时候，要去坐在末位上，好让邀请你的人一旦来，就会对你说：‘朋友，请来上座。’那时候，你就在所有一同坐席的人面前有光彩了。</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 18:14; 马太福音 23:12; 箴言 29:23"> <span className="woj">因为每一个自我高举的都会被降卑；而自我降卑的都会被高举。”</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 5:46; 雅各书 2:1–6; 路加福音 6:32–36"> 耶稣又对邀请他的人说：<span className="woj">“你预备午餐或晚餐的时候，不要叫你的朋友、兄弟、亲戚或富有的邻居，免得他们也回请你，你就得了你的回报了。</span></span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 14:21; 以赛亚书 58:10; 箴言 14:31"> <span className="woj">相反，你预备宴席的时候，要邀请那些贫穷的、残疾的、瘸腿的、瞎眼的，</span></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 19:17; 使徒行传 24:15; 约翰福音 5:29"> <span className="woj">这样你就蒙福了，因为他们没有可回报你的，而在义人复活的时候，你将得到回报。”</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="启示录 19:9; 路加福音 22:30; 路加福音 13:29"> 一同坐席的有一个人听了这些话，就说：“将来能在神的国里吃饭<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="饭——原文直译“饼”。">d</a></sup>的人是蒙福的！”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马太福音 22:2–14; 启示录 22:17; 以赛亚书 55:1–7"> 耶稣对他说：<span className="woj">“有一个人预备盛大的宴席，邀请了许多人。</span></span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 11:27–29; 马太福音 10:1–4; 马太福音 22:3–4"> <span className="woj">到了宴席的时刻，他派奴仆去对那些被邀请的人说：‘请来吧，一切都已经预备好了！’</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="提摩太前书 6:9–10; 路加福音 17:26–31; 路加福音 18:24"> <span className="woj">“可是他们都开始一致地推辞。第一个说：‘我买了一块地，必须去看看，请你容我推辞吧。’</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> <span className="woj">“另一个说：‘我买了五对牛，正要去试试它们，请你容我推辞吧。’</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命记 24:5; 哥林多前书 7:33; 路加福音 14:26–28"> <span className="woj">“另有人说：‘我刚娶了妻子，所以不能去。’</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 14:13; 马太福音 11:5; 路加福音 14:24"> <span className="woj">“奴仆回来把这些事报告给主人。那家的主人就发怒，吩咐奴仆说：‘赶快出去，到城里的大街</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="大街——或译作“广场”。">e</a></sup><span className="woj">小巷，把那些贫穷的、残疾的、瞎眼的、瘸腿的，都带到这里来。’</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约翰福音 14:2; 以弗所书 3:8; 提摩太前书 2:5–6"> <span className="woj">“奴仆说：‘主人，你所吩咐的已经做了，可是还有位子。’</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 22:9–10; 歌罗西书 1:28; 使徒行传 13:47–48"> <span className="woj">“主人就对奴仆说：‘出去，到大街和小巷</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="小巷——原文直译“篱笆边”。">f</a></sup><span className="woj">上去，强求人进来，好坐满我的房子。</span></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 21:43; 使徒行传 13:46; 约翰福音 8:24"> <span className="woj">我告诉你们：原本被邀请的那些人，没有一个能尝到我的宴席。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 6:24–27; 路加福音 12:1"> 有一大群人与耶稣同行。他转过身来对他们说：</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 10:37; 约翰福音 12:25; 腓立比书 3:8"> <span className="woj">“如果有人到我这里来，而不恨自己的父亲、母亲、妻子、儿女、兄弟、姐妹，甚至自己的生命，他就不能做我的门徒。</span></span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 10:38; 路加福音 9:23–25; 马可福音 8:34–37"> <span className="woj">凡是不背着自己的十字架来跟从我的，也不能做我的门徒。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="箴言 24:27; 马太福音 10:22; 约书亚记 24:19–24"> <span className="woj">“你们当中到底有谁想盖一座楼，不先坐下来计算费用，看自己是否能够完成呢？</span></span>
<span className="v" id="v29" data-v="29"> <span className="woj">免得立好了地基，却不能完工，看见的人都开始嘲笑他，</span></span>
<span className="v" id="v30" data-v="30" data-xref="希伯来书 6:11; 约翰二书 1:8; 哥林多前书 3:11–14"> <span className="woj">说：‘这个人开始盖了，却不能完工！’</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="箴言 20:18; 箴言 25:8; 列王纪下 18:20–22"> <span className="woj">“或者，有哪一个君王要出去和别的君王交战，不先坐下来考虑是否能够用一万兵去迎战那用两万兵来攻打他的呢？</span></span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 12:20; 雅各书 4:6–10; 路加福音 12:58"> <span className="woj">否则，就会趁着他还远的时候，差派特使去求问和平的事宜。</span></span>
<span className="v" id="v33" data-v="33" data-xref="腓立比书 3:7–8; 约翰一书 2:15–16; 路加福音 5:28"> <span className="woj">同样，你们当中任何人，如果不向自己所拥有的一切告别，就不能做我的门徒。</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马太福音 5:13; 歌罗西书 4:6; 马可福音 9:49–50"> <span className="woj">“因此盐是好的，但如果连盐也失去了味道，还能用什么来调味呢？</span></span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 11:15; 路加福音 9:44; 启示录 2:11"> <span className="woj">把它用在田地里或在粪肥里都不合适，只好把它丢在外面。凡是有耳可听的，就应当听！”</span></span>
</div>
</div>

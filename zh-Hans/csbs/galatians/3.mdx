<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="GAL" data-book-slug="galatians" data-book-name="加拉太书" data-chapter="3" data-verses="29">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 5:7–8; 哥林多后书 11:3; 加拉太书 1:6"> 唉，无知的加拉太人哪！是谁迷惑了你们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古抄本附“使你们不信从真理”。">a</a></sup>呢？被钉十字架的耶稣基督，难道不是先前被描绘在你们眼前的吗？</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 10:16–17; 加拉太书 3:14; 使徒行传 15:8"> 我只想请教你们这一点：你们领受了圣灵，是本于律法上的行为，还是本于信而听从呢？</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 5:4–8; 加拉太书 4:7–10; 希伯来书 7:16–19"> 你们是这样的无知吗？你们以圣灵开始，现在却要以肉体完成吗？</span>
<span className="v" id="v4" data-v="4" data-xref="约翰二书 1:8; 哥林多前书 15:2; 希伯来书 10:32–39"> 你们受了这么多的苦，都没有意义吗？会不会真的没有意义呢！</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 3:2; 使徒行传 14:9–10; 使徒行传 19:11–12"> 那么，神赐给你们圣灵，又在你们中间行神迹，是本于你们在律法上的行为，还是本于你们信而听从呢？</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 15:6; 罗马书 4:21–22; 雅各书 2:23"> 正如“亚伯拉罕信神，这就被算为他的义”，</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 9:7–8; 加拉太书 3:9; 加拉太书 3:26–29"> 因此你们应当知道：那些本于信的，他们才是亚伯拉罕的子孙。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 12:3; 创世记 22:18; 创世记 28:14"> 既然经文预先看见神要使外邦人因信称义，就预先把福音传给了亚伯拉罕，说：“万国都要藉着你蒙祝福。”</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 4:16; 加拉太书 3:29; 罗马书 4:24"> 这样，那些有信仰的人，与有信仰的亚伯拉罕一同蒙祝福。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命记 27:26; 罗马书 8:7; 罗马书 3:19–20"> 凡是本于律法上行为的人，都在诅咒之下，因为经上记着：“任何人不持守、不遵行律法书上所记载的一切，都是被诅咒的。”</span>
<span className="v" id="v11" data-v="11" data-xref="哈巴谷书 2:4; 罗马书 1:17; 希伯来书 10:38"> 所以，明显地没有人能藉着律法在神面前被称为义，因为经上说：“义人将因信而活。”</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 18:5; 罗马书 10:5–6; 尼希米记 9:29"> 律法不是本于信，但是“遵行这些事的人，将因此而活。”</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前书 2:24; 申命记 21:23; 希伯来书 9:12"> 基督替我们成了诅咒，从律法的诅咒中救赎了我们，因为经上记着：“凡是被挂在木头上的，都是被诅咒的。”</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 3:28–29; 哥林多前书 12:13; 以西结书 36:26–27"> 这是为了让亚伯拉罕所蒙的祝福，能在基督耶稣里临到外邦人，好使我们能藉着信领受所应许的圣灵。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="希伯来书 9:17; 罗马书 6:19; 罗马书 3:5"> 弟兄们，我按人的意思说话：甚至是人的约，一旦证实了，也没有人能废弃或加添。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 17:7–8; 罗马书 4:13; 路加福音 1:55"> 神的各样应许，原是对亚伯拉罕和他的一个后裔说的。神并没有说“后裔们”，像是指着许多人；而是说“你的一个后裔”，像是指着一个人，这一位就是基督。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 11:39–40; 创世记 15:13; 罗马书 4:13–14"> 我说的这话是：四百三十年以后出现的律法，不能废弃神<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古抄本附“为基督”。">b</a></sup>预先立好的约，使那应许无效。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 6:12–15; 加拉太书 2:21; 罗马书 4:13–16"> 如果继业是本于律法，就不再是本于应许了；但是神把继业<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="继业——辅助词语。">c</a></sup>赐给亚伯拉罕是藉着应许。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 7:53; 罗马书 7:7–13; 希伯来书 2:2"> 那么，为什么要有律法呢？律法是为了过犯的缘故被加上的，直到那蒙应许的后裔<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="那蒙应许的后裔——指“耶稣基督”。">d</a></sup>来临；律法是藉着天使，通过中保的手所规定的。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太前书 2:5; 申命记 6:4; 约伯记 9:33"> 不过中保没有为一方的，神却是一位。</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太书 2:21; 罗马书 9:31; 罗马书 3:20–22"> 那么，律法和神的各样应许是对立的吗？绝对不是！如果一个能使人得生命的律法被赐下，义就真是本于律法了。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 11:32; 希伯来书 9:15; 加拉太书 3:23"> 然而，经上的话把万物<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="万物——或译作“万人”。">e</a></sup>都圈在罪孽之下，为要使这因信耶稣基督而来的应许，赐给那些相信的人。</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 5:18; 加拉太书 3:24–25; 加拉太书 3:19"> 只是在这信仰临到之前，我们都被圈在律法之下受看守，直到这将要来临的信仰被启示出来。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 10:4; 使徒行传 13:38–39; 罗马书 7:24–25"> 这样，律法一向是我们的导师<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="导师——或译作“监护人”。">f</a></sup>，直到基督，好使我们能因信称义。</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 6:14; 罗马书 7:4; 希伯来书 10:15–18"> 不过，这信仰既然已经临到，我们就不在导师<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="导师——或译作“监护人”。">g</a></sup>之下了，</span>
<span className="v" id="v26" data-v="26" data-xref="以弗所书 1:5; 哥林多后书 6:18; 约翰福音 1:12–13"> 因为你们藉着信，在基督耶稣里，都是神的儿女。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="罗马书 13:14; 哥林多前书 12:13; 罗马书 6:3–4"> 实际上，你们所有受洗<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="受洗——或译作“受浸”。">h</a></sup>归入基督的，就穿上了基督，</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 12:12–13; 歌罗西书 3:11; 罗马书 3:29–30"> 其中没有犹太人或希腊人，没有为奴的或自由的，没有男的或女的，因为你们在基督耶稣里都合而为一了。</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所书 3:6; 罗马书 9:7–8; 加拉太书 3:7"> 而且，如果你们属于基督，你们就是亚伯拉罕的后裔，是照着应许的继承人。</span>
</div>
</div>

</div>

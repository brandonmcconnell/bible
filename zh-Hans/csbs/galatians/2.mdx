<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 2:3; 使徒行传 14:12; 哥林多后书 8:23"> 过了十四年，我与巴拿巴一起再次上耶路撒冷，并且带着提多一起去。</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太书 2:6; 腓立比书 2:16; 帖撒罗尼迦前书 3:5"> 我是照着启示上去的，向他们陈述了我在外邦人中所传的福音，不过是单独地向那些公认是人物的做了陈述，免得我过去或是现在所奔跑的都落了空<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="免得我过去或是现在所奔跑的都落了空——或译作“这样，我过去或是现在就不会白白奔跑了”。">a</a></sup>。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 5:2–6; 使徒行传 16:3; 哥林多前书 9:20–21"> 与我在一起的提多，虽然是希腊人，也没有被迫受割礼。</span>
<span className="v" id="v4" data-v="4" data-xref="犹大书 1:4; 加拉太书 5:1; 加拉太书 4:3"> 其实提到这件事<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="提到这件事——辅助词语。">b</a></sup>，是因着一些偷偷进来的假弟兄的缘故；他们混进来窥视我们在基督耶稣里所拥有的自由，为了要奴役我们。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 2:14; 加拉太书 4:16; 歌罗西书 1:5"> 我们对这些人，一刻也没有屈服妥协，好使福音的真理在你们中间继续存留。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="加拉太书 2:2; 使徒行传 10:34; 哥林多后书 12:11"> 至于那些公认是人物的——无论他们从前什么样，都对我没有区别；神不以外貌取人。那些公认是人物的并没有给我增添什么；</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 9:15; 提摩太前书 2:7; 加拉太书 1:16"> 不过他们反而看出来：我受了委托去传福音给没有受割礼的人，正如彼得受了委托去传福音给受割礼的人，</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 9:15; 使徒行传 22:21; 使徒行传 2:14–41"> 因为在彼得里面做工、使他做受割礼之人使徒的那一位，也在我里面做工、使我做外邦人的使徒。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 12:3; 启示录 3:12; 加拉太书 2:2"> 公认是柱石的雅各、矶法和约翰，既然明白了神所赐给我的恩典，就向巴拿巴和我伸出右手行契合之礼<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="伸出右手行契合之礼——原文直译“伸出右手的契合”。">c</a></sup>，要我们往外邦人那里去，而他们往受割礼的人那里去；</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 24:17; 约翰一书 3:17; 希伯来书 13:16"> 只是要我们记得穷人，而这一点也正是我一向努力做的。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 5:20; 哥林多后书 5:16; 使徒行传 15:1"> 不过矶法<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="矶法——有古抄本作“彼得”。">d</a></sup>来到安提阿的时候，我曾当面抵挡他，因为他有该责备的地方。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 10:28; 路加福音 15:2; 使徒行传 11:2–3"> 原来，从雅各那里来的一些人到达之前，矶法与外邦人一起吃饭；可是那些人一到，他因为怕那些割礼派的人<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="割礼派的人——指“那些主张外邦人也必须受割礼的人”；或译作“受割礼的人”。">e</a></sup>，就退缩，与外邦人分开了。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 15:33; 以弗所书 4:14; 希伯来书 13:9"> 其余的犹太人也跟着他装假，以致连巴拿巴也被他们的伪善引入歧途。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 2:5; 使徒行传 10:28; 使徒行传 15:10–11"> 但我一看见他们的行为不符合福音的真理，就在大家面前对矶法<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="矶法——有古抄本作“彼得”。">f</a></sup>说：“你身为犹太人，如果像外邦人而不像犹太人那样生活，怎么还要强求外邦人像犹太人一样呢？”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="提多书 3:3; 以弗所书 2:3; 以弗所书 2:11–12"> 我们生来是犹太人，不是“外邦中的罪人”，</span>
<span className="v" id="v16" data-v="16" data-xref="腓立比书 3:9; 诗篇 143:2; 罗马书 9:30"> 不过我们知道：人被称为义不是本于律法上的行为，而是藉着信耶稣基督。于是我们信了基督耶稣，为要因信基督称义，而不是本于律法上的行为，因为没有一个人<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="人——原文直译“肉体”。">g</a></sup>本于律法上的行为会被称为义。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 6:1–2; 约翰一书 3:8–10; 约翰一书 3:5"> 但如果我们自己寻求在基督里被称为义，却被发现还是罪人，那么，难道基督就成了罪的仆人吗？绝对不是！</span>
<span className="v" id="v18" data-v="18" data-xref="加拉太书 4:9–12; 加拉太书 2:4–5; 加拉太书 2:12–16"> 因为我如果重建自己以前所拆毁的，就证明我是违犯律法的人。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 7:4; 罗马书 6:2; 帖撒罗尼迦前书 5:10"> 原来藉着律法，我已经向律法死了，使我能向神活着。我已经和基督一起被钉十字架，</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太书 5:24; 哥林多后书 5:15; 罗马书 6:4–6"> 所以现在活着的不再是我，而是基督在我里面活着；并且如今我在肉体中活着，是因信神的儿子而活；他爱我，甚至为我舍弃了自己。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 11:6; 加拉太书 3:21; 希伯来书 7:11"> 我不弃绝神的恩典，因为义如果是藉着律法而来的，那么，基督就白白地死了。</span>
</div>
</div>

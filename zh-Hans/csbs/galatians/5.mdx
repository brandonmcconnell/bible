<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 3:17; 加拉太书 5:13; 彼得前书 2:16"> 基督释放了我们，使我们得自由。所以你们当站立得稳，不要再被奴役的轭所束缚。</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太书 5:6; 使徒行传 15:1; 罗马书 9:31–32"> 看，我保罗告诉你们：如果你们要受割礼，基督就对你们毫无益处了。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 3:10; 罗马书 2:25; 雅各书 2:10–11"> 我再次忠告每一个受割礼的人：他有责任遵行全部律法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他有责任遵行全部律法——原文直译“他欠下这笔遵行全部律法的债”。">a</a></sup>。</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 9:31–32; 彼得后书 2:20–22; 罗马书 11:6"> 你们这些藉着律法被称为义的人，你们是与基督隔绝，从恩典中堕落了。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 130:5; 帖撒罗尼迦前书 1:10; 诗篇 62:5"> 要知道，我们藉着圣灵，本于信，满怀着<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="满怀着——原文直译“热切等待”。">b</a></sup>称义的盼望；</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 6:15; 哥林多前书 7:19; 雅各书 2:14–26"> 因为在基督耶稣里，受割礼或不受割礼都没有用处，只有藉着爱行出来的信仰才有用处。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 9:24; 加拉太书 3:1; 希伯来书 12:1"> 你们一向跑得很好，到底是谁拦阻了你们，使你们不信从真理呢？</span>
<span className="v" id="v8" data-v="8" data-xref="加拉太书 1:6; 罗马书 8:28"> 这种劝诱不是出于召唤你们的那一位。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 15:33; 哥林多前书 5:6–7; 马可福音 8:15"> 一点点酵母能使整个面团发酵。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 5:12; 哥林多后书 2:3; 加拉太书 1:7"> 我在主里深信你们不会有别的思想；不过那搅扰你们的，无论他是谁，都将受到惩罚。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 1:23; 加拉太书 6:12; 加拉太书 4:29"> 弟兄们，如果我仍然传讲割礼，我为什么还受逼迫呢？如果我这样做，十字架使人绊脚的地方早就没有了。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 5:10; 哥林多前书 5:13; 提多书 3:10"> 我真希望那些搅乱你们的人把自己阉割了！</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="彼得前书 2:16; 哥林多前书 9:19; 哥林多前书 8:9"> 弟兄们，你们蒙召是为了得自由，只是不可用这自由给肉体一个机会，而是要藉着爱彼此服事，</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 7:12; 利未记 19:18; 加拉太书 6:2"> 因为全部律法都在“要爱邻如己”这一句话里得以满足了。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 3:3; 雅各书 3:14–3; 加拉太书 5:26"> 你们要当心！如果你们继续相咬相吞，恐怕就要彼此毁灭了。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="加拉太书 5:24–25; 罗马书 8:12–14; 加拉太书 6:8"> 所以我说：你们应当顺着圣灵行走，这样就绝不会去满足肉体的欲望了；</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 8:13; 约翰福音 3:6; 罗马书 8:5–8"> 因为肉体的欲望与圣灵对立，圣灵也与肉体对立。这两者彼此反对，使你们不能做自己所愿意做的。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 8:14; 罗马书 6:14–15; 加拉太书 5:25"> 但如果你们被圣灵带领，就不在律法之下了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 6:9–10; 歌罗西书 3:5–8; 马太福音 15:18–19"> 肉体的行为是清清楚楚的，它们就是：通奸<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古抄本没有“通奸”。">c</a></sup>、淫乱、污秽、好色、</span>
<span className="v" id="v20" data-v="20" data-xref="提多书 3:10; 哥林多前书 11:19; 启示录 21:8"> 拜偶像、行邪术<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="邪术——或译作“巫术”或“毒品”。">d</a></sup>、仇恨、纷争、嫉恨、暴怒、争竞<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="争竞——或译作“结党”。">e</a></sup>、分裂、结派、</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 6:9–10; 罗马书 8:13; 罗马书 13:13"> 嫉妒、凶杀<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有古抄本没有“凶杀”。">f</a></sup>、醉酒、荒宴以及类似这样的事。对这些事，我现在要预先告诉你们，就像我以前告诉过你们的那样：行这些事的人不会继承神的国。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 3:12–17; 哥林多前书 13:4–7; 约翰福音 15:5"> 然而，圣灵的果子是：爱心、喜乐、和平、忍耐、仁慈、良善、忠信、</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太前书 1:9; 使徒行传 24:25; 提多书 2:2"> 温柔、自制。这样的事，没有律法反对。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 6:6; 罗马书 13:14; 罗马书 8:13"> 那些属于基督耶稣的人，已经把肉体与肉体的<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="肉体的——辅助词语。">g</a></sup>渴望和情欲一同钉上十字架了。</span>
<span className="v" id="v25" data-v="25" data-xref="加拉太书 5:16; 罗马书 8:4–5; 罗马书 8:2"> 我们既然藉着圣灵而活，就让我们靠着圣灵行走。</span>
<span className="v" id="v26" data-v="26" data-xref="雅各书 3:14–16; 腓立比书 2:1–3; 雅各书 4:16"> 我们不可贪图虚荣，彼此惹气，互相嫉妒。</span>
</div>

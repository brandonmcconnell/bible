<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 4:23; 加拉太书 4:29; 创世记 24:2–3"> 我说：继承人虽然是一切的主人，但是当他还是小孩子的时候，与奴仆没有区别；</span>
<span className="v" id="v2" data-v="2"> 他是在监护人和管家之下，直到父亲所预定的时候来到。</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 2:20; 歌罗西书 2:8; 加拉太书 4:9"> 我们也是这样：我们还是小孩子的时候，在世界的原则下受奴役。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 7:14; 约翰福音 1:14; 罗马书 1:3"> 但是等到时候一满足，神就派遣他的儿子，由女人所生，生在律法之下，</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 9:15; 以弗所书 1:5; 彼得前书 1:18–20"> 为要救赎律法之下的人，好使我们得到儿子的名份。</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 8:15–17; 罗马书 5:5; 罗马书 8:9"> 而且因你们是儿子，神就派遣他儿子的灵进入你们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你们——有古抄本作“我们”。">a</a></sup>的心，呼叫：“阿爸！父啊！”</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:16–17; 加拉太书 3:29–2; 加拉太书 3:26"> 这样，你不再是奴仆，却是儿子了；既然是儿子，就藉着神，也是继承人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="藉着神，也是继承人——有古抄本作“藉着基督，也是神的继承人”。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 8:4; 以弗所书 2:11–12; 帖撒罗尼迦后书 1:8"> 从前，你们不认识神的时候，固然给那些本性上不是神的做了奴仆，</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 8:3; 加拉太书 3:3; 罗马书 8:3"> 但如今，你们认识了神——不过更要说，被神所认识——怎么能再回到那无能、无用的原则里去呢？你们愿意再重新做它们的奴仆吗？</span>
<span className="v" id="v10" data-v="10" data-xref="歌罗西书 2:16–17; 罗马书 14:5; 利未记 23:1–44"> 你们竟严守着某些日子、月份、节期、年份！</span>
<span className="v" id="v11" data-v="11" data-xref="帖撒罗尼迦前书 3:5; 腓立比书 2:16; 加拉太书 2:2"> 我替你们担心，恐怕我为你们的劳苦毫无意义了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 2:5; 列王纪上 22:4; 创世记 34:15"> 弟兄们，我请求你们要像我一样，因为我也像你们一样。你们一点也没有亏负过我。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 2:3; 哥林多后书 12:7–10; 哥林多后书 11:30"> 你们知道，我原先传福音给你们，是身体有病的时候。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 10:40; 帖撒罗尼迦前书 2:13; 希伯来书 13:2"> 虽然我的身体对你们<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="你们——有古抄本作“我”。">c</a></sup>是个试炼，但你们并没有藐视我，也没有唾弃我，反而接受我如同接受神的使者、如同接受基督耶稣。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="罗马书 5:2; 约翰一书 3:16–18; 歌罗西书 4:13"> 你们当时的福份到哪里去了<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="到哪里去了——有古抄本作“成了什么”。">d</a></sup>呢？我可以给你们做见证：那时如果有可能，你们连自己的眼睛都会挖出来给我！</span>
<span className="v" id="v16" data-v="16" data-xref="阿摩司书 5:10; 箴言 9:8; 约翰福音 8:45"> 我对你们说真话<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="对你们说真话 ——或译作“对你们真诚”。">e</a></sup>，结果就成了你们的敌人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="敌人——或译作“反对者”。">f</a></sup>吗？</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 16:18; 哥林多后书 11:13–15; 彼得后书 2:3"> 那些人<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="那些人——指“假教师”。">g</a></sup>对你们热心，并不是出于好意，而是想要离间你们，好让你们对他们热心。</span>
<span className="v" id="v18" data-v="18" data-xref="腓立比书 2:12; 启示录 3:19; 腓立比书 1:27"> 不过在善事上常有热心，却是好的，但不要仅仅是我与你们在一起的时候才这样。</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所书 4:13; 罗马书 8:29; 罗马书 13:14"> 我的孩子们哪，为了你们，我再次经受临产的阵痛，直到基督在你们里面成形！</span>
<span className="v" id="v20" data-v="20" data-xref="帖撒罗尼迦前书 2:17–18; 哥林多前书 4:19–21; 帖撒罗尼迦前书 3:9"> 我现在想要与你们在一起，也要改变我的语气，因为我为你们的缘故心里困惑。</span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="加拉太书 3:10; 加拉太书 3:23–24; 罗马书 7:5–6"> 你们这些愿意在律法之下的人哪，请告诉我，难道你们没有听过律法吗？</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 16:15; 创世记 21:10; 创世记 21:1–2"> 因为经上记着：亚伯拉罕有两个儿子，一个出于女仆<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="女仆——指“夏甲”。参《创世记》16:15。">h</a></sup>，一个出于自由女人<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="自由女人——指“撒拉”。参《创世记》21:2。">i</a></sup>。</span>
<span className="v" id="v23" data-v="23" data-xref="希伯来书 11:11; 罗马书 9:7–8; 加拉太书 4:28–29"> 那出于女仆的是由肉体生的，那出于自由女人的是藉着应许生的。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 21:9–13; 希伯来书 10:15–18; 创世记 16:8"> 这些都是有寓意的。就是说，这两个女人是两个约。一个出于西奈山，生子为奴，她就是夏甲。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 19:44; 使徒行传 1:11; 加拉太书 1:17"> 这夏甲是指着阿拉伯的西奈山，相当于现在的耶路撒冷，因为耶路撒冷<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="耶路撒冷——原文直译“她”。">j</a></sup>和她的儿女都是为奴的。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 12:22; 腓立比书 3:20; 弥迦书 4:1–2"> 但那在上面的耶路撒冷是自由女人；她是我们<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="我们——有古抄本作“我们所有人”。">k</a></sup>的母亲。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 54:1–5; 诗篇 113:9; 路得记 4:14–16"> 因为经上记着：<br /><span className="pl pl-1">“不能生育、没有生产的女子啊，</span><br /><span className="pl pl-1">你要欢喜！</span><br /><span className="pl pl-1">没有经历临产阵痛的女子啊，</span><br /><span className="pl pl-1">你要放声呼喊！</span><br /><span className="pl pl-1">因为没有丈夫的女子，</span><br /><span className="pl pl-1">比有丈夫的女子有更多的儿女。”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="加拉太书 4:23; 罗马书 9:8–9; 罗马书 4:13–18"> 不过弟兄们，你们<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="你们——有古抄本作“我们”。">l</a></sup>就像以撒一样，是应许的儿女。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 21:9; 罗马书 8:13; 加拉太书 5:11"> 但正如那由肉体生的<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="那由肉体生的——指“夏甲的儿子以实玛利”。">m</a></sup>当时逼迫了那由圣灵生的<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="那由圣灵生的——指“撒拉的儿子以撒”。">n</a></sup>，现在也是这样。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 21:10–12; 约翰福音 8:35; 罗马书 8:15–17"> 然而经上是怎么说的呢？<br />“把女仆和她的儿子赶出去！因为女仆的儿子，绝不可以与自由女人的儿子一同做继承人。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 8:36; 约翰福音 1:12–13; 加拉太书 5:1"> 因此，弟兄们，我们不是女仆的儿女，而是自由女人的儿女。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 1:11–12; 哥林多前书 1:1; 罗马书 1:1"> 我<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="我——辅助词语。">a</a></sup>保罗做使徒，既不是出于人，也不是藉着人，而是藉着耶稣基督和使他从死人中复活的父神；</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 16:1; 腓立比书 4:21; 使徒行传 16:5–6"> 我和所有与我在一起的弟兄致加拉太的各教会：</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="约翰二书 1:3; 哥林多后书 13:14; 罗马书 1:7–15"> 愿恩典与平安从神我们的父和主耶稣基督<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="神我们的父和主耶稣基督——有古抄本作“父神和我们的主耶稣基督”。">b</a></sup>临到你们！</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 20:28; 罗马书 4:25; 加拉太书 2:20"> 基督照着神我们父的旨意，已经为我们的罪孽献上了自己，为要把我们从现今这邪恶的世代救出来。</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 11:36; 犹大书 1:25; 诗篇 72:19"> 愿荣耀归于他，直到永永远远！阿们。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 11:4; 加拉太书 5:7–8; 以赛亚书 29:13"> 我感到惊奇，你们这么轻易地离弃了藉着基督的恩典召唤你们的那一位，转向了别的福音。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 15:24; 罗马书 16:17–18; 加拉太书 5:10"> 其实那并不是另一个福音，而是有些人在搅扰你们，想要篡改基督的福音。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 11:13–14; 加拉太书 1:9; 启示录 22:18–19"> 然而，就算是我们，或是天上来的使者，如果向你们传讲的福音，与我们先前所传给你们的不同，他就该受诅咒。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 16:17; 箴言 30:6; 申命记 4:2"> 我们先前说过，现在我再说：如果有人向你们传讲的福音，与你们先前所领受的不同，他就该受诅咒。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="帖撒罗尼迦前书 2:4; 使徒行传 5:29; 以弗所书 6:6"> 我现在到底是要得人的信任，还是要得神的信任呢？难道我是想讨人的喜悦吗？如果我仍然讨人的喜悦，我就不是基督的奴仆了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="加拉太书 1:1; 哥林多前书 2:9–10; 哥林多前书 11:23"> 弟兄们，我要你们明白，我所传的福音不是按人的意思，</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 1:16; 哥林多前书 2:10; 加拉太书 1:1"> 因为我既不是从人领受的，也不是受人教导的，而是藉着耶稣基督的启示领受的。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 8:3; 哥林多前书 15:9; 使徒行传 22:3–5"> 你们听说过我以前在犹太教中的行事为人：我曾极力地逼迫神的教会，残害她。</span>
<span className="v" id="v14" data-v="14" data-xref="歌罗西书 2:8; 使徒行传 26:5; 腓立比书 3:4–6"> 我在犹太教中，比我本族的许多同辈更进一步，是一个对我祖先的传统格外热心的人。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 1:5; 以赛亚书 49:5; 以赛亚书 49:1"> 然而神，就是当我在母腹里时就把我分别出来、又藉着他的恩典召唤我的那一位，乐意</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 16:17; 以弗所书 3:5–10; 以弗所书 6:12"> 将他的儿子启示在我里面，好使我在外邦人中传扬他。我没有立刻与人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="人——原文直译“血和肉”。">c</a></sup>商量，</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 9:20–25; 哥林多后书 11:32–33; 加拉太书 1:18"> 也没有上耶路撒冷去见那些比我先做使徒的，而是往阿拉伯去，然后再回到大马士革。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行传 9:22–23; 使徒行传 9:26–29; 使徒行传 22:17–18"> 三年以后，我才上耶路撒冷去见矶法<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="矶法——有古抄本作“彼得”。">d</a></sup>，在他那里住了十五天。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 13:55; 马可福音 6:3; 马太福音 12:46"> 至于其他的使徒，除了主的弟弟<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="弟弟——原文直译“兄弟”。">e</a></sup>雅各，我都没有见过。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 9:1; 哥林多后书 11:31; 哥林多后书 11:10–11"> 我现在所写给你们的，看哪，是在神面前写的，我不是在说谎。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 15:41; 使徒行传 9:30; 使徒行传 6:9"> 后来，我到了叙利亚和奇里乞亚地区。</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒罗尼迦前书 2:14; 罗马书 16:7; 帖撒罗尼迦后书 1:1"> 那时，在基督里的犹太各教会，还没有见过我的面。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 15:8–10; 使徒行传 9:13; 提摩太前书 1:13–16"> 他们只是听说：“以前逼迫我们的那个人，现在却在传扬他曾经残害过的信仰。”</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 9:8; 使徒行传 11:18; 路加福音 15:10"> 他们就因我的缘故不住地荣耀神。</span>
</div>
</div>

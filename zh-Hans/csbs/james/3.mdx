<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:47–48; 提摩太前书 1:7; 彼得前书 5:3"> 我的弟兄们，你们不应该有很多人做教师，因为你们知道，我们做教师的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="做教师的——辅助词语。">a</a></sup>将受更严厉的审判。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各书 1:26; 箴言 13:3; 彼得前书 3:10"> 实际上，我们每一个人在很多事上都会跌倒。如果有人在言语上不跌倒，这个人就是一个成熟的人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="成熟的人——或译作“完全的人”。">b</a></sup>，也能够克制全身。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="诗篇 32:9; 诗篇 39:1; 雅各书 1:26"> 我们如果<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="我们如果——有古抄本作“看，我们”。">c</a></sup>把嚼子放在马嘴里，使它们服从<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="使它们服从——原文直译“使它们服从我们”。">d</a></sup>，就可以驾驭它们的全身。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 107:25–27; 马太福音 8:24; 使徒行传 27:14–38"> 再看船只，虽然它那么大，又被狂风吹逐，但是无论舵手的意图想去哪里，它都能被小小的舵来驾驭。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 18:21; 耶利米书 9:3–8; 箴言 12:18"> 照样，舌头虽然是身体上一个小小的部分，却能大大地自夸。看哪，那么小的火，能点燃那么大的森林！</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 120:2–3; 箴言 16:27; 马可福音 7:15"> 舌头是火，它在我们身体的各部分中，是个不公义的世界；它玷污全身，焚烧人生的路程，而且自己却被地狱焚烧。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马可福音 5:4"> 原来，各类野兽、飞禽、爬行动物和水族都能被制伏，也已经被人类制伏了，</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 3:13; 诗篇 140:3; 诗篇 55:21"> 可是没有人能制伏舌头；它是不止息的邪恶，充满着致死的毒。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 10:7; 创世记 1:26–27; 诗篇 62:4"> 我们用这舌头颂赞我们的<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="我们的——辅助词语。">e</a></sup>主<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="主——有古抄本作“神”。">f</a></sup>——我们的<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="我们的——辅助词语。">g</a></sup>父，又用这舌头来诅咒照着神的形像被造的人。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 12:14; 彼得前书 3:9; 哥林多前书 3:3"> 颂赞和诅咒从同一张嘴里出来！我的弟兄们，这些事不应该如此！</span>
<span className="v" id="v11" data-v="11"> 难道从同一个洞里涌出来的泉源，能又甜又苦吗？</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 6:43–44; 马太福音 12:33; 马太福音 7:16–20"> 我的弟兄们，难道无花果树能结出橄榄，葡萄树能结出无花果吗？咸水也不能产生甜水<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="咸水也不能产生甜水——有古抄本作“照样，没有泉源能产生咸水又产生甜水”。">h</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="加拉太书 5:23; 雅各书 3:17; 马太福音 5:5"> 到底你们中间谁是有智慧、有见识的呢？他就应当藉着良好的品行，以智慧的温柔，使自己的行为显明出来；</span>
<span className="v" id="v14" data-v="14" data-xref="雅各书 3:16; 哥林多前书 13:4; 腓立比书 2:3"> 但如果你们心里怀着苦毒的嫉妒和争竞<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="争竞——或译作“结党”。">i</a></sup>，就不要自夸、说谎而抵挡真理。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各书 3:17; 雅各书 1:17; 哥林多前书 3:19"> 这种智慧不是从上面下来的，而是属地的，属血气的，属鬼魔的。</span>
<span className="v" id="v16" data-v="16" data-xref="雅各书 3:14; 哥林多前书 3:3; 哥林多前书 14:33"> 要知道，哪里有嫉妒和争竞<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="争竞——或译作“结党”。">j</a></sup>，哪里就有混乱和各样的恶事。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 5:22–23; 箴言 2:6; 哥林多前书 13:4–7"> 至于从上面来的智慧，首先是纯洁的，然后是和平的、谦和的、温顺的，满有怜悯和美好的果子的，是不偏私、不虚假的；</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 5:9; 何西阿书 10:12; 腓立比书 1:11"> 并且义行的果子，是由那些缔造和平的人，在和平中种下的。</span>
</div>

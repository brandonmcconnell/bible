<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 12:15; 彼得前书 1:1; 约翰福音 7:35"> 神和主耶稣基督的奴仆雅各，<br />问候散居在各地的十二个支派。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="彼得前书 1:6–8; 雅各书 1:12; 哥林多后书 12:9–10"> 我的弟兄们，你们遇到各种试炼的时候，应当看做是极大的喜乐，</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 5:3–4; 希伯来书 10:36; 歌罗西书 1:11"> 因为你们知道，你们的信仰经过考验就生出忍耐；</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 21:19; 彼得前书 5:10; 马太福音 5:48"> 但要让忍耐发挥完全的功效，好使你们成熟、完备，在任何事上都没有缺欠。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="箴言 2:3–6; 约翰福音 15:7; 箴言 3:5–7"> 如果你们中间有人缺乏智慧，他就应当向那慷慨赐予万人又不责骂人的神祈求；神就会赐予他。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 21:21–22; 希伯来书 11:6; 马可福音 11:22–24"> 不过他要凭着信仰祈求，不要有任何疑惑，因为疑惑的人就像海中的波浪，被风吹动翻腾。</span>
<span className="v" id="v7" data-v="7" data-xref="雅各书 4:3; 以赛亚书 58:3–4; 箴言 21:27"> 这样的人不要想从主那里得到什么，</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 18:21; 马太福音 6:24; 雅各书 4:8"> 他是心怀二意的人，在他所有的道路上都摇摆不定。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="耶利米书 9:23–24; 雅各书 2:5–6; 箴言 19:1"> 卑微<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="卑微——或译作“谦卑”。">a</a></sup>的弟兄应当以自己被高举而夸耀；</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前书 1:24; 约翰一书 2:17; 约伯记 14:2"> 富有的应当以自己被降卑而夸耀，因为他将要像草上的花那样消逝。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 40:7–8; 诗篇 37:35–36; 诗篇 49:6–14"> 太阳带着热气升起，草地枯萎，草上的花也凋谢，它表面的美丽也就消逝了；照样，富有的人在他的追求中，也将衰残。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彼得前书 5:10; 彼得前书 1:6–8; 启示录 2:10"> 忍受试炼的人是蒙福的；因为他经过考验以后，就要得到生命的冠冕，就是主<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="主——有古抄本作“他”。">b</a></sup>应许给那些爱他之人的。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="哈巴谷书 2:12–13; 雅各书 1:12; 罗马书 9:19–20"> 人受诱惑的时候，不可说：“我被神诱惑”，因为神是不能被邪恶诱惑的，神也不诱惑任何人。</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 7:21–22; 以弗所书 4:22; 马太福音 15:18"> 而每个人受诱惑，都是被自己的欲望所牵扯、所引诱的；</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 7:14; 约伯记 15:35; 罗马书 5:12–21"> 一旦欲望怀了胎，就生下罪来；罪长成了，就生出死亡。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="加拉太书 6:7; 雅各书 1:19; 腓立比书 2:12"> 我亲爱的弟兄们，你们不要被迷惑了！</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 3:27; 马太福音 7:11; 希伯来书 13:8"> 一切美好的赏赐和各样完美的恩赐，都是从上面、从众光之父降下来的；在他没有改变，也没有转动的影子。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 8:29–31; 彼得前书 1:23; 约翰福音 3:3–5"> 他照着自己的旨意，藉着真理的话语生了我们，要使我们在他所造的万物中成为一种初熟的果子。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="箴言 17:27; 箴言 21:23; 箴言 14:29"> 我亲爱的弟兄们，你们应当知道：<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="你们应当知道：——有古抄本作“因此，”。">c</a></sup>每个人都该快快地听，不急于发言、不急于动怒，</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太后书 2:24–25; 以弗所书 4:26; 雅各书 3:17–18"> 因为人的愤怒不能成就神的义。</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所书 4:22; 以弗所书 1:13; 彼得前书 2:11"> 因此，你们要脱去一切的污秽和满盈的恶毒，要以温柔的心接受那栽种在你们里面的话语，就是能拯救你们灵魂<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="灵魂——或译作“生命”。">d</a></sup>的话语。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="罗马书 2:13; 路加福音 6:46–48; 约翰福音 13:17"> 你们要成为这话语的实行者，不要只成为听者而欺骗自己。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 7:26–27; 以西结书 33:31–32; 雅各书 2:14–26"> 因为，如果有人是这话语的听者，而不是实行者，这个人就像人对着镜子观看自己生来的面貌，</span>
<span className="v" id="v24" data-v="24" data-xref="彼得后书 3:11; 路加福音 1:66; 路加福音 7:39"> 看了就走开，立刻忘了自己是什么样子；</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 11:28; 约翰福音 13:17; 哥林多后书 3:17–18"> 但是详细察看那使人得自由的完美律法，并且继续持守的人，因他不是健忘的听者，而是行为的实行者，这个人就将要在他所行的事上蒙祝福。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以弗所书 4:29; 诗篇 141:3; 彼得前书 3:10"> 如果<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古抄本附“你们中间”。">e</a></sup>有人自以为是虔诚的，却不克制自己的舌头，反而欺骗自己的心，这个人的虔诚<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="虔诚——或译作“宗教”。">f</a></sup>就是虚妄的。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 1:16–17; 约翰一书 3:17–19; 加拉太书 6:9–10"> 在父神看来，纯洁而没有玷污的虔诚<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="虔诚——或译作“宗教”。">g</a></sup>是这样的：照顾患难中的孤儿寡妇，并且保守自己不受世界的玷污。</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 24:23; 雅各书 2:9; 利未记 19:15"> 我的弟兄们，你们应当持守对我们荣耀的主耶稣基督的信仰，不要怀着偏待人的心。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 15:22; 以斯帖记 3:10; 以斯帖记 8:2"> 如果有一个戴着金戒指、穿着华丽衣服的人进了你们的会堂，又有一个穿着肮脏衣服的穷人也进来了，</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 8:9; 雅各书 2:6; 路加福音 7:44–46"> 你们却看重那穿华丽衣服的人，对他说“请你坐在这好位子上”，而对那穷人说“你站在那里”，或说“坐在我的脚凳下边”；</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 7:24; 约伯记 34:19; 马太福音 7:1–5"> 难道你们中间不就有了歧视，而你们也成了心怀恶念的审判官吗？</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马太福音 5:3; 路加福音 6:20; 启示录 2:9"> 我亲爱的弟兄们，请听！神难道不是拣选了世上的那些贫穷人，使他们在信仰上富有，并且做他<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="他——辅助词语。">a</a></sup>国度的继承人吗？这国度是他应许给爱他之人的。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 17:5; 哥林多前书 11:22; 箴言 14:31"> 但你们却侮辱了这贫穷人！那欺压你们、把你们拉上法庭的，难道不是那些富有的人吗？</span>
<span className="v" id="v7" data-v="7" data-xref="腓立比书 2:9–11; 启示录 13:5–6; 提摩太前书 1:13"> 那亵渎你们所敬奉的美好之名的，难道不是他们吗？</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未记 19:18; 加拉太书 5:14; 马太福音 22:39"> 不过，你们如果照着经上那条至尊的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="至尊的——或译作“王的”。">b</a></sup>律法“要爱邻如己”完全实行，你们就做得很好了。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 19:15; 雅各书 2:1–4; 约翰一书 3:4"> 但如果你们偏待人，就是犯罪，并被律法指证是违犯律法的人。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 3:10; 马太福音 5:18–19; 申命记 27:26"> 因为那遵守整个律法的人，只在一条上跌倒，就成了干犯所有律法的了。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 20:13–14; 马太福音 5:21–28; 申命记 5:17–18"> 原来那位说过“不可通奸”的，也说过“不可杀人”。你即使不通奸，却杀人，你还是成了违犯律法的人。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="雅各书 1:25; 雅各书 2:8; 彼得后书 1:4–8"> 既然你们将要照着那使人得自由的律法受审判，就应当照此说话、行事。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 5:7; 马太福音 6:15; 箴言 21:13"> 要知道，那不施怜悯的人，要受毫无怜悯的审判；怜悯胜过审判。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 7:26–27; 马太福音 7:21–23; 雅各书 1:22–25"> 我的弟兄们，如果有人说自己有信仰，但却没有行为，这有什么好处呢？难道这种信仰能救他吗？</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 3:11; 马太福音 25:35–40; 以赛亚书 58:7"> 如果有弟兄或姐妹衣不蔽体，又缺乏日用的食物，</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 3:27–28; 约翰一书 3:16–18; 马太福音 25:42–45"> 而你们当中有人对他们说：“平平安安地去吧！愿你们穿得暖、吃得饱！”，却不给他们身体所需要的，这有什么好处呢？</span>
<span className="v" id="v17" data-v="17" data-xref="雅各书 2:26; 彼得后书 1:5–9; 雅各书 2:19–20"> 信仰也是这样：如果没有行为，这信仰就是死的。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="雅各书 3:13; 雅各书 2:14; 加拉太书 5:6"> 不过有人会说：“你有信仰；我有行为。”请给我看看你没有行为的信仰，我也本于自己的行为给你看看我的信仰。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 4:34; 马可福音 1:24; 马太福音 8:29"> 你相信神只有一位，你就做得很好！连鬼魔也相信，并且恐惧战兢。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="雅各书 2:17; 雅各书 2:26; 箴言 12:11"> 唉，你这虚空的人哪！你想知道没有行为的信仰是无用的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="无用的——有古抄本作“死的”。">c</a></sup>吗？</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 22:16–18; 创世记 22:9–12; 约翰福音 8:39"> 我们的先祖亚伯拉罕把他的儿子以撒献在祭坛上，难道不是本于行为被称为义吗？</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒罗尼迦前书 1:3; 希伯来书 11:17–19; 加拉太书 5:6"> 你看，信仰和他的行为相辅相成，而且信仰是本于行为得以完全的。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 15:6; 以赛亚书 41:8; 历代志下 20:7"> 这就应验了经上所说的：“亚伯拉罕信神，这就被算为他的义。”他又被称为“神的朋友”。</span>
<span className="v" id="v24" data-v="24" data-xref="雅各书 2:21–22; 雅各书 2:15–18; 诗篇 60:12"> 可见人被称为义是本于行为，不仅是本于信仰。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 11:31; 约书亚记 6:22–25; 约书亚记 2:19–21"> 同样，妓女拉合接待了那些使者，又从另一条路把他们送走，难道不也是本于行为被称为义吗？</span>
<span className="v" id="v26" data-v="26" data-xref="雅各书 2:20; 雅各书 2:17; 雅各书 2:14"> 要知道，就像身体没有灵魂是死的，照样，信仰没有行为也是死的。</span>
</div>
</div>

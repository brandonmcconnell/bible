<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 11:28; 提摩太前书 6:9–10; 箴言 11:4"> 现在来吧，你们这些富有的人哪！应当为那些将要临到你们的惨祸而痛哭、哀号！</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 6:19–20; 约伯记 13:28; 路加福音 12:33"> 你们的财富腐烂了；你们的衣服被虫蛀了；</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 2:5; 雅各书 5:7–8; 启示录 21:8"> 你们的金银也生锈了，这锈将成为控告你们的见证，又要像火那样吃你们的肉。在这末后的日子里，你们竟然积蓄财富！</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 19:13; 耶利米书 22:13; 申命记 24:14–15"> 看哪！工人收割你们的田地，你们所克扣他们的工钱正在呼叫，收割者的冤声也已经达到万军之主的耳中了。</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太前书 5:6; 路加福音 16:25; 路加福音 16:19"> 你们在地上奢侈生活、享乐度日，为宰杀的日子养肥了自己的心！</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前书 2:22–23; 约翰福音 19:9–11; 以赛亚书 53:7"> 你们把义人定了罪、把他杀害了，他没有抗拒你们。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="希伯来书 12:1–3; 雅各书 5:8–9; 约珥书 2:23"> 所以弟兄们，你们当恒久忍耐，直到主的来临。看哪，农夫等待着田地里宝贵的果实，为此恒久忍耐，直到果实得着秋雨春雨。</span>
<span className="v" id="v8" data-v="8" data-xref="雅各书 5:9; 加拉太书 5:22; 诗篇 37:7"> 你们也当恒久忍耐，坚固你们的心，因为主的来临已经近了。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="利未记 19:18; 哥林多前书 4:5; 雅各书 4:11"> 弟兄们，不要彼此埋怨，免得你们受审判。看哪，审判者已经站在门口了！</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="希伯来书 11:32–38; 马太福音 5:11–12; 希伯来书 13:7"> 弟兄们，你们要把那些奉主名讲话的先知当做受苦和忍耐的榜样。</span>
<span className="v" id="v11" data-v="11" data-xref="雅各书 1:12; 出埃及记 34:6; 约伯记 1:21–22"> 看哪，那些忍耐过的人，我们称他们有福！你们听说过约伯的忍耐，也看见了主所赐给他<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="所赐给他——辅助词语。">a</a></sup>的结局，知道主是充满怜悯和仁慈的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 5:33–37; 马太福音 23:16–22; 哥林多后书 1:17–20"> 我的弟兄们，最要紧的是：不可起誓。不可指着天起誓，不可指着地起誓，也不可用任何别的誓言起誓。你们说话<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="说话——辅助词语。">b</a></sup>，是，就说是；不是，就说不是；免得落在审判之下<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="审判之下——有古抄本作“伪善之中”。">c</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="诗篇 50:15; 约拿书 2:2; 使徒行传 16:24–25"> 你们中间谁受苦，就应该祷告；谁欢喜，就应该歌颂。</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 6:13; 使徒行传 28:8; 马可福音 16:18"> 你们中间谁患病<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="患病——或译作“软弱”。">d</a></sup>，就应该请教会的长老们来，让他们奉主的名用油来膏抹他、为他祷告。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰一书 5:14–16; 雅各书 5:13; 雅各书 5:16"> 出于信的祈求，将会救那病人<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="病人——或译作“疲倦的人”。">e</a></sup>；主将使他起来；即使他犯了罪，也将被赦免。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 29:12–13; 箴言 15:29; 马太福音 21:22"> 所以你们当彼此认罪，彼此代求，好使你们得痊愈。义人所做的<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="所做的——或译作“竭力的”。">f</a></sup>祈祷是大有力量的。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 17:1; 路加福音 4:25; 启示录 11:6"> 以利亚和我们同样是人，但他用祷告来祈求不要降雨，果然地上三年零六个月没有降雨。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 18:42–45; 耶利米书 14:22; 列王纪上 18:18"> 后来他又祷告，天就降下雨水，地也产出果实来。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="加拉太书 6:1; 马太福音 18:15; 雅各书 5:20"> 我的弟兄们，如果你们中间有人被迷惑离开了真理，而有人使他回转过来，</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前书 4:8; 箴言 10:12; 提摩太前书 4:16"> 这人应当知道：那使一个罪人从他的迷途中回转过来的，将拯救他的灵魂脱离死亡，并且遮盖众多的罪孽。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 38:1–7; 出埃及记 20:24–26; 出埃及记 40:10"> “你要用金合欢木造一座祭坛，长五肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="五肘——相当于2.3公尺；下同。1肘=45.7公分。">a</a></sup>，宽五肘，祭坛是方形的，高三肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="三肘——相当于1.4公尺。">b</a></sup>；</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 118:27; 出埃及记 29:12; 利未记 4:7"> 要在祭坛的四角上做犄角，犄角从祭坛而出；又要把祭坛包上铜。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 7:45; 民数记 4:14; 历代志上 28:17"> 你要做一些桶，用来收去祭坛的灰，并要做一些铲子、碗、肉叉和火盆；祭坛的一切器具，都要用铜做。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 35:16; 出埃及记 25:12; 出埃及记 38:4–5"> 你要为祭坛做一个铜格网，在网的四角上做四个铜环，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 38:4"> 把网安放在祭坛的边框之下，使网达到祭坛的半腰。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 35:13–15; 民数记 4:44; 出埃及记 30:4"> 你要用金合欢木为祭坛做两根杠，把它们包上铜，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 25:28; 出埃及记 30:4; 民数记 4:13–14"> 把杠穿进环中，抬祭坛时，杠就在祭坛的两边。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 25:40; 出埃及记 25:9; 希伯来书 8:5"> 你要用木板把祭坛做成空心的，要照着在山上向你所指明的去做。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 38:9–20; 以西结书 40:32; 以西结书 42:3"> “你要做帐幕的院子。南边要用捻成的细麻线编织院子的帷幔，边长一百肘<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一百肘——相当于45.7公尺；下同。1肘=45.7公分。">c</a></sup>。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 26:19–21; 耶利米书 52:21; 出埃及记 36:38"> 帷幔的柱子二十根，柱子的铜底座二十个，柱子上的钩子和箍环都是银的。</span>
<span className="v" id="v11" data-v="11"> 北边的长度也一样，帷幔长一百肘，帷幔的柱子二十根，柱子的铜底座二十个，柱子上的钩子和箍环都是银的。</span>
<span className="v" id="v12" data-v="12"> 院子的西边，帷幔宽五十肘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="五十肘——相当于22.9公尺；下同。1肘=45.7公分。">d</a></sup>，帷幔的柱子十根，柱子的底座十个。</span>
<span className="v" id="v13" data-v="13"> 院子的东边，就是日出的方向，宽五十肘：</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 27:9; 出埃及记 26:36"> 门的一边，帷幔宽十五肘<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="十五肘——相当于6.9公尺；下同。1肘=45.7公分。">e</a></sup>，帷幔的柱子三根，柱子的底座三个；</span>
<span className="v" id="v15" data-v="15"> 门的另一边，帷幔也宽十五肘，帷幔的柱子三根，柱子的底座三个；</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 26:36; 士师记 5:30; 出埃及记 28:39"> 院子的门帘宽二十肘<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="二十肘——相当于9.1公尺。1肘=45.7公分。">f</a></sup>，用蓝色、紫色、朱红色线和捻成的细麻线，以刺绣的工艺编织，帷幔的柱子四根，柱子的底座四个。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> “院子四围所有的柱子都要有银箍环箍着，柱子上的钩子都是银的，柱子的底座都是铜的。</span>
<span className="v" id="v18" data-v="18"> 院子长一百肘<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="一百肘——相当于45.7公尺。1肘=45.7公分。">g</a></sup>，两边各宽五十肘<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="五十肘——相当于22.9公尺。">h</a></sup>；帷幔高五肘<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="五肘——相当于2.3公尺。">i</a></sup>，用捻成的细麻线编织，柱子的底座都是铜的。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 35:18; 以赛亚书 22:23–25; 民数记 4:32"> 帐幕中各样服事所用的一切器具，并帐幕所有的橛子，以及院子所有的橛子，都是铜的。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="利未记 24:1–4; 撒迦利亚书 4:11–14; 诗篇 23:5"> “你要吩咐以色列子孙，把压榨的纯橄榄油拿来给你，用来点灯，使灯持续点燃着。</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 19:21; 民数记 18:23; 撒母耳记上 3:3"> 亚伦和他的儿子们要在会幕中，在见证柜前的幔子外，从傍晚到早晨，在耶和华面前照管灯。这是以色列子孙世世代代永远的律例。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 32:19; 出埃及记 31:18; 诗篇 119:89"> 耶和华对摩西说：“你要凿出两块石版，像先前的那样；我要把你先前摔碎的石版上的话，写在这两块石版上。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 19:20; 申命记 9:25; 出埃及记 19:11"> 早晨之前，你要预备好；到了早晨，你要上西奈山，在山顶那里站在我面前。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 19:12–13; 出埃及记 19:21; 提摩太前书 2:5"> 任何人都不可与你一同上来，整座山都不可有人，羊群和牛群也不可在这座山前面吃草。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 摩西就凿出了两块石版，像先前的那样；他清早起来，照着耶和华所指示他的，上到西奈山，手中拿着两块石版。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及记 33:19; 民数记 11:25; 路加福音 9:34–35"> 耶和华在云彩中降临，与摩西一同站在那里，并宣告耶和华的名。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 86:15; 约珥书 2:13; 诗篇 103:8–13"> 耶和华在摩西面前经过，宣告说：<br />“耶和华，耶和华，是有怜悯、有恩惠的神；他不轻易发怒，有丰盛的慈爱和信实，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 20:5–6; 诗篇 103:3; 申命记 5:9–10"> 为千代存留慈爱，赦免罪孽、过犯和罪恶，但绝不会让有罪的免于罪责，而会追究罪责，从父亲到儿子、孙子，直到第三代、第四代。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 4:31; 历代志下 20:18; 创世记 17:3"> 摩西急忙俯身于地下拜。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 33:12; 申命记 32:9; 诗篇 94:14"> 他说：“主啊，如果我在你眼前蒙恩，求主在我们中间同我们一起去！虽然这是硬着颈项的百姓，但求你赦免我们的罪孽和罪恶，以我们为你的继业。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命记 10:21; 诗篇 77:14; 以赛亚书 64:3"> 耶和华说：“看哪，我要立约！我要在你众百姓面前行奇妙的事，是在全地、万国中没有行<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="行——原文直译“创造”。">a</a></sup>过的；你所在的万民中，万民必看见耶和华的作为，因为我向你行的是可畏的事。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 33:2; 出埃及记 3:17; 出埃及记 3:8"> 我今天吩咐你的，你要遵守。看哪，我必从你们面前驱逐亚摩利人、迦南人、赫提人、比利洗人、希未人、耶布斯人！</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 23:32–33; 约书亚记 23:12–13; 申命记 7:2"> 你要谨慎，不可与你所去之地的居民立约，免得他们成为你们当中的陷阱。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 18:4; 出埃及记 23:24; 申命记 7:25–26"> 你们要拆毁他们的祭坛，打碎他们的神柱，砍掉他们的亚舍拉柱。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 4:24; 申命记 32:21; 哥林多前书 10:22"> 你不可向别的神明下拜，因为耶和华他的名字是‘嫉愤者’，他是嫉愤的神。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士师记 2:17; 诗篇 106:28; 民数记 25:2"> “你不可与那地的居民立约，因为他们行淫追随他们的神明、向他们的神明献祭的时候，有人邀请你，你就会吃他的祭物；</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 7:3–4; 列王纪上 11:2–4; 以斯拉记 9:2"> 你为你的儿子娶来他的女儿，他的女儿行淫追随她们的神明，就会使你的儿子也行淫追随她们的神明。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="利未记 19:4; 出埃及记 32:8; 以赛亚书 46:6–7"> “不可为自己铸造神像。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 13:4; 利未记 23:6; 出埃及记 13:6–7"> “你要守无酵节，照着我吩咐你的，在亚笔月所定的日期吃无酵饼七天，因为你是在亚笔月从埃及出来的。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及记 13:2; 出埃及记 22:29; 出埃及记 13:12"> “所有的头胎都属于我；你的牲畜中所有头生的，无论是牛是羊，凡是公的都属于我。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 13:13; 出埃及记 23:15; 申命记 16:16"> 头生的驴子，你要用羔羊赎回；如果不赎回，就要打断它的脖子。你儿子们中所有头生的，你都要赎回；谁也不可空手朝见我。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及记 23:12; 申命记 21:4; 路加福音 13:14"> “六天你要劳碌，但第七天要安息；在耕种或收割的时候，也要安息。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及记 23:16; 申命记 16:10–15; 约翰福音 7:2"> “在收割初熟小麦的时候，你要守七七节；在过年的时候，你要守收藏节。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 23:14; 申命记 16:16; 出埃及记 23:17"> 一年三次，你所有的男子都要朝见主耶和华以色列的神。</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 78:55; 出埃及记 33:2; 箴言 16:7"> 我必从你面前赶出列国，扩宽你的边界；你一年三次上去朝见耶和华你神的时候，没有人会贪图你的土地。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及记 23:18; 出埃及记 12:10; 哥林多前书 5:7–8"> “不可把我祭物的血与有酵之物一起献祭，也不可使逾越节的祭物过夜留到早晨。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 23:19; 申命记 14:21; 申命记 26:2"> “要把你土地里上好的初熟之物带到你神耶和华的殿中。<br />“不可用母山羊的奶煮它的小山羊。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="出埃及记 24:4; 申命记 31:9; 申命记 4:13"> 耶和华对摩西说：“你要把这些话语记下来，因为我是照着这些话语与你和以色列一起立约的。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="出埃及记 34:1; 出埃及记 24:18; 申命记 9:18"> 摩西在那里与耶和华一起四十昼夜，没有吃饭没有喝水。耶和华把这约的话语，就是十诫，写在两块版上。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马太福音 17:2; 路加福音 9:29; 出埃及记 32:15"> 摩西从西奈山下来——下山的时候，摩西手中拿着两块见证版——摩西不知道自己的脸皮因他与耶和华说话而发光。</span>
<span className="v" id="v30" data-v="30" data-xref="马可福音 9:3; 路加福音 5:8; 民数记 12:8"> 亚伦和所有的以色列子孙看见摩西，看哪，他的脸皮发光！他们就害怕接近他。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 3:15; 出埃及记 24:1–3; 创世记 45:3"> 摩西呼叫他们，亚伦和所有的会众领袖都回到他那里，摩西就与他们说话。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 22:14; 出埃及记 24:3; 马太福音 28:20"> 之后，所有的以色列子孙近前来，摩西就把耶和华在西奈山上与他所说的一切都吩咐他们。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多后书 4:4–6; 哥林多后书 3:13–18; 罗马书 10:4"> 摩西与他们说完了话，就用帕子蒙上脸。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多后书 3:16; 希伯来书 10:19–22; 希伯来书 4:16"> 每当摩西来到耶和华面前与他说话的时候，摩西就把帕子取下，直到他出来；他出来后，就把耶和华所指示的告诉以色列子孙。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及记 34:29–30; 约翰福音 5:35; 但以理书 12:3"> 以色列子孙看见摩西的脸，见摩西的脸皮发光，摩西就再次用帕子蒙上脸，直到他进去与耶和华说话。</span>
</div>
</div>

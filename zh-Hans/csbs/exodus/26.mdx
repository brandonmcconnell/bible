<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 36:8–19; 出埃及记 26:36; 出埃及记 26:31"> “你要用十幅幔帐造帐幕，幔帐要用捻成的细麻线和蓝色、紫色、朱红色线编织，以精巧的工艺绣上基路伯。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 7:2; 民数记 4:25; 历代志上 17:1"> 每幅幔帐长二十八肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="二十八肘——相当于12.8公尺。1肘=45.7公分。">a</a></sup>，每幅幔帐宽四肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="四肘——相当于1.8公尺。">b</a></sup>，所有幔帐的尺寸都要一样。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 36:10; 歌罗西书 2:2; 以弗所书 2:21–22"> 五幅幔帐要彼此相连，另五幅幔帐也要彼此相连。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 36:11–12; 出埃及记 36:17; 出埃及记 26:10–11"> 在一组幔帐的最后一幅边上，要用蓝色线做扣环；在另一组幔帐的最后一幅边上，也要照样做。</span>
<span className="v" id="v5" data-v="5"> 在一组幔帐的边上，要做五十个扣环；在另一组幔帐的边上，也要做五十个扣环，扣环彼此相对。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 36:13; 出埃及记 26:11; 出埃及记 26:33"> 你要做五十个金钩，用这些钩子把两组幔帐彼此相连为一大幅<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="为一大幅——辅助词语。">c</a></sup>，好使帐幕成为一个整体。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 26:14; 诗篇 45:13; 出埃及记 26:9"> “你要用山羊毛做幔帐，作为帐幕上的罩篷，要做十一幅幔帐。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 26:13; 出埃及记 26:2"> 每幅幔帐长三十肘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="三十肘——相当于13.7公尺。1肘=45.7公分。">d</a></sup>，每幅幔帐宽四肘<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="四肘——相当于1.8公尺。">e</a></sup>，十一幅幔帐的尺寸都要一样。</span>
<span className="v" id="v9" data-v="9"> 你要把五幅幔帐连成一组，把另外的六幅幔帐也连成一组，并把第六幅幔帐在罩篷的前部叠上去。</span>
<span className="v" id="v10" data-v="10"> 在一组幔帐的最后一幅边上，要做五十个扣环；在另一组幔帐的边上，也要做五十个扣环。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 26:3; 出埃及记 26:6"> 你要做五十个铜钩，把这些钩子钩入扣环，把罩篷连起来，好使它成为一个整体。</span>
<span className="v" id="v12" data-v="12"> 罩篷幔帐遮盖帐幕<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="遮盖帐幕——辅助词语。">f</a></sup>多出的部分，就是多出的半幅幔帐，要垂在帐幕的后面。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 26:2; 出埃及记 26:8"> 罩篷幔帐遮盖那大幅幔帐<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="遮盖那大幅幔帐——辅助词语。">g</a></sup>多出的长度，要一肘在一边，一肘在另一边，垂在帐幕的两边——在一边和另一边，好遮盖帐幕。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 36:19; 出埃及记 25:5; 出埃及记 35:23"> 你要用染红的公绵羊皮为罩篷做一个遮盖，其上再用海狮皮做一个顶罩。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及记 36:20–33; 民数记 4:31–32; 出埃及记 40:17–18"> “你要用金合欢木为帐幕做竖板。</span>
<span className="v" id="v16" data-v="16"> 每块木板长十肘<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="十肘——相当于4.6公尺。1肘=45.7公分。">h</a></sup>，每块木板宽一肘半<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="一肘半——相当于0.7公尺。">i</a></sup>。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 36:22; 出埃及记 26:19; 出埃及记 36:24"> 每块木板要有两个榫头，彼此并列<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="彼此并列——或译作“使木板彼此连接”。">j</a></sup>；帐幕所有的木板都要这样做。</span>
<span className="v" id="v18" data-v="18"> 你要为帐幕做木板，为南边，就是朝南的那边，做二十块木板；</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 38:27; 出埃及记 38:30–31; 出埃及记 26:37"> 在这二十块木板底下，做四十个银底座；一块木板底下有两个底座连接它的两个榫头，下一块木板底下也有两个底座连接它的两个榫头。</span>
<span className="v" id="v20" data-v="20"> 你要为帐幕的另一边，就是北边，做二十块木板，</span>
<span className="v" id="v21" data-v="21"> 以及四十个银底座；一块木板底下有两个底座，下一块木板底下也有两个底座。</span>
<span className="v" id="v22" data-v="22"> 你也要为帐幕的后部，就是西面，做六块木板；</span>
<span className="v" id="v23" data-v="23"> 并在帐幕后部的两个边角做两块木板，</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 36:29–30; 诗篇 133:1–3; 哥林多前书 1:10"> 两个边角要双层，双层木板从下端到顶端完全对齐，顶端用一个环扣住；两块木板都要这样，形成两个凸角。</span>
<span className="v" id="v25" data-v="25"> 这样共有八块木板和十六个银底座；一块木板底下有两个底座，下一块木板底下也有两个底座。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="罗马书 15:1; 民数记 4:31; 加拉太书 6:1–2"> “你要用金合欢木做横闩，为帐幕一边的木板做五根，</span>
<span className="v" id="v27" data-v="27"> 为帐幕另一边的木板做五根横闩，又为帐幕后边，就是西面的木板，也做五根横闩。</span>
<span className="v" id="v28" data-v="28"> 在木板中部，中间那根横闩，从一端穿到另一端。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 25:11–12"> 你要把木板包上金，又用金子做其上的环，用来穿横闩；横闩也要包上金。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 25:40; 希伯来书 8:5; 出埃及记 25:9"> 你要照着在山上向你指明的规制，把帐幕立起来。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马太福音 27:51; 历代志下 3:14; 出埃及记 36:35"> “你要用蓝色、紫色、朱红色线和捻成的细麻线编织幔子，以精巧的工艺绣上基路伯。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 26:37; 出埃及记 36:38; 以斯帖记 1:6"> 你要把幔子垂挂在四根包金的金合欢木柱子上；柱子上有金钩，柱子在四个银底座上。</span>
<span className="v" id="v33" data-v="33" data-xref="希伯来书 9:2–3; 利未记 16:2; 出埃及记 40:21"> 你要把幔子垂挂在钩子之下，把见证柜抬进幔子内；这幔子就为你们隔开了圣所和至圣所。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 40:20; 出埃及记 25:21; 希伯来书 9:5"> 你要把施恩座安放在至圣所里的见证柜上。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及记 40:24; 出埃及记 40:22; 希伯来书 9:2"> 你要把桌子放在幔子外，把灯台放在桌子对面，在帐幕的南边；桌子要安置在帐幕的北边。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="出埃及记 36:37; 民数记 9:15; 出埃及记 26:31"> “你要用蓝色、紫色、朱红色线和捻成的细麻线，以刺绣的工艺，为帐篷的入口编织帘幕。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及记 36:38"> 你要用金合欢木为帘幕做五根柱子，把柱子包上金，柱子上有金钩；又要为柱子铸五个铜底座。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 26:30; 出埃及记 13:4; 民数记 7:1"> “一月一日，你要把会幕的帐幕立起来，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 35:12; 民数记 4:5; 启示录 11:19"> 把见证柜安放在那里，用幔子遮掩这柜；</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 24:8; 出埃及记 40:22–25; 出埃及记 37:10–24"> 把桌子搬进去，摆好桌子上应摆的东西；又把灯台搬进去，点上灯。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 10:19–22; 希伯来书 9:24; 约翰一书 2:1–2"> 你要把金香坛放在见证柜前面，挂上帐幕的门帘；</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 40:29; 约翰一书 4:9–10; 希伯来书 13:10"> 把燔祭的祭坛放在会幕的帐幕入口的前面；</span>
<span className="v" id="v7" data-v="7" data-xref="撒迦利亚书 13:1; 约翰一书 1:7; 诗篇 26:6"> 又把洗濯盆放在会幕和祭坛之间，盆中盛水。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 40:33; 以弗所书 4:11–12; 马太福音 16:18"> 你要在四围设院子，挂上院子的门帘。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="利未记 8:10; 民数记 7:1; 马太福音 3:16"> “你要把膏油拿来，膏抹帐幕和帐幕里的一切，使帐幕和帐幕的一切器具分别为圣，帐幕就成为神圣的。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 29:36–37; 路加福音 1:35; 以赛亚书 61:1"> 你要膏抹燔祭的祭坛和祭坛的一切器具，使祭坛分别为圣，祭坛就成为至圣的。</span>
<span className="v" id="v11" data-v="11"> 你要膏抹洗濯盆和盆座，使盆分别为圣。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="利未记 8:1–13; 利未记 9:1–24; 出埃及记 29:1–35"> “你要把亚伦和他的儿子们带到会幕的入口，用水洗他们；</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 28:41; 约翰一书 2:20; 约翰一书 2:27"> 给亚伦穿上圣衣，膏抹他，使他分别为圣，作祭司事奉我；</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 61:10; 罗马书 8:30; 哥林多前书 1:30"> 又把他的儿子们带来，给他们穿上袍子，</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 25:13; 希伯来书 5:1–14; 希伯来书 8:1–10"> 膏抹他们，像膏抹他们的父亲那样，使他们作祭司事奉我。他们受膏抹，就使他们世世代代拥有永远的祭司职份。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命记 4:1; 出埃及记 40:17–32; 申命记 12:32"> 摩西遵行耶和华所指示他的一切，都照着做了。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 7:1; 出埃及记 40:1–2; 民数记 9:1"> 第二年一月一日，帐幕立了起来。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 37:27–28; 彼得前书 1:5; 利未记 26:11"> 摩西把帐幕立了起来，安好帐幕的底座，竖起木板，穿上横闩，立起柱子，</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 26:1–14; 出埃及记 36:8–19"> 把罩篷铺在帐幕上，又把罩篷的顶罩安放其上，是照着耶和华指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 16:34; 申命记 10:5; 希伯来书 10:19–21"> 摩西把见证版拿来，安放在柜里，把杠穿在柜的两边，把施恩座安放在柜上面；</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 26:33; 出埃及记 40:3; 出埃及记 35:12"> 又把柜抬进帐幕，挂上帘幕的幔子来遮掩见证柜，是照着耶和华指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及记 26:35; 约翰福音 6:53–57; 以弗所书 3:8"> 摩西把桌子安置在会幕中，在帐幕的北边，幔子的外面；</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 25:30; 出埃及记 40:4; 希伯来书 9:2"> 在桌子上摆好陈设饼，摆在耶和华面前，是照着耶和华指示摩西的。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 26:35; 启示录 2:5; 约翰福音 1:1"> 他把灯台放在会幕中，在桌子对面，在帐幕的南边；</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 40:4; 出埃及记 25:37; 启示录 4:5"> 又把灯点在耶和华面前，是照着耶和华指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 40:5; 希伯来书 7:25; 约翰福音 11:42"> 他把金坛安放在会幕中，幔子的前面；</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 30:7"> 在坛上烧献芬芳香，是照着耶和华指示摩西的。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 40:5; 希伯来书 10:19–20; 以弗所书 2:18"> 他挂上帐幕的门帘。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 40:6; 希伯来书 13:5–6; 希伯来书 13:10"> 他把燔祭的祭坛安放在会幕的帐幕入口，把燔祭和素祭献在祭坛上，都是照着耶和华指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及记 40:7; 出埃及记 38:8; 以西结书 36:25"> 他把洗濯盆安放在会幕和祭坛之间，盆中盛水，用来洗濯；</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 30:19–20; 诗篇 26:6; 约翰福音 13:10"> 摩西、亚伦和他的儿子们在盆中洗手洗脚。</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 73:19; 出埃及记 30:19–20; 出埃及记 40:19"> 当他们进入会幕，或接近祭坛的时候，他们就洗濯，是照着耶和华指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="出埃及记 40:8; 出埃及记 27:9–16; 约翰福音 17:4"> 他在帐幕和祭坛的四围设了院子，挂上院子的门帘。这样，摩西就完成了工作。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="启示录 15:8; 民数记 9:15–23; 历代志下 7:2"> 那时，云彩遮盖会幕，耶和华的荣耀充满了帐幕。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 8:11; 利未记 16:2; 历代志下 7:2"> 摩西不能进入会幕，因为云彩停留在会幕上，耶和华的荣耀充满了帐幕。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="尼希米记 9:19; 民数记 9:17; 出埃及记 13:21–22"> 在以色列子孙的整个行程中，每当云彩从帐幕上收上去，他们就起行；</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 9:19–22; 诗篇 31:15"> 如果云彩不收上去，他们就不起行，直到云彩收上去那天。</span>
<span className="v" id="v38" data-v="38" data-xref="诗篇 78:14; 民数记 9:15; 出埃及记 13:21"> 在他们的整个行程中，白天有耶和华的云彩在帐幕上，夜间有火在云彩中，就在以色列全家的眼前。</span>
</div>
</div>

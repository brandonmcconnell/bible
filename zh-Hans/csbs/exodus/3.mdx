<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 19:8; 出埃及记 17:6; 诗篇 78:70–72"> 有一天，摩西正在牧放他岳父米甸祭司耶特罗的羊群；他把羊群引领到旷野的深处，来到神的山，就是何烈山。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 7:30–35; 以赛亚书 43:2; 马可福音 12:26"> 这时耶和华的使者在荆棘丛的火焰中向他显现。摩西观看，看哪，荆棘丛在火中燃烧，但荆棘丛却没有被吞噬！</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 7:31; 诗篇 107:8; 约伯记 37:14"> 摩西就说：“我要转过去观看这个大异象，那荆棘丛为什么没有被烧毁！”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="申命记 33:16; 撒母耳记上 3:6; 使徒行传 9:4"> 当耶和华看见摩西要转过去观看，神就在荆棘丛中向他呼唤，说：“摩西，摩西！”<br />他说：“我在这里！”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约书亚记 5:15; 使徒行传 7:33; 出埃及记 19:12"> 神说：“不要靠近这里，脱下你脚上的鞋子，因为你所站的地方是圣地。”</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 20:37; 马太福音 22:32; 出埃及记 4:5"> 神又说：“我是你先祖的神——亚伯拉罕的神、以撒的神、雅各的神。”摩西就遮掩自己的脸，因为他害怕看见神。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="诗篇 145:19; 诗篇 106:44; 出埃及记 2:23–25"> 耶和华说：“我确实看见了我子民在埃及的苦难，也听见了他们因监工的压迫而发出的哀声；我确实知道他们的痛苦。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 50:24; 创世记 15:18–21; 出埃及记 3:17"> 所以我下来是要解救他们脱离埃及人的手，并把他们从那地带上来，带到那美好宽广之地——流奶与蜜之地，就是迦南人、赫提人、亚摩利人、比利洗人、希未人、耶布斯人的地方。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 22:22–23; 出埃及记 2:23; 出埃及记 1:13–14"> 现在看哪，以色列子孙的哀声已经达到我这里，我也看见了埃及人怎样压迫他们！</span>
<span className="v" id="v10" data-v="10" data-xref="弥迦书 6:4; 撒母耳记上 12:6; 诗篇 105:26"> 现在你去，我要派遣你到法老那里，把我的子民以色列子孙从埃及领出来！”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 18:18; 哥林多后书 3:5; 出埃及记 6:12"> 摩西对神说：“我是谁，竟能到法老那里去？竟能把以色列子孙从埃及领出来？”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约书亚记 1:5; 罗马书 8:31; 以赛亚书 41:10"> 神说：“我必定与你同在。你把子民从埃及领出来之后，你们必在这山上服事神——这就是给你的标记，表明<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="表明——辅助词语。">a</a></sup>是我派遣了你。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 30:4; 以赛亚书 9:6; 耶利米书 23:6"> 摩西对神说：“看哪！我到以色列子孙那里去，对他们说‘你们先祖的神派遣我到你们这里’，他们如果问我‘他的名字是什么’，那么我要对他们说什么呢？”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="约翰福音 8:58; 希伯来书 13:8; 启示录 1:8"> 神对摩西说：“我是‘我所是’的那一位。”神接着说：“你要对以色列子孙如此说：‘我所是’的那一位派遣我到你们这里。”</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 17:7–8; 希伯来书 13:8; 玛拉基书 3:6"> 神又对摩西说：“你要对以色列子孙如此说：‘耶和华你们先祖的神——亚伯拉罕的神、以撒的神、雅各的神，派遣我到你们这里。’这是我的名字，直到永远；这也是我的名号，直到万代。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="诗篇 8:4; 出埃及记 4:31; 出埃及记 4:29"> “你去招聚以色列的长老们，对他们说：‘耶和华你们先祖的神——亚伯拉罕、以撒、雅各的神，向我显现，说：“我确实眷顾了你们，也看见了你们在埃及所受的对待；</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 15:13–21; 创世记 50:24; 创世记 46:4"> 我就说：我要把你们带上来，脱离埃及的苦难，到迦南人、赫提人、亚摩利人、比利洗人、希未人、耶布斯人之地，就是那流奶与蜜之地。”’</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 9:1; 出埃及记 7:16; 出埃及记 10:24–26"> 以色列的长老们必听从你的话。然后，你和他们要到埃及王那里去，对他说：‘希伯来人的神耶和华向我们显现了<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="向我们显现了——原文直译“与我们相见了”。">b</a></sup>。现在，请让我们在旷野中走三天的路程，好使我们向我们的神耶和华献祭。’</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 5:2; 出埃及记 6:1; 出埃及记 7:1–14"> 不过我知道，如果不用大能的手，埃及王是不会允许你们走的。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 7:36; 尼希米记 9:10; 出埃及记 9:15"> 所以我要伸手，在埃及当中行我一切的奇妙作为，以此打击埃及；然后他才会让你们走。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 12:36; 诗篇 105:37; 出埃及记 11:3"> 我要使这子民在埃及人眼前蒙恩，这样你们走的时候就不会空手而去。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 39:10; 出埃及记 11:2; 出埃及记 12:35–36"> 每个女人都要向她的邻居，向寄居在她家里的女人索要银器、金器和衣服，并穿戴在你们的儿女身上；这样你们就剥夺了埃及人。”</span>
</div>
</div>

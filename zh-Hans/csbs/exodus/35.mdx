<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 34:32; 出埃及记 31:1–11; 罗马书 2:13"> 摩西招聚全体以色列会众，对他们说：“以下是耶和华指示你们要做的事：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 23:3; 路加福音 13:14–15; 出埃及记 20:9–10"> 六天可以做工，但第七天对你们是完全安息的安息日，是归耶和华为圣的；任何人在这日做工，就要被处死。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 16:23; 民数记 15:32–36; 出埃及记 12:16"> 在安息日，你们居住的任何地方都不可生火。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及记 25:1–2"> 摩西对全体以色列会众说：“耶和华所指示的话是这样的，他说：</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 9:7; 诗篇 110:3; 出埃及记 25:2–7"> 你们要从你们中间拿供物献给耶和华；凡甘心乐意的，就把献给耶和华的供物带来：金、银、铜，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 26:7–14; 出埃及记 26:31; 出埃及记 28:15"> 蓝色线、紫色线、朱红色线、细麻、山羊毛，</span>
<span className="v" id="v7" data-v="7"> 染红的公绵羊皮、海狮皮，金合欢木，</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 27:20; 出埃及记 25:1–40; 出埃及记 30:23"> 点灯的油、制作膏油和芬芳香的香料，</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 39:6–14; 出埃及记 28:9; 出埃及记 25:5"> 以及以弗得和胸牌上用的红玛瑙石和镶嵌的宝石。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及记 31:1–6; 出埃及记 36:1–4"> “你们中间一切有才能<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有才能——原文直译“心里有智慧”；本章下同。">a</a></sup>的，都要来做耶和华所吩咐的一切：</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 26:1–37; 出埃及记 36:8–34; 出埃及记 31:7–9"> 帐幕——帐幕的罩篷、顶罩、钩子、木板、横闩、柱子、底座、</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 25:10–22; 出埃及记 26:31–33; 出埃及记 37:1–9"> 柜和柜的杠、施恩座、帘幕的幔子、</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 25:23–30; 利未记 24:5–6; 出埃及记 37:10–16"> 桌子和桌子的杠、桌子的一切器具、陈设饼、</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 25:31–39; 马太福音 5:14–15; 出埃及记 37:17–24"> 点灯的灯台和灯台的器具、灯和点灯的油、</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 30:1–10; 出埃及记 30:22–38; 出埃及记 37:25–28"> 香坛和香坛的杠、膏油和芬芳香、帐幕入口的门帘、</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 27:1–8; 出埃及记 30:18–21; 出埃及记 38:1–8"> 燔祭的祭坛、祭坛用的铜格网、祭坛的杠、祭坛的一切器具、洗濯盆和盆座、</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 7:2; 出埃及记 38:9–20; 出埃及记 27:9–19"> 院子的帷幔、帷幔的柱子、底座、院子的门帘、</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 27:19"> 帐幕的橛子、院子的橛子、帐幕和院子的绳子、</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 31:10; 民数记 4:5–15; 出埃及记 28:1–43"> 圣所事奉用的编织的衣服——祭司亚伦的圣衣和他儿子们作祭司事奉时的衣服。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 全体以色列会众就从摩西面前出去。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 25:2; 出埃及记 35:26; 历代志上 29:14"> 凡是心里受激励、甘心奉献的人都来了，把献给耶和华的供物带来，用于做会幕的工作、各样的服事和圣衣。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米记 7:70–72; 马太福音 2:11; 以斯拉记 2:68–69"> 凡甘心乐意的男男女女都来了，把胸针、耳环、戒指、项链和一切的金器都带来；他们每个人都把这些摇一摇，作为摇献的金祭物，献给耶和华。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 29:8; 出埃及记 25:2–7; 出埃及记 35:6–10"> 凡有蓝色线、紫色线、朱红色线、细麻、山羊毛、染红的公绵羊皮、海狮皮的人，都把它们带来了。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 8:12"> 凡奉上银或铜为供物的，都把献给耶和华的供物带来了。凡有金合欢木用于工程上各样工作的，都把它们带来了。</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 16:12; 路加福音 8:2–3; 箴言 14:1"> 凡有才能的女人都亲手纺线，把所纺的蓝色线、紫色线、朱红色线和细麻都带来了。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 35:21; 出埃及记 36:8; 出埃及记 35:29"> 凡心里受激励、有智慧的女人，都纺山羊毛。</span>
<span className="v" id="v27" data-v="27" data-xref="以斯拉记 2:68; 历代志上 29:6; 出埃及记 35:9"> 首领们把以弗得和胸牌上用的红玛瑙石和镶嵌的宝石、</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 30:23–38; 出埃及记 35:8"> 点灯的油、制作膏油和芬芳香的香料，都带来了。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多后书 9:7; 出埃及记 35:21–22; 出埃及记 35:4"> 凡是甘心奉献的以色列子孙，无论男女，都把甘心奉献物带来给耶和华，为要做耶和华藉着摩西所指示的一切工作。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及记 31:1–6; 雅各书 1:17; 哥林多前书 12:11"> 摩西对以色列子孙说：“你们看，耶和华已经提名召唤了犹大支派中户珥的孙子、乌利的儿子比撒列！</span>
<span className="v" id="v31" data-v="31" data-xref="雅各书 1:17; 以赛亚书 11:2–5; 以赛亚书 61:1–3"> 耶和华用神的灵充满了他，使他有智慧、聪慧、知识、各样的技艺，</span>
<span className="v" id="v32" data-v="32"> 能构思艺术设计，能做金、银、铜的工艺，</span>
<span className="v" id="v33" data-v="33"> 能做镶嵌宝石的石雕工艺，又能做木雕工艺，为要做各样的精巧工艺。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 31:6; 历代志下 2:14; 以斯拉记 7:27"> 耶和华又把指教的能力放在他和但支派中亚希撒抹的儿子亚何利亚伯的心里；</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及记 35:31; 列王纪上 7:14; 以赛亚书 28:26"> 并用智慧充满他们的心，使他们擅长做各样的工艺——雕刻，设计，用蓝色、紫色、朱红色线和细麻刺绣，以及纺织——使他们成为做各样工艺的人和构思艺术设计的人。</span>
</div>
</div>

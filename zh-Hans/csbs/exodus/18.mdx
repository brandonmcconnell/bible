<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 2:16; 诗篇 77:14–15; 出埃及记 3:1"> 摩西的岳父米甸祭司耶特罗，听见了神为摩西和神的子民以色列所做的一切，就是耶和华怎样把以色列人从埃及领出来的事。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="出埃及记 2:21; 出埃及记 4:25–26"> 摩西的岳父耶特罗带来了摩西的妻子西坡拉——她先前被送回家；</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 2:22; 使徒行传 7:29; 诗篇 39:12"> 耶特罗也带来了西坡拉的两个儿子，一个名叫革顺，因为摩西说“我在外邦之地作了寄居者”；</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 13:6; 提摩太后书 4:17; 哥林多后书 1:8–10"> 一个名叫以利以谢，因为摩西说“我父亲的神是我的帮助者，他解救我脱离了法老的刀剑”。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及记 3:1; 出埃及记 3:12; 出埃及记 24:16–17"> 摩西的岳父耶特罗与摩西的两个儿子和摩西的妻子一同来到旷野摩西那里，就是他在神的山扎营的地方。</span>
<span className="v" id="v6" data-v="6"> 耶特罗传话给摩西说<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="传话给摩西说——原文直译“对摩西说”。">a</a></sup>：“我，你的岳父耶特罗，与你的妻子和她的两个儿子就要来到你这里了。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="创世记 29:13; 创世记 14:17; 撒母耳记下 11:7"> 摩西就出来迎接他的岳父，向他下拜，亲吻他，彼此问安，然后一起进入了帐篷。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 145:4–12; 尼希米记 9:9–15; 诗篇 107:2"> 摩西向他的岳父讲述了耶和华为以色列的缘故对法老和埃及所做的一切事，以及以色列人在路上所遭遇的一切艰难，并耶和华怎样解救了他们。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 12:26; 罗马书 12:15; 以赛亚书 66:10"> 耶特罗因耶和华为以色列所做的一切美事，就是解救他们脱离埃及人之手的事，而欢乐喜悦。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 14:20; 撒母耳记下 18:28; 路加福音 1:68"> 耶特罗说：“耶和华是当受颂赞的！他解救你们脱离埃及人的手和法老的手，把这百姓从埃及人的手下解救出来。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 95:3; 出埃及记 15:11; 历代志下 2:5"> 现在，通过埃及人狂傲对待这百姓的后果，我知道耶和华伟大，超越一切神明。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 31:54; 申命记 12:7; 出埃及记 24:11"> 摩西的岳父耶特罗带来了燔祭和祭物献给神；亚伦和以色列所有的长老都来了，与摩西的岳父在神面前吃饭。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 16:5; 约伯记 29:7; 士师记 5:10"> 第二天，摩西坐着为百姓施行审断，百姓从早到晚站在摩西周围。</span>
<span className="v" id="v14" data-v="14"> 摩西的岳父看见摩西为百姓所做的一切，就说：“你为百姓做的这是什么事呢？为什么你独自坐着，而全体民众从早到晚站在你周围呢？”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数记 15:34; 民数记 27:5; 民数记 9:8"> 摩西对他的岳父说：“这是因为百姓到我这里来求问神。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 24:14; 哥林多前书 6:1; 撒母耳记下 15:3"> 他们之间发生了什么事，就会到我这里来，我就在双方之间施行审断，使他们明白神的律例和训诲。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 摩西的岳父对他说：“你这样做不好。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 11:14–17; 使徒行传 6:1–4; 哥林多后书 12:15"> 你和这些与你在一起的百姓都一定会疲惫不堪，因为这事对你太沉重，你独自一人做不了。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 27:5; 申命记 5:5; 出埃及记 20:19"> 现在你当听从我的话，我给你提个建议，愿神与你同在！你要在神的面前代表百姓，把他们的事带到神那里；</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 5:1; 诗篇 143:8; 申命记 1:18"> 你要用律例和训诲警诫他们，使他们明白他们当走的路和当做的事；</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 6:3; 申命记 1:13–17; 历代志下 19:5–10"> 你要从全体民众当中选出有才能的、敬畏神的、诚实的、恨恶私利的人，立他们作千夫长、百夫长、五十夫长、十夫长来管理百姓，</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 11:17; 民数记 27:2; 民数记 15:33"> 让他们随时为百姓施行审断——所有的大事都带到你这里来，而所有的小事都由他们自己审断。这样，你就可以轻省些，他们也可以与你一起分担。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 8:6–7; 出埃及记 18:18; 撒母耳记上 8:22"> 如果你这样做，神也这样吩咐你，你就能站立得住，全体民众也能平安地回到自己的地方。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以斯拉记 10:2; 出埃及记 18:19; 出埃及记 18:2–5"> 摩西听从了他岳父的话，照着他所说的一切做了。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 1:15; 出埃及记 18:21; 使徒行传 6:5"> 摩西从全体以色列人中挑选了有才能的人，立他们作百姓的首领，作千夫长、百夫长、五十夫长、十夫长。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 18:22; 出埃及记 18:14–15; 申命记 17:8"> 他们随时为百姓施行审断——难断的事就带到摩西那里，而所有的小事都由他们自己审断。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="民数记 10:29–30; 士师记 19:9; 创世记 31:55"> 后来，摩西送走了他的岳父，他的岳父就回本地去了。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 26:59; 历代志上 23:12–14; 出埃及记 6:16–20"> 有一个利未家的男子娶了一个利未女子为妻。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:23; 使徒行传 7:20; 诗篇 112:5"> 那女人怀孕，生了一个儿子，见他俊美，就把他藏了三个月。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 1:22; 使徒行传 7:19; 创世记 6:14"> 后来再也藏不下去了，那女人就为他取来一个蒲草箱，涂上沥青和柏油，把那孩子放在里面，然后把箱子放在尼罗河岸的芦荻中。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 26:59; 出埃及记 15:20; 弥迦书 6:4"> 那孩子的姐姐远远地站着，想知道会有什么事发生在那孩子身上。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 7:21; 诗篇 12:5; 诗篇 9:9"> 那时，法老的女儿下到尼罗河去洗澡；她的使女们正在尼罗河岸走动。她看见芦荻中的箱子，就打发她的女仆把箱子取来。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 8:50; 彼得前书 3:8; 使徒行传 7:21"> 她打开箱子，看见了一个孩子。看哪，那男孩正在哭！她就可怜那男孩，说：“这是个希伯来人的孩子！”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 2:4; 民数记 26:59; 民数记 12:1"> 那孩子的姐姐对法老的女儿说：“我去为你从希伯来妇女中叫来一个乳母，让她替你乳养这孩子，好吗？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 46:3–4; 诗篇 27:10; 出埃及记 6:20"> 法老的女儿对她说：“去吧！”那童女就去，叫来那孩子的母亲。</span>
<span className="v" id="v9" data-v="9"> 法老的女儿对那女人说：“你把这孩子带去，替我乳养他，我必给你酬报。”那女人就把孩子抱过来，乳养他。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 11:24; 创世记 16:11; 撒母耳记上 1:20"> 孩子长大了，那女人把他带到法老的女儿那里，他就作了法老女儿的儿子。法老的女儿给他起名为摩西，说：“因为我把他从水里拉上来。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="希伯来书 11:24–26; 使徒行传 7:22–24; 出埃及记 1:11"> 过了好些日子，摩西长大了。有一天，他出去到他的同胞那里，看见他们的苦役。他看见一个埃及人正在打他的一个希伯来同胞。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 7:24–26"> 摩西左顾右看，确认没有人，就打死了那个埃及人，把他埋在沙土里。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 7:26–28; 哥林多前书 6:7–8"> 第二天他又出去，看哪，有两个希伯来人在打架！他就对那有错的人说：“你为什么打你的邻人呢？”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 12:14; 马太福音 21:23; 创世记 19:9"> 那人说：“谁立你作首领和审判官来管我们呢？难道你想杀我，像你杀那个埃及人一样吗？”<br />摩西就害怕，心想：“这事必定被人知道了。”</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 7:29; 希伯来书 11:27; 创世记 24:11"> 法老听到这事，就设法要杀摩西。于是摩西从法老面前逃走，到米甸地居住。有一天，他坐在一口水井旁。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="创世记 24:11; 出埃及记 3:1; 撒母耳记上 9:11"> 米甸的祭司有七个女儿；她们这天<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这天——辅助词语。">a</a></sup>来打水，灌满水槽，要给她们父亲的羊群饮水。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 29:10; 创世记 21:25; 创世记 26:15–22"> 有些牧人来驱赶她们，但摩西起来救助了她们，给她们的羊群饮水。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 3:1; 民数记 10:29; 出埃及记 4:18"> 她们回到父亲流珥那里，父亲就问：“今天你们为什么这么快就回来了呢？”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="创世记 50:11; 创世记 29:10"> 她们回答：“有一个埃及人救我们脱离那些牧人的手，甚至还为我们打水，又给羊群饮水。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 31:54; 创世记 43:25; 希伯来书 13:2"> 他问女儿们：“那人在哪里？你们为什么就这样撇下他呢？你们去请他来吃饭吧！”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 31:38–40; 希伯来书 13:5; 希伯来书 11:25"> 摩西愿意与那人住在一起，那人就把自己的女儿西坡拉嫁给摩西。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 11:13–14; 使徒行传 7:29; 出埃及记 22:21"> 西坡拉生了一个儿子，摩西给他起名为革顺，因为他说：“我在外邦之地作了寄居者。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="创世记 18:20–21; 雅各书 5:4; 出埃及记 3:7–9"> 过了许多日子，埃及王死了。以色列子孙因所服的劳役而叹息、哀求；他们因所服的劳役而发出的呼求上达于神。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 26:3; 诗篇 105:42; 出埃及记 6:5"> 神垂听他们的哀声；神记念他与亚伯拉罕、以撒、雅各所立的约；</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 4:31; 诗篇 55:22; 出埃及记 3:7–8"> 神垂顾以色列子孙；神顾念<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="顾念——原文直译“知道”。">b</a></sup>他们。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 16:1; 出埃及记 12:6; 利未记 23:16–18"> 以色列子孙从埃及地出来后的第三个月的初一<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="的初一——辅助词语。">a</a></sup>，就在那一天，他们来到西奈旷野。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 3:1; 出埃及记 17:1; 出埃及记 3:12"> 他们从利菲迪姆起行，来到了西奈旷野，在旷野中扎营；以色列人就在那里的山前扎了营。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="出埃及记 3:4; 使徒行传 7:38; 出埃及记 20:21"> 摩西上到神那里，耶和华从那山上向他呼唤说：“你要如此对雅各家说，如此告诉以色列子孙：</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 32:11–12; 以赛亚书 63:9; 以赛亚书 40:31"> ‘你们看见了我对埃及所做的事，以及我怎样把你们背在如鹰的羽翼上，带你们来到我这里。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 14:2; 申命记 7:6; 申命记 26:18"> 现在，如果你们留心听我的声音，遵守我的约，你们就会在万民中作我珍贵的产业，因为全地都是属于我的。</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 5:10; 彼得前书 2:9; 彼得前书 2:5"> 你们要归我作祭司的国度和圣洁的国民。’这些话你要对以色列子孙说。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 4:29–30; 出埃及记 3:16; 哥林多前书 15:1"> 摩西就去召来百姓的长老们，把耶和华指示他的这一切话都陈明在他们面前。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 24:7; 出埃及记 24:3; 约书亚记 24:24"> 全体民众一同回应说：“耶和华所说的一切，我们都会遵行。”摩西就把百姓的话带回给耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命记 4:36; 出埃及记 19:16; 出埃及记 24:15–16"> 耶和华对摩西说：“看哪，我要在厚密的云彩中临到你那里，好让子民听见我与你说话，他们就会永远相信你。”摩西把百姓的话告诉了耶和华。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 10:22; 创世记 35:2; 利未记 11:44–45"> 耶和华对摩西说：“你到子民那里去，今天和明天要把他们分别为圣，让他们洗自己的衣服，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 19:16; 出埃及记 34:5; 申命记 33:2"> 为第三天预备好，因为第三天耶和华要在全体民众眼前降临在西奈山上。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 12:20–21; 约书亚记 3:4; 出埃及记 19:21"> 你要在子民周围定下界限，说：‘你们要谨慎，不可上这山，也不可碰山的边界。凡碰这山的，必须被处死；</span>
<span className="v" id="v13" data-v="13" data-xref="帖撒罗尼迦前书 4:16; 希伯来书 12:20; 出埃及记 19:16"> 你们不可用手碰那人，必须用石头砸死，或用箭射死；无论是牲畜还是人，都不得存活。’号角长鸣的时候，子民才可以上山。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及记 19:10"> 摩西下了山到百姓那里，把百姓分别为圣；他们都洗了自己的衣服。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 7:5; 撒母耳记上 21:4–5; 出埃及记 19:11"> 摩西对百姓说：“你们要为第三天预备好，不要与女人亲近。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="希伯来书 12:18–19; 诗篇 18:11–14; 希伯来书 12:21"> 到了第三天早晨的时候，山上有雷声、闪电和浓厚的云彩，又有极其大的号角声，营中的全体民众都战兢。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 4:10; 申命记 5:5"> 摩西把百姓从营地领出来迎接神，他们都站在山下。</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 5:5; 出埃及记 3:2; 诗篇 144:5"> 那时整座西奈山都冒烟，因为耶和华在火中降临到山上；山的浓烟上腾，像窑炉的烟那样，整座山都大大震动。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 81:7; 出埃及记 19:16; 尼希米记 9:13"> 号角声越来越大，摩西说话，神就在雷声中回应他。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="尼希米记 9:13; 出埃及记 34:2; 出埃及记 19:11"> 耶和华降临在西奈山，临到山顶上。耶和华呼唤摩西上山顶，摩西就上去了。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 6:19; 出埃及记 3:5; 希伯来书 12:28–29"> 耶和华对摩西说：“你下去警诫子民，免得他们闯过界限到耶和华这里来看，以致他们中间有许多人灭亡<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="灭亡——原文直译“倒下”。">b</a></sup>；</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 24:5; 使徒行传 5:10; 历代志上 13:9–11"> 又告诫那些接近耶和华的祭司们把自己分别为圣，免得耶和华的怒气<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="的怒气——辅助词语。">c</a></sup>向他们发作。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出埃及记 19:12; 约书亚记 3:4–5"> 摩西对耶和华说：“百姓不能上西奈山，因为你已经警诫了我们，说：‘要为这座山定下界限，把它分别为圣。’”</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 4:16; 希伯来书 12:18–25; 希伯来书 12:29"> 耶和华对他说：“你下去，与亚伦一起上来；但祭司们和子民不可闯过界限上到耶和华这里，免得耶和华的怒气<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="的怒气——辅助词语。">d</a></sup>向他们发作。”</span>
<span className="v" id="v25" data-v="25"> 于是，摩西下到百姓那里去告诉他们。</span>
</div>
</div>

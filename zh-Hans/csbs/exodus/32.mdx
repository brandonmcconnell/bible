<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 7:40; 申命记 9:9; 出埃及记 24:18"> 百姓见摩西迟迟不下山，就聚集到亚伦那里，对他说：“起来！为我们造一个行走在我们前面的神明，因为那摩西，就是把我们从埃及地带上来的那个人，我们不知道他发生了什么事。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="士师记 8:24–27; 出埃及记 12:35–36; 以西结书 16:17"> 亚伦对他们说：“把你们妻子儿女耳朵上的金环摘下，拿来给我！”</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 46:6; 以赛亚书 40:19–20; 耶利米书 10:9"> 全体民众就把他们耳朵上的金环摘下，拿来给亚伦。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米记 9:18; 申命记 9:16; 列王纪上 12:28"> 亚伦从他们的手中接过来，用雕刻工具做模子，造了一个牛犊铸像。<br />他们就说：“以色列啊，这是你的神，是把你从埃及地带上来的那一位！”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪下 10:20; 利未记 23:2; 利未记 23:37"> 亚伦看见，就在牛犊前面筑了一座祭坛；亚伦宣告说：“明天是耶和华的节期。”</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 10:7; 民数记 25:2; 使徒行传 7:41–42"> 第二天，他们早早起来献上了燔祭，也带来了平安祭，然后百姓坐下吃喝，起来玩乐。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 32:11; 何西阿书 9:9; 士师记 2:19"> 耶和华对摩西说：“你赶快下去！因为你从埃及地带上来的百姓已经败坏了。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 12:28; 出埃及记 20:23; 出埃及记 20:3–4"> 他们很快就偏离了我指示他们的道路，为自己造了一个牛犊铸像，向它下拜，向它献祭，说：‘以色列啊，这是你的神，是把你从埃及地带上来的那一位！’”</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 7:51; 申命记 9:13; 以赛亚书 48:4"> 耶和华又对摩西说：“我看见这子民，看哪，他们是硬着颈项的子民！</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 9:14; 民数记 14:12; 申命记 9:19"> 现在，你由着我，我的怒气要向他们发作，我要灭绝他们，然后我要使你成为一个强大的民族。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="申命记 9:18–20; 申命记 9:26–29; 诗篇 106:23"> 摩西就恳求他的神耶和华的情面，说：“耶和华啊，你的怒气为什么要向你的子民发作呢？他们是你以伟大的能力，用大能的手，从埃及地领出来的。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 14:13–16; 申命记 9:28; 约书亚记 7:9"> 为什么要让埃及人说‘他出于恶意领他们出来，为要在山中杀死他们，从地面上灭绝他们’？求你转消你猛烈的怒气，改变心意，不向你的子民降灾祸。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 6:13; 创世记 12:7; 创世记 22:16"> 求你记念你的仆人亚伯拉罕、以撒和以色列；你曾经指着自己向他们起誓，对他们说：‘我必使你们的后裔增多，如同天上的星辰，我必把我说过的这全地都赐给你们的后裔；他们必继承这地，直到永远。’”</span>
<span className="v" id="v14" data-v="14" data-xref="约拿书 3:10; 诗篇 106:45; 耶利米书 26:13"> 于是，耶和华改变心意，不把他所说的灾祸降在他的子民身上。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命记 9:15; 出埃及记 40:20; 申命记 5:22"> 摩西转身从山上下来，手中拿着两块见证版；这版两面都写着字，正面背面都写着字。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 31:18; 希伯来书 8:10; 申命记 10:1"> 这版是神的工作，文字是神的文字，刻在版上。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及记 24:13; 出埃及记 17:9; 约书亚记 6:20"> 约书亚听见百姓喊叫的声音，就对摩西说：“营中有战争的声音。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 15:1–18; 但以理书 5:4; 但以理书 5:23"> 摩西说：<br /><span className="pl pl-1">“这不是战胜呼叫的声音，</span><br /><span className="pl pl-1">也不是战败呼叫的声音，</span><br /><span className="pl pl-1">我听见的是歌唱的声音。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命记 9:16–17; 耶利米书 31:32; 耶利米哀歌 5:15"> 摩西靠近营地，看见牛犊，又看见人在跳舞，摩西就怒气发作，他把两块版从手中扔出，摔碎在山下；</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 9:21; 列王纪下 23:6; 列王纪下 23:15"> 又把他们造的牛犊拿过来，用火焚烧，磨成粉末，撒在水面上，让以色列子孙喝。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 20:9; 约书亚记 7:19–26; 列王纪上 21:22"> 摩西对亚伦说：“这百姓对你做了什么，以致你把这大罪带给了他们？”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命记 9:24; 出埃及记 15:24; 出埃及记 16:20"> 亚伦说：“求我主不要怒气发作；你是知道这百姓的，他们倾向罪恶<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="倾向罪恶——原文直译“在罪恶中”。">a</a></sup>。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 32:1–4; 出埃及记 32:8"> 他们对我说：‘为我们造一个行走在我们前面的神明，因为那摩西，就是把我们从埃及地带上来的那个人，我们不知道他发生了什么事。’</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 32:4; 路加福音 10:29; 罗马书 3:10"> 我对他们说‘谁有金子就摘下来’，他们就给了我；我把金子扔进火中，这牛犊就出来了！”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 47:3; 弥迦书 1:11; 启示录 16:15"> 摩西看见百姓放纵——因为亚伦放纵他们，使他们在敌人中成为笑柄——</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 9:32; 马太福音 12:30; 撒母耳记下 20:11"> 摩西就站在营门口，说：“谁属于耶和华，到我这里来！”于是所有的利未子孙都聚集到他那里。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 25:5; 路加福音 14:26; 申命记 33:8–9"> 摩西对他们说：“以色列的神耶和华如此说：‘你们各人要把刀佩在大腿上，在营中往来，从一个门到另一个门，各人要杀死自己的兄弟、朋友和亲属。’”</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 33:9; 玛拉基书 2:4–6; 哥林多前书 10:8"> 利未的子孙就照着摩西的话去做了。那一天，百姓中倒下的约有三千人。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 25:11–13; 马太福音 10:37; 撒迦利亚书 13:3"> 摩西说：“今天你们已经奉献自己<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="已经奉献自己——或译作“要承接圣职”。">b</a></sup>归于耶和华，因为你们各人与自己的儿子和兄弟对立，今天给自己带来了祝福。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 12:20; 民数记 25:13; 列王纪下 17:21"> 第二天，摩西对百姓说：“你们犯了大罪，现在我要上到耶和华那里去，或许我可以为你们赎罪。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及记 20:23; 但以理书 9:11; 但以理书 9:8"> 摩西回到耶和华那里，说：“哦，这百姓犯了大罪，为自己造了金神像！</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 69:28; 罗马书 9:3; 启示录 21:27"> 现在，求你饶恕他们的罪；不然，请你把我从你所记的册子上抹掉吧！”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="申命记 29:20; 以西结书 18:4; 启示录 20:12"> 耶和华对摩西说：“谁对我犯罪，我就把谁从我的册子上抹掉。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 23:20; 申命记 32:35; 马太福音 23:35"> 现在你去，引导子民到我所告诉你的地方！看哪，我的使者必行走在你的前面！不过，在我惩罚的日子，我必惩罚他们的罪。”</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 7:41; 出埃及记 32:25; 撒母耳记下 12:9–10"> 耶和华打击百姓，是因为他们向亚伦造的牛犊所做的事。</span>
</div>

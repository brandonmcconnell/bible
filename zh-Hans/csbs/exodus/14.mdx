<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 12:1; 出埃及记 13:1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 33:7–8; 耶利米书 44:1; 出埃及记 13:17–18"> “你要吩咐以色列子孙转回去，在比哈希录前面，密夺和海之间扎营，就是在巴力洗分前面，面对着它，靠着海边扎营。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 4:28; 撒母耳记上 23:23; 诗篇 71:11"> 这样，法老就会说以色列子孙在这地迷了路，旷野把他们困住了。</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 9:22–23; 出埃及记 7:5; 罗马书 9:17"> 那时我要使法老的心刚硬，他会追赶他们，但我必藉着法老和他的全军得荣耀，埃及人就知道我是耶和华。”于是以色列子孙就这样做了。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="诗篇 105:25; 出埃及记 12:33; 路加福音 11:24–26"> 有人向埃及王报告以色列百姓逃走了；法老和他的臣仆就对以色列百姓改变了心意，说：“我们做的这是什么呢？居然让以色列人走，不再服事我们。”</span>
<span className="v" id="v6" data-v="6"> 于是法老备好他的战车，带着他的军队<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="军队——原文直译“子民”。">a</a></sup>一起去，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 15:4; 士师记 4:3; 诗篇 68:17"> 又带着六百辆精选的战车和埃及其余<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="其余——辅助词语。">b</a></sup>所有的战车，每辆战车上都有军官。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 13:17; 民数记 33:3; 申命记 26:8"> 耶和华使埃及王法老的心刚硬，他就追赶以色列子孙；那时以色列子孙正昂然无惧地<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="昂然无惧地——原文直译“高举着手”。">c</a></sup>出去。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 15:9; 约书亚记 24:6; 出埃及记 14:2"> 埃及人追赶他们，法老所有的马匹、战车、马兵和军队，追上了在海边扎营的以色列子孙；那地方靠着比哈希录，在巴力洗分前面。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约书亚记 24:7; 诗篇 34:17; 尼希米记 9:9"> 法老逼近的时候，以色列子孙举目，看哪，埃及人追过来了！以色列子孙就极其害怕，向耶和华呼求。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 106:7–8; 民数记 14:1–4; 出埃及记 15:23–24"> 他们对摩西说：“难道埃及没有坟墓，你就把我们带来死在旷野吗？你把我们从埃及领出来，你对我们做的这是什么呢？</span>
<span className="v" id="v12" data-v="12" data-xref="约拿书 4:3; 出埃及记 6:9; 约拿书 4:8"> 我们在埃及的时候，难道没有对你说过‘不要管我们，让我们服事埃及人’这话吗？因为服事埃及人总比死在旷野好。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志下 20:17; 历代志下 20:15; 出埃及记 14:30"> 摩西对以色列百姓说：“不要害怕，要站稳！看耶和华今天要为你们施行的拯救，因为你们今天所看见的埃及人，你们永远不会再看见了。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 3:22; 申命记 20:4; 历代志下 20:17"> 耶和华必为你们争战，你们要沉默！”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约书亚记 7:10; 以斯拉记 10:4–5; 尼希米记 9:9"> 耶和华对摩西说：“你为什么向我呼求呢？你要吩咐以色列子孙前行。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 7:19; 出埃及记 4:20; 出埃及记 4:2"> 你要举起你的杖，向海伸出你的手，把海分开，让以色列子孙从海中的干地上过去。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 14:8; 出埃及记 14:4; 以西结书 34:11"> 而我，看哪，我要使埃及人的心刚硬，他们就会随着下去。这样，我必藉着法老、他的全军、他的战车和马兵得荣耀。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 7:5; 出埃及记 14:4; 出埃及记 7:17"> 我藉着法老、他的战车和马兵得荣耀的时候，埃及人就知道我是耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 63:9; 出埃及记 32:34; 出埃及记 23:20–21"> 于是，在以色列营地前面行走的神的使者就移动，转到他们后面；云柱也从他们前面移动，立在他们后面。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 8:14; 哥林多后书 2:15–16; 箴言 4:18–19"> 云柱来到埃及营地和以色列营地之间，一边是云彩和黑暗，一边是火<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="火——辅助词语。">d</a></sup>照亮夜间。这样，双方整夜没有彼此靠近。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 63:12; 出埃及记 15:8; 诗篇 66:6"> 摩西向海伸出他的手，耶和华就用猛烈的东风刮了整整一夜，使海水退去，把海变成干地；于是水被分开了，</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 11:29; 诗篇 66:6; 出埃及记 15:19"> 以色列子孙就从海中的干地上过去，水在他们的右边和左边形成了墙。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出埃及记 15:19; 出埃及记 14:17; 出埃及记 15:9"> 埃及人追赶过来，法老所有的马匹、战车和马兵都随着他们下到海中。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 13:21; 诗篇 77:16–19; 出埃及记 14:25"> 到了晨更的时候，耶和华从云火柱中俯看埃及的军队，使埃及的军队溃乱，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 14:14; 申命记 3:22; 约伯记 20:24"> 又使他们的车轮脱落，难以驾驶。埃及人就说：“我们从以色列人面前逃跑吧！因为耶和华为他们争战，攻击埃及了。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 14:16; 出埃及记 8:5; 雅各书 2:13"> 耶和华对摩西说：“向海伸出你的手，使水回落淹没埃及人、他们的战车和马兵。”</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 4:18; 诗篇 78:53; 希伯来书 11:29"> 摩西就向海伸出他的手，清晨来临的时候，海恢复了原状；埃及人正迎着水逃跑，耶和华就把埃及人抖落在海中。</span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 78:53; 诗篇 106:9–11; 哈巴谷书 3:13"> 水一回落，就淹没了战车、马兵，以及随着以色列子孙下到海中的法老全军；他们中间连一个也没有留下。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 14:22; 诗篇 77:19–20; 以赛亚书 43:2"> 以色列子孙却从海中的干地上走过，水在他们的右边和左边形成了墙。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="诗篇 106:8; 诗篇 106:10; 诗篇 92:9–11"> 那一天，耶和华拯救以色列人脱离了埃及人的手；以色列人看见埃及人横尸海边。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 2:11; 约翰福音 11:45; 约翰福音 2:23–25"> 以色列人看见了耶和华向埃及施展大能的手段，百姓就敬畏耶和华，并相信耶和华和他的仆人摩西。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 36:1; 出埃及记 35:30; 约翰福音 3:27"> “你看，我已经提名召唤了犹大支派中户珥的孙子、乌利的儿子比撒列！</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 35:31; 以赛亚书 28:26; 列王纪上 7:14"> 我用神的灵充满了他，使他有智慧、聪慧、知识、各样的技艺，</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 26:1; 出埃及记 25:32–35; 历代志下 2:13–14"> 能构思艺术设计，能做金、银、铜的工艺，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 28:9–21"> 能做镶嵌宝石的石雕工艺，又能做木雕工艺，为要做各样的工艺。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 35:10; 出埃及记 35:34–1; 出埃及记 28:3"> 看哪，我指定了但支派中亚希撒抹的儿子亚何利亚伯与他一起！一切有才能<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有才能——原文直译“心里有智慧”。">a</a></sup>的，我在他们心里赐下了智慧，好使他们做我吩咐你的一切：</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 36:8–9; 出埃及记 25:10–22; 出埃及记 26:1–37"> 会幕、见证柜和其上的施恩座、会幕中的一切器具、</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 37:10–28; 出埃及记 30:1–10; 出埃及记 25:23–40"> 桌子和桌子的器具、纯金的灯台和灯台的一切器具、香坛、</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 38:1–8; 出埃及记 27:1–8; 出埃及记 40:11"> 燔祭的祭坛和祭坛的一切器具、洗濯盆和盆座、</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 4:5–14; 出埃及记 28:1–43; 出埃及记 39:1–43"> 编织的衣服——祭司亚伦的圣衣和他儿子们作祭司事奉时的衣服、</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 37:29; 出埃及记 30:23–38"> 膏油和圣所用的芬芳香；他们要照着我吩咐你的一切去做。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 耶和华指示摩西说：</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 20:12; 以西结书 20:20; 利未记 19:30"> “你要吩咐以色列子孙说：‘你们一定要谨守我的安息日，因为这是我与你们之间世世代代的标记，好使你们知道：我是把你们分别为圣的耶和华。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 35:2–3; 民数记 15:32–36; 以西结书 20:21"> 因此你们要谨守安息日，因为这日是给你们的圣日。凡亵渎这日的，必须被处死；任何人在这日做工，就要从民中被剪除。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 2:2; 出埃及记 16:23; 利未记 23:3"> 六天可以做工，但第七天是完全安息的安息日，是归耶和华为圣的；任何人在安息日做工，就必须被处死。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 50:5; 创世记 9:13; 创世记 17:11"> 因此以色列子孙要谨守安息日，他们世世代代要持守<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="持守——原文直译“遵行”。">b</a></sup>安息日，作为永远的约。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 1:31; 出埃及记 31:13; 创世记 2:2–3"> 这是我与以色列子孙之间的标记，直到永远，因为六日中耶和华造了诸天和大地，在第七日他就安息、休息了。’”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命记 4:13; 出埃及记 32:15–16; 申命记 5:22"> 耶和华在西奈山与摩西说完了话，就交给他两块见证版，就是神用手指写下的石版。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 31:10; 出埃及记 35:23; 出埃及记 35:19"> 他们用蓝色、紫色、朱红色线，做了圣所事奉用的编织的衣服，又为亚伦做了圣衣，是照着耶和华指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="出埃及记 28:6–12; 利未记 8:7; 出埃及记 25:7"> 比撒列用金色、蓝色、紫色、朱红色线和捻成的细麻线做了以弗得。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 36:8; 出埃及记 26:1"> 他们把金子锤成薄片，剪成细线，以精巧的工艺织入了蓝色、紫色、朱红色线和细麻之中；</span>
<span className="v" id="v4" data-v="4"> 又为以弗得做了两条相连的肩带，与它的两端相连。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 1:13; 马太福音 28:20; 以赛亚书 11:5"> 以弗得上的精巧织带，与以弗得的做法一样，都从同样的材料——金色、蓝色、紫色、朱红色线和捻成的细麻线织出，是照着耶和华指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 28:9; 以西结书 28:13; 约伯记 28:16"> 他们把两块红玛瑙石镶嵌在金槽中，像雕刻印章那样，雕刻了以色列儿子们的名字。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 4:7; 出埃及记 28:12; 出埃及记 28:29"> 他把这两块宝石安在以弗得的肩带上，作为以色列儿子们的记念石，是照着耶和华指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 28:4; 利未记 8:8–9; 以赛亚书 59:17"> 他以精巧的工艺做了一个胸牌，与以弗得的做法一样，用金色、蓝色、紫色、朱红色线和捻成的细麻线来做。</span>
<span className="v" id="v9" data-v="9"> 胸牌是方形的；他们把胸牌做成了双层，长一拃<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一拃——约20公分；下同。">a</a></sup>，宽一拃，叠为双层。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 28:21; 出埃及记 28:16–17; 启示录 21:19–21"> 他们在胸牌上镶嵌了四行宝石：第一行是红宝石、黄玉、绿宝石，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 28:18; 以西结书 28:13"> 第二行是绿松石、蓝宝石、金刚石，</span>
<span className="v" id="v12" data-v="12"> 第三行是红锆石、白玛瑙、紫晶，</span>
<span className="v" id="v13" data-v="13"> 第四行是黄水晶、红玛瑙、碧玉。这些都镶嵌在各自的金槽中。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 21:12"> 这些宝石都按着以色列儿子们的名字，十二块都按着他们的名字，像雕刻印章那样，按着各自的名字，代表十二个支派。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 10:28; 约翰福音 17:12; 彼得前书 1:5"> 他们在胸牌上用编绳子的工艺做了纯金的链子；</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 25:12"> 他们做了两个金槽和两个金环，把两个环接在胸牌上边<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="上边——辅助词语。">b</a></sup>的两端；</span>
<span className="v" id="v17" data-v="17"> 他们把两条金链子接在胸牌上边<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="上边——辅助词语。">c</a></sup>两端的两个环中，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 28:14; 雅歌 1:10"> 把两条链子的另两端接在两个槽上，把它们连在以弗得前面的肩带上。</span>
<span className="v" id="v19" data-v="19"> 他们再做了两个金环，安在胸牌下边<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="下边——辅助词语。">d</a></sup>的两端，在以弗得内侧的边上；</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 26:3"> 又做了两个金环，把它们接在以弗得前面的两条肩带下面，靠近接缝处，在以弗得的精巧织带上方。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 16:24; 哥林多前书 1:25; 哥林多前书 1:27"> 他们用蓝色的细绳把胸牌的环与以弗得的环连接，使胸牌贴在以弗得的精巧织带上，使胸牌不致从以弗得上松脱，是照着耶和华指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及记 28:31–35"> 他用纺织的工艺做了以弗得的外袍，整件都是蓝色的。</span>
<span className="v" id="v23" data-v="23"> 外袍的中间之处，有一个领口，像战袍的领口那样，领口有围边，免得撕裂。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 28:33; 加拉太书 5:22"> 他们在外袍的下摆上，用捻成的蓝色、紫色、朱红色线做了石榴，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 28:33–34; 雅歌 4:13; 诗篇 89:15"> 又用纯金做了铃铛，把铃铛加在石榴之间，在外袍下摆围边上的石榴之间，</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 28:34; 雅歌 4:13; 雅歌 6:7"> 一个铃铛一个石榴，一个铃铛一个石榴，在外袍下摆的围边上，是用于事奉，是照着耶和华指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以西结书 44:18; 彼得前书 1:13; 以赛亚书 61:10"> 他们用纺织的工艺，为亚伦和他的儿子们做了细麻袍子，</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 28:4; 以西结书 44:18; 出埃及记 28:39"> 细麻顶冠和细麻头饰巾，用捻成的细麻线做了细麻裤子，</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 28:39"> 又用蓝色、紫色、朱红色线和捻成的细麻线，以刺绣的工艺做了腰带，是照着耶和华指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="启示录 5:10; 希伯来书 7:26; 希伯来书 1:3"> 他们用纯金做了一面圣冠牌子，像雕刻印章那样，在金牌上刻了字“归耶和华为圣”；</span>
<span className="v" id="v31" data-v="31"> 又用一条蓝色的细绳把金牌系在顶冠上面，是照着耶和华指示摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="出埃及记 39:42–43; 马太福音 28:20; 出埃及记 25:40"> 这样，会幕的一切工作都完成了。以色列子孙遵行耶和华所指示摩西的一切，都照着做了。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 35:11–19; 出埃及记 31:7–11; 出埃及记 36:1–38"> 他们把帐幕带到摩西那里，就是帐篷和帐篷的一切器具：钩子、木板、横闩、柱子、底座、</span>
<span className="v" id="v34" data-v="34"> 染红公绵羊皮的遮盖、海狮皮的顶罩、帘幕的幔子、</span>
<span className="v" id="v35" data-v="35" data-xref="希伯来书 9:5; 出埃及记 25:17; 希伯来书 9:8"> 见证柜和柜的杠、施恩座、</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 25:30; 列王纪上 7:48"> 桌子和桌子的一切器具、陈设饼、</span>
<span className="v" id="v37" data-v="37" data-xref="腓立比书 2:15; 出埃及记 27:21; 马太福音 5:14–16"> 纯金的灯台、排列的灯、灯台的一切器具、点灯的油、</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及记 30:7; 出埃及记 37:29; 出埃及记 30:3"> 金坛、膏油、芬芳香、帐篷的门帘、</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪上 8:64; 出埃及记 38:30"> 铜祭坛、祭坛用的铜格网、祭坛的杠、祭坛的一切器具、洗濯盆和盆座、</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及记 27:9–16"> 院子的帷幔、帷幔的柱子、底座、院子的门帘、绳子、橛子、会幕的帐幕服事所用的一切器具、</span>
<span className="v" id="v41" data-v="41" data-xref="出埃及记 28:2; 出埃及记 31:10; 出埃及记 39:1"> 圣所事奉用的编织的衣服——祭司亚伦的圣衣和他儿子们作祭司事奉时的衣服。</span>
<span className="v" id="v42" data-v="42" data-xref="出埃及记 35:10; 出埃及记 23:21–22; 提摩太后书 2:15"> 这样，以色列子孙照着耶和华所指示摩西的一切，完成了一切工作。</span>
<span className="v" id="v43" data-v="43" data-xref="民数记 6:23–27; 利未记 9:22–23; 撒母耳记下 6:18"> 摩西查看一切工作，看哪，他们遵行耶和华所指示的，都照着做了。于是，摩西祝福了他们。</span>
</div>

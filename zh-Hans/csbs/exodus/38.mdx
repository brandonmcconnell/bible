<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 27:1–8; 以西结书 43:13–17; 出埃及记 40:6"> 他用金合欢木造了一座燔祭坛，长五肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="五肘——相当于2.3公尺。1肘=45.7公分。">a</a></sup>，宽五肘，是方形的，高三肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="三肘——相当于1.4公尺。">b</a></sup>；</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 27:2; 约伯记 6:12"> 在祭坛的四角上做了犄角，犄角从祭坛而出；又把祭坛包上了铜。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="出埃及记 27:3; 撒母耳记上 2:13"> 他做了祭坛的一切器具：桶、铲子、碗、肉叉和火盆；祭坛的一切器具，他都用铜做。</span>
<span className="v" id="v4" data-v="4"> 他为祭坛做了一个铜格网，安放在祭坛的边框之下，使网达到祭坛的半腰。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 27:4"> 他在铜格网的四角铸了四个环，用来穿杠。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 10:3; 出埃及记 25:6"> 他用金合欢木做了杠，把它们包上铜，</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 9:15; 哥林多前书 2:2; 哥林多前书 1:24"> 把杠穿进祭坛两边的环中，用来抬祭坛。他用木板把祭坛做成了空心的。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 2:22; 路加福音 2:37; 出埃及记 40:7"> 他用会幕入口服事的女人的铜<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="铜——辅助词语。">c</a></sup>镜做了一个铜盆和铜盆座。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 27:9–19; 诗篇 89:7; 列王纪上 6:36"> 他做了院子。南边用捻成的细麻线编织了院子的帷幔，共一百肘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一百肘——相当于45.7公尺。1肘=45.7公分。">d</a></sup>。</span>
<span className="v" id="v10" data-v="10"> 帷幔的柱子二十根，柱子的铜底座二十个，柱子上的钩子和箍环都是银的。</span>
<span className="v" id="v11" data-v="11"> 北边也是一百肘，帷幔的柱子二十根，柱子的铜底座二十个，柱子上的钩子和箍环都是银的。</span>
<span className="v" id="v12" data-v="12"> 西边的帷幔是五十肘<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="五十肘——相当于22.9公尺；下同。1肘=45.7公分。">e</a></sup>，帷幔的柱子十根，柱子的底座十个，柱子上的钩子和箍环都是银的。</span>
<span className="v" id="v13" data-v="13"> 东边，就是日出的方向，也是五十肘：</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 27:14"> 门的一边，帷幔十五肘<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="十五肘——相当于6.9公尺；下同。">f</a></sup>，帷幔的柱子三根，柱子的底座三个；</span>
<span className="v" id="v15" data-v="15"> 门的另一边也一样，院子门口两边的帷幔各十五肘，帷幔的柱子三根，柱子的底座三个。</span>
<span className="v" id="v16" data-v="16"> 院子四围所有的帷幔都是用捻成的细麻线编织的。</span>
<span className="v" id="v17" data-v="17"> 柱子的底座都是铜的，柱子上的钩子和箍环都是银的，包柱顶的也都是银的；院子的所有柱子都有银箍环箍着。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="历代志下 3:14"> 院子的门帘是用蓝色、紫色、朱红色线和捻成的细麻线，以刺绣的工艺编织；长二十肘<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="二十肘——相当于9.1公尺。1肘=45.7公分。">g</a></sup>，宽五肘<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="五肘——相当于2.3公尺。">h</a></sup>之高，与院子的帷幔一样高。</span>
<span className="v" id="v19" data-v="19"> 帷幔的柱子四根，柱子的铜底座四个，柱子上的钩子都是银的，包柱顶的和箍环也都是银的。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 3:9; 出埃及记 27:19; 以弗所书 2:21–22"> 帐幕和院子四围所有的橛子都是铜的。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 7:44; 民数记 9:15; 历代志下 24:6"> 以下是有关帐幕，就是见证帐幕的清单，是照着摩西的吩咐清点的；这是祭司亚伦的儿子以塔玛尔经手的利未人的服事。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 35:30–3; 出埃及记 31:1–5; 诗篇 119:6"> 耶和华所指示摩西的一切，犹大支派中户珥的孙子、乌利的儿子比撒列都做了。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 35:34; 出埃及记 31:6"> 与他一起的，有但支派中亚希撒抹的儿子亚何利亚伯，能雕刻，能设计，又能用蓝色、紫色、朱红色线和细麻刺绣。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数记 18:16; 民数记 3:47; 利未记 27:25"> 用于做圣所工程一切工作的所有金子，就是摇献的金子，按圣所的谢克尔<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="谢克尔——重量单位；后来成为货币单位。1谢克尔=11.4公克。本章下同。">i</a></sup>标准，是二十九他连得<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="二十九他连得——相当于991.8公斤。1他连得=34.2公斤。">j</a></sup>七百三十谢克尔<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="七百三十谢克尔——相当于8.3公斤。">k</a></sup>。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 30:12"> 会众中被数点的人所付的银子，按圣所的谢克尔标准，是一百他连得<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="一百他连得——相当于3.4公吨；下同。1他连得=34.2公斤。">l</a></sup>一千七百七十五谢克尔<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="一千七百七十五谢克尔——相当于20.2公斤；下同。">m</a></sup>：</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 1:46; 出埃及记 30:13; 出埃及记 12:37"> 所有通过数点归入被数之众的人，每人一比加<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="一比加——相当于5.7公克。1比加=0.5谢克尔=10季拉。">n</a></sup>，按圣所的谢克尔标准，是半谢克尔<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="半谢克尔——相当于5.7公克。">o</a></sup>；二十岁以上的，共六十万三千五百五十人。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 26:19; 出埃及记 26:25; 出埃及记 26:21"> 一百他连得银子用来铸圣所的底座和幔子的底座：一百个底座一百他连得，一个底座一他连得；</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 27:17"> 一千七百七十五谢克尔银子用来做柱子上的钩子，包上柱顶，并做柱子的箍环。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 摇献的铜是七十他连得<sup className="fn"><a href="#fn-p" id="fnref-p" data-fn="七十他连得——相当于2.4公吨。1他连得=34.2公斤。">p</a></sup>两千四百谢克尔<sup className="fn"><a href="#fn-q" id="fnref-q" data-fn="两千四百谢克尔——相当于27.4公斤。1谢克尔=11.4公克。">q</a></sup>。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 26:37; 出埃及记 27:17; 出埃及记 27:10"> 这些铜用来做会幕入口的底座、铜祭坛、祭坛用的铜格网、祭坛的一切器具、</span>
<span className="v" id="v31" data-v="31"> 院子四围的底座、院子门口的底座、帐幕所有的橛子和院子四围所有的橛子。</span>
</div>
</div>

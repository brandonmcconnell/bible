<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 12:33; 出埃及记 12:31; 出埃及记 3:19–20"> 耶和华对摩西说：“现在你必看到我要对法老做的事；他必因我大能的手让子民走，他必因我大能的手从自己的地驱逐他们。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="耶利米书 9:24; 玛拉基书 3:6; 使徒行传 17:24–25"> 神指示摩西说：“我是耶和华。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 83:18; 诗篇 68:4; 创世记 17:1"> 我曾经以‘全能的神’向亚伯拉罕、以撒、雅各显现；至于我的名字‘耶和华’，我未曾让他们知道。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 28:4; 创世记 15:18; 创世记 17:7–8"> 我又与他们确立了我的约，要赐给他们迦南地，就是他们曾寄居在其中的寄居之地。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 2:24; 诗篇 106:44–45; 以赛亚书 63:9"> 现在，我听见了以色列子孙因埃及人奴役他们而发出的哀声，我就记念我的约。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="申命记 26:8; 历代志上 17:21; 出埃及记 7:4"> “因此你当对以色列子孙说：‘我是耶和华。我要把你们从埃及的苦役中领出来，我要解救你们脱离埃及的奴役，我要用伸出的膀臂和极大的审判来赎回你们；</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 7:6; 申命记 29:13; 申命记 4:20"> 我要拣选你们作我的子民，我也要作你们的神。这样你们就知道：我是耶和华你们的神，是把你们从埃及的苦役中领出来的那一位。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 26:3; 创世记 15:18; 以西结书 20:42"> 我要领你们进入我举手起誓要赐给亚伯拉罕、以撒、雅各的那地，我要把那地赐给你们作产业。我是耶和华。’”</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 5:21; 约伯记 21:4; 出埃及记 14:12"> 摩西就把这话告诉了以色列子孙，但他们因灵里的沮丧和沉重的劳役，没有听从摩西。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 于是耶和华指示摩西说：</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 6:29; 出埃及记 5:23; 出埃及记 3:10"> “你去，对埃及王法老说，让以色列子孙走，离开法老的地。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及记 4:10; 耶利米书 1:6; 出埃及记 6:30"> 摩西在耶和华面前说：“看哪，以色列子孙尚且不听从我，法老又怎么会听从我呢？因为我是个口唇笨拙<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="口唇笨拙——原文直译“嘴唇没有受割礼”。">a</a></sup>的人。”</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 27:23; 提摩太前书 6:13; 诗篇 91:11"> 耶和华对摩西和亚伦说话，吩咐了他们有关以色列子孙和埃及王法老的事，要他们把以色列子孙从埃及地领出来。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="创世记 46:9; 历代志上 5:3; 民数记 26:5–7"> 以下是他们父家的首领：<br /><span className="pl pl-1">以色列长子鲁本的儿子是哈诺、法路、希斯伦和迦米。</span><br /><span className="pl pl-1">这是鲁本的家族。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="历代志上 4:24; 创世记 46:10; 民数记 26:12–13"> <span className="pl pl-1">西缅的儿子是耶姆利、雅悯、阿辖、雅斤、琐哈尔，以及扫罗——迦南女子的儿子。</span><br /><span className="pl pl-1">这是西缅的家族。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="民数记 3:17; 创世记 46:11; 历代志上 6:1"> <span className="pl pl-1">利未的儿子，按着他们的家系，名字如下：革顺、哥辖、米拉利；</span><br /><span className="pl pl-1">利未一生的年岁是一百三十七岁。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 6:17; 民数记 3:18; 历代志上 23:7"> <span className="pl pl-1">革顺的儿子，按着他们的家族，名字如下</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="名字如下——辅助词语。">b</a></sup><br /><span className="pl pl-1">：立尼、示每。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 6:18; 历代志上 6:2; 民数记 3:19"> <span className="pl pl-1">哥辖的儿子是阿姆兰、以斯哈、希伯伦和乌基业；</span><br /><span className="pl pl-1">哥辖一生的年岁是一百三十三岁。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="民数记 3:20; 历代志上 23:21; 历代志上 6:19"> <span className="pl pl-1">米拉利的儿子是玛赫利和穆希。</span><br /><span className="pl pl-1">这是利未的家族，都按着他们的家系。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="民数记 26:59; 出埃及记 2:1–2; 出埃及记 6:18"> <span className="pl pl-1">阿姆兰娶了他父亲的妹妹约基别为妻，</span><br /><span className="pl pl-1">约基别为他生了亚伦和摩西；</span><br /><span className="pl pl-1">阿姆兰一生的年岁是一百三十七岁。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="民数记 16:1; 历代志上 6:37–38; 民数记 16:32"> <span className="pl pl-1">以斯哈的儿子是可拉、尼斐和泽克利。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="利未记 10:4; 民数记 3:30; 尼希米记 3:20"> <span className="pl pl-1">乌基业的儿子是米沙利、以利撒番和西提利。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="路得记 4:19–20; 民数记 2:3; 民数记 1:7"> <span className="pl pl-1">亚伦娶了亚米拿达的女儿、拿顺的妹妹以利沙巴为妻，</span><br /><span className="pl pl-1">以利沙巴为他生了纳达布、亚比户、以利亚撒和以塔玛尔。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 6:22–23; 民数记 16:1; 撒母耳记上 1:1"> <span className="pl pl-1">可拉的儿子是亚惜、以利加拿和亚比亚撒。</span><br /><span className="pl pl-1">这是可拉的家族。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 24:33; 民数记 25:7–13; 约书亚记 22:31–32"> <span className="pl pl-1">亚伦的儿子以利亚撒娶了普提业的一个女儿为妻，</span><br /><span className="pl pl-1">他的妻子为他生了非尼哈。</span><br /><span className="pl pl-1">以上是利未人父系的首领，都按着他们的家族。</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 12:51; 出埃及记 12:17; 出埃及记 7:4"> 正是这亚伦和摩西，耶和华曾对他们说：“你们要把以色列子孙从埃及地一队一队领出来！”</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 6:26; 出埃及记 7:10; 诗篇 77:20"> 而对埃及王法老说话，要把以色列子孙从埃及领出来的，也正是这摩西和亚伦。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 当耶和华在埃及地对摩西说话的日子，</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 6:11; 出埃及记 7:2; 出埃及记 6:2"> 耶和华指示摩西说：“我是耶和华。我对你所说的一切，你都要告诉埃及王法老。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及记 6:12; 出埃及记 4:10; 哥林多前书 9:16–17"> 摩西却在耶和华面前说：“看哪，我是个口唇笨拙<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="口唇笨拙——原文直译“嘴唇没有受割礼”。">c</a></sup>的人，法老怎么会听从我呢？”</span>
</div>
</div>

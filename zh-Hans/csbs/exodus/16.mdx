<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 33:10–12; 出埃及记 15:27; 出埃及记 17:1"> 全体以色列会众从伊利姆起行，在他们从埃及地出来后的第二个月的十五日，来到伊利姆和西奈之间汛的旷野。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 10:10; 出埃及记 15:24; 诗篇 106:25"> 全体以色列会众在旷野向摩西和亚伦发怨言。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 11:4–5; 民数记 20:3–5; 出埃及记 17:3"> 以色列子孙对他们说：“我们宁愿在埃及地死在耶和华的手中！那时我们坐在肉锅旁边，吃粮吃到饱；你们却把我们领到这旷野，要饿死这全体会众！”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 10:3; 诗篇 78:24–25; 申命记 8:2"> 耶和华对摩西说：“看哪，我要从天上降下粮食给你们！子民要出去，每天捡拾每天的份额，我好试验他们会不会遵行我的法规。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 16:22–23; 出埃及记 35:2–3; 利未记 25:21–22"> 到了第六天，他们要把所收进来的预备好，那将是他们天天捡拾的双倍。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 6:7; 民数记 16:28; 出埃及记 16:12–13"> 摩西和亚伦对所有的以色列子孙说：“晚上，你们就会知道是耶和华把你们从埃及地领出来的；</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 40:5; 民数记 16:11; 约翰福音 11:40"> 早晨，你们就会看到耶和华的荣耀，因为耶和华听见了你们对他的怨言。我们算什么，你们为何向我们发怨言呢？”</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 13:2; 撒母耳记上 8:7; 帖撒罗尼迦前书 4:8"> 摩西又说：“到了晚上，耶和华会给你们肉吃；到了早晨，他会给你们粮食吃到饱，因为耶和华听见了你们向他所发的怨言。我们算什么呢？你们的怨言其实不是向我们发的，而是向耶和华发的。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数记 16:16; 出埃及记 16:2; 出埃及记 16:8"> 摩西对亚伦说：“你要对全体以色列会众说：‘你们要近前来到耶和华的面前，因为他已经听见了你们的怨言。’”</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 16:7; 民数记 16:19; 民数记 16:42"> 亚伦对全体以色列会众说话的时候，他们转向旷野，看哪，耶和华的荣耀在云彩中显现！</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和华指示摩西说：</span>
<span className="v" id="v12" data-v="12" data-xref="约珥书 3:17; 以西结书 39:22; 出埃及记 6:7"> “我已经听见以色列子孙的怨言，你要告诉他们说：‘黄昏的时候，你们会有肉吃；到了早晨，你们会有粮食得饱足。这样你们就知道：我是耶和华你们的神。’”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 11:9; 诗篇 105:40; 诗篇 78:27–28"> 到了晚上，有鹌鹑飞上来，遮盖了营地；到了早晨，营地的四围有一层露水。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 11:7–9; 诗篇 105:40; 诗篇 78:24"> 那一层露水蒸发之后，看哪，旷野的地面上有薄片状的东西，薄得像地上的霜！</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 16:4; 约翰福音 6:58; 出埃及记 16:31"> 以色列子孙看到就彼此说：“这是什么呢？”因为他们不知道那是什么。<br />摩西对他们说：“这就是耶和华赐给你们吃的粮食。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 16:36; 出埃及记 16:18; 出埃及记 16:32–33"> 耶和华所指示的话是这样的：‘你们要按各人的食量捡拾，也要按你们各人帐篷中的人数捡收，一人一俄梅珥<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一俄梅珥——相当于2.2公升，计量谷物的量器；本章下同。">a</a></sup>。’”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 以色列子孙就这样做了。有人捡拾得多，有人捡拾得少；</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 8:14–15"> 但他们用俄梅珥量的时候，多捡拾的没有剩余，少捡拾的也没有缺少；各人都按自己的食量捡拾。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 12:10; 出埃及记 23:18; 马太福音 6:34"> 摩西对他们说：“谁都不可留下一点粮食到早晨。”</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 10:14; 民数记 16:15; 以弗所书 4:26"> 有些人却没有听从摩西，把一些粮食留到早晨，那些粮食就生虫发臭了。于是摩西对他们发怒。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="箴言 6:6–11; 传道书 12:1; 哥林多后书 6:2"> 每天早晨，他们按各人的食量捡拾；太阳一热，粮食就融化了。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 16:5; 利未记 25:22; 出埃及记 16:16"> 到了第六天，他们捡拾双倍的粮食，一人两俄梅珥。所有的会众领袖都来告诉摩西这事<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这事——辅助词语。">b</a></sup>。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 23:3; 出埃及记 31:15; 出埃及记 20:8–11"> 摩西就对他们说：“耶和华这样说：‘明天是完全安息的日子，是耶和华的圣安息日。今天<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="今天——辅助词语。">c</a></sup>你们要烤的就烤，要煮的就煮，所有剩余的要留在一边<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="留在一边——原文直译“为自己存放”。">d</a></sup>保存到早晨。’”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出埃及记 16:20; 出埃及记 16:33"> 他们就照着摩西吩咐的，把剩余的留到早晨，那些粮食既没有发臭，里面也没有生蛆。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 16:23; 出埃及记 16:29; 尼希米记 9:14"> 摩西说：“今天就吃这个吧，因为今天是耶和华的安息日，今天你们在田野中必找不到粮食。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 5:13; 出埃及记 20:9–11; 以西结书 46:1"> 六天你们可以捡拾粮食，但第七天是安息日，那一天不会有粮食。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="箴言 20:4"> 到了第七天，百姓中有些人出去捡拾，但找不到粮食。</span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 78:10; 诗篇 106:13; 民数记 14:11"> 耶和华对摩西说：“你们拒绝遵守我的诫命和训诲，要到什么时候呢？</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 31:13; 以赛亚书 58:13–14; 以西结书 20:12"> 你们看，耶和华赐给了你们安息日，因此第六天他就赐给你们两天的粮食；第七天你们各人都要留在原处，任何人都不可离开自己的地方。”</span>
<span className="v" id="v30" data-v="30" data-xref="申命记 5:12–14; 利未记 23:3; 希伯来书 4:9"> 于是百姓就在第七天安息了。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="雅歌 2:3; 民数记 11:6–9; 出埃及记 16:15"> 以色列家给这粮食起名为“吗哪”，它像芫荽的种子，是白色的，它的味道像加蜂蜜的薄饼。</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 105:5; 路加福音 22:19; 诗篇 111:4–5"> 摩西说：“耶和华所指示的话是这样的：‘你们要把一俄梅珥满满的吗哪保存下来给你们的世世代代，好让他们看到我把你们从埃及地领出来的时候，给你们在旷野中吃的粮食。’”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="希伯来书 9:4"> 摩西对亚伦说：“拿一个罐子，装入满满一俄梅珥的吗哪，放在耶和华面前，保存下来给你们的世世代代。”</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 27:21; 出埃及记 25:21; 出埃及记 25:16"> 亚伦就照着耶和华所指示摩西的，把吗哪放在见证版前面，保存下来。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="尼希米记 9:20–21; 约书亚记 5:12; 申命记 8:2–3"> 以色列子孙吃这吗哪四十年，直到他们来到有人居住的地方；他们吃这吗哪，直到他们来到迦南地的边界。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 16:16; 出埃及记 16:32–33"> （一俄梅珥<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一俄梅珥——相当于2.2公升。">e</a></sup>是一伊法<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一伊法——相当于22公升。">f</a></sup>的十分之一。）</span>
</div>
</div>

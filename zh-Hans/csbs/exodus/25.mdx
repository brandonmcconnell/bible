<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 9:7; 尼希米记 11:2; 以斯拉记 2:68"> “你要吩咐以色列子孙拿供物给我；凡是甘心奉献的人，你们就从他们收取给我的供物。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 8:9; 约伯记 28:2"> 以下是你们要从他们收取的供物：金、银、铜，</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 19:8; 创世记 41:42; 以西结书 16:10"> 蓝色线、紫色线、朱红色线、细麻、山羊毛，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 26:37–1; 出埃及记 26:14–15; 出埃及记 36:20"> 染红的公绵羊皮、海狮皮<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="海狮皮——原文语义不确定，基本意思是一种精细的皮革；本卷下同。">a</a></sup>，金合欢木，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 27:20; 出埃及记 25:37; 出埃及记 40:24–25"> 点灯的油、制作膏油和芬芳香的香料，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 28:4; 出埃及记 28:6–30"> 以及以弗得和胸牌上用的红玛瑙石和镶嵌的宝石。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 6:16; 列王纪上 6:13; 启示录 21:3"> “他们要为我造一个圣所，好使我住在他们中间。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 25:40; 希伯来书 8:5; 使徒行传 7:44"> 我将向你指明的一切，就是帐幕的样式和其中一切器具的样式，你们要照着去做。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="希伯来书 9:4; 出埃及记 37:1–3; 申命记 10:1–3"> “他们要用金合欢木做一个柜，长二肘半<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="二肘半——相当于114.3公分；下同。1肘=45.7公分。">b</a></sup>，宽一肘半<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一肘半——相当于68.6公分；下同。">c</a></sup>，高一肘半。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 25:24; 出埃及记 30:3; 历代志下 3:4"> 你要把它包上纯金，里里外外都包上，并在它的四围镶上金边；</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 27:7; 出埃及记 25:26; 出埃及记 25:15"> 又要为它铸四个金环，安装在它的四个脚上，两个环在一边，两个环在另一边。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 15:15; 民数记 4:11; 出埃及记 27:6"> 你要用金合欢木做两根杠，把它们包上金，</span>
<span className="v" id="v14" data-v="14"> 把杠穿进柜两边的环中，用它们来抬柜。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 8:8; 历代志下 5:9"> 杠要留在柜的环中，不可抽出来。</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 31:26; 列王纪上 8:9; 希伯来书 9:4"> 你要把我将赐给你的见证版安放在柜里。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 9:5; 出埃及记 37:6; 希伯来书 4:16"> 你要用纯金做施恩座<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="施恩座——或译作“赎罪盖”；下同。">d</a></sup>，长二肘半，宽一肘半；</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 10:20; 希伯来书 9:5; 列王纪上 8:6–7"> 又要在施恩座的两端，用金子造两个基路伯，锤擛成形——</span>
<span className="v" id="v19" data-v="19"> 一端造一个基路伯，另一端也造一个基路伯，从施恩座的两端造出基路伯。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志上 28:18; 列王纪上 8:7; 希伯来书 9:5"> 两个基路伯要向上展开翅膀，用它们的翅膀遮掩施恩座；基路伯的脸要彼此相向，它们的脸要朝着施恩座。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 26:34; 罗马书 10:4; 出埃及记 25:16–17"> 你要把施恩座安放在柜上面，把我将赐给你的见证版安放在柜里。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 29:42–43; 民数记 7:89; 以赛亚书 37:16"> 我要在那里与你相会，并从施恩座上，从见证柜上面的两个基路伯之间，把我要吩咐你传给以色列子孙的一切事告诉你。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="希伯来书 9:2; 出埃及记 37:10–16; 列王纪上 7:48"> “你要用金合欢木做一张桌子，长二肘<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="二肘——相当于91.4公分。1肘=45.7公分。">e</a></sup>，宽一肘<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一肘——相当于45.7公分。">f</a></sup>，高一肘半<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="一肘半——相当于68.6公分。">g</a></sup>。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 25:11; 列王纪上 6:20–22"> 你要把它包上纯金，并在它的四围镶上金边；</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 37:2; 出埃及记 30:3"> 要在它的四围做一掌宽<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="一掌宽——相当于7.4公分。">h</a></sup>的边框，并在它的边框四围镶上金边；</span>
<span className="v" id="v26" data-v="26"> 又要为它做四个金环，安装在它的四角，就是它的四个腿上。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 25:14; 出埃及记 25:28"> 环要靠近边框，用来穿杠抬桌子。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 25:14; 使徒行传 9:15; 民数记 10:17"> 你要用金合欢木做两根杠，把它们包上金，用它们来抬桌子。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 4:7; 出埃及记 37:16; 启示录 3:20"> 你要做桌子上浇奠用的盘、碟、壶和杯；这些都要用纯金来做。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 24:5–9; 马太福音 12:4; 出埃及记 39:36"> 你要在桌子上摆放陈设饼，使陈设饼常在我面前。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪上 7:49; 撒迦利亚书 4:2; 出埃及记 37:17–24"> “你要用纯金做一个灯台，灯台要锤擛成形——它的底座、枝干、花杯、花萼和花瓣都要与灯台一体锤出。</span>
<span className="v" id="v32" data-v="32"> 从灯台的两边要伸出六根枝干，三根枝干在一边，三根枝干在另一边。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 17:4–8; 耶利米书 1:11–12; 撒迦利亚书 4:3"> 在一边的每根枝干上有三个杏花形状的花杯，每个都有花萼和花瓣；在另一边的每根枝干上也有三个杏花形状的花杯，每个都有花萼和花瓣；从灯台伸出的六根枝干都要这样。</span>
<span className="v" id="v34" data-v="34"> 灯台的主干<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="的主干——辅助词语。">i</a></sup>上有四个杏花形状的花杯，每个都有花萼和花瓣；</span>
<span className="v" id="v35" data-v="35"> 从灯台伸出的第一对两根枝干下面有一个花萼，第二对两根枝干下面有一个花萼，第三对两根枝干下面也有一个花萼；从灯台伸出的六根枝干都要这样。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 25:18; 列王纪上 10:16–17; 历代志下 9:15"> 它们的花萼和枝干要与灯台一体锤出，整个灯台都要用同一块纯金锤成。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="民数记 8:2; 启示录 1:20–1; 利未记 24:2–4"> “你要做灯台的七盏灯，把它们安装在灯台上，使灯照亮灯台前方。</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪下 12:13; 耶利米书 52:18; 列王纪下 25:14"> 灯台的灯剪和灯盘都要用纯金做；</span>
<span className="v" id="v39" data-v="39"> 要用一他连得<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="一他连得——相当于34.2公斤。">j</a></sup>纯金做灯台和所有这些器具。</span>
<span className="v" id="v40" data-v="40" data-xref="希伯来书 8:5; 出埃及记 26:30; 使徒行传 7:44"> 你当留意，要照着在山上向你指明的样式去做！</span>
</div>
</div>

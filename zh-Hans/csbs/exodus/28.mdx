<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 18:7; 希伯来书 5:1–5; 民数记 17:2–9"> “你要从以色列子孙中，把你哥哥亚伦和他的儿子们带到你这里，使亚伦、亚伦的儿子纳达布、亚比户、以利亚撒和以塔玛尔作祭司事奉我。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 8:30; 出埃及记 31:10; 启示录 19:8"> 你要为你哥哥亚伦做圣衣，以显出荣耀、华美。</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所书 1:17; 哥林多前书 12:7–11; 以赛亚书 11:2"> 你要吩咐一切有才能<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有才能——原文直译“心里有智慧”。">a</a></sup>的人，就是我用智慧的灵所充满的人，他们要为亚伦做圣衣，使他分别为圣，作祭司事奉我。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 6:14; 启示录 9:17; 以赛亚书 59:17"> 以下是他们要做的衣装：胸牌、以弗得、外袍、编织的袍子、顶冠、腰带。他们要为你哥哥亚伦和他的儿子们做圣衣，使他们作祭司事奉我。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 25:3–4; 出埃及记 39:2–3"> 他们要拿金色、蓝色、紫色、朱红色线和细麻来做。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 39:2–7; 出埃及记 26:1"> “他们要用金色、蓝色、紫色、朱红色线和捻成的细麻线，以精巧的工艺做以弗得；</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 39:4"> 以弗得要有两条肩带与它的两端相连，使之相连在一起。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 28:27–28; 利未记 8:7; 出埃及记 29:5"> 以弗得上的精巧织带，要与以弗得的做法一样，都从同样的材料——金色、蓝色、紫色、朱红色线和捻成的细麻线织出。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以西结书 28:13; 历代志下 2:7; 以赛亚书 49:16"> “你要拿两块红玛瑙石，在它们上面雕刻以色列儿子们的名字：</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 1:1–4; 创世记 43:33"> 六个名字在一块宝石上，六个名字在另一块宝石上，都按着他们的家系；</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太后书 2:19; 启示录 7:2; 耶利米书 22:24"> 要用宝石匠雕刻印章的工艺，在这两块宝石上雕刻以色列儿子们的名字，再把宝石镶嵌在金槽中。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 28:29; 约书亚记 4:7; 出埃及记 39:6–7"> 你要把这两块宝石安在以弗得的肩带上，为以色列子孙作记念石。亚伦要在耶和华面前把他们的名字背负在他的双肩上，作为记念。</span>
<span className="v" id="v13" data-v="13"> 你要做两个金槽，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 39:15; 出埃及记 39:17–18; 列王纪上 7:17"> 又要用编绳子的工艺做两条纯金的链子，把绳子一样的链子接在槽上。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="出埃及记 28:30; 出埃及记 26:1; 出埃及记 28:4"> “你要以精巧的工艺做一个决断胸牌，要与以弗得的做法一样，用金色、蓝色、紫色、朱红色线和捻成的细麻线来做。</span>
<span className="v" id="v16" data-v="16"> 胸牌是方形的，叠为双层，长一拃<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一拃——约20公分；下同。">b</a></sup>，宽一拃。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 28:13; 出埃及记 39:10–21; 箴言 8:11"> 你要在胸牌上镶嵌四行宝石：<br /><span className="pl pl-1">第一行是红宝石、黄玉、绿宝石，</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 27:16; 约伯记 28:6; 雅歌 5:14"> <span className="pl pl-1">第二行是绿松石、蓝宝石、金刚石，</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 54:12; 出埃及记 39:12"> <span className="pl pl-1">第三行是红锆石、白玛瑙、紫晶，</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 1:16; 启示录 4:3; 但以理书 10:6"> <span className="pl pl-1">第四行是黄水晶、红玛瑙、碧玉。</span><br />这些都要镶嵌在各自的金槽中。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 21:12; 启示录 7:4–8; 列王纪上 18:31"> 这些宝石都要按着以色列儿子们的名字，十二块都按着他们的名字，像雕刻印章那样，按着各自的名字，代表十二个支派。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> “你要在胸牌上用编绳子的工艺做纯金的链子；</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 25:11–15"> 你要在胸牌上做两个金环，把两个环接在胸牌上边<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="上边——辅助词语。">c</a></sup>的两端；</span>
<span className="v" id="v24" data-v="24"> 你要把两条金链子接在胸牌上边<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="上边——辅助词语。">d</a></sup>两端的两个环中，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 39:15; 出埃及记 39:4; 出埃及记 28:14"> 把两条链子的另两端接在两个槽上，连在以弗得前面的肩带上。</span>
<span className="v" id="v26" data-v="26"> 你要再做两个金环，把它们安在胸牌下边<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="下边——辅助词语。">e</a></sup>的两端，在以弗得内侧的边上；</span>
<span className="v" id="v27" data-v="27"> 又做两个金环，把它们接在以弗得前面的两条肩带下面，靠近接缝处，在以弗得的精巧织带上方。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 15:38; 出埃及记 28:31; 出埃及记 39:30–31"> 你要用蓝色的细绳把胸牌的环与以弗得的环连接，使胸牌贴在以弗得的精巧织带上，使胸牌不致从以弗得上松脱。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="出埃及记 28:12; 出埃及记 28:30; 耶利米书 30:21"> “亚伦进入圣所的时候，要把决断胸牌上以色列儿子们的名字挂在他的胸前，在耶和华面前常作记念。</span>
<span className="v" id="v30" data-v="30" data-xref="尼希米记 7:65; 以斯拉记 2:63; 民数记 27:21"> 你要把乌陵和土明放在决断胸牌里；于是亚伦进到耶和华面前的时候，乌陵和土明就会在他的胸前。这样，亚伦在耶和华面前就常在心中背负着决断以色列子孙的责任。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="利未记 8:7; 出埃及记 28:4; 出埃及记 39:22–26"> “你要做以弗得的外袍，整件都是蓝色的。</span>
<span className="v" id="v32" data-v="32" data-xref="尼希米记 4:16; 约翰福音 19:23–24; 出埃及记 39:28"> 外袍头部的中间之处，要有一个领口，领口要有围边，用纺织的工艺做成，像战袍的领口那样，免得撕裂。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 39:24–26; 撒迦利亚书 14:20; 列王纪上 7:18"> 外袍下摆的围边上，要用蓝色、紫色、朱红色线做石榴，石榴之间要有金铃铛，</span>
<span className="v" id="v34" data-v="34" data-xref="雅歌 8:2; 约翰福音 15:4–8; 歌罗西书 1:10"> 一个金铃铛一个石榴，一个金铃铛一个石榴，在外袍下摆的围边上。</span>
<span className="v" id="v35" data-v="35" data-xref="希伯来书 9:12; 利未记 16:2"> 亚伦事奉的时候要把外袍穿上；他进入圣所到耶和华面前以及出来的时候，外袍上的铃声就会被听见，他就不致死亡。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="撒迦利亚书 14:20; 利未记 8:9; 出埃及记 39:30"> “你要用纯金做一面牌子，像雕刻印章那样，在牌子上面雕刻‘归耶和华为圣’。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="出埃及记 29:6; 出埃及记 28:4; 撒迦利亚书 3:5"> “你要用一条蓝色的细绳把金牌系在顶冠上，就在顶冠的前面。</span>
<span className="v" id="v38" data-v="38" data-xref="彼得前书 2:24; 民数记 18:1; 利未记 10:17"> 牌子要在亚伦的额头上，亚伦要承担有关神圣之物的罪责——神圣之物是以色列子孙分别为圣的所有神圣的礼物；牌子要常在亚伦的额头上，好使他们在耶和华面前蒙悦纳。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="诗篇 45:14"> “你要用细麻编织袍子，用细麻布做顶冠，以刺绣的工艺做腰带。</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及记 39:41; 出埃及记 28:4; 出埃及记 28:2"> 你要为亚伦的儿子们做袍子，为他们做腰带，为他们做头巾，以显出荣耀、华美。</span>
<span className="v" id="v41" data-v="41" data-xref="出埃及记 29:7; 利未记 8:1–36; 出埃及记 40:15"> 你要把这些给你的哥哥亚伦和他的儿子们穿上，又膏抹他们，使他们承接圣职、分别为圣，作祭司事奉我。</span>
<span className="v" id="v42" data-v="42" data-xref="以西结书 44:18; 利未记 6:10; 利未记 16:4"> 你要用细麻布为他们做裤子，遮蔽下体，从腰间直到大腿。</span>
<span className="v" id="v43" data-v="43" data-xref="出埃及记 27:21; 出埃及记 20:26; 利未记 5:17"> 亚伦和他的儿子们进入会幕，或接近祭坛，在圣所事奉的时候，要把裤子穿上，使他们不致承担罪责而死。这要成为亚伦和他的后裔永远的律例。</span>
</div>
</div>

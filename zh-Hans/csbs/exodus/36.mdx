<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 28:3; 出埃及记 35:30–35; 出埃及记 31:1–6"> 比撒列和亚何利亚伯，以及一切有才能<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有才能——原文直译“心里有智慧”；本章下同。">a</a></sup>的人，就是蒙耶和华赐智慧和聪慧在他们里面、知道怎样做圣所一切建造工作的人，都要照着耶和华所吩咐的一切去做。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 4:17; 希伯来书 5:4; 出埃及记 31:6"> 摩西就召比撒列和亚何利亚伯，一切有才能的人，就是蒙耶和华赐智慧在他们心里的人，以及所有心里受激励的人，近前来做这工作。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 35:29; 出埃及记 35:27; 出埃及记 35:5–21"> 他们在摩西面前接受了以色列子孙为圣所的建造工作而带来的一切供物。每天早晨，以色列子孙不断地把甘心奉献物带来给摩西。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 3:10; 路加福音 12:42; 马太福音 24:45"> 那些做圣所一切工作的巧匠<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="巧匠——原文直译“智慧人”。">b</a></sup>，各人放下自己在做的工作，</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 31:6–10; 哥林多后书 8:2–3; 历代志下 24:14"> 来告诉摩西说：“百姓带来的太多，已经超过了耶和华指示要做的建造工作所需要的。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 于是摩西吩咐在营中传令说：“无论男女都不必再为圣所奉献任何供物。”这样，百姓才被阻止，不再带来供物；</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 31:10"> 因为材料已经足够做一切的工作，而且有余。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪上 6:23; 出埃及记 26:1–37; 以西结书 1:5–28"> 这些工作的人中，一切有才能的，用十幅幔帐造了帐幕；比撒列用捻成的细麻线和蓝色、紫色、朱红色线编织幔帐，以精巧的工艺绣上了基路伯。</span>
<span className="v" id="v9" data-v="9"> 每幅幔帐长二十八肘<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="二十八肘——相当于12.8公尺。1肘=45.7公分。">c</a></sup>，每幅幔帐宽四肘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="四肘——相当于1.8公尺。">d</a></sup>，所有幔帐的尺寸都一样。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 12:27; 出埃及记 26:3; 诗篇 122:3"> 五幅幔帐彼此相连，另五幅幔帐也彼此相连。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 26:4"> 在一组幔帐的最后一幅边上，用蓝色线做扣环；另一组幔帐的最后一幅边上，也照样做。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 26:5; 出埃及记 26:10"> 在一组幔帐的边上，做五十个扣环；在另一组幔帐的边上，也做五十个扣环，扣环彼此相对。</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前书 2:4–5; 以弗所书 2:20–22; 哥林多前书 12:20"> 他做了五十个金钩，用这些钩子把两组幔帐彼此相连，好使帐幕成为一个整体。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及记 26:7–13"> 他用山羊毛做幔帐，作为帐幕上的罩篷，做了十一幅幔帐。</span>
<span className="v" id="v15" data-v="15"> 每幅幔帐长三十肘<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="三十肘——相当于13.7公尺。1肘=45.7公分。">e</a></sup>，每幅幔帐宽四肘<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="四肘——相当于1.8公尺。">f</a></sup>，十一幅幔帐的尺寸都一样。</span>
<span className="v" id="v16" data-v="16"> 他把五幅幔帐连成一组，把另外的六幅幔帐也连成一组。</span>
<span className="v" id="v17" data-v="17"> 在一组幔帐的最后一幅边上，做五十个扣环；在另一组幔帐的边上，也做五十个扣环。</span>
<span className="v" id="v18" data-v="18"> 他做了五十个铜钩，把罩篷连起来，好使它成为一个整体。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 26:14"> 他用染红的公绵羊皮为罩篷做一个顶罩，其上再用海狮皮做了一个顶罩。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 25:5; 民数记 25:1; 出埃及记 40:18–19"> 他用金合欢木为帐幕做了竖板。</span>
<span className="v" id="v21" data-v="21"> 每块木板长十肘<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="十肘——相当于4.6公尺。1肘=45.7公分。">g</a></sup>，每块木板宽一肘半<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="一肘半——相当于0.7公尺。">h</a></sup>。</span>
<span className="v" id="v22" data-v="22"> 每块木板有两个榫头，彼此并列<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="彼此并列——或译作“使木板彼此连接”。">i</a></sup>；帐幕所有的木板都这样做。</span>
<span className="v" id="v23" data-v="23"> 他为帐幕做了木板，为南边做了二十块木板；</span>
<span className="v" id="v24" data-v="24"> 在这二十块木板底下，做了四十个银底座；一块木板底下有两个底座连接它的两个榫头，下一块木板底下也有两个底座连接它的两个榫头。</span>
<span className="v" id="v25" data-v="25"> 他为帐幕的另一边，就是北边，做了二十块木板，</span>
<span className="v" id="v26" data-v="26"> 以及四十个银底座；一块木板底下有两个底座，下一块木板底下也有两个底座。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 26:22; 出埃及记 26:27"> 他也为帐幕的后部，就是西面，做了六块木板；</span>
<span className="v" id="v28" data-v="28"> 并在帐幕后部的两个边角做两块木板，</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 4:32; 以弗所书 3:18–19; 哥林多前书 1:10"> 两个边角是双层，双层木板从下端到顶端完全对齐，顶端用一个环扣住；两块木板都是这样，形成两个凸角。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 26:25"> 这样共有八块木板和十六个银底座；每块木板底下都有两个底座。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及记 26:26–29; 出埃及记 25:28; 出埃及记 30:5"> 他用金合欢木做横闩，为帐幕一边的木板做了五根，</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 26:26"> 为帐幕另一边的木板做了五根横闩，又为帐幕后边，就是西面的木板，也做了五根横闩。</span>
<span className="v" id="v33" data-v="33"> 他使中间那根横闩，在木板中部，从一端穿到另一端。</span>
<span className="v" id="v34" data-v="34"> 他把木板包上了金，又用金子做了其上的环，用来穿横闩；也把横闩包上了金。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 27:51; 希伯来书 10:20; 出埃及记 40:21"> 他用蓝色、紫色、朱红色线和捻成的细麻线编织幔子，以精巧的工艺绣上了基路伯。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 1:18"> 他用金合欢木为幔子做了四根柱子，把它们包上了金；柱子上有金钩；他又为柱子铸了四个银底座。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="出埃及记 26:36–37; 出埃及记 40:28"> 他用蓝色、紫色、朱红色线和捻成的细麻线，以刺绣的工艺，为帐篷的入口编织了帘幕。</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及记 27:10"> 他为帘幕做了五根柱子和柱子上的钩子，把柱顶和柱子上的箍环包上了金；柱子有五个铜底座。</span>
</div>
</div>

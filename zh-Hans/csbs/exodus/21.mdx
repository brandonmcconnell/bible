<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 4:14; 申命记 6:20; 出埃及记 24:3–4"> “以下是你要在百姓面前立的法规：</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="申命记 15:12–15; 出埃及记 12:44; 申命记 15:18"> “如果你买了一个希伯来奴仆，他要服事你六年，第七年他可以作为自由人无偿离去。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 15:12–14"> 如果他单身来，就可以单身离去；如果他是有妇之夫，他的妻子也可以与他一同离去。</span>
<span className="v" id="v4" data-v="4"> 如果他的主人给了他妻子，妻子又为他生了儿子或女儿，妻子和孩子就要归主人，而他要单身离去。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 5:14–15; 申命记 15:16–17; 以赛亚书 26:13"> “如果那奴仆明确地说‘我爱我的主人、我的妻子儿女，我不愿意自由离去’，</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 15:17; 利未记 25:40; 申命记 19:17–18"> 他的主人就要把他带到神<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="神——或译作“审判官”。">a</a></sup>面前，然后带他到门前或门框那里；他的主人要用锥子为他穿耳洞，他就要永远服事主人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="尼希米记 5:5; 出埃及记 21:2–3"> “如果有人把自己的女儿卖为女仆，女仆不可像男仆那样离去。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 28:8; 申命记 20:7; 玛拉基书 2:11–15"> 如果她的主人选定她归自己，后来却不喜欢她，就要让她赎身；主人既然对她失信，就没有权力把她卖给外邦人。</span>
<span className="v" id="v9" data-v="9"> 如果主人选定她归自己的儿子，就要照着待女儿的惯例对待她。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 7:1–6"> 如果主人为自己另娶一个女人，不可减少原先那女人的食物、衣服和房事。</span>
<span className="v" id="v11" data-v="11"> 如果主人不为她做这三件事，她就可以无偿离去，不用付赎金<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="赎金——原文直译“银子”。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 9:6; 马太福音 26:52; 利未记 24:17"> “打人致死的，必须被处死；</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 20:2–9; 撒母耳记上 24:18; 申命记 4:41–43"> 但如果不是预谋杀人，而是神使那人落在他的手中，我就会给你指定一个地方，让他可以逃到那里。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 2:28–34; 希伯来书 10:26; 民数记 15:30–31"> 如果有人蓄意针对他的邻人，用诡计杀死他，你即使从我的祭坛那里，也要把他抓去处死。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命记 21:18–21; 箴言 30:17; 提摩太前书 1:9"> “打父母的，必须被处死。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命记 24:7; 提摩太前书 1:10; 出埃及记 22:4"> “拐带人口的，无论是把人卖了，或是把人留在手中，都必须被处死。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="箴言 20:20; 马可福音 7:10–11; 申命记 27:16"> “诅咒父母的，必须被处死。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 21:20; 申命记 25:11; 撒母耳记下 14:6"> “如果人彼此相争，一个用石头或拳头打另一个，被打的没有死，而是躺在床上，</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 3:29; 撒迦利亚书 8:4"> 后来他如果能起来用拐杖出外行走，那打他的就免于罪罚，但要赔偿他误工的损失，并负责他彻底痊愈。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="箴言 29:19; 申命记 19:21; 民数记 35:19"> “如果有人用棍打他的男仆或女仆，以致奴仆当场<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="当场——辅助词语。">c</a></sup>死在他的手下，他就必定受报应；</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 25:44–46"> 但如果奴仆还挺了一两天，那人就不会受报应，因为奴仆是他的财产<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="财产——原文直译“银子”。">d</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命记 22:18–19; 出埃及记 21:30; 申命记 16:18"> “如果人彼此打架，伤到孕妇，以致她早产，但没有其他损伤，那伤她的就必须照着那妇人的丈夫所要求的受惩罚，按审判官所判的来赔偿；</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 19:21; 民数记 35:31; 利未记 24:19"> 但如果有其他损伤，就要以命偿命，</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 19:21; 马太福音 5:38–40; 马太福音 7:2"> 以眼还眼，以牙还牙，以手还手，以脚还脚，</span>
<span className="v" id="v25" data-v="25"> 以灼还灼，以伤还伤，以打还打。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 21:20; 约伯记 31:13–15; 诗篇 72:12–14"> “如果有人打他男仆的眼睛或女仆的眼睛，以致毁了一只眼睛，就要因眼睛的缘故让奴仆走，作自由人。</span>
<span className="v" id="v27" data-v="27"> 如果有人打掉他男仆的牙齿或女仆的牙齿，就要因牙齿的缘故让奴仆走，作自由人。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="出埃及记 21:32; 利未记 20:15–16; 创世记 9:5–6"> “如果有牛顶男人或女人，以致人死了，那牛就必须用石头砸死，它的肉也不可以吃，不过牛的主人可以算为无罪；</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 21:1–9"> 但如果那牛向来顶人，它的主人也被告诫过，却没有把牛看好，以致牛把男人或女人顶死了，那牛就要用石头砸死，它的主人也要被处死。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 21:22; 出埃及记 30:12; 民数记 35:31–33"> 如果他被要求了赎价，他就要照着所要求的来付上他性命的赎价。</span>
<span className="v" id="v31" data-v="31"> 牛无论顶了男孩<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="男孩——原文直译“儿子”。">e</a></sup>或顶了女孩<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="女孩——原文直译“女儿”。">f</a></sup>，都要照着这条规定处置它的主人。</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 26:15; 撒迦利亚书 11:12–13; 马太福音 27:3–9"> 如果牛顶了男仆或女仆，它的主人就要给奴仆的主人三十谢克尔<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="三十谢克尔——相当于342公克。1谢克尔=11.4公克。">g</a></sup>银子，而那牛要用石头砸死。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="箴言 28:10; 耶利米书 18:20; 传道书 10:8"> “如果有人敞开坑口，或是挖了坑却没有遮盖坑口，以致有牛或驴掉进里面，</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 22:6; 出埃及记 21:29–30; 出埃及记 22:14"> 那坑的主人就要赔偿，付银子给牲畜的主人，而死牲畜就归自己。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35"> “如果有人的牛伤了他邻人的牛，以致邻人的牛死了，就要把活牛卖了，平分银子，也要平分死牛；</span>
<span className="v" id="v36" data-v="36"> 但如果早已知道那牛向来顶人，它的主人却没有把牛看好，它的主人就必须以牛赔牛，而死牛就归自己。</span>
</div>
</div>

</div>

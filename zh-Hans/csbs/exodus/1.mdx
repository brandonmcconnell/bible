<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="历代志上 2:1–2; 创世记 46:8–26; 创世记 35:23–26"> 以色列的儿子们——各带家属与雅各一同来到埃及——他们的名字如下：</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 35:22"> <span className="pl pl-1">鲁本、西缅、利未、犹大、</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 28:20; 创世记 35:23"> <span className="pl pl-1">以萨迦、西布伦、便雅悯、</span><br /></span>
<span className="v" id="v4" data-v="4"> <span className="pl pl-1">但、拿弗他利、迦得、亚设。</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="申命记 10:22; 创世记 46:26–27; 士师记 8:30"> 雅各所有的直系子孙，共有七十人。那时约瑟已经在埃及了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 50:26; 创世记 50:24; 使徒行传 7:14–16"> 后来约瑟和他所有的兄弟，以及那一代所有的人都死了。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 46:3; 创世记 1:28; 申命记 26:5"> 以色列子孙生养、繁衍、增多，极其强盛，充满了那地。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 7:18; 传道书 2:18–19; 传道书 9:15"> 再后来有一位不知道约瑟的新王兴起，统治埃及。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 105:24–25; 传道书 4:4; 雅各书 3:14–16"> 他对自己的子民说：“看哪！以色列民比我们更多、更强大。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 7:19; 诗篇 83:3–4; 箴言 1:11"> 来吧！让我们精明地对付他们，免得他们增多，一旦战争发生，他们就会与我们的仇敌联合，攻打我们，然后离开这地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="离开这地——原文直译“从这地上去”。">a</a></sup>。”</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 15:13; 创世记 47:11; 出埃及记 3:7"> 于是埃及人指派督工来管理以色列子孙，用苦役来苦待他们。他们为法老建造了两座积货城：比东和拉美西斯。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 105:24; 出埃及记 1:9; 罗马书 8:28"> 然而，埃及人越是苦待他们，他们越是增多，越是扩散。埃及人就因以色列子孙的缘故而忧心。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 4:20"> 于是埃及人更严酷地奴役以色列子孙。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 7:19; 民数记 20:15; 出埃及记 2:23"> 埃及人用沉重的劳役——和泥、做砖，以及田野中的各样劳役——严酷地奴役他们的一切劳役，使他们的生活很苦。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 当时埃及王吩咐两个希伯来接生婆，一个名叫施弗拉，另一个名叫普阿；</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 1:22; 马太福音 21:38; 启示录 12:4"> 他说：“你们为希伯来妇女接生，看她们临盆<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="临盆——原文直译“在产床上”。">b</a></sup>的时候，如果所生的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="所生的——辅助词语。">c</a></sup>是个男婴<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="男婴——原文直译“儿子”。">d</a></sup>，就把他杀死；如果是个女婴<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="女婴——原文直译“女儿”。">e</a></sup>，就让她存活。”</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 5:29; 出埃及记 1:21; 马太福音 10:28"> 然而，接生婆敬畏神，没有照着埃及王吩咐她们的去做，却让男孩也存活。</span>
<span className="v" id="v18" data-v="18" data-xref="传道书 8:4; 撒母耳记下 13:28"> 埃及王就把接生婆叫来，问她们：“你们为什么做这样的事，让男孩也存活呢？”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约书亚记 2:4–24; 撒母耳记下 17:19–20; 撒母耳记上 21:2"> 接生婆回答法老：“因为希伯来妇女不像埃及妇女，希伯来妇女很健壮，接生婆还没有到她们那里之前，她们就已经生产了。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 3:10; 传道书 8:12; 箴言 11:18"> 神善待接生婆，以色列百姓就增多，而且极其强盛。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 11:38; 撒母耳记上 2:35; 诗篇 37:3"> 接生婆因为敬畏神，神就为她们建立了家庭。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 7:19; 箴言 1:16; 出埃及记 1:16"> 法老吩咐他所有的子民说：“希伯来人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="希伯来人——辅助词语。">f</a></sup>所生的每一个男婴<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="男婴——原文直译“儿子”。">g</a></sup>，你们都要把他扔进尼罗河里；而每一个女婴<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="女婴——原文直译“女儿”。">h</a></sup>，你们可以让她存活。”</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 4:15–16; 诗篇 82:6; 约翰福音 10:35–36"> 耶和华对摩西说：“你看，我使你在法老面前像神一样，而你哥哥亚伦是你的先知。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 4:15; 出埃及记 6:29; 申命记 4:2"> 我所吩咐你的一切，你都要说；然后你哥哥亚伦要对法老说，让以色列子孙走，离开法老的地。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 4:21; 出埃及记 11:9; 诗篇 105:27–36"> 然而，我要使法老硬着心，也要在埃及地使我的神迹和奇事增多。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 11:9; 出埃及记 6:6; 出埃及记 12:51"> 法老不会听从你们；我要向埃及下手，用极大的审判把我的大军——我的子民以色列子孙，从埃及地领出来。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 14:18; 出埃及记 7:17; 出埃及记 8:22"> 当我伸出手攻击埃及，把以色列子孙从埃及人中间领出来的时候，埃及人就知道我是耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 7:2; 创世记 6:22; 出埃及记 7:10"> 摩西和亚伦就这样做了；耶和华所指示他们的，他们都照着做了。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 34:7; 使徒行传 7:30; 申命记 31:2"> 他们对法老说话的时候，摩西八十岁，亚伦八十三岁。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 耶和华对摩西和亚伦说：</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 4:2; 约翰福音 2:18; 以赛亚书 7:11"> “当法老吩咐你们说‘你们行一件奇事吧’，你就对亚伦说：‘拿你的杖，扔在法老面前，杖就会变成一条大蛇。’”</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 4:3; 路加福音 10:19; 阿摩司书 9:3"> 摩西和亚伦就到法老那里去，照着耶和华所指示的做了。亚伦把他的杖扔在法老和他的臣仆面前，杖就变成了一条大蛇。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 7:22; 提摩太后书 3:8; 出埃及记 8:18"> 于是法老召来智慧人和行巫术的。这些埃及的术士们也用他们的邪术照样做。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰一书 4:4; 出埃及记 9:11; 出埃及记 8:18–19"> 他们各人扔下自己的杖，他们的杖也都变成了大蛇；但亚伦的杖吞掉了他们的杖。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 4:21; 出埃及记 8:15; 撒迦利亚书 7:11–12"> 然而，法老的心刚硬，不听从摩西和亚伦，正如耶和华所说的。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及记 10:20; 出埃及记 8:15; 出埃及记 10:1"> 耶和华对摩西说：“法老心里顽固，拒绝让我的子民走。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 8:20; 出埃及记 2:5; 出埃及记 7:10"> 明天早晨你要到法老那里去。看哪，他会出来到水边，你就站在尼罗河岸迎候他。你手中要拿着那根曾变成蛇的杖。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 3:18; 出埃及记 9:1; 出埃及记 9:13"> 你要对他说：‘希伯来人的神耶和华派遣我到你这里说：让我的子民走，好使他们在旷野中服事我。看哪，直到现在你都不听！</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 4:9; 出埃及记 5:2; 出埃及记 7:5"> 耶和华如此说：看哪，我要用我手中的杖击打尼罗河里的水，水就会变成血，这样你就知道我是耶和华。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 7:24; 出埃及记 7:21; 民数记 11:20"> 尼罗河里的鱼都会死，尼罗河也会发臭，埃及人就不能<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="不能——原文直译“厌恶”。">a</a></sup>喝尼罗河里的水了。’”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及记 14:21; 出埃及记 10:12; 出埃及记 8:5–6"> 耶和华对摩西说：“你要对亚伦说：‘拿你的杖，伸出你的手在埃及众水之上，就是在他们的河流、运河、池塘以及所有的蓄水池之上，水就会变成血；在埃及全地都会有血，甚至在木器、石器里。’”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="诗篇 78:44; 诗篇 105:29; 出埃及记 7:17–18"> 摩西和亚伦就照着耶和华所指示的做了。亚伦在法老眼前和他的臣仆眼前举起杖，击打尼罗河里的水，尼罗河里的水就全都变成了血。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 7:18; 启示录 8:9"> 尼罗河里的鱼都死了，尼罗河也发臭了，埃及人就不能喝尼罗河里的水。在埃及全地都是血。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及记 7:11; 提摩太后书 3:8; 耶利米书 27:18"> 埃及的术士们也用他们的邪术照样做。于是法老的心就刚硬，不听从摩西和亚伦，正如耶和华所说的。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 36:24; 以西结书 40:4; 玛拉基书 2:2"> 法老转身回到他的宫殿里，竟没有把这事放在心上。</span>
<span className="v" id="v24" data-v="24"> 所有的埃及人在尼罗河周围挖地找水喝，因为他们不能喝尼罗河里的水。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 10:23; 出埃及记 8:9–10; 撒母耳记下 24:13"> 耶和华打击尼罗河之后，满了七天。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华指示摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 2:23; 民数记 3:13; 申命记 15:19"> “在以色列子孙中所有头生的，就是所有的头胎，无论是人还是牲畜，都要分别为圣归我；他们是属于我的。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命记 24:18; 申命记 5:15; 出埃及记 20:2"> 摩西对以色列百姓说：“你们要记念从埃及、从为奴之家出来的这一天，因为耶和华用大能的手把你们从这里领了出来。你们不可吃有酵之物。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 34:18; 出埃及记 23:15; 出埃及记 12:2"> 你们是在亚笔月的这一天出来的。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 3:8; 约书亚记 24:11; 出埃及记 12:25–26"> 日后，耶和华领你进入迦南人、赫提人、亚摩利人、希未人、耶布斯人之地，就是他向你的先祖起誓要赐给你的那流奶与蜜之地，那时你也要在这个月守这服事之礼。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 12:15–20; 出埃及记 34:18; 利未记 23:8"> 你要吃无酵饼七天；第七天是耶和华的节期。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 12:19; 马太福音 16:6"> 在这七天，你要吃无酵饼；在你那里不可看到有酵之物，在你的全境也不可看到酵。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 13:14; 出埃及记 12:26–27; 诗篇 44:1"> 到那日，你要告诉你的儿子说：‘这是因为耶和华在我出埃及的时候为我所做的事。’</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 6:8; 申命记 11:18–19; 民数记 15:39"> 这要在你手上作为标记，在你额上<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="额上——原文直译“双眼之间”。">a</a></sup>作为记念，使耶和华的律法在你的口中，因为耶和华用大能的手把你从埃及领了出来。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 12:14; 出埃及记 12:24–25; 出埃及记 23:15"> 因此，你每年都要在所定的日期遵守这律例。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出埃及记 13:5"> “日后，耶和华照着他向你和你的先祖所起的誓，领你进入迦南人之地，把这地赐给你的时候，</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 18:15; 利未记 27:26; 出埃及记 34:19"> 你也要把所有的头胎都献给耶和华。你拥有的牲畜中所有头生的，凡是公的都属于耶和华。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 34:20; 民数记 18:15–17; 启示录 14:4"> 所有头生的驴子，你要用羔羊赎回；如果不赎回，就要打断它的脖子。你儿子们中所有头生的人，你都要赎回。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及记 13:3; 约书亚记 4:6; 诗篇 145:4"> “日后，你的儿子问你说‘这是什么意思呢？’你就要对他说‘耶和华用大能的手把我们从埃及、从为奴之家领了出来。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 12:29"> 那时法老强硬地不让我们走，耶和华就把埃及地所有头生的，无论是头生的人还是头生的牲畜，都杀死了。因此我把牲畜中所有头胎的，凡是公的都祭献给耶和华；而我所有头生的儿子，我都要赎回。’</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 13:9; 申命记 11:18; 申命记 6:7–9"> 这要在你手上作为标记，在你额上<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="额上——原文直译“双眼之间”。">b</a></sup>作为标志，因为耶和华用大能的手把我们从埃及领了出来。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及记 14:11–12; 尼希米记 9:17; 民数记 14:1–4"> 法老让以色列百姓走的时候，神没有引导他们走非利士人之地的路，尽管那条路近，因为神说：“恐怕子民看到战争而改变心意，就回埃及去。”</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 14:2; 申命记 32:10; 民数记 33:6–8"> 于是神使百姓绕道走旷野的路往红海去，以色列子孙就整装列队上去，离开埃及地。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="创世记 50:24–25; 约书亚记 24:32; 使徒行传 7:16"> 摩西把约瑟的骸骨一起带上，因为约瑟曾经让以色列子孙郑重地起誓，对他们说：“神必定眷顾你们，而你们要把我的骸骨从这里一起带上去。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数记 33:5–6; 出埃及记 12:37"> 他们从疏割起行，在旷野边上的伊坦扎营。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 10:1–2; 尼希米记 9:12; 申命记 1:33"> 耶和华在他们前面行走，白天用云柱引导他们的路，夜间用火柱照亮他们，使他们昼夜都可以行走。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 121:5–8; 启示录 10:1"> 白天云柱，夜间火柱，总不离开以色列百姓面前。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 12:7; 出埃及记 32:13; 出埃及记 32:7"> 耶和华对摩西说：“去，你和你从埃及地带上来的百姓要从这里上去，进入我起誓要给亚伯拉罕、以撒、雅各的那地——我曾对他们说：‘我必把这地赐给你的后裔’。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 32:34; 约书亚记 24:11; 出埃及记 23:27–31"> 我必派遣使者在你前面，我必驱逐迦南人、亚摩利人、赫提人、比利洗人、希未人、耶布斯人。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 32:9–10; 出埃及记 3:8; 使徒行传 7:51"> 你们要上到那流奶与蜜之地。我不在你们中间同你们一起上去，因为你们是硬着颈项的子民，免得我在路上灭绝你们。”</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 14:39; 民数记 14:1; 以西结书 26:16"> 百姓听见这个坏消息就悲恸，没有人佩戴装饰。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民数记 16:21; 民数记 16:45–46; 出埃及记 33:3–4"> 耶和华对摩西说：“你要对以色列子孙说：‘你们是硬着颈项的子民，如果我在你们中间同你们一起上去，哪怕只是一瞬间也会灭绝你们。现在，你们要从你们身上取下装饰，我好知道要怎么处置你们。’”</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 33:4; 出埃及记 32:3; 耶利米书 2:19"> 于是，从何烈山起，以色列子孙就摘掉了他们的装饰。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 55:6–7; 出埃及记 29:42–43; 箴言 15:29"> 摩西一向拿帐篷支搭在营地外面，离营地有一段距离；摩西称呼它为“会幕”。所有寻求耶和华的，就到营地外面的会幕去。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 16:27"> 每当摩西出去到那帐篷的时候，全体民众就都起来，各人站在自己帐篷的入口，望着摩西，直到他进入那帐篷。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 99:7; 出埃及记 31:18; 出埃及记 13:21–22"> 每当摩西进入那帐篷的时候，云柱就降下来，停留在那帐篷的入口，耶和华就与摩西说话。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 8:22; 列王纪上 8:14; 出埃及记 4:31"> 全体民众看见云柱停留在帐篷入口的时候，就都起来，各人在自己帐篷的入口下拜。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 12:8; 申命记 34:10; 出埃及记 24:13"> 耶和华与摩西面对面说话，就像人与朋友说话。摩西回到营地的时候，他的助手<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="助手——或译作“侍从”。">a</a></sup>，年轻人嫩的儿子约书亚却不离开那帐篷。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及记 33:17; 耶利米书 1:5; 约翰福音 10:14–15"> 摩西对耶和华说：“看，你对我说‘把这百姓带上来’，却没有让我知道你要派遣谁与我同去。你曾说：‘我按你的名认识你，你也在我眼前蒙了恩。’</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 119:33; 诗篇 25:4; 诗篇 27:11"> 现在，如果我在你眼前蒙恩，求你使我明白你的道路，使我认识你，好让我在你眼前蒙恩。看，这民是你的子民！”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="约书亚记 21:44; 马太福音 11:28; 约书亚记 1:5"> 耶和华说：“我必亲自与你同去，我必使你得安息。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及记 34:9; 诗篇 4:6; 出埃及记 33:3"> 摩西对耶和华说：“如果你不亲自与我们同去，就不要把我们从这里带上去。</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 4:7; 民数记 14:14; 列王纪上 8:53"> 人怎么能知道我和你的子民在你眼前蒙恩呢？难道不是因为你与我们同去，才使我和你的子民从地面上的万民中分别出来吗？”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 65:24; 约翰一书 5:14–15; 出埃及记 33:12"> 耶和华对摩西说：“你所求的这事我必做，因为你在我眼前蒙恩，并且我按你的名认识你。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="启示录 21:23; 出埃及记 33:20; 提多书 2:13"> 摩西说：“求你向我显出你的荣耀。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="罗马书 9:15–18; 以弗所书 1:6–8; 耶利米书 31:14"> 耶和华说：“我要使我一切的美善在你面前经过，我要在你面前宣告耶和华的名。我要恩待谁就恩待谁，我要怜悯谁就怜悯谁。”</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 32:30; 约翰福音 1:18; 提摩太前书 6:16"> 他又说：“你不能看见我的脸，因为没有人看见我还能存活。”</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 5:31; 撒迦利亚书 3:7; 约书亚记 20:4"> 耶和华说：“看哪，我这里有个地方，你要站在磐石上！</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 91:1; 以赛亚书 2:21; 诗篇 91:4"> 我的荣耀经过的时候，我要把你放在磐石缝中，用我的手掌遮蔽你，直到我过去。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 33:20; 约翰福音 1:18; 提摩太前书 6:16"> 然后我会移开我的手掌，你就会看见我的背，却不会看见我的脸。”</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华在埃及地对摩西和亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 13:4; 申命记 16:1; 出埃及记 34:18"> “本月要作为你们的正月，作为你们一年的第一个月。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 1:2; 哥林多前书 5:7; 约翰福音 1:29"> 你们要吩咐全体以色列会众说：本月十日，他们各人要按着父家为自己取羔羊，一家一只羔羊。</span>
<span className="v" id="v4" data-v="4"> 如果一家的人太少，吃不了一只羔羊，那么就要与最靠近的邻居按人数共取一只；你们要按各人的食量估算羔羊的量。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前书 1:18–19; 希伯来书 9:13–14; 玛拉基书 1:14"> 羔羊必须是无瑕疵的一岁公羊，可以从绵羊或山羊里取。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 23:5; 历代志下 30:15–18; 民数记 28:16"> 你们要把羔羊保留到本月十四日；当天黄昏的时候，以色列全体会众要宰杀羔羊。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 11:28; 出埃及记 12:22–23; 希伯来书 9:22"> 他们要取一些血，涂在他们吃羔羊的房屋的两边门框上和门楣上。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 34:25; 申命记 16:7; 出埃及记 13:3"> 那天夜里，他们要吃用火烤的羔羊肉，与无酵饼和苦菜一起吃。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 12:8; 申命记 16:7; 耶利米哀歌 1:13"> 你们不可吃任何生的或用水煮的羔羊肉，只可吃用火烤的，连头带腿，与内脏一起烤；</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 23:18; 出埃及记 34:25; 出埃及记 29:34"> 你们一点也不可留到早晨，任何留到早晨的，都要用火烧掉。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 12:27; 以弗所书 6:15; 哥林多前书 5:7"> 你们要这样吃羔羊的肉：腰间束带，脚上穿鞋，手中拿杖，并要快快地吃。这是耶和华的逾越节。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数记 33:4; 出埃及记 12:23; 诗篇 82:6"> “那天夜里，我要遍行埃及地，击杀埃及地所有头生的，无论是人还是牲畜；我还要对埃及的一切神明施行审判。我是耶和华。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 11:28; 出埃及记 12:23; 约翰一书 1:7"> 这血在你们所住的房屋上，要作为你们的标记。我看见这血，就会越过你们；我打击埃及地的时候，毁灭的灾殃就不会临到你们。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王纪下 23:21; 出埃及记 12:24; 出埃及记 13:9–10"> “这一天要成为你们的记念，你们要守这日为耶和华的节期；你们世世代代要守这节期，作为永远的律例。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 17:14; 申命记 16:3; 出埃及记 23:15"> 你们要吃无酵饼七天；第一天就要把酵从你们的家里除掉，因为从第一天到第七天，凡吃了有酵之物的，那人就要从以色列中被剪除。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 23:7–8; 民数记 28:18; 出埃及记 16:23"> 第一天你们要有神圣的聚会，第七天你们也要有神圣的聚会；在这两天，任何工作都不可做，只能预备各人吃的东西，这是你们唯一可做的。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及记 7:5; 出埃及记 13:3; 出埃及记 12:41"> “你们要守无酵节，因为就在这一天，我把你们的大军从埃及地领出来，所以你们世世代代要守这一日，作为永远的律例。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 23:5–8; 出埃及记 12:15; 出埃及记 12:1–2"> 从一月十四日傍晚到二十一日傍晚，你们要吃无酵饼。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 12:15; 出埃及记 23:15; 申命记 16:3"> 在这七天，你们的家里不可有酵，因为凡吃了有酵之物的，无论是外人还是本族人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="本族人——原文直译“本地人”；本章下同。">a</a></sup>，那人就要从以色列的会众当中被剪除。</span>
<span className="v" id="v20" data-v="20"> 一切有酵之物，你们都不可吃；在你们居住的任何地方，你们都要吃无酵饼。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及记 12:3; 路加福音 22:7–13; 历代志下 35:5–6"> 于是摩西召来以色列所有的长老，对他们说：“你们要按着你们的家族，为自己挑选并取来一只羔羊，宰杀这逾越节的羔羊。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 11:28; 民数记 19:18; 诗篇 51:7"> 你们要拿一把牛膝草，蘸在盆中的血里，把盆中的血涂在门楣上和两边的门框上。你们谁都不可出自己的家门，直到早晨，</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 7:3; 启示录 9:4; 希伯来书 11:28"> 因为耶和华要遍行这地，击杀埃及人；耶和华看见门楣上和两边门框上的血，就会越过那门，不允许那毁灭者进入你们的房屋击杀你们。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出埃及记 12:14; 创世记 17:8–10"> “你们要遵守这吩咐，作为你和你子孙的定例，直到永远。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 3:17; 出埃及记 3:8; 申命记 12:8–9"> 日后，你们进入耶和华应许赐给你们的那地，也要守这服事之礼。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 13:14–15; 申命记 32:7; 诗篇 145:4"> 日后，你们的子孙问你们‘这服事之礼对你们是什么意思呢？’</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 4:31; 出埃及记 12:11; 哥林多前书 5:7"> 你们就要说‘这是献给耶和华的逾越节之祭；他在击杀埃及人的时候，越过了在埃及的以色列子孙的房屋，解救了我们的家。’”于是，以色列百姓俯身下拜。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 11:28"> 以色列子孙就这样去做；耶和华所指示摩西和亚伦的，以色列子孙都照着去做了。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="诗篇 78:51; 出埃及记 4:23; 诗篇 105:36"> 到了半夜，耶和华击杀了埃及地所有头生的——从坐宝座的法老的长子到牢房里的俘虏的长子，以及所有头生的牲畜。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 11:6; 阿摩司书 5:17; 箴言 21:13"> 法老夜间起来，他所有的臣仆和所有的埃及人也都起来了；在埃及有极大的哀声，因为没有一家不死人的。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 6:1; 出埃及记 10:9; 出埃及记 3:19–20"> 于是法老夜间召来摩西和亚伦，说：“起来，你们和以色列子孙都从我的子民中间出去！照着你们所说的，去服事耶和华；</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 10:26; 创世记 27:34; 创世记 27:38"> 也照着你们所说的，带着你们的羊群和牛群走！不过，你们也要为我祝福！”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="诗篇 105:38; 出埃及记 11:1; 创世记 20:3"> 埃及人催促以色列百姓，要他们赶快走，离开那地，因为埃及人说：“我们全都要死了。”</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 8:3"> 于是以色列百姓拿起未放入酵的面团和揉面盆，用他们的衣服包住，扛在肩膀上。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="出埃及记 3:21–22; 出埃及记 11:2–3; 创世记 15:14"> 以色列子孙照着摩西的话去做，向埃及人索要银器、金器和衣服。</span>
<span className="v" id="v36" data-v="36" data-xref="创世记 15:14; 使徒行传 7:10; 出埃及记 3:21–22"> 耶和华使以色列百姓在埃及人眼前蒙恩，埃及人就给了他们索要的；这样他们就剥夺了埃及人。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="民数记 1:46; 出埃及记 38:26; 民数记 33:3"> 以色列子孙从拉美西斯起程往疏割去，除了孩童，步行的男人约有六十万；</span>
<span className="v" id="v38" data-v="38" data-xref="民数记 11:4; 撒迦利亚书 8:23"> 与他们一起上去的，还有众多混杂的族群，以及羊群、牛群等极多的牲畜。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及记 11:1; 出埃及记 6:1; 出埃及记 12:31–33"> 他们把从埃及带出来的未放入酵的面团烤成无酵饼，因为他们被驱逐离开埃及，不能耽延，也没有为自己预备食物。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="创世记 15:13; 使徒行传 7:6; 使徒行传 13:17"> 以色列子孙在埃及居住的时间是四百三十年。</span>
<span className="v" id="v41" data-v="41" data-xref="哈巴谷书 2:3; 约翰福音 7:8; 使徒行传 1:7"> 到了四百三十年结束的时候，就在这一天，耶和华的全军都从埃及地出来了。</span>
<span className="v" id="v42" data-v="42" data-xref="申命记 16:1–6; 出埃及记 12:14; 出埃及记 13:10"> 这一夜是为耶和华所谨守的，因为他把他们从埃及地领出来；这一夜是所有的以色列子孙世世代代都要为耶和华谨守的夜。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="出埃及记 12:48; 民数记 9:14; 出埃及记 12:11"> 耶和华对摩西和亚伦说：“逾越节的律例是这样的：所有外邦人都不可吃逾越节的羔羊；</span>
<span className="v" id="v44" data-v="44" data-xref="创世记 17:12–13; 创世记 17:23"> 至于各人用银子买来的每一个奴仆，在你给他行过割礼之后，他就可以吃。</span>
<span className="v" id="v45" data-v="45" data-xref="利未记 22:10; 以弗所书 2:12"> 客居者和雇工都不可吃。</span>
<span className="v" id="v46" data-v="46" data-xref="民数记 9:12; 约翰福音 19:36; 约翰福音 19:33"> 你们要在同一间屋子里吃，羔羊的肉一点也不可带到屋子外面，羔羊的骨头一根也不可折断。</span>
<span className="v" id="v47" data-v="47" data-xref="出埃及记 12:6; 民数记 9:13; 出埃及记 12:3"> 全体以色列会众都要守这节期。</span>
<span className="v" id="v48" data-v="48" data-xref="民数记 9:14; 歌罗西书 3:11; 加拉太书 3:28"> 如果有外人寄居在你们中间，也愿意向耶和华守逾越节，那么他们中的每一个男子都要在受割礼之后，才可以近前来守节期；他也就像本族人那样了；但所有未受割礼的人都不可吃逾越节的羔羊。</span>
<span className="v" id="v49" data-v="49" data-xref="民数记 15:15–16; 民数记 15:29; 利未记 24:22"> 本族人与寄居在你们中间的外人，都是同一个条例。”</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="马太福音 7:24–25; 出埃及记 6:26; 出埃及记 7:4"> 所有的以色列子孙就这样做了；耶和华所指示摩西和亚伦的，以色列子孙都照着做了。</span>
<span className="v" id="v51" data-v="51" data-xref="出埃及记 12:41; 出埃及记 6:26"> 就在这一天，耶和华把以色列子孙从埃及地一队一队领出来了。</span>
</div>
</div>

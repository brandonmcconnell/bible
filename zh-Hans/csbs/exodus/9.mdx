<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 8:1; 出埃及记 10:3; 出埃及记 8:20"> 耶和华对摩西说：“你到法老那里去，对他说：‘耶和华希伯来人的神如此说：让我的子民走，好使他们服事我。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 8:2; 出埃及记 4:23; 利未记 26:27–28"> 如果你拒绝让他们走，还要强行留住他们，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 7:4; 使徒行传 13:11; 撒母耳记上 6:9"> 看哪，耶和华的手就使极其严重的瘟疫临到你田野中的牲畜，就是马匹、驴子、骆驼、牛群和羊群！</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 8:22; 出埃及记 10:23; 玛拉基书 3:18"> 但是耶和华会把以色列的牲畜和埃及的牲畜分别开来，所有属于以色列子孙的，一只也不会死。’”</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 8:23; 出埃及记 10:4; 耶利米书 28:16–17"> 耶和华定下了时间，说：“明天，耶和华必在这地做这事。”</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 78:48; 出埃及记 9:25; 诗篇 78:50"> 第二天，耶和华就做了这事。埃及的牲畜全都死了，而属于以色列子孙的牲畜一只也没有死。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 7:14; 出埃及记 8:32; 以赛亚书 48:4"> 法老派人去，看哪，属于以色列的牲畜连一只也没有死！然而，法老又硬着心，不让以色列百姓走。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 8:16"> 耶和华对摩西和亚伦说：“你们要双手满满捧着炉灰，摩西在法老眼前向天空扬撒这炉灰。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 16:2; 申命记 28:27; 约伯记 2:7"> 这炉灰将在埃及全地变成微尘，使埃及全地的人和牲畜的身上都生出流脓的疮。”</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 28:27"> 于是他们就拿了炉灰，站在法老面前。摩西把炉灰向天扬撒，人和牲畜的身上就生出了流脓的疮。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 7:11–12; 出埃及记 8:18–19; 启示录 16:2"> 术士们因这疮的缘故在摩西面前站立不住，因为术士们和所有埃及人的身上都生出了疮。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 4:21; 出埃及记 7:13–14; 诗篇 81:11–12"> 然而，耶和华使法老的心刚硬，他就不听从摩西和亚伦，正如耶和华对摩西所说的。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="出埃及记 8:20; 出埃及记 7:15; 出埃及记 9:1"> 耶和华对摩西说：“你要清早起来，站到法老面前，对他说，‘希伯来人的神耶和华如此说：让我的子民走，好使他们服事我。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 8:10; 利未记 26:28; 历代志上 17:20"> 要知道，这一次我要使我所有的灾殃降到你<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="你——原文直译“你的心”。">a</a></sup>、你的臣仆和你的子民身上，为要你知道在全地上没有能与我相比的。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 3:20; 出埃及记 9:3; 出埃及记 9:16"> 如果我现在伸手用瘟疫打击你和你的子民，你早已从地上除灭了。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 9:17; 箴言 16:4; 诗篇 83:17–18"> 实际上，我使你存留是为要向你显明我的大能，好让我的名在全地上被讲述。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 37:29; 以赛亚书 10:15; 以赛亚书 37:23–24"> 你还在对我的子民自高，不让他们走。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 20:6; 诗篇 83:15; 出埃及记 9:22–25"> 看哪，明天大约这个时候，我必降下极其猛烈的冰雹，是自从埃及建国之日直到现在未曾有过的！</span>
<span className="v" id="v19" data-v="19" data-xref="哈巴谷书 3:2"> 现在，你要派人去，把你的牲畜和田野中所有属于你的都带去避难。任何在田野中没有被聚集到房屋里的人和牲畜，冰雹必降在他们身上，他们就必死。’”</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 13:13; 箴言 22:3; 希伯来书 11:7"> 法老的臣仆中，那些惧怕耶和华这话的，就让自己的仆人们和牲畜逃避进房屋；</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 40:4; 约伯记 34:14; 历代志上 22:19"> 而那些不把耶和华这话放在心上的，就把自己的仆人们和牲畜留在田野中。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="启示录 16:21; 出埃及记 7:19; 出埃及记 8:5"> 耶和华对摩西说：“向天伸出你的手，使冰雹落在埃及全地，落在人和牲畜身上，落在埃及地田间所有的蔬草上。”</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 18:13; 约书亚记 10:11; 以赛亚书 30:30"> 摩西向天伸出他的杖，耶和华就发出雷声和冰雹，有火闪到地上。耶和华在埃及地降下冰雹。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 9:23; 马太福音 24:21; 出埃及记 10:6"> 那时有冰雹，又有火在冰雹中不断地闪烁，极其猛烈！这是埃及全地自从开国以来未曾有过的。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 78:47; 诗篇 105:32–33"> 在埃及全地，冰雹打击了田野中所有的人和牲畜；冰雹又打击了田间所有的蔬草，摧毁了田野中所有的树木。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 11:7; 出埃及记 9:4; 出埃及记 10:23"> 只有以色列子孙所住的歌珊地，没有冰雹。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米哀歌 1:18; 诗篇 129:4; 出埃及记 10:16"> 于是法老派人召来摩西和亚伦，对他们说：“这一次我犯了罪，耶和华是公义的，而我和我的子民是邪恶的。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 8:8; 出埃及记 10:17; 出埃及记 8:28"> 请你们向耶和华祈求，因为我们已经受够了神的雷声和冰雹。我让你们走，你们不用再留下来了。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 10:26; 列王纪上 8:38; 以赛亚书 1:15"> 摩西对他说：“我一出城，就会向耶和华伸开我的双手，雷声就会停止，也不会再有冰雹，好让你知道这地是属于耶和华的。</span>
<span className="v" id="v30" data-v="30" data-xref="以赛亚书 26:10; 箴言 16:6; 以赛亚书 63:17"> 至于你和你的臣仆，我知道你们在神耶和华的面前还是没有敬畏之心。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路得记 1:22; 路得记 2:23; 哈巴谷书 3:17"> 那时，因为大麦已经吐穗，亚麻也开了花，亚麻和大麦就被击打了。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 10:22"> 小麦和黑麦却没有被击打，因为它们是晚熟的。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="出埃及记 9:29; 出埃及记 8:12; 雅各书 5:17–18"> 摩西从法老那里出了城，向耶和华伸开他的双手，雷声和冰雹就停止了，雨水也不再倾泻在地。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 7:14; 历代志下 36:13; 出埃及记 4:21"> 法老看见雨水、冰雹和雷声都停止了，就再次犯罪，他和他的臣仆都硬着心。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及记 4:21"> 法老的心刚硬，不让以色列子孙走，正如耶和华藉着摩西所说的。</span>
</div>
</div>

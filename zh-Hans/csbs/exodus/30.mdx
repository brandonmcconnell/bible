<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 8:3; 出埃及记 37:25–28; 出埃及记 40:5"> “你要造一座焚香的坛，用金合欢木来造，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 27:2"> 长一肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘——相当于45.7公分；下同。">a</a></sup>，宽一肘，是方形的，高二肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="二肘——相当于91.4公分。">b</a></sup>；犄角从坛而出。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 25:11; 出埃及记 25:24"> 你要把坛包上纯金，坛的顶部、坛的四边和坛的犄角都要包上，并在坛的四围镶上金边；</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 25:27; 出埃及记 26:29; 出埃及记 27:7"> 又要在金边之下、在坛的相对两边为坛做两个金环，用来穿杠抬坛。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 25:13; 出埃及记 25:27"> 你要用金合欢木做两根杠，把它们包上金。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 25:21–22; 出埃及记 30:36; 利未记 16:13"> “你要把坛放在靠近见证柜的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="靠近见证柜的——原文直译“见证柜前面的”。">c</a></sup>幔子前，对着见证柜上的施恩座——我与你相会的地方。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 2:28; 历代志上 23:13; 出埃及记 27:20–21"> 亚伦要在坛上烧献芬芳香：每天早晨他照管灯的时候，都要烧献这香；</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 9:24; 帖撒罗尼迦前书 5:17; 希伯来书 7:25"> 黄昏亚伦点灯的时候，也要烧献这香；这要作为你们世世代代在耶和华面前常献的香。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 10:1"> 你们不可在坛上献异样的香、燔祭、素祭，也不可在坛上浇奠酒祭。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未记 16:18; 希伯来书 9:22–23; 利未记 16:29–30"> “亚伦要一年一次在坛的犄角上赎罪，一年一次用赎罪祭牲的血在坛上赎罪；你们世世代代都要这样做。这坛是归耶和华为至圣的。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和华指示摩西说：</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 31:50; 历代志上 27:24; 出埃及记 38:25–26"> “当你统计以色列子孙的人口数点他们的时候，各人要在你数点他们的时候向耶和华付上他们性命的赎价；这样灾殃就不会在数点他们的时候临到他们。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 27:25; 民数记 3:47; 以西结书 45:12"> 所有通过数点归入被数之众的人，都要付上这赎价：按圣所的谢克尔<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="谢克尔——重量单位；后来成为货币单位。1谢克尔=11.4公克。本章下同。">d</a></sup>标准付上半谢克尔<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="半谢克尔——相当于5.7公克；下同。1谢克尔=11.4公克。">e</a></sup>——一谢克尔是二十季拉<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="二十季拉——相当于11.4公克。1季拉=0.57公克。">f</a></sup>——这半谢克尔是献给耶和华的供物。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 1:20; 民数记 1:18; 民数记 1:3"> 所有通过数点归入被数之众的人，二十岁以上的，都要把供物献给耶和华。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 31:50; 利未记 17:11; 出埃及记 30:12"> 富人不可多付，穷人不可少付，都要付半谢克尔，献给耶和华作供物，为你们的性命赎罪。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米记 10:32–33; 民数记 16:40; 出埃及记 38:25–31"> 你要从以色列子孙收取这赎罪银，用在会幕的服事上，使它为以色列子孙在耶和华面前作记念，为你们的性命赎罪。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和华指示摩西说：</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 40:7; 出埃及记 38:8; 列王纪上 7:23"> “你要做一个用于洗濯的铜盆和铜盆座，放在会幕和祭坛之间，盆中盛水。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 52:11; 出埃及记 40:31–32; 诗篇 26:6"> 亚伦和他的儿子们要在盆中洗手洗脚。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 10:1–3; 希伯来书 12:28–29; 历代志上 13:10"> 当他们进入会幕，或接近祭坛事奉、烧献火祭给耶和华的时候，他们要用水洗濯，免得死亡；</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 28:43; 出埃及记 27:21"> 他们要洗手洗脚，免得死亡。这要成为亚伦和他的后裔世世代代永远的定例。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 耶和华指示摩西说：</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 27:19; 雅歌 4:14; 以西结书 27:22"> “你要取上等的香料：没药液五百谢克尔<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="五百谢克尔——相当于5.7公斤；下同。1谢克尔=11.4公克。">g</a></sup>、香肉桂是没药的一半——两百五十谢克尔<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="两百五十谢克尔——相当于2.85公斤；下同。1谢克尔=11.4公克。">h</a></sup>、香菖蒲两百五十谢克尔、</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 45:8; 出埃及记 29:40; 民数记 3:47"> 桂皮五百谢克尔，都要按圣所的谢克尔标准；又要取橄榄油一欣<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="一欣——相当于3.7公升。">i</a></sup>。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 37:29; 历代志上 9:30; 出埃及记 40:9"> 你要用这些来制作圣膏油，就是用调配师的做法调配的香膏。这要成为圣膏油。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="民数记 7:1; 约翰一书 2:20; 以赛亚书 61:1"> “你要用它膏抹会幕和见证柜、</span>
<span className="v" id="v27" data-v="27"> 桌子和桌子的一切器具、灯台和灯台的器具、香坛、</span>
<span className="v" id="v28" data-v="28"> 燔祭的祭坛和祭坛的一切器具、洗濯盆和盆座。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 23:19; 出埃及记 29:37; 利未记 6:18"> 你要把它们分别为圣，它们就成为至圣的；所有碰它们的也都分别为圣了。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 8:12; 出埃及记 28:3; 利未记 8:30"> 你要膏抹亚伦和他的儿子们，使他们分别为圣，作祭司事奉我。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及记 37:29; 利未记 21:10; 诗篇 89:20"> “你要吩咐以色列子孙说：‘你们世世代代要把这膏油归我作圣膏油。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 30:25; 出埃及记 30:37–38; 利未记 21:10"> 不可浇在一般人的身上，也不可照着它的配方去制作膏油；这膏油是神圣的，你们要把它当作神圣的。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 30:38; 创世记 17:14; 出埃及记 12:15"> 任何人照着这膏油去调配，或把膏油抹在祭司以外的人身上，就要从民中被剪除。’”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="出埃及记 37:29; 出埃及记 25:6; 出埃及记 30:23"> 耶和华对摩西说：“你要取芬芳的香料：苏合香、螺香、白松香；这些芬芳的香料和纯净的乳香，分量要相等。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 2:13; 出埃及记 30:25; 约翰福音 12:3"> 你要用这些做香，就是用调配师的做法调配，是加盐的、纯净的、神圣的。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 25:22; 出埃及记 30:6; 出埃及记 16:34"> 你要把一些香捣成粉末，放一些在会幕中的见证柜前——我与你相会的地方；你们要以这香为至圣。</span>
<span className="v" id="v37" data-v="37" data-xref="利未记 2:3; 出埃及记 29:37; 出埃及记 30:32–33"> 你所做的这香，不可照着它的配方为自己做；你要把这香当作神圣的，归给耶和华。</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及记 30:33"> 任何人照着这香去做，为要闻它的香味，就要从民中被剪除。”</span>
</div>
</div>

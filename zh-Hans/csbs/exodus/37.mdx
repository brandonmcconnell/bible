<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 25:10–20; 出埃及记 26:33; 民数记 10:33–36"> 比撒列用金合欢木做了一个柜，长二肘半<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="二肘半——相当于114.3公分。1肘=45.7公分。">a</a></sup>，宽一肘半<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一肘半——相当于68.6公分；下同。">b</a></sup>，高一肘半。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 30:3"> 他把柜的里里外外都包上了纯金，并在它的四围镶上了金边；</span>
<span className="v" id="v3" data-v="3"> 又为它铸了四个金环，安装在它的四个脚上，两个环在一边，两个环在另一边。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 9:15; 彼得前书 1:7; 民数记 4:14–15"> 他用金合欢木做了两根杠，把它们包上了金，</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 4:15; 撒母耳记下 6:3–7; 民数记 1:50"> 把杠穿进柜两边的环中，用来抬柜。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="希伯来书 9:5; 提多书 2:14; 罗马书 3:25"> 他用纯金做了施恩座<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="施恩座——或译作“赎罪盖”；下同。">c</a></sup>，长二肘半<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="二肘半——相当于114.3公分。1肘=45.7公分。">d</a></sup>，宽一肘半<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一肘半——相当于68.6公分。">e</a></sup>；</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 10:2; 诗篇 104:4; 诗篇 80:1"> 又在施恩座的两端，用金子造了两个基路伯，锤擛成形——</span>
<span className="v" id="v8" data-v="8"> 一端造一个基路伯，另一端也造一个基路伯，从施恩座的两端造出基路伯。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 1:51; 希伯来书 1:14; 创世记 28:12"> 两个基路伯向上展开翅膀，用它们的翅膀遮掩施恩座，它们的脸彼此相向；基路伯的脸朝向施恩座。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约翰福音 1:14; 以西结书 40:39–42; 玛拉基书 1:12"> 他用金合欢木做了一张桌子，长二肘<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="二肘——相当于91.4公分。">f</a></sup>，宽一肘<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="一肘——相当于45.7公分。">g</a></sup>，高一肘半<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="一肘半——相当于68.6公分。">h</a></sup>。</span>
<span className="v" id="v11" data-v="11"> 他把桌子包上了纯金，并在它的四围镶上了金边；</span>
<span className="v" id="v12" data-v="12"> 在它的四围做了一掌宽<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="一掌宽——相当于7.4公分。">i</a></sup>的边框，并在它的边框四围镶上了金边；</span>
<span className="v" id="v13" data-v="13"> 又为它铸了四个金环，安装在它的四角，就是它的四个腿上。</span>
<span className="v" id="v14" data-v="14"> 环靠近边框，用来穿杠抬桌子。</span>
<span className="v" id="v15" data-v="15"> 他用金合欢木做了两根杠，把它们包上了金，用来抬桌子。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 25:29; 列王纪上 7:50; 列王纪下 12:13"> 他做了桌子上浇奠用的器具：盘、碟、壶和杯；这些都是纯金的。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及记 25:31–39; 希伯来书 9:2; 历代志下 13:11"> 他用纯金做了一个灯台，灯台是锤擛成形的——它的底座、枝干、花杯、花萼和花瓣都与灯台一体锤出。</span>
<span className="v" id="v18" data-v="18"> 从灯台的两边伸出六根枝干，三根枝干在一边，三根枝干在另一边。</span>
<span className="v" id="v19" data-v="19"> 在一边的每根枝干上有三个杏花形状的花杯，每个都有花萼和花瓣；在另一边的每根枝干上也有三个杏花形状的花杯，每个都有花萼和花瓣；从灯台伸出的六根枝干都是这样。</span>
<span className="v" id="v20" data-v="20" data-xref="传道书 12:5; 耶利米书 1:11; 出埃及记 25:33"> 灯台的主干<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="的主干——辅助词语。">j</a></sup>上有四个杏花形状的花杯，每个都有花萼和花瓣；</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 25:35"> 从灯台伸出的第一对两根枝干下面有一个花萼，第二对两根枝干下面有一个花萼，第三对两根枝干下面也有一个花萼；从灯台伸出的六根枝干都是这样。</span>
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 3:5; 出埃及记 25:31; 诗篇 51:17"> 它们的花萼和枝干与灯台一体锤出，整个灯台都用同一块纯金锤成。</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 1:12; 出埃及记 25:37; 启示录 1:20–1"> 他做了灯台的七盏灯，以及灯台的灯剪和灯盘，都是纯金的；</span>
<span className="v" id="v24" data-v="24"> 用一他连得<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="一他连得——相当于34.2公斤。">k</a></sup>纯金做了灯台和灯台的一切器具。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及记 30:1–5; 希伯来书 7:25; 启示录 8:3–4"> 他用金合欢木造了一座香坛，长一肘<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="一肘——相当于45.7公分；下同。">l</a></sup>，宽一肘，是方形的，高二肘<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="二肘——相当于91.4公分。">m</a></sup>；犄角从坛而出。</span>
<span className="v" id="v26" data-v="26"> 他把坛包上纯金，坛的顶部、坛的四边和坛的犄角都包上了，并在坛的四围镶上了金边；</span>
<span className="v" id="v27" data-v="27"> 又在金边之下、在坛的相对两边为坛做了两个金环，用来穿杠抬坛。</span>
<span className="v" id="v28" data-v="28"> 他用金合欢木做了两根杠，把它们包上了金。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="诗篇 141:2; 希伯来书 7:25; 约翰一书 2:20"> 他用调配师的做法制作了圣膏油和纯净的芬芳香。</span>
</div>

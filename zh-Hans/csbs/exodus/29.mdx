<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 4:3; 玛拉基书 1:13–14; 出埃及记 12:5"> “你要为他们做以下的事，使他们分别为圣，作祭司事奉我：取一头公牛、两只无瑕疵的公绵羊，</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 6:15; 利未记 2:15; 利未记 7:12"> 以及无酵饼、调了油的无酵饼和抹上油的无酵薄饼；你要用麦子的细面粉做这些饼。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 6:17; 利未记 8:26; 利未记 8:2"> 你要把这些饼放在一个篮子里，用篮子带来，也把公牛和两只公绵羊都带来。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 40:12; 希伯来书 10:22; 出埃及记 26:36"> 你要把亚伦和他的儿子们带到会幕的入口，用水洗他们；</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 28:2–8; 利未记 8:7–8"> 拿来衣装，给亚伦穿上袍子、以弗得的外袍、以弗得和胸牌，给他束上以弗得的精巧织带；</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 8:9; 出埃及记 28:36–39"> 并且把顶冠戴在他的头上，把圣冠安在顶冠上；</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 35:25; 利未记 21:10; 约翰福音 3:34"> 又拿来膏油，浇在他的头上，膏抹他。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 8:13; 出埃及记 28:40"> 然后你要把他的儿子们带来，给他们穿上袍子，</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 18:7; 利未记 8:22–28; 申命记 18:5"> 给亚伦和他的儿子们束上腰带，戴上头巾。这样，他们就按着永远的律例拥有祭司的职份。你要这样使亚伦和他的儿子们承接圣职。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未记 1:4; 利未记 8:14; 出埃及记 29:15"> “你要把公牛带到会幕前，亚伦和他的儿子们要按手在这公牛的头上。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 9:8; 利未记 9:12; 出埃及记 29:4"> 你要在耶和华面前，在会幕的入口，宰杀这公牛，</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 27:2; 利未记 9:9; 利未记 8:15"> 取一些公牛的血，用手指抹在祭坛犄角上，把其余的血全都倒在祭坛的基座那里。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 3:3–4; 撒母耳记上 2:16; 利未记 9:10"> 你要取出所有覆盖内脏的脂肪、肝叶、两个肾脏和其上的脂肪，在祭坛上烧献为烟。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 4:11–12; 利未记 4:21; 出埃及记 30:10"> 至于公牛的肉、皮、粪便，都要在营地外面用火烧掉。这是赎罪祭。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及记 29:19; 出埃及记 29:3; 利未记 8:18–21"> “你要取一只公绵羊，亚伦和他的儿子们要按手在这公绵羊的头上。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 29:11–12"> 你要宰杀这公绵羊，取一些血，洒在祭坛四壁。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 4:14; 利未记 1:13; 利未记 1:9"> 你要把公绵羊切成碎块，洗净内脏和腿，把它们与碎块和头放在一起，</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 8:21; 腓立比书 4:18; 创世记 22:7"> 把整只公绵羊在祭坛上烧献为烟。这是献给耶和华的燔祭，是献给耶和华的馨香火祭。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及记 29:3; 利未记 8:22–29"> “你要取另一只公绵羊，亚伦和他的儿子们要按手在这公绵羊的头上。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 50:5; 希伯来书 10:22; 利未记 14:16"> 你要宰杀这公绵羊，取一些血，抹在亚伦的右耳垂和他儿子们的右耳垂上，以及他们右手的拇指和右脚的拇趾上，把其余的血洒在祭坛四壁。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 9:22; 出埃及记 29:7; 出埃及记 29:1"> 你要取一些祭坛上的血，也取一些膏油，弹洒在亚伦和他的衣服上，以及他的儿子们和他们的衣服上。这样，亚伦和他的衣服，他的儿子们和他们的衣服，就都分别为圣了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及记 29:13; 利未记 9:21; 利未记 9:19"> “你要从这公绵羊取出脂肪、肥尾巴、覆盖内脏的脂肪、肝叶、两个肾脏和其上的脂肪，以及右大腿，因为这是圣职礼所用的公绵羊；</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 29:2–3; 利未记 8:26"> 又要从耶和华面前的无酵饼篮子里取一块饼、一块油饼和一块薄饼；</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 7:30; 利未记 8:27; 利未记 9:21"> 你要把这一切都放在亚伦的手中和他儿子们的手中，作为摇献祭物在耶和华面前摇一摇。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 8:28; 出埃及记 29:41; 利未记 3:16"> 然后，你要从他们的手中把这些取过来，连同燔祭在祭坛上烧献为烟，作为耶和华面前的馨香之气。这是献给耶和华的火祭。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="利未记 8:29; 利未记 7:31; 利未记 7:34"> “你要取亚伦圣职礼所用的公绵羊的胸肉，作为摇献祭物在耶和华面前摇一摇；这是你的份。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 10:15; 民数记 18:11; 申命记 18:3"> 摇献的胸肉和供物的大腿，就是亚伦和他的儿子们圣职礼所用的公绵羊身上取下被摇过被奉上的部分，你要分别为圣。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 15:19–20; 利未记 7:11–38; 利未记 10:14–15"> 这是亚伦和他的子孙从以色列子孙所得永远的份例，因为这是供物；这是从以色列子孙所得、从他们的平安祭物中取出的供物，献给耶和华的供物。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数记 18:8; 出埃及记 28:3–4; 出埃及记 30:30"> “亚伦的圣衣要传给他的后代子孙，他们要穿着受膏抹，承接圣职。</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 20:28; 利未记 13:5; 使徒行传 20:6–7"> 亚伦的子孙中接替他作祭司的，进入会幕在圣所中事奉，都要穿圣衣七天。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="利未记 8:31; 撒母耳记上 2:13; 以西结书 46:20–24"> “你要取圣职礼所用的公绵羊，在神圣的地方煮它的肉。</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 12:4; 出埃及记 29:23; 出埃及记 29:2–3"> 亚伦和他的儿子们要在会幕的入口吃公绵羊的肉和篮子里的饼。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 18:4; 利未记 10:13–18; 诗篇 22:26"> 他们承接圣职、分别为圣时用来赎罪的那些祭物，只有他们可以吃，他们以外的人不可以吃，因为那些是神圣之物。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 12:10; 利未记 8:32; 出埃及记 29:22"> 圣职礼所用的肉或饼，如果有剩下的留到早晨，就要用火烧掉，不可以吃，因为那是神圣之物。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="出埃及记 29:30; 利未记 14:8–11; 利未记 8:4–36"> “你要照着我吩咐你的一切，向亚伦和他的儿子们这样做，用七天使他们承接圣职。</span>
<span className="v" id="v36" data-v="36" data-xref="希伯来书 10:11; 希伯来书 9:22–23; 出埃及记 30:28–29"> 你要每天献一头公牛作为赎罪祭用来赎罪；你要为祭坛行赎罪礼，使它洁净；要膏抹它，使它分别为圣。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及记 40:10; 马太福音 23:19; 出埃及记 30:28–29"> 你要为祭坛行赎罪礼七天，使它分别为圣。这样，祭坛就成为至圣的，所有碰祭坛的也都分别为圣了。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="历代志下 2:4; 历代志上 16:40; 民数记 28:3–8"> “以下是你要在祭坛上所献的：每天两只一岁的羊羔，持续不断；</span>
<span className="v" id="v39" data-v="39" data-xref="以西结书 46:13–15; 列王纪下 16:15; 诗篇 5:3"> 早晨献上一只羊羔，黄昏的时候献上另一只羊羔。</span>
<span className="v" id="v40" data-v="40" data-xref="腓立比书 2:17; 以西结书 46:14; 约珥书 2:14"> 与第一只羊羔一同献上的，要有十分之一伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="十分之一伊法——相当于2.2公升。1伊法=22公升。">a</a></sup>细面粉与四分之一欣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="四分之一欣——相当于0.9公升；下同。1欣=3.7公升。">b</a></sup>压榨的油调合的素祭<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="素祭——辅助词语。">c</a></sup>，以及四分之一欣酒的酒祭。</span>
<span className="v" id="v41" data-v="41" data-xref="以西结书 46:13–15; 列王纪上 18:29; 诗篇 141:2"> 第二只羊羔要在黄昏的时候献上，要一同献上早晨那样的素祭和酒祭。这是献给耶和华的馨香火祭。</span>
<span className="v" id="v42" data-v="42" data-xref="出埃及记 25:22"> 这要作为你们世世代代常献的燔祭，在会幕的入口，在耶和华面前——在那里我要与你们相会，在那里向你说话。</span>
<span className="v" id="v43" data-v="43" data-xref="列王纪上 8:11; 历代志下 7:1–3; 玛拉基书 3:1"> 在那里我要与以色列子孙相会，那里就必因我的荣耀分别为圣。</span>
<span className="v" id="v44" data-v="44" data-xref="利未记 21:15; 利未记 22:9; 利未记 22:16"> 我要使会幕和祭坛分别为圣，也要使亚伦和他的儿子们分别为圣，作祭司事奉我。</span>
<span className="v" id="v45" data-v="45" data-xref="利未记 26:12; 哥林多后书 6:16; 出埃及记 25:8"> 我要住在以色列子孙中间，作他们的神。</span>
<span className="v" id="v46" data-v="46" data-xref="出埃及记 20:2; 耶利米书 31:33; 以西结书 20:5"> 这样他们就知道：我是耶和华他们的神，是我把他们从埃及地领出来，为要居住在他们中间。我是耶和华他们的神。</span>
</div>
</div>

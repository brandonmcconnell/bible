<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 101:5; 箴言 19:5; 申命记 19:16–21"> “不可散布虚假的传闻；不可与恶人联手作恶毒的见证人。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="箴言 1:10–11; 箴言 1:15; 路加福音 23:23–24"> “不可随众行恶；不可在争讼的事上随众偏行，作证屈枉公义<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="公义——辅助词语。">a</a></sup>，</span>
<span className="v" id="v3" data-v="3" data-xref="雅各书 3:17; 利未记 19:15; 诗篇 82:2–3"> 也不可在争讼的事上偏袒贫弱者。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="申命记 22:1–4; 帖撒罗尼迦前书 5:15; 马太福音 5:44"> “如果你遇见仇敌的牛或驴迷失，就必须把它带回来给你的仇敌。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="申命记 22:4"> “如果你看见恨你之人的驴被压卧在重担之下，就不可置之不理留给驴的主人，必须与他一起挪开重担。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="玛拉基书 3:5; 耶利米书 5:28; 利未记 19:15"> “不可在贫穷人的争讼上屈枉公正。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 4:25; 出埃及记 34:7; 出埃及记 23:1"> 要远离虚假的控告，不可杀死无辜人和义人，因为我不会称恶人为义。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 16:19; 箴言 17:23; 以赛亚书 5:23"> 不可收取贿赂，因为贿赂会使明眼人眼瞎，又会歪曲义人的话。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 27:19; 出埃及记 22:21; 申命记 24:14–18"> 不可压迫寄居者，因为你们在埃及地作过寄居者，寄居者的心你们是知道的。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未记 25:3–4"> “六年你要耕种田地，收聚田地的出产，</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 26:34–35; 利未记 25:2–7; 利未记 25:11–12"> 但第七年要让田地歇息休耕，好使你百姓中的贫穷人有吃的；他们所剩下的，田野的走兽可以吃。你也要照样对待你的葡萄园和橄榄园。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="路加福音 13:14; 出埃及记 34:21; 出埃及记 35:3"> “六天你要做工，但第七天要安息，好使你的牛和驴安歇，也使你女仆的儿子和寄居者恢复精力。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约书亚记 23:7; 撒迦利亚书 13:2; 提摩太前书 4:16"> “我对你们所说的一切，你们都要谨守。别的神明的名号，你们不可提起，也不可让人从你的口中听到。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命记 16:16; 出埃及记 34:22–24; 利未记 23:34"> “一年三次，你要向我守节期。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 22:7; 出埃及记 34:20; 民数记 28:16–25"> 要守无酵节，照着我吩咐你的，在亚笔月所定的日期吃无酵饼七天，因为你是在这个月从埃及出来的；谁也不可空手朝见我。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 34:22; 出埃及记 22:29; 利未记 23:9–21"> 要守收割节，就是收割你在田地播种、劳碌所得的初熟之物的节期。要守收藏节，就是在年底、你从田地收聚你劳碌所得之物的时候。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 16:16; 出埃及记 34:23; 出埃及记 23:14"> 一年三次，你所有的男子都要朝见主耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 34:25; 利未记 2:11; 申命记 16:4"> “不可把我祭物的血与有酵之物一起献祭，也不可使我节期祭牲<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="祭牲——辅助词语。">b</a></sup>的脂肪过夜留到早晨。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及记 34:26; 申命记 14:21; 申命记 26:10"> “要把你土地里上好的初熟之物带到你神耶和华的殿中。<br />“不可用母山羊的奶煮它的小山羊。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 33:14; 诗篇 91:11; 出埃及记 32:34"> “看哪，我必派遣使者在你前面，为要在路上保守你，领你到我预备好的地方！</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 78:56; 诗篇 78:40; 希伯来书 12:25"> 你们在他面前要谨慎，听他的声音，不要违背他；否则，他不会饶恕你们的悖逆，因为他是奉我名的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="他是奉我名的——原文直译“我的名在他里面”。">c</a></sup>。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 12:3; 申命记 30:7; 撒迦利亚书 2:8"> 如果你留心听他的声音，遵行我所说的一切，我就作你仇敌的仇敌，作你敌人的敌人。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 23:20; 以赛亚书 5:13; 创世记 15:19–21"> 我的使者必走在你前面，领你到亚摩利人、赫提人、比利洗人、迦南人、希未人、耶布斯人那里；我必除灭他们。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 20:5; 申命记 12:30–31; 民数记 33:52"> 你不可向他们的神明下拜，不可服事它们，也不可照着那些人所做的去做，而要把那些神明彻底除掉，把神柱完全打碎。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 7:15; 出埃及记 15:26; 约书亚记 22:5"> 你们要服事耶和华你们的神，他就必祝福你的粮食和你的水。我必从你们当中除去疾病；</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 7:14; 约伯记 5:26; 申命记 28:4"> 在你的地上不会有流产的或不能生育的；我必使你满了寿数。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="申命记 2:25; 创世记 35:5; 申命记 11:25"> “我会在你前面发出威吓，使你所到之处的所有民众混乱，使你一切仇敌转身而逃。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 7:20; 约书亚记 24:11–12"> 我会在你前面派出黄蜂，使它们从你面前驱逐希未人、迦南人、赫提人。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 7:22; 约书亚记 17:12–13; 士师记 3:1–4"> 我不会在一年之内就从你面前驱逐他们，免得那地变得荒凉，田野的走兽增多危害你。</span>
<span className="v" id="v30" data-v="30"> 我会一点一点地从你面前驱逐他们，直到你繁衍增多，继承那地。</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 15:18; 申命记 11:24; 约书亚记 21:44"> 我会定下你的边界，从红海直到非利士人之海，又从旷野直到大河<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="大河——指幼发拉底河。">d</a></sup>。我会把那地的居民交在你的手中，你要把他们从你面前驱逐出去。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 7:2; 出埃及记 34:12; 出埃及记 34:15"> 你不可与他们和他们的神明立约；</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 106:36; 申命记 7:16; 出埃及记 34:12"> 不可让他们住在你的地上，免得他们使你犯罪敌对我。如果你服事他们的神明，这必定成为你的陷阱。”</span>
</div>
</div>

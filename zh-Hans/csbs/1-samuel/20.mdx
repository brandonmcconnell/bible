<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得后书 2:9; 哥林多后书 1:12; 约翰一书 3:21"> 大卫逃离拉玛的纳约特，来见约拿单，说：“我做了什么？我的罪孽是什么？我在你父亲面前犯了什么罪，以致他要寻索我的性命呢？”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 9:15; 约翰福音 17:8; 约翰福音 15:15"> 约拿单回答他：“绝对没有，你不会死的。看哪，我父亲做事，无论大小没有不告诉我的，我父亲怎么会向我隐瞒这事呢？没有这样的事！”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 25:26; 申命记 6:13; 列王纪下 2:6"> 大卫又起誓说：“你父亲深知我在你眼前蒙恩，就想：‘不要让约拿单知道这事，免得他忧伤。’然而我指着耶和华的永生和你的生命起誓：我离死只有一步！”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 约拿单就对大卫说：“你怎么说，我就为你怎么做。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民数记 10:10; 撒母耳记上 19:2; 民数记 28:11"> 大卫对约拿单说：“看哪，明天是新月节，我应该与王一同坐席吃饭。但请让我离开，躲藏在田野里，直到后天傍晚。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 17:58; 撒母耳记上 9:12; 申命记 12:5"> 如果你父亲问起我，你就说：‘大卫恳求我让他赶回他本乡伯利恒去，因为全家族要在那里举行年祭。’</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 25:17; 以斯帖记 7:7; 申命记 1:23"> 如果你父亲说：‘好！’你的仆人就平安；如果他大为恼火，你就要知道：他已经决意要加害我了。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 14:32; 撒母耳记上 18:3; 撒母耳记上 23:18"> 那时求你以恩慈对待你的仆人，因为你曾与你仆人一同在耶和华面前立约。如果在我身上有罪孽，你就亲自杀我吧！何必把我交给你父亲呢？”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 20:42; 撒母耳记上 19:2; 撒母耳记上 20:38"> 约拿单说：“你绝不会有事的！况且如果我确实知道我父亲已经决意要加害你，我会不告诉你吗？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 25:14; 撒母耳记上 25:17; 创世记 42:30"> 大卫问约拿单：“要是你父亲严厉地回应你，谁来告诉我呢？”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 约拿单对大卫说：“走，我们出去到田野里！”他们两个人就出去到了田野。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 22:22; 约伯记 31:4; 箴言 25:2–3"> 约拿单对大卫说：“愿以色列的神耶和华作证：明后天大约这个时候，我会探探我父亲是否对大卫有善意，然后我一定派人到你这里告诉你。</span>
<span className="v" id="v13" data-v="13" data-xref="路得记 1:17; 历代志上 22:11; 约书亚记 1:5"> 如果我父亲有意要加害你，而我不告诉你，不送你平安地离开，就愿耶和华处置约拿单，重重地处置！愿耶和华与你同在，像他曾与我父亲同在那样。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 9:3; 以弗所书 5:1–2"> 在我活着的时候，愿你以耶和华的慈爱对待我，免我死亡；</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 21:7; 撒母耳记上 24:21; 撒母耳记下 9:1–7"> 在耶和华把大卫的每个仇敌从这地面上剪除的时候，愿你也不要对我家断绝慈爱，直到永远。”</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 25:22; 撒母耳记上 18:3; 撒母耳记下 21:8"> 于是约拿单与大卫家立约：“愿耶和华从大卫仇敌的手中追讨背约之罪！”</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 18:24; 撒母耳记上 18:1; 撒母耳记上 18:3"> 约拿单因着对大卫的爱，就让大卫再次起誓，因为他爱大卫如同爱自己的性命。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 20:25; 撒母耳记上 20:5"> 约拿单对他说：“明天是新月节，人们会问起你，因为你的座位空着。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 19:2; 撒母耳记上 20:5"> 第三天，你要赶快下去，到你在出事的日子曾经隐藏的那地方，在伊泽尔磐石旁边等着。</span>
<span className="v" id="v20" data-v="20"> 我会向磐石旁边射三支箭，就像射向靶子那样。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 5:2; 阿摩司书 8:14; 耶利米书 12:16"> 看哪，我会派一个少年，去找回那些箭。如果我对那少年明确地说：‘看，箭在你后面，把它们捡回来’，那么你就回来，因为我指着耶和华的永生起誓：你必平安无事。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 20:37"> 如果我对少年说：‘看，箭在你前面’，那么你就要走，因为是耶和华让你离去。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 20:14–15; 撒母耳记上 20:42; 创世记 31:50"> 我和你所说的这些话，看哪，有耶和华在你我之间作证<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="作证——辅助词语。">a</a></sup>，直到永远。”</span>
<span className="v" id="v24" data-v="24" data-xref="箴言 4:17; 以赛亚书 1:11–15; 箴言 21:3"> 于是大卫躲藏在田野里。 扫罗怒责约拿单<br />到了新月节，王入席要吃饭。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 20:18; 士师记 16:20"> 王像往常那样坐在他的座位上，座位靠墙；约拿单在对面<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="在对面——马索拉文本作“起立”。">b</a></sup>，押尼珥坐在扫罗旁边，而大卫的位子空着。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 15:5; 利未记 11:24; 利未记 11:27"> 扫罗那天没有说什么，因为他想：“有意外的事发生，大卫不洁净了，他一定是不洁净了。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="彼得前书 2:4; 撒母耳记上 19:15; 撒母耳记上 18:11"> 第二天，就是新月节第二天，大卫的位子还是空着。扫罗就问儿子约拿单：“为什么耶西的儿子昨天、今天都没有来赴宴呢？”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 20:6"> 约拿单回答扫罗：“大卫恳求我准许他回伯利恒。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记上 17:28"> 他说：‘请让我走，因为我们家族要在那城里举行祭祀，我哥哥亲自吩咐我回去。现在，如果我在你眼前蒙恩，就请让我缺席，让我去见我的哥哥们。’因此他没有来赴王的筵席。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="箴言 21:24; 雅各书 1:19–20; 箴言 25:28"> 扫罗就对约拿单发怒，对他说：“你这忤逆的娼妇之子！难道我不知道吗？你在袒护耶西的儿子，以致自己蒙羞，也使你母亲露体蒙羞！</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记上 19:6; 撒母耳记上 20:8; 撒母耳记上 19:11–15"> 只要耶西的儿子活在这地上一天，你和你的王位就不能稳固。现在，你派人去把他带到我这里来，他必须死！”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马太福音 27:23; 撒母耳记上 19:5; 路加福音 23:22"> 约拿单回应他父亲扫罗说：“他为什么该死？他做了什么呢？”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="撒母耳记上 20:7; 撒母耳记上 18:11; 撒母耳记上 19:10"> 扫罗把长矛朝着约拿单掷出去，要击杀他。约拿单就知道，他父亲是决意要杀大卫。</span>
<span className="v" id="v34" data-v="34" data-xref="以弗所书 4:26; 马可福音 3:5; 传道书 7:20"> 约拿单在烈怒中起来离开筵席，他在新月节第二天没有吃饭，因为他为父亲羞辱大卫而忧伤。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 20:5; 撒母耳记上 20:19"> 到了清晨，约拿单按着与大卫的约定，出去到田野里，有一个小少年跟着他。</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳记上 20:20–22"> 他对那少年说：“往前跑，去把我将射的箭找回来！”少年就跑去，约拿单把箭射到他前头。</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳记上 20:22"> 那少年跑到约拿单所射的箭落地之处，约拿单就在少年的后面呼喊说：“箭不是在你前头吗？”</span>
<span className="v" id="v38" data-v="38" data-xref="诗篇 55:6–9; 箴言 6:4–5; 马可福音 13:14–16"> 约拿单又在少年后面呼喊：“赶快去，不要停留！”少年捡起了那些箭，回到他主人那里。</span>
<span className="v" id="v39" data-v="39"> 那少年什么也不知道，只有约拿单和大卫知道这意思。</span>
<span className="v" id="v40" data-v="40"> 约拿单把自己的兵器交给那少年，对他说：“去吧，拿回城里！”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="创世记 29:11; 撒母耳记上 18:3; 撒母耳记下 9:6"> 少年走后，大卫从磐石旁边<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="磐石旁边——依据七十士译本；马索拉文本作“南边”。">c</a></sup>出来，脸伏于地，下拜三次。然后他们彼此亲吻，一起哭泣，大卫哭得尤其厉害。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="撒母耳记上 1:17; 撒母耳记上 23:18; 撒母耳记上 20:22–23"> 约拿单对大卫说：“平平安安地去吧！我们两人已经指着耶和华的名起誓说：‘愿耶和华在你我之间、我的后裔与你的后裔之间作证，直到永远。’”于是大卫起身离去，约拿单也回城去了。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="此句在马索拉文本为21:1。">d</a></sup></span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 6:27; 弥迦书 7:5; 撒母耳记下 1:25–26"> 有一天，扫罗的儿子约拿单对替他拿兵器的年轻人说：“走，我们过到对面非利士的守军那里吧！”他却没有把这事告诉他的父亲。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 13:15–16; 以赛亚书 10:28–29"> 那时扫罗在基比亚的边界，坐在米矶仑的石榴树下，随同他的军兵约有六百人，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 22:20; 撒母耳记上 2:28; 撒母耳记上 4:21"> 其中有佩戴着以弗得的亚希雅。他是亚希突的儿子，亚希突是以迦博的哥哥，是非尼哈的儿子，非尼哈是从前在示罗作耶和华祭司的以利的儿子。当时人们不知道约拿单离开了。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 13:23"> 约拿单想要穿过关口到非利士的守军那里，关口这边有一座石峰，那边也有一座石峰：一座叫播薛，另一座叫西尼；</span>
<span className="v" id="v5" data-v="5"> 一峰在北，与米克玛相对，一峰在南，与迦巴相对。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 19:26; 罗马书 8:31; 撒迦利亚书 4:6"> 约拿单对替他拿兵器的年轻人说：“走，我们过到未受割礼之人的守军那里吧！或许耶和华会为我们行动，因为无论人多人少，什么也不能阻碍耶和华施行拯救。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 7:3; 撒迦利亚书 8:23; 撒母耳记上 10:7"> 替他拿兵器的对他说：“你心里想的一切，你尽管去做吧！只管前行，看哪，我与你同心。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="士师记 7:9–14"> 约拿单就说：“看，我们过到他们那里，让他们看见我们。</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 6:36–40; 创世记 24:13–14"> 如果他们对我们说：‘站住，等我们过到你们那里！’我们就留在原地，不上他们那里去。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 24:14; 撒母耳记上 10:7; 士师记 7:11"> 如果他们说：‘上我们这里来！’我们就上去，因为耶和华已经把他们交在我们手中了，这是给我们的征兆。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 13:6; 撒母耳记上 14:22; 士师记 6:2"> 于是他们两人就让非利士的守军看见他们。非利士人说：“看，希伯来人从他们躲藏的洞里出来了！”</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 17:43–44; 撒母耳记下 5:24; 士师记 7:15"> 守军中有人向约拿单和替他拿兵器的喊道：“上我们这里来，让我们教训教训你们！”<br />约拿单就对拿兵器的说：“跟我上去，因为耶和华已经把他们交在以色列手中了。”</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 8:31; 约书亚记 23:10; 利未记 26:7–8"> 约拿单手脚并用爬了上去，替他拿兵器的跟在后面。非利士人在约拿单面前仆倒，拿兵器的跟在后面杀死他们。</span>
<span className="v" id="v14" data-v="14"> 约拿单和替他拿兵器的发起第一次攻击，在大约二十公亩<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="二十公亩——原文作“半茨梅德”；1茨梅德=4,047平方公尺，是一对耕牛一日的犁地面积。">a</a></sup>地的范围内，击杀了约有二十人。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 13:17; 创世记 35:5; 撒母耳记下 5:24"> 于是，营地和郊外的所有军兵，一片恐慌，守军和突击队都战兢，大地也颤抖，这是从神而来的恐慌。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 20:22–25; 以赛亚书 19:2; 士师记 7:22"> 在便雅悯的基比亚，扫罗的守望兵观看，看哪，敌军溃散，四处奔逃。</span>
<span className="v" id="v17" data-v="17"> 扫罗就对那些随同他的军兵说：“你们现在数点一下，看看谁从我们这里离开了。”他们数点，就发现约拿单和替他拿兵器的不在。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 30:7–8; 撒母耳记上 5:2; 士师记 20:23"> 扫罗对亚希雅说：“把神的约柜带来！”当时神的约柜与以色列子民在一起。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 14:24; 民数记 27:21; 约书亚记 9:14"> 扫罗正对祭司说话的时候，非利士营地中的喧嚣越来越大，扫罗就对祭司说：“停手吧！”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="士师记 7:22; 历代志下 20:23; 撒母耳记上 14:16"> 扫罗和随同他的全体军兵都集合，来到战场，看哪，非利士人彼此刀剑相向，有极大的骚乱。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 29:4; 士师记 7:23"> 那些以前归顺非利士人、与他们一起上到周围敌营的希伯来人，现在回来与那些随同扫罗和约拿单的以色列人在一起了。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 13:6; 撒母耳记上 31:7"> 躲藏在以法莲山地的所有以色列人，听说非利士人逃跑了，也都到战场上追击敌人。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 14:30; 撒母耳记上 13:5; 诗篇 44:6–8"> 那一天，耶和华拯救了以色列人。 扫罗轻率的誓言<br />战争延伸到伯亚文。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 6:26; 罗马书 10:2; 士师记 1:28"> 那天以色列人的处境窘迫，因为扫罗让军兵起过誓说：“在我报复了仇敌以先、在傍晚之前吃东西的人是受诅咒的！”所以军兵中没有一个人吃东西<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="吃东西——原文直译“尝食物”。">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及记 3:8; 民数记 13:27; 申命记 9:28"> 那整个地方，进入森林，地面上都有蜂蜜。</span>
<span className="v" id="v26" data-v="26" data-xref="传道书 9:2"> 当军兵进入森林，看哪，有蜂蜜流淌，但没有人用手取蜜放入嘴里，因为他们害怕所起的誓。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 14:29; 撒母耳记上 14:43; 撒母耳记上 30:12"> 而约拿单没有听见他父亲让军兵起誓，所以他伸出手里的杖，把杖尖蘸在有蜜的蜂巢里，然后用手取蜜放入嘴里，眼睛就明亮了。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 14:43; 撒母耳记上 14:24"> 军兵中有人告诉他说：“你父亲让大家郑重起誓说：‘今天吃东西的人，是受诅咒的！’所以军兵就疲乏了。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王纪上 18:18; 约书亚记 7:25"> 约拿单说：“我父亲给国家带来了困扰。你们看，我尝了一点这蜂蜜，眼睛就明亮了。</span>
<span className="v" id="v30" data-v="30" data-xref="传道书 9:18"> 如果今天军兵能随意吃从仇敌夺来的东西，那该多好！现在被击杀的非利士人不就更多了吗？”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约书亚记 10:12; 约书亚记 19:42"> 那天他们击杀非利士人，从米克玛直到阿雅仑，军兵非常疲乏。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 15:19; 利未记 3:17; 利未记 17:10–14"> 军兵冲向战利品，取来羊、牛和牛犊，在地上宰杀，然后军兵们带着血就吃了。</span>
<span className="v" id="v33" data-v="33" data-xref="罗马书 2:1; 马太福音 7:5"> 有人报告扫罗说：“看哪，人们在吃带血的肉，对耶和华犯罪了。”<br />扫罗说：“你们背信了！现在把一块大石头滚到我这里来！”</span>
<span className="v" id="v34" data-v="34"> 他又说：“你们分散开来，到军兵中去吩咐他们：各人要把自己的牛羊牵到我这里来，在这里宰杀了吃；不可对耶和华犯罪去吃带血的肉。”于是那夜，所有军兵都把各自手里的牛牵来，在那里宰杀了。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记上 7:17; 撒母耳记上 7:12; 提摩太后书 3:5"> 之后扫罗为耶和华筑了一座祭坛，这是他为耶和华筑的第一座祭坛。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以赛亚书 48:1–2; 诗篇 73:28; 玛拉基书 2:7"> 扫罗说：“我们要趁夜下去追赶非利士人，掠夺他们直到天亮，不让他们一人存留。”<br />军兵说：“你看怎样好就怎样做吧！”<br />但祭司说：“让我们在这里求问<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="求问——原文直译“亲近”。">c</a></sup>神。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="撒母耳记上 28:6; 撒母耳记上 30:7–8; 撒母耳记上 23:9–12"> 扫罗就求问神：“我可以下去追赶非利士人吗？你会把他们交在以色列人手中吗？”那一天，神没有回应他。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="士师记 20:2; 约书亚记 7:14–26; 民数记 24:17"> 扫罗说：“所有军兵的首领，你们都上这里来，要察看今天这罪是怎么发生的！</span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳记上 14:44; 撒母耳记下 12:5; 撒母耳记上 14:24"> 我指着拯救以色列的耶和华的永生起誓：即使罪在我的儿子约拿单，他也必须死！”全体军兵中没有人回应他。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="撒母耳记下 15:15; 撒母耳记上 14:7; 撒母耳记上 14:36"> 他对全体以色列人说：“你们站在这一边，我和我儿子约拿单在那一边。”<br />军兵对扫罗说：“你看怎样好就怎样做吧！”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="使徒行传 1:24; 约书亚记 7:16–18; 撒母耳记上 10:20–21"> 扫罗对以色列的神耶和华说：“求你指明正确的抽签结果！”于是约拿单和扫罗被抽中，军兵都脱罪了。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> 扫罗说：“在我和我儿子约拿单之间抽签吧。”结果约拿单被抽中了。</span>
<span className="v" id="v43" data-v="43" data-xref="约书亚记 7:19; 撒母耳记上 14:27; 约拿书 1:7–10"> 扫罗对约拿单说：“告诉我，你做了什么？”<br />约拿单就告诉他说：“我只是用手杖尖蘸了一点蜂蜜吃，我这样就必须死吗？”</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="撒母耳记上 14:39; 路得记 1:17; 撒母耳记上 25:22"> 扫罗说：“约拿单，你必须死，否则愿神处置我，重重地处置我！”</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="路加福音 21:18; 使徒行传 27:34; 撒母耳记下 14:11"> 军兵对扫罗说：“约拿单为以色列成就了这样大的拯救，怎么可以死呢？绝对不可！我们指着耶和华的永生起誓：连他的一根头发也不可落在地上！因为他今天是与神一同行事。”这样，人们救了约拿单，他就免于一死；</span>
<span className="v" id="v46" data-v="46"> 扫罗回去，不再追赶非利士人，非利士人也回自己的地方去了。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="撒母耳记下 10:6; 撒母耳记上 14:52; 撒母耳记下 8:3"> 扫罗得了以色列的王位，攻打四围一切仇敌，攻打摩押人、亚扪人、以东人、琐巴的众王和非利士人，凡他所到之处尽都征服。</span>
<span className="v" id="v48" data-v="48" data-xref="出埃及记 17:14; 撒母耳记上 15:3–7; 申命记 25:19"> 他作战英勇，击败了亚玛力人，解救以色列人脱离抢掠他们之人的手。</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="历代志上 8:33; 撒母耳记上 31:2; 撒母耳记下 6:20–23"> 扫罗的儿子是约拿单、伊施韦和麦基舒亚。他有两个女儿，大的名叫米拉，小的名叫米甲。</span>
<span className="v" id="v50" data-v="50" data-xref="撒母耳记下 2:8; 撒母耳记上 17:55; 撒母耳记下 3:27"> 扫罗的妻子名叫娅希暖，是亚希玛斯的女儿。他的元帅名叫押尼珥，是扫罗的叔叔尼珥的儿子；</span>
<span className="v" id="v51" data-v="51" data-xref="撒母耳记上 9:1; 撒母耳记上 9:21"> 扫罗的父亲基士和押尼珥的父亲尼珥都是亚比耶的儿子。</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="撒母耳记上 8:11; 撒母耳记上 8:1"> 扫罗一生的日子常与非利士人发生激烈的战争。扫罗遇见任何有能力的人或英勇的人，都会招聚到他那里。</span>
</div>
</div>

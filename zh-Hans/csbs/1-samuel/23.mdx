<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 15:44; 弥迦书 6:15; 尼希米记 3:17–18"> 有人告诉大卫说：“看哪，非利士人在攻打基伊拉，抢掠打谷场。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 23:4; 撒母耳记下 5:19; 撒母耳记下 5:23"> 大卫就求问耶和华说：“我可以去攻打这些非利士人吗？”<br />耶和华回答大卫：“去吧，你可以攻打非利士人，拯救基伊拉。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米书 12:5; 诗篇 11:1; 撒母耳记上 23:15"> 大卫的部下却对他说：“看哪，我们在犹大这里尚且惧怕，更何况去基伊拉攻打非利士的军队呢！”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士师记 7:7; 约书亚记 8:7; 列王纪下 3:18"> 于是大卫再次求问耶和华。耶和华回答他，说：“起身，下到基伊拉去，因为我必把非利士人交在你手中。”</span>
<span className="v" id="v5" data-v="5"> 大卫和他的部下就往基伊拉去，与非利士人争战，掳走他们的牲畜，大大击杀他们。这样，大卫拯救了基伊拉的居民。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 22:20; 撒母耳记上 14:3; 撒母耳记上 14:18"> 亚希米勒的儿子亚比亚特逃到基伊拉大卫那里时，手中拿着以弗得下去。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 24:4–6; 约伯记 20:5; 撒母耳记上 26:8–9"> 有人告诉扫罗：“大卫到了基伊拉。”扫罗就说：“神把他交在我手中了，因为他进入一座有门有闩的城，把自己关在里面了。”</span>
<span className="v" id="v8" data-v="8"> 于是扫罗召集全军出战，要下到基伊拉去围困大卫和他的部下。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 30:7; 撒母耳记上 23:6; 民数记 27:21"> 大卫知道扫罗图谋害他，就对祭司亚比亚特说：“把以弗得拿过来！”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="罗马书 3:15–16; 撒母耳记上 23:8; 创世记 18:24"> 大卫求问说：“以色列的神耶和华啊，你的仆人确实听说了扫罗想要来基伊拉，因我的缘故毁掉这城。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 33:3; 诗篇 50:15; 马太福音 7:7–8"> 基伊拉的居民会把我交在扫罗的手中吗？扫罗会像你仆人所听说的那样下来吗？以色列的神耶和华啊，请你指示仆人。”<br />耶和华回答：“他会下来。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 23:20; 诗篇 31:8; 诗篇 62:1"> 大卫接着问：“基伊拉的居民会把我和我的人交在扫罗手中吗？”<br />耶和华回答：“会交出去。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 22:2; 撒母耳记上 25:13; 撒母耳记上 30:9–10"> 于是，大卫和他的部下约六百人就起身离开基伊拉，到处迁移。有人告诉扫罗，大卫已经逃离基伊拉，扫罗就不下去了。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 54:3–4; 诗篇 32:7; 约书亚记 15:24"> 大卫住在旷野的各个要塞里，或住在西弗旷野的山地。扫罗天天寻索大卫，神却不把大卫交在他手中。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 大卫知道扫罗已经出来寻索他的性命，那时大卫在西弗旷野的何列什。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 35:3–4; 希伯来书 12:12–13; 约伯记 4:3–4"> 扫罗的儿子约拿单起身去何列什见大卫，勉励他靠着神坚强，</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 20:31; 撒母耳记上 24:20; 使徒行传 28:16"> 对他说：“不要怕，因为我父亲扫罗的手害不了你。你必作以色列的王，我将在你之下位居第二，连我父亲扫罗也知道会这样。”</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 21:7; 撒母耳记上 20:42; 撒母耳记上 18:3"> 于是他们二人在耶和华面前立约，然后大卫仍住在何列什，而约拿单回自己的家去了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 26:1; 撒母耳记上 26:3; 诗篇 54:1–7"> 西弗人上到基比亚见扫罗，说：“大卫难道不是躲藏在我们这里，在旷野南边哈基拉山上的何列什要塞吗？</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 23:12; 箴言 29:26; 箴言 11:23"> 王啊，你愿意什么时候下来就请下来；至于我们，我们必把他交在王的手中。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 22:8; 以赛亚书 66:5; 弥迦书 3:11"> 扫罗说：“愿你们蒙耶和华祝福！因为你们顾惜我。</span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 5:13"> 请你们去再次确认，察看他的落脚之处，有谁在那里看到他，因为有人对我说，他非常狡猾。</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 3:15–16; 马可福音 14:1; 民数记 10:36"> 你们要查清他躲藏的所有地方，确定后回来见我，我就与你们一同去。如果他在那地方，我就把他从犹大的千家万户中搜出来。”</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记上 25:2; 约书亚记 15:55"> 于是西弗人动身，在扫罗之先回西弗去了。<br />那时大卫和他的部下在玛云旷野，荒漠南边的亚拉巴。</span>
<span className="v" id="v25" data-v="25" data-xref="士师记 15:8; 撒母耳记上 23:28"> 扫罗和他的部下去寻索大卫，有人告诉大卫，他就下到岩石带，留在玛云旷野。扫罗听说了，就去玛云旷野追赶大卫。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="诗篇 17:9; 哥林多后书 1:8; 诗篇 140:1–9"> 扫罗在山这边走，大卫和他的部下在山那边走。大卫慌忙躲避扫罗，扫罗和他的部下要围困大卫和他的部下，抓住他们。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 19:9; 诗篇 116:3; 申命记 32:36"> 这时有一个使者来告诉扫罗：“请赶快回去，因为非利士人入境抢掠了。”</span>
<span className="v" id="v28" data-v="28"> 于是扫罗返回不追赶大卫，而迎战非利士人去了。因此那地方被称为隔断岩<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="隔断岩——音译作“西拉-哈玛希罗结”。">a</a></sup>。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志下 20:2; 约书亚记 15:62; 以西结书 47:10"> 大卫从那里上去，住在恩盖迪的要塞里。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="此节在马索拉文本为24:1。">b</a></sup></span>
</div>
</div>

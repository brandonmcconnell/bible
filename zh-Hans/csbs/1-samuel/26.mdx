<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 23:19; 诗篇 54:1–7; 约书亚记 15:24"> 西弗人来到基比亚见扫罗，说：“大卫不是躲藏在旷野对面的哈基拉山中吗？”</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 24:2; 撒母耳记上 13:2; 诗篇 140:4–9"> 扫罗就动身，带着以色列中的三千精兵下到西弗旷野，要在西弗旷野寻索大卫。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 23:19; 撒母耳记上 26:1"> 扫罗在荒漠对面的哈基拉山，在路边扎了营。那时大卫住在旷野，他发现扫罗追他来到了旷野。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 10:16; 约书亚记 2:1"> 大卫派出探子，得知扫罗确实来了。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 17:55; 撒母耳记上 17:20; 撒母耳记上 14:50–51"> 于是大卫动身，来到扫罗扎营的地方。大卫看见了扫罗和尼珥的儿子元帅押尼珥睡卧的地方，扫罗睡在行营中间，军兵在他的四围扎营。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 7:10–11; 撒母耳记下 2:18; 创世记 15:20"> 大卫就问赫提人亚希米勒以及洗鲁雅的儿子、约押的弟弟亚比筛，说：“谁与我一起下到营地中扫罗那里？”<br />亚比筛回答：“我与你一同下去。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="帖撒罗尼迦前书 5:2–3"> 夜间大卫和亚比筛来到军兵那里，看哪，扫罗正躺在行营中沉睡，他的长矛插在枕头旁的地上，押尼珥和军兵睡在他四围。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 24:4; 撒母耳记上 26:23; 申命记 32:30"> 亚比筛对大卫说：“今天神把你的仇敌交在你手中了。现在，请让我用长矛把他一枪刺透在地，不用第二枪。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 1:14; 诗篇 105:15; 撒母耳记下 1:16"> 大卫对亚比筛说：“不要杀害他！有谁对耶和华的受膏者下手而能免于罪罚呢？”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 47:29; 申命记 31:14; 诗篇 37:13"> 大卫又说：“我指着耶和华的永生起誓：一定是耶和华来打击他——或是到了所定的日子而死，或是出战阵亡；</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 24:6; 撒母耳记上 24:12; 撒母耳记下 1:14"> 耶和华绝不允许我对耶和华的受膏者下手。现在，你把他头旁的长矛和水瓶拿过来，然后我们就走！”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 2:21; 创世记 15:12; 以赛亚书 29:10"> 大卫拿了扫罗枕头旁的长矛和水瓶，他们就走了。没有人看见，没有人知道，也没有人醒来，人们全都在沉睡，因为是耶和华使他们陷入沉睡。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 24:8; 士师记 9:7"> 大卫过到对面，站在远处的山顶上，他们之间有很大的距离。</span>
<span className="v" id="v14" data-v="14"> 大卫向军兵和尼珥的儿子押尼珥呼叫，说：“押尼珥，你不回应吗？”<br />押尼珥回应说：“你是谁，竟敢对着王呼叫？”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 大卫对押尼珥说：“你不是个大丈夫吗？在以色列中，有谁能与你相比呢？民中有人来要杀害王你的主，你为什么没有保护王你的主呢？</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 79:11; 撒母耳记下 12:5; 撒母耳记上 26:9"> 你这事做得不好。我指着耶和华的永生起誓：你们是该死的，因为你们没有保护耶和华的受膏者你们的主。现在你看看王的长矛和他枕头旁的水瓶在哪里呢？”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 24:16; 撒母耳记上 24:8"> 扫罗认出大卫的声音，就问：“我儿大卫，这是你的声音吗？”<br />大卫回答：“我主我王啊，是我的声音。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 24:9; 撒母耳记上 24:11–14; 约翰福音 10:32"> 又说：“我主为什么追赶你的仆人呢？我到底做了什么，我手中有什么恶行呢？</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 14:16; 撒母耳记下 16:11; 撒母耳记下 20:19"> 现在，求我主我王听你仆人的话：如果是耶和华促动你攻击我，愿耶和华悦纳供物；如果是出于人，就愿他们在耶和华面前受诅咒！因为今日他们驱逐我，不让我在耶和华的继业上有份，说：‘去服事别的神吧！’</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 24:14; 马太福音 26:55; 撒母耳记上 25:29"> 现在，求你不要让我的血流在远离耶和华面前的地方。以色列王出来，不过是寻索一只跳蚤，就像人在山中追赶鹧鸪那样。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 15:24; 撒母耳记上 24:17; 出埃及记 9:27"> 扫罗说：“我有罪了！我儿大卫啊，回来吧！我不会再伤害你了，因为今天我的性命在你眼中看为宝贵。看哪，我很愚蠢，并且错得极其严重。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 大卫回应说：“看哪，这是王的长矛，请让一个仆人过来拿回去吧。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 62:12; 撒母耳记上 24:6–7; 诗篇 18:20–26"> 愿耶和华按着各人的公义和信实回报他！因为耶和华今天把你交在了我手中，我却不愿意对耶和华的受膏者下手。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 5:7; 哥林多后书 1:9–10; 诗篇 54:7"> 看哪，今天我怎样重视你的性命，愿耶和华也怎样重视我的性命，愿他解救我脱离一切患难！”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="民数记 24:9–10; 箴言 26:25; 撒母耳记上 24:19"> 扫罗对大卫说：“我儿大卫，你是蒙祝福的！你必成就大事，也必得胜。”于是大卫上路离开，扫罗也回自己的地方去了。</span>
</div>
</div>

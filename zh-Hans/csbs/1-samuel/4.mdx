<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 29:1; 撒母耳记上 7:12; 撒母耳记上 5:1"> 这样，撒母耳的话语就临到了全以色列。 约柜被夺<br />那时以色列人出去迎战非利士人，在以便以谢旁边扎营，非利士人在阿费克扎营。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米哀歌 3:40; 撒母耳记上 17:8; 约书亚记 7:5–8"> 非利士人摆阵迎战以色列人；战斗展开后，以色列人败在非利士人面前，非利士人在战场上击杀了大约四千人。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="提摩太后书 3:5; 民数记 10:35; 哥林多前书 10:1–5"> 军队回到营地中，以色列的长老们说：“为什么今天耶和华让我们败在非利士人面前呢？我们把耶和华的约柜从示罗带到我们这里吧，让约柜来到我们当中，拯救我们脱离仇敌的手！”</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 6:2; 民数记 7:89; 诗篇 80:1"> 于是民众派人去示罗，从那里把坐在基路伯之上的万军之耶和华的约柜抬来，以利的两个儿子何弗尼和非尼哈也跟着神的约柜来了。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 6:5; 约伯记 20:5; 阿摩司书 6:3"> 当耶和华的约柜来到营地时，全体以色列人大声欢呼，那地都震动了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 32:17–18"> 非利士人听见了欢呼的声音，就说：“希伯来人营地中有这么大的欢呼声是怎么回事呢？”随后得知是耶和华的约柜来到了那营地。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 32:30; 出埃及记 14:25; 出埃及记 15:14–16"> 非利士人就害怕，说：“有神来到他们营地了！”又说：“我们有祸了！从来没有这样的事。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 9:14; 出埃及记 7:5; 诗篇 78:43–51"> 我们有祸了！谁能解救我们脱离这大能之神的手呢？这神就是在旷野用各种灾害打击埃及人的那一位。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 16:13; 士师记 13:1; 撒母耳记下 10:12"> 非利士人哪，你们要坚强，要作大丈夫，免得你们服事希伯来人，就像他们曾服事你们一样。你们要作大丈夫，要战斗！”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未记 26:17; 列王纪下 14:12; 申命记 28:25"> 于是非利士人进攻，以色列人被打败，各人逃回自己的帐篷。那是一场极大的杀戮，以色列的步兵倒毙了三万。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 2:34; 诗篇 78:64; 撒母耳记上 2:32"> 神的约柜被夺去，以利的两个儿子何弗尼和非尼哈也死了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约书亚记 7:6; 尼希米记 9:1; 撒母耳记下 15:32"> 有一个便雅悯人从军阵中跑出来，当天来到示罗，他的战袍撕裂，头蒙灰尘。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 1:9; 撒母耳记上 4:18; 约书亚记 7:9"> 他来到的时候，看哪，以利正坐在路旁的座位上守望，因为他为神的约柜忧心。那人进城里报信时，全城都哀叫起来。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 以利听见哀呼声，就问：“这喧嚣的声音是怎么回事呢？”那人赶快过来，向以利报告。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 3:2; 诗篇 90:10; 列王纪上 14:4"> 以利已经九十八岁了，眼目僵直，不能看见。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 1:4; 撒母耳记上 3:6; 约书亚记 7:19"> 那人对以利说：“我是从军阵中来的，我今天刚从军阵中逃出来。”<br />以利就问：“我儿，情况怎么样？”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 3:11; 撒母耳记上 4:10–11"> 报信的人回答说：“以色列人在非利士人面前逃跑，而且民中遭受了极大的杀戮，你的两个儿子何弗尼和非尼哈也死了，神的约柜被夺去了。”</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 4:21–22; 彼得前书 4:17–18; 诗篇 69:9"> 他一提到神的约柜，以利就从座位上向后仰倒在城门边，由于人老体重，脖子折断而死。以利作以色列的士师四十年。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 当时以利的儿媳妇，非尼哈的妻子怀孕临产，她一听到消息说神的约柜被夺去、她的公公和丈夫也死了，就被阵痛击溃，屈身生产。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 35:17–18; 诗篇 77:2; 约翰福音 16:21"> 她临死的时候，身边侍候的妇女们说：“不要担心，你生了一个儿子！”她却没有回应，也不理会。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 26:8; 耶利米书 2:11; 诗篇 78:61"> 她给孩子起名为以迦博，说：“荣耀离开了以色列。”这是指着神的约柜被夺去以及她公公和丈夫的事说的。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 137:5–6; 约翰福音 2:17"> 她说：“荣耀离开了以色列，因为神的约柜被夺去了。”</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 28:3; 民数记 20:29; 申命记 34:8"> 撒母耳死了，全以色列聚集哀悼他，把他葬在拉玛他的家<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="家——或译作“墓穴”。">a</a></sup>。之后大卫动身，下到帕兰旷野去。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="创世记 38:13; 撒母耳记上 23:24; 约书亚记 15:55"> 在玛云有一个人，他的产业在迦密。那人非常富有，有绵羊三千只，山羊一千只，那时他正在迦密剪羊毛。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 14:1; 箴言 31:10; 以赛亚书 32:5–7"> 那人名叫纳巴尔，他的妻子名叫娅比盖。这女人既有美好的见识，又身材秀美；而她的男人既顽梗，又行事凶恶。他是迦勒族的人。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="创世记 38:13; 撒母耳记下 13:23"> 大卫在旷野听说纳巴尔正在剪羊毛，</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 43:23; 撒母耳记上 17:22"> 就派遣十个仆人，对那些仆人说：“你们上迦密去见纳巴尔，提我的名向他问安。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 10:5; 历代志上 12:18; 诗篇 122:7"> 你们要如此说：‘愿你长寿！愿你平安！愿你的家平安！愿属于你的一切都平安！</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 25:21; 撒母耳记上 25:15–16; 撒母耳记上 22:2"> 我听说现在有人在为你剪羊毛。你的牧人与我们在一起时，我们没有欺负过他们；他们在迦密的所有日子，也没有丢失过什么东西。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯帖记 9:19; 尼希米记 8:10–12; 路加福音 14:12–14"> 你问一问你的仆人，他们就会告诉你。愿我派去的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="我派去的——辅助词语。">b</a></sup>这些仆人在你眼前蒙恩，因为我们是在喜庆的日子来的。请你随手拿点什么，赐给你的仆人们和你儿子大卫。’”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王纪下 2:15; 历代志下 14:7; 创世记 8:4"> 大卫的仆人们到了，就提大卫的名对纳巴尔说了这一切话，然后在那里<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="在那里——辅助词语。">c</a></sup>等候。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 9:28; 以赛亚书 32:7; 撒母耳记上 22:7–8"> 纳巴尔回应大卫的仆人们说：“大卫是谁？耶西的儿子是谁？如今从主人那里逃走的仆人很多。</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 8:6; 加拉太书 6:10; 哥林多后书 6:9"> 我能拿我的饼、我的水，以及我为那些剪羊毛之人宰杀的肉，给我不知道来自哪里的人吗？”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 36:21–22; 撒母耳记下 24:13; 希伯来书 13:17"> 于是大卫的仆人们转身上路回去了。他们来到大卫那里，把这一切话都告诉了他。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 23:13; 箴言 25:8; 撒母耳记上 24:5–6"> 大卫对他的部下说：“各人佩上刀剑！”每个人就佩上刀剑，大卫也佩上刀剑。约有四百人跟着大卫上去，两百人留下看守辎重。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 13:10; 马可福音 15:29"> 纳巴尔的仆人中有一个年轻人告诉纳巴尔的妻子娅比盖说：“看哪，大卫从旷野派遣使者来向我们的主人问安，主人却辱骂了他们。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 25:7; 撒母耳记上 25:21; 腓立比书 2:15"> 其实那些人对我们非常好，我们在田野与他们往来的所有日子，没有受过他们欺负，也没有丢失过什么东西。</span>
<span className="v" id="v16" data-v="16" data-xref="约伯记 1:10; 出埃及记 14:22; 撒迦利亚书 2:5"> 我们在他们附近牧羊的所有日子，无论黑夜白天，他们都是我们四围的屏障。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 20:7; 申命记 13:13; 撒母耳记上 20:9"> 现在请你想好，看看该做什么，因为祸患一定会临到我们主人和他的全家。他是个恶劣的人，无法与他说话。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 16:1; 马太福音 5:25; 箴言 6:4–5"> 娅比盖赶快取来两百个饼、两皮袋酒、五只预备好的羊、五斗<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="五斗——原文作“五细亚”；相当于36公升。1细亚=7.3公升。">d</a></sup>烤麦子、一百个葡萄饼、两百个无花果饼，都放在驴背上，</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 32:20; 创世记 32:16; 箴言 31:11–12"> 然后对仆人们说：“你们在我前面先走，看哪，我跟在你们后面。”但她没有告诉丈夫纳巴尔。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王纪下 4:24"> 娅比盖骑着驴，正从山坡下来，看哪，大卫和他的部下也正迎着娅比盖下来，她就迎上他们。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 17:13; 以弗所书 4:31; 罗马书 12:21"> 此前大卫曾说：“我在旷野守护这人的一切，使他没有丢失过任何东西，实在是枉然的！他竟对我以恶报善。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 14:10; 撒母耳记上 20:13; 撒母耳记上 3:17"> 如果我留下属于这人的任何一个男丁<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="男丁——原文直译“对着墙撒尿的”。">e</a></sup>到早晨，就愿神处置大卫<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="大卫——依据七十士译本；马索拉文本作“大卫的仇敌”。">f</a></sup>，重重地处置！”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 20:41; 士师记 1:14; 约书亚记 15:18"> 娅比盖看见大卫，就赶快从驴子上下来，在大卫面前脸伏于地下拜。</span>
<span className="v" id="v24" data-v="24" data-xref="以斯帖记 8:3; 撒母耳记上 25:28; 撒母耳记下 14:9"> 娅比盖俯伏在大卫脚前，说：“我主啊，愿这罪责归于我！请容许你的女仆向你说话，求你听女仆的话：</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 25:17; 玛拉基书 2:2; 撒母耳记下 13:33"> 请我主不要把这恶劣人纳巴尔放在心上，因为他的名字怎样，他的为人也怎样；他的名字是纳巴尔，愚顽也伴随着他；我——你的女仆并没有看见我主所派来的仆人们。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 18:32; 罗马书 12:19–20; 创世记 20:6"> 现在，我主啊，我指着耶和华的永生和你的生命起誓：耶和华阻止了你流人的血，阻止了你亲手报仇。愿你的仇敌和那些谋害我主的人都像纳巴尔一样！</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 33:11; 撒母耳记上 30:26; 列王纪下 5:15"> 现在，请把婢女给我主带来的这些礼物赐给跟随我主的仆人们。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 18:17; 撒母耳记下 7:11; 撒母耳记上 24:11"> 求你饶恕女仆的过犯！耶和华必定为我主建立一个持久的家室，因为我主是为耶和华争战；在你一生的日子里，在你身上必找不到任何过犯。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约翰福音 17:21; 马太福音 10:29–30; 玛拉基书 3:17"> “即使有人起来追赶你，寻索你的性命，我主的性命却必裹藏在你的神耶和华生命的囊中。至于你仇敌的性命，耶和华必甩出去，像从投石索的兜囊中甩出去那样。</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 13:14; 诗篇 89:20; 撒母耳记上 23:17"> 当耶和华成就他向我主所应许的一切福份，任命你作以色列领袖的时候，</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 40:14; 罗马书 12:19; 路加福音 23:42"> 我主就不会因无故杀人流血、亲手报仇而心里内疚、良心受责备。耶和华赐福我主的时候，求你记念你的女仆。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="路加福音 1:68; 出埃及记 18:10; 诗篇 72:18"> 大卫对娅比盖说：“以色列的神耶和华是当受颂赞的！因他今天派遣了你来迎接我。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记上 25:26; 箴言 28:23; 箴言 9:9"> 你的见识是当受称赞的，你也当受称赞，因为你今天阻止了我流人的血，阻止了我亲手报仇。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记上 11:11; 撒母耳记上 25:26; 约书亚记 10:6"> 我指着那阻止我加害你的以色列之神耶和华的永生起誓：要不是你赶来迎接我，到早晨天亮时，属于纳巴尔的男丁<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="男丁——原文直译“对着墙撒尿的”。">g</a></sup>一个也不会存留！”</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 19:21; 撒母耳记上 20:42; 列王纪下 5:19"> 大卫从娅比盖手中接受了她带来的东西，对她说：“平平安安地回家去吧！看，我已经听了你的话，顾及了你的情面。”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="撒母耳记上 25:19; 撒母耳记下 13:23; 撒母耳记下 13:28"> 娅比盖回到纳巴尔那里，看哪，他在家里摆设宴席，像王的宴席一样。纳巴尔心情好，醉得很厉害，所以娅比盖无论大事小事都没有告诉他，直到早晨天亮。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="申命记 28:28; 撒母耳记上 25:34; 撒母耳记上 25:22"> 到了早晨，纳巴尔酒醒后，他的妻子把这些事告诉他，他就失去了意识<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="他就失去了意识——原文直译“他的心就在他里面死了”。">h</a></sup>，身体变得硬如石头。</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳记上 26:10; 列王纪下 15:5; 撒母耳记上 6:9"> 大约过了十天，耶和华打击纳巴尔，他就死了。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="撒母耳记上 25:26; 撒母耳记上 25:34; 箴言 22:23"> 大卫听说纳巴尔死了，就说：“耶和华是当受颂赞的！他为我伸了冤，除去了纳巴尔<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="纳巴尔——原文直译“纳巴尔的手”。">i</a></sup>加给我的羞辱，也拦阻了仆人行恶；耶和华使纳巴尔的恶归到他自己头上。”<br />大卫派人去对娅比盖说，要娶她为妻。</span>
<span className="v" id="v40" data-v="40" data-xref="创世记 24:51; 创世记 24:37–38"> 大卫的仆人们来到迦密见娅比盖，告诉她说：“大卫派遣我们到你这里来，要迎娶你作他的妻子。”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="提摩太前书 5:10; 约翰福音 13:3–5; 路得记 2:10"> 娅比盖就起来，脸伏于地下拜，说：“看哪，你的女仆愿意作婢女，为我主的仆人洗脚。”</span>
<span className="v" id="v42" data-v="42" data-xref="创世记 24:61–67; 诗篇 45:10–11"> 娅比盖急忙动身，骑上驴子，带着五个侍候她的使女，跟着大卫的使者们去，作了大卫的妻子。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="撒母耳记上 30:5; 约书亚记 15:56; 撒母耳记上 27:3"> 大卫先前娶了耶斯列人娅希暖，她与娅比盖都作了大卫的妻子；</span>
<span className="v" id="v44" data-v="44" data-xref="撒母耳记下 3:14; 撒母耳记上 18:27; 撒母耳记上 18:20"> 那时，扫罗已经把他的女儿米甲，就是大卫的妻子，嫁给了迦琳人拉伊的儿子帕尔提。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 15:35; 历代志下 28:18; 历代志上 11:13"> 那时非利士人招聚军兵出战。他们聚集在犹大的梭哥，在梭哥和亚西加之间的以弗-大悯扎营。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 21:9; 撒母耳记上 17:19"> 扫罗和以色列人也聚集，在以拉溪谷扎营，摆阵迎战非利士人。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3"> 非利士人站在这边山上，以色列人站在那边山上，他们中间有溪谷。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 11:22; 撒母耳记下 21:16–22; 历代志上 20:4–8"> 从非利士营地中出来一个挑战的人，名叫歌利亚，是迦特人，身高六肘又一拃<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="六肘又一拃——相当于3公尺。1肘=45.7公分；1拃=约20公分。">a</a></sup>。</span>
<span className="v" id="v5" data-v="5"> 他头戴铜盔，身穿鳞状铜铠甲，这铠甲重五千谢克尔<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="五千谢克尔——相当于57公斤。1谢克尔=11.4公克。">b</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 17:45; 历代志下 9:15; 列王纪上 10:16"> 他双腿上有铜胫甲，两肩之间有铜标枪。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 21:19; 撒母耳记上 17:41; 历代志上 11:23"> 他长矛的杆粗如织布机轴，矛头的铁重六百谢克尔<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="六百谢克尔——相当于6.8公斤。1谢克尔=11.4公克。">c</a></sup>。有一个拿盾牌的人，走在他前面。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 8:17; 历代志上 21:3; 撒母耳记上 17:26"> 歌利亚站住，向以色列军阵叫喊，对他们说：“你们出来摆开战阵是为了什么呢？我不是非利士人吗？你们不是扫罗的仆人吗？你们挑选一个人，让他下到我这里来！</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 11:1"> 如果他能与我交战，击杀了我，我们就作你们的奴仆；如果我胜过他，击杀了他，你们就作我们的奴仆，服事我们。”</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 17:25–26; 撒母耳记上 17:45; 撒母耳记上 17:36"> 那非利士人又说：“今天我辱骂以色列的军队。你们派一个人到我这里，让我们对战！”</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 1:9; 申命记 31:8; 箴言 28:1"> 扫罗和全体以色列人听见那非利士人的这些话就都丧胆，极其害怕。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 16:10–11; 创世记 35:19; 撒母耳记上 16:18"> 大卫是犹大伯利恒一个以法他人的儿子；这以法他人名叫耶西，有八个儿子。扫罗年间，耶西已经老了，上了年纪<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="上了年纪——依据七十士译本；或译作“在民中年高位重”。">d</a></sup>。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 2:13; 撒母耳记下 21:21; 撒母耳记上 17:28"> 耶西的三个大的儿子跟随扫罗出征；出征的三个儿子的名字是：长子以利押，次子亚比拿达，三子沙玛。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 16:11; 创世记 25:23"> 大卫是最小的儿子，那三个大的跟随了扫罗，</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 16:11; 撒母耳记上 16:19–23"> 大卫时常去扫罗那里，又返回伯利恒牧放他父亲的羊群。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马太福音 4:2; 路加福音 4:2"> 那非利士人每天早晨和傍晚都站出来骂阵<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="骂阵——辅助词语。">e</a></sup>，一连四十天。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 25:18; 撒母耳记下 17:28; 路得记 2:14"> 有一天，耶西对他儿子大卫说：“你现在要给你的哥哥们带去这一斗<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一斗——原文作“一伊法”。1伊法=22公升。">f</a></sup>烤麦子和这十个饼，赶快去营地你哥哥们那里；</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 37:14; 撒母耳记上 16:20; 撒母耳记下 17:29"> 同时也给千夫长带上这十块奶酪。你要看看你哥哥们是否平安，带回来一个他们的信物。</span>
<span className="v" id="v19" data-v="19"> 扫罗与他们以及以色列众人正在以拉溪谷与非利士人争战。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 26:5; 路加福音 19:43; 以弗所书 6:1–2"> 于是大卫清早起来，把羊群交托给一个看守的人，就照着耶西所吩咐的，带上东西出发了。<br />他来到行营时，军队正出去摆阵，呐喊出战。</span>
<span className="v" id="v21" data-v="21"> 以色列人和非利士人摆阵，两军对峙。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 10:5–6; 士师记 18:15; 以赛亚书 10:28"> 大卫把他带的东西交托在看守辎重的人手中，就跑向军阵，去向他的哥哥们问安。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 17:8–10"> 他正与他们说话的时候，看哪，那个挑战的人从非利士军阵中上来了。这非利士人名叫歌利亚，来自迦特。他又说那些同样的话；大卫都听见了。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记上 13:6–7; 利未记 26:36; 以赛亚书 7:2"> 以色列众人看见那人，就从他面前逃跑，极其害怕。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约书亚记 15:16; 启示录 2:7; 启示录 3:12"> 以色列人中有人说：“你们看见上来的这人吗？他上来是为了羞辱以色列的。有谁能击杀这人，王必赏赐他极大的财富，并且会把女儿赐给他，还会使他的父家在以色列免除赋税。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="申命记 5:26; 撒母耳记上 11:2; 撒母耳记上 14:6"> 大卫问站在旁边的人说：“如果有人击杀这非利士人，除掉以色列的羞辱，他会被怎样对待呢？这未受割礼的非利士人是谁，竟敢辱骂永生神的军队！”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 17:25"> 人们就用先前同样的话回答他：击杀这人的，会被如此如此对待。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马太福音 10:36; 创世记 37:11; 箴言 18:19"> 大卫与那些人说话时，他的大哥以利押听见了，以利押就对大卫发怒，说：“你为什么下来这里呢？你把旷野里那些小羊交托给谁了？我知道你的狂傲和恶意，你下来就是为了看打仗！”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="彼得前书 3:9; 哥林多前书 2:15; 箴言 15:1"> 大卫说：“我究竟做了什么呢？不就是问了一句话吗？”</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 17:26–27"> 于是转身离开他哥哥，到别人面前问了同样的问题，人们还是以先前同样的话回答他。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="箴言 22:29"> 有人听见大卫所说的话，报告到扫罗面前；扫罗派人把大卫带来。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 16:18; 申命记 20:1–3; 诗篇 3:6"> 大卫对扫罗说：“谁也不要因那人而丧胆，你的仆人必去与那非利士人对战！”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="民数记 13:31; 申命记 9:2; 启示录 13:4"> 扫罗对大卫说：“你不能去与那非利士人对战，因为你还是个少年，而他从年幼时就是战士。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> 大卫对扫罗说：“你的仆人是为父亲牧羊的，当狮子或熊过来，从羊群中叼走一只羔羊时，</span>
<span className="v" id="v35" data-v="35" data-xref="阿摩司书 3:12; 提摩太后书 4:17–18; 但以理书 6:22"> 我就出去追赶它，攻击它，把羊从它口中解救出来。它起来攻击我，我就揪住它的胡须，击打它，把它杀死。</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳记上 17:10; 使徒行传 5:38–39; 罗马书 2:28–29"> 无论狮子还是熊，你的仆人都击杀过。这未受割礼的非利士人也必像它们中的一个，因为他辱骂永生神的军队。”</span>
<span className="v" id="v37" data-v="37" data-xref="提摩太后书 4:17–18; 诗篇 138:7–8; 哥林多后书 1:9–10"> 大卫又说：“从狮子爪和熊掌解救我的耶和华，他必解救我脱离这非利士人的手。”<br />于是扫罗对大卫说：“你去吧，愿耶和华与你同在！”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> 扫罗给大卫穿上自己的战袍，把铜盔戴在他头上，又给他穿上铠甲。</span>
<span className="v" id="v39" data-v="39" data-xref="撒迦利亚书 4:6; 哥林多后书 10:4–5; 何西阿书 1:7"> 大卫把扫罗的刀佩带在战袍上，试着走了一下，因为他没有穿过；然后大卫对扫罗说：“我穿戴这些不能走动，因为我没有穿过。”于是大卫把铠甲从身上脱了下来。</span>
<span className="v" id="v40" data-v="40" data-xref="哥林多前书 1:27–29; 马太福音 10:10; 士师记 15:15–16"> 大卫手里拿着自己的木杖，从溪中挑选了五块光滑的石头，把它们放进囊袋——牧人用的袋子里；然后手拿投石索，就迎向那非利士人。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41"> 那非利士人也朝着大卫走来，越来越近；在他前面有一个拿盾牌的人。</span>
<span className="v" id="v42" data-v="42" data-xref="撒母耳记上 16:12; 撒母耳记上 17:33; 诗篇 123:3–4"> 那非利士人观望，看见大卫，就轻视他，因为他还是个少年，面色红润、容貌俊美。</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳记下 9:8; 撒母耳记下 3:8; 撒母耳记上 24:14"> 那非利士人对大卫说：“我是一条狗吗？你竟然拿木杖来对付我！”于是那非利士人指着自己的神诅咒大卫。</span>
<span className="v" id="v44" data-v="44" data-xref="以西结书 28:9–10; 箴言 18:12; 列王纪上 20:10–11"> 然后那非利士人对大卫说：“过来吧！我要把你的肉给天空的飞鸟和田野的走兽。”</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="哥林多后书 10:4; 历代志下 32:8; 哥林多后书 3:5"> 大卫对那非利士人说：“你是靠着刀剑、长矛和标枪来对付我，而我是靠着你所辱骂的以色列军队的神——万军之耶和华的名来对付你。</span>
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 52:10; 约书亚记 4:24; 列王纪下 19:19"> 今天耶和华必把你交在我手中，我要击杀你，从你身上砍下你的头。今天我还要把非利士军兵的尸首给天空的飞鸟和地上的走兽。这样全地都会知道：以色列中有一位神；</span>
<span className="v" id="v47" data-v="47" data-xref="诗篇 44:6–7; 撒迦利亚书 4:6; 何西阿书 1:7"> 这全体会众也会知道：耶和华不是靠着刀剑和长矛施行拯救，战争的胜败在于耶和华。他必把你们交在我们手中！”</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="箴言 28:1; 诗篇 27:1"> 那非利士人起身，走过来迎战大卫的时候，大卫也快速跑向战场迎战那非利士人。</span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前书 1:27–28; 列王纪下 9:24; 列王纪上 22:34"> 大卫把手伸进袋子里，取出一块石头，用投石索甩出去，击中了那非利士人，打在他的额头上。石头陷入他的额头，他就面朝地仆倒。</span>
<span className="v" id="v50" data-v="50" data-xref="士师记 15:15; 撒母耳记上 17:39; 撒母耳记上 23:21"> 这样大卫用投石索和石头胜了那非利士人。大卫手中没有刀，却击倒了那非利士人，杀了他。</span>
<span className="v" id="v51" data-v="51" data-xref="希伯来书 11:34; 撒母耳记上 21:9; 撒母耳记下 23:21"> 大卫跑过去，站在那非利士人身旁，抓住他的刀，从鞘中拔出来，杀了他，然后砍下他的头。非利士人看见他们的勇士死了，就逃跑。</span>
<span className="v" id="v52" data-v="52" data-xref="约书亚记 15:11; 约书亚记 15:33–36; 约书亚记 15:45–46"> 以色列人和犹大人起来呐喊，追击非利士人，直到溪谷<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="溪谷——七十士译本和有些古抄本作“迦特”。">g</a></sup>的岔口和以革伦的城门。非利士被杀的人倒在通往沙拉音的路上，直到迦特和以革伦。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="耶利米书 4:20; 列王纪下 7:7–16; 耶利米书 30:16"> 以色列人追击非利士人回来，抢掠了他们的营地。</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及记 16:33; 约书亚记 4:7–8; 撒母耳记上 21:9"> 大卫拿走那非利士人的头，带到耶路撒冷，而把那人的兵器存放在自己的帐篷里。</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="撒母耳记上 16:21–22; 撒母耳记上 17:58"> 当时扫罗看见大卫出去迎战那非利士人，就问元帅押尼珥：“押尼珥，这少年是谁的儿子？”<br />押尼珥回答：“王啊，我指着王的生命起誓：我不知道。”</span>
</div>
<div className="bp">
<span className="v" id="v56" data-v="56"> 王说：“你问问这少年是谁的儿子。”</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="撒母耳记上 17:54"> 当大卫击杀了那非利士人回来时，押尼珥就带他来到扫罗面前，他手里还提着那非利士人的头。</span>
<span className="v" id="v58" data-v="58" data-xref="撒母耳记上 17:12; 撒母耳记上 16:18–19"> 扫罗问大卫：“少年人，你是谁的儿子？”<br />大卫回答：“我是你仆人伯利恒人耶西的儿子。”</span>
</div>
</div>

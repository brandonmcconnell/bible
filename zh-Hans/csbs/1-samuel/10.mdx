<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 16:13; 诗篇 78:71; 撒母耳记上 9:16"> 撒母耳拿了一瓶膏油，浇在扫罗头上，然后亲吻他，说：“耶和华不是已经膏立你为领袖掌管他的继业吗？</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 9:3–5; 创世记 35:19–20; 约书亚记 18:28"> 今天你离开我以后，将在便雅悯境内的谢撒，拉结的坟墓附近遇见两个人。他们会对你说：‘你去寻找的那几头母驴已经找到了。看哪，你父亲已经不操心驴的事，反而为你们担忧，说：“我儿子的情况，我该怎么办呢？”’</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 35:3; 创世记 35:1; 创世记 28:22"> “你从那里经过再往前走，来到他泊的橡树，在那里会遇见三个上伯特利拜见神的人，一个带着三只小山羊，一个带着三块饼，一个带着一皮袋酒。</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 18:15"> 他们会向你问安，然后给你两块饼，你要从他们手中接过来。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪下 3:15; 撒母耳记上 13:3; 撒母耳记上 19:20"> “此后你要去神的山，那里有非利士的驻军。你到那城的时候，会遇见一队先知正从高坛下来，他们都在说神言；在他们前面有弹里拉琴的、击鼓的、吹笛的、弹竖琴的。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 10:10; 撒母耳记上 19:23–24; 民数记 11:25"> 耶和华的灵会大大临到你，你就会与他们一同说神言，转变为另一个人。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 6:12; 约书亚记 1:5; 以赛亚书 7:14"> 这些征兆临到你的时候，你手所当做的，只管去做，因为神与你同在。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 11:14–15; 撒母耳记上 13:4; 撒母耳记上 13:8–15"> 你要在我之前下到吉甲，看哪，我也将下到你那里去献上燔祭，献上平安祭。你要等候七天，直到我来到你那里，指示你当做的事。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 38:7–8; 撒母耳记上 10:2–6; 士师记 7:11"> 扫罗转身离开撒母耳的时候，神就把他的心转变为另一颗心，这一切征兆都在那日发生了。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 10:5–6; 撒母耳记上 19:20–24"> 他来到那座山，看哪，有一队先知迎见他。神的灵大大临到他，他就在他们中间说神言。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 19:24; 约翰福音 7:15; 马太福音 13:54–55"> 所有以前认识扫罗的人，他们都看见扫罗与众先知一同说神言，就彼此说：“基士的儿子发生了什么事呢？难道扫罗也列在先知中吗？”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 54:13; 约翰福音 6:45; 雅各书 1:17"> 那里的一个人回应说：“这些人的师父<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="师父——原文直译“父亲”。">a</a></sup>是谁呢？”<br />因此这成了一句俗语：“难道扫罗也列在先知中吗？”</span>
<span className="v" id="v13" data-v="13"> 扫罗说神言结束后，就前往高坛。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 14:50; 列王纪下 5:25; 撒母耳记上 9:3–10"> 后来扫罗的叔叔问扫罗和他的仆人：“你们到哪里去了呢？”<br />他回答：“寻找驴子去了，我们没有找到，就去见撒母耳。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 扫罗的叔叔说：“请告诉我，撒母耳对你们说了什么。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="箴言 29:11; 士师记 14:6; 撒母耳记上 9:20"> 扫罗回答他叔叔：“他清楚地告诉我们，驴已经找到了。”至于撒母耳所说有关王位的事，扫罗没有告诉他。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="士师记 20:1; 撒母耳记上 7:5–6"> 撒母耳招聚民众到米斯巴，到耶和华那里。</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 6:8–9; 尼希米记 9:27–28; 士师记 2:1"> 他对以色列子民说：“以色列的神耶和华如此说：我把以色列从埃及带上来，解救你们脱离埃及的手，脱离压迫你们的各国的手。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 12:12; 撒母耳记上 8:19; 约书亚记 24:1"> 今天你们却厌弃你们的神，就是使你们脱离一切灾祸和患难的拯救者；你们对他说：‘求你立一个王统治我们。’现在，你们要按着自己的支派和宗族，站在耶和华面前。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约书亚记 7:16–18; 使徒行传 1:24–26; 撒母耳记上 14:41"> 撒母耳让以色列所有的支派都上前来，便雅悯支派被抽中；</span>
<span className="v" id="v21" data-v="21"> 然后让便雅悯支派按着家族上前来，玛特利家族被抽中；最后基士的儿子扫罗被抽中。民众就寻找他，却找不到。</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 27:21; 士师记 20:18; 撒母耳记上 23:2–4"> 于是他们再次求问耶和华：“那人来了这里没有？”<br />耶和华说：“看哪，他躲藏在行李堆中。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 9:2; 撒母耳记上 16:7; 撒母耳记上 17:4"> 他们就跑去，把扫罗从那里带出来。他站在民众当中，比众人高出一头。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 1:25; 列王纪上 1:39; 撒母耳记下 21:6"> 撒母耳对全体民众说：“你们看到耶和华所拣选的人了吗？在全民中，实在没有人能与他相比。”<br />民众都呼喊说：“愿王万岁！”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 8:11–18; 申命记 17:14–20; 罗马书 13:1–7"> 于是撒母耳把王国的法规向民众宣告了，又写在书卷上，放在耶和华面前。然后撒母耳遣散全体民众，让各人回自己的家去。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="撒母耳记上 11:4; 约书亚记 18:28; 撒母耳记上 15:34"> 扫罗也回基比亚自己的家去了，那些心里被神感动的勇士们，也与扫罗一同去了。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 13:13; 历代志下 17:5; 列王纪上 10:25"> 然而有些卑劣之徒说：“这人怎么能拯救我们呢？”他们就轻视他，也没有给他带礼物，扫罗却保持沉默。</span>
</div>

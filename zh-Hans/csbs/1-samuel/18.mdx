<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 20:17; 箴言 18:24; 撒母耳记上 18:3"> 大卫和扫罗说完了话以后，约拿单的心就与大卫的心相契合，约拿单爱他如同爱自己的性命。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 17:15; 撒母耳记上 16:21–23"> 从那天起，扫罗留下大卫，不让他回他父亲的家。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 20:8–17; 撒母耳记上 20:42; 撒母耳记下 21:7"> 约拿单与大卫结为盟友，因为他爱大卫如同爱自己的性命。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 41:42; 路加福音 15:22; 以斯帖记 6:8–9"> 约拿单脱下身上的外袍给了大卫，又把他的战袍，甚至刀、弓、腰带，都给了大卫。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 18:30; 撒母耳记上 18:14–15; 歌罗西书 4:5"> 大卫出征，在扫罗派遣他去做的所有事上都通达。扫罗就立他作战士们的统领，这在全体军兵和扫罗的臣仆们眼中都看为好。</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 15:20; 士师记 11:34; 诗篇 68:25"> 在大卫击杀了那非利士人之后，大家返回的时候，妇女们从以色列的各城镇出来唱歌跳舞，伴着铃鼓、欢呼、三弦琴来迎接扫罗王。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 21:11; 撒母耳记上 29:5; 出埃及记 15:21"> 妇女们欢庆歌唱，说：<br /><span className="pl pl-1">“扫罗击杀千千，</span><br /><span className="pl pl-1">大卫击杀万万！”</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 15:28; 箴言 13:10; 雅各书 4:5"> 扫罗非常恼火，这话使他很不高兴，就说：“他们归给大卫万万，而归给我千千，只剩王位还没给他了！”</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 7:22; 创世记 31:2; 马太福音 20:15"> 从那天起，扫罗一直猜忌大卫。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 19:9; 帖撒罗尼迦后书 2:11; 列王纪上 18:29"> 第二天，从神那里来的搅扰之灵大大临到扫罗，他在宫殿中说神言<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="说神言——或译作“胡言乱语”。">a</a></sup>。大卫一如往日手弹竖琴，扫罗手里拿着长矛，</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 20:33; 以赛亚书 54:17; 路加福音 4:30"> 扫罗掷出长矛，心里说：“我要把大卫刺穿，钉在墙上。”但大卫两次都从他面前躲开了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 18:15; 撒母耳记上 18:29; 撒母耳记上 16:13–14"> 扫罗惧怕大卫，因为耶和华与大卫同在，却离开了扫罗。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 5:2; 诗篇 121:8; 撒母耳记上 18:16–17"> 所以扫罗把大卫从身边调离，立他为千夫长，他就领军出入。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 39:23; 马太福音 28:20; 撒母耳记上 16:18"> 大卫在他一切的道路上都通达，因为耶和华与他同在。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各书 3:17; 歌罗西书 4:5; 雅各书 1:5"> 扫罗见他行事极其通达，就惧怕他。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 18:5; 民数记 27:17; 列王纪上 3:7"> 但以色列和犹大都爱大卫，因为是他带领他们出入。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 17:25; 撒母耳记上 25:28; 撒母耳记上 18:25"> 扫罗对大卫说：“看哪，我把我的大女儿米拉给你为妻，只要你作我的勇士，为耶和华作战。”因为扫罗想：“我的手不对付他，让非利士人的手对付他吧！”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 7:18; 撒母耳记上 9:21; 撒母耳记上 18:23"> 大卫对扫罗说：“我是谁？我的出身、我父亲的家族在以色列算什么，我竟然作王的女婿！”</span>
<span className="v" id="v19" data-v="19" data-xref="士师记 7:22; 撒母耳记下 21:8; 士师记 14:20"> 到了扫罗的女儿米拉该嫁给大卫的时候，她却被许配给米何拉人亚得列为妻。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 18:28"> 扫罗的女儿米甲爱大卫；有人把这事告诉了扫罗，这事在他眼中看为好。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 18:17; 出埃及记 10:7; 耶利米书 9:8"> 他想：“我要把米甲嫁给大卫，使她成为大卫的陷阱，好让非利士人的手对付他。”于是扫罗对大卫说：“今天你有第二次机会作我的女婿。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="诗篇 36:1–3; 诗篇 55:21; 撒母耳记下 13:28–29"> 扫罗吩咐他的臣仆：“你们要私下对大卫说：‘看哪，王喜欢你，他所有的臣仆们也爱你，如今你就作王的女婿吧。’”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="诗篇 119:141; 箴言 14:20; 传道书 9:15–16"> 扫罗的臣仆们就把这些话说给大卫听。大卫说：“难道作王的女婿在你们眼中算为小事吗？我不过是个贫穷、卑微的人。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 扫罗的臣仆们向扫罗报告说，大卫说了这些话。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 34:12; 撒母耳记上 18:17; 撒母耳记上 14:24"> 扫罗就说：“你们对大卫这样说：‘王想要的不是聘金，他只要一百个非利士人的包皮，为要报复王的仇敌。’”这是扫罗的谋算，要让大卫在非利士人手中倒下。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="撒母耳记上 18:21"> 扫罗的臣仆们把这些事告诉了大卫；作王的女婿这事在大卫眼中看为好。日期未满，</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记下 3:14; 士师记 14:19; 撒母耳记上 18:13"> 大卫就动身，带着他的部下去击杀了两百个非利士人。大卫把他们的包皮带来，满数交给王，为要作王的女婿。于是扫罗把他的女儿米甲给大卫为妻。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 24:20; 撒母耳记上 26:25; 创世记 37:8–11"> 扫罗看见并知道耶和华与大卫同在，而且自己的女儿米甲也爱大卫，</span>
<span className="v" id="v29" data-v="29" data-xref="传道书 4:4; 约翰福音 11:53; 雅各书 2:19"> 扫罗就更加惧怕大卫，终生与大卫为敌。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 18:5; 撒母耳记下 11:1; 彼得前书 2:4"> 非利士人的首领们经常出兵，每逢他们出战的时候，大卫比扫罗所有的臣仆更有智慧，因此他的名极受尊重。</span>
</div>

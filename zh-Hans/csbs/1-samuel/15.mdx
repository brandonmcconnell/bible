<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="csbs" data-translation-id="cmn_csbs" data-translation-label="CSBS" data-book="1SA" data-book-slug="1-samuel" data-book-name="撒母耳记上" data-chapter="15" data-verses="35">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 9:16; 撒母耳记上 12:14; 诗篇 2:10–11"> 撒母耳对扫罗说：“耶和华派遣我来膏立你为王，统治他的子民以色列，所以，你现在要听从耶和华的命令。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 25:17–19; 出埃及记 17:8–16; 民数记 24:20"> 万军之耶和华如此说：‘我要清算亚玛力人对以色列人所做的事，就是当以色列人从埃及上来时，亚玛力人在路上攻击他们。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 20:16–18; 民数记 24:20; 民数记 31:17"> 现在你要去攻打亚玛力人，把他们所有的一切都灭绝净尽，不可怜恤他们；无论是男女、幼童、婴儿，还是牛羊、骆驼、驴子，都要杀灭。’”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约书亚记 15:24; 撒母耳记上 11:8; 撒母耳记上 13:15"> 于是扫罗召集军队，在提拉因数点他们，有步兵二十万，还有犹大人一万。</span>
<span className="v" id="v5" data-v="5"> 扫罗来到亚玛力人的城，埋伏在溪谷中。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 1:16; 民数记 10:29–32; 出埃及记 18:19"> 扫罗对基尼人说：“你们走，离开亚玛力人下去吧，免得我把你们与他们一同除灭了。当全体以色列人从埃及上来时，你们曾经向他们施慈爱。”于是基尼人从亚玛力人中间离开了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="创世记 16:7; 创世记 25:18; 撒母耳记上 14:48"> 扫罗击杀亚玛力人，从哈腓拉直到埃及东边的书珥，</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 30:1; 以斯帖记 3:1; 民数记 24:7"> 活捉了亚玛力王亚甲，把所有的民众都灭绝于刀刃之下。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 15:15; 撒母耳记上 15:19; 撒母耳记上 15:3"> 但扫罗和军兵顾惜亚甲和上好的牛羊、肥牛犊、羊羔以及一切美好的东西，不愿意把这些灭绝净尽；至于一切轻贱的、没有价值的东西，他们都灭绝了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 那时耶和华的话语临到撒母耳，说：</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 13:13; 创世记 6:6; 撒母耳记下 24:16"> “我后悔立扫罗为王了，因为他转离不跟从我，也不执行我的命令。”撒母耳为此很苦恼，整夜向耶和华哀求。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约书亚记 15:55; 撒母耳记下 18:18; 撒母耳记上 25:2"> 撒母耳清早起来去见扫罗，有人告诉撒母耳说：“扫罗去了迦密，看哪，他为自己竖立了一座纪念碑，然后转身下到吉甲去了。”</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 17:2; 路得记 3:10; 箴言 31:31"> 撒母耳到了扫罗那里，扫罗对他说：“愿你蒙耶和华祝福！我已经执行了耶和华的命令。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 3:13–15; 耶利米书 2:18–19; 耶利米书 2:34–37"> 撒母耳说：“那么我耳中这羊叫的声音、我所听见的牛叫声，是怎么回事呢？”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 15:21; 撒母耳记上 15:9; 出埃及记 32:22–23"> 扫罗说：“这些是军兵从亚玛力人那里带回来的，因为他们顾惜上好的牛羊，为要献祭给耶和华你的神。至于其余的，我们都已经灭绝了。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 9:27; 列王纪上 22:16; 撒母耳记上 12:7"> 撒母耳对扫罗说：“住口吧！让我把耶和华夜间对我说的话告诉你。”<br />扫罗对他说：“请说。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 10:22; 撒母耳记上 9:21; 撒母耳记上 15:1–3"> 撒母耳说：“虽然你看自己微小，但你难道不是以色列众支派的首领吗？耶和华膏立你为以色列的王。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:29; 创世记 13:13; 创世记 15:16"> 耶和华派给你使命，说：‘你去，把那些罪人——亚玛力人灭绝净尽。你要与他们争战，直到灭绝他们。’</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 14:32; 历代志下 33:6; 历代志下 36:12"> 你为什么没有听从耶和华的话，而冲向战利品，做耶和华眼中看为恶的事呢？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 15:13; 马太福音 19:20; 罗马书 10:3"> 扫罗对撒母耳说：“我就是听从了耶和华的话，完成了耶和华所派给我的使命。我把亚玛力王亚甲抓来了，也灭绝了亚玛力人。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 15:15; 出埃及记 32:22–23; 创世记 3:13"> 军兵还从战利品中取了一些牛羊，是当灭之物中那些上好的，要在吉甲献祭给耶和华你的神。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="何西阿书 6:6; 诗篇 51:16–17; 箴言 21:3"> 撒母耳说：<br /><span className="pl pl-1">“耶和华喜悦燔祭和祭物，</span><br /><span className="pl pl-1">难道与喜悦人听从耶和华的话等同吗？</span><br /><span className="pl pl-1">看哪，听从胜过献祭，</span><br /><span className="pl pl-1">听命胜过公绵羊的脂油；</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 28:16; 撒母耳记上 13:14; 利未记 20:6"> <span className="pl pl-1">要知道，悖逆如同占卜的罪，</span><br /><span className="pl pl-1">顽梗就像拜偶像的恶。</span><br /><span className="pl pl-1">你既然厌弃耶和华的话，</span><br /><span className="pl pl-1">耶和华也厌弃你作王。”</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 12:13; 以赛亚书 51:12–13; 民数记 22:34"> 扫罗对撒母耳说：“我犯罪了！我确实违背了耶和华的吩咐和你的话语。因为我惧怕军兵，就听了他们的话。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 10:17"> 现在，请你饶恕我的罪，与我一同回去，让我敬拜耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="何西阿书 4:6; 撒母耳记上 13:14; 撒母耳记上 16:1"> 撒母耳对扫罗说：“我不与你一同回去，因为你厌弃了耶和华的话，耶和华也厌弃你作以色列的王。”</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 11:30–31"> 撒母耳转身要走，扫罗抓住他外袍的衣摆，外袍被撕裂了。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 28:17–18; 使徒行传 13:22; 但以理书 4:32"> 撒母耳就对他说：“耶和华今天从你身上撕去了以色列的王国，赐给了你的邻人，他比你好。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 24:14; 民数记 23:19; 提多书 1:2"> 以色列的永恒者不说谎，也不改变心意；因为他不像人那样会改变心意。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约翰福音 5:44; 约翰福音 12:43; 以赛亚书 29:13"> 扫罗说：“我犯罪了！现在请你在我子民的长老们面前和以色列人面前尊重我，与我一同回去，让我敬拜耶和华你的神。”</span>
<span className="v" id="v31" data-v="31"> 于是撒母耳跟扫罗回去，扫罗就敬拜耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="启示录 18:7; 帖撒罗尼迦前书 5:3; 耶利米书 48:44"> 撒母耳说：“把亚玛力王亚甲带到我这里来！”<br />亚甲欢欢喜喜地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="欢欢喜喜地——或译作“被捆绑着”。">a</a></sup>来到他那里，心里想：“死亡的苦痛必定过去了！”</span>
</div>
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="士师记 1:7; 创世记 9:6; 马太福音 7:2"> 撒母耳说：<br /><span className="pl pl-1">“你的刀剑怎样使女人丧子，</span><br /><span className="pl pl-1">你的母亲也必怎样在女人中丧子。”</span><br />于是撒母耳在吉甲，在耶和华面前把亚甲砍碎。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="撒母耳记上 11:4; 撒母耳记上 7:17"> 然后撒母耳回拉玛，扫罗也回自己的家，上扫罗的基比亚去了。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记上 15:11; 撒母耳记上 19:24; 撒母耳记上 16:1"> 撒母耳直到死的日子，再也没有见扫罗，但撒母耳为扫罗悲恸。耶和华后悔立扫罗为以色列的王。</span>
</div>
</div>

</div>

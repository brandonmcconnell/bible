<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="路加福音 1:46–56; 诗篇 13:5; 以赛亚书 12:2–3"> 那时哈娜祷告说：<br /><span className="pl pl-1">“我的心因耶和华而欢乐，</span><br /><span className="pl pl-1">我的角因耶和华而高举；</span><br /><span className="pl pl-1">我的口向众仇敌张大，</span><br /><span className="pl pl-1">因我以你的救恩欢喜。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 22:32; 以赛亚书 44:6; 诗篇 86:8"> <span className="pl pl-1">没有像耶和华那样的圣者，</span><br /><span className="pl pl-1">除你以外实在没有；</span><br /><span className="pl pl-1">没有磐石像我们的神。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 8:13; 列王纪上 8:39; 箴言 24:12"> <span className="pl pl-1">你们不要再说高傲自大的话，</span><br /><span className="pl pl-1">不要让傲慢的话从你们口中出来，</span><br /><span className="pl pl-1">因为耶和华是全知的神，</span><br /><span className="pl pl-1">人的行为都被他衡量。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 76:3; 诗篇 37:15; 诗篇 46:9"> <span className="pl pl-1">勇士的弓被折断，</span><br /><span className="pl pl-1">软弱的却以力量束腰；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 15:9; 路加福音 1:53; 诗篇 113:9"> <span className="pl pl-1">饱足的为食物受雇，</span><br /><span className="pl pl-1">饥饿的却不再挨饿；</span><br /><span className="pl pl-1">不能怀孕的生了七个，</span><br /><span className="pl pl-1">儿子众多的反倒衰败。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="申命记 32:39; 以赛亚书 26:19; 启示录 1:18"> <span className="pl pl-1">耶和华使人死，也使人活；</span><br /><span className="pl pl-1">使人下阴间，也使人从那里上来。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 75:7; 约伯记 5:11; 申命记 8:17–18"> <span className="pl pl-1">耶和华使人贫穷，也使人富有；</span><br /><span className="pl pl-1">使人降卑，也使人升高。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 113:7–8; 但以理书 2:48; 雅各书 2:5"> <span className="pl pl-1">他从尘土中兴起贫弱者，</span><br /><span className="pl pl-1">从粪堆中提拔贫穷人，</span><br /><span className="pl pl-1">要使他们与高贵人同坐，</span><br /><span className="pl pl-1">使他们继承荣耀的宝座；</span><br /><span className="pl pl-1">因为大地的支柱都属于耶和华，</span><br /><span className="pl pl-1">他把世界安置在其上。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 121:3; 诗篇 91:11–12; 诗篇 33:16–17"> <span className="pl pl-1">他必保守他忠信者的脚步，</span><br /><span className="pl pl-1">恶人却在黑暗中灭亡；</span><br /><span className="pl pl-1">人得胜不是靠着力量。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 2:9; 诗篇 89:24; 诗篇 18:13–14"> <span className="pl pl-1">耶和华必击碎那些与他抗争的，</span><br /><span className="pl pl-1">他将从天上打雷攻击他们。</span><br /><span className="pl pl-1">耶和华必审判地极；</span><br /><span className="pl pl-1">他将赐力量给他所立的</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="所立的——辅助词语。">a</a></sup><br /><span className="pl pl-1">王，</span><br /><span className="pl pl-1">使他受膏者的角高举。”</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 3:1; 撒母耳记上 2:18; 撒母耳记上 1:28"> 以利加拿一行<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一行——辅助词语。">b</a></sup>回拉玛自己的家去了，而那孩子留在祭司以利面前事奉耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="罗马书 1:28–30; 耶利米书 2:8; 士师记 2:10"> 以利的两个儿子是卑劣之徒，不尊重<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="不尊重——原文直译“不认识”。">c</a></sup>耶和华，</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 7:29–34"> 也不尊重祭司对民众的规矩。每当有人献祭，正在煮肉的时候，祭司的仆人就会来，手拿三齿的叉子，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 29:27–28; 以赛亚书 56:11; 撒母耳记上 2:29"> 插入盆或筐子，或大锅小锅，叉子插上来的，祭司全都拿去归自己。他们就是这样对待所有来到示罗的以色列人。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 3:16; 利未记 3:3–5; 罗马书 16:18"> 甚至在烧献脂肪以前，祭司的仆人也会来，对献祭的人说：“把祭肉交给祭司去烤，他不接受你煮过的肉，他只要生肉。”</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 7:23–25; 利未记 3:16; 彼得前书 5:2–3"> 如果献祭的人说“必须先烧献了脂肪，然后你可以随意拿”，祭司的仆人就会说“不，你现在就给我，不然我就抢了”。</span>
<span className="v" id="v17" data-v="17" data-xref="玛拉基书 2:7–9; 创世记 13:13; 玛拉基书 2:13"> 这两个年轻祭司的罪在耶和华面前极大，因为他们藐视耶和华的供物。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 3:1; 出埃及记 28:4; 撒母耳记上 2:11"> 当时，撒母耳还是个孩子，穿戴着细麻布的以弗得，在耶和华面前事奉。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 1:3; 撒母耳记上 1:21; 出埃及记 23:14"> 他母亲每年都会为他做一件小外袍，与丈夫一起上来献年祭的时候就带给他。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 1:27–28; 路加福音 2:34; 路得记 4:11"> 以利就会祝福以利加拿和他妻子，说：“愿耶和华藉着这妇人再赐给你后裔，代替她求来献给耶和华的这孩子。”然后，他们就回自己的地方去了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 2:40; 撒母耳记上 3:19; 创世记 21:1"> 耶和华眷顾哈娜，她就怀孕，又生了三个儿子、两个女儿。那孩子撒母耳在耶和华面前渐渐长大。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及记 38:8; 撒母耳记上 2:13–17; 耶利米书 7:9–10"> 这时以利已经很老了，他听说儿子们对以色列众人所做的一切，还听说他们与会幕门口服事的妇女们同睡，</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 8:12; 腓立比书 3:19; 使徒行传 9:4"> 就对他们说：“你们为什么做这样的事呢？我从这民众都听说了你们的恶行。</span>
<span className="v" id="v24" data-v="24" data-xref="玛拉基书 2:8; 提摩太前书 3:7; 使徒行传 6:3"> 我儿啊，不要这样，我所听见耶和华子民传来的风声实在不好。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 3:14; 约书亚记 11:20; 希伯来书 10:26"> 人如果对人犯罪，有神可以为他调解；人如果对耶和华犯罪，有谁能为他调解呢？”但他们不听从父亲的话，因为耶和华定意要他们死。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 2:52; 路加福音 2:40; 使徒行传 2:47"> 那孩子撒母耳的身量，以及耶和华和人对他的喜爱，都不断增长。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="申命记 33:1; 出埃及记 4:27; 出埃及记 4:14–16"> 有一位神人来见以利，对他说：“耶和华如此说：当你的父家在埃及法老手下<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="法老手下——原文直译“属于法老的家”。">d</a></sup>的时候，我不是明确向他们显现了自己吗？</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 28:1; 利未记 8:7–8; 民数记 18:19"> 我不是从以色列所有支派中拣选了他们作我的祭司吗？我让他们上我的祭坛烧香，在我面前佩戴以弗得，把以色列子民的各种火祭都赐给了你的父家。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 10:37; 申命记 32:15; 撒母耳记上 2:13–17"> 你们为什么践踏我为我的居所指示的祭物和供物呢？你竟尊重你的儿子超过尊重我，又用我子民以色列上好的供物来养肥你们自己。</span>
</div>
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="约翰福音 12:26; 耶利米书 18:9–10; 箴言 3:9–10"> “因此以色列的神耶和华宣告：<br /><span className="pl pl-1">我确实说过，</span><br /><span className="pl pl-1">你和你的父家</span><br /><span className="pl pl-1">要永远行在我面前。</span><br /><span className="pl pl-1">但现在，耶和华宣告：绝不会这样了！</span><br /><span className="pl pl-1">因为尊重我的，我必尊重他；</span><br /><span className="pl pl-1">轻视我的，他必被藐视。</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒母耳记上 22:17–20; 列王纪上 2:26–27; 诗篇 37:17"> “看哪，日子将到，我必砍下你的膀臂和你父家的膀臂，使你家中没有一个老年人。</span>
<span className="v" id="v32" data-v="32" data-xref="撒迦利亚书 8:4; 撒母耳记上 4:11; 诗篇 78:59–64"> 当以色列在各方面蒙福的时候，你却要看到我居所的危难；你家中永远不再有老年人。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪上 2:26–27; 列王纪上 1:7; 撒母耳记上 22:21–23"> 你家中没被我从祭坛前剪除的人，必使你的眼睛衰竭、心里忧伤；而所有你家中增添的人，都死于壮年。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记上 4:11; 列王纪上 13:3; 撒母耳记上 4:17"> 那将要临到你两个儿子何弗尼和非尼哈的事，就是给你的征兆：他们二人将在同一天死去。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 7:27; 撒母耳记下 7:11; 列王纪上 11:38"> “我将为自己兴起一位忠实的祭司，他会照着我的心、我的灵行事；我将为他建立一个持久的家室，他必终生行在我受膏者的面前。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 2:27; 玛拉基书 1:13; 以西结书 44:10–12"> 你家中所有存留的人都将为一锭银子、一块饼，来向他下拜，说：‘求你给我安排一个祭司的职份，好让我有块饼吃。’”</span>
</div>

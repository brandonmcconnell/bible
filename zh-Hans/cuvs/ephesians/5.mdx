<span className="v" id="v3" data-v="3" data-xref="歌罗西书 3:5; 以弗所书 5:5; 加拉太书 5:19–21"> 至于淫乱并一切污秽，或是贪婪，在你们中间连提都不可，方合圣徒的体统。</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 3:8; 以弗所书 4:29; 帖撒罗尼迦前书 5:18"> 淫词、妄语，和戏笑的话都不相宜；总要说感谢的话。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 5:21; 哥林多前书 6:9–10; 以弗所书 5:3"> 因为你们确实地知道，无论是淫乱的，是污秽的，是有贪心的，在基督和 神的国里都是无分的。有贪心的，就与拜偶像的一样。</span>

## 行事为人当像光明的子女

<div className="bt">
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="罗马书 1:18; 歌罗西书 2:8; 马太福音 24:4"> 不要被人虚浮的话欺哄；因这些事， 神的忿怒必临到那悖逆之子。</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 18:4; 以弗所书 5:11; 提摩太前书 5:22"> 所以，你们不要与他们同伙。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 8:12; 约翰一书 1:7; 使徒行传 26:18"> 从前你们是暗昧的，但如今在主里面是光明的，行事为人就当像光明的子女。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 3:9–10; 加拉太书 5:22–23; 约翰三书 1:11"> 光明所结的果子就是一切良善、公义、诚实。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 12:1–2; 希伯来书 12:28; 诗篇 19:14"> 总要察验何为主所喜悦的事。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 13:12; 提摩太前书 5:20; 帖撒罗尼迦后书 3:6"> 那暗昧无益的事，不要与人同行，倒要责备行这事的人；</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 5:3; 耶利米书 23:24; 传道书 12:14"> 因为他们暗中所行的，就是提起来也是可耻的。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 3:20–21; 哥林多前书 4:5; 何西阿书 2:10"> 凡事受了责备，就被光显明出来，因为一切能显明的就是光。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 60:1; 罗马书 13:11–12; 以赛亚书 26:19"> 所以主说：<br /><span className="pl pl-1">你这睡着的人当醒过来，</span><br /><span className="pl pl-1">从死里复活！</span><br /><span className="pl pl-1">基督就要光照你了。</span></span>
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 4:5; 雅各书 3:13; 腓立比书 1:27"> 你们要谨慎行事，不要像愚昧人，当像智慧人。</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 4:5; 阿摩司书 5:13; 约翰福音 12:35"> 要爱惜光阴，因为现今的世代邪恶。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 12:2; 帖撒罗尼迦前书 5:18; 歌罗西书 1:9"> 不要作糊涂人，要明白主的旨意如何。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 20:1; 路加福音 1:15; 罗马书 13:13"> 不要醉酒，酒能使人放荡；乃要被圣灵充满。</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 3:16; 哥林多前书 14:26; 诗篇 95:2"> 当用诗章、颂词、灵歌彼此对说，口唱心和地赞美主。</span>
<span className="v" id="v20" data-v="20" data-xref="歌罗西书 3:17; 帖撒罗尼迦前书 5:18; 希伯来书 13:15"> 凡事要奉我们主耶稣基督的名常常感谢父 神。</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比书 2:3; 以弗所书 5:24; 以弗所书 5:22"> 又当存敬畏基督的心，彼此顺服。</span>
</div>
</div>

## 丈夫和妻子

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 3:18–1; 彼得前书 3:1–6; 提多书 2:5"> 你们作妻子的，当顺服自己的丈夫，如同顺服主。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 11:3–10; 歌罗西书 1:18; 以弗所书 1:22–23"> 因为丈夫是妻子的头，如同基督是教会的头；他又是教会全体的救主。</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所书 5:33; 歌罗西书 3:20; 提多书 2:7"> 教会怎样顺服基督，妻子也要怎样凡事顺服丈夫。</span>
<span className="v" id="v25" data-v="25" data-xref="彼得前书 3:7; 歌罗西书 3:19; 以弗所书 5:28"> 你们作丈夫的，要爱你们的妻子，正如基督爱教会，为教会舍己。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 10:22; 约翰福音 15:3; 以西结书 36:25"> 要用水借着道把教会洗净，成为圣洁，</span>
<span className="v" id="v27" data-v="27" data-xref="歌罗西书 1:22; 希伯来书 9:14; 彼得前书 1:19"> 可以献给自己，作个荣耀的教会，毫无玷污、皱纹等类的病，乃是圣洁没有瑕疵的。</span>
<span className="v" id="v28" data-v="28" data-xref="以弗所书 5:25; 马太福音 19:5; 创世记 2:21–24"> 丈夫也当照样爱妻子，如同爱自己的身子；爱妻子便是爱自己了。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 34:14–15; 以弗所书 5:31; 传道书 4:5"> 从来没有人恨恶自己的身子，总是保养顾惜，正像基督待教会一样，</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前书 6:15; 哥林多前书 12:12–27; 罗马书 12:5"> 因我们是他身上的肢体<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷加：就是他的骨他的肉">a</a></sup>。</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 2:24; 马太福音 19:5; 马可福音 10:7–8"> 为这个缘故，人要离开父母，与妻子连合，二人成为一体。</span>
<span className="v" id="v32" data-v="32" data-xref="启示录 21:2; 哥林多后书 11:2; 以赛亚书 54:5"> 这是极大的奥秘，但我是指着基督和教会说的。</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前书 3:2–7; 以斯帖记 1:20; 以弗所书 5:25"> 然而，你们各人都当爱妻子，如同爱自己一样。妻子也当敬重她的丈夫。</span>
</div>
</div>

## 保罗奉差向外邦人传福音

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 1:24; 提摩太后书 1:8; 腓立比书 1:13–16"> 因此，我—保罗为你们外邦人作了基督耶稣被囚的，替你们祈祷<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="此句是照对十四节所加">a</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 1:25–27; 提摩太前书 1:11; 提摩太后书 1:11"> 谅必你们曾听见 神赐恩给我，将关切你们的职分托付我，</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 1:12; 罗马书 16:25; 以弗所书 1:9–11"> 用启示使我知道福音的奥秘，正如我以前略略写过的。</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 4:3; 哥林多前书 4:1; 哥林多后书 11:6"> 你们念了，就能晓得我深知基督的奥秘。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前书 1:10–12; 彼得后书 3:2; 提多书 1:1–3"> 这奥秘在以前的世代没有叫人知道，像如今借着圣灵启示他的圣使徒和先知一样。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 3:26–29; 约翰一书 1:3; 约翰一书 2:25"> 这奥秘就是外邦人在基督耶稣里，借着福音，得以同为后嗣，同为一体，同蒙应许。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 1:19; 以弗所书 3:20; 以弗所书 3:2"> 我作了这福音的执事，是照 神的恩赐，这恩赐是照他运行的大能赐给我的。</span>
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 1:27; 哥林多前书 15:9; 以弗所书 2:7"> 我本来比众圣徒中最小的还小，然而他还赐我这恩典，叫我把基督那测不透的丰富传给外邦人，</span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 1:26; 马太福音 13:35; 提摩太后书 1:9"> 又使众人都明白，这历代以来隐藏在创造万物之 神里的奥秘是如何安排的，</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前书 1:12; 以弗所书 6:12; 哥林多前书 2:7"> 为要借着教会使天上执政的、掌权的，现在得知 神百般的智慧。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太后书 1:9; 以弗所书 1:11; 以弗所书 1:4"> 这是照 神从万世以前，在我们主基督耶稣里所定的旨意。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 2:18; 罗马书 5:2; 希伯来书 4:14–16"> 我们因信耶稣，就在他里面放胆无惧，笃信不疑地来到 神面前。</span>
<span className="v" id="v13" data-v="13" data-xref="歌罗西书 1:24; 帖撒罗尼迦后书 3:13; 哥林多后书 1:6"> 所以，我求你们不要因我为你们所受的患难丧胆，这原是你们的荣耀。</span>
</div>
</div>

## 明白基督的爱

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="诗篇 95:6; 以弗所书 1:16–19; 腓立比书 2:10"> 因此，我在父面前屈膝，（</span>
<span className="v" id="v15" data-v="15" data-xref="以弗所书 1:10; 启示录 5:8–14; 以弗所书 1:21"> 天上地上的各<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：全">b</a></sup>家，都是从他得名。）</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 1:11; 腓立比书 4:13; 以赛亚书 40:29–31"> 求他按着他丰盛的荣耀，借着他的灵，叫你们心里的力量刚强起来，</span>
<span className="v" id="v17" data-v="17" data-xref="歌罗西书 2:7; 约翰一书 4:16; 约翰福音 14:23"> 使基督因你们的信，住在你们心里，叫你们的爱心有根有基，</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 103:11–12; 约伯记 11:7–9; 以弗所书 1:18–23"> 能以和众圣徒一同明白基督的爱是何等长阔高深，</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所书 1:23; 歌罗西书 2:9–10; 歌罗西书 1:10"> 并知道这爱是过于人所能测度的，便叫 神一切所充满的，充满了你们。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 9:8; 罗马书 4:21; 耶利米书 32:27"> 神能照着运行在我们心里的大力充充足足地成就一切，超过我们所求所想的。</span>
<span className="v" id="v21" data-v="21" data-xref="犹大书 1:25; 罗马书 11:36; 彼得后书 3:18"> 但愿他在教会中，并在基督耶稣里，得着荣耀，直到世世代代，永永远远。阿们！</span>
</div>
</div>

## 耶和华命令重建圣殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯拉记 2:2; 以斯拉记 3:8; 以斯拉记 3:2"> 大流士王第二年六月初一日，耶和华的话借先知哈该向犹大省长撒拉铁的儿子所罗巴伯和约撒答的儿子大祭司约书亚说：</span>
<span className="v" id="v2" data-v="2" data-xref="以斯拉记 4:23–2; 尼希米记 4:10; 传道书 11:4"> 万军之耶和华如此说：「这百姓说，建造耶和华殿的时候尚未来到。」</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 5:1; 撒迦利亚书 1:1"> 那时耶和华的话临到先知哈该说：</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 7:2; 诗篇 132:3–5; 腓立比书 2:21"> 「这殿仍然荒凉，你们自己还住天花板的房屋吗？</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米哀歌 3:40; 哥林多后书 13:5; 哈该书 1:7"> 现在万军之耶和华如此说：你们要省察自己的行为。</span>
<span className="v" id="v6" data-v="6" data-xref="哈该书 1:9; 申命记 28:38–40; 何西阿书 4:10"> 你们撒的种多，收的却少；你们吃，却不得饱；喝，却不得足；穿衣服，却不得暖；得工钱的，将工钱装在破漏的囊中。」</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 119:59–60; 哈该书 1:5; 腓立比书 3:1"> 万军之耶和华如此说：「你们要省察自己的行为。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 132:13–14; 历代志下 7:16; 哈该书 2:7"> 你们要上山取木料，建造这殿，我就因此喜乐，且得荣耀。这是耶和华说的。</span>
<span className="v" id="v9" data-v="9" data-xref="哈该书 1:4; 哈该书 2:16–17; 哈该书 1:6"> 你们盼望多得，所得的却少；你们收到家中，我就吹去。这是为什么呢？因为我的殿荒凉，你们各人却顾<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是奔">a</a></sup>自己的房屋。这是万军之耶和华说的。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 8:35; 利未记 26:19; 申命记 28:23–24"> 所以为你们的缘故，天就不降甘露，地也不出土产。</span>
<span className="v" id="v11" data-v="11" data-xref="哈该书 2:17; 申命记 28:22; 列王纪下 8:1"> 我命干旱临到地土、山冈、五谷、新酒，和油，并地上的出产、人民、牲畜，以及人手一切劳碌得来的。」</span>
</div>
</div>

## 百姓顺从耶和华的命令

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 50:10; 以斯拉记 5:2; 哈该书 1:14"> 那时，撒拉铁的儿子所罗巴伯和约撒答的儿子大祭司约书亚，并剩下的百姓，都听从耶和华—他们 神的话和先知哈该奉耶和华—他们 神差来所说的话；百姓也在耶和华面前存敬畏的心。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 43:2; 马太福音 28:20; 玛拉基书 3:1"> 耶和华的使者哈该奉耶和华差遣对百姓说：「耶和华说：我与你们同在。」</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 36:22; 希伯来书 13:21; 哈该书 2:21"> 耶和华激动犹大省长撒拉铁的儿子所罗巴伯和约撒答的儿子大祭司约书亚，并剩下之百姓的心，他们就来为万军之耶和华—他们 神的殿做工。</span>
<span className="v" id="v15" data-v="15" data-xref="哈该书 1:1; 哈该书 2:20; 哈该书 2:1"> 这是在大流士王第二年六月二十四日。</span>

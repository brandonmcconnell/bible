## 摩押王召巴兰

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 34:1; 申命记 3:8; 民数记 21:20"> 以色列人起行，在摩押平原、约旦河东，对着耶利哥安营。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 11:25; 民数记 21:20–35; 民数记 21:3"> 以色列人向亚摩利人所行的一切事，西拨的儿子巴勒都看见了。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 15:15; 以赛亚书 23:5; 约书亚记 9:24"> 摩押人因以色列民甚多，就大大惧怕，心内忧急，</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 25:15–18; 民数记 31:8; 民数记 24:17"> 对米甸的长老说：「现在这众人要把我们四围所有的一概舔尽，就如牛舔尽田间的草一般。」那时西拨的儿子巴勒作摩押王。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 23:4; 约书亚记 24:9; 弥迦书 6:5"> 他差遣使者往大河边的毗夺去，到比珥的儿子巴兰本乡那里，召巴兰来，说：「有一宗民从埃及出来，遮满地面，与我对居。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 24:9; 民数记 23:7–8; 使徒行传 16:16"> 这民比我强盛，现在求你来为我咒诅他们，或者我能得胜，攻打他们，赶出此地。因为我知道，你为谁祝福，谁就得福；你咒诅谁，谁就受咒诅。」</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 9:7–8; 弥迦书 3:11; 罗马书 16:18"> 摩押的长老和米甸的长老手里拿着卦金，到了巴兰那里，将巴勒的话都告诉了他。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 23:12; 民数记 22:19–20; 耶利米书 12:2"> 巴兰说：「你们今夜在这里住宿，我必照耶和华所晓谕我的回报你们。」摩押的使臣就在巴兰那里住下了。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 20:3; 民数记 22:20; 创世记 16:8"> 神临到巴兰那里，说：「在你这里的人都是谁？」</span>
<span className="v" id="v10" data-v="10"> 巴兰回答说：「是摩押王西拨的儿子巴勒打发人到我这里来，说：</span>
<span className="v" id="v11" data-v="11"> 『从埃及出来的民遮满地面，你来为我咒诅他们，或者我能与他们争战，把他们赶出去。』」</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 23:5; 以弗所书 1:3; 创世记 12:2"> 神对巴兰说：「你不可同他们去，也不可咒诅那民，因为那民是蒙福的。」</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 23:5; 民数记 22:14"> 巴兰早晨起来，对巴勒的使臣说：「你们回本地去吧，因为耶和华不容我和你们同去。」</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 22:37; 民数记 22:13"> 摩押的使臣就起来，回巴勒那里去，说：「巴兰不肯和我们同来。」</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 10:7–8; 民数记 22:7–8"> 巴勒又差遣使臣，比先前的又多又尊贵。</span>
<span className="v" id="v16" data-v="16"> 他们到了巴兰那里，对他说：「西拨的儿子巴勒这样说：『求你不容什么事拦阻你不到我这里来，</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 24:11; 以斯帖记 5:11; 马太福音 4:8–9"> 因为我必使你得极大的尊荣。你向我要什么，我就给你什么；只求你来为我咒诅这民。』」</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 24:13; 列王纪上 22:14; 历代志下 18:13"> 巴兰回答巴勒的臣仆说：「巴勒就是将他满屋的金银给我，我行大事小事也不得越过耶和华—我 神的命。</span>
<span className="v" id="v19" data-v="19" data-xref="犹大书 1:11; 彼得后书 2:3; 提摩太前书 6:9–10"> 现在我请你们今夜在这里住宿，等我得知耶和华还要对我说什么。」</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 23:12; 民数记 24:13; 民数记 23:26"> 当夜， 神临到巴兰那里，说：「这些人若来召你，你就起来同他们去，你只要遵行我对你所说的话。」</span>
</div>
</div>

## 巴兰和他的驴

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="箴言 1:15–16"> 巴兰早晨起来，备上驴，和摩押的使臣一同去了。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 4:24; 耶利米哀歌 2:4; 民数记 22:32"> 神因他去就发了怒；耶和华的使者站在路上敌挡他。他骑着驴，有两个仆人跟随他。</span>
<span className="v" id="v23" data-v="23" data-xref="犹大书 1:11; 彼得后书 2:16; 哥林多前书 1:27–29"> 驴看见耶和华的使者站在路上，手里有拔出来的刀，就从路上跨进田间，巴兰便打驴，要叫它回转上路。</span>
<span className="v" id="v24" data-v="24"> 耶和华的使者就站在葡萄园的窄路上；这边有墙，那边也有墙。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 47:12; 约伯记 5:13–15"> 驴看见耶和华的使者，就贴靠墙，将巴兰的脚挤伤了；巴兰又打驴。</span>
<span className="v" id="v26" data-v="26" data-xref="何西阿书 2:6; 以赛亚书 26:11"> 耶和华的使者又往前去，站在狭窄之处，左右都没有转折的地方。</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 14:16; 雅各书 1:19; 箴言 27:3–4"> 驴看见耶和华的使者，就卧在巴兰底下，巴兰发怒，用杖打驴。</span>
<span className="v" id="v28" data-v="28" data-xref="彼得后书 2:16; 路加福音 1:37; 出埃及记 4:11"> 耶和华叫驴开口，对巴兰说：「我向你行了什么，你竟打我这三次呢？」</span>
<span className="v" id="v29" data-v="29" data-xref="箴言 12:10; 马太福音 15:19; 箴言 12:16"> 巴兰对驴说：「因为你戏弄我，我恨不能手中有刀，把你杀了。」</span>
<span className="v" id="v30" data-v="30" data-xref="彼得后书 2:16; 哥林多前书 1:27–28"> 驴对巴兰说：「我不是你从小时直到今日所骑的驴吗？我素常向你这样行过吗？」巴兰说：「没有。」</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 21:19; 路加福音 24:31; 使徒行传 26:18"> 当时，耶和华使巴兰的眼目明亮，他就看见耶和华的使者站在路上，手里有拔出来的刀，巴兰便低头俯伏在地。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 28:18; 使徒行传 13:10; 民数记 22:22"> 耶和华的使者对他说：「你为何这三次打你的驴呢？我出来敌挡你，因你所行的，在我面前偏僻。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 16:33–35; 民数记 14:37; 列王纪上 13:24–28"> 驴看见我就三次从我面前偏过去；驴若没有偏过去，我早把你杀了，留它存活。」</span>
<span className="v" id="v34" data-v="34" data-xref="约伯记 34:31–32; 撒母耳记下 12:13; 撒母耳记上 15:24"> 巴兰对耶和华的使者说：「我有罪了。我不知道你站在路上阻挡我；你若不喜欢我去，我就转回。」</span>
<span className="v" id="v35" data-v="35" data-xref="帖撒罗尼迦后书 2:9–12; 以赛亚书 37:26–29; 民数记 22:20–21"> 耶和华的使者对巴兰说：「你同这些人去吧！你只要说我对你说的话。」于是巴兰同着巴勒的使臣去了。</span>
</div>
</div>

## 巴勒欢迎巴兰

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以赛亚书 16:2; 使徒行传 28:15; 耶利米书 48:20"> 巴勒听见巴兰来了，就往摩押京城去迎接他；这城是在边界上，在亚嫩河旁。</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 24:11; 约翰福音 5:44; 马太福音 4:8–9"> 巴勒对巴兰说：「我不是急急地打发人到你那里去召你吗？你为何不到我这里来呢？我岂不能使你得尊荣吗？」</span>
<span className="v" id="v38" data-v="38" data-xref="民数记 22:18; 箴言 19:21; 民数记 23:16"> 巴兰说：「我已经到你这里来了！现在我岂能擅自说什么呢？ 神将什么话传给我，我就说什么。」</span>
<span className="v" id="v39" data-v="39"> 巴兰和巴勒同行，来到基列·胡琐。</span>
<span className="v" id="v40" data-v="40" data-xref="民数记 23:14; 箴言 1:16; 民数记 23:2"> 巴勒宰了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是献">a</a></sup>牛羊，送给巴兰和陪伴的使臣。</span>

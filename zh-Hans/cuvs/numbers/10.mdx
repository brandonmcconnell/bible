## 制银号

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华晓谕摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 1:13; 约珥书 1:14; 诗篇 81:3"> 「你要用银子做两枝号，都要锤出来的，用以招聚会众，并叫众营起行。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 4:5; 约珥书 2:15–16"> 吹这号的时候，全会众要到你那里，聚集在会幕门口。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 7:2; 出埃及记 18:21; 民数记 1:4–16"> 若单吹一枝，众首领，就是以色列军中的统领，要聚集到你那里。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 2:3–9; 民数记 10:14; 以赛亚书 58:1"> 吹出大声的时候，东边安的营都要起行。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 10:18; 民数记 2:10–16"> 二次吹出大声的时候，南边安的营都要起行。他们将起行，必吹出大声。</span>
<span className="v" id="v7" data-v="7" data-xref="约珥书 2:1; 民数记 10:3–4"> 但招聚会众的时候，你们要吹号，却不要吹出大声。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 6:4–16; 民数记 31:6; 历代志上 15:24"> 亚伦子孙作祭司的要吹这号；这要作你们世世代代永远的定例。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 10:18; 士师记 2:18; 创世记 8:1"> 你们在自己的地，与欺压你们的敌人打仗，就要用号吹出大声，便在耶和华—你们的 神面前得蒙纪念，也蒙拯救脱离仇敌。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 81:3; 帖撒罗尼迦前书 4:16; 哥林多前书 11:24–26"> 在你们快乐的日子和节期，并月朔，献燔祭和平安祭，也要吹号，这都要在你们的 神面前作为纪念。我是耶和华—你们的 神。」</span>
</div>
</div>

## 离开西奈山

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出埃及记 40:17; 民数记 1:1; 民数记 9:11"> 第二年二月二十日，云彩从法柜的帐幕收上去。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 21:21; 民数记 12:16; 民数记 9:5"> 以色列人就按站往前行，离开西奈的旷野，云彩停住在巴兰的旷野。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 1:6; 民数记 9:23"> 这是他们照耶和华借摩西所吩咐的，初次往前行。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 2:3–9; 民数记 1:7; 民数记 7:12"> 按着军队首先往前行的是犹大营的纛。统领军队的是亚米拿达的儿子拿顺。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 7:18; 民数记 1:8"> 统领以萨迦支派军队的是苏押的儿子拿坦业。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 7:24; 民数记 1:9"> 统领西布伦支派军队的是希伦的儿子以利押。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 7:6–8; 民数记 1:51; 希伯来书 12:28"> 帐幕拆卸，革顺的子孙和米拉利的子孙就抬着帐幕先往前行。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 2:10–16; 民数记 1:5; 民数记 26:5–18"> 按着军队往前行的是吕便营的纛。统领军队的是示丢珥的儿子以利蓿。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 1:6; 民数记 7:36"> 统领西缅支派军队的是苏利沙代的儿子示路蔑。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 1:14; 民数记 2:14; 民数记 7:42"> 统领迦得支派军队的是丢珥的儿子以利雅萨。</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 10:17; 民数记 7:9; 民数记 4:4–16"> 哥辖人抬着圣物先往前行。他们未到以前，抬帐幕的已经把帐幕支好。</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 2:18–24; 民数记 1:10; 民数记 26:23–41"> 按着军队往前行的是以法莲营的纛，统领军队的是亚米忽的儿子以利沙玛。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 1:10; 民数记 7:54"> 统领玛拿西支派军队的是比大蓿的儿子迦玛列。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 1:11; 民数记 7:60"> 统领便雅悯支派军队的是基多尼的儿子亚比但。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 6:9; 民数记 1:12; 创世记 49:16–17"> 在诸营末后的是但营的纛，按着军队往前行。统领军队的是亚米沙代的儿子亚希以谢。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 1:13; 民数记 7:72"> 统领亚设支派军队的是俄兰的儿子帕结。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 1:15; 民数记 7:78"> 统领拿弗他利支派军队的是以南的儿子亚希拉。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 2:34; 民数记 24:4–5; 哥林多前书 14:33"> 以色列人按着军队往前行，就是这样。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 12:7; 士师记 4:11; 出埃及记 3:1"> 摩西对他岳父<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：内兄">a</a></sup>—米甸人流珥的儿子何巴—说：「我们要行路，往耶和华所应许之地去；他曾说：『我要将这地赐给你们。』现在求你和我们同去，我们必厚待你，因为耶和华指着以色列人已经应许给好处。」</span>
<span className="v" id="v30" data-v="30" data-xref="路得记 1:15–17; 诗篇 45:10; 马太福音 21:29"> 何巴回答说：「我不去；我要回本地本族那里去。」</span>
<span className="v" id="v31" data-v="31" data-xref="约伯记 29:15; 加拉太书 6:2; 哥林多前书 12:14–21"> 摩西说：「求你不要离开我们；因为你知道我们要在旷野安营，你可以当作我们的眼目。</span>
<span className="v" id="v32" data-v="32" data-xref="士师记 1:16; 申命记 10:18; 约翰一书 1:3"> 你若和我们同去，将来耶和华有什么好处待我们，我们也必以什么好处待你。」</span>
</div>
</div>

## 众民和约柜往前行

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="申命记 1:33; 出埃及记 3:1; 诗篇 95:11"> 以色列人离开耶和华的山，往前行了三天的路程；耶和华的约柜在前头行了三天的路程，为他们寻找安歇的地方。</span>
<span className="v" id="v34" data-v="34" data-xref="尼希米记 9:12; 尼希米记 9:19; 诗篇 105:39"> 他们拔营往前行，日间有耶和华的云彩在他们以上。</span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 68:1–2; 以赛亚书 17:12–14; 诗篇 132:8"> 约柜往前行的时候，摩西就说：「耶和华啊，求你兴起！愿你的仇敌四散！愿恨你的人从你面前逃跑！」</span>
<span className="v" id="v36" data-v="36" data-xref="申命记 1:10; 诗篇 90:13–17; 以赛亚书 63:17"> 约柜停住的时候，他就说：「耶和华啊，求你回到以色列的千万人中！」</span>
</div>
</div>

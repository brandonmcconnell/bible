## 米利暗受罚

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 2:21; 创世记 26:34–35; 创世记 24:37"> 摩西娶了古实女子为妻。米利暗和亚伦因他所娶的古实女子就毁谤他，说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 35:12–13; 民数记 16:3; 弥迦书 6:4"> 「难道耶和华单与摩西说话，不也与我们说话吗？」这话耶和华听见了。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 11:29; 雅各书 3:13; 哥林多后书 11:5"> 摩西为人极其谦和，胜过世上的众人。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 76:9; 民数记 16:16–21"> 耶和华忽然对摩西、亚伦、米利暗说：「你们三个人都出来，到会幕这里。」他们三个人就出来了。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 11:25; 出埃及记 34:5; 诗篇 99:7"> 耶和华在云柱中降临，站在会幕门口，召亚伦和米利暗，二人就出来了。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 3:5; 创世记 31:10–11; 创世记 46:2"> 耶和华说：「你们且听我的话：你们中间若有先知，我—耶和华必在异象中向他显现，在梦中与他说话。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 3:2–6; 约书亚记 1:1; 诗篇 105:26"> 我的仆人摩西不是这样；他是在我全家尽忠的。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 34:10; 哥林多前书 13:12; 出埃及记 33:11"> 我要与他面对面说话，乃是明说，不用谜语，并且他必见我的形象。你们毁谤我的仆人摩西，为何不惧怕呢？」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 17:22; 何西阿书 5:15; 民数记 11:1"> 耶和华就向他们二人发怒而去。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 24:9; 列王纪下 5:27; 出埃及记 4:6"> 云彩从会幕上挪开了，不料，米利暗长了大麻风，有雪那样白。亚伦一看米利暗长了大麻风，</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 19:19; 撒母耳记下 24:10; 箴言 30:32"> 就对摩西说：「我主啊，求你不要因我们愚昧犯罪，便将这罪加在我们身上。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 88:4–5; 哥林多前书 15:8; 提摩太前书 5:6"> 求你不要使她像那出母腹、肉已半烂的死胎。」</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 12:21; 路加福音 6:28; 雅各书 5:15"> 于是摩西哀求耶和华说：「 神啊，求你医治她！」</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 25:9; 约伯记 30:10; 以赛亚书 50:6"> 耶和华对摩西说：「她父亲若吐唾沫在她脸上，她岂不蒙羞七天吗？现在要把她在营外关锁七天，然后才可以领她进来。」</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 24:8–9; 弥迦书 7:8–9; 弥迦书 6:4"> 于是米利暗关锁在营外七天。百姓没有行路，直等到把米利暗领进来。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 11:35; 民数记 33:18; 民数记 10:12"> 以后百姓从哈洗录起行，在巴兰的旷野安营。</span>
</div>

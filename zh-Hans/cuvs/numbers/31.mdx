## 跟米甸人打仗

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华吩咐摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 27:13; 民数记 25:14–18; 启示录 6:10"> 「你要在米甸人身上报以色列人的仇，后来要归到你列祖<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是本民">a</a></sup>那里。」</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 26:25; 民数记 25:11; 列王纪下 10:30"> 摩西吩咐百姓说：「要从你们中间叫人带兵器出去攻击米甸，好在米甸人身上为耶和华报仇。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 26:8; 撒母耳记上 14:6; 士师记 7:2"> 从以色列众支派中，每支派要打发一千人去打仗。」</span>
<span className="v" id="v5" data-v="5"> 于是从以色列千万人中，每支派交出一千人，共一万二千人，带着兵器预备打仗。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 14:44; 民数记 10:8–9; 历代志下 13:12–15"> 摩西就打发每支派的一千人去打仗，并打发祭司以利亚撒的儿子非尼哈同去；非尼哈手里拿着圣所的器皿和吹大声的号筒。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 21:11; 列王纪上 11:15–16; 撒母耳记上 27:9"> 他们就照耶和华所吩咐摩西的，与米甸人打仗，杀了所有的男丁。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 13:21–22; 民数记 25:15; 启示录 2:14"> 在所杀的人中，杀了米甸的五王，就是以未、利金、苏珥、户珥、利巴，又用刀杀了比珥的儿子巴兰。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 20:14; 历代志下 28:8–10; 历代志下 28:5"> 以色列人掳了米甸人的妇女孩子，并将他们的牲畜、羊群，和所有的财物都夺了来，当作掳物，</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 1:7; 撒母耳记上 30:1; 约书亚记 6:24"> 又用火焚烧他们所住的城邑和所有的营寨，</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 20:14; 约书亚记 8:2"> 把一切所夺的、所掳的，连人带牲畜都带了去，</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 22:1"> 将所掳的人，所夺的牲畜、财物，都带到摩押平原，在约旦河边与耶利哥相对的营盘，交给摩西和祭司以利亚撒，并以色列的会众。</span>
</div>
</div>

## 打仗回来

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 5:2; 撒母耳记上 30:21; 民数记 31:12"> 摩西和祭司以利亚撒，并会众一切的首领，都出到营外迎接他们。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 13:19; 撒母耳记上 15:13–14; 民数记 31:48"> 摩西向打仗回来的军长，就是千夫长、百夫长，发怒，</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 15:3; 耶利米书 48:10; 申命记 2:34"> 对他们说：「你们要存留这一切妇女的活命吗？</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 25:1–9; 彼得后书 2:15; 启示录 2:14"> 这些妇女因巴兰的计谋，叫以色列人在毗珥的事上得罪耶和华，以致耶和华的会众遭遇瘟疫。</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 21:11–12; 申命记 20:16–18; 申命记 7:2"> 所以，你们要把一切的男孩和所有已嫁的女子都杀了。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 21:10–14; 历代志下 28:8–10; 申命记 20:14"> 但女孩子中，凡没有出嫁的，你们都可以存留她的活命。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 19:11–22; 民数记 5:2; 历代志上 22:8"> 你们要在营外驻扎七日；凡杀了人的，和一切摸了被杀的，并你们所掳来的人口，第三日，第七日，都要洁净自己，</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 19:22; 创世记 35:2; 出埃及记 19:10"> 也要因一切的衣服、皮物、山羊毛织的物，和各样的木器，洁净自己。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数记 30:16"> 祭司以利亚撒对打仗回来的兵丁说：「耶和华所吩咐摩西律法中的条例乃是这样：</span>
<span className="v" id="v22" data-v="22"> 金、银、铜、铁、锡、铅，</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 19:9; 民数记 19:17; 哥林多前书 3:13"> 凡能见火的，你们要叫它经火就为洁净，然而还要用除污秽的水洁净它；凡不能见火的，你们要叫它过水。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 11:25; 利未记 15:13; 利未记 14:9"> 第七日，你们要洗衣服，就为洁净，然后可以进营。」</span>
</div>
</div>

## 分战利品

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25"> 耶和华晓谕摩西说：</span>
<span className="v" id="v26" data-v="26"> 「你和祭司以利亚撒，并会众的各族长，要计算所掳来的人口和牲畜的总数。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 22:8; 诗篇 68:12; 撒母耳记上 30:24–25"> 把所掳来的分作两半：一半归与出去打仗的精兵，一半归与全会众。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 18:26; 民数记 31:30; 民数记 31:47"> 又要从出去打仗所得的人口、牛、驴、羊群中，每五百取一，作为贡物奉给耶和华。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 29:27; 申命记 12:19; 申命记 12:12"> 从他们一半之中，要取出来交给祭司以利亚撒，作为耶和华的举祭。</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 3:31; 民数记 3:7–8; 民数记 3:25"> 从以色列人的一半之中，就是从人口、牛、驴、羊群、各样牲畜中，每五十取一，交给看守耶和华帐幕的利未人。」</span>
<span className="v" id="v31" data-v="31"> 于是摩西和祭司以利亚撒照耶和华所吩咐摩西的行了。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 除了兵丁所夺的财物以外，所掳来的：羊六十七万五千只；</span>
<span className="v" id="v33" data-v="33"> 牛七万二千只；</span>
<span className="v" id="v34" data-v="34"> 驴六万一千匹；</span>
<span className="v" id="v35" data-v="35"> 女人共三万二千口，都是没有出嫁的。</span>
<span className="v" id="v36" data-v="36"> 出去打仗之人的分，就是他们所得的那一半，共计羊三十三万七千五百只，</span>
<span className="v" id="v37" data-v="37"> 从其中归耶和华为贡物的，有六百七十五只；</span>
<span className="v" id="v38" data-v="38"> 牛三万六千只，从其中归耶和华为贡物的，有七十二只；</span>
<span className="v" id="v39" data-v="39"> 驴三万零五百匹，从其中归耶和华为贡物的，有六十一匹；</span>
<span className="v" id="v40" data-v="40"> 人一万六千口，从其中归耶和华的，有三十二口。</span>
<span className="v" id="v41" data-v="41" data-xref="民数记 18:8; 民数记 18:19; 希伯来书 7:9–12"> 摩西把贡物，就是归与耶和华的举祭，交给祭司以利亚撒，是照耶和华所吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> 以色列人所得的那一半，就是摩西从打仗的人取来分给他们的。（</span>
<span className="v" id="v43" data-v="43"> 会众的那一半有：羊三十三万七千五百只；</span>
<span className="v" id="v44" data-v="44"> 牛三万六千只；</span>
<span className="v" id="v45" data-v="45"> 驴三万零五百匹；</span>
<span className="v" id="v46" data-v="46"> 人一万六千口。）</span>
<span className="v" id="v47" data-v="47" data-xref="民数记 31:30; 路加福音 10:1–8; 以赛亚书 56:10–11"> 无论是人口是牲畜，摩西每五十取一，交给看守耶和华帐幕的利未人，是照耶和华所吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48"> 带领千军的各军长，就是千夫长、百夫长，都近前来见摩西，</span>
<span className="v" id="v49" data-v="49" data-xref="约翰福音 18:9; 撒母耳记上 30:18–19; 诗篇 72:14"> 对他说：「仆人权下的兵已经计算总数，并不短少一人。</span>
<span className="v" id="v50" data-v="50" data-xref="出埃及记 30:12; 出埃及记 30:15–16; 诗篇 116:12"> 如今我们将各人所得的金器，就是脚链子、镯子、打印的戒指、耳环、手钏，都送来为耶和华的供物，好在耶和华面前为我们的生命赎罪。」</span>
<span className="v" id="v51" data-v="51" data-xref="民数记 7:2–6"> 摩西和祭司以利亚撒就收了他们的金子，都是打成的器皿。</span>
<span className="v" id="v52" data-v="52"> 千夫长、百夫长所献给耶和华为举祭的金子共有一万六千七百五十舍客勒。</span>
<span className="v" id="v53" data-v="53" data-xref="申命记 20:14; 民数记 31:32"> 各兵丁都为自己夺了财物。</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及记 30:16; 撒迦利亚书 6:14; 使徒行传 10:4"> 摩西和祭司以利亚撒收了千夫长、百夫长的金子，就带进会幕，在耶和华面前作为以色列人的纪念。</span>
</div>
</div>

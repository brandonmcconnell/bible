## 拿细耳人的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 13:5; 阿摩司书 2:11–12; 罗马书 1:1"> 「你晓谕以色列人说：无论男女许了特别的愿，就是拿细耳人的愿<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="拿细耳就是归主的意思；下同">a</a></sup>，要离俗归耶和华。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:15; 提摩太前书 5:23; 阿摩司书 2:12"> 他就要远离清酒浓酒，也不可喝什么清酒浓酒做的醋；不可喝什么葡萄汁，也不可吃鲜葡萄和干葡萄。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 6:5; 民数记 6:21; 民数记 6:8–9"> 在一切离俗的日子，凡葡萄树上结的，自核至皮所做的物，都不可吃。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 1:11; 士师记 16:17; 士师记 13:5"> 「在他一切许愿离俗的日子，不可用剃头刀剃头，要由发绺长长了。他要圣洁，直到离俗归耶和华的日子满了。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 21:11; 利未记 19:28; 利未记 21:1–3"> 在他离俗归耶和华的一切日子，不可挨近死尸。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 9:6; 利未记 21:1–2; 利未记 21:10–12"> 他的父母或是弟兄姊妹死了的时候，他不可因他们使自己不洁净，因为那离俗归 神的凭据是在他头上。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 6:17–18"> 在他一切离俗的日子是归耶和华为圣。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数记 6:18; 使徒行传 18:18; 利未记 14:9"> 「若在他旁边忽然有人死了，以致沾染了他离俗的头，他要在第七日，得洁净的时候，剃头。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 15:29; 利未记 1:14; 利未记 15:14"> 第八日，他要把两只斑鸠或两只雏鸽带到会幕门口，交给祭司。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 14:30–31; 利未记 5:8–10"> 祭司要献一只作赎罪祭，一只作燔祭，为他赎那因死尸而有的罪，并要当日使他的头成为圣洁。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 5:6; 马太福音 24:13; 利未记 14:24"> 他要另选离俗归耶和华的日子，又要牵一只一岁的公羊羔来作赎愆祭；但先前的日子要归徒然，因为他在离俗之间被玷污了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 21:26"> 「拿细耳人满了离俗的日子乃有这条例：人要领他到会幕门口，</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 3:6; 利未记 4:32; 利未记 4:2–3"> 他要将供物奉给耶和华，就是一只没有残疾、一岁的公羊羔作燔祭，一只没有残疾、一岁的母羊羔作赎罪祭，和一只没有残疾的公绵羊作平安祭，</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 2:4; 出埃及记 29:2; 民数记 15:10"> 并一筐子无酵调油的细面饼，与抹油的无酵薄饼，并同献的素祭和奠祭。</span>
<span className="v" id="v16" data-v="16"> 祭司要在耶和华面前献那人的赎罪祭和燔祭；</span>
<span className="v" id="v17" data-v="17"> 也要把那只公羊和那筐无酵饼献给耶和华作平安祭，又要将同献的素祭和奠祭献上。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 21:24; 民数记 6:9; 使徒行传 18:18"> 拿细耳人要在会幕门口剃离俗的头，把离俗头上的发放在平安祭下的火上。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 2:15; 利未记 7:30; 出埃及记 29:23–28"> 他剃了以后，祭司就要取那已煮的公羊一条前腿，又从筐子里取一个无酵饼和一个无酵薄饼，都放在他手上。</span>
<span className="v" id="v20" data-v="20" data-xref="传道书 9:7; 出埃及记 29:27–28; 民数记 5:25"> 祭司要拿这些作为摇祭，在耶和华面前摇一摇；这与所摇的胸、所举的腿同为圣物，归给祭司。然后拿细耳人可以喝酒。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="希伯来书 13:16; 以斯拉记 2:69; 民数记 5:29"> 「许愿的拿细耳人为离俗所献的供物，和他以外所能得的献给耶和华，就有这条例。他怎样许愿就当照离俗的条例行。」</span>
</div>
</div>

## 祭司的祝福

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22"> 耶和华晓谕摩西说：</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 21:5; 历代志上 23:13; 创世记 48:20"> 「你告诉亚伦和他儿子说：你们要这样为以色列人祝福，说：</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦前书 5:23; 诗篇 121:4–7; 腓立比书 4:7"> 『愿耶和华赐福给你，保护你。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 80:19; 诗篇 119:135; 诗篇 31:16"> 愿耶和华使他的脸光照你，赐恩给你。</span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 4:6; 诗篇 29:11; 帖撒罗尼迦后书 3:16"> 愿耶和华向你仰脸，赐你平安。』</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 7:14; 但以理书 9:18–19; 申命记 28:10"> 他们要如此奉我的名为以色列人祝福；我也要赐福给他们。」</span>
</div>

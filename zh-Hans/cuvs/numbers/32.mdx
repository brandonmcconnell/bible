## 约旦河东的两支派

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 21:32; 民数记 32:3; 创世记 13:10–11"> 吕便子孙和迦得子孙的牲畜极其众多；他们看见雅谢地和基列地是可牧放牲畜之地，</span>
<span className="v" id="v2" data-v="2"> 就来见摩西和祭司以利亚撒，并会众的首领，说：</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 48:34; 以赛亚书 16:8–9; 民数记 32:34–38"> 「亚大录、底本、雅谢、宁拉、希实本、以利亚利、示班、尼波、比稳，</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 21:34; 申命记 2:24–35; 民数记 21:24"> 就是耶和华在以色列会众前面所攻取之地，是可牧放牲畜之地，你仆人也有牲畜」；</span>
<span className="v" id="v5" data-v="5" data-xref="路得记 2:10; 约书亚记 7:7; 耶利米书 31:2"> 又说：「我们若在你眼前蒙恩，求你把这地给我们为业，不要领我们过约旦河。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 13:5; 撒母耳记下 11:11; 腓立比书 2:4"> 摩西对迦得子孙和吕便子孙说：「难道你们的弟兄去打仗，你们竟坐在这里吗？</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 13:27–4; 民数记 32:9; 申命记 1:28"> 你们为何使以色列人灰心丧胆、不过去进入耶和华所赐给他们的那地呢？</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 1:19–25; 民数记 14:2; 民数记 13:2–26"> 我先前从加低斯·巴尼亚打发你们先祖去窥探那地，他们也是这样行。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 13:23–10; 申命记 1:24–28"> 他们上以实各谷，去窥探那地回来的时候，使以色列人灰心丧胆，不进入耶和华所赐给他们的地。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 14:11; 诗篇 95:11; 以西结书 20:15"> 当日，耶和华的怒气发作，就起誓说：</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 14:28–30; 民数记 14:24; 民数记 26:2"> 『凡从埃及上来、二十岁以外的人断不得看见我对亚伯拉罕、以撒、雅各起誓应许之地，因为他们没有专心跟从我。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 1:36; 民数记 14:30; 民数记 14:24"> 惟有基尼洗族耶孚尼的儿子迦勒和嫩的儿子约书亚可以看见，因为他们专心跟从我。』</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 10:5; 民数记 14:33–35; 希伯来书 3:16–19"> 耶和华的怒气向以色列人发作，使他们在旷野飘流四十年，等到在耶和华眼前行恶的那一代人都消灭了。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 11:48; 诗篇 78:57; 马太福音 23:31–33"> 谁知，你们起来接续先祖，增添罪人的数目，使耶和华向以色列大发烈怒。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 8:11–12; 历代志下 15:2; 历代志下 7:19–22"> 你们若退后不跟从他，他还要把以色列人撇在旷野，便是你们使这众民灭亡。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="创世记 33:17; 民数记 34:22"> 两支派的人挨近摩西，说：「我们要在这里为牲畜垒圈，为妇人孩子造城。</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 4:12–13; 民数记 32:29–32; 申命记 3:18–20"> 我们自己要带兵器行在以色列人的前头，好把他们领到他们的地方；但我们的妇人孩子，因这地居民的缘故，要住在坚固的城内。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 22:1–5"> 我们不回家，直等到以色列人各承受自己的产业。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 13:8; 约书亚记 12:1–6; 民数记 34:15"> 我们不和他们在约旦河那边一带之地同受产业，因为我们的产业是坐落在约旦河东边这里。」</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 4:12–13; 申命记 3:18–20; 约书亚记 1:13–15"> 摩西对他们说：「你们若这样行，在耶和华面前带着兵器出去打仗，</span>
<span className="v" id="v21" data-v="21"> 所有带兵器的人都要在耶和华面前过约旦河，等他赶出他的仇敌，</span>
<span className="v" id="v22" data-v="22" data-xref="约书亚记 22:9; 约书亚记 22:4; 申命记 3:20"> 那地被耶和华制伏了，然后你们可以回来，向耶和华和以色列才为无罪，这地也必在耶和华面前归你们为业。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 59:12; 箴言 13:21; 创世记 44:16"> 倘若你们不这样行，就得罪耶和华，要知道你们的罪必追上你们。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 32:16; 民数记 30:2; 民数记 32:34–42"> 如今你们口中所出的，只管去行，为你们的妇人孩子造城，为你们的羊群垒圈。」</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 1:13–14"> 迦得子孙和吕便子孙对摩西说：「仆人要照我主所吩咐的去行。</span>
<span className="v" id="v26" data-v="26" data-xref="约书亚记 1:14"> 我们的妻子、孩子、羊群，和所有的牲畜都要留在基列的各城。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 4:12; 民数记 32:17; 民数记 12:11"> 但你的仆人，凡带兵器的，都要照我主所说的话，在耶和华面前过去打仗。」</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约书亚记 1:13"> 于是，摩西为他们嘱咐祭司以利亚撒和嫩的儿子约书亚，并以色列众支派的族长，说：</span>
<span className="v" id="v29" data-v="29"> 「迦得子孙和吕便子孙，凡带兵器在耶和华面前去打仗的，若与你们一同过约旦河，那地被你们制伏了，你们就要把基列地给他们为业。</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 22:19"> 倘若他们不带兵器和你们一同过去，就要在迦南地你们中间得产业。」</span>
<span className="v" id="v31" data-v="31"> 迦得子孙和吕便子孙回答说：「耶和华怎样吩咐仆人，仆人就怎样行。</span>
<span className="v" id="v32" data-v="32"> 我们要带兵器，在耶和华面前过去，进入迦南地，只是约旦河这边、我们所得为业之地仍归我们。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约书亚记 12:6; 申命记 29:8; 申命记 3:12–17"> 摩西将亚摩利王西宏的国和巴珊王噩的国，连那地和周围的城邑，都给了迦得子孙和吕便子孙，并约瑟的儿子玛拿西半个支派。</span>
<span className="v" id="v34" data-v="34" data-xref="申命记 2:36; 民数记 32:3; 以赛亚书 17:2"> 迦得子孙建造底本、亚他录、亚罗珥、</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 32:1; 民数记 32:3"> 亚他录·朔反、雅谢、约比哈、</span>
<span className="v" id="v36" data-v="36" data-xref="民数记 32:3"> 伯·宁拉、伯·哈兰，都是坚固城。他们又垒羊圈。</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 21:27; 民数记 32:3; 以赛亚书 15:4"> 吕便子孙建造希实本、以利亚利、基列亭、</span>
<span className="v" id="v38" data-v="38" data-xref="以赛亚书 46:1; 民数记 32:3; 约书亚记 23:7"> 尼波、巴力·免、西比玛（尼波、巴力·免，名字是改了的），又给他们所建造的城另起别名。</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 50:23; 约书亚记 17:1; 民数记 26:29"> 玛拿西的儿子玛吉，他的子孙往基列去，占了那地，赶出那里的亚摩利人。</span>
<span className="v" id="v40" data-v="40" data-xref="约书亚记 17:1; 约书亚记 13:29–31; 申命记 3:13–15"> 摩西将基列赐给玛拿西的儿子玛吉，他子孙就住在那里。</span>
<span className="v" id="v41" data-v="41" data-xref="申命记 3:14; 士师记 10:4; 约书亚记 13:30"> 玛拿西的子孙睚珥去占了基列的村庄，就称这些村庄为哈倭特·睚珥。</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 49:11; 撒母耳记下 18:18"> 挪巴去占了基纳和基纳的乡村，就按自己的名称基纳为挪巴。</span>
</div>
</div>

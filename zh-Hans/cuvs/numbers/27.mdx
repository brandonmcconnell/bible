## 西罗非哈的女儿们

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 26:33; 加拉太书 3:28; 历代志上 7:15"> 属约瑟的儿子玛拿西的各族，有玛拿西的玄孙，玛吉的曾孙，基列的孙子，希弗的儿子西罗非哈的女儿，名叫玛拉、挪阿、曷拉、密迦、得撒。她们前来，</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 15:33–34; 申命记 17:8–10; 出埃及记 18:19–26"> 站在会幕门口，在摩西和祭司以利亚撒，并众首领与全会众面前，说：</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 26:64–65; 以西结书 18:4; 民数记 14:35"> 「我们的父亲死在旷野。他不与可拉同党聚集攻击耶和华，是在自己罪中死的；他也没有儿子。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 17:4; 诗篇 109:13; 出埃及记 32:11"> 为什么因我们的父亲没有儿子就把他的名从他族中除掉呢？求你们在我们父亲的弟兄中分给我们产业。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="利未记 24:12–13; 约伯记 23:4; 箴言 3:5–6"> 于是，摩西将她们的案件呈到耶和华面前。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 3:28; 诗篇 68:5–6"> 耶和华晓谕摩西说：</span>
<span className="v" id="v7" data-v="7" data-xref="加拉太书 3:28; 耶利米书 49:11; 约书亚记 17:4"> 「西罗非哈的女儿说得有理。你定要在她们父亲的弟兄中，把地分给她们为业；要将她们父亲的产业归给她们。</span>
<span className="v" id="v8" data-v="8"> 你也要晓谕以色列人说：『人若死了没有儿子，就要把他的产业归给他的女儿。</span>
<span className="v" id="v9" data-v="9"> 他若没有女儿，就要把他的产业给他的弟兄。</span>
<span className="v" id="v10" data-v="10"> 他若没有弟兄，就要把他的产业给他父亲的弟兄。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 35:29; 路得记 4:3–6; 耶利米书 32:8"> 他父亲若没有弟兄，就要把他的产业给他族中最近的亲属，他便要得为业。』这要作以色列人的律例典章，是照耶和华吩咐摩西的。」</span>
</div>
</div>

## 约书亚被选为摩西的继承人

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数记 33:47–48; 申命记 34:1–4; 申命记 3:23–27"> 耶和华对摩西说：「你上这亚巴琳山，观看我所赐给以色列人的地。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 10:6; 民数记 31:2; 民数记 20:24–28"> 看了以后，你也必归到你列祖<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是本民">a</a></sup>那里，像你哥哥亚伦一样。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 1:37; 民数记 20:8–13; 出埃及记 17:7"> 因为你们在寻的旷野，当会众争闹的时候，违背了我的命，没有在涌水之地、会众眼前尊我为圣。」（这水就是寻的旷野加低斯米利巴水。）</span>
<span className="v" id="v15" data-v="15"> 摩西对耶和华说：</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 16:22; 耶利米书 3:15; 希伯来书 12:9"> 「愿耶和华万人之灵的 神，立一个人治理会众，</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 34:5; 马可福音 6:34; 列王纪上 22:17"> 可以在他们面前出入，也可以引导他们，免得耶和华的会众如同没有牧人的羊群一般。」</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 34:9; 民数记 27:23; 创世记 41:38"> 耶和华对摩西说：「嫩的儿子约书亚是心中有圣灵的；你将他领来，按手在他头上，</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 3:28; 申命记 31:7–8; 申命记 31:23"> 使他站在祭司以利亚撒和全会众面前，嘱咐他，</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 1:16–18; 撒母耳记上 10:9; 列王纪下 2:9–10"> 又将你的尊荣给他几分，使以色列全会众都听从他。</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 9:14; 撒母耳记上 28:6; 出埃及记 28:30"> 他要站在祭司以利亚撒面前；以利亚撒要凭乌陵的判断，在耶和华面前为他求问。他和以色列全会众都要遵以利亚撒的命出入。」</span>
<span className="v" id="v22" data-v="22"> 于是摩西照耶和华所吩咐的将约书亚领来，使他站在祭司以利亚撒和全会众面前，</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 3:28; 民数记 27:19; 申命记 31:7–8"> 按手在他头上，嘱咐他，是照耶和华借摩西所说的话。</span>
</div>
</div>

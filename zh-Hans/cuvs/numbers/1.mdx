## 以色列的第一次人口普查

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 25:22; 出埃及记 19:1; 民数记 10:11–12"> 以色列人出埃及地后，第二年二月初一日，耶和华在西奈的旷野、会幕中晓谕摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 38:26; 出埃及记 30:12; 民数记 1:18"> 「你要按以色列全会众的家室、宗族、人名的数目计算所有的男丁。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 30:14; 民数记 14:29; 民数记 33:1"> 凡以色列中，从二十岁以外，能出去打仗的，你和亚伦要照他们的军队数点。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 1:16; 出埃及记 18:25; 民数记 13:2–15"> 每支派中必有一人作本支派的族长，帮助你们。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 7:30; 创世记 30:5–20; 创世记 49:1–33"> 他们的名字：属吕便的，有示丢珥的儿子以利蓿；</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 7:36; 民数记 2:12"> 属西缅的，有苏利沙代的儿子示路蔑；</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 3:32; 民数记 10:14; 马太福音 1:2–5"> 属犹大的，有亚米拿达的儿子拿顺；</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 7:18; 民数记 10:15; 民数记 2:5"> 属以萨迦的，有苏押的儿子拿坦业；</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 7:24; 民数记 10:16; 民数记 2:7"> 属西布伦的，有希伦的儿子以利押；</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 7:54; 民数记 7:48; 历代志上 7:26–27"> 约瑟子孙、属以法莲的，有亚米忽的儿子以利沙玛；属玛拿西的，有比大蓿的儿子迦玛列；</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 7:60; 民数记 10:24; 民数记 2:22"> 属便雅悯的，有基多尼的儿子亚比但；</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 7:66; 民数记 2:25; 民数记 10:25"> 属但的，有亚米沙代的儿子亚希以谢；</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 7:72; 民数记 10:26; 民数记 2:27"> 属亚设的，有俄兰的儿子帕结；</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 2:14; 民数记 7:42; 民数记 10:20"> 属迦得的，有丢珥的儿子以利雅萨；</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 7:78; 民数记 10:27; 民数记 2:29"> 属拿弗他利的，有以南的儿子亚希拉。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 7:2; 出埃及记 18:21; 出埃及记 18:25"> 这都是从会中选召的，各作本支派的首领，都是以色列军中的统领。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 10:3; 启示录 7:4–17; 民数记 1:5–15"> 于是，摩西、亚伦带着这些按名指定的人，</span>
<span className="v" id="v18" data-v="18" data-xref="以斯拉记 2:59; 尼希米记 7:61; 希伯来书 7:3"> 当二月初一日招聚全会众。会众就照他们的家室、宗族、人名的数目，从二十岁以外的，都述说自己的家谱。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 1:2; 民数记 26:1–2; 撒母耳记下 24:1–10"> 耶和华怎样吩咐摩西，他就怎样在西奈的旷野数点他们。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数记 26:5–7; 民数记 2:10–11; 创世记 46:9"> 以色列的长子，吕便子孙的后代，照着家室、宗族、人名的数目，从二十岁以外，凡能出去打仗、被数的男丁，共有四万六千五百名。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数记 26:12–14; 创世记 34:25–30; 民数记 2:12–13"> 西缅子孙的后代，照着家室、宗族、人名的数目，从二十岁以外，凡能出去打仗、被数的男丁，共有五万九千三百名。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数记 26:15–18; 创世记 46:16; 民数记 2:14–15"> 迦得子孙的后代，照着家室、宗族、人名的数目，从二十岁以外，凡能出去打仗、被数的，共有四万五千六百五十名。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="创世记 29:35; 民数记 26:19–22; 撒母耳记下 24:9"> 犹大子孙的后代，照着家室、宗族、人名的数目，从二十岁以外，凡能出去打仗、被数的，共有七万四千六百名。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="创世记 46:13; 创世记 49:14–15; 创世记 30:18"> 以萨迦子孙的后代，照着家室、宗族、人名的数目，从二十岁以外，凡能出去打仗、被数的，共有五万四千四百名。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="民数记 26:26–27; 创世记 49:13; 创世记 30:20"> 西布伦子孙的后代，照着家室、宗族、人名的数目，从二十岁以外，凡能出去打仗、被数的，共有五万七千四百名。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="民数记 26:35–37; 申命记 33:17; 创世记 46:20"> 约瑟子孙属以法莲子孙的后代，照着家室、宗族、人名的数目，从二十岁以外，凡能出去打仗、被数的，共有四万零五百名。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="民数记 26:28–34"> 玛拿西子孙的后代，照着家室、宗族、人名的数目，从二十岁以外，凡能出去打仗、被数的，共有三万二千二百名。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="创世记 49:27; 创世记 44:20; 启示录 7:8"> 便雅悯子孙的后代，照着家室、宗族、人名的数目，从二十岁以外，凡能出去打仗、被数的，共有三万五千四百名。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="创世记 46:23; 创世记 30:5–6; 创世记 49:16–17"> 但子孙的后代，照着家室、宗族、人名的数目，从二十岁以外，凡能出去打仗、被数的，共有六万二千七百名。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="创世记 30:12–13; 创世记 46:27; 创世记 49:20"> 亚设子孙的后代，照着家室、宗族、人名的数目，从二十岁以外，凡能出去打仗、被数的，共有四万一千五百名。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="创世记 49:21; 民数记 26:48–50; 创世记 46:24"> 拿弗他利子孙的后代，照着家室、宗族、人名的数目，从二十岁以外，凡能出去打仗、被数的，共有五万三千四百名。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="民数记 26:64; 民数记 1:2–16"> 这些就是被数点的，是摩西、亚伦，和以色列中十二个首领所数点的；这十二个人各作各宗族的代表。</span>
<span className="v" id="v45" data-v="45"> 这样，凡以色列人中被数的，照着宗族，从二十岁以外，能出去打仗、被数的，共有六十万零三千五百五十名。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="民数记 2:33; 民数记 3:1–49; 民数记 26:57–62"> 利未人却没有按着支派数在其中，</span>
<span className="v" id="v48" data-v="48"> 因为耶和华晓谕摩西说：</span>
<span className="v" id="v49" data-v="49" data-xref="民数记 26:62; 民数记 2:33"> 「惟独利未支派你不可数点，也不可在以色列人中计算他们的总数。</span>
<span className="v" id="v50" data-v="50" data-xref="出埃及记 38:21; 出埃及记 31:18; 民数记 4:15"> 只要派利未人管法柜的帐幕和其中的器具，并属乎帐幕的；他们要抬<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：搬运">a</a></sup>帐幕和其中的器具，并要办理帐幕的事，在帐幕的四围安营。</span>
<span className="v" id="v51" data-v="51" data-xref="民数记 3:38; 民数记 3:10; 撒母耳记上 6:19"> 帐幕将往前行的时候，利未人要拆卸；将支搭的时候，利未人要竖起。近前来的外人必被治死。</span>
<span className="v" id="v52" data-v="52" data-xref="民数记 2:2; 民数记 2:34; 民数记 10:1–36"> 以色列人支搭帐棚，要照他们的军队，各归本营，各归本纛。</span>
<span className="v" id="v53" data-v="53" data-xref="民数记 16:46; 历代志上 23:32; 利未记 10:6"> 但利未人要在法柜帐幕的四围安营，免得忿怒临到以色列会众；利未人并要谨守法柜的帐幕。」</span>
<span className="v" id="v54" data-v="54" data-xref="申命记 12:32; 出埃及记 40:16; 出埃及记 39:32"> 以色列人就这样行。凡耶和华所吩咐摩西的，他们就照样行了。</span>
</div>
</div>

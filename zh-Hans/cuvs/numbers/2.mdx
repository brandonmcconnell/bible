## 各支派在营地的位置

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华晓谕摩西、亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 14:40; 民数记 10:22; 民数记 1:50"> 「以色列人要各归自己的纛下，在本族的旗号那里，对着会幕的四围安营。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 2:10; 路得记 4:20; 路加福音 3:32–33"> 在东边，向日出之地，照着军队安营的是犹大营的纛。有亚米拿达的儿子拿顺作犹大人的首领。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 26:22; 民数记 1:27"> 他军队被数的，共有七万四千六百名。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 1:8; 民数记 7:18; 民数记 7:23"> 挨着他安营的是以萨迦支派。有苏押的儿子拿坦业作以萨迦人的首领。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 26:25; 民数记 1:29"> 他军队被数的，共有五万四千四百名。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 1:9; 民数记 7:24; 民数记 10:16"> 又有西布伦支派。希伦的儿子以利押作西布伦人的首领。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 26:26–27; 民数记 1:31"> 他军队被数的，共有五万七千四百名。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 10:14"> 凡属犹大营、按着军队被数的，共有十八万六千四百名，要作第一队往前行。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民数记 1:5; 创世记 49:3–4; 民数记 7:35"> 「在南边，按着军队是吕便营的纛。有示丢珥的儿子以利蓿作吕便人的首领。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 26:7; 民数记 1:21"> 他军队被数的，共有四万六千五百名。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 1:6; 民数记 10:19; 民数记 7:41"> 挨着他安营的是西缅支派。苏利沙代的儿子示路蔑作西缅人的首领。</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 26:14; 民数记 1:23"> 他军队被数的，共有五万九千三百名。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 1:14; 民数记 7:42; 民数记 7:47"> 又有迦得支派。丢珥的儿子以利雅萨作迦得人的首领。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 26:18; 民数记 1:25"> 他军队被数的，共有四万五千六百五十名，</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 10:18; 民数记 2:9; 民数记 2:24"> 凡属吕便营、按着军队被数的，共有十五万一千四百五十名，要作第二队往前行。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民数记 10:21; 民数记 10:17; 民数记 3:38"> 「随后，会幕要往前行，有利未营在诸营中间。他们怎样安营就怎样往前行，各按本位，各归本纛。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民数记 1:10; 民数记 10:22; 创世记 48:14–20"> 「在西边，按着军队是以法莲营的纛。亚米忽的儿子以利沙玛作以法莲人的首领。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 1:33; 民数记 26:37"> 他军队被数的，共有四万零五百名。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 1:10; 民数记 7:54; 民数记 10:23"> 挨着他的是玛拿西支派。比大蓿的儿子迦玛列作玛拿西人的首领。</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 26:34; 民数记 1:35"> 他军队被数的，共有三万二千二百名。</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 1:11; 民数记 7:60; 民数记 10:24"> 又有便雅悯支派。基多尼的儿子亚比但作便雅悯人的首领。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 1:37; 民数记 26:41"> 他军队被数的，共有三万五千四百名。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 10:22; 民数记 2:31; 诗篇 80:2"> 凡属以法莲营、按着军队被数的，共有十万零八千一百名，要作第三队往前行。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="民数记 1:12; 民数记 7:66; 民数记 10:25"> 「在北边，按着军队是但营的纛。亚米沙代的儿子亚希以谢作但人的首领。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 26:43; 民数记 1:39"> 他军队被数的，共有六万二千七百名。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 1:13; 民数记 7:77; 民数记 7:72"> 挨着他安营的是亚设支派。俄兰的儿子帕结作亚设人的首领。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 1:41; 民数记 26:47"> 他军队被数的，共有四万一千五百名。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 1:15; 民数记 10:27; 民数记 26:48–50"> 又有拿弗他利支派。以南的儿子亚希拉作拿弗他利人的首领。</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 1:42–43; 民数记 26:50"> 他军队被数的，共有五万三千四百名。</span>
<span className="v" id="v31" data-v="31" data-xref="民数记 10:25; 民数记 2:16; 民数记 2:9"> 凡但营被数的，共有十五万七千六百名，要归本纛作末队往前行。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="民数记 1:46; 出埃及记 38:26; 民数记 2:9"> 这些以色列人，照他们的宗族，按他们的军队，在诸营中被数的，共有六十万零三千五百五十名。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 26:57–62; 民数记 1:47–49"> 惟独利未人没有数在以色列人中，是照耶和华所吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="诗篇 119:6; 民数记 24:2; 民数记 24:5–6"> 以色列人就这样行，各人照他们的家室、宗族归于本纛，安营起行，都是照耶和华所吩咐摩西的。</span>
</div>
</div>

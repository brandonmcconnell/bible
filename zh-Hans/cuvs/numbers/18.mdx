## 祭司和利未人的职责

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 28:38; 希伯来书 13:17; 彼得前书 2:24"> 耶和华对亚伦说：「你和你的儿子，并你本族的人，要一同担当干犯圣所的罪孽。你和你的儿子也要一同担当干犯祭司职任的罪孽。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 29:34; 民数记 18:4; 以西结书 44:15"> 你要带你弟兄利未人，就是你祖宗支派的人前来，使他们与你联合，服事你，只是你和你的儿子，要一同在法柜的帐幕前供职。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 4:15; 民数记 16:40; 民数记 4:19–20"> 他们要守所吩咐你的，并守全帐幕，只是不可挨近圣所的器具和坛，免得他们和你们都死亡。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 6:19; 民数记 1:51; 民数记 3:10"> 他们要与你联合，也要看守会幕，办理帐幕一切的事，只是外人不可挨近你们。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 27:21; 利未记 24:3; 民数记 16:46"> 你们要看守圣所和坛，免得忿怒再临到以色列人。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 3:9; 民数记 3:12; 民数记 3:45"> 我已将你们的弟兄利未人从以色列人中拣选出来归耶和华，是给你们为赏赐的，为要办理会幕的事。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 15:15–16; 约翰福音 3:27; 民数记 3:10"> 你和你的儿子要为一切属坛和幔子内的事一同守祭司的职任。你们要这样供职；我将祭司的职任给你们当作赏赐事奉我。凡挨近的外人必被治死。」</span>
</div>
</div>

## 祭司当得之物

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未记 6:16; 利未记 7:6; 出埃及记 29:29"> 耶和华晓谕亚伦说：「我已将归我的举祭，就是以色列人一切分别为圣的物，交给你经管；因你受过膏，把这些都赐给你和你的子孙，当作永得的分。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 7:7; 利未记 14:13; 利未记 6:25–26"> 以色列人归给我至圣的供物，就是一切的素祭、赎罪祭、赎愆祭，其中所有存留不经火的，都为至圣之物，要归给你和你的子孙。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 7:6; 利未记 6:29; 利未记 6:16"> 你要拿这些当至圣物吃；凡男丁都可以吃。你当以此物为圣。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 18:3; 出埃及记 29:27–28; 利未记 10:14"> 以色列人所献的举祭并摇祭都是你的；我已赐给你和你的儿女，当作永得的分；凡在你家中的洁净人都可以吃。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 18:4; 出埃及记 23:19; 出埃及记 34:26"> 凡油中、新酒中、五谷中至好的，就是以色列人所献给耶和华初熟之物，我都赐给你。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 22:29; 出埃及记 23:19; 弥迦书 7:1"> 凡从他们地上所带来给耶和华初熟之物也都要归与你。你家中的洁净人都可以吃。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 27:28; 以西结书 44:29"> 以色列中一切永献的都必归与你。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 34:20; 出埃及记 13:2; 出埃及记 13:12–13"> 他们所有奉给耶和华的，连人带牲畜，凡头生的，都要归给你；只是人头生的，总要赎出来；不洁净牲畜头生的，也要赎出来。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 30:13; 民数记 3:47; 利未记 27:2–7"> 其中在一月之外所当赎的，要照你所估定的价，按圣所的平，用银子五舍客勒赎出来（一舍客勒是二十季拉）。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 29:16; 申命记 15:19–22; 利未记 3:2–5"> 只是头生的牛，或是头生的绵羊和山羊，必不可赎，都是圣的，要把它的血洒在坛上，把它的脂油焚烧，当作馨香的火祭献给耶和华。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 7:31–34; 出埃及记 29:26–28"> 它的肉必归你，像被摇的胸、被举的右腿归你一样。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 13:5; 利未记 2:13; 民数记 18:11"> 凡以色列人所献给耶和华圣物中的举祭，我都赐给你和你的儿女，当作永得的分。这是给你和你的后裔、在耶和华面前作为永远的盐约<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="盐就是不废坏的意思">a</a></sup>。」</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 44:28; 申命记 10:9; 约书亚记 13:33"> 耶和华对亚伦说：「你在以色列人的境内不可有产业，在他们中间也不可有分。我就是你的分，是你的产业。」</span>
</div>
</div>

## 利未人的分

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="尼希米记 12:44; 申命记 14:22–29; 尼希米记 10:37"> 「凡以色列中出产的十分之一，我已赐给利未的子孙为业；因他们所办的是会幕的事，所以赐给他们为酬他们的劳。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 22:9; 民数记 1:51–52; 民数记 3:38"> 从今以后，以色列人不可挨近会幕，免得他们担罪而死。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 3:7; 民数记 18:20; 民数记 18:1"> 惟独利未人要办会幕的事，担当罪孽；这要作你们世世代代永远的定例。他们在以色列人中不可有产业；</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 18:26; 玛拉基书 3:8–10"> 因为以色列人中出产的十分之一，就是献给耶和华为举祭的，我已赐给利未人为业。所以我对他们说：『在以色列人中不可有产业。』」</span>
</div>
</div>

## 利未人的十分之一奉献

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25"> 耶和华吩咐摩西说：</span>
<span className="v" id="v26" data-v="26" data-xref="尼希米记 10:38; 民数记 18:21"> 「你晓谕利未人说：你们从以色列人中所取的十分之一，就是我给你们为业的，要再从那十分之一中取十分之一作为举祭献给耶和华，</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 18:30; 申命记 15:14; 列王纪下 6:27"> 这举祭要算为你们场上的谷，又如满酒榨的酒。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 6:20–10; 创世记 14:18"> 这样，你们从以色列人中所得的十分之一也要作举祭献给耶和华，从这十分之一中，将所献给耶和华的举祭归给祭司亚伦。</span>
<span className="v" id="v29" data-v="29"> 奉给你们的一切礼物，要从其中将至好的，就是分别为圣的，献给耶和华为举祭。</span>
<span className="v" id="v30" data-v="30" data-xref="箴言 3:9–10; 创世记 43:11; 马太福音 6:33"> 所以你要对利未人说：你们从其中将至好的举起，这就算为你们场上的粮，又如酒榨的酒。</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多前书 9:10–14; 提摩太前书 5:17–18; 路加福音 10:7"> 你们和你们家属随处可以吃；这原是你们的赏赐，是酬你们在会幕里办事的劳。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 19:8; 利未记 22:2; 玛拉基书 1:7"> 你们从其中将至好的举起，就不至因这物担罪。你们不可亵渎以色列人的圣物，免得死亡。」</span>
</div>
</div>

## 民众埋怨

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 1:45; 民数记 11:1–4"> 当下，全会众大声喧嚷；那夜百姓都哭号。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 15:24; 出埃及记 17:3; 民数记 16:41"> 以色列众人向摩西、亚伦发怨言；全会众对他们说：「巴不得我们早死在埃及地，或是死在这旷野。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 14:31–32; 耶利米书 9:3; 诗篇 78:40"> 耶和华为什么把我们领到那地，使我们倒在刀下呢？我们的妻子和孩子必被掳掠。我们回埃及去岂不好吗？」</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 7:39; 尼希米记 9:16–17; 申命记 17:16"> 众人彼此说：「我们不如立一个首领回埃及去吧！」</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 16:4; 民数记 16:22; 民数记 16:45"> 摩西、亚伦就俯伏在以色列全会众面前。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 14:30; 民数记 13:30; 民数记 14:38"> 窥探地的人中，嫩的儿子约书亚和耶孚尼的儿子迦勒撕裂衣服，</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 13:27; 申命记 1:25; 申命记 8:7–9"> 对以色列全会众说：「我们所窥探、经过之地是极美之地。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 22:20; 以赛亚书 62:4; 民数记 13:27"> 耶和华若喜悦我们，就必将我们领进那地，把地赐给我们；那地原是流奶与蜜之地。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 7:18; 罗马书 8:31; 申命记 31:6"> 但你们不可背叛耶和华，也不要怕那地的居民；因为他们是我们的食物，并且荫庇他们的已经离开他们。有耶和华与我们同在，不要怕他们！」</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 17:4; 撒母耳记上 30:6; 利未记 9:23"> 但全会众说：「拿石头打死他们二人。」忽然，耶和华的荣光在会幕中向以色列众人显现。</span>
</div>
</div>

## 摩西为民众祷告

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="诗篇 78:32; 诗篇 106:24; 诗篇 78:22"> 耶和华对摩西说：「这百姓藐视我要到几时呢？我在他们中间行了这一切神迹，他们还不信我要到几时呢？</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 32:10; 民数记 25:9; 撒母耳记下 24:12–15"> 我要用瘟疫击杀他们，使他们不得承受那地，叫你的后裔成为大国，比他们强胜。」</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 106:23; 以西结书 20:9; 申命记 32:27"> 摩西对耶和华说：「埃及人必听见这事；因为你曾施展大能，将这百姓从他们中间领上来。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 15:14; 出埃及记 33:11; 申命记 5:4"> 埃及人要将这事传给迦南地的居民；那民已经听见你—耶和华是在这百姓中间；因为你面对面被人看见，有你的云彩停在他们以上。你日间在云柱中，夜间在火柱中，在他们前面行。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 6:16"> 如今你若把这百姓杀了，如杀一人，那些听见你名声的列邦必议论说：</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 9:28; 约书亚记 7:9; 约书亚记 7:7"> 『耶和华因为不能把这百姓领进他向他们起誓应许之地，所以在旷野把他们杀了。』</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 9:6; 马太福音 9:8; 弥迦书 3:8"> 现在求主大显能力，照你所说过的话说：</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 34:6–7; 诗篇 145:8; 出埃及记 20:5"> 『耶和华不轻易发怒，并有丰盛的慈爱，赦免罪孽和过犯；万不以有罪的为无罪，必追讨他的罪，自父及子，直到三、四代。』</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 34:9; 诗篇 78:38; 诗篇 106:45"> 求你照你的大慈爱赦免这百姓的罪孽，好像你从埃及到如今常赦免他们一样。」</span>
<span className="v" id="v20" data-v="20" data-xref="弥迦书 7:18–20; 雅各书 5:16; 诗篇 106:23"> 耶和华说：「我照着你的话赦免了他们。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 72:19; 哈巴谷书 2:14; 以赛亚书 6:3"> 然我指着我的永生起誓，遍地要被我的荣耀充满。</span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 19:3; 创世记 31:7; 出埃及记 32:1"> 这些人虽看见我的荣耀和我在埃及与旷野所行的神迹，仍然试探我这十次，不听从我的话，</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 32:11; 民数记 26:64; 以西结书 20:15"> 他们断不得看见我向他们的祖宗所起誓应许之地。凡藐视我的，一个也不得看见；</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 14:6–9; 约书亚记 14:6–14; 以弗所书 6:6"> 惟独我的仆人迦勒，因他另有一个心志，专一跟从我，我就把他领进他所去过的那地；他的后裔也必得那地为业。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 1:40; 民数记 13:29; 诗篇 81:11–13"> 亚玛力人和迦南人住在谷中，明天你们要转回，从红海的路往旷野去。」</span>
</div>
</div>

## 耶和华惩罚埋怨的民众

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和华对摩西、亚伦说：</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 16:12; 哥林多前书 10:10; 出埃及记 16:28"> 「这恶会众向我发怨言，我忍耐他们要到几时呢？以色列人向我所发的怨言，我都听见了。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 14:21; 希伯来书 3:17; 民数记 14:2"> 你们告诉他们，耶和华说：『我指着我的永生起誓，我必要照你们达到我耳中的话待你们。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 1:45; 哥林多前书 10:5; 希伯来书 3:17"> 你们的尸首必倒在这旷野，并且你们中间凡被数点、从二十岁以外、向我发怨言的，</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 26:65; 民数记 14:38; 申命记 1:36–38"> 必不得进我起誓应许叫你们住的那地；惟有耶孚尼的儿子迦勒和嫩的儿子约书亚才能进去。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 1:39; 诗篇 106:24; 民数记 26:64"> 但你们的妇人孩子，就是你们所说、要被掳掠的，我必把他们领进去，他们就得知你们所厌弃的那地。</span>
<span className="v" id="v32" data-v="32" data-xref="哥林多前书 10:5; 民数记 14:29; 希伯来书 3:17"> 至于你们，你们的尸首必倒在这旷野；</span>
<span className="v" id="v33" data-v="33" data-xref="以西结书 23:35; 民数记 32:13; 申命记 2:14"> 你们的儿女必在旷野飘流四十年，担当你们淫行的罪，直到你们的尸首在旷野消灭。</span>
<span className="v" id="v34" data-v="34" data-xref="以西结书 4:6; 民数记 13:25; 耶利米书 18:9–10"> 按你们窥探那地的四十日，一年顶一日，你们要担当罪孽四十年，就知道我与你们疏远了，</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 23:19; 哥林多前书 10:5; 希伯来书 3:19"> 我—耶和华说过，我总要这样待这一切聚集敌我的恶会众；他们必在这旷野消灭，在这里死亡。』」</span>
<span className="v" id="v36" data-v="36" data-xref="民数记 13:31–33; 民数记 13:4–16"> 摩西所打发、窥探那地的人回来，报那地的恶信，叫全会众向摩西发怨言，</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前书 10:10; 民数记 16:49; 希伯来书 3:17"> 这些报恶信的人都遭瘟疫，死在耶和华面前。</span>
<span className="v" id="v38" data-v="38" data-xref="约书亚记 14:6–10; 民数记 26:65"> 其中惟有嫩的儿子约书亚和耶孚尼的儿子迦勒仍然存活。</span>
</div>
</div>

## 首次进攻迦南

<div className="bt">
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出埃及记 33:4; 马太福音 8:12; 希伯来书 12:17"> 摩西将这些话告诉以色列众人，他们就甚悲哀。</span>
<span className="v" id="v40" data-v="40" data-xref="申命记 1:41; 马太福音 7:21–23; 路加福音 13:25"> 清早起来，上山顶去，说：「我们在这里，我们有罪了；情愿上耶和华所应许的地方去。」</span>
<span className="v" id="v41" data-v="41" data-xref="历代志下 24:20; 约伯记 4:9; 耶利米书 2:37"> 摩西说：「你们为何违背耶和华的命令呢？这事不能顺利了。</span>
<span className="v" id="v42" data-v="42" data-xref="申命记 1:42; 约书亚记 7:8; 约书亚记 7:12"> 不要上去；因为耶和华不在你们中间，恐怕你们被仇敌杀败了。</span>
<span className="v" id="v43" data-v="43" data-xref="民数记 13:29; 民数记 14:25; 历代志下 15:2"> 亚玛力人和迦南人都在你们面前，你们必倒在刀下；因你们退回不跟从耶和华，所以他必不与你们同在。」</span>
<span className="v" id="v44" data-v="44" data-xref="申命记 1:43; 撒母耳记上 4:3–11; 民数记 31:6"> 他们却擅敢上山顶去，然而耶和华的约柜和摩西没有出营。</span>
<span className="v" id="v45" data-v="45" data-xref="民数记 21:3; 士师记 1:17; 申命记 1:44"> 于是亚玛力人和住在那山上的迦南人都下来击打他们，把他们杀退了，直到何珥玛。</span>
</div>
</div>

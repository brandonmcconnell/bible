## 分给利未人的城邑

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 22:1; 民数记 31:12; 民数记 33:50"> 耶和华在摩押平原—约旦河边、耶利哥对面晓谕摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 14:3–4; 以西结书 48:8; 约书亚记 21:2–42"> 「你吩咐以色列人，要从所得为业的地中把些城给利未人居住，也要把这城四围的郊野给利未人。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 11:14; 约书亚记 21:11; 以西结书 45:2"> 这城邑要归他们居住，城邑的郊野可以牧养他们的牛羊和各样的牲畜，又可以安置他们的财物。</span>
<span className="v" id="v4" data-v="4"> 你们给利未人的郊野，要从城根起，四围往外量一千肘。</span>
<span className="v" id="v5" data-v="5"> 另外东量二千肘，南量二千肘，西量二千肘，北量二千肘，为边界，城在当中；这要归他们作城邑的郊野。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 21:13; 约书亚记 21:3; 诗篇 9:9"> 你们给利未人的城邑，其中当有六座逃城，使误杀人的可以逃到那里。此外还要给他们四十二座城。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 21:3–42; 历代志上 6:54–81"> 你们要给利未人的城，共有四十八座，连城带郊野都要给他们。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 26:54; 民数记 33:54; 约书亚记 21:1–42"> 以色列人所得的地业从中要把些城邑给利未 人；人多的就多给，人少的就少给；各支派要按所承受为业之地把城邑给利未人。」</span>
</div>
</div>

## 逃城

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9"> 耶和华晓谕摩西说：</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 12:9; 申命记 19:1–2; 利未记 14:34"> 「你吩咐以色列人说：你们过约旦河，进了迦南地，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 21:13; 约书亚记 20:2; 民数记 35:6"> 就要分出几座城，为你们作逃城，使误杀人的可以逃到那里。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 20:3–6; 申命记 19:6; 约书亚记 20:9"> 这些城可以作逃避报仇人的城，使误杀人的不至于死，等他站在会众面前听审判。</span>
<span className="v" id="v13" data-v="13"> 你们所分出来的城，要作六座逃城。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 19:8–10; 申命记 4:41–43; 约书亚记 20:7–9"> 在约旦河东要分出三座城，在迦南地也要分出三座城，都作逃城。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 15:16; 加拉太书 3:28; 罗马书 3:29"> 这六座城要给以色列人和他们中间的外人，并寄居的，作为逃城，使误杀人的都可以逃到那里。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="利未记 24:17; 创世记 9:5–6; 申命记 19:11–13"> 「倘若人用铁器打人，以致打死，他就是故杀人的；故杀人的必被治死。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 21:18"> 若用可以打死人的石头打死了人，他就是故杀人的；故杀人的必被治死。</span>
<span className="v" id="v18" data-v="18"> 若用可以打死人的木器打死了人，他就是故杀人的；故杀人的必被治死。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 20:3; 申命记 19:6; 申命记 19:12"> 报血仇的必亲自杀那故杀人的，一遇见就杀他。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 21:14; 申命记 19:11; 撒母耳记下 3:27"> 人若因怨恨把人推倒，或是埋伏往人身上扔物，以致于死，</span>
<span className="v" id="v21" data-v="21"> 或是因仇恨用手打人，以致于死，那打人的必被治死。他是故杀人的；报血仇的一遇见就杀他。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数记 35:11; 出埃及记 21:13; 约书亚记 20:3"> 「倘若人没有仇恨，忽然将人推倒，或是没有埋伏把物扔在人身上，</span>
<span className="v" id="v23" data-v="23"> 或是没有看见的时候用可以打死人的石头扔在人身上，以致于死，本来与他无仇，也无意害他。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 20:6; 民数记 35:12"> 会众就要照典章，在打死人的和报血仇的中间审判。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 29:7; 利未记 4:3; 罗马书 3:24–26"> 会众要救这误杀人的脱离报血仇人的手，也要使他归入逃城。他要住在其中，直等到受圣膏的大祭司死了。</span>
<span className="v" id="v26" data-v="26"> 但误杀人的，无论什么时候，若出了逃城的境外，</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 22:2; 申命记 19:10; 申命记 19:6"> 报血仇的在逃城境外遇见他，将他杀了，报血仇的就没有流血之罪。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 3:14; 希伯来书 10:26–30; 希伯来书 6:4–8"> 因为误杀人的该住在逃城里，等到大祭司死了。大祭司死了以后，误杀人的才可以回到他所得为业之地。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 27:11; 民数记 27:1"> 这在你们一切的住处，要作你们世世代代的律例典章。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="希伯来书 10:28; 申命记 19:15; 马太福音 18:16"> 「无论谁故杀人，要凭几个见证人的口把那故杀人的杀了，只是不可凭一个见证的口叫人死。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 19:11–13; 创世记 9:5–6; 诗篇 51:14"> 故杀人、犯死罪的，你们不可收赎价代替他的命；他必被治死。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 4:12; 加拉太书 3:10–13; 加拉太书 2:21"> 那逃到逃城的人，你们不可为他收赎价，使他在大祭司未死以先再来住在本地。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 11:50–51; 诗篇 106:38; 何西阿书 4:2–3"> 这样，你们就不污秽所住之地，因为血是污秽地的；若有在地上流人血的，非流那杀人者的血，那地就不得洁净<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是赎">a</a></sup>。</span>
<span className="v" id="v34" data-v="34" data-xref="民数记 5:3; 诗篇 135:21; 启示录 21:27"> 你们不可玷污所住之地，就是我住在其中之地，因为我—耶和华住在以色列人中间。」</span>
</div>
</div>

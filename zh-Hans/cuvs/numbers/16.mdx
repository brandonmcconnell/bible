## 可拉、大坍、亚比兰的叛变

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="犹大书 1:11; 申命记 11:6; 出埃及记 6:21"> 利未的曾孙、哥辖的孙子、以斯哈的儿子可拉，和吕便子孙中以利押的儿子大坍、亚比兰，与比勒的儿子安，</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 26:9; 以西结书 23:10; 创世记 6:4"> 并以色列会中的二百五十个首领，就是有名望选入会中的人，在摩西面前一同起来，</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 106:16; 民数记 14:14; 出埃及记 19:6"> 聚集攻击摩西、亚伦，说：「你们擅自专权！全会众个个既是圣洁，耶和华也在他们中间，你们为什么自高，超过耶和华的会众呢？」</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 14:5; 民数记 20:6; 约书亚记 7:6"> 摩西听见这话就俯伏在地，</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 65:4; 民数记 17:5; 提摩太后书 2:19"> 对可拉和他一党的人说：「到了早晨，耶和华必指示谁是属他的，谁是圣洁的，就叫谁亲近他；他所拣选的是谁，必叫谁亲近他。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 10:1; 民数记 16:46–48; 列王纪上 18:21–23"> 可拉啊，你们要这样行，你和你的一党要拿香炉来。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 16:3; 以弗所书 1:4; 列王纪上 18:17–18"> 明日，在耶和华面前，把火盛在炉中，把香放在其上。耶和华拣选谁，谁就为圣洁。你们这利未的子孙擅自专权了！」</span>
<span className="v" id="v8" data-v="8"> 摩西又对可拉说：「利未的子孙哪，你们听我说！</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 7:13; 申命记 10:8; 以西结书 44:10–11"> 以色列的 神从以色列会中将你们分别出来，使你们亲近他，办耶和华帐幕的事，并站在会众面前替他们当差。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 13:10; 约翰三书 1:9; 民数记 18:7"> 耶和华又使你和你一切弟兄—利未的子孙—一同亲近他，这岂为小事？你们还要求祭司的职任吗？</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 16:7–8; 出埃及记 17:2; 民数记 16:3"> 你和你一党的人聚集是要攻击耶和华。亚伦算什么，你们竟向他发怨言呢？」</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 2:13–14; 犹大书 1:8; 箴言 29:9"> 摩西打发人去召以利押的儿子大坍、亚比兰。他们说：「我们不上去！</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 7:35; 出埃及记 2:14; 民数记 11:5"> 你将我们从流奶与蜜之地领上来，要在旷野杀我们，这岂为小事？你还要自立为王辖管我们吗？</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 20:24; 民数记 36:8–10; 民数记 20:5"> 并且你没有将我们领到流奶与蜜之地，也没有把田地和葡萄园给我们为业。难道你要剜这些人的眼睛吗？我们不上去！」</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 4:4–5; 哥林多后书 7:2; 帖撒罗尼迦前书 2:10"> 摩西就甚发怒，对耶和华说：「求你不要享受他们的供物。我并没有夺过他们一匹驴，也没有害过他们一个人。」</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 12:3; 撒母耳记上 12:7; 提摩太后书 2:14"> 摩西对可拉说：「明天，你和你一党的人，并亚伦，都要站在耶和华面前；</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 12:7"> 各人要拿一个香炉，共二百五十个，把香放在上面，到耶和华面前。你和亚伦也各拿自己的香炉。」</span>
<span className="v" id="v18" data-v="18"> 于是他们各人拿一个香炉，盛上火，加上香，同摩西、亚伦站在会幕门前。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 14:10; 民数记 16:42; 出埃及记 16:7"> 可拉招聚全会众到会幕门前，要攻击摩西、亚伦；耶和华的荣光就向全会众显现。</span>
<span className="v" id="v20" data-v="20"> 耶和华晓谕摩西、亚伦说：</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 16:45; 出埃及记 32:10; 诗篇 73:19"> 「你们离开这会众，我好在转眼之间把他们灭绝。」</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 27:16; 撒迦利亚书 12:1; 约伯记 12:10"> 摩西、亚伦就俯伏在地，说：「 神，万人之灵的 神啊，一人犯罪，你就要向全会众发怒吗？」</span>
<span className="v" id="v23" data-v="23"> 耶和华晓谕摩西说：</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 16:21"> 「你吩咐会众说：『你们离开可拉、大坍、亚比兰帐棚的四围。』」</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 11:16–17; 民数记 11:25; 民数记 11:30"> 摩西起来，往大坍、亚比兰那里去；以色列的长老也随着他去。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 52:11; 哥林多后书 6:17; 启示录 18:4"> 他吩咐会众说：「你们离开这恶人的帐棚吧，他们的物件，什么都不可摸，恐怕你们陷在他们的罪中，与他们一同消灭。」</span>
<span className="v" id="v27" data-v="27" data-xref="约伯记 9:4; 以赛亚书 28:14; 约伯记 40:10–11"> 于是众人离开可拉、大坍、亚比兰帐棚的四围。大坍、亚比兰带着妻子、儿女、小孩子，都出来，站在自己的帐棚门口。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 6:38; 出埃及记 3:12; 约翰福音 14:11"> 摩西说：「我行的这一切事本不是凭我自己心意行的，乃是耶和华打发我行的，必有证据使你们知道。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米哀歌 4:22; 列王纪上 22:28; 出埃及记 32:34"> 这些人死若与世人无异，或是他们所遭的与世人相同，就不是耶和华打发我来的。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 55:15; 民数记 16:33; 约伯记 31:3"> 倘若耶和华创作一件新事，使地开口，把他们和一切属他们的都吞下去，叫他们活活地坠落阴间，你们就明白这些人是藐视耶和华了。」</span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 106:17–18; 民数记 27:3; 申命记 11:6"> 摩西刚说完了这一切话，他们脚下的地就开了口，</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 106:17; 民数记 26:11; 启示录 12:16"> 把他们和他们的家眷，并一切属可拉的人丁、财物，都吞下去。</span>
<span className="v" id="v33" data-v="33" data-xref="以西结书 32:18; 以赛亚书 14:9; 诗篇 9:15"> 这样，他们和一切属他们的，都活活地坠落阴间；地口在他们上头照旧合闭，他们就从会中灭亡。</span>
<span className="v" id="v34" data-v="34" data-xref="撒迦利亚书 14:5; 以赛亚书 33:3; 启示录 6:15–17"> 在他们四围的以色列众人听他们呼号，就都逃跑，说：「恐怕地也把我们吞下去。」</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 26:10; 利未记 10:2; 诗篇 106:18"> 又有火从耶和华那里出来，烧灭了那献香的二百五十个人。</span>
</div>
</div>

## 香炉

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36"> 耶和华晓谕摩西说：</span>
<span className="v" id="v37" data-v="37" data-xref="利未记 27:28; 民数记 16:18; 民数记 16:7"> 「你吩咐祭司亚伦的儿子以利亚撒从火中捡起那些香炉来，把火撒在别处，因为那些香炉是圣的。</span>
<span className="v" id="v38" data-v="38" data-xref="民数记 26:10; 以西结书 14:8; 彼得后书 2:6"> 把那些犯罪、自害己命之人的香炉，叫人锤成片子，用以包坛。那些香炉本是他们在耶和华面前献过的，所以是圣的，并且可以给以色列人作记号。」</span>
<span className="v" id="v39" data-v="39"> 于是祭司以利亚撒将被烧之人所献的铜香炉拿来，人就锤出来，用以包坛，</span>
<span className="v" id="v40" data-v="40" data-xref="民数记 3:10; 民数记 18:4–7; 历代志下 26:16–21"> 给以色列人作纪念，使亚伦后裔之外的人不得近前来在耶和华面前烧香，免得他遭可拉和他一党所遭的。这乃是照耶和华借着摩西所吩咐的。</span>
</div>
</div>

## 亚伦救了人民

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数记 16:1–7; 诗篇 106:23; 民数记 14:2"> 第二天，以色列全会众都向摩西、亚伦发怨言说：「你们杀了耶和华的百姓了。」</span>
<span className="v" id="v42" data-v="42" data-xref="民数记 16:19; 利未记 9:23; 民数记 20:6"> 会众聚集攻击摩西、亚伦的时候，向会幕观看，不料，有云彩遮盖了，耶和华的荣光显现。</span>
<span className="v" id="v43" data-v="43"> 摩西、亚伦就来到会幕前。</span>
<span className="v" id="v44" data-v="44"> 耶和华吩咐摩西说：</span>
<span className="v" id="v45" data-v="45" data-xref="民数记 16:21–22; 民数记 16:24; 民数记 20:6"> 「你们离开这会众，我好在转眼之间把他们灭绝。」他们二人就俯伏于地。</span>
<span className="v" id="v46" data-v="46" data-xref="民数记 8:19; 历代志上 27:24; 利未记 10:6"> 摩西对亚伦说：「拿你的香炉，把坛上的火盛在其中，又加上香，快快带到会众那里，为他们赎罪；因为有忿怒从耶和华那里出来，瘟疫已经发作了。」</span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 5:44; 申命记 33:10–11; 诗篇 106:29"> 亚伦照着摩西所说的拿来，跑到会中，不料，瘟疫在百姓中已经发作了。他就加上香，为百姓赎罪。</span>
<span className="v" id="v48" data-v="48" data-xref="撒母耳记下 24:25; 希伯来书 7:24–25; 民数记 16:18"> 他站在活人死人中间，瘟疫就止住了。</span>
<span className="v" id="v49" data-v="49" data-xref="民数记 25:9; 民数记 16:32–35; 希伯来书 2:1–3"> 除了因可拉事情死的以外，遭瘟疫死的，共有一万四千七百人。</span>
<span className="v" id="v50" data-v="50" data-xref="历代志上 21:26–30; 民数记 16:43"> 亚伦回到会幕门口，到摩西那里，瘟疫已经止住了。</span>
</div>
</div>

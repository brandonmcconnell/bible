## 不洁的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华晓谕摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 21:1; 利未记 13:46; 民数记 12:14"> 「你吩咐以色列人，使一切长大麻风的，患漏症的，并因死尸不洁净的，都出营外去。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 23:14; 利未记 26:11–12; 诗篇 68:18"> 无论男女都要使他们出到营外，免得污秽他们的营；这营是我所住的。」</span>
<span className="v" id="v4" data-v="4"> 以色列人就这样行，使他们出到营外。耶和华怎样吩咐摩西，以色列人就怎样行了。</span>
</div>
</div>

## 赔偿亏负

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5"> 耶和华对摩西说：</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 5:1–4; 利未记 5:14–7"> 「你晓谕以色列人说：无论男女，若犯了人所常犯的罪，以致干犯耶和华，那人就有了罪。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 5:5; 利未记 26:40; 约书亚记 7:19"> 他要承认所犯的罪，将所亏负人的，如数赔还，另外加上五分之一，也归与所亏负的人。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 6:6–7; 利未记 7:7; 利未记 25:25–26"> 那人若没有亲属可受所赔还的，那所赔还的就要归与服事耶和华的祭司；至于那为他赎罪的公羊是在外。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 18:3–4; 利未记 7:6–14; 利未记 6:17–18"> 以色列人一切的圣物中，所奉给祭司的举祭都要归与祭司。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 10:13"> 各人所分别为圣的物，无论是什么，都要归给祭司。」</span>
</div>
</div>

## 疑妻不贞的案件

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和华对摩西说：</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 5:19–20; 箴言 2:16–17"> 「你晓谕以色列人说：人的妻若有邪行，得罪她丈夫，</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 18:20; 利未记 20:10; 箴言 7:18–19"> 有人与她行淫，事情严密，瞒过她丈夫，而且她被玷污，没有作见证的人，当她行淫的时候也没有被捉住，</span>
<span className="v" id="v14" data-v="14" data-xref="雅歌 8:6; 箴言 6:34; 西番雅书 3:8"> 她丈夫生了疑恨的心，疑恨她，她是被玷污，或是她丈夫生了疑恨的心，疑恨她，她并没有被玷污，</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 29:16; 列王纪上 17:18; 利未记 5:11"> 这人就要将妻送到祭司那里，又为她带着大麦面伊法十分之一作供物，不可浇上油，也不可加上乳香；因为这是疑恨的素祭，是思念的素祭，使人思念罪孽。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="启示录 2:22–23; 耶利米书 17:10; 希伯来书 13:4"> 「祭司要使那妇人近前来，站在耶和华面前。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 30:18; 约翰福音 8:6; 民数记 19:2–9"> 祭司要把圣水盛在瓦器里，又从帐幕的地上取点尘土，放在水中。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 5:4; 民数记 5:22; 启示录 10:9–10"> 祭司要叫那妇人蓬头散发，站在耶和华面前，把思念的素祭，就是疑恨的素祭，放在她手中。祭司手里拿着致咒诅的苦水，</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 7:2; 民数记 5:12; 马太福音 26:63"> 要叫妇人起誓，对她说：『若没有人与你行淫，也未曾背着丈夫做污秽的事，你就免受这致咒诅苦水的灾。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 5:12"> 你若背着丈夫行了污秽的事，在你丈夫以外有人与你行淫，</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 6:26; 尼希米记 10:29; 撒母耳记上 14:24"> （祭司叫妇人发咒起誓，）愿耶和华叫你大腿消瘦，肚腹发胀，使你在你民中被人咒诅，成了誓语；</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 109:18; 诗篇 89:52; 约伯记 31:39–40"> 并且这致咒诅的水入你的肠中，要叫你的肚腹发胀，大腿消瘦。』妇人要回答说：『阿们，阿们。』</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 3:19; 诗篇 51:1; 诗篇 51:9"> 「祭司要写这咒诅的话，将所写的字抹在苦水里，</span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亚书 5:3–4; 玛拉基书 3:5"> 又叫妇人喝这致咒诅的苦水；这水要进入她里面变苦了。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 8:27; 民数记 5:18; 民数记 5:15"> 祭司要从妇人的手中取那疑恨的素祭，在耶和华面前摇一摇，拿到坛前；</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 2:2; 利未记 2:9; 利未记 5:12"> 又要从素祭中取出一把，作为这事的纪念，烧在坛上，然后叫妇人喝这水。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 42:18; 撒迦利亚书 8:13; 耶利米书 29:18"> 叫她喝了以后，她若被玷污，得罪了丈夫，这致咒诅的水必进入她里面变苦了，她的肚腹就要发胀，大腿就要消瘦，那妇人便要在他民中被人咒诅。</span>
<span className="v" id="v28" data-v="28" data-xref="弥迦书 7:7–10; 哥林多后书 4:17; 诗篇 113:9"> 若妇人没有被玷污，却是清洁的，就要免受这灾，且要怀孕。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数记 5:19; 民数记 5:12; 民数记 5:15"> 「妻子背着丈夫行了污秽的事，</span>
<span className="v" id="v30" data-v="30"> 或是人生了疑恨的心，疑恨他的妻，就有这疑恨的条例。那时他要叫妇人站在耶和华面前，祭司要在她身上照这条例而行。</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 20:10; 罗马书 2:8–9; 以西结书 18:4"> 男人就为无罪，妇人必担当自己的罪孽。」</span>
</div>
</div>

</div>

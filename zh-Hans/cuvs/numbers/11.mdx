## 在他备拉发怨言

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 21:5; 民数记 16:35; 列王纪下 1:12"> 众百姓发怨言，他们的恶语达到耶和华的耳中。耶和华听见了就怒气发作，使火在他们中间焚烧，直烧到营的边界。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 21:7; 雅各书 5:16; 民数记 16:45–48"> 百姓向摩西哀求，摩西祈求耶和华，火就熄了。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 9:22"> 那地方便叫做他备拉，因为耶和华的火烧在他们中间。</span>
</div>

## 摩西选立七十个长老

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 10:6; 出埃及记 12:38; 诗篇 106:14"> 他们中间的闲杂人大起贪欲的心；以色列人又哭号说：「谁给我们肉吃呢？</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 16:3; 诗篇 17:14; 腓立比书 3:19"> 我们记得，在埃及的时候不花钱就吃鱼，也记得有黄瓜、西瓜、韭菜、葱、蒜。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 21:5; 撒母耳记下 13:4"> 现在我们的心血枯竭了，除这吗哪以外，在我们眼前并没有别的东西。」</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 16:31; 创世记 2:12; 出埃及记 16:14–15"> 这吗哪仿佛芫荽子，又好像珍珠。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 16:31; 出埃及记 16:16–18; 出埃及记 16:23"> 百姓周围行走，把吗哪收起来，或用磨推，或用臼捣，煮在锅中，又做成饼，滋味好像新油。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 16:13–14; 诗篇 78:23–25; 申命记 32:2"> 夜间露水降在营中，吗哪也随着降下。）</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 78:21; 民数记 16:27; 民数记 14:1–2"> 摩西听见百姓各在各家的帐棚门口哭号。耶和华的怒气便大发作，摩西就不喜悦。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 1:12; 出埃及记 5:22; 耶利米书 15:10"> 摩西对耶和华说：「你为何苦待仆人？我为何不在你眼前蒙恩，竟把这管理百姓的重任加在我身上呢？</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 49:23; 以赛亚书 40:11; 帖撒罗尼迦前书 2:7"> 这百姓岂是我怀的胎，岂是我生下来的呢？你竟对我说：『把他们抱在怀里，如养育之父抱吃奶的孩子，直抱到你起誓应许给他们祖宗的地去。』</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 15:33; 马可福音 8:4; 约翰福音 6:5–9"> 我从哪里得肉给这百姓吃呢？他们都向我哭号说：『你给我们肉吃吧！』</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 18:18; 申命记 1:9–12; 哥林多后书 2:16"> 管理这百姓的责任太重了，我独自担当不起。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比书 1:20–24; 列王纪上 19:4; 约拿书 4:3"> 你这样待我，我若在你眼前蒙恩，求你立时将我杀了，不叫我见自己的苦情。」</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 24:1; 出埃及记 24:9; 申命记 16:18"> 耶和华对摩西说：「你从以色列的长老中招聚七十个人，就是你所知道作百姓的长老和官长的，到我这里来，领他们到会幕前，使他们和你一同站立。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 11:25; 撒母耳记上 10:6; 哥林多前书 12:4–11"> 我要在那里降临，与你说话，也要把降于你身上的灵分赐他们，他们就和你同当这管百姓的重任，免得你独自担当。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 19:10; 使徒行传 7:39; 出埃及记 16:3–7"> 又要对百姓说：『你们应当自洁，预备明天吃肉，因为你们哭号说：谁给我们肉吃！我们在埃及很好。这声音达到了耶和华的耳中，所以他必给你们肉吃。</span>
<span className="v" id="v19" data-v="19"> 你们不止吃一天、两天、五天、十天、二十天，</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 106:15; 民数记 21:5; 诗篇 78:27–30"> 要吃一个整月，甚至肉从你们鼻孔里喷出来，使你们厌恶了，因为你们厌弃住在你们中间的耶和华，在他面前哭号说：我们为何出了埃及呢！』」</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 12:37; 民数记 1:46; 创世记 12:2"> 摩西对耶和华说：「这与我同住的百姓、步行的男人有六十万，你还说：『我要把肉给他们，使他们可以吃一个整月。』</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 15:33; 列王纪下 7:2; 约翰福音 6:9"> 难道给他们宰了羊群牛群，或是把海中所有的鱼都聚了来，就够他们吃吗？」</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 59:1; 以赛亚书 50:2; 创世记 18:14"> 耶和华对摩西说：「耶和华的膀臂岂是缩短了吗？现在要看我的话向你应验不应验。」</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 11:16; 民数记 11:26"> 摩西出去，将耶和华的话告诉百姓，又招聚百姓的长老中七十个人来，使他们站在会幕的四围。</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 11:17; 约珥书 2:28–29; 撒母耳记上 10:10"> 耶和华在云中降临，对摩西说话，把降与他身上的灵分赐那七十个长老。灵停在他们身上的时候，他们就受感说话，以后却没有再说。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 36:5; 撒母耳记上 20:26; 撒母耳记上 10:22"> 但有两个人仍在营里，一个名叫伊利达，一个名叫米达。他们本是在那些被录的人中，却没有到会幕那里去。灵停在他们身上，他们就在营里说预言。</span>
<span className="v" id="v27" data-v="27"> 有个少年人跑来告诉摩西说：「伊利达、米达在营里说预言。」</span>
<span className="v" id="v28" data-v="28" data-xref="马可福音 9:38–40; 路加福音 9:49–50; 约翰福音 3:26"> 摩西的帮手，嫩的儿子约书亚，就是摩西所拣选的一个人，说：「请我主摩西禁止他们。」</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 14:5; 马太福音 9:37–38; 路加福音 10:2"> 摩西对他说：「你为我的缘故嫉妒人吗？惟愿耶和华的百姓都受感说话！愿耶和华把他的灵降在他们身上！」</span>
<span className="v" id="v30" data-v="30"> 于是，摩西和以色列的长老都回到营里去。</span>
</div>
</div>

## 神赐鹌鹑为食物

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及记 16:13; 诗篇 105:40; 诗篇 78:26–29"> 有风从耶和华那里刮起，把鹌鹑由海面刮来，飞散在营边和营的四围；这边约有一天的路程，那边约有一天的路程，离地面约有二肘。</span>
<span className="v" id="v32" data-v="32" data-xref="以西结书 45:11; 出埃及记 16:36"> 百姓起来，终日终夜，并次日一整天，捕取鹌鹑；至少的也取了十贺梅珥，为自己摆列在营的四围。</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 78:30–31; 诗篇 106:14–15; 民数记 25:9"> 肉在他们牙齿之间尚未嚼烂，耶和华的怒气就向他们发作，用最重的灾殃击杀了他们。</span>
<span className="v" id="v34" data-v="34" data-xref="申命记 9:22; 哥林多前书 10:6; 民数记 33:16"> 那地方便叫做基博罗·哈他瓦<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是贪欲之人的坟墓">a</a></sup>，因为他们在那里葬埋那起贪欲之心的人。</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 33:17; 民数记 12:16; 申命记 1:1"> 百姓从基博罗·哈他瓦走到哈洗录，就住在哈洗录。</span>
</div>

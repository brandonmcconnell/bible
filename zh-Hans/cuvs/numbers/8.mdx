## 安置七盏灯

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华晓谕摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 25:37; 出埃及记 40:25; 利未记 24:1–2"> 「你告诉亚伦说：点灯的时候，七盏灯都要向灯台前面发光。」</span>
<span className="v" id="v3" data-v="3"> 亚伦便这样行。他点灯台上的灯，使灯向前发光，是照耶和华所吩咐摩西的。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 25:31–40; 出埃及记 25:9; 出埃及记 25:18"> 这灯台的做法是用金子锤出来的，连座带花都是锤出来的。摩西制造灯台，是照耶和华所指示的样式。</span>
</div>
</div>

## 为利未人行洁净与奉献礼

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5"> 耶和华晓谕摩西说：</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 7:1; 雅各书 4:8; 出埃及记 19:15"> 「你从以色列人中选出利未人来，洁净他们。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 19:13; 民数记 19:7–10; 利未记 8:6"> 洁净他们当这样行：用除罪水弹在他们身上，又叫他们用剃头刀刮全身，洗衣服，洁净自己。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 2:1; 出埃及记 29:1; 利未记 16:3"> 然后叫他们取一只公牛犊，并同献的素祭，就是调油的细面；你要另取一只公牛犊作赎罪祭。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 40:12; 利未记 8:3; 出埃及记 29:4–37"> 将利未人奉到会幕前，招聚以色列全会众。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 1:4; 使徒行传 6:6; 提摩太前书 4:14"> 将利未人奉到耶和华面前，以色列人要按手在他们头上。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 7:30; 利未记 8:29; 民数记 1:49–53"> 亚伦也将他们奉到耶和华面前，为以色列人当作摇祭，使他们好办耶和华的事。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 10:4–10; 出埃及记 29:10; 利未记 1:4"> 利未人要按手在那两只牛的头上；你要将一只作赎罪祭，一只作燔祭，献给耶和华，为利未人赎罪。</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 8:21; 民数记 8:11; 罗马书 15:16"> 你也要使利未人站在亚伦和他儿子面前，将他们当作摇祭奉给耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 3:45; 玛拉基书 3:17; 民数记 18:6"> 「这样，你从以色列人中将利未人分别出来，利未人便要归我。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 8:11; 民数记 8:13; 民数记 3:23–37"> 此后利未人要进去办会幕的事，你要洁净他们，将他们当作摇祭奉上；</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 3:12; 民数记 3:45; 民数记 3:9"> 因为他们是从以色列人中全然给我的，我拣选他们归我，是代替以色列人中一切头生的。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 13:2; 路加福音 2:23; 出埃及记 13:12–15"> 以色列人中一切头生的，连人带牲畜，都是我的。我在埃及地击杀一切头生的那天，将他们分别为圣归我。</span>
<span className="v" id="v18" data-v="18"> 我拣选利未人代替以色列人中一切头生的。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 1:53; 民数记 16:46; 历代志下 26:16–20"> 我从以色列人中将利未人当作赏赐给亚伦和他的儿子，在会幕中办以色列人的事，又为以色列人赎罪，免得他们挨近圣所，有灾殃临到他们中间。」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 摩西、亚伦，并以色列全会众便向利未人如此行。凡耶和华指着利未人所吩咐摩西的，以色列人就向他们这样行。</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 8:7; 民数记 19:19; 民数记 8:15"> 于是利未人洁净自己，除了罪，洗了衣服；亚伦将他们当作摇祭奉到耶和华面前，又为他们赎罪，洁净他们。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 31:2; 历代志下 35:8–15; 民数记 8:15"> 然后利未人进去，在亚伦和他儿子面前，在会幕中办事。耶和华指着利未人怎样吩咐摩西，以色列人就怎样向他们行了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和华晓谕摩西说：</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 4:3; 历代志上 23:3; 民数记 4:23"> 「利未人是这样：从二十五岁以外，他们要前来任职，办会幕的事。</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 4:23; 提摩太后书 4:7"> 到了五十岁要停工退任，不再办事，</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 1:53; 民数记 3:32; 提摩太前书 4:15"> 只要在会幕里，和他们的弟兄一同伺候，谨守所吩咐的，不再办事了。至于所吩咐利未人的，你要这样向他们行。」</span>
</div>
</div>

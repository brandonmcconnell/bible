## 十二个探子

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华晓谕摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 1:22–25; 民数记 32:8; 民数记 34:18"> 「你打发人去窥探我所赐给以色列人的迦南地，他们每支派中要打发一个人，都要作首领的。」</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 12:16; 民数记 32:8; 申命记 1:19"> 摩西就照耶和华的吩咐从巴兰的旷野打发他们去；他们都是以色列人的族长。</span>
<span className="v" id="v4" data-v="4"> 他们的名字：属吕便支派的有撒刻的儿子沙母亚。</span>
<span className="v" id="v5" data-v="5"> 属西缅支派的有何利的儿子沙法。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 34:19; 民数记 14:6; 民数记 13:30"> 属犹大支派的有耶孚尼的儿子迦勒。</span>
<span className="v" id="v7" data-v="7"> 属以萨迦支派的有约色的儿子以迦。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 24:13; 民数记 11:28; 民数记 13:16"> 属以法莲支派的有嫩的儿子何希阿。</span>
<span className="v" id="v9" data-v="9"> 属便雅悯支派的有拉孚的儿子帕提。</span>
<span className="v" id="v10" data-v="10"> 属西布伦支派的有梭底的儿子迦叠。</span>
<span className="v" id="v11" data-v="11"> 约瑟的子孙，属玛拿西支派的有稣西的儿子迦底。</span>
<span className="v" id="v12" data-v="12"> 属但支派的有基玛利的儿子亚米利。</span>
<span className="v" id="v13" data-v="13"> 属亚设支派的有米迦勒的儿子西帖。</span>
<span className="v" id="v14" data-v="14"> 属拿弗他利支派的有缚西的儿子拿比。</span>
<span className="v" id="v15" data-v="15"> 属迦得支派的有玛基的儿子臼利。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 13:8; 出埃及记 17:9; 民数记 14:6"> 这就是摩西所打发、窥探那地之人的名字。摩西就称嫩的儿子何希阿为约书亚。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="士师记 1:9; 创世记 12:9; 士师记 1:19"> 摩西打发他们去窥探迦南地，说：「你们从南地上山地去，</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 34:14; 出埃及记 3:8"> 看那地如何，其中所住的民是强是弱，是多是少，</span>
<span className="v" id="v19" data-v="19"> 所住之地是好是歹，所住之处是营盘是坚城。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 31:23; 申命记 31:6–8; 以西结书 34:14"> 又看那地土是肥美是瘠薄，其中有树木没有。你们要放开胆量，把那地的果子带些来。」（那时正是葡萄初熟的时候。）</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数记 20:1; 民数记 33:36; 民数记 27:14"> 他们上去窥探那地，从寻的旷野到利合，直到哈马口。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 78:12; 诗篇 78:43; 以赛亚书 19:11"> 他们从南地上去，到了希伯 ；在那里有亚衲族人亚希幔、示筛、挞买。（原来希伯 城被建造比埃及的锁安城早七年。）</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 13:24; 民数记 32:9; 申命记 1:24–25"> 他们到了以实各谷，从那里砍了葡萄树的一枝，上头有一挂葡萄，两个人用杠抬着，又带了些石榴和无花果来。（</span>
<span className="v" id="v24" data-v="24"> 因为以色列人从那里砍来的那挂葡萄，所以那地方叫做以实各谷。）</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及记 34:28; 出埃及记 24:18; 民数记 14:33–34"> 过了四十天，他们窥探那地才回来，</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 32:8; 民数记 20:1; 申命记 1:19"> 到了巴兰旷野的加低斯，见摩西、亚伦，并以色列的全会众，回报摩西、亚伦，并全会众，又把那地的果子给他们看；</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 3:8; 出埃及记 3:17; 出埃及记 13:5"> 又告诉摩西说：「我们到了你所打发我们去的那地，果然是流奶与蜜之地；这就是那地的果子。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 9:1–2; 申命记 1:28; 民数记 13:33"> 然而住那地的民强壮，城邑也坚固宽大，并且我们在那里看见了亚衲族的人。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 14:43; 士师记 6:3; 创世记 15:19–21"> 亚玛力人住在南地；赫人、耶布斯人、亚摩利人住在山地；迦南人住在海边并约旦河旁。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="民数记 14:24; 罗马书 8:31; 腓立比书 4:13"> 迦勒在摩西面前安抚百姓，说：「我们立刻上去得那地吧！我们足能得胜。」</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 1:28; 约书亚记 14:8; 希伯来书 3:19"> 但那些和他同去的人说：「我们不能上去攻击那民，因为他们比我们强壮。」</span>
<span className="v" id="v32" data-v="32" data-xref="阿摩司书 2:9; 民数记 14:36–37; 以西结书 36:13–14"> 探子中有人论到所窥探之地，向以色列人报恶信，说：「我们所窥探、经过之地是吞吃居民之地，我们在那里所看见的人民都身量高大。</span>
<span className="v" id="v33" data-v="33" data-xref="申命记 1:28; 以赛亚书 40:22; 创世记 6:4"> 我们在那里看见亚衲族人，就是伟人；他们是伟人的后裔。据我们看，自己就如蚱蜢一样；据他们看，我们也是如此。」</span>
</div>
</div>

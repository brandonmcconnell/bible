## 亚伦的儿子们

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 6:20; 创世记 10:1; 出埃及记 6:16"> 耶和华在西奈山晓谕摩西的日子，亚伦和摩西的后代如下：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 6:23; 民数记 26:60; 出埃及记 28:1"> 亚伦的儿子，长子名叫拿答，还有亚比户、以利亚撒、以他玛。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 28:41; 利未记 8:30; 利未记 8:12"> 这是亚伦儿子的名字，都是受膏的祭司，是摩西叫他们承接圣职供祭司职分的。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 10:1–2; 民数记 26:61"> 拿答、亚比户在西奈的旷野向耶和华献凡火的时候就死在耶和华面前了。他们也没有儿子。以利亚撒、以他玛在他们的父亲亚伦面前供祭司的职分。</span>
</div>
</div>

## 利未人被派作祭司

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5"> 耶和华晓谕摩西说：</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 10:8; 民数记 2:33; 民数记 1:49–53"> 「你使利未支派近前来，站在祭司亚伦面前好服事他，</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 1:50; 民数记 8:15; 民数记 8:11"> 替他和会众在会幕前守所吩咐的，办理帐幕的事。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 4:33; 民数记 10:17; 以赛亚书 52:11"> 又要看守会幕的器具，并守所吩咐以色列人的，办理帐幕的事。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 8:19; 民数记 18:6–7; 以弗所书 4:8"> 你要将利未人给亚伦和他的儿子，因为他们是从以色列人中选出来给他的。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 1:51; 民数记 3:38; 罗马书 12:7"> 你要嘱咐亚伦和他的儿子谨守自己祭司的职任。近前来的外人必被治死。」</span>
<span className="v" id="v11" data-v="11"> 耶和华晓谕摩西说：</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 3:41; 民数记 8:16; 民数记 18:6"> 「我从以色列人中拣选了利未人，代替以色列人一切头生的；利未人要归我。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 2:23; 出埃及记 13:12; 出埃及记 13:2"> 因为凡头生的是我的；我在埃及地击杀一切头生的那日就把以色列中一切头生的，连人带牲畜都分别为圣归我；他们定要属我。我是耶和华。」</span>
</div>
</div>

## 利未人男丁的统计

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14"> 耶和华在西奈的旷野晓谕摩西说：</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 26:62; 马可福音 10:14; 提摩太后书 3:15"> 「你要照利未人的宗族、家室数点他们。凡一个月以外的男子都要数点。」</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 3:39; 民数记 4:37; 民数记 4:49"> 于是摩西照耶和华所吩咐的数点他们。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 46:11; 出埃及记 6:16–19; 民数记 15:5–23"> 利未众子的名字是革顺、哥辖、米拉利。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 6:17; 历代志上 26:1–32; 出埃及记 6:17–19"> 革顺的儿子，按着家室，是立尼、示每。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 6:18; 历代志上 6:18; 历代志上 15:17–21"> 哥辖的儿子，按着家室，是暗兰、以斯哈、希伯伦、乌薛。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 6:19; 历代志上 6:19; 民数记 3:33"> 米拉利的儿子，按着家室，是抹利、母示。这些按着宗族是利未人的家室。</span>
<span className="v" id="v21" data-v="21"> 属革顺的，有立尼族、示每族。这是革顺的二族。</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 4:38–40"> 其中被数、从一个月以外所有的男子共有七千五百名。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 1:53; 民数记 2:17"> 这革顺的二族要在帐幕后西边安营。</span>
<span className="v" id="v24" data-v="24"> 拉伊勒的儿子以利雅萨作革顺人宗族的首领。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 25:9; 历代志上 23:32; 历代志上 9:14–33"> 革顺的子孙在会幕中所要看守的，就是帐幕和罩棚，并罩棚的盖与会幕的门帘，</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 35:18; 出埃及记 38:9–16; 出埃及记 27:9–16"> 院子的帷子和门帘（院子是围帐幕和坛的），并一切使用的绳子。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志上 26:23; 民数记 3:19; 历代志上 23:12"> 属哥辖的，有暗兰族、以斯哈族、希伯伦族、乌薛族。这是哥辖的诸族。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 3:31; 民数记 4:35–36; 民数记 3:7"> 按所有男子的数目，从一个月以外看守圣所的，共有八千六百名。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 1:53; 民数记 3:23; 民数记 2:10"> 哥辖儿子的诸族要在帐幕的南边安营。</span>
<span className="v" id="v30" data-v="30"> 乌薛的儿子以利撒反作哥辖宗族家室的首领。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 36:35–36; 出埃及记 27:1–8; 出埃及记 26:31–33"> 他们所要看守的是约柜、桌子、灯台、两座坛与圣所内使用的器皿，并帘子和一切使用之物。</span>
<span className="v" id="v32" data-v="32" data-xref="民数记 4:27; 民数记 4:16; 民数记 20:25–28"> 祭司亚伦的儿子以利亚撒作利未人众首领的领袖，要监察那些看守圣所的人。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 3:20; 历代志上 6:19; 历代志上 23:21"> 属米拉利的，有抹利族、母示族。这是米拉利的二族。</span>
<span className="v" id="v34" data-v="34" data-xref="民数记 2:9; 民数记 2:11; 民数记 1:21"> 他们被数的，按所有男子的数目，从一个月以外的，共有六千二百名。</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 1:53; 民数记 2:25; 民数记 3:28–29"> 亚比亥的儿子苏列作米拉利二宗族的首领。他们要在帐幕的北边安营。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 26:32; 出埃及记 26:37; 出埃及记 26:15–29"> 米拉利子孙的职分是看守帐幕的板、闩、柱子、带卯的座，和帐幕一切所使用的器具，</span>
<span className="v" id="v37" data-v="37"> 院子四围的柱子、带卯的座、橛子，和绳子。</span>
<span className="v" id="v38" data-v="38" data-xref="民数记 3:10; 民数记 1:53; 民数记 2:3"> 在帐幕前东边，向日出之地安营的是摩西、亚伦，和亚伦的儿子。他们看守圣所，替以色列人守耶和华所吩咐的。近前来的外人必被治死。</span>
<span className="v" id="v39" data-v="39" data-xref="民数记 26:62; 马太福音 7:14; 民数记 4:47–48"> 凡被数的利未人，就是摩西、亚伦照耶和华吩咐所数的，按着家室，从一个月以外的男子，共有二万二千名。</span>
</div>
</div>

## 利未人代替长子的地位

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="民数记 3:15; 路加福音 10:20; 诗篇 87:6"> 耶和华对摩西说：「你要从以色列人中数点一个月以外、凡头生的男子，把他们的名字记下。</span>
<span className="v" id="v41" data-v="41" data-xref="民数记 3:12; 民数记 3:45; 民数记 8:16"> 我是耶和华。你要拣选利未人归我，代替以色列人所有头生的，也取利未人的牲畜代替以色列所有头生的牲畜。」</span>
<span className="v" id="v42" data-v="42"> 摩西就照耶和华所吩咐的把以色列人头生的都数点了。</span>
<span className="v" id="v43" data-v="43" data-xref="民数记 3:39"> 按人名的数目，从一个月以外、凡头生的男子，共有二万二千二百七十三名。</span>
<span className="v" id="v44" data-v="44"> 耶和华晓谕摩西说：</span>
<span className="v" id="v45" data-v="45" data-xref="民数记 3:12; 民数记 3:40–41"> 「你拣选利未人代替以色列人所有头生的，也取利未人的牲畜代替以色列人的牲畜。利未人要归我；我是耶和华。</span>
<span className="v" id="v46" data-v="46" data-xref="出埃及记 13:13; 民数记 18:15–16"> 以色列人中头生的男子比利未人多二百七十三个，必当将他们赎出来。</span>
<span className="v" id="v47" data-v="47" data-xref="出埃及记 30:13; 利未记 27:6; 民数记 18:16"> 你要按人丁，照圣所的平，每人取赎银五舍客勒（一舍客勒是二十季拉），</span>
<span className="v" id="v48" data-v="48"> 把那多余之人的赎银交给亚伦和他的儿子。」</span>
<span className="v" id="v49" data-v="49"> 于是摩西从那被利未人所赎以外的人取了赎银。</span>
<span className="v" id="v50" data-v="50" data-xref="民数记 3:46–47; 彼得前书 3:18; 马太福音 20:28"> 从以色列人头生的所取之银，按圣所的平，有一千三百六十五舍客勒。</span>
<span className="v" id="v51" data-v="51" data-xref="民数记 3:48; 民数记 16:15; 撒母耳记上 12:3–4"> 摩西照耶和华的话把这赎银给亚伦和他的儿子，正如耶和华所吩咐的。</span>
</div>
</div>

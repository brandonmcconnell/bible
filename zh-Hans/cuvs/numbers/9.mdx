## 第二个逾越节

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 1:1; 出埃及记 40:2"> 以色列人出埃及地以后，第二年正月，耶和华在西奈的旷野吩咐摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 16:1–2; 哥林多前书 5:7–8; 历代志下 35:1"> 「以色列人应当在所定的日期守逾越节，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 12:6–11; 利未记 23:5; 历代志下 30:2"> 就是本月十四日黄昏的时候，你们要在所定的日期守这节，要按这节的律例典章而守。」</span>
<span className="v" id="v4" data-v="4"> 于是摩西吩咐以色列人守逾越节。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 5:10; 马太福音 28:20; 出埃及记 12:1–13"> 他们就在西奈的旷野，正月十四日黄昏的时候，守逾越节。凡耶和华所吩咐摩西的，以色列人都照样行了。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 27:2; 出埃及记 18:15; 民数记 5:2"> 有几个人因死尸而不洁净，不能在那日守逾越节。当日他们到摩西、亚伦面前，</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 16:2; 哥林多前书 5:7–8; 出埃及记 12:27"> 说：「我们虽因死尸而不洁净，为何被阻止、不得同以色列人在所定的日期献耶和华的供物呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 85:8; 民数记 27:5; 哥林多前书 4:4"> 摩西对他们说：「你们暂且等候，我可以去听耶和华指着你们是怎样吩咐的。」</span>
<span className="v" id="v9" data-v="9"> 耶和华对摩西说：</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 2:1–2; 以弗所书 2:12–13; 哥林多前书 11:28"> 「你晓谕以色列人说：你们和你们后代中，若有人因死尸而不洁净，或在远方行路，还要向耶和华守逾越节。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 30:2–15; 出埃及记 12:43–49; 约翰福音 19:36"> 他们要在二月十四日黄昏的时候，守逾越节。要用无酵饼与苦菜，和逾越节的羊羔同吃。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 19:36; 出埃及记 12:46; 出埃及记 12:10"> 一点不可留到早晨；羊羔的骨头一根也不可折断。他们要照逾越节的一切律例而守。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 17:14; 出埃及记 12:15; 民数记 9:7"> 那洁净而不行路的人若推辞不守逾越节，那人要从民中剪除；因为他在所定的日期不献耶和华的供物，应该担当他的罪。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 12:48–49; 利未记 24:22; 以赛亚书 56:3–7"> 若有外人寄居在你们中间，愿意向耶和华守逾越节，他要照逾越节的律例典章行，不管是寄居的是本地人，同归一例。」</span>
</div>
</div>

## 云彩遮盖帐幕

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及记 13:21; 出埃及记 40:34; 尼希米记 9:19"> 立起帐幕的那日，有云彩遮盖帐幕，就是法柜的帐幕；从晚上到早晨，云彩在其上，形状如火。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米记 9:12; 出埃及记 40:38; 哥林多前书 10:1"> 常是这样，云彩遮盖帐幕，夜间形状如火。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 40:36–38; 诗篇 32:8; 约翰福音 10:9"> 云彩几时从帐幕收上去，以色列人就几时起行；云彩在哪里停住，以色列人就在那里安营。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 10:1; 约翰二书 1:6; 出埃及记 17:1"> 以色列人遵耶和华的吩咐起行，也遵耶和华的吩咐安营。云彩在帐幕上停住几时，他们就住营几时。</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 3:7; 民数记 1:52–53; 民数记 3:8"> 云彩在帐幕上停留许多日子，以色列人就守耶和华所吩咐的不起行。</span>
<span className="v" id="v20" data-v="20"> 有时云彩在帐幕上几天，他们就照耶和华的吩咐住营，也照耶和华的吩咐起行。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米记 9:19; 尼希米记 9:12"> 有时从晚上到早晨，有这云彩在帐幕上；早晨云彩收上去，他们就起行。有时昼夜云彩停在帐幕上，收上去的时候，他们就起行。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 32:8; 出埃及记 40:36–37; 出埃及记 40:16"> 云彩停留在帐幕上，无论是两天，是一月，是一年，以色列人就住营不起行；但云彩收上去，他们就起行。</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 22:3; 民数记 9:19; 创世记 26:5"> 他们遵耶和华的吩咐安营，也遵耶和华的吩咐起行。他们守耶和华所吩咐的，都是凭耶和华吩咐摩西的。</span>
</div>
</div>

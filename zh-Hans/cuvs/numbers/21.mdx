## 战胜迦南人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 1:16; 民数记 33:40; 约书亚记 12:14"> 住南地的迦南人亚拉得王，听说以色列人从亚他林路来，就和以色列人争战，掳了他们几个人。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 11:30; 创世记 28:20; 撒母耳记上 1:11"> 以色列人向耶和华发愿说：「你若将这民交付我手，我就把他们的城邑尽行毁灭。」</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 14:45; 申命记 1:44; 诗篇 10:17"> 耶和华应允了以色列人，把迦南人交付他们，他们就把迦南人和迦南人的城邑尽行毁灭。那地方的名便叫何珥玛<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是毁灭的意思">a</a></sup>。</span>
</div>
</div>

## 铜制的蛇

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及记 6:9; 士师记 11:18; 民数记 32:7"> 他们从何珥山起行，往红海那条路走，要绕过以东地。百姓因这路难行，心中甚是烦躁，</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 78:19; 民数记 16:13–14; 出埃及记 17:2–3"> 就怨 神和摩西说：「你们为什么把我们从埃及领出来、使我们死在旷野呢？这里没有粮，没有水，我们的心厌恶这淡薄的食物。」</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 10:9; 耶利米书 8:17; 申命记 8:15"> 于是耶和华使火蛇进入百姓中间，蛇就咬他们。以色列人中死了许多。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 8:24; 民数记 11:2; 诗篇 78:34"> 百姓到摩西那里，说：「我们怨 耶和华和你，有罪了。求你祷告耶和华，叫这些蛇离开我们。」于是摩西为百姓祷告。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 3:14; 诗篇 106:43–45; 诗篇 145:8"> 耶和华对摩西说：「你制造一条火蛇，挂在杆子上；凡被咬的，一望这蛇，就必得活。」</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 3:14–15; 希伯来书 12:2; 约翰福音 6:40"> 摩西便制造一条铜蛇，挂在杆子上；凡被蛇咬的，一望这铜蛇就活了。</span>
</div>
</div>

## 从何珥山到摩押谷

<div className="bt">
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="民数记 33:43–45"> 以色列人起行，安营在阿伯。</span>
<span className="v" id="v11" data-v="11"> 又从阿伯起行，安营在以耶·亚巴琳，与摩押相对的旷野，向日出之地。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 2:13–14"> 从那里起行，安营在撒烈谷。</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 11:18; 民数记 22:36; 以赛亚书 16:2"> 从那里起行，安营在亚嫩河那边。这亚嫩河是在旷野，从亚摩利的境界流出来的；原来亚嫩河是摩押的边界，在摩押和亚摩利人搭界的地方。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 10:13; 撒母耳记下 1:18"> 所以耶和华的战记上说：「苏法的哇哈伯与亚嫩河的谷，</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 21:28; 申命记 2:18; 申命记 2:9"> 并向亚珥城众谷的下坡，是靠近摩押的境界。」</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 20:8; 以赛亚书 12:3; 以赛亚书 41:17–18"> 以色列人从那里起行，到了比珥<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就是井的意思">b</a></sup>。从前耶和华吩咐摩西说：「招聚百姓，我好给他们水喝」，说的就是这井。</span>
<span className="v" id="v17" data-v="17" data-xref="雅各书 5:13; 出埃及记 15:1–2; 诗篇 106:12"> 当时，以色列人唱歌说：<br /><span className="pl pl-1">井啊，涌上水来！</span><br /><span className="pl pl-1">你们要向这井歌唱。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 33:22; 提摩太前书 6:17–18; 雅各书 4:12"> <span className="pl pl-1">这井是首领和民中的尊贵人</span><br /><span className="pl pl-1">用圭用杖所挖所掘的。</span>以色列人从旷野往玛他拿去，</span>
<span className="v" id="v19" data-v="19"> 从玛他拿到拿哈列，从拿哈列到巴末，</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 23:28; 民数记 23:14; 申命记 1:5"> 从巴末到摩押地的谷，又到那下望旷野之毗斯迦的山顶。</span>
</div>
</div>

## 战胜亚摩利王和巴珊王

<div className="bt">
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="申命记 2:26–28; 民数记 20:14–19; 士师记 11:19–21"> 以色列人差遣使者去见亚摩利人的王西宏，说：</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 20:17"> 「求你容我们从你的地经过；我们不偏入田间和葡萄园，也不喝井里的水，只走大道<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是王道">c</a></sup>，直到过了你的境界。」</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 11:20; 申命记 29:7–8; 以赛亚书 15:4"> 西宏不容以色列人从他的境界经过，就招聚他的众民出到旷野，要攻击以色列人，到了雅杂与以色列人争战。</span>
<span className="v" id="v24" data-v="24" data-xref="阿摩司书 2:9; 约书亚记 24:8; 创世记 32:22"> 以色列人用刀杀了他，得了他的地，从亚嫩河到雅博河，直到亚扪人的境界，因为亚扪人的境界多有坚垒。</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 32:33–42; 以赛亚书 16:8–9; 耶利米书 48:2"> 以色列人夺取这一切的城邑，也住亚摩利人的城邑，就是希实本与希实本的一切乡村。</span>
<span className="v" id="v26" data-v="26"> 这希实本是亚摩利王西宏的京城；西宏曾与摩押的先王争战，从他手中夺取了全地，直到亚嫩河。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 14:4; 民数记 21:14; 哈巴谷书 2:6"> 所以那些作诗歌的说：<br /><span className="pl pl-1">你们来到希实本；</span><br /><span className="pl pl-1">愿西宏的城被修造，被建立。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="民数记 21:15; 耶利米书 48:45–46; 以赛亚书 15:1–2"> <span className="pl pl-1">因为有火从希实本发出，</span><br /><span className="pl pl-1">有火焰出于西宏的城，</span><br /><span className="pl pl-1">烧尽摩押的亚珥和亚嫩河邱坛的祭司</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="祭司原文是主">d</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="士师记 11:24; 列王纪下 23:13; 耶利米书 48:46"> <span className="pl pl-1">摩押啊，你有祸了！</span><br /><span className="pl pl-1">基抹的民哪，你们灭亡了！</span><br /><span className="pl pl-1">基抹的男子逃奔，</span><br /><span className="pl pl-1">女子被掳，交付亚摩利的王西宏。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 48:18; 以赛亚书 15:2; 耶利米书 48:22"> <span className="pl pl-1">我们射了他们；</span><br /><span className="pl pl-1">希实本直到底本尽皆毁灭。</span><br /><span className="pl pl-1">我们使地变成荒场，直到挪法；</span><br /><span className="pl pl-1">这挪法直延到米底巴。</span></span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 13:8–12; 民数记 32:33–42; 申命记 3:16–17"> 这样，以色列人就住在亚摩利人之地。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 48:32; 民数记 32:1; 民数记 32:35"> 摩西打发人去窥探雅谢，以色列人就占了雅谢的镇市，赶出那里的亚摩利人。</span>
<span className="v" id="v33" data-v="33" data-xref="约书亚记 13:12; 申命记 1:4; 申命记 29:7"> 以色列人转回，向巴珊去。巴珊王噩和他的众民都出来，在以得来与他们交战。</span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 135:10–11; 约书亚记 8:7; 申命记 3:2–3"> 耶和华对摩西说：「不要怕他！因我已将他和他的众民，并他的地，都交在你手中；你要待他像从前待住希实本的亚摩利王西宏一般。」</span>
<span className="v" id="v35" data-v="35" data-xref="申命记 29:7–8; 约书亚记 13:12; 申命记 3:3–17"> 于是他们杀了他和他的众子，并他的众民，没有留下一个，就得了他的地。</span>
</div>

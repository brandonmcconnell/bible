## 献祭的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 23:10; 民数记 15:18; 利未记 25:2"> 「你晓谕以色列人说：你们到了我所赐给你们居住的地，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 29:18; 创世记 8:21; 腓立比书 4:18"> 若愿意从牛群羊群中取牛羊作火祭，献给耶和华，无论是燔祭是平安祭，为要还特许的愿，或是作甘心祭，或是逢你们节期献的，都要奉给耶和华为馨香之祭。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 29:40; 利未记 23:13; 利未记 6:14"> 那献供物的就要将细面伊法十分之一，并油一欣四分之一，调和作素祭，献给耶和华。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 28:7; 民数记 28:14; 士师记 9:13"> 无论是燔祭是平安祭，你要为每只绵羊羔，一同预备奠祭的酒一欣四分之一。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 28:12–14; 民数记 15:4"> 为公绵羊预备细面伊法十分之二，并油一欣三分之一，调和作素祭，</span>
<span className="v" id="v7" data-v="7"> 又用酒一欣三分之一作奠祭，献给耶和华为馨香之祭。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 3:1; 利未记 7:11–18; 利未记 1:3"> 你预备公牛作燔祭，或是作平安祭，为要还特许的愿，或是作平安祭，献给耶和华，</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 28:14; 民数记 28:12; 利未记 6:14"> 就要把细面伊法十分之三，并油半欣，调和作素祭，和公牛一同献上，</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 15:5; 民数记 6:15"> 又用酒半欣作奠祭，献给耶和华为馨香的火祭。</span>
<span className="v" id="v11" data-v="11"> 「献公牛、公绵羊、绵羊羔、山羊羔，每只都要这样办理。</span>
<span className="v" id="v12" data-v="12"> 照你们所预备的数目，按着只数都要这样办理。</span>
<span className="v" id="v13" data-v="13"> 凡本地人将馨香的火祭献给耶和华，都要这样办理。</span>
<span className="v" id="v14" data-v="14"> 若有外人和你们同居，或有人世世代代住在你们中间，愿意将馨香的火祭献给耶和华，你们怎样办理，他也要照样办理。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 9:14; 民数记 15:29; 出埃及记 12:49"> 至于会众，你们和同居的外人都归一例，作为你们世世代代永远的定例，在耶和华面前，你们怎样，寄居的也要怎样。</span>
<span className="v" id="v16" data-v="16"> 你们并与你们同居的外人当有一样的条例，一样的典章。」</span>
<span className="v" id="v17" data-v="17"> 耶和华对摩西说：</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 15:2; 申命记 26:1–15"> 「你晓谕以色列人说：你们到了我所领你们进去的那地，</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 5:11–12"> 吃那地的粮食，就要把举祭献给耶和华。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 2:14; 出埃及记 34:26; 申命记 26:2–10"> 你们要用初熟的麦子磨面，做饼当举祭奉献；你们举上，好像举禾场的举祭一样。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 29:28; 民数记 18:26"> 你们世世代代要用初熟的麦子磨面，当举祭献给耶和华。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 4:2; 利未记 4:27; 利未记 5:15–17"> 「你们有错误的时候，不守耶和华所晓谕摩西的这一切命令，</span>
<span className="v" id="v23" data-v="23"> 就是耶和华借摩西一切所吩咐你们的，自那日以至你们的世世代代，</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 4:23; 利未记 4:13–21; 利未记 5:15"> 若有误行，是会众所不知道的，后来全会众就要将一只公牛犊作燔祭，并照典章把素祭和奠祭一同献给耶和华为馨香之祭，又献一只公山羊作赎罪祭。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 4:20; 罗马书 3:25; 希伯来书 2:17"> 祭司要为以色列全会众赎罪，他们就必蒙赦免，因为这是错误。他们又因自己的错误，把供物，就是向耶和华献的火祭和赎罪祭，一并奉到耶和华面前。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 15:24"> 以色列全会众和寄居在他们中间的外人就必蒙赦免，因为这罪是百姓误犯的。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 4:27–28; 使徒行传 17:30; 使徒行传 3:17"> 「若有一个人误犯了罪，他就要献一岁的母山羊作赎罪祭。</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 4:35"> 那误行的人犯罪的时候，祭司要在耶和华面前为他赎罪，他就必蒙赦免。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 15:15; 利未记 16:29; 利未记 17:15"> 以色列中的本地人和寄居在他们中间的外人，若误行了什么事，必归一样的条例。</span>
<span className="v" id="v30" data-v="30" data-xref="希伯来书 10:26; 诗篇 19:13; 申命记 1:43"> 但那擅敢行事的，无论是本地人是寄居的，他亵渎了耶和华，必从民中剪除。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 12:9; 箴言 13:13; 以西结书 18:20"> 因他藐视耶和华的言语，违背耶和华的命令，那人总要剪除；他的罪孽要归到他身上。」</span>
</div>
</div>

## 违反安息日的人

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="出埃及记 35:2–3; 出埃及记 31:14–15; 出埃及记 20:8–10"> 以色列人在旷野的时候，遇见一个人在安息日捡柴。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 8:3–20"> 遇见他捡柴的人，就把他带到摩西、亚伦并全会众那里，</span>
<span className="v" id="v34" data-v="34" data-xref="利未记 24:12; 民数记 9:8"> 将他收在监内；因为当怎样办他，还没有指明。</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 7:58; 出埃及记 31:14–15; 列王纪上 21:13"> 耶和华吩咐摩西说：「总要把那人治死；全会众要在营外用石头把他打死。」</span>
<span className="v" id="v36" data-v="36" data-xref="约书亚记 7:25"> 于是全会众将他带到营外，用石头打死他，是照耶和华所吩咐摩西的。</span>
</div>
</div>

## 有关衣服 子的条例

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37"> 耶和华晓谕摩西说：</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 23:5; 申命记 22:12; 马太福音 9:20"> 「你吩咐以色列人，叫他们世世代代在衣服边上做 子，又在底边的 子上钉一根蓝细带子。</span>
<span className="v" id="v39" data-v="39" data-xref="诗篇 106:39; 箴言 28:26; 诗篇 73:27"> 你们佩带这 子，好叫你们看见就记念遵行耶和华一切的命令，不随从自己的心意、眼目行邪淫，像你们素常一样；</span>
<span className="v" id="v40" data-v="40" data-xref="罗马书 12:1; 帖撒罗尼迦前书 4:7; 利未记 11:44–45"> 使你们记念遵行我一切的命令，成为圣洁，归与你们的 神。</span>
<span className="v" id="v41" data-v="41" data-xref="彼得前书 2:9–10; 以西结书 36:25–27; 希伯来书 11:16"> 「我是耶和华—你们的 神，曾把你们从埃及地领出来，要作你们的 神。我是耶和华—你们的 神。」</span>

## 在加低斯发生的事件

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 13:21; 出埃及记 15:20; 民数记 33:36"> 正月间，以色列全会众到了寻的旷野，就住在加低斯。米利暗死在那里，就葬在那里。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="民数记 16:19; 民数记 16:42; 出埃及记 15:23–24"> 会众没有水喝，就聚集攻击摩西、亚伦。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 17:2; 民数记 14:1–2; 民数记 16:31–35"> 百姓向摩西争闹说：「我们的弟兄曾死在耶和华面前，我们恨不得与他们同死。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 17:3; 诗篇 106:21; 民数记 16:13–14"> 你们为何把耶和华的会众领到这旷野、使我们和牲畜都死在这里呢？</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 16:14; 耶利米书 2:2; 耶利米书 2:6"> 你们为何逼着我们出埃及、领我们到这坏地方呢？这地方不好撒种，也没有无花果树、葡萄树、石榴树，又没有水喝。」</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 14:5; 民数记 16:4; 民数记 16:19"> 摩西、亚伦离开会众，到会幕门口，俯伏在地；耶和华的荣光向他们显现。</span>
<span className="v" id="v7" data-v="7"> 耶和华晓谕摩西说：</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 4:17; 使徒行传 2:1–4; 启示录 22:17"> 「你拿着杖去，和你的哥哥亚伦招聚会众，在他们眼前吩咐磐石发出水来，水就从磐石流出，给会众和他们的牲畜喝。」</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 17:10"> 于是摩西照耶和华所吩咐的，从耶和华面前取了杖去。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="诗篇 106:32–33; 使徒行传 14:9–15; 路加福音 9:54–55"> 摩西、亚伦就招聚会众到磐石前。摩西说：「你们这些背叛的人听我说：我为你们使水从这磐石中流出来吗？」</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 10:4; 出埃及记 17:6; 申命记 8:15"> 摩西举手，用杖击打磐石两下，就有许多水流出来，会众和他们的牲畜都喝了。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 1:37; 民数记 27:14; 以西结书 36:23"> 耶和华对摩西、亚伦说：「因为你们不信我，不在以色列人眼前尊我为圣，所以你们必不得领这会众进我所赐给他们的地去。」</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 17:7; 诗篇 95:8; 申命记 33:8"> 这水名叫米利巴水<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="米利巴就是争闹的意思">a</a></sup>，是因以色列人向耶和华争闹，耶和华就在他们面前显为圣。</span>
</div>
</div>

## 以东王不容以色列人通行

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="士师记 11:16–17; 申命记 23:7; 俄巴底亚书 1:10–12"> 摩西从加低斯差遣使者去见以东王，说：「你的弟兄以色列人这样说：『我们所遭遇的一切艰难，</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 12:40; 申命记 26:6; 创世记 46:6"> 就是我们的列祖下到埃及，我们在埃及久住；埃及人恶待我们的列祖和我们，</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 14:19; 出埃及记 23:20; 出埃及记 33:2"> 我们哀求耶和华的时候，他听了我们的声音，差遣使者把我们从埃及领出来。这事你都知道。如今，我们在你边界上的城加低斯。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 2:27; 申命记 2:29; 民数记 21:22–24"> 求你容我们从你的地经过。我们不走田间和葡萄园，也不喝井里的水，只走大道<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是王道">b</a></sup>，不偏左右，直到过了你的境界。』」</span>
<span className="v" id="v18" data-v="18"> 以东王说：「你不可从我的地经过，免得我带刀出去攻击你。」</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 2:28; 申命记 2:6; 出埃及记 12:38"> 以色列人说：「我们要走大道上去；我们和牲畜若喝你的水，必给你价值。不求别的，只求你容我们步行过去。」</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 11:17; 阿摩司书 1:11; 创世记 32:6"> 以东王说：「你们不可经过！」就率领许多人出来，要用强硬的手攻击以色列人。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 11:18; 申命记 2:29; 申命记 2:4–8"> 这样，以东王不肯容以色列人从他的境界过去。于是他们转去，离开他。</span>
</div>
</div>

## 亚伦逝世

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数记 20:1; 民数记 20:14; 民数记 21:4"> 以色列全会众从加低斯起行，到了何珥山。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 33:37"> 耶和华在附近以东边界的何珥山上晓谕摩西、亚伦说：</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 25:8; 申命记 32:50; 民数记 31:2"> 「亚伦要归到他列祖<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是本民">c</a></sup>那里。他必不得入我所赐给以色列人的地；因为在米利巴水，你们违背了我的命。</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 33:38–39"> 你带亚伦和他的儿子以利亚撒上何珥山，</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 20:24; 以赛亚书 22:21–22; 希伯来书 7:11"> 把亚伦的圣衣脱下来，给他的儿子以利亚撒穿上；亚伦必死在那里，归他列祖。」</span>
<span className="v" id="v27" data-v="27"> 摩西就照耶和华所吩咐的行。三人当着会众的眼前上了何珥山。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 10:6; 出埃及记 29:29–30; 申命记 34:9"> 摩西把亚伦的圣衣脱下来，给他的儿子以利亚撒穿上，亚伦就死在山顶那里。于是摩西和以利亚撒下了山。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 34:8; 历代志下 35:24–25; 创世记 1:10"> 全会众，就是以色列全家，见亚伦已经死了，便都为亚伦哀哭了三十天。</span>
</div>
</div>

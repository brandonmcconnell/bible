## 表演耶路撒冷被困

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="何西阿书 1:2–9; 阿摩司书 3:2; 以西结书 12:3–16"> 「人子啊，你要拿一块砖，摆在你面前，将一座耶路撒冷城画在其上，</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 21:22; 耶利米书 6:6; 路加福音 19:42–44"> 又围困这城，造台筑垒，安营攻击，在四围安设撞锤攻城，</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 12:6; 以赛亚书 8:18; 以赛亚书 20:3"> 又要拿个铁鏊，放在你和城的中间，作为铁墙。你要对面攻击这城，使城被困；这样，好作以色列家的预兆。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 16:22; 利未记 10:17; 民数记 18:1"> 「你要向左侧卧，承当以色列家的罪孽；要按你向左侧卧的日数，担当他们的罪孽。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 14:34; 以赛亚书 53:6"> 因为我已将他们作孽的年数定为你向左侧卧的日数，就是三百九十日，你要这样担当以色列家的罪孽。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 14:34; 但以理书 12:11–12; 但以理书 9:24–26"> 再者，你满了这些日子，还要向右侧卧，担当犹大家的罪孽。我给你定规侧卧四十日，一日顶一年。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 52:10; 以西结书 21:2; 以西结书 6:2"> 你要露出膀臂，面向被困的耶路撒冷，说预言攻击这城。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 3:25"> 我用绳索捆绑你，使你不能辗转，直等你满了困城的日子。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 4:13; 以赛亚书 28:25; 以西结书 4:16"> 「你要取小麦、大麦、豆子、红豆、小米、粗麦，装在一个器皿中，用以为自己做饼；要按你侧卧的三百九十日吃这饼。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 26:26; 以西结书 45:12; 申命记 28:51–68"> 你所吃的要按分两吃，每日二十舍客勒，按时而吃。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 5:13; 约翰福音 3:34; 以西结书 4:16"> 你喝水也要按制子，每日喝一欣六分之一，按时而喝。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 36:12; 创世记 18:6"> 你吃这饼像吃大麦饼一样，要用人粪在众人眼前烧烤。」</span>
<span className="v" id="v13" data-v="13" data-xref="但以理书 1:8; 何西阿书 9:3–4"> 耶和华说：「以色列人在我所赶他们到的各国中，也必这样吃不洁净的食物。」</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 10:14; 以西结书 20:49; 以西结书 9:8"> 我说：「哎！主耶和华啊，我素来未曾被玷污，从幼年到如今没有吃过自死的，或被野兽撕裂的，那可憎的肉也未曾入我的口。」</span>
<span className="v" id="v15" data-v="15"> 于是他对我说：「看哪，我给你牛粪代替人粪，你要将你的饼烤在其上。」</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 5:16; 以赛亚书 3:1; 利未记 26:26"> 他又对我说：「人子啊，我必在耶路撒冷折断他们的杖，就是断绝他们的粮。他们吃饼要按分两，忧虑而吃；喝水也要按制子，惊惶而喝；</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 24:23; 利未记 26:39; 以西结书 33:10"> 使他们缺粮缺水，彼此惊惶，因自己的罪孽消灭。」</span>

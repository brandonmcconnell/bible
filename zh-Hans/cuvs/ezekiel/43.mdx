## 耶和华回到圣殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 44:1; 以西结书 42:15; 以西结书 46:1"> 以后，他带我到一座门，就是朝东的门。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 18:1; 以西结书 11:23; 以赛亚书 6:3"> 以色列 神的荣光从东而来。他的声音如同多水的声音；地就因他的荣耀发光。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 9:5; 以西结书 9:1; 耶利米书 1:10"> 其状如从前他来灭城的时候我所见的异象，那异象如我在迦巴鲁河边所见的异象，我就俯伏在地。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 10:18–19; 以西结书 44:2; 以西结书 43:2"> 耶和华的荣光从朝东的门照入殿中。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 12:2–4; 列王纪上 8:10–11; 以西结书 8:3"> 灵将我举起，带入内院，不料，耶和华的荣光充满了殿。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结书 40:3; 以赛亚书 66:6; 启示录 16:1"> 我听见有一位从殿中对我说话。有一人站在我旁边。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 43:9; 诗篇 47:8; 利未记 26:30"> 他对我说：「人子啊，这是我宝座之地，是我脚掌所踏之地。我要在这里住，在以色列人中直到永远。以色列家和他们的君王必不再玷污我的圣名，就是行邪淫、在锡安 的高处葬埋他们君王的尸首，</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 5:11; 以西结书 8:3–16; 历代志下 33:7"> 使他们的门槛挨近我的门槛，他们的门框挨近我的门框；他们与我中间仅隔一墙，并且行可憎的事，玷污了我的圣名，所以我发怒灭绝他们。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 43:7; 以西结书 37:26–28; 以西结书 18:30–31"> 现在他们当从我面前远除邪淫和他们君王的尸首，我就住在他们中间直到永远。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西结书 40:4; 以西结书 16:61; 以西结书 16:63"> 「人子啊，你要将这殿指示以色列家，使他们因自己的罪孽惭愧，也要他们量殿的尺寸。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 36:27; 以西结书 11:20; 马太福音 28:20"> 他们若因自己所行的一切事惭愧，你就将殿的规模、样式、出入之处，和一切形状、典章、礼仪、法则指示他们，在他们眼前写上，使他们遵照殿的一切规模典章去做。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 40:2; 启示录 21:27; 诗篇 93:5"> 殿的法则乃是如此：殿在山顶上，四围的全界要称为至圣。这就是殿的法则。」</span>
</div>
</div>

## 祭坛

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西结书 40:5; 出埃及记 27:1–8; 以西结书 41:8"> 以下量祭坛，是以肘为度（这肘是一肘零一掌）。底座高一肘，边宽一肘，四围起边高一掌，这是坛的座。</span>
<span className="v" id="v14" data-v="14"> 从底座到下层磴台，高二肘，边宽一肘。从小磴台到大磴台，高四肘，边宽一肘。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 27:2; 诗篇 118:27; 利未记 9:9"> 坛上的供台，高四肘。供台的四拐角上都有角。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 27:1; 历代志下 4:1; 出埃及记 38:1–2"> 供台长十二肘，宽十二肘，四面见方。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 20:26; 以西结书 40:6; 出埃及记 25:25"> 磴台长十四肘，宽十四肘，四面见方。四围起边高半肘，底座四围的边宽一肘。台阶朝东。</span>
</div>
</div>

## 奉献祭坛

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 40:29; 希伯来书 10:4–12; 以西结书 2:1"> 他对我说：「人子啊，主耶和华如此说：建造祭坛，为要在其上献燔祭洒血，造成的时候典章如下：</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 40:46; 以西结书 44:15; 民数记 16:40"> 主耶和华说，你要将一只公牛犊作为赎罪祭，给祭司利未人撒督的后裔，就是那亲近我、事奉我的。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 16:19; 利未记 8:15; 出埃及记 29:12"> 你要取些公牛的血，抹在坛的四角和磴台的四拐角，并四围所起的边上。你这样洁净坛，坛就洁净了。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 29:14; 利未记 4:12; 利未记 8:17"> 你又要将那作赎罪祭的公牛犊烧在殿外、圣地之外预定之处。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 43:25–26; 以西结书 43:20; 彼得前书 1:19"> 次日，要将无残疾的公山羊献为赎罪祭；要洁净坛，像用公牛犊洁净的一样。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 29:1"> 洁净了坛，就要将一只无残疾的公牛犊和羊群中一只无残疾的公绵羊</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 2:13; 马可福音 9:49–50; 民数记 18:19"> 奉到耶和华前。祭司要撒盐在其上，献与耶和华为燔祭。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 8:33; 出埃及记 29:35–37; 利未记 8:35"> 七日内，每日要预备一只公山羊为赎罪祭，也要预备一只公牛犊和羊群中的一只公绵羊，都要没有残疾的。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 29:24; 利未记 8:34; 出埃及记 32:29"> 七日祭司洁净坛，坛就洁净了；要这样把坛分别为圣。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 9:1; 以西结书 20:40–41; 彼得前书 2:5"> 满了七日，自八日以后，祭司要在坛上献你们的燔祭和平安祭；我必悦纳你们。这是主耶和华说的。」</span>
</div>
</div>

</div>

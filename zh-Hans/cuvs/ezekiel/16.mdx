## 不忠实的耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话又临到我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 22:2; 以西结书 20:4; 以赛亚书 58:1"> 「人子啊，你要使耶路撒冷知道她那些可憎的事，</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 16:45; 以赛亚书 51:1–2; 申命记 20:17"> 说主耶和华对耶路撒冷如此说：你根本，你出世，是在迦南地；你父亲是亚摩利人，你母亲是赫人。</span>
<span className="v" id="v4" data-v="4" data-xref="何西阿书 2:3; 创世记 15:13; 出埃及记 5:16–21"> 论到你出世的景况，在你初生的日子没有为你断脐带，也没有用水洗你，使你洁净，丝毫没有撒盐在你身上，也没有用布裹你。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 32:10; 创世记 21:10; 出埃及记 1:22"> 谁的眼也不可怜你，为你做一件这样的事怜恤你；但你初生的日子扔在田野，是因你被厌恶。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所书 2:4–5; 约翰福音 5:25; 提多书 3:3–7"> 「我从你旁边经过，见你滚在血中，就对你说：你虽在血中，仍可存活；你虽在血中，仍可存活。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 1:10; 出埃及记 1:7; 以赛亚书 62:3"> 我使你生长好像田间所长的，你就渐渐长大，以致极其俊美，两乳成形，头发长成，你却仍然赤身露体。</span>
<span className="v" id="v8" data-v="8" data-xref="路得记 3:9; 耶利米书 2:2–3; 罗马书 5:8"> 「我从你旁边经过，看见你的时候正动爱情，便用衣襟搭在你身上，遮盖你的赤体；又向你起誓，与你结盟，你就归于我。这是主耶和华说的。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 23:5; 路得记 3:3; 约翰一书 2:27"> 那时我用水洗你，洗净你身上的血，又用油抹你。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 16:18; 以西结书 16:13; 以赛亚书 61:10"> 我也使你身穿绣花衣服，脚穿海狗皮鞋，并用细麻布给你束腰，用丝绸为衣披在你身上，</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 24:22; 以赛亚书 3:19; 创世记 41:42"> 又用妆饰打扮你，将镯子戴在你手上，将金链戴在你项上。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 3:21; 以赛亚书 28:5; 耶利米书 13:18"> 我也将环子戴在你鼻子上，将耳环戴在你耳朵上，将华冠戴在你头上。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 32:13–14; 诗篇 50:2; 列王纪上 4:21"> 这样，你就有金银的妆饰，穿的是细麻衣和丝绸，并绣花衣；吃的是细面、蜂蜜，并油。你也极其美貌，发达到王后的尊荣。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 10:24; 耶利米哀歌 2:15; 哥林多前书 4:7"> 你美貌的名声传在列邦中，你十分美貌，是因我加在你身上的威荣。这是主耶和华说的。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 57:8; 耶利米书 2:20; 以西结书 16:25"> 「只是你仗着自己的美貌，又因你的名声就行邪淫。你纵情淫乱，使过路的任意而行。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 23:7; 以西结书 7:20; 历代志下 28:24"> 你用衣服为自己在高处结彩，在其上行邪淫。这样的事将来必没有，也必不再行了。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 23:14–21; 耶利米书 3:9; 以西结书 16:11"> 你又将我所给你那华美的金银、宝器为自己制造人像，与他行邪淫；</span>
<span className="v" id="v18" data-v="18"> 又用你的绣花衣服给他披上，并将我的膏油和香料摆在他跟前；</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 16:13; 何西阿书 2:8–13; 创世记 8:21"> 又将我赐给你的食物，就是我赐给你吃的细面、油，和蜂蜜，都摆在他跟前为馨香的供物。这是主耶和华说的。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 23:37; 以西结书 20:31; 耶利米书 7:31"> 并且你将给我所生的儿女焚献给他。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 17:17; 利未记 18:21; 申命记 18:10"> 你行淫乱岂是小事，竟将我的儿女杀了，使他们经火归与他吗？</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 2:2; 何西阿书 11:1; 以西结书 16:43"> 你行这一切可憎和淫乱的事，并未追念你幼年赤身露体滚在血中的日子。」</span>
</div>
</div>

## 耶路撒冷像淫妇

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="启示录 12:12; 以西结书 2:10; 以西结书 24:6"> 「你行这一切恶事之后（主耶和华说：你有祸了！有祸了！）</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 78:58; 以西结书 16:39; 以西结书 16:31"> 又为自己建造圆顶花楼，在各街上做了高台。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 16:31; 耶利米书 3:2; 创世记 38:21"> 你在一切市口上建造高台，使你的美貌变为可憎的，又与一切过路的多行淫乱。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 23:19–21; 以西结书 20:7–8; 以西结书 8:10"> 你也和你邻邦放纵情欲的埃及人行淫，加增你的淫乱，惹我发怒。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 9:12; 以西结书 16:57; 以西结书 16:37"> 因此我伸手攻击你，减少你应用的粮食，又将你交给恨你的非利士众女<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="众女是城邑的意思；本章下同">a</a></sup>，使她们任意待你。她们见你的淫行，为你羞耻。</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪下 16:7; 何西阿书 10:6; 列王纪下 16:10–18"> 你因贪色无厌，又与亚述人行淫，与他们行淫之后，仍不满意，</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪下 21:9; 士师记 2:12–19; 以西结书 13:14–23"> 并且多行淫乱，直到那贸易之地，就是迦勒底，你仍不满意。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 3:3; 以赛亚书 1:3; 以赛亚书 3:9"> 「主耶和华说：你行这一切事，都是不知羞耻妓女所行的，可见你的心是何等懦弱！</span>
<span className="v" id="v31" data-v="31" data-xref="以西结书 16:33–34; 以赛亚书 52:3; 以西结书 16:39"> 因你在一切市口上建造圆顶花楼，在各街上做了高台，你却藐视赏赐，不像妓女。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 2:28; 以西结书 23:37; 耶利米书 2:25"> 哎！你这行淫的妻啊，宁肯接外人，不接丈夫。</span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 57:9; 何西阿书 8:9–10; 以西结书 16:41"> 凡妓女是得人赠送，你反倒赠送你所爱的人，贿赂他们从四围来与你行淫。</span>
<span className="v" id="v34" data-v="34"> 你行淫与别的妇女相反，因为不是人从你行淫；你既赠送人，人并不赠送你；所以你与别的妇女相反。」</span>
</div>
</div>

## 神审判耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="约翰福音 4:18; 列王纪上 22:19; 约翰福音 4:10"> 「你这妓女啊，要听耶和华的话。</span>
<span className="v" id="v36" data-v="36" data-xref="以西结书 23:10; 以西结书 24:13; 西番雅书 3:1"> 主耶和华如此说：因你的污秽倾泄了，你与你所爱的行淫露出下体，又因你拜一切可憎的偶像，流儿女的血献给他，</span>
<span className="v" id="v37" data-v="37" data-xref="何西阿书 2:10; 耶利米书 13:22; 何西阿书 2:3"> 我就要将你一切相欢相爱的和你一切所恨的都聚集来，从四围攻击你；又将你的下体露出，使他们看尽了。</span>
<span className="v" id="v38" data-v="38" data-xref="利未记 20:10; 创世记 9:6; 西番雅书 1:17"> 我也要审判你，好像官长审判淫妇和流人血的妇女一样。我因忿怒忌恨，使流血的罪归到你身上。</span>
<span className="v" id="v39" data-v="39" data-xref="以西结书 23:26; 何西阿书 2:3; 以西结书 16:24–25"> 我又要将你交在他们手中；他们必拆毁你的圆顶花楼，毁坏你的高台，剥去你的衣服，夺取你的华美宝器，留下你赤身露体。</span>
<span className="v" id="v40" data-v="40" data-xref="以西结书 23:47; 哈巴谷书 1:6–10; 约翰福音 8:5–7"> 他们也必带多人来攻击你，用石头打死你，用刀剑刺透你，</span>
<span className="v" id="v41" data-v="41" data-xref="以西结书 23:48; 耶利米书 52:13; 耶利米书 39:8"> 用火焚烧你的房屋，在许多妇人眼前向你施行审判。我必使你不再行淫，也不再赠送与人。</span>
<span className="v" id="v42" data-v="42" data-xref="以西结书 5:13; 以西结书 21:17; 以赛亚书 40:1–2"> 这样，我就止息向你发的忿怒，我的忌恨也要离开你，我要安静不再恼怒。</span>
<span className="v" id="v43" data-v="43" data-xref="以西结书 16:22; 以西结书 11:21; 诗篇 78:42"> 因你不追念你幼年的日子，在这一切的事上向我发烈怒，所以我必照你所行的报应在你头上，你就不再贪淫，行那一切可憎的事。这是主耶和华说的。」</span>
</div>
</div>

## 有其母必有其女

<div className="bt">
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="以西结书 18:2–3; 诗篇 106:35–38; 撒母耳记上 24:13"> 「凡说俗语的必用俗语攻击你，说：『母亲怎样，女儿也怎样。』</span>
<span className="v" id="v45" data-v="45" data-xref="撒迦利亚书 11:8; 以赛亚书 1:4; 以西结书 23:37–39"> 你正是你母亲的女儿，厌弃丈夫和儿女；你正是你姊妹的姊妹，厌弃丈夫和儿女。你母亲是赫人，你父亲是亚摩利人。</span>
<span className="v" id="v46" data-v="46" data-xref="以西结书 23:4; 以西结书 16:48–49; 以西结书 16:53–56"> 你的姊姊是撒马利亚，她和她的众女住在你左边；你的妹妹是所多玛，她和她的众女住在你右边。</span>
<span className="v" id="v47" data-v="47" data-xref="列王纪下 21:9; 以西结书 16:51; 以西结书 5:6–7"> 你没有效法她们的行为，也没有照她们可憎的事去做，你以那为小事，你一切所行的倒比她们更坏。</span>
<span className="v" id="v48" data-v="48" data-xref="马太福音 10:15; 路加福音 10:12; 使徒行传 7:52"> 主耶和华说：我指着我的永生起誓，你妹妹所多玛与她的众女尚未行你和你众女所行的事。</span>
<span className="v" id="v49" data-v="49" data-xref="诗篇 138:6; 以西结书 28:2; 创世记 13:10"> 看哪，你妹妹所多玛的罪孽是这样：她和她的众女都心骄气傲，粮食饱足，大享安逸，并没有扶助困苦和穷乏人的手。</span>
<span className="v" id="v50" data-v="50" data-xref="创世记 19:24; 创世记 18:20; 创世记 19:5"> 她们狂傲，在我面前行可憎的事，我看见便将她们除掉。</span>
<span className="v" id="v51" data-v="51" data-xref="耶利米书 3:8–11; 路加福音 12:47–48; 罗马书 3:9–20"> 撒马利亚没有犯你一半的罪，你行可憎的事比她更多，使你的姊妹因你所行一切可憎的事，倒显为义。</span>
<span className="v" id="v52" data-v="52" data-xref="马太福音 7:1–5; 以西结书 36:15; 以西结书 16:56"> 你既断定你姊妹为义<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="为义：或译当受羞辱">b</a></sup>，就要担当自己的羞辱；因你所犯的罪比她们更为可憎，她们就比你更显为义；你既使你的姊妹显为义，你就要抱愧担当自己的羞辱。」</span>
</div>
</div>

## 所多玛、撒马利亚要复兴

<div className="bt">
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="以西结书 29:14; 耶利米书 12:16; 以西结书 39:25"> 「我必叫她们被掳的归回，就是叫所多玛和她的众女，撒马利亚和她的众女，并你们中间被掳的，都要归回，</span>
<span className="v" id="v54" data-v="54" data-xref="以西结书 14:22–23; 耶利米书 2:26; 以西结书 36:31–32"> 好使你担当自己的羞辱，并因你一切所行的使她们得安慰，你就抱愧。</span>
<span className="v" id="v55" data-v="55" data-xref="以西结书 36:11; 玛拉基书 3:4; 以西结书 16:53"> 你的妹妹所多玛和她的众女必归回原位；撒马利亚和她的众女，你和你的众女，也必归回原位。</span>
<span className="v" id="v56" data-v="56" data-xref="以赛亚书 65:5; 路加福音 15:28–30; 西番雅书 3:11"> 在你骄傲的日子，你的恶行没有显露以先，你的口就不提你的妹妹所多玛。那受了凌辱的亚兰众女和亚兰四围非利士的众女都恨恶你，藐视你。</span>
<span className="v" id="v58" data-v="58" data-xref="以西结书 23:49; 耶利米哀歌 5:7; 创世记 4:13"> 耶和华说：你贪淫和可憎的事，你已经担当了。」</span>
</div>
</div>

## 永远的约

<div className="bt">
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="以赛亚书 24:5; 以西结书 17:19; 申命记 29:25"> 「主耶和华如此说：你这轻看誓言、背弃盟约的，我必照你所行的待你。</span>
<span className="v" id="v60" data-v="60" data-xref="何西阿书 2:19–20; 希伯来书 12:24; 以西结书 16:8"> 然而我要追念在你幼年时与你所立的约，也要与你立定永约。</span>
<span className="v" id="v61" data-v="61" data-xref="希伯来书 8:13; 加拉太书 4:26–31; 以赛亚书 66:7–12"> 你接待你姊姊和你妹妹的时候，你要追念你所行的，自觉惭愧；并且我要将她们赐你为女儿，却不是按着前约。</span>
<span className="v" id="v62" data-v="62" data-xref="耶利米书 24:7; 以西结书 6:7; 以西结书 39:22"> 我要坚定与你所立的约（你就知道我是耶和华），</span>
<span className="v" id="v63" data-v="63" data-xref="诗篇 39:9; 罗马书 3:19; 以西结书 36:31–32"> 好使你在我赦免你一切所行的时候，心里追念，自觉抱愧，又因你的羞辱就不再开口。这是主耶和华说的。」</span>
</div>

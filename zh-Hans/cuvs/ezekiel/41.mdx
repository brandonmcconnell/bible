## 靠圣殿墙边的厢房

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪上 6:5–6; 以西结书 42:3–14; 以西结书 41:6–9"> 他又量殿墙，厚六肘；围着殿有旁屋，各宽四肘。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 6:10; 列王纪上 6:5–6; 以西结书 40:17"> 旁屋有三层，层叠而上，每层排列三十间。旁屋的梁木搁在殿墙坎上，免得插入殿墙。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 6:8; 希伯来书 6:1; 马太福音 13:32"> 这围殿的旁屋越高越宽；因旁屋围殿悬叠而上，所以越上越宽，从下一层，由中一层，到上一层。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 40:5; 启示录 21:16"> 我又见围着殿有高月台。旁屋的根基，高足一竿，就是六大肘。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 41:11; 以西结书 42:4; 以西结书 42:1"> 旁屋的外墙厚五肘。旁屋之外还有余地。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 40:17"> 在旁屋与对面的房屋中间有空地，宽二十肘。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 41:9; 以西结书 42:4"> 旁屋的门都向余地：一门向北，一门向南。周围的余地宽五肘。</span>
</div>
</div>

## 圣殿的内部

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪上 6:4; 以西结书 40:25; 以西结书 40:16"> 内殿、院廊、门槛、严紧的窗棂，并对着门槛的三层楼廊，从地到窗棂（窗棂都有蔽子），</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 42:15"> 直到门以上，就是到内殿和外殿内外四围墙壁，都按尺寸用木板遮蔽。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 7:36; 以西结书 40:16; 以西结书 40:22"> 墙上雕刻基路伯和棕树。每二基路伯中间有一棵棕树，每基路伯有二脸。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 10:14; 以西结书 1:10"> 这边有人脸向着棕树，那边有狮子脸向着棕树，殿内周围都是如此。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 41:18"> 从地至门以上，都有基路伯和棕树。殿墙就是这样。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 41:1; 列王纪上 6:33; 以西结书 40:14"> 殿的门柱是方的。至圣所的前面，形状和殿的形状一样。</span>
<span className="v" id="v22" data-v="22" data-xref="玛拉基书 1:12; 以西结书 23:41; 玛拉基书 1:7"> 坛是木头做的，高三肘，长二肘。坛角和坛面，并四旁，都是木头做的。他对我说：「这是耶和华面前的桌子。」</span>
</div>
</div>

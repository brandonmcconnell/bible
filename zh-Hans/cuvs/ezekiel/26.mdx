## 斥责泰尔

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西结书 20:1; 以西结书 1:2; 耶利米书 39:2"> 第十一年十一月初一日，耶和华的话临到我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 23:1–18; 以西结书 36:2; 约珥书 3:4"> 「人子啊，因泰尔向耶路撒冷说：『阿哈，那作众民之门的已经破坏，向我开放；她既变为荒场，我必丰盛。』</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 51:42; 以赛亚书 5:30; 弥迦书 4:11"> 所以，主耶和华如此说：泰尔啊，我必与你为敌，使许多国民上来攻击你，如同海使波浪涌上来一样。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 23:11; 阿摩司书 1:10; 以西结书 26:9"> 他们必破坏泰尔的墙垣，拆毁她的城楼。我也要刮净尘土，使她成为净光的磐石。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 29:19; 以西结书 27:32; 以西结书 25:7"> 她必在海中作晒网的地方，也必成为列国的掳物。这是主耶和华说的。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 16:46; 以西结书 26:8; 耶利米书 49:2"> 属泰尔城邑的居民<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是田间的众女；八节同">a</a></sup>必被刀剑杀灭，他们就知道我是耶和华。」</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 7:12; 但以理书 2:37; 以西结书 23:24"> 主耶和华如此说：「我必使诸王之王的巴比伦王尼布甲尼撒率领马匹车辆、马兵、军队，和许多人民从北方来攻击你泰尔。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 21:22; 耶利米书 52:4; 耶利米书 32:24"> 他必用刀剑杀灭属你城邑的居民，也必造台筑垒举盾牌攻击你。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 26:15"> 他必安设撞城锤攻破你的墙垣，用铁器拆毁你的城楼。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 26:15; 以西结书 27:28; 耶利米书 47:3"> 因他的马匹众多，尘土扬起遮蔽你。他进入你的城门，好像人进入已有破口之城。那时，你的墙垣必因骑马的和战车、辎重车的响声震动。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 5:28; 以赛亚书 26:5; 哈巴谷书 1:8"> 他的马蹄必践踏你一切的街道；他必用刀杀戮你的居民。你坚固的柱子<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：柱像">b</a></sup>必倒在地上。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 23:8; 历代志下 32:27; 撒迦利亚书 9:3–4"> 人必以你的财宝为掳物，以你的货财为掠物，破坏你的墙垣，拆毁你华美的房屋，将你的石头、木头、尘土都抛在水中。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 7:34; 以赛亚书 23:16; 以赛亚书 14:11"> 我必使你唱歌的声音止息；人也不再听见你弹琴的声音。</span>
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 1:4; 约伯记 12:14; 民数记 23:19"> 我必使你成为净光的磐石，作晒网的地方。你不得再被建造，因为这是主耶和华说的。」</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 27:35; 耶利米书 49:21; 以西结书 26:18"> 主耶和华对泰尔如此说：「在你中间行杀戮，受伤之人唉哼的时候，因你倾倒的响声，海岛岂不都震动吗？</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 32:10; 约拿书 3:6; 约伯记 8:22"> 那时靠海的君王必都下位，除去朝服，脱下花衣，披上战兢，坐在地上，时刻发抖，为你惊骇。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 14:12; 以西结书 19:1; 撒母耳记下 1:25–27"> 他们必为你作起哀歌说：<br /><span className="pl pl-1">你这有名之城，</span><br /><span className="pl pl-1">素为航海之人居住，</span><br /><span className="pl pl-1">在海上为最坚固的；</span><br /><span className="pl pl-1">平日你和居民使一切住在那里的人无不惊恐；</span><br /><span className="pl pl-1">现在何竟毁灭了？</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 26:15; 以赛亚书 23:5–7; 以西结书 27:35"> <span className="pl pl-1">如今在你这倾覆的日子，</span><br /><span className="pl pl-1">海岛都必战兢；</span><br /><span className="pl pl-1">海中的群岛见你归于无有就都惊惶。」</span></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 8:7–8; 以西结书 26:3; 但以理书 11:40"> 主耶和华如此说：「泰尔啊，我使你变为荒凉，如无人居住的城邑；又使深水漫过你，大水淹没你。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 27:13; 路加福音 10:15; 撒迦利亚书 2:8"> 那时，我要叫你下入阴府，与古时的人一同在地的深处、久已荒凉之地居住，使你不再有居民。我也要在活人之地显荣耀<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="我也......荣耀：或译在活人之地不再有荣耀">c</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 27:36; 以西结书 28:19; 启示录 18:21"> 我必叫你令人惊恐，不再存留于世；人虽寻找你，却永寻不见。这是主耶和华说的。」</span>

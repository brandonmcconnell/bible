<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 10:9–10; 以西结书 3:17–21; 以西结书 2:8–9"> 他对我说：「人子啊，要吃你所得的，要吃这书卷，好去对以色列家讲说。」</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 25:17; 使徒行传 26:19"> 于是我开口，他就使我吃这书卷，</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 15:16; 启示录 10:9–10; 诗篇 119:103"> 又对我说：「人子啊，要吃我所赐给你的这书卷，充满你的肚腹。」我就吃了，口中觉得其甜如蜜。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 10:5–6; 使徒行传 1:8; 以西结书 2:3"> 他对我说：「人子啊，你往以色列家那里去，将我的话对他们讲说。</span>
<span className="v" id="v5" data-v="5" data-xref="约拿书 1:2; 以赛亚书 33:19; 约拿书 3:2–4"> 你奉差遣不是往那说话深奥、言语难懂的民那里去，乃是往以色列家去；</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 11:20–24; 罗马书 9:30–33; 约拿书 3:5–10"> 不是往那说话深奥、言语难懂的多国去，他们的话语是你不懂得的。我若差你往他们那里去，他们必听从你。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 10:16; 以西结书 2:4; 撒母耳记上 8:7"> 以色列家却不肯听从你，因为他们不肯听从我；原来以色列全家是额坚心硬的人。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 1:18; 使徒行传 7:51–56; 弥迦书 3:8"> 看哪，我使你的脸硬过他们的脸，使你的额硬过他们的额。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 2:6; 耶利米书 1:8; 以赛亚书 50:7"> 我使你的额像金钢钻，比火石更硬。他们虽是悖逆之家，你不要怕他们，也不要因他们的脸色惊惶。」</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 119:11; 约伯记 22:22; 以西结书 3:1–3"> 他又对我说：「人子啊，我对你所说的一切话，要心里领会，耳中听闻。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 2:7; 以西结书 3:27; 以西结书 33:30"> 你往你本国被掳的子民那里去，他们或听，或不听，你要对他们讲说，告诉他们这是主耶和华说的。」</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 8:3; 使徒行传 8:39; 以西结书 11:1"> 那时，灵将我举起，我就听见在我身后有震动轰轰的声音，说：「从耶和华的所在显出来的荣耀是该称颂的！」</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 1:24; 以西结书 10:16–17; 以西结书 10:5"> 我又听见那活物翅膀相碰，与活物旁边轮子旋转震动轰轰的响声。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 37:1; 耶利米书 20:7–9; 列王纪下 3:15"> 于是灵将我举起，带我而去。我心中甚苦，灵性忿激，并且耶和华的灵<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是手">a</a></sup>在我身上大有能力。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 137:1; 约伯记 2:13; 创世记 50:10"> 我就来到提勒·亚毕，住在迦巴鲁河边被掳的人那里，到他们所住的地方，在他们中间忧忧闷闷地坐了七日。</span>
</div>
</div>

## 耶和华派以西结作守望者

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米书 42:7"> 过了七日，耶和华的话临到我说：</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 52:8; 希伯来书 13:17; 历代志下 19:10"> 「人子啊，我立你作以色列家守望的人，所以你要听我口中的话，替我警戒他们。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 33:6; 雅各书 5:19–20; 以西结书 3:20"> 我何时指着恶人说：他必要死；你若不警戒他，也不劝戒他，使他离开恶行，拯救他的性命，这恶人必死在罪孽之中；我却要向你讨他丧命的罪<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是血">b</a></sup>。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 33:9; 以西结书 14:20; 提摩太前书 4:16"> 倘若你警戒恶人，他仍不转离罪恶，也不离开恶行，他必死在罪孽之中，你却救自己脱离了罪。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 18:24; 以西结书 18:26; 以西结书 33:12–13"> 再者，义人何时离义而犯罪，我将绊脚石放在他面前，他就必死；因你没有警戒他，他必死在罪中，他素来所行的义不被记念；我却要向你讨他丧命的罪<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是血">c</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太前书 4:16; 箴言 9:9; 提多书 2:15"> 倘若你警戒义人，使他不犯罪，他就不犯罪；他因受警戒就必存活，你也救自己脱离了罪。」</span>
</div>
</div>

## 以西结暂成哑巴

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 9:6; 以西结书 37:1; 以西结书 8:4"> 耶和华的灵<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原文是手">d</a></sup>在那里降在我身上。他对我说：「你起来往平原去，我要在那里和你说话。」</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 1:28; 使徒行传 7:55; 启示录 1:17"> 于是我起来往平原去，不料，耶和华的荣耀正如我在迦巴鲁河边所见的一样，停在那里，我就俯伏于地。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 2:2; 但以理书 10:19; 但以理书 10:8–10"> 灵就进入我里面，使我站起来。耶和华对我说：「你进房屋去，将门关上。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 4:8; 使徒行传 9:16; 马可福音 3:21"> 人子啊，人必用绳索捆绑你，你就不能出去在他们中间来往。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 24:27; 弥迦书 3:6–7; 阿摩司书 8:11–12"> 我必使你的舌头贴住上膛，以致你哑口，不能作责备他们的人；他们原是悖逆之家。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 12:2–3; 以西结书 24:27; 以西结书 3:11"> 但我对你说话的时候，必使你开口，你就要对他们说：『主耶和华如此说。』听的可以听，不听的任他不听，因为他们是悖逆之家。」</span>
</div>
</div>

## 斥责泰尔王

<div className="bp poetry">

<span className="v" id="v2" data-v="2" data-xref="以西结书 28:9; 帖撒罗尼迦后书 2:4; 以赛亚书 14:13–14"> 「人子啊，你对泰尔君王说，主耶和华如此说：<br /><span className="pl pl-1">因你心里高傲，说：我是神；</span><br /><span className="pl pl-1">我在海中坐神之位。</span><br /><span className="pl pl-1">你虽然居心自比神，</span><br /><span className="pl pl-1">也不过是人，并不是神！</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="但以理书 1:20; 但以理书 2:22; 但以理书 2:27–28"> <span className="pl pl-1">看哪，你比但以理更有智慧，</span><br /><span className="pl pl-1">什么秘事都不能向你隐藏。</span><br /></span>

<span className="v" id="v6" data-v="6" data-xref="以西结书 28:2; 出埃及记 9:17; 雅各书 1:11"> <span className="pl pl-1">所以主耶和华如此说：</span><br /><span className="pl pl-1">因你居心自比神，</span><br /></span>

## 泰尔王的终局

<div className="bt">
<div className="bp poetry">
<span className="v" id="v11" data-v="11"> 耶和华的话临到我说：</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 19:1; 以西结书 26:17; 哥林多后书 1:22"> 「人子啊，你为泰尔王作起哀歌，说主耶和华如此说：<br /><span className="pl pl-1">你无所不备，</span><br /><span className="pl pl-1">智慧充足，全然美丽。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 28:15; 创世记 2:8; 以西结书 27:16"> <span className="pl pl-1">你曾在伊甸 神的园中，</span><br /><span className="pl pl-1">佩戴各样宝石，</span><br /><span className="pl pl-1">就是红宝石、红璧玺、金钢石、</span><br /><span className="pl pl-1">水苍玉、红玛瑙、碧玉、</span><br /><span className="pl pl-1">蓝宝石、绿宝石、红玉，和黄金；</span><br /><span className="pl pl-1">又有精美的鼓笛在你那里，</span><br /><span className="pl pl-1">都是在你受造之日预备齐全的。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 14:12–15; 出埃及记 30:26; 以西结书 28:13"> <span className="pl pl-1">你是那受膏遮掩约柜的基路伯；</span><br /><span className="pl pl-1">我将你安置在 神的圣山上；</span><br /><span className="pl pl-1">你在发光如火的宝石中间往来。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="彼得后书 2:4; 以西结书 28:17–18; 罗马书 7:9"> <span className="pl pl-1">你从受造之日所行的都完全，</span><br /><span className="pl pl-1">后来在你中间又察出不义。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="提摩太前书 6:9–10; 哈巴谷书 2:8; 哈巴谷书 2:17"> <span className="pl pl-1">因你贸易很多，</span><br /><span className="pl pl-1">就被强暴的事充满，以致犯罪，</span><br /><span className="pl pl-1">所以我因你亵渎圣地，</span><br /><span className="pl pl-1">就从 神的山驱逐你。</span><br /><span className="pl pl-1">遮掩约柜的基路伯啊，</span><br /><span className="pl pl-1">我已将你从发光如火的宝石中除灭。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 28:5; 以西结书 31:10; 雅各书 4:6"> <span className="pl pl-1">你因美丽心中高傲，</span><br /><span className="pl pl-1">又因荣光败坏智慧，</span><br /><span className="pl pl-1">我已将你摔倒在地，</span><br /><span className="pl pl-1">使你倒在君王面前，</span><br /><span className="pl pl-1">好叫他们目睹眼见。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="玛拉基书 4:3; 启示录 18:8; 阿摩司书 1:9–10"> <span className="pl pl-1">你因罪孽众多，</span><br /><span className="pl pl-1">贸易不公，</span><br /><span className="pl pl-1">就亵渎你那里的圣所。</span><br /><span className="pl pl-1">故此，我使火从你中间发出，烧灭你，</span><br /><span className="pl pl-1">使你在所有观看的人眼前变为地上的炉灰。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 26:21; 启示录 18:21; 启示录 18:15–19"> <span className="pl pl-1">各国民中，凡认识你的，</span><br /><span className="pl pl-1">都必为你惊奇。</span><br /><span className="pl pl-1">你令人惊恐，</span><br /><span className="pl pl-1">不再存留于世，直到永远。」</span></span>
</div>

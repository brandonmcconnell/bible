## 圣殿附近的两座屋子

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 40:20; 以西结书 40:17; 以西结书 42:13"> 他带我出来向北，到外院，又带我进入圣屋；这圣屋一排顺着空地，一排与北边铺石地之屋相对。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 41:13"> 这圣屋长一百肘，宽五十肘，有向北的门。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 41:15–16; 以西结书 41:10; 雅歌 7:5"> 对着内院那二十肘宽之空地，又对着外院的铺石地，在第三层楼上有楼廊对着楼廊。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 46:19; 路加福音 13:24; 马太福音 7:14"> 在圣屋前有一条夹道，宽十肘，长一百肘。房门都向北。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 41:7"> 圣屋因为楼廊占去些地方，所以上层比中下两层窄些。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 41:6; 列王纪上 6:8"> 圣屋有三层，却无柱子，不像外院的屋子有柱子；所以上层比中下两层更窄。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 42:12; 以西结书 42:10"> 圣屋外，东边有墙，靠着外院，长五十肘。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 41:13–14"> 靠着外院的圣屋长五十肘。殿北面的圣屋长一百肘。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 46:19; 以西结书 44:5"> 在圣屋以下，东头有进入之处，就是从外院进入之处。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 42:1; 以西结书 42:13; 以西结书 41:12–15"> 向南<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是东">a</a></sup>在内院墙里有圣屋，一排与铺石地之屋相对，一排顺着空地。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 42:4"> 这圣屋前的夹道与北边圣屋的夹道长宽一样；出入之处与北屋门的样式相同。</span>
<span className="v" id="v12" data-v="12"> 正在墙前、夹道的东头，有门可以进入，与向南圣屋的门一样。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 10:17; 利未记 7:6; 以西结书 40:46"> 他对我说：「顺着空地的南屋北屋，都是圣屋；亲近耶和华的祭司当在那里吃至圣的物，也当在那里放至圣的物，就是素祭、赎罪祭，和赎愆祭，因此处为圣。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 44:19; 利未记 8:7; 出埃及记 29:4–9"> 祭司进去出了圣所的时候，不可直到外院，但要在圣屋放下他们供职的衣服，因为是圣衣；要穿上别的衣服才可以到属民的外院。」</span>
</div>
</div>

## 圣殿周围的尺寸

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西结书 43:1; 以西结书 41:15; 以西结书 40:6–16"> 他量完了内殿，就带我出朝东的门，量院的四围。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 40:3; 启示录 11:1–2; 撒迦利亚书 2:1"> 他用量度的竿量四围，量东面五百肘<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是竿；本章下同">b</a></sup>，</span>
<span className="v" id="v17" data-v="17"> 用竿量北面五百肘，</span>
<span className="v" id="v18" data-v="18"> 用竿量南面五百肘，</span>
<span className="v" id="v19" data-v="19"> 又转到西面，用竿量五百肘。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 45:2; 以西结书 22:26; 以西结书 40:5"> 他量四面，四围有墙，长五百肘，宽五百肘，为要分别圣地与俗地。</span>
</div>

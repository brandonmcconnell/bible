## 神惩罚以东

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 22:1; 以西结书 21:1; 以西结书 34:1"> 耶和华的话又临到我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 6:2; 创世记 32:3; 以西结书 25:8"> 「人子啊，你要面向西珥山发预言，攻击它，</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 6:12; 以西结书 35:7; 以西结书 6:14"> 对它说，主耶和华如此说：西珥山哪，我与你为敌，必向你伸手攻击你，使你荒凉，令人惊骇。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 35:9; 玛拉基书 1:3–4; 约珥书 3:19"> 我必使你的城邑变为荒场，成为凄凉。你就知道我是耶和华。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 137:7; 俄巴底亚书 1:10–16; 阿摩司书 1:11"> 因为你永怀仇恨，在以色列人遭灾、罪孽到了尽头的时候，将他们交与刀剑，</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 63:2–6; 启示录 18:24; 俄巴底亚书 1:15"> 所以主耶和华说：我指着我的永生起誓，我必使你遭遇流血的报应，罪<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是血；本节同">a</a></sup>必追赶你；你既不恨恶杀人流血，所以这罪必追赶你。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 29:11; 以西结书 35:3; 士师记 5:6–7"> 我必使西珥山荒凉，令人惊骇，来往经过的人我必剪除。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 31:12; 以西结书 32:4–5; 以西结书 39:4–5"> 我必使西珥山满有被杀的人。被刀杀的，必倒在你小山和山谷，并一切的溪水中。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 25:13; 玛拉基书 1:3–4; 以西结书 6:7"> 我必使你永远荒凉，使你的城邑无人居住，你的民就知道我是耶和华。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 36:5; 诗篇 83:4–12; 以西结书 48:35"> 「因为你曾说：『这二国这二邦必归于我，我必得为业』（其实耶和华仍在那里），</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 9:16; 马太福音 7:2; 诗篇 73:17–18"> 所以主耶和华说：我指着我的永生起誓，我必照你的怒气和你从仇恨中向他们所发的嫉妒待你。我审判你的时候，必将自己显明在他们中间。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 36:2; 诗篇 83:12; 以西结书 6:7"> 你也必知道我—耶和华听见了你的一切毁谤，就是你攻击以色列山的话，说：『这些山荒凉，是归我们吞灭的。』</span>
<span className="v" id="v13" data-v="13" data-xref="但以理书 11:36; 以赛亚书 36:20; 耶利米书 29:23"> 你们也用口向我夸大，增添与我反对的话，我都听见了。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 51:48; 以赛亚书 14:7–8; 以赛亚书 65:13–15"> 主耶和华如此说：全地欢乐的时候，我必使你荒凉。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 35:3–4; 耶利米哀歌 4:21; 以赛亚书 34:5–6"> 你怎样因以色列家的地业荒凉而喜乐，我必照你所行的待你。西珥山哪，你和以东全地必都荒凉。你们就知道我是耶和华。」</span>

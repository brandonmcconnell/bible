## 生锈的锅

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西结书 8:1; 以西结书 20:1; 以西结书 29:17"> 第九年十月初十日，耶和华的话又临到我说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 39:1; 耶利米书 52:4; 列王纪下 25:1"> 「人子啊，今日正是巴比伦王就近耶路撒冷的日子，你要将这日记下，</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 11:3; 以西结书 17:2; 以西结书 20:49"> 要向这悖逆之家设比喻说，主耶和华如此说：<br /><span className="pl pl-1">将锅放在火上，</span><br /><span className="pl pl-1">放好了，就倒水在其中；</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="弥迦书 3:2–3; 以西结书 22:18–22; 马太福音 7:2"> <span className="pl pl-1">将肉块，就是一切肥美的肉块、腿，</span><br /><span className="pl pl-1">和肩都聚在其中，</span><br /><span className="pl pl-1">拿美好的骨头把锅装满；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 52:24–27; 耶利米书 52:10; 耶利米书 39:6"> <span className="pl pl-1">取羊群中最好的，</span><br /><span className="pl pl-1">将柴堆在锅下，</span><br /><span className="pl pl-1">使锅开滚，</span><br /><span className="pl pl-1">好把骨头煮在其中。</span></span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 22:2; 那鸿书 3:1; 俄巴底亚书 1:11"> 「主耶和华如此说：祸哉！这流人血的城，就是长锈的锅。其中的锈未曾除掉，须要将肉块从其中一一取出来，不必为它拈阄。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 17:13; 申命记 12:16; 约伯记 16:18"> 城中所流的血倒在净光的磐石上，不倒在地上，用土掩盖。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 32:21–22; 启示录 18:5–10; 以西结书 22:30–31"> 这城中所流的血倒在净光的磐石上，不得掩盖，乃是出于我，为要发忿怒施行报应。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 24:6; 哈巴谷书 2:12; 以赛亚书 31:9"> 所以主耶和华如此说：祸哉！这流人血的城，我也必大堆火柴，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米哀歌 2:16; 耶利米书 17:3; 耶利米哀歌 1:10"> 添上木柴，使火着旺，将肉煮烂，把汤熬浓，使骨头烤焦；</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 21:10; 玛拉基书 4:1; 以赛亚书 1:25"> 把锅倒空坐在炭火上，使锅烧热，使铜烧红，熔化其中的污秽，除净其上的锈。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 9:5; 耶利米书 2:13; 耶利米书 5:3"> 这锅劳碌疲乏，所长的大锈仍未除掉；这锈就是用火也不能除掉。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 22:24; 以西结书 5:13; 西番雅书 3:2"> 在你污秽中有淫行，我洁净你，你却不洁净。你的污秽再不能洁净，直等我向你发的忿怒止息。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 16:27; 以西结书 18:30; 以赛亚书 3:11"> 我—耶和华说过的必定成就，必照话而行，必不返回，必不顾惜，也不后悔。人必照你的举动行为审判你。这是主耶和华说的。」</span>
</div>

## 先知妻子的死

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15"> 耶和华的话又临到我说：</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 22:10; 耶利米书 13:17; 雅歌 7:10"> 「人子啊，我要将你眼目所喜爱的忽然取去，你却不可悲哀哭泣，也不可流泪，</span>
<span className="v" id="v17" data-v="17" data-xref="何西阿书 9:4; 撒母耳记下 15:30; 利未记 10:6"> 只可叹息，不可出声，不可办理丧事；头上仍勒裹头巾，脚上仍穿鞋，不可蒙着嘴唇，也不可吃吊丧的食物。」</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 7:29–30"> 于是我将这事早晨告诉百姓，晚上我的妻就死了。次日早晨我便遵命而行。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 12:9; 以西结书 37:18; 玛拉基书 3:7–8"> 百姓问我说：「你这样行与我们有什么关系，你不告诉我们吗？」</span>
<span className="v" id="v20" data-v="20"> 我回答他们：「耶和华的话临到我说：</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 23:47; 以西结书 23:25; 诗篇 27:4"> 『你告诉以色列家，主耶和华如此说：我必使我的圣所，就是你们势力所夸耀、眼里所喜爱、心中所爱惜的被亵渎，并且你们所遗留的儿女必倒在刀下。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 78:64; 耶利米书 16:4–7; 以西结书 24:16–17"> 那时，你们必行我仆人所行的，不蒙着嘴唇，也不吃吊丧的食物。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 33:10; 以西结书 4:17; 利未记 26:39"> 你们仍要头上勒裹头巾，脚上穿鞋；不可悲哀哭泣。你们必因自己的罪孽相对叹息，渐渐消灭。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 4:3; 以赛亚书 20:3; 路加福音 11:29–30"> 以西结必这样为你们作预兆；凡他所行的，你们也必照样行。那事来到，你们就知道我是主耶和华。』</span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 24:21; 诗篇 48:2; 耶利米书 11:22"> 「人子啊，我除掉他们所倚靠、所欢喜的荣耀，并眼中所喜爱、心里所重看的儿女。</span>
<span className="v" id="v26" data-v="26" data-xref="约伯记 1:15–19; 以西结书 33:21–22; 撒母耳记上 4:12–18"> 那日逃脱的人岂不来到你这里，使你耳闻这事吗？</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 33:22; 以西结书 29:21; 路加福音 21:15"> 你必向逃脱的人开口说话，不再哑口。你必这样为他们作预兆，他们就知道我是耶和华。」</span>

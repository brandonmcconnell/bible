## 枯骨的复苏

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 3:22; 以西结书 1:3; 使徒行传 8:39"> 耶和华的灵<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是手">a</a></sup>降在我身上。耶和华借他的灵带我出去，将我放在平原中；这平原遍满骸骨。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 141:7; 以西结书 37:11; 申命记 11:30"> 他使我从骸骨的四围经过，谁知在平原的骸骨甚多，而且极其枯干。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 11:25–26; 约翰福音 5:21; 申命记 32:39"> 他对我说：「人子啊，这些骸骨能复活吗？」我说：「主耶和华啊，你是知道的。」</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 5:25; 约翰福音 5:28–29; 马太福音 21:21"> 他又对我说：「你向这些骸骨发预言说：枯干的骸骨啊，要听耶和华的话。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 37:14; 诗篇 104:29–30; 创世记 2:7"> 主耶和华对这些骸骨如此说：『我必使气息进入你们里面，你们就要活了。</span>
<span className="v" id="v6" data-v="6" data-xref="约珥书 2:27; 以赛亚书 49:23; 约珥书 3:17"> 我必给你们加上筋，使你们长肉，又将皮遮蔽你们，使气息进入你们里面，你们就要活了；你们便知道我是耶和华。』」</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 2:2; 列王纪上 19:11–13; 耶利米书 13:5–7"> 于是，我遵命说预言。正说预言的时候，不料，有响声，有地震；骨与骨互相联络。</span>
<span className="v" id="v8" data-v="8"> 我观看，见骸骨上有筋，也长了肉，又有皮遮蔽其上，只是还没有气息。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 3:8; 雅歌 4:16; 诗篇 104:30"> 主对我说：「人子啊，你要发预言，向风发预言，说主耶和华如此说：气息啊，要从四方<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是风">b</a></sup>而来，吹在这些被杀的人身上，使他们活了。」</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 11:11; 诗篇 104:30; 启示录 20:4–5"> 于是我遵命说预言，气息就进入骸骨，骸骨便活了，并且站起来，成为极大的军队。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 2:1; 诗篇 77:7–9; 以西结书 39:25"> 主对我说：「人子啊，这些骸骨就是以色列全家。他们说：『我们的骨头枯干了，我们的指望失去了，我们灭绝净尽了。』</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 26:19; 何西阿书 13:14; 帖撒罗尼迦前书 4:16"> 所以你要发预言对他们说，主耶和华如此说：『我的民哪，我必开你们的坟墓，使你们从坟墓中出来，领你们进入以色列地。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 37:6; 以西结书 16:62; 诗篇 126:2–3"> 我的民哪，我开你们的坟墓，使你们从坟墓中出来，你们就知道我是耶和华。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 36:27; 约珥书 2:28–29; 以西结书 36:36"> 我必将我的灵放在你们里面，你们就要活了。我将你们安置在本地，你们就知道我—耶和华如此说，也如此成就了。这是耶和华说的。』」</span>
</div>
</div>

## 犹大和以色列组成联合王国

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15"> 耶和华的话又临到我说：</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 15:9; 历代志下 10:19; 历代志下 10:17"> 「人子啊，你要取一根木杖，在其上写『为犹大和他的同伴以色列人』；又取一根木杖，在其上写『为约瑟，就是为以法莲，又为他的同伴以色列全家』。</span>
<span className="v" id="v17" data-v="17" data-xref="何西阿书 1:11; 耶利米书 50:4; 以赛亚书 11:13"> 你要使这两根木杖接连为一，在你手中成为一根。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 24:19; 以西结书 12:9; 以西结书 17:12"> 你本国的子民问你说：『这是什么意思？你不指示我们吗？』</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 10:6; 以西结书 37:16–17; 以弗所书 2:13–14"> 你就对他们说：『主耶和华如此说：我要将约瑟和他同伴以色列支派的杖，就是那在以法莲手中的，与犹大的杖一同接连为一，在我手中成为一根。』</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 12:3; 民数记 17:6–9; 何西阿书 12:10"> 你所写的那两根杖要在他们眼前拿在手中，</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 36:24; 耶利米书 29:14; 耶利米书 23:8"> 要对他们说，主耶和华如此说：我要将以色列人从他们所到的各国收取，又从四围聚集他们，引导他们归回本地。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 37:24; 以西结书 34:23–24; 耶利米书 3:18"> 我要使他们在那地，在以色列山上成为一国，有一王作他们众民的王。他们不再为二国，决不再分为二国；</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 21:3–4; 以西结书 36:28–29; 约翰一书 1:9"> 也不再因偶像和可憎的物，并一切的罪过玷污自己。我却要救他们出离一切的住处，就是他们犯罪的地方；我要洁净他们，如此，他们要作我的子民，我要作他们的 神。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 34:23–24; 何西阿书 3:5; 以西结书 37:25"> 「我的仆人大卫必作他们的王；众民必归一个牧人。他们必顺从我的典章，谨守遵行我的律例。</span>
<span className="v" id="v25" data-v="25" data-xref="阿摩司书 9:15; 以西结书 37:24; 以西结书 28:25"> 他们必住在我赐给我仆人雅各的地上，就是你们列祖所住之地。他们和他们的子孙，并子孙的子孙，都永远住在那里。我的仆人大卫必作他们的王，直到永远。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 55:3; 耶利米书 30:19; 以西结书 34:25"> 并且我要与他们立平安的约，作为永约。我也要将他们安置在本地，使他们的人数增多，又在他们中间设立我的圣所，直到永远。</span>
<span className="v" id="v27" data-v="27" data-xref="启示录 21:3; 约翰福音 1:14; 以西结书 37:23"> 我的居所必在他们中间；我要作他们的 神，他们要作我的子民。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 17:17–19; 以西结书 20:12; 出埃及记 31:13"> 我的圣所在以色列人中间直到永远，外邦人就必知道我是叫以色列成为圣的耶和华。」</span>
</div>
</div>

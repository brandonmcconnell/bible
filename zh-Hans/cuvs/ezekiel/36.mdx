## 神赐福给以色列

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 37:4; 以西结书 34:14; 以西结书 37:22"> 「人子啊，你要对以色列山发预言说：以色列山哪，要听耶和华的话。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 32:13; 以西结书 25:3; 以西结书 35:10"> 主耶和华如此说：因仇敌说：『阿哈！这永久的山冈都归我们为业了！』</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 44:13–14; 耶利米哀歌 2:15–16; 耶利米书 18:16"> 所以要发预言说，主耶和华如此说：因为敌人使你荒凉，四围吞吃，好叫你归与其余的外邦人为业，并且多嘴多舌的人提起你来，百姓也说你有臭名。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 34:28; 申命记 11:11; 以西结书 36:6"> 故此，以色列山要听主耶和华的话。大山小冈、水沟山谷、荒废之地、被弃之城，为四围其余的外邦人所占据、所讥刺的，</span>
<span className="v" id="v5" data-v="5" data-xref="弥迦书 7:8; 以西结书 36:3; 诗篇 137:7"> 主耶和华对你们如此说：我真发愤恨如火，责备那其余的外邦人和以东的众人。他们快乐满怀，心存恨恶，将我的地归自己为业，又看为被弃的掠物。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 123:3–4; 以西结书 34:29; 诗篇 74:23"> 所以，你要指着以色列地说预言，对大山小冈、水沟山谷说，主耶和华如此说：我发愤恨和忿怒说，因你们曾受外邦人的羞辱，</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 20:5; 阿摩司书 1:1–15; 以西结书 20:15"> 所以我起誓说：你们四围的外邦人总要担当自己的羞辱。这是主耶和华说的。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 27:6; 希伯来书 10:37; 以西结书 34:26–29"> 「以色列山哪，你必发枝条，为我的民以色列结果子，因为他们快要来到。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 46:11; 何西阿书 2:21–23; 以西结书 36:34"> 看哪，我是帮助你的，也必向你转意，使你得以耕种。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 36:33; 耶利米书 33:12; 以西结书 36:37"> 我必使以色列全家的人数在你上面增多，城邑有人居住，荒场再被建造。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 33:12; 耶利米书 23:5–8; 耶利米书 31:27"> 我必使人和牲畜在你上面加增；他们必生养众多。我要使你照旧有人居住，并要赐福与你比先前更多，你就知道我是耶和华。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 15:7; 以西结书 36:13; 耶利米书 32:44"> 我必使人，就是我的民以色列，行在你上面。他们必得你为业；你也不再使他们丧子。</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 13:32"> 主耶和华如此说：因为人对你说：『你是吞吃人的，又使国民丧子』，</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 37:25–28; 阿摩司书 9:15; 以赛亚书 60:21"> 所以主耶和华说：你必不再吞吃人，也不再使国民丧子。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 34:29; 诗篇 89:50; 以西结书 36:6"> 我使你不再听见各国的羞辱，不再受万民的辱骂，也不再使国民绊跌。这是主耶和华说的。」</span>
</div>
</div>

## 以色列的新生活

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16"> 耶和华的话又临到我说：</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 2:7; 民数记 35:33–34; 弥迦书 2:10"> 「人子啊，以色列家住在本地的时候，在行动作为上玷污那地。他们的行为在我面前，好像正在经期的妇人那样污秽。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 34:21; 以西结书 7:8; 耶利米哀歌 2:4"> 所以我因他们在那地上流人的血，又因他们以偶像玷污那地，就把我的忿怒倾在他们身上。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 39:24; 申命记 28:64; 以西结书 5:12"> 我将他们分散在列国，四散在列邦，按他们的行动作为惩罚他们。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 2:24; 以赛亚书 52:5; 耶利米书 33:24"> 他们到了所去的列国，就使我的圣名被亵渎；因为人谈论他们说，这是耶和华的民，是从耶和华的地出来的。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 48:9; 诗篇 74:18; 以西结书 20:9"> 我却顾惜我的圣名，就是以色列家在所到的列国中所亵渎的。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 106:8; 以西结书 36:32; 诗篇 115:1–2"> 「所以，你要对以色列家说，主耶和华如此说：以色列家啊，我行这事不是为你们，乃是为我的圣名，就是在你们到的列国中所亵渎的。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 20:41; 以赛亚书 5:16; 以西结书 39:7"> 我要使我的大名显为圣；这名在列国中已被亵渎，就是你们在他们中间所亵渎的。我在他们眼前，在你们身上显为圣的时候，他们就知道我是耶和华。这是主耶和华说的。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 37:21; 以西结书 34:13; 阿摩司书 9:14–15"> 我必从各国收取你们，从列邦聚集你们，引导你们归回本地。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 10:22; 约翰福音 3:5; 耶利米书 33:8"> 我必用清水洒在你们身上，你们就洁净了。我要洁净你们，使你们脱离一切的污秽，弃掉一切的偶像。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 11:19–20; 诗篇 51:10; 哥林多后书 5:17"> 我也要赐给你们一个新心，将新灵放在你们里面，又从你们的肉体中除掉石心，赐给你们肉心。</span>
<span className="v" id="v27" data-v="27" data-xref="提多书 3:3–6; 希伯来书 13:21; 哥林多前书 3:16"> 我必将我的灵放在你们里面，使你们顺从我的律例，谨守遵行我的典章。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 31:33; 耶利米书 32:38; 以西结书 37:27"> 你们必住在我所赐给你们列祖之地。你们要作我的子民，我要作你们的 神。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 1:7–9; 马太福音 1:21; 何西阿书 2:21–23"> 我必救你们脱离一切的污秽，也必命五谷丰登，不使你们遭遇饥荒。</span>
<span className="v" id="v30" data-v="30" data-xref="以西结书 34:27; 约珥书 2:26; 申命记 29:23–28"> 我必使树木多结果子，田地多出土产，好叫你们不再因饥荒受外邦人的讥诮。</span>
<span className="v" id="v31" data-v="31" data-xref="以西结书 6:9; 以西结书 20:43; 尼希米记 9:26–35"> 那时，你们必追想你们的恶行和你们不善的作为，就因你们的罪孽和可憎的事厌恶自己。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 9:5; 以西结书 36:22; 提摩太后书 1:9"> 主耶和华说：你们要知道，我这样行不是为你们。以色列家啊，当为自己的行为抱愧蒙羞。</span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 58:12; 以西结书 36:10; 耶利米书 33:10"> 「主耶和华如此说：我洁净你们，使你们脱离一切罪孽的日子，必使城邑有人居住，荒场再被建造。</span>
<span className="v" id="v34" data-v="34" data-xref="以西结书 6:14; 耶利米书 25:9–11; 历代志下 36:21"> 过路的人虽看为荒废之地，现今这荒废之地仍得耕种。</span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 51:3; 约珥书 2:3; 耶利米书 33:9"> 他们必说：『这先前为荒废之地，现在成如伊甸园；这荒废凄凉、毁坏的城邑现在坚固有人居住。』</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 24:35; 民数记 23:19; 以西结书 17:24"> 那时，在你们四围其余的外邦人必知道我—耶和华修造那毁坏之处，培植那荒废之地。我—耶和华说过，也必成就。</span>
<span className="v" id="v37" data-v="37" data-xref="约翰一书 5:14; 希伯来书 10:21–22; 以西结书 14:3"> 「主耶和华如此说：我要加增以色列家的人数，多如羊群。他们必为这事向我求问，我要给他们成就。</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪上 8:63; 使徒行传 2:5–11; 约翰福音 10:16"> 耶路撒冷在守节作祭物所献的羊群怎样多，照样，荒凉的城邑必被人群充满。他们就知道我是耶和华。」</span>
</div>

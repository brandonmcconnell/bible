## 哀悼泰尔的挽歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 耶和华的话又临到我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 19:1; 耶利米书 9:10; 以西结书 28:12"> 「人子啊，要为泰尔作起哀歌，</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 27:4; 以赛亚书 23:11; 以赛亚书 23:2–3"> 说：你居住海口，是众民的商埠；你的交易通到许多的海岛。主耶和华如此说：<br /><span className="pl pl-1">泰尔啊，你曾说：</span><br /><span className="pl pl-1">我是全然美丽的。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 26:5"> <span className="pl pl-1">你的境界在海中，</span><br /><span className="pl pl-1">造你的使你全然美丽。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="申命记 3:9; 以赛亚书 14:8; 雅歌 4:8"> <span className="pl pl-1">他们用示尼珥的松树做你的一切板，</span><br /><span className="pl pl-1">用黎巴嫩的香柏树做桅杆，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="创世记 10:4; 以赛亚书 2:13; 撒迦利亚书 11:2"> <span className="pl pl-1">用巴珊的橡树做你的桨，</span><br /><span className="pl pl-1">用象牙镶嵌基提海岛的黄杨木为坐板</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：舱板">a</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 10:9; 出埃及记 25:4; 创世记 10:4"> <span className="pl pl-1">你的篷帆是用埃及绣花细麻布做的，</span><br /><span className="pl pl-1">可以做你的大旗；</span><br /><span className="pl pl-1">你的凉棚是用以利沙岛的蓝色、紫色布做的。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="创世记 10:18; 列王纪上 9:27; 以西结书 27:11"> <span className="pl pl-1">西顿和亚发的居民作你荡桨的。</span><br /><span className="pl pl-1">泰尔啊，你中间的智慧人作掌舵的。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 5:18; 约书亚记 13:5; 诗篇 83:7"> <span className="pl pl-1">迦巴勒的老者和聪明人</span><br /><span className="pl pl-1">都在你中间作补缝的；</span><br /><span className="pl pl-1">一切泛海的船只和水手</span><br /><span className="pl pl-1">都在你中间经营交易的事。</span></span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 38:5; 以西结书 30:5; 以赛亚书 66:19"> 「波斯人、路德人、弗人在你军营中作战士；他们在你中间悬挂盾牌和头盔，彰显你的尊荣。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 27:3–4"> 亚发人和你的军队都在你四围的墙上，你的望楼也有勇士；他们悬挂盾牌，成全你的美丽。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 10:4; 以赛亚书 23:10; 以西结书 38:13"> 「他施人因你多有各类的财物，就作你的客商，拿银、铁、锡、铅兑换你的货物。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 10:2; 以赛亚书 66:19; 以西结书 39:1"> 雅完人、土巴人、米设人都与你交易；他们用人口和铜器兑换你的货物。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 10:3; 以西结书 38:6; 历代志上 1:6"> 陀迦玛族用马和战马并骡子兑换你的货物。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 10:7; 启示录 18:12; 列王纪上 10:22"> 底但人与你交易，许多海岛作你的码头；他们拿象牙、乌木与你兑换<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：进贡">b</a></sup>。</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 10:6; 以西结书 28:13; 撒母耳记下 10:6"> 亚兰人因你的工作很多，就作你的客商；他们用绿宝石、紫色布绣货、细麻布、珊瑚、红宝石兑换你的货物。</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 11:33; 列王纪上 5:9; 耶利米书 8:22"> 犹大和以色列地的人都与你交易；他们用米匿的麦子、饼、蜜、油、乳香兑换你的货物。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 7:8; 创世记 15:2; 以西结书 47:16–18"> 大马士革人因你的工作很多，又因你多有各类的财物，就拿黑本酒和白羊毛与你交易。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 30:23–24; 诗篇 45:8; 雅歌 4:13–14"> 威但人和雅完人拿纺成的线、亮铁、桂皮、菖蒲兑换你的货物。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 25:3; 以西结书 27:15"> 底但人用高贵的毯子、鞍、屉与你交易。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 60:7; 创世记 25:13; 列王纪上 10:15"> 阿拉伯人和基达的一切首领都作你的客商，用羊羔、公绵羊、公山羊与你交易。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 10:7; 以赛亚书 60:6; 诗篇 72:10"> 示巴和拉玛的商人与你交易，他们用各类上好的香料、各类的宝石，和黄金兑换你的货物。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 19:12; 以赛亚书 37:12; 阿摩司书 1:5"> 哈兰人、干尼人、伊甸人、示巴的商人，和亚述人、基抹人与你交易。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪下 2:8"> 这些商人以美好的货物包在绣花蓝色包袱内，又有华丽的衣服装在香柏木的箱子里，用绳捆着与你交易。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 2:16; 诗篇 48:7; 以赛亚书 23:14"> <span className="pl pl-1">他施的船只接连成帮为你运货，</span><br /><span className="pl pl-1">你便在海中丰富极其荣华。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 48:7; 以西结书 26:19; 使徒行传 27:14"> <span className="pl pl-1">荡桨的已经把你荡到大水之处，</span><br /><span className="pl pl-1">东风在海中将你打破。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 11:4; 以西结书 27:24; 以西结书 27:12"> <span className="pl pl-1">你的资财、物件、货物、</span><br /><span className="pl pl-1">水手、掌舵的、</span><br /><span className="pl pl-1">补缝的、经营交易的，</span><br /><span className="pl pl-1">并你中间的战士和人民，</span><br /><span className="pl pl-1">在你破坏的日子必都沉在海中。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 26:10; 出埃及记 15:14; 以西结书 31:16"> <span className="pl pl-1">你掌舵的呼号之声一发，</span><br /><span className="pl pl-1">郊野都必震动。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 26:16; 以西结书 32:10; 启示录 18:17–24"> <span className="pl pl-1">凡荡桨的和水手，</span><br /><span className="pl pl-1">并一切泛海掌舵的，</span><br /><span className="pl pl-1">都必下船登岸。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 6:26; 撒母耳记下 1:2; 耶利米哀歌 2:10"> <span className="pl pl-1">他们必为你放声痛哭，</span><br /><span className="pl pl-1">把尘土撒在头上，</span><br /><span className="pl pl-1">在灰中打滚；</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="以西结书 7:18; 以赛亚书 22:12; 以赛亚书 15:2"> <span className="pl pl-1">又为你使头上光秃，</span><br /><span className="pl pl-1">用麻布束腰，</span><br /><span className="pl pl-1">号咷痛哭，</span><br /><span className="pl pl-1">苦苦悲哀。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="以西结书 26:17; 启示录 18:18; 以西结书 27:2"> <span className="pl pl-1">他们哀号的时候，</span><br /><span className="pl pl-1">为你作起哀歌哀哭，</span><br /><span className="pl pl-1">说：有何城如泰尔？</span><br /><span className="pl pl-1">有何城如她在海中成为寂寞的呢？</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="启示录 18:19; 以西结书 27:3; 以西结书 28:16"> <span className="pl pl-1">你由海上运出货物，</span><br /><span className="pl pl-1">就使许多国民充足；</span><br /><span className="pl pl-1">你以许多资财、货物</span><br /><span className="pl pl-1">使地上的君王丰富。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="以西结书 27:26–27; 撒迦利亚书 9:3–4; 以西结书 26:19–21"> <span className="pl pl-1">你在深水中被海浪打破的时候，</span><br /><span className="pl pl-1">你的货物和你中间的一切人民，</span><br /><span className="pl pl-1">就都沉下去了。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="以西结书 32:10; 以赛亚书 23:6; 以西结书 26:15–18"> <span className="pl pl-1">海岛的居民为你惊奇；</span><br /><span className="pl pl-1">他们的君王都甚恐慌，</span><br /><span className="pl pl-1">面带愁容。</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 18:16; 诗篇 37:10; 西番雅书 2:15"> <span className="pl pl-1">各国民中的客商都向你发嘶声；</span><br /><span className="pl pl-1">你令人惊恐，</span><br /><span className="pl pl-1">不再存留于世，直到永远。」</span></span>

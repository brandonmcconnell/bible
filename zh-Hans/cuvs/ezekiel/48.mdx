## 各支派分配土地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 47:15–17; 约书亚记 19:40–47; 启示录 7:4–8"> 众支派按名所得之地记在下面：从北头，由希特伦往哈马口，到大马士革地界上的哈萨·以难。北边靠着哈马地（各支派的地都有东西的边界），是但的一分。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 19:24–31; 创世记 30:12–13"> 挨着但的地界，从东到西，是亚设的一分。</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 19:32–39; 创世记 30:7–8"> 挨着亚设的地界，从东到西，是拿弗他利的一分。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 17:1–11; 约书亚记 13:29–31; 创世记 48:14–20"> 挨着拿弗他利的地界，从东到西，是玛拿西的一分。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 17:8–10; 约书亚记 17:14–18; 约书亚记 16:1–10"> 挨着玛拿西的地界，从东到西，是以法莲的一分。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 13:15–21; 创世记 29:32; 创世记 49:3–4"> 挨着以法莲的地界，从东到西，是吕便的一分。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 15:1–63; 约书亚记 19:9; 创世记 29:35"> 挨着吕便的地界，从东到西，是犹大的一分。</span>

## 中部特区

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西结书 45:1–6; 以赛亚书 12:6; 以赛亚书 33:20–22"> 挨着犹大的地界，从东到西，必有你们所当献的供地，宽二万五千肘。从东界到西界，长短与各分之地相同，圣地当在其中。</span>
<span className="v" id="v9" data-v="9"> 你们献与耶和华的供地要长二万五千肘，宽一万肘。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 45:4; 以西结书 44:28; 马太福音 10:10"> 这圣供地要归与祭司，北长二万五千肘，西宽一万肘，东宽一万肘，南长二万五千肘。耶和华的圣地当在其中。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 40:46; 以西结书 44:10; 马太福音 24:45–46"> 这地要归与撒督的子孙中成为圣的祭司，就是那守我所吩咐的。当以色列人走迷的时候，他们不像那些利未人走迷了。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 27:21; 以西结书 45:4"> 这要归与他们为供地，是全地中至圣的。供地挨着利未人的地界。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 45:3; 申命记 12:19; 以西结书 45:5"> 利未人所得的地要长二万五千肘，宽一万肘，与祭司的地界相等，都长二万五千肘，宽一万肘。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 27:28; 利未记 27:9–10; 出埃及记 22:29"> 这地不可卖，不可换，初熟之物也不可归与别人，因为是归耶和华为圣的。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 42:20; 以西结书 45:6; 以西结书 44:23"> 这二万五千肘前面所剩下五千肘宽之地要作俗用，作为造城盖房郊野之地。城要在当中。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 21:16"> 城的尺寸乃是如此：北面四千五百肘，南面四千五百肘，东面四千五百肘，西面四千五百肘。</span>
<span className="v" id="v17" data-v="17"> 城必有郊野，向北二百五十肘，向南二百五十肘，向东二百五十肘，向西二百五十肘。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 9:27; 以斯拉记 2:43–58; 以西结书 45:6"> 靠着圣供地的余地，东长一万肘，西长一万肘，要与圣供地相等；其中的土产要作城内工人的食物。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 45:6; 列王纪上 4:7–23; 尼希米记 11:1–36"> 所有以色列支派中，在城内做工的，都要耕种这地。</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 21:16; 希伯来书 12:17"> 你们所献的圣供地连归城之地，是四方的：长二万五千肘，宽二万五千肘。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 48:22; 以西结书 37:24; 以西结书 48:8"> 圣供地连归城之地，两边的余地要归与王。供地东边，南北二万五千肘，东至东界，西边南北二万五千肘，西至西界，与各分之地相同，都要归王。圣供地和殿的圣地要在其中，</span>
<span className="v" id="v22" data-v="22"> 并且利未人之地，与归城之地的东西两边延长之地（这两地在王地中间），就是在犹大和便雅悯两界中间，要归与王。</span>
</div>
</div>

## 其他支派的土地

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约书亚记 18:21–28; 以西结书 48:1–7; 创世记 35:16–19"> 论到其余的支派，从东到西，是便雅悯的一分。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 19:1–9; 创世记 29:33; 创世记 49:5–7"> 挨着便雅悯的地界，从东到西，是西缅的一分。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 19:17–23; 创世记 30:14–18"> 挨着西缅的地界，从东到西，是以萨迦的一分。</span>
<span className="v" id="v26" data-v="26" data-xref="约书亚记 19:10–16; 创世记 30:19–20"> 挨着以萨迦的地界，从东到西，是西布伦的一分。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 13:24–28; 创世记 30:10–11"> 挨着西布伦的地界，从东到西，是迦得的一分。</span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 47:15; 历代志下 20:2; 以西结书 47:19–20"> 迦得地的南界是从他玛到米利巴·加低斯的水，延到埃及小河，直到大海。</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 13:1–21; 民数记 34:2; 民数记 34:13"> 这就是你们要拈阄分给以色列支派为业之地，乃是他们各支派所得之分。这是主耶和华说的。</span>
</div>
</div>

## 耶路撒冷的城门

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="以西结书 48:16; 启示录 21:16; 以西结书 48:32–35"> 城的北面四千五百肘。出城之处如下；</span>
<span className="v" id="v31" data-v="31" data-xref="启示录 21:12–13; 以赛亚书 26:1–2; 启示录 21:21"> 城的各门要按以色列支派的名字。北面有三门，一为吕便门，一为犹大门，一为利未门；</span>
<span className="v" id="v32" data-v="32"> 东面四千五百肘，有三门，一为约瑟门，一为便雅悯门，一为但门；</span>
<span className="v" id="v33" data-v="33"> 南面四千五百肘，有三门，一为西缅门，一为以萨迦门，一为西布伦门；</span>
<span className="v" id="v34" data-v="34"> 西面四千五百肘，有三门，一为迦得门，一为亚设门，一为拿弗他利门。</span>
<span className="v" id="v35" data-v="35" data-xref="启示录 21:3; 撒迦利亚书 2:10; 启示录 22:3"> 城四围共一万八千肘。从此以后，这城的名字必称为「耶和华的所在」。</span>
</div>
</div>

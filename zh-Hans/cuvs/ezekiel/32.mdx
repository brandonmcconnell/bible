## 以鳄鱼比拟埃及王

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西结书 30:20; 以西结书 32:17; 以西结书 31:1"> 十二年十二月初一日，耶和华的话临到我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 29:3; 那鸿书 2:11–13; 以西结书 27:2"> 「人子啊，你要为埃及王法老作哀歌，说：<br /><span className="pl pl-1">从前你在列国中，如同少壮狮子；</span><br /><span className="pl pl-1">现在你却像海中的大鱼。</span><br /><span className="pl pl-1">你冲出江河，</span><br /><span className="pl pl-1">用爪搅动诸水，</span><br /><span className="pl pl-1">使江河浑浊。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 12:13; 耶利米书 16:16; 传道书 9:12"> <span className="pl pl-1">主耶和华如此说：</span><br /><span className="pl pl-1">我必用多国的人民，</span><br /><span className="pl pl-1">将我的网撒在你身上，</span><br /><span className="pl pl-1">把你拉上来。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 18:6; 以西结书 29:5; 以西结书 31:12–13"> <span className="pl pl-1">我必将你丢在地上，</span><br /><span className="pl pl-1">抛在田野，</span><br /><span className="pl pl-1">使空中的飞鸟都落在你身上，</span><br /><span className="pl pl-1">使遍地的野兽吃你得饱。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 31:12"> <span className="pl pl-1">我必将你的肉丢在山间，</span><br /><span className="pl pl-1">用你高大的尸首填满山谷。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 34:3; 以赛亚书 34:7; 启示录 14:20"> <span className="pl pl-1">我又必用你的血浇灌你所游泳之地，</span><br /><span className="pl pl-1">漫过山顶；</span><br /><span className="pl pl-1">河道都必充满。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 24:29; 约珥书 2:31; 以赛亚书 13:10"> <span className="pl pl-1">我将你扑灭的时候，</span><br /><span className="pl pl-1">要把天遮蔽，</span><br /><span className="pl pl-1">使众星昏暗，</span><br /><span className="pl pl-1">以密云遮掩太阳，</span><br /><span className="pl pl-1">月亮也不放光。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="创世记 1:14; 箴言 20:20"> <span className="pl pl-1">我必使天上的亮光都在你以上变为昏暗，</span><br /><span className="pl pl-1">使你的地上黑暗。</span><br /><span className="pl pl-1">这是主耶和华说的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="启示录 18:10–15; 以西结书 30:26; 耶利米书 25:15–25"> 「我使你败亡的风声传到你所不认识的各国。那时，我必使多民的心因你愁烦。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 26:16; 以西结书 27:35; 列王纪上 9:8"> 我在许多国民和君王面前向你抡我的刀，国民就必因你惊奇，君王也必因你极其恐慌。在你仆倒的日子，他们各人为自己的性命时刻战兢。」</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 43:10; 以西结书 26:7; 以西结书 30:22–25"> 主耶和华如此说：「巴比伦王的刀必临到你。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 28:7; 以西结书 29:19; 以西结书 31:11"> 我必借勇士的刀使你的众民仆倒；这勇士都是列国中强暴的。<br /><span className="pl pl-1">他们必使埃及的骄傲归于无有；</span><br /><span className="pl pl-1">埃及的众民必被灭绝。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 29:11; 以西结书 29:8; 以西结书 30:12"> <span className="pl pl-1">我必从埃及多水旁除灭所有的走兽；</span><br /><span className="pl pl-1">人脚兽蹄必不再搅浑这水。</span><br /></span>
<span className="v" id="v14" data-v="14"> <span className="pl pl-1">那时，我必使埃及河澄清，</span><br /><span className="pl pl-1">江河像油缓流。</span><br /><span className="pl pl-1">这是主耶和华说的。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 6:7; 出埃及记 7:5; 出埃及记 14:4"> <span className="pl pl-1">我使埃及地变为荒废凄凉；</span><br /><span className="pl pl-1">这地缺少从前所充满的，</span><br /><span className="pl pl-1">又击杀其中一切的居民。</span><br /><span className="pl pl-1">那时，他们就知道我是耶和华。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 1:17; 历代志下 35:25; 以西结书 26:17"> 「人必用这哀歌去哀哭，列国的女子为埃及和她的群众也必以此悲哀。这是主耶和华说的。」</span>
</div>
</div>

## 为埃及哀号

<div className="bt">
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="以西结书 32:1; 以西结书 33:21; 以西结书 1:2"> 十二年十二月十五日，耶和华的话临到我说：</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 31:14; 以西结书 32:2; 耶利米书 1:10"> 「人子啊，你要为埃及群众哀号，又要将埃及和有名之国的女子，并下坑的人，一同扔到阴府去。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 31:18; 以西结书 32:29–30; 耶利米书 9:25–26"> <span className="pl pl-1">你埃及的美丽胜过谁呢？</span><br /><span className="pl pl-1">你下去与未受割礼的人一同躺卧吧！</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="诗篇 28:3; 以西结书 32:23–26; 以西结书 32:29–30"> 他们必在被杀的人中仆到。她被交给刀剑，要把她和她的群众拉去。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 14:9–10; 以西结书 32:27; 以西结书 32:19"> 强盛的勇士要在阴间对埃及王和帮助他的说话；他们是未受割礼被杀的人，已经下去，躺卧不动。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以西结书 32:26; 以西结书 32:29–30; 以西结书 32:24"> 「亚述和她的众民都在那里，她民的坟墓在她四围；他们都是被杀倒在刀下的。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 26:20; 以西结书 32:24–27; 诗篇 27:13"> 他们的坟墓在坑中极深之处。她的众民在她坟墓的四围，都是被杀倒在刀下的；他们曾在活人之地使人惊恐。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以西结书 32:18; 以西结书 26:20; 耶利米书 49:34–39"> 「以拦也在那里，她的群众在她坟墓的四围，都是被杀倒在刀下、未受割礼而下阴府的；他们曾在活人之地使人惊恐，并且与下坑的人一同担当羞辱。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 139:8; 历代志上 10:4; 撒母耳记下 1:20"> 人给她和她的群众在被杀的人中设立床榻。她民的坟墓在她四围，他们都是未受割礼被刀杀的；他们曾在活人之地使人惊恐，并且与下坑的人一同担当羞辱。以拦已经放在被杀的人中。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以西结书 27:13; 创世记 10:2; 以西结书 38:2–3"> 「米设、土巴，和她们的群众都在那里。她民的坟墓在她四围，他们都是未受割礼被刀杀的；他们曾在活人之地使人惊恐。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 14:18–19; 约伯记 3:13–15; 以西结书 32:21"> 他们不得与那未受割礼仆倒的勇士一同躺卧；这些勇士带着兵器下阴间，头枕刀剑，骨头上有本身的罪孽；他们曾在活人之地使勇士惊恐。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="但以理书 2:34–35"> 「法老啊，你必在未受割礼的人中败坏，与那些被杀的人一同躺卧。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="耶利米书 49:7–22; 玛拉基书 1:3–4; 俄巴底亚书 1:1–9"> 「以东也在那里。她君王和一切首领虽然仗着势力，还是放在被杀的人中；他们必与未受割礼的和下坑的人一同躺卧。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="以西结书 38:6; 以西结书 39:2; 以西结书 28:21"> 「在那里有北方的众王子和一切西顿人，都与被杀的人下去。他们虽然仗着势力使人惊恐，还是蒙羞。他们未受割礼，和被刀杀的一同躺卧，与下坑的人一同担当羞辱。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="以西结书 31:16; 以西结书 14:22; 耶利米哀歌 2:13"> 「法老看见他们，便为他被杀的军队受安慰。这是主耶和华说的。</span>
<span className="v" id="v32" data-v="32" data-xref="以西结书 32:27; 创世记 35:5; 哥林多后书 5:11"> 我任凭法老在活人之地使人惊恐，法老和他的群众必放在未受割礼和被杀的人中。这是主耶和华说的。」</span>
</div>
</div>

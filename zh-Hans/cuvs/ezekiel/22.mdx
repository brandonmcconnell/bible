## 耶路撒冷的过犯

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话又临到我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 58:1; 以西结书 24:6; 以西结书 24:9"> 「人子啊，你要审问审问这流人血的城吗？当使她知道她一切可憎的事。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 22:27; 罗马书 2:5; 彼得后书 2:3"> 你要说，主耶和华如此说：哎！这城有流人血的事在其中，叫她受报的日期来到，又做偶像玷污自己，陷害自己。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 21:16; 诗篇 44:13–14; 以西结书 22:2"> 你因流了人的血，就为有罪；你做了偶像，就玷污自己，使你受报之日临近，报应之年来到。所以我叫你受列国的凌辱和列邦的讥诮。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 22:2; 耶利米书 15:2–3"> 你这名臭、多乱的城啊，那些离你近、离你远的都必讥诮你。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结书 22:27; 以赛亚书 1:23; 撒迦利亚书 3:3"> 「看哪，以色列的首领各逞其能，在你中间流人之血。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 27:16; 出埃及记 22:21–22; 利未记 20:9"> 在你中间有轻慢父母的，有欺压寄居的，有亏负孤儿寡妇的。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 23:38–39; 以西结书 22:26; 以西结书 20:13"> 你藐视了我的圣物，干犯了我的安息日。</span>
<span className="v" id="v9" data-v="9" data-xref="何西阿书 4:14; 利未记 19:16; 何西阿书 4:10"> 在你中间有谗谤人、流人血的；有在山上吃过祭偶像之物的，有行淫乱的。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 18:19; 利未记 18:7–8; 以西结书 18:6"> 在你中间有露继母下体羞辱父亲的，有玷辱月经不洁净之妇人的。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 18:15; 撒母耳记下 13:14; 利未记 20:17"> 这人与邻舍的妻行可憎的事；那人贪淫玷污儿妇；还有玷辱同父之姊妹的。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 27:25; 以西结书 23:35; 诗篇 106:21"> 在你中间有为流人血受贿赂的；有向借钱的弟兄取利，向借粮的弟兄多要的。且因贪得无厌，欺压邻舍夺取财物，竟忘了我。这是主耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以西结书 21:17; 以赛亚书 33:15; 阿摩司书 2:6–8"> 「看哪，我因你所得不义之财和你中间所流的血，就拍掌叹息。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 21:7; 以西结书 17:24; 以西结书 24:14"> 到了我惩罚你的日子，你的心还能忍受吗？你的手还能有力吗？我—耶和华说了这话，就必照着行。</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米记 1:8; 以西结书 22:22; 申命记 4:27"> 我必将你分散在列国，四散在列邦。我也必从你中间除掉你的污秽。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 6:7; 诗篇 83:18; 以西结书 7:24"> 你必在列国人的眼前因自己所行的被亵渎，你就知道我是耶和华。」</span>
</div>
</div>

## 神的大炼炉

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和华的话临到我说：</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 119:119; 以赛亚书 1:22; 耶利米书 6:28–30"> 「人子啊，以色列家在我看为渣滓。他们都是炉中的铜、锡、铁、铅，都是银渣滓。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 13:30; 以西结书 24:3–6; 弥迦书 4:12"> 所以主耶和华如此说：因你们都成为渣滓，我必聚集你们在耶路撒冷中。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 4:11–12; 以赛亚书 54:16; 以西结书 24:13"> 人怎样将银、铜、铁、铅、锡聚在炉中，吹火熔化；照样，我也要发怒气和忿怒，将你们聚集放在城中，熔化你们。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 64:7; 那鸿书 1:6; 诗篇 50:3"> 我必聚集你们，把我烈怒的火吹在你们身上，你们就在其中熔化。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 20:8; 以西结书 20:33; 何西阿书 5:10"> 银子怎样熔化在炉中，你们也必照样熔化在城中，你们就知道我—耶和华是将忿怒倒在你们身上了。」</span>
</div>
</div>

## 以色列领袖们的罪恶

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和华的话临到我说：</span>
<span className="v" id="v24" data-v="24" data-xref="历代志下 36:14–16; 耶利米书 2:30; 历代志下 28:22"> 「人子啊，你要对这地说：你是未得洁净之地，在恼恨的日子也没有雨下在你以上。</span>
<span className="v" id="v25" data-v="25" data-xref="何西阿书 6:9; 耶利米书 2:34; 以西结书 13:19"> 其中的先知同谋背叛，如咆哮的狮子抓撕掠物。他们吞灭人民，抢夺财宝，使这地多有寡妇。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 10:10; 以西结书 44:23; 以西结书 22:8"> 其中的祭司强解我的律法，亵渎我的圣物，不分别圣的和俗的，也不使人分辨洁净的和不洁净的，又遮眼不顾我的安息日；我也在他们中间被亵慢。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 22:13; 以赛亚书 1:23; 以西结书 22:6"> 其中的首领仿佛豺狼抓撕掠物，杀人流血，伤害人命，要得不义之财。</span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 13:6–7; 以西结书 13:10–16; 耶利米书 23:25–32"> 其中的先知为百姓用未泡透的灰抹墙，就是为他们见虚假的异象，用谎诈的占卜，说：『主耶和华如此说』，其实耶和华没有说。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 22:7; 出埃及记 23:9; 出埃及记 22:21"> 国内众民一味地欺压，惯行抢夺，亏负困苦穷乏的，背理欺压寄居的。</span>
<span className="v" id="v30" data-v="30" data-xref="以赛亚书 59:16; 耶利米书 5:1; 诗篇 106:23"> 我在他们中间寻找一人重修墙垣，在我面前为这国站在破口防堵，使我不灭绝这国，却找不着一个。</span>
<span className="v" id="v31" data-v="31" data-xref="以西结书 16:43; 以西结书 7:8–9; 以西结书 9:10"> 所以我将恼恨倒在他们身上，用烈怒的火灭了他们，照他们所行的报应在他们头上。这是主耶和华说的。」</span>
</div>
</div>

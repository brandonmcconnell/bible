## 斥责埃及

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西结书 29:17; 以西结书 26:1; 以西结书 20:1"> 第十年十月十二日，耶和华的话临到我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 6:2; 耶利米书 44:30; 耶利米书 46:2–16"> 「人子啊，你要向埃及王法老预言攻击他和埃及全地，</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 32:2; 以赛亚书 27:1; 耶利米书 44:30"> 说主耶和华如此说：<br /><span className="pl pl-1">埃及王法老啊，</span><br /><span className="pl pl-1">我与你这卧在自己河中的大鱼为敌。</span><br /><span className="pl pl-1">你曾说：这河是我的，</span><br /><span className="pl pl-1">是我为自己造的。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 19:28; 以西结书 38:4; 阿摩司书 4:2"> <span className="pl pl-1">我—耶和华必用钩子钩住你的腮颊，</span><br /><span className="pl pl-1">又使江河中的鱼贴住你的鳞甲；</span><br /><span className="pl pl-1">我必将你和所有贴住你鳞甲的鱼，</span><br /><span className="pl pl-1">从江河中拉上来，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 34:20; 以西结书 32:4–6; 耶利米书 8:2"> <span className="pl pl-1">把你并江河中的鱼都抛在旷野；</span><br /><span className="pl pl-1">你必倒在田间，</span><br /><span className="pl pl-1">不被收殓，不被掩埋。</span><br /><span className="pl pl-1">我已将你给地上野兽、空中飞鸟作食物。</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王纪下 18:21; 以赛亚书 36:6; 出埃及记 9:14"> 「埃及一切的居民，因向以色列家成了芦苇的杖，就知道我是耶和华。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 36:6; 以西结书 17:15–17; 耶利米书 17:5–6"> 他们用手持住你，你就断折，伤了他们的肩；他们倚靠你，你就断折，闪了他们的腰。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 14:17; 以西结书 30:10; 以西结书 29:19–20"> 所以主耶和华如此说：我必使刀剑临到你，从你中间将人与牲畜剪除。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 29:3; 箴言 16:18; 以西结书 29:10–12"> 埃及地必荒废凄凉，他们就知道我是耶和华。<br />「因为法老说：『这河是我的，是我所造的』，</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 30:12; 以西结书 30:6–9; 出埃及记 14:2"> 所以我必与你并你的江河为敌，使埃及地，从色弗尼塔直到古实境界，全然荒废凄凉。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 32:13; 耶利米书 43:11–12; 以西结书 30:10–13"> 人的脚、兽的蹄都不经过，四十年之久并无人居住。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 46:19; 以西结书 30:7; 以西结书 30:23"> 我必使埃及地在荒凉的国中成为荒凉，使埃及城在荒废的城中变为荒废，共有四十年。我必将埃及人分散在列国，四散在列邦。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="耶利米书 46:26; 以赛亚书 19:22"> 主耶和华如此说：「满了四十年，我必招聚分散在各国民中的埃及人。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 30:14; 以赛亚书 11:11; 耶利米书 44:1"> 我必叫埃及被掳的人回来，使他们归回本地巴忒罗。在那里必成为低微的国，</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 10:11; 以西结书 30:13; 以西结书 17:14"> 必为列国中最低微的，也不再自高于列国之上。我必减少他们，以致不再辖制列国。</span>
<span className="v" id="v16" data-v="16" data-xref="何西阿书 8:13; 以赛亚书 20:5; 以西结书 29:6–7"> 埃及必不再作以色列家所倚靠的；以色列家仰望埃及人的时候，便思念罪孽。他们就知道我是主耶和华。」</span>
</div>
</div>

## 尼布甲尼撒要征服埃及

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西结书 29:1; 以西结书 1:2; 以西结书 24:1"> 二十七年正月初一日，耶和华的话临到我说：</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 27:6; 耶利米书 25:9; 以西结书 26:7–12"> 「人子啊，巴比伦王尼布甲尼撒使他的军兵大大效劳，攻打泰尔，以致头都光秃，肩都磨破；然而他和他的军兵攻打泰尔，并没有从那里得什么酬劳。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 30:24–25; 耶利米书 43:10–13; 以西结书 32:11"> 所以主耶和华如此说：我必将埃及地赐给巴比伦王尼布甲尼撒；他必掳掠埃及群众，抢其中的财为掳物，夺其中的货为掠物，这就可以作他军兵的酬劳。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 25:9; 以赛亚书 10:6–7; 以赛亚书 45:1–3"> 我将埃及地赐给他，酬他所效的劳，因王与军兵是为我勤劳。这是主耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 2:10; 路加福音 21:15; 诗篇 132:17"> 「当那日，我必使以色列家的角发生，又必使你—以西结在他们中间得以开口；他们就知道我是耶和华。」</span>
</div>

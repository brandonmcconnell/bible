## 归给耶和华的土地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 48:29; 撒迦利亚书 14:20–21; 民数记 34:13"> 你们拈阄分地为业，要献上一分给耶和华为圣供地，长二万五千肘，宽一万肘。这分以内，四围都为圣地。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 42:16–20; 以西结书 27:28"> 其中有作为圣所之地，长五百肘，宽五百肘，四面见方。四围再有五十肘为郊野之地。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 48:10"> 要以肘为度量地，长二万五千肘，宽一万肘。其中有圣所，是至圣的。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 43:19; 民数记 16:5; 以西结书 40:45"> 这是全地的一分圣地，要归与供圣所职事的祭司，就是亲近事奉耶和华的，作为他们房屋之地与圣所之圣地。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 48:13; 尼希米记 10:38–39; 以西结书 48:20"> 又有一分，长二万五千肘，宽一万肘，要归与在殿中供职的利未人，作为二十间房屋之业。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结书 48:15–18; 以西结书 48:30–35"> 也要分定属城的地业，宽五千肘，长二万五千肘，挨着那分圣供地，要归以色列全家。</span>
</div>
</div>

## 君王的土地

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以西结书 48:21; 以西结书 34:24; 以西结书 46:16–18"> 归王之地要在圣供地和属城之地的两旁，就是圣供地和属城之地的旁边，西至西头，东至东头，从西到东，其长与每支派的分一样。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 11:3–5; 以西结书 46:18; 以西结书 22:27"> 这地在以色列中必归王为业。我所立的王必不再欺压我的民，却要按支派将地分给以色列家。</span>
</div>
</div>

## 君王应守的规例

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒迦利亚书 8:16; 耶利米书 22:3; 以西结书 44:6"> 主耶和华如此说：「以色列的王啊，你们应当知足，要除掉强暴和抢夺的事，施行公平和公义，不再勒索我的民。这是主耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="弥迦书 6:10–11; 阿摩司书 8:4–6; 箴言 16:11"> 「你们要用公道天平、公道伊法、公道罢特。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 5:10"> 伊法与罢特大小要一样。罢特可盛贺梅珥十分之一，伊法也可盛贺梅珥十分之一，都以贺梅珥的大小为准。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 30:13; 民数记 3:47; 利未记 27:25"> 舍客勒是二十季拉；二十舍客勒，二十五舍客勒，十五舍客勒，为你们的弥那。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 「你们当献的供物乃是这样：一贺梅珥麦子要献伊法六分之一；一贺梅珥大麦要献伊法六分之一。</span>
<span className="v" id="v14" data-v="14"> 你们献所分定的油，按油的罢特，一柯珥油要献罢特十分之一（原来十罢特就是一贺梅珥）。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 1:4; 利未记 6:30; 歌罗西书 1:21"> 从以色列滋润的草场上每二百羊中，要献一只羊羔。这都可作素祭、燔祭、平安祭，为民赎罪。这是主耶和华说的。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 30:14–15; 以赛亚书 16:1"> 此地的民都要奉上这供物给以色列中的王。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 46:4–12; 历代志下 31:3; 以赛亚书 66:23"> 王的本分是在节期、月朔、安息日，就是以色列家一切的节期，奉上燔祭、素祭、奠祭。他要预备赎罪祭、素祭、燔祭，和平安祭，为以色列家赎罪。」</span>
</div>
</div>

## 节期

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未记 16:16; 出埃及记 12:2; 以西结书 43:22"> 主耶和华如此说：「正月初一日，你要取无残疾的公牛犊，洁净圣所。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 43:20; 以西结书 43:14; 利未记 16:18–20"> 祭司要取些赎罪祭牲的血，抹在殿的门柱上和坛磴台的四角上，并内院的门框上。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 19:12; 利未记 4:27–35; 以西结书 45:15"> 本月初七日<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="七十士译本是七月初一日">a</a></sup>也要为误犯罪的和愚蒙犯罪的如此行，为殿赎罪。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="利未记 23:5–8; 哥林多前书 5:7–8; 民数记 9:2–14"> 「正月十四日，你们要守逾越节，守节七日，要吃无酵饼。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 4:14; 哥林多后书 5:21; 马太福音 20:28"> 当日，王要为自己和国内的众民预备一只公牛作赎罪祭。</span>
<span className="v" id="v23" data-v="23" data-xref="约伯记 42:8; 利未记 23:8; 民数记 23:1–2"> 这节的七日，每日他要为耶和华预备无残疾的公牛七只、公绵羊七只为燔祭。每日又要预备公山羊一只为赎罪祭。</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 46:5–7; 民数记 28:12–15"> 他也要预备素祭，就是为一只公牛同献一伊法细面，为一只公绵羊同献一伊法细面，每一伊法细面加油一欣。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 23:33–43; 民数记 29:12–38; 历代志下 5:3"> 七月十五日守节的时候，七日他都要如此行，照逾越节的赎罪祭、燔祭、素祭，和油的条例一样。」</span>
</div>
</div>

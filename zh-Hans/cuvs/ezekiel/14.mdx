## 神斥责拜偶像的罪

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 8:1; 以西结书 20:1; 列王纪下 6:32"> 有几个以色列长老到我这里来，坐在我面前。</span>
<span className="v" id="v2" data-v="2" data-xref="阿摩司书 3:7; 列王纪上 14:4"> 耶和华的话就临到我说：</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 14:7; 以西结书 7:19; 以西结书 20:3"> 「人子啊，这些人已将他们的假神接到心里，把陷于罪的绊脚石放在面前，我岂能丝毫被他们求问吗？</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 66:4; 以西结书 14:7; 以赛亚书 3:11"> 所以你要告诉他们：『主耶和华如此说：以色列家的人中，凡将他的假神接到心里，把陷于罪的绊脚石放在面前，又就了先知来的，我—耶和华在他所求的事上，必按他众多的假神回答他<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：必按他拜许多假神的罪报应他">a</a></sup>，</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 1:4; 撒迦利亚书 11:8; 罗马书 1:28"> 好在以色列家的心事上捉住他们，因为他们都借着假神与我生疏。』</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以西结书 18:30; 以赛亚书 30:22; 以西结书 36:31–32"> 「所以你要告诉以色列家说：『主耶和华如此说：回头吧！离开你们的偶像，转脸莫从你们一切可憎的事。』</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 12:48; 以赛亚书 58:1–2; 利未记 24:22"> 因为以色列家的人，或在以色列中寄居的外人，凡与我隔绝，将他的假神接到心里，把陷于罪的绊脚石放在面前，又就了先知来要为自己的事求问我的，我—耶和华必亲自回答他。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 15:7; 耶利米书 44:11; 以西结书 5:15"> 我必向那人变脸，使他作了警戒，笑谈，令人惊骇，并且我要将他从我民中剪除；你们就知道我是耶和华。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 20:25; 耶利米书 4:10; 诗篇 81:11–12"> 先知若被迷惑说一句预言，是我—耶和华任那先知受迷惑，我也必向他伸手，将他从我民以色列中除灭。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 23:49; 以西结书 14:4; 耶利米书 8:11–12"> 他们必担当自己的罪孽。先知的罪孽和求问之人的罪孽都是一样，</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 37:23; 以西结书 44:10; 启示录 21:7"> 好使以色列家不再走迷离开我，不再因各样的罪过玷污自己，只要作我的子民，我作他们的 神。这是主耶和华说的。」</span>
</div>
</div>

## 挪亚、但以理、约伯

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12"> 耶和华的话临到我说：</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 26:26; 以西结书 4:16; 以赛亚书 24:20"> 「人子啊，若有一国犯罪干犯我，我也向他伸手折断他们的杖，就是断绝他们的粮，使饥荒临到那地，将人与牲畜从其中剪除；</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 14:20; 耶利米书 15:1; 以西结书 28:3"> 其中虽有挪亚、但以理、约伯这三人，他们只能因他们的义救自己的性命。这是主耶和华说的。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 5:17; 利未记 26:22; 耶利米书 15:3"> 我若使恶兽经过糟践那地，使地荒凉，以致因这些兽，人都不得经过；</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 19:29; 雅各书 5:16; 以西结书 33:11"> 虽有这三人在其中，主耶和华说：我指着我的永生起誓，他们连儿带女都不能得救，只能自己得救，那地仍然荒凉。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 26:25; 以西结书 21:3–4; 西番雅书 1:3"> 或者我使刀剑临到那地，说：刀剑哪，要经过那地，以致我将人与牲畜从其中剪除；</span>
<span className="v" id="v18" data-v="18"> 虽有这三人在其中，主耶和华说：我指着我的永生起誓，他们连儿带女都不能得救，只能自己得救。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 38:22; 以西结书 5:12; 耶利米书 14:12"> 或者我叫瘟疫流行那地，使我灭命<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是带血">b</a></sup>的忿怒倾在其上，好将人与牲畜从其中剪除；</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 14:14; 约翰一书 2:29; 以赛亚书 3:10"> 虽有挪亚、但以理、约伯在其中，主耶和华说：我指着我的永生起誓，他们连儿带女都不能救，只能因他们的义救自己的性命。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以西结书 33:27; 以西结书 5:17; 以西结书 14:13"> 主耶和华如此说：「我将这四样大灾—就是刀剑、饥荒、恶兽、瘟疫降在耶路撒冷，将人与牲畜从其中剪除，岂不更重吗？</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 12:16; 以西结书 20:43; 希伯来书 12:6–11"> 然而其中必有剩下的人，他们连儿带女必带到你们这里来，你们看见他们所行所为的，要因我降给耶路撒冷的一切灾祸，便得了安慰。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 22:8–9; 启示录 15:4; 申命记 8:2"> 你们看见他们所行所为的，得了安慰，就知道我在耶路撒冷中所行的并非无故。这是主耶和华说的。」</span>
</div>
</div>

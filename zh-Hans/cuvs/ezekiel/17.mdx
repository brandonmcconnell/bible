## 老鹰和葡萄树的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话临到我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 20:49; 马太福音 13:35; 哥林多前书 13:12"> 「人子啊，你要向以色列家出谜语，设比喻，</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿书 8:1; 耶利米书 48:40; 以西结书 17:7"> 说主耶和华如此说：有一大鹰，翅膀大，翎毛长，羽毛丰满，彩色俱备，来到黎巴嫩，将香柏树梢拧去，</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 43:14; 以赛亚书 47:15; 启示录 18:11–19"> 就是折去香柏树尽尖的嫩枝，叼到贸易之地，放在买卖城中；</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 44:4; 申命记 8:7–9; 耶利米书 37:1"> 又将以色列地的枝子栽于肥田里，插在大水旁，如插柳树，</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 17:14; 箴言 16:18–19"> 就渐渐生长，成为蔓延矮小的葡萄树。其枝转向那鹰，其根在鹰以下，于是成了葡萄树，生出枝子，发出小枝。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 31:4; 以西结书 17:15; 列王纪下 24:20"> 「又有一大鹰，翅膀大，羽毛多。这葡萄树从栽种的畦中向这鹰弯过根来，发出枝子，好得它的浇灌。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 17:5–6"> 这树栽于肥田多水的旁边，好生枝子，结果子，成为佳美的葡萄树。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 17:10; 耶利米书 32:5; 以赛亚书 30:1–7"> 你要说，主耶和华如此说：这葡萄树岂能发旺呢？鹰岂不拔出它的根来，芟除它的果子，使它枯干，使它发的嫩叶都枯干了吗？也不用大力和多民，就拔出它的根来。</span>
<span className="v" id="v10" data-v="10" data-xref="何西阿书 13:15; 约翰福音 15:6; 马太福音 21:19"> 葡萄树虽然栽种，岂能发旺呢？一经东风，岂不全然枯干吗？必在生长的畦中枯干了。」</span>
</div>
</div>

## 解释比喻

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和华的话临到我说：</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 24:19; 以西结书 17:3; 以西结书 1:2"> 「你对那悖逆之家说：你们不知道这些事是什么意思吗？你要告诉他们说，巴比伦王曾到耶路撒冷，将其中的君王和首领带到巴比伦自己那里去。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 36:13; 列王纪下 24:15–17; 以西结书 17:5"> 从以色列的宗室中取一人与他立约，使他发誓，并将国中有势力的人掳去，</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 29:14; 申命记 28:43; 撒母耳记上 2:30"> 使国低微不能自强，惟因守盟约得以存立。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 52:3; 耶利米书 38:18; 以西结书 17:7"> 他却背叛巴比伦王，打发使者往埃及去，要他们给他马匹和多民。他岂能亨通呢？行这样事的人岂能逃脱呢？他背约岂能逃脱呢？</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 12:13; 耶利米书 52:11; 以西结书 17:18–19"> 他轻看向王所起的誓，背弃王与他所立的约。主耶和华说：我指着我的永生起誓，他定要死在立他作王、巴比伦王的京都。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 37:7; 以西结书 4:2; 以西结书 29:6–7"> 敌人筑垒造台，与他打仗的时候，为要剪除多人，法老虽领大军队和大群众，还是不能帮助他。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 29:24; 历代志下 30:8; 耶利米哀歌 5:6"> 他轻看誓言，背弃盟约，已经投降，却又做这一切的事，他必不能逃脱。」</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 5:11; 耶利米书 5:9; 耶利米书 5:2"> 所以主耶和华如此说：「我指着我的永生起誓，他既轻看指我所起的誓，背弃指我所立的约，我必要使这罪归在他头上。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 12:13; 以西结书 32:3; 耶利米书 2:35"> 我必将我的网撒在他身上，他必在我的网罗中缠住。我必带他到巴比伦，并要在那里因他干犯我的罪刑罚他。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 25:5; 列王纪下 25:11; 以西结书 12:14"> 他的一切军队，凡逃跑的，都必倒在刀下；所剩下的，也必分散四方<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="方：原文是风">a</a></sup>。你们就知道说这话的是我—耶和华。」</span>
</div>
</div>

## 神对将来的应许

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 53:2; 撒迦利亚书 6:12–13; 以赛亚书 11:1–5"> 主耶和华如此说：「我要将香柏树梢拧去栽上，就是从尽尖的嫩枝中折一嫩枝，栽于极高的山上；</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 13:32; 以西结书 31:6; 以赛亚书 2:2"> 在以色列高处的山栽上。它就生枝子，结果子，成为佳美的香柏树，各类飞鸟都必宿在其下，就是宿在枝子的荫下。</span>
<span className="v" id="v24" data-v="24" data-xref="阿摩司书 9:11; 哥林多前书 1:27–28; 以西结书 24:14"> 田野的树木都必知道我—耶和华使高树矮小，矮树高大；青树枯干，枯树发旺。我—耶和华如此说，也如此行了。」</span>
</div>

<span className="v" id="v1" data-v="1"> 耶和华的话又临到我说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 31:29–30; 耶利米哀歌 5:7; 以西结书 37:11"> 「你们在以色列地怎么用这俗语说『父亲吃了酸葡萄，儿子的牙酸倒了』呢？」</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 18:19–20; 以西结书 33:11–20; 以西结书 18:30"> 主耶和华说：「我指着我的永生起誓，你们在以色列中，必不再有用这俗语的因由。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 18:20; 罗马书 6:23; 民数记 16:22"> 看哪，世人都是属我的；为父的怎样属我，为子的也照样属我；犯罪的，他必死亡。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 33:14; 约翰一书 3:7; 箴言 21:3"> 「人若是公义，且行正直与合理的事：</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 18:15; 申命记 4:19; 以西结书 6:13"> 未曾在山上吃过祭偶像之物，未曾仰望以色列家的偶像，未曾玷污邻舍的妻，未曾在妇人的经期内亲近她，</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 18:16; 出埃及记 22:26; 以西结书 18:12"> 未曾亏负人，乃将欠债之人的当头还给他；未曾抢夺人的物件，却将食物给饥饿的人吃，将衣服给赤身的人穿；</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 22:25; 撒迦利亚书 8:16; 申命记 23:19–20"> 未曾向借钱的弟兄取利，也未曾向借粮的弟兄多要，缩手不作罪孽，在两人之间，按至理判断；</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 20:11; 哈巴谷书 2:4; 阿摩司书 5:4"> 遵行我的律例，谨守我的典章，按诚实行事—这人是公义的，必定存活。这是主耶和华说的。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 21:12; 约翰一书 3:12; 约翰福音 18:40"> 「他若生一个儿子，作强盗，是流人血的，不行以上所说之善，反行其中之恶，乃在山上吃过祭偶像之物，并玷污邻舍的妻，</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 8:17; 以西结书 8:6; 列王纪下 21:11"> 亏负困苦和穷乏的人，抢夺人的物，未曾将当头还给人，仰望偶像，并行可憎的事，</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 22:25; 利未记 20:9; 以西结书 3:18"> 向借钱的弟兄取利，向借粮的弟兄多要—这人岂能存活呢？他必不能存活。他行这一切可憎的事，必要死亡，他的罪<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是血">a</a></sup>必归到他身上。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 34:21; 箴言 23:24; 耶利米书 8:6"> 「他若生一个儿子，见父亲所犯的一切罪便惧怕<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷：思量">b</a></sup>，不照样去做；</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 18:6–7; 以西结书 18:11–13"> 未曾在山上吃过祭偶像之物，未曾仰望以色列家的偶像，未曾玷污邻舍的妻，</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 18:7; 以赛亚书 58:7–10; 约伯记 22:7"> 未曾亏负人，未曾取人的当头，未曾抢夺人的物件，却将食物给饥饿的人吃，将衣服给赤身的人穿，</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 18:8–9; 马太福音 18:27–35; 以西结书 18:13"> 缩手不害贫穷人，未曾向借钱的弟兄取利，也未曾向借粮的弟兄多要；他顺从我的典章，遵行我的律例，就不因父亲的罪孽死亡，定要存活。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 3:18; 以西结书 18:26; 以西结书 18:24"> 至于他父亲；因为欺人太甚，抢夺弟兄，在本国的民中行不善，他必因自己的罪孽死亡。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 20:5; 撒迦利亚书 1:3–6; 申命记 5:9"> 「你们还说：『儿子为何不担当父亲的罪孽呢？』儿子行正直与合理的事，谨守遵行我的一切律例，他必定存活。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 24:16; 列王纪下 14:6; 以西结书 18:4"> 惟有犯罪的，他必死亡。儿子必不担当父亲的罪孽，父亲也不担当儿子的罪孽。义人的善果必归自己，恶人的恶报也必归自己。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 18:27–28; 提多书 2:11–14; 以西结书 33:19"> 「恶人若回头离开所做的一切罪恶，谨守我一切的律例，行正直与合理的事，他必定存活，不致死亡。</span>
<span className="v" id="v22" data-v="22" data-xref="弥迦书 7:19; 以西结书 33:16; 以赛亚书 43:25"> 他所犯的一切罪过都不被记念，因所行的义，他必存活。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 33:11; 提摩太前书 2:4; 彼得后书 3:9"> 主耶和华说：恶人死亡，岂是我喜悦的吗？不是喜悦他回头离开所行的道存活吗？</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 33:18; 箴言 21:16; 约翰二书 1:8"> 义人若转离义行而作罪孽，照着恶人所行一切可憎的事而行，他岂能存活吗？他所行的一切义都不被记念；他必因所犯的罪、所行的恶死亡。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 33:17; 玛拉基书 3:13–15; 玛拉基书 2:17"> 「你们还说：『主的道不公平！』以色列家啊，你们当听，我的道岂不公平吗？你们的道岂不是不公平吗？</span>
<span className="v" id="v26" data-v="26"> 义人若转离义行而作罪孽死亡，他是因所作的罪孽死亡。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 18:21; 以赛亚书 1:18; 以赛亚书 55:7"> 再者，恶人若回头离开所行的恶，行正直与合理的事，他必将性命救活了。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 32:29; 路加福音 15:17–18; 雅各书 2:10–12"> 因为他思量，回头离开所犯的一切罪过，必定存活，不致死亡。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 18:25; 箴言 19:3; 以西结书 18:2"> 以色列家还说：『主的道不公平！』以色列家啊，我的道岂不公平吗？你们的道岂不是不公平吗？」</span>
<span className="v" id="v30" data-v="30" data-xref="以西结书 18:21; 马太福音 16:27; 马太福音 3:2"> 所以主耶和华说：「以色列家啊，我必按你们各人所行的审判你们。你们当回头离开所犯的一切罪过。这样，罪孽必不使你们败亡。</span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 51:10; 以西结书 36:26; 以西结书 11:19"> 你们要将所犯的一切罪过尽行抛弃，自做一个新心和新灵。以色列家啊，你们何必死亡呢？</span>
<span className="v" id="v32" data-v="32" data-xref="彼得后书 3:9; 以西结书 18:23; 以西结书 33:11"> 主耶和华说：我不喜悦那死人之死，所以你们当回头而存活。」</span>

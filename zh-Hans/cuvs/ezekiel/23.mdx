## 两个犯罪的姊妹

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话又临到我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 16:44–46; 耶利米书 3:7–10"> 「人子啊，有两个女子，是一母所生，</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 17:7; 以西结书 16:22; 约书亚记 24:14"> 她们在埃及行邪淫，在幼年时行邪淫。她们在那里作处女的时候，有人拥抱她们的怀，抚摸她们的乳。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 16:8; 诗篇 76:2; 耶利米书 2:2–3"> 她们的名字，姊姊名叫阿荷拉，妹妹名叫阿荷利巴。她们都归于我，生了儿女。论到她们的名字，阿荷拉就是撒马利亚，阿荷利巴就是耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="何西阿书 5:13; 列王纪下 17:3; 列王纪下 16:7"> 「阿荷拉归我之后行邪淫，贪恋所爱的人，就是她的邻邦亚述人。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 23:23"> 这些人都穿蓝衣，作省长、副省长，都骑着马，是可爱的少年人。</span>
<span className="v" id="v7" data-v="7" data-xref="何西阿书 5:3; 何西阿书 6:10; 以西结书 22:3–4"> 阿荷拉就与亚述人中最美的男子放纵淫行，她因所恋爱之人的一切偶像，玷污自己。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 23:19; 以西结书 23:3; 出埃及记 32:4"> 自从在埃及的时候，她就没有离开淫乱，因为她年幼作处女的时候，埃及人与她行淫，抚摸她的乳，纵欲与她行淫。</span>
<span className="v" id="v9" data-v="9" data-xref="何西阿书 11:5; 列王纪下 15:29; 列王纪下 17:23"> 因此，我将她交在她所爱的人手中，就是她所恋爱的亚述人手中。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 23:29; 何西阿书 2:10; 耶利米书 22:8–9"> 他们就露了她的下体，掳掠她的儿女，用刀杀了她，使她在妇女中留下臭名，因他们向她施行审判。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米书 3:8–11; 以西结书 16:47–51; 以西结书 23:4"> 「她妹妹阿荷利巴虽然看见了，却还贪恋，比她姊姊更丑；行淫乱比她姊姊更多。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 16:7–15; 以西结书 23:23; 历代志下 28:16–23"> 她贪恋邻邦的亚述人，就是穿极华美的衣服，骑着马的省长、副省长，都是可爱的少年人。</span>
<span className="v" id="v13" data-v="13" data-xref="何西阿书 12:1–2; 列王纪下 17:18–19; 以西结书 23:31"> 我看见她被玷污了，她姊妹二人同行一路。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 8:10; 耶利米书 22:14; 耶利米书 50:2"> 阿荷利巴又加增淫行，因她看见人像画在墙上，就是用丹色所画迦勒底人的像，</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 8:18; 撒母耳记上 18:4; 以赛亚书 22:21"> 腰间系着带子，头上有下垂的裹头巾，都是军长的形状，仿照巴比伦人的形象；他们的故土就是迦勒底。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 16:29; 马太福音 5:28; 约伯记 31:1"> 阿荷利巴一看见就贪恋他们，打发使者往迦勒底去见他们。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 23:28; 以西结书 23:22; 创世记 10:10"> 巴比伦人就来登她爱情的床，与她行淫玷污她。她被玷污，随后心里与他们生疏。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 78:59; 诗篇 106:40; 耶利米书 12:8"> 这样，她显露淫行，又显露下体；我心就与她生疏，像先前与她姊姊生疏一样。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 23:3; 以西结书 20:7; 以西结书 16:51"> 她还加增她的淫行，追念她幼年在埃及地行邪淫的日子，</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 17:15; 以西结书 16:26; 耶利米书 5:8"> 贪恋情人身壮精足，如驴如马。</span>
<span className="v" id="v21" data-v="21"> 这样，你就想起你幼年的淫行。那时，埃及人拥抱你的怀，抚摸你的乳。」</span>
</div>
</div>

## 神审判妹妹

<div className="bt">
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="以西结书 16:37; 启示录 17:16; 耶利米书 6:22–23"> 阿荷利巴啊，主耶和华如此说：「我必激动你先爱而后生疏的人来攻击你。我必使他们来，在你四围攻击你。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 50:21; 列王纪下 24:2; 列王纪下 20:14–17"> 所来的就是巴比伦人、迦勒底的众人、比割人、书亚人、哥亚人，同着他们的还有亚述众人，乃是作省长、副省长、作军长有名声的，都骑着马，是可爱的少年人。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 24:14; 以西结书 26:10; 以西结书 23:45"> 他们必带兵器、战车、辎重车，率领大众来攻击你。他们要拿大小盾牌，顶盔摆阵，在你四围攻击你。我要将审判的事交给他们，他们必按着自己的条例审判你。</span>
<span className="v" id="v25" data-v="25" data-xref="以西结书 23:47; 以西结书 8:1–18; 以西结书 15:6–7"> 我必以忌恨攻击你；他们必以忿怒办你。他们必割去你的鼻子和耳朵；你遗留<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：余剩；下同">a</a></sup>的人必倒在刀下。他们必掳去你的儿女；你所遗留的必被火焚烧。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 16:39; 耶利米书 13:22; 以西结书 23:29"> 他们必剥去你的衣服，夺取你华美的宝器。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 16:41; 以西结书 23:3; 以西结书 23:19"> 这样，我必使你的淫行和你从埃及地染来的淫乱止息了，使你不再仰望亚述，也不再追念埃及。</span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 23:22; 以西结书 23:17; 耶利米书 34:20"> 主耶和华如此说：我必将你交在你所恨恶的人手中，就是你心与他生疏的人手中。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 16:39; 以西结书 23:25–26; 以西结书 23:45–47"> 他们必以恨恶办你，夺取你一切劳碌得来的，留下你赤身露体。你淫乱的下体，连你的淫行，带你的淫乱，都被显露。</span>
<span className="v" id="v30" data-v="30" data-xref="以西结书 6:9; 诗篇 106:35–38; 耶利米书 2:18–20"> 人必向你行这些事；因为你随从外邦人行邪淫，被他们的偶像玷污了。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 21:13; 耶利米书 7:14–15; 以西结书 16:47–51"> 你走了你姊姊所走的路，所以我必将她的杯交在你手中。」</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 51:17; 诗篇 60:3; 以西结书 22:4–5"> <span className="pl pl-1">主耶和华如此说：</span><br /><span className="pl pl-1">你必喝你姊姊所喝的杯；</span><br /><span className="pl pl-1">那杯又深又广，盛得甚多，</span><br /><span className="pl pl-1">使你被人嗤笑讥刺。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 51:17; 耶利米书 25:27; 耶利米书 25:15–16"> <span className="pl pl-1">你必酩酊大醉，满有愁苦，</span><br /><span className="pl pl-1">喝干你姊姊撒马利亚的杯，</span><br /><span className="pl pl-1">就是令人惊骇凄凉的杯。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 75:8; 以赛亚书 51:17; 启示录 18:7"> <span className="pl pl-1">你必喝这杯，以致喝尽。</span><br /><span className="pl pl-1">杯破又啃杯片，</span><br /><span className="pl pl-1">撕裂自己的乳；</span><br /><span className="pl pl-1">因为这事我曾说过。</span><br /><span className="pl pl-1">这是主耶和华说的。</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="列王纪上 14:9; 以赛亚书 17:10; 耶利米书 32:33"> 主耶和华如此说：「因你忘记我，将我丢在背后，所以你要担当你淫行和淫乱的报应。」</span>
</div>
</div>

## 神审判两姊妹

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以西结书 22:2; 以赛亚书 58:1; 以西结书 16:2"> 耶和华又对我说：「人子啊，你要审问阿荷拉与阿荷利巴吗？当指出她们所行可憎的事。</span>
<span className="v" id="v37" data-v="37" data-xref="以西结书 16:36; 耶利米书 32:35; 耶利米书 7:31"> 她们行淫，手中有杀人的血，又与偶像行淫，并使她们为我所生的儿女经火烧给偶像。</span>
<span className="v" id="v38" data-v="38" data-xref="以西结书 20:13; 列王纪下 21:7; 以西结书 7:20"> 此外，她们还有向我所行的，就是同日玷污我的圣所，干犯我的安息日。</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪下 21:4; 以西结书 44:7; 耶利米书 23:11"> 她们杀了儿女献与偶像，当天又入我的圣所，将圣所亵渎了。她们在我殿中所行的乃是如此。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="列王纪下 9:30; 耶利米书 4:30; 以西结书 16:13–16"> 「况且你们二妇打发使者去请远方人。使者到他们那里，他们就来了。你们为他们沐浴己身，粉饰眼目，佩戴妆饰，</span>
<span className="v" id="v41" data-v="41" data-xref="以斯帖记 1:6; 耶利米书 44:17; 以赛亚书 65:11"> 坐在华美的床上，前面摆设桌案，将我的香料膏油摆在其上。</span>
<span className="v" id="v42" data-v="42" data-xref="以西结书 16:11–12; 启示录 12:3; 出埃及记 32:18–19"> 在那里有群众安逸欢乐的声音，并有粗俗的人和酒徒从旷野同来，把镯子戴在二妇的手上，把华冠戴在她们的头上。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="以西结书 23:3; 耶利米书 13:23; 以斯拉记 9:7"> 「我论这行淫衰老的妇人说：现在人还要与她行淫，她也要与人行淫。</span>
<span className="v" id="v44" data-v="44" data-xref="以西结书 23:9–13; 以西结书 23:3"> 人与阿荷拉，并阿荷利巴二淫妇苟合，好像与妓女苟合。</span>
<span className="v" id="v45" data-v="45" data-xref="何西阿书 6:5; 利未记 20:10; 以西结书 23:36–39"> 必有义人，照审判淫妇和流人血的妇人之例，审判她们；因为她们是淫妇，手中有杀人的血。」</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="以西结书 16:40; 耶利米书 15:4; 耶利米书 24:9"> 主耶和华如此说：「我必使多人来攻击她们，使她们抛来抛去，被人抢夺。</span>
<span className="v" id="v47" data-v="47" data-xref="以西结书 16:40–41; 耶利米书 39:8; 以西结书 24:21"> 这些人必用石头打死她们，用刀剑杀害她们，又杀戮她们的儿女，用火焚烧她们的房屋。</span>
<span className="v" id="v48" data-v="48" data-xref="以西结书 6:6; 以西结书 23:27; 以西结书 16:41"> 这样，我必使淫行从境内止息，好叫一切妇人都受警戒，不效法你们的淫行。</span>
<span className="v" id="v49" data-v="49" data-xref="以西结书 9:10; 以西结书 7:4; 以西结书 6:7"> 人必照着你们的淫行报应你们；你们要担当拜偶像的罪，就知道我是主耶和华。」</span>
</div>
</div>

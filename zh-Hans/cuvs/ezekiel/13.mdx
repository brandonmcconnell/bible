## 斥责假先知

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话临到我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 13:17; 耶利米书 37:19; 以西结书 22:28"> 「人子啊，你要说预言攻击以色列中说预言的先知，对那些本己心发预言的说：『你们当听耶和华的话。』」</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米哀歌 2:14; 耶利米书 23:28–32; 何西阿书 9:7"> 主耶和华如此说：「愚顽的先知有祸了，他们随从自己的心意，却一无所见。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 19:20; 弥迦书 2:11; 帖撒罗尼迦后书 2:9–10"> 以色列啊，你的先知好像荒场中的狐狸，</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 22:30; 诗篇 106:23; 以赛亚书 58:12"> 没有上去堵挡破口，也没有为以色列家重修墙垣，使他们当耶和华的日子在阵上站立得住。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 29:8; 以西结书 22:28; 耶利米书 28:15"> 这些人所见的是虚假，是谎诈的占卜。他们说是耶和华说的，其实耶和华并没有差遣他们，他们倒使人指望那话必然立定。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 13:6; 马太福音 24:23–24; 以西结书 13:2–3"> 你们岂不是见了虚假的异象吗？岂不是说了谎诈的占卜吗？你们说，这是耶和华说的，其实我没有说。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西结书 5:8; 以西结书 21:3; 以西结书 28:22"> 所以主耶和华如此说：「因你们说的是虚假，见的是谎诈，我就与你们反对。这是主耶和华说的。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 87:6; 诗篇 69:28; 以西结书 20:38"> 我的手必攻击那见虚假异象、用谎诈占卜的先知，他们必不列在我百姓的会中，不录在以色列家的册上，也不进入以色列地；你们就知道我是主耶和华。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 22:28; 以西结书 13:16; 耶利米书 6:14"> 因为他们诱惑我的百姓，说：『平安！』其实没有平安，就像有人立起墙壁，他们倒用未泡透的灰抹上。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 38:22; 以赛亚书 28:2; 那鸿书 1:7–8"> 所以你要对那些抹上未泡透灰的人说：『墙要倒塌，必有暴雨漫过。大冰雹啊，你们要降下，狂风也要吹裂这墙。』</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 3:13; 耶利米哀歌 2:14–15; 士师记 9:38"> 这墙倒塌之后，人岂不问你们说：『你们抹上未泡透的灰在哪里呢？』」</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 30:30; 启示录 16:21; 诗篇 148:8"> 所以主耶和华如此说：「我要发怒，使狂风吹裂这墙，在怒中使暴雨漫过，又发怒降下大冰雹，毁灭这墙。</span>
<span className="v" id="v14" data-v="14" data-xref="弥迦书 1:6; 耶利米书 14:15; 耶利米书 6:15"> 我要这样拆毁你们那未泡透灰所抹的墙，拆平到地，以致根基露出，墙必倒塌，你们也必在其中灭亡；你们就知道我是耶和华。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 30:13; 诗篇 62:3; 尼希米记 4:3"> 我要这样向墙和用未泡透灰抹墙的人成就我怒中所定的，并要对你们说：『墙和抹墙的人都没有了。』</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 13:10; 耶利米书 6:14; 耶利米书 8:11"> 这抹墙的就是以色列的先知，他们指着耶路撒冷说预言，为这城见了平安的异象，其实没有平安。这是主耶和华说的。」</span>
</div>
</div>

## 斥责假的女先知

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西结书 13:2; 列王纪下 22:14; 士师记 4:4"> 「人子啊，你要面向本民中、从己心发预言的女子说预言，攻击她们，</span>
<span className="v" id="v18" data-v="18" data-xref="彼得后书 2:14; 以西结书 13:20; 提摩太后书 4:3"> 说主耶和华如此说：『这些妇女有祸了！她们为众人的膀臂缝靠枕，给高矮之人做下垂的头巾，为要猎取人的性命。难道你们要猎取我百姓的性命，为利己将人救活吗？</span>
<span className="v" id="v19" data-v="19" data-xref="弥迦书 3:5; 箴言 28:21; 耶利米书 23:17"> 你们为两把大麦，为几块饼，在我民中亵渎我，对肯听谎言的民说谎，杀死不该死的人，救活不该活的人。』」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西结书 13:18; 提摩太后书 3:8–9; 以西结书 13:8–9"> 所以主耶和华如此说：「看哪，我与你们的靠枕反对，就是你们用以猎取人、使人的性命如鸟飞的。我要将靠枕从你们的膀臂上扯去，释放你们猎取如鸟飞的人。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 91:3"> 我也必撕裂你们下垂的头巾，救我百姓脱离你们的手，不再被猎取，落在你们手中。你们就知道我是耶和华。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 23:14; 耶利米书 14:13–17; 彼得后书 2:18–19"> 我不使义人伤心，你们却以谎话使他伤心，又坚固恶人的手，使他不回头离开恶道得以救活。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 13:21; 以西结书 12:24; 弥迦书 3:6"> 你们就不再见虚假的异象，也不再行占卜的事；我必救我的百姓脱离你们的手；你们就知道我是耶和华。」</span>
</div>
</div>

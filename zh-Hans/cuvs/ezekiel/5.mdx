## 以西结剃发

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 7:20; 以西结书 44:20; 利未记 21:5"> 「人子啊，你要拿一把快刀，当作剃头刀，用这刀剃你的头发和你的胡须，用天平将须发平分。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 5:12; 利未记 26:33; 以西结书 4:1–8"> 围困城的日子满了，你要将三分之一在城中用火焚烧，将三分之一在城的四围用刀砍碎，将三分之一任风吹散；我也要拔刀追赶。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 52:16; 耶利米书 40:6; 耶利米书 39:10"> 你要从其中取几根包在衣襟里，</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 4:4; 耶利米书 41:1–18; 列王纪下 25:25"> 再从这几根中取些扔在火中焚烧，从里面必有火出来烧入以色列全家。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 4:1; 申命记 4:6; 耶利米书 6:6"> 主耶和华如此说：这就是耶路撒冷。我曾将她安置在列邦之中；列国都在她的四围。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 11:10; 以西结书 16:47–48; 尼希米记 9:16–17"> 她行恶，违背我的典章，过于列国；干犯我的律例，过于四围的列邦，因为她弃掉我的典章。至于我的律例，她并没有遵行。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 2:10–11; 历代志下 33:9; 列王纪下 21:9–11"> 所以主耶和华如此说：因为你们纷争过于四围的列国，也不遵行我的律例，不谨守我的典章，并以遵从四围列国的恶规尚不满意，</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 15:7; 耶利米书 24:9; 以西结书 21:3"> 所以主耶和华如此说：看哪，我与你反对，必在列国的眼前，在你中间，施行审判；</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 24:21; 但以理书 9:12; 阿摩司书 3:2"> 并且因你一切可憎的事，我要在你中间行我所未曾行的，以后我也不再照着行。</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亚书 2:6; 申命记 28:64; 以西结书 12:14"> 在你中间父亲要吃儿子，儿子要吃父亲。我必向你施行审判，我必将你所剩下的分散四方<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="方：原文是风">a</a></sup>。」</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 7:20; 以西结书 7:9; 以西结书 11:18"> 主耶和华说：「我指着我的永生起誓，因你用一切可憎的物、可厌的事玷污了我的圣所，故此，我定要使你人数减少，我眼必不顾惜你，也不可怜你。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 5:2; 耶利米书 15:2; 耶利米书 43:10–11"> 你的民三分之一必遭瘟疫而死，在你中间必因饥荒消灭；三分之一必在你四围倒在刀下；我必将三分之一分散四方<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="方：原文是风">b</a></sup>，并要拔刀追赶他们。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 1:24; 以西结书 36:5–6; 以西结书 21:17"> 「我要这样成就怒中所定的；我向他们发的忿怒止息了，自己就得着安慰。我在他们身上成就怒中所定的那时，他们就知道我—耶和华所说的是出于热心；</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 22:4; 尼希米记 2:17; 诗篇 79:1–4"> 并且我必使你在四围的列国中，在经过的众人眼前，成了荒凉和羞辱。</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 25:17; 耶利米书 22:8–9; 列王纪上 9:7"> 这样，我必以怒气和忿怒，并烈怒的责备，向你施行审判。那时，你就在四围的列国中成为羞辱、讥刺、警戒、惊骇。这是我—耶和华说的。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 4:16; 申命记 32:23–24; 以西结书 14:13"> 那时，我要将灭人、使人饥荒的恶箭，就是射去灭人的，射在你们身上，并要加增你们的饥荒，断绝你们所倚靠的粮食；</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 38:22; 以西结书 14:21; 利未记 26:22"> 又要使饥荒和恶兽到你那里，叫你丧子，瘟疫和流血的事也必盛行在你那里；我也要使刀剑临到你。这是我—耶和华说的。」</span>

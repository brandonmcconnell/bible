## 以香柏树比拟埃及

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西结书 30:20; 耶利米书 52:5–6; 以西结书 1:2"> 十一年三月初一日，耶和华的话临到我说：</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 29:19; 以西结书 30:10; 以西结书 31:18"> 「人子啊，你要向埃及王法老和他的众人说：<br /><span className="pl pl-1">在威势上谁能与你相比呢？</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 10:33–34; 但以理书 4:10; 但以理书 4:20–23"> <span className="pl pl-1">亚述王曾如黎巴嫩中的香柏树，</span><br /><span className="pl pl-1">枝条荣美，影密如林，</span><br /><span className="pl pl-1">极其高大，树尖插入云中。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="启示录 17:15; 箴言 14:28; 以西结书 17:5"> <span className="pl pl-1">众水使它生长；</span><br /><span className="pl pl-1">深水使它长大。</span><br /><span className="pl pl-1">所栽之地有江河围流，</span><br /><span className="pl pl-1">汊出的水道延到田野诸树。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 4:11; 以西结书 17:5; 诗篇 1:3"> <span className="pl pl-1">所以它高大超过田野诸树；</span><br /><span className="pl pl-1">发旺的时候，枝子繁多，</span><br /><span className="pl pl-1">因得大水之力枝条长长。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 17:23; 马太福音 13:32; 但以理书 4:12"> <span className="pl pl-1">空中的飞鸟都在枝子上搭窝；</span><br /><span className="pl pl-1">田野的走兽都在枝条下生子；</span><br /><span className="pl pl-1">所有大国的人民都在它荫下居住。</span><br /></span>
<span className="v" id="v7" data-v="7"> <span className="pl pl-1">树大条长，成为荣美，</span><br /><span className="pl pl-1">因为根在众水之旁。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 28:13; 创世记 13:10; 以赛亚书 51:3"> <span className="pl pl-1">神园中的香柏树不能遮蔽它；</span><br /><span className="pl pl-1">松树不及它的枝子；</span><br /><span className="pl pl-1">枫树不及它的枝条；</span><br /><span className="pl pl-1">神园中的树都没有它荣美。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 28:13; 但以理书 2:37–38; 创世记 13:10"> <span className="pl pl-1">我使它的枝条蕃多，成为荣美，</span><br /><span className="pl pl-1">以致 神伊甸园中的树都嫉妒它。」</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以西结书 28:17; 但以理书 5:20; 历代志下 32:25"> 所以主耶和华如此说：「因它高大，树尖插入云中，心骄气傲，</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 32:11–12; 那鸿书 3:18; 但以理书 5:18–19"> 我就必将它交给列国中大有威势的人；他必定办它。我因它的罪恶，已经驱逐它。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 28:7; 以西结书 35:8; 以西结书 30:11"> 外邦人，就是列邦中强暴的，将它砍断弃掉。它的枝条落在山间和一切谷中，它的枝子折断，落在地的一切河旁。地上的众民已经走去，离开它的荫下。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 32:4; 以西结书 29:5; 以赛亚书 18:6"> 空中的飞鸟都要宿在这败落的树上，田野的走兽都要卧在它的枝条下，</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 63:9–10; 尼希米记 13:18; 彼得后书 2:6"> 好使水旁的诸树不因高大而自尊，也不将树尖插入云中，并且那些得水滋润、有势力的，也不得高大自立。因为它们在世人中，和下坑的人都被交与死亡，到阴府去了。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="玛拉基书 3:4; 那鸿书 2:8–10; 启示录 18:9–11"> 主耶和华如此说：「它下阴间的那日，我便使人悲哀。我为它遮盖深渊，使江河凝结，大水停流；我也使黎巴嫩为它凄惨，田野的诸树都因它发昏。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 14:15; 以赛亚书 14:8; 以西结书 26:15"> 我将它扔到阴间，与下坑的人一同下去。那时，列国听见它坠落的响声就都震动，并且伊甸的一切树—就是黎巴嫩得水滋润、最佳最美的树—都在阴府受了安慰。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 9:17; 以西结书 31:6; 以西结书 31:3"> 它们也与它同下阴间，到被杀的人那里。它们曾作它的膀臂，在列国中它的荫下居住。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 32:19; 以西结书 32:21; 以西结书 28:10"> 在这样荣耀威势上，在伊甸园诸树中，谁能与你相比呢？然而你要与伊甸的诸树一同下到阴府，在未受割礼的人中，与被杀的人一同躺卧。<br />「法老和他的群众乃是如此。这是主耶和华说的。」</span>
</div>

## 拉撒路的死

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 10:38–42; 约翰福音 12:17; 列王纪下 20:1–12"> 有一个患病的人，名叫拉撒路，住在伯大尼，就是马利亚和她姊姊马大的村庄。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 12:3; 马可福音 14:3; 马太福音 26:6–7"> 这马利亚就是那用香膏抹主，又用头发擦他脚的；患病的拉撒路是她的兄弟。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 11:5; 启示录 3:19; 提摩太后书 4:20"> 她姊妹两个就打发人去见耶稣，说：「主啊，你所爱的人病了。」</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 11:40; 约翰福音 9:3; 彼得前书 4:14"> 耶稣听见，就说：「这病不至于死，乃是为 神的荣耀，叫 神的儿子因此得荣耀。」</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 15:9–13; 约翰福音 16:27; 约翰福音 17:26"> 耶稣素来爱马大和她妹子并拉撒路。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 30:18; 以赛亚书 55:8–9; 创世记 45:1–5"> 听见拉撒路病了，就在所居之地仍住了两天。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 10:40–42; 路加福音 9:51; 使徒行传 20:22–24"> 然后对门徒说：「我们再往犹太去吧。」</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 10:31; 约翰福音 8:59; 使徒行传 21:12–13"> 门徒说：「拉比，犹太人近来要拿石头打你，你还往那里去吗？」</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 9:4; 约翰福音 12:35; 耶利米书 31:9"> 耶稣回答说：「白日不是有十二小时吗？人在白日走路，就不至跌倒，因为看见这世上的光。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 2:10–11; 箴言 4:18–19; 耶利米书 13:16"> 若在黑夜走路，就必跌倒，因为他没有光。」</span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 12:2; 约翰福音 11:13; 约翰福音 11:43–44"> 耶稣说了这话，随后对他们说：「我们的朋友拉撒路睡了，我去叫醒他。」</span>
<span className="v" id="v12" data-v="12"> 门徒说：「主啊，他若睡了，就必好了。」</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 9:24"> 耶稣这话是指着他死说的，他们却以为是说照常睡了。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 16:25; 约翰福音 16:29; 约翰福音 10:24"> 耶稣就明明地告诉他们说：「拉撒路死了。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太后书 2:10; 约翰福音 14:10–11; 以赛亚书 54:15"> 我没有在那里就欢喜，这是为你们的缘故，好叫你们相信。如今我们可以往他那里去吧。」</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 13:37; 马太福音 10:3; 约翰福音 21:2"> 多马，又称为低土马，就对那同作门徒的说：「我们也去和他同死吧。」</span>
</div>
</div>

## 复活在我，生命在我

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 11:39; 何西阿书 6:2; 使徒行传 2:27–31"> 耶稣到了，就知道拉撒路在坟墓里已经四天了。</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 14:20; 启示录 21:16; 约翰福音 6:19"> 伯大尼离耶路撒冷不远，约有六里路。</span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 2:11; 约翰福音 11:31; 帖撒罗尼迦前书 5:11"> 有好些犹太人来看马大和马利亚，要为她们的兄弟安慰她们。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:38–42; 帖撒罗尼迦前书 4:17; 马太福音 25:1"> 马大听见耶稣来了，就出去迎接他；马利亚却仍然坐在家里。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 11:32; 列王纪上 17:18; 马太福音 9:18"> 马大对耶稣说：「主啊，你若早在这里，我兄弟必不死。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 9:31; 约翰福音 11:41–42; 马太福音 28:18"> 就是现在，我也知道，你无论向 神求什么， 神也必赐给你。」</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 11:43–44"> 耶稣说：「你兄弟必然复活。」</span>
<span className="v" id="v24" data-v="24" data-xref="但以理书 12:2–3; 使徒行传 24:15; 约翰福音 5:28–29"> 马大说：「我知道在末日复活的时候，他必复活。」</span>
<span className="v" id="v25" data-v="25" data-xref="帖撒罗尼迦前书 4:14; 约翰福音 3:36; 约翰一书 5:11–12"> 耶稣对她说：「复活在我，生命也在我。信我的人虽然死了，也必复活；</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 10:28; 约翰福音 5:24; 罗马书 8:13"> 凡活着信我的人必永远不死。你信这话吗？」</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 16:16; 约翰福音 6:69; 约翰福音 6:14"> 马大说：「主啊，是的，我信你是基督，是 神的儿子，就是那要临到世界的。」</span>
</div>
</div>

## 耶稣哭了

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约翰福音 11:20; 约翰福音 13:13; 马可福音 10:49"> 马大说了这话，就回去暗暗地叫她妹子马利亚，说：「夫子来了，叫你。」</span>
<span className="v" id="v29" data-v="29" data-xref="箴言 15:23; 诗篇 27:8; 雅歌 3:1–4"> 马利亚听见了，就急忙起来，到耶稣那里去。</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 11:20"> 那时，耶稣还没有进村子，仍在马大迎接他的地方。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 11:19; 创世记 37:35; 撒母耳记下 12:16–18"> 那些同马利亚在家里安慰她的犹太人，见她急忙起来出去，就跟着她，以为她要往坟墓那里去哭。</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 11:21; 路加福音 17:16; 路加福音 5:8"> 马利亚到了耶稣那里，看见他，就俯伏在他脚前，说：「主啊，你若早在这里，我兄弟必不死。」</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 11:38; 约翰福音 12:27; 马可福音 3:5"> 耶稣看见她哭，并看见与她同来的犹太人也哭，就心里悲叹，又甚忧愁，</span>
<span className="v" id="v34" data-v="34" data-xref="马可福音 15:47; 马太福音 28:6; 约翰福音 1:39"> 便说：「你们把他安放在哪里？」他们回答说：「请主来看。」</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 19:41; 希伯来书 4:15; 约翰福音 11:33"> 耶稣哭了。</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 11:3; 约翰一书 3:1; 约翰一书 4:9–10"> 犹太人就说：「你看他爱这人是何等恳切。」</span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 9:6–7; 约翰福音 11:32; 路加福音 23:39"> 其中有人说：「他既然开了瞎子的眼睛，岂不能叫这人不死吗？」</span>
</div>
</div>

## 拉撒路复活

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="约翰福音 11:33; 路加福音 24:2; 马太福音 27:60"> 耶稣又心里悲叹，来到坟墓前；那坟墓是个洞，有一块石头挡着。</span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 11:17; 马可福音 16:3; 诗篇 49:7"> 耶稣说：「你们把石头挪开。」那死人的姊姊马大对他说：「主啊，他现在必是臭了，因为他死了已经四天了。」</span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 11:4; 约翰福音 11:23–26; 罗马书 4:17–25"> 耶稣说：「我不是对你说过，你若信，就必看见 神的荣耀吗？」</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 11:25; 约翰福音 17:1; 诗篇 123:1"> 他们就把石头挪开。耶稣举目望天，说：「父啊，我感谢你，因为你已经听我。</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 3:17; 约翰福音 17:21; 约翰一书 4:14"> 我也知道你常听我，但我说这话是为周围站着的众人，叫他们信是你差了我来。」</span>
<span className="v" id="v43" data-v="43" data-xref="列王纪下 4:33–36; 使徒行传 9:40; 使徒行传 9:34"> 说了这话，就大声呼叫说：「拉撒路出来！」</span>
<span className="v" id="v44" data-v="44" data-xref="约翰福音 5:25; 约翰福音 20:7; 约翰福音 11:25–26"> 那死人就出来了，手脚裹着布，脸上包着手巾。耶稣对他们说：「解开，叫他走！」</span>
</div>
</div>

## 杀害耶稣的阴谋

<div className="bt">
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="约翰福音 2:23; 约翰福音 11:19; 约翰福音 10:41"> 那些来看马利亚的犹太人见了耶稣所做的事，就多有信他的；</span>
<span className="v" id="v46" data-v="46" data-xref="约翰福音 9:13; 使徒行传 5:25; 约翰福音 12:37"> 但其中也有去见法利赛人的，将耶稣所做的事告诉他们。</span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 26:3; 约翰福音 12:19; 使徒行传 4:5–6"> 祭司长和法利赛人聚集公会，说：「这人行好些神迹，我们怎么办呢？</span>
<span className="v" id="v48" data-v="48" data-xref="帖撒罗尼迦前书 2:15–16; 马太福音 23:35–38; 马太福音 27:25"> 若这样由着他，人人都要信他，罗马人也要来夺我们的地土和我们的百姓。」</span>
<span className="v" id="v49" data-v="49" data-xref="马太福音 26:3; 约翰福音 11:51; 约翰福音 18:13–14"> 内中有一个人，名叫该亚法，本年作大祭司，对他们说：「你们不知道什么。</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 18:14; 路加福音 24:46; 罗马书 3:8"> 独不想一个人替百姓死，免得通国灭亡，就是你们的益处。」</span>
<span className="v" id="v51" data-v="51" data-xref="但以理书 9:26; 哥林多后书 5:21; 出埃及记 28:30"> 他这话不是出于自己，是因他本年作大祭司，所以预言耶稣将要替这一国死；</span>
<span className="v" id="v52" data-v="52" data-xref="约翰福音 10:16; 以赛亚书 49:6; 约翰一书 2:2"> 也不但替这一国死，并要将 神四散的子民都聚集归一。</span>
<span className="v" id="v53" data-v="53" data-xref="使徒行传 5:33; 使徒行传 9:23; 马可福音 14:1"> 从那日起，他们就商议要杀耶稣</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="约翰福音 7:1; 约翰福音 7:4; 历代志下 13:19"> 所以，耶稣不再显然行在犹太人中间，就离开那里往靠近旷野的地方去，到了一座城，名叫以法莲，就在那里和门徒同住。</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="历代志下 30:17–20; 希伯来书 9:13–14; 约翰福音 6:4"> 犹太人的逾越节近了，有许多人从乡下上耶路撒冷去，要在节前洁净自己。</span>
<span className="v" id="v56" data-v="56" data-xref="约翰福音 7:11; 约翰福音 11:7–8"> 他们就寻找耶稣，站在殿里彼此说：「你们的意思如何，他不来过节吗？」</span>
<span className="v" id="v57" data-v="57" data-xref="约翰福音 9:22; 约翰福音 8:59; 约翰福音 5:16–18"> 那时，祭司长和法利赛人早已吩咐说，若有人知道耶稣在哪里，就要报明，好去拿他。</span>
</div>
</div>

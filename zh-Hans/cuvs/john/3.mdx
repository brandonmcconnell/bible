## 耶稣与尼哥德慕

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 19:39; 约翰福音 7:47–50; 约翰福音 3:10"> 有一个法利赛人，名叫尼哥德慕，是犹太人的官。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 5:36; 使徒行传 10:38; 使徒行传 2:22"> 这人夜里来见耶稣，说：「拉比，我们知道你是由 神那里来作师傅的；因为你所行的神迹，若没有 神同在，无人能行。」</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 5:17; 约翰福音 3:5–6; 彼得前书 1:23–25"> 耶稣回答说：「我实实在在地告诉你，人若不重生，就不能见 神的国。」</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 2:14; 哥林多前书 1:18; 约翰福音 3:3"> 尼哥德慕说：「人已经老了，如何能重生呢？岂能再进母腹生出来吗？」</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 36:25–27; 以弗所书 5:26; 使徒行传 2:38"> 耶稣说：「我实实在在地告诉你，人若不是从水和圣灵生的，就不能进 神的国。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 5:16–21; 以西结书 36:26–27; 罗马书 8:4–9"> 从肉身生的就是肉身；从灵生的就是灵。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 3:3; 以弗所书 4:22–24; 罗马书 12:1–2"> 我说：『你们必须重生』，你不要以为希奇。</span>
<span className="v" id="v8" data-v="8" data-xref="传道书 11:4–5; 哥林多前书 2:11; 使徒行传 2:2"> 风随着意思吹，你听见风的响声，却不晓得从哪里来，往哪里去；凡从圣灵生的，也是如此。」</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 6:60; 路加福音 1:34; 以赛亚书 42:16"> 尼哥德慕问他说：「怎能有这事呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 22:29; 耶利米书 8:8–9; 以西结书 11:19"> 耶稣回答说：「你是以色列人的先生，还不明白这事吗？</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 8:38; 约翰一书 5:6–12; 约翰福音 12:49"> 我实实在在地告诉你，我们所说的是我们知道的；我们所见证的是我们见过的；你们却不领受我们的见证。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 3:1–2; 哥林多前书 2:7–9; 希伯来书 5:11"> 我对你们说地上的事，你们尚且不信，若说天上的事，如何能信呢？</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 30:4; 约翰福音 6:38; 使徒行传 2:34"> 除了从天降下、仍旧在天的人子，没有人升过天。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 21:7–9; 约翰福音 8:28; 约翰福音 12:32–34"> 摩西在旷野怎样举蛇，人子也必照样被举起来，</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 3:16; 约翰福音 6:40; 约翰福音 12:44–46"> 叫一切信他的都得永生<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：叫一切信的人在他里面得永生">a</a></sup>。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 5:8; 约翰一书 4:9–10; 约翰福音 3:15"> 「 神爱世人，甚至将他的独生子赐给他们，叫一切信他的，不致灭亡，反得永生。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰一书 4:14; 路加福音 19:10; 约翰福音 12:47–48"> 因为 神差他的儿子降世，不是要定世人的罪<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：审判世人；下同">b</a></sup>，乃是要叫世人因他得救。</span>
<span className="v" id="v18" data-v="18" data-xref="马可福音 16:16; 约翰一书 5:10; 罗马书 8:1"> 信他的人，不被定罪；不信的人，罪已经定了，因为他不信 神独生子的名。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 8:12; 帖撒罗尼迦后书 2:12; 约翰福音 9:39–41"> 光来到世间，世人因自己的行为是恶的，不爱光，倒爱黑暗，定他们的罪就是在此。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 5:11–13; 约翰福音 7:7; 约伯记 24:13–17"> 凡作恶的便恨光，并不来就光，恐怕他的行为受责备。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 1:6; 诗篇 139:23–24; 约翰三书 1:11"> 但行真理的必来就光，要显明他所行的是靠 神而行。」</span>
</div>
</div>

## 耶稣和施洗约翰

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约翰福音 4:1–3; 约翰福音 3:26; 约翰福音 2:13"> 这事以后，耶稣和门徒到了犹太地，在那里居住，施洗。</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 1:4–5; 以西结书 43:2; 马太福音 3:5–6"> 约翰在靠近撒冷的哀嫩也施洗；因为那里水多，众人都去受洗。（</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 4:12; 马太福音 14:3; 马可福音 6:17"> 那时约翰还没有下在监里。）</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 2:6; 马太福音 3:11; 希伯来书 6:2"> 约翰的门徒和一个犹太人辩论洁净的礼，</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 1:7; 约翰福音 1:15; 约翰福音 12:19"> 就来见约翰，说：「拉比，从前同你在约旦河外、你所见证的那位，现在施洗，众人都往他那里去了。」</span>
<span className="v" id="v27" data-v="27" data-xref="雅各书 1:17; 哥林多前书 4:7; 哥林多前书 15:10"> 约翰说：「若不是从天上赐的，人就不能得什么。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 1:20; 约翰福音 1:23; 马太福音 3:11–12"> 我曾说：『我不是基督，是奉差遣在他前面的』，你们自己可以给我作见证。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 9:15; 何西阿书 2:19; 以赛亚书 54:5"> 娶新妇的就是新郎；新郎的朋友站着，听见新郎的声音就甚喜乐。故此，我这喜乐满足了。</span>
<span className="v" id="v30" data-v="30" data-xref="歌罗西书 1:18; 诗篇 72:17–19; 希伯来书 3:2–6"> 他必兴旺，我必衰微。」</span>
</div>
</div>

## 从天上来的那一位

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 8:23; 马太福音 28:18; 罗马书 9:5"> 「从天上来的是在万有之上；从地上来的是属乎地，他所说的也是属乎地。从天上来的是在万有之上。</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 3:11; 约翰福音 15:15; 约翰福音 1:11"> 他将所见所闻的见证出来，只是没有人领受他的见证。</span>
<span className="v" id="v33" data-v="33" data-xref="希伯来书 6:17; 以弗所书 1:13; 提多书 1:1–2"> 那领受他见证的，就印上印，证明 神是真的。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 10:38; 马太福音 12:18; 约翰福音 15:26"> 神所差来的就说 神的话，因为 神赐圣灵给他是没有限量的。</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 28:18; 约翰福音 5:22; 约翰福音 5:20"> 父爱子，已将万有交在他手里。</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 5:24; 约翰福音 1:12; 帖撒罗尼迦前书 5:9"> 信子的人有永生；不信子的人得不着永生<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是不得见永生">c</a></sup>， 神的震怒常在他身上。」</span>
</div>

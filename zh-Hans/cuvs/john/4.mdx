## 耶稣和撒马利亚妇人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 3:26; 约翰福音 3:22; 哥林多后书 4:5"> 主知道法利赛人听见他收门徒，施洗，比约翰还多，（</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 10:48; 哥林多前书 1:13–17"> 其实不是耶稣亲自施洗，乃是他的门徒施洗，）</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 10:23; 约翰福音 10:40; 约翰福音 2:11"> 他就离了犹太，又往加利利去。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 17:11; 路加福音 2:49; 路加福音 9:51–52"> 必须经过撒马利亚，</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 24:32; 创世记 33:19; 创世记 48:22"> 于是到了撒马利亚的一座城，名叫叙加，靠近雅各给他儿子约瑟的那块地。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 4:15; 希伯来书 2:17; 马太福音 8:24"> 在那里有雅各井；耶稣因走路困乏，就坐在井旁。那时约有午正。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 10:42; 列王纪上 17:10; 创世记 24:43"> 有一个撒马利亚的妇人来打水。耶稣对她说：「请你给我水喝。」（</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 9:13; 约翰福音 4:39; 约翰福音 4:5"> 那时门徒进城买食物去了。）</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 10:28; 马太福音 10:5; 列王纪下 17:24–41"> 撒马利亚的妇人对他说：「你既是犹太人，怎么向我一个撒马利亚妇人要水喝呢？」原来犹太人和撒马利亚人没有来往。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 4:14; 启示录 7:17; 约翰福音 7:37–39"> 耶稣回答说：「你若知道 神的恩赐，和对你说『给我水喝』的是谁，你必早求他，他也必早给了你活水。」</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 2:14; 约翰福音 3:4"> 妇人说：「先生，没有打水的器具，井又深，你从哪里得活水呢？</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 4:6; 约翰福音 8:53; 马太福音 12:42"> 我们的祖宗雅各将这井留给我们，他自己和儿子并牲畜也都喝这井里的水，难道你比他还大吗？」</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 6:27; 以赛亚书 65:13–14; 路加福音 16:24"> 耶稣回答说：「凡喝这水的还要再渴；</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 7:38–39; 约翰福音 6:35; 以赛亚书 49:10"> 人若喝我所赐的水就永远不渴。我所赐的水要在他里头成为泉源，直涌到永生。」</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 6:34; 罗马书 8:5; 诗篇 4:6"> 妇人说：「先生，请把这水赐给我，叫我不渴，也不用来这么远打水。」</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 4:13; 启示录 2:23; 约翰福音 4:18"> 耶稣说：「你去叫你丈夫也到这里来。」</span>
<span className="v" id="v17" data-v="17"> 妇人说：「我没有丈夫。」耶稣说：「你说没有丈夫是不错的。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 3:20; 哥林多前书 7:10–11; 罗马书 7:3"> 你已经有五个丈夫，你现在有的并不是你的丈夫。你这话是真的。」</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 7:39; 约翰福音 6:14; 约翰福音 9:17"> 妇人说：「先生，我看出你是先知。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 12:6–7; 申命记 27:12; 申命记 11:29"> 我们的祖宗在这山上礼拜，你们倒说，应当礼拜的地方是在耶路撒冷。」</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太前书 2:8; 玛拉基书 1:11; 约翰福音 4:23"> 耶稣说：「妇人，你当信我。时候将到，你们拜父，也不在这山上，也不在耶路撒冷。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 17:23; 以赛亚书 2:3; 罗马书 9:4–5"> 你们所拜的，你们不知道；我们所拜的，我们知道，因为救恩是从犹太人出来的。</span>
<span className="v" id="v23" data-v="23" data-xref="腓立比书 3:3; 约翰福音 5:25; 马太福音 15:7–9"> 时候将到，如今就是了，那真正拜父的，要用心灵和诚实拜他，因为父要这样的人拜他。」</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 3:17; 马太福音 15:8–9; 腓立比书 3:3"> 神是个灵<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或无个字">a</a></sup>，所以拜他的必须用心灵和诚实拜他。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 1:49; 但以理书 9:24–26; 约翰福音 1:41–42"> 妇人说：「我知道弥赛亚（就是那称为基督的）要来；他来了，必将一切的事都告诉我们。」</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 8:24; 马可福音 14:61–62; 罗马书 10:20–21"> 耶稣说：「这和你说话的就是他！」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 7:39; 约翰福音 4:8–9"> 当下门徒回来，就希奇耶稣和一个妇人说话；只是没有人说：「你是要什么？」或说：「你为什么和她说话？」</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 4:7; 路加福音 24:33; 马可福音 16:8–10"> 那妇人就留下水罐子，往城里去，对众人说：</span>
<span className="v" id="v29" data-v="29" data-xref="启示录 22:17; 哥林多前书 14:24–25; 约翰福音 4:25"> 「你们来看！有一个人将我素来所行的一切事都给我说出来了，莫非这就是基督吗？」</span>
<span className="v" id="v30" data-v="30" data-xref="罗马书 5:20; 使徒行传 8:5–8; 路加福音 17:16–18"> 众人就出城，往耶稣那里去。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 1:38; 创世记 24:33; 使徒行传 16:30–34"> 这其间，门徒对耶稣说：「拉比，请吃。」</span>
<span className="v" id="v32" data-v="32" data-xref="约伯记 23:12; 诗篇 119:103; 约翰福音 4:34"> 耶稣说：「我有食物吃，是你们不知道的。」</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 16:6–11; 路加福音 9:45"> 门徒就彼此对问说：「莫非有人拿什么给他吃吗？」</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 6:38; 约翰福音 5:30; 约伯记 23:12"> 耶稣说：「我的食物就是遵行差我来者的旨意，做成他的工。</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 10:2–3; 马太福音 9:37–38; 约翰福音 4:30"> 你们岂不说『到收割的时候还有四个月』吗？我告诉你们，举目向田观看，庄稼已经熟了<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是发白">b</a></sup>，可以收割了。</span>
<span className="v" id="v36" data-v="36" data-xref="雅各书 5:19–20; 罗马书 1:13; 哥林多前书 3:5–9"> 收割的人得工价，积蓄五谷到永生，叫撒种的和收割的一同快乐。</span>
<span className="v" id="v37" data-v="37" data-xref="弥迦书 6:15; 约伯记 31:8; 路加福音 19:21"> 俗语说：『那人撒种，这人收割』，这话可见是真的。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 1:7; 历代志下 36:15; 使徒行传 10:42–43"> 我差你们去收你们所没有劳苦的；别人劳苦，你们享受他们所劳苦的。」</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="约翰福音 4:29; 约翰福音 4:5; 约翰福音 10:41–42"> 那城里有好些撒马利亚人信了耶稣，因为那妇人作见证说：「他将我素来所行的一切事都给我说出来了。」</span>
<span className="v" id="v40" data-v="40" data-xref="启示录 3:20; 使徒行传 16:15; 路加福音 24:29"> 于是撒马利亚人来见耶稣，求他在他们那里住下，他便在那里住了两天。</span>
<span className="v" id="v41" data-v="41" data-xref="哥林多前书 2:4–5; 使徒行传 1:8; 使徒行传 8:12"> 因耶稣的话，信的人就更多了，</span>
<span className="v" id="v42" data-v="42" data-xref="约翰一书 4:14; 约翰福音 1:29; 约翰一书 5:20"> 便对妇人说：「现在我们信，不是因为你的话，是我们亲自听见了，知道这真是救世主。」</span>
</div>
</div>

## 耶稣治好大臣的儿子

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="马太福音 4:13; 罗马书 15:8; 马可福音 7:27–28"> 过了那两天，耶稣离了那地方，往加利利去。</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 13:57; 路加福音 4:24; 马可福音 6:4"> 因为耶稣自己作过见证说：「先知在本地是没有人尊敬的。」</span>
<span className="v" id="v45" data-v="45" data-xref="约翰福音 2:23; 约翰福音 2:13–16; 申命记 16:16"> 到了加利利，加利利人既然看见他在耶路撒冷过节所行的一切事，就接待他，因为他们也是上去过节。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="约翰福音 2:1–11; 路加福音 7:2; 何西阿书 5:15"> 耶稣又到了加利利的迦拿，就是他从前变水为酒的地方。有一个大臣，他的儿子在迦百农患病。</span>
<span className="v" id="v47" data-v="47" data-xref="约翰福音 4:3; 约翰福音 11:21; 约翰福音 11:32"> 他听见耶稣从犹太到了加利利，就来见他，求他下去医治他的儿子，因为他儿子快要死了。</span>
<span className="v" id="v48" data-v="48" data-xref="约翰福音 20:29; 希伯来书 2:4; 哥林多前书 1:22"> 耶稣就对他说：「若不看见神迹奇事，你们总是不信。」</span>
<span className="v" id="v49" data-v="49" data-xref="马可福音 5:23; 诗篇 88:10–12; 诗篇 40:17"> 那大臣说：「先生，求你趁着我的孩子还没有死就下去。」</span>
<span className="v" id="v50" data-v="50" data-xref="马太福音 8:13; 马可福音 7:29–30; 罗马书 4:20–21"> 耶稣对他说：「回去吧，你的儿子活了！」那人信耶稣所说的话就回去了。</span>
<span className="v" id="v51" data-v="51" data-xref="列王纪上 17:23; 约翰福音 4:50; 约翰福音 4:53"> 正下去的时候，他的仆人迎见他，说他的儿子活了。</span>
<span className="v" id="v52" data-v="52"> 他就问什么时候见好的。他们说：「昨日未时热就退了。」</span>
<span className="v" id="v53" data-v="53" data-xref="诗篇 107:20; 路加福音 19:9; 使徒行传 16:34"> 他便知道这正是耶稣对他说「你儿子活了」的时候；他自己和全家就都信了。</span>
<span className="v" id="v54" data-v="54" data-xref="约翰福音 4:45; 约翰福音 2:1–11"> 这是耶稣在加利利行的第二件神迹，是他从犹太回去以后行的。</span>
</div>

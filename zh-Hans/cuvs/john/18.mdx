## 耶稣被捕

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 14:32; 马太福音 26:36; 撒母耳记下 15:23"> 耶稣说了这话，就同门徒出去，过了汲沦溪。在那里有一个园子，他和门徒进去了。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 21:37; 路加福音 22:39; 马可福音 11:11–12"> 卖耶稣的犹大也知道那地方，因为耶稣和门徒屡次上那里去聚集。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 18:12; 路加福音 22:47–53; 诗篇 22:12"> 犹大领了一队兵，和祭司长并法利赛人的差役，拿着灯笼、火把、兵器，就来到园里。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 13:1; 约翰福音 18:7; 诗篇 27:3"> 耶稣知道将要临到自己的一切事，就出来对他们说：「你们找谁？」</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 21:11; 约翰福音 19:19; 马太福音 2:23"> 他们回答说：「找拿撒勒人耶稣。」耶稣说：「我就是！」卖他的犹大也同他们站在那里。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 27:2; 诗篇 70:2–3; 列王纪下 1:9–15"> 耶稣一说「我就是」，他们就退后倒在地上。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 18:4"> 他又问他们说：「你们找谁？」他们说：「找拿撒勒人耶稣。」</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 10:28; 马太福音 26:56; 哥林多后书 12:9"> 耶稣说：「我已经告诉你们，我就是。你们若找我，就让这些人去吧。」</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 17:12"> 这要应验耶稣从前的话，说：「你所赐给我的人，我没有失落一个。」</span>
<span className="v" id="v10" data-v="10" data-xref="马可福音 14:47; 马太福音 26:51–54; 路加福音 22:49–51"> 西门·彼得带着一把刀，就拔出来，将大祭司的仆人砍了一刀，削掉他的右耳；那仆人名叫马勒古。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 20:22; 马太福音 26:39; 约翰福音 20:17"> 耶稣就对彼得说：「收刀入鞘吧，我父所给我的那杯，我岂可不喝呢？」</span>
</div>
</div>

## 耶稣被带到亚那面前

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 26:57; 约翰福音 18:3; 使徒行传 21:37"> 那队兵和千夫长，并犹太人的差役就拿住耶稣，把他捆绑了，</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 18:24; 约翰福音 11:51; 马太福音 26:3"> 先带到亚那面前，因为亚那是本年作大祭司该亚法的岳父。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 11:49–52"> 这该亚法就是从前向犹太人发议论说「一个人替百姓死是有益的」那位。</span>
</div>
</div>

## 彼得不认耶稣

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 22:54; 马可福音 14:54; 马太福音 26:58–68"> 西门·彼得跟着耶稣，还有一个门徒跟着。那门徒是大祭司所认识的，他就同耶稣进了大祭司的院子。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 26:69; 马可福音 14:66–68; 路加福音 22:55–57"> 彼得却站在门外。大祭司所认识的那个门徒出来，和看门的使女说了一声，就领彼得进去。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 26:69–70; 约翰福音 21:15; 路加福音 22:56–57"> 那看门的使女对彼得说：「你不也是这人的门徒吗？」他说：「我不是。」</span>
<span className="v" id="v18" data-v="18" data-xref="马可福音 14:54; 约翰福音 18:25; 马可福音 14:67"> 仆人和差役因为天冷，就生了炭火，站在那里烤火；彼得也同他们站着烤火。</span>
</div>
</div>

## 大祭司盘问耶稣

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马可福音 14:55–65; 路加福音 20:20; 路加福音 22:63–71"> 大祭司就以耶稣的门徒和他的教训盘问他。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 7:26; 以赛亚书 48:16; 马太福音 4:23"> 耶稣回答说：「我从来是明明地对世人说话。我常在会堂和殿里，就是犹太人聚集的地方教训人；我在暗地里并没有说什么。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 26:59–60; 使徒行传 24:12–13; 路加福音 22:67"> 你为什么问我呢？可以问那听见的人，我对他们说的是什么；我所说的，他们都知道。」</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 19:3; 马可福音 14:65; 路加福音 22:63–64"> 耶稣说了这话，旁边站着的一个差役用手掌打他，说：「你这样回答大祭司吗？」</span>
<span className="v" id="v23" data-v="23" data-xref="彼得前书 2:20–23; 哥林多后书 10:1; 马太福音 5:39"> 耶稣说：「我若说的不是，你可以指证那不是；我若说的是，你为什么打我呢？」</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 18:13; 马太福音 26:57"> 亚那就把耶稣解到大祭司该亚法那里，仍是捆着解去的。</span>
</div>
</div>

## 彼得再次不认耶稣

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马可福音 14:67–72; 约翰福音 18:17–18; 创世记 18:15"> 西门·彼得正站着烤火，有人对他说：「你不也是他的门徒吗？」彼得不承认，说：「我不是。」</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 18:1; 约翰福音 18:10; 马太福音 26:73"> 有大祭司的一个仆人，是彼得削掉耳朵那人的亲属，说：「我不是看见你同他在园子里吗？」</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 13:38; 马可福音 14:71–72; 路加福音 22:60–62"> 彼得又不承认。立时鸡就叫了。</span>
</div>
</div>

## 耶稣在彼拉多面前受审

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约翰福音 18:33; 约翰福音 19:9; 马太福音 27:27"> 众人将耶稣从该亚法那里往衙门内解去，那时天还早。他们自己却不进衙门，恐怕染了污秽，不能吃逾越节的筵席。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 27:23; 马可福音 15:2–5; 马太福音 27:11–14"> 彼拉多就出来，到他们那里，说：「你们告这人是为什么事呢？」</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 3:13; 路加福音 20:19–26; 马可福音 10:33"> 他们回答说：「这人若不是作恶的，我们就不把他交给你。」</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 19:6–7; 约翰福音 19:15; 使徒行传 25:18–20"> 彼拉多说：「你们自己带他去，按着你们的律法审问他吧。」犹太人说：「我们没有杀人的权柄。」</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 3:14; 马太福音 20:19; 马太福音 26:2"> 这要应验耶稣所说自己将要怎样死的话了。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 23:3–4; 约翰福音 18:37; 约翰福音 19:3"> 彼拉多又进了衙门，叫耶稣来，对他说：「你是犹太人的王吗？」</span>
<span className="v" id="v34" data-v="34"> 耶稣回答说：「这话是你自己说的，还是别人论我对你说的呢？」</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 18:14–16; 尼希米记 4:2; 罗马书 3:1–2"> 彼拉多说：「我岂是犹太人呢？你本国的人和祭司长把你交给我。你做了什么事呢？」</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 17:20–21; 歌罗西书 1:12–14; 罗马书 14:17"> 耶稣回答说：「我的国不属这世界；我的国若属这世界，我的臣仆必要争战，使我不至于被交给犹太人。只是我的国不属这世界。」</span>
<span className="v" id="v37" data-v="37" data-xref="约翰一书 4:6; 约翰福音 8:47; 约翰福音 8:14"> 彼拉多就对他说：「这样，你是王吗？」耶稣回答说：「你说我是王。我为此而生，也为此来到世间，特为给真理作见证。凡属真理的人就听我的话。」</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 19:4; 路加福音 23:4; 约翰福音 19:6"> 彼拉多说：「真理是什么呢？」 耶稣被判死刑 （太27·15—31；可15·6—20；路23·13—25） 说了这话，又出来到犹太人那里，对他们说：「我查不出他有什么罪来。</span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 27:15–18; 路加福音 23:16–23; 马可福音 15:6–14"> 但你们有个规矩，在逾越节要我给你们释放一个人，你们要我给你们释放犹太人的王吗？」</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 23:25; 马可福音 15:15; 马太福音 27:16"> 他们又喊着说：「不要这人，要巴拉巴！」这巴拉巴是个强盗。</span>
</div>

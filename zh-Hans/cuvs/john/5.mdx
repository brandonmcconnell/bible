## 在毕士大池边治病

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 16:16; 出埃及记 23:14–17; 出埃及记 34:23"> 这事以后，到了犹太人的一个节期，耶稣就上耶路撒冷去。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米记 12:39; 尼希米记 3:1; 尼希米记 3:32"> 在耶路撒冷，靠近羊门有一个池子，希伯来话叫作毕士大，旁边有五个廊子；</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 3:1–4; 路加福音 7:22; 马太福音 15:30"> 里面躺着瞎眼的、瘸腿的、血气枯干的许多病人。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷加：等候水动；4因为有天使按时下池子搅动那水，水动之后，谁先下去，无论害什么病就痊愈了。">a</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 3:2; 路加福音 8:43; 马可福音 9:21"> 在那里有一个人，病了三十八年。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 18:41; 希伯来书 4:15; 希伯来书 4:13"> 耶稣看见他躺着，知道他病了许久，就问他说：「你要痊愈吗？」</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 72:12; 申命记 32:36; 哥林多前书 9:24"> 病人回答说：「先生，水动的时候，没有人把我放在池子里；我正去的时候，就有别人比我先下去。」</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 5:24; 马太福音 9:6; 马可福音 2:11"> 耶稣对他说：「起来，拿你的褥子走吧！」</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 3:7–8; 约翰福音 9:14; 马可福音 3:2–4"> 那人立刻痊愈，就拿起褥子来走了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 17:21; 路加福音 6:2; 约翰福音 9:16"> 那天是安息日，所以犹太人对那医好的人说：「今天是安息日，你拿褥子是不可的。」</span>
<span className="v" id="v11" data-v="11" data-xref="马可福音 2:9–11; 约翰福音 9:16"> 他却回答说：「那使我痊愈的，对我说：『拿你的褥子走吧。』」</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 21:23; 士师记 6:29; 罗马书 10:2"> 他们问他说：「对你说『拿褥子走』的是什么人？」</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 4:30; 路加福音 24:31; 约翰福音 8:59"> 那医好的人不知道是谁；因为那里的人多，耶稣已经躲开了。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 8:11; 利未记 26:23–24; 诗篇 118:18"> 后来耶稣在殿里遇见他，对他说：「你已经痊愈了，不要再犯罪，恐怕你遭遇的更加利害。」</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 9:11–12; 约翰福音 4:29; 约翰福音 9:25"> 那人就去告诉犹太人，使他痊愈的是耶稣。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 10:39; 约翰福音 7:19–20; 马可福音 3:6"> 所以犹太人逼迫耶稣，因为他在安息日做了这事。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 9:4; 约翰福音 14:10; 歌罗西书 1:16"> 耶稣就对他们说：「我父做事直到如今，我也做事。」</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 10:30; 约翰福音 10:33; 约翰福音 19:7"> 所以犹太人越发想要杀他；因他不但犯了安息日，并且称 神为他的父，将自己和 神当作平等。</span>
</div>
</div>

## 子的权柄

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约翰福音 12:49; 约翰福音 8:28; 约翰福音 14:10"> 耶稣对他们说：「我实实在在地告诉你们，子凭着自己不能做什么，惟有看见父所做的，子才能做；父所做的事，子也照样做。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 3:35; 马太福音 3:17; 约翰福音 17:26"> 父爱子，将自己所做的一切事指给他看，还要将比这更大的事指给他看，叫你们希奇。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 8:11; 申命记 32:39; 约翰福音 11:25"> 父怎样叫死人起来，使他们活着，子也照样随自己的意思使人活着。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 5:27; 使徒行传 17:31; 哥林多后书 5:10"> 父不审判什么人，乃将审判的事全交与子，</span>
<span className="v" id="v23" data-v="23" data-xref="约翰一书 2:23; 路加福音 10:16; 马太福音 11:27"> 叫人都尊敬子如同尊敬父一样。不尊敬子的，就是不尊敬差子来的父。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 3:36; 约翰福音 6:40; 约翰一书 5:11–13"> 我实实在在地告诉你们，那听我话、又信差我来者的，就有永生；不至于定罪，是已经出死入生了。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 5:28; 以弗所书 5:14; 以弗所书 2:5"> 我实实在在地告诉你们，时候将到，现在就是了，死人要听见 神儿子的声音，听见的人就要活了。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 11:26; 约翰福音 1:4; 出埃及记 3:14"> 因为父怎样在自己有生命，就赐给他儿子也照样在自己有生命，</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 10:42; 约翰福音 5:22; 使徒行传 17:31"> 并且因为他是人子，就赐给他行审判的权柄。</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 20:12; 帖撒罗尼迦前书 4:14–17; 以赛亚书 26:19"> 你们不要把这事看作希奇。时候要到，凡在坟墓里的，都要听见他的声音，就出来：</span>
<span className="v" id="v29" data-v="29" data-xref="但以理书 12:2–3; 罗马书 2:6–10; 使徒行传 24:15"> 行善的，复活得生；作恶的，复活定罪。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约翰福音 6:38; 约翰福音 5:19; 约翰福音 4:34"> 「我凭着自己不能做什么，我怎么听见就怎么审判。我的审判也是公平的；因为我不求自己的意思，只求那差我来者的意思。」</span>
</div>
</div>

## 为耶稣作证

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="箴言 27:2; 约翰福音 8:54; 启示录 3:14"> 「我若为自己作见证，我的见证就不真。</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 1:33; 约翰福音 12:28–30; 约翰福音 5:36–37"> 另有一位给我作见证，我也知道他给我作的见证是真的。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 1:29–34; 约翰福音 3:26–36; 约翰福音 1:15–27"> 你们曾差人到约翰那里，他为真理作过见证。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 19:41–42; 约翰福音 20:31; 约翰一书 5:9"> 其实，我所受的见证不是从人来的；然而，我说这些话，为要叫你们得救。</span>
<span className="v" id="v35" data-v="35" data-xref="彼得后书 1:19; 约翰福音 1:7–8; 马太福音 11:11"> 约翰是点着的明灯，你们情愿暂时喜欢他的光。</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 10:25; 约翰福音 10:37–38; 约翰福音 15:24"> 但我有比约翰更大的见证；因为父交给我要我成就的事，就是我所做的事，这便见证我是父所差来的。</span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 8:18; 约翰福音 1:18; 马太福音 3:17"> 差我来的父也为我作过见证。你们从来没有听见他的声音，也没有看见他的形象。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰一书 2:14; 申命记 6:6–9; 约翰福音 12:44–48"> 你们并没有他的道存在心里；因为他所差来的，你们不信。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 24:27; 路加福音 24:44; 彼得后书 1:19–21"> 你们查考圣经<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：应当查考圣经">b</a></sup>，因你们以为内中有永生；给我作见证的就是这经。</span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 3:19; 约翰福音 1:11; 诗篇 81:11"> 然而，你们不肯到我这里来得生命。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="约翰福音 7:18; 约翰福音 5:34; 帖撒罗尼迦前书 2:6"> 「我不受从人来的荣耀。</span>
<span className="v" id="v42" data-v="42" data-xref="约翰一书 4:20; 约翰一书 3:17; 约翰福音 2:25"> 但我知道，你们心里没有 神的爱。</span>
<span className="v" id="v43" data-v="43" data-xref="约翰福音 10:25; 马太福音 24:5; 约翰福音 17:4–6"> 我奉我父的名来，你们并不接待我；若有别人奉自己的名来，你们倒要接待他。</span>
<span className="v" id="v44" data-v="44" data-xref="约翰福音 12:43; 罗马书 2:29; 腓立比书 2:3"> 你们互相受荣耀，却不求从独一之 神来的荣耀，怎能信我呢？</span>
<span className="v" id="v45" data-v="45" data-xref="罗马书 3:19–20; 加拉太书 3:10; 哥林多后书 3:7–11"> 不要想我在父面前要告你们；有一位告你们的，就是你们所仰赖的摩西。</span>
<span className="v" id="v46" data-v="46" data-xref="申命记 18:15; 申命记 18:18–19; 约翰福音 1:45"> 你们如果信摩西，也必信我，因为他书上有指着我写的话。</span>
<span className="v" id="v47" data-v="47" data-xref="路加福音 16:31; 路加福音 16:29"> 你们若不信他的书，怎能信我的话呢？」</span>
</div>
</div>

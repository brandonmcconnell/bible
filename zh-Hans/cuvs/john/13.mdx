## 耶稣为门徒洗脚

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 12:23; 约翰一书 4:19; 约翰福音 13:34"> 逾越节以前，耶稣知道自己离世归父的时候到了。他既然爱世间属自己的人，就爱他们到底。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各书 1:13–17; 使徒行传 5:3; 约翰福音 13:26–27"> 吃晚饭的时候，魔鬼已将卖耶稣的意思放在西门的儿子加略人犹大心里。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 3:35; 马太福音 11:27; 希伯来书 1:2"> 耶稣知道父已将万有交在他手里，且知道自己是从 神出来的，又要归到 神那里去，</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 22:27; 哥林多后书 8:9; 路加福音 12:37"> 就离席站起来，脱了衣服，拿一条手巾束腰，</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 7:44; 诗篇 51:2; 创世记 18:4"> 随后把水倒在盆里，就洗门徒的脚，并用自己所束的手巾擦干。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 3:11–14; 约翰福音 1:27; 路加福音 5:8"> 挨到西门·彼得，彼得对他说：「主啊，你洗我的脚吗？」</span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 12:8; 约翰福音 12:16; 约翰福音 14:26"> 耶稣回答说：「我所做的，你如今不知道，后来必明白。」</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 36:25; 使徒行传 22:16; 提多书 3:5"> 彼得说：「你永不可洗我的脚！」耶稣说：「我若不洗你，你就与我无分了。」</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 51:7; 诗篇 51:2; 彼得前书 3:21"> 西门·彼得说：「主啊，不但我的脚，连手和头也要洗。」</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 15:3; 哥林多后书 7:1; 哥林多后书 5:17"> 耶稣说：「凡洗过澡的人，只要把脚一洗，全身就干净了。你们是干净的，然而不都是干净的。」</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 13:26; 约翰福音 13:2; 约翰福音 13:21"> 耶稣原知道要卖他的是谁，所以说：「你们不都是干净的。」</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 13:7; 约翰福音 13:4; 以西结书 24:24"> 耶稣洗完了他们的脚，就穿上衣服，又坐下，对他们说：「我向你们所做的，你们明白吗？</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 6:46; 哥林多前书 12:3; 约翰福音 11:28"> 你们称呼我夫子，称呼我主，你们说的不错，我本来是。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 5:5; 使徒行传 20:35; 罗马书 12:16"> 我是你们的主，你们的夫子，尚且洗你们的脚，你们也当彼此洗脚。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰一书 2:6; 马太福音 11:29; 彼得前书 3:17–18"> 我给你们作了榜样，叫你们照着我向你们所做的去做。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 6:40; 约翰福音 15:20; 马太福音 10:24–25"> 我实实在在地告诉你们，仆人不能大于主人，差人也不能大于差他的人。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 11:28; 雅各书 4:17; 雅各书 1:25"> 你们既知道这事，若是去行就有福了。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 41:9; 马太福音 26:23; 约翰福音 17:12"> 我这话不是指着你们众人说的，我知道我所拣选的是谁。现在要应验经上的话，说：『同我吃饭的人用脚踢我。』</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 43:10; 约翰福音 14:29; 约翰福音 16:4"> 如今事情还没有成就，我要先告诉你们，叫你们到事情成就的时候可以信我是基督。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:16; 路加福音 9:48; 马太福音 25:40"> 我实实在在地告诉你们，有人接待我所差遣的，就是接待我；接待我，就是接待那差遣我的。」</span>
</div>
</div>

## 预言自己将被出卖

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约翰福音 13:18; 马太福音 26:21; 马可福音 14:18"> 耶稣说了这话，心里忧愁，就明说：「我实实在在地告诉你们，你们中间有一个人要卖我了。」</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 22:23; 马太福音 26:22; 马可福音 14:19"> 门徒彼此对看，猜不透所说的是谁。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 19:26; 约翰福音 21:7; 约翰福音 21:20"> 有一个门徒，是耶稣所爱的，侧身挨近耶稣的怀里。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 12:17; 路加福音 1:22; 使徒行传 13:16"> 西门·彼得点头对他说：「你告诉我们，主是指着谁说的。」</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 21:20; 创世记 44:4–12; 以斯帖记 7:5"> 那门徒便就势靠着耶稣的胸膛，问他说：「主啊，是谁呢？」</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 26:23; 约翰福音 13:30; 马可福音 14:19–20"> 耶稣回答说：「我蘸一点饼给谁，就是谁。」耶稣就蘸了一点饼，递给加略人西门的儿子犹大。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 22:3; 约翰福音 13:2; 传道书 9:3"> 他吃了以后，撒但就入了他的心。耶稣便对他说：「你所做的，快做吧！」</span>
<span className="v" id="v28" data-v="28"> 同席的人没有一个知道是为什么对他说这话。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 12:5–6; 约翰福音 13:1; 以弗所书 4:28"> 有人因犹大带着钱囊，以为耶稣是对他说：「你去买我们过节所应用的东西」，或是叫他拿什么周济穷人。</span>
<span className="v" id="v30" data-v="30" data-xref="以赛亚书 59:7; 约伯记 24:13–15; 箴言 4:16"> 犹大受了那点饼，立刻就出去。那时候是夜间了。</span>
</div>
</div>

## 新的命令

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 14:13; 彼得前书 4:11; 约翰福音 7:39"> 他既出去，耶稣就说：「如今人子得了荣耀， 神在人子身上也得了荣耀。</span>
<span className="v" id="v32" data-v="32" data-xref="启示录 22:1; 以赛亚书 53:10–12; 约翰福音 17:4–6"> 神要因自己荣耀人子，并且要快快地荣耀他。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 7:33–34; 约翰福音 8:21–24; 约翰福音 16:16–22"> 小子们，我还有不多的时候与你们同在；后来你们要找我，但我所去的地方你们不能到。这话我曾对犹太人说过，如今也照样对你们说。</span>
<span className="v" id="v34" data-v="34" data-xref="以弗所书 5:2; 利未记 19:18; 约翰福音 15:17"> 我赐给你们一条新命令，乃是叫你们彼此相爱；我怎样爱你们，你们也要怎样相爱。</span>
<span className="v" id="v35" data-v="35" data-xref="约翰一书 4:20–21; 约翰一书 3:10–14; 约翰一书 2:10"> 你们若有彼此相爱的心，众人因此就认出你们是我的门徒了。」</span>
</div>
</div>

## 预言彼得不认主

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="彼得后书 1:14; 约翰福音 13:33; 约翰福音 21:21–22"> 西门·彼得问耶稣说：「主往哪里去？」耶稣回答说：「我所去的地方，你现在不能跟我去，后来却要跟我去。」</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 21:13; 使徒行传 20:24; 马可福音 14:27–31"> 彼得说：「主啊，我为什么现在不能跟你去？我愿意为你舍命！」</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 22:34; 马太福音 26:34; 马可福音 14:30"> 耶稣说：「你愿意为我舍命吗？我实实在在地告诉你，鸡叫以先，你要三次不认我。」</span>
</div>

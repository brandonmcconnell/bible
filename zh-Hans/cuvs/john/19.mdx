<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 53:5; 以赛亚书 50:6; 马太福音 20:19"> 当下彼拉多将耶稣鞭打了。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 15:16–20; 路加福音 23:11; 马太福音 27:27–31"> 兵丁用荆棘编做冠冕戴在他头上，给他穿上紫袍，</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 27:29; 马太福音 26:49; 路加福音 1:28"> 又挨近他，说：「恭喜，犹太人的王啊！」他们就用手掌打他。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 18:38; 约翰福音 19:6; 路加福音 23:4"> 彼拉多又出来对众人说：「我带他出来见你们，叫你们知道我查不出他有什么罪来。」</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 19:2; 希伯来书 12:2; 以赛亚书 7:14"> 耶稣出来，戴着荆棘冠冕，穿着紫袍。彼拉多对他们说：「你们看这个人！」</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 18:31; 约翰福音 19:4; 使徒行传 2:23"> 祭司长和差役看见他，就喊着说：「钉他十字架！钉他十字架！」彼拉多说：「你们自己把他钉十字架吧！我查不出他有什么罪来。」</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 24:16; 约翰福音 5:18; 马太福音 26:63–66"> 犹太人回答说：「我们有律法，按那律法，他是该死的，因他以自己为 神的儿子。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约翰福音 19:13; 使徒行传 14:11–19"> 彼拉多听见这话，越发害怕，</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 18:33; 诗篇 38:13–15; 腓立比书 1:28"> 又进衙门，对耶稣说：「你是哪里来的？」耶稣却不回答。</span>
<span className="v" id="v10" data-v="10" data-xref="但以理书 5:19; 约翰福音 18:39; 但以理书 3:14–15"> 彼拉多说：「你不对我说话吗？你岂不知我有权柄释放你，也有权柄把你钉十字架吗？」</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 13:1; 约翰福音 3:27; 使徒行传 2:23"> 耶稣回答说：「若不是从上头赐给你的，你就毫无权柄办我。所以，把我交给你的那人罪更重了。」</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 17:6–7; 约翰福音 18:33–36; 马可福音 6:16–26"> 从此，彼拉多想要释放耶稣，无奈犹太人喊着说：「你若释放这个人，就不是凯撒的忠臣<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是朋友">a</a></sup>。凡以自己为王的，就是背叛凯撒了。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="诗篇 82:5–7; 马太福音 27:19; 阿摩司书 4:7"> 彼拉多听见这话，就带耶稣出来，到了一个地方，名叫「铺华石处」，希伯来话叫厄巴大，就在那里坐堂。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 27:62; 约翰福音 19:5; 马可福音 15:25"> 那日是预备逾越节的日子，约有午正。彼拉多对犹太人说：「看哪，这是你们的王！」</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 23:18; 使徒行传 21:36; 约翰福音 19:6"> 他们喊着说：「除掉他！除掉他！钉他在十字架上！」彼拉多说：「我可以把你们的王钉十字架吗？」祭司长回答说：「除了凯撒，我们没有王。」</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 23:24–25; 马太福音 27:26–31; 马可福音 15:15–20"> 于是彼拉多将耶稣交给他们去钉十字架。</span>
</div>
</div>

## 耶稣被钉十字架

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 23:33; 路加福音 14:27; 路加福音 23:26"> 他们就把耶稣带了去。耶稣背着自己的十字架出来，到了一个地方，名叫「髑髅地」，希伯来话叫各各他。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 53:12; 马可福音 15:24–27; 加拉太书 3:13"> 他们就在那里钉他在十字架上，还有两个人和他一同钉着，一边一个，耶稣在中间。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 27:37; 路加福音 23:38; 马可福音 15:26"> 彼拉多又用牌子写了一个名号，安在十字架上，写的是：「犹太人的王，拿撒勒人耶稣。」</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 26:14; 启示录 16:16; 使徒行传 22:2"> 有许多犹太人念这名号；因为耶稣被钉十字架的地方与城相近，并且是用希伯来、罗马、希腊三样文字写的。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 19:14; 约翰福音 19:19"> 犹太人的祭司长就对彼拉多说：「不要写『犹太人的王』，要写『他自己说：我是犹太人的王』。」</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 76:10; 诗篇 65:7; 箴言 8:29"> 彼拉多说：「我所写的，我已经写上了。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="路加福音 23:34; 马可福音 15:24; 马太福音 27:35"> 兵丁既然将耶稣钉在十字架上，就拿他的衣服分为四分，每兵一分；又拿他的里衣，这件里衣原来没有缝儿，是上下一片织成的。</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 22:18; 约翰福音 19:28; 约翰福音 19:36–37"> 他们就彼此说：「我们不要撕开，只要拈阄，看谁得着。」这要应验经上的话说：<br /><span className="pl pl-1">他们分了我的外衣，</span><br /><span className="pl pl-1">为我的里衣拈阄。</span><br />兵丁果然做了这事。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 23:49; 马太福音 27:55–56; 约翰福音 20:1"> 站在耶稣十字架旁边的，有他母亲与他母亲的姊妹，并革罗罢的妻子马利亚，和抹大拉的马利亚。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 21:24; 约翰福音 20:2; 约翰福音 2:4"> 耶稣见母亲和他所爱的那门徒站在旁边，就对他母亲说：「母亲<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是妇人">b</a></sup>，看，你的儿子！」</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 12:48–50; 约翰福音 16:32; 提摩太前书 5:2–4"> 又对那门徒说：「看，你的母亲！」从此，那门徒就接她到自己家里去了。</span>
</div>
</div>

## 耶稣的死

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="诗篇 69:21; 诗篇 22:15; 约翰福音 19:30"> 这事以后，耶稣知道各样的事已经成了，为要使经上的话应验，就说：「我渴了。」</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 19:18; 路加福音 23:36; 马可福音 15:36"> 有一个器皿盛满了醋，放在那里；他们就拿海绒蘸满了醋，绑在牛膝草上，送到他口。</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 17:4; 腓立比书 2:8; 歌罗西书 2:14–17"> 耶稣尝<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是受">c</a></sup>了那醋，就说：「成了！」便低下头，将灵魂交付 神了。</span>
</div>
</div>

## 肋旁被扎

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 19:14; 约翰福音 19:42; 马可福音 15:42"> 犹太人因这日是预备日，又因那安息日是个大日，就求彼拉多叫人打断他们的腿，把他们拿去，免得尸首当安息日留在十字架上。</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 19:18; 路加福音 23:39–43"> 于是兵丁来，把头一个人的腿，并与耶稣同钉第二个人的腿，都打断了。</span>
<span className="v" id="v33" data-v="33"> 只是来到耶稣那里，见他已经死了，就不打断他的腿。</span>
<span className="v" id="v34" data-v="34" data-xref="约翰一书 5:6; 撒迦利亚书 12:10; 撒迦利亚书 13:1"> 惟有一个兵拿枪扎他的肋旁，随即有血和水流出来。</span>
<span className="v" id="v35" data-v="35" data-xref="约翰福音 21:24; 希伯来书 2:3–4; 约翰一书 1:1–3"> 看见这事的那人就作见证—他的见证也是真的，并且他知道自己所说的是真的—叫你们也可以信。</span>
<span className="v" id="v36" data-v="36" data-xref="诗篇 34:20; 民数记 9:12; 出埃及记 12:46"> 这些事成了，为要应验经上的话说：「他的骨头一根也不可折断。」</span>
<span className="v" id="v37" data-v="37" data-xref="撒迦利亚书 12:10; 启示录 1:7; 诗篇 22:16–17"> 经上又有一句说：「他们要仰望自己所扎的人。」</span>
</div>
</div>

## 耶稣的安葬

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="马可福音 15:42–47; 马太福音 27:57–61; 箴言 29:25"> 这些事以后，有亚利马太人约瑟，是耶稣的门徒，只因怕犹太人，就暗暗地作门徒。他来求彼拉多，要把耶稣的身体领去。彼拉多允准，他就把耶稣的身体领去了。</span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 7:50–52; 雅歌 4:14; 约翰福音 3:1–21"> 又有尼哥德慕，就是先前夜里去见耶稣的，带着没药和沉香约有一百斤前来。</span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 11:44; 约翰福音 20:5–7; 使徒行传 5:6"> 他们就照犹太人殡葬的规矩，把耶稣的身体用细麻布加上香料裹好了。</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 23:53; 马太福音 27:60; 约翰福音 20:15"> 在耶稣钉十字架的地方有一个园子，园子里有一座新坟墓，是从来没有葬过人的。</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 19:31; 约翰福音 19:14; 以赛亚书 53:9"> 只因是犹太人的预备日，又因那坟墓近，他们就把耶稣安放在那里。</span>
</div>

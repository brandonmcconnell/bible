## 耶稣的兄弟不信

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 5:16–18; 约翰福音 4:3; 马太福音 21:38"> 这事以后，耶稣在加利利游行，不愿在犹太游行，因为犹太人想要杀他。</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亚书 14:16–19; 申命记 16:13–16; 出埃及记 23:16–17"> 当时犹太人的住棚节近了。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 12:46; 约翰福音 7:5; 路加福音 8:19"> 耶稣的弟兄就对他说：「你离开这里上犹太去吧，叫你的门徒也看见你所行的事。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 18:20; 箴言 18:1–2; 马太福音 23:5"> 人要显扬名声，没有在暗处行事的；你如果行这些事，就当将自己显明给世人看。」</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 3:21; 约翰福音 1:11–13; 弥迦书 7:5–6"> 因为连他的弟兄说这话，是因为不信他。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 7:8; 约翰福音 2:4; 约翰福音 7:30"> 耶稣就对他们说：「我的时候还没有到；你们的时候常是方便的。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 15:18–19; 约翰福音 3:19; 加拉太书 4:16"> 世人不能恨你们，却是恨我，因为我指证他们所做的事是恶的。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 7:6; 约翰福音 8:20; 约翰福音 7:30"> 你们上去过节吧，我现在不上去过这节，因为我的时候还没有满。」</span>
<span className="v" id="v9" data-v="9"> 耶稣说了这话，仍旧住在加利利。</span>
</div>
</div>

## 耶稣过住棚节

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="阿摩司书 5:13; 马太福音 10:16; 以赛亚书 42:2–3"> 但他弟兄上去以后，他也上去过节，不是明去，似乎是暗去的。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 11:56"> 正在节期，犹太人寻找耶稣，说：「他在哪里？」</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 7:40–43; 约翰福音 9:16; 约翰福音 7:32"> 众人为他纷纷议论，有的说：「他是好人。」有的说：「不然，他是迷惑众人的。」</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 9:22; 约翰福音 19:38; 约翰福音 20:19"> 只是没有人明明地讲论他，因为怕犹太人。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="约翰福音 7:28; 路加福音 19:47; 约翰福音 7:37"> 到了节期，耶稣上殿里去教训人。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 4:22; 马太福音 7:28–29; 马太福音 13:54"> 犹太人就希奇，说：「这个人没有学过，怎么明白书呢？」</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 14:10; 约翰福音 14:24; 约翰福音 17:8"> 耶稣说：「我的教训不是我自己的，乃是那差我来者的。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 8:31–32; 约翰福音 8:43; 耶利米书 31:33–34"> 人若立志遵着他的旨意行，就必晓得这教训或是出于 神，或是我凭着自己说的。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 5:41; 哥林多前书 10:31–33; 约翰福音 13:31–32"> 人凭着自己说，是求自己的荣耀；惟有求那差他来者的荣耀，这人是真的，在他心里没有不义。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 1:17; 约翰福音 11:53; 马太福音 12:14"> 摩西岂不是传律法给你们吗？你们却没有一个人守律法。为什么想要杀我呢？」</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 10:20; 约翰福音 8:48; 约翰福音 8:52"> 众人回答说：「你是被鬼附着了！谁想要杀你？」</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 7:23; 约翰福音 5:2–11"> 耶稣说：「我做了一件事，你们都以为希奇。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 12:3; 创世记 17:10–14; 罗马书 4:9–11"> 摩西传割礼给你们（其实不是从摩西起的，乃是从祖先起的），因此你们也在安息日给人行割礼。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 12:5; 约翰福音 5:14–16; 马太福音 12:2"> 人若在安息日受割礼，免得违背摩西的律法，我在安息日叫一个人全然好了，你们就向我生气吗？</span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 11:3–4; 雅各书 2:9; 约翰福音 8:15"> 不可按外貌断定是非，总要按公平断定是非。」</span>
</div>
</div>

## 这是基督吗？

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 7:10–11"> 耶路撒冷人中有的说：「这不是他们想要杀的人吗？</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太后书 1:7–8; 约翰福音 7:48; 约翰福音 12:42"> 你看他还明明地讲道，他们也不向他说什么，难道官长真知道这是基督吗？</span>
<span className="v" id="v27" data-v="27" data-xref="弥迦书 5:2; 约翰福音 7:41–42; 约翰福音 6:42"> 然而，我们知道这个人从哪里来；只是基督来的时候，没有人知道他从哪里来。」</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 8:42; 约翰福音 8:19; 约翰福音 8:26"> 那时，耶稣在殿里教训人，大声说：「你们也知道我，也知道我从哪里来；我来并不是由于自己。但那差我来的是真的。你们不认识他，</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 8:55; 马太福音 11:27; 约翰福音 17:18"> 我却认识他；因为我是从他来的，他也是差了我来。」</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 8:20; 约翰福音 10:39; 约翰福音 7:6"> 他们就想要捉拿耶稣；只是没有人下手，因为他的时候还没有到。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 12:42; 马太福音 12:23; 约翰福音 10:41–42"> 但众人中间有好些信他的，说：「基督来的时候，他所行的神迹岂能比这人所行的更多吗？」</span>
</div>
</div>

## 差役捉拿耶稣

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="约翰福音 18:3; 路加福音 22:52–53; 约翰福音 11:47–48"> 法利赛人听见众人为耶稣这样纷纷议论，祭司长和法利赛人就打发差役去捉拿他。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 16:5; 约翰福音 13:33; 马可福音 16:19"> 于是耶稣说：「我还有不多的时候和你们同在，以后就回到差我来的那里去。</span>
<span className="v" id="v34" data-v="34" data-xref="箴言 1:24–31; 约翰福音 13:33–36; 约翰福音 14:6"> 你们要找我，却找不着；我所在的地方你们不能到。」</span>
<span className="v" id="v35" data-v="35" data-xref="雅各书 1:1; 以赛亚书 11:12; 西番雅书 3:10"> 犹太人就彼此对问说：「这人要往哪里去，叫我们找不着呢？难道他要往散住希腊中的犹太人那里去教训希腊人吗？</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 3:9; 约翰福音 7:34; 约翰福音 12:34"> 他说：『你们要找我，却找不着；我所在的地方，你们不能到』，这话是什么意思呢？」</span>
</div>
</div>

## 活水的江河

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="以赛亚书 55:1; 约翰福音 4:14; 约翰福音 6:35"> 节期的末日，就是最大之日，耶稣站着高声说：「人若渴了，可以到我这里来喝。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 4:14; 以赛亚书 44:3; 以赛亚书 58:11"> 信我的人就如经上所说：『从他腹中要流出活水的江河来。』」</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 2:17; 约珥书 2:28; 约翰福音 14:16–17"> 耶稣这话是指着信他之人要受圣灵说的。那时还没有赐下圣灵来，因为耶稣尚未得着荣耀。</span>
</div>
</div>

## 群众因耶稣而纷争

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="马太福音 21:11; 约翰福音 1:21; 约翰福音 6:14"> 众人听见这话，有的说：「这真是那先知。」</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 7:52; 约翰福音 1:46; 约翰福音 1:49"> 有的说：「这是基督。」但也有的说：「基督岂是从加利利出来的吗？</span>
<span className="v" id="v42" data-v="42" data-xref="弥迦书 5:2; 马太福音 2:5; 路加福音 2:4"> 经上岂不是说『基督是大卫的后裔，从大卫本乡伯利恒出来的』吗？」</span>
<span className="v" id="v43" data-v="43" data-xref="约翰福音 9:16; 约翰福音 10:19; 约翰福音 7:12"> 于是众人因着耶稣起了纷争。</span>
<span className="v" id="v44" data-v="44" data-xref="约翰福音 7:30; 使徒行传 23:11; 约翰福音 8:20"> 其中有人要捉拿他，只是无人下手。</span>
</div>
</div>

## 犹太领袖的不信

<div className="bt">
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="约翰福音 7:32; 使徒行传 5:21–27"> 差役回到祭司长和法利赛人那里。他们对差役说：「你们为什么没有带他来呢？」</span>
<span className="v" id="v46" data-v="46" data-xref="马太福音 7:28–29; 路加福音 4:22; 约翰福音 7:26"> 差役回答说：「从来没有像他这样说话的！」</span>
<span className="v" id="v47" data-v="47" data-xref="约翰福音 7:12; 哥林多后书 6:8; 列王纪下 18:32"> 法利赛人说：「你们也受了迷惑吗？</span>
<span className="v" id="v48" data-v="48" data-xref="约翰福音 12:42; 哥林多前书 1:20; 哥林多前书 2:8"> 官长或是法利赛人岂有信他的呢？</span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前书 1:20–21; 约翰福音 9:40; 约翰福音 9:34"> 但这些不明白律法的百姓是被咒诅的！」</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 19:39; 约翰福音 3:1–2"> 内中有尼哥德慕，就是从前去见耶稣的，对他们说：</span>
<span className="v" id="v51" data-v="51" data-xref="箴言 18:13; 申命记 1:17; 申命记 19:15–19"> 「不先听本人的口供，不知道他所做的事，难道我们的律法还定他的罪吗？」</span>
<span className="v" id="v52" data-v="52" data-xref="约翰福音 7:41; 约翰福音 1:46; 以赛亚书 9:1–2"> 他们回答说：「你也是出于加利利吗？你且去查考，就可知道加利利没有出过先知。」</span>
</div>

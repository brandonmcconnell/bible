## 行淫时被捉的女人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 21:1; 马可福音 11:1; 路加福音 19:37"> 于是各人都回家去了；耶稣却往橄榄山去，</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 26:55; 路加福音 4:20; 路加福音 21:37"> 清早又回到殿里。众百姓都到他那里去，他就坐下，教训他们。</span>
<span className="v" id="v3" data-v="3"> 文士和法利赛人带着一个行淫时被拿的妇人来，叫她站在当中，</span>
<span className="v" id="v4" data-v="4"> 就对耶稣说：「夫子，这妇人是正行淫之时被拿的。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 20:10; 申命记 22:21–24; 以西结书 16:38–40"> 摩西在律法上吩咐我们把这样的妇人用石头打死。你说该把她怎么样呢？」</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 17:13; 路加福音 10:25; 传道书 3:7"> 他们说这话，乃试探耶稣，要得着告他的把柄。耶稣却弯着腰，用指头在地上画字。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 7:1–5; 罗马书 2:21–25; 罗马书 2:1–3"> 他们还是不住地问他，耶稣就直起腰来，对他们说：「你们中间谁是没有罪的，谁就可以先拿石头打她。」</span>
<span className="v" id="v8" data-v="8"> 于是又弯着腰，用指头在地上画字。</span>
<span className="v" id="v9" data-v="9" data-xref="传道书 7:22; 罗马书 2:15; 约翰一书 3:20"> 他们听见这话，就从老到少，一个一个地都出去了，只剩下耶稣一人，还有那妇人仍然站在当中。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 41:11–12"> 耶稣就直起腰来，对她说：「妇人，那些人在哪里呢？没有人定你的罪吗？」</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 3:17; 约翰福音 5:14; 以赛亚书 1:16–18"> 她说：「主啊，没有。」耶稣说：「我也不定你的罪。去吧，从此不要再犯罪了！」</span>
</div>
</div>

## 耶稣是世界的光

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约翰福音 12:46; 约翰福音 9:5; 约翰福音 12:35"> 耶稣又对众人说：「我是世界的光。跟从我的，就不在黑暗里走，必要得着生命的光。」</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 5:31–47"> 法利赛人对他说：「你是为自己作见证，你的见证不真。」</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 16:28; 约翰福音 13:3; 约翰福音 8:42"> 耶稣说：「我虽然为自己作见证，我的见证还是真的；因我知道我从哪里来，往哪里去；你们却不知道我从哪里来，往哪里去。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 16:7; 约翰福音 7:24; 约翰福音 12:47"> 你们是以外貌<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是凭肉身">a</a></sup>判断人，我却不判断人。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 17:31; 约翰福音 8:29; 约翰福音 16:32"> 就是判断人，我的判断也是真的；因为不是我独自在这里，还有差我来的父与我同在。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 19:15; 申命记 17:6; 希伯来书 10:28"> 你们的律法上也记着说：『两个人的见证是真的。』</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 8:38; 约翰福音 8:58; 约翰福音 8:25"> 我是为自己作见证，还有差我来的父也是为我作见证。」</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 16:3; 约翰福音 8:54–55; 约翰福音 14:6–9"> 他们就问他说：「你的父在哪里？」耶稣回答说：「你们不认识我，也不认识我的父；若是认识我，也就认识我的父。」</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 7:30; 约翰福音 7:8; 马可福音 12:41"> 这些话是耶稣在殿里的库房、教训人时所说的，也没有人拿他，因为他的时候还没有到。</span>
</div>
</div>

## 我所去的地方你们不能到

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约翰福音 7:34; 约翰福音 8:24; 哥林多前书 15:17–18"> 耶稣又对他们说：「我要去了，你们要找我，并且你们要死在罪中。我所去的地方，你们不能到。」</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 8:52; 诗篇 22:6; 约翰福音 8:48"> 犹太人说：「他说『我所去的地方，你们不能到』，难道他要自尽吗？」</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 3:31; 约翰福音 17:14; 约翰福音 17:16"> 耶稣对他们说：「你们是从下头来的，我是从上头来的；你们是属这世界的，我不是属这世界的。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 3:36; 马可福音 16:16; 约翰福音 3:18"> 所以我对你们说，你们要死在罪中。你们若不信我是基督，必要死在罪中。」</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 5:17–29; 路加福音 22:67; 约翰福音 1:22"> 他们就问他说：「你是谁？」耶稣对他们说：「就是我从起初所告诉你们的。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 15:15; 约翰福音 12:47–50; 约翰福音 8:40"> 我有许多事讲论你们，判断你们；但那差我来的是真的，我在他那里所听见的，我就传给世人。」</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 6:9; 约翰福音 8:43; 哥林多后书 4:3–4"> 他们不明白耶稣是指着父说的。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 5:19; 约翰福音 5:30; 约翰福音 6:38"> 所以耶稣说：「你们举起人子以后，必知道我是基督，并且知道我没有一件事是凭着自己做的。我说这些话乃是照着父所教训我的。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 6:38; 约翰福音 16:32; 约翰福音 4:34"> 那差我来的是与我同在；他没有撇下我独自在这里，因为我常做他所喜悦的事。」</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 7:31; 约翰福音 2:23; 约翰福音 11:45"> 耶稣说这话的时候，就有许多人信他。</span>
</div>
</div>

## 真理必使你们得自由

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰二书 1:9; 约翰福音 15:4–9; 提摩太后书 3:14"> 耶稣对信他的犹太人说：「你们若常常遵守我的道，就真是我的门徒；</span>
<span className="v" id="v32" data-v="32" data-xref="罗马书 8:2; 约翰福音 8:36; 约翰福音 17:17"> 你们必晓得真理，真理必叫你们得以自由。」</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 3:9; 约翰福音 8:39; 创世记 15:13"> 他们回答说：「我们是亚伯拉罕的后裔，从来没有作过谁的奴仆。你怎么说『你们必得以自由』呢？」</span>
<span className="v" id="v34" data-v="34" data-xref="罗马书 6:16; 彼得后书 2:19; 箴言 5:22"> 耶稣回答说：「我实实在在地告诉你们，所有犯罪的就是罪的奴仆。</span>
<span className="v" id="v35" data-v="35" data-xref="加拉太书 4:4–7; 路加福音 15:31; 罗马书 8:15–17"> 奴仆不能永远住在家里；儿子是永远住在家里。</span>
<span className="v" id="v36" data-v="36" data-xref="哥林多后书 3:17; 加拉太书 5:1; 罗马书 8:2"> 所以天父的儿子若叫你们自由，你们就真自由了。</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前书 2:14; 约翰福音 8:45–47; 约翰福音 7:1"> 我知道你们是亚伯拉罕的子孙，你们却想要杀我，因为你们心里容不下我的道。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 5:19; 约翰福音 8:44; 约翰福音 8:41"> 我所说的是在我父那里看见的；你们所行的是在你们的父那里听见的。」</span>
</div>
</div>

## 你们的父是魔鬼

<div className="bt">
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="加拉太书 3:7; 约翰福音 8:37; 罗马书 9:7"> 他们说：「我们的父就是亚伯拉罕。」耶稣说：「你们若是亚伯拉罕的儿子，就必行亚伯拉罕所行的事。</span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 8:26; 加拉太书 4:29; 加拉太书 4:16"> 我将在 神那里所听见的真理告诉了你们，现在你们却想要杀我，这不是亚伯拉罕所行的事。</span>
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 64:8; 约翰福音 8:38; 以赛亚书 63:16"> 你们是行你们父所行的事。」他们说：「我们不是从淫乱生的；我们只有一位父，就是 神。」</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 12:49; 约翰福音 14:10; 约翰福音 17:8"> 耶稣说：「倘若 神是你们的父，你们就必爱我；因为我本是出于 神，也是从 神而来，并不是由着自己来，乃是他差我来。</span>
<span className="v" id="v43" data-v="43" data-xref="约翰福音 12:39–40; 罗马书 8:7–8; 约翰福音 7:17"> 你们为什么不明白我的话呢？无非是因你们不能听我的道。</span>
<span className="v" id="v44" data-v="44" data-xref="使徒行传 13:10; 约翰一书 3:12; 约翰一书 3:8–10"> 你们是出于你们的父魔鬼，你们父的私欲你们偏要行。他从起初是杀人的，不守真理，因他心里没有真理。他说谎是出于自己；因他本来是说谎的，也是说谎之人的父。</span>
<span className="v" id="v45" data-v="45" data-xref="提摩太后书 4:3–4; 加拉太书 4:16; 约翰福音 18:37"> 我将真理告诉你们，你们就因此不信我。</span>
<span className="v" id="v46" data-v="46" data-xref="希伯来书 4:15; 约翰福音 16:8; 彼得前书 2:22"> 你们中间谁能指证我有罪呢？我既然将真理告诉你们，为什么不信我呢？</span>
<span className="v" id="v47" data-v="47" data-xref="约翰福音 10:26–27; 约翰二书 1:9; 约翰福音 18:37"> 出于 神的，必听 神的话；你们不听，因为你们不是出于 神。」</span>
</div>
</div>

## 还没有亚伯拉罕就有了我

<div className="bt">
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="约翰福音 7:20; 约翰福音 8:52; 马太福音 10:5"> 犹太人回答说：「我们说你是撒马利亚人，并且是鬼附着的，这话岂不正对吗？」</span>
<span className="v" id="v49" data-v="49" data-xref="彼得前书 2:23; 以赛亚书 49:3; 约翰福音 13:31–32"> 耶稣说：「我不是鬼附着的；我尊敬我的父，你们倒轻慢我。</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 5:41; 约翰福音 8:54; 约翰福音 7:18"> 我不求自己的荣耀，有一位为我求荣耀、定是非的。</span>
<span className="v" id="v51" data-v="51" data-xref="约翰福音 11:25–26; 约翰福音 5:24; 约翰福音 3:15–16"> 我实实在在地告诉你们，人若遵守我的道，就永远不见死。」</span>
<span className="v" id="v52" data-v="52" data-xref="约翰福音 9:24; 约翰福音 8:48; 希伯来书 2:9"> 犹太人对他说：「现在我们知道你是鬼附着的。亚伯拉罕死了，众先知也死了，你还说：『人若遵守我的道，就永远不尝死味。』</span>
<span className="v" id="v53" data-v="53" data-xref="约翰福音 4:12; 罗马书 9:5; 希伯来书 7:1–7"> 难道你比我们的祖宗亚伯拉罕还大吗？他死了，众先知也死了，你将自己当作什么人呢？」</span>
<span className="v" id="v54" data-v="54" data-xref="约翰福音 8:50; 箴言 25:27; 彼得后书 1:17"> 耶稣回答说：「我若荣耀自己，我的荣耀就算不得什么；荣耀我的乃是我的父，就是你们所说是你们的 神。</span>
<span className="v" id="v55" data-v="55" data-xref="约翰福音 8:19; 约翰福音 8:44; 约翰福音 7:28–29"> 你们未曾认识他；我却认识他。我若说不认识他，我就是说谎的，像你们一样；但我认识他，也遵守他的道。</span>
<span className="v" id="v56" data-v="56" data-xref="希伯来书 11:13; 创世记 22:18; 加拉太书 3:7–9"> 你们的祖宗亚伯拉罕欢欢喜喜地仰望我的日子，既看见了就快乐。」</span>
<span className="v" id="v57" data-v="57"> 犹太人说：「你还没有五十岁，岂见过亚伯拉罕呢？」</span>
<span className="v" id="v58" data-v="58" data-xref="出埃及记 3:14; 歌罗西书 1:17; 约翰福音 17:5"> 耶稣说：「我实实在在地告诉你们，还没有亚伯拉罕就有了我。」</span>
<span className="v" id="v59" data-v="59" data-xref="约翰福音 11:8; 约翰福音 10:30–33; 约翰福音 10:39–40"> 于是他们拿石头要打他；耶稣却躲藏，从殿里出去了。</span>
</div>
</div>

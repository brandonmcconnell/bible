## 耶稣给五千人吃饱

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 6:31–44; 约翰福音 6:23; 路加福音 5:1"> 这事以后，耶稣渡过加利利海，就是提比哩亚海。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 4:24–25; 马太福音 12:15; 马太福音 15:30–31"> 有许多人因为看见他在病人身上所行的神迹，就跟随他。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 6:15; 路加福音 9:28; 路加福音 6:12–13"> 耶稣上了山，和门徒一同坐在那里。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 2:13; 约翰福音 11:55; 约翰福音 5:1"> 那时犹太人的逾越节近了。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 15:33; 路加福音 9:12–13; 马太福音 14:14–15"> 耶稣举目看见许多人来，就对腓力说：「我们从哪里买饼叫这些人吃呢？」（</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 22:1; 申命记 13:3; 历代志下 32:31"> 他说这话是要试验腓力；他自己原知道要怎样行。）</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 11:21–22; 马可福音 6:37; 约翰福音 12:5"> 腓力回答说：「就是二十两银子的饼，叫他们各人吃一点也是不够的。」</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 1:40–44; 马太福音 4:18"> 有一个门徒，就是西门·彼得的兄弟安得烈，对耶稣说：</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 4:42–44; 马太福音 14:17; 马可福音 6:38"> 「在这里有一个孩童，带着五个大麦饼、两条鱼，只是分给这许多人还算什么呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 9:14–16; 马太福音 15:35–36; 马可福音 6:39–41"> 耶稣说：「你们叫众人坐下。」原来那地方的草多，众人就坐下，数目约有五千。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 6:23; 帖撒罗尼迦前书 5:18; 马太福音 15:36"> 耶稣拿起饼来，祝谢了，就分给那坐着的人；分鱼也是这样，都随着他们所要的。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 1:53; 尼希米记 9:25; 尼希米记 8:10"> 他们吃饱了，耶稣对门徒说：「把剩下的零碎收拾起来，免得有糟蹋的。」</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 11:24–25; 列王纪下 4:2–7; 哥林多后书 9:8–9"> 他们便将那五个大麦饼的零碎，就是众人吃了剩下的，收拾起来，装满了十二个篮子。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 18:15–18; 马太福音 21:11; 使徒行传 7:37"> 众人看见耶稣所行的神迹，就说：「这真是那要到世间来的先知！」</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 18:36; 约翰福音 6:15–21; 约翰福音 7:3–4"> 耶稣既知道众人要来强逼他作王，就独自又退到山上去了。</span>
</div>
</div>

## 耶稣在海面上行走

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16"> 到了晚上，他的门徒下海边去，</span>
<span className="v" id="v17" data-v="17" data-xref="马可福音 6:45; 约翰福音 6:24–25; 约翰福音 2:12"> 上了船，要过海往迦百农去。天已经黑了，耶稣还没有来到他们那里。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 107:25; 诗篇 135:7; 马太福音 14:24"> 忽然狂风大作，海就翻腾起来。</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 6:47–49; 马太福音 14:25–26; 约伯记 9:8"> 门徒摇橹，约行了十里多路，看见耶稣在海面上走，渐渐近了船，他们就害怕。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 14:27–31; 以赛亚书 43:1–2; 以赛亚书 44:8"> 耶稣对他们说：「是我，不要怕！」</span>
<span className="v" id="v21" data-v="21" data-xref="马可福音 6:51; 马太福音 14:32–33; 启示录 3:20"> 门徒就喜欢接他上船，船立时到了他们所要去的地方。</span>
</div>
</div>

## 耶稣是生命的粮

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马可福音 6:45; 马太福音 14:22; 约翰福音 6:2"> 第二日，站在海那边的众人知道那里没有别的船，只有一只小船，又知道耶稣没有同他的门徒上船，乃是门徒自己去的。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 6:1; 约翰福音 6:11–12"> 然而，有几只小船从提比哩亚来，靠近主祝谢后分饼给人吃的地方。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 6:17; 路加福音 8:40; 马可福音 6:53"> 众人见耶稣和门徒都不在那里，就上了船，往迦百农去找耶稣。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 1:38–39; 马太福音 23:7"> 既在海那边找着了，就对他说：「拉比，是几时到这里来的？」</span>
<span className="v" id="v26" data-v="26" data-xref="雅各书 4:3–4; 腓立比书 3:19; 腓立比书 2:21"> 耶稣回答说：「我实实在在地告诉你们，你们找我，并不是因见了神迹，乃是因吃饼得饱。</span>
<span className="v" id="v27" data-v="27" data-xref="歌罗西书 3:2; 以赛亚书 55:2; 约翰福音 6:54"> 不要为那必坏的食物劳力，要为那存到永生的食物劳力，就是人子要赐给你们的，因为人子是父 神所印证的。」</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 16:30; 使徒行传 9:6; 马太福音 19:16"> 众人问他说：「我们当行什么才算做 神的工呢？」</span>
<span className="v" id="v29" data-v="29" data-xref="约翰一书 3:23; 使徒行传 16:31; 约翰福音 3:36"> 耶稣回答说：「信 神所差来的，这就是做 神的工。」</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 12:37; 约翰福音 10:38; 哥林多前书 1:22"> 他们又说：「你行什么神迹，叫我们看见就信你；你到底做什么事呢？</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米记 9:15; 诗篇 105:40; 诗篇 78:24–25"> 我们的祖宗在旷野吃过吗哪，如经上写着说：『他从天上赐下粮来给他们吃。』」</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 15:1; 约翰福音 6:58; 出埃及记 16:4"> 耶稣说：「我实实在在地告诉你们，那从天上来的粮不是摩西赐给你们的，乃是我父将天上来的真粮赐给你们。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 8:42; 约翰福音 17:8; 约翰福音 3:13"> 因为 神的粮就是那从天上降下来、赐生命给世界的。」</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 4:15; 约翰福音 6:26; 诗篇 4:6"> 他们说：「主啊，常将这粮赐给我们！」</span>
<span className="v" id="v35" data-v="35" data-xref="约翰福音 6:48–58; 启示录 22:17; 约翰福音 6:41"> 耶稣说：「我就是生命的粮。到我这里来的，必定不饿；信我的，永远不渴。</span>
<span className="v" id="v36" data-v="36" data-xref="彼得前书 1:8–9; 路加福音 16:31; 约翰福音 12:37"> 只是我对你们说过，你们已经看见我，还是不信。</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 11:28; 约翰福音 6:39; 约翰福音 17:24"> 凡父所赐给我的人必到我这里来；到我这里来的，我总不丢弃他。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 5:30; 约翰福音 4:34; 约翰福音 3:31"> 因为我从天上降下来，不是要按自己的意思行，乃是要按那差我来者的意思行。</span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 17:12; 约翰福音 6:40; 约翰福音 18:9"> 差我来者的意思就是：他所赐给我的，叫我一个也不失落，在末日却叫他复活。</span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 6:54; 约翰福音 5:24; 罗马书 6:23"> 因为我父的意思是叫一切见子而信的人得永生，并且在末日我要叫他复活。」</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 6:51–52; 约翰福音 6:48; 约翰福音 6:33"> 犹太人因为耶稣说「我是从天上降下来的粮」，就私下议论他，</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 4:22; 马可福音 6:3; 马太福音 13:55–56"> 说：「这不是约瑟的儿子耶稣吗？他的父母我们岂不认得吗？他如今怎么说『我是从天上降下来的』呢？」</span>
<span className="v" id="v43" data-v="43" data-xref="希伯来书 4:13; 约翰福音 6:64; 马可福音 9:33"> 耶稣回答说：「你们不要大家议论。</span>
<span className="v" id="v44" data-v="44" data-xref="约翰福音 6:65; 约翰福音 6:39–40; 马太福音 11:25–27"> 若不是差我来的父吸引人，就没有能到我这里来的；到我这里来的，在末日我要叫他复活。</span>
<span className="v" id="v45" data-v="45" data-xref="以赛亚书 54:13; 耶利米书 31:33–34; 希伯来书 10:16"> 在先知书上写着说：『他们都要蒙 神的教训。』凡听见父之教训又学习的，就到我这里来。</span>
<span className="v" id="v46" data-v="46" data-xref="约翰福音 1:18; 约翰福音 7:29; 马太福音 11:27"> 这不是说有人看见过父，惟独从 神来的，他看见过父。</span>
<span className="v" id="v47" data-v="47" data-xref="约翰福音 3:36; 歌罗西书 3:3–4; 罗马书 5:9–10"> 我实实在在地告诉你们，信的人有永生。</span>
<span className="v" id="v48" data-v="48" data-xref="约翰福音 6:51; 哥林多前书 11:24–25; 哥林多前书 10:16–17"> 我就是生命的粮。</span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前书 10:3–5; 犹大书 1:5; 撒迦利亚书 1:5"> 你们的祖宗在旷野吃过吗哪，还是死了。</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 6:33; 约翰福音 6:51; 罗马书 8:10"> 这是从天上降下来的粮，叫人吃了就不死。</span>
<span className="v" id="v51" data-v="51" data-xref="路加福音 22:19; 约翰福音 6:33; 希伯来书 10:5–12"> 我是从天上降下来生命的粮；人若吃这粮，就必永远活着。我所要赐的粮就是我的肉，为世人之生命所赐的。」</span>
<span className="v" id="v52" data-v="52" data-xref="约翰福音 9:16; 约翰福音 10:19; 约翰福音 6:41"> 因此，犹太人彼此争论说：「这个人怎能把他的肉给我们吃呢？」</span>
<span className="v" id="v53" data-v="53" data-xref="约翰一书 5:12; 马太福音 26:26–28; 约翰福音 6:55"> 耶稣说：「我实实在在地告诉你们，你们若不吃人子的肉，不喝人子的血，就没有生命在你们里面。</span>
<span className="v" id="v54" data-v="54" data-xref="约翰福音 6:39–40; 约翰福音 6:27; 腓立比书 3:7–10"> 吃我肉、喝我血的人就有永生，在末日我要叫他复活。</span>
<span className="v" id="v55" data-v="55" data-xref="约翰福音 15:1; 约翰福音 8:31; 约翰福音 6:32"> 我的肉真是可吃的，我的血真是可喝的。</span>
<span className="v" id="v56" data-v="56" data-xref="约翰一书 3:24; 约翰福音 15:4–5; 约翰福音 14:20"> 吃我肉、喝我血的人常在我里面，我也常在他里面。</span>
<span className="v" id="v57" data-v="57" data-xref="加拉太书 2:20; 约翰福音 5:26; 约翰福音 17:21"> 永活的父怎样差我来，我又因父活着；照样，吃我肉的人也要因我活着。</span>
<span className="v" id="v58" data-v="58" data-xref="约翰福音 3:36; 约翰福音 6:47–51; 约翰福音 6:41"> 这就是从天上降下来的粮。吃这粮的人就永远活着，不像你们的祖宗吃过吗哪还是死了。」</span>
<span className="v" id="v59" data-v="59" data-xref="约翰福音 6:24; 箴言 8:1–3; 路加福音 4:31"> 这些话是耶稣在迦百农会堂里教训人说的。</span>
</div>
</div>

## 永生的话语

<div className="bt">
<div className="bp">
<span className="v" id="v60" data-v="60" data-xref="约翰福音 6:66; 约翰福音 8:43; 约翰福音 8:31"> 他的门徒中有好些人听见了，就说：「这话甚难，谁能听呢？」</span>
<span className="v" id="v61" data-v="61" data-xref="约翰福音 2:24–25; 约翰福音 6:64; 约翰福音 21:17"> 耶稣心里知道门徒为这话议论，就对他们说：「这话是叫你们厌弃<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是跌倒">a</a></sup>吗？</span>
<span className="v" id="v62" data-v="62" data-xref="马可福音 16:19; 约翰福音 3:13; 约翰福音 17:4–5"> 倘或你们看见人子升到他原来所在之处，怎么样呢？</span>
<span className="v" id="v63" data-v="63" data-xref="加拉太书 5:25; 希伯来书 4:12; 诗篇 119:93"> 叫人活着的乃是灵，肉体是无益的。我对你们所说的话就是灵，就是生命。</span>
<span className="v" id="v64" data-v="64" data-xref="约翰福音 10:26; 提摩太后书 2:19; 希伯来书 4:13"> 只是你们中间有不信的人。」耶稣从起头就知道谁不信他，谁要卖他。</span>
<span className="v" id="v65" data-v="65" data-xref="约翰福音 6:44–45; 约翰福音 6:37; 约翰福音 3:27"> 耶稣又说：「所以我对你们说过，若不是蒙我父的恩赐，没有人能到我这里来。」</span>
<span className="v" id="v66" data-v="66" data-xref="路加福音 9:62; 约翰一书 2:19; 希伯来书 10:38"> 从此，他门徒中多有退去的，不再和他同行。</span>
<span className="v" id="v67" data-v="67" data-xref="路得记 1:11–18; 约翰福音 6:70; 路加福音 14:25–33"> 耶稣就对那十二个门徒说：「你们也要去吗？」</span>
<span className="v" id="v68" data-v="68" data-xref="诗篇 73:25; 约翰福音 5:24; 约翰一书 5:11–13"> 西门·彼得回答说：「主啊，你有永生之道，我们还归从谁呢？</span>
<span className="v" id="v69" data-v="69" data-xref="约翰福音 11:27; 路加福音 9:20; 马可福音 8:29"> 我们已经信了，又知道你是 神的圣者。」</span>
<span className="v" id="v70" data-v="70" data-xref="约翰福音 13:27; 约翰福音 13:2; 约翰福音 17:12"> 耶稣说：「我不是拣选了你们十二个门徒吗？但你们中间有一个是魔鬼。」</span>
<span className="v" id="v71" data-v="71" data-xref="马太福音 26:14–16; 犹大书 1:4; 使徒行传 1:16–20"> 耶稣这话是指着加略人西门的儿子犹大说的；他本是十二个门徒里的一个，后来要卖耶稣的。</span>

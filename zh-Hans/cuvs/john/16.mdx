## 忧愁变为喜乐

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰福音 7:33; 使徒行传 1:3; 约翰福音 14:18–24"> 「等不多时，你们就不得见我；再等不多时，你们还要见我。」</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 16:16; 马可福音 9:32; 约翰福音 16:5"> 有几个门徒就彼此说：「他对我们说：『等不多时，你们就不得见我；再等不多时，你们还要见我』；又说：『因我往父那里去。』这是什么意思呢？」</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 24:25; 马太福音 16:9–11; 希伯来书 5:12"> 门徒彼此说：「他说『等不多时』到底是什么意思呢？我们不明白他所说的话。」</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 16:30; 约翰福音 16:16; 约翰福音 14:19"> 耶稣看出他们要问他，就说：「我说『等不多时，你们就不得见我；再等不多时，你们还要见我』，你们为这话彼此相问吗？</span>
<span className="v" id="v20" data-v="20" data-xref="雅各书 1:2; 马太福音 5:4; 诗篇 126:5–6"> 我实实在在地告诉你们，你们将要痛哭、哀号，世人倒要喜乐；你们将要忧愁，然而你们的忧愁要变为喜乐。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 113:9; 以赛亚书 13:8; 帖撒罗尼迦前书 5:3"> 妇人生产的时候就忧愁，因为她的时候到了；既生了孩子，就不再记念那苦楚，因为欢喜世上生了一个人。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 1:8; 使徒行传 13:52; 约翰福音 16:6"> 你们现在也是忧愁，但我要再见你们，你们的心就喜乐了；这喜乐也没有人能夺去。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 15:7; 约翰福音 14:13–14; 马太福音 21:22"> 到那日，你们什么也就不问我了。我实实在在地告诉你们，你们若向父求什么，他必因我的名赐给你们。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 7:7–8; 雅各书 4:2–3; 约翰福音 15:11"> 向来你们没有奉我的名求什么，如今你们求，就必得着，叫你们的喜乐可以满足。」</span>
</div>

## 我已经胜过世界

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 16:12; 马可福音 4:13; 马太福音 13:34–35"> 「这些事，我是用比喻对你们说的；时候将到，我不再用比喻对你们说，乃要将父明明地告诉你们。</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 8:34; 约翰福音 17:24; 约翰福音 17:19"> 到那日，你们要奉我的名祈求；我并不对你们说，我要为你们求父。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 14:21; 约翰福音 14:23; 约翰福音 17:23"> 父自己爱你们；因为你们已经爱我，又信我是从父出来的。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 13:1; 约翰福音 13:3; 约翰福音 8:14"> 我从父出来，到了世界；我又离开世界，往父那里去。」</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 16:25"> 门徒说：「如今你是明说，并不用比喻了。</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 21:17; 约翰福音 17:8; 约翰福音 16:17"> 现在我们晓得你凡事都知道，也不用人问你，因此我们信你是从 神出来的。」</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 9:44–45; 约翰福音 13:38"> 耶稣说：「现在你们信吗？</span>
<span className="v" id="v32" data-v="32" data-xref="撒迦利亚书 13:7; 马太福音 26:31; 约翰福音 8:29"> 看哪，时候将到，且是已经到了，你们要分散，各归自己的地方去，留下我独自一人；其实我不是独自一人，因为有父与我同在。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 14:27; 约翰一书 5:4; 帖撒罗尼迦后书 3:16"> 我将这些事告诉你们，是要叫你们在我里面有平安。在世上，你们有苦难；但你们可以放心，我已经胜了世界。」</span>

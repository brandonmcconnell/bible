## 耶稣的祷告

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 13:31–32; 约翰福音 17:4–5; 腓立比书 2:9–11"> 耶稣说了这话，就举目望天，说：「父啊，时候到了，愿你荣耀你的儿子，使儿子也荣耀你；</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 10:28–29; 约翰福音 6:39; 但以理书 7:14"> 正如你曾赐给他权柄管理凡有血气的，叫他将永生赐给你所赐给他的人。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰一书 5:20; 约翰一书 5:11–12; 耶利米书 9:23–24"> 认识你—独一的真神，并且认识你所差来的耶稣基督，这就是永生。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 4:34; 使徒行传 20:24; 提摩太后书 4:7"> 我在地上已经荣耀你，你所托付我的事，我已成全了。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 1:1–3; 歌罗西书 1:15–17; 约翰福音 10:30"> 父啊，现在求你使我同你享荣耀，就是未有世界以先，我同你所有的荣耀。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 17:26; 约翰福音 14:21–24; 约翰一书 5:20"> 「你从世上赐给我的人，我已将你的名显明与他们。他们本是你的，你将他们赐给我，他们也遵守了你的道。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 7:16–17; 约翰福音 16:15; 约翰福音 14:7–10"> 如今他们知道，凡你所赐给我的，都是从你那里来的；</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 17:14; 约翰福音 15:15; 约翰福音 16:30"> 因为你所赐给我的道，我已经赐给他们，他们也领受了，又确实知道，我是从你出来的，并且信你差了我来。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 9:24; 约翰福音 17:2; 约翰福音 17:6"> 我为他们祈求，不为世人祈求，却为你所赐给我的人祈求，因他们本是你的。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 10:30; 彼得前书 2:9; 启示录 5:8–14"> 凡是我的，都是你的；你的也是我的，并且我因他们得了荣耀。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 6:9; 箴言 18:10; 约翰福音 17:12–18"> 从今以后，我不在世上，他们却在世上；我往你那里去。圣父啊，求你因你所赐给我的名保守他们，叫他们合而为一像我们一样。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 109:6–19; 约翰福音 10:27–28; 约翰福音 18:9"> 我与他们同在的时候，因你所赐给我的名保守了他们，我也护卫了他们；其中除了那灭亡之子，没有一个灭亡的，好叫经上的话得应验。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 12:2; 加拉太书 5:22; 约翰福音 15:11"> 现在我往你那里去，我还在世上说这话，是叫他们心里充满我的喜乐。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 17:16; 约翰福音 15:18–21; 约翰一书 5:19–20"> 我已将你的道赐给他们。世界又恨他们；因为他们不属世界，正如我不属世界一样。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 121:7; 约翰一书 5:18; 马太福音 6:13"> 我不求你叫他们离开世界，只求你保守他们脱离那恶者<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：脱离罪恶">a</a></sup>。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 17:14"> 他们不属世界，正如我不属世界一样。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 15:3; 诗篇 119:160; 以弗所书 5:26"> 求你用真理使他们成圣；你的道就是真理。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 5:20; 约翰福音 20:21; 约翰福音 17:3"> 你怎样差我到世上，我也照样差他们到世上。</span>
<span className="v" id="v19" data-v="19" data-xref="提多书 2:14; 希伯来书 2:11; 约翰福音 17:17"> 我为他们的缘故，自己分别为圣，叫他们也因真理成圣。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 17:6–11; 使徒行传 2:41; 使徒行传 4:4"> 「我不但为这些人祈求，也为那些因他们的话信我的人祈求，</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 12:12; 歌罗西书 3:11–14; 约翰福音 17:11"> 使他们都合而为一。正如你父在我里面，我在你里面，使他们也在我们里面，叫世人可以信你差了我来。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多后书 3:18; 约翰福音 14:20; 马可福音 16:17–20"> 你所赐给我的荣耀，我已赐给他们，使他们合而为一，像我们合而为一。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 17:21; 约翰福音 16:27; 约翰一书 3:1"> 我在他们里面，你在我里面，使他们完完全全地合而为一，叫世人知道你差了我来，也知道你爱他们如同爱我一样。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 17:5; 约翰福音 12:26; 约翰福音 14:3"> 父啊，我在哪里，愿你所赐给我的人也同我在那里，叫他们看见你所赐给我的荣耀；因为创立世界以前，你已经爱我了。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 17:11; 约翰福音 7:29; 约翰福音 17:8"> 公义的父啊，世人未曾认识你，我却认识你；这些人也知道你差了我来。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 17:23; 约翰福音 17:6; 约翰福音 15:9"> 我已将你的名指示他们，还要指示他们，使你所爱我的爱在他们里面，我也在他们里面。」</span>
</div>

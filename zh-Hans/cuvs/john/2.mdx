## 迦拿的婚礼

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 4:46; 箴言 31:10–12; 约翰福音 21:2"> 第三日，在加利利的迦拿有娶亲的筵席，耶稣的母亲在那里。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 1:40–49; 马太福音 10:40–42; 哥林多前书 7:39"> 耶稣和他的门徒也被请去赴席。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 104:15; 腓立比书 4:6; 以赛亚书 24:11"> 酒用尽了，耶稣的母亲对他说：「他们没有酒了。」</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 7:6; 约翰福音 13:1; 约翰福音 7:30"> 耶稣说：「母亲<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是妇人">a</a></sup>，我与你有什么相干？我的时候还没有到。」</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 15:14; 创世记 6:22; 希伯来书 11:8"> 他母亲对用人说：「他告诉你们什么，你们就做什么。」</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 3:25; 希伯来书 9:10; 以弗所书 5:26"> 照犹太人洁净的规矩，有六口石缸摆在那里，每口可以盛两三桶水。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 4:2–6; 约翰福音 2:5; 约翰福音 2:3"> 耶稣对用人说：「把缸倒满了水。」他们就倒满了，直到缸口。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 2:9; 箴言 3:5–6; 罗马书 13:7"> 耶稣又说：「现在可以舀出来，送给管筵席的。」他们就送了去。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 4:46; 约翰福音 7:17; 诗篇 119:100"> 管筵席的尝了那水变的酒，并不知道是哪里来的，只有舀水的用人知道。管筵席的便叫新郎来，</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 7:16–17; 箴言 9:1–6; 路加福音 16:25"> 对他说：「人都是先摆上好酒，等客喝足了，才摆上次的，你倒把好酒留到如今！」</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 20:30–31; 约翰福音 1:14; 约翰福音 3:2"> 这是耶稣所行的头一件神迹，是在加利利的迦拿行的，显出他的荣耀来；他的门徒就信他了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 12:46; 马太福音 13:55–56; 马可福音 6:3"> 这事以后，耶稣与他的母亲、弟兄，和门徒都下迦百农去，在那里住了不多几日。</span>
</div>
</div>

## 洁净圣殿

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 2:41; 约翰福音 11:55; 约翰福音 2:23"> 犹太人的逾越节近了，耶稣就上耶路撒冷去。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 19:45–46; 马可福音 11:15; 马可福音 11:17"> 看见殿里有卖牛、羊、鸽子的，并有兑换银钱的人坐在那里，</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 18:6; 撒迦利亚书 4:6; 哥林多后书 10:4"> 耶稣就拿绳子做成鞭子，把牛羊都赶出殿去，倒出兑换银钱之人的银钱，推翻他们的桌子，</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 21:13; 耶利米书 7:11; 马可福音 11:17"> 又对卖鸽子的说：「把这些东西拿去！不要将我父的殿当作买卖的地方。」</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 69:9; 诗篇 119:139"> 他的门徒就想起经上记着说：「我为你的殿心里焦急，如同火烧。」</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 21:23; 马可福音 8:11; 马可福音 11:27–28"> 因此犹太人问他说：「你既做这些事，还显什么神迹给我们看呢？」</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 14:58; 马可福音 15:29; 马太福音 27:40"> 耶稣回答说：「你们拆毁这殿，我三日内要再建立起来。」</span>
<span className="v" id="v20" data-v="20"> 犹太人便说：「这殿是四十六年才造成的，你三日内就再建立起来吗？」</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 6:19; 哥林多前书 3:16; 以弗所书 2:20–22"> 但耶稣这话是以他的身体为殿。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 12:16; 约翰福音 16:4; 路加福音 24:7–8"> 所以到他从死里复活以后，门徒就想起他说过这话，便信了圣经和耶稣所说的。</span>
</div>
</div>

## 耶稣洞悉人心

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约翰福音 7:31; 路加福音 8:13; 约翰福音 6:14"> 当耶稣在耶路撒冷过逾越节的时候，有许多人看见他所行的神迹，就信了他的名。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 6:64; 希伯来书 4:13; 使徒行传 1:24"> 耶稣却不将自己交托他们；因为他知道万人，</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 13:11; 马太福音 9:4; 约翰福音 6:64"> 也用不着谁见证人怎样，因他知道人心里所存的。</span>
</div>

## 道成肉身

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 1:1; 约翰福音 17:5; 启示录 19:13"> 太初有道，道与 神同在，道就是 神。</span>
<span className="v" id="v2" data-v="2"> 这道太初与 神同在。</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 1:16–17; 哥林多前书 8:6; 启示录 4:11"> 万物是借着他造的；凡被造的，没有一样不是借着他造的。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 8:12; 约翰福音 12:46; 约翰福音 5:26"> 生命在他里头，这生命就是人的光。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 3:19–20; 约翰福音 12:36–40; 哥林多前书 2:14"> 光照在黑暗里，黑暗却不接受光。</span>
<span className="v" id="v6" data-v="6" data-xref="玛拉基书 3:1; 约翰福音 3:28; 以赛亚书 40:3–5"> 有一个人，是从 神那里差来的，名叫约翰。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 19:4; 约翰福音 1:36; 约翰福音 5:33–35"> 这人来，为要作见证，就是为光作见证，叫众人因他可以信。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 1:20; 约翰福音 3:28; 使徒行传 19:4"> 他不是那光，乃是要为光作见证。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 12:46; 约翰福音 1:4; 约翰一书 2:8"> 那光是真光，照亮一切生在世上的人。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 17:25; 约翰一书 3:1; 哥林多前书 2:8"> 他在世界，世界也是借着他造的，世界却不认识他。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:14; 以赛亚书 53:2–3; 约翰福音 3:32"> 他到自己的地方来，自己的人倒不接待他。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 3:26; 罗马书 8:14; 约翰一书 3:1"> 凡接待他的，就是信他名的人，他就赐他们权柄作 神的儿女。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰一书 3:9; 雅各书 1:18; 彼得前书 1:23"> 这等人不是从血气生的，不是从情欲生的，也不是从人意生的，乃是从 神生的。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰一书 4:9; 提摩太前书 3:16; 以赛亚书 40:5"> 道成了肉身，住在我们中间，充充满满地有恩典有真理。我们也见过他的荣光，正是父独生子的荣光。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 3:11; 歌罗西书 1:17; 路加福音 3:16"> 约翰为他作见证，喊着说：「这就是我曾说：『那在我以后来的，反成了在我以前的，因他本来在我以前。』」</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 1:19; 罗马书 5:2; 以弗所书 2:5–10"> 从他丰满的恩典里，我们都领受了，而且恩上加恩。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 6:14; 约翰福音 14:6; 罗马书 3:19–26"> 律法本是借着摩西传的；恩典和真理都是由耶稣基督来的。</span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 1:15; 约翰福音 6:46; 马太福音 11:27"> 从来没有人看见 神，只有在父怀里的独生子将他表明出来。</span>
</div>
</div>

## 施洗约翰的见证

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 3:15–18; 约翰福音 10:24; 使徒行传 19:4"> 约翰所作的见证记在下面：犹太人从耶路撒冷差祭司和利未人到约翰那里，问他说：「你是谁？」</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 1:7–8; 马太福音 3:11–12; 约翰福音 3:28–36"> 他就明说，并不隐瞒，明说：「我不是基督。」</span>
<span className="v" id="v21" data-v="21" data-xref="玛拉基书 4:5; 申命记 18:15–18; 马太福音 11:14"> 他们又问他说：「这样，你是谁呢？是以利亚吗？」他说：「我不是。」「是那先知吗？」他回答说：「不是。」</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 24:13"> 于是他们说：「你到底是谁，叫我们好回复差我们来的人。你自己说，你是谁？」</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 40:3–5; 马可福音 1:3; 马太福音 3:3"> 他说：「我就是那在旷野有人声喊着说：『修直主的道路』，正如先知以赛亚所说的。」</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 11:53; 马太福音 23:13–15; 路加福音 11:39–44"> 那些人是法利赛人差来的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：那差来的是法利赛人">a</a></sup>；</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 18:18; 申命记 18:15; 约翰福音 1:20–22"> 他们就问他说：「你既不是基督，不是以利亚，也不是那先知，为什么施洗呢？」</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 1:10–11; 路加福音 3:16; 使徒行传 1:5"> 约翰回答说：「我是用水施洗，但有一位站在你们中间，是你们不认识的，</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 1:30; 马可福音 1:7; 马太福音 3:11"> 就是那在我以后来的，我给他解鞋带也不配。」</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 10:40; 约翰福音 3:23; 士师记 7:24"> 这是在约旦河外伯大尼<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷：伯大巴喇">b</a></sup>，约翰施洗的地方作的见证。</span>
</div>
</div>

## 神的羔羊

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 53:7; 约翰一书 2:2; 约翰一书 3:5"> 次日，约翰看见耶稣来到他那里，就说：「看哪， 神的羔羊，除去<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或译：背负">c</a></sup>世人罪孽的！</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 1:27; 约翰福音 1:15; 路加福音 3:16"> 这就是我曾说：『有一位在我以后来、反成了在我以前的，因他本来在我以前。』</span>
<span className="v" id="v31" data-v="31" data-xref="玛拉基书 3:1; 路加福音 1:17; 玛拉基书 4:2–5"> 我先前不认识他，如今我来用水施洗，为要叫他显明给以色列人。」</span>
<span className="v" id="v32" data-v="32" data-xref="马可福音 1:10; 路加福音 3:22; 马太福音 3:16"> 约翰又作见证说：「我曾看见圣灵，仿佛鸽子从天降下，住在他的身上。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 1:5; 马太福音 3:11; 路加福音 3:16"> 我先前不认识他，只是那差我来用水施洗的、对我说：『你看见圣灵降下来，住在谁的身上，谁就是用圣灵施洗的。』</span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 2:7; 约翰福音 1:49; 诗篇 89:26–27"> 我看见了，就证明这是 神的儿子。」</span>
</div>
</div>

## 初次选召门徒

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="约翰福音 3:25–26; 玛拉基书 3:16"> 再次日，约翰同两个门徒站在那里。</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 1:29; 彼得前书 1:19–20; 以赛亚书 65:1–2"> 他见耶稣行走，就说：「看哪，这是 神的羔羊！」</span>
<span className="v" id="v37" data-v="37" data-xref="罗马书 10:17; 约翰福音 1:43; 撒迦利亚书 8:21"> 两个门徒听见他的话，就跟从了耶稣。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 18:7; 约翰福音 3:2; 约翰福音 1:49"> 耶稣转过身来，看见他们跟着，就问他们说：「你们要什么？」他们说：「拉比，在哪里住？」（拉比翻出来就是夫子。）</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 24:29; 马太福音 11:28–30; 约翰福音 6:37"> 耶稣说：「你们来看。」他们就去看他在哪里住，这一天便与他同住；那时约有申正了。</span>
<span className="v" id="v40" data-v="40" data-xref="马可福音 1:16–20; 马太福音 4:18–22; 约翰福音 1:40–42"> 听见约翰的话跟从耶稣的那两个人，一个是西门·彼得的兄弟安得烈。</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 4:25; 约翰福音 1:45; 诗篇 89:20"> 他先找着自己的哥哥西门，对他说：「我们遇见弥赛亚了。」（弥赛亚翻出来就是基督。）</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 21:15–17; 哥林多前书 3:22; 哥林多前书 15:5"> 于是领他去见耶稣。耶稣看着他，说：「你是约翰的儿子西门<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="约翰在马太十六章十七节称约拿">d</a></sup>，你要称为矶法。」（矶法翻出来就是彼得。）</span>
</div>
</div>

## 呼召腓力和拿但业

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="马太福音 9:9; 约翰福音 14:8; 以赛亚书 65:1"> 又次日，耶稣想要往加利利去，遇见腓力，就对他说：「来跟从我吧。」</span>
<span className="v" id="v44" data-v="44" data-xref="约翰福音 12:21; 马太福音 11:21; 马可福音 8:22"> 这腓力是伯赛大人，和安得烈、彼得同城。</span>
<span className="v" id="v45" data-v="45" data-xref="申命记 18:18–22; 路加福音 24:27; 弥迦书 5:2"> 腓力找着拿但业，对他说：「摩西在律法上所写的和众先知所记的那一位，我们遇见了，就是约瑟的儿子拿撒勒人耶稣。」</span>
<span className="v" id="v46" data-v="46" data-xref="约翰福音 7:52; 约翰福音 7:41–42; 约翰福音 4:29"> 拿但业对他说：「拿撒勒还能出什么好的吗？」腓力说：「你来看！」</span>
<span className="v" id="v47" data-v="47" data-xref="启示录 14:5; 诗篇 32:2; 诗篇 73:1"> 耶稣看见拿但业来，就指着他说：「看哪，这是个真以色列人，他心里是没有诡诈的。」</span>
<span className="v" id="v48" data-v="48" data-xref="以赛亚书 65:24; 约翰福音 2:25; 诗篇 139:1–2"> 拿但业对耶稣说：「你从哪里知道我呢？」耶稣回答说：「腓力还没有招呼你，你在无花果树底下，我就看见你了。」</span>
<span className="v" id="v49" data-v="49" data-xref="西番雅书 3:15; 撒迦利亚书 9:9; 马太福音 27:42"> 拿但业说：「拉比，你是 神的儿子，你是以色列的王！」</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 11:40; 约翰福音 20:29; 路加福音 1:45"> 耶稣对他说：「因为我说『在无花果树底下看见你』，你就信吗？你将要看见比这更大的事」；</span>
<span className="v" id="v51" data-v="51" data-xref="创世记 28:12; 使徒行传 7:56; 路加福音 22:43"> 又说：「我实实在在地告诉你们，你们将要看见天开了， 神的使者上去下来在人子身上。」</span>
</div>

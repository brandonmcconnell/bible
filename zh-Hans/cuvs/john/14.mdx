## 耶稣是道路、真理、生命

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 26:3; 约翰福音 16:22–23; 以赛亚书 12:2–3"> 「你们心里不要忧愁；你们信 神，也当信我。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 5:1; 约翰福音 13:36; 希伯来书 13:14"> 在我父的家里有许多住处；若是没有，我就早已告诉你们了。我去原是为你们预备地方去。</span>
<span className="v" id="v3" data-v="3" data-xref="帖撒罗尼迦前书 4:16–17; 约翰福音 12:26; 提摩太后书 2:12"> 我若去为你们预备了地方，就必再来接你们到我那里去，我在哪里，叫你们也在那里。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 10:9; 约翰福音 16:28; 约翰福音 13:3"> 我往哪里去，你们知道；那条路，你们也知道<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷：我往哪里去，你们知道那条路">a</a></sup>。」</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 11:16; 马可福音 9:19; 约翰福音 20:25–28"> 多马对他说：「主啊，我们不知道你往哪里去，怎么知道那条路呢？」</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 4:12; 约翰福音 10:9; 以弗所书 2:18"> 耶稣说：「我就是道路、真理、生命；若不借着我，没有人能到父那里去。</span>
<span className="v" id="v7" data-v="7" data-xref="歌罗西书 1:15–17; 约翰福音 8:19; 路加福音 10:22"> 你们若认识我，也就认识我的父。从今以后，你们认识他，并且已经看见他。」</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 33:18–23; 启示录 22:3–5; 约翰福音 1:43–46"> 腓力对他说：「求主将父显给我们看，我们就知足了。」</span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 1:15; 约翰福音 12:45; 约翰福音 14:7"> 耶稣对他说：「腓力，我与你们同在这样长久，你还不认识我吗？人看见了我，就是看见了父；你怎么说『将父显给我们看』呢？</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 5:19; 约翰福音 10:38; 约翰福音 10:30"> 我在父里面，父在我里面，你不信吗？我对你们所说的话，不是凭着自己说的，乃是住在我里面的父做他自己的事。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 10:38; 约翰福音 10:25; 约翰福音 5:36"> 你们当信我，我在父里面，父在我里面；即或不信，也当因我所做的事信我。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 21:21; 马可福音 16:17; 路加福音 10:17–19"> 我实实在在地告诉你们，我所做的事，信我的人也要做，并且要做比这更大的事，因为我往父那里去。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 15:7; 马可福音 11:24; 马太福音 7:7"> 你们奉我的名无论求什么，我必成就，叫父因儿子得荣耀。</span>
<span className="v" id="v14" data-v="14"> 你们若奉我的名求什么，我必成就。」</span>
</div>
</div>

## 应许赐圣灵

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰一书 2:3–5; 约翰一书 5:2–3; 约翰福音 14:21–24"> 「你们若爱我，就必遵守我的命令。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 14:26; 约翰福音 15:26; 约翰福音 16:7–15"> 我要求父，父就另外赐给你们一位保惠师<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：训慰师；下同">b</a></sup>，叫他永远与你们同在，</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 36:27; 约翰福音 16:13; 约翰一书 2:27"> 就是真理的圣灵，乃世人不能接受的；因为不见他，也不认识他。你们却认识他，因他常与你们同在，也要在你们里面。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 14:3; 诗篇 23:4; 马太福音 18:20"> 我不撇下你们为孤儿，我必到你们这里来。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 16:16; 约翰福音 7:33; 希伯来书 7:25"> 还有不多的时候，世人不再看见我，你们却看见我；因为我活着，你们也要活着。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 15:5–7; 加拉太书 2:20; 约翰福音 17:21–23"> 到那日，你们就知道我在父里面，你们在我里面，我也在你们里面。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 14:15; 约翰一书 5:3; 约翰一书 2:5"> 有了我的命令又遵守的，这人就是爱我的；爱我的必蒙我父爱他，我也要爱他，并且要向他显现。」</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 1:13; 路加福音 6:16; 马太福音 10:3"> 犹大（不是加略人犹大）问耶稣说：「主啊，为什么要向我们显现，不向世人显现呢？」</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 14:21; 约翰福音 14:15; 启示录 3:20–21"> 耶稣回答说：「人若爱我，就必遵守我的道；我父也必爱他，并且我们要到他那里去，与他同住。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 7:16; 约翰福音 14:10; 约翰福音 8:42"> 不爱我的人就不遵守我的道。你们所听见的道不是我的，乃是差我来之父的道。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 17:6–8; 约翰福音 13:19; 约翰福音 16:12"> 「我还与你们同住的时候，已将这些话对你们说了。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 15:26; 约翰福音 14:16; 约翰一书 2:27"> 但保惠师，就是父因我的名所要差来的圣灵，他要将一切的事指教你们，并且要叫你们想起我对你们所说的一切话。</span>
<span className="v" id="v27" data-v="27" data-xref="腓立比书 4:7; 约翰福音 16:33; 以赛亚书 41:10"> 我留下平安给你们；我将我的平安赐给你们。我所赐的，不像世人所赐的。你们心里不要忧愁，也不要胆怯。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 10:29–30; 哥林多前书 15:24–28; 哥林多前书 11:3"> 你们听见我对你们说了，我去还要到你们这里来。你们若爱我，因我到父那里去，就必喜乐，因为父是比我大的。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 13:19; 约翰福音 16:4–31; 马太福音 24:24–25"> 现在事情还没有成就，我预先告诉你们，叫你们到事情成就的时候就可以信。</span>
<span className="v" id="v30" data-v="30" data-xref="约翰一书 5:19; 约翰一书 4:4; 启示录 12:9"> 以后我不再和你们多说话，因为这世界的王将到。他在我里面是毫无所有；</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 10:18; 腓立比书 2:8; 约翰福音 12:49"> 但要叫世人知道我爱父，并且父怎样吩咐我，我就怎样行。起来，我们走吧！」</span>
</div>
</div>

## 圣物的圣洁

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 18:21; 申命记 15:19; 利未记 22:32"> 「你吩咐亚伦和他子孙说：要远离以色列人所分别为圣、归给我的圣物，免得亵渎我的圣名。我是耶和华。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 7:20–21; 民数记 19:13; 诗篇 16:11"> 你要对他们说：你们世世代代的后裔，凡身上有污秽、亲近以色列人所分别为圣、归耶和华圣物的，那人必在我面前剪除。我是耶和华。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 11:39; 利未记 15:2–3; 利未记 15:13–16"> 亚伦的后裔，凡长大麻风的，或是有漏症的，不可吃圣物，直等他洁净了。无论谁摸那因死尸不洁净的物<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：人">a</a></sup>，或是遗精的人，</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 11:43–44; 利未记 15:7; 利未记 15:19"> 或是摸什么使他不洁净的爬物，或是摸那使他不洁净的人（不拘那人有什么不洁净），</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 15:5; 希伯来书 10:22; 哈该书 2:13"> 摸了这些人、物的，必不洁净到晚上；若不用水洗身，就不可吃圣物。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 21:22; 申命记 18:3–4; 哥林多前书 9:13–14"> 日落的时候，他就洁净了，然后可以吃圣物，因为这是他的食物。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 17:15; 出埃及记 22:31; 以西结书 44:31"> 自死的或是被野兽撕裂的，他不可吃，因此污秽自己。我是耶和华。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 28:43; 民数记 18:22; 民数记 18:32"> 所以他们要守我所吩咐的，免得轻忽了，因此担罪而死。我是叫他们成圣的耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 12:4; 撒母耳记上 21:6; 出埃及记 29:33"> 「凡外人不可吃圣物；寄居在祭司家的，或是雇工人，都不可吃圣物；</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 17:13; 出埃及记 12:44; 民数记 18:11–13"> 倘若祭司买人，是他的钱买的，那人就可以吃圣物；生在他家的人也可以吃。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 40:13; 利未记 21:3"> 祭司的女儿若嫁外人，就不可吃举祭的圣物。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 10:14; 创世记 38:11; 民数记 18:11–19"> 但祭司的女儿若是寡妇，或是被休的，没有孩子，又归回父家，与她青年一样，就可以吃她父亲的食物；只是外人不可吃。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 27:15; 利未记 27:13; 利未记 5:15–19"> 若有人误吃了圣物，要照圣物的原数加上五分之一交给祭司。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 18:32; 利未记 19:8; 以西结书 22:26"> 祭司不可亵渎以色列人所献给耶和华的圣物，</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 22:9; 彼得前书 2:24; 以赛亚书 53:11–12"> 免得他们在吃圣物上自取罪孽，因为我是叫他们成圣的耶和华。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和华对摩西说：</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 1:2; 申命记 12:6; 民数记 15:3"> 「你晓谕亚伦和他子孙，并以色列众人说：以色列家中的人，或在以色列中寄居的，凡献供物，无论是所许的愿，是甘心献的，就是献给耶和华作燔祭的，</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 1:10; 利未记 1:3; 以弗所书 5:27"> 要将没有残疾的公牛，或是绵羊，或是山羊献上，如此方蒙悦纳。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 17:1; 玛拉基书 1:8; 申命记 15:21"> 凡有残疾的，你们不可献上，因为这不蒙悦纳。</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 15:8; 民数记 15:3; 利未记 3:6"> 凡从牛群或是羊群中，将平安祭献给耶和华，为要还特许的愿，或是作甘心献的，所献的必纯全无残疾的才蒙悦纳。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 22:20; 玛拉基书 1:8; 利未记 1:9"> 瞎眼的、折伤的、残废的、有瘤子的、长癣的、长疥的都不可献给耶和华，也不可在坛上作为火祭献给耶和华。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 21:18"> 无论是公牛是绵羊羔，若肢体有余的，或是缺少的，只可作甘心祭献上；用以还愿，却不蒙悦纳。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 22:20; 申命记 23:1; 利未记 21:20"> 肾子损伤的，或是压碎的，或是破裂的，或是骟了的，不可献给耶和华，在你们的地上也不可这样行。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 21:8; 以斯拉记 6:8–10; 民数记 15:14–16"> 这类的物，你们从外人的手，一样也不可接受作你们 神的食物献上；因为这些都有损坏，有残疾，不蒙悦纳。」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 耶和华晓谕摩西说：</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 22:30; 利未记 19:23–24; 利未记 22:25"> 「才生的公牛，或是绵羊或是山羊，七天当跟着母；从第八天以后，可以当供物蒙悦纳，作为耶和华的火祭。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 22:6–7; 申命记 14:21; 出埃及记 34:26"> 无论是母牛是母羊，不可同日宰母和子。</span>
<span className="v" id="v29" data-v="29" data-xref="诗篇 116:17; 诗篇 107:22; 阿摩司书 4:5"> 你们献感谢祭给耶和华，要献得可蒙悦纳。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 7:15–18; 出埃及记 16:19–20; 利未记 19:7"> 要当天吃，一点不可留到早晨。我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="申命记 4:40; 利未记 19:37; 民数记 15:40"> 「你们要谨守遵行我的诫命。我是耶和华。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 18:21; 路加福音 11:2; 马太福音 6:9"> 你们不可亵渎我的圣名；我在以色列人中，却要被尊为圣。我是叫你们成圣的耶和华，</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 11:45; 出埃及记 6:7; 利未记 25:38"> 把你们从埃及地领出来，作你们的 神。我是耶和华。」</span>
</div>
</div>

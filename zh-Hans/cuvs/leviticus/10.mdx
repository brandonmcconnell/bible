## 拿答和亚比户犯罪

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 26:61; 申命记 12:32; 利未记 16:12"> 亚伦的儿子拿答、亚比户各拿自己的香炉，盛上火，加上香，在耶和华面前献上凡火，是耶和华没有吩咐他们的，</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 26:61; 民数记 16:35; 利未记 9:24"> 就有火从耶和华面前出来，把他们烧灭，他们就死在耶和华面前。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 19:22; 利未记 21:6; 以赛亚书 49:3"> 于是摩西对亚伦说：「这就是耶和华所说：『我在亲近我的人中要显为圣；在众民面前，我要得荣耀。』」亚伦就默默不言。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 6:22; 出埃及记 6:18; 使徒行传 5:6"> 摩西召了亚伦叔父乌薛的儿子米沙利、以利撒反来，对他们说：「上前来，把你们的亲属从圣所前抬到营外。」</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 8:13"> 于是二人上前来，把他们穿着袍子抬到营外，是照摩西所吩咐的。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 22:18; 约书亚记 7:1; 民数记 16:22"> 摩西对亚伦和他儿子以利亚撒、以他玛说：「不可蓬头散发，也不可撕裂衣裳，免得你们死亡，又免得耶和华向会众发怒；只要你们的弟兄以色列全家为耶和华所发的火哀哭。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 21:12; 利未记 8:30; 使徒行传 10:38"> 你们也不可出会幕的门，恐怕你们死亡，因为耶和华的膏油在你们的身上。」他们就照摩西的话行了。</span>
</div>
</div>

## 有关祭司的条例

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8"> 耶和华晓谕亚伦说：</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 1:15; 提摩太前书 3:3; 以弗所书 5:18"> 「你和你儿子进会幕的时候，清酒、浓酒都不可喝，免得你们死亡；这要作你们世世代代永远的定例。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 22:26; 彼得前书 1:14–16; 利未记 11:47"> 使你们可以将圣的、俗的，洁净的、不洁净的，分别出来；</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 28:20; 玛拉基书 2:7; 尼希米记 8:8"> 又使你们可以将耶和华借摩西晓谕以色列人的一切律例教训他们。」</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 21:22; 民数记 18:9–10; 利未记 7:9"> 摩西对亚伦和他剩下的儿子以利亚撒、以他玛说：「你们献给耶和华火祭中所剩的素祭，要在坛旁不带酵而吃，因为是至圣的。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 2:3; 利未记 6:16; 民数记 18:10"> 你们要在圣处吃；因为在献给耶和华的火祭中，这是你的分和你儿子的分；所吩咐我的本是这样。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 18:11; 利未记 7:29–34; 出埃及记 29:24–28"> 所摇的胸，所举的腿，你们要在洁净地方吃。你和你的儿女都要同吃；因为这些是从以色列人平安祭中给你，当你的分和你儿子的分。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 7:34; 创世记 17:13; 利未记 7:29–30"> 所举的腿，所摇的胸，他们要与火祭的脂油一同带来当摇祭，在耶和华面前摇一摇；这要归你和你儿子，当作永得的分，都是照耶和华所吩咐的。」</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 9:3; 利未记 9:15; 利未记 6:26"> 当下摩西急切地寻找作赎罪祭的公山羊，谁知已经焚烧了，便向亚伦剩下的儿子以利亚撒、以他玛发怒，说：</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 7:6–7; 民数记 18:1; 利未记 6:24–30"> 「这赎罪祭既是至圣的，主又给了你们，为要你们担当会众的罪孽，在耶和华面前为他们赎罪，你们为何没有在圣所吃呢？</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 6:30; 利未记 6:26"> 看哪，这祭牲的血并没有拿到圣所里去，你们本当照我所吩咐的，在圣所里吃这祭肉。」</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 9:12; 利未记 9:8; 耶利米书 14:12"> 亚伦对摩西说：「今天他们在耶和华面前献上赎罪祭和燔祭，我又遇见这样的灾，若今天吃了赎罪祭，耶和华岂能看为美呢？」</span>
<span className="v" id="v20" data-v="20" data-xref="撒迦利亚书 7:8–9; 马太福音 12:20; 历代志下 30:18–20"> 摩西听见这话，便以为美。</span>

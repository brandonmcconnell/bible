## 赎罪日

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 10:1–2"> 亚伦的两个儿子近到耶和华面前死了。死了之后，耶和华晓谕摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 30:10; 列王纪上 8:10–12; 希伯来书 10:19–20"> 「要告诉你哥哥亚伦，不可随时进圣所的幔子内、到柜上的施恩座前，免得他死亡，因为我要从云中显现在施恩座上。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 4:3; 希伯来书 9:24–25; 希伯来书 9:7"> 亚伦进圣所，要带一只公牛犊为赎罪祭，一只公绵羊为燔祭。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 28:39–43; 以西结书 44:17–18; 出埃及记 30:20"> 要穿上细麻布圣内袍，把细麻布裤子穿在身上，腰束细麻布带子，头戴细麻布冠冕；这都是圣服。他要用水洗身，然后穿戴。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 29:21; 利未记 8:2; 以斯拉记 6:17"> 要从以色列会众取两只公山羊为赎罪祭，一只公绵羊为燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="利未记 9:7; 希伯来书 9:7; 希伯来书 7:27"> 「亚伦要把赎罪祭的公牛奉上，为自己和本家赎罪；</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 12:1; 利未记 4:4; 马太福音 16:21"> 也要把两只公山羊安置在会幕门口、耶和华面前，</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 1:23–26; 约拿书 1:7; 箴言 16:33"> 为那两只羊拈阄，一阄归与耶和华，一阄归与阿撒泻勒。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 4:27–28; 使徒行传 2:23"> 亚伦要把那拈阄归与耶和华的羊献为赎罪祭，</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 2:2; 利未记 16:21–22; 希伯来书 9:23–24"> 但那拈阄归与阿撒泻勒的羊要活着安置在耶和华面前，用以赎罪，打发人送到旷野去，归与阿撒泻勒。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="利未记 16:6; 希伯来书 7:27; 希伯来书 9:7"> 「亚伦要把赎罪祭的公牛牵来宰了，为自己和本家赎罪；</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 10:1; 出埃及记 30:34–38; 启示录 8:3–4"> 拿香炉，从耶和华面前的坛上盛满火炭，又拿一捧捣细的香料，都带入幔子内，</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 25:21; 出埃及记 30:1; 出埃及记 30:7–8"> 在耶和华面前，把香放在火上，使香的烟云遮掩法柜上的施恩座，免得他死亡；</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 9:25; 利未记 4:5–6; 希伯来书 9:13"> 也要取些公牛的血，用指头弹在施恩座的东面，又在施恩座的前面弹血七次。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="希伯来书 9:7; 希伯来书 2:17; 希伯来书 9:3"> 「随后他要宰那为百姓作赎罪祭的公山羊，把羊的血带入幔子内，弹在施恩座的上面和前面，好像弹公牛的血一样。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 9:22–23; 利未记 16:18; 以西结书 45:18–19"> 他因以色列人诸般的污秽、过犯，就是他们一切的罪愆，当这样在圣所行赎罪之礼，并因会幕在他们污秽之中，也要照样而行。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 53:6; 路加福音 1:10; 出埃及记 34:3"> 他进圣所赎罪的时候，会幕里不可有人，直等到他为自己和本家并以色列全会众赎了罪出来。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 4:7; 希伯来书 5:7–8; 利未记 16:16"> 他出来，要到耶和华面前的坛那里，在坛上行赎罪之礼，又要取些公牛的血和公山羊的血，抹在坛上四角的周围；</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 13:1; 以西结书 43:18–22"> 也要用指头把血弹在坛上七次，洁净了坛，从坛上除掉以色列人诸般的污秽，使坛成圣。」</span>
</div>
</div>

## 代罪羊

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="利未记 16:16; 以西结书 45:20; 歌罗西书 1:20"> 「亚伦为圣所和会幕并坛献完了赎罪祭，就要把那只活着的公山羊奉上。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 53:6; 哥林多后书 5:21; 以斯拉记 10:1"> 两手按在羊头上，承认以色列人诸般的罪孽过犯，就是他们一切的罪愆，把这罪都归在羊的头上，借着所派之人的手，送到旷野去。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 9:28; 以赛亚书 53:11–12; 约翰福音 1:29"> 要把这羊放在旷野，这羊要担当他们一切的罪孽，带到无人之地。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以西结书 44:19; 以西结书 42:14; 利未记 16:4"> 「亚伦要进会幕，把他进圣所时所穿的细麻布衣服脱下，放在那里，</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 16:3–5; 希伯来书 10:19–22; 出埃及记 28:4–14"> 又要在圣处用水洗身，穿上衣服，出来，把自己的燔祭和百姓的燔祭献上，为自己和百姓赎罪。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 29:13; 利未记 4:8–10; 利未记 16:6"> 赎罪祭牲的脂油要在坛上焚烧。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 16:10; 希伯来书 7:19; 民数记 19:21"> 那放羊归与阿撒泻勒的人要洗衣服，用水洗身，然后进营。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 4:21; 利未记 6:30; 利未记 4:11–12"> 作赎罪祭的公牛和公山羊的血既带入圣所赎罪，这牛羊就要搬到营外，将皮、肉、粪用火焚烧。</span>
<span className="v" id="v28" data-v="28"> 焚烧的人要洗衣服，用水洗身，然后进营。」</span>
</div>
</div>

## 守赎罪日

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 58:3; 民数记 29:7; 出埃及记 20:10"> 「每逢七月初十日，你们要刻苦己心，无论是本地人，是寄居在你们中间的外人，什么工都不可做；这要作你们永远的定例。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 33:8; 诗篇 51:2; 以弗所书 5:26"> 因在这日要为你们赎罪，使你们洁净。你们要在耶和华面前得以洁净，脱尽一切的罪愆。</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 23:32; 以赛亚书 58:5; 利未记 25:4"> 这日你们要守为圣安息日，要刻苦己心；这为永远的定例。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 16:4; 出埃及记 29:29–30; 利未记 4:5"> 那受膏、接续他父亲承接圣职的祭司要穿上细麻布的圣衣，行赎罪之礼。</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 16:16; 利未记 16:24; 利未记 16:6"> 他要在至圣所和会幕与坛行赎罪之礼，并要为众祭司和会众的百姓赎罪。</span>
<span className="v" id="v34" data-v="34" data-xref="希伯来书 9:7; 希伯来书 9:25; 出埃及记 30:10"> 这要作你们永远的定例—就是因以色列人一切的罪，要一年一次为他们赎罪。」<br />于是，亚伦照耶和华所吩咐摩西的行了。</span>
</div>
</div>

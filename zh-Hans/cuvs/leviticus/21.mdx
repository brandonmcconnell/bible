## 祭司圣洁的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 44:25; 利未记 21:11; 利未记 10:6–7"> 耶和华对摩西说：「你告诉亚伦子孙作祭司的说：祭司不可为民中的死人沾染自己，</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦前书 4:13; 利未记 18:6"> 除非为他骨肉之亲的父母、儿女、弟兄，</span>
<span className="v" id="v3" data-v="3"> 和未曾出嫁、作处女的姊妹，才可以沾染自己。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 24:16–17"> 祭司既在民中为首，就不可从俗沾染自己。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 14:1; 以西结书 44:20; 利未记 19:27–28"> 不可使头光秃；不可剃除胡须的周围，也不可用刀划身。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 3:11; 利未记 18:21; 彼得前书 2:9"> 要归 神为圣，不可亵渎 神的名；因为耶和华的火祭，就是 神的食物，是他们献的，所以他们要成为圣。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 21:13–14; 以西结书 44:22; 利未记 21:8"> 不可娶妓女或被污的女人为妻，也不可娶被休的妇人为妻，因为祭司是归 神为圣。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 20:7–8; 利未记 19:2; 利未记 11:44–45"> 所以你要使他成圣，因为他奉献你 神的食物；你要以他为圣，因为我—使你们成圣的耶和华—是圣的。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 38:24; 利未记 19:29; 以西结书 9:6"> 祭司的女儿若行淫辱没自己，就辱没了父亲，必用火将她焚烧。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 10:6–7; 利未记 16:32; 马太福音 26:65"> 「在弟兄中作大祭司、头上倒了膏油、又承接圣职、穿了圣衣的，不可蓬头散发，也不可撕裂衣服。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 19:14; 利未记 21:1–2; 民数记 6:7"> 不可挨近死尸，也不可为父母沾染自己。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 10:7; 出埃及记 29:6–7; 利未记 8:9–12"> 不可出圣所，也不可亵渎 神的圣所，因为 神膏油的冠冕在他头上。我是耶和华。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 21:7; 哥林多后书 11:2; 启示录 14:4"> 他要娶处女为妻。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 21:7; 以西结书 44:22"> 寡妇或是被休的妇人，或是被污为妓的女人，都不可娶；只可娶本民中的处女为妻。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 11:16; 哥林多前书 7:14; 尼希米记 13:23–29"> 不可在民中辱没他的儿女，因为我是叫他成圣的耶和华。」</span>
<span className="v" id="v16" data-v="16"> 耶和华对摩西说：</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 65:4; 民数记 16:5; 利未记 10:3"> 「你告诉亚伦说：你世世代代的后裔，凡有残疾的，都不可近前来献他 神的食物。</span>
<span className="v" id="v18" data-v="18" data-xref="提摩太前书 3:2–3; 利未记 22:19–25; 提多书 1:7"> 因为凡有残疾的，无论是瞎眼的、瘸腿的、塌鼻子的、肢体有余的、</span>
<span className="v" id="v19" data-v="19"> 折脚折手的、</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 23:1; 以赛亚书 56:3"> 驼背的、矮矬的、眼睛有毛病的、长癣的、长疥的，或是损坏肾子的，都不可近前来。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 21:6; 利未记 21:8; 利未记 21:17"> 祭司亚伦的后裔，凡有残疾的，都不可近前来，将火祭献给耶和华。他有残疾，不可近前来献 神的食物。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 2:3; 民数记 18:19; 利未记 24:8–9"> 神的食物，无论是圣的，至圣的，他都可以吃。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 21:12; 以西结书 44:9–14; 出埃及记 30:6–8"> 但不可进到幔子前，也不可就近坛前；因为他有残疾，免得亵渎我的圣所。我是叫他成圣的耶和华。」</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太前书 1:18; 玛拉基书 2:1–7; 提摩太后书 2:2"> 于是，摩西晓谕亚伦和亚伦的子孙，并以色列众人。</span>

## 有关食物的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西、亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 15:11; 利未记 11:11; 希伯来书 9:10"> 「你们晓谕以色列人说，在地上一切走兽中可吃的乃是这些：</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 2:10; 哥林多后书 6:17; 申命记 6:6–7"> 凡蹄分两瓣、倒嚼的走兽，你们都可以吃。</span>
<span className="v" id="v4" data-v="4"> 但那倒嚼或分蹄之中不可吃的乃是：骆驼—因为倒嚼不分蹄，就与你们不洁净；</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 104:18; 箴言 30:26; 马太福音 7:26"> 沙番—因为倒嚼不分蹄，就与你们不洁净；</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 14:7"> 兔子—因为倒嚼不分蹄，就与你们不洁净；</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 66:17; 以赛亚书 65:4; 以赛亚书 66:3"> 猪—因为蹄分两瓣，却不倒嚼，就与你们不洁净。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 52:11; 歌罗西书 2:16; 希伯来书 9:10"> 这些兽的肉，你们不可吃；死的，你们不可摸，都与你们不洁净。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="加拉太书 5:6; 雅各书 2:18; 使徒行传 20:21"> 「水中可吃的乃是这些：凡在水里、海里、河里、有翅有鳞的，都可以吃。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 29:27; 利未记 7:18; 诗篇 139:21–22"> 凡在海里、河里，并一切水里游动的活物，无翅无鳞的，你们都当以为可憎。</span>
<span className="v" id="v11" data-v="11"> 这些无翅无鳞、以为可憎的，你们不可吃它的肉；死的也当以为可憎。</span>
<span className="v" id="v12" data-v="12"> 凡水里无翅无鳞的，你们都当以为可憎。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约伯记 39:27–30; 耶利米书 4:22; 提多书 3:3"> 「雀鸟中你们当以为可憎、不可吃的乃是：雕、狗头雕、红头雕、</span>
<span className="v" id="v14" data-v="14"> 鹞鹰、小鹰与其类；</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 12:24; 列王纪上 17:6; 箴言 30:17"> 乌鸦与其类；</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 34:11–15; 以弗所书 5:7–11; 以弗所书 2:2–3"> 鸵鸟、夜鹰、鱼鹰、鹰与其类；</span>
<span className="v" id="v17" data-v="17"> 鸮鸟、鸬鹚、猫头鹰、</span>
<span className="v" id="v18" data-v="18"> 角鸱、鹈鹕、秃雕、</span>
<span className="v" id="v19" data-v="19"> 鹳、鹭鸶与其类；戴 与蝙蝠。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="提摩太后书 4:10; 腓立比书 3:18–19; 利未记 11:23"> 「凡有翅膀用四足爬行的物，你们都当以为可憎。</span>
<span className="v" id="v21" data-v="21"> 只是有翅膀用四足爬行的物中，有足有腿，在地上蹦跳的，你们还可以吃。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 3:4; 马可福音 1:6; 出埃及记 10:4–5"> 其中有蝗虫、蚂蚱、蟋蟀与其类；蚱蜢与其类；这些你们都可以吃。</span>
<span className="v" id="v23" data-v="23"> 但是有翅膀有四足的爬物，你们都当以为可憎。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 15:33; 以弗所书 2:1–3; 哥林多后书 6:17"> 「这些都能使你们不洁净。凡摸了死的，必不洁净到晚上。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 15:5; 利未记 14:8; 民数记 31:24"> 凡拿了死的，必不洁净到晚上，并要洗衣服。</span>
<span className="v" id="v26" data-v="26"> 凡走兽分蹄不成两瓣、也不倒嚼的，是与你们不洁净；凡摸了的就不洁净。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 11:23; 利未记 11:20"> 凡四足的走兽，用掌行走的，是与你们不洁净；摸其尸的，必不洁净到晚上。</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 11:24–25"> 拿其尸的，必不洁净到晚上，并要洗衣服。这些是与你们不洁净的。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="利未记 11:41–42; 提摩太后书 3:2–5; 诗篇 10:3"> 「地上爬物与你们不洁净的乃是这些：鼬鼠、鼫鼠、蜥蜴与其类；</span>
<span className="v" id="v30" data-v="30"> 壁虎、龙子、守宫、蛇医、蝘蜓。</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 11:24–25; 利未记 11:8"> 这些爬物都是与你们不洁净的。在它死了以后，凡摸了的，必不洁净到晚上。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 15:12; 提多书 3:5; 提多书 2:14"> 其中死了的，掉在什么东西上，这东西就不洁净，无论是木器、衣服、皮子、口袋，不拘是做什么工用的器皿，须要放在水中，必不洁净到晚上，到晚上才洁净了。</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 6:28; 利未记 15:12; 利未记 14:45"> 若有死了掉在瓦器里的，其中不拘有什么，就不洁净，你们要把这瓦器打破了。</span>
<span className="v" id="v34" data-v="34" data-xref="提多书 1:15; 箴言 21:4; 箴言 21:27"> 其中一切可吃的食物，沾水的就不洁净，并且那样器皿中一切可喝的，也必不洁净。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 15:12; 利未记 6:28; 利未记 11:33"> 其中已死的，若有一点掉在什么物件上，那物件就不洁净，不拘是炉子，是锅台，就要打碎，都不洁净，也必与你们不洁净。</span>
<span className="v" id="v36" data-v="36" data-xref="撒迦利亚书 13:1; 约翰福音 4:14"> 但是泉源或是聚水的池子仍是洁净；惟挨了那死的，就不洁净。</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前书 15:37; 彼得前书 1:23; 约翰一书 5:18"> 若是死的，有一点掉在要种的子粒上，子粒仍是洁净；</span>
<span className="v" id="v38" data-v="38"> 若水已经浇在子粒上，那死的有一点掉在上头，这子粒就与你们不洁净。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="利未记 11:40; 利未记 11:24; 利未记 15:7"> 「你们可吃的走兽若是死了，有人摸它，必不洁净到晚上；</span>
<span className="v" id="v40" data-v="40" data-xref="利未记 22:8; 以西结书 44:31; 申命记 14:21"> 有人吃那死了的走兽，必不洁净到晚上，并要洗衣服；拿了死走兽的，必不洁净到晚上，并要洗衣服。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="利未记 11:29; 利未记 11:20; 利未记 11:23"> 「凡地上的爬物是可憎的，都不可吃。</span>
<span className="v" id="v42" data-v="42" data-xref="提多书 1:12; 以赛亚书 65:25; 哥林多后书 11:3"> 凡用肚子行走的和用四足行走的，或是有许多足的，就是一切爬在地上的，你们都不可吃，因为是可憎的。</span>
<span className="v" id="v43" data-v="43" data-xref="利未记 20:25; 利未记 11:41–42"> 你们不可因什么爬物使自己成为可憎的，也不可因这些使自己不洁净，以致染了污秽。</span>
<span className="v" id="v44" data-v="44" data-xref="出埃及记 20:2; 彼得前书 1:15–16; 利未记 19:2"> 我是耶和华—你们的 神；所以你们要成为圣洁，因为我是圣洁的。你们也不可在地上的爬物污秽自己。</span>
<span className="v" id="v45" data-v="45" data-xref="利未记 11:44; 出埃及记 20:2; 出埃及记 6:7"> 我是把你们从埃及地领出来的耶和华，要作你们的 神；所以你们要圣洁，因为我是圣洁的。」</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="利未记 14:54; 利未记 15:32; 以西结书 43:12"> 这是走兽、飞鸟，和水中游动的活物，并地上爬物的条例。</span>
<span className="v" id="v47" data-v="47" data-xref="利未记 10:10; 以西结书 44:23; 罗马书 14:13–23"> 要把洁净的和不洁净的，可吃的与不可吃的活物，都分别出来。</span>
</div>
</div>

</div>

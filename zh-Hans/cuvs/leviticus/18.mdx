## 有关淫乱的禁令

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 6:7; 利未记 11:44; 以西结书 20:5"> 「你晓谕以色列人说：我是耶和华—你们的 神。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 20:23; 出埃及记 23:24; 彼得前书 4:2–4"> 你们从前住的埃及地，那里人的行为，你们不可效法，我要领你们到的迦南地，那里人的行为也不可效法，也不可照他们的恶俗行。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 18:2; 利未记 18:26; 以西结书 20:19"> 你们要遵我的典章，守我的律例，按此而行。我是耶和华—你们的 神。</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 10:5; 以西结书 20:11; 加拉太书 3:12"> 所以，你们要守我的律例典章；人若遵行，就必因此活着。我是耶和华。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 20:17–21; 利未记 18:7–19; 利未记 20:11–12"> 「你们都不可露骨肉之亲的下体，亲近他们。我是耶和华。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 20:11; 以西结书 22:10; 利未记 18:8–16"> 不可露你母亲的下体，羞辱了你父亲。她是你的母亲，不可露她的下体。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 20:11; 哥林多前书 5:1; 申命记 27:20"> 不可露你继母的下体；这本是你父亲的下体。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 20:17; 申命记 27:22; 以西结书 22:11"> 你的姊妹，不拘是异母同父的，是异父同母的，无论是生在家生在外的，都不可露她们的下体。</span>
<span className="v" id="v10" data-v="10"> 不可露你孙女或是外孙女的下体，露了她们的下体就是露了自己的下体。</span>
<span className="v" id="v11" data-v="11"> 你继母从你父亲生的女儿本是你的妹妹，不可露她的下体。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 20:19; 出埃及记 6:20"> 不可露你姑母的下体；她是你父亲的骨肉之亲。</span>
<span className="v" id="v13" data-v="13"> 不可露你姨母的下体；她是你母亲的骨肉之亲。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 20:20"> 不可亲近你伯叔之妻，羞辱了你伯叔；她是你的伯叔母。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 20:12; 创世记 38:26; 以西结书 22:11"> 不可露你儿妇的下体；她是你儿子的妻，不可露她的下体。</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 25:5; 利未记 20:21; 马太福音 22:24"> 不可露你弟兄妻子的下体；这本是你弟兄的下体。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 20:14; 阿摩司书 2:7; 申命记 27:23"> 不可露了妇人的下体，又露她女儿的下体，也不可娶她孙女或是外孙女，露她们的下体；她们是骨肉之亲，这本是大恶。</span>
<span className="v" id="v18" data-v="18" data-xref="玛拉基书 2:15; 创世记 30:15; 创世记 29:28"> 你妻还在的时候，不可另娶她的姊妹作对头，露她的下体。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 20:18; 利未记 15:24; 以西结书 22:10"> 「女人行经不洁净的时候，不可露她的下体，与她亲近。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 20:14; 哥林多前书 6:9; 希伯来书 13:4"> 不可与邻舍的妻行淫，玷污自己。</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 12:31; 利未记 20:2–5; 申命记 18:10"> 不可使你的儿女经火归与摩洛，也不可亵渎你 神的名。我是耶和华。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 20:13; 罗马书 1:26–27; 哥林多前书 6:9"> 不可与男人苟合，像与女人一样；这本是可憎恶的。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 22:19; 利未记 20:15–16; 利未记 20:12"> 不可与兽淫合，玷污自己。女人也不可站在兽前，与它淫合；这本是逆性的事。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 18:12; 利未记 18:30; 利未记 20:22–23"> 「在这一切的事上，你们都不可玷污自己；因为我在你们面前所逐出的列邦，在这一切的事上玷污了自己；</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 18:28; 利未记 20:22–23; 耶利米书 2:7"> 连地也玷污了，所以我追讨那地的罪孽，那地也吐出它的居民。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 18:5; 利未记 17:10; 利未记 18:30"> 故此，你们要守我的律例典章。这一切可憎恶的事，无论是本地人，是寄居在你们中间的外人，都不可行，（</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 36:14; 利未记 18:24; 申命记 23:18"> 在你们以先居住那地的人行了这一切可憎恶的事，地就玷污了，）</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 3:16; 利未记 20:22; 利未记 18:25"> 免得你们玷污那地的时候，地就把你们吐出，像吐出在你们以先的国民一样。</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 20:6; 出埃及记 12:15; 利未记 17:10"> 无论什么人，行了其中可憎的一件事，必从民中剪除。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 20:23; 申命记 18:9–12; 利未记 22:9"> 所以，你们要守我所吩咐的，免得你们随从那些可憎的恶俗，就是在你们以先的人所常行的，以致玷污了自己。我是耶和华—你们的 神。」</span>

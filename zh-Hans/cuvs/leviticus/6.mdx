<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华晓谕摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 3:9; 使徒行传 5:4; 利未记 5:15"> 「若有人犯罪，干犯耶和华，在邻舍交付他的物上，或是在交易上行了诡诈，或是抢夺人的财物，或是欺压邻舍，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 23:4; 利未记 19:12; 出埃及记 22:9–11"> 或是在捡了遗失的物上行了诡诈，说谎起誓，在这一切的事上犯了什么罪；</span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 18:18; 阿摩司书 3:10; 利未记 5:3–4"> 他既犯了罪，有了过犯，就要归还他所抢夺的，或是因欺压所得的，或是人交付他的，或是人遗失他所捡的物，</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 5:16; 路加福音 19:8; 民数记 5:7–8"> 或是他因什么物起了假誓，就要如数归还，另外加上五分之一，在查出他有罪的日子要交还本主。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 5:15; 利未记 5:18; 以赛亚书 53:10–11"> 也要照你所估定的价，把赎愆祭牲—就是羊群中一只没有残疾的公绵羊—牵到耶和华面前，给祭司为赎愆祭。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 4:26; 约翰一书 1:9; 约翰一书 2:1–2"> 祭司要在耶和华面前为他赎罪；他无论行了什么事，使他有了罪，都必蒙赦免。」</span>
</div>
</div>

## 祭司献燔祭的责任

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8"> 耶和华晓谕摩西说：</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 6:12–13; 民数记 28:3; 出埃及记 29:38–42"> 「你要吩咐亚伦和他的子孙说，燔祭的条例乃是这样：燔祭要放在坛的柴上，从晚上到天亮，坛上的火要常常烧着。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 28:39–43; 利未记 16:4; 利未记 1:13"> 祭司要穿上细麻布衣服，又要把细麻布裤子穿在身上，把坛上所烧的燔祭灰收起来，倒在坛的旁边；</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 4:12; 以西结书 44:19; 希伯来书 13:11–13"> 随后要脱去这衣服，穿上别的衣服，把灰拿到营外洁净之处。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 9:24; 出埃及记 29:38–42; 尼希米记 13:31"> 坛上的火要在其上常常烧着，不可熄灭。祭司要每日早晨在上面烧柴，并要把燔祭摆在坛上，在其上烧平安祭牲的脂油。</span>
<span className="v" id="v13" data-v="13"> 在坛上必有常常烧着的火，不可熄灭。」</span>
</div>
</div>

## 祭司献素祭的责任

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 15:4; 利未记 2:1–2; 约翰福音 6:32"> 「素祭的条例乃是这样：亚伦的子孙要在坛前把这祭献在耶和华面前。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 2:2; 利未记 2:9"> 祭司要从其中—就是从素祭的细面中—取出自己的一把，又要取些油和素祭上所有的乳香，烧在坛上，奉给耶和华为馨香素祭的纪念。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 44:29; 利未记 2:3; 利未记 10:12–13"> 所剩下的，亚伦和他子孙要吃，必在圣处不带酵而吃，要在会幕的院子里吃。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 2:3; 利未记 2:11; 民数记 18:9–10"> 烤的时候不可搀酵。这是从所献给我的火祭中赐给他们的分，是至圣的，和赎罪祭并赎愆祭一样。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 6:29; 民数记 18:10; 哈该书 2:12–14"> 凡献给耶和华的火祭，亚伦子孙中的男丁都要吃这一分，直到万代，作他们永得的分。摸这些祭物的，都要成为圣。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 耶和华晓谕摩西说：</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 29:2; 出埃及记 16:36; 利未记 2:1–16"> 「当亚伦受膏的日子，他和他子孙所要献给耶和华的供物，就是细面伊法十分之一，为常献的素祭：早晨一半，晚上一半。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 2:5; 利未记 7:9; 历代志上 9:31"> 要在铁鏊上用油调和做成，调匀了，你就拿进来；烤好了分成块子，献给耶和华为馨香的素祭。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 29:22–25; 以赛亚书 53:10; 利未记 8:21"> 亚伦的子孙中，接续他为受膏的祭司，要把这素祭献上，要全烧给耶和华。这是永远的定例。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 2:10; 利未记 6:16–17"> 祭司的素祭都要烧了，却不可吃。」</span>
</div>
</div>

## 祭司献赎罪祭的责任

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24"> 耶和华晓谕摩西说：</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 4:24; 利未记 1:11; 利未记 1:3"> 「你对亚伦和他的子孙说，赎罪祭的条例乃是这样：要在耶和华面前、宰燔祭牲的地方宰赎罪祭牲；这是至圣的。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 10:17–18; 以西结书 44:28–29; 何西阿书 4:8"> 为赎罪献这祭的祭司要吃，要在圣处，就是在会幕的院子里吃。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 29:37; 哈该书 2:12; 哥林多后书 7:1"> 凡摸这祭肉的要成为圣；这祭牲的血若弹在什么衣服上，所弹的那一件要在圣处洗净。</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 11:33; 利未记 15:12; 希伯来书 9:9–10"> 惟有煮祭物的瓦器要打碎；若是煮在铜器里，这铜器要擦磨，在水中涮净。</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 6:25; 利未记 6:17–18; 民数记 18:10"> 凡祭司中的男丁都可以吃；这是至圣的。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 10:18; 利未记 16:27–28; 希伯来书 13:11"> 凡赎罪祭，若将血带进会幕在圣所赎罪，那肉都不可吃，必用火焚烧。」</span>
</div>
</div>

</div>

## 处罚悖逆的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 21:21; 利未记 18:21; 利未记 20:27"> 「你还要晓谕以色列人说：凡以色列人，或是在以色列中寄居的外人，把自己的儿女献给摩洛的，总要治死他；本地人要用石头把他打死。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 18:21; 以西结书 5:11; 以西结书 23:38–39"> 我也要向那人变脸，把他从民中剪除；因为他把儿女献给摩洛，玷污我的圣所，亵渎我的圣名。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 17:2–5; 使徒行传 17:30; 列王纪上 20:42"> 那人把儿女献给摩洛，本地人若佯为不见，不把他治死，</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 106:39; 何西阿书 2:13; 何西阿书 2:5"> 我就要向这人和他的家变脸，把他和一切随他与摩洛行邪淫的人都从民中剪除。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 19:31; 以赛亚书 8:19; 利未记 20:27"> 「人偏向交鬼的和行巫术的，随他们行邪淫，我要向那人变脸，把他从民中剪除。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 11:44; 利未记 19:2; 彼得前书 1:15–16"> 所以你们要自洁成圣，因为我是耶和华—你们的 神。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 31:13; 雅各书 1:22; 帖撒罗尼迦前书 5:23"> 你们要谨守遵行我的律例；我是叫你们成圣的耶和华。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 21:17; 马可福音 7:10; 申命记 27:16"> 凡咒骂父母的，总要治死他；他咒骂了父母，他的罪<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是血；本章同">a</a></sup>要归到他身上。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 8:4–5; 申命记 22:22–24; 申命记 5:18"> 「与邻舍之妻行淫的，奸夫淫妇都必治死。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 27:20; 申命记 27:23; 阿摩司书 2:7"> 与继母行淫的，就是羞辱了他父亲，总要把他们二人治死，罪要归到他们身上。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 18:15; 利未记 18:23; 创世记 38:18"> 与儿妇同房的，总要把他们二人治死；他们行了逆伦的事，罪要归到他们身上。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 6:9; 利未记 18:22; 犹大书 1:7"> 人若与男人苟合，像与女人一样，他们二人行了可憎的事，总要把他们治死，罪要归到他们身上。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 18:17; 申命记 27:23; 约书亚记 7:15"> 人若娶妻，并娶其母，便是大恶，要把这三人用火焚烧，使你们中间免去大恶。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 18:23; 申命记 27:21; 出埃及记 22:19"> 人若与兽淫合，总要治死他，也要杀那兽。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 21:32; 出埃及记 19:13; 希伯来书 12:20"> 女人若与兽亲近，与它淫合，你要杀那女人和那兽，总要把他们治死，罪要归到他们身上。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 18:9; 申命记 27:22; 以西结书 22:11"> 「人若娶他的姊妹，无论是异母同父的，是异父同母的，彼此见了下体，这是可耻的事；他们必在本民的眼前被剪除。他露了姊妹的下体，必担当自己的罪孽。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 15:24; 利未记 18:19; 以西结书 18:6"> 妇人有月经，若与她同房，露了她的下体，就是露了妇人的血源，妇人也露了自己的血源，二人必从民中剪除。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 18:6; 利未记 18:12–30; 出埃及记 6:20"> 不可露姨母或是姑母的下体，这是露了骨肉之亲的下体；二人必担当自己的罪孽。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 18:14; 约伯记 18:19; 路加福音 23:29"> 人若与伯叔之妻同房，就羞辱了他的伯叔；二人要担当自己的罪，必无子女而死。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 18:16; 马太福音 14:3–4"> 人若娶弟兄之妻，这本是污秽的事，羞辱了他的弟兄；二人必无子女。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 18:25–28; 以西结书 36:27; 利未记 18:4–5"> 「所以，你们要谨守遵行我一切的律例典章，免得我领你们去住的那地把你们吐出。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 9:5; 利未记 18:24; 利未记 18:30"> 我在你们面前所逐出的国民，你们不可随从他们的风俗；因为他们行了这一切的事，所以我厌恶他们。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 14:2; 出埃及记 6:8; 申命记 7:6"> 但我对你们说过，你们要承受他们的地，就是我要赐给你们为业、流奶与蜜之地。我是耶和华—你们的 神，使你们与万民有分别的。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 14:3–21; 利未记 11:1–47; 使徒行传 10:11–15"> 所以，你们要把洁净和不洁净的禽兽分别出来；不可因我给你们分为不洁净的禽兽，或是滋生在地上的活物，使自己成为可憎恶的。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前书 1:15–16; 利未记 20:7; 利未记 20:24"> 你们要归我为圣，因为我—耶和华是圣的，并叫你们与万民有分别，使你们作我的民。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 19:31; 利未记 20:6; 撒母耳记上 28:7–9"> 「无论男女，是交鬼的或行巫术的，总要治死他们。人必用石头把他们打死，罪要归到他们身上。」</span>
</div>

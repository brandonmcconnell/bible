## 素祭的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 6:14–18; 利未记 9:17; 以赛亚书 66:20"> 「若有人献素祭为供物给耶和华，要用细面浇上油，加上乳香，</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 5:12; 利未记 6:15; 使徒行传 10:4"> 带到亚伦子孙作祭司的那里；祭司就要从细面中取出一把来，并取些油和所有的乳香，然后要把所取的这些作为纪念，烧在坛上，是献与耶和华为馨香的火祭。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 10:12–13; 民数记 18:9; 利未记 21:22"> 素祭所剩的要归给亚伦和他的子孙；这是献与耶和华的火祭中为至圣的。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及记 29:2; 哥林多前书 5:7–8; 诗篇 22:14"> 「若用炉中烤的物为素祭，就要用调油的无酵细面饼，或是抹油的无酵薄饼。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 6:21; 利未记 7:9"> 若用铁鏊上做的物为素祭，就要用调油的无酵细面，</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 18:1–19; 诗篇 22:1–21; 马可福音 14:1–15"> 分成块子，浇上油；这是素祭。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 2:1–2; 利未记 7:9"> 若用煎盘做的物为素祭，就要用油与细面做成。</span>
<span className="v" id="v8" data-v="8"> 要把这些东西做的素祭带到耶和华面前，并奉给祭司，带到坛前。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 2:2; 腓立比书 4:18; 利未记 6:15"> 祭司要从素祭中取出作为纪念的，烧在坛上，是献与耶和华为馨香的火祭。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 2:3"> 素祭所剩的要归给亚伦和他的子孙。这是献与耶和华的火祭中为至圣的。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="加拉太书 5:9; 路加福音 12:1; 出埃及记 23:18"> 「凡献给耶和华的素祭都不可有酵；因为你们不可烧一点酵、一点蜜当作火祭献给耶和华。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 23:19; 创世记 23:10–11; 出埃及记 22:29"> 这些物要献给耶和华作为初熟的供物，只是不可在坛上献为馨香的祭。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 43:24; 马太福音 5:13; 歌罗西书 4:6"> 凡献为素祭的供物都要用盐调和，在素祭上不可缺了你 神立约的盐。一切的供物都要配盐而献。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 23:10; 玛拉基书 1:11; 民数记 28:2"> 若向耶和华献初熟之物为素祭，要献上烘了的禾穗子，就是轧了的新穗子，当作初熟之物的素祭。</span>
<span className="v" id="v15" data-v="15"> 并要抹上油，加上乳香；这是素祭。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 5:7; 罗马书 8:26–27; 以赛亚书 61:1"> 祭司要把其中作为纪念的，就是一些轧了的禾穗子和一些油，并所有的乳香，都焚烧，是向耶和华献的火祭。」</span>
</div>

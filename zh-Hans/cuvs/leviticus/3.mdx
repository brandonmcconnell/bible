## 平安祭的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 6:14; 利未记 1:3; 罗马书 5:1–2"> 「人献供物为平安祭<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="平安：或译酬恩；下同">a</a></sup>，若是从牛群中献，无论是公的是母的，必用没有残疾的献在耶和华面前。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 29:10; 利未记 1:4–5; 使徒行传 2:36–38"> 他要按手在供物的头上，宰于会幕门口。亚伦子孙作祭司的，要把血洒在坛的周围。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 29:13; 利未记 4:8–9; 出埃及记 29:22"> 从平安祭中，将火祭献给耶和华，也要把盖脏的脂油和脏上所有的脂油，</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 3:10; 利未记 8:25; 出埃及记 29:22"> 并两个腰子和腰子上的脂油，就是靠腰两旁的脂油，与肝上的网子和腰子，一概取下。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 6:12; 出埃及记 29:13; 彼得前书 2:5"> 亚伦的子孙要把这些烧在坛的燔祭上，就是在火的柴上，是献与耶和华为馨香的火祭。</span>
<span className="v" id="v6" data-v="6" data-xref="提多书 2:11–12; 加拉太书 3:28; 利未记 1:2"> 「人向耶和华献供物为平安祭，若是从羊群中献，无论是公的是母的，必用没有残疾的。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 8:62; 以弗所书 5:12; 利未记 17:8–9"> 若献一只羊羔为供物，必在耶和华面前献上，</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 1:5; 以弗所书 3:12; 利未记 3:13"> 并要按手在供物的头上，宰于会幕前。亚伦的子孙要把血洒在坛的周围。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 29:22; 利未记 9:19; 利未记 8:25"> 从平安祭中，将火祭献给耶和华，其中的脂油和整肥尾巴都要在靠近脊骨处取下，并要把盖脏的脂油和脏上所有的脂油，</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 3:4"> 两个腰子和腰子上的脂油，就是靠腰两旁的脂油，并肝上的网子和腰子，一概取下。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 21:17; 利未记 21:6; 利未记 3:16"> 祭司要在坛上焚烧，是献给耶和华为食物的火祭。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 9:15; 以赛亚书 53:2; 哥林多后书 5:21"> 「人的供物若是山羊，必在耶和华面前献上。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 3:8; 罗马书 5:15–21; 哥林多后书 5:21"> 要按手在山羊头上，宰于会幕前。亚伦的子孙要把血洒在坛的周围，</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 26:38; 马太福音 22:37; 利未记 3:9–11"> 又把盖脏的脂油和脏上所有的脂油，两个腰子和腰子上的脂油，就是靠腰两旁的脂油，并肝上的网子和腰子，一概取下，献给耶和华为火祭。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 7:23–25; 马太福音 22:37; 以赛亚书 53:10"> 祭司要在坛上焚烧，作为馨香火祭的食物。脂油都是耶和华的。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 9:4; 马太福音 26:28; 申命记 15:23"> 在你们一切的住处，脂油和血都不可吃；这要成为你们世世代代永远的定例。」</span>

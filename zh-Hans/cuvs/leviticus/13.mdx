## 有关皮肤病的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华晓谕摩西、亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 24:8; 利未记 14:56; 利未记 14:3"> 「人的肉皮上若长了疖子，或长了癣，或长了火斑，在他肉皮上成了大麻风的灾病，就要将他带到祭司亚伦或亚伦作祭司的一个子孙面前。</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 3:19–20; 使徒行传 20:28; 玛拉基书 2:7"> 祭司要察看肉皮上的灾病，若灾病处的毛已经变白，灾病的现象深于肉上的皮，这便是大麻风的灾病。祭司要察看他，定他为不洁净。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 12:15; 哥林多前书 4:5; 提摩太前书 5:24"> 若火斑在他肉皮上是白的，现象不深于皮，其上的毛也没有变白，祭司就要将有灾病的人关锁七天。</span>
<span className="v" id="v5" data-v="5"> 第七天，祭司要察看他，若看灾病止住了，没有在皮上发散，祭司还要将他关锁七天。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 11:25; 利未记 14:8; 申命记 32:5"> 第七天，祭司要再察看他，若灾病发暗，而且没有在皮上发散，祭司要定他为洁净，原来是癣；那人就要洗衣服，得为洁净。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 38:3; 利未记 13:35–36; 提摩太后书 2:16–17"> 但他为得洁净，将身体给祭司察看以后，癣若在皮上发散开了，他要再将身体给祭司察看。</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 15:7–8; 腓立比书 3:18–19; 使徒行传 8:21"> 祭司要察看，癣若在皮上发散，就要定他为不洁净，是大麻风。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 「人有了大麻风的灾病，就要将他带到祭司面前。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 5:27; 历代志下 26:19–20; 利未记 13:14–15"> 祭司要察看，皮上若长了白疖，使毛变白，在长白疖之处有了红瘀肉，</span>
<span className="v" id="v11" data-v="11"> 这是肉皮上的旧大麻风，祭司要定他为不洁净，不用将他关锁，因为他是不洁净了。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰一书 1:8–10; 约伯记 42:6; 罗马书 7:14"> 大麻风若在皮上四外发散，长满了患灾病人的皮，据祭司察看，从头到脚无处不有，</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 9:41; 以赛亚书 64:6"> 祭司就要察看，全身的肉若长满了大麻风，就要定那患灾病的为洁净；全身都变为白，他乃洁净了。</span>
<span className="v" id="v14" data-v="14"> 但红肉几时显在他的身上就几时不洁净。</span>
<span className="v" id="v15" data-v="15"> 祭司一看那红肉就定他为不洁净。红肉本是不洁净，是大麻风。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太书 1:14–16; 罗马书 7:14–24; 腓立比书 3:6–8"> 红肉若复原，又变白了，他就要来见祭司。</span>
<span className="v" id="v17" data-v="17"> 祭司要察看，灾病处若变白了，祭司就要定那患灾病的为洁净，他乃洁净了。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 9:9; 以赛亚书 38:21; 诗篇 38:3–7"> 「人若在皮肉上长疮，却治好了，</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 13:24"> 在长疮之处又起了白疖，或是白中带红的火斑，就要给祭司察看。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 5:14; 利未记 13:3; 彼得后书 2:20"> 祭司要察看，若现象洼于皮，其上的毛也变白了，就要定他为不洁净，是大麻风的灾病发在疮中。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 5:5"> 祭司若察看，其上没有白毛，也没有洼于皮，乃是发暗，就要将他关锁七天。</span>
<span className="v" id="v22" data-v="22"> 若在皮上发散开了，祭司就要定他为不洁净，是灾病。</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 6:1; 约伯记 34:31–32; 马太福音 26:75"> 火斑若在原处止住，没有发散，便是疮的痕迹，祭司就要定他为洁净。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 3:24"> 「人的皮肉上若起了火毒，火毒的瘀肉成了火斑，或是白中带红的，或是全白的，</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 13:18–20; 利未记 13:4"> 祭司就要察看，火斑中的毛若变白了，现象又深于皮，是大麻风在火毒中发出，就要定他为不洁净，是大麻风的灾病。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 13:23; 利未记 13:4–5"> 但是祭司察看，在火斑中若没有白毛，也没有洼于皮，乃是发暗，就要将他关锁七天。</span>
<span className="v" id="v27" data-v="27"> 到第七天，祭司要察看他，火斑若在皮上发散开了，就要定他为不洁净，是大麻风的灾病。</span>
<span className="v" id="v28" data-v="28"> 火斑若在原处止住，没有在皮上发散，乃是发暗，是起的火毒，祭司要定他为洁净，不过是火毒的痕迹。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 9:15; 马太福音 13:14–15; 哥林多后书 4:3–4"> 「无论男女，若在头上有灾病，或是男人胡须上有灾病，</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 13:34–37; 利未记 14:54"> 祭司就要察看；这灾病现象若深于皮，其间有细黄毛，就要定他为不洁净，这是头疥，是头上或是胡须上的大麻风。</span>
<span className="v" id="v31" data-v="31"> 祭司若察看头疥的灾病，现象不深于皮，其间也没有黑毛，就要将长头疥灾病的关锁七天。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 13:30; 马太福音 23:5; 路加福音 18:9–12"> 第七天，祭司要察看灾病，若头疥没有发散，其间也没有黄毛，头疥的现象不深于皮，</span>
<span className="v" id="v33" data-v="33"> 那人就要剃去须发，但他不可剃头疥之处。祭司要将那长头疥的，再关锁七天。</span>
<span className="v" id="v34" data-v="34" data-xref="犹大书 1:22; 约翰一书 4:1; 启示录 2:2"> 第七天，祭司要察看头疥，头疥若没有在皮上发散，现象也不深于皮，就要定他为洁净，他要洗衣服，便成为洁净。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 13:27; 提摩太后书 2:16–17; 利未记 13:7"> 但他得洁净以后，头疥若在皮上发散开了，</span>
<span className="v" id="v36" data-v="36"> 祭司就要察看他。头疥若在皮上发散，就不必找那黄毛，他是不洁净了。</span>
<span className="v" id="v37" data-v="37"> 祭司若看头疥已经止住，其间也长了黑毛，头疥已然痊愈，那人是洁净了，就要定他为洁净。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> 「无论男女，皮肉上若起了火斑，就是白火斑，</span>
<span className="v" id="v39" data-v="39" data-xref="罗马书 7:22–25; 雅各书 3:2; 传道书 7:20"> 祭司就要察看，他们肉皮上的火斑若白中带黑，这是皮上发出的白癣，那人是洁净了。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="加拉太书 4:13; 罗马书 8:10; 雅歌 5:11"> 「人头上的发若掉了，他不过是头秃，还是洁净。</span>
<span className="v" id="v41" data-v="41"> 他顶前若掉了头发，他不过是顶门秃，还是洁净。</span>
<span className="v" id="v42" data-v="42"> 头秃处或是顶门秃处若有白中带红的灾病，这就是大麻风发在他头秃处或是顶门秃处，</span>
<span className="v" id="v43" data-v="43"> 祭司就要察看，他起的那灾病若在头秃处或是顶门秃处有白中带红的，像肉皮上大麻风的现象，</span>
<span className="v" id="v44" data-v="44" data-xref="彼得后书 2:1–2; 马太福音 6:23; 以赛亚书 1:5"> 那人就是长大麻风，不洁净的，祭司总要定他为不洁净，他的灾病是在头上。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="弥迦书 3:7; 利未记 10:6; 以西结书 24:17"> 「身上有长大麻风灾病的，他的衣服要撕裂，也要蓬头散发，蒙着上唇，喊叫说：『不洁净了！不洁净了！』</span>
<span className="v" id="v46" data-v="46" data-xref="列王纪下 7:3; 列王纪下 15:5; 历代志下 26:21"> 灾病在他身上的日子，他便是不洁净；他既是不洁净，就要独居营外。」</span>
</div>
</div>

## 衣物发霉的条例

<div className="bt">
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="犹大书 1:23; 罗马书 13:12; 以西结书 16:16"> 「染了大麻风灾病的衣服，无论是羊毛衣服、是麻布衣服，</span>
<span className="v" id="v48" data-v="48" data-xref="利未记 13:51; 启示录 3:4; 申命记 8:11"> 无论是在经上、在纬上，是麻布的、是羊毛的，是在皮子上，或在皮子做的什么物件上，</span>
<span className="v" id="v49" data-v="49"> 或在衣服上、皮子上，经上、纬上，或在皮子做的什么物件上，这灾病若是发绿，或是发红，是大麻风的灾病，要给祭司察看。</span>
<span className="v" id="v50" data-v="50" data-xref="以西结书 44:23"> 祭司就要察看那灾病，把染了灾病的物件关锁七天。</span>
<span className="v" id="v51" data-v="51" data-xref="利未记 14:44"> 第七天，他要察看那灾病，灾病或在衣服上，经上、纬上，皮子上，若发散，这皮子无论当作何用，这灾病是蚕食的大麻风，都是不洁净了。</span>
<span className="v" id="v52" data-v="52" data-xref="利未记 11:35; 利未记 11:33; 利未记 14:44–45"> 那染了灾病的衣服，或是经上、纬上，羊毛上，麻衣上，或是皮子做的什么物件上，他都要焚烧；因为这是蚕食的大麻风，必在火中焚烧。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53"> 「祭司要察看，若灾病在衣服上，经上、纬上，或是皮子做的什么物件上，没有发散，</span>
<span className="v" id="v54" data-v="54"> 祭司就要吩咐他们，把染了灾病的物件洗了，再关锁七天。</span>
<span className="v" id="v55" data-v="55" data-xref="以西结书 24:13; 希伯来书 6:4–8; 彼得后书 2:20–22"> 洗过以后，祭司要察看，那物件若没有变色，灾病也没有消散，那物件就不洁净，是透重的灾病，无论正面反面，都要在火中焚烧。</span>
<span className="v" id="v56" data-v="56"> 洗过以后，祭司要察看，若见那灾病发暗，他就要把那灾病从衣服上，皮子上，经上、纬上，都撕去。</span>
<span className="v" id="v57" data-v="57" data-xref="马太福音 22:7; 启示录 21:8; 马太福音 3:12"> 若仍现在衣服上，或是经上、纬上、皮子做的什么物件上，这就是灾病又发了，必用火焚烧那染灾病的物件。</span>
<span className="v" id="v58" data-v="58" data-xref="列王纪下 5:14; 启示录 1:5; 诗篇 51:2"> 所洗的衣服，或是经，或是纬，或是皮子做的什么物件，若灾病离开了，要再洗，就洁净了。」</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59"> 这就是大麻风灾病的条例，无论是在羊毛衣服上，麻布衣服上，经上、纬上，和皮子做的什么物件上，可以定为洁净或是不洁净。</span>
</div>
</div>

</div>

## 血的神圣

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2"> 「你晓谕亚伦和他儿子并以色列众人说，耶和华所吩咐的乃是这样：</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 17:8; 利未记 17:15; 申命记 12:5–7"> 凡以色列家中的人宰公牛，或是绵羊羔，或是山羊，不拘宰于营内营外，</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 10:7; 申命记 12:5–21; 以赛亚书 66:3"> 若未曾牵到会幕门口、耶和华的帐幕前献给耶和华为供物，流血的罪必归到那人身上。他流了血，要从民中剪除。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 22:9; 列王纪上 14:23; 历代志下 28:4"> 这是为要使以色列人把他们在田野里所献的祭带到会幕门口、耶和华面前，交给祭司，献与耶和华为平安祭。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 18:17; 利未记 3:2; 出埃及记 29:18"> 祭司要把血洒在会幕门口、耶和华的坛上，把脂油焚烧，献给耶和华为馨香的祭。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 10:20; 出埃及记 34:15; 申命记 32:17"> 他们不可再献祭给他们行邪淫所随从的鬼魔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是公山羊">a</a></sup>；这要作他们世世代代永远的定例。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 1:2–3; 利未记 17:4; 利未记 17:10"> 「你要晓谕他们说：凡以色列家中的人，或是寄居在他们中间的外人，献燔祭或是平安祭，</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 17:4"> 若不带到会幕门口献给耶和华，那人必从民中剪除。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 17:11; 利未记 3:17; 申命记 12:23"> 「凡以色列家中的人，或是寄居在他们中间的外人，若吃什么血，我必向那吃血的人变脸，把他从民中剪除。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 9:22; 约翰一书 1:7; 罗马书 3:25"> 因为活物的生命是在血中。我把这血赐给你们，可以在坛上为你们的生命赎罪；因血里有生命，所以能赎罪。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 12:49"> 因此，我对以色列人说：你们都不可吃血；寄居在你们中间的外人也不可吃血。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 12:16; 以西结书 24:7; 利未记 7:26"> 凡以色列人，或是寄居在他们中间的外人，若打猎得了可吃的禽兽，必放出它的血来，用土掩盖。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 9:4; 申命记 12:23; 利未记 17:11–12"> 「论到一切活物的生命，就在血中。所以我对以色列人说：无论什么活物的血，你们都不可吃，因为一切活物的血就是他的生命。凡吃了血的，必被剪除。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 14:21; 出埃及记 22:31; 利未记 22:8"> 凡吃自死的，或是被野兽撕裂的，无论是本地人，是寄居的，必不洁净到晚上，都要洗衣服，用水洗身，到了晚上才为洁净。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 5:1; 民数记 19:19–20; 利未记 7:18"> 但他若不洗衣服，也不洗身，就必担当他的罪孽。」</span>

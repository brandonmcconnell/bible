## 为误犯的罪献祭的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 19:12; 希伯来书 9:7; 利未记 4:27"> 「你晓谕以色列人说：若有人在耶和华所吩咐不可行的什么事上误犯了一件，</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 7:27–28; 利未记 4:14; 利未记 9:2"> 或是受膏的祭司犯罪，使百姓陷在罪里，就当为他所犯的罪把没有残疾的公牛犊献给耶和华为赎罪祭。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 1:3–4; 但以理书 9:26; 以赛亚书 53:6"> 他要牵公牛到会幕门口，在耶和华面前按手在牛的头上，把牛宰于耶和华面前。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 16:14; 民数记 19:4; 利未记 4:16–17"> 受膏的祭司要取些公牛的血带到会幕，</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 16:14; 利未记 14:18; 利未记 26:28"> 把指头蘸于血中，在耶和华面前对着圣所的幔子弹血七次，</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 8:15; 利未记 9:9; 利未记 16:18"> 又要把些血抹在会幕内、耶和华面前香坛的四角上，再把公牛所有的血倒在会幕门口、燔祭坛的脚那里。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 3:3–5; 利未记 4:26; 利未记 4:31"> 要把赎罪祭公牛所有的脂油，乃是盖脏的脂油和脏上所有的脂油，</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 3:4"> 并两个腰子和腰子上的脂油，就是靠腰两旁的脂油，与肝上的网子和腰子，一概取下，</span>
<span className="v" id="v10" data-v="10"> 与平安祭公牛上所取的一样；祭司要把这些烧在燔祭的坛上。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 19:5; 出埃及记 29:14; 利未记 9:8–11"> 公牛的皮和所有的肉，并头、腿、脏、腑、粪，</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 13:11; 出埃及记 29:14; 利未记 16:27"> 就是全公牛，要搬到营外洁净之地、倒灰之所，用火烧在柴上。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未记 5:17; 利未记 5:2–5; 何西阿书 5:15"> 「以色列全会众若行了耶和华所吩咐不可行的什么事，误犯了罪，是隐而未现、会众看不出来的，</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 4:23; 利未记 4:3; 利未记 4:28"> 会众一知道所犯的罪就要献一只公牛犊为赎罪祭，牵到会幕前。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 1:4; 利未记 16:21; 利未记 8:14"> 会中的长老就要在耶和华面前按手在牛的头上，将牛在耶和华面前宰了。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 4:5–12; 希伯来书 9:12–14"> 受膏的祭司要取些公牛的血带到会幕，</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 4:6–7"> 把指头蘸于血中，在耶和华面前对着幔子弹血七次，</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 4:7"> 又要把些血抹在会幕内、耶和华面前坛的四角上，再把所有的血倒在会幕门口、燔祭坛的脚那里。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 5:6; 利未记 4:26; 民数记 15:25"> 把牛所有的脂油都取下，烧在坛上；</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 15:25; 希伯来书 10:10–12; 利未记 12:8"> 收拾这牛，与那赎罪祭的牛一样。祭司要为他们赎罪，他们必蒙赦免。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 16:15; 马太福音 20:28; 哥林多后书 5:21"> 他要把牛搬到营外烧了，像烧头一个牛一样；这是会众的赎罪祭。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未记 4:2; 利未记 4:13; 民数记 31:13"> 「官长若行了耶和华—他 神所吩咐不可行的什么事，误犯了罪，</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 4:14; 罗马书 8:3; 民数记 7:22"> 所犯的罪自己知道了，就要牵一只没有残疾的公山羊为供物，</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 3:13; 利未记 7:2; 利未记 4:3–35"> 按手在羊的头上，宰于耶和华面前、宰燔祭牲的地方；这是赎罪祭。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 4:7; 利未记 4:18; 利未记 4:30"> 祭司要用指头蘸些赎罪祭牲的血，抹在燔祭坛的四角上，把血倒在燔祭坛的脚那里。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 4:20; 利未记 4:31; 利未记 4:35"> 所有的脂油，祭司都要烧在坛上，正如平安祭的脂油一样。至于他的罪，祭司要为他赎了，他必蒙赦免。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="利未记 4:2; 民数记 15:27; 利未记 4:13"> 「民中若有人行了耶和华所吩咐不可行的什么事，误犯了罪，</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 4:23; 利未记 4:3; 利未记 4:32"> 所犯的罪自己知道了，就要为所犯的罪牵一只没有残疾的母山羊为供物，</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 4:4; 利未记 4:24; 利未记 1:4"> 按手在赎罪祭牲的头上，在那宰燔祭牲的地方宰了。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 4:7; 利未记 4:25; 利未记 4:34"> 祭司要用指头蘸些羊的血，抹在燔祭坛的四角上，所有的血都要倒在坛的脚那里，</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 4:26; 利未记 4:35; 利未记 1:9"> 又要把羊所有的脂油都取下，正如取平安祭牲的脂油一样。祭司要在坛上焚烧，在耶和华面前作为馨香的祭，为他赎罪，他必蒙赦免。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="利未记 4:28; 彼得前书 3:18; 彼得前书 2:22"> 「人若牵一只绵羊羔为赎罪祭的供物，必要牵一只没有残疾的母羊，</span>
<span className="v" id="v33" data-v="33" data-xref="利未记 4:29–31; 利未记 4:4"> 按手在赎罪祭牲的头上，在那宰燔祭牲的地方宰了作赎罪祭。</span>
<span className="v" id="v34" data-v="34" data-xref="利未记 4:30; 利未记 4:25; 利未记 4:7"> 祭司要用指头蘸些赎罪祭牲的血，抹在燔祭坛的四角上，所有的血都要倒在坛的脚那里，</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 4:26; 利未记 4:20; 利未记 14:18"> 又要把所有的脂油都取下，正如取平安祭羊羔的脂油一样。祭司要按献给耶和华火祭的条例，烧在坛上。至于所犯的罪，祭司要为他赎了，他必蒙赦免。」</span>
</div>
</div>

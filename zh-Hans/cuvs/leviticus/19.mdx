## 圣洁和公正的法例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 11:44–45; 利未记 20:7; 彼得前书 1:15–16"> 「你晓谕以色列全会众说：你们要圣洁，因为我耶和华—你们的 神是圣洁的。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 20:12; 出埃及记 20:8; 希伯来书 12:9"> 你们各人都当孝敬父母，也要守我的安息日。我是耶和华—你们的 神。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 26:1; 出埃及记 20:23; 诗篇 115:4–7"> 你们不可偏向虚无的神，也不可为自己铸造神像。我是耶和华—你们的 神。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 22:19; 利未记 22:29; 利未记 7:16"> 你们献平安祭给耶和华的时候，要献得可蒙悦纳。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 7:11–17"> 这祭物要在献的那一天和第二天吃，若有剩到第三天的，就必用火焚烧。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 7:18–21; 利未记 22:25; 耶利米书 16:18"> 第三天若再吃，这就为可憎恶的，必不蒙悦纳。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 22:15; 利未记 5:1"> 凡吃的人必担当他的罪孽；因为他亵渎了耶和华的圣物，那人必从民中剪除。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="利未记 23:22; 申命记 24:19–22; 路得记 2:2"> 「在你们的地收割庄稼，不可割尽田角，也不可拾取所遗落的。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 17:6; 利未记 25:6; 以赛亚书 24:13"> 不可摘尽葡萄园的果子，也不可拾取葡萄园所掉的果子；要留给穷人和寄居的。我是耶和华—你们的 神。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="诗篇 101:7; 以弗所书 4:25; 歌罗西书 3:9"> 「你们不可偷盗，不可欺骗，也不可彼此说谎。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 20:7; 申命记 5:11; 利未记 18:21"> 不可指着我的名起假誓，亵渎你 神的名。我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="雅各书 5:4; 玛拉基书 3:5; 申命记 24:14–15"> 「不可欺压你的邻舍，也不可抢夺他的物。雇工人的工价，不可在你那里过夜，留到早晨。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 27:18; 利未记 19:32; 利未记 25:17"> 不可咒骂聋子，也不可将绊脚石放在瞎子面前，只要敬畏你的 神。我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命记 1:17; 箴言 24:23; 申命记 27:19"> 「你们施行审判，不可行不义；不可偏护穷人，也不可重看有势力的人，只要按着公义审判你的邻舍。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 23:1; 出埃及记 23:7; 箴言 20:19"> 不可在民中往来搬弄是非，也不可与邻舍为敌，置之于死<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是流他的血">a</a></sup>。我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰一书 2:9; 约翰一书 2:11; 路加福音 17:3"> 「不可心里恨你的弟兄；总要指摘你的邻舍，免得因他担罪。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 13:9; 马太福音 22:39–40; 马可福音 12:31–34"> 不可报仇，也不可埋怨你本国的子民，却要爱人如己。我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多后书 6:14–17; 申命记 22:9–11; 马太福音 9:16–17"> 「你们要守我的律例。不可叫你的牲畜与异类配合；不可用两样搀杂的种种你的地，也不可用两样搀杂的料做衣服穿在身上。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命记 22:23–24; 出埃及记 21:20–21"> 「婢女许配了丈夫，还没有被赎、得释放，人若与她行淫，二人要受刑罚，却不把他们治死，因为婢女还没有得自由。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 6:6–7; 利未记 5:1–6; 利未记 5:15"> 那人要把赎愆祭，就是一只公绵羊牵到会幕门口、耶和华面前。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 4:26; 利未记 4:20"> 祭司要用赎愆祭的羊在耶和华面前赎他所犯的罪，他的罪就必蒙赦免。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="利未记 22:27; 使徒行传 7:51; 耶利米书 9:25–26"> 「你们到了迦南地，栽种各样结果子的树木，就要以所结的果子如未受割礼的一样。三年之久，你们要以这些果子，如未受割礼的，是不可吃的。</span>
<span className="v" id="v24" data-v="24" data-xref="箴言 3:9; 申命记 18:4; 民数记 18:12–13"> 但第四年所结的果子全要成为圣，用以赞美耶和华。</span>
<span className="v" id="v25" data-v="25" data-xref="哈该书 1:9–11; 玛拉基书 3:8–10; 利未记 26:3–4"> 第五年，你们要吃那树上的果子，好叫树给你们结果子更多。我是耶和华—你们的 神。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="申命记 18:10–14; 列王纪下 17:17; 历代志下 33:6"> 「你们不可吃带血的物；不可用法术，也不可观兆。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 21:5; 申命记 14:1; 以西结书 44:20"> 头的周围<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：两鬓">b</a></sup>不可剃，胡须的周围也不可损坏。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 14:1; 利未记 21:5; 列王纪上 18:28"> 不可为死人用刀划身，也不可在身上刺花纹。我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="申命记 23:17–18; 利未记 21:7; 何西阿书 4:12–14"> 「不可辱没你的女儿，使她为娼妓，恐怕地上的人专向淫乱，地就满了大恶。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 26:2; 利未记 19:3; 传道书 5:1"> 你们要守我的安息日，敬我的圣所。我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 8:19; 利未记 20:27; 利未记 20:6–7"> 「不可偏向那些交鬼的和行巫术的；不可求问他们，以致被他们玷污了。我是耶和华—你们的 神。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="提摩太前书 5:1; 耶利米哀歌 5:12; 箴言 16:31"> 「在白发的人面前，你要站起来；也要尊敬老人，又要敬畏你的 神。我是耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="出埃及记 23:9; 出埃及记 22:21; 玛拉基书 3:5"> 「若有外人在你们国中和你同居，就不可欺负他。</span>
<span className="v" id="v34" data-v="34" data-xref="申命记 10:19; 利未记 19:18; 出埃及记 12:48–49"> 和你们同居的外人，你们要看他如本地人一样，并要爱他如己，因为你们在埃及地也作过寄居的。我是耶和华—你们的 神。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="申命记 25:15; 申命记 25:13; 箴言 16:11"> 「你们施行审判，不可行不义；在尺、秤、升、斗上也是如此。</span>
<span className="v" id="v36" data-v="36" data-xref="箴言 11:1; 出埃及记 20:2; 申命记 25:13–15"> 要用公道天平、公道法码、公道升斗、公道秤。我是耶和华—你们的 神，曾把你们从埃及地领出来的。</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 8:1; 利未记 18:4–5; 申命记 5:1"> 你们要谨守遵行我一切的律例典章。我是耶和华。」</span>
</div>
</div>

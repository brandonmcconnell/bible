## 尼希米胜过阻扰他工作的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 2:10; 希伯来书 11:36; 诗篇 35:15–16"> 参巴拉听见我们修造城墙就发怒，大大恼恨，嗤笑犹大人，</span>
<span className="v" id="v2" data-v="2" data-xref="以斯拉记 4:9–10; 哥林多前书 1:27; 以西结书 37:3–13"> 对他弟兄和撒马利亚的军兵说：「这些软弱的犹大人做什么呢？要保护自己吗？要献祭吗？要一日成功吗？要从土堆里拿出火烧的石头再立墙吗？」</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 2:19; 列王纪上 20:10; 尼希米记 2:10"> 亚扪人多比雅站在旁边，说：「他们所修造的石墙，就是狐狸上去也必跐倒。」</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 79:12; 诗篇 123:3–4; 箴言 3:34"> 我们的 神啊，求你垂听，因为我们被藐视。求你使他们的毁谤归于他们的头上，使他们在掳到之地作为掠物。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 109:14; 耶利米书 18:23; 诗篇 69:27–28"> 不要遮掩他们的罪孽，不要使他们的罪恶从你面前涂抹，因为他们在修造的人眼前惹动你的怒气。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="腓立比书 2:13; 尼希米记 6:15; 希伯来书 13:21"> 这样，我们修造城墙，城墙就都连络，高至一半，因为百姓专心做工。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="尼希米记 2:10; 尼希米记 4:1; 使徒行传 5:33"> 参巴拉、多比雅、阿拉伯人、亚扪人、亚实突人听见修造耶路撒冷城墙，着手进行堵塞破裂的地方，就甚发怒。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 83:3–11; 以赛亚书 8:9–10; 耶利米书 20:10"> 大家同谋要来攻击耶路撒冷，使城内扰乱。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 5:8; 使徒行传 4:24–30; 诗篇 50:15"> 然而，我们祷告我们的 神，又因他们的缘故，就派人看守，昼夜防备。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="诗篇 11:1–2; 哈该书 1:2; 历代志下 2:18"> 犹大人说：「灰土尚多，扛抬的人力气已经衰败，所以我们不能建造城墙。」</span>
<span className="v" id="v11" data-v="11" data-xref="帖撒罗尼迦前书 5:2; 使徒行传 23:12; 诗篇 56:6"> 我们的敌人且说：「趁他们不知不见，我们进入他们中间，杀他们，使工作止住。」</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 31:7; 创世记 31:41; 民数记 14:22"> 那靠近敌人居住的犹大人十次从各处来见我们，说：「你们必要回到我们那里。」</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 4:17–18; 以弗所书 6:11–20; 雅歌 3:7–8"> 所以我使百姓各按宗族拿刀、拿枪、拿弓站在城墙后边低洼的空处。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 10:12; 民数记 14:9; 以赛亚书 41:10–14"> 我察看了，就起来对贵胄、官长，和其余的人说：「不要怕他们！当记念主是大而可畏的。你们要为弟兄、儿女、妻子、家产争战。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 17:14; 罗马书 12:11; 约伯记 5:12–13"> 仇敌听见我们知道他们的心意，见 神也破坏他们的计谋，就不来了。我们都回到城墙那里，各做各的工。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米记 4:23; 诗篇 101:6; 尼希米记 5:15–16"> 从那日起，我的仆人一半做工，一半拿枪、拿盾牌、拿弓、穿<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：拿">a</a></sup>铠甲，官长都站在犹大众人的后边。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 6:7; 提摩太后书 4:7; 提摩太后书 2:3"> 修造城墙的，扛抬材料的，都一手做工一手拿兵器。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 10:9; 历代志下 13:12–17"> 修造的人都腰间佩刀修造，吹角的人在我旁边。</span>
<span className="v" id="v19" data-v="19"> 我对贵胄、官长，和其余的人说：「这工程浩大，我们在城墙上相离甚远；</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 14:14; 申命记 1:30; 申命记 20:4"> 你们听见角声在哪里，就聚集到我们那里去。我们的 神必为我们争战。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="加拉太书 6:9; 歌罗西书 1:29; 哥林多前书 15:58"> 于是，我们做工，一半拿兵器，从天亮直到星宿出现的时候。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米记 11:1–2"> 那时，我又对百姓说：「各人和他的仆人当在耶路撒冷住宿，好在夜间保守我们，白昼做工。」</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 9:48; 尼希米记 7:2; 哥林多前书 15:10"> 这样，我和弟兄仆人，并跟从我的护兵都不脱衣服，出去打水也带兵器。</span>
</div>
</div>

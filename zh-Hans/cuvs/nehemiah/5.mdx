## 尼希米处理官长们的剥削

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 5:7; 出埃及记 22:25–27; 哥林多前书 6:6–8"> 百姓和他们的妻大大呼号，埋怨他们的弟兄犹大人。</span>
<span className="v" id="v2" data-v="2" data-xref="玛拉基书 2:2; 诗篇 128:2–4; 诗篇 127:3–5"> 有的说：「我们和儿女人口众多，要去得粮食度命」；</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 25:35–39; 玛拉基书 3:8–11; 创世记 47:15–25"> 有的说：「我们典了田地、葡萄园、房屋，要得粮食充饥」；</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉记 4:13; 以斯拉记 4:20; 申命记 28:47–48"> 有的说：「我们已经指着田地、葡萄园，借了钱给王纳税。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 4:1; 利未记 25:39–43; 以赛亚书 58:7"> 我们的身体与我们弟兄的身体一样；我们的儿女与他们的儿女一般。现在我们将要使儿女作人的仆婢，我们的女儿已有为婢的；我们并无力拯救，因为我们的田地、葡萄园已经归了别人。」</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 11:8; 尼希米记 13:25; 以弗所书 4:26"> 我听见他们呼号说这些话，便甚发怒。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 23:19–20; 利未记 25:36; 出埃及记 22:25"> 我心里筹划，就斥责贵胄和官长说：「你们各人向弟兄取利！」于是我招聚大会攻击他们。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 25:47–49; 哥林多前书 8:11; 马太福音 25:29"> 我对他们说：「我们尽力赎回我们弟兄，就是卖与外邦的犹大人；你们还要卖弟兄，使我们赎回来吗？」他们就静默不语，无话可答。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 25:36; 撒母耳记下 12:14; 罗马书 2:24"> 我又说：「你们所行的不善！你们行事不当敬畏我们的 神吗？不然，难免我们的仇敌外邦人毁谤我们。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 6:1; 出埃及记 22:25–27; 以西结书 18:13"> 我和我的弟兄与仆人也将银钱粮食借给百姓；我们大家都当免去利息。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 58:6; 利未记 6:4–5; 路加福音 3:8"> 如今我劝你们将他们的田地、葡萄园、橄榄园、房屋，并向他们所取的银钱、粮食、新酒，和油，百分之一的利息都归还他们。」</span>
<span className="v" id="v12" data-v="12" data-xref="以斯拉记 10:5; 耶利米书 34:8–10; 马太福音 19:21–22"> 众人说：「我们必归还，不再向他们索要，必照你的话行。」我就召了祭司来，叫众人起誓，必照着所应许的而行。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 18:6; 历代志上 16:36; 马太福音 10:14"> 我也抖着胸前的衣襟，说：「凡不成就这应许的，愿 神照样抖他离开家产和他劳碌得来的，直到抖空了。」会众都说：「阿们！」又赞美耶和华。百姓就照着所应许的去行。</span>
</div>
</div>

## 尼希米大公无私

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="尼希米记 13:6; 帖撒罗尼迦后书 3:8–9; 哥林多前书 9:4–15"> 自从我奉派作犹大地的省长，就是从亚达薛西王二十年直到三十二年，共十二年之久，我与我弟兄都没有吃省长的俸禄。</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米记 5:9; 以赛亚书 50:10; 箴言 16:6"> 在我以前的省长加重百姓的担子，每日索要粮食和酒，并银子四十舍客勒，就是他们的仆人也辖制百姓；但我因敬畏 神不这样行。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太书 6:9; 帖撒罗尼迦前书 2:5–6; 哥林多前书 15:58"> 并且我恒心修造城墙，并没有置买田地；我的仆人也都聚集在那里做工。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 18:19; 彼得前书 4:9–10; 撒母耳记下 9:7"> 除了从四围外邦中来的犹大人以外，有犹大平民和官长一百五十人在我席上吃饭。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 4:22–23; 诗篇 37:21; 诗篇 37:26"> 每日预备一只公牛，六只肥羊，又预备些飞禽；每十日一次，多预备各样的酒。虽然如此，我并不要省长的俸禄，因为百姓服役甚重。</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米记 13:31; 诗篇 106:4; 尼希米记 13:14"> 我的 神啊，求你记念我为这百姓所行的一切事，施恩与我。</span>
</div>

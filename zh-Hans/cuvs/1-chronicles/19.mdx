## 大卫击败亚扪人和亚兰人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 11:1–2; 撒母耳记下 10:1–19; 撒母耳记上 12:12"> 此后，亚扪人的王拿辖死了，他儿子接续他作王。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 23:3–6; 撒母耳记上 30:26; 创世记 19:37–38"> 大卫说：「我要照哈嫩的父亲拿辖厚待我的恩典厚待哈嫩。」于是大卫差遣使者为他丧父安慰他。大卫的臣仆到了亚扪人的境内见哈嫩，要安慰他，</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 1:23–24; 哥林多前书 13:5–7; 列王纪上 12:8–11"> 但亚扪人的首领对哈嫩说：「大卫差人来安慰你，你想他是尊敬你父亲吗？他的臣仆来见你不是为详察窥探、倾覆这地吗？」</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 10:4–5; 以赛亚书 15:2; 马可福音 12:4"> 哈嫩便将大卫臣仆的胡须剃去一半，又割断他们下半截的衣服，使他们露出下体，打发他们回去。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 6:24–26; 马太福音 18:31; 列王纪上 16:34"> 有人将臣仆所遇的事告诉大卫，他就差人去迎接他们，因为他们甚觉羞耻；告诉他们说：「可以住在耶利哥，等到胡须长起再回来。」</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 18:5; 创世记 34:30; 历代志上 18:9"> 亚扪人知道大卫憎恶他们，哈嫩和亚扪人就打发人拿一千他连得银子，从美索不达米亚、亚兰、玛迦、琐巴雇战车和马兵，</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 21:30; 约书亚记 13:9; 约书亚记 13:16"> 于是雇了三万二千辆战车和玛迦王并他的军兵；他们来安营在米底巴前。亚扪人也从他们的城里出来，聚集交战。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志上 11:6; 历代志上 11:10–47; 撒母耳记下 23:8–39"> 大卫听见了，就差派约押统带勇猛的全军出去。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 20:1; 列王纪上 20:24; 以赛亚书 28:6"> 亚扪人出来在城门前摆阵，所来的诸王另在郊野摆阵。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 10:9–14; 士师记 20:42–43; 约书亚记 8:22"> 约押看见敌人在他前后摆阵，就从以色列军中挑选精兵，使他们对着亚兰人摆阵；</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 18:12; 历代志上 11:20; 历代志上 19:9"> 其余的兵交与他兄弟亚比筛，对着亚扪人摆阵。</span>
<span className="v" id="v12" data-v="12" data-xref="腓立比书 1:27–28; 尼希米记 4:20; 传道书 4:9–12"> 约押对亚比筛说：「亚兰人若强过我，你就来帮助我；亚扪人若强过你，我就去帮助你。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 4:14; 诗篇 27:14; 撒母耳记下 10:12"> 我们都当刚强，为本国的民和 神的城邑作大丈夫，愿耶和华凭他的意旨而行。」</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 20:19–21; 历代志下 13:5–16; 耶利米书 46:15–16"> 于是约押和跟随他的人前进攻打亚兰人；亚兰人在约押面前逃跑。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 8:31; 利未记 26:7"> 亚扪人见亚兰人逃跑，他们也在约押的兄弟亚比筛面前逃跑进城。约押就回耶路撒冷去了。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 10:16; 撒迦利亚书 14:1–3; 弥迦书 4:11–12"> 亚兰人见自己被以色列人打败，就打发使者将大河那边的亚兰人调来，哈大利谢的将军朔法率领他们。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 22:6–7; 历代志上 19:9"> 有人告诉大卫，他就聚集以色列众人过约旦河，来到亚兰人那里，迎着他们摆阵。大卫既摆阵攻击亚兰人，亚兰人就与他打仗。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 10:18; 诗篇 33:16; 诗篇 18:32"> 亚兰人在以色列人面前逃跑。大卫杀了亚兰七千辆战车的人，四万步兵，又杀了亚兰的将军朔法。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 10:19; 约书亚记 9:9–11; 列王纪上 20:1"> 属哈大利谢的诸王见自己被以色列人打败，就与大卫和好，归服他。于是亚兰人不敢再帮助亚扪人了。</span>

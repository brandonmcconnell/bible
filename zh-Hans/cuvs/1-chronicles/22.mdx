## 筹备建殿

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="历代志下 2:17; 列王纪上 9:20–21; 列王纪上 5:17–18"> 大卫吩咐聚集住以色列地的外邦人，从其中派石匠凿石头，要建造 神的殿。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 22:14; 历代志上 29:2; 列王纪上 7:47"> 大卫预备许多铁做门上的钉子和钩子，又预备许多铜，多得无法可称；</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 5:6–10; 以斯拉记 3:7; 历代志下 2:3"> 又预备无数的香柏木，因为西顿人和泰尔人给大卫运了许多香柏木来。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 3:7; 历代志上 29:1; 约翰福音 3:30"> 大卫说：「我儿子所罗门还年幼娇嫩，要为耶和华建造的殿宇必须高大辉煌，使名誉荣耀传遍万国；所以我要为殿预备材料。」于是，大卫在未死之先预备的材料甚多。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 27:23; 使徒行传 20:25–31; 使徒行传 1:2"> 大卫召了他儿子所罗门来，嘱咐他给耶和华—以色列的 神建造殿宇，</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 132:5; 列王纪上 8:16–20; 历代志下 6:7–9"> 对所罗门说：「我儿啊，我心里本想为耶和华—我 神的名建造殿宇，</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 5:3; 历代志上 28:3; 历代志上 17:4–10"> 只是耶和华的话临到我说：『你流了多人的血，打了多次大仗，你不可为我的名建造殿宇，因为你在我眼前使多人的血流在地上。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 4:25; 列王纪上 5:4; 列王纪上 4:20"> 你要生一个儿子，他必作太平的人；我必使他安静，不被四围的仇敌扰乱。他的名要叫所罗门<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是太平的意思">a</a></sup>。他在位的日子，我必使以色列人平安康泰。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 1:5; 撒母耳记下 7:13–14; 历代志上 17:12–14"> 他必为我的名建造殿宇。他要作我的子；我要作他的父。他作以色列王；我必坚定他的国位，直到永远。』</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 22:16; 历代志上 28:20; 提摩太后书 4:22"> 我儿啊，现今愿耶和华与你同在，使你亨通，照他指着你说的话，建造耶和华—你 神的殿。</span>
<span className="v" id="v12" data-v="12" data-xref="雅各书 1:5; 箴言 14:8; 列王纪上 3:9–12"> 但愿耶和华赐你聪明智慧，好治理以色列国，遵行耶和华—你 神的律法。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 1:6–9; 历代志上 28:20; 历代志上 28:7"> 你若谨守遵行耶和华借摩西吩咐以色列的律例典章，就得亨通。你当刚强壮胆，不要惧怕，也不要惊惶。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志上 22:3; 列王纪下 25:16; 历代志上 29:4–7"> 我在困难之中为耶和华的殿预备了金子十万他连得，银子一百万他连得，铜和铁多得无法可称；我也预备了木头、石头，你还可以增添。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 28:6; 出埃及记 35:32; 列王纪上 7:14"> 你有许多匠人，就是石匠、木匠，和一切能做各样工的巧匠，</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 22:11; 腓立比书 4:13; 以弗所书 5:14"> 并有无数的金银铜铁。你当起来办事，愿耶和华与你同在。」</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 28:1–6; 约翰三书 1:8; 历代志上 29:6"> 大卫又吩咐以色列的众首领帮助他儿子所罗门，说：</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 22:9; 历代志上 23:25; 撒母耳记下 7:1"> 「耶和华—你们的 神不是与你们同在吗？不是叫你们四围都平安吗？因他已将这地的居民交在我手中，这地就在耶和华与他百姓面前制伏了。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 28:9; 申命记 4:29; 历代志上 16:11"> 现在你们应当立定心意，寻求耶和华—你们的 神；也当起来建造耶和华 神的圣所，好将耶和华的约柜和供奉 神的圣器皿都搬进为耶和华名建造的殿里。」</span>
</div>

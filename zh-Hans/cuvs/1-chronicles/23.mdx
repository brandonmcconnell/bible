## 利未人的职务

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="约书亚记 24:1; 历代志下 34:29–30; 历代志上 13:1"> 大卫招聚以色列的众首领和祭司利未人。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 23:24; 民数记 4:2–49"> 利未人从三十岁以外的都被数点，他们男丁的数目共有三万八千；</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 19:8; 申命记 16:18; 历代志上 26:29–31"> 其中有二万四千人管理耶和华殿的事，有六千人作官长和士师，</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 29:25–26; 历代志下 8:14; 诗篇 87:7"> 有四千人作守门的，又有四千人用大卫所做的乐器颂赞耶和华。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 8:14; 历代志上 6:1; 历代志上 6:16"> 大卫将利未人革顺、哥辖、米拉利的子孙分了班次。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 26:21; 出埃及记 6:17; 历代志上 6:17–20"> 革顺的子孙有拉但和示每。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志上 6:33–34; 历代志上 15:20–21; 历代志上 15:7"> 拉但的长子是耶歇，还有细坦和约珥，共三人。</span>
<span className="v" id="v9" data-v="9"> 示每的儿子是示罗密、哈薛、哈兰三人。这是拉但族的族长。</span>
<span className="v" id="v10" data-v="10"> 示每的儿子是雅哈、细拿、耶乌施、比利亚共四人。</span>
<span className="v" id="v11" data-v="11"> 雅哈是长子，细撒是次子。但耶乌施和比利亚的子孙不多，所以算为一族。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 6:18; 民数记 3:27; 民数记 26:58"> 哥辖的儿子是暗兰、以斯哈、希伯伦、乌薛共四人。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 21:5; 出埃及记 6:20; 撒母耳记上 2:28"> 暗兰的儿子是亚伦、摩西。亚伦和他的子孙分出来，好分别至圣的物，在耶和华面前烧香、事奉他，奉他的名祝福，直到永远。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 33:1; 诗篇 90:1; 历代志上 26:23–25"> 至于神人摩西，他的子孙名字记在利未支派的册上。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 18:3–4; 出埃及记 2:22; 出埃及记 4:20"> 摩西的儿子是革舜和以利以谢。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 26:24; 历代志上 25:20; 历代志上 24:20"> 革舜的长子是细布业；</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 26:25"> 以利以谢的儿子是利哈比雅。以利以谢没有别的儿子，但利哈比雅的子孙甚多。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 26:26; 历代志上 24:22"> 以斯哈的长子是示罗密。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 24:23; 历代志上 15:9; 历代志上 23:12"> 希伯伦的长子是耶利雅，次子是亚玛利亚，三子是雅哈悉，四子是耶加面。</span>
<span className="v" id="v20" data-v="20"> 乌薛的长子是米迦，次子是耶西雅。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 6:19; 历代志上 6:20; 历代志上 24:26–30"> 米拉利的儿子是抹利、母示。抹利的儿子是以利亚撒、基士。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 24:28; 民数记 36:6–8"> 以利亚撒死了，没有儿子，只有女儿，他们本族基士的儿子娶了她们为妻。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 24:30"> 母示的儿子是末力、以得、耶利摩共三人。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 10:17; 民数记 10:21; 历代志上 23:3"> 以上利未子孙作族长的，照着男丁的数目，从二十岁以外，都办耶和华殿的事务。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 132:13–14; 历代志上 22:18; 撒母耳记下 7:11"> 大卫说：「耶和华—以色列的 神已经使他的百姓平安，他永远住在耶路撒冷。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 4:5; 民数记 7:9; 民数记 4:15"> 利未人不必再抬帐幕和其中所用的一切器皿了。」</span>
<span className="v" id="v27" data-v="27" data-xref="历代志上 23:24; 诗篇 72:20; 撒母耳记下 23:1"> 照着大卫临终所吩咐的，利未人从二十岁以外的都被数点。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 35:3–6; 历代志下 31:11; 历代志下 35:11–14"> 他们的职任是服事亚伦的子孙，在耶和华的殿和院子，并屋中办事，洁净一切圣物，就是办 神殿的事务，</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 19:35–36; 出埃及记 25:30; 利未记 6:20–23"> 并管理陈设饼，素祭的细面，或无酵薄饼，或用盘烤，或用油调和的物，又管理各样的升斗尺度；</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 92:1–3; 以斯拉记 3:10–11; 历代志上 9:33"> 每日早晚，站立称谢赞美耶和华，</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 1:13–14; 民数记 28:1–29; 民数记 10:10"> 又在安息日、月朔，并节期，按数照例，将燔祭常常献给耶和华；</span>
<span className="v" id="v32" data-v="32" data-xref="民数记 1:53; 民数记 3:38; 民数记 3:6–9"> 又看守会幕和圣所，并守耶和华吩咐他们弟兄亚伦子孙的，办耶和华殿的事。</span>

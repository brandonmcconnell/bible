## 颂赞之歌

<div className="bt">
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="诗篇 105:1–15; 以赛亚书 12:4; 列王纪下 19:19"> <span className="pl pl-1">你们要称谢耶和华，求告他的名，</span><br /><span className="pl pl-1">在万民中传扬他的作为！</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 3:16; 诗篇 96:1–3; 诗篇 98:1–4"> <span className="pl pl-1">要向他唱诗、歌颂，</span><br /><span className="pl pl-1">谈论他一切奇妙的作为。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 7:7–8; 耶利米书 29:13; 诗篇 34:2"> <span className="pl pl-1">要以他的圣名夸耀；</span><br /><span className="pl pl-1">寻求耶和华的人，心中应当欢喜。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 27:8–9; 西番雅书 2:2–3; 诗篇 68:35"> <span className="pl pl-1">要寻求耶和华与他的能力，</span><br /><span className="pl pl-1">时常寻求他的面。</span><br /></span>

<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="诗篇 48:10–11; 以赛亚书 26:9; 出埃及记 15:2"> <span className="pl pl-1">他是耶和华—我们的 神，</span><br /><span className="pl pl-1">全地都有他的判断。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 105:8; 玛拉基书 4:4; 申命记 7:9"> <span className="pl pl-1">你们要记念他的约，直到永远；</span><br /><span className="pl pl-1">他所吩咐的话，直到千代，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="创世记 26:3; 创世记 17:2; 创世记 35:11"> <span className="pl pl-1">就是与亚伯拉罕所立的约，</span><br /><span className="pl pl-1">向以撒所起的誓。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="创世记 17:7–8; 创世记 35:11–12; 约书亚记 24:11–13"> <span className="pl pl-1">他又将这约向雅各定为律例，</span><br /><span className="pl pl-1">向以色列定为永远的约，</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="创世记 13:15; 弥迦书 2:5; 创世记 17:8"> <span className="pl pl-1">说：我必将迦南地赐给你，</span><br /><span className="pl pl-1">作你产业的分。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="创世记 34:30; 申命记 7:7; 使徒行传 7:5"> <span className="pl pl-1">当时你们人丁有限，数目稀少，</span><br /><span className="pl pl-1">并且在那地为寄居的；</span><br /></span>

<span className="v" id="v22" data-v="22" data-xref="创世记 20:7; 诗篇 105:15; 创世记 49:8–10"> <span className="pl pl-1">说：不可难为我受膏的人，</span><br /><span className="pl pl-1">也不可恶待我的先知！</span></span>

<span className="v" id="v23" data-v="23" data-xref="诗篇 96:1–13; 诗篇 71:15; 以赛亚书 51:6–8"> <span className="pl pl-1">全地都要向耶和华歌唱！</span><br /><span className="pl pl-1">天天传扬他的救恩，</span><br /></span>

<span className="v" id="v26" data-v="26" data-xref="诗篇 102:25; 利未记 19:4; 以赛亚书 42:5"> <span className="pl pl-1">外邦的神都属虚无，</span><br /><span className="pl pl-1">惟独耶和华创造诸天。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 16:11; 诗篇 96:6; 诗篇 28:7–8"> <span className="pl pl-1">有尊荣和威严在他面前，</span><br /><span className="pl pl-1">有能力和喜乐在他圣所。</span></span>

## 在耶路撒冷和基遍的敬拜

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="历代志下 8:14; 以斯拉记 3:4; 历代志上 16:4–6"> 大卫派亚萨和他的弟兄在约柜前常常事奉耶和华，一日尽一日的职分；</span>
<span className="v" id="v38" data-v="38" data-xref="历代志上 26:10; 历代志上 13:14; 历代志上 25:3"> 又派俄别·以东和他的弟兄六十八人，与耶杜顿的儿子俄别·以东，并何萨作守门的；</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪上 3:4; 历代志上 15:11; 历代志下 1:3–4"> 且派祭司撒督和他弟兄众祭司在基遍的邱坛、耶和华的帐幕前燔祭坛上，每日早晚，照着耶和华律法书上所吩咐以色列人的，常给耶和华献燔祭。</span>
<span className="v" id="v41" data-v="41" data-xref="历代志下 5:13; 历代志上 25:1–6; 历代志下 20:21"> 与他们一同被派的有希幔、耶杜顿，和其余被选名字录在册上的，称谢耶和华，因他的慈爱永远长存。</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 150:3–6; 历代志上 25:6–7; 历代志下 29:25–28"> 希幔、耶杜顿同着他们吹号、敲钹，大发响声，并用别的乐器随着歌颂 神。耶杜顿的子孙作守门的。</span>
</div>

## 被掳归回的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 7:64; 历代志上 5:25–26; 耶利米书 52:14–15"> 以色列人都按家谱计算，写在以色列诸王记上。犹大人因犯罪就被掳到巴比伦。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米记 7:73; 以斯拉记 2:58; 以斯拉记 2:70"> 先从巴比伦回来，住在自己地业城邑中的有以色列人、祭司、利未人、尼提宁的首领。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 11:1; 历代志下 11:16; 尼希米记 11:4–9"> 住在耶路撒冷的有犹大人、便雅悯人、以法莲人、玛拿西人。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 2:5; 创世记 46:12; 民数记 26:20"> 犹大儿子法勒斯的子孙中有乌太。乌太是亚米忽的儿子；亚米忽是暗利的儿子；暗利是音利的儿子；音利是巴尼的儿子。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 26:20; 尼希米记 11:5"> 示罗的子孙中有长子亚帅雅和他的众子。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 26:20; 历代志上 2:6; 创世记 38:30"> 谢拉的子孙中有耶乌利和他的弟兄，共六百九十人。</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米记 10:20; 尼希米记 11:7; 尼希米记 8:4"> 便雅悯人中有哈西努的曾孙、何达威雅的孙子、米书兰的儿子撒路，</span>
<span className="v" id="v8" data-v="8"> 又有耶罗罕的儿子伊比尼雅，米基立的孙子、乌西的儿子以拉，伊比尼雅的曾孙、流珥的孙子、示法提雅的儿子米书兰，</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米记 11:8"> 和他们的族弟兄，按着家谱计算共有九百五十六名。这些人都是他们的族长。</span>
</div>
</div>

## 住在耶路撒冷的祭司

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="尼希米记 12:19; 尼希米记 11:10–24"> 祭司中有耶大雅、耶何雅立、雅斤，</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 11:11; 列王纪下 25:18; 民数记 4:33"> 还有管理 神殿希勒家的儿子亚萨利雅。希勒家是米书兰的儿子；米书兰是撒督的儿子；撒督是米拉约的儿子；米拉约是亚希突的儿子。</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米记 7:40; 以斯拉记 2:37; 尼希米记 11:12–13"> 有玛基雅的曾孙、巴施户珥的孙子、耶罗罕的儿子亚大雅，又有亚第业的儿子玛赛；亚第业是雅希细拉的儿子；雅希细拉是米书兰的儿子；米书兰是米实利密的儿子；米实利密是音麦的儿子。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 11:14; 历代志上 26:30; 历代志上 26:32"> 他们和众弟兄都是族长，共有一千七百六十人，是善于做 神殿使用之工的。</span>
</div>
</div>

## 住在耶路撒冷的利未人

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 26:57; 尼希米记 10:11; 历代志上 6:29"> 利未人米拉利的子孙中，有哈沙比雅的曾孙、押利甘的孙子、哈述的儿子示玛雅。</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米记 11:22; 尼希米记 11:17; 历代志上 11:17"> 有拔巴甲、黑勒施、迦拉，并亚萨的曾孙、细基利的孙子、米迦的儿子玛探雅，</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 25:1; 历代志下 35:15; 历代志上 12:25"> 又有耶杜顿的曾孙、迦拉的孙子、示玛雅的儿子俄巴底，还有以利加拿的孙子、亚撒的儿子比利家。他们都住在尼陀法人的村庄。</span>
</div>
</div>

## 住在耶路撒冷的圣殿守卫

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="历代志上 26:1–32; 历代志上 23:5; 尼希米记 11:19"> 守门的是沙龙、亚谷、达们、亚希幔，和他们的弟兄；沙龙为长。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 46:1–2; 以西结书 44:2–3; 列王纪上 10:5"> 从前这些人看守朝东的王门，如今是利未营中守门的。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 26:9–11; 诗篇 44:1; 列王纪下 11:15"> 可拉的曾孙、以比雅撒的孙子、可利的儿子沙龙，和他的族弟兄可拉人都管理使用之工，并守会幕的门。他们的祖宗曾管理耶和华的营盘，又把守营门。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 31:6; 民数记 3:32; 民数记 4:33"> 从前以利亚撒的儿子非尼哈管理他们，耶和华也与他同在。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 26:14; 历代志上 26:2"> 米施利米雅的儿子撒迦利雅是看守会幕之门的。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 9:9; 历代志上 28:13; 历代志上 23:1–32"> 被选守门的人共有二百一十二名。他们在自己的村庄，按着家谱计算，是大卫和先见撒母耳所派当这紧要职任的。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 44:14; 历代志下 23:19; 以西结书 44:10–11"> 他们和他们的子孙按着班次看守耶和华殿的门，就是会幕的门。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 26:14–18"> 在东西南北，四方都有守门的。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 11:5; 历代志下 23:8; 列王纪下 11:7"> 他们的族弟兄住在村庄，每七日来与他们换班。</span>
<span className="v" id="v26" data-v="26" data-xref="尼希米记 13:5; 尼希米记 10:38–39; 历代志上 26:20–27"> 这四个门领都是利未人，各有紧要的职任，看守 神殿的仓库。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志上 23:30–32; 玛拉基书 1:10; 撒母耳记上 3:15"> 他们住在 神殿的四围，是因委托他们守殿，要每日早晨开门。</span>
</div>
</div>

## 其余的利未人

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="尼希米记 13:4–5; 尼希米记 12:44; 历代志上 26:22–26"> 利未人中有管理使用器皿的，按着数目拿出拿入；</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 23:29; 出埃及记 30:23–38; 出埃及记 27:20"> 又有人管理器具和圣所的器皿，并细面、酒、油、乳香、香料。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 30:23–25; 出埃及记 37:29; 出埃及记 30:35–38"> 祭司中有人用香料做膏油。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 9:19; 历代志上 9:22; 利未记 6:21"> 利未人玛他提雅是可拉族沙龙的长子，他紧要的职任是管理盘中烤的物。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 24:5–8; 历代志上 6:33–48; 出埃及记 25:30"> 他们族弟兄哥辖子孙中，有管理陈设饼的，每安息日预备摆列。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="历代志上 6:31–33; 诗篇 134:1–2; 历代志上 16:4–6"> 歌唱的有利未人的族长，住在属殿的房屋，昼夜供职，不做别样的工。</span>
<span className="v" id="v34" data-v="34" data-xref="尼希米记 11:1–15; 历代志上 9:13"> 以上都是利未人著名的族长，住在耶路撒冷。</span>
</div>
</div>

## 扫罗王的祖先和后代

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="历代志上 2:23–24; 历代志上 2:50–52; 历代志上 8:29–40"> 在基遍住的有基遍的父亲耶利。他的妻名叫玛迦；</span>
<span className="v" id="v36" data-v="36" data-xref="历代志上 9:39; 历代志上 8:33"> 他长子是亚伯顿。他又生苏珥、基士、巴力、尼珥、拿答、</span>
<span className="v" id="v37" data-v="37" data-xref="历代志上 8:31"> 基多、亚希约、撒迦利雅、米基罗。</span>
<span className="v" id="v38" data-v="38" data-xref="历代志上 8:32"> 米基罗生示米暗。这些人和他们的弟兄在耶路撒冷对面居住。</span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳记上 13:22; 历代志上 8:33–38; 历代志上 10:2"> 尼珥生基士；基士生扫罗；扫罗生约拿单、麦基舒亚、亚比拿达、伊施·巴力。</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳记下 4:4; 历代志上 8:34–36"> 约拿单的儿子是米力·巴力<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是米非波设">a</a></sup>；米力·巴力生米迦。</span>
<span className="v" id="v41" data-v="41" data-xref="历代志上 8:35"> 米迦的儿子是毗敦、米勒、他利亚、亚哈斯。</span>
<span className="v" id="v42" data-v="42" data-xref="历代志上 8:36"> 亚哈斯生雅拉；雅拉生亚拉篾、亚斯玛威、心利；心利生摩撒；</span>
<span className="v" id="v43" data-v="43" data-xref="历代志上 8:37"> 摩撒生比尼亚；比尼亚生利法雅；利法雅的儿子是以利亚萨；以利亚萨的儿子是亚悉。</span>
<span className="v" id="v44" data-v="44"> 亚悉有六个儿子，他们的名字是亚斯利干、波基路、以实玛利、示亚利雅、俄巴底雅、哈难。这都是亚悉的儿子。</span>
</div>

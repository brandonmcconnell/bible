## 圣殿的卫队

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 23:19; 民数记 26:9–11; 诗篇 44:1"> 守门的班次记在下面：可拉族亚萨的子孙中，有可利的儿子米施利米雅。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 9:21"> 米施利米雅的长子是撒迦利亚，次子是耶叠，三子是西巴第雅，四子是耶提聂，</span>
<span className="v" id="v3" data-v="3"> 五子是以拦，六子是约哈难，七子是以利约乃。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 16:38; 历代志上 15:24; 历代志上 15:18"> 俄别·以东的长子是示玛雅，次子是约萨拔，三子是约亚，四子是沙甲，五子是拿坦业，</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 128:1"> 六子是亚米利，七子是以萨迦，八子是毗乌利太，因为 神赐福与俄别·以东。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 12:28; 提摩太前书 6:12; 士师记 6:12"> 他的儿子示玛雅有几个儿子，都是大能的壮士，掌管父亲的家。</span>
<span className="v" id="v7" data-v="7"> 示玛雅的儿子是俄得尼、利法益、俄备得、以利萨巴。以利萨巴的弟兄是壮士，还有以利户和西玛迦。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 3:6; 彼得前书 4:11; 哥林多前书 12:4–11"> 这都是俄别·以东的子孙，他们和他们的儿子并弟兄，都是善于办事的壮士。俄别·以东的子孙共六十二人。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 26:14; 历代志上 26:1"> 米施利米雅的儿子和弟兄都是壮士，共十八人。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 16:38; 历代志上 5:1–2"> 米拉利子孙何萨有几个儿子：长子是申利，他原不是长子，是他父亲立他作长子。</span>
<span className="v" id="v11" data-v="11"> 次子是希勒家，三子是底巴利雅，四子是撒迦利亚。何萨的儿子并弟兄共十三人。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 25:8"> 这些人都是守门的班长，与他们的弟兄一同在耶和华殿里按班供职。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 25:8; 历代志上 24:31; 历代志上 24:5"> 他们无论大小，都按着宗族掣签分守各门。</span>
<span className="v" id="v14" data-v="14"> 掣签守东门的是示利米雅；他的儿子撒迦利亚是精明的谋士，掣签守北门。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 25:24; 历代志上 26:17"> 俄别·以东守南门，他的儿子守库房。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米记 12:24; 历代志上 26:10–12; 列王纪上 10:5"> 书聘与何萨守西门，在靠近沙利基门、通着往上去的街道上，班与班相对。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 8:14; 历代志上 9:24"> 每日东门有六个利未人，北门有四个，南门有四个，库房有两个，又有两个轮班替换。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 23:11"> 在西面街道上有四个，在游廊上有两个。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 16:11"> 以上是可拉子孙和米拉利子孙守门的班次。</span>
</div>
</div>

## 其他职守

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="历代志上 26:22; 历代志上 28:12–19; 历代志上 22:14–16"> 利未子孙中有亚希雅掌管 神殿的府库和圣物的府库。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 23:7; 历代志上 6:17; 历代志上 29:8"> 革顺族、拉但子孙里，作族长的是革顺族拉但的子孙耶希伊利。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 23:8; 尼希米记 10:38; 历代志上 26:20"> 耶希伊利的儿子西坦和他兄弟约珥掌管耶和华殿里的府库。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 3:27; 历代志上 23:12; 民数记 3:19"> 暗兰族、以斯哈族、希伯伦族、乌泄族也有职分。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 24:20; 历代志上 23:15–16"> 摩西的孙子、革舜的儿子细布业掌管府库。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志上 23:17–18; 历代志上 23:15; 出埃及记 18:4"> 还有他的弟兄以利以谢。以利以谢的儿子是利哈比雅；利哈比雅的儿子是耶筛亚；耶筛亚的儿子是约兰；约兰的儿子是细基利；细基利的儿子是示罗密。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 8:11; 历代志上 29:2–9; 历代志上 22:14"> 这示罗密和他的弟兄掌管府库的圣物，就是大卫王和众族长、千夫长、百夫长，并军长所分别为圣的物。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 12:14; 约书亚记 6:19; 尼希米记 10:32–34"> 他们将争战时所夺的财物分别为圣，以备修造耶和华的殿。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 9:9; 撒母耳记上 17:55; 撒母耳记下 10:9–14"> 先见撒母耳、基士的儿子扫罗、尼珥的儿子押尼珥、洗鲁雅的儿子约押所分别为圣的物都归示罗密和他的弟兄掌管。</span>
</div>
</div>

## 其余利未人的职守

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="历代志上 23:4; 尼希米记 11:16; 历代志下 34:13"> 以斯哈族有基拿尼雅和他众子作官长和士师，管理以色列的外事。</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 27:17; 历代志上 23:19; 历代志上 23:12"> 希伯伦族有哈沙比雅和他弟兄一千七百人，都是壮士，在约旦河西、以色列地办理耶和华与王的事。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 23:19; 约书亚记 21:39; 历代志上 29:27"> 希伯伦族中有耶利雅作族长。大卫作王第四十年，在基列的雅谢，从这族中寻得大能的勇士。</span>
<span className="v" id="v32" data-v="32" data-xref="历代志下 19:11; 历代志上 12:37; 历代志上 23:24"> 耶利雅的弟兄有二千七百人，都是壮士，且作族长；大卫王派他们在吕便支派、迦得支派、玛拿西半支派中办理 神和王的事。</span>
</div>

## 祭司的职务

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 23:6; 出埃及记 6:23; 民数记 26:60"> 亚伦子孙的班次记在下面：亚伦的儿子是拿答、亚比户、以利亚撒、以他玛。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 10:2; 民数记 3:4; 民数记 26:61"> 拿答、亚比户死在他们父亲之先，没有留下儿子；故此，以利亚撒、以他玛供祭司的职分。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 8:17; 历代志上 24:31; 撒母耳记上 21:1"> 以利亚撒的子孙撒督和以他玛的子孙亚希米勒，同着大卫将他们的族弟兄分成班次。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 23:24; 民数记 25:11–13; 历代志上 15:6–12"> 以利亚撒子孙中为首的比以他玛子孙中为首的更多，分班如下：以利亚撒的子孙中有十六个族长，以他玛的子孙中有八个族长；</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 24:31; 约书亚记 18:10; 使徒行传 4:1"> 都掣签分立，彼此一样。在圣所和 神面前作首领的有以利亚撒的子孙，也有以他玛的子孙。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 18:16; 马太福音 8:19; 尼希米记 8:1"> 作书记的利未人拿坦业的儿子示玛雅在王和首领，与祭司撒督、亚比亚他的儿子亚希米勒，并祭司利未人的族长面前记录他们的名字。在以利亚撒的子孙中取一族，在以他玛的子孙中取一族。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 2:36; 尼希米记 11:10; 尼希米记 12:19"> 掣签的时候，第一掣出来的是耶何雅立，第二是耶大雅，</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 2:39; 尼希米记 7:35; 尼希米记 12:15"> 第三是哈琳，第四是梭琳，</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米记 12:17"> 第五是玛基雅，第六是米雅民，</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 1:5; 尼希米记 12:4; 尼希米记 12:17"> 第七是哈歌斯，第八是亚比雅，</span>
<span className="v" id="v11" data-v="11" data-xref="以斯拉记 2:36; 尼希米记 12:10; 尼希米记 7:39"> 第九是耶书亚，第十是示迦尼，</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米记 12:10"> 第十一是以利亚实，第十二是雅金，</span>
<span className="v" id="v13" data-v="13"> 第十三是胡巴，第十四是耶是比押，</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 7:40; 以斯拉记 2:37; 以斯拉记 10:20"> 第十五是璧迦，第十六是音麦，</span>
<span className="v" id="v15" data-v="15"> 第十七是希悉，第十八是哈辟悉，</span>
<span className="v" id="v16" data-v="16"> 第十九是毗他希雅，第二十是以西结，</span>
<span className="v" id="v17" data-v="17"> 第二十一是雅斤，第二十二是迦末，</span>
<span className="v" id="v18" data-v="18"> 第二十三是第来雅，第二十四是玛西亚。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 9:25; 哥林多前书 14:40; 希伯来书 7:11"> 这就是他们的班次，要照耶和华—以色列的 神借他们祖宗亚伦所吩咐的条例进入耶和华的殿办理事务。</span>
</div>
</div>

## 利未人名单

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="历代志上 26:24; 历代志上 23:16; 历代志上 6:18"> 利未其余的子孙如下：暗兰的子孙里有书巴业；书巴业的子孙里有耶希底亚。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 23:17; 历代志上 26:25"> 利哈比雅的子孙里有长子伊示雅。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 23:18; 民数记 3:27; 民数记 3:19"> 以斯哈的子孙里有示罗摩；示罗摩的子孙里有雅哈。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 23:19; 历代志上 26:31"> 希伯伦 的子孙里有长子耶利雅，次子亚玛利亚，三子雅哈悉，四子耶加面。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 23:20"> 乌薛的子孙里有米迦；米迦的子孙里有沙密。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志上 15:20; 历代志上 15:18; 历代志上 23:20"> 米迦的兄弟是伊示雅；伊示雅的子孙里有撒迦利雅。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志上 23:21"> 米拉利的儿子是抹利、母示、雅西雅；雅西雅的儿子有比挪；</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 3:20; 历代志上 23:21; 历代志上 6:19"> 米拉利的子孙里有雅西雅的儿子比挪、朔含、撒刻、伊比利。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志上 23:22"> 抹利的儿子是以利亚撒；以利亚撒没有儿子。</span>
<span className="v" id="v29" data-v="29"> 基士的子孙里有耶拉篾。</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 23:23; 历代志上 6:47"> 母示的儿子是末力、以得、耶利摩。按着宗族这都是利未的子孙。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 24:5–6; 历代志上 26:13; 历代志上 25:8"> 他们在大卫王和撒督，并亚希米勒与祭司利未人的族长面前掣签，正如他们弟兄亚伦的子孙一般。各族的长者与兄弟没有分别。</span>
</div>

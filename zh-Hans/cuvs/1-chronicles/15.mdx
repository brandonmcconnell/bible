## 准备搬运约柜

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 16:1; 历代志上 17:1–5; 诗篇 132:5"> 大卫在大卫城为自己建造宫殿，又为 神的约柜预备地方，支搭帐幕。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 10:8; 申命记 31:9; 民数记 18:1–8"> 那时大卫说：「除了利未人之外，无人可抬 神的约柜；因为耶和华拣选他们抬 神的约柜，且永远事奉他。」</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 8:1; 历代志上 13:5; 历代志上 15:1"> 大卫招聚以色列众人到耶路撒冷，要将耶和华的约柜抬到他所预备的地方。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 6:16–22; 历代志上 12:26–28; 历代志上 6:16–30"> 大卫又聚集亚伦的子孙和利未人。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 6:22–24"> 哥辖子孙中有族长乌列和他的弟兄一百二十人。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 6:29–30"> 米拉利子孙中有族长亚帅雅和他的弟兄二百二十人。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 15:11; 历代志上 23:8"> 革顺子孙中有族长约珥和他的弟兄一百三十人。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 6:22"> 以利撒反子孙中有族长示玛雅和他的弟兄二百人。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 6:18; 历代志上 23:19; 历代志上 26:30–31"> 希伯 子孙中有族长以列和他的弟兄八十人。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 6:18; 历代志上 6:18; 历代志上 23:12"> 乌薛子孙中有族长亚米拿达和他的弟兄一百一十二人。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 12:28; 列王纪上 2:35; 撒母耳记上 22:20–23"> 大卫将祭司撒督和亚比亚他，并利未人乌列、亚帅雅、约珥、示玛雅、以列、亚米拿达召来，</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 35:6; 出埃及记 19:14–15; 历代志上 15:14"> 对他们说：「你们是利未人的族长，你们和你们的弟兄应当自洁，好将耶和华—以色列 神的约柜抬到我所预备的地方。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 6:3; 哥林多前书 14:40; 约翰一书 1:8–10"> 因你们先前没有抬这约柜，按定例求问耶和华—我们的 神，所以他刑罚<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是闯杀">a</a></sup>我们。」</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 29:15; 约珥书 2:16–17; 历代志下 29:34"> 于是祭司利未人自洁，好将耶和华—以色列 神的约柜抬上来。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 4:15; 民数记 7:9; 历代志下 5:9"> 利未子孙就用杠，肩抬 神的约柜，是照耶和华借摩西所吩咐的。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志上 13:8; 历代志下 5:13; 历代志上 16:42"> 大卫吩咐利未人的族长，派他们歌唱的弟兄用琴瑟和钹作乐，欢欢喜喜地大声歌颂。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 6:39; 历代志上 6:44; 历代志上 6:33"> 于是利未人派约珥的儿子希幔和他弟兄中比利家的儿子亚萨，并他们族弟兄米拉利子孙里古沙雅的儿子以探。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 26:4; 历代志上 26:8; 历代志上 13:14"> 其次还有他们的弟兄撒迦利雅、便雅薛、示米拉末、耶歇、乌尼、以利押、比拿雅、玛西雅、玛他提雅、以利斐利户、弥克尼雅，并守门的俄别·以东和耶利。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 25:6; 历代志上 16:5; 历代志上 13:8"> 这样，派歌唱的希幔、亚萨、以探敲铜钹，大发响声；</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 46:1–11"> 派撒迦利雅、雅薛、示米拉末、耶歇、乌尼、以利押、玛西雅、比拿雅鼓瑟，调用女音；</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 10:5; 历代志上 25:6–7; 诗篇 81:1–2"> 又派玛他提雅、以利斐利户、弥克尼雅、俄别·以东、耶利、亚撒西雅领首弹琴，调用第八。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 15:27; 历代志上 15:16; 历代志上 25:7–8"> 利未人的族长基拿尼雅是歌唱人的首领，又教训人歌唱，因为他精通此事。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 84:10; 列王纪下 22:4; 历代志上 9:21–23"> 比利家、以利加拿是约柜前守门的。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 16:6; 民数记 10:8; 历代志上 15:28"> 祭司示巴尼、约沙法、拿坦业、亚玛赛、撒迦利雅、比拿亚、以利以谢在 神的约柜前吹号。俄别·以东和耶希亚也是约柜前守门的。</span>
</div>
</div>

## 约柜迁入耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 6:12–23; 弥迦书 5:2; 腓立比书 3:3"> 于是，大卫和以色列的长老，并千夫长都去从俄别·以东的家欢欢喜喜地将耶和华的约柜抬上来。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 23:29; 历代志上 29:14; 诗篇 66:13–15"> 神赐恩与抬耶和华约柜的利未人，他们就献上七只公牛，七只公羊。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 2:18; 撒母耳记下 6:14"> 大卫和抬约柜的利未人，并歌唱人的首领基拿尼雅，以及歌唱的人，都穿着细麻布的外袍；大卫另外穿着细麻布的以弗得。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志上 13:8; 历代志上 15:16; 历代志下 5:12–13"> 这样，以色列众人欢呼吹角、吹号、敲钹、鼓瑟、弹琴，大发响声，将耶和华的约柜抬上来。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 6:20–23; 撒母耳记下 6:16; 申命记 31:26"> 耶和华的约柜进了大卫城的时候，扫罗的女儿米甲从窗户里观看，见大卫王踊跃跳舞，心里就轻视他。</span>
</div>

## 大卫数点以色列民

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 24:1–25; 撒迦利亚书 3:1; 约伯记 2:4–6"> 撒但起来攻击以色列人，激动大卫数点他们。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 27:23–24; 撒母耳记下 3:10; 撒母耳记下 24:15"> 大卫就吩咐约押和民中的首领说：「你们去数点以色列人，从别是巴直到但，回来告诉我，我好知道他们的数目。」</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 1:11; 以赛亚书 26:15; 历代志上 19:13"> 约押说：「愿耶和华使他的百姓比现在加增百倍。我主我王啊，他们不都是你的仆人吗？我主为何吩咐行这事，为何使以色列人陷在罪里呢？」</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 5:29; 出埃及记 1:17; 但以理书 3:18"> 但王的命令胜过约押。约押就出去，走遍以色列地，回到耶路撒冷，</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 24:9; 历代志上 27:23"> 将百姓的总数奏告大卫：以色列人拿刀的有一百一十万；犹大人拿刀的有四十七万。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 27:24; 民数记 1:47–49; 撒母耳记下 20:9–10"> 惟有利未人和便雅悯人没有数在其中，因为约押厌恶王的这命令。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 15:5; 约书亚记 7:5; 撒母耳记下 21:14"> 神不喜悦这数点百姓的事，便降灾给以色列人。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 12:13; 约翰一书 1:9; 创世记 34:7"> 大卫祷告 神说：「我行这事大有罪了！现在求你除掉仆人的罪孽，因我所行的甚是愚昧。」</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 9:9; 撒母耳记下 24:11; 历代志上 29:29"> 耶和华吩咐大卫的先见迦得说：</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 13:21–22; 启示录 3:19; 箴言 1:29–31"> 「你去告诉大卫说，耶和华如此说：我有三样灾，随你选择一样，我好降与你。」</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 19:20"> 于是，迦得来见大卫，对他说：「耶和华如此说：『你可以随意选择：</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 28:27; 使徒行传 12:23; 以西结书 14:19–21"> 或三年的饥荒；或败在你敌人面前，被敌人的刀追杀三个月；或在你国中有耶和华的刀，就是三日的瘟疫，耶和华的使者在以色列的四境施行毁灭。』现在你要想一想，我好回复那差我来的。」</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 130:7; 以赛亚书 55:7; 腓立比书 1:23"> 大卫对迦得说：「我甚为难。我愿落在耶和华的手里，因为他有丰盛的怜悯；我不愿落在人的手里。」</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 12:30; 历代志上 27:24; 列王纪下 19:35"> 于是，耶和华降瘟疫与以色列人，以色列人就死了七万。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 6:6; 出埃及记 32:14; 耶利米书 26:18"> 神差遣使者去灭耶路撒冷，刚要灭的时候，耶和华看见后悔，就不降这灾了，吩咐灭城的天使说：「够了，住手吧！」那时，耶和华的使者站在耶布斯人阿珥楠的禾场那里。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 14:5; 列王纪上 21:27; 列王纪下 6:17"> 大卫举目，看见耶和华的使者站在天地间，手里有拔出来的刀，伸在耶路撒冷以上。大卫和长老都身穿麻衣，面伏于地。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 16:63; 撒母耳记下 24:17; 约翰福音 10:11–12"> 大卫祷告 神说：「吩咐数点百姓的不是我吗？我犯了罪，行了恶，但这群羊做了什么呢？愿耶和华—我 神的手攻击我和我的父家，不要攻击你的民，降瘟疫与他们。」</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 3:1; 撒母耳记下 24:18; 历代志上 21:11"> 耶和华的使者吩咐迦得去告诉大卫，叫他上去，在耶布斯人阿珥楠的禾场上为耶和华筑一座坛；</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 9:6; 约翰福音 2:5; 列王纪下 5:10–14"> 大卫就照着迦得奉耶和华名所说的话上去了。</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 6:11"> 那时阿珥楠正打麦子，回头看见天使，就和他四个儿子都藏起来了。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 25:23; 撒母耳记下 24:18–20"> 大卫到了阿珥楠那里，阿珥楠看见大卫，就从禾场上出去，脸伏于地，向他下拜。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 24:21; 列王纪上 21:2; 民数记 25:8"> 大卫对阿珥楠说：「你将这禾场与相连之地卖给我，我必给你足价，我好在其上为耶和华筑一座坛，使民间的瘟疫止住。」</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 24:22–23; 撒母耳记上 6:14; 创世记 23:4–6"> 阿珥楠对大卫说：「你可以用这禾场，愿我主我王照你所喜悦的去行。我也将牛给你作燔祭，把打粮的器具当柴烧，拿麦子作素祭。这些我都送给你。」</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 16:16–17; 创世记 14:23; 创世记 23:13"> 大卫王对阿珥楠说：「不然！我必要用足价向你买。我不用你的物献给耶和华，也不用白得之物献为燔祭。」</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 24:24–25"> 于是大卫为那块地平了六百舍客勒金子给阿珥楠。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 9:24; 士师记 6:21; 箴言 15:8"> 大卫在那里为耶和华筑了一座坛，献燔祭和平安祭，求告耶和华。耶和华就应允他，使火从天降在燔祭坛上。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 18:11; 诗篇 103:20; 历代志上 21:15–16"> 耶和华吩咐使者，他就收刀入鞘。</span>
<span className="v" id="v28" data-v="28"> 那时，大卫见耶和华在耶布斯人阿珥楠的禾场上应允了他，就在那里献祭。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 16:39; 历代志下 1:3; 历代志下 1:13"> 摩西在旷野所造之耶和华的帐幕和燔祭坛都在基遍的高处；</span>
<span className="v" id="v30" data-v="30" data-xref="启示录 1:17; 希伯来书 12:28–29; 启示录 15:4"> 只是大卫不敢前去求问 神，因为惧怕耶和华使者的刀。</span>

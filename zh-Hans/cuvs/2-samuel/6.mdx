## 运约柜到耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 13:1–4; 列王纪上 8:1; 历代志上 13:6–14"> 大卫又聚集以色列中所有挑选的人三万。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 4:4; 撒母耳记上 7:1; 诗篇 80:1"> 大卫起身，率领跟随他的众人前往，要从巴拉·犹大将 神的约柜运来；这约柜就是坐在二基路伯上万军之耶和华留名的约柜。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 6:7; 民数记 7:4–9; 民数记 4:5–12"> 他们将 神的约柜从冈上亚比拿达的家里抬出来，放在新车上；亚比拿达的两个儿子乌撒和亚希约赶这新车。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 13:7; 撒母耳记上 7:1–2"> 他们将 神的约柜从冈上亚比拿达家里抬出来的时候，亚希约在柜前行走。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 13:8; 诗篇 150:3–5; 阿摩司书 5:23"> 大卫和以色列的全家在耶和华面前，用松木制造的各样乐器和琴、瑟、鼓、钹、锣，作乐跳舞。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 13:9; 民数记 4:15; 民数记 4:19–20"> 到了拿艮的禾场，因为牛失前蹄<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：惊跳">a</a></sup>，乌撒就伸手扶住 神的约柜。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 6:19; 历代志上 15:13; 历代志上 13:10"> 神耶和华向乌撒发怒，因这错误击杀他，他就死在 神的约柜旁。</span>
<span className="v" id="v8" data-v="8" data-xref="约拿书 4:1; 历代志上 13:11–12; 约拿书 4:9"> 大卫因耶和华击杀<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是闯杀">b</a></sup>乌撒，心里愁烦，就称那地方为毗列斯·乌撒，直到今日。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 119:120; 历代志上 13:11–12; 民数记 17:12–13"> 那日，大卫惧怕耶和华，说：「耶和华的约柜怎可运到我这里来？」</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 26:4–8; 撒母耳记下 15:19; 历代志上 15:18"> 于是大卫不肯将耶和华的约柜运进大卫的城，却运到迦特人俄别·以东的家中。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 39:5; 创世记 30:27; 箴言 3:9–10"> 耶和华的约柜在迦特人俄别·以东家中三个月；耶和华赐福给俄别·以东和他的全家。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 15:25–3; 列王纪上 8:1; 马太福音 10:42"> 有人告诉大卫王说：「耶和华因为约柜赐福给俄别·以东的家和一切属他的。」大卫就去，欢欢喜喜地将 神的约柜从俄别·以东家中抬到大卫的城里。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 8:5; 历代志上 15:15; 民数记 4:15"> 抬耶和华约柜的人走了六步，大卫就献牛与肥羊为祭。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 2:18; 出埃及记 15:20; 诗篇 150:4"> 大卫穿着细麻布的以弗得，在耶和华面前极力跳舞。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 68:24–27; 历代志上 15:28; 历代志上 15:25"> 这样，大卫和以色列的全家欢呼吹角，将耶和华的约柜抬上来。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 2:14; 历代志上 15:29; 诗篇 69:7"> 耶和华的约柜进了大卫城的时候，扫罗的女儿米甲从窗户里观看，见大卫王在耶和华面前踊跃跳舞，心里就轻视他。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 15:1; 历代志下 1:4; 列王纪上 8:5"> 众人将耶和华的约柜请进去，安放在所预备的地方，就是在大卫所搭的帐幕里。大卫在耶和华面前献燔祭和平安祭。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 8:55; 历代志上 16:2; 创世记 14:19"> 大卫献完了燔祭和平安祭，就奉万军之耶和华的名给民祝福，</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米记 8:10; 历代志下 35:7–8; 历代志上 16:3"> 并且分给以色列众人，无论男女，每人一个饼，一块肉，一个葡萄饼；众人就各回各家去了。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记下 6:16; 撒母耳记下 6:14; 士师记 9:4"> 大卫回家要给眷属祝福；扫罗的女儿米甲出来迎接他，说：「以色列王今日在臣仆的婢女眼前露体，如同一个轻贱人无耻露体一样，有好大的荣耀啊！」</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 13:22; 诗篇 89:19–20; 撒母耳记上 13:14"> 大卫对米甲说：「这是在耶和华面前；耶和华已拣选我，废了你父和你父的全家，立我作耶和华民以色列的君，所以我必在耶和华面前跳舞。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 4:14; 希伯来书 12:2; 以赛亚书 51:7"> 我也必更加卑微，自己看为轻贱。你所说的那些婢女，她们倒要尊敬我。」</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 1:25; 以赛亚书 22:14; 以赛亚书 4:1"> 扫罗的女儿米甲，直到死日，没有生养儿女。</span>

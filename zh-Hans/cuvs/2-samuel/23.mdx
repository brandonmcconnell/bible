## 大卫的遗言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 16:12–13; 撒母耳记下 7:8–9; 诗篇 89:20"> 以下是大卫末了的话。耶西的儿子大卫得居高位，是雅各 神所膏的，作以色列的美歌者，说：</span>
<span className="v" id="v2" data-v="2" data-xref="彼得后书 1:21; 马太福音 22:43; 马可福音 12:36"> <span className="pl pl-1">耶和华的灵借着我说：</span><br /><span className="pl pl-1">他的话在我口中。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 22:32; 申命记 32:4; 出埃及记 18:21"> <span className="pl pl-1">以色列的 神、</span><br /><span className="pl pl-1">以色列的磐石晓谕我说：</span><br /><span className="pl pl-1">那以公义治理人民的，</span><br /><span className="pl pl-1">敬畏 神执掌权柄，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="士师记 5:31; 诗篇 72:6; 何西阿书 6:5"> <span className="pl pl-1">他必像日出的晨光，</span><br /><span className="pl pl-1">如无云的清晨，</span><br /><span className="pl pl-1">雨后的晴光，</span><br /><span className="pl pl-1">使地发生嫩草。</span><br /></span>

<span className="v" id="v6" data-v="6" data-xref="以西结书 2:6; 以赛亚书 33:12; 申命记 13:13"> <span className="pl pl-1">但匪类都必像荆棘被丢弃；</span><br /><span className="pl pl-1">人不敢用手拿它；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 6:8; 帖撒罗尼迦后书 2:8; 以赛亚书 27:4"> <span className="pl pl-1">拿它的人必带铁器和枪杆，</span><br /><span className="pl pl-1">终久它必被火焚烧。</span></span>

## 大卫的勇士

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="历代志上 27:2; 历代志上 11:11–47; 历代志上 27:32"> 大卫勇士的名字记在下面：他革扪人约设·巴设，又称伊斯尼人亚底挪，他是军长的统领，一时击杀了八百人。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="历代志上 27:4; 历代志上 11:12–14; 撒母耳记上 17:26"> 其次是亚合人朵多的儿子以利亚撒。从前非利士人聚集要打仗，以色列人迎着上去，有跟随大卫的三个勇士向非利士人骂阵，其中有以利亚撒。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 19:5; 撒母耳记上 11:13; 士师记 15:14"> 他起来击杀非利士人，直到手臂疲乏，手黏住刀把。那日耶和华使以色列人大获全胜；众民在以利亚撒后头专夺财物。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="历代志上 11:13–14; 历代志上 11:27; 撒母耳记下 23:33"> 其次是哈拉人亚基的儿子沙玛。一日，非利士人聚集成群，在一块长满红豆的田里，众民就在非利士人面前逃跑。</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 21:31; 撒母耳记下 23:10; 诗篇 3:8"> 沙玛却站在那田间击杀非利士人，救护了那田。耶和华使以色列人大获全胜。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 22:1; 撒母耳记下 5:18; 约书亚记 12:15"> 收割的时候，有三十个勇士中的三个人下到亚杜兰洞见大卫。非利士的军兵在利乏音谷安营。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 22:4–5; 撒母耳记上 13:4; 撒母耳记上 10:5"> 那时大卫在山寨，非利士人的防营在伯利恒。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 4:14; 诗篇 42:1–2; 以赛亚书 41:17"> 大卫渴想，说：「甚愿有人将伯利恒城门旁、井里的水打来给我喝。」</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 35:14; 哥林多后书 5:14; 腓立比书 2:17"> 这三个勇士就闯过非利士人的营盘，从伯利恒城门旁的井里打水，拿来奉给大卫。他却不肯喝，将水奠在耶和华面前，</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 17:10; 马可福音 14:24; 哥林多前书 15:30"> 说：「耶和华啊，这三个人冒死去打水；这水好像他们的血一般，我断不敢喝。」如此，大卫不肯喝。这是三个勇士所做的事。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 10:10; 撒母耳记下 10:14; 历代志上 11:20–21"> 洗鲁雅的儿子、约押的兄弟亚比筛是这三个勇士的首领；他举枪杀了三百人，就在三个勇士里得了名。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 13:8; 马太福音 13:23; 哥林多前书 15:41"> 他在这三个勇士里是最尊贵的，所以作他们的首领，只是不及前三个勇士。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳记下 8:18; 约书亚记 15:21; 撒母耳记下 20:23"> 有甲薛勇士耶何耶大的儿子比拿雅行过大能的事；他杀了摩押人亚利伊勒的两个儿子，又在下雪的时候下坑里去，杀了一个狮子，</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 17:51; 历代志上 11:23; 歌罗西书 2:15"> 又杀了一个强壮的埃及人；埃及人手里拿着枪，比拿雅只拿着棍子下去，从埃及人手里夺过枪来，用那枪将他杀死。</span>
<span className="v" id="v22" data-v="22"> 这是耶何耶大的儿子比拿雅所行的事，就在三个勇士里得了名。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 20:23; 历代志上 27:6; 撒母耳记上 22:14"> 他比那三十个勇士都尊贵，只是不及前三个勇士。大卫立他作护卫长。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 2:18; 历代志上 27:7; 历代志上 11:26"> 三十个勇士里有约押的兄弟亚撒黑，伯利恒人朵多的儿子伊勒哈难，</span>
<span className="v" id="v25" data-v="25" data-xref="士师记 7:1; 历代志上 11:27–28"> 哈律人沙玛，哈律人以利加，</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 14:2; 历代志上 11:27–28; 历代志上 27:9–10"> 帕勒提人希利斯，提哥亚人益吉的儿子以拉，</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 21:18; 历代志上 11:19; 历代志上 11:28"> 亚拿突人亚比以谢，户沙人米本乃，</span>
<span className="v" id="v28" data-v="28" data-xref="历代志上 27:13; 列王纪下 25:23; 历代志上 11:30"> 亚合人撒们，尼陀法人玛哈莱，</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 11:30–31; 约书亚记 18:28; 历代志上 27:15"> 尼陀法人巴拿的儿子希立，便雅悯族、基比亚人利拜的儿子以太，</span>
<span className="v" id="v30" data-v="30" data-xref="士师记 12:15; 历代志上 27:14; 士师记 12:13"> 比拉顿人比拿雅，迦实溪人希太，</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 3:16; 历代志上 11:32–33"> 伯·亚拉巴人亚比亚本，巴鲁米人押斯玛弗，</span>
<span className="v" id="v32" data-v="32" data-xref="历代志上 11:34"> 沙本人以利雅哈巴，雅善儿子中的约拿单，</span>
<span className="v" id="v33" data-v="33" data-xref="历代志上 11:27; 撒母耳记下 23:11; 历代志上 11:35"> 哈拉人沙玛，哈拉人沙拉的儿子亚希暗，</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记下 11:3; 撒母耳记下 15:12; 撒母耳记下 10:6"> 玛迦人亚哈拜的儿子以利法列，基罗人亚希多弗的儿子以连，</span>
<span className="v" id="v35" data-v="35" data-xref="历代志上 11:37; 约书亚记 15:55"> 迦密人希斯莱，亚巴人帕莱，</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳记下 8:3; 历代志上 11:38"> 琐巴人拿单的儿子以甲，迦得人巴尼，</span>
<span className="v" id="v37" data-v="37" data-xref="历代志上 11:37; 历代志上 11:39; 撒母耳记下 4:2"> 亚扪人洗勒，比录人拿哈莱（是给洗鲁雅的儿子约押拿兵器的），</span>
<span className="v" id="v38" data-v="38" data-xref="历代志上 2:53; 撒母耳记下 20:26; 历代志上 11:40"> 以帖人以拉，以帖人迦立，</span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳记下 11:3; 马太福音 1:6; 列王纪上 15:5"> 赫人乌利亚，共有三十七人。</span>
</div>

## 约押设法让押沙龙回来

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 13:39; 撒母耳记下 2:18; 撒母耳记下 18:33"> 洗鲁雅的儿子约押，知道王心里想念押沙龙，</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 11:6; 阿摩司书 1:1; 路得记 3:3"> 就打发人往提哥亚去，从那里叫了一个聪明的妇人来，对她说：「请你假装居丧的，穿上孝衣，不要用膏抹身，要装作为死者许久悲哀的妇人；</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 14:19; 出埃及记 4:15; 以赛亚书 51:16"> 进去见王，对王如此如此说。」于是约押将当说的话教导了妇人。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 1:2; 列王纪下 6:26–28; 撒母耳记上 25:23"> 提哥亚妇人到王面前，伏地叩拜，说：「王啊，求你拯救！」</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 9:8–15; 撒母耳记下 12:1–3"> 王问她说：「你有什么事呢？」回答说：「婢女实在是寡妇，我丈夫死了。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 4:8; 申命记 22:26–27; 出埃及记 2:13"> 我有两个儿子，一日在田间争斗，没有人解劝，这个就打死那个。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 35:19; 马太福音 21:38; 撒母耳记下 12:17"> 现在全家的人都起来攻击婢女，说：『你将那打死兄弟的交出来，我们好治死他，偿他打死兄弟的命，灭绝那承受家业的。』这样，他们要将我剩下的炭火灭尽，不与我丈夫留名留后在世上。」</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 18:13; 以赛亚书 11:3–4; 约伯记 29:16"> 王对妇人说：「你回家去吧！我必为你下令。」</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 25:24; 列王纪上 2:33; 马太福音 27:25"> 提哥亚妇人又对王说：「我主我王，愿这罪归我和我父家，与王和王的位无干。」</span>
<span className="v" id="v10" data-v="10"> 王说：「凡难为你的，你就带他到我这里来，他必不再搅扰你。」</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 14:45; 马太福音 10:30; 民数记 35:19"> 妇人说：「愿王记念耶和华—你的 神，不许报血仇的人施行灭绝，恐怕他们灭绝我的儿子。」王说：「我指着永生的耶和华起誓：你的儿子连一根头发也不致落在地上。」</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 18:27; 撒母耳记上 25:24; 使徒行传 26:1"> 妇人说：「求我主我王容婢女再说一句话。」王说：「你说吧！」</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 13:37–38; 撒母耳记下 12:7; 士师记 20:2"> 妇人说：「王为何也起意要害 神的民呢？王不使那逃亡的人回来，王的这话就是自证己错了！</span>
<span className="v" id="v14" data-v="14" data-xref="约伯记 30:23; 民数记 35:28; 希伯来书 9:27"> 我们都是必死的，如同水泼在地上，不能收回。 神并不夺取人的性命，乃设法使逃亡的人不致成为赶出、回不来的。</span>
<span className="v" id="v15" data-v="15"> 我来将这话告诉我主我王，是因百姓使我惧怕。婢女想，不如将这话告诉王，或者王成就婢女所求的。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 26:19"> 人要将我和我儿子从 神的地业上一同除灭，王必应允救我脱离他的手。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 29:9; 撒母耳记下 19:27; 撒母耳记下 14:20"> 婢女又想，我主我王的话必安慰我；因为我主我王能辨别是非，如同 神的使者一样。惟愿耶和华—你的 神与你同在！」</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 38:25; 撒母耳记上 3:17–18; 耶利米书 38:14"> 王对妇人说：「我要问你一句话，你一点不要瞒我。」妇人说：「愿我主我王说。」</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 14:3; 撒母耳记上 1:26; 撒母耳记上 20:3"> 王说：「你这些话莫非是约押的主意吗？」妇人说：「我敢在我主我王面前起誓：王的话正对，不偏左右，是王的仆人约押吩咐我的，这些话是他教导我的。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记下 14:17; 撒母耳记下 19:27; 约伯记 32:21–22"> 王的仆人约押如此行，为要挽回这事。我主的智慧却如 神使者的智慧，能知世上一切事。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳记下 14:11; 撒母耳记上 14:39; 马可福音 6:26"> 王对约押说：「我应允你这事。你可以去，把那少年人押沙龙带回来。」</span>
<span className="v" id="v22" data-v="22" data-xref="路得记 2:2; 约伯记 31:20; 约伯记 29:11"> 约押就面伏于地叩拜，祝谢于王，又说：「王既应允仆人所求的，仆人今日知道在我主我王眼前蒙恩了。」</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 3:3; 撒母耳记下 13:37–38"> 于是约押起身往基述去，将押沙龙带回耶路撒冷。</span>
<span className="v" id="v24" data-v="24" data-xref="启示录 22:4; 创世记 43:3; 撒母耳记下 3:13"> 王说：「使他回自己家里去，不要见我的面。」押沙龙就回自己家里去，没有见王的面。</span>
</div>
</div>

## 大卫饶恕押沙龙

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 1:6; 申命记 28:35; 约伯记 2:7"> 以色列全地之中，无人像押沙龙那样俊美，得人的称赞，从脚底到头顶毫无瑕疵。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 44:20; 哥林多前书 11:14; 撒母耳记下 18:9"> 他的头发甚重，每到年底剪发一次；所剪下来的，按王的平称一称，重二百舍客勒。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记下 18:18; 撒母耳记下 13:1; 以赛亚书 14:22"> 押沙龙生了三个儿子，一个女儿。女儿名叫她玛，是个容貌俊美的女子。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 押沙龙住在耶路撒冷足有二年，没有见王的面。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 14:30–31; 以斯帖记 1:12; 马太福音 22:3"> 押沙龙打发人去叫约押来，要托他去见王，约押却不肯来。第二次打发人去叫他，他仍不肯来。</span>
<span className="v" id="v30" data-v="30" data-xref="士师记 15:4–5; 列王纪下 10:6–7; 列王纪下 9:33"> 所以押沙龙对仆人说：「你们看，约押有一块田，与我的田相近，其中有大麦，你们去放火烧了。」押沙龙的仆人就去放火烧了那田。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31"> 于是约押起来，到了押沙龙家里，问他说：「你的仆人为何放火烧了我的田呢？」</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 20:8; 出埃及记 14:12; 箴言 28:13"> 押沙龙回答约押说：「我打发人去请你来，好托你去见王，替我说：『我为何从基述回来呢？不如仍在那里。』现在要许我见王的面；我若有罪，任凭王杀我就是了。」</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 33:4; 路加福音 15:20; 创世记 27:26"> 于是约押去见王，将这话奏告王，王便叫押沙龙来。押沙龙来见王，在王面前俯伏于地，王就与押沙龙亲嘴。</span>
</div>
</div>

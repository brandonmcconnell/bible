## 示巴反叛

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 12:16; 历代志下 10:16; 申命记 13:13"> 在那里恰巧有一个匪徒，名叫示巴，是便雅悯人比基利的儿子。他吹角，说：「我们与大卫无分，与耶西的儿子无涉。以色列人哪，你们各回各家去吧！」</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 6:66–68; 使徒行传 11:23; 撒母耳记下 19:15"> 于是以色列人都离开大卫，跟随比基利的儿子示巴。但犹大人从约旦河直到耶路撒冷，都紧紧跟随他们的王。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 16:21–22; 撒母耳记下 15:16; 创世记 40:3"> 大卫王来到耶路撒冷，进了宫殿，就把从前留下看守宫殿的十个妃嫔禁闭在冷宫，养活她们，不与她们亲近。她们如同寡妇被禁，直到死的日子。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 19:13; 撒母耳记下 17:25; 历代志上 2:17"> 王对亚玛撒说：「你要在三日之内将犹大人招聚了来，你也回到这里来。」</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 19:13; 撒母耳记上 13:8"> 亚玛撒就去招聚犹大人，却耽延过了王所限的日期。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 21:17; 撒母耳记下 11:11; 列王纪上 1:33"> 大卫对亚比筛说：「现在恐怕比基利的儿子示巴加害于我们比押沙龙更甚。你要带领你主的仆人追赶他，免得他得了坚固城，躲避我们。」</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 8:18; 列王纪上 1:38; 撒母耳记下 20:23"> 约押的人和基利提人、比利提人，并所有的勇士，都跟着亚比筛，从耶路撒冷出去追赶比基利的儿子示巴。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 3:30; 撒母耳记下 2:13; 撒母耳记下 20:4–5"> 他们到了基遍的大磐石那里，亚玛撒来迎接他们。那时约押穿着战衣，腰束佩刀的带子，刀在鞘内；约押前行，刀从鞘内掉出来。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 22:47–48; 马太福音 26:48–49; 弥迦书 7:2"> 约押左手拾起刀来，对亚玛撒说：「我兄弟，你好啊！」就用右手抓住亚玛撒的胡子，要与他亲嘴。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 2:23; 撒母耳记下 3:27; 士师记 3:21"> 亚玛撒没有防备约押手里所拿的刀；约押用刀刺入他的肚腹，他的肠子流在地上，没有再刺他，就死了。 约押和他兄弟亚比筛往前追赶比基利的儿子示巴。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 20:13; 撒母耳记下 20:21; 列王纪下 9:32"> 有约押的一个少年人站在亚玛撒尸身旁边，对众人说：「谁喜悦约押，谁归顺大卫，就当跟随约押去。」</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 24:21–22; 诗篇 9:16; 撒母耳记下 17:25"> 亚玛撒在道路上滚在自己的血里。那人见众民经过都站住，就把亚玛撒的尸身从路上挪到田间，用衣服遮盖。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 6:12; 以赛亚书 7:3; 列王纪下 18:17"> 尸身从路上挪移之后，众民就都跟随约押去追赶比基利的儿子示巴。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 15:29; 列王纪上 15:20; 历代志下 16:4"> 他走遍以色列各支派，直到伯·玛迦的亚比拉，并比利人的全地；那些地方的人也都聚集跟随他。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 19:32; 耶利米书 32:24; 列王纪上 15:20"> 约押和跟随的人到了伯·玛迦的亚比拉，围困示巴，就对着城筑垒；跟随约押的众民用锤撞城，要使城塌陷。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 14:2; 传道书 9:14–18; 撒母耳记上 25:32–33"> 有一个聪明妇人从城上呼叫说：「听啊，听啊，请约押近前来，我好与他说话。」</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 14:12; 撒母耳记上 25:24"> 约押就近前来，妇人问他说：「你是约押不是？」他说：「我是。」妇人说：「求你听婢女的话。」约押说：「我听。」</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 20:10–11"> 妇人说：「古时有话说，当先在亚比拉求问，然后事就定妥。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 26:19; 撒母耳记下 21:3; 撒母耳记下 17:16"> 我们这城的人在以色列人中是和平、忠厚的。你为何要毁坏以色列中的大城，吞灭耶和华的产业呢？」</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:29; 箴言 28:13; 耶利米书 17:9"> 约押回答说：「我决不吞灭毁坏，</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 26:9; 士师记 2:9; 撒母耳记下 17:2–3"> 乃因以法莲山地的一个人—比基利的儿子示巴—举手攻击大卫王，你们若将他一人交出来，我便离城而去。」妇人对约押说：「那人的首级必从城墙上丢给你。」</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 20:1; 传道书 7:19; 撒母耳记下 11:6–21"> 妇人就凭她的智慧去劝众人。他们便割下比基利的儿子示巴的首级，丢给约押。约押吹角，众人就离城而散，各归各家去了。约押回耶路撒冷，到王那里。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 8:16–18; 历代志上 18:15–17; 列王纪上 4:3–6"> 约押作以色列全军的元帅；耶何耶大的儿子比拿雅统辖基利提人和比利提人；</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 4:3; 列王纪上 12:18; 列王纪上 4:6"> 亚多兰掌管服苦的人；亚希律的儿子约沙法作史官；</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 4:4; 撒母耳记下 8:17; 历代志上 18:16"> 示法作书记；撒督和亚比亚他作祭司长；</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 23:38; 出埃及记 2:14; 创世记 41:45"> 睚珥人以拉作大卫的宰相。</span>

## 大卫受膏作犹大王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 30:31; 撒母耳记上 23:4; 创世记 32:2"> 此后，大卫问耶和华说：「我上犹大的一个城去可以吗？」耶和华说：「可以。」大卫说：「我上哪一个城去呢？」耶和华说：「上希伯 去。」</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 25:42–43; 撒母耳记上 30:5; 路加福音 22:28–29"> 于是大卫和他的两个妻—一个是耶斯列人亚希暖，一个是作过迦密人拿八妻的亚比该—都上那里去了。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 30:1; 历代志上 12:1–7; 撒母耳记上 27:2–3"> 大卫也将跟随他的人和他们各人的眷属一同带上去，住在希伯 的城邑中。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 5:5; 撒母耳记上 31:11–13; 撒母耳记下 5:3"> 犹大人来到希伯 ，在那里膏大卫作犹大家的王。<br />有人告诉大卫说：「葬埋扫罗的是基列·雅比人。」</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 23:21; 诗篇 115:15; 路得记 2:20"> 大卫就差人去见基列·雅比人，对他们说：「你们厚待你们的主—扫罗，将他葬埋。愿耶和华赐福与你们！</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 14:22; 出埃及记 34:6; 马太福音 5:44"> 你们既行了这事，愿耶和华以慈爱诚实待你们，我也要为此厚待你们。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 6:10; 撒母耳记下 10:12; 创世记 15:1"> 现在你们的主—扫罗死了，犹大家已经膏我作他们的王，所以你们要刚强奋勇。」</span>
</div>
</div>

## 伊施波设作以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 14:50; 创世记 32:2; 撒母耳记下 3:7–8"> 扫罗的元帅尼珥的儿子押尼珥，曾将扫罗的儿子伊施波设带过河，到玛哈念，</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 19:18; 约书亚记 13:8–11; 民数记 1:40"> 立他作王，治理基列、亚书利、耶斯列、以法莲、便雅悯，和以色列众人。</span>
<span className="v" id="v10" data-v="10"> 扫罗的儿子伊施波设登基的时候年四十岁，作以色列王二年；惟独犹大家归从大卫。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 2:11; 撒母耳记下 5:4–5; 历代志上 3:4"> 大卫在希伯 作犹大家的王，共七年零六个月。</span>
</div>
</div>

## 扫罗家和大卫家争战

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约书亚记 18:25; 约书亚记 10:2; 约书亚记 9:3"> 尼珥的儿子押尼珥和扫罗的儿子伊施波设的仆人从玛哈念出来，往基遍去。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 8:16; 历代志上 2:16; 撒母耳记下 20:23"> 洗鲁雅的儿子约押和大卫的仆人也出来，在基遍池旁与他们相遇；一班坐在池这边，一班坐在池那边。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 2:17; 箴言 10:23; 箴言 17:14"> 押尼珥对约押说：「让少年人起来，在我们面前戏耍吧！」约押说：「可以。」</span>
<span className="v" id="v15" data-v="15"> 就按着定数起来：属扫罗儿子伊施波设的便雅悯人过去十二名，大卫的仆人也过去十二名，</span>
<span className="v" id="v16" data-v="16"> 彼此揪头，用刀刺肋，一同仆倒。所以，那地叫做希利甲·哈素林，就在基遍。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 3:1"> 那日的战事凶猛，押尼珥和以色列人败在大卫的仆人面前。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 12:8; 哈巴谷书 3:19; 雅歌 8:14"> 在那里有洗鲁雅的三个儿子：约押、亚比筛、亚撒黑。亚撒黑脚快如野鹿一般；</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 2:21; 约书亚记 1:7; 箴言 4:27"> 亚撒黑追赶押尼珥，直追赶他不偏左右。</span>
<span className="v" id="v20" data-v="20"> 押尼珥回头说：「你是亚撒黑吗？」回答说：「是。」</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 14:19"> 押尼珥对他说：「你或转向左转向右，拿住一个少年人，剥去他的战衣。」亚撒黑却不肯转开不追赶他。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 3:27; 箴言 29:1; 列王纪下 14:10–12"> 押尼珥又对亚撒黑说：「你转开不追赶我吧！我何必杀你呢？若杀你，有什么脸见你哥哥约押呢？」</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 3:27; 撒母耳记下 4:6; 撒母耳记下 5:6"> 亚撒黑仍不肯转开。故此，押尼珥就用枪 刺入他的肚腹，甚至枪从背后透出，亚撒黑就在那里仆倒而死。众人赶到亚撒黑仆倒而死的地方，就都站住。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 约押和亚比筛追赶押尼珥，日落的时候，到了通基遍旷野的路旁，基亚对面的亚玛山。</span>
<span className="v" id="v25" data-v="25"> 便雅悯人聚集，跟随押尼珥站在一个山顶上。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 46:14; 耶利米书 46:10; 使徒行传 7:26"> 押尼珥呼叫约押说：「刀剑岂可永远杀人吗？你岂不知终久必有苦楚吗？你要等何时才叫百姓回去、不追赶弟兄呢？」</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 17:14; 撒母耳记下 2:14; 箴言 15:1"> 约押说：「我指着永生的 神起誓：你若不说戏耍的那句话，今日早晨百姓就回去，不追赶弟兄了。」</span>
<span className="v" id="v28" data-v="28"> 于是约押吹角，众民就站住，不再追赶以色列人，也不再打仗了。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 2:8; 雅歌 2:17"> 押尼珥和跟随他的人整夜经过亚拉巴，过约旦河，走过毕伦，到了玛哈念。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 约押追赶押尼珥回来，聚集众民，见大卫的仆人中缺少了十九个人和亚撒黑。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 3:1; 列王纪上 20:11"> 但大卫的仆人杀了便雅悯人和跟随押尼珥的人，共三百六十名。</span>
<span className="v" id="v32" data-v="32" data-xref="历代志上 2:13–16; 撒母耳记上 17:58; 历代志下 21:1"> 众人将亚撒黑送到伯利恒，葬在他父亲的坟墓里。约押和跟随他的人走了一夜，天亮的时候到了希伯 。</span>
</div>
</div>

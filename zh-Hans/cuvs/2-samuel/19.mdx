## 约押劝谏王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 18:5; 撒母耳记下 18:14; 箴言 17:25"> 有人告诉约押说：「王为押沙龙哭泣悲哀。」</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 19:12; 箴言 16:15"> 众民听说王为他儿子忧愁，他们得胜的欢乐却变成悲哀。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 31:27; 撒母耳记下 19:32; 撒母耳记下 17:24"> 那日众民暗暗地进城，就如败阵逃跑、惭愧的民一般。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 18:33; 撒母耳记下 15:30"> 王蒙着脸，大声哭号说：「我儿押沙龙啊！押沙龙，我儿，我儿啊！」</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 18:47–48; 诗篇 3:8; 尼希米记 9:27"> 约押进去见王，说：「你今日使你一切仆人脸面惭愧了！他们今日救了你的性命和你儿女妻妾的性命，</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 23:5; 撒母耳记下 3:24–25; 箴言 19:9–10"> 你却爱那恨你的人，恨那爱你的人。你今日明明地不以将帅、仆人为念。我今日看明，若押沙龙活着，我们都死亡，你就喜悦了。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 14:28; 创世记 34:3; 箴言 19:15"> 现在你当出去，安慰你仆人的心。我指着耶和华起誓：你若不出去，今夜必无一人与你同在一处；这祸患就比你从幼年到如今所遭的更甚！」</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 18:24; 撒母耳记下 18:4; 撒母耳记下 19:3"> 于是王起来，坐在城门口。众民听说王坐在城门口，就都到王面前。 大卫回耶路撒冷 以色列人已经逃跑，各回各家去了。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 15:14; 创世记 3:12–13; 撒母耳记下 8:1–14"> 以色列众支派的人纷纷议论说：「王曾救我们脱离仇敌的手，又救我们脱离非利士人的手，现在他躲避押沙龙逃走了。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 18:14; 士师记 18:9; 何西阿书 8:4"> 我们膏押沙龙治理我们，他已经阵亡。现在为什么不出一言请王回来呢？」</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 15:29; 列王纪上 2:35; 撒母耳记下 15:35–36"> 大卫王差人去见祭司撒督和亚比亚他，说：「你们当向犹大长老说：『以色列众人已经有话请王回宫，你们为什么落在他们后头呢？</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 5:1; 创世记 2:23; 以弗所书 5:30"> 你们是我的弟兄，是我的骨肉，为什么在人后头请王回来呢？』</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 17:25; 列王纪上 19:2; 路得记 1:17"> 也要对亚玛撒说：『你不是我的骨肉吗？我若不立你替约押常作元帅，愿 神重重地降罚与我！』」</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 20:1; 使徒行传 4:32; 诗篇 110:2–3"> 如此就挽回犹大众人的心，如同一人的心。他们便打发人去见王，说：「请王和王的一切臣仆回来。」</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 5:9; 撒母耳记上 11:14–15"> 王就回来，到了约旦河。犹大人来到吉甲，要去迎接王，请他过约旦河。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 2:8; 撒母耳记下 16:5–13; 列王纪上 2:36–46"> 巴户琳的便雅悯人、基拉的儿子示每急忙与犹大人一同下去迎接大卫王。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 16:1–4; 撒母耳记下 9:2; 撒母耳记下 9:10"> 跟从示每的有一千便雅悯人，还有扫罗家的仆人洗巴和他十五个儿子，二十个仆人；他们都趟过约旦河迎接王。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 81:15; 启示录 3:9; 诗篇 66:3"> 有摆渡船过去，渡王的家眷，任王使用。 大卫宽恕示每 王要过约旦河的时候，基拉的儿子示每就俯伏在王面前，</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 22:15; 撒母耳记下 13:20; 撒母耳记下 13:33"> 对王说：「我主我王出耶路撒冷的时候，仆人行悖逆的事，现在求我主不要因此加罪与仆人，不要记念，也不要放在心上。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 12:25; 诗篇 78:34–37; 创世记 48:14"> 仆人明知自己有罪，所以约瑟全家之中，今日我首先下来迎接我主我王。」</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 22:28; 撒母耳记上 26:9; 列王纪上 21:10–11"> 洗鲁雅的儿子亚比筛说：「示每既咒骂耶和华的受膏者，不应当治死他吗？」</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 11:13; 撒母耳记下 16:10; 撒母耳记下 3:39"> 大卫说：「洗鲁雅的儿子，我与你们有何关涉，使你们今日与我反对呢？今日在以色列中岂可治死人呢？我岂不知今日我作以色列的王吗？」</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 2:46; 列王纪上 2:8–9; 列王纪上 2:37"> 于是王对示每说：「你必不死。」王就向他起誓。</span>
</div>
</div>

## 大卫善待米非波设

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米书 41:5; 马太福音 6:16; 撒母耳记下 15:30"> 扫罗的孙子米非波设也下去迎接王。他自从王去的日子，直到王平平安安地回来，没有修脚，没有剃胡须，也没有洗衣服。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 16:17"> 他来到耶路撒冷迎接王的时候，王问他说：「米非波设，你为什么没有与我同去呢？」</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 16:2–3; 撒母耳记下 4:4; 撒母耳记下 9:3"> 他回答说：「我主我王，仆人是瘸腿的。那日我想要备驴骑上，与王同去，无奈我的仆人欺哄了我，</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记下 14:17; 撒母耳记下 14:20; 撒母耳记上 29:9"> 又在我主我王面前谗毁我。然而我主我王如同 神的使者一般，你看怎样好，就怎样行吧！</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 9:13; 撒母耳记下 9:10; 撒母耳记下 21:6–9"> 因为我祖全家的人，在我主我王面前都算为死人，王却使仆人在王的席上同人吃饭，我现在向王还能辨理诉冤吗？」</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 18:15; 诗篇 101:5; 诗篇 82:2"> 王对他说：「你何必再提你的事呢？我说，你与洗巴均分地土。」</span>
<span className="v" id="v30" data-v="30" data-xref="腓立比书 1:20; 使徒行传 20:24; 撒母耳记下 1:26"> 米非波设对王说：「我主我王既平平安安地回宫，就任凭洗巴都取了也可以。」</span>
</div>
</div>

## 大卫善待巴西莱

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪上 2:7; 尼希米记 7:63; 以斯拉记 2:61"> 基列人巴西莱从罗基琳下来，要送王过约旦河，就与王一同过了约旦河。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 25:2; 约伯记 1:3; 箴言 16:31"> 巴西莱年纪老迈，已经八十岁了。王住在玛哈念的时候，他就拿食物来供给王；他原是大富户。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 25:34–40; 路加福音 22:28–30; 撒母耳记下 9:11"> 王对巴西莱说：「你与我同去，我要在耶路撒冷那里养你的老。」</span>
<span className="v" id="v34" data-v="34" data-xref="雅各书 4:14; 哥林多前书 7:29; 创世记 47:8–9"> 巴西莱对王说：「我在世的年日还能有多少，使我与王同上耶路撒冷呢？</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 15:33; 以斯拉记 2:65; 诗篇 90:10"> 仆人现在八十岁了，还能尝出饮食的滋味、辨别美恶吗？还能听男女歌唱的声音吗？仆人何必累赘我主我王呢？</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 6:38"> 仆人只要送王过约旦河，王何必赐我这样的恩典呢？</span>
<span className="v" id="v37" data-v="37" data-xref="列王纪上 2:7; 耶利米书 41:17; 撒母耳记下 19:40"> 求你准我回去，好死在我本城，葬在我父母的墓旁。这里有王的仆人金罕，让他同我主我王过去，可以随意待他。」</span>
<span className="v" id="v38" data-v="38"> 王说：「金罕可以与我同去，我必照你的心愿待他。你向我求什么，我都必为你成就。」</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 31:55; 路得记 1:14; 创世记 47:7"> 于是众民过约旦河，王也过去。王与巴西莱亲嘴，为他祝福，巴西莱就回本地去了。</span>
</div>
</div>

## 以色列人和犹大人为王起争论

<div className="bt">
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="马太福音 21:9; 创世记 49:10; 撒母耳记下 19:11–15"> 王过去，到了吉甲，金罕也跟他过去。犹大众民和以色列民的一半也都送王过去。</span>
<span className="v" id="v41" data-v="41" data-xref="士师记 8:1; 士师记 12:1; 约翰福音 7:5–6"> 以色列众人来见王，对他说：「我们弟兄犹大人为什么暗暗送王和王的家眷，并跟随王的人过约旦河？」</span>
<span className="v" id="v42" data-v="42" data-xref="撒母耳记下 19:12; 撒母耳记下 5:1; 历代志上 2:3–17"> 犹大众人回答以色列人说：「因为王与我们是亲属，你们为何因这事发怒呢？我们吃了王的什么呢？王赏赐了我们什么呢？」</span>
<span className="v" id="v43" data-v="43" data-xref="加拉太书 5:20; 撒母耳记下 5:1; 列王纪上 11:30–31"> 以色列人回答犹大人说：「按支派，我们与王有十分的情分；在大卫身上，我们也比你们更有情分。你们为何藐视我们，请王回来不先与我们商量呢？」 但犹大人的话比以色列人的话更硬。</span>

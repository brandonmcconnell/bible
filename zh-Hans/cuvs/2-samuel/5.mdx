## 大卫作犹大和以色列王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 11:1–3; 撒母耳记下 19:13; 创世记 29:14"> 以色列众支派来到希伯 见大卫，说：「我们原是你的骨肉。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 2:6; 弥迦书 5:4; 以西结书 34:23"> 从前扫罗作我们王的时候，率领以色列人出入的是你；耶和华也曾应许你说：『你必牧养我的民以色列，作以色列的君。』」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 2:4; 撒母耳记上 16:13; 撒母耳记上 23:18"> 于是以色列的长老都来到希伯 见大卫王，大卫在希伯 耶和华面前与他们立约，他们就膏大卫作以色列的王。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 29:27; 路加福音 3:23; 列王纪上 2:11"> 大卫登基的时候年三十岁，在位四十年；</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 2:11; 历代志上 3:4; 列王纪上 2:11"> 在希伯 作犹大王七年零六个月，在耶路撒冷作以色列和犹大王三十三年。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 1:8; 耶利米书 37:10; 历代志上 11:4–9"> 大卫和跟随他的人到了耶路撒冷，要攻打住那地方的耶布斯人。耶布斯人对大卫说：「你若不赶出瞎子、瘸子，必不能进这地方」；心里想大卫决不能进去。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 2:10; 撒母耳记下 6:16; 撒母耳记下 6:12"> 然而大卫攻取锡安的保障，就是大卫的城。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 15:16–17; 历代志上 11:6–9; 撒母耳记上 17:25"> 当日，大卫说：「谁攻打耶布斯人，当上水沟攻打我心里所恨恶的瘸子、瞎子。」从此有俗语说：「在那里有瞎子、瘸子，他不能进屋去。」</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 9:15; 列王纪上 9:24; 历代志下 32:5"> 大卫住在保障里，给保障起名叫大卫城。大卫又从米罗以里，周围筑墙。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 3:1; 罗马书 8:31; 诗篇 46:11"> 大卫日见强盛，因为耶和华—万军之 神与他同在。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 14:1; 列王纪上 5:1–2; 列王纪上 5:18"> 泰尔王希兰将香柏木运到大卫那里，又差遣使者和木匠、石匠给大卫建造宫殿。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 7:16; 列王纪上 10:9; 历代志上 14:2"> 大卫就知道耶和华坚立他作以色列王，又为自己的民以色列使他的国兴旺。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 3:9; 申命记 17:17; 历代志下 13:21"> 大卫离开希伯 之后，在耶路撒冷又立后妃，又生儿女。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志上 3:5–9; 路加福音 2:31; 历代志上 14:4"> 在耶路撒冷所生的儿子是沙母亚、朔罢、拿单、所罗门、</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 3:6; 历代志上 14:5"> 益辖、以利书亚、尼斐、雅非亚、</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 3:8; 历代志上 14:7"> 以利沙玛、以利雅大、以利法列。</span>
</div>
</div>

## 战胜非利士人

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 23:14; 历代志上 14:8–9; 历代志上 11:16"> 非利士人听见人膏大卫作以色列王，非利士众人就上来寻索大卫；大卫听见，就下到保障。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 15:8; 撒母耳记下 23:13; 创世记 14:5"> 非利士人来了，布散在利乏音谷。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 2:1; 撒母耳记上 23:2; 撒母耳记下 5:23"> 大卫求问耶和华说：「我可以上去攻打非利士人吗？你将他们交在我手里吗？」耶和华说：「你可以上去，我必将非利士人交在你手里。」</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 28:21"> 大卫来到巴力·毗拉心，在那里击杀非利士人，说：「耶和华在我面前冲破敌人，如同水冲去一般。」因此称那地方为巴力·毗拉心。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 14:11–12; 申命记 7:5; 撒母耳记上 5:2–6"> 非利士人将偶像撇在那里，大卫和跟随他的人拿去了。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 14:13; 撒母耳记下 5:18; 列王纪上 20:22"> 非利士人又上来，布散在利乏音谷。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 14:14; 马太福音 9:29–30; 马太福音 8:23–25"> 大卫求问耶和华；耶和华说：「不要一直地上去，要转到他们后头，从桑林对面攻打他们。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪下 7:6; 士师记 4:14; 士师记 7:15"> 你听见桑树梢上有脚步的声音，就要急速前去，因为那时耶和华已经在你前头去攻打非利士人的军队。」</span>
<span className="v" id="v25" data-v="25" data-xref="历代志上 14:16; 约书亚记 16:10; 以赛亚书 28:21"> 大卫就遵着耶和华所吩咐的去行，攻打非利士人，从迦巴直到基色。</span>

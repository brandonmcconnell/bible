## 暗嫩和她玛

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 3:9; 撒母耳记下 3:2–3; 撒母耳记下 13:15"> 大卫的儿子押沙龙有一个美貌的妹子，名叫她玛。大卫的儿子暗嫩爱她。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 7:10; 列王纪上 21:4; 雅歌 5:8"> 暗嫩为他妹子她玛忧急成病。她玛还是处女，暗嫩以为难向她行事。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 16:9; 哥林多前书 3:19; 雅各书 3:15"> 暗嫩有一个朋友，名叫约拿达，是大卫长兄示米亚的儿子。这约拿达为人极其狡猾；</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 20:17; 利未记 18:9; 以斯帖记 5:13–14"> 他问暗嫩说：「王的儿子啊，为何一天比一天瘦弱呢？请你告诉我。」暗嫩回答说：「我爱我兄弟押沙龙的妹子她玛。」</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 6:24–25; 箴言 19:27; 使徒行传 23:15"> 约拿达说：「你不如躺在床上装病；你父亲来看你，就对他说：『求父叫我妹子她玛来，在我眼前预备食物，递给我吃，使我看见，好从她手里接过来吃。』」</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 18:6; 马太福音 13:33"> 于是暗嫩躺卧装病。王来看他，他对王说：「求父叫我妹子她玛来，在我眼前为我做两个饼，我好从她手里接过来吃。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 大卫就打发人到宫里，对她玛说：「你往你哥哥暗嫩的屋里去，为他预备食物。」</span>
<span className="v" id="v8" data-v="8"> 她玛就到她哥哥暗嫩的屋里；暗嫩正躺卧。她玛抟面，在他眼前做饼，且烤熟了，</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 45:1; 约翰福音 3:20; 士师记 3:19"> 在他面前将饼从锅里倒出来，他却不肯吃，便说：「众人离开我出去吧！」众人就都离开他，出去了。</span>
<span className="v" id="v10" data-v="10"> 暗嫩对她玛说：「你把食物拿进卧房，我好从你手里接过来吃。」她玛就把所做的饼拿进卧房，到她哥哥暗嫩那里，</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 39:11–12"> 拿着饼上前给他吃，他便拉住她玛，说：「我妹妹，你来与我同寝。」</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 19:23; 利未记 20:17; 士师记 20:6"> 她玛说：「我哥哥，不要玷辱我。以色列人中不当这样行，你不要做这丑事；</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 19:24; 创世记 20:12; 创世记 19:8"> 你玷辱了我，我何以掩盖我的羞耻呢？你在以色列中也成了愚妄人。你可以求王，他必不禁止我归你。」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 12:11; 以斯帖记 7:8; 士师记 20:5"> 但暗嫩不肯听她的话，因比她力大，就玷辱她，与她同寝。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西结书 23:17"> 随后，暗嫩极其恨她，那恨她的心比先前爱她的心更甚，对她说：「你起来，去吧！」</span>
<span className="v" id="v16" data-v="16"> 她玛说：「不要这样！你赶出我去的这罪比你才行的更重！」但暗嫩不肯听她的话，</span>
<span className="v" id="v17" data-v="17"> 就叫伺候自己的仆人来，说：「将这个女子赶出去！她一出去，你就关门，上闩。」</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 5:30; 创世记 37:3; 诗篇 45:13–14"> 那时她玛穿着彩衣，因为没有出嫁的公主都是这样穿。暗嫩的仆人就把她赶出去，关门上闩。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 7:6; 耶利米书 2:37; 撒母耳记下 1:11"> 她玛把灰尘撒在头上，撕裂所穿的彩衣，以手抱头，一面行走，一面哭喊。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="罗马书 12:19; 创世记 46:15; 创世记 34:2"> 她胞兄押沙龙问她说：「莫非你哥哥暗嫩与你亲近了吗？我妹妹，暂且不要作声，他是你的哥哥，不要将这事放在心上。」她玛就孤孤单单地住在她胞兄押沙龙家里。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 34:7; 撒母耳记下 3:28–29; 撒母耳记上 2:29"> 大卫王听见这事，就甚发怒。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 19:17–18; 创世记 31:24; 创世记 24:50"> 押沙龙并不和他哥哥暗嫩说好说歹；因为暗嫩玷辱他妹妹她玛，所以押沙龙恨恶他。</span>
</div>
</div>

## 押沙龙为妹报仇

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="创世记 38:12–13; 撒母耳记上 25:4; 历代志下 26:10"> 过了二年，在靠近以法莲的巴力·夏琐有人为押沙龙剪羊毛；押沙龙请王的众子与他同去。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 11:8–15; 耶利米书 41:6–7; 诗篇 55:21"> 押沙龙来见王，说：「现在有人为仆人剪羊毛，请王和王的臣仆与仆人同去。」</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 14:23; 士师记 19:7–10; 撒母耳记下 14:22"> 王对押沙龙说：「我儿，我们不必都去，恐怕使你耗费太多。」押沙龙再三请王，王仍是不肯去，只为他祝福。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 20:9; 撒母耳记下 3:27; 撒母耳记下 11:13–15"> 押沙龙说：「王若不去，求王许我哥哥暗嫩同去。」王说：「何必要他去呢？」</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 26:24–26"> 押沙龙再三求王，王就许暗嫩和王的众子与他同去。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="士师记 19:6; 士师记 19:22; 士师记 19:9"> 押沙龙吩咐仆人说：「你们注意，看暗嫩饮酒畅快的时候，我对你们说杀暗嫩，你们便杀他，不要惧怕。这不是我吩咐你们的吗？你们只管壮胆奋勇！」</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 18:9; 列王纪上 1:33; 列王纪下 1:9–12"> 押沙龙的仆人就照押沙龙所吩咐的，向暗嫩行了。王的众子都起来，各人骑上骡子，逃跑了。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 他们还在路上，有风声传到大卫那里，说：「押沙龙将王的众子都杀了，没有留下一个。」</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 1:11; 撒母耳记下 12:16; 约伯记 1:20"> 王就起来，撕裂衣服，躺在地上。王的臣仆也都撕裂衣服，站在旁边。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 16:9; 撒母耳记下 13:3; 创世记 27:41"> 大卫的长兄，示米亚的儿子约拿达说：「我主，不要以为王的众子—少年人都杀了，只有暗嫩一个人死了。自从暗嫩玷辱押沙龙妹子她玛的那日，押沙龙就定意杀暗嫩了。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 19:19"> 现在，我主我王，不要把这事放在心上，以为王的众子都死了，只有暗嫩一个人死了。」</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="创世记 4:8–14; 箴言 28:17; 阿摩司书 5:19"> 押沙龙逃跑了。<br />守望的少年人举目观看，见有许多人从山坡的路上来。</span>
<span className="v" id="v35" data-v="35"> 约拿达对王说：「看哪，王的众子都来了，果然与你仆人所说的相合。」</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳记下 18:33; 撒母耳记下 12:21; 撒母耳记下 13:15"> 话才说完，王的众子都到了，放声大哭；王和臣仆也都哭得甚恸。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="撒母耳记下 3:3; 撒母耳记下 14:32; 撒母耳记下 13:34"> 押沙龙逃到基述王亚米忽的儿子达买那里去了。大卫天天为他儿子悲哀。</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳记下 15:8; 撒母耳记下 14:23; 撒母耳记下 14:32"> 押沙龙逃到基述，在那里住了三年。</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 24:67; 创世记 38:12; 创世记 37:35"> 暗嫩死了以后，大卫王得了安慰，心里切切想念押沙龙。</span>
</div>
</div>

</div>

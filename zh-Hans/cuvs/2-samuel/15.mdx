## 押沙龙阴谋造反

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 1:5; 撒母耳记下 12:11; 撒母耳记上 8:11"> 此后，押沙龙为自己预备车马，又派五十人在他前头奔走。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 18:14; 路得记 4:1; 约伯记 24:14"> 押沙龙常常早晨起来，站在城门的道旁，凡有争讼要去求王判断的，押沙龙就叫他过来，问他说：「你是哪一城的人？」回答说：「仆人是以色列某支派的人。」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 8:15; 以西结书 22:7; 彼得前书 2:17"> 押沙龙对他说：「你的事有情有理，无奈王没有委人听你伸诉。」</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 9:29; 士师记 9:1–5; 箴言 27:2"> 押沙龙又说：「恨不得我作国中的士师！凡有争讼求审判的到我这里来，我必秉公判断。」</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 14:33; 诗篇 55:21; 箴言 26:25"> 若有人近前来要拜押沙龙，押沙龙就伸手拉住他，与他亲嘴。</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 16:18; 彼得后书 2:3; 箴言 11:9"> 以色列人中，凡去见王求判断的，押沙龙都是如此待他们。这样，押沙龙暗中得了以色列人的心。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 58:4; 撒母耳记上 16:13; 撒母耳记上 16:1–2"> 满了四十年<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有作四年的">a</a></sup>，押沙龙对王说：「求你准我往希伯 去，还我向耶和华所许的愿。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 28:20–21; 撒母耳记下 13:37–38; 撒母耳记上 1:11"> 因为仆人住在亚兰的基述，曾许愿说：『耶和华若使我再回耶路撒冷，我必事奉他。』」</span>
<span className="v" id="v9" data-v="9"> 王说：「你平平安安地去吧！」押沙龙就起身，往希伯 去了。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 12:38; 撒母耳记下 5:5; 撒母耳记下 3:2–3"> 押沙龙打发探子走遍以色列各支派，说：「你们一听见角声就说：『押沙龙在希伯 作王了！』」</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 9:13; 撒母耳记上 22:15; 罗马书 16:18–19"> 押沙龙在耶路撒冷请了二百人与他同去，都是诚诚实实去的，并不知道其中的真情。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 41:9; 撒母耳记下 15:31; 约书亚记 15:51"> 押沙龙献祭的时候，打发人去将大卫的谋士、基罗人亚希多弗从他本城请了来。于是叛逆的势派甚大；因为随从押沙龙的人民，日渐增多。</span>
</div>
</div>

## 大卫逃离耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="士师记 9:3; 马太福音 27:22; 撒母耳记下 15:6"> 有人报告大卫说：「以色列人的心都归向押沙龙了！」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 19:9; 以西结书 46:18; 诗篇 55:3–11"> 大卫就对耶路撒冷跟随他的臣仆说：「我们要起来逃走，不然都不能躲避押沙龙了；要速速地去，恐怕他忽然来到，加害于我们，用刀杀尽合城的人。」</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 6:66–69; 箴言 18:24; 路加福音 22:28–29"> 王的臣仆对王说：「我主我王所定的，仆人都愿遵行。」</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 16:21–22; 撒母耳记下 20:3; 诗篇 3:1"> 于是王带着全家的人出去了，但留下十个妃嫔看守宫殿。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 3:1–2; 传道书 10:7; 诗篇 66:12"> 王出去，众民都跟随他，到伯·墨哈，就住下了。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 8:18; 撒母耳记上 30:14; 撒母耳记下 20:7"> 王的臣仆都在他面前过去。基利提人、比利提人，就是从迦特跟随王来的六百人，也都在他面前过去。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 18:2; 路得记 1:11–13"> 王对迦特人以太说：「你是外邦逃来的人，为什么与我们同去呢？你可以回去与新王同住，或者回你本地去吧！</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 23:13; 撒母耳记下 2:6; 约翰福音 1:17"> 你来的日子不多，我今日怎好叫你与我们一同飘流、没有一定的住处呢？你不如带你的弟兄回去吧！愿耶和华用慈爱诚实待你。」</span>
<span className="v" id="v21" data-v="21" data-xref="路得记 1:16–17; 箴言 17:17; 列王纪下 4:30"> 以太对王说：「我指着永生的耶和华起誓，又敢在王面前起誓：无论生死，王在哪里，仆人也必在那里。」</span>
<span className="v" id="v22" data-v="22"> 大卫对以太说：「你前去过河吧！」于是迦特人以太带着跟随他的人和所有的妇人孩子，就都过去了。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 16:2; 列王纪上 2:37; 约翰福音 18:1"> 本地的人都放声大哭。众民尽都过去，王也过了汲沦溪；众民往旷野去了。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 4:15; 撒母耳记下 8:17; 撒母耳记下 20:25"> 撒督和抬 神约柜的利未人也一同来了，将 神的约柜放下。亚比亚他上来，等着众民从城里出来过去。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 25:30; 诗篇 26:8; 诗篇 43:3–4"> 王对撒督说：「你将 神的约柜抬回城去。我若在耶和华眼前蒙恩，他必使我回来，再见约柜和他的居所。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记上 3:18; 撒母耳记下 22:20; 列王纪上 10:9"> 倘若他说：『我不喜悦你』，看哪，我在这里，愿他凭自己的意旨待我！」</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 9:9; 撒母耳记下 17:17; 撒母耳记下 24:11"> 王又对祭司撒督说：「你不是先见吗？你可以安然回城；你儿子亚希玛斯和亚比亚他的儿子约拿单都可以与你同去。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 17:16; 撒母耳记下 15:23; 撒母耳记下 17:1"> 我在旷野的渡口那里等你们报信给我。」</span>
<span className="v" id="v29" data-v="29"> 于是撒督和亚比亚他将 神的约柜抬回耶路撒冷，他们就住在那里。</span>
<span className="v" id="v30" data-v="30" data-xref="以斯帖记 6:12; 撒母耳记下 19:4; 路加福音 19:41"> 大卫蒙头赤脚上橄榄山，一面上一面哭。跟随他的人也都蒙头哭着上去；</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 17:14; 撒母耳记下 17:23; 雅各书 3:15"> 有人告诉大卫说：「亚希多弗也在叛党之中，随从押沙龙。」大卫祷告说：「耶和华啊，求你使亚希多弗的计谋变为愚拙！」</span>
<span className="v" id="v32" data-v="32" data-xref="约书亚记 16:2; 撒母耳记下 1:2; 诗篇 3:3–5"> 大卫到了山顶、敬拜 神的地方，见亚基人户筛，衣服撕裂，头蒙灰尘来迎接他。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 19:35"> 大卫对他说：「你若与我同去，必累赘我；</span>
<span className="v" id="v34" data-v="34" data-xref="约书亚记 8:2; 撒母耳记下 16:16–19; 马太福音 10:16"> 你若回城去，对押沙龙说：『王啊，我愿作你的仆人；我向来作你父亲的仆人，现在我也照样作你的仆人。』这样，你就可以为我破坏亚希多弗的计谋。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 17:15–16"> 祭司撒督和亚比亚他岂不都在那里吗？你在王宫里听见什么，就要告诉祭司撒督和亚比亚他。</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳记下 17:17; 撒母耳记下 15:27; 撒母耳记下 18:19–33"> 撒督的儿子亚希玛斯，亚比亚他的儿子约拿单，也都在那里。凡你们所听见的可以托这二人来报告我。」</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳记下 16:15–16; 历代志上 27:33"> 于是，大卫的朋友户筛进了城；押沙龙也进了耶路撒冷。</span>
</div>

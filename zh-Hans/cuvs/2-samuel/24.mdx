## 大卫调查人口

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 21:1; 历代志上 27:23–24; 雅各书 1:13–14"> 耶和华又向以色列人发怒，就激动大卫，使他吩咐人去数点以色列人和犹大人。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 3:10; 士师记 20:1; 撒母耳记下 20:23"> 大卫就吩咐跟随他的元帅约押说：「你去走遍以色列众支派，从但直到别是巴，数点百姓，我好知道他们的数目。」</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 1:11; 诗篇 115:14; 箴言 14:28"> 约押对王说：「无论百姓多少，愿耶和华—你的 神再加增百倍，使我主我王亲眼得见。我主我王何必喜悦行这事呢？」</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 5:29; 传道书 8:4; 历代志上 21:4"> 但王的命令胜过约押和众军长。约押和众军长就从王面前出去，数点以色列的百姓。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 13:9; 申命记 2:36; 约书亚记 13:16"> 他们过了约旦河，在迦得谷中、城的右边亚罗珥安营，与雅谢相对，</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 19:28; 创世记 31:47–48; 士师记 18:28–29"> 又到了基列和他停·合示地，又到了但·雅安，绕到西顿，</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 19:29; 约书亚记 11:3; 创世记 21:22–33"> 来到泰尔的保障，并希未人和迦南人的各城，又到犹大南方的别是巴。</span>
<span className="v" id="v8" data-v="8"> 他们走遍全地，过了九个月零二十天，就回到耶路撒冷。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 27:23–24; 历代志上 21:5–6; 民数记 1:44–46"> 约押将百姓的总数奏告于王：以色列拿刀的勇士有八十万；犹大有五十万。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 12:13; 撒母耳记上 13:13; 箴言 28:13"> 大卫数点百姓以后，就心中自责，祷告耶和华说：「我行这事大有罪了。耶和华啊，求你除掉仆人的罪孽，因我所行的甚是愚昧。」</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 22:5; 撒母耳记上 9:9; 历代志上 29:29"> 大卫早晨起来，耶和华的话临到先知迦得，就是大卫的先见，说：</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 12:6–10; 启示录 3:19; 箴言 3:12"> 「你去告诉大卫，说耶和华如此说：『我有三样灾，随你选择一样，我好降与你。』」</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 21:12; 利未记 26:25; 撒母耳记下 21:1"> 于是迦得来见大卫，对他说：「你愿意国中有七年的饥荒呢？是在你敌人面前逃跑，被追赶三个月呢？是在你国中有三日的瘟疫呢？现在你要揣摩思想，我好回复那差我来的。」</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 51:1; 诗篇 119:156; 历代志上 21:13"> 大卫对迦得说：「我甚为难！我愿落在耶和华的手里，因为他有丰盛的怜悯。我不愿落在人的手里。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="历代志上 21:14; 历代志上 27:24; 民数记 25:9"> 于是，耶和华降瘟疫与以色列人，自早晨到所定的时候；从但直到别是巴，民间死了七万人。</span>
<span className="v" id="v16" data-v="16" data-xref="约珥书 2:13–14; 创世记 6:6; 出埃及记 12:23"> 天使向耶路撒冷伸手要灭城的时候，耶和华后悔，就不降这灾了，吩咐灭民的天使说：「够了！住手吧！」那时耶和华的使者在耶布斯人亚劳拿的禾场那里。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 74:1; 历代志上 21:16–17; 撒母耳记下 24:10"> 大卫看见灭民的天使，就祷告耶和华说：「我犯了罪，行了恶；但这群羊做了什么呢？愿你的手攻击我和我的父家。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="历代志上 21:18–30; 撒母耳记下 24:11"> 当日，迦得来见大卫，对他说：「你上去，在耶布斯人亚劳拿的禾场上为耶和华筑一座坛。」</span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 11:8; 尼希米记 9:26; 历代志下 36:16"> 大卫就照着迦得奉耶和华名所说的话上去了。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 18:2; 路得记 2:10; 历代志上 21:20–21"> 亚劳拿观看，见王和他臣仆前来，就迎接出去，脸伏于地，向王下拜，</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 21:22; 民数记 25:8; 撒母耳记下 21:3–14"> 说：「我主我王为何来到仆人这里呢？」大卫说：「我要买你这禾场，为耶和华筑一座坛，使民间的瘟疫止住。」</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 19:21; 撒母耳记上 6:14; 历代志上 21:22"> 亚劳拿对大卫说：「我主我王，你喜悦用什么，就拿去献祭。看哪，这里有牛可以作燔祭，有打粮的器具和套牛的轭可以当柴烧。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 20:40–41; 以赛亚书 32:8; 诗篇 20:3–4"> 王啊，这一切，我亚劳拿都奉给你」；又对王说：「愿耶和华—你的 神悦纳你。」</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 21:24–25; 玛拉基书 1:12–14; 创世记 23:13"> 王对亚劳拿说：「不然。我必要按着价值向你买；我不肯用白得之物作燔祭献给耶和华—我的 神。」大卫就用五十舍客勒银子买了那禾场与牛。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 21:14; 耶利米哀歌 3:32–33; 创世记 8:20"> 大卫在那里为耶和华筑了一座坛，献燔祭和平安祭。如此，耶和华垂听国民所求的，瘟疫在以色列人中就止住了。</span>
</div>

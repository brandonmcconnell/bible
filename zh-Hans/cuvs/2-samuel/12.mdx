## 拿单的信息和大卫的悔改

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 20:35–41; 诗篇 51:1–19; 撒母耳记下 11:10–17"> 耶和华差遣拿单去见大卫。拿单到了大卫那里，对他说：「在一座城里有两个人：一个是富户，一个是穷人。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 15:16; 约伯记 1:3; 撒母耳记下 5:13–16"> 富户有许多牛群羊群；</span>
<span className="v" id="v3" data-v="3" data-xref="弥迦书 7:5; 撒母耳记下 11:3; 箴言 5:18–19"> 穷人除了所买来养活的一只小母羊羔之外，别无所有。羊羔在他家里和他儿女一同长大，吃他所吃的，喝他所喝的，睡在他怀中，在他看来如同女儿一样。</span>
<span className="v" id="v4" data-v="4" data-xref="雅各书 1:14; 撒母耳记下 11:3–4; 创世记 18:2–7"> 有一客人来到这富户家里；富户舍不得从自己的牛群羊群中取一只预备给客人吃，却取了那穷人的羊羔，预备给客人吃。」</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 38:24; 罗马书 2:1; 撒母耳记上 26:16"> 大卫就甚恼怒那人，对拿单说：「我指着永生的耶和华起誓，行这事的人该死！</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 22:1; 路加福音 19:8; 箴言 6:31"> 他必偿还羊羔四倍；因为他行这事，没有怜恤的心。」</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 14:14; 撒母耳记上 16:13; 撒母耳记下 22:1"> 拿单对大卫说：「你就是那人！耶和华—以色列的 神如此说：『我膏你作以色列的王，救你脱离扫罗的手。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 84:11; 罗马书 8:32; 撒母耳记下 9:7"> 我将你主人的家业赐给你，将你主人的妻交在你怀里，又将以色列和犹大家赐给你；你若还以为不足，我早就加倍地赐给你。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 15:19; 诗篇 139:1–2; 撒母耳记上 15:23"> 你为什么藐视耶和华的命令，行他眼中看为恶的事呢？你借亚扪人的刀杀害赫人乌利亚，又娶了他的妻为妻。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 18:14–15; 马太福音 26:52; 罗马书 2:4"> 你既藐视我，娶了赫人乌利亚的妻为妻，所以刀剑必永不离开你的家。』</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 16:21–22; 申命记 28:30; 撒母耳记下 15:10"> 耶和华如此说：『我必从你家中兴起祸患攻击你；我必在你眼前把你的妃嫔赐给别人，他在日光之下就与她们同寝。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 16:22; 撒母耳记下 11:4–15; 传道书 12:14"> 你在暗中行这事，我却要在以色列众人面前，日光之下，报应你。』」</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 51:4; 撒母耳记下 24:10; 箴言 28:13"> 大卫对拿单说：「我得罪耶和华了！」拿单说：「耶和华已经除掉你的罪，你必不至于死。</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 2:24; 以赛亚书 52:5; 诗篇 89:31–33"> 只是你行这事，叫耶和华的仇敌大得亵渎的机会，故此，你所得的孩子必定要死。」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 25:38; 诗篇 104:29; 历代志下 13:20"> 拿单就回家去了。 大卫的儿子夭折 耶和华击打乌利亚妻给大卫所生的孩子，使他得重病。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 13:31; 使徒行传 9:9; 诗篇 69:10"> 所以大卫为这孩子恳求 神，而且禁食，进入内室，终夜躺在地上。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 3:35; 撒母耳记上 28:23"> 他家中的老臣来到他旁边，要把他从地上扶起来，他却不肯起来，也不同他们吃饭。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 20:15"> 到第七日，孩子死了。大卫的臣仆不敢告诉他孩子死了，因他们说：「孩子还活着的时候，我们劝他，他尚且不肯听我们的话，若告诉他孩子死了，岂不更加忧伤吗？」</span>
<span className="v" id="v19" data-v="19"> 大卫见臣仆彼此低声说话，就知道孩子死了，问臣仆说：「孩子死了吗？」他们说：「死了。」</span>
<span className="v" id="v20" data-v="20" data-xref="约伯记 1:20; 路得记 3:3; 耶利米哀歌 3:39–41"> 大卫就从地上起来，沐浴，抹膏，换了衣裳，进耶和华的殿敬拜；然后回宫，吩咐人摆饭，他便吃了。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 2:15"> 臣仆问他说：「你所行的是什么意思？孩子活着的时候，你禁食哭泣；孩子死了，你倒起来吃饭。」</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 38:1–3; 以赛亚书 38:5; 约拿书 3:9–10"> 大卫说：「孩子还活着，我禁食哭泣；因为我想，或者耶和华怜恤我，使孩子不死也未可知。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 37:35; 约伯记 30:23; 路加福音 23:43"> 孩子死了，我何必禁食，我岂能使他返回呢？我必往他那里去，他却不能回我这里来。」</span>
</div>
</div>

## 所罗门出生

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="马太福音 1:6; 历代志上 28:5–6; 历代志上 22:9–10"> 大卫安慰他的妻拔示巴，与她同寝，她就生了儿子，给他起名叫所罗门。耶和华也喜爱他，</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 7:4; 尼希米记 13:26; 列王纪上 1:11"> 就借先知拿单赐他一个名字，叫耶底底亚，因为耶和华爱他。</span>
</div>
</div>

## 大卫攻取拉巴

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="历代志上 20:1–3; 申命记 3:11; 撒母耳记下 11:25"> 约押攻取亚扪人的京城拉巴。</span>
<span className="v" id="v27" data-v="27" data-xref="以西结书 21:20; 撒母耳记下 11:1; 申命记 3:11"> 约押打发使者去见大卫，说：「我攻打拉巴，取其水城。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 7:18"> 现在你要聚集其余的军兵来，安营围攻这城，恐怕我取了这城，人就以我的名叫这城。」</span>
<span className="v" id="v29" data-v="29"> 于是大卫聚集众军，往拉巴去攻城，就取了这城，</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 20:2"> 夺了亚扪人之王所戴的金冠冕<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="王：或译玛勒堪；玛勒堪就是米勒公，又名摩洛，亚扪族之神名">a</a></sup>，其上的金子重一他连得，又嵌着宝石。人将这冠冕戴在大卫头上。大卫从城里夺了许多财物，</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 20:3; 诗篇 21:8–9; 阿摩司书 1:3"> 将城里的人拉出来，放在锯下，或铁耙下，或铁斧下，或叫他经过砖窑<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：强他们用锯，或用打粮食的铁器，或用铁斧做工，或使在砖窑里服役">b</a></sup>；大卫待亚扪各城的居民都是如此。其后，大卫和众军都回耶路撒冷去了。</span>
</div>

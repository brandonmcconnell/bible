## 押沙龙败亡

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 8:10; 撒母耳记上 8:12; 出埃及记 17:9"> 大卫数点跟随他的人，立千夫长、百夫长率领他们。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 7:16; 撒母耳记下 15:19–22; 撒母耳记下 10:7–10"> 大卫打发军兵出战，分为三队：一队在约押手下，一队在洗鲁雅的儿子、约押兄弟亚比筛手下，一队在迦特人以太手下。大卫对军兵说：「我必与你们一同出战。」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 21:17; 出埃及记 17:10–12; 列王纪上 22:31"> 军兵却说：「你不可出战。若是我们逃跑，敌人必不介意；我们阵亡一半，敌人也不介意。因为你一人强似我们万人，你不如在城里预备帮助我们。」</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 18:24; 撒母耳记下 18:1; 撒母耳记上 29:2"> 王向他们说：「你们以为怎样好，我就怎样行。」于是王站在城门旁，军兵或百或千地挨次出去了。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 21:18–21; 撒母耳记下 16:11; 诗篇 103:13"> 王嘱咐约押、亚比筛、以太说：「你们要为我的缘故宽待那少年人押沙龙。」王为押沙龙嘱咐众将的话，兵都听见了。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 17:18; 约书亚记 17:15; 士师记 12:4–6"> 兵就出到田野迎着以色列人，在以法莲树林里交战。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 24:21; 撒母耳记下 2:31; 撒母耳记下 2:26"> 以色列人败在大卫的仆人面前；那日阵亡的甚多，共有二万人。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 15:10; 约书亚记 10:11; 诗篇 43:1"> 因为在那里四面打仗，死于树林的比死于刀剑的更多。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 14:26; 箴言 30:17; 约伯记 31:3"> 押沙龙偶然遇见大卫的仆人。押沙龙骑着骡子，从大橡树密枝底下经过，他的头发被树枝绕住，就悬挂起来，所骑的骡子便离他去了。</span>
<span className="v" id="v10" data-v="10"> 有个人看见，就告诉约押说：「我看见押沙龙挂在橡树上了。」</span>
<span className="v" id="v11" data-v="11"> 约押对报信的人说：「你既看见他，为什么不将他打死落在地上呢？你若打死他，我就赏你十舍客勒银子，一条带子。」</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 18:5"> 那人对约押说：「我就是得你一千舍客勒银子，我也不敢伸手害王的儿子；因为我们听见王嘱咐你和亚比筛并以太说：『你们要谨慎，不可害那少年人押沙龙。』</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 14:19–20; 希伯来书 4:13; 撒母耳记下 4:10–12"> 我若妄为害了他的性命，就是你自己也必与我为敌（原来，无论何事都瞒不过王。）」</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 45:5; 马太福音 12:40; 撒母耳记下 14:30"> 约押说：「我不能与你留连。」约押手拿三杆短枪，趁押沙龙在橡树上还活着，就刺透他的心。</span>
<span className="v" id="v15" data-v="15"> 给约押拿兵器的十个少年人围绕押沙龙，将他杀死。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 2:28; 撒母耳记下 20:22; 哥林多前书 14:8"> 约押吹角，拦阻众人，他们就回来，不再追赶以色列人。</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 7:26; 约书亚记 8:29; 撒母耳记下 19:8"> 他们将押沙龙丢在林中一个大坑里，上头堆起一大堆石头。以色列众人都逃跑，各回各家去了。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 14:17; 撒母耳记下 14:27; 撒母耳记上 15:12"> 押沙龙活着的时候，在王谷立了一根石柱，因他说：「我没有儿子为我留名。」他就以自己的名称那石柱叫押沙龙柱，直到今日。</span>
</div>
</div>

## 大卫听闻押沙龙死讯

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 15:36; 撒母耳记下 18:31; 诗篇 9:4"> 撒督的儿子亚希玛斯说：「容我跑去，将耶和华向仇敌给王报仇的信息报与王知。」</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记下 18:5; 撒母耳记下 18:33; 撒母耳记下 17:16–21"> 约押对他说：「你今日不可去报信，改日可以报信；因为今日王的儿子死了，所以你不可去报信。」</span>
<span className="v" id="v21" data-v="21"> 约押对古示人说：「你去将你所看见的告诉王。」古示人在约押面前下拜，就跑去了。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 1:28; 以弗所书 5:4"> 撒督的儿子亚希玛斯又对约押说：「无论怎样，求你容我随着古示人跑去。」约押说：「我儿，你报这信息，既不得赏赐，何必要跑去呢？」</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 20:4"> 他又说：「无论怎样，我要跑去。」约押说：「你跑去吧！」亚希玛斯就从平原往前跑，跑过古示人去了。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 19:8; 撒母耳记下 13:34; 以西结书 33:2–7"> 大卫正坐在城瓮里。守望的人上城门楼的顶上，举目观看，见有一个人独自跑来。</span>
<span className="v" id="v25" data-v="25"> 守望的人就大声告诉王。王说：「他若独自来，必是报口信的。」那人跑得渐渐近了。</span>
<span className="v" id="v26" data-v="26"> 守望的人又见一人跑来，就对守城门的人说：「又有一人独自跑来。」王说：「这也必是报信的。」</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 9:20; 列王纪上 1:42; 罗马书 10:15"> 守望的人说：「我看前头人的跑法，好像撒督的儿子亚希玛斯的跑法一样。」王说：「他是个好人，必是报好信息。」</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 14:4; 创世记 14:20; 创世记 24:27"> 亚希玛斯向王呼叫说：「平安了！」就在王面前脸伏于地叩拜，说：「耶和华—你的 神是应当称颂的，因他已将那举手攻击我主我王的人交给王了。」</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 18:22; 撒母耳记下 20:9; 撒母耳记下 18:19–20"> 王问说：「少年人押沙龙平安不平安？」亚希玛斯回答说：「约押打发王的仆人，那时仆人听见众民大声喧哗，却不知道是什么事。」</span>
<span className="v" id="v30" data-v="30"> 王说：「你退去，站在旁边。」他就退去，站在旁边。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 18:19; 撒母耳记下 18:28; 路加福音 18:7–8"> 古示人也来到，说：「有信息报给我主我王！耶和华今日向一切兴起攻击你的人给你报仇了。」</span>
<span className="v" id="v32" data-v="32" data-xref="士师记 5:31; 撒母耳记上 25:26; 但以理书 4:19"> 王问古示人说：「少年人押沙龙平安不平安？」古示人回答说：「愿我主我王的仇敌，和一切兴起要杀害你的人，都与那少年人一样。」</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 19:4; 撒母耳记下 12:10–23; 箴言 17:25"> 王就心里伤恸，上城门楼去哀哭，一面走一面说：「我儿押沙龙啊！我儿，我儿押沙龙啊！我恨不得替你死，押沙龙啊，我儿！我儿！」</span>

## 大卫和拔示巴

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 20:1; 列王纪上 20:26; 列王纪上 20:22"> 过了一年，到列王出战的时候，大卫又差派约押，率领臣仆和以色列众人出战。他们就打败亚扪人，围攻拉巴。大卫仍住在耶路撒冷。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 5:28; 诗篇 119:37; 约伯记 31:1"> 一日，太阳平西，大卫从床上起来，在王宫的平顶上游行，看见一个妇人沐浴，容貌甚美，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 23:39; 历代志上 3:5; 雅各书 1:14–15"> 大卫就差人打听那妇人是谁。有人说：「她是以连的女儿，赫人乌利亚的妻拔示巴。」</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 18:19; 雅各书 1:14–15; 诗篇 51:1–19"> 大卫差人去，将妇人接来；那时她的月经才得洁净。她来了，大卫与她同房，她就回家去了。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 22:22; 箴言 6:34"> 于是她怀了孕，打发人去告诉大卫说：「我怀了孕。」</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 28:13; 创世记 4:7; 撒母耳记上 15:30"> 大卫差人到约押那里，说：「你打发赫人乌利亚到我这里来。」约押就打发乌利亚去见大卫。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 37:14; 撒母耳记上 17:22; 创世记 29:6"> 乌利亚来了，大卫问约押好，也问兵好，又问争战的事怎样。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 18:4; 创世记 43:34; 以赛亚书 29:15"> 大卫对乌利亚说：「你回家去，洗洗脚吧！」乌利亚出了王宫，随后王送他一分食物。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 21:30; 约伯记 5:12–14"> 乌利亚却和他主人的仆人一同睡在宫门外，没有回家去。</span>
<span className="v" id="v10" data-v="10"> 有人告诉大卫说：「乌利亚没有回家去。」大卫就问乌利亚说：「你从远路上来，为什么不回家去呢？」</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 7:2; 撒母耳记下 20:6; 撒母耳记下 7:6"> 乌利亚对大卫说：「约柜和以色列与犹大兵都住在棚里，我主约押和我主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：王">a</a></sup>的仆人都在田野安营，我岂可回家吃喝、与妻子同寝呢？我敢在王面前起誓<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是我指着王和王的性命起誓">b</a></sup>：我决不行这事！」</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 2:37; 耶利米书 2:22–23"> 大卫吩咐乌利亚说：「你今日仍住在这里，明日我打发你去。」于是乌利亚那日和次日住在耶路撒冷。</span>
<span className="v" id="v13" data-v="13" data-xref="哈巴谷书 2:15; 创世记 19:32–35; 箴言 20:1"> 大卫召了乌利亚来，叫他在自己面前吃喝，使他喝醉。到了晚上，乌利亚出去与他主的仆人一同住宿，还没有回到家里去。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 17:9; 列王纪上 21:8–10; 诗篇 19:13"> 次日早晨，大卫写信与约押，交乌利亚随手带去。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 12:9; 诗篇 51:4; 耶利米书 20:13"> 信内写着说：「要派乌利亚前进，到阵势极险之处，你们便退后，使他被杀。」</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 29:12; 撒母耳记上 22:17–19; 使徒行传 5:29"> 约押围城的时候，知道敌人那里有勇士，便将乌利亚派在那里。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 12:9; 诗篇 51:14"> 城里的人出来和约押打仗；大卫的仆人中有几个被杀的，赫人乌利亚也死了。</span>
<span className="v" id="v18" data-v="18"> 于是，约押差人去将争战的一切事告诉大卫，</span>
<span className="v" id="v19" data-v="19"> 又嘱咐使者说：「你把争战的一切事对王说完了，</span>
<span className="v" id="v20" data-v="20"> 王若发怒，问你说：『你们打仗为什么挨近城墙呢？岂不知敌人必从城上射箭吗？</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 7:1; 士师记 9:50–54; 撒母耳记下 3:27"> 从前打死耶路·比设<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="就是耶路·巴力，见士师记九章一节">c</a></sup>儿子亚比米勒的是谁呢？岂不是一个妇人从城上抛下一块上磨石来，打在他身上，他就死在提备斯吗？你们为什么挨近城墙呢？』你就说：『王的仆人—赫人乌利亚也死了。』」</span>
<span className="v" id="v22" data-v="22"> 使者起身，来见大卫，照着约押所吩咐他的话奏告大卫。</span>
<span className="v" id="v23" data-v="23"> 使者对大卫说：「敌人强过我们，出到郊野与我们打仗，我们追杀他们，直到城门口。</span>
<span className="v" id="v24" data-v="24"> 射箭的从城上射王的仆人，射死几个，赫人乌利亚也死了。」</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 12:26; 约书亚记 7:8–9; 传道书 9:1–3"> 王向使者说：「你告诉约押说：『不要因这事愁闷，刀剑或吞灭这人或吞灭那人，没有一定的；你只管竭力攻城，将城倾覆。』可以用这话勉励约押。」</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 14:2; 创世记 27:41; 撒母耳记下 3:31"> 乌利亚的妻听见丈夫乌利亚死了，就为他哀哭。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 51:4–5; 撒母耳记下 12:9; 申命记 22:29"> 哀哭的日子过了，大卫差人将她接到宫里，她就作了大卫的妻，给大卫生了一个儿子。但大卫所行的这事，耶和华甚不喜悦。</span>
</div>

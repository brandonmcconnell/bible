## 保罗受患难后的感恩

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以弗所书 1:3; 彼得前书 1:3; 罗马书 15:5–6"> 愿颂赞归与我们的主耶稣基督的父 神，就是发慈悲的父，赐各样安慰的 神。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 5:11; 以赛亚书 51:12; 帖撒罗尼迦后书 2:16–17"> 我们在一切患难中，他就安慰我们，叫我们能用 神所赐的安慰去安慰那遭各样患难的人。</span>
<span className="v" id="v5" data-v="5" data-xref="歌罗西书 1:24; 腓立比书 3:10; 哥林多后书 4:10–11"> 我们既多受基督的苦楚，就靠基督多得安慰。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太后书 2:10; 哥林多后书 1:4; 哥林多后书 4:15–18"> 我们受患难呢，是为叫你们得安慰，得拯救；我们得安慰呢，也是为叫你们得安慰；这安慰能叫你们忍受我们所受的那样苦楚。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:17–18; 帖撒罗尼迦后书 1:4–7; 雅各书 1:12"> 我们为你们所存的盼望是确定的，因为知道你们既是同受苦楚，也必同得安慰。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 4:7–12; 哥林多前书 15:32; 哥林多前书 4:8"> 弟兄们，我们不要你们不晓得，我们从前在亚细亚遭遇苦难，被压太重，力不能胜，甚至连活命的指望都绝了；</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 3:5; 希伯来书 11:19; 哥林多后书 4:7"> 自己心里也断定是必死的，叫我们不靠自己，只靠叫死人复活的 神。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 4:10; 诗篇 34:19; 彼得后书 2:9"> 他曾救我们脱离那极大的死亡，现在仍要救我们，并且我们指望他将来还要救我们。</span>
<span className="v" id="v11" data-v="11" data-xref="腓立比书 1:19; 哥林多后书 4:15; 使徒行传 12:5"> 你们以祈祷帮助我们，好叫许多人为我们谢恩，就是为我们因许多人所得的恩。</span>
</div>
</div>

## 保罗延期访问哥林多

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 2:17; 哥林多前书 2:13; 雅各书 3:13–18"> 我们所夸的是自己的良心，见证我们凭着 神的圣洁和诚实；在世为人不靠人的聪明，乃靠 神的恩惠，向你们更是这样。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 4:2; 腓利门书 1:6; 哥林多后书 13:6"> 我们现在写给你们的话，并不外乎你们所念的、所认识的，我也盼望你们到底还是要认识；</span>
<span className="v" id="v14" data-v="14" data-xref="腓立比书 2:16; 哥林多前书 1:8; 帖撒罗尼迦前书 2:19–20"> 正如你们已经有几分认识我们，以我们夸口，好像我们在我们主耶稣的日子以你们夸口一样。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 4:19; 罗马书 1:11; 罗马书 15:29"> 我既然这样深信，就早有意到你们那里去，叫你们再得益处；</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 16:5–7; 使徒行传 21:5; 使徒行传 19:21–22"> 也要从你们那里经过，往马其顿去，再从马其顿回到你们那里，叫你们给我送行往犹太去。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 5:37; 雅各书 5:12; 哥林多后书 10:2–3"> 我有此意，岂是反复不定吗？我所起的意，岂是从情欲起的，叫我忽是忽非吗？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 1:9; 启示录 3:7; 约翰福音 7:28"> 我指着信实的 神说，我们向你们所传的道，并没有是而又非的。</span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 13:8; 启示录 1:17; 约翰二书 1:9"> 因为我和西拉并提摩太，在你们中间所传 神的儿子耶稣基督，总没有是而又非的，在他只有一是。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰一书 2:24–25; 加拉太书 3:22; 启示录 7:12"> 神的应许，不论有多少，在基督都是是的。所以借着他也都是实在<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="实在：原文是阿们">a</a></sup>的，叫 神因我们得荣耀。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 2:27; 彼得前书 5:10; 约翰一书 2:20"> 那在基督里坚固我们和你们，并且膏我们的就是 神。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 4:30; 哥林多后书 5:5; 以弗所书 1:13–14"> 他又用印印了我们，并赐圣灵在我们心里作凭据<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是质">b</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="加拉太书 1:20; 哥林多前书 4:21; 罗马书 1:9"> 我呼吁 神给我的心作见证，我没有往哥林多去是为要宽容你们。</span>
<span className="v" id="v24" data-v="24" data-xref="彼得前书 5:3; 哥林多前书 15:1; 腓立比书 1:25–26"> 我们并不是辖管你们的信心，乃是帮助你们的快乐，因为你们凭信才站立得住。</span>
</div>
</div>

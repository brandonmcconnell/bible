<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约伯记 19:25–26; 约翰一书 3:2; 彼得后书 1:13–14"> 我们原知道，我们这地上的帐棚若拆毁了，必得 神所造，不是人手所造，在天上永存的房屋。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 8:23; 哥林多前书 15:53–54; 哥林多后书 5:3–4"> 我们在这帐棚里叹息，深想得那从天上来的房屋，好像穿上衣服；</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 3:7–11; 启示录 16:15; 启示录 3:18"> 倘若穿上，被遇见的时候就不至于赤身了。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 15:53–54; 哥林多后书 5:2; 以赛亚书 25:8"> 我们在这帐棚里叹息劳苦，并非愿意脱下这个，乃是愿意穿上那个，好叫这必死的被生命吞灭了。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 1:22; 以弗所书 1:13–14; 罗马书 8:23"> 为此，培植我们的就是 神，他又赐给我们圣灵作凭据<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是质">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 5:1; 腓立比书 3:20–21; 希伯来书 11:13"> 所以，我们时常坦然无惧，并且晓得我们住在身内，便与主相离。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 11:1–27; 哥林多后书 4:18; 罗马书 8:24–25"> 因我们行事为人是凭着信心，不是凭着眼见。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比书 1:20–24; 哥林多后书 5:6; 约翰福音 14:3"> 我们坦然无惧，是更愿意离开身体与主同住。</span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 1:10; 彼得后书 3:14; 罗马书 14:18"> 所以，无论是住在身内，离开身外，我们立了志向，要得主的喜悦。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 16:27; 启示录 22:12; 以弗所书 6:8"> 因为我们众人必要在基督台前显露出来，叫各人按着本身所行的，或善或恶受报。</span>
</div>
</div>

## 劝人与 神和好的职分

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="犹大书 1:23; 希伯来书 10:31; 提摩太后书 2:24–26"> 我们既知道主是可畏的，所以劝人。但我们在 神面前是显明的，盼望在你们的良心里也是显明的。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 3:1; 哥林多后书 1:14; 加拉太书 6:12–14"> 我们不是向你们再举荐自己，乃是叫你们因我们有可夸之处，好对那凭外貌不凭内心夸口的人，有言可答。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 11:16–17; 哥林多后书 11:1; 哥林多后书 12:6"> 我们若果颠狂，是为 神；若果谨守，是为你们。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 2:20; 罗马书 14:7–9; 马太福音 10:37–38"> 原来基督的爱激励我们；因我们想，一人既替众人死，众人就都死了；</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 14:7–9; 彼得前书 4:2–4; 彼得前书 1:14–15"> 并且他替众人死，是叫那些活着的人不再为自己活，乃为替他们死而复活的主活。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 3:11; 腓立比书 3:7–8; 约翰福音 6:63"> 所以，我们从今以后，不凭着外貌<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是肉体；本节同">b</a></sup>认人了。虽然凭着外貌认过基督，如今却不再这样认他了。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 36:26; 以弗所书 4:22–24; 以赛亚书 43:18–19"> 若有人在基督里，他就是新造的人，旧事已过，都变成新的了。</span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 1:20–21; 哥林多后书 5:19–20; 罗马书 5:10–11"> 一切都是出于 神；他借着基督使我们与他和好，又将劝人与他和好的职分赐给我们。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 43:25; 以赛亚书 44:22; 约翰一书 2:1–2"> 这就是 神在基督里，叫世人与自己和好，不将他们的过犯归到他们身上，并且将这和好的道理托付了我们。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 6:20; 路加福音 14:23; 玛拉基书 2:7"> 所以，我们作基督的使者，就好像 神借我们劝你们一般。我们替基督求你们与 神和好。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得前书 2:22–24; 彼得前书 3:18; 罗马书 5:19"> 神使那无罪<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="无罪：原文是不知罪">c</a></sup>的，替我们成为罪，好叫我们在他里面成为 神的义。</span>
</div>
</div>

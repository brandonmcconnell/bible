## 保罗和假使徒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 11:4; 哥林多前书 1:21; 哥林多后书 11:19"> 但愿你们宽容我这一点愚妄，其实你们原是宽容我的。</span>
<span className="v" id="v2" data-v="2" data-xref="何西阿书 2:19–20; 以弗所书 5:26–27; 以赛亚书 54:5"> 我为你们起的愤恨，原是 神那样的愤恨。因为我曾把你们许配一个丈夫，要把你们如同贞洁的童女，献给基督。</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 2:8; 加拉太书 1:6; 以弗所书 4:14"> 我只怕你们的心或偏于邪，失去那向基督所存纯一清洁的心，就像蛇用诡诈诱惑了夏娃一样。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 1:6–8; 哥林多前书 3:11; 提摩太前书 2:5"> 假如有人来另传一个耶稣，不是我们所传过的；或者你们另受一个灵，不是你们所受过的；或者另得一个福音，不是你们所得过的；你们容让他也就罢了。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 12:11–12; 哥林多前书 15:10; 加拉太书 2:6–9"> 但我想，我一点不在那些最大的使徒以下。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所书 3:4; 哥林多前书 1:17; 哥林多后书 4:2"> 我的言语虽然粗俗，我的知识却不粗俗。这是我们在凡事上向你们众人显明出来的。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 12:13; 帖撒罗尼迦前书 2:9; 哥林多后书 10:1"> 我因为白白传 神的福音给你们，就自居卑微，叫你们高升，这算是我犯罪吗？</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比书 4:18; 哥林多后书 11:9; 腓立比书 4:14–16"> 我亏负了别的教会，向他们取了工价来给你们效力。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦后书 3:8–9; 帖撒罗尼迦前书 2:9; 帖撒罗尼迦前书 2:6"> 我在你们那里缺乏的时候，并没有累着你们一个人；因我所缺乏的，那从马其顿来的弟兄们都补足了。我向来凡事谨守，后来也必谨守，总不至于累着你们。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 9:1; 罗马书 1:9; 使徒行传 18:12"> 既有基督的诚实在我里面，就无人能在亚该亚一带地方阻挡我这自夸。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 12:15; 哥林多后书 6:11–12; 哥林多后书 7:3"> 为什么呢？是因我不爱你们吗？这有 神知道。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 9:12; 哥林多前书 5:6; 哥林多后书 5:12"> 我现在所做的，后来还要做，为要断绝那些寻机会人的机会，使他们在所夸的事上也不过与我们一样。</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太书 1:7; 启示录 2:2; 约翰一书 4:1"> 那等人是假使徒，行事诡诈，装作基督使徒的模样。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 1:8; 哥林多后书 2:11; 哥林多后书 11:3"> 这也不足为怪，因为连撒但也装作光明的天使。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比书 3:19; 启示录 9:11; 以赛亚书 9:14–15"> 所以他的差役，若装作仁义的差役，也不算希奇。他们的结局必然照着他们的行为。</span>
</div>
</div>

## 保罗作使徒所受的患难

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 11:1; 哥林多后书 12:6; 哥林多后书 12:11"> 我再说，人不可把我看作愚妄的。纵然如此，也要把我当作愚妄人接纳，叫我可以略略自夸。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 7:12; 腓立比书 3:3–6; 哥林多后书 9:4"> 我说的话不是奉主命说的，乃是像愚妄人放胆自夸；</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 4:10; 哥林多后书 11:21–23; 哥林多后书 10:12–18"> 既有好些人凭着血气自夸，我也要自夸了。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 4:10; 哥林多前书 10:15; 哥林多前书 8:1"> 你们既是精明人，就能甘心忍耐愚妄人。</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太书 2:4; 加拉太书 4:3; 加拉太书 5:1"> 假若有人强你们作奴仆，或侵吞你们，或掳掠你们，或侮慢你们，或打你们的脸，你们都能忍耐他。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 10:10; 哥林多后书 11:17; 哥林多后书 10:1–2"> 我说这话是羞辱自己，好像我们从前是软弱的。然而，人在何事上勇敢，（我说句愚妄话，）我也勇敢。</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比书 3:5; 罗马书 11:1; 罗马书 9:4"> 他们是希伯来人吗？我也是。他们是以色列人吗？我也是。他们是亚伯拉罕的后裔吗？我也是。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 6:4–5; 哥林多后书 1:9–10; 哥林多后书 6:9"> 他们是基督的仆人吗？（我说句狂话，）我更是。我比他们多受劳苦，多下监牢，受鞭打是过重的，冒死是屡次有的。</span>
<span className="v" id="v24" data-v="24" data-xref="马可福音 13:9; 申命记 25:2–3; 马太福音 10:17"> 被犹太人鞭打五次，每次四十减去一下；</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 14:19; 使徒行传 16:37; 希伯来书 11:37"> 被棍打了三次；被石头打了一次；遇着船坏三次，一昼一夜在深海里。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 14:5; 使徒行传 17:5; 使徒行传 13:50"> 又屡次行远路，遭江河的危险、盗贼的危险、同族的危险、外邦人的危险、城里的危险、旷野的危险、海中的危险、假弟兄的危险。</span>
<span className="v" id="v27" data-v="27" data-xref="腓立比书 4:12; 哥林多后书 6:5; 帖撒罗尼迦前书 2:9"> 受劳碌、受困苦，多次不得睡，又饥又渴，多次不得食，受寒冷，赤身露体。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 7:17; 罗马书 15:16; 使徒行传 20:18–35"> 除了这外面的事，还有为众教会挂心的事，天天压在我身上。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 8:13; 哥林多前书 9:22; 加拉太书 4:8–20"> 有谁软弱，我不软弱呢？有谁跌倒，我不焦急呢？</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多后书 12:5–11; 箴言 25:27; 哥林多前书 2:3"> 我若必须自夸，就夸那关乎我软弱的事便了。</span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 9:5; 以弗所书 1:3; 约翰福音 10:30"> 那永远可称颂之主耶稣的父 神知道我不说谎。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 9:24–25; 哥林多后书 11:26"> 在大马士革的亚哩达王手下的提督把守大马士革城，要捉拿我，</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 9:25; 撒母耳记上 19:12; 约书亚记 2:18"> 我就从窗户中，在筐子里，从城墙上被人缒下去，脱离了他的手。</span>
</div>
</div>

## 慷慨的捐助

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 16:9; 哥林多后书 9:2; 哥林多后书 9:4"> 弟兄们，我把 神赐给马其顿众教会的恩告诉你们，</span>
<span className="v" id="v2" data-v="2" data-xref="雅各书 2:5; 箴言 11:25; 哥林多后书 6:10"> 就是他们在患难中受大试炼的时候，仍有满足的快乐，在极穷之间还格外显出他们乐捐的厚恩。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 35:29; 出埃及记 35:5; 出埃及记 35:21–22"> 我可以证明，他们是按着力量，而且也过了力量，自己甘心乐意地捐助，</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 24:17; 加拉太书 6:10; 哥林多后书 9:1"> 再三地求我们，准他们在这供给圣徒的恩情上有分；</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 12:1; 罗马书 14:7–9; 历代志下 30:12"> 并且他们所做的，不但照我们所想望的，更照 神的旨意先把自己献给主，又归附了我们。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 12:18; 哥林多后书 8:19; 哥林多后书 8:4"> 因此我劝提多，既然在你们中间开办这慈惠的事，就当办成了。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 9:8; 彼得后书 1:5–8; 帖撒罗尼迦后书 1:3"> 你们既然在信心、口才、知识、热心，和待我们的爱心上，都格外显出满足来，就当在这慈惠的事上也格外显出满足来。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 7:6; 约翰一书 3:17–19; 雅各书 2:14–16"> 我说这话，不是吩咐你们，乃是借着别人的热心试验你们爱心的实在。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 8:32; 腓立比书 2:6–8; 马太福音 20:28"> 你们知道我们主耶稣基督的恩典：他本来富足，却为你们成了贫穷，叫你们因他的贫穷，可以成为富足。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 6:18–19; 希伯来书 13:16; 哥林多后书 9:2"> 我在这事上把我的意见告诉你们，是与你们有益；因为你们下手办这事，而且起此心意，已经有一年了，</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 9:2"> 如今就当办成这事。既有愿做的心，也当照你们所有的去办成。</span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 12:42–44; 哥林多后书 9:7; 路加福音 21:1–4"> 因为人若有愿做的心，必蒙悦纳，乃是照他所有的，并不是照他所无的。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 4:34; 罗马书 15:26–27"> 我原不是要别人轻省，你们受累，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 9:12; 使徒行传 4:34"> 乃要均平，就是要你们的富余，现在可以补他们的不足，使他们的富余，将来也可以补你们的不足，这就均平了。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 16:18; 路加福音 22:35"> 如经上所记：<br /><span className="pl pl-1">多收的也没有余；</span><br /><span className="pl pl-1">少收的也没有缺。</span></span>
</div>
</div>

## 提多和他的同工

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="启示录 17:17; 耶利米书 32:40; 哥林多后书 2:13–14"> 多谢 神，感动提多的心，叫他待你们殷勤，像我一样。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 8:6; 希伯来书 13:22; 哥林多后书 8:10"> 他固然是听了我的劝，但自己更是热心，情愿往你们那里去。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 12:18; 哥林多后书 8:19; 哥林多前书 7:17"> 我们还打发一位兄弟和他同去，这人在福音上得了众教会的称赞。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 16:3–4; 哥林多后书 4:15; 哥林多后书 9:8"> 不但这样，他也被众教会挑选，和我们同行，把所托与我们的这捐资送到了，可以荣耀主，又表明我们乐意的心。</span>
<span className="v" id="v20" data-v="20" data-xref="帖撒罗尼迦前书 5:22; 罗马书 14:16; 以弗所书 5:15"> 这就免得有人因我们收的捐银很多，就挑我们的不是。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 12:17; 彼得前书 2:12; 腓立比书 4:8"> 我们留心行光明的事，不但在主面前，就在人面前也是这样。</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比书 2:20–22"> 我们又打发一位兄弟同去；这人的热心，我们在许多事上屡次试验过。现在他因为深信你们，就更加热心了。</span>
<span className="v" id="v23" data-v="23" data-xref="腓立比书 2:25; 腓利门书 1:17; 哥林多后书 8:6"> 论到提多，他是我的同伴，一同为你们劳碌的。论到那两位兄弟，他们是众教会的使者，是基督的荣耀。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 7:14; 哥林多后书 7:4; 哥林多后书 9:2–4"> 所以，你们务要在众教会面前显明你们爱心的凭据，并我所夸奖你们的凭据。</span>
</div>

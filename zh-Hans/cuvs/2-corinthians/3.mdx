## 新约的执事

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 12:11; 哥林多后书 10:12; 哥林多后书 5:12"> 我们岂是又举荐自己吗？岂像别人用人的荐信给你们或用你们的荐信给人吗？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 9:1–2; 帖撒罗尼迦前书 1:8; 罗马书 1:8"> 你们就是我们的荐信，写在我们的心里，被众人所知道所念诵的。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 11:19; 耶利米书 31:33; 希伯来书 8:10"> 你们明显是基督的信，借着我们修成的。不是用墨写的，乃是用永生 神的灵写的；不是写在石版上，乃是写在心版上。</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比书 1:6; 以弗所书 3:12; 哥林多后书 2:14"> 我们因基督，所以在 神面前才有这样的信心。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 12:9; 腓立比书 4:13; 哥林多前书 15:10"> 并不是我们凭自己能承担什么事；我们所能承担的，乃是出于 神。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 6:63; 罗马书 7:6; 耶利米书 31:31"> 他叫我们能承当这新约的执事，不是凭着字句，乃是凭着精意；因为那字句是叫人死，精意<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：圣灵">a</a></sup>是叫人活。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 3:9–11; 罗马书 10:4; 出埃及记 31:18"> 那用字刻在石头上属死的职事尚且有荣光，甚至以色列人因摩西面上的荣光，不能定睛看他的脸；这荣光原是渐渐退去的，</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 3:16; 以弗所书 2:18; 加拉太书 3:14"> 何况那属灵的职事岂不更有荣光吗？</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 3:21–22; 希伯来书 12:18–21; 哥林多后书 5:21"> 若是定罪的职事有荣光，那称义的职事荣光就越发大了。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得后书 1:17; 哈该书 2:7–9; 使徒行传 26:13"> 那从前有荣光的，因这极大的荣光就算不得有荣光了；</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 5:20–21; 希伯来书 8:13; 希伯来书 7:21–25"> 若那废掉的有荣光，这长存的就更有荣光了。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 7:4; 使徒行传 4:13; 腓立比书 1:20"> 我们既有这样的盼望，就大胆讲说，</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 34:33–35; 希伯来书 10:1–9; 以弗所书 2:14–15"> 不像摩西将帕子蒙在脸上，叫以色列人不能定睛看到那将废者的结局。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 4:3–4; 使徒行传 26:18; 罗马书 11:25"> 但他们的心地刚硬，直到今日诵读旧约的时候，这帕子还没有揭去。这帕子在基督里已经废去了。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 13:27–29"> 然而直到今日，每逢诵读摩西书的时候，帕子还在他们心上。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 34:34; 以赛亚书 29:18; 以赛亚书 25:7"> 但他们的心几时归向主，帕子就几时除去了。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 8:2; 加拉太书 5:13; 约翰福音 8:32"> 主就是那灵；主的灵在哪里，那里就得以自由。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 4:6; 以弗所书 4:22–24; 罗马书 12:2"> 我们众人既然敞着脸得以看见主的荣光，好像从镜子里返照，就变成主的形状，荣上加荣，如同从主的灵变成的。</span>
</div>

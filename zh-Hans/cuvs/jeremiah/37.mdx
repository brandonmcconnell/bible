## 西底家求耶利米代祷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 22:24; 列王纪下 24:17; 列王纪下 24:12"> 约西亚的儿子西底家代替约雅敬的儿子哥尼雅为王，是巴比伦王尼布甲尼撒立在犹大地作王的。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 24:19–20; 箴言 29:12; 历代志下 36:12–16"> 但西底家和他的臣仆，并国中的百姓，都不听从耶和华借先知耶利米所说的话。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米书 21:1–2; 耶利米书 29:25; 耶利米书 42:20"> 西底家王打发示利米雅的儿子犹甲和祭司玛西雅的儿子西番雅去见先知耶利米，说：「求你为我们祷告耶和华—我们的 神。」</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 37:15; 耶利米书 32:2–3"> 那时耶利米在民中出入，因为他们还没有把他囚在监里。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 17:15; 耶利米书 37:11; 耶利米书 34:21"> 法老的军队已经从埃及出来，那围困耶路撒冷的迦勒底人听见他们的风声，就拔营离开耶路撒冷去了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 耶和华的话临到先知耶利米说：</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米哀歌 4:17; 列王纪下 22:18; 以西结书 17:17"> 「耶和华—以色列的 神如此说：犹大王打发你们来求问我，你们要如此对他说：『那出来帮助你们法老的军队必回埃及本国去。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 39:2–8; 耶利米书 38:23; 耶利米书 34:21–22"> 迦勒底人必再来攻打这城，并要攻取，用火焚烧。</span>
<span className="v" id="v9" data-v="9" data-xref="俄巴底亚书 1:3; 耶利米书 29:8; 加拉太书 6:3"> 耶和华如此说：你们不要自欺说「迦勒底人必定离开我们」，因为他们必不离开。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 50:45; 以赛亚书 30:17; 约珥书 2:11"> 你们即便杀败了与你们争战的迦勒底全军，但剩下受伤的人也必各人从帐棚里起来，用火焚烧这城。』」</span>
</div>
</div>

## 耶利米被捕入狱

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米书 37:5"> 迦勒底的军队因怕法老的军队，拔营离开耶路撒冷的时候，</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 1:1; 尼希米记 6:11; 列王纪上 19:3"> 耶利米就杂在民中出离耶路撒冷，要往便雅悯地去，在那里得自己的地业。</span>
<span className="v" id="v13" data-v="13" data-xref="撒迦利亚书 14:10; 耶利米书 38:7; 路加福音 23:2"> 他到了便雅悯门那里，有守门官名叫伊利雅，是哈拿尼亚的孙子、示利米雅的儿子，他就拿住先知耶利米，说：「你是投降迦勒底人哪！」</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 52:1–2; 耶利米书 40:4–6; 诗篇 27:12"> 耶利米说：「你这是谎话，我并不是投降迦勒底人。」伊利雅不听他的话，就拿住他，解到首领那里。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 38:26; 耶利米书 20:1–3; 耶利米书 26:16"> 首领恼怒耶利米，就打了他，将他囚在文士约拿单的房屋中，因为他们以这房屋当作监牢。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米书 38:6; 耶利米书 38:10–13; 耶利米哀歌 3:53"> 耶利米来到狱中，进入牢房，在那里囚了多日。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 21:7; 耶利米书 24:8; 列王纪上 14:1–4"> 西底家王打发人提出他来，在自己的宫内私下问他说：「从耶和华有什么话临到没有？」耶利米说：「有！」又说：「你必交在巴比伦王手中。」</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 25:8; 约翰福音 10:32; 但以理书 6:22"> 耶利米又对西底家王说：「我在什么事上得罪你，或你的臣仆，或这百姓，你竟将我囚在监里呢？</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 2:28; 耶利米书 28:10–17; 耶利米书 6:14"> 对你们预言巴比伦王必不来攻击你们和这地的先知，现今在哪里呢？</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 36:7; 耶利米书 38:6–9; 使徒行传 28:18–19"> 主—我的王啊，求你现在垂听，准我在你面前的恳求：不要使我回到文士约拿单的房屋中，免得我死在那里。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="耶利米书 38:13; 耶利米书 38:28; 耶利米书 38:9"> 于是，西底家王下令，他们就把耶利米交在护卫兵的院中，每天从饼铺街取一个饼给他，直到城中的饼用尽了。这样，耶利米仍在护卫兵的院中。</span>
</div>
</div>

</div>

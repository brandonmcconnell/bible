## 耶利米在圣殿讲道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话临到耶利米说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 26:2; 启示录 3:22; 阿摩司书 7:16"> 「你当站在耶和华殿的门口，在那里宣传这话说：你们进这些门敬拜耶和华的一切犹大人，当听耶和华的话。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 18:11; 耶利米书 26:13; 以赛亚书 1:16–19"> 万军之耶和华—以色列的 神如此说：你们改正行动作为，我就使你们在这地方仍然居住。</span>
<span className="v" id="v4" data-v="4" data-xref="弥迦书 3:11; 马太福音 3:9–10; 西番雅书 3:11"> 你们不要倚靠虚谎的话，说：『这些是耶和华的殿，是耶和华的殿，是耶和华的殿！』</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪上 6:12–13; 以赛亚书 1:19; 耶利米书 7:3"> 「你们若实在改正行动作为，在人和邻舍中间诚然施行公平，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 22:21–24; 撒迦利亚书 7:9–12; 耶利米书 13:10"> 不欺压寄居的和孤儿寡妇，在这地方不流无辜人的血，也不随从别神陷害自己，</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 4:40; 耶利米书 25:5; 耶利米书 3:18"> 我就使你们在这地方仍然居住，就是我古时所赐给你们列祖的地，直到永远。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 28:15; 以西结书 13:6–16; 耶利米书 23:14–16"> 「看哪，你们倚靠虚谎无益的话。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 7:6; 出埃及记 20:3; 雅各书 4:1–4"> 你们偷盗，杀害，奸淫，起假誓，向巴力烧香，并随从素不认识的别神，</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 32:34; 以西结书 23:37; 以西结书 23:39"> 且来到这称为我名下的殿，在我面前敬拜；又说：『我们可以自由了。』你们这样的举动是要行那些可憎的事吗？</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:45–46; 以赛亚书 56:7; 马太福音 21:13"> 这称为我名下的殿在你们眼中岂可看为贼窝吗？我都看见了。这是耶和华说的。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 18:1; 耶利米书 26:6; 撒母耳记上 4:10–11"> 你们且往示罗去，就是我先前立为我名的居所，察看我因这百姓以色列的罪恶向那地所行的如何。」</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 65:12; 历代志下 36:15–16; 耶利米书 7:25"> 耶和华说：「现在因你们行了这一切的事，我也从早起来警戒你们，你们却不听从；呼唤你们，你们却不答应。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 78:60; 列王纪下 25:9; 耶利米书 7:4"> 所以我要向这称为我名下、你们所倚靠的殿，与我所赐给你们和你们列祖的地施行，照我从前向示罗所行的一样。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 15:1; 列王纪下 17:23; 耶利米书 52:3"> 我必将你们从我眼前赶出，正如赶出你们的众弟兄，就是以法莲的一切后裔。」</span>
</div>
</div>

## 人民违背命令

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="耶利米书 11:14; 耶利米书 14:11–12; 耶利米书 15:1"> 「所以，你不要为这百姓祈祷；不要为他们呼求祷告；也不要向我为他们祈求，因我不听允你。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 8:6–18; 以西结书 14:23; 耶利米书 6:27"> 他们在犹大城邑中和耶路撒冷街上所行的，你没有看见吗？</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 19:13; 耶利米书 44:17–19; 哥林多前书 10:22"> 孩子捡柴，父亲烧火，妇女抟面做饼，献给天后，又向别神浇奠祭，惹我发怒。」</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 20:11; 耶利米书 2:19; 但以理书 9:7–8"> 耶和华说：「他们岂是惹我发怒呢？不是自己惹祸，以致脸上惭愧吗？」</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 42:18; 耶利米哀歌 2:3–5; 以赛亚书 42:25"> 所以主耶和华如此说：「看哪，我必将我的怒气和忿怒倾在这地方的人和牲畜身上，并田野的树木和地里的出产上，必如火着起，不能熄灭。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="何西阿书 8:13; 耶利米书 6:20; 阿摩司书 5:21–23"> 万军之耶和华—以色列的 神如此说：「你们将燔祭加在平安祭上，吃肉吧！</span>
<span className="v" id="v22" data-v="22" data-xref="何西阿书 6:6; 撒母耳记上 15:22; 诗篇 51:16–17"> 因为我将你们列祖从埃及地领出来的那日，燔祭平安祭的事我并没有提说，也没有吩咐他们。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 15:26; 申命记 5:33; 出埃及记 19:5–6"> 我只吩咐他们这一件说：『你们当听从我的话，我就作你们的 神，你们也作我的子民。你们行我所吩咐的一切道，就可以得福。』</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 81:11–12; 耶利米书 8:5; 耶利米书 7:26"> 他们却不听从，不侧耳而听，竟随从自己的计谋和顽梗的恶心，向后不向前。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 36:15; 耶利米书 25:4; 尼希米记 9:26"> 自从你们列祖出埃及地的那日，直到今日，我差遣我的仆人众先知到你们那里去，每日从早起来差遣他们。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 16:12; 历代志下 30:8; 耶利米书 7:24"> 你们却不听从，不侧耳而听，竟硬着颈项行恶，比你们列祖更甚。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米书 26:2; 耶利米书 1:7; 以赛亚书 65:12"> 「你要将这一切的话告诉他们，他们却不听从；呼唤他们，他们却不答应。</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 59:14–15; 箴言 1:7; 以赛亚书 1:4–5"> 你要对他们说：这就是不听从耶和华—他们 神的话、不受教训的国民；从他们的口中，诚实灭绝了。」</span>
</div>
</div>

## 在欣嫩子谷的罪行

<div className="bt">
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="约伯记 1:20; 弥迦书 1:16; 耶利米书 6:30"> <span className="pl pl-1">耶路撒冷啊，要剪发抛弃，</span><br /><span className="pl pl-1">在净光的高处举哀；</span><br /><span className="pl pl-1">因为耶和华丢掉离弃了惹他忿怒的世代。</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米书 32:34; 以西结书 7:20; 但以理书 9:27"> 耶和华说：「犹大人行我眼中看为恶的事，将可憎之物设立在称为我名下的殿中，污秽这殿。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 23:10; 耶利米书 32:35; 利未记 18:21"> 他们在欣嫩子谷建筑陀斐特的邱坛，好在火中焚烧自己的儿女。这并不是我所吩咐的，也不是我心所起的意。」</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 19:11; 耶利米书 19:6; 列王纪下 23:10"> 耶和华说：「因此，日子将到，这地方不再称为陀斐特和欣嫩子谷，反倒称为杀戮谷。因为要在陀斐特葬埋尸首，甚至无处可葬；</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 12:9; 申命记 28:26; 启示录 19:17–18"> 并且这百姓的尸首必给空中的飞鸟和地上的野兽作食物，并无人哄赶。</span>
<span className="v" id="v34" data-v="34" data-xref="启示录 18:23; 何西阿书 2:11; 以西结书 26:13"> 那时，我必使犹大城邑中和耶路撒冷街上，欢喜和快乐的声音，新郎和新妇的声音，都止息了，因为地必成为荒场。」</span>
</div>
</div>

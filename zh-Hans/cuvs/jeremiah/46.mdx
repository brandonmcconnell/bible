## 埃及在迦基米施受挫

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 1:10; 撒迦利亚书 2:8; 耶利米书 4:7"> 耶和华论列国的话临到先知耶利米。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 23:29; 耶利米书 46:14; 耶利米书 25:19"> 论到关乎埃及王法老尼哥的军队：这军队安营在幼发拉底河边的迦基米施，是巴比伦王尼布甲尼撒在犹大王约西亚的儿子约雅敬第四年所打败的。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 21:5; 约珥书 3:9; 那鸿书 2:1"> <span className="pl pl-1">你们要预备大小盾牌，</span><br /><span className="pl pl-1">往前上阵。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以西结书 21:9–11; 耶利米书 51:3; 撒母耳记上 17:5"> <span className="pl pl-1">你们套上车，</span><br /><span className="pl pl-1">骑上马！</span><br /><span className="pl pl-1">顶盔站立，</span><br /><span className="pl pl-1">磨枪贯甲！</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 49:29; 耶利米书 6:25; 耶利米书 46:21"> <span className="pl pl-1">我为何看见他们惊惶转身退后呢？</span><br /><span className="pl pl-1">他们的勇士打败了，</span><br /><span className="pl pl-1">急忙逃跑，并不回头；</span><br /><span className="pl pl-1">惊吓四围都有！</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="但以理书 11:19; 耶利米书 46:12; 诗篇 27:2"> <span className="pl pl-1">不要容快跑的逃避；</span><br /><span className="pl pl-1">不要容勇士逃脱</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：快跑的不能逃避；勇士不能逃脱">a</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">他们在北方幼发拉底河边绊跌仆倒。</span></span>

<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="耶利米书 47:2; 以赛亚书 8:7–8; 但以理书 11:22"> <span className="pl pl-1">像尼罗河涨发，</span><br /><span className="pl pl-1">像江河之水翻腾的是谁呢？</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 10:13–16; 以西结书 32:2; 以赛亚书 37:24–26"> <span className="pl pl-1">埃及像尼罗河涨发，</span><br /><span className="pl pl-1">像江河的水翻腾。</span><br /><span className="pl pl-1">他说：我要涨发遮盖遍地；</span><br /><span className="pl pl-1">我要毁灭城邑和其中的居民。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 66:19; 以西结书 27:10; 那鸿书 3:9"> <span className="pl pl-1">马匹上去吧！</span><br /><span className="pl pl-1">车辆急行吧！</span><br /><span className="pl pl-1">勇士，就是手拿盾牌的古实人和弗人</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="又作利比亚人">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">并拉弓的路德族，都出去吧！</span><br /></span>

<span className="v" id="v11" data-v="11" data-xref="耶利米书 8:22; 弥迦书 1:9; 那鸿书 3:19"> <span className="pl pl-1">埃及的民</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是处女">c</a></sup><br /><span className="pl pl-1">哪，</span><br /><span className="pl pl-1">可以上基列取乳香去；</span><br /><span className="pl pl-1">你虽多服良药，</span><br /><span className="pl pl-1">总是徒然，不得治好。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="那鸿书 3:8–10; 以赛亚书 19:2; 耶利米书 46:6"> <span className="pl pl-1">列国听见你的羞辱，</span><br /><span className="pl pl-1">遍地满了你的哀声；</span><br /><span className="pl pl-1">勇士与勇士彼此相碰，</span><br /><span className="pl pl-1">一齐跌倒。</span></span>
</div>
</div>

## 尼布甲尼撒来犯

<div className="bt">
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="耶利米书 44:30; 耶利米书 43:10–13; 以赛亚书 19:1–25"> 耶和华对先知耶利米所说的话，论到巴比伦王尼布甲尼撒要来攻击埃及地：</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 46:10; 耶利米书 44:1; 耶利米书 46:3–4"> <span className="pl pl-1">你们要传扬在埃及，宣告在密夺，</span><br /><span className="pl pl-1">报告在挪弗、答比匿说：</span><br /><span className="pl pl-1">要站起出队，自作准备，</span><br /><span className="pl pl-1">因为刀剑在你四围施行吞灭的事。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 66:15–16; 诗篇 68:2; 诗篇 18:39"> <span className="pl pl-1">你的壮士为何被冲去呢？</span><br /><span className="pl pl-1">他们站立不住；</span><br /><span className="pl pl-1">因为耶和华驱逐他们，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="利未记 26:36–37; 耶利米书 51:9; 耶利米书 46:6"> <span className="pl pl-1">使多人绊跌；</span><br /><span className="pl pl-1">他们也彼此撞倒，说：</span><br /><span className="pl pl-1">起来吧！我们再往本民本地去，</span><br /><span className="pl pl-1">好躲避欺压的刀剑。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 19:11–16; 出埃及记 15:9; 列王纪上 20:10"> <span className="pl pl-1">他们在那里喊叫说：</span><br /><span className="pl pl-1">埃及王法老不过是个声音</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或译：已经败亡">d</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">他已错过所定的时候了。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="耶利米书 48:15; 士师记 4:6; 约书亚记 19:22"> <span className="pl pl-1">君王—名为万军之耶和华的说：</span><br /><span className="pl pl-1">我指着我的永生起誓：</span><br /><span className="pl pl-1">尼布甲尼撒</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原文是他">e</a></sup><br /><span className="pl pl-1">来的势派</span><br /><span className="pl pl-1">必像他泊在众山之中，</span><br /><span className="pl pl-1">像迦密在海边一样。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 20:4; 耶利米书 48:18; 以西结书 30:13"> <span className="pl pl-1">住在埃及的民哪</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="原文是女子">f</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">要预备掳去时所用的物件；</span><br /><span className="pl pl-1">因为挪弗必成为荒场，</span><br /><span className="pl pl-1">且被烧毁，无人居住。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="何西阿书 10:11; 耶利米书 47:2; 耶利米书 1:14"> <span className="pl pl-1">埃及是肥美的母牛犊；</span><br /><span className="pl pl-1">但出于北方的毁灭</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="或译：牛虻">g</a></sup><br /><span className="pl pl-1">来到了！来到了！</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 46:5; 俄巴底亚书 1:13; 列王纪下 7:6"> <span className="pl pl-1">其中的雇勇好像圈里的肥牛犊，</span><br /><span className="pl pl-1">他们转身退后，</span><br /><span className="pl pl-1">一齐逃跑，站立不住；</span><br /><span className="pl pl-1">因为他们遭难的日子、</span><br /><span className="pl pl-1">追讨的时候已经临到。</span></span>

<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 14:8; 以赛亚书 29:4; 弥迦书 1:8"> <span className="pl pl-1">其中的声音好像蛇行一样。</span><br /><span className="pl pl-1">敌人要成队而来，如砍伐树木的手拿斧子攻击他。</span><br /></span>

<span className="v" id="v24" data-v="24" data-xref="耶利米书 1:15; 以西结书 29:1–21; 耶利米书 46:11"> <span className="pl pl-1">埃及的民</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="原文是女子">i</a></sup><br /><span className="pl pl-1">必然蒙羞，</span><br /><span className="pl pl-1">必交在北方人的手中。</span></span>
<span className="v" id="v25" data-v="25" data-xref="西番雅书 2:11; 耶利米书 43:12–13; 以赛亚书 20:5–6"> 万军之耶和华—以色列的 神说：「我必刑罚挪的亚扪<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="埃及尊大之神">j</a></sup>和法老，并埃及与埃及的神，以及君王，也必刑罚法老和倚靠他的人。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结书 32:11; 耶利米书 44:30; 以西结书 29:8–14"> 我要将他们交付寻索其命之人的手和巴比伦王尼布甲尼撒与他臣仆的手；以后埃及必再有人居住，与从前一样。这是耶和华说的。」</span>
</div>

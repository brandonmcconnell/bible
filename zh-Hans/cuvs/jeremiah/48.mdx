## 摩押的毁灭

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="民数记 32:3; 民数记 32:37–38; 耶利米书 48:22–23"> 论摩押。万军之耶和华—以色列的 神如此说：<br /><span className="pl pl-1">尼波有祸了！因变为荒场。</span><br /><span className="pl pl-1">基列亭蒙羞被攻取；</span><br /><span className="pl pl-1">米斯迦蒙羞被毁坏；</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="民数记 32:37; 耶利米书 31:36; 以赛亚书 16:14"> <span className="pl pl-1">摩押不再被称赞。</span><br /><span className="pl pl-1">有人在希实本设计谋害她，说：</span><br /><span className="pl pl-1">来吧！我们将她剪除，不再成国。</span><br /><span className="pl pl-1">玛得缅哪，你也必默默无声；</span><br /><span className="pl pl-1">刀剑必追赶你。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 15:5; 耶利米书 48:34; 耶利米书 48:5"> <span className="pl pl-1">从何罗念有喊荒凉大毁灭的哀声：</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 137:9; 民数记 21:27–30; 以斯帖记 8:11"> <span className="pl pl-1">摩押毁灭了！</span><br /><span className="pl pl-1">她的孩童</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：家僮">a</a></sup><br /><span className="pl pl-1">发哀声，使人听见。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 15:5"> <span className="pl pl-1">人上鲁希坡随走随哭，</span><br /><span className="pl pl-1">因为在何罗念的下坡听见毁灭的哀声。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 17:6; 耶利米书 51:6; 约伯记 30:3–7"> <span className="pl pl-1">你们要奔逃，自救性命，</span><br /><span className="pl pl-1">独自居住，好像旷野的杜松。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="民数记 21:29; 耶利米书 9:23; 诗篇 52:7"> <span className="pl pl-1">你因倚靠自己所做的和自己的财宝必被攻取。</span><br /><span className="pl pl-1">基抹和属他的祭司、首领也要一同被掳去。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 6:26; 耶利米书 51:56; 耶利米书 25:9"> <span className="pl pl-1">行毁灭的必来到各城，</span><br /><span className="pl pl-1">并无一城得免。</span><br /><span className="pl pl-1">山谷必致败落，</span><br /><span className="pl pl-1">平原必被毁坏；</span><br /><span className="pl pl-1">正如耶和华所说的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="诗篇 11:1; 耶利米书 48:28; 以赛亚书 16:2"> <span className="pl pl-1">要将翅膀给摩押，</span><br /><span className="pl pl-1">使她可以飞去。</span><br /><span className="pl pl-1">她的城邑必致荒凉，</span><br /><span className="pl pl-1">无人居住。</span><br />（</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 15:3; 列王纪上 20:42; 士师记 5:23"> 懒惰为耶和华行事的，必受咒诅；禁止刀剑不经血的，必受咒诅。）</span>
</div>
</div>

## 摩押的城镇被毁灭

<div className="bt">
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="西番雅书 1:12; 撒迦利亚书 1:15; 耶利米书 48:29"> <span className="pl pl-1">摩押自幼年以来常享安逸，</span><br /><span className="pl pl-1">如酒在渣滓上澄清，</span><br /><span className="pl pl-1">没有从这器皿倒在那器皿里，</span><br /><span className="pl pl-1">也未曾被掳去。</span><br /><span className="pl pl-1">因此，它的原味尚存，</span><br /><span className="pl pl-1">香气未变。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="那鸿书 2:2; 以赛亚书 30:14; 以西结书 25:9–10"> 耶和华说：「日子将到，我必打发倒酒的往她那里去，将她倒出来，倒空她的器皿，打碎她的坛子。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 45:16; 士师记 11:24; 耶利米书 48:39"> 摩押必因基抹羞愧，像以色列家从前倚靠伯特利的神羞愧一样。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 33:16; 以赛亚书 10:13; 以赛亚书 10:16"> <span className="pl pl-1">你们怎么说：</span><br /><span className="pl pl-1">我们是勇士，是有勇力打仗的呢？</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 50:27; 耶利米书 46:18; 耶利米书 51:57"> <span className="pl pl-1">摩押变为荒场，</span><br /><span className="pl pl-1">敌人上去进了她的城邑。</span><br /><span className="pl pl-1">她所特选的少年人下去遭了杀戮；</span><br /><span className="pl pl-1">这是君王—名为万军之耶和华说的。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 13:22; 耶利米书 1:12; 以西结书 12:28"> <span className="pl pl-1">摩押的灾殃临近；</span><br /><span className="pl pl-1">她的苦难速速来到。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 9:4; 以赛亚书 14:4–5; 以西结书 19:11–14"> <span className="pl pl-1">凡在她四围的和认识她名的，</span><br /><span className="pl pl-1">你们都要为她悲伤，说：</span><br /><span className="pl pl-1">那结实的杖和那美好的棍，</span><br /><span className="pl pl-1">何竟折断了呢？</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="民数记 21:30; 以赛亚书 47:1; 以赛亚书 15:2"> <span className="pl pl-1">住在底本的民哪</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是女子">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">要从你荣耀的位上下来，</span><br /><span className="pl pl-1">坐受干渴；</span><br /><span className="pl pl-1">因毁灭摩押的上来攻击你，</span><br /><span className="pl pl-1">毁坏了你的保障。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="申命记 2:36; 撒母耳记上 4:16; 撒母耳记上 4:13–14"> <span className="pl pl-1">住亚罗珥的啊，</span><br /><span className="pl pl-1">要站在道旁观望，</span><br /><span className="pl pl-1">问逃避的男人和逃脱的女人说：</span><br /><span className="pl pl-1">是什么事呢？</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 16:2; 民数记 21:26–28; 申命记 2:36"> <span className="pl pl-1">摩押因毁坏蒙羞；</span><br /><span className="pl pl-1">你们要哀号呼喊，</span><br /><span className="pl pl-1">要在亚嫩旁报告说：</span><br /><span className="pl pl-1">摩押变为荒场！</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约书亚记 13:18; 以赛亚书 15:4; 耶利米书 48:8"> 「刑罚临到平原之地的何伦、雅杂、米法押、</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 48:18; 民数记 33:46; 民数记 32:34"> 底本、尼波、伯·低比拉太音、</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 13:17; 耶利米书 48:1; 民数记 32:38"> 基列亭、伯·迦末、伯·米恩、</span>
<span className="v" id="v24" data-v="24" data-xref="阿摩司书 2:2; 耶利米书 48:41; 约书亚记 21:36"> 加略、波斯拉，和摩押地远近所有的城邑。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 75:10; 诗篇 10:15; 撒迦利亚书 1:19–21"> 摩押的角砍断了，摩押的膀臂折断了。这是耶和华说的。」</span>
</div>
</div>

## 摩押要受凌辱

<div className="bt">
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="耶利米书 48:42; 以赛亚书 29:9; 耶利米书 51:39"> 「你们要使摩押沉醉，因她向耶和华夸大。她要在自己所吐之中打滚，又要被人嗤笑。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 2:26; 弥迦书 7:8–10; 西番雅书 2:8"> 摩押啊，你不曾嗤笑以色列吗？她岂是在贼中查出来的呢？你每逢提到她便摇头。</span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 55:6–7; 士师记 6:2; 雅歌 2:14"> <span className="pl pl-1">摩押的居民哪，</span><br /><span className="pl pl-1">要离开城邑，住在山崖里，</span><br /><span className="pl pl-1">像鸽子在深渊口上搭窝。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 16:6; 诗篇 138:6; 以赛亚书 2:11–12"> <span className="pl pl-1">我们听说摩押人骄傲，</span><br /><span className="pl pl-1">是极其骄傲；</span><br /><span className="pl pl-1">听说他自高自傲，</span><br /><span className="pl pl-1">并且狂妄，居心自大。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 50:36; 以赛亚书 16:6; 以赛亚书 37:28–29"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">我知道他的忿怒是虚空的；</span><br /><span className="pl pl-1">他夸大的话一无所成。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 15:5; 列王纪下 3:25; 耶利米书 48:36"> <span className="pl pl-1">因此，我要为摩押哀号，</span><br /><span className="pl pl-1">为摩押全地呼喊；</span><br /><span className="pl pl-1">人必为吉珥·哈列设人叹息。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 16:8–9; 民数记 21:32; 约书亚记 13:19"> <span className="pl pl-1">西比玛的葡萄树啊，我为你哀哭，</span><br /><span className="pl pl-1">甚于雅谢人哀哭。</span><br /><span className="pl pl-1">你的枝子蔓延过海，</span><br /><span className="pl pl-1">直长到雅谢海。</span><br /><span className="pl pl-1">那行毁灭的已经临到你夏天的果子</span><br /><span className="pl pl-1">和你所摘的葡萄。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 5:10; 哈该书 2:16; 耶利米书 25:9–10"> <span className="pl pl-1">肥田和摩押地的欢喜快乐都被夺去；</span><br /><span className="pl pl-1">我使酒榨的酒绝流，</span><br /><span className="pl pl-1">无人踹酒欢呼；</span><br /><span className="pl pl-1">那欢呼却变为仇敌的呐喊</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是那欢呼却不是欢呼">c</a></sup><br /><span className="pl pl-1">。</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="以赛亚书 15:4–6; 民数记 32:3; 申命记 34:3"> 「希实本人发的哀声达到以利亚利，直达到雅杂；从琐珥达到何罗念，直到伊基拉·施利施亚，因为宁林的水必然干涸。」</span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 15:2; 以赛亚书 16:12; 民数记 28:14"> 耶和华说：「我必在摩押地使那在邱坛献祭的，和那向他的神烧香的都断绝了。</span>
<span className="v" id="v36" data-v="36" data-xref="以赛亚书 15:7; 以赛亚书 16:11; 以赛亚书 15:5"> 我心腹为摩押哀鸣如箫，我心肠为吉珥·哈列设人也是如此，因摩押人所得的财物都灭没了。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="耶利米书 41:5; 创世记 37:34; 耶利米书 47:5"> 「各人头上光秃，胡须剪短，手有划伤，腰束麻布。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米书 22:28; 耶利米书 25:34; 以赛亚书 22:1"> 在摩押的各房顶上和街市上处处有人哀哭；因我打碎摩押，好像打碎无人喜悦的器皿。这是耶和华说的。</span>
<span className="v" id="v39" data-v="39" data-xref="以赛亚书 20:4–6; 耶利米哀歌 4:1; 耶利米哀歌 2:1"> 摩押何等毁坏！何等哀号！何等羞愧转背！这样，摩押必令四围的人嗤笑惊骇。」</span>
</div>

## 摩押无路可逃

<div className="bt">
<div className="bp poetry">
<span className="v" id="v40" data-v="40" data-xref="以赛亚书 8:8; 申命记 28:49; 耶利米书 49:22"> <span className="pl pl-1">耶和华如此说：</span><br /><span className="pl pl-1">仇敌必如大鹰飞起，</span><br /><span className="pl pl-1">展开翅膀，攻击摩押。</span><br /></span>
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 21:3; 以赛亚书 13:8; 弥迦书 4:9–10"> <span className="pl pl-1">加略被攻取，保障也被占据。</span><br /><span className="pl pl-1">到那日，摩押的勇士心中疼痛如临产的妇人。</span><br /></span>
<span className="v" id="v42" data-v="42" data-xref="耶利米书 48:2; 以赛亚书 7:8; 以赛亚书 37:23"> <span className="pl pl-1">摩押必被毁灭，不再成国，</span><br /><span className="pl pl-1">因她向耶和华夸大。</span><br /></span>
<span className="v" id="v43" data-v="43" data-xref="耶利米哀歌 3:47; 以赛亚书 24:17–18; 申命记 32:23–25"> <span className="pl pl-1">耶和华说：摩押的居民哪，</span><br /><span className="pl pl-1">恐惧、陷坑、网罗都临近你。</span><br /></span>

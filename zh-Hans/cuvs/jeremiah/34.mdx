## 给西底家的信息

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 1:15; 但以理书 2:37–38; 列王纪下 25:1–9"> 巴比伦王尼布甲尼撒率领他的全军和地上属他的各国各邦，攻打耶路撒冷和属耶路撒冷所有的城邑。那时，耶和华的话临到耶利米说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 21:10; 耶利米书 34:22; 耶利米书 37:8–10"> 「耶和华—以色列的 神说，你去告诉犹大王西底家，耶和华如此说：我要将这城交付巴比伦王的手，他必用火焚烧。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 32:4; 耶利米书 21:7; 列王纪下 25:4–7"> 你必不能逃脱他的手，定被拿住，交在他的手中。你的眼要见巴比伦王的眼，他要口对口和你说话，你也必到巴比伦去。</span>
<span className="v" id="v4" data-v="4"> 犹大王西底家啊，你还要听耶和华的话。耶和华论到你如此说：你必不被刀剑杀死，</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 22:18; 历代志下 16:14; 列王纪下 22:20"> 你必平安而死，人必为你焚烧物件，好像为你列祖，就是在你以前的先王焚烧一般。人必为你举哀说：『哀哉！我主啊。』耶和华说：这话是我说的。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 15:16–24; 撒母耳记上 3:18; 列王纪上 21:19"> 于是，先知耶利米在耶路撒冷将这一切话告诉犹大王西底家。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 10:3; 耶利米书 4:5; 列王纪下 18:13–14"> 那时，巴比伦王的军队正攻打耶路撒冷，又攻打犹大所剩下的城邑，就是拉吉和亚西加。原来犹大的坚固城只剩下这两座。</span>
</div>
</div>

## 违背释放奴隶的约

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未记 25:10; 列王纪下 23:2–3; 列王纪下 11:17"> 西底家王与耶路撒冷的众民立约，要向他们宣告自由，叫各人任他希伯来的仆人和婢女自由出去，谁也不可使他的一个犹大弟兄作奴仆。（此后，有耶和华的话临到耶利米。）</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 26:16; 耶利米书 26:10; 耶利米书 38:4"> 所有立约的首领和众民就任他的仆人婢女自由出去，谁也不再叫他们作奴仆。大家都顺从，将他们释放了；</span>
<span className="v" id="v11" data-v="11" data-xref="彼得后书 2:20–22; 箴言 26:11; 马太福音 12:43–45"> 后来却又反悔，叫所任去自由的仆人婢女回来，勉强他们仍为仆婢。</span>
<span className="v" id="v12" data-v="12"> 因此耶和华的话临到耶利米说：</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 6:8; 约书亚记 24:17; 申命记 5:27"> 「耶和华—以色列的 神如此说：我将你们的列祖从埃及地为奴之家领出来的时候，与他们立约说：</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 15:12; 列王纪上 9:22; 列王纪下 17:13–14"> 『你的一个希伯来弟兄若卖给你，服事你六年，到第七年你们各人就要任他自由出去。』只是你们列祖不听从我，也不侧耳而听。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 34:8; 列王纪下 23:3; 尼希米记 10:29"> 如今你们回转，行我眼中看为正的事，各人向邻舍宣告自由，并且在称为我名下的殿中、在我面前立约。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 19:12; 出埃及记 20:7; 耶利米书 34:11"> 你们却又反悔，亵渎我的名，各人叫所任去随意自由的仆人婢女回来，勉强他们仍为仆婢。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 7:2; 申命记 28:25; 加拉太书 6:7"> 所以耶和华如此说：你们没有听从我，各人向弟兄邻舍宣告自由。看哪！我向你们宣告一样自由，就是使你们自由于刀剑、饥荒、瘟疫之下，并且使你们在天下万国中抛来抛去。这是耶和华说的。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 15:10; 创世记 15:17–18; 何西阿书 6:7"> 犹大的首领、耶路撒冷的首领、太监、祭司，和国中的众民曾将牛犊劈开，分成两半，从其中经过，在我面前立约。后来又违背我的约，不遵行这约上的话。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 7:33; 耶利米书 16:4; 耶利米书 19:7"> 我必将他们交在仇敌和寻索其命的人手中；他们的尸首必给空中的飞鸟和地上的野兽作食物。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 52:24–27; 耶利米书 39:6; 耶利米书 52:10"> 并且我必将犹大王西底家和他的首领交在他们仇敌和寻索其命的人，与那暂离你们而去巴比伦王军队的手中。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 9:11; 耶利米书 39:8; 耶利米书 39:1–2"> 耶和华说：我必吩咐他们回到这城，攻打这城，将城攻取，用火焚烧。我也要使犹大的城邑变为荒场，无人居住。」</span>
</div>
</div>

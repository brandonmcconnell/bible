## 耶利米和约

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话临到耶利米说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 11:6; 出埃及记 19:5; 历代志下 29:10"> 「当听这约的话，告诉犹大人和耶路撒冷的居民，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 27:26; 申命记 28:15–68; 申命记 29:19–20"> 对他们说，耶和华—以色列的 神如此说：不听从这约之话的人必受咒诅。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 26:12; 耶利米书 7:22–23; 申命记 4:20"> 这约是我将你们列祖从埃及地领出来、脱离铁炉的那日所吩咐他们的，说：『你们要听从我的话，照我一切所吩咐的去行。』这样，你们就作我的子民，我也作你们的 神；</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 7:12–13; 诗篇 105:9–11; 耶利米书 28:6"> 我好坚定向你们列祖所起的誓，给他们流奶与蜜之地，正如今日一样。」我就回答说：「耶和华啊，阿们！」</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 1:22; 罗马书 2:13; 耶利米书 7:2"> 耶和华对我说：「你要在犹大城邑中和耶路撒冷街市上，宣告这一切话说：你们当听从遵行这约的话。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 36:15; 以弗所书 4:17; 撒母耳记上 8:9"> 因为我将你们列祖从埃及地领出来的那日，直到今日，都是从早起来，切切告诫他们说：『你们当听从我的话。』</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 7:24; 耶利米书 7:26; 耶利米书 35:15"> 他们却不听从，不侧耳而听，竟随从自己顽梗的恶心去行。所以我使这约中一切咒诅的话临到他们身上；这约是我吩咐他们行的，他们却不去行。」</span>
<span className="v" id="v9" data-v="9" data-xref="何西阿书 6:9; 马太福音 26:3–4; 弥迦书 3:11"> 耶和华对我说：「在犹大人和耶路撒冷居民中有同谋背叛的事。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 31:16; 以西结书 16:59; 诗篇 78:8–10"> 他们转去效法他们的先祖，不肯听我的话，犯罪作孽，又随从别神，事奉它。以色列家和犹大家背了我与他们列祖所立的约。」</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 8:18; 箴言 1:28; 以赛亚书 1:15"> 所以耶和华如此说：「我必使灾祸临到他们，是他们不能逃脱的。他们必向我哀求，我却不听。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 2:28; 申命记 32:37; 历代志下 28:22"> 那时，犹大城邑的人和耶路撒冷的居民要去哀求他们烧香所供奉的神；只是遭难的时候，这些神毫不拯救他们。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 2:28; 列王纪下 23:13; 以赛亚书 2:8"> 犹大啊，你神的数目与你城的数目相等；你为那可耻的巴力所筑烧香的坛也与耶路撒冷街道的数目相等。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 7:16; 耶利米书 11:11; 约翰一书 5:16"> 「所以你不要为这百姓祈祷，不要为他们呼求祷告；因为他们遭难向我哀求的时候，我必不应允。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 2:14; 提多书 1:15; 耶利米书 3:1–2"> 我所亲爱的，既行许多淫乱，圣肉也离了你，你在我殿中做什么呢？你作恶就喜乐。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 11:17–24; 以赛亚书 27:11; 诗篇 52:8"> 从前耶和华给你起名叫青橄榄树，又华美又结好果子；如今他用哄嚷之声，点火在其上，枝子也被折断。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 5:2; 耶利米书 2:21; 耶利米书 12:2"> 原来栽培你的万军之耶和华已经说，要降祸攻击你，是因以色列家和犹大家行恶，向巴力烧香，惹我发怒，是自作自受。」</span>
</div>
</div>

## 杀害耶利米的阴谋

<div className="bt">
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 23:11–12; 列王纪下 6:9–10; 以西结书 8:6–18"> <span className="pl pl-1">耶和华指示我，我就知道；</span><br /><span className="pl pl-1">你将他们所行的给我指明。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 53:7–8; 耶利米书 20:10; 诗篇 83:4"> <span className="pl pl-1">我却像柔顺的羊羔被牵到宰杀之地；</span><br /><span className="pl pl-1">我并不知道他们设计谋害我，</span><br /><span className="pl pl-1">说：我们把树连果子都灭了吧！</span><br /><span className="pl pl-1">将他从活人之地剪除，</span><br /><span className="pl pl-1">使他的名不再被纪念。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 20:12; 耶利米书 17:10; 撒母耳记上 16:7"> <span className="pl pl-1">按公义判断、察验人肺腑心肠的万军之耶和华啊，</span><br /><span className="pl pl-1">我却要见你在他们身上报仇，</span><br /><span className="pl pl-1">因我将我的案件向你禀明了。</span></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 20:10; 阿摩司书 2:12; 路加福音 13:33–34"> 所以，耶和华论到寻索你命的亚拿突人如此说：「他们说：你不要奉耶和华的名说预言，免得你死在我们手中。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 18:21; 历代志下 36:17; 耶利米书 9:21"> 所以万军之耶和华如此说：看哪，我必刑罚他们；他们的少年人必被刀剑杀死，他们的儿女必因饥荒灭亡，</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 23:12; 弥迦书 7:4; 何西阿书 9:7"> 并且没有余剩的人留给他们；因为在追讨之年，我必使灾祸临到亚拿突人。」</span>
</div>

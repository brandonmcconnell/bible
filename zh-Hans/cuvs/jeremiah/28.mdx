## 耶利米和先知哈拿尼雅

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 27:1; 约书亚记 9:3; 以赛亚书 9:15"> 当年，就是犹大王西底家登基第四年五月，基遍人押朔的儿子，先知哈拿尼雅，在耶和华的殿中当着祭司和众民对我说：</span>
<span className="v" id="v2" data-v="2" data-xref="弥迦书 3:11; 以西结书 13:5–16; 耶利米书 27:2–12"> 「万军之耶和华—以色列的 神如此说：我已经折断巴比伦王的轭。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 24:13; 历代志下 36:10; 但以理书 1:2"> 二年之内，我要将巴比伦王尼布甲尼撒从这地掠到巴比伦的器皿，就是耶和华殿中的一切器皿都带回此地。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 22:24; 列王纪下 25:27–30; 耶利米书 28:2"> 我又要将犹大王约雅敬的儿子耶哥尼雅和被掳到巴比伦去的一切犹大人带回此地，因为我要折断巴比伦王的轭。这是耶和华说的。」</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 28:1; 耶利米书 26:2; 耶利米书 19:14"> 先知耶利米当着祭司和站在耶和华殿里的众民对先知哈拿尼雅说：</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 41:13; 列王纪上 1:36; 耶利米书 11:5"> 「阿们！愿耶和华如此行，愿耶和华成就你所预言的话，将耶和华殿中的器皿和一切被掳去的人从巴比伦带回此地。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 22:28"> 然而我向你和众民耳中所要说的话，你应当听。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 4:26–27; 列王纪上 17:1; 列王纪上 22:8"> 从古以来，在你我以前的先知，向多国和大邦说预言，论到争战、灾祸、瘟疫的事。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 18:22; 耶利米书 6:14; 耶利米书 4:10"> 先知预言的平安，到话语成就的时候，人便知道他真是耶和华所差来的。」</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 27:2; 耶利米书 28:4; 玛拉基书 3:13"> 于是，先知哈拿尼雅将先知耶利米颈项上的轭取下来，折断了。</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 14:7; 历代志下 18:22–23; 耶利米书 27:2–12"> 哈拿尼雅又当着众民说：「耶和华如此说：二年之内我必照样从列国人的颈项上折断巴比伦王尼布甲尼撒的轭。」于是先知耶利米就走了。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 1:2; 但以理书 9:2; 列王纪下 20:4"> 先知哈拿尼雅把先知耶利米颈项上的轭折断以后，耶和华的话临到耶利米说：</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 149:8; 耶利米书 27:15; 耶利米哀歌 2:14"> 「你去告诉哈拿尼雅说，耶和华如此说：你折断木轭，却换了铁轭！</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 28:48; 耶利米书 27:6–7; 但以理书 2:38"> 因为万军之耶和华—以色列的 神如此说：我已将铁轭加在这些国的颈项上，使他们服事巴比伦王尼布甲尼撒，他们总要服事他；我也把田野的走兽给了他。」</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 14:14–15; 耶利米书 27:15; 耶利米书 23:21"> 于是先知耶利米对先知哈拿尼雅说：「哈拿尼雅啊，你应当听！耶和华并没有差遣你，你竟使这百姓倚靠谎言。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 29:32; 创世记 7:4; 出埃及记 32:12"> 所以耶和华如此说：看哪，我要叫你去世，你今年必死，因为你向耶和华说了叛逆的话。」</span>
<span className="v" id="v17" data-v="17" data-xref="撒迦利亚书 1:6; 以赛亚书 44:25–26"> 这样，先知哈拿尼雅当年七月间就死了。</span>

## 耶和华审判亚扪

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="阿摩司书 1:13–15; 西番雅书 2:8–11; 以西结书 25:2–10"> 论亚扪人。耶和华如此说：<br /><span className="pl pl-1">以色列没有儿子吗？</span><br /><span className="pl pl-1">没有后嗣吗？</span><br /><span className="pl pl-1">玛勒堪为何得迦得之地为业呢？</span><br /><span className="pl pl-1">属他的民为何住其中的城邑呢？</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 4:19; 以西结书 21:20; 申命记 3:11"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">日子将到，我必使人听见打仗的喊声，</span><br /><span className="pl pl-1">是攻击亚扪人拉巴的喊声。</span><br /><span className="pl pl-1">拉巴要成为乱堆；</span><br /><span className="pl pl-1">属她的乡村</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是女子">a</a></sup><br /><span className="pl pl-1">要被火焚烧。</span><br /><span className="pl pl-1">先前得以色列地为业的，</span><br /><span className="pl pl-1">此时以色列倒要得他们的地为业。</span><br /><span className="pl pl-1">这是耶和华说的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="耶利米书 48:7; 耶利米书 48:37; 以赛亚书 15:2"> <span className="pl pl-1">希实本哪，你要哀号，</span><br /><span className="pl pl-1">因为爱地变为荒场。</span><br /><span className="pl pl-1">拉巴的居民</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是女子">b</a></sup><br /><span className="pl pl-1">哪，要呼喊，</span><br /><span className="pl pl-1">以麻布束腰；</span><br /><span className="pl pl-1">要哭号，在篱笆中跑来跑去；</span><br /><span className="pl pl-1">因玛勒堪和属他的祭司、</span><br /><span className="pl pl-1">首领要一同被掳去。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="提摩太前书 6:17; 耶利米书 9:23; 耶利米书 21:13"> <span className="pl pl-1">背道的民</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是女子">c</a></sup><br /><span className="pl pl-1">哪，</span><br /><span className="pl pl-1">你们为何因有山谷，</span><br /><span className="pl pl-1">就是水流的山谷夸张呢？</span><br /><span className="pl pl-1">为何倚靠财宝说：</span><br /><span className="pl pl-1">谁能来到我们这里呢？</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 46:5; 耶利米书 49:29; 耶利米书 15:8"> <span className="pl pl-1">主—万军之耶和华说：</span><br /><span className="pl pl-1">我要使恐吓从四围的人中临到你们；</span><br /><span className="pl pl-1">你们必被赶出，</span><br /><span className="pl pl-1">各人一直前往，</span><br /><span className="pl pl-1">没有人收聚逃民。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 49:39; 耶利米书 48:47; 以西结书 16:53"> <span className="pl pl-1">后来我还要使被掳的亚扪人归回。</span><br /><span className="pl pl-1">这是耶和华说的。</span></span>
</div>
</div>

## 耶和华审判以东

<div className="bt">
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="阿摩司书 1:11–12; 耶利米书 25:21; 创世记 36:15"> 论以东。万军之耶和华如此说：<br /><span className="pl pl-1">提幔中再没有智慧吗？</span><br /><span className="pl pl-1">明哲人不再有谋略吗？</span><br /><span className="pl pl-1">他们的智慧尽归无有吗？</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 25:23; 耶利米书 46:21; 耶利米书 49:30"> <span className="pl pl-1">底但的居民哪，要转身逃跑，</span><br /><span className="pl pl-1">住在深密处；</span><br /><span className="pl pl-1">因为我向以扫追讨的时候，</span><br /><span className="pl pl-1">必使灾殃临到他。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="俄巴底亚书 1:5–6; 以赛亚书 17:6"> <span className="pl pl-1">摘葡萄的若来到他那里，</span><br /><span className="pl pl-1">岂不剩下些葡萄呢？</span><br /><span className="pl pl-1">盗贼若夜间而来，</span><br /><span className="pl pl-1">岂不毁坏直到够了呢？</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 17:14; 玛拉基书 1:3–4; 以赛亚书 45:3"> <span className="pl pl-1">我却使以扫赤露，</span><br /><span className="pl pl-1">显出他的隐密处；</span><br /><span className="pl pl-1">他不能自藏。</span><br /><span className="pl pl-1">他的后裔、弟兄、邻舍尽都灭绝；</span><br /><span className="pl pl-1">他也归于无有。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 68:5; 何西阿书 14:3; 雅各书 1:27"> <span className="pl pl-1">你撇下孤儿，我必保全他们的命；</span><br /><span className="pl pl-1">你的寡妇可以倚靠我。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="耶利米书 25:28–29; 俄巴底亚书 1:16; 耶利米书 25:15"> 耶和华如此说：「原不该喝那杯的一定要喝。你能尽免刑罚吗？你必不能免，一定要喝！」</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 22:16; 以赛亚书 34:6; 创世记 36:33"> 耶和华说：「我指着自己起誓，波斯拉必令人惊骇、羞辱、咒诅，并且荒凉。她的一切城邑必变为永远的荒场。」</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 30:4; 以赛亚书 37:7; 以西结书 7:25–26"> <span className="pl pl-1">我从耶和华那里听见信息，</span><br /><span className="pl pl-1">并有使者被差往列国去，说：</span><br /><span className="pl pl-1">你们聚集来攻击以东，</span><br /><span className="pl pl-1">要起来争战。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 1:51; 俄巴底亚书 1:2; 弥迦书 7:10"> <span className="pl pl-1">我使你在列国中为最小，</span><br /><span className="pl pl-1">在世人中被藐视。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 49:25; 阿摩司书 9:2; 约伯记 39:27"> <span className="pl pl-1">住在山穴中据守山顶的啊，</span><br /><span className="pl pl-1">论到你的威吓，</span><br /><span className="pl pl-1">你因心中的狂傲自欺；</span><br /><span className="pl pl-1">你虽如大鹰高高搭窝，</span><br /><span className="pl pl-1">我却从那里拉下你来。</span><br /><span className="pl pl-1">这是耶和华说的。</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西结书 35:7; 耶利米书 50:13; 耶利米书 49:13"> 「以东必令人惊骇；凡经过的人就受惊骇，又因她一切的灾祸嗤笑。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 49:33; 申命记 29:23; 耶利米书 50:40"> 耶和华说：必无人住在那里，也无人在其中寄居，要像所多玛、蛾摩拉，和邻近的城邑倾覆的时候一样。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 12:5; 耶利米书 30:21; 耶利米书 50:44–46"> 仇敌必像狮子从约旦河边的丛林上来，攻击坚固的居所。转眼之间，我要使以东人逃跑，离开这地。谁蒙拣选，我就派谁治理这地。谁能比我呢？谁能给我定规日期呢？有何牧人能在我面前站立得住呢？</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 50:45; 玛拉基书 1:3–4; 耶利米书 49:7"> 你们要听耶和华攻击以东所说的谋略和他攻击提幔居民所定的旨意。仇敌定要将他们群众微弱的拉去，定要使他们的居所荒凉。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 50:46; 以西结书 32:10; 以赛亚书 14:4–15"> 因他们仆倒的声音，地就震动。人在红海那里必听见呼喊的声音。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 48:40–41; 何西阿书 8:1; 以赛亚书 13:8"> 仇敌必如大鹰飞起，展开翅膀攻击波斯拉。到那日，以东的勇士心中疼痛如临产的妇人。」</span>
</div>
</div>

## 耶和华审判大马士革

<div className="bt">
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 10:9; 列王纪下 18:34; 创世记 15:2"> <span className="pl pl-1">论大马士革。</span><br /><span className="pl pl-1">哈马和亚珥拔蒙羞，</span><br /><span className="pl pl-1">因他们听见凶恶的信息就消化了。</span><br /><span className="pl pl-1">海上有忧愁，不得平静。</span><br /></span>
<span className="v" id="v24" data-v="24"> <span className="pl pl-1">大马士革发软，转身逃跑。</span><br /><span className="pl pl-1">战兢将她捉住；</span><br /><span className="pl pl-1">痛苦忧愁将她抓住，</span><br /><span className="pl pl-1">如产难的妇人一样。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 33:9; 耶利米书 51:41; 以赛亚书 1:26"> <span className="pl pl-1">我所喜乐可称赞的城，</span><br /><span className="pl pl-1">为何被撇弃了呢？</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 50:30; 阿摩司书 4:10; 耶利米书 11:22"> <span className="pl pl-1">她的少年人必仆倒在街上；</span><br /><span className="pl pl-1">当那日，一切兵丁必默默无声。</span><br /><span className="pl pl-1">这是万军之耶和华说的。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="阿摩司书 1:3–5; 列王纪上 15:18–20; 耶利米书 43:12"> <span className="pl pl-1">我必在大马士革城中使火着起，</span><br /><span className="pl pl-1">烧灭便·哈达的宫殿。</span></span>
</div>
</div>

## 审判基达和夏琐城

<div className="bt">
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="士师记 6:3; 创世记 25:13; 以赛亚书 11:14"> 论巴比伦王尼布甲尼撒所攻打的基达和夏琐的诸国。耶和华如此说：<br /><span className="pl pl-1">迦勒底人哪，起来上基达去，</span><br /><span className="pl pl-1">毁灭东方人。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 46:5; 耶利米书 6:25; 哈巴谷书 3:7"> <span className="pl pl-1">他们的帐棚和羊群都要夺去，</span><br /><span className="pl pl-1">将幔子和一切器皿，并骆驼为自己掠去。</span><br /><span className="pl pl-1">人向他们喊着说：</span><br /><span className="pl pl-1">四围都有惊吓。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 25:9; 耶利米书 27:6; 以赛亚书 10:7"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">夏琐的居民哪，要逃奔远方，</span><br /><span className="pl pl-1">住在深密处；</span><br /><span className="pl pl-1">因为巴比伦王尼布甲尼撒设计谋害你们，</span><br /><span className="pl pl-1">起意攻击你们。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="以西结书 38:11; 民数记 23:9; 申命记 33:28"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">迦勒底人哪，起来！</span><br /><span className="pl pl-1">上安逸无虑的居民那里去；</span><br /><span className="pl pl-1">他们是无门无闩、独自居住的。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 9:26; 耶利米书 25:23; 耶利米书 49:36"> <span className="pl pl-1">他们的骆驼必成为掠物；</span><br /><span className="pl pl-1">他们众多的牲畜必成为掳物。</span><br /><span className="pl pl-1">我必将剃周围头发的人分散四方</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原文是风">d</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">使灾殃从四围临到他们。</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 10:22; 耶利米书 9:11; 耶利米书 51:37"> <span className="pl pl-1">夏琐必成为野狗的住处，</span><br /><span className="pl pl-1">永远凄凉；</span><br /><span className="pl pl-1">必无人住在那里，</span><br /><span className="pl pl-1">也无人在其中寄居。</span></span>
</div>
</div>

## 耶和华审判以拦

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="创世记 10:22; 但以理书 8:2; 耶利米书 25:25"> 犹大王西底家登基的时候，耶和华论以拦的话临到先知耶利米说：</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 22:6; 耶利米书 51:56; 诗篇 46:9"> 「万军之耶和华如此说：我必折断以拦人的弓，就是他们为首的权力。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 49:32; 启示录 7:1; 以西结书 5:10"> 我要使四风从天的四方刮来，临到以拦人，将他们分散四方<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原文是风">e</a></sup>。这被赶散的人没有一国不到的。」</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 9:16; 耶利米书 48:2; 耶利米书 49:22"> 耶和华说：「我必使以拦人在仇敌和寻索其命的人面前惊惶；我也必使灾祸，就是我的烈怒临到他们，又必使刀剑追杀他们，直到将他们灭尽。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米书 43:10; 但以理书 7:9–14"> 我要在以拦设立我的宝座，从那里除灭君王和首领。这是耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="耶利米书 48:47; 何西阿书 3:5; 弥迦书 4:1"> 「到末后，我还要使被掳的以拦人归回。这是耶和华说的。」</span>
</div>
</div>

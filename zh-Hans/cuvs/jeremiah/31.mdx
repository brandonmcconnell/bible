## 以色列人还乡

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 30:22; 耶利米书 30:24; 撒迦利亚书 13:9"> 耶和华说：「那时，我必作以色列各家的 神；他们必作我的子民。」</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 10:33; 诗篇 95:11; 马太福音 11:28"> 耶和华如此说：<br /><span className="pl pl-1">脱离刀剑的就是以色列人。</span><br /><span className="pl pl-1">我使他享安息的时候，</span><br /><span className="pl pl-1">他曾在旷野蒙恩。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 103:17; 以赛亚书 54:8–9; 何西阿书 11:4"> <span className="pl pl-1">古时</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：从远方">a</a></sup><br /><span className="pl pl-1">耶和华向以色列</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是我">b</a></sup><br /><span className="pl pl-1">显现，说：</span><br /><span className="pl pl-1">我以永远的爱爱你，</span><br /><span className="pl pl-1">因此我以慈爱吸引你。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 33:7; 耶利米书 31:13; 阿摩司书 5:2"> <span className="pl pl-1">以色列的民</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是处女">c</a></sup><br /><span className="pl pl-1">哪，</span><br /><span className="pl pl-1">我要再建立你，你就被建立；</span><br /><span className="pl pl-1">你必再以击鼓为美，</span><br /><span className="pl pl-1">与欢乐的人一同跳舞而出；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="阿摩司书 9:14; 利未记 19:23–25; 申命记 28:30"> <span className="pl pl-1">又必在撒马利亚的山上栽种葡萄园，</span><br /><span className="pl pl-1">栽种的人要享用所结的果子。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 50:4–5; 弥迦书 4:1–3; 耶利米书 50:19"> <span className="pl pl-1">日子必到，以法莲山上守望的人必呼叫说：</span><br /><span className="pl pl-1">起来吧！我们可以上锡安，</span><br /><span className="pl pl-1">到耶和华—我们的 神那里去。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="诗篇 14:7; 诗篇 28:9; 以赛亚书 37:31"> <span className="pl pl-1">耶和华如此说：</span><br /><span className="pl pl-1">你们当为雅各欢乐歌唱，</span><br /><span className="pl pl-1">因万国中为首的欢呼。</span><br /><span className="pl pl-1">当传扬颂赞说：</span><br /><span className="pl pl-1">耶和华啊，</span><br /><span className="pl pl-1">求你拯救你的百姓以色列所剩下的人。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 34:16; 以赛亚书 42:16; 耶利米书 23:8"> <span className="pl pl-1">我必将他们从北方领来，</span><br /><span className="pl pl-1">从地极招聚；</span><br /><span className="pl pl-1">同着他们来的有瞎子、瘸子、孕妇、产妇；</span><br /><span className="pl pl-1">他们必成为大帮回到这里来。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 5:4; 耶利米书 3:4; 出埃及记 4:22"> <span className="pl pl-1">他们要哭泣而来。</span><br /><span className="pl pl-1">我要照他们恳求的引导他们，</span><br /><span className="pl pl-1">使他们在河水旁走正直的路，</span><br /><span className="pl pl-1">在其上不致绊跌；</span><br /><span className="pl pl-1">因为我是以色列的父，</span><br /><span className="pl pl-1">以法莲是我的长子。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 40:11; 以西结书 34:12; 申命记 30:4"> <span className="pl pl-1">列国啊，要听耶和华的话，</span><br /><span className="pl pl-1">传扬在远处的海岛说：</span><br /><span className="pl pl-1">赶散以色列的必招聚他，</span><br /><span className="pl pl-1">又看守他，好像牧人看守羊群。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 48:20; 提多书 2:14; 以赛亚书 44:23"> <span className="pl pl-1">因耶和华救赎了雅各，</span><br /><span className="pl pl-1">救赎他脱离比他更强之人的手。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 35:10; 以赛亚书 58:11; 约珥书 3:18"> <span className="pl pl-1">他们要来到锡安的高处歌唱，</span><br /><span className="pl pl-1">又流归耶和华施恩之地，</span><br /><span className="pl pl-1">就是有五谷、新酒，和油，</span><br /><span className="pl pl-1">并羊羔、牛犊之地。</span><br /><span className="pl pl-1">他们的心必像浇灌的园子；</span><br /><span className="pl pl-1">他们也不再有一点愁烦。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 30:11; 以赛亚书 61:3; 以赛亚书 51:11"> <span className="pl pl-1">那时，处女必欢乐跳舞；</span><br /><span className="pl pl-1">年少的、年老的，也必一同欢乐；</span><br /><span className="pl pl-1">因为我要使他们的悲哀变为欢喜，</span><br /><span className="pl pl-1">并要安慰他们，使他们的愁烦转为快乐。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 31:25; 彼得前书 2:9; 耶利米书 33:9"> <span className="pl pl-1">我必以肥油使祭司的心满足；</span><br /><span className="pl pl-1">我的百姓也要因我的恩惠知足。</span><br /><span className="pl pl-1">这是耶和华说的。</span></span>
</div>
</div>

## 耶和华怜悯以色列

<div className="bt">
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="马太福音 2:16–18; 耶利米书 40:1; 诗篇 77:2"> <span className="pl pl-1">耶和华如此说：</span><br /><span className="pl pl-1">在拉玛听见号咷痛哭的声音，</span><br /><span className="pl pl-1">是拉结哭她儿女，不肯受安慰，</span><br /><span className="pl pl-1">因为他们都不在了。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="路得记 2:12; 耶利米书 30:3; 希伯来书 6:10"> <span className="pl pl-1">耶和华如此说：</span><br /><span className="pl pl-1">你禁止声音不要哀哭，</span><br /><span className="pl pl-1">禁止眼目不要流泪，</span><br /><span className="pl pl-1">因你所做之工必有赏赐；</span><br /><span className="pl pl-1">他们必从敌国归回。</span><br /><span className="pl pl-1">这是耶和华说的。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="耶利米哀歌 3:21; 耶利米书 29:11–16; 耶利米哀歌 3:18"> <span className="pl pl-1">耶和华说：你末后必有指望；</span><br /><span className="pl pl-1">你的儿女必回到自己的境界。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 31:9; 诗篇 80:3; 约伯记 5:17"> <span className="pl pl-1">我听见以法莲为自己悲叹说：</span><br /><span className="pl pl-1">你责罚我，我便受责罚，</span><br /><span className="pl pl-1">像不惯负轭的牛犊一样。</span><br /><span className="pl pl-1">求你使我回转，我便回转，</span><br /><span className="pl pl-1">因为你是耶和华—我的 神。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 36:31; 耶利米书 3:25; 以西结书 21:12"> <span className="pl pl-1">我回转以后就真正懊悔；</span><br /><span className="pl pl-1">受教以后就拍腿叹息；</span><br /><span className="pl pl-1">我因担当幼年的凌辱就抱愧蒙羞。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 55:7; 弥迦书 7:18–19; 以赛亚书 63:15"> <span className="pl pl-1">耶和华说：以法莲是我的爱子吗？</span><br /><span className="pl pl-1">是可喜悦的孩子吗？</span><br /><span className="pl pl-1">我每逢责备他，仍深顾念他；</span><br /><span className="pl pl-1">所以我的心肠恋慕他；</span><br /><span className="pl pl-1">我必要怜悯他。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="耶利米书 50:5; 以赛亚书 62:10; 诗篇 84:5"> <span className="pl pl-1">以色列民</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原文是处女">d</a></sup><br /><span className="pl pl-1">哪，</span><br /><span className="pl pl-1">你当为自己设立指路碑，</span><br /><span className="pl pl-1">竖起引路柱。</span><br /><span className="pl pl-1">你要留心向大路，</span><br /><span className="pl pl-1">就是你所去的原路；</span><br /><span className="pl pl-1">你当回转，回转到你这些城邑。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 49:4; 耶利米书 7:24; 马太福音 1:21"> <span className="pl pl-1">背道的民</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原文是女子">e</a></sup><br /><span className="pl pl-1">哪，</span><br /><span className="pl pl-1">你反来复去要到几时呢？</span><br /><span className="pl pl-1">耶和华在地上造了一件新事，</span><br /><span className="pl pl-1">就是女子护卫男子。</span></span>
</div>
</div>

## 神子民的光明前途

<div className="bt">
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="撒迦利亚书 8:3; 以赛亚书 1:26; 耶利米书 50:7"> 万军之耶和华—以色列的 神如此说：「我使被掳之人归回的时候，他们在犹大地和其中的城邑必再这样说：<br /><span className="pl pl-1">公义的居所啊，</span><br /><span className="pl pl-1">圣山哪，愿耶和华赐福给你。</span></span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亚书 8:4–8; 以西结书 36:10; 撒迦利亚书 2:4"> 犹大和属犹大城邑的人，农夫和放羊的人，要一同住在其中。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 5:6; 马太福音 11:28; 约翰福音 4:14"> 疲乏的人，我使他饱饫；愁烦的人，我使他知足。」</span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 127:2; 撒迦利亚书 4:1–2"> 先知说：「我醒了，觉着睡得香甜！」</span>
<span className="v" id="v27" data-v="27" data-xref="何西阿书 2:23; 撒迦利亚书 10:9; 以西结书 36:9"> 耶和华说：「日子将到，我要把人的种和牲畜的种播种在以色列家和犹大家。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 24:6; 耶利米书 1:10; 耶利米书 18:7–9"> 我先前怎样留意将他们拔出、拆毁、毁坏、倾覆、苦害，也必照样留意将他们建立、栽植。这是耶和华说的。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米哀歌 5:7; 以西结书 18:2–3; 耶利米书 31:30"> 当那些日子，人不再说：<br /><span className="pl pl-1">父亲吃了酸葡萄，</span><br /><span className="pl pl-1">儿子的牙酸倒了。</span></span>
<span className="v" id="v30" data-v="30" data-xref="以西结书 18:20; 以赛亚书 3:11; 申命记 24:16"> 但各人必因自己的罪死亡；凡吃酸葡萄的，自己的牙必酸倒。」</span>
<span className="v" id="v31" data-v="31" data-xref="希伯来书 10:16–17; 以西结书 37:26; 耶利米书 31:31–34"> 耶和华说：「日子将到，我要与以色列家和犹大家另立新约，</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 24:6–8; 申命记 5:3; 出埃及记 19:5"> 不像我拉着他们祖宗的手，领他们出埃及地的时候，与他们所立的约。我虽作他们的丈夫，他们却背了我的约。这是耶和华说的。」</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多后书 3:3; 希伯来书 10:16; 希伯来书 8:10"> 耶和华说：「那些日子以后，我与以色列家所立的约乃是这样：我要将我的律法放在他们里面，写在他们心上。我要作他们的 神，他们要作我的子民。</span>
<span className="v" id="v34" data-v="34" data-xref="以赛亚书 43:25; 希伯来书 8:12; 约翰一书 2:27"> 他们各人不再教导自己的邻舍和自己的弟兄说：『你该认识耶和华』，因为他们从最小的到至大的都必认识我。我要赦免他们的罪孽，不再记念他们的罪恶。这是耶和华说的。」</span>
<span className="v" id="v35" data-v="35" data-xref="耶利米书 10:16; 以赛亚书 51:15; 诗篇 136:7–9"> <span className="pl pl-1">那使太阳白日发光，</span><br /><span className="pl pl-1">使星月有定例，黑夜发亮，</span><br /><span className="pl pl-1">又搅动大海，使海中波浪匉訇的，</span><br /><span className="pl pl-1">万军之耶和华是他的名。</span><br /><span className="pl pl-1">他如此说：</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="以赛亚书 54:9–10; 耶利米书 33:20–26; 诗篇 89:36–37"> <span className="pl pl-1">这些定例若能在我面前废掉，</span><br /><span className="pl pl-1">以色列的后裔也就在我面前断绝，</span><br /><span className="pl pl-1">永远不再成国。</span><br /><span className="pl pl-1">这是耶和华说的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v37" data-v="37" data-xref="耶利米书 33:24–26; 以赛亚书 40:12; 耶利米书 33:22"> 耶和华如此说：<br /><span className="pl pl-1">若能量度上天，</span><br /><span className="pl pl-1">寻察下地的根基，</span><br /><span className="pl pl-1">我就因以色列后裔一切所行的弃绝他们。</span><br /><span className="pl pl-1">这是耶和华说的。</span></span>
<span className="v" id="v38" data-v="38" data-xref="撒迦利亚书 14:10; 列王纪下 14:13; 耶利米书 30:18"> 耶和华说：「日子将到，这城必为耶和华建造，从哈楠业楼直到角门。</span>
<span className="v" id="v39" data-v="39" data-xref="撒迦利亚书 2:1–2; 以西结书 40:8"> 准绳要往外量出，直到迦立山，又转到歌亚。</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳记下 15:23; 约珥书 3:17; 列王纪下 11:16"> 抛尸的全谷和倒灰之处，并一切田地，直到汲沦溪，又直到东方马门的拐角，都要归耶和华为圣，不再拔出，不再倾覆，直到永远。」</span>
</div>

## 耶利米写信给巴比伦的犹大人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖记 9:20; 使徒行传 15:23; 希伯来书 13:22"> 先知耶利米从耶路撒冷寄信与被掳的祭司、先知，和众民，并生存的长老，就是尼布甲尼撒从耶路撒冷掳到巴比伦去的。（</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 22:24–28; 耶利米书 27:20; 历代志下 36:9–10"> 这在耶哥尼雅王和太后、太监，并犹大、耶路撒冷的首领，以及工匠、铁匠都离了耶路撒冷以后。）</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 8:11; 历代志下 34:20; 耶利米书 39:14"> 他借沙番的儿子以利亚萨和希勒家的儿子基玛利的手寄去。他们二人是犹大王西底家打发往巴比伦去见尼布甲尼撒王的。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 24:5; 以赛亚书 10:5–6; 以赛亚书 45:7"> 信上说：「万军之耶和华—以色列的 神对一切被掳去的（就是我使他们从耶路撒冷被掳到巴比伦的人）如此说：</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 29:28; 耶利米书 29:10; 以西结书 28:26"> 你们要盖造房屋，住在其中；栽种田园，吃其中所产的；</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 24:3–4; 创世记 24:51; 创世记 28:1–4"> 娶妻生儿女，为你们的儿子娶妻，使你们的女儿嫁人，生儿养女。在那里生养众多，不致减少。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前书 2:1–2; 以斯拉记 6:10; 彼得前书 2:13–17"> 我所使你们被掳到的那城，你们要为那城求平安，为那城祷告耶和华；因为那城得平安，你们也随着得平安。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 5:6; 耶利米书 5:31; 帖撒罗尼迦后书 2:9–11"> 万军之耶和华—以色列的 神如此说：不要被你们中间的先知和占卜的诱惑，也不要听信自己所做的梦；</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 27:15; 耶利米书 29:31; 耶利米书 29:23"> 因为他们托我的名对你们说假预言，我并没有差遣他们。这是耶和华说的。</span>
<span className="v" id="v10" data-v="10" data-xref="但以理书 9:2; 撒迦利亚书 7:5; 耶利米书 24:6–7"> 「耶和华如此说：为巴比伦所定的七十年满了以后，我要眷顾你们，向你们成就我的恩言，使你们仍回此地。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 55:8–12; 诗篇 33:11; 弥迦书 4:12"> 耶和华说：我知道我向你们所怀的意念是赐平安的意念，不是降灾祸的意念，要叫你们末后有指望。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 7:7–8; 耶利米书 33:3; 诗篇 50:15"> 你们要呼求我，祷告我，我就应允你们。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 4:29–31; 诗篇 119:2; 马太福音 7:7"> 你们寻求我，若专心寻求我，就必寻见。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 36:1–38; 耶利米书 30:3; 历代志上 28:9"> 耶和华说：我必被你们寻见，我也必使你们被掳的人归回，将你们从各国中和我所赶你们到的各处招聚了来，又将你们带回我使你们被掳掠离开的地方。这是耶和华说的。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 29:8–9; 耶利米书 28:1–17; 以西结书 1:3"> 「你们说：『耶和华在巴比伦为我们兴起先知』；</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 38:2–3; 耶利米书 38:17–23; 以西结书 17:12–21"> 所以耶和华论到坐大卫宝座的王和住在这城里的一切百姓，就是未曾与你们一同被掳的弟兄，</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 24:8–10; 耶利米书 29:18; 耶利米书 24:1–3"> 万军之耶和华如此说：『看哪，我必使刀剑、饥荒、瘟疫临到他们，使他们像极坏的无花果，坏得不可吃。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 29:8; 耶利米书 15:4; 耶利米书 42:18"> 我必用刀剑、饥荒、瘟疫追赶他们，使他们在天下万国抛来抛去，在我所赶他们到的各国中，令人咒诅、惊骇、嗤笑、羞辱。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 6:19; 耶利米书 26:5; 耶利米书 7:24–26"> 耶和华说：这是因为他们没有听从我的话，就是我从早起来差遣我仆人众先知去说的，无奈他们不听。这是耶和华说的。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 24:5; 弥迦书 4:10; 以西结书 3:15"> 所以你们一切被掳去的，就是我从耶路撒冷打发到巴比伦去的，当听耶和华的话。』」</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 14:14–15; 耶利米哀歌 2:14; 耶利米书 29:8–9"> 万军之耶和华—以色列的 神论到哥赖雅的儿子亚哈，并玛西雅的儿子西底家，如此说：「他们是托我名向你们说假预言的，我必将他们交在巴比伦王尼布甲尼撒的手中；他要在你们眼前杀害他们。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 65:15; 但以理书 3:6; 但以理书 3:21"> 住巴比伦一切被掳的犹大人必借这二人赌咒说：『愿耶和华使你像巴比伦王在火中烧的西底家和亚哈一样。』</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 23:14; 希伯来书 4:13; 玛拉基书 3:5"> 这二人是在以色列中行了丑事，与邻舍的妻行淫，又假托我名说我未曾吩咐他们的话。知道的是我，作见证的也是我。这是耶和华说的。」</span>
</div>
</div>

## 示玛雅的信件

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="耶利米书 29:31–32"> 「论到尼希兰人示玛雅，你当说，</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 37:3; 耶利米书 29:29; 耶利米书 52:24"> 万军之耶和华—以色列的 神如此说：你曾用自己的名寄信给耶路撒冷的众民和祭司玛西雅的儿子西番雅，并众祭司，说：</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 20:1–2; 列王纪下 9:11; 约翰福音 10:20"> 『耶和华已经立你西番雅为祭司，代替祭司耶何耶大，使耶和华殿中有官长，好将一切狂妄自称为先知的人用枷枷住，用锁锁住。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 25:16; 耶利米书 43:2–3; 耶利米书 29:26"> 现在亚拿突人耶利米向你们自称为先知，你们为何没有责备他呢？</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 29:5; 耶利米书 29:1; 耶利米书 29:10"> 因为他寄信给我们在巴比伦的人说：被掳的事必长久。你们要盖造房屋，住在其中；栽种田园，吃其中所产的。』」</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 29:25"> 祭司西番雅就把这信念给先知耶利米听。</span>
<span className="v" id="v30" data-v="30"> 于是耶和华的话临到耶利米说：</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米书 29:9; 耶利米书 29:23–24; 耶利米书 14:14–15"> 「你当寄信给一切被掳的人说：『耶和华论到尼希兰人示玛雅说：因为示玛雅向你们说预言，我并没有差遣他，他使你们倚靠谎言；</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 28:16; 列王纪下 7:19–20; 耶利米书 17:6"> 所以耶和华如此说：我必刑罚尼希兰人示玛雅和他的后裔，他必无一人存留住在这民中，也不得见我所要赐与我百姓的福乐，因为他向耶和华说了叛逆的话。这是耶和华说的。』」</span>

## 耶利米在陶匠的家

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华的话临到耶利米说：</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 1:1; 使徒行传 9:6; 耶利米书 19:1–2"> 「你起来，下到窑匠的家里去，我在那里要使你听我的话。」</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 15:14; 约拿书 1:3; 使徒行传 26:19"> 我就下到窑匠的家里去，正遇他转轮做器皿。</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 9:20–23; 耶利米书 18:6; 以赛亚书 45:9"> 窑匠用泥做的器皿，在他手中做坏了，他又用这泥另做别的器皿；窑匠看怎样好，就怎样做。</span>
<span className="v" id="v5" data-v="5"> 耶和华的话就临到我说：</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 64:8; 罗马书 9:20–21; 耶利米书 18:4"> 「耶和华说：以色列家啊，我待你们，岂不能照这窑匠弄泥吗？以色列家啊，泥在窑匠的手中怎样，你们在我的手中也怎样。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 1:10; 耶利米书 12:14–17; 耶利米书 45:4"> 我何时论到一邦或一国说，要拔出、拆毁、毁坏；</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 18:21; 耶利米书 26:13; 约拿书 3:9–10"> 我所说的那一邦，若是转意离开他们的恶，我就必后悔，不将我想要施行的灾祸降与他们。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 31:28; 阿摩司书 9:11–15; 耶利米书 1:10"> 我何时论到一邦或一国说，要建立、栽植；</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 33:18; 撒母耳记上 2:30; 以西结书 18:24"> 他们若行我眼中看为恶的事，不听从我的话，我就必后悔，不将我所说的福气赐给他们。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 17:13; 以赛亚书 55:6–7; 耶利米书 35:15"> 现在你要对犹大人和耶路撒冷的居民说：『耶和华如此说：我造出灾祸攻击你们，定意刑罚你们。你们各人当回头离开所行的恶道，改正你们的行动作为。』</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 2:25; 耶利米书 7:24; 申命记 29:19"> 「他们却说：『这是枉然。我们要照自己的计谋去行。』各人随自己顽梗的恶心做事。」</span>
</div>
</div>

<div className="bt">
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="耶利米书 5:30; 何西阿书 6:10; 耶利米书 23:14"> <span className="pl pl-1">所以，耶和华如此说：</span><br /><span className="pl pl-1">你们且往各国访问，</span><br /><span className="pl pl-1">有谁听见这样的事？</span><br /><span className="pl pl-1">以色列民</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是处女">a</a></sup><br /><span className="pl pl-1">行了一件极可憎恶的事。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 6:68"> <span className="pl pl-1">黎巴嫩的雪从田野的磐石上岂能断绝呢？</span><br /><span className="pl pl-1">从远处流下的凉水岂能干涸呢？</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 6:16; 耶利米书 2:32; 何西阿书 11:2"> <span className="pl pl-1">我的百姓竟忘记我，</span><br /><span className="pl pl-1">向假神烧香，</span><br /><span className="pl pl-1">使他们在所行的路上，在古道上绊跌，</span><br /><span className="pl pl-1">使他们行没有修筑的斜路，</span><br /></span>

## 谋害耶利米

<div className="bt">
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="诗篇 52:2; 耶利米书 11:19; 玛拉基书 2:7"> 他们就说：「来吧！我们可以设计谋害耶利米；因为我们有祭司讲律法，智慧人设谋略，先知说预言，都不能断绝。来吧！我们可以用舌头击打他，不要理会他的一切话。」</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米记 6:9; 耶利米书 20:12; 诗篇 55:16–17"> <span className="pl pl-1">耶和华啊，求你理会我，</span><br /><span className="pl pl-1">且听那些与我争竞之人的话。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 35:7; 诗篇 57:6; 诗篇 106:23"> <span className="pl pl-1">岂可以恶报善呢？</span><br /><span className="pl pl-1">他们竟挖坑要害我的性命！</span><br /><span className="pl pl-1">求你记念我怎样站在你面前为他们代求，</span><br /><span className="pl pl-1">要使你的忿怒向他们转消。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 109:9–20; 耶利米哀歌 5:3; 阿摩司书 4:10"> <span className="pl pl-1">故此，愿你将他们的儿女交与饥荒和刀剑；</span><br /><span className="pl pl-1">愿他们的妻无子，且作寡妇；</span><br /><span className="pl pl-1">又愿他们的男人被死亡所灭，</span><br /><span className="pl pl-1">他们的少年人在阵上被刀击杀。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 6:26; 诗篇 140:5; 西番雅书 1:10–11"> <span className="pl pl-1">你使敌军忽然临到他们的时候，</span><br /><span className="pl pl-1">愿人听见哀声从他们的屋内发出；</span><br /><span className="pl pl-1">因他们挖坑要捉拿我，</span><br /><span className="pl pl-1">暗设网罗要绊我的脚。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 35:4; 诗篇 69:22–28; 尼希米记 4:4–5"> <span className="pl pl-1">耶和华啊，他们要杀我的那一切计谋，</span><br /><span className="pl pl-1">你都知道。</span><br /><span className="pl pl-1">不要赦免他们的罪孽，</span><br /><span className="pl pl-1">也不要从你面前涂抹他们的罪恶，</span><br /><span className="pl pl-1">要叫他们在你面前跌倒；</span><br /><span className="pl pl-1">愿你发怒的时候罚办他们。</span></span>
</div>

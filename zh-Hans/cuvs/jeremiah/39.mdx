## 耶路撒冷陷落

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结书 24:1–2; 耶利米书 52:4–7; 列王纪下 25:1–12"> 犹大王西底家第九年十月，巴比伦王尼布甲尼撒率领全军来围困耶路撒冷。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 52:6–7; 弥迦书 2:12–13; 列王纪下 25:3–4"> 西底家十一年四月初九日，城被攻破。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 21:4; 耶利米书 38:17; 耶利米书 39:13"> 耶路撒冷被攻取的时候，巴比伦王的首领尼甲·沙利薛、三甲·尼波、撒西金—拉撒力、尼甲·沙利薛—拉墨，并巴比伦王其余的一切首领都来坐在中门。</span>
<span className="v" id="v4" data-v="4" data-xref="阿摩司书 2:14; 历代志下 32:5; 列王纪下 25:4–7"> 犹大王西底家和一切兵丁看见他们，就在夜间从靠近王园两城中间的门出城逃跑，往亚拉巴逃去。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 23:33; 约书亚记 5:10; 耶利米书 52:26–27"> 迦勒底的军队追赶他们，在耶利哥的平原追上西底家，将他拿住，带到哈马地的利比拉、巴比伦王尼布甲尼撒那里；尼布甲尼撒就审判他。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 52:10; 耶利米书 34:19–21; 耶利米书 24:8–10"> 巴比伦王在利比拉、西底家眼前杀了他的众子，又杀了犹大的一切贵胄，</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 12:13; 列王纪下 25:7; 耶利米书 52:11"> 并且剜西底家的眼睛，用铜链锁着他，要带到巴比伦去。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米记 1:3; 耶利米书 38:18; 耶利米书 21:10"> 迦勒底人用火焚烧王宫和百姓的房屋，又拆毁耶路撒冷的城墙。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 40:1; 创世记 37:36; 耶利米书 10:18"> 那时，护卫长尼布撒拉旦将城里所剩下的百姓和投降他的逃民，以及其余的民都掳到巴比伦去了。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 25:12; 耶利米书 40:7; 耶利米书 52:16"> 护卫长尼布撒拉旦却将民中毫无所有的穷人留在犹大地，当时给他们葡萄园和田地。</span>
</div>
</div>

## 耶利米被释放

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 24:23; 耶利米书 15:21; 约伯记 5:19"> 巴比伦王尼布甲尼撒提到耶利米，嘱咐护卫长尼布撒拉旦说：</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 16:7; 耶利米书 40:4; 箴言 21:1"> 「你领他去，好好地看待他，切不可害他；他对你怎么说，你就向他怎么行。」</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 39:3; 耶利米书 39:9"> 护卫长尼布撒拉旦和尼布沙斯班—拉撒力、尼甲·沙利薛—拉墨，并巴比伦王的一切官长，</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 38:28; 列王纪下 22:12; 耶利米书 26:24"> 打发人去，将耶利米从护卫兵院中提出来，交与沙番的孙子亚希甘的儿子基大利，带回家去。于是耶利米住在民中。</span>
</div>
</div>

## 以伯·米勒的希望

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="提摩太后书 2:9; 耶利米书 32:1–2; 耶利米书 36:1–5"> 耶利米还囚在护卫兵院中的时候，耶和华的话临到他说：</span>
<span className="v" id="v16" data-v="16" data-xref="但以理书 9:12; 撒迦利亚书 1:6; 约书亚记 23:14–15"> 「你去告诉古实人以伯·米勒说，万军之耶和华—以色列的 神如此说：我说降祸不降福的话必临到这城，到那时必在你面前成就了。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 41:1–2; 诗篇 91:14–15; 诗篇 50:15"> 耶和华说：到那日我必拯救你，你必不致交在你所怕的人手中。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 38:2; 诗篇 34:22; 耶利米书 21:9"> 我定要搭救你，你不致倒在刀下，却要以自己的命为掠物，因你倚靠我。这是耶和华说的。」</span>
</div>
</div>

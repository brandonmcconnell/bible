## 重申复国的应许

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 38:28; 耶利米书 37:21; 耶利米书 32:2–3"> 耶利米还囚在护卫兵的院内，耶和华的话第二次临到他说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 6:3; 出埃及记 15:3; 以赛亚书 37:26"> 「成就的是耶和华，造作、为要建立的也是耶和华；耶和华是他的名。他如此说：</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 29:12; 以赛亚书 65:24; 以弗所书 3:20"> 你求告我，我就应允你，并将你所不知道、又大又难的事指示你。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 32:24; 哈巴谷书 1:10; 以西结书 4:2"> 论到这城中的房屋和犹大王的宫室，就是拆毁为挡敌人高垒和刀剑的，耶和华—以色列的 神如此说：</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 8:17; 耶利米书 21:10; 耶利米书 21:4–7"> 人要与迦勒底人争战，正是拿死尸充满这房屋，就是我在怒气和忿怒中所杀的人，因他们的一切恶，我就掩面不顾这城。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 10:10; 以赛亚书 30:26; 提多书 3:5–6"> 看哪，我要使这城得以痊愈安舒，使城中的人得医治，又将丰盛的平安和诚实显明与他们。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 1:26; 耶利米书 30:3; 阿摩司书 9:14–15"> 我也要使犹大被掳的和以色列被掳的归回，并建立他们和起初一样。</span>
<span className="v" id="v8" data-v="8" data-xref="撒迦利亚书 13:1; 弥迦书 7:18–19; 诗篇 51:2"> 我要除净他们的一切罪，就是向我所犯的罪；又要赦免他们的一切罪，就是干犯我、违背我的罪。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 126:2–3; 以赛亚书 60:5; 西番雅书 3:17–20"> 这城要在地上万国人面前使我得颂赞，得荣耀，名为可喜可乐之城。万国人因听见我向这城所赐的福乐、所施的恩惠平安，就惧怕战兢。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 32:43; 耶利米书 32:36; 以西结书 37:11"> 耶和华如此说：「你们论这地方，说是荒废无人民无牲畜之地，但在这荒凉无人民无牲畜的犹大城邑和耶路撒冷的街上，</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 16:34; 诗篇 106:1; 诗篇 107:22"> 必再听见有欢喜和快乐的声音、新郎和新妇的声音，并听见有人说：<br /><span className="pl pl-1">要称谢万军之耶和华，</span><br /><span className="pl pl-1">因耶和华本为善；</span><br /><span className="pl pl-1">他的慈爱永远长存！</span><br />又有奉感谢祭到耶和华殿中之人的声音；因为我必使这地被掳的人归回，和起初一样。这是耶和华说的。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 65:10; 以西结书 34:12–15; 耶利米书 36:29"> 万军之耶和华如此说：「在这荒废无人民无牲畜之地，并其中所有的城邑，必再有牧人的住处；他们要使羊群躺卧在那里。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 27:32; 路加福音 15:4; 耶利米书 17:26"> 在山地的城邑、高原的城邑、南地的城邑、便雅悯地、耶路撒冷四围的各处，和犹大的城邑必再有羊群从数点的人手下经过。这是耶和华说的。」</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="哈该书 2:6–9; 耶利米书 23:5; 历代志上 17:13–14"> 耶和华说：「日子将到，我应许以色列家和犹大家的恩言必然成就。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 11:1–5; 耶利米书 23:5–6; 以赛亚书 4:2"> 当那日子，那时候，我必使大卫公义的苗裔长起来；他必在地上施行公平和公义。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 23:6; 哥林多前书 1:30; 以赛亚书 45:17"> 在那日子犹大必得救，耶路撒冷必安然居住，他的名必称为『耶和华—我们的义』。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王纪上 2:4; 诗篇 89:29–37; 路加福音 1:32–33"> 「因为耶和华如此说：大卫必永不断人坐在以色列家的宝座上；</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 56:7; 启示录 1:6; 申命记 18:1"> 祭司、利未人在我面前也不断人献燔祭、烧素祭，时常办理献祭的事。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 耶和华的话临到耶利米说：</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 8:22; 诗篇 89:37; 以赛亚书 54:9–10"> 「耶和华如此说：你们若能废弃我所立白日黑夜的约，使白日黑夜不按时轮转，</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 89:34; 历代志下 7:18; 撒母耳记下 23:5"> 就能废弃我与我仆人大卫所立的约，使他没有儿子在他的宝座上为王，并能废弃我与事奉我的祭司、利未人所立的约。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 15:5; 创世记 22:17; 希伯来书 11:12"> 天上的万象不能数算，海边的尘沙也不能斗量；我必照样使我仆人大卫的后裔和事奉我的利未人多起来。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和华的话临到耶利米说：</span>
<span className="v" id="v24" data-v="24" data-xref="尼希米记 4:2–4; 诗篇 83:4; 诗篇 44:13–14"> 「你没有揣摩这百姓的话吗？他们说：『耶和华所拣选的二族，他已经弃绝了。』他们这样藐视我的百姓，以为不再成国。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 74:16–17; 耶利米书 31:35–36; 诗篇 104:19"> 耶和华如此说：若是我立白日黑夜的约不能存住，若是我未曾安排天地的定例，</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 31:37; 以赛亚书 14:1; 何西阿书 2:23"> 我就弃绝雅各的后裔和我仆人大卫的后裔，不使大卫的后裔治理亚伯拉罕、以撒、雅各的后裔；因为我必使他们被掳的人归回，也必怜悯他们。」</span>
</div>

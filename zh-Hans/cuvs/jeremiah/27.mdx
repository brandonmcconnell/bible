## 耶利米负轭

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 27:3; 耶利米书 28:1; 耶利米书 27:12"> 犹大王约西亚的儿子约雅敬<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="约雅敬是西底家的别名，看第三节">a</a></sup>登基的时候，有这话从耶和华临到耶利米说：</span>
<span className="v" id="v2" data-v="2" data-xref="阿摩司书 7:1; 阿摩司书 7:4; 耶利米书 27:12"> 「耶和华对我如此说：你做绳索与轭，加在自己的颈项上，</span>
<span className="v" id="v3" data-v="3" data-xref="阿摩司书 1:9–3; 以西结书 25:1–17; 以西结书 17:15–21"> 借那些来到耶路撒冷见犹大王西底家的使臣之手，把绳索与轭送到以东王、摩押王、亚扪王、泰尔王、西顿王那里，</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 51:19; 耶利米书 10:10; 耶利米书 25:27"> 且嘱咐使臣，传与他们的主人说，万军之耶和华—以色列的 神如此说：</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 32:17; 耶利米书 51:15; 诗篇 115:15–16"> 我用大能和伸出来的膀臂，创造大地和地上的人民、牲畜。我看给谁相宜，就把地给谁。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 28:14; 耶利米书 25:9; 但以理书 2:37–38"> 现在我将这些地都交给我仆人巴比伦王尼布甲尼撒的手，我也将田野的走兽给他使用。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 52:31; 启示录 13:5–10; 但以理书 5:25–31"> 列国都必服事他和他的儿孙，直到他本国遭报的日期来到。那时，多国和大君王要使他作他们的奴仆。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以西结书 14:21; 以西结书 17:19–21; 耶利米书 38:17–19"> 「无论哪一邦哪一国，不肯服事这巴比伦王尼布甲尼撒，也不把颈项放在巴比伦王的轭下，我必用刀剑、饥荒、瘟疫刑罚那邦，直到我借巴比伦王的手将他们毁灭。这是耶和华说的。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 14:14; 玛拉基书 3:5; 耶利米书 29:8"> 至于你们，不可听从你们的先知和占卜的、圆梦的、观兆的，以及行邪术的；他们告诉你们说：『你们不致服事巴比伦王。』</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 32:31; 耶利米书 28:16; 耶利米书 23:25"> 他们向你们说假预言，要叫你们迁移，远离本地，以致我将你们赶出去，使你们灭亡。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 27:8; 耶利米书 27:2; 耶利米书 38:2"> 但哪一邦肯把颈项放在巴比伦王的轭下服事他，我必使那邦仍在本地存留，得以耕种居住。这是耶和华说的。」</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米书 28:1; 耶利米书 38:17; 历代志下 36:11–13"> 我就照这一切的话对犹大王西底家说：「要把你们的颈项放在巴比伦王的轭下，服事他和他的百姓，便得存活。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 18:31; 耶利米书 27:8; 箴言 8:36"> 你和你的百姓为何要因刀剑、饥荒、瘟疫死亡，正如耶和华论到不服事巴比伦王的那国说的话呢？</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 14:14; 哥林多后书 11:13–15; 耶利米书 29:8–9"> 不可听那些先知对你们所说的话；他们说：『你们不致服事巴比伦王』，其实他们向你们说假预言。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 27:10; 历代志下 25:16; 耶利米书 6:13–15"> 耶和华说：『我并没有打发他们，他们却托我的名说假预言，好使我将你们和向你们说预言的那些先知赶出去，一同灭亡。』」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪下 24:13; 耶利米书 28:3; 但以理书 1:2"> 我又对祭司和这众民说：「耶和华如此说：你们不可听那先知对你们所说的预言。他们说：『耶和华殿中的器皿快要从巴比伦带回来』；其实他们向你们说假预言。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 38:17; 耶利米书 38:23; 耶利米书 7:34"> 不可听从他们，只管服事巴比伦王便得存活。这城何致变为荒场呢？</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 7:8; 耶利米书 18:20; 撒母耳记上 12:19"> 他们若果是先知，有耶和华的话临到他们，让他们祈求万军之耶和华，使那在耶和华殿中和犹大王宫内，并耶路撒冷剩下的器皿，不被带到巴比伦去。（</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 25:13; 耶利米书 52:17–23; 列王纪下 25:17"> 因为万军之耶和华论到柱子、铜海、盆座，并剩在这城里的器皿，</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 24:1; 历代志下 36:10; 列王纪下 24:14–16"> 就是巴比伦王尼布甲尼撒掳掠犹大王约雅敬的儿子耶哥尼雅，和犹大、耶路撒冷一切贵胄的时候所没有掠去的器皿。）</span>
<span className="v" id="v21" data-v="21"> 论到那在耶和华殿中和犹大王宫内，并耶路撒冷剩下的器皿，万军之耶和华—以色列的 神如此说：</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 29:10; 以斯拉记 7:19; 耶利米书 32:5"> 必被带到巴比伦存在那里，直到我眷顾以色列人的日子。那时，我必将这器皿带回来，交还此地。这是耶和华说的。」</span>
</div>

## 从北方来的敌人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 36:1; 列王纪下 24:1–2; 但以理书 1:1"> 犹大王约西亚的儿子约雅敬第四年，就是巴比伦王尼布甲尼撒的元年，耶和华论犹大众民的话临到耶利米。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 18:11; 耶利米书 19:14–15; 马可福音 7:14–15"> 先知耶利米就将这话对犹大众人和耶路撒冷的一切居民说：</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 11:7; 耶利米书 26:5; 耶利米书 1:2"> 「从犹大王亚们的儿子约西亚十三年直到今日，这二十三年之内，常有耶和华的话临到我；我也对你们传说，就是从早起来传说，只是你们没有听从。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 25:3; 耶利米书 26:5; 耶利米书 13:10–11"> 耶和华也从早起来，差遣他的仆人众先知到你们这里来（只是你们没有听从，也没有侧耳而听），</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 7:7; 创世记 17:8; 以赛亚书 55:6–7"> 说：『你们各人当回头，离开恶道和所作的恶，便可居住耶和华古时所赐给你们和你们列祖之地，直到永远。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 8:19; 耶利米书 7:6; 耶利米书 35:15"> 不可随从别神事奉敬拜，以你们手所做的惹我发怒；这样，我就不加害与你们。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 21:15; 箴言 8:36; 申命记 32:21"> 然而你们没有听从我，竟以手所做的惹我发怒，陷害自己。这是耶和华说的。』」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 所以万军之耶和华如此说：「因为你们没有听从我的话，</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 13:3; 耶利米书 18:16; 耶利米书 1:15"> 我必召北方的众族和我仆人巴比伦王尼布甲尼撒来攻击这地和这地的居民，并四围一切的国民。我要将他们尽行灭绝，以致他们令人惊骇、嗤笑，并且永久荒凉。这是耶和华说的。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 7:34; 启示录 18:22–23; 以西结书 26:13"> 我又要使欢喜和快乐的声音，新郎和新妇的声音，推磨的声音和灯的亮光，从他们中间止息。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 9:2; 撒迦利亚书 1:12; 历代志下 36:21–22"> 这全地必然荒凉，令人惊骇。这些国民要服事巴比伦王七十年。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理书 9:2; 以赛亚书 13:19; 耶利米书 29:10"> 七十年满了以后，我必刑罚巴比伦王和那国民，并迦勒底人之地，因他们的罪孽使那地永远荒凉。这是耶和华说的。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 1:10; 耶利米书 1:5; 但以理书 5:31"> 我也必使我向那地所说的话，就是记在这书上的话，是耶利米向这些国民说的预言，都临到那地。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 51:6; 耶利米书 27:7; 耶利米书 50:9"> 因为有多国和大君王必使迦勒底人作奴仆；我也必照他们的行为，按他们手所做的报应他们。」</span>
</div>
</div>

## 神审判列国

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="诗篇 75:8; 以赛亚书 51:17; 启示录 14:10"> 耶和华—以色列的 神对我如此说：「你从我手中接这杯忿怒的酒，使我所差遣你去的各国的民喝。</span>
<span className="v" id="v16" data-v="16" data-xref="那鸿书 3:11; 耶利米书 51:7; 耶利米书 51:39"> 他们喝了就要东倒西歪，并要发狂，因我使刀剑临到他们中间。」</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="耶利米书 1:10; 耶利米书 25:28; 以西结书 43:3"> 我就从耶和华的手中接了这杯，给耶和华所差遣我去的各国的民喝，</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 24:9; 诗篇 60:3; 耶利米书 44:22"> 就是耶路撒冷和犹大的城邑，并耶路撒冷的君王与首领，使这城邑荒凉，令人惊骇、嗤笑、咒诅，正如今日一样。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 46:13–26; 那鸿书 3:8–10; 耶利米书 46:2"> 又有埃及王法老和他的臣仆、首领，以及他的众民，</span>
<span className="v" id="v20" data-v="20" data-xref="约伯记 1:1; 以西结书 30:5; 以赛亚书 20:1"> 并杂族的人民和乌斯地的诸王，与非利士地的诸王（亚实基伦、迦萨、以革伦，以及亚实突剩下的人）；</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 48:1–22; 诗篇 137:7; 耶利米书 9:26"> 以东、摩押、亚扪人、</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 47:4; 阿摩司书 1:9–10; 以西结书 28:22–23"> 泰尔的诸王、西顿的诸王、海岛的诸王、</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 9:26; 耶利米书 49:32; 耶利米书 49:8"> 底但、提玛、布斯，和一切剃周围头发的；</span>
<span className="v" id="v24" data-v="24" data-xref="历代志下 9:14; 耶利米书 25:20; 以西结书 30:5"> 阿拉伯的诸王、住旷野杂族人民的诸王、</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 11:11; 创世记 10:22; 以赛亚书 13:17"> 心利的诸王、以拦的诸王、米底亚的诸王、</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 51:41; 耶利米书 25:9; 耶利米书 50:1–46"> 北方远近的诸王，以及天下地上的万国喝了，以后示沙克<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是巴比伦">a</a></sup>王也要喝。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米书 25:16; 哈巴谷书 2:16; 以西结书 21:4–5"> 「你要对他们说：『万军之耶和华—以色列的 神如此说：你们要喝，且要喝醉，要呕吐，且要跌倒，不得再起来，都因我使刀剑临到你们中间。』</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约伯记 34:33; 耶利米书 51:29; 以赛亚书 14:24–27"> 「他们若不肯从你手接这杯喝，你就要对他们说：『万军之耶和华如此说：你们一定要喝！</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 38:21; 箴言 11:31; 彼得前书 4:17"> 我既从称为我名下的城起首施行灾祸，你们能尽免刑罚吗？你们必不能免，因为我要命刀剑临到地上一切的居民。这是万军之耶和华说的。』</span>
</div>
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="阿摩司书 1:2; 约珥书 3:16; 以赛亚书 42:13"> 「所以你要向他们预言这一切的话，攻击他们，说：<br /><span className="pl pl-1">耶和华必从高天吼叫，</span><br /><span className="pl pl-1">从圣所发声，</span><br /><span className="pl pl-1">向自己的羊群大声吼叫；</span><br /><span className="pl pl-1">他要向地上一切的居民呐喊，</span><br /><span className="pl pl-1">像踹葡萄的一样。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="何西阿书 4:1; 约珥书 3:2; 以赛亚书 66:16"> <span className="pl pl-1">必有响声达到地极，</span><br /><span className="pl pl-1">因为耶和华与列国相争；</span><br /><span className="pl pl-1">凡有血气的，他必审问；</span><br /><span className="pl pl-1">至于恶人，他必交给刀剑。</span><br /><span className="pl pl-1">这是耶和华说的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="耶利米书 23:19; 以赛亚书 34:2; 历代志下 15:6"> <span className="pl pl-1">万军之耶和华如此说：</span><br /><span className="pl pl-1">看哪，必有灾祸从这国发到那国，</span><br /><span className="pl pl-1">并有大暴风从地极刮起。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 66:16; 耶利米书 8:2; 诗篇 79:3"> 「到那日，从地这边直到地那边都有耶和华所杀戮的。必无人哀哭，不得收殓，不得葬埋，必在地上成为粪土。</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米书 6:26; 耶利米书 50:27; 诗篇 2:9"> <span className="pl pl-1">牧人哪，你们当哀号，呼喊；</span><br /><span className="pl pl-1">群众的头目啊，你们要滚在灰中；</span><br /><span className="pl pl-1">因为你们被杀戮分散的日子足足来到。</span><br /><span className="pl pl-1">你们要跌碎，好像美器打碎一样。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="约伯记 11:20; 阿摩司书 2:14; 耶利米书 52:8–11"> <span className="pl pl-1">牧人无路逃跑；</span><br /><span className="pl pl-1">群众的头目也无法逃脱。</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 4:8; 耶利米书 25:34"> <span className="pl pl-1">听啊，有牧人呼喊，</span><br /><span className="pl pl-1">有群众头目哀号的声音，</span><br /><span className="pl pl-1">因为耶和华使他们的草场变为荒场。</span><br /></span>
<span className="v" id="v37" data-v="37" data-xref="以赛亚书 27:10–11; 以赛亚书 32:14"> <span className="pl pl-1">耶和华发出猛烈的怒气，</span><br /><span className="pl pl-1">平安的羊圈就都寂静无声。</span><br /></span>
<span className="v" id="v38" data-v="38" data-xref="耶利米书 4:7; 耶利米书 5:6; 何西阿书 13:7–8"> <span className="pl pl-1">他离了隐密处像狮子一样，</span><br /><span className="pl pl-1">他们的地，因刀剑凶猛的欺压，</span><br /><span className="pl pl-1">又因他猛烈的怒气都成为可惊骇的。」</span></span>
</div>
</div>

<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="历代志下 36:16; 以西结书 12:22–28; 耶利米书 23:14–17"> <span className="pl pl-1">他们不认耶和华，说：</span><br /><span className="pl pl-1">这并不是他，</span><br /><span className="pl pl-1">灾祸必不临到我们；</span><br /><span className="pl pl-1">刀剑和饥荒，我们也看不见。</span><br /></span>

## 神警告他的子民

<div className="bt">
<div className="bp poetry">
<span className="v" id="v20" data-v="20"> <span className="pl pl-1">当传扬在雅各家，</span><br /><span className="pl pl-1">报告在犹大说：</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 28:26; 以西结书 12:2; 以赛亚书 6:9–10"> <span className="pl pl-1">愚昧无知的百姓啊，</span><br /><span className="pl pl-1">你们有眼不看，</span><br /><span className="pl pl-1">有耳不听，</span><br /><span className="pl pl-1">现在当听这话。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 38:10–11; 诗篇 104:9; 约伯记 26:10"> <span className="pl pl-1">耶和华说：你们怎么不惧怕我呢？</span><br /><span className="pl pl-1">我以永远的定例，</span><br /><span className="pl pl-1">用沙为海的界限，</span><br /><span className="pl pl-1">水不得越过。</span><br /><span className="pl pl-1">因此，你们在我面前还不战兢吗？</span><br /><span className="pl pl-1">波浪虽然翻腾，却不能逾越；</span><br /><span className="pl pl-1">虽然匉訇，却不能过去。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 6:28; 申命记 21:18; 诗篇 95:10"> <span className="pl pl-1">但这百姓有背叛忤逆的心；</span><br /><span className="pl pl-1">他们叛我而去，</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 147:8; 约珥书 2:23; 创世记 8:22"> <span className="pl pl-1">心内也不说：</span><br /><span className="pl pl-1">我们应当敬畏耶和华—我们的 神；</span><br /><span className="pl pl-1">他按时赐雨，就是秋雨春雨，</span><br /><span className="pl pl-1">又为我们定收割的节令，永存不废。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 59:2; 诗篇 107:17; 诗篇 107:34"> <span className="pl pl-1">你们的罪孽使这些事转离你们；</span><br /><span className="pl pl-1">你们的罪恶使你们不能得福。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="箴言 1:11; 诗篇 64:5; 以西结书 22:2–12"> <span className="pl pl-1">因为在我民中有恶人。</span><br /><span className="pl pl-1">他们埋伏窥探，好像捕鸟的人；</span><br /><span className="pl pl-1">他们设立圈套陷害人。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="弥迦书 1:12; 耶利米书 9:6; 何西阿书 12:7–8"> <span className="pl pl-1">笼内怎样满了雀鸟，</span><br /><span className="pl pl-1">他们的房中也照样充满诡诈；</span><br /><span className="pl pl-1">所以他们得成为大，而且富足。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 1:23; 申命记 32:15; 耶利米书 7:6"> <span className="pl pl-1">他们肥胖光润，</span><br /><span className="pl pl-1">作恶过甚，不为人伸冤！</span><br /><span className="pl pl-1">就是不为孤儿伸冤，</span><br /><span className="pl pl-1">不使他亨通，</span><br /><span className="pl pl-1">也不为穷人辨屈。</span><br /></span>

## 耶利米在枯井里

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 7:9; 以斯拉记 2:3; 使徒行传 4:6–10"> 玛坦的儿子示法提雅、巴施户珥的儿子基大利、示利米雅的儿子犹甲、玛基雅的儿子巴施户珥听见耶利米对众人所说的话，说：</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 39:18; 耶利米书 34:17; 耶利米书 45:5"> 「耶和华如此说：住在这城里的必遭刀剑、饥荒、瘟疫而死；但出去归降迦勒底人的必得存活，就是以自己命为掠物的，必得存活。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 21:10; 耶利米书 32:3–5"> 耶和华如此说：这城必要交在巴比伦王军队的手中，他必攻取这城。」</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 26:11; 使徒行传 16:20; 尼希米记 6:9"> 于是首领对王说：「求你将这人治死；因他向城里剩下的兵丁和众民说这样的话，使他们的手发软。这人不是求这百姓得平安，乃是叫他们受灾祸。」</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 19:12–16; 撒母耳记下 3:39; 撒母耳记下 19:22"> 西底家王说：「他在你们手中，无论何事，王也不能与你们反对。」</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 37:21; 耶利米书 38:22; 耶利米书 37:16"> 他们就拿住耶利米，下在哈米勒的儿子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：王的儿子">a</a></sup>玛基雅的牢狱里；那牢狱在护卫兵的院中。他们用绳子将耶利米系下去。牢狱里没有水，只有淤泥，耶利米就陷在淤泥中。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命记 21:19; 阿摩司书 5:10; 耶利米书 29:2"> 在王宫的太监古实人以伯·米勒，听见他们将耶利米下了牢狱（那时王坐在便雅悯门口），</span>
<span className="v" id="v8" data-v="8"> 以伯·米勒就从王宫里出来，对王说：</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 37:21–6; 以斯帖记 7:4–6; 箴言 31:8–9"> 「主—我的王啊，这些人向先知耶利米一味地行恶，将他下在牢狱中；他在那里必因饥饿而死，因为城中再没有粮食。」</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 21:1; 以斯帖记 8:7; 以斯帖记 5:2"> 王就吩咐古实人以伯·米勒说：「你从这里带领三十人，趁着先知耶利米未死以前，将他从牢狱中提上来。」</span>
<span className="v" id="v11" data-v="11"> 于是以伯·米勒带领这些人同去，进入王宫，到库房以下，从那里取了些碎布和破烂的衣服，用绳子缒下牢狱去到耶利米那里。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 12:10; 以弗所书 4:32; 罗马书 12:15"> 古实人以伯·米勒对耶利米说：「你用这些碎布和破烂的衣服放在绳子上，垫你的胳肢窝。」耶利米就照样行了。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 37:21; 使徒行传 28:16; 使徒行传 23:35"> 这样，他们用绳子将耶利米从牢狱里拉上来。耶利米仍在护卫兵的院中。</span>
</div>
</div>

## 西底家问计于耶利米

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米书 37:17; 列王纪上 22:16; 耶利米书 21:1–2"> 西底家王打发人带领先知耶利米，进耶和华殿中第三门里见王。王就对耶利米说：「我要问你一件事，你丝毫不可向我隐瞒。」</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 22:67–68"> 耶利米对西底家说：「我若告诉你，你岂不定要杀我吗？我若劝戒你，你必不听从我。」</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 37:17; 耶利米书 38:1–6; 以赛亚书 57:16"> 西底家王就私下向耶利米说：「我指着那造我们生命之永生的耶和华起誓：我必不杀你，也不将你交在寻索你命的人手中。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="耶利米书 27:12; 耶利米书 27:17; 耶利米书 38:2"> 耶利米对西底家说：「耶和华—万军之 神、以色列的 神如此说：你若出去归降巴比伦王的首领，你的命就必存活，这城也不致被火焚烧，你和你的全家都必存活。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 38:3; 耶利米书 24:8–10; 列王纪下 25:4–10"> 你若不出去归降巴比伦王的首领，这城必交在迦勒底人手中。他们必用火焚烧，你也不得脱离他们的手。」</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 12:42; 耶利米书 38:22; 约翰福音 19:12–13"> 西底家王对耶利米说：「我怕那些投降迦勒底人的犹大人，恐怕迦勒底人将我交在他们手中，他们戏弄我。」</span>
<span className="v" id="v20" data-v="20" data-xref="但以理书 4:27; 以赛亚书 55:3; 耶利米书 26:13"> 耶利米说：「迦勒底人必不将你交出。求你听从我对你所说耶和华的话，这样你必得好处，你的命也必存活。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 2:7; 以西结书 2:4–5; 耶利米书 26:15"> 你若不肯出去，耶和华指示我的话乃是这样：</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 43:6; 耶利米哀歌 1:2; 耶利米哀歌 5:11"> 犹大王宫里所剩的妇女必都带到巴比伦王的首领那里。这些妇女必说：<br /><span className="pl pl-1">你知己的朋友催逼你，</span><br /><span className="pl pl-1">胜过你；</span><br /><span className="pl pl-1">见你的脚陷入淤泥中，</span><br /><span className="pl pl-1">就转身退后了。</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="耶利米书 41:10; 耶利米书 39:6; 耶利米书 38:18"> 「人必将你的后妃和你的儿女带到迦勒底人那里；你也不得脱离他们的手，必被巴比伦王的手捉住；你也必使这城被火焚烧。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 西底家对耶利米说：「不要使人知道这些话，你就不至于死。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 38:27; 耶利米书 38:4–6"> 首领若听见了我与你说话，就来见你，问你说：『你对王说什么话不要向我们隐瞒，我们就不杀你。王向你说什么话也要告诉我们。』</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 37:20; 耶利米书 37:15; 以斯帖记 4:8"> 你就对他们说：『我在王面前恳求不要叫我回到约拿单的房屋死在那里。』」</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 10:15–16; 列王纪下 6:19; 使徒行传 23:6"> 随后众首领来见耶利米，问他，他就照王所吩咐的一切话回答他们。他们不再与他说话，因为事情没有泄漏。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 37:21; 耶利米书 39:14; 诗篇 23:4"> 于是耶利米仍在护卫兵的院中，直到耶路撒冷被攻取的日子。</span>
</div>
</div>

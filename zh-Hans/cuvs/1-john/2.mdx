## 我们的中保基督

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太前书 2:5; 罗马书 8:34; 约翰福音 14:6"> 我小子们哪，我将这些话写给你们，是要叫你们不犯罪。若有人犯罪，在父那里我们有一位中保，就是那义者耶稣基督。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 4:14; 彼得前书 3:18; 约翰一书 4:10"> 他为我们的罪作了挽回祭，不是单为我们的罪，也是为普天下人的罪。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 14:15; 约翰福音 15:10; 路加福音 6:46"> 我们若遵守他的诫命，就晓得是认识他。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰一书 1:6; 提多书 1:16; 雅各书 2:14–16"> 人若说「我认识他」，却不遵守他的诫命，便是说谎话的，真理也不在他心里了。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 14:23; 约翰福音 14:21; 约翰一书 4:12–13"> 凡遵守主道的，爱 神的心在他里面实在是完全的。从此，我们知道我们是在主里面。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前书 2:21; 约翰福音 13:15; 哥林多前书 11:1"> 人若说他住在主里面，就该自己照主所行的去行。</span>
</div>
</div>

## 新命令

<div className="bt">
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="约翰一书 3:11; 利未记 19:18; 马可福音 12:29–34"> 亲爱的弟兄啊，我写给你们的，不是一条新命令，乃是你们从起初所受的旧命令；这旧命令就是你们所听见的道。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 5:8; 罗马书 13:12; 约翰福音 13:34"> 再者，我写给你们的，是一条新命令，在主是真的，在你们也是真的；因为黑暗渐渐过去，真光已经照耀。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 4:20; 约翰一书 2:11; 约翰一书 3:13–17"> 人若说自己在光明中，却恨他的弟兄，他到如今还是在黑暗里。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 3:14; 罗马书 9:32–33; 罗马书 14:13"> 爱弟兄的，就是住在光明中，在他并没有绊跌的缘由。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 12:35; 提多书 3:3; 约翰一书 1:6"> 惟独恨弟兄的，是在黑暗里，且在黑暗里行，也不知道往哪里去，因为黑暗叫他眼睛瞎了。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 10:43; 使徒行传 13:38; 以弗所书 1:7"> <span className="pl pl-1">小子们哪，我写信给你们，</span><br /><span className="pl pl-1">因为你们的罪借着主名得了赦免。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 14:7; 约翰一书 2:14; 路加福音 10:22"> <span className="pl pl-1">父老啊，我写信给你们，</span><br /><span className="pl pl-1">因为你们认识那从起初原有的。</span><br /><span className="pl pl-1">少年人哪，我写信给你们，</span><br /><span className="pl pl-1">因为你们胜了那恶者。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 119:11; 约翰一书 2:13; 歌罗西书 3:16"> <span className="pl pl-1">小子们哪，我曾写信给你们，</span><br /><span className="pl pl-1">因为你们认识父。</span><br /><span className="pl pl-1">父老啊，我曾写信给你们，</span><br /><span className="pl pl-1">因为你们认识那从起初原有的。</span><br /><span className="pl pl-1">少年人哪，我曾写信给你们；</span><br /><span className="pl pl-1">因为你们刚强，</span><br /><span className="pl pl-1">神的道常存在你们心里；</span><br /><span className="pl pl-1">你们也胜了那恶者。</span></span>
<span className="v" id="v15" data-v="15" data-xref="雅各书 4:4; 罗马书 12:2; 马太福音 6:24"> 不要爱世界和世界上的事。人若爱世界，爱父的心就不在他里面了。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 13:14; 加拉太书 5:17; 诗篇 119:36–37"> 因为，凡世界上的事，就像肉体的情欲、眼目的情欲，并今生的骄傲，都不是从父来的，乃是从世界来的。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 24:35; 罗马书 12:2; 哥林多前书 7:31"> 这世界和其上的情欲都要过去，惟独遵行 神旨意的，是永远常存。</span>
</div>
</div>

## 敌基督者

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰一书 4:3; 约翰二书 1:7; 马太福音 24:24"> 小子们哪，如今是末时了。你们曾听见说，那敌基督的要来；现在已经有好些敌基督的出来了，从此我们就知道如今是末时了。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 20:30; 哥林多前书 11:19; 路加福音 8:13"> 他们从我们中间出去，却不是属我们的；若是属我们的，就必仍旧与我们同在；他们出去，显明都不是属我们的。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 14:26; 约翰一书 2:27; 哥林多后书 1:21–22"> 你们从那圣者受了恩膏，并且知道这一切的事<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：都有知识">a</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得后书 1:12; 犹大书 1:5; 箴言 1:5"> 我写信给你们，不是因你们不知道真理，正是因你们知道，并且知道没有虚谎是从真理出来的。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰二书 1:7; 约翰一书 4:3; 约翰一书 2:18"> 谁是说谎话的呢？不是那不认耶稣为基督的吗？不认父与子的，这就是敌基督的。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰一书 4:15; 约翰福音 8:19; 约翰福音 5:23"> 凡不认子的，就没有父；认子的，连父也有了。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 14:23; 约翰福音 15:9–10; 约翰一书 4:13"> 论到你们，务要将那从起初所听见的，常存在心里。若将从起初所听见的存在心里，你们就必住在子里面，也必住在父里面。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 10:28; 提多书 3:7; 犹大书 1:21"> 主所应许我们的就是永生。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得后书 2:1–3; 约翰二书 1:7; 使徒行传 20:29–30"> 我将这些话写给你们，是指着那引诱你们的人说的。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 14:26; 约翰一书 2:20–21; 哥林多前书 2:13"> 你们从主所受的恩膏常存在你们心里，并不用人教训你们，自有主的恩膏在凡事上教训你们。这恩膏是真的，不是假的；你们要按这恩膏的教训住在主里面。</span>
</div>
</div>

<div className="bp">

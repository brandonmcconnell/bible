<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 1:12; 加拉太书 3:26; 哥林多后书 6:18"> 你看父赐给我们是何等的慈爱，使我们得称为 神的儿女；我们也真是他的儿女。世人所以不认识我们，是因未曾认识他。</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比书 3:21; 歌罗西书 3:4; 哥林多前书 13:12"> 亲爱的弟兄啊，我们现在是 神的儿女，将来如何，还未显明；但我们知道，主若显现，我们必要像他，因为必得见他的真体。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 7:1; 约翰一书 2:6; 彼得后书 3:14"> 凡向他有这指望的，就洁净自己，像他洁净一样。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰一书 5:17; 罗马书 3:20; 罗马书 4:15"> 凡犯罪的，就是违背律法；违背律法就是罪。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 5:21; 希伯来书 9:28; 彼得前书 3:18"> 你们知道主曾显现，是要除掉人的罪，在他并没有罪。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰三书 1:11; 约翰一书 2:4; 约翰一书 3:9"> 凡住在他里面的，就不犯罪；凡犯罪的，是未曾看见他，也未曾认识他。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰一书 2:29; 彼得前书 1:15–16; 罗马书 2:13"> 小子们哪，不要被人诱惑。行义的才是义人，正如主是义的一样。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 2:14; 约翰福音 8:44; 歌罗西书 2:15"> 犯罪的是属魔鬼，因为魔鬼从起初就犯罪。 神的儿子显现出来，为要除灭魔鬼的作为。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 5:18; 彼得前书 1:23; 约翰福音 1:13"> 凡从 神生的，就不犯罪，因 神的道<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是种">a</a></sup>存在他心里；他也不能犯罪，因为他是由 神生的。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 4:8; 约翰三书 1:11; 路加福音 6:35"> 从此就显出谁是 神的儿女，谁是魔鬼的儿女。凡不行义的就不属 神，不爱弟兄的也是如此。</span>
</div>
</div>

## 彼此相爱

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约翰福音 15:12; 约翰二书 1:5; 约翰一书 4:7"> 我们应当彼此相爱。这就是你们从起初所听见的命令。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 11:4; 创世记 4:4–15; 箴言 29:27"> 不可像该隐；他是属那恶者，杀了他的兄弟。为什么杀了他呢？因自己的行为是恶的，兄弟的行为是善的。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 15:18–19; 约翰福音 17:14; 路加福音 21:17"> 弟兄们，世人若恨你们，不要以为希奇。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 13:35; 约翰一书 5:2; 约翰一书 4:20–21"> 我们因为爱弟兄，就晓得是已经出死入生了。没有爱心的，仍住在死中。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 5:21–22; 箴言 26:24–26; 启示录 21:8"> 凡恨他弟兄的，就是杀人的；你们晓得凡杀人的，没有永生存在他里面。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰一书 4:9–11; 以弗所书 5:2; 约翰福音 13:34"> 主为我们舍命，我们从此就知道何为爱；我们也当为弟兄舍命。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 13:16; 以赛亚书 58:7–10; 申命记 15:7–11"> 凡有世上财物的，看见弟兄穷乏，却塞住怜恤的心，爱 神的心怎能存在他里面呢？</span>
<span className="v" id="v18" data-v="18" data-xref="雅各书 2:15–16; 罗马书 12:9; 彼得前书 1:22"> 小子们哪，我们相爱，不要只在言语和舌头上，总要在行为和诚实上。</span>
</div>
</div>

## 在 神面前安稳

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="希伯来书 10:22; 约翰一书 3:21; 希伯来书 6:10–11"> 从此就知道我们是属真理的，并且我们的心在 神面前可以安稳。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 139:1–4; 耶利米书 17:10; 希伯来书 4:13"> 我们的心若责备我们， 神比我们的心大，一切事没有不知道的。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 2:28; 希伯来书 4:16; 哥林多后书 1:12"> 亲爱的弟兄啊，我们的心若不责备我们，就可以向 神坦然无惧了。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 15:7; 约翰福音 9:31; 约翰一书 5:14"> 并且我们一切所求的，就从他得着；因为我们遵守他的命令，行他所喜悦的事。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 6:29; 约翰福音 13:34; 彼得前书 1:22"> 神的命令就是叫我们信他儿子耶稣基督的名，且照他所赐给我们的命令彼此相爱。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 3:16; 约翰一书 4:15–16; 约翰一书 4:12–13"> 遵守 神命令的，就住在 神里面， 神也住在他里面。我们所以知道 神住在我们里面是因他所赐给我们的圣灵。</span>
</div>
</div>

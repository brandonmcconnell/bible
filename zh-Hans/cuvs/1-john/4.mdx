## 神的灵和敌基督者的灵

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 5:21; 彼得后书 2:1; 提摩太前书 4:1"> 亲爱的弟兄啊，一切的灵，你们不可都信，总要试验那些灵是出于 神的不是，因为世上有许多假先知已经出来了。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 1:14; 哥林多前书 12:3; 提摩太前书 3:16"> 凡灵认耶稣基督是成了肉身来的，就是出于 神的；从此你们可以认出 神的灵来。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰一书 2:22; 约翰二书 1:7; 约翰一书 2:18"> 凡灵不认耶稣，就不是出于 神，这是那敌基督者的灵。你们从前听见他要来，现在已经在世上了。</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 8:31; 约翰一书 5:4; 罗马书 8:37"> 小子们哪，你们是属 神的，并且胜了他们；因为那在你们里面的，比那在世界上的更大。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 8:23; 彼得后书 2:2–3; 约翰福音 17:14"> 他们是属世界的，所以论世界的事，世人也听从他们。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 14:17; 约翰福音 10:27; 哥林多前书 2:12–14"> 我们是属 神的，认识 神的就听从我们；不属 神的就不听从我们。从此我们可以认出真理的灵和谬妄的灵来。</span>
</div>
</div>

## 神就是爱

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约翰一书 4:20–1; 约翰一书 4:8; 彼得前书 1:22"> 亲爱的弟兄啊，我们应当彼此相爱，因为爱是从 神来的。凡有爱心的，都是由 神而生，并且认识 神。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰一书 4:16; 诗篇 86:15; 哥林多后书 13:11"> 没有爱心的，就不认识 神，因为 神就是爱。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 3:16; 约翰一书 5:11; 罗马书 8:32"> 神差他独生子到世间来，使我们借着他得生， 神爱我们的心在此就显明了。</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 2:4–5; 罗马书 5:8–10; 约翰一书 4:19"> 不是我们爱 神，乃是 神爱我们，差他的儿子为我们的罪作了挽回祭，这就是爱了。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 15:12–13; 歌罗西书 3:13; 约翰福音 13:34"> 亲爱的弟兄啊， 神既是这样爱我们，我们也当彼此相爱。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 1:18; 约翰一书 2:5; 约翰一书 4:17–18"> 从来没有人见过 神，我们若彼此相爱， 神就住在我们里面，爱他的心在我们里面得以完全了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以弗所书 2:20–22; 约翰一书 3:24; 哥林多前书 3:16–17"> 神将他的灵赐给我们，从此就知道我们是住在他里面，他也住在我们里面。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰一书 4:10; 约翰福音 3:16–17; 约翰福音 4:42"> 父差子作世人的救主；这是我们所看见且作见证的。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 10:9; 约翰一书 5:5; 马太福音 10:32"> 凡认耶稣为 神儿子的， 神就住在他里面，他也住在 神里面。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰一书 3:24; 诗篇 36:7–9; 约翰一书 3:1"> 神爱我们的心，我们也知道也信。<br />神就是爱；住在爱里面的，就是住在 神里面， 神也住在他里面。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰一书 4:12; 约翰一书 2:28; 罗马书 8:29"> 这样，爱在我们里面得以完全，我们就可以在审判的日子坦然无惧。因为他如何，我们在这世上也如何。</span>
<span className="v" id="v18" data-v="18" data-xref="提摩太后书 1:7; 罗马书 8:15; 约翰一书 4:12"> 爱里没有惧怕；爱既完全，就把惧怕除去。因为惧怕里含着刑罚，惧怕的人在爱里未得完全。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 4:10; 约翰福音 3:16; 约翰福音 15:16"> 我们爱，因为 神先爱我们。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰一书 3:17; 约翰一书 2:9; 约翰一书 4:12"> 人若说「我爱 神」，却恨他的弟兄，就是说谎话的；不爱他所看见的弟兄，就不能爱没有看见的 神<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷：怎能爱没有看见的 神呢">a</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 22:37–39; 利未记 19:18; 约翰一书 3:11"> 爱 神的，也当爱弟兄，这是我们从 神所受的命令。</span>
</div>
</div>

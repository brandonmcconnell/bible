## 约书亚在示剑向百姓讲话

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 23:2; 撒母耳记上 10:19; 创世记 33:18–19"> 约书亚将以色列的众支派聚集在示剑，召了以色列的长老、族长、审判官，并官长来，他们就站在 神面前。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 24:15; 以西结书 16:3; 创世记 31:30"> 约书亚对众民说：「耶和华—以色列的 神如此说：『古时你们的列祖，就是亚伯拉罕和拿鹤的父亲他拉，住在大河那边事奉别神，</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 12:1–4; 创世记 21:2–3; 使徒行传 7:2–3"> 我将你们的祖宗亚伯拉罕从大河那边带来，领他走遍迦南全地，又使他的子孙众多，把以撒赐给他；</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 36:8; 申命记 2:5; 创世记 25:24–26"> 又把雅各和以扫赐给以撒，将西珥山赐给以扫为业；后来雅各和他的子孙下到埃及去了。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 3:10; 出埃及记 7:1–12; 诗篇 105:26–36"> 我差遣摩西、亚伦，并照我在埃及中所行的降灾与埃及，然后把你们领出来。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 7:36; 希伯来书 11:29; 以赛亚书 63:12–13"> 我领你们列祖出埃及，他们就到了红海；埃及人带领车辆马兵追赶你们列祖到红海。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 4:34; 出埃及记 14:10; 出埃及记 14:20"> 你们列祖哀求耶和华，他就使你们和埃及人中间黑暗了，又使海水淹没埃及人。我在埃及所行的事，你们亲眼见过。你们在旷野也住了许多年日。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 21:21–35; 诗篇 135:10–11; 尼希米记 9:22"> 我领你们到约旦河东亚摩利人所住之地。他们与你们争战，我将他们交在你们手中，你们便得了他们的地为业；我也在你们面前将他们灭绝。</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 11:25; 弥迦书 6:5; 民数记 22:2"> 那时，摩押王西拨的儿子巴勒起来攻击以色列人，打发人召了比珥的儿子巴兰来咒诅你们。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 23:5; 民数记 24:5–10; 以赛亚书 54:17"> 我不肯听巴兰的话，所以他倒为你们连连祝福。这样，我便救你们脱离巴勒的手。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 4:10–12; 约书亚记 3:14–17; 诗篇 114:5"> 你们过了约旦河，到了耶利哥；耶利哥人、亚摩利人、比利洗人、迦南人、赫人、革迦撒人、希未人、耶布斯人都与你们争战；我把他们交在你们手里。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 7:20; 出埃及记 23:28; 诗篇 44:3–6"> 我打发黄蜂飞在你们前面，将亚摩利人的二王从你们面前撵出，并不是用你的刀，也不是用你的弓。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 6:10–12; 申命记 8:7; 约书亚记 21:45"> 我赐给你们地土，非你们所修治的；我赐给你们城邑，非你们所建造的。你们就住在其中，又得吃非你们所栽种的葡萄园、橄榄园的果子。』</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 12:24; 申命记 10:12; 创世记 35:2"> 「现在你们要敬畏耶和华，诚心实意地事奉他，将你们列祖在大河那边和在埃及所事奉的神除掉，去事奉耶和华。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 18:21; 约翰福音 6:67–68; 路得记 1:15–16"> 若是你们以事奉耶和华为不好，今日就可以选择所要事奉的：是你们列祖在大河那边所事奉的神呢？是你们所住这地的亚摩利人的神呢？至于我和我家，我们必定事奉耶和华。」</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 10:38–39; 撒母耳记上 12:23; 罗马书 6:2"> 百姓回答说：「我们断不敢离弃耶和华去事奉别神；</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 19:4; 以赛亚书 63:7–14; 以赛亚书 46:4"> 因耶和华—我们的 神曾将我们和我们列祖从埃及地的为奴之家领出来，在我们眼前行了那些大神迹，在我们所行的道上，所经过的诸国，都保护了我们。</span>
<span className="v" id="v18" data-v="18" data-xref="弥迦书 4:2; 出埃及记 10:2; 诗篇 116:16"> 耶和华又把住此地的亚摩利人都从我们面前赶出去。所以，我们必事奉耶和华，因为他是我们的 神。」</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 5:16; 出埃及记 23:21; 诗篇 99:9"> 约书亚对百姓说：「你们不能事奉耶和华；因为他是圣洁的 神，是忌邪的 神，必不赦免你们的过犯罪恶。</span>
<span className="v" id="v20" data-v="20" data-xref="希伯来书 10:26–27; 以西结书 18:24; 历代志上 28:9"> 你们若离弃耶和华去事奉外邦神，耶和华在降福之后，必转而降祸与你们，把你们灭绝。」</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 20:19; 以赛亚书 44:5; 申命记 5:27–28"> 百姓回答约书亚说：「不然，我们定要事奉耶和华。」</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 119:173; 诗篇 119:11; 约伯记 15:6"> 约书亚对百姓说：「你们选定耶和华，要事奉他，你们自己作见证吧！」他们说：「我们愿意作见证。」</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 6:16–18; 约书亚记 24:14; 希伯来书 12:28–29"> 约书亚说：「你们现在要除掉你们中间的外邦神，专心归向耶和华—以色列的 神。」</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 24:7; 出埃及记 24:3; 申命记 5:27–29"> 百姓回答约书亚说：「我们必事奉耶和华—我们的 神，听从他的话。」</span>
<span className="v" id="v25" data-v="25" data-xref="尼希米记 9:38; 历代志下 23:16; 出埃及记 15:25"> 当日，约书亚就与百姓立约，在示剑为他们立定律例典章。</span>
<span className="v" id="v26" data-v="26" data-xref="士师记 9:6; 创世记 35:4; 约书亚记 4:20–24"> 约书亚将这些话都写在 神的律法书上，又将一块大石头立在橡树下耶和华的圣所旁边。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 19:40; 约书亚记 22:34; 约书亚记 22:27–28"> 约书亚对百姓说：「看哪，这石头可以向我们作见证；因为是听见了耶和华所吩咐我们的一切话，倘或你们背弃你们的 神，这石头就可以向你们作见证<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="倘或…见证：或译所以要向你们作见证，免得你们背弃耶和华—你们的 神">a</a></sup>。」</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 2:6"> 于是约书亚打发百姓各归自己的地业去了。</span>
</div>
</div>

## 约书亚和以利亚撒去世

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="士师记 2:8; 提摩太后书 4:7–8; 申命记 34:5"> 这些事以后，耶和华的仆人嫩的儿子约书亚，正一百一十岁，就死了。</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 19:50; 士师记 2:9; 撒母耳记下 23:30"> 以色列人将他葬在他地业的境内，就是在以法莲山地的亭拿·西拉，在迦实山的北边。</span>
<span className="v" id="v31" data-v="31" data-xref="士师记 2:7; 申命记 31:13; 申命记 11:2"> 约书亚在世和约书亚死后，那些知道耶和华为以色列人所行诸事的长老还在的时候，以色列人事奉耶和华。</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 50:25; 创世记 33:19; 出埃及记 13:19"> 以色列人从埃及所带来约瑟的骸骨，葬埋在示剑，就是在雅各从前用一百块银子向示剑的父亲、哈抹的子孙所买的那块地里；这就作了约瑟子孙的产业。</span>
<span className="v" id="v33" data-v="33" data-xref="约书亚记 22:13; 出埃及记 6:25; 以赛亚书 57:1–2"> 亚伦的儿子以利亚撒也死了，就把他葬在他儿子非尼哈所得以法莲山地的小山上。</span>

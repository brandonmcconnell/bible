## 余地的分配

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 19:51; 撒母耳记上 1:3; 约书亚记 21:2"> 以色列的全会众都聚集在示罗，把会幕设立在那里，那地已经被他们制伏了。</span>
<span className="v" id="v2" data-v="2"> 以色列人中其余的七个支派还没有分给他们地业。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 18:9; 箴言 13:4; 箴言 10:4"> 约书亚对以色列人说：「耶和华—你们列祖的 神所赐给你们的地，你们耽延不去得，要到几时呢？</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 18:6; 约书亚记 4:2; 约书亚记 18:3"> 你们每支派当选举三个人，我要打发他们去，他们就要起身走遍那地，按着各支派应得的地业写明<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：画图">a</a></sup>，就回到我这里来。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 16:1–10; 约书亚记 19:1–9; 约书亚记 15:1–12"> 他们要将地分做七分；犹大仍在南方，住在他的境内。约瑟家仍在北方，住在他的境内。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 14:2; 约书亚记 18:10; 使徒行传 13:19"> 你们要将地分做七分，写明了拿到我这里来。我要在耶和华—我们 神面前，为你们拈阄。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 13:33; 约书亚记 13:8–31; 民数记 18:20"> 利未人在你们中间没有分，因为供耶和华祭司的职任就是他们的产业。迦得支派、吕便支派，和玛拿西半支派已经在约旦河东得了地业，就是耶和华仆人摩西所给他们的。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约书亚记 18:10; 罗马书 14:19; 撒母耳记上 14:41"> 划地势的人起身去的时候，约书亚嘱咐他们说：「你们去走遍那地，划明地势，就回到我这里来。我要在示罗这里，耶和华面前，为你们拈阄。」</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 13:19"> 他们就去了，走遍那地，按着城邑分做七分，写在册子上，回到示罗营中见约书亚。</span>
<span className="v" id="v10" data-v="10" data-xref="歌罗西书 1:12; 使徒行传 13:19; 约书亚记 18:6"> 约书亚就在示罗，耶和华面前，为他们拈阄。约书亚在那里，按着以色列人的支派，将地分给他们。</span>
</div>
</div>

## 分给便雅悯支派的土地

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约书亚记 16:1–10; 约书亚记 15:1–8; 申命记 10:1–22"> 便雅悯支派，按着宗族拈阄所得之地，是在犹大、约瑟子孙中间。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 16:1; 约书亚记 7:2; 约书亚记 2:1"> 他们的北界是从约旦河起，往上贴近耶利哥的北边；又往西通过山地，直到伯·亚文的旷野；</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 28:19; 约书亚记 16:2–3; 约书亚记 10:11"> 从那里往南接连到路斯，贴近路斯（路斯就是伯特利），又下到亚他绿·亚达，靠近下伯·和 南边的山；</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 15:9; 历代志上 13:5–6; 撒母耳记上 7:1–2"> 从那里往西，又转向南，从伯·和 南对面的山，直达到犹大人的城基列·巴力（基列·巴力就是基列·耶琳）；这是西界。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 15:9"> 南界是从基列·耶琳的尽边起，往西达到尼弗多亚的水源；</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 23:10; 约书亚记 15:7–8; 以赛亚书 30:33"> 又下到欣嫩子谷对面山的尽边，就是利乏音谷北边的山；又下到欣嫩谷，贴近耶布斯的南边；又下到隐·罗结；</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 15:6"> 又往北通到隐·示麦，达到亚都冥坡对面的基利绿；又下到吕便之子波罕的磐石；</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 15:6; 约书亚记 15:61"> 又接连到亚拉巴对面，往北下到亚拉巴；</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 14:3; 约书亚记 15:2; 民数记 34:3"> 又接连到伯·曷拉的北边，直通到盐海的北汊，就是约旦河的南头；这是南界。</span>
<span className="v" id="v20" data-v="20"> 东界是约旦河。这是便雅悯人按着宗族，照他们四围的交界所得的地业。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约书亚记 18:12; 约书亚记 6:1; 约书亚记 18:19"> 便雅悯支派按着宗族所得的城邑就是：耶利哥、伯·曷拉、伊麦·基悉、</span>
<span className="v" id="v22" data-v="22" data-xref="约书亚记 15:6; 列王纪上 12:29–32; 约书亚记 18:18"> 伯·亚拉巴、洗玛脸、伯特利、</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 13:17"> 亚文、巴拉、俄弗拉、</span>
<span className="v" id="v24" data-v="24" data-xref="以斯拉记 2:26; 约书亚记 21:17; 以赛亚书 10:29"> 基法·阿摩尼、俄弗尼、迦巴，共十二座城，还有属城的村庄；</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 9:17; 列王纪上 3:4–5; 约书亚记 10:2"> 又有基遍、拉玛、比录、</span>
<span className="v" id="v26" data-v="26" data-xref="士师记 10:17; 以斯拉记 2:25; 约书亚记 9:17"> 米斯巴、基非拉、摩撒、</span>
<span className="v" id="v27" data-v="27"> 利坚、伊利毗勒、他拉拉、</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 21:14; 约书亚记 15:8; 士师记 20:4–5"> 洗拉、以利弗、耶布斯（耶布斯就是耶路撒冷）、基比亚、基列，共十四座城，还有属城的村庄。这是便雅悯人按着宗族所得的地业。</span>
</div>
</div>

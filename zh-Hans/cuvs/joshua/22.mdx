## 约书亚打发二支派半的人回去

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 32:18–33; 申命记 29:7–8"> 当时，约书亚召了吕便人、迦得人，和玛拿西半支派的人来，</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 1:12–18; 申命记 3:16–20; 民数记 32:20–29"> 对他们说：「耶和华仆人摩西所吩咐你们的，你们都遵守了；我所吩咐你们的，你们也都听从了。</span>
<span className="v" id="v3" data-v="3" data-xref="腓立比书 1:23–27"> 你们这许多日子，总没有撇离你们的弟兄，直到今日，并守了耶和华—你们 神所吩咐你们当守的。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 13:8; 民数记 32:18; 申命记 3:20"> 如今耶和华—你们 神照着他所应许的，使你们弟兄得享平安，现在可以转回你们的帐棚，到耶和华的仆人摩西在约旦河东所赐你们为业之地。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 22:37; 出埃及记 20:6; 罗马书 8:28"> 只要切切地谨慎遵行耶和华仆人摩西所吩咐你们的诫命律法，爱耶和华—你们的 神，行他一切的道，守他的诫命，专靠他，尽心尽性事奉他。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约书亚记 14:13; 路加福音 24:50; 创世记 47:7"> 于是约书亚为他们祝福，打发他们去，他们就回自己的帐棚去了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约书亚记 17:1–12; 民数记 32:33; 约书亚记 13:29–31"> 玛拿西那半支派，摩西早已在巴珊分给他们地业。这半支派，约书亚在约旦河西，在他们弟兄中，分给他们地业。约书亚打发他们回帐棚的时候为他们祝福，</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 31:27; 申命记 8:9–14; 箴言 3:16"> 对他们说：「你们带许多财物，许多牲畜和金、银、铜、铁，并许多衣服，回你们的帐棚去，要将你们从仇敌夺来的物，与你们众弟兄同分。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数记 32:29; 民数记 32:26; 民数记 32:1"> 于是吕便人、迦得人、玛拿西半支派的人从迦南地的示罗起行，离开以色列人，回往他们得为业的基列地，就是照耶和华借摩西所吩咐的得了为业之地。</span>
</div>
</div>

## 约旦河旁的祭坛

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约书亚记 24:26–27; 创世记 31:46–52; 约书亚记 4:5–9"> 吕便人、迦得人，和玛拿西半支派的人到了靠近约旦河的一带迦南地，就在约旦河那里筑了一座坛；那坛看着高大。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 13:12–14; 利未记 17:8–9; 约书亚记 2:7"> 以色列人听说吕便人、迦得人、玛拿西半支派的人靠近约旦河边，在迦南地属以色列人的那边筑了一座坛。</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 20:1–11; 申命记 13:15; 加拉太书 4:17–18"> 全会众一听见，就聚集在示罗，要上去攻打他们。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 25:7; 诗篇 106:30–31; 出埃及记 6:25"> 以色列人打发祭司以利亚撒的儿子非尼哈，往基列地去见吕便人、迦得人、玛拿西半支派的人；</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 1:4; 出埃及记 18:25"> 又打发十个首领与非尼哈同去，就是以色列每支派的一个首领，都是以色列军中的统领。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 21:3; 撒母耳记上 15:23; 申命记 30:17"> 他们到了基列地，见吕便人、迦得人，和玛拿西半支派的人，对他们说：</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 12:13–14"> 「耶和华全会众这样说，你们今日转去不跟从耶和华，干犯以色列的 神，为自己筑一座坛，悖逆了耶和华，这犯的是什么罪呢？</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 25:1–18; 诗篇 106:28–29; 申命记 4:3–4"> 从前拜毗珥的罪孽还算小吗？虽然瘟疫临到耶和华的会众，到今日我们还没有洗净这罪。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 16:22; 约书亚记 22:16; 约书亚记 7:11"> 你们今日竟转去不跟从耶和华吗？你们今日既悖逆耶和华，明日他必向以色列全会众发怒。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 18:1; 历代志下 11:16–17; 使徒行传 10:14–15"> 你们所得为业之地，若嫌不洁净，就可以过到耶和华之地，就是耶和华的帐幕所住之地，在我们中间得地业。只是不可悖逆耶和华，也不可得罪我们，在耶和华—我们 神的坛以外为自己筑坛。</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 7:1; 约书亚记 7:5; 约书亚记 7:18"> 从前谢拉的曾孙亚干岂不是在那当灭的物上犯了罪，就有忿怒临到以色列全会众吗？那人在所犯的罪中不独一人死亡。」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="雅各书 1:19; 箴言 16:1; 彼得前书 3:15"> 于是吕便人、迦得人、玛拿西半支派的人回答以色列军中的统领说：</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 8:39; 诗篇 44:21; 申命记 10:17"> 「大能者 神耶和华！大能者 神耶和华！他是知道的！以色列人也必知道！我们若有悖逆的意思，或是干犯耶和华（愿你今日不保佑我们），</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 20:16; 申命记 18:19; 以西结书 3:18"> 为自己筑坛，要转去不跟从耶和华，或是要将燔祭、素祭、平安祭献在坛上，愿耶和华亲自讨我们的罪。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 4:6; 申命记 6:20; 创世记 30:33"> 我们行这事并非无故，是特意做的，说：恐怕日后你们的子孙对我们的子孙说：『你们与耶和华—以色列的 神有何关涉呢？</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 12:16; 以斯拉记 4:2–3; 撒母耳记上 26:19"> 因为耶和华把约旦河定为我们和你们这吕便人、迦得人的交界，你们与耶和华无分了。』这样，你们的子孙就使我们的子孙不再敬畏耶和华了。</span>
<span className="v" id="v26" data-v="26"> 因此我们说：『不如为自己筑一座坛，不是为献燔祭，也不是为献别的祭，</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 24:27; 创世记 31:48; 申命记 12:17–18"> 乃是为你我中间和你我后人中间作证据，好叫我们也在耶和华面前献燔祭、平安祭，和别的祭事奉他，免得你们的子孙日后对我们的子孙说，你们与耶和华无分了。』</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 25:40; 以西结书 43:10–11; 希伯来书 8:5"> 所以我们说：『日后你们对我们，或对我们的后人这样说，我们就可以回答说，你们看我们列祖所筑的坛是耶和华坛的样式；这并不是为献燔祭，也不是为献别的祭，乃是为作你我中间的证据。』</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 24:16; 申命记 12:13–14; 约书亚记 22:23"> 我们在耶和华—我们 神帐幕前的坛以外，另筑一座坛，为献燔祭、素祭，和别的祭，悖逆耶和华，今日转去不跟从他，我们断没有这个意思。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约书亚记 22:33; 以斯帖记 1:21; 箴言 15:1"> 祭司非尼哈与会中的首领，就是与他同来以色列军中的统领，听见吕便人、迦得人、玛拿西人所说的话，就都以为美。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志下 15:2; 利未记 26:11–12; 以赛亚书 12:6"> 祭司以利亚撒的儿子非尼哈对吕便人、迦得人、玛拿西人说：「今日我们知道耶和华在我们中间，因为你们没有向他犯了这罪。现在你们救以色列人脱离耶和华的手了。」</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="约书亚记 22:12–14; 箴言 25:13"> 祭司以利亚撒的儿子非尼哈与众首领离了吕便人、迦得人，从基列地回往迦南地，到了以色列人那里，便将这事回报他们。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志上 29:20; 路加福音 2:28; 但以理书 2:19"> 以色列人以这事为美，就称颂 神，不再提上去攻打吕便人、迦得人、毁坏他们所住的地了。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="约书亚记 22:27; 马太福音 4:10; 以赛亚书 43:10"> 吕便人、迦得人给坛起名叫证坛，意思说：这坛在我们中间证明耶和华是 神。</span>
</div>
</div>

</div>

## 约书亚派探子进耶利哥

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 11:31; 雅各书 2:25; 马太福音 1:5"> 当下，嫩的儿子约书亚从什亭暗暗打发两个人作探子，吩咐说：「你们去窥探那地和耶利哥。」于是二人去了，来到一个妓女名叫喇合的家里，就在那里躺卧。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 43:13; 但以理书 4:35; 箴言 21:30"> 有人告诉耶利哥王说：「今夜有以色列人来到这里窥探此地。」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 10:3; 创世记 42:9–12; 使徒行传 12:6"> 耶利哥王打发人去见喇合说：「那来到你这里、进了你家的人要交出来，因为他们来窥探全地。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 6:19; 撒母耳记下 17:19–20; 撒母耳记下 16:18–19"> 女人将二人隐藏，就回答说：「那人果然到我这里来；他们是哪里来的我却不知道。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 50:20; 以西结书 47:12; 启示录 21:25"> 天黑、要关城门的时候，他们出去了，往哪里去我却不知道。你们快快地去追赶，就必追上。」（</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 11:23; 雅各书 2:25; 歌罗西书 3:3"> 先是女人领二人上了房顶，将他们藏在那里所摆的麻秸中。）</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 3:28; 约书亚记 2:5; 士师记 12:5"> 那些人就往约旦河的渡口追赶他们去了。追赶他们的人一出去，城门就关了。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 二人还没有躺卧，女人就上房顶，到他们那里，</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 23:27; 申命记 2:25; 约书亚记 2:11"> 对他们说：「我知道耶和华已经把这地赐给你们，并且因你们的缘故我们都惊慌了。这地的一切居民在你们面前心都消化了；</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 21:21–35; 出埃及记 15:14–16; 出埃及记 14:21–31"> 因为我们听见你们出埃及的时候，耶和华怎样在你们前面使红海的水干了，并且你们怎样待约旦河东的两个亚摩利王西宏和噩，将他们尽行毁灭。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 4:39; 约书亚记 5:1; 约书亚记 7:5"> 我们一听见这些事，心就消化了。因你们的缘故，并无一人有胆气。耶和华—你们的 神本是上天下地的 神。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 2:18; 约书亚记 9:18–20; 提摩太后书 1:16–18"> 现在我既是恩待你们，求你们指着耶和华向我起誓，也要恩待我父家，并给我一个实在的证据，</span>
<span className="v" id="v13" data-v="13"> 要救活我的父母、弟兄、姊妹，和一切属他们的，拯救我们性命不死。」</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 5:7; 士师记 1:24–25; 创世记 24:49"> 二人对她说：「你若不泄漏我们这件事，我们情愿替你们死。耶和华将这地赐给我们的时候，我们必以慈爱诚实待你。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行传 9:25; 哥林多后书 11:33; 约书亚记 6:20"> 于是女人用绳子将二人从窗户里缒下去；因她的房子是在城墙边上，她也住在城墙上。</span>
<span className="v" id="v16" data-v="16" data-xref="雅各书 2:25; 撒母耳记上 23:14; 诗篇 11:1"> 她对他们说：「你们且往山上去，恐怕追赶的人碰见你们；要在那里隐藏三天，等追赶的人回来，然后才可以走你们的路。」</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 30:2; 撒母耳记下 21:7; 创世记 24:3–8"> 二人对她说：「你要这样行。不然，你叫我们所起的誓就与我们无干了。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 6:23; 约书亚记 2:21; 约书亚记 2:12–13"> 我们来到这地的时候，你要把这条朱红线绳系在缒我们下去的窗户上，并要使你的父母、弟兄，和你父的全家都聚集在你家中。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 27:31; 列王纪上 2:36–42; 出埃及记 12:13"> 凡出了你家门往街上去的，他的罪<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是血">a</a></sup>必归到自己的头上，与我们无干了。凡在你家里的，若有人下手害他，流他血的罪就归到我们的头上。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 11:13"> 你若泄漏我们这件事，你叫我们所起的誓就与我们无干了。」</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 2:5; 约书亚记 2:18; 马太福音 7:24"> 女人说：「照你们的话行吧！」于是打发他们去了，又把朱红线绳系在窗户上。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 19:10–12; 撒母耳记下 17:20; 诗篇 32:6–7"> 二人到山上，在那里住了三天，等着追赶的人回去了。追赶的人一路找他们，却找不着。</span>
<span className="v" id="v23" data-v="23"> 二人就下山回来，过了河，到嫩的儿子约书亚那里，向他述说所遭遇的一切事；</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 23:31; 约书亚记 1:8; 约书亚记 2:9–11"> 又对约书亚说：「耶和华果然将那全地交在我们手中；那地的一切居民在我们面前心都消化了。」</span>
</div>
</div>

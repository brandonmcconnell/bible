## 利未人的城邑

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 14:1; 约书亚记 19:51; 约书亚记 17:4"> 那时，利未人的众族长来到祭司以利亚撒和嫩的儿子约书亚，并以色列各支派的族长面前，</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 18:1; 民数记 35:2–8; 马太福音 10:10"> 在迦南地的示罗对他们说：「从前耶和华借着摩西吩咐给我们城邑居住，并城邑的郊野可以牧养我们的牲畜。」</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 49:7; 申命记 33:8–10; 历代志上 6:54–81"> 于是以色列人照耶和华所吩咐的，从自己的地业中，将以下所记的城邑和城邑的郊野给了利未人。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="历代志上 6:54–60; 约书亚记 24:33; 约书亚记 21:8–19"> 为哥辖族拈阄：利未人的祭司、亚伦的子孙，从犹大支派、西缅支派、便雅悯支派的地业中，按阄得了十三座城。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 21:20–26; 出埃及记 6:16–25; 历代志上 6:66–70"> 哥辖其余的子孙，从以法莲支派、但支派、玛拿西半支派的地业中，按阄得了十座城。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约书亚记 21:27–33; 历代志上 6:71–76; 出埃及记 6:16–17"> 革顺的子孙，从以萨迦支派、亚设支派、拿弗他利支派、住巴珊的玛拿西半支派的地业中，按阄得了十三座城。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约书亚记 21:34–40; 历代志上 6:77–81; 出埃及记 6:19"> 米拉利的子孙，按着宗族，从吕便支派、迦得支派、西布伦支派的地业中，按阄得了十二座城。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约书亚记 21:3; 约书亚记 18:6; 民数记 33:54"> 以色列人照着耶和华借摩西所吩咐的，将这些城邑和城邑的郊野，按阄分给利未人。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="历代志上 6:65; 约书亚记 21:13–18"> 从犹大支派、西缅支派的地业中，将以下所记的城给了利未支派哥辖宗族亚伦的子孙；因为给他们拈出头一阄，</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 6:55; 路加福音 1:39; 撒母耳记下 5:1–5"> 将犹大山地的基列·亚巴和四围的郊野给了他们。亚巴是亚衲族的始祖。（基列·亚巴就是希伯 ）。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 14:13–15; 历代志上 6:55–57"> 惟将属城的田地和村庄给了耶孚尼的儿子迦勒为业。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约书亚记 15:42; 约书亚记 10:29; 约书亚记 15:54"> 以色列人将希伯 ，就是误杀人的逃城和属城的郊野，给了祭司亚伦的子孙；又给他们立拿和属城的郊野，</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 15:48; 约书亚记 15:50; 撒母耳记上 30:27–28"> 雅提珥和属城的郊野，以实提莫和属城的郊野，</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 15:49; 约书亚记 15:51; 约书亚记 12:13"> 何 和属城的郊野，底璧和属城的郊野，</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 15:10; 历代志上 6:59; 约书亚记 15:55"> 亚因和属城的郊野，淤他和属城的郊野，伯·示麦和属城的郊野，共九座城，都是从这二支派中分出来的。</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 18:24–25; 约书亚记 9:3; 历代志上 6:60"> 又从便雅悯支派的地业中给了他们基遍和属城的郊野，迦巴和属城的郊野，</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 10:30; 历代志上 6:60; 耶利米书 1:1"> 亚拿突和属城的郊野，亚勒们和属城的郊野，共四座城。</span>
<span className="v" id="v19" data-v="19"> 亚伦子孙作祭司的共有十三座城，还有属城的郊野。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="历代志上 6:66; 约书亚记 21:5"> 利未支派中哥辖的宗族，就是哥辖其余的子孙，拈阄所得的城有从以法莲支派中分出来的。</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 20:7; 士师记 9:1; 列王纪上 12:1"> 以色列人将以法莲山地的示剑，就是误杀人的逃城和属城的郊野，给了他们；又给他们基色和属城的郊野，</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 6:68; 约书亚记 16:3; 约书亚记 18:13–14"> 基伯先和属城的郊野，伯·和 和属城的郊野，共四座城；</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 19:44–45"> 又从但支派的地业中给了他们伊利提基和属城的郊野，基比顿和属城的郊野，</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 19:42; 约书亚记 10:12; 历代志上 6:69"> 亚雅 和属城的郊野，迦特·临门和属城的郊野，共四座城；</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 17:11; 士师记 5:19"> 又从玛拿西半支派的地业中给了他们他纳和属城的郊野，迦特·临门和属城的郊野，共两座城。</span>
<span className="v" id="v26" data-v="26"> 哥辖其余的子孙共有十座城，还有属城的郊野。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="历代志上 6:71; 申命记 1:4; 约书亚记 20:8"> 以色列人又从玛拿西半支派的地业中将巴珊的哥兰，就是误杀人的逃城和属城的郊野，给了利未支派革顺的子孙；又给他们比·施提拉和属城的郊野，共两座城；</span>
<span className="v" id="v28" data-v="28" data-xref="约书亚记 19:12; 历代志上 6:72–73"> 又从以萨迦支派的地业中给了他们基善和属城的郊野，大比拉和属城的郊野，</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 10:23; 约书亚记 12:11; 约书亚记 10:3"> 耶末和属城的郊野，隐·干宁和属城的郊野，共四座城；</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 6:74–75; 约书亚记 19:25–28"> 又从亚设支派的地业中给了他们米沙勒和属城的郊野，押顿和属城的郊野，</span>
<span className="v" id="v31" data-v="31" data-xref="士师记 18:21; 历代志上 6:75; 士师记 1:31"> 黑甲和属城的郊野，利合和属城的郊野，共四座城；</span>
<span className="v" id="v32" data-v="32" data-xref="历代志上 6:76; 约书亚记 20:7; 约书亚记 19:37"> 又从拿弗他利支派的地业中将加利利的基低斯，就是误杀人的逃城和属城的郊野，给了他们；又给他们哈末·多珥和属城的郊野，加珥坦和属城的郊野，共三座城。</span>
<span className="v" id="v33" data-v="33"> 革顺人按着宗族所得的城，共十三座，还有属城的郊野。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="历代志上 6:77; 约书亚记 19:11; 约书亚记 21:7"> 其余利未支派米拉利子孙，从西布伦支派的地业中所得的，就是约念和属城的郊野，加珥他和属城的郊野，</span>
<span className="v" id="v35" data-v="35"> 丁拿和属城的郊野，拿哈拉和属城的郊野，共四座城；</span>
<span className="v" id="v36" data-v="36" data-xref="约书亚记 20:8; 申命记 4:43; 民数记 21:23"> 又从吕便支派的地业中给了他们比悉和属城的郊野，雅杂和属城的郊野，</span>
<span className="v" id="v37" data-v="37"> 基底莫和属城的郊野，米法押和属城的郊野，共四座城；</span>
<span className="v" id="v38" data-v="38" data-xref="创世记 32:2; 列王纪上 22:3; 历代志上 6:80"> 又从迦得支派的地业中，将基列的拉末，就是误杀人的逃城和属城的郊野，给了他们；又给他们玛哈念和属城的郊野，</span>
<span className="v" id="v39" data-v="39" data-xref="以赛亚书 16:8–9; 民数记 32:35; 民数记 32:1"> 希实本和属城的郊野，雅谢和属城的郊野，共四座城。</span>
<span className="v" id="v40" data-v="40"> 其余利未支派的人，就是米拉利的子孙，按着宗族拈阄所得的，共十二座城。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数记 35:1–8; 申命记 33:10; 创世记 49:7"> 利未人在以色列人的地业中所得的城，共四十八座，并有属城的郊野。</span>
<span className="v" id="v42" data-v="42"> 这些城四围都有属城的郊野，城城都是如此。</span>
</div>
</div>

## 以色列人得地为业

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="创世记 13:15; 诗篇 106:42–45; 出埃及记 23:27–31"> 这样，耶和华将从前向他们列祖起誓所应许的全地赐给以色列人，他们就得了为业，住在其中。</span>
<span className="v" id="v44" data-v="44" data-xref="约书亚记 11:23; 希伯来书 4:9; 申命记 31:3–5"> 耶和华照着向他们列祖起誓所应许的一切话，使他们四境平安；他们一切仇敌中，没有一人在他们面前站立得住。耶和华把一切仇敌都交在他们手中。</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪上 8:56; 约书亚记 23:14–15; 民数记 23:19"> 耶和华应许赐福给以色列家的话一句也没有落空，都应验了。</span>
</div>

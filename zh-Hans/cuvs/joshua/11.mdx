## 约书亚击败耶宾和他的盟国

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 11:10; 诗篇 2:1–4; 士师记 4:2"> 夏琐王耶宾听见这事，就打发人去见玛顿王约巴、伸 王、押煞王，</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 12:3; 士师记 1:27; 约书亚记 17:11"> 与北方山地、基尼烈南边的亚拉巴高原，并西边多珥山冈的诸王；</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 3:3; 约书亚记 18:26; 创世记 31:49"> 又去见东方和西方的迦南人，与山地的亚摩利人、赫人、比利洗人、耶布斯人，并黑门山根米斯巴地的希未人。</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 7:12; 撒母耳记上 13:5; 创世记 32:12"> 这些王和他们的众军都出来，人数多如海边的沙，并有许多马匹车辆。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 118:10–12; 启示录 16:14; 以赛亚书 8:9"> 这诸王会合，来到米伦水边，一同安营，要与以色列人争战。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 10:8; 撒母耳记下 8:4; 士师记 20:28"> 耶和华对约书亚说：「你不要因他们惧怕。明日这时，我必将他们交付以色列人全然杀了。你要砍断他们马的蹄筋，用火焚烧他们的车辆。」</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 10:9; 帖撒罗尼迦前书 5:2–3"> 于是约书亚率领一切兵丁，在米伦水边突然向前攻打他们。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 13:6; 约书亚记 19:28; 撒迦利亚书 9:2"> 耶和华将他们交在以色列人手里，以色列人就击杀他们，追赶他们到西顿大城，到米斯利弗·玛音，直到东边米斯巴的平原，将他们击杀，没有留下一个。</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 11:6; 以西结书 39:9–10"> 约书亚就照耶和华所吩咐他的去行，砍断他们马的蹄筋，用火焚烧他们的车辆。</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 11:1; 士师记 4:2"> 当时，约书亚转回夺了夏琐，用刀击杀夏琐王。（素来夏琐在这诸国中是为首的。）</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 10:40; 申命记 20:16"> 以色列人用刀击杀城中的人口，将他们尽行杀灭；凡有气息的没有留下一个。约书亚又用火焚烧夏琐。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 20:16–17; 申命记 7:2; 民数记 33:50–53"> 约书亚夺了这些王的一切城邑，擒获其中的诸王，用刀击杀他们，将他们尽行杀灭，正如耶和华仆人摩西所吩咐的。</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 30:18"> 至于造在山冈上的城，除了夏琐以外，以色列人都没有焚烧。约书亚只将夏琐焚烧了。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 20:14; 民数记 31:9; 约书亚记 8:27"> 那些城邑所有的财物和牲畜，以色列人都取为自己的掠物；惟有一切人口都用刀击杀，直到杀尽；凡有气息的没有留下一个。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 1:7; 出埃及记 34:11–13; 使徒行传 20:20"> 耶和华怎样吩咐他仆人摩西，摩西就照样吩咐约书亚，约书亚也照样行。凡耶和华所吩咐摩西的，约书亚没有一件懈怠不行的。</span>
</div>
</div>

## 约书亚占领的土地

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约书亚记 10:41; 约书亚记 11:21; 约书亚记 12:8"> 约书亚夺了那全地，就是山地、一带南地、歌珊全地、高原、亚拉巴、以色列的山地，和山下的高原。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 7:24; 约书亚记 11:3; 约书亚记 13:5"> 从上西珥的哈拉山，直到黑门山下黎巴嫩平原的巴力·迦得，并且擒获那些地的诸王，将他们杀死。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 14:7–10; 约书亚记 11:23"> 约书亚和这诸王争战了许多年日。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 9:3–27"> 除了基遍的希未人之外，没有一城与以色列人讲和的，都是以色列人争战夺来的。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 9:18; 申命记 20:16–17; 出埃及记 4:21"> 因为耶和华的意思是要使他们心里刚硬，来与以色列人争战，好叫他们尽被杀灭，不蒙怜悯，正如耶和华所吩咐摩西的。</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 9:2; 民数记 13:22–23; 约书亚记 15:13–14"> 当时约书亚来到，将住山地、希伯 、底璧、亚拿伯、犹大山地、以色列山地所有的亚衲族人剪除了。约书亚将他们和他们的城邑尽都毁灭。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 17:4; 历代志上 18:1; 约书亚记 15:46"> 在以色列人的地没有留下一个亚衲族人，只在迦萨、迦特，和亚实突有留下的。</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 21:44–45; 民数记 26:52–55; 约书亚记 14:1–15"> 这样，约书亚照着耶和华所吩咐摩西的一切话夺了那全地，就按着以色列支派的宗族将地分给他们为业。于是国中太平，没有争战了。</span>
</div>

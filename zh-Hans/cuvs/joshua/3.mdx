## 以色列人过约旦河

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 2:1; 马可福音 1:35; 民数记 25:1"> 约书亚清早起来，和以色列众人都离开什亭，来到约旦河，就住在那里，等候过河。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 1:10–11"> 过了三天，官长走遍营中，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 31:9; 撒母耳记下 6:13; 申命记 31:25"> 吩咐百姓说：「你们看见耶和华—你们 神的约柜，又见祭司利未人抬着，就要离开所住的地方，跟着约柜去。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 89:7; 希伯来书 12:28–29; 出埃及记 3:5"> 只是你们和约柜相离要量二千肘，不可与约柜相近，使你们知道所当走的路，因为这条路你们向来没有走过。」</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 7:13; 利未记 20:7; 约珥书 2:16"> 约书亚吩咐百姓说：「你们要自洁，因为明天耶和华必在你们中间行奇事。」</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 14:2–3; 民数记 14:15; 弥迦书 2:13"> 约书亚又吩咐祭司说：「你们抬起约柜，在百姓前头过去。」于是他们抬起约柜，在百姓前头走。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 4:14; 约书亚记 1:5; 历代志上 29:25"> 耶和华对约书亚说：「从今日起，我必使你在以色列众人眼前尊大，使他们知道我怎样与摩西同在，也必照样与你同在。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 3:3; 约书亚记 3:17; 历代志下 29:15"> 你要吩咐抬约柜的祭司说：『你们到了约旦河的水边上，就要在约旦河水里站住。』」</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 4:1; 申命记 12:8"> 约书亚对以色列人说：「你们近前来，听耶和华—你们 神的话。」</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 7:1; 出埃及记 33:2; 诗篇 44:2–3"> 约书亚说：「看哪，普天下主的约柜必在你们前头过去，到约旦河里，因此你们就知道在你们中间有永生 神；并且他必在你们面前赶出迦南人、赫人、希未人、比利洗人、革迦撒人、亚摩利人、耶布斯人。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 4:2; 约书亚记 4:9; 约书亚记 4:4"> 你们现在要从以色列支派中拣选十二个人，每支派一人，</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 15:8; 诗篇 78:13; 约书亚记 3:15–16"> 等到抬普天下主耶和华约柜的祭司把脚站在约旦河水里，约旦河的水，就是从上往下流的水，必然断绝，立起成垒。」</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 7:44–45; 约书亚记 6:6; 哥林多前书 1:24–25"> 百姓离开帐棚要过约旦河的时候，抬约柜的祭司乃在百姓的前头。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 12:15; 约书亚记 4:18; 约书亚记 3:13"> 他们到了约旦河，脚一入水（原来约旦河水在收割的日子涨过两岸），</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 3:13; 列王纪上 4:12; 列王纪上 7:46"> 那从上往下流的水便在极远之地、撒拉但旁的亚当城那里停住，立起成垒；那往亚拉巴的海，就是盐海，下流的水全然断绝。于是百姓在耶利哥的对面过去了。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 14:22; 出埃及记 14:29; 诗篇 66:6"> 抬耶和华约柜的祭司在约旦河中的干地上站定，以色列众人都从干地上过去，直到国民尽都过了约旦河。</span>

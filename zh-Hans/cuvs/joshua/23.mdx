## 约书亚的遗言

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 13:1; 约书亚记 21:44; 约书亚记 11:23"> 耶和华使以色列人安静，不与四围的一切仇敌争战，已经多日。约书亚年纪老迈，</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 24:1; 申命记 31:28; 历代志上 28:1"> 就把以色列众人的长老、族长、审判官，并官长都召了来，对他们说：「我年纪已经老迈。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 14:14; 约书亚记 10:42; 约书亚记 10:14"> 耶和华—你们的 神因你们的缘故向那些国所行的一切事，你们亲眼看见了，因那为你们争战的是耶和华—你们的 神。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 13:6–7; 约书亚记 18:10; 约书亚记 13:2"> 我所剪除和所剩下的各国，从约旦河起到日落之处的大海，我已经拈阄分给你们各支派为业。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 11:23; 约书亚记 13:6; 出埃及记 33:2"> 耶和华—你们的 神必将他们从你们面前赶出去，使他们离开你们，你们就必得他们的地为业，正如耶和华—你们的 神所应许的。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 5:32; 申命记 28:14; 箴言 4:26–27"> 所以，你们要大大壮胆，谨守遵行写在摩西律法书上的一切话，不可偏离左右。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 23:13; 诗篇 16:4; 申命记 7:2–3"> 不可与你们中间所剩下的这些国民搀杂。他们的神，你们不可提他的名，不可指着他起誓，也不可事奉、叩拜；</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 10:20; 约书亚记 22:5; 申命记 13:4"> 只要照着你们到今日所行的，专靠耶和华—你们的 神。</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 1:5; 申命记 11:23; 约书亚记 23:5"> 因为耶和华已经把又大又强的国民从你们面前赶出；直到今日，没有一人在你们面前站立得住。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 32:30; 利未记 26:8; 申命记 3:22"> 你们一人必追赶千人，因耶和华—你们的 神照他所应许的，为你们争战。</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 22:5; 申命记 6:5–12; 箴言 4:23"> 你们要分外谨慎，爱耶和华—你们的 神。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 7:3; 以西结书 18:24; 西番雅书 1:6"> 你们若稍微转去，与你们中间所剩下的这些国民联络，彼此结亲，互相往来，</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 7:16; 民数记 33:55; 出埃及记 23:33"> 你们要确实知道，耶和华—你们的 神必不再将他们从你们眼前赶出；他们却要成为你们的网罗、机槛、肋上的鞭、眼中的刺，直到你们在耶和华—你们 神所赐的这美地上灭亡。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 21:33; 列王纪上 2:2; 利未记 26:3–13"> 「我现在要走世人必走的路。你们是一心一意地知道，耶和华—你们 神所应许赐福与你们的话没有一句落空，都应验在你们身上了。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 28:15–68; 利未记 26:14–46; 士师记 3:8"> 耶和华—你们 神所应许的一切福气怎样临到你们身上，耶和华也必照样使各样祸患临到你们身上，直到把你们从耶和华—你们 神所赐的这美地上除灭。</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 4:25–26; 列王纪下 24:20"> 你们若违背耶和华—你们 神吩咐你们所守的约，去事奉别神，叩拜他，耶和华的怒气必向你们发作，使你们在他所赐的美地上速速灭亡。」</span>
</div>

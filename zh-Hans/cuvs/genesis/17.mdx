## 割礼—立约的记号

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="腓立比书 4:13; 以弗所书 3:20; 路加福音 1:6"> 亚伯兰年九十九岁的时候，耶和华向他显现，对他说：「我是全能的 神。你当在我面前作完全人，</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 17:4–6; 创世记 12:2; 诗篇 105:8–11"> 我就与你立约，使你的后裔极其繁多。」</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 13:20; 创世记 17:17; 民数记 16:45"> 亚伯兰俯伏在地； 神又对他说：</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 35:11; 加拉太书 3:28–29; 创世记 12:2"> 「我与你立约：你要作多国的父。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 1:21–23; 尼希米记 9:7; 创世记 17:15"> 从此以后，你的名不再叫亚伯兰，要叫亚伯拉罕，因为我已立你作多国的父。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 17:4; 马太福音 1:6–17; 创世记 35:11"> 我必使你的后裔极其繁多；国度从你而立，君王从你而出。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 9:7–9; 使徒行传 2:39; 创世记 26:24"> 我要与你并你世世代代的后裔坚立我的约，作永远的约，是要作你和你后裔的 神。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 26:12; 诗篇 105:11; 出埃及记 6:7"> 我要将你现在寄居的地，就是迦南全地，赐给你和你的后裔永远为业，我也必作他们的 神。」</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 56:4–5; 诗篇 25:10; 诗篇 103:18"> 神又对亚伯拉罕说：「你和你的后裔必世世代代遵守我的约。</span>
<span className="v" id="v10" data-v="10" data-xref="歌罗西书 2:11–12; 罗马书 4:9–11; 使徒行传 7:8"> 你们所有的男子都要受割礼；这就是我与你并你的后裔所立的约，是你们所当遵守的。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 4:11; 使徒行传 7:8; 申命记 10:16"> 你们都要受割礼<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是割阳皮；十四、二十三、二十四、二十五节同">a</a></sup>；这是我与你们立约的证据。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 12:3; 路加福音 2:21; 出埃及记 12:48–49"> 你们世世代代的男子，无论是家里生的，是在你后裔之外用银子从外人买的，生下来第八日，都要受割礼。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 12:44; 创世记 37:36; 尼希米记 5:8"> 你家里生的和你用银子买的，都必须受割礼。这样，我的约就立在你们肉体上作永远的约。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 4:24–26; 民数记 15:30–31; 出埃及记 12:19"> 但不受割礼的男子必从民中剪除，因他背了我的约。」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 12:25; 创世记 32:28; 创世记 17:5"> 神又对亚伯拉罕说：「你的妻子撒莱不可再叫撒莱，她的名要叫撒拉。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 35:11; 创世记 17:6; 以赛亚书 49:23"> 我必赐福给她，也要使你从她得一个儿子。我要赐福给她，她也要作多国之母；必有百姓的君王从她而出。」</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 11:16; 创世记 21:6; 创世记 18:12"> 亚伯拉罕就俯伏在地喜笑，心里说：「一百岁的人还能得孩子吗？撒拉已经九十岁了，还能生养吗？」</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 2:39; 诗篇 41:12; 诗篇 4:6"> 亚伯拉罕对 神说：「但愿以实玛利活在你面前。」</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 1:13–20; 创世记 21:2–3; 列王纪下 4:16–17"> 神说：「不然，你妻子撒拉要给你生一个儿子，你要给他起名叫以撒。我要与他坚定所立的约，作他后裔永远的约。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 21:18; 创世记 21:13; 创世记 25:12–18"> 至于以实玛利，我也应允你：我必赐福给他，使他昌盛，极其繁多。他必生十二个族长；我也要使他成为大国。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 21:2–3; 创世记 26:2–5; 加拉太书 3:29"> 到明年这时节，撒拉必给你生以撒，我要与他坚定所立的约。」</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 18:33; 创世记 35:9–15; 士师记 6:21"> 神和亚伯拉罕说完了话，就离开他上升去了。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 119:60; 创世记 18:19; 创世记 17:10–14"> 正当那日，亚伯拉罕遵着 神的命，给他的儿子以实玛利和家里的一切男子，无论是在家里生的，是用银子买的，都行了割礼。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 4:11; 创世记 17:17; 罗马书 4:19–20"> 亚伯拉罕受割礼的时候年九十九岁。</span>
<span className="v" id="v25" data-v="25"> 他儿子以实玛利受割礼的时候年十三岁。</span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 119:60; 创世记 22:3–4; 创世记 12:4"> 正当那日，亚伯拉罕和他儿子以实玛利一同受了割礼。</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 18:19"> 家里所有的人，无论是在家里生的，是用银子从外人买的，也都一同受了割礼。</span>
</div>

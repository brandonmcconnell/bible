## 雅各准备迎见以扫

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 91:11; 诗篇 34:7; 希伯来书 1:4"> 雅各仍旧行路， 神的使者遇见他。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 2:8; 约书亚记 5:14; 约书亚记 21:38"> 雅各看见他们就说：「这是 神的军兵」，于是给那地方起名叫玛哈念<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是二军兵的意思">a</a></sup>。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 25:30; 约书亚记 24:4; 申命记 2:5"> 雅各打发人先往西珥地去，就是以东地，见他哥哥以扫，</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前书 3:6; 路加福音 14:11; 创世记 33:8"> 吩咐他们说：「你们对我主以扫说：『你的仆人雅各这样说：我在拉班那里寄居，直到如今。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 33:8; 创世记 33:15; 创世记 33:11"> 我有牛、驴、羊群、仆婢，现在打发人来报告我主，为要在你眼前蒙恩。』」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 33:1; 创世记 32:8; 创世记 32:11"> 所打发的人回到雅各那里，说：「我们到了你哥哥以扫那里，他带着四百人，正迎着你来。」</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 35:3; 哥林多后书 1:8–10; 出埃及记 14:10"> 雅各就甚惧怕，而且愁烦，便把那与他同在的人口和羊群、牛群、骆驼分做两队，</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 10:16; 创世记 33:1–3"> 说：「以扫若来击杀这一队，剩下的那一队还可以逃避。」</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 31:42; 诗篇 34:4–6; 创世记 31:3"> 雅各说：「耶和华—我祖亚伯拉罕的 神，我父亲以撒的 神啊，你曾对我说：『回你本地本族去，我要厚待你。』</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 18:35; 创世记 24:27; 撒母耳记下 7:18"> 你向仆人所施的一切慈爱和诚实，我一点也不配得；我先前只拿着我的杖过这约旦河，如今我却成了两队了。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 59:1–2; 箴言 18:19; 马太福音 6:13"> 求你救我脱离我哥哥以扫的手；因为我怕他来杀我，连妻子带儿女一同杀了。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 28:13–15; 希伯来书 6:17; 提多书 1:2"> 你曾说：『我必定厚待你，使你的后裔如同海边的沙，多得不可胜数。』」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 18:16; 创世记 43:11; 箴言 19:6"> 当夜，雅各在那里住宿，就从他所有的物中拿礼物要送给他哥哥以扫：</span>
<span className="v" id="v14" data-v="14" data-xref="约伯记 1:3; 申命记 8:18; 约伯记 42:12"> 母山羊二百只，公山羊二十只，母绵羊二百只，公绵羊二十只，</span>
<span className="v" id="v15" data-v="15"> 奶崽子的骆驼三十只—各带着崽子，母牛四十只，公牛十只，母驴二十匹，驴驹十匹；</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 33:8–9; 创世记 32:20; 箴言 2:11"> 每样各分一群，交在仆人手下，就对仆人说：「你们要在我前头过去，使群群相离，有空闲的地方」；</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 33:3"> 又吩咐尽先走的说：「我哥哥以扫遇见你的时候，问你说：『你是哪家的人？要往哪里去？你前头这些是谁的？』</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 32:4–5"> 你就说：『是你仆人雅各的，是送给我主以扫的礼物；他自己也在我们后边。』」</span>
<span className="v" id="v19" data-v="19"> 又吩咐第二、第三，和一切赶群畜的人说：「你们遇见以扫的时候也要这样对他说；</span>
<span className="v" id="v20" data-v="20" data-xref="约伯记 42:8–9; 箴言 21:14; 创世记 43:11"> 并且你们要说：『你仆人雅各在我们后边。』」因雅各心里说：「我借着在我前头去的礼物解他的恨，然后再见他的面，或者他容纳我。」</span>
<span className="v" id="v21" data-v="21"> 于是礼物先过去了；那夜，雅各在队中住宿。</span>
</div>
</div>

## 雅各在毗努伊勒摔跤

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命记 3:16; 申命记 2:37; 提摩太前书 5:8"> 他夜间起来，带着两个妻子，两个使女，并十一个儿子，都过了雅博渡口，</span>
<span className="v" id="v23" data-v="23"> 先打发他们过河，又打发所有的都过去，</span>
<span className="v" id="v24" data-v="24" data-xref="何西阿书 12:3–5; 以弗所书 6:12; 路加福音 13:24"> 只剩下雅各一人。有一个人来和他摔跤，直到黎明。</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多后书 12:7–9; 何西阿书 12:3–4; 马太福音 26:41"> 那人见自己胜不过他，就将他的大腿窝摸了一把，雅各的大腿窝正在摔跤的时候就扭了。</span>
<span className="v" id="v26" data-v="26" data-xref="何西阿书 12:4; 诗篇 115:12–13; 哥林多后书 12:8–9"> 那人说：「天黎明了，容我去吧！」雅各说：「你不给我祝福，我就不容你去。」</span>
<span className="v" id="v27" data-v="27"> 那人说：「你名叫什么？」他说：「我名叫雅各。」</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 2:17; 创世记 35:10; 以赛亚书 62:2–4"> 那人说：「你的名不要再叫雅各，要叫以色列；因为你与 神与人较力，都得了胜。」</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 9:6; 士师记 13:16–18; 约伯记 11:7"> 雅各问他说：「请将你的名告诉我。」那人说：「何必问我的名？」于是在那里给雅各祝福。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 24:10–11; 民数记 12:8; 以赛亚书 6:5"> 雅各便给那地方起名叫毗努伊勒<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就是 神之面的意思">b</a></sup>，意思说：「我面对面见了 神，我的性命仍得保全。」</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多后书 12:7; 创世记 19:15; 士师记 8:8"> 日头刚出来的时候，雅各经过毗努伊勒，他的大腿就瘸了。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 5:5"> 故此，以色列人不吃大腿窝的筋，直到今日，因为那人摸了雅各大腿窝的筋。</span>
</div>
</div>

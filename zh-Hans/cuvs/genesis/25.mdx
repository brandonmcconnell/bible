## 亚伯拉罕的其他后代

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 1:32–33; 创世记 23:1–2; 创世记 28:1"> 亚伯拉罕又娶了一妻，名叫基土拉。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 1:32–33; 民数记 25:17–18; 约伯记 2:11"> 基土拉给他生了心兰、约珊、米但、米甸、伊施巴，和书亚。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 25:13; 耶利米书 49:8; 以西结书 27:20"> 约珊生了示巴和底但。底但的子孙是亚书利族、利都是族，和利乌米族。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 60:6"> 米甸的儿子是以法、以弗、哈诺、亚比大，和以勒大。这都是基土拉的子孙。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 24:36; 希伯来书 1:2; 加拉太书 3:29"> 亚伯拉罕将一切所有的都给了以撒。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 21:14; 士师记 6:3; 使徒行传 14:17"> 亚伯拉罕把财物分给他庶出的众子，趁着自己还在世的时候打发他们离开他的儿子以撒，往东方去。</span>
</div>
</div>

## 亚伯拉罕的死和埋葬

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="创世记 12:4"> 亚伯拉罕一生的年日是一百七十五岁。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 35:28–29; 创世记 15:15; 历代志上 29:28"> 亚伯拉罕寿高年迈，气绝而死，归到他列祖<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是本民">a</a></sup>那里。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 50:13; 创世记 35:29; 创世记 49:29–30"> 他两个儿子以撒、以实玛利把他埋葬在麦比拉洞里。这洞在幔利前、赫人琐辖的儿子以弗 的田中，</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 23:16; 创世记 49:31"> 就是亚伯拉罕向赫人买的那块田。亚伯拉罕和他妻子撒拉都葬在那里。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 22:17; 创世记 16:14; 创世记 24:62"> 亚伯拉罕死了以后， 神赐福给他的儿子以撒。以撒靠近庇耳·拉海·莱居住。</span>
</div>
</div>

## 以实玛利的后代

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="诗篇 83:6; 创世记 17:20; 创世记 21:13"> 撒拉的使女埃及人夏甲给亚伯拉罕所生的儿子是以实玛利。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 1:29–31; 以赛亚书 60:7; 雅歌 1:5"> 以实玛利儿子们的名字，按着他们的家谱记在下面。以实玛利的长子是尼拜约，又有基达、亚德别、米比衫、</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 21:11; 以赛亚书 21:16"> 米施玛、度玛、玛撒、</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 5:19; 约伯记 2:11"> 哈大、提玛、伊突、拿非施、基底玛。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 17:20; 创世记 17:23"> 这是以实玛利众子的名字，照着他们的村庄、营寨，作了十二族的族长。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 15:15; 创世记 25:7–8"> 以实玛利享寿一百三十七岁，气绝而死，归到他列祖<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是本民">b</a></sup>那里。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 16:12; 创世记 20:1; 列王纪下 23:29"> 他子孙的住处在他众弟兄东边，从哈腓拉直到埃及前的书珥，正在亚述的道上。</span>
</div>
</div>

## 以扫和雅各出生

<div className="bt">
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="马太福音 1:2; 路加福音 3:34; 使徒行传 7:8"> 亚伯拉罕的儿子以撒的后代记在下面。亚伯拉罕生以撒。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 24:29; 创世记 24:67; 创世记 22:23"> 以撒娶利百加为妻的时候正四十岁。利百加是巴旦·亚兰地的亚兰人彼土利的女儿，是亚兰人拉班的妹子。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:13; 以赛亚书 58:9; 以斯拉记 8:23"> 以撒因他妻子不生育，就为她祈求耶和华；耶和华应允他的祈求，他的妻子利百加就怀了孕。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 9:9; 撒母耳记上 28:6; 撒母耳记上 30:8"> 孩子们在她腹中彼此相争，她就说：「若是这样，我为什么活着呢<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或译：我为什么如此呢">c</a></sup>？」她就去求问耶和华。</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 9:10–13; 创世记 27:40; 创世记 27:29"> 耶和华对她说：<br /><span className="pl pl-1">两国在你腹内；</span><br /><span className="pl pl-1">两族要从你身上出来。</span><br /><span className="pl pl-1">这族必强于那族；</span><br /><span className="pl pl-1">将来大的要服事小的。</span></span>
<span className="v" id="v24" data-v="24"> 生产的日子到了，腹中果然是双子。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 27:11; 创世记 27:16; 创世记 27:23"> 先产的身体发红，浑身有毛，如同皮衣，他们就给他起名叫以扫<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="就是有毛的意思">d</a></sup>。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 27:36; 何西阿书 12:3; 创世记 38:28–30"> 随后又生了以扫的兄弟，手抓住以扫的脚跟，因此给他起名叫雅各<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="就是抓住的意思">e</a></sup>。利百加生下两个儿子的时候，以撒年正六十岁。</span>
</div>
</div>

## 以扫出卖长子的名分

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="希伯来书 11:9; 创世记 21:20; 创世记 10:9"> 两个孩子渐渐长大，以扫善于打猎，常在田野；雅各为人安静，常住在帐棚里。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 27:19; 创世记 27:31; 创世记 27:4"> 以撒爱以扫，因为常吃他的野味；利百加却爱雅各。</span>
<span className="v" id="v29" data-v="29" data-xref="箴言 13:25; 以赛亚书 40:30–31; 撒母耳记上 14:28"> 有一天，雅各熬汤，以扫从田野回来累昏了。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 36:1; 出埃及记 15:15; 创世记 36:9"> 以扫对雅各说：「我累昏了，求你把这红汤给我喝。」因此以扫又叫以东<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="就是红的意思">f</a></sup>。</span>
<span className="v" id="v31" data-v="31"> 雅各说：「你今日把长子的名分卖给我吧。」</span>
<span className="v" id="v32" data-v="32" data-xref="玛拉基书 3:14; 约伯记 21:15; 约伯记 22:17"> 以扫说：「我将要死，这长子的名分于我有什么益处呢？」</span>
<span className="v" id="v33" data-v="33" data-xref="希伯来书 12:16; 创世记 27:36; 希伯来书 6:16"> 雅各说：「你今日对我起誓吧。」以扫就对他起了誓，把长子的名分卖给雅各。</span>
<span className="v" id="v34" data-v="34" data-xref="腓立比书 3:18–19; 希伯来书 12:16–17; 哥林多前书 15:32"> 于是雅各将饼和红豆汤给了以扫，以扫吃了喝了，便起来走了。这就是以扫轻看了他长子的名分。</span>
</div>
</div>

## 亚伯拉罕和亚比米勒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 26:1; 创世记 26:6; 创世记 18:1"> 亚伯拉罕从那里向南地迁去，寄居在加低斯和书珥中间的基拉耳。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 12:15; 创世记 26:7; 创世记 12:11–13"> 亚伯拉罕称他的妻撒拉为妹子，基拉耳王亚比米勒差人把撒拉取了去。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 20:7; 马太福音 27:19; 诗篇 105:14"> 但夜间， 神来，在梦中对亚比米勒说：「你是个死人哪！因为你取了那女人来；她原是别人的妻子。」</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 18:23–25; 历代志上 21:17; 撒母耳记下 4:11"> 亚比米勒却还没有亲近撒拉；他说：「主啊，连有义的国，你也要毁灭吗？</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 7:8; 列王纪上 9:4; 但以理书 6:22"> 那人岂不是自己对我说『她是我的妹子』吗？就是女人也自己说：『他是我的哥哥。』我做这事是心正手洁的。」</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 25:34; 箴言 21:1; 撒母耳记上 25:26"> 神在梦中对他说：「我知道你做这事是心中正直；我也拦阻了你，免得你得罪我，所以我不容你沾着她。</span>
<span className="v" id="v7" data-v="7" data-xref="约伯记 42:8; 撒母耳记上 7:5; 撒母耳记下 24:17"> 现在你把这人的妻子归还他；因为他是先知，他要为你祷告，使你存活。你若不归还他，你当知道，你和你所有的人都必要死。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 亚比米勒清早起来，召了众臣仆来，将这些事都说给他们听，他们都甚惧怕。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 12:18; 创世记 26:10; 创世记 39:9"> 亚比米勒召了亚伯拉罕来，对他说：「你怎么向我这样行呢？我在什么事上得罪了你，你竟使我和我国里的人陷在大罪里？你向我行不当行的事了！」</span>
<span className="v" id="v10" data-v="10"> 亚比米勒又对亚伯拉罕说：「你见了什么才做这事呢？」</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 26:7; 创世记 12:12; 约伯记 28:28"> 亚伯拉罕说：「我以为这地方的人总不惧怕 神，必为我妻子的缘故杀我。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 11:29; 创世记 12:13; 帖撒罗尼迦前书 5:22"> 况且她也实在是我的妹子；她与我是同父异母，后来作了我的妻子。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 12:1; 创世记 12:9; 使徒行传 7:3–5"> 当 神叫我离开父家、飘流在外的时候，我对她说：『我们无论走到什么地方，你可以对人说：他是我的哥哥；这就是你待我的恩典了。』」</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 12:16; 创世记 20:2; 创世记 20:7"> 亚比米勒把牛、羊、仆婢赐给亚伯拉罕，又把他的妻子撒拉归还他。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 34:10; 创世记 13:9; 创世记 47:6"> 亚比米勒又说：「看哪，我的地都在你面前，你可以随意居住」；</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 27:5; 创世记 20:5; 创世记 24:65"> 又对撒拉说：「我给你哥哥一千银子，作为你在合家人面前遮羞的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="羞：原文是眼">a</a></sup>，你就在众人面前没有不是了。」</span>
<span className="v" id="v17" data-v="17" data-xref="雅各书 5:16; 马太福音 21:22; 约伯记 42:9–10"> 亚伯拉罕祷告 神， 神就医好了亚比米勒和他的妻子，并他的众女仆，她们便能生育。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 12:17; 创世记 30:2; 创世记 16:2"> 因耶和华为亚伯拉罕的妻子撒拉的缘故，已经使亚比米勒家中的妇人不能生育。</span>
</div>
</div>

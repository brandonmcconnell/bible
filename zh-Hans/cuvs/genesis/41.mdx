## 约瑟为法老解梦

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 20:3; 创世记 29:14; 出埃及记 4:9"> 过了两年，法老做梦，梦见自己站在河边，</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 19:6"> 有七只母牛从河里上来，又美好又肥壮，在芦荻中吃草。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 41:20–21; 创世记 41:4"> 随后又有七只母牛从河里上来，又丑陋又干瘦，与那七只母牛一同站在河边。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 3:15"> 这又丑陋又干瘦的七只母牛吃尽了那又美好又肥壮的七只母牛。法老就醒了。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 32:14"> 他又睡着，第二回做梦，梦见一棵麦子长了七个穗子，又肥大又佳美，</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 17:10; 何西阿书 13:15; 以西结书 19:12"> 随后又长了七个穗子，又细弱又被东风吹焦了。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 37:5; 创世记 20:3"> 这细弱的穗子吞了那七个又肥大又饱满的穗子。法老醒了，不料是个梦。</span>
<span className="v" id="v8" data-v="8" data-xref="但以理书 4:7; 出埃及记 7:22; 马太福音 2:1"> 到了早晨，法老心里不安，就差人召了埃及所有的术士和博士来；法老就把所做的梦告诉他们，却没有人能给法老圆解。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 40:14; 创世记 40:23; 创世记 40:1–3"> 那时酒政对法老说：「我今日想起我的罪来。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 39:20; 创世记 40:2–3; 创世记 37:36"> 从前法老恼怒臣仆，把我和膳长下在护卫长府内的监里。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 40:5–8"> 我们二人同夜各做一梦，各梦都有讲解。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 40:12–19; 创世记 37:36; 创世记 39:1"> 在那里同着我们有一个希伯来的少年人，是护卫长的仆人，我们告诉他，他就把我们的梦圆解，是按着各人的梦圆解的。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 43:3; 创世记 40:20–22; 创世记 40:12"> 后来正如他给我们圆解的成就了：我官复原职，膳长被挂起来了。」</span>
<span className="v" id="v14" data-v="14" data-xref="但以理书 2:25; 诗篇 113:7–8; 诗篇 105:19–22"> 法老遂即差人去召约瑟，他们便急忙带他出监，他就剃头，刮脸，换衣裳，进到法老面前。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理书 5:16; 但以理书 5:12; 诗篇 25:14"> 法老对约瑟说：「我做了一梦，没有人能解；我听见人说，你听了梦就能解。」</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 3:5; 创世记 40:8; 但以理书 2:47"> 约瑟回答法老说：「这不在乎我， 神必将平安的话回答法老。」</span>
<span className="v" id="v17" data-v="17"> 法老对约瑟说：「我梦见我站在河边，</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 24:8; 耶利米书 24:1–3; 耶利米书 24:5"> 有七只母牛从河里上来，又肥壮又美好，在芦荻中吃草。</span>
<span className="v" id="v19" data-v="19"> 随后又有七只母牛上来，又软弱又丑陋又干瘦，在埃及遍地，我没有见过这样不好的。</span>
<span className="v" id="v20" data-v="20"> 这又干瘦又丑陋的母牛吃尽了那以先的七只肥母牛，</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 3:3; 诗篇 37:19; 启示录 10:9–10"> 吃了以后却看不出是吃了，那丑陋的样子仍旧和先前一样。我就醒了。</span>
<span className="v" id="v22" data-v="22"> 我又梦见一棵麦子，长了七个穗子，又饱满又佳美，</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 129:6–7; 何西阿书 13:15; 列王纪下 19:26"> 随后又长了七个穗子，枯槁细弱，被东风吹焦了。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理书 4:7; 创世记 41:8; 出埃及记 8:19"> 这些细弱的穗子吞了那七个佳美的穗子。我将这梦告诉了术士，却没有人能给我解说。」</span>
<span className="v" id="v25" data-v="25" data-xref="但以理书 2:45; 启示录 4:1; 以弗所书 1:17"> 约瑟对法老说：「法老的梦乃是一个。 神已将所要做的事指示法老了。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 41:47; 创世记 41:2; 创世记 41:53"> 七只好母牛是七年，七个好穗子也是七年；这梦乃是一个。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 8:1; 撒母耳记下 24:19"> 那随后上来的七只又干瘦又丑陋的母牛是七年，那七个虚空、被东风吹焦的穗子也是七年，都是七个荒年。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 41:25; 创世记 41:16"> 这就是我对法老所说， 神已将所要做的事显明给法老了。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 41:26; 创世记 41:46–47; 创世记 41:49"> 埃及遍地必来七个大丰年，</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 47:13; 创世记 41:54; 雅各书 5:17"> 随后又要来七个荒年，甚至在埃及地都忘了先前的丰收，全地必被饥荒所灭。</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 24:20; 撒母耳记上 5:6"> 因那以后的饥荒甚大，便不觉得先前的丰收了。</span>
<span className="v" id="v32" data-v="32" data-xref="民数记 23:19; 以赛亚书 46:10–11; 以赛亚书 14:24–27"> 至于法老两回做梦，是因 神命定这事，而且必速速成就。</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 41:39; 使徒行传 6:3; 申命记 1:13"> 所以，法老当拣选一个有聪明有智慧的人，派他治理埃及地。</span>
<span className="v" id="v34" data-v="34" data-xref="箴言 22:3; 路加福音 16:5; 箴言 6:6–8"> 法老当这样行，又派官员管理这地。当七个丰年的时候，征收埃及地的五分之一，</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 45:6–7; 创世记 41:56; 出埃及记 4:13"> 叫他们把将来丰年一切的粮食聚敛起来，积蓄五谷，收存在各城里做食物，归于法老的手下。</span>
<span className="v" id="v36" data-v="36" data-xref="创世记 47:13–25"> 所积蓄的粮食可以防备埃及地将来的七个荒年，免得这地被饥荒所灭。」</span>
</div>
</div>

## 约瑟被立为埃及的宰相

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒行传 7:10; 列王纪上 21:2; 撒母耳记下 3:36"> 法老和他一切臣仆都以这事为妙。</span>
<span className="v" id="v38" data-v="38" data-xref="约伯记 32:8; 但以理书 5:14; 民数记 27:18"> 法老对臣仆说：「像这样的人，有 神的灵在他里头，我们岂能找得着呢？」</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 41:33; 创世记 41:28; 创世记 41:25"> 法老对约瑟说：「 神既将这事都指示你，可见没有人像你这样有聪明有智慧。</span>
<span className="v" id="v40" data-v="40" data-xref="箴言 22:29; 使徒行传 7:10; 诗篇 105:21–22"> 你可以掌管我的家；我的民都必听从你的话。惟独在宝座上我比你大。」</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 28:18; 腓立比书 2:9–11; 创世记 42:6"> 法老又对约瑟说：「我派你治理埃及全地。」</span>
<span className="v" id="v42" data-v="42" data-xref="但以理书 5:29; 但以理书 5:7; 以斯帖记 3:10"> 法老就摘下手上打印的戒指，戴在约瑟的手上，给他穿上细麻衣，把金链戴在他的颈项上，</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行传 7:10; 创世记 45:8; 创世记 45:26"> 又叫约瑟坐他的副车，喝道的在前呼叫说：「跪下。」这样，法老派他治理埃及全地。</span>
<span className="v" id="v44" data-v="44" data-xref="诗篇 105:22; 出埃及记 11:7"> 法老对约瑟说：「我是法老，在埃及全地，若没有你的命令，不许人擅自办事<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是动手动脚">a</a></sup>。」</span>
<span className="v" id="v45" data-v="45" data-xref="创世记 46:20; 以西结书 30:17; 出埃及记 2:16"> 法老赐名给约瑟，叫撒发那忒·巴内亚，又将安城的祭司波提非拉的女儿亚西纳给他为妻。约瑟就出去巡行埃及地。</span>
<span className="v" id="v46" data-v="46" data-xref="但以理书 1:19; 列王纪上 12:6; 撒母耳记上 16:21"> 约瑟见埃及王法老的时候年三十岁。他从法老面前出去，遍行埃及全地。</span>
<span className="v" id="v47" data-v="47" data-xref="创世记 26:12; 诗篇 72:16"> 七个丰年之内，地的出产极丰极盛<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是一把一把的">b</a></sup>，</span>
<span className="v" id="v48" data-v="48" data-xref="创世记 41:34–36; 创世记 47:21"> 约瑟聚敛埃及地七个丰年一切的粮食，把粮食积存在各城里；各城周围田地的粮食都积存在本城里。</span>
<span className="v" id="v49" data-v="49" data-xref="诗篇 78:27; 士师记 6:5; 创世记 22:17"> 约瑟积蓄五谷甚多，如同海边的沙，无法计算，因为谷不可胜数。</span>
<span className="v" id="v50" data-v="50" data-xref="创世记 46:20; 创世记 48:5; 撒母耳记下 8:18"> 荒年未到以前，安城的祭司波提非拉的女儿亚西纳给约瑟生了两个儿子。</span>
<span className="v" id="v51" data-v="51" data-xref="诗篇 30:5; 箴言 31:7; 申命记 33:17"> 约瑟给长子起名叫玛拿西<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="就是使之忘了的意思">c</a></sup>，因为他说：「 神使我忘了一切的困苦和我父的全家。」</span>
<span className="v" id="v52" data-v="52" data-xref="创世记 49:22; 创世记 50:23; 创世记 17:6"> 他给次子起名叫以法莲<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="就是使之昌盛的意思">d</a></sup>，因为他说：「 神使我在受苦的地方昌盛。」</span>
<span className="v" id="v53" data-v="53" data-xref="创世记 41:29–31; 诗篇 73:20; 路加福音 16:25"> 埃及地的七个丰年一完，</span>
<span className="v" id="v54" data-v="54" data-xref="创世记 45:11; 使徒行传 7:11; 诗篇 105:16"> 七个荒年就来了。正如约瑟所说的，各地都有饥荒；惟独埃及全地有粮食。</span>
<span className="v" id="v55" data-v="55" data-xref="马太福音 17:5; 马太福音 3:17; 耶利米书 14:1–6"> 及至埃及全地有了饥荒，众民向法老哀求粮食，法老对他们说：「你们往约瑟那里去，凡他所说的，你们都要做。」</span>
<span className="v" id="v56" data-v="56" data-xref="创世记 42:6; 撒迦利亚书 5:3; 路加福音 21:35"> 当时饥荒遍满天下，约瑟开了各处的仓，粜粮给埃及人；在埃及地饥荒甚大。</span>
<span className="v" id="v57" data-v="57" data-xref="创世记 41:54; 创世记 42:5; 创世记 41:56"> 各地的人都往埃及去，到约瑟那里籴粮，因为天下的饥荒甚大。</span>

## 约瑟为囚犯解梦

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 40:13; 创世记 39:20–23; 以斯帖记 6:1"> 这事以后，埃及王的酒政和膳长得罪了他们的主—埃及王，</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 16:14; 箴言 19:12; 诗篇 76:10"> 法老就恼怒酒政和膳长这二臣，</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 39:20; 创世记 39:23"> 把他们下在护卫长府内的监里，就是约瑟被囚的地方。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 39:1; 诗篇 37:5; 创世记 37:36"> 护卫长把他们交给约瑟，约瑟便伺候他们；他们有些日子在监里。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 41:11; 创世记 40:8; 创世记 37:5–10"> 被囚在监之埃及王的酒政和膳长二人同夜各做一梦，各梦都有讲解。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 41:8; 但以理书 2:1–3; 创世记 40:8"> 到了早晨，约瑟进到他们那里，见他们有愁闷的样子。</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米记 2:2; 撒母耳记上 1:8; 路加福音 24:17"> 他便问法老的二臣，就是与他同囚在他主人府里的，说：「你们今日为什么面带愁容呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="但以理书 2:47; 创世记 41:15–16; 但以理书 2:28"> 他们对他说：「我们各人做了一梦，没有人能解。」约瑟说：「解梦不是出于 神吗？请你们将梦告诉我。」</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 7:13–15; 创世记 37:5–10; 但以理书 4:8"> 酒政便将他的梦告诉约瑟说：「我梦见在我面前有一棵葡萄树，</span>
<span className="v" id="v10" data-v="10"> 树上有三根枝子，好像发了芽，开了花，上头的葡萄都成熟了。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 1:11–1; 列王纪上 10:5; 历代志下 9:4"> 法老的杯在我手中，我就拿葡萄挤在法老的杯里，将杯递在他手中。」</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 41:12; 士师记 7:14; 创世记 41:25–26"> 约瑟对他说：「你所做的梦是这样解：三根枝子就是三天；</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 3:3; 耶利米书 52:31; 列王纪下 25:27"> 三天之内，法老必提你出监，叫你官复原职，你仍要递杯在法老的手中，和先前作他的酒政一样。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 2:12; 路加福音 23:42; 撒母耳记上 20:14–15"> 但你得好处的时候，求你记念我，施恩与我，在法老面前提说我，救我出这监牢。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 3:17–18; 创世记 39:20; 提摩太前书 1:10"> 我实在是从希伯来人之地被拐来的；我在这里也没有做过什么，叫他们把我下在监里。」</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 40:1–2"> 膳长见梦解得好，就对约瑟说：「我在梦中见我头上顶着三筐白饼；</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 49:20; 历代志上 12:20"> 极上的筐子里有为法老烤的各样食物，有飞鸟来吃我头上筐子里的食物。」</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 40:12; 创世记 41:26; 哥林多前书 11:24"> 约瑟说：「你的梦是这样解：三个筐子就是三天；</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 40:22; 使徒行传 20:27; 撒母耳记下 21:6"> 三天之内，法老必斩断你的头，把你挂在木头上，必有飞鸟来吃你身上的肉。」</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 40:19; 创世记 40:13; 马太福音 14:6"> 到了第三天，是法老的生日，他为众臣仆设摆筵席，把酒政和膳长提出监来，</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 40:13; 尼希米记 2:1"> 使酒政官复原职，他仍旧递杯在法老手中；</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 40:19; 创世记 41:16; 但以理书 2:30"> 但把膳长挂起来，正如约瑟向他们所解的话。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 31:12; 约伯记 19:14; 诗篇 105:19"> 酒政却不记念约瑟，竟忘了他。</span>

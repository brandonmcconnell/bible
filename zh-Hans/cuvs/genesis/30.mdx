<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约伯记 5:2; 创世记 29:31; 创世记 37:11"> 拉结见自己不给雅各生子，就嫉妒她姊姊，对雅各说：「你给我孩子，不然我就死了。」</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 16:2; 诗篇 127:3; 列王纪下 5:7"> 雅各向拉结生气，说：「叫你不生育的是 神，我岂能代替他作主呢？」</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 50:23; 约伯记 3:12; 路得记 4:11"> 拉结说：「有我的使女辟拉在这里，你可以与她同房，使她生子在我膝下，我便因她也得孩子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是被建立">a</a></sup>。」</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 35:22; 创世记 21:10; 撒母耳记下 12:11"> 拉结就把她的使女辟拉给丈夫为妾；雅各便与她同房，</span>
<span className="v" id="v5" data-v="5"> 辟拉就怀孕，给雅各生了一个儿子。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米哀歌 3:59; 诗篇 35:24; 诗篇 43:1"> 拉结说：「 神伸了我的冤，也听了我的声音，赐我一个儿子」，因此给他起名叫但<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就是伸冤的意思">b</a></sup>。</span>
<span className="v" id="v7" data-v="7"> 拉结的使女辟拉又怀孕，给雅各生了第二个儿子。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 32:24–25; 创世记 23:6; 创世记 49:21"> 拉结说：「我与我姊姊大大相争，并且得胜」，于是给他起名叫拿弗他利<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="就是相争的意思">c</a></sup>。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 30:4; 创世记 30:17; 创世记 29:35"> 利亚见自己停了生育，就把使女悉帕给雅各为妾。</span>
<span className="v" id="v10" data-v="10"> 利亚的使女悉帕给雅各生了一个儿子。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 49:19; 以赛亚书 65:11; 创世记 35:26"> 利亚说：「万幸！」于是给他起名叫迦得<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="就是万幸的意思">d</a></sup>。</span>
<span className="v" id="v12" data-v="12"> 利亚的使女悉帕又给雅各生了第二个儿子。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 1:48; 箴言 31:28; 雅歌 6:9"> 利亚说：「我有福啊，众女子都要称我是有福的」，于是给他起名叫亚设<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="就是有福的意思">e</a></sup>。</span>
<span className="v" id="v14" data-v="14" data-xref="雅歌 7:13; 创世记 25:30"> 割麦子的时候，吕便往田里去，寻见风茄，拿来给他母亲利亚。拉结对利亚说：「请你把你儿子的风茄给我些。」</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 16:13; 哥林多前书 4:3; 民数记 16:9–10"> 利亚说：「你夺了我的丈夫还算小事吗？你又要夺我儿子的风茄吗？」拉结说：「为你儿子的风茄，今夜他可以与你同寝。」</span>
<span className="v" id="v16" data-v="16"> 到了晚上，雅各从田里回来，利亚出来迎接他，说：「你要与我同寝，因为我实在用我儿子的风茄把你雇下了。」那一夜，雅各就与她同寝。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 30:6; 创世记 30:22; 出埃及记 3:7"> 神应允了利亚，她就怀孕，给雅各生了第五个儿子。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 49:14–15; 申命记 33:18; 创世记 46:13"> 利亚说：「 神给了我价值，因为我把使女给了我丈夫」，于是给他起名叫以萨迦<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="就是价值的意思">f</a></sup>。</span>
<span className="v" id="v19" data-v="19"> 利亚又怀孕，给雅各生了第六个儿子。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 35:23; 马太福音 4:13; 创世记 49:13"> 利亚说：「 神赐我厚赏；我丈夫必与我同住，因我给他生了六个儿子」，于是给他起名西布伦<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="就是同住的意思">g</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 34:1–3; 创世记 34:26; 创世记 46:15"> 后来又生了一个女儿，给她起名叫底拿。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 29:31; 诗篇 113:9; 诗篇 127:3"> 神顾念拉结，应允了她，使她能生育。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 1:25; 创世记 29:31; 路加福音 1:27"> 拉结怀孕生子，说：「 神除去了我的羞耻」，</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 49:22–26; 创世记 35:24; 创世记 37:2"> 就给他起名叫约瑟<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="就是增添的意思">h</a></sup>，意思说：「愿耶和华再增添我一个儿子。」</span>
</div>
</div>

## 雅各和拉班定工价

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 24:54; 创世记 24:56; 创世记 28:15"> 拉结生约瑟之后，雅各对拉班说：「请打发我走，叫我回到我本乡本土去。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 29:30; 何西阿书 12:12; 创世记 31:26"> 请你把我服事你所得的妻子和儿女给我，让我走；我怎样服事你，你都知道。」</span>
<span className="v" id="v27" data-v="27" data-xref="路得记 2:13; 使徒行传 7:10; 以赛亚书 61:9"> 拉班对他说：「我若在你眼前蒙恩，请你仍与我同住，因为我已算定，耶和华赐福与我是为你的缘故」；</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 29:15; 创世记 29:19"> 又说：「请你定你的工价，我就给你。」</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 31:6; 创世记 31:38–40; 彼得前书 2:18"> 雅各对他说：「我怎样服事你，你的牲畜在我手里怎样，是你知道的。</span>
<span className="v" id="v30" data-v="30" data-xref="提摩太前书 5:8; 哥林多后书 12:14; 申命记 11:10"> 我未来之先，你所有的很少，现今却发大众多，耶和华随我的脚步赐福与你。如今，我什么时候才为自己兴家立业呢？」</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 21:4–6; 希伯来书 13:5; 诗篇 118:8"> 拉班说：「我当给你什么呢？」雅各说：「什么你也不必给我，只有一件事，你若应承，我便仍旧牧放你的羊群。</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 31:8; 创世记 31:10; 创世记 30:35"> 今天我要走遍你的羊群，把绵羊中凡有点的、有斑的，和黑色的，并山羊中凡有斑的、有点的，都挑出来；将来这一等的就算我的工价。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 13:14; 撒母耳记下 22:21; 撒母耳记上 26:23"> 以后你来查看我的工价，凡在我手里的山羊不是有点有斑的，绵羊不是黑色的，那就算是我偷的；这样便可证出我的公义来。」</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 7:7; 民数记 22:29; 哥林多前书 14:5"> 拉班说：「好啊！我情愿照着你的话行。」</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 31:9"> 当日，拉班把有纹的、有斑的公山羊，有点的、有斑的、有杂白纹的母山羊，并黑色的绵羊，都挑出来，交在他儿子们的手下，</span>
<span className="v" id="v36" data-v="36"> 又使自己和雅各相离三天的路程。雅各就牧养拉班其余的羊。</span>
<span className="v" id="v37" data-v="37" data-xref="创世记 31:9–13; 以西结书 31:8"> 雅各拿杨树、杏树、枫树的嫩枝，将皮剥成白纹，使枝子露出白的来，</span>
<span className="v" id="v38" data-v="38"> 将剥了皮的枝子，对着羊群，插在饮羊的水沟里和水槽里，羊来喝的时候，牝牡配合。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及记 12:35–36; 创世记 31:9–12; 创世记 31:40"> 羊对着枝子配合，就生下有纹的、有点的、有斑的来。</span>
<span className="v" id="v40" data-v="40"> 雅各把羊羔分出来，使拉班的羊与这有纹和黑色的羊相对，把自己的羊另放一处，不叫他和拉班的羊混杂。</span>
<span className="v" id="v41" data-v="41"> 到羊群肥壮配合的时候，雅各就把枝子插在水沟里，使羊对着枝子配合。</span>
<span className="v" id="v42" data-v="42"> 只是到羊瘦弱配合的时候就不插枝子。这样，瘦弱的就归拉班，肥壮的就归雅各。</span>
<span className="v" id="v43" data-v="43" data-xref="创世记 24:35; 创世记 30:30; 创世记 26:13–14"> 于是雅各极其发大，得了许多的羊群、仆婢、骆驼，和驴。</span>
</div>

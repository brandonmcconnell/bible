## 以撒出生

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 12:6; 创世记 18:10; 创世记 18:14"> 耶和华按着先前的话眷顾撒拉，便照他所说的给撒拉成就。</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太书 4:22; 希伯来书 11:11; 创世记 18:10"> 当亚伯拉罕年老的时候，撒拉怀了孕；到 神所说的日期，就给亚伯拉罕生了一个儿子。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 17:19; 罗马书 9:7; 创世记 21:6"> 亚伯拉罕给撒拉所生的儿子起名叫以撒。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 7:8; 申命记 12:32; 约翰福音 7:22–23"> 以撒生下来第八日，亚伯拉罕照着 神所吩咐的，给以撒行了割礼。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 17:17; 罗马书 4:19; 创世记 17:1"> 他儿子以撒生的时候，亚伯拉罕年一百岁。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 126:2; 以赛亚书 54:1; 创世记 17:17"> 撒拉说：「 神使我喜笑，凡听见的必与我一同喜笑」；</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 18:11–12; 以赛亚书 66:8; 帖撒罗尼迦后书 1:10"> 又说：「谁能预先对亚伯拉罕说『撒拉要乳养婴孩』呢？因为在他年老的时候，我给他生了一个儿子。」</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 1:22; 何西阿书 1:8; 创世记 40:20"> 孩子渐长，就断了奶。以撒断奶的日子，亚伯拉罕设摆丰盛的筵席。</span>
</div>
</div>

## 夏甲和以实玛利被逐

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="加拉太书 4:29; 创世记 16:15; 加拉太书 4:22"> 当时，撒拉看见埃及人夏甲给亚伯拉罕所生的儿子戏笑，</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 8:35; 约翰一书 2:19; 加拉太书 4:22–31"> 就对亚伯拉罕说：「你把这使女和她儿子赶出去！因为这使女的儿子不可与我的儿子以撒一同承受产业。」</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 12:11; 创世记 17:18; 马太福音 10:37"> 亚伯拉罕因他儿子的缘故很忧愁。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 11:18; 罗马书 9:7–8; 创世记 17:19"> 神对亚伯拉罕说：「你不必为这童子和你的使女忧愁。凡撒拉对你说的话，你都该听从；因为从以撒生的，才要称为你的后裔。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 16:10; 创世记 17:20; 创世记 21:18"> 至于使女的儿子，我也必使他的后裔成立一国，因为他是你所生的。」</span>
<span className="v" id="v14" data-v="14" data-xref="传道书 9:10; 诗篇 119:60; 创世记 16:7"> 亚伯拉罕清早起来，拿饼和一皮袋水，给了夏甲，搭在她的肩上，又把孩子交给她，打发她走。夏甲就走了，在别是巴的旷野走迷了路。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 3:9; 诗篇 63:1; 耶利米书 14:3"> 皮袋的水用尽了，夏甲就把孩子撇在小树底下，</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 49:15; 创世记 29:11; 撒母耳记上 24:16"> 自己走开约有一箭之远，相对而坐，说：「我不忍见孩子死」，就相对而坐，放声大哭。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 16:11; 诗篇 50:15; 出埃及记 3:7"> 神听见童子的声音； 神的使者从天上呼叫夏甲说：「夏甲，你为何这样呢？不要害怕， 神已经听见童子的声音了。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 21:13; 创世记 16:10; 创世记 17:20"> 起来！把童子抱在怀中<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="怀：原文是手">a</a></sup>，我必使他的后裔成为大国。」</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 22:31; 列王纪下 6:17–20; 以赛亚书 35:5–6"> 神使夏甲的眼睛明亮，她就看见一口水井，便去将皮袋盛满了水，给童子喝。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 28:15; 创世记 39:21; 创世记 16:12"> 神保佑童子，他就渐长，住在旷野，成了弓箭手。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 26:34–35; 创世记 24:3–4; 民数记 12:16"> 他住在巴兰的旷野；他母亲从埃及地给他娶了一个妻子。</span>
</div>
</div>

## 亚伯拉罕跟亚比米勒立约

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约书亚记 3:7; 创世记 26:26; 创世记 26:28"> 当那时候，亚比米勒同他军长非各对亚伯拉罕说：「凡你所行的事都有 神的保佑。</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 2:12; 创世记 20:14; 希伯来书 6:16"> 我愿你如今在这里指着 神对我起誓，不要欺负我与我的儿子，并我的子孙。我怎样厚待了你，你也要照样厚待我与你所寄居这地的民。」</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 6:16; 创世记 14:13; 罗马书 12:18"> 亚伯拉罕说：「我情愿起誓。」</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 26:15–22; 创世记 29:8; 箴言 25:9"> 从前，亚比米勒的仆人霸占了一口水井，亚伯拉罕为这事指责亚比米勒。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 13:7; 列王纪下 5:20–24"> 亚比米勒说：「谁做这事，我不知道，你也没有告诉我，今日我才听见了。」</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 14:22–23; 以赛亚书 32:8; 罗马书 1:31"> 亚伯拉罕把羊和牛给了亚比米勒，二人就彼此立约。</span>
<span className="v" id="v28" data-v="28"> 亚伯拉罕把七只母羊羔另放在一处。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记上 15:14; 创世记 33:8; 出埃及记 12:26"> 亚比米勒问亚伯拉罕说：「你把这七只母羊羔另放在一处，是什么意思呢？」</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 31:52; 约书亚记 24:27; 约书亚记 22:27–28"> 他说：「你要从我手里受这七只母羊羔，作我挖这口井的证据。」</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 26:33; 创世记 21:14; 列王纪上 4:25"> 所以他给那地方起名叫别是巴<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就是盟誓的井的意思">b</a></sup>，因为他们二人在那里起了誓。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 13:17; 创世记 21:27; 士师记 13:1"> 他们在别是巴立了约，亚比米勒就同他军长非各起身回非利士地去了。</span>
<span className="v" id="v33" data-v="33" data-xref="提摩太前书 1:17; 以赛亚书 40:28; 诗篇 90:2"> 亚伯拉罕在别是巴栽上一棵垂丝柳树，又在那里求告耶和华—永生 神的名。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志上 29:15; 彼得前书 2:11; 希伯来书 11:9"> 亚伯拉罕在非利士人的地寄居了多日。</span>
</div>
</div>

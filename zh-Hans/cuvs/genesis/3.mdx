## 人违背命令

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 11:3; 哥林多后书 11:14; 启示录 12:9"> 耶和华 神所造的，惟有蛇比田野一切的活物更狡猾。蛇对女人说：「 神岂是真说不许你们吃园中所有树上的果子吗？」</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 58:4"> 女人对蛇说：「园中树上的果子，我们可以吃，</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 2:16–17; 哥林多后书 6:17; 出埃及记 19:12–13"> 惟有园当中那棵树上的果子， 神曾说：『你们不可吃，也不可摸，免得你们死。』」</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 8:44; 哥林多后书 11:3; 提摩太前书 2:14"> 蛇对女人说：「你们不一定死；</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 28:2; 帖撒罗尼迦后书 2:4; 哥林多后书 11:13–15"> 因为 神知道，你们吃的日子眼睛就明亮了，你们便如 神能知道善恶。」</span>
<span className="v" id="v6" data-v="6" data-xref="约翰一书 2:16; 雅各书 1:14–15; 提摩太前书 2:14"> 于是女人见那棵树的果子好作食物，也悦人的眼目，且是可喜爱的，能使人有智慧，就摘下果子来吃了，又给她丈夫，她丈夫也吃了。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 59:6; 创世记 2:25; 创世记 3:5"> 他们二人的眼睛就明亮了，才知道自己是赤身露体，便拿无花果树的叶子为自己编做裙子。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 23:24; 箴言 15:3; 希伯来书 4:13"> 天起了凉风，耶和华 神在园中行走。那人和他妻子听见 神的声音，就藏在园里的树木中，躲避耶和华 神的面。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 4:9; 创世记 16:8; 创世记 18:20–21"> 耶和华 神呼唤那人，对他说：「你在哪里？」</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 2:25; 诗篇 119:120; 以赛亚书 47:3"> 他说：「我在园中听见你的声音，我就害怕；因为我赤身露体，我便藏了。」</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 3:20; 创世记 4:10; 诗篇 50:21"> 耶和华说：「谁告诉你赤身露体呢？莫非你吃了我吩咐你不可吃的那树上的果子吗？」</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 28:13; 雅各书 1:13–15; 约伯记 31:33"> 那人说：「你所赐给我、与我同居的女人，她把那树上的果子给我，我就吃了。」</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 11:3; 提摩太前书 2:14; 创世记 4:10–12"> 耶和华 神对女人说：「你做的是什么事呢？」女人说：「那蛇引诱我，我就吃了。」</span>
</div>
</div>

## 神的宣判

<div className="bt">
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="弥迦书 7:17; 以赛亚书 65:25; 诗篇 72:9"> <span className="pl pl-1">耶和华 神对蛇说：</span><br /><span className="pl pl-1">你既做了这事，就必受咒诅，</span><br /><span className="pl pl-1">比一切的牲畜野兽更甚；</span><br /><span className="pl pl-1">你必用肚子行走，</span><br /><span className="pl pl-1">终身吃土。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 16:20; 约翰一书 3:8; 启示录 12:17"> <span className="pl pl-1">我又要叫你和女人彼此为仇；</span><br /><span className="pl pl-1">你的后裔和女人的后裔也彼此为仇。</span><br /><span className="pl pl-1">女人的后裔要伤你的头；</span><br /><span className="pl pl-1">你要伤他的脚跟。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="提多书 2:5; 歌罗西书 3:18; 哥林多前书 11:3"> <span className="pl pl-1">又对女人说：</span><br /><span className="pl pl-1">我必多多加增你怀胎的苦楚；</span><br /><span className="pl pl-1">你生产儿女必多受苦楚。</span><br /><span className="pl pl-1">你必恋慕你丈夫；</span><br /><span className="pl pl-1">你丈夫必管辖你。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 8:20–22; 创世记 5:29; 以赛亚书 24:5–6"> <span className="pl pl-1">又对亚当说：</span><br /><span className="pl pl-1">你既听从妻子的话，</span><br /><span className="pl pl-1">吃了我所吩咐你不可吃的那树上的果子，</span><br /><span className="pl pl-1">地必为你的缘故受咒诅；</span><br /><span className="pl pl-1">你必终身劳苦才能从地里得吃的。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 13:7; 约伯记 5:5; 以赛亚书 7:23"> <span className="pl pl-1">地必给你长出荆棘和蒺藜来；</span><br /><span className="pl pl-1">你也要吃田间的菜蔬。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="传道书 12:7; 约伯记 34:15; 诗篇 104:29"> <span className="pl pl-1">你必汗流满面才得糊口，</span><br /><span className="pl pl-1">直到你归了土，</span><br /><span className="pl pl-1">因为你是从土而出的。</span><br /><span className="pl pl-1">你本是尘土，仍要归于尘土。</span></span>
<span className="v" id="v20" data-v="20" data-xref="创世记 2:23; 马太福音 1:23; 创世记 5:29"> 亚当给他妻子起名叫夏娃，因为她是众生之母。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 61:10; 哥林多后书 5:21; 哥林多后书 5:2–3"> 耶和华 神为亚当和他妻子用皮子做衣服给他们穿。</span>
</div>
</div>

## 亚当和夏娃被赶出伊甸园

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="启示录 2:7; 启示录 22:14; 箴言 3:18"> 耶和华 神说：「那人已经与我们相似，能知道善恶；现在恐怕他伸手又摘生命树的果子吃，就永远活着。」</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 4:2; 创世记 3:19; 创世记 4:12"> 耶和华 神便打发他出伊甸园去，耕种他所自出之土。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 1:7; 诗篇 104:4; 出埃及记 25:18–22"> 于是把他赶出去了；又在伊甸园的东边安设基路伯和四面转动发火焰的剑，要把守生命树的道路。</span>
</div>

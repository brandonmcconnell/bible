## 以撒祝福雅各

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 3:2; 创世记 48:10; 创世记 25:23–25"> 以撒年老，眼睛昏花，不能看见，就叫了他大儿子以扫来，说：「我儿。」以扫说：「我在这里。」</span>
<span className="v" id="v2" data-v="2" data-xref="雅各书 4:14; 传道书 9:10; 箴言 27:1"> 他说：「我如今老了，不知道哪一天死。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 25:27–28; 创世记 10:9; 哥林多前书 6:12"> 现在拿你的器械，就是箭囊和弓，往田野去为我打猎，</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 11:20; 创世记 48:9; 创世记 49:28"> 照我所爱的做成美味，拿来给我吃，使我在未死之先给你祝福。」</span>
<span className="v" id="v5" data-v="5"> 以撒对他儿子以扫说话，利百加也听见了。以扫往田野去打猎，要得野味带来。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 25:28"> 利百加就对她儿子雅各说：「我听见你父亲对你哥哥以扫说：</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 6:26; 撒母耳记上 24:19; 申命记 33:1"> 『你去把野兽带来，做成美味给我吃，我好在未死之先，在耶和华面前给你祝福。』</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 6:1; 创世记 27:13; 使徒行传 5:29"> 现在，我儿，你要照着我所吩咐你的，听从我的话。</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 13:15; 撒母耳记上 16:20"> 你到羊群里去，给我拿两只肥山羊羔来，我便照你父亲所爱的给他做成美味。</span>
<span className="v" id="v10" data-v="10"> 你拿到你父亲那里给他吃，使他在未死之先给你祝福。」</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 25:25"> 雅各对他母亲利百加说：「我哥哥以扫浑身是有毛的，我身上是光滑的；</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 27:18; 创世记 25:27; 玛拉基书 1:14"> 倘若我父亲摸着我，必以我为欺哄人的，我就招咒诅，不得祝福。」</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 27:25; 撒母耳记上 25:24; 撒母耳记下 14:9"> 他母亲对他说：「我儿，你招的咒诅归到我身上；你只管听我的话，去把羊羔给我拿来。」</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 27:9; 箴言 23:2–3; 创世记 25:28"> 他便去拿来，交给他母亲；他母亲就照他父亲所爱的做成美味。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 27:27; 路加福音 20:46; 路加福音 15:22"> 利百加又把家里所存大儿子以扫上好的衣服给她小儿子雅各穿上，</span>
<span className="v" id="v16" data-v="16"> 又用山羊羔皮包在雅各的手上和颈项的光滑处，</span>
<span className="v" id="v17" data-v="17"> 就把所做的美味和饼交在她儿子雅各的手里。</span>
<span className="v" id="v18" data-v="18"> 雅各到他父亲那里说：「我父亲！」他说：「我在这里。我儿，你是谁？」</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 28:15; 马太福音 26:70–74; 撒迦利亚书 13:3–4"> 雅各对他父亲说：「我是你的长子以扫；我已照你所吩咐我的行了。请起来坐着，吃我的野味，好给我祝福。」</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 20:7; 约伯记 13:7; 创世记 24:12"> 以撒对他儿子说：「我儿，你如何找得这么快呢？」他说：「因为耶和华—你的 神使我遇见好机会得着的。」</span>
<span className="v" id="v21" data-v="21" data-xref="雅各书 4:8; 以赛亚书 57:19; 创世记 27:12"> 以撒对雅各说：「我儿，你近前来，我摸摸你，知道你真是我的儿子以扫不是。」</span>
<span className="v" id="v22" data-v="22"> 雅各就挨近他父亲以撒。以撒摸着他，说：「声音是雅各的声音，手却是以扫的手。」</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 27:16; 希伯来书 11:20; 罗马书 9:11–12"> 以撒就辨不出他来；因为他手上有毛，像他哥哥以扫的手一样，就给他祝福；</span>
<span className="v" id="v24" data-v="24" data-xref="歌罗西书 3:9; 以弗所书 4:25; 箴言 12:22"> 又说：「你真是我儿子以扫吗？」他说：「我是。」</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 27:4"> 以撒说：「你递给我，我好吃我儿子的野味，给你祝福。」雅各就递给他，他便吃了，又拿酒给他，他也喝了。</span>
<span className="v" id="v26" data-v="26"> 他父亲以撒对他说：「我儿，你上前来与我亲嘴。」</span>
<span className="v" id="v27" data-v="27" data-xref="希伯来书 6:7; 诗篇 65:10; 希伯来书 11:20"> 他就上前与父亲亲嘴。他父亲一闻他衣服上的香气，就给他祝福，说：<br /><span className="pl pl-1">我儿的香气</span><br /><span className="pl pl-1">如同耶和华赐福之田地的香气一样。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="申命记 33:28; 申命记 33:13; 诗篇 133:3"> <span className="pl pl-1">愿 神赐你天上的甘露，</span><br /><span className="pl pl-1">地上的肥土，</span><br /><span className="pl pl-1">并许多五谷新酒。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="创世记 12:3; 民数记 24:9; 以赛亚书 49:23"> <span className="pl pl-1">愿多民事奉你，</span><br /><span className="pl pl-1">多国跪拜你。</span><br /><span className="pl pl-1">愿你作你弟兄的主；</span><br /><span className="pl pl-1">你母亲的儿子向你跪拜。</span><br /><span className="pl pl-1">凡咒诅你的，愿他受咒诅；</span><br /><span className="pl pl-1">为你祝福的，愿他蒙福。</span></span>
</div>
</div>

## 以扫求以撒祝福

<div className="bt">
<div className="bp poetry">
<span className="v" id="v30" data-v="30"> 以撒为雅各祝福已毕，雅各从他父亲那里才出来，他哥哥以扫正打猎回来，</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 27:4"> 也做了美味，拿来给他父亲，说：「请父亲起来，吃你儿子的野味，好给我祝福。」</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 27:18"> 他父亲以撒对他说：「你是谁？」他说：「我是你的长子以扫。」</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 28:3–4; 罗马书 11:29; 以弗所书 1:3"> 以撒就大大地战兢，说：「你未来之先，是谁得了野味拿来给我呢？我已经吃了，为他祝福；他将来也必蒙福。」</span>
<span className="v" id="v34" data-v="34" data-xref="希伯来书 12:17; 箴言 1:31; 撒母耳记上 30:4"> 以扫听了他父亲的话，就放声痛哭，说：「我父啊，求你也为我祝福！」</span>
<span className="v" id="v35" data-v="35" data-xref="帖撒罗尼迦前书 4:6; 约伯记 13:7; 玛拉基书 2:10"> 以撒说：「你兄弟已经用诡计来将你的福分夺去了。」</span>
<span className="v" id="v36" data-v="36" data-xref="创世记 25:26; 约翰福音 1:47; 创世记 32:28"> 以扫说：「他名雅各，岂不是正对吗？因为他欺骗了我两次：他从前夺了我长子的名分，你看，他现在又夺了我的福分。」以扫又说：「你没有留下为我可祝的福吗？」</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳记下 8:14; 创世记 27:28–29; 创世记 25:23"> 以撒回答以扫说：「我已立他为你的主，使他的弟兄都给他作仆人，并赐他五谷新酒可以养生。我儿，现在我还能为你做什么呢？」</span>
<span className="v" id="v38" data-v="38" data-xref="希伯来书 12:17; 创世记 27:34; 以赛亚书 65:14"> 以扫对他父亲说：「父啊，你只有一样可祝的福吗？我父啊，求你也为我祝福！」以扫就放声而哭。</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 27:28; 希伯来书 11:20; 约书亚记 24:4"> <span className="pl pl-1">他父亲以撒说：</span><br /><span className="pl pl-1">地上的肥土必为你所住；</span><br /><span className="pl pl-1">天上的甘露必为你所得。</span><br /></span>
<span className="v" id="v40" data-v="40" data-xref="列王纪下 8:20–22; 创世记 25:23; 历代志下 25:11–12"> <span className="pl pl-1">你必倚靠刀剑度日，</span><br /><span className="pl pl-1">又必事奉你的兄弟；</span><br /><span className="pl pl-1">到你强盛的时候，</span><br /><span className="pl pl-1">必从你颈项上挣开他的轭。</span></span>
<span className="v" id="v41" data-v="41" data-xref="约翰一书 3:12–15; 创世记 37:4; 创世记 50:3–4"> 以扫因他父亲给雅各祝的福，就怨恨雅各，心里说：「为我父亲居丧的日子近了，到那时候，我要杀我的兄弟雅各。」</span>
<span className="v" id="v42" data-v="42" data-xref="创世记 37:18–20; 撒母耳记上 30:5; 创世记 42:21–22"> 有人把利百加大儿子以扫的话告诉利百加，她就打发人去，叫了她小儿子雅各来，对他说：「你哥哥以扫想要杀你，报仇雪恨。</span>
<span className="v" id="v43" data-v="43" data-xref="创世记 27:8; 创世记 11:31; 创世记 27:13"> 现在，我儿，你要听我的话：起来，逃往哈兰、我哥哥拉班那里去，</span>
<span className="v" id="v44" data-v="44" data-xref="创世记 31:38; 创世记 31:41"> 同他住些日子，直等你哥哥的怒气消了。</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 19:21; 创世记 4:8–16; 创世记 9:5–6"> 你哥哥向你消了怒气，忘了你向他所做的事，我便打发人去把你从那里带回来。为什么一日丧你们二人呢？」</span>
</div>
</div>

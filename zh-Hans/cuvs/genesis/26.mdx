## 以撒住在基拉耳

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 12:10; 创世记 25:11; 创世记 21:22–32"> 在亚伯拉罕的日子，那地有一次饥荒；这时又有饥荒，以撒就往基拉耳去，到非利士人的王亚比米勒那里。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 12:7; 诗篇 37:3; 创世记 17:1"> 耶和华向以撒显现，说：「你不要下埃及去，要住在我所指示你的地。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 28:15; 诗篇 105:9; 创世记 17:8"> 你寄居在这地，我必与你同在，赐福给你，因为我要将这些地都赐给你和你的后裔。我必坚定我向你父亚伯拉罕所起的誓。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 3:25; 创世记 15:5; 创世记 22:17–18"> 我要加增你的后裔，像天上的星那样多，又要将这些地都赐给你的后裔。并且地上万国必因你的后裔得福—</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 7:24; 创世记 22:18; 创世记 22:16"> 都因亚伯拉罕听从我的话，遵守我的吩咐和我的命令、律例、法度。」</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 20:1"> 以撒就住在基拉耳。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 29:25; 创世记 12:13; 创世记 20:2"> 那地方的人问到他的妻子，他便说：「那是我的妹子。」原来他怕说：「是我的妻子」；他心里想：「恐怕这地方的人为利百加的缘故杀我」，因为她容貌俊美。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 62:5; 箴言 5:18–19; 箴言 7:6"> 他在那里住了许久。有一天，非利士人的王亚比米勒从窗户里往外观看，见以撒和他的妻子利百加戏玩。</span>
<span className="v" id="v9" data-v="9"> 亚比米勒召了以撒来，对他说：「她实在是你的妻子，你怎么说她是你的妹子？」以撒说：「我心里想，恐怕我因她而死。」</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 20:9–10; 创世记 12:18–19"> 亚比米勒说：「你向我们做的是什么事呢？民中险些有人和你的妻同寝，把我们陷在罪里。」</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 105:15; 创世记 20:6; 箴言 6:29"> 于是亚比米勒晓谕众民说：「凡沾着这个人，或是他妻子的，定要把他治死。」</span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 4:8; 创世记 24:1; 创世记 26:3"> 以撒在那地耕种，那一年有百倍的收成。耶和华赐福给他，</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 112:3; 箴言 10:22; 创世记 24:35"> 他就昌大，日增月盛，成了大富户。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 37:11; 创世记 13:2; 箴言 27:4"> 他有羊群牛群，又有许多仆人，非利士人就嫉妒他。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 21:30; 创世记 21:25"> 当他父亲亚伯拉罕在世的日子，他父亲的仆人所挖的井，非利士人全都塞住，填满了土。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 1:9"> 亚比米勒对以撒说：「你离开我们去吧。因为你比我们强盛得多。」</span>
<span className="v" id="v17" data-v="17"> 以撒就离开那里，在基拉耳谷支搭帐棚，住在那里。</span>
<span className="v" id="v18" data-v="18" data-xref="撒迦利亚书 13:2; 何西阿书 2:17; 民数记 32:38"> 当他父亲亚伯拉罕在世之日所挖的水井因非利士人在亚伯拉罕死后塞住了，以撒就重新挖出来，仍照他父亲所叫的叫那些井的名字。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 4:10–11; 约翰福音 7:38; 雅歌 4:15"> 以撒的仆人在谷中挖井，便得了一口活水井。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 21:25"> 基拉耳的牧人与以撒的牧人争竞，说：「这水是我们的。」以撒就给那井起名叫埃色<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是相争的意思">a</a></sup>，因为他们和他相争。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯拉记 4:6"> 以撒的仆人又挖了一口井，他们又为这井争竞，因此以撒给这井起名叫西提拿<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就是为敌的意思">b</a></sup>。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 17:6; 出埃及记 1:7; 诗篇 118:5"> 以撒离开那里，又挖了一口井，他们不为这井争竞了，他就给那井起名叫利河伯<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="就是宽阔的意思">c</a></sup>。他说：「耶和华现在给我们宽阔之地，我们必在这地昌盛。」</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 20:1; 创世记 21:31; 创世记 46:1"> 以撒从那里上别是巴去。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 15:1; 出埃及记 3:6; 以赛亚书 43:1–2"> 当夜耶和华向他显现，说：「我是你父亲亚伯拉罕的 神，不要惧怕！因为我与你同在，要赐福给你，并要为我仆人亚伯拉罕的缘故，使你的后裔繁多。」</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 13:18; 诗篇 116:17; 创世记 12:7–8"> 以撒就在那里筑了一座坛，求告耶和华的名，并且支搭帐棚；他的仆人便在那里挖了一口井。</span>
</div>
</div>

## 以撒跟亚比米勒立约

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="创世记 21:22–32; 创世记 20:3"> 亚比米勒，同他的朋友亚户撒和他的军长非各，从基拉耳来见以撒。</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 26:16; 士师记 11:7; 使徒行传 7:14"> 以撒对他们说：「你们既然恨我，打发我走了，为什么到我这里来呢？」</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 21:22–23; 以赛亚书 45:14; 以赛亚书 61:9"> 他们说：「我们明明地看见耶和华与你同在，便说，不如我们两下彼此起誓，彼此立约，</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 24:31; 创世记 21:22; 创世记 22:17"> 使你不害我们，正如我们未曾害你，一味地厚待你，并且打发你平平安安地走。你是蒙耶和华赐福的了。」</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 19:3; 罗马书 12:18; 希伯来书 12:14"> 以撒就为他们设摆筵席，他们便吃了喝了。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记上 20:16–17; 希伯来书 6:16; 创世记 25:33"> 他们清早起来彼此起誓。以撒打发他们走，他们就平平安安地离开他走了。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 10:4; 箴言 13:4; 箴言 2:4–5"> 那一天，以撒的仆人来，将挖井的事告诉他说：「我们得了水了。」</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 21:31; 创世记 26:28"> 他就给那井起名叫示巴；因此那城叫做别是巴，直到今日。</span>
</div>
</div>

## 以扫的外族妻子

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="创世记 36:2; 创世记 36:13; 出埃及记 34:16"> 以扫四十岁的时候娶了赫人比利的女儿犹滴，与赫人以伦的女儿巴实抹为妻。</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 27:46–2; 创世记 28:8; 创世记 6:2"> 她们常使以撒和利百加心里愁烦。</span>

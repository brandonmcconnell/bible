## 失落的杯

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 42:25; 创世记 43:16; 创世记 24:2"> 约瑟吩咐家宰说：「把粮食装满这些人的口袋，尽着他们的驴所能驮的，又把各人的银子放在各人的口袋里，</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 8:8; 创世记 42:20; 申命记 8:16"> 并将我的银杯和那少年人籴粮的银子一同装在他的口袋里。」家宰就照约瑟所说的话行了；</span>
<span className="v" id="v3" data-v="3"> 天一亮就打发那些人带着驴走了。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 10:32; 诗篇 35:12; 箴言 17:13"> 他们出城走了不远，约瑟对家宰说：「起来，追那些人去，追上了就对他们说：『你们为什么以恶报善呢？</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 30:27; 利未记 19:26; 列王纪下 21:6"> 这不是我主人饮酒的杯吗？岂不是他占卜用的吗？你们这样行是作恶了。』」</span>
<span className="v" id="v6" data-v="6"> 家宰追上他们，将这些话对他们说了。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 38:16–18; 创世记 37:18–32; 列王纪下 8:13"> 他们回答说：「我主为什么说这样的话呢？你仆人断不能做这样的事。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 43:12; 创世记 42:35; 罗马书 13:9"> 你看，我们从前在口袋里所见的银子，尚且从迦南地带来还你，我们怎能从你主人家里偷窃金银呢？</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 31:32; 诗篇 7:3–5; 约伯记 31:38–40"> 你仆人中无论在谁那里搜出来，就叫他死，我们也作我主的奴仆。」</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 22:3; 创世记 44:17; 创世记 44:33"> 家宰说：「现在就照你们的话行吧！在谁那里搜出来，谁就作我的奴仆；其余的都没有罪。」</span>
<span className="v" id="v11" data-v="11"> 于是他们各人急忙把口袋卸在地上，各人打开口袋。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 44:26–32; 创世记 42:36–38; 创世记 43:14"> 家宰就搜查，从年长的起到年幼的为止，那杯竟在便雅悯的口袋里搜出来。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 1:11; 创世记 37:29–34; 撒母耳记下 1:2"> 他们就撕裂衣服，各人把驮子抬在驴上，回城去了。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 50:18; 创世记 43:25; 创世记 43:16"> 犹大和他弟兄们来到约瑟的屋中，约瑟还在那里，他们就在他面前俯伏于地。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 4:10; 创世记 21:26; 创世记 3:13"> 约瑟对他们说：「你们做的是什么事呢？你们岂不知像我这样的人必能占卜吗？」</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 44:9; 但以理书 9:7; 民数记 32:23"> 犹大说：「我们对我主说什么呢？还有什么话可说呢？我们怎能自己表白出来呢？ 神已经查出仆人的罪孽了。我们与那在他手中搜出杯来的都是我主的奴仆。」</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 17:15; 撒母耳记下 23:3; 创世记 18:25"> 约瑟说：「我断不能这样行！在谁的手中搜出杯来，谁就作我的奴仆；至于你们，可以平平安安地上你们父亲那里去。」</span>
</div>
</div>

## 犹大替便雅悯哀求

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 32:22; 创世记 41:40; 创世记 18:30"> 犹大挨近他，说：「我主啊，求你容仆人说一句话给我主听，不要向仆人发烈怒，因为你如同法老一样。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 43:7; 创世记 43:29; 创世记 42:7–10"> 我主曾问仆人们说：『你们有父亲有兄弟没有？』</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 37:3; 创世记 42:38; 路加福音 7:12"> 我们对我主说：『我们有父亲，已经年老，还有他老年所生的一个小孩子。他哥哥死了，他母亲只撇下他一人，他父亲疼爱他。』</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 42:15; 创世记 42:20; 阿摩司书 9:4"> 你对仆人说：『把他带到我这里来，叫我亲眼看看他。』</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 44:30; 创世记 42:38"> 我们对我主说：『童子不能离开他父亲，若是离开，他父亲必死。』</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 43:5; 创世记 43:3; 创世记 42:15–20"> 你对仆人说：『你们的小兄弟若不与你们一同下来，你们就不得再见我的面。』</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 42:29–34"> 我们上到你仆人—我们父亲那里，就把我主的话告诉了他。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 43:2; 创世记 43:5"> 我们的父亲说：『你们再去给我籴些粮来。』</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 11:7; 创世记 43:4–5"> 我们就说：『我们不能下去。我们的小兄弟若和我们同往，我们就可以下去。因为，小兄弟若不与我们同往，我们必不得见那人的面。』</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 46:19; 创世记 35:16–18; 创世记 30:22–25"> 你仆人—我父亲对我们说：『你们知道我的妻子给我生了两个儿子。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 37:33; 创世记 37:13–14; 创世记 42:36"> 一个离开我出去了；我说他必是被撕碎了，直到如今我也没有见他。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 42:38; 创世记 43:14; 申命记 31:17"> 现在你们又要把这个带去离开我，倘若他遭害，那便是你们使我白发苍苍、悲悲惨惨地下阴间去了。』</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 18:1; 撒母耳记下 18:33; 创世记 44:31"> 我父亲的命与这童子的命相连。如今我回到你仆人—我父亲那里，若没有童子与我们同在，</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 44:29; 创世记 37:35; 哥林多后书 7:10"> 我们的父亲见没有童子，他就必死。这便是我们使你仆人—我们的父亲白发苍苍、悲悲惨惨地下阴间去了。</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 43:8–9; 创世记 43:16"> 因为仆人曾向我父亲为这童子作保，说：『我若不带他回来交给父亲，我便在父亲面前永远担罪。』</span>
<span className="v" id="v33" data-v="33" data-xref="约翰一书 3:16; 出埃及记 32:32; 希伯来书 7:22"> 现在求你容仆人住下，替这童子作我主的奴仆，叫童子和他哥哥们一同上去。</span>
<span className="v" id="v34" data-v="34" data-xref="以斯帖记 8:6; 诗篇 116:3; 诗篇 119:143"> 若童子不和我同去，我怎能上去见我父亲呢？恐怕我看见灾祸临到我父亲身上。」</span>
</div>
</div>

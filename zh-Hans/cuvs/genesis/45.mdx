## 约瑟和兄弟相认

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 18:15; 使徒行传 10:41; 创世记 43:30–31"> 约瑟在左右站着的人面前情不自禁，吩咐一声说：「人都要离开我出去！」约瑟和弟兄们相认的时候并没有一人站在他面前。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 46:29; 使徒行传 20:37; 民数记 14:1"> 他就放声大哭；埃及人和法老家中的人都听见了。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 7:13; 使徒行传 9:5; 撒迦利亚书 12:10"> 约瑟对他弟兄们说：「我是约瑟。我的父亲还在吗？」他弟兄不能回答，因为在他面前都惊惶。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="创世记 37:28; 马太福音 14:27; 创世记 50:18"> 约瑟又对他弟兄们说：「请你们近前来。」他们就近前来。他说：「我是你们的兄弟约瑟，就是你们所卖到埃及的。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 50:20; 使徒行传 7:9–15; 创世记 45:7–8"> 现在，不要因为把我卖到这里自忧自恨。这是 神差我在你们以先来，为要保全生命。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 47:23; 创世记 41:54; 创世记 41:56"> 现在这地的饥荒已经二年了，还有五年不能耕种，不能收成。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 44:4; 使徒行传 7:35; 诗篇 18:50"> 神差我在你们以先来，为要给你们存留余种在世上，又要大施拯救，保全你们的生命。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 15:16; 罗马书 9:16; 约翰福音 19:11"> 这样看来，差我到这里来的不是你们，乃是 神。他又使我如法老的父，作他全家的主，并埃及全地的宰相。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 45:19–20; 创世记 45:13"> 你们要赶紧上到我父亲那里，对他说：『你儿子约瑟这样说： 神使我作全埃及的主，请你下到我这里来，不要耽延。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 9:26; 出埃及记 8:22; 创世记 46:34–6"> 你和你的儿子孙子，连牛群羊群，并一切所有的，都可以住在歌珊地，与我相近。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 47:12; 创世记 47:6; 马太福音 15:5–6"> 我要在那里奉养你；因为还有五年的饥荒，免得你和你的眷属，并一切所有的，都败落了。』</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 42:23; 路加福音 24:39; 约翰福音 20:27"> 况且你们的眼和我兄弟便雅悯的眼都看见是我亲口对你们说话。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 7:14; 启示录 21:23; 彼得前书 1:10–12"> 你们也要将我在埃及一切的荣耀和你们所看见的事都告诉我父亲，又要赶紧地将我父亲搬到我这里来。」</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 33:4; 创世记 29:11; 创世记 46:29"> 于是约瑟伏在他兄弟便雅悯的颈项上哭，便雅悯也在他的颈项上哭。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 15:20; 撒母耳记上 10:1; 诗篇 77:4"> 他又与众弟兄亲嘴，抱着他们哭，随后他弟兄们就和他说话。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="创世记 41:33; 以斯帖记 1:21; 创世记 20:15"> 这风声传到法老的宫里，说：「约瑟的弟兄们来了。」法老和他的臣仆都很喜欢。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 42:25–26; 创世记 44:1–2"> 法老对约瑟说：「你吩咐你的弟兄们说：『你们要这样行：把驮子抬在牲口上，起身往迦南地去。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 27:28; 民数记 18:12; 创世记 47:6"> 将你们的父亲和你们的眷属都搬到我这里来，我要把埃及地的美物赐给你们，你们也要吃这地肥美的出产。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 46:5; 创世记 45:27; 创世记 31:17–18"> 现在我吩咐你们要这样行：从埃及地带着车辆去，把你们的孩子和妻子，并你们的父亲都搬来。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 1:19; 路加福音 17:31; 申命记 7:16"> 你们眼中不要爱惜你们的家具，因为埃及全地的美物都是你们的。』」</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 45:19; 以西结书 23:24; 耶利米哀歌 1:18"> 以色列的儿子们就如此行。约瑟照着法老的吩咐给他们车辆和路上用的食物，</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 43:34; 列王纪下 5:5; 士师记 14:12"> 又给他们各人一套衣服，惟独给便雅悯三百银子，五套衣服；</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 24:10; 出埃及记 16:3; 创世记 43:11"> 送给他父亲公驴十匹，驮着埃及的美物，母驴十匹，驮着粮食与饼和菜，为他父亲路上用。</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦前书 5:13; 诗篇 133:1–3; 创世记 42:21–22"> 于是约瑟打发他弟兄们回去，又对他们说：「你们不要在路上相争。」</span>
<span className="v" id="v25" data-v="25"> 他们从埃及上去，来到迦南地、他们的父亲雅各那里，</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 44:28; 创世记 37:35; 路加福音 24:34"> 告诉他说：「约瑟还在，并且作埃及全地的宰相。」雅各心里冰凉，因为不信他们。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 85:6; 以赛亚书 57:15; 创世记 45:19"> 他们便将约瑟对他们说的一切话都告诉了他。他们父亲雅各又看见约瑟打发来接他的车辆，心就苏醒了。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 2:28–30; 约翰福音 16:21–22; 创世记 46:30"> 以色列说：「罢了！罢了！我的儿子约瑟还在，趁我未死以先，我要去见他一面。」</span>
</div>
</div>

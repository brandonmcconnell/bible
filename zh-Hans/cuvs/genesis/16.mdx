## 夏甲和以实玛利

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 4:24; 创世记 12:16; 创世记 15:2–3"> 亚伯兰的妻子撒莱不给他生儿女。撒莱有一个使女，名叫夏甲，是埃及人。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 21:4; 创世记 18:10; 创世记 3:17"> 撒莱对亚伯兰说：「耶和华使我不能生育。求你和我的使女同房，或者我可以因她得孩子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="得孩子：原文是被建立">a</a></sup>。」亚伯兰听从了撒莱的话。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 16:5; 创世记 12:4–5; 撒母耳记下 5:13"> 于是亚伯兰的妻子撒莱将使女埃及人夏甲给了丈夫为妾；那时亚伯兰在迦南已经住了十年。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 30:23; 撒母耳记下 6:16; 哥林多前书 13:4–5"> 亚伯兰与夏甲同房，夏甲就怀了孕；她见自己有孕，就小看她的主母。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 31:53; 出埃及记 5:21; 诗篇 7:8"> 撒莱对亚伯兰说：「我因你受屈。我将我的使女放在你怀中，她见自己有了孕，就小看我。愿耶和华在你我中间判断。」</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 38:5; 箴言 14:29; 彼得前书 3:7"> 亚伯兰对撒莱说：「使女在你手下，你可以随意待她。」撒莱苦待她，她就从撒莱面前逃走了。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 25:18; 出埃及记 15:22; 创世记 21:17"> 耶和华的使者在旷野书珥路上的水泉旁遇见她，</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 3:9; 创世记 4:10; 传道书 10:4"> 对她说：「撒莱的使女夏甲，你从哪里来？要往哪里去？」夏甲说：「我从我的主母撒莱面前逃出来。」</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 5:5–6; 传道书 10:4; 提多书 2:9"> 耶和华的使者对她说：「你回到你主母那里，服在她手下」；</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 17:20; 诗篇 83:6–7; 创世记 25:12–18"> 又说：「我必使你的后裔极其繁多，甚至不可胜数」；</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 2:23–24; 出埃及记 3:7; 以赛亚书 7:14"> 并说：「你如今怀孕要生一个儿子，可以给他起名叫以实玛利<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就是 神听见的意思">b</a></sup>，因为耶和华听见了你的苦情。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 25:18; 创世记 21:20; 约伯记 39:5–8"> 他为人必像野驴。他的手要攻打人，人的手也要攻打他；他必住在众弟兄的东边。」</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 139:1–12; 创世记 32:30; 箴言 5:21"> 夏甲就称那对她说话的耶和华为「看顾人的 神」。因而说：「在这里我也看见那看顾我的吗？」</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 24:62; 创世记 25:11; 创世记 21:31"> 所以这井名叫庇耳·拉海·莱。这井正在加低斯和巴列中间。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 25:12; 创世记 21:9–21; 创世记 17:25–26"> 后来夏甲给亚伯兰生了一个儿子；亚伯兰给他起名叫以实玛利。</span>
<span className="v" id="v16" data-v="16"> 夏甲给亚伯兰生以实玛利的时候，亚伯兰年八十六岁。</span>
</div>

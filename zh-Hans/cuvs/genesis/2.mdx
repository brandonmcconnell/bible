## 伊甸园

<div className="bt">
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="创世记 5:1; 启示录 1:8; 创世记 1:4"> 创造天地的来历，在耶和华 神造天地的日子，乃是这样，</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 3:23; 希伯来书 6:7; 约伯记 5:10"> 野地还没有草木，田间的菜蔬还没有长起来；因为耶和华 神还没有降雨在地上，也没有人耕地，</span>
<span className="v" id="v6" data-v="6"> 但有雾气从地上腾，滋润遍地。</span>
<span className="v" id="v7" data-v="7" data-xref="传道书 12:7; 约伯记 33:4; 哥林多前书 15:45"> 耶和华 神用地上的尘土造人，将生气吹在他鼻孔里，他就成了有灵的活人，名叫 亚当。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 28:13; 创世记 3:24; 创世记 13:10"> 耶和华 神在东方的伊甸立了一个园子，把所造的人安置在那里。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 3:22; 启示录 2:7; 启示录 22:14"> 耶和华 神使各样的树从地里长出来，可以悦人的眼目，其上的果子好作食物。园子当中又有生命树和分别善恶的树。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 22:1; 诗篇 46:4"> 有河从伊甸流出来，滋润那园子，从那里分为四道：</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 25:18; 创世记 10:29; 撒母耳记上 15:7"> 第一道名叫比逊，就是环绕哈腓拉全地的。在那里有金子，</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 28:20; 民数记 11:7; 以西结书 28:13"> 并且那地的金子是好的；在那里又有珍珠和红玛瑙。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 10:6; 以赛亚书 11:11"> 第二道河名叫基训，就是环绕古实全地的。</span>
<span className="v" id="v14" data-v="14" data-xref="但以理书 10:4; 创世记 15:18; 申命记 1:7"> 第三道河名叫底格里斯，流在亚述的东边。第四道河就是幼发拉底河。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 128:2; 创世记 2:8; 以弗所书 4:28"> 耶和华 神将那人安置在伊甸园，使他修理，看守。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 15:22; 提摩太前书 4:4; 提摩太前书 6:17"> 耶和华 神吩咐他说：「园中各样树上的果子，你可以随意吃，</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 6:23; 雅各书 1:15; 创世记 3:19"> 只是分别善恶树上的果子，你不可吃，因为你吃的日子必定死！」</span>
<span className="v" id="v18" data-v="18" data-xref="传道书 4:9–12; 哥林多前书 11:7–12; 箴言 18:22"> 耶和华 神说：「那人独居不好，我要为他造一个配偶帮助他。」</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 8:4–8; 创世记 1:28; 创世记 9:2"> 耶和华 神用土所造成的野地各样走兽和空中各样飞鸟都带到那人面前，看他叫什么。那人怎样叫各样的活物，那就是它的名字。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 2:18"> 那人便给一切牲畜和空中飞鸟、野地走兽都起了名；只是那人没有遇见配偶帮助他。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 15:12; 约伯记 4:13; 撒母耳记上 26:12"> 耶和华 神使他沉睡，他就睡了；于是取下他的一条肋骨，又把肉合起来。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 11:8–9; 提摩太前书 2:13; 希伯来书 13:4"> 耶和华 神就用那人身上所取的肋骨造成一个女人，领她到那人跟前。</span>
<span className="v" id="v23" data-v="23" data-xref="以弗所书 5:28–30; 哥林多前书 11:8–9; 撒母耳记下 5:1"> 那人说：<br /><span className="pl pl-1">这是我骨中的骨，</span><br /><span className="pl pl-1">肉中的肉，</span><br /><span className="pl pl-1">可以称她为「女人」，</span><br /><span className="pl pl-1">因为她是从「男人」身上取出来的。</span></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 19:3–9; 以弗所书 5:28–31; 马可福音 10:6–12"> 因此，人要离开父母，与妻子连合，二人成为一体。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 3:7; 创世记 3:10–11; 罗马书 10:11"> 当时夫妻二人赤身露体，并不羞耻。</span>

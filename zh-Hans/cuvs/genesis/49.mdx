## 雅各的遗嘱

<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="民数记 24:14; 耶利米书 23:20; 但以理书 10:14"> 雅各叫了他的儿子们来，说：「你们都来聚集，我好把你们日后必遇的事告诉你们。</span>

</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="申命记 21:17; 诗篇 78:51; 诗篇 105:36"> <span className="pl pl-1">吕便哪，你是我的长子，</span><br /><span className="pl pl-1">是我力量强壮的时候生的，</span><br /><span className="pl pl-1">本当大有尊荣，权力超众。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="创世记 34:25–31; 创世记 46:10–11; 创世记 29:33–34"> <span className="pl pl-1">西缅和利未是弟兄；</span><br /><span className="pl pl-1">他们的刀剑是残忍的器具。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="创世记 34:30; 诗篇 26:9; 诗篇 16:9"> <span className="pl pl-1">我的灵啊，不要与他们同谋；</span><br /><span className="pl pl-1">我的心哪，不要与他们联络；</span><br /><span className="pl pl-1">因为他们趁怒杀害人命，</span><br /><span className="pl pl-1">任意砍断牛腿大筋。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="希伯来书 7:14; 创世记 27:29; 历代志上 5:2"> <span className="pl pl-1">犹大啊，你弟兄们必赞美你；</span><br /><span className="pl pl-1">你手必掐住仇敌的颈项；</span><br /><span className="pl pl-1">你父亲的儿子们必向你下拜。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="民数记 24:9; 民数记 23:24; 启示录 5:5"> <span className="pl pl-1">犹大是个小狮子；</span><br /><span className="pl pl-1">我儿啊，你抓了食便上去。</span><br /><span className="pl pl-1">你屈下身去，卧如公狮，</span><br /><span className="pl pl-1">蹲如母狮，谁敢惹你？</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 1:32–33; 民数记 24:17; 以赛亚书 9:6"> <span className="pl pl-1">圭必不离犹大，</span><br /><span className="pl pl-1">杖必不离他两脚之间，</span><br /><span className="pl pl-1">直等细罗</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是赐平安者">a</a></sup><br /><span className="pl pl-1">来到，</span><br /><span className="pl pl-1">万民都必归顺。</span><br /></span>

<span className="v" id="v12" data-v="12" data-xref="箴言 23:29"> <span className="pl pl-1">他的眼睛必因酒红润；</span><br /><span className="pl pl-1">他的牙齿必因奶白亮。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="申命记 33:18–19; 创世记 30:20; 约书亚记 19:10–16"> <span className="pl pl-1">西布伦必住在海口，</span><br /><span className="pl pl-1">必成为停船的海口；</span><br /><span className="pl pl-1">他的境界必延到西顿。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="历代志上 12:32; 创世记 30:18; 申命记 33:18"> <span className="pl pl-1">以萨迦是个强壮的驴，</span><br /><span className="pl pl-1">卧在羊圈之中。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 81:6; 马太福音 23:4; 约书亚记 14:15"> <span className="pl pl-1">他以安静为佳，以肥地为美，</span><br /><span className="pl pl-1">便低肩背重，成为服苦的仆人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="创世记 30:6; 申命记 33:22; 士师记 18:26–27"> <span className="pl pl-1">但必判断他的民，</span><br /><span className="pl pl-1">作以色列支派之一。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 12:35; 士师记 18:22–31; 士师记 14:1–15"> <span className="pl pl-1">但必作道上的蛇，路中的虺，</span><br /><span className="pl pl-1">咬伤马蹄，使骑马的坠落于后。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 119:174; 诗篇 119:166; 弥迦书 7:7"> <span className="pl pl-1">耶和华啊，我向来等候你的救恩。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="创世记 30:11; 历代志上 5:11–22; 申命记 33:20–21"> <span className="pl pl-1">迦得必被敌军追逼，</span><br /><span className="pl pl-1">他却要追逼他们的脚跟。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="申命记 33:24–25; 创世记 30:13; 创世记 46:17"> <span className="pl pl-1">亚设之地必出肥美的粮食，</span><br /><span className="pl pl-1">且出君王的美味。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="申命记 33:23; 创世记 30:8; 约书亚记 19:32–39"> <span className="pl pl-1">拿弗他利是被释放的母鹿；</span><br /><span className="pl pl-1">他出嘉美的言语。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="创世记 41:52; 诗篇 128:3; 诗篇 1:1–3"> <span className="pl pl-1">约瑟是多结果子的树枝，</span><br /><span className="pl pl-1">是泉旁多结果的枝子；</span><br /><span className="pl pl-1">他的枝条探出墙外。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="创世记 37:24; 诗篇 64:3; 诗篇 118:13"> <span className="pl pl-1">弓箭手将他苦害，</span><br /><span className="pl pl-1">向他射箭，逼迫他。</span><br /></span>

<span className="v" id="v26" data-v="26" data-xref="申命记 33:15–16; 哈巴谷书 3:6; 以赛亚书 66:5"> <span className="pl pl-1">你父亲所祝的福</span><br /><span className="pl pl-1">胜过我祖先所祝的福，</span><br /><span className="pl pl-1">如永世的山岭，至极的边界；</span><br /><span className="pl pl-1">这些福必降在约瑟的头上，</span><br /><span className="pl pl-1">临到那与弟兄迥别之人的顶上。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="士师记 20:25; 创世记 35:18; 以西结书 22:27"> <span className="pl pl-1">便雅悯是个撕掠的狼，</span><br /><span className="pl pl-1">早晨要吃他所抓的，</span><br /><span className="pl pl-1">晚上要分他所夺的。」</span></span>

</div>

## 雅各的死和埋葬

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="创世记 47:30; 创世记 50:13; 创世记 15:15"> 他又嘱咐他们说：「我将要归到我列祖<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是本民">b</a></sup>那里，你们要将我葬在赫人以弗 田间的洞里，与我祖我父在一处，</span>

## 神应许亚伯拉罕得儿子

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 14:13; 创世记 48:3; 创世记 13:18"> 耶和华在幔利橡树那里向亚伯拉罕显现出来。那时正热，亚伯拉罕坐在帐棚门口，</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 13:2; 创世记 18:22; 创世记 19:1"> 举目观看，见有三个人在对面站着。他一见，就从帐棚门口跑去迎接他们，俯伏在地，</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 32:5"> 说：「我主，我若在你眼前蒙恩，求你不要离开仆人往前去。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 24:32; 创世记 19:2; 创世记 43:24"> 容我拿点水来，你们洗洗脚，在树下歇息歇息。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 104:15; 士师记 13:15; 士师记 6:18"> 我再拿一点饼来，你们可以加添心力，然后往前去。你们既到仆人这里来，理当如此。」他们说：「就照你说的行吧。」</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 13:33; 希伯来书 13:2; 使徒行传 16:15"> 亚伯拉罕急忙进帐棚见撒拉，说：「你速速拿三细亚细面调和做饼。」</span>
<span className="v" id="v7" data-v="7" data-xref="玛拉基书 1:14; 路加福音 15:27; 路加福音 15:30"> 亚伯拉罕又跑到牛群里，牵了一只又嫩又好的牛犊来，交给仆人，仆人急忙预备好了。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 19:3; 士师记 13:15; 启示录 3:20"> 亚伯拉罕又取了奶油和奶，并预备好的牛犊来，摆在他们面前，自己在树下站在旁边，他们就吃了。</span>
<span className="v" id="v9" data-v="9" data-xref="提多书 2:5; 创世记 24:67; 创世记 4:9"> 他们问亚伯拉罕说：「你妻子撒拉在哪里？」他说：「在帐棚里。」</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 21:2; 创世记 17:21; 罗马书 9:8–9"> 三人中有一位说：「到明年这时候，我必要回到你这里；你的妻子撒拉必生一个儿子。」撒拉在那人后边的帐棚门口也听见了这话。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 17:17; 希伯来书 11:11–12; 路加福音 1:36"> 亚伯拉罕和撒拉年纪老迈，撒拉的月经已断绝了。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 3:6; 创世记 17:17; 路加福音 1:18–20"> 撒拉心里暗笑，说：「我既已衰败，我主也老迈，岂能有这喜事呢？」</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 2:25"> 耶和华对亚伯拉罕说：「撒拉为什么暗笑，说：『我既已年老，果真能生养吗？』</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 1:37; 马太福音 19:26; 马可福音 10:27"> 耶和华岂有难成的事吗？到了日期，明年这时候，我必回到你这里，撒拉必生一个儿子。」</span>
<span className="v" id="v15" data-v="15" data-xref="约翰一书 1:8; 箴言 28:13; 以弗所书 4:23"> 撒拉就害怕，不承认，说：「我没有笑。」那位说：「不然，你实在笑了。」</span>
</div>
</div>

## 亚伯拉罕为所多玛祈求

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行传 15:3; 使徒行传 21:5; 使徒行传 20:38"> 三人就从那里起行，向所多玛观看，亚伯拉罕也与他们同行，要送他们一程。</span>
<span className="v" id="v17" data-v="17" data-xref="阿摩司书 3:7; 诗篇 25:14; 约翰福音 15:15"> 耶和华说：「我所要做的事岂可瞒着亚伯拉罕呢？</span>
<span className="v" id="v18" data-v="18" data-xref="加拉太书 3:8; 创世记 26:4; 加拉太书 3:14"> 亚伯拉罕必要成为强大的国；地上的万国都必因他得福。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 6:6–7; 申命记 4:9–10; 提摩太前书 3:4–5"> 我眷顾他，为要叫他吩咐他的众子和他的眷属遵守我的道，秉公行义，使我所应许亚伯拉罕的话都成就了。」</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 19:13; 以西结书 16:49–50; 以赛亚书 3:9"> 耶和华说：「所多玛和蛾摩拉的罪恶甚重，声闻于我。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 3:8; 创世记 11:5; 西番雅书 1:12"> 我现在要下去，察看他们所行的，果然尽像那达到我耳中的声音一样吗？若是不然，我也必知道。」</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 19:1; 使徒行传 7:55; 以西结书 22:30"> 二人转身离开那里，向所多玛去；但亚伯拉罕仍旧站在耶和华面前。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 16:22; 撒母耳记下 24:17; 创世记 20:4"> 亚伯拉罕近前来，说：「无论善恶，你都要剿灭吗？</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 5:1; 以赛亚书 1:9; 马太福音 7:13–14"> 假若那城里有五十个义人，你还剿灭那地方吗？不为城里这五十个义人饶恕其中的人吗？</span>
<span className="v" id="v25" data-v="25" data-xref="约伯记 8:3; 以赛亚书 3:10–11; 约伯记 8:20"> 将义人与恶人同杀，将义人与恶人一样看待，这断不是你所行的。审判全地的主岂不行公义吗？」</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 5:1; 马太福音 24:22; 以赛亚书 65:8"> 耶和华说：「我若在所多玛城里见有五十个义人，我就为他们的缘故饶恕那地方的众人。」</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 3:19; 以赛亚书 6:5; 哥林多前书 15:47–48"> 亚伯拉罕说：「我虽然是灰尘，还敢对主说话。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 18:29; 列王纪上 20:32–33; 创世记 18:26"> 假若这五十个义人短了五个，你就因为短了五个毁灭全城吗？」他说：「我在那里若见有四十五个，也不毁灭那城。」</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所书 6:18; 希伯来书 4:16"> 亚伯拉罕又对他说：「假若在那里见有四十个怎么样呢？」他说：「为这四十个的缘故，我也不做这事。」</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 89:7; 诗篇 9:12; 以斯帖记 4:11–16"> 亚伯拉罕说：「求主不要动怒，容我说，假若在那里见有三十个怎么样呢？」他说：「我在那里若见有三十个，我也不做这事。」</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 11:8; 创世记 18:27; 路加福音 18:1"> 亚伯拉罕说：「我还敢对主说话，假若在那里见有二十个怎么样呢？」他说：「为这二十个的缘故，我也不毁灭那城。」</span>
<span className="v" id="v32" data-v="32" data-xref="雅各书 5:15–17; 士师记 6:39; 马太福音 7:7"> 亚伯拉罕说：「求主不要动怒，我再说这一次，假若在那里见有十个呢？」他说：「为这十个的缘故，我也不毁灭那城。」</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 18:22; 创世记 32:26; 创世记 31:55"> 耶和华与亚伯拉罕说完了话就走了；亚伯拉罕也回到自己的地方去了。</span>

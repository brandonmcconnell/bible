## 所多玛的罪恶

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 18:22; 创世记 18:1–5; 希伯来书 13:2"> 那两个天使晚上到了所多玛；罗得正坐在所多玛城门口，看见他们，就起来迎接，脸伏于地下拜，</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 18:4; 路加福音 24:28–29; 希伯来书 13:2"> 说：「我主啊，请你们到仆人家里洗洗脚，住一夜，清早起来再走。」他们说：「不！我们要在街上过夜。」</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 18:6–8; 士师记 6:19; 撒母耳记上 28:24"> 罗得切切地请他们，他们这才进去，到他屋里。罗得为他们预备筵席，烤无酵饼，他们就吃了。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 13:13; 箴言 4:16; 出埃及记 23:2"> 他们还没有躺下，所多玛城里各处的人，连老带少，都来围住那房子，</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 19:22; 以赛亚书 3:9; 犹大书 1:7"> 呼叫罗得说：「今日晚上到你这里来的人在哪里呢？把他们带出来，任我们所为。」</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 19:23"> 罗得出来，把门关上，到众人那里，</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 6:9–11; 士师记 19:23; 利未记 20:13"> 说：「众弟兄，请你们不要做这恶事。</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 19:24; 创世记 19:31–38; 士师记 9:15"> 我有两个女儿，还是处女，容我领出来，任凭你们的心愿而行；只是这两个人既然到我舍下，不要向他们做什么。」</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 2:14; 彼得后书 2:7–8; 创世记 13:12"> 众人说：「退去吧！」又说：「这个人来寄居，还想要作官哪！现在我们要害你比害他们更甚。」众人就向前拥挤罗得，要攻破房门。</span>
<span className="v" id="v10" data-v="10"> 只是那二人伸出手来，将罗得拉进屋去，把门关上，</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 6:18; 使徒行传 13:11; 申命记 28:28–29"> 并且使门外的人，无论老少，眼都昏迷；他们摸来摸去，总寻不着房门。</span>
</div>
</div>

## 罗得离开所多玛

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 7:1; 彼得后书 2:7; 启示录 18:4"> 二人对罗得说：「你这里还有什么人吗？无论是女婿是儿女，和这城中一切属你的人，你都要将他们从这地方带出去。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 18:20; 马太福音 13:49–50; 犹大书 1:7"> 我们要毁灭这地方；因为城内罪恶的声音在耶和华面前甚大，耶和华差我们来，要毁灭这地方。」</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 16:21; 耶利米书 51:6; 民数记 16:45"> 罗得就出去，告诉娶了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：将要娶">a</a></sup>他女儿的女婿们说：「你们起来离开这地方，因为耶和华要毁灭这城。」他女婿们却以为他说的是戏言。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数记 16:24–27; 启示录 18:4; 创世记 19:22"> 天明了，天使催逼罗得说：「起来！带着你的妻子和你在这里的两个女儿出去，免得你因这城里的罪恶同被剿灭。」</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 9:15–16; 提多书 3:5; 约翰福音 6:44"> 但罗得迟延不走。二人因为耶和华怜恤罗得，就拉着他的手和他妻子的手，并他两个女儿的手，把他们领出来，安置在城外；</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 24:16–18; 路加福音 9:62; 腓立比书 3:13–14"> 领他们出来以后，就说：「逃命吧！不可回头看，也不可在平原站住。要往山上逃跑，免得你被剿灭。」</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 13:6–8; 使徒行传 10:14; 创世记 32:26"> 罗得对他们说：「我主啊，不要如此！</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 27:1; 诗篇 103:1–22; 提摩太前书 1:14–16"> 你仆人已经在你眼前蒙恩；你又向我显出莫大的慈爱，救我的性命。我不能逃到山上去，恐怕这灾祸临到我，我便死了。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 119:175; 箴言 3:5–7; 创世记 19:30"> 看哪，这座城又小又近，容易逃到，这不是一个小的吗？求你容我逃到那里，我的性命就得存活。」</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 145:19; 诗篇 34:15; 诗篇 102:17"> 天使对他说：「这事我也应允你；我不倾覆你所说的这城。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 13:10; 创世记 14:2; 创世记 32:25–28"> 你要速速地逃到那城；因为你还没有到那里，我不能做什么。」因此那城名叫琐珥<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就是小的意思">b</a></sup>。</span>
</div>
</div>

## 所多玛蛾摩拉的毁灭

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23"> 罗得到了琐珥，日头已经出来了。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 29:23; 以赛亚书 13:19; 阿摩司书 4:11"> 当时，耶和华将硫磺与火从天上耶和华那里降与所多玛和蛾摩拉，</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 107:34; 创世记 14:3; 创世记 13:10"> 把那些城和全平原，并城里所有的居民，连地上生长的，都毁灭了。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 17:31–32; 创世记 19:17; 箴言 14:14"> 罗得的妻子在后边回头一看，就变成了一根盐柱。</span>
<span className="v" id="v27" data-v="27" data-xref="哈巴谷书 2:1; 诗篇 5:3; 希伯来书 2:1"> 亚伯拉罕清早起来，到了他从前站在耶和华面前的地方，</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 18:9; 启示录 9:2; 启示录 21:8"> 向所多玛和蛾摩拉与平原的全地观看，不料，那地方烟气上腾，如同烧窑一般。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 8:1; 申命记 9:5; 创世记 18:23–33"> 当 神毁灭平原诸城的时候，他记念亚伯拉罕，正在倾覆罗得所住之城的时候，就打发罗得从倾覆之中出来。</span>
</div>
</div>

## 摩押人和亚扪人的起源

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="创世记 19:19; 以赛亚书 15:5; 雅各书 1:8"> 罗得因为怕住在琐珥，就同他两个女儿从琐珥上去，住在山里；他和两个女儿住在一个洞里。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 25:5; 以赛亚书 4:1; 创世记 16:2"> 大女儿对小女儿说：「我们的父亲老了，地上又无人按着世上的常规进到我们这里。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 18:6–7; 创世记 11:3; 创世记 9:21"> 来！我们可以叫父亲喝酒，与他同寝。这样，我们好从他存留后裔。」</span>
<span className="v" id="v33" data-v="33" data-xref="哈巴谷书 2:15–16; 箴言 23:29–35; 箴言 20:1"> 于是，那夜她们叫父亲喝酒，大女儿就进去和她父亲同寝；她几时躺下，几时起来，父亲都不知道。</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米书 8:12; 耶利米书 6:15; 以赛亚书 3:9"> 第二天，大女儿对小女儿说：「我昨夜与父亲同寝。今夜我们再叫他喝酒，你可以进去与他同寝。这样，我们好从父亲存留后裔。」</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 24:16; 诗篇 8:4; 彼得前书 4:7"> 于是，那夜她们又叫父亲喝酒，小女儿起来与她父亲同寝；她几时躺下，几时起来，父亲都不知道。</span>
<span className="v" id="v36" data-v="36" data-xref="哈巴谷书 2:15; 士师记 1:7; 马太福音 7:2"> 这样，罗得的两个女儿都从她父亲怀了孕。</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 2:9; 列王纪下 3:1–27; 民数记 21:29"> 大女儿生了儿子，给他起名叫摩押，就是现今摩押人的始祖。</span>
<span className="v" id="v38" data-v="38" data-xref="申命记 2:19; 士师记 10:6–40; 诗篇 83:4–8"> 小女儿也生了儿子，给他起名叫便·亚米，就是现今亚扪人的始祖。</span>
</div>
</div>

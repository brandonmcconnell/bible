## 洪水消退

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 30:22; 创世记 19:29; 诗篇 136:23"> 神记念挪亚和挪亚方舟里的一切走兽牲畜。 神叫风吹地，水势渐落。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 7:11; 马太福音 8:26–27; 箴言 8:28"> 渊源和天上的窗户都闭塞了，天上的大雨也止住了。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 7:24; 创世记 7:11"> 水从地上渐退。过了一百五十天，水就渐消。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 19:37; 耶利米书 51:27; 以赛亚书 37:38"> 七月十七日，方舟停在亚拉腊山上。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 7:11"> 水又渐消，到十月初一日，山顶都现出来了。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 6:16; 但以理书 6:10"> 过了四十天，挪亚开了方舟的窗户，</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 147:9; 列王纪上 17:6; 列王纪上 17:4"> 放出一只乌鸦去；那乌鸦飞来飞去，直到地上的水都干了。</span>
<span className="v" id="v8" data-v="8" data-xref="雅歌 2:14; 雅歌 1:15; 马太福音 10:16"> 他又放出一只鸽子去，要看看水从地上退了没有。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 11:28; 诗篇 116:7; 申命记 28:65"> 但遍地上都是水，鸽子找不着落脚之地，就回到方舟挪亚那里，挪亚伸手把鸽子接进方舟来。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 7:4; 创世记 7:10; 创世记 8:12"> 他又等了七天，再把鸽子从方舟放出去。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 8:15; 撒迦利亚书 4:12–14; 罗马书 10:15"> 到了晚上，鸽子回到他那里，嘴里叼着一个新拧下来的橄榄叶子，挪亚就知道地上的水退了。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 25:9; 以赛亚书 30:18; 创世记 8:10"> 他又等了七天，放出鸽子去，鸽子就不再回来了。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 7:11"> 到挪亚六百零一岁，正月初一日，地上的水都干了。挪亚撤去方舟的盖观看，便见地面上干了。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 7:13–14; 创世记 7:11"> 到了二月二十七日，地就都干了。</span>
<span className="v" id="v15" data-v="15"> 神对挪亚说：</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 7:13; 诗篇 121:8; 诗篇 91:11"> 「你和你的妻子、儿子、儿妇都可以出方舟。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 1:22; 创世记 9:1; 耶利米书 31:27–28"> 在你那里凡有血肉的活物，就是飞鸟、牲畜，和一切爬在地上的昆虫，都要带出来，叫它在地上多多滋生，大大兴旺。」</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 121:8"> 于是挪亚和他的妻子、儿子、儿妇都出来了。</span>
<span className="v" id="v19" data-v="19"> 一切走兽、昆虫、飞鸟，和地上所有的动物，各从其类，也都出了方舟。</span>
</div>
</div>

## 挪亚献祭

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="希伯来书 13:15–16; 罗马书 12:1; 创世记 22:9"> 挪亚为耶和华筑了一座坛，拿各类洁净的牲畜、飞鸟献在坛上为燔祭。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 2:15; 以弗所书 5:2; 以赛亚书 54:9–10"> 耶和华闻那馨香之气，就心里说：「我不再因人的缘故咒诅地（人从小时心里怀着恶念），也不再按着我才行的灭各种的活物了。</span>
<span className="v" id="v22" data-v="22" data-xref="雅各书 5:7; 诗篇 74:16–17; 耶利米书 5:24"> 地还存留的时候，稼穑、寒暑、冬夏、昼夜就永不停息了。」</span>
</div>
</div>

## 约瑟和他的兄弟

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 17:8; 创世记 23:4; 创世记 36:7"> 雅各住在迦南地，就是他父亲寄居的地。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 35:25–26; 创世记 35:22; 撒母耳记上 2:22–24"> 雅各的记略如下。<br />约瑟十七岁与他哥哥们一同牧羊。他是个童子，与他父亲的妾辟拉、悉帕的儿子们常在一处。约瑟将他哥哥们的恶行报给他们的父亲。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 3:35; 创世记 37:32; 撒母耳记下 13:18"> 以色列原来爱约瑟过于爱他的众子，因为约瑟是他年老生的；他给约瑟做了一件彩衣。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 27:41; 约翰一书 3:12; 约翰一书 4:20"> 约瑟的哥哥们见父亲爱约瑟过于爱他们，就恨约瑟，不与他说和睦的话。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 28:12; 创世记 42:9; 约翰福音 17:14"> 约瑟做了一梦，告诉他哥哥们，他们就越发恨他。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 44:18; 士师记 9:7"> 约瑟对他们说：「请听我所做的梦：</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 44:14; 创世记 42:6; 创世记 43:26"> 我们在田里捆禾稼，我的捆起来站着，你们的捆来围着我的捆下拜。」</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 10:27; 使徒行传 7:35; 希伯来书 10:29"> 他的哥哥们回答说：「难道你真要作我们的王吗？难道你真要管辖我们吗？」他们就因为他的梦和他的话越发恨他。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 7:9–14; 创世记 37:7; 但以理书 8:10"> 后来他又做了一梦，也告诉他的哥哥们说：「看哪，我又做了一梦，梦见太阳、月亮，与十一个星向我下拜。」</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 27:29; 腓立比书 2:10–11; 以赛亚书 60:14"> 约瑟将这梦告诉他父亲和他哥哥们，他父亲就责备他说：「你做的这是什么梦！难道我和你母亲、你弟兄果然要来俯伏在地，向你下拜吗？」</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 7:9; 路加福音 2:19; 路加福音 2:51"> 他哥哥们都嫉妒他，他父亲却把这话存在心里。</span>
</div>
</div>

## 约瑟被卖到埃及

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 37:1; 创世记 33:18; 创世记 34:25–31"> 约瑟的哥哥们往示剑去放他们父亲的羊。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 6:1–3; 撒母耳记上 3:8; 撒母耳记上 3:16"> 以色列对约瑟说：「你哥哥们不是在示剑放羊吗？你来，我要打发你往他们那里去。」约瑟说：「我在这里。」</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 35:27; 路加福音 19:42; 诗篇 125:5"> 以色列说：「你去看看你哥哥们平安不平安，群羊平安不平安，就回来报信给我」；于是打发他出希伯 谷，他就往示剑去了。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 4:27; 士师记 4:22; 创世记 21:14"> 有人遇见他在田野走迷了路，就问他说：「你找什么？」</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:10; 雅歌 1:7"> 他说：「我找我的哥哥们，求你告诉我，他们在何处放羊。」</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 6:13"> 那人说：「他们已经走了，我听见他们说要往多坍去。」约瑟就去追赶他哥哥们，遇见他们在多坍。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 23:12; 诗篇 37:12; 诗篇 37:32"> 他们远远地看见他，趁他还没有走到跟前，大家就同谋要害死他，</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 28:12; 创世记 37:11; 创世记 37:5"> 彼此说：「你看！那做梦的来了。</span>
<span className="v" id="v20" data-v="20" data-xref="提多书 3:3; 箴言 27:4; 马太福音 2:2–16"> 来吧！我们将他杀了，丢在一个坑里，就说有恶兽把他吃了。我们且看他的梦将来怎么样。」</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 42:22; 创世记 35:22; 约书亚记 10:28"> 吕便听见了，要救他脱离他们的手，说：「我们不可害他的性命」；</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 22:12; 申命记 13:9; 创世记 42:22"> 又说：「不可流他的血，可以把他丢在这野地的坑里，不可下手害他。」吕便的意思是要救他脱离他们的手，把他归还他的父亲。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 37:3; 马太福音 27:28; 创世记 42:21"> 约瑟到了他哥哥们那里，他们就剥了他的外衣，就是他穿的那件彩衣，</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 38:6; 诗篇 130:1–2; 撒迦利亚书 9:11"> 把他丢在坑里；那坑是空的，里头没有水。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 37:28; 创世记 43:11; 耶利米书 8:22"> 他们坐下吃饭，举目观看，见有一伙米甸 的以实玛利人从基列来，用骆驼驮着香料、乳香、没药，要带下埃及去。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 37:20; 创世记 4:10; 创世记 25:32"> 犹大对众弟兄说：「我们杀我们的兄弟，藏了他的血有什么益处呢？</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 16:26; 创世记 42:21; 撒母耳记上 18:17"> 我们不如将他卖给以实玛利人，不可下手害他；因为他是我们的兄弟，我们的骨肉。」众弟兄就听从了他。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 7:9; 诗篇 105:17; 创世记 45:4–5"> 有些米甸的商人从那里经过，哥哥们就把约瑟从坑里拉上来，讲定二十舍客勒银子，把约瑟卖给以实玛利人。他们就把约瑟带到埃及去了。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约伯记 1:20; 创世记 37:34; 创世记 44:13"> 吕便回到坑边，见约瑟不在坑里，就撕裂衣服，</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 42:13; 耶利米书 31:15; 创世记 42:32"> 回到兄弟们那里，说：「童子没有了。我往哪里去才好呢？」</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 37:23; 箴言 28:13; 创世记 37:3"> 他们宰了一只公山羊，把约瑟的那件彩衣染了血，</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 15:30; 创世记 37:3; 创世记 44:20–23"> 打发人送到他们的父亲那里，说：「我们捡了这个；请认一认是你儿子的外衣不是？」</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 37:20; 创世记 44:28; 约翰福音 13:7"> 他认得，就说：「这是我儿子的外衣。有恶兽把他吃了，约瑟被撕碎了！撕碎了！」</span>
<span className="v" id="v34" data-v="34" data-xref="创世记 37:29; 撒母耳记下 3:31; 诗篇 69:11"> 雅各便撕裂衣服，腰间围上麻布，为他儿子悲哀了多日。</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 42:38; 约伯记 2:11; 撒母耳记下 12:17"> 他的儿女都起来安慰他，他却不肯受安慰，说：「我必悲哀着下阴间，到我儿子那里。」约瑟的父亲就为他哀哭。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="创世记 40:4; 创世记 37:28; 列王纪下 25:8"> 米甸人带约瑟到埃及，把他卖给法老的内臣—护卫长波提乏。</span>
</div>
</div>

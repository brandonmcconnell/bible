## 雅各到了拉班的家

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 6:3; 士师记 6:33; 何西阿书 12:12"> 雅各起行，到了东方人之地，</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 4:14; 以赛亚书 49:10; 约翰福音 4:6"> 看见田间有一口井，有三群羊卧在井旁；因为人饮羊群都是用那井里的水。井口上的石头是大的。</span>
<span className="v" id="v3" data-v="3"> 常有羊群在那里聚集，牧人把石头转离井口饮羊，随后又把石头放在井口的原处。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 28:10; 创世记 27:43; 使徒行传 7:2"> 雅各对牧人说：「弟兄们，你们是哪里来的？」他们说：「我们是哈兰来的。」</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 24:24; 创世记 24:29; 创世记 31:53"> 他问他们说：「拿鹤的孙子拉班，你们认识吗？」他们说：「我们认识。」</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 20:9; 创世记 37:14; 出埃及记 18:7"> 雅各说：「他平安吗？」他们说：「平安。看哪，他女儿拉结领着羊来了。」</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 5:16; 加拉太书 6:9–10"> 雅各说：「日头还高，不是羊群聚集的时候，你们不如饮羊，再去放一放。」</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 16:3; 路加福音 24:2; 创世记 34:14"> 他们说：「我们不能，必等羊群聚齐，人把石头转离井口才可饮羊。」</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 2:21; 雅歌 1:7–8; 出埃及记 2:15–16"> 雅各正和他们说话的时候，拉结领着她父亲的羊来了，因为那些羊是她牧放的。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 2:17"> 雅各看见母舅拉班的女儿拉结和母舅拉班的羊群，就上前把石头转离井口，饮他母舅拉班的羊群。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 33:4; 创世记 45:14–15; 创世记 45:2"> 雅各与拉结亲嘴，就放声而哭。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 24:28; 创世记 13:8; 创世记 14:14–16"> 雅各告诉拉结，自己是她父亲的外甥，是利百加的儿子，拉结就跑去告诉她父亲。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 24:29; 使徒行传 20:37; 罗马书 16:16"> 拉班听见外甥雅各的信息，就跑去迎接，抱着他，与他亲嘴，领他到自己的家。雅各将一切的情由告诉拉班。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 19:12–13; 创世记 2:23; 士师记 9:2"> 拉班对他说：「你实在是我的骨肉。」雅各就和他同住了一个月。</span>
</div>
</div>

## 雅各为拉结和利亚服事拉班

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="创世记 30:28; 创世记 31:7"> 拉班对雅各说：「你虽是我的骨肉<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是弟兄">a</a></sup>，岂可白白地服事我？请告诉我，你要什么为工价？」</span>
<span className="v" id="v16" data-v="16" data-xref="路得记 4:11; 创世记 49:31; 创世记 31:4"> 拉班有两个女儿，大的名叫利亚，小的名叫拉结。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 12:11; 创世记 46:19–22; 创世记 24:16"> 利亚的眼睛没有神气，拉结却生得美貌俊秀。</span>
<span className="v" id="v18" data-v="18" data-xref="何西阿书 12:12; 出埃及记 22:16–17; 创世记 34:12"> 雅各爱拉结，就说：「我愿为你小女儿拉结服事你七年。」</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 6:11; 以赛亚书 6:5; 诗篇 12:2"> 拉班说：「我把她给你，胜似给别人，你与我同住吧！」</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 13:7; 以弗所书 5:2; 何西阿书 12:12"> 雅各就为拉结服事了七年；他因为深爱拉结，就看这七年如同几天。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 15:1; 创世记 29:20; 创世记 4:1"> 雅各对拉班说：「日期已经满了，求你把我的妻子给我，我好与她同房。」</span>
<span className="v" id="v22" data-v="22" data-xref="启示录 19:9; 路得记 4:10–13; 士师记 14:10–18"> 拉班就摆设筵席，请齐了那地方的众人。</span>
<span className="v" id="v23" data-v="23" data-xref="弥迦书 7:5; 创世记 38:14–15; 创世记 24:65"> 到晚上，拉班将女儿利亚送来给雅各，雅各就与她同房。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 16:1; 创世记 30:9–12; 创世记 46:18"> 拉班又将婢女悉帕给女儿利亚作使女。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 7:2; 箴言 11:31; 哥林多前书 3:13"> 到了早晨，雅各一看是利亚，就对拉班说：「你向我做的是什么事呢？我服事你，不是为拉结吗？你为什么欺哄我呢？」</span>
<span className="v" id="v26" data-v="26"> 拉班说：「大女儿还没有给人，先把小女儿给人，在我们这地方没有这规矩。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 18:18; 士师记 14:12; 创世记 2:2–3"> 你为这个满了七日，我就把那个也给你，你再为她服事我七年。」</span>
<span className="v" id="v28" data-v="28"> 雅各就如此行。满了利亚的七日，拉班便将女儿拉结给雅各为妻。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 35:22; 创世记 29:24; 创世记 30:3–8"> 拉班又将婢女辟拉给女儿拉结作使女。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 31:41; 创世记 29:20; 创世记 31:15"> 雅各也与拉结同房，并且爱拉结胜似爱利亚，于是又服事了拉班七年。</span>
</div>
</div>

## 雅各的儿女

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒母耳记上 2:21; 马太福音 10:37; 申命记 21:15"> 耶和华见利亚失宠<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是被恨；下同">b</a></sup>，就使她生育，拉结却不生育。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 26:7; 出埃及记 4:31; 出埃及记 3:7"> 利亚怀孕生子，就给他起名叫吕便<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="就是有儿子的意思">c</a></sup>，因而说：「耶和华看见我的苦情，如今我的丈夫必爱我。」</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 34:25; 创世记 49:5–6; 创世记 34:30"> 她又怀孕生子，就说：「耶和华因为听见我失宠，所以又赐给我这个儿子」，于是给他起名叫西缅<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="就是听见的意思">d</a></sup>。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 32:26–29; 创世记 49:5–7; 创世记 46:11"> 她又怀孕生子，起名叫利未<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="就是联合的意思">e</a></sup>，说：「我给丈夫生了三个儿子，他必与我联合。」</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 1:2; 历代志上 5:2; 创世记 49:8–12"> 她又怀孕生子，说：「这回我要赞美耶和华」，因此给他起名叫犹大<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="就是赞美的意思">f</a></sup>。这才停了生育。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="创世记 28:3–4; 创世记 24:3; 创世记 27:46"> 以撒叫了雅各来，给他祝福，并嘱咐他说：「你不要娶迦南的女子为妻。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 25:20; 何西阿书 12:12; 创世记 24:50"> 你起身往巴旦·亚兰去，到你外祖彼土利家里，在你母舅拉班的女儿中娶一女为妻。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 48:3; 创世记 35:11; 创世记 1:28"> 愿全能的 神赐福给你，使你生养众多，成为多族，</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 3:14; 创世记 12:7; 以弗所书 1:3"> 将应许亚伯拉罕的福赐给你和你的后裔，使你承受你所寄居的地为业，就是 神赐给亚伯拉罕的地。」</span>
<span className="v" id="v5" data-v="5"> 以撒打发雅各走了，他就往巴旦·亚兰去，到亚兰人彼土利的儿子拉班那里。拉班是雅各、以扫的母舅。</span>
</div>
</div>

## 以扫另娶一妻

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 27:33; 创世记 28:1"> 以扫见以撒已经给雅各祝福，而且打发他往巴旦·亚兰去，在那里娶妻，并见祝福的时候嘱咐他说：「不要娶迦南的女子为妻」，</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 6:1; 以弗所书 6:3; 歌罗西书 3:20"> 又见雅各听从父母的话往巴旦·亚兰去了，</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 24:3; 创世记 26:34–35; 撒母耳记上 8:6"> 以扫就晓得他父亲以撒看不中迦南的女子，</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 36:3; 创世记 36:18; 创世记 36:13"> 便往以实玛利那里去，在他二妻之外又娶了玛哈拉为妻。她是亚伯拉罕儿子以实玛利的女儿，尼拜约的妹子。</span>
</div>
</div>

## 雅各在伯特利做的梦

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 7:2; 创世记 11:31; 创世记 32:10"> 雅各出了别是巴，向哈兰走去；</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 8:20; 创世记 28:18; 创世记 31:46"> 到了一个地方，因为太阳落了，就在那里住宿，便拾起那地方的一块石头枕在头下，在那里躺卧睡了，</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 1:51; 民数记 12:6; 创世记 32:1–2"> 梦见一个梯子立在地上，梯子的头顶着天，有 神的使者在梯子上，上去下来。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 13:15; 创世记 48:3; 创世记 35:12"> 耶和华站在梯子以上<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：站在他旁边">a</a></sup>，说：「我是耶和华—你祖亚伯拉罕的 神，也是以撒的 神；我要将你现在所躺卧之地赐给你和你的后裔。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 12:3; 使徒行传 3:25; 创世记 18:18"> 你的后裔必像地上的尘沙那样多，必向东西南北开展；地上万族必因你和你的后裔得福。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 1:5; 以赛亚书 41:10; 耶利米书 1:19"> 我也与你同在。你无论往哪里去，我必保佑你，领你归回这地，总不离弃你，直到我成全了向你所应许的。」</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 5:15; 出埃及记 3:5; 出埃及记 15:11"> 雅各睡醒了，说：「耶和华真在这里，我竟不知道！」</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太前书 3:15; 创世记 35:1–13; 传道书 5:1"> 就惧怕，说：「这地方何等可畏！这不是别的，乃是 神的殿，也是天的门。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="创世记 35:14; 创世记 31:45; 创世记 31:13"> 雅各清早起来，把所枕的石头立作柱子，浇油在上面。</span>
<span className="v" id="v19" data-v="19" data-xref="何西阿书 12:4–5; 创世记 35:1; 创世记 48:3"> 他就给那地方起名叫伯特利<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就是 神殿的意思">b</a></sup>；但那地方起先名叫路斯。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太前书 6:8; 撒母耳记下 15:8; 创世记 31:13"> 雅各许愿说：「 神若与我同在，在我所行的路上保佑我，又给我食物吃，衣服穿，</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 11:31; 申命记 26:17; 撒母耳记下 19:24"> 使我平平安安地回到我父亲的家，我就必以耶和华为我的 神。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 35:7; 创世记 14:20; 申命记 14:22–23"> 我所立为柱子的石头也必作 神的殿；凡你所赐给我的，我必将十分之一献给你。」</span>
</div>
</div>

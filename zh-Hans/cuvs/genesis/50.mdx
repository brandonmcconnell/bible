<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 46:4; 申命记 6:7–8; 使徒行传 8:2"> 约瑟伏在他父亲的面上哀哭，与他亲嘴。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 50:26; 历代志下 16:14; 约翰福音 19:39–40"> 约瑟吩咐伺候他的医生用香料薰他父亲，医生就用香料薰了以色列。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 20:29; 申命记 34:8; 创世记 50:10"> 薰尸的常例是四十天；那四十天满了，埃及人为他哀哭了七十天。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="创世记 18:3; 以斯帖记 4:2"> 为他哀哭的日子过了，约瑟对法老家中的人说：「我若在你们眼前蒙恩，请你们报告法老说：</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 16:14; 以赛亚书 22:16; 马太福音 27:60"> 『我父亲要死的时候叫我起誓说：你要将我葬在迦南地，在我为自己所掘的坟墓里。』现在求你让我上去葬我父亲，以后我必回来。」</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 48:21"> 法老说：「你可以上去，照着你父亲叫你起的誓，将他葬埋。」</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 14:16"> 于是约瑟上去葬他父亲。与他一同上去的，有法老的臣仆和法老家中的长老，并埃及国的长老，</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 32:24–27; 出埃及记 10:26; 出埃及记 10:8–9"> 还有约瑟的全家和他的弟兄们，并他父亲的眷属；只有他们的妇人孩子，和羊群牛群，都留在歌珊地。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 14:28; 列王纪下 18:24; 雅歌 1:9"> 又有车辆马兵，和他一同上去；那一帮人甚多。</span>
<span className="v" id="v10" data-v="10" data-xref="约伯记 2:13; 使徒行传 8:2; 撒母耳记下 1:17"> 他们到了约旦河外、亚达的禾场，就在那里大大地号咷痛哭。约瑟为他父亲哀哭了七天。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 10:15–19; 创世记 24:6; 申命记 11:30"> 迦南的居民见亚达禾场上的哀哭，就说：「这是埃及人一场极大的哀哭。」因此那地方名叫亚伯·麦西，是在约旦河东。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 7:16; 创世记 49:29–32; 以弗所书 6:1"> 雅各的儿子们就遵着他父亲所吩咐的办了，</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 49:29–31; 创世记 23:16–18; 使徒行传 7:16"> 把他搬到迦南地，葬在幔利前、麦比拉田间的洞里；那洞和田是亚伯拉罕向赫人以弗 买来为业，作坟地的。</span>
<span className="v" id="v14" data-v="14"> 约瑟葬了他父亲以后，就和众弟兄，并一切同他上去葬他父亲的人，都回埃及去了。</span>
</div>
</div>

## 约瑟安慰哥哥们

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="箴言 28:1; 创世记 42:21–22; 诗篇 53:5"> 约瑟的哥哥们见父亲死了，就说：「或者约瑟怀恨我们，照着我们从前待他一切的恶足足地报复我们。」</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 29:25"> 他们就打发人去见约瑟，说：「你父亲未死以先吩咐说：</span>
<span className="v" id="v17" data-v="17" data-xref="以弗所书 4:32; 马太福音 6:14–15; 创世记 45:8"> 『你们要对约瑟这样说：从前你哥哥们恶待你，求你饶恕他们的过犯和罪恶。』如今求你饶恕你父亲 神之仆人的过犯。」他们对约瑟说这话，约瑟就哭了。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 37:7–11; 创世记 42:6; 创世记 45:3"> 他的哥哥们又来俯伏在他面前，说：「我们是你的仆人。」</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 12:19; 创世记 45:5; 创世记 30:2"> 约瑟对他们说：「不要害怕，我岂能代替 神呢？</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 8:28; 诗篇 119:71; 创世记 45:5–8"> 从前你们的意思是要害我，但 神的意思原是好的，要保全许多人的性命，成就今日的光景。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 47:12; 彼得前书 3:9; 创世记 45:10–11"> 现在你们不要害怕，我必养活你们和你们的妇人孩子。」于是约瑟用亲爱的话安慰他们。</span>
</div>
</div>

## 约瑟的死

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22"> 约瑟和他父亲的眷属都住在埃及。约瑟活了一百一十岁。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 32:39; 创世记 30:3; 约伯记 42:16"> 约瑟得见以法莲第三代的子孙。玛拿西的孙子、玛吉的儿子也养在约瑟的膝上。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 3:16–17; 创世记 35:12; 创世记 26:3"> 约瑟对他弟兄们说：「我要死了，但 神必定看顾你们，领你们从这地上去，到他起誓所应许给亚伯拉罕、以撒、雅各之地。」</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 13:19; 约书亚记 24:32; 创世记 47:29–31"> 约瑟叫以色列的子孙起誓说：「 神必定看顾你们；你们要把我的骸骨从这里搬上去。」</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 50:2–3; 创世记 47:9; 约书亚记 24:29"> 约瑟死了，正一百一十岁。人用香料将他薰了，把他收殓在棺材里，停在埃及。</span>
</div>
</div>

## 雅各祝福以法莲和玛拿西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 41:50–52; 创世记 46:20; 诗篇 128:6"> 这事以后，有人告诉约瑟说：「你的父亲病了。」他就带着两个儿子玛拿西和以法莲同去。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 6:10; 撒母耳记上 23:16; 申命记 3:28"> 有人告诉雅各说：「请看，你儿子约瑟到你这里来了。」以色列就勉强在床上坐起来。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 35:9–12; 出埃及记 6:3; 创世记 28:3"> 雅各对约瑟说：「全能的 神曾在迦南地的路斯向我显现，赐福与我，</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 17:8; 创世记 35:11; 创世记 26:4"> 对我说：『我必使你生养众多，成为多民，又要把这地赐给你的后裔，永远为业。』</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 41:50–52; 约书亚记 14:4; 创世记 46:20"> 我未到埃及见你之先，你在埃及地所生的以法莲和玛拿西这两个儿子是我的，正如吕便和西缅是我的一样。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 14:4"> 你在他们以后所生的就是你的，他们可以归于他们弟兄的名下得产业。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 35:16–19; 马太福音 2:18; 创世记 35:9"> 至于我，我从巴旦来的时候，拉结死在我眼前，在迦南地的路上，离以法他还有一段路程，我就把她葬在以法他的路上（以法他就是伯利恒）。」</span>
<span className="v" id="v8" data-v="8"> 以色列看见约瑟的两个儿子，就说：「这是谁？」</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 27:4; 创世记 33:5; 希伯来书 11:21"> 约瑟对他父亲说：「这是 神在这里赐给我的儿子。」以色列说：「请你领他们到我跟前，我要给他们祝福。」</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 27:1; 创世记 27:27; 撒母耳记上 3:2"> 以色列年纪老迈，眼睛昏花，不能看见。约瑟领他们到他跟前，他就和他们亲嘴，抱着他们。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 3:20; 创世记 45:26; 创世记 42:36"> 以色列对约瑟说：「我想不到得见你的面，不料， 神又使我得见你的儿子。」</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 42:6; 利未记 19:32; 创世记 19:1"> 约瑟把两个儿子从以色列两膝中领出来，自己就脸伏于地下拜。</span>
<span className="v" id="v13" data-v="13"> 随后，约瑟又拉着他们两个，以法莲在他的右手里，对着以色列的左手，玛拿西在他的左手里，对着以色列的右手，领他们到以色列的跟前。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 41:51; 诗篇 118:16; 马太福音 19:15"> 以色列伸出右手来，按在以法莲的头上（以法莲乃是次子），又剪搭过左手来，按在玛拿西的头上（玛拿西原是长子）。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 17:1; 歌罗西书 2:6; 以赛亚书 33:16"> 他就给约瑟祝福说：「愿我祖亚伯拉罕和我父以撒所事奉的 神，就是一生牧养我直到今日的 神，</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 34:22; 创世记 49:22; 创世记 48:5"> 救赎我脱离一切患难的那使者，赐福与这两个童子。愿他们归在我的名下和我祖亚伯拉罕、我父以撒的名下。又愿他们在世界中生养众多。」</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 48:14; 罗马书 9:7–8; 历代志上 21:7"> 约瑟见他父亲把右手按在以法莲的头上，就不喜悦，便提起他父亲的手，要从以法莲头上挪到玛拿西的头上。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 19:18; 创世记 29:26; 创世记 43:33"> 约瑟对他父亲说：「我父，不是这样。这本是长子，求你把右手按在他的头上。」</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 33:17; 民数记 1:33–35; 创世记 25:28"> 他父亲不从，说：「我知道，我儿，我知道。他也必成为一族，也必昌大。只是他的兄弟将来比他还大；他兄弟的后裔要成为多族。」</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 24:60; 路得记 4:11–12; 创世记 28:3"> 当日就给他们祝福说：「以色列人要指着你们祝福说：『愿 神使你如以法莲、玛拿西一样。』」于是立以法莲在玛拿西以上。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 50:24; 创世记 46:4; 创世记 28:15"> 以色列又对约瑟说：「我要死了，但 神必与你们同在，领你们回到你们列祖之地。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 4:5; 约书亚记 24:32; 历代志上 5:2"> 并且我从前用弓用刀从亚摩利人手下夺的那块地，我都赐给你，使你比众弟兄多得一分。」</span>

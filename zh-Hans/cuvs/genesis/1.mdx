## 神的创造

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 1:1–3; 希伯来书 11:3; 以赛亚书 45:18"> 起初， 神创造天地。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 4:23; 诗篇 104:30; 以赛亚书 45:18"> 地是空虚混沌，渊面黑暗； 神的灵运行在水面上。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 4:6; 约翰福音 1:5; 以赛亚书 45:7"> 神说：「要有光」，就有了光。</span>
<span className="v" id="v4" data-v="4" data-xref="传道书 2:13; 创世记 1:18; 传道书 11:7"> 神看光是好的，就把光暗分开了。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 74:16; 以赛亚书 45:7; 帖撒罗尼迦前书 5:5"> 神称光为「昼」，称暗为「夜」。有晚上，有早晨，这是头一日。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="耶利米书 51:15; 诗篇 33:6; 约伯记 37:18"> 神说：「诸水之间要有空气，将水分为上下。」</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 8:28–29; 诗篇 148:4; 马太福音 8:27"> 神就造出空气，将空气以下的水、空气以上的水分开了。事就这样成了。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 1:5; 创世记 1:19; 创世记 1:10"> 神称空气为「天」。有晚上，有早晨，是第二日。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="彼得后书 3:5; 约拿书 1:9; 耶利米书 5:22"> 神说：「天下的水要聚在一处，使旱地露出来。」事就这样成了。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 32:4; 诗篇 104:31; 创世记 1:4"> 神称旱地为「地」，称水的聚处为「海」。 神看着是好的。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 104:14–17; 希伯来书 6:7; 诗篇 147:8"> 神说：「地要发生青草和结种子的菜蔬，并结果子的树木，各从其类，果子都包着核。」事就这样成了。</span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 4:28; 以赛亚书 55:10–11; 马太福音 13:24–26"> 于是地发生了青草和结种子的菜蔬，各从其类；并结果子的树木，各从其类；果子都包着核。 神看着是好的。</span>
<span className="v" id="v13" data-v="13"> 有晚上，有早晨，是第三日。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="诗篇 104:19–20; 申命记 4:19; 耶利米书 31:35"> 神说：「天上要有光体，可以分昼夜，作记号，定节令、日子、年岁，</span>
<span className="v" id="v15" data-v="15"> 并要发光在天空，普照在地上。」事就这样成了。</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 136:7–9; 申命记 4:19; 诗篇 8:3"> 于是 神造了两个大光，大的管昼，小的管夜，又造众星，</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 8:3; 诗篇 8:1; 约伯记 38:12"> 就把这些光摆列在天空，普照在地上，</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 31:35; 诗篇 19:6"> 管理昼夜，分别明暗。 神看着是好的。</span>
<span className="v" id="v19" data-v="19"> 有晚上，有早晨，是第四日。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 2:19; 诗篇 104:24–25; 列王纪上 4:33"> 神说：「水要多多滋生有生命的物；要有雀鸟飞在地面以上，天空之中。」</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 104:24–26; 创世记 1:25; 创世记 8:19"> 神就造出大鱼和水中所滋生各样有生命的动物，各从其类；又造出各样飞鸟，各从其类。 神看着是好的。</span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 40:15; 创世记 8:17; 诗篇 107:38"> 神就赐福给这一切，说：「滋生繁多，充满海中的水；雀鸟也要多生在地上。」</span>
<span className="v" id="v23" data-v="23"> 有晚上，有早晨，是第五日。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="诗篇 50:9–10; 创世记 6:20; 创世记 8:19"> 神说：「地要生出活物来，各从其类；牲畜、昆虫、野兽，各从其类。」事就这样成了。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 27:5; 约伯记 12:8–10; 创世记 2:19–20"> 于是 神造出野兽，各从其类；牲畜，各从其类；地上一切昆虫，各从其类。 神看着是好的。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歌罗西书 3:10; 以弗所书 4:24; 诗篇 8:4–8"> 神说：「我们要照着我们的形象、按着我们的样式造人，使他们管理海里的鱼、空中的鸟、地上的牲畜，和全地，并地上所爬的一切昆虫。」</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 19:4; 以弗所书 2:10; 创世记 5:1–2"> 神就照着自己的形象造人，乃是照着他的形象造男造女。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 9:1; 创世记 9:7; 利未记 26:9"> 神就赐福给他们，又对他们说：「要生养众多，遍满地面，治理这地，也要管理海里的鱼、空中的鸟，和地上各样行动的活物。」</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 9:3; 诗篇 104:14–15; 诗篇 145:15–16"> 神说：「看哪，我将遍地上一切结种子的菜蔬和一切树上所结有核的果子全赐给你们作食物。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 104:14; 诗篇 145:15–16; 诗篇 147:9"> 至于地上的走兽和空中的飞鸟，并各样爬在地上有生命的物，我将青草赐给它们作食物。」事就这样成了。</span>
<span className="v" id="v31" data-v="31" data-xref="提摩太前书 4:4; 诗篇 104:24; 诗篇 19:1–2"> 神看着一切所造的都甚好。有晚上，有早晨，是第六日。</span>
</div>
</div>

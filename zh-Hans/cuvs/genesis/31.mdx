## 雅各逃离拉班

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="传道书 4:4; 诗篇 49:16–17; 约伯记 31:31"> 雅各听见拉班的儿子们有话说：「雅各把我们父亲所有的都夺了去，并借着我们父亲的，得了这一切的荣耀<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：财">a</a></sup>。」</span>
<span className="v" id="v2" data-v="2" data-xref="但以理书 3:19; 撒母耳记上 18:9–11; 创世记 4:5"> 雅各见拉班的气色向他不如从前了。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 28:15; 创世记 32:9; 希伯来书 13:5"> 耶和华对雅各说：「你要回你祖、你父之地，到你亲族那里去，我必与你同在。」</span>
<span className="v" id="v4" data-v="4"> 雅各就打发人，叫拉结和利亚到田野羊群那里来，</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 31:2–3; 创世记 31:53; 创世记 48:15"> 对她们说：「我看你们父亲的气色向我不如从前了；但我父亲的 神向来与我同在。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 30:29; 以弗所书 6:5–8; 提多书 2:9–10"> 你们也知道，我尽了我的力量服事你们的父亲。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 37:28; 创世记 31:29; 民数记 14:22"> 你们的父亲欺哄我，十次改了我的工价；然而 神不容他害我。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 30:32"> 他若说：『有点的归你作工价』，羊群所生的都有点；他若说：『有纹的归你作工价』，羊群所生的都有纹。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 31:1; 创世记 31:16; 箴言 13:22"> 这样， 神把你们父亲的牲畜夺来赐给我了。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 13:1; 创世记 30:39; 创世记 20:6"> 羊配合的时候，我梦中举目一看，见跳母羊的公羊都是有纹的、有点的、有花斑的。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 58:9; 创世记 31:13; 撒母耳记上 3:6"> 神的使者在那梦中呼叫我说：『雅各。』我说：『我在这里。』</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 3:7; 申命记 24:15; 创世记 31:42"> 他说：『你举目观看，跳母羊的公羊都是有纹的、有点的、有花斑的；凡拉班向你所做的，我都看见了。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 31:3; 创世记 32:9; 创世记 28:12–22"> 我是伯特利的 神；你在那里用油浇过柱子，向我许过愿。现今你起来，离开这地，回你本地去吧！』」</span>
<span className="v" id="v14" data-v="14" data-xref="路得记 4:11; 创世记 2:24; 创世记 29:24"> 拉结和利亚回答雅各说：「在我们父亲的家里还有我们可得的分吗？还有我们的产业吗？</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 29:15–20; 创世记 31:41; 创世记 29:27–30"> 我们不是被他当作外人吗？因为他卖了我们，吞了我们的价值。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 30:35–1; 创世记 31:9; 诗篇 45:10"> 神从我们父亲所夺出来的一切财物，那就是我们和我们孩子们的。现今凡 神所吩咐你的，你只管去行吧！」</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 30:17; 创世记 24:61; 创世记 24:10"> 雅各起来，使他的儿子和妻子都骑上骆驼，</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 27:1–2; 创世记 27:41; 创世记 35:27–29"> 又带着他在巴旦·亚兰所得的一切牲畜和财物，往迦南地、他父亲以撒那里去了。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 19:13; 创世记 31:30; 何西阿书 3:4"> 当时拉班剪羊毛去了，拉结偷了他父亲家中的神像。</span>
<span className="v" id="v20" data-v="20"> 雅各背着亚兰人拉班偷走了，并不告诉他，</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 12:17; 创世记 37:25; 创世记 46:28"> 就带着所有的逃跑。他起身过大河，面向基列山行去。</span>
</div>
</div>

## 拉班追赶雅各

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约伯记 5:12–13; 创世记 30:36; 出埃及记 14:5–31"> 到第三日，有人告诉拉班，雅各逃跑了。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 13:8; 创世记 24:27; 出埃及记 2:11"> 拉班带领他的众弟兄去追赶，追了七日，在基列山就追上了。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 24:50; 创世记 31:29; 创世记 20:3"> 夜间， 神到亚兰人拉班那里，在梦中对他说：「你要小心，不可与雅各说好说歹。」</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 12:8; 创世记 33:18; 希伯来书 11:9"> 拉班追上雅各。雅各在山上支搭帐棚；拉班和他的众弟兄也在基列山上支搭帐棚。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记上 30:2; 创世记 12:18; 创世记 20:9–10"> 拉班对雅各说：「你做的是什么事呢？你背着我偷走了，又把我的女儿们带了去，如同用刀剑掳去的一般。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 15:20; 箴言 26:23–26; 创世记 31:3–5"> 你为什么暗暗地逃跑，偷着走，并不告诉我，叫我可以欢乐、唱歌、击鼓、弹琴地送你回去？</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 31:55; 路得记 1:14; 使徒行传 20:37"> 又不容我与外孙和女儿亲嘴？你所行的真是愚昧！</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 31:53; 创世记 31:42; 创世记 31:24"> 我手中原有能力害你，只是你父亲的 神昨夜对我说：『你要小心，不可与雅各说好说歹。』</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 10:11; 创世记 31:19; 士师记 18:24"> 现在你虽然想你父家，不得不去，为什么又偷了我的神像呢？」</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 29:25; 创世记 31:26–27; 创世记 20:11"> 雅各回答拉班说：「恐怕你把你的女儿从我夺去，所以我逃跑。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 12:3–5; 创世记 31:30; 创世记 31:19"> 至于你的神像，你在谁那里搜出来，就不容谁存活。当着我们的众弟兄，你认一认，在我这里有什么东西是你的，就拿去。」原来雅各不知道拉结偷了那些神像。</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 24:67; 创世记 24:28"> 拉班进了雅各、利亚，并两个使女的帐棚，都没有搜出来，就从利亚的帐棚出来，进了拉结的帐棚。</span>
<span className="v" id="v34" data-v="34" data-xref="创世记 31:19; 创世记 31:17"> 拉结已经把神像藏在骆驼的驮篓里，便坐在上头。拉班摸遍了那帐棚，并没有摸着。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 19:32; 出埃及记 20:12; 彼得前书 2:18"> 拉结对她父亲说：「现在我身上不便，不能在你面前起来，求我主不要生气。」这样，拉班搜寻神像，竟没有搜出来。</span>
<span className="v" id="v36" data-v="36" data-xref="以弗所书 4:26; 创世记 49:7; 民数记 16:15"> 雅各就发怒斥责拉班说：「我有什么过犯，有什么罪恶，你竟这样火速地追我？</span>
<span className="v" id="v37" data-v="37" data-xref="彼得前书 2:12; 哥林多前书 6:4–5; 撒母耳记上 12:3–4"> 你摸遍了我一切的家具，你搜出什么来呢？可以放在你我弟兄面前，叫他们在你我中间辨别辨别。</span>
<span className="v" id="v38" data-v="38" data-xref="创世记 30:27; 申命记 28:4; 以西结书 34:2–4"> 我在你家这二十年，你的母绵羊、母山羊没有掉过胎。你群中的公羊，我没有吃过；</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及记 22:31; 出埃及记 22:10–13; 利未记 22:8"> 被野兽撕裂的，我没有带来给你，是我自己赔上。无论是白日，是黑夜，被偷去的，你都向我索要。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 2:8; 出埃及记 2:19–22; 彼得前书 5:2–4"> 我白日受尽干热，黑夜受尽寒霜，不得合眼睡着，我常是这样。</span>
<span className="v" id="v41" data-v="41" data-xref="创世记 31:7; 哥林多前书 15:10; 哥林多后书 11:26"> 我这二十年在你家里，为你的两个女儿服事你十四年，为你的羊群服事你六年，你又十次改了我的工价。</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 31:7; 创世记 31:53; 以赛亚书 8:13"> 若不是我父亲以撒所敬畏的 神，就是亚伯拉罕的 神与我同在，你如今必定打发我空手而去。 神看见我的苦情和我的劳碌，就在昨夜责备你。」</span>
</div>

## 雅各和拉班立约

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43"> 拉班回答雅各说：「这女儿是我的女儿，这些孩子是我的孩子，这些羊群也是我的羊群；凡在你眼前的都是我的。我的女儿并她们所生的孩子，我今日能向他们做什么呢？</span>
<span className="v" id="v44" data-v="44" data-xref="创世记 31:52; 约书亚记 24:25–27; 约书亚记 22:27"> 来吧！你我二人可以立约，作你我中间的证据。」</span>
<span className="v" id="v45" data-v="45" data-xref="创世记 28:18–22"> 雅各就拿一块石头立作柱子，</span>
<span className="v" id="v46" data-v="46" data-xref="传道书 3:5; 创世记 31:23; 创世记 31:54"> 又对众弟兄说：「你们堆聚石头。」他们就拿石头来堆成一堆，大家便在旁边吃喝。</span>
<span className="v" id="v47" data-v="47" data-xref="希伯来书 12:1"> 拉班称那石堆为伊迦尔·撒哈杜他，雅各却称那石堆为迦累得<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="都是以石堆为证的意思">b</a></sup>。</span>
<span className="v" id="v48" data-v="48" data-xref="约书亚记 24:27; 约书亚记 13:8–9; 创世记 31:23"> 拉班说：「今日这石堆作你我中间的证据。」因此这地方名叫迦累得，</span>
<span className="v" id="v49" data-v="49" data-xref="士师记 11:29; 士师记 10:17; 撒母耳记上 7:5–6"> 又叫米斯巴，意思说：「我们彼此离别以后，愿耶和华在你我中间鉴察。</span>
<span className="v" id="v50" data-v="50" data-xref="耶利米书 42:5; 耶利米书 29:23; 弥迦书 1:2"> 你若苦待我的女儿，又在我的女儿以外另娶妻，虽没有人知道，却有 神在你我中间作见证。」</span>
<span className="v" id="v51" data-v="51"> 拉班又说：「你看我在你我中间所立的这石堆和柱子。</span>
<span className="v" id="v52" data-v="52" data-xref="创世记 31:48; 创世记 31:44–45"> 这石堆作证据，这柱子也作证据。我必不过这石堆去害你；你也不可过这石堆和柱子来害我。</span>
<span className="v" id="v53" data-v="53" data-xref="创世记 31:42; 创世记 16:5; 约书亚记 24:2"> 但愿亚伯拉罕的 神和拿鹤的 神，就是他们父亲的 神，在你我中间判断。」雅各就指着他父亲以撒所敬畏的 神起誓，</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及记 18:12; 创世记 37:25; 创世记 26:30"> 又在山上献祭，请众弟兄来吃饭。他们吃了饭，便在山上住宿。</span>
<span className="v" id="v55" data-v="55" data-xref="创世记 31:28; 申命记 23:5; 创世记 18:33"> 拉班清早起来，与他外孙和女儿亲嘴，给他们祝福，回往自己的地方去了。</span>
</div>

## 洪水

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 24:37–39; 彼得后书 2:5–9; 创世记 6:9"> 耶和华对挪亚说：「你和你的全家都要进入方舟；因为在这世代中，我见你在我面前是义人。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 8:20; 利未记 10:10; 利未记 11:1–47"> 凡洁净的畜类，你要带七公七母；不洁净的畜类，你要带一公一母；</span>
<span className="v" id="v3" data-v="3"> 空中的飞鸟也要带七公七母，可以留种，活在全地上；</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 6:13; 创世记 7:12; 创世记 7:17"> 因为再过七天，我要降雨在地上四十昼夜，把我所造的各种活物都从地上除灭。」</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 6:22; 路加福音 8:21; 出埃及记 39:32"> 挪亚就遵着耶和华所吩咐的行了。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 5:32; 创世记 8:13"> 当洪水泛滥在地上的时候，挪亚整六百岁。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 17:27; 创世记 6:18; 马太福音 24:38"> 挪亚就同他的妻和儿子儿妇都进入方舟，躲避洪水。</span>
<span className="v" id="v8" data-v="8"> 洁净的畜类和不洁净的畜类，飞鸟并地上一切的昆虫，</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 7:16; 创世记 2:19; 耶利米书 8:7"> 都是一对一对地，有公有母，到挪亚那里进入方舟，正如 神所吩咐挪亚的。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 6:17; 创世记 7:4; 路加福音 17:27"> 过了那七天，洪水泛滥在地上。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 8:2; 玛拉基书 3:10; 箴言 8:28–29"> 当挪亚六百岁，二月十七日那一天，大渊的泉源都裂开了，天上的窗户也敞开了，</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 7:4; 马太福音 4:2; 创世记 7:17"> 四十昼夜降大雨在地上。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 6:18; 创世记 7:1; 创世记 6:10"> 正当那日，挪亚和他三个儿子闪、含、雅弗，并挪亚的妻子和三个儿妇，都进入方舟。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 7:8–9; 创世记 7:2–3"> 他们和百兽，各从其类，一切牲畜，各从其类，爬在地上的昆虫，各从其类，一切禽鸟，各从其类，都进入方舟。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 6:19–20; 以赛亚书 11:6"> 凡有血肉、有气息的活物，都一对一对地到挪亚那里，进入方舟。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 25:10; 路加福音 13:25; 诗篇 91:1–10"> 凡有血肉进入方舟的，都是有公有母，正如 神所吩咐挪亚的。耶和华就把他关在方舟里头。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 7:4; 创世记 7:12"> 洪水泛滥在地上四十天，水往上长，把方舟从地上漂起。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 14:28; 诗篇 69:15; 约伯记 22:16"> 水势浩大，在地上大大地往上长，方舟在水面上漂来漂去。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 104:6–9; 诗篇 46:2–3; 彼得后书 3:6"> 水势在地上极其浩大，天下的高山都淹没了。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 3:23; 诗篇 104:6"> 水势比山高过十五肘，山岭都淹没了。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 6:13; 创世记 7:4; 创世记 6:17"> 凡在地上有血肉的动物，就是飞鸟、牲畜、走兽，和爬在地上的昆虫，以及所有的人，都死了。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 2:7; 创世记 6:17"> 凡在旱地上、鼻孔有气息的生灵都死了。</span>
<span className="v" id="v23" data-v="23" data-xref="彼得后书 2:5; 彼得前书 3:20; 希伯来书 11:7"> 凡地上各类的活物，连人带牲畜、昆虫，以及空中的飞鸟，都从地上除灭了，只留下挪亚和那些与他同在方舟里的。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 8:3–4"> 水势浩大，在地上共一百五十天。</span>

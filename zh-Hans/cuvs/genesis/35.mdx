## 神在伯特利赐福雅各

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 31:13; 何西阿书 12:4; 诗篇 91:15"> 神对雅各说：「起来！上伯特利去，住在那里；要在那里筑一座坛给 神，就是你逃避你哥哥以扫的时候向你显现的那位。」</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 19:14; 出埃及记 19:10; 以西结书 18:31"> 雅各就对他家中的人并一切与他同在的人说：「你们要除掉你们中间的外邦神，也要自洁，更换衣裳。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 43:2; 创世记 32:7; 创世记 31:3"> 我们要起来，上伯特利去，在那里我要筑一座坛给 神，就是在我遭难的日子应允我的祷告、在我行的路上保佑我的那位。」</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 9:6; 申命记 7:25; 出埃及记 32:20"> 他们就把外邦人的神像和他们耳朵上的环子交给雅各；雅各都藏在示剑那里的橡树底下。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及记 23:27; 历代志下 17:10; 约书亚记 5:1"> 他们便起行前往。 神使那周围城邑的人都甚惊惧，就不追赶雅各的众子了。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 28:19; 创世记 28:22; 创世记 12:8"> 于是雅各和一切与他同在的人到了迦南地的路斯，就是伯特利。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 35:3; 创世记 35:1; 创世记 28:13"> 他在那里筑了一座坛，就给那地方起名叫伊勒·伯特利<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是伯特利之 神的意思">a</a></sup>；因为他逃避他哥哥的时候， 神在那里向他显现。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 24:59; 撒母耳记上 31:13; 士师记 2:5"> 利百加的奶母底波拉死了，就葬在伯特利下边橡树底下；那棵树名叫亚伦·巴古。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 35:1; 创世记 18:1; 创世记 26:2"> 雅各从巴旦·亚兰回来， 神又向他显现，赐福与他，</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 17:5; 创世记 32:27–28; 创世记 17:15"> 且对他说：「你的名原是雅各，从今以后不要再叫雅各，要叫以色列。」这样，他就改名叫以色列。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 17:1; 创世记 9:1; 创世记 22:17"> 神又对他说：「我是全能的 神；你要生养众多，将来有一族和多国的民从你而生，又有君王从你而出。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 12:7; 创世记 28:13; 创世记 26:3–4"> 我所赐给亚伯拉罕和以撒的地，我要赐给你与你的后裔。」</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 17:22; 创世记 18:33; 士师记 6:21"> 神就从那与雅各说话的地方升上去了。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 28:18–19; 撒母耳记上 7:12; 出埃及记 17:15"> 雅各便在那里立了一根石柱，在柱子上奠酒，浇油。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 28:19"> 雅各就给那地方起名叫伯特利。</span>
</div>
</div>

## 拉结去世

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="弥迦书 5:2; 创世记 48:7; 列王纪下 5:19"> 他们从伯特利起行，离以法他还有一段路程，拉结临产甚是艰难。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 30:24; 撒母耳记上 4:19–21"> 正在艰难的时候，收生婆对她说：「不要怕，你又要得一个儿子了。」</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 12:20; 使徒行传 7:59; 路加福音 23:46"> 她将近于死，灵魂要走的时候，就给她儿子起名叫便·俄尼；他父亲却给他起名叫便雅悯。</span>
<span className="v" id="v19" data-v="19" data-xref="弥迦书 5:2; 创世记 48:7; 路得记 4:11"> 拉结死了，葬在以法他的路旁；以法他就是伯利恒。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 10:2; 创世记 35:14; 撒母耳记下 18:17–18"> 雅各在她的坟上立了一统碑，就是拉结的墓碑，到今日还在。</span>
<span className="v" id="v21" data-v="21" data-xref="弥迦书 4:8; 路加福音 2:8"> 以色列起行前往，在以得台那边支搭帐棚。</span>
</div>
</div>

## 雅各的儿子们

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="历代志上 5:1; 利未记 18:8; 撒母耳记下 20:3"> 以色列住在那地的时候，吕便去与他父亲的妾辟拉同寝，以色列也听见了。<br />雅各共有十二个儿子。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 30:18–20; 创世记 46:8–15; 创世记 29:32–35"> 利亚所生的是雅各的长子吕便，还有西缅、利未、犹大、以萨迦、西布伦。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 30:22–24; 创世记 46:19–22; 创世记 35:16–18"> 拉结所生的是约瑟、便雅悯。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 46:23–25; 创世记 37:2; 创世记 30:4–8"> 拉结的使女辟拉所生的是但、拿弗他利。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 30:9–13; 创世记 46:16–18; 创世记 25:20"> 利亚的使女悉帕所生的是迦得、亚设。这是雅各在巴旦·亚兰所生的儿子。</span>
</div>
</div>

## 以撒去世

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="创世记 13:18; 创世记 23:19; 创世记 18:1"> 雅各来到他父亲以撒那里，到了基列·亚巴的幔利，乃是亚伯拉罕和以撒寄居的地方；基列·亚巴就是希伯 。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 25:7; 创世记 50:26; 创世记 47:28"> 以撒共活了一百八十岁。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 15:15; 创世记 49:33; 创世记 49:31"> 以撒年纪老迈，日子满足，气绝而死，归到他列祖<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是本民">b</a></sup>那里。他两个儿子以扫、雅各把他埋葬了。</span>
</div>

## 雅各和以扫相见

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 32:6–7; 创世记 27:41–42; 创世记 32:16"> 雅各举目观看，见以扫来了，后头跟着四百人，他就把孩子们分开交给利亚、拉结，和两个使女，</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 29:30; 创世记 30:22–24; 创世记 37:3"> 并且叫两个使女和她们的孩子在前头，利亚和她的孩子在后头，拉结和约瑟在尽后头。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 42:6; 路加福音 14:11; 创世记 18:2"> 他自己在他们前头过去，一连七次俯伏在地才就近他哥哥。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="创世记 45:14–15; 诗篇 34:4; 路加福音 15:20"> 以扫跑来迎接他，将他抱住，又搂着他的颈项，与他亲嘴，两个人就哭了。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 127:3; 以赛亚书 8:18; 创世记 48:9"> 以扫举目看见妇人孩子，就说：「这些和你同行的是谁呢？」雅各说：「这些孩子是 神施恩给你的仆人的。」</span>
<span className="v" id="v6" data-v="6"> 于是两个使女和她们的孩子前来下拜；</span>
<span className="v" id="v7" data-v="7"> 利亚和她的孩子也前来下拜；随后约瑟和拉结也前来下拜。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 32:5; 创世记 39:5; 创世记 32:13–20"> 以扫说：「我所遇见的这些群畜是什么意思呢？」雅各说：「是要在我主面前蒙恩的。」</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 27:39; 腓利门书 1:7; 创世记 27:41"> 以扫说：「兄弟啊，我的已经够了，你的仍归你吧！」</span>
<span className="v" id="v10" data-v="10" data-xref="约伯记 33:26; 启示录 22:4; 创世记 32:30"> 雅各说：「不然，我若在你眼前蒙恩，就求你从我手里收下这礼物；因为我见了你的面，如同见了 神的面，并且你容纳了我。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 25:27; 腓立比书 4:18; 创世记 30:43"> 求你收下我带来给你的礼物；因为 神恩待我，使我充足。」雅各再三地求他，他才收下了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 以扫说：「我们可以起身前往，我在你前头走。」</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 40:11; 以西结书 34:15–16; 以西结书 34:23–25"> 雅各对他说：「我主知道孩子们年幼娇嫩，牛羊也正在乳养的时候，若是催赶一天，群畜都必死了。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 32:3; 以赛亚书 40:11; 罗马书 15:1"> 求我主在仆人前头走，我要量着在我面前群畜和孩子的力量慢慢地前行，直走到西珥我主那里。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路得记 2:13; 创世记 47:25; 创世记 34:11"> 以扫说：「容我把跟随我的人留几个在你这里。」雅各说：「何必呢？只要在我主眼前蒙恩就是了。」</span>
<span className="v" id="v16" data-v="16"> 于是，以扫当日起行，回往西珥去了。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 60:6; 约书亚记 13:27; 士师记 8:5"> 雅各就往疏割去，在那里为自己盖造房屋，又为牲畜搭棚；因此那地方名叫疏割<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是棚的意思">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="士师记 9:1; 使徒行传 7:16; 约书亚记 24:1"> 雅各从巴旦·亚兰回来的时候，平平安安地到了迦南地的示剑城，在城东支搭帐棚，</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 7:16; 约翰福音 4:5; 约书亚记 24:32"> 就用一百块银子向示剑的父亲、哈抹的子孙买了支帐棚的那块地，</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 35:7; 创世记 21:33; 创世记 32:28"> 在那里筑了一座坛，起名叫伊利·伊罗伊·以色列<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就是 神、以色列 神的意思">b</a></sup>。</span>
</div>
</div>

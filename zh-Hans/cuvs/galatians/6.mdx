## 各人的重担要互相担当

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 15:1; 提摩太后书 2:25; 帖撒罗尼迦后书 3:15"> 弟兄们，若有人偶然被过犯所胜，你们属灵的人就当用温柔的心把他挽回过来；又当自己小心，恐怕也被引诱。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 15:1; 帖撒罗尼迦前书 5:14; 约翰福音 13:34"> 你们各人的重担要互相担当，如此，就完全了基督的律法。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 26:12; 哥林多前书 8:2; 哥林多前书 3:18"> 人若无有，自己还以为有，就是自欺了。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 13:5; 诗篇 26:2; 哥林多前书 11:28"> 各人应当察验自己的行为；这样，他所夸的就专在自己，不在别人了，</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 32:19; 罗马书 14:10–12; 哥林多后书 5:10–11"> 因为各人必担当自己的担子。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前书 5:17–18; 罗马书 15:27; 申命记 12:19"> 在道理上受教的，当把一切需用的供给施教的人。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 9:6; 何西阿书 10:12; 约伯记 4:8"> 不要自欺， 神是轻慢不得的。人种的是什么，收的也是什么。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 8:13; 雅各书 3:18; 彼得后书 2:19"> 顺着情欲撒种的，必从情欲收败坏；顺着圣灵撒种的，必从圣灵收永生。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 15:58; 帖撒罗尼迦后书 3:13; 以赛亚书 40:30–31"> 我们行善，不可丧志；若不灰心，到了时候就要收成。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 13:16; 箴言 3:27; 帖撒罗尼迦前书 5:15"> 所以，有了机会就当向众人行善，向信徒一家的人更当这样。</span>
</div>
</div>

## 警告和祝福

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 16:21–23; 罗马书 16:22"> 请看我亲手写给你们的字是何等的大呢！</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 5:11; 歌罗西书 2:23; 使徒行传 15:1"> 凡希图外貌体面的人都勉强你们受割礼，无非是怕自己为基督的十字架受逼迫。</span>
<span className="v" id="v13" data-v="13" data-xref="腓立比书 3:3; 哥林多前书 5:6; 罗马书 2:17–25"> 他们那些受割礼的，连自己也不守律法；他们愿意你们受割礼，不过要借着你们的肉体夸口。</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 6:6; 耶利米书 9:23–24; 加拉太书 2:20"> 但我断不以别的夸口，只夸我们主耶稣基督的十字架；因这十字架，就我而论，世界已经钉在十字架上；就世界而论，我已经钉在十字架上。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多后书 5:17; 歌罗西书 3:10–11; 以弗所书 2:10"> 受割礼不受割礼都无关紧要，要紧的就是作新造的人。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太书 3:29; 罗马书 9:6–8; 腓立比书 3:3"> 凡照此理而行的，愿平安、怜悯加给他们，和 神的以色列民。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 1:5; 歌罗西书 1:24; 哥林多后书 11:23–25"> 从今以后，人都不要搅扰我，因为我身上带着耶稣的印记。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 16:20; 提摩太后书 4:22; 腓利门书 1:25"> 弟兄们，愿我主耶稣基督的恩常在你们心里。阿们！</span>

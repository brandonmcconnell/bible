## 保罗关怀加拉太人

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 8:4; 以弗所书 2:11–12; 帖撒罗尼迦后书 1:8"> 但从前你们不认识 神的时候，是给那些本来不是神的作奴仆；</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 8:3; 加拉太书 3:3; 罗马书 8:3"> 现在你们既然认识 神，更可说是被 神所认识的，怎么还要归回那懦弱无用的小学，情愿再给他作奴仆呢？</span>
<span className="v" id="v10" data-v="10" data-xref="歌罗西书 2:16–17; 罗马书 14:5; 利未记 23:1–44"> 你们谨守日子、月份、节期、年份，</span>
<span className="v" id="v11" data-v="11" data-xref="帖撒罗尼迦前书 3:5; 腓立比书 2:16; 加拉太书 2:2"> 我为你们害怕，惟恐我在你们身上是枉费了工夫。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 2:5; 列王纪上 22:4; 创世记 34:15"> 弟兄们，我劝你们要像我一样，因为我也像你们一样。你们一点没有亏负我。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 2:3; 哥林多后书 12:7–10; 哥林多后书 11:30"> 你们知道我头一次传福音给你们，是因为身体有疾病。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 10:40; 帖撒罗尼迦前书 2:13; 希伯来书 13:2"> 你们为我身体的缘故受试炼，没有轻看我，也没有厌弃我，反倒接待我，如同 神的使者，如同基督耶稣。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 5:2; 约翰一书 3:16–18; 歌罗西书 4:13"> 你们当日所夸的福气在哪里呢？那时你们若能行，就是把自己的眼睛剜出来给我，也都情愿。这是我可以给你们作见证的。</span>
<span className="v" id="v16" data-v="16" data-xref="阿摩司书 5:10; 箴言 9:8; 约翰福音 8:45"> 如今我将真理告诉你们，就成了你们的仇敌吗？</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 16:18; 哥林多后书 11:13–15; 彼得后书 2:3"> 那些人热心待你们，却不是好意，是要离间你们<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是把你们关在外面">b</a></sup>，叫你们热心待他们。</span>
<span className="v" id="v18" data-v="18" data-xref="腓立比书 2:12; 启示录 3:19; 腓立比书 1:27"> 在善事上，常用热心待人原是好的，却不单我与你们同在的时候才这样。</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所书 4:13; 罗马书 8:29; 罗马书 13:14"> 我小子啊，我为你们再受生产之苦，直等到基督成形在你们心里。</span>
<span className="v" id="v20" data-v="20" data-xref="帖撒罗尼迦前书 2:17–18; 哥林多前书 4:19–21; 帖撒罗尼迦前书 3:9"> 我巴不得现今在你们那里，改换口气，因我为你们心里作难。</span>
</div>
</div>

## 夏甲和撒拉的例子

<div className="bt">
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="加拉太书 3:10; 加拉太书 3:23–24; 罗马书 7:5–6"> 你们这愿意在律法以下的人，请告诉我，你们岂没有听见律法吗？</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 16:15; 创世记 21:10; 创世记 21:1–2"> 因为律法上记着，亚伯拉罕有两个儿子，一个是使女生的，一个是自主之妇人生的。</span>
<span className="v" id="v23" data-v="23" data-xref="希伯来书 11:11; 罗马书 9:7–8; 加拉太书 4:28–29"> 然而，那使女所生的是按着血气生的；那自主之妇人所生的是凭着应许生的。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 21:9–13; 希伯来书 10:15–18; 创世记 16:8"> 这都是比方：那两个妇人就是两约。一约是出于西奈山，生子为奴，乃是夏甲。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 19:44; 使徒行传 1:11; 加拉太书 1:17"> 这夏甲二字是指着阿拉伯的西奈山，与现在的耶路撒冷同类，因耶路撒冷和她的儿女都是为奴的。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 12:22; 腓立比书 3:20; 弥迦书 4:1–2"> 但那在上的耶路撒冷是自主的，她是我们的母。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 54:1–5; 诗篇 113:9; 路得记 4:14–16"> 因为经上记着：<br /><span className="pl pl-1">不怀孕、不生养的，你要欢乐；</span><br /><span className="pl pl-1">未曾经过产难的，你要高声欢呼；</span><br /><span className="pl pl-1">因为没有丈夫的，比有丈夫的儿女更多。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="加拉太书 4:23; 罗马书 9:8–9; 罗马书 4:13–18"> 弟兄们，我们是凭着应许作儿女，如同以撒一样。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 21:9; 罗马书 8:13; 加拉太书 5:11"> 当时，那按着血气生的逼迫了那按着圣灵生的，现在也是这样。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 21:10–12; 约翰福音 8:35; 罗马书 8:15–17"> 然而经上是怎么说的呢？是说：「把使女和她儿子赶出去！因为使女的儿子不可与自主妇人的儿子一同承受产业。」</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 8:36; 约翰福音 1:12–13; 加拉太书 5:1"> 弟兄们，这样看来，我们不是使女的儿女，乃是自主妇人的儿女了。</span>
</div>
</div>

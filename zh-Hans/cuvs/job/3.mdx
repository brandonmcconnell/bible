## 约伯咒诅自己

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 20:14–15; 诗篇 106:33; 诗篇 39:2–3"> 此后，约伯开口咒诅自己的生日，</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 18:14"> 说：</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 20:14–18; 耶利米书 15:10; 约伯记 10:18–19"> <span className="pl pl-1">愿我生的那日</span><br /><span className="pl pl-1">和说怀了男胎的那夜都灭没。</span><br /></span>

<span className="v" id="v5" data-v="5" data-xref="约伯记 10:21–22; 诗篇 23:4; 约伯记 28:3"> <span className="pl pl-1">愿黑暗和死荫索取那日；</span><br /><span className="pl pl-1">愿密云停在其上；</span><br /><span className="pl pl-1">愿日蚀恐吓它。</span><br /></span>
<span className="v" id="v6" data-v="6"> <span className="pl pl-1">愿那夜被幽暗夺取，</span><br /><span className="pl pl-1">不在年中的日子同乐，</span><br /><span className="pl pl-1">也不入月中的数目。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 24:8; 耶利米书 7:34; 启示录 18:22–23"> <span className="pl pl-1">愿那夜没有生育，</span><br /><span className="pl pl-1">其间也没有欢乐的声音。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="约伯记 41:1; 约伯记 41:10; 马可福音 5:38"> <span className="pl pl-1">愿那咒诅日子且能惹动鳄鱼的</span><br /><span className="pl pl-1">咒诅那夜。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="约伯记 41:18; 耶利米书 13:16; 约伯记 30:26"> <span className="pl pl-1">愿那夜黎明的星宿变为黑暗，</span><br /><span className="pl pl-1">盼亮却不亮，</span><br /><span className="pl pl-1">也不见早晨的光线</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是眼皮">a</a></sup><br /><span className="pl pl-1">；</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 20:17; 传道书 6:3–5; 创世记 20:18"> <span className="pl pl-1">因没有把怀我胎的门关闭，</span><br /><span className="pl pl-1">也没有将患难对我的眼隐藏。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="约伯记 10:18–19; 以赛亚书 46:3; 诗篇 71:6"> <span className="pl pl-1">我为何不出母胎而死？</span><br /><span className="pl pl-1">为何不出母腹绝气？</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 66:12; 创世记 30:3; 创世记 50:23"> <span className="pl pl-1">为何有膝接收我？</span><br /><span className="pl pl-1">为何有奶哺养我？</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="传道书 9:10; 约伯记 21:13; 约伯记 14:10–12"> <span className="pl pl-1">不然，我就早已躺卧安睡，</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="约伯记 15:28; 诗篇 89:48; 诗篇 49:14"> <span className="pl pl-1">和地上为自己重造荒邱的君王、谋士，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 10:27; 约伯记 22:25; 西番雅书 1:18"> <span className="pl pl-1">或与有金子、将银子装满了房屋的王子</span><br /><span className="pl pl-1">一同安息；</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 58:8; 传道书 6:3; 哥林多前书 15:8"> <span className="pl pl-1">或像隐而未现、不到期而落的胎，</span><br /><span className="pl pl-1">归于无有，如同未见光的婴孩。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="启示录 14:13; 约伯记 17:16; 希伯来书 4:11"> <span className="pl pl-1">在那里恶人止息搅扰，</span><br /><span className="pl pl-1">困乏人得享安息，</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="约伯记 39:7; 以赛亚书 14:3–4; 出埃及记 5:6–8"> <span className="pl pl-1">被囚的人同得安逸，</span><br /><span className="pl pl-1">不听见督工的声音。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="传道书 8:8; 约伯记 30:23; 传道书 12:7"> <span className="pl pl-1">大小都在那里；</span><br /><span className="pl pl-1">奴仆脱离主人的辖制。</span></span>
</div>
<div className="bp poetry">

<span className="v" id="v21" data-v="21" data-xref="启示录 9:6; 箴言 2:4; 列王纪上 19:4"> <span className="pl pl-1">他们切望死，却不得死；</span><br /><span className="pl pl-1">求死，胜于求隐藏的珍宝。</span><br /></span>

<span className="v" id="v23" data-v="23" data-xref="约伯记 19:8; 耶利米哀歌 3:7; 以赛亚书 40:27"> <span className="pl pl-1">人的道路既然遮隐，</span><br /><span className="pl pl-1">神又把他四面围困，</span><br /><span className="pl pl-1">为何有光赐给他呢？</span><br /></span>

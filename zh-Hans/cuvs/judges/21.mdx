## 为便雅悯支派人找妻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 20:1; 马可福音 6:23; 使徒行传 23:12"> 以色列人在米斯巴曾起誓说：「我们都不将女儿给便雅悯人为妻。」</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 20:26; 士师记 20:18; 撒母耳记上 30:4"> 以色列人来到伯特利，坐在 神面前直到晚上，放声痛哭，</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 74:1; 约书亚记 7:7–9; 以赛亚书 63:17"> 说：「耶和华—以色列的 神啊，为何以色列中有这样缺了一支派的事呢？」</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 24:25; 列王纪上 8:64; 诗篇 78:34–35"> 次日清早，百姓起来，在那里筑了一座坛，献燔祭和平安祭。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 5:23; 士师记 21:18; 士师记 21:1"> 以色列人彼此问说：「以色列各支派中，谁没有同会众上到耶和华面前来呢？」先是以色列人起过大誓说，凡不上米斯巴到耶和华面前来的，必将他治死。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 21:15; 士师记 20:23; 路加福音 19:41–42"> 以色列人为他们的弟兄便雅悯后悔，说：「如今以色列中绝了一个支派了。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 21:1; 士师记 21:18; 撒母耳记上 14:28–29"> 我们既在耶和华面前起誓说，必不将我们的女儿给便雅悯人为妻，现在我们当怎样办理、使他们剩下的人有妻呢？」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 31:11–13; 撒母耳记上 11:1–3; 撒母耳记下 2:5–6"> 又彼此问说：「以色列支派中谁没有上米斯巴到耶和华面前来呢？」他们就查出基列·雅比没有一人进营到会众那里；</span>
<span className="v" id="v9" data-v="9"> 因为百姓被数的时候，没有一个基列·雅比人在那里。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 5:23; 士师记 21:5; 撒母耳记上 11:7"> 会众就打发一万二千大勇士，吩咐他们说：「你们去用刀将基列·雅比人连妇女带孩子都击杀了。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 31:17–18; 申命记 2:34"> 所当行的就是这样：要将一切男子和已嫁的女子尽行杀戮。」</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 18:1; 耶利米书 7:12; 诗篇 78:60"> 他们在基列·雅比人中，遇见了四百个未嫁的处女，就带到迦南地的示罗营里。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="士师记 20:47; 申命记 20:10; 以弗所书 2:17"> 全会众打发人到临门磐的便雅悯人那里，向他们说和睦的话。</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 21:12; 哥林多前书 7:2; 士师记 20:47"> 当时便雅悯人回来了，以色列人就把所存活基列·雅比的女子给他们为妻，还是不够。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 21:6; 历代志上 15:13; 以赛亚书 58:12"> 百姓为便雅悯人后悔，因为耶和华使以色列人缺了一个支派<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是使以色列中有了破口">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 会中的长老说：「便雅悯中的女子既然除灭了，我们当怎样办理、使那余剩的人有妻呢？」</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 26:55; 民数记 36:7"> 又说：「便雅悯逃脱的人当有地业，免得以色列中涂抹了一个支派。</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 21:1; 士师记 11:35"> 只是我们不能将自己的女儿给他们为妻；因为以色列人曾起誓说，有将女儿给便雅悯人为妻的，必受咒诅。」</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 16:10; 申命记 16:1; 申命记 16:13"> 他们又说：「在利波拿以南，伯特利以北，在示剑大路以东的示罗，年年有耶和华的节期」；</span>
<span className="v" id="v20" data-v="20"> 就吩咐便雅悯人说：「你们去，在葡萄园中埋伏。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 11:34; 出埃及记 15:20; 传道书 3:4"> 若看见示罗的女子出来跳舞，就从葡萄园出来，在示罗的女子中各抢一个为妻，回便雅悯地去。</span>
<span className="v" id="v22" data-v="22" data-xref="士师记 21:1; 士师记 21:18; 士师记 21:14"> 他们的父亲或是弟兄若来与我们争竞，我们就说：『求你们看我们的情面，施恩给这些人，因我们在争战的时候没有给他们留下女子为妻。这也不是你们将女子给他们的；若是你们给的，就算有罪。』」</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 20:48"> 于是便雅悯人照样而行，按着他们的数目从跳舞的女子中抢去为妻，就回自己的地业去，又重修城邑居住。</span>
<span className="v" id="v24" data-v="24"> 当时以色列人离开那里，各归本支派、本宗族、本地业去了。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="申命记 12:8; 士师记 17:6; 箴言 3:5"> 那时，以色列中没有王，各人任意而行。</span>
</div>
</div>

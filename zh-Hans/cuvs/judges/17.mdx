## 米迦的偶像

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 18:2; 约书亚记 17:14–18; 士师记 10:1"> 以法莲山地有一个人名叫米迦。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米记 13:25; 路得记 3:10; 撒母耳记上 23:21"> 他对母亲说：「你那一千一百舍客勒银子被人拿去，你因此咒诅，并且告诉了我。看哪，这银子在我这里，是我拿去了。」他母亲说：「我儿啊，愿耶和华赐福与你！」</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 20:4; 出埃及记 20:23; 利未记 19:4"> 米迦就把这一千一百舍客勒银子还他母亲。他母亲说：「我分出这银子来为你献给耶和华，好雕刻一个像，铸成一个像。现在我还是交给你。」</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 46:6–7; 耶利米书 10:9–10"> 米迦将银子还他母亲，他母亲将二百舍客勒银子交给银匠，雕刻一个像，铸成一个像，安置在米迦的屋内。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 18:14; 士师记 8:27; 创世记 31:19"> 这米迦有了神堂，又制造以弗得和家中的神像，分派他一个儿子作祭司。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 12:8; 箴言 14:12; 士师记 21:25"> 那时以色列中没有王，各人任意而行。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="弥迦书 5:2; 马太福音 2:1; 路得记 1:1–2"> 犹大的伯利恒有一个少年人，是犹大族的利未人，他在那里寄居。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米记 13:10–11; 士师记 17:11; 约书亚记 24:33"> 这人离开犹大的伯利恒城，要找一个可住的地方。行路的时候，到了以法莲山地，走到米迦的家。</span>
<span className="v" id="v9" data-v="9"> 米迦问他说：「你从哪里来？」他回答说：「从犹大的伯利恒来。我是利未人，要找一个可住的地方。」</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 13:19; 士师记 18:19–20; 提摩太前书 6:10"> 米迦说：「你可以住在我这里，我以你为父、为祭司。我每年给你十舍客勒银子，一套衣服和度日的食物。」利未人就进了他的家。</span>
<span className="v" id="v11" data-v="11"> 利未人情愿与那人同住；那人看这少年人如自己的儿子一样。</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 18:30; 民数记 16:8–10; 民数记 16:5"> 米迦分派这少年的利未人作祭司，他就住在米迦的家里。</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 10:2–3; 箴言 14:12; 约翰福音 16:2"> 米迦说：「现在我知道耶和华必赐福与我，因我有一个利未人作祭司。」</span>

## 底波拉和巴拉

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 5:3; 士师记 3:12; 士师记 3:7"> 以笏死后，以色列人又行耶和华眼中看为恶的事，</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 11:1; 士师记 4:16; 士师记 4:13"> 耶和华就把他们付与在夏琐作王的迦南王耶宾手中；他的将军是西西拉，住在外邦人的夏罗设。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 1:19; 诗篇 106:42; 士师记 3:9"> 耶宾王有铁车九百辆。他大大欺压以色列人二十年，以色列人就呼求耶和华。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 15:20; 路加福音 2:36; 列王纪下 22:14"> 有一位女先知名叫底波拉，是拉比多的妻，当时作以色列的士师。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 18:19; 耶利米书 31:15; 出埃及记 18:26"> 她住在以法莲山地拉玛和伯特利中间，在底波拉的棕树下。以色列人都上她那里去听判断。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 13:47; 士师记 8:18; 希伯来书 11:32"> 她打发人从拿弗他利的基低斯将亚比挪庵的儿子巴拉召了来，对他说：「耶和华—以色列的 神吩咐你说：『你率领一万拿弗他利和西布伦人上他泊山去。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 18:40; 以西结书 38:10–16; 诗篇 83:9–10"> 我必使耶宾的将军西西拉率领他的车辆和全军往基顺河，到你那里去；我必将他交在你手中。』」</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 4:10–14; 马太福音 14:30–31"> 巴拉说：「你若同我去，我就去；你若不同我去，我就不去。」</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 2:14; 撒母耳记上 2:30; 士师记 4:17–22"> 底波拉说：「我必与你同去，只是你在所行的路上得不着荣耀，因为耶和华要将西西拉交在一个妇人手里。」于是底波拉起来，与巴拉一同往基低斯去了。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 5:18; 士师记 5:15; 士师记 4:14"> 巴拉就招聚西布伦人和拿弗他利人到基低斯，跟他上去的有一万人。底波拉也同他上去。</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 1:16; 约书亚记 19:33; 民数记 10:29"> 摩西岳父<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：内兄">a</a></sup>何巴的后裔，基尼人希百曾离开基尼族，到靠近基低斯、撒拿音的橡树旁支搭帐棚。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 89:12; 耶利米书 46:18; 约书亚记 19:12"> 有人告诉西西拉说：「亚比挪庵的儿子巴拉已经上他泊山了。」</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 4:2–3; 士师记 4:7"> 西西拉就聚集所有的铁车九百辆和跟随他的全军，从外邦人的夏罗设出来，到了基顺河。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 9:3; 撒母耳记下 5:24; 以赛亚书 52:12"> 底波拉对巴拉说：「你起来，今日就是耶和华将西西拉交在你手的日子。耶和华岂不在你前头行吗？」于是巴拉下了他泊山，跟随他有一万人。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 10:10; 诗篇 83:9–10; 士师记 5:20–21"> 耶和华使西西拉和他一切车辆全军溃乱，在巴拉面前被刀杀败；西西拉下车步行逃跑。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 2:12; 利未记 26:7–8; 雅各书 2:13"> 巴拉追赶车辆、军队，直到外邦人的夏罗设。西西拉的全军都倒在刀下，没有留下一人。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 69:22; 以赛亚书 57:21; 阿摩司书 5:19–20"> 只有西西拉步行逃跑，到了基尼人希百之妻雅亿的帐棚，因为夏琐王耶宾与基尼人希百家和好。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 6:19"> 雅亿出来迎接西西拉，对他说：「请我主进来，不要惧怕」；西西拉就进了她的帐棚。雅亿用被将他遮盖。</span>
<span className="v" id="v19" data-v="19" data-xref="士师记 5:25–26; 创世记 24:43; 以赛亚书 41:17"> 西西拉对雅亿说：「我渴了，求你给我一点水喝。」雅亿就打开皮袋，给他奶子喝，仍旧把他遮盖。</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 2:3–5; 撒母耳记下 17:20"> 西西拉又对雅亿说：「请你站在帐棚门口，若有人来问你说：『有人在这里没有？』你就说：『没有。』」</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 5:26–27; 哥林多前书 1:27; 士师记 3:21"> 西西拉疲乏沉睡。希百的妻雅亿取了帐棚的橛子，手里拿着锤子，轻悄悄地到他旁边，将橛子从他鬓边钉进去，钉入地里。西西拉就死了。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 17:10–15; 撒母耳记下 17:3"> 巴拉追赶西西拉的时候，雅亿出来迎接他说：「来吧，我将你所寻找的人给你看。」他就进入帐棚，看见西西拉已经死了，倒在地上，橛子还在他鬓中。</span>
<span className="v" id="v23" data-v="23" data-xref="尼希米记 9:24; 诗篇 18:47; 诗篇 18:39"> 这样， 神使迦南王耶宾被以色列人制伏了。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记上 3:12"> 从此以色列人的手越发有力，胜了迦南王耶宾，直到将他灭绝了。</span>

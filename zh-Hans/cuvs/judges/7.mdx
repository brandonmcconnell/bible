## 基甸击败米甸人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 6:32; 传道书 9:10; 创世记 12:6"> 耶路·巴力就是基甸，他和一切跟随的人早晨起来，在哈律泉旁安营。米甸营在他们北边的平原，靠近摩利冈。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="申命记 8:17; 哥林多前书 1:27–29; 哥林多后书 4:7"> 耶和华对基甸说：「跟随你的人过多，我不能将米甸人交在他们手中，免得以色列人向我夸大，说：『是我们自己的手救了我们。』</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 20:8; 启示录 17:14; 启示录 21:8"> 现在你要向这些人宣告说：『凡惧怕胆怯的，可以离开基列山回去。』」于是有二万二千人回去，只剩下一万。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="诗篇 33:16; 撒母耳记上 16:7; 撒母耳记上 14:6"> 耶和华对基甸说：「人还是过多；你要带他们下到水旁，我好在那里为你试试他们。我指点谁说：『这人可以同你去』，他就可以同你去；我指点谁说：『这人不可同你去』，他就不可同你去。」</span>
<span className="v" id="v5" data-v="5"> 基甸就带他们下到水旁。耶和华对基甸说：「凡用舌头舔水，像狗舔的，要使他单站在一处；凡跪下喝水的，也要使他单站在一处。」</span>
<span className="v" id="v6" data-v="6"> 于是用手捧着舔水的有三百人，其余的都跪下喝水。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 14:6; 以赛亚书 41:14–16; 士师记 7:18–22"> 耶和华对基甸说：「我要用这舔水的三百人拯救你们，将米甸人交在你手中；其余的人都可以各归各处去。」</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 6:20; 民数记 10:9; 约书亚记 6:4"> 这三百人就带着食物和角；其余的以色列人，基甸都打发他们各归各的帐棚，只留下这三百人。米甸营在他下边的平原里。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 46:2–3; 士师记 3:28; 使徒行传 18:9–10"> 当那夜，耶和华吩咐基甸说：「起来，下到米甸营里去，因我已将他们交在你手中。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 4:10–14; 士师记 4:8–9"> 倘若你怕下去，就带你的仆人普拉下到那营里去。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 6:10; 士师记 7:13–15; 以赛亚书 35:3–4"> 你必听见他们所说的，然后你就有胆量下去攻营。」于是基甸带着仆人普拉下到营旁。</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 8:10; 士师记 6:5; 约书亚记 11:4"> 米甸人、亚玛力人，和一切东方人都布散在平原，如同蝗虫那样多。他们的骆驼无数，多如海边的沙。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 1:27; 以赛亚书 41:14–15; 士师记 4:9"> 基甸到了，就听见一人将梦告诉同伴说：「我做了一梦，梦见一个大麦饼滚入米甸营中，到了帐幕，将帐幕撞倒，帐幕就翻转倾覆了。」</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 7:6–7; 约书亚记 2:9; 约书亚记 2:24"> 那同伴说：「这不是别的，乃是以色列人约阿施的儿子基甸的刀； 神已将米甸和全军都交在他的手中。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="哥林多后书 10:4–6; 创世记 40:8; 历代志下 20:18–19"> 基甸听见这梦和梦的讲解，就敬拜 神，回到以色列营中，说：「起来吧！耶和华已将米甸的军队交在你们手中了。」</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 4:7"> 于是基甸将三百人分作三队，把角和空瓶交在各人手里（瓶内都藏着火把），</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 11:1; 马太福音 16:24; 希伯来书 13:7"> 吩咐他们说：「你们要看我行事：我到了营的旁边怎样行，你们也要怎样行。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 20:15–17; 撒母耳记上 17:47"> 我和一切跟随我的人吹角的时候，你们也要在营的四围吹角，喊叫说：『耶和华和基甸的刀！』」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="诗篇 2:9; 出埃及记 14:24; 马太福音 25:6"> 基甸和跟随他的一百人，在三更之初才换更的时候，来到营旁，就吹角，打破手中的瓶。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 27:13; 哥林多后书 4:7; 哥林多前书 15:52"> 三队的人就都吹角，打破瓶子，左手拿着火把，右手拿着角，喊叫说：「耶和华和基甸的刀！」</span>
<span className="v" id="v21" data-v="21" data-xref="历代志下 20:17; 箴言 28:1; 列王纪下 7:6–7"> 他们在营的四围各站各的地方；全营的人都乱窜。三百人呐喊，使他们逃跑。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 4:12; 约书亚记 6:20; 约书亚记 6:4"> 三百人就吹角，耶和华使全营的人用刀互相击杀，逃到西利拉的伯·哈示他，直逃到靠近他巴的亚伯·米何拉。</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 6:35; 撒母耳记上 14:21–22"> 以色列人就从拿弗他利、亚设，和玛拿西全地聚集来追赶米甸人。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="士师记 3:27–28; 腓立比书 1:27; 罗马书 15:30"> 基甸打发人走遍以法莲山地，说：「你们下来攻击米甸人，争先把守约旦河的渡口，直到伯·巴拉。」于是以法莲的众人聚集，把守约旦河的渡口，直到伯·巴拉，</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 10:26; 士师记 8:3–4; 诗篇 83:11–12"> 捉住了米甸人的两个首领：一名俄立，一名西伊伯；将俄立杀在俄立磐石上，将西伊伯杀在西伊伯酒榨那里；又追赶米甸人，将俄立和西伊伯的首级带过约旦河，到基甸那里。</span>
</div>
</div>

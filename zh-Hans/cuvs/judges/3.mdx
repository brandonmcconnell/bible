## 留下来的民族

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 2:21–22; 申命记 7:22; 箴言 17:3"> 耶和华留下这几族，为要试验那不曾知道与迦南争战之事的以色列人，</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 3:5; 创世记 3:7; 哥林多前书 9:26–27"> 好叫以色列的后代又知道又学习未曾晓得的战事。</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 13:3; 约书亚记 13:5; 士师记 10:7"> 所留下的就是非利士的五个首领和一切迦南人、西顿人，并住黎巴嫩山的希未人，从巴力·黑们山直到哈马口。</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 3:1; 士师记 2:22; 出埃及记 15:25"> 留下这几族，为要试验以色列人，知道他们肯听从耶和华借摩西吩咐他们列祖的诫命不肯。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 106:34–38; 创世记 10:15–18; 出埃及记 3:8"> 以色列人竟住在迦南人、赫人、亚摩利人、比利洗人、希未人、耶布斯人中间，</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 7:3–4; 出埃及记 34:16; 列王纪上 11:1–5"> 娶他们的女儿为妻，将自己的女儿嫁给他们的儿子，并事奉他们的神。</span>
</div>
</div>

## 俄陀聂

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 34:13; 列王纪下 23:6; 列王纪上 18:19"> 以色列人行耶和华眼中看为恶的事，忘记耶和华—他们的 神，去事奉诸巴力和亚舍拉，</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 2:14; 哈巴谷书 3:7; 士师记 4:9"> 所以耶和华的怒气向以色列人发作，就把他们交在美索不达米亚王古珊·利萨田的手中。以色列人服事古珊·利萨田八年。</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 3:15; 士师记 1:13; 诗篇 22:5"> 以色列人呼求耶和华的时候，耶和华就为他们兴起一位拯救者救他们，就是迦勒兄弟基纳斯的儿子俄陀聂。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 13:25; 撒母耳记上 11:6; 士师记 14:19"> 耶和华的灵降在他身上，他就作了以色列的士师，出去争战。耶和华将美索不达米亚王古珊·利萨田交在他手中，他便胜了古珊·利萨田。</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 5:31; 士师记 8:28; 约书亚记 11:23"> 于是国中太平四十年。基纳斯的儿子俄陀聂死了。</span>
</div>
</div>

## 以笏

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 12:9; 士师记 2:19; 士师记 2:14"> 以色列人又行耶和华眼中看为恶的事，耶和华就使摩押王伊矶伦强盛，攻击以色列人。</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 1:16; 申命记 34:3; 士师记 5:14"> 伊矶伦招聚亚扪人和亚玛力人，去攻打以色列人，占据棕树城。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 28:47–48; 申命记 28:40; 利未记 26:23–25"> 于是以色列人服事摩押王伊矶伦十八年。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 3:9; 诗篇 78:34; 以赛亚书 36:16"> 以色列人呼求耶和华的时候，耶和华就为他们兴起一位拯救者，就是便雅悯人基拉的儿子以笏；他是左手便利的。以色列人托他送礼物给摩押王伊矶伦。</span>
<span className="v" id="v16" data-v="16" data-xref="雅歌 3:8; 启示录 2:12; 诗篇 149:6"> 以笏打了一把两刃的剑，长一肘，带在右腿上衣服里面。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 34:20; 约伯记 15:27; 耶利米书 50:11"> 他将礼物献给摩押王伊矶伦（原来伊矶伦极其肥胖）；</span>
<span className="v" id="v18" data-v="18"> 以笏献完礼物，便将抬礼物的人打发走了，</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 4:20; 士师记 3:20; 使徒行传 23:18–19"> 自己却从靠近吉甲凿石之地回来，说：「王啊，我有一件机密事奏告你。」王说：「回避吧！」于是左右侍立的人都退去了。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 10:7; 阿摩司书 3:15; 诗篇 29:1"> 以笏来到王面前；王独自一人坐在凉楼上。以笏说：「我奉 神的命报告你一件事。」王就从座位上站起来。</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亚书 13:3; 约伯记 20:25; 撒母耳记上 15:33"> 以笏便伸左手，从右腿上拔出剑来，刺入王的肚腹，</span>
<span className="v" id="v22" data-v="22"> 连剑把都刺进去了。剑被肥肉夹住，他没有从王的肚腹拔出来，且穿通了后身。</span>
<span className="v" id="v23" data-v="23"> 以笏就出到游廊，将楼门尽都关锁。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记上 24:3"> 以笏出来之后，王的仆人到了，看见楼门关锁，就说：「他必是在楼上大解。」</span>
<span className="v" id="v25" data-v="25"> 他们等烦了，见仍不开楼门，就拿钥匙开了，不料，他们的主人已死，倒在地上。</span>
<span className="v" id="v26" data-v="26"> 他们耽延的时候，以笏就逃跑了，经过凿石之地，逃到西伊拉；</span>
<span className="v" id="v27" data-v="27" data-xref="士师记 6:34; 撒母耳记上 13:3; 士师记 5:14"> 到了，就在以法莲山地吹角。以色列人随着他下了山地，他在前头引路，</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 12:5; 士师记 7:9; 士师记 7:15"> 对他们说：「你们随我来，因为耶和华已经把你们的仇敌摩押人交在你们手中。」于是他们跟着他下去，把守约旦河的渡口，不容摩押一人过去。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 32:15; 士师记 3:17; 诗篇 17:10"> 那时击杀了摩押人约有一万，都是强壮的勇士，没有一人逃脱。</span>
<span className="v" id="v30" data-v="30" data-xref="士师记 3:11; 士师记 5:31"> 这样，摩押就被以色列人制伏了。国中太平八十年。</span>
</div>
</div>

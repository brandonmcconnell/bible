## 米迦和但支派

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 17:6; 士师记 19:1; 士师记 1:34"> 那时，以色列中没有王。但支派的人仍是寻地居住；因为到那日子，他们还没有在以色列支派中得地为业。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 13:25; 约书亚记 2:1; 士师记 18:11"> 但人从琐拉和以实陶打发本族中的五个勇士，去仔细窥探那地，吩咐他们说：「你们去窥探那地。」他们来到以法莲山地，进了米迦的住宅，就在那里住宿。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 12:6; 创世记 27:22; 马太福音 26:73"> 他们临近米迦的住宅，听出那少年利未人的口音来，就进去问他说：「谁领你到这里来？你在这里做什么？你在这里得什么？」</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士师记 17:10; 以西结书 13:19; 箴言 28:21"> 他回答说：「米迦待我如此如此，请我作祭司。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 8:10; 以赛亚书 30:1; 列王纪上 22:5"> 他们对他说：「请你求问 神，使我们知道所行的道路通达不通达。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王纪上 22:6; 列王纪上 22:15; 诗篇 33:18"> 祭司对他们说：「你们可以平平安安地去，你们所行的道路是在耶和华面前的。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约书亚记 19:47; 士师记 18:27–28; 撒母耳记上 3:13"> 五人就走了，来到拉亿，见那里的民安居无虑，如同西顿人安居一样。在那地没有人掌权扰乱他们；他们离西顿人也远，与别人没有来往。</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 18:11; 士师记 18:2; 士师记 13:2"> 五人回到琐拉和以实陶，见他们的弟兄；弟兄问他们说：「你们有什么话？」</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 2:23–24; 民数记 13:30; 约书亚记 18:3"> 他们回答说：「起来，我们上去攻击他们吧！我们已经窥探那地，见那地甚好。你们为何静坐不动呢？要急速前往得那地为业，不可迟延。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 18:27; 士师记 18:7; 申命记 2:29"> 你们到了那里，必看见安居无虑的民，地也宽阔。 神已将那地交在你们手中；那地百物俱全，一无所缺。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="士师记 18:16"> 于是但族中的六百人，各带兵器，从琐拉和以实陶前往，</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 13:25; 约书亚记 15:60; 历代志下 1:4"> 上到犹大的基列·耶琳，在基列·耶琳后边安营。因此那地方名叫玛哈尼·但，直到今日。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 24:30; 士师记 19:1; 士师记 18:2–3"> 他们从那里往以法莲山地去，来到米迦的住宅。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="士师记 17:5; 士师记 18:3–4; 撒母耳记上 14:28"> 从前窥探拉亿地的五个人对他们的弟兄说：「这宅子里有以弗得和家中的神像，并雕刻的像与铸成的像，你们知道吗？现在你们要想一想当怎样行。」</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 43:27; 撒母耳记上 17:22; 约翰福音 14:27"> 五人就进入米迦的住宅，到了那少年利未人的房内问他好。</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 18:11"> 那六百但人各带兵器，站在门口。</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 18:14; 士师记 17:4–5; 士师记 18:2"> 窥探地的五个人走进去，将雕刻的像、以弗得、家中的神像，并铸成的像，都拿了去。祭司和带兵器的六百人，一同站在门口。</span>
<span className="v" id="v18" data-v="18"> 那五个人进入米迦的住宅，拿出雕刻的像、以弗得、家中的神像，并铸成的像，祭司就问他们说：「你们做什么呢？」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约伯记 29:9; 约伯记 21:5; 士师记 17:10"> 他们回答说：「不要作声，用手捂口，跟我们去吧！我们必以你为父、为祭司。你作一家的祭司好呢？还是作以色列一族一支派的祭司好呢？」</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 56:11; 以西结书 13:19; 箴言 30:15"> 祭司心里喜悦，便拿着以弗得和家中的神像，并雕刻的像，进入他们中间。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 他们就转身离开那里，妻子、儿女、牲畜、财物都在前头。</span>
<span className="v" id="v22" data-v="22"> 离米迦的住宅已远，米迦的近邻都聚集来，追赶但人，</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 114:5; 撒母耳记下 14:5; 撒母耳记上 11:5"> 呼叫但人。但人回头问米迦说：「你聚集这许多人来做什么呢？」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哈巴谷书 2:18–19; 以赛亚书 44:18–20; 诗篇 115:8"> 米迦说：「你们将我所做的神像和祭司都带了去，我还有所剩的吗？怎么还问我说『做什么』呢？」</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约伯记 27:2; 约伯记 3:5; 撒母耳记上 30:6"> 但人对米迦说：「你不要使我们听见你的声音，恐怕有性暴的人攻击你，以致你和你的全家尽都丧命。」</span>
<span className="v" id="v26" data-v="26"> 但人还是走他们的路。米迦见他们的势力比自己强盛，就转身回家去了。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约书亚记 19:47; 士师记 18:7; 士师记 18:10"> 但人将米迦所做的神像和他的祭司都带到拉亿，见安居无虑的民，就用刀杀了那民，又放火烧了那城，</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 10:6; 士师记 18:7; 民数记 13:21"> 并无人搭救；因为离西顿远，他们又与别人没有来往。城在平原，那平原靠近伯·利合。但人又在那里修城居住，</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 19:47; 创世记 14:14; 列王纪上 15:20"> 照着他们始祖以色列之子但的名字，给那城起名叫但；原先那城名叫拉亿。</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 4:10–11; 士师记 13:1; 士师记 17:5"> 但人就为自己设立那雕刻的像。摩西的孙子、革舜的儿子约拿单，和他的子孙作但支派的祭司，直到那地遭掳掠的日子。</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 18:1; 撒母耳记上 1:3; 士师记 19:18"> 神的殿在示罗多少日子，但人为自己设立米迦所雕刻的像也在但多少日子。</span>
</div>
</div>

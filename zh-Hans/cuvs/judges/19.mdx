## 利未人和他的妾

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 18:1; 士师记 17:8; 玛拉基书 2:15"> 当以色列中没有王的时候，有住以法莲山地那边的一个利未人，娶了一个犹大伯利恒的女子为妾。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结书 16:28; 申命记 22:21; 利未记 21:9"> 妾行淫离开丈夫，回犹大的伯利恒，到了父家，在那里住了四个月。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 34:3; 创世记 50:21; 利未记 19:17"> 她丈夫起来，带着一个仆人、两匹驴去见她，用好话劝她回来。女子就引丈夫进入父家。她父见了那人，便欢欢喜喜地迎接。</span>
<span className="v" id="v4" data-v="4"> 那人的岳父，就是女子的父亲，将那人留下住了三天。于是二人一同吃喝、住宿。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 19:8; 创世记 18:5; 诗篇 104:15"> 到第四天，利未人清早起来要走，女子的父亲对女婿说：「请你吃点饭，加添心力，然后可以行路。」</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 19:9; 士师记 16:25; 路得记 3:7"> 于是二人坐下一同吃喝。女子的父亲对那人说：「请你再住一夜，畅快你的心。」</span>
<span className="v" id="v7" data-v="7"> 那人起来要走，他岳父强留他，他又住了一宿。</span>
<span className="v" id="v8" data-v="8"> 到第五天，他清早起来要走，女子的父亲说：「请你吃点饭，加添心力，等到日头偏西再走。」于是二人一同吃饭。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 27:1; 路加福音 24:29; 雅各书 4:13–14"> 那人同他的妾和仆人起来要走，他岳父，就是女子的父亲，对他说：「看哪，日头偏西了，请你再住一夜；天快晚了，可以在这里住宿，畅快你的心。明天早早起行回家去。」</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 15:63; 约书亚记 15:8; 士师记 1:8"> 那人不愿再住一夜，就备上那两匹驴，带着妾起身走了，来到耶布斯的对面（耶布斯就是耶路撒冷。）</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 5:6; 士师记 1:21; 士师记 19:10"> 临近耶布斯的时候，日头快要落了，仆人对主人说：「我们不如进这耶布斯人的城里住宿。」</span>
<span className="v" id="v12" data-v="12"> 主人回答说：「我们不可进不是以色列人住的外邦城，不如过到基比亚去」；</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 10:26; 何西阿书 5:8; 以赛亚书 10:29"> 又对仆人说：「我们可以到一个地方，或住在基比亚，或住在拉玛。」</span>
<span className="v" id="v14" data-v="14"> 他们就往前走。将到便雅悯的基比亚，日头已经落了；</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 19:18; 马太福音 25:35; 马太福音 25:43"> 他们进入基比亚要在那里住宿，就坐在城里的街上，因为无人接他们进家住宿。</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 19:1; 诗篇 104:23; 创世记 3:19"> 晚上，有一个老年人从田间做工回来。他原是以法莲山地的人，住在基比亚；那地方的人却是便雅悯人。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 32:17; 创世记 16:8"> 老年人举目看见客人坐在城里的街上，就问他说：「你从哪里来？要往哪里去？」</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 18:31; 约翰福音 15:6; 撒母耳记上 1:7"> 他回答说：「我们从犹大的伯利恒来，要往以法莲山地那边去。我原是那里的人，到过犹大的伯利恒，现在我往耶和华的殿去，在这里无人接我进他的家。</span>
<span className="v" id="v19" data-v="19"> 其实我有粮草可以喂驴，我与我的妾，并我的仆人，有饼有酒，并不缺少什么。」</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 6:23; 雅各书 2:15–16; 希伯来书 13:2"> 老年人说：「愿你平安！你所需用的我都给你，只是不可在街上过夜。」</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 43:24; 创世记 18:4; 路加福音 7:44"> 于是领他们到家里，喂上驴，他们就洗脚吃喝。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 19:4–5; 哥林多前书 6:9; 士师记 20:5"> 他们心里正欢畅的时候，城中的匪徒围住房子，连连叩门，对房主老人说：「你把那进你家的人带出来，我们要与他交合。」</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 34:7; 撒母耳记下 13:12; 士师记 20:6"> 那房主出来对他们说：「弟兄们哪，不要这样作恶；这人既然进了我的家，你们就不要行这丑事。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 19:8; 申命记 21:14; 创世记 34:2"> 我有个女儿，还是处女，并有这人的妾，我将她们领出来任凭你们玷辱她们，只是向这人不可行这样的丑事。」</span>
<span className="v" id="v25" data-v="25" data-xref="何西阿书 10:9; 何西阿书 9:9; 何西阿书 7:4–7"> 那些人却不听从他的话。那人就把他的妾拉出去交给他们，他们便与她交合，终夜凌辱她，直到天色快亮才放她去。</span>
<span className="v" id="v26" data-v="26" data-xref="士师记 19:3; 创世记 18:12; 彼得前书 3:6"> 天快亮的时候，妇人回到她主人住宿的房门前，就仆倒在地，直到天亮。</span>
<span className="v" id="v27" data-v="27"> 早晨，她的主人起来开了房门，出去要行路，不料那妇人仆倒在房门前，两手搭在门槛上；</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 20:5; 列王纪上 18:29"> 就对妇人说：「起来，我们走吧！」妇人却不回答。那人便将她驮在驴上，起身回本处去了。</span>
<span className="v" id="v29" data-v="29" data-xref="士师记 20:6–7; 撒母耳记上 11:7; 罗马书 10:2"> 到了家里，用刀将妾的尸身切成十二块，使人拿着传送以色列的四境。</span>
<span className="v" id="v30" data-v="30" data-xref="士师记 20:7; 箴言 13:10; 何西阿书 9:9"> 凡看见的人都说：「从以色列人出埃及地，直到今日，这样的事没有行过，也没有见过。现在应当思想，大家商议当怎样办理。」</span>

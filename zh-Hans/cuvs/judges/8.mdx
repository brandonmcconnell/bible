## 击败米甸人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 19:41; 士师记 12:1–6; 约伯记 5:2"> 以法莲人对基甸说：「你去与米甸人争战，没有招我们同去，为什么这样待我们呢？」他们就与基甸大大地争吵。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 13:4–7; 腓立比书 2:2–3; 雅各书 3:13–18"> 基甸对他们说：「我所行的岂能比你们所行的呢？以法莲拾取剩下的葡萄不强过亚比以谢所摘的葡萄吗？</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 15:1; 士师记 7:24–25; 约翰福音 4:37"> 神已将米甸人的两个首领俄立和西伊伯交在你们手中；我所行的岂能比你们所行的呢？」基甸说了这话，以法莲人的怒气就消了。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 6:9; 哥林多后书 4:16; 撒母耳记上 14:28–29"> 基甸和跟随他的三百人到约旦河过渡，虽然疲乏，还是追赶。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 33:17; 诗篇 60:6; 撒母耳记上 25:18"> 基甸对疏割人说：「求你们拿饼来给跟随我的人吃，因为他们疲乏了；我们追赶米甸人的两个王西巴和撒慕拿。」</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 20:11; 腓立比书 2:21; 箴言 18:23"> 疏割人的首领回答说：「西巴和撒慕拿已经在你手里，你使我们将饼给你的军兵吗？」</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 7:15"> 基甸说：「耶和华将西巴和撒慕拿交在我手之后，我就用野地的荆条和枳棘打伤你们。」</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 32:30–31; 列王纪上 12:25"> 基甸从那里上到毗努伊勒，对那里的人也是这样说；毗努伊勒人也与疏割人回答他的话一样。</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 8:17; 列王纪上 22:27–28"> 他向毗努伊勒人说：「我平平安安回来的时候，我必拆毁这楼。」</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 7:12; 士师记 20:25; 士师记 20:2"> 那时西巴和撒慕拿，并跟随他们的军队都在加各，约有一万五千人，就是东方人全军所剩下的；已经被杀约有十二万拿刀的。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 32:35; 民数记 32:42; 士师记 18:27"> 基甸就由挪巴和约比哈东边，从住帐棚人的路上去，杀败了米甸人的军兵，因为他们坦然无惧。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 83:11; 阿摩司书 2:14; 约伯记 12:16–21"> 西巴和撒慕拿逃跑；基甸追赶他们，捉住米甸的二王西巴和撒慕拿，惊散全军。</span>
<span className="v" id="v13" data-v="13"> 约阿施的儿子基甸由希列斯坡从阵上回来，</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 1:24–25; 撒母耳记上 30:11–15"> 捉住疏割的一个少年人，问他：「疏割的首领长老是谁？」他就将首领长老七十七个人的名字写出来。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 8:6–7"> 基甸到了疏割，对那里的人说：「你们从前讥诮我说：『西巴和撒慕拿已经在你手里，你使我们将饼给跟随你的疲乏人吗？』现在西巴和撒慕拿在这里。」</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 8:7; 以斯拉记 2:6; 箴言 10:13"> 于是捉住那城内的长老，用野地的荆条和枳棘责打<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是指教">a</a></sup>疏割人；</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 8:9; 列王纪上 12:25"> 又拆了毗努伊勒的楼，杀了那城里的人。</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 4:6; 犹大书 1:16; 诗篇 89:12"> 基甸问西巴和撒慕拿说：「你们在他泊山所杀的人是什么样式？」回答说：「他们好像你，各人都有王子的样式。」</span>
<span className="v" id="v19" data-v="19"> 基甸说：「他们是我同母的弟兄，我指着永生的耶和华起誓，你们从前若存留他们的性命，我如今就不杀你们了。」</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 149:9; 撒母耳记上 15:33; 约书亚记 10:24"> 于是对他的长子益帖说：「你起来杀他们。」但益帖因为是童子，害怕，不敢拔刀。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 83:11; 士师记 8:26; 以赛亚书 3:18"> 西巴和撒慕拿说：「你自己起来杀我们吧！因为人如何，力量也是如何。」基甸就起来，杀了西巴和撒慕拿，夺获他们骆驼项上戴的月牙圈。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 6:15; 士师记 9:8–15; 撒母耳记上 12:12"> 以色列人对基甸说：「你既救我们脱离米甸人的手，愿你和你的儿孙管理我们。」</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 33:22; 撒母耳记上 12:12; 撒母耳记上 10:19"> 基甸说：「我不管理你们，我的儿子也不管理你们，惟有耶和华管理你们。」</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 25:13; 创世记 37:25; 创世记 37:28"> 基甸又对他们说：「我有一件事求你们：请你们各人将所夺的耳环给我。」（原来仇敌是以实玛利人，都是戴金耳环的。）</span>
<span className="v" id="v25" data-v="25"> 他们说：「我们情愿给你」，就铺开一件外衣，各人将所夺的耳环丢在其上。</span>
<span className="v" id="v26" data-v="26" data-xref="启示录 18:16; 约翰福音 19:2; 启示录 18:12"> 基甸所要出来的金耳环重一千七百舍客勒金子。此外还有米甸王所戴的月环、耳坠，和所穿的紫色衣服，并骆驼项上的金链子。</span>
<span className="v" id="v27" data-v="27" data-xref="士师记 17:5; 士师记 18:14; 诗篇 106:39"> 基甸以此制造了一个以弗得，设立在本城俄弗拉。后来以色列人拜那以弗得行了邪淫；这就作了基甸和他全家的网罗。</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 5:31; 士师记 3:11; 士师记 3:30"> 这样，米甸人被以色列人制伏了，不敢再抬头。基甸还在的日子，国中太平四十年。</span>
</div>
</div>

## 基甸去世

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="士师记 6:32; 士师记 7:1; 撒母耳记上 12:11"> 约阿施的儿子耶路·巴力回去，住在自己家里。</span>
<span className="v" id="v30" data-v="30" data-xref="士师记 9:5; 士师记 9:2; 列王纪上 11:3"> 基甸有七十个亲生的儿子，因为他有许多的妻。</span>
<span className="v" id="v31" data-v="31" data-xref="士师记 9:18; 创世记 22:24; 创世记 16:15"> 他的妾住在示剑，也给他生了一个儿子。基甸与他起名叫亚比米勒。</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 25:8; 士师记 6:24; 约伯记 5:26"> 约阿施的儿子基甸，年纪老迈而死，葬在亚比以谢族的俄弗拉，在他父亲约阿施的坟墓里。</span>
<span className="v" id="v33" data-v="33" data-xref="士师记 9:46; 士师记 2:19; 士师记 9:4"> 基甸死后，以色列人又去随从诸巴力行邪淫，以巴力·比利土为他们的神。</span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 78:42; 诗篇 106:21; 诗篇 78:11"> 以色列人不记念耶和华—他们的 神，就是拯救他们脱离四围仇敌之手的，</span>
<span className="v" id="v35" data-v="35" data-xref="传道书 9:14–15; 士师记 9:5; 士师记 9:16–19"> 也不照着耶路·巴力，就是基甸向他们所施的恩惠厚待他的家。</span>
</div>

## 犹大和西缅支派俘虏亚多尼·比色

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 20:18; 民数记 27:21; 士师记 20:28"> 约书亚死后，以色列人求问耶和华说：「我们中间谁当首先上去攻击迦南人，与他们争战？」</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 5:5; 希伯来书 7:14; 民数记 2:3"> 耶和华说：「犹大当先上去，我已将那地交在他手中。」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 10:11; 约书亚记 19:1; 士师记 1:17"> 犹大对他哥哥西缅说：「请你同我到拈阄所得之地去，好与迦南人争战；以后我也同你到你拈阄所得之地去。」于是西缅与他同去。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 11:8; 出埃及记 23:28–29; 约书亚记 11:6–8"> 犹大就上去；耶和华将迦南人和比利洗人交在他们手中。他们在比色击杀了一万人，</span>
<span className="v" id="v5" data-v="5"> 又在那里遇见亚多尼·比色，与他争战，杀败迦南人和比利洗人。</span>
<span className="v" id="v6" data-v="6"> 亚多尼·比色逃跑；他们追赶，拿住他，砍断他手脚的大拇指。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 15:33; 启示录 13:10; 路加福音 6:37–38"> 亚多尼·比色说：「从前有七十个王，手脚的大拇指都被我砍断，在我桌子底下拾取零碎食物。现在 神按着我所行的报应我了。」于是他们将亚多尼·比色带到耶路撒冷，他就死在那里。</span>
</div>
</div>

## 犹大支派攻取耶路撒冷和希伯

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约书亚记 15:63; 士师记 1:21"> 犹大人攻打耶路撒冷，将城攻取，用刀杀了城内的人，并且放火烧城。</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 15:13–20; 约书亚记 11:21; 约书亚记 10:36"> 后来犹大人下去，与住山地、南地，和高原的迦南人争战。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 13:22; 约书亚记 14:15; 耶利米书 9:23"> 犹大人去攻击住希伯 的迦南人，杀了示筛、亚希幔、挞买。希伯 从前名叫基列·亚巴。</span>
</div>
</div>

## 俄陀聂攻取底壁城

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约书亚记 15:15; 约书亚记 10:38–39"> 他们从那里去攻击底壁的居民；底壁从前名叫基列·西弗。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 15:16–17; 撒母耳记上 17:25; 撒母耳记上 18:23"> 迦勒说：「谁能攻打基列·西弗，将城夺取，我就把我女儿押撒给他为妻。」</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 3:9"> 迦勒兄弟基纳斯的儿子俄陀聂夺取了那城，迦勒就把女儿押撒给他为妻。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 15:18–19"> 押撒过门的时候，劝丈夫向她父亲求一块田。押撒一下驴，迦勒问她说：「你要什么？」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 25:18; 哥林多后书 9:5; 彼得前书 3:9"> 她说：「求你赐福给我，你既将我安置在南地，求你也给我水泉。」迦勒就把上泉下泉赐给她。</span>
</div>
</div>

## 犹大和便雅悯支派的胜利

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数记 10:29–32; 士师记 4:11; 撒母耳记上 15:6"> 摩西的内兄<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：岳父">a</a></sup>是基尼人，他的子孙与犹大人一同离了棕树城，往亚拉得以南的犹大旷野去，就住在民中。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 21:3; 士师记 1:3; 约书亚记 19:4"> 犹大和他哥哥西缅同去，击杀了住洗法的迦南人，将城尽行毁灭，那城的名便叫何珥玛。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 11:22; 士师记 3:3; 约书亚记 15:45–47"> 犹大又取了迦萨和迦萨的四境，亚实基伦和亚实基伦的四境，以革伦和以革伦的四境。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 41:10; 士师记 1:2; 诗篇 60:12"> 耶和华与犹大同在，犹大就赶出山地的居民，只是不能赶出平原的居民，因为他们有铁车。</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 1:10; 约书亚记 15:13–14; 民数记 14:24"> 以色列人照摩西所说的，将希伯 给了迦勒；迦勒就从那里赶出亚衲族的三个族长。</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 15:63; 士师记 19:10–12; 士师记 1:8"> 便雅悯人没有赶出住耶路撒冷的耶布斯人。耶布斯人仍在耶路撒冷与便雅悯人同住，直到今日。</span>
</div>
</div>

## 以法莲和玛拿西支派攻取伯特利

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="士师记 1:19; 列王纪下 18:7; 民数记 1:32"> 约瑟家也上去攻打伯特利；耶和华与他们同在。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 28:19; 创世记 35:6; 创世记 48:3"> 约瑟家打发人去窥探伯特利（那城起先名叫路斯）。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 2:12–14; 撒母耳记上 30:15"> 窥探的人看见一个人从城里出来，就对他说：「求你将进城的路指示我们，我们必恩待你。」</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 6:22–25"> 那人将进城的路指示他们，他们就用刀击杀了城中的居民，但将那人和他全家放去。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 7:6; 历代志下 1:17"> 那人往赫人之地去，筑了一座城，起名叫路斯。那城到如今还叫这名。</span>
</div>
</div>

## 以色列人没有赶出去的民

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约书亚记 17:11–13; 耶利米书 48:10; 诗篇 106:34–35"> 玛拿西没有赶出伯·善和属伯·善乡村的居民，他纳和属他纳乡村的居民，多珥和属多珥乡村的居民，以伯莲和属以伯莲乡村的居民，米吉多和属米吉多乡村的居民；迦南人却执意住在那些地方。</span>
<span className="v" id="v28" data-v="28"> 及至以色列强盛了，就使迦南人做苦工，没有把他们全然赶出。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约书亚记 16:10; 列王纪上 9:16"> 以法莲没有赶出住基色的迦南人。于是迦南人仍住在基色，在以法莲中间。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约书亚记 19:15"> 西布伦没有赶出基伦的居民和拿哈拉的居民。于是迦南人仍住在西布伦中间，成了服苦的人。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约书亚记 19:24–30"> 亚设没有赶出亚柯和西顿的居民，亚黑拉和亚革悉的居民，黑巴、亚弗革与利合的居民。</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 106:34–35"> 于是，亚设因为没有赶出那地的迦南人，就住在他们中间。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约书亚记 19:32–38; 士师记 1:30; 诗篇 18:24"> 拿弗他利没有赶出伯·示麦和伯·亚纳的居民，于是拿弗他利就住在那地的迦南人中间；然而伯·示麦和伯·亚纳的居民成了服苦的人。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="约书亚记 19:47; 士师记 18:1"> 亚摩利人强逼但人住在山地，不容他们下到平原；</span>
<span className="v" id="v35" data-v="35" data-xref="约书亚记 19:42; 士师记 12:12; 约书亚记 10:12"> 亚摩利人却执意住在希烈山和亚雅 并沙宾。然而约瑟家胜了他们，使他们成了服苦的人。</span>
<span className="v" id="v36" data-v="36" data-xref="民数记 34:4; 约书亚记 15:2–3"> 亚摩利人的境界，是从亚克拉滨坡，从西拉而上。</span>
</div>
</div>

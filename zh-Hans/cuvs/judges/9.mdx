## 亚比米勒

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 8:31; 诗篇 83:2–4; 撒母耳记下 15:6"> 耶路·巴力的儿子亚比米勒到了示剑见他的众母舅，对他们和他外祖全家的人说：</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 29:14; 士师记 8:30; 希伯来书 2:14"> 「请你们问示剑的众人说，是耶路·巴力的众子七十人都管理你们好呢？还是一人管理你们好呢？你们又要记念我是你们的骨肉。」</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 29:15; 诗篇 10:3; 箴言 1:11–14"> 他的众母舅便将这一切话为他说给示剑人听，示剑人的心就归向亚比米勒。他们说：「他原是我们的弟兄」；</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 8:33; 使徒行传 17:5; 历代志下 13:7"> 就从巴力·比利土的庙中取了七十舍客勒银子给亚比米勒；亚比米勒用以雇了些匪徒跟随他。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 11:1–2; 历代志下 21:4; 士师记 6:24"> 他往俄弗拉到他父亲的家，将他弟兄、耶路·巴力的众子七十人都杀在一块磐石上；只剩下耶路·巴力的小儿子约坦，因为他躲藏了。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 5:9; 列王纪上 12:20; 列王纪下 12:20"> 示剑人和米罗人都一同聚集，往示剑橡树旁的柱子那里，立亚比米勒为王。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 11:29; 约翰福音 4:20; 申命记 27:12"> 有人将这事告诉约坦，他就去站在基利心山顶上，向众人大声喊叫说：「示剑人哪，你们要听我的话， 神也就听你们的话。</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 8:22–23; 但以理书 4:10–18; 列王纪下 14:9"> 有一时，树木要膏一树为王，管理他们，就去对橄榄树说：『请你作我们的王。』</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 2:1; 出埃及记 29:7; 使徒行传 4:27"> 橄榄树回答说：『我岂肯止住供奉神和尊重人的油，飘摇在众树之上呢？』</span>
<span className="v" id="v10" data-v="10"> 树木对无花果树说：『请你来作我们的王。』</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 13:6–7"> 无花果树回答说：『我岂肯止住所结甜美的果子，飘摇在众树之上呢？』</span>
<span className="v" id="v12" data-v="12"> 树木对葡萄树说：『请你来作我们的王。』</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 104:15; 传道书 10:19; 民数记 15:5"> 葡萄树回答说：『我岂肯止住使神和人喜乐的新酒，飘摇在众树之上呢？』</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 14:9"> 众树对荆棘说：『请你来作我们的王。』</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 30:2; 士师记 9:20; 何西阿书 14:7"> 荆棘回答说：『你们若诚诚实实地膏我为王，就要投在我的荫下；不然，愿火从荆棘里出来，烧灭黎巴嫩的香柏树。』</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 8:35"> 「现在你们立亚比米勒为王，若按诚实正直善待耶路·巴力和他的全家，这就是酬他的劳。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 16:4; 罗马书 5:8; 启示录 12:11"> 从前我父冒死为你们争战，救了你们脱离米甸人的手。</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 9:5–6; 士师记 8:30–31; 士师记 9:14"> 你们如今起来攻击我的父家，将他众子七十人杀在一块磐石上，又立他婢女所生的儿子亚比米勒为示剑人的王；他原是你们的弟兄。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 8:6; 雅各书 4:16; 腓立比书 3:3"> 你们如今若按诚实正直待耶路·巴力和他的家，就可因亚比米勒得欢乐，他也可因你们得欢乐；</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 9:15; 士师记 9:56–57; 历代志下 20:22–23"> 不然，愿火从亚比米勒发出，烧灭示剑人和米罗众人，又愿火从示剑人和米罗人中出来，烧灭亚比米勒。」</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 21:16; 撒母耳记下 20:14; 约书亚记 19:8"> 约坦因怕他弟兄亚比米勒，就逃跑，来到比珥，住在那里。</span>
<span className="v" id="v22" data-v="22"> 亚比米勒管理以色列人三年。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 33:1; 以赛亚书 19:14; 以赛亚书 19:2"> 神使恶魔降在亚比米勒和示剑人中间，示剑人就以诡诈待亚比米勒。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 2:32; 诗篇 7:16; 以斯帖记 9:25"> 这是要叫耶路·巴力七十个儿子所受的残害归与他们的哥哥亚比米勒，又叫那流他们血的罪归与帮助他杀弟兄的示剑人。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 8:12–13; 箴言 1:11–12; 约书亚记 8:4"> 示剑人在山顶上设埋伏，等候亚比米勒。凡从他们那里经过的人，他们就抢夺。有人将这事告诉亚比米勒。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 13:8; 创世记 19:7"> 以别的儿子迦勒和他的弟兄来到示剑，示剑人都信靠他。</span>
<span className="v" id="v27" data-v="27" data-xref="士师记 9:4; 士师记 9:46; 诗篇 109:17"> 示剑人出城到田间去，摘下葡萄，踹酒，设摆筵宴，进他们神的庙中吃喝，咒诅亚比米勒。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 34:2; 创世记 34:6; 撒母耳记上 25:10"> 以别的儿子迦勒说：「亚比米勒是谁？示剑是谁？使我们服事他呢？他不是耶路·巴力的儿子吗？他的帮手不是西布勒吗？你们可以服事示剑的父亲哈抹的后裔。我们为何服事亚比米勒呢？</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 15:4; 撒母耳记下 2:14–17; 以赛亚书 36:8–9"> 惟愿这民归我的手下，我就除掉亚比米勒。」迦勒又对亚比米勒说：「增添你的军兵出来吧。」</span>
<span className="v" id="v30" data-v="30"> 邑宰西布勒听见以别的儿子迦勒的话，就发怒，</span>
<span className="v" id="v31" data-v="31"> 悄悄地打发人去见亚比米勒，说：「以别的儿子迦勒和他的弟兄到了示剑，煽惑城中的民攻击你。</span>
<span className="v" id="v32" data-v="32" data-xref="罗马书 3:15; 诗篇 36:4; 箴言 1:11–16"> 现在你和跟随你的人今夜起来，在田间埋伏。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记上 10:7; 传道书 9:10; 利未记 25:26"> 到早晨太阳一出，你就起来闯城。迦勒和跟随他的人出来攻击你的时候，你便向他们见机而做。」</span>
<span className="v" id="v34" data-v="34"> 于是，亚比米勒和跟随他的众人夜间起来，分作四队，埋伏等候示剑人。</span>
<span className="v" id="v35" data-v="35"> 以别的儿子迦勒出去，站在城门口。亚比米勒和跟随他的人从埋伏之处起来。</span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 8:24; 以西结书 7:7"> 迦勒看见那些人，就对西布勒说：「看哪，有人从山顶上下来了。」西布勒说：「你看见山的影子，以为是人。」</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 18:14"> 迦勒又说：「看哪，有人从高处下来，又有一队从米恶尼尼橡树的路上而来。」</span>
<span className="v" id="v38" data-v="38" data-xref="士师记 9:28–29; 列王纪下 14:8–14; 撒母耳记下 2:26–27"> 西布勒对他说：「你曾说，亚比米勒是谁，叫我们服事他？你所夸的口在哪里呢？这不是你所藐视的民吗？你现在出去，与他们交战吧！」</span>
<span className="v" id="v39" data-v="39"> 于是迦勒率领示剑人出去，与亚比米勒交战。</span>
<span className="v" id="v40" data-v="40" data-xref="列王纪上 20:18–21; 列王纪上 20:30"> 亚比米勒追赶迦勒；迦勒在他面前逃跑，有许多受伤仆倒的，直到城门。</span>
<span className="v" id="v41" data-v="41" data-xref="士师记 9:28; 士师记 9:30"> 亚比米勒住在亚鲁玛。西布勒赶出迦勒和他弟兄，不准他们住在示剑。</span>
<span className="v" id="v42" data-v="42"> 次日，民出到田间，有人告诉亚比米勒；</span>
<span className="v" id="v43" data-v="43"> 他就把他的人分作三队，埋伏在田间，看见示剑人从城里出来，就起来击杀他们。</span>
<span className="v" id="v44" data-v="44" data-xref="加拉太书 5:15; 士师记 9:15; 士师记 9:20"> 亚比米勒和跟随他的一队向前闯去，站在城门口；那两队直闯到田间，击杀了众人。</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪下 3:25; 申命记 29:23; 雅各书 2:13"> 亚比米勒整天攻打城，将城夺取，杀了其中的居民，将城拆毁，撒上了盐。</span>
<span className="v" id="v46" data-v="46" data-xref="士师记 8:33; 士师记 9:4; 列王纪上 8:26"> 示剑楼的人听见了，就躲入巴力·比利土庙的卫所。</span>
<span className="v" id="v47" data-v="47"> 有人告诉亚比米勒说：「示剑楼的人都聚在一处。」</span>
<span className="v" id="v48" data-v="48" data-xref="诗篇 68:14; 箴言 1:11–12; 士师记 7:17–18"> 亚比米勒和跟随他的人就都上撒们山。亚比米勒手拿斧子，砍下一根树枝，扛在肩上，对跟随他的人说：「你们看我所行的，也当赶紧照样行。」</span>
<span className="v" id="v49" data-v="49" data-xref="加拉太书 5:15; 雅各书 3:16; 士师记 9:20"> 众人就各砍一枝，跟随亚比米勒，把树枝堆在卫所的四围，放火烧了卫所，以致示剑楼的人都死了，男女约有一千。</span>
<span className="v" id="v50" data-v="50"> 亚比米勒到提备斯，向提备斯安营，就攻取了那城。</span>
<span className="v" id="v51" data-v="51"> 城中有一座坚固的楼；城里的众人，无论男女，都逃进楼去，关上门，上了楼顶。</span>
<span className="v" id="v52" data-v="52" data-xref="士师记 9:48–49; 列王纪下 14:10; 列王纪下 15:16"> 亚比米勒到了楼前攻打，挨近楼门，要用火焚烧。</span>
<span className="v" id="v53" data-v="53" data-xref="撒母耳记下 11:21; 约伯记 31:3; 耶利米书 49:20"> 有一个妇人把一块上磨石抛在亚比米勒的头上，打破了他的脑骨。</span>
<span className="v" id="v54" data-v="54" data-xref="撒母耳记上 31:4–5"> 他就急忙喊叫拿他兵器的少年人，对他说：「拔出你的刀来，杀了我吧！免得人议论我说，他为一个妇人所杀。」于是少年人把他刺透，他就死了。</span>
<span className="v" id="v55" data-v="55" data-xref="撒母耳记下 18:16; 撒母耳记下 20:21–22; 列王纪上 22:35–36"> 以色列人见亚比米勒死了，便各回自己的地方去了。</span>
<span className="v" id="v56" data-v="56" data-xref="诗篇 94:23; 士师记 9:24; 箴言 5:22"> 这样， 神报应亚比米勒向他父亲所行的恶，就是杀了弟兄七十个人的恶。</span>
<span className="v" id="v57" data-v="57" data-xref="士师记 9:20; 约书亚记 6:26; 列王纪上 16:34"> 示剑人的一切恶， 神也都报应在他们头上；耶路·巴力的儿子约坦的咒诅归到他们身上了。</span>

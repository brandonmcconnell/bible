## 以色列人准备打仗

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 11:11; 撒母耳记上 3:20; 撒母耳记上 10:17"> 于是以色列从但到别是巴，以及住基列地的众人都出来，如同一人，聚集在米斯巴耶和华面前。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 8:10; 士师记 20:17; 士师记 20:15"> 以色列民的首领，就是各支派的军长，都站在 神百姓的会中；拿刀的步兵共有四十万。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 19:22–27; 路加福音 14:31–32; 路加福音 12:58–59"> 以色列人上到米斯巴，便雅悯人都听见了。以色列人说：「请你将这件恶事的情由对我们说明。」</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 19:15–28"> 那利未人，就是被害之妇人的丈夫，回答说：「我和我的妾到了便雅悯的基比亚住宿。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 19:22; 士师记 19:25–26; 创世记 19:4–8"> 基比亚人夜间起来，围了我住的房子，想要杀我，又将我的妾强奸致死。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 19:29; 约书亚记 7:15; 士师记 19:23"> 我就把我妾的尸身切成块子，使人拿着传送以色列得为业的全地，因为基比亚人在以色列中行了凶淫丑恶的事。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 19:30; 哥林多前书 5:6; 哥林多前书 5:10–12"> 你们以色列人都当筹划商议。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="传道书 9:10; 士师记 20:1; 箴言 21:3"> 众民都起来如同一人，说：「我们连一人都不回自己帐棚、自己房屋去。</span>
<span className="v" id="v9" data-v="9" data-xref="约拿书 1:7; 尼希米记 11:1; 约书亚记 14:2"> 我们向基比亚人必这样行，照所掣的签去攻击他们。</span>
<span className="v" id="v10" data-v="10"> 我们要在以色列各支派中，一百人挑取十人，一千人挑取百人，一万人挑取千人，为民运粮，等大众到了便雅悯的基比亚，就照基比亚人在以色列中所行的丑事征伐他们。」</span>
<span className="v" id="v11" data-v="11"> 于是以色列众人彼此连合如同一人，聚集攻击那城。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命记 13:14; 申命记 20:10; 罗马书 12:18"> 以色列众支派打发人去，问便雅悯支派的各家说：「你们中间怎么做了这样的恶事呢？</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 17:12; 申命记 13:13; 士师记 19:22"> 现在你们要将基比亚的那些匪徒交出来，我们好治死他们，从以色列中除掉这恶。」便雅悯人却不肯听从他们弟兄以色列人的话。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 20:20; 约伯记 15:25–26; 民数记 21:23"> 便雅悯人从他们的各城里出来，聚集到了基比亚，要与以色列人打仗。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 26:41; 士师记 20:25; 民数记 1:37"> 那时便雅悯人从各城里点出拿刀的，共有二万六千；另外还有基比亚人点出七百精兵。</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 3:15; 历代志上 12:2; 撒母耳记上 17:49–50"> 在众军之中有拣选的七百精兵，都是左手便利的，能用机弦甩石打人，毫发不差。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 1:46; 历代志下 17:14–18; 民数记 26:51"> 便雅悯人之外，点出以色列人拿刀的，共有四十万，都是战士。</span>
</div>
</div>

## 攻打便雅悯人

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="士师记 20:23; 士师记 20:26–27; 民数记 27:21"> 以色列人就起来，到伯特利去求问 神说：「我们中间谁当首先上去与便雅悯人争战呢？」耶和华说：「犹大当先上去。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约书亚记 7:16; 约书亚记 3:1; 约书亚记 6:12"> 以色列人早晨起来，对着基比亚安营。</span>
<span className="v" id="v20" data-v="20"> 以色列人出来，要与便雅悯人打仗，就在基比亚前摆阵。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 20:25; 诗篇 73:18–19; 历代志下 28:10"> 便雅悯人就从基比亚出来，当日杀死以色列人二万二千。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 64:5; 士师记 20:17; 撒母耳记上 30:6"> 以色列人彼此奋勇，仍在头一日摆阵的地方又摆阵。</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 20:26–27; 诗篇 78:34–36; 约书亚记 7:6"> 未摆阵之先，以色列人上去，在耶和华面前哭号，直到晚上，求问耶和华说：「我们再去与我们弟兄便雅悯人打仗可以不可以？」耶和华说：「可以上去攻击他们。」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 第二日，以色列人就上前攻击便雅悯人。</span>
<span className="v" id="v25" data-v="25" data-xref="士师记 20:21; 创世记 18:25; 罗马书 2:5"> 便雅悯人也在这日从基比亚出来，与以色列人接战，又杀死他们一万八千，都是拿刀的。</span>
<span className="v" id="v26" data-v="26" data-xref="士师记 20:23; 约珥书 2:12–18; 士师记 20:18"> 以色列众人就上到伯特利，坐在耶和华面前哭号，当日禁食直到晚上；又在耶和华面前献燔祭和平安祭。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 18:1; 士师记 20:18; 撒母耳记上 4:3–4"> 那时， 神的约柜在那里；亚伦的孙子、以利亚撒的儿子非尼哈侍立在约柜前。以色列人问耶和华说：「我们当再出去与我们弟兄便雅悯人打仗呢？还是罢兵呢？」耶和华说：「你们当上去，因为明日我必将他们交在你们手中。」</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约书亚记 8:4; 撒母耳记下 5:23; 士师记 20:34"> 以色列人在基比亚的四围设下伏兵。</span>
<span className="v" id="v30" data-v="30"> 第三日，以色列人又上去攻击便雅悯人，在基比亚前摆阵，与前两次一样。</span>
<span className="v" id="v31" data-v="31" data-xref="士师记 19:13–14; 约书亚记 7:5; 以赛亚书 10:29"> 便雅悯人也出来迎敌，就被引诱离城；在田间两条路上，一通伯特利，一通基比亚，像前两次，动手杀死以色列人约有三十个。</span>
<span className="v" id="v32" data-v="32" data-xref="约书亚记 8:15–16"> 便雅悯人说：「他们仍旧败在我们面前。」但以色列人说：「我们不如逃跑，引诱他们离开城到路上来。」</span>
<span className="v" id="v33" data-v="33" data-xref="约书亚记 8:18–22"> 以色列众人都起来，在巴力·他玛摆阵，以色列的伏兵从马利·迦巴埋伏的地方冲上前去。</span>
<span className="v" id="v34" data-v="34" data-xref="约书亚记 8:14; 以赛亚书 47:11; 约伯记 21:13"> 有以色列人中的一万精兵，来到基比亚前接战，势派甚是凶猛；便雅悯人却不知道灾祸临近了。</span>
<span className="v" id="v35" data-v="35" data-xref="约伯记 20:5; 士师记 20:15; 士师记 20:44–46"> 耶和华使以色列人杀败便雅悯人。那日，以色列人杀死便雅悯人二万五千一百，都是拿刀的。</span>
</div>
</div>

## 以色列人得胜

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="约书亚记 8:15–29"> 于是便雅悯人知道自己败了。先是以色列人；因为靠着在基比亚前所设的伏兵，就在便雅悯人面前诈败。</span>
<span className="v" id="v37" data-v="37" data-xref="约书亚记 8:19; 约书亚记 6:5; 出埃及记 19:13"> 伏兵急忙闯进基比亚，用刀杀死全城的人。</span>
<span className="v" id="v38" data-v="38" data-xref="约书亚记 8:20; 创世记 17:21; 列王纪下 4:16"> 以色列人预先同伏兵约定在城内放火，以烟气上腾为号。</span>
<span className="v" id="v39" data-v="39" data-xref="士师记 20:32"> 以色列人临退阵的时候，便雅悯人动手杀死以色列人，约有三十个，就说：「他们仍像前次被我们杀败了。」</span>
<span className="v" id="v40" data-v="40" data-xref="约书亚记 8:20; 启示录 19:3; 创世记 19:28"> 当烟气如柱从城中上腾的时候，便雅悯人回头观看，见全城的烟气冲天。</span>
<span className="v" id="v41" data-v="41" data-xref="彼得后书 2:12; 路加福音 21:26; 启示录 6:15–17"> 以色列人又转身回来，便雅悯人就甚惊惶，因为看见灾祸临到自己了。</span>
<span className="v" id="v42" data-v="42" data-xref="约书亚记 8:15; 何西阿书 9:9; 耶利米哀歌 1:3"> 他们在以色列人面前转身往旷野逃跑；以色列人在后面追杀。那从各城里出来的，也都夹攻杀灭他们。</span>
<span className="v" id="v43" data-v="43" data-xref="约书亚记 8:20–22"> 以色列人围绕便雅悯人，追赶他们，在他们歇脚之处、对着日出之地的基比亚践踏他们。</span>
<span className="v" id="v44" data-v="44"> 便雅悯人死了的有一万八千，都是勇士。</span>
<span className="v" id="v45" data-v="45" data-xref="约书亚记 15:32; 士师记 21:13; 撒迦利亚书 14:10"> 其余的人转身向旷野逃跑，往临门磐去。以色列人在道路上杀了他们五千人，如拾取遗穗一样，追到基顿又杀了他们二千人。</span>
<span className="v" id="v46" data-v="46" data-xref="士师记 20:35; 士师记 20:15"> 那日便雅悯死了的共有二万五千人，都是拿刀的勇士。</span>
<span className="v" id="v47" data-v="47" data-xref="以赛亚书 1:9; 诗篇 103:9–10; 哈巴谷书 3:2"> 只剩下六百人，转身向旷野逃跑，到了临门磐，就在那里住了四个月。</span>
<span className="v" id="v48" data-v="48" data-xref="申命记 13:15–17; 历代志下 25:13; 历代志下 28:6–9"> 以色列人又转到便雅悯地，将各城的人和牲畜，并一切所遇见的，都用刀杀尽，又放火烧了一切城邑。</span>
</div>
</div>

## 赞美耶和华

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 138:1; 诗篇 149:1; 诗篇 106:1"> <span className="pl pl-1">你们要赞美耶和华！</span><br /><span className="pl pl-1">我要在正直人的大会中，并公会中，</span><br /><span className="pl pl-1">一心称谢耶和华。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 104:24; 箴言 24:14; 诗篇 139:14"> <span className="pl pl-1">耶和华的作为本为大；</span><br /><span className="pl pl-1">凡喜爱的都必考察。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 145:4–5; 诗篇 145:10–12; 启示录 5:12–14"> <span className="pl pl-1">他所行的是尊荣和威严；</span><br /><span className="pl pl-1">他的公义存到永远。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 103:8; 以赛亚书 63:7; 诗篇 145:8"> <span className="pl pl-1">他行了奇事，使人记念；</span><br /><span className="pl pl-1">耶和华有恩惠，有怜悯。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 105:8; 路加福音 1:72; 马太福音 6:26–33"> <span className="pl pl-1">他赐粮食给敬畏他的人；</span><br /><span className="pl pl-1">他必永远记念他的约。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 2:8; 诗篇 80:8; 诗篇 44:2"> <span className="pl pl-1">他向百姓显出大能的作为，</span><br /><span className="pl pl-1">把外邦的地赐给他们为业。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 19:7; 诗篇 89:14; 诗篇 119:160"> <span className="pl pl-1">他手所行的是诚实公平；</span><br /><span className="pl pl-1">他的训词都是确实的，</span><br /></span>

## 大卫的胜利之歌

<div className="bt">
<div className="hs">耶和华的仆人大卫的诗，交与伶长。当耶和华救他脱离一切仇敌和扫罗之手的日子，他向耶和华念这诗的话。说：</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 22:1–51; 歌罗西书 1:11; 约翰一书 4:19"> <span className="pl pl-1">耶和华，我的力量啊，我爱你！</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 144:2; 诗篇 62:7; 诗篇 19:14"> <span className="pl pl-1">耶和华是我的岩石，我的山寨，我的救主，</span><br /><span className="pl pl-1">我的 神，我的磐石，我所投靠的。</span><br /><span className="pl pl-1">他是我的盾牌，</span><br /><span className="pl pl-1">是拯救我的角，是我的高台。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 91:15; 诗篇 145:3; 诗篇 62:8"> <span className="pl pl-1">我要求告当赞美的耶和华；</span><br /><span className="pl pl-1">这样我必从仇敌手中被救出来。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="诗篇 116:3; 马太福音 27:24–25; 马可福音 14:33–34"> <span className="pl pl-1">曾有死亡的绳索缠绕我，</span><br /><span className="pl pl-1">匪类的急流使我惊惧，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 86:13; 诗篇 88:3–8; 使徒行传 2:24"> <span className="pl pl-1">阴间的绳索缠绕我，</span><br /><span className="pl pl-1">死亡的网罗临到我。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="诗篇 50:15; 撒母耳记下 22:7; 诗篇 34:15"> <span className="pl pl-1">我在急难中求告耶和华，</span><br /><span className="pl pl-1">向我的 神呼求。</span><br /><span className="pl pl-1">他从殿中听了我的声音；</span><br /><span className="pl pl-1">我在他面前的呼求入了他的耳中。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 4:31; 诗篇 68:7–8; 使徒行传 16:25–26"> <span className="pl pl-1">那时，因他发怒，地就摇撼战抖；</span><br /><span className="pl pl-1">山的根基也震动摇撼。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 21:9; 诗篇 11:6; 那鸿书 1:5–6"> <span className="pl pl-1">从他鼻孔冒烟上腾；</span><br /><span className="pl pl-1">从他口中发火焚烧，连炭也着了。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 144:5–15; 申命记 33:26; 撒母耳记下 22:10"> <span className="pl pl-1">他又使天下垂，亲自降临，</span><br /><span className="pl pl-1">有黑云在他脚下。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 104:3; 撒母耳记下 22:11–12; 诗篇 99:1"> <span className="pl pl-1">他坐着基路伯飞行；</span><br /><span className="pl pl-1">他借着风的翅膀快飞。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 97:2; 申命记 4:11; 诗篇 91:1"> <span className="pl pl-1">他以黑暗为藏身之处，</span><br /><span className="pl pl-1">以水的黑暗、天空的厚云为他四围的行宫。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 10:11; 启示录 16:21; 马太福音 17:2"> <span className="pl pl-1">因他面前的光辉，</span><br /><span className="pl pl-1">他的厚云行过便有冰雹火炭。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 104:7; 撒母耳记上 7:10; 诗篇 140:10"> <span className="pl pl-1">耶和华也在天上打雷；</span><br /><span className="pl pl-1">至高者发出声音便有冰雹火炭。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 144:6; 哈巴谷书 3:11; 民数记 24:8"> <span className="pl pl-1">他射出箭来，使仇敌四散；</span><br /><span className="pl pl-1">多多发出闪电，使他们扰乱。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 106:9; 出埃及记 15:8; 弥迦书 6:2"> <span className="pl pl-1">耶和华啊，你的斥责一发，</span><br /><span className="pl pl-1">你鼻孔的气一出，</span><br /><span className="pl pl-1">海底就出现，</span><br /><span className="pl pl-1">大地的根基也显露。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 22:17; 诗篇 144:7; 诗篇 57:3"> <span className="pl pl-1">他从高天伸手抓住我，</span><br /><span className="pl pl-1">把我从大水中拉上来。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 2:14–15; 诗篇 35:10; 诗篇 142:6"> <span className="pl pl-1">他救我脱离我的劲敌和那些恨我的人，</span><br /><span className="pl pl-1">因为他们比我强盛。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="俄巴底亚书 1:10–14; 申命记 32:35; 诗篇 46:11"> <span className="pl pl-1">我遭遇灾难的日子，他们来攻击我；</span><br /><span className="pl pl-1">但耶和华是我的倚靠。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 118:5; 诗篇 31:8; 诗篇 18:36"> <span className="pl pl-1">他又领我到宽阔之处；</span><br /><span className="pl pl-1">他救拔我，因他喜悦我。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="诗篇 24:4; 马太福音 6:4; 诗篇 58:11"> <span className="pl pl-1">耶和华按着我的公义报答我，</span><br /><span className="pl pl-1">按着我手中的清洁赏赐我。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 119:102; 诗篇 17:4; 诗篇 26:1"> <span className="pl pl-1">因为我遵守了耶和华的道，</span><br /><span className="pl pl-1">未曾作恶离开我的 神。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 119:13; 诗篇 119:112; 诗篇 119:30"> <span className="pl pl-1">他的一切典章常在我面前；</span><br /><span className="pl pl-1">他的律例我也未曾丢弃。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 18:8–9; 诗篇 11:7; 历代志上 29:17"> <span className="pl pl-1">我在他面前作了完全人；</span><br /><span className="pl pl-1">我也保守自己远离我的罪孽。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 10:41–42; 路得记 2:12; 撒母耳记上 26:23"> <span className="pl pl-1">所以，耶和华按我的公义，</span><br /><span className="pl pl-1">按我在他眼前手中的清洁偿还我。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="马太福音 5:7; 诗篇 62:12; 马太福音 18:33–35"> <span className="pl pl-1">慈爱的人，你以慈爱待他；</span><br /><span className="pl pl-1">完全的人，你以完全待他。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="箴言 3:34; 利未记 26:23–24; 雅各书 2:13"> <span className="pl pl-1">清洁的人，你以清洁待他；</span><br /><span className="pl pl-1">乖僻的人，你以弯曲待他。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 66:2; 雅各书 2:5; 以赛亚书 57:15"> <span className="pl pl-1">困苦的百姓，你必拯救；</span><br /><span className="pl pl-1">高傲的眼目，你必使他降卑。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 22:29; 约伯记 29:3; 以赛亚书 42:16"> <span className="pl pl-1">你必点着我的灯；</span><br /><span className="pl pl-1">耶和华—我的 神必照明我的黑暗。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 22:30; 以弗所书 6:10–13; 哥林多后书 12:9–10"> <span className="pl pl-1">我借着你冲入敌军，</span><br /><span className="pl pl-1">借着我的 神跳过墙垣。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="申命记 32:4; 箴言 30:5; 撒母耳记下 22:31"> <span className="pl pl-1">至于 神，他的道是完全的；</span><br /><span className="pl pl-1">耶和华的话是炼净的。</span><br /><span className="pl pl-1">凡投靠他的，他便作他们的盾牌。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="申命记 32:31; 诗篇 86:8; 撒母耳记下 22:32"> <span className="pl pl-1">除了耶和华，谁是 神呢？</span><br /><span className="pl pl-1">除了我们的 神，谁是磐石呢？</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 45:5; 诗篇 28:7; 撒母耳记下 22:33"> <span className="pl pl-1">惟有那以力量束我的腰、</span><br /><span className="pl pl-1">使我行为完全的，他是 神。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="哈巴谷书 3:19; 申命记 32:13; 申命记 33:29"> <span className="pl pl-1">他使我的脚快如母鹿的蹄，</span><br /><span className="pl pl-1">又使我在高处安稳。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 144:1; 诗篇 46:9; 撒母耳记下 22:36"> <span className="pl pl-1">他教导我的手能以争战，</span><br /><span className="pl pl-1">甚至我的膀臂能开铜弓。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 22:36; 雅各书 3:17–18; 诗篇 28:7"> <span className="pl pl-1">你把你的救恩给我作盾牌；</span><br /><span className="pl pl-1">你的右手扶持我；</span><br /><span className="pl pl-1">你的温和使我为大。</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="箴言 4:12; 撒母耳记下 22:37; 约伯记 36:16"> <span className="pl pl-1">你使我脚下的地步宽阔；</span><br /><span className="pl pl-1">我的脚未曾滑跌。</span><br /></span>
<span className="v" id="v37" data-v="37" data-xref="以赛亚书 53:10–12; 诗篇 44:5; 诗篇 35:2"> <span className="pl pl-1">我要追赶我的仇敌，并要追上他们；</span><br /><span className="pl pl-1">不将他们灭绝，我总不归回。</span><br /></span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳记下 5:1–25; 撒母耳记下 22:39; 撒母耳记上 23:5"> <span className="pl pl-1">我要打伤他们，使他们不能起来；</span><br /><span className="pl pl-1">他们必倒在我的脚下。</span><br /></span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳记下 22:40–41; 诗篇 18:32; 哥林多前书 15:25–28"> <span className="pl pl-1">因为你曾以力量束我的腰，使我能争战；</span><br /><span className="pl pl-1">你也使那起来攻击我的都服在我以下。</span><br /></span>
<span className="v" id="v40" data-v="40" data-xref="诗篇 21:12; 诗篇 94:23"> <span className="pl pl-1">你又使我的仇敌在我面前转背逃跑，</span><br /><span className="pl pl-1">叫我能以剪除那恨我的人。</span><br /></span>
<span className="v" id="v41" data-v="41" data-xref="箴言 1:28; 约伯记 27:9; 约伯记 35:12–13"> <span className="pl pl-1">他们呼求，却无人拯救；</span><br /><span className="pl pl-1">就是呼求耶和华，他也不应允。</span><br /></span>
<span className="v" id="v42" data-v="42" data-xref="以赛亚书 10:6; 撒迦利亚书 10:5; 列王纪下 13:7"> <span className="pl pl-1">我捣碎他们，如同风前的灰尘，</span><br /><span className="pl pl-1">倒出他们，如同街上的泥土。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v43" data-v="43" data-xref="以赛亚书 55:5; 撒母耳记下 3:1; 以赛亚书 52:15"> <span className="pl pl-1">你救我脱离百姓的争竞，</span><br /><span className="pl pl-1">立我作列国的元首；</span><br /><span className="pl pl-1">我素不认识的民必事奉我。</span><br /></span>
<span className="v" id="v44" data-v="44" data-xref="诗篇 66:3; 诗篇 81:15; 申命记 33:29"> <span className="pl pl-1">他们一听见我的名声就必顺从我；</span><br /><span className="pl pl-1">外邦人要投降我。</span><br /></span>
<span className="v" id="v45" data-v="45" data-xref="弥迦书 7:17; 雅各书 1:11; 以赛亚书 24:4"> <span className="pl pl-1">外邦人要衰残，</span><br /><span className="pl pl-1">战战兢兢地出他们的营寨。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v46" data-v="46" data-xref="撒母耳记下 22:47; 诗篇 57:5; 诗篇 18:2"> <span className="pl pl-1">耶和华是活神。</span><br /><span className="pl pl-1">愿我的磐石被人称颂；</span><br /><span className="pl pl-1">愿救我的 神被人尊崇。</span><br /></span>
<span className="v" id="v47" data-v="47" data-xref="诗篇 47:3; 罗马书 12:19; 那鸿书 1:2"> <span className="pl pl-1">这位 神，就是那为我伸冤、</span><br /><span className="pl pl-1">使众民服在我以下的。</span><br /></span>
<span className="v" id="v48" data-v="48" data-xref="诗篇 140:1; 诗篇 140:4; 诗篇 86:14"> <span className="pl pl-1">你救我脱离仇敌，</span><br /><span className="pl pl-1">又把我举起，高过那些起来攻击我的；</span><br /><span className="pl pl-1">你救我脱离强暴的人。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v49" data-v="49" data-xref="罗马书 15:9; 撒母耳记下 22:50–51; 诗篇 72:18–19"> <span className="pl pl-1">耶和华啊，因此我要在外邦中称谢你，</span><br /><span className="pl pl-1">歌颂你的名。</span><br /></span>
<span className="v" id="v50" data-v="50" data-xref="诗篇 144:10; 诗篇 132:10; 撒母耳记下 7:13"> <span className="pl pl-1">耶和华赐极大的救恩给他所立的王，</span><br /><span className="pl pl-1">施慈爱给他的受膏者，</span><br /><span className="pl pl-1">就是给大卫和他的后裔，直到永远。</span></span>
</div>

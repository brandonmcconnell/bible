## 渴慕 神

<div className="bt">
<div className="hs">大卫在犹大旷野的时候，作了这诗。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 143:6; 诗篇 84:2; 诗篇 42:1–2"> <span className="pl pl-1">神啊，你是我的 神，</span><br /><span className="pl pl-1">我要切切地寻求你，</span><br /><span className="pl pl-1">在干旱疲乏无水之地，我渴想你；</span><br /><span className="pl pl-1">我的心切慕你。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 27:4; 诗篇 105:4; 诗篇 84:2–11"> <span className="pl pl-1">我在圣所中曾如此瞻仰你，</span><br /><span className="pl pl-1">为要见你的能力和你的荣耀。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 69:16; 诗篇 51:15; 腓立比书 1:23"> <span className="pl pl-1">因你的慈爱比生命更好，</span><br /><span className="pl pl-1">我的嘴唇要颂赞你。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 104:33; 诗篇 134:2; 诗篇 28:2"> <span className="pl pl-1">我还活的时候要这样称颂你；</span><br /><span className="pl pl-1">我要奉你的名举手。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="诗篇 36:7–9; 以赛亚书 25:6; 以斯拉记 3:11–13"> <span className="pl pl-1">我在床上记念你，</span><br /><span className="pl pl-1">在夜更的时候思想你；</span><br /><span className="pl pl-1">我的心就像饱足了骨髓肥油，</span><br /><span className="pl pl-1">我也要以欢乐的嘴唇赞美你。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 1:10; 诗篇 61:4; 诗篇 27:9"> <span className="pl pl-1">因为你曾帮助我，</span><br /><span className="pl pl-1">我就在你翅膀的荫下欢呼。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 41:10; 诗篇 18:35; 诗篇 73:23"> <span className="pl pl-1">我心紧紧地跟随你；</span><br /><span className="pl pl-1">你的右手扶持我。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="诗篇 55:15; 诗篇 9:17; 诗篇 40:14"> <span className="pl pl-1">但那些寻索要灭我命的人</span><br /><span className="pl pl-1">必往地底下去；</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 18:21; 以西结书 35:5; 以西结书 39:4"> <span className="pl pl-1">他们必被刀剑所杀，</span><br /><span className="pl pl-1">被野狗所吃。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="申命记 6:13; 诗篇 21:1; 以赛亚书 65:16"> <span className="pl pl-1">但是王必因 神欢喜。</span><br /><span className="pl pl-1">凡指着他发誓的必要夸口，</span><br /><span className="pl pl-1">因为说谎之人的口必被塞住。</span></span>
</div>

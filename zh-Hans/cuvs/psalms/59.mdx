## 为安全求主施助

<div className="bt">
<div className="hs">扫罗打发人窥探大卫的房屋，要杀他。那时，大卫作这金诗，交与伶长。调用休要毁坏。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 19:11–24; 诗篇 18:48; 诗篇 57:1"> <span className="pl pl-1">我的 神啊，求你救我脱离仇敌，</span><br /><span className="pl pl-1">把我安置在高处，得脱那些起来攻击我的人。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 139:19; 诗篇 26:9; 诗篇 55:23"> <span className="pl pl-1">求你救我脱离作孽的人</span><br /><span className="pl pl-1">和喜爱流人血的人！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="诗篇 56:6; 诗篇 69:4; 撒母耳记上 24:11"> <span className="pl pl-1">因为，他们埋伏要害我的命；</span><br /><span className="pl pl-1">有能力的人聚集来攻击我。</span><br /><span className="pl pl-1">耶和华啊，这不是为我的过犯，</span><br /><span className="pl pl-1">也不是为我的罪愆。</span><br /></span>

<span className="v" id="v5" data-v="5" data-xref="诗篇 84:8; 诗篇 55:15; 诗篇 9:15"> <span className="pl pl-1">万军之 神—耶和华以色列的 神啊！</span><br /><span className="pl pl-1">求你兴起，惩治万邦！</span><br /><span className="pl pl-1">不要怜悯行诡诈的恶人！ （细拉）</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="诗篇 59:14; 诗篇 22:16; 撒母耳记上 19:11"> <span className="pl pl-1">他们晚上转回，</span><br /><span className="pl pl-1">叫号如狗，围城绕行。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 57:4; 箴言 15:2; 诗篇 10:11"> <span className="pl pl-1">他们口中喷吐恶言，嘴里有刀；</span><br /><span className="pl pl-1">他们说：有谁听见？</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="箴言 1:26; 诗篇 37:13; 诗篇 2:4"> <span className="pl pl-1">但你—耶和华必笑话他们；</span><br /><span className="pl pl-1">你要嗤笑万邦。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 9:9; 诗篇 62:2; 诗篇 27:14"> <span className="pl pl-1">我的力量啊，我必仰望你，</span><br /><span className="pl pl-1">因为 神是我的高台。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 54:7; 诗篇 59:17; 彼得前书 5:10"> <span className="pl pl-1">我的 神要以慈爱迎接我；</span><br /><span className="pl pl-1">神要叫我看见我仇敌遭报。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="诗篇 3:3; 启示录 9:6; 约伯记 40:12"> <span className="pl pl-1">不要杀他们，恐怕我的民忘记。</span><br /><span className="pl pl-1">主啊，你是我们的盾牌；</span><br /><span className="pl pl-1">求你用你的能力使他们四散，</span><br /><span className="pl pl-1">且降为卑。</span><br /></span>

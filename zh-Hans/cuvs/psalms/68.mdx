## 胜利之歌

<div className="bt">
<div className="hs">大卫的诗歌，交与伶长。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="民数记 10:35; 以赛亚书 51:9–10; 以赛亚书 42:13–14"> <span className="pl pl-1">愿 神兴起，使他的仇敌四散，</span><br /><span className="pl pl-1">叫那恨他的人从他面前逃跑。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="弥迦书 1:4; 诗篇 37:20; 以赛亚书 9:18"> <span className="pl pl-1">他们被驱逐，如烟被风吹散；</span><br /><span className="pl pl-1">恶人见 神之面而消灭，如蜡被火熔化。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="申命记 33:26; 以赛亚书 12:4–6; 诗篇 66:4"> <span className="pl pl-1">你们当向 神唱诗，歌颂他的名；</span><br /><span className="pl pl-1">为那坐车行过旷野的修平大路。</span><br /><span className="pl pl-1">他的名是耶和华，</span><br /><span className="pl pl-1">要在他面前欢乐！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="诗篇 10:14; 耶利米书 49:11; 诗篇 82:3–4"> <span className="pl pl-1">神在他的圣所作孤儿的父，</span><br /><span className="pl pl-1">作寡妇的伸冤者。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 13:21; 士师记 5:4; 士师记 4:14"> <span className="pl pl-1">神啊，你曾在你百姓前头出来，</span><br /><span className="pl pl-1">在旷野行走。 （细拉）</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 19:18; 出埃及记 19:16; 申命记 5:23–25"> <span className="pl pl-1">那时，地见 神的面而震动，天也落雨；</span><br /><span className="pl pl-1">西奈山见以色列 神的面也震动。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="出埃及记 15:20; 诗篇 40:3; 出埃及记 17:9–16"> <span className="pl pl-1">主发命令，</span><br /><span className="pl pl-1">传好信息的妇女成了大群。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 10:16; 士师记 5:19; 撒母耳记上 30:24"> <span className="pl pl-1">统兵的君王逃跑了，逃跑了；</span><br /><span className="pl pl-1">在家等候的妇女分受所夺的。</span><br /></span>

<span className="v" id="v14" data-v="14" data-xref="士师记 9:48; 诗篇 51:7; 以赛亚书 1:18"> <span className="pl pl-1">全能者在境内赶散列王的时候，</span><br /><span className="pl pl-1">势如飘雪在撒们。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="诗篇 87:1–2; 诗篇 78:68–69; 申命记 3:10"> <span className="pl pl-1">巴珊山是 神的山；</span><br /><span className="pl pl-1">巴珊山是多峰多岭的山。</span><br /></span>

</div>

<div className="bp poetry">

</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="诗篇 12:6; 提多书 1:2; 申命记 32:4"> <span className="pl pl-1">因为耶和华的言语正直；</span><br /><span className="pl pl-1">凡他所做的尽都诚实。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 11:7; 诗篇 119:64; 诗篇 104:24"> <span className="pl pl-1">他喜爱仁义公平；</span><br /><span className="pl pl-1">遍地满了耶和华的慈爱。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="希伯来书 11:3; 彼得后书 3:5; 约伯记 33:4"> <span className="pl pl-1">诸天借耶和华的命而造；</span><br /><span className="pl pl-1">万象借他口中的气而成。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 15:8; 约书亚记 3:16; 约书亚记 3:13"> <span className="pl pl-1">他聚集海水如垒，</span><br /><span className="pl pl-1">收藏深洋在库房。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="启示录 14:6–7; 诗篇 96:9–10; 诗篇 22:27"> <span className="pl pl-1">愿全地都敬畏耶和华！</span><br /><span className="pl pl-1">愿世上的居民都惧怕他！</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="创世记 1:3; 诗篇 33:6; 诗篇 148:5–6"> <span className="pl pl-1">因为他说有，就有，</span><br /><span className="pl pl-1">命立，就立。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 21:11; 约伯记 5:12–13; 以赛亚书 44:25"> <span className="pl pl-1">耶和华使列国的筹算归于无有，</span><br /><span className="pl pl-1">使众民的思念无有功效。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 19:21; 以赛亚书 46:10; 约伯记 23:13"> <span className="pl pl-1">耶和华的筹算永远立定；</span><br /><span className="pl pl-1">他心中的思念万代常存。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 144:15; 彼得前书 2:9; 约翰福音 15:16"> <span className="pl pl-1">以耶和华为 神的，那国是有福的！</span><br /><span className="pl pl-1">他所拣选为自己产业的，那民是有福的！</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="约伯记 28:24; 诗篇 11:4; 诗篇 53:2"> <span className="pl pl-1">耶和华从天上观看；</span><br /><span className="pl pl-1">他看见一切的世人。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 8:39; 列王纪上 8:27; 以赛亚书 57:15"> <span className="pl pl-1">从他的居所往外察看地上一切的居民—</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 32:19; 诗篇 44:21; 何西阿书 7:2"> <span className="pl pl-1">他是那造成他们众人心的，</span><br /><span className="pl pl-1">留意他们一切作为的。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 44:3; 耶利米书 9:23; 诗篇 44:6–7"> <span className="pl pl-1">君王不能因兵多得胜；</span><br /><span className="pl pl-1">勇士不能因力大得救。</span><br /></span>

</div>

<span className="v" id="v20" data-v="20" data-xref="以赛亚书 40:31; 诗篇 27:14; 诗篇 130:5–6"> <span className="pl pl-1">我们的心向来等候耶和华；</span><br /><span className="pl pl-1">他是我们的帮助，我们的盾牌。</span><br /></span>

</div>

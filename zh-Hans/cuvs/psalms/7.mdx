## 为公义而祈祷

<div className="bt">
<div className="hs">大卫指着便雅悯人古实的话，向耶和华唱的流离歌。</div>
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 31:15; 哈巴谷书 3:1; 彼得前书 4:19"> <span className="pl pl-1">耶和华—我的 神啊，我投靠你！</span><br /><span className="pl pl-1">求你救我脱离一切追赶我的人，将我救拔出来！</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 50:22; 以赛亚书 38:13; 提摩太后书 4:17"> <span className="pl pl-1">恐怕他们像狮子撕裂我，</span><br /><span className="pl pl-1">甚至撕碎，无人搭救。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="诗篇 59:3; 撒母耳记上 24:11; 撒母耳记上 26:18–19"> <span className="pl pl-1">耶和华—我的 神啊，我若行了这事，</span><br /><span className="pl pl-1">若有罪孽在我手里，</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 55:20; 撒母耳记上 22:14; 撒母耳记上 24:17–19"> <span className="pl pl-1">我若以恶报那与我交好的人—</span><br /><span className="pl pl-1">连那无故与我为敌的，我也救了他，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 10:6; 撒迦利亚书 10:5; 耶利米书 17:13"> <span className="pl pl-1">就任凭仇敌追赶我，直到追上，</span><br /><span className="pl pl-1">将我的性命踏在地下，</span><br /><span className="pl pl-1">使我的荣耀归于灰尘。 （细拉）</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="诗篇 44:23; 诗篇 35:23; 诗篇 3:7"> <span className="pl pl-1">耶和华啊，求你在怒中起来，</span><br /><span className="pl pl-1">挺身而立，抵挡我敌人的暴怒！</span><br /><span className="pl pl-1">求你为我兴起！你已经命定施行审判！</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 57:15; 启示录 16:5–7; 启示录 18:20"> <span className="pl pl-1">愿众民的会环绕你！</span><br /><span className="pl pl-1">愿你从其上归于高位！</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 96:13; 罗马书 14:10–12; 诗篇 43:1"> <span className="pl pl-1">耶和华向众民施行审判；</span><br /><span className="pl pl-1">耶和华啊，求你按我的公义和我心中的纯正判断我。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="耶利米书 11:20; 耶利米书 17:10; 耶利米书 20:12"> <span className="pl pl-1">愿恶人的恶断绝！</span><br /><span className="pl pl-1">愿你坚立义人！</span><br /><span className="pl pl-1">因为公义的 神察验人的心肠肺腑。</span><br /></span>

<span className="v" id="v11" data-v="11" data-xref="那鸿书 1:2; 那鸿书 1:6; 诗篇 94:15"> <span className="pl pl-1">神是公义的审判者，</span><br /><span className="pl pl-1">又是天天向恶人发怒的 神。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 3:19; 马太福音 3:10; 申命记 32:41"> <span className="pl pl-1">若有人不回头，他的刀必磨快，</span><br /><span className="pl pl-1">弓必上弦，预备妥当了。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="帖撒罗尼迦后书 1:6; 诗篇 45:5; 诗篇 64:7"> <span className="pl pl-1">他也预备了杀人的器械；</span><br /><span className="pl pl-1">他所射的是火箭。</span><br /></span>

<span className="v" id="v15" data-v="15" data-xref="约伯记 4:8; 诗篇 141:10; 箴言 26:27"> <span className="pl pl-1">他掘了坑，又挖深了，</span><br /><span className="pl pl-1">竟掉在自己所挖的阱里。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以斯帖记 9:25; 诗篇 37:12–13; 列王纪上 2:32"> <span className="pl pl-1">他的毒害必临到他自己的头上；</span><br /><span className="pl pl-1">他的强暴必落到他自己的脑袋上。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="诗篇 9:2; 诗篇 98:2; 诗篇 71:15–16"> <span className="pl pl-1">我要照着耶和华的公义称谢他，</span><br /><span className="pl pl-1">歌颂耶和华至高者的名。</span></span>
</div>

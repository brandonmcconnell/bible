## 恃财之愚

<div className="bt">

<span className="v" id="v6" data-v="6" data-xref="提摩太前书 6:17; 诗篇 52:7; 耶利米书 9:23"> <span className="pl pl-1">那些倚仗财货自夸钱财多的人，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 16:26; 提摩太前书 2:6; 彼得前书 1:18"> <span className="pl pl-1">一个也无法赎自己的弟兄，</span><br /><span className="pl pl-1">也不能替他将赎价给 神，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 16:26; 约伯记 36:18–19"> <span className="pl pl-1">叫他长远活着，不见朽坏；</span><br /><span className="pl pl-1">因为赎他生命的价值极贵，</span><br /><span className="pl pl-1">只可永远罢休。</span></span>
</div>
<div className="bp poetry">

<span className="v" id="v12" data-v="12" data-xref="传道书 3:18–21; 诗篇 49:20; 诗篇 82:7"> <span className="pl pl-1">但人居尊贵中不能长久，</span><br /><span className="pl pl-1">如同死亡的畜类一样。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:20; 哥林多前书 3:19; 路加福音 16:27–28"> <span className="pl pl-1">他们行的这道本为自己的愚昧；</span><br /><span className="pl pl-1">但他们以后的人还佩服他们的话语。 （细拉）</span><br /></span>

<span className="v" id="v15" data-v="15" data-xref="诗篇 73:24; 诗篇 56:13; 诗篇 86:13"> <span className="pl pl-1">只是 神必救赎我的灵魂脱离阴间的权柄，</span><br /><span className="pl pl-1">因他必收纳我。 （细拉）</span></span>
</div>

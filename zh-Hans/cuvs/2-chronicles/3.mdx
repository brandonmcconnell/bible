<span className="v" id="v1" data-v="1" data-xref="历代志上 21:18; 创世记 22:14; 历代志上 22:1"> 所罗门就在耶路撒冷、耶和华向他父大卫显现的摩利亚山上，就是耶布斯人阿珥楠的禾场上、大卫所指定的地方预备好了，开工建造耶和华的殿。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 6:1"> 所罗门作王第四年二月初二日开工建造。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 6:2–3; 历代志上 28:11–19"> 所罗门建筑 神殿的根基，乃是这样：长六十肘，宽二十肘，都按着古时的尺寸。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 10:23; 使徒行传 5:12; 使徒行传 3:11"> 殿前的廊子长二十肘，与殿的宽窄一样，高一百二十肘；里面贴上精金。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 6:15–17; 列王纪上 6:21–22"> 大殿的墙都用松木板遮蔽，又贴了精金，上面雕刻棕树和链子；</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 54:11–12; 历代志上 29:8; 启示录 21:18–21"> 又用宝石装饰殿墙，使殿华美；所用的金子都是巴瓦音的金子。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 6:20–22; 出埃及记 26:29; 以西结书 7:20"> 又用金子贴殿和殿的栋梁、门槛、墙壁、门扇；墙上雕刻基路伯。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 26:33; 列王纪上 6:19–20; 列王纪上 6:16"> 又建造至圣所，长二十肘，与殿的宽窄一样，宽也是二十肘；贴上精金，共用金子六百他连得。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 28:11"> 金钉重五十舍客勒。楼房都贴上金子。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="列王纪上 6:23–28; 出埃及记 25:18"> 在至圣所按造像的法子造两个基路伯，用金子包裹。</span>
<span className="v" id="v11" data-v="11"> 两个基路伯的翅膀共长二十肘。这基路伯的一个翅膀长五肘，挨着殿这边的墙；那一个翅膀也长五肘，与那基路伯翅膀相接。</span>
<span className="v" id="v12" data-v="12"> 那基路伯的一个翅膀长五肘，挨着殿那边的墙；那一个翅膀也长五肘，与这基路伯的翅膀相接。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 25:20"> 两个基路伯张开翅膀，共长二十肘，面向外殿而立。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 9:3; 希伯来书 10:20; 马太福音 27:51"> 又用蓝色、紫色、朱红色线和细麻织幔子，在其上绣出基路伯来。</span>

## 两根铜柱

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王纪上 7:15–24; 耶利米书 52:20–23"> 在殿前造了两根柱子，高三十五肘；每柱顶高五肘。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 7:20; 列王纪上 6:21"> 又照圣所内链子的样式做链子，安在柱顶上；又做一百石榴，安在链子上。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 7:21"> 将两根柱子立在殿前，一根在右边，一根在左边；右边的起名叫雅斤，左边的起名叫波阿斯。</span>

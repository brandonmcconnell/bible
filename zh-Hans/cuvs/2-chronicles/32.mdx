## 亚述人恐吓耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 18:13–37; 列王纪下 17:6; 历代志下 20:1–2"> 这虔诚的事以后，亚述王西拿基立来侵入犹大，围困一切坚固城，想要攻破占据。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 9:53; 路加福音 9:51; 列王纪下 12:17"> 希西家见西拿基立来，定意要攻打耶路撒冷，</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 24:6; 箴言 20:18; 箴言 15:22"> 就与首领和勇士商议，塞住城外的泉源；他们就都帮助他。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 32:30; 列王纪下 18:9; 列王纪上 19:21"> 于是有许多人聚集，塞了一切泉源，并通流国中的小河，说：「亚述王来，为何让他得着许多水呢？」</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 25:23; 列王纪上 9:24; 列王纪下 25:4"> 希西家力图自强，就修筑所有拆毁的城墙，高与城楼相齐；在城外又筑一城，坚固大卫城的米罗，制造了许多军器、盾牌；</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 40:2; 历代志下 30:22; 尼希米记 8:16"> 设立军长管理百姓，将他们招聚在城门的宽阔处，用话勉励他们，说：</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 6:16; 罗马书 8:31; 以弗所书 6:10"> 「你们当刚强壮胆，不要因亚述王和跟随他的大军恐惧、惊慌；因为与我们同在的，比与他们同在的更大。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 17:5; 历代志下 20:17; 以赛亚书 41:10"> 与他们同在的是肉臂，与我们同在的是耶和华—我们的 神，他必帮助我们，为我们争战。」百姓就靠犹大王希西家的话，安然无惧了。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王纪下 18:17; 约书亚记 10:31; 以赛亚书 36:2"> 此后，亚述王西拿基立和他的全军攻打拉吉，就差遣臣仆到耶路撒冷见犹大王希西家和一切在耶路撒冷的犹大人，说：</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 18:19; 以赛亚书 36:4"> 「亚述王西拿基立如此说：『你们倚靠什么，还在耶路撒冷受困呢？</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 27:43; 诗篇 11:1–3; 以赛亚书 36:18"> 希西家对你们说「耶和华—我们的 神必救我们脱离亚述王的手」，这不是诱惑你们，使你们受饥渴而死吗？</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 31:1; 申命记 12:13–14; 申命记 12:26–27"> 这希西家岂不是废去耶和华的邱坛和祭坛，吩咐犹大与耶路撒冷的人说「你们当在一个坛前敬拜，在其上烧香」吗？</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 18:33–35; 以赛亚书 44:8–10; 但以理书 4:30"> 我与我列祖向列邦所行的，你们岂不知道吗？列邦的神何尝能救自己的国脱离我手呢？</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 10:11–12; 出埃及记 15:9–11; 以赛亚书 42:8"> 我列祖所灭的国，那些神中谁能救自己的民脱离我手呢？难道你们的神能救你们脱离我手吗？</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 5:2; 但以理书 3:15; 以赛亚书 36:18"> 所以你们不要叫希西家这样欺哄诱惑你们，也不要信他；因为没有一国一邦的神能救自己的民脱离我手和我列祖的手，何况你们的神更不能救你们脱离我的手。』」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="诗篇 73:9; 约翰福音 15:21; 约伯记 15:25–26"> 西拿基立的臣仆还有别的话毁谤耶和华 神和他仆人希西家。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 37:14; 列王纪下 19:12; 以赛亚书 37:28–29"> 西拿基立也写信毁谤耶和华—以色列的 神说：「列邦的神既不能救他的民脱离我手，希西家的神也不能救他的民脱离我手了。」</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 17:10; 列王纪下 18:26–28; 撒母耳记上 17:26"> 亚述王的臣仆用犹大言语向耶路撒冷城上的民大声呼叫，要惊吓他们，扰乱他们，以便取城。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 19:18; 以赛亚书 2:8; 耶利米书 32:30"> 他们论耶路撒冷的 神，如同论世上人手所造的神一样。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="诗篇 91:14–15; 以赛亚书 37:14–20; 历代志下 14:11"> 希西家王和亚摩斯的儿子先知以赛亚因此祷告，向天呼求。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 37:36–38; 诗篇 76:5; 诗篇 18:50"> 耶和华就差遣一个使者进入亚述王营中，把所有大能的勇士和官长、将帅尽都灭了。亚述王满面含羞地回到本国，进了他神的庙中，有他亲生的儿子在那里用刀杀了他。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 31:4–5; 诗篇 18:48–50; 帖撒罗尼迦后书 3:5"> 这样，耶和华救希西家和耶路撒冷的居民脱离亚述王西拿基立的手，也脱离一切仇敌的手，又赐他们四境平安。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 17:5; 马太福音 2:11; 历代志下 1:1"> 有许多人到耶路撒冷，将供物献与耶和华，又将宝物送给犹大王希西家。此后，希西家在列邦人的眼中看为尊大。</span>
</div>
</div>

## 希西家的疾病和骄傲

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 38:1–8; 列王纪下 20:1–11; 以赛亚书 38:21–22"> 那时希西家病得要死，就祷告耶和华，耶和华应允他，赐他一个兆头。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 24:18; 历代志下 26:16; 历代志下 32:31"> 希西家却没有照他所蒙的恩报答耶和华；因他心里骄傲，所以忿怒要临到他和犹大并耶路撒冷。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 26:18–19; 历代志下 34:27–28; 历代志下 33:12"> 但希西家和耶路撒冷的居民觉得心里骄傲，就一同自卑，以致耶和华的忿怒在希西家的日子没有临到他们。</span>
</div>
</div>

## 希西家的财富和尊荣

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="历代志上 27:25–31; 历代志下 1:12; 箴言 10:22"> 希西家大有尊荣资财，建造府库，收藏金银、宝石、香料、盾牌，和各样的宝器，</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 7:8; 历代志下 26:10; 列王纪上 4:26"> 又建造仓房，收藏五谷、新酒，和油，又为各类牲畜盖棚立圈；</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 29:12; 箴言 10:22; 撒母耳记上 2:7"> 并且建立城邑，还有许多的羊群牛群，因为 神赐他极多的财产。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 1:33; 以赛亚书 22:9–11; 诗篇 1:1–3"> 这希西家也塞住基训的上源，引水直下，流在大卫城的西边。希西家所行的事尽都亨通。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 8:2; 箴言 17:3; 创世记 22:1"> 惟有一件事，就是巴比伦王差遣使者来见希西家，访问国中所现的奇事；这件事 神离开他，要试验他，好知道他心内如何。</span>
</div>
</div>

## 希西家逝世

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 36:1–22; 列王纪下 18:1–20; 历代志下 31:20–21"> 希西家其余的事和他的善行都写在亚摩斯的儿子先知以赛亚的默示书上和犹大、以色列的诸王记上。</span>
<span className="v" id="v33" data-v="33" data-xref="箴言 10:7; 列王纪上 1:21; 历代志下 16:14"> 希西家与他列祖同睡，葬在大卫子孙的高陵上。他死的时候，犹大人和耶路撒冷的居民都尊敬他。他儿子玛拿西接续他作王。</span>
</div>
</div>

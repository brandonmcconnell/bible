## 筹备建造圣殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 5:5; 历代志上 22:10; 列王纪上 7:1"> 所罗门定意要为耶和华的名建造殿宇，又为自己的国建造宫室。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 2:18; 列王纪上 5:15–16"> 所罗门就挑选七万扛抬的，八万在山上凿石头的，三千六百督工的。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 14:1; 撒母耳记下 5:11; 列王纪上 5:1–11"> 所罗门差人去见泰尔王希兰，说：「你曾运香柏木与我父大卫建宫居住，求你也这样待我。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 30:7; 出埃及记 25:30; 历代志下 2:1"> 我要为耶和华—我 神的名建造殿宇，分别为圣献给他，在他面前焚烧美香，常摆陈设饼，每早晚、安息日、月朔，并耶和华—我们 神所定的节期献燔祭。这是以色列人永远的定例。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 16:25; 出埃及记 15:11; 诗篇 135:5"> 我所要建造的殿宇甚大；因为我们的 神至大，超乎诸神。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 66:1; 历代志下 6:18; 列王纪上 8:27"> 天和天上的天，尚且不足他居住的，谁能为他建造殿宇呢？我是谁？能为他建造殿宇吗？不过在他面前烧香而已。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 2:13–14; 历代志上 22:15–16; 出埃及记 31:3–5"> 现在求你差一个巧匠来，就是善用金、银、铜、铁，和紫色、朱红色、蓝色线，并精于雕刻之工的巧匠，与我父大卫在犹大和耶路撒冷所预备的巧匠一同做工；</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 5:6; 列王纪上 10:11; 历代志下 9:10–11"> 又求你从黎巴嫩运些香柏木、松木、檀香木到我这里来，因我知道你的仆人善于砍伐黎巴嫩的树木。我的仆人也必与你的仆人同工。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 9:8; 历代志下 2:5; 历代志下 7:21"> 这样，可以给我预备许多的木料，因我要建造的殿宇高大出奇。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 5:11; 以斯拉记 7:22; 罗马书 13:7–8"> 你的仆人砍伐树木，我必给他们打好了的小麦二万歌珥，大麦二万歌珥，酒二万罢特，油二万罢特。」</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪上 10:9; 历代志下 9:8; 诗篇 72:17"> 泰尔王希兰写信回答所罗门说：「耶和华因为爱他的子民，所以立你作他们的王」；</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 33:6; 彼得前书 1:3; 启示录 4:11"> 又说：「创造天地的耶和华—以色列的 神是应当称颂的！他赐给大卫王一个有智慧的儿子，使他有谋略聪明，可以为耶和华建造殿宇，又为自己的国建造宫室。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志下 4:16"> 「现在我打发一个精巧有聪明的人去，他是我父亲希兰所用的，</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 2:7; 出埃及记 31:3–4; 列王纪上 7:13–14"> 是但支派一个妇人的儿子。他父亲是泰尔人，他善用金、银、铜、铁、石、木，和紫色、蓝色、朱红色线与细麻制造各物，并精于雕刻，又能想出各样的巧工。请你派定这人，与你的巧匠和你父—我主大卫的巧匠一同做工。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 2:10; 列王纪上 5:11"> 我主所说的小麦、大麦、酒、油，愿我主运来给众仆人。</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 19:46; 列王纪上 5:8–9; 以斯拉记 3:7"> 我们必照你所需用的，从黎巴嫩砍伐树木，扎成筏子，浮海运到约帕；你可以从那里运到耶路撒冷。」</span>
</div>
</div>

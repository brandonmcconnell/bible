## 希西家的改革

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 18:4; 历代志下 32:12; 创世记 19:15"> 这事既都完毕，在那里的以色列众人就到犹大的城邑，打碎柱像，砍断木偶，又在犹大、便雅悯、以法莲、玛拿西遍地将邱坛和祭坛拆毁净尽。于是以色列众人各回各城，各归各地。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 24:1; 历代志上 16:4–6; 历代志下 29:24–26"> 希西家派定祭司利未人的班次，各按各职献燔祭和平安祭，又在耶和华殿<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是营">a</a></sup>门内事奉，称谢颂赞耶和华。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 45:17; 历代志下 35:7; 歌罗西书 2:16–17"> 王又从自己的产业中定出分来为燔祭，就是早晚的燔祭和安息日、月朔，并节期的燔祭，都是按耶和华律法上所载的；</span>
<span className="v" id="v4" data-v="4" data-xref="玛拉基书 2:7; 民数记 18:8–21; 尼希米记 13:10–13"> 又吩咐住耶路撒冷的百姓将祭司、利未人所应得的分给他们，使他们专心遵守耶和华的律法。</span>
<span className="v" id="v5" data-v="5" data-xref="尼希米记 13:12; 历代志下 24:10–11; 尼希米记 10:35–39"> 谕旨一出，以色列人就把初熟的五谷、新酒、油、蜜，和田地的出产多多送来，又把各物的十分之一送来的极多。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 27:30; 历代志下 11:16–17; 申命记 14:28"> 住犹大各城的以色列人和犹大人也将牛羊的十分之一，并分别为圣归耶和华—他们 神之物，就是十分取一之物，尽都送来，积成堆垒；</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 23:16–24"> 从三月积起，到七月才完。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 1:3; 创世记 14:19–20; 腓立比书 4:10"> 希西家和众首领来，看见堆垒，就称颂耶和华，又为耶和华的民以色列人祝福。</span>
<span className="v" id="v9" data-v="9"> 希西家向祭司、利未人查问这堆垒。</span>
<span className="v" id="v10" data-v="10" data-xref="玛拉基书 3:10; 历代志上 6:8; 哥林多后书 9:8–11"> 撒督家的大祭司亚撒利雅回答说：「自从民将供物送到耶和华殿以来，我们不但吃饱，且剩下的甚多；因为耶和华赐福给他的民，所剩下的才这样丰盛。」</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 10:38–39; 尼希米记 13:5; 尼希米记 13:12–13"> 希西家吩咐在耶和华殿里预备仓房，他们就预备了。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 35:9; 列王纪下 12:15; 历代志上 26:20–26"> 他们诚心将供物和十分取一之物，并分别为圣之物，都搬入仓内。利未人歌楠雅掌管这事，他兄弟示每为副管。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 24:5; 历代志下 31:10–11; 历代志上 9:11"> 耶歇、亚撒细雅、拿哈、亚撒黑、耶利末、约撒拔、以列、伊斯玛基雅、玛哈、比拿雅都是督理，在歌楠雅和他兄弟示每的手下，是希西家王和管理 神殿的亚撒利雅所派的。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 23:38; 历代志上 26:12; 利未记 27:28"> 守东门的利未人音拿的儿子可利，掌管乐意献与 神的礼物，发放献与耶和华的供物和至圣的物。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 21:9–19; 历代志上 9:22; 历代志下 29:12"> 在他手下有伊甸、珉雅珉、耶书亚、示玛雅、亚玛利雅、示迦尼雅，在祭司的各城里供紧要的职任，无论弟兄大小，都按着班次分给他们。</span>
<span className="v" id="v16" data-v="16" data-xref="以斯拉记 3:4; 利未记 21:22–23; 历代志上 23:3"> 按家谱，三岁以外的男丁，凡每日进耶和华殿、按班次供职的，也分给他；</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 23:24; 历代志上 23:27; 民数记 3:15"> 又按宗族家谱分给祭司，按班次职任分给二十岁以外的利未人，</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 15:16; 以赛亚书 5:16; 历代志下 31:15"> 又按家谱计算，分给他们会中的妻子、儿女；因他们身供要职，自洁成圣。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 31:12–15; 利未记 25:34; 民数记 35:2–5"> 按名派定的人要把应得的分给亚伦子孙，住在各城郊野、祭司所有的男丁和一切载入家谱的利未人。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 20:3; 列王纪下 22:2; 使徒行传 24:16"> 希西家在犹大遍地这样办理，行耶和华—他 神眼中看为善为正为忠的事。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 6:33; 耶利米书 29:13; 约书亚记 1:7–8"> 凡他所行的，无论是办 神殿的事，是遵律法守诫命，是寻求他的 神，都是尽心去行，无不亨通。</span>

## 示巴女王访问所罗门

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 12:42; 路加福音 11:31; 列王纪上 10:1–13"> 示巴女王听见所罗门的名声，就来到耶路撒冷，要用难解的话试问所罗门；跟随她的人甚多，又有骆驼驮着香料、宝石，和许多金子。她来见了所罗门，就把心里所有的对所罗门都说出来。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 15:15; 列王纪上 3:12; 马可福音 4:34"> 所罗门将她所问的都答上了，没有一句不明白、不能答的。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 3:1–4; 列王纪上 10:3; 列王纪上 6:1–7"> 示巴女王见所罗门的智慧和他所建造的宫室、</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 12:37; 列王纪上 4:22–23; 诗篇 143:7"> 席上的珍馐美味、群臣分列而坐、仆人两旁侍立，以及他们的衣服装饰、酒政，和酒政的衣服装饰，又见他上耶和华殿的台阶，就诧异得神不守舍，</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 10:6"> 对王说：「我在本国里所听见论到你的事和你的智慧实在是真的！</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 10:7; 历代志下 9:5; 列王纪上 4:34"> 我先不信那些话，及至我来亲眼见了，才知道你的大智慧；人所告诉我的，还不到一半；你的实迹越过我所听见的名声。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 27:4; 箴言 3:14; 箴言 10:21"> 你的群臣、你的仆人常侍立在你面前听你智慧的话是有福的。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 2:11; 历代志上 29:23; 以赛亚书 32:1–2"> 耶和华—你的 神是应当称颂的！他喜悦你，使你坐他的国位，为耶和华—你的 神作王；因为你的 神爱以色列人，要永远坚立他们，所以立你作他们的王，使你秉公行义。」</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 9:1; 诗篇 72:10; 诗篇 72:15"> 于是示巴女王将一百二十他连得金子和宝石，与极多的香料送给所罗门王；她送给王的香料，以后再没有这样的。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志下 8:18; 列王纪上 10:11; 列王纪上 10:22"> 希兰的仆人和所罗门的仆人从俄斐运了金子来，也运了檀香木<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：乌木；下同">a</a></sup>和宝石来。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 10:12; 历代志上 23:5; 诗篇 92:1–3"> 王用檀香木为耶和华殿和王宫做台，又为歌唱的人做琴瑟；犹大地从来没有见过这样的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王纪上 10:13; 以弗所书 3:20; 诗篇 20:4"> 所罗门王按示巴女王所带来的，还她礼物，另外照她一切所要所求的，都送给她。于是女王和她臣仆转回本国去了。</span>
</div>
</div>

## 所罗门王的财富

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="诗篇 72:15; 诗篇 68:29; 列王纪上 10:14–28"> 所罗门每年所得的金子共有六百六十六他连得，</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 68:29; 诗篇 72:10"> 另外还有商人所进的金子，并且阿拉伯诸王与属国的省长都带金银给所罗门。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 10:16–17; 历代志下 12:9–10"> 所罗门王用锤出来的金子打成挡牌二百面，每面用金子六百舍客勒；</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 7:2"> 又用锤出来的金子打成盾牌三百面，每面用金子三百舍客勒，都放在黎巴嫩林宫里。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 10:18–20; 诗篇 45:8; 启示录 20:11"> 王用象牙制造一个大宝座，用精金包裹。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 24:9; 启示录 5:5; 民数记 23:24"> 宝座有六层台阶，又有金脚凳，与宝座相连。宝座两旁有扶手，靠近扶手有两个狮子站立。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 19:28; 启示录 21:12"> 六层台阶上有十二个狮子站立，每层有两个：左边一个，右边一个；在列国中没有这样做的。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 10:21; 以斯帖记 1:7; 历代志下 9:27"> 所罗门王一切的饮器都是金的，黎巴嫩林宫里的一切器皿都是精金的。所罗门年间，银子算不了什么。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 22:48; 约伯记 39:13; 列王纪上 10:22"> 因为王的船只与希兰的仆人一同往他施去；他施船只三年一次装载金、银、象牙、猿猴、孔雀回来。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="历代志下 1:12; 诗篇 89:27; 列王纪上 4:30–31"> 所罗门王的财宝与智慧胜过天下的列王。</span>
<span className="v" id="v23" data-v="23" data-xref="雅各书 1:5; 雅各书 3:17; 箴言 2:6"> 普天下的王都求见所罗门，要听 神赐给他智慧的话。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 10:25; 约伯记 42:11; 诗篇 72:10"> 他们各带贡物，就是金器、银器、衣服、军械、香料、骡马，每年有一定之例。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 4:26; 列王纪上 10:26; 历代志下 1:14"> 所罗门有套车的马四千棚，有马兵一万二千，安置在屯车的城邑和耶路撒冷，就是王那里。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 4:21; 创世记 15:18; 列王纪上 4:24"> 所罗门统管诸王，从大河到非利士地，直到埃及的边界。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 1:15–17; 以赛亚书 9:10; 列王纪上 10:27–29"> 王在耶路撒冷使银子多如石头，香柏木多如高原的桑树。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 1:16; 列王纪上 10:28; 以赛亚书 31:1"> 有人从埃及和各国为所罗门赶马群来。</span>
</div>
</div>

## 所罗门政绩简述

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="历代志上 29:29; 列王纪上 11:41–43; 列王纪上 11:29"> 所罗门其余的事，自始至终，不都写在先知拿单的书上和示罗人亚希雅的预言书上，并先见易多论尼八儿子耶罗波安的默示书上吗？</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 11:42–43"> 所罗门在耶路撒冷作以色列众人的王共四十年。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪上 2:10; 撒母耳记下 7:12; 列王纪上 1:21"> 所罗门与他列祖同睡，葬在他父大卫城里。他儿子罗波安接续他作王。</span>
</div>

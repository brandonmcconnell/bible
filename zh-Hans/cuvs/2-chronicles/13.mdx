## 亚比雅与耶罗波安争战

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 12:16; 列王纪上 15:1–8"> 耶罗波安王十八年，亚比雅登基作犹大王，</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 11:20; 列王纪上 15:6–7; 士师记 19:16"> 在耶路撒冷作王三年。他母亲名叫米该亚<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="又作玛迦">a</a></sup>，是基比亚人乌列的女儿。<br />亚比雅常与耶罗波安争战。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 26:12–13; 历代志上 21:5; 撒母耳记上 17:1–3"> 有一次亚比雅率领挑选的兵四十万摆阵，都是勇敢的战士；耶罗波安也挑选大能的勇士八十万，对亚比雅摆阵。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约书亚记 18:22; 历代志下 15:2; 创世记 10:18"> 亚比雅站在以法莲山地中的洗玛脸山上，说：「耶罗波安和以色列众人哪，要听我说！</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 18:19; 利未记 2:13; 马可福音 9:49–50"> 耶和华—以色列的 神曾立盐约<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="盐就是不废坏的意思">b</a></sup>，将以色列国永远赐给大卫和他的子孙，你们不知道吗？</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 11:26; 列王纪上 12:20; 历代志下 10:19"> 无奈大卫儿子所罗门的臣仆、尼八儿子耶罗波安起来背叛他的主人。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 9:4; 历代志下 12:13; 使徒行传 17:5"> 有些无赖的匪徒聚集跟从他，逞强攻击所罗门的儿子罗波安；那时罗波安还幼弱，不能抵挡他们。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪上 12:28; 历代志下 11:15; 路加福音 19:14"> 「现在你们有意抗拒大卫子孙手下所治耶和华的国，你们的人也甚多，你们那里又有耶罗波安为你们所造当作神的金牛犊。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 11:14–15; 耶利米书 2:11; 出埃及记 29:35"> 你们不是驱逐耶和华的祭司亚伦的后裔和利未人吗？不是照着外邦人的恶俗为自己立祭司吗？无论何人牵一只公牛犊、七只公绵羊将自己分别出来，就可作虚无之神的祭司。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 19:5–6; 历代志下 11:16–17; 撒迦利亚书 13:9"> 至于我们，耶和华是我们的 神，我们并没有离弃他。我们有事奉耶和华的祭司，都是亚伦的后裔，并有利未人各尽其职，</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 2:4; 利未记 24:2–9; 出埃及记 29:38"> 每日早晚向耶和华献燔祭，烧美香，又在精金的桌子上摆陈设饼；又有金灯台和灯盏，每晚点起，因为我们遵守耶和华—我们 神的命；惟有你们离弃了他。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 5:39; 罗马书 8:31; 民数记 10:8–9"> 率领我们的是 神，我们这里也有 神的祭司拿号向你们吹出大声。以色列人哪，不要与耶和华—你们列祖的 神争战，因你们必不能亨通。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约书亚记 8:4; 约书亚记 8:9; 箴言 21:30"> 耶罗波安却在犹大人的后头设伏兵。这样，以色列人在犹大人的前头，伏兵在犹大人的后头。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 14:11; 出埃及记 14:10; 约书亚记 8:20"> 犹大人回头观看，见前后都有敌兵，就呼求耶和华，祭司也吹号。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 14:12; 约书亚记 11:8; 诗篇 118:4–7"> 于是犹大人呐喊；犹大人呐喊的时候， 神就使耶罗波安和以色列众人败在亚比雅与犹大人面前。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 16:8; 士师记 11:21; 约书亚记 10:12"> 以色列人在犹大人面前逃跑， 神将他们交在犹大人手里。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 28:6; 历代志下 13:3; 历代志下 13:12"> 亚比雅和他的军兵大大杀戮以色列人，以色列人仆倒死亡的精兵有五十万。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 5:20; 历代志下 14:11; 那鸿书 1:7"> 那时，以色列人被制伏了，犹大人得胜，是因倚靠耶和华—他们列祖的 神。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 15:8; 约书亚记 15:9; 约书亚记 10:39"> 亚比雅追赶耶罗波安，攻取了他的几座城，就是伯特利和属伯特利的镇市，耶沙拿和属耶沙拿的镇市，以法拉音<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或译：以弗伦">c</a></sup>和属以法拉音的镇市。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 25:38; 列王纪上 14:20; 使徒行传 12:23"> 亚比雅在世的时候，耶罗波安不能再强盛；耶和华攻击他，他就死了。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 9:5; 撒母耳记下 5:12–13; 士师记 10:4"> 亚比雅却渐渐强盛，娶妻妾十四个，生了二十二个儿子，十六个女儿。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 9:29; 历代志下 12:15; 历代志下 24:27"> 亚比雅其余的事和他的言行都写在先知易多的传上。</span>
</div>

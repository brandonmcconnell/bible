## 圣殿奉献礼

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 18:38; 历代志上 21:26; 利未记 9:23–24"> 所罗门祈祷已毕，就有火从天上降下来，烧尽燔祭和别的祭。耶和华的荣光充满了殿；</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 15:8; 历代志下 5:14; 出埃及记 24:17"> 因耶和华的荣光充满了耶和华殿，所以祭司不能进殿。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 5:13; 历代志下 20:21; 路加福音 1:50"> 那火降下、耶和华的荣光在殿上的时候，以色列众人看见，就在铺石地俯伏叩拜，称谢耶和华说：<br /><span className="pl pl-1">耶和华本为善，</span><br /><span className="pl pl-1">他的慈爱永远长存！</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪上 8:62–63"> 王和众民在耶和华面前献祭。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 10:22; 以西结书 45:17; 历代志下 30:24"> 所罗门王用牛二万二千，羊十二万献祭。这样，王和众民为 神的殿行奉献之礼。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 5:12; 历代志上 15:16–21; 历代志下 7:3"> 祭司侍立，各供其职；利未人也拿着耶和华的乐器，就是大卫王造出来、借利未人颂赞耶和华的。（他的慈爱永远长存！）祭司在众人面前吹号，以色列人都站立。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王纪上 8:64–66; 希伯来书 13:10–12; 历代志下 36:14"> 所罗门因他所造的铜坛容不下燔祭、素祭，和脂油，便将耶和华殿前院子当中分别为圣，在那里献燔祭和平安祭牲的脂油。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="创世记 15:18; 列王纪上 8:65; 尼希米记 8:13–18"> 那时所罗门和以色列众人，就是从哈马口直到埃及小河，所有的以色列人都聚集成为大会，守节七日。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 23:36; 列王纪上 8:65; 约珥书 1:14"> 第八日设立严肃会，行奉献坛的礼七日，守节七日。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 8:66; 诗篇 100:2; 申命记 12:18"> 七月二十三日，王遣散众民；他们因见耶和华向大卫和所罗门与他民以色列所施的恩惠，就都心中喜乐，各归各家去了。</span>
</div>
</div>

## 神再次向所罗门显现

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪上 9:1–9; 传道书 2:10–11; 历代志下 2:1"> 所罗门造成了耶和华殿和王宫；在耶和华殿和王宫凡他心中所要做的，都顺顺利利地做成了。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 17:1; 列王纪上 9:2; 历代志下 7:16"> 夜间耶和华向所罗门显现，对他说：「我已听了你的祷告，也选择这地方作为祭祀我的殿宇。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 6:26–28; 申命记 11:17; 启示录 11:6"> 我若使天闭塞不下雨，或使蝗虫吃这地的出产，或使瘟疫流行在我民中，</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米哀歌 3:40–41; 雅各书 4:9–10; 以赛亚书 55:6–7"> 这称为我名下的子民，若是自卑、祷告，寻求我的面，转离他们的恶行，我必从天上垂听，赦免他们的罪，医治他们的地。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 3:12; 历代志下 6:40; 尼希米记 1:6"> 我必睁眼看、侧耳听在此处所献的祷告。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 7:15; 历代志下 7:12; 历代志下 6:5–6"> 现在我已选择这殿，分别为圣，使我的名永在其中，我的眼、我的心也必常在那里。</span>
<span className="v" id="v17" data-v="17" data-xref="撒迦利亚书 3:7; 以西结书 36:27; 列王纪上 11:38"> 你若在我面前效法你父大卫所行的，遵行我一切所吩咐你的，谨守我的律例典章，</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 6:16; 耶利米书 33:20–21; 撒母耳记下 7:13–16"> 我就必坚固你的国位，正如我与你父大卫所立的约，说：『你的子孙必不断人作以色列的王。』</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="利未记 26:14; 申命记 28:15; 利未记 26:33–46"> 「倘若你们转去丢弃我指示你们的律例诫命，去事奉敬拜别神，</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 17:20; 申命记 28:37; 耶利米书 24:9"> 我就必将以色列人从我赐给他们的地上拔出根来，并且我为己名所分别为圣的殿也必舍弃不顾，使他在万民中作笑谈，被讥诮。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 22:8–9; 耶利米书 16:10–12; 耶利米书 19:8"> 这殿虽然甚高，将来经过的人必惊讶说：『耶和华为何向这地和这殿如此行呢？』</span>
<span className="v" id="v22" data-v="22" data-xref="但以理书 9:12; 耶利米哀歌 2:16–17; 以西结书 14:23"> 人必回答说：『是因此地的人离弃耶和华—他们列祖的 神，就是领他们出埃及地的 神，去亲近别神，敬拜事奉他，所以耶和华使这一切灾祸临到他们。』」</span>
</div>
</div>

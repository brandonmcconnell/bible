## 犹大王玛拿西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 21:1–18; 历代志上 3:13; 以赛亚书 3:12"> 玛拿西登基的时候年十二岁，在耶路撒冷作王五十五年。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 28:3; 申命记 18:9; 列王纪下 17:11"> 他行耶和华眼中看为恶的事，效法耶和华在以色列人面前赶出的外邦人那可憎的事，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 16:21; 申命记 17:3; 历代志下 31:1"> 重新建筑他父希西家所拆毁的邱坛，又为巴力筑坛，做木偶，且敬拜事奉天上的万象，</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 7:16; 列王纪上 8:29; 申命记 12:11"> 在耶和华的殿宇中筑坛—耶和华曾指着这殿说：「我的名必永远在耶路撒冷。」</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 4:9; 耶利米书 32:34–35; 以西结书 8:7–18"> 他在耶和华殿的两院中为天上的万象筑坛，</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 18:21; 利未记 20:6; 历代志下 28:3"> 并在欣嫩子谷使他的儿女经火，又观兆，用法术，行邪术，立交鬼的和行巫术的，多行耶和华眼中看为恶的事，惹动他的怒气，</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 33:4; 历代志下 7:16; 列王纪上 11:13"> 又在 神殿内立雕刻的偶像。 神曾对大卫和他儿子所罗门说：「我在以色列各支派中所选择的耶路撒冷和这殿，必立我的名直到永远。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 7:10; 申命记 5:31–1; 利未记 8:36"> 以色列人若谨守遵行我借摩西所吩咐他们的一切法度、律例、典章，我就不再使他们挪移离开我所赐给他们列祖之地。」</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 24:3–4; 箴言 29:12; 历代志下 33:2"> 玛拿西引诱犹大和耶路撒冷的居民，以致他们行恶比耶和华在以色列人面前所灭的列国更甚。</span>
</div>
</div>

## 玛拿西悔改

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志下 36:15–16; 耶利米书 44:4–5; 撒迦利亚书 1:4"> 耶和华警戒玛拿西和他的百姓，他们却是不听。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 28:36; 历代志下 36:6; 尼希米记 9:32"> 所以耶和华使亚述王的将帅来攻击他们，用铙钩钩住玛拿西，用铜链锁住他，带到巴比伦去。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 10:3; 诗篇 50:15; 历代志下 32:26"> 他在急难的时候，就恳求耶和华—他的 神，且在他列祖的 神面前极其自卑。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 5:20; 但以理书 4:25; 马太福音 7:7–8"> 他祈祷耶和华，耶和华就允准他的祈求，垂听他的祷告，使他归回耶路撒冷，仍坐国位。玛拿西这才知道惟独耶和华是 神。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 27:3; 列王纪上 1:33; 尼希米记 3:3"> 此后，玛拿西在大卫城外，从谷内基训西边直到鱼门口，建筑城墙，环绕俄斐勒，这墙筑得甚高；又在犹大各坚固城内设立勇敢的军长；</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 33:3–7; 何西阿书 14:1–3; 列王纪下 21:7"> 并除掉外邦人的神像与耶和华殿中的偶像，又将他在耶和华殿的山上和耶路撒冷所筑的各坛都拆毁抛在城外；</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 14:4; 列王纪上 18:30; 历代志下 33:9"> 重修耶和华的祭坛，在坛上献平安祭、感谢祭，吩咐犹大人事奉耶和华—以色列的 神。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 32:12; 列王纪上 22:43; 列王纪下 15:4"> 百姓却仍在邱坛上献祭，只献给耶和华—他们的 神。</span>
</div>
</div>

## 玛拿西逝世

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="历代志下 33:19; 历代志下 33:12–13; 阿摩司书 7:12"> 玛拿西其余的事和祷告他 神的话，并先见奉耶和华—以色列 神的名警戒他的言语，都写在以色列诸王记上。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 9:11; 约翰一书 1:9; 但以理书 5:22"> 他的祷告，与 神怎样应允他，他未自卑以前的罪愆过犯，并在何处建筑邱坛，设立亚舍拉和雕刻的偶像，都写在何赛的书上。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 1:10; 历代志下 32:33; 列王纪下 21:18–25"> 玛拿西与他列祖同睡，葬在自己的宫院里。他儿子亚们接续他作王。</span>
</div>
</div>

## 犹大王亚们

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="雅各书 4:13–15; 路加福音 12:19–20; 历代志下 33:1"> 亚们登基的时候年二十二岁，在耶路撒冷作王二年。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 21:20; 以西结书 20:18; 列王纪下 21:1–11"> 他行耶和华眼中看为恶的事，效法他父玛拿西所行的，祭祀事奉他父玛拿西所雕刻的偶像，</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 33:12; 历代志下 33:19; 耶利米书 7:26"> 不在耶和华面前像他父玛拿西自卑。这亚们所犯的罪越犯越大。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 11:22; 历代志下 25:27–28; 历代志下 24:25–26"> 他的臣仆背叛，在宫里杀了他。</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 35:31; 历代志下 34:1; 历代志下 36:1"> 但国民杀了那些背叛亚们王的人，立他儿子约西亚接续他作王。</span>
</div>
</div>

## 所罗门的成就

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 9:10–28"> 所罗门建造耶和华殿和王宫，二十年才完毕了。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 9:11–18"> 以后所罗门重新修筑希兰送给他的那些城邑，使以色列人住在那里。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 13:21; 历代志上 18:3; 撒母耳记下 8:3"> 所罗门往哈马琐巴去，攻取了那地方。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 9:17–19"> 所罗门建造旷野里的达莫，又建造哈马所有的积货城，</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 7:24; 约书亚记 16:5; 历代志下 14:7"> 又建造上伯·和 、下伯·和 作为保障，都有墙，有门，有闩；</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 7:2; 历代志下 8:4; 历代志下 1:14"> 又建造巴拉和所有的积货城，并屯车辆马兵的城，与耶路撒冷、黎巴嫩，以及自己治理的全国中所愿意建造的。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 15:18–21; 申命记 7:1; 列王纪上 9:20–22"> 至于国中所剩下不属以色列人的赫人、亚摩利人、比利洗人、希未人、耶布斯人，</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 16:10; 列王纪上 9:21; 列王纪上 4:6"> 就是以色列人未曾灭绝的，所罗门挑取他们的后裔作服苦的奴仆，直到今日。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 8:11–12; 出埃及记 19:5–6; 加拉太书 4:31"> 惟有以色列人，所罗门不使他们当奴仆做工，乃是作他的战士、军长的统领、车兵长、马兵长。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 9:23; 列王纪上 5:16; 历代志下 2:18"> 所罗门王有二百五十督工的，监管工人。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 3:1; 列王纪上 7:8; 列王纪上 9:24"> 所罗门将法老的女儿带出大卫城，上到为她建造的宫里；因所罗门说：「耶和华约柜所到之处都为圣地，所以我的妻不可住在以色列王大卫的宫里。」</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 4:1; 历代志下 15:8; 约翰福音 10:23"> 所罗门在耶和华的坛上，就是在廊子前他所筑的坛上，与耶和华献燔祭；</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 16:16; 出埃及记 29:38–42; 以西结书 46:3–15"> 又遵着摩西的吩咐在安息日、月朔，并一年三节，就是除酵节、七七节、住棚节，献每日所当献的祭。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志上 9:17; 以斯拉记 6:18; 尼希米记 12:36"> 所罗门照着他父大卫所定的例，派定祭司的班次，使他们各供己事，又使利未人各尽其职，赞美耶和华，在祭司面前做每日所当做的；又派守门的按着班次看守各门，因为神人大卫是这样吩咐的。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 30:12; 历代志上 9:29; 列王纪上 7:51"> 王所吩咐众祭司和利未人的，无论是管府库或办别的事，他们都不违背。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 5:18; 列王纪上 6:7"> 所罗门建造耶和华的殿，从立根基直到成功的日子，工料俱备。这样，耶和华的殿全然完毕。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 14:22; 申命记 2:8; 民数记 33:35"> 那时，所罗门往以东地靠海的以旬·迦别和以禄去。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 9:10; 历代志下 9:13; 传道书 2:8"> 希兰差遣他的臣仆，将船只和熟悉泛海的仆人送到所罗门那里。他们同着所罗门的仆人到了俄斐，得了四百五十他连得金子，运到所罗门王那里。</span>

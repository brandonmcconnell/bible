## 先知米该雅警告亚哈王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 17:5; 历代志下 21:6; 历代志下 19:2"> 约沙法大有尊荣资财，就与亚哈结亲。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 9:1; 历代志下 19:2; 列王纪上 1:9"> 过了几年，他下到撒马利亚去见亚哈；亚哈为他和跟从他的人宰了许多牛羊，劝他与自己同去攻取基列的拉末。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 22:4; 列王纪下 3:7; 约翰二书 1:10–11"> 以色列王亚哈问犹大王约沙法说：「你肯同我去攻取基列的拉末吗？」他回答说：「你我不分彼此，我的民与你的民一样，必与你同去争战。」</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 21:2; 撒母耳记下 5:19; 撒母耳记下 2:1"> 约沙法对以色列王说：「请你先求问耶和华。」</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太后书 4:3; 弥迦书 3:11; 耶利米书 28:1–17"> 于是以色列王招聚先知四百人，问他们说：「我们上去攻取基列的拉末可以不可以？」他们说：「可以上去，因为 神必将那城交在王的手里。」</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 22:7–9; 列王纪下 3:11–13"> 约沙法说：「这里不是还有耶和华的先知，我们可以求问他吗？」</span>
<span className="v" id="v7" data-v="7" data-xref="阿摩司书 5:10; 弥迦书 2:7; 列王纪上 21:20"> 以色列王对约沙法说：「还有一个人，是音拉的儿子米该雅。我们可以托他求问耶和华，只是我恨他；因为他指着我所说的预言，不说吉语，常说凶言。」约沙法说：「王不必这样说。」</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 22:9; 以赛亚书 39:7; 历代志下 18:25–26"> 以色列王就召了一个太监来，说：「你快去将音拉的儿子米该雅召来。」</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 14:9; 但以理书 7:9; 马太福音 19:28"> 以色列王和犹大王约沙法在撒马利亚城门前的空场上，各穿朝服坐在位上，所有的先知都在他们面前说预言。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 23:17; 撒迦利亚书 1:18–21; 耶利米书 28:2–3"> 基拿拿的儿子西底家造了两个铁角，说：「耶和华如此说：『你要用这角抵触亚兰人，直到将他们灭尽。』」</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 24:24–25; 历代志下 18:33–34; 犹大书 1:16"> 所有的先知也都这样预言说：「可以上基列的拉末去，必然得胜，因为耶和华必将那城交在王的手中。」</span>
<span className="v" id="v12" data-v="12" data-xref="弥迦书 2:6; 诗篇 10:11; 弥迦书 2:11"> 那去召米该雅的使者对米该雅说：「众先知一口同音地都向王说吉言，你不如与他们说一样的话，也说吉言。」</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 22:35; 民数记 24:13; 民数记 22:18–20"> 米该雅说：「我指着永生的耶和华起誓，我的 神说什么，我就说什么。」</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 22:15; 耶利米哀歌 4:21; 阿摩司书 4:4–5"> 米该雅到王面前，王问他说：「米该雅啊，我们上去攻取基列的拉末可以不可以？」他说：「可以上去，必然得胜，敌人必交在你们手里。」</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 26:63; 撒母耳记上 14:24; 列王纪上 22:16"> 王对他说：「我当嘱咐你几次，你才奉耶和华的名向我说实话呢？」</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 9:36; 以西结书 34:5–6; 民数记 27:17"> 米该雅说：「我看见以色列众民散在山上，如同没有牧人的羊群一般。耶和华说：『这民没有主人，他们可以平平安安地各归各家去。』」</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 18:7; 列王纪上 22:18; 箴言 29:1"> 以色列王对约沙法说：「我岂没有告诉你，这人指着我所说的预言，不说吉语，单说凶言吗？」</span>
<span className="v" id="v18" data-v="18" data-xref="但以理书 7:9; 以赛亚书 6:1–5; 列王纪上 22:19–23"> 米该雅说：「你们要听耶和华的话。我看见耶和华坐在宝座上，天上的万军侍立在他左右。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 14:9; 历代志下 25:19; 箴言 11:5"> 耶和华说：『谁去引诱以色列王亚哈上基列的拉末去阵亡呢？』这个就这样说，那个就那样说。</span>
<span className="v" id="v20" data-v="20" data-xref="约伯记 1:6; 哥林多后书 11:13–15; 哥林多后书 11:3"> 随后，有一个神灵出来，站在耶和华面前说：『我去引诱他。』耶和华问他说：『你用何法呢？』</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 8:44; 列王纪上 22:21–22; 约翰一书 4:6"> 他说：『我去，要在他众先知口中作谎言的灵。』耶和华说：『这样，你必能引诱他，你去如此行吧！』</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 19:14; 以西结书 14:9; 约伯记 12:16"> 现在耶和华使谎言的灵入了你这些先知的口，并且耶和华已经命定降祸与你。」</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 14:65; 耶利米书 20:2; 历代志下 18:10"> 基拿拿的儿子西底家前来打米该雅的脸，说：「耶和华的灵从哪里离开我与你说话呢？」</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 29:21–22; 以赛亚书 26:20; 耶利米书 28:16–17"> 米该雅说：「你进严密的屋子藏躲的那日，就必看见了。」</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 18:8; 历代志下 34:8; 耶利米书 38:6–7"> 以色列王说：「将米该雅带回，交给邑宰亚们和王的儿子约阿施，说：</span>
<span className="v" id="v26" data-v="26" data-xref="历代志下 16:10; 诗篇 80:5; 路加福音 23:2"> 『王如此说：把这个人下在监里，使他受苦，吃不饱喝不足，等候我平平安安地回来。』」</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 20:45–46; 阿摩司书 9:10; 弥迦书 1:2"> 米该雅说：「你若能平安回来，那就是耶和华没有借我说这话了」；又说：「众民哪，你们都要听！」</span>
</div>

## 亚哈阵亡

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王纪上 22:29–33"> 以色列王和犹大王约沙法上基列的拉末去了。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记上 28:8; 耶利米书 23:24; 箴言 26:25"> 以色列王对约沙法说：「我要改装上阵，你可以仍穿王服。」于是以色列王改装，他们就上阵去了。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 19:11; 申命记 1:17; 列王纪上 20:42"> 先是亚兰王吩咐车兵长说：「他们的兵将，无论大小，你们都不可与他们争战，只要与以色列王争战。」</span>
<span className="v" id="v31" data-v="31" data-xref="历代志下 13:14; 诗篇 118:13; 哥林多后书 1:9–10"> 车兵长看见约沙法便说，这必是以色列王，就转过去与他争战。约沙法一呼喊，耶和华就帮助他， 神又感动他们离开他。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 22:33"> 车兵长见不是以色列王，就转去不追他了。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志下 35:23; 撒母耳记下 15:11; 列王纪上 22:34–35"> 有一人随便开弓，恰巧射入以色列王的甲缝里。王对赶车的说：「我受了重伤，你转过车来，拉我出阵吧！」</span>
<span className="v" id="v34" data-v="34" data-xref="箴言 13:21; 历代志下 18:27; 箴言 28:17"> 那日阵势越战越猛，以色列王勉强站在车上抵挡亚兰人，直到晚上。约在日落的时候，王就死了。</span>

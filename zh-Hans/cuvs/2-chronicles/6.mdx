## 所罗门向人民宣告

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 18:8–11; 利未记 16:2; 出埃及记 20:21"> 那时，所罗门说：<br /><span className="pl pl-1">耶和华曾说他必住在幽暗之处。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 2:4–6; 诗篇 135:21; 历代志上 28:6"> <span className="pl pl-1">但我已经建造殿宇作你的居所，</span><br /><span className="pl pl-1">为你永远的住处。</span></span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 8:14; 历代志下 29:29; 列王纪上 8:55–61"> 王转脸为以色列会众祝福，以色列会众就都站立。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 72:18–19; 马太福音 24:35; 诗篇 68:32–35"> 所罗门说：「耶和华—以色列的 神是应当称颂的！因他亲口向我父大卫所应许的，也亲手成就了。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 20:24; 列王纪上 8:16; 撒母耳记上 13:13–14"> 他说：『自从我领我民出埃及地以来，我未曾在以色列众支派中选择一城建造殿宇为我名的居所，也未曾拣选一人作我民以色列的君；</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 28:4; 诗篇 132:13; 历代志下 12:13"> 但选择耶路撒冷为我名的居所，又拣选大卫治理我民以色列。』」</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 17:1; 列王纪上 5:3; 历代志上 22:7"> 所罗门说：「我父大卫曾立意要为耶和华—以色列 神的名建殿，</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 8:12; 马可福音 14:8; 列王纪上 8:18–21"> 耶和华却对我父大卫说：『你立意要为我的名建殿，这意思甚好；</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 7:12–13; 历代志上 17:4; 历代志上 17:11–12"> 只是你不可建殿，惟你所生的儿子必为我名建殿。』</span>
<span className="v" id="v10" data-v="10" data-xref="传道书 1:4; 历代志上 28:5; 历代志上 17:11"> 「现在耶和华成就了他所应许的话，使我接续我父大卫坐以色列的国位，是照耶和华所说的，又为耶和华—以色列 神的名建造了殿。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 5:10; 历代志下 5:7; 列王纪上 8:21"> 我将约柜安置在其中，柜内有耶和华的约，就是他与以色列人所立的约。」</span>
</div>
</div>

## 所罗门的祷告

<div className="bt">
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="诗篇 63:4; 以赛亚书 50:10; 约伯记 11:13"> 所罗门当着以色列会众，站在耶和华的坛前，举起手来，</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 8:54; 尼希米记 8:4; 诗篇 95:6"> （所罗门曾造一个铜台，长五肘，宽五肘，高三肘，放在院中）就站在台上，当着以色列的会众跪下，向天举手，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 15:11; 申命记 7:9; 尼希米记 1:5"> 说：「耶和华—以色列的 神啊，天上地下没有神可比你的！你向那尽心行在你面前的仆人守约施慈爱；</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 22:9–10; 撒母耳记下 7:12; 列王纪上 8:24"> 向你仆人—我父大卫所应许的话现在应验了。你亲口应许，亲手成就，正如今日一样。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 2:4; 约翰福音 15:14–15; 历代志下 7:18"> 耶和华—以色列的 神啊，你所应许你仆人—我父大卫的话说：『你的子孙若谨慎自己的行为，遵守我的律法，像你在我面前所行的一样，就不断人坐以色列的国位。』现在求你应验这话。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 11:5; 以赛亚书 41:17; 历代志下 6:4"> 耶和华—以色列的 神啊，求你成就向你仆人大卫所应许的话。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 2:6; 以赛亚书 66:1; 诗篇 139:7–10"> 「 神果真与世人同住在地上吗？看哪，天和天上的天尚且不足你居住的，何况我所建的这殿呢？</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 8:28; 路加福音 18:1–7; 约翰福音 17:20"> 惟求耶和华—我的 神垂顾仆人的祷告祈求，俯听仆人在你面前的祈祷呼吁。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 34:15; 但以理书 6:10; 诗篇 121:5"> 愿你昼夜看顾这殿，就是你应许立为你名的居所；求你垂听仆人向此处祷告的话。</span>
<span className="v" id="v21" data-v="21" data-xref="弥迦书 7:18; 但以理书 9:19; 以赛亚书 43:25"> 你仆人和你民以色列向此处祈祷的时候，求你从天上你的居所垂听，垂听而赦免。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 22:11; 利未记 5:1; 民数记 5:19–22"> 「人若得罪邻舍，有人叫他起誓，他来到这殿，在你的坛前起誓，</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 3:10–11; 箴言 17:15; 耶利米书 51:56"> 求你从天上垂听，判断你的仆人，定恶人有罪，照他所行的报应在他头上；定义人有理，照他的义赏赐他。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 26:17; 列王纪下 17:7–18; 约书亚记 7:8"> 「你的民以色列若得罪你，败在仇敌面前，又回心转意承认你的名，在这殿里向你祈求祷告，</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 33:6–13; 以斯拉记 1:1–6; 创世记 13:15"> 求你从天上垂听，赦免你民以色列的罪，使他们归回你赐给他们和他们列祖之地。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 28:23; 申命记 11:17; 利未记 26:19"> 「你的民因得罪你，你惩罚他们，使天闭塞不下雨，他们若向此处祷告，承认你的名，离开他们的罪，</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 8:35–36; 耶利米书 5:24; 撒迦利亚书 10:1"> 求你在天上垂听，赦免你仆人和你民以色列的罪，将当行的善道指教他们，且降雨在你的地，就是你赐给你民为业之地。</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 9:3–11; 约珥书 2:25; 路得记 1:1"> 「国中若有饥荒、瘟疫、旱风、霉烂、蝗虫、蚂蚱，或有仇敌犯境，围困城邑，无论遭遇什么灾祸疾病，</span>
<span className="v" id="v29" data-v="29" data-xref="诗篇 50:15; 诗篇 32:2–6; 历代志下 6:12–13"> 你的民以色列，或是众人，或是一人，自觉灾祸甚苦，向这殿举手，无论祈求什么，祷告什么，</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 28:9; 撒母耳记上 16:7; 启示录 2:23"> 求你从天上你的居所垂听赦免。你是知道人心的，要照各人所行的待他们（惟有你知道世人的心），</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 9:31; 约伯记 28:28; 诗篇 128:1"> 使他们在你赐给我们列祖之地上一生一世敬畏你，遵行你的道。</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 56:3–7; 列王纪上 8:41–43; 马太福音 8:10–11"> 「论到不属你民以色列的外邦人，为你的大名和大能的手，并伸出来的膀臂，从远方而来，向这殿祷告，</span>
<span className="v" id="v33" data-v="33" data-xref="历代志下 7:14; 列王纪上 8:16; 启示录 11:15"> 求你从天上你的居所垂听，照着外邦人所祈求的而行，使天下万民都认识你的名，敬畏你，像你的民以色列一样，又使他们知道我建造的这殿是称为你名下的。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志下 20:6–13; 历代志下 18:31; 历代志下 20:4"> 「你的民若奉你的差遣，无论往何处去与仇敌争战，向你所选择的城与我为你名所建造的殿祷告，</span>
<span className="v" id="v35" data-v="35" data-xref="但以理书 9:17–19; 诗篇 9:3–4; 耶利米书 5:28"> 求你从天上垂听他们的祷告祈求，使他们得胜。</span>
<span className="v" id="v36" data-v="36" data-xref="传道书 7:20; 雅各书 3:2; 约翰一书 1:8–10"> 「你的民若得罪你（世上没有不犯罪的人），你向他们发怒，将他们交给仇敌掳到或远或近之地；</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 31:18–20; 但以理书 9:5–11; 以赛亚书 64:6–12"> 他们若在掳到之地想起罪来，回心转意，恳求你说：『我们有罪了，我们悖逆了，我们作恶了』；</span>
<span className="v" id="v38" data-v="38" data-xref="历代志下 33:11–13; 但以理书 6:10; 但以理书 9:3–4"> 他们若在掳到之地尽心尽性归服你，又向自己的地，就是你赐给他们列祖之地和你所选择的城，并我为你名所建造的殿祷告，</span>
<span className="v" id="v39" data-v="39" data-xref="弥迦书 7:18–20; 历代志下 6:35; 诗篇 25:18"> 求你从天上你的居所垂听你民的祷告祈求，为他们伸冤，赦免他们的过犯。</span>
<span className="v" id="v40" data-v="40" data-xref="历代志下 7:15; 诗篇 116:2; 尼希米记 1:6"> <span className="pl pl-1">「我的 神啊，现在求你睁眼看，侧耳听在此处所献的祷告。</span><br /></span>
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 61:10; 历代志上 28:2; 诗篇 132:8–10"> <span className="pl pl-1">耶和华 神啊，求你起来，</span><br /><span className="pl pl-1">和你有能力的约柜同入安息之所。</span><br /><span className="pl pl-1">耶和华 神啊，愿你的祭司披上救恩；</span><br /><span className="pl pl-1">愿你的圣民蒙福欢乐。</span><br /></span>
<span className="v" id="v42" data-v="42" data-xref="以赛亚书 55:3; 诗篇 132:1; 以赛亚书 61:1"> <span className="pl pl-1">耶和华 神啊，求你不要厌弃你的受膏者，</span><br /><span className="pl pl-1">要记念向你仆人大卫所施的慈爱。」</span></span>
</div>

## 预备守逾越节

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 5:7–8; 历代志下 11:13; 何西阿书 5:4"> 希西家差遣人去见以色列和犹大众人，又写信给以法莲和玛拿西人，叫他们到耶路撒冷耶和华的殿，向耶和华—以色列的 神守逾越节；</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 9:10–11; 历代志上 13:1–3; 历代志下 30:13"> 因为王和众首领，并耶路撒冷全会众已经商议，要在二月内守逾越节。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 29:34; 出埃及记 12:6; 出埃及记 12:18"> 正月<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是那时">a</a></sup>间他们不能守；因为自洁的祭司尚不敷用，百姓也没有聚集在耶路撒冷；</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 13:4"> 王与全会众都以这事为善。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 20:1; 利未记 23:2; 以斯帖记 8:8–10"> 于是定了命令，传遍以色列，从别是巴直到但，使他们都来，在耶路撒冷向耶和华—以色列的 神守逾越节；因为照所写的例，守这节的不多了<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：因为民许久没有照所写的例守节了">b</a></sup>。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 51:31; 以斯帖记 8:14; 列王纪下 15:19"> 驿卒就把王和众首领的信，遵着王命传遍以色列和犹大。信内说：「以色列人哪，你们当转向耶和华—亚伯拉罕、以撒、以色列的 神，好叫他转向你们这脱离亚述王手的余民。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 29:8; 以西结书 20:13–18; 撒迦利亚书 1:3–4"> 你们不要效法你们列祖和你们的弟兄；他们干犯耶和华—他们列祖的 神，以致耶和华丢弃他们，使他们败亡<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或译：令人惊骇">c</a></sup>，正如你们所见的。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 32:9; 历代志下 29:10; 申命记 10:16"> 现在不要像你们列祖硬着颈项，只要归顺耶和华，进入他的圣所，就是永远成圣的居所；又要事奉耶和华—你们的 神，好使他的烈怒转离你们。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 55:7; 弥迦书 7:18; 诗篇 86:5"> 你们若转向耶和华，你们的弟兄和儿女必在掳掠他们的人面前蒙怜恤，得以归回这地，因为耶和华—你们的 神有恩典、施怜悯。你们若转向他，他必不转脸不顾你们。」</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 36:16; 历代志下 30:6; 尼希米记 2:19"> 驿卒就由这城跑到那城，传遍了以法莲、玛拿西，直到西布伦。那里的人却戏笑他们，讥诮他们。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 30:18; 历代志下 30:21; 历代志下 30:25"> 然而亚设、玛拿西、西布伦中也有人自卑，来到耶路撒冷。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 32:39; 耶利米书 24:7; 腓立比书 2:13"> 神也感动犹大人，使他们一心遵行王与众首领凭耶和华之言所发的命令。</span>
</div>
</div>

## 守逾越节

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志下 30:2; 诗篇 84:7"> 二月，有许多人在耶路撒冷聚集，成为大会，要守除酵节。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 28:24; 撒母耳记下 15:23; 历代志下 15:16"> 他们起来，把耶路撒冷的祭坛和烧香的坛尽都除去，抛在汲沦溪中。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 29:34; 历代志下 5:11; 出埃及记 19:22"> 二月十四日，宰了逾越节的羊羔。祭司与利未人觉得惭愧，就洁净自己，把燔祭奉到耶和华殿中，</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 33:1; 历代志下 35:15; 列王纪下 11:14"> 遵着神人摩西的律法，照例站在自己的地方；祭司从利未人手里接过血来，洒在坛上。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 29:34; 历代志下 35:3–6; 出埃及记 12:6"> 会中有许多人尚未自洁，所以利未人为一切不洁之人宰逾越节的羊羔，使他们在耶和华面前成为圣洁。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 11:28; 雅各书 5:15–16; 但以理书 9:19"> 以法莲、玛拿西、以萨迦、西布伦有许多人尚未自洁，他们却也吃逾越节的羊羔，不合所记录的定例。希西家为他们祷告说：「凡专心寻求 神，就是耶和华—他列祖之 神的，虽不照着圣所洁净之礼自洁，求至善的耶和华也饶恕他。」</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 15:26; 雅各书 5:15–16; 诗篇 103:3"> 耶和华垂听希西家的祷告，就饶恕<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原文是医治">d</a></sup>百姓。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 12:15; 出埃及记 13:6; 申命记 12:12"> 在耶路撒冷的以色列人大大喜乐，守除酵节七日。利未人和祭司用响亮的乐器，日日颂赞耶和华。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 32:6; 尼希米记 9:3; 以赛亚书 40:1–2"> 希西家慰劳一切善于事奉耶和华的利未人。于是众人吃节筵七日，又献平安祭，且向耶和华—他们列祖的 神认罪。</span>
</div>
</div>

## 再度守节

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪上 8:65; 历代志下 7:9"> 全会众商议，要再守节七日；于是欢欢喜喜地又守节七日。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志下 29:34; 历代志下 35:7–8; 以弗所书 4:8"> 犹大王希西家赐给会众公牛一千只，羊七千只为祭物；众首领也赐给会众公牛一千只，羊一万只，并有许多的祭司洁净自己。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 30:11; 历代志下 30:18; 历代志上 16:10–11"> 犹大全会众、祭司、利未人，并那从以色列地来的会众和寄居的人，以及犹大寄居的人，尽都喜乐。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志下 7:8–10"> 这样，在耶路撒冷大有喜乐，自从以色列王大卫儿子所罗门的时候，在耶路撒冷没有这样的喜乐。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 26:15; 诗篇 68:5; 民数记 6:23–26"> 那时，祭司、利未人起来，为民祝福。他们的声音蒙 神垂听，他们的祷告达到天上的圣所。</span>
</div>

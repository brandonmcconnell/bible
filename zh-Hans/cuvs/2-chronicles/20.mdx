## 与以东交战

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 83:5–8; 以赛亚书 16:6; 历代志下 32:1"> 此后，摩押人和亚扪人，又有米乌尼人，一同来攻击约沙法。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 14:7; 撒母耳记上 23:29; 约书亚记 15:62"> 有人来报告约沙法说：「从海外亚兰<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="又作以东">a</a></sup>那边有大军来攻击你，如今他们在哈洗逊·他玛，就是隐·基底。」</span>
<span className="v" id="v3" data-v="3" data-xref="但以理书 9:3; 历代志下 19:3; 撒母耳记上 7:6"> 约沙法便惧怕，定意寻求耶和华，在犹大全地宣告禁食。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 50:15; 诗篇 60:10–12; 诗篇 69:35"> 于是犹大人聚会，求耶和华帮助。犹大各城都有人出来寻求耶和华。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 19:15–19; 历代志下 6:12–13; 历代志下 34:31"> 约沙法就在犹大和耶路撒冷的会中，站在耶和华殿的新院前，</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 4:39; 历代志上 29:11–12; 但以理书 4:17"> 说：「耶和华—我们列祖的 神啊，你不是天上的 神吗？你不是万邦万国的主宰吗？在你手中有大能大力，无人能抵挡你。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 41:8; 雅各书 2:23; 诗篇 44:2"> 我们的 神啊，你不是曾在你民以色列人面前驱逐这地的居民，将这地赐给你朋友亚伯拉罕的后裔永远为业吗？</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 6:10; 历代志下 2:4"> 他们住在这地，又为你的名建造圣所，说：</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 6:28–30; 历代志下 6:20; 列王纪上 8:33"> 『倘有祸患临到我们，或刀兵灾殃，或瘟疫饥荒，我们在急难的时候，站在这殿前向你呼求，你必垂听而拯救，因为你的名在这殿里。』</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 2:19; 申命记 2:4–5; 申命记 2:9"> 从前以色列人出埃及地的时候，你不容以色列人侵犯亚扪人、摩押人，和西珥山人，以色列人就离开他们，不灭绝他们。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 83:3–12; 士师记 11:23–24; 耶利米书 18:20"> 看哪，他们怎样报复我们，要来驱逐我们出离你的地，就是你赐给我们为业之地。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 121:1–2; 诗篇 25:15; 诗篇 141:8"> 我们的 神啊，你不惩罚他们吗？因为我们无力抵挡这来攻击我们的大军，我们也不知道怎样行，我们的眼目单仰望你。」</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 10:1; 使徒行传 21:5; 申命记 29:10"> 犹大众人和他们的婴孩、妻子、儿女都站在耶和华面前。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 15:1; 历代志下 24:20; 使徒行传 10:31"> 那时，耶和华的灵在会中临到利未人亚萨的后裔—玛探雅的玄孙，耶利的曾孙，比拿雅的孙子，撒迦利雅的儿子雅哈悉。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 32:7–8; 申命记 31:6; 出埃及记 14:13–14"> 他说：「犹大众人、耶路撒冷的居民，和约沙法王，你们请听。耶和华对你们如此说：『不要因这大军恐惧惊惶；因为胜败不在乎你们，乃在乎 神。</span>
<span className="v" id="v16" data-v="16"> 明日你们要下去迎敌，他们是从洗斯坡上来，你们必在耶鲁伊勒旷野前的谷口遇见他们。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 14:13–14; 历代志下 15:2; 以赛亚书 41:10"> 犹大和耶路撒冷人哪，这次你们不要争战，要摆阵站着，看耶和华为你们施行拯救。不要恐惧，也不要惊惶。明日当出去迎敌，因为耶和华与你们同在。』」</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 4:31; 历代志下 7:3; 创世记 24:26"> 约沙法就面伏于地，犹大众人和耶路撒冷的居民也俯伏在耶和华面前，叩拜耶和华。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 15:16–22; 历代志上 16:42; 历代志上 16:5"> 哥辖族和可拉族的利未人都起来，用极大的声音赞美耶和华以色列的 神。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 8:31; 约翰福音 14:1; 约翰福音 11:40"> 次日清早，众人起来往提哥亚的旷野去。出去的时候，约沙法站着说：「犹大人和耶路撒冷的居民哪，要听我说：信耶和华—你们的 神就必立稳；信他的先知就必亨通。」</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 107:1; 诗篇 106:1; 历代志下 5:13"> 约沙法既与民商议了，就设立歌唱的人，颂赞耶和华，使他们穿上圣洁的礼服，走在军前赞美耶和华说：「当称谢耶和华，因他的慈爱永远长存！」</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 14:20; 以赛亚书 19:2; 以西结书 38:21"> 众人方唱歌赞美的时候，耶和华就派伏兵击杀那来攻击犹大人的亚扪人、摩押人，和西珥山人，他们就被打败了。</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 7:22; 撒母耳记上 14:20; 以西结书 35:2–3"> 因为亚扪人和摩押人起来，击杀住西珥山的人，将他们灭尽；灭尽住西珥山的人之后，他们又彼此自相击杀。</span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 37:36; 诗篇 110:6; 历代志上 5:22"> 犹大人来到旷野的望楼，向那大军观看，见尸横遍地，没有一个逃脱的。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 30:19–20; 列王纪下 7:9–16; 民数记 31:15"> 约沙法和他的百姓就来收取敌人的财物，在尸首中见了许多财物、珍宝，他们剥脱下来的多得不可携带；因为甚多，直收取了三日。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 17:15; 创世记 32:20; 历代志下 5:9"> 第四日众人聚集在比拉迦谷<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就是称颂的意思">b</a></sup>，在那里称颂耶和华。因此那地方名叫比拉迦谷，直到今日。</span>
<span className="v" id="v27" data-v="27" data-xref="尼希米记 12:43; 希伯来书 6:20; 诗篇 30:1"> 犹大人和耶路撒冷人都欢欢喜喜地回耶路撒冷，约沙法率领他们；因为耶和华使他们战胜仇敌，就欢喜快乐。</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 14:2–3; 诗篇 57:8; 诗篇 92:3"> 他们弹琴、鼓瑟、吹号来到耶路撒冷，进了耶和华的殿。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志下 17:10; 列王纪下 7:6; 出埃及记 23:27"> 列邦诸国听见耶和华战败以色列的仇敌，就甚惧怕。</span>
<span className="v" id="v30" data-v="30" data-xref="历代志下 15:15; 历代志下 14:6–7; 撒母耳记下 7:1"> 这样，约沙法的国得享太平，因为 神赐他四境平安。</span>
</div>

## 约沙法逝世

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪上 22:41–44"> 约沙法作犹大王，登基的时候年三十五岁，在耶路撒冷作王二十五年。他母亲名叫阿苏巴，乃示利希的女儿。</span>
<span className="v" id="v32" data-v="32" data-xref="历代志下 14:2–5; 列王纪上 15:11; 历代志下 14:11–13"> 约沙法效法他父亚撒所行的，不偏左右，行耶和华眼中看为正的事。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志下 17:6; 历代志下 19:3; 历代志下 12:14"> 只是邱坛还没有废去，百姓也没有立定心意归向他们列祖的 神。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 16:1; 历代志下 19:2; 列王纪上 16:7"> 约沙法其余的事，自始至终都写在哈拿尼的儿子耶户的书上，也载入以色列诸王记上。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 22:48–49; 列王纪下 1:2–16"> 此后，犹大王约沙法与以色列王亚哈谢交好；亚哈谢行恶太甚。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 10:22; 历代志下 9:21; 列王纪上 9:26"> 二王合伙造船要往他施去，遂在以旬·迦别造船。</span>
<span className="v" id="v37" data-v="37" data-xref="箴言 13:20; 历代志下 19:2; 历代志下 9:21"> 那时玛利沙人、多大瓦的儿子以利以谢向约沙法预言说：「因你与亚哈谢交好，耶和华必破坏你所造的。」后来那船果然破坏，不能往他施去了。</span>

## 推翻亚她利雅

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 15:12; 列王纪下 11:4–20; 尼希米记 9:38"> 第七年，耶何耶大奋勇自强，将百夫长耶罗罕的儿子亚撒利雅，约哈难的儿子以实玛利，俄备得的儿子亚撒利雅，亚大雅的儿子玛西雅，细基利的儿子以利沙法召来，与他们立约。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 11:13–17; 历代志下 21:2; 历代志上 15:12"> 他们走遍犹大，从犹大各城里招聚利未人和以色列的众族长到耶路撒冷来。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 21:7; 撒母耳记下 7:12; 历代志下 6:16"> 会众在 神殿里与王立约。耶何耶大对他们说：「看哪，王的儿子必当作王，正如耶和华指着大卫子孙所应许的话」；</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 23:3–6; 历代志上 26:13–16; 路加福音 1:8–9"> 又说：「你们当这样行：祭司和利未人凡安息日进班的，三分之一要把守各门，</span>
<span className="v" id="v5" data-v="5" data-xref="以西结书 46:2–3; 使徒行传 3:2; 列王纪下 11:5–6"> 三分之一要在王宫，三分之一要在基址门；众百姓要在耶和华殿的院内。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 23:28–32; 列王纪下 11:6–7"> 除了祭司和供职的利未人之外，不准别人进耶和华的殿；惟独他们可以进去，因为他们圣洁。众百姓要遵守耶和华所吩咐的。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 3:38; 民数记 3:10; 列王纪下 11:8–9"> 利未人要手中各拿兵器，四围护卫王；凡擅入殿宇的，必当治死。王出入的时候，你们当跟随他。」</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪下 11:9; 历代志上 24:1–26"> 利未人和犹大众人都照着祭司耶何耶大一切所吩咐的去行，各带所管安息日进班出班的人来，因为祭司耶何耶大不许他们下班。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 21:9; 撒母耳记下 8:7"> 祭司耶何耶大便将 神殿里所藏大卫王的枪、盾牌、挡牌交给百夫长，</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 40:6; 历代志下 6:12; 列王纪下 11:11"> 又分派众民手中各拿兵器，在坛和殿那里，从殿右直到殿左，站在王子的四围；</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 10:24; 出埃及记 25:16; 列王纪下 11:12"> 于是领王子出来，给他戴上冠冕，将律法书交给他，立他作王。耶何耶大和众子膏他，众人说：「愿王万岁！」</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 11:13–16; 列王纪下 9:32–37"> 亚她利雅听见民奔走赞美王的声音，就到民那里，进耶和华的殿，</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 29:2; 历代志下 34:31; 列王纪下 9:23"> 看见王站在殿门的柱旁，百夫长和吹号的人侍立在王左右，国民都欢乐吹号，又有歌唱的，用各样的乐器领人歌唱赞美；亚她利雅就撕裂衣服，喊叫说：「反了！反了！」</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 9:7; 列王纪下 11:8; 列王纪下 11:15"> 祭司耶何耶大带管辖军兵的百夫长出来，吩咐他们说：「将她赶到班外，凡跟随她的必用刀杀死！」因为祭司说：「不可在耶和华殿里杀她。」</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米记 3:28; 耶利米书 31:40; 历代志下 22:10"> 众兵就闪开，让她去；她走到王宫的马门，便在那里把她杀了。</span>
</div>
</div>

## 耶何耶大的改革

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志下 29:10; 尼希米记 9:38; 列王纪下 11:17"> 耶何耶大与众民和王立约，都要作耶和华的民。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 18:40; 列王纪下 10:25–28; 列王纪下 18:4"> 于是众民都到巴力庙，拆毁了庙，打碎坛和像，又在坛前将巴力的祭司玛坦杀了。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 5:5; 民数记 28:1–31; 历代志下 29:25"> 耶何耶大派官看守耶和华的殿，是在祭司利未人手下。这祭司利未人是大卫分派在耶和华殿中、照摩西律法上所写的，给耶和华献燔祭，又按大卫所定的例，欢乐歌唱；</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 26:1–32; 历代志上 9:22–24"> 且设立守门的把守耶和华殿的各门，无论为何事，不洁净的人都不准进去。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 11:19; 列王纪下 15:35; 列王纪下 11:9–10"> 又率领百夫长和贵胄，与民间的官长，并国中的众民，请王从耶和华殿下来，由上门进入王宫，立王坐在国位上。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 11:20; 启示录 18:20; 启示录 19:1–4"> 国民都欢乐，合城都安静。众人已将亚她利雅用刀杀了。</span>
</div>

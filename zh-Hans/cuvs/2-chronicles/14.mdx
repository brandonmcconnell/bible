## 亚撒王击败古实人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 9:31; 列王纪上 2:10; 列王纪上 14:31"> 亚比雅与他列祖同睡，葬在大卫城里。他儿子亚撒接续他作王。亚撒年间，国中太平十年。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 15:11; 历代志下 31:20; 列王纪上 15:14"> 亚撒行耶和华—他 神眼中看为善为正的事，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 7:5; 出埃及记 34:13; 列王纪下 23:14"> 除掉外邦神的坛和邱坛，打碎柱像，砍下木偶，</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 30:19; 诗篇 119:10; 诗篇 101:2–8"> 吩咐犹大人寻求耶和华—他们列祖的 神，遵行他的律法、诫命；</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 34:4; 历代志下 34:7"> 又在犹大各城邑除掉邱坛和日像，那时国享太平；</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 15:15; 历代志上 22:9; 约伯记 34:29"> 又在犹大建造了几座坚固城。国中太平数年，没有战争，因为耶和华赐他平安。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前书 3:12; 历代志下 14:6; 耶利米书 29:12–14"> 他对犹大人说：「我们要建造这些城邑，四围筑墙，盖楼，安门，做闩；地还属我们，是因寻求耶和华—我们的 神；我们既寻求他，他就赐我们四境平安。」于是建造城邑，诸事亨通。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 13:3; 历代志下 17:14–19; 历代志下 11:1"> 亚撒的军兵，出自犹大拿盾牌拿枪的三十万人；出自便雅悯拿盾牌拉弓的二十八万人。这都是大能的勇士。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 16:8; 历代志下 12:2–3; 历代志下 11:8"> 有古实王谢拉率领军兵一百万，战车三百辆，出来攻击犹大人，到了玛利沙。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 1:17; 约书亚记 19:4"> 于是亚撒出去与他迎敌，就在玛利沙的洗法谷彼此摆阵。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 1:19; 哥林多后书 12:9–10; 诗篇 22:5"> 亚撒呼求耶和华—他的 神说：「耶和华啊，惟有你能帮助软弱的，胜过强盛的。耶和华—我们的 神啊，求你帮助我们；因为我们仰赖你，奉你的名来攻击这大军。耶和华啊，你是我们的 神，不要容人胜过你。」</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 13:15; 诗篇 136:17–18; 申命记 28:7"> 于是耶和华使古实人败在亚撒和犹大人面前，古实人就逃跑了；</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 10:19; 创世记 26:1; 创世记 20:1"> 亚撒和跟随他的军兵追赶他们，直到基拉耳。古实人被杀的甚多，不能再强盛，因为败在耶和华与他军兵面前。犹大人就夺了许多财物，</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 17:10; 创世记 35:5; 历代志下 20:29"> 又打破基拉耳四围的城邑；耶和华使其中的人都甚恐惧。犹大人又将所有的城掳掠一空，因其中的财物甚多，</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 31:30–47; 民数记 31:9; 撒母耳记上 30:20"> 又毁坏了群畜的圈，夺取许多的羊和骆驼，就回耶路撒冷去了。</span>

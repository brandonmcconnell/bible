## 圣殿的设备

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 8:64; 以西结书 43:13–17; 列王纪上 9:25"> 他又制造一座铜坛，长二十肘，宽二十肘，高十肘；</span>
<span className="v" id="v2" data-v="2" data-xref="提多书 3:5; 撒迦利亚书 13:1; 出埃及记 30:18–21"> 又铸一个铜海，样式是圆的，高五肘，径十肘，围三十肘；</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 1:10; 以西结书 10:14; 哥林多前书 9:9–10"> 海周围有野瓜<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="野瓜：原文是牛">a</a></sup>的样式，每肘十瓜，共有两行，是铸海的时候铸上的；</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 28:19–20; 启示录 21:14; 马可福音 16:15"> 有十二只铜牛驮海：三只向北，三只向西，三只向南，三只向东；海在牛上，牛尾向内；</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 7:26"> 海厚一掌，边如杯边，又如百合花，可容三千罢特；</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 7:38; 出埃及记 30:18–21; 列王纪上 7:40"> 又制造十个盆：五个放在右边，五个放在左边，献燔祭所用之物都洗在其内；但海是为祭司沐浴的。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 25:31–40; 列王纪上 7:49; 约翰福音 8:12"> 他又照所定的样式造十个金灯台放在殿里：五个在右边，五个在左边；</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 7:48; 玛拉基书 1:12; 出埃及记 25:23–30"> 又造十张桌子放在殿里：五张在右边，五张在左边；又造一百个金碗；</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 6:36; 列王纪下 21:5; 列王纪上 7:12"> 又建立祭司院和大院，并院门，用铜包裹门扇；</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 7:39"> 将海安在殿门的右边，就是南边。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪上 7:40–51; 列王纪上 7:14"> 户兰又造了盆、铲、碗。这样，他为所罗门王做完了 神殿的工。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 7:41; 历代志下 3:15–17"> 所造的就是：两根柱子和柱上两个如球的顶，并两个盖柱顶的网子</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 7:20; 列王纪上 7:42; 耶利米书 52:23"> 和四百石榴，安在两个网子上（每网两行盖着两个柱上如球的顶）。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 7:27–43"> 盆座和其上的盆，</span>
<span className="v" id="v15" data-v="15"> 海和海下的十二只牛，</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 2:13; 列王纪上 7:13–14; 历代志下 4:11"> 盆、铲子、肉锸子，与耶和华殿里的一切器皿，都是巧匠户兰用光亮的铜为所罗门王造成的，</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 7:46"> 是在约旦平原疏割和撒利但中间借胶泥铸成的。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 7:47; 耶利米书 52:20; 历代志上 22:14"> 所罗门制造的这一切甚多，铜的轻重无法可查。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="启示录 9:13; 但以理书 5:2–3; 出埃及记 25:23–30"> 所罗门又造 神殿里的金坛和陈设饼的桌子，</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 4:7; 出埃及记 25:31–37; 列王纪上 6:5"> 并精金的灯台和灯盏，可以照例点在内殿前。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 6:29; 出埃及记 37:20; 列王纪上 6:35"> 灯台上的花和灯盏，并蜡剪都是金的，且是纯金的；</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 12:13; 列王纪下 25:14; 耶利米书 52:18"> 又用精金制造镊子、盘子、调羹、火鼎。至于殿门和至圣所的门扇，并殿的门扇，都是金子妆饰的。</span>
</div>
</div>

## 祷告的教训

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="诗篇 19:14; 路加福音 22:39–45; 罗马书 8:26–27"> 耶稣在一个地方祷告；祷告完了，有个门徒对他说：「求主教导我们祷告，像约翰教导他的门徒。」</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 6:6–15; 传道书 5:2; 诗篇 72:18–19"> 耶稣说：「你们祷告的时候，要说：<br /><span className="pl pl-1">我们在天上的父</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷：父啊">a</a></sup><br /><span className="pl pl-1">：</span><br /><span className="pl pl-1">愿人都尊你的名为圣。</span><br /><span className="pl pl-1">愿你的国降临；</span><br /><span className="pl pl-1">愿你的旨意行在地上，</span><br /><span className="pl pl-1">如同行在天上</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷没有愿你的旨意…">b</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 6:11; 马太福音 6:34; 箴言 30:8"> <span className="pl pl-1">我们日用的饮食，</span><br /><span className="pl pl-1">天天赐给我们。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 6:12–15; 马太福音 26:41; 以赛亚书 43:25–26"> <span className="pl pl-1">赦免我们的罪，</span><br /><span className="pl pl-1">因为我们也赦免凡亏欠我们的人。</span><br /><span className="pl pl-1">不叫我们遇见试探；</span><br /><span className="pl pl-1">救我们脱离凶恶</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古卷没有末句">c</a></sup><br /><span className="pl pl-1">。」</span></span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 18:1–8"> 耶稣又说：「你们中间谁有一个朋友半夜到他那里去，说：『朋友！请借给我三个饼；</span>
<span className="v" id="v6" data-v="6"> 因为我有一个朋友行路，来到我这里，我没有什么给他摆上。』</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 13:25; 加拉太书 6:17; 路加福音 7:6"> 那人在里面回答说：『不要搅扰我，门已经关闭，孩子们也同我在床上了，我不能起来给你。』</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 32:26; 歌罗西书 4:12; 罗马书 15:30"> 我告诉你们，虽不因他是朋友起来给他，但因他情词迫切地直求，就必起来照他所需用的给他。</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 11:24; 约翰福音 16:23–24; 马太福音 21:22"> 我又告诉你们，你们祈求，就给你们；寻找，就寻见；叩门，就给你们开门。</span>
<span className="v" id="v10" data-v="10" data-xref="雅各书 4:3; 耶利米哀歌 3:54–58; 诗篇 31:22"> 因为，凡祈求的，就得着；寻找的，就寻见；叩门的，就给他开门。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 7:9; 以赛亚书 49:15"> 你们中间作父亲的，谁有儿子求饼，反给他石头呢？求鱼，反拿蛇当鱼给他呢？</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 9:10; 路加福音 10:19; 以西结书 2:6"> 求鸡蛋，反给他蝎子呢？</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 7:11; 以赛亚书 44:3–4; 罗马书 8:32"> 你们虽然不好，尚且知道拿好东西给儿女；何况天父，岂不更将圣灵给求他的人吗？」</span>
</div>

## 耶稣和别西卜

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 12:22–24; 马太福音 9:32–34; 马可福音 7:32–37"> 耶稣赶出一个叫人哑巴的鬼；鬼出去了，哑巴就说出话来；众人都希奇。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 9:34; 马太福音 12:24–30; 约翰福音 8:48"> 内中却有人说：「他是靠着鬼王别西卜赶鬼。」</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 6:30; 哥林多前书 1:22; 马可福音 8:11–12"> 又有人试探耶稣，向他求从天上来的神迹。</span>
<span className="v" id="v17" data-v="17" data-xref="马可福音 3:23–27; 马太福音 12:25–29; 以赛亚书 19:2–3"> 他晓得他们的意念，便对他们说：「凡一国自相纷争，就成为荒场；凡一家自相纷争，就必败落。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 12:26; 马太福音 12:31–34; 路加福音 11:15"> 若撒但自相纷争，他的国怎能站得住呢？因为你们说我是靠着别西卜赶鬼。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 9:49; 约伯记 15:6; 罗马书 3:19"> 我若靠着别西卜赶鬼，你们的子弟赶鬼又靠着谁呢？这样，他们就要断定你们的是非。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 8:19; 马太福音 12:28; 路加福音 10:9"> 我若靠着 神的能力赶鬼，这就是 神的国临到你们了。</span>
<span className="v" id="v21" data-v="21" data-xref="马可福音 3:27; 马太福音 12:29"> 壮士披挂整齐，看守自己的住宅，他所有的都平安无事；</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 49:24–25; 以赛亚书 53:12; 约翰一书 3:8"> 但有一个比他更壮的来，胜过他，就夺去他所倚靠的盔甲兵器，又分了他的赃。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 12:30; 路加福音 9:50; 马可福音 9:40"> 不与我相合的，就是敌我的；不同我收聚的，就是分散的。」</span>
</div>
</div>

## 污鬼回来

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="马太福音 12:43–45; 彼得前书 5:8; 约伯记 2:2"> 「污鬼离了人身，就在无水之地过来过去，寻求安歇之处；既寻不着，便说：『我要回到我所出来的屋里去。』</span>
<span className="v" id="v25" data-v="25" data-xref="帖撒罗尼迦后书 2:9–12; 彼得后书 2:10–19; 犹大书 1:8–13"> 到了，就看见里面打扫干净，修饰好了，</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 5:14; 马太福音 12:45; 彼得后书 2:20–22"> 便去另带了七个比自己更恶的鬼来，都进去住在那里。那人末后的景况比先前更不好了。」</span>
</div>

## 求神迹的受责备

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 11:16; 马可福音 8:11–12; 哥林多前书 1:22"> 当众人聚集的时候，耶稣开讲说：「这世代是一个邪恶的世代。他们求看神迹，除了约拿的神迹以外，再没有神迹给他们看。</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 12:40–42; 约拿书 1:17; 约拿书 3:2–10"> 约拿怎样为尼尼微人成了神迹，人子也要照样为这世代的人成了神迹。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志下 9:1; 列王纪上 10:1–13; 罗马书 2:27"> 当审判的时候，南方的女王要起来定这世代的罪；因为她从地极而来，要听所罗门的智慧话。看哪，在这里有一人比所罗门更大。</span>
<span className="v" id="v32" data-v="32" data-xref="希伯来书 7:26; 路加福音 11:31; 约拿书 3:5–4"> 当审判的时候，尼尼微人要起来定这世代的罪，因为尼尼微人听了约拿所传的就悔改了。看哪，在这里有一人比约拿更大。」</span>
</div>
</div>

## 论心里的光

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 8:16–17; 马可福音 4:21–22; 马太福音 5:15–16"> 「没有人点灯放在地窨子里，或是斗底下，总是放在灯台上，使进来的人得见亮光。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 6:22–23; 使徒行传 26:18; 耶利米书 5:21"> 你眼睛就是身上的灯。你的眼睛若了亮，全身就光明；眼睛若昏花，全身就黑暗。</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 16:25; 彼得后书 1:9; 雅各书 3:13–17"> 所以，你要省察，恐怕你里头的光或者黑暗了。</span>
<span className="v" id="v36" data-v="36" data-xref="箴言 20:27; 箴言 6:23; 箴言 4:18–19"> 若是你全身光明，毫无黑暗，就必全然光明，如同灯的明光照亮你。」</span>
</div>
</div>

## 谴责法利赛人和文士

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 7:36; 哥林多前书 9:19–23; 路加福音 14:1"> 说话的时候，有一个法利赛人请耶稣同他吃饭，耶稣就进去坐席。</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 15:2–3; 马可福音 7:2–5; 约翰福音 3:25"> 这法利赛人看见耶稣饭前不洗手便诧异。</span>
<span className="v" id="v39" data-v="39" data-xref="提多书 1:15; 箴言 30:12; 创世记 6:5"> 主对他说：「如今你们法利赛人洗净杯盘的外面，你们里面却满了勒索和邪恶。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 12:20; 哥林多前书 15:36; 马太福音 23:26"> 无知的人哪，造外面的，不也造里面吗？</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 12:33; 雅各书 1:27; 提多书 1:15"> 只要把里面的施舍给人，凡物于你们就都洁净了。</span>
<span className="v" id="v42" data-v="42" data-xref="马太福音 23:23; 路加福音 18:12; 箴言 21:3"> 「你们法利赛人有祸了！因为你们将薄荷、芸香并各样菜蔬献上十分之一，那公义和爱 神的事反倒不行了。这原是你们当行的；那也是不可不行的。</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 20:46; 马可福音 12:38–39; 路加福音 14:7–11"> 你们法利赛人有祸了！因为你们喜爱会堂里的首位，又喜爱人在街市上问你们的安。</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 23:27–28; 诗篇 5:9; 使徒行传 23:3"> 你们有祸了！因为你们如同不显露的坟墓，走在上面的人并不知道。」</span>
<span className="v" id="v45" data-v="45" data-xref="约翰福音 9:40; 马太福音 22:35; 耶利米书 6:10"> 律法师中有一个回答耶稣说：「夫子！你这样说也把我们糟蹋了。」</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 11:52; 以赛亚书 10:1; 马太福音 23:2–4"> 耶稣说：「你们律法师也有祸了！因为你们把难担的担子放在人身上，自己一个指头却不肯动。</span>
<span className="v" id="v47" data-v="47" data-xref="帖撒罗尼迦前书 2:15; 使徒行传 7:51; 马太福音 23:29–33"> 你们有祸了！因为你们修造先知的坟墓，那先知正是你们的祖宗所杀的。</span>
<span className="v" id="v48" data-v="48" data-xref="雅各书 5:10; 马太福音 23:31; 历代志下 36:16"> 可见你们祖宗所做的事，你们又证明又喜欢；因为他们杀了先知，你们修造先知的坟墓。</span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前书 1:30; 歌罗西书 2:3; 以弗所书 4:11"> 所以 神用智慧<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="用智慧：或译的智者">d</a></sup>曾说：『我要差遣先知和使徒到他们那里去，有的他们要杀害，有的他们要逼迫』，</span>
<span className="v" id="v50" data-v="50" data-xref="创世记 9:5–6; 启示录 18:20–24; 列王纪下 24:4"> 使创世以来所流众先知血的罪都要问在这世代的人身上，</span>
<span className="v" id="v51" data-v="51" data-xref="历代志下 24:20–22; 马太福音 23:35; 希伯来书 11:4"> 就是从亚伯的血起，直到被杀在坛和殿中间撒迦利亚的血为止。我实在告诉你们，这都要问在这世代的人身上。</span>
<span className="v" id="v52" data-v="52" data-xref="马太福音 23:13; 玛拉基书 2:7; 路加福音 11:45–46"> 你们律法师有祸了！因为你们把知识的钥匙夺了去，自己不进去，正要进去的人你们也阻挡他们。」</span>
<span className="v" id="v53" data-v="53" data-xref="哥林多前书 13:5; 耶利米书 20:10; 路加福音 20:20"> 耶稣从那里出来，文士和法利赛人就极力地催逼他，引动他多说话，</span>
<span className="v" id="v54" data-v="54" data-xref="马可福音 12:13; 马太福音 22:15; 马太福音 22:35"> 私下窥听，要拿他的话柄。</span>
</div>

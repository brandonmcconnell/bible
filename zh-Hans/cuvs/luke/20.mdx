## 质问耶稣的权柄

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 21:23–27; 路加福音 19:47–48; 使徒行传 6:12"> 有一天，耶稣在殿里教训百姓，讲福音的时候，祭司长和文士并长老上前来，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 2:14; 马可福音 11:28–33; 约翰福音 2:18"> 问他说：「你告诉我们，你仗着什么权柄做这些事？给你这权柄的是谁呢？」</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 15:2–3; 路加福音 22:68; 歌罗西书 4:6"> 耶稣回答说：「我也要问你们一句话，你们且告诉我。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 15:18; 马太福音 11:7–19; 马太福音 17:11–12"> 约翰的洗礼是从天上来的？是从人间来的呢？」</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 1:34; 约翰福音 1:15–18; 约翰福音 1:30"> 他们彼此商议说：「我们若说『从天上来』，他必说：『你们为什么不信他呢？』</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 21:26; 马太福音 11:9; 约翰福音 10:41"> 若说『从人间来』，百姓都要用石头打死我们，因为他们信约翰是先知。」</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 29:14; 彼得后书 3:3; 以赛亚书 41:28"> 于是回答说：「不知道是从哪里来的。」</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 26:4–5; 马太福音 21:27; 马可福音 11:33"> 耶稣说：「我也不告诉你们，我仗着什么权柄做这些事。」</span>
</div>
</div>

## 凶恶园户的比喻

<div className="bt">
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="马太福音 21:33–46; 马可福音 12:1–12; 以赛亚书 5:1–7"> 耶稣就设比喻对百姓说：「有人栽了一个葡萄园，租给园户，就往外国去住了许久。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 36:15–16; 尼希米记 9:26; 马太福音 21:34–36"> 到了时候，打发一个仆人到园户那里去，叫他们把园中当纳的果子交给他；园户竟打了他，叫他空手回去。</span>
<span className="v" id="v11" data-v="11" data-xref="何西阿书 10:1; 希伯来书 11:36–37; 帖撒罗尼迦前书 2:2"> 又打发一个仆人去，他们也打了他，并且凌辱他，叫他空手回去。</span>
<span className="v" id="v12" data-v="12"> 又打发第三个仆人去，他们也打伤了他，把他推出去了。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 3:17; 约翰福音 3:16–17; 耶利米书 36:7"> 园主说：『我怎么办呢？我要打发我的爱子去，或者他们尊敬他。』</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 8:17; 希伯来书 1:2; 使徒行传 2:23"> 不料，园户看见他，就彼此商量说：『这是承受产业的，我们杀他吧，使产业归于我们！』</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 13:12; 马可福音 12:6–9; 马太福音 21:37–40"> 于是把他推出葡萄园外，杀了。这样，葡萄园的主人要怎样处治他们呢？</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:27; 使徒行传 13:46; 马太福音 21:41"> 他要来除灭这些园户，将葡萄园转给别人。」听见的人说：「这是万不可的！」</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 118:22; 以赛亚书 28:16; 使徒行传 4:11"> 耶稣看着他们说：「经上记着：<br /><span className="pl pl-1">匠人所弃的石头</span><br /><span className="pl pl-1">已作了房角的头块石头。</span><br />这是什么意思呢？</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 8:14–15; 撒迦利亚书 12:3; 但以理书 2:44–45"> 凡掉在那石头上的，必要跌碎；那石头掉在谁的身上，就要把谁砸得稀烂。」</span>
</div>
</div>

## 纳税给凯撒的问题

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 19:47–48; 路加福音 20:14; 马太福音 21:45–46"> 文士和祭司长看出这比喻是指着他们说的，当时就想要下手拿他，只是惧怕百姓。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 11:54; 马太福音 22:15–22; 马太福音 27:2"> 于是窥探耶稣，打发奸细装作好人，要在他的话上得把柄，好将他交在巡抚的政权之下。</span>
<span className="v" id="v21" data-v="21" data-xref="帖撒罗尼迦前书 2:4–5; 马太福音 26:49–50; 马太福音 22:16"> 奸细就问耶稣说：「夫子，我们晓得你所讲所传都是正道，也不取人的外貌，乃是诚诚实实传 神的道。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米记 9:37; 马可福音 12:14–17; 使徒行传 5:37"> 我们纳税给凯撒，可以不可以？」</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 22:18; 哥林多前书 3:19; 路加福音 5:22"> 耶稣看出他们的诡诈，就对他们说：</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 18:28; 使徒行传 11:28; 使徒行传 26:32"> 「拿一个银钱来给我看。这像和这号是谁的？」他们说：「是凯撒的。」</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 13:6–7; 马可福音 12:17; 彼得前书 2:13–17"> 耶稣说：「这样，凯撒的物当归给凯撒， 神的物当归给 神。」</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 20:20; 箴言 26:4–5; 提多书 1:10"> 他们当着百姓，在这话上得不着把柄，又希奇他的应对，就闭口无言了。</span>
</div>
</div>

## 复活的问题

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行传 4:1–2; 哥林多前书 15:12; 马可福音 12:18–27"> 撒都该人常说没有复活的事。有几个来问耶稣说：</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 25:5–10; 创世记 38:8; 创世记 38:11"> 「夫子！摩西为我们写着说：『人若有妻无子就死了，他兄弟当娶他的妻，为哥哥生子立后。』</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 20:20; 耶利米书 22:30"> 有弟兄七人，第一个娶了妻，没有孩子死了；</span>
<span className="v" id="v30" data-v="30"> 第二个、第三个也娶过她；</span>
<span className="v" id="v31" data-v="31"> 那七个人都娶过她，没有留下孩子就死了。</span>
<span className="v" id="v32" data-v="32" data-xref="传道书 1:4; 传道书 9:5; 希伯来书 9:27"> 后来妇人也死了。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 22:24–28; 马可福音 12:19–23"> 这样，当复活的时候，她是哪一个的妻子呢？因为他们七个人都娶过她。」</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 16:8; 路加福音 17:27; 希伯来书 13:4"> 耶稣说：「这世界的人有娶有嫁；</span>
<span className="v" id="v35" data-v="35" data-xref="帖撒罗尼迦后书 1:5; 约翰福音 5:29; 但以理书 12:2–3"> 惟有算为配得那世界，与从死里复活的人也不娶也不嫁；</span>
<span className="v" id="v36" data-v="36" data-xref="启示录 21:4; 腓立比书 3:21; 马太福音 22:30"> 因为他们不能再死，和天使一样；既是复活的人，就为 神的儿子。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及记 3:2–6; 马可福音 12:26–27; 使徒行传 7:30–32"> 至于死人复活，摩西在荆棘篇上，称主是亚伯拉罕的 神，以撒的 神，雅各的 神，就指示明白了。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 11:25–26; 歌罗西书 3:3–4; 罗马书 6:10–11"> 神原不是死人的 神，乃是活人的 神；因为在他那里<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="那里：或译看来">a</a></sup>，人都是活的。」</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 23:9; 马可福音 12:28–34; 马太福音 22:34–40"> 有几个文士说：「夫子！你说得好。」</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 22:46; 马可福音 12:34; 箴言 26:5"> 以后他们不敢再问他什么。</span>
</div>
</div>

## 谴责文士

<div className="bt">
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="马太福音 15:10; 马可福音 12:38–39; 马可福音 8:34"> 众百姓听的时候，耶稣对门徒说：</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 11:43; 马可福音 12:38–39; 路加福音 14:7"> 「你们要防备文士。他们好穿长衣游行，喜爱人在街市上问他们安，又喜爱会堂里的高位，筵席上的首座；</span>
<span className="v" id="v47" data-v="47" data-xref="马可福音 12:40; 雅各书 3:1; 提多书 1:16"> 他们侵吞寡妇的家产，假意作很长的祷告。这些人要受更重的刑罚！」</span>

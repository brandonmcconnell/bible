## 耶稣受试探

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="马太福音 4:1–11; 使徒行传 10:38; 马可福音 1:12–13"> 耶稣被圣灵充满，从约旦河回来，圣灵将他引到旷野，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 34:28; 希伯来书 4:15; 申命记 9:9"> 四十天受魔鬼的试探。那些日子没有吃什么；日子满了，他就饿了。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 4:3; 路加福音 3:22"> 魔鬼对他说：「你若是 神的儿子，可以吩咐这块石头变成食物。」</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 8:3; 马太福音 4:4; 马太福音 6:31"> 耶稣回答说：「经上记着说：『人活着不是单靠食物，乃是靠 神口里所出的一切话。』」</span>
<span className="v" id="v5" data-v="5" data-xref="约翰一书 2:15–16; 哥林多前书 15:52; 马太福音 4:8"> 魔鬼又领他上了高山，霎时间把天下的万国都指给他看，</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 12:31; 约翰一书 5:19; 约翰福音 14:30"> 对他说：「这一切权柄、荣华，我都要给你，因为这原是交付我的，我愿意给谁就给谁。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 8:28; 诗篇 72:11; 以赛亚书 45:14"> 你若在我面前下拜，这都要归你。」</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 6:13; 申命记 10:20; 马太福音 4:10"> 耶稣说：「经上记着说：<br /><span className="pl pl-1">当拜主—你的 神，</span><br /><span className="pl pl-1">单要事奉他。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="马太福音 4:5–6; 路加福音 4:3; 马太福音 8:29"> 魔鬼又领他到耶路撒冷去，叫他站在殿顶<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="顶：原文是翅">a</a></sup>上，对他说：「你若是 神的儿子，可以从这里跳下去；</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 91:11–12; 希伯来书 1:14; 哥林多后书 11:14"> 因为经上记着说：<br /><span className="pl pl-1">主要为你吩咐他的使者保护你；</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 91:12"> <span className="pl pl-1">他们要用手托着你，</span><br /><span className="pl pl-1">免得你的脚碰在石头上。」</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命记 6:16; 希伯来书 3:8–9; 哥林多前书 10:9"> 耶稣对他说：「经上说：『不可试探主—你的 神。』」</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 4:15; 雅各书 4:7; 马太福音 4:11"> 魔鬼用完了各样的试探，就暂时离开耶稣。</span>
</div>
</div>

## 开始在加利利传道

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 4:23–25; 使徒行传 10:37; 马太福音 4:12"> 耶稣满有圣灵的能力，回到加利利；他的名声就传遍了四方。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 4:23; 马太福音 9:8; 马太福音 9:35"> 他在各会堂里教训人，众人都称赞他。</span>
</div>
</div>

## 拿撒勒人厌弃耶稣

<div className="bt">
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="使徒行传 17:2; 使徒行传 13:14–16; 马太福音 2:23"> 耶稣来到拿撒勒，就是他长大的地方。在安息日，照他平常的规矩进了会堂，站起来要念圣经。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 61:1–3; 使徒行传 13:15; 使徒行传 7:42"> 有人把先知以赛亚的书交给他，他就打开，找到一处写着说：</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 61:1; 马太福音 11:5; 诗篇 146:7–8"> <span className="pl pl-1">主的灵在我身上，</span><br /><span className="pl pl-1">因为他用膏膏我，</span><br /><span className="pl pl-1">叫我传福音给贫穷的人；</span><br /><span className="pl pl-1">差遣我报告：</span><br /><span className="pl pl-1">被掳的得释放，</span><br /><span className="pl pl-1">瞎眼的得看见，</span><br /><span className="pl pl-1">叫那受压制的得自由，</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 61:2; 以赛亚书 63:4; 哥林多后书 6:1"> <span className="pl pl-1">报告 神悦纳人的禧年。</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 4:17; 约翰福音 8:2; 路加福音 19:48"> 于是把书卷起来，交还执事，就坐下。会堂里的人都定睛看他。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 4:25–26; 使徒行传 3:18; 使徒行传 2:16–18"> 耶稣对他们说：「今天这经应验在你们耳中了。」</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 13:54–56; 诗篇 45:2; 使徒行传 6:10"> 众人都称赞他，并希奇他口中所出的恩言；又说：「这不是约瑟的儿子吗？」</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 4:46–53; 马太福音 11:23–24; 马可福音 2:1–12"> 耶稣对他们说：「你们必引这俗语向我说：『医生，你医治自己吧！我们听见你在迦百农所行的事，也当行在你自己家乡里』」；</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 13:57; 约翰福音 4:44; 马可福音 6:4–5"> 又说：「我实在告诉你们，没有先知在自己家乡被人悦纳的。</span>
<span className="v" id="v25" data-v="25" data-xref="雅各书 5:17; 列王纪上 17:1; 马太福音 20:15"> 我对你们说实话，当以利亚的时候，天闭塞了三年零六个月，遍地有大饥荒，那时，以色列中有许多寡妇，</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 17:9–24; 马太福音 11:21; 俄巴底亚书 1:20"> 以利亚并没有奉差往她们一个人那里去，只奉差往西顿的撒勒法一个寡妇那里去。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 5:1–27; 约翰福音 17:12; 马太福音 12:4"> 先知以利沙的时候，以色列中有许多长大麻风的，但内中除了叙利亚国的乃缦，没有一个得洁净的。」</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 5:33; 历代志下 24:20–21; 耶利米书 38:6"> 会堂里的人听见这话，都怒气满胸，</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 8:59; 使徒行传 21:28–32; 民数记 15:35"> 就起来撵他出城（他们的城造在山上）；他们带他到山崖，要把他推下去。</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 10:39; 约翰福音 8:59; 约翰福音 18:6–7"> 他却从他们中间直行，过去了。</span>
</div>
</div>

## 一个污鬼附身的人

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马可福音 1:21–28; 马太福音 4:13; 使徒行传 13:50–2"> 耶稣下到迦百农，就是加利利的一座城，在安息日教训众人。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 4:36; 马太福音 7:28–29; 约翰福音 6:63"> 他们很希奇他的教训，因为他的话里有权柄。</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 1:23"> 在会堂里有一个人，被污鬼的精气附着，大声喊叫说：</span>
<span className="v" id="v34" data-v="34" data-xref="马可福音 1:24; 雅各书 2:19; 马太福音 8:29"> 「唉！拿撒勒的耶稣，我们与你有什么相干？你来灭我们吗？我知道你是谁，乃是 神的圣者。」</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 4:41; 路加福音 4:39; 马太福音 8:26"> 耶稣责备他说：「不要作声，从这人身上出来吧！」鬼把那人摔倒在众人中间，就出来了，却也没有害他。</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 4:32; 彼得前书 3:22; 马太福音 12:22–23"> 众人都惊讶，彼此对问说：「这是什么道理呢？因为他用权柄能力吩咐污鬼，污鬼就出来。」</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 1:45; 路加福音 4:14; 以赛亚书 52:13"> 于是耶稣的名声传遍了周围地方。</span>
</div>
</div>

## 治好许多病人

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="马太福音 8:14–15; 马可福音 1:29–31; 约翰福音 11:22"> 耶稣出了会堂，进了西门的家。西门的岳母害热病甚重，有人为她求耶稣。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 4:41; 路加福音 4:35; 路加福音 8:24"> 耶稣站在她旁边，斥责那热病，热就退了。她立刻起来服事他们。</span>
<span className="v" id="v40" data-v="40" data-xref="马可福音 1:32–34; 马太福音 8:16–17; 马可福音 5:23"> 日落的时候，凡有病人的，不论害什么病，都带到耶稣那里。耶稣按手在他们各人身上，医好他们。</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 1:34; 雅各书 2:19; 路加福音 4:34–35"> 又有鬼从好些人身上出来，喊着说：「你是 神的儿子。」耶稣斥责他们，不许他们说话，因为他们知道他是基督。</span>
</div>
</div>

## 在加利利各会堂传道

<div className="bt">
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="路加福音 6:12; 马可福音 1:35–38; 约翰福音 4:34"> 天亮的时候，耶稣出来，走到旷野地方。众人去找他，到了他那里，要留住他，不要他离开他们。</span>
<span className="v" id="v43" data-v="43" data-xref="马可福音 1:38–39; 提摩太后书 4:2; 约翰福音 9:4"> 但耶稣对他们说：「我也必须在别城传 神国的福音，因我奉差原是为此。」</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 4:23; 马可福音 1:39; 路加福音 4:15"> 于是耶稣在加利利的各会堂传道。</span>
</div>

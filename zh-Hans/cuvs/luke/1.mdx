## 预言施洗约翰的诞生

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="历代志上 24:10; 马太福音 2:1; 尼希米记 12:4"> 当犹太王希律的时候，亚比雅班里有一个祭司，名叫撒迦利亚；他妻子是亚伦的后人，名叫伊利莎白。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 7:1; 创世记 17:1; 腓立比书 2:15"> 他们二人在 神面前都是义人，遵行主的一切诫命礼仪，没有可指摘的，</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 11:11; 创世记 18:11; 撒母耳记上 1:2"> 只是没有孩子；因为伊利莎白不生育，两个人又年纪老迈了。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 8:14; 历代志上 24:19; 历代志下 31:2"> 撒迦利亚按班次在 神面前供祭司的职分，</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 29:11; 出埃及记 30:7–8; 历代志上 23:13"> 照祭司的规矩掣签，得进主殿烧香。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 16:17; 启示录 8:3; 希伯来书 4:14"> 烧香的时候，众百姓在外面祷告。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 40:26–27; 使徒行传 10:3–4; 士师记 13:3"> 有主的使者站在香坛的右边，向他显现。</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 13:22; 士师记 6:22; 路加福音 2:9–10"> 撒迦利亚看见，就惊慌害怕。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 2:21; 使徒行传 10:31; 创世记 25:21"> 天使对他说：「撒迦利亚，不要害怕，因为你的祈祷已经被听见了。你的妻子伊利莎白要给你生一个儿子，你要给他起名叫约翰。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 1:58; 箴言 23:24; 创世记 21:6"> 你必欢喜快乐；有许多人因他出世，也必喜乐。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 1:5; 民数记 6:2–4; 路加福音 7:33"> 他在主面前将要为大，淡酒浓酒都不喝，从母腹里就被圣灵充满了。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 40:3–5; 马太福音 21:32; 玛拉基书 3:1"> 他要使许多以色列人回转，归于主—他们的 神。</span>
<span className="v" id="v17" data-v="17" data-xref="玛拉基书 4:5–6; 马太福音 11:14; 路加福音 1:76"> 他必有以利亚的心志能力，行在主的前面，叫为父的心转向儿女，叫悖逆的人转从义人的智慧，又为主预备合用的百姓。」</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 38:22; 创世记 17:17; 路加福音 1:7"> 撒迦利亚对天使说：「我凭着什么可知道这事呢？我已经老了，我的妻子也年纪老迈了。」</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 1:26; 马太福音 18:10; 但以理书 9:21–23"> 天使回答说：「我是站在 神面前的加百列，奉差而来对你说话，将这好信息报给你。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 3:26; 以西结书 24:27; 路加福音 1:22"> 到了时候，这话必然应验；只因你不信，你必哑巴，不能说话，直到这事成就的日子。」</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 6:23–27"> 百姓等候撒迦利亚，诧异他许久在殿里。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 1:62; 约翰福音 13:24; 使徒行传 21:40"> 及至他出来，不能和他们说话，他们就知道他在殿里见了异象；因为他直向他们打手式，竟成了哑巴。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 9:25; 列王纪下 11:5–7"> 他供职的日子已满，就回家去了。</span>
<span className="v" id="v24" data-v="24"> 这些日子以后，他的妻子伊利莎白怀了孕，就隐藏了五个月，</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 30:22–23; 以赛亚书 54:1–4; 创世记 21:1–2"> 说：「主在眷顾我的日子，这样看待我，要把我在人间的羞耻除掉。」</span>
</div>
</div>

## 预言耶稣的降生

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 2:23; 路加福音 1:19; 约翰福音 7:41"> 到了第六个月，天使加百列奉 神的差遣往加利利的一座城去（这城名叫拿撒勒），</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 1:18; 以赛亚书 7:14; 马太福音 1:16"> 到一个童女那里，是已经许配大卫家的一个人，名叫约瑟。童女的名字叫马利亚；</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 6:12; 但以理书 10:19; 路加福音 1:30"> 天使进去，对她说：「蒙大恩的女子，我问你安，主和你同在了！」</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 10:17; 路加福音 1:12; 使徒行传 10:4"> 马利亚因这话就很惊慌，又反复思想这样问安是什么意思。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 1:13; 罗马书 8:31; 路加福音 12:32"> 天使对她说：「马利亚，不要怕！你在 神面前已经蒙恩了。</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 7:14; 马太福音 1:21; 马太福音 1:25"> 你要怀孕生子，可以给他起名叫耶稣。</span>

<span className="v" id="v36" data-v="36"> 况且你的亲戚伊利莎白，在年老的时候也怀了男胎，就是那素来称为不生育的，现在有孕六个月了。</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 19:26; 耶利米书 32:27; 马可福音 10:27"> 因为，出于 神的话，没有一句不带能力的。」</span>
<span className="v" id="v38" data-v="38" data-xref="罗马书 4:20–21; 诗篇 119:38; 诗篇 116:16"> 马利亚说：「我是主的使女，情愿照你的话成就在我身上。」天使就离开她去了。</span>
</div>
</div>

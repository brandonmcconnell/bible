## 预言圣殿被毁

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 2:20; 马太福音 24:1–51; 马可福音 13:1–37"> 有人谈论圣殿是用美石和供物妆饰的；</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 24:2; 马可福音 13:2; 耶利米哀歌 5:18"> 耶稣就说：「论到你们所看见的这一切，将来日子到了，在这里没有一块石头留在石头上，不被拆毁了。」</span>
</div>
</div>

## 预兆和逼迫

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行传 1:6–7; 马可福音 13:14; 马可福音 13:3–4"> 他们问他说：「夫子！什么时候有这事呢？这事将到的时候有什么预兆呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="约翰一书 4:1; 马可福音 13:5–6; 以弗所书 5:6"> 耶稣说：「你们要谨慎，不要受迷惑；因为将来有好些人冒我的名来，说：『我是基督』，又说：『时候近了』，你们不要跟从他们！</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 21:28; 马太福音 24:6–8; 马可福音 13:7–8"> 你们听见打仗和扰乱的事，不要惊惶；因为这些事必须先有，只是末期不能立时就到。」</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 2:19–20; 马可福音 13:8; 历代志下 15:5–6"> 当时，耶稣对他们说：「民要攻打民，国要攻打国；</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 24:29–30; 路加福音 21:25–27"> 地要大大震动，多处必有饥荒、瘟疫，又有可怕的异象和大神迹从天上显现。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 4:12–14; 使徒行传 5:40; 使徒行传 22:30"> 但这一切的事以先，人要下手拿住你们，逼迫你们，把你们交给会堂，并且收在监里，又为我的名拉你们到君王诸侯面前。</span>
<span className="v" id="v13" data-v="13" data-xref="腓立比书 1:12; 腓立比书 1:28; 帖撒罗尼迦后书 1:5"> 但这些事终必为你们的见证。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 12:11–12; 马可福音 13:11; 马太福音 10:19–20"> 所以，你们当立定心意，不要预先思想怎样分诉；</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 1:9; 以弗所书 6:19; 路加福音 12:12"> 因为我必赐你们口才、智慧，是你们一切敌人所敌不住、驳不倒的。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 12:53; 启示录 6:9; 弥迦书 7:5–6"> 连你们的父母、弟兄、亲族、朋友也要把你们交官；你们也有被他们害死的。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 15:19; 路加福音 6:22; 约翰福音 15:21"> 你们要为我的名被众人恨恶，</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 10:30; 撒母耳记上 14:45; 路加福音 12:7"> 然而，你们连一根头发也必不损坏。</span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 10:36; 马太福音 10:22; 雅各书 1:3"> 你们常存忍耐，就必保全灵魂<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：必得生命">a</a></sup>。」</span>
</div>
</div>

## 预言耶路撒冷被毁

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 19:43; 但以理书 9:27; 马可福音 13:14"> 「你们看见耶路撒冷被兵围困，就可知道它成荒场的日子近了。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 6:1; 创世记 19:17; 路加福音 17:31–33"> 那时，在犹太的应当逃到山上；在城里的应当出来；在乡下的不要进城；</span>
<span className="v" id="v22" data-v="22" data-xref="何西阿书 9:7; 以赛亚书 65:12–16; 以赛亚书 63:4"> 因为这是报应的日子，使经上所写的都得应验。</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 13:17; 马太福音 24:19; 路加福音 23:29"> 当那些日子，怀孕的和奶孩子的有祸了！因为将有大灾难降在这地方，也有震怒临到这百姓。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 11:25; 启示录 11:2; 以赛亚书 63:18"> 他们要倒在刀下，又被掳到各国去。耶路撒冷要被外邦人践踏，直到外邦人的日期满了。」</span>
</div>
</div>

## 人子的降临

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 13:10; 约珥书 2:30–31; 启示录 6:12–14"> 「日、月、星辰要显出异兆，地上的邦国也有困苦；因海中波浪的响声，就慌慌不定。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 24:29; 申命记 28:65–67; 彼得后书 3:10–12"> 天势都要震动，人想起那将要临到世界的事，就都吓得魂不附体。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 24:30; 启示录 1:7; 马可福音 13:26"> 那时，他们要看见人子有能力，有大荣耀驾云降临。</span>
<span className="v" id="v28" data-v="28" data-xref="罗马书 8:23; 以赛亚书 60:1–2; 以弗所书 4:30"> 一有这些事，你们就当挺身昂首，因为你们得赎的日子近了。」</span>
</div>

## 从无花果树学功课

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马太福音 24:32–35; 马可福音 13:28–30"> 耶稣又设比喻对他们说：「你们看无花果树和各样的树；它发芽的时候，你们一看见，自然晓得夏天近了。</span>
<span className="v" id="v31" data-v="31" data-xref="雅各书 5:9; 希伯来书 10:37; 彼得前书 4:7"> 这样，你们看见这些事渐渐地成就，也该晓得 神的国近了。</span>
<span className="v" id="v32" data-v="32" data-xref="马可福音 13:30; 马太福音 24:34; 马太福音 23:36"> 我实在告诉你们，这世代还没有过去，这些事都要成就。</span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 40:8; 马可福音 13:31; 马太福音 24:35"> 天地要废去，我的话却不能废去。」</span>
</div>

## 劝告门徒警醒

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马可福音 4:19; 路加福音 12:45–46; 路加福音 12:40"> 「你们要谨慎，恐怕因贪食、醉酒，并今生的思虑累住你们的心，那日子就如同网罗忽然临到你们；</span>
<span className="v" id="v35" data-v="35" data-xref="启示录 16:15; 诗篇 11:6; 耶利米书 48:43–44"> 因为那日子要这样临到全地上一切居住的人。</span>
<span className="v" id="v36" data-v="36" data-xref="约翰一书 2:28; 马太福音 25:13; 彼得前书 5:8"> 你们要时时警醒，常常祈求，使你们能逃避这一切要来的事，得以站立在人子面前。」</span>

<span className="v" id="v38" data-v="38" data-xref="约翰福音 8:1–2"> 众百姓清早上圣殿，到耶稣那里，要听他讲道。</span>

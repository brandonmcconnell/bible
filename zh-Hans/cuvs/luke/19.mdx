## 耶稣和撒该

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 6:1–27; 路加福音 18:35; 列王纪下 2:18–22"> 耶稣进了耶利哥，正经过的时候，</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 18:24–27; 历代志下 17:5–6"> 有一个人名叫撒该，作税吏长，是个财主。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 23:8; 路加福音 9:7–9; 约翰福音 12:21"> 他要看看耶稣是怎样的人；只因人多，他的身量又矮，所以不得看见，</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 9:10; 路加福音 5:19; 列王纪上 10:27"> 就跑到前头，爬上桑树，要看耶稣，因为耶稣必从那里经过。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 3:20; 约翰福音 14:23; 希伯来书 13:2"> 耶稣到了那里，抬头一看，对他说：「撒该，快下来！今天我必住在你家里。」</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 5:29; 使徒行传 16:34; 使徒行传 16:15"> 他就急忙下来，欢欢喜喜地接待耶稣。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 15:2; 路加福音 7:39; 路加福音 7:34"> 众人看见，都私下议论说：「他竟到罪人家里去住宿。」</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 12:6; 民数记 5:7; 路加福音 18:22–23"> 撒该站着对主说：「主啊，我把所有的一半给穷人；我若讹诈了谁，就还他四倍。」</span>
<span className="v" id="v9" data-v="9" data-xref="加拉太书 3:7; 路加福音 13:16; 罗马书 4:16"> 耶稣说：「今天救恩到了这家，因为他也是亚伯拉罕的子孙。</span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 34:16; 马太福音 1:21; 提摩太前书 1:13–16"> 人子来，为要寻找、拯救失丧的人。」</span>
</div>
</div>

## 十锭银子的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路加福音 17:20; 使徒行传 1:6; 帖撒罗尼迦后书 2:1–3"> 众人正在听见这些话的时候，耶稣因为将近耶路撒冷，又因他们以为 神的国快要显出来，就另设一个比喻，说：</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 25:14–30; 路加福音 19:12–27; 路加福音 20:9"> 「有一个贵胄往远方去，要得国回来，</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 25:14–15; 约翰福音 12:26; 哥林多前书 12:7–11"> 便叫了他的十个仆人来，交给他们十锭<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="锭：原文作弥拿，一弥拿约银十两">a</a></sup>银子，说：『你们去做生意，直等我回来。』</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 8:7; 使徒行传 7:51–52; 使徒行传 3:14–15"> 他本国的人却恨他，打发使者随后去，说：『我们不愿意这个人作我们的王。』</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 4:1–5; 罗马书 14:10–12; 诗篇 2:4–6"> 他既得国回来，就吩咐叫那领银子的仆人来，要知道他们做生意赚了多少。</span>
<span className="v" id="v16" data-v="16" data-xref="雅各书 2:18–26; 提摩太后书 4:7–8; 哥林多前书 15:10"> 头一个上来，说：『主啊，你的一锭银子已经赚了十锭。』</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 16:10; 马太福音 25:21; 启示录 2:26–29"> 主人说：『好！良善的仆人，你既在最小的事上有忠心，可以有权柄管十座城。』</span>
<span className="v" id="v18" data-v="18" data-xref="马可福音 4:20; 马太福音 13:23; 哥林多后书 8:12"> 第二个来，说：『主啊，你的一锭银子已经赚了五锭。』</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 15:58; 哥林多前书 15:41–42; 哥林多前书 3:8"> 主人说：『你也可以管五座城。』</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 25:24; 箴言 26:13–16; 雅各书 4:17"> 又有一个来说：『主啊，看哪，你的一锭银子在这里，我把它包在手巾里存着。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 25:24–25; 罗马书 8:7; 约翰一书 4:18"> 我原是怕你，因为你是严厉的人；没有放下的，还要去拿，没有种下的，还要去收。』</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 1:16; 马太福音 12:37; 约伯记 15:5–6"> 主人对他说：『你这恶仆，我要凭你的口定你的罪。你既知道我是严厉的人，没有放下的，还要去拿，没有种下的，还要去收，</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 22:25–27; 罗马书 2:4–5; 申命记 23:19–20"> 为什么不把我的银子交给银行，等我来的时候，连本带利都可以要回来呢？』</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 16:2; 路加福音 12:20"> 就对旁边站着的人说：『夺过他这一锭来，给那有十锭的。』</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 16:2; 撒母耳记下 7:19; 以赛亚书 55:8–9"> 他们说：『主啊，他已经有十锭了。』</span>
<span className="v" id="v26" data-v="26" data-xref="约翰二书 1:8; 路加福音 8:18; 马太福音 21:43"> 主人说：『我告诉你们，凡有的，还要加给他；没有的，连他所有的也要夺过来。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 19:14; 诗篇 21:8–9; 马太福音 22:7"> 至于我那些仇敌，不要我作他们王的，把他们拉来，在我面前杀了吧！』」</span>
</div>
</div>

## 光荣地进耶路撒冷

<div className="bt">
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="路加福音 9:51; 希伯来书 12:2; 彼得前书 4:1"> 耶稣说完了这话，就在前面走，上耶路撒冷去。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 1:12; 马太福音 21:17; 马太福音 21:1–11"> 将近伯法其和伯大尼，在一座山名叫橄榄山那里，就打发两个门徒，说：</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 22:8–13; 路加福音 19:32; 撒母耳记上 10:2–9"> 「你们往对面村子里去，进去的时候，必看见一匹驴驹拴在那里，是从来没有人骑过的，可以解开牵来。</span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 24:1; 诗篇 50:10–12; 马可福音 11:3–6"> 若有人问为什么解它，你们就说：『主要用它。』」</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 22:13"> 打发的人去了，所遇见的正如耶稣所说的。</span>
<span className="v" id="v33" data-v="33"> 他们解驴驹的时候，主人问他们说：「解驴驹做什么？」</span>
<span className="v" id="v34" data-v="34" data-xref="撒迦利亚书 9:9; 约翰福音 10:35; 哥林多后书 8:9"> 他们说：「主要用它。」</span>
<span className="v" id="v35" data-v="35" data-xref="马可福音 11:7–8; 马太福音 21:7; 约翰福音 12:14"> 他们牵到耶稣那里，把自己的衣服搭在上面，扶着耶稣骑上。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪下 9:13; 马太福音 21:8"> 走的时候，众人把衣服铺在路上。</span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 12:12–13; 以斯拉记 3:10–13; 马太福音 21:1"> 将近耶路撒冷，正下橄榄山的时候，众门徒因所见过的一切异能，都欢乐起来，大声赞美 神，</span>
<span className="v" id="v38" data-v="38" data-xref="撒迦利亚书 9:9; 路加福音 13:35; 诗篇 118:22–26"> 说：<br /><span className="pl pl-1">奉主名来的王是应当称颂的！</span><br /><span className="pl pl-1">在天上有和平；</span><br /><span className="pl pl-1">在至高之处有荣光。</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒行传 4:1–2; 马太福音 23:13; 使徒行传 4:16–18"> 众人中有几个法利赛人对耶稣说：「夫子，责备你的门徒吧！」</span>
<span className="v" id="v40" data-v="40" data-xref="哈巴谷书 2:11; 以赛亚书 55:12; 马太福音 3:9"> 耶稣说：「我告诉你们，若是他们闭口不说，这些石头必要呼叫起来。」</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 13:34–35; 约翰福音 11:35; 诗篇 119:136"> 耶稣快到耶路撒冷，看见城，就为它哀哭，</span>
<span className="v" id="v42" data-v="42" data-xref="申命记 32:29; 希伯来书 10:26–29; 以赛亚书 48:18"> 说：「巴不得你在这日子知道关系你平安的事；无奈这事现在是隐藏的，叫你的眼看不出来。</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 21:20–24; 以赛亚书 29:1–4; 以西结书 4:2"> 因为日子将到，你的仇敌必筑起土垒，周围环绕你，四面困住你，</span>
<span className="v" id="v44" data-v="44" data-xref="路加福音 21:6; 路加福音 13:34–35; 约翰福音 3:18–21"> 并要扫灭你和你里头的儿女，连一块石头也不留在石头上，因你不知道眷顾你的时候。」</span>
</div>
</div>

## 洁净圣殿

<div className="bt">
<div className="bp poetry">
<span className="v" id="v45" data-v="45" data-xref="马太福音 21:12–13; 马可福音 11:15–17; 约翰福音 2:13–17"> 耶稣进了殿，赶出里头做买卖的人，</span>
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 56:7; 耶利米书 7:11; 诗篇 93:5"> 对他们说：「经上说：<br /><span className="pl pl-1">我的殿必作祷告的殿，</span><br /><span className="pl pl-1">你们倒使它成为贼窝了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="马可福音 11:18; 马太福音 26:55; 马可福音 11:27–33"> 耶稣天天在殿里教训人。祭司长和文士与百姓的尊长都想要杀他，</span>
<span className="v" id="v48" data-v="48" data-xref="尼希米记 8:3; 使徒行传 16:14; 约翰福音 7:46–49"> 但寻不出法子来，因为百姓都侧耳听他。</span>
</div>

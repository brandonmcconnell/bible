## 主差遣七十人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 6:7–13; 路加福音 9:52; 民数记 11:24–26"> 这事以后，主又设立七十个人，差遣他们两个两个地在他前面，往自己所要到的各城各地方去，</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 9:36–38; 约翰福音 4:35–38; 哥林多前书 3:6–9"> 就对他们说：「要收的庄稼多，做工的人少。所以，你们当求庄稼的主打发工人出去收他的庄稼。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 10:16; 使徒行传 20:29; 以西结书 2:3–6"> 你们去吧！我差你们出去，如同羊羔进入狼群。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 22:35; 列王纪下 4:29; 路加福音 10:4–12"> 不要带钱囊，不要带口袋，不要带鞋；在路上也不要问人的安。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 25:6; 马太福音 10:12–13; 以赛亚书 57:19"> 无论进哪一家，先要说：『愿这一家平安。』</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦后书 3:16; 哥林多后书 2:15–16; 以弗所书 5:6"> 那里若有当得平安的人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="当得平安的人：原文是平安之子">a</a></sup>，你们所求的平安就必临到那家；不然，就归与你们了。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前书 5:17–18; 马太福音 10:10–11; 加拉太书 6:6"> 你们要住在那家，吃喝他们所供给的，因为工人得工价是应当的；不要从这家搬到那家。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 10:27; 马太福音 10:40; 路加福音 10:10"> 无论进哪一城，人若接待你们，给你们摆上什么，你们就吃什么。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 3:2; 约翰福音 3:5; 路加福音 10:11"> 要医治那城里的病人，对他们说：『 神的国临近你们了。』</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 18:6; 马太福音 10:14; 使徒行传 13:51"> 无论进哪一城，人若不接待你们，你们就到街上去，</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 10:9; 使徒行传 13:51; 使徒行传 13:26"> 说：『就是你们城里的尘土黏在我们的脚上，我们也当着你们擦去。虽然如此，你们该知道 神的国临近了。』</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 10:15; 马太福音 11:24; 耶利米哀歌 4:6"> 我告诉你们，当审判的日子，所多玛所受的，比那城还容易受呢！」</span>
</div>
</div>

## 不悔改的城有祸了

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 23:1–18; 约珥书 3:4–8; 以西结书 26:1–26"> 「哥拉汛哪，你有祸了！伯赛大啊，你有祸了！因为在你们中间所行的异能若行在泰尔、西顿，他们早已披麻蒙灰，坐在地上悔改了。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 15:22–25; 罗马书 2:1; 路加福音 12:47–48"> 当审判的日子，泰尔、西顿所受的，比你们还容易受呢！</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 14:13–15; 马太福音 4:13; 路加福音 13:28"> 迦百农啊，你已经升到天上<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：你将要升到天上吗">b</a></sup>，将来必推下阴间。」</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 13:20; 马太福音 10:40; 帖撒罗尼迦前书 4:8"> 又对门徒说：「听从你们的就是听从我；弃绝你们的就是弃绝我；弃绝我的就是弃绝那差我来的。」</span>
</div>
</div>

## 七十个人回来

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 16:20; 马可福音 16:17; 路加福音 9:1"> 那七十个人欢欢喜喜地回来，说：「主啊！因你的名，就是鬼也服了我们。」</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 12:7–9; 以赛亚书 14:12; 启示录 9:1"> 耶稣对他们说：「我曾看见撒但从天上坠落，像闪电一样。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 91:13; 马可福音 16:18; 罗马书 16:20"> 我已经给你们权柄可以践踏蛇和蝎子，又胜过仇敌一切的能力，断没有什么能害你们。</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 20:15; 启示录 20:12; 希伯来书 12:23"> 然而，不要因鬼服了你们就欢喜，要因你们的名记录在天上欢喜。」</span>
</div>
</div>

## 耶稣的欢乐

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 4:3; 马太福音 13:11–16; 马太福音 11:25–27"> 正当那时，耶稣被圣灵感动就欢乐，说：「父啊，天地的主，我感谢你！因为你将这些事向聪明通达人就藏起来，向婴孩就显出来。父啊！是的，因为你的美意本是如此。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 11:27; 约翰福音 1:18; 约翰福音 6:44–46"> 一切所有的都是我父交付我的；除了父，没有人知道子是谁；除了子和子所愿意指示的，没有人知道父是谁。」</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 13:16–17"> 耶稣转身暗暗地对门徒说：「看见你们所看见的，那眼睛就有福了。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 8:56; 希伯来书 11:13; 彼得前书 1:10–12"> 我告诉你们，从前有许多先知和君王要看你们所看的，却没有看见，要听你们所听的，却没有听见。」</span>
</div>
</div>

## 好撒马利亚人

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马太福音 22:34–39; 路加福音 18:18; 马太福音 19:16–19"> 有一个律法师起来试探耶稣， 说：「夫子！我该做什么才可以承受永生？」</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 10:5; 以赛亚书 8:20; 加拉太书 3:21–22"> 耶稣对他说：「律法上写的是什么？你念的是怎样呢？」</span>
<span className="v" id="v27" data-v="27" data-xref="马可福音 12:30–31; 马太福音 22:37–40; 申命记 6:5"> 他回答说：「你要尽心、尽性、尽力、尽意爱主—你的 神；又要爱邻舍如同自己。」</span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 20:11; 利未记 18:5; 马太福音 19:17"> 耶稣说：「你回答的是；你这样行，就必得永生。」</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 16:15; 罗马书 4:2; 利未记 19:34"> 那人要显明自己有理，就对耶稣说：「谁是我的邻舍呢？」</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 88:4; 路加福音 18:31; 耶利米哀歌 2:12"> 耶稣回答说：「有一个人从耶路撒冷下耶利哥去，落在强盗手中。他们剥去他的衣裳，把他打个半死，就丢下他走了。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰一书 3:16–18; 诗篇 69:20; 耶利米书 5:31"> 偶然有一个祭司从这条路下来，看见他就从那边过去了。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 27:10; 使徒行传 18:17; 诗篇 109:25"> 又有一个利未人来到这地方，看见他，也照样从那边过去了。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪上 8:50; 耶利米书 38:7–13; 路加福音 7:13"> 惟有一个撒马利亚人行路来到那里，看见他就动了慈心，</span>
<span className="v" id="v34" data-v="34" data-xref="罗马书 12:20; 诗篇 147:3; 帖撒罗尼迦前书 5:15"> 上前用油和酒倒在他的伤处，包裹好了，扶他骑上自己的牲口，带到店里去照应他。</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 19:17; 路加福音 14:13; 罗马书 16:23"> 第二天拿出二钱银子来，交给店主，说：『你且照应他；此外所费用的，我回来必还你。』</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 7:42; 马太福音 21:28–31; 马太福音 17:25"> 你想，这三个人哪一个是落在强盗手中的邻舍呢？」</span>
<span className="v" id="v37" data-v="37" data-xref="约翰一书 3:16–18; 弥迦书 6:8; 彼得前书 2:21"> 他说：「是怜悯他的。」耶稣说：「你去照样行吧。」</span>
</div>
</div>

## 耶稣探望马大和马利亚

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="约翰福音 11:19–20; 约翰福音 11:1–5; 约翰福音 12:1–3"> 他们走路的时候，耶稣进了一个村庄。有一个女人，名叫马大，接他到自己家里。</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 8:34; 路加福音 8:35; 约翰福音 12:3"> 她有一个妹子，名叫马利亚，在耶稣脚前坐着听他的道。</span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 6:27; 路加福音 12:29; 马太福音 14:15"> 马大伺候的事多，心里忙乱，就进前来，说：「主啊，我的妹子留下我一个人伺候，你不在意吗？请吩咐她来帮助我。」</span>
<span className="v" id="v41" data-v="41" data-xref="腓立比书 4:6; 路加福音 21:34; 马太福音 6:25–34"> 耶稣回答说：「马大！马大！你为许多的事思虑烦扰，</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 27:4; 诗篇 16:5–6; 约翰福音 10:27–28"> 但是不可少的只有一件；马利亚已经选择那上好的福分，是不能夺去的。」</span>
</div>
</div>

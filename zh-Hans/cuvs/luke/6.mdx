## 安息日的问题

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 23:25; 马可福音 2:23–28; 马太福音 12:1–8"> 有一个安息日，耶稣从麦地经过。他的门徒掐了麦穗，用手搓着吃。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 12:2; 约翰福音 5:16; 约翰福音 5:9–11"> 有几个法利赛人说：「你们为什么做安息日不可做的事呢？」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 21:3–6; 马可福音 2:25–26; 马太福音 12:3–5"> 耶稣对他们说：「经上记着大卫和跟从他的人饥饿之时所做的事，连这个你们也没有念过吗？</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 24:5–9"> 他怎么进了 神的殿，拿陈设饼吃，又给跟从的人吃？这饼除了祭司以外，别人都不可吃。」</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 2:27; 启示录 1:10; 马可福音 9:7"> 又对他们说：「人子是安息日的主。」</span>
</div>
</div>

## 治好枯干了一只手的人

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="马可福音 3:1–6; 马太福音 12:9–14; 路加福音 4:31"> 又有一个安息日，耶稣进了会堂教训人，在那里有一个人右手枯干了。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 20:20; 诗篇 38:12; 路加福音 13:14"> 文士和法利赛人窥探耶稣，在安息日治病不治病，要得把柄去告他。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 42:4; 马太福音 9:4; 路加福音 5:22"> 耶稣却知道他们的意念，就对那枯干一只手的人说：「起来！站在当中。」那人就起来，站着。</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 3:4; 马太福音 12:12–13; 路加福音 14:3"> 耶稣对他们说：「我问你们，在安息日行善行恶，救命害命，哪样是可以的呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 4:6–7; 马可福音 3:5; 约翰福音 5:8"> 他就周围看着他们众人，对那人说：「伸出手来！」他把手一伸，手就复了原。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 2:1–2; 使徒行传 5:33; 传道书 9:3"> 他们就满心大怒，彼此商议怎样处治耶稣。</span>
</div>
</div>

## 挑选十二门徒

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="希伯来书 5:7; 马可福音 6:46; 马可福音 1:35"> 那时，耶稣出去，上山祷告，整夜祷告 神；</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 3:13–19; 马太福音 9:36–4; 启示录 21:14"> 到了天亮，叫他的门徒来，就从他们中间挑选十二个人，称他们为使徒。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 1:13; 马太福音 4:21; 马太福音 4:18"> 这十二个人有西门（耶稣又给他起名叫彼得），还有他兄弟安得烈，又有雅各和约翰，腓力和巴多罗买，</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 9:9; 马可福音 3:18; 使徒行传 1:13"> 马太和多马，亚勒腓的儿子雅各和奋锐党的西门，</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 14:22; 约翰福音 6:70–71; 马可福音 3:18"> 雅各的儿子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：兄弟">a</a></sup>犹大，和卖主的加略人犹大。</span>
</div>
</div>

## 向群众传道

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 11:21; 马太福音 4:23–25; 诗篇 107:17–20"> 耶稣和他们下了山，站在一块平地上；同站的有许多门徒，又有许多百姓，从犹太全地和耶路撒冷，并泰尔、西顿的海边来，都要听他讲道，又指望医治他们的病；</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 17:15; 马太福音 15:22; 使徒行传 5:16"> 还有被污鬼缠磨的，也得了医治。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 14:36; 马可福音 3:10; 使徒行传 5:15–16"> 众人都想要摸他；因为有能力从他身上发出来，医好了他们。</span>
</div>
</div>

## 论福和祸

<div className="bt">
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="雅各书 2:5; 路加福音 6:20–24; 哥林多后书 8:9"> 耶稣举目看着门徒，说：<br /><span className="pl pl-1">你们贫穷的人有福了！</span><br /><span className="pl pl-1">因为 神的国是你们的。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 6:35; 马太福音 5:6; 雅各书 1:12"> <span className="pl pl-1">你们饥饿的人有福了！</span><br /><span className="pl pl-1">因为你们将要饱足。</span><br /><span className="pl pl-1">你们哀哭的人有福了！</span><br /><span className="pl pl-1">因为你们将要喜笑。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="马太福音 5:10–12; 马太福音 10:22; 彼得前书 4:12–16"> 「人为人子恨恶你们，拒绝你们，辱骂你们，弃掉你们的名，以为是恶，你们就有福了！</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 5:41; 启示录 21:7; 启示录 3:12"> 当那日，你们要欢喜跳跃，因为你们在天上的赏赐是大的。他们的祖宗待先知也是这样。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 6:2; 雅各书 5:1–6; 诗篇 49:6–7"> <span className="pl pl-1">但你们富足的人有祸了！</span><br /><span className="pl pl-1">因为你们受过你们的安慰。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 65:13; 雅各书 4:9; 箴言 14:13"> <span className="pl pl-1">你们饱足的人有祸了！</span><br /><span className="pl pl-1">因为你们将要饥饿。</span><br /><span className="pl pl-1">你们喜笑的人有祸了！</span><br /><span className="pl pl-1">因为你们将要哀恸哭泣。</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="约翰福音 15:19; 雅各书 4:4; 马太福音 7:15"> 「人都说你们好的时候，你们就有祸了！因为他们的祖宗待假先知也是这样。」</span>
</div>

## 论爱仇敌

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="帖撒罗尼迦前书 5:15; 路加福音 6:35; 罗马书 12:17–21"> 「只是我告诉你们这听道的人，你们的仇敌，要爱他！恨你们的，要待他好！</span>
<span className="v" id="v28" data-v="28" data-xref="彼得前书 3:9; 哥林多前书 4:12; 罗马书 12:14"> 咒诅你们的，要为他祝福！凌辱你们的，要为他祷告！</span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 10:34; 马太福音 5:39–42; 哥林多后书 11:20"> 有人打你这边的脸，连那边的脸也由他打。有人夺你的外衣，连里衣也由他拿去。</span>
<span className="v" id="v30" data-v="30" data-xref="申命记 15:7–10; 哥林多后书 9:6–14; 马太福音 6:12"> 凡求你的，就给他。有人夺你的东西去，不用再要回来。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 7:12; 加拉太书 5:14; 马太福音 22:39"> 你们愿意人怎样待你们，你们也要怎样待人。</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 5:46–47; 彼得前书 2:19–20"> 你们若单爱那爱你们的人，有什么可酬谢的呢？就是罪人也爱那爱他们的人。</span>
<span className="v" id="v33" data-v="33"> 你们若善待那善待你们的人，有什么可酬谢的呢？就是罪人也是这样行。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 5:42; 路加福音 14:12–14; 路加福音 6:35"> 你们若借给人，指望从他收回，有什么可酬谢的呢？就是罪人也借给罪人，要如数收回。</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 5:44–45; 约翰福音 13:35; 箴言 19:17"> 你们倒要爱仇敌，也要善待他们，并要借给人不指望偿还，你们的赏赐就必大了，你们也必作至高者的儿子，因为他恩待那忘恩的和作恶的。</span>
<span className="v" id="v36" data-v="36" data-xref="以弗所书 5:1–2; 马太福音 5:48; 彼得前书 1:15–16"> 你们要慈悲，像你们的父慈悲一样。」</span>
</div>
</div>

## 不要论断人

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="以弗所书 4:32; 雅各书 5:9; 马太福音 7:1–5"> 「你们不要论断人，就不被论断；你们不要定人的罪，就不被定罪；你们要饶恕人，就必蒙饶恕<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="饶恕：原文是释放">b</a></sup>；</span>
<span className="v" id="v38" data-v="38" data-xref="哥林多后书 9:6–8; 申命记 15:10; 马可福音 4:24"> 你们要给人，就必有给你们的，并且用十足的升斗，连摇带按，上尖下流地倒在你们怀里；因为你们用什么量器量给人，也必用什么量器量给你们。」</span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 15:14; 提摩太后书 3:13; 提摩太前书 6:3–5"> 耶稣又用比喻对他们说：「瞎子岂能领瞎子，两个人不是都要掉在坑里吗？</span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 13:16; 马太福音 10:24–25; 约翰福音 15:20"> 学生不能高过先生；凡学成了的不过和先生一样。</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 8:7; 雅各书 1:24; 罗马书 2:1"> 为什么看见你弟兄眼中有刺，却不想自己眼中有梁木呢？</span>
<span className="v" id="v42" data-v="42" data-xref="罗马书 2:21–29; 帖撒罗尼迦前书 2:10–12; 诗篇 51:9–13"> 你不见自己眼中有梁木，怎能对你弟兄说：『容我去掉你眼中的刺』呢？你这假冒为善的人！先去掉自己眼中的梁木，然后才能看得清楚，去掉你弟兄眼中的刺。」</span>
</div>
</div>

## 树和果子

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="耶利米书 2:21; 马太福音 12:33; 马太福音 7:16–20"> 「因为，没有好树结坏果子，也没有坏树结好果子。</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 12:33; 雅各书 3:12; 加拉太书 5:19–23"> 凡树木看果子，就可以认出它来。人不是从荆棘上摘无花果，也不是从蒺藜里摘葡萄。</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 4:23; 马太福音 12:34–37; 以弗所书 4:29"> 善人从他心里所存的善就发出善来；恶人从他心里所存的恶就发出恶来；因为心里所充满的，口里就说出来。」</span>
</div>
</div>

## 两种盖房子的人

<div className="bt">
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="加拉太书 6:7; 玛拉基书 1:6; 马太福音 7:21–23"> 「你们为什么称呼我『主啊，主啊』却不遵我的话行呢？</span>
<span className="v" id="v47" data-v="47" data-xref="雅各书 1:22–25; 马太福音 7:24–27; 路加福音 11:28"> 凡到我这里来，听见我的话就去行的，我要告诉你们他像什么人：</span>
<span className="v" id="v48" data-v="48" data-xref="哥林多前书 3:10–15; 诗篇 62:2; 马太福音 7:25–26"> 他像一个人盖房子，深深地挖地，把根基安在磐石上；到发大水的时候，水冲那房子，房子总不能摇动，因为根基立在磐石上<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古卷：因为盖造得好">c</a></sup>。</span>
<span className="v" id="v49" data-v="49" data-xref="以西结书 33:31; 雅各书 1:22–26; 马太福音 23:3"> 惟有听见不去行的，就像一个人在土地上盖房子，没有根基；水一冲，随即倒塌了，并且那房子坏的很大。」</span>

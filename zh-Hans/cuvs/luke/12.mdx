## 防备假冒为善

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 2:1; 哥林多前书 5:7–8; 雅各书 3:17"> 这时，有几万人聚集，甚至彼此践踏。耶稣开讲，先对门徒说：「你们要防备法利赛人的酵，就是假冒为善。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 4:22; 路加福音 8:17; 哥林多后书 5:10"> 掩盖的事没有不露出来的；隐藏的事没有不被人知道的。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 10:27; 马太福音 12:36; 传道书 10:20"> 因此，你们在暗中所说的，将要在明处被人听见；在内室附耳所说的，将要在房上被人宣扬。」</span>
</div>
</div>

## 该怕的是谁

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="马太福音 10:28; 耶利米书 1:8; 启示录 2:10"> 「我的朋友，我对你们说，那杀身体以后不能再做什么的，不要怕他们。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得后书 2:4; 马太福音 10:28; 启示录 14:7"> 我要指示你们当怕的是谁：当怕那杀了以后又有权柄丢在地狱里的。我实在告诉你们，正要怕他。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 12:24; 诗篇 145:15–16; 诗篇 147:9"> 五个麻雀不是卖二分银子吗？但在 神面前，一个也不忘记；</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 10:30–31; 马太福音 6:26; 以赛亚书 43:3–4"> 就是你们的头发，也都被数过了。不要惧怕，你们比许多麻雀还贵重！」</span>
</div>
</div>

## 在人的面前承认基督

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="马太福音 10:32–33; 约翰一书 2:23; 罗马书 10:9–10"> 「我又告诉你们，凡在人面前认我的，人子在 神的使者面前也必认他；</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太后书 2:12; 路加福音 9:26; 马可福音 8:38"> 在人面前不认我的，人子在 神的使者面前也必不认他。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 12:31–32; 约翰一书 5:16; 提摩太前书 1:13"> 凡说话干犯人子的，还可得赦免；惟独亵渎圣灵的，总不得赦免。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 10:17–20; 路加福音 21:12–14; 使徒行传 4:5–7"> 人带你们到会堂，并官府和有权柄的人面前，不要思虑怎么分诉，说什么话；</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 21:15; 马太福音 10:20; 使徒行传 4:8"> 因为正在那时候，圣灵要指教你们当说的话。」</span>
</div>
</div>

## 无知财主的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 6:45; 提摩太前书 6:5; 以西结书 33:31"> 众人中有一个人对耶稣说：「夫子！请你吩咐我的兄长和我分开家业。」</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 2:3; 罗马书 2:1; 罗马书 9:20"> 耶稣说：「你这个人！谁立我作你们断事的官，给你们分家业呢？」</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 13:5; 提摩太前书 6:6–10; 诗篇 119:36–37"> 于是对众人说：「你们要谨慎自守，免去一切的贪心，因为人的生命不在乎家道丰富。」</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 26:12–14; 何西阿书 2:8; 创世记 41:47–49"> 就用比喻对他们说：「有一个财主田产丰盛；</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 5:42; 以赛亚书 58:7; 罗马书 12:13"> 自己心里思想说：『我的出产没有地方收藏，怎么办呢？』</span>
<span className="v" id="v18" data-v="18" data-xref="雅各书 3:15; 雅各书 4:15; 路加福音 12:21"> 又说：『我要这么办：要把我的仓房拆了，另盖更大的，在那里好收藏我一切的粮食和财物，</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 27:1; 雅各书 4:13–15; 哥林多前书 15:32"> 然后要对我的灵魂说：灵魂哪，你有许多财物积存，可作多年的费用，只管安安逸逸地吃喝快乐吧！』</span>
<span className="v" id="v20" data-v="20" data-xref="约伯记 27:8; 耶利米书 17:11; 提摩太前书 6:7"> 神却对他说：『无知的人哪，今夜必要你的灵魂；你所预备的要归谁呢？』</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 6:19–20; 路加福音 12:33; 雅各书 2:5"> 凡为自己积财，在 神面前却不富足的，也是这样。」</span>
</div>
</div>

## 不要忧虑

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马太福音 6:25–34; 腓立比书 4:6; 希伯来书 13:5"> 耶稣又对门徒说：「所以我告诉你们，不要为生命忧虑吃什么，为身体忧虑穿什么；</span>
<span className="v" id="v23" data-v="23" data-xref="约伯记 2:6; 箴言 13:8; 约伯记 2:4"> 因为生命胜于饮食，身体胜于衣裳。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 10:31; 诗篇 147:9; 路加福音 12:7"> 你想乌鸦，也不种也不收，又没有仓又没有库， 神尚且养活它。你们比飞鸟是何等地贵重呢！</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 6:27; 马太福音 5:36; 路加福音 19:3"> 你们哪一个能用思虑使寿数多加一刻呢<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：使身量多加一肘呢">a</a></sup>？</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前书 5:7; 诗篇 39:6; 传道书 7:13"> 这最小的事，你们尚且不能做，为什么还忧虑其余的事呢？</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 6:28–30; 路加福音 12:24; 列王纪上 10:1–13"> 你想百合花怎么长起来；它也不劳苦，也不纺线。然而我告诉你们，就是所罗门极荣华的时候，他所穿戴的，还不如这花一朵呢！</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 14:31; 以赛亚书 40:6; 马太福音 6:30"> 你们这小信的人哪，野地里的草今天还在，明天就丢在炉里， 神还给它这样的妆饰，何况你们呢！</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 6:31; 路加福音 12:22; 路加福音 22:35"> 你们不要求吃什么，喝什么，也不要挂心；</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 6:32; 马太福音 6:8; 以弗所书 4:17"> 这都是外邦人所求的。你们必须用这些东西，你们的父是知道的。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 6:33; 希伯来书 13:5; 诗篇 34:9"> 你们只要求他的国，这些东西就必加给你们了。</span>
<span className="v" id="v32" data-v="32" data-xref="希伯来书 12:28; 彼得前书 1:3–5; 启示录 1:6"> 你们这小群，不要惧怕，因为你们的父乐意把国赐给你们。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 19:21; 使徒行传 4:34–35; 使徒行传 2:45"> 你们要变卖所有的周济人，为自己预备永不坏的钱囊，用不尽的财宝在天上，就是贼不能近、虫不能蛀的地方。</span>
<span className="v" id="v34" data-v="34" data-xref="歌罗西书 3:1–3; 马太福音 6:21; 腓立比书 3:20"> 因为，你们的财宝在哪里，你们的心也在那里。」</span>
</div>
</div>

## 警醒的仆人

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="彼得前书 1:13; 以弗所书 6:14; 马太福音 25:4–10"> 「你们腰里要束上带，灯也要点着，</span>
<span className="v" id="v36" data-v="36" data-xref="犹大书 1:20–21; 雅各书 5:7–8; 启示录 3:20"> 自己好像仆人等候主人从婚姻的筵席上回来。他来到，叩门，就立刻给他开门。</span>
<span className="v" id="v37" data-v="37" data-xref="彼得后书 3:14; 马太福音 24:42; 约翰福音 13:4–5"> 主人来了，看见仆人警醒，那仆人就有福了。我实在告诉你们，主人必叫他们坐席，自己束上带，进前伺候他们。</span>
<span className="v" id="v38" data-v="38" data-xref="帖撒罗尼迦前书 5:4–5; 马太福音 25:6"> 或是二更天来，或是三更天来，看见仆人这样，那仆人就有福了。</span>
<span className="v" id="v39" data-v="39" data-xref="彼得后书 3:10; 启示录 3:3; 启示录 16:15"> 家主若知道贼什么时候来，就必警醒，不容贼挖透房屋，这是你们所知道的。</span>
<span className="v" id="v40" data-v="40" data-xref="帖撒罗尼迦前书 5:6; 马太福音 25:13; 罗马书 13:11"> 你们也要预备；因为你们想不到的时候，人子就来了。」</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 13:37; 彼得前书 4:7; 彼得前书 5:8"> 彼得说：「主啊，这比喻是为我们说的呢？还是为众人呢？」</span>
<span className="v" id="v42" data-v="42" data-xref="马太福音 24:45–46; 彼得前书 5:1–4; 希伯来书 13:17"> 主说：「谁是那忠心有见识的管家，主人派他管理家里的人，按时分粮给他们呢？</span>
<span className="v" id="v43" data-v="43"> 主人来到，看见仆人这样行，那仆人就有福了。</span>
<span className="v" id="v44" data-v="44" data-xref="路加福音 22:29–30; 马太福音 24:47; 路加福音 19:17–19"> 我实在告诉你们，主人要派他管理一切所有的。</span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 24:48–50; 启示录 18:7–8; 腓立比书 3:18–19"> 那仆人若心里说：『我的主人必来得迟』，就动手打仆人和使女，并且吃喝醉酒；</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 12:40; 马太福音 24:51; 诗篇 11:5"> 在他想不到的日子，不知道的时辰，那仆人的主人要来，重重地处治他<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：把他腰斩了">b</a></sup>，定他和不忠心的人同罪。</span>
<span className="v" id="v47" data-v="47" data-xref="雅各书 4:17; 约翰福音 9:41; 约翰福音 12:48"> 仆人知道主人的意思，却不预备，又不顺他的意思行，那仆人必多受责打；</span>
<span className="v" id="v48" data-v="48" data-xref="雅各书 3:1; 利未记 5:17; 路加福音 16:10–12"> 惟有那不知道的，做了当受责打的事，必少受责打；因为多给谁，就向谁多取；多托谁，就向谁多要。」</span>
</div>
</div>

## 杀害耶稣的阴谋

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 12:6–23; 马太福音 26:2–5; 约翰福音 11:55–57"> 除酵节（又名逾越节）近了。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 11:47–53; 马太福音 12:14; 路加福音 20:19"> 祭司长和文士想法子怎么才能杀害耶稣，是因他们惧怕百姓。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 13:2; 马可福音 14:10–11; 约翰福音 13:26–27"> 这时，撒但入了那称为加略人犹大的心；他本是十二门徒里的一个。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 4:1; 使徒行传 5:24; 路加福音 22:52"> 他去和祭司长并守殿官商量，怎么可以把耶稣交给他们。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 26:15–16; 使徒行传 1:18; 马太福音 27:3–5"> 他们欢喜，就约定给他银子。</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 14:2; 马太福音 26:5"> 他应允了，就找机会，要趁众人不在跟前的时候把耶稣交给他们。</span>
</div>
</div>

## 预备逾越节的筵席

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 12:18; 马可福音 14:12–16; 哥林多前书 5:7"> 除酵节，须宰逾越羊羔的那一天到了。</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 14:13–16; 使徒行传 4:19; 使徒行传 4:13"> 耶稣打发彼得、约翰，说：「你们去为我们预备逾越节的筵席，好叫我们吃。」</span>
<span className="v" id="v9" data-v="9"> 他们问他说：「要我们在哪里预备？」</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 16:4; 马太福音 26:18–19; 使徒行传 8:26–29"> 耶稣说：「你们进了城，必有人拿着一瓶水迎面而来，你们就跟着他，到他所进的房子里去，</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 11:28; 启示录 3:20; 路加福音 19:34"> 对那家的主人说：『夫子说：客房在哪里？我与门徒好在那里吃逾越节的筵席。』</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 16:14–15; 使徒行传 1:13; 约翰福音 2:25"> 他必指给你们摆设整齐的一间大楼，你们就在那里预备。」</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 21:33; 路加福音 19:32; 约翰福音 2:5"> 他们去了，所遇见的正如耶稣所说的；他们就预备了逾越节的筵席。</span>
</div>
</div>

## 设立主的晚餐

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 26:20; 马可福音 14:17; 申命记 16:6–7"> 时候到了，耶稣坐席，使徒也和他同坐。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 12:50; 约翰福音 4:34; 约翰福音 17:1"> 耶稣对他们说：「我很愿意在受害以先和你们吃这逾越节的筵席。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 14:15; 启示录 19:9; 路加福音 22:30"> 我告诉你们，我不再吃这筵席，直到成就在 神的国里。」</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 22:19; 诗篇 116:13; 申命记 8:10"> 耶稣接过杯来，祝谢了，说：「你们拿这个，大家分着喝。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 26:29; 路加福音 22:16; 马可福音 14:25"> 我告诉你们，从今以后，我不再喝这葡萄汁，直等 神的国来到。」</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 11:23–29; 哥林多前书 10:16; 马可福音 14:22–24"> 又拿起饼来，祝谢了，就擘开，递给他们，说：「这是我的身体，为你们舍的，你们也应当如此行，为的是记念我。」</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 26:28; 哥林多前书 11:25; 撒迦利亚书 9:11"> 饭后也照样拿起杯来，说：「这杯是用我血所立的新约，是为你们流出来的。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 41:9; 约翰福音 13:26; 约翰福音 13:21–22"> 看哪，那卖我之人的手与我一同在桌子上。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 2:23; 诗篇 109:6–15; 诗篇 55:12–15"> 人子固然要照所预定的去世，但卖人子的人有祸了！」</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 13:22–25; 马可福音 14:19; 马太福音 26:22"> 他们就彼此对问，是哪一个要做这事。</span>
</div>
</div>

## 争论谁为大

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 9:46; 马可福音 9:34; 马可福音 10:37–41"> 门徒起了争论，他们中间哪一个可算为大。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 20:25–28; 马可福音 10:41–45"> 耶稣说：「外邦人有君王为主治理他们，那掌权管他们的称为恩主。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前书 5:5; 路加福音 9:48; 马太福音 18:3–5"> 但你们不可这样；你们里头为大的，倒要像年幼的，为首领的，倒要像服事人的。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 20:28; 路加福音 12:37; 约翰福音 13:5–16"> 是谁为大？是坐席的呢？是服事人的呢？不是坐席的大吗？然而，我在你们中间如同服事人的。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 2:18; 希伯来书 4:15; 使徒行传 1:25"> 我在磨炼之中，常和我同在的就是你们。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 25:34; 提摩太后书 2:12; 雅各书 2:5"> 我将国赐给你们，正如我父赐给我一样，</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 19:28; 马太福音 8:11; 启示录 2:26–27"> 叫你们在我国里，坐在我的席上吃喝，并且坐在宝座上，审判以色列十二个支派。」</span>
</div>
</div>

## 预言彼得不认主

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="彼得前书 5:8; 撒迦利亚书 3:1; 约伯记 1:6–12"> 主又说：「西门！西门！撒但想要得着你们，好筛你们像筛麦子一样；</span>
<span className="v" id="v32" data-v="32" data-xref="彼得前书 5:8–10; 约翰福音 21:15–17; 约翰福音 17:9–11"> 但我已经为你祈求，叫你不至于失了信心。你回头以后，要坚固你的弟兄。」</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 14:31; 马太福音 26:33–35; 马可福音 14:29"> 彼得说：「主啊，我就是同你下监，同你受死，也是甘心！」</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 13:38; 马太福音 26:34; 马可福音 14:30"> 耶稣说：「彼得，我告诉你，今日鸡还没有叫，你要三次说不认得我。」</span>
</div>
</div>

## 钱囊、口袋、刀

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 10:9–10; 路加福音 10:4; 诗篇 23:1"> 耶稣又对他们说：「我差你们出去的时候，没有钱囊，没有口袋，没有鞋，你们缺少什么没有？」他们说：「没有。」</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 10:22–25; 帖撒罗尼迦前书 3:4; 帖撒罗尼迦前书 2:14–15"> 耶稣说：「但如今有钱囊的可以带着，有口袋的也可以带着，没有刀的要卖衣服买刀。</span>
<span className="v" id="v37" data-v="37" data-xref="以赛亚书 53:12; 路加福音 23:32; 哥林多后书 5:21"> 我告诉你们，经上写着说：『他被列在罪犯之中。』这话必应验在我身上，因为那关系我的事必然成就。」</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 22:49; 马太福音 26:52–54; 约翰福音 18:36"> 他们说：「主啊，请看！这里有两把刀。」耶稣说：「够了。」</span>
</div>
</div>

## 在橄榄山上祷告

<div className="bt">
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 21:37; 约翰福音 18:1–2; 马太福音 21:1"> 耶稣出来，照常往橄榄山去，门徒也跟随他。</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 6:13; 马太福音 26:36–46; 路加福音 22:46"> 到了那地方，就对他们说：「你们要祷告，免得入了迷惑。」</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 26:39; 马可福音 14:35; 路加福音 18:11"> 于是离开他们约有扔一块石头那么远，跪下祷告，</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 12:27–28; 马太福音 26:39; 马太福音 26:42"> 说：「父啊！你若愿意，就把这杯撤去；然而，不要成就我的意思，只要成就你的意思。」</span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 4:11; 马太福音 26:53; 诗篇 91:11–12"> 有一位天使从天上显现，加添他的力量。</span>
<span className="v" id="v44" data-v="44" data-xref="耶利米哀歌 1:12; 希伯来书 5:7; 诗篇 22:12–21"> 耶稣极其伤痛，祷告更加恳切，汗珠如大血点滴在地上。</span>
<span className="v" id="v45" data-v="45" data-xref="马可福音 14:40–41; 马太福音 26:43; 马太福音 26:40"> 祷告完了，就起来，到门徒那里，见他们因为忧愁都睡着了，</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 22:40; 约拿书 1:6; 路加福音 21:34–36"> 就对他们说：「你们为什么睡觉呢？起来祷告，免得入了迷惑！」</span>
</div>
</div>

## 耶稣被捕

<div className="bt">
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="马可福音 14:41–50; 约翰福音 18:2–11; 路加福音 22:3–6"> 说话之间，来了许多人。那十二个门徒里名叫犹大的，走在前头，就近耶稣，要与他亲嘴。</span>
<span className="v" id="v48" data-v="48" data-xref="马可福音 14:44–46; 撒母耳记下 20:9–10; 箴言 27:6"> 耶稣对他说：「犹大！你用亲嘴的暗号卖人子吗？」</span>
<span className="v" id="v49" data-v="49" data-xref="路加福音 22:38"> 左右的人见光景不好，就说：「主啊！我们拿刀砍可以不可以？」</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 18:10–11; 马可福音 14:47; 罗马书 12:19"> 内中有一个人把大祭司的仆人砍了一刀，削掉了他的右耳。</span>
<span className="v" id="v51" data-v="51" data-xref="罗马书 12:21; 哥林多后书 10:1; 彼得前书 2:21–23"> 耶稣说：「到了这个地步，由他们吧！」就摸那人的耳朵，把他治好了。</span>
<span className="v" id="v52" data-v="52" data-xref="路加福音 22:4; 马可福音 14:48–49; 约翰福音 17:12"> 耶稣对那些来拿他的祭司长和守殿官并长老说：「你们带着刀棒出来拿我，如同拿强盗吗？</span>
<span className="v" id="v53" data-v="53" data-xref="约翰福音 12:27; 以弗所书 6:12; 使徒行传 26:18"> 我天天同你们在殿里，你们不下手拿我。现在却是你们的时候，黑暗掌权了。」</span>
</div>
</div>

## 彼得三次不认主

<div className="bt">
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="马可福音 14:53–54; 马太福音 26:57–58; 约翰福音 18:12–17"> 他们拿住耶稣，把他带到大祭司的宅里。彼得远远地跟着。</span>
<span className="v" id="v55" data-v="55" data-xref="诗篇 26:4–5; 哥林多后书 6:15–17; 马可福音 14:66–72"> 他们在院子里生了火，一同坐着；彼得也坐在他们中间。</span>
<span className="v" id="v56" data-v="56" data-xref="约翰福音 18:17; 马可福音 14:6; 马可福音 14:17"> 有一个使女看见彼得坐在火光里，就定睛看他，说：「这个人素来也是同那人一伙的。」</span>
<span className="v" id="v57" data-v="57" data-xref="约翰一书 1:9; 约翰福音 18:25; 马太福音 26:70"> 彼得却不承认，说：「女子，我不认得他。」</span>
<span className="v" id="v58" data-v="58" data-xref="约翰福音 18:25; 马太福音 26:71–72; 马可福音 14:69–70"> 过了不多的时候，又有一个人看见他，说：「你也是他们一党的。」彼得说：「你这个人！我不是。」</span>
<span className="v" id="v59" data-v="59" data-xref="约翰福音 18:26–27; 马可福音 14:69–70; 马太福音 26:73–74"> 约过了一小时，又有一个人极力地说：「他实在是同那人一伙的，因为他也是加利利人。」</span>
<span className="v" id="v60" data-v="60" data-xref="马太福音 26:74–75; 路加福音 22:34; 马可福音 14:71–72"> 彼得说：「你这个人！我不晓得你说的是什么！」正说话之间，鸡就叫了。</span>
<span className="v" id="v61" data-v="61" data-xref="路加福音 22:34; 以赛亚书 57:15–18; 耶利米书 31:18–20"> 主转过身来看彼得，彼得便想起主对他所说的话：「今日鸡叫以先，你要三次不认我。」</span>
<span className="v" id="v62" data-v="62" data-xref="马太福音 26:75; 哥林多前书 10:12; 马可福音 14:72"> 他就出去痛哭。</span>
</div>
</div>

<span className="v" id="v67" data-v="67" data-xref="马太福音 11:3–5; 约翰福音 8:43–45; 马太福音 26:63–68"> 说：「你若是基督，就告诉我们。」耶稣说：「我若告诉你们，你们也不信；</span>
<span className="v" id="v68" data-v="68" data-xref="路加福音 20:41–44; 路加福音 20:3–7"> 我若问你们，你们也不回答。</span>

<span className="v" id="v71" data-v="71" data-xref="马太福音 26:65–66; 马可福音 14:63–64"> 他们说：「何必再用见证呢？他亲口所说的，我们都亲自听见了。」</span>

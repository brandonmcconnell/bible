## 寡妇和法官的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 4:2; 罗马书 12:12; 帖撒罗尼迦前书 5:17"> 耶稣设一个比喻，是要人常常祷告，不可灰心。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 29:7; 诗篇 8:1–4; 路加福音 18:4"> 说：「某城里有一个官，不惧怕 神，也不尊重世人。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 1:17; 耶利米书 5:28; 申命记 27:19"> 那城里有个寡妇，常到他那里，说：『我有一个对头，求你给我伸冤。』</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 4:12–13; 路加福音 16:3; 路加福音 12:17"> 他多日不准，后来心里说：『我虽不惧怕 神，也不尊重世人，</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 11:8; 路加福音 18:39; 士师记 16:16"> 只因这寡妇烦扰我，我就给她伸冤吧，免得她常来缠磨我！』」</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 7:13"> 主说：「你们听这不义之官所说的话。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 10:35–37; 彼得后书 3:9; 路加福音 11:13"> 神的选民昼夜呼吁他，他纵然为他们忍了多时，岂不终久给他们伸冤吗？</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 10:23–26; 彼得后书 3:8–9; 马太福音 24:9–13"> 我告诉你们，要快快地给他们伸冤了。然而，人子来的时候，遇得见世上有信德吗？」</span>
</div>
</div>

## 法利赛人和税吏的祷告

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 16:15; 箴言 30:12; 以赛亚书 65:5"> 耶稣向那些仗着自己是义人，藐视别人的，设一个比喻，</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 21:31–32; 列王纪上 8:30; 列王纪下 20:5"> 说：「有两个人上殿里去祷告：一个是法利赛人，一个是税吏。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 6:5; 以赛亚书 65:5; 启示录 3:17"> 法利赛人站着，自言自语地祷告说：『 神啊，我感谢你，我不像别人勒索、不义、奸淫，也不像这个税吏。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 11:42; 马太福音 23:23–24; 马太福音 9:14"> 我一个礼拜禁食两次，凡我所得的都捐上十分之一。』</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 9:6; 约翰一书 1:8–10; 提摩太前书 1:15"> 那税吏远远地站着，连举目望天也不敢，只捶着胸说：『 神啊，开恩可怜我这个罪人！』</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 14:11; 路加福音 16:15; 雅各书 4:10"> 我告诉你们，这人回家去比那人倒算为义了；因为，凡自高的，必降为卑；自卑的，必升为高。」</span>
</div>
</div>

## 耶稣为小孩祝福

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="马可福音 10:13–16; 马太福音 19:13–15; 撒母耳记上 1:24"> 有人抱着自己的婴孩来见耶稣，要他摸他们；门徒看见就责备那些人。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 18:3–4; 哥林多前书 14:20; 哥林多前书 7:14"> 耶稣却叫他们来，说：「让小孩子到我这里来，不要禁止他们，因为在 神国的正是这样的人。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 18:3; 马可福音 10:15; 诗篇 131:1–2"> 我实在告诉你们，凡要承受 神国的，若不像小孩子，断不能进去。」</span>
</div>
</div>

## 富足的官寻求永生之道

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马可福音 10:17–31; 使徒行传 16:30; 马太福音 19:16–30"> 有一个官问耶稣说：「良善的夫子，我该做什么事才可以承受永生？」</span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 15:14–16; 雅各书 1:17; 希伯来书 7:26"> 耶稣对他说：「你为什么称我是良善的？除了 神一位之外，再没有良善的。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 20:12–17; 申命记 5:16–21; 罗马书 13:9"> 诫命你是晓得的：『不可奸淫；不可杀人；不可偷盗；不可作假见证；当孝敬父母。』」</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比书 3:6; 罗马书 10:2–3; 马可福音 10:20–21"> 那人说：「这一切我从小都遵守了。」</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 12:33; 提摩太前书 6:18–19; 马太福音 19:21"> 耶稣听见了，就说：「你还缺少一件：要变卖你一切所有的，分给穷人，就必有财宝在天上；你还要来跟从我。」</span>
<span className="v" id="v23" data-v="23" data-xref="以西结书 33:31; 约翰一书 2:15; 约伯记 31:24–25"> 他听见这话，就甚忧愁，因为他很富足。</span>
<span className="v" id="v24" data-v="24" data-xref="箴言 30:9; 雅各书 2:5–7; 马可福音 10:23–27"> 耶稣看见他，就说：「有钱财的人进 神的国是何等的难哪！</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 23:24"> 骆驼穿过针的眼比财主进 神的国还容易呢！」</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 13:23"> 听见的人说：「这样，谁能得救呢？」</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 32:17; 马太福音 19:26; 路加福音 1:37"> 耶稣说：「在人所不能的事，在 神却能。」</span>
<span className="v" id="v28" data-v="28" data-xref="马可福音 10:28; 腓立比书 3:7; 马太福音 19:27"> 彼得说：「看哪，我们已经撇下自己所有的跟从你了。」</span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 10:29–31; 马太福音 10:37–39; 路加福音 14:26–28"> 耶稣说：「我实在告诉你们，人为 神的国撇下房屋，或是妻子、弟兄、父母、儿女，</span>
<span className="v" id="v30" data-v="30" data-xref="希伯来书 13:5–6; 约伯记 42:10; 启示录 2:17"> 没有在今世不得百倍，在来世不得永生的。」</span>
</div>
</div>

## 耶稣第三次预言受难和复活

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马太福音 20:17–19; 以赛亚书 53:1–12; 诗篇 22:1–31"> 耶稣带着十二个门徒，对他们说：「看哪，我们上耶路撒冷去，先知所写的一切事都要成就在人子身上。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 23:11; 以赛亚书 50:6; 以赛亚书 53:3"> 他将要被交给外邦人；他们要戏弄他，凌辱他，吐唾沫在他脸上，</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 15:3–4; 路加福音 24:7; 马太福音 27:63"> 并要鞭打他，杀害他；第三日他要复活。」</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 9:45; 马可福音 9:32; 路加福音 24:25"> 这些事门徒一样也不懂得，意思乃是隐藏的；他们不晓得所说的是什么。</span>
</div>
</div>

## 治好耶利哥的瞎子

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 20:29–34; 马可福音 10:46–52; 路加福音 16:20–21"> 耶稣将近耶利哥的时候，有一个瞎子坐在路旁讨饭。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 21:10–11; 路加福音 15:26"> 听见许多人经过，就问是什么事。</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 2:23; 约翰福音 19:19; 约翰福音 12:35–36"> 他们告诉他，是拿撒勒人耶稣经过。</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 9:27; 路加福音 18:39; 马太福音 15:22"> 他就呼叫说：「大卫的子孙耶稣啊，可怜我吧！」</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 32:26–28; 诗篇 141:1; 路加福音 18:15"> 在前头走的人就责备他，不许他作声；他却越发喊叫说：「大卫的子孙，可怜我吧！」</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 20:31–34; 马可福音 10:48–52"> 耶稣站住，吩咐把他领过来，到了跟前，就问他说：</span>
<span className="v" id="v41" data-v="41" data-xref="列王纪上 3:5–15; 马太福音 20:21–22; 腓立比书 4:6"> 「你要我为你做什么？」他说：「主啊，我要能看见。」</span>
<span className="v" id="v42" data-v="42" data-xref="马太福音 8:3; 路加福音 8:48; 路加福音 17:19"> 耶稣说：「你可以看见！你的信救了你了。」</span>
<span className="v" id="v43" data-v="43" data-xref="诗篇 146:8; 帖撒罗尼迦后书 1:10–12; 以赛亚书 43:21"> 瞎子立刻看见了，就跟随耶稣，一路归荣耀与 神。众人看见这事，也赞美 神。</span>
</div>
</div>

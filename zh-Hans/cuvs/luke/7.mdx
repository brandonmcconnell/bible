## 治好百夫长的仆人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 8:5–13; 路加福音 7:1–10; 马太福音 7:28–29"> 耶稣对百姓讲完了这一切的话，就进了迦百农。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 5:2–3; 创世记 24:27; 约翰福音 4:46–47"> 有一个百夫长所宝贵的仆人害病，快要死了。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 8:5; 约翰福音 4:47; 路加福音 9:38"> 百夫长风闻耶稣的事，就托犹太人的几个长老去求耶稣来救他的仆人。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 3:4; 马太福音 10:11; 路加福音 7:6–7"> 他们到了耶稣那里，就切切地求他说：「你给他行这事是他所配得的；</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 2:11–12; 历代志上 29:3–9; 列王纪上 5:1"> 因为他爱我们的百姓，给我们建造会堂。」</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 5:24; 创世记 32:10; 雅各书 4:6"> 耶稣就和他们同去。离那家不远，百夫长托几个朋友去见耶稣，对他说：「主啊！不要劳动；因你到我舍下，我不敢当。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 107:20; 诗篇 33:9; 路加福音 4:36"> 我也自以为不配去见你，只要你说一句话，我的仆人就必好了。</span>
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 3:22; 使徒行传 23:17; 使徒行传 22:25–26"> 因为我在人的权下，也有兵在我以下，对这个说：『去！』他就去；对那个说：『来！』他就来；对我的仆人说：『你做这事！』他就去做。」</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 15:28; 罗马书 3:1–3; 马太福音 8:10"> 耶稣听见这话，就希奇他，转身对跟随的众人说：「我告诉你们，这么大的信心，就是在以色列中，我也没有遇见过。」</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 4:50–53; 马太福音 8:13; 马太福音 15:28"> 那托来的人回到百夫长家里，看见仆人已经好了。</span>
</div>
</div>

## 使拿因城寡妇之子复活

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 10:38"> 过了不多时<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷：次日">a</a></sup>，耶稣往一座城去，这城名叫拿因，他的门徒和极多的人与他同行。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 8:42; 路加福音 8:52; 列王纪上 17:9"> 将近城门，有一个死人被抬出来。这人是他母亲独生的儿子；他母亲又是寡妇。有城里的许多人同着寡妇送殡。</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 103:13; 以赛亚书 63:9; 诗篇 86:15"> 主看见那寡妇，就怜悯她，对她说：「不要哭！」</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 5:25; 约翰福音 11:43–44; 使徒行传 9:40–41"> 于是进前按着杠，抬的人就站住了。耶稣说：「少年人，我吩咐你，起来！」</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 13:21; 列王纪下 4:32–37; 列王纪上 17:23–24"> 那死人就坐起，并且说话。耶稣便把他交给他母亲。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 9:8; 路加福音 7:39; 路加福音 1:68"> 众人都惊奇，归荣耀与 神，说：「有大先知在我们中间兴起来了！」又说：「 神眷顾了他的百姓！」</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 4:24; 马可福音 6:14; 马太福音 9:26"> 他这事的风声就传遍了犹太和周围地方。</span>
</div>
</div>

## 施洗约翰的门徒来见耶稣

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰福音 3:26; 马太福音 11:2–19"> 约翰的门徒把这些事都告诉约翰。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 9:6–7; 约翰福音 4:25; 创世记 22:18"> 他便叫了两个门徒来，打发他们到主那里去，说：「那将要来的是你吗？还是我们等候别人呢？」</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 7:19"> 那两个人来到耶稣那里，说：「施洗的约翰打发我们来问你：『那将要来的是你吗？还是我们等候别人呢？』」</span>
<span className="v" id="v21" data-v="21" data-xref="马可福音 3:10; 诗篇 90:7–9; 希伯来书 12:6"> 正当那时候，耶稣治好了许多有疾病的，受灾患的，被恶鬼附着的，又开恩叫好些瞎子能看见。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 35:5–6; 以赛亚书 61:1–3; 路加福音 4:18"> 耶稣回答说：「你们去，把所看见所听见的事告诉约翰，就是瞎子看见，瘸子行走，长大麻风的洁净，聋子听见，死人复活，穷人有福音传给他们。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 11:6; 彼得前书 2:7–8; 罗马书 9:32–33"> 凡不因我跌倒的，就有福了！」</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所书 4:14; 约翰福音 1:23; 路加福音 1:80"> 约翰所差来的人既走了，耶稣就对众人讲论约翰说：「你们从前出去到旷野，是要看什么呢？要看风吹动的芦苇吗？</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 59:17; 以斯帖记 8:15; 以斯帖记 1:3"> 你们出去，到底是要看什么？要看穿细软衣服的人吗？那穿华丽衣服、宴乐度日的人是在王宫里。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 1:76; 约翰福音 5:35; 路加福音 20:6"> 你们出去，究竟是要看什么？要看先知吗？我告诉你们，是的，他比先知大多了。</span>
<span className="v" id="v27" data-v="27" data-xref="玛拉基书 3:1; 路加福音 1:76; 马可福音 1:2"> 经上记着说：『我要差遣我的使者在你前面预备道路』，所说的就是这个人。</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 13:16–17; 马太福音 11:11; 歌罗西书 1:25–27"> 我告诉你们，凡妇人所生的，没有一个大过约翰的；然而 神国里最小的比他还大。」</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 3:12; 路加福音 7:35; 使徒行传 18:25"> 众百姓和税吏既受过约翰的洗，听见这话，就以 神为义；</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 13:34; 哥林多后书 6:1; 马太福音 22:35"> 但法利赛人和律法师没有受过约翰的洗，竟为自己废弃了 神 的旨意。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="二十九三十两节或译：众百姓和税吏听见了约翰的话，就受了他的洗，便以 神为义；但法利赛人和律法师不受约翰的洗，竟为自己废弃了 神的旨意。">b</a></sup></span>
</div>
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="马太福音 11:16–19; 耶利米哀歌 2:13; 马可福音 4:30"> 主又说：「这样，我可用什么比这世代的人呢？他们好像什么呢？</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 11:16–19; 耶利米书 5:3–5; 箴言 17:16"> 好像孩童坐在街市上，彼此呼叫说：<br /><span className="pl pl-1">我们向你们吹笛，</span><br /><span className="pl pl-1">你们不跳舞；</span><br /><span className="pl pl-1">我们向你们举哀，</span><br /><span className="pl pl-1">你们不啼哭。</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 1:15; 马可福音 1:6; 约翰福音 8:52"> 施洗的约翰来，不吃饼，不喝酒，你们说他是被鬼附着的。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 15:2; 路加福音 7:36; 约翰福音 12:2"> 人子来，也吃也喝，你们说他是贪食好酒的人，是税吏和罪人的朋友。</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 8:32–36; 马太福音 11:19; 何西阿书 14:9"> 但智慧之子都以智慧为是。」</span>
</div>
</div>

## 有罪的女人得蒙赦免

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="马可福音 14:3–9; 马太福音 26:5–6; 路加福音 14:1"> 有一个法利赛人请耶稣和他吃饭；耶稣就到法利赛人家里去坐席。</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 14:3–9; 马太福音 26:6–13; 马太福音 21:31"> 那城里有一个女人，是个罪人，知道耶稣在法利赛人家里坐席，就拿着盛香膏的玉瓶，</span>
<span className="v" id="v38" data-v="38" data-xref="诗篇 126:5–6; 诗篇 51:17; 创世记 18:4"> 站在耶稣背后，挨着他的脚哭，眼泪湿了耶稣的脚，就用自己的头发擦干，又用嘴连连亲他的脚，把香膏抹上。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 7:16; 路加福音 15:2; 马可福音 7:21"> 请耶稣的法利赛人看见这事，心里说：「这人若是先知，必知道摸他的是谁，是个怎样的女人；乃是个罪人。」</span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 16:19; 路加福音 5:31; 以西结书 33:31"> 耶稣对他说：「西门！我有句话要对你说。」西门说：「夫子，请说。」</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 7:47; 罗马书 5:20; 马太福音 18:28"> 耶稣说：「一个债主有两个人欠他的债；一个欠五十两银子，一个欠五两银子；</span>
<span className="v" id="v42" data-v="42" data-xref="但以理书 9:18–19; 歌罗西书 3:13; 罗马书 3:24"> 因为他们无力偿还，债主就开恩免了他们两个人的债。这两个人哪一个更爱他呢？」</span>
<span className="v" id="v43" data-v="43" data-xref="诗篇 116:16–18; 提摩太前书 1:13–16; 路加福音 7:47"> 西门回答说：「我想是那多得恩免的人。」耶稣说：「你断的不错。」</span>
<span className="v" id="v44" data-v="44" data-xref="提摩太前书 5:10; 士师记 19:21; 创世记 18:4"> 于是转过来向着那女人，便对西门说：「你看见这女人吗？我进了你的家，你没有给我水洗脚；但这女人用眼泪湿了我的脚，用头发擦干。</span>
<span className="v" id="v45" data-v="45" data-xref="撒母耳记下 15:5; 撒母耳记下 19:39; 罗马书 16:16"> 你没有与我亲嘴；但这女人从我进来的时候就不住地用嘴亲我的脚。</span>
<span className="v" id="v46" data-v="46" data-xref="诗篇 23:5; 传道书 9:8; 马太福音 6:17"> 你没有用油抹我的头；但这女人用香膏抹我的脚。</span>
<span className="v" id="v47" data-v="47" data-xref="约翰一书 4:19; 约翰一书 3:18; 以赛亚书 1:18"> 所以我告诉你，她许多的罪都赦免了，因为她的爱多；但那赦免少的，他的爱就少。」</span>
<span className="v" id="v48" data-v="48" data-xref="马太福音 9:2; 马可福音 2:5; 路加福音 5:20"> 于是对那女人说：「你的罪赦免了。」</span>
<span className="v" id="v49" data-v="49" data-xref="路加福音 5:20–21; 马太福音 9:3; 马可福音 2:7"> 同席的人心里说：「这是什么人，竟赦免人的罪呢？」</span>
<span className="v" id="v50" data-v="50" data-xref="马可福音 5:34; 路加福音 8:48; 路加福音 18:42"> 耶稣对那女人说：「你的信救了你；平平安安回去吧！」</span>
</div>

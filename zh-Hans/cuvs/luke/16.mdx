## 不义的管家

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 4:10; 马太福音 25:14–30; 雅各书 4:3"> 耶稣又对门徒说：「有一个财主的管家，别人向他主人告他浪费主人的财物。</span>
<span className="v" id="v2" data-v="2" data-xref="传道书 11:9–10; 彼得前书 4:5; 启示录 20:12"> 主人叫他来，对他说：『我听见你这事怎么样呢？把你所经管的交代明白，因你不能再作我的管家。』</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 5:31; 以赛亚书 10:3; 箴言 18:9"> 那管家心里说：『主人辞我，不用我再作管家，我将来做什么？锄地呢？无力；讨饭呢？怕羞。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 30:9; 耶利米书 4:22; 雅各书 3:15"> 我知道怎么行，好叫人在我不作管家之后，接我到他们家里去。』</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 7:41–42; 马太福音 18:24"> 于是把欠他主人债的，一个一个地叫了来，问头一个说：『你欠我主人多少？』</span>
<span className="v" id="v6" data-v="6" data-xref="提多书 2:10; 路加福音 16:12; 路加福音 16:9"> 他说：『一百篓<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="每篓约五十斤">a</a></sup>油。』管家说：『拿你的帐，快坐下，写五十。』</span>
<span className="v" id="v7" data-v="7" data-xref="雅歌 8:11–12; 路加福音 20:9; 路加福音 20:12"> 又问一个说：『你欠多少？』他说：『一百石麦子。』管家说：『拿你的帐，写八十。』</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦前书 5:5; 以弗所书 5:8; 箴言 6:6–8"> 主人就夸奖这不义的管家做事聪明；因为今世之子，在世事之上，较比光明之子更加聪明。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 19:21; 提摩太前书 6:17–19; 但以理书 4:27"> 我又告诉你们，要借着那不义的钱财结交朋友，到了钱财无用的时候，他们可以接你们到永存的帐幕里去。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 16:11–12; 马太福音 25:21; 路加福音 19:17"> 人在最小的事上忠心，在大事上也忠心；在最小的事上不义，在大事上也不义。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 12:33; 雅各书 2:5; 箴言 8:18–19"> 倘若你们在不义的钱财上不忠心，谁还把那真实的钱财托付你们呢？</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 19:13–26; 马太福音 25:14–29; 约伯记 1:21"> 倘若你们在别人的东西上不忠心，谁还把你们自己的东西给你们呢？</span>
<span className="v" id="v13" data-v="13" data-xref="约翰一书 2:15–16; 马太福音 6:24; 雅各书 4:4"> 一个仆人不能事奉两个主；不是恶这个爱那个，就是重这个轻那个。你们不能又事奉 神，又事奉玛门。」</span>
</div>
</div>

## 律法和 神的国

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 23:35; 路加福音 20:47; 耶利米书 6:13"> 法利赛人是贪爱钱财的；他们听见这一切话，就嗤笑耶稣。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 16:7; 箴言 21:2; 哥林多前书 4:5"> 耶稣对他们说：「你们是在人面前自称为义的，你们的心， 神却知道；因为人所尊贵的，是 神看为可憎恶的。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 11:9–14; 马太福音 21:32; 使徒行传 3:24–25"> 律法和先知到约翰为止，从此 神国的福音传开了，人人努力要进去。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 5:18; 路加福音 21:33; 彼得前书 1:25"> 天地废去较比律法的一点一画落空还容易。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 19:9; 马可福音 10:11–12; 马太福音 5:31–32"> 凡休妻另娶的就是犯奸淫；娶被休之妻的也是犯奸淫。」</span>
</div>
</div>

## 财主和拉撒路

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以西结书 16:49; 阿摩司书 6:4–6; 路加福音 18:24–25"> 「有一个财主穿着紫色袍和细麻布衣服，天天奢华宴乐。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 3:2; 撒母耳记上 2:8; 雅各书 2:5"> 又有一个讨饭的，名叫拉撒路，浑身生疮，被人放在财主门口，</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 15:27; 马可福音 7:28; 约翰福音 6:12"> 要得财主桌子上掉下来的零碎充饥，并且狗来舔他的疮。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:24; 诗篇 49:16–19; 雅各书 1:11"> 后来那讨饭的死了，被天使带去放在亚伯拉罕的怀里。财主也死了，并且埋葬了。</span>
<span className="v" id="v23" data-v="23" data-xref="彼得后书 2:4; 路加福音 16:28; 马太福音 18:9"> 他在阴间受痛苦，举目远远地望见亚伯拉罕，又望见拉撒路在他怀里，</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 4:10; 启示录 22:1; 启示录 7:16–17"> 就喊着说：『我祖亚伯拉罕哪，可怜我吧！打发拉撒路来，用指头尖蘸点水，凉凉我的舌头；因为我在这火焰里，极其痛苦。』</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 6:24; 约翰一书 2:15; 诗篇 17:14"> 亚伯拉罕说：『儿啊，你该回想你生前享过福，拉撒路也受过苦；如今他在这里得安慰，你倒受痛苦。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 3:36; 诗篇 49:14; 诗篇 50:22"> 不但这样，并且在你我之间，有深渊限定，以致人要从这边过到你们那边是不能的；要从那边过到我们这边也是不能的。』</span>
<span className="v" id="v27" data-v="27"> 财主说：『我祖啊！既是这样，求你打发拉撒路到我父家去；</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 2:40; 诗篇 49:12–13; 帖撒罗尼迦前书 4:6"> 因为我还有五个弟兄，他可以对他们作见证，免得他们也来到这痛苦的地方。』</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 15:21; 路加福音 24:27; 路加福音 16:16"> 亚伯拉罕说：『他们有摩西和先知的话可以听从。』</span>
<span className="v" id="v30" data-v="30" data-xref="启示录 16:9–11; 路加福音 16:24; 路加福音 13:5"> 他说：『我祖亚伯拉罕哪，不是的，若有一个从死里复活的，到他们那里去的，他们必要悔改。』</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多后书 4:3; 使徒行传 19:8; 约翰福音 11:43–53"> 亚伯拉罕说：『若不听从摩西和先知的话，就是有一个从死里复活的，他们也是不听劝。』」</span>
</div>
</div>

## 耶稣降生

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 3:1; 马太福音 24:14; 使徒行传 25:21"> 当那些日子，凯撒奥古斯都有旨意下来，叫天下人民都报名上册。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 3:1; 马太福音 4:24; 使徒行传 26:30"> 这是居里扭作叙利亚巡抚的时候，头一次行报名上册的事。</span>
<span className="v" id="v3" data-v="3"> 众人各归各城，报名上册。</span>
<span className="v" id="v4" data-v="4" data-xref="弥迦书 5:2; 约翰福音 7:42; 撒母耳记上 16:1"> 约瑟也从加利利的拿撒勒城上犹太去，到了大卫的城，名叫伯利恒，因他本是大卫一族一家的人，</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 22:22–27; 马太福音 1:18–19"> 要和他所聘之妻马利亚一同报名上册。那时马利亚的身孕已经重了。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 33:11; 启示录 12:1–5; 弥迦书 5:2"> 他们在那里的时候，马利亚的产期到了，</span>
<span className="v" id="v7" data-v="7" data-xref="加拉太书 4:4; 哥林多后书 8:9; 以赛亚书 53:2–3"> 就生了头胎的儿子，用布包起来，放在马槽里，因为客店里没有地方。</span>
</div>
</div>

## 天使报喜讯给牧羊的人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="创世记 31:39–40; 诗篇 78:70–71; 撒母耳记上 17:34–35"> 在伯利恒之野地里有牧羊的人，夜间按着更次看守羊群。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 60:1; 哥林多后书 3:18; 列王纪上 8:11"> 有主的使者站在他们旁边，主的荣光四面照着他们；牧羊的人就甚惧怕。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 40:9; 以赛亚书 61:1; 以赛亚书 52:7"> 那天使对他们说：「不要惧怕！我报给你们大喜的信息，是关乎万民的；</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 9:6; 马太福音 1:21; 使徒行传 2:36"> 因今天在大卫的城里，为你们生了救主，就是主基督。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 7:14; 以赛亚书 53:1–2; 以赛亚书 7:11"> 你们要看见一个婴孩，包着布，卧在马槽里，那就是记号了。」</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 103:20–21; 启示录 5:11; 诗篇 148:2"> 忽然，有一大队天兵同那天使赞美 神说：</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 5:1; 路加福音 19:38; 歌罗西书 1:20"> <span className="pl pl-1">在至高之处荣耀归与 神！</span><br /><span className="pl pl-1">在地上平安归与他所喜悦的人</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷：喜悦归与人">a</a></sup><br /><span className="pl pl-1">！</span></span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 3:22; 马太福音 2:1–2; 马太福音 2:9–11"> 众天使离开他们，升天去了。牧羊的人彼此说：「我们往伯利恒去，看看所成的事，就是主所指示我们的。」</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:32; 路加福音 2:12; 路加福音 2:7"> 他们急忙去了，就寻见马利亚和约瑟，又有那婴孩卧在马槽里；</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 66:16; 路加福音 8:39; 诗篇 71:17–18"> 既然看见，就把天使论这孩子的话传开了。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 2:47; 路加福音 4:36; 路加福音 1:65–66"> 凡听见的，就诧异牧羊之人对他们所说的话。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 2:51; 路加福音 1:66; 箴言 4:4"> 马利亚却把这一切的事存在心里，反复思想。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 106:48; 以赛亚书 29:19; 使徒行传 11:18"> 牧羊的人回去了，因所听见所看见的一切事，正如天使向他们所说的，就归荣耀与 神，赞美他。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:31; 创世记 17:12; 加拉太书 4:4–5"> 满了八天，就给孩子行割礼，与他起名叫耶稣；这就是没有成胎以前，天使所起的名。</span>
</div>
</div>

## 在圣殿里献与主

<div className="bt">
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="利未记 12:1–8"> 按摩西律法满了洁净的日子，他们带着孩子上耶路撒冷去，要把他献与主，（</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 13:2; 出埃及记 22:29; 民数记 3:13"> 正如主的律法上所记：「凡头生的男子必称圣归主。」）</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 12:6–8; 利未记 12:2; 哥林多后书 8:9"> 又要照主的律法上所说，或用一对斑鸠，或用两只雏鸽献祭。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 25:9; 路加福音 2:38; 路加福音 1:6"> 在耶路撒冷有一个人，名叫西面；这人又公义又虔诚，素常盼望以色列的安慰者来到，又有圣灵在他身上。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 8:51; 希伯来书 11:5; 路加福音 9:27"> 他得了圣灵的启示，知道自己未死以前，必看见主所立的基督。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 4:1; 路加福音 2:41; 路加福音 2:51"> 他受了圣灵的感动，进入圣殿，正遇见耶稣的父母抱着孩子进来，要照律法的规矩办理。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 1:64; 路加福音 2:20; 路加福音 2:13–14"> 西面就用手接过他来，称颂 神说：</span>
<span className="v" id="v29" data-v="29" data-xref="启示录 14:13; 创世记 15:15; 腓立比书 1:23"> <span className="pl pl-1">主啊！如今可以照你的话，</span><br /><span className="pl pl-1">释放仆人安然去世；</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="以赛亚书 49:6; 路加福音 2:10–11; 路加福音 3:6"> <span className="pl pl-1">因为我的眼睛已经看见你的救恩—</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 62:1–2; 以赛亚书 42:1–4; 诗篇 98:2–3"> <span className="pl pl-1">就是你在万民面前所预备的：</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 60:1–3; 以赛亚书 49:6; 使徒行传 26:23"> <span className="pl pl-1">是照亮外邦人的光，</span><br /><span className="pl pl-1">又是你民以色列的荣耀。</span></span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 1:65–66; 以赛亚书 8:18; 路加福音 2:48"> 孩子的父母因这论耶稣的话就希奇。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 1:23; 彼得前书 2:7–8; 以赛亚书 8:14–15"> 西面给他们祝福，又对孩子的母亲马利亚说：「这孩子被立，是要叫以色列中许多人跌倒，许多人兴起；又要作毁谤的话柄，叫许多人心里的意念显露出来；你自己的心也要被刀刺透。」</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 15:20; 创世记 30:13; 使徒行传 21:9"> 又有女先知，名叫亚拿，是亚设支派法内力的女儿，年纪已经老迈，从作童女出嫁的时候，同丈夫住了七年就寡居了，</span>
<span className="v" id="v37" data-v="37" data-xref="提摩太前书 5:5; 诗篇 23:6; 使徒行传 14:23"> 现在已经八十四岁<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：就寡居了八十四年">b</a></sup>，并不离开圣殿，禁食祈求，昼夜事奉 神。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 2:25; 哥林多后书 9:15; 马可福音 15:43"> 正当那时，她进前来称谢 神，将孩子的事对一切盼望耶路撒冷得救赎的人讲说。</span>
</div>
</div>

## 回拿撒勒

<div className="bt">
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 2:4; 加拉太书 4:4–5; 申命记 12:32"> 约瑟和马利亚照主的律法办完了一切的事，就回加利利，到自己的城拿撒勒去了。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 2:52; 路加福音 1:80; 以赛亚书 11:1–5"> 孩子渐渐长大，强健起来，充满智慧，又有 神的恩在他身上。</span>
</div>
</div>

## 孩童耶稣在圣殿里

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="出埃及记 12:14; 民数记 28:16; 申命记 12:18"> 每年到逾越节，他父母就上耶路撒冷去。</span>
<span className="v" id="v42" data-v="42"> 当他十二岁的时候，他们按着节期的规矩上去。</span>
<span className="v" id="v43" data-v="43" data-xref="历代志下 30:21–23; 出埃及记 12:15; 历代志下 25:17"> 守满了节期，他们回去，孩童耶稣仍旧在耶路撒冷。他的父母并不知道，</span>
<span className="v" id="v44" data-v="44" data-xref="诗篇 122:1–4; 以赛亚书 2:3; 诗篇 42:4"> 以为他在同行的人中间，走了一天的路程，就在亲族和熟识的人中找他，</span>
<span className="v" id="v45" data-v="45"> 既找不着，就回耶路撒冷去找他。</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 5:17; 以赛亚书 49:1–2; 以赛亚书 50:4"> 过了三天，就遇见他在殿里，坐在教师中间，一面听，一面问。</span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 7:28; 路加福音 4:32; 诗篇 119:99"> 凡听见他的，都希奇他的聪明和他的应对。</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 2:49; 马太福音 12:46; 路加福音 3:23"> 他父母看见就很希奇。他母亲对他说：「我儿！为什么向我们这样行呢？看哪，你父亲和我伤心来找你！」</span>
<span className="v" id="v49" data-v="49" data-xref="约翰福音 6:38; 约翰福音 8:29; 玛拉基书 3:1"> 耶稣说：「为什么找我呢？岂不知我应当以我父的事为念吗<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或译：岂不知我应当在我父的家里吗">c</a></sup>？」</span>
<span className="v" id="v50" data-v="50" data-xref="路加福音 18:34; 路加福音 9:45; 马可福音 9:32"> 他所说的这话，他们不明白。</span>
<span className="v" id="v51" data-v="51" data-xref="路加福音 2:19; 但以理书 7:28; 创世记 37:11"> 他就同他们下去，回到拿撒勒，并且顺从他们。他母亲把这一切的事都存在心里。</span>
<span className="v" id="v52" data-v="52" data-xref="路加福音 2:40; 箴言 3:3–4; 撒母耳记上 2:26"> 耶稣的智慧和身量<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或译：年纪">d</a></sup>，并 神和人喜爱他的心，都一齐增长。</span>
</div>

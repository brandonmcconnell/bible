## 摩押的难民逃到犹大

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 3:4; 以赛亚书 10:32; 列王纪下 14:7"> <span className="pl pl-1">你们当将羊羔奉给那地掌权的，</span><br /><span className="pl pl-1">从西拉往旷野，送到锡安城</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是女子">a</a></sup><br /><span className="pl pl-1">的山。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 27:8; 士师记 11:18; 耶利米书 48:20"> <span className="pl pl-1">摩押的居民</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是女子">b</a></sup><br /><span className="pl pl-1">在亚嫩渡口，</span><br /><span className="pl pl-1">必像游飞的鸟，如拆窝的雏。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 32:2; 列王纪上 18:4; 以赛亚书 25:4"> <span className="pl pl-1">求你献谋略，行公平，</span><br /><span className="pl pl-1">使你的影子在午间如黑夜，</span><br /><span className="pl pl-1">隐藏被赶散的人，不可显露逃民。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 14:4; 以赛亚书 51:13; 以赛亚书 9:4"> <span className="pl pl-1">求你容我这被赶散的人和你同居。</span><br /><span className="pl pl-1">至于摩押，求你作他的隐密处，</span><br /><span className="pl pl-1">脱离灭命者的面。</span><br /><span className="pl pl-1">勒索人的归于无有，</span><br /><span className="pl pl-1">毁灭的事止息了，</span><br /><span className="pl pl-1">欺压人的从国中除灭了，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 7:14; 弥迦书 4:7; 以赛亚书 9:6–7"> <span className="pl pl-1">必有宝座因慈爱坚立；</span><br /><span className="pl pl-1">必有一位诚诚实实坐在其上，</span><br /><span className="pl pl-1">在大卫帐幕中施行审判，</span><br /><span className="pl pl-1">寻求公平，速行公义。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="阿摩司书 2:1; 俄巴底亚书 1:3–4; 耶利米书 48:29–30"> <span className="pl pl-1">我们听说摩押人骄傲，</span><br /><span className="pl pl-1">是极其骄傲；</span><br /><span className="pl pl-1">听说他狂妄、骄傲、忿怒；</span><br /><span className="pl pl-1">他夸大的话是虚空的。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 3:25; 历代志上 16:3; 耶利米书 48:20"> <span className="pl pl-1">因此，摩押人必为摩押哀号；</span><br /><span className="pl pl-1">人人都要哀号。</span><br /><span className="pl pl-1">你们摩押人要为吉珥·哈列设的葡萄饼哀叹，</span><br /><span className="pl pl-1">极其忧伤。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 15:4; 民数记 32:38; 耶利米书 48:32"> <span className="pl pl-1">因为希实本的田地</span><br /><span className="pl pl-1">和西比玛的葡萄树都衰残了。</span><br /><span className="pl pl-1">列国的君主折断其上美好的枝子；</span><br /><span className="pl pl-1">这枝子长到雅谢延到旷野，</span><br /><span className="pl pl-1">嫩枝向外探出，直探过盐海。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 40:12; 以赛亚书 15:4–5; 耶利米书 40:10"> <span className="pl pl-1">因此，我要为西比玛的葡萄树哀哭，</span><br /><span className="pl pl-1">与雅谢人哀哭一样。</span><br /><span className="pl pl-1">希实本、以利亚利啊，</span><br /><span className="pl pl-1">我要以眼泪浇灌你；</span><br /><span className="pl pl-1">因为有交战呐喊的声音</span><br /><span className="pl pl-1">临到你夏天的果子，</span><br /><span className="pl pl-1">并你收割的庄稼。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 48:33; 士师记 9:27; 阿摩司书 5:17"> <span className="pl pl-1">从肥美的田中夺去了欢喜快乐；</span><br /><span className="pl pl-1">在葡萄园里必无歌唱，也无欢呼的声音。</span><br /><span className="pl pl-1">踹酒的在酒榨中不得踹出酒来；</span><br /><span className="pl pl-1">我使他欢呼的声音止息。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 15:5; 耶利米书 48:36; 何西阿书 11:8"> <span className="pl pl-1">因此，我心腹为摩押哀鸣如琴；</span><br /><span className="pl pl-1">我心肠为吉珥·哈列设也是如此。</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 15:2; 列王纪上 18:29; 耶利米书 48:35"> 摩押人朝见的时候，在高处疲乏，又到他圣所祈祷，也不蒙应允。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 44:8"> 这是耶和华从前论摩押的话。</span>

</div>

## 神要惩罚埃及

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 12:12; 启示录 1:7; 约书亚记 2:11"> 论埃及的默示：<br /><span className="pl pl-1">看哪，耶和华乘驾快云，</span><br /><span className="pl pl-1">临到埃及。</span><br /><span className="pl pl-1">埃及的偶像在他面前战兢；</span><br /><span className="pl pl-1">埃及人的心在里面消化。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="士师记 7:22; 撒母耳记上 14:20; 马太福音 10:36"> <span className="pl pl-1">我必激动埃及人攻击埃及人—</span><br /><span className="pl pl-1">弟兄攻击弟兄，</span><br /><span className="pl pl-1">邻舍攻击邻舍；</span><br /><span className="pl pl-1">这城攻击那城，</span><br /><span className="pl pl-1">这国攻击那国。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 8:19; 但以理书 2:2; 历代志上 10:13"> <span className="pl pl-1">埃及人的心神必在里面耗尽；</span><br /><span className="pl pl-1">我必败坏他们的谋略。</span><br /><span className="pl pl-1">他们必求问偶像和念咒的、</span><br /><span className="pl pl-1">交鬼的、行巫术的。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 20:4; 耶利米书 46:26; 以西结书 29:19"> <span className="pl pl-1">我必将埃及人交在残忍主的手中；</span><br /><span className="pl pl-1">强暴王必辖制他们。</span><br /><span className="pl pl-1">这是主—万军之耶和华说的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="耶利米书 51:36; 以西结书 30:12; 撒迦利亚书 14:18"> <span className="pl pl-1">海中的水必绝尽，</span><br /><span className="pl pl-1">河也消没干涸。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 37:25; 出埃及记 7:18; 列王纪下 19:24"> <span className="pl pl-1">江河要变臭；</span><br /><span className="pl pl-1">埃及的河水都必减少枯干。</span><br /><span className="pl pl-1">苇子和芦荻都必衰残；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 32:20; 约珥书 1:17–18; 以赛亚书 23:3"> <span className="pl pl-1">靠尼罗河旁的草田，</span><br /><span className="pl pl-1">并沿尼罗河所种的田，都必枯干。</span><br /><span className="pl pl-1">庄稼被风吹去，归于无有。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以西结书 47:10; 哈巴谷书 1:15; 民数记 11:5"> <span className="pl pl-1">打鱼的必哀哭。</span><br /><span className="pl pl-1">在尼罗河一切钓鱼的必悲伤；</span><br /><span className="pl pl-1">在水上撒网的必都衰弱。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 27:7; 箴言 7:16; 列王纪上 10:28"> <span className="pl pl-1">用梳好的麻造物的</span><br /><span className="pl pl-1">和织白布的都必羞愧；</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="申命记 11:10; 出埃及记 7:19; 出埃及记 8:5"> <span className="pl pl-1">国柱必被打碎，</span><br /><span className="pl pl-1">所有佣工的，心必愁烦。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="民数记 13:22; 使徒行传 7:22; 列王纪上 4:30"> <span className="pl pl-1">琐安的首领极其愚昧；</span><br /><span className="pl pl-1">法老大有智慧的谋士，</span><br /><span className="pl pl-1">所筹划的成为愚谋。</span><br /><span className="pl pl-1">你们怎敢对法老说：</span><br /><span className="pl pl-1">我是智慧人的子孙，</span><br /><span className="pl pl-1">我是古王的后裔？</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 1:20; 以赛亚书 14:24; 士师记 9:38"> <span className="pl pl-1">你的智慧人在哪里呢？</span><br /><span className="pl pl-1">万军之耶和华向埃及所定的旨意，</span><br /><span className="pl pl-1">他们可以知道，可以告诉你吧！</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 30:13; 耶利米书 2:16; 耶利米书 46:14"> <span className="pl pl-1">琐安的首领都变为愚昧；</span><br /><span className="pl pl-1">挪弗的首领都受了迷惑。</span><br /><span className="pl pl-1">当埃及支派房角石的，</span><br /><span className="pl pl-1">使埃及人走错了路。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦后书 2:11; 列王纪上 22:20–23; 以西结书 14:7–9"> <span className="pl pl-1">耶和华使乖谬的灵搀入埃及中间；</span><br /><span className="pl pl-1">首领使埃及一切所做的都有差错，</span><br /><span className="pl pl-1">好像醉酒之人呕吐的时候东倒西歪一样。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 9:14–15; 帖撒罗尼迦前书 4:11–12; 箴言 14:23"> <span className="pl pl-1">埃及中，无论是头与尾，</span><br /><span className="pl pl-1">棕枝与芦苇，所做之工都不成就。</span></span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 51:30; 那鸿书 3:13; 以赛亚书 11:15"> 到那日，埃及人必像妇人一样，他们必因万军之耶和华在埃及以上所抡的手，战兢惧怕。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 14:24; 但以理书 4:35; 以西结书 29:6–7"> 犹大地必使埃及惊恐，向谁提起犹大地，谁就惧怕。这是因万军之耶和华向埃及所定的旨意。</span>
<span className="v" id="v18" data-v="18" data-xref="西番雅书 3:9; 撒迦利亚书 2:11; 以赛亚书 19:21"> 当那日，埃及地必有五城的人说迦南的方言，又指着万军之耶和华起誓。有一城必称为「灭亡城」。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 28:18; 约书亚记 22:10; 约书亚记 22:26"> 当那日，在埃及地中必有为耶和华筑的一座坛；在埃及的边界上必有为耶和华立的一根柱。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 50:15; 提多书 2:13; 以赛亚书 45:21–22"> 这都要在埃及地为万军之耶和华作记号和证据。埃及人因为受人的欺压哀求耶和华，他就差遣一位救主作护卫者，拯救他们。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 11:9; 玛拉基书 1:11; 约翰福音 17:3"> 耶和华必被埃及人所认识。在那日，埃及人必认识耶和华，也要献祭物和供物敬拜他，并向耶和华许愿还愿。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 32:39; 希伯来书 12:11; 何西阿书 14:1"> 耶和华必击打埃及，又击打又医治，埃及人就归向耶和华。他必应允他们的祷告，医治他们。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 11:16; 以弗所书 2:18–22; 以赛亚书 35:8–10"> 当那日，必有从埃及通亚述去的大道。亚述人要进入埃及，埃及人也进入亚述；埃及人要与亚述人一同敬拜耶和华。</span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 65:8; 创世记 12:2; 加拉太书 3:14"> 当那日，以色列必与埃及、亚述三国一律，使地上的人得福；</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 29:23; 何西阿书 2:23; 罗马书 9:24–25"> 因为万军之耶和华赐福给他们，说：「埃及—我的百姓，亚述—我手的工作，以色列—我的产业，都有福了！」</span>

## 传给亚哈斯王的信息

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 15:37; 列王纪下 16:1; 以赛亚书 1:1"> 乌西雅的孙子、约坦的儿子、犹大王亚哈斯在位的时候，亚兰王利汛和利玛利的儿子、以色列王比加上来攻打耶路撒冷，却不能攻取。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 8:12; 以赛亚书 7:13; 以赛亚书 9:9"> 有人告诉大卫家说：「亚兰与以法莲已经同盟。」王的心和百姓的心就都跳动，好像林中的树被风吹动一样。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 18:17; 以赛亚书 36:2; 罗马书 9:27"> 耶和华对以赛亚说：「你和你的儿子施亚雅述出去，到上池的水沟头，在漂布地的大路上，去迎接亚哈斯，</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 35:4; 耶利米哀歌 3:26; 申命记 20:3"> 对他说：『你要谨慎安静，不要因亚兰王利汛和利玛利的儿子这两个冒烟的火把头所发的烈怒害怕，也不要心里胆怯。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 83:3–4; 撒迦利亚书 1:15; 诗篇 2:2"> 因为亚兰和以法莲，并利玛利的儿子，设恶谋害你，</span>
<span className="v" id="v6" data-v="6"> 说：我们可以上去攻击犹大，扰乱它，攻破它，在其中立他比勒的儿子为王。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 8:10; 耶利米哀歌 3:37; 以赛亚书 46:10–11"> 所以主耶和华如此说：<br /><span className="pl pl-1">这所谋的必立不住，</span><br /><span className="pl pl-1">也不得成就。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 17:1–3; 创世记 14:15; 撒母耳记下 8:6"> <span className="pl pl-1">原来亚兰的首城是大马士革；</span><br /><span className="pl pl-1">大马士革的首领是利汛。</span>（六十五年之内，以法莲必然破坏，不再成为国民。）</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 11:6; 罗马书 11:20; 历代志下 20:20"> <span className="pl pl-1">以法莲的首城是撒马利亚；</span><br /><span className="pl pl-1">撒马利亚的首领是利玛利的儿子。</span><br /><span className="pl pl-1">你们若是不信，</span><br /><span className="pl pl-1">定然不得立稳。』」</span></span>
</div>

## 以马内利的记号

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 8:5; 以赛亚书 1:5; 以赛亚书 10:20"> 耶和华又晓谕亚哈斯说：</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 37:30; 以赛亚书 38:7–8; 以赛亚书 38:22"> 「你向耶和华—你的 神求一个兆头：或求显在深处，或求显在高处。」</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 33:31; 历代志下 28:22; 玛拉基书 3:15"> 亚哈斯说：「我不求；我不试探耶和华。」</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 43:24; 以赛亚书 63:10; 以西结书 34:18"> 以赛亚说：「大卫家啊，你们当听！你们使人厌烦岂算小事，还要使我的 神厌烦吗？</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 1:23; 以赛亚书 9:6; 路加福音 1:31"> 因此，主自己要给你们一个兆头，必有童女怀孕生子，给他起名叫以马内利<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是 神与我们同在的意思">a</a></sup>。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 7:22; 阿摩司书 5:15; 马太福音 3:4"> 到他晓得弃恶择善的时候，他必吃奶油与蜂蜜。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 8:4; 申命记 1:39; 以赛亚书 9:11"> 因为在这孩子还不晓得弃恶择善之先，你所憎恶的那二王之地必致见弃。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 8:7–8; 以赛亚书 10:5–6; 历代志下 28:19–21"> 耶和华必使亚述王攻击你的日子临到你和你的百姓，并你的父家，自从以法莲离开犹大以来，未曾有这样的日子。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 5:26; 约书亚记 24:12; 申命记 1:44"> 「那时，耶和华要发嘶声，使埃及江河源头的苍蝇和亚述地的蜂子飞来；</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 2:19; 耶利米书 16:16; 以赛亚书 2:21"> 都必飞来，落在荒凉的谷内、磐石的穴里，和一切荆棘篱笆中，并一切的草场上。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 8:7; 以西结书 29:18; 以赛亚书 10:15"> 「那时，主必用大河外赁的剃头刀，就是亚述王，剃去头发和脚上的毛，并要剃净胡须。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 5:17; 耶利米书 39:10; 以赛亚书 37:30"> 「那时，一个人要养活一只母牛犊，两只母绵羊；</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 7:15; 马太福音 3:4; 撒母耳记下 17:29"> 因为出的奶多，他就得吃奶油，在境内所剩的人都要吃奶油与蜂蜜。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 5:6; 雅歌 8:11–12; 马太福音 21:33"> 「从前，凡种一千棵葡萄树、值银一千舍客勒的地方，到那时必长荆棘和蒺藜。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 27:3"> 人上那里去，必带弓箭，因为遍地满了荆棘和蒺藜。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 7:21–22; 以赛亚书 13:20–22; 以赛亚书 5:17"> 所有用锄刨挖的山地，你因怕荆棘和蒺藜，不敢上那里去；只可成了放牛之处，为羊践踏之地。」</span>
</div>

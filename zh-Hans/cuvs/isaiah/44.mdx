## 耶和华是独一的 神

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 41:8; 罗马书 11:5–6; 耶利米书 30:10"> <span className="pl pl-1">我的仆人雅各，</span><br /><span className="pl pl-1">我所拣选的以色列啊，</span><br /><span className="pl pl-1">现在你当听。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 1:5; 以赛亚书 43:1; 以赛亚书 46:3–4"> <span className="pl pl-1">造作你，又从你出胎造就你，</span><br /><span className="pl pl-1">并要帮助你的耶和华如此说：</span><br /><span className="pl pl-1">我的仆人雅各，</span><br /><span className="pl pl-1">我所拣选的耶书 哪，</span><br /><span className="pl pl-1">不要害怕！</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="约珥书 2:28; 使徒行传 2:17; 以赛亚书 59:21"> <span className="pl pl-1">因为我要将水浇灌口渴的人，</span><br /><span className="pl pl-1">将河浇灌干旱之地。</span><br /><span className="pl pl-1">我要将我的灵浇灌你的后裔，</span><br /><span className="pl pl-1">将我的福浇灌你的子孙。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 58:11; 诗篇 1:3; 诗篇 92:13–15"> <span className="pl pl-1">他们要发生在草中，</span><br /><span className="pl pl-1">像溪水旁的柳树。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 8:5; 撒迦利亚书 13:9; 彼得前书 2:9"> <span className="pl pl-1">这个要说：我是属耶和华的；</span><br /><span className="pl pl-1">那个要以雅各的名自称；</span><br /><span className="pl pl-1">又一个要亲手写：归耶和华的</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：在手上写归耶和华">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">并自称为以色列。</span></span>

## 虚无的偶像

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 41:24; 耶利米书 10:14–15; 诗篇 97:7"> 制造雕刻偶像的尽都虚空；他们所喜悦的都无益处；他们的见证无所看见，无所知晓，他们便觉羞愧。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 10:5; 哈巴谷书 2:18; 使徒行传 19:26"> 谁制造神像，铸造无益的偶像？</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 42:17; 以赛亚书 45:16; 诗篇 97:7"> 看哪，他的同伴都必羞愧。工匠也不过是人，任他们聚会，任他们站立，都必惧怕，一同羞愧。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 41:6–7; 以赛亚书 40:19; 以赛亚书 46:6–7"> 铁匠把铁在火炭中烧热，用锤打铁器，用他有力的膀臂锤成；他饥饿而无力，不喝水而发倦。</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 17:4–5; 诗篇 115:5–7; 使徒行传 17:29"> 木匠拉线，用笔划出样子，用刨子刨成形状，用圆尺划了模样，仿照人的体态，做成人形，好住在房屋中。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 40:20; 耶利米书 10:3–8; 何西阿书 4:12"> 他砍伐香柏树，又取柞<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：青桐">b</a></sup>树和橡树，在树林中选定了一棵。他栽种松树，得雨长养。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 25:14; 启示录 9:20; 士师记 2:19"> 这树，人可用以烧火；他自己取些烤火，又烧着烤饼，而且做神像跪拜，做雕刻的偶像向它叩拜。</span>
<span className="v" id="v16" data-v="16"> 他把一分烧在火中，把一分烤肉吃饱。自己烤火说：「啊哈，我暖和了，我见火了。」</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 45:20; 列王纪上 18:26; 但以理书 6:27"> 他用剩下的做了一神，就是雕刻的偶像。他向这偶像俯伏叩拜，祷告它说：「求你拯救我，因你是我的神。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 6:9–10; 哥林多后书 4:3–4; 约翰福音 12:39–40"> 他们不知道，也不思想；因为耶和华闭住他们的眼，不能看见，塞住他们的心，不能明白。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 27:15; 列王纪上 11:7; 列王纪上 11:5"> 谁心里也不醒悟，也没有知识，没有聪明，能说：「我曾拿一分在火中烧了，在炭火上烤过饼；我也烤过肉吃。这剩下的，我岂要作可憎的物吗？我岂可向木ⶍ子叩拜呢？」</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 1:28; 约伯记 15:31; 何西阿书 12:1"> 他以灰为食，心中昏迷，使他偏邪，他不能自救，也不能说：「我右手中岂不是有虚谎吗？」</span>
</div>
</div>

## 耶和华是创造主也是救赎主

<div className="bt">
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 44:1–2; 以赛亚书 49:15–16; 以赛亚书 43:15"> <span className="pl pl-1">雅各，以色列啊，</span><br /><span className="pl pl-1">你是我的仆人，要记念这些事。</span><br /><span className="pl pl-1">以色列啊，你是我的仆人，</span><br /><span className="pl pl-1">我造就你必不忘记你。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 43:25; 哥林多前书 6:20; 使徒行传 3:18–19"> <span className="pl pl-1">我涂抹了你的过犯，像厚云消散；</span><br /><span className="pl pl-1">我涂抹了你的罪恶，如薄云灭没。</span><br /><span className="pl pl-1">你当归向我，因我救赎了你。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="以弗所书 1:6–7; 启示录 5:8–14; 诗篇 69:34"> <span className="pl pl-1">诸天哪，应当歌唱，</span><br /><span className="pl pl-1">因为耶和华做成这事。</span><br /><span className="pl pl-1">地的深处啊，应当欢呼；</span><br /><span className="pl pl-1">众山应当发声歌唱；</span><br /><span className="pl pl-1">树林和其中所有的树都当如此！</span><br /><span className="pl pl-1">因为耶和华救赎了雅各，</span><br /><span className="pl pl-1">并要因以色列荣耀自己。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 45:12; 以赛亚书 42:5; 以赛亚书 54:5"> <span className="pl pl-1">从你出胎，造就你的救赎主—耶和华如此说：</span><br /><span className="pl pl-1">我—耶和华是创造万物的，</span><br /><span className="pl pl-1">是独自铺张诸天、铺开大地的。</span><br /><span className="pl pl-1">谁与我同在呢？</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 33:10; 约伯记 5:12–14; 耶利米书 50:36"> <span className="pl pl-1">使说假话的兆头失效，</span><br /><span className="pl pl-1">使占卜的癫狂，</span><br /><span className="pl pl-1">使智慧人退后，</span><br /><span className="pl pl-1">使他的知识变为愚拙；</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 18:36–38; 以赛亚书 42:9; 尼希米记 1:3"> <span className="pl pl-1">使我仆人的话语立定，</span><br /><span className="pl pl-1">我使者的谋算成就。</span><br /><span className="pl pl-1">论到耶路撒冷说：必有人居住；</span><br /><span className="pl pl-1">论到犹大的城邑说：必被建造，</span><br /><span className="pl pl-1">其中的荒场我也必兴起。</span><br /></span>

<span className="v" id="v28" data-v="28" data-xref="历代志下 36:22–3; 以赛亚书 45:1; 以赛亚书 45:13"> <span className="pl pl-1">论塞鲁士说：他是我的牧人，</span><br /><span className="pl pl-1">必成就我所喜悦的，</span><br /><span className="pl pl-1">必下令建造耶路撒冷，</span><br /><span className="pl pl-1">发命立稳圣殿的根基。</span></span>

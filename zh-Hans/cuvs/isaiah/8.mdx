<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 30:8; 约伯记 19:23–24; 哈巴谷书 2:2–3"> 耶和华对我说：「你取一个大牌，拿人所用的笔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：人常用的字">a</a></sup>，写上『玛黑珥·沙拉勒·哈施·罢斯』<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就是掳掠速临、抢夺快到的意思">b</a></sup>。</span>

<span className="v" id="v3" data-v="3" data-xref="何西阿书 1:3–9; 士师记 4:4; 以赛亚书 7:13–14"> 我—以赛亚与妻子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是女先知">c</a></sup>同室；她怀孕生子，耶和华就对我说：「给他起名叫玛黑珥·沙拉勒·哈施·罢斯；</span>

## 亚述王快来了

<div className="bt">
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 7:10"> 耶和华又晓谕我说：</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 9:7; 尼希米记 3:15; 以赛亚书 7:6"> 「这百姓既厌弃西罗亚缓流的水，喜悦利汛和利玛利的儿子；</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 17:12–13; 创世记 6:17; 以赛亚书 7:17"> 因此，主必使大河翻腾的水猛然冲来，就是亚述王和他所有的威势，必漫过一切的水道，涨过两岸；</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 7:14; 以赛亚书 30:28; 马太福音 1:23"> 必冲入犹大，涨溢泛滥，直到颈项。以马内利啊，他展开翅膀，遍满你的地。」</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 14:5–6; 箴言 11:21; 诗篇 37:14–15"> <span className="pl pl-1">列国的人民哪，任凭你们喧嚷，终必破坏；</span><br /><span className="pl pl-1">远方的众人哪，当侧耳而听！</span><br /><span className="pl pl-1">任凭你们束起腰来，终必破坏；</span><br /><span className="pl pl-1">你们束起腰来，终必破坏。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米哀歌 3:37; 罗马书 8:31; 约伯记 5:12"> <span className="pl pl-1">任凭你们同谋，终归无有；</span><br /><span className="pl pl-1">任凭你们言定，终不成立；</span><br /><span className="pl pl-1">因为 神与我们同在。</span></span>

## 耶和华警告先知

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以西结书 3:14; 箴言 1:15; 耶利米书 15:19"> 耶和华以大能的手，指教我不可行这百姓所行的道，对我这样说：</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 3:14–15; 路加福音 21:9; 诗篇 53:5"> 「这百姓说同谋背叛，你们不要说同谋背叛。他们所怕的，你们不要怕，也不要畏惧。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:5; 以赛亚书 26:3–4; 启示录 15:4"> 但要尊万军之耶和华为圣，以他为你们所当怕的，所当畏惧的。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 2:8; 罗马书 9:32–33; 以赛亚书 28:16"> 他必作为圣所，却向以色列两家作绊脚的石头，跌人的磐石；向耶路撒冷的居民作为圈套和网罗。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 21:44; 路加福音 20:17–18; 以赛亚书 28:13"> 许多人必在其上绊脚跌倒，而且跌碎，并陷入网罗，被缠住。」</span>
</div>
</div>

## 不可求问死人

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="但以理书 12:4; 希伯来书 3:5; 马可福音 4:10–11"> 你要卷起律法书，在我门徒中间封住训诲。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 10:36–39; 哈巴谷书 2:3; 耶利米哀歌 3:25–26"> 我要等候那掩面不顾雅各家的耶和华；我也要仰望他。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 2:13–14; 路加福音 2:34; 撒迦利亚书 8:3"> 看哪，我与耶和华所给我的儿女，就是从住在锡安山万军之耶和华来的，在以色列中作为预兆和奇迹。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 10:13; 利未记 20:6; 历代志下 33:6"> 有人对你们说：「当求问那些交鬼的和行巫术的，就是声音绵蛮，言语微细的。」你们便回答说：「百姓不当求问自己的 神吗？岂可为活人求问死人呢？」</span>
<span className="v" id="v20" data-v="20" data-xref="彼得后书 1:19; 提摩太后书 3:15–17; 以赛亚书 30:8–11"> 人当以训诲和法度为标准；他们所说的，若不与此相符，必不得见晨光。</span>
</div>
</div>

## 遭难的时候

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 9:20; 箴言 19:3; 耶利米哀歌 4:4–5"> 他们必经过这地，受艰难，受饥饿；饥饿的时候，心中焦躁，咒骂自己的君王和自己的 神。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 5:30; 马太福音 22:13; 耶利米书 13:16"> 仰观上天，俯察下地，不料，尽是艰难、黑暗，和幽暗的痛苦。他们必被赶入乌黑的黑暗中去。</span>
</div>

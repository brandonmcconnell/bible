## 跟埃及订立无用的条约

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 65:2; 以赛亚书 1:2; 何西阿书 7:13"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">祸哉！这悖逆的儿女。</span><br /><span className="pl pl-1">他们同谋，却不由于我，</span><br /><span className="pl pl-1">结盟，却不由于我的灵，</span><br /><span className="pl pl-1">以致罪上加罪；</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 36:6; 民数记 27:21; 申命记 28:68"> <span className="pl pl-1">起身下埃及去，并没有求问我；</span><br /><span className="pl pl-1">要靠法老的力量加添自己的力量，</span><br /><span className="pl pl-1">并投在埃及的荫下。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 20:5; 罗马书 10:11; 耶利米书 17:5–6"> <span className="pl pl-1">所以，法老的力量必作你们的羞辱；</span><br /><span className="pl pl-1">投在埃及的荫下，要为你们的惭愧。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 19:11; 以赛亚书 57:9; 耶利米书 43:7"> <span className="pl pl-1">他们的首领已在琐安；</span><br /><span className="pl pl-1">他们的使臣到了哈内斯。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 2:36; 以赛亚书 30:7; 以赛亚书 30:16"> <span className="pl pl-1">他们必因那不利于他们的民蒙羞。</span><br /><span className="pl pl-1">那民并非帮助，也非利益，</span><br /><span className="pl pl-1">只作羞耻凌辱。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="申命记 8:15; 以赛亚书 46:1–2; 耶利米书 11:4"> <span className="pl pl-1">论南方牲畜的默示：</span><br /><span className="pl pl-1">他们把财物驮在驴驹的脊背上，</span><br /><span className="pl pl-1">将宝物驮在骆驼的肉鞍上，</span><br /><span className="pl pl-1">经过艰难困苦之地，</span><br /><span className="pl pl-1">就是公狮、母狮、蝮蛇、火焰的飞龙之地，</span><br /><span className="pl pl-1">往那不利于他们的民那里去。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 2:22; 以赛亚书 7:4; 诗篇 118:8–9"> <span className="pl pl-1">埃及的帮助是徒然无益的；</span><br /><span className="pl pl-1">所以我称她为「坐而不动的拉哈伯」。</span></span>
</div>
</div>

## 不顺服的百姓

<div className="bt">
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="申命记 31:22; 哈巴谷书 2:2; 以赛亚书 8:1"> <span className="pl pl-1">现今你去，</span><br /><span className="pl pl-1">在他们面前将这话刻在版上，</span><br /><span className="pl pl-1">写在书上，</span><br /><span className="pl pl-1">以便传留后世，直到永永远远。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 30:1; 使徒行传 7:51; 撒迦利亚书 1:4–6"> <span className="pl pl-1">因为他们是悖逆的百姓、说谎的儿女，</span><br /><span className="pl pl-1">不肯听从耶和华训诲的儿女。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 13:7–10; 罗马书 16:18; 阿摩司书 2:12"> <span className="pl pl-1">他们对先见说：不要望见不吉利的事，</span><br /><span className="pl pl-1">对先知说：不要向我们讲正直的话；</span><br /><span className="pl pl-1">要向我们说柔和的话，</span><br /><span className="pl pl-1">言虚幻的事。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 8:7; 罗马书 1:30; 约翰福音 15:23–24"> <span className="pl pl-1">你们要离弃正道，偏离直路，</span><br /><span className="pl pl-1">不要在我们面前再提说以色列的圣者。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 31:1–3; 以赛亚书 5:24; 帖撒罗尼迦前书 4:8"> <span className="pl pl-1">所以，以色列的圣者如此说：</span><br /><span className="pl pl-1">因为你们藐视这训诲的话，</span><br /><span className="pl pl-1">倚赖欺压和乖僻，以此为可靠的，</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 29:5; 以西结书 13:10–15; 列王纪上 20:30"> <span className="pl pl-1">故此，这罪孽在你们身上，</span><br /><span className="pl pl-1">好像将要破裂凸出来的高墙，</span><br /><span className="pl pl-1">顷刻之间忽然坍塌；</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 2:9; 耶利米书 19:10–11; 彼得后书 2:4–5"> <span className="pl pl-1">要被打碎，好像把窑匠的瓦器打碎，</span><br /><span className="pl pl-1">毫不顾惜，</span><br /><span className="pl pl-1">甚至碎块中找不到一片可用以从炉内取火，</span><br /><span className="pl pl-1">从池中舀水。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 26:3–4; 以赛亚书 32:17; 耶利米书 3:22–23"> <span className="pl pl-1">主耶和华—以色列的圣者曾如此说：</span><br /><span className="pl pl-1">你们得救在乎归回安息；</span><br /><span className="pl pl-1">你们得力在乎平静安稳；</span><br /><span className="pl pl-1">你们竟自不肯。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 31:1; 以赛亚书 31:3; 申命记 28:25"> <span className="pl pl-1">你们却说：不然，我们要骑马奔走。</span><br /><span className="pl pl-1">所以你们必然奔走；</span><br /><span className="pl pl-1">又说：我们要骑飞快的牲口。</span><br /><span className="pl pl-1">所以追赶你们的，也必飞快。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="申命记 28:25; 约书亚记 23:10; 申命记 32:30"> <span className="pl pl-1">一人叱喝，必令千人逃跑；</span><br /><span className="pl pl-1">五人叱喝，你们都必逃跑；</span><br /><span className="pl pl-1">以致剩下的，好像山顶的旗杆，</span><br /><span className="pl pl-1">冈上的大旗。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="耶利米哀歌 3:25–26; 彼得后书 3:9; 箴言 16:20"> <span className="pl pl-1">耶和华必然等候，要施恩给你们；</span><br /><span className="pl pl-1">必然兴起，好怜悯你们。</span><br /><span className="pl pl-1">因为耶和华是公平的 神；</span><br /><span className="pl pl-1">凡等候他的都是有福的！</span></span>
</div>
</div>

## 神要赐福给他的子民

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 60:20; 诗篇 50:15; 以赛亚书 65:24"> 百姓必在锡安、在耶路撒冷居住；你不再哭泣。主必因你哀求的声音施恩给你；他听见的时候就必应允你。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 22:27; 诗篇 80:5; 阿摩司书 8:11–12"> 主虽然以艰难给你当饼，以困苦给你当水，你的教师却不再隐藏；你眼必看见你的教师。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 32:8; 箴言 3:5–6; 以赛亚书 58:11"> 你或向左或向右，你必听见后边有声音说：「这是正路，要行在其间。」</span>
<span className="v" id="v22" data-v="22" data-xref="士师记 17:3–4; 以赛亚书 31:7; 撒迦利亚书 13:2"> 你雕刻偶像所包的银子和铸造偶像所镀的金子，你要玷污，要抛弃，好像污秽之物，对偶像说：「去吧！」</span>
<span className="v" id="v23" data-v="23" data-xref="撒迦利亚书 8:11–12; 以赛亚书 32:20; 诗篇 65:9–13"> 你将种子撒在地里，主必降雨在其上，并使地所出的粮肥美丰盛。到那时，你的牲畜必在宽阔的草场吃草。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 45:6; 申命记 25:4; 撒母耳记上 8:12"> 耕地的牛和驴驹必吃加盐的料；这料是用木杴和杈子扬净的。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 43:19–20; 以赛亚书 35:6–7; 以赛亚书 2:14–15"> 在大行杀戮的日子，高台倒塌的时候，各高山冈陵必有川流河涌。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 60:19–20; 申命记 32:39; 启示录 22:5"> 当耶和华缠裹他百姓的损处，医治他民鞭伤的日子，月光必像日光，日光必加七倍，像七日的光一样。</span>
</div>
</div>

## 神要惩罚亚述

<div className="bt">
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="帖撒罗尼迦后书 2:8; 那鸿书 1:5–6; 诗篇 18:7–9"> <span className="pl pl-1">看哪，耶和华的名从远方来，</span><br /><span className="pl pl-1">怒气烧起，密烟上腾。</span><br /><span className="pl pl-1">他的嘴唇满有忿恨；</span><br /><span className="pl pl-1">他的舌头像吞灭的火。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 37:29; 以赛亚书 11:4; 帖撒罗尼迦后书 2:8"> <span className="pl pl-1">他的气如涨溢的河水，直涨到颈项，</span><br /><span className="pl pl-1">要用毁灭的筛箩筛净列国，</span><br /><span className="pl pl-1">并且在众民的口中必有使人错行的嚼环。</span></span>
<span className="v" id="v29" data-v="29" data-xref="诗篇 42:4; 诗篇 95:1–2; 出埃及记 15:1–21"> 你们必唱歌，像守圣节的夜间一样，并且心中喜乐，像人吹笛，上耶和华的山，到以色列的磐石那里。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 18:13–14; 约书亚记 10:11; 以赛亚书 29:6"> 耶和华必使人听他威严的声音，又显他降罚的膀臂和他怒中的忿恨，并吞灭的火焰与霹雷、暴风、冰雹。</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 11:4; 以赛亚书 9:4; 弥迦书 5:5–6"> 亚述人必因耶和华的声音惊惶；耶和华必用杖击打他。</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 11:15; 以赛亚书 19:16; 以赛亚书 2:19"> 耶和华必将命定的杖加在他身上；每打一下，人必击鼓弹琴。打杖的时候，耶和华必抡起手来，与他交战。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪下 23:10; 创世记 19:24; 耶利米书 19:6"> 原来陀斐特又深又宽，早已为王预备好了；其中堆的是火与许多木柴。耶和华的气如一股硫磺火使他着起来。</span>
</div>

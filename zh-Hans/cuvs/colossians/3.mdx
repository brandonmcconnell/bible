<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 8:6; 马太福音 6:33; 哥林多后书 4:18"> 所以，你们若真与基督一同复活，就当求在上面的事；那里有基督坐在 神的右边。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 2:15–17; 历代志上 22:19; 歌罗西书 3:1"> 你们要思念上面的事，不要思念地上的事。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 2:20; 罗马书 6:2; 歌罗西书 2:20"> 因为你们已经死了，你们的生命与基督一同藏在 神里面。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 11:25; 约翰一书 3:2; 加拉太书 2:20"> 基督是我们的生命，他显现的时候，你们也要与他一同显现在荣耀里。</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 8:13; 加拉太书 5:19–21; 加拉太书 5:24"> 所以，要治死你们在地上的肢体，就如淫乱、污秽、邪情、恶欲，和贪婪（贪婪就与拜偶像一样）。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所书 5:6; 罗马书 1:18; 彼得前书 1:14"> 因这些事， 神的忿怒必临到那悖逆之子。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 2:2; 彼得前书 4:3–4; 罗马书 6:19–20"> 当你们在这些事中活着的时候，也曾这样行过。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 4:29; 以弗所书 4:22; 雅各书 1:20–21"> 但现在你们要弃绝这一切的事，以及恼恨、忿怒、恶毒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：阴毒">a</a></sup>、毁谤，并口中污秽的言语。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 4:22; 以弗所书 4:25; 利未记 19:11"> 不要彼此说谎；因你们已经脱去旧人和旧人的行为，</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 4:23–24; 罗马书 12:2; 以弗所书 2:10"> 穿上了新人。这新人在知识上渐渐更新，正如造他主的形象。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太书 3:28–29; 哥林多前书 12:13; 罗马书 10:12"> 在此并不分希腊人、犹太人，受割礼的、未受割礼的，化外人、西古提人，为奴的、自主的，惟有基督是包括一切，又住在各人之内。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 4:32; 以弗所书 4:2; 约翰一书 4:19"> 所以，你们既是 神的选民，圣洁蒙爱的人，就要存<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是穿；下同">b</a></sup>怜悯、恩慈、谦虚、温柔、忍耐的心。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 4:32; 马可福音 11:25; 雅各书 2:13"> 倘若这人与那人有嫌隙，总要彼此包容，彼此饶恕；主怎样饶恕了你们，你们也要怎样饶恕人。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 4:8; 以弗所书 5:2; 哥林多前书 13:1–13"> 在这一切之外，要存着爱心，爱心就是联络全德的。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比书 4:6–7; 约翰福音 14:27; 以赛亚书 26:3"> 又要叫基督的平安在你们心里作主；你们也为此蒙召，归为一体；且要存感谢的心。</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 119:11; 以弗所书 5:19; 约翰福音 15:7"> 当用各样的智慧，把基督的道理丰丰富富地存在心里<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或译：当把基督的道理丰丰富富地存在心里，以各样的智慧">c</a></sup>，用诗章、颂词、灵歌，彼此教导，互相劝戒，心被恩感，歌颂 神。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 10:31; 歌罗西书 3:23; 箴言 3:6"> 无论做什么，或说话或行事，都要奉主耶稣的名，借着他感谢父 神。</span>
</div>

## 新生活的本分

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以弗所书 5:22–9; 提多书 2:4–5; 哥林多前书 11:3"> 你们作妻子的，当顺服自己的丈夫，这在主里面是相宜的。</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前书 3:7; 创世记 2:23–24; 歌罗西书 3:21"> 你们作丈夫的，要爱你们的妻子，不可苦待她们。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 20:12; 以弗所书 6:1–3; 箴言 6:20"> 你们作儿女的，要凡事听从父母，因为这是主所喜悦的。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 4:1–4; 以弗所书 6:4; 诗篇 103:13"> 你们作父亲的，不要惹儿女的气，恐怕他们失了志气。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 6:5–7; 提摩太前书 6:1–2; 加拉太书 1:10"> 你们作仆人的，要凡事听从你们肉身的主人，不要只在眼前事奉，像是讨人喜欢的，总要存心诚实敬畏主。</span>
<span className="v" id="v23" data-v="23" data-xref="歌罗西书 3:17; 以弗所书 6:6–7; 罗马书 14:8"> 无论做什么，都要从心里做，像是给主做的，不是给人做的，</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所书 6:8; 加拉太书 1:10; 使徒行传 20:32"> 因你们知道从主那里必得着基业为赏赐；你们所事奉的乃是主基督。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 10:34; 罗马书 2:11; 哥林多后书 5:10"> 那行不义的必受不义的报应；主并不偏待人。</span>
</div>

## 以色列的余民

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 11:22; 撒母耳记上 12:22; 腓立比书 3:5"> 我且说， 神弃绝了他的百姓吗？断乎没有！因为我也是以色列人，亚伯拉罕的后裔，属便雅悯支派的。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 94:14; 罗马书 8:29–30; 出埃及记 32:1"> 神并没有弃绝他预先所知道的百姓。你们岂不晓得经上论到以利亚是怎么说的呢？他在 神面前怎样控告以色列人说：</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 19:10–18; 列王纪上 18:13; 尼希米记 9:26"> 「主啊，他们杀了你的先知，拆了你的祭坛，只剩下我一个人；他们还要寻索我的命。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 19:18; 民数记 25:3; 西番雅书 1:4"> 神的回话是怎么说的呢？他说：「我为自己留下七千人，是未曾向巴力屈膝的。」</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 9:27; 以弗所书 1:5–6; 罗马书 9:11"> 如今也是这样，照着拣选的恩典，还有所留的余数。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 2:21; 罗马书 4:4–5; 提摩太后书 1:9"> 既是出于恩典，就不在乎行为；不然，恩典就不是恩典了。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 9:18; 罗马书 11:5; 哥林多后书 4:4"> 这是怎么样呢？以色列人所求的，他们没有得着。惟有蒙拣选的人得着了；其余的就成了顽梗不化的。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 29:4; 以赛亚书 29:10; 以西结书 12:2"> 如经上所记：<br /><span className="pl pl-1">神给他们昏迷的心，</span><br /><span className="pl pl-1">眼睛不能看见，</span><br /><span className="pl pl-1">耳朵不能听见，</span><br /><span className="pl pl-1">直到今日。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="诗篇 69:22–23; 路加福音 12:20; 诗篇 28:4"> 大卫也说：<br /><span className="pl pl-1">愿他们的筵席变为网罗，变为机槛，</span><br /><span className="pl pl-1">变为绊脚石，作他们的报应。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 69:23; 申命记 28:64–68; 彼得后书 2:4"> <span className="pl pl-1">愿他们的眼睛昏蒙，不得看见；</span><br /><span className="pl pl-1">愿你时常弯下他们的腰。</span></span>
</div>
</div>

## 外邦人得救

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 13:46–48; 罗马书 11:31; 罗马书 10:19"> 我且说，他们失脚是要他们跌倒吗？断乎不是！反倒因他们的过失，救恩便临到外邦人，要激动他们发愤。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 11:25; 歌罗西书 1:27; 罗马书 11:15"> 若他们的过失为天下的富足，他们的缺乏为外邦人的富足，何况他们的丰满呢？</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 9:15; 提摩太后书 1:11–12; 以弗所书 3:8"> 我对你们外邦人说这话；因我是外邦人的使徒，所以敬重<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是荣耀">a</a></sup>我的职分，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 7:16; 提摩太前书 4:16; 罗马书 9:3"> 或者可以激动我骨肉之亲发愤，好救他们一些人。</span>
<span className="v" id="v15" data-v="15" data-xref="以弗所书 1:10; 罗马书 5:10–11; 歌罗西书 1:20–21"> 若他们被丢弃，天下就得与 神和好，他们被收纳，岂不是死而复生吗？</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 44:30; 雅各书 1:18; 箴言 3:9"> 所献的新面若是圣洁，全团也就圣洁了；树根若是圣洁，树枝也就圣洁了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以弗所书 2:11–13; 以弗所书 3:6; 马太福音 21:43"> 若有几根枝子被折下来，你这野橄榄得接在其中，一同得着橄榄根的肥汁，</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 10:12; 罗马书 11:20; 以弗所书 2:19–20"> 你就不可向旧枝子夸口；若是夸口，当知道不是你托着根，乃是根托着你。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 11:17; 罗马书 11:11–12; 罗马书 11:23–24"> 你若说，那枝子被折下来是特为叫我接上。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 12:16; 哥林多后书 1:24; 哥林多前书 10:12"> 不错！他们因为不信，所以被折下来；你因为信，所以立得住；你不可自高，反要惧怕。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得后书 2:4–9; 耶利米书 25:29; 耶利米书 49:12"> 神既不爱惜原来的枝子，也必不爱惜你。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 3:14; 希伯来书 3:6; 哥林多前书 15:2"> 可见， 神的恩慈和严厉向那跌倒的人是严厉的，向你是有恩慈的，只要你长久在他的恩慈里；不然，你也要被砍下来。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 3:16; 撒迦利亚书 12:10; 马太福音 23:39"> 而且他们若不是长久不信，仍要被接上，因为 神能够把他们从新接上。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 11:17–18; 罗马书 11:30"> 你是从那天生的野橄榄上砍下来的，尚且逆着性得接在好橄榄上，何况这本树的枝子，要接在本树上呢！</span>
</div>
</div>

## 以色列人的复兴

<div className="bt">
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="路加福音 21:24; 哥林多后书 3:14–16; 罗马书 16:25"> 弟兄们，我不愿意你们不知道这奥秘（恐怕你们自以为聪明），就是以色列人有几分是硬心的，等到外邦人的数目添满了，</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 59:20; 耶利米书 31:31–37; 诗篇 14:7"> 于是以色列全家都要得救。如经上所记：<br /><span className="pl pl-1">必有一位救主从锡安出来，</span><br /><span className="pl pl-1">要消除雅各家的一切罪恶；</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 31:31–34; 以赛亚书 59:21; 以西结书 36:25–29"> <span className="pl pl-1">又说：我除去他们罪的时候，</span><br /><span className="pl pl-1">这就是我与他们所立的约。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="申命记 10:15; 申命记 7:7–8; 马太福音 21:43"> 就着福音说，他们为你们的缘故是仇敌；就着拣选说，他们为列祖的缘故是蒙爱的。</span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 7:21; 民数记 23:19; 玛拉基书 3:6"> 因为 神的恩赐和选召是没有后悔的。</span>
<span className="v" id="v30" data-v="30" data-xref="歌罗西书 3:7; 以弗所书 2:1–2; 哥林多前书 7:25"> 你们从前不顺服 神，如今因他们的不顺服，你们倒蒙了怜恤。</span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 11:15; 罗马书 10:16; 罗马书 11:25"> 这样，他们也是不顺服，叫他们因着施给你们的怜恤，现在也就蒙怜恤。</span>
<span className="v" id="v32" data-v="32" data-xref="加拉太书 3:22; 罗马书 3:9; 提摩太前书 2:4–6"> 因为 神将众人都圈在不顺服之中，特意要怜恤众人。</span>
<span className="v" id="v33" data-v="33" data-xref="约伯记 5:9; 约伯记 11:7–9; 诗篇 92:5"> <span className="pl pl-1">深哉， 神丰富的智慧和知识！</span><br /><span className="pl pl-1">他的判断何其难测！</span><br /><span className="pl pl-1">他的踪迹何其难寻！</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="以赛亚书 40:13; 哥林多前书 2:16; 约伯记 15:8"> <span className="pl pl-1">谁知道主的心？</span><br /><span className="pl pl-1">谁作过他的谋士呢？</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="约伯记 41:11; 约伯记 35:7; 哥林多前书 4:7"> <span className="pl pl-1">谁是先给了他，</span><br /><span className="pl pl-1">使他后来偿还呢？</span><br /></span>
<span className="v" id="v36" data-v="36" data-xref="歌罗西书 1:15–17; 哥林多前书 8:6; 希伯来书 2:10"> <span className="pl pl-1">因为万有都是本于他，</span><br /><span className="pl pl-1">倚靠他，归于他。</span><br /><span className="pl pl-1">愿荣耀归给他，直到永远。阿们！</span></span>
</div>
</div>

## 不求自己的喜悦，要叫邻舍喜悦

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 5:14; 罗马书 14:1; 加拉太书 6:1–2"> 我们坚固的人应该担代不坚固人的软弱，不求自己的喜悦。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 14:19; 哥林多前书 10:24; 腓立比书 2:4–5"> 我们各人务要叫邻舍喜悦，使他得益处，建立德行。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 69:9; 腓立比书 2:8; 约翰福音 4:34"> 因为基督也不求自己的喜悦，如经上所记：「辱骂你人的辱骂都落在我身上。」</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 10:11; 提摩太后书 3:16–17; 罗马书 4:23–24"> 从前所写的圣经都是为教训我们写的，叫我们因圣经所生的忍耐和安慰可以得着盼望。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 2:4–5; 彼得前书 3:8; 罗马书 12:16"> 但愿赐忍耐安慰的 神叫你们彼此同心，效法基督耶稣，</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 10:29–30; 启示录 1:6; 以弗所书 1:3"> 一心一口荣耀 神—我们主耶稣基督的父！</span>
</div>
</div>

## 神的福音一视同仁

<div className="bt">
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="马太福音 10:40; 约翰福音 13:34; 罗马书 5:2"> 所以，你们要彼此接纳，如同基督接纳你们一样，使荣耀归与 神。</span>
<span className="v" id="v8" data-v="8" data-xref="加拉太书 4:4–5; 马太福音 15:24; 约翰福音 1:11"> 我说，基督是为 神真理作了受割礼人的执事，要证实所应许列祖的话，</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 22:50; 诗篇 18:49; 罗马书 3:29"> 并叫外邦人因他的怜悯荣耀 神。如经上所记：<br /><span className="pl pl-1">因此，我要在外邦中称赞你，</span><br /><span className="pl pl-1">歌颂你的名；</span></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 67:3–4; 申命记 32:43; 以赛亚书 42:10–12"> 又说：<br /><span className="pl pl-1">你们外邦人当与主的百姓一同欢乐；</span></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 117:1"> 又说：<br /><span className="pl pl-1">外邦啊，你们当赞美主！</span><br /><span className="pl pl-1">万民哪，你们都当颂赞他！</span></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 11:10; 以赛亚书 11:1; 马太福音 12:21"> 又有以赛亚说：<br /><span className="pl pl-1">将来有耶西的根，</span><br /><span className="pl pl-1">就是那兴起来要治理外邦的；</span><br /><span className="pl pl-1">外邦人要仰望他。</span></span>
<span className="v" id="v13" data-v="13" data-xref="帖撒罗尼迦后书 2:16–17; 罗马书 12:12; 哥林多后书 9:8"> 但愿使人有盼望的 神，因信将诸般的喜乐、平安充满你们的心，使你们借着圣灵的能力大有盼望！</span>
</div>
</div>

## 保罗的宣教使命

<div className="bt">
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="歌罗西书 3:16; 彼得后书 1:12; 约翰一书 2:21"> 弟兄们，我自己也深信你们是满有良善，充足了诸般的知识，也能彼此劝戒。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 12:3; 哥林多前书 15:10; 罗马书 1:5"> 但我稍微放胆写信给你们，是要提醒你们的记性，特因 神所给我的恩典，</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 11:13; 罗马书 1:1; 使徒行传 9:15"> 使我为外邦人作基督耶稣的仆役，作 神福音的祭司，叫所献上的外邦人，因着圣灵成为圣洁，可蒙悦纳。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 2:14–16; 哥林多后书 12:11–21; 希伯来书 5:1"> 所以论到 神的事，我在基督耶稣里有可夸的。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 15:12; 罗马书 1:5; 使徒行传 21:19"> 除了基督借我做的那些事，我什么都不敢提，只提他借我言语作为，用神迹奇事的能力，并圣灵的能力，使外邦人顺服；</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多后书 12:12; 希伯来书 2:4; 使徒行传 19:11–12"> 甚至我从耶路撒冷，直转到以利哩古，到处传了基督的福音。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 10:13–16; 哥林多前书 3:9–15; 以弗所书 2:20–22"> 我立了志向，不在基督的名被称过的地方传福音，免得建造在别人的根基上。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 52:15; 以赛亚书 65:1"> 就如经上所记：<br /><span className="pl pl-1">未曾闻知他信息的，将要看见；</span><br /><span className="pl pl-1">未曾听过的，将要明白。</span></span>
</div>
</div>

## 保罗计划访问罗马

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="罗马书 1:13; 帖撒罗尼迦前书 2:17–18"> 我因多次被拦阻，总不得到你们那里去。</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 15:32; 罗马书 1:10–12; 罗马书 15:29"> 但如今，在这里再没有可传的地方，而且这好几年，我切心想望到西班牙去的时候，可以到你们那里，</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 15:28; 罗马书 1:12; 使徒行传 15:3"> 盼望从你们那里经过，得见你们，先与你们彼此交往，心里稍微满足，然后蒙你们送行。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 24:17; 使徒行传 19:21; 使徒行传 20:22"> 但现在，我往耶路撒冷去供给圣徒。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多后书 8:1–9; 使徒行传 11:27–30; 哥林多后书 9:2"> 因为马其顿和亚该亚人乐意凑出捐项给耶路撒冷圣徒中的穷人。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 9:11; 加拉太书 6:6; 腓利门书 1:19"> 这固然是他们乐意的，其实也算是所欠的债；因外邦人既然在他们属灵的好处上有分，就当把养身之物供给他们。</span>
<span className="v" id="v28" data-v="28" data-xref="罗马书 15:24; 腓立比书 4:17; 歌罗西书 1:6"> 等我办完了这事，把这善果向他们交付明白，我就要路过你们那里，往西班牙去。</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所书 4:13; 罗马书 1:10–12; 诗篇 16:11"> 我也晓得，去的时候必带着基督丰盛的恩典而去。</span>
<span className="v" id="v30" data-v="30" data-xref="歌罗西书 4:12; 哥林多后书 1:11; 哥林多后书 4:11"> 弟兄们，我借着我们主耶稣基督，又借着圣灵的爱，劝你们与我一同竭力，为我祈求 神，</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒罗尼迦后书 3:2; 哥林多后书 8:4; 哥林多后书 9:1"> 叫我脱离在犹太不顺从的人，也叫我为耶路撒冷所办的捐项可蒙圣徒悦纳，</span>
<span className="v" id="v32" data-v="32" data-xref="哥林多前书 16:18; 腓利门书 1:20; 腓利门书 1:7"> 并叫我顺着 神的旨意，欢欢喜喜地到你们那里，与你们同得安息。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多后书 13:11; 腓立比书 4:9; 帖撒罗尼迦前书 5:23"> 愿赐平安的 神常和你们众人同在。阿们！</span>
</div>
</div>

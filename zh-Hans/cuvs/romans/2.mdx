## 神的公义判断

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 6:37; 罗马书 2:3; 约翰福音 8:7–9"> 你这论断人的，无论你是谁，也无可推诿。你在什么事上论断人，就在什么事上定自己的罪；因你这论断人的，自己所行却和别人一样。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 9:7–8; 西番雅书 3:5; 诗篇 145:17"> 我们知道这样行的人， 神必照真理审判他。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 16:5; 路加福音 12:14; 罗马书 1:32–1"> 你这人哪，你论断行这样事的人，自己所行的却和别人一样，你以为能逃脱 神的审判吗？</span>
<span className="v" id="v4" data-v="4" data-xref="彼得后书 3:9; 以赛亚书 30:18; 出埃及记 34:6"> 还是你藐视他丰富的恩慈、宽容、忍耐，不晓得他的恩慈是领你悔改呢？</span>
<span className="v" id="v5" data-v="5" data-xref="传道书 12:14; 罗马书 1:18; 罗马书 2:2–3"> 你竟任着你刚硬不悔改的心，为自己积蓄忿怒，以致 神震怒，显他公义审判的日子来到。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 62:12; 耶利米书 32:19; 马太福音 16:27"> 他必照各人的行为报应各人。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太后书 4:7–8; 路加福音 8:15; 提摩太后书 1:10"> 凡恒心行善、寻求荣耀、尊贵和不能朽坏之福的，就以永生报应他们；</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 3:18–21; 帖撒罗尼迦后书 1:8; 提摩太前书 6:3–4"> 惟有结党、不顺从真理、反顺从不义的，就以忿怒、恼恨报应他们；</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 4:17; 以西结书 18:4; 罗马书 1:16"> 将患难、困苦加给一切作恶的人，先是犹太人，后是希腊人，</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 32:17; 以赛亚书 26:12; 民数记 6:26"> 却将荣耀、尊贵、平安加给一切行善的人，先是犹太人，后是希腊人。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 10:17; 使徒行传 10:34; 历代志下 19:7"> 因为 神不偏待人。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 9:21; 加拉太书 3:10; 加拉太书 2:16–19"> 凡没有律法犯了罪的，也必不按律法灭亡；凡在律法以下犯了罪的，也必按律法受审判。（</span>
<span className="v" id="v13" data-v="13" data-xref="雅各书 1:22–25; 约翰一书 3:7; 雅各书 2:21–25"> 原来在 神面前，不是听律法的为义，乃是行律法的称义。</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 2:12; 罗马书 1:19–20; 罗马书 2:27"> 没有律法的外邦人若顺着本性行律法上的事，他们虽然没有律法，自己就是自己的律法。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多后书 5:11; 哥林多后书 1:12; 罗马书 1:18–19"> 这是显出律法的功用刻在他们心里，他们是非之心同作见证，并且他们的思念互相较量，或以为是，或以为非。）</span>
<span className="v" id="v16" data-v="16" data-xref="传道书 12:14; 哥林多前书 4:5; 使徒行传 17:31"> 就在 神借耶稣基督审判人隐秘事的日子，照着我的福音所言。</span>
</div>
</div>

## 犹太人与律法

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 2:23; 弥迦书 3:11; 以赛亚书 48:1–2"> 你称为犹太人，又倚靠律法，且指着 神夸口；</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 5:21; 申命记 4:8; 雅各书 4:17"> 既从律法中受了教训，就晓得 神的旨意，也能分别是非<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：也喜爱那美好的事">a</a></sup>；</span>
<span className="v" id="v19" data-v="19" data-xref="启示录 3:17–18; 马太福音 15:14; 以赛亚书 49:6"> 又深信自己是给瞎子领路的，是黑暗中人的光，</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太后书 3:5; 提多书 1:16; 提摩太后书 1:13"> 是蠢笨人的师傅，是小孩子的先生，在律法上有知识和真理的模范。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 9:27; 马太福音 23:3–28; 路加福音 12:47"> 你既是教导别人，还不教导自己吗？你讲说人不可偷窃，自己还偷窃吗？</span>
<span className="v" id="v22" data-v="22" data-xref="玛拉基书 3:8; 马太福音 12:39; 马可福音 11:17"> 你说人不可奸淫，自己还奸淫吗？你厌恶偶像，自己还偷窃庙中之物吗？</span>
<span className="v" id="v23" data-v="23" data-xref="雅各书 4:16–17; 罗马书 2:17; 罗马书 3:2"> 你指着律法夸口，自己倒犯律法、玷辱 神吗？</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 36:20–23; 以赛亚书 52:5; 彼得后书 2:2"> 神的名在外邦人中，因你们受了亵渎，正如经上所记的。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 4:4; 加拉太书 5:3–6; 使徒行传 7:51"> 你若是行律法的，割礼固然于你有益；若是犯律法的，你的割礼就算不得割礼。</span>
<span className="v" id="v26" data-v="26" data-xref="歌罗西书 2:11; 哥林多前书 7:18–19; 罗马书 8:4"> 所以那未受割礼的，若遵守律法的条例，他虽然未受割礼，岂不算是有割礼吗？</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 12:41–42; 罗马书 2:29; 哥林多后书 3:6"> 而且那本来未受割礼的，若能全守律法，岂不是要审判你这有仪文和割礼竟犯律法的人吗？</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太书 6:15; 马太福音 3:9; 罗马书 9:6–8"> 因为外面作犹太人的，不是真犹太人；外面肉身的割礼，也不是真割礼。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 30:6; 腓立比书 3:3; 申命记 10:16"> 惟有里面作的，才是真犹太人；真割礼也是心里的，在乎灵，不在乎仪文。这人的称赞不是从人来的，乃是从 神来的。</span>
</div>

## 求告主名的必要得救

<div className="bt">
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="利未记 18:5; 以西结书 20:11; 尼希米记 9:29"> 摩西写着说：「人若行那出于律法的义，就必因此活着。」</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 30:11–14; 箴言 30:4; 以弗所书 4:8–10"> 惟有出于信心的义如此说：「你不要心里说：谁要升到天上去呢？（就是要领下基督来；）</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 13:20; 启示录 1:18; 罗马书 4:25"> 谁要下到阴间去呢？（就是要领基督从死里上来。）」</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 30:14; 罗马书 1:16–17; 提摩太前书 4:6"> 他到底怎么说呢？他说：<br /><span className="pl pl-1">这道离你不远，</span><br /><span className="pl pl-1">正在你口里，在你心里—</span><br />（就是我们所传信主的道。）</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 12:8; 使徒行传 16:31; 腓立比书 2:11"> 你若口里认耶稣为主，心里信 神叫他从死里复活，就必得救。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 4:15; 罗马书 10:9; 加拉太书 2:16"> 因为，人心里相信就可以称义，口里承认就可以得救。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 28:16; 罗马书 9:33; 彼得前书 2:6"> 经上说：「凡信他的人必不至于羞愧。」</span>
<span className="v" id="v12" data-v="12" data-xref="腓立比书 4:19; 启示录 17:14; 加拉太书 3:28"> 犹太人和希腊人并没有分别，因为众人同有一位主；他也厚待一切求告他的人。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 2:21; 约珥书 2:32"> 因为「凡求告主名的就必得救」。</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="马可福音 16:15–16; 使徒行传 26:17–18; 提多书 1:3"> 然而，人未曾信他，怎能求他呢？未曾听见他，怎能信他呢？没有传道的，怎能听见呢？</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 52:7; 那鸿书 1:15; 以弗所书 2:17"> 若没有奉差遣，怎能传道呢？如经上所记：「报福音、传喜信的人，他们的脚踪何等佳美！」</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 53:1; 罗马书 3:3; 约翰福音 12:38–40"> 只是人没有都听从福音，因为以赛亚说：「主啊，我们所传的有谁信呢？」</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 3:2; 加拉太书 3:5; 帖撒罗尼迦前书 2:13"> 可见，信道是从听道来的，听道是从基督的话来的。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 19:4; 罗马书 1:8; 马太福音 24:14"> 但我说，人没有听见吗？诚然听见了。<br /><span className="pl pl-1">他们的声音传遍天下；</span><br /><span className="pl pl-1">他们的言语传到地极。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="申命记 32:21; 罗马书 11:11; 罗马书 11:14"> 我再说，以色列人不知道吗？先有摩西说：<br /><span className="pl pl-1">我要用那不成子民的惹动你们的愤恨；</span><br /><span className="pl pl-1">我要用那无知的民触动你们的怒气。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 65:1–2; 罗马书 9:30; 以赛亚书 55:4–5"> 又有以赛亚放胆说：<br /><span className="pl pl-1">没有寻找我的，我叫他们遇见；</span><br /><span className="pl pl-1">没有访问我的，我向他们显现。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 65:2–5; 彼得前书 2:8; 耶利米书 35:15"> 至于以色列人，他说：「我整天伸手招呼那悖逆顶嘴的百姓。」</span>
</div>

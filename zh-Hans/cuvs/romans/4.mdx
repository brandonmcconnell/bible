## 以亚伯拉罕为例

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 51:2; 罗马书 4:16; 哥林多后书 11:22"> 如此说来，我们的祖宗亚伯拉罕凭着肉体得了什么呢？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 1:31; 哥林多后书 11:30; 腓立比书 3:9"> 倘若亚伯拉罕是因行为称义，就有可夸的；只是在 神面前并无可夸。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 15:6; 雅各书 2:23; 加拉太书 3:6–8"> 经上说什么呢？说：「亚伯拉罕信 神，这就算为他的义。」</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 11:6; 罗马书 9:32; 罗马书 11:35"> 做工的得工价，不算恩典，乃是该得的；</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 3:9; 罗马书 3:22; 提多书 3:3–7"> 惟有不做工的，只信称罪人为义的 神，他的信就算为义。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太后书 1:9; 腓立比书 3:9; 哥林多前书 1:30"> 正如大卫称那在行为以外蒙 神算为义的人是有福的。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 32:1–2; 诗篇 130:3–4; 路加福音 7:47–50"> 他说：<br /><span className="pl pl-1">得赦免其过、遮盖其罪的，</span><br /><span className="pl pl-1">这人是有福的。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 32:2; 彼得前书 2:24; 哥林多后书 5:19–20"> <span className="pl pl-1">主不算为有罪的，</span><br /><span className="pl pl-1">这人是有福的。</span></span>
<span className="v" id="v9" data-v="9" data-xref="加拉太书 3:14; 歌罗西书 3:11; 加拉太书 3:26–28"> 如此看来，这福是单加给那受割礼的人吗？不也是加给那未受割礼的人吗？因我们所说，亚伯拉罕的信，就算为他的义，</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 6:15; 加拉太书 5:6; 创世记 17:10"> 是怎么算的呢？是在他受割礼的时候呢？是在他未受割礼的时候呢？不是在受割礼的时候，乃是在未受割礼的时候。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 3:22; 路加福音 19:9; 哥林多后书 1:22"> 并且他受了割礼的记号，作他未受割礼的时候因信称义的印证，叫他作一切未受割礼而信之人的父，使他们也算为义；</span>
<span className="v" id="v12" data-v="12" data-xref="雅歌 1:8; 约翰福音 8:39–40; 箴言 2:20"> 又作受割礼之人的父，就是那些不但受割礼，并且按我们的祖宗亚伯拉罕未受割礼而信之踪迹去行的人。</span>
</div>
</div>

## 应许因信而实现

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="加拉太书 3:29; 创世记 22:17–18; 创世记 28:14"> 因为 神应许亚伯拉罕和他后裔，必得承受世界，不是因律法，乃是因信而得的义。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 3:18–24; 腓立比书 3:9; 罗马书 4:16"> 若是属乎律法的人才得为后嗣，信就归于虚空，应许也就废弃了。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 5:13; 加拉太书 3:10; 罗马书 3:19–20"> 因为律法是惹动忿怒的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：叫人受刑的">a</a></sup>；哪里没有律法，那里就没有过犯。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 3:24–26; 以弗所书 2:8; 加拉太书 3:22"> 所以人得为后嗣是本乎信，因此就属乎恩，叫应许定然归给一切后裔；不但归给那属乎律法的，也归给那效法亚伯拉罕之信的。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 1:28; 创世记 17:4–5; 约翰福音 5:21"> 亚伯拉罕所信的，是那叫死人复活、使无变为有的 神，他在主面前作我们世人的父。如经上所记：「我已经立你作多国的父。」</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 8:24; 创世记 15:5–6; 使徒行传 27:25"> 他在无可指望的时候，因信仍有指望，就得以作多国的父，正如先前所说：「你的后裔将要如此。」</span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 11:11–19; 罗马书 4:20–21; 创世记 17:17"> 他将近百岁的时候，虽然想到自己的身体如同已死，撒拉的生育已经断绝，他的信心还是不软弱；</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 1:45; 哥林多前书 16:13; 但以理书 10:19"> 并且仰望 神的应许，总没有因不信心里起疑惑，反倒因信心里得坚固，将荣耀归给 神，</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:37; 耶利米书 32:27; 创世记 18:14"> 且满心相信 神所应许的必能做成。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 4:6; 罗马书 4:3"> 所以，这就算为他的义。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 10:11; 罗马书 15:4; 哥林多前书 10:6"> 「算为他义」的这句话不是单为他写的，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 2:24; 彼得前书 1:21; 使徒行传 13:30"> 也是为我们将来得算为义之人写的，就是我们这信 神使我们的主耶稣从死里复活的人。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰一书 4:9–10; 以赛亚书 53:5–6; 哥林多后书 5:21"> 耶稣被交给人，是为我们的过犯；复活，是为叫我们称义<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：耶稣是为我们的过犯交付了，是为我们称义复活了">b</a></sup>。</span>
</div>
</div>

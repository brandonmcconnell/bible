## 神拣选以色列人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="提摩太前书 2:7; 罗马书 1:9; 加拉太书 1:20"> 我在基督里说真话，并不谎言，有我良心被圣灵感动，给我作见证：</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比书 3:18; 诗篇 119:136; 耶利米书 13:17"> 我是大有忧愁，心里时常伤痛；</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 32:32; 以斯帖记 8:6; 罗马书 11:14"> 为我弟兄，我骨肉之亲，就是自己被咒诅，与基督分离，我也愿意。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 2:12; 诗篇 147:19; 罗马书 9:6"> 他们是以色列人；那儿子的名分、荣耀、诸约、律法、礼仪、应许都是他们的。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 10:30; 约翰福音 1:1–3; 歌罗西书 1:16–19"> 列祖就是他们的祖宗；按肉体说，基督也是从他们出来的。他是在万有之上，永远可称颂的 神。阿们！</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 2:28–29; 加拉太书 6:16; 罗马书 11:1–2"> 这不是说 神的话落了空。因为从以色列生的不都是以色列人，</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 21:12; 希伯来书 11:18; 约翰福音 8:37–39"> 也不因为是亚伯拉罕的后裔就都作他的儿女；惟独「从以撒生的才要称为你的后裔。」</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 1:13; 罗马书 4:11–16; 加拉太书 3:26–29"> 这就是说，肉身所生的儿女不是 神的儿女，惟独那应许的儿女才算是后裔。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 18:10; 创世记 18:14; 创世记 17:21"> 因为所应许的话是这样说：「到明年这时候我要来，撒拉必生一个儿子。」</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 25:21–23; 路加福音 16:26; 罗马书 5:11"> 不但如此，还有利百加，既从一个人，就是从我们的祖宗以撒怀了孕，（</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太后书 1:9; 以弗所书 1:4–5; 彼得后书 1:10"> 双子还没有生下来，善恶还没有做出来，只因要显明 神拣选人的旨意，不在乎人的行为，乃在乎召人的主。）</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 25:22–23; 撒母耳记下 8:14; 列王纪上 22:47"> 神就对利百加说：「将来，大的要服事小的。」</span>
<span className="v" id="v13" data-v="13" data-xref="玛拉基书 1:2–3; 申命记 21:15; 创世记 29:33"> 正如经上所记：雅各是我所爱的；以扫是我所恶的。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 19:7; 诗篇 145:17; 申命记 32:4"> 这样，我们可说什么呢？难道 神有什么不公平吗？断乎没有！</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 33:19; 罗马书 9:16; 弥迦书 7:18"> 因他对摩西说：<br /><span className="pl pl-1">我要怜悯谁就怜悯谁，</span><br /><span className="pl pl-1">要恩待谁就恩待谁。</span></span>
<span className="v" id="v16" data-v="16" data-xref="以弗所书 2:8; 马太福音 11:25–26; 彼得前书 2:9–10"> 据此看来，这不在乎那定意的，也不在乎那奔跑的，只在乎发怜悯的 神。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 9:16; 箴言 16:4; 出埃及记 14:17–18"> 因为经上有话向法老说：「我将你兴起来，特要在你身上彰显我的权能，并要使我的名传遍天下。」</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 11:20; 出埃及记 4:21; 罗马书 9:15–16"> 如此看来， 神要怜悯谁就怜悯谁，要叫谁刚硬就叫谁刚硬。</span>
</div>
</div>

## 神的忿怒和怜悯

<div className="bt">
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="但以理书 4:35; 历代志下 20:6; 哥林多前书 15:12"> 这样，你必对我说：「他为什么还指责人呢？有谁抗拒他的旨意呢？」</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 29:16; 以赛亚书 45:9–11; 以赛亚书 64:8"> 你这个人哪，你是谁，竟敢向 神强嘴呢？受造之物岂能对造他的说：「你为什么这样造我呢？」</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 64:8; 箴言 16:4; 提摩太后书 2:20–21"> 窑匠难道没有权柄从一团泥里拿一块做成贵重的器皿，又拿一块做成卑贱的器皿吗？</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 16:4; 犹大书 1:4; 罗马书 9:21"> 倘若 神要显明他的忿怒，彰显他的权能，就多多忍耐宽容那可怒、预备遭毁灭的器皿，</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 2:4; 彼得前书 1:2–5; 歌罗西书 1:27"> 又要将他丰盛的荣耀彰显在那蒙怜悯、早预备得荣耀的器皿上。</span>
<span className="v" id="v24" data-v="24" data-xref="歌罗西书 3:11; 使徒行传 13:47–48; 以弗所书 3:6–8"> 这器皿就是我们被 神所召的，不但是从犹太人中，也是从外邦人中。这有什么不可呢？</span>
<span className="v" id="v25" data-v="25" data-xref="何西阿书 2:23; 彼得前书 2:10; 约翰福音 16:27"> 就像 神在何西阿书上说：<br /><span className="pl pl-1">那本来不是我子民的，</span><br /><span className="pl pl-1">我要称为「我的子民」；</span><br /><span className="pl pl-1">本来不是蒙爱的，</span><br /><span className="pl pl-1">我要称为「蒙爱的」。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="何西阿书 1:9–10; 约翰一书 3:1–3; 加拉太书 3:26"> <span className="pl pl-1">从前在什么地方对他们说：</span><br /><span className="pl pl-1">你们不是我的子民，</span><br /><span className="pl pl-1">将来就在那里称他们为「永生 神的儿子」。</span></span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 10:20–23; 罗马书 11:4–6; 以赛亚书 1:9"> 以赛亚指着以色列人喊着说：「以色列人虽多如海沙，得救的不过是剩下的余数；</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 10:23; 启示录 19:11; 使徒行传 17:31"> 因为主要在世上施行他的话，叫他的话都成全，速速地完结。」</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 1:9; 以赛亚书 13:19; 阿摩司书 4:11"> 又如以赛亚先前说过：<br /><span className="pl pl-1">若不是万军之主给我们存留余种，</span><br /><span className="pl pl-1">我们早已像所多玛、蛾摩拉的样子了。</span></span>
</div>
</div>

## 以色列人和福音

<div className="bt">
<div className="bp poetry">
<span className="v" id="v30" data-v="30" data-xref="腓立比书 3:9; 希伯来书 11:7; 加拉太书 2:16"> 这样，我们可说什么呢？那本来不追求义的外邦人反得了义，就是因信而得的义。</span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 11:7; 罗马书 3:20; 雅各书 2:10–11"> 但以色列人追求律法的义，反得不着律法的义。</span>
<span className="v" id="v32" data-v="32" data-xref="哥林多前书 1:23; 彼得前书 2:8; 路加福音 7:23"> 这是什么缘故呢？是因为他们不凭着信心求，只凭着行为求；他们正跌在那绊脚石上。</span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 28:16; 以赛亚书 8:14–15; 罗马书 10:11"> 就如经上所记：<br /><span className="pl pl-1">我在锡安放一块绊脚的石头，跌人的磐石；</span><br /><span className="pl pl-1">信靠他的人必不至于羞愧。</span></span>
</div>

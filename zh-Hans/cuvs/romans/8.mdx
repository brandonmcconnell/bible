## 在圣灵里的生活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 3:18–19; 哥林多后书 5:17; 加拉太书 3:13"> 如今，那些在基督耶稣里的就不定罪了。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 6:14; 哥林多后书 3:17; 罗马书 6:18"> 因为赐生命圣灵的律，在基督耶稣里释放了我，使我脱离罪和死的律了。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 13:39; 加拉太书 4:4–5; 希伯来书 7:18–19"> 律法既因肉体软弱，有所不能行的， 神就差遣自己的儿子，成为罪身的形状，作了赎罪祭，在肉体中定了罪案，</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 5:16; 加拉太书 5:22–25; 歌罗西书 1:22"> 使律法的义成就在我们这不随从肉体、只随从圣灵的人身上。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 2:14; 加拉太书 5:19–25; 约翰福音 3:6"> 因为，随从肉体的人体贴肉体的事；随从圣灵的人体贴圣灵的事。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 6:8; 罗马书 8:7; 罗马书 8:13"> 体贴肉体的，就是死；体贴圣灵的，乃是生命、平安。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 2:14; 约翰一书 2:15–16; 雅各书 4:4"> 原来体贴肉体的，就是与 神为仇；因为不服 神的律法，也是不能服，</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 3:5–6; 希伯来书 11:5–6; 罗马书 8:9"> 而且属肉体的人不能得 神的喜欢。</span>
<span className="v" id="v9" data-v="9" data-xref="加拉太书 4:6; 哥林多前书 3:16; 提摩太后书 1:14"> 如果 神的灵住在你们心里，你们就不属肉体，乃属圣灵了。人若没有基督的灵，就不是属基督的。</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 3:17; 加拉太书 2:20; 哥林多后书 5:21"> 基督若在你们心里，身体就因罪而死，心灵却因义而活。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 4:14; 罗马书 6:4–5; 哥林多后书 4:11"> 然而，叫耶稣从死里复活者的灵若住在你们心里，那叫基督耶稣从死里复活的，也必借着住在你们心里的圣灵，使你们必死的身体又活过来。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="罗马书 6:2–15; 哥林多前书 6:19–20; 彼得前书 4:2–3"> 弟兄们，这样看来，我们并不是欠肉体的债去顺从肉体活着。</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太书 6:8; 彼得前书 2:11; 哥林多前书 9:27"> 你们若顺从肉体活着，必要死；若靠着圣灵治死身体的恶行，必要活着。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 5:18; 约翰福音 1:12; 加拉太书 3:26"> 因为凡被 神的灵引导的，都是 神的儿子。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 4:5–7; 提摩太后书 1:7; 哥林多前书 2:12"> 你们所受的，不是奴仆的心，仍旧害怕；所受的，乃是儿子的心，因此我们呼叫：「阿爸！父！」</span>
<span className="v" id="v16" data-v="16" data-xref="约翰一书 4:13; 哥林多后书 1:22; 哥林多后书 5:5"> 圣灵与我们的心同证我们是 神的儿女；</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 4:7; 加拉太书 3:29; 以弗所书 3:6"> 既是儿女，便是后嗣，就是 神的后嗣，和基督同作后嗣。如果我们和他一同受苦，也必和他一同得荣耀。</span>
</div>
</div>

## 将来的荣耀

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 4:17–18; 彼得前书 4:13; 彼得前书 1:5–7"> 我想，现在的苦楚若比起将来要显于我们的荣耀就不足介意了。</span>
<span className="v" id="v19" data-v="19" data-xref="玛拉基书 3:17–18; 罗马书 8:23; 约翰一书 3:2"> 受造之物切望等候 神的众子显出来。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 3:17–19; 创世记 5:29; 罗马书 8:22"> 因为受造之物服在虚空之下，不是自己愿意，乃是因那叫他如此的。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 22:3–5; 使徒行传 3:21; 彼得后书 3:13"> 但受造之物仍然指望脱离败坏的辖制，得享<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="享：原文是入">a</a></sup>神儿女自由的荣耀。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 12:4; 耶利米书 12:11; 约翰福音 16:21"> 我们知道，一切受造之物一同叹息，劳苦，直到如今。</span>
<span className="v" id="v23" data-v="23" data-xref="腓立比书 3:20–21; 哥林多后书 5:2–5; 希伯来书 9:28"> 不但如此，就是我们这有圣灵初结果子的，也是自己心里叹息，等候得着儿子的名分，乃是我们的身体得赎。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 5:7; 希伯来书 11:1; 哥林多后书 4:18"> 我们得救是在乎盼望；只是所见的盼望不是盼望，谁还盼望他所见的呢<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷：人所看见的何必再盼望呢">b</a></sup>？</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 12:12; 希伯来书 10:36; 诗篇 27:14"> 但我们若盼望那所不见的，就必忍耐等候。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 10:20; 以弗所书 6:18; 加拉太书 4:6"> 况且，我们的软弱有圣灵帮助；我们本不晓得当怎样祷告，只是圣灵亲自用说不出来的叹息替我们祷告。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 17:10; 约翰一书 5:14–15; 以弗所书 2:18"> 鉴察人心的，晓得圣灵的意思，因为圣灵照着 神的旨意替圣徒祈求。</span>
<span className="v" id="v28" data-v="28" data-xref="彼得前书 5:10; 雅各书 1:12; 创世记 50:20"> 我们晓得万事都互相效力，叫爱 神的人得益处，就是按他旨意被召的人。</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所书 1:4–5; 耶利米书 1:5; 以弗所书 1:11"> 因为他预先所知道的人，就预先定下效法他儿子的模样，使他儿子在许多弟兄中作长子。</span>
<span className="v" id="v30" data-v="30" data-xref="启示录 17:14; 罗马书 8:28; 以弗所书 1:11"> 预先所定下的人又召他们来；所召来的人又称他们为义；所称为义的人又叫他们得荣耀。</span>
</div>
</div>

## 神的爱

<div className="bt">
<div className="bp poetry">
<span className="v" id="v31" data-v="31" data-xref="诗篇 118:6; 耶利米书 1:19; 诗篇 56:11"> 既是这样，还有什么说的呢？ 神若帮助我们，谁能敌挡我们呢？</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 3:16; 罗马书 8:28; 诗篇 84:11"> 神既不爱惜自己的儿子，为我们众人舍了，岂不也把万物和他一同白白地赐给我们吗？</span>
<span className="v" id="v33" data-v="33" data-xref="启示录 12:10–11; 以赛亚书 50:8–9; 以赛亚书 54:17"> 谁能控告 神所拣选的人呢？有 神称他们为义了<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或译：是称他们为义的 神吗">c</a></sup>。</span>
<span className="v" id="v34" data-v="34" data-xref="希伯来书 7:25; 罗马书 8:27; 希伯来书 9:24"> 谁能定他们的罪呢？有基督耶稣已经死了，而且从死里复活，现今在 神的右边，也替我们祈求<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="有基督......或译：是已经死了，而且从死里复活，现今在 神的右边，也替我们祈求的基督耶稣吗">d</a></sup>。</span>
<span className="v" id="v35" data-v="35" data-xref="约翰福音 10:28; 诗篇 103:17; 约翰福音 16:33"> 谁能使我们与基督的爱隔绝呢？难道是患难吗？是困苦吗？是逼迫吗？是饥饿吗？是赤身露体吗？是危险吗？是刀剑吗？</span>
<span className="v" id="v36" data-v="36" data-xref="诗篇 44:22; 以赛亚书 53:7; 哥林多前书 15:30"> 如经上所记：<br /><span className="pl pl-1">我们为你的缘故终日被杀；</span><br /><span className="pl pl-1">人看我们如将宰的羊。</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="哥林多前书 15:57; 约翰一书 4:4; 哥林多后书 2:14"> 然而，靠着爱我们的主，在这一切的事上已经得胜有余了。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 10:28; 罗马书 14:8; 提摩太后书 1:12"> 因为我深信无论是死，是生，是天使，是掌权的，是有能的，是现在的事，是将来的事，</span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 10:28–30; 罗马书 8:35; 罗马书 5:8"> 是高处的，是低处的，是别的受造之物，都不能叫我们与 神的爱隔绝；这爱是在我们的主基督耶稣里的。</span>
</div>
</div>

## 假先知和假师傅

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 7:15; 犹大书 1:4; 申命记 13:1–3"> 从前在百姓中有假先知起来，将来在你们中间也必有假师傅，私自引进陷害人的异端，连买他们的主他们也不承认，自取速速地灭亡。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 2:24; 犹大书 1:10; 彼得前书 2:12"> 将有许多人随从他们邪淫的行为，便叫真道因他们的缘故被毁谤。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 2:17; 申命记 32:35; 罗马书 16:18"> 他们因有贪心，要用捏造的言语在你们身上取利。他们的刑罚，自古以来并不迟延；他们的灭亡也必速速来到<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是也不打盹">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="犹大书 1:6; 马太福音 25:41; 罗马书 8:32"> 就是天使犯了罪， 神也没有宽容，曾把他们丢在地狱，交在黑暗坑中，等候审判。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 11:7; 彼得后书 3:6; 犹大书 1:14–15"> 神也没有宽容上古的世代，曾叫洪水临到那不敬虔的世代，却保护了传义道的挪亚一家八口。</span>
<span className="v" id="v6" data-v="6" data-xref="犹大书 1:7; 路加福音 17:28–30; 申命记 29:23"> 又判定所多玛、蛾摩拉，将二城倾覆，焚烧成灰，作为后世不敬虔人的鉴戒；</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 19:16; 创世记 19:29; 创世记 19:7–8"> 只搭救了那常为恶人淫行忧伤的义人罗得。（</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 119:158; 以西结书 9:4; 诗篇 119:136"> 因为那义人住在他们中间，看见听见他们不法的事，他的义心就天天伤痛。）</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 34:15–19; 哥林多前书 10:13; 启示录 3:10"> 主知道搭救敬虔的人脱离试探，把不义的人留在刑罚之下，等候审判的日子。</span>
<span className="v" id="v10" data-v="10" data-xref="犹大书 1:16; 犹大书 1:10; 犹大书 1:18"> 那些随肉身、纵污秽的情欲、轻慢主治之人的，更是如此。<br />他们胆大任性，毁谤在尊位的，也不知惧怕。</span>
<span className="v" id="v11" data-v="11" data-xref="犹大书 1:9; 帖撒罗尼迦后书 1:7; 诗篇 104:4"> 就是天使，虽然力量权能更大，还不用毁谤的话在主面前告他们。</span>
<span className="v" id="v12" data-v="12" data-xref="犹大书 1:10; 耶利米书 12:3; 加拉太书 6:8"> 但这些人好像没有灵性，生来就是畜类，以备捉拿宰杀的。他们毁谤所不晓得的事，正在败坏人的时候，自己必遭遇败坏。</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 13:13; 罗马书 2:8–9; 希伯来书 2:2–3"> 行的不义，就得了不义的工价。这些人喜爱白昼宴乐，他们已被玷污，又有瑕疵，正与你们一同坐席，就以自己的诡诈为快乐。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得后书 2:3; 彼得后书 2:18; 以弗所书 2:3"> 他们满眼是淫色<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是淫妇">b</a></sup>，止不住犯罪，引诱那心不坚固的人，心中习惯了贪婪，正是被咒诅的种类。</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 2:14; 犹大书 1:11; 申命记 23:4–5"> 他们离弃正路，就走差了，随从比珥之子巴兰的路。巴兰就是那贪爱不义之工价的先知，</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 22:21–33; 传道书 7:25; 路加福音 16:11"> 他却为自己的过犯受了责备；那不能说话的驴以人言拦阻先知的狂妄。</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="犹大书 1:12–13; 以弗所书 4:14; 耶利米书 14:3"> 这些人是无水的井，是狂风催逼的雾气，有墨黑的幽暗为他们存留。</span>
<span className="v" id="v18" data-v="18" data-xref="彼得后书 2:20; 犹大书 1:15–16; 罗马书 13:13"> 他们说虚妄矜夸的大话，用肉身的情欲和邪淫的事引诱那些刚才脱离妄行的人。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 8:34; 罗马书 6:16–22; 加拉太书 5:13"> 他们应许人得以自由，自己却作败坏的奴仆，因为人被谁制伏就是谁的奴仆。</span>
<span className="v" id="v20" data-v="20" data-xref="希伯来书 10:26–27; 希伯来书 6:4–8; 腓立比书 3:19"> 倘若他们因认识主—救主耶稣基督，得以脱离世上的污秽，后来又在其中被缠住、制伏，他们末后的景况就比先前更不好了。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 18:24; 希伯来书 6:4–6; 雅各书 4:17"> 他们晓得义路，竟背弃了传给他们的圣命，倒不如不晓得为妙。</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 26:11"> 俗语说得真不错：<br /><span className="pl pl-1">狗所吐的，它转过来又吃；</span><br /><span className="pl pl-1">猪洗净了又回到泥里去滚；</span><br /><span className="pl pl-1">这话在他们身上正合式。</span></span>
</div>

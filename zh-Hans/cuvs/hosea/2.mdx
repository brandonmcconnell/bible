## 不贞的歌篾—不忠的以色列

<div className="bt">
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 50:1; 以西结书 16:25; 以西结书 23:45"> <span className="pl pl-1">你们要与你们的母亲大大争辩；</span><br /><span className="pl pl-1">因为她不是我的妻子，</span><br /><span className="pl pl-1">我也不是她的丈夫。</span><br /><span className="pl pl-1">叫她除掉脸上的淫像</span><br /><span className="pl pl-1">和胸间的淫态，</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 16:22; 以赛亚书 32:13–14; 以西结书 19:13"> <span className="pl pl-1">免得我剥她的衣服，</span><br /><span className="pl pl-1">使她赤体，与才生的时候一样，</span><br /><span className="pl pl-1">使她如旷野，如干旱之地，</span><br /><span className="pl pl-1">因渴而死。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 13:14; 何西阿书 1:6; 以西结书 8:18"> <span className="pl pl-1">我必不怜悯她的儿女，</span><br /><span className="pl pl-1">因为他们是从淫乱而生的。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 1:21; 何西阿书 3:1; 耶利米书 44:17–18"> <span className="pl pl-1">他们的母亲行了淫乱，</span><br /><span className="pl pl-1">怀他们的母做了可羞耻的事，</span><br /><span className="pl pl-1">因为她说：我要随从所爱的；</span><br /><span className="pl pl-1">我的饼、水、羊毛、麻、油、酒</span><br /><span className="pl pl-1">都是他们给的。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="约伯记 19:8; 约伯记 3:23; 耶利米哀歌 3:7–9"> <span className="pl pl-1">因此，我必用荆棘堵塞她的道，</span><br /><span className="pl pl-1">筑墙挡住她，</span><br /><span className="pl pl-1">使她找不着路。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 2:2; 何西阿书 5:13; 以西结书 23:4"> <span className="pl pl-1">她必追随所爱的，却追不上；</span><br /><span className="pl pl-1">她必寻找他们，却寻不见，</span><br /><span className="pl pl-1">便说：我要归回前夫，</span><br /><span className="pl pl-1">因我那时的光景比如今还好。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 1:3; 何西阿书 4:11; 何西阿书 13:2"> <span className="pl pl-1">她不知道是我给她五谷、新酒，和油，</span><br /><span className="pl pl-1">又加增她的金银；</span><br /><span className="pl pl-1">她却以此供奉</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或译：制造">c</a></sup><br /><span className="pl pl-1">巴力。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="何西阿书 2:3; 哈该书 1:6–11; 玛拉基书 1:4"> <span className="pl pl-1">因此到了收割的日子，</span><br /><span className="pl pl-1">出酒的时候，</span><br /><span className="pl pl-1">我必将我的五谷、新酒收回，</span><br /><span className="pl pl-1">也必将她应当遮体的羊毛和麻夺回来。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 23:29; 耶利米书 13:26; 何西阿书 13:7–8"> <span className="pl pl-1">如今我必在她所爱的眼前显露她的丑态；</span><br /><span className="pl pl-1">必无人能救她脱离我的手。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 1:13–14; 阿摩司书 5:21; 耶利米书 7:34"> <span className="pl pl-1">我也必使她的宴乐、节期、月朔、安息日，</span><br /><span className="pl pl-1">并她的一切大会都止息了。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 7:23; 以赛亚书 5:5; 何西阿书 2:5"> <span className="pl pl-1">我也必毁坏她的葡萄树和无花果树，</span><br /><span className="pl pl-1">就是她说「这是我所爱的给我为赏赐」的。</span><br /><span className="pl pl-1">我必使这些树变为荒林，</span><br /><span className="pl pl-1">为田野的走兽所吃。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="何西阿书 13:6; 士师记 3:7; 何西阿书 13:1"> <span className="pl pl-1">我必追讨她素日给诸巴力烧香的罪；</span><br /><span className="pl pl-1">那时她佩带耳环和别样妆饰，</span><br /><span className="pl pl-1">随从她所爱的，却忘记我。</span><br /><span className="pl pl-1">这是耶和华说的。</span></span>
</div>

## 神对他子民的爱

<div className="bt">
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 40:1–2; 启示录 12:6; 以西结书 20:35–36"> <span className="pl pl-1">后来我必劝导她，领她到旷野，</span><br /><span className="pl pl-1">对她说安慰的话。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 2:2; 以西结书 28:26; 何西阿书 11:1"> <span className="pl pl-1">她从那里出来，我必赐她葡萄园，</span><br /><span className="pl pl-1">又赐她亚割谷作为指望的门。</span><br /><span className="pl pl-1">她必在那里应声</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或译：歌唱">d</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">与幼年的日子一样，</span><br /><span className="pl pl-1">与从埃及地上来的时候相同。</span></span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 54:5; 何西阿书 2:7; 耶利米书 3:14"> 耶和华说：「那日你必称呼我伊施<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="就是我夫的意思">e</a></sup>，不再称呼我巴力<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="就是我主的意思">f</a></sup>；</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 23:13; 约书亚记 23:7; 诗篇 16:4"> 因为我必从我民的口中除掉诸巴力的名号，这名号不再提起。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 34:25; 以西结书 39:9–10; 诗篇 46:9"> 当那日，我必为我的民，与田野的走兽和空中的飞鸟，并地上的昆虫立约；又必在国中折断弓刀，止息争战，使他们安然躺卧。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多后书 11:2; 启示录 21:2; 以赛亚书 54:8–10"> 我必聘你永远归我为妻，以仁义、公平、慈爱、怜悯聘你归我；</span>
<span className="v" id="v20" data-v="20" data-xref="约翰一书 5:20; 约翰福音 17:3; 耶利米书 24:7"> 也以诚实聘你归我，你就必认识我—耶和华。</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亚书 8:12; 以赛亚书 65:24; 罗马书 8:32"> <span className="pl pl-1">耶和华说：那日我必应允，</span><br /><span className="pl pl-1">我必应允天，天必应允地；</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="约珥书 2:19; 何西阿书 1:4; 何西阿书 1:11"> <span className="pl pl-1">地必应允五谷、新酒，和油，</span><br /><span className="pl pl-1">这些必应允耶斯列民</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="耶斯列就是 神栽种的意思">g</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 9:25–26; 彼得前书 2:9–10; 撒迦利亚书 13:9"> <span className="pl pl-1">我必将她种在这地。</span><br /><span className="pl pl-1">素不蒙怜悯的，我必怜悯；</span><br /><span className="pl pl-1">本非我民的，我必对他说：</span><br /><span className="pl pl-1">你是我的民；</span><br /><span className="pl pl-1">他必说：你是我的 神。」</span></span>

## 以基督的心为心

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 3:12; 约翰一书 4:12; 约翰一书 4:7–8"> 所以，在基督里若有什么劝勉，爱心有什么安慰，圣灵有什么交通，心中有什么慈悲怜悯，</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 12:16; 彼得前书 3:8–9; 哥林多前书 1:10"> 你们就要意念相同，爱心相同，有一样的心思，有一样的意念，使我的喜乐可以满足。</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 12:10; 加拉太书 5:26; 以弗所书 5:21"> 凡事不可结党，不可贪图虚浮的荣耀；只要存心谦卑，各人看别人比自己强。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 10:24; 罗马书 15:1; 雅各书 2:8"> 各人不要单顾自己的事，也要顾别人的事。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰一书 2:6; 马太福音 11:29; 彼得前书 2:21"> <span className="pl pl-1">你们当以基督耶稣的心为心：</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 5:18; 哥林多后书 4:4; 希伯来书 1:3"> <span className="pl pl-1">他本有 神的形象，</span><br /><span className="pl pl-1">不以自己与 神同等为强夺的；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 8:9; 马太福音 20:28; 约翰福音 1:14"> <span className="pl pl-1">反倒虚己，</span><br /><span className="pl pl-1">取了奴仆的形象，</span><br /><span className="pl pl-1">成为人的样式；</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 10:18; 希伯来书 12:2; 罗马书 5:19"> <span className="pl pl-1">既有人的样子，就自己卑微，</span><br /><span className="pl pl-1">存心顺服，以至于死，</span><br /><span className="pl pl-1">且死在十字架上。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="启示录 19:16; 马太福音 28:18; 彼得前书 3:22"> <span className="pl pl-1">所以， 神将他升为至高，</span><br /><span className="pl pl-1">又赐给他那超乎万名之上的名，</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 45:23–25; 马太福音 28:18; 启示录 5:13–14"> <span className="pl pl-1">叫一切在天上的、地上的，和地底下的，</span><br /><span className="pl pl-1">因耶稣的名无不屈膝，</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="约翰一书 4:15; 罗马书 14:11; 约翰福音 13:13"> <span className="pl pl-1">无不口称「耶稣基督为主」，</span><br /><span className="pl pl-1">使荣耀归与父 神。</span></span>
</div>
</div>

## 在这世上像明光照耀

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彼得后书 1:5–10; 路加福音 13:23–24; 哥林多前书 15:58"> 这样看来，我亲爱的弟兄，你们既是常顺服的，不但我在你们那里，就是我如今不在你们那里，更是顺服的，就当恐惧战兢做成你们得救的工夫。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 13:21; 哥林多后书 3:5; 提摩太后书 1:9"> 因为你们立志行事都是 神在你们心里运行，为要成就他的美意。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 4:9; 哥林多前书 10:10; 腓立比书 2:3"> 凡所行的，都不要发怨言，起争论，</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 5:14–16; 彼得前书 2:12; 马太福音 5:45"> 使你们无可指摘，诚实无伪，在这弯曲悖谬的世代作 神无瑕疵的儿女。你们显在这世代中，好像明光照耀，</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 9:26; 加拉太书 2:2; 约翰一书 1:1"> 将生命的道表明出来，叫我在基督的日子好夸我没有空跑，也没有徒劳。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太后书 4:6; 罗马书 15:16; 希伯来书 13:15–16"> 我以你们的信心为供献的祭物，我若被浇奠在其上，也是喜乐，并且与你们众人一同喜乐。</span>
<span className="v" id="v18" data-v="18" data-xref="雅各书 1:2–4; 腓立比书 4:4; 腓立比书 3:1"> 你们也要照样喜乐，并且与我一同喜乐。</span>
</div>
</div>

## 提摩太和以巴弗提

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 4:17; 帖撒罗尼迦前书 3:6–8; 帖撒罗尼迦前书 3:2"> 我靠主耶稣指望快打发提摩太去见你们，叫我知道你们的事，心里就得着安慰。</span>
<span className="v" id="v20" data-v="20" data-xref="腓立比书 2:2; 哥林多前书 16:10; 腓立比书 2:22"> 因为我没有别人与我同心，实在挂念你们的事。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 10:24; 马太福音 16:24; 腓立比书 2:4"> 别人都求自己的事，并不求耶稣基督的事。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 4:17; 哥林多后书 2:9; 提摩太后书 1:2"> 但你们知道提摩太的明证；他兴旺福音，与我同劳，待我像儿子待父亲一样。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 22:3; 腓立比书 2:19"> 所以，我一看出我的事要怎样了结，就盼望立刻打发他去；</span>
<span className="v" id="v24" data-v="24" data-xref="约翰三书 1:14; 腓利门书 1:22; 腓立比书 1:25–26"> 但我靠着主自信我也必快去。</span>
<span className="v" id="v25" data-v="25" data-xref="腓立比书 4:18; 腓利门书 1:1–2; 腓立比书 4:3"> 然而，我想必须打发以巴弗提到你们那里去。他是我的兄弟，与我一同做工，一同当兵，是你们所差遣的，也是供给我需用的。</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 12:15; 箴言 12:25; 以弗所书 3:13"> 他很想念你们众人，并且极其难过，因为你们听见他病了。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 34:19; 腓立比书 2:30; 诗篇 103:3–4"> 他实在是病了，几乎要死；然而 神怜恤他，不但怜恤他，也怜恤我，免得我忧上加忧。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 16:22; 提摩太后书 1:4; 腓立比书 2:26–27"> 所以我越发急速打发他去，叫你们再见他，就可以喜乐，我也可以少些忧愁。</span>
<span className="v" id="v29" data-v="29" data-xref="帖撒罗尼迦前书 5:12; 哥林多前书 16:18; 提摩太前书 5:17"> 故此，你们要在主里欢欢乐乐地接待他，而且要尊重这样的人；</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前书 16:17; 使徒行传 20:24; 腓立比书 4:10"> 因他为做基督的工夫，几乎至死，不顾性命，要补足你们供给我的不及之处。</span>
</div>
</div>

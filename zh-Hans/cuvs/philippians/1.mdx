## 保罗为腓立比信徒祷告

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 1:4; 帖撒罗尼迦前书 1:2–3; 腓利门书 1:4–5"> 我每逢想念你们，就感谢我的 神；</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 1:2; 罗马书 1:9; 约翰二书 1:4"> 每逢为你们众人祈求的时候，常是欢欢喜喜地祈求。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 4:14–15; 腓立比书 1:7; 希伯来书 3:14"> 因为从头一天直到如今，你们是同心合意地兴旺福音。</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦前书 5:23–24; 腓立比书 2:13; 以弗所书 4:12"> 我深信那在你们心里动了善工的，必成全这工，直到耶稣基督的日子。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 7:3; 腓立比书 1:5; 歌罗西书 4:18"> 我为你们众人有这样的意念，原是应当的；因你们常在我心里，无论我是在捆锁之中，是辩明证实福音的时候，你们都与我一同得恩。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比书 4:1; 罗马书 1:9; 提摩太后书 1:4"> 我体会基督耶稣的心肠，切切地想念你们众人；这是 神可以给我作见证的。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦前书 3:12; 歌罗西书 1:9; 彼得后书 1:5–6"> 我所祷告的，就是要你们的爱心在知识和各样见识上多而又多，</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 12:2; 帖撒罗尼迦前书 3:13; 帖撒罗尼迦前书 5:23"> 使你们能分别是非<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：喜爱那美好的事">a</a></sup>，作诚实无过的人，直到基督的日子；</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 12:11; 约翰福音 15:8; 约翰福音 15:4–5"> 并靠着耶稣基督结满了仁义的果子，叫荣耀称赞归与 神。</span>
</div>
</div>

## 我活着就是基督

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="提摩太后书 2:9; 罗马书 8:28; 使徒行传 11:19–21"> 弟兄们，我愿意你们知道，我所遭遇的事更是叫福音兴旺，</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太后书 2:9; 以弗所书 3:1; 腓立比书 1:7"> 以致我受的捆锁在御营全军和其余的人中，已经显明是为基督的缘故。</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所书 6:19–20; 帖撒罗尼迦前书 2:2; 路加福音 1:74"> 并且那在主里的弟兄多半因我受的捆锁就笃信不疑，越发放胆传 神的道，无所惧怕。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 16:17–18; 腓立比书 2:3; 哥林多后书 11:13"> 有的传基督是出于嫉妒纷争，也有的是出于好意。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 2:17; 哥林多后书 4:1–2; 诗篇 69:26"> 这一等是出于爱心，知道我是为辩明福音设立的；</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太后书 1:11–12; 腓立比书 2:3; 腓立比书 1:7"> 那一等传基督是出于结党，并不诚实，意思要加增我捆锁的苦楚。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 9:50; 马可福音 9:38–40; 哥林多前书 15:11"> 这有何妨呢？或是假意，或是真心，无论怎样，基督究竟被传开了。为此，我就欢喜，并且还要欢喜；</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 8:28; 使徒行传 16:7; 哥林多后书 1:11"> 因为我知道，这事借着你们的祈祷和耶稣基督之灵的帮助，终必叫我得救。</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前书 4:16; 哥林多前书 6:20; 以赛亚书 54:4"> 照着我所切慕、所盼望的，没有一事叫我羞愧。只要凡事放胆，无论是生是死，总叫基督在我身上照常显大。</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太书 2:20; 哥林多后书 5:8; 哥林多后书 5:1"> 因我活着就是基督，我死了就有益处。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 4:2; 加拉太书 2:20; 腓立比书 1:24"> 但我在肉身活着，若成就我工夫的果子，我就不知道该挑选什么。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 5:8; 诗篇 17:15; 启示录 14:13"> 我正在两难之间，情愿离世与基督同在，因为这是好得无比的。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 16:7; 腓立比书 1:22; 腓立比书 1:25–26"> 然而，我在肉身活着，为你们更是要紧的。</span>
<span className="v" id="v25" data-v="25" data-xref="腓立比书 2:24; 哥林多后书 1:24; 以弗所书 4:11–13"> 我既然这样深信，就知道仍要住在世间，且与你们众人同住，使你们在所信的道上又长进又喜乐，</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多后书 1:14; 哥林多后书 5:12; 腓立比书 3:3"> 叫你们在基督耶稣里的欢乐，因我再到你们那里去，就越发加增。</span>
<span className="v" id="v27" data-v="27" data-xref="以弗所书 4:1; 哥林多前书 16:13–14; 哥林多前书 1:10"> 只要你们行事为人与基督的福音相称，叫我或来见你们，或不在你们那里，可以听见你们的景况，知道你们同有一个心志，站立得稳，为所信的福音齐心努力。</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太后书 1:7–8; 帖撒罗尼迦后书 1:5–6; 马太福音 10:28"> 凡事不怕敌人的惊吓，这是证明他们沉沦，你们得救都是出于 神。</span>
<span className="v" id="v29" data-v="29" data-xref="雅各书 1:2; 彼得前书 4:13; 使徒行传 5:41"> 因为你们蒙恩，不但得以信服基督，并要为他受苦。</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒罗尼迦前书 2:2; 使徒行传 16:19–40; 提摩太后书 4:7"> 你们的争战，就与你们在我身上从前所看见、现在所听见的一样。</span>
</div>
</div>

## 以蝗虫为耶和华日子的警告

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约珥书 2:15; 约珥书 1:15; 彼得前书 4:7"> <span className="pl pl-1">你们要在锡安吹角，</span><br /><span className="pl pl-1">在我圣山吹出大声。</span><br /><span className="pl pl-1">国中的居民都要发颤；</span><br /><span className="pl pl-1">因为耶和华的日子将到，</span><br /><span className="pl pl-1">已经临近。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="约珥书 1:6; 西番雅书 1:14–15; 约珥书 2:10–11"> <span className="pl pl-1">那日是黑暗、幽冥、</span><br /><span className="pl pl-1">密云、乌黑的日子，</span><br /><span className="pl pl-1">好像晨光铺满山岭。</span><br /><span className="pl pl-1">有一队蝗虫</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是民">a</a></sup><br /><span className="pl pl-1">又大又强；</span><br /><span className="pl pl-1">从来没有这样的，</span><br /><span className="pl pl-1">以后直到万代也必没有。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 51:3; 约珥书 1:19–20; 创世记 2:8"> <span className="pl pl-1">它们前面如火烧灭，</span><br /><span className="pl pl-1">后面如火焰烧尽。</span><br /><span className="pl pl-1">未到以前，地如伊甸园；</span><br /><span className="pl pl-1">过去以后，成了荒凉的旷野；</span><br /><span className="pl pl-1">没有一样能躲避它们的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="启示录 9:7"> <span className="pl pl-1">它们的形状如马，</span><br /><span className="pl pl-1">奔跑如马兵。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="启示录 9:9; 以赛亚书 5:24; 以赛亚书 30:30"> <span className="pl pl-1">在山顶蹦跳的响声如车辆的响声，</span><br /><span className="pl pl-1">又如火焰烧碎秸的响声，</span><br /><span className="pl pl-1">好像强盛的民摆阵预备打仗。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="那鸿书 2:10; 以赛亚书 13:8; 耶利米书 30:6"> <span className="pl pl-1">它们一来，众民伤恸，</span><br /><span className="pl pl-1">脸都变色。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 30:27; 撒母耳记下 1:23; 撒母耳记下 2:18–19"> <span className="pl pl-1">它们如勇士奔跑，</span><br /><span className="pl pl-1">像战士爬城；</span><br /><span className="pl pl-1">各都步行，不乱队伍。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 23:10; 约伯记 33:18; 历代志下 32:5"> <span className="pl pl-1">彼此并不拥挤，向前各行其路，</span><br /><span className="pl pl-1">直闯兵器，不偏左右。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 9:21; 约翰福音 10:1; 出埃及记 10:6"> <span className="pl pl-1">它们蹦上城，蹿上墙，</span><br /><span className="pl pl-1">爬上房屋，</span><br /><span className="pl pl-1">进入窗户如同盗贼。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="马太福音 24:29; 以赛亚书 13:10; 约珥书 3:15–16"> <span className="pl pl-1">它们一来，</span><br /><span className="pl pl-1">地震天动，</span><br /><span className="pl pl-1">日月昏暗，</span><br /><span className="pl pl-1">星宿无光。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="玛拉基书 3:2; 那鸿书 1:6; 耶利米书 30:7"> <span className="pl pl-1">耶和华在他军旅前发声，</span><br /><span className="pl pl-1">他的队伍甚大；</span><br /><span className="pl pl-1">成就他命的是强盛者。</span><br /><span className="pl pl-1">因为耶和华的日子大而可畏，</span><br /><span className="pl pl-1">谁能当得起呢？</span></span>
</div>
</div>

## 呼吁百姓悔改

<div className="bp poetry">

<span className="v" id="v13" data-v="13" data-xref="诗篇 86:15; 诗篇 34:18; 出埃及记 34:6–7"> <span className="pl pl-1">你们要撕裂心肠，</span><br /><span className="pl pl-1">不撕裂衣服。</span><br /><span className="pl pl-1">归向耶和华—你们的 神；</span><br /><span className="pl pl-1">因为他有恩典，有怜悯，</span><br /><span className="pl pl-1">不轻易发怒，</span><br /><span className="pl pl-1">有丰盛的慈爱，</span><br /><span className="pl pl-1">并且后悔不降所说的灾。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="约珥书 1:14; 约珥书 2:1; 列王纪上 21:12"> <span className="pl pl-1">你们要在锡安吹角，</span><br /><span className="pl pl-1">分定禁食的日子，</span><br /><span className="pl pl-1">宣告严肃会。</span><br /></span>

<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="诗篇 115:2; 以西结书 8:16; 诗篇 79:10"> <span className="pl pl-1">事奉耶和华的祭司</span><br /><span className="pl pl-1">要在廊子和祭坛中间哭泣，说：</span><br /><span className="pl pl-1">耶和华啊，求你顾惜你的百姓，</span><br /><span className="pl pl-1">不要使你的产业受羞辱，</span><br /><span className="pl pl-1">列邦管辖他们。</span><br /><span className="pl pl-1">为何容列国的人说：</span><br /><span className="pl pl-1">「他们的 神在哪里」呢？</span></span>

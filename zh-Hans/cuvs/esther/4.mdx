## 末底改求以斯帖帮忙

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理书 9:3; 以西结书 27:30–31; 撒母耳记下 13:19"> 末底改知道所做的这一切事，就撕裂衣服，穿麻衣，蒙灰尘，在城中行走，痛哭哀号。</span>
<span className="v" id="v2" data-v="2"> 到了朝门前停住脚步，因为穿麻衣的不可进朝门。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 22:12; 但以理书 9:3; 以赛亚书 58:5"> 王的谕旨所到的各省各处，犹大人大大悲哀，禁食哭泣哀号，穿麻衣躺在灰中的甚多。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 77:2; 耶利米书 31:15; 以斯帖记 1:12"> 王后以斯帖的宫女和太监来把这事告诉以斯帖，她甚是忧愁，就送衣服给末底改穿，要他脱下麻衣，他却不受。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 12:26; 罗马书 12:15; 以斯帖记 1:10"> 以斯帖就把王所派伺候她的一个太监，名叫哈他革召来，吩咐他去见末底改，要知道这是什么事，是什么缘故。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯帖记 4:3; 以斯帖记 7:2; 以斯帖记 9:12"> 于是哈他革出到朝门前的宽阔处见末底改。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯帖记 3:2–15"> 末底改将自己所遇的事，并哈曼为灭绝犹大人应许捐入王库的银数都告诉了他；</span>
<span className="v" id="v8" data-v="8" data-xref="传道书 10:4; 约伯记 9:15; 提摩太前书 6:13"> 又将所抄写传遍书珊城要灭绝犹大人的旨意交给哈他革，要给以斯帖看，又要给她说明，并嘱咐她进去见王，为本族的人在王面前恳切祈求。</span>
<span className="v" id="v9" data-v="9"> 哈他革回来，将末底改的话告诉以斯帖；</span>
<span className="v" id="v10" data-v="10"> 以斯帖就吩咐哈他革去见末底改，说：</span>
<span className="v" id="v11" data-v="11" data-xref="以斯帖记 5:1–2; 以斯帖记 8:4; 但以理书 2:9"> 「王的一切臣仆和各省的人民都知道有一个定例：若不蒙召，擅入内院见王的，无论男女必被治死；除非王向他伸出金杖，不得存活。现在我没有蒙召进去见王已经三十日了。」</span>
<span className="v" id="v12" data-v="12"> 人就把以斯帖这话告诉末底改。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 24:10–12; 腓立比书 2:30; 约翰福音 12:25"> 末底改托人回复以斯帖说：「你莫想在王宫里强过一切犹大人，得免这祸。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 45:4–8; 撒母耳记上 12:22; 申命记 32:36"> 此时你若闭口不言，犹大人必从别处得解脱，蒙拯救；你和你父家必致灭亡。焉知你得了王后的位分不是为现今的机会吗？」</span>
<span className="v" id="v15" data-v="15"> 以斯帖就吩咐人回报末底改说：</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 20:24; 历代志下 20:3; 约珥书 2:12–17"> 「你当去招聚书珊城所有的犹大人，为我禁食三昼三夜，不吃不喝；我和我的宫女也要这样禁食。然后我违例进去见王，我若死就死吧！」</span>
<span className="v" id="v17" data-v="17"> 于是末底改照以斯帖一切所吩咐的去行。</span>

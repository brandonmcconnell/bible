## 哈曼阴谋除灭犹大人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 24:7; 以斯帖记 5:11; 但以理书 6:2"> 这事以后，亚哈随鲁王抬举亚甲族哈米大他的儿子哈曼，使他高升，叫他的爵位超过与他同事的一切臣宰。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯帖记 3:5; 诗篇 15:4; 以斯帖记 5:9"> 在朝门的一切臣仆都跪拜哈曼，因为王如此吩咐；惟独末底改不跪不拜。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯帖记 3:2; 出埃及记 1:17; 以斯帖记 2:19"> 在朝门的臣仆问末底改说：「你为何违背王的命令呢？」</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 39:10; 约拿书 1:9; 但以理书 6:20–28"> 他们天天劝他，他还是不听，他们就告诉哈曼，要看末底改的事站得住站不住，因他已经告诉他们自己是犹大人。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 3:19; 以斯帖记 5:9; 箴言 21:24"> 哈曼见末底改不跪不拜，他就怒气填胸。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 83:4; 启示录 12:12"> 他们已将末底改的本族告诉哈曼；他以为下手害末底改一人是小事，就要灭绝亚哈随鲁王通国所有的犹大人，就是末底改的本族。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 6:15; 以西结书 21:21–22; 以斯帖记 9:24–26"> 亚哈随鲁王十二年正月，就是尼散月，人在哈曼面前，按日日月月掣普珥，就是掣签，要定何月何日为吉，择定了十二月，就是亚达月。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 4:12–15; 使徒行传 16:20–21; 申命记 4:27"> 哈曼对亚哈随鲁王说：「有一种民散居在王国各省的民中；他们的律例与万民的律例不同，也不守王的律例，所以容留他们与王无益。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 23:16; 马太福音 18:24"> 王若以为美，请下旨意灭绝他们；我就捐一万他连得银子交给掌管国帑的人，纳入王的府库。」</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 41:42; 以斯帖记 8:2; 以斯帖记 7:6"> 于是王从自己手上摘下戒指给犹大人的仇敌—亚甲族哈米大他的儿子哈曼。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 23:25; 耶利米书 40:4; 耶利米书 26:14"> 王对哈曼说：「这银子仍赐给你，这民也交给你，你可以随意待他们。」</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 21:8; 以斯帖记 1:22; 但以理书 6:12"> 正月十三日，就召了王的书记来，照着哈曼一切所吩咐的，用各省的文字、各族的方言，奉亚哈随鲁王的名写旨意，传与总督和各省的省长，并各族的首领；又用王的戒指盖印，</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 30:6; 以斯帖记 9:10; 以斯帖记 8:10–14"> 交给驿卒传到王的各省，吩咐将犹大人，无论老少妇女孩子，在一日之间，十二月，就是亚达月十三日，全然剪除，杀戮灭绝，并夺他们的财为掠物。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖记 8:13–14"> 抄录这旨意，颁行各省，宣告各族，使他们预备等候那日。</span>
<span className="v" id="v15" data-v="15" data-xref="以斯帖记 8:15; 约翰福音 16:20; 箴言 29:2"> 驿卒奉王命急忙起行，旨意也传遍书珊城。王同哈曼坐下饮酒，书珊城的民却都慌乱。</span>

## 犹大人的反击

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖记 2:7; 以斯帖记 2:15; 箴言 13:22"> 当日，亚哈随鲁王把犹大人仇敌哈曼的家产赐给王后以斯帖。末底改也来到王面前，因为以斯帖已经告诉王，末底改是她的亲属。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯帖记 3:10; 创世记 41:42; 但以理书 2:48"> 王摘下自己的戒指，就是从哈曼追回的，给了末底改。以斯帖派末底改管理哈曼的家产。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="何西阿书 12:4; 以赛亚书 38:2; 列王纪下 4:27"> 以斯帖又俯伏在王脚前，流泪哀告，求他除掉亚甲族哈曼害犹大人的恶谋。</span>
<span className="v" id="v4" data-v="4" data-xref="以斯帖记 5:2; 以斯帖记 4:11"> 王向以斯帖伸出金杖；以斯帖就起来，站在王前，</span>
<span className="v" id="v5" data-v="5" data-xref="以斯帖记 7:3; 以斯帖记 5:8; 以斯帖记 3:12–13"> 说：「亚甲族哈米大他的儿子哈曼设谋传旨，要杀灭在王各省的犹大人。现今王若愿意，我若在王眼前蒙恩，王若以为美，若喜悦我，请王另下旨意，废除哈曼所传的那旨意。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯帖记 7:4; 罗马书 10:1; 罗马书 9:2–3"> 我何忍见我本族的人受害？何忍见我同宗的人被灭呢？」</span>
<span className="v" id="v7" data-v="7" data-xref="以斯帖记 7:10–1; 加拉太书 3:13; 箴言 13:22"> 亚哈随鲁王对王后以斯帖和犹大人末底改说：「因哈曼要下手害犹大人，我已将他的家产赐给以斯帖，人也将哈曼挂在木架上。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯帖记 1:19; 以斯帖记 3:12; 以斯帖记 8:5"> 现在你们可以随意奉王的名写谕旨给犹大人，用王的戒指盖印；因为奉王名所写、用王戒指盖印的谕旨，人都不能废除。」</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以斯帖记 1:22; 以斯帖记 1:1; 列王纪下 18:26"> 三月，就是西弯月二十三日，将王的书记召来，按着末底改所吩咐的，用各省的文字、各族的方言，并犹大人的文字方言写谕旨，传给那从印度直到古实一百二十七省的犹大人和总督省长首领。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 60:6; 耶利米书 2:23; 以赛亚书 66:20"> 末底改奉亚哈随鲁王的名写谕旨，用王的戒指盖印，交给骑御马圈快马的驿卒，传到各处。</span>
<span className="v" id="v11" data-v="11" data-xref="以斯帖记 3:13; 诗篇 37:14–15; 诗篇 146:6–9"> 谕旨中，王准各省各城的犹大人在一日之间，十二月，就是亚达月十三日，聚集保护性命，剪除杀戮灭绝那要攻击犹大人的一切仇敌和他们的妻子儿女，夺取他们的财为掠物。</span>
<span className="v" id="v13" data-v="13" data-xref="启示录 6:10; 以斯帖记 3:14; 士师记 16:28"> 抄录这谕旨，颁行各省，宣告各族，使犹大人预备等候那日，在仇敌身上报仇。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖记 3:15; 但以理书 8:2; 以斯帖记 2:3"> 于是骑快马的驿卒被王命催促，急忙起行；谕旨也传遍书珊城。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 16:19; 马太福音 6:29; 以斯帖记 3:15"> 末底改穿着蓝色白色的朝服，头戴大金冠冕，又穿紫色细麻布的外袍，从王面前出来；书珊城的人民都欢呼快乐。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 11:10; 诗篇 97:11; 诗篇 18:28"> 犹大人有光荣，欢喜快乐而得尊贵。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯帖记 9:19; 撒迦利亚书 8:20–23; 撒母耳记上 25:8"> 王的谕旨所到的各省各城，犹大人都欢喜快乐，设摆筵宴，以那日为吉日。那国的人民，有许多因惧怕犹大人，就入了犹大籍。</span>
</div>
</div>

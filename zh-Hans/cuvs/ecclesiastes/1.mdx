## 人生的虚空

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="传道书 12:8–10; 传道书 1:12; 传道书 7:27"> 在耶路撒冷作王、大卫的儿子、传道者的言语。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 144:4; 罗马书 8:20; 传道书 5:10"> <span className="pl pl-1">传道者说：虚空的虚空，</span><br /><span className="pl pl-1">虚空的虚空，凡事都是虚空。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="传道书 3:9; 传道书 5:16; 传道书 2:22"> <span className="pl pl-1">人一切的劳碌，</span><br /><span className="pl pl-1">就是他在日光之下的劳碌，有什么益处呢？</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 104:5; 撒迦利亚书 1:5; 传道书 6:12"> <span className="pl pl-1">一代过去，一代又来，</span><br /><span className="pl pl-1">地却永远长存。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 19:4–6; 哈巴谷书 3:11; 诗篇 42:1"> <span className="pl pl-1">日头出来，日头落下，</span><br /><span className="pl pl-1">急归所出之地。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 3:8; 传道书 11:5; 诗篇 107:25"> <span className="pl pl-1">风往南刮，又向北转，</span><br /><span className="pl pl-1">不住地旋转，而且返回转行原道。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="约伯记 38:10–11; 诗篇 104:6–9"> <span className="pl pl-1">江河都往海里流，海却不满；</span><br /><span className="pl pl-1">江河从何处流，仍归还何处。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 27:20; 马太福音 11:28; 传道书 4:8"> <span className="pl pl-1">万事令人厌烦</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：万物满有困乏">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">人不能说尽。</span><br /><span className="pl pl-1">眼看，看不饱；</span><br /><span className="pl pl-1">耳听，听不足。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="传道书 3:15; 传道书 6:10; 传道书 2:12"> <span className="pl pl-1">已有的事后必再有；</span><br /><span className="pl pl-1">已行的事后必再行。</span><br /><span className="pl pl-1">日光之下并无新事。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 7:51; 路加福音 17:26–30; 马太福音 23:30–32"> <span className="pl pl-1">岂有一件事人能指着说这是新的？</span><br /><span className="pl pl-1">哪知，在我们以前的世代早已有了。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="传道书 2:16; 诗篇 9:6; 传道书 9:5"> <span className="pl pl-1">已过的世代，无人记念；</span><br /><span className="pl pl-1">将来的世代，后来的人也不记念。</span></span>
</div>
</div>

## 传道者的经验

<div className="bt">
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="传道书 1:1; 列王纪上 4:1–19"> 我传道者在耶路撒冷作过以色列的王。</span>
<span className="v" id="v13" data-v="13" data-xref="传道书 3:10; 创世记 3:19; 提摩太前书 4:15"> 我专心用智慧寻求、查究天下所做的一切事，乃知 神叫世人所经练的是极重的劳苦。</span>
<span className="v" id="v14" data-v="14" data-xref="传道书 2:11; 传道书 2:17; 传道书 2:26"> 我见日光之下所做的一切事，都是虚空，都是捕风。</span>
<span className="v" id="v15" data-v="15" data-xref="传道书 7:12–13; 以赛亚书 40:4; 传道书 3:14"> <span className="pl pl-1">弯曲的，不能变直；</span><br /><span className="pl pl-1">缺少的，不能足数。</span></span>
<span className="v" id="v16" data-v="16" data-xref="传道书 2:9; 列王纪上 4:30; 列王纪上 10:7"> 我心里议论说：我得了大智慧，胜过我以前在耶路撒冷的众人，而且我心中多经历智慧和知识的事。</span>
<span className="v" id="v17" data-v="17" data-xref="传道书 2:3; 帖撒罗尼迦前书 5:21; 传道书 1:13–14"> 我又专心察明智慧、狂妄，和愚昧，乃知这也是捕风。</span>
<span className="v" id="v18" data-v="18" data-xref="约伯记 28:28; 传道书 12:12–13; 哥林多前书 3:18–20"> <span className="pl pl-1">因为多有智慧，就多有愁烦；</span><br /><span className="pl pl-1">加增知识的，就加增忧伤。</span></span>
</div>
</div>

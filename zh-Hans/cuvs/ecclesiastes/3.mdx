## 万事均有定时

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="传道书 3:17; 马太福音 16:3; 传道书 8:5–6"> <span className="pl pl-1">凡事都有定期，</span><br /><span className="pl pl-1">天下万务都有定时。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 9:27; 约伯记 14:5; 马太福音 15:13"> <span className="pl pl-1">生有时，死有时；</span><br /><span className="pl pl-1">栽种有时，拔出所栽种的也有时；</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="何西阿书 6:1–2; 撒母耳记上 2:6; 耶利米书 45:4"> <span className="pl pl-1">杀戮有时，医治有时；</span><br /><span className="pl pl-1">拆毁有时，建造有时；</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 12:15; 诗篇 30:5; 雅各书 4:9"> <span className="pl pl-1">哭有时，笑有时；</span><br /><span className="pl pl-1">哀恸有时，跳舞有时；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 3:25; 约书亚记 10:27; 约书亚记 4:3–9"> <span className="pl pl-1">抛掷石头有时，堆聚石头有时；</span><br /><span className="pl pl-1">怀抱有时，不怀抱有时；</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="腓立比书 3:7–8; 路加福音 9:24–25; 马可福音 8:35–37"> <span className="pl pl-1">寻找有时，失落有时；</span><br /><span className="pl pl-1">保守有时，舍弃有时；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="阿摩司书 5:13; 弥迦书 7:5; 耶利米哀歌 3:28"> <span className="pl pl-1">撕裂有时，缝补有时；</span><br /><span className="pl pl-1">静默有时，言语有时；</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 5:25; 以弗所书 5:28–29; 路加福音 14:26"> <span className="pl pl-1">喜爱有时，恨恶有时；</span><br /><span className="pl pl-1">争战有时，和好有时。</span></span>
<span className="v" id="v9" data-v="9" data-xref="传道书 1:3; 传道书 5:16; 箴言 14:23"> 这样看来，做事的人在他的劳碌上有什么益处呢？</span>
<span className="v" id="v10" data-v="10" data-xref="传道书 1:13–14; 创世记 3:19; 传道书 2:26"> 我见 神叫世人劳苦，使他们在其中受经练。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 11:33; 罗马书 1:19–20; 约伯记 11:7"> 神造万物，各按其时成为美好，又将永生<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是永远">a</a></sup>安置在世人心里。然而 神从始至终的作为，人不能参透。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 37:3; 传道书 3:22; 提摩太前书 6:18"> 我知道世人，莫强如终身喜乐行善；</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 128:2; 传道书 9:7; 传道书 2:24"> 并且人人吃喝，在他一切劳碌中享福，这也是 神的恩赐。</span>
<span className="v" id="v14" data-v="14" data-xref="雅各书 1:17; 诗篇 33:11; 罗马书 11:36"> 我知道 神一切所做的都必永存；无所增添，无所减少。 神这样行，是要人在他面前存敬畏的心。</span>
<span className="v" id="v15" data-v="15" data-xref="传道书 1:9–10; 传道书 6:10"> 现今的事早先就有了，将来的事早已也有了，并且 神使已过的事重新再来<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：并且 神再寻回已过的事">b</a></sup>。</span>
</div>

## 世上的不公平

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="传道书 4:1; 传道书 5:8; 诗篇 94:21–22"> 我又见日光之下，在审判之处有奸恶，在公义之处也有奸恶。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 5:10; 传道书 12:14; 马太福音 16:27"> 我心里说， 神必审判义人和恶人；因为在那里，各样事务，一切工作，都有定时。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 73:22; 诗篇 49:12; 希伯来书 9:27"> 我心里说，这乃为世人的缘故，是 神要试验他们，使他们觉得自己不过像兽一样。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 49:12; 诗篇 49:20; 诗篇 89:47–48"> 因为世人遭遇的，兽也遭遇，所遭遇的都是一样：这个怎样死，那个也怎样死，气息都是一样。人不能强于兽，都是虚空。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 3:19; 约伯记 34:15; 传道书 12:7"> 都归一处，都是出于尘土，也都归于尘土。</span>
<span className="v" id="v21" data-v="21" data-xref="传道书 12:7; 约翰福音 14:3; 哥林多后书 5:1"> 谁知道人的灵是往上升，兽的魂是下入地呢？</span>
<span className="v" id="v22" data-v="22" data-xref="传道书 2:24; 传道书 3:11–12; 传道书 10:14"> 故此，我见人莫强如在他经营的事上喜乐，因为这是他的分。他身后的事谁能使他回来得见呢？</span>
</div>
</div>

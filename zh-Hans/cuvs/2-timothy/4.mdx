<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦前书 5:14; 提摩太前书 4:15–16; 提多书 2:15"> 务要传道，无论得时不得时总要专心，并用百般的忍耐、各样的教训责备人，警戒人，劝勉人。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得后书 2:1–3; 提摩太后书 3:1–6; 提摩太前书 4:1–3"> 因为时候要到，人必厌烦纯正的道理，耳朵发痒，就随从自己的情欲，增添好些师傅，</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 7:11; 提摩太前书 1:4; 使徒行传 7:57"> 并且掩耳不听真道，偏向荒渺的言语。</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太后书 1:8; 彼得前书 1:13; 提摩太后书 2:3"> 你却要凡事谨慎，忍受苦难，做传道的工夫，尽你的职分。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="腓立比书 1:23; 腓立比书 2:17; 彼得后书 1:14–15"> 我现在被浇奠，我离世的时候到了。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前书 6:12; 哥林多前书 9:24–27; 希伯来书 12:1–2"> 那美好的仗我已经打过了，当跑的路我已经跑尽了，所信的道我已经守住了。</span>
<span className="v" id="v8" data-v="8" data-xref="雅各书 1:12; 启示录 2:10; 彼得前书 5:4"> 从此以后，有公义的冠冕为我存留，就是按着公义审判的主到了那日要赐给我的；不但赐给我，也赐给凡爱慕他显现的人。</span>
</div>

## 私事的嘱咐

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="提摩太后书 1:4; 提摩太后书 4:21"> 你要赶紧地到我这里来。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 2:15–16; 提摩太后书 1:15; 歌罗西书 4:14–15"> 因为底马贪爱现今的世界，就离弃我往帖撒罗尼迦去了；革勒士往加拉太去；提多往挞马太去；</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 12:12; 腓利门书 1:24; 使徒行传 12:25"> 独有路加在我这里。你来的时候，要把马可带来，因为他在传道<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：服事我">a</a></sup>的事上于我有益处。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 6:21; 使徒行传 20:4; 提多书 3:12"> 我已经打发推基古往以弗所去。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 4:11; 哥林多后书 11:27; 使徒行传 16:11"> 我在特罗亚留于加布的那件外衣，你来的时候可以带来，那些书也要带来，更要紧的是那些皮卷。</span>
<span className="v" id="v14" data-v="14" data-xref="提摩太前书 1:20; 帖撒罗尼迦后书 1:6; 诗篇 28:4"> 铜匠亚历山大多多地害我；主必照他所行的报应他。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太后书 3:8; 腓立比书 3:2; 马太福音 10:16–17"> 你也要防备他，因为他极力敌挡了我们的话。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行传 7:60; 约翰福音 16:32; 马可福音 14:50"> 我初次申诉，没有人前来帮助，竟都离弃我；但愿这罪不归与他们。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前书 5:8; 腓立比书 1:12–14; 撒母耳记上 17:37"> 惟有主站在我旁边，加给我力量，使福音被我尽都传明，叫外邦人都听见；我也从狮子口里被救出来。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 121:7; 帖撒罗尼迦后书 3:3; 犹大书 1:24–25"> 主必救我脱离诸般的凶恶，也必救我进他的天国。愿荣耀归给他，直到永永远远。阿们。</span>
</div>
</div>

## 问候与祝福

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 18:2; 哥林多前书 16:19; 罗马书 16:3–4"> 问百基拉、亚居拉，和阿尼色弗一家的人安。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 20:4; 使徒行传 19:22; 腓立比书 2:26–27"> 以拉都在哥林多住下了。特罗非摩病了，我就留他在米利都。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 4:9; 腓立比书 4:22; 约翰三书 1:14"> 你要赶紧在冬天以前到我这里来。有友布罗、布田、利奴、革老底亚，和众弟兄都问你安。</span>
</div>

</div>

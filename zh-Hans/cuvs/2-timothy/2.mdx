## 基督耶稣的精兵

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 12:9–10; 以弗所书 6:10; 提摩太后书 1:7"> 我儿啊，你要在基督耶稣的恩典上刚强起来。</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太后书 1:13–14; 提摩太前书 4:6; 提摩太前书 6:12"> 你在许多见证人面前听见我所教训的，也要交托那忠心能教导别人的人。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 12:2–3; 雅各书 1:12; 提摩太后书 4:5"> 你要和我同受苦难，好像基督耶稣的精兵。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 2:4; 路加福音 8:14; 彼得后书 2:20"> 凡在军中当兵的，不将世务缠身，好叫那招他当兵的人喜悦。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 9:24–27; 启示录 3:11; 提摩太后书 4:7–8"> 人若在场上比武，非按规矩，就不能得冠冕。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 10:36; 哥林多前书 9:7–11; 哥林多前书 3:6–9"> 劳力的农夫理当先得粮食。</span>
<span className="v" id="v7" data-v="7" data-xref="雅各书 1:5; 约翰一书 5:20; 路加福音 24:45"> 我所说的话，你要思想，因为凡事主必给你聪明。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 2:24; 罗马书 2:16; 哥林多前书 15:11–20"> 你要记念耶稣基督乃是大卫的后裔，他从死里复活，正合乎我所传的福音。</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比书 1:7; 使徒行传 28:31; 提摩太后书 1:8"> 我为这福音受苦难，甚至被捆绑，像犯人一样。然而 神的道却不被捆绑。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前书 5:10; 歌罗西书 1:24; 提摩太后书 2:3"> 所以，我为选民凡事忍耐，叫他们也可以得着那在基督耶稣里的救恩和永远的荣耀。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 6:8; 歌罗西书 3:3–4; 罗马书 6:5"> 有可信的话说：<br /><span className="pl pl-1">我们若与基督同死，也必与他同活；</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 8:17; 马太福音 10:33; 启示录 20:4"> <span className="pl pl-1">我们若能忍耐，也必和他一同作王。</span><br /><span className="pl pl-1">我们若不认他，他也必不认我们；</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="民数记 23:19; 罗马书 3:3; 帖撒罗尼迦后书 3:3"> <span className="pl pl-1">我们纵然失信，他仍是可信的，</span><br /><span className="pl pl-1">因为他不能背乎自己。</span></span>
</div>
</div>

## 无愧的工人

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="提多书 3:9–11; 提摩太后书 2:23; 提摩太后书 4:1"> 你要使众人回想这些事，在主面前嘱咐他们：不可为言语争辩；这是没有益处的，只能败坏听见的人。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 2:4; 彼得后书 1:10; 提摩太前书 4:6"> 你当竭力在 神面前得蒙喜悦，作无愧的工人，按着正意分解真理的道。</span>
<span className="v" id="v16" data-v="16" data-xref="提多书 3:9; 提摩太前书 6:20; 提摩太后书 2:14"> 但要远避世俗的虚谈，因为这等人必进到更不敬虔的地步。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太前书 1:20; 那鸿书 3:15; 雅各书 5:3"> 他们的话如同毒疮，越烂越大；其中有许米乃和腓理徒，</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 15:12; 提摩太前书 1:19; 希伯来书 3:10"> 他们偏离了真道，说复活的事已过，就败坏好些人的信心。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 10:14; 哥林多前书 8:3; 那鸿书 1:7"> 然而， 神坚固的根基立住了；上面有这印记说：「主认识谁是他的人」；又说：「凡称呼主名的人总要离开不义。」</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 9:21–23; 彼得前书 2:5; 提摩太前书 3:15"> 在大户人家，不但有金器银器，也有木器瓦器；有作为贵重的，有作为卑贱的。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 3:17; 以弗所书 2:10; 哥林多后书 7:1"> 人若自洁，脱离卑贱的事，就必作贵重的器皿，成为圣洁，合乎主用，预备行各样的善事。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:11; 彼得前书 3:11; 哥林多前书 6:18"> 你要逃避少年的私欲，同那清心祷告主的人追求公义、信德、仁爱、和平。</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太后书 2:14; 提多书 3:9; 提摩太前书 4:7"> 惟有那愚拙无学问的辩论，总要弃绝，因为知道这等事是起争竞的。</span>
<span className="v" id="v24" data-v="24" data-xref="提多书 3:2; 雅各书 1:19–20; 提摩太前书 3:2–3"> 然而主的仆人不可争竞，只要温温和和地待众人，善于教导，存心忍耐，</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 11:18; 加拉太书 6:1; 提摩太前书 2:4"> 用温柔劝戒那抵挡的人；或者 神给他们悔改的心，可以明白真道，</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太前书 3:7; 以赛亚书 49:25–26; 诗篇 124:7"> 叫他们这已经被魔鬼任意掳去的，可以醒悟，脱离他的网罗。</span>
</div>

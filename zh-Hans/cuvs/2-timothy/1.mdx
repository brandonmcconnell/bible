## 忠于福音

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="罗马书 1:8–9; 希伯来书 13:8; 使徒行传 23:1"> 我感谢 神，就是我接续祖先用清洁的良心所事奉的 神。祈祷的时候，不住的想念你，</span>
<span className="v" id="v4" data-v="4" data-xref="提摩太后书 4:9; 腓立比书 1:8; 帖撒罗尼迦前书 2:17–1"> 记念你的眼泪，昼夜切切地想要见你，好叫我满心快乐。</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太前书 1:5; 使徒行传 16:1; 提摩太后书 3:15"> 想到你心里无伪之信，这信是先在你外祖母罗以和你母亲友妮基心里的，我深信也在你的心里。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前书 4:14; 彼得前书 4:10–11; 罗马书 12:6–8"> 为此我提醒你，使你将 神借我按手所给你的恩赐再如火挑旺起来。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:15; 约翰一书 4:18; 加拉太书 5:22"> 因为 神赐给我们，不是胆怯的心，乃是刚强、仁爱、谨守的心。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 1:16; 马可福音 8:38; 彼得前书 4:13–15"> 你不要以给我们的主作见证为耻，也不要以我这为主被囚的为耻；总要按 神的能力，与我为福音同受苦难。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 2:8–9; 提多书 3:4–5; 以弗所书 1:3–4"> 神救了我们，以圣召召我们，不是按我们的行为，乃是按他的旨意和恩典；这恩典是万古之先，在基督耶稣里赐给我们的，</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 1:2; 罗马书 16:26; 彼得后书 3:18"> 但如今借着我们救主基督耶稣的显现才表明出来了。他已经把死废去，借着福音，将不能坏的生命彰显出来。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 2:7; 以弗所书 3:7–8; 使徒行传 9:15"> 我为这福音奉派作传道的，作使徒，作师傅。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太后书 1:8; 犹大书 1:24; 彼得前书 4:19"> 为这缘故，我也受这些苦难。然而我不以为耻；因为知道我所信的是谁，也深信他能保全我所交付他的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：他所交托我的">a</a></sup>，直到那日。</span>
<span className="v" id="v13" data-v="13" data-xref="提多书 1:9; 提摩太后书 3:14; 腓立比书 4:9"> 你从我听的那纯正话语的规模，要用在基督耶稣里的信心和爱心，常常守着。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 14:17; 罗马书 8:13; 提摩太前书 6:20"> 从前所交托你的善道，你要靠着那住在我们里面的圣灵牢牢地守着。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太后书 4:16; 腓立比书 2:21; 使徒行传 19:10"> 凡在亚细亚的人都离弃我，这是你知道的，其中有腓吉路和黑摩其尼。</span>
<span className="v" id="v16" data-v="16" data-xref="提摩太后书 4:19; 腓利门书 1:20; 腓利门书 1:7"> 愿主怜悯阿尼色弗一家的人；因他屡次使我畅快，不以我的锁链为耻，</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 28:30–31"> 反倒在罗马的时候，殷勤地找我，并且找着了。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 6:10; 提摩太后书 1:12; 提摩太前书 1:3"> 愿主使他在那日得主的怜悯。他在以弗所怎样多多地服事我，是你明明知道的。</span>
</div>
</div>

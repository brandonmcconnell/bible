## 末世的人性

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得后书 3:3; 提摩太后书 4:3; 提摩太前书 4:1–3"> 你该知道，末世必有危险的日子来到。</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比书 2:21; 罗马书 1:29–31; 犹大书 1:16"> 因为那时，人要专顾自己，贪爱钱财，自夸，狂傲，谤 ，违背父母，忘恩负义，心不圣洁，</span>
<span className="v" id="v3" data-v="3" data-xref="犹大书 1:18; 罗马书 1:31; 马太福音 10:21"> 无亲情，不解怨，好说谗言，不能自约，性情凶暴，不爱良善，</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比书 3:18–19; 提摩太前书 3:6; 犹大书 1:4"> 卖主卖友，任意妄为，自高自大，爱宴乐，不爱 神，</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 29:13; 提多书 1:16; 马太福音 23:27–28"> 有敬虔的外貌，却背了敬虔的实意；这等人你要躲开。</span>
<span className="v" id="v6" data-v="6" data-xref="犹大书 1:4; 彼得后书 3:17; 提多书 3:3"> 那偷进人家、牢笼无知妇女的，正是这等人。这些妇女担负罪恶，被各样的私欲引诱，</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太后书 4:3–4; 以弗所书 4:14; 提摩太前书 2:4"> 常常学习，终久不能明白真道。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 13:8–11; 启示录 2:20; 提摩太前书 6:5"> 从前雅尼和佯庇怎样敌挡摩西，这等人也怎样敌挡真道。他们的心地坏了，在真道上是可废弃的。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太后书 3:8; 出埃及记 7:12; 耶利米书 28:15–17"> 然而他们不能再这样敌挡；因为他们的愚昧必在众人面前显露出来，像那二人一样。</span>
</div>
</div>

## 对提摩太的最后指示

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 6:11; 提多书 2:7; 彼得后书 1:5–7"> 但你已经服从了我的教训、品行、志向、信心、宽容、爱心、忍耐，</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 34:19; 使徒行传 14:5–6; 哥林多后书 11:23–28"> 以及我在安提阿、以哥念、路司得所遭遇的逼迫、苦难。我所忍受是何等的逼迫；但从这一切苦难中，主都把我救出来了。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 3:14; 彼得前书 4:12–16; 彼得前书 2:20–21"> 不但如此，凡立志在基督耶稣里敬虔度日的也都要受逼迫。</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太前书 4:1; 彼得后书 2:20; 提多书 3:3"> 只是作恶的和迷惑人的，必越久越恶，他欺哄人，也被人欺哄。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:13; 提摩太后书 2:2; 提摩太后书 1:13"> 但你所学习的，所确信的，要存在心里；因为你知道是跟谁学的，</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 119:98–99; 路加福音 24:45; 箴言 22:6"> 并且知道你是从小明白圣经，这圣经能使你因信基督耶稣，有得救的智慧。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 15:4; 希伯来书 4:12; 彼得后书 1:19–21"> 圣经都是 神所默示的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：凡 神所默示的圣经">a</a></sup>，于教训、督责、使人归正、教导人学义都是有益的，</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太后书 2:21; 以弗所书 2:10; 哥林多后书 9:8"> 叫属 神的人得以完全，预备行各样的善事。</span>
</div>
</div>

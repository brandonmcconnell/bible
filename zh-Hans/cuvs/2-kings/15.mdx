## 犹大王亚撒利雅

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 26:3–4; 列王纪下 14:21; 历代志下 26:1"> 以色列王耶罗波安二十七年，犹大王亚玛谢的儿子亚撒利雅登基，</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 26:3–4"> 他登基的时候年十六岁，在耶路撒冷作王五十二年。他母亲名叫耶可利雅，是耶路撒冷人。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 14:3–4; 列王纪下 12:2–3; 历代志下 26:4"> 亚撒利雅行耶和华眼中看为正的事，效法他父亲亚玛谢一切所行的；</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 15:35; 列王纪下 14:4; 列王纪下 12:3"> 只是邱坛还没有废去，百姓仍在那里献祭烧香。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 13:46; 民数记 12:14; 列王纪下 7:3"> 耶和华降灾与王，使他长大麻风，直到死日，他就住在别的宫里。他的儿子约坦管理家事，治理国民。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 26:5–15; 列王纪下 14:18"> 亚撒利雅其余的事，凡他所行的都写在犹大列王记上。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 26:23; 以赛亚书 6:1"> 亚撒利雅与他列祖同睡，葬在大卫城他列祖的坟地里。他儿子约坦接续他作王。</span>
</div>
</div>

## 以色列王撒迦利雅

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪下 14:16–17; 列王纪下 14:29–1; 列王纪下 14:21"> 犹大王亚撒利雅三十八年，耶罗波安的儿子撒迦利雅在撒马利亚作以色列王六个月。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 14:24; 列王纪下 13:2; 列王纪下 13:11"> 他行耶和华眼中看为恶的事，效法他列祖所行的，不离开尼八的儿子耶罗波安使以色列人陷在罪里的那罪。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 15:28; 列王纪下 15:14; 列王纪下 9:24"> 雅比的儿子沙龙背叛他，在百姓面前击杀他，篡了他的位。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 14:28"> 撒迦利雅其余的事都写在以色列诸王记上。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 10:30; 马可福音 13:31; 列王纪下 13:13"> 这是从前耶和华应许耶户说：「你的子孙必坐以色列的国位直到四代。」这话果然应验了。</span>
</div>
</div>

## 以色列王沙龙

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王纪下 15:1; 马太福音 1:8–9; 列王纪下 15:8"> 犹大王乌西雅<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是亚撒利雅">a</a></sup>三十九年，雅比的儿子沙龙登基在撒马利亚作王一个月。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 14:17; 列王纪上 16:17; 列王纪上 16:15"> 迦底的儿子米拿现从得撒上撒马利亚，杀了雅比的儿子沙龙，篡了他的位。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 14:19; 列王纪上 14:29; 列王纪下 15:11"> 沙龙其余的事和他背叛的情形都写在以色列诸王记上。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 8:12; 列王纪上 4:24; 何西阿书 13:16"> 那时米拿现从得撒起攻打提斐萨和其四境，击杀城中一切的人，剖开其中所有的孕妇，都因他们没有给他开城。</span>
</div>
</div>

## 以色列王米拿现

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17"> 犹大王亚撒利雅三十九年，迦底的儿子米拿现登基，在撒马利亚作以色列王十年。</span>
<span className="v" id="v18" data-v="18"> 他行耶和华眼中看为恶的事，终身不离开尼八的儿子耶罗波安使以色列人陷在罪里的那罪。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 14:5; 历代志上 5:25–26; 列王纪下 18:16"> 亚述王普勒来攻击以色列国，米拿现给他一千他连得银子，请普勒帮助他坚定国位。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 18:14–17; 列王纪下 23:35; 列王纪下 17:3–4"> 米拿现向以色列一切大富户索要银子，使他们各出五十舍客勒，就给了亚述王。于是亚述王回去，不在国中停留。</span>
<span className="v" id="v21" data-v="21"> 米拿现其余的事，凡他所行的都写在以色列诸王记上。</span>
<span className="v" id="v22" data-v="22"> 米拿现与他列祖同睡。他儿子比加辖接续他作王。</span>
</div>
</div>

## 以色列王比加辖

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪上 15:25; 列王纪上 22:51; 约伯记 20:5"> 犹大王亚撒利雅五十年，米拿现的儿子比加辖在撒马利亚登基作以色列王二年。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪下 15:9; 列王纪下 15:18"> 他行耶和华眼中看为恶的事，不离开尼八的儿子耶罗波安使以色列人陷在罪里的那罪。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 28:6; 列王纪下 9:14; 列王纪上 16:9"> 比加辖的将军、利玛利的儿子比加背叛他，在撒马利亚王宫里的卫所杀了他。亚珥歌伯和亚利耶并基列的五十人帮助比加；比加击杀他，篡了他的位。</span>
<span className="v" id="v26" data-v="26"> 比加辖其余的事，凡他所行的都写在以色列诸王记上。</span>
</div>
</div>

## 以色列王比加

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 7:4; 以赛亚书 7:1; 列王纪下 15:23"> 犹大王亚撒利雅五十二年，利玛利的儿子比加在撒马利亚登基作以色列王二十年。</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪下 15:18; 列王纪下 13:6; 列王纪下 15:9"> 他行耶和华眼中看为恶的事，不离开尼八的儿子耶罗波安使以色列人陷在罪里的那罪。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 5:26; 列王纪下 17:6; 列王纪下 16:7"> 以色列王比加年间，亚述王提革拉·毗列色来夺了以云、亚伯·伯·玛迦、亚挪、基低斯、夏琐、基列、加利利，和拿弗他利全地，将这些地方的居民都掳到亚述去了。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 17:1; 历代志下 28:4–6; 列王纪下 16:1"> 乌西雅的儿子约坦二十年，以拉的儿子何细亚背叛利玛利的儿子比加，击杀他，篡了他的位。</span>

## 犹大王约坦

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="历代志上 3:12; 列王纪下 15:7; 历代志下 27:1–9"> 以色列王利玛利的儿子比加第二年，犹大王乌西雅的儿子约坦登基。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志下 27:1"> 他登基的时候年二十五岁，在耶路撒冷作王十六年。他母亲名叫耶路沙，是撒督的女儿。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志下 26:4–5; 列王纪下 15:3–4; 历代志下 27:2"> 约坦行耶和华眼中看为正的事，效法他父亲乌西雅一切所行的；</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪下 12:3; 历代志下 23:20; 历代志下 27:3–9"> 只是邱坛还没有废去，百姓仍在那里献祭烧香。约坦建立耶和华殿的上门。</span>
<span className="v" id="v36" data-v="36" data-xref="历代志下 27:4–9; 列王纪下 15:6–7"> 约坦其余的事，凡他所行的都写在犹大列王记上。</span>
<span className="v" id="v37" data-v="37" data-xref="列王纪下 16:5; 以赛亚书 7:1; 路加福音 21:28"> 在那些日子，耶和华才使亚兰王利汛和利玛利的儿子比加去攻击犹大。</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪上 14:20; 列王纪上 14:31; 列王纪下 16:1"> 约坦与他列祖同睡，葬在他祖大卫城他列祖的坟地里。他儿子亚哈斯接续他作王。</span>
</div>

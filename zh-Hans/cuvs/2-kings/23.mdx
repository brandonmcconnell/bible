## 约西亚废除异教崇拜

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 34:29–33; 历代志下 30:2; 申命记 31:28"> 王差遣人招聚犹大和耶路撒冷的众长老来。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 22:8; 申命记 31:10–13; 启示录 20:12"> 王和犹大众人与耶路撒冷的居民，并祭司、先知，和所有的百姓，无论大小，都一同上到耶和华的殿；王就把耶和华殿里所得的约书念给他们听。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 11:14; 列王纪下 11:17; 申命记 13:4"> 王站在柱旁，在耶和华面前立约，要尽心尽性地顺从耶和华，遵守他的诫命、法度、律例，成就这书上所记的约言。众民都服从这约。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 21:3; 列王纪下 21:7; 历代志下 33:3"> 王吩咐大祭司希勒家和副祭司，并把门的，将那为巴力和亚舍拉，并天上万象所造的器皿，都从耶和华殿里搬出来，在耶路撒冷外汲沦溪旁的田间烧了，把灰拿到伯特利去。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 44:17–19; 列王纪下 21:3–4; 何西阿书 10:5"> 从前犹大列王所立拜偶像的祭司，在犹大城邑的邱坛和耶路撒冷的周围烧香，现在王都废去，又废去向巴力和日、月、行星<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：十二宫">a</a></sup>，并天上万象烧香的人；</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 34:4; 列王纪下 23:15; 列王纪上 14:23"> 又从耶和华殿里将亚舍拉搬到耶路撒冷外汲沦溪边焚烧，打碎成灰，将灰撒在平民的坟上；</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 15:12; 以西结书 16:16; 列王纪上 14:24"> 又拆毁耶和华殿里娈童的屋子，就是妇女为亚舍拉织帐子的屋子，</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 15:22; 约书亚记 21:17; 列王纪上 19:3"> 并且从犹大的城邑带众祭司来，污秽祭司烧香的邱坛，从迦巴直到别是巴，又拆毁城门旁的邱坛，这邱坛在邑宰约书亚门前，进城门的左边。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 44:10–14; 撒母耳记上 2:36; 玛拉基书 2:8–9"> 但是邱坛的祭司不登耶路撒冷耶和华的坛，只在他们弟兄中间吃无酵饼。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 30:33; 耶利米书 19:6; 利未记 18:21"> 又污秽欣嫩子谷的陀斐特，不许人在那里使儿女经火献给摩洛；</span>
<span className="v" id="v11" data-v="11" data-xref="以西结书 8:16; 申命记 4:19; 历代志下 14:5"> 又将犹大列王在耶和华殿门旁、太监拿单·米勒靠近游廊的屋子、向日头所献的马废去，且用火焚烧日车。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 21:5; 西番雅书 1:5; 耶利米书 19:13"> 犹大列王在亚哈斯楼顶上所筑的坛和玛拿西在耶和华殿两院中所筑的坛，王都拆毁打碎了，就把灰倒在汲沦溪中。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 11:7; 列王纪上 11:5; 民数记 21:29"> 从前以色列王所罗门在耶路撒冷前、邪僻山右边为西顿人可憎的神亚斯她录、摩押人可憎的神基抹、亚扪人可憎的神米勒公所筑的邱坛，王都污秽了，</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 7:5; 出埃及记 23:24; 列王纪下 23:16"> 又打碎柱像，砍下木偶，将人的骨头充满了那地方。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王纪下 23:6; 列王纪上 14:16; 列王纪上 21:22"> 他将伯特利的坛，就是叫以色列人陷在罪里、尼八的儿子耶罗波安所筑的那坛，都拆毁焚烧，打碎成灰，并焚烧了亚舍拉。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 13:1–2; 列王纪上 13:32; 约翰福音 10:35"> 约西亚回头，看见山上的坟墓，就打发人将坟墓里的骸骨取出来，烧在坛上，污秽了坛，正如从前神人宣传耶和华的话。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 13:1; 列王纪上 13:30–31"> 约西亚问说：「我所看见的是什么碑？」那城里的人回答说：「先前有神人从犹大来，预先说王现在向伯特利坛所行的事，这就是他的墓碑。」</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 13:31; 列王纪上 13:1–22"> 约西亚说：「由他吧！不要挪移他的骸骨。」他们就不动他的骸骨，也不动从撒马利亚来那先知的骸骨。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 34:6–7; 列王纪下 17:9; 以西结书 8:17–18"> 从前以色列诸王在撒马利亚的城邑建筑邱坛的殿，惹动耶和华的怒气，现在约西亚都废去了，就如他在伯特利所行的一般；</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 11:18; 历代志下 34:5; 出埃及记 22:20"> 又将邱坛的祭司都杀在坛上，并在坛上烧人的骨头，就回耶路撒冷去了。</span>
</div>
</div>

## 约西亚守逾越节

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命记 16:1–8; 民数记 9:2–5; 历代志下 35:1–19"> 王吩咐众民说：「你们当照这约书上所写的，向耶和华—你们的 神守逾越节。」</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 30:1–3; 历代志下 30:13–20; 历代志下 35:3–19"> 自从士师治理以色列人和以色列王、犹大王的时候，直到如今，实在没有守过这样的逾越节；</span>
<span className="v" id="v23" data-v="23"> 只有约西亚王十八年在耶路撒冷向耶和华守这逾越节。</span>
</div>
</div>

## 约西亚的其他改革

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="利未记 19:31; 列王纪下 21:6; 创世记 31:19"> 凡犹大国和耶路撒冷所有交鬼的、行巫术的，与家中的神像和偶像，并一切可憎之物，约西亚尽都除掉，成就了祭司希勒家在耶和华殿里所得律法书上所写的话。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 18:5; 耶利米书 29:13; 申命记 6:5"> 在约西亚以前没有王像他尽心、尽性、尽力地归向耶和华，遵行摩西的一切律法；在他以后也没有兴起一个王像他。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王纪下 21:11–13; 列王纪下 24:4; 耶利米书 3:7–10"> 然而，耶和华向犹大所发猛烈的怒气仍不止息，是因玛拿西诸事惹动他。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 18:11; 列王纪下 21:13; 列王纪下 21:4"> 耶和华说：「我必将犹大人从我面前赶出，如同赶出以色列人一般；我必弃掉我从前所选择的这城—耶路撒冷和我所说立我名的殿。」</span>
</div>
</div>

## 约西亚逝世

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王纪下 20:20"> 约西亚其余的事，凡他所行的都写在犹大列王记上。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 46:2; 历代志下 35:20–24; 士师记 5:19"> 约西亚年间，埃及王法老尼哥上到幼发拉底河攻击亚述王；约西亚王去抵挡他。埃及王遇见约西亚在米吉多，就杀了他。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 9:28; 历代志下 36:1–4; 列王纪下 21:24"> 他的臣仆用车将他的尸首从米吉多送到耶路撒冷，葬在他自己的坟墓里。国民膏约西亚的儿子约哈斯接续他父亲作王。</span>
</div>
</div>

## 犹大王约哈斯

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="历代志上 3:15; 列王纪下 24:18; 耶利米书 22:11"> 约哈斯登基的时候年二十三岁，在耶路撒冷作王三个月。他母亲名叫哈慕她，是立拿人耶利米的女儿。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪下 21:2–7; 列王纪下 21:21–22"> 约哈斯行耶和华眼中看为恶的事，效法他列祖一切所行的。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪上 8:65; 列王纪下 25:6; 耶利米书 39:5–6"> 法老尼哥将约哈斯锁禁在哈马地的利比拉，不许他在耶路撒冷作王，又罚犹大国银子一百他连得，金子一他连得。</span>
<span className="v" id="v34" data-v="34" data-xref="以西结书 19:3–4; 列王纪下 24:17; 历代志上 3:15"> 法老尼哥立约西亚的儿子以利亚敬接续他父亲约西亚作王，给他改名叫约雅敬，却将约哈斯带到埃及，他就死在那里。</span>
</div>
</div>

## 犹大王约雅敬

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="列王纪下 23:33; 列王纪下 15:19–20"> 约雅敬将金银给法老，遵着法老的命向国民征取金银，按着各人的力量派定，索要金银，好给法老尼哥。</span>
<span className="v" id="v36" data-v="36" data-xref="历代志下 36:5; 耶利米书 26:1; 历代志上 3:15"> 约雅敬登基的时候年二十五岁，在耶路撒冷作王十一年。他母亲名叫西布大，是鲁玛人毗大雅的女儿。</span>
<span className="v" id="v37" data-v="37" data-xref="历代志下 33:22–23; 以西结书 19:5–9; 耶利米书 36:31"> 约雅敬行耶和华眼中看为恶的事，效法他列祖一切所行的。</span>
</div>
</div>

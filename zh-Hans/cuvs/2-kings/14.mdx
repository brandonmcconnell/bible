## 犹大王亚玛谢

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 13:10; 历代志下 25:1–4; 列王纪下 14:15"> 以色列王约哈斯的儿子约阿施第二年，犹大王约阿施的儿子亚玛谢登基。</span>
<span className="v" id="v2" data-v="2"> 他登基的时候年二十五岁，在耶路撒冷作王二十九年。他母亲名叫约耶但，是耶路撒冷人。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 25:2–3; 撒迦利亚书 1:4–6; 列王纪上 11:4"> 亚玛谢行耶和华眼中看为正的事，但不如他祖大卫，乃效法他父约阿施一切所行的；</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 12:3; 列王纪下 16:4; 列王纪下 15:35"> 只是邱坛还没有废去，百姓仍在那里献祭烧香。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 25:3–4; 列王纪下 12:20–21; 民数记 35:33"> 国一坚定，就把杀他父王的臣仆杀了，</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 24:16; 以西结书 18:20; 以西结书 18:4"> 却没有治死杀王之人的儿子，是照摩西律法书上耶和华所吩咐的说：「不可因子杀父，也不可因父杀子，各人要为本身的罪而死。」</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 8:13; 历代志上 18:12; 约书亚记 15:38"> 亚玛谢在盐谷杀了以东人一万，又攻取了西拉，改名叫约帖，直到今日。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 25:17–24; 撒母耳记下 2:14–17; 列王纪下 14:11"> 那时，亚玛谢差遣使者去见耶户的孙子约哈斯的儿子以色列王约阿 施，说：「你来，我们二人相见于战场。」</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 9:8–15; 列王纪上 4:33; 历代志下 33:11"> 以色列王约阿施差遣使者去见犹大王亚玛谢，说：「黎巴嫩的蒺藜差遣使者去见黎巴嫩的香柏树，说：将你的女儿给我儿子为妻。后来黎巴嫩有一只野兽经过，把蒺藜践踏了。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 26:16; 申命记 8:14; 历代志下 32:25"> 你打败了以东人就心高气傲，你以此为荣耀，在家里安居就罢了，为何要惹祸，使自己和犹大国一同败亡呢？」</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 19:38; 历代志下 25:16; 约书亚记 15:10"> 亚玛谢却不肯听这话。于是以色列王约阿施上来，在犹大的伯·示麦与犹大王亚玛谢相见于战场。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 18:17; 撒母耳记上 4:10; 列王纪上 22:36"> 犹大人败在以色列人面前，各自逃回家里去了。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 8:16; 尼希米记 12:39; 撒迦利亚书 14:10"> 以色列王约阿施在伯·示麦擒住亚哈谢的孙子、约阿施的儿子犹大王亚玛谢，就来到耶路撒冷，拆毁耶路撒冷的城墙，从以法莲门直到角门共四百肘，</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 14:26; 列王纪上 7:51; 列王纪上 15:18"> 又将耶和华殿里与王宫府库里所有的金银和器皿都拿了去，并带人去为质，就回撒马利亚去了。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 13:12–13; 列王纪上 14:19–20; 列王纪下 10:34–35"> 约阿施其余所行的事和他的勇力，并与犹大王亚玛谢争战的事，都写在以色列诸王记上。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 13:9; 列王纪下 13:13; 列王纪上 1:21"> 约阿施与他列祖同睡，葬在撒马利亚，以色列诸王的坟地里。他儿子耶罗波安接续他作王。</span>
</div>
</div>

## 犹大王亚玛谢去世

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="历代志下 25:25–28; 列王纪下 13:10; 列王纪下 14:23"> 以色列王约哈斯的儿子约阿施死后，犹大王约阿施的儿子亚玛谢又活了十五年。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 11:41; 列王纪上 14:29; 列王纪下 13:8"> 亚玛谢其余的事都写在犹大列王记上。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 10:31; 列王纪下 15:25; 列王纪下 12:20–21"> 耶路撒冷有人背叛亚玛谢，他就逃到拉吉；叛党却打发人到拉吉将他杀了。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 9:28; 列王纪下 12:21; 历代志下 33:20"> 人就用马将他的尸首驮到耶路撒冷，葬在大卫城他列祖的坟地里。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 21:24; 马太福音 1:8–9; 列王纪下 15:13"> 犹大众民立亚玛谢的儿子亚撒利雅<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="又名乌西雅">a</a></sup>接续他父作王，那时他年十六岁。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 16:6; 列王纪上 9:26; 申命记 2:8"> 亚玛谢与他列祖同睡之后，亚撒利雅收回以拉他仍归犹大，又重新修理。</span>
</div>
</div>

## 以色列王耶罗波安二世

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="何西阿书 1:1; 阿摩司书 7:9–11; 阿摩司书 1:1"> 犹大王约阿施的儿子亚玛谢十五年，以色列王约阿施的儿子耶罗波安在撒马利亚登基，作王四十一年。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪下 13:6; 列王纪下 13:11; 创世记 38:7"> 他行耶和华眼中看为恶的事，不离开尼八的儿子耶罗波安使以色列人陷在罪里的一切罪。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 3:17; 马太福音 12:39–40; 约书亚记 19:13"> 他收回以色列边界之地，从哈马口直到亚拉巴海，正如耶和华—以色列的 神借他仆人迦特希弗人亚米太的儿子先知约拿所说的。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 32:36; 出埃及记 3:7; 列王纪下 13:4"> 因为耶和华看见以色列人甚是艰苦，无论困住的、自由的都没有了，也无人帮助以色列人。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 13:23; 列王纪下 13:5; 罗马书 11:2–12"> 耶和华并没有说要将以色列的名从天下涂抹，乃借约阿施的儿子耶罗波安拯救他们。</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪上 11:24; 历代志上 18:5–6; 撒母耳记下 8:6"> 耶罗波安其余的事，凡他所行的和他的勇力，他怎样争战，怎样收回大马士革和先前属犹大的哈马归以色列，都写在以色列诸王记上。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪下 15:8"> 耶罗波安与他列祖以色列诸王同睡。他儿子撒迦利雅接续他作王。</span>
</div>

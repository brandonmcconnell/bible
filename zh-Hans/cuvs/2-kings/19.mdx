## 希西家王派人求问以赛亚

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 21:27; 列王纪下 18:37; 历代志下 32:20–22"> 希西家王听见，就撕裂衣服，披上麻布，进了耶和华的殿；</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 1:1; 以赛亚书 2:1; 马太福音 4:14"> 使家宰以利亚敬和书记舍伯那，并祭司中的长老，都披上麻布，去见亚摩斯的儿子先知以赛亚，</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 30:5–7; 以赛亚书 66:9; 何西阿书 13:13"> 对他说：「希西家如此说：『今日是急难、责罚、凌辱的日子，就如妇人将要生产婴孩，却没有力量生产。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 16:12; 罗马书 9:27; 约书亚记 14:12"> 或者耶和华—你的 神听见拉伯沙基的一切话，就是他主人亚述王打发他来辱骂永生 神的话，耶和华—你的 神听见这话，就发斥责。故此，求你为余剩的民扬声祷告。』」</span>
<span className="v" id="v5" data-v="5"> 希西家王的臣仆就去见以赛亚。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 18:35; 列王纪下 18:17; 以赛亚书 37:6–38"> 以赛亚对他们说：「要这样对你们的主人说，耶和华如此说：『你听见亚述王的仆人亵渎我的话，不要惧怕。</span>
<span className="v" id="v7" data-v="7" data-xref="俄巴底亚书 1:1; 列王纪下 7:6; 诗篇 18:14–15"> 我必惊动<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是使灵进入">a</a></sup>他的心，他要听见风声就归回本地。我必使他在那里倒在刀下。』」</span>
</div>
</div>

## 亚述人再度威胁

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪下 18:14; 约书亚记 10:29; 约书亚记 12:11"> 拉伯沙基回去，正遇见亚述王攻打立拿，原来他早听见亚述王拔营离开拉吉。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 23:27; 以赛亚书 37:9; 列王纪下 18:17"> 亚述王听见人论古实王特哈加说：「他出来要与你争战。」于是亚述王又打发使者去见希西家，吩咐他们说：</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 18:5; 列王纪下 18:29–30; 历代志下 32:15–19"> 「你们对犹大王希西家如此说：『不要听你所倚靠的 神欺哄你，说耶路撒冷必不交在亚述王的手中。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 10:8–11; 历代志下 32:13–14; 列王纪下 19:17–18"> 你总听说亚述诸王向列国所行的，乃是尽行灭绝，难道你还能得救吗？</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 17:6; 创世记 11:31; 以西结书 27:23"> 我列祖所毁灭的，就是歌散、哈兰、利色，和属提·拉撒的伊甸人，这些国的神何曾拯救这些国呢？</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 18:34; 列王纪下 17:24; 以赛亚书 11:11"> 哈马的王、亚珥拔的王、西法瓦音城的王、希拿，和以瓦的王都在哪里呢？』」</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 37:14; 诗篇 91:1–2; 诗篇 123:1–4"> 希西家从使者手里接过书信来，看完了，就上耶和华的殿，将书信在耶和华面前展开。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 44:6; 列王纪下 5:15; 但以理书 4:34–35"> 希西家向耶和华祷告说：「坐在二基路伯上耶和华—以色列的 神啊，你是天下万国的 神，你曾创造天地。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 6:40; 诗篇 31:2; 列王纪下 19:4"> 耶和华啊，求你侧耳而听！耶和华啊，求你睁眼而看！要听西拿基立打发使者来辱骂永生 神的话。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 5:26; 约伯记 9:2; 哥林多前书 14:25"> 耶和华啊，亚述诸王果然使列国和列国之地变为荒凉，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 17:29; 以赛亚书 44:9–20; 耶利米书 10:3–9"> 将列国的神像都扔在火里；因为它本不是神，乃是人手所造的，是木头石头的，所以灭绝它。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 83:18; 列王纪上 8:43; 诗篇 67:1–2"> 耶和华—我们的 神啊，现在求你救我们脱离亚述王的手，使天下万国都知道惟独你—耶和华是 神！」</span>
</div>
</div>

## 以赛亚传给王的信息

<div className="bt">
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="列王纪下 20:5; 历代志下 32:20–21; 耶利米书 33:3"> 亚摩斯的儿子以赛亚就打发人去见希西家，说：「耶和华—以色列的 神如此说：『你既然求我攻击亚述王西拿基立，我已听见了。』</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米哀歌 2:13; 约伯记 16:4; 耶利米书 14:17"> 耶和华论他这样说：<br /><span className="pl pl-1">锡安的处女藐视你，嗤笑你；</span><br /><span className="pl pl-1">耶路撒冷的女子向你摇头。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 5:24; 诗篇 71:22; 以赛亚书 30:11–12"> <span className="pl pl-1">你辱骂谁？亵渎谁？</span><br /><span className="pl pl-1">扬起声来，高举眼目攻击谁呢？</span><br /><span className="pl pl-1">乃是攻击以色列的圣者！</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 18:17; 诗篇 20:7; 以赛亚书 10:18"> <span className="pl pl-1">你借你的使者辱骂主，</span><br /><span className="pl pl-1">并说：我率领许多战车上山顶，</span><br /><span className="pl pl-1">到黎巴嫩极深之处；</span><br /><span className="pl pl-1">我要砍伐其中高大的香柏树和佳美的松树；</span><br /><span className="pl pl-1">我必上极高之处，进入肥田的树林。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 19:6; 出埃及记 15:9; 撒母耳记下 17:13"> <span className="pl pl-1">我已经在外邦挖井喝水；</span><br /><span className="pl pl-1">我必用脚掌踏干埃及的一切河。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 45:7; 以赛亚书 10:5–6; 以赛亚书 37:26–27"> <span className="pl pl-1">耶和华说，我早先所做的，</span><br /><span className="pl pl-1">古时所立的，就是现在借你</span><br /><span className="pl pl-1">使坚固城荒废，变为乱堆，</span><br /><span className="pl pl-1">这事你岂没有听见吗？</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 51:30; 诗篇 102:11; 耶利米书 51:32"> <span className="pl pl-1">所以其中的居民力量甚小，</span><br /><span className="pl pl-1">惊惶羞愧。</span><br /><span className="pl pl-1">他们像野草，像青菜，</span><br /><span className="pl pl-1">如房顶上的草，</span><br /><span className="pl pl-1">又如未长成而枯干的禾稼。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 37:28–29; 耶利米书 23:23–24; 诗篇 139:1–11"> <span className="pl pl-1">你坐下，你出去，你进来，</span><br /><span className="pl pl-1">你向我发烈怒，我都知道。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="以西结书 29:4; 以西结书 38:4; 列王纪下 19:33"> <span className="pl pl-1">因你向我发烈怒，</span><br /><span className="pl pl-1">又因你狂傲的话达到我耳中，</span><br /><span className="pl pl-1">我就要用钩子钩上你的鼻子，</span><br /><span className="pl pl-1">把嚼环放在你口里，</span><br /><span className="pl pl-1">使你从你来的路转回去。</span></span>
<span className="v" id="v29" data-v="29" data-xref="利未记 25:20–22; 列王纪下 20:8–9; 出埃及记 3:12"> 「以色列人哪，我赐你们一个证据：你们今年要吃自生的，明年也要吃自长的；至于后年，你们要耕种收割，栽植葡萄园，吃其中的果子。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 19:4; 以赛亚书 27:6; 历代志下 32:22–23"> 犹大家所逃脱余剩的，仍要往下扎根，向上结果。</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 9:7; 罗马书 11:5; 罗马书 9:27"> 必有余剩的民从耶路撒冷而出；必有逃脱的人从锡安山而来。耶和华的热心必成就这事。</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 8:7–10; 撒母耳记下 20:15; 以赛亚书 37:33–35"> 「所以，耶和华论亚述王如此说：『他必不得来到这城，也不在这里射箭，不得拿盾牌到城前，也不筑垒攻城。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪下 19:28; 列王纪下 19:36"> 他从哪条路来，必从那条路回去，必不得来到这城。这是耶和华说的。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 11:12–13; 列王纪下 20:6; 列王纪上 15:4"> 因我为自己的缘故，又为我仆人大卫的缘故，必保护拯救这城。』」</span>
<span className="v" id="v35" data-v="35" data-xref="历代志下 32:21–22; 撒母耳记下 24:16; 出埃及记 12:29–30"> 当夜，耶和华的使者出去，在亚述营中杀了十八万五千人。清早有人起来，一看，都是死尸了。</span>
<span className="v" id="v36" data-v="36" data-xref="约拿书 1:2; 列王纪下 19:7; 列王纪下 19:33"> 亚述王西拿基立就拔营回去，住在尼尼微。</span>
<span className="v" id="v37" data-v="37" data-xref="以斯拉记 4:2; 创世记 8:4; 列王纪下 19:7"> 一日在他的神尼斯洛庙里叩拜，他儿子亚得米勒和沙利色用刀杀了他，就逃到亚拉腊地。他儿子以撒哈顿接续他作王。</span>
</div>

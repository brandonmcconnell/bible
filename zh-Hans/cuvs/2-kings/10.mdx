## 耶户写信給耶斯列首领

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 8:30; 列王纪上 13:32; 列王纪上 21:8–14"> 亚哈有七十个儿子在撒马利亚。耶户写信送到撒马利亚，通知耶斯列的首领，就是长老和教养亚哈众子的人，说：</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 5:6"> 「你们那里既有你们主人的众子和车马、器械、坚固城，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 2:8–9; 列王纪上 12:20–21; 撒母耳记下 2:12–17"> 接了这信，就可以在你们主人的众子中选择一个贤能合宜的，使他坐他父亲的位，你们也可以为你们主人的家争战。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 9:24; 列王纪下 9:27; 以赛亚书 27:4"> 他们却甚惧怕，彼此说：「二王在他面前尚且站立不住，我们怎能站得住呢？」</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 20:32; 列王纪上 20:4; 约书亚记 9:11"> 家宰、邑宰，和长老，并教养众子的人，打发人去见耶户，说：「我们是你的仆人，凡你所吩咐我们的都必遵行，我们不立谁作王，你看怎样好就怎样行。」</span>
</div>
</div>

## 亚哈众子被杀

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="启示录 2:20–23; 申命记 5:9; 民数记 25:4"> 耶户又给他们写信说：「你们若归顺我，听从我的话，明日这时候，要将你们主人众子的首级带到耶斯列来见我。」那时王的儿子七十人都住在教养他们那城中的尊贵人家里。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 21:21; 列王纪下 11:1; 列王纪下 10:9"> 信一到，他们就把王的七十个儿子杀了，将首级装在筐里，送到在耶斯列的耶户那里。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 21:23; 撒母耳记下 11:18–21; 马可福音 6:28"> 有使者来告诉耶户说：「他们将王众子的首级送来了。」耶户说：「将首级在城门口堆作两堆，搁到明日。」</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 9:14–24; 以赛亚书 5:3; 何西阿书 1:4"> 次日早晨，耶户出来，站着对众民说：「你们都是公义的，我背叛我主人，将他杀了；这些人却是谁杀的呢？</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 21:29; 列王纪上 21:19; 列王纪下 9:7–10"> 由此可知，耶和华指着亚哈家所说的话一句没有落空，因为耶和华借他仆人以利亚所说的话都成就了。」</span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 18:19; 列王纪上 18:19; 列王纪上 22:6"> 凡亚哈家在耶斯列所剩下的人和他的大臣、密友、祭司，耶户尽都杀了，没有留下一个。</span>
</div>
</div>

## 亚哈谢的兄弟被杀

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12"> 耶户起身往撒马利亚去。在路上、牧人剪羊毛之处，</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 8:29; 列王纪下 8:24; 历代志下 21:17"> 遇见犹大王亚哈谢的弟兄，问他们说：「你们是谁？」回答说：「我们是亚哈谢的弟兄，现在下去要问王和太后的众子安。」</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 22:10; 列王纪下 10:6; 列王纪下 10:10–11"> 耶户吩咐说：「活捉他们！」跟从的人就活捉了他们，将他们杀在剪羊毛之处的坑边，共四十二人，没有留下一个。</span>
</div>
</div>

## 亚哈家剩下的人被杀

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米书 35:14–19; 以斯拉记 10:19; 以西结书 17:18"> 耶户从那里前行，恰遇利甲的儿子约拿达来迎接他，耶户问他安，对他说：「你诚心待我像我诚心待你吗？」约拿达回答说：「是。」耶户说：「若是这样，你向我伸手」，他就伸手；耶户拉他上车。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 19:10; 马太福音 6:5; 列王纪下 10:31"> 耶户说：「你和我同去，看我为耶和华怎样热心」；于是请他坐在车上，</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 9:8; 历代志下 22:8; 玛拉基书 4:1"> 到了撒马利亚，就把撒马利亚的亚哈家剩下的人都杀了，直到灭尽，正如耶和华对以利亚所说的。</span>
</div>
</div>

## 拜巴力的人被杀

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王纪上 16:31–32; 列王纪下 3:2; 罗马书 3:8"> 耶户招聚众民，对他们说：「亚哈事奉巴力还冷淡，耶户却更热心。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 22:6; 列王纪上 18:19; 哥林多后书 11:3"> 现在我要给巴力献大祭。应当叫巴力的众先知和一切拜巴力的人，并巴力的众祭司，都到我这里来，不可缺少一个；凡不来的必不得活。」耶户这样行，是用诡计要杀尽拜巴力的人。</span>
<span className="v" id="v20" data-v="20" data-xref="约珥书 1:14; 出埃及记 32:5; 列王纪上 18:19–20"> 耶户说：「要为巴力宣告严肃会！」于是宣告了。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 16:32; 列王纪下 11:18; 约珥书 3:2"> 耶户差人走遍以色列地；凡拜巴力的人都来齐了，没有一个不来的。他们进了巴力庙，巴力庙中从前边直到后边都满了人。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 28:2; 马太福音 22:11–12"> 耶户吩咐掌管礼服的人说：「拿出礼服来，给一切拜巴力的人穿。」他就拿出礼服来给了他们。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 13:30; 马太福音 25:32–33; 马太福音 13:41"> 耶户和利甲的儿子约拿达进了巴力庙，对拜巴力的人说：「你们察看察看，在你们这里不可有耶和华的仆人，只可容留拜巴力的人。」</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 20:30–42"> 耶户和约拿达进去，献平安祭和燔祭。 耶户先安派八十人在庙外，吩咐说：「我将这些人交在你们手中，若有一人脱逃，谁放的必叫他偿命！」</span>
<span className="v" id="v25" data-v="25" data-xref="启示录 16:6–7; 以西结书 22:21–22; 列王纪上 18:40"> 耶户献完了燔祭，就出来吩咐护卫兵和众军长说：「你们进去杀他们，不容一人出来！」护卫兵和军长就用刀杀他们，将尸首抛出去，便到巴力庙的城去了，</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 14:23; 列王纪下 3:2; 列王纪下 19:18"> 将巴力庙中的柱像都拿出来烧了；</span>
<span className="v" id="v27" data-v="27" data-xref="但以理书 3:29; 以斯拉记 6:11; 但以理书 2:5"> 毁坏了巴力柱像，拆毁了巴力庙作为厕所，直到今日。</span>
<span className="v" id="v28" data-v="28"> 这样，耶户在以色列中灭了巴力。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪上 12:28–30; 列王纪上 14:16; 列王纪上 13:33–34"> 只是耶户不离开尼八的儿子耶罗波安使以色列人陷在罪里的那罪，就是拜伯特利和但的金牛犊。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 10:35; 列王纪下 13:1; 列王纪下 13:10"> 耶和华对耶户说：「因你办好我眼中看为正的事，照我的心意待亚哈家，你的子孙必接续你坐以色列的国位，直到四代。」</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 10:29; 箴言 4:23; 希伯来书 2:1"> 只是耶户不尽心遵守耶和华—以色列 神的律法，不离开耶罗波安使以色列人陷在罪里的那罪。</span>
</div>
</div>

## 耶户去世

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="列王纪下 8:12; 列王纪上 19:17; 列王纪下 13:22"> 在那些日子，耶和华才割裂以色列国，使哈薛攻击以色列的境界，</span>
<span className="v" id="v33" data-v="33" data-xref="阿摩司书 1:3–4; 申命记 2:36; 约书亚记 13:9–12"> 乃是约旦河东、基列全地，从靠近亚嫩谷边的亚罗珥起，就是基列和巴珊的迦得人、吕便人、玛拿西人之地。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 11:41; 列王纪上 14:29; 列王纪上 14:19"> 耶户其余的事，凡他所行的和他的勇力都写在以色列诸王记上。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 14:20; 列王纪上 14:31; 列王纪上 1:21"> 耶户与他列祖同睡，葬在撒马利亚；他儿子约哈斯接续他作王。</span>
<span className="v" id="v36" data-v="36"> 耶户在撒马利亚作以色列王二十八年。</span>
</div>
</div>

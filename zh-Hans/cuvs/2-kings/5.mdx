## 乃缦得医治

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 4:27; 罗马书 15:18; 箴言 21:31"> 亚兰王的元帅乃缦在他主人面前为尊为大，因耶和华曾借他使亚兰人得胜；他又是大能的勇士，只是长了大麻风。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 6:23; 列王纪下 13:20; 撒母耳记上 13:17–18"> 先前亚兰人成群地出去，从以色列国掳了一个小女子，这女子就服事乃缦的妻。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 26:29; 路加福音 17:12–14; 民数记 11:29"> 她对主母说：「巴不得我主人去见撒马利亚的先知，必能治好他的大麻风。」</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 1:26–27; 约翰福音 4:28–29; 约翰福音 1:42–46"> 乃缦进去，告诉他主人说，以色列国的女子如此如此说。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 14:12; 列王纪下 8:8–9; 民数记 22:17–18"> 亚兰王说：「你可以去，我也达信于以色列王。」于是乃缦带银子十他连得，金子六千舍客勒，衣裳十套，就去了；</span>
<span className="v" id="v6" data-v="6"> 且带信给以色列王，信上说：「我打发臣仆乃缦去见你，你接到这信，就要治好他的大麻风。」</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 2:6; 列王纪上 20:7; 创世记 30:2"> 以色列王看了信就撕裂衣服，说：「我岂是 神，能使人死使人活呢？这人竟打发人来，叫我治好他的大麻风。你们看一看，这人何以寻隙攻击我呢？」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪上 18:36–37; 何西阿书 12:13; 以西结书 2:5"> 神人以利沙听见以色列王撕裂衣服，就打发人去见王，说：「你为什么撕了衣服呢？可使那人到我这里来，他就知道以色列中有先知了。」</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 16:37–39; 列王纪下 6:32; 以赛亚书 60:14"> 于是，乃缦带着车马到了以利沙的家，站在门前。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 9:7; 哥林多前书 6:11; 利未记 14:7"> 以利沙打发一个使者，对乃缦说：「你去在约旦河中沐浴七回，你的肉就必复原，而得洁净。」</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 15:27; 路加福音 14:11; 马太福音 8:8"> 乃缦却发怒走了，说：「我想他必定出来见我，站着求告耶和华—他 神的名，在患处以上摇手，治好这大麻风。</span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 1:9; 列王纪下 5:17; 列王纪下 2:14"> 大马士革的河亚罢拿和法珥法岂不比以色列的一切水更好吗？我在那里沐浴不得洁净吗？」于是气忿忿地转身去了。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 6:21; 列王纪下 13:14; 列王纪下 2:12"> 他的仆人进前来，对他说：「我父啊，先知若吩咐你做一件大事，你岂不做吗？何况说你去沐浴而得洁净呢？」</span>
<span className="v" id="v14" data-v="14" data-xref="约伯记 33:25; 路加福音 4:27; 路加福音 5:13"> 于是乃缦下去，照着神人的话，在约旦河里沐浴七回；他的肉复原，好像小孩子的肉，他就洁净了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理书 2:47; 但以理书 6:26–27; 约书亚记 2:9–11"> 乃缦带着一切跟随他的人，回到神人那里，站在他面前，说：「如今我知道，除了以色列之外，普天下没有 神。现在求你收点仆人的礼物。」</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 5:26; 列王纪下 5:20; 列王纪下 3:14"> 以利沙说：「我指着所事奉永生的耶和华起誓，我必不受。」乃缦再三地求他，他却不受。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 26:18; 列王纪下 5:12; 罗马书 14:1"> 乃缦说：「你若不肯受，请将两骡子驮的土赐给仆人。从今以后，仆人必不再将燔祭或平安祭献与别神，只献给耶和华。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 7:2; 列王纪下 7:17; 列王纪下 17:35"> 惟有一件事，愿耶和华饶恕你仆人：我主人进临门庙叩拜的时候，我用手搀他在临门庙，我也屈身。我在临门庙屈身的这事，愿耶和华饶恕我。」</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 1:17; 马可福音 5:34; 出埃及记 4:18"> 以利沙对他说：「你可以平平安安地回去！」<br />乃缦就离开他去了；走了不远，</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 4:12; 列王纪下 4:31; 列王纪下 6:31"> 神人以利沙的仆人基哈西心里说：「我主人不愿从这亚兰人乃缦手里受他带来的礼物，我指着永生的耶和华起誓，我必跑去追上他，向他要些。」</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 7:6–7; 列王纪下 9:17–22; 列王纪下 4:26"> 于是基哈西追赶乃缦。乃缦看见有人追赶，就急忙下车迎着他，说：「都平安吗？」</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 5:5; 以赛亚书 59:3; 使徒行传 5:3–4"> 说：「都平安。我主人打发我来说：『刚才有两个少年人，是先知门徒，从以法莲山地来见我，请你赐他们一他连得银子，两套衣裳。』」</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 12:10; 列王纪上 20:7; 列王纪下 2:17"> 乃缦说：「请受二他连得」；再三地请受，便将二他连得银子装在两个口袋里，又将两套衣裳交给两个仆人；他们就在基哈西前头抬着走。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 21:16; 约书亚记 7:11–12; 约书亚记 7:1"> 到了山冈，基哈西从他们手中接过来，放在屋里，打发他们回去。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 5:22; 创世记 16:8; 箴言 30:20"> 基哈西进去，站在他主人面前。以利沙问他说：「基哈西你从哪里来？」回答说：「仆人没有往哪里去。」</span>
<span className="v" id="v26" data-v="26" data-xref="歌罗西书 2:5; 哥林多前书 5:3; 列王纪下 6:12"> 以利沙对他说：「那人下车转回迎你的时候，我的心岂没有去呢？这岂是受银子、衣裳、买橄榄园、葡萄园、牛羊、仆婢的时候呢？</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 4:6; 民数记 12:10; 列王纪下 15:5"> 因此，乃缦的大麻风必沾染你和你的后裔，直到永远。」基哈西从以利沙面前退出去，就长了大麻风，像雪那样白。</span>
</div>

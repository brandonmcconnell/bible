## 犹大王希西家

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 28:27–1; 马太福音 1:9–10; 历代志上 3:13"> 以色列王以拉的儿子何细亚第三年，犹大王亚哈斯的儿子希西家登基。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 29:1–2"> 他登基的时候年二十五岁，在耶路撒冷作王二十九年。他母亲名叫亚比，是撒迦利雅的女儿。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 20:3; 列王纪上 11:4; 历代志下 31:20–21"> 希西家行耶和华眼中看为正的事，效法他祖大卫一切所行的。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 31:1; 民数记 21:8–9; 列王纪下 18:22"> 他废去邱坛，毁坏柱像，砍下木偶，打碎摩西所造的铜蛇，因为到那时以色列人仍向铜蛇烧香。希西家叫铜蛇为铜块<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：人称铜蛇为铜像">a</a></sup>。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 23:25; 列王纪下 19:10; 马太福音 27:43"> 希西家倚靠耶和华—以色列的 神，在他前后的犹大列王中没有一个及他的。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 23:8; 申命记 10:20; 约翰福音 14:15"> 因为他专靠耶和华，总不离开，谨守耶和华所吩咐摩西的诫命。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:31; 创世记 39:2–3; 列王纪下 16:7"> 耶和华与他同在，他无论往何处去尽都亨通。他背叛、不肯事奉亚述王。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 14:29; 列王纪下 17:9; 历代志下 28:18"> 希西家攻击非利士人，直到迦萨，并迦萨的四境，从了望楼到坚固城。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="何西阿书 10:14; 列王纪下 17:3–23; 列王纪下 18:1"> 希西家王第四年，就是以色列王以拉的儿子何细亚第七年，亚述王撒缦以色上来围困撒马利亚；</span>
<span className="v" id="v10" data-v="10" data-xref="阿摩司书 6:7; 阿摩司书 9:1–4; 弥迦书 1:6–9"> 过了三年就攻取了城。希西家第六年，以色列王何细亚第九年，撒马利亚被攻取了。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 5:26; 列王纪下 17:6; 以赛亚书 37:12"> 亚述王将以色列人掳到亚述，把他们安置在哈腊与歌散的哈博河边，并米底亚人的城邑；</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 4:17; 彼得前书 2:8; 弥迦书 3:4"> 都因他们不听从耶和华—他们 神的话，违背他的约，就是耶和华仆人摩西吩咐他们所当守的。</span>
</div>
</div>

## 亚述人威胁耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 36:1–22; 历代志下 32:1–23; 以赛亚书 7:17–25"> 希西家王十四年，亚述王西拿基立上来攻击犹大的一切坚固城，将城攻取。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 18:7; 路加福音 14:32; 列王纪上 20:4"> 犹大王希西家差人往拉吉去见亚述王，说：「我有罪了，求你离开我；凡你罚我的，我必承当。」于是亚述王罚犹大王希西家银子三百他连得，金子三十他连得。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 16:8; 列王纪上 15:18–19; 列王纪下 12:18"> 希西家就把耶和华殿里和王宫府库里所有的银子都给了他。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 29:3; 列王纪上 6:31–35"> 那时，犹大王希西家将耶和华殿门上的金子和他自己包在柱上的金子都刮下来，给了亚述王。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 20:1; 列王纪下 20:20; 以赛亚书 7:3"> 亚述王从拉吉差遣他珥探、拉伯撒利，和拉伯沙基率领大军往耶路撒冷，到希西家王那里去。他们上到耶路撒冷，就站在上池的水沟旁，在漂布地的大路上。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 19:2; 以赛亚书 36:3; 撒母耳记下 8:16–17"> 他们呼叫王的时候，就有希勒家的儿子家宰以利亚敬，并书记舍伯那和亚萨的儿子史官约亚，出来见他们。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 36:4; 列王纪下 19:10; 以赛亚书 10:8–14"> 拉伯沙基说：「你们去告诉希西家说，亚述大王如此说：『你所倚靠的有什么可仗赖的呢？</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 21:30–31"> 你说有打仗的计谋和能力，我看不过是虚话。你到底倚靠谁才背叛我呢？</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 30:7; 以西结书 29:6–7; 以赛亚书 30:2–3"> 看哪，你所倚靠的埃及是那压伤的苇杖；人若靠这杖，就必刺透他的手。埃及王法老向一切倚靠他的人也是这样。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 31:1; 列王纪下 18:4–5; 马太福音 27:43"> 你们若对我说：我们倚靠耶和华—我们的 神，希西家岂不是将 神的邱坛和祭坛废去，且对犹大和耶路撒冷的人说：你们当在耶路撒冷这坛前敬拜吗？</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 17:42; 列王纪上 20:10; 尼希米记 4:2–5"> 现在你把当头给我主亚述王，我给你二千匹马，看你这一面骑马的人够不够。</span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 10:8; 申命记 17:16; 以赛亚书 36:6"> 若不然，怎能打败我主臣仆中最小的军长呢？你竟倚靠埃及的战车马兵吗？</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 19:6; 以赛亚书 10:5–6; 列王纪下 19:22–37"> 现在我上来攻击毁灭这地，岂没有耶和华的意思吗？耶和华吩咐我说：你上去攻击毁灭这地吧！』」</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以斯拉记 4:7; 但以理书 2:4; 以赛亚书 36:11–12"> 希勒家的儿子以利亚敬和舍伯那，并约亚，对拉伯沙基说：「求你用亚兰言语和仆人说话，因为我们懂得；不要用犹大言语和我们说话，达到城上百姓的耳中。」</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 73:8; 耶利米哀歌 4:5; 以西结书 4:15"> 拉伯沙基说：「我主差遣我来，岂是单对你和你的主说这些话吗？不也是对这些坐在城上、要与你们一同吃自己粪、喝自己尿的人说吗？」</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 36:13–18; 以赛亚书 10:8–13; 以西结书 29:3"> 于是拉伯沙基站着，用犹大言语大声喊着说：「你们当听亚述大王的话！</span>
<span className="v" id="v29" data-v="29" data-xref="历代志下 32:15; 帖撒罗尼迦后书 2:8; 历代志下 32:11"> 王如此说：『你们不要被希西家欺哄了；因他不能救你们脱离我的手。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 125:1–2; 路加福音 23:35; 列王纪下 19:32–34"> 也不要听希西家使你们倚靠耶和华，说耶和华必要拯救我们，这城必不交在亚述王的手中。』</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪上 4:25; 列王纪上 4:20; 撒迦利亚书 3:10"> 不要听希西家的话！因亚述王如此说：『你们要与我和好，出来投降我，各人就可以吃自己葡萄树和无花果树的果子，喝自己井里的水。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 8:7–9; 出埃及记 3:8; 申命记 11:12"> 等我来领你们到一个地方与你们本地一样，就是有五谷和新酒之地，有粮食和葡萄园之地，有橄榄树和蜂蜜之地，好使你们存活，不至于死。希西家劝导你们，说耶和华必拯救我们；你们不要听他的话。</span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 10:10–11; 列王纪下 19:12–13; 历代志下 32:19"> 列国的神有哪一个救他本国脱离亚述王的手呢？</span>
<span className="v" id="v34" data-v="34" data-xref="以赛亚书 10:9; 列王纪下 17:23–33; 耶利米书 49:23"> 哈马、亚珥拔的神在哪里呢？西法瓦音、希拿、以瓦的神在哪里呢？他们曾救撒马利亚脱离我的手吗？</span>
<span className="v" id="v35" data-v="35" data-xref="但以理书 3:15; 以赛亚书 10:15; 出埃及记 5:2"> 这些国的神有谁曾救自己的国脱离我的手呢？难道耶和华能救耶路撒冷脱离我的手吗？』」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="阿摩司书 5:13; 箴言 9:7; 马太福音 7:6"> 百姓静默不言，并不回答一句，因为王曾吩咐说：「不要回答他。」</span>
<span className="v" id="v37" data-v="37" data-xref="列王纪下 22:11; 创世记 37:29; 列王纪下 5:7"> 当下，希勒家的儿子家宰以利亚敬和书记舍伯那，并亚萨的儿子史官约亚，都撕裂衣服，来到希西家那里，将拉伯沙基的话告诉了他。</span>
</div>
</div>

## 找回斧子的头

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 2:3; 列王纪下 4:1; 约书亚记 17:14"> 先知门徒对以利沙说：「看哪，我们同你所住的地方过于窄小，</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 21:3; 使徒行传 18:3; 帖撒罗尼迦前书 2:9"> 求你容我们往约旦河去，各人从那里取一根木料建造房屋居住。」他说：「你们去吧！」</span>
<span className="v" id="v3" data-v="3" data-xref="约伯记 6:28; 士师记 19:6; 列王纪下 5:23"> 有一人说：「求你与仆人同去。」回答说：「我可以去。」</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 19:5; 申命记 29:11"> 于是以利沙与他们同去。到了约旦河，就砍伐树木。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 37:21; 传道书 10:10; 列王纪下 6:15"> 有一人砍树的时候，斧头掉在水里，他就呼叫说：「哀哉！我主啊，这斧子是借的。」</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 2:21; 马可福音 8:23–25; 列王纪下 4:41"> 神人问说：「掉在哪里了？」他将那地方指给以利沙看。以利沙砍了一根木头，抛在水里，斧头就漂上来了。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 4:36; 出埃及记 4:4; 列王纪下 4:7"> 以利沙说：「拿起来吧！」那人就伸手拿起来了。</span>
</div>
</div>

## 亚兰军败于以色列人

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪下 6:24; 箴言 21:30; 箴言 20:18"> 亚兰王与以色列人争战，和他的臣仆商议说：「我要在某处某处安营。」</span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司书 3:7; 启示录 1:1; 列王纪下 6:12"> 神人打发人去见以色列王，说：「你要谨慎，不要从某处经过，因为亚兰人从那里下来了。」</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 13:14; 列王纪下 5:14; 使徒行传 27:24"> 以色列王差人去窥探神人所告诉所警戒他去的地方，就防备未受其害，不止一两次。</span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 18:7–11; 以赛亚书 57:20–21; 马太福音 2:3–12"> 亚兰王因这事心里惊疑，召了臣仆来，对他们说：「我们这里有谁帮助以色列王，你们不指给我吗？」</span>
<span className="v" id="v12" data-v="12" data-xref="但以理书 2:28–30; 阿摩司书 3:7; 列王纪下 6:9–10"> 有一个臣仆说：「我主，我王！无人帮助他，只有以色列中的先知以利沙，将王在卧房所说的话告诉以色列王了。」</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 37:17; 约翰福音 11:47–53; 撒母耳记上 23:22–23"> 王说：「你们去探他在哪里，我好打发人去捉拿他。」有人告诉王说：「他在多坍。」</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 18:17; 撒母耳记上 24:2; 撒母耳记上 23:26"> 王就打发车马和大军往那里去，夜间到了，围困那城。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 8:26; 历代志下 20:12; 诗篇 53:5"> 神人的仆人清早起来出去，看见车马军兵围困了城。仆人对神人说：「哀哉！我主啊，我们怎样行才好呢？」</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 41:10–14; 罗马书 8:31; 约翰一书 4:4"> 神人说：「不要惧怕！与我们同在的比与他们同在的更多。」</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 68:17; 诗篇 34:7; 撒迦利亚书 6:1–7"> 以利沙祷告说：「耶和华啊，求你开这少年人的眼目，使他能看见。」耶和华开他的眼目，他就看见满山有火车火马围绕以利沙。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 13:11; 约翰福音 12:40; 创世记 19:11"> 敌人下到以利沙那里，以利沙祷告耶和华说：「求你使这些人的眼目昏迷。」耶和华就照以利沙的话，使他们的眼目昏迷。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 24:16; 撒母耳记下 16:18–19; 路加福音 9:23"> 以利沙对他们说：「这不是那道，也不是那城；你们跟我去，我必领你们到所寻找的人那里。」于是领他们到了撒马利亚。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 6:17; 路加福音 24:31; 路加福音 16:23"> 他们进了撒马利亚，以利沙祷告说：「耶和华啊，求你开这些人的眼目，使他们能看见。」耶和华开他们的眼目，他们就看见了，不料，是在撒马利亚的城中。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 5:13; 列王纪下 8:9; 列王纪下 2:12"> 以色列王见了他们，就问以利沙说：「我父啊，我可以击杀他们吗？」</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 12:20–21; 创世记 48:22; 何西阿书 2:18"> 回答说：「不可击杀他们！就是你用刀用弓掳来的，岂可击杀他们吗<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：也不可击杀，何况这些人呢">a</a></sup>？当在他们面前设摆饮食，使他们吃喝回到他们的主人那里。」</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 5:2; 列王纪下 24:2; 路加福音 6:35"> 王就为他们预备了许多食物；他们吃喝完了，打发他们回到他们主人那里。从此，亚兰军不再犯以色列境了。</span>
</div>
</div>

## 围困撒马利亚

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王纪上 20:1; 列王纪上 22:31; 传道书 9:14"> 此后，亚兰王便·哈达聚集他的全军，上来围困撒马利亚。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 6:28–29; 耶利米书 14:18; 耶利米书 14:13–15"> 于是撒马利亚被围困，有饥荒，甚至一个驴头值银八十舍客勒，二升鸽子粪值银五舍客勒。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 14:4; 以赛亚书 10:3; 路加福音 18:3"> 一日，以色列王在城上经过，有一个妇人向他呼叫说：「我主，我王啊！求你帮助。」</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 118:8–9; 诗篇 124:1–3; 诗篇 60:11"> 王说：「耶和华不帮助你，我从何处帮助你？是从禾场，是从酒榨呢？」</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 14:5; 士师记 18:23; 耶利米哀歌 4:10"> 王问妇人说：「你有什么苦处？」她回答说：「这妇人对我说：『将你的儿子取来，我们今日可以吃，明日可以吃我的儿子。』</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 26:29; 申命记 28:53; 申命记 28:57"> 我们就煮了我的儿子吃了。次日我对她说：『要将你的儿子取来，我们可以吃。』她却将她的儿子藏起来了。」</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 21:27; 列王纪下 5:7; 列王纪下 19:1"> 王听见妇人的话，就撕裂衣服；（王在城上经过）百姓看见王贴身穿着麻衣。</span>
<span className="v" id="v31" data-v="31" data-xref="路得记 1:17; 列王纪上 19:2; 约翰福音 11:50"> 王说：「我今日若容沙法的儿子以利沙的头仍在他项上，愿 神重重地降罚与我！」</span>
<span className="v" id="v32" data-v="32" data-xref="以西结书 20:1; 列王纪上 18:4; 以西结书 8:1"> 那时，以利沙正坐在家中，长老也与他同坐。王打发一个伺候他的人去；他还没有到，以利沙对长老说：「你们看这凶手之子，打发人来斩我的头；你们看着使者来到，就关上门，用门将他推出去。在他后头不是有他主人脚步的响声吗？」</span>
<span className="v" id="v33" data-v="33" data-xref="约伯记 2:9; 以赛亚书 8:21; 创世记 4:13"> 正说话的时候，使者来到，王也到了，说：「这灾祸是从耶和华那里来的，我何必再仰望耶和华呢？」</span>
</div>
</div>

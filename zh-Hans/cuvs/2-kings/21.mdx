## 犹大王玛拿西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 62:4; 历代志下 32:33–9; 马太福音 1:10"> 玛拿西登基的时候年十二岁，在耶路撒冷作王五十五年。他母亲名叫协西巴。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 12:31; 历代志下 36:14; 历代志下 33:2–4"> 玛拿西行耶和华眼中看为恶的事，效法耶和华在以色列人面前赶出的外邦人所行可憎的事。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 18:4; 列王纪下 17:16; 申命记 17:3"> 重新建筑他父希西家所毁坏的邱坛，又为巴力筑坛，做亚舍拉像，效法以色列王亚哈所行的，且敬拜事奉天上的万象；</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 8:29; 撒母耳记下 7:13; 耶利米书 32:34"> 在耶和华殿宇中筑坛。耶和华曾指着这殿说：「我必立我的名在耶路撒冷。」</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 7:12; 列王纪下 23:4; 列王纪下 23:12"> 他在耶和华殿的两院中为天上的万象筑坛，</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 17:17; 利未记 19:31; 利未记 18:21"> 并使他的儿子经火，又观兆，用法术，立交鬼的和行巫术的，多行耶和华眼中看为恶的事，惹动他的怒气；</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 7:16; 列王纪上 9:3; 撒母耳记下 7:13"> 又在殿内立雕刻的亚舍拉像。耶和华曾对大卫和他儿子所罗门说：「我在以色列众支派中所选择的耶路撒冷和这殿，必立我的名，直到永远。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 7:10; 申命记 5:28–29; 诗篇 81:11–16"> 以色列人若谨守遵行我一切所吩咐他们的和我仆人摩西所吩咐他们的一切律法，我就不再使他们挪移离开我所赐给他们列祖之地。」</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 29:12; 尼希米记 9:26; 列王纪上 14:16"> 他们却不听从。玛拿西引诱他们行恶，比耶和华在以色列人面前所灭的列国更甚。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 23:34–37; 历代志下 33:10; 历代志下 36:15"> 耶和华借他仆人众先知说：</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 24:3–4; 列王纪上 21:26; 列王纪下 21:9"> 「因犹大王玛拿西行这些可憎的恶事比先前亚摩利人所行的更甚，使犹大人拜他的偶像，陷在罪里；</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 19:3; 撒母耳记上 3:11; 但以理书 9:12"> 所以耶和华—以色列的 神如此说：我必降祸与耶路撒冷和犹大，叫一切听见的人无不耳鸣。</span>
<span className="v" id="v13" data-v="13" data-xref="阿摩司书 7:7–8; 耶利米哀歌 2:8; 以赛亚书 34:11"> 我必用量撒马利亚的准绳和亚哈家的线铊拉在耶路撒冷上，必擦净耶路撒冷，如人擦盘，将盘倒扣。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 23:33; 列王纪下 19:4; 诗篇 89:38–45"> 我必弃掉所余剩的子民<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是产业">a</a></sup>，把他们交在仇敌手中，使他们成为一切仇敌掳掠之物；</span>
<span className="v" id="v15" data-v="15" data-xref="以西结书 20:30; 申命记 31:27; 以西结书 20:21"> 是因他们自从列祖出埃及直到如今，常行我眼中看为恶的事，惹动我的怒气。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数记 35:33; 历代志下 33:9; 列王纪下 21:11"> 玛拿西行耶和华眼中看为恶的事，使犹大人陷在罪里，又流许多无辜人的血，充满了耶路撒冷，从这边直到那边。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王纪下 20:20–21; 历代志下 33:1–20"> 玛拿西其余的事，凡他所行的和他所犯的罪都写在犹大列王记上。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 33:20; 列王纪下 21:26; 历代志下 32:33"> 玛拿西与他列祖同睡，葬在自己宫院乌撒的园内；他儿子亚们接续他作王。</span>
</div>
</div>

## 犹大王亚们

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="历代志下 33:21–23; 列王纪上 22:51; 历代志上 3:14"> 亚们登基的时候年二十二岁，在耶路撒冷作王二年。他母亲名叫米舒利密，是约提巴人哈鲁斯的女儿。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 23:32; 列王纪下 21:11; 使徒行传 7:51"> 亚们行耶和华眼中看为恶的事，与他父亲玛拿西所行的一样；</span>
<span className="v" id="v21" data-v="21"> 行他父亲一切所行的，敬奉他父亲所敬奉的偶像，</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 22:17; 列王纪上 11:33; 历代志上 28:9"> 离弃耶和华—他列祖的 神，不遵行耶和华的道。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 12:20; 列王纪下 14:19; 历代志下 33:24–25"> 亚们王的臣仆背叛他，在宫里杀了他。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪下 14:5; 列王纪下 11:17; 列王纪下 14:21"> 但国民杀了那些背叛亚们王的人，立他儿子约西亚接续他作王。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 20:20; 列王纪下 21:17"> 亚们其余所行的事都写在犹大列王记上。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 21:18; 马太福音 1:10; 列王纪上 13:5"> 亚们葬在乌撒的园内自己的坟墓里。他儿子约西亚接续他作王。</span>
</div>
</div>

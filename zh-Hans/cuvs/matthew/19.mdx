## 休妻的问题

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 10:40; 马太福音 19:1–9; 马太福音 7:28"> 耶稣说完了这些话，就离开加利利，来到犹太的境界约旦河外。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 12:15; 马可福音 6:55–56; 马太福音 15:30–31"> 有许多人跟着他，他就在那里把他们的病人治好了。</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 10:2; 希伯来书 3:9; 马太福音 16:1"> 有法利赛人来试探耶稣，说：「人无论什么缘故都可以休妻吗？」</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 2:23; 创世记 1:27; 创世记 5:2"> 耶稣回答说：「那起初造人的，是造男造女，</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 2:21–24; 哥林多前书 7:4; 哥林多前书 7:2"> 并且说：『因此，人要离开父母，与妻子连合，二人成为一体。』这经你们没有念过吗？</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 13:4; 马可福音 10:9; 哥林多前书 7:10–14"> 既然如此，夫妻不再是两个人，乃是一体的了。所以， 神配合的，人不可分开。」</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 24:1–4; 马太福音 5:31; 马可福音 10:4"> 法利赛人说：「这样，摩西为什么吩咐给妻子休书，就可以休她呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="玛拉基书 2:13–14; 创世记 2:24; 马可福音 10:5"> 耶稣说：「摩西因为你们的心硬，所以许你们休妻，但起初并不是这样。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 5:32; 路加福音 16:18; 哥林多前书 7:39"> 我告诉你们，凡休妻另娶的，若不是为淫乱的缘故，就是犯奸淫了；有人娶那被休的妇人，也是犯奸淫了。」</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 7:32–35; 箴言 19:13–14; 箴言 21:19"> 门徒对耶稣说：「人和妻子既是这样，倒不如不娶。」</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 7:17; 哥林多前书 7:35; 哥林多前书 7:7–9"> 耶稣说：「这话不是人都能领受的，惟独赐给谁，谁才能领受。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 7:32–38; 哥林多前书 9:5; 以赛亚书 56:3–4"> 因为有生来是阉人，也有被人阉的，并有为天国的缘故自阉的。这话谁能领受就可以领受。」</span>
</div>
</div>

## 耶稣为小孩祝福

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马可福音 10:13–16; 路加福音 18:15–17; 马太福音 18:2–5"> 那时，有人带着小孩子来见耶稣，要耶稣给他们按手祷告，门徒就责备那些人。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 18:3; 路加福音 18:16–17; 哥林多前书 14:20"> 耶稣说：「让小孩子到我这里来，不要禁止他们；因为在天国的，正是这样的人。」</span>
<span className="v" id="v15" data-v="15" data-xref="马可福音 10:16; 提摩太后书 3:15; 哥林多前书 7:14"> 耶稣给他们按手，就离开那地方去了。</span>
</div>
</div>

## 少年财主

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马可福音 10:17–30; 约翰福音 3:15; 犹大书 1:21"> 有一个人来见耶稣，说：「夫子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷：良善的夫子">a</a></sup>，我该做什么善事才能得永生？」</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 18:5; 路加福音 10:26–28; 加拉太书 3:11–13"> 耶稣对他说：「你为什么以善事问我呢？只有一位是善的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷：你为什么称我是良善的？除了 神以外，没有一个良善的">b</a></sup>。你若要进入永生，就当遵守诫命。」</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 5:16–21; 出埃及记 20:12–17; 马可福音 10:19"> 他说：「什么诫命？」耶稣说：「就是不可杀人；不可奸淫；不可偷盗；不可作假见证；</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 19:18; 出埃及记 20:12; 马太福音 22:39"> 当孝敬父母；又当爱人如己。」</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太书 3:24; 马可福音 10:20–21; 腓立比书 3:6"> 那少年人说：「这一切我都遵守了，还缺少什么呢？」</span>
<span className="v" id="v21" data-v="21" data-xref="马可福音 10:21; 路加福音 18:22; 路加福音 12:33"> 耶稣说：「你若愿意作完全人，可去变卖你所有的，分给穷人，就必有财宝在天上；你还要来跟从我。」</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 6:24; 以西结书 33:31; 马太福音 13:22"> 那少年人听见这话，就忧忧愁愁地走了，因为他的产业很多。</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太前书 6:9–10; 马太福音 13:22; 马可福音 10:23"> 耶稣对门徒说：「我实在告诉你们，财主进天国是难的。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 5:44; 路加福音 18:25; 马可福音 10:24–25"> 我又告诉你们，骆驼穿过针的眼，比财主进 神的国还容易呢！」</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 10:13; 马太福音 24:22; 罗马书 11:5–7"> 门徒听见这话，就希奇得很，说：「这样谁能得救呢？」</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 32:27; 路加福音 1:37; 约伯记 42:2"> 耶稣看着他们，说：「在人这是不能的，在 神凡事都能。」</span>
<span className="v" id="v27" data-v="27" data-xref="腓立比书 3:8; 路加福音 18:28; 路加福音 5:11"> 彼得就对他说：「看哪，我们已经撇下所有的跟从你，将来我们要得什么呢？」</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 22:28–30; 哥林多前书 6:2–3; 马太福音 25:31"> 耶稣说：「我实在告诉你们，你们这跟从我的人，到复兴的时候，人子坐在他荣耀的宝座上，你们也要坐在十二个宝座上，审判以色列十二个支派。</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 18:29–30; 马可福音 10:29–30; 腓立比书 3:8"> 凡为我的名撇下房屋，或是弟兄、姊妹、父亲、母亲、<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古卷加：妻子、">c</a></sup>儿女、田地的，必要得着百倍，并且承受永生。</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 20:16; 路加福音 13:30; 马可福音 10:31"> 然而，有许多在前的，将要在后；在后的，将要在前。」</span>
</div>
</div>

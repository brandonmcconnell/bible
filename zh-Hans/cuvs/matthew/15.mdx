## 古人的传统

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="马可福音 3:22; 马太福音 23:2; 路加福音 5:21"> 那时，有法利赛人和文士从耶路撒冷来见耶稣，说：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 11:38; 马可福音 7:2; 歌罗西书 2:20–23"> 「你的门徒为什么犯古人的遗传呢？因为吃饭的时候，他们不洗手。」</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 2:23; 提多书 1:14; 歌罗西书 2:8"> 耶稣回答说：「你们为什么因着你们的遗传犯 神的诫命呢？</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 20:12; 利未记 20:9; 出埃及记 21:17"> 神说：『当孝敬父母』；又说：『咒骂父母的，必治死他。』</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 7:10–13; 使徒行传 5:29; 马太福音 23:16–18"> 你们倒说：『无论何人对父母说：我所当奉给你的已经作了供献，</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前书 5:8; 耶利米书 8:8; 马可福音 7:13"> 他就可以不孝敬父母。』这就是你们借着遗传，废了 神的诫命。</span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 7:6; 马太福音 23:23–29; 使徒行传 28:25–27"> 假冒为善的人哪，以赛亚指着你们说的预言是不错的。他说：</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 29:13; 以西结书 33:31; 使徒行传 8:21"> <span className="pl pl-1">这百姓用嘴唇尊敬我，</span><br /><span className="pl pl-1">心却远离我；</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 29:13; 马可福音 7:7; 提摩太前书 1:4"> <span className="pl pl-1">他们将人的吩咐当作道理教导人，</span><br /><span className="pl pl-1">所以拜我也是枉然。」</span></span>
<span className="v" id="v10" data-v="10" data-xref="马可福音 7:14–15; 路加福音 20:45–47; 路加福音 24:45"> 耶稣就叫了众人来，对他们说：「你们要听，也要明白。</span>
<span className="v" id="v11" data-v="11" data-xref="马可福音 7:15; 马太福音 15:18–20; 雅各书 3:5–8"> 入口的不能污秽人，出口的乃能污秽人。」</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 22:13–14; 哥林多前书 10:32–33; 加拉太书 2:5"> 当时，门徒进前来对他说：「法利赛人听见这话，不服<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是跌倒">a</a></sup>，你知道吗？」</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 15:2; 以赛亚书 60:21; 约翰福音 15:6"> 耶稣回答说：「凡栽种的物，若不是我天父栽种的，必要拔出来。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 6:39; 以赛亚书 56:10; 马太福音 23:16–24"> 任凭他们吧！他们是瞎眼领路的；若是瞎子领瞎子，两个人都要掉在坑里。」</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 13:36; 马可福音 4:34; 约翰福音 16:29"> 彼得对耶稣说：「请将这比喻讲给我们听。」</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 16:9; 马可福音 7:18; 马可福音 9:32"> 耶稣说：「你们到如今还不明白吗？</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 6:45; 哥林多前书 6:13; 马太福音 7:19–20"> 岂不知凡入口的，是运到肚子里，又落在茅厕里吗？</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 15:28; 马太福音 12:34; 雅各书 3:6–10"> 惟独出口的，是从心里发出来的，这才污秽人。</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 7:21–23; 加拉太书 5:19–21; 耶利米书 17:9"> 因为从心里发出来的，有恶念、凶杀、奸淫、苟合、偷盗、妄证、谤 。</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 7:3–4; 以弗所书 5:3–6; 哥林多前书 6:18–20"> 这都是污秽人的；至于不洗手吃饭，那却不污秽人。」</span>
</div>
</div>

## 迦南妇人的信心

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马可福音 7:24–30; 马太福音 11:21–23; 士师记 1:31"> 耶稣离开那里，退到泰尔、西顿的境内去。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 9:27; 马可福音 7:25–26; 马太福音 17:15"> 有一个迦南妇人，从那地方出来，喊着说：「主啊，大卫的子孙，可怜我！我女儿被鬼附得甚苦。」</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 14:15; 马可福音 10:47–48; 耶利米哀歌 3:8"> 耶稣却一言不答。门徒进前来，求他说：「这妇人在我们后头喊叫，请打发她走吧。」</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 10:5–6; 罗马书 15:8; 耶利米书 50:6–7"> 耶稣说：「我奉差遣不过是到以色列家迷失的羊那里去。」</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 32:26; 马太福音 20:31; 马太福音 14:33"> 那妇人来拜他，说：「主啊，帮助我！」</span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 7:27–28; 马太福音 7:6; 腓立比书 3:2"> 他回答说：「不好拿儿女的饼丢给狗吃。」</span>
<span className="v" id="v27" data-v="27" data-xref="以弗所书 3:8; 路加福音 16:21; 约伯记 40:4–5"> 妇人说：「主啊，不错；但是狗也吃它主人桌子上掉下来的碎渣儿。」</span>
<span className="v" id="v28" data-v="28" data-xref="马可福音 9:23–24; 马太福音 8:13; 诗篇 145:19"> 耶稣说：「妇人，你的信心是大的！照你所要的，给你成全了吧。」从那时候，她女儿就好了。</span>
</div>
</div>

## 治好许多病人

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马太福音 4:18; 约翰福音 6:1; 马太福音 5:1"> 耶稣离开那地方，来到靠近加利利的海边，就上山坐下。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 6:17–19; 使徒行传 5:15–16; 马太福音 14:35–36"> 有许多人到他那里，带着瘸子、瞎子、哑巴、有残疾的，和好些别的病人，都放在他脚前；他就治好了他们。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 9:8; 路加福音 18:43; 路加福音 17:15–18"> 甚至众人都希奇；因为看见哑巴说话，残疾的痊愈，瘸子行走，瞎子看见，他们就归荣耀给以色列的 神。</span>
</div>
</div>

## 耶稣给四千人吃饱

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行传 27:33; 路加福音 12:29–30; 马太福音 9:36"> 耶稣叫门徒来，说：「我怜悯这众人；因为他们同我在这里已经三天，也没有吃的了。我不愿意叫他们饿着回去，恐怕在路上困乏。」</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 6:37; 马太福音 14:15; 马可福音 8:4–5"> 门徒说：「我们在这野地，哪里有这么多的饼叫这许多人吃饱呢？」</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 16:9–10; 路加福音 24:41–42; 约翰福音 21:9–10"> 耶稣说：「你们有多少饼？」他们说：「有七个，还有几条小鱼。」</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 9:14–16; 马可福音 6:39–40; 约翰福音 6:10"> 他就吩咐众人坐在地上，</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 22:19; 罗马书 14:6; 约翰福音 6:11"> 拿着这七个饼和几条鱼，祝谢了，擘开，递给门徒；门徒又递给众人。</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 8:19–21; 马太福音 16:9–10; 马太福音 15:33"> 众人都吃，并且吃饱了，收拾剩下的零碎，装满了七个筐子。</span>
<span className="v" id="v38" data-v="38"> 吃的人，除了妇女孩子，共有四千。</span>
<span className="v" id="v39" data-v="39" data-xref="马可福音 8:10; 马太福音 14:22"> 耶稣叫众人散去，就上船，来到马加丹的境界。</span>
</div>

## 光荣地进耶路撒冷

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="撒迦利亚书 14:4; 马可福音 11:1–10; 路加福音 21:37"> 耶稣和门徒将近耶路撒冷，到了伯法其，在橄榄山那里。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 19:30–32; 马可福音 11:2–3; 约翰福音 2:5–8"> 耶稣就打发两个门徒，对他们说：「你们往对面村子里去，必看见一匹驴拴在那里，还有驴驹同在一处；你们解开，牵到我这里来。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 8:1–2; 使徒行传 17:25; 哥林多后书 8:9"> 若有人对你们说什么，你们就说：『主要用它。』那人必立时让你们牵来。</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 9:9; 约翰福音 12:15; 马太福音 1:22"> 这事成就是要应验先知的话，说：</span>
<span className="v" id="v5" data-v="5" data-xref="撒迦利亚书 9:9–10; 以赛亚书 62:11; 以赛亚书 12:6"> 要对锡安的居民<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是女子">a</a></sup>说：<br /><span className="pl pl-1">看哪，你的王来到你这里，</span><br /><span className="pl pl-1">是温柔的，又骑着驴，</span><br /><span className="pl pl-1">就是骑着驴驹子。」</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 39:43; 约翰福音 15:14; 出埃及记 40:16"> 门徒就照耶稣所吩咐的去行，</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 9:13; 马可福音 11:4–8; 路加福音 19:32–35"> 牵了驴和驴驹来，把自己的衣服搭在上面，耶稣就骑上。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪下 9:13; 约翰福音 12:13; 利未记 23:40"> 众人多半把衣服铺在路上；还有人砍下树枝来铺在路上。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 118:24–26; 路加福音 2:14; 约翰福音 12:13–15"> 前行后随的众人喊着说：<br /><span className="pl pl-1">和散那</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原有求救的意思，在此是称颂的话">b</a></sup><br /><span className="pl pl-1">归于大卫的子孙！</span><br /><span className="pl pl-1">奉主名来的是应当称颂的！</span><br /><span className="pl pl-1">高高在上和散那！</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 9:5; 路得记 1:19; 约翰福音 12:16–19"> 耶稣既进了耶路撒冷，合城都惊动了，说：「这是谁？」</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 6:14; 路加福音 7:16; 约翰福音 7:40"> 众人说：「这是加利利拿撒勒的先知耶稣。」</span>
</div>
</div>

## 洁净圣殿

<div className="bt">
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="约翰福音 2:14–17; 路加福音 19:45–47; 马可福音 11:15–18"> 耶稣进了 神的殿，赶出殿里一切做买卖的人，推倒兑换银钱之人的桌子，和卖鸽子之人的凳子，</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 7:11; 以赛亚书 56:7; 路加福音 19:46"> 对他们说：「经上记着说：<br /><span className="pl pl-1">我的殿必称为祷告的殿，</span><br /><span className="pl pl-1">你们倒使它成为贼窝了。」</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="使徒行传 3:1–9; 使徒行传 10:38; 马太福音 11:4–5"> 在殿里有瞎子、瘸子到耶稣跟前，他就治好了他们。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 21:9; 路加福音 19:39–40; 以赛亚书 26:11"> 祭司长和文士看见耶稣所行的奇事，又见小孩子在殿里喊着说：「和散那归于大卫的子孙！」就甚恼怒，</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 8:2; 马太福音 11:25; 路加福音 19:39–40"> 对他说：「这些人所说的，你听见了吗？」耶稣说：「是的。经上说『你从婴孩和吃奶的口中完全了赞美』的话，你们没有念过吗？」</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 11:18; 马可福音 11:11; 路加福音 24:50"> 于是离开他们，出城到伯大尼去，在那里住宿。</span>
</div>
</div>

## 咒诅无花果树

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 4:2; 希伯来书 4:15; 马太福音 12:1"> 早晨回城的时候，他饿了，</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 15:6; 马可福音 11:14; 提多书 1:16"> 看见路旁有一棵无花果树，就走到跟前，在树上找不着什么，不过有叶子，就对树说：「从今以后，你永不结果子。」那无花果树就立刻枯干了。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 40:6–8; 马可福音 11:20–21; 雅各书 1:10–11"> 门徒看见了，便希奇说：「无花果树怎么立刻枯干了呢？」</span>
<span className="v" id="v21" data-v="21" data-xref="雅各书 1:6; 马太福音 17:20; 马可福音 11:22–23"> 耶稣回答说：「我实在告诉你们，你们若有信心，不疑惑，不但能行无花果树上所行的事，就是对这座山说：『你挪开此地，投在海里！』也必成就。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 7:7; 约翰一书 5:14–15; 马可福音 11:24"> 你们祷告，无论求什么，只要信，就必得着。」</span>
</div>
</div>

## 质问耶稣的权柄

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 4:7; 马可福音 11:27–33; 历代志上 24:1–19"> 耶稣进了殿，正教训人的时候，祭司长和民间的长老来问他说：「你仗着什么权柄做这些事？给你这权柄的是谁呢？」</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 6:9; 歌罗西书 4:6; 马太福音 10:16"> 耶稣回答说：「我也要问你们一句话，你们若告诉我，我就告诉你们我仗着什么权柄做这些事。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰一书 3:20; 马可福音 1:1–11; 约翰福音 3:18"> 约翰的洗礼是从哪里来的？是从天上来的？是从人间来的呢？」他们彼此商议说：「我们若说『从天上来』，他必对我们说：『这样，你们为什么不信他呢？』</span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 6:20; 马太福音 14:5; 约翰福音 5:35"> 若说『从人间来』，我们又怕百姓，因为他们都以约翰为先知。」</span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 1:18–22; 帖撒罗尼迦后书 2:9–10; 路加福音 20:7–8"> 于是回答耶稣说：「我们不知道。」耶稣说：「我也不告诉你们我仗着什么权柄做这些事。」</span>
</div>
</div>

## 两个儿子的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 15:58; 马太福音 20:1; 哥林多前书 10:15"> 又说：「一个人有两个儿子。他来对大儿子说：『我儿，你今天到葡萄园里去做工。』</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 18:28–32; 马太福音 3:2–8; 以赛亚书 55:6–7"> 他回答说：『我不去』，以后自己懊悔，就去了。</span>
<span className="v" id="v30" data-v="30" data-xref="提多书 1:16; 以西结书 33:31; 马太福音 23:3"> 又来对小儿子也是这样说。他回答说：『父啊，我去』，他却不去。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 7:29; 路加福音 7:37–50; 马太福音 7:21"> 你们想，这两个儿子是哪一个遵行父命呢？」他们说：「大儿子。」耶稣说：「我实在告诉你们，税吏和娼妓倒比你们先进 神的国。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 7:37–50; 撒迦利亚书 7:11–12; 路加福音 7:29–30"> 因为约翰遵着义路到你们这里来，你们却不信他；税吏和娼妓倒信他。你们看见了，后来还是不懊悔去信他。」</span>
</div>
</div>

## 凶恶园户的比喻

<div className="bt">
<div className="bp poetry">
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 5:1–4; 马可福音 12:1–12; 路加福音 20:9–19"> 「你们再听一个比喻：有个家主栽了一个葡萄园，周围圈上篱笆，里面挖了一个压酒池，盖了一座楼，租给园户，就往外国去了。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 20:10–19; 以赛亚书 5:4; 撒迦利亚书 1:3–6"> 收果子的时候近了，就打发仆人到园户那里去收果子。</span>
<span className="v" id="v35" data-v="35" data-xref="历代志下 36:15–16; 马太福音 5:12; 希伯来书 11:36–37"> 园户拿住仆人，打了一个，杀了一个，用石头打死一个。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 22:4"> 主人又打发别的仆人去，比先前更多；园户还是照样待他们。</span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 3:16; 约翰福音 3:35–36; 西番雅书 3:7"> 后来打发他的儿子到他们那里去，意思说：『他们必尊敬我的儿子。』</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 20:14; 创世记 37:18–20; 马可福音 12:7–8"> 不料，园户看见他儿子，就彼此说：『这是承受产业的。来吧，我们杀他，占他的产业！』</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 2:23; 雅各书 5:6; 路加福音 22:52–54"> 他们就拿住他，推出葡萄园外，杀了。</span>
<span className="v" id="v40" data-v="40" data-xref="希伯来书 10:29; 马可福音 12:9; 路加福音 20:15–16"> 园主来的时候要怎样处治这些园户呢？」</span>
<span className="v" id="v41" data-v="41" data-xref="使徒行传 18:6; 马太福音 21:43; 使徒行传 28:28"> 他们说：「要下毒手除灭那些恶人，将葡萄园另租给那按着时候交果子的园户。」</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 118:22–23; 以赛亚书 28:16; 使徒行传 4:11"> 耶稣说：「经上写着：<br /><span className="pl pl-1">匠人所弃的石头</span><br /><span className="pl pl-1">已作了房角的头块石头。</span><br /><span className="pl pl-1">这是主所做的，</span><br /><span className="pl pl-1">在我们眼中看为希奇。</span><br />这经你们没有念过吗？</span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 21:41; 马太福音 8:11–12; 彼得前书 2:9"> 所以我告诉你们， 神的国必从你们夺去，赐给那能结果子的百姓。</span>
<span className="v" id="v44" data-v="44" data-xref="以赛亚书 8:14–15; 彼得前书 2:8; 但以理书 2:34–35"> 谁掉在这石头上，必要跌碎；这石头掉在谁的身上，就要把谁砸得稀烂。」</span>
<span className="v" id="v45" data-v="45" data-xref="路加福音 20:19; 路加福音 11:45; 马太福音 12:12"> 祭司长和法利赛人听见他的比喻，就看出他是指着他们说的。</span>
<span className="v" id="v46" data-v="46" data-xref="马太福音 21:11; 马太福音 21:26; 路加福音 7:16"> 他们想要捉拿他，只是怕众人，因为众人以他为先知。</span>
</div>

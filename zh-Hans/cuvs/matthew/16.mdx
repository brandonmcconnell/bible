## 求主显个神迹

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 11:16; 马太福音 16:6; 使徒行传 4:1"> 法利赛人和撒都该人来试探耶稣，请他从天上显个神迹给他们看。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 12:54–56"> 耶稣回答说：「晚上天发红，你们就说：『天必要晴。』</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 12:56; 历代志上 12:32; 马太福音 11:5"> 早晨天发红，又发黑，你们就说：『今日必有风雨。』你们知道分辨天上的气色，倒不能分辨这时候的神迹。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 11:29–30; 马太福音 12:39–40; 约拿书 1:17"> 一个邪恶淫乱的世代求神迹，除了约拿的神迹以外，再没有神迹给他看。」耶稣就离开他们去了。</span>
</div>
</div>

## 防备法利赛人和撒都该人的酵

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马可福音 8:13–14; 马太福音 15:39"> 门徒渡到那边去，忘了带饼。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 12:1; 加拉太书 5:9; 马太福音 16:12"> 耶稣对他们说：「你们要谨慎，防备法利赛人和撒都该人的酵。」</span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 8:16–18; 马太福音 15:16–18; 使徒行传 10:14"> 门徒彼此议论说：「这是因为我们没有带饼吧。」</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 6:30; 马太福音 14:31; 马太福音 8:26"> 耶稣看出来，就说：「你们这小信的人，为什么因为没有饼彼此议论呢？</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 14:17–21; 约翰福音 6:9–13; 路加福音 9:13–17"> 你们还不明白吗？不记得那五个饼分给五千人、又收拾了多少篮子的零碎吗？</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 15:34–38; 马可福音 8:17–21; 马可福音 8:5–9"> 也不记得那七个饼分给四千人、又收拾了多少筐子的零碎吗？</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 16:6; 路加福音 12:56; 马可福音 8:21"> 我对你们说：『要防备法利赛人和撒都该人的酵』，这话不是指着饼说的，你们怎么不明白呢？」</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 5:20; 使徒行传 23:8; 马太福音 15:4–9"> 门徒这才晓得他说的不是叫他们防备饼的酵，乃是防备法利赛人和撒都该人的教训。</span>
</div>
</div>

## 彼得认耶稣为基督

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:18–20; 马可福音 8:27–29; 但以理书 7:13"> 耶稣到了凯撒利亚·腓立比的境内，就问门徒说：「人说我<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷没有我字">a</a></sup>—人子是谁？」</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 6:15; 马太福音 14:2; 玛拉基书 4:5"> 他们说：「有人说是施洗的约翰；有人说是以利亚；又有人说是耶利米或是先知里的一位。」</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 9:20; 马太福音 13:11; 马可福音 8:29"> 耶稣说：「你们说我是谁？」</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 14:33; 约翰福音 11:27; 约翰一书 4:15"> 西门·彼得回答说：「你是基督，是永生 神的儿子。」</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 6:45; 以弗所书 1:17–18; 马太福音 11:25–27"> 耶稣对他说：「西门·巴·约拿，你是有福的！因为这不是属血肉的指示你的，乃是我在天上的父指示的。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 2:19–22; 哥林多前书 3:9–11; 以赛亚书 28:16"> 我还告诉你，你是彼得，我要把我的教会建造在这磐石上；阴间的权柄<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="权柄：原文是门">b</a></sup>不能胜过他。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 18:18; 以赛亚书 22:22; 启示录 1:18"> 我要把天国的钥匙给你，凡你在地上所捆绑的，在天上也要捆绑；凡你在地上所释放的，在天上也要释放。」</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 8:30; 路加福音 9:21; 约翰福音 1:41"> 当下，耶稣嘱咐门徒，不可对人说他是基督。</span>
</div>
</div>

## 耶稣预言受难和复活

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 24:6–7; 马太福音 20:17–19; 马太福音 17:22–23"> 从此，耶稣才指示门徒，他必须上耶路撒冷去，受长老、祭司长、文士许多的苦，并且被杀，第三日复活。</span>
<span className="v" id="v22" data-v="22" data-xref="马可福音 8:32; 约翰福音 13:6–8; 马太福音 16:16–17"> 彼得就拉着他，劝他说：「主啊，万不可如此！这事必不临到你身上。」</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 8:5–8; 歌罗西书 3:2; 腓立比书 3:19"> 耶稣转过来，对彼得说：「撒但，退我后边去吧！你是绊我脚的；因为你不体贴 神的意思，只体贴人的意思。」</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 10:38; 路加福音 14:27; 彼得前书 4:1–2"> 于是耶稣对门徒说：「若有人要跟从我，就当舍己，背起他的十字架来跟从我。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 10:39; 马可福音 8:35; 启示录 12:11"> 因为，凡要救自己生命<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="生命：或译灵魂；下同">c</a></sup>的，必丧掉生命；凡为我丧掉生命的，必得着生命。</span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 8:36–37; 约伯记 27:8; 路加福音 9:25"> 人若赚得全世界，赔上自己的生命，有什么益处呢？人还能拿什么换生命呢？</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多后书 5:10; 诗篇 62:12; 罗马书 2:6"> 人子要在他父的荣耀里，同着众使者降临；那时候，他要照各人的行为报应各人。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 9:27; 马可福音 9:1; 约翰福音 8:52"> 我实在告诉你们，站在这里的，有人在没尝死味以前必看见人子降临在他的国里。」</span>
</div>
</div>

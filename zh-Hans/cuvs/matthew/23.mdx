## 谴责文士和法利赛人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:1; 路加福音 20:45–46; 马太福音 15:10–20"> 那时，耶稣对众人和门徒讲论，</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 20:46; 马可福音 12:38; 玛拉基书 2:7"> 说：「文士和法利赛人坐在摩西的位上，</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太后书 3:5; 提多书 1:16; 罗马书 2:19–24"> 凡他们所吩咐你们的，你们都要谨守遵行。但不要效法他们的行为；因为他们能说，不能行。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 11:46; 使徒行传 15:10; 加拉太书 6:13"> 他们把难担的重担捆起来，搁在人的肩上，但自己一个指头也不肯动。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 6:1–16; 约翰福音 12:43; 腓立比书 2:3"> 他们一切所做的事都是要叫人看见，所以将佩戴的经文做宽了，衣裳的 子做长了，</span>
<span className="v" id="v6" data-v="6" data-xref="约翰三书 1:9; 路加福音 11:43–54; 马可福音 12:38–39"> 喜爱筵席上的首座，会堂里的高位，</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 1:38; 约翰福音 1:49; 约翰福音 3:26"> 又喜爱人在街市上问他安，称呼他拉比<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="拉比就是夫子">a</a></sup>。</span>
<span className="v" id="v8" data-v="8" data-xref="雅各书 3:1; 哥林多前书 1:12–13; 彼得前书 5:3"> 但你们不要受拉比的称呼，因为只有一位是你们的夫子；你们都是弟兄。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 3:1; 希伯来书 12:9; 玛拉基书 1:6"> 也不要称呼地上的人为父，因为只有一位是你们的父，就是在天上的父。</span>
<span className="v" id="v10" data-v="10"> 也不要受师尊的称呼，因为只有一位是你们的师尊，就是基督。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 9:19; 加拉太书 5:13; 约翰福音 13:14–15"> 你们中间谁为大，谁就要作你们的用人。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 5:5; 雅各书 4:6; 箴言 29:23"> 凡自高的，必降为卑；自卑的，必升为高。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 11:52; 马太福音 23:29; 马太福音 23:23"> 「你们这假冒为善的文士和法利赛人有祸了！因为你们正当人前，把天国的门关了，自己不进去，正要进去的人，你们也不容他们进去。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷加： 14你们这假冒为善的文士和法利赛人有祸了！因为你们侵吞寡妇的家产，假意做很长的祷告，所以要受更重的刑罚。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以弗所书 2:3; 使徒行传 13:10; 使徒行传 13:43"> 「你们这假冒为善的文士和法利赛人有祸了！因为你们走遍洋海陆地，勾引一个人入教，既入了教，却使他作地狱之子，比你们还加倍。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马太福音 15:14; 马太福音 5:33–35; 雅各书 5:12"> 「你们这瞎眼领路的有祸了！你们说：『凡指着殿起誓的，这算不得什么；只是凡指着殿中金子起誓的，他就该谨守。』</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 23:19; 民数记 16:38–39; 诗篇 94:8"> 你们这无知瞎眼的人哪，什么是大的？是金子呢？还是叫金子成圣的殿呢？</span>
<span className="v" id="v18" data-v="18"> 你们又说：『凡指着坛起誓的，这算不得什么；只是凡指着坛上礼物起誓的，他就该谨守。』</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 29:37; 出埃及记 30:29"> 你们这瞎眼的人哪，什么是大的？是礼物呢？还是叫礼物成圣的坛呢？</span>
<span className="v" id="v20" data-v="20"> 所以，人指着坛起誓，就是指着坛和坛上一切所有的起誓；</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 26:8; 列王纪上 8:13; 历代志下 6:2"> 人指着殿起誓，就是指着殿和那住在殿里的起誓；</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 5:34; 诗篇 11:4; 以赛亚书 66:1"> 人指着天起誓，就是指着 神的宝座和那坐在上面的起誓。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 11:42; 弥迦书 6:8; 何西阿书 6:6"> 「你们这假冒为善的文士和法利赛人有祸了！因为你们将薄荷、茴香、芹菜献上十分之一，那律法上更重的事，就是公义、怜悯、信实，反倒不行了。这更重的是你们当行的；那也是不可不行的。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 19:24; 马太福音 27:6–8; 马太福音 15:2–6"> 你们这瞎眼领路的，蠓虫你们就滤出来，骆驼你们倒吞下去。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 11:39–40; 马太福音 15:19–20; 马可福音 7:4–13"> 「你们这假冒为善的文士和法利赛人有祸了！因为你们洗净杯盘的外面，里面却盛满了勒索和放荡。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多后书 7:1; 雅各书 4:8; 希伯来书 10:22"> 你这瞎眼的法利赛人，先洗净杯盘的里面，好叫外面也干净了。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 11:44; 使徒行传 23:3; 民数记 19:16"> 「你们这假冒为善的文士和法利赛人有祸了！因为你们好像粉饰的坟墓，外面好看，里面却装满了死人的骨头和一切的污秽。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 16:15; 诗篇 51:6; 马太福音 23:5"> 你们也是如此，在人前，外面显出公义来，里面却装满了假善和不法的事。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 11:47–48; 使徒行传 2:29"> 「你们这假冒为善的文士和法利赛人有祸了！因为你们建造先知的坟，修饰义人的墓，说：</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 2:30; 马太福音 23:34–35; 马太福音 21:35–36"> 『若是我们在我们祖宗的时候，必不和他们同流先知的血。』</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 7:51–52; 帖撒罗尼迦前书 2:15–16; 约书亚记 24:22"> 这就是你们自己证明是杀害先知者的子孙了。</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 15:16; 民数记 32:14; 帖撒罗尼迦前书 2:16"> 你们去充满你们祖宗的恶贯吧！</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 3:7; 马太福音 12:34; 马太福音 5:22"> 你们这些蛇类、毒蛇之种啊，怎能逃脱地狱的刑罚呢？</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 10:16–17; 马太福音 13:52; 歌罗西书 1:28"> 所以我差遣先知和智慧人并文士到你们这里来，有的你们要杀害，要钉十字架；有的你们要在会堂里鞭打，从这城追逼到那城，</span>
<span className="v" id="v35" data-v="35" data-xref="历代志下 24:20–22; 撒迦利亚书 1:1; 希伯来书 11:4"> 叫世上所流义人的血都归到你们身上，从义人亚伯的血起，直到你们在殿和坛中间所杀的巴拉加的儿子撒迦利亚的血为止。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 10:23; 马太福音 24:34; 马可福音 13:30–31"> 我实在告诉你们，这一切的罪都要归到这世代了。」</span>
</div>
</div>

## 为耶路撒冷哀哭

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 13:34–35; 路得记 2:12; 诗篇 91:4"> 「耶路撒冷啊，耶路撒冷啊，你常杀害先知，又用石头打死那奉差遣到你这里来的人。我多次愿意聚集你的儿女，好像母鸡把小鸡聚集在翅膀底下，只是你们不愿意。</span>
<span className="v" id="v38" data-v="38" data-xref="耶利米书 22:5; 路加福音 13:35; 路加福音 21:24"> 看哪，你们的家成为荒场留给你们。</span>
<span className="v" id="v39" data-v="39" data-xref="诗篇 118:26; 马太福音 21:9; 罗马书 11:25"> 我告诉你们，从今以后，你们不得再见我，直等到你们说：『奉主名来的是应当称颂的。』」</span>
</div>

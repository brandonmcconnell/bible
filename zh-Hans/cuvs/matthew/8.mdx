## 洁净长大麻风的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 8:18; 马太福音 4:25–1; 路加福音 5:15"> 耶稣下了山，有许多人跟着他。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 15:25; 路加福音 17:12–19; 马太福音 18:26"> 有一个长大麻风的来拜他，说：「主若肯，必能叫我洁净了。」</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 5:13; 诗篇 33:9; 列王纪下 5:14"> 耶稣伸手摸他，说：「我肯，你洁净了吧！」他的大麻风立刻就洁净了。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 14:2–32; 路加福音 5:14; 路加福音 17:14"> 耶稣对他说：「你切不可告诉人，只要去把身体给祭司察看，献上摩西所吩咐的礼物，对众人作证据。」</span>
</div>
</div>

## 治好百夫长的仆人

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="路加福音 7:1–10; 使徒行传 27:43; 使徒行传 10:1–33"> 耶稣进了迦百农，有一个百夫长进前来，求他说：</span>
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 4:1; 马太福音 4:24; 使徒行传 9:33"> 「主啊，我的仆人害瘫痪病，躺在家里，甚是疼苦。」</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 9:18–19; 路加福音 7:6; 马可福音 5:23–24"> 耶稣说：「我去医治他。」</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 107:20; 路加福音 7:6–7; 诗篇 33:9"> 百夫长回答说：「主啊，你到我舍下，我不敢当；只要你说一句话，我的仆人就必好了。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 4:35–36; 提多书 2:9; 歌罗西书 3:22"> 因为我在人的权下，也有兵在我以下；对这个说『去！』他就去；对那个说『来！』他就来；对我的仆人说：『你做这事！』他就去做。」</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 15:28; 路加福音 7:9; 马可福音 6:6"> 耶稣听见就希奇，对跟从的人说：「我实在告诉你们，这么大的信心，就是在以色列中，我也没有遇见过。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 13:28–29; 以弗所书 3:6; 加拉太书 3:28–29"> 我又告诉你们，从东从西，将有许多人来，在天国里与亚伯拉罕、以撒、雅各一同坐席；</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 25:30; 路加福音 13:28; 马太福音 21:43"> 惟有本国的子民竟被赶到外边黑暗里去，在那里必要哀哭切齿了。」</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 9:29–30; 马可福音 9:23; 约翰福音 4:50"> 耶稣对百夫长说：「你回去吧！照你的信心，给你成全了。」那时，他的仆人就好了。</span>
</div>
</div>

## 治好许多病人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="路加福音 4:38–41; 马可福音 1:29–34; 哥林多前书 9:5"> 耶稣到了彼得家里，见彼得的岳母害热病躺着。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 13:21; 路加福音 4:38–39; 路加福音 8:54"> 耶稣把她的手一摸，热就退了；她就起来服事耶稣。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 15:26; 马太福音 14:14; 马可福音 1:32–34"> 到了晚上，有人带着许多被鬼附的来到耶稣跟前，他只用一句话就把鬼都赶出去，并且治好了一切有病的人。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 53:4; 彼得前书 2:24; 马太福音 1:22"> 这是要应验先知以赛亚的话，说：<br /><span className="pl pl-1">他代替我们的软弱，</span><br /><span className="pl pl-1">担当我们的疾病。</span></span>
</div>
</div>

## 要跟从耶稣的人

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 4:42–43; 路加福音 8:22; 马可福音 4:35"> 耶稣见许多人围着他，就吩咐渡到那边去。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 22:33–34; 约翰福音 13:36–38; 路加福音 14:25–27"> 有一个文士来，对他说：「夫子，你无论往哪里去，我要跟从你。」</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 84:3; 路加福音 2:7; 以赛亚书 53:2–3"> 耶稣说：「狐狸有洞，天空的飞鸟有窝，人子却没有枕头的地方。」</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 9:59–62; 利未记 21:11–12; 民数记 6:6–7"> 又有一个门徒对耶稣说：「主啊，容我先回去埋葬我的父亲。」</span>
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 2:13; 路加福音 15:32; 以弗所书 5:14"> 耶稣说：「任凭死人埋葬他们的死人；你跟从我吧！」</span>
</div>
</div>

## 平静风和海

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 8:22–25; 马可福音 4:36–41; 马太福音 9:1"> 耶稣上了船，门徒跟着他。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 8:23; 诗篇 107:23–27; 马可福音 4:37–38"> 海里忽然起了暴风，甚至船被波浪掩盖；耶稣却睡着了。</span>
<span className="v" id="v25" data-v="25" data-xref="约拿书 1:6; 历代志下 14:11; 马可福音 4:38–39"> 门徒来叫醒了他，说：「主啊，救我们，我们丧命啦！」</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 41:10–14; 诗篇 65:7; 诗篇 107:28–30"> 耶稣说：「你们这小信的人哪，为什么胆怯呢？」于是起来，斥责风和海，风和海就大大地平静了。</span>
<span className="v" id="v27" data-v="27" data-xref="马可福音 7:37; 马可福音 6:51; 马太福音 14:33"> 众人希奇，说：「这是怎样的人？连风和海也听从他了！」</span>
</div>
</div>

## 治好加大拉被鬼附的人

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 8:26–39; 马可福音 5:1–20; 使徒行传 10:38"> 耶稣既渡到那边去，来到加大拉人的地方，就有两个被鬼附的人从坟茔里出来迎着他，极其凶猛，甚至没有人能从那条路上经过。</span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 1:24; 路加福音 4:34; 雅各书 2:19"> 他们喊着说：「 神的儿子，我们与你有什么相干？时候还没有到，你就上这里来叫我们受苦吗？」</span>
<span className="v" id="v30" data-v="30" data-xref="申命记 14:8; 利未记 11:7; 马可福音 5:11"> 离他们很远，有一大群猪吃食。</span>
<span className="v" id="v31" data-v="31" data-xref="启示录 20:1–2; 路加福音 8:30–33; 马可福音 5:12"> 鬼就央求耶稣，说：「若把我们赶出去，就打发我们进入猪群吧！」</span>
<span className="v" id="v32" data-v="32" data-xref="马可福音 5:13; 使徒行传 2:23; 启示录 20:7"> 耶稣说：「去吧！」鬼就出来，进入猪群。全群忽然闯下山崖，投在海里淹死了。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 8:34–36; 马可福音 5:14–16; 使徒行传 19:15–17"> 放猪的就逃跑进城，将这一切事和被鬼附的人所遭遇的都告诉人。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 16:39; 路加福音 8:37–39; 路加福音 5:8"> 合城的人都出来迎见耶稣，既见了就央求他离开他们的境界。</span>
</div>
</div>

<div className="bt">
<div className="bp">

## 论祷告

<div className="bt">
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="路加福音 18:10–11; 马太福音 6:2; 路加福音 18:13"> 「你们祷告的时候，不可像那假冒为善的人，爱站在会堂里和十字路口上祷告，故意叫人看见。我实在告诉你们，他们已经得了他们的赏赐。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 4:33; 马太福音 14:23; 以赛亚书 65:24"> 你祷告的时候，要进你的内屋，关上门，祷告你在暗中的父；你父在暗中察看，必然报答你。</span>
<span className="v" id="v7" data-v="7" data-xref="传道书 5:2–3; 传道书 5:7; 列王纪上 18:26–29"> 你们祷告，不可像外邦人，用许多重复话，他们以为话多了必蒙垂听。</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 6:32; 路加福音 12:30; 腓立比书 4:6"> 你们不可效法他们；因为你们没有祈求以先，你们所需用的，你们的父早已知道了。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 11:1–4; 启示录 4:11; 罗马书 8:15"> 所以，你们祷告要这样说：<br /><span className="pl pl-1">我们在天上的父：</span><br /><span className="pl pl-1">愿人都尊你的名为圣。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 10:36; 马太福音 26:42; 马太福音 12:50"> <span className="pl pl-1">愿你的国降临；</span><br /><span className="pl pl-1">愿你的旨意行在地上，</span><br /><span className="pl pl-1">如同行在天上。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 30:8; 路加福音 11:3; 马太福音 4:4"> <span className="pl pl-1">我们日用的饮食，今日赐给我们。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 4:32; 马可福音 11:25; 以弗所书 1:7"> <span className="pl pl-1">免我们的债，</span><br /><span className="pl pl-1">如同我们免了人的债。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 10:13; 启示录 7:14–17; 马太福音 26:41"> <span className="pl pl-1">不叫我们遇见试探；</span><br /><span className="pl pl-1">救我们脱离凶恶</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：脱离恶者">b</a></sup><br /><span className="pl pl-1">。</span><br /><span className="pl pl-1">因为国度、权柄、荣耀，全是你的，</span><br /><span className="pl pl-1">直到永远。阿们</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古卷没有因为…阿们等字">c</a></sup><br /><span className="pl pl-1">！</span></span>
<span className="v" id="v14" data-v="14" data-xref="以弗所书 4:32; 马可福音 11:25; 歌罗西书 3:13"> 「你们饶恕人的过犯，你们的天父也必饶恕你们的过犯；</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 18:35"> 你们不饶恕人的过犯，你们的天父也必不饶恕你们的过犯。」</span>
</div>
</div>

## 论禁食

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 58:3–5; 马太福音 9:14–15; 但以理书 9:3"> 「你们禁食的时候，不可像那假冒为善的人，脸上带着愁容；因为他们把脸弄得难看，故意叫人看出他们是禁食。我实在告诉你们，他们已经得了他们的赏赐。</span>
<span className="v" id="v17" data-v="17" data-xref="路得记 3:3; 传道书 9:8; 撒母耳记下 12:20"> 你禁食的时候，要梳头洗脸，</span>

<div className="bp">

## 不要忧虑

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="腓立比书 4:6; 彼得前书 5:7; 罗马书 8:32"> 「所以我告诉你们，不要为生命忧虑吃什么，喝什么；为身体忧虑穿什么。生命不胜于饮食吗？身体不胜于衣裳吗？</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 10:29–31; 诗篇 147:9; 路加福音 12:24–32"> 你们看那天上的飞鸟，也不种，也不收，也不积蓄在仓里，你们的天父尚且养活它。你们不比飞鸟贵重得多吗？</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 12:25–26; 传道书 3:14; 诗篇 39:5–6"> 你们哪一个能用思虑使寿数多加一刻呢<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="或译：使身量多加一肘呢">e</a></sup>？</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 6:25; 腓立比书 4:6; 路加福音 12:27"> 何必为衣裳忧虑呢？你想野地里的百合花怎么长起来；它也不劳苦，也不纺线。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志下 9:20–22; 历代志下 9:4–6; 彼得前书 3:2–5"> 然而我告诉你们，就是所罗门极荣华的时候，他所穿戴的，还不如这花一朵呢！</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 14:31; 路加福音 12:28; 彼得前书 1:24"> 你们这小信的人哪！野地里的草今天还在，明天就丢在炉里， 神还给它这样的妆饰，何况你们呢！</span>
<span className="v" id="v31" data-v="31" data-xref="彼得前书 5:7; 路加福音 12:29; 马太福音 4:4"> 所以，不要忧虑说，吃什么？喝什么？穿什么？</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 6:8; 路加福音 12:30; 以弗所书 4:17"> 这都是外邦人所求的。你们需用的这一切东西，你们的天父是知道的。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 12:31; 马太福音 5:6; 约翰福音 6:27"> 你们要先求他的国和他的义，这些东西都要加给你们了。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 6:25; 约翰福音 14:27; 希伯来书 13:5–6"> 所以，不要为明天忧虑，因为明天自有明天的忧虑；一天的难处一天当就够了。」</span>
</div>

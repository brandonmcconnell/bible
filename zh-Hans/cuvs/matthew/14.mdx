## 施洗约翰的死

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 3:1; 马可福音 8:15; 路加福音 9:7–9"> 那时，分封的王希律听见耶稣的名声，</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 16:14; 约翰福音 10:41; 马可福音 8:28"> 就对臣仆说：「这是施洗的约翰从死里复活，所以这些异能从他里面发出来。」</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 6:17; 路加福音 3:19–20; 马太福音 4:12"> 起先，希律为他兄弟腓力的妻子希罗底的缘故，把约翰拿住，锁在监里。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 20:21; 利未记 18:16; 马可福音 6:18"> 因为约翰曾对他说：「你娶这妇人是不合理的。」</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 21:26; 马太福音 11:9; 马可福音 6:19–20"> 希律就想要杀他，只是怕百姓，因为他们以约翰为先知。</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 6:21–23; 创世记 40:20; 何西阿书 1:5–6"> 到了希律的生日，希罗底的女儿在众人面前跳舞，使希律欢喜。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯帖记 5:3; 以斯帖记 5:6; 以斯帖记 7:2"> 希律就起誓，应许随她所求的给她。</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 6:24; 箴言 29:10; 箴言 1:16"> 女儿被母亲所使，就说：「请把施洗约翰的头放在盘子里，拿来给我。」</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 19:12–16; 撒母耳记上 14:28; 马可福音 6:26"> 王便忧愁，但因他所起的誓，又因同席的人，就吩咐给她；</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 17:12; 马太福音 21:35–36; 路加福音 9:9"> 于是打发人去，在监里斩了约翰，</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 16:6; 创世记 49:7; 以西结书 16:3–4"> 把头放在盘子里，拿来给了女子；女子拿去给她母亲。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 8:2; 马太福音 27:58–61"> 约翰的门徒来，把尸首领去埋葬了，就去告诉耶稣。</span>
</div>
</div>

## 耶稣给五千人吃饱

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:10–17; 马太福音 14:1–2; 马可福音 6:30–44"> 耶稣听见了，就上船从那里独自退到野地里去。众人听见，就从各城里步行跟随他。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 4:15; 马太福音 9:36; 希伯来书 2:17"> 耶稣出来，见有许多的人，就怜悯他们，治好了他们的病人。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 15:23; 马可福音 8:3; 马可福音 6:35–36"> 天将晚的时候，门徒进前来，说：「这是野地，时候已经过了，请叫众人散开，他们好往村子里去，自己买吃的。」</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 4:42–44; 哥林多后书 8:2–3; 传道书 11:2"> 耶稣说：「不用他们去，你们给他们吃吧！」</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 15:33–34; 马可福音 6:37–38; 路加福音 9:13"> 门徒说：「我们这里只有五个饼，两条鱼。」</span>
<span className="v" id="v18" data-v="18"> 耶稣说：「拿过来给我。」</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 8:6–7; 路加福音 24:30; 撒母耳记上 9:13"> 于是吩咐众人坐在草地上，就拿着这五个饼，两条鱼，望着天祝福，擘开饼，递给门徒，门徒又递给众人。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 16:12; 马可福音 6:42–44; 马太福音 16:8–10"> 他们都吃，并且吃饱了，把剩下的零碎收拾起来，装满了十二个篮子。</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比书 4:19; 哥林多后书 9:8–11; 使徒行传 4:4"> 吃的人，除了妇女孩子，约有五千。</span>
</div>
</div>

## 耶稣在海面上行走

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马可福音 6:45–51; 约翰福音 6:15–21; 马太福音 15:39"> 耶稣随即催门徒上船，先渡到那边去，等他叫众人散开。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 6:12; 马可福音 6:46; 马太福音 26:36"> 散了众人以后，他就独自上山去祷告。到了晚上，只有他一人在那里。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 6:18; 马可福音 6:48; 马太福音 8:24"> 那时船在海中，因风不顺，被浪摇撼。</span>
<span className="v" id="v25" data-v="25" data-xref="约伯记 9:8; 约翰福音 6:19; 马可福音 6:48"> 夜里四更天，耶稣在海面上走，往门徒那里去。</span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 6:49–50; 启示录 1:17; 路加福音 1:11–12"> 门徒看见他在海面上走，就惊慌了，说：「是个鬼怪！」便害怕，喊叫起来。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 23:11; 启示录 1:17–18; 约翰福音 16:33"> 耶稣连忙对他们说：「你们放心，是我，不要怕！」</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 6:68; 罗马书 12:3; 马太福音 26:33–35"> 彼得说：「主，如果是你，请叫我从水面上走到你那里去。」</span>
<span className="v" id="v29" data-v="29" data-xref="腓立比书 4:13; 马可福音 9:23; 使徒行传 3:16"> 耶稣说：「你来吧。」彼得就从船上下去，在水面上走，要到耶稣那里去；</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米哀歌 3:54–57; 提摩太后书 4:16–17; 马可福音 14:38"> 只因见风甚大，就害怕，将要沉下去，便喊着说：「主啊，救我！」</span>
<span className="v" id="v31" data-v="31" data-xref="雅各书 1:6–8; 诗篇 138:7; 创世记 22:14"> 耶稣赶紧伸手拉住他，说：「你这小信的人哪，为什么疑惑呢？」</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 107:29–30; 马可福音 4:41; 约翰福音 6:21"> 他们上了船，风就住了。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 11:27; 诗篇 2:7; 罗马书 1:4"> 在船上的人都拜他，说：「你真是 神的儿子了。」</span>
</div>
</div>

## 治好革尼撒勒的病人

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马可福音 6:53–56; 路加福音 5:1; 约翰福音 6:24–25"> 他们过了海，来到革尼撒勒地方。</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 4:24–25; 马可福音 6:55; 马可福音 1:28–34"> 那里的人一认出是耶稣，就打发人到周围地方去，把所有的病人带到他那里，</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 6:19; 马可福音 3:10; 出埃及记 28:33–43"> 只求耶稣准他们摸他的衣裳 子；摸着的人就都好了。</span>
</div>

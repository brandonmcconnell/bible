## 博士朝拜

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="弥迦书 5:2; 约翰福音 7:42; 路加福音 2:4–7"> 当希律王的时候，耶稣生在犹太的伯利恒。有几个博士从东方来到耶路撒冷，说：</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 24:17; 耶利米书 23:5; 启示录 22:16"> 「那生下来作犹太人之王的在哪里？我们在东方看见他的星，特来拜他。」</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 17:6–7; 约翰福音 11:47–48; 马太福音 23:37"> 希律王听见了，就心里不安；耶路撒冷合城的人也都不安。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 21:23; 马太福音 7:29; 使徒行传 6:12"> 他就召齐了祭司长和民间的文士，问他们说：「基督当生在何处？」</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 7:42; 路得记 1:1; 撒母耳记上 16:1"> 他们回答说：「在犹太的伯利恒。因为有先知记着，说：</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 34:23–25; 弥迦书 5:2; 以赛亚书 9:6–7"> 犹大地的伯利恒啊，<br /><span className="pl pl-1">你在犹大诸城中并不是最小的；</span><br /><span className="pl pl-1">因为将来有一位君王要从你那里出来，</span><br /><span className="pl pl-1">牧养我以色列民。」</span></span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 1:10; 撒母耳记上 18:21; 诗篇 55:21"> 当下，希律暗暗地召了博士来，细问那星是什么时候出现的，</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 3:19–20; 耶利米书 41:5–7; 路加福音 20:20–21"> 就差他们往伯利恒去，说：「你们去仔细寻访那小孩子，寻到了就来报信，我也好去拜他。」</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 2:2; 箴言 8:17; 诗篇 25:12"> 他们听见王的话就去了。在东方所看见的那星忽然在他们前头行，直行到小孩子的地方，就在上头停住了。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 105:3; 路加福音 2:20; 路加福音 2:10"> 他们看见那星，就大大地欢喜；</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 60:6; 诗篇 72:10; 路加福音 2:16"> 进了房子，看见小孩子和他母亲马利亚，就俯伏拜那小孩子，揭开宝盒，拿黄金、乳香、没药为礼物献给他。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 2:22; 马太福音 2:19; 马太福音 2:13"> 博士因为在梦中被主指示不要回去见希律，就从别的路回本地去了。</span>
</div>
</div>

## 逃往埃及

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 10:7; 使徒行传 5:19; 马太福音 1:20"> 他们去后，有主的使者向约瑟梦中显现，说：「起来！带着小孩子同他母亲逃往埃及，住在那里，等我吩咐你；因为希律必寻找小孩子，要除灭他。」</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 2:20–21; 使徒行传 26:21; 马太福音 1:24"> 约瑟就起来，夜间带着小孩子和他母亲往埃及去，</span>
<span className="v" id="v15" data-v="15" data-xref="何西阿书 11:1; 出埃及记 4:22; 民数记 24:8"> 住在那里，直到希律死了。这是要应验主借先知所说的话，说：「我从埃及召出我的儿子来。」</span>
</div>
</div>

## 屠杀男孩

<div className="bt">
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 59:7; 箴言 28:15; 士师记 16:10"> 希律见自己被博士愚弄，就大大发怒，差人将伯利恒城里并四境所有的男孩，照着他向博士仔细查问的时候，凡两岁以里的，都杀尽了。</span>
<span className="v" id="v17" data-v="17"> 这就应了先知耶利米的话，说：</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 31:15; 耶利米书 9:17–21; 耶利米书 4:31"> 在拉玛听见号咷大哭的声音，<br /><span className="pl pl-1">是拉结哭她儿女，</span><br /><span className="pl pl-1">不肯受安慰，</span><br /><span className="pl pl-1">因为他们都不在了。</span></span>
</div>
</div>

## 从埃及回来

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马太福音 1:20; 但以理书 8:25; 马太福音 2:12–13"> 希律死了以后，有主的使者在埃及向约瑟梦中显现，说：</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 4:19; 列王纪上 12:1–3; 马太福音 2:13"> 「起来！带着小孩子和他母亲往以色列地去，因为要害小孩子性命的人已经死了。」</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 11:8; 创世记 6:22"> 约瑟就起来，把小孩子和他母亲带到以色列地去；</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 48:17–18; 路加福音 2:39; 约翰福音 7:52"> 只因听见亚基老接着他父亲希律作了犹太王，就怕往那里去，又在梦中被主指示，便往加利利境内去了，</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 13:5; 约翰福音 1:45–46; 马可福音 1:24"> 到了一座城，名叫拿撒勒，就住在那里。这是要应验先知所说，他将称为拿撒勒人的话了。</span>
</div>
</div>

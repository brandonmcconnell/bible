<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 15:1; 约翰福音 18:28; 弥迦书 2:1"> 到了早晨，众祭司长和民间的长老大家商议要治死耶稣，</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 20:19; 使徒行传 3:13; 提摩太前书 6:13"> 就把他捆绑，解去，交给巡抚彼拉多。</span>

## 犹大的死

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 7:10; 路加福音 22:47–48; 约伯记 20:15–29"> 这时候，卖耶稣的犹大看见耶稣已经定了罪，就后悔，把那三十块钱拿回来给祭司长和长老，说：</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 15:30; 提多书 1:16; 使徒行传 18:15–17"> 「我卖了无辜之人的血是有罪了。」他们说：「那与我们有什么相干？你自己承当吧！」</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 1:18–19; 撒母耳记下 17:23; 列王纪上 16:18"> 犹大就把那银钱丢在殿里，出去吊死了。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 6:7–9; 申命记 23:18; 以赛亚书 61:8"> 祭司长拾起银钱来，说：「这是血价，不可放在库里。」</span>
<span className="v" id="v7" data-v="7"> 他们商议，就用那银钱买了窑户的一块田，为要埋葬外乡人。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 1:19; 马太福音 28:15; 约书亚记 4:9"> 所以那块田直到今日还叫做「血田」。</span>
<span className="v" id="v9" data-v="9" data-xref="撒迦利亚书 11:12–13; 马太福音 1:22; 利未记 27:2–7"> 这就应了先知耶利米的话，说：「他们用那三十块钱，就是被估定之人的价钱，是以色列人中所估定的，</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亚书 11:13"> 买了窑户的一块田；这是照着主所吩咐我的。」</span>
</div>
</div>

## 耶稣在彼拉多面前受审

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路加福音 23:2–3; 马可福音 15:2–5; 马太福音 26:25"> 耶稣站在巡抚面前；巡抚问他说：「你是犹太人的王吗？」耶稣说：「你说的是。」</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 26:63; 以赛亚书 53:7; 马太福音 27:14"> 他被祭司长和长老控告的时候，什么都不回答。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 26:62; 约翰福音 18:35; 使徒行传 22:24"> 彼拉多就对他说：「他们作见证告你这么多的事，你没有听见吗？」</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 8:18; 诗篇 71:7; 哥林多前书 4:9"> 耶稣仍不回答，连一句话也不说，以致巡抚甚觉希奇。</span>
</div>
</div>

## 耶稣被判死刑

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 18:38–40; 路加福音 23:16; 约翰福音 19:16"> 巡抚有一个常例，每逢这节期，随众人所要的释放一个囚犯给他们。</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 15:7; 使徒行传 3:14; 路加福音 23:25"> 当时有一个出名的囚犯叫巴拉巴。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 19:15; 列王纪上 18:21; 马可福音 15:9–12"> 众人聚集的时候，彼拉多就对他们说：「你们要我释放哪一个给你们？是巴拉巴呢？是称为基督的耶稣呢？」</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 27:4; 使徒行传 5:17; 马可福音 15:10"> 巡抚原知道他们是因为嫉妒才把他解了来。</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 9:9; 箴言 29:1; 马太福音 27:24"> 正坐堂的时候，他的夫人打发人来说：「这义人的事，你一点不可管，因为我今天在梦中为他受了许多的苦。」</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 3:14–15; 约翰福音 19:15–16; 约翰福音 18:40"> 祭司长和长老挑唆众人，求释放巴拉巴，除灭耶稣。</span>
<span className="v" id="v21" data-v="21"> 巡抚对众人说：「这两个人，你们要我释放哪一个给你们呢？」他们说：「巴拉巴。」</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 53:2–3; 以赛亚书 49:7; 使徒行传 13:38"> 彼拉多说：「这样，那称为基督的耶稣我怎么办他呢？」他们都说：「把他钉十字架！」</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 37:18–19; 使徒行传 7:57; 使徒行传 23:12–15"> 巡抚说：「为什么呢？他做了什么恶事呢？」他们便极力地喊着说：「把他钉十字架！」</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 27:4; 诗篇 26:6; 哥林多后书 5:21"> 彼拉多见说也无济于事，反要生乱，就拿水在众人面前洗手，说：「流这义人的血，罪不在我，你们承当吧。」</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 2:19; 使徒行传 5:28; 使徒行传 7:52"> 众人都回答说：「他的血归到我们和我们的子孙身上。」</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 53:5; 约翰福音 19:1; 马可福音 15:15"> 于是彼拉多释放巴拉巴给他们，把耶稣鞭打了，交给人钉十字架。</span>
</div>
</div>

## 兵丁戏弄耶稣

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约翰福音 18:28; 约翰福音 18:33; 使徒行传 10:1"> 巡抚的兵就把耶稣带进衙门，叫全营的兵都聚集在他那里。</span>
<span className="v" id="v28" data-v="28" data-xref="马可福音 15:17; 约翰福音 19:2–5; 路加福音 23:11"> 他们给他脱了衣服，穿上一件朱红色袍子，</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 53:3; 马太福音 20:19; 诗篇 69:19–20"> 用荆棘编做冠冕，戴在他头上，拿一根苇子放在他右手里，跪在他面前，戏弄他，说：「恭喜，犹太人的王啊！」</span>
<span className="v" id="v30" data-v="30" data-xref="以赛亚书 50:6; 马太福音 26:67; 以赛亚书 53:7"> 又吐唾沫在他脸上，拿苇子打他的头。</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 53:7; 列王纪上 21:13; 列王纪上 21:10"> 戏弄完了，就给他脱了袍子，仍穿上他自己的衣服，带他出去，要钉十字架。</span>
</div>
</div>

## 耶稣被钉十字架

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马可福音 15:21; 马太福音 16:24; 路加福音 23:26"> 他们出来的时候，遇见一个古利奈人，名叫西门，就勉强他同去，好背着耶稣的十字架。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 19:17–19; 马可福音 15:22–32; 马可福音 15:34"> 到了一个地方名叫各各他，意思就是「髑髅地」。</span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 69:21; 马可福音 15:23; 马太福音 27:48"> 兵丁拿苦胆调和的酒给耶稣喝；他尝了，就不肯喝。</span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 22:18; 马可福音 15:24–32; 路加福音 23:34"> 他们既将他钉在十字架上，就拈阄分他的衣服，</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 27:54; 马可福音 15:44; 马可福音 15:39"> 又坐在那里看守他。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 23:38; 约翰福音 19:19–22; 马可福音 15:26"> 在他头以上安一个牌子，写着他的罪状，说：「这是犹太人的王耶稣。」</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 19:18; 路加福音 23:39–43; 以赛亚书 53:12"> 当时，有两个强盗和他同钉十字架，一个在右边，一个在左边。</span>
<span className="v" id="v39" data-v="39" data-xref="诗篇 109:25; 耶利米哀歌 1:12; 诗篇 69:7–12"> 从那里经过的人讥诮他，摇着头，说：</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 26:61; 马太福音 4:6; 马太福音 4:3"> 「你这拆毁圣殿、三日又建造起来的，可以救自己吧！你如果是 神的儿子，就从十字架上下来吧！」</span>
<span className="v" id="v41" data-v="41" data-xref="诗篇 35:26; 以赛亚书 28:22; 诗篇 22:12–13"> 祭司长和文士并长老也是这样戏弄他，说：</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 1:49; 马太福音 27:37; 使徒行传 4:14"> 「他救了别人，不能救自己。他是以色列的王，现在可以从十字架上下来，我们就信他。</span>
<span className="v" id="v43" data-v="43" data-xref="诗篇 22:8; 约翰福音 10:36; 以赛亚书 37:10"> 他倚靠 神， 神若喜悦他，现在可以救他；因为他曾说：『我是 神的儿子。』」</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 27:38; 马可福音 15:32; 路加福音 23:39–43"> 那和他同钉的强盗也是这样地讥诮他。</span>
</div>
</div>

## 耶稣的死

<div className="bt">
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="阿摩司书 8:9; 马可福音 15:33–34; 路加福音 23:44–45"> 从午正到申初，遍地都黑暗了。</span>
<span className="v" id="v46" data-v="46" data-xref="诗篇 22:1; 希伯来书 5:7; 以赛亚书 53:10"> 约在申初，耶稣大声喊着说：「以利！以利！拉马撒巴各大尼？」就是说：「我的 神！我的 神！为什么离弃我？」</span>
<span className="v" id="v47" data-v="47" data-xref="玛拉基书 4:5; 马可福音 15:35–36; 马太福音 11:14"> 站在那里的人，有的听见就说：「这个人呼叫以利亚呢！」</span>
<span className="v" id="v48" data-v="48" data-xref="诗篇 69:21; 马太福音 27:34; 路加福音 23:36"> 内中有一个人赶紧跑去，拿海绒蘸满了醋，绑在苇子上，送给他喝。</span>
<span className="v" id="v49" data-v="49"> 其余的人说：「且等着，看以利亚来救他不来。」</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 19:30; 以赛亚书 53:9–12; 诗篇 22:14–15"> 耶稣又大声喊叫，气就断了。</span>
<span className="v" id="v51" data-v="51" data-xref="希伯来书 10:19–22; 马可福音 15:38; 希伯来书 6:19"> 忽然，殿里的幔子从上到下裂为两半，地也震动，磐石也崩裂，</span>
<span className="v" id="v52" data-v="52" data-xref="以赛亚书 26:19; 帖撒罗尼迦前书 4:14; 哥林多前书 15:20"> 坟墓也开了，已睡圣徒的身体多有起来的。</span>
<span className="v" id="v53" data-v="53" data-xref="启示录 11:2; 以赛亚书 48:2; 启示录 21:2"> 到耶稣复活以后，他们从坟墓里出来，进了圣城，向许多人显现。</span>
<span className="v" id="v54" data-v="54" data-xref="马太福音 27:36; 马可福音 15:39; 马太福音 27:43"> 百夫长和一同看守耶稣的人看见地震并所经历的事，就极其害怕，说：「这真是 神的儿子了！」</span>
<span className="v" id="v55" data-v="55" data-xref="路加福音 8:2–3; 路加福音 23:48–49; 约翰福音 19:25–27"> 有好些妇女在那里，远远地观看；她们是从加利利跟随耶稣来服事他的。</span>
<span className="v" id="v56" data-v="56" data-xref="约翰福音 19:25; 马可福音 15:47–1; 马太福音 28:1"> 内中有抹大拉的马利亚，又有雅各和约西的母亲马利亚，并有西庇太两个儿子的母亲。</span>
</div>
</div>

## 耶稣的安葬

<div className="bt">
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="约翰福音 19:38–42; 马可福音 15:42–47; 路加福音 23:50–56"> 到了晚上，有一个财主，名叫约瑟，是亚利马太来的，他也是耶稣的门徒。</span>
<span className="v" id="v58" data-v="58" data-xref="路加福音 23:52–53; 马可福音 15:44–46"> 这人去见彼拉多，求耶稣的身体；彼拉多就吩咐给他。</span>
<span className="v" id="v59" data-v="59"> 约瑟取了身体，用干净细麻布裹好，</span>
<span className="v" id="v60" data-v="60" data-xref="以赛亚书 53:9; 马太福音 28:2; 马太福音 27:66"> 安放在自己的新坟墓里，就是他凿在磐石里的。他又把大石头滚到墓门口，就去了。</span>
<span className="v" id="v61" data-v="61" data-xref="马太福音 28:1; 马太福音 27:56"> 有抹大拉的马利亚和那个马利亚在那里，对着坟墓坐着。</span>
</div>
</div>

## 封石妥守

<div className="bt">
<div className="bp">
<span className="v" id="v62" data-v="62" data-xref="马可福音 15:42; 约翰福音 19:14; 约翰福音 19:42"> 次日，就是预备日的第二天，祭司长和法利赛人聚集来见彼拉多，说：</span>
<span className="v" id="v63" data-v="63" data-xref="路加福音 9:22; 马太福音 16:21; 约翰福音 2:19"> 「大人，我们记得那诱惑人的还活着的时候曾说：『三日后我要复活。』</span>
<span className="v" id="v64" data-v="64" data-xref="马太福音 28:13; 马太福音 12:45"> 因此，请吩咐人将坟墓把守妥当，直到第三日，恐怕他的门徒来，把他偷了去，就告诉百姓说：『他从死里复活了。』这样，那后来的迷惑比先前的更利害了！」</span>
<span className="v" id="v65" data-v="65" data-xref="马太福音 27:66; 马太福音 28:11–15; 箴言 21:30"> 彼拉多说：「你们有看守的兵，去吧！尽你们所能的把守妥当。」</span>
<span className="v" id="v66" data-v="66" data-xref="但以理书 6:17; 马太福音 27:60; 提摩太后书 2:19"> 他们就带着看守的兵同去，封了石头，将坟墓把守妥当。</span>
</div>
</div>

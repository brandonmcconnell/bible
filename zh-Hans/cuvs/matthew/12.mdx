## 安息日的问题

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 23:25; 马可福音 2:23–28; 路加福音 6:1–5"> 那时，耶稣在安息日从麦地经过。他的门徒饿了，就掐起麦穗来吃。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 12:10; 约翰福音 7:21–24; 路加福音 14:3"> 法利赛人看见，就对耶稣说：「看哪，你的门徒做安息日不可做的事了！」</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 21:3–6; 路加福音 6:3; 马可福音 2:25–26"> 耶稣对他们说：「经上记着大卫和跟从他的人饥饿之时所做的事，你们没有念过吗？</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 24:5–9; 出埃及记 25:30; 利未记 8:31"> 他怎么进了 神的殿，吃了陈设饼，这饼不是他和跟从他的人可以吃得，惟独祭司才可以吃。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 28:9–10; 约翰福音 7:22–23; 尼希米记 13:17"> 再者，律法上所记的，当安息日，祭司在殿里犯了安息日还是没有罪，你们没有念过吗？</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 12:41–42; 历代志下 6:18; 彼得前书 2:4–5"> 但我告诉你们，在这里有一人比殿更大。</span>
<span className="v" id="v7" data-v="7" data-xref="何西阿书 6:6; 马太福音 9:13; 弥迦书 6:6–8"> 『我喜爱怜恤，不喜爱祭祀。』你们若明白这话的意思，就不将无罪的当作有罪的了。</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 2:28; 路加福音 6:5; 约翰福音 5:17–23"> 因为人子是安息日的主。」</span>
</div>
</div>

## 治好枯干了一只手的人

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马可福音 3:1–6; 路加福音 6:6–11"> 耶稣离开那地方，进了一个会堂。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 13:14; 约翰福音 9:16; 约翰福音 8:6"> 那里有一个人枯干了一只手。有人问耶稣说：「安息日治病可以不可以？」意思是要控告他。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 22:4; 路加福音 14:5; 路加福音 13:15–17"> 耶稣说：「你们中间谁有一只羊，当安息日掉在坑里，不把它抓住、拉上来呢？</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 6:26; 路加福音 6:9; 马可福音 3:4"> 人比羊何等贵重呢！所以，在安息日做善事是可以的。」</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 13:13; 使徒行传 3:7–8"> 于是对那人说：「伸出手来！」他把手一伸，手就复了原，和那只手一样。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 11:53; 约翰福音 10:39; 马可福音 3:6"> 法利赛人出去，商议怎样可以除灭耶稣。</span>
</div>
</div>

## 神所拣选的仆人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="马可福音 3:7–12; 马太福音 10:23; 马太福音 19:2"> 耶稣知道了，就离开那里，有许多人跟着他。他把其中有病的人都治好了；</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 8:4; 马太福音 9:30; 马太福音 17:9"> 又嘱咐他们，不要给他传名。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 42:1–4; 以赛亚书 42:9; 马太福音 13:35"> 这是要应验先知以赛亚的话，说：</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 42:1; 路加福音 4:18; 使徒行传 10:38"> <span className="pl pl-1">看哪！我的仆人，</span><br /><span className="pl pl-1">我所拣选、所亲爱、心里所喜悦的，</span><br /><span className="pl pl-1">我要将我的灵赐给他；</span><br /><span className="pl pl-1">他必将公理传给外邦。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 11:29; 约翰福音 18:36–38; 提摩太后书 2:24–25"> <span className="pl pl-1">他不争竞，不喧嚷；</span><br /><span className="pl pl-1">街上也没有人听见他的声音。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 42:3–4; 以西结书 34:16; 以赛亚书 61:1–3"> <span className="pl pl-1">压伤的芦苇，他不折断；</span><br /><span className="pl pl-1">将残的灯火，他不吹灭；</span><br /><span className="pl pl-1">等他施行公理，叫公理得胜。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 11:10; 罗马书 15:12–13; 以赛亚书 42:4"> <span className="pl pl-1">外邦人都要仰望他的名。</span></span>
</div>
</div>

## 耶稣和别西卜

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 11:14–15; 马可福音 7:35–37; 以赛亚书 29:18"> 当下，有人将一个被鬼附着、又瞎又哑的人带到耶稣那里，耶稣就医治他，甚至那哑巴又能说话，又能看见。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 9:27; 约翰福音 4:29; 马太福音 22:42–43"> 众人都惊奇，说：「这不是大卫的子孙吗？」</span>
<span className="v" id="v24" data-v="24" data-xref="马可福音 3:22; 马太福音 9:34; 路加福音 11:15"> 但法利赛人听见，就说：「这个人赶鬼，无非是靠着鬼王别西卜啊。」</span>
<span className="v" id="v25" data-v="25" data-xref="加拉太书 5:15; 耶利米书 17:10; 马太福音 9:4"> 耶稣知道他们的意念，就对他们说：「凡一国自相纷争，就成为荒场；一城一家自相纷争，必站立不住；</span>
<span className="v" id="v26" data-v="26" data-xref="歌罗西书 1:13; 启示录 20:2–3; 约翰一书 5:19"> 若撒但赶逐撒但，就是自相纷争，他的国怎能站得住呢？</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 19:13–16; 马可福音 9:38–39; 路加福音 9:49–50"> 我若靠着别西卜赶鬼，你们的子弟赶鬼又靠着谁呢？这样，他们就要断定你们的是非。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 11:20; 但以理书 7:14; 马太福音 6:33"> 我若靠着 神的灵赶鬼，这就是 神的国临到你们了。</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 49:24; 马可福音 3:27; 路加福音 11:21–22"> 人怎能进壮士家里，抢夺他的家具呢？除非先捆住那壮士，才可以抢夺他的家财。</span>
<span className="v" id="v30" data-v="30" data-xref="马可福音 9:40; 路加福音 11:23; 约书亚记 24:15"> 不与我相合的，就是敌我的；不同我收聚的，就是分散的。」</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 12:10; 马可福音 3:28–30; 希伯来书 10:29"> 所以我告诉你们：「人一切的罪和亵渎的话都可得赦免，惟独亵渎圣灵，总不得赦免。</span>
<span className="v" id="v32" data-v="32" data-xref="马可福音 3:29; 希伯来书 10:26–29; 希伯来书 6:4–6"> 凡说话干犯人子的，还可得赦免；惟独说话干犯圣灵的，今世来世总不得赦免。」</span>
</div>
</div>

## 树和果子

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 6:43–44; 马太福音 7:16–20; 雅各书 4:8"> 「你们或以为树好，果子也好；树坏，果子也坏；因为看果子就可以知道树。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 6:45; 马太福音 15:18; 以弗所书 4:29"> 毒蛇的种类！你们既是恶人，怎能说出好话来呢？因为心里所充满的，口里就说出来。</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 15:4; 歌罗西书 4:6; 箴言 15:28"> 善人从他心里所存的善就发出善来；恶人从他心里所存的恶就发出恶来。</span>
<span className="v" id="v36" data-v="36" data-xref="传道书 12:14; 罗马书 2:16; 启示录 20:12"> 我又告诉你们，凡人所说的闲话，当审判的日子，必要句句供出来；</span>
<span className="v" id="v37" data-v="37" data-xref="箴言 13:3; 雅各书 2:21–25"> 因为要凭你的话定你为义，也要凭你的话定你有罪。」</span>
</div>
</div>

## 要求神迹

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="哥林多前书 1:22; 马可福音 8:11–12; 路加福音 11:16"> 当时，有几个文士和法利赛人对耶稣说：「夫子，我们愿意你显个神迹给我们看。」</span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 16:4; 路加福音 11:29–32; 马可福音 8:38"> 耶稣回答说：「一个邪恶淫乱的世代求看神迹，除了先知约拿的神迹以外，再没有神迹给他们看。</span>
<span className="v" id="v40" data-v="40" data-xref="约拿书 1:17; 马太福音 27:63–64; 马太福音 16:21"> 约拿三日三夜在大鱼肚腹中，人子也要这样三日三夜在地里头。</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 12:42; 希伯来书 11:7; 马太福音 12:6"> 当审判的时候，尼尼微人要起来定这世代的罪，因为尼尼微人听了约拿所传的就悔改了。看哪，在这里有一人比约拿更大！</span>
<span className="v" id="v42" data-v="42" data-xref="列王纪上 10:1–13; 历代志下 9:1–12; 希伯来书 1:2–4"> 当审判的时候，南方的女王要起来定这世代的罪；因为她从地极而来，要听所罗门的智慧话。看哪，在这里有一人比所罗门更大！」</span>
</div>
</div>

## 污鬼回来

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="路加福音 11:24–26; 路加福音 8:28–32; 马太福音 8:29"> 「污鬼离了人身，就在无水之地过来过去，寻求安歇之处，却寻不着。</span>
<span className="v" id="v44" data-v="44" data-xref="约翰一书 4:4; 启示录 13:8–9; 犹大书 1:4–5"> 于是说：『我要回到我所出来的屋里去。』到了，就看见里面空闲，打扫干净，修饰好了，</span>
<span className="v" id="v45" data-v="45" data-xref="路加福音 11:26; 马可福音 5:9; 希伯来书 6:4–8"> 便去另带了七个比自己更恶的鬼来，都进去住在那里。那人末后的景况比先前更不好了。这邪恶的世代也要如此。」</span>
</div>
</div>

## 耶稣的母亲和兄弟们

<div className="bt">
<div className="bp">

<span className="v" id="v47" data-v="47"> 有人告诉他说：「看哪，你母亲和你弟兄站在外边，要与你说话。」</span>
<span className="v" id="v48" data-v="48" data-xref="马可福音 3:32–33; 马太福音 10:37; 路加福音 2:52"> 他却回答那人说：「谁是我的母亲？谁是我的弟兄？」</span>
<span className="v" id="v49" data-v="49" data-xref="马可福音 3:34; 约翰福音 17:8–9; 约翰福音 20:17–20"> 就伸手指着门徒，说：「看哪，我的母亲，我的弟兄。</span>
<span className="v" id="v50" data-v="50" data-xref="路加福音 8:21; 马可福音 3:35; 约翰福音 15:14"> 凡遵行我天父旨意的人，就是我的弟兄姊妹和母亲了。」</span>

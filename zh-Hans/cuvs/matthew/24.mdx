<div className="bp">

## 灾难的起头

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马可福音 13:3–4; 使徒行传 1:7; 帖撒罗尼迦前书 5:1–11"> 耶稣在橄榄山上坐着，门徒暗暗地来说：「请告诉我们，什么时候有这些事？你降临和世界的末了有什么预兆呢？」</span>
<span className="v" id="v4" data-v="4" data-xref="约翰一书 4:1; 耶利米书 29:8; 帖撒罗尼迦后书 2:3"> 耶稣回答说：「你们要谨慎，免得有人迷惑你们。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 24:11; 马太福音 24:24; 耶利米书 14:14"> 因为将来有好些人冒我的名来，说：『我是基督』，并且要迷惑许多人。</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 13:7–8; 路加福音 21:9; 彼得前书 3:14–15"> 你们也要听见打仗和打仗的风声，总不要惊慌；因为这些事是必须有的，只是末期还没有到。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 21:11; 启示录 6:8; 以赛亚书 19:2"> 民要攻打民，国要攻打国；多处必有饥荒、地震。</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦前书 5:3; 彼得前书 4:17–18; 申命记 28:59"> 这都是灾难<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="灾难：原文是生产之难">a</a></sup>的起头。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 16:2; 约翰福音 15:19–20; 路加福音 21:16–17"> 那时，人要把你们陷在患难里，也要杀害你们；你们又要为我的名被万民恨恶。</span>
<span className="v" id="v10" data-v="10" data-xref="弥迦书 7:5–6; 路加福音 21:16; 马太福音 11:6"> 那时，必有许多人跌倒，也要彼此陷害，彼此恨恶；</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 24:24; 马太福音 7:15; 马太福音 24:5"> 且有好些假先知起来，迷惑多人。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 2:4–5; 雅各书 4:1–4; 启示录 3:15"> 只因不法的事增多，许多人的爱心才渐渐冷淡了。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 10:22; 马可福音 13:13; 启示录 2:10"> 惟有忍耐到底的，必然得救。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 14:6; 罗马书 10:18; 罗马书 16:25–26"> 这天国的福音要传遍天下，对万民作见证，然后末期才来到。」</span>
</div>
</div>

## 大灾难

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理书 9:27; 但以理书 12:11; 马可福音 13:14"> 「你们看见先知但以理所说的『那行毁坏可憎的』站在圣地（读这经的人须要会意）。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 19:15–17; 路加福音 21:21–22; 希伯来书 11:7"> 那时，在犹太的，应当逃到山上；</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 17:31–33; 马可福音 13:15–16; 马太福音 10:27"> 在房上的，不要下来拿家里的东西；</span>
<span className="v" id="v18" data-v="18"> 在田里的，也不要回去取衣裳。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 23:29–30; 申命记 28:53–56; 路加福音 21:23"> 当那些日子，怀孕的和奶孩子的有祸了。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 16:29; 使徒行传 1:12"> 你们应当祈求，叫你们逃走的时候，不遇见冬天或是安息日。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理书 12:1; 约珥书 2:2; 玛拉基书 4:1"> 因为那时必有大灾难，从世界的起头直到如今，没有这样的灾难，后来也必没有。</span>
<span className="v" id="v22" data-v="22" data-xref="马可福音 13:20; 提摩太后书 2:10; 马太福音 24:31"> 若不减少那日子，凡有血气的总没有一个得救的；只是为选民，那日子必减少了。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 21:8; 路加福音 17:23–24; 申命记 13:1–3"> 那时，若有人对你们说：『基督在这里』，或说：『基督在那里』，你们不要信！</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦后书 2:9–11; 马可福音 13:22; 启示录 13:13–14"> 因为假基督、假先知将要起来，显大神迹、大奇事，倘若能行，连选民也就迷惑了。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 16:1; 路加福音 21:13; 以赛亚书 48:5–6"> 看哪，我预先告诉你们了。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 3:2–3; 以赛亚书 40:3; 马太福音 3:1"> 若有人对你们说：『看哪，基督在旷野里』，你们不要出去！或说：『看哪，基督在内屋中』，你们不要信！</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 17:24–37; 撒迦利亚书 9:14; 约伯记 37:3"> 闪电从东边发出，直照到西边。人子降临也要这样。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 17:37; 约伯记 39:27–30; 申命记 28:49"> 尸首在哪里，鹰也必聚在那里。」</span>
</div>
</div>

<div className="bt">
<div className="bp poetry">
<span className="v" id="v29" data-v="29" data-xref="阿摩司书 8:9; 约珥书 3:15; 以赛亚书 13:10"> 「那些日子的灾难一过去，<br /><span className="pl pl-1">日头就变黑了，</span><br /><span className="pl pl-1">月亮也不放光，</span><br /><span className="pl pl-1">众星要从天上坠落，</span><br /><span className="pl pl-1">天势都要震动。</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="启示录 1:7; 但以理书 7:13; 路加福音 21:27"> 那时，人子的兆头要显在天上，地上的万族都要哀哭。他们要看见人子，有能力，有大荣耀，驾着天上的云降临。</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒罗尼迦前书 4:16; 马可福音 13:27; 以赛亚书 27:13"> 他要差遣使者，用号筒的大声，将他的选民，从四方<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="方：原文是风">b</a></sup>，从天这边到天那边，都招聚了来。」</span>
</div>
</div>

## 从无花果树学个比方

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马可福音 13:28–29; 路加福音 21:29–30"> 「你们可以从无花果树学个比方：当树枝发嫩长叶的时候，你们就知道夏天近了。</span>
<span className="v" id="v33" data-v="33" data-xref="雅各书 5:9; 希伯来书 10:37; 以西结书 7:2–14"> 这样，你们看见这一切的事，也该知道人子近了，正在门口了。</span>
<span className="v" id="v34" data-v="34" data-xref="马可福音 13:30–31; 路加福音 21:32–33; 马太福音 16:28"> 我实在告诉你们，这世代还没有过去，这些事都要成就。</span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 40:8; 彼得前书 1:25; 民数记 23:19"> 天地要废去，我的话却不能废去。」</span>
</div>
</div>

## 那日那时没有人知道

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="马可福音 13:32; 使徒行传 1:7; 马太福音 24:44"> 「但那日子，那时辰，没有人知道，连天上的使者也不知道，子也不知道，惟独父知道。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 17:26–27; 创世记 6:1–7; 彼得后书 2:5"> 挪亚的日子怎样，人子降临也要怎样。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 17:26–28; 罗马书 13:13–14; 路加福音 14:18–20"> 当洪水以前的日子，人照常吃喝嫁娶，直到挪亚进方舟的那日；</span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 3:20; 马太福音 24:37; 使徒行传 13:41"> 不知不觉洪水来了，把他们全都冲去。人子降临也要这样。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 17:34–37; 彼得后书 2:7–9; 彼得后书 2:5"> 那时，两个人在田里，取去一个，撇下一个。</span>
<span className="v" id="v41" data-v="41" data-xref="出埃及记 11:5; 以赛亚书 47:2; 路加福音 17:35"> 两个女人推磨，取去一个，撇下一个。</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 21:36; 帖撒罗尼迦前书 5:6; 马太福音 25:13"> 所以，你们要警醒，因为不知道你们的主是哪一天来到。</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 12:39; 马太福音 24:44; 帖撒罗尼迦前书 5:2–6"> 家主若知道几更天有贼来，就必警醒，不容人挖透房屋；这是你们所知道的。</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 25:10; 马太福音 24:42; 马太福音 25:13"> 所以，你们也要预备，因为你们想不到的时候，人子就来了。」</span>
</div>
</div>

## 忠心和不忠心的仆人

<div className="bt">
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="马太福音 25:21; 马太福音 25:23; 哥林多前书 4:1–2"> 「谁是忠心有见识的仆人，为主人所派，管理家里的人，按时分粮给他们呢？</span>
<span className="v" id="v46" data-v="46" data-xref="启示录 16:15; 路加福音 12:43; 路加福音 12:37"> 主人来到，看见他这样行，那仆人就有福了。</span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 25:23; 马太福音 25:21; 路加福音 12:37"> 我实在告诉你们，主人要派他管理一切所有的。</span>
<span className="v" id="v48" data-v="48" data-xref="马太福音 18:32; 以赛亚书 32:6; 路加福音 12:45"> 倘若那恶仆心里说：『我的主人必来得迟』，</span>
<span className="v" id="v49" data-v="49" data-xref="启示录 17:6; 启示录 16:6; 弥迦书 3:5"> 就动手打他的同伴，又和酒醉的人一同吃喝。</span>
<span className="v" id="v50" data-v="50" data-xref="帖撒罗尼迦前书 5:2–3; 启示录 3:3; 马太福音 24:42–44"> 在想不到的日子，不知道的时辰，那仆人的主人要来，</span>
<span className="v" id="v51" data-v="51" data-xref="马太福音 8:12; 马太福音 22:13; 路加福音 12:46"> 重重地处治他<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或译：把他腰斩了">c</a></sup>，定他和假冒为善的人同罪；在那里必要哀哭切齿了。」</span>
</div>

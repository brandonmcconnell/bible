## 喜筵的比喻

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 20:1–16; 马太福音 12:43–45; 路加福音 14:16"> 耶稣又用比喻对他们说：</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 19:7–9; 马太福音 13:24; 以弗所书 5:24–32"> 「天国好比一个王为他儿子摆设娶亲的筵席，</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 22:17; 约翰福音 5:40; 路加福音 14:15–17"> 就打发仆人去，请那些被召的人来赴席，他们却不肯来。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 13:46; 马太福音 21:36; 约翰福音 6:50–57"> 王又打发别的仆人，说：『你们告诉那被召的人，我的筵席已经预备好了，牛和肥畜已经宰了，各样都齐备，请你们来赴席。』</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 2:3; 路加福音 14:18–20; 约翰一书 2:15–16"> 那些人不理就走了；一个到自己田里去；一个做买卖去；</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 15:19–20; 约翰福音 16:2–3; 使徒行传 7:51–57"> 其余的拿住仆人，凌辱他们，把他们杀了。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 19:27; 彼得前书 4:17–18; 路加福音 21:24"> 王就大怒，发兵除灭那些凶手，烧毁他们的城。</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦后书 1:5; 使徒行传 13:46; 启示录 3:4"> 于是对仆人说：『喜筵已经齐备，只是所召的人不配。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 14:21–24; 箴言 1:20–23; 马可福音 16:15–16"> 所以你们要往岔路口上去，凡遇见的，都召来赴席。』</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 6:9–11; 启示录 19:6–9; 哥林多后书 12:21"> 那些仆人就出去，到大路上，凡遇见的，不论善恶都召聚了来，筵席上就坐满了客。</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 3:4–5; 启示录 19:8; 希伯来书 4:12–13"> 王进来观看宾客，见那里有一个没有穿礼服的，</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 2:9; 约伯记 5:16; 马太福音 20:13"> 就对他说：『朋友，你到这里来怎么不穿礼服呢？』那人无言可答。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 8:12; 马太福音 25:30; 马太福音 24:51"> 于是王对使唤的人说：『捆起他的手脚来，把他丢在外边的黑暗里；在那里必要哀哭切齿了。』</span>
<span className="v" id="v14" data-v="14" data-xref="彼得后书 1:10; 路加福音 13:23–24; 马太福音 7:13–14"> 因为被召的人多，选上的人少。」</span>
</div>
</div>

## 纳税给凯撒的问题

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 20:20–26; 马可福音 12:13–17; 诗篇 2:2"> 当时，法利赛人出去商议，怎样就着耶稣的话陷害他，</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 3:6; 马可福音 8:15; 马可福音 12:14"> 就打发他们的门徒同希律党的人去见耶稣，说：「夫子，我们知道你是诚实人，并且诚诚实实传 神的道，什么人你都不徇情面，因为你不看人的外貌。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 2:1; 罗马书 13:6–7; 马太福音 17:25"> 请告诉我们，你的意见如何？纳税给凯撒可以不可以？」</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 8:6; 路加福音 5:22; 约翰福音 2:25"> 耶稣看出他们的恶意，就说：「假冒为善的人哪，为什么试探我？</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 20:2; 启示录 6:6; 马太福音 18:28"> 拿一个上税的钱给我看！」他们就拿一个银钱来给他。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 20:24"> 耶稣说：「这像和这号是谁的？」</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 13:7; 箴言 24:21; 使徒行传 4:19"> 他们说：「是凯撒的。」耶稣说：「这样，凯撒的物当归给凯撒； 神的物当归给 神。」</span>
<span className="v" id="v22" data-v="22" data-xref="马可福音 12:12; 马太福音 22:46; 路加福音 20:25–26"> 他们听见就希奇，离开他走了。</span>
</div>
</div>

## 复活的问题

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 4:1; 马可福音 12:18–27; 使徒行传 23:6–8"> 撒都该人常说没有复活的事。那天，他们来问耶稣说：</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 25:5–10; 路加福音 20:28; 路得记 1:11"> 「夫子，摩西说：『人若死了，没有孩子，他兄弟当娶他的妻，为哥哥生子立后。』</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 20:29–33; 马可福音 12:19–23; 希伯来书 9:27"> 从前，在我们这里有弟兄七人，第一个娶了妻，死了，没有孩子，撇下妻子给兄弟。</span>
<span className="v" id="v26" data-v="26"> 第二、第三，直到第七个，都是如此。</span>
<span className="v" id="v27" data-v="27"> 末后，妇人也死了。</span>
<span className="v" id="v28" data-v="28"> 这样，当复活的时候，她是七个人中哪一个的妻子呢？因为他们都娶过她。」</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 20:9; 罗马书 15:4; 路加福音 1:37"> 耶稣回答说：「你们错了；因为不明白圣经，也不晓得 神的大能。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 20:34–36; 马可福音 12:24–25; 马太福音 24:38"> 当复活的时候，人也不娶也不嫁，乃像天上的使者一样。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 12:3; 马太福音 21:16; 马太福音 21:42"> 论到死人复活， 神在经上向你们所说的，你们没有念过吗？</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 3:6; 马可福音 12:26–27; 路加福音 20:37–38"> 他说：『我是亚伯拉罕的 神，以撒的 神，雅各的 神。』 神不是死人的 神，乃是活人的 神。」</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 12:17; 马可福音 6:2; 约翰福音 7:46"> 众人听见这话，就希奇他的教训。</span>
</div>
</div>

## 最大的诫命

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马可福音 12:28–31; 马太福音 25:3–5; 马太福音 12:14"> 法利赛人听见耶稣堵住了撒都该人的口，他们就聚集。</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 7:30; 路加福音 10:25–37; 路加福音 11:52"> 内中有一个人是律法师，要试探耶稣，就问他说：</span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 12:28–33; 马太福音 5:19–20; 路加福音 11:42"> 「夫子，律法上的诫命，哪一条是最大的呢？」</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 12:29–30; 路加福音 10:27; 申命记 6:5"> 耶稣对他说：「你要尽心、尽性、尽意爱主—你的 神。</span>
<span className="v" id="v38" data-v="38"> 这是诫命中的第一，且是最大的。</span>
<span className="v" id="v39" data-v="39" data-xref="马可福音 12:31; 路加福音 10:27–37; 利未记 19:18"> 其次也相仿，就是要爱人如己。</span>
<span className="v" id="v40" data-v="40" data-xref="罗马书 13:9; 马太福音 7:12; 约翰一书 4:19–21"> 这两条诫命是律法和先知一切道理的总纲。」</span>
</div>
</div>

## 大卫子孙的问题

<div className="bt">
<div className="bp poetry">
<span className="v" id="v41" data-v="41" data-xref="路加福音 20:41–44; 马可福音 12:35–37; 马太福音 22:34"> 法利赛人聚集的时候，耶稣问他们说：</span>
<span className="v" id="v42" data-v="42" data-xref="耶利米书 23:5–6; 约翰福音 6:68–69; 马太福音 16:13–17"> 「论到基督，你们的意见如何？他是谁的子孙呢？」他们回答说：「是大卫的子孙。」</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳记下 23:2; 启示录 4:2; 马可福音 12:36"> 耶稣说：「这样，大卫被圣灵感动，怎么还称他为主，说：</span>
<span className="v" id="v44" data-v="44" data-xref="诗篇 110:1; 希伯来书 1:13; 使徒行传 2:34–35"> 主对我主说：<br /><span className="pl pl-1">你坐在我的右边，</span><br /><span className="pl pl-1">等我把你仇敌放在你的脚下。</span></span>
<span className="v" id="v45" data-v="45" data-xref="罗马书 1:3–4; 启示录 22:16; 约翰福音 8:58"> 大卫既称他为主，他怎么又是大卫的子孙呢？」</span>
<span className="v" id="v46" data-v="46" data-xref="马可福音 12:34; 路加福音 20:40; 路加福音 14:6"> 他们没有一个人能回答一言。从那日以后，也没有人敢再问他什么。</span>
</div>

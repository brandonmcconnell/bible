## 施洗约翰的门徒来见耶稣

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="马可福音 6:17; 马太福音 14:3; 马太福音 9:14"> 约翰在监里听见基督所做的事，就打发两个门徒去，</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 11:27; 玛拉基书 3:1; 申命记 18:15–18"> 问他说：「那将要来的是你吗？还是我们等候别人呢？」</span>
<span className="v" id="v4" data-v="4"> 耶稣回答说：「你们去，把所听见、所看见的事告诉约翰。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 35:4–6; 以赛亚书 61:1–3; 路加福音 4:18"> 就是瞎子看见，瘸子行走，长大麻风的洁净，聋子听见，死人复活，穷人有福音传给他们。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 8:14–15; 哥林多前书 2:14; 马太福音 26:31"> 凡不因我跌倒的就有福了！」</span>
<span className="v" id="v7" data-v="7" data-xref="雅各书 1:6; 约翰福音 5:35; 马可福音 1:3–5"> 他们走的时候，耶稣就对众人讲论约翰说：「你们从前出到旷野是要看什么呢？要看风吹动的芦苇吗？</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 3:4; 列王纪下 1:8; 撒迦利亚书 13:4"> 你们出去到底是要看什么？要看穿细软衣服的人吗？那穿细软衣服的人是在王宫里。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 1:76; 马太福音 14:5; 马太福音 21:24–26"> 你们出去究竟是为什么？是要看先知吗？我告诉你们，是的，他比先知大多了。</span>
<span className="v" id="v10" data-v="10" data-xref="玛拉基书 3:1; 以赛亚书 40:3; 玛拉基书 4:5"> 经上记着说：『我要差遣我的使者在你前面预备道路』，所说的就是这个人。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 7:28; 以弗所书 3:8; 马太福音 3:11"> 我实在告诉你们，凡妇人所生的，没有一个兴起来大过施洗约翰的；然而天国里最小的比他还大。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 16:16; 路加福音 13:24; 以弗所书 6:11–13"> 从施洗约翰的时候到如今，天国是努力进入的，努力的人就得着了。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 5:17–18; 罗马书 3:21; 使徒行传 13:27"> 因为众先知和律法说预言，到约翰为止。</span>
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 4:5; 马太福音 17:10–13; 马可福音 9:11–13"> 你们若肯领受，这人就是那应当来的以利亚。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 8:8; 马太福音 13:9; 马可福音 4:23"> 有耳可听的，就应当听！</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 7:31–35; 马太福音 12:34; 马太福音 23:36"> 我可用什么比这世代呢？好像孩童坐在街市上招呼同伴，说：</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 28:9–13; 以赛亚书 30:29; 耶利米书 9:17–20"> 我们向你们吹笛，<br /><span className="pl pl-1">你们不跳舞；</span><br /><span className="pl pl-1">我们向你们举哀，</span><br /><span className="pl pl-1">你们不捶胸。</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 1:15; 马太福音 3:4; 约翰福音 10:20"> 约翰来了，也不吃也不喝，人就说他是被鬼附着的；</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 9:10–11; 路加福音 15:1–2; 路加福音 19:7"> 人子来了，也吃也喝，人又说他是贪食好酒的人，是税吏和罪人的朋友。但智慧之子总以智慧为是<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷：但智慧在行为上就显为是">a</a></sup>。」</span>
</div>
</div>

## 耶稣责备不悔改的城

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:13–15; 耶利米书 8:6; 提摩太后书 2:25–26"> 耶稣在诸城中行了许多异能，那些城的人终不悔改，就在那时候责备他们，说：</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 3:6–7; 使徒行传 12:20; 路加福音 9:10"> 「哥拉汛哪，你有祸了！伯赛大啊，你有祸了！因为在你们中间所行的异能，若行在泰尔、西顿，他们早已披麻蒙灰悔改了。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 11:24; 马太福音 10:15; 希伯来书 10:26–31"> 但我告诉你们，当审判的日子，泰尔、西顿所受的，比你们还容易受呢！</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 14:13–15; 约翰福音 4:46–54; 创世记 13:13"> 迦百农啊，你已经升到天上<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：你将要升到天上吗">b</a></sup>，将来必坠落阴间；因为在你那里所行的异能，若行在所多玛，它还可以存到今日。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 10:15; 马太福音 11:22; 马可福音 6:11"> 但我告诉你们，当审判的日子，所多玛所受的，比你还容易受呢！」</span>
</div>
</div>

## 到我这里来

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马太福音 21:16; 诗篇 8:2; 马太福音 16:17"> 那时，耶稣说：「父啊，天地的主，我感谢你！因为你将这些事向聪明通达人就藏起来，向婴孩就显出来。</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太后书 1:9; 以弗所书 1:11; 约伯记 33:13"> 父啊，是的，因为你的美意本是如此。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 14:6–9; 马太福音 28:18; 路加福音 10:22"> 一切所有的，都是我父交付我的；除了父，没有人知道子；除了子和子所愿意指示的，没有人知道父。</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 11:29; 约翰福音 7:37; 约翰福音 6:37"> 凡劳苦担重担的人可以到我这里来，我就使你们得安息。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 6:16; 约翰一书 2:6; 腓立比书 2:7–8"> 我心里柔和谦卑，你们当负我的轭，学我的样式；这样，你们心里就必得享安息。</span>
<span className="v" id="v30" data-v="30" data-xref="约翰一书 5:3; 约翰福音 16:33; 腓立比书 4:13"> 因为我的轭是容易的，我的担子是轻省的。」</span>
</div>

## 所罗门的箴言

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 1:1; 箴言 29:15; 箴言 17:25"> <span className="pl pl-1">所罗门的箴言：</span><br /><span className="pl pl-1">智慧之子使父亲欢乐；</span><br /><span className="pl pl-1">愚昧之子叫母亲担忧。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="箴言 11:4; 箴言 12:28; 诗篇 49:6–10"> <span className="pl pl-1">不义之财毫无益处；</span><br /><span className="pl pl-1">惟有公义能救人脱离死亡。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 37:3; 马太福音 6:30–33; 诗篇 37:25"> <span className="pl pl-1">耶和华不使义人受饥饿；</span><br /><span className="pl pl-1">恶人所欲的，他必推开。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 21:5; 箴言 20:4; 箴言 19:15"> <span className="pl pl-1">手懒的，要受贫穷；</span><br /><span className="pl pl-1">手勤的，却要富足。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="箴言 6:8; 箴言 30:25; 箴言 17:2"> <span className="pl pl-1">夏天聚敛的，是智慧之子；</span><br /><span className="pl pl-1">收割时沉睡的，是贻羞之子。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="申命记 28:2; 箴言 28:20; 约伯记 29:13"> <span className="pl pl-1">福祉临到义人的头；</span><br /><span className="pl pl-1">强暴蒙蔽恶人的口。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 112:6; 路加福音 1:48; 马可福音 14:9"> <span className="pl pl-1">义人的纪念被称赞；</span><br /><span className="pl pl-1">恶人的名字必朽烂。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 7:24–25; 箴言 12:1; 雅各书 3:13"> <span className="pl pl-1">心中智慧的，必受命令；</span><br /><span className="pl pl-1">口里愚妄的，必致倾倒。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 28:18; 马太福音 10:26; 诗篇 26:11–12"> <span className="pl pl-1">行正直路的，步步安稳；</span><br /><span className="pl pl-1">走弯曲道的，必致败露。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 35:19; 箴言 6:13; 约翰三书 1:10"> <span className="pl pl-1">以眼传神的，使人忧患；</span><br /><span className="pl pl-1">口里愚妄的，必致倾倒。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 13:14; 以弗所书 4:29; 箴言 10:6"> <span className="pl pl-1">义人的口是生命的泉源；</span><br /><span className="pl pl-1">强暴蒙蔽恶人的口。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 4:8; 哥林多前书 13:4–7; 箴言 17:9"> <span className="pl pl-1">恨能挑启争端；</span><br /><span className="pl pl-1">爱能遮掩一切过错。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 26:3; 箴言 6:32; 以赛亚书 50:4"> <span className="pl pl-1">明哲人嘴里有智慧；</span><br /><span className="pl pl-1">无知人背上受刑杖。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 18:7; 箴言 10:8; 箴言 13:3"> <span className="pl pl-1">智慧人积存知识；</span><br /><span className="pl pl-1">愚妄人的口速致败坏。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 18:11; 箴言 19:7; 诗篇 52:7"> <span className="pl pl-1">富户的财物是他的坚城；</span><br /><span className="pl pl-1">穷人的贫乏是他的败坏。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 6:23; 以赛亚书 3:10–11; 希伯来书 6:10"> <span className="pl pl-1">义人的勤劳致生；</span><br /><span className="pl pl-1">恶人的进项致死</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="死：原文是罪">a</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="彼得后书 1:5–11; 路加福音 11:28; 箴言 6:23"> <span className="pl pl-1">谨守训诲的，乃在生命的道上；</span><br /><span className="pl pl-1">违弃责备的，便失迷了路。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 26:24–26; 诗篇 55:21; 撒母耳记下 3:27"> <span className="pl pl-1">隐藏怨恨的，有说谎的嘴；</span><br /><span className="pl pl-1">口出谗谤的，是愚妄的人。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="雅各书 1:19; 雅各书 3:2; 箴言 17:27–28"> <span className="pl pl-1">多言多语难免有过；</span><br /><span className="pl pl-1">禁止嘴唇是有智慧。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 17:9; 箴言 12:18; 创世记 6:5"> <span className="pl pl-1">义人的舌乃似高银；</span><br /><span className="pl pl-1">恶人的心所值无几。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="何西阿书 4:6; 箴言 17:16; 箴言 1:29"> <span className="pl pl-1">义人的口教养多人；</span><br /><span className="pl pl-1">愚昧人因无知而死亡。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 107:38; 创世记 26:12; 撒母耳记上 2:7–8"> <span className="pl pl-1">耶和华所赐的福使人富足，</span><br /><span className="pl pl-1">并不加上忧虑。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 15:21; 箴言 2:14; 箴言 14:9"> <span className="pl pl-1">愚妄人以行恶为戏耍；</span><br /><span className="pl pl-1">明哲人却以智慧为乐。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 145:19; 以赛亚书 66:4; 马太福音 5:6"> <span className="pl pl-1">恶人所怕的，必临到他；</span><br /><span className="pl pl-1">义人所愿的，必蒙应允。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 15:5; 诗篇 58:9; 马太福音 7:24–27"> <span className="pl pl-1">暴风一过，恶人归于无有；</span><br /><span className="pl pl-1">义人的根基却是永久。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="箴言 25:13; 箴言 26:6; 马太福音 25:26"> <span className="pl pl-1">懒惰人叫差他的人</span><br /><span className="pl pl-1">如醋倒牙，如烟薰目。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="箴言 9:11; 箴言 3:2; 诗篇 91:16"> <span className="pl pl-1">敬畏耶和华使人日子加多；</span><br /><span className="pl pl-1">但恶人的年岁必被减少。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="约伯记 8:13; 罗马书 15:13; 诗篇 73:24–26"> <span className="pl pl-1">义人的盼望必得喜乐；</span><br /><span className="pl pl-1">恶人的指望必致灭没。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 21:15; 罗马书 2:8–9; 腓立比书 4:13"> <span className="pl pl-1">耶和华的道是正直人的保障，</span><br /><span className="pl pl-1">却成了作孽人的败坏。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 37:22; 诗篇 125:1; 诗篇 37:9–10"> <span className="pl pl-1">义人永不挪移；</span><br /><span className="pl pl-1">恶人不得住在地上。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 37:30; 箴言 10:13; 箴言 10:20–21"> <span className="pl pl-1">义人的口滋生智慧；</span><br /><span className="pl pl-1">乖谬的舌必被割断。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="箴言 15:28; 箴言 12:6; 箴言 11:11"> <span className="pl pl-1">义人的嘴能令人喜悦；</span><br /><span className="pl pl-1">恶人的口说乖谬的话。</span></span>

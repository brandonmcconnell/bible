## 智慧的益处

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 2:1; 诗篇 34:11; 箴言 1:8"> <span className="pl pl-1">众子啊，要听父亲的教训，</span><br /><span className="pl pl-1">留心得知聪明。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前书 4:6; 申命记 32:2; 提多书 1:9"> <span className="pl pl-1">因我所给你们的是好教训；</span><br /><span className="pl pl-1">不可离弃我的法则</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：指教">a</a></sup><br /><span className="pl pl-1">。</span><br /></span>

<span className="v" id="v4" data-v="4" data-xref="箴言 3:1; 以弗所书 6:4; 约翰福音 12:50"> <span className="pl pl-1">父亲教训我说：你心要存记我的言语，</span><br /><span className="pl pl-1">遵守我的命令，便得存活。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="雅各书 1:5; 箴言 3:13–18; 箴言 1:22–23"> <span className="pl pl-1">要得智慧，要得聪明，不可忘记，</span><br /><span className="pl pl-1">也不可偏离我口中的言语。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦后书 2:10; 箴言 4:21–22; 以弗所书 3:17"> <span className="pl pl-1">不可离弃智慧，智慧就护卫你；</span><br /><span className="pl pl-1">要爱她，她就保守你。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="传道书 7:12; 传道书 9:16–18; 箴言 23:23"> <span className="pl pl-1">智慧为首；</span><br /><span className="pl pl-1">所以，要得智慧。</span><br /><span className="pl pl-1">在你一切所得之内必得聪明</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：用你一切所得的去换聪明">b</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="但以理书 12:3; 撒母耳记上 2:30; 箴言 3:35"> <span className="pl pl-1">高举智慧，她就使你高升；</span><br /><span className="pl pl-1">怀抱智慧，她就使你尊荣。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="箴言 1:9; 彼得前书 5:4; 希伯来书 2:7–9"> <span className="pl pl-1">她必将华冠加在你头上，</span><br /><span className="pl pl-1">把荣冕交给你。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="帖撒罗尼迦前书 2:13; 箴言 3:2; 耶利米书 9:20"> <span className="pl pl-1">我儿，你要听受我的言语，</span><br /><span className="pl pl-1">就必延年益寿。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 25:4–5; 传道书 12:9; 箴言 8:9"> <span className="pl pl-1">我已指教你走智慧的道，</span><br /><span className="pl pl-1">引导你行正直的路。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 3:23; 诗篇 18:36; 彼得前书 2:8"> <span className="pl pl-1">你行走，脚步必不致狭窄；</span><br /><span className="pl pl-1">你奔跑，也不致跌倒。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 2:1; 箴言 3:18; 箴言 23:23"> <span className="pl pl-1">要持定训诲，不可放松；</span><br /><span className="pl pl-1">必当谨守，因为它是你的生命。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 1:1; 哥林多前书 15:33; 箴言 1:10"> <span className="pl pl-1">不可行恶人的路；</span><br /><span className="pl pl-1">不要走坏人的道。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以弗所书 5:11; 约伯记 22:23; 帖撒罗尼迦前书 5:22"> <span className="pl pl-1">要躲避，不可经过；</span><br /><span className="pl pl-1">要转身而去。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 36:4; 弥迦书 2:1; 以赛亚书 57:20"> <span className="pl pl-1">这等人若不行恶，不得睡觉；</span><br /><span className="pl pl-1">不使人跌倒，睡卧不安；</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="雅各书 5:4–5; 诗篇 14:4; 弥迦书 6:12"> <span className="pl pl-1">因为他们以奸恶吃饼，</span><br /><span className="pl pl-1">以强暴喝酒。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="约翰福音 8:12; 约伯记 11:17; 但以理书 12:3"> <span className="pl pl-1">但义人的路好像黎明的光，</span><br /><span className="pl pl-1">越照越明，直到日午。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="箴言 5:1; 以赛亚书 55:3; 箴言 7:1"> <span className="pl pl-1">我儿，要留心听我的言词，</span><br /><span className="pl pl-1">侧耳听我的话语，</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="箴言 3:21; 箴言 3:3; 箴言 7:1–2"> <span className="pl pl-1">都不可离你的眼目，</span><br /><span className="pl pl-1">要存记在你心中。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 4:10; 箴言 12:18; 耶利米书 33:6"> <span className="pl pl-1">因为得着它的，就得了生命，</span><br /><span className="pl pl-1">又得了医全体的良药。</span><br /></span>

<span className="v" id="v25" data-v="25" data-xref="诗篇 119:37; 马太福音 6:22; 约伯记 31:1"> <span className="pl pl-1">你的眼目要向前正看；</span><br /><span className="pl pl-1">你的眼睛</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原文是皮">d</a></sup><br /><span className="pl pl-1">当向前直观。</span><br /></span>

<span className="v" id="v3" data-v="3" data-xref="箴言 10:25; 以弗所书 3:17; 箴言 12:12"> <span className="pl pl-1">人靠恶行不能坚立；</span><br /><span className="pl pl-1">义人的根必不动摇。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 14:30; 箴言 31:10–25; 箴言 14:1"> <span className="pl pl-1">才德的妇人是丈夫的冠冕；</span><br /><span className="pl pl-1">贻羞的妇人如同朽烂在她丈夫的骨中。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 139:23; 以赛亚书 55:7; 诗篇 140:1–3"> <span className="pl pl-1">义人的思念是公平；</span><br /><span className="pl pl-1">恶人的计谋是诡诈。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 14:3; 耶利米书 5:26; 箴言 1:11–19"> <span className="pl pl-1">恶人的言论是埋伏流人的血；</span><br /><span className="pl pl-1">正直人的口必拯救人。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 7:24–27; 箴言 11:21; 箴言 10:25"> <span className="pl pl-1">恶人倾覆，归于无有；</span><br /><span className="pl pl-1">义人的家必站得住。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 10:18; 哥林多前书 4:5; 哥林多前书 3:10–15"> <span className="pl pl-1">人必按自己的智慧被称赞；</span><br /><span className="pl pl-1">心中乖谬的，必被藐视。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 14:11; 箴言 13:7"> <span className="pl pl-1">被人轻贱，却有仆人，</span><br /><span className="pl pl-1">强如自尊，缺少食物。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="申命记 25:4; 创世记 33:13–14; 民数记 22:28–32"> <span className="pl pl-1">义人顾惜他牲畜的命；</span><br /><span className="pl pl-1">恶人的怜悯也是残忍。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 28:19; 箴言 14:23; 帖撒罗尼迦前书 4:11–12"> <span className="pl pl-1">耕种自己田地的，必得饱食；</span><br /><span className="pl pl-1">追随虚浮的，却是无知。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 17:7–8; 约翰福音 15:5; 路加福音 8:13–15"> <span className="pl pl-1">恶人想得坏人的网罗；</span><br /><span className="pl pl-1">义人的根得以结实。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 21:23; 箴言 11:8; 诗篇 64:8"> <span className="pl pl-1">恶人嘴中的过错是自己的网罗；</span><br /><span className="pl pl-1">但义人必脱离患难。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 18:20–21; 以赛亚书 3:10–11; 箴言 13:2"> <span className="pl pl-1">人因口所结的果子，必饱得美福；</span><br /><span className="pl pl-1">人手所做的，必为自己的报应。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 3:7; 箴言 26:12; 箴言 14:16"> <span className="pl pl-1">愚妄人所行的，在自己眼中看为正直；</span><br /><span className="pl pl-1">惟智慧人肯听人的劝教。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 29:11; 雅各书 1:19; 箴言 10:12"> <span className="pl pl-1">愚妄人的恼怒立时显露；</span><br /><span className="pl pl-1">通达人能忍辱藏羞。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 14:5; 箴言 14:25; 箴言 24:28"> <span className="pl pl-1">说出真话的，显明公义；</span><br /><span className="pl pl-1">作假见证的，显出诡诈。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 16:24; 箴言 15:4; 诗篇 57:4"> <span className="pl pl-1">说话浮躁的，如刀刺人；</span><br /><span className="pl pl-1">智慧人的舌头却为医人的良药。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 19:9; 诗篇 52:4–5; 约伯记 20:5"> <span className="pl pl-1">口吐真言，永远坚立；</span><br /><span className="pl pl-1">舌说谎话，只存片时。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 5:9; 彼得前书 3:8–13; 箴言 12:12"> <span className="pl pl-1">图谋恶事的，心存诡诈；</span><br /><span className="pl pl-1">劝人和睦的，便得喜乐。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="彼得前书 3:13; 诗篇 91:10; 罗马书 8:28"> <span className="pl pl-1">义人不遭灾害；恶人满受祸患。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 5:6; 箴言 11:20; 启示录 22:15"> <span className="pl pl-1">说谎言的嘴为耶和华所憎恶；</span><br /><span className="pl pl-1">行事诚实的，为他所喜悦。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 13:16; 箴言 11:13; 箴言 10:19"> <span className="pl pl-1">通达人隐藏知识；</span><br /><span className="pl pl-1">愚昧人的心彰显愚昧。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="箴言 12:27; 箴言 10:4; 箴言 21:25–26"> <span className="pl pl-1">殷勤人的手必掌权；</span><br /><span className="pl pl-1">懒惰的人必服苦。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="箴言 16:24; 箴言 15:13; 箴言 17:22"> <span className="pl pl-1">人心忧虑，屈而不伸；</span><br /><span className="pl pl-1">一句良言，使心欢乐。</span><br /></span>

<span className="v" id="v28" data-v="28" data-xref="约翰三书 1:11; 罗马书 5:21; 以西结书 18:20–24"> <span className="pl pl-1">在公义的道上有生命；</span><br /><span className="pl pl-1">其路之中并无死亡。</span></span>

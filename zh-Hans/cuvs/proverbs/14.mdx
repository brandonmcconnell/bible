<span className="v" id="v5" data-v="5" data-xref="箴言 6:19; 箴言 19:5; 出埃及记 23:1"> <span className="pl pl-1">诚实见证人不说谎话；</span><br /><span className="pl pl-1">假见证人吐出谎言。</span><br /></span>

<span className="v" id="v7" data-v="7" data-xref="箴言 13:20; 以弗所书 5:11; 哥林多前书 5:11"> <span className="pl pl-1">到愚昧人面前，</span><br /><span className="pl pl-1">不见他嘴中有知识。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 5:17; 提摩太后书 3:13; 雅各书 3:13"> <span className="pl pl-1">通达人的智慧在乎明白己道；</span><br /><span className="pl pl-1">愚昧人的愚妄乃是诡诈</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：自叹">a</a></sup><br /><span className="pl pl-1">。</span><br /></span>

<span className="v" id="v10" data-v="10" data-xref="腓立比书 4:7; 箴言 18:14; 箴言 15:13"> <span className="pl pl-1">心中的苦楚，自己知道；</span><br /><span className="pl pl-1">心里的喜乐，外人无干。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 3:33; 箴言 12:7; 马太福音 7:26–27"> <span className="pl pl-1">奸恶人的房屋必倾倒；</span><br /><span className="pl pl-1">正直人的帐棚必兴盛。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 16:25; 马太福音 7:13–14; 箴言 12:15"> <span className="pl pl-1">有一条路，人以为正，</span><br /><span className="pl pl-1">至终成为死亡之路。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="传道书 2:2; 雅各书 4:9; 传道书 2:10–11"> <span className="pl pl-1">人在喜笑中，心也忧愁；</span><br /><span className="pl pl-1">快乐至极就生愁苦。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 6:8; 箴言 12:14; 希伯来书 3:12"> <span className="pl pl-1">心中背道的，必满得自己的结果；</span><br /><span className="pl pl-1">善人必从自己的行为得以知足。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="以弗所书 5:17; 箴言 14:8; 约翰一书 4:1"> <span className="pl pl-1">愚蒙人是话都信；</span><br /><span className="pl pl-1">通达人步步谨慎。</span><br /></span>

<span className="v" id="v17" data-v="17" data-xref="箴言 14:29; 雅各书 1:19; 传道书 7:9"> <span className="pl pl-1">轻易发怒的，行事愚妄；</span><br /><span className="pl pl-1">设立诡计的，被人恨恶。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="彼得前书 1:18; 彼得前书 5:4; 耶利米书 44:17"> <span className="pl pl-1">愚蒙人得愚昧为产业；</span><br /><span className="pl pl-1">通达人得知识为冠冕。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="创世记 42:6; 玛拉基书 4:3; 出埃及记 8:8"> <span className="pl pl-1">坏人俯伏在善人面前；</span><br /><span className="pl pl-1">恶人俯伏在义人门口。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="箴言 19:4; 箴言 10:15; 箴言 19:6–7"> <span className="pl pl-1">贫穷人连邻舍也恨他；</span><br /><span className="pl pl-1">富足人朋友最多。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 19:17; 箴言 28:27; 箴言 11:12"> <span className="pl pl-1">藐视邻舍的，这人有罪；</span><br /><span className="pl pl-1">怜悯贫穷的，这人有福。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 12:2; 约翰福音 1:17; 诗篇 61:7"> <span className="pl pl-1">谋恶的，岂非走入迷途吗？</span><br /><span className="pl pl-1">谋善的，必得慈爱和诚实。</span><br /></span>

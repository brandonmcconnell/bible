<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 15:22; 何西阿书 6:6; 弥迦书 6:6–8"> <span className="pl pl-1">行仁义公平</span><br /><span className="pl pl-1">比献祭更蒙耶和华悦纳。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 6:17; 彼得前书 5:5; 以赛亚书 2:17"> <span className="pl pl-1">恶人发达</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="发达：原文是灯">a</a></sup><br /><span className="pl pl-1">，眼高心傲，</span><br /><span className="pl pl-1">这乃是罪。</span><br /></span>

<span className="v" id="v6" data-v="6" data-xref="箴言 13:11; 箴言 10:2; 箴言 20:21"> <span className="pl pl-1">用诡诈之舌求财的，就是自己取死；</span><br /><span className="pl pl-1">所得之财乃是吹来吹去的浮云。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 21:21; 以弗所书 5:6; 箴言 1:18–19"> <span className="pl pl-1">恶人的强暴必将自己扫除，</span><br /><span className="pl pl-1">因他们不肯按公平行事。</span><br /></span>

<span className="v" id="v9" data-v="9" data-xref="箴言 19:13; 箴言 21:19; 箴言 27:15–16"> <span className="pl pl-1">宁可住在房顶的角上，</span><br /><span className="pl pl-1">不在宽阔的房屋与争吵的妇人同住。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="弥迦书 3:2–3; 箴言 3:29; 诗篇 36:4"> <span className="pl pl-1">恶人的心乐人受祸；</span><br /><span className="pl pl-1">他眼并不怜恤邻舍。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 19:25; 箴言 18:15; 箴言 9:9"> <span className="pl pl-1">亵慢的人受刑罚，愚蒙的人就得智慧；</span><br /><span className="pl pl-1">智慧人受训诲，便得知识。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 14:11; 诗篇 37:35–36; 彼得后书 3:6–7"> <span className="pl pl-1">义人思想恶人的家，</span><br /><span className="pl pl-1">知道恶人倾倒，必致灭亡。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="箴言 28:27; 马太福音 6:14; 箴言 1:28"> <span className="pl pl-1">塞耳不听穷人哀求的，</span><br /><span className="pl pl-1">他将来呼吁也不蒙应允。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 18:16; 箴言 19:6; 箴言 17:8"> <span className="pl pl-1">暗中送的礼物挽回怒气；</span><br /><span className="pl pl-1">怀中搋的贿赂止息暴怒。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 10:29; 马太福音 7:23; 马太福音 13:41–42"> <span className="pl pl-1">秉公行义使义人喜乐，</span><br /><span className="pl pl-1">使作孽的人败坏。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 10:38; 诗篇 125:5; 诗篇 49:14"> <span className="pl pl-1">迷离通达道路的，</span><br /><span className="pl pl-1">必住在阴魂的会中。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="箴言 23:21; 提摩太前书 5:6; 提摩太后书 3:4"> <span className="pl pl-1">爱宴乐的，必致穷乏；</span><br /><span className="pl pl-1">好酒，爱膏油的，必不富足。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 11:8; 以赛亚书 43:3–4; 以赛亚书 53:4–5"> <span className="pl pl-1">恶人作了义人的赎价；</span><br /><span className="pl pl-1">奸诈人代替正直人。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 21:9; 诗篇 120:5–6; 诗篇 55:6–7"> <span className="pl pl-1">宁可住在旷野，</span><br /><span className="pl pl-1">不与争吵使气的妇人同住。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 25:3–4; 诗篇 112:3; 传道书 7:11"> <span className="pl pl-1">智慧人家中积蓄宝物膏油；</span><br /><span className="pl pl-1">愚昧人随得来随吞下。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 5:6; 哥林多前书 15:58; 箴言 22:4"> <span className="pl pl-1">追求公义仁慈的，</span><br /><span className="pl pl-1">就寻得生命、公义，和尊荣。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="传道书 7:19; 箴言 24:5; 传道书 9:13–18"> <span className="pl pl-1">智慧人爬上勇士的城墙，</span><br /><span className="pl pl-1">倾覆他所倚靠的坚垒。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 13:3; 箴言 18:21; 雅各书 1:26"> <span className="pl pl-1">谨守口与舌的，</span><br /><span className="pl pl-1">就保守自己免受灾难。</span><br /></span>

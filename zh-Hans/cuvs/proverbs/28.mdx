<span className="v" id="v3" data-v="3" data-xref="马太福音 18:28–30"> <span className="pl pl-1">穷人欺压贫民，</span><br /><span className="pl pl-1">好像暴雨冲没粮食。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 1:32; 以弗所书 5:11; 马太福音 14:4"> <span className="pl pl-1">违弃律法的，夸奖恶人；</span><br /><span className="pl pl-1">遵守律法的，却与恶人相争。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 92:6; 雅各书 1:5; 约翰一书 2:27"> <span className="pl pl-1">坏人不明白公义；</span><br /><span className="pl pl-1">惟有寻求耶和华的，无不明白。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 19:1; 箴言 28:18; 路加福音 16:19–23"> <span className="pl pl-1">行为纯正的穷乏人</span><br /><span className="pl pl-1">胜过行事乖僻的富足人。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="彼得前书 4:3–4; 箴言 29:3; 箴言 3:1–35"> <span className="pl pl-1">谨守律法的，是智慧之子；</span><br /><span className="pl pl-1">与贪食人作伴的，却羞辱其父。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="约伯记 27:16–17; 箴言 13:22; 传道书 2:26"> <span className="pl pl-1">人以厚利加增财物，</span><br /><span className="pl pl-1">是给那怜悯穷人者积蓄的。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 66:18; 提摩太后书 4:3–4; 撒迦利亚书 7:11–13"> <span className="pl pl-1">转耳不听律法的，</span><br /><span className="pl pl-1">他的祈祷也为可憎。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 26:27; 诗篇 37:25–26; 加拉太书 2:4"> <span className="pl pl-1">诱惑正直人行恶道的，必掉在自己的坑里；</span><br /><span className="pl pl-1">惟有完全人必承受福分。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="箴言 18:17; 传道书 9:15–17; 箴言 26:16"> <span className="pl pl-1">富足人自以为有智慧，</span><br /><span className="pl pl-1">但聪明的贫穷人能将他查透。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 29:2; 箴言 11:10; 箴言 28:28"> <span className="pl pl-1">义人得志，有大荣耀；</span><br /><span className="pl pl-1">恶人兴起，人就躲藏。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="约翰一书 1:8–10; 诗篇 32:3–5; 约伯记 31:33"> <span className="pl pl-1">遮掩自己罪过的，必不亨通；</span><br /><span className="pl pl-1">承认离弃罪过的，必蒙怜恤。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 23:17; 诗篇 2:11; 以赛亚书 66:2"> <span className="pl pl-1">常存敬畏的，便为有福；</span><br /><span className="pl pl-1">心存刚硬的，必陷在祸患里。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 5:8; 马太福音 2:16; 箴言 19:12"> <span className="pl pl-1">暴虐的君王辖制贫民，</span><br /><span className="pl pl-1">好像吼叫的狮子、觅食的熊。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 18:21; 耶利米书 22:15–17; 传道书 4:1"> <span className="pl pl-1">无知的君多行暴虐；</span><br /><span className="pl pl-1">以贪财为可恨的，必年长日久。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="创世记 9:6; 列王纪上 21:19; 出埃及记 21:14"> <span className="pl pl-1">背负流人血之罪的，必往坑里奔跑，</span><br /><span className="pl pl-1">谁也不可拦阻他。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:9; 箴言 28:6; 启示录 3:3"> <span className="pl pl-1">行动正直的，必蒙拯救；</span><br /><span className="pl pl-1">行事弯曲的，立时跌倒。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="箴言 12:11; 士师记 9:4; 箴言 27:23–27"> <span className="pl pl-1">耕种自己田地的，必得饱食；</span><br /><span className="pl pl-1">追随虚浮的，足受穷乏。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 16:10–12; 箴言 13:11; 启示录 2:10"> <span className="pl pl-1">诚实人必多得福；</span><br /><span className="pl pl-1">想要急速发财的，不免受罚。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="箴言 24:23; 箴言 18:5; 以西结书 13:19"> <span className="pl pl-1">看人的情面乃为不好；</span><br /><span className="pl pl-1">人因一块饼枉法也为不好。</span><br /></span>

<span className="v" id="v24" data-v="24" data-xref="马太福音 15:4–6; 箴言 18:9; 箴言 19:26"> <span className="pl pl-1">偷窃父母的，说：这不是罪，</span><br /><span className="pl pl-1">此人就是与强盗同类。</span><br /></span>

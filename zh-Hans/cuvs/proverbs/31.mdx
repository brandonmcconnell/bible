<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 6:20; 箴言 1:8; 提摩太后书 1:5"> <span className="pl pl-1">利慕伊勒王的言语，是他母亲教训他的真言。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 49:15; 撒母耳记上 1:11; 撒母耳记上 1:28"> <span className="pl pl-1">我的儿啊，我腹中生的儿啊，</span><br /><span className="pl pl-1">我许愿得的儿啊！我当怎样教训你呢？</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="申命记 17:17; 尼希米记 13:26; 箴言 7:26–27"> <span className="pl pl-1">不要将你的精力给妇女；</span><br /><span className="pl pl-1">也不要有败坏君王的行为。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="箴言 20:1; 传道书 10:17; 以赛亚书 5:22"> <span className="pl pl-1">利慕伊勒啊，君王喝酒，君王喝酒不相宜；</span><br /><span className="pl pl-1">王子说浓酒在那里也不相宜；</span><br /></span>

<span className="v" id="v6" data-v="6" data-xref="提摩太前书 5:23; 诗篇 104:15; 撒母耳记上 1:10"> <span className="pl pl-1">可以把浓酒给将亡的人喝，</span><br /><span className="pl pl-1">把清酒给苦心的人喝，</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 5:18"> <span className="pl pl-1">让他喝了，就忘记他的贫穷，</span><br /><span className="pl pl-1">不再记念他的苦楚。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 82:3–4; 箴言 24:11–12; 以斯帖记 4:13–16"> <span className="pl pl-1">你当为哑巴</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：不能自辩的">a</a></sup><br /><span className="pl pl-1">开口，</span><br /><span className="pl pl-1">为一切孤独的伸冤。</span><br /></span>

## 论贤妻

<div className="bt">
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="箴言 19:14; 箴言 12:4; 箴言 18:22"> <span className="pl pl-1">才德的妇人谁能得着呢？</span><br /><span className="pl pl-1">她的价值远胜过珍珠。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="彼得前书 3:1–7; 列王纪下 4:22–23; 列王纪下 4:9–10"> <span className="pl pl-1">她丈夫心里倚靠她，</span><br /><span className="pl pl-1">必不缺少利益；</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 25:18–22; 撒母耳记上 25:26–27"> <span className="pl pl-1">她一生使丈夫有益无损。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="提多书 2:5; 提摩太前书 5:10; 帖撒罗尼迦后书 3:10–12"> <span className="pl pl-1">她寻找羊绒和麻，</span><br /><span className="pl pl-1">甘心用手做工。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 31:24; 列王纪上 9:26–28; 以西结书 27:3–36"> <span className="pl pl-1">她好像商船从远方运粮来，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 12:11; 马可福音 1:35; 路加福音 12:42"> <span className="pl pl-1">未到黎明她就起来，</span><br /><span className="pl pl-1">把食物分给家中的人，</span><br /><span className="pl pl-1">将当做的工分派婢女。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 13:44; 雅歌 8:12; 约书亚记 15:18"> <span className="pl pl-1">她想得田地就买来；</span><br /><span className="pl pl-1">用手所得之利栽种葡萄园。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="约伯记 38:3; 彼得前书 1:13; 以弗所书 6:10"> <span className="pl pl-1">她以能力束腰，</span><br /><span className="pl pl-1">使膀臂有力。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 2:9; 马太福音 25:3–10; 诗篇 127:2"> <span className="pl pl-1">她觉得所经营的有利；</span><br /><span className="pl pl-1">她的灯终夜不灭。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 35:25–26"> <span className="pl pl-1">她手拿捻线竿，</span><br /><span className="pl pl-1">手把纺线车。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 4:28; 希伯来书 13:16; 箴言 22:9"> <span className="pl pl-1">她张手周济困苦人，</span><br /><span className="pl pl-1">伸手帮补穷乏人。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="创世记 45:22; 撒母耳记下 1:24; 箴言 25:20"> <span className="pl pl-1">她不因下雪为家里的人担心，</span><br /><span className="pl pl-1">因为全家都穿着朱红衣服。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="启示录 19:8; 箴言 7:16; 创世记 41:42"> <span className="pl pl-1">她为自己制作绣花毯子；</span><br /><span className="pl pl-1">她的衣服是细麻和紫色布做的。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 12:4; 路得记 4:1; 申命记 16:18"> <span className="pl pl-1">她丈夫在城门口与本地的长老同坐，</span><br /><span className="pl pl-1">为众人所认识。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 27:16; 路加福音 16:19; 箴言 31:19"> <span className="pl pl-1">她做细麻布衣裳出卖，</span><br /><span className="pl pl-1">又将腰带卖与商家。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="约伯记 40:10; 罗马书 13:14; 约伯记 29:14"> <span className="pl pl-1">能力和威仪是她的衣服；</span><br /><span className="pl pl-1">她想到日后的景况就喜笑。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="以弗所书 4:29; 箴言 16:24; 箴言 10:31"> <span className="pl pl-1">她开口就发智慧；</span><br /><span className="pl pl-1">她舌上有仁慈的法则。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="提摩太前书 5:10; 提多书 2:4; 帖撒罗尼迦后书 3:6"> <span className="pl pl-1">她观察家务，</span><br /><span className="pl pl-1">并不吃闲饭。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="提摩太后书 3:15–17; 提摩太后书 1:5; 列王纪上 2:19"> <span className="pl pl-1">她的儿女起来称她有福；</span><br /><span className="pl pl-1">她的丈夫也称赞她，</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="雅歌 6:8–9; 以弗所书 5:27"> <span className="pl pl-1">说：才德的女子很多，</span><br /><span className="pl pl-1">惟独你超过一切。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="箴言 1:7; 彼得前书 3:4–5; 箴言 11:22"> <span className="pl pl-1">艳丽是虚假的，美容是虚浮的；</span><br /><span className="pl pl-1">惟敬畏耶和华的妇女必得称赞。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 128:2; 希伯来书 6:10; 马太福音 7:16"> <span className="pl pl-1">愿她享受操作所得的；</span><br /><span className="pl pl-1">愿她的工作在城门口荣耀她。</span></span>

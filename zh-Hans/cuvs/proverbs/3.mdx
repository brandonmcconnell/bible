## 给青年人的忠告

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="箴言 4:5; 约翰福音 14:21–24; 申命记 6:6–9"> <span className="pl pl-1">我儿，不要忘记我的法则</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：指教">a</a></sup><br /><span className="pl pl-1">；</span><br /><span className="pl pl-1">你心要谨守我的诫命；</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 6:1–3; 箴言 4:10; 诗篇 91:16"> <span className="pl pl-1">因为它必将长久的日子，</span><br /><span className="pl pl-1">生命的年数与平安，加给你。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 7:3; 哥林多后书 3:3; 希伯来书 10:16"> <span className="pl pl-1">不可使慈爱、诚实离开你，</span><br /><span className="pl pl-1">要系在你颈项上，刻在你心版上。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 2:52; 撒母耳记上 2:26; 罗马书 14:18"> <span className="pl pl-1">这样，你必在 神和世人眼前</span><br /><span className="pl pl-1">蒙恩宠，有聪明。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="诗篇 37:5; 耶利米书 17:7–8; 箴言 28:26"> <span className="pl pl-1">你要专心仰赖耶和华，</span><br /><span className="pl pl-1">不可倚靠自己的聪明，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="箴言 16:3; 诗篇 32:8; 腓立比书 4:6"> <span className="pl pl-1">在你一切所行的事上都要认定他，</span><br /><span className="pl pl-1">他必指引你的路。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="约伯记 28:28; 罗马书 12:16; 箴言 26:12"> <span className="pl pl-1">不要自以为有智慧；</span><br /><span className="pl pl-1">要敬畏耶和华，远离恶事。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 4:22; 诗篇 147:3; 箴言 16:24"> <span className="pl pl-1">这便医治你的肚脐，</span><br /><span className="pl pl-1">滋润你的百骨。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="申命记 26:2–15; 哥林多前书 16:2; 出埃及记 23:19"> <span className="pl pl-1">你要以财物</span><br /><span className="pl pl-1">和一切初熟的土产尊荣耶和华。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="箴言 19:17; 申命记 28:8; 箴言 22:9"> <span className="pl pl-1">这样，你的仓房必充满有余；</span><br /><span className="pl pl-1">你的酒榨有新酒盈溢。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="约伯记 5:17; 启示录 3:19; 希伯来书 12:5–12"> <span className="pl pl-1">我儿，你不可轻看耶和华的管教</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：惩治">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">也不可厌烦他的责备；</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="申命记 8:5; 启示录 3:19; 箴言 29:17"> <span className="pl pl-1">因为耶和华所爱的，他必责备，</span><br /><span className="pl pl-1">正如父亲责备所喜爱的儿子。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="箴言 8:32–35; 箴言 4:5–9; 传道书 9:15–18"> <span className="pl pl-1">得智慧，得聪明的，</span><br /><span className="pl pl-1">这人便为有福。</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="箴言 16:16; 箴言 8:19; 约伯记 28:13–19"> <span className="pl pl-1">因为得智慧胜过得银子，</span><br /><span className="pl pl-1">其利益强如精金，</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 8:11; 约伯记 28:18; 诗篇 73:25–26"> <span className="pl pl-1">比珍珠</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或译：红宝石">c</a></sup><br /><span className="pl pl-1">宝贵；</span><br /><span className="pl pl-1">你一切所喜爱的，都不足与比较。</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="箴言 3:2; 哥林多后书 6:10; 箴言 22:4"> <span className="pl pl-1">她右手有长寿，</span><br /><span className="pl pl-1">左手有富贵。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 1:79; 以赛亚书 26:3; 腓立比书 4:8–9"> <span className="pl pl-1">她的道是安乐；</span><br /><span className="pl pl-1">她的路全是平安。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 11:30; 启示录 2:7; 箴言 15:4"> <span className="pl pl-1">她与持守她的作生命树；</span><br /><span className="pl pl-1">持定她的，俱各有福。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 104:24; 耶利米书 10:12; 约翰福音 1:3"> <span className="pl pl-1">耶和华以智慧立地，</span><br /><span className="pl pl-1">以聪明定天，</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="创世记 7:11; 诗篇 65:9–12; 约伯记 36:27–28"> <span className="pl pl-1">以知识使深渊裂开，</span><br /><span className="pl pl-1">使天空滴下甘露。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="约书亚记 1:8; 申命记 6:6–9; 申命记 32:46–47"> <span className="pl pl-1">我儿，要谨守真智慧和谋略，</span><br /><span className="pl pl-1">不可使她离开你的眼目。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="箴言 4:22; 箴言 1:9; 以赛亚书 38:16"> <span className="pl pl-1">这样，她必作你的生命，</span><br /><span className="pl pl-1">颈项的美饰。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="箴言 4:12; 箴言 10:9; 诗篇 121:3"> <span className="pl pl-1">你就坦然行路，</span><br /><span className="pl pl-1">不致碰脚。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 3:5; 诗篇 4:8; 箴言 6:22"> <span className="pl pl-1">你躺下，必不惧怕；</span><br /><span className="pl pl-1">你躺卧，睡得香甜。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 41:10–14; 诗篇 112:7; 彼得前书 3:14"> <span className="pl pl-1">忽然来的惊恐，不要害怕；</span><br /><span className="pl pl-1">恶人遭毁灭，也不要恐惧。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 91:3; 撒母耳记上 2:9; 箴言 14:26"> <span className="pl pl-1">因为耶和华是你所倚靠的；</span><br /><span className="pl pl-1">他必保守你的脚不陷入网罗。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v27" data-v="27" data-xref="加拉太书 6:10; 雅各书 2:15–16; 罗马书 13:7"> <span className="pl pl-1">你手若有行善的力量，不可推辞，</span><br /><span className="pl pl-1">就当向那应得的人施行。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="利未记 19:13; 申命记 24:12–15; 哥林多后书 8:11"> <span className="pl pl-1">你那里若有现成的，不可对邻舍说：</span><br /><span className="pl pl-1">去吧，明天再来，我必给你。</span><br /></span>
<span className="v" id="v29" data-v="29" data-xref="箴言 6:14; 箴言 16:29–30; 诗篇 55:20"> <span className="pl pl-1">你的邻舍既在你附近安居，</span><br /><span className="pl pl-1">你不可设计害他。</span><br /></span>
<span className="v" id="v30" data-v="30" data-xref="提摩太后书 2:24; 箴言 29:22; 罗马书 12:18–21"> <span className="pl pl-1">人未曾加害与你，</span><br /><span className="pl pl-1">不可无故与他相争。</span><br /></span>
<span className="v" id="v31" data-v="31" data-xref="箴言 24:1; 诗篇 37:1; 加拉太书 5:21"> <span className="pl pl-1">不可嫉妒强暴的人，</span><br /><span className="pl pl-1">也不可选择他所行的路。</span><br /></span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 25:14; 约翰福音 15:15; 箴言 11:20"> <span className="pl pl-1">因为，乖僻人为耶和华所憎恶；</span><br /><span className="pl pl-1">正直人为他所亲密。</span><br /></span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 37:22; 利未记 26:14–46; 约伯记 8:6–7"> <span className="pl pl-1">耶和华咒诅恶人的家庭，</span><br /><span className="pl pl-1">赐福与义人的居所。</span><br /></span>
<span className="v" id="v34" data-v="34" data-xref="雅各书 4:6; 彼得前书 5:5; 诗篇 138:6"> <span className="pl pl-1">他讥诮那好讥诮的人，</span><br /><span className="pl pl-1">赐恩给谦卑的人。</span><br /></span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 132:18; 以赛亚书 65:13–15; 诗篇 73:24"> <span className="pl pl-1">智慧人必承受尊荣；</span><br /><span className="pl pl-1">愚昧人高升也成为羞辱。</span></span>
</div>

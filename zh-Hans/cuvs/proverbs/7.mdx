<div className="bt">
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="创世记 26:8; 士师记 5:28; 撒母耳记下 6:16"> <span className="pl pl-1">我曾在我房屋的窗户内，</span><br /><span className="pl pl-1">从我窗棂之间往外观看：</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="箴言 6:32; 箴言 1:22; 箴言 1:32"> <span className="pl pl-1">见愚蒙人内，少年人中，</span><br /><span className="pl pl-1">分明有一个无知的少年人，</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 5:8; 箴言 7:12; 士师记 16:1"> <span className="pl pl-1">从街上经过，走近淫妇的巷口，</span><br /><span className="pl pl-1">直往通她家的路去，</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="约伯记 24:13–15; 罗马书 13:12–14; 以弗所书 5:11"> <span className="pl pl-1">在黄昏，或晚上，</span><br /><span className="pl pl-1">或半夜，或黑暗之中。</span></span>
</div>
<div className="bp poetry">

<span className="v" id="v11" data-v="11" data-xref="箴言 9:13; 提多书 2:5; 箴言 31:10–31"> <span className="pl pl-1">这妇人喧嚷，不守约束，</span><br /><span className="pl pl-1">在家里停不住脚，</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="箴言 23:28; 箴言 9:14; 启示录 18:3"> <span className="pl pl-1">有时在街市上，有时在宽阔处，</span><br /><span className="pl pl-1">或在各巷口蹲伏，</span><br /></span>

<span className="v" id="v14" data-v="14" data-xref="箴言 21:27; 利未记 7:11; 箴言 17:1"> <span className="pl pl-1">平安祭在我这里，</span><br /><span className="pl pl-1">今日才还了我所许的愿。</span><br /></span>

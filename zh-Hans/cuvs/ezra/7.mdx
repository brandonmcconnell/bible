## 以斯拉到达耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 2:1; 历代志上 6:4–14; 以斯拉记 7:21"> 这事以后，波斯王亚达薛西年间，有个以斯拉，他是西莱雅的儿子，西莱雅是亚撒利雅的儿子，亚撒利雅是希勒家的儿子，</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 2:35; 撒母耳记下 8:17"> 希勒家是沙龙的儿子，沙龙是撒督的儿子，撒督是亚希突的儿子，</span>
<span className="v" id="v3" data-v="3"> 亚希突是亚玛利雅的儿子，亚玛利雅是亚撒利雅的儿子，亚撒利雅是米拉约的儿子，</span>
<span className="v" id="v4" data-v="4"> 米拉约是西拉希雅的儿子，西拉希雅是乌西的儿子，乌西是布基的儿子，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 6:25; 历代志下 26:20; 历代志上 6:4"> 布基是亚比书的儿子，亚比书是非尼哈的儿子，非尼哈是以利亚撒的儿子，以利亚撒是大祭司亚伦的儿子。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯拉记 8:22; 以斯拉记 7:28; 以斯拉记 8:31"> 这以斯拉从巴比伦上来，他是敏捷的文士，通达耶和华—以色列 神所赐摩西的律法书。王允准他一切所求的，是因耶和华—他 神的手帮助他。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 8:1–20; 历代志上 6:31–48; 历代志上 9:17–27"> 亚达薛西王第七年，以色列人、祭司、利未人、歌唱的、守门的、尼提宁，有上耶路撒冷的。</span>
<span className="v" id="v8" data-v="8"> 王第七年五月，以斯拉到了耶路撒冷。</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉记 7:6; 尼希米记 2:8; 尼希米记 2:18"> 正月初一日，他从巴比伦起程；因他 神施恩的手帮助他，五月初一日就到了耶路撒冷。</span>
<span className="v" id="v10" data-v="10" data-xref="玛拉基书 2:7; 提摩太后书 4:2; 马太福音 7:24"> 以斯拉定志考究遵行耶和华的律法，又将律例典章教训以色列人。</span>
</div>
</div>

## 亚达薛西王给以斯拉的文件

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以斯拉记 5:6; 以斯拉记 7:6; 马太福音 23:2"> 祭司以斯拉是通达耶和华诫命和赐以色列之律例的文士。亚达薛西王赐给他们谕旨，上面写着说：</span>
<span className="v" id="v12" data-v="12" data-xref="但以理书 2:37; 以西结书 26:7; 以斯拉记 4:17"> 「诸王之王亚达薛西，达于祭司以斯拉通达天上 神律法大德的文士，云云。</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 6:1; 诗篇 148:6; 历代志下 30:5"> 住在我国中的以色列人、祭司、利未人，凡甘心上耶路撒冷去的，我降旨准他们与你同去。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖记 1:14; 以斯拉记 7:25–26; 以斯拉记 7:28"> 王与七个谋士既然差你去，照你手中 神的律法书察问犹大和耶路撒冷的景况；</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 135:21; 历代志下 6:2; 以斯拉记 6:12"> 又带金银，就是王和谋士甘心献给住耶路撒冷、以色列 神的，</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 29:6; 以斯拉记 1:4; 历代志上 29:9"> 并带你在巴比伦全省所得的金银，和百姓、祭司乐意献给耶路撒冷—他们 神殿的礼物。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 12:5–11; 民数记 15:4–13; 以斯拉记 6:9–10"> 所以你当用这金银，急速买公牛、公绵羊、绵羊羔，和同献的素祭奠祭之物，献在耶路撒冷—你们 神殿的坛上。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 22:7; 以弗所书 5:17; 列王纪下 12:15"> 剩下的金银，你和你的弟兄看着怎样好，就怎样用，总要遵着你们 神的旨意。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 3:17; 以斯拉记 8:33–34; 历代志下 32:19"> 所交给你 神殿中使用的器皿，你要交在耶路撒冷 神面前。</span>
<span className="v" id="v20" data-v="20" data-xref="以斯拉记 6:4; 以斯拉记 6:8–18"> 你 神殿里若再有需用的经费，你可以从王的府库里支取。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯拉记 4:16; 以斯拉记 7:6; 以斯拉记 7:10–13"> 「我—亚达薛西王又降旨与河西的一切库官，说：『通达天上 神律法的文士祭司以斯拉，无论向你们要什么，你们要速速地备办，</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 16:6–7; 利未记 2:13; 以西结书 45:14"> 就是银子直到一百他连得，麦子一百柯珥，酒一百罢特，油一百罢特，盐不计其数，也要给他。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 119:4; 以斯拉记 7:18; 以斯拉记 6:10–12"> 凡天上之 神所吩咐的，当为天上 神的殿详细办理。为何使忿怒临到王和王众子的国呢？</span>
<span className="v" id="v24" data-v="24" data-xref="以斯拉记 7:7; 以斯拉记 4:13; 以斯拉记 2:36–55"> 我又晓谕你们，至于祭司、利未人、歌唱的、守门的，和尼提宁，并在 神殿当差的人，不可叫他们进贡，交课，纳税。』</span>
<span className="v" id="v25" data-v="25" data-xref="以斯拉记 7:10; 申命记 16:18; 雅各书 1:5"> 「以斯拉啊，要照着你 神赐你的智慧，将所有明白你 神律法的人立为士师、审判官，治理河西的百姓，使他们教训一切不明白 神律法的人。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯拉记 6:11; 申命记 13:1–18; 利未记 20:1–27"> 凡不遵行你 神律法和王命令的人就当速速定他的罪，或治死，或充军，或抄家，或囚禁。」</span>
</div>
</div>

## 以斯拉称颂耶和华

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以斯拉记 6:22; 启示录 17:17; 以赛亚书 60:13"> 以斯拉说：「耶和华—我们列祖的 神是应当称颂的！因他使王起这心意修饰耶路撒冷耶和华的殿，</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太后书 4:17–18; 以斯拉记 5:5; 创世记 32:28"> 又在王和谋士，并大能的军长面前施恩于我。因耶和华—我 神的手帮助我，我就得以坚强，从以色列中招聚首领，与我一同上来。」</span>
</div>

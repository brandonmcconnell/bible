## 从被掳之地回来的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯拉记 7:7; 以斯拉记 2:62; 历代志上 9:1"> 当亚达薛西王年间，同我从巴比伦上来的人，他们的族长和他们的家谱记在下面：</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 3:22; 历代志上 3:1; 历代志上 6:3–15"> 属非尼哈的子孙有革顺；属以他玛的子孙有但以理；属大卫的子孙有哈突；</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 2:3; 尼希米记 10:14; 尼希米记 7:8"> 属巴录的后裔，就是示迦尼的子孙有撒迦利亚，同着他，按家谱计算，男丁一百五十人；</span>
<span className="v" id="v4" data-v="4" data-xref="以斯拉记 2:6; 尼希米记 10:14; 尼希米记 7:11"> 属巴哈·摩押的子孙有西拉希雅的儿子以利约乃，同着他有男丁二百；</span>
<span className="v" id="v5" data-v="5"> 属示迦尼的子孙有雅哈悉的儿子，同着他有男丁三百；</span>
<span className="v" id="v6" data-v="6" data-xref="以斯拉记 2:15; 尼希米记 10:16; 尼希米记 7:20"> 属亚丁的子孙有约拿单的儿子以别，同着他有男丁五十；</span>
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 2:31; 尼希米记 7:34; 以斯拉记 2:7"> 属以拦的子孙有亚他利雅的儿子耶筛亚，同着他有男丁七十；</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米记 11:4; 以斯拉记 2:4; 尼希米记 7:9"> 属示法提雅的子孙有米迦勒的儿子西巴第雅，同着他有男丁八十；</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米记 7:11; 以斯拉记 2:6"> 属约押的子孙有耶歇的儿子俄巴底亚，同着他有男丁二百一十八；</span>
<span className="v" id="v10" data-v="10"> 属示罗密的子孙有约细斐的儿子，同着他有男丁一百六十；</span>
<span className="v" id="v11" data-v="11" data-xref="以斯拉记 10:28; 尼希米记 7:16; 以斯拉记 2:11"> 属比拜的子孙有比拜的儿子撒迦利亚，同着他有男丁二十八；</span>
<span className="v" id="v12" data-v="12" data-xref="以斯拉记 2:12; 尼希米记 7:17"> 属押甲的子孙有哈加坦的儿子约哈难，同着他有男丁一百一十；</span>
<span className="v" id="v13" data-v="13" data-xref="以斯拉记 2:13; 尼希米记 7:18"> 属亚多尼干的子孙，就是末尾的，他们的名字是以利法列、耶利、示玛雅，同着他们有男丁六十；</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 10:12; 以斯拉记 2:14; 尼希米记 7:19"> 属比革瓦伊的子孙有乌太和撒布，同着他们有男丁七十。</span>

## 以斯拉为圣殿招集利未人

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以斯拉记 8:21; 以斯拉记 8:31; 以斯拉记 7:7"> 我招聚这些人在流入亚哈瓦的河边，我们在那里住了三日。我查看百姓和祭司，见没有利未人在那里，</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 2:6; 以斯拉记 8:18; 以斯拉记 10:39"> 就召首领以利以谢、亚列、示玛雅、以利拿单、雅立、以利拿单、拿单、撒迦利亚、米书兰，又召教习约雅立和以利拿单。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯拉记 2:43; 出埃及记 4:15; 民数记 8:22–26"> 我打发他们往迦西斐雅地方去见那里的首领易多，又告诉他们当向易多和他的弟兄尼提宁说什么话，叫他们为我们 神的殿带使用的人来。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 3:15; 以斯拉记 7:28; 尼希米记 2:8"> 蒙我们 神施恩的手帮助我们，他们在以色列的曾孙、利未的孙子、抹利的后裔中带一个通达人来；还有示利比和他的众子与弟兄共一十八人。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 6:1; 历代志上 6:16; 尼希米记 10:11"> 又有哈沙比雅，同着他有米拉利的子孙耶筛亚，并他的众子和弟兄共二十人。</span>
<span className="v" id="v20" data-v="20" data-xref="以斯拉记 2:43; 以斯拉记 7:7; 历代志上 9:2"> 从前大卫和众首领派尼提宁服事利未人，现在从这尼提宁中也带了二百二十人来，都是按名指定的。</span>
</div>
</div>

## 以斯拉领百姓禁食祷告

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="历代志下 20:3; 约珥书 1:14; 撒母耳记上 7:6"> 那时，我在亚哈瓦河边宣告禁食，为要在我们 神面前克苦己心，求他使我们和妇人孩子，并一切所有的，都得平坦的道路。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 3:12; 诗篇 33:18–19; 历代志下 16:9"> 我求王拨步兵马兵帮助我们抵挡路上的仇敌，本以为羞耻；因我曾对王说：「我们 神施恩的手必帮助一切寻求他的；但他的能力和忿怒必攻击一切离弃他的。」</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 29:12–13; 马太福音 7:7–8; 以斯拉记 8:31"> 所以我们禁食祈求我们的 神，他就应允了我们。</span>
</div>
</div>

## 献给圣殿的礼物

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以斯拉记 8:18–19"> 我分派祭司长十二人，就是示利比、哈沙比雅，和他们的弟兄十人，</span>
<span className="v" id="v25" data-v="25" data-xref="以斯拉记 8:33; 以斯拉记 7:14–16; 以斯拉记 1:8"> 将王和谋士、军长，并在那里的以色列众人为我们 神殿所献的金银和器皿，都秤了交给他们。</span>
<span className="v" id="v26" data-v="26" data-xref="以斯拉记 1:9–11"> 我秤了交在他们手中的银子有六百五十他连得；银器重一百他连得；金子一百他连得；</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米哀歌 4:2"> 金碗二十个，重一千达利克；上等光铜的器皿两个，宝贵如金。</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 22:2–3; 利未记 21:6–8; 历代志上 23:28"> 我对他们说：「你们归耶和华为圣，器皿也为圣；金银是甘心献给耶和华—你们列祖之 神的。</span>
<span className="v" id="v29" data-v="29" data-xref="以斯拉记 8:33–34; 马可福音 13:34–35; 历代志上 26:20–26"> 你们当警醒看守，直到你们在耶路撒冷耶和华殿的库内，在祭司长和利未族长，并以色列的各族长面前过了秤。」</span>
<span className="v" id="v30" data-v="30" data-xref="以斯拉记 8:22; 历代志上 29:2–3; 以赛亚书 60:13"> 于是，祭司、利未人按着分量接受金银和器皿，要带到耶路撒冷我们 神的殿里。</span>
</div>
</div>

## 返回耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="以斯拉记 8:21–22; 以斯拉记 7:9; 以斯拉记 8:15"> 正月十二日，我们从亚哈瓦河边起行，要往耶路撒冷去。我们 神的手保佑我们，救我们脱离仇敌和路上埋伏之人的手。</span>
<span className="v" id="v32" data-v="32" data-xref="尼希米记 2:11; 以斯拉记 7:8–9"> 我们到了耶路撒冷，在那里住了三日。</span>
<span className="v" id="v33" data-v="33" data-xref="尼希米记 3:4; 尼希米记 3:21; 以斯拉记 8:30"> 第四日，在我们 神的殿里把金银和器皿都秤了，交在祭司乌利亚的儿子米利末的手中。同着他有非尼哈的儿子以利亚撒，还有利未人耶书亚的儿子约撒拔和宾内的儿子挪亚底。</span>
<span className="v" id="v34" data-v="34"> 当时都点了数目，按着分量写在册上。</span>
<span className="v" id="v35" data-v="35" data-xref="以斯拉记 6:17; 历代志下 29:31–32; 诗篇 66:10–15"> 从掳到之地归回的人向以色列的 神献燔祭，就是为以色列众人献公牛十二只，公绵羊九十六只，绵羊羔七十七只，又献公山羊十二只作赎罪祭，这都是向耶和华焚献的。</span>
<span className="v" id="v36" data-v="36" data-xref="以斯拉记 7:21–24; 以斯拉记 4:7–23; 以斯拉记 6:13"> 他们将王的谕旨交给王所派的总督与河西的省长，他们就帮助百姓，又供给 神殿里所需用的。</span>
</div>

## 恢复敬拜 神的生活

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 4:32; 利未记 23:24; 哥林多前书 1:10"> 到了七月，以色列人住在各城；那时他们如同一人，聚集在耶路撒冷。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 3:17; 以斯拉记 2:2; 哈该书 1:1"> 约萨达的儿子耶书亚和他的弟兄众祭司，并撒拉铁的儿子所罗巴伯与他的弟兄，都起来建筑以色列 神的坛，要照神人摩西律法书上所写的，在坛上献燔祭。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 4:4; 民数记 28:2–8; 以斯拉记 8:21–22"> 他们在原有的根基上筑坛，因惧怕邻国的民，又在其上向耶和华早晚献燔祭，</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米记 8:14–17; 民数记 29:12–38; 出埃及记 23:16"> 又照律法书上所写的守住棚节，按数照例献每日所当献的燔祭；</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 29:39; 民数记 28:19; 出埃及记 29:38–42"> 其后献常献的燔祭，并在月朔与耶和华的一切圣节献祭，又向耶和华献各人的甘心祭。</span>
<span className="v" id="v6" data-v="6"> 从七月初一日起，他们就向耶和华献燔祭。但耶和华殿的根基尚未立定。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 5:6; 使徒行传 9:36; 使徒行传 12:20"> 他们又将银子给石匠、木匠，把粮食、酒、油给西顿人、泰尔人，使他们将香柏树从黎巴嫩运到海里，浮海运到约帕，是照波斯王塞鲁士所允准的。</span>
</div>
</div>

## 开始重建圣殿

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 4:3; 历代志上 23:4; 历代志上 23:24–32"> 百姓到了耶路撒冷 神殿的地方。第二年二月，撒拉铁的儿子所罗巴伯，约萨达的儿子耶书亚和其余的弟兄，就是祭司、利未人，并一切被掳归回耶路撒冷的人，都兴工建造；又派利未人，从二十岁以外的，督理建造耶和华殿的工作。</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉记 2:40; 以斯拉记 3:8; 尼希米记 7:43"> 于是犹大<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="在二章四十节作何达威雅">a</a></sup>的后裔，就是耶书亚和他的子孙与弟兄，甲篾和他的子孙，利未人希拿达的子孙与弟兄，都一同起来，督理那在 神殿做工的人。</span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="历代志上 25:1–7; 历代志上 15:27; 历代志上 16:37"> 匠人立耶和华殿根基的时候，祭司皆穿礼服吹号，亚萨的子孙利未人敲钹，照以色列王大卫所定的例，都站着赞美耶和华。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 16:34; 诗篇 106:1; 诗篇 107:1"> 他们彼此唱和，赞美称谢耶和华说：<br /><span className="pl pl-1">他本为善，</span><br /><span className="pl pl-1">他向以色列人永发慈爱。</span><br />他们赞美耶和华的时候，众民大声呼喊，因耶和华殿的根基已经立定。</span>
<span className="v" id="v12" data-v="12" data-xref="哈该书 2:3; 马太福音 13:31–32; 以赛亚书 60:22"> 然而有许多祭司、利未人、族长，就是见过旧殿的老年人，现在亲眼看见立这殿的根基，便大声哭号，也有许多人大声欢呼，</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 19:37–40; 撒母耳记上 4:5; 尼希米记 12:43"> 甚至百姓不能分辨欢呼的声音和哭号的声音；因为众人大声呼喊，声音听到远处。</span>
</div>
</div>

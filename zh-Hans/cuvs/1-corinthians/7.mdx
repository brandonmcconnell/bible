## 婚姻的问题

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 7:8; 哥林多前书 7:26–27; 哥林多前书 7:37–38"> 论到你们信上所提的事，我说男不近女倒好。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 5:28; 以弗所书 5:33; 哥林多前书 7:9"> 但要免淫乱的事，男子当各有自己的妻子；女子也当各有自己的丈夫。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得前书 3:7; 出埃及记 21:10"> 丈夫当用合宜之分待妻子；妻子待丈夫也要如此。</span>
<span className="v" id="v4" data-v="4" data-xref="何西阿书 3:3; 马太福音 19:9; 马可福音 10:11–12"> 妻子没有权柄主张自己的身子，乃在丈夫；丈夫也没有权柄主张自己的身子，乃在妻子。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 19:15; 约珥书 2:16; 撒迦利亚书 12:12–14"> 夫妻不可彼此亏负，除非两相情愿，暂时分房，为要专心祷告方可；以后仍要同房，免得撒但趁着你们情不自禁，引诱你们。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 8:8; 哥林多前书 7:25; 哥林多前书 7:12"> 我说这话，原是准你们的，不是命你们的。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 19:11–12; 罗马书 12:6; 哥林多前书 9:5"> 我愿意众人像我一样；只是各人领受 神的恩赐，一个是这样，一个是那样。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 7:32; 哥林多前书 7:34–35; 哥林多前书 7:26–27"> 我对着没有嫁娶的和寡妇说，若他们常像我就好。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 7:2; 提摩太前书 5:14; 提摩太前书 5:11"> 倘若自己禁止不住，就可以嫁娶。与其欲火攻心，倒不如嫁娶为妙。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 5:32; 路加福音 16:18; 马太福音 19:3–9"> 至于那已经嫁娶的，我吩咐他们；其实不是我吩咐，乃是主吩咐说：妻子不可离开丈夫，</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 3:1; 哥林多前书 7:10; 以赛亚书 50:1"> 若是离开了，不可再嫁，或是仍同丈夫和好。丈夫也不可离弃妻子。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 11:17; 哥林多前书 7:6; 哥林多前书 7:25"> 我对其余的人说（不是主说）：倘若某弟兄有不信的妻子，妻子也情愿和他同住，他就不要离弃妻子。</span>
<span className="v" id="v13" data-v="13"> 妻子有不信的丈夫，丈夫也情愿和她同住，她就不要离弃丈夫。</span>
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 2:15–16; 提摩太前书 4:5; 提多书 1:15"> 因为不信的丈夫就因着妻子成了圣洁，并且不信的妻子就因着丈夫<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是弟兄">a</a></sup>成了圣洁。不然，你们的儿女就不洁净，但如今他们是圣洁的了。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 14:19; 哥林多后书 13:11; 雅各书 3:17–18"> 倘若那不信的人要离去，就由他离去吧！无论是弟兄，是姊妹，遇着这样的事都不必拘束。 神召我们原是要我们和睦。</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前书 3:1–2; 哥林多前书 9:22; 罗马书 11:14"> 你这作妻子的，怎么知道不能救你的丈夫呢？你这作丈夫的，怎么知道不能救你的妻子呢？</span>
</div>
</div>

## 照主分给各人的去行

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 4:17; 罗马书 12:3–8; 哥林多前书 7:24"> 只要照主所分给各人的，和 神所召各人的而行。我吩咐各教会都是这样。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 15:5; 使徒行传 15:28; 使徒行传 15:24"> 有人已受割礼蒙召呢，就不要废割礼；有人未受割礼蒙召呢，就不要受割礼。</span>
<span className="v" id="v19" data-v="19" data-xref="加拉太书 6:15; 加拉太书 5:6; 约翰一书 2:3–4"> 受割礼算不得什么，不受割礼也算不得什么，只要守 神的诫命就是了。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 7:17; 帖撒罗尼迦前书 4:11; 帖撒罗尼迦后书 3:12"> 各人蒙召的时候是什么身分，仍要守住这身分。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得前书 2:18–24; 歌罗西书 3:11; 路加福音 10:40–41"> 你是作奴隶蒙召的吗？不要因此忧虑；若能以自由，就求自由更好。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:16; 腓利门书 1:16; 歌罗西书 3:22–24"> 因为作奴仆蒙召于主的，就是主所释放的人；作自由之人蒙召的，就是基督的奴仆。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 6:20; 彼得前书 1:18–19; 提多书 2:14"> 你们是重价买来的，不要作人的奴仆。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 7:20; 歌罗西书 3:23–24; 哥林多前书 7:17"> 弟兄们，你们各人蒙召的时候是什么身分，仍要在 神面前守住这身分。</span>
</div>
</div>

## 未婚和寡居

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="哥林多前书 7:6; 哥林多前书 4:2; 哥林多前书 7:40"> 论到童身的人，我没有主的命令，但我既蒙主怜恤能作忠心的人，就把自己的意见告诉你们。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多前书 7:1; 哥林多前书 7:8; 彼得前书 4:17"> 因现今的艰难，据我看来，人不如守素安常才好。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 7:20; 哥林多前书 7:12–14"> 你有妻子缠着呢，就不要求脱离；你没有妻子缠着呢，就不要求妻子。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 13:4; 哥林多前书 7:32–36; 哥林多前书 7:26"> 你若娶妻，并不是犯罪；处女若出嫁，也不是犯罪。然而这等人肉身必受苦难，我却愿意你们免这苦难。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰一书 2:17; 哥林多前书 7:31; 罗马书 13:11–12"> 弟兄们，我对你们说：时候减少了。从此以后，那有妻子的，要像没有妻子；</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 30:5; 路加福音 6:25; 路加福音 6:21"> 哀哭的，要像不哀哭；快乐的，要像不快乐；置买的，要像无有所得；</span>
<span className="v" id="v31" data-v="31" data-xref="约翰一书 2:17; 彼得前书 4:7; 雅各书 4:14"> 用世物的，要像不用世物，因为这世界的样子将要过去了。</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 6:25–34; 提摩太前书 5:5; 腓立比书 4:6"> 我愿你们无所挂虑。没有娶妻的，是为主的事挂虑，想怎样叫主喜悦。</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前书 3:7; 歌罗西书 3:19; 以弗所书 5:25–33"> 娶了妻的，是为世上的事挂虑，想怎样叫妻子喜悦。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 10:40–42; 哥林多前书 6:20; 路加福音 2:36–37"> 妇人和处女也有分别。没有出嫁的，是为主的事挂虑，要身体、灵魂都圣洁；已经出嫁的，是为世上的事挂虑，想怎样叫丈夫喜悦。</span>
<span className="v" id="v35" data-v="35" data-xref="哥林多前书 7:33–34; 哥林多前书 7:36; 路加福音 8:14"> 我说这话是为你们的益处，不是要牢笼你们，乃是要叫你们行合宜的事，得以殷勤服事主，没有分心的事。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="哥林多前书 7:37; 哥林多前书 7:9; 撒母耳记上 2:33"> 若有人以为自己待他的女儿不合宜，女儿也过了年岁，事又当行，他就可随意办理，不算有罪，叫二人成亲就是了。</span>
<span className="v" id="v37" data-v="37"> 倘若人心里坚定，没有不得已的事，并且由得自己作主，心里又决定了留下女儿不出嫁，如此行也好。</span>
<span className="v" id="v38" data-v="38" data-xref="希伯来书 13:4; 哥林多前书 7:1–2; 哥林多前书 7:8"> 这样看来，叫自己的女儿出嫁是好，不叫她出嫁更是好。</span>
<span className="v" id="v39" data-v="39" data-xref="罗马书 7:2–3; 哥林多后书 6:14–16; 哥林多前书 7:10"> 丈夫活着的时候，妻子是被约束的；丈夫若死了，妻子就可以自由，随意再嫁，只是要嫁这在主里面的人。</span>
<span className="v" id="v40" data-v="40" data-xref="哥林多前书 7:35; 彼得后书 3:15–16; 哥林多前书 7:8"> 然而按我的意见，若常守节更有福气。我也想自己是被 神的灵感动了。</span>
</div>
</div>

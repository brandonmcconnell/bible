## 属灵的恩赐

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 12:4–11; 哥林多前书 14:37; 哥林多前书 14:1–18"> 弟兄们，论到属灵的恩赐，我不愿意你们不明白。</span>
<span className="v" id="v2" data-v="2" data-xref="彼得前书 4:3; 帖撒罗尼迦前书 1:9; 诗篇 115:5"> 你们作外邦人的时候，随事被牵引，受迷惑，去服事那哑巴偶像，这是你们知道的。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰一书 4:2–3; 马太福音 16:16–17; 罗马书 10:9"> 所以我告诉你们，被 神的灵感动的，没有说「耶稣是可咒诅」的；若不是被圣灵感动的，也没有能说「耶稣是主」的。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前书 4:10; 哥林多前书 12:28; 罗马书 12:4–6"> 恩赐原有分别，圣灵却是一位。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 4:11–12; 罗马书 12:6–8; 罗马书 14:8–9"> 职事也有分别，主却是一位。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 3:7; 哥林多前书 12:11; 约翰福音 5:17"> 功用也有分别， 神却是一位，在众人里面运行一切的事。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前书 4:10–11; 罗马书 12:6–8; 哥林多前书 14:19"> 圣灵显在各人身上，是叫人得益处。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 2:6; 哥林多前书 2:6–10; 诗篇 143:10"> 这人蒙圣灵赐他智慧的言语，那人也蒙这位圣灵赐他知识的言语，</span>
<span className="v" id="v9" data-v="9" data-xref="雅各书 5:14–15; 哥林多后书 4:13; 以弗所书 2:8"> 又有一人蒙这位圣灵赐他信心，还有一人蒙这位圣灵赐他医病的恩赐，</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 14:39; 约翰一书 4:1; 马可福音 16:17"> 又叫一人能行异能，又叫一人能作先知，又叫一人能辨别诸灵，又叫一人能说方言，又叫一人能翻方言。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 12:4; 希伯来书 2:4; 哥林多后书 10:13"> 这一切都是这位圣灵所运行、随己意分给各人的。</span>
</div>
</div>

## 一个身体有许多肢体

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="罗马书 12:4–5; 歌罗西书 3:15; 哥林多前书 12:27"> 就如身子是一个，却有许多肢体；而且肢体虽多，仍是一个身子；基督也是这样。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 4:5; 歌罗西书 3:11; 加拉太书 3:28"> 我们不拘是犹太人，是希腊人，是为奴的，是自主的，都从一位圣灵受洗，成了一个身体，饮于一位圣灵。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 12:27–28; 哥林多前书 12:12; 以弗所书 4:25"> 身子原不是一个肢体，乃是许多肢体。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 9:8–15; 列王纪下 14:9"> 设若脚说：「我不是手，所以不属乎身子，」它不能因此就不属乎身子。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 12:3; 哥林多前书 12:22; 腓立比书 2:3"> 设若耳说：「我不是眼，所以不属乎身子，」它也不能因此就不属乎身子。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 12:21; 诗篇 139:13–16; 箴言 20:12"> 若全身是眼，从哪里听声呢？若全身是耳，从哪里闻味呢？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 12:28; 罗马书 12:3; 哥林多前书 12:11"> 但如今， 神随自己的意思把肢体俱各安排在身上了。</span>
<span className="v" id="v19" data-v="19"> 若都是一个肢体，身子在哪里呢？</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 12:14; 哥林多前书 12:12"> 但如今肢体是多的，身子却是一个。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯拉记 10:1–5; 尼希米记 4:16–21; 约伯记 29:11"> 眼不能对手说：「我用不着你」；头也不能对脚说：「我用不着你。」</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 14:28; 传道书 9:14–15; 传道书 4:9–12"> 不但如此，身上肢体人以为软弱的，更是不可少的。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 3:21; 创世记 3:7"> 身上肢体，我们看为不体面的，越发给它加上体面；不俊美的，越发得着俊美。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 3:11; 创世记 2:25"> 我们俊美的肢体，自然用不着装饰；但 神配搭这身子，把加倍的体面给那有缺欠的肢体，</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多后书 13:11; 哥林多前书 1:10–12; 约翰福音 17:21–26"> 免得身上分门别类，总要肢体彼此相顾。</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 12:15; 加拉太书 6:2; 希伯来书 13:3"> 若一个肢体受苦，所有的肢体就一同受苦；若一个肢体得荣耀，所有的肢体就一同快乐。</span>
<span className="v" id="v27" data-v="27" data-xref="以弗所书 4:12; 歌罗西书 1:24; 以弗所书 5:30"> 你们就是基督的身子，并且各自作肢体。</span>
<span className="v" id="v28" data-v="28" data-xref="以弗所书 4:11–13; 罗马书 12:6–8; 哥林多前书 12:18"> 神在教会所设立的：第一是使徒，第二是先知，第三是教师，其次是行异能的，再次是得恩赐医病的，帮助人的，治理事的，说方言的。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 12:4–11; 哥林多前书 12:14–20"> 岂都是使徒吗？岂都是先知吗？岂都是教师吗？岂都是行异能的吗？</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前书 12:10"> 岂都是得恩赐医病的吗？岂都是说方言的吗？岂都是翻方言的吗？</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多前书 13:1; 哥林多前书 14:39; 马太福音 5:6"> 你们要切切地求那更大的恩赐。 爱 我现今把最妙的道指示你们。</span>
</div>
</div>

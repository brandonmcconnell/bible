## 说方言和作先知讲道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 14:39; 提摩太前书 4:14; 哥林多前书 12:1"> 你们要追求爱，也要切慕属灵的恩赐，其中更要羡慕的，是作先知讲道<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文作：是说预言；下同">a</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 16:17; 使徒行传 19:6; 使徒行传 10:46"> 那说方言的，原不是对人说，乃是对 神说，因为没有人听出来。然而，他在心灵里却是讲说各样的奥秘。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 14:12; 提摩太前书 4:13; 犹大书 1:20"> 但作先知讲道的，是对人说，要造就、安慰、劝勉人。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 14:22; 哥林多前书 14:26; 马可福音 16:17"> 说方言的，是造就自己；作先知讲道的，乃是造就教会。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 12:28–30; 哥林多前书 12:10; 马可福音 16:17"> 我愿意你们都说方言，更愿意你们作先知讲道；因为说方言的，若不翻出来，使教会被造就，那作先知讲道的，就比他强了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以弗所书 1:17; 罗马书 6:17; 提摩太后书 3:16"> 弟兄们，我到你们那里去，若只说方言，不用启示，或知识，或预言，或教训，给你们讲解，我与你们有什么益处呢？</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 14:8; 路加福音 7:32; 哥林多前书 13:1"> 就是那有声无气的物，或箫，或琴，若发出来的声音没有分别，怎能知道所吹所弹的是什么呢？</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 10:9; 以西结书 33:3–6; 耶利米书 4:19"> 若吹无定的号声，谁能预备打仗呢？</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 9:26"> 你们也是如此。舌头若不说容易明白的话，怎能知道所说的是什么呢？这就是向空说话了。</span>
<span className="v" id="v10" data-v="10"> 世上的声音，或者甚多，却没有一样是无意思的。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 28:2; 罗马书 1:14; 歌罗西书 3:11"> 我若不明白那声音的意思，这说话的人必以我为化外之人，我也以他为化外之人。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 14:26; 哥林多前书 14:3–4; 哥林多前书 14:1"> 你们也是如此，既是切慕属灵的恩赐，就当求多得造就教会的恩赐。</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 11:24; 哥林多前书 12:30; 约翰福音 14:13–14"> 所以那说方言的，就当求着能翻出来。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 14:2; 哥林多前书 14:15–16; 哥林多前书 14:19"> 我若用方言祷告，是我的灵祷告，但我的悟性没有果效。</span>
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 3:16; 约翰福音 4:23–24; 以弗所书 6:18"> 这却怎么样呢？我要用灵祷告，也要用悟性祷告；我要用灵歌唱，也要用悟性歌唱。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 16:36; 诗篇 106:48; 启示录 5:14"> 不然，你用灵祝谢，那在座不通方言的人，既然不明白你的话，怎能在你感谢的时候说「阿们」呢？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 14:4; 哥林多前书 14:6"> 你感谢的固然是好，无奈不能造就别人。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 1:4–6; 哥林多前书 4:7"> 我感谢 神，我说方言比你们众人还多。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 14:21–22; 哥林多前书 14:4"> 但在教会中，宁可用悟性说五句教导人的话，强如说万句方言。</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="彼得前书 2:2; 哥林多前书 13:11; 罗马书 16:19"> 弟兄们，在心志上不要作小孩子。然而，在恶事上要作婴孩，在心志上总要作大人。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 28:11–12; 耶利米书 5:15; 申命记 28:49"> 律法上记着：<br /><span className="pl pl-1">主说：我要用外邦人的舌头</span><br /><span className="pl pl-1">和外邦人的嘴唇向这百姓说话；</span><br /><span className="pl pl-1">虽然如此，</span><br /><span className="pl pl-1">他们还是不听从我。</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 2:6–12; 马可福音 16:17; 哥林多前书 14:1"> 这样看来，说方言不是为信的人作证据，乃是为不信的人；作先知讲道不是为不信的人作证据，乃是为信的人。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 2:13; 使徒行传 26:24; 哥林多前书 11:18"> 所以，全教会聚在一处的时候，若都说方言，偶然有不通方言的，或是不信的人进来，岂不说你们癫狂了吗？</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 2:37; 哥林多前书 2:15; 希伯来书 4:12–13"> 若都作先知讲道，偶然有不信的，或是不通方言的人进来，就被众人劝醒，被众人审明，</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 45:14; 撒迦利亚书 8:23; 诗篇 72:11"> 他心里的隐情显露出来，就必将脸伏地，敬拜 神，说：「 神真是在你们中间了。」</span>
</div>
</div>

## 凡事都要按次序行

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以弗所书 5:19; 罗马书 14:19; 哥林多前书 12:7–10"> 弟兄们，这却怎么样呢？你们聚会的时候，各人或有诗歌，或有教训，或有启示，或有方言，或有翻出来的话，凡事都当造就人。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 14:26"> 若有说方言的，只好两个人，至多三个人，且要轮流着说，也要一个人翻出来。</span>
<span className="v" id="v28" data-v="28"> 若没有人翻，就当在会中闭口，只对自己和 神说就是了。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 12:10; 帖撒罗尼迦前书 5:19–21; 约翰一书 4:1–3"> 至于作先知讲道的，只好两个人或是三个人，其余的就当慎思明辨。</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒罗尼迦前书 5:19–20; 约伯记 33:31–33; 约伯记 32:11"> 若旁边坐着的得了启示，那先说话的就当闭口不言。</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒罗尼迦前书 5:14; 哥林多前书 14:3; 帖撒罗尼迦前书 5:11"> 因为你们都可以一个一个地作先知讲道，叫众人学道理，叫众人得劝勉。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 4:19–20; 约翰一书 4:1; 撒母耳记上 10:10–13"> 先知的灵原是顺服先知的；</span>
<span className="v" id="v33" data-v="33" data-xref="雅各书 3:17–18; 哥林多前书 14:40; 帖撒罗尼迦后书 3:16"> 因为 神不是叫人混乱，乃是叫人安静。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="提摩太前书 2:11–12; 创世记 3:16; 民数记 30:3–13"> 妇女在会中要闭口不言，像在圣徒的众教会一样，因为不准她们说话。她们总要顺服，正如律法所说的。</span>
<span className="v" id="v35" data-v="35" data-xref="以弗所书 5:12; 彼得前书 3:7; 以弗所书 5:25–27"> 她们若要学什么，可以在家里问自己的丈夫，因为妇女在会中说话原是可耻的。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 18:1–17; 撒迦利亚书 14:8; 使徒行传 17:15"> 神的道理岂是从你们出来吗？岂是单临到你们吗？</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="约翰一书 4:6; 哥林多后书 10:7; 彼得后书 3:2"> 若有人以为自己是先知，或是属灵的，就该知道，我所写给你们的是主的命令。</span>
<span className="v" id="v38" data-v="38" data-xref="提摩太后书 4:3–4; 何西阿书 4:17; 启示录 22:11–12"> 若有不知道的，就由他不知道吧！</span>
<span className="v" id="v39" data-v="39" data-xref="哥林多前书 12:31; 哥林多前书 14:1; 帖撒罗尼迦前书 5:20"> 所以我弟兄们，你们要切慕作先知讲道，也不要禁止说方言。</span>
<span className="v" id="v40" data-v="40" data-xref="歌罗西书 2:5; 提多书 1:5; 哥林多前书 14:26–33"> 凡事都要规规矩矩地按着次序行。</span>
</div>
</div>

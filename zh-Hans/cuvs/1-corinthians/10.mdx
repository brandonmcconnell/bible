## 警戒拜偶像的事

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 14:29; 尼希米记 9:11–12; 诗篇 78:13–14"> 弟兄们，我不愿意你们不晓得，我们的祖宗从前都在云下，都从海中经过，</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 3:2–3; 哥林多前书 1:13–16; 出埃及记 14:31"> 都在云里、海里受洗归了摩西；</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 8:3; 尼希米记 9:15; 出埃及记 16:35"> 并且都吃了一样的灵食，</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 17:6; 约翰福音 7:37; 以赛亚书 48:21"> 也都喝了一样的灵水。所喝的，是出于随着他们的灵磐石；那磐石就是基督。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 3:17; 犹大书 1:5; 民数记 14:37"> 但他们中间多半是 神不喜欢的人，所以在旷野倒毙。</span>
<span className="v" id="v6" data-v="6" data-xref="犹大书 1:7; 哥林多前书 10:11; 希伯来书 4:11"> 这些事都是我们的鉴戒，叫我们不要贪恋恶事，像他们那样贪恋的；</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 32:6–8; 诗篇 106:19–20; 哥林多前书 6:9"> 也不要拜偶像，像他们有人拜的。如经上所记：「百姓坐下吃喝，起来玩耍。」</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 25:1–9; 哥林多前书 6:18; 诗篇 106:29"> 我们也不要行奸淫，像他们有人行的，一天就倒毙了二万三千人；</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 21:5–6; 诗篇 78:18; 希伯来书 3:8–11"> 也不要试探主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷：基督">a</a></sup>，像他们有人试探的，就被蛇所灭。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 14:2; 民数记 16:41; 民数记 14:37"> 你们也不要发怨言，像他们有发怨言的，就被灭命的所灭。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 15:4; 罗马书 13:11; 哥林多前书 9:10"> 他们遭遇这些事都要作为鉴戒，并且写在经上，正是警戒我们这末世的人。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 11:20; 彼得后书 3:17; 箴言 16:18"> 所以，自己以为站得稳的，须要谨慎，免得跌倒。</span>
<span className="v" id="v13" data-v="13" data-xref="彼得后书 2:9; 提摩太后书 4:18; 帖撒罗尼迦后书 3:3"> 你们所遇见的试探，无非是人所能受的。 神是信实的，必不叫你们受试探过于所能受的；在受试探的时候，总要给你们开一条出路，叫你们能忍受得住。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 21:8; 约翰一书 5:21; 彼得前书 2:11"> 我所亲爱的弟兄啊，你们要逃避拜偶像的事。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 8:1; 帖撒罗尼迦前书 5:21; 哥林多前书 11:13"> 我好像对明白人说的，你们要审察我的话。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 26:26–28; 哥林多前书 11:23–29; 使徒行传 2:42"> 我们所祝福的杯，岂不是同领基督的血吗？我们所擘开的饼，岂不是同领基督的身体吗？</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 12:5; 歌罗西书 3:15; 哥林多前书 12:27"> 我们虽多，仍是一个饼，一个身体，因为我们都是分受这一个饼。</span>
<span className="v" id="v18" data-v="18" data-xref="腓立比书 3:3–5; 加拉太书 6:16; 利未记 7:6"> 你们看属肉体的以色列人，那吃祭物的岂不是在祭坛上有分吗？</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 8:4; 哥林多前书 3:7; 哥林多前书 13:2"> 我是怎么说呢？岂是说祭偶像之物算得什么呢？或说偶像算得什么呢？</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 9:20; 诗篇 106:37–39; 申命记 32:16–17"> 我乃是说，外邦人所献的祭是祭鬼，不是祭 神。我不愿意你们与鬼相交。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 6:24; 列王纪上 18:21; 哥林多后书 6:15–17"> 你们不能喝主的杯又喝鬼的杯，不能吃主的筵席又吃鬼的筵席。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 32:21; 申命记 32:16; 希伯来书 10:31"> 我们可惹主的愤恨吗？我们比他还有能力吗？</span>
</div>
</div>

## 凡事为荣耀 神而行

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 6:12; 哥林多前书 8:9; 以弗所书 4:29"> 凡事都可行，但不都有益处。凡事都可行，但不都造就人。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 15:1–2; 哥林多前书 10:33; 腓立比书 2:4–5"> 无论何人，不要求自己的益处，乃要求别人的益处。</span>
<span className="v" id="v25" data-v="25" data-xref="提摩太前书 4:4; 哥林多前书 8:7; 提多书 1:15"> 凡市上所卖的，你们只管吃，不要为良心的缘故问什么话，</span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 24:1; 出埃及记 19:5; 诗篇 50:12"> 因为地和其中所充满的都属乎主。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 10:25; 路加福音 10:7–8; 哥林多前书 5:9–11"> 倘有一个不信的人请你们赴席，你们若愿意去，凡摆在你们面前的，只管吃，不要为良心的缘故问什么话。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 8:10–13; 哥林多前书 8:7; 哥林多前书 10:26"> 若有人对你们说：「这是献过祭的物」，就要为那告诉你们的人，并为良心的缘故不吃。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 9:19; 罗马书 14:15–21; 哥林多前书 8:9–13"> 我说的良心不是你的，乃是他的。我这自由为什么被别人的良心论断呢？</span>
<span className="v" id="v30" data-v="30" data-xref="罗马书 14:6; 提摩太前书 4:3–4"> 我若谢恩而吃，为什么因我谢恩的物被人毁谤呢？</span>
<span className="v" id="v31" data-v="31" data-xref="歌罗西书 3:17; 歌罗西书 3:23; 彼得前书 4:11"> 所以，你们或吃或喝，无论做什么，都要为荣耀 神而行。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 20:28; 哥林多前书 10:33; 罗马书 14:13"> 不拘是犹太人，是希腊人，是 神的教会，你们都不要使他跌倒；</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 10:24; 加拉太书 1:10; 哥林多前书 9:19–23"> 就好像我凡事都叫众人喜欢，不求自己的益处，只求众人的益处，叫他们得救。</span>
</div>
</div>

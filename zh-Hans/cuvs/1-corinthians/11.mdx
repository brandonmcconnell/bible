## 礼拜时蒙头的问题

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦后书 2:15; 哥林多前书 4:17; 箴言 31:28–31"> 我称赞你们，因你们凡事记念我，又坚守我所传给你们的。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 3:16; 歌罗西书 1:18; 歌罗西书 3:18"> 我愿意你们知道，基督是各人的头；男人是女人的头； 神是基督的头。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 15:30; 哥林多前书 12:28; 哥林多前书 12:10"> 凡男人祷告或是讲道<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：说预言；下同">a</a></sup>，若蒙着头，就羞辱自己的头。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 21:12; 路加福音 2:36; 使徒行传 2:17"> 凡女人祷告或是讲道，若不蒙着头，就羞辱自己的头，因为这就如同剃了头发一样。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 22:5; 民数记 5:18"> 女人若不蒙着头，就该剪了头发；女人若以剪发、剃发为羞愧，就该蒙着头。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 11:3; 创世记 5:1; 诗篇 8:6"> 男人本不该蒙着头，因为他是 神的形象和荣耀；但女人是男人的荣耀。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太前书 2:13; 创世记 2:21–23"> 起初，男人不是由女人而出，女人乃是由男人而出；</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 2:18; 创世记 2:23–24; 创世记 2:20"> 并且男人不是为女人造的，女人乃是为男人造的。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 24:64–65; 希伯来书 1:14; 马太福音 18:10"> 因此，女人为天使的缘故，应当在头上有服权柄的记号。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太书 3:28; 哥林多前书 7:10–14; 哥林多前书 12:12–22"> 然而照主的安排，女也不是无男，男也不是无女。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 11:36; 哥林多前书 8:6; 希伯来书 1:2–3"> 因为女人原是由男人而出，男人也是由女人而出；但万有都是出乎 神。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:57; 约翰福音 7:24; 哥林多前书 10:15"> 你们自己审察，女人祷告 神，不蒙着头是合宜的吗？</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 14:26; 哥林多前书 14:35"> 你们的本性不也指示你们，男人若有长头发，便是他的羞辱吗？</span>
<span className="v" id="v15" data-v="15"> 但女人有长头发，乃是她的荣耀，因为这头发是给她作盖头的。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 7:17; 提摩太前书 6:3–4; 帖撒罗尼迦前书 2:14"> 若有人想要辩驳，我们却没有这样的规矩， 神的众教会也是没有的。</span>
</div>
</div>

## 圣餐时的混乱

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="希伯来书 10:25; 哥林多前书 14:23; 哥林多前书 11:22"> 我现今吩咐你们的话，不是称赞你们；因为你们聚会不是受益，乃是招损。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 3:3; 哥林多前书 1:10–12; 哥林多前书 5:1"> 第一，我听说，你们聚会的时候彼此分门别类，我也稍微地信这话。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 2:19; 提多书 3:10; 使徒行传 20:30"> 在你们中间不免有分门结党的事，好叫那些有经验的人显明出来。</span>
<span className="v" id="v20" data-v="20"> 你们聚会的时候，算不得吃主的晚餐；</span>
<span className="v" id="v21" data-v="21" data-xref="彼得后书 2:13; 犹大书 1:12; 哥林多前书 11:23–25"> 因为吃的时候，各人先吃自己的饭，甚至这个饥饿，那个酒醉。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 20:28; 箴言 17:5; 雅各书 2:5–6"> 你们要吃喝，难道没有家吗？还是藐视 神的教会，叫那没有的羞愧呢？我向你们可怎么说呢？可因此称赞你们吗？我不称赞！</span>
</div>
</div>

## 圣餐的设立

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 22:19–20; 马太福音 26:26–28; 哥林多前书 11:23–25"> 我当日传给你们的，原是从主领受的，就是主耶稣被卖的那一夜，拿起饼来，</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 6:53–58; 哥林多前书 11:27–28; 哥林多前书 10:3–4"> 祝谢了，就擘开，说：「这是我的身体，为你们舍<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷：擘开">b</a></sup>的，你们应当如此行，为的是记念我。」</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 22:20; 希伯来书 9:15–20; 希伯来书 13:20"> 饭后，也照样拿起杯来，说：「这杯是用我的血所立的新约，你们每逢喝的时候，要如此行，为的是记念我。」</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 9:28; 启示录 1:7; 约翰福音 14:3"> 你们每逢吃这饼，喝这杯，是表明主的死，直等到他来。</span>
</div>
</div>

## 不按理吃主的晚餐

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约翰福音 6:51; 哥林多前书 10:21; 希伯来书 10:29"> 所以，无论何人，不按理吃主的饼，喝主的杯，就是干犯主的身、主的血了。</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太书 6:4; 哥林多后书 13:5; 耶利米哀歌 3:40"> 人应当自己省察，然后吃这饼、喝这杯。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 11:27; 哥林多前书 11:30; 哥林多前书 11:32–34"> 因为人吃喝，若不分辨是主的身体，就是吃喝自己的罪了。</span>
<span className="v" id="v30" data-v="30" data-xref="启示录 3:19; 民数记 20:12; 阿摩司书 3:2"> 因此，在你们中间有好些软弱的与患病的，死<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是睡">c</a></sup>的也不少。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰一书 1:9; 诗篇 32:3–5; 启示录 2:5"> 我们若是先分辨自己，就不至于受审。</span>
<span className="v" id="v32" data-v="32" data-xref="希伯来书 12:5–11; 诗篇 118:18; 箴言 3:11–12"> 我们受审的时候，乃是被主惩治，免得我们和世人一同定罪。</span>
<span className="v" id="v33" data-v="33"> 所以我弟兄们，你们聚会吃的时候，要彼此等待。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 11:21–22; 哥林多前书 7:17; 哥林多前书 4:19"> 若有人饥饿，可以在家里先吃，免得你们聚会，自己取罪。其余的事，我来的时候再安排。</span>
</div>

<div className="bt">
<div className="bp">

<span className="v" id="v2" data-v="2" data-xref="玛拉基书 3:9–10; 申命记 15:11–14; 申命记 8:18"> 每逢七日的第一日，各人要照自己的进项抽出来留着，免得我来的时候现凑。</span>

<span className="v" id="v4" data-v="4" data-xref="哥林多后书 8:4; 哥林多后书 8:19; 罗马书 15:25"> 若我也该去，他们可以和我同去。</span>

## 行程的计划

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 19:21; 哥林多前书 4:19; 哥林多后书 1:15–17"> 我要从马其顿经过；既经过了，就要到你们那里去，</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 15:3; 罗马书 15:24; 使徒行传 20:38"> 或者和你们同住几时，或者也过冬。无论我往哪里去，你们就可以给我送行。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 18:21; 哥林多前书 4:19; 雅各书 4:15"> 我如今不愿意路过见你们；主若许我，我就指望和你们同住几时。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 2:1; 出埃及记 23:16; 使徒行传 18:19"> 但我要仍旧住在以弗所，直等到五旬节；</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 2:12; 使徒行传 14:27; 歌罗西书 4:3"> 因为有宽大又有功效的门为我开了，并且反对的人也多。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 15:58; 帖撒罗尼迦前书 3:2; 罗马书 16:21"> 若是提摩太来到，你们要留心，叫他在你们那里无所惧怕；因为他劳力做主的工，像我一样。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 4:12; 使徒行传 15:33; 提多书 2:15"> 所以，无论谁都不可藐视他，只要送他平安前行，叫他到我这里来，因我指望他和弟兄们同来。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 1:12; 哥林多前书 3:5; 提多书 3:4"> 至于兄弟亚波罗，我再三地劝他同弟兄们到你们那里去；但这时他决不愿意去，几时有了机会他必去。</span>
</div>
</div>

## 请求和问安

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约书亚记 1:9; 以弗所书 6:13–18; 以弗所书 6:10"> 你们务要警醒，在真道上站立得稳，要作大丈夫，要刚强。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 13:34–35; 彼得前书 4:8; 提摩太前书 1:5"> 凡你们所做的都要凭爱心而做。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 1:16; 罗马书 16:5; 罗马书 16:2"> 弟兄们，你们晓得司提反一家，是亚该亚初结的果子，并且他们专以服事圣徒为念。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 13:17; 帖撒罗尼迦前书 5:12; 约翰三书 1:8"> 我劝你们顺服这样的人，并一切同工同劳的人。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 11:9; 腓立比书 2:30; 腓利门书 1:13"> 司提反和福徒拿都，并亚该古到这里来，我很喜欢；因为你们待我有不及之处，他们补上了。</span>
<span className="v" id="v18" data-v="18" data-xref="腓利门书 1:7; 哥林多后书 7:13; 帖撒罗尼迦前书 5:12"> 他们叫我和你们心里都快活。这样的人，你们务要敬重。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 18:2; 腓利门书 1:2; 罗马书 16:3–5"> 亚细亚的众教会问你们安。亚居拉和百基拉并在他们家里的教会，因主多多地问你们安。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 16:16; 帖撒罗尼迦前书 5:26; 彼得前书 5:14"> 众弟兄都问你们安。你们要亲嘴问安，彼此务要圣洁。</span>
<span className="v" id="v21" data-v="21" data-xref="歌罗西书 4:18; 加拉太书 6:11; 帖撒罗尼迦后书 3:17"> 我—保罗亲笔问安。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 6:24; 约翰福音 14:21; 哥林多后书 5:14–15"> 若有人不爱主，这人可诅可咒。主必要来！</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 16:20; 罗马书 16:23"> 愿主耶稣基督的恩常与你们众人同在！</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 14:16; 启示录 3:19; 哥林多后书 12:15"> 我在基督耶稣里的爱与你们众人同在。阿们！</span>
</div>

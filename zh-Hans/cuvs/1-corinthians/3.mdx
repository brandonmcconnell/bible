## 神的同工

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 5:13; 哥林多前书 2:14–15; 以弗所书 4:13–14"> 弟兄们，我从前对你们说话，不能把你们当作属灵的，只得把你们当作属肉体，在基督里为婴孩的。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 5:11–14; 约翰福音 16:12; 彼得前书 2:2"> 我是用奶喂你们，没有用饭喂你们。那时你们不能吃，就是如今还是不能。</span>
<span className="v" id="v3" data-v="3" data-xref="雅各书 3:16; 加拉太书 5:15; 提多书 3:3"> 你们仍是属肉体的，因为在你们中间有嫉妒、纷争，这岂不是属乎肉体、照着世人的样子行吗？</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 1:12; 哥林多前书 3:3; 哥林多前书 4:6"> 有说：「我是属保罗的」；有说：「我是属亚波罗的。」这岂不是你们和世人一样吗？</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 6:4; 哥林多后书 6:1; 彼得前书 4:10"> 亚波罗算什么？保罗算什么？无非是执事，照主所赐给他们各人的，引导你们相信。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 3:9–10; 箴言 11:25; 哥林多后书 10:14–15"> 我栽种了，亚波罗浇灌了，惟有 神叫他生长。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 15:5; 加拉太书 6:3; 诗篇 115:1"> 可见栽种的，算不得什么，浇灌的，也算不得什么；只在那叫他生长的 神。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 2:6; 马太福音 16:27; 约翰二书 1:8"> 栽种的和浇灌的，都是一样，但将来各人要照自己的工夫得自己的赏赐。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 2:5; 以弗所书 2:20–22; 哥林多后书 6:1"> 因为我们是与 神同工的；你们是 神所耕种的田地，所建造的房屋。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 3:11; 以弗所书 2:20; 罗马书 15:20"> 我照 神所给我的恩，好像一个聪明的工头，立好了根基，有别人在上面建造；只是各人要谨慎怎样在上面建造。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 2:20; 以赛亚书 28:16; 提摩太后书 2:19"> 因为那已经立好的根基就是耶稣基督，此外没有人能立别的根基。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太后书 4:3; 提摩太后书 3:7; 提摩太后书 2:20"> 若有人用金、银、宝石、草木、禾秸在这根基上建造，</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前书 1:7; 哥林多前书 3:14–15; 启示录 20:12"> 各人的工程必然显露，因为那日子要将它表明出来，有火发现；这火要试验各人的工程怎样。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 3:8; 马太福音 25:21–23; 哥林多前书 4:5"> 人在那根基上所建造的工程若存得住，他就要得赏赐。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰二书 1:8; 哥林多前书 3:12–13; 犹大书 1:23"> 人的工程若被烧了，他就要受亏损，自己却要得救；虽然得救，乃像从火里经过的一样。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 6:19; 以西结书 36:27; 哥林多后书 6:16"> 岂不知你们是 神的殿， 神的灵住在你们里头吗？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 6:18–20; 以西结书 43:12; 民数记 19:20"> 若有人毁坏 神的殿， 神必要毁坏那人；因为 神的殿是圣的，这殿就是你们。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="箴言 3:5; 以赛亚书 5:21; 加拉太书 6:3"> 人不可自欺。你们中间若有人在这世界自以为有智慧，倒不如变作愚拙，好成为有智慧的。</span>
<span className="v" id="v19" data-v="19" data-xref="约伯记 5:13; 诗篇 141:10; 哥林多前书 1:19–20"> 因这世界的智慧，在 神看是愚拙。如经上记着说：「主叫有智慧的，中了自己的诡计」；</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 94:11; 歌罗西书 2:8; 罗马书 1:21"> 又说：「主知道智慧人的意念是虚妄的。」</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 8:32; 罗马书 8:28; 耶利米书 9:23–24"> 所以无论谁，都不可拿人夸口，因为万有全是你们的。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 4:11–12; 腓立比书 1:21; 哥林多前书 9:19–22"> 或保罗，或亚波罗，或矶法，或世界，或生，或死，或现今的事，或将来的事，全是你们的；</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 3:29; 哥林多前书 11:3; 约翰福音 17:9–10"> 并且你们是属基督的，基督又是属 神的。</span>
</div>
</div>

## 活石和圣洁的国度

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以弗所书 4:31; 雅各书 1:21; 雅各书 4:11"> 所以，你们既除去一切的恶毒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：阴毒">a</a></sup>、诡诈，并假善、嫉妒，和一切毁谤的话，</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 5:12–13; 以弗所书 4:15; 彼得后书 3:18"> 就要爱慕那纯净的灵奶，像才生的婴孩爱慕奶一样，叫你们因此渐长，以致得救。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 34:8; 希伯来书 6:5–6; 诗篇 63:5"> 你们若尝过主恩的滋味，就必如此。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 118:22–23; 使徒行传 4:11–12; 彼得前书 2:7"> 主乃活石，固然是被人所弃的，却是被 神所拣选、所宝贵的。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 2:20–22; 彼得前书 2:9; 哥林多前书 3:9"> 你们来到主面前，也就像活石，被建造成为灵宫，作圣洁的祭司，借着耶稣基督奉献 神所悦纳的灵祭。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 28:16; 罗马书 9:32–33; 彼得前书 2:4"> 因为经上说：<br /><span className="pl pl-1">看哪，我把所拣选、</span><br /><span className="pl pl-1">所宝贵的房角石安放在锡安；</span><br /><span className="pl pl-1">信靠他的人必不至于羞愧。</span></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 118:22–23; 马可福音 12:10–11; 使徒行传 4:11–12"> 所以，他在你们信的人就为宝贵，在那不信的人有话说：<br /><span className="pl pl-1">匠人所弃的石头</span><br /><span className="pl pl-1">已作了房角的头块石头。</span></span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 8:14; 哥林多前书 1:23; 罗马书 9:32–33"> 又说：作了绊脚的石头，跌人的磐石。他们既不顺从，就在道理上绊跌<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：他们绊跌都因不顺从道理">b</a></sup>；他们这样绊跌也是预定的。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 19:5–6; 申命记 7:6; 启示录 1:6"> 惟有你们是被拣选的族类，是有君尊的祭司，是圣洁的国度，是属 神的子民，要叫你们宣扬那召你们出黑暗入奇妙光明者的美德。</span>
<span className="v" id="v10" data-v="10" data-xref="何西阿书 2:23; 希伯来书 4:16; 何西阿书 1:9–10"> <span className="pl pl-1">你们从前算不得子民，</span><br /><span className="pl pl-1">现在却作了 神的子民；</span><br /><span className="pl pl-1">从前未曾蒙怜恤，</span><br /><span className="pl pl-1">现在却蒙了怜恤。</span></span>
</div>
</div>

## 作 神的仆人

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约翰一书 2:15–17; 加拉太书 5:24; 彼得前书 4:2"> 亲爱的弟兄啊，你们是客旅，是寄居的。我劝你们要禁戒肉体的私欲；这私欲是与灵魂争战的。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 3:16; 马太福音 5:16; 提多书 2:7–8"> 你们在外邦人中，应当品行端正，叫那些毁谤你们是作恶的，因看见你们的好行为，便在鉴察<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或译：眷顾">c</a></sup>的日子归荣耀给 神。</span>
<span className="v" id="v13" data-v="13" data-xref="提多书 3:1; 罗马书 13:1–7; 提摩太前书 2:1–2"> 你们为主的缘故，要顺服人的一切制度，或是在上的君王，</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 13:3–4"> 或是君王所派罚恶赏善的臣宰。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 3:17; 提多书 2:8; 马太福音 7:26"> 因为 神的旨意原是要你们行善，可以堵住那糊涂无知人的口。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太书 5:13; 罗马书 6:22; 罗马书 6:18"> 你们虽是自由的，却不可借着自由遮盖恶毒<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或译：阴毒">d</a></sup>，总要作 神的仆人。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 24:21; 罗马书 12:10; 罗马书 13:7"> 务要尊敬众人，亲爱教中的弟兄，敬畏 神，尊敬君王。</span>
</div>
</div>

## 基督受苦的榜样

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="提多书 2:9–10; 以弗所书 6:5–7; 歌罗西书 3:22–25"> 你们作仆人的，凡事要存敬畏的心顺服主人；不但顺服那善良温和的，就是那乖僻的也要顺服。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 5:10–12; 彼得前书 3:14–17; 彼得前书 2:20"> 倘若人为叫良心对得住 神，就忍受冤屈的苦楚，这是可喜爱的。</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前书 2:19; 彼得前书 3:17; 马太福音 5:10–12"> 你们若因犯罪受责打，能忍耐，有什么可夸的呢？但你们若因行善受苦，能忍耐，这在 神看是可喜爱的。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 2:6; 马太福音 16:24; 约翰福音 13:15"> 你们蒙召原是为此；因基督也为你们受过苦，给你们留下榜样，叫你们跟随他的脚踪行。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 53:9; 哥林多后书 5:21; 希伯来书 4:15"> 他并没有犯罪，口里也没有诡诈。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 53:7; 彼得前书 4:19; 希伯来书 12:3"> 他被骂不还口；受害不说威吓的话，只将自己交托那按公义审判人的主。</span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 53:4–6; 马太福音 8:17; 罗马书 6:11"> 他被挂在木头上，亲身担当了我们的罪，使我们既然在罪上死，就得以在义上活。因他受的鞭伤，你们便得了医治。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 53:6; 以西结书 34:6; 路加福音 15:4–6"> 你们从前好像迷路的羊，如今却归到你们灵魂的牧人监督了。</span>
</div>

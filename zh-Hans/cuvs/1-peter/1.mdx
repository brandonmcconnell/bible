## 问候

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="雅各书 1:1; 使徒行传 2:5–11; 希伯来书 11:13"> 耶稣基督的使徒彼得写信给那分散在本都、加拉太、加帕多家、亚细亚、庇推尼寄居的，</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦后书 2:13; 以弗所书 1:4–5; 希伯来书 12:24"> 就是照父 神的先见被拣选，借着圣灵得成圣洁，以致顺服耶稣基督，又蒙他血所洒的人。愿恩惠、平安多多地加给你们。</span>

## 活的盼望

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="彼得前书 1:23; 约翰一书 5:4; 罗马书 15:13"> 愿颂赞归与我们主耶稣基督的父 神！他曾照自己的大怜悯，借耶稣基督从死里复活，重生了我们，叫我们有活泼的盼望，</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 21:27; 希伯来书 9:15; 彼得前书 5:4"> 可以得着不能朽坏、不能玷污、不能衰残、为你们存留在天上的基业。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 1:6; 以弗所书 2:8; 帖撒罗尼迦后书 2:13–14"> 你们这因信蒙 神能力保守的人，必能得着所预备、到末世要显现的救恩。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 1:2; 彼得前书 5:10; 罗马书 12:12"> 因此，你们是大有喜乐；但如今，在百般的试炼中暂时忧愁，</span>
<span className="v" id="v7" data-v="7" data-xref="约伯记 23:10; 以赛亚书 48:10; 彼得前书 4:12"> 叫你们的信心既被试验，就比那被火试验仍然能坏的金子更显宝贵，可以在耶稣基督显现的时候得着称赞、荣耀、尊贵。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 20:29; 哥林多后书 5:7; 罗马书 15:13"> 你们虽然没有见过他，却是爱他；如今虽不得看见，却因信他就有说不出来、满有荣光的大喜乐；</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 6:22; 雅各书 1:21; 希伯来书 11:13"> 并且得着你们信心的果效，就是灵魂的救恩。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 13:17; 路加福音 10:24; 路加福音 24:25–27"> 论到这救恩，那预先说你们要得恩典的众先知早已详细地寻求考察，</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 52:13–14; 彼得后书 1:21; 路加福音 24:25–27"> 就是考察在他们心里基督的灵，预先证明基督受苦难，后来得荣耀，是指着什么时候，并怎样的时候。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 15:26; 哥林多前书 2:10; 以弗所书 3:10"> 他们得了启示，知道他们所传讲<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是服事">a</a></sup>的一切事，不是为自己，乃是为你们。那靠着从天上差来的圣灵传福音给你们的人，现在将这些事报给你们；天使也愿意详细察看这些事。</span>
</div>
</div>

## 应当过圣洁的生活

<div className="bt">
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="彼得前书 5:8; 路加福音 12:35; 彼得前书 4:7"> 所以要约束你们的心<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是束上你们心中的腰">b</a></sup>，谨慎自守，专心盼望耶稣基督显现的时候所带来给你们的恩。</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 12:2; 提多书 3:3–5; 彼得前书 4:2–3"> 你们既作顺命的儿女，就不要效法从前蒙昧无知的时候那放纵私欲的样子。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 5:48; 哥林多后书 7:1; 希伯来书 12:14"> 那召你们的既是圣洁，你们在一切所行的事上也要圣洁。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 11:44; 利未记 19:2; 利未记 20:7"> 因为经上记着说：「你们要圣洁，因为我是圣洁的。」</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 10:34–35; 历代志下 19:7; 马太福音 6:9"> 你们既称那不偏待人、按各人行为审判人的主为父，就当存敬畏的心度你们在世寄居的日子，</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 6:20; 提多书 2:14; 诗篇 49:7–8"> 知道你们得赎，脱去你们祖宗所传流虚妄的行为，不是凭着能坏的金银等物，</span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 1:7; 彼得前书 2:22–24; 约翰福音 1:29"> 乃是凭着基督的宝血，如同无瑕疵、无玷污的羔羊之血。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 1:4; 提摩太后书 1:9–10; 希伯来书 9:26"> 基督在创世以前是预先被 神知道的，却在这末世才为你们显现。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 2:24; 希伯来书 2:9; 约翰福音 12:44"> 你们也因着他，信那叫他从死里复活、又给他荣耀的 神，叫你们的信心和盼望都在于 神。</span>
<span className="v" id="v22" data-v="22" data-xref="提摩太前书 1:5; 希伯来书 13:1; 罗马书 12:9–10"> 你们既因顺从真理，洁净了自己的心，以致爱弟兄没有虚假，就当从心里<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="从心里：有古卷是从清洁的心">c</a></sup>彼此切实相爱。</span>
<span className="v" id="v23" data-v="23" data-xref="彼得前书 1:3; 希伯来书 4:12; 约翰福音 1:13"> 你们蒙了重生，不是由于能坏的种子，乃是由于不能坏的种子，是借着 神活泼常存的道。</span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 40:6–8; 诗篇 103:15; 雅各书 4:14"> 因为<br /><span className="pl pl-1">凡有血气的，尽都如草；</span><br /><span className="pl pl-1">他的美荣都像草上的花。</span><br /><span className="pl pl-1">草必枯干，花必凋谢；</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 40:8; 马太福音 5:18; 诗篇 119:89"> <span className="pl pl-1">惟有主的道是永存的。</span>所传给你们的福音就是这道。</span>
</div>
</div>

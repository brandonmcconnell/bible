## 约书亚继承摩西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 摩西去告诉以色列众人</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 34:7; 民数记 27:17; 列王纪上 3:7"> 说：「我现在一百二十岁了，不能照常出入；耶和华也曾对我说：『你必不得过这约旦河。』</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 9:3; 申命记 31:23; 申命记 3:28"> 耶和华—你们的 神必引导你们过去，将这些国民在你们面前灭绝，你们就得他们的地。约书亚必引导你们过去，正如耶和华所说的。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 23:28–31; 申命记 2:33; 申命记 3:3–11"> 耶和华必待他们，如同从前待他所灭绝的亚摩利二王西宏与噩以及他们的国一样。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 7:2; 申命记 20:16–17; 出埃及记 23:32–33"> 耶和华必将他们交给你们；你们要照我所吩咐的一切命令待他们。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 1:9; 以弗所书 6:10; 诗篇 27:14"> 你们当刚强壮胆，不要害怕，也不要畏惧他们，因为耶和华—你的 神和你同去。他必不撇下你，也不丢弃你。」</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 3:28; 申命记 31:6; 申命记 1:38"> 摩西召了约书亚来，在以色列众人眼前对他说：「你当刚强壮胆！因为，你要和这百姓一同进入耶和华向他们列祖起誓应许所赐之地；你也要使他们承受那地为业。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 33:14; 申命记 31:6; 约书亚记 1:9"> 耶和华必在你前面行；他必与你同在，必不撇下你，也不丢弃你。不要惧怕，也不要惊惶。」</span>
</div>
</div>

## 每七年诵读律法一次

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数记 4:15; 约书亚记 3:3; 申命记 17:18"> 摩西将这律法写出来，交给抬耶和华约柜的祭司利未子孙和以色列的众长老。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 23:34–43; 申命记 15:1–2"> 摩西吩咐他们说：「每逢七年的末一年，就在豁免年的定期住棚节的时候，</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 23:2; 约书亚记 8:34–35; 申命记 16:16–17"> 以色列众人来到耶和华—你 神所选择的地方朝见他。那时，你要在以色列众人面前将这律法念给他们听。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 4:10; 诗篇 34:11–14; 申命记 6:6–7"> 要招聚他们男、女、孩子，并城里寄居的，使他们听，使他们学习，好敬畏耶和华—你们的 神，谨守、遵行这律法的一切话，</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 11:2; 申命记 6:7; 箴言 22:6"> 也使他们未曾晓得这律法的儿女得以听见，学习敬畏耶和华—你们的 神，在你们过约旦河要得为业之地，存活的日子，常常这样行。」</span>
</div>
</div>

## 对摩西和约书亚的最后嘱咐

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 27:13; 申命记 31:23; 约伯记 2:1"> 耶和华对摩西说：「你的死期临近了；要召约书亚来，你们二人站在会幕里，我好嘱咐他。」于是摩西和约书亚去站在会幕里。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 40:38; 诗篇 99:7; 出埃及记 33:9–10"> 耶和华在会幕里云柱中显现，云柱停在会幕门以上。</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 10:6; 士师记 10:13; 士师记 2:12"> 耶和华又对摩西说：「你必和你列祖同睡。这百姓要起来，在他们所要去的地上，在那地的人中，随从外邦神行邪淫，离弃我，违背我与他们所立的约。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 14:42; 以赛亚书 8:17; 诗篇 104:29"> 那时，我的怒气必向他们发作；我也必离弃他们，掩面不顾他们，以致他们被吞灭，并有许多的祸患灾难临到他们。那日他们必说：『这些祸患临到我们，岂不是因我们的 神不在我们中间吗？』</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 31:16–17"> 那时，因他们偏向别神所行的一切恶，我必定掩面不顾他们。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 6:7; 申命记 31:21–22; 申命记 31:26"> 现在你要写一篇歌，教导以色列人，传给他们，使这歌见证他们的不是；</span>
<span className="v" id="v20" data-v="20" data-xref="何西阿书 13:6; 申命记 6:10–12; 尼希米记 9:25–26"> 因为我将他们领进我向他们列祖起誓应许那流奶与蜜之地，他们在那里吃得饱足，身体肥胖，就必偏向别神，事奉他们，藐视我，背弃我的约。</span>
<span className="v" id="v21" data-v="21" data-xref="何西阿书 5:3; 诗篇 139:2; 约翰福音 2:24–25"> 那时，有许多祸患灾难临到他们，这歌必在他们面前作见证，他们后裔的口中必念诵不忘。我未领他们到我所起誓应许之地以先，他们所怀的意念我都知道了。」</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 31:19; 申命记 31:9"> 当日摩西就写了一篇歌，教导以色列人。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 31:7–8; 申命记 31:14; 使徒行传 7:45"> 耶和华嘱咐嫩的儿子约书亚说：「你当刚强壮胆，因为你必领以色列人进我所起誓应许他们的地；我必与你同在。」</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 31:9; 申命记 17:18"> 摩西将这律法的话写在书上，及至写完了，</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 31:9"> 就吩咐抬耶和华约柜的利未人说：</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 31:19; 列王纪下 22:8–11; 加拉太书 2:19"> 「将这律法书放在耶和华—你们 神的约柜旁，可以在那里见证以色列人的不是；</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 32:20; 申命记 9:24; 使徒行传 7:51"> 因为我知道你们是悖逆的，是硬着颈项的。我今日还活着与你们同在，你们尚且悖逆耶和华，何况我死后呢？</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 32:1; 申命记 4:26; 申命记 30:19"> 你们要将你们支派的众长老和官长都招聚了来，我好将这些话说与他们听，并呼天唤地见证他们的不是。</span>
<span className="v" id="v29" data-v="29" data-xref="士师记 2:19; 申命记 32:5; 路加福音 21:24"> 我知道我死后，你们必全然败坏，偏离我所吩咐你们的道，行耶和华眼中看为恶的事，以手所做的惹他发怒；日后必有祸患临到你们。」</span>
</div>
</div>

## 有关未结案的谋杀案件

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 26:21; 诗篇 5:6; 箴言 28:17"> 「在耶和华—你 神所赐你为业的地上，若遇见被杀的人倒在田野，不知道是谁杀的，</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 13:3–4; 申命记 16:18–19"> 长老和审判官就要出去，从被杀的人那里量起，直量到四围的城邑，</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 19:2; 马太福音 11:28–30; 耶利米书 31:18"> 看哪城离被杀的人最近，那城的长老就要从牛群中取一只未曾耕地、未曾负轭的母牛犊，</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前书 2:21–24; 彼得前书 3:18"> 把母牛犊牵到流水、未曾耕种的山谷去，在谷中打折母牛犊的颈项。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 23:13; 玛拉基书 2:7; 申命记 10:8"> 祭司利未的子孙要近前来；因为耶和华—你的 神拣选了他们事奉他，奉耶和华的名祝福，所有争讼殴打的事都要凭他们判断。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 73:13; 诗篇 26:6; 诗篇 51:7"> 那城的众长老，就是离被杀的人最近的，要在那山谷中，在所打折颈项的母牛犊以上洗手，</span>
<span className="v" id="v7" data-v="7" data-xref="约伯记 21:21–23; 约伯记 21:31–34; 撒母耳记下 16:8"> 祷告<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是回答">a</a></sup>说：『我们的手未曾流这人的血；我们的眼也未曾看见这事。</span>
<span className="v" id="v8" data-v="8" data-xref="约拿书 1:14; 列王纪下 24:4; 以西结书 23:24–25"> 耶和华啊，求你赦免你所救赎的以色列民，不要使流无辜血的罪归在你的百姓以色列中间。』这样，流血的罪必得赦免。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 19:12–13; 列王纪下 10:30–31; 申命记 13:18"> 你行耶和华眼中看为正的事，就可以从你们中间除掉流无辜血的罪。」</span>
</div>
</div>

## 有关女战俘的案件

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命记 20:10–16; 约书亚记 21:44"> 「你出去与仇敌争战的时候，耶和华—你的 神将他们交在你手中，你就掳了他们去。</span>
<span className="v" id="v11" data-v="11" data-xref="箴言 31:10; 创世记 34:3; 创世记 12:14–15"> 若在被掳的人中见有美貌的女子，恋慕她，要娶她为妻，</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 14:9; 民数记 6:9; 以弗所书 4:22"> 就可以领她到你家里去；她便要剃头发，修指甲，</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 45:10–11; 路加福音 14:26–27"> 脱去被掳时所穿的衣服，住在你家里哀哭父母一个整月，然后可以与她同房。你作她的丈夫，她作你的妻子。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 22:29; 创世记 34:2; 申命记 22:19"> 后来你若不喜悦她，就要由她随意出去，决不可为钱卖她，也不可当婢女待她，因为你玷污了她。」</span>
</div>
</div>

## 有关长子的继承权

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="创世记 29:33; 创世记 29:20; 创世记 29:18"> 「人若有二妻，一为所爱，一为所恶，所爱的、所恶的都给他生了儿子，但长子是所恶之妻生的。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 26:10; 历代志上 5:2; 历代志下 21:3"> 到了把产业分给儿子承受的时候，不可将所爱之妻生的儿子立为长子，在所恶之妻生的儿子以上，</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 49:3; 创世记 25:31–34; 诗篇 105:36"> 却要认所恶之妻生的儿子为长子，将产业多加一分给他；因这儿子是他力量强壮的时候生的，长子的名分本当归他。」</span>
</div>
</div>

## 有关逆子的处置

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未记 19:3; 出埃及记 20:12; 阿摩司书 4:11–12"> 「人若有顽梗悖逆的儿子，不听从父母的话，他们虽惩治他，他仍不听从，</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 13:3; 申命记 21:2; 申命记 16:18"> 父母就要抓住他，将他带到本地的城门、本城的长老那里，</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 23:29–35; 箴言 20:1; 箴言 23:19–21"> 对长老说：『我们这儿子顽梗悖逆，不听从我们的话，是贪食好酒的人。』</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 19:19–20; 申命记 13:10–11; 利未记 24:16"> 本城的众人就要用石头将他打死。这样，就把那恶从你们中间除掉，以色列众人都要听见害怕。」</span>

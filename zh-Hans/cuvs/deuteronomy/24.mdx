## 离婚和再婚

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 19:7–9; 马可福音 10:4–12; 以赛亚书 50:1"> 「人若娶妻以后，见她有什么不合理的事，不喜悦她，就可以写休书交在她手中，打发她离开夫家。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 10:11; 哥林多前书 7:15; 以西结书 44:22"> 妇人离开夫家以后，可以去嫁别人。</span>
<span className="v" id="v3" data-v="3"> 后夫若恨恶她，写休书交在她手中，打发她离开夫家，或是娶她为妻的后夫死了，</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 3:1; 约书亚记 22:17–18; 利未记 18:24–28"> 打发她去的前夫不可在妇人玷污之后再娶她为妻，因为这是耶和华所憎恶的；不可使耶和华—你 神所赐为业之地被玷污了。」</span>
</div>
</div>

## 一般条例

<div className="bt">
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="箴言 5:18; 申命记 20:7; 创世记 2:24"> 「新娶妻之人不可从军出征，也不可托他办理什么公事，可以在家清闲一年，使他所娶的妻快活。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 20:19; 路加福音 12:15; 启示录 18:22"> 「不可拿人的全盘磨石或是上磨石作当头，因为这是拿人的命作当头。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 21:16; 提摩太前书 1:10; 出埃及记 22:1–4"> 「若遇见人拐带以色列中的一个弟兄，当奴才待他，或是卖了他，那拐带人的就必治死。这样，便将那恶从你们中间除掉。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 14:2; 马可福音 1:44; 利未记 13:1–46"> 「在大麻风的灾病上，你们要谨慎，照祭司利未人一切所指教你们的留意遵行。我怎样吩咐他们，你们要怎样遵行。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 12:10–15; 哥林多前书 10:11; 哥林多前书 10:6"> 当记念出埃及后，在路上，耶和华—你 神向米利暗所行的事。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 15:8; 出埃及记 22:27"> 「你借给邻舍，不拘是什么，不可进他家拿他的当头。</span>
<span className="v" id="v11" data-v="11"> 要站在外面，等那向你借贷的人把当头拿出来交给你。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 24:17; 约伯记 22:6; 约伯记 24:3"> 他若是穷人，你不可留他的当头过夜。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 6:25; 但以理书 4:27; 出埃及记 22:26–27"> 日落的时候，总要把当头还他，使他用那件衣服盖着睡觉，他就为你祝福；这在耶和华—你 神面前就是你的义了。</span>
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 3:5; 箴言 14:31; 箴言 22:16"> 「困苦穷乏的雇工，无论是你的弟兄或是在你城里寄居的，你不可欺负他。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 19:13; 箴言 3:27–28; 雅各书 5:4"> 要当日给他工价，不可等到日落—因为他穷苦，把心放在工价上—恐怕他因你求告耶和华，罪便归你了。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 18:20; 历代志下 25:4; 耶利米书 31:29–30"> 「不可因子杀父，也不可因父杀子；凡被杀的都为本身的罪。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 16:19; 申命记 27:19; 出埃及记 23:6"> 「你不可向寄居的和孤儿屈枉正直，也不可拿寡妇的衣裳作当头。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 5:15; 申命记 15:15; 申命记 16:12"> 要记念你在埃及作过奴仆。耶和华—你的 神从那里将你救赎，所以我吩咐你这样行。</span>
<span className="v" id="v19" data-v="19" data-xref="利未记 23:22; 利未记 19:9–10; 申命记 14:29"> 「你在田间收割庄稼，若忘下一捆，不可回去再取，要留给寄居的与孤儿寡妇。这样，耶和华—你 神必在你手里所办的一切事上赐福与你。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 19:10"> 你打橄榄树，枝上剩下的，不可再打；要留给寄居的与孤儿寡妇。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 19:9–10; 申命记 24:19"> 你摘葡萄园的葡萄，所剩下的，不可再摘；要留给寄居的与孤儿寡妇。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 24:18; 约翰一书 4:10–11; 申命记 5:14–15"> 你也要记念你在埃及地作过奴仆，所以我吩咐你这样行。</span>
</div>
</div>

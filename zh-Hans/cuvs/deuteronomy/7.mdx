## 耶和华的子民

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 31:3; 使徒行传 13:19; 申命记 4:38"> 「耶和华—你 神领你进入要得为业之地，从你面前赶出许多国民，就是赫人、革迦撒人、亚摩利人、迦南人、比利洗人、希未人、耶布斯人，共七国的民，都比你强大。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 2:2; 出埃及记 23:32–33; 申命记 20:16–17"> 耶和华—你 神将他们交给你击杀，那时你要把他们灭绝净尽，不可与他们立约，也不可怜恤他们。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 11:2; 约书亚记 23:12–13; 出埃及记 34:15–16"> 不可与他们结亲。不可将你的女儿嫁他们的儿子，也不可叫你的儿子娶他们的女儿；</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 6:15; 士师记 2:11; 申命记 4:26"> 因为他必使你儿子转离不跟从主，去事奉别神，以致耶和华的怒气向你们发作，就速速地将你们灭绝。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 23:24; 申命记 12:2–3; 出埃及记 34:13"> 你们却要这样待他们：拆毁他们的祭坛，打碎他们的柱像，砍下他们的木偶，用火焚烧他们雕刻的偶像。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 14:2; 出埃及记 19:5–6; 彼得前书 2:9"> 因为你归耶和华—你 神为圣洁的民；耶和华—你 神从地上的万民中拣选你，特作自己的子民。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 10:22; 罗马书 9:11–15; 罗马书 11:6"> 「耶和华专爱你们，拣选你们，并非因你们的人数多于别民，原来你们的人数在万民中是最少的。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 20:2; 出埃及记 32:13; 以弗所书 2:4–5"> 只因耶和华爱你们，又因要守他向你们列祖所起的誓，就用大能的手领你们出来，从为奴之家救赎你们脱离埃及王法老的手。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 10:23; 提摩太后书 2:13; 帖撒罗尼迦后书 3:3"> 所以，你要知道耶和华—你的 神，他是 神，是信实的 神；向爱他、守他诫命的人守约，施慈爱，直到千代；</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 59:18; 那鸿书 1:2; 罗马书 12:19"> 向恨他的人当面报应他们，将他们灭绝。凡恨他的人必报应他们，决不迟延。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 14:15; 申命记 4:1; 申命记 5:32"> 所以，你要谨守遵行我今日所吩咐你的诫命、律例、典章。」</span>
</div>
</div>

## 遵行诫命必蒙福

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命记 28:1–14; 申命记 7:9; 利未记 26:3–13"> 「你们果然听从这些典章，谨守遵行，耶和华—你 神就必照他向你列祖所起的誓守约，施慈爱。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 14:21; 约翰福音 15:10; 申命记 28:3–5"> 他必爱你，赐福与你，使你人数增多，也必在他向你列祖起誓应许给你的地上赐福与你身所生的，地所产的，并你的五谷、新酒，和油，以及牛犊、羊羔。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 23:26–33; 申命记 28:4; 诗篇 127:3"> 你必蒙福胜过万民；你们的男女没有不能生养的，牲畜也没有不能生育的。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 15:26; 诗篇 105:36–37; 利未记 26:3–4"> 耶和华必使一切的病症离开你；你所知道埃及各样的恶疾，他不加在你身上，只加在一切恨你的人身上。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 23:33; 士师记 8:27; 申命记 13:8"> 耶和华—你 神所要交给你的一切人民，你要将他们除灭；你眼不可顾惜他们。你也不可事奉他们的神，因这必成为你的网罗。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 13:32; 民数记 33:53; 申命记 18:21"> 「你若心里说，这些国的民比我更多，我怎能赶出他们呢？</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 105:5; 申命记 31:6; 申命记 1:29"> 你不要惧怕他们，要牢牢记念耶和华—你 神向法老和埃及全地所行的事，</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 4:34; 尼希米记 9:10–11; 耶利米书 32:20–21"> 就是你亲眼所看见的大试验、神迹、奇事，和大能的手，并伸出来的膀臂，都是耶和华—你 神领你出来所用的。耶和华—你 神必照样待你所惧怕的一切人民。</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 24:12; 出埃及记 23:28–30"> 并且耶和华—你 神必打发黄蜂飞到他们中间，直到那剩下而藏躲的人从你面前灭亡。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米记 1:5; 申命记 10:17; 尼希米记 9:32"> 你不要因他们惊恐，因为耶和华—你 神在你们中间是大而可畏的 神。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 23:29–30; 约书亚记 15:63"> 耶和华—你 神必将这些国的民从你面前渐渐赶出；你不可把他们速速灭尽，恐怕野地的兽多起来害你。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 8:20; 申命记 2:15; 耶利米书 17:18"> 耶和华—你 神必将他们交给你，大大地扰乱他们，直到他们灭绝了；</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 10:8; 约书亚记 23:9; 约书亚记 1:5"> 又要将他们的君王交在你手中，你就使他们的名从天下消灭。必无一人能在你面前站立得住，直到你将他们灭绝了。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 32:20; 历代志上 14:12; 申命记 17:1"> 他们雕刻的神像，你们要用火焚烧；其上的金银，你不可贪图，也不可收取，免得你因此陷入网罗；这原是耶和华—你 神所憎恶的。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 13:17; 何西阿书 14:8; 以西结书 11:18"> 可憎的物，你不可带进家去；不然，你就成了当毁灭的，与那物一样。你要十分厌恶，十分憎嫌，因为这是当毁灭的物。」</span>
</div>
</div>

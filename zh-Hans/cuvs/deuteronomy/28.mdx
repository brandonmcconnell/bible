## 遵行诫命蒙福

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 1:19; 出埃及记 23:22; 利未记 26:3–13"> 「你若留意听从耶和华—你 神的话，谨守遵行他的一切诫命，就是我今日所吩咐你的，他必使你超乎天下万民之上。</span>
<span className="v" id="v2" data-v="2" data-xref="撒迦利亚书 1:6; 申命记 28:15; 提摩太前书 4:8"> 你若听从耶和华—你 神的话，这以下的福必追随你，临到你身上：</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 144:12–15; 创世记 39:5; 哈该书 2:19"> 你在城里必蒙福，在田间也必蒙福。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 10:22; 创世记 49:25; 申命记 7:13"> 你身所生的，地所产的，牲畜所下的，以及牛犊、羊羔，都必蒙福。</span>
<span className="v" id="v5" data-v="5"> 你的筐子和你的抟面盆都必蒙福。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 121:8; 民数记 27:17; 历代志下 1:10"> 你出也蒙福，入也蒙福。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 22:38–41; 利未记 26:7–8; 诗篇 89:23"> 「仇敌起来攻击你，耶和华必使他们在你面前被你杀败；他们从一条路来攻击你，必从七条路逃跑。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 15:10; 利未记 26:10; 箴言 3:9–10"> 在你仓房里，并你手所办的一切事上，耶和华所命的福必临到你。耶和华—你 神也要在所给你的地上赐福与你。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 19:5–6; 申命记 7:6; 申命记 26:18–19"> 你若谨守耶和华—你 神的诫命，遵行他的道，他必照着向你所起的誓立你作为自己的圣民。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 7:14; 申命记 11:25; 耶利米书 33:9"> 天下万民见你归在耶和华的名下，就要惧怕你。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 30:9; 箴言 10:22; 利未记 26:9"> 你在耶和华向你列祖起誓应许赐你的地上，他必使你身所生的，牲畜所下的，地所产的，都绰绰有余。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 15:6; 约珥书 2:23–24; 申命记 15:10"> 耶和华必为你开天上的府库，按时降雨在你的地上。在你手里所办的一切事上赐福与你。你必借给许多国民，却不致向他们借贷。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 28:1; 申命记 4:6–9; 腓立比书 1:27"> 你若听从耶和华—你 神的诫命，就是我今日所吩咐你的，谨守遵行，不偏左右，也不随从事奉别神，耶和华就必使你作首不作尾，但居上不居下。」</span>
</div>
</div>

## 悖逆的后果

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="玛拉基书 2:2; 申命记 28:2; 申命记 29:20"> 「你若不听从耶和华—你 神的话，不谨守遵行他的一切诫命律例，就是我今日所吩咐你的，这以下的咒诅都必追随你，临到你身上：</span>
<span className="v" id="v16" data-v="16" data-xref="玛拉基书 3:9–12; 箴言 3:33; 约珥书 1:4"> 你在城里必受咒诅，在田间也必受咒诅。</span>
<span className="v" id="v17" data-v="17" data-xref="哈该书 1:6; 申命记 28:5; 诗篇 69:22"> 你的筐子和你的抟面盆都必受咒诅。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 26:26; 利未记 26:19–20; 约伯记 18:16–19"> 你身所生的，地所产的，以及牛犊、羊羔，都必受咒诅。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 28:6; 士师记 5:6–7; 历代志下 15:5"> 你出也受咒诅，入也受咒诅。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 66:15; 玛拉基书 2:2; 申命记 4:26"> 耶和华因你行恶离弃他，必在你手里所办的一切事上，使咒诅、扰乱、责罚临到你，直到你被毁灭，速速地灭亡。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 26:25; 耶利米书 24:10; 耶利米书 16:4"> 耶和华必使瘟疫贴在你身上，直到他将你从所进去得为业的地上灭绝。</span>
<span className="v" id="v22" data-v="22" data-xref="阿摩司书 4:9; 利未记 26:16; 哈该书 2:17"> 耶和华要用痨病、热病、火症、疟疾、刀剑、旱风<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：干旱">a</a></sup>、霉烂攻击你。这都要追赶你，直到你灭亡。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 26:19; 耶利米书 14:1–6; 列王纪上 18:2"> 你头上的天要变为铜，脚下的地要变为铁。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 28:12; 以赛亚书 5:24; 阿摩司书 4:11"> 耶和华要使那降在你地上的雨变为尘沙，从天临在你身上，直到你灭亡。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 30:17; 以西结书 23:46; 耶利米书 24:9"> 「耶和华必使你败在仇敌面前，你从一条路去攻击他们，必从七条路逃跑。你必在天下万国中抛来抛去。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 34:20; 耶利米书 16:4; 耶利米书 7:33"> 你的尸首必给空中的飞鸟和地上的走兽作食物，并无人哄赶。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 5:6; 申命记 28:35; 利未记 21:20"> 耶和华必用埃及人的疮并痔疮、牛皮癣与疥攻击你，使你不能医治。</span>
<span className="v" id="v28" data-v="28" data-xref="帖撒罗尼迦后书 2:9–11; 以赛亚书 19:11–17; 以赛亚书 6:9–10"> 耶和华必用癫狂、眼瞎、心惊攻击你。</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 59:10; 约伯记 5:14; 士师记 6:1–6"> 你必在午间摸索，好像瞎子在暗中摸索一样。你所行的必不亨通，时常遭遇欺压、抢夺，无人搭救。</span>
<span className="v" id="v30" data-v="30" data-xref="阿摩司书 5:11; 耶利米书 8:10; 约伯记 31:10"> 你聘定了妻，别人必与她同房；你建造房屋，不得住在其内；你栽种葡萄园，也不得用其中的果子。</span>
<span className="v" id="v31" data-v="31" data-xref="约伯记 1:14–15; 士师记 6:1"> 你的牛在你眼前宰了，你必不得吃它的肉；你的驴在你眼前被抢夺，不得归还；你的羊归了仇敌，无人搭救。</span>
<span className="v" id="v32" data-v="32" data-xref="约珥书 3:6; 申命记 28:41; 约伯记 17:5"> 你的儿女必归与别国的民；你的眼目终日切望，甚至失明，你手中无力拯救。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 5:17; 申命记 28:29–30; 以赛亚书 1:7"> 你的土产和你劳碌得来的，必被你所不认识的国民吃尽。你时常被欺负，受压制，</span>
<span className="v" id="v34" data-v="34" data-xref="启示录 16:10–11; 申命记 28:68; 以赛亚书 33:14"> 甚至你因眼中所看见的，必致疯狂。</span>
<span className="v" id="v35" data-v="35" data-xref="申命记 28:27; 以赛亚书 3:24; 以赛亚书 3:17"> 耶和华必攻击你，使你膝上腿上，从脚掌到头顶，长毒疮无法医治。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 16:13; 申命记 4:28; 列王纪下 25:11"> 「耶和华必将你和你所立的王领到你和你列祖素不认识的国去；在那里你必事奉木头石头的神。</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 25:9; 列王纪上 9:7–8; 耶利米书 24:9"> 你在耶和华领你到的各国中，要令人惊骇、笑谈、讥诮。</span>
<span className="v" id="v38" data-v="38" data-xref="哈该书 1:6; 弥迦书 6:15; 约珥书 1:4"> 你带到田间的种子虽多，收进来的却少，因为被蝗虫吃了。</span>
<span className="v" id="v39" data-v="39" data-xref="以赛亚书 17:10–11; 约珥书 2:2–4; 约拿书 4:7"> 你栽种、修理葡萄园，却不得收葡萄，也不得喝葡萄酒，因为被虫子吃了。</span>
<span className="v" id="v40" data-v="40" data-xref="弥迦书 6:15; 诗篇 23:5; 诗篇 104:15"> 你全境有橄榄树，却不得其油抹身，因为树上的橄榄不熟自落了。</span>
<span className="v" id="v41" data-v="41" data-xref="申命记 28:32; 耶利米哀歌 1:5; 列王纪下 24:14"> 你生儿养女，却不算是你的，因为必被掳去。</span>
<span className="v" id="v42" data-v="42" data-xref="阿摩司书 7:1–2; 申命记 28:38–39"> 你所有的树木和你地里的出产必被蝗虫所吃。</span>
<span className="v" id="v43" data-v="43" data-xref="申命记 28:13; 撒母耳记上 13:19–23; 列王纪下 17:20"> 在你中间寄居的，必渐渐上升，比你高而又高；你必渐渐下降，低而又低。</span>
<span className="v" id="v44" data-v="44" data-xref="申命记 28:12–13; 耶利米哀歌 1:5"> 他必借给你，你却不能借给他；他必作首，你必作尾。</span>
<span className="v" id="v45" data-v="45" data-xref="申命记 28:15; 以赛亚书 1:20; 耶利米书 24:9–10"> 这一切咒诅必追随你，赶上你，直到你灭亡；因为你不听从耶和华—你 神的话，不遵守他所吩咐的诫命律例。</span>
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 8:18; 申命记 28:37; 以西结书 14:8"> 这些咒诅必在你和你后裔的身上成为异迹奇事，直到永远！</span>
<span className="v" id="v47" data-v="47" data-xref="申命记 16:11; 申命记 12:7–12; 尼希米记 9:35–37"> 「因为你富有的时候，不欢心乐意地事奉耶和华—你的 神，</span>
<span className="v" id="v48" data-v="48" data-xref="耶利米书 28:13–14; 耶利米哀歌 5:2–6; 以西结书 4:16–17"> 所以你必在饥饿、干渴、赤露、缺乏之中事奉耶和华所打发来攻击你的仇敌。他必把铁轭加在你的颈项上，直到将你灭绝。</span>
<span className="v" id="v49" data-v="49" data-xref="耶利米哀歌 4:19; 耶利米书 49:22; 耶利米书 48:40"> 「耶和华要从远方、地极带一国的民，如鹰飞来攻击你。这民的言语，你不懂得。</span>
<span className="v" id="v50" data-v="50" data-xref="以赛亚书 47:6; 历代志下 36:17; 路加福音 21:23–24"> 这民的面貌凶恶，不顾恤年老的，也不恩待年少的。</span>
<span className="v" id="v51" data-v="51" data-xref="申命记 28:33; 以赛亚书 62:8; 利未记 26:26"> 他们必吃你牲畜所下的和你地土所产的，直到你灭亡。你的五谷、新酒，和油，以及牛犊、羊羔，都不给你留下，直到将你灭绝。</span>
<span className="v" id="v52" data-v="52" data-xref="耶利米书 52:4–7; 以西结书 4:1–8; 马太福音 24:15–16"> 他们必将你困在你各城里，直到你所倚靠、高大坚固的城墙都被攻塌。他们必将你困在耶和华—你 神所赐你遍地的各城里。</span>
<span className="v" id="v53" data-v="53" data-xref="耶利米哀歌 4:10; 耶利米书 19:9; 利未记 26:29"> 你在仇敌围困窘迫之中，必吃你本身所生的，就是耶和华—你 神所赐给你的儿女之肉。</span>
<span className="v" id="v54" data-v="54" data-xref="申命记 15:9; 马太福音 20:15; 申命记 13:6"> 你们中间，柔弱娇嫩的人必恶眼看他弟兄和他怀中的妻，并他余剩的儿女；</span>
<span className="v" id="v55" data-v="55" data-xref="耶利米书 34:2; 耶利米书 52:6; 耶利米书 5:10"> 甚至在你受仇敌围困窘迫的城中，他要吃儿女的肉，不肯分一点给他的亲人，因为他一无所剩。</span>
<span className="v" id="v56" data-v="56" data-xref="申命记 28:54; 以赛亚书 3:16; 耶利米哀歌 4:3–6"> 你们中间，柔弱娇嫩的妇人，是因娇嫩柔弱不肯把脚踏地的，必恶眼看她怀中的丈夫和她的儿女。</span>
<span className="v" id="v57" data-v="57" data-xref="以赛亚书 49:15; 创世记 49:10"> 她两腿中间出来的婴孩与她所要生的儿女，她因缺乏一切就要在你受仇敌围困窘迫的城中将他们暗暗地吃了。</span>
<span className="v" id="v58" data-v="58" data-xref="以赛亚书 42:8; 耶利米书 7:9–10; 玛拉基书 1:14"> 「这书上所写律法的一切话是叫你敬畏耶和华—你 神可荣可畏的名。你若不谨守遵行，耶和华就必将奇灾，就是至大至长的灾，至重至久的病，加在你和你后裔的身上，</span>
<span className="v" id="v60" data-v="60" data-xref="申命记 7:15; 出埃及记 15:26; 申命记 28:27"> 也必使你所惧怕、埃及人的病都临到你，贴在你身上，</span>
<span className="v" id="v61" data-v="61" data-xref="申命记 4:25–26"> 又必将没有写在这律法书上的各样疾病、灾殃降在你身上，直到你灭亡。</span>
<span className="v" id="v62" data-v="62" data-xref="申命记 10:22; 尼希米记 9:23; 申命记 4:27"> 你们先前虽然像天上的星那样多，却因不听从耶和华—你 神的话，所剩的人数就稀少了。</span>
<span className="v" id="v63" data-v="63" data-xref="箴言 1:26; 耶利米书 32:41; 申命记 30:9"> 先前耶和华怎样喜悦善待你们，使你们众多，也要照样喜悦毁灭你们，使你们灭亡；并且你们从所要进去得的地上必被拔除。</span>
<span className="v" id="v64" data-v="64" data-xref="申命记 4:27–28; 利未记 26:33; 耶利米书 16:13"> 耶和华必使你们分散在万民中，从地这边到地那边，你必在那里事奉你和你列祖素不认识、木头石头的神。</span>
<span className="v" id="v65" data-v="65" data-xref="利未记 26:36; 罗马书 11:10; 阿摩司书 9:4"> 在那些国中，你必不得安逸，也不得落脚之地；耶和华却使你在那里心中跳动，眼目失明，精神消耗。</span>
<span className="v" id="v66" data-v="66" data-xref="耶利米哀歌 1:13; 希伯来书 10:27; 启示录 6:15–17"> 你的性命必悬悬无定；你昼夜恐惧，自料性命难保。</span>
<span className="v" id="v67" data-v="67" data-xref="申命记 28:34; 约伯记 7:3–4; 启示录 9:6"> 你因心里所恐惧的，眼中所看见的，早晨必说，巴不得到晚上才好；晚上必说，巴不得到早晨才好。</span>
<span className="v" id="v68" data-v="68" data-xref="耶利米书 44:12; 耶利米书 43:7; 何西阿书 8:13"> 耶和华必使你坐船回埃及去，走我曾告诉你不得再见的路；在那里你必卖己身与仇敌作奴婢，却无人买。」</span>

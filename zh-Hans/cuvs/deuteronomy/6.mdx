## 最大的诫命

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 4:1; 申命记 12:1; 申命记 4:45"> 「这是耶和华—你们 神所吩咐教训你们的诫命、律例、典章，使你们在所要过去得为业的地上遵行，</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 4:40; 申命记 13:4; 出埃及记 20:20"> 好叫你和你子子孙孙一生敬畏耶和华—你的 神，谨守他的一切律例诫命，就是我所吩咐你的，使你的日子得以长久。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 22:17; 出埃及记 3:8; 创世记 26:4"> 以色列啊，你要听，要谨守遵行，使你可以在那流奶与蜜之地得以享福，人数极其增多，正如耶和华—你列祖的 神所应许你的。</span>
<span className="v" id="v4" data-v="4" data-xref="马可福音 12:29–32; 以赛亚书 44:6; 提摩太前书 2:5"> 「以色列啊，你要听！耶和华—我们 神是独一的主。</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 12:30; 马太福音 22:37; 路加福音 10:27"> 你要尽心、尽性、尽力爱耶和华—你的 神。</span>
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 3:16; 箴言 7:3; 耶利米书 31:33"> 我今日所吩咐你的话都要记在心上，</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 11:19; 以弗所书 6:4; 诗篇 78:4–6"> 也要殷勤教训你的儿女。无论你坐在家里，行在路上，躺下，起来，都要谈论。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 6:21; 箴言 3:3; 申命记 11:18"> 也要系在手上为记号，戴在额上为经文；</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 11:20; 以赛亚书 30:8; 以赛亚书 57:8"> 又要写在你房屋的门框上，并你的城门上。」</span>

## 警告人民不可背逆 神

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约书亚记 24:13; 诗篇 105:44; 尼希米记 9:25"> 「耶和华—你的 神领你进他向你列祖亚伯拉罕、以撒、雅各起誓应许给你的地。那里有城邑，又大又美，非你所建造的；</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 7:12–18; 申命记 8:10–20; 以西结书 16:10–20"> 有房屋，装满各样美物，非你所装满的；有凿成的水井，非你所凿成的；还有葡萄园、橄榄园，非你所栽种的；你吃了而且饱足。</span>
<span className="v" id="v12" data-v="12"> 那时你要谨慎，免得你忘记将你从埃及地、为奴之家领出来的耶和华。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 4:8; 申命记 10:20; 马太福音 4:10"> 你要敬畏耶和华—你的 神，事奉他，指着他的名起誓。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 25:6; 约翰一书 5:21; 申命记 13:7"> 不可随从别神，就是你们四围国民的神；</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 4:24; 出埃及记 20:5; 申命记 7:4"> 因为在你们中间的耶和华—你 神是忌邪的 神，惟恐耶和华—你 神的怒气向你发作，就把你从地上除灭。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 17:7; 路加福音 4:12; 马太福音 4:7"> 「你们不可试探耶和华—你们的 神，像你们在玛撒那样试探他。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 11:22; 诗篇 119:4; 哥林多前书 15:58"> 要留意遵守耶和华—你们 神所吩咐的诫命、法度、律例。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 4:40; 申命记 12:25; 罗马书 12:2"> 耶和华眼中看为正、看为善的，你都要遵行，使你可以享福，并可以进去得耶和华向你列祖起誓应许的那美地，</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 33:52–53; 出埃及记 23:28–30; 士师记 3:1–4"> 照耶和华所说的，从你面前撵出你的一切仇敌。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 13:14; 出埃及记 12:26; 约书亚记 4:6–7"> 「日后，你的儿子问你说：『耶和华—我们 神吩咐你们的这些法度、律例、典章是什么意思呢？』</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 6:17–18; 以弗所书 2:11–12; 申命记 15:15"> 你就告诉你的儿子说：『我们在埃及作过法老的奴仆；耶和华用大能的手将我们从埃及领出来，</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 4:34; 诗篇 58:10–11; 申命记 7:19"> 在我们眼前，将重大可怕的神迹奇事施行在埃及地和法老并他全家的身上，</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 6:18; 申命记 6:10; 出埃及记 13:5"> 将我们从那里领出来，要领我们进入他向我们列祖起誓应许之地，把这地赐给我们。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 32:39; 诗篇 41:2; 申命记 10:12–13"> 耶和华又吩咐我们遵行这一切律例，要敬畏耶和华—我们的 神，使我们常得好处，蒙他保全我们的生命，像今日一样。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 24:13; 罗马书 10:3; 利未记 18:5"> 我们若照耶和华—我们 神所吩咐的一切诫命谨守遵行，这就是我们的义了。』」</span>

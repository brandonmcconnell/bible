## 惟一的敬拜场所

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 8:40; 约伯记 7:1; 申命记 4:19"> 「你们存活于世的日子，在耶和华—你们列祖的 神所赐你们为业的地上，要谨守遵行的律例典章乃是这些：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 7:5; 列王纪下 16:4; 民数记 33:51–52"> 你们要将所赶出的国民事奉神的各地方，无论是在高山，在小山，在各青翠树下，都毁坏了；</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 2:2; 撒迦利亚书 13:2; 民数记 33:52"> 也要拆毁他们的祭坛，打碎他们的柱像，用火焚烧他们的木偶，砍下他们雕刻的神像，并将其名从那地方除灭。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 20:23; 申命记 20:18; 申命记 16:21–22"> 你们不可照他们那样事奉耶和华—你们的 神。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 12:11; 申命记 26:2; 历代志下 7:12"> 但耶和华—你们的 神从你们各支派中选择何处为立他名的居所，你们就当往那里去求问，</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 15:19–20; 玛拉基书 3:10; 利未记 27:32–33"> 将你们的燔祭、平安祭、十分取一之物，和手中的举祭，并还愿祭、甘心祭，以及牛群羊群中头生的，都奉到那里。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 12:18; 利未记 23:40; 申命记 14:26"> 在那里，耶和华—你们 神的面前，你们和你们的家属都可以吃，并且因你手所办的一切事蒙耶和华—你的 神赐福，就都欢乐。</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 21:25; 士师记 17:6; 箴言 21:2"> 我们今日在这里所行的是各人行自己眼中看为正的事，你们将来不可这样行；</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 8:56; 诗篇 95:11; 申命记 25:19"> 因为你们还没有到耶和华—你 神所赐你的安息地，所给你的产业。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 33:11; 以西结书 34:28; 申命记 3:27"> 但你们过了约旦河，得以住在耶和华—你们 神使你们承受为业之地，又使你们太平，不被四围的一切仇敌扰乱，安然居住。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 12:5; 申命记 15:20; 申命记 17:8"> 那时要将我所吩咐你们的燔祭、平安祭、十分取一之物，和手中的举祭，并向耶和华许愿献的一切美祭，都奉到耶和华—你们 神所选择要立为他名的居所。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 12:7; 申命记 10:9; 申命记 26:12"> 你们和儿女、仆婢，并住在你们城里无分无业的利未人，都要在耶和华—你们的 神面前欢乐。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 12:28–32; 列王纪上 15:34; 历代志下 15:17"> 你要谨慎，不可在你所看中的各处献燔祭。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 12:11; 哥林多后书 5:19; 申命记 12:5"> 惟独耶和华从你那一支派中所选择的地方，你就要在那里献燔祭，行我一切所吩咐你的。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命记 14:5; 申命记 15:22–23; 申命记 14:26"> 「然而，在你各城里都可以照耶和华—你 神所赐你的福分，随心所欲宰牲吃肉；无论洁净人不洁净人都可以吃，就如吃羚羊与鹿一般。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 9:4; 申命记 15:23; 申命记 12:23–24"> 只是不可吃血，要倒在地上，如同倒水一样。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 26:14; 申命记 12:6; 申命记 14:22–29"> 你的五谷、新酒，和油的十分之一，或是牛群羊群中头生的，或是你许愿献的，甘心献的，或是手中的举祭，都不可在你城里吃。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 12:7; 申命记 14:23; 申命记 12:5"> 但要在耶和华—你的 神面前吃，在耶和华—你 神所要选择的地方，你和儿女、仆婢，并住在你城里的利未人，都可以吃；也要因你手所办的，在耶和华—你 神面前欢乐。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 31:4–21; 尼希米记 10:34–39; 申命记 14:27–29"> 你要谨慎，在你所住的地方永不可丢弃利未人。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命记 19:8; 申命记 11:24; 出埃及记 34:24"> 「耶和华—你的 神照他所应许扩张你境界的时候，你心里想要吃肉，说：『我要吃肉』，就可以随心所欲地吃肉。</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 12:5; 列王纪上 14:21; 申命记 16:11"> 耶和华—你 神所选择要立他名的地方若离你太远，就可以照我所吩咐的，将耶和华赐给你的牛羊取些宰了，可以随心所欲在你城里吃。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 12:15–16"> 你吃那肉，要像吃羚羊与鹿一般；无论洁净人不洁净人都可以吃。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 17:11; 创世记 9:4; 利未记 17:13–14"> 只是你要心意坚定，不可吃血，因为血是生命；不可将血<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是生命">a</a></sup>与肉同吃。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 12:16; 申命记 15:23"> 不可吃血，要倒在地上，如同倒水一样。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 11:38; 申命记 4:40; 以赛亚书 3:10"> 不可吃血。这样，你行耶和华眼中看为正的事，你和你的子孙就可以得福。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 18:19; 民数记 5:9–10; 申命记 12:11"> 只是你分别为圣的物和你的还愿祭要奉到耶和华所选择的地方去。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 1:13; 利未记 17:11; 利未记 1:9"> 你的燔祭，连肉带血，都要献在耶和华—你 神的坛上。平安祭的血要倒在耶和华—你 神的坛上；平安祭的肉，你自己可以吃。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 4:40; 约翰福音 15:14; 约翰福音 15:10"> 你要谨守听从我所吩咐的一切话，行耶和华—你 神眼中看为善，看为正的事。这样，你和你的子孙就可以永远享福。」</span>
</div>
</div>

## 警告不可拜偶像

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约书亚记 23:4; 申命记 19:1; 申命记 9:3"> 「耶和华—你 神将你要去赶出的国民从你面前剪除，你得了他们的地居住，</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 10:2; 以西结书 20:32; 申命记 7:16"> 那时就要谨慎，不可在他们除灭之后随从他们的恶俗，陷入网罗，也不可访问他们的神说：『这些国民怎样事奉他们的神，我也要照样行。』</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米书 32:35; 申命记 18:9–10; 列王纪下 17:15–17"> 你不可向耶和华—你的 神这样行，因为他们向他们的神行了耶和华所憎嫌所恨恶的一切事，甚至将自己的儿女用火焚烧，献与他们的神。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 4:2; 启示录 22:18–19; 约书亚记 1:7"> 凡我所吩咐的，你们都要谨守遵行，不可加添，也不可删减。</span>

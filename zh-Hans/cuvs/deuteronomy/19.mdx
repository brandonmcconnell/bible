## 设立庇护城

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 12:29; 申命记 6:10; 申命记 7:1–2"> 「耶和华—你 神将列国之民剪除的时候，耶和华—你 神也将他们的地赐给你，你接着住他们的城邑并他们的房屋，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 21:13; 约书亚记 20:2–7; 申命记 4:41–43"> 就要在耶和华—你 神所赐你为业的地上分定三座城。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 57:14; 希伯来书 12:13; 以赛亚书 35:8"> 要将耶和华—你 神使你承受为业的地分为三段；又要预备道路，使误杀人的，都可以逃到那里去。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 35:15–24; 申命记 4:42; 以赛亚书 30:33"> 「误杀人的逃到那里可以存活，定例乃是这样：凡素无仇恨，无心杀了人的，</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 35:25; 箴言 27:12; 列王纪下 6:5–7"> 就如人与邻舍同入树林砍伐树木，手拿斧子一砍，本想砍下树木，不料，斧头脱了把，飞落在邻舍身上，以致于死，这人逃到那些城的一座城，就可以存活，</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 35:12; 撒母耳记下 14:7; 申命记 21:22"> 免得报血仇的，心中火热追赶他，因路远就追上，将他杀死；其实他不该死，因为他与被杀的素无仇恨。</span>
<span className="v" id="v7" data-v="7"> 所以我吩咐你说，要分定三座城。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 12:20; 出埃及记 34:24; 出埃及记 23:31"> 耶和华—你 神若照他向你列祖所起的誓扩张你的境界，将所应许赐你列祖的地全然给你，</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 20:7–8; 申命记 11:22–25; 申命记 12:32"> 你若谨守遵行我今日所吩咐的这一切诫命，爱耶和华—你的 神，常常遵行他的道，就要在这三座城之外，再添三座城，</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 59:7; 箴言 6:17; 马太福音 27:4–5"> 免得无辜之人的血流在耶和华—你 神所赐你为业的地上，流血的罪就归于你。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 35:16–21; 申命记 27:24; 创世记 9:6"> 「若有人恨他的邻舍，埋伏着起来击杀他，以致于死，便逃到这些城的一座城，</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 2:28–34; 列王纪上 2:5–6"> 本城的长老就要打发人去，从那里带出他来，交在报血仇的手中，将他治死。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 2:31; 申命记 21:9; 申命记 7:16"> 你眼不可顾惜他，却要从以色列中除掉流无辜血的罪，使你可以得福。」</span>
</div>
</div>

## 有关证人的条例

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数记 35:30; 申命记 17:6; 哥林多后书 13:1"> 「人无论犯什么罪，作什么恶，不可凭一个人的口作见证，总要凭两三个人的口作见证才可定案。</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 27:12; 诗篇 35:11; 出埃及记 23:1–7"> 若有凶恶的见证人起来，见证某人作恶，</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 17:9; 申命记 21:5; 玛拉基书 2:7"> 这两个争讼的人就要站在耶和华面前，和当时的祭司，并审判官面前，</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 13:14; 申命记 17:4; 历代志下 19:6–7"> 审判官要细细地查究，若见证人果然是作假见证的，以假见证陷害弟兄，</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 19:5; 箴言 19:9; 但以理书 6:24"> 你们就要待他如同他想要待的弟兄。这样，就把那恶从你们中间除掉。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 21:21; 申命记 17:13; 申命记 13:11"> 别人听见都要害怕，就不敢在你们中间再行这样的恶了。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 5:38–39; 出埃及记 21:23–25; 申命记 19:13"> 你眼不可顾惜，要以命偿命，以眼还眼，以牙还牙，以手还手，以脚还脚。」</span>
</div>

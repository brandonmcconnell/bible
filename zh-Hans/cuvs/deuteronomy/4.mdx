## 摩西劝人民遵行耶和华的律例典章

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 10:5; 以西结书 20:11; 利未记 18:5"> 「以色列人哪，现在我所教训你们的律例典章，你们要听从遵行，好叫你们存活，得以进入耶和华—你们列祖之 神所赐给你们的地，承受为业。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 12:32; 箴言 30:6; 启示录 22:18–19"> 所吩咐你们的话，你们不可加添，也不可删减，好叫你们遵守我所吩咐的，就是耶和华—你们 神的命令。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 25:1–9; 诗篇 106:28–29; 约书亚记 22:17"> 耶和华因巴力·毗珥的事所行的，你们亲眼看见了。凡随从巴力·毗珥的人，耶和华—你们的 神都从你们中间除灭了。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 10:20; 约书亚记 23:8; 约翰福音 6:67–69"> 惟有你们专靠耶和华—你们 神的人，今日全都存活。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 28:20; 帖撒罗尼迦前书 4:1–2; 希伯来书 3:5"> 我照着耶和华—我 神所吩咐的将律例典章教训你们，使你们在所要进去得为业的地上遵行。</span>
<span className="v" id="v6" data-v="6" data-xref="约伯记 28:28; 诗篇 111:10; 提摩太后书 3:15"> 所以你们要谨守遵行；这就是你们在万民眼前的智慧、聪明。他们听见这一切律例，必说：『这大国的人真是有智慧，有聪明！』</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 145:18; 撒母耳记下 7:23; 诗篇 34:18"> 哪一大国的人有神与他们相近，像耶和华—我们的 神、在我们求告他的时候与我们相近呢？</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 147:19–20; 罗马书 7:12–14; 诗篇 119:127–128"> 又哪一大国有这样公义的律例典章、像我今日在你们面前所陈明的这一切律法呢？</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 6:7; 申命记 11:19; 诗篇 78:3–8"> 「你只要谨慎，殷勤保守你的心灵，免得忘记你亲眼所看见的事，又免得你一生、这事离开你的心；总要传给你的子子孙孙。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 19:9; 希伯来书 12:18–19; 出埃及记 19:16"> 你在何烈山站在耶和华—你 神面前的那日，耶和华对我说：『你为我招聚百姓，我要叫他们听见我的话，使他们存活在世的日子，可以学习敬畏我，又可以教训儿女这样行。』</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 5:23; 出埃及记 19:16–18; 希伯来书 12:18–19"> 那时你们近前来，站在山下；山上有火焰冲天，并有昏黑、密云、幽暗。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 4:15; 申命记 5:4; 申命记 5:22"> 耶和华从火焰中对你们说话，你们只听见声音，却没有看见形象。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 34:28; 出埃及记 31:18; 申命记 9:9–11"> 他将所吩咐你们当守的约指示你们，就是十条诫，并将这诫写在两块石版上。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 105:44–45; 以西结书 21:1–23"> 那时耶和华又吩咐我将律例典章教训你们，使你们在所要过去得为业的地上遵行。」</span>
</div>
</div>

## 警告人民不可拜偶像

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命记 4:12; 以赛亚书 40:18; 哥林多后书 4:4–6"> 「所以，你们要分外谨慎；因为耶和华在何烈山、从火中对你们说话的那日，你们没有看见什么形象。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 17:29; 申命记 5:8; 出埃及记 20:4–5"> 惟恐你们败坏自己，雕刻偶像，仿佛什么男像女像，</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 1:23"> 或地上走兽的像，或空中飞鸟的像，</span>
<span className="v" id="v18" data-v="18"> 或地上爬物的像，或地底下水中鱼的像。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 1:25; 申命记 17:3; 列王纪下 21:3"> 又恐怕你向天举目观看，见耶和华—你的 神为天下万民所摆列的日月星，就是天上的万象，自己便被勾引敬拜事奉它。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 8:51; 耶利米书 11:4; 出埃及记 19:5–6"> 耶和华将你们从埃及领出来，脱离铁炉，要特作自己产业的子民，像今日一样。</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 1:37; 民数记 20:12; 诗篇 106:32–33"> 耶和华又因你们的缘故向我发怒，起誓必不容我过约旦河，也不容我进入耶和华—你 神所赐你为业的那美地。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 3:25; 申命记 3:27; 彼得后书 1:13–15"> 我只得死在这地，不能过约旦河；但你们必过去得那美地。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 4:9; 希伯来书 3:12; 约书亚记 23:16"> 你们要谨慎，免得忘记耶和华—你们 神与你们所立的约，为自己雕刻偶像，就是耶和华—你 神所禁止你做的偶像；</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 12:29; 那鸿书 1:6; 申命记 9:3"> 因为耶和华—你的 神乃是烈火，是忌邪的 神。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 4:16; 何西阿书 9:9; 哥林多前书 10:22"> 「你们在那地住久了，生子生孙，就雕刻偶像，仿佛什么形象，败坏自己，行耶和华—你 神眼中看为恶的事，惹他发怒。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 32:1; 弥迦书 6:2; 耶利米书 22:29"> 我今日呼天唤地向你们作见证，你们必在过约旦河得为业的地上速速灭尽！你们不能在那地上长久，必尽行除灭。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 28:62–64; 利未记 26:33; 以西结书 12:15"> 耶和华必使你们分散在万民中；在他所领你们到的万国里，你们剩下的人数稀少。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 28:64; 耶利米书 16:13; 申命记 28:36"> 在那里，你们必事奉人手所造的神，就是用木石造成、不能看、不能听、不能吃、不能闻的神。</span>
<span className="v" id="v29" data-v="29" data-xref="诗篇 119:2; 耶利米书 29:12–14; 历代志下 15:4"> 但你们在那里必寻求耶和华—你的 神。你尽心尽性寻求他的时候，就必寻见。</span>
<span className="v" id="v30" data-v="30" data-xref="约珥书 2:12–13; 耶利米书 23:20; 何西阿书 3:5"> 日后你遭遇一切患难的时候，你必归回耶和华—你的 神，听从他的话。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 31:8; 诗篇 116:5; 尼希米记 9:31"> 耶和华—你 神原是有怜悯的 神；他总不撇下你，不灭绝你，也不忘记他起誓与你列祖所立的约。</span>
<span className="v" id="v32" data-v="32" data-xref="约伯记 8:8; 马太福音 24:31; 诗篇 44:1"> 「你且考察在你以前的世代，自 神造人在世以来，从天这边到天那边，曾有何民听见 神在火中说话的声音，像你听见还能存活呢？这样的大事何曾有、何曾听见呢？</span>
<span className="v" id="v34" data-v="34" data-xref="申命记 26:8; 申命记 5:15; 出埃及记 6:6"> 神何曾从别的国中将一国的人民领出来，用试验、神迹、奇事、争战、大能的手，和伸出来的膀臂，并大可畏的事，像耶和华—你们的 神在埃及，在你们眼前为你们所行的一切事呢？</span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 45:18; 撒母耳记上 2:2; 以赛亚书 45:5"> 这是显给你看，要使你知道，惟有耶和华—他是 神，除他以外，再无别神。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 19:9; 出埃及记 19:19; 申命记 4:33"> 他从天上使你听见他的声音，为要教训你，又在地上使你看见他的烈火，并且听见他从火中所说的话。</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 10:15; 以赛亚书 63:9; 出埃及记 13:9"> 因他爱你的列祖，所以拣选他们的后裔，用大能亲自领你出了埃及，</span>
<span className="v" id="v38" data-v="38" data-xref="申命记 7:1; 申命记 9:1–5; 出埃及记 23:27–28"> 要将比你强大的国民从你面前赶出，领你进去，将他们的地赐你为业，像今日一样。</span>
<span className="v" id="v39" data-v="39" data-xref="约书亚记 2:11; 申命记 4:35; 历代志上 29:11"> 所以，今日你要知道，也要记在心上，天上地下惟有耶和华他是 神，除他以外，再无别神。</span>
<span className="v" id="v40" data-v="40" data-xref="申命记 6:3; 以弗所书 6:3; 申命记 12:28"> 我今日将他的律例诫命晓谕你，你要遵守，使你和你的子孙可以得福，并使你的日子在耶和华—你 神所赐的地上得以长久。」</span>
</div>
</div>

## 设立河东的庇护城

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数记 35:6; 民数记 35:14–15; 约书亚记 20:2–9"> 「那时，摩西在约旦河东，向日出之地，分定三座城，</span>
<span className="v" id="v42" data-v="42" data-xref="希伯来书 6:18; 申命记 19:1–10; 民数记 35:15–28"> 使那素无仇恨、无心杀了人的，可以逃到这三城之中的一座城，就得存活：</span>
<span className="v" id="v43" data-v="43" data-xref="约书亚记 20:8; 列王纪上 4:13; 约书亚记 21:27"> 为吕便人分定旷野平原的比悉；为迦得人分定基列的拉末；为玛拿西人分定巴珊的哥兰。」</span>

## 重申律法诫命

<div className="bt">
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="申命记 27:3; 利未记 27:34; 玛拉基书 4:4"> 摩西在以色列人面前所陈明的律法—</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪上 2:3; 申命记 4:1; 诗篇 119:7"> 就是摩西在以色列人出埃及后所传给他们的法度、律例、典章；</span>
<span className="v" id="v46" data-v="46" data-xref="申命记 3:29; 申命记 4:47; 申命记 1:4–5"> 在约旦河东伯·毗珥对面的谷中，在住希实本、亚摩利王西宏之地；这西宏是摩西和以色列人出埃及后所击杀的。</span>
<span className="v" id="v47" data-v="47" data-xref="申命记 3:1–14; 民数记 21:33–35; 申命记 29:7–8"> 他们得了他的地，又得了巴珊王噩的地，就是两个亚摩利王，在约旦河东向日出之地。</span>
<span className="v" id="v48" data-v="48" data-xref="申命记 3:9; 申命记 2:36; 申命记 3:12"> 从亚嫩谷边的亚罗珥，直到西云山，就是黑门山。</span>
<span className="v" id="v49" data-v="49" data-xref="申命记 3:17; 约书亚记 13:20; 申命记 34:1"> 还有约旦河东的全亚拉巴，直到亚拉巴海，靠近毗斯迦山根。</span>
</div>

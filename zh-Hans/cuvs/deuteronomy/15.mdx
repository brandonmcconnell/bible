## 安息年

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 31:10; 出埃及记 23:10–11; 利未记 25:2–4"> 「每逢七年末一年，你要施行豁免。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 7:42; 雅各书 2:13; 路加福音 6:34–38"> 豁免的定例乃是这样：凡债主要把所借给邻舍的豁免了；不可向邻舍和弟兄追讨，因为耶和华的豁免年已经宣告了。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 23:20; 马太福音 17:25–26; 哥林多前书 6:6–7"> 若借给外邦人，你可以向他追讨；但借给你弟兄，无论是什么，你要松手豁免了。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 58:10–11; 箴言 28:27; 箴言 11:24–25"> 你若留意听从耶和华—你 神的话，谨守遵行我今日所吩咐你这一切的命令，就必在你们中间没有穷人了（在耶和华—你 神所赐你为业的地上，耶和华必大大赐福与你。）</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 28:12–13; 路加福音 6:35; 尼希米记 9:27"> 因为耶和华—你的 神必照他所应许你的赐福与你。你必借给许多国民，却不致向他们借贷；你必管辖许多国民，他们却不能管辖你。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰一书 3:16–17; 申命记 15:9; 箴言 21:13"> 「在耶和华—你 神所赐你的地上，无论哪一座城里，你弟兄中若有一个穷人，你不可忍着心、揝着手不帮补你穷乏的弟兄。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 6:34; 马太福音 5:42"> 总要向他松开手，照他所缺乏的借给他，补他的不足。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 24:15; 马太福音 20:15; 耶利米书 17:10"> 你要谨慎，不可心里起恶念，说：『第七年的豁免年快到了』，你便恶眼看你穷乏的弟兄，什么都不给他，以致他因你求告耶和华，罪便归于你了。</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 22:9; 希伯来书 13:16; 以赛亚书 58:10"> 你总要给他，给他的时候心里不可愁烦；因耶和华—你的 神必在你这一切所行的，并你手里所办的事上，赐福与你。</span>
<span className="v" id="v11" data-v="11" data-xref="马可福音 14:7; 马太福音 26:11; 约翰福音 12:8"> 原来那地上的穷人永不断绝；所以我吩咐你说：『总要向你地上困苦穷乏的弟兄松开手。』」</span>
</div>
</div>

## 对待奴婢的条例

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米书 34:14; 利未记 25:39–41; 出埃及记 21:2–6"> 「你弟兄中，若有一个希伯来男人或希伯来女人被卖给你，服事你六年，到第七年就要任他自由出去。</span>
<span className="v" id="v13" data-v="13" data-xref="玛拉基书 3:5; 耶利米书 22:13; 箴言 3:27–28"> 你任他自由的时候，不可使他空手而去，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 16:2; 箴言 10:22; 诗篇 68:10"> 要从你羊群、禾场、酒榨之中多多地给他；耶和华—你的 神怎样赐福与你，你也要照样给他。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 16:12; 马太福音 18:32–33; 申命记 5:14–15"> 要记念你在埃及地作过奴仆，耶和华—你的 神将你救赎；因此，我今日吩咐你这件事。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 21:5–6; 诗篇 40:8; 诗篇 40:6"> 他若对你说：『我不愿意离开你』，是因他爱你和你的家，且因在你那里很好，</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 1:22; 利未记 25:39–42"> 你就要拿锥子将他的耳朵在门上刺透，他便永为你的奴仆了。你待婢女也要这样。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 17:7–8; 以赛亚书 16:14; 以赛亚书 21:16"> 你任他自由的时候，不可以为难事，因他服事你六年，较比雇工的工价多加一倍了。耶和华—你的 神就必在你所做的一切事上赐福与你。」</span>
</div>
</div>

## 头生牛羊的条例

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及记 13:2; 出埃及记 13:12; 利未记 27:26"> 「你牛群羊群中头生的，凡是公的，都要分别为圣，归耶和华—你的 神。牛群中头生的，不可用它耕地；羊群中头生的，不可剪毛。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 12:17; 申命记 14:23; 申命记 12:5–7"> 这头生的，你和你的家属，每年要在耶和华所选择的地方，在耶和华—你 神面前吃。</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 17:1; 玛拉基书 1:7–8; 利未记 22:19–25"> 这头生的若有什么残疾，就如瘸腿的、瞎眼的，无论有什么恶残疾，都不可献给耶和华—你的 神；</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 12:21–22; 申命记 12:15–16"> 可以在你城里吃；洁净人与不洁净人都可以吃，就如吃羚羊与鹿一般。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 12:16; 利未记 7:26; 申命记 12:23"> 只是不可吃它的血；要倒在地上，如同倒水一样。」</span>

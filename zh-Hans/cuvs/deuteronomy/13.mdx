<span className="v" id="v1" data-v="1" data-xref="耶利米书 23:25–28; 约翰一书 4:1; 耶利米书 29:8"> 「你们中间若有先知或是做梦的起来，向你显个神迹奇事，</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 13:6; 马太福音 7:22–23; 启示录 13:13–14"> 对你说：『我们去随从你素来所不认识的别神，事奉它吧。』他所显的神迹奇事虽有应验，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 8:2; 哥林多前书 11:19; 诗篇 66:10"> 你也不可听那先知或是那做梦之人的话；因为这是耶和华—你们的 神试验你们，要知道你们是尽心尽性爱耶和华—你们的 神不是。</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 1:10; 申命记 10:20; 哥林多前书 6:17"> 你们要顺从耶和华—你们的 神，敬畏他，谨守他的诫命，听从他的话，事奉他，专靠他。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 5:13; 申命记 18:20; 耶利米书 14:15"> 那先知或是那做梦的既用言语叛逆那领你们出埃及地、救赎你脱离为奴之家的耶和华—你们的 神，要勾引你离开耶和华—你 神所吩咐你行的道，你便要将他治死。这样，就把那恶从你们中间除掉。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 17:2–7; 彼得后书 2:1; 以弗所书 4:14"> 「你的同胞弟兄，或是你的儿女，或是你怀中的妻，或是如同你性命的朋友，若暗中引诱你，说：『我们不如去事奉你和你列祖素来所不认识的别神—</span>
<span className="v" id="v7" data-v="7"> 是你四围列国的神。』无论是离你近，离你远，从地这边到地那边的神，</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 19:13; 箴言 1:10; 申命记 7:16"> 你不可依从他，也不可听从他，眼不可顾惜他。你不可怜恤他，也不可遮庇他，</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 7:58; 路加福音 14:26; 马太福音 10:37"> 总要杀他；你先下手，然后众民也下手，将他治死。</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 7:25; 利未记 24:14–16; 出埃及记 20:2"> 要用石头打死他，因为他想要勾引你离开那领你出埃及地为奴之家的耶和华—你的 神。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 19:20; 申命记 17:13; 提摩太前书 5:20"> 以色列众人都要听见害怕，就不敢在你们中间再行这样的恶了。</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 20:1–17; 约书亚记 22:11–34"> 「在耶和华—你 神所赐你居住的各城中，你若听人说，有些匪类从你们中间的一座城出来勾引本城的居民，说：『我们不如去事奉你们素来所不认识的别神』；</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 17:4; 以赛亚书 11:3–4; 约翰福音 7:24"> 你就要探听，查究，细细地访问，果然是真，准有这可憎恶的事行在你们中间，</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 22:20; 利未记 27:28; 申命记 7:2"> 你必要用刀杀那城里的居民，把城里所有的，连牲畜，都用刀杀尽。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 49:2; 约书亚记 8:28; 以赛亚书 25:2"> 你从那城里所夺的财物都要堆积在街市上，用火将城和其内所夺的财物都在耶和华—你 神面前烧尽；那城就永为荒堆，不可再建造。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 26:4; 申命记 7:26; 约书亚记 7:26"> 那当毁灭的物连一点都不可粘你的手。你要听从耶和华—你 神的话，遵守我今日所吩咐你的一切诫命，行耶和华—你 神眼中看为正的事，耶和华就必转意，不发烈怒，恩待你，怜恤你，照他向你列祖所起的誓使你人数增多。」</span>

## 十诫

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 4:1; 马太福音 23:3; 申命记 29:10"> 摩西将以色列众人召了来，对他们说：「以色列人哪，我今日晓谕你们的律例典章，你们要听，可以学习，谨守遵行。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 4:23; 出埃及记 19:5–8; 出埃及记 24:8"> 耶和华—我们的 神在何烈山与我们立约。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 29:10–15; 创世记 17:21; 创世记 17:7"> 这约不是与我们列祖立的，乃是与我们今日在这里存活之人立的。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 19:18–19; 申命记 34:10; 出埃及记 19:9"> 耶和华在山上，从火中，面对面与你们说话—</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 3:19; 出埃及记 19:16; 出埃及记 20:18–21"> 那时我站在耶和华和你们中间，要将耶和华的话传给你们；因为你们惧怕那火，没有上山—说：</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 20:2–17; 诗篇 81:5–10; 利未记 26:1–2"> 「『我是耶和华—你的 神，曾将你从埃及地为奴之家领出来。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 20:3; 马太福音 4:10; 约翰一书 5:21"> 「『除了我以外，你不可有别的神。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 20:4; 申命记 4:15–19"> 「『不可为自己雕刻偶像，也不可做什么形象，仿佛上天、下地和地底下、水中的百物。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 20:4–6; 出埃及记 34:7; 但以理书 9:4–9"> 不可跪拜那些像，也不可事奉它，因为我耶和华—你的 神是忌邪的 神。恨我的，我必追讨他的罪，自父及子，直到三、四代；</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 8:28; 约翰一书 1:7; 耶利米书 32:18"> 爱我、守我诫命的，我必向他们发慈爱，直到千代。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 20:7; 利未记 19:12; 申命记 6:13"> 「『不可妄称耶和华—你 神的名；因为妄称耶和华名的，耶和华必不以他为无罪。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 20:8–11; 以赛亚书 58:13; 以赛亚书 56:6"> 「『当照耶和华—你 神所吩咐的守安息日为圣日。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 20:12; 路加福音 13:14–16; 出埃及记 23:12"> 六日要劳碌做你一切的工，</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 4:4; 创世记 2:2; 出埃及记 23:12"> 但第七日是向耶和华—你 神当守的安息日。这一日，你和你的儿女、仆婢、牛、驴、牲畜，并在你城里寄居的客旅，无论何工都不可做，使你的仆婢可以和你一样安息。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 5:6; 申命记 15:15; 申命记 16:12"> 你也要记念你在埃及地作过奴仆；耶和华—你 神用大能的手和伸出来的膀臂将你从那里领出来。因此，耶和华—你的 神吩咐你守安息日。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 20:12; 以弗所书 6:1–3; 歌罗西书 3:20"> 「『当照耶和华—你 神所吩咐的孝敬父母，使你得福，并使你的日子在耶和华—你 神所赐你的地上得以长久。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 20:13; 罗马书 13:9; 马太福音 5:21–22"> 「『不可杀人。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 20:14; 路加福音 18:20; 利未记 20:10"> 「『不可奸淫。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 20:15; 罗马书 13:9; 以弗所书 4:28"> 「『不可偷盗。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 20:16; 出埃及记 23:1; 箴言 19:9"> 「『不可作假见证陷害人。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 20:17; 罗马书 13:9; 路加福音 12:15"> 「『不可贪恋人的妻子；也不可贪图人的房屋、田地、仆婢、牛、驴，并他一切所有的。』</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 24:12; 出埃及记 31:18; 申命记 4:12–15"> 「这些话是耶和华在山上，从火中、云中、幽暗中，大声晓谕你们全会众的；此外并没有添别的话。他就把这话写在两块石版上，交给我了。」</span>
</div>
</div>

## 百姓看见火焰烧山而惧怕

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出埃及记 20:18–19; 希伯来书 12:18–21"> 「那时，火焰烧山，你们听见从黑暗中出来的声音；你们支派中所有的首领和长老都来就近我，</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 4:33; 出埃及记 19:19; 出埃及记 33:20"> 说：『看哪，耶和华—我们 神将他的荣光和他的大能显给我们看，我们又听见他的声音从火中出来。今日我们得见 神与人说话，人还存活。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 18:16; 加拉太书 3:10; 哥林多后书 3:7–9"> 现在这大火将要烧灭我们，我们何必冒死呢？若再听见耶和华—我们 神的声音就必死亡。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 4:33; 罗马书 3:20; 马太福音 26:63"> 凡属血气的，曾有何人听见永生 神的声音从火中出来，像我们听见还能存活呢？</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 20:19; 希伯来书 12:19"> 求你近前去，听耶和华—我们 神所要说的一切话，将他对你说的话都传给我们，我们就听从遵行。』</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 18:17; 民数记 36:5; 民数记 27:7"> 「你们对我说的话，耶和华都听见了。耶和华对我说：『这百姓的话，我听见了；他们所说的都是。</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 48:18; 以西结书 33:31–32; 申命记 11:1"> 惟愿他们存这样的心敬畏我，常遵守我的一切诫命，使他们和他们的子孙永远得福。</span>
<span className="v" id="v30" data-v="30"> 你去对他们说：你们回帐棚去吧！</span>
<span className="v" id="v31" data-v="31" data-xref="加拉太书 3:19; 以西结书 20:11; 申命记 5:1"> 至于你，可以站在我这里，我要将一切诫命、律例、典章传给你；你要教训他们，使他们在我赐他们为业的地上遵行。』</span>
<span className="v" id="v32" data-v="32" data-xref="约书亚记 23:6; 箴言 4:27; 约书亚记 1:7"> 所以，你们要照耶和华—你们 神所吩咐的谨守遵行，不可偏离左右。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 7:23; 申命记 4:40; 路加福音 1:6"> 耶和华—你们 神所吩咐你们行的，你们都要去行，使你们可以存活得福，并使你们的日子在所要承受的地上得以长久。」</span>
</div>

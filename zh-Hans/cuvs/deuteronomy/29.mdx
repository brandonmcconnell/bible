## 在摩押跟以色列人立约

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 5:2–3; 希伯来书 8:9; 出埃及记 24:2–8"> 这是耶和华在摩押地吩咐摩西与以色列人立约的话，是在他和他们于何烈山所立的约之外。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 19:4; 出埃及记 8:12; 约书亚记 24:5–6"> 摩西召了以色列众人来，对他们说：「耶和华在埃及地，在你们眼前向法老和他众臣仆，并他全地所行的一切事，你们都看见了，</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 4:32–35; 尼希米记 9:9–11; 申命记 7:18–19"> 就是你亲眼看见的大试验和神迹，并那些大奇事。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 4:18; 以赛亚书 6:9–10; 箴言 20:12"> 但耶和华到今日没有使你们心能明白，眼能看见，耳能听见。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 8:4; 尼希米记 9:21; 申命记 8:2"> 我领你们在旷野四十年，你们身上的衣服并没有穿破，脚上的鞋也没有穿坏。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 8:3; 以弗所书 5:18; 哥林多前书 9:25"> 你们没有吃饼，也没有喝清酒浓酒。这要使你们知道，耶和华是你们的 神。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 2:24–17; 民数记 32:33–42; 诗篇 135:10–12"> 你们来到这地方，希实本王西宏、巴珊王噩都出来与我们交战，我们就击杀了他们，</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 3:12–13; 民数记 32:33"> 取了他们的地给吕便支派、迦得支派，和玛拿西半支派为业。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 2:3; 申命记 4:6; 路加福音 11:28"> 所以你们要谨守遵行这约的话，好叫你们在一切所行的事上亨通。</span>
<span className="v" id="v10" data-v="10" data-xref="约珥书 2:16–17; 启示录 20:12; 申命记 31:12–13"> 「今日，你们的首领、族长<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="-11 原文是支派">a</a></sup>、长老、官长、以色列的男丁，你们的妻子儿女，和营中寄居的，以及为你们劈柴挑水的人，都站在耶和华—你们的 神面前，</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 15:12–15; 列王纪下 11:17; 申命记 5:2–3"> 为要你顺从耶和华—你 神今日与你所立的约，向你所起的誓。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 6:7; 创世记 17:7; 申命记 28:9"> 这样，他要照他向你所应许的话，又向你列祖亚伯拉罕、以撒、雅各所起的誓，今日立你作他的子民，他作你的 神。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 31:31–34; 希伯来书 8:7–12"> 我不但与你们立这约，起这誓，</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 2:39; 哥林多前书 7:14; 耶利米书 50:5"> 凡与我们一同站在耶和华—我们 神面前的，并今日不在我们这里的人，我也与他们立这约，起这誓。</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 2:19; 申命记 2:9; 申命记 2:4"> 「我们曾住过埃及地，也从列国经过；这是你们知道的。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 28:36"> 你们也看见他们中间可憎之物，并他们木、石、金、银的偶像。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 12:15; 申命记 11:16–17; 申命记 13:1–15"> 惟恐你们中间，或男或女，或族长或支派长，今日心里偏离耶和华—我们的 神，去事奉那些国的神；又怕你们中间有恶根生出苦菜和茵 来，</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 7:24; 民数记 15:30; 民数记 15:39"> 听见这咒诅的话，心里仍是自夸说：『我虽然行事心里顽梗，连累众人，却还是平安。』</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 74:1; 诗篇 79:5; 申命记 9:14"> 耶和华必不饶恕他；耶和华的怒气与愤恨要向他发作，如烟冒出，将这书上所写的一切咒诅都加在他身上。耶和华又要从天下涂抹他的名，</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 25:41; 约书亚记 7:1–26; 以西结书 13:9"> 也必照着写在律法书上、约中的一切咒诅将他从以色列众支派中分别出来，使他受祸。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 19:8"> 你们的后代，就是以后兴起来的子孙，和远方来的外人，看见这地的灾殃，并耶和华所降与这地的疾病，</span>
<span className="v" id="v23" data-v="23" data-xref="西番雅书 2:9; 耶利米书 17:6; 以赛亚书 34:9"> 又看见遍地有硫磺，有盐卤，有火迹，没有耕种，没有出产，连草都不生长—好像耶和华在忿怒中所倾覆的所多玛、蛾摩拉、押玛、洗扁一样—</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 22:8–9; 列王纪上 9:8–9; 罗马书 2:5"> 所看见的人，连万国人，都必问说：『耶和华为何向此地这样行呢？这样大发烈怒是什么意思呢？』</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 8:9; 以赛亚书 47:6; 耶利米书 50:7"> 人必回答说：『是因这地的人离弃了耶和华—他们列祖的 神，领他们出埃及地的时候与他们所立的约，</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 28:64; 士师记 2:12–13; 士师记 5:8"> 去事奉敬拜素不认识的别神，是耶和华所未曾给他们安排的。</span>
<span className="v" id="v27" data-v="27" data-xref="但以理书 9:11–14; 申命记 28:15–68; 申命记 27:15–26"> 所以耶和华的怒气向这地发作，将这书上所写的一切咒诅都降在这地上。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 7:20; 列王纪上 14:15; 诗篇 52:5"> 耶和华在怒气、忿怒、大恼恨中将他们从本地拔出来，扔在别的地上，像今日一样。』</span>
<span className="v" id="v29" data-v="29" data-xref="但以理书 2:22; 使徒行传 1:7; 罗马书 11:33–34"> 「隐秘的事是属耶和华—我们 神的；惟有明显的事是永远属我们和我们子孙的，好叫我们遵行这律法上的一切话。」</span>

## 摩西回忆

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 25:1; 约书亚记 22:7; 民数记 33:17–18"> 以下所记的是摩西在约旦河东的旷野、疏弗对面的亚拉巴—就是巴兰、陀弗、拉班、哈洗录、底撒哈中间—向以色列众人所说的话。（</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 32:8; 民数记 13:26; 申命记 9:23"> 从何烈山经过西珥山到加低斯·巴尼亚有十一天的路程。）</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 33:38; 申命记 4:1–2; 民数记 20:1"> 出埃及第四十年十一月初一日，摩西照耶和华借着他所吩咐以色列人的话都晓谕他们。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 21:21–35; 约书亚记 12:2–6; 约书亚记 13:10–12"> 那时，他已经击杀了住希实本的亚摩利王西宏和住以得来、亚斯他录的巴珊王噩。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 4:8; 申命记 32:46; 申命记 31:9"> 摩西在约旦河东的摩押地讲律法说：</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 3:1; 民数记 10:11–13; 出埃及记 19:1–2"> 「耶和华—我们的 神在何烈山晓谕我们说：你们在这山上住的日子够了；</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 11:24; 约书亚记 10:40; 阿摩司书 2:9"> 要起行转到亚摩利人的山地和靠近这山地的各处，就是亚拉巴、山地、高原、南地，沿海一带迦南人的地，并黎巴嫩山又到幼发拉底大河。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 15:18; 创世记 12:7; 创世记 26:3–4"> 如今我将这地摆在你们面前；你们要进去得这地，就是耶和华向你们列祖亚伯拉罕、以撒、雅各起誓应许赐给他们和他们后裔为业之地。」</span>
</div>
</div>

## 摩西指派审判官

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 18:18; 民数记 11:17; 民数记 11:11–14"> 「那时，我对你们说：『管理你们的重任，我独自担当不起。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 10:22; 出埃及记 32:13; 创世记 22:17"> 耶和华—你们的 神使你们多起来。看哪，你们今日像天上的星那样多。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 115:14; 创世记 22:17; 民数记 6:27"> 惟愿耶和华—你们列祖的 神使你们比如今更多千倍，照他所应许你们的话赐福与你们。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 3:5; 列王纪上 3:7–9; 哥林多后书 2:16"> 但你们的麻烦，和管理你们的重任，并你们的争讼，我独自一人怎能担当得起呢？</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 18:21; 使徒行传 1:21–23; 民数记 11:16–17"> 你们要按着各支派选举有智慧、有见识、为众人所认识的，我立他们为你们的首领。』</span>
<span className="v" id="v14" data-v="14"> 你们回答我说：『照你所说的行了为妙。』</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 16:18; 出埃及记 18:25–26; 以弗所书 4:11"> 我便将你们各支派的首领，有智慧、为众人所认识的，照你们的支派，立他们为官长、千夫长、百夫长、五十夫长、十夫长，管理你们。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰福音 7:24; 出埃及记 22:21; 历代志下 19:6–10"> 「当时，我嘱咐你们的审判官说：『你们听讼，无论是弟兄彼此争讼，是与同居的外人争讼，都要按公义判断。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 16:19; 出埃及记 18:26; 雅各书 2:9"> 审判的时候，不可看人的外貌；听讼不可分贵贱，不可惧怕人，因为审判是属乎 神的。若有难断的案件，可以呈到我这里，我就判断。』</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 12:32; 申命记 4:5; 使徒行传 20:20"> 那时，我将你们所当行的事都吩咐你们了。」</span>
</div>
</div>

## 从加低斯·巴尼亚派探子侦察

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命记 1:2; 申命记 8:15; 耶利米书 2:6"> 「我们照着耶和华—我们 神所吩咐的从何烈山起行，经过你们所看见那大而可怕的旷野，往亚摩利人的山地去，到了加低斯·巴尼亚。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 1:7–8"> 我对你们说：『你们已经到了耶和华—我们 神所赐给我们的亚摩利人之山地。</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 1:9; 诗篇 46:1; 民数记 14:8–9"> 看哪，耶和华—你的 神已将那地摆在你面前，你要照耶和华—你列祖的 神所说的上去得那地为业；不要惧怕，也不要惊惶。』</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 13:1–20"> 你们都就近我来说：『我们要先打发人去，为我们窥探那地，将我们上去该走何道，必进何城，都回报我们。』</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 13:3–33"> 这话我以为美，就从你们中间选了十二个人，每支派一人。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 13:21–27; 约书亚记 2:1–2"> 于是他们起身上山地去，到以实各谷，窥探那地。</span>
<span className="v" id="v25" data-v="25"> 他们手里拿着那地的果子下来，到我们那里，回报说：『耶和华—我们的 神所赐给我们的是美地。』</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="民数记 14:1–4; 使徒行传 7:51; 诗篇 106:24–25"> 「你们却不肯上去，竟违背了耶和华—你们 神的命令，</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 9:28; 诗篇 106:25; 民数记 14:3"> 在帐棚内发怨言说：『耶和华因为恨我们，所以将我们从埃及地领出来，要交在亚摩利人手中，除灭我们。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 13:28–33; 申命记 9:1–2; 约书亚记 15:14"> 我们上哪里去呢？我们的弟兄使我们的心消化，说那地的民比我们又大又高，城邑又广大又坚固，高得顶天，并且我们在那里看见亚衲族的人。』</span>
<span className="v" id="v29" data-v="29"> 我就对你们说：『不要惊恐，也不要怕他们。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 14:14; 尼希米记 4:20; 罗马书 8:31"> 在你们前面行的耶和华—你们的 神必为你们争战，正如他在埃及和旷野，在你们眼前所行的一样。</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 46:3–4; 使徒行传 13:18; 何西阿书 11:3–4"> 你们在旷野所行的路上，也曾见耶和华—你们的 神抚养你们，如同人抚养儿子一般，直等你们来到这地方。』</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 106:24; 犹大书 1:5; 希伯来书 3:18–19"> 你们在这事上却不信耶和华—你们的 神。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 10:33; 诗篇 78:14; 尼希米记 9:12"> 他在路上，在你们前面行，为你们找安营的地方；夜间在火柱里，日间在云柱里，指示你们所当行的路。」</span>
</div>
</div>

## 耶和华刑罚以色列人

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="民数记 14:22–30; 诗篇 95:11; 以西结书 20:15"> 「耶和华听见你们这话，就发怒，起誓说：</span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 95:11"> 『这恶世代的人，连一个也不得见我起誓应许赐给你们列祖的美地；</span>
<span className="v" id="v36" data-v="36" data-xref="民数记 14:24; 约书亚记 14:6–14; 民数记 32:12"> 惟有耶孚尼的儿子迦勒必得看见，并且我要将他所踏过的地赐给他和他的子孙，因为他专心跟从我。』</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 20:12; 申命记 4:21; 申命记 34:4"> 耶和华为你的缘故也向我发怒，说：『你必不得进入那地。</span>
<span className="v" id="v38" data-v="38" data-xref="申命记 3:28; 民数记 14:30; 申命记 31:7–8"> 伺候你、嫩的儿子约书亚，他必得进入那地；你要勉励他，因为他要使以色列人承受那地为业。</span>
<span className="v" id="v39" data-v="39" data-xref="以赛亚书 7:15–16; 民数记 14:3; 民数记 14:31"> 并且你们的妇人孩子，就是你们所说、必被掳掠的，和今日不知善恶的儿女，必进入那地。我要将那地赐给他们，他们必得为业。</span>
<span className="v" id="v40" data-v="40" data-xref="民数记 14:25"> 至于你们，要转回，从红海的路往旷野去。』</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数记 14:39–45; 箴言 19:3; 民数记 22:34"> 「那时，你们回答我说：『我们得罪了耶和华，情愿照耶和华—我们 神一切所吩咐的上去争战。』于是你们各人带着兵器，争先上山地去了。</span>
<span className="v" id="v42" data-v="42" data-xref="民数记 14:41–43; 约书亚记 7:8–13; 以赛亚书 59:1–2"> 耶和华吩咐我说：『你对他们说：不要上去，也不要争战；因我不在你们中间，恐怕你们被仇敌杀败了。』</span>
<span className="v" id="v43" data-v="43" data-xref="民数记 14:44; 以赛亚书 63:10; 使徒行传 7:51"> 我就告诉了你们，你们却不听从，竟违背耶和华的命令，擅自上山地去了。</span>
<span className="v" id="v44" data-v="44" data-xref="诗篇 118:12; 民数记 14:45; 民数记 21:3"> 住那山地的亚摩利人就出来攻击你们，追赶你们，如蜂拥一般，在西珥杀退你们，直到何珥玛。</span>
<span className="v" id="v45" data-v="45" data-xref="希伯来书 12:17; 诗篇 78:34"> 你们便回来，在耶和华面前哭号；耶和华却不听你们的声音，也不向你们侧耳。</span>
<span className="v" id="v46" data-v="46" data-xref="民数记 20:1; 民数记 20:22; 士师记 11:16–17"> 于是你们在加低斯住了许多日子。」</span>
</div>
</div>

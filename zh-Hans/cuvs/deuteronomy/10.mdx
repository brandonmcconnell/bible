## 摩西重新接受十诫

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 34:1–2; 出埃及记 25:10–15; 申命记 10:3–4"> 「那时，耶和华吩咐我说：『你要凿出两块石版，和先前的一样，上山到我这里来，又要做一木柜。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 8:9; 申命记 10:5; 申命记 4:13"> 你先前摔碎的那版，其上的字我要写在这版上；你要将这版放在柜中。』</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 34:4; 出埃及记 37:1–9; 出埃及记 25:10"> 于是我用皂荚木做了一柜，又凿出两块石版，和先前的一样，手里拿这两块版上山去了。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 9:10; 出埃及记 34:28; 希伯来书 12:18–19"> 耶和华将那大会之日、在山上从火中所传与你们的十条诫，照先前所写的，写在这版上，将版交给我了。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 34:29; 出埃及记 40:20; 申命记 10:2"> 我转身下山，将这版放在我所做的柜中，现今还在那里，正如耶和华所吩咐我的。」 （</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 33:38; 民数记 20:23–28; 民数记 33:30–33"> 以色列人从比罗比尼·亚干<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：亚干井">a</a></sup>起行，到了摩西拉。亚伦死在那里，就葬在那里。他儿子以利亚撒接续他供祭司的职分。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 33:32–34"> 他们从那里起行，到了谷歌大，又从谷歌大到了有溪水之地的约巴他。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 21:5; 申命记 18:5; 民数记 6:23–26"> 那时，耶和华将利未支派分别出来，抬耶和华的约柜，又侍立在耶和华面前事奉他，奉他的名祝福，直到今日。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结书 44:28; 民数记 18:20–24; 申命记 18:1–2"> 所以利未人在他弟兄中无分无业，耶和华是他的产业，正如耶和华—你 神所应许他的。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 9:18–19; 申命记 9:25; 出埃及记 34:28"> 「我又像从前在山上住了四十昼夜。那次耶和华也应允我，不忍将你灭绝。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 33:1; 出埃及记 32:34"> 耶和华吩咐我说：『你起来引导这百姓，使他们进去得我向他们列祖起誓应许所赐之地。』」</span>

## 神的要求

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="弥迦书 6:8; 申命记 6:5; 路加福音 10:27"> 「以色列啊，现在耶和华—你 神向你所要的是什么呢？只要你敬畏耶和华—你的 神，遵行他的道，爱他，尽心尽性事奉他，</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 32:39; 申命记 6:24; 雅各书 1:25"> 遵守他的诫命律例，就是我今日所吩咐你的，为要叫你得福。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 19:5; 诗篇 24:1; 诗篇 115:16"> 看哪，天和天上的天，地和地上所有的，都属耶和华—你的 神。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 4:37; 申命记 7:7–8; 罗马书 9:13–23"> 耶和华但喜悦你的列祖，爱他们，从万民中拣选他们的后裔，就是你们，像今日一样。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 4:4; 申命记 30:6; 利未记 26:41"> 所以你们要将心里的污秽除掉，不可再硬着颈项。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 10:34; 罗马书 2:11; 但以理书 2:47"> 因为耶和华—你们的 神—他是万神之神，万主之主，至大的 神，大有能力，大而可畏，不以貌取人，也不受贿赂。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 146:9; 诗篇 68:5; 耶利米书 49:11"> 他为孤儿寡妇伸冤，又怜爱寄居的，赐给他衣食。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 22:21; 利未记 19:33–34; 路加福音 17:18"> 所以你们要怜爱寄居的，因为你们在埃及地也作过寄居的。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 6:13; 申命记 13:4; 路加福音 4:8"> 你要敬畏耶和华—你的 神，事奉他，专靠他，也要指着他的名起誓。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 17:14; 诗篇 106:21–22; 出埃及记 15:2"> 他是你所赞美的，是你的 神，为你做了那大而可畏的事，是你亲眼所看见的。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 46:27; 出埃及记 1:5; 创世记 15:5"> 你的列祖七十人下埃及；现在耶和华—你的 神使你如同天上的星那样多。」</span>
</div>

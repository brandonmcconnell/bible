## 信心和智慧

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="彼得前书 1:6–8; 雅各书 1:12; 哥林多后书 12:9–10"> 我的弟兄们，你们落在百般试炼中，都要以为大喜乐；</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 5:3–4; 希伯来书 10:36; 歌罗西书 1:11"> 因为知道你们的信心经过试验，就生忍耐。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 21:19; 彼得前书 5:10; 马太福音 5:48"> 但忍耐也当成功，使你们成全、完备，毫无缺欠。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 2:3–6; 约翰福音 15:7; 箴言 3:5–7"> 你们中间若有缺少智慧的，应当求那厚赐与众人、也不斥责人的 神，主就必赐给他。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 21:21–22; 希伯来书 11:6; 马可福音 11:22–24"> 只要凭着信心求，一点不疑惑；因为那疑惑的人，就像海中的波浪，被风吹动翻腾。</span>
<span className="v" id="v7" data-v="7" data-xref="雅各书 4:3; 以赛亚书 58:3–4; 箴言 21:27"> 这样的人不要想从主那里得什么。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 18:21; 马太福音 6:24; 雅各书 4:8"> 心怀二意的人，在他一切所行的路上都没有定见。</span>
</div>
</div>

## 贫穷和富有

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="耶利米书 9:23–24; 雅各书 2:5–6; 箴言 19:1"> 卑微的弟兄升高，就该喜乐；</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前书 1:24; 约翰一书 2:17; 约伯记 14:2"> 富足的降卑，也该如此；因为他必要过去，如同草上的花一样。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 40:7–8; 诗篇 37:35–36; 诗篇 49:6–14"> 太阳出来，热风刮起，草就枯干，花也凋谢，美容就消没了；那富足的人，在他所行的事上也要这样衰残。</span>
</div>
</div>

## 考验和试探

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彼得前书 5:10; 彼得前书 1:6–8; 启示录 2:10"> 忍受试探的人是有福的，因为他经过试验以后，必得生命的冠冕；这是主应许给那些爱他之人的。</span>
<span className="v" id="v13" data-v="13" data-xref="哈巴谷书 2:12–13; 雅各书 1:12; 罗马书 9:19–20"> 人被试探，不可说：「我是被 神试探」；因为 神不能被恶试探，他也不试探人。</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 7:21–22; 以弗所书 4:22; 马太福音 15:18"> 但各人被试探，乃是被自己的私欲牵引诱惑的。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 7:14; 约伯记 15:35; 罗马书 5:12–21"> 私欲既怀了胎，就生出罪来；罪既长成，就生出死来。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="加拉太书 6:7; 雅各书 1:19; 腓立比书 2:12"> 我亲爱的弟兄们，不要看错了。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 3:27; 马太福音 7:11; 希伯来书 13:8"> 各样美善的恩赐和各样全备的赏赐都是从上头来的，从众光之父那里降下来的；在他并没有改变，也没有转动的影儿。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 8:29–31; 彼得前书 1:23; 约翰福音 3:3–5"> 他按自己的旨意，用真道生了我们，叫我们在他所造的万物中好像初熟的果子。</span>
</div>
</div>

## 听道和行道

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="箴言 17:27; 箴言 21:23; 箴言 14:29"> 我亲爱的弟兄们，这是你们所知道的。但你们各人要快快地听，慢慢地说，慢慢地动怒，</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太后书 2:24–25; 以弗所书 4:26; 雅各书 3:17–18"> 因为人的怒气并不成就 神的义。</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所书 4:22; 以弗所书 1:13; 彼得前书 2:11"> 所以，你们要脱去一切的污秽和盈余的邪恶，存温柔的心领受那所栽种的道，就是能救你们灵魂的道。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="罗马书 2:13; 路加福音 6:46–48; 约翰福音 13:17"> 只是你们要行道，不要单单听道，自己欺哄自己。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 7:26–27; 以西结书 33:31–32; 雅各书 2:14–26"> 因为听道而不行道的，就像人对着镜子看自己本来的面目，</span>
<span className="v" id="v24" data-v="24" data-xref="彼得后书 3:11; 路加福音 1:66; 路加福音 7:39"> 看见，走后，随即忘了他的相貌如何。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 11:28; 约翰福音 13:17; 哥林多后书 3:17–18"> 惟有详细察看那全备、使人自由之律法的，并且时常如此，这人既不是听了就忘，乃是实在行出来，就在他所行的事上必然得福。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以弗所书 4:29; 诗篇 141:3; 彼得前书 3:10"> 若有人自以为虔诚，却不勒住他的舌头，反欺哄自己的心，这人的虔诚是虚的。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 1:16–17; 约翰一书 3:17–19; 加拉太书 6:9–10"> 在 神我们的父面前，那清洁没有玷污的虔诚，就是看顾在患难中的孤儿寡妇，并且保守自己不沾染世俗。</span>
</div>
</div>

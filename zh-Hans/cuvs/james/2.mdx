## 警告偏私

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="箴言 24:23; 雅各书 2:9; 利未记 19:15"> 我的弟兄们，你们信奉我们荣耀的主耶稣基督，便不可按着外貌待人。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 15:22; 以斯帖记 3:10; 以斯帖记 8:2"> 若有一个人带着金戒指，穿着华美衣服，进你们的会堂去；又有一个穷人穿着肮脏衣服也进去；</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 8:9; 雅各书 2:6; 路加福音 7:44–46"> 你们就重看那穿华美衣服的人，说：「请坐在这好位上」；又对那穷人说：「你站在那里」，或「坐在我脚凳下边。」</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 7:24; 约伯记 34:19; 马太福音 7:1–5"> 这岂不是你们偏心待人，用恶意断定人吗？</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马太福音 5:3; 路加福音 6:20; 启示录 2:9"> 我亲爱的弟兄们，请听， 神岂不是拣选了世上的贫穷人，叫他们在信上富足，并承受他所应许给那些爱他之人的国吗？</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 17:5; 哥林多前书 11:22; 箴言 14:31"> 你们反倒羞辱贫穷人。那富足人岂不是欺压你们、拉你们到公堂去吗？</span>
<span className="v" id="v7" data-v="7" data-xref="腓立比书 2:9–11; 启示录 13:5–6; 提摩太前书 1:13"> 他们不是亵渎你们所敬奉<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="所敬奉：或译被称">a</a></sup>的尊名吗？</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="利未记 19:18; 加拉太书 5:14; 马太福音 22:39"> 经上记着说：「要爱人如己。」你们若全守这至尊的律法才是好的。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 19:15; 雅各书 2:1–4; 约翰一书 3:4"> 但你们若按外貌待人，便是犯罪，被律法定为犯法的。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 3:10; 马太福音 5:18–19; 申命记 27:26"> 因为凡遵守全律法的，只在一条上跌倒，他就是犯了众条。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 20:13–14; 马太福音 5:21–28; 申命记 5:17–18"> 原来那说「不可奸淫」的，也说「不可杀人」；你就是不奸淫，却杀人，仍是成了犯律法的。</span>
<span className="v" id="v12" data-v="12" data-xref="雅各书 1:25; 雅各书 2:8; 彼得后书 1:4–8"> 你们既然要按使人自由的律法受审判，就该照这律法说话行事。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 5:7; 马太福音 6:15; 箴言 21:13"> 因为那不怜悯人的，也要受无怜悯的审判；怜悯原是向审判夸胜。</span>
</div>
</div>

## 信心和行为

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 7:26–27; 马太福音 7:21–23; 雅各书 1:22–25"> 我的弟兄们，若有人说自己有信心，却没有行为，有什么益处呢？这信心能救他吗？</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 3:11; 马太福音 25:35–40; 以赛亚书 58:7"> 若是弟兄或是姊妹，赤身露体，又缺了日用的饮食；</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 3:27–28; 约翰一书 3:16–18; 马太福音 25:42–45"> 你们中间有人对他们说：「平平安安地去吧！愿你们穿得暖，吃得饱」，却不给他们身体所需用的，这有什么益处呢？</span>
<span className="v" id="v17" data-v="17" data-xref="雅各书 2:26; 彼得后书 1:5–9; 雅各书 2:19–20"> 这样，信心若没有行为就是死的。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="雅各书 3:13; 雅各书 2:14; 加拉太书 5:6"> 必有人说：「你有信心，我有行为；你将你没有行为的信心指给我看，我便借着我的行为，将我的信心指给你看。」</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 4:34; 马可福音 1:24; 马太福音 8:29"> 你信 神只有一位，你信的不错；鬼魔也信，却是战惊。</span>
<span className="v" id="v20" data-v="20" data-xref="雅各书 2:17; 雅各书 2:26; 箴言 12:11"> 虚浮的人哪，你愿意知道没有行为的信心是死的吗？</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 22:16–18; 创世记 22:9–12; 约翰福音 8:39"> 我们的祖宗亚伯拉罕把他儿子以撒献在坛上，岂不是因行为称义吗？</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒罗尼迦前书 1:3; 希伯来书 11:17–19; 加拉太书 5:6"> 可见，信心是与他的行为并行，而且信心因着行为才得成全。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 15:6; 以赛亚书 41:8; 历代志下 20:7"> 这就应验经上所说：「亚伯拉罕信 神，这就算为他的义。」他又得称为 神的朋友。</span>
<span className="v" id="v24" data-v="24" data-xref="雅各书 2:21–22; 雅各书 2:15–18; 诗篇 60:12"> 这样看来，人称义是因着行为，不是单因着信。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 11:31; 约书亚记 6:22–25; 约书亚记 2:19–21"> 妓女喇合接待使者，又放他们从别的路上出去，不也是一样因行为称义吗？</span>
<span className="v" id="v26" data-v="26" data-xref="雅各书 2:20; 雅各书 2:17; 雅各书 2:14"> 身体没有灵魂是死的，信心没有行为也是死的。</span>
</div>
</div>

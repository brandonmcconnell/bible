## 论舌头

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:47–48; 提摩太前书 1:7; 彼得前书 5:3"> 我的弟兄们，不要多人作师傅，因为晓得我们要受更重的判断。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各书 1:26; 箴言 13:3; 彼得前书 3:10"> 原来我们在许多事上都有过失；若有人在话语上没有过失，他就是完全人，也能勒住自己的全身。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 32:9; 诗篇 39:1; 雅各书 1:26"> 我们若把嚼环放在马嘴里，叫它顺服，就能调动它的全身。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 107:25–27; 马太福音 8:24; 使徒行传 27:14–38"> 看哪，船只虽然甚大，又被大风催逼，只用小小的舵，就随着掌舵的意思转动。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 18:21; 耶利米书 9:3–8; 箴言 12:18"> 这样，舌头在百体里也是最小的，却能说大话。<br />看哪，最小的火能点着最大的树林。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 120:2–3; 箴言 16:27; 马可福音 7:15"> 舌头就是火，在我们百体中，舌头是个罪恶的世界，能污秽全身，也能把生命的轮子点起来，并且是从地狱里点着的。</span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 5:4"> 各类的走兽、飞禽、昆虫、水族，本来都可以制伏，也已经被人制伏了；</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 3:13; 诗篇 140:3; 诗篇 55:21"> 惟独舌头没有人能制伏，是不止息的恶物，满了害死人的毒气。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 10:7; 创世记 1:26–27; 诗篇 62:4"> 我们用舌头颂赞那为主、为父的，又用舌头咒诅那照着 神形象被造的人。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 12:14; 彼得前书 3:9; 哥林多前书 3:3"> 颂赞和咒诅从一个口里出来！我的弟兄们，这是不应当的！</span>
<span className="v" id="v11" data-v="11"> 泉源从一个眼里能发出甜苦两样的水吗？</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 6:43–44; 马太福音 12:33; 马太福音 7:16–20"> 我的弟兄们，无花果树能生橄榄吗？葡萄树能结无花果吗？咸水里也不能发出甜水来。</span>
</div>
</div>

## 论从上头来的智慧

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="加拉太书 5:23; 雅各书 3:17; 马太福音 5:5"> 你们中间谁是有智慧有见识的呢？他就当在智慧的温柔上显出他的善行来。</span>
<span className="v" id="v14" data-v="14" data-xref="雅各书 3:16; 哥林多前书 13:4; 腓立比书 2:3"> 你们心里若怀着苦毒的嫉妒和纷争，就不可自夸，也不可说谎话抵挡真道。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各书 3:17; 雅各书 1:17; 哥林多前书 3:19"> 这样的智慧不是从上头来的，乃是属地的，属情欲的，属鬼魔的。</span>
<span className="v" id="v16" data-v="16" data-xref="雅各书 3:14; 哥林多前书 3:3; 哥林多前书 14:33"> 在何处有嫉妒、纷争，就在何处有扰乱和各样的坏事。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 5:22–23; 箴言 2:6; 哥林多前书 13:4–7"> 惟独从上头来的智慧，先是清洁，后是和平，温良柔顺，满有怜悯，多结善果，没有偏见，没有假冒。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 5:9; 何西阿书 10:12; 腓立比书 1:11"> 并且使人和平的，是用和平所栽种的义果。</span>
</div>
</div>

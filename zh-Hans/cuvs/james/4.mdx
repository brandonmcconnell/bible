## 不可与世俗为友

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 2:11; 加拉太书 5:17; 罗马书 7:23"> 你们中间的争战斗殴是从哪里来的呢？不是从你们百体中战斗之私欲来的吗？</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 16:24; 马太福音 7:7–8; 雅各书 1:5"> 你们贪恋，还是得不着；你们杀害嫉妒，又斗殴争战，也不能得。你们得不着，是因为你们不求。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰一书 5:14; 约翰一书 3:22; 雅各书 1:6–7"> 你们求也得不着，是因为你们妄求，要浪费在你们的宴乐中。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰一书 2:15–16; 罗马书 8:7; 约翰福音 15:19"> 你们这些淫乱的人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是淫妇">a</a></sup>哪，岂不知与世俗为友就是与 神为敌吗？所以凡想要与世俗为友的，就是与 神为敌了。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 6:16; 哥林多前书 6:19; 民数记 11:29"> 你们想经上所说是徒然的吗？ 神所赐、住在我们里面的灵，是恋爱至于嫉妒吗？</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 23:12; 箴言 3:34; 彼得前书 5:5"> 但他赐更多的恩典，所以经上说：<br /><span className="pl pl-1">神阻挡骄傲的人，</span><br /><span className="pl pl-1">赐恩给谦卑的人。</span></span>
<span className="v" id="v7" data-v="7" data-xref="彼得前书 5:8–9; 以弗所书 4:27; 以弗所书 6:11–12"> 故此，你们要顺服 神。务要抵挡魔鬼，魔鬼就必离开你们逃跑了。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 145:18; 希伯来书 10:22; 玛拉基书 3:7"> 你们亲近 神， 神就必亲近你们。有罪的人哪，要洁净你们的手！心怀二意的人哪，要清洁你们的心！</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 7:10–11; 马太福音 5:4; 路加福音 6:25"> 你们要愁苦、悲哀、哭泣，将喜笑变作悲哀，欢乐变作愁闷。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 147:6; 马太福音 23:12; 彼得前书 5:6"> 务要在主面前自卑，主就必叫你们升高。</span>
</div>
</div>

## 不可论断弟兄

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="彼得前书 2:1; 罗马书 2:1; 雅各书 5:9"> 弟兄们，你们不可彼此批评。人若批评弟兄，论断弟兄，就是批评律法，论断律法。你若论断律法，就不是遵行律法，乃是判断人的。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 14:4; 罗马书 2:1; 马太福音 10:28"> 设立律法和判断人的，只有一位，就是那能救人也能灭人的。你是谁，竟敢论断别人呢？</span>
</div>
</div>

## 警戒自夸

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 27:1; 路加福音 12:17–20; 创世记 11:3–4"> 嗐！你们有话说：「今天明天我们要往某城里去，在那里住一年，做买卖得利。」</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 1:24; 诗篇 39:5; 约翰一书 2:17"> 其实明天如何，你们还不知道。你们的生命是什么呢？你们原来是一片云雾，出现少时就不见了。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 19:21; 希伯来书 6:3; 耶利米哀歌 3:37"> 你们只当说：「主若愿意，我们就可以活着，也可以做这事，或做那事。」</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 27:1; 哥林多前书 5:6; 诗篇 52:7"> 现今你们竟以张狂夸口；凡这样夸口都是恶的。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 9:41; 约翰福音 13:17; 约翰福音 15:22"> 人若知道行善，却不去行，这就是他的罪了。</span>
</div>

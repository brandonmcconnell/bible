## 北方的支派反叛

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="士师记 9:6; 历代志下 10:1–19; 士师记 9:1"> 罗波安往示剑去；因为以色列人都到了示剑要立他作王。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 11:40; 历代志下 10:2–3; 列王纪上 11:26–31"> 尼八的儿子耶罗波安先前躲避所罗门王，逃往埃及，住在那里（他听见这事。）</span>
<span className="v" id="v3" data-v="3"> 以色列人打发人去请他来，他就和以色列会众都来见罗波安，对他说：</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 8:11–18; 列王纪上 4:7; 马太福音 11:29–30"> 「你父亲使我们负重轭，做苦工，现在求你使我们做的苦工、负的重轭轻松些，我们就事奉你。」</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 12:12"> 罗波安对他们说：「你们暂且去，第三日再来见我。」民就去了。</span>
<span className="v" id="v6" data-v="6" data-xref="约伯记 12:12; 约伯记 32:7; 撒母耳记下 16:20"> 罗波安之父所罗门在世的日子，有侍立在他面前的老年人，罗波安王和他们商议，说：「你们给我出个什么主意，我好回复这民。」</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 15:1; 历代志下 10:6–7; 列王纪上 12:13"> 老年人对他说：「现在王若服事这民如仆人，用好话回答他们，他们就永远作王的仆人。」</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 19:20; 传道书 10:2–3; 历代志下 10:8"> 王却不用老年人给他出的主意，就和那些与他一同长大、在他面前侍立的少年人商议，</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 22:6–8; 撒母耳记下 17:5–6; 历代志下 10:9"> 说：「这民对我说：『你父亲使我们负重轭，求你使我们轻松些。』你们给我出个什么主意，我好回复他们。」</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 10:10–11; 箴言 10:14; 以赛亚书 47:6"> 那同他长大的少年人说：「这民对王说：『你父亲使我们负重轭，求你使我们轻松些。』王要对他们如此说：『我的小拇指头比我父亲的腰还粗。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 27:11; 以西结书 2:6; 耶利米书 28:13–14"> 我父亲使你们负重轭，我必使你们负更重的轭！我父亲用鞭子责打你们，我要用蝎子鞭责打你们！』」</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 12:5; 历代志下 10:12–14"> 耶罗波安和众百姓遵着罗波安王所说「你们第三日再来见我」的那话，第三日他们果然来了。</span>
<span className="v" id="v13" data-v="13" data-xref="雅各书 3:17; 箴言 13:20; 传道书 10:12"> 王用严厉的话回答百姓，不用老年人给他所出的主意，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 5:16–18; 列王纪上 12:10–11; 出埃及记 5:5–9"> 照着少年人所出的主意对民说：「我父亲使你们负重轭，我必使你们负更重的轭！我父亲用鞭子责打你们，我要用蝎子鞭责打你们！」</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 12:24; 申命记 2:30; 士师记 14:4"> 王不肯依从百姓，这事乃出于耶和华，为要应验他借示罗人亚希雅对尼八的儿子耶罗波安所说的话。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 20:1; 耶利米书 23:5–6; 历代志下 10:16"> 以色列众民见王不依从他们，就对王说：<br /><span className="pl pl-1">我们与大卫有什么分儿呢？</span><br /><span className="pl pl-1">与耶西的儿子并没有关涉。</span><br /><span className="pl pl-1">以色列人哪，各回各家去吧！</span><br /><span className="pl pl-1">大卫家啊，自己顾自己吧！</span>于是，以色列人都回自己家里去了，</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 11:36; 列王纪上 11:13; 历代志下 11:13–17"> 惟独住犹大城邑的以色列人，罗波安仍作他们的王。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 4:6; 撒母耳记下 20:24; 列王纪上 5:14"> 罗波安王差遣掌管服苦之人的亚多兰往以色列人那里去，以色列人就用石头打死他。罗波安王急忙上车，逃回耶路撒冷去了。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 17:21; 历代志下 10:19; 约书亚记 4:9"> 这样，以色列人背叛大卫家，直到今日。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 11:13; 列王纪上 11:32; 何西阿书 8:4"> 以色列众人听见耶罗波安回来了，就打发人去请他到会众面前，立他作以色列众人的王。除了犹大支派以外，没有顺从大卫家的。</span>
</div>
</div>

## 示玛雅的预言

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="历代志下 11:1–3; 历代志上 21:5; 历代志下 14:8"> 罗波安来到耶路撒冷，招聚犹大全家和便雅悯支派的人共十八万，都是挑选的战士，要与以色列家争战，好将国夺回，再归所罗门的儿子罗波安。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 11:2; 历代志下 12:5–7; 列王纪上 13:1"> 但 神的话临到神人示玛雅，说：</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 12:17"> 「你去告诉所罗门的儿子犹大王罗波安和犹大、便雅悯全家，并其余的民说：</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 12:15; 历代志下 25:7–8; 何西阿书 8:4"> 『耶和华如此说：你们不可上去与你们的弟兄以色列人争战。各归各家去吧！因为这事出于我。』」众人就听从耶和华的话，遵着耶和华的命回去了。</span>
</div>
</div>

## 耶罗波安离弃 神

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="士师记 8:17; 士师记 8:8; 士师记 9:45–49"> 耶罗波安在以法莲山地建筑示剑，就住在其中；又从示剑出去，建筑毗努伊勒。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 38:18–21; 以赛亚书 7:9; 马可福音 2:6–8"> 耶罗波安心里说：「恐怕这国仍归大卫家；</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 12:5–7; 箴言 29:25; 申命记 12:14"> 这民若上耶路撒冷去，在耶和华的殿里献祭，他们的心必归向他们的主—犹大王罗波安，就把我杀了，仍归犹大王罗波安。」</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪下 10:29; 出埃及记 32:8; 列王纪下 17:16"> 耶罗波安王就筹划定妥，铸造了两个金牛犊，对众民说：「以色列人哪，你们上耶路撒冷去实在是难；这就是领你们出埃及地的神。」</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 28:19; 士师记 18:27–31; 何西阿书 4:15"> 他就把牛犊一只安在伯特利，一只安在但。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 17:21; 列王纪上 13:34; 列王纪下 10:31"> 这事叫百姓陷在罪里，因为他们往但去拜那牛犊。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志下 13:9; 列王纪下 17:32; 列王纪上 13:32–33"> 耶罗波安在邱坛那里建殿，将那不属利未人的凡民立为祭司。</span>
</div>
</div>

## 在伯特利拜牛犊被定罪

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="列王纪上 8:5; 列王纪上 8:2; 阿摩司书 7:10–13"> 耶罗波安定八月十五日为节期，像在犹大的节期一样，自己上坛献祭。他在伯特利也这样向他所铸的牛犊献祭，又将立为邱坛的祭司安置在伯特利。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪上 13:1; 民数记 15:39; 马太福音 15:6"> 他在八月十五日，就是他私自所定的月日，为以色列人立作节期的日子，在伯特利上坛烧香。</span>
</div>

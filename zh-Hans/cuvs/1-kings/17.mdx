## 以利亚和旱灾

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 4:25–26; 雅各书 5:17; 路加福音 1:17"> 基列寄居的提斯比人以利亚对亚哈说：「我指着所事奉永生耶和华—以色列的 神起誓，这几年我若不祷告，必不降露，不下雨。」</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 18:1; 耶利米书 7:1; 何西阿书 1:1–2"> 耶和华的话临到以利亚说：</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 12:6; 耶利米书 36:26; 诗篇 83:3"> 「你离开这里往东去，藏在约旦河东边的基立溪旁。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 17:9; 诗篇 147:9; 约伯记 38:41"> 你要喝那溪里的水，我已吩咐乌鸦在那里供养你。」</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 19:9; 马太福音 16:24; 约翰福音 15:14"> 于是以利亚照着耶和华的话，去住在约旦河东的基立溪旁。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 78:23–24; 马太福音 6:31–33; 耶利米书 37:21"> 乌鸦早晚给他叼饼和肉来，他也喝那溪里的水。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 54:10; 以赛亚书 40:30–31"> 过了些日子，溪水就干了，因为雨没有下在地上。</span>
</div>
</div>

## 以利亚和撒勒法的寡妇

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="创世记 22:14; 列王纪上 17:2; 希伯来书 13:6"> 耶和华的话临到他说：</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 4:26; 俄巴底亚书 1:20; 哥林多后书 4:7"> 「你起身往西顿的撒勒法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="撒勒法与路加福音四章二十六节同">a</a></sup>去，住在那里；我已吩咐那里的一个寡妇供养你。」</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 4:7; 创世记 24:17; 创世记 21:15"> 以利亚就起身往撒勒法去。到了城门，见有一个寡妇在那里捡柴，以利亚呼叫她说：「求你用器皿取点水来给我喝。」</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 25:35–40; 列王纪上 18:4; 希伯来书 13:2"> 她去取水的时候，以利亚又呼叫她说：「也求你拿点饼来给我！」</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 15:33–34; 列王纪上 17:1; 创世记 21:16"> 她说：「我指着永生耶和华—你的 神起誓，我没有饼，坛内只有一把面，瓶里只有一点油；我现在找两根柴，回家要为我和我儿子做饼；我们吃了，死就死吧！」</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 6:33; 玛拉基书 3:10; 创世记 22:1–2"> 以利亚对她说：「不要惧怕！可以照你所说的去做吧！只要先为我做一个小饼拿来给我，然后为你和你的儿子做饼。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 15:36–38; 马太福音 14:17–20; 列王纪下 4:42–44"> 因为耶和华—以色列的 神如此说：坛内的面必不减少，瓶里的油必不缺短，直到耶和华使雨降在地上的日子。」</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 11:17; 马可福音 12:43; 马太福音 15:28"> 妇人就照以利亚的话去行。她和她家中的人，并以利亚，吃了许多日子。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 9:28–30; 约翰福音 4:50–51; 路加福音 1:37"> 坛内的面果不减少，瓶里的油也不缺短，正如耶和华借以利亚所说的话。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="彼得前书 1:7; 但以理书 5:23; 约翰福音 11:14"> 这事以后，作那家主母的妇人，她儿子病了；病得甚重，以致身无气息。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 5:8; 约翰福音 2:4; 列王纪下 3:13"> 妇人对以利亚说：「神人哪，我与你何干？你竟到我这里来，使 神想念我的罪，以致我的儿子死呢？」</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 4:32; 列王纪下 4:10; 使徒行传 9:37"> 以利亚对她说：「把你儿子交给我。」以利亚就从妇人怀中将孩子接过来，抱到他所住的楼中，放在自己的床上，</span>
<span className="v" id="v20" data-v="20" data-xref="雅各书 5:15–18; 马太福音 21:22; 约书亚记 7:8–9"> 就求告耶和华说：「耶和华—我的 神啊，我寄居在这寡妇的家里，你就降祸与她，使她的儿子死了吗？」</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 20:10; 使徒行传 9:40; 列王纪下 4:33–35"> 以利亚三次伏在孩子的身上，求告耶和华说：「耶和华—我的 神啊，求你使这孩子的灵魂仍入他的身体！」</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 32:39; 启示录 11:11; 希伯来书 11:35"> 耶和华应允以利亚的话，孩子的灵魂仍入他的身体，他就活了。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 4:36–37; 使徒行传 9:41; 路加福音 7:15"> 以利亚将孩子从楼上抱下来，进屋子交给他母亲，说：「看哪，你的儿子活了！」</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 16:30; 约翰福音 2:11; 约翰福音 3:2"> 妇人对以利亚说：「现在我知道你是神人，耶和华借你口所说的话是真的。」</span>
</div>
</div>

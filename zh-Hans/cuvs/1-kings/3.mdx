## 所罗门祈祷求智慧

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 9:24; 列王纪上 11:1; 列王纪上 6:1–15"> 所罗门与埃及王法老结亲，娶了法老的女儿为妻，接她进入大卫城，直等到造完了自己的宫和耶和华的殿，并耶路撒冷周围的城墙。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 22:43; 历代志下 33:17; 申命记 12:2–5"> 当那些日子，百姓仍在邱坛献祭，因为还没有为耶和华的名建殿。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 8:3; 诗篇 31:23; 申命记 30:16"> 所罗门爱耶和华，遵行他父亲大卫的律例，只是还在邱坛献祭烧香。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 16:39; 历代志下 1:3; 历代志下 7:5"> 所罗门王上基遍去献祭；因为在那里有极大<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：出名">a</a></sup>的邱坛，他在那坛上献一千牺牲作燔祭。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 9:2; 雅各书 1:5–6; 民数记 12:6"> 在基遍，夜间梦中，耶和华向所罗门显现，对他说：「你愿我赐你什么？你可以求。」</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 9:4; 列王纪上 1:48; 哥林多后书 9:11"> 所罗门说：「你仆人—我父亲大卫用诚实、公义、正直的心行在你面前，你就向他大施恩典，又为他存留大恩，赐他一个儿子坐在他的位上，正如今日一样。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 29:1; 民数记 27:17; 耶利米书 1:6"> 耶和华—我的 神啊，如今你使仆人接续我父亲大卫作王；但我是幼童，不知道应当怎样出入。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 15:5; 创世记 13:16; 历代志上 21:2"> 仆人住在你所拣选的民中，这民多得不可胜数。</span>
<span className="v" id="v9" data-v="9" data-xref="雅各书 1:5; 箴言 16:16; 希伯来书 5:14"> 所以求你赐我智慧，可以判断你的民，能辨别是非。不然，谁能判断这众多的民呢？」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="箴言 15:8"> 所罗门因为求这事，就蒙主喜悦。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 8:26; 雅各书 4:2–3; 箴言 16:31"> 神对他说：「你既然求这事，不为自己求寿、求富，也不求灭绝你仇敌的性命，单求智慧可以听讼，</span>
<span className="v" id="v12" data-v="12" data-xref="约翰一书 5:14–15; 传道书 1:16; 马太福音 12:42"> 我就应允你所求的，赐你聪明智慧，甚至在你以前没有像你的，在你以后也没有像你的。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 3:20; 马太福音 6:33; 箴言 3:16"> 你所没有求的，我也赐给你，就是富足、尊荣，使你在世的日子，列王中没有一个能比你的。</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 3:2; 诗篇 91:16; 列王纪上 15:5"> 你若效法你父亲大卫，遵行我的道，谨守我的律例、诫命，我必使你长寿。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="创世记 41:7; 列王纪上 8:65; 以斯帖记 1:3"> 所罗门醒了，不料是个梦。他就回到耶路撒冷，站在耶和华的约柜前，献燔祭和平安祭，又为他众臣仆设摆筵席。</span>
</div>
</div>

## 所罗门审断一件疑难的案件

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及记 18:16; 士师记 11:1; 民数记 27:2"> 一日，有两个妓女来，站在王面前。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 13:7; 创世记 43:20"> 一个说：「我主啊，我和这妇人同住一房；她在房中的时候，我生了一个男孩。</span>
<span className="v" id="v18" data-v="18"> 我生孩子后第三日，这妇人也生了孩子。我们是同住的，除了我们二人之外，房中再没有别人。</span>
<span className="v" id="v19" data-v="19"> 夜间，这妇人睡着的时候，压死了她的孩子。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 3:20; 马太福音 13:25; 诗篇 139:11"> 她半夜起来，趁我睡着，从我旁边把我的孩子抱去，放在她怀里，将她的死孩子放在我怀里。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 21:7; 撒母耳记上 1:23; 耶利米哀歌 4:3–4"> 天要亮的时候，我起来要给我的孩子吃奶，不料，孩子死了；及至天亮，我细细地察看，不是我所生的孩子。」</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 3:23–24"> 那妇人说：「不然，活孩子是我的，死孩子是你的。」这妇人说：「不然，死孩子是你的，活孩子是我的。」她们在王面前如此争论。</span>
<span className="v" id="v23" data-v="23"> 王说：「这妇人说『活孩子是我的，死孩子是你的』，那妇人说『不然，死孩子是你的，活孩子是我的』」，</span>
<span className="v" id="v24" data-v="24"> 就吩咐说：「拿刀来！」人就拿刀来。</span>
<span className="v" id="v25" data-v="25" data-xref="箴言 25:8"> 王说：「将活孩子劈成两半，一半给那妇人，一半给这妇人。」</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 49:15; 耶利米书 31:20; 约翰一书 3:17"> 活孩子的母亲为自己的孩子心里急痛，就说：「求我主将活孩子给那妇人吧，万不可杀他！」那妇人说：「这孩子也不归我，也不归你，把他劈了吧！」</span>
<span className="v" id="v27" data-v="27"> 王说：「将活孩子给这妇人，万不可杀他；这妇人实在是他的母亲。」</span>
<span className="v" id="v28" data-v="28" data-xref="但以理书 2:47; 列王纪上 3:9–12; 歌罗西书 2:3"> 以色列众人听见王这样判断，就都敬畏他；因为见他心里有 神的智慧，能以断案。</span>
</div>
</div>

## 犹大王亚比央

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 14:31; 历代志下 13:1–22"> 尼八的儿子耶罗波安王十八年，亚比央登基作犹大王，</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 13:2; 历代志下 11:20–22; 列王纪上 15:13"> 在耶路撒冷作王三年。他母亲名叫玛迦，是押沙龙的女儿。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 11:4; 诗篇 119:80; 列王纪上 3:14"> 亚比央行他父亲在他以前所行的一切恶，他的心不像他祖大卫的心，诚诚实实地顺服耶和华—他的 神。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 11:36; 历代志下 21:7; 以赛亚书 37:35"> 然而耶和华—他的 神因大卫的缘故，仍使他在耶路撒冷有灯光，叫他儿子接续他作王，坚立耶路撒冷。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 14:8; 撒母耳记下 11:15–17; 列王纪上 15:3"> 因为大卫除 了赫人乌利亚那件事，都是行耶和 华眼中看为正的事，一生没有违背 耶和华一切所吩咐的。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 14:30"> 罗波安在 世的日子常与耶罗波安争战。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 13:2–22; 列王纪上 14:29"> 亚 比央其余的事，凡他所行的，都写在犹大列王记上。亚比央常与耶罗波安争战。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 14:1; 列王纪上 14:31; 马太福音 1:7–8"> 亚比央与他列祖同睡， 葬在大卫的城里。他儿子亚撒接续他作王。</span>
</div>
</div>

## 犹大王亚撒

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9"> 以色列王耶罗波安二十年，亚撒登基作犹大王，</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 15:2; 列王纪上 15:13; 历代志下 13:2"> 在耶路撒冷作王四十一年。他祖母名叫玛迦，是押沙龙的女儿。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 14:2; 历代志下 15:17; 列王纪上 15:3"> 亚撒效法他祖大卫行耶和华眼中看为正的事，</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 22:46; 列王纪上 14:23–24; 历代志下 14:2–5"> 从国中除去娈童，又除掉他列祖所造的一切偶像；</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 32:20; 申命记 7:5; 撒迦利亚书 13:3"> 并且贬了他祖母玛迦太后的位，因她造了可憎的偶像亚舍拉。亚撒砍下她的偶像，烧在汲沦溪边，</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 22:43; 列王纪上 8:61; 列王纪上 15:3"> 只是邱坛还没有废去。亚撒一生却向耶和华存诚实的心。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 7:51; 历代志下 14:13; 历代志下 15:18"> 亚撒将他父亲所分别为圣与自己所分别为圣的金银和器皿都奉到耶和华的殿里。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 15:32; 列王纪上 14:30; 历代志下 16:1–6"> 亚撒和以色列王巴沙在世的日子常常争战。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 12:27; 历代志下 16:1–6; 约书亚记 18:25"> 以色列王巴沙上来要攻击犹大，修筑拉玛，不许人从犹大王亚撒那里出入。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 14:26; 列王纪下 12:18; 列王纪上 11:23–24"> 于是亚撒将耶和华殿和王宫府库里所剩下的金银都交在他臣仆手中，打发他们往住大马士革的亚兰王—希旬的孙子、他伯利们的儿子便·哈达那里去，</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 1:31; 历代志下 16:7; 罗马书 3:8"> 说：「你父曾与我父立约，我与你也要立约。现在我将金银送你为礼物，求你废掉你与以色列王巴沙所立的约，使他离开我。」</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 15:29; 士师记 18:29; 约书亚记 11:2"> 便·哈达听从亚撒王的话，派军长去攻击以色列的城邑；他们就攻破以云、但、亚伯·伯·玛迦、基尼烈全境、拿弗他利全境。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 14:17; 列王纪上 16:15–18; 历代志下 16:5"> 巴沙听见，就停工不修筑拉玛了，仍住在得撒。</span>
<span className="v" id="v22" data-v="22" data-xref="约书亚记 21:17; 约书亚记 18:24; 约书亚记 18:26"> 于是亚撒王宣告犹大众人，不准一个推辞，吩咐他们将巴沙修筑拉玛所用的石头、木头都运去，用以修筑便雅悯的迦巴和米斯巴。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 16:11–14; 列王纪上 14:29–31; 列王纪上 15:7–8"> 亚撒其余的事，凡他所行的，并他的勇力与他所建筑的城邑，都写在犹大列王记上。亚撒年老的时候，脚上有病。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 1:8; 列王纪上 22:41–43; 历代志下 17:1–9"> 亚撒与他列祖同睡，葬在他祖大卫城他列祖的坟地里。他儿子约沙法接续他作王。</span>
</div>
</div>

## 以色列王拿答

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王纪上 14:20; 列王纪上 14:12"> 犹大王亚撒第二年，耶罗波安的儿子拿答登基作以色列王共二年，</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 14:16; 列王纪上 15:34; 列王纪上 15:30"> 拿答行耶和华眼中看为恶的事，行他父亲所行的，犯他父亲使以色列人陷在罪里的那罪。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 19:44; 约书亚记 21:23; 列王纪上 14:14"> 以萨迦人亚希雅的儿子巴沙背叛拿答，在非利士的基比顿杀了他。那时拿答和以色列众人正围困基比顿。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 32:35"> 在犹大王亚撒第三年巴沙杀了他，篡了他的位。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪上 14:9–16; 列王纪下 19:25; 列王纪下 10:10–11"> 巴沙一作王就杀了耶罗波安的全家，凡有气息的没有留下一个，都灭尽了，正应验耶和华借他仆人示罗人亚希雅所说的话。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 15:26; 列王纪上 14:22; 列王纪上 14:9–16"> 这是因为耶罗波安所犯的罪使以色列人陷在罪里，惹动耶和华—以色列 神的怒气。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪上 14:19; 列王纪上 16:20; 列王纪上 16:14"> 拿答其余的事，凡他所行的，都写在以色列诸王记上。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 15:16"> 亚撒和以色列王巴沙在世的日子常常争战。</span>
</div>
</div>

## 以色列王巴沙

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="列王纪上 16:8"> 犹大王亚撒第三年，亚希雅的儿子巴沙在得撒登基作以色列众人的王共二十四年。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 15:26; 列王纪上 14:16; 列王纪上 12:28–29"> 他行耶和华眼中看为恶的事，行耶罗波安所行的道，犯他使以色列人陷在罪里的那罪。</span>
</div>
</div>

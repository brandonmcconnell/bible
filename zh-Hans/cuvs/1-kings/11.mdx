## 所罗门离弃 神

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 17:17; 箴言 6:24; 尼希米记 13:23–27"> 所罗门王在法老的女儿之外，又宠爱许多外邦女子，就是摩押女子、亚扪女子、以东女子、西顿女子、赫人女子。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 34:16; 申命记 7:3–4; 约书亚记 23:12–13"> 论到这些国的人，耶和华曾晓谕以色列人说：「你们不可与她们往来相通，因为她们必诱惑你们的心去随从她们的神。」所罗门却恋爱这些女子。</span>
<span className="v" id="v3" data-v="3" data-xref="传道书 7:28; 撒母耳记下 5:13–16; 历代志下 11:21"> 所罗门有妃七百，都是公主；还有嫔三百。这些妃嫔诱惑他的心。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 9:4; 列王纪上 8:61; 列王纪上 11:6"> 所罗门年老的时候，他的妃嫔诱惑他的心去随从别神，不效法他父亲大卫诚诚实实地顺服耶和华—他的 神。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 2:13; 列王纪上 11:7; 列王纪下 23:13"> 因为所罗门随从西顿人的女神亚斯她录和亚扪人可憎的神米勒公。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 14:24; 约书亚记 14:8; 约书亚记 14:14"> 所罗门行耶和华眼中看为恶的事，不效法他父亲大卫专心顺从耶和华。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 21:29; 士师记 11:24; 使徒行传 7:43"> 所罗门为摩押可憎的神基抹和亚扪人可憎的神摩洛，在耶路撒冷对面的山上建筑邱坛。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 10:11–12; 列王纪上 11:1; 以西结书 16:22–29"> 他为那些向自己的神烧香献祭的外邦女子，就是他娶来的妃嫔也是这样行。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 9:2; 列王纪上 3:5; 申命记 7:4"> 耶和华向所罗门发怒，因为他的心偏离向他两次显现的耶和华—以色列的 神。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 6:12–13; 历代志下 7:17–22; 列王纪上 9:4–7"> 耶和华曾吩咐他不可随从别神，他却没有遵守耶和华所吩咐的。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 12:15–16; 列王纪上 11:31; 列王纪下 17:21"> 所以耶和华对他说：「你既行了这事，不遵守我所吩咐你守的约和律例，我必将你的国夺回，赐给你的臣子。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 20:19; 撒母耳记上 9:4–5; 列王纪下 22:19–20"> 然而，因你父亲大卫的缘故，我不在你活着的日子行这事，必从你儿子的手中将国夺回。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 12:20; 申命记 12:11; 列王纪上 11:32"> 只是我不将全国夺回，要因我仆人大卫和我所选择的耶路撒冷，还留一支派给你的儿子。」</span>
</div>
</div>

## 所罗门的敌人

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志上 5:26; 诗篇 89:30–34; 以赛亚书 13:17"> 耶和华使以东人哈达兴起，作所罗门的敌人；他是以东王的后裔。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 8:14; 历代志上 18:12–13; 申命记 20:13"> 先前大卫攻击以东，元帅约押上去葬埋阵亡的人，将以东的男丁都杀了。</span>
<span className="v" id="v16" data-v="16"> 约押和以色列众人在以东住了六个月，直到将以东的男丁尽都剪除。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 2:13–14; 出埃及记 2:1–10; 列王纪下 11:2"> 那时哈达还是幼童；他和他父亲的臣仆，几个以东人逃往埃及。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 10:12; 申命记 33:2; 申命记 1:1"> 他们从米甸起行，到了巴兰；从巴兰带着几个人来到埃及见埃及王法老；法老为他派定粮食，又给他房屋田地。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 39:4; 耶利米书 43:7–9; 创世记 39:21"> 哈达在法老面前大蒙恩惠，以致法老将王后答比匿的妹子赐他为妻。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 21:7; 撒母耳记上 1:24"> 答比匿的妹子给哈达生了一个儿子，名叫基努拔。答比匿使基努拔在法老的宫里断奶，基努拔就与法老的众子一同住在法老的宫里。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 2:10; 出埃及记 4:19; 马太福音 2:20"> 哈达在埃及听见大卫与他列祖同睡，元帅约押也死了，就对法老说：「求王容我回本国去。」</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 18:22–23; 路加福音 22:35; 马可福音 14:31"> 法老对他说：「你在我这里有什么缺乏，你竟要回你本国去呢？」他回答说：「我没有缺乏什么，只是求王容我回去。」</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 11:14; 撒母耳记下 8:3; 撒母耳记下 10:15–18"> 神又使以利亚大的儿子利逊兴起，作所罗门的敌人。他先前逃避主人琐巴王哈大底谢。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 10:8; 撒母耳记下 10:18; 列王纪上 20:34"> 大卫击杀琐巴人的时候，利逊招聚了一群人，自己作他们的头目，往大马士革居住，在那里作王。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 15:2; 诗篇 106:40; 列王纪上 5:4"> 所罗门活着的时候，哈达为患之外，利逊也作以色列的敌人。他恨恶以色列人，且作了亚兰人的王。</span>
</div>
</div>

## 神给耶罗波安的应许

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="历代志下 13:6; 列王纪上 12:2; 列王纪上 11:28"> 所罗门的臣仆、尼八的儿子耶罗波安也举手攻击王。他是以法莲支派的洗利达人，他母亲是寡妇，名叫洗鲁阿。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 9:24; 列王纪上 9:15; 箴言 30:32"> 他举手攻击王的缘故，乃由先前所罗门建造米罗，修补他父亲大卫城的破口。</span>
<span className="v" id="v28" data-v="28" data-xref="箴言 22:29; 撒母耳记下 19:20; 士师记 1:22–23"> 耶罗波安是大有才能的人。所罗门见这少年人殷勤，就派他监管约瑟家的一切工程。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪上 12:15; 列王纪上 14:2; 历代志下 9:29"> 一日，耶罗波安出了耶路撒冷，示罗人先知亚希雅在路上遇见他；亚希雅身上穿着一件新衣。他们二人在田野，以外并无别人。</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 15:27–28; 撒母耳记上 24:4–5"> 亚希雅将自己穿的那件新衣撕成十二片，</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪上 11:11–12"> 对耶罗波安说：「你可以拿十片。耶和华—以色列的 神如此说：『我必将国从所罗门手里夺回，将十个支派赐给你。（</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 11:13; 列王纪上 12:20–21; 列王纪上 14:21"> 我因仆人大卫和我在以色列众支派中所选择的耶路撒冷城的缘故，仍给所罗门留一个支派。）</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪上 11:9; 列王纪上 11:5–7; 列王纪上 9:5–7"> 因为他离弃我，敬拜西顿人的女神亚斯她录、摩押的神基抹，和亚扪人的神米勒公，没有遵从我的道，行我眼中看为正的事，守我的律例典章，像他父亲大卫一样。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 11:12–13; 列王纪上 11:31; 约伯记 11:6"> 但我不从他手里将全国夺回；使他终身为君，是因我所拣选的仆人大卫谨守我的诫命律例。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 12:20; 列王纪上 11:12; 出埃及记 20:5–6"> 我必从他儿子的手里将国夺回，以十个支派赐给你，</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪下 8:19; 列王纪上 11:13; 列王纪上 15:4"> 还留一个支派给他的儿子，使我仆人大卫在我所选择立我名的耶路撒冷城里，在我面前长有灯光。</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 14:26; 列王纪上 11:26; 撒母耳记下 3:21"> 我必拣选你，使你照心里一切所愿的，作王治理以色列。</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳记下 7:11; 约书亚记 1:5; 申命记 31:8"> 你若听从我一切所吩咐你的，遵行我的道，行我眼中看为正的事，谨守我的律例诫命，像我仆人大卫所行的，我就与你同在，为你立坚固的家，像我为大卫所立的一样，将以色列人赐给你。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 1:32–33; 路加福音 2:11; 以赛亚书 11:1–10"> 我必因所罗门所行的使大卫后裔受患难，但不至于永远。』」</span>
<span className="v" id="v40" data-v="40" data-xref="历代志下 12:2–9; 以赛亚书 14:24–27; 耶利米哀歌 3:37"> 所罗门因此想要杀耶罗波安。耶罗波安却起身逃往埃及；到了埃及王示撒那里，就住在埃及，直到所罗门死了。</span>
</div>
</div>

## 所罗门去世

<div className="bt">
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="历代志下 9:29–31"> 所罗门其余的事，凡他所行的和他的智慧都写在所罗门记上。</span>
<span className="v" id="v42" data-v="42" data-xref="列王纪上 2:11"> 所罗门在耶路撒冷作以色列众人的王共四十年。</span>
<span className="v" id="v43" data-v="43" data-xref="列王纪下 21:18; 列王纪上 2:10; 马太福音 1:7"> 所罗门与他列祖同睡，葬在他父亲大卫的城里。他儿子罗波安接续他作王。</span>
</div>

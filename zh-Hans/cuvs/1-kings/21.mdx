## 拿伯的葡萄园

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 6:33; 历代志下 28:22; 约书亚记 19:18"> 这事以后，又有一事。耶斯列人拿伯在耶斯列有一个葡萄园，靠近撒马利亚王亚哈的宫。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 8:14; 雅各书 1:14–15; 提摩太前书 6:9"> 亚哈对拿伯说：「你将你的葡萄园给我作菜园，因为是靠近我的宫；我就把更好的葡萄园换给你，或是你要银子，我就按着价值给你。」</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 36:7; 利未记 25:23; 以西结书 46:18"> 拿伯对亚哈说：「我敬畏耶和华，万不敢将我先人留下的产业给你。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 20:43; 雅各书 1:14; 约拿书 4:9"> 亚哈因耶斯列人拿伯说「我不敢将我先人留下的产业给你」，就闷闷不乐地回宫，躺在床上，转脸向内，也不吃饭。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪上 16:31; 创世记 3:6; 列王纪上 19:2"> 王后耶洗别来问他说：「你为什么心里这样忧闷，不吃饭呢？」</span>
<span className="v" id="v6" data-v="6" data-xref="以斯帖记 5:9–14; 雅各书 4:2–7; 提摩太前书 6:9–10"> 他回答说：「因我向耶斯列人拿伯说：『你将你的葡萄园给我，我给你价银，或是你愿意，我就把别的葡萄园换给你』；他却说：『我不将我的葡萄园给你。』」</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 8:14; 弥迦书 7:3; 撒母耳记下 13:4"> 王后耶洗别对亚哈说：「你现在是治理以色列国不是？只管起来，心里畅畅快快地吃饭，我必将耶斯列人拿伯的葡萄园给你。」</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="尼希米记 6:5; 列王纪下 10:11; 以斯拉记 4:7–8"> 于是托亚哈的名写信，用王的印印上，送给那些与拿伯同城居住的长老贵胄。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 58:4; 马太福音 23:13; 路加福音 20:47"> 信上写着说：「你们当宣告禁食，叫拿伯坐在民间的高位上，</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 22:28; 使徒行传 6:11; 利未记 24:15–16"> 又叫两个匪徒坐在拿伯对面，作见证告他说：『你谤渎 神和王了』；随后就把他拉出去用石头打死。」</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 4:19; 利未记 19:15; 列王纪下 10:6–7"> 那些与拿伯同城居住的长老贵胄得了耶洗别的信，就照信而行，</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 58:4; 列王纪上 21:8–10"> 宣告禁食，叫拿伯坐在民间的高位上。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 9:26; 申命记 22:24; 传道书 10:20"> 有两个匪徒来，坐在拿伯的对面，当着众民作见证告他说：「拿伯谤渎 神和王了！」众人就把他拉到城外，用石头打死。</span>
<span className="v" id="v14" data-v="14" data-xref="传道书 8:14; 撒母耳记下 11:14–24; 传道书 5:8"> 于是打发人去见耶洗别，说：「拿伯被石头打死了。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="箴言 1:10–16; 箴言 4:17; 列王纪上 21:7"> 耶洗别听见拿伯被石头打死，就对亚哈说：「你起来得耶斯列人拿伯不肯为价银给你的葡萄园吧！现在他已经死了。」</span>
<span className="v" id="v16" data-v="16" data-xref="俄巴底亚书 1:12–14; 罗马书 1:32; 撒母耳记下 11:25–27"> 亚哈听见拿伯死了，就起来，下去要得耶斯列人拿伯的葡萄园。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="诗篇 9:12; 以赛亚书 26:21; 列王纪下 5:26"> 耶和华的话临到提斯比人以利亚说：</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 13:32; 历代志下 22:9"> 「你起来，去见住撒马利亚的以色列王亚哈，他下去要得拿伯的葡萄园，现今正在那园里。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 22:38; 撒母耳记下 12:9; 哈巴谷书 2:9"> 你要对他说：『耶和华如此说：你杀了人，又得他的产业吗？』又要对他说：『耶和华如此说：狗在何处舔拿伯的血，也必在何处舔你的血。』」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王纪下 17:17; 罗马书 7:14; 列王纪上 21:25"> 亚哈对以利亚说：「我仇敌啊，你找到我吗？」他回答说：「我找到你了；因为你卖了自己，行耶和华眼中看为恶的事。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 14:10; 撒母耳记上 25:34; 列王纪下 10:1–7"> 耶和华说：『我必使灾祸临到你，将你除尽。凡属你的男丁，无论困住的、自由的，都从以色列中剪除。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 16:3; 列王纪上 14:16; 列王纪上 16:11"> 我必使你的家像尼八的儿子耶罗波安的家，又像亚希雅的儿子巴沙的家；因为你惹我发怒，又使以色列人陷在罪里。』</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 9:10; 列王纪下 9:30–37; 列王纪上 21:25"> 论到耶洗别，耶和华也说：『狗在耶斯列的外郭必吃耶洗别的肉。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 16:4; 列王纪上 14:11; 耶利米书 15:3"> 凡属亚哈的人，死在城中的必被狗吃，死在田野的必被空中的鸟吃。』」<br />（</span>
<span className="v" id="v25" data-v="25" data-xref="箴言 22:14; 列王纪上 21:20; 列王纪上 16:30–33"> 从来没有像亚哈的，因他自卖，行耶和华眼中看为恶的事，受了王后耶洗别的耸动；</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 21:11; 创世记 15:16; 利未记 18:25–30"> 就照耶和华在以色列人面前所赶出的亚摩利人，行了最可憎恶的事，信从偶像。）</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="列王纪下 6:30; 创世记 37:34; 撒母耳记下 3:31"> 亚哈听见这话，就撕裂衣服，禁食，身穿麻布，睡卧也穿着麻布，并且缓缓而行。</span>
<span className="v" id="v28" data-v="28"> 耶和华的话临到提斯比人以利亚说：</span>
<span className="v" id="v29" data-v="29" data-xref="彼得后书 3:9; 弥迦书 7:18; 诗篇 86:15"> 「亚哈在我面前这样自卑，你看见了吗？因他在我面前自卑，他还在世的时候，我不降这祸；到他儿子的时候，我必降这祸与他的家。」</span>
</div>

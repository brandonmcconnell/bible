<span className="v" id="v2" data-v="2" data-xref="列王纪上 15:34; 列王纪上 14:7; 撒母耳记上 2:8"> 「我既从尘埃中提拔你，立你作我民以色列的君，你竟行耶罗波安所行的道，使我民以色列陷在罪里，惹我发怒，</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 14:10; 列王纪上 15:29–30; 以赛亚书 66:24"> 我必除尽你和你的家，使你的家像尼八的儿子耶罗波安的家一样。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 14:11; 列王纪上 21:24"> 凡属巴沙的人，死在城中的必被狗吃，死在田野的必被空中的鸟吃。」</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪上 14:19; 列王纪上 15:31; 历代志下 16:1–6"> 巴沙其余的事，凡他所行的和他的勇力，都写在以色列诸王记上。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 14:17; 列王纪上 15:21; 列王纪上 16:13–14"> 巴沙与他列祖同睡，葬在得撒。他儿子以拉接续他作王。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 14:14; 何西阿书 1:4; 诗篇 115:4"> 耶和华的话临到哈拿尼的儿子先知耶户，责备巴沙和他的家，因他行耶和华眼中看为恶的一切事，以他手所做的惹耶和华发怒，像耶罗波安的家一样，又因他杀了耶罗波安的全家。</span>

## 以色列王以拉

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8"> 犹大王亚撒二十六年，巴沙的儿子以拉在得撒登基作以色列王共二年。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 18:3; 创世记 39:4; 但以理书 5:1–4"> 有管理他一半战车的臣子心利背叛他。当他在得撒家宰亚杂家里喝醉的时候，</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 9:31"> 心利就进去杀了他，篡了他的位。这是犹大王亚撒二十七年的事。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 25:22; 列王纪上 16:3; 列王纪上 15:29"> 心利一坐王位就杀了巴沙的全家，连他的亲属、朋友也没有留下一个男丁。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 16:1; 列王纪上 16:7; 历代志下 10:15"> 心利这样灭绝巴沙的全家，正如耶和华借先知耶户责备巴沙的话。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 32:21; 列王纪上 15:30; 以赛亚书 41:29"> 这是因巴沙和他儿子以拉的一切罪，就是他们使以色列人陷在罪里的那罪，以虚无的神惹耶和华—以色列 神的怒气。</span>
<span className="v" id="v14" data-v="14"> 以拉其余的事，凡他所行的，都写在以色列诸王记上。</span>
</div>
</div>

## 以色列王心利

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王纪上 15:27; 约书亚记 19:44; 约伯记 20:5"> 犹大王亚撒二十七年，心利在得撒作王七日。那时民正安营围攻非利士的基比顿。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 22:2; 列王纪下 8:26; 弥迦书 6:16"> 民在营中听说心利背叛，又杀了王，故此以色列众人当日在营中立元帅暗利作以色列王。</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 9:50; 路加福音 19:43–44; 列王纪下 18:9–12"> 暗利率领以色列众人，从基比顿上去，围困得撒。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 17:23; 撒母耳记上 31:4–5; 约伯记 2:9–10"> 心利见城破失，就进了王宫的卫所，放火焚烧宫殿，自焚而死。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 15:26; 列王纪上 14:16; 列王纪上 12:28"> 这是因他犯罪，行耶和华眼中看为恶的事，行耶罗波安所行的，犯他使以色列人陷在罪里的那罪。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 16:14; 列王纪上 16:5; 列王纪上 16:27"> 心利其余的事和他背叛的情形都写在以色列诸王记上。</span>
</div>
</div>

## 以色列王暗利

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马太福音 12:25; 以弗所书 4:3–5; 箴言 28:2"> 那时，以色列民分为两半：一半随从基纳的儿子提比尼，要立他作 王；一半随从暗利。</span>
<span className="v" id="v22" data-v="22"> 但随从暗利的民胜过随从基纳的儿子提比尼的民。提比尼死了，暗利就作了王。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 16:8; 列王纪上 16:29; 历代志下 22:2"> 犹大王亚撒三十一年，暗利登基作以色列王共十二年；在得撒作王六年。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 13:32; 列王纪上 16:32; 使徒行传 8:5–8"> 暗利用二他连得银子向撒玛买了撒马利亚山，在山上造城，就按着山的原主撒玛的名，给所造的城起名叫撒马利亚。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="弥迦书 6:16; 列王纪上 16:30–31; 列王纪上 14:9"> 暗利行耶和华眼中看为恶的事，比他以前的列王作恶更甚。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 16:19; 列王纪上 16:13; 列王纪上 12:26–33"> 因他行了尼八的儿子耶罗波安所行的，犯他使以色列人陷在罪里的那罪，以虚无的神惹耶和华—以色列 神的怒气。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 16:20; 列王纪上 16:14; 列王纪上 16:5"> 暗利其余的事和他所显出的勇力都写在以色列诸王记上。</span>
<span className="v" id="v28" data-v="28"> 暗利与他列祖同睡，葬在撒马利亚。他儿子亚哈接续他作王。</span>
</div>
</div>

## 以色列王亚哈

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29"> 犹大王亚撒三十八年，暗利的儿子亚哈登基作了以色列王。暗利的儿子亚哈在撒马利亚作以色列王二十二年。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 16:25; 列王纪上 21:25; 列王纪上 14:9"> 暗利的儿子亚哈行耶和华眼中看为恶的事，比他以前的列王更甚，</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 17:16; 列王纪下 10:18; 士师记 18:7"> 犯了尼八的儿子耶罗波安所犯的罪；他还以为轻，又娶了西顿王谒巴力的女儿耶洗别为妻，去事奉敬拜巴力，</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪下 10:21; 列王纪下 10:26–27"> 在撒马利亚建造巴力的庙，在庙里为巴力筑坛。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪下 13:6; 列王纪上 21:25; 列王纪下 21:3"> 亚哈又做亚舍拉，他所行的惹耶和华—以色列 神的怒气，比他以前的以色列诸王更甚。</span>
<span className="v" id="v34" data-v="34" data-xref="约书亚记 6:26; 约书亚记 23:14–15; 马太福音 24:35"> 亚哈在位的时候，有伯特利人希伊勒重修耶利哥城；立根基的时候，丧了长子亚比兰；安门的时候，丧了幼子西割，正如耶和华借嫩的儿子约书亚所说的话。</span>
</div>
</div>

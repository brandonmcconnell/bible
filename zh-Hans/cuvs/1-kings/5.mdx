## 所罗门准备建殿

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 14:1; 历代志下 2:3; 列王纪上 5:10"> 泰尔王希兰，平素爱大卫；他听见以色列人膏所罗门，接续他父亲作王，就差遣臣仆来见他。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 2:3"> 所罗门也差遣人去见希兰，说：</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 28:3; 历代志上 22:8; 诗篇 110:1"> 「你知道我父亲大卫因四围的争战，不能为耶和华—他 神的名建殿，直等到耶和华使仇敌都服在他脚下。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 22:9; 列王纪上 4:24; 使徒行传 9:31"> 现在耶和华—我的 神使我四围平安，没有仇敌，没有灾祸。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 17:12; 历代志上 22:10; 撒母耳记下 7:12–13"> 我定意要为耶和华—我 神的名建殿，是照耶和华应许我父亲大卫的话说：『我必使你儿子接续你坐你的位，他必为我的名建殿。』</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 2:8; 列王纪上 6:9–10; 罗马书 12:17"> 所以求你吩咐你的仆人在黎巴嫩为我砍伐香柏木，我的仆人也必帮助他们，我必照你所定的，给你仆人的工价；因为你知道，在我们中间没有人像西顿人善于砍伐树木。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="箴言 23:24; 以赛亚书 9:6; 历代志下 2:11–12"> 希兰听见所罗门的话，就甚喜悦，说：「今日应当称颂耶和华；因他赐给大卫一个有智慧的儿子，治理这众多的民。」</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 6:34; 历代志下 3:5; 撒母耳记下 6:5"> 希兰打发人去见所罗门，说：「你差遣人向我所提的那事，我都听见了；论到香柏木和松木，我必照你的心愿而行。</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉记 3:7; 以西结书 27:17; 使徒行传 12:20"> 我的仆人必将这木料从黎巴嫩运到海里，扎成筏子，浮海运到你所指定我的地方，在那里拆开，你就可以收取；你也要成全我的心愿，将食物给我的家。」</span>
<span className="v" id="v10" data-v="10"> 于是希兰照着所罗门所要的，给他香柏木和松木；</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 2:10; 列王纪上 4:22"> 所罗门给希兰麦子二万歌珥，清油二十歌珥，作他家的食物。所罗门每年都是这样给希兰。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 3:12; 阿摩司书 1:9; 雅各书 1:5"> 耶和华照着所应许的赐智慧给所罗门。希兰与所罗门和好，彼此立约。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王纪上 9:15; 列王纪上 4:6"> 所罗门王从以色列人中挑取服苦的人共有三万，</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 4:6–19; 历代志上 27:1–15"> 派他们轮流每月一万人上黎巴嫩去；一个月在黎巴嫩，两个月在家里。亚多尼兰掌管他们。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 9:20–22; 历代志下 2:17–18; 历代志下 8:7–9"> 所罗门用七万扛抬的，八万在山上凿石头的。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 9:23; 历代志下 2:2"> 此外，所罗门用三千三百督工的，监管工人。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 6:7; 历代志上 22:2; 以赛亚书 28:16"> 王下令，人就凿出又大又宝贵的石头来，用以立殿的根基。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 13:5; 以西结书 27:9; 诗篇 83:7"> 所罗门的匠人和希兰的匠人，并迦巴勒人，都将石头凿好，预备木料和石头建殿。</span>
</div>
</div>

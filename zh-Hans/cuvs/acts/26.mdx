## 保罗在亚基帕王面前申辩

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 9:15; 箴言 1:24; 使徒行传 26:2"> 亚基帕对保罗说：「准你为自己辩明。」于是保罗伸手分诉，说：「</span>
<span className="v" id="v2" data-v="2"> 亚基帕王啊，犹太人所告我的一切事，今日得在你面前分诉，实为万幸；</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 6:14; 使徒行传 26:26; 使徒行传 26:7"> 更可幸的，是你熟悉犹太人的规矩和他们的辩论；所以求你耐心听我。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 1:13; 提摩太后书 3:10; 腓立比书 3:5"> 我从起初在本国的民中，并在耶路撒冷，自幼为人如何，犹太人都知道。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 23:6; 使徒行传 22:3; 使徒行传 24:5"> 他们若肯作见证就晓得，我从起初是按着我们教中最严紧的教门作了法利赛人。</span>
<span className="v" id="v6" data-v="6" data-xref="提多书 2:13; 使徒行传 24:15; 使徒行传 28:20"> 现在我站在这里受审，是因为指望 神向我们祖宗所应许的；</span>
<span className="v" id="v7" data-v="7" data-xref="雅各书 1:1; 腓立比书 3:11; 提摩太前书 5:5"> 这应许，我们十二个支派，昼夜切切地事奉 神，都指望得着。王啊，我被犹太人控告，就是因这指望。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 15:12–20; 使徒行传 4:2; 使徒行传 17:31–32"> 神叫死人复活，你们为什么看作不可信的呢？</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前书 1:13; 使徒行传 22:8; 腓立比书 3:6"> 从前我自己以为应当多方攻击拿撒勒人耶稣的名，</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 8:3; 使徒行传 9:13–14; 使徒行传 9:21"> 我在耶路撒冷也曾这样行了。既从祭司长得了权柄，我就把许多圣徒囚在监里。他们被杀，我也出名定案。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 22:19; 马太福音 10:17; 使徒行传 13:45"> 在各会堂，我屡次用刑强逼他们说亵渎的话，又分外恼恨他们，甚至追逼他们，直到外邦的城邑。」</span>
</div>
</div>

## 保罗叙述归主经过

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 26:10; 使徒行传 22:5–11; 使徒行传 9:1–8"> 「那时，我领了祭司长的权柄和命令，往大马士革去。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 17:2; 启示录 21:23; 启示录 1:16"> 王啊，我在路上，晌午的时候，看见从天发光，比日头还亮，四面照着我并与我同行的人。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 21:40; 使徒行传 22:2; 使徒行传 9:7"> 我们都仆倒在地，我就听见有声音用希伯来话向我说：『扫罗！扫罗！为什么逼迫我？你用脚踢刺是难的！』</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 15:20–21; 马太福音 25:45; 出埃及记 16:8"> 我说：『主啊，你是谁？』主说：『我就是你所逼迫的耶稣。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 22:14–15; 以西结书 2:1; 但以理书 10:11"> 你起来站着，我特意向你显现，要派你作执事，作见证，将你所看见的事和我将要指示你的事证明出来。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 9:15; 提摩太前书 2:7; 耶利米书 1:19"> 我也要救你脱离百姓和外邦人的手。</span>
<span className="v" id="v18" data-v="18" data-xref="彼得前书 2:9; 以弗所书 1:18; 以弗所书 5:8"> 我差你到他们那里去，要叫他们的眼睛得开，从黑暗中归向光明，从撒但权下归向 神；又因信我，得蒙赦罪，和一切成圣的人同得基业。』」</span>
</div>
</div>

## 保罗向犹太和外邦人作见证

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 50:5; 加拉太书 1:16; 以西结书 2:7–8"> 「亚基帕王啊，我故此没有违背那从天上来的异象；</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 3:8; 使徒行传 3:19; 使徒行传 2:38"> 先在大马士革，后在耶路撒冷和犹太全地，以及外邦，劝勉他们应当悔改归向 神，行事与悔改的心相称。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 21:30–31; 使徒行传 21:27; 使徒行传 25:3"> 因此，犹太人在殿里拿住我，想要杀我。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 24:14; 约翰福音 5:46; 罗马书 3:21"> 然而我蒙 神的帮助，直到今日还站得住，对着尊贵、卑贱、老幼作见证；所讲的并不外乎众先知和摩西所说将来必成的事，</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 53:1–12; 路加福音 24:26; 歌罗西书 1:18"> 就是基督必须受害，并且因从死里复活，要首先把光明的道传给百姓和外邦人。」</span>
</div>
</div>

## 保罗恳请亚基帕信主

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 2:13–14; 哥林多前书 1:23; 哥林多前书 4:10"> 保罗这样分诉，非斯都大声说：「保罗，你癫狂了吧。你的学问太大，反叫你癫狂了！」</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 23:26; 提多书 1:9; 提多书 2:7–8"> 保罗说：「非斯都大人，我不是癫狂，我说的乃是真实明白话。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 26:2–3; 使徒行传 2:1–12; 以赛亚书 30:20"> 王也晓得这些事，所以我向王放胆直言，我深信这些事没有一件向王隐藏的，因都不是在背地里做的。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 26:22–23"> 亚基帕王啊，你信先知吗？我知道你是信的。」</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 11:26; 马太福音 10:18; 使徒行传 26:29"> 亚基帕对保罗说：「你想少微一劝，便叫我作基督徒啊<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：你这样劝我，几乎叫我作基督徒了">a</a></sup>！」</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所书 6:20; 歌罗西书 1:28; 罗马书 10:1"> 保罗说：「无论是少劝是多劝，我向 神所求的，不但你一个人，就是今天一切听我的，都要像我一样，只是不要像我有这些锁链。」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行传 18:15; 使徒行传 28:22; 使徒行传 25:23"> 于是，王和巡抚并百妮基与同坐的人都起来，</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 23:29; 使徒行传 23:9; 使徒行传 28:18"> 退到里面，彼此谈论说：「这人并没有犯什么该死该绑的罪。」</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 28:18; 使徒行传 25:11–12; 使徒行传 25:25"> 亚基帕又对非斯都说：「这人若没有上告于凯撒，就可以释放了。」</span>
</div>
</div>

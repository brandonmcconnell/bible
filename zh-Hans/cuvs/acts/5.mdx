## 亚拿尼亚和撒非喇

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 10:1–3; 提摩太后书 2:20; 马太福音 13:47–48"> 有一个人，名叫亚拿尼亚，同他的妻子撒非喇卖了田产，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 4:37; 彼得后书 2:14–15; 马太福音 23:5"> 把价银私自留下几分，他的妻子也知道，其余的几分拿来放在使徒脚前。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 23:24; 以赛亚书 29:15; 约翰福音 13:2"> 彼得说：「亚拿尼亚！为什么撒但充满了你的心，叫你欺哄圣灵，把田地的价银私自留下几分呢？</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 5:3; 约书亚记 7:25–26; 列王纪下 5:25–27"> 田地还没有卖，不是你自己的吗？既卖了，价银不是你作主吗？你怎么心里起这意念呢？你不是欺哄人，是欺哄 神了。」</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 5:10–11; 使徒行传 2:43; 使徒行传 5:13"> 亚拿尼亚听见这话，就仆倒，断了气；听见的人都甚惧怕。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 19:40; 撒母耳记下 18:17; 申命记 21:23"> 有些少年人起来，把他包裹，抬出去埋葬了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 约过了三小时，他的妻子进来，还不知道这事。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 5:2"> 彼得对她说：「你告诉我，你们卖田地的价银就是这些吗？」她说：「就是这些。」</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 10:9; 使徒行传 5:3–4; 诗篇 95:8–11"> 彼得说：「你们为什么同心试探主的灵呢？埋葬你丈夫之人的脚已到门口，他们也要把你抬出去。」</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 5:5"> 妇人立刻仆倒在彼得脚前，断了气。那些少年人进来，见她已经死了，就抬出去，埋在她丈夫旁边。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 5:5; 哥林多前书 10:11–12; 使徒行传 19:17"> 全教会和听见这事的人都甚惧怕。</span>
</div>
</div>

## 主借使徒行了许多神迹奇事

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 19:11; 哥林多后书 12:12; 希伯来书 2:4"> 主借使徒的手在民间行了许多神迹奇事；他们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：信的人">a</a></sup>都同心合意地在所罗门的廊下。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 2:47; 使徒行传 4:21; 约翰福音 12:42"> 其余的人没有一个敢贴近他们，百姓却尊重他们。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 2:47; 使徒行传 4:4; 以赛亚书 55:11–13"> 信而归主的人越发增添，连男带女很多。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 14:36; 使徒行传 19:11–12; 约翰福音 14:12"> 甚至有人将病人抬到街上，放在床上或褥子上，指望彼得过来的时候，或者得他的影儿照在什么人身上。</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 16:17–18; 马可福音 2:3–4; 马太福音 15:30–31"> 还有许多人带着病人和被污鬼缠磨的，从耶路撒冷四围的城邑来，全都得了医治。</span>
</div>
</div>

## 使徒受迫害

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行传 13:45; 使徒行传 7:9; 使徒行传 17:5"> 大祭司和他的一切同人，就是撒都该教门的人，都起来，满心忌恨，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 4:3; 路加福音 21:12; 哥林多后书 11:23"> 就下手拿住使徒，收在外监。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 16:26; 诗篇 34:7; 使徒行传 12:7–11"> 但主的使者夜间开了监门，领他们出来，</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 6:63; 约翰福音 6:68; 约翰一书 5:11–12"> 说：「你们去站在殿里，把这生命的道都讲给百姓听。」</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 8:2; 使徒行传 22:15; 使徒行传 12:18–19"> 使徒听了这话，天将亮的时候就进殿里去教训人。大祭司和他的同人来了，叫齐公会的人和以色列族的众长老，就差人到监里去，要把使徒提出来。</span>
<span className="v" id="v22" data-v="22"> 但差役到了，不见他们在监里，就回来禀报说：</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 2:4; 诗篇 33:10; 但以理书 6:22–24"> 「我们看见监牢关得极妥当，看守的人也站在门外；及至开了门，里面一个人都不见。」</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 4:1; 使徒行传 5:26; 约翰福音 12:19"> 守殿官和祭司长听见这话，心里犯难，不知这事将来如何。</span>
<span className="v" id="v25" data-v="25"> 有一个人来禀报说：「你们收在监里的人，现在站在殿里教训百姓。」</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 5:13; 使徒行传 4:21; 马太福音 26:5"> 于是守殿官和差役去带使徒来，并没有用强暴，因为怕百姓用石头打他们。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马太福音 5:22; 使徒行传 4:7; 路加福音 22:66"> 带到了，便叫使徒站在公会前；大祭司问他们说：</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 27:25; 使徒行传 7:52; 使徒行传 4:10–11"> 「我们不是严严地禁止你们，不可奉这名教训人吗？你们倒把你们的道理充满了耶路撒冷，想要叫这人的血归到我们身上！」</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 4:19; 撒母耳记上 15:24; 马可福音 7:7–9"> 彼得和众使徒回答说：「顺从 神，不顺从人，是应当的。</span>
<span className="v" id="v30" data-v="30" data-xref="加拉太书 3:13; 彼得前书 2:24; 使徒行传 10:39"> 你们挂在木头上杀害的耶稣，我们祖宗的 神已经叫他复活。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 24:47; 使徒行传 2:33; 希伯来书 2:10"> 神且用右手将他高举<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：他就是 神高举在自己的右边">b</a></sup>，叫他作君王，作救主，将悔改的心和赦罪的恩赐给以色列人。</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 15:26–27; 希伯来书 2:3–4; 使徒行传 1:8"> 我们为这事作见证； 神赐给顺从之人的圣灵也为这事作见证。」</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="使徒行传 7:54; 使徒行传 2:37; 路加福音 4:28–29"> 公会的人听见就极其恼怒，想要杀他们。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 22:3; 路加福音 2:46; 路加福音 5:17"> 但有一个法利赛人，名叫迦玛列，是众百姓所敬重的教法师，在公会中站起来，吩咐人把使徒暂且带到外面去，</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 22:26; 耶利米书 26:19; 马太福音 27:19"> 就对众人说：「以色列人哪，论到这些人，你们应当小心怎样办理。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 8:9; 彼得后书 2:2; 加拉太书 6:3"> 从前杜达起来，自夸为大，附从他的人约有四百，他被杀后，附从他的全都散了，归于无有。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 2:1–2; 诗篇 7:14–15; 马太福音 26:52"> 此后，报名上册的时候，又有加利利的犹大起来，引诱些百姓跟从他；他也灭亡，附从他的人也都四散了。</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 15:13; 耶利米哀歌 3:37; 以赛亚书 8:9–10"> 现在，我劝你们不要管这些人，任凭他们吧！他们所谋的、所行的，若是出于人，必要败坏；</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 21:30; 以赛亚书 46:10; 马太福音 16:18"> 若是出于 神，你们就不能败坏他们，恐怕你们倒是攻击 神了。」</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 10:17; 使徒行传 5:28; 使徒行传 4:17–21"> 公会的人听从了他，便叫使徒来，把他们打了，又吩咐他们不可奉耶稣的名讲道，就把他们释放了。</span>
<span className="v" id="v41" data-v="41" data-xref="雅各书 1:2; 彼得前书 4:13–16; 路加福音 6:22"> 他们离开公会，心里欢喜，因被算是配为这名受辱。</span>
<span className="v" id="v42" data-v="42" data-xref="使徒行传 2:46; 使徒行传 20:20; 路加福音 21:37"> 他们就每日在殿里、在家里不住地教训人，传耶稣是基督。</span>
</div>
</div>

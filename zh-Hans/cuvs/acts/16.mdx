## 提摩太跟保罗、西拉同工

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太后书 1:5; 提摩太后书 1:2; 哥林多前书 4:17"> 保罗来到特庇，又到路司得。在那里有一个门徒，名叫提摩太，是信主之犹太妇人的儿子，他父亲却是希腊人。</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前书 5:10; 提摩太后书 3:15; 使徒行传 14:21"> 路司得和以哥念的弟兄都称赞他。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 2:3; 哥林多前书 9:20; 加拉太书 5:6"> 保罗要带他同去，只因那些地方的犹太人都知道他父亲是希腊人，就给他行了割礼。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 15:28–29; 使徒行传 15:2; 使徒行传 11:30"> 他们经过各城，把耶路撒冷使徒和长老所定的条规交给门徒遵守。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 9:31; 使徒行传 2:47; 使徒行传 6:7"> 于是众教会信心越发坚固，人数天天加增。</span>
</div>
</div>

## 保罗看见马其顿人的异象

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 18:23; 使徒行传 16:7; 使徒行传 13:2–4"> 圣灵既然禁止他们在亚细亚讲道，他们就经过弗吕家、加拉太一带地方。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:9; 腓立比书 1:19; 加拉太书 4:6"> 到了每西亚的边界，他们想要往庇推尼去，耶稣的灵却不许。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 2:12; 提摩太后书 4:13; 使徒行传 16:11"> 他们就越过每西亚，下到特罗亚去。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 9:10–12; 使徒行传 19:21; 使徒行传 18:5"> 在夜间有异象现与保罗。有一个马其顿人站着求他说：「请你过到马其顿来帮助我们。」</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 2:12–13; 使徒行传 14:7; 使徒行传 16:10–17"> 保罗既看见这异象，我们随即想要往马其顿去，以为 神召我们传福音给那里的人听。</span>
</div>
</div>

## 吕底亚归主

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 21:1; 使徒行传 16:8"> 于是从特罗亚开船，一直行到撒摩特喇，第二天到了尼亚坡里。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦前书 2:2; 腓立比书 1:1; 使徒行传 20:6"> 从那里来到腓立比，就是马其顿这一方的头一个城，也是罗马的驻防城。我们在这城里住了几天。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 13:14; 歌罗西书 1:23; 使徒行传 17:2"> 当安息日，我们出城门，到了河边，知道那里有一个祷告的地方，我们就坐下对那聚会的妇女讲道。</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所书 1:17–18; 路加福音 24:45; 以赛亚书 50:5"> 有一个卖紫色布疋的妇人，名叫吕底亚，是推雅推喇城的人，素来敬拜 神。她听见了，主就开导她的心，叫她留心听保罗所讲的话。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 11:14; 希伯来书 13:2; 使徒行传 16:33"> 她和她一家既领了洗，便求我们说：「你们若以为我是真信主的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：你们若以为我是忠心事主的">a</a></sup>，请到我家里来住」；于是强留我们。</span>
</div>
</div>

## 在腓立比被囚

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="利未记 19:31; 申命记 18:9–11; 以赛亚书 8:19"> 后来，我们往那祷告的地方去。有一个使女迎着面来，她被巫鬼所附，用法术，叫她主人们大得财利。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 14:6; 彼得前书 2:16; 马可福音 5:7"> 她跟随保罗和我们，喊着说：「这些人是至高 神的仆人，对你们传说救人的道。」</span>
<span className="v" id="v18" data-v="18" data-xref="马可福音 16:17; 路加福音 10:17–19; 使徒行传 3:6"> 她一连多日这样喊叫，保罗就心中厌烦，转身对那鬼说：「我奉耶稣基督的名，吩咐你从她身上出来！」那鬼当时就出来了。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 17:6; 使徒行传 21:30; 使徒行传 8:3"> 使女的主人们见得利的指望没有了，便揪住保罗和西拉，拉他们到市上去见首领；</span>
<span className="v" id="v20" data-v="20" data-xref="雅各书 4:4; 约翰福音 15:18–20; 使徒行传 28:22"> 又带到官长面前说：「这些人原是犹太人，竟骚扰我们的城，</span>
<span className="v" id="v21" data-v="21" data-xref="以斯帖记 3:8; 使徒行传 26:3; 耶利米书 10:3"> 传我们罗马人所不可受不可行的规矩。」</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒罗尼迦前书 2:2; 哥林多后书 6:5; 哥林多后书 11:23–25"> 众人就一同起来攻击他们。官长吩咐剥了他们的衣裳，用棍打；</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 2:10; 提摩太后书 2:9; 撒母耳记上 23:22–23"> 打了许多棍，便将他们下在监里，嘱咐禁卒严紧看守。</span>
<span className="v" id="v24" data-v="24" data-xref="约伯记 13:27; 约伯记 33:11; 耶利米书 29:26"> 禁卒领了这样的命，就把他们下在内监里，两脚上了木狗。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="帖撒罗尼迦前书 5:16–18; 诗篇 119:62; 雅各书 1:2"> 约在半夜，保罗和西拉祷告，唱诗赞美 神，众囚犯也侧耳而听。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 4:31; 使徒行传 5:19; 使徒行传 12:10"> 忽然，地大震动，甚至监牢的地基都摇动了，监门立刻全开，众囚犯的锁链也都松开了。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 12:19; 马太福音 27:5; 士师记 9:54"> 禁卒一醒，看见监门全开，以为囚犯已经逃走，就拔刀要自杀。</span>
<span className="v" id="v28" data-v="28" data-xref="帖撒罗尼迦前书 5:15; 路加福音 23:34; 路加福音 6:27–28"> 保罗大声呼叫说：「不要伤害自己！我们都在这里。」</span>
<span className="v" id="v29" data-v="29" data-xref="启示录 3:9; 使徒行传 24:25; 以赛亚书 60:14"> 禁卒叫人拿灯来，就跳进去，战战兢兢地俯伏在保罗、西拉面前；</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 2:37; 约翰福音 6:27–29; 以赛亚书 58:9"> 又领他们出来，说：「二位先生，我当怎样行才可以得救？」</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 1:12; 使徒行传 2:38–39; 约翰福音 3:36"> 他们说：「当信主耶稣，你和你一家都必得救。」</span>
<span className="v" id="v32" data-v="32" data-xref="罗马书 1:16; 歌罗西书 1:27–28; 提摩太前书 1:13–16"> 他们就把主的道讲给他和他全家的人听。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 1:16; 使徒行传 16:15; 使徒行传 16:25"> 当夜，就在那时候，禁卒把他们带去，洗他们的伤；他和属乎他的人立时都受了洗。</span>
<span className="v" id="v34" data-v="34" data-xref="罗马书 15:13; 使徒行传 2:46; 罗马书 5:11"> 于是禁卒领他们上自己家里去，给他们摆上饭。他和全家，因为信了 神，都很喜乐。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="耶利米书 5:22; 诗篇 76:10; 使徒行传 5:40"> 到了天亮，官长打发差役来，说：「释放那两个人吧。」</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 15:33; 约翰福音 14:27; 撒母耳记上 1:17"> 禁卒就把这话告诉保罗说：「官长打发人来叫释放你们，如今可以出监，平平安安地去吧。」</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 22:25–29; 诗篇 58:1–2; 马太福音 10:16"> 保罗却说：「我们是罗马人，并没有定罪，他们就在众人面前打了我们，又把我们下在监里，现在要私下撵我们出去吗？这是不行的。叫他们自己来领我们出去吧！」</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 22:29; 马太福音 21:46; 马太福音 14:5"> 差役把这话回禀官长。官长听见他们是罗马人，就害怕了，</span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 8:34; 马可福音 5:17; 但以理书 6:23"> 于是来劝他们，领他们出来，请他们离开那城。</span>
<span className="v" id="v40" data-v="40" data-xref="帖撒罗尼迦前书 3:2–3; 使徒行传 16:14; 使徒行传 14:22"> 二人出了监，往吕底亚家里去，见了弟兄们，劝慰他们一番，就走了。</span>
</div>
</div>

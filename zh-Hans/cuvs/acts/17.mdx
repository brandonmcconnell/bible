## 帖撒罗尼迦的骚动

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 1:1; 腓立比书 4:16; 使徒行传 20:4"> 保罗和西拉经过暗妃坡里、亚波罗尼亚，来到帖撒罗尼迦，在那里有犹太人的会堂。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 9:20; 使徒行传 17:17; 使徒行传 18:4"> 保罗照他素常的规矩进去，一连三个安息日，本着圣经与他们辩论，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 18:28; 使徒行传 9:22; 路加福音 24:32"> 讲解陈明基督必须受害，从死里复活；又说：「我所传与你们的这位耶稣就是基督。」</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 17:12; 使徒行传 13:43; 使徒行传 14:4"> 他们中间有些人听了劝，就附从保罗和西拉，并有许多虔敬的希腊人，尊贵的妇女也不少。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 5:26; 使徒行传 17:13; 罗马书 16:21"> 但那不信的犹太人心里嫉妒，招聚了些市井匪类，搭伙成群，耸动合城的人闯进耶孙的家，要将保罗、西拉带到百姓那里。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 24:5; 使徒行传 16:19–21; 使徒行传 28:22"> 找不着他们，就把耶孙和几个弟兄拉到地方官那里，喊叫说：「那搅乱天下的也到这里来了，</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 23:2; 使徒行传 16:21; 约翰福音 19:12"> 耶孙收留他们。这些人都违背凯撒的命令，说另有一个王耶稣。」</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 2:3; 约翰福音 11:48"> 众人和地方官听见这话，就惊慌了；</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 17:5"> 于是取了耶孙和其余之人的保状，就释放了他们。</span>
</div>
</div>

## 使徒们在庇哩亚传道

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 17:2; 帖撒罗尼迦前书 2:2; 使徒行传 17:13–14"> 弟兄们随即在夜间打发保罗和西拉往庇哩亚去。二人到了，就进入犹太人的会堂。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 34:16; 箴言 2:1–5; 约翰福音 5:39"> 这地方的人贤于帖撒罗尼迦的人，甘心领受这道，天天考查圣经，要晓得这道是与不是。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 5:14; 使徒行传 14:1; 使徒行传 13:50"> 所以他们中间多有相信的，又有希腊尊贵的妇女，男子也不少。</span>
<span className="v" id="v13" data-v="13" data-xref="帖撒罗尼迦前书 2:14–16; 箴言 28:25; 使徒行传 6:12"> 但帖撒罗尼迦的犹太人知道保罗又在庇哩亚传 神的道，也就往那里去，耸动搅扰众人。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 17:10; 马太福音 10:23; 使徒行传 9:25"> 当时弟兄们便打发保罗往海边去，西拉和提摩太仍住在庇哩亚。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 18:5; 帖撒罗尼迦前书 3:1; 使徒行传 18:1"> 送保罗的人带他到了雅典，既领了保罗的命，叫西拉和提摩太速速到他这里来，就回去了。</span>
</div>
</div>

## 保罗在雅典

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="诗篇 119:158; 彼得后书 2:7; 诗篇 119:136"> 保罗在雅典等候他们的时候，看见满城都是偶像，就心里着急；</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 13:16; 使徒行传 14:1–4; 使徒行传 17:2–4"> 于是在会堂里与犹太人和虔敬的人，并每日在市上所遇见的人，辩论。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 1:20–21; 歌罗西书 2:8; 路加福音 11:53"> 还有伊壁鸠鲁和斯多亚两门的学士，与他争论。有的说：「这胡言乱语的要说什么？」有的说：「他似乎是传说外邦鬼神的。」这话是因保罗传讲耶稣与复活的道。</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 1:27; 使徒行传 17:22; 使徒行传 24:24"> 他们就把他带到亚略·巴古，说：「你所讲的这新道，我们也可以知道吗？</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 1:23; 何西阿书 8:12; 哥林多前书 2:14"> 因为你有些奇怪的事传到我们耳中，我们愿意知道这些事是什么意思。」（</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 2:16–17; 歌罗西书 4:5; 以弗所书 5:16"> 雅典人和住在那里的客人都不顾别的事，只将新闻说说听听。）</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 25:19; 使徒行传 19:35; 使徒行传 17:16"> 保罗站在亚略·巴古当中，说：「众位雅典人哪，我看你们凡事很敬畏鬼神。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 4:22; 加拉太书 4:8–9; 约翰福音 17:3"> 我游行的时候，观看你们所敬拜的，遇见一座坛，上面写着『未识之神』。你们所不认识而敬拜的，我现在告诉你们。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 8:27; 申命记 10:14; 使徒行传 7:48"> 创造宇宙和其中万物的 神，既是天地的主，就不住人手所造的殿，</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 50:8–13; 创世记 2:7; 以赛亚书 42:5"> 也不用人手服事，好像缺少什么；自己倒将生命、气息、万物，赐给万人。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 32:7–8; 创世记 3:20; 罗马书 5:12–19"> 他从一本<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="本：有古卷是血脉">a</a></sup>造出万族的人，住在全地上，并且预先定准他们的年限和所住的疆界，</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 23:23–24; 申命记 4:7; 使徒行传 14:17"> 要叫他们寻求 神，或者可以揣摩而得，其实他离我们各人不远；</span>
<span className="v" id="v28" data-v="28" data-xref="约伯记 12:10; 歌罗西书 1:17; 希伯来书 1:3"> 我们生活、动作、存留，都在乎他。就如你们作诗的，有人说：『我们也是他所生的。』</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 40:25; 出埃及记 20:4; 诗篇 115:4–8"> 我们既是 神所生的，就不当以为 神的神性像人用手艺、心思所雕刻的金、银、石。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 14:16; 提多书 2:11–12; 路加福音 24:47"> 世人蒙昧无知的时候， 神并不监察，如今却吩咐各处的人都要悔改。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 25:31–46; 彼得后书 3:7; 罗马书 2:16"> 因为他已经定了日子，要借着他所设立的人按公义审判天下，并且叫他从死里复活，给万人作可信的凭据。」</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 17:18; 使徒行传 26:8; 使徒行传 25:19"> 众人听见从死里复活的话，就有讥诮他的；又有人说：「我们再听你讲这个吧！」</span>
<span className="v" id="v33" data-v="33"> 于是保罗从他们当中出去了。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 17:19; 罗马书 11:5–6; 使徒行传 13:48"> 但有几个人贴近他，信了主，其中有亚略·巴古的官丢尼修，并一个妇人，名叫大马哩，还有别人一同信从。</span>
</div>
</div>

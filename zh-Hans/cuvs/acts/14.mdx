## 在以哥念传道

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 18:4; 使徒行传 13:51; 使徒行传 13:46"> 二人在以哥念同进犹太人的会堂，在那里讲的，叫犹太人和希腊人信的很多。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 13:50; 使徒行传 21:27–30; 使徒行传 14:19"> 但那不顺从的犹太人耸动外邦人，叫他们心里恼恨弟兄。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 2:4; 以弗所书 6:18–20; 使徒行传 20:32"> 二人在那里住了多日，倚靠主放胆讲道，主借他们的手施行神迹奇事，证明他的恩道。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 28:24; 使徒行传 14:14; 路加福音 11:21–23"> 城里的众人就分了党，有附从犹太人的，有附从使徒的。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 14:19; 提摩太后书 3:11; 使徒行传 17:5"> 那时，外邦人和犹太人，并他们的官长，一齐拥上来，要凌辱使徒，用石头打他们。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 14:20–21; 马太福音 10:23; 提摩太后书 3:11"> 使徒知道了，就逃往吕高尼的路司得、特庇两个城和周围地方去，</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 14:21; 使徒行传 16:10; 帖撒罗尼迦前书 2:2"> 在那里传福音。</span>
</div>
</div>

## 在路司得传道

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 3:2; 约翰福音 9:1–2; 约翰福音 5:3–5"> 路司得城里坐着一个两脚无力的人，生来是瘸腿的，从来没有走过。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 3:4; 马太福音 15:28; 马太福音 9:28–29"> 他听保罗讲道，保罗定睛看他，见他有信心，可得痊愈，</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 35:6; 约翰福音 5:8–9; 约翰福音 14:12"> 就大声说：「你起来，两脚站直！」那人就跳起来，而且行走。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 28:6; 使徒行传 8:10; 使徒行传 12:22"> 众人看见保罗所做的事，就用吕高尼的话大声说：「有神借着人形降临在我们中间了。」</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 19:35"> 于是称巴拿巴为宙斯，称保罗为希耳米，因为他说话领首。</span>
<span className="v" id="v13" data-v="13" data-xref="但以理书 2:46; 使徒行传 10:25"> 有城外宙斯庙的祭司牵着牛，拿着花圈，来到门前，要同众人向使徒献祭。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 26:65; 哥林多前书 9:5–6; 列王纪下 5:7"> 巴拿巴、保罗二使徒听见，就撕开衣裳，跳进众人中间，喊着说：</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 10:26; 哥林多前书 8:4; 雅各书 5:17"> 「诸君，为什么做这事呢？我们也是人，性情和你们一样。我们传福音给你们，是叫你们离弃这些虚妄，归向那创造天、地、海，和其中万物的永生 神。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 17:30; 诗篇 81:12; 罗马书 1:28"> 他在从前的世代，任凭万国各行其道；</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 1:19–20; 约珥书 2:23; 约伯记 5:10"> 然而为自己未尝不显出证据来，就如常施恩惠，从天降雨，赏赐丰年，叫你们饮食饱足，满心喜乐。」</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 44:16–17; 创世记 19:9; 创世记 11:6"> 二人说了这些话，仅仅地拦住众人不献祭与他们。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多后书 11:25; 提摩太后书 3:11; 使徒行传 13:50–51"> 但有些犹太人从安提阿和以哥念来，挑唆众人，就用石头打保罗，以为他是死了，便拖到城外。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 1:9–10; 哥林多后书 6:9; 使徒行传 14:6"> 门徒正围着他，他就起来，走进城去。 回到叙利亚的安提阿<br />第二天，同巴拿巴往特庇去，</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 14:19; 使徒行传 14:1; 使徒行传 13:51"> 对那城里的人传了福音，使好些人作门徒，就回路司得、以哥念、安提阿去，</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 5:10; 提摩太后书 3:12; 约翰福音 16:33"> 坚固门徒的心，劝他们恒守所信的道；又说：「我们进入 神的国，必须经历许多艰难。」</span>
<span className="v" id="v23" data-v="23" data-xref="提多书 1:5; 使徒行传 11:30; 雅各书 5:14"> 二人在各教会中选立了长老，又禁食祷告，就把他们交托所信的主。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 13:13–14; 使徒行传 15:38"> 二人经过彼西底，来到旁非利亚。</span>
<span className="v" id="v25" data-v="25"> 在别加讲了道，就下亚大利去，</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 15:40; 使徒行传 11:19; 哥林多后书 1:12"> 从那里坐船，往安提阿去。当初，他们被众人所托、蒙 神之恩、要办现在所做之工，就是在这地方。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 16:9; 使徒行传 15:12; 歌罗西书 4:3"> 到了那里，聚集了会众，就述说 神借他们所行的一切事，并 神怎样为外邦人开了信道的门。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 11:26; 使徒行传 15:35"> 二人就在那里同门徒住了多日。</span>

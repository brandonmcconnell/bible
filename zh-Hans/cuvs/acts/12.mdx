## 雅各被杀，彼得被囚

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 24:9; 约翰福音 15:20; 马太福音 10:17–18"> 那时，希律王下手苦害教会中几个人，</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:37; 马太福音 20:23; 马太福音 4:21–22"> 用刀杀了约翰的哥哥雅各。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 23:15; 约翰福音 12:43; 使徒行传 24:27"> 他见犹太人喜欢这事，又去捉拿彼得。那时正是除酵的日子。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 19:21; 路加福音 22:33; 路加福音 21:12"> 希律拿了彼得，收在监里，交付四班兵丁看守，每班四个人，意思要在逾越节后把他提出来，当着百姓办他。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 12:26; 帖撒罗尼迦前书 5:17; 雅各书 5:16"> 于是彼得被囚在监里；教会却为他切切地祷告 神。</span>
</div>
</div>

## 彼得获救出狱

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 21:33; 希伯来书 13:6; 腓立比书 4:6–7"> 希律将要提他出来的前一夜，彼得被两条铁链锁着，睡在两个兵丁当中；看守的人也在门外看守。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 5:19; 使徒行传 16:26; 诗篇 146:7"> 忽然，有主的一个使者站在旁边，屋里有光照耀，天使拍彼得的肋旁，拍醒了他，说：「快快起来！」那铁链就从他手上脱落下来。</span>
<span className="v" id="v8" data-v="8"> 天使对他说：「束上带子，穿上鞋。」他就那样做。天使又说：「披上外衣，跟着我来。」</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 126:1; 希伯来书 11:8; 创世记 45:26"> 彼得就出来跟着他，不知道天使所做是真的，只当见了异象。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 5:19; 使徒行传 16:26; 以赛亚书 45:1–2"> 过了第一层第二层监牢，就来到临街的铁门，那门自己开了。他们出来，走过一条街，天使便离开他去了。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 6:22; 但以理书 3:28; 彼得后书 2:9"> 彼得醒悟过来，说：「我现在真知道主差遣他的使者，救我脱离希律的手和犹太百姓一切所盼望的。」</span>
<span className="v" id="v12" data-v="12" data-xref="约翰一书 5:14–15; 使徒行传 12:5; 马太福音 18:19–20"> 想了一想，就往那称呼马可的约翰、他母亲马利亚家去，在那里有好些人聚集祷告。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 12:16; 路加福音 13:25; 约翰福音 18:16–17"> 彼得敲外门，有一个使女，名叫罗大，出来探听，</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 24:41; 马太福音 28:8"> 听得是彼得的声音，就欢喜的顾不得开门，跑进去告诉众人说：「彼得站在门外。」</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 18:10; 路加福音 24:11; 马可福音 16:14"> 他们说：「你是疯了！」使女极力地说：「真是他！」他们说：「必是他的天使！」</span>
<span className="v" id="v16" data-v="16"> 彼得不住地敲门。他们开了门，看见他，就甚惊奇。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 21:40; 使徒行传 13:16; 使徒行传 19:33"> 彼得摆手，不要他们作声，就告诉他们主怎样领他出监；又说：「你们把这事告诉雅各和众弟兄。」于是出去，往别处去了。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 5:22–25; 使徒行传 16:27; 使徒行传 19:23"> 到了天亮，兵丁扰乱得很，不知道彼得往哪里去了。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 16:27; 诗篇 37:32–33; 约翰福音 12:10–11"> 希律找他，找不着，就审问看守的人，吩咐把他们拉去杀了。后来希律离开犹太，下凯撒利亚去，住在那里。</span>
</div>
</div>

## 希律的死

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以斯拉记 3:7; 马太福音 11:21–22; 以西结书 27:17"> 希律恼怒泰尔、西顿的人。他们那一带地方是从王的地土得粮，因此就托了王的内侍臣伯拉斯都的情，一心来求和。</span>
<span className="v" id="v21" data-v="21"> 希律在所定的日子，穿上朝服，坐在位上，对他们讲论一番。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 14:10–13; 启示录 13:4; 犹大书 1:16"> 百姓喊着说：「这是神的声音，不是人的声音。」</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 115:1; 使徒行传 10:25–26; 帖撒罗尼迦后书 2:4"> 希律不归荣耀给 神，所以主的使者立刻罚他，他被虫所咬，气就绝了。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行传 6:7; 使徒行传 19:20; 帖撒罗尼迦后书 3:1"> 神的道日见兴旺，越发广传。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 12:12; 彼得前书 5:13; 使徒行传 15:37"> 巴拿巴和扫罗办完了他们供给的事，就从耶路撒冷回来，带着称呼马可的约翰同去。</span>
</div>
</div>

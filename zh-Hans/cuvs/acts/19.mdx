## 保罗在以弗所

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 18:23–28; 哥林多前书 16:12; 哥林多前书 1:12"> 亚波罗在哥林多的时候，保罗经过了上边一带地方，就来到以弗所；在那里遇见几个门徒，</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 7:39; 使徒行传 11:15–17; 加拉太书 3:5"> 问他们说：「你们信的时候受了圣灵没有？」他们回答说：「没有，也未曾听见有圣灵赐下来。」</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 18:25; 哥林多前书 12:13; 使徒行传 8:16"> 保罗说：「这样，你们受的是什么洗呢？」他们说：「是约翰的洗。」</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 1:29–34; 使徒行传 11:16; 使徒行传 1:5"> 保罗说：「约翰所行的是悔改的洗，告诉百姓当信那在他以后要来的，就是耶稣。」</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 8:12; 使徒行传 8:16; 罗马书 6:3–4"> 他们听见这话，就奉主耶稣的名受洗。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 6:6; 使徒行传 2:4; 马可福音 16:17"> 保罗按手在他们头上，圣灵便降在他们身上，他们就说方言，又说预言<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：又讲道">a</a></sup>。</span>
<span className="v" id="v7" data-v="7"> 一共约有十二个人。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 28:23; 使徒行传 1:3; 使徒行传 9:20–22"> 保罗进会堂，放胆讲道，一连三个月，辩论 神国的事，劝化众人。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 19:23; 使徒行传 9:2; 使徒行传 18:6–8"> 后来，有些人心里刚硬不信，在众人面前毁谤这道，保罗就离开他们，也叫门徒与他们分离，便在推喇奴的学房天天辩论。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 20:31; 提摩太后书 1:15; 使徒行传 16:6"> 这样有两年之久，叫一切住在亚细亚的，无论是犹太人，是希腊人，都听见主的道。</span>
</div>
</div>

## 士基瓦的儿子们

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马可福音 16:17–20; 使徒行传 5:12; 罗马书 15:18–19"> 神借保罗的手行了些非常的奇事；</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 5:15; 列王纪下 13:20–21; 马可福音 16:17"> 甚至有人从保罗身上拿手巾或围裙放在病人身上，病就退了，恶鬼也出去了。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 12:27; 马可福音 9:38; 路加福音 11:19"> 那时，有几个游行各处、念咒赶鬼的犹太人，向那被恶鬼附的人擅自称主耶稣的名，说：「我奉保罗所传的耶稣敕令你们出来！」</span>
<span className="v" id="v14" data-v="14"> 做这事的，有犹太祭司长士基瓦的七个儿子。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 16:17–18; 路加福音 4:33–35; 马可福音 1:34"> 恶鬼回答他们说：「耶稣我认识，保罗我也知道。你们却是谁呢？」</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 8:29; 马可福音 5:3–4; 马可福音 5:15"> 恶鬼所附的人就跳在他们身上，胜了其中二人，制伏他们，叫他们赤着身子受了伤，从那房子里逃出去了。</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦后书 1:12; 使徒行传 5:5; 腓立比书 2:9–11"> 凡住在以弗所的，无论是犹太人，是希腊人，都知道这事，也都惧怕；主耶稣的名从此就尊大了。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 10:10; 诗篇 32:5; 马太福音 3:6"> 那已经信的，多有人来承认诉说自己所行的事。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 13:8; 出埃及记 32:20; 创世记 35:4"> 平素行邪术的，也有许多人把书拿来，堆积在众人面前焚烧。他们算计书价，便知道共合五万块钱。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 12:24; 使徒行传 6:7; 以赛亚书 55:11"> 主的道大大兴旺，而且得胜，就是这样。</span>
</div>
</div>

## 以弗所的暴动

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 20:22; 使徒行传 20:16; 使徒行传 23:11"> 这些事完了，保罗心里定意经过了马其顿、亚该亚，就往耶路撒冷去；又说：「我到了那里以后，也必须往罗马去看看。」</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 16:23; 提摩太后书 4:20; 使徒行传 16:3"> 于是从帮助他的人中打发提摩太、以拉都二人往马其顿去，自己暂时等在亚细亚。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 19:9; 使徒行传 24:22; 哥林多后书 1:8–10"> 那时，因为这道起的扰乱不小。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太前书 6:9–10; 使徒行传 16:16; 使徒行传 16:19"> 有一个银匠，名叫底米丢，是制造亚底米神银龛的，他使这样手艺人生意发达。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 16:19; 何西阿书 12:7–8; 启示录 18:11–19"> 他聚集他们和同行的工人，说：「众位，你们知道我们是倚靠这生意发财。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 17:29; 哥林多前书 8:4; 以赛亚书 44:10–20"> 这保罗不但在以弗所，也几乎在亚细亚全地，引诱迷惑许多人，说：『人手所做的，不是神。』这是你们所看见所听见的。</span>
<span className="v" id="v27" data-v="27" data-xref="西番雅书 2:11; 提摩太前书 6:5; 马太福音 23:13"> 这样，不独我们这事业被人藐视，就是大女神亚底米的庙也要被人轻忽，连亚细亚全地和普天下所敬拜的大女神之威荣也要消灭了。」</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 13:4; 启示录 17:13; 使徒行传 16:19–24"> 众人听见，就怒气填胸，喊着说：「大哉，以弗所人的亚底米啊！」</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 20:4; 歌罗西书 4:10; 使徒行传 27:2"> 满城都轰动起来。众人拿住与保罗同行的马其顿人该犹和亚里达古，齐心拥进戏园里去。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 21:39; 撒母耳记下 18:2–3; 使徒行传 17:22–31"> 保罗想要进去，到百姓那里，门徒却不许他去。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 19:10; 使徒行传 21:12; 使徒行传 16:6"> 还有亚细亚几位首领，是保罗的朋友，打发人来劝他，不要冒险到戏园里去。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 21:34; 使徒行传 19:40; 马太福音 11:7–9"> 聚集的人纷纷乱乱，有喊叫这个的，有喊叫那个的；大半不知道是为什么聚集。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 12:17; 提摩太后书 4:14; 提摩太前书 1:20"> 有人把亚历山大从众人中带出来，犹太人推他往前，亚历山大就摆手，要向百姓分诉；</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 19:28; 马太福音 6:7; 启示录 13:4"> 只因他们认出他是犹太人，就大家同声喊着说：「大哉！以弗所人的亚底米啊。」如此约有两小时。</span>
<span className="v" id="v35" data-v="35" data-xref="帖撒罗尼迦后书 2:10–11; 提摩太前书 4:2; 以弗所书 2:12"> 那城里的书记安抚了众人，就说：「以弗所人哪，谁不知道以弗所人的城是看守大亚底米的庙和从宙斯那里落下来的像呢？</span>
<span className="v" id="v36" data-v="36" data-xref="箴言 14:29; 使徒行传 5:35–39; 箴言 25:8"> 这事既是驳不倒的，你们就当安静，不可造次。</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多后书 6:3; 罗马书 2:22; 使徒行传 25:8"> 你们把这些人带来，他们并没有偷窃庙中之物，也没有谤 我们的女神。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 13:7; 哥林多前书 6:1; 使徒行传 18:14"> 若是底米丢和他同行的人有控告人的事，自有放告的日子<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：自有公堂">b</a></sup>，也有方伯可以彼此对告。</span>
<span className="v" id="v39" data-v="39"> 你们若问别的事，就可以照常例聚集断定。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行传 17:5–8; 马太福音 26:5; 使徒行传 20:1"> 今日的扰乱本是无缘无故，我们难免被查问。论到这样聚众，我们也说不出所以然来。」</span>
<span className="v" id="v41" data-v="41" data-xref="传道书 9:17; 诗篇 65:7; 哥林多后书 1:8–10"> 说了这话，便叫众人散去。</span>
</div>
</div>

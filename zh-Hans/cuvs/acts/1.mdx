## 赐圣灵的应许

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 1:3; 路加福音 24:19; 马太福音 4:23–24"> 提阿非罗啊，我已经作了前书，论到耶稣开头一切所行所教训的，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 1:9; 约翰福音 20:21; 以赛亚书 59:20–21"> 直到他借着圣灵吩咐所拣选的使徒，以后被接上升的日子为止。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 15:5–7; 使徒行传 13:31; 约翰福音 20:26"> 他受害之后，用许多的凭据将自己活活地显给使徒看，四十天之久向他们显现，讲说 神国的事。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 24:49; 约翰福音 14:16; 约翰福音 15:26"> 耶稣和他们聚集的时候，嘱咐他们说：「不要离开耶路撒冷，要等候父所应许的，就是你们听见我说过的。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 3:11; 使徒行传 11:15–16; 路加福音 3:16"> 约翰是用水施洗，但不多几日，你们要受圣灵的洗。」</span>
</div>
</div>

## 耶稣升天

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="路加福音 19:11; 路加福音 17:20; 但以理书 7:27"> 他们聚集的时候，问耶稣说：「主啊，你复兴以色列国就在这时候吗？」</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 24:36; 帖撒罗尼迦前书 5:1–2; 马可福音 13:32"> 耶稣对他们说：「父凭着自己的权柄所定的时候、日期，不是你们可以知道的。</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 28:19; 马可福音 16:15; 罗马书 15:19"> 但圣灵降临在你们身上，你们就必得着能力，并要在耶路撒冷、犹太全地，和撒马利亚，直到地极，作我的见证。」</span>
<span className="v" id="v9" data-v="9" data-xref="但以理书 7:13; 路加福音 24:50–51; 马可福音 16:19"> 说了这话，他们正看的时候，他就被取上升，有一朵云彩把他接去，便看不见他了。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 24:4; 约翰福音 20:12; 启示录 7:14"> 当他往上去，他们定睛望天的时候，忽然有两个人身穿白衣，站在旁边，说：</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 1:7; 帖撒罗尼迦前书 4:16; 马可福音 13:26"> 「加利利人哪，你们为什么站着望天呢？这离开你们被接升天的耶稣，你们见他怎样往天上去，他还要怎样来。」</span>
</div>
</div>

## 接替犹大职分的人

<div className="bt">
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="路加福音 24:52; 马太福音 21:1; 路加福音 24:50"> 有一座山，名叫橄榄山，离耶路撒冷不远，约有安息日可走的路程。当下，门徒从那里回耶路撒冷去，</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 20:8; 路加福音 22:12; 马可福音 14:15"> 进了城，就上了所住的一间楼房；在那里有彼得、约翰、雅各、安得烈、腓力、多马、巴多罗买、马太、亚勒腓的儿子雅各、奋锐党的西门，和雅各的儿子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：兄弟">a</a></sup>犹大。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 6:4; 以弗所书 6:18; 歌罗西书 4:2"> 这些人同着几个妇人和耶稣的母亲马利亚，并耶稣的弟兄，都同心合意地恒切祷告。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 15:6; 使徒行传 21:20; 启示录 3:4"> 那时，有许多人聚会，约有一百二十名，彼得就在弟兄中间站起来，</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 41:9; 约翰福音 13:18; 诗篇 55:12–15"> 说：「弟兄们！圣灵借大卫的口，在圣经上预言领人捉拿耶稣的犹大，这话是必须应验的。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 1:25; 马可福音 3:19; 约翰福音 17:12"> 他本来列在我们数中，并且在使徒的职任上得了一分。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 27:3–10; 马太福音 26:14–15; 诗篇 55:23"> 这人用他作恶的工价买了一块田，以后身子仆倒，肚腹崩裂，肠子都流出来。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 2:22; 马太福音 28:15; 使徒行传 21:40"> 住在耶路撒冷的众人都知道这事，所以按着他们那里的话给那块田起名叫亚革大马，就是「血田」的意思。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 69:25; 诗篇 109:8–15; 使徒行传 1:25"> 因为诗篇上写着，说：<br /><span className="pl pl-1">愿他的住处变为荒场，</span><br /><span className="pl pl-1">无人在内居住；</span>又说：<br /><span className="pl pl-1">愿别人得他的职分。</span></span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 15:27; 路加福音 10:1–2; 民数记 27:17"> 所以，主耶稣在我们中间始终出入的时候，</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 1:2; 使徒行传 4:33; 使徒行传 1:8–9"> 就是从约翰施洗起，直到主离开我们被接上升的日子为止，必须从那常与我们作伴的人中立一位与我们同作耶稣复活的见证。」</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 15:22; 使徒行传 1:26"> 于是选举两个人，就是那叫做巴撒巴，又称呼犹士都的约瑟，和马提亚。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记上 16:7; 使徒行传 15:8; 希伯来书 4:13"> 众人就祷告说：「主啊，你知道万人的心，求你从这两个人中，指明你所拣选的是谁，叫他得这使徒的位分。这位分犹大已经丢弃，往自己的地方去了。」</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 16:8; 约书亚记 18:10; 撒母耳记上 14:41–42"> 于是众人为他们摇签，摇出马提亚来；他就和十一个使徒同列。</span>
</div>

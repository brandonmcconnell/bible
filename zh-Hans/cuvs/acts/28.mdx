## 保罗在马耳他岛上

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 27:26; 使徒行传 27:44; 使徒行传 27:39"> 我们既已得救，才知道那岛名叫马耳他。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 1:14; 希伯来书 13:2; 歌罗西书 3:11"> 土人看待我们，有非常的情分；因为当时下雨，天气又冷，就生火接待我们众人。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 23:33; 马太福音 12:34; 使徒行传 28:4"> 那时，保罗拾起一捆柴，放在火上，有一条毒蛇，因为热了出来，咬住他的手。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 13:2; 路加福音 13:4; 约翰福音 7:24"> 土人看见那毒蛇悬在他手上，就彼此说：「这人必是个凶手，虽然从海里救上来，天理还不容他活着。」</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 10:19; 马可福音 16:18; 诗篇 91:13"> 保罗竟把那毒蛇甩在火里，并没有受伤。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 12:22; 使徒行传 14:11–13; 马太福音 21:9"> 土人想他必要肿起来，或是忽然仆倒死了；看了多时，见他无害，就转念，说：「他是个神。」</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 10:40–41; 路加福音 19:6–9; 使徒行传 28:2"> 离那地方不远，有田产是岛长部百流的；他接纳我们，尽情款待三日。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 9:40; 马可福音 6:5; 雅各书 5:14–16"> 当时，部百流的父亲患热病和痢疾躺着。保罗进去，为他祷告，按手在他身上，治好了他。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 5:12; 马可福音 6:54–56; 使徒行传 5:15"> 从此，岛上其余的病人也来，得了医治。</span>
<span className="v" id="v10" data-v="10" data-xref="帖撒罗尼迦前书 2:6; 腓立比书 4:11–12; 马太福音 6:31–34"> 他们又多方地尊敬我们；到了开船的时候，也把我们所需用的送到船上。</span>
</div>
</div>

## 保罗抵达罗马

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 27:6; 哥林多前书 8:4; 以赛亚书 45:20"> 过了三个月，我们上了亚历山大的船往前行；这船以「宙斯双子」为记，是在那海岛过了冬的。</span>
<span className="v" id="v12" data-v="12"> 到了叙拉古，我们停泊三日；</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 27:13"> 又从那里绕行，来到利基翁。过了一天，起了南风，第二天就来到部丢利。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 21:4; 使徒行传 20:6; 使徒行传 19:1"> 在那里遇见弟兄们，请我们与他们同住了七天。这样，我们来到罗马。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 13:3; 罗马书 15:24; 出埃及记 4:14"> 那里的弟兄们一听见我们的信息就出来，到亚比乌市和三馆地方迎接我们。保罗见了他们，就感谢 神，放心壮胆。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 27:3; 使徒行传 24:23; 使徒行传 28:30–31"> 进了罗马城，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷加：百夫长把众囚犯交给御营的统领，惟有">a</a></sup>保罗蒙准和一个看守他的兵另住在一处。</span>
</div>
</div>

## 保罗在罗马传道

<div className="bt">
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="使徒行传 25:8; 使徒行传 6:14; 使徒行传 25:10"> 过了三天，保罗请犹太人的首领来。他们来了，就对他们说：「弟兄们，我虽没有做什么事干犯本国的百姓和我们祖宗的规条，却被锁绑，从耶路撒冷解在罗马人的手里。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 26:31–32; 使徒行传 23:29; 使徒行传 22:24–25"> 他们审问了我，就愿意释放我；因为在我身上，并没有该死的罪。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 26:32; 使徒行传 25:21; 使徒行传 25:10–12"> 无奈犹太人不服，我不得已，只好上告于凯撒，并非有什么事要控告我本国的百姓。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 6:20; 提摩太后书 2:9; 使徒行传 26:6–7"> 因此，我请你们来见面说话，我原为以色列人所指望的，被这链子捆锁。」</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 54:17; 以赛亚书 41:11; 以赛亚书 50:8"> 他们说：「我们并没有接着从犹太来论你的信，也没有弟兄到这里来报给我们说你有什么不好处。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:12; 使徒行传 24:14; 彼得前书 3:16"> 但我们愿意听你的意见如何；因为这教门，我们晓得是到处被毁谤的。」</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 17:2–3; 使徒行传 19:8; 使徒行传 18:28"> 他们和保罗约定了日子，就有许多人到他的寓处来。保罗从早到晚，对他们讲论这事，证明 神国的道，引摩西的律法和先知的书，以耶稣的事劝勉他们。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 14:4; 使徒行传 17:4–5; 使徒行传 19:8–9"> 他所说的话，有信的，有不信的。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 15:7; 彼得后书 1:21; 马可福音 7:6"> 他们彼此不合，就散了；未散以先，保罗说了一句话，说：「圣灵借先知以赛亚向你们祖宗所说的话是不错的。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 6:9–10; 以西结书 12:2; 以赛亚书 42:19–20"> 他说：<br /><span className="pl pl-1">你去告诉这百姓说：</span><br /><span className="pl pl-1">你们听是要听见，却不明白；</span><br /><span className="pl pl-1">看是要看见，却不晓得；</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 6:10"> <span className="pl pl-1">因为这百姓油蒙了心，</span><br /><span className="pl pl-1">耳朵发沉，</span><br /><span className="pl pl-1">眼睛闭着；</span><br /><span className="pl pl-1">恐怕眼睛看见，</span><br /><span className="pl pl-1">耳朵听见，</span><br /><span className="pl pl-1">心里明白，回转过来，</span><br /><span className="pl pl-1">我就医治他们。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 2:30–32; 使徒行传 26:17–18; 罗马书 3:29–30"> 所以你们当知道， 神这救恩，如今传给外邦人，他们也必听受。」<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷加：29 保罗说了这话，犹太人议论纷纷地就走了。">b</a></sup></span>
<span className="v" id="v30" data-v="30"> 保罗在自己所租的房子里住了足足两年。凡来见他的人，他全都接待，</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 4:29; 以弗所书 6:19–20; 马太福音 4:23"> 放胆传讲 神国的道，将主耶稣基督的事教导人，并没有人禁止。</span>
</div>
</div>

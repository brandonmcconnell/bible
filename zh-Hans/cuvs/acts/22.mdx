## 保罗叙述归主的经过

<div className="bt">
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 9:3–8; 使徒行传 26:12–18; 启示录 1:16"> 「我将到大马士革，正走的时候，约在晌午，忽然从天上发大光，四面照着我。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 2:9; 马太福音 25:45; 创世记 22:11"> 我就仆倒在地，听见有声音对我说：『扫罗！扫罗！你为什么逼迫我？』</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 26:9; 撒母耳记上 8:7; 出埃及记 16:7–8"> 我回答说：『主啊，你是谁？』他说：『我就是你所逼迫的拿撒勒人耶稣。』</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 9:7; 但以理书 10:7; 使徒行传 26:13"> 与我同行的人看见了那光，却没有听明那位对我说话的声音。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 16:30; 使徒行传 22:12–16; 使徒行传 2:37"> 我说：『主啊，我当做什么？』主说：『起来，进大马士革去，在那里，要将所派你做的一切事告诉你。』</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 9:8–9; 使徒行传 13:11; 以赛亚书 42:16"> 我因那光的荣耀不能看见，同行的人就拉着我手进了大马士革。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 10:22; 使徒行传 6:3; 约翰三书 1:12"> 那里有一个人，名叫亚拿尼亚，按着律法是虔诚人，为一切住在那里的犹太人所称赞。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 9:17–18; 腓利门书 1:16"> 他来见我，站在旁边，对我说：『兄弟扫罗，你可以看见。』我当时往上一看，就看见了他。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 1:12; 哥林多前书 15:8; 哥林多前书 9:1"> 他又说：『我们祖宗的 神拣选了你，叫你明白他的旨意，又得见那义者，听他口中所出的声音。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 23:11; 使徒行传 4:20; 约翰福音 15:27"> 因为你要将所看见的，所听见的，对着万人为他作见证。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 2:38; 使徒行传 2:21; 提多书 3:5"> 现在你为什么耽延呢？起来，求告他的名受洗，洗去你的罪。』」</span>
</div>
</div>

## 保罗奉召向外邦人传道

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 12:1–4; 使徒行传 10:9–10; 使徒行传 9:26–28"> 「后来，我回到耶路撒冷，在殿里祷告的时候，魂游象外，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 9:29; 路加福音 21:21; 以西结书 3:6–7"> 看见主向我说：『你赶紧地离开耶路撒冷，不可迟延；因你为我作的见证，这里的人必不领受。』</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 22:4; 马太福音 10:17; 使徒行传 8:3"> 我就说：『主啊，他们知道我从前把信你的人收在监里，又在各会堂里鞭打他们。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 7:58; 使徒行传 8:1; 罗马书 1:32"> 并且你的见证人司提反被害流血的时候，我也站在旁边欢喜；又看守害死他之人的衣裳。』</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 9:15; 提摩太前书 2:7; 以弗所书 3:6–8"> 主向我说：『你去吧！我要差你远远地往外邦人那里去。』」</span>
</div>
</div>

## 保罗与长官交涉

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 25:24; 使徒行传 21:36; 约翰福音 19:15"> 众人听他说到这句话，就高声说：「这样的人，从世上除掉他吧！他是不当活着的。」</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 16:13; 使徒行传 26:11; 传道书 10:3"> 众人喧嚷，摔掉衣裳，把尘土向空中扬起来。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 21:31–32; 使徒行传 21:34; 约翰福音 19:1"> 千夫长就吩咐将保罗带进营楼去，叫人用鞭子拷问他，要知道他们向他这样喧嚷是为什么缘故。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 16:37; 使徒行传 25:16; 使徒行传 27:43"> 刚用皮条捆上，保罗对旁边站着的百夫长说：「人是罗马人，又没有定罪，你们就鞭打他，有这个例吗？」</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 23:27; 使徒行传 22:29"> 百夫长听见这话，就去见千夫长，告诉他说：「你要做什么？这人是罗马人。」</span>
<span className="v" id="v27" data-v="27"> 千夫长就来问保罗说：「你告诉我，你是罗马人吗？」保罗说：「是。」</span>
<span className="v" id="v28" data-v="28"> 千夫长说：「我用许多银子才入了罗马的民籍。」保罗说：「我生来就是。」</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 21:33; 使徒行传 22:24–26; 使徒行传 16:38–39"> 于是那些要拷问保罗的人就离开他去了。千夫长既知道他是罗马人，又因为捆绑了他，也害怕了。</span>
</div>
</div>

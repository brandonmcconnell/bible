## 圣灵降临

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 15:6; 腓立比书 2:2; 使徒行传 1:13–15"> 五旬节到了，门徒都聚集在一处。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 4:31; 列王纪上 19:11; 诗篇 18:10"> 忽然，从天上有响声下来，好像一阵大风吹过，充满了他们所坐的屋子，</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 3:11; 约翰福音 1:32–33; 耶利米书 23:29"> 又有舌头如火焰显现出来，分开落在他们各人头上。</span>
<span className="v" id="v4" data-v="4" data-xref="马可福音 16:17; 使徒行传 13:52; 使徒行传 4:31"> 他们就都被圣灵充满，按着圣灵所赐的口才说起别国的话来。</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 2:25; 使徒行传 8:2; 歌罗西书 1:23"> 那时，有虔诚的犹太人从天下各国来，住在耶路撒冷。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 2:3; 哥林多前书 16:9; 使徒行传 2:2"> 这声音一响，众人都来聚集，各人听见门徒用众人的乡谈说话，就甚纳闷；</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 2:12; 使徒行传 1:11; 约翰福音 7:52"> 都惊讶希奇说：「看哪，这说话的不都是加利利人吗？</span>
<span className="v" id="v8" data-v="8"> 我们各人怎么听见他们说我们生来所用的乡谈呢？</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 1:1; 使徒行传 18:2; 启示录 1:4"> 我们帕提亚人、米底亚人、以拦人，和住在美索不达米亚、犹太、加帕多家、本都、亚细亚、</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 16:6; 撒迦利亚书 8:23; 撒迦利亚书 8:20"> 弗吕家、旁非利亚、埃及的人，并靠近古利奈的利比亚一带地方的人，从罗马来的客旅中，或是犹太人，或是进犹太教的人，</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 12:10; 出埃及记 15:11; 诗篇 78:4"> 克里特和阿拉伯人，都听见他们用我们的乡谈，讲说 神的大作为。」</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 15:26; 使徒行传 17:20; 路加福音 18:36"> 众人就都惊讶猜疑，彼此说：「这是什么意思呢？」</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 14:23; 使徒行传 2:15; 撒母耳记上 1:14"> 还有人讥诮说：「他们无非是新酒灌满了。」</span>
</div>
</div>

## 彼得在五旬节的讲论

<div className="bt">
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 51:7; 以赛亚书 51:1; 申命记 27:9"> 彼得和十一个使徒站起，高声说：「犹太人和一切住在耶路撒冷的人哪，这件事你们当知道，也当侧耳听我的话。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 5:5–8; 撒母耳记上 1:15; 马太福音 20:3"> 你们想这些人是醉了；其实不是醉了，因为时候刚到巳初。</span>
<span className="v" id="v16" data-v="16" data-xref="约珥书 2:28–32"> 这正是先知约珥所说的：</span>
<span className="v" id="v17" data-v="17" data-xref="约珥书 2:28–32; 以赛亚书 44:3; 提多书 3:4–6"> <span className="pl pl-1">神说：在末后的日子，</span><br /><span className="pl pl-1">我要将我的灵浇灌凡有血气的。</span><br /><span className="pl pl-1">你们的儿女要说预言；</span><br /><span className="pl pl-1">你们的少年人要见异象；</span><br /><span className="pl pl-1">老年人要做异梦。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="加拉太书 3:28; 歌罗西书 3:11; 哥林多前书 7:21–22"> <span className="pl pl-1">在那些日子，</span><br /><span className="pl pl-1">我要将我的灵浇灌我的仆人和使女，</span><br /><span className="pl pl-1">他们就要说预言。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="约珥书 2:30–31; 西番雅书 1:14–18; 玛拉基书 4:1–6"> <span className="pl pl-1">在天上，我要显出奇事；</span><br /><span className="pl pl-1">在地下，我要显出神迹；</span><br /><span className="pl pl-1">有血，有火，有烟雾。</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="彼得后书 3:10; 阿摩司书 8:9; 马太福音 24:29"> <span className="pl pl-1">日头要变为黑暗，</span><br /><span className="pl pl-1">月亮要变为血；</span><br /><span className="pl pl-1">这都在主大而明显的日子未到以前。</span><br /></span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 10:12–13; 约珥书 2:32; 诗篇 86:5"> <span className="pl pl-1">到那时候，</span><br /><span className="pl pl-1">凡求告主名的，就必得救。</span></span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 3:2; 约翰福音 14:10–11; 马太福音 12:28"> 「以色列人哪，请听我的话： 神借着拿撒勒人耶稣在你们中间施行异能、奇事、神迹，将他证明出来，这是你们自己知道的。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 22:22; 使徒行传 4:28; 使徒行传 3:18"> 他既按着 神的定旨先见被交与人，你们就借着无法之人的手，把他钉在十字架上，杀了。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 6:14; 彼得前书 1:21; 使徒行传 2:32"> 神却将死的痛苦解释了，叫他复活，因为他原不能被死拘禁。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 16:8–11; 以赛亚书 41:13; 诗篇 62:6"> 大卫指着他说：<br /><span className="pl pl-1">我看见主常在我眼前；</span><br /><span className="pl pl-1">他在我右边，叫我不至于摇动。</span></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 16:9; 诗篇 63:5; 诗篇 71:23"> 所以，我心里欢喜，<br /><span className="pl pl-1">我的灵</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是舌">a</a></sup><br /><span className="pl pl-1">快乐；</span><br /><span className="pl pl-1">并且我的肉身要安居在指望中。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 16:10; 使徒行传 2:31; 启示录 1:18"> <span className="pl pl-1">因你必不将我的灵魂撇在阴间，</span><br /><span className="pl pl-1">也不叫你的圣者见朽坏。</span><br /></span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 16:11; 诗篇 25:4; 诗篇 21:6"> <span className="pl pl-1">你已将生命的道路指示我，</span><br /><span className="pl pl-1">必叫我因见你的面</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：叫我在你面前">b</a></sup><br /><span className="pl pl-1">得着满足的快乐。</span></span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 13:36; 列王纪上 2:10; 使徒行传 7:8–9"> 「弟兄们！先祖大卫的事，我可以明明地对你们说：他死了，也葬埋了，并且他的坟墓直到今日还在我们这里。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 132:11–18; 诗篇 89:3–4; 耶利米书 33:14–15"> 大卫既是先知，又晓得 神曾向他起誓，要从他的后裔中立一位坐在他的宝座上，</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 2:27; 诗篇 16:10; 使徒行传 13:35"> 就预先看明这事，讲论基督复活说：<br /><span className="pl pl-1">他的灵魂不撇在阴间；</span><br /><span className="pl pl-1">他的肉身也不见朽坏。</span></span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 3:15; 使徒行传 1:8; 使徒行传 1:22"> 这耶稣， 神已经叫他复活了，我们都为这事作见证。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 1:4; 使徒行传 5:31; 使徒行传 2:17"> 他既被 神的右手高举<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或译：他既高举在 神的右边">c</a></sup>，又从父受了所应许的圣灵，就把你们所看见所听见的，浇灌下来。</span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 110:1; 马太福音 22:42–45; 希伯来书 1:13"> 大卫并没有升到天上，但自己说：<br /><span className="pl pl-1">主对我主说：</span><br /><span className="pl pl-1">你坐在我的右边，</span></span>
<span className="v" id="v35" data-v="35" data-xref="启示录 19:19–3; 罗马书 16:20; 以赛亚书 60:14"> 等我使你仇敌作你的脚凳。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 5:30–31; 罗马书 14:8–12; 哥林多后书 5:10"> 「故此，以色列全家当确实地知道，你们钉在十字架上的这位耶稣， 神已经立他为主，为基督了。」</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 3:10; 使徒行传 22:10; 希伯来书 4:12–13"> 众人听见这话，觉得扎心，就对彼得和其余的使徒说：「弟兄们，我们当怎样行？」</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 22:16; 马可福音 16:16; 使徒行传 8:12"> 彼得说：「你们各人要悔改，奉耶稣基督的名受洗，叫你们的罪得赦，就必领受所赐的圣灵；</span>
<span className="v" id="v39" data-v="39" data-xref="以赛亚书 44:3; 创世记 17:7–8; 罗马书 8:30"> 因为这应许是给你们和你们的儿女，并一切在远方的人，就是主—我们 神所召来的。」</span>
<span className="v" id="v40" data-v="40" data-xref="腓立比书 2:15; 申命记 32:5; 马太福音 17:17"> 彼得还用许多话作见证，劝勉他们说：「你们当救自己脱离这弯曲的世代。」</span>
<span className="v" id="v41" data-v="41" data-xref="使徒行传 4:4; 使徒行传 2:47; 使徒行传 16:31–34"> 于是领受他话的人就受了洗。那一天，门徒约添了三千人，</span>
<span className="v" id="v42" data-v="42" data-xref="希伯来书 10:25; 使徒行传 1:14; 约翰一书 1:3"> 都恒心遵守使徒的教训，彼此交接，擘饼，祈祷。</span>
</div>
</div>

## 在圣徒中间的生活

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="路加福音 7:16; 约翰福音 14:12; 路加福音 8:37"> 众人都惧怕；使徒又行了许多奇事神迹。</span>
<span className="v" id="v44" data-v="44" data-xref="使徒行传 4:32; 约翰一书 3:16–18; 哥林多后书 8:14–15"> 信的人都在一处，凡物公用，</span>
<span className="v" id="v45" data-v="45" data-xref="约翰一书 3:17; 提摩太前书 6:18–19; 雅各书 2:14–16"> 并且卖了田产、家业，照各人所需用的分给各人。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒行传 5:42; 使徒行传 20:7; 使徒行传 2:42"> 他们天天同心合意恒切地在殿里，且在家中擘饼，存着欢喜、诚实的心用饭，</span>
<span className="v" id="v47" data-v="47" data-xref="使徒行传 16:5; 使徒行传 5:13–14; 使徒行传 2:41"> 赞美 神，得众民的喜爱。主将得救的人天天加给他们。</span>

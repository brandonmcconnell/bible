## 保罗在哥林多

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 1:2; 提摩太后书 4:20; 哥林多后书 1:1"> 这事以后，保罗离了雅典，来到哥林多。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 16:3–4; 哥林多前书 16:19; 提摩太后书 4:19"> 遇见一个犹太人，名叫亚居拉，他生在本都；因为克劳第命犹太人都离开罗马，新近带着妻百基拉，从意大利来。保罗就投奔了他们。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 4:12; 帖撒罗尼迦前书 2:9; 哥林多后书 11:9"> 他们本是制造帐棚为业。保罗因与他们同业，就和他们同住做工。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 5:11; 使徒行传 17:17; 使徒行传 28:23"> 每逢安息日，保罗在会堂里辩论，劝化犹太人和希腊人。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 5:14; 使徒行传 18:28; 使徒行传 20:21"> 西拉和提摩太从马其顿来的时候，保罗为道迫切，向犹太人证明耶稣是基督。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 33:4; 撒母耳记下 1:16; 以西结书 33:8–9"> 他们既抗拒、毁谤，保罗就抖着衣裳，说：「你们的罪<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是血">a</a></sup>归到你们自己头上，与我无干<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是我却干净">b</a></sup>。从今以后，我要往外邦人那里去。」</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 16:14; 歌罗西书 4:11; 使徒行传 10:2"> 于是离开那里，到了一个人的家中；这人名叫提多·犹士都，是敬拜 神的，他的家靠近会堂。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 1:13–17; 罗马书 10:14–17; 马可福音 16:15–16"> 管会堂的基利司布和全家都信了主，还有许多哥林多人听了，就相信受洗。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 23:11; 以弗所书 6:19–20; 使徒行传 27:23–25"> 夜间，主在异象中对保罗说：「不要怕，只管讲，不要闭口，</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 12:9; 出埃及记 4:12; 以赛亚书 41:10"> 有我与你同在，必没有人下手害你，因为在这城里我有许多的百姓。」</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 14:3; 使徒行传 19:10; 使徒行传 20:31"> 保罗在那里住了一年零六个月，将 神的道教训他们。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 13:50; 使徒行传 18:27; 使徒行传 13:7"> 到迦流作亚该亚方伯的时候，犹太人同心起来攻击保罗，拉他到公堂，</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 25:8; 使徒行传 24:5–6; 使徒行传 6:13"> 说：「这个人劝人不按着律法敬拜 神。」</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 3:14–15; 使徒行传 25:11; 马可福音 9:19"> 保罗刚要开口，迦流就对犹太人说：「你们这些犹太人！如果是为冤枉或奸恶的事，我理当耐性听你们。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 23:29; 使徒行传 25:19; 提摩太前书 6:4"> 但所争论的，若是关乎言语、名目，和你们的律法，你们自己去办吧！这样的事我不愿意审问」；</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 12:16; 诗篇 76:10; 罗马书 13:3–4"> 就把他们撵出公堂。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 1:1; 阿摩司书 6:6; 使徒行传 17:32"> 众人便揪住管会堂的所提尼，在堂前打他。这些事迦流都不管。</span>
</div>
</div>

## 保罗回到安提阿

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行传 21:24; 民数记 6:18; 民数记 6:5–9"> 保罗又住了多日，就辞别了弟兄，坐船往叙利亚去；百基拉、亚居拉和他同去。他因为许过愿，就在坚革哩剪了头发。</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所书 1:1; 提摩太前书 1:3; 提摩太后书 1:18"> 到了以弗所，保罗就把他们留在那里，自己进了会堂，和犹太人辩论。</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 1:37–38; 哥林多前书 16:12; 使徒行传 20:16"> 众人请他多住些日子，他却不允，</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 4:19; 雅各书 4:15; 罗马书 15:32"> 就辞别他们，说：「 神若许我，我还要回到你们这里」；于是开船离了以弗所。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 8:40; 使徒行传 15:4; 使徒行传 23:23"> 在凯撒利亚下了船，就上耶路撒冷去问教会安，随后下安提阿去。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 14:22; 使徒行传 16:6; 使徒行传 15:41"> 住了些日子，又离开那里，挨次经过加拉太和弗吕家地方，坚固众门徒。</span>
</div>
</div>

## 亚波罗在以弗所讲道

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 4:6; 提多书 3:13; 哥林多前书 3:5–6"> 有一个犹太人，名叫亚波罗，来到以弗所。他生在亚历山大，是有学问<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或译：口才">c</a></sup>的，最能讲解圣经。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 19:3; 罗马书 12:11; 何西阿书 14:9"> 这人已经在主的道上受了教训，心里火热，将耶稣的事详细讲论教训人；只是他单晓得约翰的洗礼。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 18:25; 使徒行传 14:3; 哥林多前书 12:21"> 他在会堂里放胆讲道；百基拉、亚居拉听见，就接他来，将 神的道给他讲解更加详细。</span>
<span className="v" id="v27" data-v="27" data-xref="帖撒罗尼迦后书 2:13–14; 雅各书 1:16–18; 彼得前书 1:2–3"> 他想要往亚该亚去，弟兄们就勉励他，并写信请门徒接待他<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或译：弟兄们就写信劝门徒接待他">d</a></sup>。他到了那里，多帮助那蒙恩信主的人，</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 18:5; 哥林多前书 15:3–4; 使徒行传 9:22"> 在众人面前极有能力驳倒犹太人，引圣经证明耶稣是基督。</span>
</div>
</div>

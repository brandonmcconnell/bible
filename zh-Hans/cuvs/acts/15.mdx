## 耶路撒冷会议

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 5:6; 使徒行传 15:5; 利未记 12:3"> 有几个人从犹太下来，教训弟兄们说：「你们若不按摩西的规条受割礼，不能得救。」</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 15:22–23; 使徒行传 15:6–7; 加拉太书 2:1–2"> 保罗、巴拿巴与他们大大地纷争辩论；众门徒就定规，叫保罗、巴拿巴和本会中几个人，为所辩论的，上耶路撒冷去见使徒和长老。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 14:27; 使徒行传 21:5; 哥林多前书 16:11"> 于是教会送他们起行。他们经过腓尼基、撒马利亚，随处传说外邦人归主的事，叫众弟兄都甚欢喜。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 14:27; 使徒行传 15:12; 使徒行传 15:3"> 到了耶路撒冷，教会和使徒并长老都接待他们，他们就述说 神同他们所行的一切事。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 5:1–3; 腓立比书 3:5–8; 使徒行传 15:1"> 惟有几个信徒是法利赛教门的人，起来说：「必须给外邦人行割礼，吩咐他们遵守摩西的律法。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="箴言 15:22; 希伯来书 13:7; 希伯来书 13:17"> 使徒和长老聚会商议这事；</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 10:17–18; 加拉太书 2:7–9; 历代志上 28:4–5"> 辩论已经多了，彼得就起来，说：「诸位弟兄，你们知道 神早已在你们中间拣选了我，叫外邦人从我口中得听福音之道，而且相信。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 1:24; 使徒行传 10:47; 使徒行传 14:3"> 知道人心的 神也为他们作了见证，赐圣灵给他们，正如给我们一样；</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 3:6; 加拉太书 5:6; 使徒行传 10:28"> 又借着信洁净了他们的心，并不分他们我们。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 5:1; 马太福音 23:4; 加拉太书 4:9"> 现在为什么试探 神，要把我们祖宗和我们所不能负的轭放在门徒的颈项上呢？</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 3:24; 提多书 3:4–7; 提多书 2:11"> 我们得救乃是因主耶稣的恩，和他们一样，这是我们所信的。」</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 14:27; 使徒行传 15:4; 使徒行传 21:19"> 众人都默默无声，听巴拿巴和保罗述说 神借他们在外邦人中所行的神迹奇事。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 12:17; 加拉太书 2:12; 雅各书 1:1"> 他们住了声，雅各就说：「诸位弟兄，请听我的话。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得后书 1:1; 使徒行传 15:7–9; 路加福音 2:31–32"> 方才西门述说 神当初怎样眷顾外邦人，从他们中间选取百姓归于自己的名下；</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 15:8–12; 使徒行传 13:47"> 众先知的话也与这意思相合。</span>
<span className="v" id="v16" data-v="16" data-xref="阿摩司书 9:11–12; 诗篇 89:35–49; 路加福音 1:31–33"> 正如经上所写的：<br /><span className="pl pl-1">此后，我要回来，</span><br /><span className="pl pl-1">重新修造大卫倒塌的帐幕，</span><br /><span className="pl pl-1">把那破坏的重新修造建立起来，</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="撒迦利亚书 2:11; 撒迦利亚书 8:20–23; 以赛亚书 65:1"> <span className="pl pl-1">叫余剩的人，</span><br /><span className="pl pl-1">就是凡称为我名下的外邦人，</span><br /><span className="pl pl-1">都寻求主。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 1:4; 以弗所书 3:9; 以赛亚书 46:9–10"> <span className="pl pl-1">这话是从创世以来显明这事的主说的。</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 15:28; 加拉太书 1:7–10; 使徒行传 15:24"> 「所以据我的意见，不可难为那归服 神的外邦人；</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 15:29; 启示录 2:20; 利未记 3:17"> 只要写信，吩咐他们禁戒偶像的污秽和奸淫，并勒死的牲畜和血。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 13:15; 使徒行传 13:27; 哥林多后书 3:14–15"> 因为从古以来，摩西的书在各城有人传讲，每逢安息日，在会堂里诵读。」</span>
</div>
</div>

## 会议的复函

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 15:27; 使徒行传 15:40; 帖撒罗尼迦前书 1:1"> 那时，使徒和长老并全教会定意从他们中间拣选人，差他们和保罗、巴拿巴同往安提阿去；所拣选的就是称呼巴撒巴的犹大和西拉。这两个人在弟兄中是作首领的。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 23:26; 雅各书 1:1; 加拉太书 1:21"> 于是写信交付他们，内中说：「使徒和作长老的弟兄们问安提阿、叙利亚、基利家外邦众弟兄的安。</span>
<span className="v" id="v24" data-v="24" data-xref="加拉太书 5:12; 加拉太书 5:10; 使徒行传 15:1"> 我们听说，有几个人从我们这里出去，用言语搅扰你们，惑乱你们的心。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷加：你们必须受割礼，守摩西的律法。">a</a></sup>其实我们并没有吩咐他们。</span>
<span className="v" id="v25" data-v="25" data-xref="彼得后书 3:15; 使徒行传 1:14; 使徒行传 15:2"> 所以，我们同心定意，拣选几个人，差他们同我们所亲爱的巴拿巴和保罗往你们那里去。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 14:19; 使徒行传 9:23–25; 腓立比书 2:29–30"> 这二人是为我主耶稣基督的名不顾性命的。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 15:22; 使徒行传 15:32; 约翰三书 1:13"> 我们就差了犹大和西拉，他们也要亲口诉说这些事。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 16:13; 启示录 2:24; 马太福音 11:30"> 因为圣灵和我们定意不将别的重担放在你们身上，惟有几件事是不可少的，</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 15:20; 使徒行传 21:25; 启示录 2:14"> 就是禁戒祭偶像的物和血，并勒死的牲畜和奸淫。这几件你们若能自己禁戒不犯就好了。愿你们平安！」</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行传 16:4; 使徒行传 6:2; 使徒行传 23:33"> 他们既奉了差遣，就下安提阿去，聚集众人，交付书信。</span>
<span className="v" id="v31" data-v="31" data-xref="加拉太书 2:4–5; 腓立比书 3:3; 加拉太书 5:1"> 众人念了，因为信上安慰的话就欢喜了。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 11:23; 使徒行传 14:22; 使徒行传 13:1"> 犹大和西拉也是先知，就用许多话劝勉弟兄，坚固他们。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 16:11; 使徒行传 16:36; 希伯来书 11:31"> 住了些日子，弟兄们打发他们平平安安地回到差遣他们的人那里去。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷加：34惟有西拉定意仍住在那里。">b</a></sup></span>
<span className="v" id="v35" data-v="35" data-xref="提摩太后书 4:2; 歌罗西书 1:28; 使徒行传 13:1"> 但保罗和巴拿巴仍住在安提阿，和许多别人一同教训人，传主的道。</span>
</div>
</div>

## 保罗和巴拿巴分手

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行传 14:6; 使徒行传 13:4; 使徒行传 13:51"> 过了些日子，保罗对巴拿巴说：「我们可以回到从前宣传主道的各城，看望弟兄们景况如何。」</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 12:12; 腓利门书 1:24; 使徒行传 13:5"> 巴拿巴有意要带称呼马可的约翰同去；</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 13:13; 箴言 25:19; 路加福音 14:27–34"> 但保罗因为马可从前在旁非利亚离开他们，不和他们同去做工，就以为不可带他去。</span>
<span className="v" id="v39" data-v="39" data-xref="歌罗西书 4:10; 传道书 7:20; 使徒行传 4:36"> 于是二人起了争论，甚至彼此分开。巴拿巴带着马可，坐船往塞浦路斯去；</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行传 15:22; 使徒行传 14:26; 使徒行传 11:23"> 保罗拣选了西拉，也出去，蒙弟兄们把他交于主的恩中。</span>
<span className="v" id="v41" data-v="41" data-xref="使徒行传 15:23; 加拉太书 1:21; 使徒行传 15:32"> 他就走遍叙利亚、基利家，坚固众教会。</span>
</div>

## 保罗要向凯撒上诉

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 23:34; 使徒行传 25:5; 使徒行传 8:40"> 非斯都到了任，过了三天，就从凯撒利亚上耶路撒冷去。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 25:15; 箴言 4:16; 使徒行传 24:1"> 祭司长和犹太人的首领向他控告保罗，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 9:24; 使徒行传 23:12–15; 撒母耳记上 23:19–21"> 又央告他，求他的情，将保罗提到耶路撒冷来，他们要在路上埋伏杀害他。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 24:23"> 非斯都却回答说：「保罗押在凯撒利亚，我自己快要往那里去」；</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 25:25; 约翰福音 18:29–30; 使徒行传 25:18–19"> 又说：「你们中间有权势的人与我一同下去，那人若有什么不是，就可以告他。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 25:17; 使徒行传 25:10; 马太福音 27:19"> 非斯都在他们那里住了不过十天八天，就下凯撒利亚去；第二天坐堂，吩咐将保罗提上来。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 24:13; 路加福音 23:10; 使徒行传 25:24"> 保罗来了，那些从耶路撒冷下来的犹太人周围站着，将许多重大的事控告他，都是不能证实的。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 24:12; 使徒行传 28:17; 哥林多后书 1:12"> 保罗分诉说：「无论犹太人的律法，或是圣殿，或是凯撒，我都没有干犯。」</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 24:27; 使徒行传 12:3; 使徒行传 25:20"> 但非斯都要讨犹太人的喜欢，就问保罗说：「你愿意上耶路撒冷去，在那里听我审断这事吗？」</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 27:18; 哥林多后书 4:2; 使徒行传 28:18"> 保罗说：「我站在凯撒的堂前，这就是我应当受审的地方。我向犹太人并没有行过什么不义的事，这也是你明明知道的。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 28:19; 使徒行传 26:32; 使徒行传 25:25"> 我若行了不义的事，犯了什么该死的罪，就是死，我也不辞。他们所告我的事若都不实，就没有人可以把我交给他们。我要上告于凯撒。」</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 19:21; 腓立比书 1:12–14; 腓立比书 1:20"> 非斯都和议会商量了，就说：「你既上告于凯撒，可以往凯撒那里去。」</span>
</div>
</div>

## 保罗被带到亚基帕王面前

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 8:40; 使徒行传 26:1; 使徒行传 26:27–28"> 过了些日子，亚基帕王和百妮基氏来到凯撒利亚，问非斯都安。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 24:27"> 在那里住了多日，非斯都将保罗的事告诉王，说：「这里有一个人，是腓力斯留在监里的。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 25:1–3; 以斯帖记 3:9; 路加福音 18:3–5"> 我在耶路撒冷的时候，祭司长和犹太的长老将他的事禀报了我，求我定他的罪。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 7:51; 申命记 19:17–18; 使徒行传 23:30"> 我对他们说，无论什么人，被告还没有和原告对质，未得机会分诉所告他的事，就先定他的罪，这不是罗马人的条例。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 25:6; 使徒行传 25:10"> 及至他们都来到这里，我就不耽延，第二天便坐堂，吩咐把那人提上来。</span>
<span className="v" id="v18" data-v="18"> 告他的人站着告他；所告的，并没有我所逆料的那等恶事。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 23:29; 使徒行传 18:15; 哥林多前书 15:3–4"> 不过是有几样辩论，为他们自己敬鬼神的事，又为一个人名叫耶稣，是已经死了，保罗却说他是活着的。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 25:9"> 这些事当怎样究问，我心里作难，所以问他说：『你愿意上耶路撒冷去，在那里为这些事听审吗？』</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 4:16; 路加福音 2:1; 使徒行传 25:10–11"> 但保罗求我留下他，要听皇上审断，我就吩咐把他留下，等我解他到凯撒那里去。」</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 9:15; 马太福音 10:18; 以赛亚书 52:15"> 亚基帕对非斯都说：「我自己也愿听这人辩论。」非斯都说：「明天你可以听。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 26:30; 使徒行传 25:13; 约翰一书 2:16"> 第二天，亚基帕和百妮基大张威势而来，同着众千夫长和城里的尊贵人进了公厅。非斯都吩咐一声，就有人将保罗带进来。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 22:22; 使徒行传 25:7; 使徒行传 25:2–3"> 非斯都说：「亚基帕王和在这里的诸位啊，你们看这人，就是一切犹太人，在耶路撒冷和这里，曾向我恳求、呼叫说：『不可容他再活着。』</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 23:29; 使徒行传 25:11–12; 路加福音 23:4"> 但我查明他没有犯什么该死的罪，并且他自己上告于皇帝，所以我定意把他解去。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 26:2–3"> 论到这人，我没有确实的事可以奏明主上。因此，我带他到你们面前，也特意带他到你亚基帕王面前，为要在查问之后有所陈奏。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 7:51; 箴言 18:13"> 据我看来，解送囚犯，不指明他的罪案是不合理的。」</span>
</div>
</div>

</div>

## 扫罗的转变

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 8:3; 提摩太前书 1:13; 加拉太书 1:13"> 扫罗仍然向主的门徒口吐威吓凶杀的话，去见大祭司，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 19:9; 使徒行传 19:23; 使徒行传 24:14"> 求文书给大马士革的各会堂，若是找着信奉这道的人，无论男女，都准他捆绑带到耶路撒冷。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 26:12–13; 哥林多前书 15:8; 使徒行传 22:6"> 扫罗行路，将到大马士革，忽然从天上发光，四面照着他；</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 2:8; 创世记 22:11; 罗马书 11:22"> 他就仆倒在地，听见有声音对他说：「扫罗！扫罗！你为什么逼迫我？」</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太前书 1:13; 撒母耳记上 3:4–10; 约伯记 9:4"> 他说：「主啊！你是谁？」主说：「我就是你所逼迫的耶稣。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 22:10; 使徒行传 26:16; 提摩太前书 1:14–16"> 起来！进城去，你所当做的事，必有人告诉你。」</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 22:9; 但以理书 10:7; 使徒行传 26:13–14"> 同行的人站在那里，说不出话来，听见声音，却看不见人。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 22:11; 使徒行传 9:18; 列王纪下 6:17–20"> 扫罗从地上起来，睁开眼睛，竟不能看见什么。有人拉他的手，领他进了大马士革；</span>
<span className="v" id="v9" data-v="9" data-xref="约拿书 3:6–8; 以斯帖记 4:16; 历代志下 33:12–13"> 三日不能看见，也不吃也不喝。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 22:1; 使徒行传 10:3; 使徒行传 22:12"> 当下，在大马士革有一个门徒，名叫亚拿尼亚。主在异象中对他说：「亚拿尼亚。」他说：「主，我在这里。」</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 21:39; 使徒行传 22:3; 使徒行传 9:30"> 主对他说：「起来！往直街去，在犹大的家里，访问一个大数人，名叫扫罗。他正祷告，</span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 5:23; 使徒行传 9:10; 使徒行传 9:17–18"> 又看见了一个人，名叫亚拿尼亚，进来按手在他身上，叫他能看见。」</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太前书 1:13–15; 使徒行传 8:3; 使徒行传 22:19–20"> 亚拿尼亚回答说：「主啊，我听见许多人说，这人怎样在耶路撒冷多多苦害你的圣徒，</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 9:21; 使徒行传 7:59; 提摩太后书 2:22"> 并且他在这里有从祭司长得来的权柄捆绑一切求告你名的人。」</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 1:15–16; 以弗所书 3:7–8; 提摩太后书 4:16–17"> 主对亚拿尼亚说：「你只管去！他是我所拣选的器皿，要在外邦人和君王，并以色列人面前宣扬我的名。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦前书 3:3; 使徒行传 21:11; 哥林多后书 6:4"> 我也要指示他，为我的名必须受许多的苦难。」</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 8:17; 使徒行传 6:6; 使徒行传 2:4"> 亚拿尼亚就去了，进入那家，把手按在扫罗身上，说：「兄弟扫罗，在你来的路上向你显现的主，就是耶稣，打发我来，叫你能看见，又被圣灵充满。」</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 3:14; 使徒行传 22:16; 使徒行传 2:38"> 扫罗的眼睛上，好像有鳞立刻掉下来，他就能看见。于是起来受了洗；</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 26:20; 撒母耳记上 30:12; 加拉太书 1:17"> 吃过饭就健壮了。 扫罗在大马士革传道<br />扫罗和大马士革的门徒同住了些日子，</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 20:28; 加拉太书 2:20; 约翰一书 4:14–15"> 就在各会堂里宣传耶稣，说他是 神的儿子。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 9:13–14; 使徒行传 8:3; 帖撒罗尼迦后书 1:10"> 凡听见的人都惊奇，说：「在耶路撒冷残害求告这名的，不是这人吗？并且他到这里来，特要捆绑他们，带到祭司长那里。」</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 18:5; 以赛亚书 40:29; 路加福音 21:15"> 但扫罗越发有能力，驳倒住大马士革的犹太人，证明耶稣是基督。</span>
</div>
</div>

## 未受犹太人的谋害

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="加拉太书 1:17–18; 帖撒罗尼迦前书 2:15–16; 使徒行传 14:19"> 过了好些日子，犹太人商议要杀扫罗，</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 11:32; 使徒行传 25:3; 使徒行传 20:3"> 但他们的计谋被扫罗知道了。他们又昼夜在城门守候，要杀他。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 2:15; 哥林多后书 11:33; 撒母耳记上 19:11–12"> 他的门徒就在夜间用筐子把他从城墙上缒下去。</span>
</div>
</div>

## 扫罗在耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 26:20; 加拉太书 1:17–19; 使徒行传 9:19"> 扫罗到了耶路撒冷，想与门徒结交，他们却都怕他，不信他是门徒。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 4:36; 使徒行传 4:29; 使徒行传 4:13"> 惟有巴拿巴接待他，领去见使徒，把他在路上怎么看见主，主怎么向他说话，他在大马士革怎么奉耶稣的名放胆传道，都述说出来。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 1:21; 民数记 27:16–17; 诗篇 121:8"> 于是扫罗在耶路撒冷和门徒出入来往，</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 6:1; 犹大书 1:9; 使徒行传 11:20"> 奉主的名放胆传道，并与说希腊话的犹太人讲论辩驳；他们却想法子要杀他。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 11:25; 使徒行传 8:40; 使徒行传 9:11"> 弟兄们知道了就送他下凯撒利亚，打发他往大数去。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="诗篇 111:10; 约翰福音 14:16–18; 以赛亚书 33:6"> 那时，犹太、加利利、撒马利亚各处的教会都得平安，被建立；凡事敬畏主，蒙圣灵的安慰，人数就增多了。</span>
</div>
</div>

## 以尼雅得医治

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行传 9:13; 使徒行传 8:25; 箴言 2:8"> 彼得周流四方的时候，也到了居住吕大的圣徒那里；</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 13:16; 约翰福音 5:5; 马可福音 2:3–11"> 遇见一个人，名叫以尼雅，得了瘫痪，在褥子上躺卧八年。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 9:6; 使徒行传 3:12; 使徒行传 3:6"> 彼得对他说：「以尼雅，耶稣基督医好你了，起来！收拾你的褥子。」他就立刻起来了。</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 11:21; 使徒行传 9:42; 历代志上 5:16"> 凡住吕大和沙 的人都看见了他，就归服主。</span>
</div>
</div>

## 多加复活

<div className="bt">
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="提多书 3:8; 提多书 2:7; 历代志下 2:16"> 在约帕有一个女徒，名叫大比大，翻希腊话就是多加<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是羚羊的意思">a</a></sup>；她广行善事，多施周济。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 1:13; 使徒行传 20:8; 约翰福音 11:36–37"> 当时，她患病而死，有人把她洗了，停在楼上。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 9:36; 使徒行传 11:26; 使徒行传 9:32"> 吕大原与约帕相近；门徒听见彼得在那里，就打发两个人去见他，央求他说：「快到我们那里去，不要耽延。」</span>
<span className="v" id="v39" data-v="39" data-xref="箴言 10:7; 箴言 31:30–31; 帖撒罗尼迦前书 1:3"> 彼得就起身和他们同去；到了，便有人领他上楼。众寡妇都站在彼得旁边哭，拿多加与她们同在时所做的里衣外衣给他看。</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 9:25; 马可福音 5:40–42; 路加福音 8:54"> 彼得叫她们都出去，就跪下祷告，转身对着死人说：「大比大，起来！」她就睁开眼睛，见了彼得，便坐起来。</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 1:31; 使徒行传 6:1; 创世记 45:26"> 彼得伸手扶她起来，叫众圣徒和寡妇进去，把多加活活地交给他们。</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 12:44; 约翰福音 12:11; 约翰福音 11:45"> 这事传遍了约帕，就有许多人信了主。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行传 10:6; 使徒行传 10:32"> 此后，彼得在约帕一个硝皮匠西门的家里住了多日。</span>
</div>

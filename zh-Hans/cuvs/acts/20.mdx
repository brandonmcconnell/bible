## 保罗再访问马其顿和希腊

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 7:5; 使徒行传 19:21; 提摩太前书 1:3"> 乱定之后，保罗请门徒来，劝勉他们，就辞别起行，往马其顿去。</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦前书 2:3; 帖撒罗尼迦前书 4:1; 歌罗西书 1:28"> 走遍了那一带地方，用许多话劝勉门徒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：众人">a</a></sup>，然后来到希腊。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 20:19; 哥林多后书 11:26; 使徒行传 9:23–24"> 在那里住了三个月，将要坐船往叙利亚去，犹太人设计要害他，他就定意从马其顿回去。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 19:29; 以弗所书 6:21; 提摩太后书 4:20"> 同他到亚细亚去的，有庇哩亚人毕罗斯的儿子所巴特，帖撒罗尼迦人亚里达古和西公都，还有特庇人该犹，并提摩太，又有亚细亚人推基古和特罗非摩。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 16:8; 使徒行传 16:10–11; 提摩太后书 4:13"> 这些人先走，在特罗亚等候我们。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 12:3; 使徒行传 16:12; 出埃及记 23:15"> 过了除酵的日子，我们从腓立比开船，五天到了特罗亚，和他们相会，在那里住了七天。</span>
</div>
</div>

## 保罗最后一次访问特罗亚

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 16:2; 使徒行传 2:42; 约翰福音 20:19"> 七日的第一日，我们聚会擘饼的时候，保罗因为要次日起行，就与他们讲论，直讲到半夜。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 1:13; 路加福音 22:12"> 我们聚会的那座楼上，有好些灯烛。</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 13:36; 马太福音 26:40–41; 约拿书 1:5–6"> 有一个少年人，名叫犹推古，坐在窗台上，困倦沉睡。保罗讲了多时，少年人睡熟了，就从三层楼上掉下去；扶起他来，已经死了。</span>
<span className="v" id="v10" data-v="10" data-xref="马可福音 5:39; 马太福音 9:23–24; 列王纪上 17:21–22"> 保罗下去，伏在他身上，抱着他，说：「你们不要发慌，他的灵魂还在身上。」</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 20:7; 使徒行传 20:9"> 保罗又上去，擘饼，吃了，谈论许久，直到天亮，这才走了。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦后书 2:16; 帖撒罗尼迦前书 5:14; 哥林多后书 1:4"> 有人把那童子活活地领来，得的安慰不小。</span>
</div>
</div>

## 从特罗亚到米利都

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马可福音 6:46; 马可福音 1:35; 马可福音 6:31–33"> 我们先上船，开往亚朔去，意思要在那里接保罗；因为他是这样安排的，他自己打算要步行。</span>
<span className="v" id="v14" data-v="14"> 他既在亚朔与我们相会，我们就接他上船，来到米推利尼。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太后书 4:20; 使徒行传 20:17"> 从那里开船，次日到了基阿的对面；又次日，在撒摩靠岸；又次日，来到米利都。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 16:8; 使徒行传 2:1; 使徒行传 19:21"> 乃因保罗早已定意越过以弗所，免得在亚细亚耽延，他急忙前走，巴不得赶五旬节能到耶路撒冷。</span>
</div>
</div>

## 保罗向以弗所长老发表谈话

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="提多书 1:5; 使徒行传 11:30; 提摩太前书 5:17"> 保罗从米利都打发人往以弗所去，请教会的长老来。</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 1:5–6; 使徒行传 18:19; 使徒行传 19:1"> 他们来了，保罗就说：「你们知道，自从我到亚细亚的日子以来，在你们中间始终为人如何，</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 3:24; 哥林多后书 2:4; 罗马书 12:11"> 服事主，凡事谦卑，眼中流泪，又因犹太人的谋害，经历试炼。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 20:27; 提摩太后书 4:2; 使徒行传 5:42"> 你们也知道，凡与你们有益的，我没有一样避讳不说的，或在众人面前，或在各人家里，我都教导你们；</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 2:38; 使徒行传 11:18; 约翰一书 5:11–13"> 又对犹太人和希腊人证明当向 神悔改，信靠我主耶稣基督。</span>
<span className="v" id="v22" data-v="22" data-xref="雅各书 4:14; 哥林多后书 5:14; 彼得后书 1:14"> 现在我往耶路撒冷去，心甚迫切<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是心被捆绑">b</a></sup>，不知道在那里要遇见什么事；</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 9:16; 帖撒罗尼迦前书 3:3; 使徒行传 21:4"> 但知道圣灵在各城里向我指证，说有捆锁与患难等待我。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太后书 4:6–8; 哥林多后书 4:1; 哥林多后书 12:10"> 我却不以性命为念，也不看为宝贵，只要行完我的路程，成就我从主耶稣所领受的职事，证明 神恩惠的福音。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行传 28:31; 使徒行传 20:38; 马太福音 4:23"> 「我素常在你们中间来往，传讲 神国的道；如今我晓得，你们以后都不得再见我的面了。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 18:6; 以西结书 3:18–21; 以西结书 33:2–9"> 所以我今日向你们证明，你们中间无论何人死亡，罪不在我身上<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是我于众人的血是洁净的">c</a></sup>。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 20:20; 帖撒罗尼迦前书 2:4; 加拉太书 1:7–10"> 因为 神的旨意，我并没有一样避讳不传给你们的。</span>
<span className="v" id="v28" data-v="28" data-xref="彼得前书 5:2–3; 提摩太前书 4:16; 以赛亚书 40:11"> 圣灵立你们作全群的监督，你们就当为自己谨慎，也为全群谨慎，牧养 神的教会，就是他用自己血所买来的<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或译：救赎的">d</a></sup>。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 7:15; 彼得后书 2:1; 约翰福音 10:12"> 我知道，我去之后必有凶暴的豺狼进入你们中间，不爱惜羊群。</span>
<span className="v" id="v30" data-v="30" data-xref="提摩太前书 1:19–20; 提摩太后书 4:3–4; 箴言 23:33"> 就是你们中间，也必有人起来说悖谬的话，要引诱门徒跟从他们。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 19:8; 使徒行传 20:19; 使徒行传 19:10"> 所以你们应当警醒，记念我三年之久昼夜不住地流泪、劝戒你们各人。</span>
<span className="v" id="v32" data-v="32" data-xref="歌罗西书 1:12; 以弗所书 1:14; 歌罗西书 3:24"> 如今我把你们交托 神和他恩惠的道；这道能建立你们，叫你们和一切成圣的人同得基业。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多后书 11:9; 哥林多前书 9:12; 哥林多前书 9:18"> 我未曾贪图一个人的金、银、衣服。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 18:3; 哥林多前书 4:12; 帖撒罗尼迦后书 3:8–9"> 我这两只手常供给我和同人的需用，这是你们自己知道的。</span>
<span className="v" id="v35" data-v="35" data-xref="希伯来书 13:16; 箴言 19:17; 哥林多后书 9:6–12"> 我凡事给你们作榜样，叫你们知道应当这样劳苦，扶助软弱的人，又当记念主耶稣的话，说：『施比受更为有福。』」</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行传 21:5; 路加福音 22:41; 腓立比书 4:6"> 保罗说完了这话，就跪下同众人祷告。</span>
<span className="v" id="v37" data-v="37" data-xref="提摩太后书 1:4; 哥林多前书 16:20; 帖撒罗尼迦前书 5:26"> 众人痛哭，抱着保罗的颈项，和他亲嘴。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 15:3; 哥林多前书 16:11; 使徒行传 20:25"> 叫他们最伤心的，就是他说「以后不能再见我的面」那句话，于是送他上船去了。</span>
</div>
</div>

## 彼得、约翰在公会被查问

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 22:4; 使徒行传 6:12; 使徒行传 23:6–9"> 使徒对百姓说话的时候，祭司们和守殿官，并撒都该人忽然来了。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 17:18; 帖撒罗尼迦前书 4:13–14; 使徒行传 24:14–15"> 因他们教训百姓，本着耶稣，传说死人复活，就很烦恼，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 5:18; 马太福音 10:16–17; 使徒行传 16:19–24"> 于是下手拿住他们；因为天已经晚了，就把他们押到第二天。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 2:41; 哥林多后书 2:14–17; 提摩太后书 2:9–10"> 但听道之人有许多信的，男丁数目约到五千。</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 4:8; 马太福音 27:1–2; 路加福音 20:1"> 第二天，官府、长老，和文士在耶路撒冷聚会，</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 3:2; 约翰福音 18:24; 马太福音 26:3"> 又有大祭司亚那和该亚法、约翰、亚历山大，并大祭司的亲族都在那里，</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 21:23; 马可福音 11:28; 使徒行传 5:40"> 叫使徒站在当中，就问他们说：「你们用什么能力，奉谁的名做这事呢？」</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 12:11–12; 马太福音 10:19–20; 使徒行传 2:4"> 那时彼得被圣灵充满，对他们说：</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 3:15–17; 使徒行传 3:7; 约翰福音 10:32"> 「治民的官府和长老啊，倘若今日因为在残疾人身上所行的善事查问我们他是怎么得了痊愈，</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 5:29–32; 使徒行传 3:6; 使徒行传 2:36"> 你们众人和以色列百姓都当知道，站在你们面前的这人得痊愈是因你们所钉十字架、 神叫他从死里复活的拿撒勒人耶稣基督的名。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 118:22–23; 以赛亚书 28:16; 马可福音 12:10–12"> 他是<br /><span className="pl pl-1">你们匠人所弃的石头，</span><br /><span className="pl pl-1">已成了房角的头块石头。</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约翰福音 14:6; 哥林多前书 3:11; 约翰福音 3:36"> 除他以外，别无拯救；因为在天下人间，没有赐下别的名，我们可以靠着得救。」</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 1:27; 约翰福音 7:15; 马太福音 11:25"> 他们见彼得、约翰的胆量，又看出他们原是没有学问的小民，就希奇，认明他们是跟过耶稣的；</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 19:36; 使徒行传 3:8–12; 使徒行传 4:21"> 又看见那治好了的人和他们一同站着，就无话可驳。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 26:30–32; 使徒行传 5:34–42; 马太福音 5:22"> 于是吩咐他们从公会出去，就彼此商议说：</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 21:15; 使徒行传 6:10; 约翰福音 12:18"> 「我们当怎样办这两个人呢？因为他们诚然行了一件明显的神迹，凡住耶路撒冷的人都知道，我们也不能说没有。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 5:28; 罗马书 15:18–22; 使徒行传 5:24"> 惟恐这事越发传扬在民间，我们必须恐吓他们，叫他们不再奉这名对人讲论。」</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 5:40; 路加福音 24:46–48; 使徒行传 5:20"> 于是叫了他们来，禁止他们总不可奉耶稣的名讲论教训人。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 5:29; 出埃及记 1:17; 哥林多前书 10:15"> 彼得、约翰说：「听从你们，不听从 神，这在 神面前合理不合理，你们自己酌量吧！</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 22:15; 耶利米书 20:9; 哥林多前书 9:16–17"> 我们所看见所听见的，不能不说。」</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 5:26; 马太福音 21:46; 路加福音 22:2"> 官长为百姓的缘故，想不出法子刑罚他们，又恐吓一番，把他们释放了。这是因众人为所行的奇事都归荣耀与 神。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 5:5; 使徒行传 9:33; 路加福音 13:11"> 原来借着神迹医好的那人有四十多岁了。</span>
</div>
</div>

## 门徒求主赐胆量

<div className="bt">
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 6:14–17; 使徒行传 12:11–12; 诗篇 119:63"> 二人既被释放，就到会友那里去，把祭司长和长老所说的话都告诉他们。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 20:11; 耶利米书 32:17; 尼希米记 9:6"> 他们听见了，就同心合意地高声向 神说：「主啊！你是造天、地、海，和其中万物的，</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 2:1–6; 使徒行传 1:16; 使徒行传 2:30"> 你曾借着圣灵，托你仆人—我们祖宗大卫的口，说：<br /><span className="pl pl-1">外邦为什么争闹？</span><br /><span className="pl pl-1">万民为什么谋算虚妄的事？</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 2:2; 启示录 17:12–14; 但以理书 9:24"> <span className="pl pl-1">世上的君王一齐起来，</span><br /><span className="pl pl-1">臣宰也聚集，</span><br /><span className="pl pl-1">要敌挡主，</span><br /><span className="pl pl-1">并主的受膏者</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：基督">a</a></sup><br /><span className="pl pl-1">。</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马太福音 27:2; 使徒行传 4:30; 路加福音 9:22"> 希律和本丢·彼拉多，外邦人和以色列民，果然在这城里聚集，要攻打你所膏的圣仆<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="仆：或译子">b</a></sup>耶稣，</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 2:23; 以赛亚书 46:10; 创世记 50:20"> 成就你手和你意旨所预定必有的事。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 4:13; 使徒行传 14:3; 腓立比书 1:14"> 他们恐吓我们，现在求主鉴察，一面叫你仆人大放胆量讲你的道，一面伸出你的手来医治疾病，并且使神迹奇事因着你圣仆<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="-30 仆：或译子">c</a></sup>耶稣的名行出来。」</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 21:22; 使徒行传 2:2; 使徒行传 2:4"> 祷告完了，聚会的地方震动，他们就都被圣灵充满，放胆讲论 神的道。</span>
</div>
</div>

## 凡物公用

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="哥林多前书 1:10; 以弗所书 4:2–6; 彼得前书 3:8"> 那许多信的人都是一心一意的，没有一人说他的东西有一样是自己的，都是大家公用。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 1:16; 使徒行传 1:22; 使徒行传 1:8"> 使徒大有能力，见证主耶稣复活；众人也都蒙大恩。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 2:45; 路加福音 12:33; 路加福音 16:9"> 内中也没有一个缺乏的；因为人人将田产房屋都卖了，把所卖的价银拿来，</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 5:2; 使徒行传 2:45; 哥林多后书 8:20–21"> 放在使徒脚前，照各人所需用的，分给各人。</span>
<span className="v" id="v36" data-v="36" data-xref="加拉太书 2:9; 加拉太书 2:13; 加拉太书 2:1"> 有一个利未人，生在塞浦路斯，名叫约瑟，使徒称他为巴拿巴（巴拿巴翻出来就是劝慰子）。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 5:1–2; 使徒行传 4:34–35; 马太福音 19:29"> 他有田地，也卖了，把价银拿来，放在使徒脚前。</span>
</div>

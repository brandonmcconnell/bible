## 神大怒的碗

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="西番雅书 3:8; 耶利米书 10:25; 启示录 15:1"> 我听见有大声音从殿中出来，向那七位天使说：「你们去，把盛 神大怒的七碗倒在地上。」</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="启示录 8:7; 启示录 16:11; 启示录 13:15–18"> 第一位天使便去，把碗倒在地上，就有恶而且毒的疮生在那些有兽印记、拜兽像的人身上。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="出埃及记 7:17–21; 启示录 8:8–9; 启示录 11:6"> 第二位天使把碗倒在海里，海就变成血，好像死人的血，海中的活物都死了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="出埃及记 7:17–20; 启示录 8:10–11; 何西阿书 13:15"> 第三位天使把碗倒在江河与众水的泉源里，水就变成血了。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 1:8; 启示录 11:17; 启示录 1:4"> 我听见掌管众水的天使说：<br /><span className="pl pl-1">昔在、今在的圣者啊，</span><br /><span className="pl pl-1">你这样判断是公义的；</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 49:26; 启示录 11:18; 启示录 6:10–11"> <span className="pl pl-1">他们曾流圣徒与先知的血，</span><br /><span className="pl pl-1">现在你给他们血喝；</span><br /><span className="pl pl-1">这是他们所该受的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="启示录 19:2; 启示录 6:9; 启示录 15:3–4"> 我又听见祭坛中有声音说：<br /><span className="pl pl-1">是的，主 神—全能者啊，</span><br /><span className="pl pl-1">你的判断义哉！诚哉！</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 2:20; 启示录 14:18; 约拿书 4:8"> 第四位天使把碗倒在日头上，叫日头能用火烤人。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 2:21; 启示录 16:21; 启示录 11:13"> 人被大热所烤，就亵渎那有权掌管这些灾的 神之名，并不悔改将荣耀归给 神。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="启示录 9:2; 马太福音 8:12; 以赛亚书 8:21–22"> 第五位天使把碗倒在兽的座位上，兽的国就黑暗了。人因疼痛就咬自己的舌头；</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 16:9; 启示录 16:2; 启示录 16:21"> 又因所受的疼痛，和生的疮，就亵渎天上的 神，并不悔改所行的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="启示录 9:14; 耶利米书 51:36; 以赛亚书 44:27"> 第六位天使把碗倒在幼发拉底大河上，河水就干了，要给那从日出之地所来的众王预备道路。</span>
<span className="v" id="v13" data-v="13" data-xref="启示录 19:20; 帖撒罗尼迦后书 2:9–11; 启示录 20:10"> 我又看见三个污秽的灵，好像青蛙，从龙口、兽口并假先知的口中出来。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 17:14; 提摩太前书 4:1; 启示录 20:8"> 他们本是鬼魔的灵，施行奇事，出去到普天下众王那里，叫他们在 神全能者的大日聚集争战。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 5:2–3; 马太福音 24:42–43; 彼得后书 3:10"> 看哪，我来像贼一样。那警醒、看守衣服、免得赤身而行、叫人见他羞耻的有福了！</span>
<span className="v" id="v16" data-v="16" data-xref="撒迦利亚书 12:11; 士师记 5:19; 约珥书 3:9–14"> 那三个鬼魔便叫众王聚集在一处，希伯来话叫作哈米吉多顿。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 19:30; 启示录 21:6; 以弗所书 6:12"> 第七位天使把碗倒在空中，就有大声音从殿中的宝座上出来，说：「成了！」</span>
<span className="v" id="v18" data-v="18" data-xref="但以理书 12:1; 启示录 4:5; 启示录 11:19"> 又有闪电、声音、雷轰、大地震，自从地上有人以来，没有这样大、这样厉害的地震。</span>
<span className="v" id="v19" data-v="19" data-xref="启示录 18:5; 启示录 17:18; 启示录 18:21"> 那大城裂为三段，列国的城也都倒塌了； 神也想起巴比伦大城来，要把那盛自己烈怒的酒杯递给他。</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 6:14; 启示录 20:11; 耶利米书 4:23–25"> 各海岛都逃避了，众山也不见了。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 11:19; 约书亚记 10:11; 启示录 16:9"> 又有大雹子从天落在人身上，每一个约重一他连得<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一他连得约有九十斤">a</a></sup>。为这雹子的灾极大，人就亵渎 神。</span>
</div>
</div>

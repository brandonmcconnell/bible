## 新天新地

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 65:17–19; 彼得后书 3:13; 以赛亚书 66:22"> 我又看见一个新天新地；因为先前的天地已经过去了，海也不再有了。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:10; 启示录 3:12; 启示录 21:10"> 我又看见圣城新耶路撒冷由 神那里从天而降，预备好了，就如新妇妆饰整齐，等候丈夫。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 37:27; 哥林多后书 6:16; 约翰福音 14:23"> 我听见有大声音从宝座出来说：「看哪， 神的帐幕在人间。他要与人同住，他们要作他的子民。 神要亲自与他们同在，作他们的 神。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 25:8; 启示录 7:17; 哥林多前书 15:26"> 神要擦去他们一切的眼泪；不再有死亡，也不再有悲哀、哭号、疼痛，因为以前的事都过去了。」</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 5:17; 以赛亚书 42:9; 以赛亚书 43:19"> 坐宝座的说：「看哪，我将一切都更新了！」又说：「你要写上；因这些话是可信的，是真实的。」</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 7:37–38; 约翰福音 4:10; 启示录 7:17"> 他又对我说：「都成了！我是阿拉法，我是俄梅戛；我是初，我是终。我要将生命泉的水白白赐给那口渴的人喝。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 6:18; 希伯来书 8:10; 启示录 2:11"> 得胜的，必承受这些为业：我要作他的 神，他要作我的儿子。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 6:9–10; 启示录 2:11; 以弗所书 5:5–6"> 惟有胆怯的、不信的、可憎的、杀人的、淫乱的、行邪术的、拜偶像的，和一切说谎话的，他们的分就在烧着硫磺的火湖里；这是第二次的死。」</span>
</div>
</div>

## 新耶路撒冷

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="启示录 21:2; 启示录 19:7; 启示录 16:1–17"> 拿着七个金碗、盛满末后七灾的七位天使中，有一位来对我说：「你到这里来，我要将新妇，就是羔羊的妻，指给你看。」</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 21:2; 以西结书 11:24; 以西结书 40:1–49"> 我被圣灵感动，天使就带我到一座高大的山，将那由 神那里、从天而降的圣城耶路撒冷指示我。</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 4:6; 启示录 22:5; 启示录 22:1"> 城中有 神的荣耀；城的光辉如同极贵的宝石，好像碧玉，明如水晶。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 48:31–34; 启示录 7:4–8; 启示录 21:17–21"> 有高大的墙，有十二个门，门上有十二位天使，门上又写着以色列十二个支派的名字。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 48:31–34"> 东边有三门，北边有三门，南边有三门，西边有三门。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 11:10; 以弗所书 2:20; 以赛亚书 54:11"> 城墙有十二根基，根基上有羔羊十二使徒的名字。</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 2:1; 启示录 11:1–2; 以西结书 41:1–5"> 对我说话的，拿着金苇子当尺，要量那城和城门城墙。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结书 48:35; 以西结书 48:8–20"> 城是四方的，长宽一样。天使用苇子量那城，共有四千里，长、宽、高都是一样；</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 7:4; 申命记 3:11; 启示录 13:18"> 又量了城墙，按着人的尺寸，就是天使的尺寸，共有一百四十四肘。</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 21:11; 启示录 21:21; 启示录 21:19"> 墙是碧玉造的；城是精金的，如同明净的玻璃。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 54:11–12; 出埃及记 28:17–21; 约伯记 28:16–19"> 城墙的根基是用各样宝石修饰的：第一根基是碧玉；第二是蓝宝石；第三是绿玛瑙；第四是绿宝石；</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 4:3"> 第五是红玛瑙；第六是红宝石；第七是黄璧玺；第八是水苍玉；第九是红璧玺；第十是翡翠；第十一是紫玛瑙；第十二是紫晶。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 21:18; 启示录 17:4; 启示录 22:2"> 十二个门是十二颗珍珠，每门是一颗珍珠。城内的街道是精金，好像明透的玻璃。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 4:23; 列王纪上 8:27; 历代志下 2:6"> 我未见城内有殿，因主 神—全能者和羔羊为城的殿。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 60:19–20; 启示录 22:5; 启示录 21:11"> 那城内又不用日月光照；因有 神的荣耀光照，又有羔羊为城的灯。</span>
<span className="v" id="v24" data-v="24" data-xref="启示录 21:26; 启示录 22:2; 撒迦利亚书 8:22–23"> 列国要在城的光里行走；地上的君王必将自己的荣耀归与那城。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 60:11; 撒迦利亚书 14:7; 启示录 22:5"> 城门白昼总不关闭，在那里原没有黑夜。</span>
<span className="v" id="v26" data-v="26" data-xref="启示录 21:24"> 人必将列国的荣耀、尊贵归与那城。</span>
<span className="v" id="v27" data-v="27" data-xref="启示录 22:14–15; 以赛亚书 52:1; 启示录 20:15"> 凡不洁净的，并那行可憎与虚谎之事的，总不得进那城；只有名字写在羔羊生命册上的才得进去。</span>
</div>
</div>

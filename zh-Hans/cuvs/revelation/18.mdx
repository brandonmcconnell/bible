## 巴比伦倾倒

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以西结书 43:2; 路加福音 17:24; 帖撒罗尼迦后书 2:8"> 此后，我看见另有一位有大权柄的天使从天降下，地就因他的荣耀发光。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 14:8; 耶利米书 51:8; 耶利米书 51:37"> 他大声喊着说：<br /><span className="pl pl-1">巴比伦大城倾倒了！倾倒了！</span><br /><span className="pl pl-1">成了鬼魔的住处</span><br /><span className="pl pl-1">和各样污秽之灵的巢穴</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：牢狱；下同">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-1">并各样污秽可憎之雀鸟的巢穴。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="启示录 14:8; 启示录 17:2; 启示录 18:9"> <span className="pl pl-1">因为列国都被她邪淫大怒的酒倾倒了。</span><br /><span className="pl pl-1">地上的君王与她行淫；</span><br /><span className="pl pl-1">地上的客商因她奢华太过就发了财。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 52:11; 哥林多后书 6:17; 耶利米书 51:6"> <span className="pl pl-1">我又听见从天上有声音说：</span><br /><span className="pl pl-1">我的民哪，你们要从那城出来，</span><br /><span className="pl pl-1">免得与她一同有罪，受她所受的灾殃；</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="创世记 18:20–21; 以斯拉记 9:6; 启示录 16:19"> <span className="pl pl-1">因她的罪恶滔天；</span><br /><span className="pl pl-1">她的不义， 神已经想起来了。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 50:29; 诗篇 137:8; 耶利米书 51:24"> <span className="pl pl-1">她怎样待人，也要怎样待她，</span><br /><span className="pl pl-1">按她所行的加倍地报应她；</span><br /><span className="pl pl-1">用她调酒的杯加倍地调给她喝。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 47:7–9; 西番雅书 2:15; 耶利米哀歌 1:1"> <span className="pl pl-1">她怎样荣耀自己，怎样奢华，</span><br /><span className="pl pl-1">也当叫她照样痛苦悲哀，</span><br /><span className="pl pl-1">因她心里说：</span><br /><span className="pl pl-1">我坐了皇后的位，</span><br /><span className="pl pl-1">并不是寡妇，</span><br /><span className="pl pl-1">决不至于悲哀。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 50:34; 耶利米书 50:31; 启示录 17:16"> <span className="pl pl-1">所以在一天之内，</span><br /><span className="pl pl-1">她的灾殃要一齐来到，</span><br /><span className="pl pl-1">就是死亡、悲哀、饥荒。</span><br /><span className="pl pl-1">她又要被火烧尽了，</span><br /><span className="pl pl-1">因为审判她的主 神大有能力。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="启示录 19:3; 启示录 18:3; 启示录 17:2"> 地上的君王，素来与她行淫、一同奢华的，看见烧她的烟，就必为她哭泣哀号。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 18:19; 启示录 18:8; 启示录 18:15–17"> 因怕她的痛苦，就远远地站着说：哀哉！哀哉！<br /><span className="pl pl-1">巴比伦大城，坚固的城啊，</span><br /><span className="pl pl-1">一时之间你的刑罚就来到了。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="启示录 18:3; 启示录 18:23; 以西结书 27:27–36"> 地上的客商也都为她哭泣悲哀，因为没有人再买他们的货物了；</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 17:4; 以西结书 27:5–25; 箴言 8:10–11"> 这货物就是金、银、宝石、珍珠、细麻布、紫色料、绸子、朱红色料、各样香木、各样象牙的器皿、各样极宝贵的木头，和铜、铁、汉白玉的器皿，</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 27:13; 阿摩司书 2:6; 彼得后书 2:3"> 并肉桂、豆蔻、香料、香膏、乳香、酒、油、细面、麦子、牛、羊、车、马，和奴仆、人口。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 10:6; 诗篇 106:14; 路加福音 16:25"> <span className="pl pl-1">巴比伦哪，你所贪爱的果子离开了你；</span><br /><span className="pl pl-1">你一切的珍馐美味</span><br /><span className="pl pl-1">和华美的物件也从你中间毁灭，</span><br /><span className="pl pl-1">决不能再见了。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="启示录 18:3; 使徒行传 19:24–27; 以西结书 27:31"> 贩卖这些货物、借着她发了财的客商，因怕她的痛苦，就远远地站着哭泣悲哀，说：</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 17:4; 路加福音 16:19–31; 启示录 18:10–11"> <span className="pl pl-1">哀哉！哀哉！这大城啊，</span><br /><span className="pl pl-1">素常穿着细麻、</span><br /><span className="pl pl-1">紫色、朱红色的衣服，</span><br /><span className="pl pl-1">又用金子、宝石，和珍珠为妆饰。</span><br /></span>
<span className="v" id="v17" data-v="17" data-xref="以西结书 27:27–36; 启示录 17:16; 以赛亚书 23:14"> <span className="pl pl-1">一时之间，这么大的富厚就归于无有了。</span><br />凡船主和坐船往各处去的，并众水手，连所有靠海为业的，都远远地站着，</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 13:4; 以西结书 27:30–32; 启示录 18:9–10"> 看见烧她的烟，就喊着说：「有何城能比这大城呢？」</span>
<span className="v" id="v19" data-v="19" data-xref="启示录 18:10; 约书亚记 7:6; 以西结书 27:30"> 他们又把尘土撒在头上，哭泣悲哀，喊着说：<br /><span className="pl pl-1">哀哉！哀哉！这大城啊。</span><br /><span className="pl pl-1">凡有船在海中的，都因她的珍宝成了富足！</span><br /><span className="pl pl-1">她在一时之间就成了荒场！</span><br /></span>
<span className="v" id="v20" data-v="20" data-xref="启示录 6:10; 启示录 19:1–3; 路加福音 18:7–8"> <span className="pl pl-1">天哪，众圣徒、众使徒、众先知啊，</span><br /><span className="pl pl-1">你们都要因她欢喜，</span><br /><span className="pl pl-1">因为 神已经在她身上伸了你们的冤。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="耶利米书 51:63–64; 以西结书 26:21; 启示录 5:2"> 有一位大力的天使举起一块石头，好像大磨石，扔在海里，说：<br /><span className="pl pl-1">巴比伦大城也必这样猛力地被扔下去，</span><br /><span className="pl pl-1">决不能再见了。</span><br /></span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 26:13; 耶利米书 25:10; 耶利米书 7:34"> <span className="pl pl-1">弹琴、作乐、吹笛、吹号的声音，</span><br /><span className="pl pl-1">在你中间决不能再听见；</span><br /><span className="pl pl-1">各行手艺人在你中间决不能再遇见；</span><br /><span className="pl pl-1">推磨的声音在你中间决不能再听见；</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="启示录 18:3; 以赛亚书 23:8; 那鸿书 3:4"> <span className="pl pl-1">灯光在你中间决不能再照耀；</span><br /><span className="pl pl-1">新郎和新妇的声音，在你中间决不能再听见。</span><br /><span className="pl pl-1">你的客商原来是地上的尊贵人；</span><br /><span className="pl pl-1">万国也被你的邪术迷惑了。</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="启示录 17:6; 启示录 16:6; 耶利米书 51:49"> 先知和圣徒，并地上一切被杀之人的血，都在这城里看见了。</span>
</div>

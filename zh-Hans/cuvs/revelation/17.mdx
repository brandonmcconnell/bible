## 大淫妇和兽

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 19:2; 启示录 17:1–17; 耶利米书 51:13"> 拿着七碗的七位天使中，有一位前来对我说：「你到这里来，我将坐在众水上的大淫妇所要受的刑罚指给你看。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 14:8; 耶利米书 51:7; 启示录 18:3"> 地上的君王与她行淫，住在地上的人喝醉了她淫乱的酒。」</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 12:3; 启示录 13:1–6; 启示录 12:6"> 我被圣灵感动，天使带我到旷野去，我就看见一个女人骑在朱红色的兽上；那兽有七头十角，遍体有亵渎的名号。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 18:16; 耶利米书 51:7; 启示录 19:2"> 那女人穿着紫色和朱红色的衣服，用金子、宝石、珍珠为妆饰；手拿金杯，杯中盛满了可憎之物，就是她淫乱的污秽。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 14:8; 启示录 18:2; 启示录 17:7"> 在她额上有名写着说：「奥秘哉！大巴比伦，作世上的淫妇和一切可憎之物的母。」</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 16:6; 启示录 13:15; 启示录 2:13"> 我又看见那女人喝醉了圣徒的血和为耶稣作见证之人的血。<br />我看见她，就大大地希奇。</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 17:1–6; 启示录 17:8"> 天使对我说：「你为什么希奇呢？我要将这女人和驮着她的那七头十角兽的奥秘告诉你。</span>
<span className="v" id="v8" data-v="8" data-xref="启示录 17:11; 启示录 11:7; 启示录 3:10"> 你所看见的兽，先前有，如今没有，将要从无底坑里上来，又要归于沉沦。凡住在地上、名字从创世以来没有记在生命册上的，见先前有、如今没有、以后再有的兽，就必希奇。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 13:18; 启示录 17:7; 马太福音 13:11"> 智慧的心在此可以思想。那七头就是女人所坐的七座山，</span>
<span className="v" id="v10" data-v="10"> 又是七位王；五位已经倾倒了，一位还在，一位还没有来到；他来的时候，必须暂时存留。</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 17:8"> 那先前有如今没有的兽，就是第八位；他也和那七位同列，并且归于沉沦。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 12:3; 启示录 13:1; 但以理书 7:24"> 你所看见的那十角就是十王；他们还没有得国，但他们一时之间要和兽同得权柄，与王一样。</span>
<span className="v" id="v13" data-v="13" data-xref="启示录 17:17; 以西结书 38:10; 以赛亚书 10:5–7"> 他们同心合意将自己的能力、权柄给那兽。</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 8:30; 提摩太前书 6:15; 马太福音 22:14"> 他们与羔羊争战，羔羊必胜过他们，因为羔羊是万主之主、万王之王。同着羔羊的，就是蒙召、被选、有忠心的，也必得胜。」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="启示录 17:1; 耶利米书 51:13; 耶利米书 51:55"> 天使又对我说：「你所看见那淫妇坐的众水，就是多民、多人、多国、多方。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 18:8; 以西结书 16:37–44; 利未记 21:9"> 你所看见的那十角与兽必恨这淫妇，使她冷落赤身，又要吃她的肉，用火将她烧尽。</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦后书 2:10–12; 箴言 21:1; 启示录 10:7"> 因为 神使诸王同心合意，遵行他的旨意，把自己的国给那兽，直等到 神的话都应验了。</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 16:19; 启示录 18:2; 但以理书 7:23"> 你所看见的那女人就是管辖地上众王的大城。」</span>
</div>
</div>

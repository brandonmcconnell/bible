## 两个兽

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="启示录 12:3; 启示录 17:3; 但以理书 7:23–25"> 我又看见一个兽从海中上来，有十角七头，在十角上戴着十个冠冕，七头上有亵渎的名号。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理书 7:4–7; 彼得前书 5:8; 启示录 17:12"> 我所看见的兽，形状像豹，脚像熊的脚，口像狮子的口。那龙将自己的能力、座位，和大权柄都给了它。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 17:8; 启示录 13:14; 启示录 17:17"> 我看见兽的七头中，有一个似乎受了死伤，那死伤却医好了。全地的人都希奇跟从那兽，</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 13:2; 启示录 18:18; 启示录 13:15"> 又拜那龙—因为它将自己的权柄给了兽，也拜兽，说：「谁能比这兽，谁能与它交战呢？」</span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 7:8; 但以理书 7:25; 但以理书 11:36"> 又赐给它说夸大亵渎话的口，又有权柄赐给它，可以任意而行四十二个月。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 12:34; 希伯来书 9:24; 启示录 12:12"> 兽就开口向 神说亵渎的话，亵渎 神的名并他的帐幕，以及那些住在天上的。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 7:21; 启示录 11:7; 但以理书 7:25"> 又任凭它与圣徒争战，并且得胜；也把权柄赐给它，制伏各族、各民、各方、各国。</span>
<span className="v" id="v8" data-v="8" data-xref="彼得前书 1:19–20; 以弗所书 1:4; 马太福音 25:34"> 凡住在地上、名字从创世以来没有记在被杀之羔羊生命册上的人，都要拜它。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 2:7; 启示录 2:17; 启示录 2:11"> <span className="pl pl-1">凡有耳的，就应当听！</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 15:2; 以赛亚书 33:1; 启示录 14:12"> <span className="pl pl-1">掳掠人的，必被掳掠；</span><br /><span className="pl pl-1">用刀杀人的，必被刀杀。</span><br /><span className="pl pl-1">圣徒的忍耐和信心就是在此。</span></span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 7:8; 哥林多后书 11:13–15; 马太福音 7:15"> 我又看见另有一个兽从地中上来，有两角如同羊羔，说话好像龙。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 17:10–11; 启示录 14:11; 启示录 14:9"> 它在头一个兽面前，施行头一个兽所有的权柄，并且叫地和住在地上的人拜那死伤医好的头一个兽。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 24:24; 启示录 19:20; 帖撒罗尼迦后书 2:9–10"> 又行大奇事，甚至在人面前，叫火从天降在地上。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 12:9; 启示录 19:20; 启示录 13:8"> 它因赐给它权柄在兽面前能行奇事，就迷惑住在地上的人，说：「要给那受刀伤还活着的兽作个像。」</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 20:4; 启示录 19:20; 但以理书 3:3–6"> 又有权柄赐给它，叫兽像有生气，并且能说话，又叫所有不拜兽像的人都被杀害。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 20:4; 启示录 19:20; 以西结书 9:4"> 它又叫众人，无论大小、贫富、自主的、为奴的，都在右手上或是在额上受一个印记。</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 15:2; 启示录 13:16; 启示录 14:11"> 除了那受印记、有了兽名或有兽名数目的，都不得做买卖。</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 15:2; 启示录 17:9; 启示录 21:17"> 在这里有智慧：凡有聪明的，可以算计兽的数目；因为这是人的数目，它的数目是六百六十六。</span>

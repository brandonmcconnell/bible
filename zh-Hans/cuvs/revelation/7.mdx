## 以色列人十四万四千被印

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 24:31; 但以理书 7:2; 耶利米书 49:36"> 此后，我看见四位天使站在地的四角，执掌地上四方的风，叫风不吹在地上、海上，和树上。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 4:30; 哥林多后书 1:22; 启示录 7:3–8"> 我又看见另有一位天使，从日出之地上来，拿着永生 神的印。他就向那得着权柄能伤害地和海的四位天使大声喊着说：</span>
<span className="v" id="v3" data-v="3" data-xref="以西结书 9:4; 启示录 22:4; 启示录 9:4"> 「地与海并树木，你们不可伤害，等我们印了我们 神众仆人的额。」</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 14:1; 启示录 14:3; 马太福音 19:28"> 我听见以色列人各支派中受印的数目有十四万四千。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 1:2–4; 民数记 10:14–27; 民数记 13:4–16"> 犹大支派中受印的有一万二千；吕便支派中有一万二千；迦得支派中有一万二千；</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 2:36"> 亚设支派中有一万二千；拿弗他利支派中有一万二千；玛拿西支派中有一万二千；</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 35:23; 民数记 26:14; 民数记 25:14"> 西缅支派中有一万二千；利未支派中有一万二千；以萨迦支派中有一万二千；</span>
<span className="v" id="v8" data-v="8"> 西布伦支派中有一万二千；约瑟支派中有一万二千；便雅悯支派中受印的有一万二千。</span>

## 无数的人从各国各族而来

<div className="bt">
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="启示录 5:9; 约翰福音 12:13; 诗篇 117:1–2"> 此后，我观看，见有许多的人，没有人能数过来，是从各国、各族、各民、各方来的，站在宝座和羔羊面前，身穿白衣，手拿棕树枝，</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 19:1; 诗篇 3:8; 以赛亚书 45:21"> 大声喊着说：「愿救恩归与坐在宝座上我们的 神，也归与羔羊！」</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 5:11–13; 启示录 19:4–6; 启示录 4:10"> 众天使都站在宝座和众长老并四活物的周围，在宝座前，面伏于地，敬拜 神，</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 5:12–14; 犹大书 1:25; 诗篇 100:4"> 说：<br /><span className="pl pl-1">阿们！颂赞、荣耀、智慧、</span><br /><span className="pl pl-1">感谢、尊贵、权柄、大力</span><br /><span className="pl pl-1">都归与我们的 神，</span><br /><span className="pl pl-1">直到永永远远。阿们！</span></span>
<span className="v" id="v13" data-v="13" data-xref="启示录 7:9; 启示录 4:10; 启示录 5:5"> 长老中有一位问我说：「这些穿白衣的是谁？是从哪里来的？」</span>
<span className="v" id="v14" data-v="14" data-xref="约翰一书 1:7; 启示录 22:14; 希伯来书 13:12"> 我对他说：「我主，你知道。」他向我说：「这些人是从大患难中出来的，曾用羔羊的血把衣裳洗白净了。</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 21:3–4; 启示录 22:3; 哥林多后书 6:16"> 所以，他们在 神宝座前，昼夜在他殿中事奉他。坐宝座的要用帐幕覆庇他们。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 49:10; 诗篇 121:6; 马太福音 5:6"> 他们不再饥，不再渴；日头和炎热也必不伤害他们。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 7:37–38; 诗篇 36:8–9; 约翰福音 4:14"> 因为宝座中的羔羊必牧养他们，领他们到生命水的泉源； 神也必擦去他们一切的眼泪。」</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 8:10; 罗马书 10:7; 启示录 9:2"> 第五位天使吹号，我就看见一个星从天落到地上，有无底坑的钥匙赐给它。</span>
<span className="v" id="v2" data-v="2" data-xref="约珥书 2:10; 创世记 19:28; 约珥书 2:2"> 它开了无底坑，便有烟从坑里往上冒，好像大火炉的烟；日头和天空都因这烟昏暗了。</span>
<span className="v" id="v3" data-v="3" data-xref="约珥书 1:4; 启示录 9:5; 约珥书 2:25"> 有蝗虫从烟中出来，飞到地上；有能力赐给它们，好像地上蝎子的能力一样，</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 7:2–4; 以西结书 9:4; 启示录 14:1"> 并且吩咐它们说，不可伤害地上的草和各样青物，并一切树木，惟独要伤害额上没有 神印记的人。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 9:10; 约伯记 2:6; 启示录 9:3"> 但不许蝗虫害死他们，只叫他们受痛苦五个月。这痛苦就像蝎子螫人的痛苦一样。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 23:30; 耶利米书 8:3; 启示录 6:16"> 在那些日子，人要求死，决不得死；愿意死，死却远避他们。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="但以理书 7:8; 那鸿书 3:17; 约珥书 2:4–5"> 蝗虫的形状，好像预备出战的马一样，头上戴的好像金冠冕，脸面好像男人的脸面，</span>
<span className="v" id="v8" data-v="8" data-xref="约珥书 1:6; 哥林多前书 11:14–15; 彼得前书 3:3"> 头发像女人的头发，牙齿像狮子的牙齿。</span>
<span className="v" id="v9" data-v="9" data-xref="约珥书 2:5–8; 那鸿书 2:4–5; 约伯记 39:25"> 胸前有甲，好像铁甲。它们翅膀的声音，好像许多车马奔跑上阵的声音。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 9:5; 启示录 9:3; 启示录 9:19"> 有尾巴像蝎子，尾巴上的毒钩能伤人五个月。</span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 26:6; 启示录 9:1–2; 以弗所书 2:2"> 有无底坑的使者作它们的王，按着希伯来话，名叫亚巴顿，希腊话，名叫亚玻伦。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="启示录 11:14; 启示录 8:13–2; 启示录 9:13–21"> 第一样灾祸过去了，还有两样灾祸要来。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="启示录 8:3–5; 出埃及记 30:2–3; 启示录 9:1"> 第六位天使吹号，我就听见有声音从 神面前金坛的四角出来，</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 16:12; 启示录 9:15; 撒母耳记下 8:3"> 吩咐那吹号的第六位天使，说：「把那捆绑在幼发拉底大河的四个使者释放了。」</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 9:18; 启示录 8:7; 启示录 8:9"> 那四个使者就被释放；他们原是预备好了，到某年某月某日某时，要杀人的三分之一。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 7:4; 诗篇 68:17; 但以理书 7:10"> 马军有二万万；他们的数目我听见了。</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 9:18; 启示录 14:10; 历代志上 12:8"> 我在异象中看见那些马和骑马的，骑马的胸前有甲如火，与紫玛瑙并硫磺。马的头好像狮子头，有火、有烟、有硫磺从马的口中出来。</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 9:17; 启示录 9:15"> 口中所出来的火与烟并硫磺，这三样灾杀了人的三分之一。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 9:15; 启示录 9:10; 以弗所书 4:14"> 这马的能力是在口里和尾巴上；因这尾巴像蛇，并且有头用以害人。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="但以理书 5:23; 申命记 31:29; 提摩太前书 4:1"> 其余未曾被这些灾所杀的人仍旧不悔改自己手所做的，还是去拜鬼魔和那些不能看、不能听、不能走，金、银、铜、木、石的偶像，</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 21:8; 哥林多后书 12:21; 启示录 17:5"> 又不悔改他们那些凶杀、邪术、奸淫、偷窃的事。</span>
</div>

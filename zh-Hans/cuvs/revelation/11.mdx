## 两个见证人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 21:15; 以西结书 42:15–20; 撒迦利亚书 2:1–2"> 有一根苇子赐给我，当作量度的杖；且有话说：「起来！将 神的殿和祭坛，并在殿中礼拜的人都量一量。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 12:6; 但以理书 7:25; 路加福音 21:24"> 只是殿外的院子要留下不用量，因为这是给了外邦人的；他们要践踏圣城四十二个月。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 12:6; 启示录 11:2; 申命记 19:15"> 我要使我那两个见证人，穿着毛衣，传道一千二百六十天。」</span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 4:11–14; 撒迦利亚书 4:2–3; 耶利米书 11:16"> 他们就是那两棵橄榄树，两个灯台，立在世界之主面前的。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 5:14; 列王纪下 1:10–12; 何西阿书 6:5"> 若有人想要害他们，就有火从他们口中出来，烧灭仇敌。凡想要害他们的都必这样被杀。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 17:1; 路加福音 4:25; 诗篇 105:26–36"> 这二人有权柄，在他们传道的日子叫天闭塞不下雨；又有权柄叫水变为血，并且能随时随意用各样的灾殃攻击世界。</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 13:7; 但以理书 8:23–24; 但以理书 7:25"> 他们作完见证的时候，那从无底坑里上来的兽必与他们交战，并且得胜，把他们杀了。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 23:14; 启示录 18:10; 启示录 18:21"> 他们的尸首就倒在大城里的街上；这城按着灵意叫所多玛，又叫埃及，就是他们的主钉十字架之处。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 79:2–3; 启示录 17:15; 启示录 10:11"> 从各民、各族、各方、各国中，有人观看他们的尸首三天半，又不许把尸首放在坟墓里。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 18:17; 启示录 3:10; 使徒行传 5:33"> 住在地上的人就为他们欢喜快乐，互相馈送礼物，因这两位先知曾叫住在地上的人受痛苦。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 2:7; 罗马书 8:11; 罗马书 8:2"> 过了这三天半，有生气从 神那里进入他们里面，他们就站起来；看见他们的人甚是害怕。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 4:1; 列王纪下 2:11; 使徒行传 1:9"> 两位先知听见有大声音从天上来，对他们说：「上到这里来。」他们就驾着云上了天，他们的仇敌也看见了。</span>
<span className="v" id="v13" data-v="13" data-xref="启示录 14:7; 启示录 6:12; 约书亚记 7:19"> 正在那时候，地大震动，城就倒塌了十分之一，因地震而死的有七千人；其余的都恐惧，归荣耀给天上的 神。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="启示录 8:13; 启示录 9:12; 启示录 15:1"> 第二样灾祸过去，第三样灾祸快到了。</span>
</div>
</div>

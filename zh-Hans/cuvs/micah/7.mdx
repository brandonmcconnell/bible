<div className="bp poetry">

<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="约翰福音 8:12; 以赛亚书 9:2; 诗篇 27:1"> <span className="pl pl-1">我的仇敌啊，不要向我夸耀。</span><br /><span className="pl pl-1">我虽跌倒，却要起来；</span><br /><span className="pl pl-1">我虽坐在黑暗里，</span><br /><span className="pl pl-1">耶和华却作我的光。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 37:6; 哥林多前书 4:5; 撒母耳记上 24:15"> <span className="pl pl-1">我要忍受耶和华的恼怒；</span><br /><span className="pl pl-1">因我得罪了他，</span><br /><span className="pl pl-1">直等他为我辨屈，为我伸冤。</span><br /><span className="pl pl-1">他必领我到光明中；</span><br /><span className="pl pl-1">我必得见他的公义。</span><br /></span>

</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="阿摩司书 9:11–15; 尼希米记 2:8; 尼希米记 2:17"> <span className="pl pl-1">以色列啊，日子必到，</span><br /><span className="pl pl-1">你的墙垣必重修；</span><br /><span className="pl pl-1">到那日，你的境界必开展</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：命令必传到远方">b</a></sup><br /><span className="pl pl-1">。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 19:23–25; 以赛亚书 11:16; 何西阿书 11:11"> <span className="pl pl-1">当那日，人必从亚述，</span><br /><span className="pl pl-1">从埃及的城邑，</span><br /><span className="pl pl-1">从埃及到大河，</span><br /><span className="pl pl-1">从这海到那海，</span><br /><span className="pl pl-1">从这山到那山，</span><br /><span className="pl pl-1">都归到你这里。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 3:10–11; 耶利米书 25:11; 弥迦书 6:13"> <span className="pl pl-1">然而，这地因居民的缘故，</span><br /><span className="pl pl-1">又因他们行事的结果，必然荒凉。</span></span>

## 耶和华怜悯以色列

<div className="bt">
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="诗篇 23:1–4; 弥迦书 5:4; 诗篇 100:3"> <span className="pl pl-1">求耶和华在迦密山的树林中，</span><br /><span className="pl pl-1">用你的杖牧放你独居的民，</span><br /><span className="pl pl-1">就是你产业的羊群。</span><br /><span className="pl pl-1">求你容他们在巴珊和基列得食物，像古时一样。</span></span>
</div>

<span className="v" id="v15" data-v="15" data-xref="诗篇 78:12–72; 出埃及记 3:20; 诗篇 68:22"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">我要把奇事显给他们看，</span><br /><span className="pl pl-1">好像出埃及地的时候一样。</span><br /></span>

## 耶和华作王，天下太平

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 2:1–4; 耶利米书 3:17; 使徒行传 2:17"> <span className="pl pl-1">末后的日子，</span><br /><span className="pl pl-1">耶和华殿的山必坚立，</span><br /><span className="pl pl-1">超乎诸山，高举过于万岭；</span><br /><span className="pl pl-1">万民都要流归这山。</span><br /></span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 2:3; 耶利米书 31:6; 使徒行传 1:8"> <span className="pl pl-1">必有许多国的民前往，说：</span><br /><span className="pl pl-1">来吧，我们登耶和华的山，</span><br /><span className="pl pl-1">奔雅各 神的殿。</span><br /><span className="pl pl-1">主必将他的道教训我们；</span><br /><span className="pl pl-1">我们也要行他的路。</span><br /><span className="pl pl-1">因为训诲必出于锡安；</span><br /><span className="pl pl-1">耶和华的言语必出于耶路撒冷。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 2:4; 约珥书 3:9–16; 马太福音 25:31–32"> <span className="pl pl-1">他必在多国的民中施行审判，</span><br /><span className="pl pl-1">为远方强盛的国断定是非。</span><br /><span className="pl pl-1">他们要将刀打成犁头，</span><br /><span className="pl pl-1">把枪打成镰刀。</span><br /><span className="pl pl-1">这国不举刀攻击那国；</span><br /><span className="pl pl-1">他们也不再学习战事。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 3:10; 列王纪上 4:25; 以西结书 39:26"> <span className="pl pl-1">人人都要坐在自己葡萄树下</span><br /><span className="pl pl-1">和无花果树下，无人惊吓。</span><br /><span className="pl pl-1">这是万军之耶和华亲口说的。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="撒迦利亚书 10:12; 约书亚记 24:15; 歌罗西书 3:17"> <span className="pl pl-1">万民各奉己神的名而行；</span><br /><span className="pl pl-1">我们却永永远远奉耶和华—我们 神的名而行。</span></span>
</div>
</div>

<div className="bt">
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="西番雅书 3:19; 以西结书 34:12–17; 以赛亚书 35:3–6"> <span className="pl pl-1">耶和华说：到那日，</span><br /><span className="pl pl-1">我必聚集瘸腿的，</span><br /><span className="pl pl-1">招聚被赶出的和我所惩治的。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 7:14; 以赛亚书 24:23; 弥迦书 2:12"> <span className="pl pl-1">我必使瘸腿的为余剩之民，</span><br /><span className="pl pl-1">使赶到远方的为强盛之民。</span><br /><span className="pl pl-1">耶和华要在锡安山作王治理他们，</span><br /><span className="pl pl-1">从今直到永远。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 1:26; 启示录 22:5; 撒迦利亚书 9:10"> <span className="pl pl-1">你这羊群的高台、锡安城</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是女子">a</a></sup><br /><span className="pl pl-1">的山哪，</span><br /><span className="pl pl-1">从前的权柄—</span><br /><span className="pl pl-1">就是耶路撒冷民</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是女子">b</a></sup><br /><span className="pl pl-1">的国权—</span><br /><span className="pl pl-1">必归与你。</span><br /></span>

<span className="v" id="v10" data-v="10" data-xref="以赛亚书 48:20; 以赛亚书 52:9–12; 列王纪下 20:18"> <span className="pl pl-1">锡安的民</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是女子">c</a></sup><br /><span className="pl pl-1">哪，</span><br /><span className="pl pl-1">你要疼痛劬劳，仿佛产难的妇人；</span><br /><span className="pl pl-1">因为你必从城里出来，</span><br /><span className="pl pl-1">住在田野，到巴比伦去。</span><br /><span className="pl pl-1">在那里要蒙解救；</span><br /><span className="pl pl-1">在那里耶和华必救赎你脱离仇敌的手。</span><br /></span>

<span className="v" id="v1" data-v="1" data-xref="希伯来书 8:3; 希伯来书 10:11; 希伯来书 7:27"> 凡从人间挑选的大祭司，是奉派替人办理属 神的事，为要献上礼物和赎罪祭<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：要为罪献上礼物和祭物">a</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 4:15; 希伯来书 2:18; 哥林多后书 12:9–10"> 他能体谅那愚蒙的和失迷的人，因为他自己也是被软弱所困。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 9:7; 希伯来书 9:7; 利未记 16:6"> 故此，他理当为百姓和自己献祭赎罪。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 28:1; 民数记 16:40; 民数记 16:5"> 这大祭司的尊荣，没有人自取。惟要蒙 神所召，像亚伦一样。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="诗篇 2:7; 约翰福音 8:54; 使徒行传 13:33"> 如此，基督也不是自取荣耀作大祭司，乃是在乎向他说「你是我的儿子，我今日生你」的那一位；</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 110:4; 希伯来书 7:17; 希伯来书 7:21"> 就如经上又有一处说：「你是照着麦基洗德的等次永远为祭司。」</span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 14:32–39; 路加福音 22:41–44; 约翰福音 17:1"> 基督在肉体的时候，既大声哀哭，流泪祷告，恳求那能救他免死的主，就因他的虔诚蒙了应允。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比书 2:8; 希伯来书 10:5–9; 约翰福音 4:34"> 他虽然为儿子，还是因所受的苦难学了顺从。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 2:10; 希伯来书 9:12; 希伯来书 9:15"> 他既得以完全，就为凡顺从他的人成了永远得救的根源，</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 5:5–6; 希伯来书 6:20"> 并蒙 神照着麦基洗德的等次称他为大祭司。</span>
</div>

## 警戒叛道的人

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马太福音 13:15; 使徒行传 28:27; 彼得后书 3:16"> 论到麦基洗德，我们有好些话，并且难以解明，因为你们听不进去。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 6:1; 哥林多前书 3:1–3; 彼得前书 2:2"> 看你们学习的工夫，本该作师傅，谁知还得有人将 神圣言小学的开端另教导你们，并且成了那必须吃奶、不能吃干粮的人。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 14:20; 彼得前书 2:2; 提摩太后书 3:16"> 凡只能吃奶的都不熟练仁义的道理，因为他是婴孩；</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 2:14–15; 帖撒罗尼迦前书 5:21; 以弗所书 1:18"> 惟独长大成人的才能吃干粮；他们的心窍习练得通达，就能分辨好歹了。</span>
</div>

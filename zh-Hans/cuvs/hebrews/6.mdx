<span className="v" id="v1" data-v="1" data-xref="希伯来书 5:12–14; 哥林多后书 7:1; 希伯来书 9:14"> 所以，我们应当离开基督道理的开端，竭力进到完全的地步，不必再立根基，就如那懊悔死行、信靠 神、</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 15:13–57; 使徒行传 17:31–32; 罗马书 6:3–5"> 各样洗礼、按手之礼、死人复活，以及永远审判各等教训。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 18:21; 哥林多前书 16:7; 哥林多前书 4:19"> 神若许我们，我们必如此行。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 10:26–29; 彼得后书 2:20–22; 马太福音 5:13"> 论到那些已经蒙了光照、尝过天恩的滋味、又于圣灵有分，</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前书 2:3; 路加福音 8:13; 马太福音 13:20–21"> 并尝过 神善道的滋味、觉悟来世权能的人，</span>
<span className="v" id="v6" data-v="6" data-xref="彼得后书 2:21; 希伯来书 10:29; 希伯来书 6:4"> 若是离弃道理，就不能叫他们从新懊悔了。因为他们把 神的儿子重钉十字架，明明地羞辱他。</span>
<span className="v" id="v7" data-v="7" data-xref="何西阿书 10:12; 以赛亚书 44:3; 诗篇 65:9–13"> 就如一块田地，吃过屡次下的雨水，生长菜蔬，合乎耕种的人用，就从 神得福；</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 3:17–18; 约翰福音 15:6; 路加福音 13:7–9"> 若长荆棘和蒺藜，必被废弃，近于咒诅，结局就是焚烧。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 10:39; 哥林多后书 7:10; 希伯来书 6:4–6"> 亲爱的弟兄们，我们虽是这样说，却深信你们的行为强过这些，而且近乎得救。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 10:42; 希伯来书 13:16; 加拉太书 6:10"> 因为 神并非不公义，竟忘记你们所做的工和你们为他名所显的爱心，就是先前伺候圣徒，如今还是伺候。</span>
<span className="v" id="v11" data-v="11" data-xref="彼得后书 1:5–8; 希伯来书 3:6; 罗马书 5:2–5"> 我们愿你们各人都显出这样的殷勤，使你们有满足的指望，一直到底。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 13:7; 希伯来书 10:36; 约翰一书 2:25"> 并且不懈怠，总要效法那些凭信心和忍耐承受应许的人。</span>

## 神确切的应许

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 22:15–18; 路加福音 1:73; 耶利米书 22:5"> 当初 神应许亚伯拉罕的时候，因为没有比自己更大可以指着起誓的，就指着自己起誓，说：</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 22:17; 申命记 1:10; 尼希米记 9:23"> 「论福，我必赐大福给你；论子孙，我必叫你的子孙多起来。」</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 12:2–3; 罗马书 4:17–25; 出埃及记 1:7"> 这样，亚伯拉罕既恒久忍耐，就得了所应许的。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 22:11; 希伯来书 6:13; 创世记 31:53"> 人都是指着比自己大的起誓，并且以起誓为实据，了结各样的争论。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 6:18; 箴言 19:21; 以赛亚书 55:11"> 照样， 神愿意为那承受应许的人格外显明他的旨意是不更改的，就起誓为证。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 23:19; 提多书 1:2; 撒母耳记上 15:29"> 借这两件不更改的事， 神决不能说谎，好叫我们这逃往避难所、持定摆在我们前头指望的人可以大得勉励。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 43:5; 罗马书 5:5–10; 希伯来书 9:7"> 我们有这指望，如同灵魂的锚，又坚固又牢靠，且通入幔内。</span>
<span className="v" id="v20" data-v="20" data-xref="希伯来书 4:14; 希伯来书 3:1; 希伯来书 5:6"> 作先锋的耶稣，既照着麦基洗德的等次成了永远的大祭司，就为我们进入幔内。</span>
</div>
</div>

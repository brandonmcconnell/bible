## 麦基洗德的祭司等次

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 14:18–20; 诗篇 57:2; 希伯来书 6:20"> 这麦基洗德就是撒冷王，又是至高 神的祭司，本是长远为祭司的。他当亚伯拉罕杀败诸王回来的时候，就迎接他，给他祝福。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 18:21; 诗篇 85:10–11; 撒母耳记上 8:17"> 亚伯拉罕也将自己所得来的，取十分之一给他。他头一个名翻出来就是仁义王，他又名撒冷王，就是平安王的意思。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 7:17; 希伯来书 7:23–28; 出埃及记 6:20–27"> 他无父，无母，无族谱，无生之始，无命之终，乃是与 神的儿子相似。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 14:20; 使徒行传 2:29; 使徒行传 7:8–9"> 你们想一想，先祖亚伯拉罕将自己所掳来上等之物取十分之一给他，这人是何等尊贵呢！</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 27:30–33; 历代志下 31:4–6; 民数记 18:21–32"> 那得祭司职任的利未子孙，领命照例向百姓取十分之一，这百姓是自己的弟兄，虽是从亚伯拉罕身<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是腰">a</a></sup>中生的，还是照例取十分之一。</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 4:13; 希伯来书 7:3–4; 创世记 13:14–17"> 独有麦基洗德，不与他们同谱，倒收纳亚伯拉罕的十分之一，为那蒙应许的亚伯拉罕祝福。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 30:27; 创世记 48:15–20; 提摩太前书 3:16"> 从来位分大的给位分小的祝福，这是驳不倒的理。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 6:20; 希伯来书 5:6; 启示录 1:18"> 在这里收十分之一的都是必死的人；但在那里收十分之一的，有为他作见证的说，他是活的；</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 5:12; 创世记 14:20; 希伯来书 7:4"> 并且可说那受十分之一的利未，也是借着亚伯拉罕纳了十分之一。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 35:11; 希伯来书 7:5; 创世记 46:26"> 因为麦基洗德迎接亚伯拉罕的时候，利未已经在他先祖的身<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是腰">b</a></sup>中。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 8:7; 加拉太书 2:21; 加拉太书 4:9"> 从前百姓在利未人祭司职任以下受律法，倘若借这职任能得完全，又何用另外兴起一位祭司，照麦基洗德的等次，不照亚伦的等次呢？</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 31:31–34; 以赛亚书 66:21; 以西结书 16:61"> 祭司的职任既已更改，律法也必须更改。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 7:11; 希伯来书 7:14; 民数记 17:5"> 因为这话所指的人本属别的支派，那支派里从来没有一人伺候祭坛。</span>
<span className="v" id="v14" data-v="14" data-xref="弥迦书 5:2; 以赛亚书 11:1; 路加福音 3:33"> 我们的主分明是从犹大出来的；但这支派，摩西并没有提到祭司。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 110:4; 希伯来书 7:17–21; 希伯来书 7:3"> 倘若照麦基洗德的样式，另外兴起一位祭司来，我的话更是显而易见的了。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 1:18; 歌罗西书 2:20; 希伯来书 7:28"> 他成为祭司，并不是照属肉体的条例，乃是照无穷<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是不能毁坏">c</a></sup>之生命的大能。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 110:4; 希伯来书 5:6; 希伯来书 7:21"> 因为有给他作见证的说：「你是照着麦基洗德的等次永远为祭司。」</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 8:3; 使徒行传 13:39; 加拉太书 4:9"> 先前的条例，因软弱无益，所以废掉了，</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 13:39; 希伯来书 4:16; 希伯来书 9:9"> （律法原来一无所成）就引进了更美的指望；靠这指望，我们便可以进到 神面前。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 18:7; 希伯来书 5:6; 诗篇 110:4"> 再者，耶稣为祭司，并不是不起誓立的。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 110:4; 希伯来书 7:17; 希伯来书 6:16–18"> 至于那些祭司，原不是起誓立的，只有耶稣是起誓立的；因为那立他的对他说：「主起了誓，决不后悔，你是永远为祭司。」</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 11:25; 创世记 44:32; 希伯来书 8:6–12"> 既是起誓立的，耶稣就作了更美之约的中保。</span>
<span className="v" id="v23" data-v="23" data-xref="尼希米记 12:10–11; 历代志上 6:3–14; 希伯来书 7:8"> 那些成为祭司的，数目本来多，是因为有死阻隔，不能长久。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 12:34; 希伯来书 7:28; 以赛亚书 9:6–7"> 这位既是永远常存的，他祭司的职任就长久不更换。</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 8:34; 约翰一书 2:1–2; 提摩太前书 2:5"> 凡靠着他进到 神面前的人，他都能拯救到底；因为他是长远活着，替他们祈求。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多后书 5:21; 希伯来书 4:14–15; 彼得前书 2:22"> 像这样圣洁、无邪恶、无玷污、远离罪人、高过诸天的大祭司，原是与我们合宜的。</span>
<span className="v" id="v27" data-v="27" data-xref="希伯来书 9:28; 希伯来书 9:12; 希伯来书 9:14"> 他不像那些大祭司，每日必须先为自己的罪，后为百姓的罪献祭；因为他只一次将自己献上，就把这事成全了。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 2:10; 希伯来书 7:21; 希伯来书 1:2"> 律法本是立软弱的人为大祭司；但在律法以后起誓的话，是立儿子为大祭司，乃是成全到永远的。</span>

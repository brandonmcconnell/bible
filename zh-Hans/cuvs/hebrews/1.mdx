## 神借着他儿子说话

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得后书 1:20–21; 约珥书 2:28; 民数记 12:6–8"> 神既在古时借着众先知多次多方地晓谕列祖，</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 1:3; 哥林多前书 8:6; 歌罗西书 1:16–18"> 就在这末世借着他儿子晓谕我们；又早已立他为承受万有的，也曾借着他创造诸世界。</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 1:15–17; 启示录 4:11; 约翰福音 14:9–10"> 他是 神荣耀所发的光辉，是 神本体的真像，常用他权能的命令托住万有。他洗净了人的罪，就坐在高天至大者的右边。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 1:21; 腓立比书 2:9–11; 彼得前书 3:22"> 他所承受的名，既比天使的名更尊贵，就远超过天使。</span>
</div>
</div>

## 儿子远超过天使

<div className="bt">
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="诗篇 2:7; 使徒行传 13:33; 希伯来书 5:5"> 所有的天使， 神从来对哪一个说：<br /><span className="pl pl-1">你是我的儿子，</span><br /><span className="pl pl-1">我今日生你？</span>又指着哪一个说：<br /><span className="pl pl-1">我要作他的父，</span><br /><span className="pl pl-1">他要作我的子？</span></span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 97:7; 歌罗西书 1:18; 申命记 32:43"> 再者， 神使长子到世上来的时候<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译： 神再使长子到世上来的时候">a</a></sup>，就说：<br /><span className="pl pl-1">神的使者都要拜他。</span></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 104:4; 希伯来书 1:14; 列王纪下 6:17"> 论到使者，又说：<br /><span className="pl pl-1">神以风为使者，</span><br /><span className="pl pl-1">以火焰为仆役；</span></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 45:6–7; 以赛亚书 9:6–7; 耶利米书 23:5–6"> 论到子却说：<br /><span className="pl pl-1">神啊，你的宝座是永永远远的；</span><br /><span className="pl pl-1">你的国权是正直的。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 45:7; 诗篇 23:5; 以赛亚书 61:3"> <span className="pl pl-1">你喜爱公义，恨恶罪恶；</span><br /><span className="pl pl-1">所以 神，就是你的 神，用喜乐油膏你，</span><br /><span className="pl pl-1">胜过膏你的同伴；</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 102:25–27; 创世记 1:1; 约翰福音 1:1–3"> <span className="pl pl-1">又说：主啊，你起初立了地的根基；</span><br /><span className="pl pl-1">天也是你手所造的。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 51:6; 马可福音 13:31; 路加福音 21:33"> <span className="pl pl-1">天地都要灭没，你却要长存。</span><br /><span className="pl pl-1">天地都要像衣服渐渐旧了；</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 102:26–27; 希伯来书 13:8; 约翰福音 8:58"> <span className="pl pl-1">你要将天地卷起来，像一件外衣，</span><br /><span className="pl pl-1">天地就都改变了。</span><br /><span className="pl pl-1">惟有你永不改变；</span><br /><span className="pl pl-1">你的年数没有穷尽。</span></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 110:1; 马可福音 12:36; 马太福音 22:44"> 所有的天使， 神从来对哪一个说：<br /><span className="pl pl-1">你坐在我的右边，</span><br /><span className="pl pl-1">等我使你仇敌作你的脚凳？</span></span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 34:7; 诗篇 103:20–21; 诗篇 91:11–12"> 天使岂不都是服役的灵、奉差遣为那将要承受救恩的人效力吗？</span>
</div>

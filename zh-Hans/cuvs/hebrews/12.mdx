## 主的管教

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太后书 4:7; 哥林多前书 9:24–27; 腓立比书 2:16"> 我们既有这许多的见证人，如同云彩围着我们，就当放下各样的重担，脱去容易缠累我们的罪，存心忍耐，奔那摆在我们前头的路程，</span>
<span className="v" id="v2" data-v="2" data-xref="弥迦书 7:7; 彼得前书 3:18; 彼得前书 2:23–24"> 仰望为我们信心创始成终的耶稣<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：仰望那将真道创始成终的耶稣">a</a></sup>。他因那摆在前面的喜乐，就轻看羞辱，忍受了十字架的苦难，便坐在 神宝座的右边。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 6:9; 哥林多后书 4:16; 启示录 2:3"> 那忍受罪人这样顶撞的，你们要思想，免得疲倦灰心。</span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 10:13; 启示录 2:13; 希伯来书 10:32–34"> 你们与罪恶相争，还没有抵挡到流血的地步。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 3:11–12; 约伯记 5:17–18; 启示录 3:19"> 你们又忘了那劝你们如同劝儿子的话，说：<br /><span className="pl pl-1">我儿，你不可轻看主的管教，</span><br /><span className="pl pl-1">被他责备的时候也不可灰心；</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="启示录 3:19; 箴言 3:12; 诗篇 119:75"> <span className="pl pl-1">因为主所爱的，他必管教，</span><br /><span className="pl pl-1">又鞭打凡所收纳的儿子。</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="箴言 19:18; 申命记 8:5; 箴言 13:24"> 你们所忍受的，是 神管教你们，待你们如同待儿子。焉有儿子不被父亲管教的呢？</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 12:6; 彼得前书 5:9–10; 诗篇 73:1"> 管教原是众子所共受的。你们若不受管教，就是私子，不是儿子了。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 16:22; 民数记 27:16; 以赛亚书 42:5"> 再者，我们曾有生身的父管教我们，我们尚且敬重他，何况万灵的父，我们岂不更当顺服他得生吗？</span>
<span className="v" id="v10" data-v="10" data-xref="彼得后书 1:4; 利未记 11:44–45; 提多书 2:14"> 生身的父都是暂随己意管教我们；惟有万灵的父管教我们，是要我们得益处，使我们在他的圣洁上有分。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 5:3–5; 哥林多后书 4:17; 希伯来书 12:5–6"> 凡管教的事，当时不觉得快乐，反觉得愁苦；后来却为那经练过的人结出平安的果子，就是义。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 35:3; 希伯来书 12:3; 帖撒罗尼迦前书 5:14"> 所以，你们要把下垂的手、发酸的腿挺起来；</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 4:26–27; 以赛亚书 35:3; 加拉太书 6:1"> 也要为自己的脚，把道路修直了，使瘸子不致歪脚<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：差路">b</a></sup>，反得痊愈。</span>
</div>
</div>

## 警告弃绝 神恩典的人

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 7:1; 彼得前书 1:15–16; 帖撒罗尼迦前书 4:7"> 你们要追求与众人和睦，并要追求圣洁；非圣洁没有人能见主。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 3:12; 申命记 29:18; 加拉太书 5:4"> 又要谨慎，恐怕有人失了 神的恩；恐怕有毒根生出来扰乱你们，因此叫众人沾染污秽；</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 25:31–34; 哥林多前书 6:15–20; 启示录 22:15"> 恐怕有淫乱的，有贪恋世俗如以扫的，他因一点食物把自己长子的名分卖了。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 1:24–31; 马太福音 25:11–12; 马太福音 7:23"> 后来想要承受父所祝的福，竟被弃绝，虽然号哭切求，却得不着门路使他父亲的心意回转。这是你们知道的。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命记 4:11; 出埃及记 24:17; 出埃及记 20:18"> 你们原不是来到那能摸的山；此山有火焰、密云、黑暗、暴风、</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 18:16; 哥林多前书 15:52; 申命记 4:12"> 角声与说话的声音。那些听见这声音的，都求不要再向他们说话；</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 19:12–13; 出埃及记 19:16; 加拉太书 3:10"> 因为他们当不起所命他们的话，说：「靠近这山的，即便是走兽，也要用石头打死。」</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 19:16; 申命记 9:19; 以赛亚书 6:3–5"> 所见的极其可怕，甚至摩西说：「我甚是恐惧战兢。」</span>
<span className="v" id="v22" data-v="22" data-xref="加拉太书 4:26; 腓立比书 3:20; 启示录 14:1"> 你们乃是来到锡安山，永生 神的城邑，就是天上的耶路撒冷。那里有千万的天使，</span>
<span className="v" id="v23" data-v="23" data-xref="雅各书 1:18; 希伯来书 11:40; 路加福音 10:20"> 有名录在天上诸长子之会所共聚的总会，有审判众人的 神和被成全之义人的灵魂，</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 9:15; 希伯来书 11:28; 希伯来书 11:4"> 并新约的中保耶稣，以及所洒的血；这血所说的比亚伯的血所说的更美。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="希伯来书 8:5; 申命记 30:17; 希伯来书 2:1–3"> 你们总要谨慎，不可弃绝那向你们说话的。因为，那些弃绝在地上警戒他们的尚且不能逃罪，何况我们违背那从天上警戒我们的呢？</span>
<span className="v" id="v26" data-v="26" data-xref="哈该书 2:6–7; 以赛亚书 13:13; 出埃及记 19:18"> 当时他的声音震动了地，但如今他应许说：「再一次我不单要震动地，还要震动天。」</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 7:31; 马太福音 24:35; 彼得后书 3:10–11"> 这再一次的话，是指明被震动的，就是受造之物都要挪去，使那不被震动的常存。</span>
<span className="v" id="v28" data-v="28" data-xref="罗马书 12:1–2; 希伯来书 13:15; 但以理书 2:44"> 所以我们既得了不能震动的国，就当感恩，照 神所喜悦的，用虔诚、敬畏的心事奉 神。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 4:24; 申命记 9:3; 希伯来书 10:27"> 因为我们的 神乃是烈火。</span>
</div>
</div>

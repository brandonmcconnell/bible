## 蒙 神悦纳的服务

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="约翰一书 4:20–1; 彼得前书 3:8; 彼得前书 1:22"> 你们务要常存弟兄相爱的心。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 25:35; 创世记 18:1–3; 彼得前书 4:9"> 不可忘记用爱心接待客旅；因为曾有接待客旅的，不知不觉就接待了天使。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 25:36; 希伯来书 10:34; 罗马书 12:15"> 你们要记念被捆绑的人，好像与他们同受捆绑；也要记念遭苦害的人，想到自己也在肉身之内。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 2:24; 箴言 5:15–23; 加拉太书 5:19"> 婚姻，人人都当尊重，床也不可污秽；因为苟合行淫的人， 神必要审判。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 31:8; 约书亚记 1:5; 申命记 31:6"> 你们存心不可贪爱钱财，要以自己所有的为足；因为主曾说：「我总不撇下你，也不丢弃你。」</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 118:6–9; 以赛亚书 41:10; 罗马书 8:31"> 所以我们可以放胆说：<br /><span className="pl pl-1">主是帮助我的，我必不惧怕；</span><br /><span className="pl pl-1">人能把我怎么样呢？</span></span>
<span className="v" id="v7" data-v="7" data-xref="帖撒罗尼迦前书 5:12–13; 希伯来书 13:17; 腓立比书 3:17"> 从前引导你们、传 神之道给你们的人，你们要想念他们，效法他们的信心，留心看他们为人的结局。</span>
<span className="v" id="v8" data-v="8" data-xref="玛拉基书 3:6; 雅各书 1:17; 启示录 1:8"> 耶稣基督昨日、今日、一直到永远，是一样的。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 4:14; 提摩太前书 6:3–5; 以弗所书 5:6"> 你们不要被那诸般怪异的教训勾引了去；因为人心靠恩得坚固才是好的，并不是靠饮食。那在饮食上专心的从来没有得着益处。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 5:7–8; 哥林多前书 10:20; 哥林多前书 9:13"> 我们有一祭坛，上面的祭物是那些在帐幕中供职的人不可同吃的。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 16:27; 出埃及记 29:14; 利未记 9:11"> 原来牲畜的血被大祭司带入圣所作赎罪祭；牲畜的身子被烧在营外。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 9:12–14; 约翰福音 19:17–18; 使徒行传 7:58"> 所以，耶稣要用自己的血叫百姓成圣，也就在城门外受苦。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 11:26; 彼得前书 4:14–16; 使徒行传 5:41"> 这样，我们也当出到营外，就了他去，忍受他所受的凌辱。</span>
<span className="v" id="v14" data-v="14" data-xref="腓立比书 3:20; 歌罗西书 3:1–3; 希伯来书 11:12–16"> 我们在这里本没有常存的城，乃是寻求那将来的城。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 107:21–22; 诗篇 50:14; 罗马书 12:1"> 我们应当靠着耶稣，常常以颂赞为祭献给 神，这就是那承认主名之人嘴唇的果子。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦后书 3:13; 加拉太书 6:10; 罗马书 12:13"> 只是不可忘记行善和捐输的事，因为这样的祭是 神所喜悦的。</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦前书 5:12–13; 提摩太前书 5:17; 希伯来书 13:7"> 你们要依从那些引导你们的，且要顺服；因他们为你们的灵魂时刻警醒，好像那将来交帐的人。你们要使他们交的时候有快乐，不致忧愁；若忧愁就与你们无益了。</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 5:25; 帖撒罗尼迦后书 3:1; 歌罗西书 4:3"> 请你们为我们祷告，因我们自觉良心无亏，愿意凡事按正道而行。</span>
<span className="v" id="v19" data-v="19" data-xref="腓利门书 1:22; 罗马书 1:10–12; 罗马书 15:31–32"> 我更求你们为我祷告，使我快些回到你们那里去。</span>
</div>
</div>

## 祝福和问安

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约翰福音 10:11; 希伯来书 10:22; 诗篇 23:1"> 但愿赐平安的 神，就是那凭永约之血、使群羊的大牧人—我主耶稣从死里复活的 神，</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比书 2:13; 帖撒罗尼迦后书 2:17; 腓立比书 4:13"> 在各样善事上成全你们，叫你们遵行他的旨意；又借着耶稣基督在你们心里行他所喜悦的事。愿荣耀归给他，直到永永远远。阿们！</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 3:1; 彼得前书 5:12; 哥林多后书 6:1"> 弟兄们，我略略写信给你们，望你们听我劝勉的话。</span>
<span className="v" id="v23" data-v="23" data-xref="腓利门书 1:1; 帖撒罗尼迦前书 3:2; 提摩太后书 1:8"> 你们该知道，我们的兄弟提摩太已经释放了；他若快来，我必同他去见你们。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 13:7; 希伯来书 13:17; 使徒行传 18:2"> 请你们问引导你们的诸位和众圣徒安。从意大利来的人也问你们安。</span>
<span className="v" id="v25" data-v="25" data-xref="歌罗西书 4:18; 提摩太后书 4:22; 提多书 3:15"> 愿恩惠常与你们众人同在。阿们！</span>
</div>

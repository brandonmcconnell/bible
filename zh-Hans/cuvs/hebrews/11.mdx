## 论信

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 5:7; 哥林多后书 4:18; 罗马书 8:24–25"> 信就是所望之事的实底，是未见之事的确据。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:39; 希伯来书 11:4"> 古人在这信上得了美好的证据。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="诗篇 33:6; 彼得后书 3:5; 约翰福音 1:3"> 我们因着信，就知道诸世界是借 神的话造成的；这样，所看见的，并不是从显然之物造出来的。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="希伯来书 12:24; 创世记 4:3–5; 约翰一书 3:11–12"> 亚伯因着信，献祭与 神，比该隐所献的更美，因此便得了称义的见证，就是 神指他礼物作的见证。他虽然死了，却因这信，仍旧说话。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 5:21–24; 犹大书 1:14; 希伯来书 11:6"> 以诺因着信，被接去，不至于见死，人也找不着他，因为 神已经把他接去了；只是他被接去以先，已经得了 神喜悦他的明证。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 8:17; 耶利米书 29:13–14; 马太福音 6:33"> 人非有信，就不能得 神的喜悦；因为到 神面前来的人必须信有 神，且信他赏赐那寻求他的人。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 6:13–1; 彼得前书 3:20; 以西结书 14:14"> 挪亚因着信，既蒙 神指示他未见的事，动了敬畏的心，预备了一只方舟，使他全家得救。因此就定了那世代的罪，自己也承受了那从信而来的义。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="创世记 12:1–4; 使徒行传 7:2–4; 马太福音 7:24–25"> 亚伯拉罕因着信，蒙召的时候就遵命出去，往将来要得为业的地方去；出去的时候，还不知往哪里去。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 12:8; 创世记 13:18; 创世记 13:3"> 他因着信，就在所应许之地作客，好像在异地居住帐棚，与那同蒙一个应许的以撒、雅各一样。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 13:14; 腓立比书 3:20; 希伯来书 12:22"> 因为他等候那座有根基的城，就是 神所经营所建造的。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 4:20–21; 希伯来书 10:23; 创世记 18:11–14"> 因着信，连撒拉自己，虽然过了生育的岁数，还能怀孕，因她以为那应许她的是可信的。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 22:17; 创世记 32:12; 创世记 15:5"> 所以从一个仿佛已死的人就生出子孙，如同天上的星那样众多，海边的沙那样无数。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 23:4; 诗篇 39:12; 希伯来书 11:27"> 这些人都是存着信心死的，并没有得着所应许的；却从远处望见，且欢喜迎接，又承认自己在世上是客旅，是寄居的。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 4:18–7; 希伯来书 11:16; 希伯来书 13:14"> 说这样话的人是表明自己要找一个家乡。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 24:6–8; 创世记 12:10; 创世记 32:9–11"> 他们若想念所离开的家乡，还有可以回去的机会。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 13:14; 希伯来书 11:10; 腓立比书 3:20"> 他们却羡慕一个更美的家乡，就是在天上的。所以 神被称为他们的 神，并不以为耻，因为他已经给他们预备了一座城。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 22:16; 创世记 22:1–12; 雅各书 2:21–24"> 亚伯拉罕因着信，被试验的时候，就把以撒献上；这便是那欢喜领受应许的，将自己独生的儿子献上。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 21:12; 罗马书 9:7; 创世记 17:19"> 论到这儿子，曾有话说：「从以撒生的才要称为你的后裔。」</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 4:17–21; 马太福音 9:28; 以弗所书 3:20"> 他以为 神还能叫人从死里复活；他也仿佛从死中得回他的儿子来。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 27:27–40; 创世记 28:2–3"> 以撒因着信，就指着将来的事给雅各、以扫祝福。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 47:31–1; 创世记 48:5–22"> 雅各因着信，临死的时候，给约瑟的两个儿子各自祝福，扶着杖头敬拜 神。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 13:19; 创世记 50:24–25; 约书亚记 24:32"> 约瑟因着信，临终的时候，提到以色列族将来要出埃及，并为自己的骸骨留下遗命。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出埃及记 1:22; 出埃及记 1:16; 希伯来书 13:6"> 摩西生下来，他的父母见他是个俊美的孩子，就因着信，把他藏了三个月，并不怕王命。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 2:10–11; 使徒行传 7:21–24"> 摩西因着信，长大了就不肯称为法老女儿之子。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 84:10; 提摩太后书 2:3–10; 约伯记 36:21"> 他宁可和 神的百姓同受苦害，也不愿暂时享受罪中之乐。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 10:35; 希伯来书 11:6; 彼得前书 4:14"> 他看为基督受的凌辱比埃及的财物更宝贵，因他想望所要得的赏赐。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多后书 4:18; 希伯来书 11:13; 希伯来书 11:1"> 他因着信，就离开埃及，不怕王怒；因为他恒心忍耐，如同看见那不能看见的主。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 12:21–30; 希伯来书 9:19; 希伯来书 12:24"> 他因着信，就守<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：立">a</a></sup>逾越节，行洒血的礼，免得那灭长子的临近以色列人。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 14:13–21; 诗篇 106:9–11; 诗篇 78:13"> 他们因着信，过红海如行干地；埃及人试着要过去，就被吞灭了。</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 6:3–20; 哥林多后书 10:4–5"> 以色列人因着信，围绕耶利哥城七日，城墙就倒塌了。</span>
<span className="v" id="v31" data-v="31" data-xref="雅各书 2:25; 约书亚记 6:22–25; 马太福音 1:5"> 妓女喇合因着信，曾和和平平地接待探子，就不与那些不顺从的人一同灭亡。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 16:1; 撒母耳记上 1:20; 撒母耳记上 16:13"> 我又何必再说呢？若要一一细说，基甸、巴拉、参孙、耶弗他、大卫、撒母耳，和众先知的事，时候就不够了。</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 144:1–2; 希伯来书 6:12–15; 希伯来书 10:36"> 他们因着信，制伏了敌国，行了公义，得了应许，堵了狮子的口，</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪下 6:16–18; 哥林多后书 12:9–10; 撒母耳记上 17:51–52"> 灭了烈火的猛势，脱了刀剑的锋刃；软弱变为刚强，争战显出勇敢，打退外邦的全军。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪下 4:27–37; 列王纪上 17:22–24; 腓立比书 3:11"> 有妇人得自己的死人复活。又有人忍受严刑，不肯苟且得释放<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是赎">b</a></sup>，为要得着更美的复活。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 20:2; 创世记 39:20; 耶利米书 37:15–21"> 又有人忍受戏弄、鞭打、捆锁、监禁、各等的磨炼，</span>
<span className="v" id="v37" data-v="37" data-xref="历代志下 24:21; 耶利米书 26:23; 列王纪上 19:10"> 被石头打死，被锯锯死，受试探，被刀杀，披着绵羊山羊的皮各处奔跑，受穷乏、患难、苦害，</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪上 18:4; 撒母耳记上 22:1; 列王纪上 19:9"> 在旷野、山岭、山洞、地穴，飘流无定，本是世界不配有的人。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 10:23–24; 希伯来书 11:13; 希伯来书 11:2"> 这些人都是因信得了美好的证据，却仍未得着所应许的；</span>
<span className="v" id="v40" data-v="40" data-xref="启示录 6:11; 希伯来书 8:6; 希伯来书 10:11–14"> 因为 神给我们预备了更美的事，叫他们若不与我们同得，就不能完全。</span>
</div>
</div>

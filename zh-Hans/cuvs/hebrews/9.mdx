## 地上和天上的圣所

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 25:8; 希伯来书 9:10–11; 希伯来书 8:2"> 原来前约有礼拜的条例和属世界的圣幕。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 40:4; 利未记 24:5–8; 出埃及记 26:35"> 因为有预备的帐幕，头一层叫作圣所，里面有灯台、桌子，和陈设饼。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 26:31–33; 出埃及记 40:3; 马太福音 27:51"> 第二幔子后又有一层帐幕，叫作至圣所，</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 17:10; 历代志下 5:10; 出埃及记 40:3"> 有金香炉<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="炉：或译坛">a</a></sup>，有包金的约柜，柜里有盛吗哪的金罐和亚伦发过芽的杖，并两块约版；</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 16:2; 民数记 7:89; 出埃及记 25:17–22"> 柜上面有荣耀基路伯的影罩着施恩<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="施恩：原文是蔽罪">b</a></sup>座。这几件我现在不能一一细说。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数记 28:3; 出埃及记 27:21; 路加福音 1:8–11"> 这些物件既如此预备齐了，众祭司就常进头一层帐幕，行拜 神的礼。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 16:34; 利未记 5:18; 希伯来书 10:19–20"> 至于第二层帐幕，惟有大祭司一年一次独自进去，没有不带着血为自己和百姓的过错献上。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 14:6; 希伯来书 3:7; 希伯来书 10:19–22"> 圣灵用此指明，头一层帐幕仍存的时候，进入至圣所的路还未显明。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 3:21; 希伯来书 5:1; 罗马书 5:14"> 那头一层帐幕作现今的一个表样，所献的礼物和祭物，就着良心说，都不能叫礼拜的人得以完全。</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 2:15; 歌罗西书 2:16; 利未记 11:2–47"> 这些事，连那饮食和诸般洗濯的规矩，都不过是属肉体的条例，命定到振兴的时候为止。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="希伯来书 9:23–24; 哥林多后书 5:1; 希伯来书 8:1–2"> 但现在基督已经来到，作了将来美事的大祭司，经过那更大更全备的帐幕，不是人手所造，也不是属乎这世界的；</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 10:4; 彼得前书 1:18–19; 希伯来书 9:15"> 并且不用山羊和牛犊的血，乃用自己的血，只一次进入圣所，成了永远赎罪的事。</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 19:2–21; 利未记 16:14–16; 使徒行传 15:9"> 若山羊和公牛的血，并母牛犊的灰，洒在不洁的人身上，尚且叫人成圣，身体洁净，</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 10:22; 彼得前书 1:19; 约翰一书 1:7"> 何况基督借着永远的灵，将自己无瑕无疵献给 神，他的血岂不更能洗净你们的心<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文是良心">c</a></sup>，除去你们的死行，使你们事奉那永生 神吗？</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="罗马书 3:24–26; 罗马书 8:30; 罗马书 8:28"> 为此，他作了新约的中保，既然受死赎了人在前约之时所犯的罪过，便叫蒙召之人得着所应许永远的产业。</span>
<span className="v" id="v16" data-v="16" data-xref="雅各书 2:10; 哥林多前书 15:22; 罗马书 5:12"> 凡有遗命必须等到留遗命<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="遗命：原文与约字同">d</a></sup>的人死了；</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 48:21; 约翰福音 14:27; 加拉太书 3:15"> 因为人死了，遗命才有效力，若留遗命的尚在，那遗命还有用处吗？</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 24:3–8; 希伯来书 9:14; 希伯来书 9:22"> 所以，前约也不是不用血立的；</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 24:5–11; 民数记 19:6; 希伯来书 10:4"> 因为摩西当日照着律法将各样诫命传给众百姓，就拿朱红色绒和牛膝草，把牛犊山羊的血和水洒在书上，又洒在众百姓身上，说：</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 24:8; 马太福音 26:28; 希伯来书 13:20"> 「这血就是 神与你们立约的凭据。」</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 8:15; 利未记 8:19; 出埃及记 29:36"> 他又照样把血洒在帐幕和各样器皿上。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 17:11; 利未记 6:7; 利未记 4:35"> 按着律法，凡物差不多都是用血洁净的；若不流血，罪就不得赦免了。</span>
</div>
</div>

## 基督献己为祭除掉了罪

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="彼得前书 1:19–21; 希伯来书 10:4; 希伯来书 9:14"> 照着天上样式做的物件必须用这些祭物去洁净；但那天上的本物自然当用更美的祭物去洁净。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 12:2; 希伯来书 9:11–12; 希伯来书 9:23"> 因为基督并不是进了人手所造的圣所（这不过是真圣所的影相），乃是进了天堂，如今为我们显在 神面前；</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 9:12; 希伯来书 9:7; 希伯来书 9:14"> 也不是多次将自己献上，像那大祭司每年带着牛羊的血<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="牛羊的血：原文作不是自己的血">e</a></sup>进入圣所，</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 9:12; 彼得前书 1:20; 希伯来书 1:2"> 如果这样，他从创世以来，就必多次受苦了。但如今在这末世显现一次，把自己献为祭，好除掉罪。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多后书 5:10; 传道书 12:7; 传道书 12:14"> 按着定命，人人都有一死，死后且有审判。</span>
<span className="v" id="v28" data-v="28" data-xref="提多书 2:13; 彼得前书 2:24; 罗马书 6:10"> 像这样，基督既然一次被献，担当了多人的罪，将来要向那等候他的人第二次显现，并与罪无关，乃是为拯救他们。</span>
</div>
</div>

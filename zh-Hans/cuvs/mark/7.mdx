## 古人的传统

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="马太福音 15:1–20; 马可福音 3:22; 路加福音 5:17"> 有法利赛人和几个文士从耶路撒冷来，到耶稣那里聚集。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 10:28; 马太福音 7:3–5; 罗马书 14:14"> 他们曾看见他的门徒中有人用俗手，就是没有洗的手，吃饭。（</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 1:14; 马可福音 7:13; 歌罗西书 2:8"> 原来法利赛人和犹太人都拘守古人的遗传，若不仔细洗手就不吃饭；</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 9:10; 马太福音 23:25; 路加福音 11:38–39"> 从市上来，若不洗浴也不吃饭；还有好些别的规矩，他们历代拘守，就是洗杯、罐、铜器等物。）</span>
<span className="v" id="v5" data-v="5" data-xref="帖撒罗尼迦后书 3:6; 使徒行传 21:21; 马太福音 15:2"> 法利赛人和文士问他说：「你的门徒为什么不照古人的遗传，用俗手吃饭呢？」</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 29:13; 提多书 1:16; 马太福音 15:7–9"> 耶稣说：「以赛亚指着你们假冒为善之人所说的预言是不错的。如经上说：<br /><span className="pl pl-1">这百姓用嘴唇尊敬我，</span><br /><span className="pl pl-1">心却远离我。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 29:13; 马太福音 15:9; 雅各书 1:26"> <span className="pl pl-1">他们将人的吩咐当作道理教导人，</span><br /><span className="pl pl-1">所以拜我也是枉然。</span></span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 7:3–4; 以赛亚书 1:12"> 你们是离弃 神的诫命，拘守人的遗传」；</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 44:16–17; 加拉太书 2:21; 以赛亚书 29:13"> 又说：「你们诚然是废弃 神的诫命，要守自己的遗传。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 21:17; 出埃及记 20:12; 申命记 5:16"> 摩西说：『当孝敬父母』；又说：『咒骂父母的，必治死他。』</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 23:18; 提摩太前书 5:4–8; 马太福音 15:5"> 你们倒说：『人若对父母说：我所当奉给你的，已经作了各耳板』（各耳板就是供献的意思），</span>
<span className="v" id="v12" data-v="12"> 以后你们就不容他再奉养父母。</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 7:9; 提多书 1:14; 马太福音 5:17–20"> 这就是你们承接遗传，废了 神的道。你们还做许多这样的事。」</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 15:10; 以赛亚书 6:9; 箴言 8:5"> 耶稣又叫众人来，对他们说：「你们都要听我的话，也要明白。</span>
<span className="v" id="v15" data-v="15" data-xref="箴言 4:23; 利未记 11:42–47; 提多书 1:15"> 从外面进去的不能污秽人，惟有从里面出来的乃能污秽人。」<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有古卷加：16有耳可听的，就应当听！">a</a></sup></span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 15:15; 马太福音 13:36; 马可福音 9:28"> 耶稣离开众人，进了屋子，门徒就问他这比喻的意思。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 15:16–17; 希伯来书 5:11; 以赛亚书 28:9–10"> 耶稣对他们说：「你们也是这样不明白吗？岂不晓得凡从外面进入的，不能污秽人，</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 15:17; 哥林多前书 6:13; 歌罗西书 2:21–22"> 因为不是入他的心，乃是入他的肚腹，又落到茅厕里（这是说，各样的食物都是洁净的）」；</span>
<span className="v" id="v20" data-v="20" data-xref="雅各书 3:6; 雅各书 1:14–15; 雅各书 4:1"> 又说：「从人里面出来的，那才能污秽人；</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 17:9; 罗马书 8:7–8; 雅各书 4:1–3"> 因为从里面，就是从人心里，发出恶念、苟合、</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 20:15; 马太福音 6:23; 彼得前书 2:15"> 偷盗、凶杀、奸淫、贪婪、邪恶、诡诈、淫荡、嫉妒、谤 、骄傲、狂妄。</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 7:15; 提多书 1:15; 哥林多前书 3:17"> 这一切的恶都是从里面出来，且能污秽人。」</span>
</div>
</div>

## 一个妇人的信心

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="马太福音 15:21–28; 马太福音 11:21; 以西结书 28:2"> 耶稣从那里起身，往泰尔、西顿的境内去，进了一家，不愿意人知道，却隐藏不住。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 15:22; 马可福音 9:17–23; 使徒行传 10:25–26"> 当下，有一个妇人，她的小女儿被污鬼附着，听见耶稣的事，就来俯伏在他脚前。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 15:22; 以赛亚书 49:12; 加拉太书 3:28"> 这妇人是希腊人，属叙利腓尼基族。她求耶稣赶出那鬼离开她的女儿。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 15:23–28; 马太福音 7:6; 使徒行传 22:21"> 耶稣对她说：「让儿女们先吃饱，不好拿儿女的饼丢给狗吃。」</span>
<span className="v" id="v28" data-v="28" data-xref="罗马书 10:12; 罗马书 3:29; 使徒行传 11:17–18"> 妇人回答说：「主啊，不错；但是狗在桌子底下也吃孩子们的碎渣儿。」</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 66:2; 马太福音 5:3; 约翰一书 3:8"> 耶稣对她说：「因这句话，你回去吧；鬼已经离开你的女儿了。」</span>
<span className="v" id="v30" data-v="30" data-xref="约翰一书 3:8; 约翰福音 4:50–52"> 她就回家去，见小孩子躺在床上，鬼已经出去了。</span>
</div>
</div>

## 耶稣治好耳聋舌结的人

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马可福音 5:20; 马太福音 15:29–31; 马太福音 4:25"> 耶稣又离了泰尔的境界，经过西顿，就从低加坡里境内来到加利利 海。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 11:14; 马可福音 5:23; 马太福音 9:32–33"> 有人带着一个耳聋舌结的人来见耶稣，求他按手在他身上。</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 8:23; 约翰福音 9:6–7; 马可福音 5:40"> 耶稣领他离开众人，到一边去，就用指头探他的耳朵，吐唾沫抹他的舌头，</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 11:41; 马可福音 5:41; 马可福音 6:41"> 望天叹息，对他说：「以法大！」就是说：「开了吧！」</span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 35:5–6; 诗篇 33:9; 马可福音 2:12"> 他的耳朵就开了，舌结也解了，说话也清楚了。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 8:4; 马可福音 8:26; 马可福音 3:12"> 耶稣嘱咐他们不要告诉人；但他越发嘱咐，他们越发传扬开了。</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 6:51; 马可福音 5:42; 出埃及记 4:10–11"> 众人分外希奇，说：「他所做的事都好，他连聋子也叫他们听见，哑巴也叫他们说话。」</span>
</div>

## 治好格拉森被鬼附的人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 8:26–39; 马太福音 8:28–34; 马可福音 4:35"> 他们来到海那边格拉森人的地方。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 1:23; 以赛亚书 65:4; 马可福音 5:8"> 耶稣一下船，就有一个被污鬼附着的人从坟茔里出来迎着他。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 65:4; 路加福音 8:29; 但以理书 4:32–33"> 那人常住在坟茔里，没有人能捆住他，就是用铁链也不能；</span>
<span className="v" id="v4" data-v="4" data-xref="雅各书 3:7–8"> 因为人屡次用脚镣和铁链捆锁他，铁链竟被他挣断了，脚镣也被他弄碎了；总没有人能制伏他。</span>
<span className="v" id="v5" data-v="5" data-xref="约伯记 2:7–8; 列王纪上 18:28; 约翰福音 8:44"> 他昼夜常在坟茔里和山中喊叫，又用石头砍自己。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 2:19; 诗篇 66:3; 路加福音 4:41"> 他远远地看见耶稣，就跑过去拜他，</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 8:29; 使徒行传 16:17; 马太福音 26:63"> 大声呼叫说：「至高 神的儿子耶稣，我与你有什么相干？我指着 神恳求你，不要叫我受苦！」</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 1:25; 马可福音 9:25–26; 使徒行传 16:18"> 是因耶稣曾吩咐他说：「污鬼啊，从这人身上出来吧！」</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 8:30; 马可福音 5:15; 马太福音 26:53"> 耶稣问他说：「你名叫什么？」回答说：「我名叫『群』，因为我们多的缘故」；</span>
<span className="v" id="v10" data-v="10" data-xref="马可福音 3:22; 马可福音 5:13"> 就再三地求耶稣，不要叫他们离开那地方。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 11:7–8; 以赛亚书 65:4; 以赛亚书 66:3"> 在那里山坡上，有一大群猪吃食；</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 2:11; 约伯记 1:10–12; 路加福音 22:31–32"> 鬼就央求耶稣说：「求你打发我们往猪群里，附着猪去。」</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 22:22; 彼得前书 3:22; 约伯记 2:6"> 耶稣准了他们，污鬼就出来，进入猪里去。于是那群猪闯下山崖，投在海里，淹死了。猪的数目约有二千。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 8:34; 马太福音 8:33"> 放猪的就逃跑了，去告诉城里和乡下的人。众人就来，要看是什么事。</span>
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 1:13; 提摩太后书 1:7; 撒母耳记上 6:20–21"> 他们来到耶稣那里，看见那被鬼附着的人，就是从前被群鬼所附的，坐着，穿上衣服，心里明白过来，他们就害怕。</span>
<span className="v" id="v16" data-v="16"> 看见这事的，便将鬼附之人所遇见的和那群猪的事都告诉了众人；</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 8:34; 马可福音 1:24; 路加福音 8:37"> 众人就央求耶稣离开他们的境界。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 8:38–39; 腓立比书 1:23–24; 马可福音 5:17"> 耶稣上船的时候，那从前被鬼附着的人恳求和耶稣同在。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 66:16; 约翰福音 4:29; 以赛亚书 38:9–20"> 耶稣不许，却对他说：「你回家去，到你的亲属那里，将主为你所做的是何等大的事，是怎样怜悯你，都告诉他们。」</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 7:31; 马太福音 4:25"> 那人就走了，在低加坡里传扬耶稣为他做了何等大的事，众人就都希奇。</span>
</div>
</div>

## 睚鲁的女儿和血漏的女人

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马太福音 9:1; 马可福音 4:1; 路加福音 8:40"> 耶稣坐船又渡到那边去，就有许多人到他那里聚集；他正在海边上。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 13:14; 使徒行传 18:8; 马可福音 5:35–36"> 有一个管会堂的人，名叫睚鲁，来见耶稣，就俯伏在他脚前，</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 13:13; 路加福音 4:40; 马可福音 16:18"> 再三地求他，说：「我的小女儿快要死了，求你去按手在她身上，使她痊愈，得以活了。」</span>
<span className="v" id="v24" data-v="24" data-xref="马可福音 5:31; 马可福音 3:20; 路加福音 7:6"> 耶稣就和他同去。 有许多人跟随拥挤他。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 15:25–27; 路加福音 8:43–44; 马太福音 9:20–22"> 有一个女人，患了十二年的血漏，</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 30:12–13; 耶利米书 8:22; 诗篇 108:12"> 在好些医生手里受了许多的苦，又花尽了她所有的，一点也不见好，病势反倒更重了。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 19:12; 马太福音 14:36; 使徒行传 5:15"> 她听见耶稣的事，就从后头来，杂在众人中间，摸耶稣的衣裳，</span>
<span className="v" id="v28" data-v="28"> 意思说：「我只摸他的衣裳，就必痊愈。」</span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 5:34; 诗篇 30:2; 马可福音 3:10"> 于是她血漏的源头立刻干了；她便觉得身上的灾病好了。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 6:19; 路加福音 8:46; 路加福音 5:17"> 耶稣顿时心里觉得有能力从自己身上出去，就在众人中间转过来，说：「谁摸我的衣裳？」</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 8:45; 路加福音 9:12"> 门徒对他说：「你看众人拥挤你，还说『谁摸我』吗？」</span>
<span className="v" id="v32" data-v="32"> 耶稣周围观看，要见做这事的女人。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 8:47; 路加福音 1:29; 路加福音 1:12"> 那女人知道在自己身上所成的事，就恐惧战兢，来俯伏在耶稣跟前，将实情全告诉他。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 8:48; 马太福音 9:22; 路加福音 7:50"> 耶稣对她说：「女儿，你的信救了你，平平安安地回去吧！你的灾病痊愈了。」</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 8:49; 约翰福音 11:39; 马可福音 5:22"> 还说话的时候，有人从管会堂的家里来，说：「你的女儿死了，何必还劳动先生呢？」</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 8:50; 马太福音 9:28–29; 约翰福音 11:40"> 耶稣听见所说的话，就对管会堂的说：「不要怕，只要信！」</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 9:40; 马可福音 14:33; 哥林多后书 13:1"> 于是带着彼得、雅各，和雅各的兄弟约翰同去，不许别人跟随他。</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 9:23–24; 路加福音 8:52–53; 马可福音 5:22"> 他们来到管会堂的家里；耶稣看见那里乱嚷，并有人大大地哭泣哀号，</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 20:10; 帖撒罗尼迦前书 5:10; 帖撒罗尼迦前书 4:13–14"> 进到里面，就对他们说：「为什么乱嚷哭泣呢？孩子不是死了，是睡着了。」</span>
<span className="v" id="v40" data-v="40" data-xref="尼希米记 2:19; 列王纪下 4:33; 马太福音 9:24–25"> 他们就嗤笑耶稣。耶稣把他们都撵出去，就带着孩子的父母和跟随的人进了孩子所在的地方，</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 1:31; 路加福音 7:14–15; 路加福音 8:54–55"> 就拉着孩子的手，对她说：「大利大，古米！」（翻出来就是说：「闺女，我吩咐你起来！」）</span>
<span className="v" id="v42" data-v="42" data-xref="马可福音 4:41; 使徒行传 3:10–13; 马可福音 7:37"> 那闺女立时起来走。他们就大大地惊奇；闺女已经十二岁了。</span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 8:4; 马太福音 9:30; 马可福音 1:43"> 耶稣切切地嘱咐他们，不要叫人知道这事，又吩咐给她东西吃。</span>

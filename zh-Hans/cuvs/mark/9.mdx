## 耶稣改变形象

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="路加福音 9:28–36; 以赛亚书 33:17; 马太福音 17:1–8"> 过了六天，耶稣带着彼得、雅各、约翰暗暗地上了高山，就在他们面前变了形象，</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 28:3; 但以理书 7:9; 启示录 7:14"> 衣服放光，极其洁白，地上漂布的，没有一个能漂得那样白。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 9:30–31; 马太福音 17:3–4; 使徒行传 3:21–24"> 忽然，有以利亚同摩西向他们显现，并且和耶稣说话。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 1:23; 约翰福音 14:8–9; 启示录 22:3–4"> 彼得对耶稣说：「拉比<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是夫子">a</a></sup>，我们在这里真好！可以搭三座棚，一座为你，一座为摩西，一座为以利亚。」</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 1:17; 但以理书 10:15–19; 马可福音 16:5–8"> 彼得不知道说什么才好，因为他们甚是惧怕。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得后书 1:17; 马太福音 3:17; 马可福音 1:11"> 有一朵云彩来遮盖他们；也有声音从云彩里出来，说：「这是我的爱子，你们要听他。」</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 10:16; 使徒行传 8:39–40; 路加福音 24:31"> 门徒忽然周围一看，不再见一人，只见耶稣同他们在那里。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 12:40; 马太福音 17:9–13; 马可福音 5:43"> 下山的时候，耶稣嘱咐他们说：「人子还没有从死里复活，你们不要将所看见的告诉人。」</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 17:18; 路加福音 24:7–8; 路加福音 18:33–34"> 门徒将这话存记在心，彼此议论「从死里复活」是什么意思。</span>
<span className="v" id="v11" data-v="11" data-xref="玛拉基书 4:5; 玛拉基书 3:1; 马太福音 11:14"> 他们就问耶稣说：「文士为什么说以利亚必须先来？」</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 53:1–12; 以赛亚书 50:6; 以赛亚书 52:14"> 耶稣说：「以利亚固然先来复兴万事；经上不是指着人子说，他要受许多的苦被人轻慢呢？</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 14:3–11; 马太福音 17:12–13; 马太福音 11:14"> 我告诉你们，以利亚已经来了，他们也任意待他，正如经上所指着他的话。」</span>
</div>
</div>

## 治好被污鬼附身的孩子

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 9:37–42; 马太福音 17:14–20; 路加福音 11:53–54"> 耶稣到了门徒那里，看见有许多人围着他们，又有文士和他们辩论。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 34:30; 马可福音 9:2–3"> 众人一见耶稣，都甚希奇，就跑上去问他的安。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 5:30–32; 马可福音 8:11"> 耶稣问他们说：「你们和他们辩论的是什么？」</span>
<span className="v" id="v17" data-v="17" data-xref="马可福音 9:25; 路加福音 11:14; 约翰福音 4:47"> 众人中间有一个人回答说：「夫子，我带了我的儿子到你这里来，他被哑巴鬼附着。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 17:19–20; 马可福音 11:23; 马太福音 17:16"> 无论在哪里，鬼捉弄他，把他摔倒，他就口中流沫，咬牙切齿，身体枯干。我请过你的门徒把鬼赶出去，他们却是不能。」</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 14:11; 约翰福音 20:27; 民数记 14:27"> 耶稣说：「嗳！不信的世代啊，我在你们这里要到几时呢？我忍耐你们要到几时呢？把他带到我这里来吧。」</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 1:26; 路加福音 4:35; 约翰福音 8:44"> 他们就带了他来。他一见耶稣，鬼便叫他重重地抽风，倒在地上，翻来覆去，口中流沫。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 9:33; 使徒行传 4:22; 马可福音 5:25"> 耶稣问他父亲说：「他得这病有多少日子呢？」回答说：「从小的时候。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 15:22–28; 马可福音 5:19; 马太福音 20:34"> 鬼屡次把他扔在火里、水里，要灭他。你若能做什么，求你怜悯我们，帮助我们。」</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 11:40; 希伯来书 11:6; 马可福音 11:23"> 耶稣对他说：「你若能信，在信的人，凡事都能。」</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 17:5; 希伯来书 12:2; 以弗所书 2:8"> 孩子的父亲立时喊着说<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷：立时流泪地喊着说">b</a></sup>：「我信！但我信不足，求主帮助。」</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 16:18; 路加福音 9:42; 马可福音 9:15"> 耶稣看见众人都跑上来，就斥责那污鬼，说：「你这聋哑的鬼，我吩咐你从他里头出来，再不要进去！」</span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 9:20; 马可福音 1:26; 马可福音 9:18"> 那鬼喊叫，使孩子大大地抽了一阵风，就出来了。孩子好像死了一般，以致众人多半说：「他是死了。」</span>
<span className="v" id="v27" data-v="27" data-xref="马可福音 1:31; 使徒行传 3:7; 马可福音 1:41"> 但耶稣拉着他的手，扶他起来，他就站起来了。</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 17:19–20; 马可福音 7:17; 马太福音 15:15"> 耶稣进了屋子，门徒就暗暗地问他说：「我们为什么不能赶出他去呢？」</span>
<span className="v" id="v29" data-v="29" data-xref="雅各书 5:15; 但以理书 9:3; 马太福音 17:20"> 耶稣说：「非用祷告<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有古卷加：禁食二字">c</a></sup>，这一类的鬼总不能出来<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或译：不能赶他出来">d</a></sup>。」</span>
</div>
</div>

## 耶稣第二次预言受难和复活

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="马太福音 17:22–23; 路加福音 9:43–45; 马可福音 6:31–32"> 他们离开那地方，经过加利利；耶稣不愿意人知道。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 16:21; 马可福音 9:12; 路加福音 24:44–46"> 于是教训门徒，说：「人子将要被交在人手里，他们要杀害他；被杀以后，过三天他要复活。」</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 2:50; 路加福音 9:45; 路加福音 18:34"> 门徒却不明白这话，又不敢问他。</span>
</div>
</div>

## 谁最伟大

<div className="bt">
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 18:1–5; 希伯来书 4:13; 路加福音 9:46–48"> 他们来到迦百农。耶稣在屋里问门徒说：「你们在路上议论的是什么？」</span>
<span className="v" id="v34" data-v="34" data-xref="马可福音 9:50; 马太福音 20:21–24; 马太福音 18:1–5"> 门徒不作声，因为他们在路上彼此争论谁为大。</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 20:25–28; 马可福音 10:42–45; 路加福音 22:26"> 耶稣坐下，叫十二个门徒来，说：「若有人愿意作首先的，他必作众人末后的，作众人的用人。」</span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 10:16; 马太福音 19:14–15; 马太福音 18:2"> 于是领过一个小孩子来，叫他站在门徒中间，又抱起他来，对他们说：</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 18:3–5; 路加福音 10:16; 马太福音 10:40–42"> 「凡为我名接待一个像这小孩子的，就是接待我；凡接待我的，不是接待我，乃是接待那差我来的。」</span>
</div>
</div>

## 不敌挡我们就是帮助我们

<div className="bt">
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="路加福音 9:49–50; 民数记 11:26–29; 路加福音 11:19"> 约翰对耶稣说：「夫子，我们看见一个人奉你的名赶鬼，我们就禁止他，因为他不跟从我们。」</span>
<span className="v" id="v39" data-v="39" data-xref="哥林多前书 12:3; 哥林多前书 13:1–2; 马太福音 13:28–29"> 耶稣说：「不要禁止他；因为没有人奉我名行异能，反倒轻易毁谤我。</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 12:30; 路加福音 11:23"> 不敌挡我们的，就是帮助我们的。</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 10:42; 马太福音 25:40; 哥林多前书 15:23"> 凡因你们是属基督，给你们一杯水喝的，我实在告诉你们，他不能不得赏赐。」</span>
</div>

## 罪的诱惑

<div className="bt">
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="马太福音 18:6; 路加福音 17:1–2; 马太福音 18:10"> 「凡使这信我的一个小子跌倒的，倒不如把大磨石拴在这人的颈项上，扔在海里。</span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 5:29–30; 马太福音 18:8–9; 马太福音 25:41"> 倘若你一只手叫你跌倒，就把它砍下来；</span>
<span className="v" id="v44" data-v="44"> 你缺了肢体进入永生，强如有两只手落到地狱，入那不灭的火里去。</span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 18:8; 马太福音 5:22; 马可福音 9:43"> 倘若你一只脚叫你跌倒，就把它砍下来；</span>
<span className="v" id="v46" data-v="46"> 你瘸腿进入永生，强如有两只脚被丢在地狱里。</span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 18:9; 马可福音 9:43; 马太福音 5:22"> 倘若你一只眼叫你跌倒，就去掉它；你只有一只眼进入 神的国，强如有两只眼被丢在地狱里。</span>
<span className="v" id="v48" data-v="48" data-xref="以赛亚书 66:24; 马可福音 9:43–45; 马太福音 25:41"> 在那里，虫是不死的，火是不灭的。</span>
<span className="v" id="v49" data-v="49" data-xref="利未记 2:13; 以西结书 43:24"> 因为必用火当盐腌各人。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="有古卷加：凡祭物必用盐腌。">e</a></sup></span>
<span className="v" id="v50" data-v="50" data-xref="歌罗西书 4:6; 罗马书 12:18; 马太福音 5:13"> 盐本是好的，若失了味，可用什么叫它再咸呢？你们里头应当有盐，彼此和睦。」</span>
</div>

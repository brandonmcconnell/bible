## 在伯大尼受膏

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="路加福音 7:37–39; 约翰福音 12:1–8; 约翰福音 11:2"> 耶稣在伯大尼长大麻风的西门家里坐席的时候，有一个女人拿着一玉瓶至贵的真哪哒香膏来，打破玉瓶，把膏浇在耶稣的头上。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 12:4–5; 马太福音 26:8–9; 玛拉基书 1:12–13"> 有几个人心中很不喜悦，说：「何用这样枉费香膏呢？</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 13:29; 以弗所书 4:28; 哥林多前书 10:10"> 这香膏可以卖三十多两银子周济穷人。」他们就向那女人生气。</span>
<span className="v" id="v6" data-v="6" data-xref="提多书 3:14; 希伯来书 10:24; 希伯来书 13:21"> 耶稣说：「由她吧！为什么难为她呢？她在我身上做的是一件美事。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 15:11; 马太福音 26:11; 雅各书 2:14–16"> 因为常有穷人和你们同在，要向他们行善随时都可以；只是你们不常有我。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 8:12; 约翰福音 12:7; 马可福音 15:42–1"> 她所做的，是尽她所能的；她是为我安葬的事把香膏预先浇在我身上。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 26:12–13; 马可福音 16:15; 马太福音 24:14"> 我实在告诉你们，普天之下，无论在什么地方传这福音，也要述说这女人所做的，以为记念。」</span>
</div>
</div>

## 和门徒同度逾越节

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及记 12:6; 出埃及记 12:18; 马太福音 26:17–19"> 除酵节的第一天，就是宰逾越羊羔的那一天，门徒对耶稣说：「你吃逾越节的筵席要我们往哪里去预备呢？」</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 22:10–13; 马太福音 26:18–19; 路加福音 19:30–33"> 耶稣就打发两个门徒，对他们说：「你们进城去，必有人拿着一瓶水迎面而来，你们就跟着他。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 3:20; 马可福音 11:3; 约翰福音 13:13"> 他进哪家去，你们就对那家的主人说：『夫子说：客房在哪里？我与门徒好在那里吃逾越节的筵席。』</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 1:13; 诗篇 110:3; 箴言 21:1–2"> 他必指给你们摆设整齐的一间大楼，你们就在那里为我们预备。」</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 16:4; 路加福音 22:13; 路加福音 22:35"> 门徒出去，进了城，所遇见的正如耶稣所说的。他们就预备了逾越节的筵席。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 22:14; 约翰福音 13:21–26; 马太福音 26:20–24"> 到了晚上，耶稣和十二个门徒都来了。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 41:9; 约翰福音 6:47; 约翰福音 6:70"> 他们坐席正吃的时候，耶稣说：「我实在告诉你们，你们中间有一个与我同吃的人要卖我了。」</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 22:21–23; 马太福音 26:22; 约翰福音 13:22"> 他们就忧愁起来，一个一个地问他说：「是我吗？」</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 13:26; 马太福音 26:23; 约翰福音 6:71"> 耶稣对他们说：「是十二个门徒中同我蘸手在盘子里的那个人。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 26:24–25; 以赛亚书 53:1–12; 约翰福音 19:28"> 人子必要去世，正如经上指着他所写的；但卖人子的人有祸了！那人不生在世上倒好。」</span>
</div>
</div>

## 在客西马尼祷告

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马可福音 14:36; 马可福音 14:39; 诗篇 18:5–6"> 他们来到一个地方，名叫客西马尼。耶稣对门徒说：「你们坐在这里，等我祷告。」</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 22:44; 希伯来书 5:7; 马可福音 5:37"> 于是带着彼得、雅各、约翰同去，就惊恐起来，极其难过，</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 12:27; 马可福音 13:35–37; 彼得前书 5:8"> 对他们说：「我心里甚是忧伤，几乎要死；你们在这里等候，警醒。」</span>
<span className="v" id="v35" data-v="35" data-xref="马可福音 14:41; 申命记 9:18; 希伯来书 5:7"> 他就稍往前走，俯伏在地，祷告说：「倘若可行，便叫那时候过去。」</span>
<span className="v" id="v36" data-v="36" data-xref="加拉太书 4:6; 罗马书 8:15–16; 约翰福音 5:30"> 他说：「阿爸！父啊！在你凡事都能；求你将这杯撤去。然而，不要从我的意思，只要从你的意思。」</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 26:40; 马可福音 14:29–31; 希伯来书 12:3"> 耶稣回来，见他们睡着了，就对彼得说：「西门，你睡觉吗？不能警醒片时吗？</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 26:41; 马太福音 24:42; 路加福音 21:36"> 总要警醒祷告，免得入了迷惑。你们心灵固然愿意，肉体却软弱了。」</span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 26:42–44; 哥林多后书 12:8; 马太福音 6:7"> 耶稣又去祷告，说的话还是与先前一样，</span>
<span className="v" id="v40" data-v="40" data-xref="马可福音 9:33–34; 罗马书 3:19; 创世记 44:16"> 又来见他们睡着了，因为他们的眼睛甚是困倦；他们也不知道怎么回答。</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 14:35; 马可福音 9:31; 约翰福音 17:1"> 第三次来，对他们说：「现在你们仍然睡觉安歇吧<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="吧：或译吗？">a</a></sup>！够了，时候到了。看哪，人子被卖在罪人手里了。</span>
<span className="v" id="v42" data-v="42" data-xref="马太福音 26:46; 约翰福音 18:1–2"> 起来！我们走吧。看哪，那卖我的人近了！」</span>
</div>
</div>

## 耶稣被捕

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="约翰福音 18:3–11; 路加福音 22:47–53; 马太福音 26:47–56"> 说话之间，忽然那十二个门徒里的犹大来了，并有许多人带着刀棒，从祭司长和文士并长老那里与他同来。</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 26:48–50; 箴言 27:6; 诗篇 55:20–21"> 卖耶稣的人曾给他们一个暗号，说：「我与谁亲嘴，谁就是他。你们把他拿住，牢牢靠靠地带去。」</span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 23:7–10; 玛拉基书 1:6; 马可福音 12:14"> 犹大来了，随即到耶稣跟前，说：「拉比」，便与他亲嘴。</span>

## 彼得三次不认主

<div className="bt">
<div className="bp">
<span className="v" id="v66" data-v="66" data-xref="马可福音 14:54; 马太福音 26:69–75; 约翰福音 18:25–27"> 彼得在下边院子里；来了大祭司的一个使女，</span>
<span className="v" id="v67" data-v="67" data-xref="马可福音 14:54; 马可福音 10:47; 马太福音 2:23"> 见彼得烤火，就看着他，说：「你素来也是同拿撒勒人耶稣一伙的。」</span>
<span className="v" id="v68" data-v="68" data-xref="马可福音 14:29–31; 马太福音 26:71–72; 约翰福音 13:36–38"> 彼得却不承认，说：「我不知道，也不明白你说的是什么。」于是出来，到了前院，鸡就叫了。</span>

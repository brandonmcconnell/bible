## 灾难的起头

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马太福音 21:1; 马可福音 4:34; 马可福音 14:33"> 耶稣在橄榄山上对圣殿而坐。彼得、雅各、约翰，和安得烈暗暗地问他说：</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 1:6–7; 马太福音 24:3; 但以理书 12:6"> 「请告诉我们，什么时候有这些事呢？这一切事将成的时候有什么预兆呢？」</span>
<span className="v" id="v5" data-v="5" data-xref="歌罗西书 2:8; 以弗所书 5:6; 耶利米书 29:8"> 耶稣说：「你们要谨慎，免得有人迷惑你们。</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 13:22; 耶利米书 23:21–25; 约翰福音 8:24"> 将来有好些人冒我的名来，说：『我是基督』，并且要迷惑许多人。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 21:9–11; 约翰福音 14:27; 马太福音 24:6–7"> 你们听见打仗和打仗的风声，不要惊慌。这些事是必须有的，只是末期还没有到。</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 24:8; 以赛亚书 37:3; 诗篇 48:6"> 民要攻打民，国要攻打国；多处必有地震、饥荒。这都是灾难<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="灾难：原文是生产之难">a</a></sup>的起头。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 10:17–18; 约翰福音 16:2; 腓立比书 1:29"> 但你们要谨慎；因为人要把你们交给公会，并且你们在会堂里要受鞭打，又为我的缘故站在诸侯与君王面前，对他们作见证。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 24:14; 歌罗西书 1:23; 罗马书 10:18"> 然而，福音必须先传给万民。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 21:14–15; 路加福音 12:11–12; 马太福音 10:19–21"> 人把你们拉去交官的时候，不要预先思虑说什么；到那时候，赐给你们什么话，你们就说什么；因为说话的不是你们，乃是圣灵。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 10:21; 路加福音 12:52–53; 路加福音 21:16"> 弟兄要把弟兄，父亲要把儿子，送到死地；儿女要起来与父母为敌，害死他们；</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 15:18–19; 马太福音 10:22; 马太福音 24:13"> 并且你们要为我的名被众人恨恶。惟有忍耐到底的，必然得救。」</span>
</div>
</div>

## 大灾难

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="但以理书 9:27; 但以理书 12:11; 但以理书 11:31"> 「你们看见那行毁坏可憎的，站在不当站的地方（读这经的人须要会意）。那时，在犹太的，应当逃到山上；</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 17:31–33; 希伯来书 11:7; 腓立比书 3:7–8"> 在房上的，不要下来，也不要进去拿家里的东西；</span>
<span className="v" id="v16" data-v="16"> 在田里的，也不要回去取衣裳。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米哀歌 4:10; 路加福音 23:29; 何西阿书 9:14"> 当那些日子，怀孕的和奶孩子的有祸了！</span>
<span className="v" id="v18" data-v="18"> 你们应当祈求，叫这些事不在冬天临到。</span>
<span className="v" id="v19" data-v="19" data-xref="但以理书 12:1; 约珥书 2:2; 马太福音 24:21"> 因为在那些日子必有灾难，自从 神创造万物直到如今，并没有这样的灾难，后来也必没有。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 24:22; 撒迦利亚书 13:8–9; 以赛亚书 65:8–9"> 若不是主减少那日子，凡有血气的，总没有一个得救的；只是为主的选民，他将那日子减少了。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 21:8; 马太福音 24:23–25; 马太福音 24:5"> 那时若有人对你们说：『看哪，基督在这里』，或说：『基督在那里』，你们不要信！</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 24:24; 帖撒罗尼迦后书 2:8–14; 马可福音 13:6"> 因为假基督、假先知将要起来，显神迹奇事，倘若能行，就把选民迷惑了。</span>
<span className="v" id="v23" data-v="23" data-xref="彼得后书 3:17; 马可福音 13:5; 约翰福音 14:29"> 你们要谨慎。看哪，凡事我都预先告诉你们了。」</span>
</div>
</div>

## 人子的降临

<div className="bt">
<div className="bp poetry">
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 13:10; 使徒行传 2:19–20; 启示录 6:12–14"> <span className="pl pl-1">「在那些日子，那灾难以后，</span><br /><span className="pl pl-1">日头要变黑了，</span><br /><span className="pl pl-1">月亮也不放光，</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 34:4; 启示录 6:13"> <span className="pl pl-1">众星要从天上坠落，</span><br /><span className="pl pl-1">天势都要震动。</span></span>
<span className="v" id="v26" data-v="26" data-xref="启示录 1:7; 马太福音 16:27; 马太福音 24:30"> 那时，他们<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="马太二十四章三十节是地上的万族">b</a></sup>要看见人子有大能力、大荣耀，驾云降临。</span>
<span className="v" id="v27" data-v="27" data-xref="撒迦利亚书 2:6; 马太福音 24:31; 申命记 30:4"> 他要差遣天使，把他的选民，从四方<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="方：原文是风">c</a></sup>，从地极直到天边，都招聚了来。」</span>
</div>

## 从无花果树学个比方

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 21:29–31; 马太福音 24:32–33"> 「你们可以从无花果树学个比方：当树枝发嫩长叶的时候，你们就知道夏天近了。</span>
<span className="v" id="v29" data-v="29" data-xref="彼得前书 4:17–18; 雅各书 5:9; 以西结书 12:25–28"> 这样，你们几时看见这些事成就，也该知道人子<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="人子：或译 神的国">d</a></sup>近了，正在门口了。</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 24:34; 路加福音 21:32; 马太福音 16:28"> 我实在告诉你们，这世代还没有过去，这些事都要成就。</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 40:8; 以赛亚书 51:6; 马太福音 24:35"> 天地要废去，我的话却不能废去。」</span>
</div>
</div>

## 那日那时没有人知道

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行传 1:7; 马太福音 24:36–42; 马太福音 25:13"> 「但那日子，那时辰，没有人知道，连天上的使者也不知道，子也不知道，惟有父知道。</span>
<span className="v" id="v33" data-v="33" data-xref="以弗所书 6:18; 路加福音 12:40; 罗马书 13:11–12"> 你们要谨慎，警醒祈祷，因为你们不晓得那日期几时来到。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 25:14–30; 约翰福音 10:3; 路加福音 12:36–40"> 这事正如一个人离开本家，寄居外邦，把权柄交给仆人，分派各人当做的工，又吩咐看门的警醒。</span>
<span className="v" id="v35" data-v="35" data-xref="马可福音 13:33; 马太福音 24:42; 马太福音 24:44"> 所以，你们要警醒；因为你们不知道家主什么时候来，或晚上，或半夜，或鸡叫，或早晨；</span>
<span className="v" id="v36" data-v="36" data-xref="帖撒罗尼迦前书 5:6–7; 罗马书 13:11–14; 马太福音 24:48–51"> 恐怕他忽然来到，看见你们睡着了。</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 13:33; 路加福音 12:41–46; 马可福音 13:35"> 我对你们所说的话，也是对众人说：要警醒！」</span>
</div>
</div>

## 拿撒勒人厌弃耶稣

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 4:16–30; 马太福音 13:54–58; 马太福音 2:23"> 耶稣离开那里，来到自己的家乡；门徒也跟从他。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 7:15; 约翰福音 6:42; 使徒行传 4:13–14"> 到了安息日，他在会堂里教训人。众人听见，就甚希奇，说：「这人从哪里有这些事呢？所赐给他的是什么智慧？他手所做的是何等的异能呢？</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 12:46; 马太福音 13:55–57; 约翰福音 6:42"> 这不是那木匠吗？不是马利亚的儿子雅各、约西、犹大、西门的长兄吗？他妹妹们不也是在我们这里吗？」他们就厌弃他<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="厌弃他：原文是因他跌倒">a</a></sup>。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 4:44; 路加福音 4:24; 马太福音 13:57"> 耶稣对他们说：「大凡先知，除了本地、亲属、本家之外，没有不被人尊敬的。」</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 13:58; 马可福音 9:23; 马可福音 5:23"> 耶稣就在那里不得行什么异能，不过按手在几个病人身上，治好他们。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 9:35; 马太福音 8:10; 路加福音 13:22"> 他也诧异他们不信，就往周围乡村教训人去了。</span>
</div>
</div>

## 耶稣差遣十二门徒

<div className="bt">
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="传道书 4:9–10; 路加福音 10:17–20; 马太福音 10:1–5"> 耶稣叫了十二个门徒来，差遣他们两个两个地出去，也赐给他们权柄，制伏污鬼；</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 9:3; 马太福音 10:9–10; 路加福音 10:4"> 并且嘱咐他们：「行路的时候不要带食物和口袋，腰袋里也不要带钱，除了拐杖以外，什么都不要带；</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 12:8; 以弗所书 6:15"> 只要穿鞋，也不要穿两件褂子」；</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 10:7–8; 路加福音 9:4; 马太福音 10:11–13"> 又对他们说：「你们无论到何处，进了人的家，就住在那里，直到离开那地方。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 10:14–15; 使徒行传 18:6; 路加福音 10:10–15"> 何处的人不接待你们，不听你们，你们离开那里的时候，就把脚上的尘土跺下去，对他们作见证。」</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 4:17; 路加福音 13:3; 使徒行传 20:21"> 门徒就出去传道，叫人悔改，</span>
<span className="v" id="v13" data-v="13" data-xref="雅各书 5:14–15; 马可福音 6:7; 路加福音 10:17"> 又赶出许多的鬼，用油抹了许多病人，治好他们。</span>
</div>
</div>

## 施洗约翰的死

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 9:7–9; 马可福音 6:14–29; 路加福音 23:7–12"> 耶稣的名声传扬出来。希律王听见了，就说：「施洗的约翰从死里复活了，所以这些异能由他里面发出来。」</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 16:14; 玛拉基书 4:5; 马太福音 21:11"> 但别人说：「是以利亚。」又有人说：「是先知，正像先知中的一位。」</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 11:10–13; 马太福音 27:4; 路加福音 9:9"> 希律听见却说：「是我所斩的约翰，他复活了。」</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 3:19–20; 马太福音 11:2; 路加福音 3:1"> 先是希律为他兄弟腓力的妻子希罗底的缘故，差人去拿住约翰，锁在监里，因为希律已经娶了那妇人。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 20:21; 利未记 18:16; 列王纪上 22:14"> 约翰曾对希律说：「你娶你兄弟的妻子是不合理的。」</span>
<span className="v" id="v19" data-v="19" data-xref="传道书 7:9; 以弗所书 4:26–27; 创世记 39:17–20"> 于是希罗底怀恨他，想要杀他，只是不能；</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 21:26; 马太福音 14:5; 历代志下 24:15–22"> 因为希律知道约翰是义人，是圣人，所以敬畏他，保护他，听他讲论，就多照着行<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷：游移不定">b</a></sup>，并且乐意听他。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯帖记 2:18; 创世记 40:20; 彼得前书 4:3"> 有一天，恰巧是希律的生日，希律摆设筵席，请了大臣和千夫长，并加利利作首领的。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯帖记 1:10–12; 马太福音 14:6; 但以理书 5:2"> 希罗底的女儿进来跳舞，使希律和同席的人都欢喜。王就对女子说：「你随意向我求什么，我必给你。」</span>
<span className="v" id="v23" data-v="23" data-xref="以斯帖记 7:2; 以斯帖记 5:3; 以斯帖记 5:6"> 又对她起誓说：「随你向我求什么，就是我国的一半，我也必给你。」</span>
<span className="v" id="v24" data-v="24" data-xref="约伯记 31:31; 以西结书 19:2–3; 创世记 27:8–11"> 她就出去对她母亲说：「我可以求什么呢？」她母亲说：「施洗约翰的头。」</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 3:15; 民数记 7:19–89; 民数记 7:13"> 她就急忙进去见王，求他说：「我愿王立时把施洗约翰的头放在盘子里给我。」</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 27:24–25; 马太福音 14:9; 马太福音 27:3–5"> 王就甚忧愁；但因他所起的誓，又因同席的人，就不肯推辞，</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 14:10–11"> 随即差一个护卫兵，吩咐拿约翰的头来。护卫兵就去，在监里斩了约翰，</span>
<span className="v" id="v28" data-v="28"> 把头放在盘子里，拿来给女子，女子就给她母亲。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 14:12; 历代志下 24:16; 马太福音 27:57–60"> 约翰的门徒听见了，就来把他的尸首领去，葬在坟墓里。</span>
</div>
</div>

## 耶稣给五千人吃饱

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 9:10; 路加福音 10:17; 马太福音 10:2"> 使徒聚集到耶稣那里，将一切所做的事、所传的道全告诉他。</span>
<span className="v" id="v31" data-v="31" data-xref="马可福音 3:20; 约翰福音 6:1; 马可福音 1:45"> 他就说：「你们来，同我暗暗地到旷野地方去歇一歇。」这是因为来往的人多，他们连吃饭也没有工夫。</span>
<span className="v" id="v32" data-v="32" data-xref="马可福音 8:2–9; 马可福音 6:45; 马可福音 4:36"> 他们就坐船，暗暗地往旷野地方去。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 6:2; 马太福音 15:29–31; 马可福音 6:54–55"> 众人看见他们去，有许多认识他们的，就从各城步行，一同跑到那里，比他们先赶到了。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 9:36; 路加福音 9:11; 民数记 27:17"> 耶稣出来，见有许多的人，就怜悯他们，因为他们如同羊没有牧人一般，于是开口教训他们许多道理。</span>
<span className="v" id="v35" data-v="35" data-xref="约翰福音 6:5–15; 路加福音 9:12–17; 马太福音 14:15–21"> 天已经晚了，门徒进前来，说：「这是野地，天已经晚了，</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 15:23; 马可福音 3:21; 马可福音 5:31"> 请叫众人散开，他们好往四面乡村里去，自己买什么吃。」</span>
<span className="v" id="v37" data-v="37" data-xref="列王纪下 4:42–44; 马太福音 15:32–33; 马可福音 8:2–3"> 耶稣回答说：「你们给他们吃吧。」门徒说：「我们可以去买二十两银子的饼给他们吃吗？」</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 15:34; 马可福音 8:5; 约翰福音 6:9"> 耶稣说：「你们有多少饼，可以去看看。」他们知道了，就说：「五个饼，两条鱼。」</span>
<span className="v" id="v39" data-v="39" data-xref="哥林多前书 14:40; 哥林多前书 14:33; 马太福音 15:35"> 耶稣吩咐他们，叫众人一帮一帮地坐在青草地上。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 9:14–15"> 众人就一排一排地坐下，有一百一排的，有五十一排的。</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 14:19; 马可福音 7:34; 路加福音 9:16"> 耶稣拿着这五个饼，两条鱼，望着天祝福，擘开饼，递给门徒，摆在众人面前，也把那两条鱼分给众人。</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 9:17; 马可福音 8:8–9; 马太福音 15:37–38"> 他们都吃，并且吃饱了。</span>
<span className="v" id="v43" data-v="43" data-xref="马可福音 8:19–20"> 门徒就把碎饼碎鱼收拾起来，装满了十二个篮子。</span>
<span className="v" id="v44" data-v="44"> 吃饼的男人共有五千。</span>
</div>
</div>

## 耶稣在海上行走

<div className="bt">
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="马太福音 14:22–33; 约翰福音 6:15–21; 马可福音 6:32"> 耶稣随即催门徒上船，先渡到那边伯赛大去，等他叫众人散开。</span>
<span className="v" id="v46" data-v="46" data-xref="马可福音 1:35; 马太福音 6:6; 路加福音 6:12"> 他既辞别了他们，就往山上去祷告。</span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 14:23; 约翰福音 6:16–17"> 到了晚上，船在海中，耶稣独自在岸上；</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 24:28; 路加福音 12:38; 约伯记 9:8"> 看见门徒因风不顺，摇橹甚苦。夜里约有四更天，就在海面上走，往他们那里去，意思要走过他们去。</span>
<span className="v" id="v49" data-v="49" data-xref="马太福音 14:25–26; 路加福音 24:37; 约伯记 9:8"> 但门徒看见他在海面上走，以为是鬼怪，就喊叫起来；</span>
<span className="v" id="v50" data-v="50" data-xref="马太福音 14:27; 约翰福音 6:19–20; 以赛亚书 43:2"> 因为他们都看见了他，且甚惊慌。耶稣连忙对他们说：「你们放心！是我，不要怕！」</span>
<span className="v" id="v51" data-v="51" data-xref="诗篇 93:3–4; 马可福音 4:39; 约翰福音 6:21"> 于是到他们那里，上了船，风就住了；他们心里十分惊奇。</span>
<span className="v" id="v52" data-v="52" data-xref="马可福音 8:17–21; 路加福音 24:25; 以赛亚书 63:17"> 这是因为他们不明白那分饼的事，心里还是愚顽。</span>
</div>
</div>

## 治好革尼撒勒的病人

<div className="bt">
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="马太福音 14:34–36; 约翰福音 6:24–25; 路加福音 5:1"> 既渡过去，来到革尼撒勒地方，就靠了岸，</span>
<span className="v" id="v54" data-v="54" data-xref="诗篇 9:10; 腓立比书 3:10"> 一下船，众人认得是耶稣，</span>
<span className="v" id="v55" data-v="55" data-xref="马太福音 4:24; 马可福音 2:1–3; 马可福音 3:7–11"> 就跑遍那一带地方，听见他在何处，便将有病的人用褥子抬到那里。</span>
<span className="v" id="v56" data-v="56" data-xref="马太福音 9:20; 路加福音 6:19; 民数记 15:38–39"> 凡耶稣所到的地方，或村中，或城里，或乡间，他们都将病人放在街市上，求耶稣只容他们摸他的衣裳 子；凡摸着的人就都好了。</span>
</div>

## 休妻的问题

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 10:40; 马可福音 4:2; 约翰福音 11:7"> 耶稣从那里起身，来到犹太的境界并约旦河外。众人又聚集到他那里，他又照常教训他们。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 7:10–11; 路加福音 11:53–54; 约翰福音 8:6"> 有法利赛人来问他说：「人休妻可以不可以？」意思要试探他。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 8:20; 加拉太书 4:21; 路加福音 10:25"> 耶稣回答说：「摩西吩咐你们的是什么？」</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 24:1–4; 马太福音 5:31–32; 以赛亚书 50:1"> 他们说：「摩西许人写了休书便可以休妻。」</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 19:8; 尼希米记 9:26; 使徒行传 7:51"> 耶稣说：「摩西因为你们的心硬，所以写这条例给你们；</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 1:27; 创世记 5:2; 创世记 1:1"> 但从起初创造的时候， 神造人是造男造女。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 2:24; 马太福音 19:5–6; 以弗所书 5:31"> 因此，人要离开父母，与妻子连合，二人成为一体。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 5:28; 创世记 2:24; 哥林多前书 6:16"> 既然如此，夫妻不再是两个人，乃是一体的了。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 7:1–3; 历代志上 7:10–13"> 所以， 神配合的，人不可分开。」</span>
<span className="v" id="v10" data-v="10" data-xref="马可福音 9:33; 马可福音 9:28; 马可福音 4:10"> 到了屋里，门徒就问他这事。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 5:31–32; 马太福音 19:9; 哥林多前书 7:10–11"> 耶稣对他们说：「凡休妻另娶的，就是犯奸淫，辜负他的妻子；</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 7:11; 哥林多前书 7:13"> 妻子若离弃丈夫另嫁，也是犯奸淫了。」</span>
</div>
</div>

## 耶稣为小孩祝福

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马太福音 19:13–15; 路加福音 18:15–17; 出埃及记 10:9–11"> 有人带着小孩子来见耶稣，要耶稣摸他们，门徒便责备那些人。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 19:14; 马太福音 18:10; 马太福音 18:4"> 耶稣看见就恼怒，对门徒说：「让小孩子到我这里来，不要禁止他们；因为在 神国的，正是这样的人。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 18:3; 路加福音 18:17; 约翰福音 3:3–6"> 我实在告诉你们，凡要承受 神国的，若不像小孩子，断不能进去。」</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 9:36; 以赛亚书 40:11; 约翰福音 21:15–17"> 于是抱着小孩子，给他们按手，为他们祝福。</span>
</div>
</div>

## 财主寻求永生之道

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 19:16–30; 路加福音 18:18–30; 罗马书 2:7"> 耶稣出来行路的时候，有一个人跑来，跪在他面前，问他说：「良善的夫子，我当做什么事才可以承受永生？」</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 18:19; 马太福音 19:17; 罗马书 3:12"> 耶稣对他说：「你为什么称我是良善的？除了 神一位之外，再没有良善的。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 20:12–17; 罗马书 13:9; 雅各书 2:11"> 诫命你是晓得的：不可杀人；不可奸淫；不可偷盗；不可作假见证；不可亏负人；当孝敬父母。」</span>
<span className="v" id="v20" data-v="20" data-xref="以西结书 33:31–32; 提摩太后书 3:5; 腓立比书 3:6"> 他对耶稣说：「夫子，这一切我从小都遵守了。」</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 6:19–21; 启示录 2:4; 路加福音 18:22"> 耶稣看着他，就爱他，对他说：「你还缺少一件：去变卖你所有的，分给穷人，就必有财宝在天上；你还要来跟从我。」</span>
<span className="v" id="v22" data-v="22" data-xref="约翰一书 2:15–16; 提摩太前书 6:9–10; 路加福音 12:15"> 他听见这话，脸上就变了色，忧忧愁愁地走了，因为他的产业很多。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 1:26; 路加福音 18:24; 马可福音 3:5"> 耶稣周围一看，对门徒说：「有钱财的人进 神的国是何等地难哪！」</span>
<span className="v" id="v24" data-v="24" data-xref="雅各书 5:1–3; 箴言 11:28; 诗篇 52:7"> 门徒希奇他的话。耶稣又对他们说：「小子，倚靠钱财的人进 神的国是何等地难哪！</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 19:24–25; 路加福音 18:25; 马太福音 23:24"> 骆驼穿过针的眼，比财主进 神的国还容易呢。」</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 16:31; 哥林多后书 11:23; 罗马书 10:9–13"> 门徒就分外希奇，对他说：「这样谁能得救呢？」</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 19:26; 耶利米书 32:27; 约伯记 42:2"> 耶稣看着他们，说：「在人是不能，在 神却不然，因为 神凡事都能。」</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 19:27–30; 路加福音 18:28–30; 路加福音 14:33"> 彼得就对他说：「看哪，我们已经撇下所有的跟从你了。」</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 9:23; 马太福音 5:10–11; 马可福音 8:35"> 耶稣说：「我实在告诉你们，人为我和福音撇下房屋，或是弟兄、姊妹、父母、儿女、田地，</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 18:30; 腓立比书 3:8; 哥林多后书 6:10"> 没有不在今世得百倍的，就是房屋、弟兄、姊妹、母亲、儿女、田地，并且要受逼迫，在来世必得永生。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 19:30; 路加福音 13:30; 马太福音 20:16"> 然而，有许多在前的，将要在后，在后的，将要在前。」</span>
</div>
</div>

## 耶稣第三次预言受难和复活

<div className="bt">
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马太福音 20:17–19; 路加福音 18:31–34; 路加福音 9:51"> 他们行路上耶路撒冷去。耶稣在前头走，门徒就希奇，跟从的人也害怕。耶稣又叫过十二个门徒来，把自己将要遭遇的事告诉他们说：</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 27:2; 马太福音 20:17–19; 马可福音 8:31"> 「看哪，我们上耶路撒冷去，人子将要被交给祭司长和文士，他们要定他死罪，交给外邦人。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 26:67; 马太福音 16:21; 马可福音 14:65"> 他们要戏弄他，吐唾沫在他脸上，鞭打他，杀害他。过了三天，他要复活。」</span>
</div>
</div>

## 雅各和约翰的要求

<div className="bt">
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 20:20–28; 撒母耳记下 14:4–11; 列王纪上 2:20"> 西庇太的儿子雅各、约翰进前来，对耶稣说：「夫子，我们无论求你什么，愿你给我们做。」</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 15:7; 列王纪上 3:5–15; 马可福音 10:51"> 耶稣说：「要我给你们做什么？」</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 19:28; 马可福音 16:19; 路加福音 24:26"> 他们说：「赐我们在你的荣耀里，一个坐在你右边，一个坐在你左边。」</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 12:50; 马太福音 20:21–22; 诗篇 75:8"> 耶稣说：「你们不知道所求的是什么。我所喝的杯，你们能喝吗？我所受的洗，你们能受吗？」</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 12:2; 启示录 1:9; 约翰福音 17:14"> 他们说：「我们能。」耶稣说：「我所喝的杯，你们也要喝；我所受的洗，你们也要受；</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 20:23; 马太福音 25:34; 约翰福音 17:24"> 只是坐在我的左右，不是我可以赐的，乃是为谁预备的，就赐给谁。」</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 20:24; 箴言 13:10; 罗马书 12:10"> 那十个门徒听见，就恼怒雅各、约翰。</span>
<span className="v" id="v42" data-v="42" data-xref="彼得前书 5:3; 路加福音 22:25; 马太福音 20:25"> 耶稣叫他们来，对他们说：「你们知道，外邦人有尊为君王的，治理他们，有大臣操权管束他们。</span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 23:8–12; 路加福音 14:11; 马可福音 9:35"> 只是在你们中间，不是这样。你们中间，谁愿为大，就必作你们的用人；</span>
<span className="v" id="v44" data-v="44"> 在你们中间，谁愿为首，就必作众人的仆人。</span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 20:28; 腓立比书 2:5–8; 哥林多后书 8:9"> 因为人子来，并不是要受人的服事，乃是要服事人，并且要舍命作多人的赎价。」</span>
</div>
</div>

## 治好瞎子巴底买

<div className="bt">
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="路加福音 18:35–1; 马太福音 20:29–34; 约翰福音 9:8"> 到了耶利哥；耶稣同门徒并许多人出耶利哥的时候，有一个讨饭的瞎子，是底买的儿子巴底买，坐在路旁。</span>
<span className="v" id="v47" data-v="47" data-xref="马可福音 1:24; 马太福音 9:27; 启示录 22:16"> 他听见是拿撒勒的耶稣，就喊着说：「大卫的子孙耶稣啊！可怜我吧！」</span>
<span className="v" id="v48" data-v="48" data-xref="耶利米书 29:13; 马可福音 7:26–29; 希伯来书 5:7"> 有许多人责备他，不许他作声。他却越发大声喊着说：「大卫的子孙哪，可怜我吧！」</span>
<span className="v" id="v49" data-v="49" data-xref="路加福音 18:40; 马太福音 20:32–34; 约翰福音 11:28"> 耶稣就站住，说：「叫过他来。」他们就叫那瞎子，对他说：「放心，起来！他叫你啦。」</span>
<span className="v" id="v50" data-v="50" data-xref="腓立比书 3:7–9; 希伯来书 12:1"> 瞎子就丢下衣服，跳起来，走到耶稣那里。</span>
<span className="v" id="v51" data-v="51" data-xref="路加福音 18:41–43; 马可福音 10:36; 马太福音 7:7"> 耶稣说：「要我为你做什么？」瞎子说：「拉波尼<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="就是夫子">a</a></sup>，我要能看见。」</span>
<span className="v" id="v52" data-v="52" data-xref="马太福音 9:22; 使徒行传 26:18; 马可福音 8:25"> 耶稣说：「你去吧！你的信救了你了。」瞎子立刻看见了，就在路上跟随耶稣。</span>
</div>

## 光荣地进耶路撒冷

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="马太福音 21:1–11; 约翰福音 12:14–19; 路加福音 19:29–40"> 耶稣和门徒将近耶路撒冷，到了伯法其和伯大尼，在橄榄山那里；耶稣就打发两个门徒，</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 21:2–3; 路加福音 19:30–31"> 对他们说：「你们往对面村子里去，一进去的时候，必看见一匹驴驹拴在那里，是从来没有人骑过的，可以解开，牵来。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 10:36; 马可福音 14:15; 诗篇 110:3"> 若有人对你们说：『为什么做这事？』你们就说：『主要用它。』那人必立时让你们牵来。」</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 26:19; 路加福音 19:32–34; 马太福音 21:6–7"> 他们去了，便看见一匹驴驹拴在门外街道上，就把它解开。</span>
<span className="v" id="v5" data-v="5"> 在那里站着的人，有几个说：「你们解驴驹做什么？」</span>
<span className="v" id="v6" data-v="6"> 门徒照着耶稣所说的回答，那些人就任凭他们牵去了。</span>
<span className="v" id="v7" data-v="7" data-xref="撒迦利亚书 9:9; 路加福音 19:35–36; 马太福音 21:7–8"> 他们把驴驹牵到耶稣那里，把自己的衣服搭在上面，耶稣就骑上。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 23:40"> 有许多人把衣服铺在路上，也有人把田间的树枝砍下来，铺在路上。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 118:25–26; 马太福音 21:9; 马太福音 23:39"> 前行后随的人都喊着说：<br /><span className="pl pl-1">和散那</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="和散那：原有求救的意思，在此乃是称颂的话">a</a></sup><br /><span className="pl pl-1">！</span><br /><span className="pl pl-1">奉主名来的是应当称颂的！</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以西结书 37:24–25; 路加福音 2:14; 路加福音 19:38–40"> <span className="pl pl-1">那将要来的我祖大卫之国是应当称颂的！</span><br /><span className="pl pl-1">高高在上和散那！</span></span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 8:1–2; 路加福音 19:41–45; 路加福音 21:37–38"> 耶稣进了耶路撒冷，入了圣殿，周围看了各样物件。天色已晚，就和十二个门徒出城，往伯大尼去了。</span>
</div>
</div>

## 咒诅无花果树

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 21:18–22; 马太福音 4:2; 约翰福音 19:28"> 第二天，他们从伯大尼出来，耶稣饿了。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 21:19; 路加福音 13:6–9; 以赛亚书 5:7"> 远远地看见一棵无花果树，树上有叶子，就往那里去，或者在树上可以找着什么。到了树下，竟找不着什么，不过有叶子，因为不是收无花果的时候。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 21:19; 马太福音 7:19; 马太福音 3:10"> 耶稣就对树说：「从今以后，永没有人吃你的果子。」他的门徒也听见了。</span>
</div>
</div>

## 洁净圣殿

<div className="bt">
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 2:13–17; 马太福音 21:12–16; 路加福音 19:45–47"> 他们来到耶路撒冷。耶稣进入圣殿，赶出殿里做买卖的人，推倒兑换银钱之人的桌子和卖鸽子之人的凳子；</span>
<span className="v" id="v16" data-v="16"> 也不许人拿着器具从殿里经过；</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 56:7; 耶利米书 7:11; 路加福音 19:46"> 便教训他们说：「经上不是记着说：<br /><span className="pl pl-1">我的殿必称为万国祷告的殿吗？</span><br /><span className="pl pl-1">你们倒使它成为贼窝了。」</span></span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 7:28; 马可福音 12:12; 马可福音 14:1–2"> 祭司长和文士听见这话，就想法子要除灭耶稣，却又怕他，因为众人都希奇他的教训。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 21:37; 马可福音 11:11; 约翰福音 12:36"> 每天晚上，耶稣出城去。</span>
</div>
</div>

## 从无花果树得教训

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马太福音 15:13; 马可福音 11:14; 约翰福音 15:6"> 早晨，他们从那里经过，看见无花果树连根都枯干了。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 3:33; 马太福音 23:7; 马太福音 25:41"> 彼得想起耶稣的话来，就对他说：「拉比，请看！你所咒诅的无花果树已经枯干了。」</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 62:8; 约翰福音 14:1; 马可福音 9:23"> 耶稣回答说：「你们当信服 神。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 17:20; 约翰福音 15:7; 马太福音 21:21"> 我实在告诉你们，无论何人对这座山说：『你挪开此地，投在海里！』他若心里不疑惑，只信他所说的必成，就必给他成了。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 21:22; 约翰一书 5:14–15; 约翰一书 3:22"> 所以我告诉你们，凡你们祷告祈求的，无论是什么，只要信是得着的，就必得着。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 6:14–15; 歌罗西书 3:13; 以弗所书 4:32"> 你们站着祷告的时候，若想起有人得罪你们，就当饶恕他，好叫你们在天上的父也饶恕你们的过犯。</span>
<span className="v" id="v26" data-v="26"> 你们若不饶恕人，你们在天上的父也不饶恕你们的过犯。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有古卷无此节">b</a></sup>」</span>
</div>
</div>

## 质问耶稣的权柄

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 20:1–8; 马太福音 21:23–27; 诗篇 2:1–5"> 他们又来到耶路撒冷。耶稣在殿里行走的时候，祭司长和文士并长老进前来，</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 2:14; 使徒行传 7:38–39; 民数记 16:3"> 问他说：「你仗着什么权柄做这些事？给你这权柄的是谁呢？」</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 20:3–8; 马太福音 21:24; 以赛亚书 52:13"> 耶稣对他们说：「我要问你们一句话，你们回答我，我就告诉你们我仗着什么权柄做这些事。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 3:1–20; 约翰福音 3:25–36; 马可福音 1:1–11"> 约翰的洗礼是从天上来的？是从人间来的呢？你们可以回答我。」</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 1:29; 约翰福音 1:34; 马太福音 21:31–32"> 他们彼此商议说：「我们若说『从天上来』，他必说：『这样，你们为什么不信他呢？』</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 21:46; 马可福音 12:12; 马太福音 14:5"> 若说『从人间来』，却又怕百姓，因为众人真以约翰为先知。」</span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 6:9–10; 哥林多后书 4:3–4; 帖撒罗尼迦后书 2:10–12"> 于是回答耶稣说：「我们不知道。」耶稣说：「我也不告诉你们我仗着什么权柄做这些事。」</span>
</div>

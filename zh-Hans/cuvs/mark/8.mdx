## 耶稣给四千人吃饱

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 15:32–39; 马可福音 6:34–44"> 那时，又有许多人聚集，并没有什么吃的。耶稣叫门徒来，说：</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 9:36; 弥迦书 7:19; 诗篇 103:13"> 「我怜悯这众人；因为他们同我在这里已经三天，也没有吃的了。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 40:31; 士师记 8:4–6; 撒母耳记上 30:10–12"> 我若打发他们饿着回家，就必在路上困乏，因为其中有从远处来的。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 4:42–44; 列王纪下 7:2; 马可福音 6:52"> 门徒回答说：「在这野地，从哪里能得饼，叫这些人吃饱呢？」</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 14:15–17; 马太福音 15:34; 路加福音 9:13"> 耶稣问他们说：「你们有多少饼？」他们说：「七个。」</span>
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 3:17; 马太福音 15:35–36; 约翰福音 6:10–11"> 他吩咐众人坐在地上，就拿着这七个饼祝谢了，擘开，递给门徒，叫他们摆开，门徒就摆在众人面前。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 14:19; 约翰福音 21:5; 路加福音 24:41–42"> 又有几条小鱼；耶稣祝了福，就吩咐也摆在众人面前。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪下 4:42–44; 诗篇 145:16; 马太福音 16:10"> 众人都吃，并且吃饱了，收拾剩下的零碎，有七筐子。</span>
<span className="v" id="v9" data-v="9"> 人数约有四千。耶稣打发他们走了，</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 15:39"> 随即同门徒上船，来到大玛努他境内。</span>
</div>
</div>

## 求主显个神迹

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 10:9; 马太福音 12:38; 申命记 6:16"> 法利赛人出来盘问耶稣，求他从天上显个神迹给他们看，想要试探他。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 12:39–40; 马可福音 7:34; 马太福音 16:4"> 耶稣心里深深地叹息，说：「这世代为什么求神迹呢？我实在告诉你们，没有神迹给这世代看。」</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 12:36; 使徒行传 13:45–46; 诗篇 81:12"> 他就离开他们，又上船往海那边去了。</span>
</div>
</div>

## 防备法利赛人和希律的酵

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 16:5"> 门徒忘了带饼；在船上除了一个饼，没有别的食物。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 5:6–8; 马太福音 16:6; 马太福音 16:11–12"> 耶稣嘱咐他们说：「你们要谨慎，防备法利赛人的酵和希律的酵。」</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 9:46; 路加福音 20:5; 马太福音 16:7–8"> 他们彼此议论说：「这是因为我们没有饼吧。」</span>
<span className="v" id="v17" data-v="17" data-xref="马可福音 6:52; 以赛亚书 63:17; 马可福音 2:8"> 耶稣看出来，就说：「你们为什么因为没有饼就议论呢？你们还不省悟，还不明白吗？你们的心还是愚顽吗？</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 28:26–27; 马太福音 13:14–15; 耶利米书 5:21"> 你们有眼睛，看不见吗？有耳朵，听不见吗？也不记得吗？</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 9:12–17; 马太福音 14:17–21; 约翰福音 6:5–13"> 我擘开那五个饼分给五千人，你们收拾的零碎装满了多少篮子呢？」他们说：「十二个。」</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 15:34–38; 马可福音 8:1–9"> 「又擘开那七个饼分给四千人，你们收拾的零碎装满了多少筐子呢？」他们说：「七个。」</span>
<span className="v" id="v21" data-v="21" data-xref="马可福音 6:52; 马太福音 16:11–12; 马可福音 8:12"> 耶稣说：「你们还是不明白吗？」</span>
</div>
</div>

## 治好伯赛大的瞎子

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马太福音 11:21; 马可福音 6:45; 路加福音 10:13"> 他们来到伯赛大，有人带一个瞎子来，求耶稣摸他。</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 7:33; 约翰福音 9:6–7; 马可福音 5:23"> 耶稣拉着瞎子的手，领他到村外，就吐唾沫在他眼睛上，按手在他身上，问他说：「你看见什么了？」</span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 32:3; 以赛亚书 29:18; 哥林多前书 13:9–12"> 他就抬头一看，说：「我看见人了；他们好像树木，并且行走。」</span>
<span className="v" id="v25" data-v="25" data-xref="彼得前书 2:9; 彼得后书 3:18; 箴言 4:18"> 随后又按手在他眼睛上，他定睛一看，就复了原，样样都看得清楚了。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 8:4; 马可福音 8:23; 马可福音 5:43"> 耶稣打发他回家，说：「连这村子你也不要进去。」</span>
</div>
</div>

## 彼得认耶稣为基督

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马太福音 16:13–20; 路加福音 9:18–20"> 耶稣和门徒出去，往凯撒利亚·腓立比村庄去；在路上问门徒说：「人说我是谁？」</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 1:21; 马太福音 14:2; 玛拉基书 4:5"> 他们说：「有人说是施洗的约翰；有人说是以利亚；又有人说是先知里的一位。」</span>
<span className="v" id="v29" data-v="29" data-xref="约翰一书 4:15; 马太福音 16:15–16; 约翰一书 5:1"> 又问他们说：「你们说我是谁？」彼得回答说：「你是基督。」</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 9:21; 马太福音 16:20; 马可福音 9:9"> 耶稣就禁戒他们，不要告诉人。</span>
</div>
</div>

## 耶稣预言受难和复活

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马可福音 10:33–34; 约翰福音 2:19; 路加福音 24:26"> 从此，他教训他们说：「人子必须受许多的苦，被长老、祭司长，和文士弃绝，并且被杀，过三天复活。」</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 16:22; 约翰福音 16:25; 约翰福音 16:29"> 耶稣明明地说这话，彼得就拉着他，劝他。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 4:10; 腓立比书 3:19; 约翰一书 2:15"> 耶稣转过来，看着门徒，就责备彼得说：「撒但，退我后边去吧！因为你不体贴 神的意思，只体贴人的意思。」</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 10:38; 路加福音 14:26–27; 约翰福音 10:27"> 于是叫众人和门徒来，对他们说：「若有人要跟从我，就当舍己，背起他的十字架来跟从我。</span>
<span className="v" id="v35" data-v="35" data-xref="提摩太后书 2:11–13; 哥林多前书 9:23; 路加福音 17:33"> 因为，凡要救自己生命<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：灵魂；下同">a</a></sup>的，必丧掉生命；凡为我和福音丧掉生命的，必救了生命。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 16:26; 路加福音 9:25; 诗篇 49:17"> 人就是赚得全世界，赔上自己的生命，有什么益处呢？</span>
<span className="v" id="v37" data-v="37" data-xref="诗篇 49:7–8; 彼得前书 1:18–19"> 人还能拿什么换生命呢？</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 12:8–9; 罗马书 1:16; 约翰一书 2:23"> 凡在这淫乱罪恶的世代，把我和我的道当作可耻的，人子在他父的荣耀里，同圣天使降临的时候，也要把那人当作可耻的。」</span>
</div>

## 但以理为同胞祷告

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理书 11:1; 但以理书 1:21; 但以理书 5:31–1"> 米底亚族亚哈随鲁的儿子大流士立为迦勒底国的王元年，</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 29:10; 耶利米书 25:11–12; 历代志下 36:21"> 就是他在位第一年，我—但以理从书上得知耶和华的话临到先知耶利米，论耶路撒冷荒凉的年数，七十年为满。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 33:3; 耶利米书 29:10–13; 雅各书 5:16–18"> 我便禁食，披麻蒙灰，定意向主 神祈祷恳求。</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 8:28; 出埃及记 20:6; 申命记 5:10"> 我向耶和华—我的 神祈祷、认罪，说：「主啊，大而可畏的 神，向爱主、守主诫命的人守约施慈爱。</span>
<span className="v" id="v5" data-v="5" data-xref="玛拉基书 3:7; 但以理书 9:11; 但以理书 9:15"> 我们犯罪作孽，行恶叛逆，偏离你的诫命典章，</span>
<span className="v" id="v6" data-v="6" data-xref="但以理书 9:10; 历代志下 36:15–16; 路加福音 20:10–12"> 没有听从你仆人众先知奉你名向我们君王、首领、列祖，和国中一切百姓所说的话。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 44:15; 耶利米书 3:25; 耶利米书 2:26–27"> 主啊，你是公义的，我们是脸上蒙羞的；因我们犹大人和耶路撒冷的居民，并以色列众人，或在近处，或在远处，被你赶到各国的人，都得罪了你，正如今日一样。</span>
<span className="v" id="v8" data-v="8" data-xref="但以理书 9:6–7; 耶利米哀歌 1:7–8; 耶利米哀歌 1:18"> 主啊，我们和我们的君王、首领、列祖因得罪了你，就都脸上蒙羞。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 1:6–8; 但以理书 9:7; 但以理书 9:5"> 主—我们的 神是怜悯饶恕人的，我们却违背了他，</span>
<span className="v" id="v10" data-v="10" data-xref="但以理书 9:6; 列王纪下 18:12; 尼希米记 9:13–17"> 也没有听从耶和华—我们 神的话，没有遵行他借仆人众先知向我们所陈明的律法。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 8:5–10; 以赛亚书 1:4–6; 申命记 28:15–68"> 以色列众人都犯了你的律法，偏行，不听从你的话；因此，在你仆人摩西律法上所写的咒诅和誓言都倾在我们身上，因我们得罪了 神。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 5:9; 耶利米哀歌 1:12; 约伯记 12:17"> 他使大灾祸临到我们，成就了警戒我们和审判我们官长的话；原来在普天之下未曾行过像在耶路撒冷所行的。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 28:15–68; 以赛亚书 9:13; 但以理书 9:11"> 这一切灾祸临到我们身上是照摩西律法上所写的，我们却没有求耶和华—我们 神的恩典，使我们回头离开罪孽，明白你的真理。</span>
<span className="v" id="v14" data-v="14" data-xref="但以理书 9:7; 尼希米记 9:33; 诗篇 51:14"> 所以耶和华留意使这灾祸临到我们身上，因为耶和华—我们的 神在他所行的事上都是公义；我们并没有听从他的话。</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米记 9:10; 出埃及记 32:11; 尼希米记 1:10"> 主—我们的 神啊，你曾用大能的手领你的子民出埃及地，使自己得了名，正如今日一样。我们犯了罪，作了恶。</span>
<span className="v" id="v16" data-v="16" data-xref="撒迦利亚书 8:3; 约珥书 3:17; 诗篇 87:1–3"> 主啊，求你按你的大仁大义，使你的怒气和忿怒转离你的城耶路撒冷，就是你的圣山。耶路撒冷和你的子民，因我们的罪恶和我们列祖的罪孽被四围的人羞辱。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 80:19; 耶利米哀歌 5:18; 哥林多后书 1:20"> 我们的 神啊，现在求你垂听仆人的祈祷恳求，为自己使脸光照你荒凉的圣所。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 37:17; 耶利米书 36:7; 列王纪下 19:16"> 我的 神啊，求你侧耳而听，睁眼而看，眷顾我们荒凉之地和称为你名下的城。我们在你面前恳求，原不是因自己的义，乃因你的大怜悯。</span>
<span className="v" id="v19" data-v="19" data-xref="但以理书 9:18; 以弗所书 1:12; 阿摩司书 7:2"> 求主垂听，求主赦免，求主应允而行，为你自己不要迟延。我的 神啊，因这城和这民都是称为你名下的。」</span>
</div>
</div>

## 加百列解释预言

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="诗篇 145:18; 但以理书 9:3–4; 罗马书 3:23"> 我说话，祷告，承认我的罪和本国之民以色列的罪，为我 神的圣山，在耶和华—我 神面前恳求。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:19; 但以理书 8:16; 列王纪上 18:36"> 我正祷告的时候，先前在异象中所见的那位加百列，奉命迅速飞来，约在献晚祭的时候，按手在我身上。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理书 9:24–27; 但以理书 10:21; 但以理书 8:16"> 他指教我说：「但以理啊，现在我出来要使你有智慧，有聪明。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理书 10:19; 马太福音 24:15; 但以理书 10:11–12"> 你初恳求的时候，就发出命令，我来告诉你，因你大蒙眷爱；所以你要思想明白这以下的事和异象。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 9:11–14; 罗马书 5:10; 耶利米书 23:5–6"> 「为你本国之民和你圣城，已经定了七十个七。要止住罪过，除净罪恶，赎尽罪孽，引进<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：彰显">a</a></sup>永义，封住异象和预言，并膏至圣者<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="者：或译所">b</a></sup>。</span>
<span className="v" id="v25" data-v="25" data-xref="以斯拉记 4:24; 以赛亚书 9:6; 以赛亚书 55:4"> 你当知道，当明白，从出令重新建造耶路撒冷，直到有受膏君的时候，必有七个七和六十二个七。正在艰难的时候，耶路撒冷城连街带濠都必重新建造。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 53:8; 那鸿书 1:8; 马可福音 13:2"> 过了六十二个七，那<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或译：有">c</a></sup>受膏者必被剪除，一无所有；必有一王的民来毁灭这城和圣所，至终必如洪水冲没。必有争战，一直到底，荒凉的事已经定了。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 24:15; 路加福音 21:20; 但以理书 12:11"> 一七之内，他必与许多人坚定盟约；一七之半，他必使祭祀与供献止息。那行毁坏可憎的<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或译：使地荒凉的">d</a></sup>如飞而来，并且有忿怒倾在那行毁坏的身上<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="或译：倾在那荒凉之地">e</a></sup>，直到所定的结局。」</span>
</div>

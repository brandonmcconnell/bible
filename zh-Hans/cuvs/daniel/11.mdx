<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理书 9:1; 但以理书 5:31; 但以理书 10:18"> 又说：「当米底亚王大流士元年，我曾起来扶助米迦勒，使他坚强。」</span>
<span className="v" id="v2" data-v="2" data-xref="以斯拉记 4:5–6; 但以理书 8:26; 启示录 21:5"> 现在我将真事指示你： 南方王和北方王 「波斯还有三王兴起，第四王必富足远胜诸王。他因富足成为强盛，就必激动大众攻击希腊国。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理书 11:16; 但以理书 11:36; 但以理书 8:21"> 必有一个勇敢的王兴起，执掌大权，随意而行。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理书 8:22; 但以理书 8:8; 耶利米书 12:17"> 他兴起的时候，他的国必破裂，向天的四方<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="方：原文是风">a</a></sup>分开，却不归他的后裔，治国的权势也都不及他；因为他的国必被拔出，归与他后裔之外的人。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 11:14; 但以理书 11:11; 但以理书 11:25"> 「南方的王必强盛，他将帅中必有一个比他更强盛，执掌权柄，他的权柄甚大。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理书 11:13; 但以理书 11:40; 但以理书 11:7"> 过些年后，他们必互相连合，南方王的女儿必就了北方王来立约；但这女子帮助之力存立不住，王和他所倚靠之力也不能存立。这女子和引导她来的，并生她的，以及当时扶助她的，都必交与死地。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 11:38–39; 但以理书 11:19–20; 以赛亚书 9:14"> 但这女子的本家<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是根">b</a></sup>必另生一子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="子：原文是枝">c</a></sup>继续王位，他必率领军队进入北方王的保障，攻击他们，而且得胜；</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 37:19; 以赛亚书 46:1–2; 耶利米书 43:12–13"> 并将他们的神像和铸成的偶像，与金银的宝器掠到埃及去。数年之内，他不去攻击北方的王。</span>
<span className="v" id="v9" data-v="9"> 北方的王<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原文是他">d</a></sup>必入南方王的国，却要仍回本地。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 51:42; 但以理书 11:7; 但以理书 11:26"> 「北方王<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原文是他">e</a></sup>的二子必动干戈，招聚许多军兵。这军兵前去，如洪水泛滥，又必再去争战，直到南方王的保障。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 8:7; 但以理书 11:5; 诗篇 33:16–17"> 南方王必发烈怒，出来与北方王争战，摆列大军；北方王的军兵必交付他手。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 12:22–23; 列王纪下 14:10; 以赛亚书 10:7–12"> 他的众军高傲，他的心也必自高；他虽使数万人仆倒，却不得常胜。</span>
<span className="v" id="v13" data-v="13" data-xref="但以理书 4:16; 但以理书 12:7; 但以理书 11:6–7"> 「北方王必回来摆列大军，比先前的更多。满了所定的年数，他必率领大军，带极多的军装来。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 17:17; 使徒行传 4:25–28"> 那时，必有许多人起来攻击南方王，并且你本国的强暴人必兴起，要应验那异象，他们却要败亡。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 6:6; 以西结书 17:17; 以西结书 4:2"> 北方王必来筑垒攻取坚固城；南方的军兵必站立不住，就是选择的精兵<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="原文是民">f</a></sup>也无力站住。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理书 8:9; 但以理书 11:36; 但以理书 11:3"> 来攻击他的，必任意而行，无人在北方王<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="原文是他">g</a></sup>面前站立得住。他必站在那荣美之地，用手施行毁灭。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 12:17; 以西结书 4:3; 以西结书 4:7"> 「他必定意用全国之力而来，立公正的约，照约而行，将自己的女儿给南方王为妻，想要败坏他<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="或译：埃及">h</a></sup>，这计却不得成就，与自己毫无益处。</span>
<span className="v" id="v18" data-v="18" data-xref="何西阿书 12:14; 耶利米书 31:10; 西番雅书 2:11"> 其后他必转回夺取了许多海岛。但有一大帅，除掉他令人受的羞辱，并且使这羞辱归他本身。</span>
<span className="v" id="v19" data-v="19" data-xref="以西结书 26:21; 诗篇 37:36; 约伯记 20:8"> 他就必转向本地的保障，却要绊跌仆倒，归于无有。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 60:17; 但以理书 11:7; 申命记 15:2–3"> 「那时，必有一人兴起接续他为王，使横征暴敛的人通行国中的荣美地。这王不多日就必灭亡，却不因忿怒，也不因争战。」</span>
</div>

## 北方的恶王

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="但以理书 11:34; 但以理书 8:25; 士师记 9:1–20"> 「必有一个卑鄙的人兴起接续为王，人未曾将国的尊荣给他，他却趁人坦然无备的时候，用谄媚的话得国。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理书 8:10–11; 但以理书 11:10; 但以理书 9:26"> 必有无数的军兵势如洪水，在他面前冲没败坏；同盟的君也必如此。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理书 8:25; 帖撒罗尼迦后书 2:9; 诗篇 52:2"> 与那君结盟之后，他必行诡诈，因为他必上来以微小的军<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="原文是民">i</a></sup>成为强盛。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理书 7:25; 箴言 23:7; 马太福音 9:4"> 趁人坦然无备的时候，他必来到国中极肥美之地，行他列祖和他列祖之祖所未曾行的，将掳物、掠物，和财宝散给众人，又要设计攻打保障，然而这都是暂时的。</span>
<span className="v" id="v25" data-v="25" data-xref="箴言 15:18; 但以理书 11:2; 箴言 28:25"> 「他必奋勇向前，率领大军攻击南方王；南方王也必以极大极强的军兵与他争战，却站立不住，因为有人设计谋害南方王。</span>
<span className="v" id="v26" data-v="26" data-xref="但以理书 11:10; 但以理书 11:40; 撒母耳记下 4:2–12"> 吃王膳的，必败坏他；他的军队必被冲没，而且被杀的甚多。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 12:2; 耶利米书 9:3–5; 哈巴谷书 2:3"> 至于这二王，他们心怀恶计，同席说谎，计谋却不成就；因为到了定期，事就了结。</span>
<span className="v" id="v28" data-v="28" data-xref="但以理书 11:30–32; 但以理书 8:24; 使徒行传 3:25"> 北方王<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="原文是他">j</a></sup>必带许多财宝回往本国，他的心反对圣约，任意而行，回到本地。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 17:26; 以赛亚书 14:31; 但以理书 11:25"> 「到了定期，他必返回，来到南方。后一次却不如前一次，</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 10:4; 民数记 24:24; 耶利米书 2:10"> 因为基提战船必来攻击他，他就丧胆而回，又要恼恨圣约，任意而行；他必回来联络背弃圣约的人。</span>
<span className="v" id="v31" data-v="31" data-xref="但以理书 12:11; 但以理书 9:27; 马太福音 24:15"> 他必兴兵，这兵必亵渎圣地，就是保障，除掉常献的燔祭，设立那行毁坏可憎的。</span>
<span className="v" id="v32" data-v="32" data-xref="历代志上 28:9; 诗篇 9:10; 约翰福音 17:3"> 作恶违背圣约的人，他必用巧言勾引；惟独认识 神的子民必刚强行事。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 24:9; 约翰福音 16:2; 玛拉基书 2:7"> 民间的智慧人必训诲多人；然而他们多日必倒在刀下，或被火烧，或被掳掠抢夺。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 7:15; 罗马书 16:18; 使徒行传 20:29–30"> 他们仆倒的时候，稍得扶助，却有许多人用谄媚的话亲近他们。</span>
<span className="v" id="v35" data-v="35" data-xref="撒迦利亚书 13:9; 玛拉基书 3:2–4; 启示录 2:10"> 智慧人中有些仆倒的，为要熬炼其余的人，使他们清净洁白，直到末了；因为到了定期，事就了结。</span>
<span className="v" id="v36" data-v="36" data-xref="启示录 13:5–6; 帖撒罗尼迦后书 2:4; 申命记 10:17"> 「王必任意而行，自高自大，超过所有的神，又用奇异的话攻击万神之神。他必行事亨通，直到主的忿怒完毕，因为所定的事必然成就。</span>
<span className="v" id="v37" data-v="37" data-xref="帖撒罗尼迦后书 2:4; 以赛亚书 14:13; 提摩太前书 4:3"> 他必不顾他列祖的神，也不顾妇女所羡慕的神，无论何神他都不顾；因为他必自大，高过一切。</span>
<span className="v" id="v38" data-v="38" data-xref="启示录 17:1–5; 以赛亚书 44:9; 启示录 13:12–17"> 他倒要敬拜保障的神，用金、银、宝石和可爱之物敬奉他列祖所不认识的神。</span>
<span className="v" id="v39" data-v="39" data-xref="启示录 18:9–13"> 他必靠外邦神的帮助，攻破最坚固的保障。凡承认他的，他必将荣耀加给他们，使他们管辖许多人，又为贿赂分地与他们。</span>
<span className="v" id="v40" data-v="40" data-xref="但以理书 11:35; 但以理书 11:10; 以赛亚书 5:28"> 「到末了，南方王要与他交战。北方王必用战车、马兵，和许多战船，势如暴风来攻击他，也必进入列国，如洪水泛滥。</span>
<span className="v" id="v41" data-v="41" data-xref="耶利米书 48:47; 耶利米书 49:6; 以赛亚书 11:13–15"> 又必进入那荣美之地，有许多国就被倾覆，但以东人、摩押人，和一大半亚扪人必脱离他的手。</span>
<span className="v" id="v42" data-v="42" data-xref="撒迦利亚书 10:10–11; 以西结书 29:14; 启示录 11:8"> 他必伸手攻击列国；埃及地也不得脱离。</span>
<span className="v" id="v43" data-v="43" data-xref="历代志下 12:3; 那鸿书 3:9; 以西结书 30:4–5"> 他必把持埃及的金银财宝和各样的宝物。利比亚人和古实人都必跟从他。</span>
<span className="v" id="v44" data-v="44" data-xref="启示录 19:19–21; 启示录 16:12; 启示录 17:13"> 但从东方和北方必有消息扰乱他，他就大发烈怒出去，要将多人杀灭净尽。</span>
<span className="v" id="v45" data-v="45" data-xref="帖撒罗尼迦后书 2:4; 但以理书 8:25; 启示录 19:19–21"> 他必在海和荣美的圣山中间设立他如宫殿的帐幕；然而到了他的结局，必无人能帮助他。」</span>
</div>

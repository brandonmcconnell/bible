## 尼布甲尼撒下令拜金像

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哈巴谷书 2:19; 耶利米书 16:20; 以赛亚书 46:6"> 尼布甲尼撒王造了一个金像，高六十肘，宽六肘，立在巴比伦省杜拉平原。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理书 3:27; 箴言 29:12; 列王纪上 12:32"> 尼布甲尼撒王差人将总督、钦差、巡抚、臬司、藩司、谋士、法官，和各省的官员都召了来，为尼布甲尼撒王所立的像行开光之礼。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 17:17; 启示录 17:13; 启示录 13:13–16"> 于是总督、钦差、巡抚、臬司、藩司、谋士、法官，和各省的官员都聚集了来，要为尼布甲尼撒王所立的像行开光之礼，就站在尼布甲尼撒所立的像前。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理书 4:1; 但以理书 6:25; 弥迦书 6:16"> 那时传令的大声呼叫说：「各方、各国、各族<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是舌；下同">a</a></sup>的人哪，有令传与你们：</span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 3:15; 但以理书 3:10; 但以理书 3:7"> 你们一听见角、笛、琵琶、琴、瑟、笙，和各样乐器的声音，就当俯伏敬拜尼布甲尼撒王所立的金像。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 13:50; 马太福音 13:42; 耶利米书 29:22"> 凡不俯伏敬拜的，必立时扔在烈火的窑中。」</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 17:8; 启示录 13:3; 启示录 13:8"> 因此各方、各国、各族的人民一听见角、笛、琵琶、琴、瑟，和各样乐器的声音，就都俯伏敬拜尼布甲尼撒王所立的金像。</span>
</div>
</div>

## 但以理的三个朋友被控违令

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 4:12–16; 但以理书 6:12–13; 以斯帖记 3:8–9"> 那时，有几个迦勒底人进前来控告犹大人。</span>
<span className="v" id="v9" data-v="9" data-xref="但以理书 5:10; 但以理书 6:6; 但以理书 6:21"> 他们对尼布甲尼撒王说：「愿王万岁！</span>
<span className="v" id="v10" data-v="10" data-xref="但以理书 3:4–7; 但以理书 6:12; 以斯帖记 3:12–14"> 王啊，你曾降旨说，凡听见角、笛、琵琶、琴、瑟、笙，和各样乐器声音的都当俯伏敬拜金像。</span>
<span className="v" id="v11" data-v="11"> 凡不俯伏敬拜的，必扔在烈火的窑中。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理书 6:13; 但以理书 2:49; 使徒行传 17:7"> 现在有几个犹大人，就是王所派管理巴比伦省事务的沙得拉、米煞、亚伯尼歌；王啊，这些人不理你，不事奉你的神，也不敬拜你所立的金像。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="但以理书 3:19; 但以理书 2:12; 以斯帖记 3:5–6"> 当时，尼布甲尼撒冲冲大怒，吩咐人把沙得拉、米煞、亚伯尼歌带过来，他们就把那些人带到王面前。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 50:2; 但以理书 3:1; 以赛亚书 46:1"> 尼布甲尼撒问他们说：「沙得拉、米煞、亚伯尼歌，你们不事奉我的神，也不敬拜我所立的金像，是故意的吗？</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 5:29; 历代志下 32:15–17; 出埃及记 5:2"> 你们再听见角、笛、琵琶、琴、瑟、笙，和各样乐器的声音，若俯伏敬拜我所造的像，却还可以；若不敬拜，必立时扔在烈火的窑中，有何神能救你们脱离我手呢？」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="但以理书 1:7; 但以理书 3:12"> 沙得拉、米煞、亚伯尼歌对王说：「尼布甲尼撒啊，这件事我们不必回答你，</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 8:31; 路加福音 1:37; 希伯来书 7:25"> 即便如此，我们所事奉的 神能将我们从烈火的窑中救出来。王啊，他也必救我们脱离你的手；</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 5:29–32; 马太福音 10:39; 启示录 2:10–11"> 即或不然，王啊，你当知道我们决不事奉你的神，也不敬拜你所立的金像。」</span>
</div>
</div>

## 但以理的三个朋友被扔进火窑

<div className="bt">
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="但以理书 3:13; 利未记 26:24; 箴言 21:24"> 当时，尼布甲尼撒怒气填胸，向沙得拉、米煞、亚伯尼歌变了脸色，吩咐人把窑烧热，比寻常更加七倍；</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 16:23; 使徒行传 16:25; 但以理书 3:15"> 又吩咐他军中的几个壮士，将沙得拉、米煞、亚伯尼歌捆起来，扔在烈火的窑中。</span>
<span className="v" id="v21" data-v="21"> 这三人穿着裤子、内袍、外衣，和别的衣服，被捆起来扔在烈火的窑中。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 12:33; 箴言 21:18; 箴言 11:8"> 因为王命紧急，窑又甚热，那抬沙得拉、米煞、亚伯尼歌的人都被火焰烧死。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理书 6:16–17; 耶利米书 38:6; 诗篇 34:19"> 沙得拉、米煞、亚伯尼歌这三个人都被捆着落在烈火的窑中。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="但以理书 6:7; 但以理书 6:22; 但以理书 3:9–10"> 那时，尼布甲尼撒王惊奇，急忙起来，对谋士说：「我们捆起来扔在火里的不是三个人吗？」他们回答王说：「王啊，是。」</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 43:2; 使徒行传 28:5; 马可福音 16:18"> 王说：「看哪，我见有四个人，并没有捆绑，在火中游行，也没有受伤；那第四个的相貌好像神子。」</span>
</div>
</div>

## 三人获释且得高升

<div className="bt">
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="但以理书 3:17; 以赛亚书 52:12; 启示录 19:5"> 于是，尼布甲尼撒就近烈火窑门，说：「至高 神的仆人沙得拉、米煞、亚伯尼歌出来，上这里来吧！」沙得拉、米煞、亚伯尼歌就从火中出来了。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 43:2; 希伯来书 11:34; 以赛亚书 26:11"> 那些总督、钦差、巡抚，和王的谋士一同聚集看这三个人，见火无力伤他们的身体，头发也没有烧焦，衣裳也没有变色，并没有火燎的气味。</span>
<span className="v" id="v28" data-v="28" data-xref="罗马书 14:7–8; 诗篇 34:7–8; 诗篇 84:11–12"> 尼布甲尼撒说：「沙得拉、米煞、亚伯尼歌的 神是应当称颂的！他差遣使者救护倚靠他的仆人，他们不遵王命，舍去己身，在他们 神以外不肯事奉敬拜别神。</span>
<span className="v" id="v29" data-v="29" data-xref="但以理书 2:5; 诗篇 76:10; 申命记 32:31"> 现在我降旨，无论何方、何国、何族的人，谤 沙得拉、米煞、亚伯尼歌之 神的，必被凌迟，他的房屋必成粪堆，因为没有别神能这样施行拯救。」</span>
<span className="v" id="v30" data-v="30" data-xref="但以理书 2:49; 撒母耳记上 2:30; 但以理书 3:12"> 那时王在巴比伦省，高升了沙得拉、米煞、亚伯尼歌。</span>
</div>
</div>

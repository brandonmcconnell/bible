## 伯沙撒王的宴会

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖记 1:3; 马可福音 6:21–22; 以赛亚书 21:4–5"> 伯沙撒王为他的一千大臣设摆盛筵，与这一千人对面饮酒。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理书 1:2; 列王纪下 24:13; 耶利米书 27:16–22"> 伯沙撒欢饮之间，吩咐人将他父<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：祖；下同">a</a></sup>尼布甲尼撒从耶路撒冷殿中所掠的金银器皿拿来，王与大臣、皇后、妃嫔好用这器皿饮酒。</span>
<span className="v" id="v3" data-v="3"> 于是他们把耶路撒冷 神殿库房中所掠的金器皿拿来，王和大臣、皇后、妃嫔就用这器皿饮酒。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理书 5:23; 哈巴谷书 2:19; 诗篇 135:15–18"> 他们饮酒，赞美金、银、铜、铁、木、石所造的神。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 4:31; 但以理书 5:24–28; 约伯记 20:5"> 当时，忽有人的指头显出，在王宫与灯台相对的粉墙上写字。王看见写字的指头</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 7:17; 但以理书 7:28; 那鸿书 2:10"> 就变了脸色，心意惊惶，腰骨好像脱节，双膝彼此相碰，</span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 5:29; 但以理书 5:16; 但以理书 2:48"> 大声吩咐将用法术的和迦勒底人并观兆的领进来，对巴比伦的哲士说，谁能读这文字，把讲解告诉我，他必身穿紫袍，项带金链，在我国中位列第三。</span>
<span className="v" id="v8" data-v="8" data-xref="但以理书 2:27; 但以理书 4:7; 创世记 41:8"> 于是王的一切哲士都进来，却不能读那文字，也不能把讲解告诉王。</span>
<span className="v" id="v9" data-v="9" data-xref="但以理书 5:6; 但以理书 2:1; 耶利米书 6:24"> 伯沙撒王就甚惊惶，脸色改变，他的大臣也都惊奇。</span>
<span className="v" id="v10" data-v="10" data-xref="但以理书 3:9; 但以理书 6:6; 但以理书 2:4"> 太后<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：皇后；下同">b</a></sup>因王和他大臣所说的话，就进入宴宫，说：「愿王万岁！你心意不要惊惶，脸面不要变色。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 4:8–9; 但以理书 2:47–48; 但以理书 4:18"> 在你国中有一人，他里头有圣神的灵，你父在世的日子，这人心中光明，又有聪明智慧，好像神的智慧。你父尼布甲尼撒王，就是王的父，立他为术士、用法术的，和迦勒底人，并观兆的领袖。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理书 5:14; 但以理书 6:3; 但以理书 1:7"> 在他里头有美好的灵性，又有知识聪明，能圆梦，释谜语，解疑惑。这人名叫但以理，尼布甲尼撒王又称他为伯提沙撒，现在可以召他来，他必解明这意思。」</span>
</div>
</div>

## 但以理解释墙上的字

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="但以理书 6:13; 但以理书 5:11; 但以理书 2:25"> 但以理就被领到王前。王问但以理说：「你是被掳之犹大人中的但以理吗？就是我父王从犹大掳来的吗？</span>
<span className="v" id="v14" data-v="14" data-xref="但以理书 5:11–12"> 我听说你里头有神的灵，心中光明，又有聪明和美好的智慧。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理书 5:7–8; 以赛亚书 47:12; 以赛亚书 29:10–12"> 现在哲士和用法术的都领到我面前，为叫他们读这文字，把讲解告诉我，无奈他们都不能把讲解说出来。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理书 5:7; 创世记 40:8; 但以理书 5:29"> 我听说你善于讲解，能解疑惑；现在你若能读这文字，把讲解告诉我，就必身穿紫袍，项戴金链，在我国中位列第三。」</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 5:16; 创世记 14:23; 列王纪下 5:26"> 但以理在王面前回答说：「你的赠品可以归你自己，你的赏赐可以归给别人；我却要为王读这文字，把讲解告诉王。</span>
<span className="v" id="v18" data-v="18" data-xref="但以理书 2:37–38; 但以理书 4:17; 但以理书 4:22–25"> 王啊，至高的 神曾将国位、大权、荣耀、威严赐与你父尼布甲尼撒；</span>
<span className="v" id="v19" data-v="19" data-xref="但以理书 3:6; 但以理书 2:12–13; 但以理书 3:4"> 因 神所赐他的大权，各方、各国、各族的人都在他面前战兢恐惧。他可以随意生杀，随意升降。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 9:17; 耶利米书 13:18; 希伯来书 3:13"> 但他心高气傲，灵也刚愎，甚至行事狂傲，就被革去王位，夺去荣耀。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理书 4:25; 以西结书 17:24; 但以理书 4:35"> 他被赶出离开世人，他的心变如兽心，与野驴同居，吃草如牛，身被天露滴湿，等他知道至高的 神在人的国中掌权，凭自己的意旨立人治国。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 33:23; 出埃及记 10:3; 雅各书 4:17"> 伯沙撒啊，你是他的儿子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或译：孙子">c</a></sup>，你虽知道这一切，你心仍不自卑，</span>
<span className="v" id="v23" data-v="23" data-xref="约伯记 12:10; 但以理书 4:37; 耶利米书 10:23"> 竟向天上的主自高，使人将他殿中的器皿拿到你面前，你和大臣、皇后、妃嫔用这器皿饮酒。你又赞美那不能看、不能听、无知无识、金、银、铜、铁、木、石所造的神，却没有将荣耀归与那手中有你气息，管理你一切行动的 神。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理书 5:5"> 因此从 神那里显出指头来写这文字。</span>
<span className="v" id="v25" data-v="25"> 「所写的文字是：『弥尼，弥尼，提客勒，乌法珥新。』</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 25:11–12; 以赛亚书 47:1–15; 耶利米书 27:7"> 讲解是这样：弥尼，就是 神已经数算你国的年日到此完毕。</span>
<span className="v" id="v27" data-v="27" data-xref="约伯记 31:6; 哥林多前书 3:13; 诗篇 62:9"> 提客勒，就是你被称在天平里，显出你的亏欠。</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 13:17; 但以理书 6:28; 但以理书 5:31"> 毗勒斯<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="与乌法珥新同义">d</a></sup>，就是你的国分裂，归与米底亚人和波斯人。」</span>
<span className="v" id="v29" data-v="29" data-xref="但以理书 5:16; 但以理书 5:7"> 伯沙撒下令，人就把紫袍给但以理穿上，把金链给他戴在颈项上，又传令使他在国中位列第三。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 51:31; 耶利米书 51:57; 耶利米书 51:39"> 当夜，迦勒底王伯沙撒被杀。</span>
<span className="v" id="v31" data-v="31" data-xref="但以理书 9:1; 但以理书 6:1"> 米底亚人大流士年六十二岁，取了迦勒底国。</span>
</div>
</div>

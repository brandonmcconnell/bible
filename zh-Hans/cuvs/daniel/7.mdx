## 但以理叙述异象


## 四兽的异象

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理书 1:17; 阿摩司书 3:7; 但以理书 5:1"> 巴比伦王伯沙撒元年，但以理在床上做梦，见了脑中的异象，就记录这梦，述说其中的大意。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 7:1; 启示录 17:15"> 但以理说：<br />我夜里见异象，看见天的四风陡起，刮在大海之上。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 13:1; 但以理书 7:17; 但以理书 2:32–33"> 有四个大兽从海中上来，形状各有不同：</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 4:7; 以赛亚书 14:13–17; 以西结书 17:3"> 头一个像狮子，有鹰的翅膀；我正观看的时候，兽的翅膀被拔去，兽从地上得立起来，用两脚站立，像人一样，又得了人心。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 2:39; 以赛亚书 13:17–18; 箴言 17:12"> 又有一兽如熊，就是第二兽，旁跨而坐，口齿内衔着三根肋骨。有吩咐这兽的说：「起来吞吃多肉。」</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 13:2; 但以理书 8:20–22; 但以理书 8:5–8"> 此后我观看，又有一兽如豹，背上有鸟的四个翅膀；这兽有四个头，又得了权柄。</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 13:1; 启示录 12:3; 启示录 17:12"> 其后我在夜间的异象中观看，见第四兽甚是可怕，极其强壮，大有力量，有大铁牙，吞吃嚼碎，所剩下的用脚践踏。这兽与前三兽大不相同，头有十角。</span>
<span className="v" id="v8" data-v="8" data-xref="启示录 13:5–6; 启示录 13:1; 诗篇 12:3"> 我正观看这些角，见其中又长起一个小角；先前的角中有三角在这角前，连根被它拔出来。这角有眼，像人的眼，有口说夸大的话。</span>
</div>
</div>

## 永存者的异象

<div className="bt">
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="启示录 1:14; 马可福音 9:3; 但以理书 7:13"> <span className="pl pl-1">我观看，</span><br /><span className="pl pl-1">见有宝座设立，</span><br /><span className="pl pl-1">上头坐着亘古常在者。</span><br /><span className="pl pl-1">他的衣服洁白如雪，</span><br /><span className="pl pl-1">头发如纯净的羊毛。</span><br /><span className="pl pl-1">宝座乃火焰，</span><br /><span className="pl pl-1">其轮乃烈火。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 30:27; 申命记 33:2; 启示录 20:11–15"> <span className="pl pl-1">从他面前有火，像河发出；</span><br /><span className="pl pl-1">事奉他的有千千，</span><br /><span className="pl pl-1">在他面前侍立的有万万；</span><br /><span className="pl pl-1">他坐着要行审判，</span><br /><span className="pl pl-1">案卷都展开了。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="启示录 19:20; 启示录 20:10; 帖撒罗尼迦后书 2:8"> 那时我观看，见那兽因小角说夸大话的声音被杀，身体损坏，扔在火中焚烧。</span>
<span className="v" id="v12" data-v="12" data-xref="但以理书 8:7; 但以理书 7:4–6"> 其余的兽，权柄都被夺去，生命却仍存留，直到所定的时候和日期。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 26:64; 启示录 1:7; 路加福音 21:27"> <span className="pl pl-1">我在夜间的异象中观看，</span><br /><span className="pl pl-1">见有一位像人子的，</span><br /><span className="pl pl-1">驾着天云而来，</span><br /><span className="pl pl-1">被领到亘古常在者面前，</span><br /></span>
<span className="v" id="v14" data-v="14" data-xref="启示录 11:15; 但以理书 7:27; 约翰福音 3:35"> <span className="pl pl-1">得了权柄、荣耀、国度，</span><br /><span className="pl pl-1">使各方、各国、各族的人都事奉他。</span><br /><span className="pl pl-1">他的权柄是永远的，不能废去；</span><br /><span className="pl pl-1">他的国必不败坏。</span></span>
</div>
</div>

## 解释异象

<div className="bt">
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="但以理书 7:28; 耶利米书 17:16; 创世记 40:7–8"> 至于我—但以理，我的灵在我里面愁烦，我脑中的异象使我惊惶。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 7:13–14; 撒迦利亚书 2:3; 启示录 5:5"> 我就近一位侍立者，问他这一切的真情。他就告诉我，将那事的讲解给我说明：</span>
<span className="v" id="v17" data-v="17" data-xref="但以理书 8:19–22; 但以理书 2:37–40; 约翰福音 18:36"> 这四个大兽就是四王将要在世上兴起。</span>
<span className="v" id="v18" data-v="18" data-xref="但以理书 7:27; 以赛亚书 60:12–14; 启示录 5:10"> 然而，至高者的圣民，必要得国享受，直到永永远远。</span>
<span className="v" id="v19" data-v="19" data-xref="但以理书 7:7; 但以理书 2:40–43"> 那时我愿知道第四兽的真情，它为何与那三兽的真情大不相同，甚是可怕，有铁牙铜爪，吞吃嚼碎，所剩下的用脚践踏；</span>
<span className="v" id="v20" data-v="20" data-xref="但以理书 7:23; 但以理书 7:8; 但以理书 7:11"> 头有十角和那另长的一角，在这角前有三角被它打落。这角有眼，有说夸大话的口，形状强横，过于它的同类。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理书 12:7; 启示录 17:14; 但以理书 8:24"> 我观看，见这角与圣民争战，胜了他们。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理书 7:18; 启示录 20:4; 启示录 5:10"> 直到亘古常在者来给至高者的圣民伸冤，圣民得国的时候就到了。</span>
<span className="v" id="v23" data-v="23" data-xref="但以理书 2:40; 但以理书 7:7; 路加福音 2:1"> <span className="pl pl-1">那侍立者这样说：</span><br /><span className="pl pl-1">第四兽就是世上必有的第四国，</span><br /><span className="pl pl-1">与一切国大不相同，</span><br /><span className="pl pl-1">必吞吃全地，</span><br /><span className="pl pl-1">并且践踏嚼碎。</span><br /></span>
<span className="v" id="v24" data-v="24" data-xref="但以理书 7:20; 但以理书 11:36; 启示录 13:1"> <span className="pl pl-1">至于那十角，就是从这国中必兴起的十王，</span><br /><span className="pl pl-1">后来又兴起一王，</span><br /><span className="pl pl-1">与先前的不同；</span><br /><span className="pl pl-1">他必制伏三王。</span><br /></span>
<span className="v" id="v25" data-v="25" data-xref="但以理书 12:7; 启示录 12:14; 帖撒罗尼迦后书 2:4"> <span className="pl pl-1">他必向至高者说夸大的话，</span><br /><span className="pl pl-1">必折磨至高者的圣民，</span><br /><span className="pl pl-1">必想改变节期和律法。</span><br /><span className="pl pl-1">圣民必交付他手一载、二载、半载。</span><br /></span>
<span className="v" id="v26" data-v="26" data-xref="启示录 20:10–11; 帖撒罗尼迦后书 2:8; 启示录 11:13"> <span className="pl pl-1">然而，审判者必坐着行审判；</span><br /><span className="pl pl-1">他的权柄必被夺去，</span><br /><span className="pl pl-1">毁坏，灭绝，一直到底。</span><br /></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 72:11; 路加福音 1:33; 启示录 11:15"> <span className="pl pl-1">国度、权柄，和天下诸国的大权</span><br /><span className="pl pl-1">必赐给至高者的圣民。</span><br /><span className="pl pl-1">他的国是永远的；</span><br /><span className="pl pl-1">一切掌权的都必事奉他，顺从他。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 2:19; 路加福音 2:51; 但以理书 10:8"> 那事至此完毕。至于我—但以理，心中甚是惊惶，脸色也改变了，却将那事存记在心。</span>

## 但以理和他的朋友们


## 但以理在尼布甲尼撒的宫廷里

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 36:5–7; 列王纪下 24:1–2; 列王纪下 24:13"> 犹大王约雅敬在位第三年，巴比伦王尼布甲尼撒来到耶路撒冷，将城围困。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 36:7; 撒迦利亚书 5:11; 耶利米书 27:19–20"> 主将犹大王约雅敬，并 神殿中器皿的几分交付他手。他就把这器皿带到示拿地，收入他神的庙里，放在他神的库中。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 39:7; 列王纪下 20:17–18; 列王纪下 24:15"> 王吩咐太监长亚施毗拿，从以色列人的宗室和贵胄中带进几个人来，</span>
<span className="v" id="v4" data-v="4" data-xref="但以理书 5:11; 使徒行传 7:22; 箴言 22:29"> 就是年少没有残疾、相貌俊美、通达各样学问、知识聪明俱备、足能侍立在王宫里的，要教他们迦勒底的文字言语。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理书 1:19; 列王纪上 10:8; 但以理书 1:8"> 王派定将自己所用的膳和所饮的酒，每日赐他们一分，养他们三年。满了三年，好叫他们在王面前侍立。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结书 14:14; 马太福音 24:15; 但以理书 2:17"> 他们中间有犹大族的人：但以理、哈拿尼雅、米沙利、亚撒利雅。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 5:12; 但以理书 4:8; 但以理书 2:49"> 太监长给他们起名：称但以理为伯提沙撒，称哈拿尼雅为沙得拉，称米沙利为米煞，称亚撒利雅为亚伯尼歌。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 141:4; 以西结书 4:13–14; 利未记 11:45–47"> 但以理却立志不以王的膳和王所饮的酒玷污自己，所以求太监长容他不玷污自己。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 39:21; 箴言 16:7; 诗篇 106:46"> 神使但以理在太监长眼前蒙恩惠，受怜悯。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 6:16–18; 约翰福音 12:42–43; 箴言 29:25"> 太监长对但以理说：「我惧怕我主我王，他已经派定你们的饮食，倘若他见你们的面貌比你们同岁的少年人肌瘦，怎么好呢？这样，你们就使我的头在王那里难保。」</span>
<span className="v" id="v11" data-v="11"> 但以理对太监长所派管理但以理、哈拿尼雅、米沙利、亚撒利雅的委办说：</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 14:2; 但以理书 1:16; 创世记 1:29–30"> 「求你试试仆人们十天，给我们素菜吃，白水喝，</span>
<span className="v" id="v13" data-v="13"> 然后看看我们的面貌和用王膳那少年人的面貌，就照你所看的待仆人吧！」</span>
<span className="v" id="v14" data-v="14"> 委办便允准他们这件事，试看他们十天。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 23:25; 箴言 10:22; 列王纪下 4:42–44"> 过了十天，见他们的面貌比用王膳的一切少年人更加俊美肥胖。</span>
<span className="v" id="v16" data-v="16" data-xref="但以理书 1:12"> 于是委办撤去派他们用的膳，饮的酒，给他们素菜吃。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 3:12; 雅各书 1:5; 但以理书 2:21"> 这四个少年人， 神在各样文字学问<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="学问：原文是智慧">a</a></sup>上赐给他们聪明知识；但以理又明白各样的异象和梦兆。</span>
<span className="v" id="v18" data-v="18" data-xref="但以理书 1:5"> 尼布甲尼撒王预定带进少年人来的日期满了，太监长就把他们带到王面前。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 22:29; 创世记 41:46; 但以理书 1:5"> 王与他们谈论，见少年人中无一人能比但以理、哈拿尼雅、米沙利、亚撒利雅，所以留他们在王面前侍立。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 8:19; 以赛亚书 47:12–14; 列王纪上 4:29–34"> 王考问他们一切事，就见他们的智慧聪明比通国的术士和用法术的胜过十倍。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理书 6:28; 但以理书 10:1"> 到塞鲁士王元年，但以理还在。</span>

## 公绵羊、公山羊的异象

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理书 11:4; 但以理书 9:2; 但以理书 7:28"> 伯沙撒王在位第三年，有异象现与我—但以理，是在先前所见的异象之后。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯帖记 1:2; 尼希米记 1:1; 创世记 10:22"> 我见了异象的时候，我以为在以拦省书珊城<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：宫">a</a></sup>中；我见异象又如在乌莱河边。</span>
<span className="v" id="v3" data-v="3" data-xref="但以理书 8:20; 但以理书 10:5; 撒迦利亚书 6:1"> 我举目观看，见有双角的公绵羊站在河边，两角都高。这角高过那角，更高的是后长的。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理书 11:16; 但以理书 11:36; 但以理书 8:7"> 我见那公绵羊往西、往北、往南抵触。兽在它面前都站立不住，也没有能救护脱离它手的；但它任意而行，自高自大。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="但以理书 8:21; 但以理书 11:3; 但以理书 8:8"> 我正思想的时候，见有一只公山羊从西而来，遍行全地，脚不沾尘。这山羊两眼当中有一非常的角。</span>
<span className="v" id="v6" data-v="6"> 它往我所看见、站在河边有双角的公绵羊那里去，大发忿怒，向它直闯。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理书 7:7; 但以理书 11:11; 约书亚记 8:20"> 我见公山羊就近公绵羊，向它发烈怒，抵触它，折断它的两角。绵羊在它面前站立不住；它将绵羊触倒在地，用脚践踏，没有能救绵羊脱离它手的。</span>
<span className="v" id="v8" data-v="8" data-xref="但以理书 7:2; 启示录 7:1; 但以理书 5:20"> 这山羊极其自高自大，正强盛的时候，那大角折断了，又在角根上向天的四方<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文是风">b</a></sup>长出四个非常的角来。</span>
<span className="v" id="v9" data-v="9" data-xref="但以理书 11:16; 以西结书 20:6; 以西结书 20:15"> 四角之中有一角长出一个小角，向南、向东、向荣美之地，渐渐成为强大。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 14:13; 启示录 12:4; 但以理书 8:7"> 它渐渐强大，高及天象，将些天象和星宿抛落在地，用脚践踏。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理书 12:11; 启示录 13:5–7; 但以理书 8:25"> 并且它自高自大，以为高及天象之君；除掉常献给君的燔祭，毁坏君的圣所。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 12:1; 以赛亚书 59:14; 但以理书 11:31–36"> 因罪过的缘故，有军旅和常献的燔祭交付它。它将真理抛在地上，任意而行，无不顺利。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="启示录 11:2; 启示录 6:10; 路加福音 21:24"> 我听见有一位圣者说话，又有一位圣者问那说话的圣者说：「这除掉常献的燔祭和施行毁坏的罪过，将圣所与军旅<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或译：以色列的军">c</a></sup>践踏的异象，要到几时才应验呢？」</span>
<span className="v" id="v14" data-v="14" data-xref="但以理书 12:7; 但以理书 7:25; 启示录 11:2–3"> 他对我说：「到二千三百日，圣所就必洁净。」</span>
</div>
</div>

## 天使加百列解释异象

<div className="bt">
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理书 10:16; 启示录 1:13; 彼得前书 1:10–11"> 我—但以理见了这异象，愿意明白其中的意思。忽有一位形状像人的站在我面前。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 1:19; 路加福音 1:26; 但以理书 8:2"> 我又听见乌莱河两岸中有人声呼叫说：「加百列啊，要使此人明白这异象。」</span>
<span className="v" id="v17" data-v="17" data-xref="但以理书 8:19; 但以理书 12:4; 哈巴谷书 2:3"> 他便来到我所站的地方。他一来，我就惊慌俯伏在地；他对我说：「人子啊，你要明白，因为这是关乎末后的异象。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="但以理书 10:18; 以西结书 2:2; 但以理书 10:16"> 他与我说话的时候，我面伏在地沉睡；他就摸我，扶我站起来，</span>
<span className="v" id="v19" data-v="19" data-xref="哈巴谷书 2:3; 但以理书 11:27; 启示录 17:17"> 说：「我要指示你恼怒临完必有的事，因为这是关乎末后的定期。</span>
<span className="v" id="v20" data-v="20" data-xref="但以理书 8:3; 但以理书 11:1–2"> 你所看见双角的公绵羊，就是米底亚和波斯王。</span>
<span className="v" id="v21" data-v="21" data-xref="但以理书 10:20; 但以理书 11:3; 但以理书 8:5–8"> 那公山羊就是希腊王<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="希腊：原文是雅完；下同">d</a></sup>；两眼当中的大角就是头一王。</span>
<span className="v" id="v22" data-v="22" data-xref="但以理书 11:4; 但以理书 8:3; 但以理书 8:8"> 至于那折断了的角，在其根上又长出四角，这四角就是四国，必从这国里兴起来，只是权势都不及他。</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 13:11–14; 帖撒罗尼迦后书 2:9–11; 启示录 19:20"> 这四国末时，犯法的人罪恶满盈，必有一王兴起，面貌凶恶，能用双关的诈语。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理书 8:12; 但以理书 11:31–36; 但以理书 7:25"> 他的权柄必大，却不是因自己的能力；他必行非常的毁灭，事情顺利，任意而行；又必毁灭有能力的和圣民。</span>
<span className="v" id="v25" data-v="25" data-xref="但以理书 8:11; 启示录 17:14; 约伯记 34:20"> 他用权术成就手中的诡计，心里自高自大，在人坦然无备的时候，毁灭多人；又要站起来攻击万君之君，至终却非因人手而灭亡。</span>
<span className="v" id="v26" data-v="26" data-xref="但以理书 10:1; 但以理书 12:9; 但以理书 12:4"> 所说二千三百日的异象是真的，但你要将这异象封住，因为关乎后来许多的日子。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="但以理书 7:28; 哈巴谷书 3:16; 但以理书 8:7"> 于是我—但以理昏迷不醒，病了数日，然后起来办理王的事务。我因这异象惊奇，却无人能明白其中的意思。</span>
</div>
</div>

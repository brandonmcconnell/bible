## 撒母耳去世

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 28:3; 民数记 20:29; 申命记 34:8"> 撒母耳死了，以色列众人聚集，为他哀哭，将他葬在拉玛—他自己的坟墓<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文是房屋">a</a></sup>里。 大卫和亚比该 大卫起身，下到巴兰的旷野。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 38:13; 撒母耳记上 23:24; 约书亚记 15:55"> 在玛云有一个人，他的产业在迦密，是一个大富户，有三千绵羊，一千山羊；他正在迦密剪羊毛。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 14:1; 箴言 31:10; 以赛亚书 32:5–7"> 那人名叫拿八，是迦勒族的人；他的妻名叫亚比该，是聪明俊美的妇人。拿八为人刚愎凶恶。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 38:13; 撒母耳记下 13:23"> 大卫在旷野听见说拿八剪羊毛，</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 43:23; 撒母耳记上 17:22"> 大卫就打发十个仆人，吩咐他们说：「你们上迦密去见拿八，提我的名问他安。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 10:5; 历代志上 12:18; 诗篇 122:7"> 要对那富户如此说：『愿你平安，愿你家平安，愿你一切所有的都平安。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 25:21; 撒母耳记上 25:15–16; 撒母耳记上 22:2"> 现在我听说有人为你剪羊毛，你的牧人在迦密的时候和我们在一处，我们没有欺负他们，他们也未曾失落什么。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯帖记 9:19; 尼希米记 8:10–12; 路加福音 14:12–14"> 可以问你的仆人，他们必告诉你。所以愿我的仆人在你眼前蒙恩，因为是在好日子来的。求你随手取点赐与仆人和你儿子大卫。』」</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 2:15; 历代志下 14:7; 创世记 8:4"> 大卫的仆人到了，将这话提大卫的名都告诉了拿八，就住了口。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 9:28; 以赛亚书 32:7; 撒母耳记上 22:7–8"> 拿八回答大卫的仆人说：「大卫是谁？耶西的儿子是谁？近来悖逆主人奔逃的仆人甚多，</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 8:6; 加拉太书 6:10; 哥林多后书 6:9"> 我岂可将饮食和为我剪羊毛人所宰的肉给我不知道从哪里来的人呢？」</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 36:21–22; 撒母耳记下 24:13; 希伯来书 13:17"> 大卫的仆人就转身从原路回去，照这话告诉大卫。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 23:13; 箴言 25:8; 撒母耳记上 24:5–6"> 大卫向跟随他的人说：「你们各人都要带上刀！」众人就都带上刀，大卫也带上刀。跟随大卫上去的约有四百人，留下二百人看守器具。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 13:10; 马可福音 15:29"> 有拿八的一个仆人告诉拿八的妻亚比该说：「大卫从旷野打发使者来问我主人的安，主人却辱骂他们。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 25:7; 撒母耳记上 25:21; 腓立比书 2:15"> 但是那些人待我们甚好；我们在田野与他们来往的时候，没有受他们的欺负，也未曾失落什么。</span>
<span className="v" id="v16" data-v="16" data-xref="约伯记 1:10; 出埃及记 14:22; 撒迦利亚书 2:5"> 我们在他们那里牧羊的时候，他们昼夜作我们的保障。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 20:7; 申命记 13:13; 撒母耳记上 20:9"> 所以你当筹划，看怎样行才好；不然，祸患定要临到我主人和他全家。他性情凶暴，无人敢与他说话。」</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 16:1; 马太福音 5:25; 箴言 6:4–5"> 亚比该急忙将二百饼，两皮袋酒，五只收拾好了的羊，五细亚烘好了的穗子，一百葡萄饼，二百无花果饼，都驮在驴上，</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 32:20; 创世记 32:16; 箴言 31:11–12"> 对仆人说：「你们前头走，我随着你们去。」这事她却没有告诉丈夫拿八。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 4:24"> 亚比该骑着驴，正下山坡，见大卫和跟随他的人从对面下来，亚比该就迎接他们。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 17:13; 以弗所书 4:31; 罗马书 12:21"> 大卫曾说：「我在旷野为那人看守所有的，以致他一样不失落，实在是徒然了！他向我以恶报善。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 14:10; 撒母耳记上 20:13; 撒母耳记上 3:17"> 凡属拿八的男丁，我若留一个到明日早晨，愿 神重重降罚与我！」</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 20:41; 士师记 1:14; 约书亚记 15:18"> 亚比该见大卫，便急忙下驴，在大卫面前脸伏于地叩拜，</span>
<span className="v" id="v24" data-v="24" data-xref="以斯帖记 8:3; 撒母耳记上 25:28; 撒母耳记下 14:9"> 俯伏在大卫的脚前，说：「我主啊，愿这罪归我！求你容婢女向你进言，更求你听婢女的话。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 25:17; 玛拉基书 2:2; 撒母耳记下 13:33"> 我主不要理这坏人拿八，他的性情与他的名相称；他名叫拿八<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="就是愚顽的意思">b</a></sup>，他为人果然愚顽。但我主所打发的仆人，婢女并没有看见。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 18:32; 罗马书 12:19–20; 创世记 20:6"> 我主啊，耶和华既然阻止你亲手报仇，取流血的罪，所以我指着永生的耶和华、又敢在你面前起誓说：『愿你的仇敌和谋害你的人都像拿八一样。』</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 33:11; 撒母耳记上 30:26; 列王纪下 5:15"> 如今求你将婢女送来的礼物给跟随你的仆人。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 18:17; 撒母耳记下 7:11; 撒母耳记上 24:11"> 求你饶恕婢女的罪过。耶和华必为我主建立坚固的家，因我主为耶和华争战；并且在你平生的日子查不出有什么过来。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 17:21; 马太福音 10:29–30; 玛拉基书 3:17"> 虽有人起来追逼你，寻索你的性命，你的性命却在耶和华—你的 神那里蒙保护，如包裹宝器一样；你仇敌的性命，耶和华必抛去，如用机弦甩石一样。</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 13:14; 诗篇 89:20; 撒母耳记上 23:17"> 我主现在若不亲手报仇流无辜人的血，到了耶和华照所应许你的话赐福与你，立你作以色列的王，那时我主必不至心里不安，觉得良心有亏。耶和华赐福与我主的时候，求你记念婢女。」</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 1:68; 出埃及记 18:10; 诗篇 72:18"> 大卫对亚比该说：「耶和华—以色列的 神是应当称颂的，因为他今日使你来迎接我。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记上 25:26; 箴言 28:23; 箴言 9:9"> 你和你的见识也当称赞；因为你今日拦阻我亲手报仇、流人的血。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记上 11:11; 撒母耳记上 25:26; 约书亚记 10:6"> 我指着阻止我加害于你的耶和华—以色列永生的 神起誓，你若不速速地来迎接我，到明日早晨，凡属拿八的男丁必定不留一个。」</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 19:21; 撒母耳记上 20:42; 列王纪下 5:19"> 大卫受了亚比该送来的礼物，就对她说：「我听了你的话，准了你的情面，你可以平平安安地回家吧！」</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳记上 25:19; 撒母耳记下 13:23; 撒母耳记下 13:28"> 亚比该到拿八那里，见他在家里设摆筵席，如同王的筵席；拿八快乐大醉。亚比该无论大小事都没有告诉他，就等到次日早晨。</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 28:28; 撒母耳记上 25:34; 撒母耳记上 25:22"> 到了早晨，拿八醒了酒，他的妻将这些事都告诉他，他就魂不附体，身僵如石头一般。</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳记上 26:10; 列王纪下 15:5; 撒母耳记上 6:9"> 过了十天，耶和华击打拿八，他就死了。</span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳记上 25:26; 撒母耳记上 25:34; 箴言 22:23"> 大卫听见拿八死了，就说：「应当称颂耶和华，因他伸了拿八羞辱我的冤，又阻止仆人行恶；也使拿八的恶归到拿八的头上。」于是大卫打发人去，与亚比该说，要娶她为妻。</span>
<span className="v" id="v40" data-v="40" data-xref="创世记 24:51; 创世记 24:37–38"> 大卫的仆人到了迦密见亚比该，对她说：「大卫打发我们来见你，想要娶你为妻。」</span>
<span className="v" id="v41" data-v="41" data-xref="提摩太前书 5:10; 约翰福音 13:3–5; 路得记 2:10"> 亚比该就起来，俯伏在地，说：「我情愿作婢女，洗我主仆人的脚。」</span>
<span className="v" id="v42" data-v="42" data-xref="创世记 24:61–67; 诗篇 45:10–11"> 亚比该立刻起身，骑上驴，带着五个使女，跟从大卫的使者去了，就作了大卫的妻。</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳记上 30:5; 约书亚记 15:56; 撒母耳记上 27:3"> 大卫先娶了耶斯列人亚希暖，她们二人都作了他的妻。</span>
<span className="v" id="v44" data-v="44" data-xref="撒母耳记下 3:14; 撒母耳记上 18:27; 撒母耳记上 18:20"> 扫罗已将他的女儿米甲，就是大卫的妻，给了迦琳人拉亿的儿子帕提为妻。</span>

## 以利加拿和他的家眷在示罗

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 6:34; 历代志上 6:25–27; 撒母耳记上 1:19"> 以法莲山地的拉玛·琐非有一个以法莲人，名叫以利加拿，是苏弗的玄孙，托户的曾孙，以利户的孙子，耶罗罕的儿子。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 16:1–2; 士师记 13:2; 创世记 29:23–29"> 他有两个妻：一名哈拿，一名毗尼拿。毗尼拿有儿女，哈拿没有儿女。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 2:41; 约书亚记 18:1; 申命记 12:5–7"> 这人每年从本城上到示罗，敬拜祭祀万军之耶和华；在那里有以利的两个儿子何弗尼、非尼哈当耶和华的祭司。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 12:17–18; 申命记 16:11; 申命记 12:5–7"> 以利加拿每逢献祭的日子，将祭肉分给他的妻毗尼拿和毗尼拿所生的儿女；</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 30:2; 创世记 29:30–31; 创世记 45:22"> 给哈拿的却是双分，因为他爱哈拿。无奈耶和华不使哈拿生育。</span>
<span className="v" id="v6" data-v="6" data-xref="约伯记 6:14; 约伯记 24:21; 利未记 18:18"> 毗尼拿见耶和华不使哈拿生育，就作她的对头，大大激动她，要使她生气。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 2:19"> 每年上到耶和华殿的时候，以利加拿都以双分给哈拿；毗尼拿仍是激动她，以致她哭泣不吃饭。</span>
<span className="v" id="v8" data-v="8" data-xref="路得记 4:15; 约伯记 6:14; 以赛亚书 54:6"> 她丈夫以利加拿对她说：「哈拿啊，你为何哭泣，不吃饭，心里愁闷呢？有我不比十个儿子还好吗？」</span>
</div>
</div>

## 哈拿和以利

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 3:3; 诗篇 27:4; 诗篇 5:7"> 他们在示罗吃喝完了，哈拿就站起来。祭司以利在耶和华殿的门框旁边，坐在自己的位上。</span>
<span className="v" id="v10" data-v="10" data-xref="约伯记 7:11; 路加福音 22:44; 约伯记 10:1"> 哈拿心里愁苦，就痛痛哭泣，祈祷耶和华，</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 13:5; 民数记 6:5; 创世记 29:32"> 许愿说：「万军之耶和华啊，你若垂顾婢女的苦情，眷念不忘婢女，赐我一个儿子，我必使他终身归与耶和华，不用剃头刀剃他的头。」</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦前书 5:17; 雅各书 5:16; 路加福音 18:1"> 哈拿在耶和华面前不住地祈祷，以利定睛看她的嘴。（</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 8:26; 使徒行传 2:13; 创世记 24:42–45"> 原来哈拿心中默祷，只动嘴唇，不出声音，因此以利以为她喝醉了。）</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所书 4:25; 约伯记 8:2; 箴言 6:9"> 以利对她说：「你要醉到几时呢？你不应该喝酒。」</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 62:8; 耶利米哀歌 2:19; 诗篇 42:4"> 哈拿回答说：「主啊，不是这样。我是心里愁苦的妇人，清酒浓酒都没有喝，但在耶和华面前倾心吐意。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 2:12; 约伯记 6:2–3; 马太福音 12:34–35"> 不要将婢女看作不正经的女子。我因被人激动，愁苦太多，所以祈求到如今。」</span>
<span className="v" id="v17" data-v="17" data-xref="马可福音 5:34; 士师记 18:6; 诗篇 20:3–5"> 以利说：「你可以平平安安地回去。愿以色列的 神允准你向他所求的！」</span>
<span className="v" id="v18" data-v="18" data-xref="路得记 2:13; 罗马书 15:13; 传道书 9:7"> 哈拿说：「愿婢女在你眼前蒙恩。」于是妇人走去吃饭，面上再不带愁容了。</span>
</div>
</div>

## 撒母耳出生和奉献

<div className="bt">
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="创世记 21:1; 创世记 30:22; 撒母耳记上 1:11"> 次日清早，他们起来，在耶和华面前敬拜，就回拉玛。到了家里，以利加拿和妻哈拿同房，耶和华顾念哈拿，</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 41:51–52; 马太福音 1:21; 出埃及记 2:10"> 哈拿就怀孕。日期满足，生了一个儿子，给他起名叫撒母耳，说：「这是我从耶和华那里求来的。」</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 1:3; 申命记 12:11; 约书亚记 24:15"> 以利加拿和他全家都上示罗去，要向耶和华献年祭，并还所许的愿。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 1:28; 撒母耳记上 1:11; 路加福音 2:22"> 哈拿却没有上去，对丈夫说：「等孩子断了奶，我便带他上去朝见耶和华，使他永远住在那里。」</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 7:25; 路加福音 11:27; 创世记 21:7–8"> 她丈夫以利加拿说：「就随你的意行吧！可以等儿子断了奶。但愿耶和华应验他的话。」于是妇人在家里乳养儿子，直到断了奶；</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 15:9–10; 约书亚记 18:1; 撒母耳记上 4:3–4"> 既断了奶，就把孩子带上示罗，到了耶和华的殿；又带了三只公牛，一伊法细面，一皮袋酒。（那时，孩子还小。）</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 18:15–16; 路加福音 2:22"> 宰了一只公牛，就领孩子到以利面前。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 4:30; 列王纪下 2:4; 列王纪下 2:6"> 妇人说：「主啊，我敢在你面前起誓，从前在你这里站着祈求耶和华的那妇人，就是我。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰一书 5:15; 诗篇 118:5; 马太福音 7:7"> 我祈求为要得这孩子；耶和华已将我所求的赐给我了。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 24:26; 创世记 24:52; 提摩太后书 3:15"> 所以，我将这孩子归与耶和华，使他终身归与耶和华。」<br /><span className="pl pl-1">于是在那里敬拜耶和华。</span></span>
</div>

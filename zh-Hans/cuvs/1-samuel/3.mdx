## 耶和华向撒母耳显现

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="阿摩司书 8:11–12; 诗篇 74:9; 撒母耳记上 3:21"> 童子撒母耳在以利面前事奉耶和华。当那些日子，耶和华的言语稀少，不常有默示。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 4:15; 诗篇 90:10; 创世记 27:1"> 一日，以利睡卧在自己的地方；他眼目昏花，看不分明。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 27:4; 利未记 24:2–4; 出埃及记 27:20–21"> 神的灯在 神耶和华殿内约柜那里，还没有熄灭，撒母耳已经睡了。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 6:8; 哥林多前书 12:6–11; 出埃及记 3:4"> 耶和华呼唤撒母耳。撒母耳说：「我在这里！」</span>
<span className="v" id="v5" data-v="5"> 就跑到以利那里，说：「你呼唤我？我在这里。」以利回答说：「我没有呼唤你，你去睡吧。」他就去睡了。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 9:2; 撒母耳记上 4:16; 撒母耳记下 18:22"> 耶和华又呼唤撒母耳。撒母耳起来，到以利那里，说：「你呼唤我？我在这里。」以利回答说：「我的儿，我没有呼唤你，你去睡吧。」</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 19:2; 耶利米书 9:24"> 那时撒母耳还未认识耶和华，也未得耶和华的默示。</span>
<span className="v" id="v8" data-v="8" data-xref="约伯记 33:14–15; 哥林多前书 13:11–12"> 耶和华第三次呼唤撒母耳。撒母耳起来，到以利那里，说：「你又呼唤我？我在这里。」以利才明白是耶和华呼唤童子。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 20:19; 以赛亚书 6:8; 诗篇 85:8"> 因此以利对撒母耳说：「你仍去睡吧；若再呼唤你，你就说：『耶和华啊，请说，仆人敬听！』」撒母耳就去，仍睡在原处。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 3:8; 撒母耳记上 3:4–6"> 耶和华又来站着，像前三次呼唤说：「撒母耳啊！撒母耳啊！」撒母耳回答说：「请说，仆人敬听！」</span>
<span className="v" id="v11" data-v="11" data-xref="哈巴谷书 1:5; 耶利米书 19:3; 列王纪下 21:12"> 耶和华对撒母耳说：「我在以色列中必行一件事，叫听见的人都必耳鸣。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 2:27–36; 撒迦利亚书 1:6; 约书亚记 23:15"> 我指着以利家所说的话，到了时候，我必始终应验在以利身上。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 19:18; 马太福音 10:37; 撒母耳记上 2:12"> 我曾告诉他必永远降罚与他的家，因他知道儿子作孽，自招咒诅，却不禁止他们。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 22:14; 撒母耳记上 2:25; 耶利米书 15:1"> 所以我向以利家起誓说：『以利家的罪孽，虽献祭奉礼物，永不能得赎去。』」</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米书 1:6–8; 玛拉基书 1:10; 撒母耳记上 1:9"> 撒母耳睡到天亮，就开了耶和华的殿门，不敢将默示告诉以利。</span>
<span className="v" id="v16" data-v="16"> 以利呼唤撒母耳说：「我儿撒母耳啊！」撒母耳回答说：「我在这里！」</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 3:35; 路得记 1:17; 诗篇 141:5"> 以利说：「耶和华对你说什么，你不要向我隐瞒；你若将 神对你所说的隐瞒一句，愿他重重地降罚与你。」</span>
<span className="v" id="v18" data-v="18" data-xref="约伯记 2:10; 以赛亚书 39:8; 士师记 10:15"> 撒母耳就把一切话都告诉了以利，并没有隐瞒。以利说：「这是出于耶和华，愿他凭自己的意旨而行。」</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="创世记 39:2; 撒母耳记上 9:6; 列王纪上 8:56"> 撒母耳长大了，耶和华与他同在，使他所说的话一句都不落空。</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 20:1; 撒母耳记下 3:10; 提摩太前书 1:12"> 从但到别是巴所有的以色列人都知道耶和华立撒母耳为先知。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 3:1; 创世记 12:7; 撒母耳记上 3:4"> 耶和华又在示罗显现；因为耶和华将自己的话默示撒母耳，撒母耳就把这话传遍以色列地。</span>
</div>
</div>

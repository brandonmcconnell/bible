## 扫罗见撒母耳

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 14:51; 使徒行传 13:21; 历代志上 9:36–39"> 有一个便雅悯人，名叫基士，是便雅悯人亚斐亚的玄孙，比歌拉的曾孙，洗罗的孙子，亚别的儿子，是个大能的勇士<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：大财主">a</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 6:2; 民数记 13:33; 撒母耳记上 16:7"> 他有一个儿子，名叫扫罗，又健壮、又俊美，在以色列人中没有一个能比他的；身体比众民高过一头。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 5:10; 撒母耳记上 10:2; 士师记 10:4"> 扫罗的父亲基士丢了几头驴，他就吩咐儿子扫罗说：「你带一个仆人去寻找驴。」</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 4:42; 约书亚记 24:33; 约翰福音 3:23"> 扫罗就走过以法莲山地，又过沙利沙地，都没有找着；又过沙琳地，驴也不在那里；又过便雅悯地，还没有找着。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 10:2; 撒母耳记上 1:1; 路加福音 12:11"> 到了苏弗地，扫罗对跟随他的仆人说：「我们不如回去，恐怕我父亲不为驴挂心，反为我们担忧。」</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 13:1; 申命记 33:1; 提摩太前书 6:11"> 仆人说：「这城里有一位神人，是众人所尊重的，凡他所说的全都应验。我们不如往他那里去，或者他能将我们当走的路指示我们。」</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 14:3; 列王纪下 8:8; 列王纪下 4:42"> 扫罗对仆人说：「我们若去，有什么可以送那人呢？我们囊中的食物都吃尽了，也没有礼物可以送那神人，我们还有什么没有？」</span>
<span className="v" id="v8" data-v="8"> 仆人回答扫罗说：「我手里有银子一舍客勒的四分之一，可以送那神人，请他指示我们当走的路。」（</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 30:10; 列王纪下 17:13; 阿摩司书 7:12"> 从前以色列中，若有人去问 神，就说：「我们问先见去吧！」现在称为「先知」的，从前称为「先见」。）</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 5:13–14"> 扫罗对仆人说：「你说的是，我们可以去。」于是他们往神人所住的城里去了。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 24:11; 出埃及记 2:16; 创世记 24:18–20"> 他们上坡要进城，就遇见几个少年女子出来打水，问她们说：「先见在这里没有？」</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 31:54; 撒母耳记上 16:2; 撒母耳记上 10:5"> 女子回答说：「在这里，他在你们前面。快去吧！他今日正到城里，因为今日百姓要在邱坛献祭。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 6:11; 马太福音 26:26; 路加福音 24:30"> 在他还没有上邱坛吃祭物之先，你们一进城必遇见他；因他未到，百姓不能吃，必等他先祝祭，然后请的客才吃。现在你们上去，这时候必遇见他。」</span>
<span className="v" id="v14" data-v="14"> 二人就上去；将进城的时候，撒母耳正迎着他们来，要上邱坛去。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 13:21; 撒母耳记上 15:1; 约伯记 33:16"> 扫罗未到的前一日，耶和华已经指示撒母耳说：</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 10:1; 诗篇 106:44; 出埃及记 3:7–9"> 「明日这时候，我必使一个人从便雅悯地到你这里来，你要膏他作我民以色列的君。他必救我民脱离非利士人的手；因我民的哀声上达于我，我就眷顾他们。」</span>
<span className="v" id="v17" data-v="17" data-xref="何西阿书 13:11; 撒母耳记上 16:6–12; 尼希米记 13:25"> 撒母耳看见扫罗的时候，耶和华对他说：「看哪，这人就是我对你所说的，他必治理我的民。」</span>
<span className="v" id="v18" data-v="18"> 扫罗在城门里走到撒母耳跟前，说：「请告诉我，先见的寓所在哪里？」</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 14:25; 约翰福音 4:29"> 撒母耳回答说：「我就是先见。你在我前面上邱坛去，因为你们今日必与我同席；明日早晨我送你去，将你心里的事都告诉你。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 8:5; 撒母耳记上 12:13; 撒母耳记上 9:3"> 至于你前三日所丢的那几头驴，你心里不必挂念，已经找着了。以色列众人所仰慕的是谁呢？不是仰慕你和你父的全家吗？」</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 15:17; 士师记 20:46–48; 诗篇 68:27"> 扫罗说：「我不是以色列支派中至小的便雅悯人吗？我家不是便雅悯支派中至小的家吗？你为何对我说这样的话呢？」</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 43:32; 路加福音 14:10"> 撒母耳领扫罗和他仆人进了客堂，使他们在请来的客中坐首位；客约有三十个人。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 1:5; 创世记 43:34"> 撒母耳对厨役说：「我交给你收存的那一分祭肉现在可以拿来。」</span>
<span className="v" id="v24" data-v="24" data-xref="以西结书 24:4; 利未记 7:32–33; 出埃及记 29:22"> 厨役就把收存的腿拿来，摆在扫罗面前，撒母耳说：「这是所留下的，放在你面前。吃吧！因我请百姓的时候，特意为你存留这肉到此时。」 当日，扫罗就与撒母耳同席。</span>
</div>
</div>

## 撒母耳膏扫罗作王

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行传 10:9; 申命记 22:8; 撒母耳记下 11:2"> 众人从邱坛下来进城，撒母耳和扫罗在房顶上说话。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 44:4; 约书亚记 7:13; 士师记 19:28"> 次日清早起来，黎明的时候，扫罗在房顶上。撒母耳呼叫他说：「起来吧，我好送你回去。」扫罗就起来，和撒母耳一同出去。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 15:14–15; 撒母耳记上 20:38–39; 列王纪下 9:5–6"> 二人下到城角，撒母耳对扫罗说：「要吩咐仆人先走（仆人就先走了）；你且站在这里，等我将 神的话传与你听。」</span>

## 以色列人要求立王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 16:18–19; 提摩太前书 5:21; 尼希米记 7:2"> 撒母耳年纪老迈，就立他儿子作以色列的士师。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 6:38; 创世记 22:19; 历代志上 6:28"> 长子名叫约珥，次子名叫亚比亚；他们在别是巴作士师。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 16:19; 诗篇 15:5; 提摩太前书 6:10"> 他儿子不行他的道，贪图财利，收受贿赂，屈枉正直。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 7:17; 撒母耳记下 5:3; 出埃及记 3:16"> 以色列的长老都聚集，来到拉玛见撒母耳，</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 17:14–15; 何西阿书 13:10–11; 撒母耳记上 8:6–8"> 对他说：「你年纪老迈了，你儿子不行你的道。现在求你为我们立一个王治理我们，像列国一样。」</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 15:11; 雅各书 1:5; 撒母耳记上 12:17"> 撒母耳不喜悦他们说「立一个王治理我们」，他就祷告耶和华。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 10:16; 撒母耳记上 10:19; 出埃及记 16:8"> 耶和华对撒母耳说：「百姓向你说的一切话，你只管依从；因为他们不是厌弃你，乃是厌弃我，不要我作他们的王。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 106:34–40; 出埃及记 32:1; 士师记 13:1"> 自从我领他们出埃及到如今，他们常常离弃我，事奉别神。现在他们向你所行的，是照他们素来所行的。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 10:25; 撒母耳记上 8:11–18; 以西结书 46:18"> 故此你要依从他们的话，只是当警戒他们，告诉他们将来那王怎样管辖他们。」</span>
<span className="v" id="v10" data-v="10"> 撒母耳将耶和华的话都传给求他立王的百姓，说：</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 14:52; 申命记 17:14–20; 撒母耳记上 10:25"> 「管辖你们的王必这样行：他必派你们的儿子为他赶车、跟马，奔走在车前；</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 22:7; 列王纪上 4:7; 历代志上 27:1–22"> 又派他们作千夫长、五十夫长，为他耕种田地，收割庄稼，打造军器和车上的器械；</span>
<span className="v" id="v13" data-v="13"> 必取你们的女儿为他制造香膏，做饭烤饼；</span>
<span className="v" id="v14" data-v="14" data-xref="以西结书 46:18; 列王纪上 21:7; 列王纪上 21:19"> 也必取你们最好的田地、葡萄园、橄榄园赐给他的臣仆。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理书 1:3; 以赛亚书 39:7; 创世记 37:36"> 你们的粮食和葡萄园所出的，他必取十分之一给他的太监和臣仆；</span>
<span className="v" id="v16" data-v="16"> 又必取你们的仆人婢女，健壮的少年人和你们的驴，供他的差役。</span>
<span className="v" id="v17" data-v="17"> 你们的羊群他必取十分之一，你们也必作他的仆人。</span>
<span className="v" id="v18" data-v="18" data-xref="弥迦书 3:4; 以赛亚书 1:15; 箴言 1:25–28"> 那时你们必因所选的王哀求耶和华，耶和华却不应允你们。」</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 44:16; 耶利米书 7:13; 以赛亚书 66:4"> 百姓竟不肯听撒母耳的话，说：「不然！我们定要一个王治理我们，</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 8:5; 诗篇 106:35; 申命记 7:6"> 使我们像列国一样，有王治理我们，统领我们，为我们争战。」</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 11:11"> 撒母耳听见百姓这一切话，就将这话陈明在耶和华面前。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 8:7; 何西阿书 13:11"> 耶和华对撒母耳说：「你只管依从他们的话，为他们立王。」撒母耳对以色列人说：「你们各归各城去吧！」</span>

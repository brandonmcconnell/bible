## 扫罗求问女巫

<div className="bt">
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="利未记 19:31; 撒母耳记上 25:1; 利未记 20:27"> 那时撒母耳已经死了，以色列众人为他哀哭，葬他在拉玛，就是在他本城里。扫罗曾在国内不容有交鬼的和行巫术的人。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 31:1; 约书亚记 19:18; 列王纪下 4:8"> 非利士人聚集，来到书念安营；扫罗聚集以色列众人在基利波安营。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 57:20–21; 但以理书 5:6; 以赛亚书 21:3–4"> 扫罗看见非利士的军旅就惧怕，心中发颤。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 12:6; 撒母耳记上 14:37; 耶利米哀歌 2:9"> 扫罗求问耶和华，耶和华却不借梦，或乌陵，或先知回答他。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 16:16; 约书亚记 17:11; 历代志上 10:13"> 扫罗吩咐臣仆说：「当为我找一个交鬼的妇人，我好去问她。」臣仆说：「在隐·多珥有一个交鬼的妇人。」</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 8:19; 历代志上 10:13; 列王纪上 22:30"> 于是扫罗改了装，穿上别的衣服，带着两个人，夜里去见那妇人。扫罗说：「求你用交鬼的法术，将我所告诉你的死人，为我招上来。」</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 28:3; 列王纪下 5:7; 撒母耳记下 18:13"> 妇人对他说：「你知道扫罗从国中剪除交鬼的和行巫术的。你为何陷害我的性命，使我死呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 14:11; 撒母耳记上 19:6; 申命记 18:10–12"> 扫罗向妇人指着耶和华起誓说：「我指着永生的耶和华起誓，你必不因这事受刑。」</span>
<span className="v" id="v11" data-v="11"> 妇人说：「我为你招谁上来呢？」回答说：「为我招撒母耳上来。」</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 28:3; 列王纪上 14:5"> 妇人看见撒母耳，就大声呼叫，对扫罗说：「你是扫罗，为什么欺哄我呢？」</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 82:6–7; 约翰福音 10:34–35; 出埃及记 22:28"> 王对妇人说：「不要惧怕，你看见了什么呢？」妇人对扫罗说：「我看见有神从地里上来。」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 15:27; 列王纪下 2:8; 撒母耳记上 24:8"> 扫罗说：「他是怎样的形状？」妇人说：「有一个老人上来，身穿长衣。」扫罗知道是撒母耳，就屈身，脸伏于地下拜。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 16:23–26; 撒母耳记上 28:6; 撒母耳记上 18:12"> 撒母耳对扫罗说：「你为什么搅扰我，招我上来呢？」扫罗回答说：「我甚窘急；因为非利士人攻击我， 神也离开我，不再借先知或梦回答我。因此请你上来，好指示我应当怎样行。」</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 6:27; 耶利米哀歌 2:5; 诗篇 68:1–3"> 撒母耳说：「耶和华已经离开你，且与你为敌，你何必问我呢？</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 15:27–29; 撒母耳记上 16:13; 撒母耳记上 13:13–14"> 耶和华照他借我说的话，已经从你手里夺去国权，赐与别人，就是大卫。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 15:9; 列王纪上 20:42; 诗篇 50:21–22"> 因你没有听从耶和华的命令；他恼怒亚玛力人，你没有灭绝他们，所以今日耶和华向你这样行，</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 5:5; 耶利米书 28:16–17; 列王纪上 22:20"> 并且耶和华必将你和以色列人交在非利士人的手里。明日你和你众子必与我在一处了；耶和华必将以色列的军兵交在非利士人手里。」</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 28:5; 约伯记 26:2; 约伯记 15:20–24"> 扫罗猛然仆倒，挺身在地，因撒母耳的话甚是惧怕；那一昼一夜，没有吃什么，就毫无气力。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 12:3; 约伯记 13:14; 撒母耳记上 19:5"> 妇人到扫罗面前，见他极其惊恐，对他说：「婢女听从你的话，不顾惜自己的性命，遵从你所吩咐的。</span>
<span className="v" id="v22" data-v="22"> 现在求你听婢女的话，容我在你面前摆上一点食物，你吃了，可以有气力行路。」</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 21:4; 路加福音 24:29; 路加福音 14:23"> 扫罗不肯，说：「我不吃。」但他的仆人和妇人再三劝他，他才听了他们的话，从地上起来，坐在床上。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 15:23; 创世记 18:7–8"> 妇人急忙将家里的一只肥牛犊宰了，又拿面抟成无酵饼烤了，</span>
<span className="v" id="v25" data-v="25"> 摆在扫罗和他仆人面前。他们吃完，当夜就起身走了。</span>
</div>

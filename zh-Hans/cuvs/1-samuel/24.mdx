## 大卫饶扫罗的命

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 23:28–29; 以西结书 22:9; 撒母耳记上 23:19"> 扫罗追赶非利士人回来，有人告诉他说：「大卫在隐·基底的旷野。」</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 26:2; 诗篇 104:18; 诗篇 37:32"> 扫罗就从以色列人中挑选三千精兵，率领他们往野羊的磐石去，寻索大卫和跟随他的人。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 3:24; 诗篇 57:1–11; 诗篇 142:1–7"> 到了路旁的羊圈，在那里有洞，扫罗进去大解。大卫和跟随他的人正藏在洞里的深处。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 26:8–11; 撒母耳记上 24:10; 撒母耳记上 26:23"> 跟随的人对大卫说：「耶和华曾应许你说：『我要将你的仇敌交在你手里，你可以任意待他。』如今时候到了！」大卫就起来，悄悄地割下扫罗外袍的衣襟。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 24:10; 列王纪下 22:19; 约翰一书 3:20–21"> 随后大卫心中自责，因为割下扫罗的衣襟；</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 1:14; 约伯记 31:29–30; 撒母耳记上 26:9–11"> 对跟随他的人说：「我的主乃是耶和华的受膏者，我在耶和华面前万不敢伸手害他，因他是耶和华的受膏者。」</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 5:44; 诗篇 7:4; 罗马书 12:17–21"> 大卫用这话拦住跟随他的人，不容他们起来害扫罗。扫罗起来，从洞里出去行路。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 25:23–24; 罗马书 13:7; 出埃及记 20:12"> 随后大卫也起来，从洞里出去，呼叫扫罗说：「我主，我王！」扫罗回头观看，大卫就屈身、脸伏于地下拜。</span>
<span className="v" id="v9" data-v="9" data-xref="传道书 7:21–22; 箴言 29:12; 箴言 16:28"> 大卫对扫罗说：「你为何听信人的谗言，说大卫想要害你呢？</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 105:15; 撒母耳记上 24:4; 撒母耳记上 26:8–9"> 今日你亲眼看见在洞中，耶和华将你交在我手里；有人叫我杀你，我却爱惜你，说：『我不敢伸手害我的主，因为他是耶和华的受膏者。』</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 26:20; 撒母耳记上 23:14; 撒母耳记上 23:23"> 我父啊，看看你外袍的衣襟在我手中。我割下你的衣襟，没有杀你；你由此可以知道我没有恶意叛逆你。你虽然猎取我的命，我却没有得罪你。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 43:1; 士师记 11:27; 诗篇 35:1"> 愿耶和华在你我中间判断是非，在你身上为我伸冤，我却不亲手加害于你。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 7:20; 马太福音 7:16–18; 马太福音 12:33–34"> 古人有句俗语说：『恶事出于恶人。』我却不亲手加害于你。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 26:20; 撒母耳记上 17:43; 撒母耳记下 9:8"> 以色列王出来要寻找谁呢？追赶谁呢？不过追赶一条死狗，一个虼蚤就是了。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 43:1; 诗篇 35:1; 诗篇 119:154"> 愿耶和华在你我中间施行审判，断定是非，并且鉴察，为我伸冤，救我脱离你的手。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 26:17; 创世记 33:4; 路加福音 21:15"> 大卫向扫罗说完这话，扫罗说：「我儿大卫，这是你的声音吗？」就放声大哭，</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 5:44; 撒母耳记上 26:21; 创世记 38:26"> 对大卫说：「你比我公义；因为你以善待我，我却以恶待你。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 26:23; 诗篇 31:8; 撒母耳记上 23:12"> 你今日显明是以善待我；因为耶和华将我交在你手里，你却没有杀我。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 18:20; 撒母耳记上 23:21; 箴言 25:21–22"> 人若遇见仇敌，岂肯放他平安无事地去呢？愿耶和华因你今日向我所行的，以善报你。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 23:17; 马太福音 2:3–6; 撒母耳记下 3:17–18"> 我也知道你必要作王，以色列的国必坚立在你手里。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 21:23; 撒母耳记下 21:6–8; 撒母耳记上 20:14–17"> 现在你要指着耶和华向我起誓，不剪除我的后裔，在我父家不灭没我的名。」</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 23:29; 约翰福音 2:24; 马太福音 10:16–17"> 于是大卫向扫罗起誓，扫罗就回家去；大卫和跟随他的人上山寨去了。</span>
</div>
</div>

## 大卫又饶扫罗的命

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 23:19; 诗篇 54:1–7; 约书亚记 15:24"> 西弗人到基比亚见扫罗，说：「大卫不是在旷野前的哈基拉山藏着吗？」</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 24:2; 撒母耳记上 13:2; 诗篇 140:4–9"> 扫罗就起身，带领以色列人中挑选的三千精兵下到西弗的旷野，要在那里寻索大卫。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 23:19; 撒母耳记上 26:1"> 扫罗在旷野前的哈基拉山，在道路上安营。大卫住在旷野，听说扫罗到旷野来追寻他，</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 10:16; 约书亚记 2:1"> 就打发人去探听，便知道扫罗果然来到。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 17:55; 撒母耳记上 17:20; 撒母耳记上 14:50–51"> 大卫起来，到扫罗安营的地方，看见扫罗和他的元帅尼珥的儿子押尼珥睡卧之处；扫罗睡在辎重营里，百姓安营在他周围。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 7:10–11; 撒母耳记下 2:18; 创世记 15:20"> 大卫对赫人亚希米勒和洗鲁雅的儿子约押的兄弟亚比筛说：「谁同我下到扫罗营里去？」亚比筛说：「我同你下去。」</span>
<span className="v" id="v7" data-v="7" data-xref="帖撒罗尼迦前书 5:2–3"> 于是大卫和亚比筛夜间到了百姓那里，见扫罗睡在辎重营里；他的枪在头旁，插在地上。押尼珥和百姓睡在他周围。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 24:4; 撒母耳记上 26:23; 申命记 32:30"> 亚比筛对大卫说：「现在 神将你的仇敌交在你手里，求你容我拿枪将他刺透在地，一刺就成，不用再刺。」</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 1:14; 诗篇 105:15; 撒母耳记下 1:16"> 大卫对亚比筛说：「不可害死他。有谁伸手害耶和华的受膏者而无罪呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 47:29; 申命记 31:14; 诗篇 37:13"> 大卫又说：「我指着永生的耶和华起誓，他或被耶和华击打，或是死期到了，或是出战阵亡；</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 24:6; 撒母耳记上 24:12; 撒母耳记下 1:14"> 我在耶和华面前，万不敢伸手害耶和华的受膏者。现在你可以将他头旁的枪和水瓶拿来，我们就走。」</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 2:21; 创世记 15:12; 以赛亚书 29:10"> 大卫从扫罗的头旁拿了枪和水瓶，二人就走了，没有人看见，没有人知道，也没有人醒起，都睡着了，因为耶和华使他们沉沉地睡了。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 24:8; 士师记 9:7"> 大卫过到那边去，远远地站在山顶上，与他们相离甚远。</span>
<span className="v" id="v14" data-v="14"> 大卫呼叫百姓和尼珥的儿子押尼珥说：「押尼珥啊，你为何不答应呢？」押尼珥说：「你是谁？竟敢呼叫王呢？」</span>
<span className="v" id="v15" data-v="15"> 大卫对押尼珥说：「你不是个勇士吗？以色列中谁能比你呢？民中有人进来要害死王—你的主，你为何没有保护王—你的主呢？</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 79:11; 撒母耳记下 12:5; 撒母耳记上 26:9"> 你这样是不好的！我指着永生的耶和华起誓，你们都是该死的；因为没有保护你们的主，就是耶和华的受膏者。现在你看看王头旁的枪和水瓶在哪里。」</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 24:16; 撒母耳记上 24:8"> 扫罗听出是大卫的声音，就说：「我儿大卫，这是你的声音吗？」大卫说：「主—我的王啊，是我的声音」；</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 24:9; 撒母耳记上 24:11–14; 约翰福音 10:32"> 又说：「我做了什么？我手里有什么恶事？我主竟追赶仆人呢？</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 14:16; 撒母耳记下 16:11; 撒母耳记下 20:19"> 求我主我王听仆人的话：若是耶和华激发你攻击我，愿耶和华收纳祭物；若是人激发你，愿他在耶和华面前受咒诅；因为他现今赶逐我，不容我在耶和华的产业上有分，说：『你去事奉别神吧！』</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 24:14; 马太福音 26:55; 撒母耳记上 25:29"> 现在求王不要使我的血流在离耶和华远的地方。以色列王出来是寻找一个虼蚤，如同人在山上猎取一个鹧鸪一般。」</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 15:24; 撒母耳记上 24:17; 出埃及记 9:27"> 扫罗说：「我有罪了！我儿大卫，你可以回来，因你今日看我的性命为宝贵；我必不再加害于你。我是糊涂人，大大错了。」</span>
<span className="v" id="v22" data-v="22"> 大卫说：「王的枪在这里，可以吩咐一个仆人过来拿去。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 62:12; 撒母耳记上 24:6–7; 诗篇 18:20–26"> 今日耶和华将王交在我手里，我却不肯伸手害耶和华的受膏者。耶和华必照各人的公义诚实报应他。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 5:7; 哥林多后书 1:9–10; 诗篇 54:7"> 我今日重看你的性命，愿耶和华也重看我的性命，并且拯救我脱离一切患难。」</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 24:9–10; 箴言 26:25; 撒母耳记上 24:19"> 扫罗对大卫说：「我儿大卫，愿你得福！你必做大事，也必得胜。」于是大卫起行，扫罗回他的本处去了。</span>

## 扫罗击败亚扪人

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 12:12; 列王纪上 20:34; 以西结书 17:13"> 亚扪人的王拿辖上来，对着基列·雅比安营。雅比众人对拿辖说：「你与我们立约，我们就服事你。」</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 17:26; 创世记 34:14; 民数记 16:14"> 亚扪人拿辖说：「你们若由我剜出你们各人的右眼，以此凌辱以色列众人，我就与你们立约。」</span>
<span className="v" id="v3" data-v="3"> 雅比的长老对他说：「求你宽容我们七日，等我们打发人往以色列的全境去；若没有人救我们，我们就出来归顺你。」</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 2:4; 撒母耳记上 10:26; 撒母耳记上 15:34"> 使者到了扫罗住的基比亚，将这话说给百姓听，百姓就都放声而哭。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪上 19:19; 士师记 18:23; 创世记 21:17"> 扫罗正从田间赶牛回来，问说：「百姓为什么哭呢？」众人将雅比人的话告诉他。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 10:10; 撒母耳记上 16:13; 士师记 6:34"> 扫罗听见这话，就被 神的灵大大感动，甚是发怒。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 19:29; 士师记 20:1; 士师记 21:5–11"> 他将一对牛切成块子，托付使者传送以色列的全境，说：「凡不出来跟随扫罗和撒母耳的，也必这样切开他的牛。」于是耶和华使百姓惧怕，他们就都出来，如同一人。</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 1:4–5; 撒母耳记下 24:9; 历代志下 17:12–19"> 扫罗在比色数点他们：以色列人有三十万，犹大人有三万。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 18:17"> 众人对那使者说：「你们要回复基列·雅比人说，明日太阳近午的时候，你们必得解救。」使者回去告诉雅比人，他们就欢喜了。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 11:2–3"> 于是雅比人对亚扪人说：「明日我们出来归顺你们，你们可以随意待我们。」</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 7:16; 雅各书 2:13; 出埃及记 14:24"> 第二日，扫罗将百姓分为三队，在晨更的时候入了亚扪人的营，击杀他们直到太阳近午，剩下的人都逃散，没有二人同在一处的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 10:27; 路加福音 19:27; 诗篇 21:8"> 百姓对撒母耳说：「那说『扫罗岂能管理我们』的是谁呢？可以将他交出来，我们好杀死他。」</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 19:22; 撒母耳记上 19:5; 出埃及记 14:13"> 扫罗说：「今日耶和华在以色列中施行拯救，所以不可杀人。」</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 10:8; 撒母耳记上 7:16; 历代志上 12:38–39"> 撒母耳对百姓说：「我们要往吉甲去，在那里立国。」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 10:8; 撒母耳记上 10:17; 历代志上 29:21–24"> 众百姓就到了吉甲那里，在耶和华面前立扫罗为王，又在耶和华面前献平安祭。扫罗和以色列众人大大欢喜。</span>
</div>
</div>

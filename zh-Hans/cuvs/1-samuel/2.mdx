## 哈拿的祷告

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="路加福音 1:46–56; 诗篇 13:5; 以赛亚书 12:2–3"> 哈拿祷告说：<br /><span className="pl pl-1">我的心因耶和华快乐；</span><br /><span className="pl pl-1">我的角因耶和华高举。</span><br /><span className="pl pl-1">我的口向仇敌张开；</span><br /><span className="pl pl-1">我因耶和华的救恩欢欣。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 22:32; 以赛亚书 44:6; 诗篇 86:8"> <span className="pl pl-1">只有耶和华为圣；</span><br /><span className="pl pl-1">除他以外没有可比的，</span><br /><span className="pl pl-1">也没有磐石像我们的 神。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="箴言 8:13; 列王纪上 8:39; 箴言 24:12"> <span className="pl pl-1">人不要夸口说骄傲的话，</span><br /><span className="pl pl-1">也不要出狂妄的言语；</span><br /><span className="pl pl-1">因耶和华是大有智识的 神，</span><br /><span className="pl pl-1">人的行为被他衡量。</span><br /></span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 76:3; 诗篇 37:15; 诗篇 46:9"> <span className="pl pl-1">勇士的弓都已折断；</span><br /><span className="pl pl-1">跌倒的人以力量束腰。</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 15:9; 路加福音 1:53; 诗篇 113:9"> <span className="pl pl-1">素来饱足的，反作用人求食；</span><br /><span className="pl pl-1">饥饿的，再不饥饿。</span><br /><span className="pl pl-1">不生育的，生了七个儿子；</span><br /><span className="pl pl-1">多有儿女的，反倒衰微。</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="申命记 32:39; 以赛亚书 26:19; 启示录 1:18"> <span className="pl pl-1">耶和华使人死，也使人活，</span><br /><span className="pl pl-1">使人下阴间，也使人往上升。</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 75:7; 约伯记 5:11; 申命记 8:17–18"> <span className="pl pl-1">他使人贫穷，也使人富足，</span><br /><span className="pl pl-1">使人卑微，也使人高贵。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 113:7–8; 但以理书 2:48; 雅各书 2:5"> <span className="pl pl-1">他从灰尘里抬举贫寒人，</span><br /><span className="pl pl-1">从粪堆中提拔穷乏人，</span><br /><span className="pl pl-1">使他们与王子同坐，</span><br /><span className="pl pl-1">得着荣耀的座位。</span><br /><span className="pl pl-1">地的柱子属于耶和华；</span><br /><span className="pl pl-1">他将世界立在其上。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="诗篇 121:3; 诗篇 91:11–12; 诗篇 33:16–17"> <span className="pl pl-1">他必保护圣民的脚步，</span><br /><span className="pl pl-1">使恶人在黑暗中寂然不动；</span><br /><span className="pl pl-1">人都不能靠力量得胜。</span><br /></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 2:9; 诗篇 89:24; 诗篇 18:13–14"> <span className="pl pl-1">与耶和华争竞的，必被打碎；</span><br /><span className="pl pl-1">耶和华必从天上以雷攻击他，</span><br /><span className="pl pl-1">必审判地极的人，</span><br /><span className="pl pl-1">将力量赐与所立的王，</span><br /><span className="pl pl-1">高举受膏者的角。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 3:1; 撒母耳记上 2:18; 撒母耳记上 1:28"> 以利加拿往拉玛回家去了。那孩子在祭司以利面前事奉耶和华。</span>
</div>
</div>

## 以利的两个儿子

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="罗马书 1:28–30; 耶利米书 2:8; 士师记 2:10"> 以利的两个儿子是恶人，不认识耶和华。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 7:29–34"> 这二祭司待百姓是这样的规矩：凡有人献祭，正煮肉的时候，祭司的仆人就来，手拿三齿的叉子，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 29:27–28; 以赛亚书 56:11; 撒母耳记上 2:29"> 将叉子往罐里，或鼎里，或釜里，或锅里一插，插上来的肉，祭司都取了去。凡上到示罗的以色列人，他们都是这样看待。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 3:16; 利未记 3:3–5; 罗马书 16:18"> 又在未烧脂油以前，祭司的仆人就来对献祭的人说：「将肉给祭司，叫他烤吧。他不要煮过的，要生的。」</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 7:23–25; 利未记 3:16; 彼得前书 5:2–3"> 献祭的人若说：「必须先烧脂油，然后你可以随意取肉。」仆人就说：「你立时给我，不然我便抢去。」</span>
<span className="v" id="v17" data-v="17" data-xref="玛拉基书 2:7–9; 创世记 13:13; 玛拉基书 2:13"> 如此，这二少年人的罪在耶和华面前甚重了，因为他们藐视耶和华的祭物<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：他们使人厌弃给耶和华献祭">a</a></sup>。</span>
</div>
</div>

## 撒母耳在示罗

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 3:1; 出埃及记 28:4; 撒母耳记上 2:11"> 那时，撒母耳还是孩子，穿着细麻布的以弗得，侍立在耶和华面前。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 1:3; 撒母耳记上 1:21; 出埃及记 23:14"> 他母亲每年为他做一件小外袍，同着丈夫上来献年祭的时候带来给他。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 1:27–28; 路加福音 2:34; 路得记 4:11"> 以利为以利加拿和他的妻祝福，说：「愿耶和华由这妇人再赐你后裔，代替你从耶和华求来的孩子。」他们就回本乡去了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 2:40; 撒母耳记上 3:19; 创世记 21:1"> 耶和华眷顾哈拿，她就怀孕生了三个儿子，两个女儿。那孩子撒母耳在耶和华面前渐渐长大。</span>
</div>
</div>

## 以利和他的儿子

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及记 38:8; 撒母耳记上 2:13–17; 耶利米书 7:9–10"> 以利年甚老迈，听见他两个儿子待以色列众人的事，又听见他们与会幕门前伺候的妇人苟合，</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 8:12; 腓立比书 3:19; 使徒行传 9:4"> 他就对他们说：「你们为何行这样的事呢？我从这众百姓听见你们的恶行。</span>
<span className="v" id="v24" data-v="24" data-xref="玛拉基书 2:8; 提摩太前书 3:7; 使徒行传 6:3"> 我儿啊，不可这样！我听见你们的风声不好，你们使耶和华的百姓犯了罪。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 3:14; 约书亚记 11:20; 希伯来书 10:26"> 人若得罪人，有士师审判他；人若得罪耶和华，谁能为他祈求呢？」然而他们还是不听父亲的话，因为耶和华想要杀他们。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 2:52; 路加福音 2:40; 使徒行传 2:47"> 孩子撒母耳渐渐长大，耶和华与人越发喜爱他。</span>
</div>
</div>

## 预言以利家遭祸

<div className="bt">
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="申命记 33:1; 出埃及记 4:27; 出埃及记 4:14–16"> 有神人来见以利，对他说：「耶和华如此说：『你祖父在埃及法老家作奴仆的时候，我不是向他们显现吗？</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 28:1; 利未记 8:7–8; 民数记 18:19"> 在以色列众支派中，我不是拣选人作我的祭司，使他烧香，在我坛上献祭，在我面前穿以弗得，又将以色列人所献的火祭都赐给你父家吗？</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 10:37; 申命记 32:15; 撒母耳记上 2:13–17"> 我所吩咐献在我居所的祭物，你们为何践踏？尊重你的儿子过于尊重我，将我民以色列所献美好的祭物肥己呢？』</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 12:26; 耶利米书 18:9–10; 箴言 3:9–10"> 因此，耶和华—以色列的 神说：『我曾说，你和你父家必永远行在我面前；现在我却说，决不容你们这样行。因为尊重我的，我必重看他；藐视我的，他必被轻视。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记上 22:17–20; 列王纪上 2:26–27; 诗篇 37:17"> 日子必到，我要折断你的膀臂和你父家的膀臂，使你家中没有一个老年人。</span>
<span className="v" id="v32" data-v="32" data-xref="撒迦利亚书 8:4; 撒母耳记上 4:11; 诗篇 78:59–64"> 在 神使以色列人享福的时候，你必看见我居所的败落。在你家中必永远没有一个老年人。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪上 2:26–27; 列王纪上 1:7; 撒母耳记上 22:21–23"> 我必不从我坛前灭尽你家中的人；那未灭的必使你眼目干瘪、心中忧伤。你家中所生的人都必死在中年。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记上 4:11; 列王纪上 13:3; 撒母耳记上 4:17"> 你的两个儿子何弗尼、非尼哈所遭遇的事可作你的证据：他们二人必一日同死。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 7:27; 撒母耳记下 7:11; 列王纪上 11:38"> 我要为自己立一个忠心的祭司；他必照我的心意而行。我要为他建立坚固的家；他必永远行在我的受膏者面前。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 2:27; 玛拉基书 1:13; 以西结书 44:10–12"> 你家所剩下的人都必来叩拜他，求块银子，求个饼，说：求你赐我祭司的职分，好叫我得点饼吃。』」</span>
</div>
</div>

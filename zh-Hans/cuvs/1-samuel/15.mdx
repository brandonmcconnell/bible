## 与亚玛力人争战

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 9:16; 撒母耳记上 12:14; 诗篇 2:10–11"> 撒母耳对扫罗说：「耶和华差遣我膏你为王，治理他的百姓以色列；所以你当听从耶和华的话。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 25:17–19; 出埃及记 17:8–16; 民数记 24:20"> 万军之耶和华如此说：『以色列人出埃及的时候，在路上亚玛力人怎样待他们，怎样抵挡他们，我都没忘。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 20:16–18; 民数记 24:20; 民数记 31:17"> 现在你要去击打亚玛力人，灭尽他们所有的，不可怜惜他们，将男女、孩童、吃奶的，并牛、羊、骆驼，和驴尽行杀死。』」</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 15:24; 撒母耳记上 11:8; 撒母耳记上 13:15"> 于是扫罗招聚百姓在提拉因，数点他们，共有步兵二十万，另有犹大人一万。</span>
<span className="v" id="v5" data-v="5"> 扫罗到了亚玛力的京城，在谷中设下埋伏。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 1:16; 民数记 10:29–32; 出埃及记 18:19"> 扫罗对基尼人说：「你们离开亚玛力人下去吧，恐怕我将你们和亚玛力人一同杀灭；因为以色列人出埃及的时候，你们曾恩待他们。」于是基尼人离开亚玛力人去了。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 16:7; 创世记 25:18; 撒母耳记上 14:48"> 扫罗击打亚玛力人，从哈腓拉直到埃及前的书珥，</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 30:1; 以斯帖记 3:1; 民数记 24:7"> 生擒了亚玛力王亚甲，用刀杀尽亚玛力的众民。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 15:15; 撒母耳记上 15:19; 撒母耳记上 15:3"> 扫罗和百姓却怜惜亚甲，也爱惜上好的牛、羊、牛犊、羊羔，并一切美物，不肯灭绝。凡下贱瘦弱的，尽都杀了。</span>
</div>
</div>

## 扫罗被废

<div className="bt">
<div className="bp poetry">
<span className="v" id="v10" data-v="10"> 耶和华的话临到撒母耳说：</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 13:13; 创世记 6:6; 撒母耳记下 24:16"> 「我立扫罗为王，我后悔了；因为他转去不跟从我，不遵守我的命令。」撒母耳便甚忧愁，终夜哀求耶和华。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 15:55; 撒母耳记下 18:18; 撒母耳记上 25:2"> 撒母耳清早起来，迎接扫罗。有人告诉撒母耳说：「扫罗到了迦密，在那里立了纪念碑，又转身下到吉甲。」</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 17:2; 路得记 3:10; 箴言 31:31"> 撒母耳到了扫罗那里，扫罗对他说：「愿耶和华赐福与你，耶和华的命令我已遵守了。」</span>
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 3:13–15; 耶利米书 2:18–19; 耶利米书 2:34–37"> 撒母耳说：「我耳中听见有羊叫、牛鸣，是从哪里来的呢？」</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 15:21; 撒母耳记上 15:9; 出埃及记 32:22–23"> 扫罗说：「这是百姓从亚玛力人那里带来的；因为他们爱惜上好的牛羊，要献与耶和华—你的 神；其余的，我们都灭尽了。」</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 9:27; 列王纪上 22:16; 撒母耳记上 12:7"> 撒母耳对扫罗说：「你住口吧！等我将耶和华昨夜向我所说的话告诉你。」扫罗说：「请讲。」</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 10:22; 撒母耳记上 9:21; 撒母耳记上 15:1–3"> 撒母耳对扫罗说：「从前你虽然以自己为小，岂不是被立为以色列支派的元首吗？耶和华膏你作以色列的王。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:29; 创世记 13:13; 创世记 15:16"> 耶和华差遣你，吩咐你说，你去击打那些犯罪的亚玛力人，将他们灭绝净尽。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 14:32; 历代志下 33:6; 历代志下 36:12"> 你为何没有听从耶和华的命令，急忙掳掠财物，行耶和华眼中看为恶的事呢？」</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 15:13; 马太福音 19:20; 罗马书 10:3"> 扫罗对撒母耳说：「我实在听从了耶和华的命令，行了耶和华所差遣我行的路，擒了亚玛力王亚甲来，灭尽了亚玛力人。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 15:15; 出埃及记 32:22–23; 创世记 3:13"> 百姓却在所当灭的物中，取了最好的牛羊，要在吉甲献与耶和华—你的 神。」</span>
<span className="v" id="v22" data-v="22" data-xref="何西阿书 6:6; 诗篇 51:16–17; 箴言 21:3"> 撒母耳说：<br /><span className="pl pl-1">耶和华喜悦燔祭和平安祭，</span><br /><span className="pl pl-1">岂如喜悦人听从他的话呢？</span><br /><span className="pl pl-1">听命胜于献祭；</span><br /><span className="pl pl-1">顺从胜于公羊的脂油。</span><br /></span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 28:16; 撒母耳记上 13:14; 利未记 20:6"> <span className="pl pl-1">悖逆的罪与行邪术的罪相等；</span><br /><span className="pl pl-1">顽梗的罪与拜虚神和偶像的罪相同。</span><br /><span className="pl pl-1">你既厌弃耶和华的命令，</span><br /><span className="pl pl-1">耶和华也厌弃你作王。</span></span>
</div>
</div>

## 扫罗认罪

<div className="bt">
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 12:13; 以赛亚书 51:12–13; 民数记 22:34"> 扫罗对撒母耳说：「我有罪了，我因惧怕百姓，听从他们的话，就违背了耶和华的命令和你的言语。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 10:17"> 现在求你赦免我的罪，同我回去，我好敬拜耶和华。」</span>
<span className="v" id="v26" data-v="26" data-xref="何西阿书 4:6; 撒母耳记上 13:14; 撒母耳记上 16:1"> 撒母耳对扫罗说：「我不同你回去；因为你厌弃耶和华的命令，耶和华也厌弃你作以色列的王。」</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 11:30–31"> 撒母耳转身要走，扫罗就扯住他外袍的衣襟，衣襟就撕断了。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 28:17–18; 使徒行传 13:22; 但以理书 4:32"> 撒母耳对他说：「如此，今日耶和华使以色列国与你断绝，将这国赐与比你更好的人。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结书 24:14; 民数记 23:19; 提多书 1:2"> 以色列的大能者必不致说谎，也不致后悔；因为他迥非世人，决不后悔。」</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 5:44; 约翰福音 12:43; 以赛亚书 29:13"> 扫罗说：「我有罪了，虽然如此，求你在我百姓的长老和以色列人面前抬举我，同我回去，我好敬拜耶和华—你的 神。」</span>
<span className="v" id="v31" data-v="31"> 于是撒母耳转身跟随扫罗回去，扫罗就敬拜耶和华。</span>
<span className="v" id="v32" data-v="32" data-xref="启示录 18:7; 帖撒罗尼迦前书 5:3; 耶利米书 48:44"> 撒母耳说：「要把亚玛力王亚甲带到我这里来。」亚甲就欢欢喜喜地来到他面前，心里说，死亡的苦难必定过去了。</span>
<span className="v" id="v33" data-v="33" data-xref="士师记 1:7; 创世记 9:6; 马太福音 7:2"> 撒母耳说：「你既用刀使妇人丧子，这样，你母亲在妇人中也必丧子。」于是，撒母耳在吉甲耶和华面前将亚甲杀死。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记上 11:4; 撒母耳记上 7:17"> 撒母耳回了拉玛。扫罗上他所住的基比亚，回自己的家去了。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记上 15:11; 撒母耳记上 19:24; 撒母耳记上 16:1"> 撒母耳直到死的日子，再没有见扫罗；但撒母耳为扫罗悲伤，是因耶和华后悔立他为以色列的王。</span>
</div>

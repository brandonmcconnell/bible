## 耶和华会幕的建立和奉献

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华晓谕摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 26:30; 出埃及记 13:4; 民数记 7:1"> 「正月初一日，你要立起帐幕，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 35:12; 民数记 4:5; 启示录 11:19"> 把法柜安放在里面，用幔子将柜遮掩。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 24:8; 出埃及记 40:22–25; 出埃及记 37:10–24"> 把桌子搬进去，摆设上面的物。把灯台搬进去，点其上的灯。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 10:19–22; 希伯来书 9:24; 约翰一书 2:1–2"> 把烧香的金坛安在法柜前，挂上帐幕的门帘。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 40:29; 约翰一书 4:9–10; 希伯来书 13:10"> 把燔祭坛安在帐幕门前。</span>
<span className="v" id="v7" data-v="7" data-xref="撒迦利亚书 13:1; 约翰一书 1:7; 诗篇 26:6"> 把洗濯盆安在会幕和坛的中间，在盆里盛水。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 40:33; 以弗所书 4:11–12; 马太福音 16:18"> 又在四围立院帷，把院子的门帘挂上。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 8:10; 民数记 7:1; 马太福音 3:16"> 用膏油把帐幕和其中所有的都抹上，使帐幕和一切器具成圣，就都成圣。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 29:36–37; 路加福音 1:35; 以赛亚书 61:1"> 又要抹燔祭坛和一切器具，使坛成圣，就都成为至圣。</span>
<span className="v" id="v11" data-v="11"> 要抹洗濯盆和盆座，使盆成圣。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 8:1–13; 利未记 9:1–24; 出埃及记 29:1–35"> 要使亚伦和他儿子到会幕门口来，用水洗身。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 28:41; 约翰一书 2:20; 约翰一书 2:27"> 要给亚伦穿上圣衣，又膏他，使他成圣，可以给我供祭司的职分；</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 61:10; 罗马书 8:30; 哥林多前书 1:30"> 又要使他儿子来，给他们穿上内袍。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 25:13; 希伯来书 5:1–14; 希伯来书 8:1–10"> 怎样膏他们的父亲，也要照样膏他们，使他们给我供祭司的职分。他们世世代代凡受膏的，就永远当祭司的职任。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命记 4:1; 出埃及记 40:17–32; 申命记 12:32"> 摩西这样行，都是照耶和华所吩咐他的。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 7:1; 出埃及记 40:1–2; 民数记 9:1"> 第二年正月初一日，帐幕就立起来。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 37:27–28; 彼得前书 1:5; 利未记 26:11"> 摩西立起帐幕，安上带卯的座，立上板，穿上闩，立起柱子。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 26:1–14; 出埃及记 36:8–19"> 在帐幕以上搭罩棚，把罩棚的顶盖盖在其上，是照耶和华所吩咐他的。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 16:34; 申命记 10:5; 希伯来书 10:19–21"> 又把法版放在柜里，把杠穿在柜的两旁，把施恩座安在柜上。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 26:33; 出埃及记 40:3; 出埃及记 35:12"> 把柜抬进帐幕，挂上遮掩柜的幔子，把法柜遮掩了，是照耶和华所吩咐他的。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 26:35; 约翰福音 6:53–57; 以弗所书 3:8"> 又把桌子安在会幕内，在帐幕北边，在幔子外。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 25:30; 出埃及记 40:4; 希伯来书 9:2"> 在桌子上将饼陈设在耶和华面前，是照耶和华所吩咐他的。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 26:35; 启示录 2:5; 约翰福音 1:1"> 又把灯台安在会幕内，在帐幕南边，与桌子相对，</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 40:4; 出埃及记 25:37; 启示录 4:5"> 在耶和华面前点灯，是照耶和华所吩咐他的。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 40:5; 希伯来书 7:25; 约翰福音 11:42"> 把金坛安在会幕内的幔子前，</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 30:7"> 在坛上烧了馨香料做的香，是照耶和华所吩咐他的。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 40:5; 希伯来书 10:19–20; 以弗所书 2:18"> 又挂上帐幕的门帘。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 40:6; 希伯来书 13:5–6; 希伯来书 13:10"> 在会幕的帐幕门前，安设燔祭坛，把燔祭和素祭献在其上，是照耶和华所吩咐他的。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 40:7; 出埃及记 38:8; 以西结书 36:25"> 把洗濯盆安在会幕和坛的中间，盆中盛水，以便洗濯。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 30:19–20; 诗篇 26:6; 约翰福音 13:10"> 摩西和亚伦并亚伦的儿子在这盆里洗手洗脚。</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 73:19; 出埃及记 30:19–20; 出埃及记 40:19"> 他们进会幕或就近坛的时候，便都洗濯，是照耶和华所吩咐他的。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 40:8; 出埃及记 27:9–16; 约翰福音 17:4"> 在帐幕和坛的四围立了院帷，把院子的门帘挂上。这样，摩西就完了工。</span>
</div>
</div>

## 云彩覆盖会幕

<div className="bt">
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="启示录 15:8; 民数记 9:15–23; 历代志下 7:2"> 当时，云彩遮盖会幕，耶和华的荣光就充满了帐幕。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 8:11; 利未记 16:2; 历代志下 7:2"> 摩西不能进会幕；因为云彩停在其上，并且耶和华的荣光充满了帐幕。</span>
<span className="v" id="v36" data-v="36" data-xref="尼希米记 9:19; 民数记 9:17; 出埃及记 13:21–22"> 每逢云彩从帐幕收上去，以色列人就起程前往；</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 9:19–22; 诗篇 31:15"> 云彩若不收上去，他们就不起程，直等到云彩收上去。</span>
<span className="v" id="v38" data-v="38" data-xref="诗篇 78:14; 民数记 9:15; 出埃及记 13:21"> 日间，耶和华的云彩是在帐幕以上；夜间，云中有火，在以色列全家的眼前。在他们所行的路上都是这样。</span>
</div>

## 奉献圣所

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华晓谕摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 9:7; 尼希米记 11:2; 以斯拉记 2:68"> 「你告诉以色列人当为我送礼物来；凡甘心乐意的，你们就可以收下归我。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 8:9; 约伯记 28:2"> 所要收的礼物：就是金、银、铜，</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 19:8; 创世记 41:42; 以西结书 16:10"> 蓝色、紫色、朱红色线，细麻，山羊毛，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 26:37–1; 出埃及记 26:14–15; 出埃及记 36:20"> 染红的公羊皮，海狗皮，皂荚木，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 27:20; 出埃及记 25:37; 出埃及记 40:24–25"> 点灯的油并做膏油和香的香料，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 28:4; 出埃及记 28:6–30"> 红玛瑙与别样的宝石，可以镶嵌在以弗得和胸牌上。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 6:16; 列王纪上 6:13; 启示录 21:3"> 又当为我造圣所，使我可以住在他们中间。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 25:40; 希伯来书 8:5; 使徒行传 7:44"> 制造帐幕和其中的一切器具都要照我所指示你的样式。」</span>
</div>
</div>

## 约柜

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="希伯来书 9:4; 出埃及记 37:1–3; 申命记 10:1–3"> 「要用皂荚木做一柜，长二肘半，宽一肘半，高一肘半。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 25:24; 出埃及记 30:3; 历代志下 3:4"> 要里外包上精金，四围镶上金牙边。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 27:7; 出埃及记 25:26; 出埃及记 25:15"> 也要铸四个金环，安在柜的四脚上；这边两环，那边两环。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 15:15; 民数记 4:11; 出埃及记 27:6"> 要用皂荚木做两根杠，用金包裹。</span>
<span className="v" id="v14" data-v="14"> 要把杠穿在柜旁的环内，以便抬柜。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 8:8; 历代志下 5:9"> 这杠要常在柜的环内，不可抽出来。</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 31:26; 列王纪上 8:9; 希伯来书 9:4"> 必将我所要赐给你的法版放在柜里。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 9:5; 出埃及记 37:6; 希伯来书 4:16"> 要用精金做施恩座<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="施恩：或译蔽罪；下同">a</a></sup>，长二肘半，宽一肘半。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 10:20; 希伯来书 9:5; 列王纪上 8:6–7"> 要用金子锤出两个基路伯来，安在施恩座的两头。</span>
<span className="v" id="v19" data-v="19"> 这头做一个基路伯，那头做一个基路伯，二基路伯要接连一块，在施恩座的两头。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志上 28:18; 列王纪上 8:7; 希伯来书 9:5"> 二基路伯要高张翅膀，遮掩施恩座。基路伯要脸对脸，朝着施恩座。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 26:34; 罗马书 10:4; 出埃及记 25:16–17"> 要将施恩座安在柜的上边，又将我所要赐给你的法版放在柜里。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 29:42–43; 民数记 7:89; 以赛亚书 37:16"> 我要在那里与你相会，又要从法柜施恩座上二基路伯中间，和你说我所要吩咐你传给以色列人的一切事。」</span>
</div>
</div>

## 陈设饼的桌子

<div className="bt">
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="希伯来书 9:2; 出埃及记 37:10–16; 列王纪上 7:48"> 「要用皂荚木做一张桌子，长二肘，宽一肘，高一肘半。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 25:11; 列王纪上 6:20–22"> 要包上精金，四围镶上金牙边。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 37:2; 出埃及记 30:3"> 桌子的四围各做一掌宽的横梁，横梁上镶着金牙边。</span>
<span className="v" id="v26" data-v="26"> 要做四个金环，安在桌子的四角上，就是桌子四脚上的四角。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 25:14; 出埃及记 25:28"> 安环子的地方要挨近横梁，可以穿杠抬桌子。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 25:14; 使徒行传 9:15; 民数记 10:17"> 要用皂荚木做两根杠，用金包裹，以便抬桌子。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 4:7; 出埃及记 37:16; 启示录 3:20"> 要做桌子上的盘子、调羹，并奠酒的爵和瓶；这都要用精金制作。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 24:5–9; 马太福音 12:4; 出埃及记 39:36"> 又要在桌子上，在我面前，常摆陈设饼。」</span>
</div>
</div>

## 灯台

<div className="bt">
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪上 7:49; 撒迦利亚书 4:2; 出埃及记 37:17–24"> 「要用精金做一个灯台。灯台的座和干与杯、球、花，都要接连一块锤出来。</span>
<span className="v" id="v32" data-v="32"> 灯台两旁要杈出六个枝子：这旁三个，那旁三个。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 17:4–8; 耶利米书 1:11–12; 撒迦利亚书 4:3"> 这旁每枝上有三个杯，形状像杏花，有球，有花；那旁每枝上也有三个杯，形状像杏花，有球，有花。从灯台杈出来的六个枝子都是如此。</span>
<span className="v" id="v34" data-v="34"> 灯台上有四个杯，形状像杏花，有球，有花。</span>
<span className="v" id="v35" data-v="35"> 灯台每两个枝子以下有球与枝子接连一块。灯台出的六个枝子都是如此。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 25:18; 列王纪上 10:16–17; 历代志下 9:15"> 球和枝子要接连一块，都是一块精金锤出来的。</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 8:2; 启示录 1:20–1; 利未记 24:2–4"> 要做灯台的七个灯盏。祭司要点这灯，使灯光对照。</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪下 12:13; 耶利米书 52:18; 列王纪下 25:14"> 灯台的蜡剪和蜡花盘也是要精金的。</span>
<span className="v" id="v39" data-v="39"> 做灯台和这一切的器具要用精金一他连得。</span>
<span className="v" id="v40" data-v="40" data-xref="希伯来书 8:5; 出埃及记 26:30; 使徒行传 7:44"> 要谨慎做这些物件，都要照着在山上指示你的样式。」</span>
</div>
</div>

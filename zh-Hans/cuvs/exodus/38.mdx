## 造燔祭坛

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 27:1–8; 以西结书 43:13–17; 出埃及记 40:6"> 他用皂荚木做燔祭坛，是四方的，长五肘，宽五肘，高三肘，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 27:2; 约伯记 6:12"> 在坛的四拐角上做四个角，与坛接连一块，用铜把坛包裹。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 27:3; 撒母耳记上 2:13"> 他做坛上的盆、铲子、盘子、肉锸子、火鼎；这一切器具都是用铜做的。</span>
<span className="v" id="v4" data-v="4"> 又为坛做一个铜网，安在坛四面的围腰板以下，从下达到坛的半腰。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 27:4"> 为铜网的四角铸四个环子，作为穿杠的用处。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 10:3; 出埃及记 25:6"> 用皂荚木做杠，用铜包裹，</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 9:15; 哥林多前书 2:2; 哥林多前书 1:24"> 把杠穿在坛两旁的环子内，用以抬坛，并用板做坛；坛是空的。</span>
</div>
</div>

## 耶和华会幕的周围

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 27:9–19; 诗篇 89:7; 列王纪上 6:36"> 他做帐幕的院子。院子的南面用捻的细麻做帷子，宽一百肘。</span>
<span className="v" id="v10" data-v="10"> 帷子的柱子二十根，带卯的铜座二十个；柱子上的钩子和杆子都是用银子做的。</span>
<span className="v" id="v11" data-v="11"> 北面也有帷子，宽一百肘。帷子的柱子二十根，带卯的铜座二十个；柱子上的钩子和杆子都是用银子做的。</span>
<span className="v" id="v12" data-v="12"> 院子的西面有帷子，宽五十肘。帷子的柱子十根，带卯的座十个；柱子的钩子和杆子都是用银子做的。</span>
<span className="v" id="v13" data-v="13"> 院子的东面，宽五十肘。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 27:14"> 门这边的帷子十五肘，那边也是一样。帷子的柱子三根，带卯的座三个。在门的左右各有帷子十五肘，帷子的柱子三根，带卯的座三个。</span>
<span className="v" id="v16" data-v="16"> 院子四面的帷子都是用捻的细麻做的。</span>
<span className="v" id="v17" data-v="17"> 柱子带卯的座是铜的，柱子上的钩子和杆子是银的，柱顶是用银子包的。院子一切的柱子都是用银杆连络的。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 3:14"> 院子的门帘是以绣花的手工，用蓝色、紫色、朱红色线，和捻的细麻织的，宽二十肘，高五肘，与院子的帷子相配。</span>
<span className="v" id="v19" data-v="19"> 帷子的柱子四根，带卯的铜座四个；柱子上的钩子和杆子是银的；柱顶是用银子包的。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 3:9; 出埃及记 27:19; 以弗所书 2:21–22"> 帐幕一切的橛子和院子四围的橛子都是铜的。</span>
</div>
</div>

## 耶和华会幕所用的金属

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 7:44; 民数记 9:15; 历代志下 24:6"> 这是法柜的帐幕中利未人所用物件的总数，是照摩西的吩咐，经祭司亚伦的儿子以他玛的手数点的。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 35:30–3; 出埃及记 31:1–5; 诗篇 119:6"> 凡耶和华所吩咐摩西的都是犹大支派户珥的孙子、乌利的儿子比撒列做的。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 35:34; 出埃及记 31:6"> 与他同工的有但支派中亚希撒抹的儿子亚何利亚伯；他是雕刻匠，又是巧匠，又能用蓝色、紫色、朱红色线，和细麻绣花。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 18:16; 民数记 3:47; 利未记 27:25"> 为圣所一切工作使用所献的金子，按圣所的平，有二十九他连得并七百三十舍客勒。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 30:12"> 会中被数的人所出的银子，按圣所的平，有一百他连得并一千七百七十五舍客勒。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 1:46; 出埃及记 30:13; 出埃及记 12:37"> 凡过去归那些被数之人的，从二十岁以外，有六十万零三千五百五十人。按圣所的平，每人出银半舍客勒，就是一比加。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 26:19; 出埃及记 26:25; 出埃及记 26:21"> 用那一百他连得银子铸造圣所带卯的座和幔子柱子带卯的座；一百他连得共一百带卯的座，每带卯的座用一他连得。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 27:17"> 用那一千七百七十五舍客勒银子做柱子上的钩子，包裹柱顶并柱子上的杆子。</span>
<span className="v" id="v29" data-v="29"> 所献的铜有七十他连得并二千四百舍客勒。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 26:37; 出埃及记 27:17; 出埃及记 27:10"> 用这铜做会幕门带卯的座和铜坛，并坛上的铜网和坛的一切器具，</span>
<span className="v" id="v31" data-v="31"> 并院子四围带卯的座和院门带卯的座，与帐幕一切的橛子和院子四围所有的橛子。</span>
</div>
</div>

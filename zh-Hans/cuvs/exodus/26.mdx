## 会幕

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 36:8–19; 出埃及记 26:36; 出埃及记 26:31"> 「你要用十幅幔子做帐幕。这些幔子要用捻的细麻和蓝色、紫色、朱红色线制造，并用巧匠的手工绣上基路伯。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 7:2; 民数记 4:25; 历代志上 17:1"> 每幅幔子要长二十八肘，宽四肘，幔子都要一样的尺寸。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 36:10; 歌罗西书 2:2; 以弗所书 2:21–22"> 这五幅幔子要幅幅相连；那五幅幔子也要幅幅相连。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 36:11–12; 出埃及记 36:17; 出埃及记 26:10–11"> 在这相连的幔子末幅边上要做蓝色的钮扣；在那相连的幔子末幅边上也要照样做。</span>
<span className="v" id="v5" data-v="5"> 要在这相连的幔子上做五十个钮扣；在那相连的幔子上也做五十个钮扣，都要两两相对。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 36:13; 出埃及记 26:11; 出埃及记 26:33"> 又要做五十个金钩，用钩使幔子相连，这才成了一个帐幕。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 26:14; 诗篇 45:13; 出埃及记 26:9"> 「你要用山羊毛织十一幅幔子，作为帐幕以上的罩棚。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 26:13; 出埃及记 26:2"> 每幅幔子要长三十肘，宽四肘；十一幅幔子都要一样的尺寸。</span>
<span className="v" id="v9" data-v="9"> 要把五幅幔子连成一幅，又把六幅幔子连成一幅，这第六幅幔子要在罩棚的前面折上去。</span>
<span className="v" id="v10" data-v="10"> 在这相连的幔子末幅边上要做五十个钮扣；在那相连的幔子末幅边上也做五十个钮扣。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 26:3; 出埃及记 26:6"> 又要做五十个铜钩，钩在钮扣中，使罩棚连成一个。</span>
<span className="v" id="v12" data-v="12"> 罩棚的幔子所余那垂下来的半幅幔子，要垂在帐幕的后头。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 26:2; 出埃及记 26:8"> 罩棚的幔子所余长的，这边一肘，那边一肘，要垂在帐幕的两旁，遮盖帐幕。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 36:19; 出埃及记 25:5; 出埃及记 35:23"> 又要用染红的公羊皮做罩棚的盖；再用海狗皮做一层罩棚上的顶盖。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 36:20–33; 民数记 4:31–32; 出埃及记 40:17–18"> 「你要用皂荚木做帐幕的竖板。</span>
<span className="v" id="v16" data-v="16"> 每块要长十肘，宽一肘半；</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 36:22; 出埃及记 26:19; 出埃及记 36:24"> 每块必有两榫相对。帐幕一切的板都要这样做。</span>
<span className="v" id="v18" data-v="18"> 帐幕的南面要做板二十块。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 38:27; 出埃及记 38:30–31; 出埃及记 26:37"> 在这二十块板底下要做四十个带卯的银座，两卯接这块板上的两榫，两卯接那块板上的两榫。</span>
<span className="v" id="v20" data-v="20"> 帐幕第二面，就是北面，也要做板二十块</span>
<span className="v" id="v21" data-v="21"> 和带卯的银座四十个；这板底下有两卯，那板底下也有两卯。</span>
<span className="v" id="v22" data-v="22"> 帐幕的后面，就是西面，要做板六块。</span>
<span className="v" id="v23" data-v="23"> 帐幕后面的拐角要做板两块。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 36:29–30; 诗篇 133:1–3; 哥林多前书 1:10"> 板的下半截要双的，上半截要整的，直顶到第一个环子；两块都要这样做两个拐角。</span>
<span className="v" id="v25" data-v="25"> 必有八块板和十六个带卯的银座；这板底下有两卯，那板底下也有两卯。</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 15:1; 民数记 4:31; 加拉太书 6:1–2"> 「你要用皂荚木作闩：为帐幕这面的板作五闩，</span>
<span className="v" id="v27" data-v="27"> 为帐幕那面的板做五闩，又为帐幕后面的板做五闩。</span>
<span className="v" id="v28" data-v="28"> 板腰间的中闩要从这一头通到那一头。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 25:11–12"> 板要用金子包裹，又要做板上的金环套闩；闩也要用金子包裹。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 25:40; 希伯来书 8:5; 出埃及记 25:9"> 要照着在山上指示你的样式立起帐幕。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 27:51; 历代志下 3:14; 出埃及记 36:35"> 「你要用蓝色、紫色、朱红色线，和捻的细麻织幔子，以巧匠的手工绣上基路伯。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 26:37; 出埃及记 36:38; 以斯帖记 1:6"> 要把幔子挂在四根包金的皂荚木柱子上，柱子上当有金钩，柱子安在四个带卯的银座上。</span>
<span className="v" id="v33" data-v="33" data-xref="希伯来书 9:2–3; 利未记 16:2; 出埃及记 40:21"> 要使幔子垂在钩子下，把法柜抬进幔子内；这幔子要将圣所和至圣所隔开。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 40:20; 出埃及记 25:21; 希伯来书 9:5"> 又要把施恩座安在至圣所内的法柜上，</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及记 40:24; 出埃及记 40:22; 希伯来书 9:2"> 把桌子安在幔子外帐幕的北面；把灯台安在帐幕的南面，彼此相对。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 36:37; 民数记 9:15; 出埃及记 26:31"> 「你要拿蓝色、紫色、朱红色线，和捻的细麻，用绣花的手工织帐幕的门帘。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及记 36:38"> 要用皂荚木为帘子做五根柱子，用金子包裹。柱子上当有金钩；又要为柱子用铜铸造五个带卯的座。」</span>

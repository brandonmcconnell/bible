## 摩西和亚伦见埃及王

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 10:9; 使徒行传 4:29; 马太福音 10:28"> 后来摩西、亚伦去对法老说：「耶和华—以色列的 神这样说：『容我的百姓去，在旷野向我守节。』」</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 3:19; 约伯记 21:15; 列王纪下 18:35"> 法老说：「耶和华是谁，使我听他的话，容以色列人去呢？我不认识耶和华，也不容以色列人去！」</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 3:18; 撒迦利亚书 14:16–19; 以西结书 6:11"> 他们说：「希伯来人的 神遇见了我们。求你容我们往旷野去，走三天的路程，祭祀耶和华—我们的 神，免得他用瘟疫、刀兵攻击我们。」</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 1:11; 使徒行传 24:5; 阿摩司书 7:10"> 埃及王对他们说：「摩西、亚伦！你们为什么叫百姓旷工呢？你们去担你们的担子吧！」</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 1:7–11; 箴言 14:28"> 又说：「看哪，这地的以色列人如今众多，你们竟叫他们歇下担子！」</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 5:10; 出埃及记 5:19; 申命记 16:18"> 当天，法老吩咐督工的和官长说：</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 19:19; 创世记 24:25"> 「你们不可照常把草给百姓做砖，叫他们自己去捡草。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 106:41"> 他们素常做砖的数目，你们仍旧向他们要，一点不可减少；因为他们是懒惰的，所以呼求说：『容我们去祭祀我们的 神。』</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 18:20; 耶利米书 43:2; 约伯记 16:3"> 你们要把更重的工夫加在这些人身上，叫他们劳碌，不听虚谎的言语。」</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 1:11; 出埃及记 3:7; 箴言 29:12"> 督工的和官长出来对百姓说：「法老这样说：『我不给你们草。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 5:13–14"> 你们自己在哪里能找草，就往那里去找吧！但你们的工一点不可减少。』」</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 15:7; 以赛亚书 5:24; 以赛亚书 47:14"> 于是百姓散在埃及遍地，捡碎秸当作草。</span>
<span className="v" id="v13" data-v="13"> 督工的催着说：「你们一天当完一天的工，与先前有草一样。」</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 10:24"> 法老督工的，责打他所派以色列人的官长，说：「你们昨天今天为什么没有照向来的数目做砖、完你们的工作呢？」</span>
<span className="v" id="v15" data-v="15"> 以色列人的官长就来哀求法老说：「为什么这样待你的仆人？</span>
<span className="v" id="v16" data-v="16"> 督工的不把草给仆人，并且对我们说：『做砖吧！』看哪，你仆人挨了打，其实是你百姓的错。」</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 26:8; 约翰福音 6:27; 出埃及记 5:8"> 但法老说：「你们是懒惰的！你们是懒惰的！所以说：『容我们去祭祀耶和华。』</span>
<span className="v" id="v18" data-v="18" data-xref="以西结书 18:18; 但以理书 2:9–13"> 现在你们去做工吧！草是不给你们的，砖却要如数交纳。」</span>
<span className="v" id="v19" data-v="19" data-xref="传道书 5:8; 传道书 4:1; 申命记 32:36"> 以色列人的官长听说「你们每天做砖的工作一点不可减少」，就知道是遭遇祸患了。</span>
<span className="v" id="v20" data-v="20"> 他们离了法老出来，正遇见摩西、亚伦站在对面，</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 34:30; 撒母耳记上 13:4; 历代志上 19:6"> 就向他们说：「愿耶和华鉴察你们，施行判断；因你们使我们在法老和他臣仆面前有了臭名，把刀递在他们手中杀我们。」</span>
</div>
</div>

## 摩西向耶和华诉苦

<div className="bt">
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="耶利米书 20:7; 列王纪上 19:10; 民数记 11:14–15"> 摩西回到耶和华那里，说：「主啊，你为什么苦待这百姓呢？为什么打发我去呢？</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 11:21; 希伯来书 10:36–37; 以赛亚书 28:16"> 自从我去见法老，奉你的名说话，他就苦待这百姓，你一点也没有拯救他们。」</span>
</div>

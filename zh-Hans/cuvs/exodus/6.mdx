## 神呼召摩西

<div className="bt">
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="耶利米书 9:24; 玛拉基书 3:6; 使徒行传 17:24–25"> 神晓谕摩西说：「我是耶和华。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 83:18; 诗篇 68:4; 创世记 17:1"> 我从前向亚伯拉罕、以撒、雅各显现为全能的 神；至于我名耶和华，他们未曾知道。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 28:4; 创世记 15:18; 创世记 17:7–8"> 我与他们坚定所立的约，要把他们寄居的迦南地赐给他们。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 2:24; 诗篇 106:44–45; 以赛亚书 63:9"> 我也听见以色列人被埃及人苦待的哀声，我也记念我的约。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 26:8; 历代志上 17:21; 出埃及记 7:4"> 所以你要对以色列人说：『我是耶和华；我要用伸出来的膀臂重重地刑罚埃及人，救赎你们脱离他们的重担，不做他们的苦工。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 7:6; 申命记 29:13; 申命记 4:20"> 我要以你们为我的百姓，我也要作你们的 神。你们要知道我是耶和华—你们的 神，是救你们脱离埃及人之重担的。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 26:3; 创世记 15:18; 以西结书 20:42"> 我起誓应许给亚伯拉罕、以撒、雅各的那地，我要把你们领进去，将那地赐给你们为业。我是耶和华。』」</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 5:21; 约伯记 21:4; 出埃及记 14:12"> 摩西将这话告诉以色列人，只是他们因苦工愁烦，不肯听他的话。</span>
<span className="v" id="v10" data-v="10"> 耶和华晓谕摩西说：</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 6:29; 出埃及记 5:23; 出埃及记 3:10"> 「你进去对埃及王法老说，要容以色列人出他的地。」</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 4:10; 耶利米书 1:6; 出埃及记 6:30"> 摩西在耶和华面前说：「以色列人尚且不听我的话，法老怎肯听我这拙口笨舌的人呢？」</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 27:23; 提摩太前书 6:13; 诗篇 91:11"> 耶和华吩咐摩西、亚伦往以色列人和埃及王法老那里去，把以色列人从埃及地领出来。</span>
</div>
</div>

## 摩西和亚伦的族谱

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="创世记 46:9; 历代志上 5:3; 民数记 26:5–7"> 以色列人家长的名字记在下面。以色列长子吕便的儿子是哈诺、法路、希斯伦、迦米；这是吕便的各家。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 4:24; 创世记 46:10; 民数记 26:12–13"> 西缅的儿子是耶母利、雅悯、阿辖、雅斤、琐辖，和迦南女子的儿子扫罗；这是西缅的各家。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 3:17; 创世记 46:11; 历代志上 6:1"> 利未众子的名字按着他们的后代记在下面：就是革顺、哥辖、米拉利。利未一生的岁数是一百三十七岁。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 6:17; 民数记 3:18; 历代志上 23:7"> 革顺的儿子按着家室是立尼、示每。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 6:18; 历代志上 6:2; 民数记 3:19"> 哥辖的儿子是暗兰、以斯哈、希伯伦、乌薛。哥辖一生的岁数是一百三十三岁。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 3:20; 历代志上 23:21; 历代志上 6:19"> 米拉利的儿子是抹利和母示；这是利未的家，都按着他们的后代。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 26:59; 出埃及记 2:1–2; 出埃及记 6:18"> 暗兰娶了他父亲的妹妹约基别为妻，她给他生了亚伦和摩西。暗兰一生的岁数是一百三十七岁。</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 16:1; 历代志上 6:37–38; 民数记 16:32"> 以斯哈的儿子是可拉、尼斐、细基利。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 10:4; 民数记 3:30; 尼希米记 3:20"> 乌薛的儿子是米沙利、以利撒反、西提利。</span>
<span className="v" id="v23" data-v="23" data-xref="路得记 4:19–20; 民数记 2:3; 民数记 1:7"> 亚伦娶了亚米拿达的女儿，拿顺的妹妹，以利沙巴为妻，她给他生了拿答、亚比户、以利亚撒、以他玛。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 6:22–23; 民数记 16:1; 撒母耳记上 1:1"> 可拉的儿子是亚惜、以利加拿、亚比亚撒；这是可拉的各家。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 24:33; 民数记 25:7–13; 约书亚记 22:31–32"> 亚伦的儿子以利亚撒娶了普铁的一个女儿为妻，她给他生了非尼哈。这是利未人的家长，都按着他们的家。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 12:51; 出埃及记 12:17; 出埃及记 7:4"> 耶和华说：「将以色列人按着他们的军队从埃及地领出来。」这是对那亚伦、摩西说的。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 6:26; 出埃及记 7:10; 诗篇 77:20"> 对埃及王法老说要将以色列人从埃及领出来的，就是这摩西、亚伦。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28"> 当耶和华在埃及地对摩西说话的日子，</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 6:11; 出埃及记 7:2; 出埃及记 6:2"> 他向摩西说：「我是耶和华；我对你说的一切话，你都要告诉埃及王法老。」</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 6:12; 出埃及记 4:10; 哥林多前书 9:16–17"> 摩西在耶和华面前说：「看哪，我是拙口笨舌的人，法老怎肯听我呢？」</span>

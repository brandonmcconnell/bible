## 以色列人在西奈山

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 16:1; 出埃及记 12:6; 利未记 23:16–18"> 以色列人出埃及地以后，满了三个月的那一天，就来到西奈的旷野。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 3:1; 出埃及记 17:1; 出埃及记 3:12"> 他们离了利非订，来到西奈的旷野，就在那里的山下安营。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 3:4; 使徒行传 7:38; 出埃及记 20:21"> 摩西到 神那里，耶和华从山上呼唤他说：「你要这样告诉雅各家，晓谕以色列人说：</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 32:11–12; 以赛亚书 63:9; 以赛亚书 40:31"> 『我向埃及人所行的事，你们都看见了，且看见我如鹰将你们背在翅膀上，带来归我。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 14:2; 申命记 7:6; 申命记 26:18"> 如今你们若实在听从我的话，遵守我的约，就要在万民中作属我的子民，因为全地都是我的。</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 5:10; 彼得前书 2:9; 彼得前书 2:5"> 你们要归我作祭司的国度，为圣洁的国民。』这些话你要告诉以色列人。」</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 4:29–30; 出埃及记 3:16; 哥林多前书 15:1"> 摩西去召了民间的长老来，将耶和华所吩咐他的话都在他们面前陈明。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 24:7; 出埃及记 24:3; 约书亚记 24:24"> 百姓都同声回答说：「凡耶和华所说的，我们都要遵行。」摩西就将百姓的话回复耶和华。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 4:36; 出埃及记 19:16; 出埃及记 24:15–16"> 耶和华对摩西说：「我要在密云中临到你那里，叫百姓在我与你说话的时候可以听见，也可以永远信你了。」于是，摩西将百姓的话奏告耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="希伯来书 10:22; 创世记 35:2; 利未记 11:44–45"> 耶和华又对摩西说：「你往百姓那里去，叫他们今天明天自洁，又叫他们洗衣服。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 19:16; 出埃及记 34:5; 申命记 33:2"> 到第三天要预备好了，因为第三天耶和华要在众百姓眼前降临在西奈山上。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 12:20–21; 约书亚记 3:4; 出埃及记 19:21"> 你要在山的四围给百姓定界限，说：『你们当谨慎，不可上山去，也不可摸山的边界；凡摸这山的，必要治死他。</span>
<span className="v" id="v13" data-v="13" data-xref="帖撒罗尼迦前书 4:16; 希伯来书 12:20; 出埃及记 19:16"> 不可用手摸他，必用石头打死，或用箭射透；无论是人是牲畜，都不得活。到角声拖长的时候，他们才可到山根来。』」</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 19:10"> 摩西下山往百姓那里去，叫他们自洁，他们就洗衣服。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 7:5; 撒母耳记上 21:4–5; 出埃及记 19:11"> 他对百姓说：「到第三天要预备好了。不可亲近女人。」</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="希伯来书 12:18–19; 诗篇 18:11–14; 希伯来书 12:21"> 到了第三天早晨，在山上有雷轰、闪电，和密云，并且角声甚大，营中的百姓尽都发颤。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 4:10; 申命记 5:5"> 摩西率领百姓出营迎接 神，都站在山下。</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 5:5; 出埃及记 3:2; 诗篇 144:5"> 西奈全山冒烟，因为耶和华在火中降于山上。山的烟气上腾，如烧窑一般，遍山大大地震动。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 81:7; 出埃及记 19:16; 尼希米记 9:13"> 角声渐渐地高而又高，摩西就说话， 神有声音答应他。</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米记 9:13; 出埃及记 34:2; 出埃及记 19:11"> 耶和华降临在西奈山顶上，耶和华召摩西上山顶，摩西就上去。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 6:19; 出埃及记 3:5; 希伯来书 12:28–29"> 耶和华对摩西说：「你下去嘱咐百姓，不可闯过来到我面前观看，恐怕他们有多人死亡；</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 24:5; 使徒行传 5:10; 历代志上 13:9–11"> 又叫亲近我的祭司自洁，恐怕我忽然出来击杀他们。」</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 19:12; 约书亚记 3:4–5"> 摩西对耶和华说：「百姓不能上西奈山，因为你已经嘱咐我们说：『要在山的四围定界限，叫山成圣。』」</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 4:16; 希伯来书 12:18–25; 希伯来书 12:29"> 耶和华对他说：「下去吧，你要和亚伦一同上来；只是祭司和百姓不可闯过来上到我面前，恐怕我忽然出来击杀他们。」</span>
<span className="v" id="v25" data-v="25"> 于是摩西下到百姓那里告诉他们。</span>
</div>

## 复造法版

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 32:19; 出埃及记 31:18; 诗篇 119:89"> 耶和华吩咐摩西说：「你要凿出两块石版，和先前你摔碎的那版一样；其上的字我要写在这版上。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 19:20; 申命记 9:25; 出埃及记 19:11"> 明日早晨，你要预备好了，上西奈山，在山顶上站在我面前。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 19:12–13; 出埃及记 19:21; 提摩太前书 2:5"> 谁也不可和你一同上去，遍山都不可有人，在山根也不可叫羊群牛群吃草。」</span>
<span className="v" id="v4" data-v="4"> 摩西就凿出两块石版，和先前的一样。清晨起来，照耶和华所吩咐的上西奈山去，手里拿着两块石版。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 33:19; 民数记 11:25; 路加福音 9:34–35"> 耶和华在云中降临，和摩西一同站在那里，宣告耶和华的名。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 86:15; 约珥书 2:13; 诗篇 103:8–13"> 耶和华在他面前宣告说：「耶和华，耶和华，是有怜悯有恩典的 神，不轻易发怒，并有丰盛的慈爱和诚实，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 20:5–6; 诗篇 103:3; 申命记 5:9–10"> 为千万人存留慈爱，赦免罪孽、过犯，和罪恶，万不以有罪的为无罪，必追讨他的罪，自父及子，直到三、四代。」</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 4:31; 历代志下 20:18; 创世记 17:3"> 摩西急忙伏地下拜，</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 33:12; 申命记 32:9; 诗篇 94:14"> 说：「主啊，我若在你眼前蒙恩，求你在我们中间同行，因为这是硬着颈项的百姓。又求你赦免我们的罪孽和罪恶，以我们为你的产业。」</span>
</div>
</div>

## 重新立约

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命记 10:21; 诗篇 77:14; 以赛亚书 64:3"> 耶和华说：「我要立约，要在百姓面前行奇妙的事，是在遍地万国中所未曾行的。在你四围的外邦人就要看见耶和华的作为，因我向你所行的是可畏惧的事。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出埃及记 33:2; 出埃及记 3:17; 出埃及记 3:8"> 「我今天所吩咐你的，你要谨守。我要从你面前撵出亚摩利人、迦南人、赫人、比利洗人、希未人、耶布斯人。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 23:32–33; 约书亚记 23:12–13; 申命记 7:2"> 你要谨慎，不可与你所去那地的居民立约，恐怕成为你们中间的网罗；</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 18:4; 出埃及记 23:24; 申命记 7:25–26"> 却要拆毁他们的祭坛，打碎他们的柱像，砍下他们的木偶。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 4:24; 申命记 32:21; 哥林多前书 10:22"> 不可敬拜别神；因为耶和华是忌邪的 神，名为忌邪者。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 2:17; 诗篇 106:28; 民数记 25:2"> 只怕你与那地的居民立约，百姓随从他们的神，就行邪淫，祭祀他们的神，有人叫你，你便吃他的祭物，</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 7:3–4; 列王纪上 11:2–4; 以斯拉记 9:2"> 又为你的儿子娶他们的女儿为妻，他们的女儿随从她们的神，就行邪淫，使你的儿子也随从她们的神行邪淫。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="利未记 19:4; 出埃及记 32:8; 以赛亚书 46:6–7"> 「不可为自己铸造神像。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 13:4; 利未记 23:6; 出埃及记 13:6–7"> 「你要守除酵节，照我所吩咐你的，在亚笔月内所定的日期吃无酵饼七天，因为你是这亚笔月内出了埃及。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 13:2; 出埃及记 22:29; 出埃及记 13:12"> 凡头生的都是我的；一切牲畜头生的，无论是牛是羊，公的都是我的。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 13:13; 出埃及记 23:15; 申命记 16:16"> 头生的驴要用羊羔代赎，若不代赎就要打折它的颈项。凡头生的儿子都要赎出来。谁也不可空手朝见我。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及记 23:12; 申命记 21:4; 路加福音 13:14"> 「你六日要做工，第七日要安息，虽在耕种收割的时候也要安息。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 23:16; 申命记 16:10–15; 约翰福音 7:2"> 在收割初熟麦子的时候要守七七节；又在年底要守收藏节。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 23:14; 申命记 16:16; 出埃及记 23:17"> 你们一切男丁要一年三次朝见主耶和华—以色列的 神。</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 78:55; 出埃及记 33:2; 箴言 16:7"> 我要从你面前赶出外邦人，扩张你的境界。你一年三次上去朝见耶和华—你 神的时候，必没有人贪慕你的地土。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及记 23:18; 出埃及记 12:10; 哥林多前书 5:7–8"> 「你不可将我祭物的血和有酵的饼一同献上。逾越节的祭物也不可留到早晨。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 23:19; 申命记 14:21; 申命记 26:2"> 地里首先初熟之物要送到耶和华—你 神的殿。不可用山羊羔母的奶煮山羊羔。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="出埃及记 24:4; 申命记 31:9; 申命记 4:13"> 耶和华吩咐摩西说：「你要将这些话写上，因为我是按这话与你和以色列人立约。」</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 34:1; 出埃及记 24:18; 申命记 9:18"> 摩西在耶和华那里四十昼夜，也不吃饭也不喝水。耶和华将这约的话，就是十条诫，写在两块版上。</span>
</div>
</div>

## 摩西下西奈山

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马太福音 17:2; 路加福音 9:29; 出埃及记 32:15"> 摩西手里拿着两块法版下西奈山的时候，不知道自己的面皮因耶和华和他说话就发了光。</span>
<span className="v" id="v30" data-v="30" data-xref="马可福音 9:3; 路加福音 5:8; 民数记 12:8"> 亚伦和以色列众人看见摩西的面皮发光就怕挨近他。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 3:15; 出埃及记 24:1–3; 创世记 45:3"> 摩西叫他们来；于是亚伦和会众的官长都到他那里去，摩西就与他们说话。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 22:14; 出埃及记 24:3; 马太福音 28:20"> 随后以色列众人都近前来，他就把耶和华在西奈山与他所说的一切话都吩咐他们。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多后书 4:4–6; 哥林多后书 3:13–18; 罗马书 10:4"> 摩西与他们说完了话就用帕子蒙上脸。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多后书 3:16; 希伯来书 10:19–22; 希伯来书 4:16"> 但摩西进到耶和华面前与他说话就揭去帕子，及至出来的时候便将耶和华所吩咐的告诉以色列人。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及记 34:29–30; 约翰福音 5:35; 但以理书 12:3"> 以色列人看见摩西的面皮发光。摩西又用帕子蒙上脸，等到他进去与耶和华说话就揭去帕子。</span>
</div>
</div>

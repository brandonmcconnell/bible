## 畜疫之灾

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 8:1; 出埃及记 10:3; 出埃及记 8:20"> 耶和华吩咐摩西说：「你进去见法老，对他说：『耶和华—希伯来人的 神这样说：容我的百姓去，好事奉我。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 8:2; 出埃及记 4:23; 利未记 26:27–28"> 你若不肯容他们去，仍旧强留他们，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 7:4; 使徒行传 13:11; 撒母耳记上 6:9"> 耶和华的手加在你田间的牲畜上，就是在马、驴、骆驼、牛群、羊群上，必有重重的瘟疫。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 8:22; 出埃及记 10:23; 玛拉基书 3:18"> 耶和华要分别以色列的牲畜和埃及的牲畜，凡属以色列人的，一样都不死。』」</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 8:23; 出埃及记 10:4; 耶利米书 28:16–17"> 耶和华就定了时候，说：「明天耶和华必在此地行这事。」</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 78:48; 出埃及记 9:25; 诗篇 78:50"> 第二天，耶和华就行这事。埃及的牲畜几乎都死了，只是以色列人的牲畜，一个都没有死。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 7:14; 出埃及记 8:32; 以赛亚书 48:4"> 法老打发人去看，谁知以色列人的牲畜连一个都没有死。法老的心却是固执，不容百姓去。</span>
</div>
</div>

## 疮灾

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 8:16"> 耶和华吩咐摩西、亚伦说：「你们取几捧炉灰，摩西要在法老面前向天扬起来。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 16:2; 申命记 28:27; 约伯记 2:7"> 这灰要在埃及全地变作尘土，在人身上和牲畜身上成了起泡的疮。」</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 28:27"> 摩西、亚伦取了炉灰，站在法老面前。摩西向天扬起来，就在人身上和牲畜身上成了起泡的疮。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 7:11–12; 出埃及记 8:18–19; 启示录 16:2"> 行法术的在摩西面前站立不住，因为在他们身上和一切埃及人身上都有这疮。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 4:21; 出埃及记 7:13–14; 诗篇 81:11–12"> 耶和华使法老的心刚硬，不听他们，正如耶和华对摩西所说的。</span>
</div>
</div>

## 雹灾

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="出埃及记 8:20; 出埃及记 7:15; 出埃及记 9:1"> 耶和华对摩西说：「你清早起来，站在法老面前，对他说：『耶和华—希伯来人的 神这样说：容我的百姓去，好事奉我。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 8:10; 利未记 26:28; 历代志上 17:20"> 因为这一次我要叫一切的灾殃临到你和你臣仆并你百姓的身上，叫你知道在普天下没有像我的。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 3:20; 出埃及记 9:3; 出埃及记 9:16"> 我若伸手用瘟疫攻击你和你的百姓，你早就从地上除灭了。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 9:17; 箴言 16:4; 诗篇 83:17–18"> 其实，我叫你存立，是特要向你显我的大能，并要使我的名传遍天下。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 37:29; 以赛亚书 10:15; 以赛亚书 37:23–24"> 你还向我的百姓自高，不容他们去吗？</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 20:6; 诗篇 83:15; 出埃及记 9:22–25"> 到明天约在这时候，我必叫重大的冰雹降下，自从埃及开国以来，没有这样的冰雹。</span>
<span className="v" id="v19" data-v="19" data-xref="哈巴谷书 3:2"> 现在你要打发人把你的牲畜和你田间一切所有的催进来；凡在田间不收回家的，无论是人是牲畜，冰雹必降在他们身上，他们就必死。』」</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 13:13; 箴言 22:3; 希伯来书 11:7"> 法老的臣仆中，惧怕耶和华这话的，便叫他的奴仆和牲畜跑进家来。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 40:4; 约伯记 34:14; 历代志上 22:19"> 但那不把耶和华这话放在心上的，就将他的奴仆和牲畜留在田里。</span>
<span className="v" id="v22" data-v="22" data-xref="启示录 16:21; 出埃及记 7:19; 出埃及记 8:5"> 耶和华对摩西说：「你向天伸杖，使埃及遍地的人身上和牲畜身上，并田间各样菜蔬上，都有冰雹。」</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 18:13; 约书亚记 10:11; 以赛亚书 30:30"> 摩西向天伸杖，耶和华就打雷下雹，有火闪到地上；耶和华下雹在埃及地上。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 9:23; 马太福音 24:21; 出埃及记 10:6"> 那时，雹与火搀杂，甚是厉害，自从埃及成国以来，遍地没有这样的。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 78:47; 诗篇 105:32–33"> 在埃及遍地，雹击打了田间所有的人和牲畜，并一切的菜蔬，又打坏田间一切的树木。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 11:7; 出埃及记 9:4; 出埃及记 10:23"> 惟独以色列人所住的歌珊地没有冰雹。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米哀歌 1:18; 诗篇 129:4; 出埃及记 10:16"> 法老打发人召摩西、亚伦来，对他们说：「这一次我犯了罪了。耶和华是公义的；我和我的百姓是邪恶的。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 8:8; 出埃及记 10:17; 出埃及记 8:28"> 这雷轰和冰雹已经够了。请你们求耶和华，我就容你们去，不再留住你们。」</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 10:26; 列王纪上 8:38; 以赛亚书 1:15"> 摩西对他说：「我一出城，就要向耶和华举手祷告；雷必止住，也不再有冰雹，叫你知道全地都是属耶和华的。</span>
<span className="v" id="v30" data-v="30" data-xref="以赛亚书 26:10; 箴言 16:6; 以赛亚书 63:17"> 至于你和你的臣仆，我知道你们还是不惧怕耶和华 神。」（</span>
<span className="v" id="v31" data-v="31" data-xref="路得记 1:22; 路得记 2:23; 哈巴谷书 3:17"> 那时，麻和大麦被雹击打；因为大麦已经吐穗，麻也开了花。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 10:22"> 只是小麦和粗麦没有被击打，因为还没有长成。）</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 9:29; 出埃及记 8:12; 雅各书 5:17–18"> 摩西离了法老出城，向耶和华举手祷告；雷和雹就止住，雨也不再浇在地上了。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 7:14; 历代志下 36:13; 出埃及记 4:21"> 法老见雨和雹与雷止住，就越发犯罪；他和他的臣仆都硬着心。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及记 4:21"> 法老的心刚硬，不容以色列人去，正如耶和华借着摩西所说的。</span>
</div>

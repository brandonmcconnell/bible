<span className="v" id="v2" data-v="2" data-xref="出埃及记 4:15; 出埃及记 6:29; 申命记 4:2"> 凡我所吩咐你的，你都要说。你的哥哥亚伦要对法老说，容以色列人出他的地。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 4:21; 出埃及记 11:9; 诗篇 105:27–36"> 我要使法老的心刚硬，也要在埃及地多行神迹奇事。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 11:9; 出埃及记 6:6; 出埃及记 12:51"> 但法老必不听你们；我要伸手重重地刑罚埃及，将我的军队以色列民从埃及地领出来。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 14:18; 出埃及记 7:17; 出埃及记 8:22"> 我伸手攻击埃及，将以色列人从他们中间领出来的时候，埃及人就要知道我是耶和华。」</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 7:2; 创世记 6:22; 出埃及记 7:10"> 摩西、亚伦这样行；耶和华怎样吩咐他们，他们就照样行了。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 34:7; 使徒行传 7:30; 申命记 31:2"> 摩西、亚伦与法老说话的时候，摩西八十岁，亚伦八十三岁。</span>

## 亚伦的杖

<div className="bt">
<div className="bp">
<span className="v" id="v8" data-v="8"> 耶和华晓谕摩西、亚伦说：</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 4:2; 约翰福音 2:18; 以赛亚书 7:11"> 「法老若对你们说：『你们行件奇事吧！』你就吩咐亚伦说：『把杖丢在法老面前，使杖变作蛇。』」</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 4:3; 路加福音 10:19; 阿摩司书 9:3"> 摩西、亚伦进去见法老，就照耶和华所吩咐的行。亚伦把杖丢在法老和臣仆面前，杖就变作蛇。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 7:22; 提摩太后书 3:8; 出埃及记 8:18"> 于是法老召了博士和术士来；他们是埃及行法术的，也用邪术照样而行。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰一书 4:4; 出埃及记 9:11; 出埃及记 8:18–19"> 他们各人丢下自己的杖，杖就变作蛇；但亚伦的杖吞了他们的杖。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 4:21; 出埃及记 8:15; 撒迦利亚书 7:11–12"> 法老心里刚硬，不肯听从摩西、亚伦，正如耶和华所说的。</span>
</div>
</div>

## 埃及遭灾 血灾

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及记 10:20; 出埃及记 8:15; 出埃及记 10:1"> 耶和华对摩西说：「法老心里固执，不肯容百姓去。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 8:20; 出埃及记 2:5; 出埃及记 7:10"> 明日早晨，他出来往水边去，你要往河边迎接他，手里要拿着那变过蛇的杖，</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 3:18; 出埃及记 9:1; 出埃及记 9:13"> 对他说：『耶和华—希伯来人的 神打发我来见你，说：容我的百姓去，好在旷野事奉我。到如今你还是不听。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 4:9; 出埃及记 5:2; 出埃及记 7:5"> 耶和华这样说：我要用我手里的杖击打河中的水，水就变作血；因此，你必知道我是耶和华。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 7:24; 出埃及记 7:21; 民数记 11:20"> 河里的鱼必死，河也要腥臭，埃及人就要厌恶吃这河里的水。』」</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 14:21; 出埃及记 10:12; 出埃及记 8:5–6"> 耶和华晓谕摩西说：「你对亚伦说：『把你的杖伸在埃及所有的水以上，就是在他们的江、河、池、塘以上，叫水都变作血。在埃及遍地，无论在木器中，石器中，都必有血。』」</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="诗篇 78:44; 诗篇 105:29; 出埃及记 7:17–18"> 摩西、亚伦就照耶和华所吩咐的行。亚伦在法老和臣仆眼前举杖击打河里的水，河里的水都变作血了。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 7:18; 启示录 8:9"> 河里的鱼死了，河也腥臭了，埃及人就不能吃这河里的水；埃及遍地都有了血。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 7:11; 提摩太后书 3:8; 耶利米书 27:18"> 埃及行法术的，也用邪术照样而行。法老心里刚硬，不肯听摩西、亚伦，正如耶和华所说的。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 36:24; 以西结书 40:4; 玛拉基书 2:2"> 法老转身进宫，也不把这事放在心上。</span>
<span className="v" id="v24" data-v="24"> 埃及人都在河的两边挖地，要得水喝，因为他们不能喝这河里的水。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及记 10:23; 出埃及记 8:9–10; 撒母耳记下 24:13"> 耶和华击打河以后满了七天。</span>
</div>

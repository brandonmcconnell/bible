## 会幕的技工

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华晓谕摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 36:1; 出埃及记 35:30; 约翰福音 3:27"> 「看哪，犹大支派中，户珥的孙子、乌利的儿子比撒列，我已经提他的名召他。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 35:31; 以赛亚书 28:26; 列王纪上 7:14"> 我也以我的灵充满了他，使他有智慧，有聪明，有知识，能做各样的工，</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 26:1; 出埃及记 25:32–35; 历代志下 2:13–14"> 能想出巧工，用金、银、铜制造各物，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 28:9–21"> 又能刻宝石，可以镶嵌，能雕刻木头，能做各样的工。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 35:10; 出埃及记 35:34–1; 出埃及记 28:3"> 我分派但支派中、亚希撒抹的儿子亚何利亚伯与他同工。凡心里有智慧的，我更使他们有智慧，能做我一切所吩咐的，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 36:8–9; 出埃及记 25:10–22; 出埃及记 26:1–37"> 就是会幕和法柜，并其上的施恩座，与会幕中一切的器具，</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 37:10–28; 出埃及记 30:1–10; 出埃及记 25:23–40"> 桌子和桌子的器具，精金的灯台和灯台的一切器具并香坛，</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 38:1–8; 出埃及记 27:1–8; 出埃及记 40:11"> 燔祭坛和坛的一切器具，并洗濯盆与盆座，</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 4:5–14; 出埃及记 28:1–43; 出埃及记 39:1–43"> 精工做的礼服，和祭司亚伦并他儿子用以供祭司职分的圣衣，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 37:29; 出埃及记 30:23–38"> 膏油和为圣所用馨香的香料。他们都要照我一切所吩咐的去做。」</span>
</div>
</div>

## 安息日

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12"> 耶和华晓谕摩西说：</span>
<span className="v" id="v13" data-v="13" data-xref="以西结书 20:12; 以西结书 20:20; 利未记 19:30"> 「你要吩咐以色列人说：『你们务要守我的安息日；因为这是你我之间世世代代的证据，使你们知道我—耶和华是叫你们成为圣的。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 35:2–3; 民数记 15:32–36; 以西结书 20:21"> 所以你们要守安息日，以为圣日。凡干犯这日的，必要把他治死；凡在这日做工的，必从民中剪除。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 2:2; 出埃及记 16:23; 利未记 23:3"> 六日要做工，但第七日是安息圣日，是向耶和华守为圣的。凡在安息日做工的，必要把他治死。』</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 50:5; 创世记 9:13; 创世记 17:11"> 故此，以色列人要世世代代守安息日为永远的约。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 1:31; 出埃及记 31:13; 创世记 2:2–3"> 这是我和以色列人永远的证据；因为六日之内耶和华造天地，第七日便安息舒畅。」</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命记 4:13; 出埃及记 32:15–16; 申命记 5:22"> 耶和华在西奈山和摩西说完了话，就把两块法版交给他，是 神用指头写的石版。</span>
</div>

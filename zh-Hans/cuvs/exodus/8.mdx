## —蛙灾

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 3:18; 出埃及记 3:12; 出埃及记 5:1"> 耶和华吩咐摩西说：「你进去见法老，对他说：『耶和华这样说：容我的百姓去，好事奉我。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 78:45; 出埃及记 9:2; 出埃及记 7:14"> 你若不肯容他们去，我必使青蛙糟蹋你的四境。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 105:30; 出埃及记 12:34"> 河里要滋生青蛙；这青蛙要上来进你的宫殿和你的卧房，上你的床榻，进你臣仆的房屋，上你百姓的身上，进你的炉灶和你的抟面盆，</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 19:11; 但以理书 4:37; 使徒行传 12:22–23"> 又要上你和你百姓并你众臣仆的身上。』」</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 7:19"> 耶和华晓谕摩西说：「你对亚伦说：『把你的杖伸在江、河、池以上，使青蛙到埃及地上来。』」</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 105:30; 诗篇 78:45; 启示录 16:13"> 亚伦便伸杖在埃及的诸水以上，青蛙就上来，遮满了埃及地。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 7:11; 出埃及记 7:22; 申命记 13:1–3"> 行法术的也用他们的邪术照样而行，叫青蛙上了埃及地。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 10:17; 出埃及记 9:28; 出埃及记 8:25–28"> 法老召了摩西、亚伦来，说：「请你们求耶和华使这青蛙离开我和我的民，我就容百姓去祭祀耶和华。」</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 18:25; 以赛亚书 10:15; 士师记 7:2"> 摩西对法老说：「任凭你吧，我要何时为你和你的臣仆并你的百姓祈求，除灭青蛙离开你和你的宫殿只留在河里呢？」</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 46:9; 诗篇 86:8; 历代志上 17:20"> 他说：「明天。」摩西说：「可以照你的话吧，好叫你知道没有像耶和华—我们 神的。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 8:3; 出埃及记 8:9"> 青蛙要离开你和你的宫殿，并你的臣仆与你的百姓，只留在河里。」</span>
<span className="v" id="v12" data-v="12" data-xref="雅各书 5:16–18; 出埃及记 8:30; 出埃及记 10:18"> 于是摩西、亚伦离开法老出去。摩西为扰害法老的青蛙呼求耶和华。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 34:10–12"> 耶和华就照摩西的话行。凡在房里、院中、田间的青蛙都死了。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 8:24; 出埃及记 7:21; 约珥书 2:20"> 众人把青蛙聚拢成堆，遍地就都腥臭。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 26:10; 传道书 8:11; 希伯来书 3:8"> 但法老见灾祸松缓，就硬着心，不肯听他们，正如耶和华所说的。</span>
</div>
</div>

## 虱灾

<div className="bt">
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及记 8:5; 出埃及记 8:17"> 耶和华吩咐摩西说：「你对亚伦说：『伸出你的杖击打地上的尘土，使尘土在埃及遍地变作虱子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：虼蚤；下同">a</a></sup>。』」</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 105:31; 以赛亚书 23:9; 使徒行传 12:23"> 他们就这样行。亚伦伸杖击打地上的尘土，就在人身上和牲畜身上有了虱子；埃及遍地的尘土都变成虱子了。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 7:11; 出埃及记 9:11; 但以理书 5:8"> 行法术的也用邪术要生出虱子来，却是不能。于是在人身上和牲畜身上都有了虱子。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 11:20; 诗篇 8:3; 出埃及记 7:5"> 行法术的就对法老说：「这是 神的手段。」法老心里刚硬，不肯听摩西、亚伦，正如耶和华所说的。</span>
</div>
</div>

## 蝇灾

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 7:15; 出埃及记 9:13; 出埃及记 8:1"> 耶和华对摩西说：「你清早起来，法老来到水边，你站在他面前，对他说：『耶和华这样说：容我的百姓去，好事奉我。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 78:45; 以赛亚书 7:18; 诗篇 105:31"> 你若不容我的百姓去，我要叫成群的苍蝇到你和你臣仆并你百姓的身上，进你的房屋，并且埃及人的房屋和他们所住的地都要满了成群的苍蝇。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 9:4; 玛拉基书 3:18; 出埃及记 10:23"> 当那日，我必分别我百姓所住的歌珊地，使那里没有成群的苍蝇，好叫你知道我是天下的耶和华。</span>
<span className="v" id="v23" data-v="23"> 我要将我的百姓和你的百姓分别出来。明天必有这神迹。』」</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 105:31; 诗篇 78:45; 出埃及记 8:21"> 耶和华就这样行。苍蝇成了大群，进入法老的宫殿，和他臣仆的房屋；埃及遍地就因这成群的苍蝇败坏了。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及记 8:8; 出埃及记 9:27; 出埃及记 10:16"> 法老召了摩西、亚伦来，说：「你们去，在这地祭祀你们的 神吧！」</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 43:32; 创世记 46:34; 申命记 7:25–26"> 摩西说：「这样行本不相宜，因为我们要把埃及人所厌恶的祭祀耶和华—我们的 神；若把埃及人所厌恶的在他们眼前献为祭，他们岂不拿石头打死我们吗？</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 3:18; 出埃及记 3:12; 出埃及记 34:11"> 我们要往旷野去，走三天的路程，照着耶和华—我们 神所要吩咐我们的祭祀他。」</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 8:8; 出埃及记 9:28; 列王纪上 13:6"> 法老说：「我容你们去，在旷野祭祀耶和华—你们的 神；只是不要走得很远。求你们为我祈祷。」</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 8:15; 耶利米书 42:20–21; 出埃及记 8:8"> 摩西说：「我要出去求耶和华，使成群的苍蝇明天离开法老和法老的臣仆并法老的百姓；法老却不可再行诡诈，不容百姓去祭祀耶和华。」</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 8:12; 出埃及记 9:33; 雅各书 5:16"> 于是摩西离开法老去求耶和华。</span>
<span className="v" id="v31" data-v="31"> 耶和华就照摩西的话行，叫成群的苍蝇离开法老和他的臣仆并他的百姓，一个也没有留下。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 8:15; 出埃及记 4:21; 罗马书 2:5"> 这一次法老又硬着心，不容百姓去。</span>
</div>
</div>

</div>

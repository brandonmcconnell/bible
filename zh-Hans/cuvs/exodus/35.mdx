## 安息日的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 34:32; 出埃及记 31:1–11; 罗马书 2:13"> 摩西招聚以色列全会众，对他们说：「这是耶和华所吩咐的话，叫你们照着行：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 23:3; 路加福音 13:14–15; 出埃及记 20:9–10"> 六日要做工，第七日乃为圣日，当向耶和华守为安息圣日。凡这日之内做工的，必把他治死。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 16:23; 民数记 15:32–36; 出埃及记 12:16"> 当安息日，不可在你们一切的住处生火。」</span>
</div>

## 为会幕奉献

<div className="bt">
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及记 25:1–2"> 摩西对以色列全会众说：「耶和华所吩咐的是这样：</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 9:7; 诗篇 110:3; 出埃及记 25:2–7"> 你们中间要拿礼物献给耶和华，凡乐意献的可以拿耶和华的礼物来，就是金、银、铜，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 26:7–14; 出埃及记 26:31; 出埃及记 28:15"> 蓝色、紫色、朱红色线，细麻，山羊毛，</span>
<span className="v" id="v7" data-v="7"> 染红的公羊皮，海狗皮，皂荚木，</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 27:20; 出埃及记 25:1–40; 出埃及记 30:23"> 点灯的油，并做膏油和香的香料，</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 39:6–14; 出埃及记 28:9; 出埃及记 25:5"> 红玛瑙与别样的宝石，可以镶嵌在以弗得和胸牌上。」</span>
</div>
</div>

## 会幕的器物

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及记 31:1–6; 出埃及记 36:1–4"> 「你们中间凡心里有智慧的都要来做耶和华一切所吩咐的：</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 26:1–37; 出埃及记 36:8–34; 出埃及记 31:7–9"> 就是帐幕和帐幕的罩棚，并帐幕的盖、钩子、板、闩、柱子、带卯的座，</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 25:10–22; 出埃及记 26:31–33; 出埃及记 37:1–9"> 柜和柜的杠，施恩座和遮掩柜的幔子，</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 25:23–30; 利未记 24:5–6; 出埃及记 37:10–16"> 桌子和桌子的杠与桌子的一切器具，并陈设饼，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 25:31–39; 马太福音 5:14–15; 出埃及记 37:17–24"> 灯台和灯台的器具，灯盏并点灯的油，</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 30:1–10; 出埃及记 30:22–38; 出埃及记 37:25–28"> 香坛和坛的杠，膏油和馨香的香料，并帐幕门口的帘子，</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 27:1–8; 出埃及记 30:18–21; 出埃及记 38:1–8"> 燔祭坛和坛的铜网，坛的杠并坛的一切器具，洗濯盆和盆座，</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 7:2; 出埃及记 38:9–20; 出埃及记 27:9–19"> 院子的帷子和帷子的柱子，带卯的座和院子的门帘，</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 27:19"> 帐幕的橛子并院子的橛子，和这两处的绳子，</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 31:10; 民数记 4:5–15; 出埃及记 28:1–43"> 精工做的礼服和祭司亚伦并他儿子在圣所用以供祭司职分的圣衣。」</span>
</div>
</div>

## 百姓奉献礼物

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20"> 以色列全会众从摩西面前退去。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 25:2; 出埃及记 35:26; 历代志上 29:14"> 凡心里受感和甘心乐意的都拿耶和华的礼物来，用以做会幕和其中一切的使用，又用以做圣衣。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米记 7:70–72; 马太福音 2:11; 以斯拉记 2:68–69"> 凡心里乐意献礼物的，连男带女，各将金器，就是胸前针、耳环<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：鼻环">a</a></sup>、打印的戒指，和手钏带来献给耶和华。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 29:8; 出埃及记 25:2–7; 出埃及记 35:6–10"> 凡有蓝色、紫色、朱红色线，细麻，山羊毛，染红的公羊皮，海狗皮的，都拿了来；</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 8:12"> 凡献银子和铜给耶和华为礼物的都拿了来；凡有皂荚木可做什么使用的也拿了来。</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 16:12; 路加福音 8:2–3; 箴言 14:1"> 凡心中有智慧的妇女亲手纺线，把所纺的蓝色、紫色、朱红色线，和细麻都拿了来。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 35:21; 出埃及记 36:8; 出埃及记 35:29"> 凡有智慧、心里受感的妇女就纺山羊毛。</span>
<span className="v" id="v27" data-v="27" data-xref="以斯拉记 2:68; 历代志上 29:6; 出埃及记 35:9"> 众官长把红玛瑙和别样的宝石，可以镶嵌在以弗得与胸牌上的，都拿了来；</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 30:23–38; 出埃及记 35:8"> 又拿香料做香，拿油点灯，做膏油。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多后书 9:7; 出埃及记 35:21–22; 出埃及记 35:4"> 以色列人，无论男女，凡甘心乐意献礼物给耶和华的，都将礼物拿来，做耶和华借摩西所吩咐的一切工。</span>
</div>
</div>

## 造会幕的技工

<div className="bt">
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及记 31:1–6; 雅各书 1:17; 哥林多前书 12:11"> 摩西对以色列人说：「犹大支派中，户珥的孙子、乌利的儿子比撒列，耶和华已经提他的名召他，</span>
<span className="v" id="v31" data-v="31" data-xref="雅各书 1:17; 以赛亚书 11:2–5; 以赛亚书 61:1–3"> 又以 神的灵充满了他，使他有智慧、聪明、知识，能做各样的工，</span>
<span className="v" id="v32" data-v="32"> 能想出巧工，用金、银、铜制造各物，</span>
<span className="v" id="v33" data-v="33"> 又能刻宝石，可以镶嵌，能雕刻木头，能做各样的巧工。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 31:6; 历代志下 2:14; 以斯拉记 7:27"> 耶和华又使他，和但支派中亚希撒抹的儿子亚何利亚伯，心里灵明，能教导人。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及记 35:31; 列王纪上 7:14; 以赛亚书 28:26"> 耶和华使他们的心满有智慧，能做各样的工，无论是雕刻的工，巧匠的工，用蓝色、紫色、朱红色线，和细麻、绣花的工，并机匠的工，他们都能做，也能想出奇巧的工。</span>
</div>
</div>

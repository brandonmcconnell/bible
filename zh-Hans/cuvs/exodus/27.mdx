## 祭坛

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 38:1–7; 出埃及记 20:24–26; 出埃及记 40:10"> 「你要用皂荚木做坛。这坛要四方的，长五肘，宽五肘，高三肘。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 118:27; 出埃及记 29:12; 利未记 4:7"> 要在坛的四拐角上做四个角，与坛接连一块，用铜把坛包裹。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 7:45; 民数记 4:14; 历代志上 28:17"> 要做盆，收去坛上的灰，又做铲子、盘子、肉锸子、火鼎；坛上一切的器具都用铜做。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 35:16; 出埃及记 25:12; 出埃及记 38:4–5"> 要为坛做一个铜网，在网的四角上做四个铜环，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 38:4"> 把网安在坛四面的围腰板以下，使网从下达到坛的半腰。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 35:13–15; 民数记 4:44; 出埃及记 30:4"> 又要用皂荚木为坛做杠，用铜包裹。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 25:28; 出埃及记 30:4; 民数记 4:13–14"> 这杠要穿在坛两旁的环子内，用以抬坛。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 25:40; 出埃及记 25:9; 希伯来书 8:5"> 要用板做坛，坛是空的，都照着在山上指示你的样式做。」</span>
</div>
</div>

## 会幕的周围

<div className="bt">
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 38:9–20; 以西结书 40:32; 以西结书 42:3"> 「你要做帐幕的院子。院子的南面要用捻的细麻做帷子，长一百肘。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 26:19–21; 耶利米书 52:21; 出埃及记 36:38"> 帷子的柱子要二十根，带卯的铜座二十个。柱子上的钩子和杆子都要用银子做。</span>
<span className="v" id="v11" data-v="11"> 北面也当有帷子，长一百肘，帷子的柱子二十根，带卯的铜座二十个。柱子上的钩子和杆子都要用银子做。</span>
<span className="v" id="v12" data-v="12"> 院子的西面当有帷子，宽五十肘，帷子的柱子十根，带卯的座十个。</span>
<span className="v" id="v13" data-v="13"> 院子的东面要宽五十肘。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 27:9; 出埃及记 26:36"> 门这边的帷子要十五肘，帷子的柱子三根，带卯的座三个。</span>
<span className="v" id="v15" data-v="15"> 门那边的帷子也要十五肘，帷子的柱子三根，带卯的座三个。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 26:36; 士师记 5:30; 出埃及记 28:39"> 院子的门当有帘子，长二十肘，要拿蓝色、紫色、朱红色线，和捻的细麻，用绣花的手工织成，柱子四根，带卯的座四个。</span>
<span className="v" id="v17" data-v="17"> 院子四围一切的柱子都要用银杆连络，柱子上的钩子要用银做，带卯的座要用铜做。</span>
<span className="v" id="v18" data-v="18"> 院子要长一百肘，宽五十肘，高五肘，帷子要用捻的细麻做，带卯的座要用铜做。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 35:18; 以赛亚书 22:23–25; 民数记 4:32"> 帐幕各样用处的器具，并帐幕一切的橛子，和院子里一切的橛子，都要用铜做。」</span>
</div>
</div>

## 燃灯的条例

<div className="bt">
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="利未记 24:1–4; 撒迦利亚书 4:11–14; 诗篇 23:5"> 「你要吩咐以色列人，把那为点灯捣成的清橄榄油拿来给你，使灯常常点着。</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 19:21; 民数记 18:23; 撒母耳记上 3:3"> 在会幕中法柜前的幔外，亚伦和他的儿子，从晚上到早晨，要在耶和华面前经理这灯。这要作以色列人世世代代永远的定例。」</span>
</div>

## 神呼召摩西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 19:8; 出埃及记 17:6; 诗篇 78:70–72"> 摩西牧养他岳父米甸祭司叶忒罗的羊群；一日领羊群往野外去，到了 神的山，就是何烈山。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 7:30–35; 以赛亚书 43:2; 马可福音 12:26"> 耶和华的使者从荆棘里火焰中向摩西显现。摩西观看，不料，荆棘被火烧着，却没有烧毁。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 7:31; 诗篇 107:8; 约伯记 37:14"> 摩西说：「我要过去看这大异象，这荆棘为何没有烧坏呢？」</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 33:16; 撒母耳记上 3:6; 使徒行传 9:4"> 耶和华 神见他过去要看，就从荆棘里呼叫说：「摩西！摩西！」他说：「我在这里。」</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 5:15; 使徒行传 7:33; 出埃及记 19:12"> 神说：「不要近前来。当把你脚上的鞋脱下来，因为你所站之地是圣地」；</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 20:37; 马太福音 22:32; 出埃及记 4:5"> 又说：「我是你父亲的 神，是亚伯拉罕的 神，以撒的 神，雅各的 神。」摩西蒙上脸，因为怕看 神。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="诗篇 145:19; 诗篇 106:44; 出埃及记 2:23–25"> 耶和华说：「我的百姓在埃及所受的困苦，我实在看见了；他们因受督工的辖制所发的哀声，我也听见了。我原知道他们的痛苦，</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 50:24; 创世记 15:18–21; 出埃及记 3:17"> 我下来是要救他们脱离埃及人的手，领他们出了那地，到美好、宽阔、流奶与蜜之地，就是到迦南人、赫人、亚摩利人、比利洗人、希未人、耶布斯人之地。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 22:22–23; 出埃及记 2:23; 出埃及记 1:13–14"> 现在以色列人的哀声达到我耳中，我也看见埃及人怎样欺压他们。</span>
<span className="v" id="v10" data-v="10" data-xref="弥迦书 6:4; 撒母耳记上 12:6; 诗篇 105:26"> 故此，我要打发你去见法老，使你可以将我的百姓以色列人从埃及领出来。」</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 18:18; 哥林多后书 3:5; 出埃及记 6:12"> 摩西对 神说：「我是什么人，竟能去见法老，将以色列人从埃及领出来呢？」</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 1:5; 罗马书 8:31; 以赛亚书 41:10"> 神说：「我必与你同在。你将百姓从埃及领出来之后，你们必在这山上事奉我；这就是我打发你去的证据。」</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 30:4; 以赛亚书 9:6; 耶利米书 23:6"> 摩西对 神说：「我到以色列人那里，对他们说：『你们祖宗的 神打发我到你们这里来。』他们若问我说：『他叫什么名字？』我要对他们说什么呢？」</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 8:58; 希伯来书 13:8; 启示录 1:8"> 神对摩西说：「我是自有永有的」；又说：「你要对以色列人这样说：『那自有的打发我到你们这里来。』」</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 17:7–8; 希伯来书 13:8; 玛拉基书 3:6"> 神又对摩西说：「你要对以色列人这样说：『耶和华—你们祖宗的 神，就是亚伯拉罕的 神，以撒的 神，雅各的 神，打发我到你们这里来。』耶和华是我的名，直到永远；这也是我的纪念，直到万代。</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 8:4; 出埃及记 4:31; 出埃及记 4:29"> 你去招聚以色列的长老，对他们说：『耶和华—你们祖宗的 神，就是亚伯拉罕的 神，以撒的 神，雅各的 神，向我显现，说：我实在眷顾了你们，我也看见埃及人怎样待你们。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 15:13–21; 创世记 50:24; 创世记 46:4"> 我也说：要将你们从埃及的困苦中领出来，往迦南人、赫人、亚摩利人、比利洗人、希未人、耶布斯人的地去，就是到流奶与蜜之地。』</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 9:1; 出埃及记 7:16; 出埃及记 10:24–26"> 他们必听你的话。你和以色列的长老要去见埃及王，对他说：『耶和华—希伯来人的 神遇见了我们，现在求你容我们往旷野去，走三天的路程，为要祭祀耶和华—我们的 神。』</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 5:2; 出埃及记 6:1; 出埃及记 7:1–14"> 我知道虽用大能的手，埃及王也不容你们去。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 7:36; 尼希米记 9:10; 出埃及记 9:15"> 我必伸手在埃及中间施行我一切的奇事，攻击那地，然后他才容你们去。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 12:36; 诗篇 105:37; 出埃及记 11:3"> 我必叫你们在埃及人眼前蒙恩，你们去的时候就不至于空手而去。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结书 39:10; 出埃及记 11:2; 出埃及记 12:35–36"> 但各妇女必向她的邻舍，并居住在她家里的女人，要金器银器和衣裳，好给你们的儿女穿戴。这样你们就把埃及人的财物夺去了。」</span>
</div>
</div>

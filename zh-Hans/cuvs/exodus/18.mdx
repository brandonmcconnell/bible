## 叶忒罗访问摩西

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 2:16; 诗篇 77:14–15; 出埃及记 3:1"> 摩西的岳父，米甸祭司叶忒罗，听见 神为摩西和 神的百姓以色列所行的一切事，就是耶和华将以色列从埃及领出来的事，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 2:21; 出埃及记 4:25–26"> 便带着摩西的妻子西坡拉，就是摩西从前打发回去的，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 2:22; 使徒行传 7:29; 诗篇 39:12"> 又带着西坡拉的两个儿子，一个名叫革舜，因为摩西说：「我在外邦作了寄居的」；</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 13:6; 提摩太后书 4:17; 哥林多后书 1:8–10"> 一个名叫以利以谢，因为他说：「我父亲的 神帮助了我，救我脱离法老的刀。」</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 3:1; 出埃及记 3:12; 出埃及记 24:16–17"> 摩西的岳父叶忒罗带着摩西的妻子和两个儿子来到 神的山，就是摩西在旷野安营的地方。</span>
<span className="v" id="v6" data-v="6"> 他对摩西说：「我是你岳父叶忒罗，带着你的妻子和两个儿子来到你这里。」</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 29:13; 创世记 14:17; 撒母耳记下 11:7"> 摩西迎接他的岳父，向他下拜，与他亲嘴，彼此问安，都进了帐棚。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 145:4–12; 尼希米记 9:9–15; 诗篇 107:2"> 摩西将耶和华为以色列的缘故向法老和埃及人所行的一切事，以及路上所遭遇的一切艰难，并耶和华怎样搭救他们，都述说与他岳父听。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 12:26; 罗马书 12:15; 以赛亚书 66:10"> 叶忒罗因耶和华待以色列的一切好处，就是拯救他们脱离埃及人的手，便甚欢喜。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 14:20; 撒母耳记下 18:28; 路加福音 1:68"> 叶忒罗说：「耶和华是应当称颂的；他救了你们脱离埃及人和法老的手，将这百姓从埃及人的手下救出来。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 95:3; 出埃及记 15:11; 历代志下 2:5"> 我现今在埃及人向这百姓发狂傲的事上得知，耶和华比万神都大。」</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 31:54; 申命记 12:7; 出埃及记 24:11"> 摩西的岳父叶忒罗把燔祭和平安祭献给 神。亚伦和以色列的众长老都来了，与摩西的岳父在 神面前吃饭。</span>
</div>
</div>

## 选立百姓的官长

<div className="bt">
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 16:5; 约伯记 29:7; 士师记 5:10"> 第二天，摩西坐着审判百姓，百姓从早到晚都站在摩西的左右。</span>
<span className="v" id="v14" data-v="14"> 摩西的岳父看见他向百姓所做的一切事，就说：「你向百姓做的是什么事呢？你为什么独自坐着，众百姓从早到晚都站在你的左右呢？」</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 15:34; 民数记 27:5; 民数记 9:8"> 摩西对岳父说：「这是因百姓到我这里来求问 神。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 24:14; 哥林多前书 6:1; 撒母耳记下 15:3"> 他们有事的时候就到我这里来，我便在两造之间施行审判；我又叫他们知道 神的律例和法度。」</span>
<span className="v" id="v17" data-v="17"> 摩西的岳父说：「你这做的不好。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 11:14–17; 使徒行传 6:1–4; 哥林多后书 12:15"> 你和这些百姓必都疲惫；因为这事太重，你独自一人办理不了。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 27:5; 申命记 5:5; 出埃及记 20:19"> 现在你要听我的话。我为你出个主意，愿 神与你同在。你要替百姓到 神面前，将案件奏告 神；</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 5:1; 诗篇 143:8; 申命记 1:18"> 又要将律例和法度教训他们，指示他们当行的道，当做的事；</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 6:3; 申命记 1:13–17; 历代志下 19:5–10"> 并要从百姓中拣选有才能的人，就是敬畏 神、诚实无妄、恨不义之财的人，派他们作千夫长、百夫长、五十夫长、十夫长，管理百姓，</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 11:17; 民数记 27:2; 民数记 15:33"> 叫他们随时审判百姓，大事都要呈到你这里，小事他们自己可以审判。这样，你就轻省些，他们也可以同当此任。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 8:6–7; 出埃及记 18:18; 撒母耳记上 8:22"> 你若这样行， 神也这样吩咐你，你就能受得住，这百姓也都平平安安归回他们的住处。」</span>
<span className="v" id="v24" data-v="24" data-xref="以斯拉记 10:2; 出埃及记 18:19; 出埃及记 18:2–5"> 于是，摩西听从他岳父的话，按着他所说的去行。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 1:15; 出埃及记 18:21; 使徒行传 6:5"> 摩西从以色列人中拣选了有才能的人，立他们为百姓的首领，作千夫长、百夫长、五十夫长、十夫长。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 18:22; 出埃及记 18:14–15; 申命记 17:8"> 他们随时审判百姓，有难断的案件就呈到摩西那里，但各样小事他们自己审判。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 10:29–30; 士师记 19:9; 创世记 31:55"> 此后，摩西让他的岳父去，他就往本地去了。</span>
</div>
</div>

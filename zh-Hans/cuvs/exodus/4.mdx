## 神赐摩西行神迹的权能

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 3:18; 出埃及记 2:14; 耶利米书 1:6"> 摩西回答说：「他们必不信我，也不听我的话，必说：『耶和华并没有向你显现。』」</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 4:17; 出埃及记 4:20; 以赛亚书 11:4"> 耶和华对摩西说：「你手里是什么？」他说：「是杖。」</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 7:10–15; 阿摩司书 5:19; 出埃及记 4:17"> 耶和华说：「丢在地上。」他一丢下去，就变作蛇；摩西便跑开。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 28:3–6; 创世记 22:1–2; 诗篇 91:13"> 耶和华对摩西说：「伸出手来，拿住它的尾巴，它必在你手中仍变为杖；</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 19:9; 创世记 48:3; 出埃及记 3:15"> 如此好叫他们信耶和华—他们祖宗的 神，就是亚伯拉罕的 神，以撒的 神，雅各的 神，是向你显现了。」</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王纪下 5:27; 民数记 12:10"> 耶和华又对他说：「把手放在怀里。」他就把手放在怀里，及至抽出来，不料，手长了大麻风，有雪那样白。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 5:14; 申命记 32:39; 马太福音 8:3"> 耶和华说：「再把手放在怀里。」他就再把手放在怀里，及至从怀里抽出来，不料，手已经复原，与周身的肉一样；</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 28:10; 申命记 32:39; 出埃及记 4:30–31"> 又说：「倘或他们不听你的话，也不信头一个神迹，他们必信第二个神迹。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 7:19–25; 出埃及记 1:22; 马太福音 7:2"> 这两个神迹若都不信，也不听你的话，你就从河里取些水，倒在旱地上，你从河里取的水必在旱地上变作血。」</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 1:6; 出埃及记 6:12; 使徒行传 7:22"> 摩西对耶和华说：「主啊，我素日不是能言的人，就是从你对仆人说话以后，也是这样。我本是拙口笨舌的。」</span>
<span className="v" id="v11" data-v="11" data-xref="阿摩司书 3:6; 诗篇 146:8; 以西结书 3:26–27"> 耶和华对他说：「谁造人的口呢？谁使人口哑、耳聋、目明、眼瞎呢？岂不是我—耶和华吗？</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 1:9; 路加福音 12:11–12; 马太福音 10:19–20"> 现在去吧，我必赐你口才，指教你所当说的话。」</span>
<span className="v" id="v13" data-v="13" data-xref="约拿书 1:3; 出埃及记 4:1; 马太福音 13:41"> 摩西说：「主啊，你愿意打发谁，就打发谁去吧！」</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 14:13–15; 出埃及记 4:27; 历代志上 21:7"> 耶和华向摩西发怒说：「不是有你的哥哥利未人亚伦吗？我知道他是能言的；现在他出来迎接你，他一见你，心里就欢喜。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 51:16; 申命记 18:18; 路加福音 21:15"> 你要将当说的话传给他；我也要赐你和他口才，又要指教你们所当行的事。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 7:1–2; 诗篇 82:6; 约翰福音 10:34–35"> 他要替你对百姓说话；你要以他当作口，他要以你当作 神。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 4:2; 哥林多前书 1:27; 出埃及记 7:9–20"> 你手里要拿这杖，好行神迹。」</span>
</div>
</div>

## 摩西返回埃及

<div className="bt">
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 3:1; 撒母耳记上 1:17; 提摩太前书 6:1"> 于是，摩西回到他岳父叶忒罗那里，对他说：「求你容我回去见我在埃及的弟兄，看他们还在不在。」叶忒罗对摩西说：「你可以平平安安地去吧！」</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 2:20; 出埃及记 2:23; 出埃及记 2:15"> 耶和华在米甸对摩西说：「你要回埃及去，因为寻索你命的人都死了。」</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 17:9; 民数记 20:8–9; 出埃及记 18:3–4"> 摩西就带着妻子和两个儿子，叫他们骑上驴，回埃及地去。摩西手里拿着 神的杖。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 9:18; 以赛亚书 63:17; 出埃及记 14:8"> 耶和华对摩西说：「你回到埃及的时候，要留意将我指示你的一切奇事行在法老面前。但我要使<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：任凭；下同">a</a></sup>他的心刚硬，他必不容百姓去。</span>
<span className="v" id="v22" data-v="22" data-xref="何西阿书 11:1; 罗马书 9:4; 耶利米书 31:9"> 你要对法老说：『耶和华这样说：以色列是我的儿子，我的长子。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 11:5; 出埃及记 12:29; 诗篇 135:8"> 我对你说过：容我的儿子去，好事奉我。你还是不肯容他去。看哪，我要杀你的长子。』」</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="创世记 17:14; 民数记 22:22–23; 何西阿书 13:8"> 摩西在路上住宿的地方，耶和华遇见他，想要杀他。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 5:2–3; 创世记 17:14; 撒母耳记下 16:7"> 西坡拉就拿一块火石，割下他儿子的阳皮，丢在摩西脚前，说：「你真是我的血郎了。」</span>
<span className="v" id="v26" data-v="26"> 这样，耶和华才放了他。西坡拉说：「你因割礼就是血郎了。」</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="出埃及记 3:1; 出埃及记 4:14–16; 列王纪上 19:8"> 耶和华对亚伦说：「你往旷野去迎接摩西。」他就去，在 神的山遇见摩西，和他亲嘴。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 4:8–9; 出埃及记 4:15–16; 马太福音 21:29"> 摩西将耶和华打发他所说的言语和嘱咐他所行的神迹都告诉了亚伦。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 3:16; 出埃及记 24:11; 出埃及记 24:1"> 摩西、亚伦就去招聚以色列的众长老。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 4:16"> 亚伦将耶和华对摩西所说的一切话述说了一遍，又在百姓眼前行了那些神迹，</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 3:18; 出埃及记 2:25; 诗篇 106:12–13"> 百姓就信了。以色列人听见耶和华眷顾他们，鉴察他们的困苦，就低头下拜。</span>
</div>
</div>

</div>

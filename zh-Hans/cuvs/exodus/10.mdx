## 蝗灾

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 4:21; 出埃及记 7:13–14; 出埃及记 3:20"> 耶和华对摩西说：「你进去见法老。我使他和他臣仆的心刚硬，为要在他们中间显我这些神迹，</span>
<span className="v" id="v2" data-v="2" data-xref="约珥书 1:3; 申命记 4:9; 申命记 6:20–22"> 并要叫你将我向埃及人所做的事，和在他们中间所行的神迹，传于你儿子和你孙子的耳中，好叫你们知道我是耶和华。」</span>
<span className="v" id="v3" data-v="3" data-xref="彼得前书 5:6; 列王纪上 21:29; 雅各书 4:10"> 摩西、亚伦就进去见法老，对他说：「耶和华—希伯来人的 神这样说：『你在我面前不肯自卑要到几时呢？容我的百姓去，好事奉我。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 9:3; 约珥书 2:25; 出埃及记 11:4–5"> 你若不肯容我的百姓去，明天我要使蝗虫进入你的境内，</span>
<span className="v" id="v5" data-v="5" data-xref="约珥书 1:4; 出埃及记 9:32; 约珥书 2:25"> 遮满地面，甚至看不见地，并且吃那冰雹所剩的和田间所长的一切树木。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 8:21; 出埃及记 8:3; 出埃及记 11:6"> 你的宫殿和你众臣仆的房屋，并一切埃及人的房屋，都要被蝗虫占满了；自从你祖宗和你祖宗的祖宗在世以来，直到今日，没有见过这样的灾。』」摩西就转身离开法老出去。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 18:21; 出埃及记 23:33; 约书亚记 23:13"> 法老的臣仆对法老说：「这人为我们的网罗要到几时呢？容这些人去事奉耶和华—他们的 神吧！埃及已经败坏了，你还不知道吗？」</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 10:24; 出埃及记 12:31; 出埃及记 8:8"> 于是摩西、亚伦被召回来见法老；法老对他们说：「你们去事奉耶和华—你们的 神；但那要去的是谁呢？」</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 5:1; 哥林多前书 5:7–8; 申命记 31:12–13"> 摩西说：「我们要和我们老的少的、儿子女儿同去，且把羊群牛群一同带去，因为我们务要向耶和华守节。」</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 13:21; 历代志下 32:15; 出埃及记 12:30–31"> 法老对他们说：「我容你们和你们妇人孩子去的时候，耶和华与你们同在吧！你们要谨慎；因为有祸在你们眼前<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：你们存着恶意">a</a></sup>，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 10:28; 诗篇 119:69; 出埃及记 5:4"> 不可都去！你们这壮年人去事奉耶和华吧，因为这是你们所求的。」于是把他们从法老面前撵出去。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 7:19; 出埃及记 10:4–5"> 耶和华对摩西说：「你向埃及地伸杖，使蝗虫到埃及地上来，吃地上一切的菜蔬，就是冰雹所剩的。」</span>
<span className="v" id="v13" data-v="13" data-xref="约拿书 1:4; 诗篇 78:26; 诗篇 148:8"> 摩西就向埃及地伸杖，那一昼一夜，耶和华使东风刮在埃及地上；到了早晨，东风把蝗虫刮了来。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 78:46; 约珥书 1:2–4; 诗篇 105:34–35"> 蝗虫上来，落在埃及的四境，甚是厉害；以前没有这样的，以后也必没有。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 10:5; 诗篇 78:46; 约珥书 1:6–7"> 因为这蝗虫遮满地面，甚至地都黑暗了，又吃地上一切的菜蔬和冰雹所剩树上的果子。埃及遍地，无论是树木，是田间的菜蔬，连一点青的也没有留下。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 9:27; 撒母耳记下 19:20; 撒母耳记上 15:30"> 于是法老急忙召了摩西、亚伦来，说：「我得罪耶和华—你们的 神，又得罪了你们。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 8:8; 出埃及记 9:28; 列王纪上 13:6"> 现在求你，只这一次，饶恕我的罪，求耶和华—你们的 神使我脱离这一次的死亡。」</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 6:28; 出埃及记 8:28–30; 出埃及记 8:9"> 摩西就离开法老去求耶和华。</span>
<span className="v" id="v19" data-v="19" data-xref="约珥书 2:20; 出埃及记 13:18; 出埃及记 15:4"> 耶和华转了极大的西风，把蝗虫刮起，吹入红海；在埃及的四境连一个也没有留下。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 4:21; 出埃及记 11:10; 申命记 2:30"> 但耶和华使法老的心刚硬，不容以色列人去。</span>
</div>
</div>

## 黑暗之灾

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="启示录 16:10–11; 犹大书 1:6; 路加福音 23:44"> 耶和华对摩西说：「你向天伸杖，使埃及地黑暗；这黑暗似乎摸得着。」</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 105:28; 启示录 16:10; 出埃及记 20:21"> 摩西向天伸杖，埃及遍地就乌黑了三天。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 8:22; 以赛亚书 42:16; 彼得前书 2:9"> 三天之久，人不能相见，谁也不敢起来离开本处；惟有以色列人家中都有亮光。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 10:8–10; 出埃及记 8:28; 创世记 34:23"> 法老就召摩西来，说：「你们去事奉耶和华；只是你们的羊群牛群要留下；你们的妇人孩子可以和你们同去。」</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 9:22; 利未记 16:9; 出埃及记 29:1–46"> 摩西说：「你总要把祭物和燔祭牲交给我们，使我们可以祭祀耶和华—我们的 神。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 23:18; 使徒行传 2:44–45; 箴言 3:9"> 我们的牲畜也要带去，连一蹄也不留下；因为我们要从其中取出来，事奉耶和华—我们的 神。我们未到那里，还不知道用什么事奉耶和华。」</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 10:20; 出埃及记 4:21; 出埃及记 14:8"> 但耶和华使法老的心刚硬，不肯容他们去。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 25:16; 历代志下 16:10; 阿摩司书 7:13"> 法老对摩西说：「你离开我去吧，你要小心，不要再见我的面！因为你见我面的那日你就必死！」</span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 11:27; 出埃及记 12:30–31; 出埃及记 11:4–8"> 摩西说：「你说得好！我必不再见你的面了。」</span>
</div>

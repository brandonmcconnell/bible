## 摩西的出生

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 26:59; 历代志上 23:12–14; 出埃及记 6:16–20"> 有一个利未家的人娶了一个利未女子为妻。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:23; 使徒行传 7:20; 诗篇 112:5"> 那女人怀孕，生一个儿子，见他俊美，就藏了他三个月，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 1:22; 使徒行传 7:19; 创世记 6:14"> 后来不能再藏，就取了一个蒲草箱，抹上石漆和石油，将孩子放在里头，把箱子搁在河边的芦荻中。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 26:59; 出埃及记 15:20; 弥迦书 6:4"> 孩子的姊姊远远站着，要知道他究竟怎么样。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 7:21; 诗篇 12:5; 诗篇 9:9"> 法老的女儿来到河边洗澡，她的使女们在河边行走。她看见箱子在芦荻中，就打发一个婢女拿来。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 8:50; 彼得前书 3:8; 使徒行传 7:21"> 她打开箱子，看见那孩子。孩子哭了，她就可怜他，说：「这是希伯来人的一个孩子。」</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 2:4; 民数记 26:59; 民数记 12:1"> 孩子的姊姊对法老的女儿说：「我去在希伯来妇人中叫一个奶妈来，为你奶这孩子，可以不可以？」</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 46:3–4; 诗篇 27:10; 出埃及记 6:20"> 法老的女儿说：「可以。」童女就去叫了孩子的母亲来。</span>
<span className="v" id="v9" data-v="9"> 法老的女儿对她说：「你把这孩子抱去，为我奶他，我必给你工价。」妇人就抱了孩子去奶他。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 11:24; 创世记 16:11; 撒母耳记上 1:20"> 孩子渐长，妇人把他带到法老的女儿那里，就作了她的儿子。她给孩子起名叫摩西，意思说：「因我把他从水里拉出来。」</span>
</div>
</div>

## 摩西逃往米甸

<div className="bt">
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="希伯来书 11:24–26; 使徒行传 7:22–24; 出埃及记 1:11"> 后来，摩西长大，他出去到他弟兄那里，看他们的重担，见一个埃及人打希伯来人的一个弟兄。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 7:24–26"> 他左右观看，见没有人，就把埃及人打死了，藏在沙土里。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 7:26–28; 哥林多前书 6:7–8"> 第二天他出去，见有两个希伯来人争斗，就对那欺负人的说：「你为什么打你同族的人呢？」</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 12:14; 马太福音 21:23; 创世记 19:9"> 那人说：「谁立你作我们的首领和审判官呢？难道你要杀我，像杀那埃及人吗？」摩西便惧怕，说：「这事必是被人知道了。」</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 7:29; 希伯来书 11:27; 创世记 24:11"> 法老听见这事，就想杀摩西，但摩西躲避法老，逃往米甸地居住。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="创世记 24:11; 出埃及记 3:1; 撒母耳记上 9:11"> 一日，他在井旁坐下。米甸的祭司有七个女儿；她们来打水，打满了槽，要饮父亲的群羊。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 29:10; 创世记 21:25; 创世记 26:15–22"> 有牧羊的人来，把她们赶走了，摩西却起来帮助她们，又饮了她们的群羊。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 3:1; 民数记 10:29; 出埃及记 4:18"> 她们来到父亲流珥那里；他说：「今日你们为何来得这么快呢？」</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 50:11; 创世记 29:10"> 她们说：「有一个埃及人救我们脱离牧羊人的手，并且为我们打水饮了群羊。」</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 31:54; 创世记 43:25; 希伯来书 13:2"> 他对女儿们说：「那个人在哪里？你们为什么撇下他呢？你们去请他来吃饭。」</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 31:38–40; 希伯来书 13:5; 希伯来书 11:25"> 摩西甘心和那人同住；那人把他的女儿西坡拉给摩西为妻。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 11:13–14; 使徒行传 7:29; 出埃及记 22:21"> 西坡拉生了一个儿子，摩西给他起名叫革舜，意思说：「因我在外邦作了寄居的。」</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="创世记 18:20–21; 雅各书 5:4; 出埃及记 3:7–9"> 过了多年，埃及王死了。以色列人因做苦工，就叹息哀求，他们的哀声达于 神。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 26:3; 诗篇 105:42; 出埃及记 6:5"> 神听见他们的哀声，就记念他与亚伯拉罕、以撒、雅各所立的约。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 4:31; 诗篇 55:22; 出埃及记 3:7–8"> 神看顾以色列人，也知道他们的苦情。</span>
</div>
</div>

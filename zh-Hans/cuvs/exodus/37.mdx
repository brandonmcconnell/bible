## 造约柜

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 25:10–20; 出埃及记 26:33; 民数记 10:33–36"> 比撒列用皂荚木做柜，长二肘半，宽一肘半，高一肘半。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 30:3"> 里外包上精金，四围镶上金牙边，</span>
<span className="v" id="v3" data-v="3"> 又铸四个金环，安在柜的四脚上：这边两环，那边两环。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 9:15; 彼得前书 1:7; 民数记 4:14–15"> 用皂荚木做两根杠，用金包裹。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 4:15; 撒母耳记下 6:3–7; 民数记 1:50"> 把杠穿在柜旁的环内，以便抬柜。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 9:5; 提多书 2:14; 罗马书 3:25"> 用精金做施恩座，长二肘半，宽一肘半。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结书 10:2; 诗篇 104:4; 诗篇 80:1"> 用金子锤出两个基路伯来，安在施恩座的两头，</span>
<span className="v" id="v8" data-v="8"> 这头做一个基路伯，那头做一个基路伯，二基路伯接连一块，在施恩座的两头。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 1:51; 希伯来书 1:14; 创世记 28:12"> 二基路伯高张翅膀，遮掩施恩座；基路伯是脸对脸，朝着施恩座。</span>
</div>
</div>

## 造陈设饼的桌子

<div className="bt">
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约翰福音 1:14; 以西结书 40:39–42; 玛拉基书 1:12"> 他用皂荚木做一张桌子，长二肘，宽一肘，高一肘半，</span>
<span className="v" id="v11" data-v="11"> 又包上精金，四围镶上金牙边。</span>
<span className="v" id="v12" data-v="12"> 桌子的四围各做一掌宽的横梁，横梁上镶着金牙边，</span>
<span className="v" id="v13" data-v="13"> 又铸了四个金环，安在桌子四脚的四角上。</span>
<span className="v" id="v14" data-v="14"> 安环子的地方是挨近横梁，可以穿杠抬桌子。</span>
<span className="v" id="v15" data-v="15"> 他用皂荚木做两根杠，用金包裹，以便抬桌子；</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 25:29; 列王纪上 7:50; 列王纪下 12:13"> 又用精金做桌子上的器皿，就是盘子、调羹，并奠酒的瓶和爵。</span>
</div>
</div>

## 造灯台

<div className="bt">
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及记 25:31–39; 希伯来书 9:2; 历代志下 13:11"> 他用精金做一个灯台；这灯台的座和干，与杯、球、花，都是接连一块锤出来的。</span>
<span className="v" id="v18" data-v="18"> 灯台两旁杈出六个枝子：这旁三个，那旁三个。</span>
<span className="v" id="v19" data-v="19"> 这旁每枝上有三个杯，形状像杏花，有球有花；那旁每枝上也有三个杯，形状像杏花，有球有花。从灯台杈出来的六个枝子都是如此。</span>
<span className="v" id="v20" data-v="20" data-xref="传道书 12:5; 耶利米书 1:11; 出埃及记 25:33"> 灯台上有四个杯，形状像杏花，有球有花。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 25:35"> 灯台每两个枝子以下有球，与枝子接连一块；灯台杈出的六个枝子都是如此。</span>
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 3:5; 出埃及记 25:31; 诗篇 51:17"> 球和枝子是接连一块，都是一块精金锤出来的。</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 1:12; 出埃及记 25:37; 启示录 1:20–1"> 用精金做灯台的七个灯盏，并灯台的蜡剪和蜡花盘。</span>
<span className="v" id="v24" data-v="24"> 他用精金一他连得做灯台和灯台的一切器具。</span>
</div>
</div>

## 造香坛

<div className="bt">
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及记 30:1–5; 希伯来书 7:25; 启示录 8:3–4"> 他用皂荚木做香坛，是四方的，长一肘，宽一肘，高二肘，坛的四角与坛接连一块；</span>
<span className="v" id="v26" data-v="26"> 又用精金把坛的上面与坛的四面并坛的四角包裹，又在坛的四围镶上金牙边。</span>
<span className="v" id="v27" data-v="27"> 做两个金环，安在牙子边以下，在坛的两旁、两根横撑上，作为穿杠的用处，以便抬坛。</span>
<span className="v" id="v28" data-v="28"> 用皂荚木做杠，用金包裹。</span>
</div>
</div>

## 逾越节

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华在埃及地晓谕摩西、亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 13:4; 申命记 16:1; 出埃及记 34:18"> 「你们要以本月为正月，为一年之首。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 1:2; 哥林多前书 5:7; 约翰福音 1:29"> 你们吩咐以色列全会众说：本月初十日，各人要按着父家取羊羔，一家一只。</span>
<span className="v" id="v4" data-v="4"> 若是一家的人太少，吃不了一只羊羔，本人就要和他隔壁的邻舍共取一只。你们预备羊羔，要按着人数和饭量计算。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前书 1:18–19; 希伯来书 9:13–14; 玛拉基书 1:14"> 要无残疾、一岁的公羊羔，你们或从绵羊里取，或从山羊里取，都可以。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 23:5; 历代志下 30:15–18; 民数记 28:16"> 要留到本月十四日，在黄昏的时候，以色列全会众把羊羔宰了。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 11:28; 出埃及记 12:22–23; 希伯来书 9:22"> 各家要取点血，涂在吃羊羔的房屋左右的门框上和门楣上。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 34:25; 申命记 16:7; 出埃及记 13:3"> 当夜要吃羊羔的肉；用火烤了，与无酵饼和苦菜同吃。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 12:8; 申命记 16:7; 耶利米哀歌 1:13"> 不可吃生的，断不可吃水煮的，要带着头、腿、五脏，用火烤了吃。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 23:18; 出埃及记 34:25; 出埃及记 29:34"> 不可剩下一点留到早晨；若留到早晨，要用火烧了。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 12:27; 以弗所书 6:15; 哥林多前书 5:7"> 你们吃羊羔当腰间束带，脚上穿鞋，手中拿杖，赶紧地吃；这是耶和华的逾越节。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 33:4; 出埃及记 12:23; 诗篇 82:6"> 因为那夜我要巡行埃及地，把埃及地一切头生的，无论是人是牲畜，都击杀了，又要败坏埃及一切的神。我是耶和华。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 11:28; 出埃及记 12:23; 约翰一书 1:7"> 这血要在你们所住的房屋上作记号；我一见这血，就越过你们去。我击杀埃及地头生的时候，灾殃必不临到你们身上灭你们。」</span>
</div>
</div>

## 无酵节

<div className="bt">
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王纪下 23:21; 出埃及记 12:24; 出埃及记 13:9–10"> 「你们要记念这日，守为耶和华的节，作为你们世世代代永远的定例。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 17:14; 申命记 16:3; 出埃及记 23:15"> 你们要吃无酵饼七日。头一日要把酵从你们各家中除去；因为从头一日起，到第七日为止，凡吃有酵之饼的，必从以色列中剪除。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 23:7–8; 民数记 28:18; 出埃及记 16:23"> 头一日你们当有圣会，第七日也当有圣会。这两日之内，除了预备各人所要吃的以外，无论何工都不可做。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 7:5; 出埃及记 13:3; 出埃及记 12:41"> 你们要守无酵节，因为我正当这日把你们的军队从埃及地领出来。所以，你们要守这日，作为世世代代永远的定例。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 23:5–8; 出埃及记 12:15; 出埃及记 12:1–2"> 从正月十四日晚上，直到二十一日晚上，你们要吃无酵饼。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 12:15; 出埃及记 23:15; 申命记 16:3"> 在你们各家中，七日之内不可有酵；因为凡吃有酵之物的，无论是寄居的，是本地的，必从以色列的会中剪除。</span>
<span className="v" id="v20" data-v="20"> 有酵的物，你们都不可吃；在你们一切住处要吃无酵饼。」</span>
</div>
</div>

## 第一个逾越节

<div className="bt">
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及记 12:3; 路加福音 22:7–13; 历代志下 35:5–6"> 于是，摩西召了以色列的众长老来，对他们说：「你们要按着家口取出羊羔，把这逾越节的羊羔宰了。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 11:28; 民数记 19:18; 诗篇 51:7"> 拿一把牛膝草，蘸盆里的血，打在门楣上和左右的门框上。你们谁也不可出自己的房门，直到早晨。</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 7:3; 启示录 9:4; 希伯来书 11:28"> 因为耶和华要巡行击杀埃及人，他看见血在门楣上和左右的门框上，就必越过那门，不容灭命的进你们的房屋，击杀你们。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 12:14; 创世记 17:8–10"> 这例，你们要守着，作为你们和你们子孙永远的定例。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 3:17; 出埃及记 3:8; 申命记 12:8–9"> 日后，你们到了耶和华按着所应许赐给你们的那地，就要守这礼。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 13:14–15; 申命记 32:7; 诗篇 145:4"> 你们的儿女问你们说：『行这礼是什么意思？』</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 4:31; 出埃及记 12:11; 哥林多前书 5:7"> 你们就说：『这是献给耶和华逾越节的祭。当以色列人在埃及的时候，他击杀埃及人，越过以色列人的房屋，救了我们各家。』」于是百姓低头下拜。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 11:28"> 耶和华怎样吩咐摩西、亚伦，以色列人就怎样行。</span>
</div>
</div>

## 头胎的被杀

<div className="bt">
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="诗篇 78:51; 出埃及记 4:23; 诗篇 105:36"> 到了半夜，耶和华把埃及地所有的长子，就是从坐宝座的法老，直到被掳囚在监里之人的长子，以及一切头生的牲畜，尽都杀了。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 11:6; 阿摩司书 5:17; 箴言 21:13"> 法老和一切臣仆，并埃及众人，夜间都起来了。在埃及有大哀号，无一家不死一个人的。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 6:1; 出埃及记 10:9; 出埃及记 3:19–20"> 夜间，法老召了摩西、亚伦来，说：「起来！连你们带以色列人，从我民中出去，依你们所说的，去事奉耶和华吧！</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 10:26; 创世记 27:34; 创世记 27:38"> 也依你们所说的，连羊群牛群带着走吧！并要为我祝福。」</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 105:38; 出埃及记 11:1; 创世记 20:3"> 埃及人催促百姓，打发他们快快出离那地，因为埃及人说：「我们都要死了。」</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 8:3"> 百姓就拿着没有酵的生面，把抟面盆包在衣服中，扛在肩头上。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及记 3:21–22; 出埃及记 11:2–3; 创世记 15:14"> 以色列人照着摩西的话行，向埃及人要金器、银器，和衣裳。</span>
<span className="v" id="v36" data-v="36" data-xref="创世记 15:14; 使徒行传 7:10; 出埃及记 3:21–22"> 耶和华叫百姓在埃及人眼前蒙恩，以致埃及人给他们所要的。他们就把埃及人的财物夺去了。</span>
</div>
</div>

## 以色列人出埃及

<div className="bt">
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="民数记 1:46; 出埃及记 38:26; 民数记 33:3"> 以色列人从兰塞起行，往疏割去；除了妇人孩子，步行的男人约有六十万。</span>
<span className="v" id="v38" data-v="38" data-xref="民数记 11:4; 撒迦利亚书 8:23"> 又有许多闲杂人，并有羊群牛群，和他们一同上去。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及记 11:1; 出埃及记 6:1; 出埃及记 12:31–33"> 他们用埃及带出来的生面烤成无酵饼。这生面原没有发起；因为他们被催逼离开埃及，不能耽延，也没有为自己预备什么食物。</span>
<span className="v" id="v40" data-v="40" data-xref="创世记 15:13; 使徒行传 7:6; 使徒行传 13:17"> 以色列人住在埃及共有四百三十年。</span>
<span className="v" id="v41" data-v="41" data-xref="哈巴谷书 2:3; 约翰福音 7:8; 使徒行传 1:7"> 正满了四百三十年的那一天，耶和华的军队都从埃及地出来了。</span>
<span className="v" id="v42" data-v="42" data-xref="申命记 16:1–6; 出埃及记 12:14; 出埃及记 13:10"> 这夜是耶和华的夜；因耶和华领他们出了埃及地，所以当向耶和华谨守，是以色列众人世世代代该谨守的。</span>
</div>
</div>

## 逾越节的条例

<div className="bt">
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="出埃及记 12:48; 民数记 9:14; 出埃及记 12:11"> 耶和华对摩西、亚伦说：「逾越节的例是这样：外邦人都不可吃这羊羔。</span>
<span className="v" id="v44" data-v="44" data-xref="创世记 17:12–13; 创世记 17:23"> 但各人用银子买的奴仆，既受了割礼就可以吃。</span>
<span className="v" id="v45" data-v="45" data-xref="利未记 22:10; 以弗所书 2:12"> 寄居的和雇工人都不可吃。</span>
<span className="v" id="v46" data-v="46" data-xref="民数记 9:12; 约翰福音 19:36; 约翰福音 19:33"> 应当在一个房子里吃；不可把一点肉从房子里带到外头去。羊羔的骨头一根也不可折断。</span>
<span className="v" id="v47" data-v="47" data-xref="出埃及记 12:6; 民数记 9:13; 出埃及记 12:3"> 以色列全会众都要守这礼。</span>
<span className="v" id="v48" data-v="48" data-xref="民数记 9:14; 歌罗西书 3:11; 加拉太书 3:28"> 若有外人寄居在你们中间，愿向耶和华守逾越节，他所有的男子务要受割礼，然后才容他前来遵守，他也就像本地人一样；但未受割礼的，都不可吃这羊羔。</span>
<span className="v" id="v49" data-v="49" data-xref="民数记 15:15–16; 民数记 15:29; 利未记 24:22"> 本地人和寄居在你们中间的外人同归一例。」</span>
<span className="v" id="v50" data-v="50" data-xref="马太福音 7:24–25; 出埃及记 6:26; 出埃及记 7:4"> 耶和华怎样吩咐摩西、亚伦，以色列众人就怎样行了。</span>
<span className="v" id="v51" data-v="51" data-xref="出埃及记 12:41; 出埃及记 6:26"> 正当那日，耶和华将以色列人按着他们的军队，从埃及地领出来。</span>
</div>
</div>

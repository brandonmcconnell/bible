## 对待奴仆的条例

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 4:14; 申命记 6:20; 出埃及记 24:3–4"> 「你在百姓面前所要立的典章是这样：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 15:12–15; 出埃及记 12:44; 申命记 15:18"> 你若买希伯来人作奴仆，他必服事你六年；第七年他可以自由，白白地出去。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 15:12–14"> 他若孤身来就可以孤身去；他若有妻，他的妻就可以同他出去。</span>
<span className="v" id="v4" data-v="4"> 他主人若给他妻子，妻子给他生了儿子或女儿，妻子和儿女要归主人，他要独自出去。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 5:14–15; 申命记 15:16–17; 以赛亚书 26:13"> 倘或奴仆明说：『我爱我的主人和我的妻子儿女，不愿意自由出去。』</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 15:17; 利未记 25:40; 申命记 19:17–18"> 他的主人就要带他到审判官<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译： 神；下同">a</a></sup>那里，又要带他到门前，靠近门框，用锥子穿他的耳朵，他就永远服事主人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="尼希米记 5:5; 出埃及记 21:2–3"> 「人若卖女儿作婢女，婢女不可像男仆那样出去。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 28:8; 申命记 20:7; 玛拉基书 2:11–15"> 主人选定她归自己，若不喜欢她，就要许她赎身；主人既然用诡诈待她，就没有权柄卖给外邦人。</span>
<span className="v" id="v9" data-v="9"> 主人若选定她给自己的儿子，就当待她如同女儿。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 7:1–6"> 若另娶一个，那女子的吃食、衣服，并好合的事，仍不可减少。</span>
<span className="v" id="v11" data-v="11"> 若不向她行这三样，她就可以不用钱赎，白白地出去。」</span>
</div>
</div>

## 惩罚暴行的条例

<div className="bt">
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 9:6; 马太福音 26:52; 利未记 24:17"> 「打人以致打死的，必要把他治死。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 20:2–9; 撒母耳记上 24:18; 申命记 4:41–43"> 人若不是埋伏着杀人，乃是 神交在他手中，我就设下一个地方，他可以往那里逃跑。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 2:28–34; 希伯来书 10:26; 民数记 15:30–31"> 人若任意用诡计杀了他的邻舍，就是逃到我的坛那里，也当捉去把他治死。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命记 21:18–21; 箴言 30:17; 提摩太前书 1:9"> 「打父母的，必要把他治死。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命记 24:7; 提摩太前书 1:10; 出埃及记 22:4"> 「拐带人口，或是把人卖了，或是留在他手下，必要把他治死。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="箴言 20:20; 马可福音 7:10–11; 申命记 27:16"> 「咒骂父母的，必要把他治死。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 21:20; 申命记 25:11; 撒母耳记下 14:6"> 「人若彼此相争，这个用石头或是拳头打那个，尚且不至于死，不过躺卧在床，</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 3:29; 撒迦利亚书 8:4"> 若再能起来扶杖而出，那打他的可算无罪；但要将他耽误的工夫用钱赔补，并要将他全然医好。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="箴言 29:19; 申命记 19:21; 民数记 35:19"> 「人若用棍子打奴仆或婢女，立时死在他的手下，他必要受刑。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 25:44–46"> 若过一两天才死，就可以不受刑，因为是用钱买的。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命记 22:18–19; 出埃及记 21:30; 申命记 16:18"> 「人若彼此争斗，伤害有孕的妇人，甚至坠胎，随后却无别害，那伤害她的，总要按妇人的丈夫所要的，照审判官所断的，受罚。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 19:21; 民数记 35:31; 利未记 24:19"> 若有别害，就要以命偿命，</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 19:21; 马太福音 5:38–40; 马太福音 7:2"> 以眼还眼，以牙还牙，以手还手，以脚还脚，</span>
<span className="v" id="v25" data-v="25"> 以烙还烙，以伤还伤，以打还打。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 21:20; 约伯记 31:13–15; 诗篇 72:12–14"> 「人若打坏了他奴仆或是婢女的一只眼，就要因他的眼放他去得以自由。</span>
<span className="v" id="v27" data-v="27"> 若打掉了他奴仆或是婢女的一个牙，就要因他的牙放他去得以自由。」</span>
</div>
</div>

## 物主的责任

<div className="bt">
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="出埃及记 21:32; 利未记 20:15–16; 创世记 9:5–6"> 「牛若触死男人或是女人，总要用石头打死那牛，却不可吃它的肉；牛的主人可算无罪。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 21:1–9"> 倘若那牛素来是触人的，有人报告了牛主，他竟不把牛拴着，以致把男人或是女人触死，就要用石头打死那牛，牛主也必治死。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 21:22; 出埃及记 30:12; 民数记 35:31–33"> 若罚他赎命的价银，他必照所罚的赎他的命。</span>
<span className="v" id="v31" data-v="31"> 牛无论触了人的儿子或是女儿，必照这例办理。</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 26:15; 撒迦利亚书 11:12–13; 马太福音 27:3–9"> 牛若触了奴仆或是婢女，必将银子三十舍客勒给他们的主人，也要用石头把牛打死。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="箴言 28:10; 耶利米书 18:20; 传道书 10:8"> 「人若敞着井口，或挖井不遮盖，有牛或驴掉在里头，</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 22:6; 出埃及记 21:29–30; 出埃及记 22:14"> 井主要拿钱赔还本主人，死牲畜要归自己。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35"> 「这人的牛若伤了那人的牛，以至于死，他们要卖了活牛，平分价值，也要平分死牛。</span>
<span className="v" id="v36" data-v="36"> 人若知道这牛素来是触人的，主人竟不把牛拴着，他必要以牛还牛，死牛要归自己。」</span>
</div>
</div>

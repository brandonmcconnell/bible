## 耶和华审判的日子

<div className="bt">
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="弥迦书 7:13; 列王纪下 22:16–17; 以西结书 33:27–29"> <span className="pl pl-1">耶和华说：</span><br /><span className="pl pl-1">我必从地上除灭万类。</span><br /></span>
<span className="v" id="v3" data-v="3" data-xref="何西阿书 4:3; 以西结书 7:19; 耶利米书 12:4"> <span className="pl pl-1">我必除灭人和牲畜，</span><br /><span className="pl pl-1">与空中的鸟、海里的鱼，</span><br /><span className="pl pl-1">以及绊脚石和恶人；</span><br /><span className="pl pl-1">我必将人从地上剪除。</span><br /><span className="pl pl-1">这是耶和华说的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="何西阿书 10:5; 弥迦书 5:13; 列王纪下 23:4–5"> <span className="pl pl-1">我必伸手攻击犹大</span><br /><span className="pl pl-1">和耶路撒冷的一切居民，</span><br /><span className="pl pl-1">也必从这地方剪除所剩下的巴力，</span><br /><span className="pl pl-1">并基玛林的名和祭司，</span><br /></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 19:13; 列王纪上 11:33; 列王纪下 17:33"> <span className="pl pl-1">与那些在房顶上敬拜天上万象的，</span><br /><span className="pl pl-1">并那些敬拜耶和华指着他起誓，</span><br /><span className="pl pl-1">又指着玛勒堪起誓的，</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 1:4; 耶利米书 2:13; 耶利米书 15:6"> <span className="pl pl-1">与那些转去不跟从耶和华的，</span><br /><span className="pl pl-1">和不寻求耶和华也不访问他的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="哈巴谷书 2:20; 撒迦利亚书 2:13; 西番雅书 1:14"> <span className="pl pl-1">你要在主耶和华面前静默无声，</span><br /><span className="pl pl-1">因为耶和华的日子快到。</span><br /><span className="pl pl-1">耶和华已经预备祭物，</span><br /><span className="pl pl-1">将他的客分别为圣。</span><br /></span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 24:21; 以赛亚书 3:18–24; 耶利米书 22:24–30"> <span className="pl pl-1">到了我—耶和华献祭的日子，</span><br /><span className="pl pl-1">必惩罚首领和王子，</span><br /><span className="pl pl-1">并一切穿外邦衣服的。</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 5:5; 阿摩司书 3:10; 撒母耳记上 2:15–16"> <span className="pl pl-1">到那日，我必惩罚一切跳过门槛、</span><br /><span className="pl pl-1">将强暴和诡诈得来之物充满主人房屋的。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v10" data-v="10" data-xref="历代志下 33:14; 阿摩司书 8:3; 列王纪下 22:14"> <span className="pl pl-1">耶和华说：当那日，</span><br /><span className="pl pl-1">从鱼门必发出悲哀的声音，</span><br /><span className="pl pl-1">从二城发出哀号的声音，</span><br /><span className="pl pl-1">从山间发出大破裂的响声。</span><br /></span>
<span className="v" id="v11" data-v="11" data-xref="雅各书 5:1; 耶利米书 25:34; 何西阿书 12:7–8"> <span className="pl pl-1">玛革提施的居民哪，你们要哀号，</span><br /><span className="pl pl-1">因为迦南的商民都灭亡了！</span><br /><span className="pl pl-1">凡搬运银子的都被剪除。</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="阿摩司书 6:1; 耶利米书 48:11; 以西结书 8:12"> <span className="pl pl-1">那时，我必用灯巡查耶路撒冷；</span><br /><span className="pl pl-1">我必惩罚那些如酒在渣滓上澄清的；</span><br /><span className="pl pl-1">他们心里说：</span><br /><span className="pl pl-1">耶和华必不降福，也不降祸。</span><br /></span>
<span className="v" id="v13" data-v="13" data-xref="阿摩司书 5:11; 弥迦书 6:15; 申命记 28:30"> <span className="pl pl-1">他们的财宝必成为掠物；</span><br /><span className="pl pl-1">他们的房屋必变为荒场。</span><br /><span className="pl pl-1">他们必建造房屋，却不得住在其内；</span><br /><span className="pl pl-1">栽种葡萄园，却不得喝所出的酒。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 4:5; 以西结书 30:3; 西番雅书 1:7"> <span className="pl pl-1">耶和华的大日临近，</span><br /><span className="pl pl-1">临近而且甚快，</span><br /><span className="pl pl-1">乃是耶和华日子的风声；</span><br /><span className="pl pl-1">勇士必痛痛地哭号。</span><br /></span>
<span className="v" id="v15" data-v="15" data-xref="约珥书 2:2; 以赛亚书 22:5; 启示录 6:17"> <span className="pl pl-1">那日是忿怒的日子，</span><br /><span className="pl pl-1">是急难困苦的日子，</span><br /><span className="pl pl-1">是荒废凄凉的日子，</span><br /><span className="pl pl-1">是黑暗幽冥、密云乌黑的日子，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="何西阿书 8:1; 阿摩司书 3:6; 以赛亚书 32:14"> <span className="pl pl-1">是吹角呐喊的日子，</span><br /><span className="pl pl-1">要攻击坚固城和高大的城楼。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="启示录 3:17; 诗篇 83:10; 耶利米书 2:17"> <span className="pl pl-1">我必使灾祸临到人身上，</span><br /><span className="pl pl-1">使他们行走如同瞎眼的，</span><br /><span className="pl pl-1">因为得罪了我。</span><br /><span className="pl pl-1">他们的血必倒出如灰尘；</span><br /><span className="pl pl-1">他们的肉必抛弃如粪土。</span><br /></span>
<span className="v" id="v18" data-v="18" data-xref="西番雅书 3:8; 以西结书 7:19; 箴言 11:4"> <span className="pl pl-1">当耶和华发怒的日子，</span><br /><span className="pl pl-1">他们的金银不能救他们；</span><br /><span className="pl pl-1">他的忿怒如火必烧灭全地，</span><br /><span className="pl pl-1">毁灭这地的一切居民，而且大大毁灭。</span></span>
</div>

## 耶路撒冷和列国

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 13:9; 以赛亚书 2:12; 以赛亚书 13:6"> 耶和华的日子临近，你的财物必被抢掠，在你中间分散。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 21:20–24; 以赛亚书 13:16; 罗马书 9:27–29"> 因为我必聚集万国与耶路撒冷争战，城必被攻取，房屋被抢夺，妇女被玷污，城中的民一半被掳去；剩下的民仍在城中，不致剪除。</span>
<span className="v" id="v3" data-v="3" data-xref="撒迦利亚书 12:9; 西番雅书 3:19; 撒迦利亚书 2:8–9"> 那时，耶和华必出去与那些国争战，好像从前争战一样。</span>
<span className="v" id="v4" data-v="4" data-xref="弥迦书 1:3–4; 以西结书 11:23; 使徒行传 1:11–12"> 那日，他的脚必站在耶路撒冷前面朝东的橄榄山上。这山必从中间分裂，自东至西成为极大的谷。山的一半向北挪移，一半向南挪移。</span>
<span className="v" id="v5" data-v="5" data-xref="犹大书 1:14–15; 阿摩司书 1:1; 马太福音 25:31"> 你们要从我山的谷中逃跑，因为山谷必延到亚萨。你们逃跑，必如犹大王乌西雅年间的人逃避大地震一样。耶和华—我的 神必降临，有一切圣者同来。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 97:10–11; 诗篇 112:4; 约翰福音 12:46"> 那日，必没有光，三光必退缩。</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 22:5; 帖撒罗尼迦前书 5:2; 但以理书 12:4"> 那日，必是耶和华所知道的，不是白昼，也不是黑夜，到了晚上才有光明。</span>
<span className="v" id="v8" data-v="8" data-xref="启示录 22:1–2; 约翰福音 7:38; 约翰福音 4:14"> 那日，必有活水从耶路撒冷出来，一半往东海流，一半往西海流；冬夏都是如此。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 4:5–6; 启示录 11:15; 但以理书 7:27"> 耶和华必作全地的王。那日耶和华必为独一无二的，他的名也是独一无二的。</span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亚书 12:6; 约书亚记 15:32; 列王纪上 15:22"> 全地，从迦巴直到耶路撒冷南方的临门，要变为亚拉巴。耶路撒冷必仍居高位，就是从便雅悯门到第一门之处，又到角门，并从哈楠业楼，直到王的酒榨。</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 22:3; 耶利米书 23:5–6; 阿摩司书 9:15"> 人必住在其中，不再有咒诅。耶路撒冷人必安然居住。</span>
<span className="v" id="v12" data-v="12" data-xref="以西结书 39:17–20; 以赛亚书 66:15–16; 弥迦书 4:11–13"> 耶和华用灾殃攻击那与耶路撒冷争战的列国人，必是这样：他们两脚站立的时候，肉必消没，眼在眶中干瘪，舌在口中溃烂。</span>
<span className="v" id="v13" data-v="13" data-xref="撒迦利亚书 12:4; 启示录 17:12–17; 士师记 7:22"> 那日，耶和华必使他们大大扰乱。他们各人彼此揪住，举手攻击。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 23:18; 撒迦利亚书 12:2; 历代志下 20:25–27"> 犹大也必在耶路撒冷争战。那时四围各国的财物，就是许多金银衣服，必被收聚。</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 14:12"> 那临到马匹、骡子、骆驼、驴，和营中一切牲畜的灾殃是与那灾殃一般。</span>
<span className="v" id="v16" data-v="16" data-xref="撒迦利亚书 14:17–19; 以赛亚书 66:23; 以赛亚书 66:18–21"> 所有来攻击耶路撒冷列国中剩下的人，必年年上来敬拜大君王—万军之耶和华，并守住棚节。</span>
<span className="v" id="v17" data-v="17" data-xref="阿摩司书 4:7–8; 以赛亚书 60:12; 耶利米书 14:4"> 地上万族中，凡不上耶路撒冷敬拜大君王—万军之耶和华的，必无雨降在他们的地上。</span>
<span className="v" id="v18" data-v="18" data-xref="撒迦利亚书 14:15; 申命记 11:10–11; 撒迦利亚书 14:12"> 埃及族若不上来，雨也不降在他们的地上；凡不上来守住棚节的列国人，耶和华也必用这灾攻击他们。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 3:19"> 这就是埃及的刑罚和那不上来守住棚节之列国的刑罚。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 3:16–17; 出埃及记 39:30; 利未记 8:9"> 当那日，马的铃铛上必有「归耶和华为圣」的这句话。耶和华殿内的锅必如祭坛前的碗一样。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结书 44:9; 罗马书 14:6–7; 哥林多前书 10:31"> 凡耶路撒冷和犹大的锅都必归万军之耶和华为圣。凡献祭的都必来取这锅，煮肉在其中。当那日，在万军之耶和华的殿中必不再有迦南人。</span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 5:7; 哥林多后书 4:18; 罗马书 8:24–25"> 我们对上帝的信，就是对所盼望之事的确定，是没有看见的事的明证。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:39; 希伯来书 11:4"> 因着这对上帝的信，古人得到了上帝的称许。</span>
<span className="v" id="v3" data-v="3" data-xref="Psalms 33:6; 彼得后书 3:5; 约翰福音 1:3"> 因着我们对上帝的信，我们明白整个宇宙是上帝命令建造的，也就是说，看得见的一切，可以看到的东西是由不能看到的东西构成的。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 12:24; Genesis 4:3–5; 约翰一书 3:11–12"> 亚伯因为相信上帝，献上了比该隐更美的祭品；借着这信心，他被上帝称许，认为他生活在正直良善之中。上帝通过接受他的献祭表明了这一点。尽管亚伯已死很久，仍然通过他的所作所为对我们说话。</span>
<span className="v" id="v5" data-v="5" data-xref="Genesis 5:21–24; 犹大书 1:14; 希伯来书 11:6"> 因为信上帝，以诺被带到天堂，让他不会死，人也找不着他，因为上帝把他带到天堂了。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="见《创世记》5:24。">a</a></sup>在发生这件事之前，他就被称为是让上帝喜悦之人。</span>
<span className="v" id="v6" data-v="6" data-xref="Proverbs 8:17; Jeremiah 29:13–14; 马太福音 6:33"> 没有信，就不能得到上帝的喜悦；因为来到上帝面前的人，必须信上帝存在，并且信他会赏赐那些寻求他的人。</span>
<span className="v" id="v7" data-v="7" data-xref="Genesis 6:13–1; 彼得前书 3:20; Ezekiel 14:14"> 诺亚信上帝，所以上帝向他警告一些之前从未发生过的事情。因为诺亚非常重视上帝的话，所以建造了一艘方舟拯救自己的家人。通过信上帝，诺亚表明世界是错的，作为奖励，上帝确认他正直良善。</span>
<span className="v" id="v8" data-v="8" data-xref="Genesis 12:1–4; 使徒行传 7:2–4; 马太福音 7:24–25"> 通过信靠上帝，当上帝呼唤亚伯拉罕去上帝将赐给他的土地时，亚伯拉罕听从了。他离开的时候，并不知道要去哪里。</span>
<span className="v" id="v9" data-v="9" data-xref="Genesis 12:8; Genesis 13:18; Genesis 13:3"> 他信上帝，住在上帝承诺之地。作为一个外族人住在帐篷里，与他分享相同承诺的以撒和雅各一起生活。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 13:14; 腓立比书 3:20; 希伯来书 12:22"> 因为他等待那座有根基的城，就是上帝所设计所建造的城。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 4:20–21; 希伯来书 10:23; Genesis 18:11–14"> 因为信，撒拉<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有些版本说亚伯拉罕。 l11:17. 当然了，以撒并非亚伯拉罕唯一的儿子。在希腊语中，这个词有“首要的”之意。">b</a></sup>虽然过了生育的年龄，还是能够怀孕，因为她认为承诺她的一切是值得信赖的。</span>
<span className="v" id="v12" data-v="12" data-xref="Genesis 22:17; Genesis 32:12; Genesis 15:5"> 这就是为什么一个几乎快死之人，竟然生出许多子孙来，仿佛天上的星那么众多，海边的沙那么无数。</span>
<span className="v" id="v13" data-v="13" data-xref="Genesis 23:4; Psalms 39:12; 希伯来书 11:27"> 他们都死了，但仍然信上帝。虽然他们没有得到上帝承诺的，但仍然在远处寻找并迎接，承认他们在这个世界上就是异族人，只是路人。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 4:18–7; 希伯来书 11:16; 希伯来书 13:14"> 说这样话的人，表明他们在寻求一个自己的国家。</span>
<span className="v" id="v15" data-v="15" data-xref="Genesis 24:6–8; Genesis 12:10; Genesis 32:9–11"> 如果他们怀念已经离开了的国家，还有可以回去的机会。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 13:14; 希伯来书 11:10; 腓立比书 3:20"> 但是现在他们所向往的，是一个更美、在天上的国家。所以上帝没有对他们失望，并且很高兴被称为他们的上帝，因为他为他们建造了一座城市。</span>
<span className="v" id="v17" data-v="17" data-xref="Genesis 22:16; Genesis 22:1–12; 雅各书 2:21–24"> 因为信，亚伯拉罕在受考验的时候，把以撒献上；这接受上帝承诺的人，仍然准备好向上帝献上了自己的独生子；<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="当然以撒不是字面上的亚伯拉罕的唯一儿子；这个词在希腊语中表示首要地位。">c</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="Genesis 21:12; 罗马书 9:7; Genesis 17:19"> 尽管曾有人告诉他：“以撒生的，才可以称为你的后裔。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="见《创世记》21:12。">d</a></sup></span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 4:17–21; 马太福音 9:28; 以弗所书 3:20"> 亚伯拉罕坚信，上帝可以让以撒死而复生。这件事在某种意义上而言确实成真了，亚伯拉罕的儿子死而复生, 形象地说。</span>
<span className="v" id="v20" data-v="20" data-xref="Genesis 27:27–40; Genesis 28:2–3"> 因为信上帝，以撒对未来将要发生的事情，祝福雅各和以扫。</span>
<span className="v" id="v21" data-v="21" data-xref="Genesis 47:31–1; Genesis 48:5–22"> 因为信上帝，雅各临死的时候，分别为约瑟的儿子祝福，并敬拜上帝，靠着他的杖。</span>
<span className="v" id="v22" data-v="22" data-xref="Exodus 13:19; Genesis 50:24–25; Joshua 24:32"> 因为信上帝，约瑟临终的时候，提到以色列子民出埃及的事，并为自己的骸骨留下遗言。</span>
<span className="v" id="v23" data-v="23" data-xref="Exodus 1:22; Exodus 1:16; 希伯来书 13:6"> 因为信上帝，摩西出生后，他的父母将他藏了三个月。他们意识到这是一个特殊的孩子，所以不害怕违背国王的命令。</span>
<span className="v" id="v24" data-v="24" data-xref="Exodus 2:10–11; 使徒行传 7:21–24"> 因为信上帝，摩西长大了以后，拒绝被称为法老女儿的儿子。</span>
<span className="v" id="v25" data-v="25" data-xref="Psalms 84:10; 提摩太后书 2:3–10; Job 36:21"> 他宁愿选择和上帝的子民一同受苦，也不肯享受罪恶中暂时的快乐。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 10:35; 希伯来书 11:6; 彼得前书 4:14"> 在他看来，为基督受的凌辱，比埃及的财富更宝贵，因为他关注未来的赏赐。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多后书 4:18; 希伯来书 11:13; 希伯来书 11:1"> 因为信上帝，他离开了埃及，不怕法老的忿怒；他坚定不移，双眼关注的就是看不到的上帝。</span>
<span className="v" id="v28" data-v="28" data-xref="Exodus 12:21–30; 希伯来书 9:19; 希伯来书 12:24"> 因为信上帝，他遵循逾越节和洒血的礼仪，以免毁灭天使触碰以色列人。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="“天使”和“以色列人”根据上下文解读。">e</a></sup></span>
<span className="v" id="v29" data-v="29" data-xref="Exodus 14:13–21; Psalms 106:9–11; Psalms 78:13"> 因为信上帝，他们走过了红海，好像走过旱地一样；埃及人也试着要过去，就被淹没了。</span>
<span className="v" id="v30" data-v="30" data-xref="Joshua 6:3–20; 哥林多后书 10:4–5"> 因为信上帝，耶利哥的城墙被围绕了七天，就倒塌了。</span>
<span className="v" id="v31" data-v="31" data-xref="雅各书 2:25; Joshua 6:22–25; 马太福音 1:5"> 因为信上帝，妓女喇合以和平方式迎接以色列的侦察之人，没有和那些不顺从之人一起灭亡。</span>
<span className="v" id="v32" data-v="32" data-xref="1 Samuel 16:1; 1 Samuel 1:20; 1 Samuel 16:13"> 我还要再说什么例子呢？如果再要述说基甸、巴拉、参孙、耶弗他、大卫、撒母耳和众先知的事，时间就不够了。</span>
<span className="v" id="v33" data-v="33" data-xref="Psalms 144:1–2; 希伯来书 6:12–15; 希伯来书 10:36"> 他们凭借对上帝的信，战胜了敌国，伸张了正义，得到了上帝承诺，堵住了狮子的口，</span>
<span className="v" id="v34" data-v="34" data-xref="2 Kings 6:16–18; 哥林多后书 12:9–10; 1 Samuel 17:51–52"> 消灭了烈火的威力，逃脱了刀剑的锋刃，软弱变成刚强，在战争中显出力量，把外国的军队击退。</span>
<span className="v" id="v35" data-v="35" data-xref="2 Kings 4:27–37; 1 Kings 17:22–24; 腓立比书 3:11"> 妇女死去的家人复活；但也有些人忍受了酷刑，不肯接受释放，为的是要得到更美的复活。</span>
<span className="v" id="v36" data-v="36" data-xref="Jeremiah 20:2; Genesis 39:20; Jeremiah 37:15–21"> 又有些人遭受了戏弄、鞭打，甚至捆锁、监禁；</span>
<span className="v" id="v37" data-v="37" data-xref="2 Chronicles 24:21; Jeremiah 26:23; 1 Kings 19:10"> 被石头打死，被切成碎片，被折磨，被刀杀死。他们穿着绵羊山羊的皮到处奔跑、受穷乏、遭患难、被虐待；</span>
<span className="v" id="v38" data-v="38" data-xref="1 Kings 18:4; 1 Samuel 22:1; 1 Kings 19:9"> 他们是这世界不配有之人，飘流无定，在荒野、山岭、石洞和地穴栖身。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 10:23–24; 希伯来书 11:13; 希伯来书 11:2"> 所有这些人都因信上帝获得许可，却还没有得着所承诺的一切；</span>
<span className="v" id="v40" data-v="40" data-xref="启示录 6:11; 希伯来书 8:6; 希伯来书 10:11–14"> 因为上帝已经为我们预备了更美的事，使他们若不跟我们在一起，就不能完全。</span>

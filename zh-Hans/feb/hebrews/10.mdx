<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="feb" data-translation-id="cmn_feb" data-translation-label="易读圣经" data-book="HEB" data-book-slug="hebrews" data-book-name="希伯来书" data-chapter="10" data-verses="39">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 8:5; 希伯来书 9:11; 歌罗西书 2:17"> 律法只是即将到来之美好的影子，并非实物本身, 所以永远无法通过年复一年的反复献祭，让那些敬拜上帝之人实现正直良善。</span>
<span className="v" id="v2" data-v="2" data-xref="Isaiah 43:25; Micah 7:19; Psalms 103:12"> 如果敬拜的人一次得洁净，良心就不再觉得有罪，那么，献祭的事不是早就停止了吗？</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 9:7; Exodus 30:10; Leviticus 23:27–28"> 可事实上，那些祭品却使人每年都想起罪来，</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 10:11; Isaiah 1:11–15; Micah 6:6–8"> 因为公牛和山羊的血不能清除罪。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="Psalms 40:6–8; Isaiah 1:11; Isaiah 7:14"> 所以，基督<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文只是简单地说“他。”耶稣所言来自9:24,9:28.">a</a></sup>到世上来的时候，会说：“祭品和礼物不是你所要的，你为我准备好身体。</span>
<span className="v" id="v6" data-v="6" data-xref="Malachi 1:10; 马太福音 3:17; Psalms 147:11"> 燔祭和赎罪祭不会让你喜悦；</span>
<span className="v" id="v7" data-v="7" data-xref="Psalms 40:7–8; 约翰福音 4:34; 约翰福音 6:38"> 那时我说：‘上帝！看啊，我来做你让我做的事情，就像经书上记载的那些关于我的事。’”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文意思“卷轴的标题”，意思是经文。引自《诗篇》40:6-8。">b</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 10:5; 马可福音 12:33"> 之前说道：“祭品和礼物，燔祭和赎罪祭，都不是你想要的，不会让你喜悦。”(尽管它们都是按照律法要求献祭的)。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 7:18–19; 希伯来书 12:27–28; 希伯来书 10:7"> 然后他又说：“看哪！我来了，是要做你想做的事情。”他废除了第一个约定，建立第二个。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 10:14; 希伯来书 10:12; 哥林多前书 6:11"> 我们通过这约定，借着耶稣基督一次献上他的身体，就已获得神圣。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="希伯来书 5:1; Numbers 28:3; 希伯来书 10:4"> 所有祭司天天事奉，反复献上同样的祭品，那些祭品永远不能清除罪。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 1:3; 歌罗西书 3:1; 罗马书 8:34"> 唯有这个祭司，进行一次永远有效的赎罪献祭，然后就在上帝的右边坐下来。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 1:13; Psalms 110:1; 路加福音 20:43"> 现在，他只需等待他的敌人被征服，让他们成为他的脚凳。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 7:25; 希伯来书 10:1; 希伯来书 9:14"> 因为他的一次献祭，就让那些圣洁之人永远成为正直良善。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 3:7; 启示录 2:11; 启示录 3:6"> 圣灵也告诉我们，他这样说：</span>
<span className="v" id="v16" data-v="16" data-xref="Jeremiah 31:33–34; 希伯来书 8:8–12; 罗马书 11:27"> “主说：‘今后，我与他们所立的约是这样的：要把我的律法放在他们的心里面，写在他们的心上。’”他又说：</span>
<span className="v" id="v17" data-v="17" data-xref="Jeremiah 31:34; 希伯来书 8:12"> “我不再记着他们的恶和不法行为。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《耶利米书》31:33-34。">c</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 10:2; 希伯来书 10:14"> 这一切被赦免后，就不需要为罪献祭了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以弗所书 2:18; 希伯来书 9:12; 希伯来书 4:16"> 所以，兄弟姐妹们，凭着耶稣的血，我们可以自信地进入至圣所。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 14:6; 约翰福音 10:9; 希伯来书 9:3"> 他通过其生死<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“他的生与死”：原意为“他的身体。”">d</a></sup>给我们开辟一条全新的、永生的道路，穿越帐幔来到上帝面前。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 2:17; 希伯来书 4:14–16; 希伯来书 8:1"> 我们有一位伟大的祭司管理上帝的家，</span>
<span className="v" id="v22" data-v="22" data-xref="Ezekiel 36:25; 约翰福音 3:5; 以弗所书 5:26"> 我们良心的邪恶既然被洒净，身体也用清水洗净了，那么，我们就应该怀着真诚的心和完备的信，走近上帝；</span>
<span className="v" id="v23" data-v="23" data-xref="帖撒罗尼迦前书 5:24; 哥林多前书 1:9; 帖撒罗尼迦后书 3:3"> 因此，让我们紧紧抓住对别人讲述的希望，不要犹豫，因为上帝的承诺值得信赖。</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦前书 5:11; 约翰一书 3:18; 希伯来书 13:1"> 让我们想想如何激励彼此，去爱，去做善事。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 2:42; 帖撒罗尼迦前书 5:11; 马太福音 18:20"> 我们不可放弃聚会，好像有些人的习惯一样；要互相劝勉。你们既然知道那日子临近<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原意为“那天。”">e</a></sup>，就更应该这样。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="彼得后书 2:20–22; 希伯来书 6:4–6; 约翰福音 9:41"> 如果我们领受了真理的知识，还是故意犯罪，就再没有留下赎罪的祭品了；</span>
<span className="v" id="v27" data-v="27" data-xref="Isaiah 26:11; 希伯来书 2:3; Zephaniah 1:18"> 剩下的只有恐惧，等待即将到来的审判，以及毁灭敌视上帝之人的可怕火焰。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 2:2; Deuteronomy 19:15; Deuteronomy 17:2–13"> 如果有人违背摩西的律法，凭着两三个证人，他仍然得不到怜悯，需要去死；</span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 6:6; 以弗所书 4:30; Isaiah 63:10"> 何况是践踏上帝之子，无视那让他圣洁的立约之血，把它当作俗物，滥用恩典之灵，你们想想，他会遭受怎样的惩罚？</span>
<span className="v" id="v30" data-v="30" data-xref="Deuteronomy 32:35–36; 罗马书 12:19; Nahum 1:2"> 我们知道上帝他说过：“我要确保正义得到伸张；我会给人们其应得的东西。”他还说：“主必审判他的子民。”<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="引自《申命记》32:35-36；《诗篇》135:14">f</a></sup></span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 10:28; 路加福音 12:5; 希伯来书 12:29"> 在永生神的大能下是很可怕的。</span>
<span className="v" id="v32" data-v="32" data-xref="希伯来书 6:4; 希伯来书 12:4; 提摩太后书 2:3–13"> 回想从前的日子，那时，你们理解了真理后<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="原意为“开悟。”">g</a></sup>，忍受了许多痛苦；</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 4:9; 腓立比书 4:14; 希伯来书 11:36"> 有时会被侮辱和攻击, 又要与那些受苦的人团结地站在一起。</span>
<span className="v" id="v34" data-v="34" data-xref="彼得前书 1:4; 提摩太后书 1:16; 马太福音 5:11–12"> 你们同情那些遭监禁的人；你们的家业被抢夺的时候，又以欢喜的心接受，因为知道自己有更美长存的家业。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="哥林多前书 15:58; 加拉太书 6:8–10; 希伯来书 3:6"> 所以，你们不可丢弃坦然无惧的心，这样的心必有丰厚赏赐。</span>
<span className="v" id="v36" data-v="36" data-xref="希伯来书 12:1; Psalms 37:7; 雅各书 5:7–11"> 你们还需要忍耐，好让你完成上帝的旨意，可以领受承诺的一切。</span>
<span className="v" id="v37" data-v="37" data-xref="雅各书 5:7–9; Habakkuk 2:3–4; 路加福音 18:8"> “还有一点点的时候，他会来，正如他所说的，不会迟延。</span>
<span className="v" id="v38" data-v="38" data-xref="加拉太书 3:11; Habakkuk 2:4; 罗马书 1:17"> 那些做正确之事的人，会因信上帝而活着；如果他们背弃承诺，他们不会让我感到满意。”<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="这引用了《以赛亚书》26:20和《哈巴谷书》2:3-4。显然，在这种情况下，承诺返回的人被视为耶稣。">h</a></sup></span>
<span className="v" id="v39" data-v="39" data-xref="约翰一书 5:5; 彼得前书 1:5; 马可福音 16:16"> 但我们不是那种退缩并最终迷失的人， 而是那些相信上帝会拯救我们的人。</span>
</div>
</div>

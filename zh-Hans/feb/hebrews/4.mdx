<span className="v" id="v1" data-v="1" data-xref="希伯来书 12:15; 希伯来书 4:9; Proverbs 28:14"> 尽管上帝给了我们进入其安息的承诺，我们就应该小心翼翼，任何人都不要错过了！</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦前书 2:13; 罗马书 10:16–17; 希伯来书 11:6"> 因为我们就像他们一样也听到了福音，只是他们不接受也不相信听见的道，所以对他们没有益处。</span>
<span className="v" id="v3" data-v="3" data-xref="Psalms 95:11; 马太福音 11:28–29; 彼得前书 1:20"> 但我们相信上帝之人已经进入安息。正如上帝所说：“我在沮丧中起誓，‘他们绝不可进入我的安息。’”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《诗篇》95:11。">a</a></sup>（尽管上帝在创立世界的那一刻就已完成其计划，但仍然如此。）</span>
<span className="v" id="v4" data-v="4" data-xref="Exodus 20:11; Exodus 31:17; Genesis 2:1–2"> 关于第七日，在经书中有一句说到：“在第七日，上帝停下了他的一切工作。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引自《创世纪》2:2.">b</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="Psalms 95:11; 希伯来书 4:3; 希伯来书 3:11"> 但前文还有一句说：“他们绝不可进入我的安息。”</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 21:43; 希伯来书 3:18–19; 使徒行传 13:46–47"> 上帝的安息仍在那里，有的人可以进去，尽管那些先前听到好消息的人因为不顺从而没有进入。；</span>
<span className="v" id="v7" data-v="7" data-xref="Psalms 95:7; 希伯来书 3:7–8; 希伯来书 3:15"> 过了很久以后，就像他之前所做的那样，上帝通过大卫所说的“今天”再次定了一个日子：“如果你们今天听从他的声音，就不要铁石心肠。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《诗篇》95:7。">c</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="Joshua 1:15; Joshua 22:4; Deuteronomy 12:9"> 如果约书亚已让他们享受了安息，上帝后来就不会再提到其他日子。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 2:10; 启示录 21:4; 启示录 7:14–17"> 所以，为了上帝的子民，必定会有一个安息日的休息。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 14:13; 希伯来书 4:3–4; 彼得前书 4:1–2"> 因为进入上帝安息之人也歇了自己的工作，好像上帝歇了自己的工作一样。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 11:28–30; 路加福音 13:24; 希伯来书 3:18–1"> 所以，我们应全力进入安息，免得有人因按照那不顺从的例子而跌落。</span>
<span className="v" id="v12" data-v="12" data-xref="Jeremiah 23:29; Isaiah 55:11; 以弗所书 6:17"> 因为上帝之道是活的，是有效的，比一切两刃剑更锋利，甚至可以刺入并剖开生命和呼吸，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="希腊语“psuche”和“pneuma”，有时被译为“灵魂”和“灵。”但很难准确理解其含义，因为一般认为“灵魂”和“灵”没有区别。这里选择“生命”和“呼吸”的理解，被认为更好地表达了原始思想。">d</a></sup>关节与骨髓，能够审判心中的思想和意念。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 4:5; Psalms 33:13–15; Proverbs 15:3"> 一切生命在上帝面前都无处遁形。我们对他负有责任，一切在他面前都暴露在外，完全显露。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 9:24; 希伯来书 12:2; 希伯来书 9:12"> 我们既然有一位升入天堂的伟大祭司，也就是就是上帝之子耶稣，就应该确定和坚持我们的信仰。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 2:17–18; 哥林多后书 5:21; Isaiah 53:4–5"> 因为大祭司并非不同情我们的软弱，他像我们一样，也曾在各方面受过试探，只是他没有犯罪。</span>
<span className="v" id="v16" data-v="16" data-xref="以弗所书 3:12; 希伯来书 7:25; 希伯来书 10:19–23"> 所以，我们只需自信地来到上帝的恩典宝座面前，在我们真正需要帮助时获得怜悯，得到恩典。</span>

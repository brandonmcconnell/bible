<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="feb" data-translation-id="cmn_feb" data-translation-label="易读圣经" data-book="HEB" data-book-slug="hebrews" data-book-name="希伯来书" data-chapter="12" data-verses="29">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太后书 4:7; 哥林多前书 9:24–27; 腓立比书 2:16"> 正因如此，既然我们身边有这么多人证明了他们对上帝的信任，让我们摆脱一切阻碍我们的东西，让我们摆脱诱惑的罪恶，让我们继续在眼前的道路上奔跑。</span>
<span className="v" id="v2" data-v="2" data-xref="Micah 7:7; 彼得前书 3:18; 彼得前书 2:23–24"> 我们应该继续仰望耶稣，他开始并完成了我们对上帝之信。因着他面前的喜乐，耶稣不顾耻辱背负十字架，最终坐在上帝宝座的右边。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 6:9; 哥林多后书 4:16; 启示录 2:3"> 这位忍受罪人那样顶撞的耶稣，你们要仔细思想，免得疲倦灰心。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 10:13; 启示录 2:13; 希伯来书 10:32–34"> 你们与罪恶斗争，还没有对抗到流血的地步；</span>
<span className="v" id="v5" data-v="5" data-xref="Proverbs 3:11–12; Job 5:17–18; 启示录 3:19"> 你们可曾忘记<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或者“你忘记了。”">a</a></sup>上帝好像劝自己孩子的话，说：“我的孩子！不可轻看主的管教，受责备的时候也不要灰心；</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 3:19; Proverbs 3:12; Psalms 119:75"> 因为主只管教爱的人，会惩罚他的每一个儿子。”</span>
<span className="v" id="v7" data-v="7" data-xref="Proverbs 19:18; Deuteronomy 8:5; Proverbs 13:24"> 受到上帝的管教时要有耐心，因为他把你当作他的孩子。哪个孩子没有经历过父亲的管教？</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 12:6; 彼得前书 5:9–10; Psalms 73:1"> 作儿子的都受过管教。如果你们没有受管教，就是私生子，不是儿子了。</span>
<span className="v" id="v9" data-v="9" data-xref="Numbers 16:22; Numbers 27:16; Isaiah 42:5"> 因为如果我们尊重管教我们的人间父亲，不是更应该接受那引领至生命的灵之父管教吗？</span>
<span className="v" id="v10" data-v="10" data-xref="彼得后书 1:4; Leviticus 11:44–45; 提多书 2:14"> 他们按自己认为合适的方式管教我们一段时间，但上帝这样做是为了我们的利益，让我们可以分享他的圣洁品格。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 5:3–5; 哥林多后书 4:17; 希伯来书 12:5–6"> 被管教时，所有的纪律似乎都就很痛苦，而不值得高兴。但后来，这些管教让那些经历之人产生平安，这样他们就可以做善事和正确的事。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="Isaiah 35:3; 希伯来书 12:3; 帖撒罗尼迦前书 5:14"> 所以，把下垂的手和发软的膝盖挺直起来；<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引自《以赛亚书》35:3。">b</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="Proverbs 4:26–27; Isaiah 35:3; 加拉太书 6:1"> 要把你们的道路修直<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《箴言》4:26。">c</a></sup>，让瘸子不会扭脚，而是得到复原。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 7:1; 彼得前书 1:15–16; 帖撒罗尼迦前书 4:7"> 你们要竭力寻求与众人和睦，并且要竭力追求圣洁。如果没有圣洁，谁也不能见主。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 3:12; Deuteronomy 29:18; 加拉太书 5:4"> 你们要小心，免得有人失去了上帝的恩典；免得苦之因<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="见《申命记》29:18.">d</a></sup>长起来缠绕你们，污染众人；</span>
<span className="v" id="v16" data-v="16" data-xref="Genesis 25:31–34; 哥林多前书 6:15–20; 启示录 22:15"> 确保没有人像以扫那样淫乱或不信教，为了一顿饭卖掉了与生俱来的权利。</span>
<span className="v" id="v17" data-v="17" data-xref="Proverbs 1:24–31; 马太福音 25:11–12; 马太福音 7:23"> 你们记得，后来以扫想要承受祝福，却被拒绝了；他虽然带着眼泪寻求，还是无法改变他所做的。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="Deuteronomy 4:11; Exodus 24:17; Exodus 20:18"> 你们还未来到那座可以触摸的、实在的山<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="显然，这里可以猜出是西奈山。">e</a></sup>。那里有烈火、密云、幽暗、暴风、</span>
<span className="v" id="v19" data-v="19" data-xref="Deuteronomy 18:16; 哥林多前书 15:52; Deuteronomy 4:12"> 号筒的响声和说话的声音；那些听见这声音的人，都请求上帝不要再向他们多说话；</span>
<span className="v" id="v20" data-v="20" data-xref="Exodus 19:12–13; Exodus 19:16; 加拉太书 3:10"> 因为他们承受不起那命令：“即使走兽挨近这山，也要用石头把它打死。”<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="引自《出埃及记》19:12-13">f</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="Exodus 19:16; Deuteronomy 9:19; Isaiah 6:3–5"> 当时显出的景象是那么可怕，连摩西都说：“我非常恐惧战兢。”<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="引自《申命记》9:19。">g</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="加拉太书 4:26; 腓立比书 3:20; 启示录 14:1"> 但你们却来到锡安山和永恒上帝的城，就是天上的耶路撒冷；在那里有千万的天使聚集，</span>
<span className="v" id="v23" data-v="23" data-xref="雅各书 1:18; 希伯来书 11:40; 路加福音 10:20"> 你来到了名字登记在天堂的长子教会，来到了审判所有人的上帝面前，以及那些有着完整生命的良善之人面前。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 9:15; 希伯来书 11:28; 希伯来书 11:4"> 你已经来到建立新约定关系的中间人耶稣面前，还有他所洒的血。这血的意义比亚伯的血更大。<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="可能意味着耶稣以宽恕之灵洒下血，而在第一次谋杀的事件中，上帝以亚伯的血呼唤复仇。">h</a></sup></span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 8:5; Deuteronomy 30:17; 希伯来书 2:1–3"> 不要拒绝那说话之人。如果他们因在人间拒绝上帝而无法逃走，可以肯定的是，如果我们背离从天上警告我们的神，我们也逃不掉！</span>
<span className="v" id="v26" data-v="26" data-xref="Haggai 2:6–7; Isaiah 13:13; Exodus 19:18"> 当时上帝的声音震动了大地；现在他承诺说：“我要再一次震动地，还要震动天。”<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="引自《哈该书》2:6。">i</a></sup></span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 7:31; 马太福音 24:35; 彼得后书 3:10–11"> “再一次”表明那些被震动的一切，就会向被造之物一样被清除，让那些不被震动的一切可以留存，</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="罗马书 12:1–2; 希伯来书 13:15; Daniel 2:44"> 因此，我们既然获得了不能震动的国，就应该感恩，按照让上帝喜悦的方式，用虔诚敬畏的心事奉他；</span>
<span className="v" id="v29" data-v="29" data-xref="Deuteronomy 4:24; Deuteronomy 9:3; 希伯来书 10:27"> 因为我们的上帝就是毁灭的烈火。<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="引自《申命记》4:24。">j</a></sup></span>
</div>
</div>

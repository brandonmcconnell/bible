<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 8:15; 彼得后书 1:12–13; Proverbs 7:1–2"> 因此，我们必须更密切地关注我们学到的一切，免得我们远离它们。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 7:53; 加拉太书 3:19; 希伯来书 10:28"> 如果天使所传递的信息都是值得相信的，那么所有罪行和不服从之举，就会得到应得的结果。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“获得其回报。”">a</a></sup></span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 10:28–29; 希伯来书 12:25; 希伯来书 5:9"> 如果我们忽略如此伟大的救赎，怎么又能逃罪呢？这救赎最初由主亲自宣讲，后来听见它的人又向我们证实。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 14:3; 以弗所书 1:5; 马可福音 16:20"> 上帝又按照自己的选择，用神迹、奇事和各种异能以及圣灵之礼，作为见证。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 11:15; 彼得后书 3:13; 希伯来书 6:5"> 上帝并没有把我们所说“即将到来的世界”，交给天使管理；</span>
<span className="v" id="v6" data-v="6" data-xref="Psalms 8:4–8; Psalms 144:3; Job 7:17–18"> 但经文中说道：“人算甚么，你竟担心他们？人之子<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“人之子”：在常规说法中指的只是一个人类；但耶稣将这个通用术语用于他自己。">b</a></sup>算甚么，你竟关心他？</span>
<span className="v" id="v7" data-v="7" data-xref="Psalms 8:5; 腓立比书 2:6–7"> 你让他比天使卑微一点；你赐给他荣耀尊贵, 将他置于万物之上。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="这里不只是指人性，也可以指耶稣：“你暂时让他低于天使，然后又赐予他荣耀和尊贵。”整段经文可以用这种双向方式来理解：将耶稣称为人之子，既是人类的代表，也是人类的救主。">c</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 13:3; 哥林多前书 15:27; Psalms 8:6"> 你让他拥有统治一切的权利。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="这同样适用于人类，即《创世记》1所述上帝赋予高于万物的权力，或者适用于耶稣作为主的权力。">d</a></sup>上帝给了他统治万物的权利，就没有什么高于他了。然而，我们看到，并不是所有的东西都受制于他的权威，还不是。</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比书 2:7–9; 启示录 5:9; 约翰一书 4:9–10"> 但我们看到耶稣，有一段时间被置于比天使低一点的位置，通过遭受死亡的痛苦，获得荣耀尊贵的冠冕。通过上帝的恩典，耶稣为众人体验死亡。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 11:36; 使徒行传 5:31; 路加福音 24:46"> 那创造和保持一切的上帝，应该为他的很多儿子带来荣耀。引导人们获得救赎的耶稣是通过苦难完全准备好的。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 10:10; 希伯来书 13:12; 希伯来书 10:14"> 因为那让人变得神圣之人，以及那些变得神圣之人，都是一家人。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原意为“全部来自一个。”">e</a></sup>所以他会毫不犹豫地称他们为兄弟。</span>
<span className="v" id="v12" data-v="12" data-xref="Psalms 22:22; Psalms 40:10; 约翰福音 18:20"> 他说：“我要向他们宣扬你的名，我要在他们的聚会中赞美你。”<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="“聚会”：这个词是“ecclesia”，这里所指为“教会。”这段话引自《诗篇》22:22。">f</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="Isaiah 8:17–18; Isaiah 12:2; Psalms 91:2"> 又说：“我要信任他。”；还说：“我来了，与上帝赐给我的孩子们一起。”<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="引自《以赛亚书》8:17-18。">g</a></sup></span>
<span className="v" id="v14" data-v="14" data-xref="提摩太后书 1:10; 罗马书 8:3; 歌罗西书 2:15"> 因为孩子们都有血肉之躯，他自己也同样拥有血肉之躯，这样就可以通过死亡，消灭那掌控死亡权力的魔鬼，</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 8:15; 提摩太后书 1:7; 路加福音 1:74–75"> 释放那些因为怕死而终身为奴仆之人。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太书 3:29; 加拉太书 3:16; 罗马书 4:16–25"> 当然，他关心的并不是天使，他只关心亚伯拉罕的子孙。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 4:14–2; 腓立比书 2:7–8; 希伯来书 2:14"> 所以他必须在各方面与其兄弟们相同，这样就可以在上帝的事情中，成为仁慈忠信的大祭司，原谅其子民的罪。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 10:13; 希伯来书 4:15–16; 犹大书 1:24"> 因为他自己已在试探中遭受苦难，能够帮助那些被试探的人。</span>

<span className="v" id="v1" data-v="1" data-xref="希伯来书 8:3; 希伯来书 10:11; 希伯来书 7:27"> 每位大祭司都从人间挑选出来，受指派为上帝有关之人做事。他会向上帝献上他们的礼物和赎罪的祭物。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 4:15; 希伯来书 2:18; 哥林多后书 12:9–10"> 大祭司理解那些无知和迷途之人的感受，因为他自己也曾体验那人类的软弱。</span>
<span className="v" id="v3" data-v="3" data-xref="Leviticus 9:7; 希伯来书 9:7; Leviticus 16:6"> 因此，他必须为其罪献祭，为人们的罪献祭。</span>
<span className="v" id="v4" data-v="4" data-xref="Exodus 28:1; Numbers 16:40; Numbers 16:5"> 没有人能为自己获得大祭司的地位，只有像亚伦一样被上帝选中才可以。</span>
<span className="v" id="v5" data-v="5" data-xref="Psalms 2:7; 约翰福音 8:54; 使徒行传 13:33"> 照样，基督也没有因成为大祭司而为荣。是哪——上帝曾对他说“你是我的儿子。今天我已成为你的父亲。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《诗篇》2：7">a</a></sup></span>
<span className="v" id="v6" data-v="6" data-xref="Psalms 110:4; 希伯来书 7:17; 希伯来书 7:21"> 在另一处经文中，上帝说：“你是照着麦基洗德的等次永远为祭司。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引自《诗篇》110：4">b</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 14:32–39; 路加福音 22:41–44; 约翰福音 17:1"> 基督还以人形存在之时，曾经流泪大声祷告，恳求那能救他脱离死亡的上帝。因他对上帝的尊敬，上帝听到了他的祈祷。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比书 2:8; 希伯来书 10:5–9; 约翰福音 4:34"> 尽管他是上帝之子，耶稣还是通过苦难学会了何为顺从。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="耶稣“通过苦难学会顺从”，这样的字面翻译，可能会显示耶稣最初并不顺从，或者为了让他学习而必须受苦。但对于先于人类存在的上帝之子而言，这两种说法都比较不恰当。这段文字的意思可能是：尽管耶稣是上帝之子，但他在人间的经历证明了顺服需要付出什么，可以得到什么。从某种成都将，就像耶稣请求将苦难之杯从他这里拿走。但随后他的意志臣服并遵从了天父。见《马太福音》26:39。">c</a></sup></span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 2:10; 希伯来书 9:12; 希伯来书 9:15"> 他结束了自己的经历后，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="不要使用“已经变得完美”这种表达，这会让有的人认为：这句话表明他一开始并不完美。">d</a></sup>就成了所有顺从他之人获得永恒救赎的根源。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 5:5–6; 希伯来书 6:20"> 他被上帝指定为按照麦基洗德的次序担任大祭司。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 13:15; 使徒行传 28:27; 彼得后书 3:16"> 说道耶稣，我们有很多话要说，这很难解释，因为你们似乎无法理解。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 6:1; 哥林多前书 3:1–3; 彼得前书 2:2"> 到现在，你们应该已有足够的时间去成为老师了，但还需要别人教你们基本信息，那些都是上帝之道的基本道理。你们似乎变成只能吃奶、无法吃干粮的人！</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 14:20; 彼得前书 2:2; 提摩太后书 3:16"> 凡吃奶的都还是个婴孩，没有经历过正义良善之路；</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 2:14–15; 帖撒罗尼迦前书 5:21; 以弗所书 1:18"> 只有长大成人才能吃干粮，始终使用其大脑学到的东西分辨是非。</span>

<li id="fn-d"><a href="#fnref-d" className="fnb">d</a> <span className="fnr">5:9</span> 不要使用“已经变得完美”这种表达，这会让有的人认为：这句话表明他一开始并不完美。</li>

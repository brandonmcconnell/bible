<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰一书 4:20–1; 彼得前书 3:8; 彼得前书 1:22"> 愿兄弟姐妹之间的爱永远保持！</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 25:35; Genesis 18:1–3; 彼得前书 4:9"> 不要忘记对陌生人也表达爱意，因为这样做，有些人就会在不知不觉间迎来了天使。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 25:36; 希伯来书 10:34; 罗马书 12:15"> 记住那些被关在监狱里的人，就像你和他们一起关在里面一样。记住那些被虐待的人，就像你和他们一起遭受肉体的痛苦。</span>
<span className="v" id="v4" data-v="4" data-xref="Genesis 2:24; Proverbs 5:15–23; 加拉太书 5:19"> 人人都应该尊重婚姻，丈夫和妻子应该彼此忠诚。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“床没有玷污。”">a</a></sup>上帝会审判淫乱之人。</span>
<span className="v" id="v5" data-v="5" data-xref="Deuteronomy 31:8; Joshua 1:5; Deuteronomy 31:6"> 不要贪钱；满足于自己所拥有的。 上帝自己说过：“我永远不会让你们失望；我永远不会放弃你们。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引自《申命记》31:6-8；《约书亚记》1:5。">b</a></sup></span>
<span className="v" id="v6" data-v="6" data-xref="Psalms 118:6–9; Isaiah 41:10; 罗马书 8:31"> 所以我们可以自信地说：“主来帮助我，我决不害怕，别人能把我怎么样呢？”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《诗篇》118:6。">c</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="帖撒罗尼迦前书 5:12–13; 希伯来书 13:17; 腓立比书 3:17"> 记住那些向你解释上帝之道的领导者。再看看他们生命得到了，要效法他们对上帝的信任。</span>
<span className="v" id="v8" data-v="8" data-xref="Malachi 3:6; 雅各书 1:17; 启示录 1:8"> 耶稣基督昨天、今天、一直到永远都是一样的。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 4:14; 提摩太前书 6:3–5; 以弗所书 5:6"> 不要被各种奇怪教义分心。心要被恩典说服，这样才是好的，不要被那些告诉我们吃什么的律法说服。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="这里的词只是“食物”，但下面的内容表明，是指礼仪律法和允许吃的食物。">d</a></sup>遵守这些法律之人，不会得到任何好处。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 5:7–8; 哥林多前书 10:20; 哥林多前书 9:13"> 我们有一座祭坛，坛上的祭物，礼拜堂中的祭祀没有权利食用。</span>
<span className="v" id="v11" data-v="11" data-xref="Leviticus 16:27; Exodus 29:14; Leviticus 9:11"> 那些祭牲的血，由大祭司带进圣幕进行赎罪献祭，祭牲的身体却要在营地外焚烧。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 9:12–14; 约翰福音 19:17–18; 使徒行传 7:58"> 耶稣同样也死在城门外，用自己的血让上帝的子民成变得圣洁。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 11:26; 彼得前书 4:14–16; 使徒行传 5:41"> 那么，让我们也出到城外他那里去，受他曾受过的凌辱。</span>
<span className="v" id="v14" data-v="14" data-xref="腓立比书 3:20; 歌罗西书 3:1–3; 希伯来书 11:12–16"> 因为在这里我们没有永远的城，我们却是寻求那将要来的城。</span>
<span className="v" id="v15" data-v="15" data-xref="Psalms 107:21–22; Psalms 50:14; 罗马书 12:1"> 所以我们常常要借着耶稣，把颂赞的祭品献给上帝，这意味着说上帝的善语，宣扬他的品格。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原意为“姓名”，通常指所描述之人的性质和性格。这里的英语表达的是“拥有一个好名字”，即品性。">e</a></sup></span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦后书 3:13; 加拉太书 6:10; 罗马书 12:13"> 别忘记行善，与其他人分享你拥有的，因为这样的献祭会让上帝喜悦。</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦前书 5:12–13; 提摩太前书 5:17; 希伯来书 13:7"> 遵从你的领导，按照他们的吩咐去做，因为他们关心你并为你负责。通过这种方式行事，让他们可以快乐——而不是悲伤地做这件事，因为这对你没有帮助！</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 5:25; 帖撒罗尼迦后书 3:1; 歌罗西书 4:3"> 请为我们祷告，因为我们深信自己良心无愧，愿意凡事遵行正道。</span>
<span className="v" id="v19" data-v="19" data-xref="腓利门书 1:22; 罗马书 1:10–12; 罗马书 15:31–32"> 我真的希望你们为我们努力祷告，好使我们能够尽快看到你们。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 10:11; 希伯来书 10:22; Psalms 23:1"> 那赐平安的上帝，是他用永恒约定的血让我们的伟大牧羊人、主耶稣死而复生。</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比书 2:13; 帖撒罗尼迦后书 2:17; 腓立比书 4:13"> 愿上帝为你们带来一切美好的东西，让你们可以遵行他的旨意。愿他与我们同在，通过耶稣基督，一起做他喜欢的一切，愿荣耀归于他，直到永远。阿门。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 3:1; 彼得前书 5:12; 哥林多后书 6:1"> 兄弟姐妹们，建议你们关注我在这封短信中所说的一切。</span>
<span className="v" id="v23" data-v="23" data-xref="腓利门书 1:1; 帖撒罗尼迦前书 3:2; 提摩太后书 1:8"> 你们要知道，我们的兄弟提摩太已经释放了；如果他来得早，我就跟他一起去看你们。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 13:7; 希伯来书 13:17; 使徒行传 18:2"> 请问候你们的所有领导和所有信徒。在意大利的信徒来也问候你们。</span>
<span className="v" id="v25" data-v="25" data-xref="歌罗西书 4:18; 提摩太后书 4:22; 提多书 3:15"> 愿恩惠与你们同在。阿门。</span>
</div>

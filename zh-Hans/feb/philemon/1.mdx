<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 1:1; 以弗所书 3:1; 腓利门书 1:9"> 这封信来自基督耶稣的囚徒保罗以及我们的提摩太兄弟，写给我们的好朋友和工友腓利门</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比书 2:25; 歌罗西书 4:17; 罗马书 16:5"> 以及我们姐妹亚腓亚，此外，还写给与我们并肩战斗的亚基布以及在你家中的教会。</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 1:7; 以弗所书 1:2; 哥林多后书 13:14"> 愿你们获得来自天父上帝和主耶稣基督的恩典和平安。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="罗马书 1:8; 以弗所书 1:16; 帖撒罗尼迦后书 1:3"> 我在祷告的时候始终会记得你们，因为你们而感谢我的上帝，</span>
<span className="v" id="v5" data-v="5" data-xref="歌罗西书 1:4; 以弗所书 1:15; 哥林多前书 16:1"> 因为我听说了你们对主耶稣的信以及对众信徒的爱。</span>
<span className="v" id="v6" data-v="6" data-xref="腓立比书 1:9–11; 彼得后书 1:8; 歌罗西书 1:9"> 当你们意识到我们从基督那里分享的所有美好事物，我祈祷你们将对上帝的满怀信任付诸行动。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 7:13; 帖撒罗尼迦前书 3:9; 哥林多后书 7:4"> 我亲爱的兄弟，你的爱带给我更多的欢喜和安慰。你激励了我们所有这些有信仰的人。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦前书 2:6; 哥林多后书 10:8; 哥林多后书 3:12"> 所以，尽管我因信基督而斗胆吩咐你履行职责，</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 5:20; 以弗所书 4:1; 罗马书 12:1"> 但我宁愿因爱而请你们提供帮助。我已经老了，现在又成为基督耶稣的囚徒，</span>
<span className="v" id="v10" data-v="10" data-xref="歌罗西书 4:9; 哥林多前书 4:15; 提摩太前书 1:2"> 现在为我在囚禁时成为我养子的欧尼西慕求你。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太后书 4:11; Job 30:1–2; 彼得前书 2:10"> 他从前对你并无用处，但现在对你我却都有用处。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 6:14–15; Jeremiah 31:20; 马可福音 11:25"> 我现以我最诚挚的愿望，派他到你那里。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“发自内心的感情。”">a</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="腓立比书 1:7; 以弗所书 3:1; 哥林多前书 16:17"> 我宁愿把他留在这里和我一起，这样他就可以在我因为讲述这个好消息而被关在枷锁里的时候代表你帮助我。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 9:7; 1 Chronicles 29:17; 彼得前书 5:2–3"> 但没得到你的同意，我决定什么也不做，不想让你们感觉被迫做好事，并非自愿这样做。</span>
<span className="v" id="v15" data-v="15" data-xref="Genesis 50:20; Genesis 45:5–8; Isaiah 20:6"> 也许你暂时失去了他，这样你就可以永远拥有他了！</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 3:22; 马太福音 23:8; 哥林多前书 7:22"> 不再是奴隶，而是高于奴隶。他是被特别爱护的兄弟。对我尤其如此，对你甚至更是如此，不论作为一个人还是相信主的信徒，都是如此。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“在肉体里，在主身体中。”">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 8:23; 马太福音 10:40; 腓利门书 1:12"> 所以，你们要是把我看作与你一起为上帝工作的同伴，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“一位与你一起为主工作的同事。”这个词在希腊语中是“伙伴”，但由于是现代用法，因此需要解释。">c</a></sup>就像迎接我一样迎接他。</span>
<span className="v" id="v18" data-v="18" data-xref="Isaiah 53:4–7"> 如果他做了什么错事或欠了你什么，都算在我头上。</span>
<span className="v" id="v19" data-v="19" data-xref="加拉太书 6:11; 加拉太书 5:2; 哥林多前书 4:15"> 我保罗亲自在这里写下：我必偿还。当然我不会提到你欠我什么，包括你的生命。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰三书 1:4; 腓利门书 1:7; 腓利门书 1:12"> 是的，兄弟啊！让我在主那里获得你的帮助；请让我以在基督中感到幸福。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="帖撒罗尼迦后书 3:4; 哥林多后书 2:3; 哥林多后书 7:16"> 我深信你会做我求你的事情——事实上，我知道你所做的将会超过我所说的，因此才写信给你。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多后书 1:11; 腓立比书 2:24; 约翰二书 1:12"> 同时，还请你为我准备一个房间，因为我希望能借着你们的祷告，可以获得释放到你们那里去。</span>
<span className="v" id="v23" data-v="23" data-xref="歌罗西书 1:7; 罗马书 16:7; 歌罗西书 4:12"> 以基督耶稣的缘故和我一同坐牢的以巴弗，</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太后书 4:10–11; 歌罗西书 4:14; 歌罗西书 4:10"> 以及我的共有马可、亚里达古、底马、路加都在问候你。</span>
<span className="v" id="v25" data-v="25" data-xref="提摩太后书 4:22; 罗马书 16:23; 罗马书 16:20"> 愿我们主耶稣基督的恩典与你们众人同在。</span>
</div>

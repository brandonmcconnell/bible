<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 1:2; 哥林多后书 1:1; 哥林多前书 1:1–2"> 这封信来自按照上帝旨意成为基督耶稣使徒的保罗，写给以弗所的基督徒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“圣人。”">a</a></sup>以及相信基督耶稣之人。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 1:7; 加拉太书 1:3; 提多书 1:4"> 愿你们获得来自我们父亲上帝以及主耶稣基督的恩惠与平安。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得前书 1:3; 哥林多后书 1:3; 以弗所书 2:6"> 赞美上帝，即我们主耶稣基督之父，他通过基督将天堂世界中的灵性善意赐予我们，</span>
<span className="v" id="v4" data-v="4" data-xref="提摩太后书 1:9; 罗马书 8:28–30; 以弗所书 2:10"> 他在创世前拣选我们与他同在<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或“与他联合。”">b</a></sup>，让我们可以在爱中成为神圣，在他面前没有过错。</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 8:29–30; 以弗所书 1:11; 加拉太书 4:5–6"> 他事先决定收养我们作为他的孩子，通过耶稣基督将我们带到他身边。他很高兴这样做，因为这就是他希望做的。</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 3:22–26; 以弗所书 1:12; 歌罗西书 1:13"> 因此我们赞美他的荣耀恩典，他通过其爱子如此仁慈地赐给我们。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="这里的儿子是个假设说法，希腊语为“亲爱的。”">c</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="彼得前书 2:24; 罗马书 3:24; 约翰一书 1:7–9"> 我们通过他的血获得救赎，通过他慷慨提供给我们的无价恩典</span>
<span className="v" id="v8" data-v="8" data-xref="启示录 5:12; 以弗所书 3:10; 罗马书 5:15"> 以及所有的智慧和理解，赦免了我们的罪。</span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 1:26–28; 罗马书 16:25–27; 以弗所书 3:3–9"> 他向我们显示了他之前隐藏的意志，他愿意在恰当的时间实行他的计划，</span>
<span className="v" id="v10" data-v="10" data-xref="歌罗西书 1:20; 腓立比书 2:9–10; 加拉太书 4:4"> 以基督聚集所有人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="又见《罗西书》1:20。">d</a></sup>，包括天上的人和地上的人。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 8:28; 彼得前书 1:4; Isaiah 46:10–11"> 通过他——我们被提前拣选出来。制定这计划之人，是根据上帝的意愿完成一切工作，</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 1:6; Jeremiah 17:5–7; 以弗所书 1:13–14"> 这样做的目的，是为了让我们<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="“我们”的意思是犹太基督徒。">e</a></sup>这些最先对基督翘首以盼之人，能够赞美他的荣耀。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 1:22; 以弗所书 4:30; 提摩太后书 2:19"> 通过他——你<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="“你”是指异族基督徒。">f</a></sup>还听到了真理之语，这是你们获得拯救的福音。通过他——因为你信任他，你就被烙上了圣灵承诺的印记，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 1:22; 哥林多后书 5:5; 以弗所书 4:30"> 这是我们得到的第一笔继承，上帝在拿走那些为了自己——也为了我们保存完好的一切时, 会将这遗产交给我们，我们会赞美他，颂扬他的荣耀！</span>
<span className="v" id="v15" data-v="15" data-xref="腓利门书 1:5; 歌罗西书 1:3–4; 帖撒罗尼迦后书 1:3"> 我听说过你们对主耶稣的信任，以及你们对所有基督徒的爱，这就是原因。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 1:8–9; 歌罗西书 1:9; 歌罗西书 1:3"> 我从未停止为你感谢上帝，在我的祈祷中记住你。</span>
<span className="v" id="v17" data-v="17" data-xref="Isaiah 11:2; 雅各书 3:17–18; 歌罗西书 1:9–10"> 我祈求我主耶稣基督的上帝，荣耀的父，赐给你们智慧的灵，让你们看到并认识他真实的样子。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 26:18; 哥林多后书 4:6; 路加福音 24:45"> 愿你的心获得启迪，这样就能明白他召唤你们去拥有的希望——他承诺将这这些荣耀富有，交给他的神圣子民作为遗产。</span>
<span className="v" id="v19" data-v="19" data-xref="腓立比书 2:13; 以弗所书 3:20; 歌罗西书 2:12"> 愿你们也理解上帝在让基督</span>
<span className="v" id="v20" data-v="20" data-xref="希伯来书 10:12; 马可福音 16:19; Psalms 110:1"> 死而复生所展现的惊人能力。上帝在天上将基督安置在他的右手边，</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比书 2:9–11; 歌罗西书 2:10; 歌罗西书 1:15–16"> 其地位远高于任何统治者、权威或领袖，或任何拥有头衔的领导者——不仅在现世，在来世也是如此。</span>
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 1:18; 歌罗西书 2:10; 哥林多前书 15:25–27"> 上帝让万物服从于基督，授予他作为在教会中掌管一切的责任，</span>
<span className="v" id="v23" data-v="23" data-xref="歌罗西书 1:18–19; 约翰福音 1:16; 歌罗西书 2:9–10"> 教会就是基督的身体，是基督为带来一切并实现圆满。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 1:10; 腓立比书 1:27; 帖撒罗尼迦前书 2:12"> 所以我——作为主的囚徒——鼓励你们按照蒙受召唤所遵守的原则生活。</span>
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 3:12–13; 哥林多前书 13:7; 哥林多前书 13:4–5"> 不要为自己而自豪，要温柔且有耐心，通过爱表达对彼此的宽容。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 1:10; 歌罗西书 3:13–15; 哥林多前书 12:12–13"> 通过将你们联系在一起的平安，尽其所能在灵里合而为一。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 2:18; 罗马书 12:4–5; 哥林多前书 12:4–13"> 因为只有一个身体，一个灵魂，正如你们被一个希望所召唤。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 8:6; 哥林多前书 12:13; 彼得前书 3:21"> 主是唯一，我们对他的信任是唯一，洗礼也是唯一；</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 11:36; Malachi 2:10; 哥林多前书 8:6"> 只有一个上帝，他是每个人的父亲。他在一切之上，通过一切，在一切之中。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="彼得前书 4:10; 罗马书 12:3; 哥林多前书 12:7–11"> 我们每个人所获得的恩典，都与基督的慷慨馈赠成正比。</span>
<span className="v" id="v8" data-v="8" data-xref="Psalms 68:18; 歌罗西书 2:15; 1 Samuel 30:26"> 正如经文所说，“当他登上高处，带走了俘虏，将礼物送给了人类。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《诗篇》68:18。">a</a></sup></span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 3:13; 马太福音 12:40; Proverbs 30:4"> （关于这一点：它说他已经上升，但这也意味着他之前曾降临我们这个卑微的世界。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 7:26; 希伯来书 4:14; 以弗所书 1:20–23"> 那降临之人也是升至最高天堂之人，他通过这种方式让整个宇宙变得完整。）</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="Jeremiah 3:15; 哥林多前书 12:28–29; 以弗所书 2:20"> 他所给予的恩赐，让有的人可以成为使徒、先知、福音传递者、牧师和教师，</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦前书 5:11–14; 以弗所书 4:16; 哥林多前书 12:27"> 这样做是为了让上帝的子民准备好帮助他人，帮助基督之躯的成长。</span>
<span className="v" id="v13" data-v="13" data-xref="歌罗西书 1:28; 约翰福音 17:21; 以弗所书 4:5"> 我们一起成长，直到我们对上帝之子的相信和知识，让我们达成合一的状态，完全成长，通过基督获得真正完全的成熟。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 13:9; 罗马书 16:17–18; 哥林多前书 14:20"> 我们不应该再是小孩子，因教义吹来的每一道微风而摇摆，被人的诡计所迷惑，被狡猾之人引入歧途；</span>
<span className="v" id="v15" data-v="15" data-xref="约翰一书 3:18; 以弗所书 4:25; Zechariah 8:16"> 相反，要用爱心说实话，应该通过基督实现全面的成长，他就是我们的头。</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 2:19; 约翰福音 15:5; 歌罗西书 2:2"> 整个身体因为他而运作，每个关节都将它连接在一起，因为每个单独的部分都在各行其责，整个身体都在成长，在爱中构建自我。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 1:21; 彼得前书 4:3–4; 帖撒罗尼迦前书 4:1–2"> 所以让我要对你们说——事实上，我通过主里坚持了这一点——你们不应该再像异族人那样过着空虚的生活。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 13:15; 以弗所书 2:12; 罗马书 1:21–23"> 他们的思想处于一片黑暗。他们不明白，因为他们什么都不知道，他们固执地不想知道，所以与上帝的生命隔绝。</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 3:5; 罗马书 1:24–26; 提摩太前书 4:2"> 因为不在乎，所以放纵肉欲，贪婪地做出各种令人作呕之事。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="提多书 2:11–14; 约翰福音 6:45; 马太福音 11:29"> 但这并不是你们所知的基督！</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 5:20; 以弗所书 1:13; 希伯来书 3:7–8"> 你们难道没听说过他吗？你们没有人教过你们他的事情吗？你们没有学到耶稣的真理吗？</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 6:6; 希伯来书 12:1; 雅各书 1:21"> 所以，要摆脱你们以往的生活方式，它通过具有欺骗性的欲望毁掉了你们陈旧的天性！</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 12:2; 罗马书 8:6; Psalms 51:10"> 要让自己在灵性和心智重生，</span>
<span className="v" id="v24" data-v="24" data-xref="歌罗西书 3:10–14; 哥林多后书 5:17; 以弗所书 2:10"> 拥有上帝创造的新天性，这样你就会像他一样，获得真理的正义和圣洁。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="歌罗西书 3:9; Zechariah 8:16; Proverbs 12:22"> 所以要拒绝谎言，彼此说真话——因为我们属于彼此。</span>
<span className="v" id="v26" data-v="26" data-xref="雅各书 1:19; Psalms 4:4; Psalms 37:8"> 不要因生气而犯罪；不要在黑夜来临时仍然感到愤怒——</span>
<span className="v" id="v27" data-v="27" data-xref="雅各书 4:7; 彼得前书 5:8; 以弗所书 6:16"> 不要给魔鬼任何机会。</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太前书 6:18; 帖撒罗尼迦前书 4:11–12; 加拉太书 6:10"> 窃贼要停止偷窃，用双手诚实工作，带来成果，这样你就能拥有可以送给他人的东西，满足他人的需要。</span>
<span className="v" id="v29" data-v="29" data-xref="歌罗西书 4:6; 帖撒罗尼迦前书 5:11; Ecclesiastes 10:12"> 不要说脏话。根据需要说出鼓励他人的话，帮助那些倾听之人。</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒罗尼迦前书 5:19; Isaiah 63:10; 以弗所书 1:13–14"> 你们属于圣灵，圣灵已对你们做出标记。在救赎之日到来之前，不要让圣灵感到失望。</span>
<span className="v" id="v31" data-v="31" data-xref="歌罗西书 3:8; Ecclesiastes 7:9; 提多书 3:2–3"> 摆脱各种怨恨、暴躁、愤怒、谩骂、侮辱以及各种邪恶。</span>
<span className="v" id="v32" data-v="32" data-xref="歌罗西书 3:12–13; 马太福音 6:14–15; 马可福音 11:25"> 善待彼此，彼此宽恕，就像上帝通过基督宽恕你们一样。</span>
</div>
</div>

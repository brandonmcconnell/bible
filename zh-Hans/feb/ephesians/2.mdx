<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 2:13; 以弗所书 2:5–6; 歌罗西书 3:1–4"> 你们因自己的罪和邪恶行为而死，</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 6:12; 约翰一书 5:19; 以弗所书 2:3"> 按照这个世界的方式、在魔鬼的控制下生活，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为是“空中力量的统治者。”">a</a></sup>魔鬼的灵会控制那些不服从上帝之人。</span>
<span className="v" id="v3" data-v="3" data-xref="提多书 3:3; 以弗所书 4:22; 加拉太书 5:16–24"> 我们所有人都曾经如此，我们的行为被我们罪恶的人性欲望和邪恶思维方式所决定。和其他人一样，我们曾经是天性愤怒的孩子。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="希腊有俗语说“儿童天生愤怒。”这句话体现的是以往关于人性的思想，可能意味着人类对于上帝“生而愤怒”或叛逆。尽管这里并没有特指上帝，但也可以理解为上帝对我们有着神圣的愤怒。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="彼得前书 1:3; 以弗所书 1:7; Psalms 86:15"> 但上帝有着慷慨的怜悯之心，因为对我们有着令人惊异的爱，</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 3:24; 以弗所书 2:8; 罗马书 5:10"> 即使我们因罪而死，他也会让我们与基督一起活着。你因为相信上帝而获得拯救！</span>
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 3:1–3; 以弗所书 1:3; 罗马书 6:4–5"> 他与基督一起让我们复活，因为基督耶稣而让我们与他一同坐于天堂。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前书 1:16–17; 提多书 3:4; 以弗所书 2:4"> 这让他就可以在通过基督耶稣，在永恒的未来向我们展示他令人惊讶的深厚恩典和善意。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 3:22–26; 以弗所书 2:5; 罗马书 4:16"> 因信任上帝，你已蒙恩得救——这并非靠你自己，而是上帝的恩赐！</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太后书 1:9; 罗马书 11:6; 提多书 3:3–5"> 这与人的努力无关，所以不要为自己感到骄傲。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比书 2:13; 歌罗西书 1:10; 希伯来书 13:21"> 我们是上帝所为的造物，以基督耶稣为名创造我们是为了行善，上帝已经计划好我们应该这样做。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="歌罗西书 2:11; 歌罗西书 2:13; 歌罗西书 3:11"> 从人的角度而言，你们就是“异族人”，对于“已受割礼”之人而言，你们就是 “未受割礼”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="换言之，犹太人（割礼）和外邦人（割礼）。">c</a></sup>之人（但这只是一种人类做出的行为而已）。你们需要记住，</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 4:8; 歌罗西书 1:21; Jeremiah 31:31–34"> 以往你不知耶稣，与基督没有任何关系，你作为异族人就不会被视为以色列的公民，对于上帝承诺的约定<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或“盟约。”">d</a></sup>而言，你就是陌生人。你会没有希望，生活在没有上帝的世界上。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 2:39; 歌罗西书 1:20–22; 歌罗西书 1:13–14"> 但现在，通过基督耶稣，你们这些曾远离之人，如今被带到基督血的旁边。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="加拉太书 3:28; 歌罗西书 3:11; 歌罗西书 3:15"> 基督就是我们的平安。通过他的身体，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="从上下文看来，保罗在这里指的是耶稣被钉十字架一事。">e</a></sup>他将两者合而为一，打破了曾分隔我们、充满敌意的墙壁，</span>
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 2:14; 加拉太书 3:10; 歌罗西书 1:21–22"> 将我们从律法的要求和规定中解放出来。他这样做是为了用自己的身体，从两者之中创造一个新的人，从而实现和平，</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 1:20–22; 罗马书 5:10; 哥林多后书 5:18–21"> 通过十字架让他们与上帝和好，就好像他们是一体，让我们对彼此不再有敌意。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="Isaiah 57:19–21; 使徒行传 10:36; 罗马书 5:1"> 他来此的目的，是与那些曾经远离他的人分享和平的福音，</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 12:13; 以弗所书 3:12; 罗马书 5:2"> 因为通过他，我们都可以借由同一个圣灵接近天父。</span>
<span className="v" id="v19" data-v="19" data-xref="腓立比书 3:20; 约翰一书 3:1; 加拉太书 6:10"> 这意味着你不再是陌生人和异族人；你们都是上帝子民的同胞，属于上帝的大家庭，</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前书 2:4–5; Isaiah 28:16; 彼得前书 2:7–8"> 这个大家庭以基督耶稣为奠基石，以使徒和先知为地基。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 3:16–17; 哥林多前书 3:9; 哥林多后书 6:16"> 整座建筑因他而连为一体，逐渐成长为主的圣殿。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:4–5; 哥林多前书 3:16; 约翰一书 4:16"> 你们也是因他而被建造出来，成为上帝通过圣灵存在之地。</span>
</div>
</div>

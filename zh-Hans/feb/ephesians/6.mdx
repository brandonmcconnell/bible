<span className="v" id="v1" data-v="1" data-xref="歌罗西书 3:20–25; Proverbs 23:22; Proverbs 6:20"> 孩子，你们要按照父母的吩咐行事，因为这才是正确的方式。</span>
<span className="v" id="v2" data-v="2" data-xref="Exodus 20:12; Deuteronomy 27:16; 马太福音 15:4–6"> “要孝敬你的父母。”这是第一条带有承诺的诫命：</span>
<span className="v" id="v3" data-v="3" data-xref="Deuteronomy 5:16; Deuteronomy 4:40; Deuteronomy 12:28"> “这样才可能让你一切顺利，让你可以在人间长寿。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《出埃及记》20:12或《申命记》5:16。">a</a></sup></span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 3:21; Proverbs 22:6; Proverbs 29:15"> 父亲们，不要让你们的孩子变得疯狂，而是要管教他们，教导他们认识上帝，用这种方式照顾他们。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前书 2:18–21; 提多书 2:9–10; 歌罗西书 3:17–24"> 仆人，你们应该服从你们的人类主人，要表现处恰当的尊重和敬畏，做事要奔着真诚的动机，就像在侍奉基督一样。</span>
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 3:22–23; 帖撒罗尼迦前书 2:4; 加拉太书 1:10"> 不要只在其他人看的时候，为了获得认可而好好工作。要像基督的仆人一样工作，诚实地遵行上帝的旨意，</span>
<span className="v" id="v7" data-v="7" data-xref="歌罗西书 3:23; 以弗所书 6:5–6; 哥林多前书 10:31"> 快乐服侍主人，就好像你是在为主而非人做事。</span>
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 3:24; 路加福音 14:14; Proverbs 11:18"> 你们知道行善之人会得到主的奖赏，无论他是仆人还是自由人。</span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 3:25–1; 使徒行传 10:34; 罗马书 2:11"> 主人应该以同样的方式对待你的仆人。不要威胁他们，记得天上的主是你的主人，也是他们的主人。他对人一视同仁，没有偏袒。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比书 4:13; Isaiah 40:31; Joshua 1:9"> 最后，要通过主和他的能力保持强大。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 10:4; 罗马书 13:12; 以弗所书 6:13"> 穿上上帝的所有盔甲，这样你们就可以抵挡魔鬼的所有攻击！</span>
<span className="v" id="v12" data-v="12" data-xref="歌罗西书 1:13; 哥林多后书 4:4; 以弗所书 2:2"> 我们不是在对抗人类的力量，而是在对抗超自然统治者和权力，它是这个世界的黑暗之主，是对抗天堂的邪恶精神力量。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 10:4; 路加福音 21:36; 以弗所书 6:11–17"> 拿起上帝提供的所有武器，这样你就能在邪恶的岁月里站稳脚跟。在付出所有努力后，发现自己仍然屹立不倒！</span>
<span className="v" id="v14" data-v="14" data-xref="Isaiah 59:17; 帖撒罗尼迦前书 5:8; Isaiah 11:5"> 请站起来，把真理的腰带系在腰间，披上公正和正义的胸甲，</span>
<span className="v" id="v15" data-v="15" data-xref="Isaiah 52:7; 罗马书 10:15; 哥林多后书 5:18–21"> 穿上准备就绪的鞋子，分享和平的福音。</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前书 5:8–9; 约翰一书 5:4–5; Proverbs 18:10"> 最重要的是，要拿起信任上帝的盾牌，这样你就可以挡住魔鬼发来的火焰之箭。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 4:12; Isaiah 59:17; 启示录 19:15"> 戴上救赎的头盔，拿着圣灵的宝剑——灵就是上帝之道。</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 5:17; 歌罗西书 4:2; 腓立比书 4:6"> 当你这样做的时候，始终要以灵之名祷告。保持清醒，继续为所有上帝的子民祈祷。</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 4:3; 使徒行传 4:29; 帖撒罗尼迦后书 3:1"> 也请为我祈祷，让我始终可以讲出正义之语，让我能自信地解释福音中隐藏的真相。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 5:20; 歌罗西书 4:4; 提摩太后书 2:9"> 我就是为了福音而被囚禁的大使，所以请为我祈祷，让我以应该拥有的无畏发声。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 20:4; 提摩太后书 4:12; 提多书 3:12"> 推基古是我们的好朋友和忠诚的传道人，他会将我所有的消息告诉你们并解释这一切，这样你们就会知道我在做什么。</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比书 2:25; 歌罗西书 4:7–8; 帖撒罗尼迦后书 2:17"> 这就是我派他道你们那里的原因——他要把我们发生的事情告诉你们并鼓励你们。</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 6:16; 加拉太书 5:6; 彼得前书 5:14"> 愿天父上帝和主耶稣基督，祝福你们那边的所有基督徒能够秉承爱和信任，获得平安。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 22:37; 哥林多后书 8:12; 马太福音 6:13"> 愿永远热爱我们主耶稣之人，都能获得恩惠。</span>

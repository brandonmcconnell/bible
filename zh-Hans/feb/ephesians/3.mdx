<span className="v" id="v1" data-v="1" data-xref="歌罗西书 1:24; 提摩太后书 1:8; 腓立比书 1:13–16"> 我——保罗，为了你们这些异族人而成为耶稣基督的囚犯，这里将讲述我如何</span>
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 1:25–27; 提摩太前书 1:11; 提摩太后书 1:11"> （我想你们可能听说过，上帝已经赋予我责任，要我与你们分享上帝的恩典），</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 1:12; 罗马书 16:25; 以弗所书 1:9–11"> 通过上帝向我显示的一切，将以往隐藏的奥秘清楚展露。之前我曾简短地写过这件事，</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 4:3; 哥林多前书 4:1; 哥林多后书 11:6"> 当你阅读本函，就能够了解我对基督奥秘的洞察。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前书 1:10–12; 彼得后书 3:2; 提多书 1:1–3"> 过去的世代没有人清楚这一点，但现在灵已经向上帝的圣使徒和先知做了启示，</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 3:26–29; 约翰一书 1:3; 约翰一书 2:25"> 证明异族人是共同的继承人，属于同一个身体，通过基督耶稣和福音分享上帝的承诺。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 1:19; 以弗所书 3:20; 以弗所书 3:2"> 上帝的恩典使我成为福音的传道者，我之所以能这么做，是上帝能力所赐予我的。</span>
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 1:27; 哥林多前书 15:9; 以弗所书 2:7"> 在所有基督徒中，我是最微不足道的一位。但这恩典赐给了我，只为了与异族人分享基督那不可思议的非凡价值，</span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 1:26; 马太福音 13:35; 提摩太后书 1:9"> 帮助每个人看到这奥秘的使命。从一开始，创造一切的上帝就隐藏着这奥秘。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前书 1:12; 以弗所书 6:12; 哥林多前书 2:7"> 通过教会，上帝要向天堂的统治者和掌权者展示他在所有方面的智慧。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太后书 1:9; 以弗所书 1:11; 以弗所书 1:4"> 通过我们的主基督耶稣，上帝也显示了这样的永恒旨意。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 2:18; 罗马书 5:2; 希伯来书 4:14–16"> 因为他以及我们对他的信任，我们就能完全自由和自信地来到上帝面前。</span>
<span className="v" id="v13" data-v="13" data-xref="歌罗西书 1:24; 帖撒罗尼迦后书 3:13; 哥林多后书 1:6"> 所以我希望你们不要因为我的痛苦而沮丧——这是为了你们，你们应该珍惜它！</span>
<span className="v" id="v14" data-v="14" data-xref="Psalms 95:6; 以弗所书 1:16–19; 腓立比书 2:10"> 这就是为什么我跪在天父面前的原因。</span>
<span className="v" id="v15" data-v="15" data-xref="以弗所书 1:10; 启示录 5:8–14; 以弗所书 1:21"> 因为天上地上的每个家庭，其天性和品格都来自天父。</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 1:11; 腓立比书 4:13; Isaiah 40:29–31"> 我跪求从他丰饶的荣耀、通过他的灵，用他的能力强化你们内心深处的力量。</span>
<span className="v" id="v17" data-v="17" data-xref="歌罗西书 2:7; 约翰一书 4:16; 约翰福音 14:23"> 愿基督于你们同在，因为你们相信他。当你们深植于爱之中，</span>
<span className="v" id="v18" data-v="18" data-xref="Psalms 103:11–12; Job 11:7–9; 以弗所书 1:18–23"> 就有能力与所有上帝的子民一起，理解基督之爱的长度、广度、高度和深度。</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所书 1:23; 歌罗西书 2:9–10; 歌罗西书 1:10"> 愿你们知晓基督超越知识的爱，让你们因上帝的丰饶而圆满完全。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 9:8; 罗马书 4:21; Jeremiah 32:27"> 通过上帝影响我们的力量，愿他给予我们的，远超过我们所求、甚至我们所想的，</span>
<span className="v" id="v21" data-v="21" data-xref="犹大书 1:25; 罗马书 11:36; 彼得后书 3:18"> 愿他在教会中能通过基督耶稣获得世代荣耀，直到永远。阿门</span>

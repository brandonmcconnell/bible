<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰一书 4:11; 彼得前书 1:15–16; 以弗所书 4:32"> 所以要模仿上帝的行为，因为你们是他深爱的孩子。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 13:34; 加拉太书 2:20; 歌罗西书 3:14"> 要生活在爱中，就像基督爱你一样。他为我们将自己献给了上帝，正如芬芳的香水。</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 3:5; 以弗所书 5:5; 加拉太书 5:19–21"> 你们应该远离任何不道德的性、下流或贪婪行径，因为上帝的子民不应该做这样的事情。</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 3:8; 以弗所书 4:29; 帖撒罗尼迦前书 5:18"> 下流的谈吐、愚蠢的喋喋不休和粗俗的笑话不适合你们——你们应该感谢上帝。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 5:21; 哥林多前书 6:9–10; 以弗所书 5:3"> 你们知道，不道德、下流、贪婪或拜偶像的人，绝不可能会在基督和上帝的国度中获得任何继承。</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 1:18; 歌罗西书 2:8; 马太福音 24:4"> 不要让任何人用谎言来愚弄你们，因为正是因为这样的事情，上帝才会对悖逆的孩子进行审判。</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 18:4; 以弗所书 5:11; 提摩太前书 5:22"> 所以在这方面，不要与他们为伍。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 8:12; 约翰一书 1:7; 使徒行传 26:18"> 你们曾经身处黑暗，但现在你们在主那里就是光。你们要像光的孩子一样生活</span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 3:9–10; 加拉太书 5:22–23; 约翰三书 1:11"> （光的果实就是一切美好、正确和真实的东西），</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 12:1–2; 希伯来书 12:28; Psalms 19:14"> 要展示主真正欣赏的东西。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 13:12; 提摩太前书 5:20; 帖撒罗尼迦后书 3:6"> 要与滋生于黑暗、毫无意义的事情撇清关系——要去揭露它们。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 5:3; Jeremiah 23:24; Ecclesiastes 12:14"> 对于那些人私下所做的行径，即使是谈论它们也是一种羞辱。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 3:20–21; 哥林多前书 4:5; Hosea 2:10"> 当一切都暴露在光之中，一切就显而易见。光显现了一切。</span>
<span className="v" id="v14" data-v="14" data-xref="Isaiah 60:1; 罗马书 13:11–12; Isaiah 26:19"> 这就是为什么有人说：“醒醒吧，你们这些睡着的人，从死亡中复生，基督会照耀你们。”</span>
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 4:5; 雅各书 3:13; 腓立比书 1:27"> 所以要小心你的生活方式，不要愚蠢，要变得明智；</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 4:5; Amos 5:13; 约翰福音 12:35"> 要善用机会，因为每一天都充满邪恶。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 12:2; 帖撒罗尼迦前书 5:18; 歌罗西书 1:9"> 不要无知——要找出主的意愿是什么。</span>
<span className="v" id="v18" data-v="18" data-xref="Proverbs 20:1; 路加福音 1:15; 罗马书 13:13"> 不要酗酒，酒会毁了你的生活，要让灵充满你们的身体。</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 3:16; 哥林多前书 14:26; Psalms 95:2"> 要彼此分享，通过《诗篇》、吟唱和圣歌，用歌曲和音乐向主表达你的感受。</span>
<span className="v" id="v20" data-v="20" data-xref="歌罗西书 3:17; 帖撒罗尼迦前书 5:18; 希伯来书 13:15"> 奉我们主耶稣基督之名，感谢上帝天父所带来的一切。</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比书 2:3; 以弗所书 5:24; 以弗所书 5:22"> 如果其他人出于对基督的敬畏而让你去做一件事，每个人都应该欣然接受。</span>
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 3:18–1; 彼得前书 3:1–6; 提多书 2:5"> 妻子要服从丈夫让你做的事，如同这是来自主的吩咐。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 11:3–10; 歌罗西书 1:18; 以弗所书 1:22–23"> 丈夫是妻子的头，就像基督是教会的头。教会是他的身体，他是教会的拯救者。</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所书 5:33; 歌罗西书 3:20; 提多书 2:7"> 就像教会遵循基督的吩咐，妻子也应该在所有事情上遵循丈夫的吩咐。</span>
<span className="v" id="v25" data-v="25" data-xref="彼得前书 3:7; 歌罗西书 3:19; 以弗所书 5:28"> 丈夫应该爱自己的妻子，像基督爱教会并为教会舍弃自己的生命。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 10:22; 约翰福音 15:3; Ezekiel 36:25"> 他让一切圣洁，他用道之水洁净一切，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="大概是对洗礼的暗示。">a</a></sup></span>
<span className="v" id="v27" data-v="27" data-xref="歌罗西书 1:22; 希伯来书 9:14; 彼得前书 1:19"> 他让教会成为自己的教会，没有瑕疵、缺陷或任何类型的过错，保持圣洁无瑕。</span>
<span className="v" id="v28" data-v="28" data-xref="以弗所书 5:25; 马太福音 19:5; Genesis 2:21–24"> 丈夫应该这样爱妻子，就像爱自己的身体一样。一个爱妻子的男人也是在爱自己——</span>
<span className="v" id="v29" data-v="29" data-xref="Ezekiel 34:14–15; 以弗所书 5:31; Ecclesiastes 4:5"> 因为没有人会恨自己的身体，而是要为身体提供营养并照料它，就像基督对待教会的方式，</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前书 6:15; 哥林多前书 12:12–27; 罗马书 12:5"> 因为我们是他身体的一部分。</span>
<span className="v" id="v31" data-v="31" data-xref="Genesis 2:24; 马太福音 19:5; 马可福音 10:7–8"> “这就是为什么男人要离开父母，与妻子结合，两者合而为一。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引自《创世纪》2:24.">b</a></sup></span>
<span className="v" id="v32" data-v="32" data-xref="启示录 21:2; 哥林多后书 11:2; Isaiah 54:5"> 这是一个深藏不露的真理，不过我所说的是基督和教会。</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前书 3:2–7; Esther 1:20; 以弗所书 5:25"> 然而，每个丈夫都应该像爱自己一样爱自己的妻子，妻子也应该尊重丈夫。</span>
</div>

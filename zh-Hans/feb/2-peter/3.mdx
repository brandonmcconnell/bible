<span className="v" id="v1" data-v="1" data-xref="提摩太后书 1:6; 彼得后书 1:12–15; 彼得前书 1:22"> 朋友们，这是我写给你们的第二封信。在这两封信中，我都在试图激发你们，提醒你们用纯净的思想进行清晰的思考。</span>
<span className="v" id="v2" data-v="2" data-xref="犹大书 1:17; 彼得后书 2:21; 路加福音 1:70"> 记住以往圣先知们说的话，以及主和救世主通过你们的使徒做出的嘱咐。</span>
<span className="v" id="v3" data-v="3" data-xref="犹大书 1:18; 提摩太前书 4:1–2; 彼得后书 2:10"> 首先应该要知道：在末世必有讥讽之人，他们充满嘲讽之心，追随自己的邪恶欲望。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="见《犹大书》1:18。">a</a></sup></span>
<span className="v" id="v4" data-v="4" data-xref="Jeremiah 17:15; Malachi 2:17; Jeremiah 5:12–13"> “那么他要降临的承诺哪去了？”他们问。“从我们祖先去世的那一刻，一切都像从创世之日开始往常一样继续。”</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 11:3; Genesis 1:9; Psalms 24:2"> 但是他们故意忽略一个事实：天空是上帝下令在很久以前创造的。大地诞生于水，被水包围。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 24:38–39; 彼得后书 2:5; 路加福音 17:27"> 水摧毁了当时存在的世界，那个世界被水淹没。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得后书 3:10; Isaiah 51:6; 彼得后书 3:12"> 但是通过同样的神圣命令，眼前存在的天地被保留下来，留待审判之日被火毁灭，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“毁于火”：原意为“在火中。”">b</a></sup>那时恶人也会被毁灭。</span>
<span className="v" id="v8" data-v="8" data-xref="Psalms 90:4; 罗马书 11:25; 哥林多前书 12:1"> 但我的朋友们，别忘记：对主而言一天就像一千年，一千年就像一天。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="见《诗篇》90：4。">c</a></sup></span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前书 2:4; 罗马书 2:4; Habakkuk 2:3"> 主并没有像某些人以为的那样，将其承诺拖后，而是对你们非常耐心。他不希望任何人迷失，而是希望每个人都过来，都悔改。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 21:1; 马太福音 24:35; 彼得后书 3:7"> 但主的日子终将到来，就像盗贼一样出乎意料。天堂将在雷鸣般的轰鸣中爆炸，所有元素<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="目前尚不清楚这些“元素”究竟指的是什么。">d</a></sup>将被焚烧和毁灭。地球和大地上的一切都将消失。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="或者“将会看到它是什么。”">e</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="彼得前书 1:15; 腓立比书 1:27; 彼得前书 2:12"> 既然一切都将如此毁灭，你应该是哪种人？你应该过着纯洁的生活，献身于上帝，</span>
<span className="v" id="v12" data-v="12" data-xref="彼得后书 3:10; Isaiah 34:4; Micah 1:4"> 期待并渴望上帝之日的到来。在那一天，天空会燃起大火并被毁灭，所有元素都会在高温中融化。</span>
<span className="v" id="v13" data-v="13" data-xref="Isaiah 65:17; 启示录 21:1; Isaiah 66:22"> 但对我们而言，我们正在寻找上帝所承诺新天和新地，那里的一切都如此良善正直。<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="或“公义所在。”">f</a></sup></span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 5:23; 帖撒罗尼迦前书 3:13; 腓立比书 1:10"> 所以我的朋友们，既然你已经预料到这一切，请确保在看到你时，你是纯洁而无可指责的，与上帝和平相处。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 2:4; 彼得后书 3:9; 提摩太前书 1:16"> 请记住，是我们主的耐心给了我们救赎的机会。我们亲爱的兄弟保罗在他所有的书信中，曾用上帝赐予他的智慧向你解释了这一切。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 15:6; 希伯来书 5:11; 雅各书 1:8"> 他谈到了这些事情，尽管他所写的部分内容肯定很难理解。一些无知和不平衡之人歪曲他所写的内容，这让他们自己蒙受损失，正如他们歪曲其他经文。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 3:14; 歌罗西书 2:8; 哥林多后书 11:13–15"> 我的朋友们，既然你们已经知道了这些，就不要让恶人的错误引你们误入歧途，不要从自己牢固的位置上跌落。</span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 1:10; 以弗所书 4:15; 彼得前书 2:2"> 愿我们的主以及救世主耶稣基督的恩典和知识，愿你们获得成长。愿荣耀归于他，无论现在还是永远！阿门。</span>
</div>

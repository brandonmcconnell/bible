<span className="v" id="v1" data-v="1" data-xref="马太福音 18:15–17; 使徒行传 19:38; 哥林多前书 14:33"> 你们如果与邻居起了纷争，为什么要向不义的法官提交诉状呢？你应该将这件事告知其他信徒。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 19:28; Daniel 7:22; 启示录 20:4"> 难道你们不知道吗？基督信徒将审判世界。如果世界都由你们来审判，怎么就不配审判如此琐碎小事？</span>
<span className="v" id="v3" data-v="3" data-xref="犹大书 1:6; 马太福音 25:41; 哥林多前书 6:4"> 你们不知道吗？我们将要审判天使，更何况今世所发生的这种人间之事？</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 5:12; 使徒行传 6:2–4"> 如果你需要评判今世之事，怎能让教会并不尊重的人做出审判？<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或者“为什么不从教会中最不受尊敬的成员中选拔法官？”">a</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 15:34; 哥林多前书 4:14; 雅各书 3:13–18"> 我说的这番话，就是要让你们羞愧。为什么？难道你们中间没有智慧之人，可以审判这样的纷争吗？</span>
<span className="v" id="v6" data-v="6" data-xref="腓立比书 2:14–15; 约翰一书 2:9–11; 约翰一书 3:11–15"> 相反，信徒会跑到法庭状告其他信徒兄弟，向不信上帝之人提交诉状？</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 12:17–19; Proverbs 20:22; 彼得前书 2:19–23"> 你们状告彼此，已经是一个彻头彻尾的灾难。接受这不公正不好吗？为什么不甘心受到欺骗？</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦前书 4:6; 歌罗西书 3:25; 马可福音 10:19"> 你们的行为反倒会造成不公正，造成欺骗，而且是针对你们在教会中的信徒同伴。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前书 1:9–10; 加拉太书 5:19–21; 以弗所书 5:4–5"> 你们难道不知道吗？不义之人将无法继承上帝之国，不要被蒙骗！那些淫乱、膜拜神像、奸淫、性变态、同性恋、</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 5:11; 加拉太书 5:21; Ezekiel 22:29"> 偷窃、贪婪、酗酒、辱骂人或勒索之人，都不能继承上帝之国。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 1:30; 歌罗西书 3:5–7; 哥林多前书 1:2"> 你们有些人曾经如此，但借由主耶稣基督之名，凭着上帝之灵，你们变得洁净、圣洁和正义。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 10:23–33; 哥林多前书 9:27; 希伯来书 12:15–16"> 人们会说：“我有做事自由”，但任何事情都要适可而止。“我有做事的自由”，但绝不会受任何事的掌控！人们说</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 6:19; 哥林多前书 3:16; 罗马书 6:12"> 食物是为了肠胃，肠胃是为了食物，但上帝却会废掉这两者。同样，身体的存在不是为了淫乱，而是为了主而存在。同样，主也是为了身体而存在。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 4:14; 罗马书 8:11; 以弗所书 1:19–20"> 上帝凭借其力量让主复活，也要用同样的力量让我们复活。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="即站起身，继续讨论的主题。">b</a></sup></span>
<span className="v" id="v15" data-v="15" data-xref="以弗所书 5:30; 罗马书 12:5; 以弗所书 4:15–16"> 你们难道不知道吗？你们的身体就是基督身体的一部分，我们怎么能使用基督的身体，与娼妓的身体苟合？当然不可以！</span>
<span className="v" id="v16" data-v="16" data-xref="Genesis 2:24; 以弗所书 5:31; 马可福音 10:8"> 难道你不知道吗？与娼妓苟合，就是与她成为“一体。”记得经文所说：“两个人要成为一体。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《创世记》2:24。">c</a></sup></span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 17:21–23; 加拉太书 2:20; 哥林多前书 12:13"> 但与主结合，就代表与主的灵融为一体</span>
<span className="v" id="v18" data-v="18" data-xref="彼得前书 2:11; 帖撒罗尼迦前书 4:3; 歌罗西书 3:5"> 行淫乱之事。人类所犯罪行都在身体之外，唯有淫乱是对自己身体犯下的罪。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 3:16; 哥林多后书 6:16; 彼得前书 2:5"> 你们不知道吗？我们体内的圣灵，就住在身体这个圣灵之殿中，这圣灵是你从上帝那里领取的并不属于你自己。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 7:23; 罗马书 12:1; 彼得前书 2:9"> 你并不属于自己，而是根据标价购买而来。所以要用你的身体为上帝带来荣耀！</span>

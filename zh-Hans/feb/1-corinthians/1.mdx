<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 1:1; 以弗所书 1:1; 哥林多后书 1:1"> 此函来自教会兄弟保罗和苏提尼。保罗已奉上帝旨意召唤，成为基督耶稣的使徒。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 1:7; 哥林多前书 6:9–11; 哥林多前书 1:30"> 本函将送至哥林多的上帝教会，他们已凭耶稣基督成就良善正直，受到召唤成为圣徒。本函还将送至世界各地敬拜主耶稣基督之人。基督是他们的主，也是我们的主。</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 1:7; 哥林多后书 1:2; 彼得前书 1:2"> 愿你们获得来自天父和主耶稣基督的恩典与平安。</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 1:8; 约翰福音 14:26; 提摩太前书 1:14"> 上帝通过基督耶稣赐予你们的恩典，为此我始终都在感谢上帝，</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 9:11; 哥林多后书 8:7; 歌罗西书 2:3"> 你们因上帝而万事丰饶，因上帝而表达思想、知识渊博。</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 1:2; 提摩太后书 1:8; 提摩太前书 2:6"> 事实上，你们的经历证明了基督的见证，</span>
<span className="v" id="v7" data-v="7" data-xref="腓立比书 3:20; 彼得后书 3:12; 希伯来书 9:28"> 当你等待主耶稣基督到来之时，才不会错过任何圣灵的恩赐。</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦前书 5:23–24; 帖撒罗尼迦前书 3:13; 歌罗西书 1:22"> 他会让你坚强到底，让你们在主耶稣基督之日前始终坚守正义。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦后书 3:3; 希伯来书 10:23; Deuteronomy 7:9"> 上帝值得我们信赖，他呼唤你们，就是为了你与他的儿子、我们的主耶稣基督同在。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比书 2:1–4; 以弗所书 4:1–7; 哥林多前书 12:25"> 兄弟姐妹们，以主耶稣基督之名，请大家同心同德，不要分裂，构筑一条心，遵循一个使命。</span>
<span className="v" id="v11" data-v="11" data-xref="Proverbs 18:6; 提摩太前书 6:4; 提摩太后书 2:23–25"> 我的兄弟姐妹们，几名革来氏人曾和我说起你们，讲述了你们内部的纷争。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 3:21–23; 约翰福音 1:42; 马太福音 23:9–10"> 让我对我的意思予以解释：你们的引领者各不相同：“我追随保罗”、“我追随亚波罗”、“我追随矶法”或“我追随基督。”</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 4:5; 哥林多后书 11:4; 使徒行传 2:38"> 难道基督是分裂的？为你们钉上十字架的是保罗？你是以保罗的名义受洗的吗？</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 18:8; 罗马书 16:23; 哥林多前书 1:4"> 感谢上帝，除了基利司布和该犹以外，我未给你们任何人施洗，</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多后书 11:2; 约翰福音 3:28–29; 约翰福音 7:18"> 所以请不要将施洗之名归于我。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 16:15; 哥林多前书 16:17; 使徒行传 16:33"> （对了，我还曾给司提芬一家人施洗；再无他人。）</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 2:1; 哥林多前书 2:13; 彼得后书 1:16"> 基督派我前来并非为了施洗，而是要传播福音，但不能以人类的伶牙俐齿，否则基督的十字架将失去力量。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或“无效。”原意为“清空。”">a</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 2:14; 罗马书 1:16; 帖撒罗尼迦后书 2:10"> 十字架之道对于迷失之人而言毫无意义，但对于我们这些获得拯救之人，却体现了上帝的至高力量。</span>
<span className="v" id="v19" data-v="19" data-xref="Isaiah 29:14; Jeremiah 8:9; 哥林多前书 3:19"> 正如经文所说：“我将摧毁智者的智慧，抹去聪明人的聪明。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="可能源自《以赛亚书》29:14。">b</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 1:22; Job 12:17; 哥林多前书 3:19"> 那么当代的智者、宗教老师和哲人又如何呢？上帝是将这世界的智慧变成愚蠢吗？</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 10:21; 罗马书 1:20–22; 马太福音 11:25"> 既然上帝在他的智慧中允许世界在其智慧中不认识上帝，这是神的恩典计划，通过这愚昧的好消息，那些相信他的人将得到拯救。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 16:1–4; 马太福音 12:38–39; 马可福音 8:11"> 犹太人要求看到神迹，希腊人渴望获得智慧，</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 2:14; 哥林多前书 2:2; 彼得前书 2:8"> 我们的道却在讲述钉在十字架上的基督——犹太人视其为冒犯，外族人视其为愚蠢。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 1:30; 歌罗西书 2:3; 哥林多前书 1:18"> 但对于上帝召唤之人，不论是犹太人或外族人，基督就是上帝的力量，上帝的智慧。</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 11:33–36; 哥林多前书 1:18; Zechariah 4:6–7"> 因为即使是上帝的愚蠢也比人类智慧，即使是上帝的软弱也比人类坚强。</span>
<span className="v" id="v26" data-v="26" data-xref="雅各书 2:5; 哥林多前书 3:18–20; 雅各书 1:9–11"> 兄弟姐妹们，不要忘记，在那些受到上帝召唤的人中，很少有人是世俗定义中的智慧、权威和尊贵之人。</span>
<span className="v" id="v27" data-v="27" data-xref="雅各书 2:5; 马太福音 11:25; 哥林多前书 1:20"> 相反，上帝所选择的是世人视为愚笨之人，这足以让那些自认为智慧之人感到羞愧。他也选择了世人被视为软弱之人，足以让自认为强壮之人羞愧。</span>
<span className="v" id="v28" data-v="28" data-xref="Job 34:24; 罗马书 4:17; Isaiah 2:11"> 他还挑选了被世人视为卑贱、被众人轻视之人，甚至还有被世人认为毫无价值之人，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="这句复杂的经文可以这样解读：上帝选择了世界认为不重要的事物和人，来显示什么才是真正重要。">c</a></sup></span>
<span className="v" id="v29" data-v="29" data-xref="罗马书 3:27; Jeremiah 9:23; 以弗所书 2:9"> 让任何人都不能在上帝面前自吹自擂。</span>
<span className="v" id="v30" data-v="30" data-xref="以弗所书 1:7; 腓立比书 3:9; 罗马书 8:1"> 因为上帝，你们才能与基督耶稣同存，基督就是上帝赐予我们的智慧。他让我们成为正义，保持正义，让我们获得自由，</span>
<span className="v" id="v31" data-v="31" data-xref="Jeremiah 9:23–24; 哥林多后书 10:17; 腓立比书 3:3"> 正如经文所说：“想要吹嘘，也要吹嘘主。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="见《耶利米书》9:23。">d</a></sup></span>
</div>

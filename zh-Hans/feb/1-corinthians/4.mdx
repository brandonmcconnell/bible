<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 4:10; 提多书 1:7; 提摩太前书 3:9"> 所以，要把自己看作基督的仆人，为“上帝的奥秘”负责。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="同样，新约中的奥秘就是上帝所揭示的真理。">a</a></sup></span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 25:21; 路加福音 12:42; 路加福音 16:10–12"> 不仅如此，承担这一职责之人，还必须值得信赖。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 7:24; 哥林多前书 2:15; 1 Samuel 16:7"> 无论你或其他人评判我，我都完全不介意。事实上，我甚至也不会评判自己。</span>
<span className="v" id="v4" data-v="4" data-xref="Psalms 143:2; 约翰一书 3:20–21; Psalms 130:3"> 我不记得自己做过错事，但这并不代表我在道德上称得上良善正直，只有主才能评判我。</span>
<span className="v" id="v5" data-v="5" data-xref="雅各书 5:7; 哥林多后书 5:10; 哥林多前书 3:13"> 所以，在恰当时机到来之前——即主降临之前，不要做出任何评判。他将照亮那被隐藏的、最黑暗的秘密，袒露人心里的动机。届时，上帝会给每个人应得的称赞。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 12:6; 哥林多后书 11:4; 哥林多后书 12:19"> 那么，兄弟姐妹们，我用我自己和亚波罗给你们做例子，让你们了解，不要超越经文所记内容，不要自高自大，不要偏爱任何人。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文的意思存在争议。所以有很多不一样的翻译版本。">b</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 3:27; 彼得前书 4:10; 雅各书 1:17"> 是什么让你如此特别？你拥有了什么，才让上帝不肯给予你？既然是来自上帝的给予，为什么要傲慢地否认这一点？</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 6:25; Proverbs 13:7; 哥林多前书 5:6"> 你以为拥有了所需的一切。你以为自己如此富有。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为：“没有我们。”">c</a></sup>你以为自己是王，不再需要我们。我倒真的希望你就是国王，这样我们就可以与你共同为王！</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 10:33; 罗马书 8:36; 哥林多后书 4:8–12"> 在我看来，上帝将我们这些使徒排在队列的最后，作为一种展示，尽管我们也会向其他人一样死去，但那只是我们在整个宇宙面前、在天使和人类面前，演了一场戏。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 2:3; 使徒行传 26:24; 哥林多前书 3:18"> 我们是基督的愚人，但与上帝同在的你却如此智慧。我们软弱，你们强壮！你们受人尊敬，我们被瞧不起！<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="从上下文来看，保罗的语言似乎带有讽刺意味。">d</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 8:35; 哥林多后书 11:23–27; 腓立比书 4:12"> 即使是现在，我们仍然饥渴难耐、衣不蔽体、遭受殴打、无处安身。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 3:9; 马太福音 5:11; 彼得前书 4:12–14"> 我们艰难辛苦地劳作。被人咒骂，我们会为其祝福；遭人迫害，我们会忍受；</span>
<span className="v" id="v13" data-v="13" data-xref="Lamentations 3:45; 使徒行传 22:22"> 被人毁谤，我们报以善意。直到现在，人们视我们为泥土、这世上最肮脏的垃圾。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:11; 哥林多前书 4:15; 约翰三书 1:4"> 我写这番话并非让你们羞愧，而是把你们当作我最爱的孩子一样给出警告。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 4:19; 哥林多前书 3:10; 哥林多前书 9:14"> 纵然你们有成千上万的基督徒教师，但却没有多少人可以称其为父。因为基督耶稣的缘故，当我与你们分享福音，便可成为你们的父亲。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 11:1; 帖撒罗尼迦后书 3:9; 腓立比书 3:17"> 所以我请求你们，一定要效法我。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="提摩太前书 1:2; 哥林多前书 16:10; 哥林多前书 7:17"> 也正是因为这个原因，我派提摩太去拜访你们。他与主同在，是我最值得信赖、最喜爱的儿子。他将提醒你们我如何追随基督，就像我在各会堂中所作的教导。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 4:6–8; 哥林多前书 5:2; 哥林多前书 4:21"> 有人以为我不会到他们那里去，于是就变得骄傲自负。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多后书 13:1–4; 使徒行传 18:21; 使徒行传 19:21"> 但只要是主的意愿，我很快就会去往那里。然后了解那些傲慢自负的人都说了什么，知晓他们的能力如何。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 2:4; 帖撒罗尼迦前书 1:5; 哥林多后书 10:4–5"> 因为上帝之国并不关注言语，而要看能力。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 13:2; 哥林多后书 13:10; 帖撒罗尼迦前书 2:7"> 那么你期待什么？让我带着棍子去殴打你，还是带着爱和温柔的灵出现？</span>
</div>

<span className="v" id="v2" data-v="2" data-xref="马可福音 16:17; 使徒行传 19:6; 使徒行传 10:46"> 那些讲述方言<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="显然，这里所说的并不是使用普通的人类语言。关于这种现象存在很多争议。很显然，正如《使徒行传》第 2 章所述，早期的教会拥有讲述和理解不同语言的能力。但这里似乎也有“狂喜的胡言乱语”之意。这种方式在哥林多被滥用，因此保罗必须在这里解决这个问题。">b</a></sup>之人，他们讲述的对象不是人，而是上帝。因为没有人能听得懂，他们讲述的是圣灵深处的奥秘。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 14:12; 提摩太前书 4:13; 犹大书 1:20"> 但为上帝讲道之人却在成就人类，为他们提供鼓舞和安慰。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 14:22; 哥林多前书 14:26; 马可福音 16:17"> 说方言知识成就自己，传播上帝之道却是在成就教会。我希望你们都会说方言，但我更希望你们都能讲道。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 12:28–30; 哥林多前书 12:10; 马可福音 16:17"> 因为方言如果不翻译，就无法成就教会。相比之下，讲道之人更重要。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所书 1:17; 罗马书 6:17; 提摩太后书 3:16"> 兄弟姐妹们，如果我到你们那里时只说方言，而不是讲述启示、知识、预言或进行教导，那又能给你们带来什么益处？</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 14:8; 路加福音 7:32; 哥林多前书 13:1"> 很多没有生命的物品也能发出声音，比如箫或琴。但如果它们无法发出清晰的音调，你又怎知它们弹奏的是什么？</span>
<span className="v" id="v8" data-v="8" data-xref="Numbers 10:9; Ezekiel 33:3–6; Jeremiah 4:19"> 同理，如果军号无法发出清晰的声音，谁又能做好战斗的准备呢？</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 9:26"> 你们的情况也是如此，如果口中说出无法听懂的语言，其他人又怎能理解你在说什么？你不过是向空气说话而已。</span>
<span className="v" id="v10" data-v="10"> 世间有那么多种语言，任何一种都有它的意义。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 28:2; 罗马书 1:14; 歌罗西书 3:11"> 如果我不理解这种语言，就无法理解讲述语言之人，他们也无法理解我。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为：我对说话之人而言就是野蛮人，说话之人对我也是野蛮人。“野蛮人”这个词表示他们只能发出“吧-吧”这样毫无意义的声音。">c</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 14:26; 哥林多前书 14:3–4; 哥林多前书 14:1"> 你们也是如此。如果你们期待获得圣灵的恩赐，就应当设法拥有更多可以成就教会的恩赐。</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 11:24; 哥林多前书 12:30; 约翰福音 14:13–14"> 说方言之人应当祈求，让他的方言能够翻译出来。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 14:2; 哥林多前书 14:15–16; 哥林多前书 14:19"> 我若用方言祷告，那么就是我的灵在祷告，对我的理解毫无用处。</span>
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 3:16; 约翰福音 4:23–24; 以弗所书 6:18"> 那么我该怎么办呢？我要以灵祷告，也要用心智祷告。我要以灵歌唱，也要以心智歌唱。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="保罗在这里似乎采用了科林斯人的措辞方式，这些人会因采用“以灵”的方式而感到自豪，似乎这比其他任何事情都优越。保罗指出，“以灵”的方式除非能够帮助理解，否则毫无帮助。">d</a></sup></span>
<span className="v" id="v16" data-v="16" data-xref="1 Chronicles 16:36; Psalms 106:48; 启示录 5:14"> 因为如果你只以灵赞美，普通人就无法知晓你在说什么，在你进行感恩祈祷后，也无法说“阿门。”</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 14:4; 哥林多前书 14:6"> 你可能进行了一次无以伦比的感恩祈祷，但对其他人却毫无帮助！</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 1:4–6; 哥林多前书 4:7"> 感谢上帝，我擅长的方言比你们大家都多。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 14:21–22; 哥林多前书 14:4"> 但在教会中，我宁愿用大家都理解的五句话去教导人，胜过用方言说出的千言万语。</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前书 2:2; 哥林多前书 13:11; 罗马书 16:19"> 兄弟姐妹们，不要像孩子一样思考。对于恶，你应该像婴儿般纯洁，但在思想上要成熟。</span>
<span className="v" id="v21" data-v="21" data-xref="Isaiah 28:11–12; Jeremiah 5:15; Deuteronomy 28:49"> 正如律法所记：“主说：我要借助说其他语言之人、借助外族人的嘴对我的子民讲话，但尽管如此，他们仍然不肯听我。”<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="引自《以赛亚书》28:11-12。">e</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 2:6–12; 马可福音 16:17; 哥林多前书 14:1"> 说方言即是一个信号，并非讲给信徒，而是讲给那些不信之人。但讲述上帝预言之道恰好相反：这个信号讲述的对象并非那些不信之人，而是信主之人。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 2:13; 使徒行传 26:24; 哥林多前书 11:18"> 如果整个教会聚在一起，大家都说方言，如果这时又不明就里或不信上帝之人走进来，难道不会觉得你们疯了吗！</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 2:37; 哥林多前书 2:15; 希伯来书 4:12–13"> 如果大家都讲上帝之道，不相信上帝或不理解这一切的人走进来，就会被众人说服，承认自己的罪。</span>
<span className="v" id="v25" data-v="25" data-xref="Isaiah 45:14; Zechariah 8:23; Psalms 72:11"> 他心里的隐秘会显露出来，他会跪倒<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="原意为：是“落在他的脸上。”">f</a></sup>敬拜上帝，确认上帝真正在你们之中。</span>
<span className="v" id="v26" data-v="26" data-xref="以弗所书 5:19; 罗马书 14:19; 哥林多前书 12:7–10"> 兄弟姐妹们，你们应该怎么办呢？当你们聚集在一起，各司其职，比如唱歌、教导、预言、以方言表达和进行翻译，这样就能做好一切，成就和鼓励教会。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 14:26"> 如果有人想说方言，那么只能有两个人这样做，或最多三人，并且要轮流说，还要有一个人翻译。</span>
<span className="v" id="v28" data-v="28"> 如果没有人翻译，说方言之人就应该在教会中保持沉默，只对自己和上帝说好了。</span>

<span className="v" id="v30" data-v="30" data-xref="帖撒罗尼迦前书 5:19–20; Job 33:31–33; Job 32:11"> 但如果聚会中有人获得特别的启示，之前发言之人就应该停下来，让那人讲述。</span>

<span className="v" id="v33" data-v="33" data-xref="雅各书 3:17–18; 哥林多前书 14:40; 帖撒罗尼迦后书 3:16"> 因为上帝不会混乱，而是和平且安静。<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="这段话处理的情况是：如果一个人声称获得特殊启示/启发，希望获得升华，就要对之提供显而易见的证明。">g</a></sup></span>
<span className="v" id="v34" data-v="34" data-xref="提摩太前书 2:11–12; Genesis 3:16; Numbers 30:3–13"> 妇女在教会中应当保持沉默，不应发言。他们应该如律法所属，顺从这样的场合。</span>

<li id="fn-f"><a href="#fnref-f" className="fnb">f</a> <span className="fnr">14:25</span> 原意为：是“落在他的脸上。”</li>
<li id="fn-g"><a href="#fnref-g" className="fnb">g</a> <span className="fnr">14:33</span> 这段话处理的情况是：如果一个人声称获得特殊启示/启发，希望获得升华，就要对之提供显而易见的证明。</li>
<li id="fn-h"><a href="#fnref-h" className="fnb">h</a> <span className="fnr">14:35</span> “不恰当。”保罗使用这个词（也可能表示可耻或羞辱）来表明这与文化背景有关。</li>
<li id="fn-i"><a href="#fnref-i" className="fnb">i</a> <span className="fnr">14:35</span> 之所以将 14:34-35 加上引号，是因为应该这样理解：这是科林斯人在信函中概述的立场，保罗在驳斥他们的论点之前先引用了它们。保罗在之前 11:5 句中，保罗在三段话中提到了妇女祈祷和预言的问题，这表明，不应将这一说法理解为禁止女性在教会发言的命令。从上下文来看，科林斯教堂中的妇女似乎在进行质疑和争论，这是他提到的混乱之一。科林斯教堂在信中所建议的解决方法，也是保罗在这里想要解决的问题。</li>

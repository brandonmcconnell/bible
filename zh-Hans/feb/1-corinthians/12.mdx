<span className="v" id="v1" data-v="1" data-xref="哥林多前书 12:4–11; 哥林多前书 14:37; 哥林多前书 14:1–18"> 现在来说说“圣灵的恩赐”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="保罗谈到了柯林斯人问过的另一个问题。">a</a></sup>。我的兄弟姐妹们，让我来解释这个问题。</span>
<span className="v" id="v2" data-v="2" data-xref="彼得前书 4:3; 帖撒罗尼迦前书 1:9; Psalms 115:5"> 你们知道，当你们还是异教徒的时候，你们总是受到欺骗，去膜拜那不能说话的神像。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰一书 4:2–3; 马太福音 16:16–17; 罗马书 10:9"> 让我明确这一点：任何以上帝之灵说话的人，都不会说“诅咒耶稣。”但只有拥有圣灵，才能说出“耶稣是主。”</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前书 4:10; 哥林多前书 12:28; 罗马书 12:4–6"> 恩赐有许多种，但都来自同一个圣灵；</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 4:11–12; 罗马书 12:6–8; 罗马书 14:8–9"> 侍奉职责有很多种类<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或“服务。”">b</a></sup>，但都来自同一位主；</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 3:7; 哥林多前书 12:11; 约翰福音 5:17"> 工作的方式也有许多种，但都来自同一位上帝，是他完成了所有这一切。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前书 4:10–11; 罗马书 12:6–8; 哥林多前书 14:19"> 圣灵被赐予每一个人，为了所有人的益处而显现。</span>
<span className="v" id="v8" data-v="8" data-xref="Proverbs 2:6; 哥林多前书 2:6–10; Psalms 143:10"> 圣灵赐予某些人说出智慧之语的能力。同样还是这圣灵，赐予其他人知识。</span>
<span className="v" id="v9" data-v="9" data-xref="雅各书 5:14–15; 哥林多后书 4:13; 以弗所书 2:8"> 这圣灵还让一些人对上帝产生了强烈的信仰，让有的人获得了治愈的恩赐。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 14:39; 约翰一书 4:1; 马可福音 16:17"> 他让有些人可以行神迹，有的人可以预言，有的人可以辨别不同的灵，有人能说各地方言，还有人获得了翻译语言的能力。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 12:4; 希伯来书 2:4; 哥林多后书 10:13"> 这一切都源自同一位圣灵，他按照自己的意思向每个人进行馈赠。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 12:4–5; 歌罗西书 3:15; 哥林多前书 12:27"> 正如人类的身体是一个整体，却包含很多器官。身体器官虽然很多，但却组合成一个身体，基督也是如此。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 4:5; 歌罗西书 3:11; 加拉太书 3:28"> 无论是犹太人或希腊人、奴隶或自由人，都在同一位圣灵那里受洗，最终成为一个身体。我们都被赐予同一个圣灵为饮。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 12:27–28; 哥林多前书 12:12; 以弗所书 4:25"> 身体器官不止一个，而是有很多。</span>
<span className="v" id="v15" data-v="15" data-xref="Judges 9:8–15; 2 Kings 14:9"> 如果脚说：“我不是手，所以我不属于这身体。”难道它真的就不属于这身体？</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 12:3; 哥林多前书 12:22; 腓立比书 2:3"> 假如耳朵说：“我不是眼睛，所以我不属于身体。”难道它真的就不属于这身体？</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 12:21; Psalms 139:13–16; Proverbs 20:12"> 如果整个身体只是一只眼睛，又怎能听到？假如整个身体只是一个耳朵，又怎能闻到味道？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 12:28; 罗马书 12:3; 哥林多前书 12:11"> 但上帝对这躯体中的每一个器官，都有自己的安排，根据他的心意放置它们。</span>
<span className="v" id="v19" data-v="19"> 假如这些器官都相同，身体又会怎样呢？</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 12:14; 哥林多前书 12:12"> 尽管器官很多，它们组合在一起就成为身体。</span>
<span className="v" id="v21" data-v="21" data-xref="Ezra 10:1–5; Nehemiah 4:16–21; Job 29:11"> 眼睛不能对手说：“我不需要你。”头也不能对脚说：“我不需要你们。”</span>
<span className="v" id="v22" data-v="22" data-xref="Proverbs 14:28; Ecclesiastes 9:14–15; Ecclesiastes 4:9–12"> 相反，身体中那些看似微不足道的器官，更是不可缺少。</span>
<span className="v" id="v23" data-v="23" data-xref="Genesis 3:21; Genesis 3:7"> 事实上，那些被我们认为不够美观的器官，把它们遮盖起来，才会带给我们“荣耀。”对于那些不大美观的器官，我们应该更谦逊地对待它们。</span>
<span className="v" id="v24" data-v="24" data-xref="Genesis 3:11; Genesis 2:25"> 那些美观的器官就不需要遮盖了。但上帝就是这样创造身体：为那些不太适合外露展示的器官，赋予了更多荣耀。</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多后书 13:11; 哥林多前书 1:10–12; 约翰福音 17:21–26"> 这样做可以让身体内部不会发生冲突，那些不同的器官应该平等对待彼此。</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 12:15; 加拉太书 6:2; 希伯来书 13:3"> 如果身体的一个器官遭受痛苦，所有其他器官也跟着一同受苦。如果善待一个器官，身体其他的器官都会感到快乐！<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="保罗在这里似乎在思考教会的机构，而不是人类的身体。">c</a></sup></span>
<span className="v" id="v27" data-v="27" data-xref="以弗所书 4:12; 歌罗西书 1:24; 以弗所书 5:30"> 你们就是基督的身体，每一个人都是这身体的一部分。</span>
<span className="v" id="v28" data-v="28" data-xref="以弗所书 4:11–13; 罗马书 12:6–8; 哥林多前书 12:18"> 在教会中，上帝首先为使徒进行安排，第二是先知，第三是教师，然后分别是行神迹者、医病治愈者、乐于助人者、优秀的长官和可说出多种语言的人。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 12:4–11; 哥林多前书 12:14–20"> 并非所有人都是使徒、先知或教师？不是所有人都能行神迹？</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前书 12:10"> 不是所有人都有治愈的恩赐？都有能力说多种语言或翻译语言？</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多前书 13:1; 哥林多前书 14:39; 马太福音 5:6"> 你们应该追寻那最重要的馈赠。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="在讨论了不同的圣灵恩赐之后，保罗阐述了信徒最该渴望获得、最重要的恩赐。当然，这部分存在很多争议。他想做的就是为下一章做准备，因为如果没有爱，这些礼物即使特别规整，终究也没有任何价值。">d</a></sup>所以现在我将向您展示一个更好的方法。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 1:6–12; 彼得前书 5:12; 哥林多前书 15:3–11"> 提醒一下：我之前向你们宣讲了福音，你们已经接受了，此后便始终坚守。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 3:6; 希伯来书 2:1; 希伯来书 3:14"> 如果你们坚守我所传给你们的福音，就会因这福音得救，否则你们所信的一切都是枉然。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得前书 2:24; 加拉太书 1:4; Isaiah 53:1–12"> 我将之前所获得的福音传递给你们，这是一条至关重要的讯息：如经文所述，耶稣已死，因我们的罪而死。</span>
<span className="v" id="v4" data-v="4" data-xref="Hosea 6:2; 马太福音 12:40; Psalms 16:10–11"> 他在被埋葬之后，又按照经文所述在第三天复活。</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 16:14; 哥林多前书 1:12; 约翰福音 1:42"> 他曾向彼得显现，然后又向十二使徒显现。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 28:10; 马可福音 16:7; 使徒行传 13:36"> 之后他又向五百多名兄弟姐妹显现，这些人中，有的已经死去，但大多数人如今仍然活着。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 24:50; 使徒行传 1:2–12; 路加福音 24:33"> 他还曾向雅各显现，再后又向所有使徒显现，</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 9:1; 使徒行传 26:16; 使徒行传 22:18"> 直到最后他才向我显现，好像我是一个未在预产期降生的婴儿。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 3:7–8; 提摩太前书 1:13–15; 使徒行传 8:3"> 我原本是所有使徒中最微不足道的那一个，本无资格被称为使徒，因为我曾经迫害上帝的教会。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比书 4:13; 哥林多后书 3:5; 腓立比书 2:13"> 但我能有今天全凭上帝的恩典，他赐予我的恩典也没有付诸东流。相反，我比其他使徒更辛苦地付出，但真正辛苦付出的不是我，而是我所获赐的上帝恩典。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 15:3–4; 哥林多前书 2:2"> 因此，无论是我或是众使徒，我们都在与你们这些信奉上帝之人，分享这福音。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 26:8; 使徒行传 17:32; 提摩太后书 2:18"> 那么，如果这福音宣布基督死而复生，为什么你们中间会有人说没有死而复生这种事？</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 11:25–26; 罗马书 8:11; 帖撒罗尼迦前书 4:14"> 如果没有死人复活之事，基督也就没有死而复生。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 15:17; 帖撒罗尼迦前书 4:14; 加拉太书 2:2"> 如果基督没有复活，我们向你们所传福音便毫无意义，你们的信也是毫无意义，</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 2:24; Job 13:7–10; 使徒行传 2:32"> 此外，当我们证明上帝让基督死而复生之时，还会被视为上帝的假证人。但如果上帝未让基督死而复生，那么是否根本就没有复活这种事？</span>
<span className="v" id="v16" data-v="16"> 如果死人无法复活，基督也就无法复活。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 4:25; 彼得前书 1:3; 哥林多前书 15:14"> 如果基督没有复活，你们的信仰就是徒然，你们仍是罪人。</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 4:13–14; 启示录 14:13; 帖撒罗尼迦前书 4:16"> 那么也意味着因基督而死之人，也将消亡。</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前书 1:21; 启示录 14:13; 提摩太后书 1:12"> 如果我们心中的希望只为今生而立，我们便是最可怜之人。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 15:23; 使徒行传 26:23; 启示录 1:5"> 但基督的确已经死而复生，成为在死亡之人中所收获的初熟果实<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“初熟果实”是指向上帝献祭的第一批收获果实，也被视为大丰收的保障。因此，基督作为初熟果实就意味着：他既是最初赴死之人，又是死人复活的保证。">a</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 11:25; 罗马书 5:12–17; 哥林多前书 15:22"> 正如死是借着一个人而来，死人的复活也是借着一个人而来。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 5:12–21; 哥林多前书 15:45–49; 约翰福音 5:21–29"> 与亚当同在的众人都已死去，同理，与基督同在的众人都会复活。</span>
<span className="v" id="v23" data-v="23" data-xref="Isaiah 26:19; 加拉太书 3:29; 哥林多前书 15:52"> 只是每个人都有自己复活的顺序：首先是基督这初熟的果实，然后才是他降临之时追随于他的众人。</span>
<span className="v" id="v24" data-v="24" data-xref="Daniel 7:27; Daniel 7:14; 马太福音 28:18"> 之后便到了最后关头，基督毁灭了<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这里的破坏是指终止他们的力量。">b</a></sup>所有统治者、掌权者和力量，将这世间之国交给天父上帝。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 10:12–13; Psalms 110:1; 马太福音 22:44"> 基督必将为王，但在这之前，基督会将他的所有敌人置于他的脚下。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="意味着他们已经被征服，变得谦卑。">c</a></sup></span>
<span className="v" id="v26" data-v="26" data-xref="提摩太后书 1:10; 哥林多前书 15:55; 启示录 21:4"> 最后被毁灭的敌人就是死亡。</span>
<span className="v" id="v27" data-v="27" data-xref="Psalms 8:6; 希伯来书 2:8; 马太福音 28:18"> 正如经文所说：“他让万物臣服于他脚下。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《诗篇》8:6。">d</a></sup>（当然了，这里所说的“万物”臣服于他，并不包括上帝，是上帝让万物服从于基督的权力。）</span>
<span className="v" id="v28" data-v="28" data-xref="歌罗西书 3:11; 哥林多前书 3:23; 以弗所书 1:23"> 在万物服从于基督的权力之后，人子也要服从于上帝的权力。因为人子对万物的权力源自上帝，以此证明上帝的权力才是至高无上的。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原意为“最重要的。”这段话有很多解释版本。很显然，它是指上帝在宇宙中的最高统治，也许最好按照原文的字面理解为“最重要。”">e</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="罗马书 6:3–4; 哥林多前书 15:16; 马太福音 20:22"> 否则，为死人施洗又是为了什么？如果死人根本不会复活，为什么要为他们施洗？<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="这句经文的神学含义争议很大。但翻译起来却很简单。">f</a></sup></span>
<span className="v" id="v30" data-v="30" data-xref="哥林多后书 6:9; 加拉太书 5:11; 哥林多后书 4:7–12"> 至于我们，我们又何必时时刻刻身处险境？</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多后书 4:10–11; 罗马书 8:36; 哥林多前书 4:9–13"> 兄弟姐妹们，让我直言不讳地告诉你们，我每天都冒着死亡的风险，但我将其视为一种自豪，为耶稣基督为你们所做的一切而感到自豪。</span>
<span className="v" id="v32" data-v="32" data-xref="Isaiah 22:13; Isaiah 56:12; 路加福音 12:19"> 之前我曾在以弗所对抗那些人，他们对待我就如同一群野兽。如果从人类的角度来看，那对我又有何益处呢？如果死人不会复活，那么何不“大吃大喝吧，因为明天就要死去。”<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="引自《耶利米书》22:13。">g</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="Proverbs 13:20; 马太福音 24:4; 哥林多前书 5:6"> 不要再被欺骗了，“坏朋友会破坏好品德。”</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 6:5; 罗马书 13:11; 希伯来书 5:11–12"> 你们要保持理智，不要犯罪！你们中有的人不认识上帝，我这样说就是为了让你们羞愧。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="Ezekiel 37:3; 哥林多前书 15:38–53; 罗马书 9:19"> 当然了，有人会问：“死人又如何复活呢？他们复活后又有着怎样的身体呢？”</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 12:24; 路加福音 11:40; 以弗所书 5:15"> 多么无知的问题！你种下的种子不会发芽生长，除非它们死了。</span>
<span className="v" id="v37" data-v="37"> 但你种下种子的时候，并非为了它最终长成的样子。你种下的只是一粒种子而已，也许是麦子或其他种子。</span>
<span className="v" id="v38" data-v="38" data-xref="哥林多前书 3:7; Isaiah 61:11; 马可福音 4:26–29"> 但上帝让这种子长成他所选择的形体，每一颗种子都长成不同形体的不同植物。</span>
<span className="v" id="v39" data-v="39" data-xref="Genesis 1:20–26"> 用于创造所有生命体的物质也各有不同，人的躯体是一种，走兽、飞鸟和鱼是另外几种，每一种都不相同。</span>
<span className="v" id="v40" data-v="40"> 有的躯体为天空之躯，有的为大地之躯。天空之躯自有一种美，大地之躯则是另一种美。</span>
<span className="v" id="v41" data-v="41" data-xref="Isaiah 24:23; Psalms 148:3–5; Deuteronomy 4:19"> 太阳闪耀着一种光芒，月亮闪耀另一种光，星星也是各不相同，每一种都有自己光芒的方式。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="马太福音 13:43; Daniel 12:3; 罗马书 8:21"> 死人复活也是同样的道理。种下腐朽之躯，复活后即得永生；</span>
<span className="v" id="v43" data-v="43" data-xref="哥林多前书 6:14; 歌罗西书 3:4; 腓立比书 3:20–21"> 如果种下的是卑微，复活后就会成为荣耀；种下的是软弱，复活后就是力量；</span>
<span className="v" id="v44" data-v="44" data-xref="哥林多前书 15:50; 路加福音 24:31; 约翰福音 20:19"> 种下的是自然之躯，复活后就是灵性之躯。因为既有自然之躯，也有灵性之躯。</span>
<span className="v" id="v45" data-v="45" data-xref="约翰福音 5:21; Genesis 2:7; 罗马书 8:2"> 正如经上如此记载：“亚当作为第一个人类，成为拥有生命的活人。<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="引自《创世纪》2:7。">h</a></sup>但最后的亚当则变成了赋予人生命的灵。”</span>
<span className="v" id="v46" data-v="46" data-xref="歌罗西书 3:9–10; 罗马书 6:6; 以弗所书 4:22–24"> 但先来到这世界的并非是灵，而是自然之躯，灵随后来到。</span>
<span className="v" id="v47" data-v="47" data-xref="约翰福音 3:31; Genesis 2:7; Genesis 3:19"> 第一个人来自大地的泥土，第二个人来自于天。</span>
<span className="v" id="v48" data-v="48" data-xref="Genesis 5:3; 罗马书 5:12–21; 约翰福音 3:6"> 来自于泥土的人类，都有着泥土造就人类的模样。来自于天的人类，都有着天造就的模样。</span>
<span className="v" id="v49" data-v="49" data-xref="罗马书 8:29; 哥林多后书 3:18; Genesis 5:3"> 我们都有着泥土人类的模样，未来也将拥有天造就的模样。</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 3:3–6; 马太福音 16:17; 以弗所书 4:17"> 但我的兄弟姐妹们，我告诉你们的是，我们现在的躯体<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="原意为：是“血肉。”">i</a></sup>无法继承上帝之国，这些必将腐朽的躯体无法继承不朽。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="帖撒罗尼迦前书 4:14–17; 腓立比书 3:21; 哥林多前书 15:20"> 听着，我要告诉你们一个奥秘：我们中不是所有人都会死去，但我们都会改变。</span>
<span className="v" id="v52" data-v="52" data-xref="帖撒罗尼迦前书 4:16–17; 马太福音 24:31; 约翰福音 5:28"> 在一剎那，在眨眼之间，在号角最后一次吹响之时。当号角吹响，死人就会复活成为不朽，我们将会改变。</span>
<span className="v" id="v53" data-v="53" data-xref="哥林多后书 5:2–4; 约翰一书 3:2; 罗马书 2:7"> 这必将腐朽之躯会实现不朽，这必死生命会获得永生。</span>
<span className="v" id="v54" data-v="54" data-xref="Isaiah 25:8; 启示录 20:14; 希伯来书 2:14–15"> 在拥有了不朽之衣后，这必将腐朽之躯就永远不会消亡。这必死生命在获得永生后，就应验了经文所记：“死亡已被彻底征服和消灭。</span>
<span className="v" id="v55" data-v="55" data-xref="Hosea 13:14; Psalms 89:48; 使徒行传 2:27"> 死亡啊！你的胜利到哪里去了？死亡啊！你的毒刺到哪里去了？”<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="见《以赛亚书》25:8；《何西阿书》13:14。">j</a></sup></span>
<span className="v" id="v56" data-v="56" data-xref="罗马书 4:15; 加拉太书 3:10–13; 罗马书 7:5–13"> 死亡的毒刺就是罪，罪的力量就是律法。</span>
<span className="v" id="v57" data-v="57" data-xref="哥林多后书 2:14; 罗马书 8:37; 约翰一书 5:4–5"> 感谢上帝，他通过主耶稣基督赐予我们胜利。</span>
<span className="v" id="v58" data-v="58" data-xref="加拉太书 6:9; 2 Chronicles 15:7; 希伯来书 6:10"> 所以我亲爱的兄弟姐妹们：要坚强，不可动摇，要尽你所能服务于主。要知道，你所做的一切，在主那里都不会付诸东流。</span>
</div>

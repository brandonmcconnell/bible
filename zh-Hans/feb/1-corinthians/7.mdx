<span className="v" id="v1" data-v="1" data-xref="哥林多前书 7:8; 哥林多前书 7:26–27; 哥林多前书 7:37–38"> 你们在信中提到： “不结婚最好。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="好像是有些科林斯人没有结婚，教会写信询问这样是否允许。">a</a></sup></span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 5:28; 以弗所书 5:33; 哥林多前书 7:9"> 但为了避免淫乱的诱惑，男人应当有自己的妻子，女人应当有自己的丈夫。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得前书 3:7; Exodus 21:10"> 丈夫应该满足妻子的性需求，而妻子应该满足丈夫的性需求。</span>
<span className="v" id="v4" data-v="4" data-xref="Hosea 3:3; 马太福音 19:9; 马可福音 10:11–12"> 妻子的身体不只属于她，还属于她的丈夫。同样，丈夫的身体不只属于他，还属于他的妻子。</span>
<span className="v" id="v5" data-v="5" data-xref="Exodus 19:15; Joel 2:16; Zechariah 12:12–14"> 夫妻不可剥夺拥有彼此身体的权力，除非暂时达成共识，比如需要花时间祈祷。此后仍然要住在一起，否则撒旦会趁着你们缺乏自控的时候，诱惑你们。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 8:8; 哥林多前书 7:25; 哥林多前书 7:12"> 我这番话并非命令，而是妥协。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 19:11–12; 罗马书 12:6; 哥林多前书 9:5"> 我希望人人都像我一样。但各人都有自己从上帝那里获得的恩赐，这恩赐也各有不同。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 7:32; 哥林多前书 7:34–35; 哥林多前书 7:26–27"> 我想对未婚者和寡妇说，他们最好能始终像我这样。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 7:2; 提摩太前书 5:14; 提摩太前书 5:11"> 但如果你缺乏自控力，就应当结婚，因为结婚总比被欲望吞噬好。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 5:32; 路加福音 16:18; 马太福音 19:3–9"> 我还要劝诫已婚之人（此言并非出自我，而是主的吩咐）：妻子不可离开丈夫。</span>
<span className="v" id="v11" data-v="11" data-xref="Jeremiah 3:1; 哥林多前书 7:10; Isaiah 50:1"> （离开就不可再嫁，或只能与丈夫复合。）丈夫也不可离弃妻子。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="早期教会面临一个特殊问题：配偶中一人为基督徒，如何与非基督徒结婚。这似乎就是这段文字想要解决的问题。">b</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 11:17; 哥林多前书 7:6; 哥林多前书 7:25"> 我还要对其他人说（此言是我的看法，并非来自主），倘若一名基督徒男人的妻子不信基督，但她愿意和他生活一起，他就不要离弃她。</span>
<span className="v" id="v13" data-v="13"> 如果一位基督徒女子的丈夫不信基督，但他愿意和她生活在一起，她也不要离弃丈夫。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="Malachi 2:15–16; 提摩太前书 4:5; 提多书 1:15"> 因为不信基督的丈夫会因妻子而圣洁，不信的妻子会因丈夫而圣洁了。否则，你们的后代便不洁净，但现在他们都变得圣洁。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="保罗这段话的意思，并不是说基督徒与非基督徒配偶结婚，就会让后者成为基督徒或实现救赎。他想要解决这样一个问题：与非基督教配偶结婚，是否会从某种方式玷污婚姻或影响基督徒的另一半。真正的问题是这种婚姻生出的孩子。这一点已经很清楚了：他们并不会“不纯洁”，而是会“圣洁的”，但没有提及孩子在灵方面的状态。">c</a></sup></span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 14:19; 哥林多后书 13:11; 雅各书 3:17–18"> 但如果不信基督的一方要离去，就由其去吧。在这种情形之下，基督徒男女不要勉强，因为上帝让我们生于平和。</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前书 3:1–2; 哥林多前书 9:22; 罗马书 11:14"> 做妻子的，你知道吗？你应该拯救你的丈夫！你做丈夫的，你知道吗？你应该拯救你的妻子！</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 4:17; 罗马书 12:3–8; 哥林多前书 7:24"> 除了这样的例子，主怎样安排你，就保持下去。上帝怎样召唤你，就继续这样的生活。我也这样教导其他教会。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 15:5; 使徒行传 15:28; 使徒行传 15:24"> 如果转变信仰时已经受了割礼？那就成为已受割礼的信徒。如果你转变信仰时未受割礼，那就做未受割礼的信徒。</span>
<span className="v" id="v19" data-v="19" data-xref="加拉太书 6:15; 加拉太书 5:6; 约翰一书 2:3–4"> 割礼不代表什么，未受割礼也不代表什么，最重要的是遵守上帝的命令。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 7:17; 帖撒罗尼迦前书 4:11; 帖撒罗尼迦后书 3:12"> 每个人受到上帝召唤时，都应当保持原来的状态。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“被召唤”，换言之就是转换信仰。">d</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="彼得前书 2:18–24; 歌罗西书 3:11; 路加福音 10:40–41"> 你被召唤时是奴仆？不要烦恼。但如果你获得自由的机会，就好好把握。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:16; 腓利门书 1:16; 歌罗西书 3:22–24"> 因为奴仆接受主的召唤后，就是属于主的自由人，你就为基督服务。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 6:20; 彼得前书 1:18–19; 提多书 2:14"> 上帝已经买下了你们，所以不要做人的奴仆。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 7:20; 歌罗西书 3:23–24; 哥林多前书 7:17"> 兄弟姐妹们，你们听到上帝的召唤时，就保持原来的状态，与上帝同在即可。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="哥林多前书 7:6; 哥林多前书 4:2; 哥林多前书 7:40"> 关于“未婚之人”，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原意为“处女。”保罗在这里继续讨论科林斯教会提出的问题。参见 7:1。">e</a></sup>我并未从主那里获得这方面的指引。但我既然获得了主的怜悯，是他信赖之人，我就需要表明我的意见。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多前书 7:1; 哥林多前书 7:8; 彼得前书 4:17"> 鉴于目前的困难情况，我认为人最好就是保持现状。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 7:20; 哥林多前书 7:12–14"> 已经结婚？就不要尝试离婚。还没有结婚？不要想办法结婚。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 13:4; 哥林多前书 7:32–36; 哥林多前书 7:26"> 如果你已经结婚，这不是罪。如果处女出嫁，也不是罪。但在当今世界中，你可能会遇到很多困难，我不希望你们受这样的苦难。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰一书 2:17; 哥林多前书 7:31; 罗马书 13:11–12"> 兄弟姐妹们，告诉你们吧，剩下的时间不多了。从今以后，结婚之人可能也像没有结婚，</span>
<span className="v" id="v30" data-v="30" data-xref="Psalms 30:5; 路加福音 6:25; 路加福音 6:21"> 哀哭之人不像在哀哭，快乐之人不像在快乐，买下东西的人仿佛从未拥有，</span>
<span className="v" id="v31" data-v="31" data-xref="约翰一书 2:17; 彼得前书 4:7; 雅各书 4:14"> 享用世界之人仿佛从未享用，因为这世界的秩序将会消失。<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="保罗在这一长段中指出，即使婚姻也必须与当代事件有关（“所剩时间不多了”）。由于生活在迫害之中，所以期待一切尽快结束，这意味着将以不同的方式看待婚姻和其他一切。">f</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马太福音 6:25–34; 提摩太前书 5:5; 腓立比书 4:6"> 我愿你们不会产生这样的忧愁。未结婚之人，应专注主最看重之事，要想着如何取悦主。</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前书 3:7; 歌罗西书 3:19; 以弗所书 5:25–33"> 但娶妻之人会关注人世间重要之事，想着如何取悦妻子，</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 10:40–42; 哥林多前书 6:20; 路加福音 2:36–37"> 这会让他的忠诚分心。同样，未婚妇女或少女要关注主最看重之事，好让身体和心灵都变得圣洁。但结婚的妇女就要为世上的事烦恼，想着如何取悦丈夫。</span>
<span className="v" id="v35" data-v="35" data-xref="哥林多前书 7:33–34; 哥林多前书 7:36; 路加福音 8:14"> 我说这些都是为了你们好，我并非想要对你们指手画脚，而是告诉你们如何行事才恰如其分，以便你可以一心一意地对主忠诚。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="哥林多前书 7:37; 哥林多前书 7:9; 1 Samuel 2:33"> 如果一个男人认为和订婚的女友做出越轨之事，如果他认为自己会被强烈的性欲望所控制，如果他认为自己应该结婚，这样的结婚并非罪过。</span>
<span className="v" id="v37" data-v="37"> 但如果他心意坚决，没有一定结婚的义务，可以控制自己的感受，在女友面前始终守身如玉，他不结婚也是对的。</span>
<span className="v" id="v38" data-v="38" data-xref="希伯来书 13:4; 哥林多前书 7:1–2; 哥林多前书 7:8"> 所以，与女朋友结婚是对的，不结婚则更好。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="罗马书 7:2–3; 哥林多后书 6:14–16; 哥林多前书 7:10"> 丈夫活着的时候，妻子需要受丈夫的约束。丈夫若死了，<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="这里使用的单词意为“入睡”，新约通常用这个词表达死亡。">g</a></sup>她就可以自由嫁人，嫁给信主之人。<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="意味着结婚双方都是基督徒。">h</a></sup></span>
<span className="v" id="v40" data-v="40" data-xref="哥林多前书 7:35; 彼得后书 3:15–16; 哥林多前书 7:8"> 但我认为，她不改嫁就会更有福报。我想这话也是来自上帝之灵的传达。</span>
</div>

<li id="fn-g"><a href="#fnref-g" className="fnb">g</a> <span className="fnr">7:39</span> 这里使用的单词意为“入睡”，新约通常用这个词表达死亡。</li>
<li id="fn-h"><a href="#fnref-h" className="fnb">h</a> <span className="fnr">7:39</span> 意味着结婚双方都是基督徒。</li>
</ol>

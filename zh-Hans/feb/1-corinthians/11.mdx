<span className="v" id="v1" data-v="1" data-xref="腓立比书 3:17; 帖撒罗尼迦前书 1:6; 哥林多前书 4:16"> 你们应该效法我，一如我效法基督。</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦后书 2:15; 哥林多前书 4:17; Proverbs 31:28–31"> 我感谢你们时刻记得我，感谢你们始终遵循我向你们宣讲的教义。</span>
<span className="v" id="v3" data-v="3" data-xref="Genesis 3:16; 歌罗西书 1:18; 歌罗西书 3:18"> 但是我希望你们理解，基督是男人的“头”，男人是女人的“头”，上帝是基督的“头。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这段话中的“头”到底怎样解释，存在很多争议。在圣经中，“头”可能与“来源”、“源头”或“权威”有关。">a</a></sup></span>
<span className="v" id="v4" data-v="4" data-xref="2 Samuel 15:30; 哥林多前书 12:28; 哥林多前书 12:10"> 男人的首领在祈祷或讲道时如果蒙着头，就是羞辱自己的头。</span>
<span className="v" id="v5" data-v="5" data-xref="Deuteronomy 21:12; 路加福音 2:36; 使徒行传 2:17"> 女人祷告或讲道时，如果不蒙着头，就是羞辱自己的头，因为这就好比剃发一般。</span>
<span className="v" id="v6" data-v="6" data-xref="Deuteronomy 22:5; Numbers 5:18"> 女人如果没有蒙着头，就应当剪去头发。如果女人以为剪发或剃头很羞耻，就应当蒙着头。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 11:3; Genesis 5:1; Psalms 8:6"> 男人不应蒙头，因为他是上帝的形象和荣耀，女人是男人的荣耀。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太前书 2:13; Genesis 2:21–23"> 因为男人并非来自女人，但女人却来自男人，</span>
<span className="v" id="v9" data-v="9" data-xref="Genesis 2:18; Genesis 2:23–24; Genesis 2:20"> 男人并非为女人而创造，女人却是为了男人而创造。</span>
<span className="v" id="v10" data-v="10" data-xref="Genesis 24:64–65; 希伯来书 1:14; 马太福音 18:10"> 因此，为了尊重守护天使，女人应当在头上显示权权威记号。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="正如许多圣经解读者所说，这是《新约》中最难理解和翻译的经文之一。有些人理解为“权威”，因为盖住头表明女人受人尊敬，在与男性的关系中拥有地位。还有人认为，这代表说话和预言的“权威性”，因为这不是妇女在这个社会中通常扮演的角色。对此还有其他许多解释，从字面上翻译为“由于天使。”">b</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="加拉太书 3:28; 哥林多前书 7:10–14; 哥林多前书 12:12–22"> 尽管如此，从主的角度来看，女人和男人一样重要，男人也和女人一样重要。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为：“尽管如此，在主面前没有女人也没有男人。”">c</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 11:36; 哥林多前书 8:6; 希伯来书 1:2–3"> 正如女人来自男人，男人也来自女人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="即回到创世纪时代，夏娃由亚当创造，但是从那时起，女人的生命由男性赋予。">d</a></sup>。但更重要的是，万物皆来自上帝。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:57; 约翰福音 7:24; 哥林多前书 10:15"> 你们可以自己判断一下，女人不蒙住头向上帝祷告是否合适？</span>
<span className="v" id="v14" data-v="14" data-xref="2 Samuel 14:26; 哥林多前书 14:35"> 男人留长发并非自然行为，是一种羞耻。</span>
<span className="v" id="v15" data-v="15"> 但女人留长发却可以给她带来荣耀吗？因为头发就像她的盖头。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 7:17; 提摩太前书 6:3–4; 帖撒罗尼迦前书 2:14"> 如果有人想要争论这个问题，他们应该意识到，这是教会遵循的唯一习惯。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="保罗这里所表示的“风俗”或“习惯”意思，而不是“规则”或“命令”解释，他以此明确表明，这只是教会在实践中的工作方式。">e</a></sup></span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 10:25; 哥林多前书 14:23; 哥林多前书 11:22"> 我现在做的是指引你们，而非称赞你们，因为当你们聚集在一起，带来的坏处远多于好处。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 3:3; 哥林多前书 1:10–12; 哥林多前书 5:1"> 首先，我听说你们在聚会的时候起了纷争，我相信这情况属实。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 2:19; 提多书 3:10; 使徒行传 20:30"> 你们当然会出现分党结派之事，这样可以真正显示出，那些真诚之人可以真正证明他们自己。</span>
<span className="v" id="v20" data-v="20"> 当你们聚集在一起，你们其实并不是在庆祝主的最后晚餐。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得后书 2:13; 犹大书 1:12; 哥林多前书 11:23–25"> 有人想要先于其他人进餐，让其他人仍然感到饥饿，还有人会喝醉。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 20:28; Proverbs 17:5; 雅各书 2:5–6"> 难道你们没有自己的家供你们吃喝吗？还是说，你们藐视上帝的教会，羞辱穷人？我该怎么和你们说呢？夸奖你们做得好吗？你们这样做，我不可能予以称赞。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 22:19–20; 马太福音 26:26–28; 哥林多前书 11:23–25"> 我向你们讲述的这一切，都来自主：在主耶稣被出卖的那一夜，他拿起饼，</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 6:53–58; 哥林多前书 11:27–28; 哥林多前书 10:3–4"> 在感谢后便掰开饼，说：“这饼就是我的身体，将赐予你们，你们要这样做来记住我。”</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 22:20; 希伯来书 9:15–20; 希伯来书 13:20"> 当晚他拿起酒杯，说：“这杯是以我的血订立的新盟约<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="这里通常被翻译为“盟约”，该词在现代英语中很少使用。它的含义就是双方之间达成的协议。在这里是指上帝与人之间的关系。">f</a></sup>，当你们饮酒的时候要记住我。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 9:28; 启示录 1:7; 约翰福音 14:3"> 每当你们吃这饼，喝这杯中酒，就是在讲述主的死，直到他回归。”</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 6:51; 哥林多前书 10:21; 希伯来书 10:29"> 因此，任何人如果以不光彩的方式吃主的饼，喝主的杯中酒，就是错对主的身体和主的血，应该感到罪恶感。</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太书 6:4; 哥林多后书 13:5; Lamentations 3:40"> 每个人在吃饼和饮这杯中酒时，都应该内省。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 11:27; 哥林多前书 11:30; 哥林多前书 11:32–34"> 因为吃喝之人如果没有意识到与主身体之间的关系，就会面临审判。</span>
<span className="v" id="v30" data-v="30" data-xref="启示录 3:19; Numbers 20:12; Amos 3:2"> 也是因为这个原因，你们中间有许多人软弱、患病、甚至死去。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰一书 1:9; Psalms 32:3–5; 启示录 2:5"> 但我们若认真内省，就不会像这样受到审判。</span>
<span className="v" id="v32" data-v="32" data-xref="希伯来书 12:5–11; Psalms 118:18; Proverbs 3:11–12"> 但当我们接受审判时，就是在接受他的管教，以免和世人一起被定罪。</span>
<span className="v" id="v33" data-v="33"> 所以我的兄弟姐妹们，你们聚集在一起吃下主的最后晚餐，要彼此等待。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 11:21–22; 哥林多前书 7:17; 哥林多前书 4:19"> 如果有人饥饿，应当在家里先吃，免得聚在一起时受到审判。我会在造访你们的时候，给予你们更多的指导。</span>

## 脚注

<ol className="fnl">
<li id="fn-a"><a href="#fnref-a" className="fnb">a</a> <span className="fnr">11:3</span> 这段话中的“头”到底怎样解释，存在很多争议。在圣经中，“头”可能与“来源”、“源头”或“权威”有关。</li>
<li id="fn-b"><a href="#fnref-b" className="fnb">b</a> <span className="fnr">11:10</span> 正如许多圣经解读者所说，这是《新约》中最难理解和翻译的经文之一。有些人理解为“权威”，因为盖住头表明女人受人尊敬，在与男性的关系中拥有地位。还有人认为，这代表说话和预言的“权威性”，因为这不是妇女在这个社会中通常扮演的角色。对此还有其他许多解释，从字面上翻译为“由于天使。”</li>
<li id="fn-c"><a href="#fnref-c" className="fnb">c</a> <span className="fnr">11:11</span> 原意为：“尽管如此，在主面前没有女人也没有男人。”</li>
<li id="fn-d"><a href="#fnref-d" className="fnb">d</a> <span className="fnr">11:12</span> 即回到创世纪时代，夏娃由亚当创造，但是从那时起，女人的生命由男性赋予。</li>
<li id="fn-e"><a href="#fnref-e" className="fnb">e</a> <span className="fnr">11:16</span> 保罗这里所表示的“风俗”或“习惯”意思，而不是“规则”或“命令”解释，他以此明确表明，这只是教会在实践中的工作方式。</li>
<li id="fn-f"><a href="#fnref-f" className="fnb">f</a> <span className="fnr">11:25</span> 这里通常被翻译为“盟约”，该词在现代英语中很少使用。它的含义就是双方之间达成的协议。在这里是指上帝与人之间的关系。</li>
</ol>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 12:13; 哥林多后书 8:1–9; 哥林多后书 9:12–15"> 让我们来说说“为信徒捐赠”的事情。我之前怎么嘱咐加拉太的众教会，现在就怎么嘱咐你们。</span>
<span className="v" id="v2" data-v="2" data-xref="Malachi 3:9–10; Deuteronomy 15:11–14; Deuteronomy 8:18"> 在每星期的第一天，你们所有人都要将自己赚的钱留下一部分。我不希望当我去见你们时，你们还要临时筹措。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 8:6; 哥林多前书 11:34; 哥林多前书 4:19–21"> 当我抵达那里之后，会为你们选中的人写推荐信，让他们把你们的捐款送到耶路撒冷。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 8:4; 哥林多后书 8:19; 罗马书 15:25"> 如果我也应该去，他们就可以与我同去。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 19:21; 哥林多前书 4:19; 哥林多后书 1:15–17"> 我此行将路过马其顿，之后就会去拜访你们，这条路刚好经过马其顿。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 15:3; 罗马书 15:24; 使徒行传 20:38"> 我也许会和你们同住一段时间，甚至会在那里过冬。之后你们就可以送我走，我将去往该去的地方。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 18:21; 哥林多前书 4:19; 雅各书 4:15"> 这一次我造访你们，打算多停留一段时间。如果主允许，我希望能多点时间和你们在一起。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 2:1; Exodus 23:16; 使徒行传 18:19"> 我将在以弗所住到五旬节，</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 2:12; 使徒行传 14:27; 歌罗西书 4:3"> 因为那里虽然仍有很多人反对我，但也有大量的机会之门向我敞开。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 15:58; 帖撒罗尼迦前书 3:2; 罗马书 16:21"> 如果提摩太抵达这里，务必不要让他因为与你们在一起而感到害怕，因为他和我一样都服务于主。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 4:12; 使徒行传 15:33; 提多书 2:15"> 不要让任何人低看他，要高高兴兴地送他走，让他可以到我这里来，我和这里的兄弟姐妹们都在等他到来。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 1:12; 哥林多前书 3:5; 提多书 3:4"> 至于亚波罗兄弟，我曾再三劝他和其他信徒一起去见你们，但他目前还不是很愿意这么做。待等到机会后，他便会去造访你们。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="Joshua 1:9; 以弗所书 6:13–18; 以弗所书 6:10"> 请保持警惕，要立场坚定地相信上帝。要勇敢，要坚强。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 13:34–35; 彼得前书 4:8; 提摩太前书 1:5"> 你们所做的一切都出自于爱。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 1:16; 罗马书 16:5; 罗马书 16:2"> 知道吗？司提芬一家人是亚该亚第一批改变信仰的信徒之一，将自己奉献于帮助上帝的子民。我的兄弟姐妹们，劝你们</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 13:17; 帖撒罗尼迦前书 5:12; 约翰三书 1:8"> 要尊重他们的引领，尊重在这份工作中以这种奉献精神提供帮助的所有人。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 11:9; 腓立比书 2:30; 腓利门书 1:13"> 很高兴司提芬、福徒拿都和亚该古都到这里来了，因为他们能够弥补你们的不足，</span>
<span className="v" id="v18" data-v="18" data-xref="腓利门书 1:7; 哥林多后书 7:13; 帖撒罗尼迦前书 5:12"> 他们让我备受鼓舞，你们也应该和我有同感。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 18:2; 腓利门书 1:2; 罗马书 16:3–5"> 亚西亚的众教会<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="即罗马小亚细亚省。">a</a></sup>问候你们。亚居拉和百基拉、以及他们家中与主同在的教会，也送去了他们最美好的祝愿。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 16:16; 帖撒罗尼迦前书 5:26; 彼得前书 5:14"> 这里所有的兄弟姐妹们都送去问候。以最热情的方式问候彼此。</span>
<span className="v" id="v21" data-v="21" data-xref="歌罗西书 4:18; 加拉太书 6:11; 帖撒罗尼迦后书 3:17"> 撰写这封信的我、也就是保罗，也在此送去问候。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 6:24; 约翰福音 14:21; 哥林多后书 5:14–15"> 不爱主之人应从教会中驱逐。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为：“让他受到指责。”">b</a></sup>主啊，请降临吧！</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 16:20; 罗马书 16:23"> 愿主耶稣基督的恩典与你们同在。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 14:16; 启示录 3:19; 哥林多后书 12:15"> 我以基督耶稣之名爱你们所有人。阿门。</span>
</div>

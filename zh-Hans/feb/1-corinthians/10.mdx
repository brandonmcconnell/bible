<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Exodus 14:29; Nehemiah 9:11–12; Psalms 78:13–14"> 兄弟姐妹们，让我来向你们解释这一点。我们的先祖都曾居于云下，都曾穿海而过。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="上帝所在的云，以及穿越红海的通道。">a</a></sup></span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 3:2–3; 哥林多前书 1:13–16; Exodus 14:31"> 他们都曾在云中和海里由摩西受洗，这是一种象征性的仪式。</span>
<span className="v" id="v3" data-v="3" data-xref="Deuteronomy 8:3; Nehemiah 9:15; Exodus 16:35"> 他们享用着同样的灵性食粮，</span>
<span className="v" id="v4" data-v="4" data-xref="Exodus 17:6; 约翰福音 7:37; Isaiah 48:21"> 都曾饮用同样的灵性之水，因为他们“饮用来自磐石之水。”这磐石与他们同在，这磐石就是基督。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 3:17; 犹大书 1:5; Numbers 14:37"> 但他们中大多数人都无法获得上帝的喜悦，因此最终死于荒野。</span>
<span className="v" id="v6" data-v="6" data-xref="犹大书 1:7; 哥林多前书 10:11; 希伯来书 4:11"> 我们应该引以为戒，不要像他们那样贪恋恶行。</span>
<span className="v" id="v7" data-v="7" data-xref="Exodus 32:6–8; Psalms 106:19–20; 哥林多前书 6:9"> 你们也不可像他们中的某些人那样膜拜神像。正如经文所说：“民众大吃大喝，沉迷异教膜拜。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="见《出埃及记》32:6。">b</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="Numbers 25:1–9; 哥林多前书 6:18; Psalms 106:29"> 我们不要像他们中的某些人那样行淫乱之事，这导致一天就有二万三千人死去。</span>
<span className="v" id="v9" data-v="9" data-xref="Numbers 21:5–6; Psalms 78:18; 希伯来书 3:8–11"> 我们不要像他们中的某些人那样试探主，结果亡命于蛇口。</span>
<span className="v" id="v10" data-v="10" data-xref="Numbers 14:2; Numbers 16:41; Numbers 14:37"> 我们不要像他们中的某些人那样埋怨上帝，最终亡于毁灭天使手中。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 15:4; 罗马书 13:11; 哥林多前书 9:10"> 所有发生在他们身上的事情都要作为我们的警示，要将其记下来，惊醒我们这些生于末世之人。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 11:20; 彼得后书 3:17; Proverbs 16:18"> 所以如果你认为自己站得稳，要小心，免得跌倒！</span>
<span className="v" id="v13" data-v="13" data-xref="彼得后书 2:9; 提摩太后书 4:18; 帖撒罗尼迦后书 3:3"> 你们经历的试探不会超过任何其他人。上帝值得信赖，他不会允许超出你们承受能力的试探。在受试探的时候，他必定给你们打开一条出路，让你们可以保持强壮。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 21:8; 约翰一书 5:21; 彼得前书 2:11"> 所以我的朋友们，要远离神像膜拜。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 8:1; 帖撒罗尼迦前书 5:21; 哥林多前书 11:13"> 我与明白事理之人讲述，你们来决定我所说的是否是真理。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 26:26–28; 哥林多前书 11:23–29; 使徒行传 2:42"> 我们感谢主在最后晚餐中所使用的酒杯，难道不是分享基督的血吗？当我们掰开饼分享的时候，难道不是共享基督的身体吗？</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 12:5; 歌罗西书 3:15; 哥林多前书 12:27"> 通过共享一块饼，显示出尽管我们人数虽多，但我们分享一个身体。</span>
<span className="v" id="v18" data-v="18" data-xref="腓立比书 3:3–5; 加拉太书 6:16; Leviticus 7:6"> 看看以色列人，那些吃下祭物的人，不就是一起在祭坛处分享吗？</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 8:4; 哥林多前书 3:7; 哥林多前书 13:2"> 那么我要表达什么意思？我是说为神像牺牲会有意义？还是神像本体真实存在？当然不是！</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 9:20; Psalms 106:37–39; Deuteronomy 32:16–17"> 异教徒向魔鬼献祭，而非上帝，但我不想与魔鬼有任何关系。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 6:24; 1 Kings 18:21; 哥林多后书 6:15–17"> 你们不能喝主的酒杯，又喝魔鬼的酒杯。你们不能参加主的宴席，又参加魔鬼的宴席。</span>
<span className="v" id="v22" data-v="22" data-xref="Deuteronomy 32:21; Deuteronomy 32:16; 希伯来书 10:31"> 难道我们想要激起主的嫉妒吗？我们比他更强大吗？</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 6:12; 哥林多前书 8:9; 以弗所书 4:29"> 有人说：“我有做事的自由”，但不是每一件事都恰当！“我有做事的自由”，但不是每一件事都有益处。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="见6:12。">c</a></sup></span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 15:1–2; 哥林多前书 10:33; 腓立比书 2:4–5"> 你不应只为自己着想，而是要为邻里着想。</span>
<span className="v" id="v25" data-v="25" data-xref="提摩太前书 4:4; 哥林多前书 8:7; 提多书 1:15"> 市场中卖什么就吃什么，不要为了良心的缘故问什么，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="这又回到了向神像献祭食物的问题。">d</a></sup></span>
<span className="v" id="v26" data-v="26" data-xref="Psalms 24:1; Exodus 19:5; Psalms 50:12"> 因为“大地和大地上的一切都属于上帝。”<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="引自《诗篇》24:1。">e</a></sup></span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 10:25; 路加福音 10:7–8; 哥林多前书 5:9–11"> 如果一个不信基督的人请你吃饭，你也应该愿意去，摆在你面前的，都可以享用，不要因为良心而问什么。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 8:10–13; 哥林多前书 8:7; 哥林多前书 10:26"> 但是如果有人告诉你们：“这是曾献祭的食物。”那么，为了告诫你的这个人着想，也为了良心的缘故，就不要吃。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 9:19; 罗马书 14:15–21; 哥林多前书 8:9–13"> 这里所说的，是他的良心。为什么我的自由要由别人的良心决定呢？<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="这个问题似乎与之前的经文不一致。无论是因吃了祭祀的肉而感到被冒犯，或是因为神像中的“神”并不存在而认为这样做没问题，保罗都主张应该宽容对待。">f</a></sup></span>
<span className="v" id="v30" data-v="30" data-xref="罗马书 14:6; 提摩太前书 4:3–4"> 我若以感恩之心吃下这食物，为什么要因我所感恩的食物而被其他人批判？</span>
<span className="v" id="v31" data-v="31" data-xref="歌罗西书 3:17; 歌罗西书 3:23; 彼得前书 4:11"> 所以，无论你吃喝什么，无论你做什么，一切都要以上帝的荣耀而行。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 20:28; 哥林多前书 10:33; 罗马书 14:13"> 无论是犹太人、希腊人或上帝的教会，不要让他们感到冒犯，</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 10:24; 加拉太书 1:10; 哥林多前书 9:19–23"> 就像我努力让大家都获得喜悦。不是想什么对自己有好处，而是应该对别人有好处，以便他们可以获得拯救。</span>
</div>

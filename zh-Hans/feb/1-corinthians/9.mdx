<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 9:17; 提摩太前书 2:7; 哥林多前书 9:19"> 我不自由吗？我不是使徒吗？我没有见过主耶稣吗？你们不是与主同在的结果吗？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 12:12; 约翰福音 6:27; 哥林多后书 3:1–3"> 对别人来说我或许不是使徒，但对你们来说，我至少是使徒的一份子，你们就是我作为主使徒的证据。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 12:16–19; 哥林多后书 13:3; 哥林多后书 13:10"> 如果有人质疑我这一点，我会这样回答。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 2:6; 帖撒罗尼迦后书 3:8–9; 路加福音 10:7"> 难道我们没有权力吃喝吗？</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 1:42; 希伯来书 13:4; 马太福音 8:14"> 难道我们没有权利像其他使徒、主的兄弟和彼得一样，与基督徒的妻子相伴吗？</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦后书 3:7–9; 使徒行传 13:1–2; 使徒行传 4:36"> 难道只有我和巴拿巴必须靠工作养活自己吗？<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文以双重否定的形式表达。建议这样理解：只有保罗和巴拿巴没有得到无需工作的特权。">a</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="Proverbs 27:18; Deuteronomy 20:6; 提摩太后书 2:3–4"> 哪个士兵必须支付其薪水？哪个葡萄园主不允许吃自己园子里的葡萄？哪个牧羊人不允许喝自己羊群的羊奶呢？</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="Isaiah 8:20; 帖撒罗尼迦前书 4:8; 罗马书 3:31"> 我这样说难道是人类的观点吗？律法不也是这样说？</span>
<span className="v" id="v9" data-v="9" data-xref="Deuteronomy 25:4; 提摩太前书 5:18; Psalms 104:27"> 摩西的律法这样写道：“牛在踩踏去谷壳的时候，不可套住它的嘴。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引自《申命记》25:4。">b</a></sup>难道上帝说的只是牛吗？</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太后书 2:6; 罗马书 15:4; 罗马书 4:23–24"> 他难道不是在指引我们吗？当然这就是说给我们听的，因为耕种之人应心存希望去耕种，收割之人应心存希望去分享收获。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 15:27; 加拉太书 6:6; 哥林多后书 11:15"> 我们在你们中间播撒灵性的种子，如果我们想要从中收获一些物质好处，这算过分吗？</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 9:15; 哥林多前书 9:18; 哥林多后书 11:12"> 如果别人对你们享有这种权利，我们不是更有权享有吗？尽管如此，我们从未使用过这种权利。相反，我们凡事忍耐，避免妨碍基督福音的传播。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="Numbers 18:8–20; Numbers 5:9–10; Leviticus 6:26"> 难道你们不知道吗？在圣殿供职之人会吃殿中的供物。侍候祭坛之人会领取他们应得的那份祭物。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 10:10; 提摩太前书 5:17–18; 哥林多前书 9:4"> 主也曾这样祝福传递福音之人，应该靠福音的支持者为生。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 2:9; 帖撒罗尼迦后书 3:8; 哥林多前书 9:12"> 但我从未使用过这种权利。我这样说并非希望别人应该如此待我，因为不去寻求这样的好处是我的荣耀，我宁愿舍弃性命也不愿丢了这荣耀。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="罗马书 1:14; Jeremiah 20:9; 歌罗西书 4:17"> 传播福音并没有任何可以夸耀支出，因为我无法不去这么做。如果不传播福音，对我将是一场灾难。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 2:7; 哥林多前书 3:8; 1 Chronicles 28:9"> 如果我自己选择这样做，就会获得赏赐。即使不是我本意选择，这职责就是对我的托付。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 11:7–9; 哥林多前书 8:9; 帖撒罗尼迦前书 2:6"> 那么，我的赏赐是什么？那就是当我传播福音时，让大家免费获得福音，而不是要求享有传递福音应有的权力。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="加拉太书 5:13; 马太福音 18:15; 雅各书 5:19–20"> 我虽然自由，不服务于任何人，但我自愿成为众人的奴仆，只为让更多人听到福音。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 16:3; 加拉太书 5:18; 使徒行传 21:20–26"> 面对犹太人，我就像犹太人一样行事，以便可以说服犹太人。面对律法制约之人，虽然律法并不会管辖我，但我还是像受律法制约的人一样行事，以便说服他们。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 2:12; 罗马书 2:14; 加拉太书 3:2"> 如果一个人没有根据律法行事，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="指那些不是犹太人、不遵守摩西律法之人。">c</a></sup>我就像不受律法制约之人一样（这样做并非不遵守上帝律法，而是遵守基督的律法），从而说服未受律法制约之人。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 10:33; 罗马书 15:1; 哥林多前书 9:19"> 对软弱的人，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="可能是指 8:7 句及以后的“较脆弱信徒”问题。">d</a></sup>我就像他们一样软弱，以便说服软弱之人。最终我面对的人如何，我就成为怎样的人，想方设法说服一些人！</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太后书 2:10; 马可福音 8:35; 哥林多前书 9:25–27"> 我所作的一切都是为了福音，为了与他人同享福音的福报。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="腓立比书 3:14; 希伯来书 12:1; 提摩太后书 4:7–8"> 难道你们不知道吗？赛跑比赛中有很多选手，虽然大家都跑，但却只有一人能获奖吗？你们应当尽全力奔跑，以便可以获奖。</span>
<span className="v" id="v25" data-v="25" data-xref="提摩太后书 2:5; 启示录 2:10; 提摩太后书 4:7–8"> 参加比赛的选手，需要严格遵循训练方法。他们这样做，不过是为了赢得最终会坏掉的冠冕，我们要的却是不朽的冠冕。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="彼得后书 1:10; 腓立比书 1:21; 提摩太后书 2:5"> 所以我要向正确的方向奔跑，我要准确地击打，而不是击打空气。</span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 8:13; 哥林多前书 9:25; 歌罗西书 3:5"> 我严格对待自己的身体，让它听我的控制，因为我不想在与所有人分享福音后，自己却没有了传递福音的资格。</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 5:13; 哥林多前书 2:14–15; 以弗所书 4:13–14"> 兄弟姐妹们，之前与你们交流之时<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="可能是他以前去拜访他们的时候。">a</a></sup>，无法把你们当作圣灵信徒，只能将你们视为俗世中人，就像婴儿时的基督。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 5:11–14; 约翰福音 16:12; 彼得前书 2:2"> 我喂养你们的是牛奶，不是饭菜，因为那时你们还没有准备好。</span>
<span className="v" id="v3" data-v="3" data-xref="雅各书 3:16; 加拉太书 5:15; 提多书 3:3"> 即使现在，你们仍然没有准备好，仍是俗世中人。因为你们仍然会嫉妒纷争，你们的行为就像普通人一样，难道不是说明，你们仍然是俗世中人吗？</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 1:12; 哥林多前书 3:3; 哥林多前书 4:6"> 有人说“我追随保罗”，有人说“我追随亚波罗”，这正说明你们仍然是普通凡人。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 6:4; 哥林多后书 6:1; 彼得前书 4:10"> 亚波罗是谁？保罗是谁？我们不过是你所信仰之人的仆人，每个人都按照上帝的要求行事。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 3:9–10; Proverbs 11:25; 哥林多后书 10:14–15"> 我负责栽种，亚波罗负责浇灌，但只有上帝才能让它生长！</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约翰福音 15:5; 加拉太书 6:3; Psalms 115:1"> 所以，栽种和浇灌之人没什么了不起，真正了不起的，是让你成长的上帝。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 2:6; 马太福音 16:27; 约翰二书 1:8"> 栽种的和浇灌之人都有着同样的目标，只是按照其付出的努力获得酬劳。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="彼得前书 2:5; 以弗所书 2:20–22; 哥林多后书 6:1"> 我们是与上帝共同劳作的工人，你们是上帝的田地，上帝的房屋。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 3:11; 以弗所书 2:20; 罗马书 15:20"> 通过上帝赐给我的恩典，我就像娴熟的建筑师打下根基，现在由其他人在上面建造。建造之人要小心自己的一举一动。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 2:20; Isaiah 28:16; 提摩太后书 2:19"> 因为除了已经打好的根基——即耶稣基督，任何人都不能立下其他根基。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太后书 4:3; 提摩太后书 3:7; 提摩太后书 2:20"> 如果有人用金银、宝石、木头、枯草或稻秆在根基上建造，</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前书 1:7; 哥林多前书 3:14–15; 启示录 20:12"> 所使用的材料早晚都会显露，因为当审判日到来，它们会在火焰中显现并经受考验。每个人的工作都会显现出它本来的样子。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 3:8; 马太福音 25:21–23; 哥林多前书 4:5"> 如果你的建筑经得起考验，就会得到赏赐。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰二书 1:8; 哥林多前书 3:12–13; 犹大书 1:23"> 如果你的建筑被烧毁，就会遭受损失。他们仍然会获得拯救，但却像穿越火焰一样。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 6:19; Ezekiel 36:27; 哥林多后书 6:16"> 难道你不知道吗？你就是上帝的圣殿，上帝之灵就在你们心中。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 6:18–20; Ezekiel 43:12; Numbers 19:20"> 毁坏上帝圣殿之人，上帝必摧之，因为上帝之殿为圣洁之地，这圣殿就是你。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="Proverbs 3:5; Isaiah 5:21; 加拉太书 6:3"> 不要自欺欺人。如果你自诩拥有人间的智慧，就应该变为愚人，这样才是真正的智慧。</span>
<span className="v" id="v19" data-v="19" data-xref="Job 5:13; Psalms 141:10; 哥林多前书 1:19–20"> 因为对于上帝而言，人间的智慧都是愚蠢。正如经书所言：“他让智慧之人的聪明，让他们犯错。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="见《约伯记》5:13。">b</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="Psalms 94:11; 歌罗西书 2:8; 罗马书 1:21"> 经书还说：“主知道智慧之人的辩论毫无意义。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《诗篇》94:11。">c</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 8:32; 罗马书 8:28; Jeremiah 9:23–24"> 所以不要夸耀人，因为你们拥有一切，</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 4:11–12; 腓立比书 1:21; 哥林多前书 9:19–22"> 无论是保罗、亚波罗或矶法，无论是世界、是生还是死，是现在或是将来，都是如此。你们拥有一切，</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 3:29; 哥林多前书 11:3; 约翰福音 17:9–10"> 你们都为基督所有，基督则为上帝所有。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 8:26–39; 马太福音 8:28–34; 马可福音 4:35"> 他们到了海的另一边，进入格拉森人的地区。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 1:23; Isaiah 65:4; 马可福音 5:8"> 耶稣下船时，就有一个恶灵附体之人，从墓地向着他们走来。</span>
<span className="v" id="v3" data-v="3" data-xref="Isaiah 65:4; 路加福音 8:29; Daniel 4:32–33"> 那人住在坟墓中间，从来没有人能束缚他，即使锁链也不行。</span>
<span className="v" id="v4" data-v="4" data-xref="雅各书 3:7–8"> 人们经常用脚镣和锁链锁住他，但他会挣断锁链，弄碎脚镣，始终没有人能制伏他。</span>
<span className="v" id="v5" data-v="5" data-xref="Job 2:7–8; 1 Kings 18:28; 约翰福音 8:44"> 他昼夜不停地在坟墓里和山野间喊叫，用尖锐的石头割自己的身体。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 2:19; Psalms 66:3; 路加福音 4:41"> 远远看见耶稣，他就跑过去跪在耶稣面前，</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 8:29; 使徒行传 16:17; 马太福音 26:63"> 大声呼叫：“至高上帝之子耶稣，你又能拿我怎么办呢？向上帝发誓，你不会叫我受苦。”</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 1:25; 马可福音 9:25–26; 使徒行传 16:18"> 耶稣命令恶灵离开那男人，</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 8:30; 马可福音 5:15; 马太福音 26:53"> 然后问他：“你叫什么名字？” 他回答：“我是‘群魔’，因为我们的数量众多。”</span>
<span className="v" id="v10" data-v="10" data-xref="马可福音 3:22; 马可福音 5:13"> 他再三央求耶稣，不要把他们从那地方赶走。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为：离开这个地区。">a</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="Leviticus 11:7–8; Isaiah 65:4; Isaiah 66:3"> 附近的山坡上有一大群猪，大约有两千头，正在吃东西。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 2:11; Job 1:10–12; 路加福音 22:31–32"> 恶灵求耶稣说：“把我们打发到猪群身上吧。”</span>
<span className="v" id="v13" data-v="13" data-xref="1 Kings 22:22; 彼得前书 3:22; Job 2:6"> 耶稣答应了他的要求。将所有恶灵引出来，送到猪群里去。于是那群猪闯下山崖，掉在海里淹死了。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 8:34; 马太福音 8:33"> 猪倌跑开了，到城里和乡村奔走相告，人们纷纷过来查看发生了什么事。</span>
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 1:13; 提摩太后书 1:7; 1 Samuel 6:20–21"> 他们来到耶稣跟前，看见那曾被恶灵附体之人坐在那边。这个曾被众多恶灵附体之人已经穿上了衣服，神志清醒。眼前的一幕让大家害怕！</span>
<span className="v" id="v16" data-v="16"> 有些人曾目睹这个恶灵附体之人的遭遇，也亲眼见到那群猪的下场，于是将其告诉新来的人。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 8:34; 马可福音 1:24; 路加福音 8:37"> 他们开始要求耶稣离开他们的地区。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 8:38–39; 腓立比书 1:23–24; 马可福音 5:17"> 耶稣上船的时候，那个曾被魔鬼附体之人求他，希望一路跟随。</span>
<span className="v" id="v19" data-v="19" data-xref="Psalms 66:16; 约翰福音 4:29; Isaiah 38:9–20"> 但耶稣拒绝了，对他说：“回自己家吧，告诉大家主为你做了一件多么伟大的事，他如何怜悯你。”</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 7:31; 马太福音 4:25"> 于是那人走了，开始在低加波利地区讲述耶稣为他所做的伟大善行，众人纷纷称奇。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 9:1; 马可福音 4:1; 路加福音 8:40"> 耶稣又坐船返回，来到湖的另一侧，一大群人围拢过来。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 13:14; 使徒行传 18:8; 马可福音 5:35–36"> 这时来了一位名叫睚鲁的会堂主管，看见耶稣后，马上俯伏在他脚前，</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 13:13; 路加福音 4:40; 马可福音 16:18"> 恳求他说：“我的小女儿快要死了，请你来将手放在她身上，把她救活吧。”</span>
<span className="v" id="v24" data-v="24" data-xref="马可福音 5:31; 马可福音 3:20; 路加福音 7:6"> 耶稣和他一起走了，众人跟着他，簇拥着他。</span>
<span className="v" id="v25" data-v="25" data-xref="Leviticus 15:25–27; 路加福音 8:43–44; 马太福音 9:20–22"> 有一个女人患了十二年的血漏病，</span>
<span className="v" id="v26" data-v="26" data-xref="Jeremiah 30:12–13; Jeremiah 8:22; Psalms 108:12"> 曾看过很多医生，受了许多苦，花光了所有积蓄，但仍毫无起色，甚至越来越严重。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 19:12; 马太福音 14:36; 使徒行传 5:15"> 她听见耶稣的事，就从耶稣身后的人群中走出来，抚摸耶稣的衣服。</span>
<span className="v" id="v28" data-v="28"> 她对自己说：“只要摸到他的衣服，我就必痊愈。”</span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 5:34; Psalms 30:2; 马可福音 3:10"> 于是她的血漏立刻停止，感觉自己的身体已经治愈。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 6:19; 路加福音 8:46; 路加福音 5:17"> 这个过程中，耶稣感到有一股力量从他身体流走，于是转过身问民众：“谁摸了我的衣服？”</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 8:45; 路加福音 9:12"> 门徒对他说：“看看这么多人簇拥你，你问‘谁触摸我’又是什么意思？”</span>
<span className="v" id="v32" data-v="32"> 耶稣环顾四周，看到了刚才触摸他衣服的女人。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 8:47; 路加福音 1:29; 路加福音 1:12"> 那女人意识到自己身上发生的事情，于是走上前匍匐在耶稣面前，告诉他实情。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 8:48; 马太福音 9:22; 路加福音 7:50"> 耶稣对她说：“我的女儿，你对我的信心治愈了你，平安地回去吧，你的病已经完全好了。”</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 8:49; 约翰福音 11:39; 马可福音 5:22"> 耶稣说话的时候，有人从会堂主管的家赶来。他们说：“你的女儿已经死了，不必再麻烦老师了。”</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 8:50; 马太福音 9:28–29; 约翰福音 11:40"> 但耶稣并未在意这番话，就对会堂主管说：“不要怕！相信我好了！<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“在我体内”的隐喻之意。">b</a></sup>”</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 9:40; 马可福音 14:33; 哥林多后书 13:1"> 他向主管家中走去，但不许别人跟随，只带了彼得、雅各和雅各的弟弟约翰。</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 9:23–24; 路加福音 8:52–53; 马可福音 5:22"> 他们来到会堂主管的家，耶稣看见许多人哭泣哀号，一片混乱，</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 20:10; 帖撒罗尼迦前书 5:10; 帖撒罗尼迦前书 4:13–14"> 他走进去对众人说：“为什么大哭大嚷呢？这小女孩没有死，只是睡着了。”</span>
<span className="v" id="v40" data-v="40" data-xref="Nehemiah 2:19; 2 Kings 4:33; 马太福音 9:24–25"> 众人嘲笑他。耶稣让众人离开，带着孩子的父母和三名门徒，进入孩子的房间。</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 1:31; 路加福音 7:14–15; 路加福音 8:54–55"> 耶稣拉着小女孩的手，对她说：“大利大，古米！”（意为：小女孩，起来吧！）</span>
<span className="v" id="v42" data-v="42" data-xref="马可福音 4:41; 使徒行传 3:10–13; 马可福音 7:37"> 这十二岁的女孩就立刻站起来开始行走，众人惊讶万分。</span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 8:4; 马太福音 9:30; 马可福音 1:43"> 耶稣严厉地嘱咐他们，不要让其他人知道这事，又告诉他们给女孩吃点东西。</span>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="feb" data-translation-id="cmn_feb" data-translation-label="易读圣经" data-book="MRK" data-book-slug="mark" data-book-name="马可福音" data-chapter="12" data-verses="44">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Isaiah 5:1–4; 马可福音 13:34; Song of Solomon 8:11–12"> 耶稣又开始用比喻故事向他们讲述：<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="见 3:23。">a</a></sup>“一个人有个葡萄园，他在四面围上篱笆，挖了一个压酒池，盖了一座瞭望台，租给几名农户后就远行去了。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="约翰福音 15:1–8; 希伯来书 1:1; Jeremiah 44:4"> 丰收时节，这位园主派了一名仆人到农户那里，收取园子里的一部分葡萄。</span>
<span className="v" id="v3" data-v="3" data-xref="帖撒罗尼迦前书 2:15; Nehemiah 9:26; Jeremiah 29:26"> 但农户却把这个仆人抓起来打了一顿，让他空手而归。</span>
<span className="v" id="v4" data-v="4"> 园主又派一个仆人过去，农户们打伤了他的头，还侮辱他。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 22:6; 马太福音 23:37; Nehemiah 9:30"> 园主再派一人，这次农户直接把他杀死。之后派去了许多仆人，有的被他们打伤，有的被他们杀掉。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 1:1–2; 马太福音 3:17; 约翰福音 1:34"> 最后，园主派自己的孩子过去，心想说：‘他们总是会尊敬我的儿子吧。’</span>
<span className="v" id="v7" data-v="7" data-xref="Genesis 37:20; 马太福音 2:16; 使徒行传 2:23"> 但农户们却彼此商量：‘这人会继承园主的产业，如果我们杀了他，产业就是我们的了。’</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 21:39; 路加福音 20:15; 马太福音 21:33"> 他们于是抓住园主的儿子把他杀掉，扔到葡萄园外。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 10:20–12; 马太福音 21:43; 路加福音 19:27"> 那么，葡萄园主该怎么办？他会跑来杀掉这些农户，把葡萄园租给别人。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="Psalms 118:22–23; 彼得前书 2:7–8; Isaiah 28:16"> 你们应该念过那段经文：‘建筑工人丢弃的石头，会成为房子的基石。’</span>
<span className="v" id="v11" data-v="11" data-xref="Psalms 118:23; 使徒行传 3:12–16; Habakkuk 1:5"> 这来自于主，在我们看来就是奇迹！”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引自《诗篇》118:22-23。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马可福音 11:18; 马太福音 22:22; 约翰福音 7:44"> 那几名犹太领袖知道，耶稣的比喻就是针对他们，于是想要捉拿他，但因为害怕民众，只好离开了。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 20:20–26; 路加福音 11:54; 马可福音 3:6"> 后来，他们派了几名法利赛人和希律的支持者到耶稣那里去，想从他的话语中找出把柄陷害他。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:4; 路加福音 20:22; 约翰福音 7:18"> 他们过来之后说：“老师，我们知道你为人诚实，从不在乎别人的认可，因为你无畏权势地位，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“你不在乎其他人，因为你从不看人脸色。”但这种直译会显得耶稣不关心别人，生性冷漠。">c</a></sup>只依据真理讲述上帝之道。那么请问，向凯撒纳税是否正确？</span>
<span className="v" id="v15" data-v="15" data-xref="Ezekiel 17:2; 启示录 2:23; 马可福音 10:2"> 我们是该交税呢还是拒绝？”<br />耶稣看出他们的虚伪，就对他们说：“为何要试探我？拿个银币给我，我来看看。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 20:24–26; 启示录 3:12; 马太福音 22:19–22"> 于是他们拿来一个银币。耶稣问：“这上面是谁的头像，谁的刻字？”他们回答他：“凯撒。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 13:7; 彼得前书 2:17; 哥林多后书 5:14–15"> 耶稣说：“是凯撒的就应属于凯撒，是上帝的就应属于上帝。”这番话让那些人感到很震惊。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 22:23–33; 使徒行传 4:1–2; 使徒行传 23:6–9"> 撒都该人向来不相信复活一事，他们来到耶稣那里，问他：</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="Deuteronomy 25:5–10; Ruth 4:5; Ruth 1:11–13"> “老师，摩西曾写道：如果一个男人死了，留下妻子，但没有儿女，他弟弟就应当娶他的妻子，为哥哥留后。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="见《申命记》25:5。">d</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 22:25–28; 路加福音 20:29–33"> 从前有兄弟七人，老大娶了妻子后死了，没有留下子嗣；</span>
<span className="v" id="v21" data-v="21"> 老二娶了这寡妇，没等到生下孩子也死了；第三个也是这样。</span>
<span className="v" id="v22" data-v="22"> 事实上，那七个兄弟都和她结过婚，但都没等留下孩子就死了，最后那女人也死了。</span>
<span className="v" id="v23" data-v="23"> 到了复活之时，如果他们都复活，她算是谁的妻子呢？因为七个人都娶过她。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约翰福音 20:9; 提摩太后书 3:15–17; 马太福音 22:29"> 耶稣对他们说：“你们错了，因为你们根本不理解经文的意思，也不知道上帝的力量。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 20:35–36; 马太福音 22:30; 约翰一书 3:2"> 因为人死后复活，将不娶不嫁，而是如天国的天使一样。</span>
<span className="v" id="v26" data-v="26" data-xref="Exodus 3:2–6; 路加福音 20:37; Genesis 17:7–8"> 关于死人复活的问题，摩西讲过一个关于荆棘的故事，上帝对摩西说：‘我是亚伯拉罕的上帝，以撒的上帝，雅各的上帝<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="见《出埃及记》3:2-6。">e</a></sup>。’你们没看过这个故事吗？</span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 14:9; 罗马书 4:17; 马可福音 12:24"> 他不是死人的上帝，而是活人的上帝。你们真是大错特错！”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马太福音 22:34–40; 路加福音 10:25–28; 路加福音 20:39"> 一个宗教老师走过来，听他们的辩论。他意识到耶稣给出了好的回答，于是就问：“诫命中哪一条最重要？”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="Deuteronomy 6:4; 路加福音 10:27; 加拉太书 3:20"> 耶稣回答：“最重要的是：‘以色列啊，请听好！主，我们的上帝，我们唯一的主。</span>
<span className="v" id="v30" data-v="30" data-xref="Deuteronomy 6:5"> 你要全心、全性、全意、全力地爱主，爱你的上帝。’<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="引自《申命记》6:4。">f</a></sup></span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 13:8–9; 马太福音 22:39; Leviticus 19:18"> 第二重要的是：‘要爱人如己’。<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="引自《利未记》19:18。">g</a></sup>再没有哪条诫命比这两条更重要。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="Deuteronomy 4:39; Deuteronomy 4:35; Isaiah 46:9"> 那位宗教老师对耶稣说：“老师，你说的很对，上帝是唯一的，除了他以外别无他人。</span>
<span className="v" id="v33" data-v="33" data-xref="Hosea 6:6; Micah 6:6–8; 1 Samuel 15:22"> 我们要全心、全意、全力地爱他，要爱人如己，这比各种仪式和祭物好多了。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="歌罗西书 4:6; 路加福音 20:40; 马太福音 22:46"> 耶稣见他回答得很睿智，便说：“你距离上帝之国不远了。”从此之后，再也没有人敢向耶稣提问。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="路加福音 20:41–44; 马太福音 22:41–45; 马太福音 26:55"> 耶稣在圣殿内讲道。他问：“宗教老师如何讲述基督是大卫的子孙呢？</span>
<span className="v" id="v36" data-v="36" data-xref="Psalms 110:1; 希伯来书 1:13; 马太福音 22:43–45"> 由于大卫曾被圣灵感召，他便声称，主对我主说：‘你坐在我的右边，等我把你的仇敌放在你的脚下。’<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="引自《诗篇》110:1。">h</a></sup></span>
<span className="v" id="v37" data-v="37" data-xref="罗马书 1:3–4; 马太福音 11:25; 马太福音 1:23"> 由于大卫让别人称其为主，他又怎么会是大卫的子孙呢？”民众对耶稣的这番话感到非常满意。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="马太福音 23:1–7; 路加福音 20:45–47; 路加福音 11:43"> 耶稣继续教导大家，说：“你们要提防那些宗教老师，他们喜欢穿长袍走来走去，喜欢人们在集市中向他们问安，</span>
<span className="v" id="v39" data-v="39" data-xref="雅各书 2:2–3"> 喜欢在会堂中位于高位，喜欢成为筵席上的首座。</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 23:13; 路加福音 20:47; 马太福音 23:33"> 他们欺骗寡妇的财产，<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="原意为“吞噬寡妇的房产。”">i</a></sup>进行冗长的祷告伪装自己。这些人在审判中必受更重的刑罚。”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 21:1–4; 2 Kings 12:9; 约翰福音 8:20"> 耶稣坐在捐款箱面前，看着人们将钱币交上来。很多富人都交上来大量的钱财，</span>
<span className="v" id="v42" data-v="42"> 然后一个穷寡妇走来，投入两枚小钱。<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="原意为两枚价值很低的“小硬币。”">j</a></sup></span>
<span className="v" id="v43" data-v="43" data-xref="哥林多后书 9:6–8; 哥林多后书 8:2; 使徒行传 11:29"> 耶稣把门徒叫过来，对他们说：“告诉你们实话，这个可怜的寡妇投入的资金比其他所有人加起来都多。</span>
<span className="v" id="v44" data-v="44" data-xref="哥林多后书 8:2–3; 约翰一书 3:17; Ezra 2:68–69"> 因为其他人都是拿出自己一部分财富，她却把自己赖以生存的钱都交上去了。”</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 23:56–12; 约翰福音 20:1–10; 马太福音 28:1–10"> 安息日结束后，抹大拉的玛利亚、雅各的母亲玛利亚和撒罗米买了香膏，打算涂抹在耶稣身体上。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 20:1; 路加福音 24:1; 马太福音 28:1"> 在一周第一天<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“一周的第一天。”">a</a></sup>大清早，太阳刚刚升起，她们来到坟墓处，</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 15:46–47; 马太福音 27:60–66"> 彼此商量：“怎么才能把墓门的大石头挪开？”</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 28:2–4; 路加福音 24:2; 约翰福音 20:1"> 但当她们来到这里再看，却发现石头已经挪开。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 20:11–12; 路加福音 24:3–5; 约翰福音 20:8"> 她们走进坟墓，却看见一名身穿白袍的青年坐在右侧，她们甚是惊恐。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="启示录 1:17–18; 哥林多前书 15:3–7; 路加福音 24:46"> 那青年对她们说：“别怕！你们想找钉上十字架的拿撒勒人耶稣，他已经不在这里了，因为他已经复活了。</span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 14:28; 马太福音 26:32; 马太福音 28:10"> 看，这里就是他安葬的地方。去告诉他的门徒和彼得，耶稣要先你们一步去加利利，正如他之前所说，你们在那里就会看见他。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 24:22–24; 路加福音 24:9–11; 马可福音 16:5–6"> 她们从坟墓中跑出来，身体不停打颤，感到很困惑。由于害怕，她们没有对任何人说起这件事。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="很多早期版本的《马可福音》到此为止。其他的版本会继续如下文。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约翰福音 20:14–19; 路加福音 8:2; 约翰福音 20:12"> 在一周第一天的清晨，耶稣复活，先向抹大拉的玛利亚显现，耶稣曾从她身上驱赶了七个恶鬼。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 20:18; 路加福音 24:17; 约翰福音 16:6"> 她将这个消息告诉一直追随耶稣的那些人，他们正在悲伤地哭泣。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 24:11; 马可福音 16:13–14; 马可福音 9:19"> 众人听玛利亚说耶稣复活，虽然是她亲眼所见，但却并不相信。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 24:13–32; 约翰福音 21:14; 约翰福音 21:1"> 随后，有两名门徒离开这里向村子走去，耶稣用另一个方式向他们显现。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 20:25; 路加福音 24:33–35; 约翰福音 20:8"> 于是他们回来告诉其他人，但其他人也不相信。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 15:5; 路加福音 24:36–43; 希伯来书 3:7–8"> 后来，当十一名门徒吃饭时，耶稣又向他们显现，责怪他们缺乏信心又顽固不化，因为他们不相信目睹他复活之人的话。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="马太福音 28:19; 马可福音 13:10; 使徒行传 1:8"> 他又对他们说：“到世界各地去，向所有人传递福音。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“所有造物。”">c</a></sup></span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 11:25–26; 约翰福音 3:36; 罗马书 10:9–14"> 信我者必会进行受洗，必会获得救赎，不信者必被定罪。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 5:16; 哥林多前书 12:28; 使徒行传 8:7"> 信我者将有神迹相伴，以我之名赶走所有鬼怪，还会以其他语言交流，</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 10:19; 雅各书 5:14–15; 使徒行传 28:3–6"> 能徒手握蛇，如果喝下毒药，也不会受到伤害，手触病患即可使其痊愈。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="彼得前书 3:22; 希伯来书 1:3; 希伯来书 12:2"> 主耶稣向门徒说完这一切，便被接到天上，落座于上帝的右边。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 2:4–5; 使徒行传 14:3; 罗马书 15:19"> 门徒们走向世界，到处传扬福音，主与他们同在，通过神迹证实他们所传之道为上帝的讯息。</span>
</div>
</div>

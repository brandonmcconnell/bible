<span className="v" id="v1" data-v="1" data-xref="马太福音 12:9–14; 路加福音 6:6–11; 马可福音 1:21"> 耶稣回到会堂，那里有个男人的一只手已经残疾。有人问耶稣：“在安息日可以治病吗？”</span>
<span className="v" id="v2" data-v="2" data-xref="Psalms 37:32; 路加福音 14:1; 路加福音 6:7"> 众人观察他会不会在安息日医治那个人，好去控告他。</span>
<span className="v" id="v3" data-v="3" data-xref="腓立比书 1:28–30; Isaiah 42:4; 路加福音 6:8"> 耶稣对那残手之人说：“起来，站在大家面前！”</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 6:9; 马太福音 12:10–12; Hosea 6:6"> 然后又对他们说：“在安息日能做哪件事，好事还是坏事？救命还是害命？”众人不发一声。</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 6:10; 以弗所书 4:18; 罗马书 11:25"> 耶稣怒目环视他们，为他们的铁石心肠感到难过。于是就对那人说：“伸出手来！”那人把手一伸，手就复原了。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 22:16; 马可福音 12:13; 马太福音 12:14"> 法利赛人离开后，立刻与希律党人一起商量如何对付耶稣和除掉他。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 4:25; 路加福音 6:17; 马太福音 12:15"> 耶稣和门徒回到海边，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="加利利海。">a</a></sup>一大群人跟着他。</span>
<span className="v" id="v8" data-v="8" data-xref="Ezekiel 35:15; Isaiah 34:5; 马太福音 11:21"> 还有许多人听说了他所做的一切，纷纷从犹太、耶路撒冷、以土迈、约旦河外和推罗、西顿等地方前来跟随他。</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 5:30; 约翰福音 6:15"> 因为人太多，耶稣就吩咐门徒为他准备一条小船，免得众人拥挤他。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 14:36; 马可福音 6:56; 马太福音 4:23"> 他医好了许多人，所有病患都挤过来希望触摸他。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 4:41; 马可福音 1:23–24; 路加福音 8:28"> 恶灵每次看到他，就仆倒在他面前，大声喊叫说：“你是上帝之子！”</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 12:16; 马可福音 1:25; 马可福音 1:34"> 但耶稣严厉要求他们，不要把他的身份张扬出去。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:1; 路加福音 6:12–16; 马太福音 10:1–4"> 耶稣继续去往丘陵乡村，召唤那些他需要的人，那些人于是纷纷聚来。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 1:8; 路加福音 9:1–6; 约翰福音 15:16"> 他选择了十二个人，称他们为 使徒。他们与耶稣在一起，接受耶稣的派遣，宣传福音，</span>
<span className="v" id="v15" data-v="15"> 耶稣还赋予他们驱魔的力量。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 1:42; 使徒行传 1:13; 马太福音 16:16–18"> 他选择的十二个人是：西门（耶稣给他起名叫彼得），</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 4:12; 马可福音 14:33; Jeremiah 23:29"> 西庇太的大儿子雅各和他弟弟约翰（耶稣给约翰起名叫半尼其，即“雷之子”），</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 1:13; 马可福音 2:14; 马太福音 9:9"> 安得烈、腓力、巴多罗迈、马太、多马、亚勒腓的儿子雅各、达太、激进派西门</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 6:71; 约翰福音 13:2; 使徒行传 1:16–25"> 以及后来出卖耶稣的加略人犹大。</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 6:31; 约翰福音 4:31–34; 马可福音 9:28"> 耶稣走进屋子，民众又聚过来，他们甚至没有时间吃饭。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 26:24; 约翰福音 10:20; 马可福音 3:31"> 耶稣的家人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“与他亲近之人。”">b</a></sup>听闻这一切，就跑过来想把他带走，说：“他疯了。”</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 15:1; 马太福音 10:25; 马太福音 9:34"> 但来自耶路撒冷的宗教老师说：“别西卜附在他身上！”又说：“他靠魔鬼之王的力量驱除魔鬼。”</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 11:17–23; 马太福音 12:25–30; 马太福音 13:34"> 但耶稣把他们叫过来，讲了一个比喻<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或“寓言”，意为类比、比较和比喻。">c</a></sup>：“撒旦怎能赶逐撒旦呢？</span>
<span className="v" id="v24" data-v="24" data-xref="Zechariah 11:14; Isaiah 19:2–3; 2 Samuel 20:6"> 一个国家若自相残杀，这个国家就无以为续，</span>
<span className="v" id="v25" data-v="25" data-xref="雅各书 3:16; Psalms 133:1; 加拉太书 5:15"> 一个家庭若内部纷争，这个家庭就会垮掉。</span>
<span className="v" id="v26" data-v="26"> 如果撒旦分裂，哥和拿就不会持久，很快就会灭亡。</span>
<span className="v" id="v27" data-v="27" data-xref="Isaiah 49:24–26; 马太福音 12:29; 路加福音 11:21–23"> 很显然，一个人闯入壮汉的家想要抢东西，但必须先把壮汉捆绑起来，才可以如愿以偿。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 12:10; 马太福音 12:31–32; 约翰一书 5:16"> 告诉你们实话，世人的一切罪行和亵渎之话，都可以得到赦免。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 12:31–32; 路加福音 12:10; 帖撒罗尼迦后书 1:9"> 但亵渎圣灵者，永世不得赦免，因为他们犯下永世罪过。”</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 10:20; 马可福音 3:22"> （耶稣这样说<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="隐喻之意。">d</a></sup>是因为他们说他“有恶灵附体。”</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 8:19–21; 马太福音 12:46–50"> 耶稣的母亲和弟弟来了，站在外面向他传了个口信，叫他出来。</span>
<span className="v" id="v32" data-v="32"> 人群围坐在耶稣身边，对他说：“你母亲和兄弟在外面找你。”</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 3:21; Deuteronomy 33:9; 马可福音 6:3"> 耶稣回答：“谁是我的母亲？谁是我的兄弟？”</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 12:49–50; 路加福音 11:27–28; 罗马书 8:29"> 他环顾身边围坐之人，说：“这就是我的母亲！我的兄弟！</span>
<span className="v" id="v35" data-v="35" data-xref="约翰一书 2:17; 马太福音 7:21; 约翰一书 3:22–23"> 凡遵行上帝旨意之人，就是我的母亲和兄弟姐妹。”</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="约翰福音 4:47; 路加福音 5:18; 路加福音 18:35–38"> 几天后耶稣重返迦百农，关于他回到这里的消息立刻传遍各地。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 2:13; 马可福音 1:45; Psalms 40:9"> 许多人纷纷聚集到他屋子里，甚至簇拥在门前。于是耶稣就对他们讲道<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“单词”，在这里是首次使用，代表上帝的福音。">a</a></sup>。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 5:18–26; 马太福音 9:1–8; 马太福音 4:24"> 这时有四个人把一个瘫痪的男人带到耶稣那里，</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 5:19; Deuteronomy 22:8"> 但因为太拥挤，无法将他带到耶稣面前。于是他们跑到屋顶上，将屋顶拆下来，在耶稣上方的开口处，将瘫痪男人和他躺的垫子送了下去。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 9:2; 雅各书 5:15; 马可福音 2:9–10"> 耶稣看见他们的信心，就对瘫痪之人说：“朋友，你的罪被宽恕了。”</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 5:21–22; 马可福音 8:17; 哥林多后书 10:5"> 当时有几名宗教老师也坐在那里，心中暗自思量：</span>
<span className="v" id="v7" data-v="7" data-xref="Isaiah 43:25; 路加福音 5:21; Micah 7:18"> “这个人为什么这样说话？他说的都是亵渎上帝之语。除了上帝以外，还有谁能赦免罪恶？”</span>
<span className="v" id="v8" data-v="8" data-xref="Psalms 139:2; 使徒行传 8:22; 路加福音 5:22"> 耶稣很了解他们的想法，就对他们说：“你们为什么这么想这件事？</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 5:22–25; 马太福音 9:5"> 说‘你的罪被救赎了’，或‘站起来行走吧’，哪一个更容易？</span>
<span className="v" id="v10" data-v="10" data-xref="Daniel 7:13–14; 马太福音 9:6–8; 约翰福音 5:20–27"> 但为了说服你们，相信人子也有宽恕罪的力量，</span>
<span className="v" id="v11" data-v="11" data-xref="马可福音 1:41; 约翰福音 5:8–10; 约翰福音 6:63"> 我要对你（瘫痪之人）说：‘起来吧，拿起你的垫子回家去吧。’”</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 9:33; 马太福音 9:8; 路加福音 7:16"> 那人就起来，立刻拿着垫子当着大家的面离开了。众人颇感惊奇，开始颂赞上帝，说：“我们从来没有见过这样的事。”</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 4:1; Proverbs 1:20–22; 路加福音 19:48"> 耶稣走出去，来到加利利海边，众人都汇聚到他面前来，他开始教导民众。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 5:27–32; 路加福音 6:15; 马太福音 9:9–13"> 他继续往前走，看见亚勒腓的儿子利未坐在交税亭处，于是就对他说：“跟我来吧！” 利未就起来跟从了耶稣。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 15:1; 路加福音 5:29–30; 马太福音 9:10–11"> 后来耶稣在利未家里吃饭，有很多税吏和“罪人”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这里的“罪人”是指在遵守宗教律法方面，并非宗教老师和法利赛人所认为的那么严格。">b</a></sup>过来和他和门徒一起吃饭；因为已经有很多人开始跟随耶稣。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:10; 路加福音 19:7; 路加福音 18:11"> 看见耶稣与罪人和税吏一起吃饭，法利赛派的宗教老师就对耶稣的门徒说：“他为什么和税吏和罪人一起吃饭？”</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 9:12–13; 路加福音 15:7; 路加福音 5:31–32"> 耶稣听言，对他们说：“健康人不需要医生，病患才需要，我来此并非召唤正义之人，而是要感召罪人。”</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 18:12; 马太福音 6:18; 马太福音 9:14–17"> 此刻约翰的门徒和法利赛人正在禁食。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="禁食：出于宗教原因，选择在某些日子不进食。">c</a></sup>于是有人过来问耶稣说：“为什么约翰和法利赛人的门徒常常禁食，你的门徒却不禁食？”</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 25:1–10; Genesis 29:22; Judges 14:10–11"> 耶稣回答：“在婚礼中，宾客与新郎在一起时怎么能禁食呢？</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 17:22; 启示录 21:9; Isaiah 54:5"> 但等到新郎离开他们，他们就会禁食了。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 9:16; 哥林多前书 10:13; Isaiah 57:16"> 没有人会用新布去缝补旧衣服，因为补丁会把衣服扯破，裂开更大的口子。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 9:17; Psalms 119:83; 路加福音 5:37–38"> 没有人会用旧羊皮袋装新酒，因为皮袋会被胀破，酒漏出来的同时皮袋也损坏了。人们总是会把新酒装在新皮袋里。”</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 12:1–8; Deuteronomy 23:24–25; 路加福音 6:1–5"> 安息日那天，耶稣走过麦田，门徒们饿了，于是摘了些麦穗充饥。</span>
<span className="v" id="v24" data-v="24" data-xref="Exodus 20:10; 希伯来书 12:3; 马太福音 12:2"> 法利赛人询问耶稣：“你看，你的门徒正在做安息日不允许的事情。”</span>
<span className="v" id="v25" data-v="25" data-xref="1 Samuel 21:3–6; 路加福音 10:26; 马太福音 22:31"> 但耶稣对他们说：“大卫和他的下属在饥饿时做了什么，你没有读过吗？</span>
<span className="v" id="v26" data-v="26" data-xref="2 Samuel 8:17; Leviticus 24:5–9; 1 Samuel 21:1"> 他走进亚比亚他担任祭司的圣殿，吃下了只有祭司才能吃的圣饼，事实上他们并不允许这么做。”</span>
<span className="v" id="v27" data-v="27" data-xref="歌罗西书 2:16; 路加福音 6:9; Deuteronomy 5:14"> 耶稣又告诉他们：“安息日为人之益处而存在，而非人为安息日之益处而存在。</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 12:8; 启示录 1:10; 约翰福音 5:17"> 因为人子是安息日的主。”</span>

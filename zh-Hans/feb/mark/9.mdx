<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 9:27; 希伯来书 2:9; 路加福音 22:30"> 耶稣又对他们说：“告诉你们实话，站在这里的有些人，在死前必定会看见上帝的天国带着力量降临人间。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="路加福音 9:28–36; Isaiah 33:17; 马太福音 17:1–8"> 六天后，耶稣带着彼得、雅各和约翰爬上高山，然后在他们面前改变了形象。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 28:3; Daniel 7:9; 启示录 7:14"> 他的衣服闪耀着洁白的光芒，人间任何漂白的布料都比不上这样的白色。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 9:30–31; 马太福音 17:3–4; 使徒行传 3:21–24"> 然后以利亚和摩西现身在他们面前，跟耶稣谈话。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="腓立比书 1:23; 约翰福音 14:8–9; 启示录 22:3–4"> 彼得对耶稣说：“拉比，我们在这里太好了！我们可以搭三个庇护所，一个为你，一个为摩西，一个为以利亚。”</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 1:17; Daniel 10:15–19; 马可福音 16:5–8"> （彼得其实不知道该说什么，因为他们都非常害怕！）</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="彼得后书 1:17; 马太福音 3:17; 马可福音 1:11"> 有一片云朵飘到<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或“笼罩在上方。”">a</a></sup>他们头顶，云中传来一个声音：“这是吾子，我之所爱，你们要听他。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 10:16; 使徒行传 8:39–40; 路加福音 24:31"> 门徒们正在张望之际，忽然就看不见别的人了，只有耶稣和他们在一起。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马太福音 12:40; 马太福音 17:9–13; 马可福音 5:43"> 他们下山的时候，耶稣吩咐他们，人子死而复生之前，不要将所见告诉其他人。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 17:18; 路加福音 24:7–8; 路加福音 18:33–34"> 门徒把这句话记在心里，但他们彼此争论死而复生是什么意思。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="Malachi 4:5; Malachi 3:1; 马太福音 11:14"> 他们就问耶稣：“宗教老师为什么说以利亚必须先来呢？”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="Isaiah 53:1–12; Isaiah 50:6; Isaiah 52:14"> 耶稣说：“的确，以利亚要先来做好准备，但为什么经书中又说人子要受许多苦，被人侮辱呢？</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 14:3–11; 马太福音 17:12–13; 马太福音 11:14"> 但我告诉你们，以利亚已降临，他们任意地虐待他，就像经书中记载的那样。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 9:37–42; 马太福音 17:14–20; 路加福音 11:53–54"> 他们回到其他门徒那里，看见一大群人围着他们，还有宗教老师在和他们辩论。</span>
<span className="v" id="v15" data-v="15" data-xref="Exodus 34:30; 马可福音 9:2–3"> 众人看见了耶稣都很惊奇，就跑上前去向他问候。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 5:30–32; 马可福音 8:11"> 他问他们：“你们和他们辩论什么？”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马可福音 9:25; 路加福音 11:14; 约翰福音 4:47"> 民众当中有一人回答他：“老师，我把我的儿子带到你这里来，他被恶灵附体，无法说话。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 17:19–20; 马可福音 11:23; 马太福音 17:16"> 无论在哪里，恶灵都会抓住他，把他摔倒，让他口吐白沫、咬牙切齿、浑身僵硬。我请你的门徒把恶灵赶出去，他们却办不到。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="Numbers 14:11; 约翰福音 20:27; Numbers 14:27"> 耶稣回答他们：“唉！这些没有信心的人啊！我在这里必须待到什么时候？我还要忍受你们多久？把他带到我这里来吧。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马可福音 1:26; 路加福音 4:35; 约翰福音 8:44"> 他们把孩子带到他跟前。那恶灵一见耶稣，就立刻让孩子倒在地上抽搐，口吐白沫打滚。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 9:33; 使徒行传 4:22; 马可福音 5:25"> 耶稣问他父亲：“他这样多久了？”<br />他说：“从小就是这样。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 15:22–28; 马可福音 5:19; 马太福音 20:34"> 恶灵经常把他扔在火中想要烧死他，把他扔在水中想要淹死他。如果你能，求你可怜我们，帮助我们。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约翰福音 11:40; 希伯来书 11:6; 马可福音 11:23"> 耶稣说：“为什么你要说<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="隐喻之意。耶稣问这个男人为什么要对他说“如果你能”，因为这句话表示了对耶稣能力的怀疑。">b</a></sup>‘如果你能？’有信心者必有力量！”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 17:5; 希伯来书 12:2; 以弗所书 2:8"> 孩子的父亲立刻喊着说：“我真的信你！但我的信心不够，求你帮助我。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行传 16:18; 路加福音 9:42; 马可福音 9:15"> 耶稣见民众围拢了来，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或“一起跑开。”这个词仅在《新约》中用过一次。">c</a></sup>开始斥责那恶灵说：“让人聋哑的恶灵，我命令你从他身上出来，不要再回去。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马可福音 9:20; 马可福音 1:26; 马可福音 9:18"> 那恶灵喊叫着，让这孩子陷入剧烈的抽搐，然后就从他身体里被驱赶出来。孩子仿佛已经死了，许多人都说：“他死了！”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马可福音 1:31; 使徒行传 3:7; 马可福音 1:41"> 但耶稣拉着男孩的手，扶他起来，他就站起来了。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马太福音 17:19–20; 马可福音 7:17; 马太福音 15:15"> 然后耶稣走进屋子，门徒私下问他说：“为什么我们就无法驱赶那恶灵呢？”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="雅各书 5:15; Daniel 9:3; 马太福音 17:20"> 耶稣对他们说：“如果不祈祷，这种恶灵无法驱赶。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="马太福音 17:22–23; 路加福音 9:43–45; 马可福音 6:31–32"> 他们离开了，途经加利利。耶稣不想让任何人知道他们的行踪，</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 16:21; 马可福音 9:12; 路加福音 24:44–46"> 因为他正在教导门徒。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="换言之，他希望花些时间教授门徒。">d</a></sup>他对他们说：“人子将遭到背叛，送到人类的官府，他们会杀害他，但他在死后三天就会复活。”</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 2:50; 路加福音 9:45; 路加福音 18:34"> 门徒不明白这话，又不敢询问。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 18:1–5; 希伯来书 4:13; 路加福音 9:46–48"> 他们来到迦百农的一个房间内住下。耶稣问他们：“你们在路上讨论什么呢？”</span>
<span className="v" id="v34" data-v="34" data-xref="马可福音 9:50; 马太福音 20:21–24; 马太福音 18:1–5"> 门徒不说话，因为他们在路上争论谁最重要。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 20:25–28; 马可福音 10:42–45; 路加福音 22:26"> 耶稣坐下，唤来十二门徒，对他们说：“一个人如果想为首，就必在众人中成为最后，做众人的仆人。”</span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 10:16; 马太福音 19:14–15; 马太福音 18:2"> 耶稣拉过一个小孩子来，叫他站在门徒中间，然后把孩子抱起来拥抱着他，对门徒说：</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 18:3–5; 路加福音 10:16; 马太福音 10:40–42"> “凡因我之名迎接这样的小孩子，就是迎接我，这样的人并非在迎接我，而是迎接那派我过来的人。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="路加福音 9:49–50; Numbers 11:26–29; 路加福音 11:19"> 约翰对耶稣说：“老师，我们看见有人以你之名驱鬼，我们想要制止他，因为他不是我们中的一员。”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="哥林多前书 12:3; 哥林多前书 13:1–2; 马太福音 13:28–29"> 耶稣说：“不要制止他，因为没有人能在以我之名行神迹的同时又诅咒我。</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 12:30; 路加福音 11:23"> 不反对我们，就是支持我们。</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 10:42; 马太福音 25:40; 哥林多前书 15:23"> 无论是谁，若以我之名给你一杯水，他这样做只因你属于基督，就不会失掉赏赐，相信我。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="马太福音 18:6; 路加福音 17:1–2; 马太福音 18:10"> 但如果有人让这些信我的小孩子犯罪，最好就是在他的脖子上拴一块大磨石，让其淹没在海里。</span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 5:29–30; 马太福音 18:8–9; 马太福音 25:41"> 如果你的一只手让你犯罪，把它砍下来。残疾却能进永生，总好过双手下哥和拿，堕入不灭的哥和拿<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="“哥和拿”有时候也会被翻译为地狱或地狱之火。哥和拿本身是耶稣撒冷城外的一个地区，主要用于焚烧垃圾废物。“地狱”一词源于北欧，是盎格鲁-撒克逊人上帝话中的词语，与这里的含义并不完全一致。又见于第 45 和 47 句。见《马太福音》5:22脚注。">e</a></sup>之火。</span>
<span className="v" id="v44" data-v="44"> <sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="在早期手抄本中并无第 44 句。">f</a></sup></span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 18:8; 马太福音 5:22; 马可福音 9:43"> 如果你的一只脚让你犯罪，把它砍下来。瘸腿却能获得永生，总好过两脚齐全却被丢在哥和拿。</span>
<span className="v" id="v46" data-v="46"> <sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="在早期手抄本中并无第 46 句。">g</a></sup></span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 18:9; 马可福音 9:43; 马太福音 5:22"> 如果你的一只眼睛让你犯罪，把它挖出来。一只眼睛进入上帝之国，总好过两眼齐全被丢进哥和拿，</span>
<span className="v" id="v48" data-v="48" data-xref="Isaiah 66:24; 马可福音 9:43–45; 马太福音 25:41"> 哥和拿里的虫不死，火永不灭。</span>
<span className="v" id="v49" data-v="49" data-xref="Leviticus 2:13; Ezekiel 43:24"> 每个人会像被‘盐腌’一样，被火灼烧。</span>
<span className="v" id="v50" data-v="50" data-xref="歌罗西书 4:6; 罗马书 12:18; 马太福音 5:13"> 盐是好东西，但如果失去了它的味道，怎样才能让它恢复咸味呢？你们需要像盐一样，彼此和睦地生活。”</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 27:1–2; 路加福音 23:1–5; 路加福音 22:66"> 第二天清晨，祭司长和长老、宗教老师以及公议会全体做出决定。他们把耶稣捆绑起来，送到彼拉多处。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 2:2; 马太福音 27:11–14; 提摩太前书 6:13"> 彼拉多问他：“你是犹太人之王？”耶稣回答：“这是你说的。”</span>
<span className="v" id="v3" data-v="3" data-xref="Isaiah 53:7; 马可福音 15:5; 约翰福音 18:29–31"> 祭司长对耶稣提起很多控告。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 19:10; 马太福音 27:13; 马太福音 26:62"> 彼拉多又问他：“你看，他们对你提出这么多控告，你不想为自己辩护吗？”</span>
<span className="v" id="v5" data-v="5" data-xref="Isaiah 53:7; Zechariah 3:8; Psalms 71:7"> 但耶稣仍一言不发，彼拉多很惊讶。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 18:39–40; 使徒行传 25:9; 使徒行传 24:27"> 每年这个时候，彼拉多都会照例按着众人的要求，特赦一名囚犯。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 23:18–19; 马太福音 27:16; 路加福音 23:25"> 有一名叫做巴拉巴的罪犯，是一个反叛组织的成员，曾杀过人。</span>
<span className="v" id="v8" data-v="8"> 民众来到彼拉多处，请他大赦巴拉巴。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 19:14–16; 约翰福音 19:4–5; 约翰福音 18:39"> 彼拉多回答他们：“那你们想不想让我释放这犹太人之王？”</span>
<span className="v" id="v10" data-v="10" data-xref="Proverbs 27:4; 提多书 3:3; Genesis 4:4–6"> 他其实知道，祭司长是因为嫉妒才把耶稣交上来。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 3:14; 约翰福音 18:40; Hosea 5:1"> 祭司长却煽动民众，一定要总督赦免巴拉巴而非耶稣。</span>
<span className="v" id="v12" data-v="12" data-xref="Jeremiah 23:5–6; Isaiah 9:6–7; Zechariah 9:9"> 彼拉多又问他们：“那么，对于这个被称为犹太人之王的人，你们想让我怎样处置？”</span>
<span className="v" id="v13" data-v="13"> 众人喊到：“把他钉上十字架！”</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 23:41; 路加福音 23:23–24; Isaiah 53:3"> 彼拉多说：“为什么呢？他做了什么恶事呢？”众人更大声地喊叫：“把他钉上十字架！”</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 19:1; 马太福音 27:26; Isaiah 50:6"> 彼拉多只想安抚愤怒的民众，于是释放了巴拉巴，但对耶稣进行了鞭打处罚，然后将他送走，准备钉上十字架。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 19:9; 马太福音 27:27–31; 约翰福音 18:28"> 士兵把耶稣带进总督府<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="罗马官员的宅邸。">a</a></sup>的院子里，召集整个军队的士兵都在那里集合。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一个军团大概 600 名士兵。">b</a></sup></span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 27:28–30; 约翰福音 19:2–5; 路加福音 23:11"> 他们给耶稣穿上紫色长袍，用荆棘编成冠冕戴在他头上。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 27:42–43; 马可福音 15:2; Genesis 37:10"> 然后向他敬礼，说：“犹太人之王万岁！”</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 14:65; Isaiah 53:3–5; 路加福音 23:11"> 接着就用芦苇反复打他的头，朝他吐唾沫还跪下来，仿佛膜拜他一般。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 19:16; 马太福音 27:31"> 嘲笑完后，士兵把他的紫色外袍脱下，让他穿回自己的衣服，然后准备将他送上十字架。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 27:32; 路加福音 23:26; 罗马书 16:13"> 有一个名叫西门的古利奈人从乡下来到城里，他是亚历山大和鲁孚的父亲。原本只是经过此地，士兵却强迫他背上耶稣的十字架。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 27:33–44; 约翰福音 19:17–27; 路加福音 23:27–38"> 他们把耶稣带到一个名叫各各他的地方，意为髑髅地，</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 27:34; 约翰福音 19:28–30; 路加福音 23:36"> 士兵拿出没药调配的酒给他喝，但耶稣没有喝。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 23:34; 约翰福音 19:23–24; 马太福音 27:35–36"> 他们把耶稣钉上十字架，抽签分他的衣服，看谁能分到什么。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="见《诗篇》22:18。">c</a></sup></span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 19:14; 马可福音 15:33; 马太福音 27:45"> 他们钉他上十字架之时，是上午九点钟。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 27:37; 马太福音 2:2; 约翰福音 19:18–22"> 耶稣的罪状牌上写着“犹太人之王。”</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 23:32–33; 马太福音 27:38; 约翰福音 19:18"> 同时钉上十字架的还有两个强盗，一个在耶稣右侧，一个在左侧。</span>
<span className="v" id="v28" data-v="28"> <sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="在很多早期手抄本中并无第 28 句。">d</a></sup></span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 14:58; Psalms 109:25; Lamentations 1:12"> 路人讥笑他，摇着头说：“哼，就是你说要拆毁圣殿，然后在三日内再次建造它的吧？</span>
<span className="v" id="v30" data-v="30"> 现在把自己从十字架上救下来吧！”</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 12:23–24; 马太福音 27:41–43; 路加福音 23:35–37"> 祭司长和宗教老师也同样讥笑他，彼此说：“他救得了别人，却不能救自己，</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 27:44; 路加福音 23:39–43; Zechariah 9:9"> 如果他真是基督，是以色列的王，现在就从十字架走下来，我们看见就会信你。”甚至连其他被钉上十字架的人都在侮辱他。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 27:45; 路加福音 23:44–45; Amos 8:9–10"> 正午时分，整个地区都陷入黑暗，直到下午三点钟。</span>
<span className="v" id="v34" data-v="34" data-xref="Psalms 22:1; 马太福音 27:46; 希伯来书 5:7"> 下午三点，耶稣大声呼叫：“以利，以利，拉马撒巴各大尼。”意思为：“我的上帝，我的上帝，你为什么抛弃我？”<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="引自《诗篇》22:1。">e</a></sup></span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 27:47–49; 马可福音 9:11–13; 马太福音 17:11–13"> 站在旁边的几个人听见了就说：“看，他呼叫以利亚呢。”</span>
<span className="v" id="v36" data-v="36" data-xref="Psalms 69:21; 马可福音 15:23; 约翰福音 19:28–30"> 有一个人跑去拿海绵浸满了酸酒，绑在芦苇上，递给耶稣喝，<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="见《诗篇》69:21。">f</a></sup>说：“等着瞧吧，看看以利亚来不来救他。”</span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 19:30; 路加福音 23:46; 马太福音 27:50"> 耶稣痛苦地大叫一声死去。</span>
<span className="v" id="v38" data-v="38" data-xref="希伯来书 10:19–23; 路加福音 23:45; 希伯来书 9:3–12"> 圣殿里的垂帘从上到下裂成两半。</span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 27:54; 路加福音 23:47–48; 马太福音 27:43"> 看见他这样死去，站在他对面的百夫长说：“这人真是上帝之子！”</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 23:49; 路加福音 8:2–3; 马太福音 27:55–56"> 有一些妇女在远处观看，她们中有抹大拉的玛利亚、小雅各和约西的母亲玛利亚以及撒罗米。</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 8:2–3; 马太福音 27:55–56"> 耶稣在加利利期间，这些女人就一直跟随他、服侍他。此外，还有许多和他一同去过耶路撒冷的女人。</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 23:50–56; 约翰福音 19:38–42; 约翰福音 19:31"> 这天是星期五，<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="原意为“准备日。”">g</a></sup>也是安息日的前一日，夜幕降临，</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 2:38; 路加福音 2:25; 路加福音 23:51"> 亚利马太的约瑟来了，他是公议会的成员，他在等待着神的国度的到来。他斗胆去见彼拉多，请求带回耶稣的身体。</span>
<span className="v" id="v44" data-v="44" data-xref="约翰福音 19:31–37"> 彼拉多惊讶耶稣已死，就把百夫长叫来，问耶稣是否已死。</span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 27:58; 约翰福音 19:38; 马可福音 15:39"> 从百夫长那里确认后，彼拉多就把遗体交给约瑟。</span>
<span className="v" id="v46" data-v="46" data-xref="Isaiah 53:9; 马太福音 27:59–60; Isaiah 22:16"> 约瑟买了细麻布，把耶稣的躯体从十字架上取下，用细麻布裹好后，葬于一个他在岩石中凿出来的坟墓内，又用一块大石头挡住墓门。</span>
<span className="v" id="v47" data-v="47" data-xref="马可福音 15:40; 马可福音 16:1; 路加福音 23:55–2"> 抹大拉的玛利亚和约西的母亲玛利亚亲眼看到安放他的地方。</span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰一书 5:11–12; 马太福音 4:3; 马太福音 3:17"> 这里讲述了上帝之子耶稣基督福音的初始。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="Malachi 3:1; 马太福音 11:10; 路加福音 1:76"> 正如以赛亚先知所写：“我派遣使者提前来到，备好你要走的道路。</span>
<span className="v" id="v3" data-v="3" data-xref="Isaiah 40:3–5; 马太福音 3:3; 路加福音 3:4–6"> 在荒野中有人在呼喊：‘预备主的道，修直他的路！’”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="见《玛拉基书》3:1 和《以赛亚书》40:3。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="使徒行传 19:3–4; 马太福音 3:6; 使徒行传 13:24–25"> 施洗约翰出现在荒野中，宣讲悔改<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“悔改”原意为“改变主意”，但在这里也体现出旧约先知的呼吁，即让自己的子民回归主，放弃虚伪的宗教思想和恶行。">b</a></sup>的洗礼，因此救赎罪行。</span>
<span className="v" id="v5" data-v="5" data-xref="Leviticus 26:40–42; 使徒行传 19:18; 马太福音 3:5–6"> 犹太和全耶路撒冷的人都来到他身边，承认自己的罪，在约旦河里接受他的洗礼。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="2 Kings 1:8; Leviticus 11:22; 马太福音 3:4"> 约翰身穿驼毛衣服，腰束皮带，以蝗虫<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="此处也可能是槐豆，与“蝗虫”拼写相近。">c</a></sup>和野蜜为食。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 13:25; 路加福音 3:16; 约翰福音 1:27"> 他这样宣讲：“在我之后将有一人到来，能力远比我强大，我甚至连弯腰给他提鞋的资格都没有。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 1:5; 哥林多前书 12:13; 使徒行传 19:4–6"> 我用水给你们施洗，他却会用圣灵给你们施洗。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马太福音 3:13–17; 马太福音 2:23; 路加福音 3:21–22"> 这时耶稣从加利利的拿撒勒前来，在约旦河里接受约翰的洗礼。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 1:31–34; 路加福音 3:22; Isaiah 42:1"> 他从水中出来的那一刻，天裂开了，圣灵如鸽子般落在<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或“进入。”">d</a></sup>他身上。</span>
<span className="v" id="v11" data-v="11" data-xref="Isaiah 42:1; 马可福音 9:7; 马太福音 3:17"> 天空传来一个声音：“你是我的爱子，你让我喜悦。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 4:1–11; 路加福音 4:1–13"> 圣灵随即将耶稣派到荒野。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 2:17–18; 希伯来书 4:15; Exodus 34:28"> 他在那里将待上四十天，受到撒旦的诱惑，身边是各种野兽，还有天使来看护他。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 4:23; 马太福音 4:12; 路加福音 8:1"> 之后，耶稣在约翰被捕后来到加利利，宣讲上帝的福音。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="马太福音 3:2; 使徒行传 2:36–38; 马太福音 4:17"> 他说：“预言的时间已到，上帝之国已来临<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="也可能是“上帝的统治已经开始！”这里的王国并不是常规意义上的某块领地，而是通过耶稣的降临恢复了上帝的王权和统治。还需注意的是，原文的动词时态表说明，这个国度并不是即将到来，而是会随耶稣的到来已经降临。这加大了悔改的紧迫性。">e</a></sup>，要悔改并相信福音。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马太福音 4:18–22; 约翰福音 1:40–42; 约翰福音 6:8"> 耶稣沿着加利利海边行走，看见西门和他弟弟安得烈在海上撒网，他们靠打鱼过活。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 5:10; 马太福音 4:19–20; 使徒行传 2:38–41"> 耶稣对他们说：“跟从我吧，我要让你们成为获得人的渔夫。”</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 18:28–30; 路加福音 5:11; 马可福音 10:28–31"> 他们立刻丢下渔网，跟从了他。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马可福音 5:37; 使徒行传 1:13; 马可福音 10:35"> 耶稣稍往前走了几步，看见西庇太的儿子雅各和弟弟约翰，正在船上整理渔网，</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 10:37; 路加福音 14:26; 马可福音 10:29"> 耶稣召唤他们，<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="隐喻之意。">f</a></sup>他们立刻离开父亲西庇太和雇工，跳下船跟从耶稣而去。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马可福音 6:2; 马可福音 1:39; 马太福音 4:23"> 他们去往迦百农，耶稣随即在安息日进入会堂向民众宣讲。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 7:28–29; 马太福音 13:54; 路加福音 4:32"> 民众对他的教导感到惊讶万分，因为他宣讲的方式非常权威，不像是其他的宗教老师。<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="“宗教老师”或“抄经者。”但这里所指的人不止是抄经者。这些人还要有权解释圣经，花时间指导人们遵守宗教律法的要求。">g</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马可福音 9:25; 马可福音 7:25; 马可福音 1:34"> 忽然，会堂中一个被恶灵附体之人开始喊叫：</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 8:29; 雅各书 2:19; 使徒行传 3:14"> “拿撒勒人耶稣，你为什么要来打扰我们？你是来毁灭我们的吗？我知道你是谁，你是上帝的圣者。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马可福音 1:34; 路加福音 4:41; 使徒行传 16:17"> 耶稣打断恶灵的话：“住口！从他身上出来！”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马可福音 9:26; 马可福音 9:20; 路加福音 11:22"> 恶灵尖叫着，使这个人陷入抽搐，并从他身上出来。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马太福音 15:31; 马可福音 7:37; 路加福音 9:1"> 众人都很惊讶，对彼此说：“这是什么？这新教义的权威太大了！即使恶灵也服从于他的命令！”</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 9:31; 路加福音 4:37; 马可福音 1:45"> 耶稣的名声立刻传遍加利利一带。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 4:38–39; 马太福音 8:14–15; 马可福音 1:21"> 他们走出会堂，与雅各和约翰一起去往西门和安得烈的家。</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前书 9:5; 马可福音 5:23; 约翰福音 11:3"> 西门的岳母此刻正发烧躺在床上，众人把这件事告诉了耶稣。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 9:41; Psalms 116:12; 马可福音 5:41"> 耶稣走到她面前，拉着她的手，扶她起来，高烧立刻退去，于是她开始为众人做饭。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马太福音 8:16; 马可福音 3:2; 路加福音 4:40"> 黄昏过后，有人不断把生病和被鬼附体之人带到耶稣面前。</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 1:5; 使徒行传 13:44"> 全城的人都聚集在门外。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 4:41; 马可福音 3:12; 马太福音 4:23"> 耶稣医好了很多人的疾病，驱走很多恶鬼。他命令恶鬼不要说话，因为鬼知道他是谁。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="路加福音 6:12; 路加福音 5:16; 路加福音 22:39–46"> 次日凌晨，天还没有亮，耶稣便起身来到荒郊野外进行祷告。</span>
<span className="v" id="v36" data-v="36"> 西门和其他人去寻找耶稣。</span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 12:19; 马可福音 1:5; Zechariah 11:11"> 找到他后就对他说：“大家都在找你呢！”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="路加福音 4:43; 约翰福音 17:8; Isaiah 61:1–3"> 耶稣对他们说：“我们必须到附近的其他城镇去，这样我就可以在那里传授福音，我就是为此而来。”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="马太福音 4:23; 马可福音 1:21; 路加福音 4:43–44"> 于是他走遍加利利各地，在会堂里传道，进行驱鬼。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="路加福音 5:12–14; 马太福音 8:2–4; Leviticus 13:1–14"> 有一个麻风病人前来寻求帮助。他跪在耶稣面前说：“主啊！如果你愿意，就能治愈我。”</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 9:36; 希伯来书 2:17; 希伯来书 4:15"> 耶稣动了怜悯的心，便伸手摸他，说：“我愿意，你治愈了！”</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="约翰福音 15:3; 马可福音 5:29; 约翰福音 4:50–53"> 这人的麻风病立刻消失了，他痊愈了。</span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 9:30; 马可福音 7:36; 路加福音 8:56"> 在那人离开以前，耶稣认真地警告他说：</span>
<span className="v" id="v44" data-v="44" data-xref="Leviticus 14:1–32; 路加福音 17:14; 马太福音 8:4"> “不要向任何人讲述这件事。去祭司那里，让他看看你的样子，然后按照摩西的要求，为这洁净献祭，向大家作证。”<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="见《利未记》14。">h</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="马可福音 2:13; 马太福音 9:31; 约翰福音 6:2"> 但那人离开后仍然到处宣讲，把这事传开了，这也让耶稣无法再公开走进城市，只好留在外面的荒野。可仍有很多人从各处赶到他这里。</span>
</div>

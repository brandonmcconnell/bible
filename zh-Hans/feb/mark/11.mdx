<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 21:1–11; 约翰福音 12:14–19; 路加福音 19:29–40"> 一行人向耶路撒冷走去，快走到伯法其和伯大尼的时候，经过橄榄山，耶稣于是派了两个门徒先行一步。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 21:2–3; 路加福音 19:30–31"> 他对他们说：“你们到前面的村子去，走进去会看见一头小驴拴在那里，没有人骑过它，把它解开，牵过来。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 10:36; 马可福音 14:15; Psalms 110:3"> 如果有人问你们在干嘛，你们就说：‘主需要它，很快就会送还。’”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="马太福音 26:19; 路加福音 19:32–34; 马太福音 21:6–7"> 门徒听命去了村子，发现一头小驴拴在门外的街上，于是就把它解开。</span>
<span className="v" id="v5" data-v="5"> 站在那里的人问他们：“你们为什么解开它？”</span>
<span className="v" id="v6" data-v="6"> 门徒照着耶稣所述回答他们，那些人就让他们牵走了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="Zechariah 9:9; 路加福音 19:35–36; 马太福音 21:7–8"> 门徒把小驴牵到耶稣那里，把自己的衣服搭在驴身上，耶稣骑了上去。</span>
<span className="v" id="v8" data-v="8" data-xref="Leviticus 23:40"> 许多人把衣服铺在路上，还有人从田野里砍了些树枝也铺在路上。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="Psalms 118:25–26; 马太福音 21:9; 马太福音 23:39"> 人群前后簇拥着他，喊道：“和撒那！<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“和撒那”原为阿拉伯语，意思很简单，意为“拯救。”">a</a></sup>祝福那奉主之名前来之人！</span>
<span className="v" id="v10" data-v="10" data-xref="Ezekiel 37:24–25; 路加福音 2:14; 路加福音 19:38–40"> 祝福我父大卫即将降临的王国！祝福最高天堂的救世主！”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引自《诗篇》118:26。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约翰福音 8:1–2; 路加福音 19:41–45; 路加福音 21:37–38"> 耶稣进入耶路撒冷后走进圣殿，环顾四周观察一番。天时不早了，他便和十二门徒出城，去往伯大尼。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 21:18–22; 马太福音 4:2; 约翰福音 19:28"> 第二天他们离开伯大尼时，耶稣感到饥饿。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 21:19; 路加福音 13:6–9; Isaiah 5:7"> 他看到远处有一棵长满叶子的无花果树，他走过去，看看能否在树上找些果子充饥。但到了树下才发现，除了叶子什么都没有，因为现在还不到无花果生长的季节。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 21:19; 马太福音 7:19; 马太福音 3:10"> 耶稣对树说：“永远也不会有人再吃你的果子了！”他的门徒也听见了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 2:13–17; 马太福音 21:12–16; 路加福音 19:45–47"> 他们返回耶路撒冷，耶稣走进圣殿后，把里面的生意人赶走，推倒兑换钱币的桌子，掀翻卖鸽子小贩的凳子，</span>
<span className="v" id="v16" data-v="16"> 制止了那些拿着物品打算穿过圣殿的人。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="Isaiah 56:7; Jeremiah 7:11; 路加福音 19:46"> 随后他向众人解释道：“经文上写着：‘我的殿应被称为祷告之殿。’<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《以赛亚书》56:7。">c</a></sup>你们竟把它变成贼窝了。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《耶利米书》7:11。">d</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 7:28; 马可福音 12:12; 马可福音 14:1–2"> 祭司长和宗教老师听见这番话，就想找个办法除掉耶稣。却又害怕耶稣，因为民众对他的训导很佩服。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 21:37; 马可福音 11:11; 约翰福音 12:36"> 夜晚时分，耶稣和师徒去往城外。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 15:13; 马可福音 11:14; 约翰福音 15:6"> 第二天清晨，在返回的路上，他们看见那棵无花果树从根处枯萎了。</span>
<span className="v" id="v21" data-v="21" data-xref="Proverbs 3:33; 马太福音 23:7; 马太福音 25:41"> 彼得想起耶稣之前所说，便说：“老师，看，你咒诅的那棵无花果树已经枯萎了。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="Psalms 62:8; 约翰福音 14:1; 马可福音 9:23"> 耶稣回答：“相信上帝。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 17:20; 约翰福音 15:7; 马太福音 21:21"> 如果我说，只要你心中没有任何疑问，相信自己所说的一定变成现实，那么任何人都能对这座山说：‘挪到海里吧’，只要他心里不怀疑，就会变成现实。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 21:22; 约翰一书 5:14–15; 约翰一书 3:22"> 所以我告诉你们，凡是你们祷告和祈求的事情，只要相信能够得到，就必得到。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 6:14–15; 歌罗西书 3:13; 以弗所书 4:32"> 在祈祷时，如果有谁得罪了你们，请饶恕他，这样你们的天父也会饶恕你们的罪过。”</span>
<span className="v" id="v26" data-v="26"> <sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="最早的手抄本不包括第 26 句，这句来自于《马太福音》6:15。">e</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 20:1–8; 马太福音 21:23–27; Psalms 2:1–5"> 他们返回耶路撒冷后，耶稣走进殿内，祭司长、宗教老师和长老来到他面前，</span>
<span className="v" id="v28" data-v="28" data-xref="Exodus 2:14; 使徒行传 7:38–39; Numbers 16:3"> 问他：“你做这一切使用了什么权力？谁给你的这个权力？”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 20:3–8; 马太福音 21:24; Isaiah 52:13"> 耶稣对他们说：“让我问你一个问题，你们若能回答，我就告诉你们谁给了我做这些事的力量。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 3:1–20; 约翰福音 3:25–36; 马可福音 1:1–11"> 关于约翰的施洗，它来自天上还是人间？你们回答我吧。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 1:29; 约翰福音 1:34; 马太福音 21:31–32"> 这些人开始议论：“如果我们说从天上来，他就会说‘那你们为什么不信他？’</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 21:46; 马可福音 12:12; 马太福音 14:5"> 如果我们说来自人间……”但他们害怕民众，因为众人都认为约翰就是先知。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="Isaiah 6:9–10; 哥林多后书 4:3–4; 帖撒罗尼迦后书 2:10–12"> 于是他们回答耶稣：“我们不知道。”耶稣也对他们说：<br />“那我为什么要告诉你们，谁给我权力做这一切呢？”</span>
</div>
</div>

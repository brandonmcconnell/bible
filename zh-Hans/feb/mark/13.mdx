<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 24:1–51; Ezekiel 11:22–23; Ezekiel 10:19"> 耶稣离开圣殿的时候，有一个门徒对他说：“老师，你看这些大石头，还有这些雄伟的建筑！”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“这些石头的模样，这些建筑的模样。”">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="路加福音 21:6; 马太福音 24:2; 1 Kings 9:7–8"> 耶稣说：“你看这些雄伟的建筑，将来不会哪块石头堆砌在其他石头上，因为一切都会倒塌。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马太福音 21:1; 马可福音 4:34; 马可福音 14:33"> 耶稣坐在橄榄山上，面向圣殿，彼得、雅各、约翰和安得烈私下问他：</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 1:6–7; 马太福音 24:3; Daniel 12:6"> “请告诉我们，这一切什么时候会发生？这一切将要发生时，会有什么预兆？”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="由于门徒将两件事放在了一个问题里，所以耶稣的回答涵盖了圣殿毁灭和最终末日的两个层面。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歌罗西书 2:8; 以弗所书 5:6; Jeremiah 29:8"> 耶稣告诉他们：“你们要小心，不要被人迷惑。</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 13:22; Jeremiah 23:21–25; 约翰福音 8:24"> 许多人会跑来假冒我的名，声称‘我就是基督’，迷惑众人。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 21:9–11; 约翰福音 14:27; 马太福音 24:6–7"> 如果你们听说附近和远方有战争，不要担心，这些事情必然发生，但不是最终结局。</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 24:8; Isaiah 37:3; Psalms 48:6"> 一个民族要攻打另一个民族，一个国家要对抗另一个国家，到处有地震和饥荒，但这就是世界诞生所经历痛苦的开始。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马太福音 10:17–18; 约翰福音 16:2; 腓立比书 1:29"> 你们要小心！因为人们会把你们交给公议会，你们会在会堂中被鞭打，还因为我的缘故，必须站在总督和君王面前向他们作证。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 24:14; 歌罗西书 1:23; 罗马书 10:18"> 但必须先将福音传给每个城邦。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 21:14–15; 路加福音 12:11–12; 马太福音 10:19–21"> 当你们被抓并送去审判，无需担心该说什么，到时候你们听到告诉你的话，就说出来，因为说话的不是你们，而是圣灵。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 10:21; 路加福音 12:52–53; 路加福音 21:16"> 兄弟会彼此背叛丧命，父亲会背叛儿子，儿女会悖逆父母，甚至置他们于死地。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 15:18–19; 马太福音 10:22; 马太福音 24:13"> 因为我的原因，你们会被众人憎恨，但只要坚持忍耐到底，一定会获得救赎。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="Daniel 9:27; Daniel 12:11; Daniel 11:31"> 当你们看见那‘污秽的偶像崇拜’<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“导致毁灭的偶像崇拜。”见《但以理书》9:27、《但以理书》11:31和《但以理书》12:11。">c</a></sup>站在但以理先知所说圣地（读至此处应认真思考），这时候，住在犹太的应当逃到山上。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 17:31–33; 希伯来书 11:7; 腓立比书 3:7–8"> 站在屋顶的人，不要跑回屋子里取东西，</span>
<span className="v" id="v16" data-v="16"> 如果你在田里，也不要回去取衣服。</span>
<span className="v" id="v17" data-v="17" data-xref="Lamentations 4:10; 路加福音 23:29; Hosea 9:14"> 那样的日子，对于怀孕和哺乳婴儿的女人极为可怕！</span>
<span className="v" id="v18" data-v="18"> 要去祈祷，不要让这一切发生在冬季。</span>
<span className="v" id="v19" data-v="19" data-xref="Daniel 12:1; Joel 2:2; 马太福音 24:21"> 因为那时必有大灾难，这是从世界的开始到现在未曾有过的，以后也必不会再有。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 24:22; Zechariah 13:8–9; Isaiah 65:8–9"> 如果上帝不想尽快结束那些日子，将无人幸免，但为了上帝所选之人，那些日子必会变短。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 21:8; 马太福音 24:23–25; 马太福音 24:5"> 那时如果有人对你们说：‘看，基督在这里！看，基督在那里！’不要信。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 24:24; 帖撒罗尼迦后书 2:8–14; 马可福音 13:6"> 因为到时必有假弥赛亚和假先知出现，可能会做出神迹和奇事，如果如此，就连天选之子都会迷惑。</span>
<span className="v" id="v23" data-v="23" data-xref="彼得后书 3:17; 马可福音 13:5; 约翰福音 14:29"> 所以务必小心！我已经提前把这一切都告诉你们了。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="Isaiah 13:10; 使徒行传 2:19–20; 启示录 6:12–14"> 那些灾难过后会发生这样的事情：‘太阳会暗淡，月亮不再发光，</span>
<span className="v" id="v25" data-v="25" data-xref="Isaiah 34:4; 启示录 6:13"> 众星从天空陨落，天之力量被动摇。’<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="见《以赛亚书》13:10。">d</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="启示录 1:7; 马太福音 16:27; 马太福音 24:30"> 届时，他们将看到人子携伟大的力量和荣光，驾云降临。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="见《但以理书》7:13-14。">e</a></sup></span>
<span className="v" id="v27" data-v="27" data-xref="Zechariah 2:6; 马太福音 24:31; Deuteronomy 30:4"> 他会派出天使，把从极地到天涯的天选之子大批召集而来。<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="原意为“从来自四个方向的风中”">f</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 21:29–31; 马太福音 24:32–33"> 要学习无花果树，当树枝发出嫩芽并长出叶子，你们便知道夏天已来。</span>
<span className="v" id="v29" data-v="29" data-xref="彼得前书 4:17–18; 雅各书 5:9; Ezekiel 12:25–28"> 同样，当你们看到这些事发生，就知道必须发生的事情已经来到，就在你的门口！</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 24:34; 路加福音 21:32; 马太福音 16:28"> 告诉你们实话，这一切必将发生，然后这个世界才会过去。</span>
<span className="v" id="v31" data-v="31" data-xref="Isaiah 40:8; Isaiah 51:6; 马太福音 24:35"> 天地都将走向终结，但我的教诲不会消失。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行传 1:7; 马太福音 24:36–42; 马太福音 25:13"> 发生这种事情时，无人再知晓日子或是时间，甚至连天使或人子都不知情，只有天父知道。</span>
<span className="v" id="v33" data-v="33" data-xref="以弗所书 6:18; 路加福音 12:40; 罗马书 13:11–12"> 要小心！保持清醒！你们不知道那一天何时来临。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 25:14–30; 约翰福音 10:3; 路加福音 12:36–40"> 这就像一个人要出外远行，唤自己的仆人来，把产业交给他们，告诉每个仆人该做什么，然后离开。他还提醒看门人要保持清醒。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马可福音 13:33; 马太福音 24:42; 马太福音 24:44"> 所以要警醒，因为你们不知道主人何时回来，也许黄昏、也许夜半、也许是黎明、也许清晨。</span>
<span className="v" id="v36" data-v="36" data-xref="帖撒罗尼迦前书 5:6–7; 罗马书 13:11–14; 马太福音 24:48–51"> 你肯定不愿意在他忽然回来时，发现你们正在睡觉。</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 13:33; 路加福音 12:41–46; 马可福音 13:35"> 我对你们所说的一切，也对众人说过，‘保持警惕！’”</span>
</div>
</div>

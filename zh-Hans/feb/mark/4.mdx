<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="feb" data-translation-id="cmn_feb" data-translation-label="易读圣经" data-book="MRK" data-book-slug="mark" data-book-name="马可福音" data-chapter="4" data-verses="41">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 5:1–3; 马可福音 2:13; 路加福音 8:4–10"> 耶稣又在海边教导众人，很多人赶来聆听。他走上海中的一条船，坐下来，民众则都站在岸上聆听。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 13:34–35; 马可福音 3:23; 马可福音 4:11"> 他用了很多比喻故事进行讲授：</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="雅各书 2:5; 马太福音 13:26; 马可福音 4:26–29"> 他说：“听着！有一个农夫要出去撒种，</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 13:19; 马可福音 4:15; 马太福音 13:4"> 有的种子落在路旁，被过来的小鸟吃掉了。</span>
<span className="v" id="v5" data-v="5" data-xref="Ezekiel 36:26; 路加福音 8:6; 路加福音 8:13"> 有的落在泥土稀薄、石头众多的土地上，在浅薄的土层上，种子很快发芽。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 1:11; Jeremiah 17:5–8; Jonah 4:8"> 但太阳一出来，就把它晒干了，因为没有实根而枯萎。</span>
<span className="v" id="v7" data-v="7" data-xref="Jeremiah 4:3; 路加福音 8:14; Genesis 3:17–18"> 有的种子落在荆棘丛，荆棘长出来后，把它挤住，它无法结出果实。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 15:5; 歌罗西书 1:6; 马可福音 4:20"> 那些落在肥沃土壤中的种子，就会繁茂成长，结出果实，是原来的 30 倍、 60 倍甚至 100 倍之多。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 11:15; 马可福音 4:23–24; 启示录 3:22"> 你若有耳可聆听，就听听我所说的讲述。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 13:10–17; 马可福音 4:34; Proverbs 13:20"> 耶稣独自一人的时候，始终跟随他的十二门徒和其他人走过来，询问这些比喻的意义。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马太福音 11:25; 路加福音 8:10; 约翰一书 5:20"> 耶稣对他们说：“上帝之国的奥秘，只给你们知道，但对于外人只会讲述比喻。因为</span>
<span className="v" id="v12" data-v="12" data-xref="Isaiah 6:9–10; Isaiah 44:18; 马太福音 13:14–15"> 他们纵使看见了也不会领悟，听见了也不会明白。不然他们就会找到我，获得原谅。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《以赛亚书》6:9-10。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="启示录 3:19; 马太福音 13:51–52; 马可福音 7:17–18"> 耶稣问他们：“你们理解这个故事吗？如果不理解，又如何明白其他故事呢？</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="使徒行传 8:4; 马太福音 13:19; 马太福音 13:37"> 农夫所撒的种子就是福音。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="话语或“信息”，耶稣带来的上帝讯息。(又见《约翰福音》1:1。)">b</a></sup></span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 5:8; 马太福音 13:19; 哥林多后书 2:11"> 落在路旁的种子，就是人们在听福音，撒旦立刻出现，把撒在其心里的福音夺走。</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 6:20; 路加福音 8:13; 马太福音 13:20–21"> 撒在石地上的种子，代表人听了福音后立刻欢喜接受，</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 11:6; 帖撒罗尼迦前书 3:3–5; 马太福音 12:31"> 但道并未在他们心中落根，只是暂时停留，一旦遇到患难和迫害，他们很快就会沦陷。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 8:14; Jeremiah 4:3; 马太福音 13:22"> 撒在荆棘中的种子则指另一些人，他们虽然听了福音，</span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 2:15–17; 提摩太前书 6:9–10; 提摩太前书 6:17"> 但现世的忧虑、对财富的迷恋和种种的欲望不断滋生，把福音挤出去，结不出果实。</span>
<span className="v" id="v20" data-v="20" data-xref="歌罗西书 1:10; 路加福音 8:15; 约翰福音 15:4–5"> 落在肥沃土壤里的种子，就是人在听到福音后真正接受它，就会结出比原来多 30 倍、 60 倍、甚至 100 倍之多的果实。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马太福音 5:15; 路加福音 11:33; 路加福音 8:16"> 耶稣又对他们说：“人们在点灯之后，不会将其放在水桶或床下，而是会将其放在灯台上。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 8:17; Ecclesiastes 12:14; 马太福音 10:26–27"> 所有隐藏之事最终都会显现，所有秘密都会被公开。</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 4:9; 马太福音 11:15; 启示录 2:29"> 有耳朵可以倾听之人，就要听我所说的讲述！”</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 2:1; 路加福音 8:18; 马太福音 7:2"> 耶稣又对他们说：“要留心你们听到的，因为你们用什么标准衡量别人，上帝就会用什么标准衡量你们，完全相同。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 13:12; 路加福音 8:18; 马太福音 25:28–29"> 如果你已经理解，就会得到更多，如果无法理解，现在拥有的也会失去。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 13:24; 哥林多前书 3:6–9; 路加福音 8:11"> 耶稣说：“上帝的王国就像一个人在地里撒种，</span>
<span className="v" id="v27" data-v="27" data-xref="Ecclesiastes 11:5; 帖撒罗尼迦后书 1:3; 哥林多前书 15:37–38"> 他夜里睡觉，白天醒来，日复一日，但并不知道种子如何发芽生长。</span>
<span className="v" id="v28" data-v="28" data-xref="马可福音 4:31–32; Hosea 6:3; 腓立比书 1:9–11"> 大地生长作物是自然而为，先长苗，后吐穗，然后穗上结满了谷粒。</span>
<span className="v" id="v29" data-v="29" data-xref="Joel 3:13; 马太福音 13:30; 马太福音 13:40–43"> 谷粒成熟后就到了收获时节，农夫用镰刀将其割下。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="可能是指《约珥书》3:13。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="马太福音 13:31–32; 路加福音 13:18–21; Lamentations 2:13"> 我们可以将上帝的王国比做什么？可以用什么比喻来形容它呢？</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 19:20; 路加福音 13:18–19; Daniel 2:44–45"> 它好像一粒芥菜种，比所有种子都小，</span>
<span className="v" id="v32" data-v="32" data-xref="Daniel 4:20–22; Daniel 4:10–14; Ezekiel 31:3–10"> 种子在种下后开始生长，长成的样子却比其他作物都大，它的大枝叶甚至吸引天空的飞鸟在它的树荫下栖息。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 13:34–35; 约翰福音 16:12; 希伯来书 5:11–14"> 耶稣用了许多这样的比喻，按照人们能够理解的方式讲述故事。</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 16:25; 马可福音 4:10; 马太福音 15:15–20"> 事实上，他在公开讲道的时候仅使用比喻。只有单独和门徒在一起时，他才会把一切解释给他们听。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 8:18; 路加福音 8:22; 路加福音 8:25"> 当天黄昏，耶稣对门徒说：“我们到海那边去吧。”</span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 3:9; 马可福音 4:1; 马可福音 5:2"> 门徒们离开民众，跟着耶稣走上船，还有其他的船跟随他们。</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 8:23–24; Job 1:19; 路加福音 8:22–23"> 忽然海上刮起狂风，波浪不断拍打船身，船上积满了水。</span>
<span className="v" id="v38" data-v="38" data-xref="彼得前书 5:7; 希伯来书 4:15; Isaiah 54:6–8"> 耶稣却在船尾靠着垫子睡着了。门徒把他叫醒说：“老师，我们就要淹死了，你不担心吗？”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="Psalms 107:29; Psalms 89:9; Psalms 65:7"> 耶稣醒来，命令风停止；又对海浪说：“不要出声！安静吧！”风立刻停止，水面变得完全平静。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 8:25; 马太福音 8:26; 马太福音 14:31"> 然后耶稣问他们：“你们为什么如此害怕？<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="这个词表示胆小鬼。">d</a></sup>怎么对我这么没有信心？”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 8:25; Job 38:11; Psalms 89:7"> 门徒心生敬畏，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="翻译版本通常表示他们露出恐惧深色，但这段话在翻译中，还应该表示他们以前曾被惊吓过。但现在，他们为所发生的事情感到惊讶和畏惧，当然也有害怕的情绪。">e</a></sup>彼此问到：“他到底是谁？连风和海浪都听他的！”</span>
</div>
</div>

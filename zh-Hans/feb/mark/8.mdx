<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="feb" data-translation-id="cmn_feb" data-translation-label="易读圣经" data-book="MRK" data-book-slug="mark" data-book-name="马可福音" data-chapter="8" data-verses="38">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 15:32–39; 马可福音 6:34–44"> 这时候又有一大群人聚集过来，他们没有东西吃。耶稣叫来门徒说：</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 9:36; Micah 7:19; Psalms 103:13"> “我同情这群人，他们和我在一起已有三天，没有任何食物可以吃。</span>
<span className="v" id="v3" data-v="3" data-xref="Isaiah 40:31; Judges 8:4–6; 1 Samuel 30:10–12"> 如果我叫他们散开，饿着肚子回家，他们会在路上晕倒，因为有人来自很远的地方。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="2 Kings 4:42–44; 2 Kings 7:2; 马可福音 6:52"> 门徒回答：“在这荒野之地，哪里能找食物让所有人吃饱呢？”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马太福音 14:15–17; 马太福音 15:34; 路加福音 9:13"> 耶稣问他们：“你们有多少饼？”他们说：“七块。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 3:17; 马太福音 15:35–36; 约翰福音 6:10–11"> 耶稣吩咐民众坐在地上，然后拿起那七块饼，向天致谢，再递给门徒，叫他们把饼分给众人。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 14:19; 约翰福音 21:5; 路加福音 24:41–42"> 他们还有几条小鱼，耶稣进行祈福后，又吩咐道：“把这些鱼拿去分给众人。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="2 Kings 4:42–44; Psalms 145:16; 马太福音 16:10"> 所有人都吃饱了，然后把剩下的零碎收拾起来，装满了七个大篮子。</span>
<span className="v" id="v9" data-v="9"> 当晚大约有四千人吃了食物。随后，耶稣解散了民众，</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 15:39"> 然后立刻和门徒上了船，来到大玛努他地区。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 10:9; 马太福音 12:38; Deuteronomy 6:16"> 法利赛人来到耶稣面前，与他辩论。为了试探他，让他显现来自天堂的神迹。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 12:39–40; 马可福音 7:34; 马太福音 16:4"> 耶稣内心深深地叹息，说：“你们这些人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“世界。”">a</a></sup>为什么总是寻求神迹？我告诉你们实话，我不会给你们显示任何神迹！”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约翰福音 12:36; 使徒行传 13:45–46; Psalms 81:12"> 于是他离开他们，上船去往对岸。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 16:5"> 门徒忘了带饼，船上除了一个饼，身边没有别的食物。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 5:6–8; 马太福音 16:6; 马太福音 16:11–12"> 耶稣嘱咐他们说：“你们要小心，提防法利赛人和希律的‘酵母’！”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 9:46; 路加福音 20:5; 马太福音 16:7–8"> 门徒们彼此问：“他这么说，是因为我们没有饼吧？”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马可福音 6:52; Isaiah 63:17; 马可福音 2:8"> 耶稣知道他们在说什么，就说：“为什么还在议论没有饼这件事呢？你们还不知道，还不明白吗？你们的心还这么迟钝吗？<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“你的心是否变硬了？”">b</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 28:26–27; 马太福音 13:14–15; Jeremiah 5:21"> 你们有眼不能看，有耳不能听吗？<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="来自《旧约》，见《申命记》29:4、《以赛亚书》42:20、《耶利米书》5:21和《以西结书》12:2。">c</a></sup></span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 9:12–17; 马太福音 14:17–21; 约翰福音 6:5–13"> 你们还记得吗？我掰开那五块饼给五千人吃，你们收拾的零碎装满了几个篮子？” 他们说：“十二个。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马太福音 15:34–38; 马可福音 8:1–9"> “那七个饼分给四千人吃，你们收拾的零碎装满了几个大篮子呢？”<br />他们说：“七个。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马可福音 6:52; 马太福音 16:11–12; 马可福音 8:12"> 耶稣问：“还不明白吗？”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马太福音 11:21; 马可福音 6:45; 路加福音 10:13"> 他们随后到了伯赛大，有人带来一个盲人，求耶稣触摸并治愈他。</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 7:33; 约翰福音 9:6–7; 马可福音 5:23"> 耶稣拉着他的手，领他到村外，在他的眼睛上吐了口唾沫，又用双手按在他的身上，问他：“能看见了吗？”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="Isaiah 32:3; Isaiah 29:18; 哥林多前书 13:9–12"> 那人环顾四周，说：“我看见人了！但他们好像走动的树一样。”</span>
<span className="v" id="v25" data-v="25" data-xref="彼得前书 2:9; 彼得后书 3:18; Proverbs 4:18"> 于是耶稣再将手按在他的眼睛上，他立刻就能看得清楚了，他被治愈了，视力恢复了。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 8:4; 马可福音 8:23; 马可福音 5:43"> 耶稣让他回家去，说：“回家的路上，不要穿越村庄。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="换言之，不要将刚才发生的事情说出去。">d</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马太福音 16:13–20; 路加福音 9:18–20"> 耶稣和门徒离开了，向腓立比附近的该撒利亚村庄走去。路上他问门徒：“人们认为我是谁？”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约翰福音 1:21; 马太福音 14:2; Malachi 4:5"> 门徒回答：“有人说是施洗约翰，有人说是以利亚，还有人说是先知。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约翰一书 4:15; 马太福音 16:15–16; 约翰一书 5:1"> 他又问他们：“那么你们认为我是谁？”<br />彼得回答：“你就是弥赛亚！”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 9:21; 马太福音 16:20; 马可福音 9:9"> 耶稣警告他们，不要把他的事情告诉其他人。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马可福音 10:33–34; 约翰福音 2:19; 路加福音 24:26"> 然后开始教导他们，人子必然会受许多苦，被长老、祭司长和宗教老师所拒绝。他们会将他杀害，但他三天后会复活。</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 16:22; 约翰福音 16:25; 约翰福音 16:29"> 耶稣很明确地做出了解释，彼得把他拉到一边，责怪他不该这么说。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 4:10; 腓立比书 3:19; 约翰一书 2:15"> 耶稣转过身来望着他的门徒，斥责彼得说：“撒旦，离我远点！因为你未想上帝所想，只想人之所想。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马太福音 10:38; 路加福音 14:26–27; 约翰福音 10:27"> 耶稣唤来民众和门徒，对他们说：“如果有人愿意跟从我，就应当舍弃自己，背起他的十字架跟随我。</span>
<span className="v" id="v35" data-v="35" data-xref="提摩太后书 2:11–13; 哥林多前书 9:23; 路加福音 17:33"> 如果你顾惜自己的生命，必丢掉性命，但为我和福音牺牲生命，必拯救生命。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="马太福音 16:26; 路加福音 9:25; Psalms 49:17"> 纵使获得全世界，却赔上自己的生命，又有何用？</span>
<span className="v" id="v37" data-v="37" data-xref="Psalms 49:7–8; 彼得前书 1:18–19"> 人拿什么换回自己的生命呢？</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 12:8–9; 罗马书 1:16; 约翰一书 2:23"> 在这不忠的罪恶人群中<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="“羞于承认我，”或者，“不要为我表态。”">e</a></sup>，如果你因为知晓我和我的传道而为耻<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="字面意思是“一代。”">f</a></sup>，那么当人子在天父的荣耀中与圣天使一起降临之时，也必将以知晓你为耻。”</span>
</div>
</div>

</div>

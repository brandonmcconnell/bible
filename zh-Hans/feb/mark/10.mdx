<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 10:40; 马可福音 4:2; 约翰福音 11:7"> 耶稣离开迦百农，动身去往约旦另一侧的犹太境内。许多人又聚集到他那里，他像平常一样教导他们。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 7:10–11; 路加福音 11:53–54; 约翰福音 8:6"> 有几个法利赛人前来试探耶稣，问他：“休妻是否合法？”</span>
<span className="v" id="v3" data-v="3" data-xref="Isaiah 8:20; 加拉太书 4:21; 路加福音 10:25"> 耶稣回答：“摩西怎么对你们说的？”</span>
<span className="v" id="v4" data-v="4" data-xref="Deuteronomy 24:1–4; 马太福音 5:31–32; Isaiah 50:1"> 他们说：“摩西准许男人写休书即可休妻。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="见《申命记》24:1。">a</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 19:8; Nehemiah 9:26; 使徒行传 7:51"> 耶稣说：“正是因为你们的铁石心肠，摩西才为你们写了这条律法。</span>
<span className="v" id="v6" data-v="6" data-xref="Genesis 1:27; Genesis 5:2; Genesis 1:1"> 但在创世之初，上帝创造了男人和女人。</span>
<span className="v" id="v7" data-v="7" data-xref="Genesis 2:24; 马太福音 19:5–6; 以弗所书 5:31"> 所以男人要离开父母，通过婚姻与妻子结合，</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 5:28; Genesis 2:24; 哥林多前书 6:16"> 二人便成为一体。不再是两个人，而成为一个人。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="见《创世纪》2:24。">b</a></sup></span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 7:1–3; 1 Chronicles 7:10–13"> 上帝结合为一体，任何人都不能将之分开。”</span>
<span className="v" id="v10" data-v="10" data-xref="马可福音 9:33; 马可福音 9:28; 马可福音 4:10"> 回到房间中，门徒们再次向耶稣询问此事。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 5:31–32; 马太福音 19:9; 哥林多前书 7:10–11"> 他对他们说：“休妻另娶者，便是对其妻子犯下奸淫之罪。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 7:11; 哥林多前书 7:13"> 如果妻子弃夫另嫁，也是犯了奸淫之罪。”</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 19:13–15; 路加福音 18:15–17; Exodus 10:9–11"> 有人带着自己的孩子来到耶稣面前，求他祝福他们，但门徒想要把孩子们赶走。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 19:14; 马太福音 18:10; 马太福音 18:4"> 耶稣见此非常不快，对门徒说：“让小孩子到我这里来，不要制止他们，因为上帝之国就属于这些孩子一样的人。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 18:3; 路加福音 18:17; 约翰福音 3:3–6"> 告诉你们实话，如果你无法像小孩子一样接受上帝之国，就绝对无法进入。”</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 9:36; Isaiah 40:11; 约翰福音 21:15–17"> 于是耶稣把小孩子抱起来，把手放在他们身上进行祝福。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 19:16–30; 路加福音 18:18–30; 罗马书 2:7"> 耶稣继续开始旅程。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="去耶路撒冷。见11:1。">c</a></sup>一个人跑过来跪在他面前，问到：“我的良善老师，我要怎样做才能获得永生？”</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 18:19; 马太福音 19:17; 罗马书 3:12"> 耶稣问他：“你为何称我良善？除了上帝以外，无人为良善。</span>
<span className="v" id="v19" data-v="19" data-xref="Exodus 20:12–17; 罗马书 13:9; 雅各书 2:11"> 你知道那条诫命吗：不可杀人，不可奸淫，不可偷盗，不可做假证供，不可欺诈，当孝敬父母......”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《出埃及纪》20:12-16或《申命记》5:16-20。">d</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="Ezekiel 33:31–32; 提摩太后书 3:5; 腓立比书 3:6"> 他对耶稣说：“老师，我从小便遵守这些诫命。”</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 6:19–21; 启示录 2:4; 路加福音 18:22"> 耶稣用充满爱的眼神看着他说：“你还缺少一样：去变卖你所有的财富，将它们分给穷人，这会让你在天国拥有财富，然后你便可来跟从我。”</span>
<span className="v" id="v22" data-v="22" data-xref="约翰一书 2:15–16; 提摩太前书 6:9–10; 路加福音 12:15"> 那人听此脸色一变，满心郁闷地离开了，因为他非常富有。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 1:26; 路加福音 18:24; 马可福音 3:5"> 耶稣环顾四周，对门徒说：“富有之人要进上帝之国，谈何容易！”</span>
<span className="v" id="v24" data-v="24" data-xref="雅各书 5:1–3; Proverbs 11:28; Psalms 52:7"> 这番话让门徒非常惊讶。耶稣又对他们说：“我的朋友们，要进上帝之国非常困难！</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 19:24–25; 路加福音 18:25; 马太福音 23:24"> 有钱人想要进入上帝之国，比让骆驼穿过针眼还困难！”</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 16:31; 哥林多后书 11:23; 罗马书 10:9–13"> 门徒们更为困惑，对彼此说：“那么人间还有谁可以被拯救呢？”</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 19:26; Jeremiah 32:27; Job 42:2"> 耶稣看着他们说：“从人的角度来看不可能，但对上帝却不然，对于上帝而言，一切皆可能。”</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 19:27–30; 路加福音 18:28–30; 路加福音 14:33"> 彼得对他说：“我们已经舍弃了一切跟随你......”</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 9:23; 马太福音 5:10–11; 马可福音 8:35"> 耶稣说：“告诉你们实话，如果你为了我和福音舍弃房屋、兄弟、姐妹、母亲、父亲、儿女、田地，好消息是，</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 18:30; 腓立比书 3:8; 哥林多后书 6:10"> 你会在适当的时候得到一百倍的家庭、兄弟姐妹、孩子和土地。但也会面临困扰，在即将到来的世界中，他们将获得永生。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 19:30; 路加福音 13:30; 马太福音 20:16"> 但先来者会排在最后，后来者排在前。”</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 20:17–19; 路加福音 18:31–34; 路加福音 9:51"> 他们继续向耶路撒冷走去，耶稣走在前面，门徒们心有疑虑，其他追随者则感到害怕。耶稣把十二门徒叫到一边，把自己即将遭遇的事情告诉他们。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 27:2; 马太福音 20:17–19; 马可福音 8:31"> 他说：“我们现在要去耶路撒冷，人子将被交给祭司长和宗教老师，他们将认定他有罪，把他交给异教徒。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="此处指罗马人。">e</a></sup></span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 26:67; 马太福音 16:21; 马可福音 14:65"> 他们将迫害他，向他吐唾沫，鞭打他，杀害他，但三天后他将复活。”</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 20:20–28; 2 Samuel 14:4–11; 1 Kings 2:20"> 西庇太的儿子雅各和约翰来到耶稣跟前，对他说：“老师，请满足我们向你请求的愿望。”</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 15:7; 1 Kings 3:5–15; 马可福音 10:51"> 耶稣说：“想要我为你们做什么？”</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 19:28; 马可福音 16:19; 路加福音 24:26"> 他们说：“当你终获荣耀，<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="隐喻之意。">f</a></sup>请让我们一个坐在你的右边，一个坐在你的左边。”</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 12:50; 马太福音 20:21–22; Psalms 75:8"> 耶稣说：“你们知道自己在求什么吗？我从杯中喝下的痛苦，你们能喝吗？我受的洗，你们能受吗？”</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 12:2; 启示录 1:9; 约翰福音 17:14"> 他们说：“能。” 耶稣说：“你们会饮我从杯中喝下的痛苦，你们会受我的洗。</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 20:23; 马太福音 25:34; 约翰福音 17:24"> 但我无法决定谁会坐在我的左右。这是上帝的意愿，他准备将其赐予谁，就会赐给谁。”</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 20:24; Proverbs 13:10; 罗马书 12:10"> 其他十个门徒听见了，对雅各和约翰之举感到很生气。</span>
<span className="v" id="v42" data-v="42" data-xref="彼得前书 5:3; 路加福音 22:25; 马太福音 20:25"> 耶稣把他们叫过来说：“你们知道各国都有统治国家的人压迫其人民。这些统治者的行为就像暴君。</span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 23:8–12; 路加福音 14:11; 马可福音 9:35"> 但这对你们而言却并非如此，谁想成为你们中的统治者，就必然变成你们的侍从，</span>
<span className="v" id="v44" data-v="44"> 谁想成为你们之首，必做众人的奴隶。</span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 20:28; 腓立比书 2:5–8; 哥林多后书 8:9"> 即使是人子来，也并非为了接受他人的服侍，而是为了服侍他人，以自己的生命赎很多人之命。”</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 18:35–1; 马太福音 20:29–34; 约翰福音 9:8"> 耶稣和门徒穿过耶利哥，在离开城镇的时候，身边簇拥着大批民众，其中有一个名叫巴底摩斯<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="对于非犹太读者，马可还补充说：巴底摩斯的意思是“提马乌斯的儿子。”">g</a></sup>的盲人坐在路旁。</span>
<span className="v" id="v47" data-v="47" data-xref="马可福音 1:24; 马太福音 9:27; 启示录 22:16"> 听见身边路过的是拿撒勒人耶稣，他就喊叫，说：“耶稣，大卫的子孙啊，可怜我吧！”</span>
<span className="v" id="v48" data-v="48" data-xref="Jeremiah 29:13; 马可福音 7:26–29; 希伯来书 5:7"> 许多人斥责他，叫他不要出声。他却更高声喊叫：“耶稣，大卫的子孙啊，可怜我吧！”</span>
<span className="v" id="v49" data-v="49" data-xref="路加福音 18:40; 马太福音 20:32–34; 约翰福音 11:28"> 耶稣站住，说：“把他叫过来。”大家把盲人唤来，对他说：“好消息！<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="原意为“鼓足勇气。”">h</a></sup>起来吧，他叫你过去了。”</span>
<span className="v" id="v50" data-v="50" data-xref="腓立比书 3:7–9; 希伯来书 12:1"> 巴底摩斯跳起来，丢下自己的外衣匆匆忙忙来到耶稣身边。</span>
<span className="v" id="v51" data-v="51" data-xref="路加福音 18:41–43; 马可福音 10:36; 马太福音 7:7"> 耶稣问他：“你要我为你做什么？”盲人说：“老师，我想要看见。”</span>
<span className="v" id="v52" data-v="52" data-xref="马太福音 9:22; 使徒行传 26:18; 马可福音 8:25"> 耶稣说：“你可以走了，你对我的信心让你痊愈了<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="或“被拯救。”这个词意思为“拯救”或“治愈。”">i</a></sup>。”巴底摩斯立刻看见了，于是便一路跟随耶稣。</span>

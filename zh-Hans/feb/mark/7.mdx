<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="feb" data-translation-id="cmn_feb" data-translation-label="易读圣经" data-book="MRK" data-book-slug="mark" data-book-name="马可福音" data-chapter="7" data-verses="37">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 15:1–20; 马可福音 3:22; 路加福音 5:17"> 几个法利赛人和宗教老师从耶路撒冷来，与耶稣相见。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 10:28; 马太福音 7:3–5; 罗马书 14:14"> 他们看见他的门徒中，有人用不干净的手吃饭（饭前不洗手）。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 1:14; 马可福音 7:13; 歌罗西书 2:8"> （法利赛人和所有犹太人都拘守祖先的传统，吃东西前必须认真洗手。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 9:10; 马太福音 23:25; 路加福音 11:38–39"> 同样，从集市回家后，若不洗手就不吃东西。他们还遵循其他传统，例如洗杯、洗罐、洗铜器等等。）<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这样做的目的，是为了确保每个流程都符合仪式要求的干净程度。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="帖撒罗尼迦后书 3:6; 使徒行传 21:21; 马太福音 15:2"> 法利赛人和宗教老师问耶稣：“你的门徒为什么不遵行祖先的传统，要用不洁的手吃饭<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“面包。”">b</a></sup>？”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="Isaiah 29:13; 提多书 1:16; 马太福音 15:7–9"> 耶稣对他们说：“以赛亚关于你们这群伪君子的预言太对了：‘这些人只把尊敬挂在嘴上，心却在远离我。</span>
<span className="v" id="v7" data-v="7" data-xref="Isaiah 29:13; 马太福音 15:9; 雅各书 1:26"> 他们只把律条当作人类规则讲述，所以拜我也是徒然。’<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《以赛亚书》29:13。">c</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 7:3–4; Isaiah 1:12"> 你们小心地遵循着人间的传统，却背弃了上帝的诫命。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="Jeremiah 44:16–17; 加拉太书 2:21; Isaiah 29:13"> 耶稣又对他们说：“你们为了坚守自己的传统，以取巧的方式违背了上帝的律法。</span>
<span className="v" id="v10" data-v="10" data-xref="Exodus 21:17; Exodus 20:12; Deuteronomy 5:16"> 摩西说：‘当孝敬父母’，还说：‘咒骂父母必被处死’。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《出埃及纪》20:12或《申命记》21:17。">d</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 23:18; 提摩太前书 5:4–8; 马太福音 15:5"> 但也有人会说：‘我把应该给你们的供奉，都用做各耳板 (上帝供物）了，</span>
<span className="v" id="v12" data-v="12"> 所以就不必为父母做什么’。</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 7:9; 提多书 1:14; 马太福音 5:17–20"> 你们通过这种方式遵循传统，摒弃上帝的教诲。你们做的很多事情都是如此。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 15:10; Isaiah 6:9; Proverbs 8:5"> 于是耶稣又把民众叫过来，对他们说：“大家听我说，也要理解，</span>
<span className="v" id="v15" data-v="15" data-xref="Proverbs 4:23; Leviticus 11:42–47; 提多书 1:15"> 真正让你污秽的，不是从外界进入你身体的东西，而是从你身体出来的东西。”</span>
<span className="v" id="v16" data-v="16"> <sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="最早期的经文中没有第 16 句。">e</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 15:15; 马太福音 13:36; 马可福音 9:28"> 然后耶稣离开民众，走进屋子，门徒过来问他这比喻是什么意思。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 15:16–17; 希伯来书 5:11; Isaiah 28:9–10"> 他对他们说：“你们这也不明白吗？难道你们不知道？从外界进入体内的，不会让人感到污秽。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 15:17; 哥林多前书 6:13; 歌罗西书 2:21–22"> 因为外界之物不会进入你的思想，而是进入你的内脏，最后排泄到外面。所以从仪式的角度来讲，所有食物都是‘洁净的’”<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有的学者认为，这句话是后加上去的。">f</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="雅各书 3:6; 雅各书 1:14–15; 雅各书 4:1"> 接着他又说：“从你身上出来的东西才使你不洁净。</span>
<span className="v" id="v21" data-v="21" data-xref="Jeremiah 17:9; 罗马书 8:7–8; 雅各书 4:1–3"> 因为从人的内在和思想所传出来的，可能是恶念、淫乱、偷盗、凶杀、</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 20:15; 马太福音 6:23; 彼得前书 2:15"> 奸淫、贪心、邪恶、诡诈、放荡、嫉妒、毁谤、骄傲、愚妄。</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 7:15; 提多书 1:15; 哥林多前书 3:17"> 这一切恶事，都源于内在，让人污秽。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="马太福音 15:21–28; 马太福音 11:21; Ezekiel 28:2"> 随后耶稣动身去往推罗地区，住在那里的一所房子中，本来不想让人知道，但他的行踪却隐藏不住。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 15:22; 马可福音 9:17–23; 使徒行传 10:25–26"> 一个女人的小女儿被恶灵附体，听说耶稣的事情后，就过来俯伏在他脚前。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 15:22; Isaiah 49:12; 加拉太书 3:28"> 这女人是希腊人，生于叙利斐尼基。他求耶稣把鬼从她女儿身上赶出去。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马太福音 15:23–28; 马太福音 7:6; 使徒行传 22:21"> 耶稣对她说：“应该先让孩子吃饱。把喂孩子的饼丢给狗吃可不好。”<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="或宠物狗、小狗。">g</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="罗马书 10:12; 罗马书 3:29; 使徒行传 11:17–18"> 那女人回答他：“主啊，是的。但狗可以在桌子底下吃孩子们掉下来的碎渣。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="Isaiah 66:2; 马太福音 5:3; 约翰一书 3:8"> 耶稣对她说：“就凭这个回答，你回去吧，鬼已经从你女儿身上出去了。”</span>
<span className="v" id="v30" data-v="30" data-xref="约翰一书 3:8; 约翰福音 4:50–52"> 她回到家，看见女儿在床上躺着，恶灵已经离开她的身体。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马可福音 5:20; 马太福音 15:29–31; 马太福音 4:25"> 耶稣离开推罗，经过西顿回到低加波利地区的加利利海。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 11:14; 马可福音 5:23; 马太福音 9:32–33"> 有人带来一个聋哑人来到他面前，求耶稣触摸他。</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 8:23; 约翰福音 9:6–7; 马可福音 5:40"> 耶稣把他从人群中带到一边，将手指伸入他的耳朵，用自己的唾沫抹在他的舌头上，</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 11:41; 马可福音 5:41; 马可福音 6:41"> 然后望着天叹了一口气，对他说：“以法大！”<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="这是个阿拉米词语，意为“打开。”">h</a></sup>意为：“打开吧！”</span>
<span className="v" id="v35" data-v="35" data-xref="Isaiah 35:5–6; Psalms 33:9; 马可福音 2:12"> 那人的听力和说话的能力就恢复了，可以正常说话。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 8:4; 马可福音 8:26; 马可福音 3:12"> 耶稣嘱咐他们不要告诉其他人，但越是嘱咐，他们就越传扬这消息。</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 6:51; 马可福音 5:42; Exodus 4:10–11"> 众人非常惊讶地说：“他的所作所为都太惊人了，竟然能让聋人听见，让哑巴说话。”</span>
</div>
</div>

<span className="v" id="v1" data-v="1" data-xref="启示录 12:3; 启示录 17:3; Daniel 7:23–25"> 龙站在海岸处，然后我又看见一个野兽从海里升起，他有十角七头，十角戴着十个皇冠，七头上显示亵渎的名字。</span>
<span className="v" id="v2" data-v="2" data-xref="Daniel 7:4–7; 彼得前书 5:8; 启示录 17:12"> 我所看见的野兽外表好似豹子，脚如熊，口像狮子。龙把自己的能力、王位和伟大权力都交给了它。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 17:8; 启示录 13:14; 启示录 17:17"> 兽的七头中，有一个似乎受了致命伤，但那致命伤却医好了。地球上的每个人都对那野兽感到惊奇，</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 13:2; 启示录 18:18; 启示录 13:15"> 于是纷纷膜拜那龙，因为他已经将其权力交给了野兽；于是他们膜拜野兽，询问：“有谁可以跟这兽相比？谁能战胜它？”</span>
<span className="v" id="v5" data-v="5" data-xref="Daniel 7:8; Daniel 7:25; Daniel 11:36"> 他被赋予了大肆吹嘘和说亵渎话的能力，而且他还被授予了四十二个月个月的权力，可以这样做。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 12:34; 希伯来书 9:24; 启示录 12:12"> 他一开口，就向上帝说出亵渎的话，侮辱了他的人格<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“名字。”">a</a></sup>、他的圣殿<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="避难所：或“住处。”">b</a></sup>以及那些住在天上的。</span>
<span className="v" id="v7" data-v="7" data-xref="Daniel 7:21; 启示录 11:7; Daniel 7:25"> 那野兽获得攻击信徒的权力，能够战胜他们；他也被赋予了对每个民族、部落、语言和国家的权柄。</span>
<span className="v" id="v8" data-v="8" data-xref="彼得前书 1:19–20; 以弗所书 1:4; 马太福音 25:34"> 所有住在地上的人都膜拜它，那些名字没有记录在生命书之中的人，这本书属于创世以来被杀的羊羔。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 2:7; 启示录 2:17; 启示录 2:11"> 如果你有耳朵，就要听！</span>
<span className="v" id="v10" data-v="10" data-xref="Jeremiah 15:2; Isaiah 33:1; 启示录 14:12"> 如果人应该被虏获，就一定会被虏获；如果有人会被刀杀，就一定会刀杀<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="这里有两种版本的说法。这段经文也可以说：用刀杀人的人，自己也会被刀杀，与《马太福音》26:52 意思相同。但下一段的内容是鼓励信徒忍受迫害，不要想着报复，因此这里的版本是首选。见《耶利米书》15:2。">c</a></sup>。在显示了上帝信徒的忍耐和信心！</span>
<span className="v" id="v11" data-v="11" data-xref="Daniel 7:8; 哥林多后书 11:13–15; 马太福音 7:15"> 我又看见另一只野兽从地里升起。它有两个角，好像羊羔，说话好像龙。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 17:10–11; 启示录 14:11; 启示录 14:9"> 他在与第一头野兽一样，拥有相同的权力，可以让大地和住在地上的人，都去膜拜那受过致命伤、但已被医好的第一头野兽。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 24:24; 启示录 19:20; 帖撒罗尼迦后书 2:9–10"> 他做出了伟大的奇迹，甚至在人面前从天上呼唤火，降落地上。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 12:9; 启示录 19:20; 启示录 13:8"> 他因为像第一头野兽那样可以做出神迹，于是迷惑了住在地上的人，便吩咐哪些人，要为受过刀伤、但死而复生的野兽做一个像。</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 20:4; 启示录 19:20; Daniel 3:3–6"> 他被允许将生命之气注入那野兽的像，让兽像能够说话，能够杀害那些不拜兽像之人。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 20:4; 启示录 19:20; Ezekiel 9:4"> 他又让每个人——无论虚弱强大、无论贫穷富有、无论自由或身为奴隶，在他们的右手或额头上得到一个标记。</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 15:2; 启示录 13:16; 启示录 14:11"> 这记号就是那野兽的名字或他名字的数字，除了有记号的人，谁也不能买，也不能卖。</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 15:2; 启示录 17:9; 启示录 21:17"> 这里需要智慧。能够理解之人，应该可以计算出野兽的数字，因为这是人的数字，它的数字是 666。</span>

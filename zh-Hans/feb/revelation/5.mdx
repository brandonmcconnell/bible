<span className="v" id="v1" data-v="1" data-xref="Ezekiel 2:9–10; Isaiah 29:11; 启示录 5:7"> 我看见坐在宝座上那位，右手拿着书卷，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“右手。”这是一种假设，希腊语中简单的表达方式为“在他的右边。”">a</a></sup>书卷两面都写满了字，有七个封印。</span>
<span className="v" id="v2" data-v="2" data-xref="Isaiah 29:11–12; 启示录 5:5; 启示录 10:1"> 我又看见一位力量强大的天使，大声喊道：“谁配展开这书卷并拆开它的封印？”</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 5:13; Isaiah 40:13–14; 罗马书 11:34"> 在天上、地上和地底，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“天上，地上或地底。”这里的意思很简单，就是“无处不在。”这并不见得意味着“地下”有意识的人。又见 5:13。">b</a></sup>没有人能够展开书卷阅读。</span>
<span className="v" id="v4" data-v="4" data-xref="Daniel 12:8–9; 启示录 4:1"> 找不到配展开并阅读书卷的人，我为之大哭。</span>
<span className="v" id="v5" data-v="5" data-xref="Isaiah 11:1; Jeremiah 23:5–6; 启示录 22:16"> 一位长老对我说：“不要哭！看，犹大部落的狮子、大卫的后裔，他已经赢得这场战斗，能够展开书卷，拆开它的七印。”</span>
<span className="v" id="v6" data-v="6" data-xref="Zechariah 4:10; 约翰福音 1:29; 启示录 5:12"> 我看见在宝座和四个活物中间，在众长老之中，有一个羊羔，好像被杀掉了，有七个羊角和七个眼睛，那是上帝的七灵，被派到世界各地。</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 5:1; 启示录 4:2–3"> 羊羔走过去，从宝座上那位的右手拿了书卷。</span>
<span className="v" id="v8" data-v="8" data-xref="Psalms 141:2; 启示录 8:3–4; 腓立比书 2:9–11"> 拿到书卷后，四个活物和二十四位长老俯伏在羊羔前，各拿着琴和盛满了香的金炉，这香是众信徒的祈祷。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 1:18–19; 约翰一书 1:7; 马太福音 26:28"> 他们唱着一首新歌：“你配拿到书卷并拆开封印，因你曾被杀，用你的血从所有部落、语言、民族和国家处赎回上帝的人。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 1:6; Daniel 7:27; 启示录 20:6"> 你让他们成为我们上帝的国和祭司，他们要在人间执掌王权。”</span>
<span className="v" id="v11" data-v="11" data-xref="Daniel 7:10; 希伯来书 12:22; 启示录 4:4"> 我继续看着，听见千万天使的声音，他们都围在宝座、活物和长老的周围，</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 5:9; 启示录 19:1; 启示录 4:11"> 大声说：“被杀的羊羔配得上获得权能、财富、智慧、力量、尊贵、荣耀和祝福！”</span>
<span className="v" id="v13" data-v="13" data-xref="腓立比书 2:10; 1 Chronicles 29:11; Psalms 148:2–13"> 我又听见在天上、地上、地底和海中的一切造物，以及天地间的万物都说：“愿祝福、尊贵、荣耀和权利，都归于坐在宝座上的那一位和羊羔，直到永远！”</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 19:4; 启示录 4:9–11; 启示录 5:8"> 四个活物说：“阿门！”众长老也俯伏敬拜。</span>

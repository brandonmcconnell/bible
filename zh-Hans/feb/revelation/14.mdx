<span className="v" id="v1" data-v="1" data-xref="Joel 2:32; 启示录 3:12; 启示录 7:3–17"> 我又观看，见羊羔站在锡安山上，与他一起的还有十四万四千人，额上都写着他的名和他父的名。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 5:8; Ezekiel 43:2; 启示录 1:15"> 我听见天上传来一个声音，听起来就像流淌的水和响雷，又像很多竖琴弹奏的琴声。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 5:9; 启示录 14:1; 启示录 15:3"> 他们在宝座前、在四个活物和众长老面前，唱了一首新歌。除了十四万四千人，即那些从地上被赎回的人，没有人能够学会这首歌。没有人能学这歌。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 3:4; 哥林多后书 11:2; 雅各书 1:18"> 这些人没有与妇女一起让自己玷污，他们在精神上是纯洁的。无论羊羔去哪里，他们都会跟随。这些人是从世人中兑换而来，作为初熟之果交给上帝和羊羔。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 5:27; Psalms 32:2; Zephaniah 3:13"> 他们不说谎言；他们没有瑕疵。</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 16:15; 启示录 8:13; 以弗所书 3:9–11"> 我又看见另一位天使在天空飞翔，有永恒的福音要传给住在地上的人，提供给不同国家、部落、语言和民族的人。</span>
<span className="v" id="v7" data-v="7" data-xref="Exodus 20:11; 启示录 15:4; Nehemiah 9:6"> 他大声说：“应当敬畏上帝，把荣耀归给他！因为他审判的时候到了。应当敬拜创造天、地、海和水泉源的那一位！”</span>
<span className="v" id="v8" data-v="8" data-xref="Isaiah 21:9; Jeremiah 51:7–8; 启示录 18:2–3"> 又有第二位天使接着喊道：“伟大的巴比伦崩塌成废墟！<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="见《以撒亚纪》21：9。">a</a></sup>她使所有的国家都喝了她的性罪之酒，使上帝愤怒地反对他们。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这里暗指《耶利米书》51:7。通过第 10 节和耶利米的暗示，似乎可以得出这样的结论：即这里所指为“上帝愤怒反对的酒。”当然，这里是用人类的语言描述上帝，虽然他明确强烈反对罪行，但不应该从堕落人性的角度理解“愤怒”和“怒火”等词语。">b</a></sup></span>
<span className="v" id="v9" data-v="9" data-xref="启示录 14:11; 启示录 14:6–8; 启示录 13:3–6"> 又有第三位天使，跟随前两个天使大声喊：“如果有人膜拜野兽和兽像，又在自己的额上或手上接受记号，</span>
<span className="v" id="v10" data-v="10" data-xref="Isaiah 51:17; 启示录 16:19; Jeremiah 25:15–17"> 他们将喝下上帝愤怒反对的酒<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或“愤慨。”">c</a></sup>，这酒未进行过滤就斟在上帝震怒的杯中，他必定在众天使和羊羔面前，在火与硫磺之中受痛<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或者“被折磨。”请注意，这里的术语（也用于下面的经文中使用）为被动语态。">d</a></sup>苦。</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 19:3; Isaiah 34:10; 马太福音 25:41"> 他们痛苦的烟向上冒，直到永远。那些膜拜野兽和兽像的，以及接受其名字记号的人，日夜得不到安宁。”</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 13:10; 启示录 12:17; 启示录 3:10"> 这意味着，信徒必须耐心地忍耐，遵守上帝的诫命，信靠耶稣。</span>
<span className="v" id="v13" data-v="13" data-xref="启示录 20:6; 提摩太后书 4:7–8; 帖撒罗尼迦前书 5:10"> 我听见天上有声音说：“你要写下来！从今以后，那些在主里死去的人有福了！”灵说：“是的，他们脱离自己的劳苦，他们所成就的也为他们佐证”<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="愿意为“将跟随他们。”">e</a></sup></span>
<span className="v" id="v14" data-v="14" data-xref="Daniel 7:13; Isaiah 19:1; 马太福音 17:5"> 我继续看。看到一朵白云，云上那位好似人子<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="见《但以理书》7:13。">f</a></sup>，头上戴着金冠，手里拿着锋利的镰刀。</span>
<span className="v" id="v15" data-v="15" data-xref="Joel 3:13; 马太福音 13:39; 马可福音 4:29"> 另一位天使从圣殿出来，对坐在云上的那位大声呼喊：“伸出你的镰刀来收割吧！因为收割时间已到，地上的庄稼已熟透。”</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 16:27; 启示录 14:19; 启示录 14:14"> 那坐在云上的向地上挥动镰刀，地上的庄稼就被收割了。</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 14:18; 启示录 14:14–15; 启示录 15:5–6"> 又有另一位天使从天上的圣殿出来，他也拿着一把锋利的镰刀。</span>
<span className="v" id="v18" data-v="18" data-xref="Joel 3:13; 启示录 16:8; 启示录 14:15–16"> 他身后是一位天使，从祭坛处而来，拥有负责火的权力；他向那拿着锋利镰刀的天使大声说：“伸出你锋利镰刀，收获地上葡萄树累累硕果！因为葡萄已经熟透。”</span>
<span className="v" id="v19" data-v="19" data-xref="Deuteronomy 32:32–33; 启示录 19:15–21"> 那天使便向地上挥动镰刀，收取地上的葡萄，把葡萄扔在上帝审判的压榨大酒池中。<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="原意为“愤怒”（又见15:7、16:1、19:15）。参见 6:16 脚注中关于“愤怒”的注释。">g</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="Lamentations 1:15; 启示录 19:14–21; Isaiah 63:1–3"> 那压榨酒池在城外被踹踏，就有血从压榨池中流出来，涨到马嚼环那么高，流到大约三百 公里那么远。<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="184英里 (296 公里)。">h</a></sup></span>
</div>

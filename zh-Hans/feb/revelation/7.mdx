<span className="v" id="v1" data-v="1" data-xref="马太福音 24:31; Daniel 7:2; Jeremiah 49:36"> 然后我看见四位天使站在地的四角<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="古人认为地球有四个角，风从那里吹来。">a</a></sup>，控制着四个方向的风，防止风吹在地面、海面和树上。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 4:30; 哥林多后书 1:22; 启示录 7:3–8"> 我又看见另外一位天使，从东方站起，拿着永活上帝的封印，向那四位得了权力、可以伤害地与海的天使，大声呼喊，</span>
<span className="v" id="v3" data-v="3" data-xref="Ezekiel 9:4; 启示录 22:4; 启示录 9:4"> 他说：“你们不要伤害大地、海洋和树木，要等我们在上帝众信徒的额上先盖上印。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="启示录 14:1; 启示录 14:3; 马太福音 19:28"> 我听见被盖印的人数：以色列子孙各部落共十四万四千人：以色列子孙所有部落中被封印的：</span>
<span className="v" id="v5" data-v="5" data-xref="Exodus 1:2–4; Numbers 10:14–27; Numbers 13:4–16"> 犹太部落一万二千人；流本部落一万二千人；迦得部落中一万二千人；</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 2:36"> 亚设支部落一万二千人；拿弗他利部落一万二千人；玛拿西部落一万二千人；</span>
<span className="v" id="v7" data-v="7" data-xref="Genesis 35:23; Numbers 26:14; Numbers 25:14"> 西缅部落一万二千人；利未部落一万二千人；以萨迦部落一万二千人；</span>
<span className="v" id="v8" data-v="8"> 西布伦部落一万二千人；约瑟部落一万二千人；便雅悯部落一万二千人。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="启示录 5:9; 约翰福音 12:13; Psalms 117:1–2"> 之后我看到一大群人，没有人能数得过来他们的数量，来自所有国家、部落、民族和方言。他们站在宝座和羊羔面前，身穿白袍，手里拿着棕树枝。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 19:1; Psalms 3:8; Isaiah 45:21"> 他们大声呼喊，说：“救赎来自那坐在宝座上我们的上帝，以及来自羊羔！”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="启示录 5:11–13; 启示录 19:4–6; 启示录 4:10"> 所有天使都围在宝座、众长老和四个活物的四 伏在宝座前，敬拜上帝。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 5:12–14; 犹大书 1:25; Psalms 100:4"> 他们说：“阿门！愿祝福、荣耀、智慧、感谢、荣誉、权能和力量，都归给我们的上帝，直到永远。阿门！”阿门。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="启示录 7:9; 启示录 4:10; 启示录 5:5"> 一位长老问我：“这些身穿白袍的是谁？他们从哪里来？”</span>
<span className="v" id="v14" data-v="14" data-xref="约翰一书 1:7; 启示录 22:14; 希伯来书 13:12"> 我回答：“我主啊，你知道答案。”他告诉我：“这些人经历过巨大的迫害。他们用羊羔的血，把自己的长袍洗白。</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 21:3–4; 启示录 22:3; 哥林多后书 6:16"> 因此他们才能坐在上帝的宝座前，日夜在他的圣殿中事奉他。那坐在宝座上的，也会以其存在而保护他们。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“以其存而保护他们”：原意为“在他们中间搭帐篷”，在《约翰福音》1:14 中使用了同样的词形容耶稣的到来。">b</a></sup></span>
<span className="v" id="v16" data-v="16" data-xref="Isaiah 49:10; Psalms 121:6; 马太福音 5:6"> 他们不会再挨饿，不会再口渴；太阳不会炙烤他们，他们也不会因炎热而受苦，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《以赛亚书》 49:10.">c</a></sup></span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 7:37–38; Psalms 36:8–9; 约翰福音 4:14"> 因为在宝座中间的羊羔会成为他们的牧羊人，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《诗篇》 23:1.">d</a></sup>领他们到生命水泉，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="引自《以赛亚书》49:10。">e</a></sup>上帝也必抹去他们的一切眼泪。”<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="引自《以赛亚书》25:8。">f</a></sup></span>
</div>
</div>

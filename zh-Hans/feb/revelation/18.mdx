<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Ezekiel 43:2; 路加福音 17:24; 帖撒罗尼迦后书 2:8"> 这之后，我看见另一位天使从天而降，他拥有伟大的权力<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或“权威。”">a</a></sup>，他的荣耀照亮了大地。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 14:8; Jeremiah 51:8; Jeremiah 51:37"> 他用强有力的声音呼喊：“伟大的巴比伦倾倒为废墟！<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="见《以撒亚纪》21：9。">b</a></sup>她已成为恶魔的住处，各样污灵的庇护所，一和一切不洁可憎之鸟的栖息地。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 14:8; 启示录 17:2; 启示录 18:9"> 因为各国都喝<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或者“因为……而堕落。”">c</a></sup>了她淫乱烈怒的酒，喝醉了；地上的君王与她行淫，世上的商人因她的挥霍发了财。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="Isaiah 52:11; 哥林多后书 6:17; Jeremiah 51:6"> 我听见天上传来另一个声音，说：“从那城出来吧，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="见《耶利米书》51:45。">d</a></sup>我的子民！免得她的罪你们也有分，受她所受的灾难；</span>
<span className="v" id="v5" data-v="5" data-xref="Genesis 18:20–21; Ezra 9:6; 启示录 16:19"> 因为她罪恶滔天，上帝发现了她的邪恶。</span>
<span className="v" id="v6" data-v="6" data-xref="Jeremiah 50:29; Psalms 137:8; Jeremiah 51:24"> 她怎样待人，你们也要怎样待她；按照她的行为加倍报应她；按照她的酒杯，将加倍的痛苦调给她。</span>
<span className="v" id="v7" data-v="7" data-xref="Isaiah 47:7–9; Zephaniah 2:15; Lamentations 1:1"> 就像她对自己的吹嘘和放纵自己的欲望一样，给她的回报也是一样的痛苦和悲伤。她告诉自己：‘我如女王统治<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="愿意为“坐着。”">e</a></sup>，我不是寡妇，决不会感到悲伤。’</span>
<span className="v" id="v8" data-v="8" data-xref="Jeremiah 50:34; Jeremiah 50:31; 启示录 17:16"> 因为只需一天，她的灾难必然来到，那就是死亡、悲哀和饥荒；她还要被火中摧毁，因为谴责<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="或“法官。”">f</a></sup>她的主上帝是有着巨大的能力。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="启示录 19:3; 启示录 18:3; 启示录 17:2"> 地上的众王跟她一同行邪淫, 骄奢无度，看见焚烧她的烟，就会为她痛哭捶胸。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 18:19; 启示录 18:8; 启示录 18:15–17"> 他们害怕会遭受她所受的痛苦，所以远远站着，说：‘灾难！灾难！灾难降临这伟大的城市巴比伦。只需一小时，您的审判就实行了！’</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="启示录 18:3; 启示录 18:23; Ezekiel 27:27–36"> 地上的商人也为她悲哀痛哭，因为没有人再买他们的货物：</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 17:4; Ezekiel 27:5–25; Proverbs 8:10–11"> 金、银、宝石、珍珠；细麻布、紫色布、丝绸、红色材料；各样香木制品，各样象牙制品，各样贵重木器、铜器、铁器、大理石制品；</span>
<span className="v" id="v13" data-v="13" data-xref="Ezekiel 27:13; Amos 2:6; 彼得后书 2:3"> 肉桂、香料、焚香、乳香；酒、橄榄油、面粉、麦子；牛、羊、马、车、奴仆和囚犯。<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="原意为“人的身体和灵魂。”">g</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 10:6; Psalms 106:14; 路加福音 16:25"> 你失去了最喜爱的甜蜜快乐<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="原意为“成熟的果实。”">h</a></sup>！一切奢华闪亮的财富都从你那里消失，再也找不到了！</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 18:3; 使徒行传 19:24–27; Ezekiel 27:31"> 贩卖这些货物、借着她发财的商人，因为害怕会遭受她受的痛苦，就远远地站着。他们哭喊着、悲伤着，说</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 17:4; 路加福音 16:19–31; 启示录 18:10–11"> ‘灾难！灾难降临了这伟大城市！她穿着细麻布紫色长袍，佩戴金子、宝石和珍珠的珠宝，</span>
<span className="v" id="v17" data-v="17" data-xref="Ezekiel 27:27–36; 启示录 17:16; Isaiah 23:14"> 只一小时，所有这些财富竟荡然无存！’每个船长、每个海上旅客和水手、以及每个靠海谋生的，都远远地站着。</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 13:4; Ezekiel 27:30–32; 启示录 18:9–10"> 摧毁她的火焰飘出烟，他们看到了，就喊叫说：‘有哪座城能与这伟大的城相比？’</span>
<span className="v" id="v19" data-v="19" data-xref="启示录 18:10; Joshua 7:6; Ezekiel 27:30"> 他们把尘土撒在自己头上，痛哭悲哀，喊着说：‘灾难！因为她的奢侈，灾难打击了这让船主富有的伟大城市！只一小时，她就被摧毁了！’</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="启示录 6:10; 启示录 19:1–3; 路加福音 18:7–8"> 天堂、众信徒、众使徒和众先知，庆祝她所发生的事，因为上帝审判她的方式就像审判你一样。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="Jeremiah 51:63–64; Ezekiel 26:21; 启示录 5:2"> 一位强大的天使，把一块好像磨石一样的石头举起来，拋入海里，说：“伟大的巴比伦城也会被这暴力拋下去，再也不存在。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="Ezekiel 26:13; Jeremiah 25:10; Jeremiah 7:34"> “你们再也不会听到音乐了，竖琴、歌手、长笛和号角。再也不会有任何行业的工匠在你这里工作。在你身上再也听不到磨坊磨出面粉的声音了。</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 18:3; Isaiah 23:8; Nahum 3:4"> 你们再也不会有灯的亮光照耀了。你们再也听不到新郎新娘的声音了。你们这些商人领导这个世界，所有国家都因你们的邪术受了迷惑。</span>
<span className="v" id="v24" data-v="24" data-xref="启示录 17:6; 启示录 16:6; Jeremiah 51:49"> 在这个城市中，能找到先知、信徒和地上一切被杀之人的血。”</span>
</div>
</div>

</div>

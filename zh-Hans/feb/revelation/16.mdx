<span className="v" id="v1" data-v="1" data-xref="Zephaniah 3:8; Jeremiah 10:25; 启示录 15:1"> 我听见圣殿中传来巨大的声音，对七位天使说：“去吧，把上帝审判的七个碗倒在地上！”</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 8:7; 启示录 16:11; 启示录 13:15–18"> 第一位天使去了，把碗倒在地上，于是在那些有兽记号和膜拜兽像的人身上，生出了可怕的恶性毒疮。</span>
<span className="v" id="v3" data-v="3" data-xref="Exodus 7:17–21; 启示录 8:8–9; 启示录 11:6"> 第二位天使把碗倒在海里，海水就变成好像死人的血，海中的所有生物都死了。</span>
<span className="v" id="v4" data-v="4" data-xref="Exodus 7:17–20; 启示录 8:10–11; Hosea 13:15"> 第三位天使把碗倒在江河和众水的泉源里，水就变成了血。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 1:8; 启示录 11:17; 启示录 1:4"> 我听见掌管众水的天使说：“正如这审判所表明的那样，那过去和现在的胜者，真如审判所显示，你是真正的正确。</span>
<span className="v" id="v6" data-v="6" data-xref="Isaiah 49:26; 启示录 11:18; 启示录 6:10–11"> 这些人曾流过信徒的血，现在你给他们血喝，这是他们该受的。”</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 19:2; 启示录 6:9; 启示录 15:3–4"> 我又听见祭坛中有声音说：“是的，主啊！全能的上帝，你的审判是正义而公正的！”</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 2:20; 启示录 14:18; Jonah 4:8"> 第四位天使把碗倒在太阳上，太阳就得到了能力，可以用火烤人。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 2:21; 启示录 16:21; 启示录 11:13"> 人被高热烧烤，亵渎那有权力掌管这些灾难的上帝之名，但他们并不悔改，不肯将荣耀归给他。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 9:2; 马太福音 8:12; Isaiah 8:21–22"> 第五位天使把碗倒在野兽的王座上，野兽的王国就黑暗，人因为痛苦就咬自己的舌头。</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 16:9; 启示录 16:2; 启示录 16:21"> 他们因为所受的痛苦和所生的疮，亵渎天上的上帝，却并不为自己所作的悔改。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 9:14; Jeremiah 51:36; Isaiah 44:27"> 第六位天使把碗倒在幼发拉底大河上，河水干涸，为了要给那些从东方来的王预备道路。</span>
<span className="v" id="v13" data-v="13" data-xref="启示录 19:20; 帖撒罗尼迦后书 2:9–11; 启示录 20:10"> 我看见三个邪灵，好像青蛙从龙口、兽口和假先知的口中出来。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 17:14; 提摩太前书 4:1; 启示录 20:8"> 他们是魔鬼的灵，做出神奇之事，他们汇聚了普天下的众王，叫他们在全能上帝的伟大审判日中聚集作战。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 5:2–3; 马太福音 24:42–43; 彼得后书 3:10"> （注意了！我会像贼一样到来！<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="即：出乎意料。">a</a></sup>祝福那些保持警惕、衣服做好准备的人，让他们不至于赤身行走并感到耻辱。）</span>
<span className="v" id="v16" data-v="16" data-xref="Zechariah 12:11; Judges 5:19; Joel 3:9–14"> 邪灵就把众王聚集在一个地方，希伯来话叫哈米吉多顿。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 19:30; 启示录 21:6; 以弗所书 6:12"> 第七位天使把碗倒在空中，此时从圣殿的宝座处传来很大的声音：“结束了！”</span>
<span className="v" id="v18" data-v="18" data-xref="Daniel 12:1; 启示录 4:5; 启示录 11:19"> 于是出现闪电、雷轰和大地震，自从地面有人生活以来，从未发生过这么大的地震，</span>
<span className="v" id="v19" data-v="19" data-xref="启示录 18:5; 启示录 17:18; 启示录 18:21"> 那大城裂为三段，列国的城也都倒塌了。上帝想起巴比伦大城，好让她得到装满他敌意之酒的杯子。</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 6:14; 启示录 20:11; Jeremiah 4:23–25"> 各海岛都消失了，众山不见。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 11:19; Joshua 10:11; 启示录 16:9"> 大冰雹从天而落，每块重约五十公斤<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="希腊人说“天赋的重量。”">b</a></sup>，砸在人身上。由于这冰雹的灾，人们便诅咒上帝，因为这灾太严重了。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 21:15; Ezekiel 42:15–20; Zechariah 2:1–2"> 有人给我一根量尺，告诉我：“你起来量一量神的殿和祭坛，数一数在那里敬拜的人。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 12:6; Daniel 7:25; 路加福音 21:24"> 但不要量圣殿外面的院子，因为它已经交给异族人，他们要践踏圣城四十二个月。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="启示录 12:6; 启示录 11:2; Deuteronomy 19:15"> 我要将能力赐给穿著麻衣的两个人见证人，他们要持续预言一千二百六十天。”</span>
<span className="v" id="v4" data-v="4" data-xref="Zechariah 4:11–14; Zechariah 4:2–3; Jeremiah 11:16"> 他们就是站在大地之主面前的两棵橄榄树和两个灯台。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="参见《撒迦利亚书》4:14。">a</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="Jeremiah 5:14; 2 Kings 1:10–12; Hosea 6:5"> 如果有人想要伤害他们，就有火从他们口中喷出，烧死他们的敌人。凡是想要伤害他们的，都会被杀死。</span>
<span className="v" id="v6" data-v="6" data-xref="1 Kings 17:1; 路加福音 4:25; Psalms 105:26–36"> 他们有力量在其预言的时候关闭天空，不再下雨；有权力将水变成血，随时用各样灾难攻击大地，它们想要多少次都可以。</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 13:7; Daniel 8:23–24; Daniel 7:25"> 他们完成其见证时，那从深渊上来的野兽就会与他们作战，战胜他们并将其杀死。</span>
<span className="v" id="v8" data-v="8" data-xref="Jeremiah 23:14; 启示录 18:10; 启示录 18:21"> 他们的尸首会倒在大城市的开阔道路上。这些城在精神层面代表着所多玛和埃及，也是他们的主被钉上十字架的地方。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="显然是指耶路撒冷。">b</a></sup></span>
<span className="v" id="v9" data-v="9" data-xref="Psalms 79:2–3; 启示录 17:15; 启示录 10:11"> 在三天半的时间中，来自各民族、部落、语言和国家的人会看着他们的尸首，但不许把尸首安葬在坟墓中。</span>
<span className="v" id="v10" data-v="10" data-xref="1 Kings 18:17; 启示录 3:10; 使徒行传 5:33"> 地上居住的人因为他们之死而欢喜庆祝，彼此赠送礼物，因为这两位先知曾经让他们受痛苦。</span>
<span className="v" id="v11" data-v="11" data-xref="Genesis 2:7; 罗马书 8:11; 罗马书 8:2"> 但三天半后，上帝赋予生命的气息进入他们体内，他们就站立起来，看见这一切的人非常惧怕。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="这段希腊文（11:7-11）中的动词时态从将来变为现在到过去。这里的翻译保持了这个变化。">c</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="启示录 4:1; 2 Kings 2:11; 使徒行传 1:9"> 两位见证人听见从天上来的巨大声音，告诉他们：“上到这里来！”于是他们驾云上了天，他们的仇敌都看到了。</span>
<span className="v" id="v13" data-v="13" data-xref="启示录 14:7; 启示录 6:12; Joshua 7:19"> 就在那时，大地震发生了，那座城倒塌了十分之一，因地震而死的有七千人，其他人都很害怕，把荣耀归于天上的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="启示录 8:13; 启示录 9:12; 启示录 15:1"> 第二次灾祸过去了，第三次灾祸快要到了！</span>
<span className="v" id="v15" data-v="15" data-xref="Daniel 7:14; 启示录 12:10; Daniel 7:27"> 第七位天使吹响号角，天上传来巨大的声音说：“世上的国家成了我们主和基督所立的国，他要作王，直到永永远远！”</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 4:4; 启示录 4:10; 启示录 7:11"> 那在上帝面前坐在自己座位上的二十四位长老，朝着向地面俯倒敬拜上帝，</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 1:8; 启示录 16:5; 启示录 4:8–9"> 他们说：“过去和现在都存在的全能之主上帝，我们感谢你，因为你执掌了大权并成为统治者！</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="启示录 19:5; 启示录 20:12; 启示录 6:10–11"> 各国非常愤怒，但你的审判也来到了，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="即审判日。关于人之愤怒与上帝愤怒的对立解读，见 6:16。">d</a></sup>这是死人受审判的时刻！你的仆人、先知、信徒只要尊重你的权威，无论虚弱或拥有全力，都要得赏赐！在此刻，你也将毁灭那些毁灭大地的人！”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="启示录 16:21; 启示录 15:5–8; Ezekiel 38:22"> 于是，上帝在天上的圣殿打开，他的约柜<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="或“契约”">e</a></sup>在圣殿中显现，随即出现闪电、雷鸣、地震、大冰雹。</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="feb" data-translation-id="cmn_feb" data-translation-label="易读圣经" data-book="REV" data-book-slug="revelation" data-book-name="启示录" data-chapter="21" data-verses="27">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Isaiah 65:17–19; 彼得后书 3:13; Isaiah 66:22"> 我又看见一个新天、新地<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="见《以赛亚书》65:17，《以赛亚书》66:22。">a</a></sup>，因为第一个天和第一个地都过去了，海也不再存在了。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:10; 启示录 3:12; 启示录 21:10"> 我看见圣城，新耶路撒冷，从天上上帝那里降下来，做好准备，仿佛打扮整齐等候丈夫的新娘。</span>
<span className="v" id="v3" data-v="3" data-xref="Ezekiel 37:27; 哥林多后书 6:16; 约翰福音 14:23"> 我听见宝座那里传来巨大声音，说：“现在上帝的家<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这个词的原意为“搭帐篷。”">b</a></sup>与人类在一起，他将与他们一起生活，他们将成为他的子民。上帝要亲自与他们同在，作他们的上帝。</span>
<span className="v" id="v4" data-v="4" data-xref="Isaiah 25:8; 启示录 7:17; 哥林多前书 15:26"> 他要从他们的眼中抹去一切眼泪<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《以赛亚书》25:8。">c</a></sup>，不再发生死亡，不再有悲哀、哭号或痛苦，因为之前的世界已不复存在。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 5:17; Isaiah 42:9; Isaiah 43:19"> 坐在宝座上的那一位说：“我让一切都变成新的！”他告诉我：“写下来，因为这些话都是可信的、真实的。”</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 7:37–38; 约翰福音 4:10; 启示录 7:17"> 他又对我说：“一切都完成了，我是阿拉法，我是欧米茄；我是初始，也是最终。我要把生命的泉水，免费送给那些口渴的人喝。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 6:18; 希伯来书 8:10; 启示录 2:11"> 那些获胜的，要继承这一切。我要作他的上帝，他要作我的孩子。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 6:9–10; 启示录 2:11; 以弗所书 5:5–6"> 但那些胆怯的、不信我的、做出可恶事情的、杀人的、淫乱的、行邪术的、拜神像的和所有说谎的人，他们选择的地点<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“他们所选之地”：或“他们的地方。”">d</a></sup>就是那烧着硫磺的火湖。这就是第二次的死亡。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="启示录 21:2; 启示录 19:7; 启示录 16:1–17"> 拿个七碗的七位天使之一，走来对我说：“和我一起来！我像你展示这位新娘，羊羔的妻子。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="启示录 21:2; Ezekiel 11:24; Ezekiel 40:1–49"> 在灵中，他带我来到一座很高山峰的顶端，向我展示上帝降下来的圣城耶路撒冷，</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 4:6; 启示录 22:5; 启示录 22:1"> 上帝的荣光让它闪耀，城市的光辉好像极贵的宝石，又像晶莹的碧玉。</span>
<span className="v" id="v12" data-v="12" data-xref="Ezekiel 48:31–34; 启示录 7:4–8; 启示录 21:17–21"> 城墙高大厚实，有十二个门，门口有十二位天使，门上写着以色列十二部落的名字。</span>
<span className="v" id="v13" data-v="13" data-xref="Ezekiel 48:31–34"> 东边有三个门，南边有三个门，西边有三个门，北边有三个门。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 11:10; 以弗所书 2:20; Isaiah 54:11"> 城墙有十二个根基，根基上有羊羔的十二使徒名字。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="Zechariah 2:1; 启示录 11:1–2; Ezekiel 41:1–5"> 对我说话的天使拿着一根黄金量尺，要丈量那城、城门和城墙。</span>
<span className="v" id="v16" data-v="16" data-xref="Ezekiel 48:35; Ezekiel 48:8–20"> 城为四方形状，长宽相同。天使用芦苇丈量那城，共 12,000 弗隆，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="大约 1,500 英里">e</a></sup>长、宽、高都一样；</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 7:4; Deuteronomy 3:11; 启示录 13:18"> 他又丈量了城墙，厚 144 腕尺<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="超过 200 英尺。">f</a></sup>。天使用的就是人类的度量衡。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="启示录 21:11; 启示录 21:21; 启示录 21:19"> 城墙以碧玉制成，城用看起来像是玻璃的纯金打造。</span>
<span className="v" id="v19" data-v="19" data-xref="Isaiah 54:11–12; Exodus 28:17–21; Job 28:16–19"> 城墙的根基点缀着各样宝石：第一座根基是碧玉，第二座是蓝宝石，第三座是玛瑙，第四座是绿宝石，</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 4:3"> 第五座是红玛瑙，第六座是红宝石，第七座是黄璧玺，第八座是水苍玉，第九座是红璧玺，第十座是翡翠，第十一座是紫玛瑙，第十二座是紫晶。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="启示录 21:18; 启示录 17:4; 启示录 22:2"> 十二个门由珍珠制成，每一个门都用一个珍珠打造。城里的街道是纯金的，好像透明的玻璃。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 4:23; 1 Kings 8:27; 2 Chronicles 2:6"> 我在那里没有看见圣殿，因为主全能的上帝和羊羔就是城的圣殿。</span>
<span className="v" id="v23" data-v="23" data-xref="Isaiah 60:19–20; 启示录 22:5; 启示录 21:11"> 这城不需要日月照明，因为有上帝的荣耀照明，而羊羔就是城市的灯。</span>
<span className="v" id="v24" data-v="24" data-xref="启示录 21:26; 启示录 22:2; Zechariah 8:22–23"> 所有国家要在它的光中行走，地上的国王要把他们的荣耀带到这城来。</span>
<span className="v" id="v25" data-v="25" data-xref="Isaiah 60:11; Zechariah 14:7; 启示录 22:5"> 城门白天决不关闭。在那里并没有黑夜。</span>
<span className="v" id="v26" data-v="26" data-xref="启示录 21:24"> 所有国家的荣华尊贵都被带到这城。</span>
<span className="v" id="v27" data-v="27" data-xref="启示录 22:14–15; Isaiah 52:1; 启示录 20:15"> 不洁净的、拜神像的、说谎的，都不能进入——只有那些写在羔羊生命册上的才可以。</span>
</div>
</div>

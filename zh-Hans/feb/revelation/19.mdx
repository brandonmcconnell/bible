<span className="v" id="v1" data-v="1" data-xref="启示录 7:10–12; 1 Chronicles 29:11; 启示录 11:15"> 这之后，我听见天上好像有一大群人的喧闹声：“哈利路亚！救恩、荣耀、权能都属于我们的上帝，</span>
<span className="v" id="v2" data-v="2" data-xref="Deuteronomy 32:43; 启示录 6:10; 启示录 18:20"> 因为他的审判是真实正义的；因为他审判了那臭名昭著、以淫乱败坏世界的淫妇；并因为那淫妇谋害其仆人而对其进行判决。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“为了她手上他仆人的血。”">a</a></sup></span>
<span className="v" id="v3" data-v="3" data-xref="Isaiah 34:10; 启示录 18:18; 启示录 14:11"> 他们又喊了一次：“哈利路亚！她的毁灭所产生的浓烟永远升腾。”</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 5:14; Nehemiah 8:6; Psalms 106:48"> 那二十四位长老和四个活物，俯伏敬拜坐在宝座上的上帝，喊道：“阿门！哈利路亚！”</span>
<span className="v" id="v5" data-v="5" data-xref="Psalms 134:1; Psalms 148:11–13; Psalms 150:6"> 接宝座传出声音，说：“所有上帝的仆人哪！凡是尊重他的，无论大小，都应当赞美我们的上帝！”</span>
<span className="v" id="v6" data-v="6" data-xref="Psalms 97:1; 启示录 14:2; Psalms 93:1"> 又听见一个声音，好像是一大群人，如奔流的水，又像惊雷，说：“哈利路亚！因为主、我们全能的上帝统治了！</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 21:9; 启示录 21:2; 启示录 19:9"> 让我们欢喜庆祝，把荣耀归给他！因为羊羔的婚期到了；他的新娘也自己预备好了。”</span>
<span className="v" id="v8" data-v="8" data-xref="Isaiah 61:10; 启示录 7:13–14; Psalms 132:9"> 她得到了干净的白色细麻衣，（细麻衣代表着信徒的好工作）</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 22:6; 马太福音 22:2–4; 路加福音 14:15–16"> 天使对我说：“写下来：‘受邀参加羊羔婚筵的人太幸福了！’”他又对我说：“这都是上帝真实说的话。”</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 22:8–9; 使徒行传 10:25–26; 约翰福音 5:39"> 我就俯伏在天使脚前要拜他。但他对我说：“不可以这样！我和你以及那些接受耶稣作见证的人一样，都是上帝的仆人。敬拜上帝，因为耶稣的证言就是预言的灵。”</span>
<span className="v" id="v11" data-v="11" data-xref="Psalms 96:13; Isaiah 11:3–5; Psalms 98:9"> 我看着天打开了。有一匹白马站在那里，骑士叫做“忠信”和“真实”，当他审判，他是正义的；当他战斗，他是正义的。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 19:16; 路加福音 10:22; 启示录 2:17–18"> 他的眼睛好像火焰，头上戴着许多皇冠，身上写着一个名字除了他自己没有人认识。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 1:1; Isaiah 63:1–6; 约翰福音 1:14"> 他身穿一件浸过血的衣服，他的名字叫做“上帝之道。”</span>
<span className="v" id="v14" data-v="14" data-xref="犹大书 1:14; 启示录 7:9; 启示录 19:8"> 天上的众军都骑着白马，穿著洁白的细麻衣，跟随他。</span>
<span className="v" id="v15" data-v="15" data-xref="Isaiah 63:2–6; 启示录 1:16; 启示录 2:27"> 他口中吐出一把利剑，用于击打列国。他将用铁杖治理他们，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="见《诗篇》 2:9.">b</a></sup>他自己还要在全能上帝审判的压酒池踩葡萄。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 17:14; 提摩太前书 6:15; Daniel 2:47"> 在他的长袍和大腿上，写着“万王之王，万主之主”的名号。</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 19:21; 启示录 8:13; Ezekiel 39:17–20"> 我又看见一位天使站在太阳中，向高空所有的飞鸟大声呼喊：“来吧！聚集起来赴上帝的伟大宴席！</span>
<span className="v" id="v18" data-v="18" data-xref="Ezekiel 39:18–20; 启示录 6:15; 1 Samuel 17:44"> 这里可以吃死人的肉：君王、领袖、壮士、还有马和骑士，以及无论是自由的、作奴隶的、伟大的、渺小的，吃所有人的肉。”</span>
<span className="v" id="v19" data-v="19" data-xref="启示录 16:16; 启示录 16:14; 启示录 17:12–14"> 我看见那野兽和地上的国王，还有他们的众军，都集合起来，要跟那马背骑士和他的军队作战。</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 20:10; 启示录 21:8; 帖撒罗尼迦后书 2:8–11"> 那野兽被捉住了；连同在兽面前做出奇事的假先知（通过这种方式，他欺骗那些接受了野兽记号、膜拜野兽像的人）。他们都被活活拋在烧着硫磺的火湖里去。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 19:11–15; 启示录 1:16; 启示录 19:17–19"> 其余的人都被那白马骑士口中吐出来的剑杀了，他们的肉让飞鸟吃饱了。</span>

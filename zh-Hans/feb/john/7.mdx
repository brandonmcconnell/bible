<span className="v" id="v1" data-v="1" data-xref="约翰福音 5:16–18; 约翰福音 4:3; 马太福音 21:38"> 此后，耶稣便在加利利游历。他不想住在犹太，因为犹太人想要他死。</span>
<span className="v" id="v2" data-v="2" data-xref="Zechariah 14:16–19; Deuteronomy 16:13–16; Exodus 23:16–17"> 但由于犹太人的住棚节即将到来，</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 12:46; 约翰福音 7:5; 路加福音 8:19"> 耶稣的弟弟们对他说：“你应当离开这里去犹太，让你的追随者能够看到你可以显现的神迹。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 18:20; Proverbs 18:1–2; 马太福音 23:5"> 想成名的人不会藏起来。既然你可显现神迹，就应该向世人展示自己！”</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 3:21; 约翰福音 1:11–13; Micah 7:5–6"> 即使他的弟弟们也不相信他。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 7:8; 约翰福音 2:4; 约翰福音 7:30"> 耶稣就对他们说：“我的时间还没有到，但你们可以去任何地方，因为对你们而言，任何时间都可以。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 15:18–19; 约翰福音 3:19; 加拉太书 4:16"> 世人没有理由恨你们，但却憎恨我，因为我表明他们的行为是邪恶的。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 7:6; 约翰福音 8:20; 约翰福音 7:30"> 你们去过节吧！我就不去这个节日了，因为我的时机还没到，还不成熟。”</span>
<span className="v" id="v9" data-v="9"> 说完这番话，他继续留在加利利。</span>
<span className="v" id="v10" data-v="10" data-xref="Amos 5:13; 马太福音 10:16; Isaiah 42:2–3"> 他的弟弟们去过节以后，耶稣也去了，但没有公开，而是躲开了众人的视线。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 11:56"> 在节日期间，犹太人的首领们四处寻找耶稣，不断问众人：“他在哪儿？”</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 7:40–43; 约翰福音 9:16; 约翰福音 7:32"> 人群中有很多人开始谈论耶稣，有的说：“他是好人。”有的说：“不，他就是个骗子。”</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 9:22; 约翰福音 19:38; 约翰福音 20:19"> 但没有人敢公开这样说，怕犹太人首领会对付他们。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 7:28; 路加福音 19:47; 约翰福音 7:37"> 逾越节过半，耶稣来到圣殿，开始教导众人。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 4:22; 马太福音 7:28–29; 马太福音 13:54"> 犹太人首领对此颇感意外，于是询问道：“这人没有学过教育，为什么如此有学识<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="即宗教方面的教育。">a</a></sup>？”</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 14:10; 约翰福音 14:24; 约翰福音 17:8"> 耶稣回答：“我的学识并非源于自己，而是来自派我到这里的那个人。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 8:31–32; 约翰福音 8:43; Jeremiah 31:33–34"> 你若选择遵循上帝的意愿，就会知道我这学识是出于上帝，还是仅在讲述我个人的想法。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 5:41; 哥林多前书 10:31–33; 约翰福音 13:31–32"> 如果你讲述的是自己的想法，就是想要荣耀自己。但如果你只是为了让派你前来之人获得荣耀，这才是真诚，才不会存在谎言。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 1:17; 约翰福音 11:53; 马太福音 12:14"> 摩西给你们带来了律法，是不是？但你们没有一个人遵行这律法。你们为什么想要杀我？”</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 10:20; 约翰福音 8:48; 约翰福音 8:52"> 众人回答：“你是魔鬼附体！没人想要杀你！”</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 7:23; 约翰福音 5:2–11"> 耶稣回答：“我显现了一个神迹<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="在安息日，所指的是5:1-9中所述之事。">b</a></sup>，你们为止感到震惊。</span>
<span className="v" id="v22" data-v="22" data-xref="Leviticus 12:3; Genesis 17:10–14; 罗马书 4:9–11"> 摩西告诉你们要进行割礼——其实这并非源自摩西，而是源自他之前的祖先。所以你们在安息日也会进行割礼。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 12:5; 约翰福音 5:14–16; 马太福音 12:2"> 如果为了遵循摩西的律法，你们在安息日举行割礼，那么我在安息日让一个人痊愈，为什么会让你们怒火中烧呢？</span>
<span className="v" id="v24" data-v="24" data-xref="Isaiah 11:3–4; 雅各书 2:9; 约翰福音 8:15"> 不要因外貌而判断别人，要做出正确的决定。”</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 7:10–11"> 这时，有几个来自耶路撒冷的人开始思量：“这就是他们想要杀的人吗？</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太后书 1:7–8; 约翰福音 7:48; 约翰福音 12:42"> 但你看他说话如此坦诚，他们却保持沉默，你觉得长官们真的相信这就是基督吗？</span>
<span className="v" id="v27" data-v="27" data-xref="Micah 5:2; 约翰福音 7:41–42; 约翰福音 6:42"> 那是不可能的，我们知道他从哪里来，而基督到来之际，没有人知道他从何而来。”</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 8:42; 约翰福音 8:19; 约翰福音 8:26"> 此刻耶稣正在殿里教导众人，他高声说：“你们以为认识我，知道我从何而来。但我来此并非出于我的意愿，那派我来此的人真实存在，你们不认识他。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 8:55; 马太福音 11:27; 约翰福音 17:18"> 但我认识他，因为我从他那里而来，也是受他派遣。”</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 8:20; 约翰福音 10:39; 约翰福音 7:6"> 于是犹太长官想要逮捕他，但没有人下手，因为他的时刻尚未到来。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 12:42; 马太福音 12:23; 约翰福音 10:41–42"> 但民众中有许多人相信他。他们说：“如果基督出现，难道会比这个人显现更多神迹吗？”</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 18:3; 路加福音 22:52–53; 约翰福音 11:47–48"> 法利赛人听到民众低声议论耶稣，他们和祭司长就派差役去逮捕耶稣。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 16:5; 约翰福音 13:33; 马可福音 16:19"> 这时候耶稣对众人说：“我和你们在一起的时间不多了，但我要回到派我前来之人那里去。</span>
<span className="v" id="v34" data-v="34" data-xref="Proverbs 1:24–31; 约翰福音 13:33–36; 约翰福音 14:6"> 你们会寻找我，但找不到，我将去的地方，你们无法进去。”</span>
<span className="v" id="v35" data-v="35" data-xref="雅各书 1:1; Isaiah 11:12; Zephaniah 3:10"> 犹太人彼此谈论：“这人要去哪个我们找不到的地方呢？难道他去的地方在异教徒那里吗？<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“希腊人。”">c</a></sup>他想去教导异教徒？</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 3:9; 约翰福音 7:34; 约翰福音 12:34"> 他说‘你们会寻找我，但找不到。我将去的地方，你们无法进去’这话，是什么意思？”</span>
<span className="v" id="v37" data-v="37" data-xref="Isaiah 55:1; 约翰福音 4:14; 约翰福音 6:35"> 在节日的最后一天、也是最隆重的那一天，耶稣站立高呼：“如果你渴了，到我这里来解渴！</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 4:14; Isaiah 44:3; Isaiah 58:11"> 正如经文所说，信我者，身体将流淌赋予生命的溪流。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="最接近的信息见《雅歌》4:15。">d</a></sup></span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 2:17; Joel 2:28; 约翰福音 14:16–17"> 他所指的是：相信他的人之后会获得圣灵，但因为耶稣尚未获得荣耀，所以圣灵还没有降临。</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 21:11; 约翰福音 1:21; 约翰福音 6:14"> 人群中有人听到这番话，就说：“他真的是先知！”<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="见 6:14。">e</a></sup></span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 7:52; 约翰福音 1:46; 约翰福音 1:49"> 有人说：“他是基督！”还有人说：“基督怎么能来自加利利呢？</span>
<span className="v" id="v42" data-v="42" data-xref="Micah 5:2; 马太福音 2:5; 路加福音 2:4"> 经文不是说基督是大卫的后裔，来自大卫的家乡伯利恒吗？”<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="即《弥迦书》5:2。">f</a></sup></span>
<span className="v" id="v43" data-v="43" data-xref="约翰福音 9:16; 约翰福音 10:19; 约翰福音 7:12"> 众人因对他的看法完全不同而争论起来，。</span>
<span className="v" id="v44" data-v="44" data-xref="约翰福音 7:30; 使徒行传 23:11; 约翰福音 8:20"> 有人想逮捕耶稣，但没有人这样做。</span>
<span className="v" id="v45" data-v="45" data-xref="约翰福音 7:32; 使徒行传 5:21–27"> 卫兵随后回到祭司长和法利赛人那里。他们问卫兵：“为什么没有把他带来？”</span>
<span className="v" id="v46" data-v="46" data-xref="马太福音 7:28–29; 路加福音 4:22; 约翰福音 7:26"> 卫兵回答：“从来没有人像他这样讲话。”</span>
<span className="v" id="v47" data-v="47" data-xref="约翰福音 7:12; 哥林多后书 6:8; 2 Kings 18:32"> 法利赛人说：“连你们也上当了？</span>
<span className="v" id="v48" data-v="48" data-xref="约翰福音 12:42; 哥林多前书 1:20; 哥林多前书 2:8"> 长官或法利赛人中有谁信他吗？没有！</span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前书 1:20–21; 约翰福音 9:40; 约翰福音 9:34"> 至于这群完全不懂律法之人，他们就是被咒诅的一群人！”</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 19:39; 约翰福音 3:1–2"> 他们当中有一人叫做尼哥德慕，以前曾经去见过耶稣。他对他们说：</span>
<span className="v" id="v51" data-v="51" data-xref="Proverbs 18:13; Deuteronomy 1:17; Deuteronomy 19:15–19"> “难道不该先审讯一下吗？查明他到底做了什么，否则我们的律法怎能给他定罪？”</span>
<span className="v" id="v52" data-v="52" data-xref="约翰福音 7:41; 约翰福音 1:46; Isaiah 9:1–2"> 他们回答：“那么你也是从加利利来的吗？去看看经文吧，你就知道先知并非来自加利利。”</span>
<span className="v" id="v53" data-v="53" data-xref="Psalms 33:10; Job 5:12–13; Psalms 76:10"> 然后众人都回家了。<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="在所有的经书中，这部分（7:53-8:11）的位置各不相同。但所讲记录的均为真实描述。">g</a></sup></span>
</div>

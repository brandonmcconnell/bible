<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 2:8; 马太福音 13:21; 马太福音 26:31–33"> “我把这一切告诉了你们，让你们不会放弃对我的信任。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 9:22; 使徒行传 26:9–11; 罗马书 10:2–3"> 人们会把你们赶出会堂，事实上时间已到，所有要杀害你们的人，都以为这样就是侍奉上帝。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 15:21; 约翰福音 17:25; 约翰福音 8:55"> 他们这样做是因为他们不认识天父，也不认识我。我把一切告诉你们，以便在这一切发生的时候，你们会记得我所说的话。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 14:29; 马可福音 13:23; 约翰福音 17:12–13"> 我无需在开始就告诉你们这一切，因为你们将跟随我。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 13:36; 约翰福音 7:33; 约翰福音 16:28"> 但现在我将要到派我来此的天父那里，但你们没有人问：‘你要到哪里去？’</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 14:1; 约翰福音 16:20–22; 路加福音 24:17"> 当然了，现在我把这一切都告诉了你们，你们便心生悲伤。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 14:26; 约翰福音 14:16–17; 约翰福音 15:26"> 但说实话，我的离开对你们更好。如果我不离开，保惠师就不会到来。我若离开，我就会派他来到你们身边。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 2:37; 犹大书 1:15; Zechariah 12:10"> 他到来的时候，就会说服世人，他们关于罪恶和正义的看法是错的，就会告诉他们什么是审判。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 15:22–25; 约翰福音 8:23–24; 约翰福音 12:47–48"> 关于罪，是因为他们不信我；</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 5:21; 彼得前书 3:18; 罗马书 10:3–4"> 关于义，是因为我到父那里去，你们就再看不见我；</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 12:31; 约翰一书 3:8; 希伯来书 2:14"> 关于审判，是因为这世界的统治者已经受了审判。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或“受到审判。”">a</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 4:33; 约翰福音 15:15; 哥林多前书 3:1–2"> 我还有许多事要告诉你们，可是你们现在无法承受；</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 14:26; 哥林多前书 2:10–13; 约翰福音 14:17"> 只等真理圣灵来到，他会教导你们一切真理。他不是为自己说话，而是把他听见的都说出来，把将来的事告诉你们。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰一书 4:13–14; 哥林多后书 3:14–18; 约翰福音 15:26"> 他让我荣耀，因为他要把从我那里获得的都告诉你们。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 17:10; 马太福音 11:27; 约翰福音 3:35"> 属于天父的一切也都属于我，所以我说，圣灵会把从我这里获得的告诉你们。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 7:33; 使徒行传 1:3; 约翰福音 14:18–24"> 不久后，你们不会再看见我，但再过一段时间，你们还要看见我。”</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 16:16; 马可福音 9:32; 约翰福音 16:5"> 于是他的门徒中有几个彼此说：“他对我们说：‘不久后，你们就不会再看见我，但再过一段时间，你们还要看见我。’又说：‘因为我要到天父那里去。’这是什么意思呢？”</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 24:25; 马太福音 16:9–11; 希伯来书 5:12"> 他们又说：“他所说的‘不久’，是什么意思呢？不理解他在讲什么。”</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 16:30; 约翰福音 16:16; 约翰福音 14:19"> 耶稣知道他们想问他，就说：“我所说的‘不久，你们不会看见我，但再过一段时间，你们还要看见我’，你们为了这话彼此议论吗？</span>
<span className="v" id="v20" data-v="20" data-xref="雅各书 1:2; 马太福音 5:4; Psalms 126:5–6"> 告诉你们实话，你们会痛哭哀号，世人却要欢喜，你们会忧愁，但你们的忧愁要变为欢乐。</span>
<span className="v" id="v21" data-v="21" data-xref="Psalms 113:9; Isaiah 13:8; 帖撒罗尼迦前书 5:3"> 妇人生产的时候会痛苦，因为这是分娩的时候。但生了孩子以后，就不再记住那痛苦了，而是欢喜孩子的诞生。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 1:8; 使徒行传 13:52; 约翰福音 16:6"> 是的，现在你们也会悲伤，但我会与你们再次相见，你们的心就会欢喜，没有人能夺走你们的欢喜。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 15:7; 约翰福音 14:13–14; 马太福音 21:22"> 到了那天，你们什么也不会问我了。告诉你们实话，以我的名向天父求的任何事，他必定给予你们。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 7:7–8; 雅各书 4:2–3; 约翰福音 15:11"> 你们一直以来没有以我的名求什么，现在你们祈求就必然应验，让你们的欢喜圆满。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 16:12; 马可福音 4:13; 马太福音 13:34–35"> 我一直用比喻向你们讲述，但很快，我不会再使用比喻，而是把关于天父的事明明白白讲出来。</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 8:34; 约翰福音 17:24; 约翰福音 17:19"> 到了那天，你们要以我的名祈求，我不是说我要以你们的名义请求天父，</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 14:21; 约翰福音 14:23; 约翰福音 17:23"> 因为天父爱你们，因为你们爱我，并且相信我来自上帝。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 13:1; 约翰福音 13:3; 约翰福音 8:14"> 我离开天父来到这世界，现在我要离开这世界，到天父那里去。”</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 16:25"> 门徒说：“现在你就明说了，不再用比喻，</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 21:17; 约翰福音 17:8; 约翰福音 16:17"> 现在我们很确定你无所不知，为了知道人们在想什么问题，你不需要问他们。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="即 16:19 中所述之事。">b</a></sup>因此，我们信你来自上帝。”</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 9:44–45; 约翰福音 13:38"> 耶稣对他们说：“现在你们真信吗？</span>
<span className="v" id="v32" data-v="32" data-xref="Zechariah 13:7; 马太福音 26:31; 约翰福音 8:29"> 时候要到了，其实已经到了，你们要分散到各自该去的地方，留我独自一个人。其实我不是独自一个人，因为有天父与我同在。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 14:27; 约翰一书 5:4; 帖撒罗尼迦后书 3:16"> 我把这些事告诉你们，是要使你们因为与我一体而平安。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="字面意思是，“在我里面的平安。”">c</a></sup>在世上你们会遭受苦难，但你们要勇敢，我已经胜过了这世界！”</span>
</div>

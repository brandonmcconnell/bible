<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 16:9; 马太福音 27:60; 约翰福音 19:25"> 下一周第一天清晨，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="即周日。">a</a></sup>天还没有亮，抹大拉的玛利亚来到墓旁，看见墓口的石头已经移开了。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 13:23; 约翰福音 20:13; 约翰福音 21:24"> 她就跑去见彼得和耶稣所爱的那个门徒，对他们说：“有人把主从坟墓里搬走了，我们不知道他们把他放在哪里了。”</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 24:12"> 彼得和那门徒就向坟墓跑去。</span>
<span className="v" id="v4" data-v="4" data-xref="2 Samuel 18:23; 哥林多后书 8:12; 哥林多前书 9:24"> 两个人一起跑，另一名门徒比彼得跑得快，先到了坟墓，</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 19:40; 约翰福音 20:11; 约翰福音 11:44"> 弯腰向里面观看，看见细麻布还在那里，但他却没有进去。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 18:17; 约翰福音 21:7; 马太福音 16:15–16"> 彼得随后也到了，他进入坟墓，看见细麻布还放在那里，</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 11:44"> 还看见耶稣头部的那块布，但没有和细麻布放在一起，而是折叠放着。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 20:25; 约翰福音 20:4; 约翰福音 1:50"> 这时候，先到坟墓的门徒也走了进去。</span>
<span className="v" id="v9" data-v="9" data-xref="Psalms 16:10; Isaiah 25:8; Isaiah 53:10–12"> 他四处张望，相信那句经文是正确的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="耶稣从死亡中重生。">b</a></sup>。在这之前，他们都没有理解经文中所说的：耶稣必须从死人中复活。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 7:53; 约翰福音 16:32"> 于是两个门徒就回到他们的住所。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="很显然，他们没有回到加利利的家，而是回到了在耶路撒冷的住所。">c</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 20:5"> 但玛利亚站在坟墓外面哭泣。她一边哭，一边弯腰往里面观看，</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 24:3–7; 启示录 3:4; 马可福音 16:5–6"> 却见到两名白衣天使，坐在曾安放耶稣身体的地方，一个坐在头的位置，一个在脚的位置。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 20:15; 约翰福音 2:4; 1 Samuel 1:8"> 天使问她：“你为什么哭？” 她说：“有人把我的主搬走了，我不知道他们把他放在哪里。”</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 24:16; 约翰福音 21:4; 马太福音 28:9"> 玛利亚说了这话，就转过身来，看见耶稣站在那里，但没有认出他就是耶稣。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 20:13; 约翰福音 18:7; 约翰福音 1:38"> 耶稣对她说：“你为什么哭？你找谁呢？”玛利亚以为耶稣是园丁，就对他说：“先生，如果是你把他搬走了，请告诉我你把他放在什么地方，我好去搬回来。”</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 10:3; 约翰福音 1:38; 使徒行传 10:3"> 耶稣对她说：“玛利亚！” 她转过身来看着耶稣，用希伯来语说了一句：“拉波尼！”（就是“老师”的意思。）</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 16:28; 以弗所书 4:8–10; 加拉太书 4:6–7"> 耶稣说：“你不要留住我，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="意为“不要困住我，将我留住。”">d</a></sup>因为我还没有升上天去见天父，去找我的兄弟们，告诉他们我要上天去见我的父，也是你们的父。我的上帝，也是你们的上帝。”</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 24:10; 马太福音 28:10; 约翰福音 20:1"> 于是抹大拉的玛利亚就去告诉其他门徒：“我已经看见主了！”她又把主对她所说的话告诉他们。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 20:26; 约翰福音 14:27; 约翰福音 20:21"> 下一周第一天夜晚的时候，门徒聚在一起，因为怕犹太人，就把门户都关上。耶稣来了，站在他们中间，说：“愿你们平安。”</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 16:22; 约翰福音 16:20; 约翰福音 20:27"> 说了这话，就把手和肋旁给他们看。门徒看见主，就欢喜了。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 17:18–19; 约翰福音 13:20; 约翰福音 3:17"> 耶稣又对他们说：“愿你们平安。天父怎样派我来，我也怎样派遣你们。”</span>
<span className="v" id="v22" data-v="22" data-xref="Job 33:4; Genesis 2:7; 使徒行传 8:15"> 说了这话，就向他们吹一口气，说：“领取圣灵吧！</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 18:18; 马太福音 16:19; 马可福音 2:5–10"> 你们赦免谁的罪，谁的罪就得赦免，你们不赦免谁的罪，谁的罪就不得赦免。”</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 11:16; 约翰福音 6:66–67; 希伯来书 10:25"> 十二个门徒中，有一个称为“双生子”的多马。耶稣来的时候，他没有和门徒在一起。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 6:30; 马可福音 16:11; 希伯来书 3:12"> 其他的门徒对他说：“我们已经见过主了。” 多马对他们说：“除非我亲眼看见他手上的钉痕，用我的指头探入那钉痕，又用我的手探入他的肋旁，否则我决不相信。”</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 20:19; Isaiah 54:10; 约翰福音 20:21"> 一星期之后，门徒又在屋子里，多马也和他们在一起。门户都关上了。耶稣到来，站在他们中间，说：“愿你们平安。”</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 20:25; 约翰一书 1:1–2; 约翰福音 20:20"> 然后对多马说：“把你的指头放在这里，看看我的手。伸出你的手，摸摸我的肋骨旁。不要疑惑，要相信！”</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 1:1; Isaiah 9:6; Isaiah 7:14"> 多马对他说：“我的主！我的上帝！”</span>
<span className="v" id="v29" data-v="29" data-xref="彼得前书 1:8; 哥林多后书 5:7; 希伯来书 11:1"> 耶稣说：“你因为看见我才信吗？那些没有看见就信的人，才是有福。”</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 21:25; 提摩太后书 3:15–17; 罗马书 15:4"> 耶稣在门徒面前还行了许多别的神迹，没有记在本书中。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 10:43; 约翰福音 3:15–16; 约翰一书 5:1"> 但记录这些事，是为了让你们信耶稣是基督，是上帝之子。你们信了，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原意为“以他之名。”">e</a></sup>就可以因相信他而获得生命。</span>
</div>

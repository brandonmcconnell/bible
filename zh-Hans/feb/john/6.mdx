<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 6:31–44; 约翰福音 6:23; 路加福音 5:1"> 在这之后，耶稣离开这里，去往加利利海（又名提比里亚海）的另外一边。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 4:24–25; 马太福音 12:15; 马太福音 15:30–31"> 由于目睹了他治愈病患的神迹，一大群人跟随他而行。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 6:15; 路加福音 9:28; 路加福音 6:12–13"> 耶稣走到山上，与门徒们坐在那里。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 2:13; 约翰福音 11:55; 约翰福音 5:1"> 此刻即将迎来犹太人的逾越节。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 15:33; 路加福音 9:12–13; 马太福音 14:14–15"> 耶稣环顾四周，看到大群人向他走来。于是他问腓力：“我们该到哪里买饼分给这些人？”</span>
<span className="v" id="v6" data-v="6" data-xref="Genesis 22:1; Deuteronomy 13:3; 2 Chronicles 32:31"> 耶稣这样说只是想看看腓力的反应，其实他早知道该怎样做。</span>
<span className="v" id="v7" data-v="7" data-xref="Numbers 11:21–22; 马可福音 6:37; 约翰福音 12:5"> 腓力回答：“就算花二百银币<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一个银币相当于一天的薪水。">a</a></sup>买饼，也不够给每人分一小块。”</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 1:40–44; 马太福音 4:18"> 有个门徒是西门（彼得）的弟弟安得烈，他对耶稣说：</span>
<span className="v" id="v9" data-v="9" data-xref="2 Kings 4:42–44; 马太福音 14:17; 马可福音 6:38"> “这里有个男孩，带着五块大麦饼和几条鱼。但这么多人，要怎么分才好呢？”</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 9:14–16; 马太福音 15:35–36; 马可福音 6:39–41"> 耶稣说：“让大家坐下吧。”这里的地上长着很多草，众人全部坐下，其中大约有五千名男子。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 6:23; 帖撒罗尼迦前书 5:18; 马太福音 15:36"> 耶稣拿起饼，感谢上帝后开始分给席地而坐的人群，然后以同样的方式分鱼，让所有人都获得了足够的食物。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 1:53; Nehemiah 9:25; Nehemiah 8:10"> 大家吃饱了之后，耶稣对门徒说：“把剩下的零碎收拾起来，免得浪费。”</span>
<span className="v" id="v13" data-v="13" data-xref="Proverbs 11:24–25; 2 Kings 4:2–7; 哥林多后书 9:8–9"> 门徒们开始收拾，五个大麦饼剩下的残渣，装满了十二个篮子。</span>
<span className="v" id="v14" data-v="14" data-xref="Deuteronomy 18:15–18; 马太福音 21:11; 使徒行传 7:37"> 众人看见耶稣显现的神迹，就说：“这的确就是将要来到世上的先知。”</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 18:36; 约翰福音 6:15–21; 约翰福音 7:3–4"> 耶稣意识到群众想要推举他为王，于是便离开众人，独自退回山中。</span>
<span className="v" id="v16" data-v="16"> 夜晚降临，他的门徒们下山到了海边，</span>
<span className="v" id="v17" data-v="17" data-xref="马可福音 6:45; 约翰福音 6:24–25; 约翰福音 2:12"> 然后上了船准备渡海去往迦百农。天色已黑，但耶稣并未来到他们身边。</span>
<span className="v" id="v18" data-v="18" data-xref="Psalms 107:25; Psalms 135:7; 马太福音 14:24"> 忽然海上刮起狂风，巨浪翻滚。</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 6:47–49; 马太福音 14:25–26; Job 9:8"> 门徒们摇桨前行了大概六公里，看到耶稣在海面上行走，朝着船的方向走来。这情景让他们十分害怕。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 14:27–31; Isaiah 43:1–2; Isaiah 44:8"> 耶稣对他们说：“别怕！是我。”</span>
<span className="v" id="v21" data-v="21" data-xref="马可福音 6:51; 马太福音 14:32–33; 启示录 3:20"> 他们立刻高兴起来，把他接上船，众人立刻抵达目的地的海滩。</span>
<span className="v" id="v22" data-v="22" data-xref="马可福音 6:45; 马太福音 14:22; 约翰福音 6:2"> 第二天，站在海另一边的人群看到只有一只小船停在那里，意识到耶稣并没有和门徒一同上船，门徒离开的时候，耶稣并未同行。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 6:1; 约翰福音 6:11–12"> 但就在主之前为众人分饼的地方，附近停着几只从提比里亚来的船。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 6:17; 路加福音 8:40; 马可福音 6:53"> 民众现在知道耶稣和门徒都不在那里，于是就上船去迦百农找耶稣。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 1:38–39; 马太福音 23:7"> 他们在对岸找到了耶稣，就问他：“拉比，你什么时候到这里来的？”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这是一个暗示问题，他们很想知道他如何抵达这里......">b</a></sup></span>
<span className="v" id="v26" data-v="26" data-xref="雅各书 4:3–4; 腓立比书 3:19; 腓立比书 2:21"> 耶稣回答：“告诉你实话，你们找我，不是因为看见了神迹，而是因为你们吃到了足够的饼。</span>
<span className="v" id="v27" data-v="27" data-xref="歌罗西书 3:2; Isaiah 55:2; 约翰福音 6:54"> 食物必会腐烂，不要为此忧心忡忡，要关心人子赐给你们的永恒食物，它会带来永续生命，因为他已获得天父的批准。”</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 16:30; 使徒行传 9:6; 马太福音 19:16"> 众人问他：“那我们该做什么才算是遵从上帝旨意呢？”</span>
<span className="v" id="v29" data-v="29" data-xref="约翰一书 3:23; 使徒行传 16:31; 约翰福音 3:36"> 耶稣回答：“上帝想让你们做的，就是相信他派来之人。”</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 12:37; 约翰福音 10:38; 哥林多前书 1:22"> 众人又问：“为了让我们信你，你要为我们显现什么神迹呢？你能做什么？</span>
<span className="v" id="v31" data-v="31" data-xref="Nehemiah 9:15; Psalms 105:40; Psalms 78:24–25"> 我们的祖先在荒野中吃过吗哪，正如经上所记：‘他把来自天堂的食物赐给他们。’”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《诗篇》78:24，参见《申命记》16:4。">c</a></sup></span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 15:1; 约翰福音 6:58; Exodus 16:4"> 耶稣回答道：“告诉你们实话，带给你们天堂食物之人并非摩西，而是我父，是他把真正的天堂食物赐给你们。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 8:42; 约翰福音 17:8; 约翰福音 3:13"> 因为上帝的食物就是来自那天堂、为世人赋予生命之人。”</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 4:15; 约翰福音 6:26; Psalms 4:6"> 众人说：“主啊，求你始终赐给我们这样的食物。”</span>
<span className="v" id="v35" data-v="35" data-xref="约翰福音 6:48–58; 启示录 22:17; 约翰福音 6:41"> 耶稣说：“我就是生命的食物，到我这里来就不会再感到饥饿。信我之人，永远不会口渴。</span>
<span className="v" id="v36" data-v="36" data-xref="彼得前书 1:8–9; 路加福音 16:31; 约翰福音 12:37"> 但就像我之前所说，你们虽然见了我，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="即耶稣所做的一切，不仅仅是看到他的人。事实上，有的古老手稿中并没有“我”这个词。">d</a></sup>但还仍然不信我。</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 11:28; 约翰福音 6:39; 约翰福音 17:24"> 天父赐给我之人必会走向我，我决不拒绝任何一人。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 5:30; 约翰福音 4:34; 约翰福音 3:31"> 因为我从天国而降，并非来达成自己之愿，而是遵循派我前来之人的旨意。</span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 17:12; 约翰福音 6:40; 约翰福音 18:9"> 他赐予我的人，我一个也不丢失，在末日要将他们复活。这就是他的旨意。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="“末日”即审判日。又见第 40、44 和 54 句。">e</a></sup></span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 6:54; 约翰福音 5:24; 罗马书 6:23"> 我父的旨意，就是让所有看到并相信人子之人实现永生，然后让我在末日之时鼓舞他们。”</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 6:51–52; 约翰福音 6:48; 约翰福音 6:33"> 因为耶稣说“我就是来自天堂的食物”，犹太人对此深感不满，于是议论纷纷。</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 4:22; 马可福音 6:3; 马太福音 13:55–56"> 他们说：“这不是约瑟的儿子耶稣吗？我们认识他父母。现在他怎么能说‘我来自天堂’呢？”</span>
<span className="v" id="v43" data-v="43" data-xref="希伯来书 4:13; 约翰福音 6:64; 马可福音 9:33"> 耶稣说：“不必再议论了。</span>
<span className="v" id="v44" data-v="44" data-xref="约翰福音 6:65; 约翰福音 6:39–40; 马太福音 11:25–27"> 如果不是派我前来的天父吸引了众人，根本不会有人能到我这里，我会在末日之时鼓舞他们。</span>
<span className="v" id="v45" data-v="45" data-xref="Isaiah 54:13; Jeremiah 31:33–34; 希伯来书 10:16"> 先知书上记着：‘众人都必受上帝的教导。’<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="引自《以赛亚书》54:13。">f</a></sup>聆听天父、遵其教诲的人，必会到我这里来。</span>
<span className="v" id="v46" data-v="46" data-xref="约翰福音 1:18; 约翰福音 7:29; 马太福音 11:27"> 从未有任何人见过天父，只有来自上帝的那个人才见过。</span>
<span className="v" id="v47" data-v="47" data-xref="约翰福音 3:36; 歌罗西书 3:3–4; 罗马书 5:9–10"> 告诉你们实话，信上帝，得永生。</span>
<span className="v" id="v48" data-v="48" data-xref="约翰福音 6:51; 哥林多前书 11:24–25; 哥林多前书 10:16–17"> 我就是生命的食物，</span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前书 10:3–5; 犹大书 1:5; Zechariah 1:5"> 你们的祖先在旷野吃过吗哪，但仍然会死去。</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 6:33; 约翰福音 6:51; 罗马书 8:10"> 但这是从天上而降的食物，吃下它就不会死。</span>
<span className="v" id="v51" data-v="51" data-xref="路加福音 22:19; 约翰福音 6:33; 希伯来书 10:5–12"> 我就是来自天堂、赋予生命的食物，吃下这食物就能获得永生。这食物即我的身体，为了让世人获得生命而赐。”</span>
<span className="v" id="v52" data-v="52" data-xref="约翰福音 9:16; 约翰福音 10:19; 约翰福音 6:41"> 随后犹太人开始进行激烈的争论。他们不解的是：“这个人怎会把他的肉身给我们吃？”</span>
<span className="v" id="v53" data-v="53" data-xref="约翰一书 5:12; 马太福音 26:26–28; 约翰福音 6:55"> 耶稣告诉他们：“说实话，除非吃人子的肉、喝人子的血，否则就无法获得真正的生命。</span>
<span className="v" id="v54" data-v="54" data-xref="约翰福音 6:39–40; 约翰福音 6:27; 腓立比书 3:7–10"> 食我肉、饮我血才能永生，我会在末日让他们复活。</span>
<span className="v" id="v55" data-v="55" data-xref="约翰福音 15:1; 约翰福音 8:31; 约翰福音 6:32"> 因为我的肉是真正的食物，我的血是真正的饮品。</span>
<span className="v" id="v56" data-v="56" data-xref="约翰一书 3:24; 约翰福音 15:4–5; 约翰福音 14:20"> 只有食我肉、饮我血之人，我才能与他们彼此同在。</span>
<span className="v" id="v57" data-v="57" data-xref="加拉太书 2:20; 约翰福音 5:26; 约翰福音 17:21"> 正如赐予生命的天父派我前来，我也因天父而活，食我肉身者即可因我而活。</span>
<span className="v" id="v58" data-v="58" data-xref="约翰福音 3:36; 约翰福音 6:47–51; 约翰福音 6:41"> 这就是来自天堂的食物，你们祖先吃下吗哪后仍然死了，但吃下天堂的食物必会永生。”</span>
<span className="v" id="v59" data-v="59" data-xref="约翰福音 6:24; Proverbs 8:1–3; 路加福音 4:31"> 这番话，就是耶稣在迦百农会堂中对众人的教导。</span>
<span className="v" id="v60" data-v="60" data-xref="约翰福音 6:66; 约翰福音 8:43; 约翰福音 8:31"> 他的很多门徒听完这番话后说：“这番话难以接受！谁会真正遵循<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="“遵循”不仅是“理解”，还指“遵守”或“认可。”">g</a></sup>它？”</span>
<span className="v" id="v61" data-v="61" data-xref="约翰福音 2:24–25; 约翰福音 6:64; 约翰福音 21:17"> 耶稣看到门徒对这番话的不解，于是便问：“这话让你们感觉受到冒犯吗？</span>
<span className="v" id="v62" data-v="62" data-xref="马可福音 16:19; 约翰福音 3:13; 约翰福音 17:4–5"> 如果你们能目睹人子升入他原本所在的地方，又怎样呢？</span>
<span className="v" id="v63" data-v="63" data-xref="加拉太书 5:25; 希伯来书 4:12; Psalms 119:93"> 是灵魂赋予人生命，绝非肉体。<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="或“毫无价值。”">h</a></sup>我对你们所说的就是灵，是生命！</span>
<span className="v" id="v64" data-v="64" data-xref="约翰福音 10:26; 提摩太后书 2:19; 希伯来书 4:13"> 但你们中却有人不信。”（耶稣从最开始就知道谁不信他，谁会背叛他）。</span>
<span className="v" id="v65" data-v="65" data-xref="约翰福音 6:44–45; 约翰福音 6:37; 约翰福音 3:27"> 耶稣补充道：“所以我要说的是，是他让这成为可能<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="或“授予。”">i</a></sup>，否则没有人能到我这里来。”</span>
<span className="v" id="v66" data-v="66" data-xref="路加福音 9:62; 约翰一书 2:19; 希伯来书 10:38"> 此后，他的门徒中有许多人都放弃了，不再追随于他。</span>
<span className="v" id="v67" data-v="67" data-xref="Ruth 1:11–18; 约翰福音 6:70; 路加福音 14:25–33"> 于是耶稣对十二门徒说：“你们呢？你们也想离去吗？”</span>
<span className="v" id="v68" data-v="68" data-xref="Psalms 73:25; 约翰福音 5:24; 约翰一书 5:11–13"> 西门（彼得）回答：“主啊，我们还能追随谁呢？你才是讲述永生之道的那个人。</span>
<span className="v" id="v69" data-v="69" data-xref="约翰福音 11:27; 路加福音 9:20; 马可福音 8:29"> 我们相信你，我们确信你就是上帝的圣者。”</span>
<span className="v" id="v70" data-v="70" data-xref="约翰福音 13:27; 约翰福音 13:2; 约翰福音 17:12"> 耶稣说：“我不是选出你们十二个人吗？但你们中间有一个是魔鬼。”</span>
<span className="v" id="v71" data-v="71" data-xref="马太福音 26:14–16; 犹大书 1:4; 使徒行传 1:16–20"> （耶稣所指为加略人西门的儿子犹大。虽然他是十二门徒之一，但后来背叛了耶稣。）</span>

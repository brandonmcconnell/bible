<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 13:31–32; 约翰福音 17:4–5; 腓立比书 2:9–11"> 耶稣讲完了这些话，就举目望天，说：“父啊，时候到了，求你让你的儿子获得荣耀，你的儿子就会让你获得荣耀，</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 10:28–29; 约翰福音 6:39; Daniel 7:14"> 正如你把管理全人类的权力给了他，让他可以将永生赐给你所给予他的人。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰一书 5:20; 约翰一书 5:11–12; Jeremiah 9:23–24"> 知道你是独一的真上帝，并且认识你所派来的耶稣基督，这就是永生。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 4:34; 使徒行传 20:24; 提摩太后书 4:7"> 现在我已在这世间给了你荣耀，完成了你交给我的任务。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 1:1–3; 歌罗西书 1:15–17; 约翰福音 10:30"> 父啊，现在让我在你面前获得荣耀，就是在创世纪前我与你同享的荣耀。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 17:26; 约翰福音 14:21–24; 约翰一书 5:20"> 你从世上分别出来赐给我的人，我已经把你的身份<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或“名字。”">a</a></sup>显示给他们了。他们是你的，你把他们赐给了我，他们也遵守了你的道。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 7:16–17; 约翰福音 16:15; 约翰福音 14:7–10"> 现在他们知道，你给我的，无论是什么，都是从你那里来，</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 17:14; 约翰福音 15:15; 约翰福音 16:30"> 你赐给我的话，我已经给了他们，他们也领受了，确定知道我是从你那里来的，并且信你差了我来。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 9:24; 约翰福音 17:2; 约翰福音 17:6"> 我为他们祈祷，我不为世人祈祷，而是为你赐给我的人祈祷，因为他们是你的。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 10:30; 彼得前书 2:9; 启示录 5:8–14"> 属于我的一切都属于你，你的一切也是我的，并且我因为他们获得了荣耀。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 6:9; Proverbs 18:10; 约翰福音 17:12–18"> 我要离开这世界了，他们却仍留在这里，我要到你那里去了。圣父啊，求你凭着赐给我的名，保护他们，让他们成为一体，就像我们一样。</span>
<span className="v" id="v12" data-v="12" data-xref="Psalms 109:6–19; 约翰福音 10:27–28; 约翰福音 18:9"> 我跟他们在一起的时候，因你赐给我的名，我看护他们，除了那‘迷失之子’以外，其他人都没有迷失，这就应验了经文上的话。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 12:2; 加拉太书 5:22; 约翰福音 15:11"> 现在我到你那里去，我在世上说这些话，就是要他们充分分享我的欢喜。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 17:16; 约翰福音 15:18–21; 约翰一书 5:19–20"> 我把你的道赐给他们，世人恨他们，因为他们不属于这世界，像我不属于这世界一样。</span>
<span className="v" id="v15" data-v="15" data-xref="Psalms 121:7; 约翰一书 5:18; 马太福音 6:13"> 我不求你让他们离开这个世界，只求你保护他们远离恶人。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 17:14"> 他们不属于这世界，像我不属于这世界一样。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 15:3; Psalms 119:160; 以弗所书 5:26"> 求你用真理让他们变得神圣，你的道就是真理。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 5:20; 约翰福音 20:21; 约翰福音 17:3"> 就像你派我到这世上来，我也将同样派他们到世界各地。</span>
<span className="v" id="v19" data-v="19" data-xref="提多书 2:14; 希伯来书 2:11; 约翰福音 17:17"> 我为他们奉献<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“献身”：与第 17 句中的“使其变得神圣”意思相同。">b</a></sup>自己，让他们能够真正成为神圣之人。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 17:6–11; 使徒行传 2:41; 使徒行传 4:4"> 我不但为他们祈求，也为那些因他们传递的福音而信我的人求，</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 12:12; 歌罗西书 3:11–14; 约翰福音 17:11"> 祈求他们都能合而为一，就像天父你与我同在，我与你同在。求他们也与我们同在，让世人相信是你派我前来。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多后书 3:18; 约翰福音 14:20; 马可福音 16:17–20"> 你赐给我的荣耀，我已经赐给了他们，使他们合而为一，像我们合而为一。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 17:21; 约翰福音 16:27; 约翰一书 3:1"> 我与他们同在，你与我同在，使他们完完全全合而为一，让世人知道你派我前来，知道你爱他们，好像爱我一样。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 17:5; 约翰福音 12:26; 约翰福音 14:3"> 父啊，我在哪里，希望你赐给我的那些人，也能到我所在的地方，让他们看见你赐给我的荣耀，因为在创立世界以前，你就已经爱我了。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 17:11; 约翰福音 7:29; 约翰福音 17:8"> 善良的天父啊，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“我父正确。”">c</a></sup>世人虽然不认识你，我却认识你，与我一起的这些人也知道你派我前来。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 17:23; 约翰福音 17:6; 约翰福音 15:9"> 我已经把你的性格显示给他们，还要再显示，让他们也能拥有你对我的爱，我将与他们同在。”</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Deuteronomy 16:16; Exodus 23:14–17; Exodus 34:23"> 此后迎来了一个犹太人节日，耶稣开始向耶路撒冷出发。</span>
<span className="v" id="v2" data-v="2" data-xref="Nehemiah 12:39; Nehemiah 3:1; Nehemiah 3:32"> 在耶路撒冷羊门附近一个的水池，希伯来语名字叫做毕士大，池边有五条游廊。</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 3:1–4; 路加福音 7:22; 马太福音 15:30"> 那里躺着许多病患，有的人看不到，有的人瘸腿，有的人瘫痪，</span>
<span className="v" id="v4" data-v="4"> <sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="在最早的手稿中并没有这一段，似乎是后来加进去，解释第 7 句。加在这里是为了提供信息：他们在那里等待水开始流动，因为天使每隔一段时间就会降临到水池，搅动里面的水。在这搅动过的水中，第一个进入池中之人无论何种疾病，都可以治愈。当时似乎有些人相信这个说法。">a</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 3:2; 路加福音 8:43; 马可福音 9:21"> 其中一人已经病了三十八年。耶稣看到他便知道他病了很久，于是问他：</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 18:41; 希伯来书 4:15; 希伯来书 4:13"> “你想要治愈吗？”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="Psalms 72:12; Deuteronomy 32:36; 哥林多前书 9:24"> 那病人回答：“先生，水被搅动的时候，没有人能把我放在池里，我试着到那边去，但总是给别人抢先。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 5:24; 马太福音 9:6; 马可福音 2:11"> 耶稣对他说：“站起来，拿着你的垫子，走吧！”</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 3:7–8; 约翰福音 9:14; 马可福音 3:2–4"> 那人立刻痊愈，拿起垫子走动起来。<br />由于那天是安息日。</span>
<span className="v" id="v10" data-v="10" data-xref="Jeremiah 17:21; 路加福音 6:2; 约翰福音 9:16"> 犹太人就对那被治愈之人说：“今天是安息日！你拿着垫子违反了律法！”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马可福音 2:9–11; 约翰福音 9:16"> 那人回答：“将我治愈的那个人对我说：‘拿着你的垫子，你可以行走了’。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 21:23; Judges 6:29; 罗马书 10:2"> 犹太人就问：“让你拿着垫子行走的人是谁？”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 4:30; 路加福音 24:31; 约翰福音 8:59"> 那人不知道治愈他的人是谁，因为耶稣已经悄然躲进了周围的人群中。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 8:11; Leviticus 26:23–24; Psalms 118:18"> 后来，耶稣在圣殿里看到这个男人，就对他说：“看，你已经痊愈了，所以不能再犯罪，否则会招来更大的灾祸。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 9:11–12; 约翰福音 4:29; 约翰福音 9:25"> 那人就跑去告诉犹太人，将他痊愈之人就是耶稣。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 10:39; 约翰福音 7:19–20; 马可福音 3:6"> 因为耶稣会在安息日做这样的事情，犹太人便开始对耶稣群起而攻之。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 9:4; 约翰福音 14:10; 歌罗西书 1:16"> 耶稣却对他们说：“我父现在仍然在工作，我也是。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或“我父始终在工作，我也在工作。”">b</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 10:30; 约翰福音 10:33; 约翰福音 19:7"> 这话让犹太人更想杀了耶稣，因为他不但破坏安息日，还称上帝为自己的父亲，与上帝平起平坐。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约翰福音 12:49; 约翰福音 8:28; 约翰福音 14:10"> 耶稣对他们解释到：“告诉你们实话，儿子凭自己什么都做不了，他只是做了曾目睹天父所做的事情，父行，子随。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 3:35; 马太福音 3:17; 约翰福音 17:26"> 因为天父爱其儿子，于是把自己所做的一切展示给他看，还要向他展示更惊人的大事，足以让你们惊讶无比。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 8:11; Deuteronomy 32:39; 约翰福音 11:25"> 因为天父让人死而复生，赋予其生命，儿子也以同样的方式，随其心意赋予死人以生命。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 5:27; 使徒行传 17:31; 哥林多后书 5:10"> 天父不评判任何人，他将这评判的权力完全交给儿子，</span>
<span className="v" id="v23" data-v="23" data-xref="约翰一书 2:23; 路加福音 10:16; 马太福音 11:27"> 所以，所有的人尊敬儿子一如尊敬天父。不尊敬儿子，就是不尊敬那派他前来的天父。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 3:36; 约翰福音 6:40; 约翰一书 5:11–13"> 告诉你实话，遵循<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“听。”">c</a></sup>我所言、相信派我来此的上帝，就会获得永生，不会被定罪，而是会死而复生。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 5:28; 以弗所书 5:14; 以弗所书 2:5"> 告诉你实话，那时刻将至——事实上它已经到来。死人将听见上帝之子的声音，听到即会复活。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 11:26; 约翰福音 1:4; Exodus 3:14"> 就如天父拥有赐予生命的力量，他也将这赐予生命的力量交给儿子。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 10:42; 约翰福音 5:22; 使徒行传 17:31"> 因为他是儿子，所以天父还把审判的权力赐给儿子。</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 20:12; 帖撒罗尼迦前书 4:14–17; Isaiah 26:19"> 不要对此感到惊讶，因为那个时刻将至，届时所有坟墓里的死人都会听见他的声音，</span>
<span className="v" id="v29" data-v="29" data-xref="Daniel 12:2–3; 罗马书 2:6–10; 使徒行传 24:15"> 然后再次复活。行善之人复活后会获得生命，作恶之人复活后会被定罪。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="见《但以理书》12:2。">d</a></sup></span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 6:38; 约翰福音 5:19; 约翰福音 4:34"> 我凭自己什么都做不了。我只是根据天父之言进行审判<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="隐喻为“我父上帝所说。”">e</a></sup>。我会进行公正的决定，因为我遵循的并非自己的意愿，而是派我前来之人的旨意。</span>
<span className="v" id="v31" data-v="31" data-xref="Proverbs 27:2; 约翰福音 8:54; 启示录 3:14"> 如果我自证，这样证明并不可信。</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 1:33; 约翰福音 12:28–30; 约翰福音 5:36–37"> 但会有其他人为我作证，我知道他关于我的证言都是真实的。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 1:29–34; 约翰福音 3:26–36; 约翰福音 1:15–27"> 你们向约翰询问我的事情，他讲述了真相。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 19:41–42; 约翰福音 20:31; 约翰一书 5:9"> 我不需要人类的证明，但向你们解释这一切，只是为了我说这些事，是要你们得救。</span>
<span className="v" id="v35" data-v="35" data-xref="彼得后书 1:19; 约翰福音 1:7–8; 马太福音 11:11"> 约翰就像一盏照耀的明灯，你们愿意在他的光中获得短暂的欢愉。</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 10:25; 约翰福音 10:37–38; 约翰福音 15:24"> 但我所给予的证据远比约翰更强大，因为我所行之事乃奉天父之命，</span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 8:18; 约翰福音 1:18; 马太福音 3:17"> 这就是天父派我前来的证明。天父遣我来此，通过我传递讯息。你们从未听过他的声音，从未见过他的容貌，</span>
<span className="v" id="v38" data-v="38" data-xref="约翰一书 2:14; Deuteronomy 6:6–9; 约翰福音 12:44–48"> 也不接受他的讯息，因为你们不相信他派到这里之人。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 24:27; 路加福音 24:44; 彼得后书 1:19–21"> 你们研究经文，认为可以通过经文获得永生，但这经文其实就证明了我！</span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 3:19; 约翰福音 1:11; Psalms 81:11"> 到我这里来，你们就会获得生命。可是你们并不想这么做。</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 7:18; 约翰福音 5:34; 帖撒罗尼迦前书 2:6"> 我不寻求人的认可。</span>
<span className="v" id="v42" data-v="42" data-xref="约翰一书 4:20; 约翰一书 3:17; 约翰福音 2:25"> 我知道你们心里并没有上帝的爱。</span>
<span className="v" id="v43" data-v="43" data-xref="约翰福音 10:25; 马太福音 24:5; 约翰福音 17:4–6"> 我代表天父来此，<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="原意为“以......为名。”">f</a></sup>你们不接纳我，但如果有人以自己的名义前来，你们却接待他们！</span>
<span className="v" id="v44" data-v="44" data-xref="约翰福音 12:43; 罗马书 2:29; 腓立比书 2:3"> 你们希望获得彼此的赞美，却不想从唯一真正的上帝那里获得赞美，这样你们怎么能信我呢？</span>
<span className="v" id="v45" data-v="45" data-xref="罗马书 3:19–20; 加拉太书 3:10; 哥林多后书 3:7–11"> 但不要以为我会向天父控诉你们。的确有人控诉你们，那就是你们如此信任的摩西。</span>
<span className="v" id="v46" data-v="46" data-xref="Deuteronomy 18:15; Deuteronomy 18:18–19; 约翰福音 1:45"> 你们若信摩西，也应信我，因为他曾写到我。</span>
<span className="v" id="v47" data-v="47" data-xref="路加福音 16:31; 路加福音 16:29"> 但你们不信他所写的，又怎能信我所说？”</span>
</div>
</div>

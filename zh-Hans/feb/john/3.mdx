<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 19:39; 约翰福音 7:47–50; 约翰福音 3:10"> 有一位名叫尼哥德慕的法利赛人，是犹太统治委员会中的一名成员。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 5:36; 使徒行传 10:38; 使徒行传 2:22"> 一天晚上，他找到耶稣说：“拉比，我们知道你是从上帝那里来的老师，如果不是因为与上帝同在，就没有人可以像你一样显现神迹。”</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 5:17; 约翰福音 3:5–6; 彼得前书 1:23–25"> 耶稣回答：“说实话，只有当你重生之时，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或“生于天国。”">a</a></sup>才能亲历上帝之国。”</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 2:14; 哥林多前书 1:18; 约翰福音 3:3"> 尼哥德慕问到：“但人老了怎能重生呢？难道是回到母亲腹中再诞生一次吗？”</span>
<span className="v" id="v5" data-v="5" data-xref="Ezekiel 36:25–27; 以弗所书 5:26; 使徒行传 2:38"> 耶稣回答：“说实话，只有用水和圣灵诞下的人，才能进入上帝之国。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 5:16–21; Ezekiel 36:26–27; 罗马书 8:4–9"> 身体而生即为身体，圣灵而生即为圣灵。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 3:3; 以弗所书 4:22–24; 罗马书 12:1–2"> 如果我对你说‘你们必须重生。’<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="第一个“你”是指尼哥德慕。第二个“你们”指的是更广泛的听众。">b</a></sup>不要感到惊讶。</span>
<span className="v" id="v8" data-v="8" data-xref="Ecclesiastes 11:4–5; 哥林多前书 2:11; 使徒行传 2:2"> 风随心所欲地吹拂，你听得到它的声音，却不知道它从何而来，又要到哪里去。对众人而言，圣灵而生的人也是如此。”</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 6:60; 路加福音 1:34; Isaiah 42:16"> 尼哥德慕说：“这怎么可能？”</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 22:29; Jeremiah 8:8–9; Ezekiel 11:19"> 耶稣说：“你是以色列有名的教师，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“你是以色列的老师。”">c</a></sup>却不明白这样的事情吗？</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 8:38; 约翰一书 5:6–12; 约翰福音 12:49"> 说实话，我们只谈论自己知道之事，见证所见之事，但你们却不接受我们的见证。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 3:1–2; 哥林多前书 2:7–9; 希伯来书 5:11"> 我告诉你们的只是人间之事，你们都不信，如果和你们讲述天国之事，你们又怎能信呢？</span>
<span className="v" id="v13" data-v="13" data-xref="Proverbs 30:4; 约翰福音 6:38; 使徒行传 2:34"> 除了从天而降的人子，没有人曾升入天国。</span>
<span className="v" id="v14" data-v="14" data-xref="Numbers 21:7–9; 约翰福音 8:28; 约翰福音 12:32–34"> 就像摩西在旷野中举起蛇，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="见《民数记》21:9。">d</a></sup>人子也必会被高举入天，</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 3:16; 约翰福音 6:40; 约翰福音 12:44–46"> 让所有相信他的人获得永生。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 5:8; 约翰一书 4:9–10; 约翰福音 3:15"> 这就是上帝爱这世界的方式，上帝他把自己的独子赐给他们，让信他的人不会死去，而是获得永生。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="这个词经常翻译成“如此”（就像“如此被爱”），它描述的是上帝爱人的方式，而不是描述爱的程度或强度。">e</a></sup></span>
<span className="v" id="v17" data-v="17" data-xref="约翰一书 4:14; 路加福音 19:10; 约翰福音 12:47–48"> 上帝派他的儿子来到人世间，不是为了谴责世人，而要让世人因他而获得救赎。</span>
<span className="v" id="v18" data-v="18" data-xref="马可福音 16:16; 约翰一书 5:10; 罗马书 8:1"> 相信他的不会被定罪，至于不相信他的人，因为他们不相信上帝的独子，这本身就已经被谴责<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="或“谴责他们自己。”">f</a></sup>了。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 8:12; 帖撒罗尼迦后书 2:12; 约翰福音 9:39–41"> 做出这样的决定<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="或“审判。”">g</a></sup>是因为光降临这个世界，但世人因作恶犯罪，不爱光反倒爱黑暗。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 5:11–13; 约翰福音 7:7; Job 24:13–17"> 作恶之人都恨光，不肯走到光下，生怕恶行暴露。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 1:6; Psalms 139:23–24; 约翰三书 1:11"> 行正道<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="原意为“行真理。”">h</a></sup>之人都愿意走进光中，显现上帝在它们身上达成的结果。”</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 4:1–3; 约翰福音 3:26; 约翰福音 2:13"> 在这之后，耶稣和门徒来到犹太地并在此住下，开始与民众在一起，为他们施洗。</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 1:4–5; Ezekiel 43:2; 马太福音 3:5–6"> 约翰施洗的地点位于撒冷附近的艾农，因为那里水很充足，众人纷纷前去接受他的施洗。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 4:12; 马太福音 14:3; 马可福音 6:17"> （当时约翰尚未入狱。）</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 2:6; 马太福音 3:11; 希伯来书 6:2"> 一天，约翰的门徒和一个犹太人在辩论洁净礼的问题。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 1:7; 约翰福音 1:15; 约翰福音 12:19"> 他们来到约翰面前，对他说：“拉比，你看，约旦河另一侧的那个人，就是你为其见证的那个人也在施洗，大家都到他那里去了！”</span>
<span className="v" id="v27" data-v="27" data-xref="雅各书 1:17; 哥林多前书 4:7; 哥林多前书 15:10"> 约翰回答：“人所获得的一切，均来自天赐。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 1:20; 约翰福音 1:23; 马太福音 3:11–12"> 我曾说过：‘我不是基督，不过是奉命为他准备道路而已’你们对此可以证明。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 9:15; Hosea 2:19; Isaiah 54:5"> 娶新娘的人是新郎！当新郎的好友站在那里，只要听到新郎的声音就会心生喜悦。我也有同样的欢喜，但现在这欢喜已经结束了。</span>
<span className="v" id="v30" data-v="30" data-xref="歌罗西书 1:18; Psalms 72:17–19; 希伯来书 3:2–6"> 他一定会变得更重要，我一定会变得更低微。”</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 8:23; 马太福音 28:18; 罗马书 9:5"> 从天而来一定比众人更伟大<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="或权威含义的“高于。”">i</a></sup>，来自大地的则属于大地，其所言也不过人间之事。只有从天而来才会比万物更伟大。</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 3:11; 约翰福音 15:15; 约翰福音 1:11"> 他对在天上的所见所闻做出见证，却没有人相信他所说的一切。</span>
<span className="v" id="v33" data-v="33" data-xref="希伯来书 6:17; 以弗所书 1:13; 提多书 1:1–2"> 接受他的见证，就代表你确认<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="原意为“批准的印记。”">j</a></sup>上帝的真实。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 10:38; 马太福音 12:18; 约翰福音 15:26"> 上帝派来之人讲述上帝之道，因为上帝不会对圣灵做出限制。</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 28:18; 约翰福音 5:22; 约翰福音 5:20"> 天父爱这人子，已经把一切都交在他的手中。</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 5:24; 约翰福音 1:12; 帖撒罗尼迦前书 5:9"> 相信人子方得永生，不信人子就无法亲历永生，而是会遭受上帝的谴责。</span>

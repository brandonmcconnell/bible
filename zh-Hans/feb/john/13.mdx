<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 12:23; 约翰一书 4:19; 约翰福音 13:34"> 逾越节前一天，耶稣知道自己时候已到，将会离开这世界，回到天父那里去。他爱这世上追随他的人，现在他将显示对他们所有的爱<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“完整的爱。”这里使用的单词既表示“完整”也表示“结束”，因此还有一种解读是：“他爱他们到最后”，这在上下文中也很合适。但耶稣表达爱的方式（包括十字架），其实显示的是上帝对我们全部的爱。">a</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各书 1:13–17; 使徒行传 5:3; 约翰福音 13:26–27"> 吃晚饭的时候，魔鬼已经把出卖耶稣的念头植入西门的儿子——加略人犹大的心里。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 3:35; 马太福音 11:27; 希伯来书 1:2"> 耶稣知道天父的权力掌控了一切，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“放在手中。”">b</a></sup>他知道自己来自上帝，也将回到上帝。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 22:27; 哥林多后书 8:9; 路加福音 12:37"> 于是他站起身，脱去外衣，在腰上扎了一条毛巾。</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 7:44; Psalms 51:2; Genesis 18:4"> 然后倒了一盆水，开始给门徒们洗脚，用腰上的毛巾擦干。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 3:11–14; 约翰福音 1:27; 路加福音 5:8"> 轮到彼得时，他问到：“主啊，你要给我洗脚吗？”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="Daniel 12:8; 约翰福音 12:16; 约翰福音 14:26"> 耶稣回答：“你现在并不知道我在为你做什么，但总有一天会明白。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="Ezekiel 36:25; 使徒行传 22:16; 提多书 3:5"> 彼得说：“不！不要洗我的脚！”耶稣回答：“如果我不为你洗脚，你和我就没有任何关系了。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="Psalms 51:7; Psalms 51:2; 彼得前书 3:21"> 彼得说：“主啊，那就不要只是洗我的脚，连我的手和头也都洗吧！”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约翰福音 15:3; 哥林多后书 7:1; 哥林多后书 5:17"> 耶稣回答：“洗过澡的人只要洗脚就能获得全身的洁净。你们是洁净的，但并非人人如此。”</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 13:26; 约翰福音 13:2; 约翰福音 13:21"> 因为耶稣知道谁出卖了他，所以他说“但并非人人如此。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约翰福音 13:7; 约翰福音 13:4; Ezekiel 24:24"> 耶稣洗完了门徒们的脚，穿上外衣回到座位上坐下，对他们说：“你们理解我为你们所做的一切吗？</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 6:46; 哥林多前书 12:3; 约翰福音 11:28"> 你们称呼我‘老师’和‘主’，这样称呼没错，我本来就是。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 5:5; 使徒行传 20:35; 罗马书 12:16"> 如果作为主和你们的老师，仍然为你们洗脚，你们也应当为彼此洗脚。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰一书 2:6; 马太福音 11:29; 彼得前书 3:17–18"> 我为你们做出榜样，希望你们也能做我所做的事情。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 6:40; 约翰福音 15:20; 马太福音 10:24–25"> 实话实说，仆人不能高于主人，奉命行事之人不能高过派遣他之人。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 11:28; 雅各书 4:17; 雅各书 1:25"> 既然你们已经理解了这些事，付诸行动就会有福报。</span>
<span className="v" id="v18" data-v="18" data-xref="Psalms 41:9; 马太福音 26:23; 约翰福音 17:12"> 但我并不是说你们所有人，我知道自己选择的那些人，但是经文中说：‘与我一起用餐的人会背叛我’，这句话将会应验。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《诗篇》41:9。">c</a></sup></span>
<span className="v" id="v19" data-v="19" data-xref="Isaiah 43:10; 约翰福音 14:29; 约翰福音 16:4"> 我在事情还没有发生之前告诉你们，因为当它发生的时候，你们就会相信我是谁。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:16; 路加福音 9:48; 马太福音 25:40"> 告诉你们实话，迎接我所派遣的人，就是迎接我，迎接我，就是迎接派我来此之人。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约翰福音 13:18; 马太福音 26:21; 马可福音 14:18"> 耶稣说完这番话，深感难过，于是大声说：“告诉你们实话，你们中间有一个人要出卖我。”</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 22:23; 马太福音 26:22; 马可福音 14:19"> 门徒们看着彼此，不知道他所指是谁。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 19:26; 约翰福音 21:7; 约翰福音 21:20"> 耶稣所爱的那名门徒<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="通常理解为：约翰在说自己（又见20:2，21:7，21:20。）">d</a></sup>坐在他身边，侧身靠近耶稣。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 12:17; 路加福音 1:22; 使徒行传 13:16"> 彼得向他示意，让他询问耶稣这个叛徒到底是谁。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 21:20; Genesis 44:4–12; Esther 7:5"> 于是那个门徒倾斜身体贴近耶稣，问到：“主啊，是谁呢？”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 26:23; 约翰福音 13:30; 马可福音 14:19–20"> 耶稣回答：“我蘸一小块饼，把它给谁就是那个人了。”</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 22:3; 约翰福音 13:2; Ecclesiastes 9:3"> 于是他蘸了一小块饼，递给加略人西门的儿子犹大。犹大接过饼以后，撒旦就进入他的身体。耶稣对他说：“你想做什么，快去做吧。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 在座众人都不知道耶稣为什么这样对犹大说话。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 12:5–6; 约翰福音 13:1; 以弗所书 4:28"> 由于犹大负责管钱，所以有人以为耶稣是叫他去购买逾越节所需用品，或是拿点东西去接济穷人。</span>
<span className="v" id="v30" data-v="30" data-xref="Isaiah 59:7; Job 24:13–15; Proverbs 4:16"> 犹大吃了饼后立刻就离开，走进了一片黑夜。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 14:13; 彼得前书 4:11; 约翰福音 7:39"> 他离开后，耶稣就说：“现在人子已获得荣耀，上帝也通过人子获得荣耀，</span>
<span className="v" id="v32" data-v="32" data-xref="启示录 22:1; Isaiah 53:10–12; 约翰福音 17:4–6"> 上帝如果通过人子获得荣耀，也将会让人子获得荣耀，并且会立刻这么做。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 7:33–34; 约翰福音 8:21–24; 约翰福音 16:16–22"> 我的孩子们，我与你们在一起的时候不多了。你们会寻找我，但我要把对犹太人所说的告诉你们：‘我去的地方，你们不能去。’</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="以弗所书 5:2; Leviticus 19:18; 约翰福音 15:17"> 我现在要给你们一个新命令：要爱彼此，要像我爱你们的方式爱彼此。</span>
<span className="v" id="v35" data-v="35" data-xref="约翰一书 4:20–21; 约翰一书 3:10–14; 约翰一书 2:10"> 如果你们爱彼此，你就是向所有人证明，你们是我的门徒。”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="彼得后书 1:14; 约翰福音 13:33; 约翰福音 21:21–22"> 彼得对耶稣说：“主啊，你要去哪里？”耶稣回答：“我去的地方，你现在无法跟随，但今后会跟上我。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒行传 21:13; 使徒行传 20:24; 马可福音 14:27–31"> 彼得说：“主啊，为什么我现在不能跟随你？为了你，要我放弃生命也可以！”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="路加福音 22:34; 马太福音 26:34; 马可福音 14:30"> 耶稣说：“你愿意为我放弃生命吗？告诉你实话，鸡叫之前，你一定会有三次不认我。”</span>
</div>
</div>

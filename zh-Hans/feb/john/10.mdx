<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 7:15; 约翰福音 10:8–10; 罗马书 16:18"> “告诉你们实话，如果一个人进羊圈<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“羊栏”或“庭院。”这里指的是房屋旁边与之相连的围场，周围环绕着一堵墙。这样的羊圈常见于人口较多的村庄，而不是空旷的乡村。">a</a></sup>没走门，而是用其他方式爬进去，那此人非贼即盗。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 10:14; 使徒行传 20:28; 彼得前书 5:4"> 从门进去的才是羊群的牧羊人。</span>
<span className="v" id="v3" data-v="3" data-xref="Ezekiel 34:11–16; 提摩太后书 2:19; 约翰福音 10:4"> 看门人给他开门，羊能听到他的声音，他呼唤着每一只羊的名字，把它们带出来。</span>
<span className="v" id="v4" data-v="4" data-xref="Deuteronomy 1:30; 约翰福音 10:16; 约翰福音 12:26"> 他把自己的羊领出来以后，走在前面，羊跟着他，因为认得他的声音。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰一书 4:5–6; 歌罗西书 2:6–10; 马可福音 4:24"> 羊群决不跟随陌生人，因为不认得陌生人的声音，它们会从他们那里跑开。”</span>
<span className="v" id="v6" data-v="6" data-xref="Isaiah 56:11; Psalms 82:5; Proverbs 28:5"> 对于耶稣所讲的这个比喻，大家并不理解它的含义。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 14:6; 以弗所书 2:18; 约翰福音 10:1"> 于是耶稣解释道：“说实话，我就是羊的门。</span>
<span className="v" id="v8" data-v="8" data-xref="Ezekiel 34:2; Jeremiah 23:1; 约翰福音 10:1"> 在我之前进入的人非贼即盗，羊也不听从他们的。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 14:6; 以弗所书 2:18; 约翰福音 10:7"> 我就是门，如果有人穿我而入，就必定得救<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或“被拯救。”">b</a></sup>，还可以来去自由，可以找到自己需要的食物。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 19:10; 约翰福音 6:51; 约翰福音 12:47"> 贼来了，但他的目的是偷窃、杀害和毁坏。我来了，是为了让你们获得生命，更完整丰饶的生命。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 10:14–15; Psalms 23:1; 约翰福音 15:13"> 我就是那善良的牧羊人，愿意为羊放弃自己的生命。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 20:29; Zechariah 11:16–17; Ezekiel 34:2–6"> 拿着工钱照看羊群的，不是牧羊人，羊不是他自己的，一见狼来，他就会丢下羊逃跑，狼就能攻击羊群，把羊群驱散了。</span>
<span className="v" id="v13" data-v="13" data-xref="腓立比书 2:20; 约翰福音 12:6; 使徒行传 18:17"> 因为这人只是花钱雇来的工人，根本不在乎羊群。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 10:27; 约翰福音 10:11; 提摩太后书 2:19"> 我就是那善良的牧羊人。我知道谁属于我，他们也认识我，</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 1:4; 约翰福音 10:11; Isaiah 53:10"> 就像天父认识我，我也认识天父一样。我愿意为羊放弃自己的生命。</span>
<span className="v" id="v16" data-v="16" data-xref="Isaiah 56:8; 约翰福音 11:52; 彼得前书 2:25"> 我还有其他的羊，但不在这个羊圈里，我必须把它们领来，它们将听到我的声音，聚成一群，只有一个牧羊人。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 10:18; 约翰福音 10:11; 希伯来书 2:9"> 天父爱我，因为我愿意舍弃生命，只为重获生命。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 2:9; 提多书 2:14; 约翰福音 2:19–21"> 没有人能夺走我的生命，我自己选择舍弃。我有权舍弃生命，也有权把它夺回，这是天父给我的命令。”</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 9:16; 哥林多前书 3:3; 约翰福音 7:40–43"> 听完这番话，犹太人再次分成了两派意见。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 7:20; 马可福音 3:21; 约翰福音 8:47–48"> 很多人会说：“他是魔鬼附体，发疯了，为什么要听他的呢？”</span>
<span className="v" id="v21" data-v="21" data-xref="Exodus 4:11; Isaiah 35:5–6; Psalms 94:9"> 还有人说：“魔鬼附体之人不可能说出这样的话。魔鬼怎能让盲人重见光明？”</span>
<span className="v" id="v22" data-v="22"> 在冬季的耶路撒冷，献殿节到了。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 5:12; 使徒行传 3:11"> 耶稣走在圣殿的所罗门廊中。犹太人围着他，向他提问：</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 22:67–70; 约翰福音 1:19; 约翰福音 8:25"> “你还要让我们疑惑到什么时候？<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一种口头表达方式，原意为“提升我们的灵魂”，意味着感觉不确定。">c</a></sup>如果你是基督，就直接告诉我们吧！”</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 10:38; 约翰福音 8:58; 约翰福音 14:11"> 耶稣对他们说：“我已经告诉你们了，你们却不相信。我以天父之名所显现的奇迹，已经证明了我是谁。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 8:47; 哥林多后书 4:3–4; 约翰福音 12:37–40"> 只是你们不信，因为你们不是我的羊。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 10:16; 约翰福音 10:14; 启示录 3:20"> 我的羊能认出我的声音，我也认识他们，他们会追随我。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 6:39–40; 约翰福音 6:37; 约翰福音 3:15–16"> 我赐给他们永生，他们永不灭亡，没有人能把他们从我手里夺去。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原意为“从我手中给出。”与 29 句相似。">d</a></sup></span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 6:37; 约翰福音 17:2; 约翰福音 17:9"> 把他们赐给我的天父比任何人都伟大，也没有人能把他们从他手中夺去。</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 1:1–2; 约翰福音 14:9; 约翰福音 17:21–23"> 我与天父本为一体。”</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 5:18; 约翰福音 8:59; 1 Samuel 30:6"> 犹太人再次拿起石头要打他。</span>
<span className="v" id="v32" data-v="32" data-xref="约翰一书 3:12; 约翰福音 5:36; Psalms 35:12"> 耶稣对他们说：“我向你们展示从天父那里获得的善良行为，你们用石头砸我又是为何事？”</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 5:18; Leviticus 24:16; 约翰福音 10:30"> 犹太人回答：“我们打你不是因为善事，而是因为你说了忤逆上帝之语；你不过凡人一个，竟敢自称上帝。”</span>
<span className="v" id="v34" data-v="34" data-xref="Psalms 82:6–7; Exodus 7:1; Psalms 82:1"> 耶稣回答：“你们的律法上不是写着‘我说，你们是上帝’吗？<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="引自《诗篇》82:6。">e</a></sup></span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 24:35; 罗马书 13:1; 路加福音 16:17"> 他称那些人为‘上帝’，其实是上帝将道传授给他们，经文不能更改。</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 5:17–18; 约翰福音 3:17; Jeremiah 1:5"> 天父特别选择了一人派到人间，你们却因为他说‘我是上帝之子’，就认为他忤逆上帝，这又是为什么？</span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 15:24; 约翰福音 10:25; 约翰福音 12:37–40"> 我若不做天父之事，那就不必信我。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 14:20; 约翰福音 10:25; 约翰福音 10:30"> 如果我正在做天父之事，你们即使是不相信我，但也应该相信这些事，因为这就是我所行之事的证据。这会让你们知道和理解天父与我同在，我与天父同在。”</span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 7:30; 约翰福音 8:59; 约翰福音 7:44"> 他们又想要逮捕耶稣，但他却逃脱了。</span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 1:28; 约翰福音 11:54; 约翰福音 7:1"> 耶稣穿过约旦河往回走，来到约翰开始施洗的地方，在这里住下。</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 1:33–34; 约翰福音 1:29–30; 马可福音 1:37"> 许多人都来到他那里，说：“约翰没有显现任何神迹，但约翰关于这个人的描述都成真了。”</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 4:41; 约翰福音 2:23; 约翰福音 7:31"> 很多人在那里相信了耶稣。</span>

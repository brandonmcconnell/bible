<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 4:46; Proverbs 31:10–12; 约翰福音 21:2"> 两天<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“第三天”（包括当天）。">a</a></sup>后，耶稣的母亲参加了在加利利的迦拿举行的一场婚宴。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 1:40–49; 马太福音 10:40–42; 哥林多前书 7:39"> 耶稣和门徒们也受邀参加。</span>
<span className="v" id="v3" data-v="3" data-xref="Psalms 104:15; 腓立比书 4:6; Isaiah 24:11"> 席间的酒喝光了，耶稣的母亲对他说：“他们没有酒了。”</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 7:6; 约翰福音 13:1; 约翰福音 7:30"> 耶稣说：“母亲，你为什么叫上我呢？<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“对我和对你来说是什么？”（也就是说，“这与我或你有什么关系？”）">b</a></sup>我的时候还未到。”</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 15:14; Genesis 6:22; 希伯来书 11:8"> 他母亲告诉仆人：“他吩咐你什么，就做什么。”</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 3:25; 希伯来书 9:10; 以弗所书 5:26"> 附近有六口石罐，每口可盛 20 到 30 加仑的水，用于犹太人的洁净礼。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“两到三桶。”">c</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="2 Kings 4:2–6; 约翰福音 2:5; 约翰福音 2:3"> 耶稣吩咐仆人：“把罐子倒满水。”他们就在里面灌满水。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 2:9; Proverbs 3:5–6; 罗马书 13:7"> 耶稣又吩咐他们：“现在倒出来，送给宴席的主人。”他们就照做了。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 4:46; 约翰福音 7:17; Psalms 119:100"> 但宴席主人不知道酒从哪里来的，只有仆人知道。当宴席主人发现所饮的不再是水，而是水变成的酒，于是就把新郎叫过来。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 7:16–17; Proverbs 9:1–6; 路加福音 16:25"> 主人对他说：“人们都是先摆上好酒，等到客人喝够了，才摆上次等的酒，但你却把好酒留到最后。”</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 20:30–31; 约翰福音 1:14; 约翰福音 3:2"> 这是耶稣的第一件神迹，地点是加利利的迦拿行。他展露了自己的荣耀，这也让他的门徒开始相信他。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 12:46; 马太福音 13:55–56; 马可福音 6:3"> 在这以后，耶稣和母亲、弟弟和门徒们去往迦百农，在那里住了几天。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 2:41; 约翰福音 11:55; 约翰福音 2:23"> 犹太人的逾越节将至，耶稣又去了耶路撒冷。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 19:45–46; 马可福音 11:15; 马可福音 11:17"> 在圣殿中，他看到这里有卖牛、羊、鸽子的小贩，还有人坐在桌子前兑换银钱。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 18:6; Zechariah 4:6; 哥林多后书 10:4"> 于是他用绳索做了一条鞭子，将众人连羊带牛都赶出了殿外，倒掉兑换银钱之人的硬币，推翻他们的桌子。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 21:13; Jeremiah 7:11; 马可福音 11:17"> 他命令卖鸽子的小贩：“把这些东西拿出去！不要把我父的圣殿变成巿场！”</span>
<span className="v" id="v17" data-v="17" data-xref="Psalms 69:9; Psalms 119:139"> 他的门徒想起经文中所说：“我愿为你的圣殿奉献，这想法如火焰在我心中燃烧！”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《诗篇》69:9。">d</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 21:23; 马可福音 8:11; 马可福音 11:27–28"> 几名犹太首领表示反对，问他：“你有什么权力这么做？你需要显示神迹证明你自己！”</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 14:58; 马可福音 15:29; 马太福音 27:40"> 耶稣回答：“如果拆毁这圣殿，我三天之内就能把它建造起来！”</span>
<span className="v" id="v20" data-v="20"> 犹太首领说：“这殿花了四十六年才建成，你三天内就能把它建好吗？”</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 6:19; 哥林多前书 3:16; 以弗所书 2:20–22"> 但其实耶稣所说的圣殿就是他的身体。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 12:16; 约翰福音 16:4; 路加福音 24:7–8"> 所以当耶稣死而复生，门徒们想起了他说过这话，也就相信了经文和耶稣所言的一切。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 7:31; 路加福音 8:13; 约翰福音 6:14"> 耶稣在耶路撒冷过逾越节期间，许多人看见他显现神迹，就纷纷相信了他。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 6:64; 希伯来书 4:13; 使徒行传 1:24"> 但耶稣却不信任他们，因为他了解关于人类的一切。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 13:11; 马太福音 9:4; 约翰福音 6:64"> 他无需任何人告诉他什么是人性，他知道人类如何思考。</span>

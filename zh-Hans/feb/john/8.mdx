<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 21:1; 马可福音 11:1; 路加福音 19:37"> 但耶稣开始去往橄榄山。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 26:55; 路加福音 4:20; 路加福音 21:37"> 黎明时分，他返回圣殿，坐下来教导身边围坐的众人。</span>
<span className="v" id="v3" data-v="3"> 宗教老师和法利赛人带来一个妇人，她在通奸之时被抓住，叫她站在众人面前。</span>
<span className="v" id="v4" data-v="4"> 他们就对耶稣说：“老师，这妇人在通奸的时候被抓住。</span>
<span className="v" id="v5" data-v="5" data-xref="Leviticus 20:10; Deuteronomy 22:21–24; Ezekiel 16:38–40"> 摩西在律法上的裁决是：我们应该用石头将这样的妇人打死，你觉得呢？”</span>
<span className="v" id="v6" data-v="6" data-xref="Jeremiah 17:13; 路加福音 10:25; Ecclesiastes 3:7"> 他们这样说，其实是想找到耶稣言语中的把柄来控告他。但耶稣却弯下身，用手指在地上写字。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 7:1–5; 罗马书 2:21–25; 罗马书 2:1–3"> 他们不停地要求耶稣给出回答。耶稣直起身对他们说：“你们中谁没有罪，谁就可以先拿起石头打她。”</span>
<span className="v" id="v8" data-v="8"> 然后他又弯下身在地上写字。</span>
<span className="v" id="v9" data-v="9" data-xref="Ecclesiastes 7:22; 罗马书 2:15; 约翰一书 3:20"> 听到这番话，控诉者中从最年长的那个人开始一个接一个地离开了，，最后人群中只留下耶稣和站在原地的那位妇人。</span>
<span className="v" id="v10" data-v="10" data-xref="Isaiah 41:11–12"> 耶稣站直身问她：“他们哪儿去了？没有人留下来定你的罪吗？”</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 3:17; 约翰福音 5:14; Isaiah 1:16–18"> 她说：“先生，没有人。” 耶稣说：“我也不会定你的罪。走吧，不要再犯罪了。”</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 12:46; 约翰福音 9:5; 约翰福音 12:35"> 耶稣又对众人说：“我就是这世界的光，如果你跟随我，就不会走进黑暗，因为你将拥有赐予你生命的光。”</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 5:31–47"> 法利赛人反驳：“你不能为自己作证！<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或“你只是在讲述自己！”">a</a></sup>你所说的无法证明任何事！”</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 16:28; 约翰福音 13:3; 约翰福音 8:42"> 耶稣告诉他们：“即使我为自己作证，我的证言仍是真实。因为我知道我从哪里来，要到哪里去，但你们却不知道我从哪里来，要到哪里去。</span>
<span className="v" id="v15" data-v="15" data-xref="1 Samuel 16:7; 约翰福音 7:24; 约翰福音 12:47"> 你们以人类最常见的方式做出判断，但我不会做出评判。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 17:31; 约翰福音 8:29; 约翰福音 16:32"> 即使我要做出评判，我的判断也是正确的，因为并非一个人在做这件事情，派我前来的天父与我同在。</span>
<span className="v" id="v17" data-v="17" data-xref="Deuteronomy 19:15; Deuteronomy 17:6; 希伯来书 10:28"> 你们的律法上也写着<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="见《申命记》17:6和《申命记》19:15。">b</a></sup>：‘两个人的见证才有效。’</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 8:38; 约翰福音 8:58; 约翰福音 8:25"> 我为自己作证，派我前来的天父也为我作证。”</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 16:3; 约翰福音 8:54–55; 约翰福音 14:6–9"> 他们问耶稣：“你的父在哪里？”耶稣回答：“你们不认识我或我的天父，如果你们认识我，就会认识我父。”</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 7:30; 约翰福音 7:8; 马可福音 12:41"> 耶稣是在圣殿银库附近教导众人时，做出了这番解释。但没有人逮捕他，因为他的时候尚未到来。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 7:34; 约翰福音 8:24; 哥林多前书 15:17–18"> 耶稣又对他们说：“我要走了，你们将会寻找我，但你们会因自己的罪而死去，我要去的地方，你们无法抵达。”</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 8:52; Psalms 22:6; 约翰福音 8:48"> 犹太人思索着，然后大声说：“他要自杀吗？他说‘我要去的地方，你们无法抵达。’是这个意思吗？”</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 3:31; 约翰福音 17:14; 约翰福音 17:16"> 耶稣告诉他们：“你们来自人间，我来自天上。你们属于这个世界，我却不属于这世界。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 3:36; 马可福音 16:16; 约翰福音 3:18"> 所以我对你们说，你们会因自己的罪而死去。因为如果你们不相信我即‘我是’，你们就会因自己的罪而死去。”</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 5:17–29; 路加福音 22:67; 约翰福音 1:22"> 他们又问：“那你到底是谁？” 耶稣回答：“我从一开始就告诉你们的了。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 15:15; 约翰福音 12:47–50; 约翰福音 8:40"> 关于你们，我有很多可以说的，我可以对你们大加谴责，但派我来此的天父讲述的却是真相，我在这个世界对你们所说的，就是从他那里听来的。”</span>
<span className="v" id="v27" data-v="27" data-xref="Isaiah 6:9; 约翰福音 8:43; 哥林多后书 4:3–4"> 他们不明白耶稣所说的就是天父。于是耶稣解释说：</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 5:19; 约翰福音 5:30; 约翰福音 6:38"> “如果你们看到人子被高举，必定知道我即‘我是’，知道我的所作所为并非源于自己，我的言语都是遵循天父的教导。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 6:38; 约翰福音 16:32; 约翰福音 4:34"> 那派我来此之人与我同在，他未弃我，因为我的所行皆令其喜悦。”</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 7:31; 约翰福音 2:23; 约翰福音 11:45"> 很多人在听到耶稣的这番话后，便相信了他。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰二书 1:9; 约翰福音 15:4–9; 提摩太后书 3:14"> 于是耶稣对信他的犹太人说：“你们若遵循我的道，就真正是我的门徒。</span>
<span className="v" id="v32" data-v="32" data-xref="罗马书 8:2; 约翰福音 8:36; 约翰福音 17:17"> 你们将知晓真理，真理会让你们自由。”</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 3:9; 约翰福音 8:39; Genesis 15:13"> 众人问到：“我们是亚伯拉罕的后裔，从未被奴役过，你说我们会自由，又是何意呢？”</span>
<span className="v" id="v34" data-v="34" data-xref="罗马书 6:16; 彼得后书 2:19; Proverbs 5:22"> 耶稣答道：“说实话，每个罪人都是罪的奴隶。</span>
<span className="v" id="v35" data-v="35" data-xref="加拉太书 4:4–7; 路加福音 15:31; 罗马书 8:15–17"> 奴隶在家庭中无法拥有永远的地位，只有儿子才是家庭中永远的成员。</span>
<span className="v" id="v36" data-v="36" data-xref="哥林多后书 3:17; 加拉太书 5:1; 罗马书 8:2"> 当上帝之子让你自由，你就真正获得自由。</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前书 2:14; 约翰福音 8:45–47; 约翰福音 7:1"> 我知道你们是亚伯拉罕的后裔，但你们不愿接收我的道，所以想杀我。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 5:19; 约翰福音 8:44; 约翰福音 8:41"> 我所说的一切皆为我父显示给我的，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或“我在天父处所见。”">c</a></sup>但你们只是遵循你们的父亲行事。”</span>
<span className="v" id="v39" data-v="39" data-xref="加拉太书 3:7; 约翰福音 8:37; 罗马书 9:7"> 他们说：“亚伯拉罕就是我们的父亲。” 耶稣说：“你们若真是亚伯拉罕的子孙，就必做亚伯拉罕所行之事。</span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 8:26; 加拉太书 4:29; 加拉太书 4:16"> 但现在，只因我讲述了从上帝那里听见的真理，你们便想杀我，亚伯拉罕绝不会这么做。</span>
<span className="v" id="v41" data-v="41" data-xref="Isaiah 64:8; 约翰福音 8:38; Isaiah 63:16"> 你们只是遵循你们的父亲。” 他们回答：“我们<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原文中强调了这个词，意为他们不非法，但耶稣是。">d</a></sup>不是非法子孙，上帝是我们唯一的父亲。”</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 12:49; 约翰福音 14:10; 约翰福音 17:8"> 耶稣说：“如果上帝真是你们的父亲，你们就该爱我，因我来自上帝，现在我就在这里。这不是我的决定，而是派我前来之人的决定。</span>
<span className="v" id="v43" data-v="43" data-xref="约翰福音 12:39–40; 罗马书 8:7–8; 约翰福音 7:17"> 为什么你们无法理解我的话？因为你们不肯听我所传递的讯息！</span>
<span className="v" id="v44" data-v="44" data-xref="使徒行传 13:10; 约翰一书 3:12; 约翰一书 3:8–10"> 你们的父是魔鬼，你们也喜欢遵循其魔鬼的欲望行事。他从一开始就是杀人犯，不讲真理，因他心里没有真理。当他说谎时便显露了他的本性，因为他就是一个说谎者，是谎言之父。</span>
<span className="v" id="v45" data-v="45" data-xref="提摩太后书 4:3–4; 加拉太书 4:16; 约翰福音 18:37"> 我说的都是真理，你们却因此而不相信我！</span>
<span className="v" id="v46" data-v="46" data-xref="希伯来书 4:15; 约翰福音 16:8; 彼得前书 2:22"> 你们中有谁能指证我有罪？我既然讲真理，你们为什么不信我？</span>
<span className="v" id="v47" data-v="47" data-xref="约翰福音 10:26–27; 约翰二书 1:9; 约翰福音 18:37"> 归属于上帝之人就会聆听上帝之语。你们不听，因为你们并不归属于上帝。”</span>
<span className="v" id="v48" data-v="48" data-xref="约翰福音 7:20; 约翰福音 8:52; 马太福音 10:5"> 犹太人对耶稣说：“我们说你是魔鬼附体的撒玛利亚人，难道不对吗？”</span>
<span className="v" id="v49" data-v="49" data-xref="彼得前书 2:23; Isaiah 49:3; 约翰福音 13:31–32"> 耶稣回答：“我不是魔鬼附体。我尊敬我父，你们却侮辱我。</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 5:41; 约翰福音 8:54; 约翰福音 7:18"> 我来此并非追求自己的荣耀，但确有一人为我寻求荣耀，来此对人做出审判。</span>
<span className="v" id="v51" data-v="51" data-xref="约翰福音 11:25–26; 约翰福音 5:24; 约翰福音 3:15–16"> 告诉你们实话，遵守我的教导将永远不会死去。”</span>
<span className="v" id="v52" data-v="52" data-xref="约翰福音 9:24; 约翰福音 8:48; 希伯来书 2:9"> 犹太人对他说：“现在我们知道你的确是魔鬼附身。亚伯拉罕死了，先知们也死了，你居然还说‘遵守我的教导将永远不会死去’，</span>
<span className="v" id="v53" data-v="53" data-xref="约翰福音 4:12; 罗马书 9:5; 希伯来书 7:1–7"> 难道你比我们的祖先亚伯拉罕还伟大吗？他死了，先知们也死了，你把自己当做什么人呢？”</span>
<span className="v" id="v54" data-v="54" data-xref="约翰福音 8:50; Proverbs 25:27; 彼得后书 1:17"> 耶稣回答：“如果我只获得自己的荣耀，那荣耀就不值一提；让我荣耀之人是上帝，正如你们所说的‘他就是上帝’。</span>
<span className="v" id="v55" data-v="55" data-xref="约翰福音 8:19; 约翰福音 8:44; 约翰福音 7:28–29"> 你们不认识他，我却认识。如果我说不认识他，就会像你们一样说谎。但我的确认识他，也遵守他的道。</span>
<span className="v" id="v56" data-v="56" data-xref="希伯来书 11:13; Genesis 22:18; 加拉太书 3:7–9"> 你们的祖先亚伯拉罕，因为期待我降临的日子而充满喜悦。当看到指示便感到如此幸福。”</span>
<span className="v" id="v57" data-v="57"> 犹太人回答：“你还不到五十岁，怎会见过亚伯拉罕呢？”</span>
<span className="v" id="v58" data-v="58" data-xref="Exodus 3:14; 歌罗西书 1:17; 约翰福音 17:5"> 耶稣说：“告诉你们实话，亚伯拉罕出生以前，我就已存在。”<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原意为“在亚伯拉罕出现之前，我是。”耶稣再次使用《出埃及记》3:14 中上帝的名字。尽管他们想要用石头砸他，做出亵渎上帝的反应，上帝对他们仍然有意义。">e</a></sup></span>
<span className="v" id="v59" data-v="59" data-xref="约翰福音 11:8; 约翰福音 10:30–33; 约翰福音 10:39–40"> 于是他们捡起石头要去砸他。耶稣躲开他们，离开了圣殿。</span>

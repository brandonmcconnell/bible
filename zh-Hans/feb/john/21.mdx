<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 6:1; 约翰福音 6:23; 马太福音 28:16"> 在这之后，耶稣在提比里亚海边再次向门徒显现。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="意为“提比利亚海。”">a</a></sup>他显现的经过是这样的：</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 4:21–22; 约翰福音 1:45–1; 约翰福音 4:46"> 当时彼得、“双生子”多马、加利利的迦拿人拿但业、西庇太的两个儿子，和另外两个门徒聚在一起。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 5:5; 马太福音 4:18–20; 帖撒罗尼迦后书 3:7–9"> 彼得对他们说：“我要打鱼去。”他们说：“我们也跟你一起去。”于是他们出去上了船，可是那一夜他们并没有打到什么。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 20:14; 路加福音 24:15–16; 路加福音 24:31"> 黎明时分，耶稣站在岸边，门徒却不知道他就是耶稣。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 4:19; 腓立比书 4:11–13; 约翰一书 2:13"> 耶稣对他们说：“我的朋友们，打到鱼没有？”他们回答：“没有。”</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 5:4–7; 使徒行传 2:41; 约翰福音 2:5"> 耶稣说：“把网撒在船的右侧就可以打到鱼。”于是他们把网撒下去，但却拉不动，因为鱼太多。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 13:23; 约翰福音 20:2; 马太福音 14:28–29"> 耶稣所爱的那名门徒对彼得说：“是主！”彼得一听见是主，就立刻穿上衣服（因为他当时没有穿衣服），纵身跳进海里。</span>
<span className="v" id="v8" data-v="8" data-xref="Deuteronomy 3:11"> 其他的门徒因为离岸不远（约有一百公尺），于是就跟着来到小船上，把那网鱼拖过来。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 21:13; 1 Kings 19:5–6; 约翰福音 21:10"> 他们上了岸，就看见那里有一堆篝火，上面正在烹饪鱼，还有一些饼。</span>
<span className="v" id="v10" data-v="10"> 耶稣对他们说：“把你们刚才打的鱼拿几条来。”</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 5:6–8; 使徒行传 2:41"> 彼得上船把网拉到岸上，那网装满了大鱼，共有一百五十三条。鱼虽然这么多，网却没有破。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 10:41; 路加福音 9:45; 约翰福音 16:19"> 耶稣对他们说：“来吃早饭吧。”门徒中没有一个人敢问他：“你是谁？”因为知道他是主。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 21:9; 使徒行传 10:41; 路加福音 24:42–43"> 耶稣走过来，把饼递给他们，又把鱼递给他们。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 20:26; 约翰福音 20:19"> 这是耶稣死而复生后，第三次向门徒显现。</span>
<span className="v" id="v15" data-v="15" data-xref="Isaiah 40:11; 约翰一书 4:19; 罗马书 15:1"> 他们吃了早饭，耶稣问西门（彼得）：“约翰的儿子西门，你爱我比这些更深吗？”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“这些。”可能是指周围的物体，即渔民的交易，但更有可能是指其他门徒。存在疑问的是彼得对耶稣的爱。">b</a></sup>他回答说：“是的，主啊，你知道我爱你。”</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 20:28; 彼得前书 5:2; 彼得前书 2:25"> 耶稣对他说：“照顾好我的羊羔。”耶稣第二次又问他：“约翰的儿子西门，你爱我吗？”他回答：“主啊，是的，你知道我爱你。”</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 13:38; 约翰福音 16:30; 马可福音 14:72"> 耶稣说：“照顾好我的绵羊。”耶稣第三次问他：“约翰的儿子西门，你爱我吗？”彼得因为耶稣第三次问他“你爱我吗？”就有些难过。于是对耶稣说：“主啊，你是无所不知的，你知道我爱你。”耶稣说：“照顾好我的绵羊。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 13:36; 使徒行传 12:3–4; 使徒行传 21:11"> 告诉你实话，当你年轻的时候，你会打扮好去任何地方，但当你变老，就要伸出手来，让别人给你穿上衣服，带你到你不愿意去的地方。”</span>
<span className="v" id="v19" data-v="19" data-xref="彼得后书 1:14; 约翰福音 21:22; 马太福音 10:38"> 耶稣说这话，是在解释他死亡的方式如何让上帝获得荣耀。然后他对彼得说：“跟我来吧。”</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 21:7; 约翰福音 20:2; 约翰福音 21:24"> 彼得转过身来，看见耶稣所爱的那名门徒跟着他们，他在最后的晚餐时曾侧身问耶稣：“主啊，出卖你的是谁？。”</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 13:23–24; 使徒行传 1:6–7; 马太福音 24:3–4"> 彼得看见他，就问耶稣：“主啊，他会怎么样呢？”</span>
<span className="v" id="v22" data-v="22" data-xref="启示录 2:25; 启示录 3:11; 马可福音 9:1"> 耶稣回答他：“如果我让他活到我到来之时，跟你有什么关系呢？你只管跟从我吧！”</span>
<span className="v" id="v23" data-v="23" data-xref="Deuteronomy 29:29; Job 33:13; Daniel 4:35"> 这句话传到其他门徒那里，说那位门徒不会死。其实耶稣并没有对他说他不会死，只是说：“如果我让他活到我到来之时，跟你有什么关系呢？”</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 19:35; 约翰福音 15:27; 约翰一书 5:6"> 这位门徒确认发生过这件事，并且将其写了下来。我们知道他的见证是真实的。</span>
<span className="v" id="v25" data-v="25" data-xref="Psalms 40:5; 约翰福音 20:30–31; Psalms 71:15"> 耶稣还做过许多其他的事情，如果全部写下来，我怀疑整个世界能否容纳所有要写的书。</span>

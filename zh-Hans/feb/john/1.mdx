<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Genesis 1:1; 约翰福音 17:5; 启示录 19:13"> 在世界之初，道即已存在<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="换言之，道在世界创造之前便已亘古存在。道的概念不仅是用字母组成的单词，更像《创世记》1:1 所述，那是神圣思想，是上帝旨意的表达，那是神性存在的证据。">a</a></sup>。这是上帝之道，道即上帝。</span>
<span className="v" id="v2" data-v="2"> 在万物之初，这道便与上帝同在。</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 1:16–17; 哥林多前书 8:6; 启示录 4:11"> 万物皆为他所造，没有上帝就没有世上的一切。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 8:12; 约翰福音 12:46; 约翰福音 5:26"> 他是生命之源，这生命就是人之光。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 3:19–20; 约翰福音 12:36–40; 哥林多前书 2:14"> 光照亮黑暗，黑暗不能将光熄灭。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这个单词在原文中的意思也可能表示“力量过大”或“理解。”">b</a></sup></span>
<span className="v" id="v6" data-v="6" data-xref="Malachi 3:1; 约翰福音 3:28; Isaiah 40:3–5"> 上帝派一位叫做约翰的人前来，</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 19:4; 约翰福音 1:36; 约翰福音 5:33–35"> 证明和解释光，让众人通过他相信上帝。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 1:20; 约翰福音 3:28; 使徒行传 19:4"> 约翰不是光，而是要来此为那光作见证。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 12:46; 约翰福音 1:4; 约翰一书 2:8"> 这真正的光来到世界，普照世人。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 17:25; 约翰一书 3:1; 哥林多前书 2:8"> 他在这个世界上，世界乃通过他创造而成，但世界却并不知晓他是谁。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或“无法认出他。”">c</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:14; Isaiah 53:2–3; 约翰福音 3:32"> 他来到自己的子民身边，但他们却不接受他。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或“他来到自己的家，但他的人民不欢迎他。”">d</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 3:26; 罗马书 8:14; 约翰一书 3:1"> 但接受他就是相信他的人，他会赋予他们成为上帝儿女的权利。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰一书 3:9; 雅各书 1:18; 彼得前书 1:23"> 他们并非以人间方式诞生的儿女，不是人类欲望的结果或父亲做出的决定，而是由上帝诞生。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰一书 4:9; 提摩太前书 3:16; Isaiah 40:5"> 道变身人类，生活在人类中间，我们可以看到他的荣光，这是天父唯一<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原意为“唯一受生。”这是指的是地位和独特性，而不是诞生之意。">e</a></sup>之子的荣光，满溢恩典和真理。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 3:11; 歌罗西书 1:17; 路加福音 3:16"> 约翰为他作见证，向民众高声呼喊：“他就是我之前所说的那个人：‘在我之后到来的人，远比我重要得多，因为他早在我之前就已存在。’”</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 1:19; 罗马书 5:2; 以弗所书 2:5–10"> 他生性慷慨，我们接受他的慷慨，不断获得恩典之礼。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 6:14; 约翰福音 14:6; 罗马书 3:19–26"> 律法借由摩西颁布，恩典和真理却是通过耶稣基督而存在。</span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 1:15; 约翰福音 6:46; 马太福音 11:27"> 从未有人见过唯一的上帝，只有距离天父最近之人，才能向我们展示何为上帝。<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="或“让他被知晓。”">f</a></sup></span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 3:15–18; 约翰福音 10:24; 使徒行传 19:4"> 犹太人从耶路撒冷派祭司和利未人来到约翰这里，问他：“你是谁？”以下便是约翰做出的公开呈明。</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 1:7–8; 马太福音 3:11–12; 约翰福音 3:28–36"> 约翰明确而坦诚地说：“我不是基督。”没有一丝犹豫。</span>
<span className="v" id="v21" data-v="21" data-xref="Malachi 4:5; Deuteronomy 18:15–18; 马太福音 11:14"> 他们问：“那么你是谁？是以利亚吗？” 他说：“不，我不是。” “是那位先知吗？”<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="在犹太人的思想中，会有一位特别的先知预料到末日。">g</a></sup>他回答：“不是。”</span>
<span className="v" id="v22" data-v="22" data-xref="2 Samuel 24:13"> 他们再问：“那么你是谁？我们需要回复派我们前来之人。你认为你自己是谁？”</span>
<span className="v" id="v23" data-v="23" data-xref="Isaiah 40:3–5; 马可福音 1:3; 马太福音 3:3"> 他说：“我就是荒野中的呼喊之声：‘修直主的路！’”他引用了以赛亚先知所说的一句话。<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="引自《以赛亚书》40:3。">h</a></sup></span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 11:53; 马太福音 23:13–15; 路加福音 11:39–44"> 这些由法利赛人<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="“祭司和利未人”：在第 19 句中有相关隐喻。">i</a></sup>派来的祭司和利未人</span>
<span className="v" id="v25" data-v="25" data-xref="Deuteronomy 18:18; Deuteronomy 18:15; 约翰福音 1:20–22"> 问约翰：“你既然不是基督、不是以利亚、也不是那位先知，那么你为什么施洗？”</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 1:10–11; 路加福音 3:16; 使徒行传 1:5"> 约翰回答：“我只是用水施洗，但你们中却有一个人，你们并不认识。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 1:30; 马可福音 1:7; 马太福音 3:11"> 他在我之后到来，我即使给他解鞋带都不配。”</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 10:40; 约翰福音 3:23; Judges 7:24"> 约翰在约旦河施洗，这一切就发生在约旦河远处的伯大尼。</span>
<span className="v" id="v29" data-v="29" data-xref="Isaiah 53:7; 约翰一书 2:2; 约翰一书 3:5"> 第二天，约翰见耶稣向他走来，就说：“看，这是上帝的羔羊，他可以去除这世间的罪！</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 1:27; 约翰福音 1:15; 路加福音 3:16"> 这就是我说的那个人‘有一个人，在我之后到来，远比我重要的多，因为他早在我之前就已存在。’</span>
<span className="v" id="v31" data-v="31" data-xref="Malachi 3:1; 路加福音 1:17; Malachi 4:2–5"> 我本来不认识他。但为了让他可以显现给以色列人，我才来此用水施洗。”</span>
<span className="v" id="v32" data-v="32" data-xref="马可福音 1:10; 路加福音 3:22; 马太福音 3:16"> 约翰又给出关于耶稣的证明：“我曾看见圣灵如鸽子般从天上降落，停留在他的身上。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 1:5; 马太福音 3:11; 路加福音 3:16"> 我本来不认识他，但派我前来用水施洗的那个人对我说：‘如果你看见圣灵降下并停留在谁身上，谁就能用圣灵进行施洗。’</span>
<span className="v" id="v34" data-v="34" data-xref="Psalms 2:7; 约翰福音 1:49; Psalms 89:26–27"> 我看到了所发生的一切，所以才能见证他就是上帝之子。”</span>
<span className="v" id="v35" data-v="35" data-xref="约翰福音 3:25–26; Malachi 3:16"> 第二天，约翰和他的两个门徒站在那里。</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 1:29; 彼得前书 1:19–20; Isaiah 65:1–2"> 约翰看见耶稣经过，就说：“看，这就是上帝的羔羊！”</span>
<span className="v" id="v37" data-v="37" data-xref="罗马书 10:17; 约翰福音 1:43; Zechariah 8:21"> 那两个门徒听见他这番话，就开始跟随耶稣。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 18:7; 约翰福音 3:2; 约翰福音 1:49"> 耶稣转过身来，看见他们跟在身后，就问：“你们在寻找什么？”他们说：“拉比（意为‘老师’），你住在哪里？”</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 24:29; 马太福音 11:28–30; 约翰福音 6:37"> 他说：“来看看吧。”于是他们就跟随他，看到他所住的地方。当时是下午四点，这一天剩下的时间，他们都和耶稣待在一起。</span>
<span className="v" id="v40" data-v="40" data-xref="马可福音 1:16–20; 马太福音 4:18–22; 约翰福音 1:40–42"> 在听从约翰跟随耶稣的那两个人中，有一个人是西门（即彼得）的弟弟安得烈。</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 4:25; 约翰福音 1:45; Psalms 89:20"> 他先找到自己的哥哥西门，告诉他：“我们遇见弥赛亚了！”（“弥赛亚”意为“基督。”）<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="“基督”的本意为“被涂抹圣油之人。”">j</a></sup></span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 21:15–17; 哥林多前书 3:22; 哥林多前书 15:5"> 然后他就带着西门去见耶稣。耶稣直接看着西门说：“你是约翰的儿子西门，但现在你叫做矶法。”（即“彼得。”）<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="矶法和彼得都有“岩石”或“石头”的意思。">k</a></sup></span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 9:9; 约翰福音 14:8; Isaiah 65:1"> 第二天，耶稣决定去加利利。路上遇见了腓力，就对他说：“跟随我吧！”</span>
<span className="v" id="v44" data-v="44" data-xref="约翰福音 12:21; 马太福音 11:21; 马可福音 8:22"> 腓力是伯赛大人，是安得烈和彼得的同乡。</span>
<span className="v" id="v45" data-v="45" data-xref="Deuteronomy 18:18–22; 路加福音 24:27; Micah 5:2"> 腓力找到拿但业，告诉他：“我们遇见了摩西在律法书上所写，众先知所记载的那个人，他就是约瑟的儿子，拿撒勒人耶稣。”</span>
<span className="v" id="v46" data-v="46" data-xref="约翰福音 7:52; 约翰福音 7:41–42; 约翰福音 4:29"> 拿但业说：“拿撒勒？那里能出什么好事？”腓力说：“来看看就知道了！”</span>
<span className="v" id="v47" data-v="47" data-xref="启示录 14:5; Psalms 32:2; Psalms 73:1"> 耶稣看见拿但业向他走过来，这样评价他：“看，这是一位真正的以色列人！没有任何污点和过错。”</span>
<span className="v" id="v48" data-v="48" data-xref="Isaiah 65:24; 约翰福音 2:25; Psalms 139:1–2"> 拿但业问他：“你怎么知道我呢？”耶稣回答：“在腓力招呼你之前，我看到你站在无花果树下。”</span>
<span className="v" id="v49" data-v="49" data-xref="Zephaniah 3:15; Zechariah 9:9; 马太福音 27:42"> 拿但业欢呼道：“拉比，你是上帝之子，你是以色列的王！”</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 11:40; 约翰福音 20:29; 路加福音 1:45"> 耶稣说：“你相信我，就是因为我说‘我看见你在无花果树下’这句话吗？你看到的会更多！”</span>
<span className="v" id="v51" data-v="51" data-xref="Genesis 28:12; 使徒行传 7:56; 路加福音 22:43"> 然后耶稣说：“告诉你实话，你将看见天空开启，上帝的天使在人子处上上下下。”<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="即雅各在《创世纪》28:12中的经历。用“人子”替代“阶梯。”">l</a></sup></span>

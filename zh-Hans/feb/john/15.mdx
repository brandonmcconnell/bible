<span className="v" id="v1" data-v="1" data-xref="Jeremiah 2:21; Isaiah 27:2–3; 哥林多前书 3:9"> “我是真正的葡萄树，天父就是园丁。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 3:10; 希伯来书 12:10–11; 马太福音 15:13"> 我的枝杈如果不结果子，他就会将其剪去，他修剪结果子的枝杈，让它结更多的果子。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 17:17; 以弗所书 5:26; 彼得前书 1:22"> 现在你们因我所言也被修剪过了，变得洁净<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="在这种情况下，修剪的意思为“洗涤。”">a</a></sup>。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰一书 2:6; 加拉太书 2:20; 约翰福音 8:31"> 你们要与我同在，我就与你们同在。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="很显然，“在......里”这个词应该被理解为“与......有关”，这节经文的其余部分已经清楚表明这一点。">b</a></sup>枝杈必须长在葡萄树上，凭它自己不能结出果实。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 4:13; 歌罗西书 1:10; 约翰福音 15:16"> 我是葡萄树，你们是枝杈。与我一体，我也与他一体，这样就会结出丰盛的果实，因为离开了我，你们什么都做不了。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 7:19; 希伯来书 6:7–8; 马太福音 13:41"> 不与我同在，就像枝杈被丢弃，变得枯干，人们会把它们拾起来，丢在火里烧掉了。</span>
<span className="v" id="v7" data-v="7" data-xref="Psalms 37:4; 约翰一书 5:14; 约翰福音 14:13"> 你们若与我同在，我的言语也与你们同在，无论你们想要什么，祈求什么，都会给你们。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 8:31; 马太福音 5:16; 腓立比书 1:11"> 因为你们结出丰盛果实，也是让天父获得荣耀，证明你们就是我的门徒。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 17:23–24; 约翰福音 17:26; 约翰一书 2:28"> 天父怎样爱我，我也怎样爱你们。你们与我的爱同在。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 14:15; 约翰一书 5:3; 约翰一书 3:21–24"> 如果你们遵守我的命令，就会与我的爱同在，正像我遵守了我父的命令，便与他的爱同在。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 17:13; 罗马书 15:13; 约翰福音 16:24"> 我把这事解释给你们听，是为了将欢喜留在你们心中，让你们的欢喜变得圆满。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰一书 4:21; 彼得前书 4:8; 约翰福音 13:34"> 我命令你们：要彼此相爱，像我爱你们一样。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 10:11; 以弗所书 5:2; 罗马书 5:6–8"> 人愿意舍命为朋友，人间没有比这更伟大的爱。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 12:50; 约翰一书 5:3; 雅各书 2:23"> 你们听从我的吩咐，就是我的朋友。</span>
<span className="v" id="v15" data-v="15" data-xref="Psalms 25:14; 哥林多前书 2:9–12; 马太福音 13:11"> 我不再称你们为仆人，因为仆人不知道主人所做的事，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="意为“一个仆人不知道他的主人在做什么。”">c</a></sup>我会称你们为朋友，因为我已把从天父那里听见的一切，都解释给了你们听。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 15:19; Jeremiah 1:5–7; 以弗所书 2:10"> 不是你们选择了我，而是我选择了你们，我赋予你们责任，去结出不朽的果实，这样你们以我之名所求的一切，天父都必将应允。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 15:12; 约翰一书 3:14–17; 彼得前书 2:17"> 这就是我的命令：彼此相爱。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰一书 3:13; 约翰福音 7:7; 马可福音 13:13"> 如果世人恨你们，记得他们在恨你们之前，就已经恨我了。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 4:4–5; 约翰福音 17:14–16; 以弗所书 1:4–11"> 你们若属于这世界，这世界也会像爱自己一样爱你。但因为你们不属于这世界，而是我从世界中选出你们，所以世人就恨你们。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太后书 3:12; 约翰福音 13:16; 马太福音 10:24"> 你们要记住我对你们说过的话：‘仆人不能比主人更重要。’他们若迫害我，也必定迫害你们，他们若遵守我的话，也必定遵守你们的话。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 10:22; 约翰福音 16:3; 马太福音 10:18"> 但他们对你们所做的一切都是因为我，因为他们不知晓派我前来的天父。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 9:41; 雅各书 4:17; 使徒行传 17:30"> 如果我没有来，没有对他们说过什么，他们就意识不到自己的罪。但现在他们无法找到开罪的借口了。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 8:40–42; 约翰二书 1:9; 约翰一书 2:23"> 恨我的人，也恨我的父。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 5:36; 约翰福音 14:9; 约翰福音 7:31"> 如果我没有通过其他人从未做过的事情，向他们进行显现，他们就不会意识到自己的罪，但尽管看到了这一切，他们仍然恨我和我父。</span>
<span className="v" id="v25" data-v="25" data-xref="Psalms 109:3; Psalms 69:4; Psalms 35:19"> 这就应验了经书所说：‘他们无缘故地恨我。’<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《诗篇》35:19，《诗篇》69:5。">d</a></sup></span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 14:26; 约翰福音 14:16–17; 约翰福音 16:13–15"> 但我会从天父那里向你们派来保惠师，他是来自天父的真理圣灵。当他来到，就会为我作见证。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰一书 4:14; 约翰福音 21:24; 使徒行传 10:39–42"> 你们也要为我作证，因为你们从开始就和我在一起。”</span>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="feb" data-translation-id="cmn_feb" data-translation-label="易读圣经" data-book="GAL" data-book-slug="galatians" data-book-name="加拉太书" data-chapter="5" data-verses="26">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 3:17; 加拉太书 5:13; 彼得前书 2:16"> 基督让我们自由，所以我们可以拥有真正的自由。要站稳脚跟，不要再被奴役的枷锁压垮。</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太书 5:6; 使徒行传 15:1; 罗马书 9:31–32"> 我保罗在这里直截了当地告诉你：如果你们依靠割礼的方式，基督对你们绝对没有益处。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 3:10; 罗马书 2:25; 雅各书 2:10–11"> 让我再说一遍：每个受割礼的人都必须遵守全部律法。</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 9:31–32; 彼得后书 2:20–22; 罗马书 11:6"> 如果你们认为自己可以通过律法就能行正义，然后放弃基督——你们已经放弃了恩典。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="Psalms 130:5; 帖撒罗尼迦前书 1:10; Psalms 62:5"> 因为我们通过灵表示相信，并满怀期待地等待灵让我们变得正直良善。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 6:15; 哥林多前书 7:19; 雅各书 2:14–26"> 因为对基督耶稣而言，受割礼或未受割礼都无济于事，只有通过爱表达的信任才最重要。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 9:24; 加拉太书 3:1; 希伯来书 12:1"> 你们过去做得很好！是谁妨碍并阻止你们相信真相？</span>
<span className="v" id="v8" data-v="8" data-xref="加拉太书 1:6; 罗马书 8:28"> 这种“说服”当然不是来自呼唤你们的那个人。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 15:33; 哥林多前书 5:6–7; 马可福音 8:15"> 你们只需要一点酵母就可以发酵整个面团。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 5:12; 哥林多后书 2:3; 加拉太书 1:7"> 我相信主，你们不会改变自己的想法，让你们困惑的那个人，无论他是谁，必会面对后果。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或“审判”">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 1:23; 加拉太书 6:12; 加拉太书 4:29"> 兄弟姐妹们，如果我仍然提倡割礼，为什么还要受压迫呢？如果那是真相，就不会再有如此冒犯众人的十字架问题。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 5:10; 哥林多前书 5:13; 提多书 3:10"> 如果给你们带来麻烦的人能比割礼更进一步，去阉割自己就好了！<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="当然这并非字面意思，而是象征说法，将割礼的理念推到极致。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="彼得前书 2:16; 哥林多前书 9:19; 哥林多前书 8:9"> 我的兄弟姐妹们，呼唤你们追寻自由！但不要用自由为借口来放纵你们有罪的人性——而是要在爱中互相服务。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 7:12; Leviticus 19:18; 加拉太书 6:2"> 因为有一条诫命概括了整个律法：“要爱人如己。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《利未记》19:18。">c</a></sup></span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 3:3; 雅各书 3:14–3; 加拉太书 5:26"> 但是如果你攻击并相互拉扯，注意不要完全摧毁自己！</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太书 5:24–25; 罗马书 8:12–14; 加拉太书 6:8"> 我建议你们跟随灵而行。不要满足你有罪的人性欲望。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 8:13; 约翰福音 3:6; 罗马书 8:5–8"> 因为有罪的人性欲望与灵对立，灵的愿望与有罪人性相对立。他们相互争斗，所以你们不能做自己想做的事。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 8:14; 罗马书 6:14–15; 加拉太书 5:25"> 但如果灵引导你，你们就不会承担律法的责任。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 6:9–10; 歌罗西书 3:5–8; 马太福音 15:18–19"> 罪人的本性很明显：淫乱、下流、放荡、</span>
<span className="v" id="v20" data-v="20" data-xref="提多书 3:10; 哥林多前书 11:19; 启示录 21:8"> 拜偶像、巫术、仇恨、对抗、嫉妒、愤怒、自私的野心、纷争、异端、</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 6:9–10; 罗马书 8:13; 罗马书 13:13"> 嫉妒、醉酒、大吃大喝等等。我之前警告过你们，现在再次警告：任何做出这种行为的人，都无法继承上帝之国。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 3:12–17; 哥林多前书 13:4–7; 约翰福音 15:5"> 但灵会结下善果，比如仁爱、喜乐、和平、忍耐、恩慈、良善、信任、</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太前书 1:9; 使徒行传 24:25; 提多书 2:2"> 温柔和克制等，而且没有任何律法禁止这些事情！</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 6:6; 罗马书 13:14; 罗马书 8:13"> 那些属于基督耶稣的人，已经将他们有罪的人性以及全部有罪的激情和欲望钉在了十字架上。</span>
<span className="v" id="v25" data-v="25" data-xref="加拉太书 5:16; 罗马书 8:4–5; 罗马书 8:2"> 如果我们活在圣灵中，也应该在按圣灵行事。</span>
<span className="v" id="v26" data-v="26" data-xref="雅各书 3:14–16; 腓立比书 2:1–3; 雅各书 4:16"> 我们不要自吹自擂，不要互相激怒和嫉妒。</span>
</div>
</div>

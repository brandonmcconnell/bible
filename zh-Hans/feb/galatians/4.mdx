<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 4:23; 加拉太书 4:29; Genesis 24:2–3"> 让我解释一下自己所说的。尽管继承人可能拥有一切，但未成年的继承人与奴隶无异。</span>
<span className="v" id="v2" data-v="2"> 继承人在父亲设定的时间前，需要受监护人和管理人的约束。</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 2:20; 歌罗西书 2:8; 加拉太书 4:9"> 我们也一样。当我们还是孩子时，就像受律法基本规则<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这里翻译的“规则”一词意思比较广泛。这个词最初的含义是字母表，后来又有了生活中“基础信息”的含义。保罗将礼仪律法比作字母和符号，都是对现实生活的基本指引，但没有拯救和治愈的力量。第 9 节中使用了相同的词。">a</a></sup>约束的奴隶。</span>
<span className="v" id="v4" data-v="4" data-xref="Isaiah 7:14; 约翰福音 1:14; 罗马书 1:3"> 但在恰当的时间，上帝派他的儿子前来，一个女人根据律法规则将其诞生，</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 9:15; 以弗所书 1:5; 彼得前书 1:18–20"> 以便他可以拯救那些被律法束缚之人，让我们可以作为养子得到应得的遗产。</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 8:15–17; 罗马书 5:5; 罗马书 8:9"> 为表明你是上帝的孩子，上帝差遣其子之灵来说服我们，让我们呼唤其“阿爸”，即“父亲。”</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:16–17; 加拉太书 3:29–2; 加拉太书 3:26"> 你们现在已经不再是奴隶，而是孩子。如果你是上帝的孩子，上帝就已经让你们成为他的继承人。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 8:4; 以弗所书 2:11–12; 帖撒罗尼迦后书 1:8"> 你们还不知道上帝的时候，曾被这个世界上所谓的“神”所奴役。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 8:3; 加拉太书 3:3; 罗马书 8:3"> 但现在你们知道了上帝——或者更好的表达是：上帝知道了你们。那你们怎么又会掉头去信那些无用和毫无价值的规则呢？你们想再次成为那些规则的奴隶吗？</span>
<span className="v" id="v10" data-v="10" data-xref="歌罗西书 2:16–17; 罗马书 14:5; Leviticus 23:1–44"> 你们关注的是特殊的日子和月份、季节和年份。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这是所指为旧约体系中遵守特殊的节期和时间。">b</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="帖撒罗尼迦前书 3:5; 腓立比书 2:16; 加拉太书 2:2"> 我担心为你们所做的一切，都白费了！</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 2:5; 1 Kings 22:4; Genesis 34:15"> 朋友们，我恳求你们：要像我一样，因为我已经变得像你们一样。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="换言之，即“被解放的异族人。”">c</a></sup>你们从未以不好的方式对待我。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 2:3; 哥林多后书 12:7–10; 哥林多后书 11:30"> 还记得我第一次造访、向你们分享福音吗？当时我生病了。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="好像是因为保罗生病而晚到了，所以他有机会与加拉太人分享了福音。">d</a></sup></span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 10:40; 帖撒罗尼迦前书 2:13; 希伯来书 13:2"> 尽管我的病对你们而言很麻烦，但你们并没有轻视或拒绝我——事实上，你们视我为上帝的天使，就像基督耶稣自己一样。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 5:2; 约翰一书 3:16–18; 歌罗西书 4:13"> 那么你们的感激之情产生了什么结果？我告诉你，那时候如果要你们把眼睛掏出来给我，你们也会的！</span>
<span className="v" id="v16" data-v="16" data-xref="Amos 5:10; Proverbs 9:8; 约翰福音 8:45"> 那么发生了什么事——我告诉你们真相，是不是成了你们的敌人？</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 16:18; 哥林多后书 11:13–15; 彼得后书 2:3"> 这些人渴望获得你们的支持，但可不是出于什么好理由。相反，他们想让你们远离我们，这样你们就会热情地支持他们。</span>
<span className="v" id="v18" data-v="18" data-xref="腓立比书 2:12; 启示录 3:19; 腓立比书 1:27"> 想做善事当然很好。但应该时刻做善事，而不是只在我与你们在一起的时候！<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="暗示这些人只希望对加拉太人有所帮助，实现他们自己的想法。">e</a></sup></span>
<span className="v" id="v19" data-v="19" data-xref="以弗所书 4:13; 罗马书 8:29; 罗马书 13:14"> 我亲爱的朋友们，我想和你们一起工作，直到你们身上也拥有了基督的品格。</span>
<span className="v" id="v20" data-v="20" data-xref="帖撒罗尼迦前书 2:17–18; 哥林多前书 4:19–21; 帖撒罗尼迦前书 3:9"> 我真心希望自己现在能和你在一起，这样我就可以改变我的语气......我很担心你们。</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太书 3:10; 加拉太书 3:23–24; 罗马书 7:5–6"> 你们这些想要按照律法生活的人，请回答我的这个问题：你们听到律法在说什么吗？</span>
<span className="v" id="v22" data-v="22" data-xref="Genesis 16:15; Genesis 21:10; Genesis 21:1–2"> 正如经文所说，亚伯拉罕有两个儿子，一个是婢女所生，一个是自由之身的妇人所生。<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="参见《创世记》16:15和《创世记》21:2-3。">f</a></sup></span>
<span className="v" id="v23" data-v="23" data-xref="希伯来书 11:11; 罗马书 9:7–8; 加拉太书 4:28–29"> 但婢女的儿子是按照人类的计划出生，<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="这里所指为莎拉计划通过她的女仆生个孩子。">g</a></sup>自由女性的儿子诞生则是承诺的而生结果。</span>
<span className="v" id="v24" data-v="24" data-xref="Genesis 21:9–13; 希伯来书 10:15–18; Genesis 16:8"> 这里有一个类比：这两位妇人代表了两个约定。一份约定来自西奈山，婢女夏甲生下了奴隶的孩子。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 19:44; 使徒行传 1:11; 加拉太书 1:17"> 夏甲象征着阿拉伯的西奈山，即现在的耶路撒冷，因为她和她的孩子们都是奴隶。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 12:22; 腓立比书 3:20; Micah 4:1–2"> 但天上的耶路撒冷却是自由的。她就是我们的母亲。</span>
<span className="v" id="v27" data-v="27" data-xref="Isaiah 54:1–5; Psalms 113:9; Ruth 4:14–16"> 正如经文所说：“如果你们没有孩子、没有生育过，你们应该感到欢喜！如果你们未曾分娩，那么欢呼吧，因为弃妇的孩子比有丈夫的女人还多！”<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="引自《以赛亚书》54:1。">h</a></sup></span>
<span className="v" id="v28" data-v="28" data-xref="加拉太书 4:23; 罗马书 9:8–9; 罗马书 4:13–18"> 现在我的朋友们，我们就像以撒一样，是承诺生下的孩子。</span>
<span className="v" id="v29" data-v="29" data-xref="Genesis 21:9; 罗马书 8:13; 加拉太书 5:11"> 然而，按照人的意愿出生的人，会迫害通过灵出生的人，今天也是如此。</span>
<span className="v" id="v30" data-v="30" data-xref="Genesis 21:10–12; 约翰福音 8:35; 罗马书 8:15–17"> 经文怎么说的？“把婢女和她的儿子打发走，因为婢女的儿子不能和自由妇人的儿子一起成为继承人。”<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="引自《创世纪》21:10。">i</a></sup></span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 8:36; 约翰福音 1:12–13; 加拉太书 5:1"> 因此，我的朋友们，我们不是婢女的孩子，而是自由女性的孩子。</span>

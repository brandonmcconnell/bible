<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 1:11–12; 哥林多前书 1:1; 罗马书 1:1"> 本信函来自保罗，我的使徒身份并非由人类组织或人类权力所指认<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“不是由人或通过人。”">a</a></sup>，恰恰相反，我是由耶稣基督和让耶稣复活的天父上帝所指认。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 16:1; 腓立比书 4:21; 使徒行传 16:5–6"> 这封写给加拉太众教会的信函，由与我同在的所有兄弟姐妹共同写就。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰二书 1:3; 哥林多后书 13:14; 罗马书 1:7–15"> 愿上帝天父以及主耶稣基督的恩惠和平安与你们同在。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 20:28; 罗马书 4:25; 加拉太书 2:20"> 基督遵循我们天父上帝的旨意，因我们的罪而献出自己的生命，让我们脱离现在这个邪恶的时代。</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 11:36; 犹大书 1:25; Psalms 72:19"> 愿荣耀归给他，直到永远。阿门。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 11:4; 加拉太书 5:7–8; Isaiah 29:13"> 让我震惊的是，你们借由耶稣恩惠的召唤信了上帝，却又如此快速将其放弃，转向其他福音，</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 15:24; 罗马书 16:17–18; 加拉太书 5:10"> 而那根本不是福音，只是其他人用于迷惑你们，想要曲解基督的福音。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 11:13–14; 加拉太书 1:9; 启示录 22:18–19"> 但无论是谁，即使是我们自己或天堂的天使，如果所传“福音”并非我们之前传给你们的福音<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="显然，保罗认为这根本就不是福音，所以用双引号“福音”表示讽刺。">b</a></sup>，就该受到谴责。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 16:17; Proverbs 30:6; Deuteronomy 4:2"> 我们想再重复这一点：如果有人所传并非我们之前传给你们的福音<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="又见1:8。">c</a></sup>，就该受到谴责。</span>
<span className="v" id="v10" data-v="10" data-xref="帖撒罗尼迦前书 2:4; 使徒行传 5:29; 以弗所书 6:6"> 你们认为我需要谁的认可？来自人或是来自上帝？你认为我试图取悦人？如果我想要取悦人，就不是基督的仆人。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太书 1:1; 哥林多前书 2:9–10; 哥林多前书 11:23"> 朋友们，让我明确地告诉你们，我所传的福音并非来自任何人类。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 1:16; 哥林多前书 2:10; 加拉太书 1:1"> 因为我并非从人那里获得这福音，也并非由人教导，而是通过耶稣基督的启示获取。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 8:3; 哥林多前书 15:9; 使徒行传 22:3–5"> 你们都听过，我过去曾是犹太宗教的追随者，听说过我如何疯狂迫害上帝的教会，残忍地想要破坏它。</span>
<span className="v" id="v14" data-v="14" data-xref="歌罗西书 2:8; 使徒行传 26:5; 腓立比书 3:4–6"> 我在犹太宗教中的经历超过了许多同代人，因为我对祖先的传统格外热情。</span>
<span className="v" id="v15" data-v="15" data-xref="Jeremiah 1:5; Isaiah 49:5; Isaiah 49:1"> 但当上帝在我出生时就让我与他人有所区别，他通过其恩典呼唤我，并很高兴地</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 16:17; 以弗所书 3:5–10; 以弗所书 6:12"> 将他的儿子向我显现，让我向所有国家宣扬福音，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或“异族人。”">d</a></sup>我便没有与任何人商量。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 9:20–25; 哥林多后书 11:32–33; 加拉太书 1:18"> 我没有到耶路撒冷与先于我成为使徒的人谈话，而是去了阿拉伯，然后再回到大马士革。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 9:22–23; 使徒行传 9:26–29; 使徒行传 22:17–18"> 三年后我才上耶路撒冷去见彼得，和他住了两个星期。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 13:55; 马可福音 6:3; 马太福音 12:46"> 我也没有见其他的使徒，除了主的兄弟雅各。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 9:1; 哥林多后书 11:31; 哥林多后书 11:10–11"> （在上帝面前，我向你们保证所写之事绝非谎言！）</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 15:41; 使徒行传 9:30; 使徒行传 6:9"> 后来我去了叙利亚和基利家。</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒罗尼迦前书 2:14; 罗马书 16:7; 帖撒罗尼迦后书 1:1"> 尽管如此，犹太教会中的众人并未见过我的面。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 15:8–10; 使徒行传 9:13; 提摩太前书 1:13–16"> 他们只听人说“那个从前迫害我们的人，现在开始传播他曾经想要破坏的信仰！”</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 9:8; 使徒行传 11:18; 路加福音 15:10"> 他们因我而颂赞上帝。</span>

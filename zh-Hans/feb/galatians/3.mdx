<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 5:7–8; 哥林多后书 11:3; 加拉太书 1:6"> 加拉太人，你们太愚蠢了！<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这里使用的词通常被翻译为“愚蠢。”但如今它的意思更多的是一种比喻。保罗认为他们没有思考，所以这个词的真正含义是“没有思考。”在第 3 节中再次使用了这个词。">a</a></sup>谁迷惑了你们？耶稣基督死于十字架，这样的事实已经清楚呈现给你们，只为让你们可以看到！</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 10:16–17; 加拉太书 3:14; 使徒行传 15:8"> 所以告诉我——你们接受灵是通过遵守律法、还是相信你所听到的一切？</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 5:4–8; 加拉太书 4:7–10; 希伯来书 7:16–19"> 你们真的是太愚蠢了！你们已经开始与灵同在<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="意为“你们开始了基督徒的生活。”">b</a></sup>。你们真的认为，现在可以通过人类的努力，让自己变得完美吗？<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或“以人类方式。”">c</a></sup></span>
<span className="v" id="v4" data-v="4" data-xref="约翰二书 1:8; 哥林多前书 15:2; 希伯来书 10:32–39"> 你们受了这么多的苦，都是徒劳的吗？（这样做并非没有目的，是不是？）</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 3:2; 使徒行传 14:9–10; 使徒行传 19:11–12"> 让我问你们个问题：上帝<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原意为“那一个。”">d</a></sup>赐给你们灵，在你们中显现那么多神迹，是因为你遵守律法？还是因为你们相信所听到的？</span>
<span className="v" id="v6" data-v="6" data-xref="Genesis 15:6; 罗马书 4:21–22; 雅各书 2:23"> 就像“相信上帝，被视为正义”的亚伯拉罕。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="引自《创世纪》15:6。">e</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 9:7–8; 加拉太书 3:9; 加拉太书 3:26–29"> 所以你们应该知道，那些相信上帝之人，就是亚伯拉罕的子孙。</span>
<span className="v" id="v8" data-v="8" data-xref="Genesis 12:3; Genesis 22:18; Genesis 28:14"> 经文中预言到，上帝会让那些信他的异族人成为正直善良之人。已经提前通过这句话向亚伯拉罕展示福音：“所有国家都因你获得祝福。”</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 4:16; 加拉太书 3:29; 罗马书 4:24"> 因此，信任上帝之人与信任上帝的亚伯拉罕一样获得祝福。</span>
<span className="v" id="v10" data-v="10" data-xref="Deuteronomy 27:26; 罗马书 8:7; 罗马书 3:19–20"> 所有依靠遵循律法<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="作为救赎的手段。">f</a></sup>之人都受到了咒诅，因为正如圣经所说：“凡不认真遵循律法书所言之人，都会受咒诅。”</span>
<span className="v" id="v11" data-v="11" data-xref="Habakkuk 2:4; 罗马书 1:17; 希伯来书 10:38"> 很显然，没有人会因试图遵守律法而被上帝视为正义，因为“那些正义之人将因信任上帝而活。”<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="引自《哈巴谷书》2:4。">g</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="Leviticus 18:5; 罗马书 10:5–6; Nehemiah 9:29"> 遵守律法与信上帝没有关系。经文只是说：“遵守律法所要求的一切，你就会活着。”<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="引自《利未记》18:5。">h</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="彼得前书 2:24; Deuteronomy 21:23; 希伯来书 9:12"> 为了拯救我们托利律法的诅咒，基督成为了我们的诅咒。<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="“成为对我们的诅咒”：意味着体验罪恶的后果。这是上帝强加的诅咒的想法在这里不是这个意思。罪本身带来了诅咒（见《罗马书》6:23）。">i</a></sup>正如经文所说，“凡悬挂在树上的，都会受咒诅”<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="引自《申命记》21:23。">j</a></sup>，</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 3:28–29; 哥林多前书 12:13; Ezekiel 36:26–27"> 这样做的目的，是为了通过基督耶稣将亚伯拉罕的祝福传给异族人，我们也可以通过信任上帝而获得圣灵的承诺。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 9:17; 罗马书 6:19; 罗马书 3:5"> 兄弟姐妹们，这里有个日常的例子。如果一个合约已经起草、同意、签署和盖章，任何人都不能忽视它或在里面补充内容。</span>
<span className="v" id="v16" data-v="16" data-xref="Genesis 17:7–8; 罗马书 4:13; 路加福音 1:55"> 现在承诺已赐给亚伯拉罕和他的儿子。<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="原意为“种子。”参见《创世记》12:7和《创世记》13:15。">k</a></sup>这里的“儿子”并非多人，而是一个人。“你的儿子”就是在说基督。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 11:39–40; Genesis 15:13; 罗马书 4:13–14"> 让我解释一下。上帝在订立之前的合约<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="或“盟约。”">l</a></sup>后四百三十年，颁布了律法，但这并未取消上帝的合约，承诺也没有被打破。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 6:12–15; 加拉太书 2:21; 罗马书 4:13–16"> 如果这样的继承来自遵守律法，就不会再来自上帝的承诺。但上帝通过承诺，将它恩赐给亚伯拉罕。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 7:53; 罗马书 7:7–13; 希伯来书 2:2"> 那么，律法的重点是什么？它的存在是为了表明什么是不法行为，直到承诺的儿子到来。律法是天使通过一位中间人传递而来。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太前书 2:5; Deuteronomy 6:4; Job 9:33"> 但如果只有一个人参与，就不需要中间人。上帝就是这个人！<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="这里的意思是，旧约律法的传递需要一个中间人（摩西）。但在承诺方面，这里直接指的是亚伯拉罕。根据保罗在这里所陈述的观点，这个承诺直接通过耶稣基督实现。通过这种方式，保罗认为承诺和兑现承诺比律法更重要。">m</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="加拉太书 2:21; 罗马书 9:31; 罗马书 3:20–22"> 那么律法是否违背了上帝的承诺？当然不是！因为如果有哪个律法可以赋予生命，我们就可以通过遵守它而成为正义。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 11:32; 希伯来书 9:15; 加拉太书 3:23"> 但经文告诉我们，我们都是罪的囚徒。我们能接受上帝承诺的唯一方法，就是相信耶稣基督。</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 5:18; 加拉太书 3:24–25; 加拉太书 3:19"> 在我们相信耶稣之前，一直都受到律法的监管，直到这种信任的方式得以显现。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 10:4; 使徒行传 13:38–39; 罗马书 7:24–25"> 在基督来之前，律法是我们的​监护人，让我们可以因信任基督而成为正义。</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 6:14; 罗马书 7:4; 希伯来书 10:15–18"> 但如今我们已经有了信任耶稣的方式，就不再需要这样的监护了。</span>
<span className="v" id="v26" data-v="26" data-xref="以弗所书 1:5; 哥林多后书 6:18; 约翰福音 1:12–13"> 因你们相信基督耶稣，你们都是上帝的孩子。</span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 13:14; 哥林多前书 12:13; 罗马书 6:3–4"> 你们因受洗而归入基督，就如同穿了一件代表基督的服装。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 12:12–13; 歌罗西书 3:11; 罗马书 3:29–30"> 不再有犹太人或希腊人、奴隶或自由人、男人或女人——你们对于基督耶稣而言都是相同的。</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所书 3:6; 罗马书 9:7–8; 加拉太书 3:7"> 如果你属于基督，就是亚伯拉罕的孩子，就是承诺的继承人！</span>
</div>

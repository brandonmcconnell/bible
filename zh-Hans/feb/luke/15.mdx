<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太前书 1:15; 马太福音 9:10–13; 路加福音 5:29–32"> 很多税吏和其他“罪人”经常来到耶稣那里，听他讲道。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 9:11; 路加福音 19:7; 路加福音 7:39"> 于是法利赛人和宗教老师抱怨到：“这个人欢迎罪人，还和他们一起吃饭。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3"> 耶稣就对他们讲了一个故事，说：</span>
<span className="v" id="v4" data-v="4" data-xref="Ezekiel 34:16; Ezekiel 34:11–12; 马太福音 18:12–14"> “如果你有一百只羊，失去一只，是不是会把剩下的九十九只留在开阔牧场，然后去寻找那丢失的羊，直到找到为止？</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 12:2; 路加福音 19:9; Isaiah 46:3–4"> 如果你找着了，就会高兴地把羊扛在肩上，</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 15:10; 路加福音 15:24; 彼得前书 2:25"> 回到家后招呼朋友和邻居来，对他们说：‘来和我一同庆祝吧，因为我找到了丢失的羊！’</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 5:32; 路加福音 15:10; 路加福音 15:32"> 告诉你们，一个罪人若能悔改，天堂就会获得更多欢乐，甚至超过九十九个不用悔改的良善之人。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 19:10; Ezekiel 34:12; 约翰福音 10:16"> 假设一个女人有十枚银币<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“古希腊货币。”">a</a></sup>，如果丢了一枚，是不是要点上灯，在整个屋子里细细寻找，直到找到？</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 15:6–7"> 当她找到那枚银币，就会叫来亲朋好友，对他们说：‘来和我一同庆祝吧，因为我找到了丢失的银币！’</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 15:7; 哥林多后书 7:10; Ezekiel 33:11"> 我告诉你们，一个罪人若能悔改，上帝的天使也会感到欢乐。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马太福音 21:23–31"> 耶稣解释道：“从前有个人有两个儿子。</span>
<span className="v" id="v12" data-v="12" data-xref="Deuteronomy 21:16–17; 马可福音 12:44; 路加福音 15:30"> 小儿子对父亲说：‘爸爸，请把我应得的家产分给我。’于是父亲就把财产分给兄弟二人。</span>
<span className="v" id="v13" data-v="13" data-xref="Proverbs 29:3; Jeremiah 2:5; Proverbs 21:17"> 几天后，小儿子带上所有的家当去了远方，在那里过着放荡的生活，奢侈浪费。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="2 Chronicles 33:11; Amos 8:9–12; Hosea 2:9–14"> 他花光了所有钱财，又恰逢当地遇上严重饥荒，他穷得肚子都吃不饱。</span>
<span className="v" id="v15" data-v="15" data-xref="提多书 3:3; 提摩太后书 2:25–26; Isaiah 1:5"> 于是他在当地一个农户那里找差事做。那人打发他到田里去放猪，</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 6:19–21; Lamentations 4:5; Hosea 12:1"> 他太饿了，甚至愿意吃猪食，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“猪吃的豆荚。”">b</a></sup>但即使这样也没有人愿意给他食物。</span>
<span className="v" id="v17" data-v="17" data-xref="Ezekiel 18:28; 以弗所书 2:4–5; 路加福音 15:18–19"> 他这时才幡然醒悟，于是对自己说：‘我父亲所有的工人都有丰盛的食物可以享用，为什么我却要在这里饿死？</span>
<span className="v" id="v18" data-v="18" data-xref="Lamentations 3:40; 约翰一书 1:8–10; 路加福音 15:21"> 我要回家，到我父亲那里去！对他说：父亲，我的罪违背了天堂，也违背了你，</span>
<span className="v" id="v19" data-v="19" data-xref="Job 42:6; 路加福音 5:8; Psalms 84:10"> 我不配再做你的儿子，请向对待雇工那样对待我吧。’</span>
<span className="v" id="v20" data-v="20" data-xref="Psalms 103:10–13; Psalms 86:5; Psalms 86:15"> 于是他动身回家去找他的父亲。<br />当他父亲看到他的身影，尽管还在远处，便动了恻隐之心，跑过去拥抱他，亲吻他。</span>
<span className="v" id="v21" data-v="21" data-xref="Psalms 51:4; 路加福音 15:18–19; Jeremiah 3:13"> 儿子说：‘父亲，我违背了天堂也违背了你，不配再做你的儿子。’</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="Genesis 41:42; Esther 8:2; 启示录 6:11"> 但父亲却吩咐仆人说：‘快把那最好的长袍拿来给他穿，给他戴上戒指，穿上鞋。</span>
<span className="v" id="v23" data-v="23" data-xref="Isaiah 25:6; 马太福音 22:2–14; Psalms 63:5"> 把我们养肥的牛犊宰了，我们要大吃一顿，</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所书 2:5; Ezekiel 34:16; 路加福音 19:10"> 因为这可是我死而复活、失而复得的儿子。’于是他们开始庆祝起来。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="Psalms 150:4; Jeremiah 31:4; 路加福音 15:11–12"> 这时候大儿子正在田里干活。他朝着家的方向走去，听见音乐和跳舞的声音，</span>
<span className="v" id="v26" data-v="26"> 于是就找来一个仆人，询问发生了什么。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行传 9:17; 腓利门书 1:16; 使徒行传 22:13"> 仆人说：‘你弟弟回来了，你父亲因为他平安归来，就宰了那头肥牛犊。’</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="Jonah 4:9; 1 Samuel 18:8; Jonah 4:1–4"> 大儿子很生气，不肯走进屋子里，于是父亲出来劝他。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 18:11–12; Zechariah 7:3; Isaiah 65:5"> 他对父亲说：‘你看，我照顾你这么多年，从来没有违背过你的命令，但你从未给我任何羊羔，让我可以和朋友们聚会。</span>
<span className="v" id="v30" data-v="30" data-xref="Proverbs 29:3; 路加福音 15:12–13; 路加福音 15:32"> 但你这个儿子，把你的钱都浪费在妓女身上，他一回来，你反倒为他宰杀肥牛犊！’</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马可福音 7:27–28; 罗马书 9:4; 罗马书 11:1"> 父亲对他说：‘孩子，你总是跟我在一起，我的一切都是你的。</span>
<span className="v" id="v32" data-v="32" data-xref="以弗所书 2:1–10; 路加福音 15:24; Isaiah 35:10"> 但你这个弟弟是死而复活、失而复得，所以我们应该高兴，应该庆祝！’”</span>
</div>
</div>

</div>

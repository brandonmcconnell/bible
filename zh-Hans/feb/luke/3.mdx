<span className="v" id="v1" data-v="1" data-xref="路加福音 23:24; Genesis 49:10; 路加福音 9:7"> 现在是提庇留国王已执政的第十五年，本丢·彼拉多担任犹太总督，希律成为加利利的君王<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“小郡主。”在其他的版本中，在这句话中也会使用“君主”一词。">a</a></sup>，他的兄弟腓力担任土利亚和特拉可尼地区的君王，吕撒尼亚则是亚比利尼的君王。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 4:6; 约翰福音 18:24; 路加福音 1:80"> 亚那和该亚法担任大祭司。撒迦利亚的儿子约翰在这段时间仍生活在荒野中，由于听到了上帝的讯息，</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:77; 马太福音 3:5–6; 使徒行传 13:24"> 他跑遍了整个约旦地区，向所有人宣告：他们需要进行洗礼，证明他们已经悔改，他们的罪才能被宽恕。</span>
<span className="v" id="v4" data-v="4" data-xref="Isaiah 40:3–5; 约翰福音 1:23; 路加福音 1:76–79"> 正如以赛亚先知所写：“在荒野中有一个声音在呼喊：‘预备主的道，修直他的路！</span>
<span className="v" id="v5" data-v="5" data-xref="Isaiah 40:4; Isaiah 42:16; Isaiah 45:2"> 所有山谷都将填满，所有山峦丘陵都将成为平地！弯曲之路变得笔直，坑洼之地恢复平坦！</span>
<span className="v" id="v6" data-v="6" data-xref="Isaiah 52:10; Isaiah 40:5; Psalms 98:2–3"> 所有人都将见到上帝的救赎。’”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引自《以赛亚书》40:3-5。">b</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 23:33; 马太福音 12:34; 帖撒罗尼迦前书 1:10"> 面对前来接受施洗的民众，约翰问到：“你们是毒蛇之子，谁允许你们逃离即将到来的审判？</span>
<span className="v" id="v8" data-v="8" data-xref="Ezekiel 18:27–31; 使徒行传 26:20; Isaiah 1:16–18"> 你们要拿出行动，证明真心悔改。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“结出可以进行忏悔的果子。”">c</a></sup>不要心中暗自产生傲慢的想法：‘我们是亚伯拉罕的后代。’告诉你们，上帝用这些石头就可以创造亚伯拉罕的后裔。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 7:19; 约翰福音 15:6; 路加福音 13:9"> 砍下树根的斧子已经准备好，所有结不出好果子的树，都会被砍倒丢入火中。”</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 2:37; 路加福音 3:14; 使徒行传 16:30"> 民众问他：“那么我们该做什么呢？”</span>
<span className="v" id="v11" data-v="11" data-xref="Isaiah 58:7–11; 约翰一书 3:17; 提摩太前书 6:18"> 他回答：“如果你有两件衣服，就要分给没有衣服之人。如果你有食物，就要分给没有食物之人。”</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 7:29; 路加福音 15:1–2; 路加福音 18:13"> 有税吏前来受洗，问他：“老师，我们该做些什么？”</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 19:8; 以弗所书 4:28; 哥林多前书 6:10"> 他说：“不可收取超过规定的税款。”</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 13:5–6; Exodus 20:16; Exodus 23:1"> 士兵也问他：“我们呢，我们又该怎么做？”他回答：“不要恐吓，不要敲诈，不要做出不实指控，要对自己的酬劳感到满意。”</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 10:24; 约翰福音 3:28–29; 约翰福音 1:19–28"> 众人充满期盼地等待着，心里暗自猜测，约翰会不会就是基督。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 3:11; 使徒行传 1:5; 使徒行传 11:15–16"> 约翰回答了众人的问题。他解释道：“是的，我是用水为你们施洗。但在我之后，还会出现一位能力比我更强大之人，我甚至连给他提鞋的资格都没有，他将用圣灵和火为你们施洗。</span>
<span className="v" id="v17" data-v="17" data-xref="Jeremiah 15:7; 马太福音 13:30; Micah 4:12"> 他手里拿着谷叉，准备把打谷场的麦子和谷壳分开。然后把麦子放入他的谷仓，再用不灭之火把谷壳烧尽。”</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 3:29–36; 约翰福音 1:34; 约翰福音 1:29"> 他在向众人传播福音之时，还提出了很多这样的警告。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 3:1; 马太福音 11:2; 马可福音 6:17–18"> 君王希律因为娶了弟媳希罗底，加之曾做过的其他恶行，因此受到了约翰的谴责。</span>
<span className="v" id="v20" data-v="20" data-xref="2 Chronicles 24:17–22; 约翰福音 3:24; 帖撒罗尼迦前书 2:15–16"> 希律将这些所谓罪行累计起来，将约翰关进了监牢。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 1:32–34; 马太福音 3:13–17; 约翰福音 12:27–28"> 但在此前，众人已受洗，耶稣也受了洗。耶稣在祷告的时候，天空忽然打开，</span>
<span className="v" id="v22" data-v="22" data-xref="Psalms 2:7; 彼得后书 1:17–18; 约翰福音 1:32"> 他看见圣灵如鸽子般降落在他身上。有声音从天上来，说：“这是我所爱之子，他让我感到喜悦。”</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 4:22; 马太福音 13:55; Numbers 4:3"> 耶稣在 30 岁左右开始其服事，人们都知道他是约瑟之子，约瑟是希里之子，</span>
<span className="v" id="v24" data-v="24"> 他的家谱依次往上推，父辈分别为玛塔、利未、麦基、雅拿、约瑟、</span>
<span className="v" id="v25" data-v="25"> 玛他提亚、亚摩斯、拿鸿、以斯利、拿该、</span>
<span className="v" id="v26" data-v="26"> 玛押、玛他提亚、西美、约瑟、约大、</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 1:12"> 约哈难、利撒、所罗巴伯、撒拉铁、尼利、</span>
<span className="v" id="v28" data-v="28"> 麦基、亚底、哥桑、以摩当、珥、</span>
<span className="v" id="v29" data-v="29"> 耶书、以利以谢、约令、玛塔、利未、</span>
<span className="v" id="v30" data-v="30"> 西缅、犹大、约瑟、约南、以利亚敬、</span>
<span className="v" id="v31" data-v="31" data-xref="1 Chronicles 3:5; 2 Samuel 5:14; Zechariah 12:12"> 米利亚、买拿、马达他、拿单、大卫、</span>
<span className="v" id="v32" data-v="32" data-xref="Ruth 4:18–22; 马太福音 1:3–6; Isaiah 11:1–2"> 耶西、俄备得、波阿斯、撒门、拿顺、</span>
<span className="v" id="v33" data-v="33" data-xref="Ruth 4:19–20; Genesis 49:8; Genesis 38:29"> 亚米拿达、亚兰、希斯仑、法勒斯、犹大、</span>
<span className="v" id="v34" data-v="34" data-xref="Genesis 21:3; Joshua 24:2; 1 Chronicles 1:24–28"> 雅各、以撒、亚伯拉罕、他拉、拿鹤、</span>
<span className="v" id="v35" data-v="35" data-xref="Genesis 11:12–21; Genesis 10:24–25"> 西鹿、拉吴、法勒、希伯、沙拉、</span>
<span className="v" id="v36" data-v="36" data-xref="Genesis 5:28–32; Genesis 10:21–22; Genesis 9:1"> 该南、亚法撒、闪、挪亚、拉麦、</span>
<span className="v" id="v37" data-v="37" data-xref="1 Chronicles 1:1–3; Genesis 5:6–28"> 玛土撒拉、以诺、雅列、玛勒列、该南、</span>
<span className="v" id="v38" data-v="38" data-xref="Genesis 2:7; Isaiah 64:8; 哥林多前书 15:45"> 以挪士、塞特以及上帝之子亚当。</span>

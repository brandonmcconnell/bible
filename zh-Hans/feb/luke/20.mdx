<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 21:23–27; 路加福音 19:47–48; 使徒行传 6:12"> 有一天，耶稣在殿里教导众人，告诉他们好消息。祭司长、宗教老师和长老走上前来，</span>
<span className="v" id="v2" data-v="2" data-xref="Exodus 2:14; 马可福音 11:28–33; 约翰福音 2:18"> 他们对他说：“告诉我们，你凭着什么权力做这些事？谁给你的这权力？”</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 15:2–3; 路加福音 22:68; 歌罗西书 4:6"> 耶稣回答：“我也要问你们一个问题，告诉我，</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 15:18; 马太福音 11:7–19; 马太福音 17:11–12"> 约翰的洗礼是从天上来，还是从人间来？”</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 1:34; 约翰福音 1:15–18; 约翰福音 1:30"> 这些人开始议论：“如果我们说‘从天上来’，他就会说‘那你们为什么不信他？’</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 21:26; 马太福音 11:9; 约翰福音 10:41"> 如果我们说：‘从人间来’，众人会用石头打我们，因为他们认定约翰是先知。”</span>
<span className="v" id="v7" data-v="7" data-xref="Isaiah 29:14; 彼得后书 3:3; Isaiah 41:28"> 于是他们回答耶稣：“我们不知道从哪里来。”</span>
<span className="v" id="v8" data-v="8" data-xref="Proverbs 26:4–5; 马太福音 21:27; 马可福音 11:33"> 耶稣说：“那我也不告诉你们，是谁给我权力做这一切。”</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 21:33–46; 马可福音 12:1–12; Isaiah 5:1–7"> 随后耶稣向众人讲了一个故事：“一个人有一个葡萄园，由于住在距离这里很远的另外一个乡村，他便将葡萄园租给了农户。</span>
<span className="v" id="v10" data-v="10" data-xref="2 Chronicles 36:15–16; Nehemiah 9:26; 马太福音 21:34–36"> 到了收获的季节，园主派一个仆人到农户那里，收取葡萄园应该上交的水果。但农户却打了那个仆人，让他空手回去。</span>
<span className="v" id="v11" data-v="11" data-xref="Hosea 10:1; 希伯来书 11:36–37; 帖撒罗尼迦前书 2:2"> 园主又派另一个仆人去，同样受到殴打和侮辱，空手而归。</span>
<span className="v" id="v12" data-v="12"> 园主又派了第三人去，农户依旧把他打伤，然后把他赶走。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 3:17; 约翰福音 3:16–17; Jeremiah 36:7"> 园主暗自想：‘该怎么办？我知道了，派我的爱子去，也许这一次他们会尊敬他。’</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 8:17; 希伯来书 1:2; 使徒行传 2:23"> 农户一看见园主的儿子，立刻交头接耳说：‘这人会继承产业，我们杀了他，这产业就成为我们的了。’</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 13:12; 马可福音 12:6–9; 马太福音 21:37–40"> 于是他们把园主之子推出葡萄园外杀了。那么主人会怎样对付他们呢？</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:27; 使徒行传 13:46; 马太福音 21:41"> 他会过来杀掉这些农户，把葡萄园租给别人。” 众人听了这个故事，就说：“希望这样的事情不要发生！”</span>
<span className="v" id="v17" data-v="17" data-xref="Psalms 118:22; Isaiah 28:16; 使徒行传 4:11"> 但耶稣看着他们说：“那么经文中说：‘建筑工人弃用的石头，现在成了主要基石。’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《诗篇》118:22。">a</a></sup>这是什么意思呢？</span>
<span className="v" id="v18" data-v="18" data-xref="Isaiah 8:14–15; Zechariah 12:3; Daniel 2:44–45"> 任何人在那石头上摔倒，都会粉身碎骨，那石头落在任何人身上，都会砸着他们。”</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 19:47–48; 路加福音 20:14; 马太福音 21:45–46"> 宗教老师和祭司长知道这比喻针对他们，当时就想把耶稣抓起来，可是又害怕民众的反应。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 11:54; 马太福音 22:15–22; 马太福音 27:2"> 他们找了个机会，派几名奸细假装虔诚信徒去找耶稣，想找到耶稣说话的把柄，然后把他交给总督裁决。</span>
<span className="v" id="v21" data-v="21" data-xref="帖撒罗尼迦前书 2:4–5; 马太福音 26:49–50; 马太福音 22:16"> 奸细问耶稣：“老师，我们知道，你所说所教都是正道，你绝不会因其他人的意见而动摇，你真的是在将上帝之道传授众人。</span>
<span className="v" id="v22" data-v="22" data-xref="Nehemiah 9:37; 马可福音 12:14–17; 使徒行传 5:37"> 那么，我们是否应该向凯撒纳税？”</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 22:18; 哥林多前书 3:19; 路加福音 5:22"> 耶稣看透了他们的诡计，于是说：</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 18:28; 使徒行传 11:28; 使徒行传 26:32"> “给我一个银币，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="耶稣专指的是当时的罗马银币。">b</a></sup>上面是谁的形象？”他们回答：“凯撒。”</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 13:6–7; 马可福音 12:17; 彼得前书 2:13–17"> 耶稣说：“那么，是凯撒的就应属于凯撒，是上帝的就应当属于上帝。”</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 20:20; Proverbs 26:4–5; 提多书 1:10"> 耶稣向众人所说的话，让他们无法抓住把柄，这番话也让他们很震惊，于是就沉默了。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 4:1–2; 哥林多前书 15:12; 马可福音 12:18–27"> 几个撒都该人来到耶稣这里，他们从来都不相信人死会复活。他们问到，</span>
<span className="v" id="v28" data-v="28" data-xref="Deuteronomy 25:5–10; Genesis 38:8; Genesis 38:11"> “老师，摩西在律法中写道：‘如果一个男人娶了妻子，但未留下一儿半女就死了，他弟弟就应当娶嫂子，为哥哥留后。’<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《申命记》25:5。">c</a></sup></span>
<span className="v" id="v29" data-v="29" data-xref="Leviticus 20:20; Jeremiah 22:30"> 从前有兄弟七人，老大娶了妻子后死了，没有留下后代，</span>
<span className="v" id="v30" data-v="30"> 随后老二,</span>
<span className="v" id="v31" data-v="31"> 老三一直到老七都娶了她，但都没有留下孩子就死了。</span>
<span className="v" id="v32" data-v="32" data-xref="Ecclesiastes 1:4; Ecclesiastes 9:5; 希伯来书 9:27"> 最终那女人也死了。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 22:24–28; 马可福音 12:19–23"> 那么，这女人复活的时候，要做哪个兄弟的妻子呢？因为七个人都娶过她。”</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 16:8; 路加福音 17:27; 希伯来书 13:4"> 耶稣说：“只有在这里的人才嫁娶。</span>
<span className="v" id="v35" data-v="35" data-xref="帖撒罗尼迦后书 1:5; 约翰福音 5:29; Daniel 12:2–3"> 但对于那些有资格进入新世界的人，那些死而复生之人，不娶也不嫁。</span>
<span className="v" id="v36" data-v="36" data-xref="启示录 21:4; 腓立比书 3:21; 马太福音 22:30"> 他们和天使一样不会死亡，因为他们是复活之子，也就是上帝的之子。</span>
<span className="v" id="v37" data-v="37" data-xref="Exodus 3:2–6; 马可福音 12:26–27; 使徒行传 7:30–32"> 至于死人复活的问题，摩西在关于荆棘<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="这里的荆棘在希腊语中会简称为棘。">d</a></sup>的经文中写过，他口中的主是：亚伯拉罕的上帝、以撒的上帝、雅各的上帝。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="引自《出埃及记》3:6。">e</a></sup></span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 11:25–26; 歌罗西书 3:3–4; 罗马书 6:10–11"> 他不是死人的上帝，而是活人的上帝，因为在他那里的人都活着。”</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 23:9; 马可福音 12:28–34; 马太福音 22:34–40"> 几个宗教老师说：“老师，你说得好。”</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 22:46; 马可福音 12:34; Proverbs 26:5"> 然后他们就不敢再提出任何问题了。</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 12:35–37; 马太福音 1:1; 马太福音 22:41–45"> 耶稣问他们：“为什么说基督是大卫的子孙？</span>
<span className="v" id="v42" data-v="42" data-xref="Psalms 110:1; 使徒行传 2:34–35; 希伯来书 1:13"> 因为大卫自己在《诗篇》中说：主对我的主说‘坐在我的右边，</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 19:27; Psalms 110:1; 启示录 19:14–21"> 我会让你的敌人变成你的脚凳。’<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="引自《诗篇》110:1。">f</a></sup></span>
<span className="v" id="v44" data-v="44" data-xref="启示录 22:16; 路加福音 1:31–35; 马太福音 1:23"> 大卫称他为‘主’，所以他怎会是大卫的子孙呢？”</span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 15:10; 马可福音 12:38–39; 马可福音 8:34"> 众人聚精会神地听着，耶稣对门徒说：</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 11:43; 马可福音 12:38–39; 路加福音 14:7"> “你们要小心宗教老师，他们喜欢穿长袍走来走去，喜欢人们在集市中向他们恭敬问安，喜欢坐会堂里的高位、宴席上的首座。</span>
<span className="v" id="v47" data-v="47" data-xref="马可福音 12:40; 雅各书 3:1; 提多书 1:16"> 他们骗光寡妇的财产，<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="原意为“吞噬寡妇的房产。”">g</a></sup>通过冗长的祈祷伪装自己。这些人在审判中必受到严重的责罚。”</span>

<span className="v" id="v1" data-v="1" data-xref="Deuteronomy 23:25; 马可福音 2:23–28; 马太福音 12:1–8"> 在一个安息日，耶稣和门徒经过一片麦田，他的门徒摘下麦穗，用手搓着吃下。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="把谷壳从谷粒上搓下来。法利赛人经常也这么做，这种工作叫做打谷。">a</a></sup></span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 12:2; 约翰福音 5:16; 约翰福音 5:9–11"> 有几个法利赛人质问耶稣：“你们怎么能这样呢？安息日不允许这样做。”</span>
<span className="v" id="v3" data-v="3" data-xref="1 Samuel 21:3–6; 马可福音 2:25–26; 马太福音 12:3–5"> 耶稣答道：“大卫和随从在饥饿时所做的事情，你没有读过吗？</span>
<span className="v" id="v4" data-v="4" data-xref="Leviticus 24:5–9"> 他难道不是走进上帝的圣殿，吃了圣饼，还把它分给他的随从？这饼只有祭司才能吃。”</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 2:27; 启示录 1:10; 马可福音 9:7"> 他又对他们说：“人子是安息日的主。”</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 3:1–6; 马太福音 12:9–14; 路加福音 4:31"> 在另外一个安息日，耶稣走进会堂布道，那里有个人右手有残疾。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 20:20; Psalms 38:12; 路加福音 13:14"> 宗教老师和法利赛人想看看耶稣会不会在安息日治病，希望找到借口控告他。</span>
<span className="v" id="v8" data-v="8" data-xref="Isaiah 42:4; 马太福音 9:4; 路加福音 5:22"> 耶稣知道他们的想法，就对手残疾的人说：“起来吧，站在大家的面前！”那人就起身站在那里。</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 3:4; 马太福音 12:12–13; 路加福音 14:3"> 然后耶稣转身对他们说：“问你们一个问题：在安息日做什么才对？是拯救生命，还是害人性命？”</span>
<span className="v" id="v10" data-v="10" data-xref="Exodus 4:6–7; 马可福音 3:5; 约翰福音 5:8"> 他环视周围众人，然后对那个男人说：“伸出你的手来！”那人把手一伸，手就复原了。</span>
<span className="v" id="v11" data-v="11" data-xref="Psalms 2:1–2; 使徒行传 5:33; Ecclesiastes 9:3"> 但宗教老师和法利赛人却勃然大怒，商量着怎样对付耶稣。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 5:7; 马可福音 6:46; 马可福音 1:35"> 不久之后的一天，耶稣到山上去祷告，他整晚待在那里，向上帝祷告。</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 3:13–19; 马太福音 9:36–4; 启示录 21:14"> 天亮之后，他把跟随他的人叫来，从中挑选了十二人，称他们为十二门徒，他们分别是：</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 1:13; 马太福音 4:21; 马太福音 4:18"> 西门（耶稣又称他为彼得）和他弟弟安得烈，以及雅各、约翰、腓力、巴多罗迈、</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 9:9; 马可福音 3:18; 使徒行传 1:13"> 马太、多马、亚勒腓的儿子雅各、激进派西门、</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 14:22; 约翰福音 6:70–71; 马可福音 3:18"> 雅各的儿子犹大和出卖主的加略人犹大。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 11:21; 马太福音 4:23–25; Psalms 107:17–20"> 耶稣和十二门徒下了山，站在一处平坦的地方，一大群信众和他的门徒都聚在这里，还有很多人从犹太全地、耶路撒冷和推罗以及西顿海边赶来，听耶稣讲道，也希望耶稣把他们的疾病医好。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 17:15; 马太福音 15:22; 使徒行传 5:16"> 那些被恶灵附体之人也痊愈了。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 14:36; 马可福音 3:10; 使徒行传 5:15–16"> 每个人都想方设法触摸他，因为他身上传递出一股力量，可以治愈众人。</span>
<span className="v" id="v20" data-v="20" data-xref="雅各书 2:5; 路加福音 6:20–24; 哥林多后书 8:9"> 耶稣看着门徒，对他们说：</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 6:35; 马太福音 5:6; 雅各书 1:12"> “你们贫穷之人有福了，因为上帝之国是你们的。你们饥饿之人有福了，因为你们会吃饱。你们哀哭之人有福了，因为你们将开怀大笑。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 5:10–12; 马太福音 10:22; 彼得前书 4:12–16"> 如果因为我是人子的缘故，你们被憎恨、排斥、羞辱和诅咒，你们就有福了。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 5:41; 启示录 21:7; 启示录 3:12"> 当那一天到来，欢喜吧，快乐地跳跃吧，因为你们在天堂获得了慷慨的赏赐，别忘了，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="隐喻之意。又见第 26 句。">b</a></sup>他们的祖先就是这样对待先知的。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 6:2; 雅各书 5:1–6; Psalms 49:6–7"> 但你们富有之人有祸了，因为你们已经得了奖励。</span>
<span className="v" id="v25" data-v="25" data-xref="Isaiah 65:13; 雅各书 4:9; Proverbs 14:13"> 你们饱足之人有祸了，因为你们将面临饥饿。你们正在欢笑的人有祸了，因为你们将要痛哭哀嚎。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 15:19; 雅各书 4:4; 马太福音 7:15"> 你们受众人夸赞之人有祸了，别忘了，你们的祖先也是这样夸赞假先知。</span>
<span className="v" id="v27" data-v="27" data-xref="帖撒罗尼迦前书 5:15; 路加福音 6:35; 罗马书 12:17–21"> 但我想告诉那些聆听之人：要爱你们的敌人，善待憎恨你们的人。</span>
<span className="v" id="v28" data-v="28" data-xref="彼得前书 3:9; 哥林多前书 4:12; 罗马书 12:14"> 如果有人咒诅你，要为他们祝福；如果有人凌辱你，要为他们祷告；</span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 10:34; 马太福音 5:39–42; 哥林多后书 11:20"> 有人打你一边的脸，转过另一边脸给他打；有人如果拿你的外衣，连里面的衣服也送给他。</span>
<span className="v" id="v30" data-v="30" data-xref="Deuteronomy 15:7–10; 哥林多后书 9:6–14; 马太福音 6:12"> 别人想要你的东西，就给他；有人拿去你的东西，不必再要回来。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 7:12; 加拉太书 5:14; 马太福音 22:39"> 想要其他人如何对待你们，你们就应当如何对待其他人。</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 5:46–47; 彼得前书 2:19–20"> 如果只爱那些爱你的人，你这样做又有什么不同呢？罪人也爱那些爱他们的人。</span>
<span className="v" id="v33" data-v="33"> 如果只善待那些善待你的人，你这样做又有什么不同呢？罪人也会这样做。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 5:42; 路加福音 14:12–14; 路加福音 6:35"> 如果你借人钱财，又指望别人偿还，你这样做又有什么不同呢？罪人借钱给其他罪人，也会要求如数归还。</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 5:44–45; 约翰福音 13:35; Proverbs 19:17"> 不能这样：要爱你们的敌人，善待他们。借出去的东西不要指望偿还，这样你们才能获得巨大恩赐。你们会成为至高上帝的儿子，因为上帝也会善待不懂得感恩之人和恶人。</span>
<span className="v" id="v36" data-v="36" data-xref="以弗所书 5:1–2; 马太福音 5:48; 彼得前书 1:15–16"> 你们要仁慈，就像你们天父一样仁慈。</span>
<span className="v" id="v37" data-v="37" data-xref="以弗所书 4:32; 雅各书 5:9; 马太福音 7:1–5"> 不可评判他人,<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或“批评。”">c</a></sup>否则你也会被他人评判；不可决定他人的罪，否则你也会被定罪；饶恕他人，就会被人饶恕；</span>
<span className="v" id="v38" data-v="38" data-xref="哥林多后书 9:6–8; Deuteronomy 15:10; 马可福音 4:24"> 要给予，才会有慷慨回报，而且是加倍的回报。在衡量应该给你多少时，会将其压实，以便可以添加更多，能从顶部溢出，倒在你的腿上！因为你付出多少将决定你得到多少。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或“你衡量给予他人的方法，也会用来衡量你的所得。”">d</a></sup></span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 15:14; 提摩太后书 3:13; 提摩太前书 6:3–5"> 耶稣又讲了一个比喻：“盲人怎能给盲人领路呢？两个人不都会掉在坑里吗？</span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 13:16; 马太福音 10:24–25; 约翰福音 15:20"> 信徒的知识怎能多于老师？只有他们学会了所有知识，才能和老师一样。</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 8:7; 雅各书 1:24; 罗马书 2:1"> 为什么你看得见兄弟眼中的灰尘，却看不到自己眼中的木头？</span>
<span className="v" id="v42" data-v="42" data-xref="罗马书 2:21–29; 帖撒罗尼迦前书 2:10–12; Psalms 51:9–13"> 你看不见自己眼中的木头，怎能对你的兄弟说：‘兄弟，让我来把你眼中的灰尘取走’？这是伪君子的行为！要先拿走自己眼中的木头，才能看得清楚，才能取走兄弟眼中的灰尘。</span>
<span className="v" id="v43" data-v="43" data-xref="Jeremiah 2:21; 马太福音 12:33; 马太福音 7:16–20"> 因为好树不能结坏果，坏树不能结好果。</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 12:33; 雅各书 3:12; 加拉太书 5:19–23"> 你可以根据果子识别树木，不能从荆棘上采无花果，也不能从蒺藜中摘葡萄。</span>
<span className="v" id="v45" data-v="45" data-xref="Proverbs 4:23; 马太福音 12:34–37; 以弗所书 4:29"> 良善之人因为心存善念而做善事，邪恶之人因为心存恶念而做坏事。因为心中所念，口中必言。</span>
<span className="v" id="v46" data-v="46" data-xref="加拉太书 6:7; Malachi 1:6; 马太福音 7:21–23"> 为什么你们称我‘主啊！主啊！’却不遵行我的吩咐？</span>
<span className="v" id="v47" data-v="47" data-xref="雅各书 1:22–25; 马太福音 7:24–27; 路加福音 11:28"> 让我举个例子：有一个人来到我面前，他听了我的指引并照做。</span>
<span className="v" id="v48" data-v="48" data-xref="哥林多前书 3:10–15; Psalms 62:2; 马太福音 7:25–26"> 这人就像在建造房屋，深挖地基，把地基建在牢固的岩石上。大水泛滥时，湍流冲刷房屋也不能让它倒塌，因为它建造得很牢固。</span>
<span className="v" id="v49" data-v="49" data-xref="Ezekiel 33:31; 雅各书 1:22–26; 马太福音 23:3"> 但听到我的教导却不遵守，就好比在沙子上建屋，没有根基，急流一冲就会倒塌，彻底毁坏。”</span>

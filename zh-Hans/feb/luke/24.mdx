<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="feb" data-translation-id="cmn_feb" data-translation-label="易读圣经" data-book="LUK" data-book-slug="luke" data-book-name="路加福音" data-chapter="24" data-verses="53">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 20:1–2; 马可福音 16:1–8; 马太福音 28:1–8"> 下一周第一天清晨，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="即周日。">a</a></sup>女人们带着准备好的香料来到耶稣的坟墓。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 16:3–4; 马太福音 27:60–66; 马可福音 15:46–47"> 但发现坟墓口的大石头已经滚到了一边，</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 24:23; 约翰福音 20:6–7; 马太福音 16:5"> 她们走进去，却没有看到主耶稣的身体。</span>
<span className="v" id="v4" data-v="4" data-xref="马可福音 16:5; 约翰福音 20:11–12; 使徒行传 1:10"> 正为此疑惑之际，眼前忽然出现两个人，身穿闪耀发光的衣服，站在她们旁边。</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 16:5–6; 马太福音 28:3–5; 启示录 1:18"> 女人们很害怕，把脸伏在地上。他们对女人说：“你们为什么要在死者中寻找一个还活着的人？</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 17:22–23; 路加福音 9:22; 马可福音 8:31"> 他不在这里，而是已经复活了。你们应当记得他在加利利时说的话，</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 16:21"> 他说：‘人子必将被交到罪人手里，钉在十字架上，在第三日复活。’”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约翰福音 12:16; 约翰福音 14:26; 约翰福音 2:19–22"> 她们想起了耶稣说的话，</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 24:22–24; 马可福音 16:7–8; 马太福音 28:7–8"> 于是就离开坟地，回去把这一切告诉了十一名门徒和其他人。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 27:56; 约翰福音 20:11–18; 路加福音 8:2–3"> 那几名女性为：抹大拉的玛利亚，约亚拿和雅各的母亲玛利亚，以及其他跟随耶稣的妇女。她们把这些事告诉了众门徒。</span>
<span className="v" id="v11" data-v="11" data-xref="Job 9:16; 马可福音 16:11; Genesis 19:14"> 但他们认为这是无稽之谈，根本不相信她们。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 20:3–10"> 但彼得还是跑到坟墓那里查看。他弯腰看进去，只看到了坟墓里的细麻布，于是就回去了，对这一切感到非常惊奇。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 24:18; 马可福音 16:12–13"> 同一天，两名门徒去往一个叫以马午斯的村子，距耶路撒冷大约十一公里。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 6:45; Deuteronomy 6:7; Malachi 3:6"> 他们在路上谈论着所发生的一切。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 18:20; 约翰福音 14:18–19; 路加福音 24:36"> 正在交谈和争辩的时候，耶稣走上前，与他们同行。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 20:14; 约翰福音 21:4; 路加福音 24:31"> 但他们却没有认出他。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 16:20–22; 约翰福音 16:6; Ezekiel 9:4–6"> 耶稣问到：“你们边走边聊什么呢？”他们就站住，面带愁容。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 19:25"> 一个名叫克利奥帕斯的门徒回答：“你造访耶路撒冷吗？关于那里发生的事情，你可能是唯一不知情的人。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马太福音 21:11; 使徒行传 7:22; 约翰福音 4:19"> 耶稣说：“什么事？”他们说：“就是拿撒勒人耶稣的事。他是先知，在上帝和众人面前显示出了伟大的奇迹。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 3:13–15; 使徒行传 4:8–10; 路加福音 23:13"> 我们的祭司长和长官竟把他交了出去，把他判了死罪，钉在十字架上。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:68; 彼得前书 1:18–19; 路加福音 2:38"> 我们一直盼望他就是救赎以色列的那个人。这些事发生到现在已经是第三天了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马可福音 16:9–10; 马太福音 28:7–8; 约翰福音 20:1–2"> 但我们中有几名妇女却有了让我们惊讶的发现。她们凌晨到坟墓那里去，</span>
<span className="v" id="v23" data-v="23"> 却找不到他的身体。她们回来说看见天使显现，天使说他已经复活了。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 24:12; 约翰福音 20:1–10"> 我们又有几个人到坟墓那里去看，与妇女们所说的一样，没有看见他。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马可福音 7:18; 马可福音 9:19; 希伯来书 5:11–12"> 耶稣说：“迟钝的人呐！对于先知所说的一切，你们信得太迟钝了！</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前书 1:11; Isaiah 53:1–12; Zechariah 13:7"> 基督这样受迫害，后来不是迎来了他的荣耀吗？”</span>
<span className="v" id="v27" data-v="27" data-xref="Isaiah 7:14; 路加福音 24:44; Deuteronomy 18:15"> 于是他从摩西和众先知说起，把所有关于他的经文解释了一遍。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马可福音 6:48; Genesis 19:2; Genesis 32:26"> 他们即将抵达要去的那个村子，耶稣表现得好像是要继续前行，</span>
<span className="v" id="v29" data-v="29" data-xref="2 Kings 4:8; 路加福音 14:23; Genesis 19:3"> 两名门徒特别想把他留住：“天晚了，太阳下山了，就住在这里吧。”于是耶稣就与他们住在一起。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="马太福音 14:19; 路加福音 24:35; 马太福音 15:36"> 吃饭的时候，他拿起饼，在感谢上帝后把饼掰开递给那两位门徒，</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 24:16; 约翰福音 8:59; 路加福音 4:30"> 他们的眼睛此刻终于看清了，认出这是耶稣，但耶稣却从他们面前消失不见了。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="路加福音 24:45; Jeremiah 23:29; 希伯来书 4:12"> 他们彼此说：“一路上他和我们说话，给我们解释经文，那时候我们的思想仿佛被火烧灼。”</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 16:13; 约翰福音 20:19–26; 使徒行传 1:14"> 他们立刻站起来返回耶路撒冷。在那里遇见十一个门徒和其他聚在一起的人。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 15:5; 马可福音 16:7; 路加福音 22:54–62"> 这十一位门徒说：“主果然复活了，已经向西门显现。”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马可福音 16:12–13; 使徒行传 2:42; 路加福音 24:30–31"> 两个人就把在路上的事，以及掰开饼时如何认出耶稣的事情，讲述了一遍。</span>
<span className="v" id="v36" data-v="36" data-xref="帖撒罗尼迦后书 3:16; Isaiah 57:18; 马可福音 16:14"> 他们正在交谈之际，耶稣现身站在他们当中，说：“愿你们平安。”</span>
<span className="v" id="v37" data-v="37" data-xref="1 Samuel 28:13; 马太福音 14:26–27; Job 4:14–16"> 他们非常惊怕，以为看见了鬼。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="Jeremiah 4:14; 希伯来书 4:13; Daniel 4:19"> 耶稣问到：“你们为什么惊恐？为什么心有疑惑？</span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 20:27; 约翰一书 1:1; Ecclesiastes 12:7"> 你们看我的手脚，就知道我是谁。摸摸我，你们就会更确认，因为鬼没有骨肉，但你们看，我有。”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40"> 说了这话，耶稣就把手脚给众人看。</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 21:5; Psalms 126:1–2; Genesis 45:26–28"> 众人感到如此狂喜和惊讶，以至于仍然不敢相信这一切。耶稣说：“你们这里有什么食物吗？”</span>
<span className="v" id="v42" data-v="42"> 他们就给了他一片做好的鱼。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行传 10:41"> 他接过来，在他们面前吃了。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="Zechariah 12:10; 路加福音 24:26–27; Zechariah 9:9"> 然后耶稣对他们说：“我还和你们在一起时，就是这样对你们解释的：摩西律法、先知书籍和《诗篇》中记载了关于我的一切，都会成真。”</span>
<span className="v" id="v45" data-v="45" data-xref="使徒行传 16:14; 约翰一书 5:20; Psalms 119:18"> 于是他打开他们的思想，让他们能够理解经书。</span>
<span className="v" id="v46" data-v="46" data-xref="Isaiah 53:2–12; Isaiah 50:6; 路加福音 24:44"> 他告诉他们：“经上记着‘基督将会受害，第三天死而复生。人们要奉他的名，</span>
<span className="v" id="v47" data-v="47" data-xref="使徒行传 5:31; Isaiah 49:6; 使徒行传 2:38"> 宣讲悔改与赦罪之道，从耶路撒冷开始，传遍世界各地。’</span>
<span className="v" id="v48" data-v="48" data-xref="使徒行传 1:8; 使徒行传 2:32; 使徒行传 13:31"> 你们就是这一切的见证。</span>
<span className="v" id="v49" data-v="49" data-xref="使徒行传 1:8; 使徒行传 1:4; Joel 2:28–32"> 现在我要将天父所承诺的赋予你们。但你们需要在城里等候，直到获得来自天堂的力量。”</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="使徒行传 1:12; 马太福音 21:17; 马可福音 11:1"> 然后他带他们走出去，走到伯大尼附近时，抬手祝福众人。</span>
<span className="v" id="v51" data-v="51" data-xref="使徒行传 1:9; 马可福音 16:19; 2 Kings 2:11"> 在祝福的同时离开了他们，被送上天堂。</span>
<span className="v" id="v52" data-v="52" data-xref="马太福音 28:9; 约翰福音 16:22; Psalms 30:11"> 众人开始膜拜他，然后充满喜悦地回到耶路撒冷，</span>
<span className="v" id="v53" data-v="53" data-xref="马可福音 16:20; 使徒行传 2:46–47; 使徒行传 5:41–42"> 此后，他们便始终都在圣殿中称颂上帝。</span>
</div>
</div>

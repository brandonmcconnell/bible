<span className="v" id="v1" data-v="1" data-xref="马可福音 1:16–20; 马太福音 4:18–22; 马可福音 3:9"> 有一天，耶稣站在革尼撒勒湖边，众人簇拥着他，希望聆听上帝之道。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 1:19; 马太福音 4:21"> 耶稣看见两只船停在湖边，渔夫离开船去洗网了。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 4:18; 马太福音 13:1–2; 约翰福音 1:41–42"> 他走上西门的那只船，请他撑船到离岸不远的水面，然后坐下，在船上教导众人。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 21:6; 马太福音 17:27"> 教导结束后，他对西门说：“把船划到水更深的地方，下网打鱼吧！”</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 2:5; 约翰福音 15:14; 路加福音 6:46–48"> 西门说：“老师，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“老师。”这里使用的这个词，与第 8 句中的希腊语并不相同。这个词通常被译为“主人”，但这种称呼方法在现代英语中并不常见。">a</a></sup>我们整夜劳苦工作却一无所获，不过我愿听从你，我会撒网。”</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 15:58; 约翰福音 21:6–11; Ecclesiastes 11:6"> 西门撒网后捞上很多鱼，几乎将网撑裂。</span>
<span className="v" id="v7" data-v="7" data-xref="加拉太书 6:2; 腓立比书 4:3; 使徒行传 11:25"> 于是他叫来另外那只船上的同伴来帮忙，他们捞上来的鱼把两只船装满了，甚至压得船开始下沉。</span>
<span className="v" id="v8" data-v="8" data-xref="Isaiah 6:5; Job 42:5–6; 启示录 1:17"> 西门（彼得）看见这番情景，就跪在耶稣面前说：“主啊，你不能靠近我，因为我是个罪人。”</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 4:32; Psalms 8:8; 马可福音 9:6"> 因为他和身边其他人一样，完全被刚才捕捞上来的鱼数量惊住了。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 4:19; 马太福音 13:47; Ezekiel 47:9–10"> 西庇太的儿子雅各和约翰是西门的打鱼同伴，他们也有同样的感觉。耶稣对西门说：“不要怕！从现在起，你就要成为收获人的渔夫了。”</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 4:20; 路加福音 5:28; 马太福音 19:27"> 这几名渔夫把两只船靠上岸后，便放下一切跟随耶稣。</span>
<span className="v" id="v12" data-v="12" data-xref="Psalms 50:15; 路加福音 17:16; 马太福音 8:2–4"> 有一次，耶稣来到一个城中，一名严重的麻风病人看到他，就伏倒将脸贴在地上，求他说：“主啊！如果你愿意，就治愈我。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这里治愈的原意为“洁净。”当然这个人希望耶稣能够治愈他的麻风病，不过他用“洁净”一词，是因为麻风病让他看起来很脏污。所以，这里的“洁净”不仅是治愈他的病，还要让他被社会所认可。">b</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 9:29–30; 约翰福音 4:50–53; Hosea 14:4"> 耶稣伸手触碰他，说：“我愿意，治愈吧！”于是这个人的麻风病立刻好了。</span>
<span className="v" id="v14" data-v="14" data-xref="Leviticus 14:2–32; 路加福音 17:14; 马可福音 1:44"> 耶稣嘱咐他：“不要告诉其他人，去给祭司看看，然后照着摩西所说的，为你的治愈进行献祭，向大家作证。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="见《利未记》14:1-32。">c</a></sup></span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 15:30–31; 路加福音 12:1; 马可福音 1:45–2"> 但关于耶稣的消息却传得越来越远，大量的民众来到这里聆听耶稣教导，希望他能治愈他们的疾病。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 6:12; 马可福音 1:35–36; 马太福音 14:23"> 但耶稣却经常躲到安静的地方祷告。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 6:19; 路加福音 8:46; 马太福音 11:5"> 有一天，耶稣正在教导众人之时，人群中有法利赛人和宗教老师，他们来自加利利和犹太的乡村以及耶路撒冷。因为主的力量与耶稣同在，所以他可以治愈病患。</span>
<span className="v" id="v18" data-v="18" data-xref="马可福音 2:3–12; 马太福音 9:2–8; 约翰福音 5:5–6"> 几个人用床抬着一个瘫痪之人，想送他到耶稣跟前。</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 2:4; 马太福音 10:27; 马太福音 24:17"> 但因为这里的人实在太多，无法挤进房间，于是他们爬上房顶，在屋瓦中挖了一个洞，将患者和垫子通过洞放了下来，正好落在人群中耶稣的面前。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 14:9; 马太福音 9:2; 马可福音 2:5"> 耶稣看出了他们对他的信任，于是说：“你们的罪被宽恕了。”</span>
<span className="v" id="v21" data-v="21" data-xref="Isaiah 43:25; 马可福音 2:6–7; 路加福音 7:49"> 于是宗教老师和法利赛人开始议论：“这人是谁？竟然会说如此亵渎上帝之语？除了上帝，谁能宽恕罪过？”</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 24:38; Isaiah 66:18; Psalms 139:2"> 耶稣知道他们正在讨论这个问题，于是对他们说：“你们为什么会想到这样的问题？</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 2:9; 马太福音 9:5"> 说‘你的罪已被宽恕’容易，还是说‘站起来走吧’容易？</span>
<span className="v" id="v24" data-v="24" data-xref="启示录 1:13; Isaiah 53:11; 路加福音 8:54"> 我想要向你们证明的是，人子在人间也有宽恕罪过的权力。”然后他对瘫痪之人说：“我现在对你说，站起来，拿着你的垫子回家去吧。”</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 9:24; 路加福音 5:13; Psalms 107:20–22"> 那人立刻在众人面前站起来，拿起刚才躺着的垫子，赞美着上帝离开了。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 9:8; 马太福音 12:23; 路加福音 7:16"> 众人对眼前的一切感到震惊，在倍感敬畏之余也纷纷开始赞美上帝。他们说：“我们今天见证了令人惊讶的事情。”</span>
<span className="v" id="v27" data-v="27" data-xref="马可福音 2:13–22; 马太福音 9:9–17; 约翰福音 1:43"> 稍后，耶稣离开了这个城镇，看见一位名叫利未的税吏坐在交税亭处，于是对他说：“跟随我吧！”</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 5:11; 马太福音 19:22–27; 1 Kings 19:19–21"> 于是 利未站起来放下一切，决定跟随耶稣。</span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 2:15; 路加福音 15:1; 哥林多前书 10:27"> 利未在自己家中大摆宴席，客人中除了很多税吏，还有其他一些人。但法利赛人和宗教老师开始抱怨耶稣的门徒，说：</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 21:28–32; 路加福音 5:17; 马可福音 7:3"> “你们为什么要跟税吏和那些罪人一起吃喝呢？”</span>
<span className="v" id="v31" data-v="31" data-xref="马可福音 2:17; 马太福音 9:12–13; Jeremiah 8:22"> 耶稣回答：“健康之人不需要医生，病患才需要。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 19:10; 路加福音 15:10; 提摩太前书 1:15–16"> 我来这里并非感召正道之人，而是要召唤罪人。”</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 9:14–17; 马可福音 2:18–22; 约翰福音 3:25"> 他们对耶稣说：“约翰的门徒经常禁食和祈祷，法利赛人的门徒也是，但你的门徒却大吃大喝。”</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 3:29; 哥林多后书 11:2; Isaiah 54:5"> 耶稣又问：“男傧相和新郎在一起时，怎么可以让男傧相禁食呢？</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 17:22; 使徒行传 14:23; 使徒行传 3:21"> 时间一到，新郎要离开大家了，那一刻他们就要禁食了。”</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 9:16–17; 马可福音 2:21–22; 哥林多后书 6:16"> 耶稣又讲了一个比喻：“没有人会从新衣服上撕下一块布，补在旧衣服上。如果这样，不但新衣服撕破了，新撕下来的布与旧衣服也不协调。</span>
<span className="v" id="v37" data-v="37" data-xref="Joshua 9:13; Psalms 119:83; Joshua 9:4"> 没有人会把新酒装在旧皮袋中，否则新酒就会把皮袋胀破，不但酒漏掉了，皮袋也损坏了。</span>
<span className="v" id="v38" data-v="38" data-xref="希伯来书 8:8–13; 哥林多后书 5:17; Ezekiel 36:26"> 人们总是把新酒放在新皮袋里。</span>
<span className="v" id="v39" data-v="39" data-xref="希伯来书 11:39; 马可福音 7:7–13; Jeremiah 6:16"> 人们喝了陈酿的酒，就不想喝新酒了，他们会说：‘陈酿的口味就是好。’”</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 4:10; 马太福音 25:14–30; 雅各书 4:3"> 耶稣向门徒讲了一个故事：“从前有个财主，有人指控他的管家浪费主人的财物。</span>
<span className="v" id="v2" data-v="2" data-xref="Ecclesiastes 11:9–10; 彼得前书 4:5; 启示录 20:12"> 主人把管家叫来，对他说：‘我听说了关于你的事情，怎么会这样？把你管的账目拿来，你不能再做管家了。’</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="Jeremiah 5:31; Isaiah 10:3; Proverbs 18:9"> 管家心想：‘主人不让我继续做管家，我又该做什么呢？去锄地没有力气！去讨饭又太羞耻了！</span>
<span className="v" id="v4" data-v="4" data-xref="Proverbs 30:9; Jeremiah 4:22; 雅各书 3:15"> 对了，我知道该做什么了。这样做，如果我不再当管家，就会有人让我去他们家做工。’</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="路加福音 7:41–42; 马太福音 18:24"> 于是他找来欠他主人债的人。他问第一个人：‘你欠我主人多少？’</span>
<span className="v" id="v6" data-v="6" data-xref="提多书 2:10; 路加福音 16:12; 路加福音 16:9"> 那人说：‘一百桶油<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一桶大约 6 加仑或 22 升。">a</a></sup>。’管家说：‘那快坐下来，拿着你的欠条，把它改成五十桶。’</span>
<span className="v" id="v7" data-v="7" data-xref="Song of Solomon 8:11–12; 路加福音 20:9; 路加福音 20:12"> 他又问另外一人：‘你欠多少？’那人说：‘一百包<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一包大约 11 蒲式耳或 390 升。">b</a></sup>麦子。’管家说：‘给你欠条，改成八十包。’</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦前书 5:5; 以弗所书 5:8; Proverbs 6:6–8"> 他的主人夸奖了这位不诚实的管家，称他做事机警，因为现世之子在对待彼此的时候，比光之子更狡诈。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马太福音 19:21; 提摩太前书 6:17–19; Daniel 4:27"> 我告诉你们，用现世的财富去结交你的朋友，这样当你失去钱财后，就可以进入永恒之家。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 16:11–12; 马太福音 25:21; 路加福音 19:17"> 如果你在极小的事情上可以获得信任，大事也是如此。如果你在极小的事情上不诚实，大事也会不诚实。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 12:33; 雅各书 2:5; Proverbs 8:18–19"> 如果你在现世财富方面不值得信任，谁还会把真实的财富托付给你们？</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 19:13–26; 马太福音 25:14–29; Job 1:21"> 如果你们对别人的东西不忠心，谁还把自己的东西交给你们呢？</span>
<span className="v" id="v13" data-v="13" data-xref="约翰一书 2:15–16; 马太福音 6:24; 雅各书 4:4"> 一个仆人不能服侍两个主人，他必会喜欢一人，讨厌另一人，或忠于一人而背离另一人。你们不能同时服侍上帝和金钱。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 23:35; 路加福音 20:47; Jeremiah 6:13"> 视财如命的法利赛人听见这些话，便开始嘲笑耶稣。</span>
<span className="v" id="v15" data-v="15" data-xref="1 Samuel 16:7; Proverbs 21:2; 哥林多前书 4:5"> 但耶稣对他们说：“你们在人前自称善人，上帝却知道你们在想什么。因为人所看中的，正是上帝所憎恶的。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 11:9–14; 马太福音 21:32; 使徒行传 3:24–25"> 律法和先知所写的，持续到约翰为止。此后所传递的就是上帝之国的福音，人人都努力想要挤进上帝之国。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 5:18; 路加福音 21:33; 彼得前书 1:25"> 但相比天地终会消散，律法文字中哪怕是最小的一个点，也更不容易消失。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 19:9; 马可福音 10:11–12; 马太福音 5:31–32"> 如果你休妻另娶，就犯了奸淫之罪。如果你娶了被休之妻，同样也是犯了奸淫之罪。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="Ezekiel 16:49; Amos 6:4–6; 路加福音 18:24–25"> 从前有一个财主很富有，总是身穿紫袍<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="紫色的衣服非常昂贵。">c</a></sup>和精致的麻衣，过着奢华无度的日子。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 3:2; 1 Samuel 2:8; 雅各书 2:5"> 有个满身长疮的乞丐名叫拉撒路，他经常坐在财主门口，</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 15:27; 马可福音 7:28; 约翰福音 6:12"> 希望用财主饭桌上掉下的残渣充饥，甚至还有狗跑来舔他的疮。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:24; Psalms 49:16–19; 雅各书 1:11"> 后来乞丐死了，天使们将他送到亚伯拉罕那里。财主也死了，被埋在土里。</span>
<span className="v" id="v23" data-v="23" data-xref="彼得后书 2:4; 路加福音 16:28; 马太福音 18:9"> 财主在阴间受尽折磨，于是向上望去，看到了亚伯拉罕和他身边的拉撒路。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约翰福音 4:10; 启示录 22:1; 启示录 7:16–17"> 于是财主喊着说：‘我父亚伯拉罕啊，可怜可怜我吧！派拉撒路来用手指蘸点水，冰冰我的舌头！我在这火焰炙烤的太难熬了。’</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 6:24; 约翰一书 2:15; Psalms 17:14"> 但亚伯拉罕回复道：‘我的孩子，想想你生前享过的福，那时拉撒路过着穷苦的生活。现在他在这里过得很舒适，你就要受苦。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 3:36; Psalms 49:14; Psalms 50:22"> 不仅如此，我们和你们之间还隔着一道深渊，从我这边根本无法去你那边，你们那边也无法到我们这边。’</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 财主说：‘我父啊，那么求你派拉撒路到我父亲的家里去，</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 2:40; Psalms 49:12–13; 帖撒罗尼迦前书 4:6"> 因为我有五个兄弟，他可以警告他们，免得他们最终也到这痛苦之地。’</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行传 15:21; 路加福音 24:27; 路加福音 16:16"> 亚伯拉罕说：‘摩西和先知都在他们那边，你的兄弟应该听他们的。’</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="启示录 16:9–11; 路加福音 16:24; 路加福音 13:5"> 财主说：‘不行啊，我父亚伯拉罕。如果出现在他们面前的人是死而复生，他们必定会悔改！’</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="哥林多后书 4:3; 使徒行传 19:8; 约翰福音 11:43–53"> 亚伯拉罕对他说：‘如果他们不听从摩西和先知的话，就算有人死而复生，他们也不会信服。’”</span>
</div>
</div>

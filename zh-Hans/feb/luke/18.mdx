<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 4:2; 罗马书 12:12; 帖撒罗尼迦前书 5:17"> 为了鼓励大家始终进行祈祷，不可灰心，耶稣对他们讲了一个故事。</span>
<span className="v" id="v2" data-v="2" data-xref="Proverbs 29:7; Psalms 8:1–4; 路加福音 18:4"> 他说：“从前在一座城中有一个法官，不敬重上帝，也不关心其他人。</span>
<span className="v" id="v3" data-v="3" data-xref="Isaiah 1:17; Jeremiah 5:28; Deuteronomy 27:19"> 城里有一个寡妇常常来到他那里，对他说：‘求你为我的敌人给出公正评判！’</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 4:12–13; 路加福音 16:3; 路加福音 12:17"> 法官一开始并不想做这件事，但后来转念一想：‘虽然我不敬重上帝，也不关心其他人，</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 11:8; 路加福音 18:39; Judges 16:16"> 但这寡妇太烦人，我就给她想要的判决吧，这样她就不会不断地来烦我了。’</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 7:13"> 主说：这是个不正义的法官，但听听他说的话。”</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 10:35–37; 彼得后书 3:9; 路加福音 11:13"> “你没发现吗？上帝所选的子民如果日夜向上帝哭求，上帝就会让其获得公道吗？上帝怎么会让他们等待呢？</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 10:23–26; 彼得后书 3:8–9; 马太福音 24:9–13"> 不会的，我告诉你们，他会很快主持正义。但人子到来之际，他在这世上还能找到信他的人吗？”</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 16:15; Proverbs 30:12; Isaiah 65:5"> 耶稣还向那些自诩正义、轻视他人的人讲了一个故事。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 21:31–32; 1 Kings 8:30; 2 Kings 20:5"> “有两个人到圣殿祷告，一个是法利赛人，一个是税吏。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 6:5; Isaiah 65:5; 启示录 3:17"> 法利赛人站着为自己祷告：‘上帝啊，感谢你让我和其他人不一样，我不欺骗，不犯罪<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“不正确”之意。">a</a></sup>，不奸淫，甚至不像这个税吏。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 11:42; 马太福音 23:23–24; 马太福音 9:14"> 我一个星期禁食两次，将收入的十分之一奉献给你。’</span>
<span className="v" id="v13" data-v="13" data-xref="Ezra 9:6; 约翰一书 1:8–10; 提摩太前书 1:15"> 但税吏站在远处，甚至不敢抬头看天，只是捶胸祷告：‘上帝啊，可怜我这个罪人！’</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 14:11; 路加福音 16:15; 雅各书 4:10"> 我告诉你们吧，上帝会看到这税吏是正确的，但不会看到另一个人。因为高抬自己的人必会被贬低，保持谦卑的人必会被抬高。”</span>
<span className="v" id="v15" data-v="15" data-xref="马可福音 10:13–16; 马太福音 19:13–15; 1 Samuel 1:24"> 有人抱着婴孩来到耶稣面前，请他祝福。门徒见状就想要制止他们。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 18:3–4; 哥林多前书 14:20; 哥林多前书 7:14"> 耶稣却让他们把婴儿抱过来，说：“让小孩子到我这里来，不要制止他们，因为上帝之国就属于他们这样的人。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 18:3; 马可福音 10:15; Psalms 131:1–2"> 实话告诉你们，如果不能像小孩子一样接受上帝之国，你就永远都无法走进。”</span>
<span className="v" id="v18" data-v="18" data-xref="马可福音 10:17–31; 使徒行传 16:30; 马太福音 19:16–30"> 有一个长官来到耶稣面前，问他：“良善的老师，我做什么才可以获得永生？”</span>
<span className="v" id="v19" data-v="19" data-xref="Job 15:14–16; 雅各书 1:17; 希伯来书 7:26"> 耶稣对他说：“你为何称我良善？除了上帝以外，无人为尊。</span>
<span className="v" id="v20" data-v="20" data-xref="Exodus 20:12–17; Deuteronomy 5:16–21; 罗马书 13:9"> 你知道那条诫命讲着：不可奸淫，不可杀人，不可偷盗，不可作假证，当孝敬父母。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引自《出埃及记》20:12-16或《申命记》5:16-20。">b</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="腓立比书 3:6; 罗马书 10:2–3; 马可福音 10:20–21"> 那男人回答：“我从小就遵守这一切。”</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 12:33; 提摩太前书 6:18–19; 马太福音 19:21"> 耶稣听了便说：“但你还少做了一件事：把你拥有的一切都卖掉，分给穷人，你就会在天国拥有财富，然后来跟从我。”</span>
<span className="v" id="v23" data-v="23" data-xref="Ezekiel 33:31; 约翰一书 2:15; Job 31:24–25"> 但那人听了这番话，立刻感到情绪低落，因为他非常富有。</span>
<span className="v" id="v24" data-v="24" data-xref="Proverbs 30:9; 雅各书 2:5–7; 马可福音 10:23–27"> 耶稣见他这样的反应，就说：“富有之人要进上帝之国，很难！</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 23:24"> 有钱人进上帝之国，要比让骆驼穿过针眼还困难。”</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 13:23"> 听到这番话，大家就问：“那谁可以获得拯救呢？”</span>
<span className="v" id="v27" data-v="27" data-xref="Jeremiah 32:17; 马太福音 19:26; 路加福音 1:37"> 耶稣说：“人类做不到的，上帝却能。”</span>
<span className="v" id="v28" data-v="28" data-xref="马可福音 10:28; 腓立比书 3:7; 马太福音 19:27"> 彼得说：“我们已舍弃所有跟从你！”</span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 10:29–31; 马太福音 10:37–39; 路加福音 14:26–28"> 耶稣说：“实话告诉你们，人为了上帝之国放弃房屋、妻子、兄弟、父母或儿女，</span>
<span className="v" id="v30" data-v="30" data-xref="希伯来书 13:5–6; Job 42:10; 启示录 2:17"> 得到的要比今世多几倍，来世还会获得永生。”</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 20:17–19; Isaiah 53:1–12; Psalms 22:1–31"> 耶稣把十二门徒带到一边，对他们说：“我们现在去耶路撒冷，先知所写的一切，即将在人子身上成真。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 23:11; Isaiah 50:6; Isaiah 53:3"> 他将被交给异族人，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“异教徒。”">c</a></sup>被嘲笑、被凌辱，人们会向他吐唾沫，</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 15:3–4; 路加福音 24:7; 马太福音 27:63"> 他们会鞭打他，然后杀害他，但他会在第三日复活。”</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 9:45; 马可福音 9:32; 路加福音 24:25"> 但门徒们并不明白耶稣这番话的意思，没有理解这句话的真意。</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 20:29–34; 马可福音 10:46–52; 路加福音 16:20–21"> 耶稣快走到耶利哥的时候，一个盲人坐在路旁乞讨。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 21:10–11; 路加福音 15:26"> 听见人群经过，他便问发生了什么事。</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 2:23; 约翰福音 19:19; 约翰福音 12:35–36"> 众人告诉他，“拿撒勒人耶稣正从这里走过。”</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 9:27; 路加福音 18:39; 马太福音 15:22"> 于是他喊道：“大卫的子孙耶稣啊，可怜可怜我吧！”</span>
<span className="v" id="v39" data-v="39" data-xref="Genesis 32:26–28; Psalms 141:1; 路加福音 18:15"> 走在前面的人制止他喊叫，让他保持安静，但他更大声地喊叫：“大卫的子孙，可怜我吧！”</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 20:31–34; 马可福音 10:48–52"> 耶稣停下来，让他们把盲人带过来。待他走近，耶稣就问他：</span>
<span className="v" id="v41" data-v="41" data-xref="1 Kings 3:5–15; 马太福音 20:21–22; 腓立比书 4:6"> “你要我为你做什么？”盲人说：“主啊，求你让我看到！”</span>
<span className="v" id="v42" data-v="42" data-xref="马太福音 8:3; 路加福音 8:48; 路加福音 17:19"> 耶稣说：“那就看见！你对我的信任，让你痊愈了。”</span>
<span className="v" id="v43" data-v="43" data-xref="Psalms 146:8; 帖撒罗尼迦后书 1:10–12; Isaiah 43:21"> 盲人立刻看见了，于是就跟随耶稣，赞颂上帝。众人见此也纷纷赞美上帝。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 4:1–11; 使徒行传 10:38; 马可福音 1:12–13"> 耶稣体内充满圣灵，从约旦河返回，圣灵带领他来到荒野，</span>
<span className="v" id="v2" data-v="2" data-xref="Exodus 34:28; 希伯来书 4:15; Deuteronomy 9:9"> 接受四十天的魔鬼考验。这些日子里他一直在禁食，最后感到饥肠辘辘。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马太福音 4:3; 路加福音 3:22"> 魔鬼对他说：“如果你是上帝之子，那就把这些石头变成面包吧。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="Deuteronomy 8:3; 马太福音 4:4; 马太福音 6:31"> 耶稣回答：“上帝的经卷中写道：‘人活着并不只靠食物。’”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《申命记》8:3。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰一书 2:15–16; 哥林多前书 15:52; 马太福音 4:8"> 魔鬼引他上到高处，将天下万国展示在他面前，</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 12:31; 约翰一书 5:19; 约翰福音 14:30"> 对他说：“我可以给你这一切的权力和地位，因为我已获得了这些权力，可以随意送给任何人。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 8:28; Psalms 72:11; Isaiah 45:14"> 只要你向我鞠躬，膜拜我，你就可以拥有这一切。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="Deuteronomy 6:13; Deuteronomy 10:20; 马太福音 4:10"> 耶稣回答：“那经文中也说了：‘你只应拜吾主上帝，只能侍奉他。’”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引自《申命记》6:13。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马太福音 4:5–6; 路加福音 4:3; 马太福音 8:29"> 魔鬼又带他到耶路撒冷，叫他站在圣殿的最高处，对他说：“你若是上帝之子，就从这里跳下去！</span>
<span className="v" id="v10" data-v="10" data-xref="Psalms 91:11–12; 希伯来书 1:14; 哥林多后书 11:14"> 因为那经文中写道：‘上帝会派天使照顾你，</span>
<span className="v" id="v11" data-v="11" data-xref="Psalms 91:12"> 托住你，免得你被石头绊倒。’”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《诗篇》91:11-12。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="Deuteronomy 6:16; 希伯来书 3:8–9; 哥林多前书 10:9"> 耶稣回道：“那经文也写着：‘不可试探你的主上帝。’”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《申命记》6:16。">d</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 4:15; 雅各书 4:7; 马太福音 4:11"> 魔鬼用尽了它所有的诱惑，便暂时离开耶稣，伺机寻找其他机会。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="或“等待恰当的时间。”">e</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 4:23–25; 使徒行传 10:37; 马太福音 4:12"> 耶稣回到加利利时，体内注满了圣灵力量，他的名声传遍四面八方。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 4:23; 马太福音 9:8; 马太福音 9:35"> 他在会堂中教导民众，深受众人赞美。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 17:2; 使徒行传 13:14–16; 马太福音 2:23"> 耶稣来到自己成长的家乡拿撒勒，在安息日那天照例进入会堂。</span>
<span className="v" id="v17" data-v="17" data-xref="Isaiah 61:1–3; 使徒行传 13:15; 使徒行传 7:42"> 有人把以赛亚先知的经书递给他，他展开书卷找到一处文字，上面写着：</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="Isaiah 61:1; 马太福音 11:5; Psalms 146:7–8"> “主的灵降临我身上，因为他指派我向贫苦之人传播福音，宣告那些被监禁之人将得到释放，盲人会看见，受压迫之人会得到自由，</span>
<span className="v" id="v19" data-v="19" data-xref="Isaiah 61:2; Isaiah 63:4; 哥林多后书 6:1"> 我还要宣告主赐福之刻的到来。”</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 4:17; 约翰福音 8:2; 路加福音 19:48"> 他把经书卷好交给身边的人，然后坐下来，会堂里的众人都注视着他。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约翰福音 4:25–26; 使徒行传 3:18; 使徒行传 2:16–18"> 耶稣对大家说：“这段经文如今已经应验了！”</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 13:54–56; Psalms 45:2; 使徒行传 6:10"> 众人纷纷表示认可，惊讶他口中所说的恩典之语。然后说：“这真是约瑟的儿子吗？”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约翰福音 4:46–53; 马太福音 11:23–24; 马可福音 2:1–12"> 耶稣回答：“我就知道你们会向我重复这句话：‘医生，先治好你自己！’然后你们会问：‘你在迦百农所行之事，为什么不在你的故乡再做一次呢？’</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 13:57; 约翰福音 4:44; 马可福音 6:4–5"> 但我实话告诉你们，先知在自己的家乡都不受欢迎。</span>
<span className="v" id="v25" data-v="25" data-xref="雅各书 5:17; 1 Kings 17:1; 马太福音 20:15"> 在以利亚的时代，曾出现三年半不下雨的干旱，到处都是大饥荒，以色列出现了许多寡妇，</span>
<span className="v" id="v26" data-v="26" data-xref="1 Kings 17:9–24; 马太福音 11:21; Obadiah 1:20"> 但以利亚并未被派向那里的任何一个人，而是被派到西顿撒勒法一个寡妇面前！</span>
<span className="v" id="v27" data-v="27" data-xref="2 Kings 5:1–27; 约翰福音 17:12; 马太福音 12:4"> 在以利沙的时代，以色列有许多麻风患者，但只有叙利亚的乃缦被治愈了！”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="使徒行传 5:33; 2 Chronicles 24:20–21; Jeremiah 38:6"> 会堂中的众人听到这番话，都感到非常愤怒。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 8:59; 使徒行传 21:28–32; Numbers 15:35"> 他们跳起来将耶稣赶出城，然后把他拖到城市所在的山顶上，要把他从悬崖上扔下去。</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 10:39; 约翰福音 8:59; 约翰福音 18:6–7"> 耶稣却穿过人群，走开了。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马可福音 1:21–28; 马太福音 4:13; 使徒行传 13:50–2"> 耶稣下来后来到加利利的迦百农城，在安息日教导众人。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 4:36; 马太福音 7:28–29; 约翰福音 6:63"> 他的教导让众人感到很惊奇，因为他的话语很有权威。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马可福音 1:23"> 会堂里有一人被恶鬼附体，他大声喊叫：</span>
<span className="v" id="v34" data-v="34" data-xref="马可福音 1:24; 雅各书 2:19; 马太福音 8:29"> “拿撒勒人耶稣，我们跟你有什么关系？你是来毁灭我们的吗？我知道你是谁，你是上帝的圣人！”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="路加福音 4:41; 路加福音 4:39; 马太福音 8:26"> 耶稣打断他：“住口！”然后命令恶鬼：“从他身上出来！”恶鬼当着众人的面把那人摔倒在地上，然后从他身上脱离出来，但没有伤害他。</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 4:32; 彼得前书 3:22; 马太福音 12:22–23"> 众人都很惊讶，彼此询问：“这是怎么回事？他用权力命令恶灵，恶灵竟然出来了。”</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 1:45; 路加福音 4:14; Isaiah 52:13"> 于是耶稣的名声传遍了周围各地。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="马太福音 8:14–15; 马可福音 1:29–31; 约翰福音 11:22"> 耶稣起身离开会堂，走进西门的家。西门的岳母正在发高烧，人们求耶稣救她。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 4:41; 路加福音 4:35; 路加福音 8:24"> 耶稣站在她旁边，命令高烧离开她，于是她立刻退烧了，开始就起身为众人准备饭菜。</span>
<span className="v" id="v40" data-v="40" data-xref="马可福音 1:32–34; 马太福音 8:16–17; 马可福音 5:23"> 日落时分，人们把各种疾病的患者都带到耶稣这里，他将手放在他们身上，一一治好所有病患。</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 1:34; 雅各书 2:19; 路加福音 4:34–35"> 他从很多人身上驱赶出恶鬼，恶鬼叫喊：“你是上帝之子。”耶稣打断了它们，不许它们说话，因为它们知道他是基督。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="路加福音 6:12; 马可福音 1:35–38; 约翰福音 4:34"> 第二天凌晨，耶稣离开众人，找到一处安静的地方。但众人纷纷出门寻找他，找到后又挽留他，希望他不要离开。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="马可福音 1:38–39; 提摩太后书 4:2; 约翰福音 9:4"> 他告诉众人：“我必须到其他城去，传播上帝之国的福音，因为这也是我被派到这里的使命。”</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 4:23; 马可福音 1:39; 路加福音 4:15"> 然后他开始到犹太的各个会堂去传道。</span>
</div>
</div>

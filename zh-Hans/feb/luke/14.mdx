<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 3:2; 路加福音 20:20; Psalms 62:4"> 在一个安息日，耶稣来到一个法利赛人长官家里吃饭，期间众人都在仔细观察他。</span>
<span className="v" id="v2" data-v="2"> 他面前有一个人，双手双腿肿胀，</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 12:10; 马可福音 3:4; 路加福音 13:14–16"> 于是耶稣对研究法律的专家和法利赛人说：“律法是否允许在安息日治病？”</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 22:46; 马太福音 21:25–27"> 众人保持沉默。耶稣摸了那病人一下，把他治好就叫他走了。</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 13:15; Exodus 23:4–5; 马太福音 12:11–12"> 然后耶稣对众人说：“如果安息日那天，你们的儿子或牛掉在井里，你们难道不会立刻把他或它拉上来吗？”</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 20:40; 路加福音 21:15; 使徒行传 6:10"> 众人无法回答这个问题。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="腓立比书 2:3; 路加福音 11:43; 马太福音 23:6"> 耶稣发现他们都选择坐在主位，于是就讲了一个故事。</span>
<span className="v" id="v8" data-v="8" data-xref="Proverbs 25:6–7"> 他说：“当你受邀参加婚筵，不要坐上主位，因为受邀客人中，可能有人比你更尊贵。</span>
<span className="v" id="v9" data-v="9" data-xref="Proverbs 16:18; Proverbs 11:2; Proverbs 3:35"> 邀请你和那人过来的主人会对你说：‘请把位置给这个人。’这时候你就只能尴尬地坐到其他位置上。</span>
<span className="v" id="v10" data-v="10" data-xref="Proverbs 25:6–7; Proverbs 15:33; 1 Samuel 15:17"> 但如果在受邀后，一开始选择坐在末位，主人就会过来对你说：‘朋友，请上座。’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="见《箴言书》25:7。">a</a></sup>这样你在同席众人面前才更有尊严。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 18:14; 马太福音 23:12; Proverbs 29:23"> 凡是高看自己一眼的人，必会被人看轻，凡谦卑之人，必会受到尊重。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 5:46; 雅各书 2:1–6; 路加福音 6:32–36"> 耶稣又对邀请他的人说：“当你在准备午餐或晚餐时，不要邀请你的亲朋好友或富有的邻居，因为他们会回请你，你就得到了报答。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 14:21; Isaiah 58:10; Proverbs 14:31"> 如果你摆宴席邀请穷人、残废人、瘸腿人和盲人，</span>
<span className="v" id="v14" data-v="14" data-xref="Proverbs 19:17; 使徒行传 24:15; 约翰福音 5:29"> 你就有福了。因为他们没有什么可以报答你。待良善之人复活之时，你必定获得报答。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="启示录 19:9; 路加福音 22:30; 路加福音 13:29"> 宴会中一名客人听了这番话，就对耶稣说：“在上帝之国里用餐之人有福了。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马太福音 22:2–14; 启示录 22:17; Isaiah 55:1–7"> 耶稣回答：“一个人大摆宴席，请了许多客人。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 11:27–29; 马太福音 10:1–4; 马太福音 22:3–4"> 到了开席的时候，他派仆人去通知受邀客人，‘来吧！宴席已经备好。’</span>
<span className="v" id="v18" data-v="18" data-xref="提摩太前书 6:9–10; 路加福音 17:26–31; 路加福音 18:24"> 但众人却都在推辞。第一个人说：‘我买了一块地，得去看一看，很抱歉。’</span>
<span className="v" id="v19" data-v="19"> 另一个说：‘我买了十头牛，要去试一试，太抱歉了。’</span>
<span className="v" id="v20" data-v="20" data-xref="Deuteronomy 24:5; 哥林多前书 7:33; 路加福音 14:26–28"> 还有一人说：‘我刚结婚，不能去。’</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 14:13; 马太福音 11:5; 路加福音 14:24"> 仆人回来把这些事告诉主人，主人很生气，对仆人说：‘快到城里的大街小巷，把穷人、残疾人、盲人和瘸腿之人都领到这里来。’</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约翰福音 14:2; 以弗所书 3:8; 提摩太前书 2:5–6"> 随后仆人说：‘主人，我已经按你的吩咐办好了，但还有空位。’</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 22:9–10; 歌罗西书 1:28; 使徒行传 13:47–48"> 主人对仆人说：‘那就到乡间小路去，把人们都叫过来，我希望屋子坐满。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 21:43; 使徒行传 13:46; 约翰福音 8:24"> 告诉你吧，之前邀请的那些人，谁也别想尝到我宴席的滋味。’”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 6:24–27; 路加福音 12:1"> 一大群人与耶稣同行，他转身对他们说：</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 10:37; 约翰福音 12:25; 腓立比书 3:8"> “如果你们想跟随我，但对我的爱无法超过对父母、妻儿、兄弟姊妹、甚至自己生命的爱，就无法成为我的门徒。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 10:38; 路加福音 9:23–25; 马可福音 8:34–37"> 如果你不能背负自己的十字架跟随我，也不能做我的门徒。</span>
<span className="v" id="v28" data-v="28" data-xref="Proverbs 24:27; 马太福音 10:22; Joshua 24:19–24"> 如果你想盖一座高塔，总是要坐下算算费用，看看能不能盖成，是不是？</span>
<span className="v" id="v29" data-v="29"> 否则，如果在打好地基后却不能完工，人们得知这一切就会讥笑你，</span>
<span className="v" id="v30" data-v="30" data-xref="希伯来书 6:11; 约翰二书 1:8; 哥林多前书 3:11–14"> 说：‘看看这个人，开工了却完不成。’</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="Proverbs 20:18; Proverbs 25:8; 2 Kings 18:20–22"> 或者一个国王与另一个国王开战，如果他只有一万兵马，而敌方却有两万兵马，他是不是要与军师们商议，看看能不能打赢？</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 12:20; 雅各书 4:6–10; 路加福音 12:58"> 如果不能，就要趁对方还未兵临城下，先派使者去讲和。</span>
<span className="v" id="v33" data-v="33" data-xref="腓立比书 3:7–8; 约翰一书 2:15–16; 路加福音 5:28"> 同样，你们中间不论谁，如果无法撇下一切跟随我，就不能做我的门徒。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 5:13; 歌罗西书 4:6; 马可福音 9:49–50"> 盐是个好东西，但如果失去了咸味，怎能让它再咸起来呢？</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 11:15; 路加福音 9:44; 启示录 2:11"> 它对田地没好处，也不能做肥料，你只能把它扔掉。如果你有耳朵，就要听一听。”</span>
</div>
</div>

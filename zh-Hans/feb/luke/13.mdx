<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="feb" data-translation-id="cmn_feb" data-translation-label="易读圣经" data-book="LUK" data-book-slug="luke" data-book-name="路加福音" data-chapter="13" data-verses="35">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 4:17–18; Lamentations 2:20; Ezekiel 9:5–7"> 就在这时候，有几个人向耶稣讲述了加利利人的事情，这几个人当时正在圣殿献祭，但彼拉多却将他们杀死了。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 9:2; 使徒行传 28:4; Job 22:5–16"> 耶稣问：“这些加利利人为什么遭受如此痛苦？是因为罪孽比其他加利利人更深重吗？</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 3:19; 马太福音 3:2; 使徒行传 2:38–40"> 告诉你们，并非如此。除非你们悔改，否则也将如此灭亡。</span>
<span className="v" id="v4" data-v="4" data-xref="Nehemiah 3:15; Job 1:19; 约翰福音 9:11"> 当年西罗亚的高塔倒塌时压死了十八个人，难道这些人的罪行比所有耶路撒冷的居民更大吗？</span>
<span className="v" id="v5" data-v="5" data-xref="Ezekiel 18:30; 路加福音 13:3; Isaiah 28:10–13"> 告诉你们，并非如此。除非你们悔改，否则也将如此灭亡。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约翰福音 15:16; Isaiah 5:1–4; 加拉太书 5:22"> 然后耶稣讲了一个故事：“有一个人在葡萄园里种了一棵无花果树。一天他来到无花果树那里找果子，但没有找到。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 7:19; 路加福音 3:9; 约翰福音 15:6"> 于是他对看园人说：‘这三年来我一直在找这棵无花果树的果子，却总是找不到，把它砍了吧！不要让它白白占了空间。’</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="彼得后书 3:9; Joel 2:17; 罗马书 10:1"> 看园人说：‘主人，再多留它一年吧，我给它周围松松土，施施肥，</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 15:2; 帖撒罗尼迦前书 2:15; 希伯来书 6:8"> 如果它结果了，那就太好了。如果没有结果，再砍它也不迟。’”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 4:23; 路加福音 4:44; 路加福音 4:15–16"> 安息日那天，耶稣在会堂向众人传道。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 8:2; 路加福音 8:27; 路加福音 13:16"> 一名恶灵附体的女人已经病了十八年，后背彻底弯曲，完全直不起来。</span>
<span className="v" id="v12" data-v="12" data-xref="Psalms 107:20; 马太福音 8:16; 路加福音 6:8–10"> 耶稣看见她，便把她叫过来说：“你可以摆脱这疾病了。”</span>
<span className="v" id="v13" data-v="13" data-xref="Psalms 107:20–22; 马可福音 16:18; 马可福音 5:23"> 然后耶稣双手按在她身上，她立刻直起腰，开始赞美上帝。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="Exodus 20:9; 马太福音 12:2; 约翰福音 9:14–16"> 但因为今天是安息日，耶稣在这一天治病让会堂的主事很不高兴。他对民众说：“每星期有六天应当工作，你们可以在那六天求医，但安息日不行。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 14:5; 约翰福音 7:21–24; 使徒行传 13:9–10"> 但主回答：“你这伪君子，这一天你们还是要把牛或者驴子从畜栏里放出来，牵去喝水，不是吗？</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 2:27; 提摩太后书 2:26; 路加福音 19:9"> 那么这女人作为亚伯拉罕的女儿，已经被撒旦困住十八年，难道不应当在安息日解开束缚，获得自由吗？”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="彼得前书 3:16; Psalms 132:18; Isaiah 45:24"> 听到这番话，反对耶稣的人都感到很羞愧，民众却因他的伟大之举而欢喜。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马可福音 4:30–34; 路加福音 17:21; 马太福音 13:31–32"> 耶稣说：“上帝之国像什么呢？我要把它比作什么呢？</span>
<span className="v" id="v19" data-v="19" data-xref="Daniel 4:12; Daniel 4:21; Daniel 2:44–45"> 它就像一粒芥菜种子，一个人把它种在自己的园子里，长成一棵树，天空的飞鸟会在它的枝头栖息。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 他又问到：“我要把上帝之国比作什么呢？</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 13:33; 哥林多前书 5:6; 帖撒罗尼迦前书 5:23–24"> 它就像酵母，女人把它与三碗<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="大约为 3 加仑或 13 升。">a</a></sup>面粉混在一起，等着它发酵。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 9:51; 马太福音 9:35; 马可福音 10:32–34"> 耶稣朝着耶路撒冷的方向走去，沿途穿乡过城，教化众人。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 7:14; 马太福音 22:14; 约翰福音 21:21–22"> 有一个人问他：“主啊，是不是只有很少的人才会得到救赎？”<br />他对众人说：</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 7:13–14; 彼得后书 1:10; 哥林多前书 9:24–27"> “要努力穿过这条窄门，我告诉你们，将来会有许多人想要进去，但却进不去。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 25:10–12; 路加福音 13:27; 马太福音 7:21–23"> 等到房子的主人起来关上门，你们就会站在门外敲门说：‘主人啊，请开门吧！’但他的回答是：‘我不认识你们，也不知道你们从哪里来。’</span>
<span className="v" id="v26" data-v="26" data-xref="Isaiah 58:2; 提多书 1:16; 提摩太后书 3:5"> 这时候你们会说：‘但我们曾与你一起吃喝，你曾在我们的街道上教导我们。’</span>
<span className="v" id="v27" data-v="27" data-xref="Psalms 6:8; 马太福音 25:41; 马太福音 7:22–23"> 他会回复：‘告诉你们吧，我不认识你们，也不知道你们从何而来。你们这些作恶之人，从我这里离开！’</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 8:11–12; 马太福音 22:13; 马太福音 25:30"> 当你们看见亚伯拉罕、以撒、雅各和众先知都已置身上帝之国，你们却被赶了出去，到时候必然有人痛苦不堪。</span>
<span className="v" id="v29" data-v="29" data-xref="Isaiah 43:6; Isaiah 66:18–20; Isaiah 49:6"> 人们从四面八方赶来，在上帝之国坐下来用餐。</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 19:30; 马可福音 10:31; 马太福音 20:16"> 后来者会排在前面，先来者会排在后面。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="Nehemiah 6:9–11; Psalms 11:1–2; 马太福音 14:1"> 这时候，有几个法利赛人对耶稣说：“你应该离开这里，因为希律想要杀你。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="希伯来书 2:10; 希伯来书 5:9; 约翰福音 17:4–5"> 耶稣回答：“去告诉那个老狐狸，今天和明天我需要驱鬼治病，到了第三天，我就会完成来到这里的使命。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或“达成我的目标。”">b</a></sup></span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 9:53; 马太福音 21:11; 使徒行传 13:27"> 但无论是今天、明天还是后天，我都必须前行，因为先知不能在耶路撒冷以外的地点死去。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马太福音 23:37–39; Deuteronomy 32:11–12; 使徒行传 7:52"> 耶路撒冷啊，耶路撒冷，你杀害先知，用石头把派给你的人砸死。我总是想把你的儿女召在一起，就像母鸡把小鸡聚在翅膀底下，只是你们不愿意。</span>
<span className="v" id="v35" data-v="35" data-xref="Psalms 118:26; 马可福音 11:9–10; 马太福音 21:9"> 看吧，你们的家将变成荒芜。告诉你们，从今以后，你们再也不会看到我，除非你们说：‘祝福奉主之名前来之人。’”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《诗篇》118:26。">c</a></sup></span>
</div>
</div>

</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 8:5–13; 路加福音 7:1–10; 马太福音 7:28–29"> 耶稣向民众讲完这一切，就开始向迦百农走去。</span>
<span className="v" id="v2" data-v="2" data-xref="2 Kings 5:2–3; Genesis 24:27; 约翰福音 4:46–47"> 那里的一位百夫长有一名十分器重的仆人，但这仆人快要死了。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 8:5; 约翰福音 4:47; 路加福音 9:38"> 百夫长听见耶稣的事，就派来几位犹太人长老过来，求他去医治他的奴仆。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 3:4; 马太福音 10:11; 路加福音 7:6–7"> 长老们就来见耶稣，恳求他说：“请过来为他做这件事吧，因为他值得你的帮助。</span>
<span className="v" id="v5" data-v="5" data-xref="2 Chronicles 2:11–12; 1 Chronicles 29:3–9; 1 Kings 5:1"> 因为他爱我们的人民，给我们建造会堂。”</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 5:24; Genesis 32:10; 雅各书 4:6"> 耶稣就和他们一同前去。在距离百夫长住宅不远的地方，百夫长派几个朋友来说：“主啊，有劳你大驾光临，实在不敢当，</span>
<span className="v" id="v7" data-v="7" data-xref="Psalms 107:20; Psalms 33:9; 路加福音 4:36"> 我觉得自己实在没有资格去见你，但只要你说一句话，我的仆人就能治愈了。</span>
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 3:22; 使徒行传 23:17; 使徒行传 22:25–26"> 我既听命于自己的长官，手下也有士兵。如果我对士兵说‘去吧！’他就会去；对另一个人说‘来吧！’他就会来；我对仆人说‘做这个吧！’他就会做。”</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 15:28; 罗马书 3:1–3; 马太福音 8:10"> 耶稣听见这些话，很是惊讶，转身对跟随的众人说：“告诉你们，我在以色列从未见过如此坚定的信心。”</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 4:50–53; 马太福音 8:13; 马太福音 15:28"> 百夫长的朋友回到家里，发现那奴仆已经痊愈了。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 10:38"> 很快，耶稣开始向拿因城走去，身边跟着他的门徒和一大群民众。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 8:42; 路加福音 8:52; 1 Kings 17:9"> 他走近城门的时候，看到另一条路上有个送葬的队伍，那是一家的独子，母亲是个寡妇。城里有一大群人陪着她。</span>
<span className="v" id="v13" data-v="13" data-xref="Psalms 103:13; Isaiah 63:9; Psalms 86:15"> 主看见她便心生怜悯，对她说：“不要哭！”</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 5:25; 约翰福音 11:43–44; 使徒行传 9:40–41"> 然后耶稣上前按着棺材，抬棺人站住。 耶稣说：“年轻人，我要对你说，起来吧！”</span>
<span className="v" id="v15" data-v="15" data-xref="2 Kings 13:21; 2 Kings 4:32–37; 1 Kings 17:23–24"> 那死去之人就坐起来，开口说话，耶稣把他交给他母亲。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 9:8; 路加福音 7:39; 路加福音 1:68"> 众人都感到敬畏万分，纷纷颂赞上帝：“我们中间出现了伟大的先知！”又说：“上帝眷顾他的子民了！”</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 4:24; 马可福音 6:14; 马太福音 9:26"> 关于耶稣的消息传遍了犹太和周围各地。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 3:26; 马太福音 11:2–19"> 约翰的门徒把这一切都告诉约翰，约翰叫来他的两名门徒，</span>
<span className="v" id="v19" data-v="19" data-xref="Isaiah 9:6–7; 约翰福音 4:25; Genesis 22:18"> 派他们去主那里，说：“你就是我们一直期待的人？还是我们需要继续等待其他人？”</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 7:19"> 两人来到耶稣跟前，说：“施洗约翰派我们来问你，‘你就是我们一直期待的人？还是我们需要继续等待其他人？’”</span>
<span className="v" id="v21" data-v="21" data-xref="马可福音 3:10; Psalms 90:7–9; 希伯来书 12:6"> 耶稣这时正在治愈众多患病、遭难、恶鬼附体之人，让盲人可以看到。</span>
<span className="v" id="v22" data-v="22" data-xref="Isaiah 35:5–6; Isaiah 61:1–3; 路加福音 4:18"> 耶稣回答约翰的门徒：“你们回去把所见所闻都告诉约翰。盲人可以看见，跛人可以走路，麻风患者被治愈，聋人可以听见，死人复活，穷人听到了福音。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 11:6; 彼得前书 2:7–8; 罗马书 9:32–33"> 那些不会因我而感到冒犯的人，有福了。”</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所书 4:14; 约翰福音 1:23; 路加福音 1:80"> 约翰派来的人走了以后，耶稣开始对众人说：“关于约翰，你们到荒野去寻找他时，希望看到什么？风吹动的芦苇吗？</span>
<span className="v" id="v25" data-v="25" data-xref="Isaiah 59:17; Esther 8:15; Esther 1:3"> 身穿华服之人吗？不，那些衣着华丽、生活奢侈的人都生活在宫殿中。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 1:76; 约翰福音 5:35; 路加福音 20:6"> 你们是在寻找先知吗？是的，约翰是先知。但我要说的是，他比先知重要得多了。</span>
<span className="v" id="v27" data-v="27" data-xref="Malachi 3:1; 路加福音 1:76; 马可福音 1:2"> 经文中记着：‘看啊，我派遣使者先你一步，预备你的道路’，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《玛拉基书》3:1。">a</a></sup>说的就是他。</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 13:16–17; 马太福音 11:11; 歌罗西书 1:25–27"> 我告诉你们，女人所诞下的人类中，没有谁比约翰更伟大，但他在上帝之国中却是最不重要的那一个！”</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 3:12; 路加福音 7:35; 使徒行传 18:25"> 经过约翰施洗的众人，甚至包括税吏，听到此言便纷纷决定追随上帝的善意正道。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 13:34; 哥林多后书 6:1; 马太福音 22:35"> 但法利赛人和研究法律的专家未受过约翰的洗礼，便拒绝上帝对他们的美意。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 11:16–19; Lamentations 2:13; 马可福音 4:30"> 耶稣又说：“这个世界的人可以比作什么呢？他们像什么呢？</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 11:16–19; Jeremiah 5:3–5; Proverbs 17:16"> 他们就像小孩子坐在巿中心，对彼此说：‘我们给你们吹笛子，你们却不跳舞，我们唱哀歌，你们也不痛哭。’</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 1:15; 马可福音 1:6; 约翰福音 8:52"> 施洗约翰来了，不吃饭，不喝酒，你们就说他是恶魔附体。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 15:2; 路加福音 7:36; 约翰福音 12:2"> 现在人子来了，看他吃喝你们又说：‘你看，这人又贪吃，又贪杯<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“吃太多食物和喝太多酒。”相比本句前面使用的单词，这里使用的词语有过度的含义。">b</a></sup>，还与税吏和罪人为伍。’</span>
<span className="v" id="v35" data-v="35" data-xref="Proverbs 8:32–36; 马太福音 11:19; Hosea 14:9"> 但上帝的智慧之道，已被他的所有追随者所证实！”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="可能是一句谚语。原意为“她的所有孩子证明了智慧的正确”，意为证据就在结果中……">c</a></sup></span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 14:3–9; 马太福音 26:5–6; 路加福音 14:1"> 有一个法利赛人请耶稣同他一起用餐，于是他就到那位法利赛人家中赴宴。</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 14:3–9; 马太福音 26:6–13; 马太福音 21:31"> 城里有一个女人，是个罪人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="通常被理解为：她过着不道德的生活。">d</a></sup>。得知他在法利赛人家里吃饭，就拿着一瓶香膏来到这里。</span>
<span className="v" id="v38" data-v="38" data-xref="Psalms 126:5–6; Psalms 51:17; Genesis 18:4"> 她跪在耶稣身边，眼泪沾湿了他的脚。于是她用自己的头发把泪水擦干，然后亲吻他的脚，抹上香膏。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 7:16; 路加福音 15:2; 马可福音 7:21"> 请耶稣吃饭的法利赛人看见她，心想：“这人若真的是先知，必定知道是谁在触摸他。这是怎样的女人，她是个罪人！”</span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 16:19; 路加福音 5:31; Ezekiel 33:31"> 于是耶稣开口说：“西门，我有话要对你说。”他说：“老师，请讲。”</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 7:47; 罗马书 5:20; 马太福音 18:28"> 耶稣说：“有两个人欠了一个债主的钱，一人欠 500 银币，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一个银币：相当于一天的薪水。">e</a></sup>一人欠 50 银币。</span>
<span className="v" id="v42" data-v="42" data-xref="Daniel 9:18–19; 歌罗西书 3:13; 罗马书 3:24"> 他们都无力偿还，于是债主就免了两人的债务。这两个人哪一个人会更爱他？”</span>
<span className="v" id="v43" data-v="43" data-xref="Psalms 116:16–18; 提摩太前书 1:13–16; 路加福音 7:47"> 西门回答：“我想是那个欠债多的人会更爱他。”耶稣说：“你说对了。”</span>
<span className="v" id="v44" data-v="44" data-xref="提摩太前书 5:10; Judges 19:21; Genesis 18:4"> 于是他转身向着那女人，对西门说：“你看到这女人吗？我走进你家，你没有给我水洗脚，但她却用眼泪湿了我的脚，用头发擦干。</span>
<span className="v" id="v45" data-v="45" data-xref="2 Samuel 15:5; 2 Samuel 19:39; 罗马书 16:16"> 你没有亲吻我，但这女人自我进来，就一直在亲吻我的脚。</span>
<span className="v" id="v46" data-v="46" data-xref="Psalms 23:5; Ecclesiastes 9:8; 马太福音 6:17"> 你没有在我的头上涂抹香膏，<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="表示款待和在尊重之意。">f</a></sup>但这女人却用香膏抹我的脚。</span>
<span className="v" id="v47" data-v="47" data-xref="约翰一书 4:19; 约翰一书 3:18; Isaiah 1:18"> 所以我告诉你，因为她的很多罪都被赦免了，所以她心中的爱多。<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="这节圣经有时候也被这样理解：这个女人的爱会带来最大的宽恕。但从上下文（尤其是第 43 句）来看，宽恕的程度决定了爱的程度。">g</a></sup>如果被赦免的少，心中爱的也少。”</span>
<span className="v" id="v48" data-v="48" data-xref="马太福音 9:2; 马可福音 2:5; 路加福音 5:20"> 然后耶稣对女人说：“你的罪被赦免了。”</span>
<span className="v" id="v49" data-v="49" data-xref="路加福音 5:20–21; 马太福音 9:3; 马可福音 2:7"> 一同进餐之人心里说：“这是谁啊？竟然可以宽恕罪过？”</span>
<span className="v" id="v50" data-v="50" data-xref="马可福音 5:34; 路加福音 8:48; 路加福音 18:42"> 耶稣对那女人说：“你的信任已经拯救了你，安心地去吧。”</span>

<span className="v" id="v1" data-v="1" data-xref="彼得前书 2:1; 哥林多前书 5:7–8; 雅各书 3:17"> 当时有成千上万的人聚在一起，甚至出现踩踏现象。耶稣就先对门徒说：“虚伪就像是法利赛人的‘酵母’，你们要提防。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 4:22; 路加福音 8:17; 哥林多后书 5:10"> 隐藏之事最终会显现，遮掩之事最终会暴露，为人所知。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 10:27; 马太福音 12:36; Ecclesiastes 10:20"> 你们在暗处说的话，必会被明处之人听见。你们在内室低语交谈的内容，必会在房顶处宣扬出去。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 10:28; Jeremiah 1:8; 启示录 2:10"> 我的朋友，告诉你们，一个人的身躯死掉了，不用害怕，因为人死后什么都做不了。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得后书 2:4; 马太福音 10:28; 启示录 14:7"> 让我来告诉你们应当怕谁，如果一个人在杀了人之后，还有力量将这些死人投入哥和拿<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“哥和拿”为字面意思，有时翻译为地狱或地狱之火。哥和拿本身是耶稣撒冷城外的一个地区，主要用于焚烧垃圾废物。其实“地狱”这个词最初来自北欧，是盎格鲁-撒克逊人上帝话中的词语，与这个词的原意并不完全一致。见《马太福音》5:22 脚注。">a</a></sup>，这样的人才最可怕。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 12:24; Psalms 145:15–16; Psalms 147:9"> 五只麻雀只能卖两个小钱，但上帝不会忘记任何一只麻雀。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 10:30–31; 马太福音 6:26; Isaiah 43:3–4"> 你们的头发甚至都已被数的一清二楚。不要怕，你们可比很多麻雀贵重得多。</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 10:32–33; 约翰一书 2:23; 罗马书 10:9–10"> 我告诉你们实话，凡是公开承认跟随我的人，人子在上帝的天使面前也会承认他。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太后书 2:12; 路加福音 9:26; 马可福音 8:38"> 凡是拒绝我的人，在上帝的天使面前也会被拒绝。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 12:31–32; 约翰一书 5:16; 提摩太前书 1:13"> 说话得罪人子可以被赦免，但亵渎圣灵则不会得到赦免。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 10:17–20; 路加福音 21:12–14; 使徒行传 4:5–7"> 如果有人把你们拉到会堂，在官长和当权者的面前，你们不要思虑怎样辩护自己或该说什么。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 21:15; 马太福音 10:20; 使徒行传 4:8"> 到了时候，圣灵就会把当说的话教导你们。”</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 6:45; 提摩太前书 6:5; Ezekiel 33:31"> 民众中有一个人问耶稣：“老师，请让我的兄弟和我分家产。”</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 2:3; 罗马书 2:1; 罗马书 9:20"> 耶稣说：“我的朋友，谁指认我做你们分家产的法官？”于是他对众人说：</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 13:5; 提摩太前书 6:6–10; Psalms 119:36–37"> “你们要小心，小心所有的贪念，因为一个人的生命并非由拥有的多少而决定。”</span>
<span className="v" id="v16" data-v="16" data-xref="Genesis 26:12–14; Hosea 2:8; Genesis 41:47–49"> 然后他又对他们讲了一个故事，说：“从前有一个富翁，拥有一片肥沃的土地。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 5:42; Isaiah 58:7; 罗马书 12:13"> 他对自己说：‘我该怎么办呢？没有足够的地方存放粮食。’</span>
<span className="v" id="v18" data-v="18" data-xref="雅各书 3:15; 雅各书 4:15; 路加福音 12:21"> 随后他决定了：‘我知道该做什么了，我要拆掉这些谷仓，建造更大的谷仓，就能存放我所有的粮食，还能放下我拥有的其他物品。</span>
<span className="v" id="v19" data-v="19" data-xref="Proverbs 27:1; 雅各书 4:13–15; 哥林多前书 15:32"> 然后我就可以对自己说：你所拥有的足够你享用很多年，所以活的轻松点，吃喝快乐，享受生活！’</span>
<span className="v" id="v20" data-v="20" data-xref="Job 27:8; Jeremiah 17:11; 提摩太前书 6:7"> 但上帝却对他说：‘你这愚蠢的人呐，你的生命今晚就会被夺走，你所存放的那些东西要给谁呢？’</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 6:19–20; 路加福音 12:33; 雅各书 2:5"> 凡为自己积累财富、但在上帝面前并不富足的人，就会这样。”</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 6:25–34; 腓立比书 4:6; 希伯来书 13:5"> 耶稣又对门徒说：“所以我告诉你们，不要担心生命、担心吃什么或者穿什么。</span>
<span className="v" id="v23" data-v="23" data-xref="Job 2:6; Proverbs 13:8; Job 2:4"> 因为生命远比食物重要，身体远比衣服重要。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 10:31; Psalms 147:9; 路加福音 12:7"> 看看乌鸦，它们不种粮也不收获，没有仓库或谷仓，上帝仍养活它们。你们比飞鸟贵重得多了。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 6:27; 马太福音 5:36; 路加福音 19:3"> 担心生命，难道能给自己的寿命延长一小时吗？</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前书 5:7; Psalms 39:6; Ecclesiastes 7:13"> 如果连这么小的事都做不好，为什么还担心其他的事呢？</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 6:28–30; 路加福音 12:24; 1 Kings 10:1–13"> 想想百合花和它们的生长方式，它们不工作也不纺布。但我告诉你们，即使是所罗门最荣耀之时的穿着，也比不上这花中的一朵呢。</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 14:31; Isaiah 40:6; 马太福音 6:30"> 想想田野上的一切，今天生长，明天就被拿去扔进火里，烹煮食物。尽管如此，但上帝仍然用漂亮的花朵装饰田野，更何况你们呢？</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 6:31; 路加福音 12:22; 路加福音 22:35"> 不用思量未来吃什么喝什么，完全不用担心。</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 6:32; 马太福音 6:8; 以弗所书 4:17"> 因为这只是世人所担心的事情。你们的天父知道你们需要这一切。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 6:33; 希伯来书 13:5; Psalms 34:9"> 你们只需寻找上帝之国，上帝就会将这一切赐予你们。</span>
<span className="v" id="v32" data-v="32" data-xref="希伯来书 12:28; 彼得前书 1:3–5; 启示录 1:6"> 你们这群绵羊啊，不要怕，因为你们的天父愿意把王国赐给你们。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 19:21; 使徒行传 4:34–35; 使徒行传 2:45"> 你们应该卖掉自己的所有，把钱拿去施舍穷人，给自己找一个永远不会破损的钱包，在天堂继续使用不尽的财宝，那里没有贼人靠近，也没有虫蛀。</span>
<span className="v" id="v34" data-v="34" data-xref="歌罗西书 3:1–3; 马太福音 6:21; 腓立比书 3:20"> 因为你最在意的事情会显示出你是谁。</span>
<span className="v" id="v35" data-v="35" data-xref="彼得前书 1:13; 以弗所书 6:14; 马太福音 25:4–10"> 穿好衣服做好准备，点上灯，</span>
<span className="v" id="v36" data-v="36" data-xref="犹大书 1:20–21; 雅各书 5:7–8; 启示录 3:20"> 像仆人等候自己的主人从婚筵回来一样，在主人回来敲门时，可以立刻给他开门。</span>
<span className="v" id="v37" data-v="37" data-xref="彼得后书 3:14; 马太福音 24:42; 约翰福音 13:4–5"> 主人回来时，如果看见仆人还在清醒看家，这些仆人就有福了。我告诉你们实话，主人必然会穿上盛装，请他们吃饭，也必然会亲自招待他们。</span>
<span className="v" id="v38" data-v="38" data-xref="帖撒罗尼迦前书 5:4–5; 马太福音 25:6"> 即使主人在午夜或天亮之前回来，看见他们保持警惕并做好准备，这些仆人就有福了！</span>
<span className="v" id="v39" data-v="39" data-xref="彼得后书 3:10; 启示录 3:3; 启示录 16:15"> 但要记住，如果主人知道窃贼什么时候来，他就会保持警惕，不会让他闯进屋里。</span>
<span className="v" id="v40" data-v="40" data-xref="帖撒罗尼迦前书 5:6; 马太福音 25:13; 罗马书 13:11"> 你们也必须做好准备，因为人子会在你想不到的时候到来。”</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 13:37; 彼得前书 4:7; 彼得前书 5:8"> 彼得问：“主啊，你说这故事，是只说给我们听还是说给所有人？”</span>
<span className="v" id="v42" data-v="42" data-xref="马太福音 24:45–46; 彼得前书 5:1–4; 希伯来书 13:17"> 主说：“主人指派家中的一个人作为管家，负责管理家里的事务，然后按时分发粮食，这样的管家是不是值得信赖又聪明？</span>
<span className="v" id="v43" data-v="43"> 主人回来的时候，看见仆人能这样做，那仆人就有福了。</span>
<span className="v" id="v44" data-v="44" data-xref="路加福音 22:29–30; 马太福音 24:47; 路加福音 19:17–19"> 告诉你们实话，主人会指派他管理主人的一切财产。</span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 24:48–50; 启示录 18:7–8; 腓立比书 3:18–19"> 但如果那仆人对自己说：‘我的主人不会那么快回来’，然后动手打骂其他的仆人和使女，开始大吃大喝。</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 12:40; 马太福音 24:51; Psalms 11:5"> 主人会在他想不到的日期和时间回来，严厉处罚他，将其视为完全不可信赖之人。</span>
<span className="v" id="v47" data-v="47" data-xref="雅各书 4:17; 约翰福音 9:41; 约翰福音 12:48"> 仆人知道主人需要什么却不准备，不按照他的意思行事，必多受责打。</span>
<span className="v" id="v48" data-v="48" data-xref="雅各书 3:1; Leviticus 5:17; 路加福音 16:10–12"> 但有的仆人虽然做了会遭受惩罚之事，但由于并不知情，所以责罚会轻一些。如果一个人给你很多，就会向你要求很多，如果一个人受你之托做了很多事，就会要求你做很多事。</span>
<span className="v" id="v49" data-v="49" data-xref="Malachi 4:1; 路加福音 12:51–52; 马太福音 3:10–12"> 我来到这里，就是为了在大地上点起一把火，我非常希望它已经燃烧起来！</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 12:27–28; 约翰福音 19:30; 约翰福音 7:6–8"> 但我还有必须进行的痛苦的洗礼，所以感觉很痛苦，希望它能尽快结束。</span>
<span className="v" id="v51" data-v="51" data-xref="马太福音 10:34–36; 路加福音 12:49; 马太福音 24:7–10"> 你们认为我来此是给人间带来和平吗？不是的，我告诉你们，我带来的是纷争。</span>
<span className="v" id="v52" data-v="52" data-xref="使徒行传 14:1–4; 约翰福音 15:18–21; Micah 7:5–6"> 从今以后，如果一个家庭有五口人，他们会分成两派产生纷争，三个反对两个，或者两个反对三个。</span>
<span className="v" id="v53" data-v="53" data-xref="Micah 7:6; 马太福音 10:21–22; 马太福音 24:10"> 他们将彼此对立：父亲反对儿子，儿子反对父亲，母亲反对女儿，女儿反对母亲，婆婆反对媳妇，媳妇反对婆婆。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="见《弥迦书》7:6。">b</a></sup></span>
<span className="v" id="v54" data-v="54" data-xref="马太福音 16:2–4; 1 Kings 18:44–45"> 耶稣又对众人说：“你们看见西边有云彩升起，立刻就会说：‘要下大雨了’，事实果然如此。</span>
<span className="v" id="v55" data-v="55" data-xref="Job 37:17; 马太福音 20:12"> 刮起南风，你们会说：‘天要热了’，真的就热了。</span>
<span className="v" id="v56" data-v="56" data-xref="马太福音 16:3; 马太福音 24:32–33; 马太福音 11:25"> 伪君子啊！你们知道如何识别天地气象，为什么不知道分辨这个时代？</span>
<span className="v" id="v57" data-v="57" data-xref="Deuteronomy 32:29; 约翰福音 7:24; 使徒行传 13:26–38"> 你们为什么自己不能判断对错呢？</span>
<span className="v" id="v58" data-v="58" data-xref="Proverbs 25:8–9; 马太福音 5:23–26; 路加福音 13:24–28"> 你和对手一起去法院，在路上应当尽力与他解决问题，否则他可能把你拉到法官面前，法官把你交给差役，把你关在监牢。</span>
<span className="v" id="v59" data-v="59" data-xref="马可福音 12:42; 马太福音 18:34; 马太福音 25:46"> 告诉你吧，除非你还清最后一分钱，否则无法从监狱出来。”</span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 3:1; 马太福音 24:14; 使徒行传 25:21"> 一天，凯撒·奥古斯都颁发命令，要对罗马帝国所有民众进行一次人口登记。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 3:1; 马太福音 4:24; 使徒行传 26:30"> 自从居里纽斯担任叙利亚总督以来，这还是首次人口普查。</span>
<span className="v" id="v3" data-v="3"> 众人回到自己的城市进行登记。</span>
<span className="v" id="v4" data-v="4" data-xref="Micah 5:2; 约翰福音 7:42; 1 Samuel 16:1"> 约瑟是大卫王的后人，于是他离开加利利的拿撒勒，前往犹太的大卫之城伯利恒。</span>
<span className="v" id="v5" data-v="5" data-xref="Deuteronomy 22:22–27; 马太福音 1:18–19"> 他与订立婚约的玛利亚一同前往，此时玛利亚即将分娩。</span>
<span className="v" id="v6" data-v="6" data-xref="Psalms 33:11; 启示录 12:1–5; Micah 5:2"> 他们来到目的地后，玛利亚的产期也到了，</span>
<span className="v" id="v7" data-v="7" data-xref="加拉太书 4:4; 哥林多后书 8:9; Isaiah 53:2–3"> 诞下她的长子，但因为客栈中没有空房间，他们只能用布包好婴儿，放在马槽中。</span>
<span className="v" id="v8" data-v="8" data-xref="Genesis 31:39–40; Psalms 78:70–71; 1 Samuel 17:34–35"> 当晚在伯利恒附近，有几名牧羊人正在看守羊群。</span>
<span className="v" id="v9" data-v="9" data-xref="Isaiah 60:1; 哥林多后书 3:18; 1 Kings 8:11"> 主派来的天使现身于他们面前，周身环绕着主的荣光，这让他们吓得魂飞魄散！</span>
<span className="v" id="v10" data-v="10" data-xref="Isaiah 40:9; Isaiah 61:1; Isaiah 52:7"> 天使说：“不要怕！看！我为你们带来了好消息，这也会让所有人感受到真正的喜悦。</span>
<span className="v" id="v11" data-v="11" data-xref="Isaiah 9:6; 马太福音 1:21; 使徒行传 2:36"> 就在今天，在这大卫之城，你们的救世主已经诞生，他就是主基督。</span>
<span className="v" id="v12" data-v="12" data-xref="Isaiah 7:14; Isaiah 53:1–2; Isaiah 7:11"> 当你们在马槽内看到一个被布包裹的婴孩，就代表你们找到他了。”</span>
<span className="v" id="v13" data-v="13" data-xref="Psalms 103:20–21; 启示录 5:11; Psalms 148:2"> 这时忽然出现了很多来自天堂的生命，开始赞美上帝。</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 5:1; 路加福音 19:38; 歌罗西书 1:20"> “赞颂天堂的上帝，人间令他喜悦之人都将获得安宁！”</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 3:22; 马太福音 2:1–2; 马太福音 2:9–11"> 众天使离开他们返回天堂。牧人彼此说：“我们去伯利恒吧，看看主所说的事情，哪些已经成真。”</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:32; 路加福音 2:12; 路加福音 2:7"> 于是他们匆忙赶去，找到了玛利亚、约瑟和放在马槽里的婴孩。</span>
<span className="v" id="v17" data-v="17" data-xref="Psalms 66:16; 路加福音 8:39; Psalms 71:17–18"> 在亲眼目睹这一切后，他们就将天使关于这婴儿的讲述告诉其他人。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 2:47; 路加福音 4:36; 路加福音 1:65–66"> 对牧羊人所说的这些事，所有人都感到惊奇万分。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 2:51; 路加福音 1:66; Proverbs 4:4"> 玛利亚将所发生的一切牢记心中，反复思量。</span>
<span className="v" id="v20" data-v="20" data-xref="Psalms 106:48; Isaiah 29:19; 使徒行传 11:18"> 牧羊人因亲眼见到天使所言成真，于是便赞美和感谢上帝，回去继续看管他们的羊群。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:31; Genesis 17:12; 加拉太书 4:4–5"> 婴儿诞生后第八天，需要进行割礼，将他起名为耶稣，这也是玛利亚尚未怀胎之时，天使为其提供的名字。</span>
<span className="v" id="v22" data-v="22" data-xref="Leviticus 12:1–8"> 当他们按照摩西的律法净化的时间结束后，约瑟和马利亚把他带到耶路撒冷，准备把他献给主。</span>
<span className="v" id="v23" data-v="23" data-xref="Exodus 13:2; Exodus 22:29; Numbers 3:13"> 就像主的律法所述：“所有长子婴儿都应先献给主。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《出埃及记》13:2。">a</a></sup></span>
<span className="v" id="v24" data-v="24" data-xref="Leviticus 12:6–8; Leviticus 12:2; 哥林多后书 8:9"> 随后他们进行了献祭，因为上帝的律法还说：应献祭“一对斑鸠或两只雏鸽。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引自《利未记》12:8。">b</a></sup></span>
<span className="v" id="v25" data-v="25" data-xref="Isaiah 25:9; 路加福音 2:38; 路加福音 1:6"> 在耶路撒冷有一人名叫西门，时刻遵循正道行事，非常虔诚。他期待能看到以色列的希望，希望圣灵降临于他。</span>
<span className="v" id="v26" data-v="26" data-xref="约翰福音 8:51; 希伯来书 11:5; 路加福音 9:27"> 圣灵曾向他显现，告诉他在有生之年必会见到主的基督。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或“基督。”">c</a></sup></span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 4:1; 路加福音 2:41; 路加福音 2:51"> 他遵循圣灵的指引来到圣殿，这时耶稣的父母抱着孩子走进来，打算按照律法献上婴儿。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 1:64; 路加福音 2:20; 路加福音 2:13–14"> 西门用双臂抱住耶稣，一边感谢上帝，一边说：</span>
<span className="v" id="v29" data-v="29" data-xref="启示录 14:13; Genesis 15:15; 腓立比书 1:23"> “主啊，我的主人，现在可以按照你的承诺，让你的仆人离开了！</span>
<span className="v" id="v30" data-v="30" data-xref="Isaiah 49:6; 路加福音 2:10–11; 路加福音 3:6"> 因为我已亲眼见到</span>
<span className="v" id="v31" data-v="31" data-xref="Isaiah 62:1–2; Isaiah 42:1–4; Psalms 98:2–3"> 你为所有人准备的救赎。</span>
<span className="v" id="v32" data-v="32" data-xref="Isaiah 60:1–3; Isaiah 49:6; 使徒行传 26:23"> 他就是将你显现给全世界的光，是你以色列子民的荣耀。”</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 1:65–66; Isaiah 8:18; 路加福音 2:48"> 西门的话让耶稣的父母很震惊。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 1:23; 彼得前书 2:7–8; Isaiah 8:14–15"> 西门向他们祝福，对耶稣的母亲玛利亚说：“这孩子必定会让很多以色列人倒下，也让很多人崛起。他就是上帝的信号，但很多人都会反对他，</span>
<span className="v" id="v35" data-v="35" data-xref="Deuteronomy 8:2; 哥林多前书 11:19; 马太福音 12:24–35"> 这也揭露了他们心中的想法。对你而言，这感觉就像被刀剑刺穿。”</span>
<span className="v" id="v36" data-v="36" data-xref="Exodus 15:20; Genesis 30:13; 使徒行传 21:9"> 亚拿是耶路撒冷的一位年事已高的女先知，是亚什部落法内利的女儿，曾有过一段七年的婚姻。</span>
<span className="v" id="v37" data-v="37" data-xref="提摩太前书 5:5; Psalms 23:6; 使徒行传 14:23"> 丈夫去世后，她便独自寡居，如今已八十四岁，经常会到圣殿中膜拜、禁食和祷告。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 2:25; 哥林多后书 9:15; 马可福音 15:43"> 此刻她刚好走近他们，于是开始赞美上帝，然后向所有期待上帝拯救耶路撒冷的众人，讲述耶稣的事情。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 2:4; 加拉太书 4:4–5; Deuteronomy 12:32"> 耶稣的父母完成了上帝律法要求的一切，于是就返回加利利，回到位于拿撒勒的家中。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 2:52; 路加福音 1:80; Isaiah 11:1–5"> 婴儿逐渐长大，愈发强壮和睿智，因为他已获得上帝的赐福。</span>
<span className="v" id="v41" data-v="41" data-xref="Exodus 12:14; Numbers 28:16; Deuteronomy 12:18"> 每年逾越节，耶稣的父母都会去耶路撒冷。</span>
<span className="v" id="v42" data-v="42"> 在他十二岁那年，他们按着惯例再次去参加这个节日。</span>
<span className="v" id="v43" data-v="43" data-xref="2 Chronicles 30:21–23; Exodus 12:15; 2 Chronicles 25:17"> 节日结束后本应该回家，但年幼的耶稣仍留在耶路撒冷，他父母却没有意识到这一点，</span>
<span className="v" id="v44" data-v="44" data-xref="Psalms 122:1–4; Isaiah 2:3; Psalms 42:4"> 以为他在返回家园的人群之中。一天后，他们开始在亲戚朋友中寻找他。</span>
<span className="v" id="v45" data-v="45"> 但一直没有找到，于是就回到耶路撒冷继续寻找。</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 5:17; Isaiah 49:1–2; Isaiah 50:4"> 三天后，才发现他在圣殿里，身边是几位宗教老师。他一面听他们说的话，一面向他们提出问题。</span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 7:28; 路加福音 4:32; Psalms 119:99"> 所有听过他讲话的人，都对他深刻的理解和回答而惊讶万分。</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 2:49; 马太福音 12:46; 路加福音 3:23"> 看到眼前这一切，他父母非常不解。他母亲说：“孩子，你怎么能这样对我们？你看，我和你父亲如此担心你，到处找你！”</span>
<span className="v" id="v49" data-v="49" data-xref="约翰福音 6:38; 约翰福音 8:29; Malachi 3:1"> 耶稣回答：“你们为什么找我？难道你们不知道，我应该在这里，在我父的家中？”</span>
<span className="v" id="v50" data-v="50" data-xref="路加福音 18:34; 路加福音 9:45; 马可福音 9:32"> 但他父母并不理解他这番话。</span>
<span className="v" id="v51" data-v="51" data-xref="路加福音 2:19; Daniel 7:28; Genesis 37:11"> 于是他就顺从父母之意回到拿撒勒，但他母亲把这一切都记在心上。</span>
<span className="v" id="v52" data-v="52" data-xref="路加福音 2:40; Proverbs 3:3–4; 1 Samuel 2:26"> 耶稣的智慧和力量不断增长，上帝和民众都喜欢他。</span>

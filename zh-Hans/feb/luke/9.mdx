<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 14:12; 路加福音 10:19; 马太福音 16:19"> 耶稣召齐十二门徒，赋予他们力量和权力，去制伏一切妖魔，医治各样的疾病。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 10:7–8; 路加福音 10:9; 马太福音 3:2"> 然后派遣他们去宣讲上帝之国和医治病人。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 22:35; Psalms 37:3; 路加福音 10:4–12"> 他对他们说：“你们路上什么都不用带，手杖、袋子、食物、银钱或是衣服都不需要。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 10:11; 马可福音 6:10; 路加福音 10:5–8"> 无论走进谁家，就住下，直到需要离开为止。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 13:51; 使徒行传 18:6; 马可福音 6:11"> 如果那家人不接待你，在离开那座城的时候，就把脚上的灰尘跺下，以此警示他们。”</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 4:30; 马可福音 16:20; 使徒行传 5:15"> 于是门徒们就出发走遍各乡，传讲福音，到处医治病人。</span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 6:14–28; 马太福音 14:1–12; 路加福音 3:1"> 君王希律听到这一切<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="尤其指代耶稣。">a</a></sup>，感到非常困惑，因为有人说：“约翰起死复生了。”</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 1:21; 路加福音 9:19; 马可福音 6:15"> 又有人说：“以利亚显现了。”还有人说：“古时的一位先知复活了。”</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 23:8; 路加福音 13:31–32"> 希律说：“毫无疑问<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="隐喻，强调“我”的意思。">b</a></sup>我已经将约翰斩头，但他又是谁，我怎么会听到关于他的这些事呢？”于是他就设法要见耶稣。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 11:21; 希伯来书 13:17; 马太福音 14:13–21"> 门徒们回来后把所做之事报告耶稣，于是他带着他们离开，去一个叫做伯赛大城的地方。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 9:2; 路加福音 5:31; 希伯来书 4:16"> 民众知道后也跟了去。他接待他们，向他们讲述上帝之国，医好需要救治之人。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 6:1; 约翰福音 6:5–15; Hosea 13:5"> 天色将晚，十二门徒来到他跟前，说：“你让众人散了吧，让他们到附近的村庄和农场去，找地方住，找东西吃，因为这里是一片荒野。”</span>
<span className="v" id="v13" data-v="13" data-xref="Proverbs 11:24–25; 约翰福音 6:5–9; 2 Kings 4:42–43"> 但耶稣说：“你们可以给他们吃的东西！”他们说：“我们只有五个饼和两条鱼，除非你想让我们去为所有人买食物。”</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 8:6; 哥林多前书 14:40; 马可福音 6:39–40"> 这里大概有五千名男人。他对门徒说：“让他们分组坐下，每组大概五十人。”</span>
<span className="v" id="v15" data-v="15"> 门徒就照他的话叫众人坐下。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 14:19; 提摩太前书 4:4–5; 马太福音 15:36"> 耶稣拿起这五个饼和两条鱼，望着天，为食物祝福。然后掰开饼，持续不断地递给门徒，与众人分享。</span>
<span className="v" id="v17" data-v="17" data-xref="2 Kings 4:44; 马太福音 15:37–38; 约翰福音 6:11–13"> 所有人都吃饱了，把剩下的食物收拾起来，装满了十二个篮子。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 16:13–16; 路加福音 11:1; 马太福音 26:36"> 还有一次耶稣独自祈祷的时候，只有门徒和他在一起。他问他们：“所有这些民众是怎么看我的？”</span>
<span className="v" id="v19" data-v="19" data-xref="Malachi 4:5; 路加福音 9:7–8; 马太福音 14:2"> 他们回答：“有人说是你是施洗的约翰，有人说你是以利亚，还有人说你是古时的一位先知复活。”</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 16:15–17; 约翰福音 4:29; 约翰福音 7:41"> 他又问他们：“你们怎么看我？” 彼得回答：“你是上帝的基督。”</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 16:20; 马太福音 17:9; 马可福音 8:30–31"> 耶稣严厉地嘱咐他们，不要把这事告诉其他人。</span>
<span className="v" id="v22" data-v="22" data-xref="Isaiah 53:1–12; 路加福音 24:7; 路加福音 18:31–34"> 他说：“人子必须遭受许多苦难，被长老、祭司长和宗教老师拒绝，然后被杀害，但会在第三日复活。”</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 10:38–39; 路加福音 14:26–27; 罗马书 8:13"> 耶稣又对众人说：“如果有人愿意跟从我，就必须舍弃自己，天天背着自己的十字架跟从于我。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 17:33; 约翰福音 12:25; 使徒行传 20:23–24"> 如果你想拯救自己的生命，就必会丢掉生命。但如果你为我牺牲生命，必拯救生命。</span>
<span className="v" id="v25" data-v="25" data-xref="马可福音 8:36; 马太福音 16:26; Psalms 49:6–8"> 即使赢得全世界，但你最终却迷失或毁灭，又有什么好处呢？</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 10:32–33; 提摩太后书 2:12; 路加福音 12:8–9"> 如果你因为我和我所授之道而感到耻辱，当人子带着荣耀以及天父和天使的荣耀降临时，也必把你视为耻辱。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 16:28; 马可福音 9:1; 约翰福音 21:22–23"> 告诉你们真相，这里的人群中，有人在死亡之前就能看到上帝之国。”</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 17:1–13; 马太福音 26:37–39; 马可福音 14:33–36"> 在他说出这番话约八天后，耶稣带着彼得、约翰和雅各上山去祷告。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 17:2; 马可福音 9:2–3; Exodus 34:29–35"> 在祷告的过程中，他的面貌忽然改变，衣服散发着洁白的光芒。</span>
<span className="v" id="v30" data-v="30" data-xref="希伯来书 3:3–6; 哥林多后书 3:7–11; 路加福音 1:17"> 摩西和以利亚显现在荣光之中，开始与耶稣交流，</span>
<span className="v" id="v31" data-v="31" data-xref="腓立比书 3:21; 彼得前书 1:11–12; 彼得前书 5:10"> 谈论他去世<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“离开。”">c</a></sup>的事，这也是他在耶路撒冷需要完成的事情。</span>
<span className="v" id="v32" data-v="32" data-xref="Daniel 8:18; 约翰福音 1:14; Daniel 10:9"> 彼得和同伴都在打盹。醒过来之后，就看见他的荣光，也认出了与耶稣站在一起的那两个人。</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 9:5–6; 马可福音 10:38; Psalms 4:6–7"> 那二人正要离开他的时候，彼得对耶稣说：“主啊，能来到这里太好了！我们可以搭三个庇护所，一个为你，一个为摩西，一个为以利亚。”但他其实并不知道自己在说什么。</span>
<span className="v" id="v34" data-v="34" data-xref="Exodus 40:34–38; 马太福音 17:5–7; Judges 13:22"> 就在他说话的时候，有一片云笼罩在他们上方，这让门徒们很害怕。</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 3:22; 使徒行传 3:22–23; 马太福音 3:17"> 云里飘出来一个声音，说：“这是我的天选之子，你们要听从他！”</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 17:9; 马可福音 9:9–10; 马可福音 9:6"> 声音消失后，众人只看到耶稣自己。关于这一刻所见之事，门徒们没有说出去，没有告诉任何人。</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 17:14–20; 马可福音 9:14–29"> 他们下山后的第二天，有一大群人等在那里迎接耶稣。</span>
<span className="v" id="v38" data-v="38" data-xref="Zechariah 12:10; 约翰福音 4:47; 路加福音 7:12"> 人群中有一个人喊着：“老师，求你看看我儿子吧，他是我的独子。</span>
<span className="v" id="v39" data-v="39" data-xref="马可福音 9:20; 路加福音 8:29; 路加福音 4:35"> 一个恶灵附上了他的身体，他会忽然喊叫，身体抽搐，口吐白沫。恶灵会折磨糟践他，不肯放过他。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 9:1; 使徒行传 19:13–16; 路加福音 10:17–19"> 我求过你的门徒把他赶出去，他们却办不到。”</span>
<span className="v" id="v41" data-v="41" data-xref="Deuteronomy 32:5; 罗马书 2:4; 约翰福音 20:27"> 耶稣说：“唉！这没有信仰的腐朽世界啊！我还要和你们在一起多久，忍受你们到几时？把你儿子带到这里来吧！”</span>
<span className="v" id="v42" data-v="42" data-xref="马可福音 9:26–27; 路加福音 7:15; 启示录 12:12"> 那孩子走过来的时候，恶鬼把他摔倒，让他不停抽搐。耶稣斥责那恶灵，然后把孩子医好，交给他父亲。</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 9:43–45; 路加福音 5:26; 马太福音 17:22"> 众人都惊奇上帝的力量。就在大家还在惊讶耶稣所做的一切时，耶稣对门徒说：</span>
<span className="v" id="v44" data-v="44" data-xref="路加福音 9:22; 使徒行传 2:23; 路加福音 2:19"> “仔细听好我将要说的话：人子将遭受人的背叛。”</span>
<span className="v" id="v45" data-v="45" data-xref="路加福音 18:34; 路加福音 2:50; 约翰福音 12:16"> 门徒不明白，因为这话的真实意思被隐藏起来了，他们无法理解其隐喻之意，也不敢多问。</span>
<span className="v" id="v46" data-v="46" data-xref="马太福音 18:1–5; 马可福音 9:33–37; 马太福音 20:20–22"> 后来，门徒之间开始争论谁最伟大。</span>
<span className="v" id="v47" data-v="47" data-xref="Psalms 139:23; 约翰福音 16:30; 路加福音 5:22"> 耶稣知道他们在争论什么，就找了一个小孩子过来，叫他站在自己旁边，</span>
<span className="v" id="v48" data-v="48" data-xref="彼得前书 5:6; 路加福音 14:11; 马可福音 9:37"> 他对门徒们说：“凡以我之名接待这孩子，就是接待我，凡接待我者，就是接待派我来到这里的上帝。你们中间谁的年龄最小，谁就最伟大。”</span>
<span className="v" id="v49" data-v="49" data-xref="马可福音 9:38–40; Numbers 11:27–29; 马可福音 10:13–14"> 约翰说：“主啊，我们看见有一个人以你的名驱鬼，我们就制止他，因为他不是我们中的一员。”</span>
<span className="v" id="v50" data-v="50" data-xref="马太福音 12:30; 路加福音 11:23; 哥林多前书 12:3"> 耶稣说：“不要制止他，因为没有人能以我之名行神迹，同时又诅咒我。”</span>
<span className="v" id="v51" data-v="51" data-xref="Isaiah 50:5–9; 马可福音 16:19; 路加福音 13:22"> 耶稣升入天堂的日子即将来临，他决意去耶路撒冷。</span>
<span className="v" id="v52" data-v="52" data-xref="马太福音 10:5; 路加福音 17:16; 路加福音 10:1"> 他派信使先走一步，造访撒玛利亚的一个村庄，为他做准备。</span>
<span className="v" id="v53" data-v="53" data-xref="约翰福音 4:9; 约翰福音 4:40–42; 路加福音 9:48"> 但那里的人不欢迎他，因为他决定去耶路撒冷。</span>
<span className="v" id="v54" data-v="54" data-xref="2 Kings 1:10–14; 雅各书 3:14–18; 雅各书 1:19–20"> 他的门徒雅各和约翰看见了，就说：“主啊，你要我们呼唤从天而降的火烧死他们吗？”</span>
<span className="v" id="v55" data-v="55" data-xref="启示录 3:19; 彼得前书 3:9; Jeremiah 17:9"> 但耶稣转过身斥责他们。</span>
<span className="v" id="v56" data-v="56" data-xref="马太福音 20:28; 罗马书 12:21; 约翰福音 3:17"> 然后一行人就开始去其他的村庄。</span>
<span className="v" id="v57" data-v="57" data-xref="马太福音 8:19–22; 约翰福音 13:37; 路加福音 9:57–60"> 在路上，有一个人对耶稣说：“你无论去哪里，我都要跟随你！”</span>
<span className="v" id="v58" data-v="58" data-xref="马太福音 8:20; 路加福音 14:26–33; 雅各书 2:5"> 耶稣对那人说：“狐狸有洞，飞鸟有窝，人子却没有栖身之地。”</span>
<span className="v" id="v59" data-v="59" data-xref="马太福音 16:24; 马太福音 6:33; 1 Kings 19:20"> 他对另一个人说：“跟随我吧！”那人说：“主啊，先让我先回去安葬我的父亲吧。”</span>
<span className="v" id="v60" data-v="60" data-xref="提摩太后书 2:3–4; 提摩太前书 5:6; 约翰福音 21:15–17"> 耶稣说：“让死人去埋葬他们的死人吧，你应该去传扬上帝之国。”</span>
<span className="v" id="v61" data-v="61" data-xref="路加福音 14:26; 路加福音 14:18–20; 1 Kings 19:20"> 又有一个人说：“主啊，我要跟随你，但容我先回去与家人道别。”</span>
<span className="v" id="v62" data-v="62" data-xref="腓立比书 3:13; 希伯来书 10:38; 彼得后书 2:20–22"> 耶稣说：“如果你已经开始耕犁，就不要向后看，否则就不适合进入上帝之国。”</span>

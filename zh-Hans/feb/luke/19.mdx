<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Joshua 6:1–27; 路加福音 18:35; 2 Kings 2:18–22"> 耶稣走进耶利哥城，穿城而过。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 18:24–27; 2 Chronicles 17:5–6"> 有一个名叫撒该的税吏长，非常富有。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 23:8; 路加福音 9:7–9; 约翰福音 12:21"> 他想看看耶稣到底是谁，但在人群中，身材矮小的他无法看见。</span>
<span className="v" id="v4" data-v="4" data-xref="Isaiah 9:10; 路加福音 5:19; 1 Kings 10:27"> 于是他跑到前面，爬上一棵无花果树，想在耶稣经过的时候看看他的样子。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="启示录 3:20; 约翰福音 14:23; 希伯来书 13:2"> 耶稣走到这里后往上一看，对他说：“撒该，快下来，今天我要住在你家中。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="路加福音 5:29; 使徒行传 16:34; 使徒行传 16:15"> 撒该马上爬下来，高兴地迎接耶稣到他家去。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 15:2; 路加福音 7:39; 路加福音 7:34"> 众人见状议论纷纷：“他竟要住在这样的罪人家中！”</span>
<span className="v" id="v8" data-v="8" data-xref="2 Samuel 12:6; Numbers 5:7; 路加福音 18:22–23"> 撒该站着对主说：“主啊，你看，我正在把一半的家财分给穷人，如果我曾欺骗谁，就会四倍奉还！”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="加拉太书 3:7; 路加福音 13:16; 罗马书 4:16"> 耶稣说：“今天这栋房子迎来了救赎，他也是亚伯拉罕的子孙。</span>
<span className="v" id="v10" data-v="10" data-xref="Ezekiel 34:16; 马太福音 1:21; 提摩太前书 1:13–16"> 因为人子来寻找和拯救的就是迷失之人。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路加福音 17:20; 使徒行传 1:6; 帖撒罗尼迦后书 2:1–3"> 众人专心听着耶稣的话。由于这里接近耶路撒冷，加上民众都认为上帝之国即将出现，于是耶稣就讲了一个故事。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 25:14–30; 路加福音 19:12–27; 路加福音 20:9"> 他说：“从前有一个贵族，他离开家去远方接受王位加冕，然后再回到家。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 25:14–15; 约翰福音 12:26; 哥林多前书 12:7–11"> 他叫了自己的十个仆人来，将钱<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="钱：原文为古希腊的货币一个迈那，价值 100 个银币，相当于 100 天的薪水。">a</a></sup>平分给他们，然后说：‘你们用这钱去做投资，一直到我回来。’</span>
<span className="v" id="v14" data-v="14" data-xref="1 Samuel 8:7; 使徒行传 7:51–52; 使徒行传 3:14–15"> 但这国家的人都憎恨他，于是派一个代表跟过去，说：‘我们不想这个人做王统治我们。’</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 4:1–5; 罗马书 14:10–12; Psalms 2:4–6"> 贵族获得王位后返回，然后将那些拿钱投资的仆人召来，询问他们做投资的收益情况。</span>
<span className="v" id="v16" data-v="16" data-xref="雅各书 2:18–26; 提摩太后书 4:7–8; 哥林多前书 15:10"> 第一个仆人上前说：‘主人，你的钱已经赚了十倍。’</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 16:10; 马太福音 25:21; 启示录 2:26–29"> 国王说：‘做得好，你是个好仆人，因为你证明了在小事上很忠心，我现在派你去管理十座城。’</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马可福音 4:20; 马太福音 13:23; 哥林多后书 8:12"> 第二个过来说：‘主人，你的钱已经赚了五倍。’</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 15:58; 哥林多前书 15:41–42; 哥林多前书 3:8"> 国王说：‘我派你去管理五座城。’</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马太福音 25:24; Proverbs 26:13–16; 雅各书 4:17"> 另一个仆人走进来说：‘主啊，你看，这是你的钱，现在还给你。我用布包着它，确保安全。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 25:24–25; 罗马书 8:7; 约翰一书 4:18"> 你是个严厉的人，我很害怕你。我怕你会拿走不属于你的东西，会收走你没有种下的作物。’</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="2 Samuel 1:16; 马太福音 12:37; Job 15:5–6"> 国王回答：‘我要根据你这番话来审判你。你知道我很严厉，会拿走不属于我的东西，会收走我没有种下的作物。</span>
<span className="v" id="v23" data-v="23" data-xref="Exodus 22:25–27; 罗马书 2:4–5; Deuteronomy 23:19–20"> 那你为什么不把我的钱存入银行，等我回来的时候，就可以连本带息取回来？’</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 16:2; 路加福音 12:20"> 国王对身边站着的仆人说：‘把他的钱拿走，交给那赚了十倍的人。’</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 16:2; 2 Samuel 7:19; Isaiah 55:8–9"> 侍卫说：‘但主人，他已经有了十倍的钱了。’</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="约翰二书 1:8; 路加福音 8:18; 马太福音 21:43"> 国王说：‘告诉你们吧，那些已经有的，还会有更多。没有的，现在有的也会被拿走。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 19:14; Psalms 21:8–9; 马太福音 22:7"> 至于那些不愿意我做国王统治他们的敌人，现在把他们拉到这里来，当着我的面杀掉！’”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 9:51; 希伯来书 12:2; 彼得前书 4:1"> 耶稣讲完这个故事，就继续向前朝着耶路撒冷走去。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 1:12; 马太福音 21:17; 马太福音 21:1–11"> 快到伯法其和伯大尼时，他来到了橄榄山，在那里叫来两名门徒，对他们说：</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 22:8–13; 路加福音 19:32; 1 Samuel 10:2–9"> “你们到前面的村子去，进去后会看见有一个地方拴着一头从未有人骑过的小驴，解开它的绳子，把它牵来。</span>
<span className="v" id="v31" data-v="31" data-xref="Psalms 24:1; Psalms 50:10–12; 马可福音 11:3–6"> 如果有人问为什么解开它，你们就说：‘主需要它。’”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="路加福音 22:13"> 两名门徒出发了，后来发生的一切与耶稣所说如出一辙。</span>
<span className="v" id="v33" data-v="33"> 他们解开小驴的时候，驴主人问：“你们为什么解开它？”</span>
<span className="v" id="v34" data-v="34" data-xref="Zechariah 9:9; 约翰福音 10:35; 哥林多后书 8:9"> 他们说：“主需要它。”</span>
<span className="v" id="v35" data-v="35" data-xref="马可福音 11:7–8; 马太福音 21:7; 约翰福音 12:14"> 门徒把小驴牵到耶稣那里，把自己的衣服搭在驴背上，耶稣坐在上面。</span>
<span className="v" id="v36" data-v="36" data-xref="2 Kings 9:13; 马太福音 21:8"> 耶稣骑驴前行，众人把自己的衣服铺在路上。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="约翰福音 12:12–13; Ezra 3:10–13; 马太福音 21:1"> 当他走近耶路撒冷，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="隐喻为“耶路撒冷。”">b</a></sup>这里也是橄榄山的下山路，门徒们因为看见了所有神迹，开始充满喜悦地大声赞美上帝。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="Zechariah 9:9; 路加福音 13:35; Psalms 118:22–26"> 他们大声喊：“奉主之名前来的王，赞颂你！<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="见《诗篇》118:26。">c</a></sup>愿和平降临天堂，愿荣耀降临至高天堂！”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="见《诗篇》148:1。">d</a></sup></span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 4:1–2; 马太福音 23:13; 使徒行传 4:16–18"> 民众中有几个法利赛人对他说：“老师，不要让你的门徒说这些！”</span>
<span className="v" id="v40" data-v="40" data-xref="Habakkuk 2:11; Isaiah 55:12; 马太福音 3:9"> 耶稣说：“我告诉你们，他们若保持沉默，石头就要呼喊了！”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 13:34–35; 约翰福音 11:35; Psalms 119:136"> 耶路撒冷越来越近了，耶稣看见这座城，开始为之哭泣，</span>
<span className="v" id="v42" data-v="42" data-xref="Deuteronomy 32:29; 希伯来书 10:26–29; Isaiah 48:18"> 他说：“我真希望你们——就是你们啊，在今天能知道通往平安的路，但都隐藏起来了，你们看不到。</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 21:20–24; Isaiah 29:1–4; Ezekiel 4:2"> 时间一到，你们的仇敌就会包围过来，搭建斜坡攻击你们，把你们团团围住，困住你们，</span>
<span className="v" id="v44" data-v="44" data-xref="路加福音 21:6; 路加福音 13:34–35; 约翰福音 3:18–21"> 他们会彻底摧毁你们，还有你们的孩子。所有的石头建筑都会轰然倒塌，因为你们在救赎到来之刻拒绝接受。”</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="马太福音 21:12–13; 马可福音 11:15–17; 约翰福音 2:13–17"> 耶稣走进圣殿，赶走做买卖之人<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="尤其是指那些贩卖动物作为献祭的人。">e</a></sup>，</span>
<span className="v" id="v46" data-v="46" data-xref="Isaiah 56:7; Jeremiah 7:11; Psalms 93:5"> 他对他们说：“经文上记着：‘我的殿将用于祷告’<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="引自《以赛亚书》56:7。">f</a></sup>。你们却把它变成贼窝了。”<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="引自《耶利米书》7:11。">g</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="马可福音 11:18; 马太福音 26:55; 马可福音 11:27–33"> 然后他每天都在圣殿里教导众人。祭司长、宗教老师和首领都想杀害他，</span>
<span className="v" id="v48" data-v="48" data-xref="Nehemiah 8:3; 使徒行传 16:14; 约翰福音 7:46–49"> 但又不知道如何下手，因为众人都围着他并聆听。</span>
</div>
</div>

</div>

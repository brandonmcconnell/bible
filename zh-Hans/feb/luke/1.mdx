<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 1:1–3; 彼得后书 1:16–19; 约翰福音 20:31"> 如你所知，很多人都曾试图用文字记录我们参与的成就<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或“已成就”，“已达成。”">a</a></sup>。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 15:27; 使徒行传 26:16; 希伯来书 2:3"> 他们所记录的证据，来自最早见证和传递上帝讯息之人。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 1:1; 使徒行传 26:25; 使徒行传 11:4"> 由于我从始至终都参与其中，所以应该可以准确无误地撰写所发生的一切。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 20:31; 使徒行传 18:25; 哥林多前书 14:19"> 敬爱的提阿非罗们，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“提阿非罗”即爱上帝之人。又见《门徒行传》1:1。">b</a></sup>我之所以这么做，是为了让你们确认自己所学之道完全值得信赖。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="1 Chronicles 24:10; 马太福音 2:1; Nehemiah 12:4"> 希律担任犹太王的那段时间，亚比雅班里有一位名叫撒迦利亚的祭司，他妻子以利沙伯是亚伦的后人。</span>
<span className="v" id="v6" data-v="6" data-xref="Genesis 7:1; Genesis 17:1; 腓立比书 2:15"> 他们的一举一动都遵循上帝正道，严格遵守主所立下的一切诫命规条。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="希伯来书 11:11; Genesis 18:11; 1 Samuel 1:2"> 但他们没有孩子，因为以利沙伯无法生育，而且二人都年岁已高。</span>
<span className="v" id="v8" data-v="8" data-xref="2 Chronicles 8:14; 1 Chronicles 24:19; 2 Chronicles 31:2"> 有一天，撒迦利亚按照排班的时间履行作为上帝祭司的职责，</span>
<span className="v" id="v9" data-v="9" data-xref="2 Chronicles 29:11; Exodus 30:7–8; 1 Chronicles 23:13"> 照惯例抽签后<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="这是类似“选秸秆”的抽签方法，因为希望在这里服侍上帝的人太多。">c</a></sup>，他被选中进入主的圣殿上香。</span>
<span className="v" id="v10" data-v="10" data-xref="Leviticus 16:17; 启示录 8:3; 希伯来书 4:14"> 在烧香的过程，众人都在外面祈祷。</span>
<span className="v" id="v11" data-v="11" data-xref="Exodus 40:26–27; 使徒行传 10:3–4; Judges 13:3"> 这时天使向撒迦利亚显现，立于香坛的右侧。</span>
<span className="v" id="v12" data-v="12" data-xref="Judges 13:22; Judges 6:22; 路加福音 2:9–10"> 撒迦利亚见状颇感惊慌，非常害怕。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="1 Samuel 2:21; 使徒行传 10:31; Genesis 25:21"> 天使说：“撒迦利亚，别害怕，上帝听到了你的祈求。你妻子以利沙伯将为你生下一子，你将为他起名为约翰。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 1:58; Proverbs 23:24; Genesis 21:6"> 这孩子会为你带来欢喜和快乐，许多人都会来庆祝他的降生。</span>
<span className="v" id="v15" data-v="15" data-xref="Jeremiah 1:5; Numbers 6:2–4; 路加福音 7:33"> 他将成为主面前的尊者。他将拒绝喝葡萄酒或其他酒精饮料。在他出生之前就被圣灵充满。</span>
<span className="v" id="v16" data-v="16" data-xref="Isaiah 40:3–5; 马太福音 21:32; Malachi 3:1"> 他将带领众多以色列人，回到主、也就是他们的上帝身边。</span>
<span className="v" id="v17" data-v="17" data-xref="Malachi 4:5–6; 马太福音 11:14; 路加福音 1:76"> 他将以以利亚的圣灵和力量走在前，劝说父亲们关爱自己的儿女，规劝悖逆之人走正道，让民众准备好迎接主。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《玛拉基书》4:5-6。">d</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="Isaiah 38:22; Genesis 17:17; 路加福音 1:7"> 撒迦利亚问天使：“我要如何相信这一切？我老了，我妻子也是一把年纪。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 1:26; 马太福音 18:10; Daniel 9:21–23"> 天使回答：“我是上帝面前的加百列，奉命向你传话，告诉你这个好消息。</span>
<span className="v" id="v20" data-v="20" data-xref="Ezekiel 3:26; Ezekiel 24:27; 路加福音 1:22"> 但你并不相信我所说的一切，所以你会失语，直到我所言之事成真，你才能开口说话。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="Numbers 6:23–27"> 众人正在外面等候撒迦利亚，见他迟迟未从圣殿出来，很是奇怪。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 1:62; 约翰福音 13:24; 使徒行传 21:40"> 但他出来时却真的失语了，无法讲话，只能打手势。于是众人意识到刚才在圣殿中出现了神迹。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="1 Chronicles 9:25; 2 Kings 11:5–7"> 他完成自己的职责后便回了家。</span>
<span className="v" id="v24" data-v="24"> 几天后，他妻子以利沙伯果真怀孕，在家中待了五个月。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="Genesis 30:22–23; Isaiah 54:1–4; Genesis 21:1–2"> 她说：“这一切是主的旨意，他这样待我，便是要让我不再在世人面前感到羞辱。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 2:23; 路加福音 1:19; 约翰福音 7:41"> 在怀孕的第六个月，上帝派天使加百列来到加利利的拿撒勒镇，现身在一个名叫玛利亚的少女面前。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 1:18; Isaiah 7:14; 马太福音 1:16"> 玛利亚当时已与一位名叫约瑟的男人订婚。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="Judges 6:12; Daniel 10:19; 路加福音 1:30"> 天使向她问候，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="天使用了当时常见的问候语，原意为“欢喜”，实际上就等于“你好。”现代版本的翻译在这里会遇到困难，因为天使的原意为“欢呼，被上帝垂青的女人”或“问候你，上帝垂青的女人”，但似乎都不恰当。但如果天使在降临时说“嗨”也不恰当……">e</a></sup>然后对她说“你很幸运，主与你同在。”</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 10:17; 路加福音 1:12; 使徒行传 10:4"> 玛利亚对此颇感困惑，不知道这问候到底意味着什么。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 1:13; 罗马书 8:31; 路加福音 12:32"> 天使说：“玛利亚，不要怕！因为上帝已对你施以恩典。</span>
<span className="v" id="v31" data-v="31" data-xref="Isaiah 7:14; 马太福音 1:21; 马太福音 1:25"> 你将怀孕生子，那婴儿将起名叫耶稣。</span>
<span className="v" id="v32" data-v="32" data-xref="Isaiah 9:6–7; Isaiah 16:5; 2 Samuel 7:11–13"> 他将成为一位伟人，被称为至高上帝之子，上帝将把向其赐予祖先大卫的王位，</span>
<span className="v" id="v33" data-v="33" data-xref="Daniel 2:44; 希伯来书 1:8; Daniel 7:13–14"> 他将永远统治雅各的家园，他的王国将永续存在。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="Judges 13:8–12; 使徒行传 9:6"> 玛利亚问天使：“但这怎能可能？我还是处女。”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 1:18; 约翰福音 1:49; 马太福音 1:20"> 天使回答：“圣灵将降临于你，至高上帝将笼罩于你。那即将诞下的婴儿生而神圣，将被称为上帝之子。</span>
<span className="v" id="v36" data-v="36"> 甚至连你的亲戚以利沙伯都怀孕了，人们说那女人无法生育，现在怀胎已有六个月。</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 19:26; Jeremiah 32:27; 马可福音 10:27"> 对于上帝而言，一切皆有可能。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="罗马书 4:20–21; Psalms 119:38; Psalms 116:16"> 玛利亚说：“我听你的，随时准备服侍上帝，愿你所言的事情发生在我身上。”于是天使便离开了。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 1:65; Joshua 15:48–59; Joshua 10:40"> 稍后，玛利亚准备了一下便急忙赶去犹太山地的一座城市，</span>
<span className="v" id="v40" data-v="40"> 来到撒迦利亚的家。她走进屋向以利沙伯问安。</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 1:67; 使徒行传 4:8; 路加福音 1:44"> 听见玛利亚的问候，以利沙伯腹中的婴儿立刻开始跳动，表达着喜悦。圣灵注入了以利沙伯的体内，</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 1:28; Judges 5:24; Genesis 22:18"> 于是她高声说：“你是一位如此有福的女人，你腹中的婴儿能由你诞下，也是一种福气！</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="约翰福音 20:28; 约翰福音 13:13; 路加福音 2:11"> 我太荣幸了，我主之母能够造访我的寒舍。</span>
<span className="v" id="v44" data-v="44"> 听到你问候的那一刻，我腹中的婴儿就欢喜跳跃。</span>
<span className="v" id="v45" data-v="45" data-xref="约翰福音 20:29; 约翰福音 11:40; 路加福音 11:27–28"> 你真荣幸，因为你已确信，主将把对你的承诺变为现实！”</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="1 Samuel 2:1–10; Psalms 34:2–3; Psalms 35:9"> 玛利亚说：“赞美主！</span>
<span className="v" id="v47" data-v="47" data-xref="Psalms 35:9; 提摩太前书 2:3; Habakkuk 3:18"> 上帝救世主让我如此欢喜，</span>
<span className="v" id="v48" data-v="48" data-xref="Psalms 138:6; Malachi 3:12; 哥林多前书 1:26–28"> 因为我作为他的仆人，尽管身世卑微，他却决定垂青于我。今后万代都会认为我是获得赐福之人。</span>
<span className="v" id="v49" data-v="49" data-xref="Psalms 126:2–3; Psalms 111:9; 以弗所书 3:20"> 全能上帝对我做出伟大之举，他的名字如此神圣。</span>
<span className="v" id="v50" data-v="50" data-xref="Psalms 103:17–18; Exodus 20:6; Genesis 17:7"> 他的怜悯将在尊敬他的世界中传递。<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="原意为“恐惧”，但现代用法中表示一种强烈的恐惧感。">f</a></sup></span>
<span className="v" id="v51" data-v="51" data-xref="Psalms 98:1; Isaiah 52:10; 1 Samuel 2:3–4"> 他凭借其力量<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="原意为“强壮的手臂。”">g</a></sup>，击败了那些自作聪明之人。</span>
<span className="v" id="v52" data-v="52" data-xref="Ezekiel 17:24; 雅各书 4:10; Psalms 107:40–41"> 他能够让位高权重之人跌落王位，让谦卑之人获得升华，</span>
<span className="v" id="v53" data-v="53" data-xref="Psalms 107:8–9; 路加福音 6:21; Psalms 34:10"> 他让饥肠辘辘之人饱餐美食，也让富足之人两手空空。</span>
<span className="v" id="v54" data-v="54" data-xref="Psalms 98:3; Micah 7:20; Isaiah 44:21"> 在他的帮助下，他的仆人以色列将永记他的怜悯，</span>
<span className="v" id="v55" data-v="55" data-xref="Psalms 105:6–10; Genesis 17:19; Psalms 132:11–17"> 正如他向我们先父、亚伯拉罕及其后裔所做的承诺。”</span>
<span className="v" id="v56" data-v="56"> 玛利亚和以利沙伯同住了三个月，然后便返回自己的家。</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="路加福音 1:13; Genesis 21:2–3; 路加福音 2:6–7"> 以利沙伯终于诞下一名男婴。</span>
<span className="v" id="v58" data-v="58" data-xref="路加福音 1:25; 路加福音 1:14; 罗马书 12:15"> 邻居和亲戚们得知主向她施以如此善意，便和她一同庆祝。</span>
<span className="v" id="v59" data-v="59" data-xref="Genesis 17:12; Leviticus 12:3; 腓立比书 3:5"> 到了第八天，他们前来为孩子行割礼，打算让他随父亲的名字叫撒迦利亚。</span>
</div>
<div className="bp">
<span className="v" id="v60" data-v="60" data-xref="路加福音 1:13; 2 Samuel 12:25; 路加福音 1:63"> 但以利沙伯说：“不要，他应该叫做约翰。”</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61"> 众人回答：“但你的亲戚中并没有这样的名字。”</span>
<span className="v" id="v62" data-v="62" data-xref="路加福音 1:22"> 他们通过手势询问孩子的父亲撒迦利亚，询问他的意见。</span>
<span className="v" id="v63" data-v="63" data-xref="路加福音 1:60; Isaiah 30:8; 路加福音 1:13"> 撒迦利亚示意要写字。令众人诧异的是，他写下的是：“他就叫约翰。”</span>
<span className="v" id="v64" data-v="64" data-xref="路加福音 1:20; Exodus 4:15–16; Ezekiel 33:22"> 忽然他再次开口说话了，开始赞美上帝。</span>
</div>
<div className="bp">
<span className="v" id="v65" data-v="65" data-xref="路加福音 1:39; 使徒行传 5:11; 路加福音 7:16"> 这一切让住在周围的人心生敬畏，这个消息很快就传遍整个犹太山地。</span>
<span className="v" id="v66" data-v="66" data-xref="使徒行传 11:21; 路加福音 2:19; 路加福音 2:51"> 众人听闻此事便思量它的含义：“这孩子将会成为怎样的人？”因为很显然，他对上帝而言非常特别。<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="原意为“因主的手与他同在。”">h</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v67" data-v="67" data-xref="Joel 2:28; 路加福音 1:41; 路加福音 1:15"> 婴儿的父亲撒迦利亚体内充满了圣灵，他预言道：</span>
</div>
<div className="bp">
<span className="v" id="v68" data-v="68" data-xref="Psalms 106:48; 路加福音 7:16; Psalms 41:13"> “主就是以色列的上帝，他如此伟大，因为他降临到子民之中，为其赋予自由，</span>
<span className="v" id="v69" data-v="69" data-xref="Psalms 18:2; Ezekiel 29:21; 2 Samuel 22:3"> 他向其仆人大卫的家族赐予伟大的救赎，</span>
<span className="v" id="v70" data-v="70" data-xref="使徒行传 3:21–24; 罗马书 1:2; 彼得后书 1:21"> 正如他自古以来借由其神圣先知所传达的预言。</span>
<span className="v" id="v71" data-v="71" data-xref="Psalms 106:10; Jeremiah 23:6; Zephaniah 3:15–20"> 他承诺拯救我们摆脱敌人，远离那些憎恨我们的人。</span>
<span className="v" id="v72" data-v="72" data-xref="希伯来书 6:13–18; Micah 7:20; Psalms 106:45"> 他怜悯我们的祖先，记得他的圣约，</span>
<span className="v" id="v73" data-v="73" data-xref="Genesis 22:16–18; Psalms 105:9; Deuteronomy 7:8"> 那是他向我们的祖先亚伯拉罕所发誓言。</span>
<span className="v" id="v74" data-v="74" data-xref="提摩太后书 1:7; Zephaniah 3:15–17; Isaiah 54:13–14"> 他让我们摆脱恐惧，从敌人手中拯救我们，</span>
<span className="v" id="v75" data-v="75" data-xref="以弗所书 4:24; 以弗所书 2:10; 提多书 2:11–14"> 这让我们可以毕生遵循正道并服侍于他。</span>
<span className="v" id="v76" data-v="76" data-xref="Malachi 3:1; Isaiah 40:3–5; 马可福音 1:2–3"> 尽管你现在只是一个婴儿，但却会被称为至高上帝的先知，因你将先于主之前，为他铺好道路，</span>
<span className="v" id="v77" data-v="77" data-xref="使徒行传 5:31; 使徒行传 2:38; 使徒行传 10:43"> 通过宽恕其子民的罪，传播救赎的讯息。</span>
<span className="v" id="v78" data-v="78" data-xref="Malachi 4:2; 彼得后书 1:19; 启示录 22:16"> 蒙上帝对我们的关爱怜悯，天堂的黎明将降临照耀我们，</span>
<span className="v" id="v79" data-v="79" data-xref="Isaiah 9:2; 马太福音 4:16; 使徒行传 26:18"> 照亮那些活在黑暗中、笼罩在死亡阴影中的人，引导我们走上平安之路。”</span>

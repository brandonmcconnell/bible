<span className="v" id="v1" data-v="1" data-xref="马太福音 4:23; 罗马书 10:15; 马太福音 9:35"> 不久之后，耶稣周游各城各村讲道，宣扬上帝之国的福音，十二门徒与他同行。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 16:9; 马太福音 27:55–56; 马可福音 15:40–41"> 同行的还有几名女人，都曾受耶稣驱赶恶鬼和治愈疾病。抹大拉的玛利亚就是其中之一，耶稣从她身上驱赶了七个恶鬼。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 4:46–53; 哥林多后书 8:9; 使徒行传 9:36–39"> 还有约亚拿，她是希律的管家古撒的妻子。此外还有苏珊娜和其他女性，她们都在用自己的财物供养耶稣和门徒。</span>
<span className="v" id="v4" data-v="4" data-xref="马可福音 4:1–9; 马太福音 13:2–9"> 当时有许多人聚在一起，还有人从其他城市来到耶稣这里，于是耶稣就讲了一个比喻故事：</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 2:1; 雅各书 1:23–24; 马可福音 4:15"> “有一个农夫出去撒种，这个过程中，有的种子落在路旁，被人踩踏或被空中的飞鸟吃掉。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 3:7–8; 路加福音 8:13; 马可福音 4:5–6"> 有的种子落在石头地上，刚长出来就枯萎了，因为得不着滋润。</span>
<span className="v" id="v7" data-v="7" data-xref="Jeremiah 4:3; 路加福音 8:14; 路加福音 21:34"> 有的落在荆棘丛中，荆棘生长的过程中，让种子无法长大。</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 11:15; 启示录 2:11; 启示录 2:7"> 有的落在肥沃土壤里，于是就蓬勃生长，结出百倍的果实。”耶稣说完这番话，便大声说：“如果你有耳朵，就好好听着！”</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 4:10; 马太福音 13:10; 马太福音 13:18"> 但门徒还是问他：“这比喻是什么意思？。”</span>
<span className="v" id="v10" data-v="10" data-xref="Isaiah 6:9; 马可福音 4:11; 马太福音 11:25"> 他说：“上帝之国的奥秘，只给你们知道。对其他人只能用比喻，‘让他们看，他们却看不见，让他们听，他们却听不懂。’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《以赛亚书》6:9。">a</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 13:19; 马可福音 4:14–20; 雅各书 1:21"> 这比喻的含义是：种子是上帝之道。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦后书 2:9–14; 启示录 12:9; 雅各书 1:23–24"> 落在路旁的种子，意思是人们听到正道后，魔鬼随即来到，将真理从他们思想中夺走，因为魔鬼害怕他们因信任上帝而获得救赎。</span>
<span className="v" id="v13" data-v="13" data-xref="Hosea 6:4; 约翰福音 5:35; Proverbs 12:12"> 落在石头地中的种子，意思是人们听到正道后高兴地接受，但是这道并未在思想中扎根，他们只是暂时相信，遭遇困难的时候就会放弃。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰一书 2:15–17; 提摩太前书 6:9–10; 提摩太前书 6:17"> 落在荆棘中的种子，意思是人们听到了正道，但他们却被今世的忧虑、财富和欢喜所占据，无法产生任何结果。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 10:36; 加拉太书 5:22–26; 歌罗西书 1:10"> 落在肥沃土壤里的种子，意思是那些为人诚实、行为正确的人，他们听到了真理的正道，然后始终坚守，熬过困难，直到结出果实。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 11:33; 马太福音 5:15–16; 马可福音 4:21–22"> 你点灯的时候不会用器皿将其盖上，也不会将灯放在床下，而是要放在灯台上，让进来的人都看得见光。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 12:2–3; 马太福音 10:26; 马可福音 4:22"> 因为隐藏之事最终会显现，遮蔽之事最终会暴露，为众人所知。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 13:12; 路加福音 19:26; 马可福音 4:23–25"> 所以应留心怎样‘听’。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“听”在这里意味着聆听并遵循上帝的讯息。">b</a></sup>如果你已经被给予，就会被给予更多。如果你从未被给予，就连你自以为拥有的，也会被夺走！”</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 12:46–50; 马可福音 3:31–35; 马可福音 3:21"> 耶稣的母亲和弟弟来到他那里，因为人多，所以无法上前。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 1:14; 马可福音 6:3; 马太福音 13:55–56"> 有人转告耶稣：“你母亲和弟弟站在外面要见你。”</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 11:27–28; 雅各书 1:22; 约翰福音 13:17"> 他回答：“听从上帝之道并遵守之人，才是我的母亲，我的兄弟。”</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 8:23–27; 马可福音 4:35–41; 马可福音 6:45"> 有一天，耶稣对他的门徒们说：“我们坐船到湖那边去吧。”于是他们就上船出发了。</span>
<span className="v" id="v23" data-v="23" data-xref="Psalms 93:3–4; Psalms 124:2–4; Psalms 148:8"> 在船航行的过程中，耶稣睡着了。湖上忽然刮起风暴，船体灌进大量的水，很可能会沉没。</span>
<span className="v" id="v24" data-v="24" data-xref="Psalms 107:25–29; 路加福音 4:39; Psalms 104:6–9"> 门徒叫醒耶稣，说：“主人！主人啊！我们要沉没了！”耶稣醒过来，命令风浪退去，于是风浪就停止了，一切归于平静。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 8:26; Proverbs 30:4; 马可福音 4:40–41"> 耶稣对他们说：“你们的信心到哪里去了？”他们又惧怕、又惊奇，对彼此说：“这到底是谁？他可以命令风浪，连风浪都听他的！”</span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 5:1–20; 马太福音 8:28–34"> 一行人航行来到了加利利对面，这里是格拉森人的地区。</span>
<span className="v" id="v27" data-v="27" data-xref="马可福音 5:2–5; 1 Samuel 19:24; Numbers 19:16"> 耶稣一上岸，迎面就看到城里一个被恶鬼附体之人。很久以来，这个人都没有穿衣服，也没有住在自己的家中，只能栖身坟墓。</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 8:29; 彼得后书 2:4; 马可福音 5:6–8"> 他一见耶稣，就俯伏在耶稣脚边，大声说：“至高上帝之子耶稣，你想要我怎样呢？不要折磨我，求你！”</span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 5:3–5; 路加福音 9:39; 提摩太后书 2:25–26"> 因为耶稣曾对这人驱赶过恶灵，但这恶灵总是附在他身上，人们不得不把他用铁链和脚炼捆住，再派人看管。但他总是能挣断锁链，在魔鬼的驱使下进入荒野。</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 26:53; 路加福音 8:2; 马太福音 8:29"> 耶稣问他：“你叫什么名字？”他说：“众鬼。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或“很多。”">c</a></sup>因为有很多恶鬼附体在他的身上。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 25:41; 腓立比书 2:10–11; Job 2:5"> 众鬼求耶稣，不要赶它们进入无底深渊。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“深处”或“无底之坑。”">d</a></sup></span>
<span className="v" id="v32" data-v="32" data-xref="Isaiah 65:4; Isaiah 66:3; 启示录 20:7"> 附近山坡上有一大群猪正在吃东西。恶鬼们求耶稣准它们进入猪群。耶稣准许了。</span>
<span className="v" id="v33" data-v="33" data-xref="彼得前书 5:8; 约翰福音 8:44; 路加福音 8:22–23"> 恶鬼们就从那人身上出来，进入猪群，猪群闯下山崖，掉在海里淹死了。</span>
<span className="v" id="v34" data-v="34" data-xref="马可福音 5:14; 马太福音 8:33; 马太福音 28:11"> 猪倌看见所发生的事就跑开了，到城市和乡村中讲述这件事。</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 10:39; 使徒行传 22:3; 约翰一书 3:8"> 众人纷纷过来查看发生了什么事。来到耶稣那里，看见恶鬼已经被驱赶。那人已经身穿衣服，神志清醒，坐在耶稣脚前，众人感到害怕。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 4:24"> 当时目睹这一幕的众人，把鬼附体之人如何得到治愈的经过说给大家听。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 16:39; 路加福音 8:28; 路加福音 10:10–11"> 于是格拉森地区的人要求耶稣离开他们，因为他们感到特别恐惧。于是耶稣便上船返回。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 9:13–16; 马可福音 5:18–20; Psalms 145:3–12"> 被驱魔的那人想要追随耶稣，于是就求耶稣。但耶稣让他回去，说：</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 17:15–18; 提摩太前书 5:8; Deuteronomy 10:21"> “你回家去吧，告诉众人上帝为你做了什么。”于是那人走遍全城，讲述耶稣为他所做的事情。</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 9:1; 马可福音 5:21; 马可福音 6:20"> 耶稣回来的时候，众人欢迎他，因为大家都在热切地等着他。</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 5:22–43; 路加福音 13:14; 使徒行传 18:8"> 有一个名叫睚鲁的会堂主管，他俯伏在耶稣脚前，求耶稣去他家，</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 7:12; 路加福音 8:45; Job 1:18–19"> 因为他大约 12 岁的独生女快要死了。在耶稣去往那人家中的路上，身边一直围绕着众多民众。</span>
<span className="v" id="v43" data-v="43" data-xref="马可福音 5:25–26; 马太福音 9:20–22; Leviticus 15:25–33"> 人群中有一个女人患有十二年的血漏病，治病花光了她所有积蓄，却始终没能医好。</span>
<span className="v" id="v44" data-v="44" data-xref="马可福音 5:27–28; Deuteronomy 22:12; 使徒行传 19:12"> 她从人群后面挤上前来，摸着耶稣的斗篷，血立刻止住了。</span>
<span className="v" id="v45" data-v="45" data-xref="马可福音 5:30–32; 路加福音 9:13; 路加福音 5:5"> 耶稣问：“谁在触摸我？”众人都说不是自己。 彼得说：“主啊，众人都簇拥在你身边，他们推推搡搡会碰到你。”</span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 6:19; 路加福音 5:17; 彼得前书 2:9"> 耶稣回答：“一定是有人触摸我，我知道，因为一股力量从我身体流出去了。”</span>
<span className="v" id="v47" data-v="47" data-xref="马可福音 5:33; 路加福音 17:15–16; 哥林多前书 2:3"> 那女人见不能隐瞒，就战战兢兢地走上前，俯伏在他面前，当着众人的面讲述触摸他的原因，以及如何立刻痊愈。</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 7:50; 马太福音 9:22; 希伯来书 4:2"> 耶稣对她说：“女儿，你的信任已经拯救了你，安心地去吧。”</span>
<span className="v" id="v49" data-v="49" data-xref="马可福音 5:35–43; Isaiah 7:12; 路加福音 7:6"> 耶稣说话的过程中，有人从会堂主管家里过来，说：“你的女儿死了，不必再劳烦老师了。”</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 11:40; 约翰福音 11:25; 马可福音 5:36"> 耶稣听见这句话，就对主管说：“不要怕，只要你有信心，她必会痊愈。”</span>
<span className="v" id="v51" data-v="51" data-xref="马可福音 14:33; 马太福音 6:5–6; 1 Kings 17:19–23"> 到了主管的房子后，除了彼得、约翰、雅各和女孩的父母以外，他不准任何人与他走进屋子。</span>
<span className="v" id="v52" data-v="52" data-xref="路加福音 23:27; 约翰福音 11:4; Zechariah 12:10"> 众人都在为女孩痛哭哀号。 他说：“不要哭，她没有死，只是睡着了。”</span>
<span className="v" id="v53" data-v="53" data-xref="路加福音 16:14; Isaiah 53:3; 约翰福音 11:39"> 众人知道女孩已经死了，于是就嘲笑他。</span>
<span className="v" id="v54" data-v="54" data-xref="Jeremiah 31:32; 约翰福音 11:43; 马可福音 1:31"> 他走进去拉着女孩的手，大声对她说：“孩子，起来！”</span>
<span className="v" id="v55" data-v="55" data-xref="约翰福音 11:44; 1 Kings 17:21–23; 马可福音 5:43"> 于是她就死而复生，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原意“她的呼吸/灵魂返回了”这个词用作呼吸和灵魂时，都是同一个意思。">e</a></sup>立刻站起来。耶稣吩咐众人给她东西吃。</span>
<span className="v" id="v56" data-v="56" data-xref="马太福音 8:4; 马太福音 9:30; 路加福音 5:14"> 她父母非常震惊。耶稣嘱咐他们不要把这件事告诉其他人。</span>

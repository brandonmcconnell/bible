<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="feb" data-translation-id="cmn_feb" data-translation-label="易读圣经" data-book="LUK" data-book-slug="luke" data-book-name="路加福音" data-chapter="21" data-verses="38">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 12:41–44; 约翰福音 8:20; 马太福音 27:6"> 耶稣环顾四周，看见有钱人把捐赠投入奉献箱。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="在圣殿中。（见 20:1。）">a</a></sup></span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 12:42"> 他又看见一个穷寡妇，在里面投入两个小钱。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="小零钱叫做雷普塔。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 8:12; 使徒行传 10:34; 哥林多后书 8:2–3"> 于是耶稣说：“实话告诉你们，穷寡妇所投入的要比其他所有人加一起还要多。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 2:44–45; 路加福音 15:12; 使徒行传 4:34"> 因为其他人只是自己财富的一部分投进去，这寡妇虽然很穷，却献出了赖以为生的所有金钱。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 2:20; 马太福音 24:1–51; 马可福音 13:1–37"> 那里有人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="也许是他的几位门徒，见《马可福音》13:1。">c</a></sup>在讨论圣殿以及它精美的石艺和供物装饰。但耶稣说：</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 24:2; 马可福音 13:2; Lamentations 5:18"> “你们看见的这些......在那一刻到来之时，所有垒砌的石头都会倒塌，一切都会被摧毁。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行传 1:6–7; 马可福音 13:14; 马可福音 13:3–4"> 他们问他：“老师，这会在什么时候发生？发生的时候会有什么预兆？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约翰一书 4:1; 马可福音 13:5–6; 以弗所书 5:6"> 耶稣提醒他们说：“你们要小心，不要被人迷惑。因为会有很多人来假冒我的名<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或“以我名义到来。”">d</a></sup>，说‘我就是基督！’，还会说‘时候到了！’但不要跟随这些人。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 21:28; 马太福音 24:6–8; 马可福音 13:7–8"> 当你们听到战乱和暴动，不要惊慌，因为这样的事情一定会先出现，但不会马上看到结局。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 2:19–20; 马可福音 13:8; 2 Chronicles 15:5–6"> 耶稣对他们说：“民族之间要有战争，国家之间要有战争。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 24:29–30; 路加福音 21:25–27"> 到时候会有剧烈的大地震，处处是饥荒和瘟疫，天空显现可怕的恐怖预兆。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 4:12–14; 使徒行传 5:40; 使徒行传 22:30"> 但在这一切发生之前，他们会抓住你们，迫害你们，把你们拖到会堂前，扔进监狱里，甚至会押到国王和总督面前。</span>
<span className="v" id="v13" data-v="13" data-xref="腓立比书 1:12; 腓立比书 1:28; 帖撒罗尼迦后书 1:5"> 但这会为你们提供一个机会，在他们面前代表我发言。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 12:11–12; 马可福音 13:11; 马太福音 10:19–20"> 所以，你们要提前坚定决心，不必提前思量如何进行自我辩护。</span>
<span className="v" id="v15" data-v="15" data-xref="Jeremiah 1:9; 以弗所书 6:19; 路加福音 12:12"> 因为我会让你们说出睿智之语，让所有的敌人都不能辩论或反驳。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 12:53; 启示录 6:9; Micah 7:5–6"> 你们将会被父母、兄弟、亲戚和朋友出卖，你们中有的人会被他们害死。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 15:19; 路加福音 6:22; 约翰福音 15:21"> 因为我，你们会被众人恨恶，</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 10:30; 1 Samuel 14:45; 路加福音 12:7"> 但你们却可以毫发无伤。</span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 10:36; 马太福音 10:22; 雅各书 1:3"> 只要坚定自己的立场，就会获得自己的生命。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="意为永生，或你真正想要拥有的一切。">e</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 19:43; Daniel 9:27; 马可福音 13:14"> 但是，当你们看见耶路撒冷被军队团团围住，就知道它距离摧毁的日子已经不远了。</span>
<span className="v" id="v21" data-v="21" data-xref="Jeremiah 6:1; Genesis 19:17; 路加福音 17:31–33"> 住在犹太的必须逃到山上；住在城里的必须离开；住在乡下的不要进城。</span>
<span className="v" id="v22" data-v="22" data-xref="Hosea 9:7; Isaiah 65:12–16; Isaiah 63:4"> 因为这是惩罚的日子，经书上所写的一切都会变成现实。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马可福音 13:17; 马太福音 24:19; 路加福音 23:29"> 到那时，怀孕和哺乳婴儿的女人将会很艰难！因为可怕的灾难将降临这片土地，众人都将被惩罚。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 11:25; 启示录 11:2; Isaiah 63:18"> 他们将被刀屠杀，俘虏到各国并被投入监狱，耶路撒冷必被异教徒践踏，直到异教徒占领的时间结束。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="Isaiah 13:10; Joel 2:30–31; 启示录 6:12–14"> 日月星辰都会有预兆，世界的国家会因海洋的波涛汹涌而陷入苦难。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 24:29; Deuteronomy 28:65–67; 彼得后书 3:10–12"> 天上的力量震撼世界，这个世界即将发生的事情让人们陷入恐惧，这恐惧会让人虚弱。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 24:30; 启示录 1:7; 马可福音 13:26"> 到那时，他们会看见人子携力量和伟大荣耀，驾云降临。<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="见《但以理书》7:13-14。">f</a></sup></span>
<span className="v" id="v28" data-v="28" data-xref="罗马书 8:23; Isaiah 60:1–2; 以弗所书 4:30"> 在发生这一切的时候，你们应当昂首挺立向上看，因为你们很快就会被救赎。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马太福音 24:32–35; 马可福音 13:28–30"> 然后耶稣举例讲了一个故事：“看看这无花果树或其他的树木。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 12:57"> 看到它们发芽，你就知道夏天将至。</span>
<span className="v" id="v31" data-v="31" data-xref="雅各书 5:9; 希伯来书 10:37; 彼得前书 4:7"> 同样，当你们看到这些事情发生，无需别人告诉你，就知道上帝之国已近。</span>
<span className="v" id="v32" data-v="32" data-xref="马可福音 13:30; 马太福音 24:34; 马太福音 23:36"> 我告诉你们真相，这一代人在有生之年定会看到这一切。</span>
<span className="v" id="v33" data-v="33" data-xref="Isaiah 40:8; 马可福音 13:31; 马太福音 24:35"> 天地都将走向终结，但我的教诲不会消失。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马可福音 4:19; 路加福音 12:45–46; 路加福音 12:40"> 小心，不要因各种派对、贪图美酒和生活困苦分散了你的注意力，因为那一天<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="“那一天”即人子到来之时。">g</a></sup>会突然降临，</span>
<span className="v" id="v35" data-v="35" data-xref="启示录 16:15; Psalms 11:6; Jeremiah 48:43–44"> 那一天会波及地球上的所有人。</span>
<span className="v" id="v36" data-v="36" data-xref="约翰一书 2:28; 马太福音 25:13; 彼得前书 5:8"> 你们要时刻警醒和祈祷，这样才有可能逃离这将要发生的事情，才可以站在人子面前。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="路加福音 22:39; 马可福音 11:19; 马太福音 21:17"> 耶稣每天都在白天到殿里教导，晚上到橄榄山中过夜。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 8:1–2"> 群众清早起来上圣殿，到他那里听他讲道。</span>
</div>
</div>

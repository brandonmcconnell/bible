<span className="v" id="v1" data-v="1" data-xref="彼得前书 1:5; 帖撒罗尼迦前书 5:23; 彼得前书 2:9"> 这封信函来自耶稣基督的仆人、雅各的兄弟犹大，写给那些被蒙招之人，那些被父上帝所爱、由受耶稣基督保护之人。</span>
<span className="v" id="v2" data-v="2" data-xref="彼得后书 1:2; 彼得前书 1:2; 启示录 1:4–6"> 愿你们感受到上帝更多的怜悯、平安和慈爱。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前书 6:12; 腓立比书 1:27; 犹大书 1:20"> 我的朋友们，我非常期待在信中讲述我们所分享的救赎。但现在我需要通过信函紧急告诉你们，鼓励你们大力捍卫关于上帝的真理，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为：“信任”或“信仰。”">a</a></sup>这些真理已经一次性且永远地全部<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“一次性全部”：在历史中，上帝曾多次在不同时间揭示关于他的真相。这里的意思可能是：上帝通过他自己在耶稣身上做出了美启示。">b</a></sup>赐给上帝的圣徒。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得后书 2:1–3; 加拉太书 2:4; 彼得后书 2:10"> 因为有些人悄悄混入你们中间。很久以前就有人写到他们，对他们进行谴责，因为他们是邪恶之人，歪曲上帝的恩典，将其变成不道德的放纵行为，同时否认我们的主和主耶稣基督。</span>
<span className="v" id="v5" data-v="5" data-xref="Numbers 26:64–65; 希伯来书 3:16–2; 哥林多前书 10:1–12"> 尽管你们已经知道了，但我还是要提醒你们，主虽然把他的百姓从埃及的土地上救了出来，但后来他还是毁灭了那些不信之人。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得后书 2:4; 马太福音 25:41; 以弗所书 6:12"> 即使是那些不满足于上帝所赐地位、放弃其应有位置的天使，上帝也会将其置于永恒的黑暗锁链中，直到那伟大的审判日。</span>
<span className="v" id="v7" data-v="7" data-xref="Deuteronomy 29:23; 彼得后书 2:6; 罗马书 1:26–27"> 同样，所多玛、蛾摩拉和附近那些追逐不道德和变态淫乱的城镇，也是将遭受永恒之火惩罚的例子。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="这里的“永恒”是指其后果，而不是指持续时间——从上下文中可以明显看出，这是审判永恒的结束。第7节中的“永恒之火”同样适用于所多玛和蛾摩拉作为例子所体现的：这将是一种永恒的影响，但成真现在没有燃烧，也不会“永远”燃烧。">c</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 13:17; 彼得前书 2:17; 彼得后书 2:10–12"> 同样，这些梦想家<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="参考在第 4 段中所述的人。">d</a></sup>污染了自己的身体藐视权威，毁谤神圣之人。</span>
<span className="v" id="v9" data-v="9" data-xref="Zechariah 3:2; 彼得后书 2:11; Deuteronomy 34:6"> 即使是天使长米迦勒，当他为了摩西的尸体与魔鬼争论时，也不敢用毁谤的语言定他的罪，只说：“愿主责备你！”</span>
<span className="v" id="v10" data-v="10" data-xref="彼得后书 2:12; 罗马书 1:21–22"> 但这些人嘲笑他们不理解的东西；而他们理解的东西却像不思考的动物一样本能地追随--这就是摧毁他们的原因。</span>
<span className="v" id="v11" data-v="11" data-xref="彼得后书 2:15; 约翰一书 3:12; 启示录 2:14"> 他们现在面对可怕的灾祸，因为他们走上了该隐的道路，就像巴兰和他的妄想，他们出于利益的动机而放弃了自己。就像可拉和他的叛乱，他们毁灭了自己。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得后书 2:17–20; 马太福音 15:13; Ezekiel 34:8"> 这些人破坏其他人的饭菜，因为他们是自私的牧羊人，没有丝毫羞耻心，只顾自己。他们是被风吹走的云，不会带来雨水。他们是光秃秃的树，不会结果——两次死亡，连根拔起。</span>
<span className="v" id="v13" data-v="13" data-xref="彼得后书 2:17; 腓立比书 3:19; Isaiah 57:20"> 他们是汹涌的海浪，溅起耻辱的泡沫。他们是虚假的星辰，注定永远陷入黑暗。</span>
<span className="v" id="v14" data-v="14" data-xref="Deuteronomy 33:2; Psalms 50:3–5; 希伯来书 11:5–6"> 亚当第七世孙以诺也曾对这些人做出预言：“看！主正在与他千万圣者降临，</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 2:16; Ecclesiastes 11:9; 哥林多前书 4:5"> 审判众人，揭露世人所做的一切恶事，以及敌对的罪人对其说的所有可怕之语。”</span>
<span className="v" id="v16" data-v="16" data-xref="彼得后书 2:18; 彼得后书 2:10; 腓立比书 2:14"> 这样的人总是在发牢骚，总是在抱怨。他们追随自己的邪恶欲望，自吹自擂，通过奉承他人获得他们想要的东西。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得后书 3:2; 约翰一书 4:6; 以弗所书 4:11"> 但你们呢，亲爱朋友们，请记住我们主耶稣基督的使徒从前所说的话。</span>
<span className="v" id="v18" data-v="18" data-xref="彼得后书 3:3; 提摩太后书 4:3; 提摩太后书 3:1–5"> 他们曾向你们解释：在末世，必有喜欢嘲弄之人，追随自己的邪恶欲望。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="见《彼得后书》3:3。">e</a></sup></span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 2:14; Proverbs 18:1; 罗马书 8:9"> 这些人会分裂，他们是没有灵的世俗之人。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 6:18; 罗马书 8:26–27; 哥林多前书 14:15"> 但我的朋友们，你们要通过对上帝的信任来成就自己。以圣灵的名义进行祈祷，</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 4:16; Lamentations 3:25–26; 希伯来书 9:28"> 在上帝的爱中保护自己，等候带来永生之主耶稣基督的怜悯。</span>
<span className="v" id="v22" data-v="22" data-xref="雅各书 5:19–20; 加拉太书 6:1; 约翰一书 5:16–18"> 向心里疑惑之人予以怜悯；</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太前书 4:16; 哥林多前书 15:33; 启示录 3:4"> 在你力所能及的情况下，把他们从火中抢救出来。显示你的怜悯，但要非常小心，甚至要憎恨那些被罪恶人性污染的“衣服。”<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="换言之，对罪人仁慈的同时，要小心人类身上穿着的“罪衣”，防止自己被“传染。”">f</a></sup></span>
<span className="v" id="v24" data-v="24" data-xref="提摩太后书 4:18; 以弗所书 3:20; 歌罗西书 1:22"> 现在，通过我们的主耶稣基督，愿那可以保护你们不会坠落的主，那能以无可挑剔的方式带来极大喜乐、将你们带到其荣耀之地的主，</span>
<span className="v" id="v25" data-v="25" data-xref="提摩太前书 1:17; 启示录 5:13–14; 彼得前书 5:10–11"> 那唯一的上帝、我们的救世主， 愿他在过去、现在和未来，拥有所有荣耀、威严、能力和权威。 阿门。</span>
</div>

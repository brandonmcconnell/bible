<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 1:12–13; 约翰福音 8:42; 约翰一书 2:29"> 凡信耶稣就是基督的人，都是源自上帝；爱父亲的人，也必会爱他的孩子。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 13:34–35; 约翰一书 2:5; 约翰一书 3:22–24"> 当我们爱上帝，遵守他的命令，就知道我们在爱上帝的孩子。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 14:15; 约翰福音 15:10; 约翰福音 14:21–24"> 我们遵守上帝的命令，就是爱上帝；他的命令遵守起来并不困难，</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 15:57; 约翰一书 4:4; 约翰福音 16:33"> 因为源自上帝的人就会战胜这世界。想要获得胜利并战胜这世界，就要相信上帝。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰一书 4:15; 约翰一书 5:1"> 只有那些相信耶稣、坚信他就是上帝之子的人，才能战胜这世界。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 15:26; 希伯来书 9:14; 约翰福音 16:13"> 那借由水和血而来的，就是耶稣基督。他不只是借由水而来，而是借由水和血而来。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这通常被解释为：洗礼的水，意味着他死亡的血。">a</a></sup>灵提供了证据来证实这一点，因为灵就是真理。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 28:19; 哥林多后书 13:14; 使徒行传 5:32"> 所以这里有三个证据：</span>
<span className="v" id="v8" data-v="8" data-xref="约翰一书 5:6–7; 约翰福音 15:26; 彼得前书 3:21"> 灵、水和血，这三样都是一致的。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="第 7 段和第 8 段的真实性一直存在争议。">b</a></sup></span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 3:16–17; 马太福音 17:5; 使徒行传 17:31"> 如果我们都能接受人类证人提供的证据，那么上帝提供的证据就更重要。上帝提供的证据，就是他对其子的见证。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 8:16; 加拉太书 4:6; 约翰福音 3:33"> 那些信上帝之子的人，已经接受并坚持这样的证据。那些不相信上帝的人，会认为上帝是个骗子，因为他们不相信上帝所提供关于其子的证据。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 6:23; 约翰一书 2:25; 约翰福音 3:36"> 这证据就是：上帝已将永恒生命赐给我们，我们则借由他的儿子拥有这生命。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 3:36; 约翰福音 5:24; 约翰福音 1:12"> 有上帝之子便有生命；没有上帝之儿子就没有生命。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 20:31; 约翰福音 1:12; 彼得后书 1:10–11"> 我写这封信，就是要告诉那些相信上帝儿子之名的人，让你们可以确定自己拥有永恒的生命。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 14:13; Jeremiah 33:3; Jeremiah 29:12–13"> 我们可以相信的是：只要我们根据他的意愿提出要求，他会听我们所说的一切。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 11:9–10; 马可福音 11:24; Proverbs 15:29"> 如果我们知道他已听到我们的请求，就可以确定会得到所求的一切。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 6:4–6; 1 Samuel 2:25; Jeremiah 11:14"> 如果你看到其他基督徒兄弟姐妹犯下并不致命的罪，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="致命的罪。原意为“会死的罪行。”">c</a></sup>你应该祈祷，上帝会赐给有罪之人以生命。（但不能是致命的罪。有一种罪是致命的，我不是说人们应该这样祈祷。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰一书 3:4; 约翰一书 5:16; 雅各书 4:7–10"> 是的，所有不正直良善的都是罪，但也有不致命的罪。）</span>
<span className="v" id="v18" data-v="18" data-xref="约翰一书 3:9; 约翰一书 5:4; 约翰一书 5:1"> 我们意识到，那些生自上帝的人不会持续犯罪。上帝的儿子<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="从字面上看，就是上帝所生的那一位，延续了本节最初一段的意思。下面的内容清楚地表明了这种概念。">d</a></sup>保护他们，魔鬼不能伤害他们。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多后书 4:4; 约翰一书 4:4–6; 以弗所书 2:2"> 我们知道我们属于上帝，以及世界处于恶者的权势之下。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 17:3; 路加福音 24:45; 约翰福音 14:9"> 我们也知道上帝的儿子已经到来，帮助我们理解，让我们意识到哪一位才是正确的。我们就活在真实的他中，在他儿子耶稣基督之中。他就是真正的上帝，是永恒的生命<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="这里可以理解为：他赐予永恒声明，也可以理解为他是永生的。">e</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 10:14; 哥林多前书 10:7; Exodus 20:3–4"> 亲爱的朋友们，要远离那些神像崇拜。</span>

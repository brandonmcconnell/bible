<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 1:12; 加拉太书 3:26; 哥林多后书 6:18"> 你们看，父赐给我们的爱是多么惊人！这就是为什么我们可以被称为上帝的孩子——因为我们的确如此！所以这个世界的人没有把我们看作上帝的孩子，是因为他们不认识父。</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比书 3:21; 歌罗西书 3:4; 哥林多前书 13:12"> 我的朋友们，我们已经是上帝的孩子；但我们未来会怎样，还没有显明；我们知道，当他出现的时候，我们一定就会像他，因为我们一定会看见他本来的样子。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 7:1; 约翰一书 2:6; 彼得后书 3:14"> 凡对他们心存希望的人，务必要让自己纯粹，就像他一样纯粹。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰一书 5:17; 罗马书 3:20; 罗马书 4:15"> 凡是有罪的，就是违反了法律，因为罪就是无法无天。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 5:21; 希伯来书 9:28; 彼得前书 3:18"> 但你们当然知道，主到来是除掉罪，他自己没有罪。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰三书 1:11; 约翰一书 2:4; 约翰一书 3:9"> 凡是住在他里面的，就不会有罪；凡有罪的，就是未曾见过他，也不认识他。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰一书 2:29; 彼得前书 1:15–16; 罗马书 2:13"> 亲爱的孩子们，不要让任何人欺骗你们，那些遵循正义良善的人，才是正义良善，正如主也是正义良善。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 2:14; 约翰福音 8:44; 歌罗西书 2:15"> 那些有罪的，都是源自魔鬼，因为魔鬼从最初就有罪。所以上帝之子才会出现，就是为了消灭魔鬼所做的一切。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 5:18; 彼得前书 1:23; 约翰福音 1:13"> 所有源自上帝的人就不会有罪，因为上帝的天性<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“他的种子。”">a</a></sup>就在他们之中；他们不能有罪，因为是上帝生了他们。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 4:8; 约翰三书 1:11; 路加福音 6:35"> 所以通过这种方式，就可以分辨谁是上帝的孩子，谁是魔鬼的孩子。那些从不做正义良善之事的人，就不属于上帝；不爱其他基督徒的人也是如此。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 15:12; 约翰二书 1:5; 约翰一书 4:7"> 你们从最初听见的讯息非常简单：我们应当彼此相爱，</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 11:4; Genesis 4:4–15; Proverbs 29:27"> 我们不能像该隐那样，他属于邪恶之人，又杀了自己的弟弟。他为什么杀自己的弟弟？因为他做的是罪恶行为，他弟弟做出的是正义良善的行为。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 15:18–19; 约翰福音 17:14; 路加福音 21:17"> 我的朋友们，如果世界恨你们，不要惊讶。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 13:35; 约翰一书 5:2; 约翰一书 4:20–21"> 我们之所以知道自己从死亡变成生命，是因为我们爱其他基督徒弟兄姐妹。 任何不爱的人仍然是死的。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 5:21–22; Proverbs 26:24–26; 启示录 21:8"> 那些恨其他基督徒弟兄姐妹的人，就是在杀人。你们知道，杀人之人就不会生活在永恒生命之中。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰一书 4:9–11; 以弗所书 5:2; 约翰福音 13:34"> 耶稣为我们舍弃自己的生命，我们是通过这种方式知道什么是爱；我们也应当为其他基督徒兄弟姐妹舍弃自己的生命。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 13:16; Isaiah 58:7–10; Deuteronomy 15:7–11"> 如果你们有人在这世上生活的很富有，看见其他基督徒兄弟姐妹生活穷乏，却从未显示怜悯，又怎能说你心中有上帝的爱呢？</span>
<span className="v" id="v18" data-v="18" data-xref="雅各书 2:15–16; 罗马书 12:9; 彼得前书 1:22"> 亲爱的朋友们，不要只是说我们爱，而是要用行动、我们如何展示真理，以此显示我们的爱。</span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 10:22; 约翰一书 3:21; 希伯来书 6:10–11"> 只有这样，我们才知道自己属于真理。但在上帝面前，我们仍然可以安心<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“心。”古人相信心脏是人类思考的器官。">b</a></sup>，</span>
<span className="v" id="v20" data-v="20" data-xref="Psalms 139:1–4; Jeremiah 17:10; 希伯来书 4:13"> 无论何时我们认为自己做错了，因为他比我们想的还要伟大，他知道一切。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 2:28; 希伯来书 4:16; 哥林多后书 1:12"> 我亲爱的朋友，如果我们因为没有做错事而感到有信心，我们在上帝面前就可以坦然。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 15:7; 约翰福音 9:31; 约翰一书 5:14"> 我们向他求的一切，他都会给我们，因为我们遵从他的命令，作让他快乐的事情。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 6:29; 约翰福音 13:34; 彼得前书 1:22"> 上帝的命令就是：我们应该相信他的儿子耶稣基督之名<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="这里的名字不只是出生后起的名字，也是从性格和声誉角度所指的名。">c</a></sup>，按照他的吩咐彼此相爱。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 3:16; 约翰一书 4:15–16; 约翰一书 4:12–13"> 凡是遵从上帝命令的人，就会一直住在上帝里面，上帝也住在他之中。我们知道，上帝凭着赐给我们的灵，生活在我们之中。</span>

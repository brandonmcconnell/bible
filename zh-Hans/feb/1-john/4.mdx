<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 5:21; 彼得后书 2:1; 提摩太前书 4:1"> 亲爱的朋友，不要相信所有灵，而是要对灵进行考验，看看这些灵是否出于上帝，因为已有许多假先知来到这世界。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 1:14; 哥林多前书 12:3; 提摩太前书 3:16"> 你们如何识别上帝的灵？凡是承认耶稣基督以人类的身形来到这世界，那灵就是来自上帝。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰一书 2:22; 约翰二书 1:7; 约翰一书 2:18"> 那些不接受耶稣的灵，就不是来自上帝。事实上，这样的灵是反基督的灵，你们听过他要来，现在他已经来到这世界。</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 8:31; 约翰一书 5:4; 罗马书 8:37"> 但你们属于上帝，并且已经胜过他们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="所指的是假先知以及激励他们的灵。">a</a></sup>，因为在你们之中的那一位，远比已在这世上的那一位更伟大。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 8:23; 彼得后书 2:2–3; 约翰福音 17:14"> 他们属于这个世界，所以都用着这个世界的说话方式，这个世界也就听他们的。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 14:17; 约翰福音 10:27; 哥林多前书 2:12–14"> 我们属于上帝，认识上帝的就会听我们的，不属于上帝的就不会听我们的。通过这种方式，我们就可以辨别真理的灵和谬误的灵。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰一书 4:20–1; 约翰一书 4:8; 彼得前书 1:22"> 亲爱的朋友们，让我们继续彼此相爱，因为爱来自上帝。爱其他人，你就是上帝所生，就认识上帝。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰一书 4:16; Psalms 86:15; 哥林多后书 13:11"> 不爱其他人，就不认识上帝，因为上帝就是爱。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 3:16; 约翰一书 5:11; 罗马书 8:32"> 上帝如何向我们显明爱？上帝派他唯一的独子来到这个世界，要让我们可以借着他而活；</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 2:4–5; 罗马书 5:8–10; 约翰一书 4:19"> 这就是爱！不是我们爱上帝，而是上帝爱我们，他派他的儿子成为我们的罪被赦免的手段。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 15:12–13; 歌罗西书 3:13; 约翰福音 13:34"> 朋友们，如果上帝就是通过这种方式爱我们，我们也应当以这种方式彼此相爱。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 1:18; 约翰一书 2:5; 约翰一书 4:17–18"> 没有人曾见过上帝。但如果我们彼此相爱，上帝就住在我们之中，他的爱就会在我们中得以实现。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 2:20–22; 约翰一书 3:24; 哥林多前书 3:16–17"> 我们如何知道我们住在他之中，他也住在我们之中？因为他给了我们通过他的灵去爱<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="暗指。">b</a></sup>的能力。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰一书 4:10; 约翰福音 3:16–17; 约翰福音 4:42"> 因为我们就是我们所见之事的见证人，见证父派子作为这世界的救世主。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 10:9; 约翰一书 5:5; 马太福音 10:32"> 凡是宣称耶稣是上帝之子的人，上帝就住在他们之中，他们也住在上帝之中。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰一书 3:24; Psalms 36:7–9; 约翰一书 3:1"> 我们已经经历并相信上帝对我们的爱。上帝就是爱，活在爱之中的人，活在上帝之中的人，上帝也活在他们之中。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰一书 4:12; 约翰一书 2:28; 罗马书 8:29"> 这就是爱让我们完整的方式，这样我们就可以在审判日充满信心：因为我们在这个世界上的生活，就像他一样。</span>
<span className="v" id="v18" data-v="18" data-xref="提摩太后书 1:7; 罗马书 8:15; 约翰一书 4:12"> 有爱的地方就没有恐惧。上帝给了我们全部的爱，这种爱驱散了我们所有恐惧。如果我们害怕，那是因为我们害怕受到惩罚，这表明我们还没有完全被上帝全部的爱所改造。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 4:10; 约翰福音 3:16; 约翰福音 15:16"> 我们爱，是因为上帝先爱我们。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰一书 3:17; 约翰一书 2:9; 约翰一书 4:12"> 如果有人说“我爱上帝”，却恨其他基督徒兄弟姐妹，那这个人就是在说谎。如果不爱他们所看到的兄弟，就无法爱那看不见的上帝。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 22:37–39; Leviticus 19:18; 约翰一书 3:11"> 爱上帝的人，也应当爱他的兄弟姐妹，这就是上帝给我们的命令。</span>

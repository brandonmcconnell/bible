<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太前书 2:5; 罗马书 8:34; 约翰福音 14:6"> 我亲爱的孩子们，我写这封信给你们，是为了让你们不犯罪。但如果有人犯了罪，在父面前会有一人保护我们，那就是耶稣基督，他是真正的正直良善。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 4:14; 彼得前书 3:18; 约翰一书 4:10"> 通过他，我们的罪得到宽恕——不只是我们的罪，还包括全世界的罪。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 14:15; 约翰福音 15:10; 路加福音 6:46"> 我们可以确定的是，如果我们遵循他的命令，就认识他。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰一书 1:6; 提多书 1:16; 雅各书 2:14–16"> 凡是说“我认识他”的人，如果不遵守他命令，就是在说谎。就不是遵循真理。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 14:23; 约翰福音 14:21; 约翰一书 4:12–13"> 但那些遵守上帝之道的人，他的爱便把他们的头脑充满。这样我们就知道，我们便与他同在。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前书 2:21; 约翰福音 13:15; 哥林多前书 11:1"> 那些说自己与他同在的，行为就应该像耶稣基督。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰一书 3:11; Leviticus 19:18; 马可福音 12:29–34"> 我的朋友们，我写给你们这封信，并不是要给出新命令，而是要说到你们从初始之刻就已有的旧命令。这旧命令就是你们听过的道。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 5:8; 罗马书 13:12; 约翰福音 13:34"> 但从某种角度而言，我也在给你们一个新命令。黑暗即将结束，真正的光已在照耀，它的真理已在耶稣和你们身上显现。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 4:20; 约翰一书 2:11; 约翰一书 3:13–17"> 那些说自己身处光明之中、却憎恨其他基督徒的人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“兄弟。”">a</a></sup>，他们的内在还有黑暗。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 3:14; 罗马书 9:32–33; 罗马书 14:13"> 那些热爱其他基督徒的人，就是生活在光中，就不会让其他人变得有罪。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“没有陷阱。”换言之，就是让别人绊倒的东西。">b</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="约翰福音 12:35; 提多书 3:3; 约翰一书 1:6"> 那些憎恨其他基督徒的人，就是身处黑暗之中。他们在黑暗中跌跌撞撞。不知道要去哪里，因为黑暗弄瞎了他的眼睛。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 10:43; 使徒行传 13:38; 以弗所书 1:7"> 亲爱的朋友们，我写信给你们这些孩子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="约翰分别提到了三个群体：儿童、父亲和年轻人。这指代的可能是不同时代基督徒的经历，并非字面所说的群体。">c</a></sup>，因为你们的罪已通过主的名得到赦免。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 14:7; 约翰一书 2:14; 路加福音 10:22"> 我写信给你们这些父亲，因为你们知道自世界之初便已存在的那个人。我写信给青年们，因为你们已战胜了邪恶之人。</span>
<span className="v" id="v14" data-v="14" data-xref="Psalms 119:11; 约翰一书 2:13; 歌罗西书 3:16"> 我写信给你们这些孩子，因为你们认识父。我写信给你们这些父亲，因为你们认识自世界之初就已存在的那个人。我写信你们这些年轻人，因为你们很坚强。上帝之道就在你们之中，你已经打败邪恶之人。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各书 4:4; 罗马书 12:2; 马太福音 6:24"> 不要爱这个世界，不要爱这世上的一切。如果你爱这个世界，你就不会再有父的爱。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 13:14; 加拉太书 5:17; Psalms 119:36–37"> 因为这世上的一切——我们的欲望之罪，渴望拥有所看到的一切，吹嘘我们今生所达成的一切，这些都不是出于父，而是出于这个世界。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 24:35; 罗马书 12:2; 哥林多前书 7:31"> 这世界和这是世上的邪恶欲望，即将走向尽头，但那遵行上帝之道的，却能永远生存。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰一书 4:3; 约翰二书 1:7; 马太福音 24:24"> 亲爱的朋友们，此刻就是末日。你们已经听到反基督力量的到来，很多反基督的力量已经到来；所以我们才知道，此刻就是末日。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 20:30; 哥林多前书 11:19; 路加福音 8:13"> 他们已经离开了我们，他们不再属于我们，当他们离开时，他们所有人就显示出不再属于我们。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 14:26; 约翰一书 2:27; 哥林多后书 1:21–22"> 但你们已在圣灵的祝福中获得膏抹<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="膏抹就是将液体（通常是油）倒在某人的头上，表明他们获得特别的祝福，通常的对象都是一些特定的任务（如旧约中的国王）。这里的膏抹是指圣灵的祝福，圣灵以耶稣之道引领一切真理。">d</a></sup>，你们所有人都知道这是真相。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得后书 1:12; 犹大书 1:5; Proverbs 1:5"> 我写信给你们，不是因为你们不明白真相，而是因为你们知道，因为谎言绝不会出于真理。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰二书 1:7; 约翰一书 4:3; 约翰一书 2:18"> 那么谁是在说谎？—— 就是那否认耶稣是基督的人。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="意思为弥赛亚。（希腊语中的基督。）两者都是指指接受膏抹之人。">e</a></sup>否认父和子，就是反基督。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰一书 4:15; 约翰福音 8:19; 约翰福音 5:23"> 否认子，便没有父；承认子，便有父。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 14:23; 约翰福音 15:9–10; 约翰一书 4:13"> 至于你们，务必要始终生活在从最初便听到一切；如果你生活在从最初听见的一切，也就住在父和子之中。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 10:28; 提多书 3:7; 犹大书 1:21"> 他已承诺给我们——永恒的生命。</span>
<span className="v" id="v26" data-v="26" data-xref="彼得后书 2:1–3; 约翰二书 1:7; 使徒行传 20:29–30"> 我写信给你们这些，是想警醒你们那些想要带你们走入迷途之人。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 14:26; 约翰一书 2:20–21; 哥林多前书 2:13"> 你们从他那里得到膏抹，就意味着圣灵<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="圣灵，见第 20 段。">f</a></sup>住在你们之中，你们不需要被任何人教导。圣灵的恩膏教导你们一切。这是事实，不是谎言。所以活在基督之中，就像你已受到教导一样。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰一书 4:17; 马可福音 8:38; 约翰一书 3:2"> 我亲爱的孩子们，你们要住在主之中，以便在他出现时，我们就可以自信，不会在他到来的时候感到惭愧。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 3:3–5; 约翰一书 3:7; 约翰一书 5:1"> 如果你们知道他的良善和正直，<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="原意为“义”——但这个词今天通常只用于宗教联系，在常用的英语中没有太多含义。">g</a></sup>就应当知道所有良善正直之人都是上帝所生。</span>
</div>

## 脚注

<ol className="fnl">
<li id="fn-a"><a href="#fnref-a" className="fnb">a</a> <span className="fnr">2:9</span> 原意为“兄弟。”</li>
<li id="fn-b"><a href="#fnref-b" className="fnb">b</a> <span className="fnr">2:10</span> 原意为“没有陷阱。”换言之，就是让别人绊倒的东西。</li>
<li id="fn-c"><a href="#fnref-c" className="fnb">c</a> <span className="fnr">2:12</span> 约翰分别提到了三个群体：儿童、父亲和年轻人。这指代的可能是不同时代基督徒的经历，并非字面所说的群体。</li>
<li id="fn-d"><a href="#fnref-d" className="fnb">d</a> <span className="fnr">2:20</span> 膏抹就是将液体（通常是油）倒在某人的头上，表明他们获得特别的祝福，通常的对象都是一些特定的任务（如旧约中的国王）。这里的膏抹是指圣灵的祝福，圣灵以耶稣之道引领一切真理。</li>
<li id="fn-e"><a href="#fnref-e" className="fnb">e</a> <span className="fnr">2:22</span> 意思为弥赛亚。（希腊语中的基督。）两者都是指指接受膏抹之人。</li>
<li id="fn-f"><a href="#fnref-f" className="fnb">f</a> <span className="fnr">2:27</span> 圣灵，见第 20 段。</li>
<li id="fn-g"><a href="#fnref-g" className="fnb">g</a> <span className="fnr">2:29</span> 原意为“义”——但这个词今天通常只用于宗教联系，在常用的英语中没有太多含义。</li>
</ol>

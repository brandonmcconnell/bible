<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 12:9–10; 以弗所书 6:10; 提摩太后书 1:7"> 所以，我的儿子，你应当在基督耶稣的恩典中强大起来，</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太后书 1:13–14; 提摩太前书 4:6; 提摩太前书 6:12"> 对于我在很多见证人面前所说的一切，你也应该听进去，分享给那些忠心又能够教导他人的人。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 12:2–3; 雅各书 1:12; 提摩太后书 4:5"> 你应当和我一起遭受磨难，就像基督耶稣的优秀士兵。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 2:4; 路加福音 8:14; 彼得后书 2:20"> 士兵因其职责而不能被每天的琐事缠身，他想要让那招兵之人欢喜。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 9:24–27; 启示录 3:11; 提摩太后书 4:7–8"> 同样，运动员如果不遵守规则，就不能获得奖励。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 10:36; 哥林多前书 9:7–11; 哥林多前书 3:6–9"> 辛苦工作的农夫理当先尝农作物的成果。</span>
<span className="v" id="v7" data-v="7" data-xref="雅各书 1:5; 约翰一书 5:20; 路加福音 24:45"> 想想我和你说的话，主将帮助你理解这一切。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 2:24; 罗马书 2:16; 哥林多前书 15:11–20"> 你的思想要关注大卫的后裔、从死人中复活的耶稣基督，这就是我所传的福音。</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比书 1:7; 使徒行传 28:31; 提摩太后书 1:8"> 因为这福音，我被像犯人一样投入监牢，但上帝之道不会被困于牢狱。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前书 5:10; 歌罗西书 1:24; 提摩太后书 2:3"> 尽管如此，我原意为上帝子民<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“选民。”">a</a></sup>而继续这样做，让他们也可以获得基督耶稣的救赎和永恒荣耀</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 6:8; 歌罗西书 3:3–4; 罗马书 6:5"> 下面这句话是可信的：“如果我们与基督同死，就必与他同活；</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 8:17; 马太福音 10:33; 启示录 20:4"> 如果我们继续忍耐，就会与他一同为王；我们若不认他，他必不认我们。</span>
<span className="v" id="v13" data-v="13" data-xref="Numbers 23:19; 罗马书 3:3; 帖撒罗尼迦后书 3:3"> 即使我们不值得信赖，他仍然值得信赖，因为他不能不真实地对待自己。”</span>
<span className="v" id="v14" data-v="14" data-xref="提多书 3:9–11; 提摩太后书 2:23; 提摩太后书 4:1"> 你要提醒众人，在上帝面前告诉他们，不要作毫无意义的争辩，这只能伤害那些听众。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 2:4; 彼得后书 1:10; 提摩太前书 4:6"> 务必要努力工作，这样你就可以在上帝面前展示自己，获得他的称许。要做一名无愧的工人，正确地讲解真理之道。</span>
<span className="v" id="v16" data-v="16" data-xref="提多书 3:9; 提摩太前书 6:20; 提摩太后书 2:14"> 远离毫无意义的闲聊，因为这样做会让人们远离上帝。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太前书 1:20; Nahum 3:15; 雅各书 5:3"> 他们的讲述好像坏疽一样具有破坏力，会摧毁健康的身体；许米乃和腓理徒就是这样的人。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 15:12; 提摩太前书 1:19; 希伯来书 3:10"> 他们偏离了真理，说复活之事是过去发生的事情，这破坏了一些人对上帝的信心。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 10:14; 哥林多前书 8:3; Nahum 1:7"> 但上帝值得信赖的坚固基石非常稳固，上面刻着这样的字：“主认识属于他之人”和“凡称呼主名之人都应远离不义”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引自《民数记》16:5。">b</a></sup>。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 9:21–23; 彼得前书 2:5; 提摩太前书 3:15"> 在庄严堂皇房子中，不能只有金子和银子做的杯碗<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“器皿”或“用品。”其原意“家用容器”似乎没有合适的英语对应词。">c</a></sup>，还应有木器、瓦器；有的是特殊用途，有的则是经常使用。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 3:17; 以弗所书 2:10; 哥林多后书 7:1"> 因此，如果你远离邪恶，就会成为圣洁而特别的杯子或碗，供主使用，准备好做各种善事。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:11; 彼得前书 3:11; 哥林多前书 6:18"> 应远离那些点燃年轻人欲望的事情，去追随正直良善、值得信赖的事情，与那些真正纯洁的基督徒一起追随爱与和平。</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太后书 2:14; 提多书 3:9; 提摩太前书 4:7"> 拒绝愚蠢而幼稚的辩论；你知道它们只会引发争斗。</span>
<span className="v" id="v24" data-v="24" data-xref="提多书 3:2; 雅各书 1:19–20; 提摩太前书 3:2–3"> 但主的仆人决不能争斗，而是要温和对待所有人，能够教导，保持耐心，</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 11:18; 加拉太书 6:1; 提摩太前书 2:4"> 温和地规劝对手。或许上帝可以帮助他们悔改，可以认识真理。</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太前书 3:7; Isaiah 49:25–26; Psalms 124:7"> 这种方式，他们可能会恢复理智，逃离魔鬼的陷阱。魔鬼曾抓住他们，让他们去做魔鬼想做的事情。</span>

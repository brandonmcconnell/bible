<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 10:42; 提摩太后书 4:8; 提摩太前书 5:21"> 这就是我在上帝和耶稣基督面前，指导你要做的事情。当耶稣基督到来并建立他的王国，将对活人和死人进行审判。</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦前书 5:14; 提摩太前书 4:15–16; 提多书 2:15"> 无论是否方便，都要讲述上帝之道；如果人们犯错，要告诉他们，警告他们，鼓励他们。当你这样做时，要用极大的耐心进行教导。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得后书 2:1–3; 提摩太后书 3:1–6; 提摩太前书 4:1–3"> 因为人们即将不再听得下真正的教导，那个时刻很快就会到来。到时候，他们会好奇地想要听不一样的教导，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“耳朵发痒。”">a</a></sup>他们身边的老师，会讲述他们爱听的东西。</span>
<span className="v" id="v4" data-v="4" data-xref="Zechariah 7:11; 提摩太前书 1:4; 使徒行传 7:57"> 他们不再聆听真理，反倒流连于谬误。</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太后书 1:8; 彼得前书 1:13; 提摩太后书 2:3"> 你要时刻保持明智，忍受磨难，进行传福音的工作，完成你的职责。</span>
<span className="v" id="v6" data-v="6" data-xref="腓立比书 1:23; 腓立比书 2:17; 彼得后书 1:14–15"> 我即将被牺牲；我离世的时候即将到来。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前书 6:12; 哥林多前书 9:24–27; 希伯来书 12:1–2"> 我已进行了一场良善的战斗，已跑完比赛，已坚持对上帝的信。</span>
<span className="v" id="v8" data-v="8" data-xref="雅各书 1:12; 启示录 2:10; 彼得前书 5:4"> 现在有一个奖励留给了我，那是因遵循好事和正直良善而获得的冠冕。主（他是总能正确行事的法官）会在那一天给我这个冠冕。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="见 1:12 注释。">b</a></sup>不只是给我，也给渴望他到来的所有人。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太后书 1:4; 提摩太后书 4:21"> 请尽快到我这边来。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰一书 2:15–16; 提摩太后书 1:15; 歌罗西书 4:14–15"> 因为底马因贪恋现今的世界，已离开我去了帖撒罗尼迦。革勒士去了加拉太，提多去了达马太。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 12:12; 腓利门书 1:24; 使徒行传 12:25"> 现在只有路加在我这里。请把马可带来，他可以帮助我的工作。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 6:21; 使徒行传 20:4; 提多书 3:12"> 我已派推基古到以弗所去。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 4:11; 哥林多后书 11:27; 使徒行传 16:11"> 你来的时候，请带上我在特罗亚时留在加布那里的外衣。还有那些书，特别是那些羊皮书，也要带来。</span>
<span className="v" id="v14" data-v="14" data-xref="提摩太前书 1:20; 帖撒罗尼迦后书 1:6; Psalms 28:4"> 铜匠亚历山大给我带来了很多麻烦，愿主根据他的行为审判他。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太后书 3:8; 腓立比书 3:2; 马太福音 10:16–17"> 你也要提防他，因为他极力反对我所说的话。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 7:60; 约翰福音 16:32; 马可福音 14:50"> 我第一次辩护的时候<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="即司法审判。">c</a></sup>，没有一个人支持我，反而离开我。但愿他们不会因此而受到责备。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前书 5:8; 腓立比书 1:12–14; 1 Samuel 17:37"> 但主站在我身边，给我力量，让我可以宣讲所有的福音信息，让所有外族人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原意为“异教徒。”">d</a></sup>都能听见；他将我从狮口中救出来。</span>
<span className="v" id="v18" data-v="18" data-xref="Psalms 121:7; 帖撒罗尼迦后书 3:3; 犹大书 1:24–25"> 主必救我脱离一切邪恶之事，也必带我安全进入他在天上的王国。愿荣耀永远归给他。阿门。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 18:2; 哥林多前书 16:19; 罗马书 16:3–4"> 替我问候百基拉<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="曾出现在《使徒行传》18:2 中，名字拼写略有差异。">e</a></sup>、亚居拉和阿尼色弗一家人。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 20:4; 使徒行传 19:22; 腓立比书 2:26–27"> 以拉都留在了哥林多。因为特罗非摩病了，我就留他在米利都。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 4:9; 腓立比书 4:22; 约翰三书 1:14"> 请尽可能在冬天前赶过来。友布罗、布田、利奴、革老底亚和所有兄弟姐妹都向你问候。</span>
<span className="v" id="v22" data-v="22" data-xref="腓利门书 1:25; 加拉太书 6:18; 歌罗西书 4:18"> 主与你同在。<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="原意为“与你的精上帝同在。”">f</a></sup>愿他的恩典与你们同在。</span>
</div>

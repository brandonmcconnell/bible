<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得后书 3:3; 提摩太后书 4:3; 提摩太前书 4:1–3"> 你要意识到，在末日期间必有艰难的时期。</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比书 2:21; 罗马书 1:29–31; 犹大书 1:16"> 那时人们只爱自己和钱财。他们会自夸、傲慢、亵渎、悖逆父母、忘恩负义、生活中不再有上帝。</span>
<span className="v" id="v3" data-v="3" data-xref="犹大书 1:18; 罗马书 1:31; 马太福音 10:21"> 他们内心无情、不肯宽恕，他们会恶言中伤、没有自律、性格凶残、痛恨良善、</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比书 3:18–19; 提摩太前书 3:6; 犹大书 1:4"> 背叛其他人、不考虑其他人/荒唐地只想着自己、追逐享乐胜于爱上帝。</span>
<span className="v" id="v5" data-v="5" data-xref="Isaiah 29:13; 提多书 1:16; 马太福音 23:27–28"> 他们外在表现得可能很虔诚，却其实并不相信虔诚的力量；要避开这样的人！</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="犹大书 1:4; 彼得后书 3:17; 提多书 3:3"> 他们这种人会偷偷潜入别人家中，操纵脆弱的妇女。这些妇女背负罪的负担，被各种私欲所累，</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太后书 4:3–4; 以弗所书 4:14; 提摩太前书 2:4"> 虽然常常学习，却始终无法明白真理！</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 13:8–11; 启示录 2:20; 提摩太前书 6:5"> 就像阎儡和阎悖如何反对摩西，这些人就是那样反对真理。他们的思想已经腐朽，认为对上帝的信是一个谎言。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或者“他们对上帝的信任都是假的。”">a</a></sup></span>
<span className="v" id="v9" data-v="9" data-xref="提摩太后书 3:8; Exodus 7:12; Jeremiah 28:15–17"> 然而他们这样的状态不会太久，他们的愚昧会在所有人面前显露，好像阎儡和阎悖那两个人。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 6:11; 提多书 2:7; 彼得后书 1:5–7"> 但你了解我的教导和行为，了解我的生命目标，了解我对上帝的信和我的爱。了解我一直以来都在忍耐什么，</span>
<span className="v" id="v11" data-v="11" data-xref="Psalms 34:19; 使徒行传 14:5–6; 哥林多后书 11:23–28"> 我受到的迫害和苦难。你了解我在安提阿、以哥念、路司得都遭遇了什么，我遇到的困境，以及主如何救我脱离这一切。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彼得前书 3:14; 彼得前书 4:12–16; 彼得前书 2:20–21"> 当然了，希望以基督耶稣献身于上帝的所有人，都必遭受迫害。</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太前书 4:1; 彼得后书 2:20; 提多书 3:3"> 与此同时，恶人和骗子则越来越坏，他们欺骗人，也欺骗自己。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:13; 提摩太后书 2:2; 提摩太后书 1:13"> 你必须坚守所学的、确信为真相的事情；你知道是谁教给你的。</span>
<span className="v" id="v15" data-v="15" data-xref="Psalms 119:98–99; 路加福音 24:45; Proverbs 22:6"> 你从儿时起就知道神圣的经文，它让你能够拥有理解力，可以通过信基督耶稣获得救赎。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 15:4; 希伯来书 4:12; 彼得后书 1:19–21"> 所有上帝启迪写下的经文，都有助于我们进行教导，纠正错误，让我们走正道，告诉我们何为良善正直。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太后书 2:21; 以弗所书 2:10; 哥林多后书 9:8"> 上帝就是通过这种方法，让那些为他工作、完成所有善行之人，做好万全准备。</span>
</div>
</div>

</div>

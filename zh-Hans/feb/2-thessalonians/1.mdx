<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 1:19; 使徒行传 16:1; 帖撒罗尼迦前书 1:1–10"> 这封信函来自保罗、西拉和提摩太，写给帖撒罗尼迦、为我们父上帝和主耶稣基督所有的教会。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 1:7; 哥林多前书 1:3; 哥林多前书 1:8"> 愿你们获得来自天父和主耶稣基督的恩典与平安。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得后书 3:18; 彼得后书 1:5–10; Proverbs 4:18"> 兄弟姐妹们，我们始终都因你们而感谢上帝，我们衷心地感谢你们。因为你们对上帝的信正在快速增加，你们彼此相爱的心也在增加。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="希伯来书 10:36; 雅各书 5:7–8; 希伯来书 12:1–3"> 因为你们在经受的所有迫害苦难中，仍然保持着勇气和信心，所以在上帝的众教会中，说到你们会让我们深感骄傲。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 1:28; 使徒行传 14:22; 路加福音 20:35"> 这是上帝做出公正决定的证明，你们配得上他的王国，你们也是为此而受苦。</span>
<span className="v" id="v6" data-v="6" data-xref="Zechariah 2:8; 歌罗西书 3:25; Psalms 94:20–23"> 因为上帝所做之事都是良善正直，他也会恰如其分地处理那些导致你们受苦之人。</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 14:13; 马太福音 16:27; 犹大书 1:14–15"> 当耶稣基督与他强大的天使们在耀眼火焰中从天国降临，他会解救你们和我们于痛苦,</span>
<span className="v" id="v8" data-v="8" data-xref="彼得前书 4:17; 彼得后书 3:7; 希伯来书 10:27"> 对那些拒绝上帝、不接受我们主基督福音之人，进行审判。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 25:41; 启示录 14:10–11; 马太福音 25:46"> 他们要受到惩罚，永远离开上帝，无法见到主和他的光荣力量。</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 1:18; 哥林多前书 3:13; 约翰福音 17:10"> 当他要从其子民处获得荣耀的那一天，被所有信他之人所尊崇，你们也在其中，因为我们所说的一切，让你们信服。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="腓立比书 2:13; 歌罗西书 1:9–13; 帖撒罗尼迦前书 1:3"> 所以我们始终为你们祷告，愿我们上帝将你们变成的样子，值得他召唤我们所做的一切。如果你们想要行为正直良善，一举一动皆来自对他的信，愿上帝用强大的力量满足你们达成这个目标的每一个愿望。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦后书 1:10; 彼得前书 4:14; 约翰福音 17:10"> 只有这样，我们主耶稣的名，才可能因你们的行为而获得荣耀，你们也会通过上帝和主耶稣基督的恩典，因他而荣耀。</span>
</div>

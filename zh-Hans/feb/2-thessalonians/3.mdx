<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 5:25; 歌罗西书 4:3; 哥林多前书 16:9"> 最后，兄弟姐妹们，请为我们祷告，让主之道可以传开并被人们真正地接受，就像你们所做的那样。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 4:3–4; 罗马书 15:31; Deuteronomy 32:20"> 祈祷我们可以摆脱那些不道德的邪恶之人，因为不是所有人都信上帝。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太后书 4:18; 帖撒罗尼迦前书 5:24; 哥林多前书 10:13"> 但主值得信赖，他将让你们更有力量，保护你们脱离邪恶之人。</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比书 1:6; 腓利门书 1:21; 帖撒罗尼迦前书 4:10"> 以主为名，我们深信你们现在和未来，都会继续按照我们所说的做，</span>
<span className="v" id="v5" data-v="5" data-xref="Psalms 119:36; 1 Chronicles 29:18; Deuteronomy 30:6"> 愿主引导你们，更深刻地理解上帝对你们的爱以及基督的忍耐。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“基督的忍耐”可能是指基督所体现的忍耐，或基督所赐的忍耐——或两者兼而有之。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦后书 3:10–11; 帖撒罗尼迦后书 3:7; 罗马书 16:17"> 兄弟姐妹们，我们以主耶稣基督之名想要告诉你们，如果哪个信徒游手好闲，不按照我们所进行的教导行事，就应当远离他。</span>
<span className="v" id="v7" data-v="7" data-xref="帖撒罗尼迦后书 3:6; 帖撒罗尼迦后书 3:9; 哥林多前书 4:16"> 你们当然知道应当以我们为榜样，因为我们与你们在一起时，我们没有游手好闲，</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 6:11; 帖撒罗尼迦前书 2:9; 以弗所书 4:28"> 没有不付钱就吃其他人的食物。相反，我们辛苦劳碌，昼夜工作，免得加重你们任何一人的负担。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦后书 3:7; 帖撒罗尼迦前书 2:6; 哥林多前书 9:4–14"> 这不是因为我们没有权利，而是要给你们作榜样，好让你们照着做。</span>
<span className="v" id="v10" data-v="10" data-xref="Genesis 3:19; Proverbs 13:4; Proverbs 20:4"> 我们与你们在一起的时候，曾经给出严格的指示，如果有人不肯工作，就不可吃饭。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 5:13; 帖撒罗尼迦后书 3:6; 帖撒罗尼迦前书 4:11"> 但现在我们听说，你们中有人游手好闲，从不工作，却专管闲事。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 4:28; 帖撒罗尼迦前书 4:11; 帖撒罗尼迦后书 3:8"> 通过主耶稣基督，我们劝告这样的人要安静工作，自食其力。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="加拉太书 6:9–10; 希伯来书 12:3; 哥林多后书 4:1"> 兄弟姐妹们，不要放弃行善。</span>
<span className="v" id="v14" data-v="14" data-xref="提多书 3:10; 帖撒罗尼迦后书 3:6; 哥林多前书 5:11"> 如果有人不听从我们这封信上的教导，要把那个人记下来，不可与他来往，让他自己觉得惭愧。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="换言之，鼓励他们做自己应该做的事情。">b</a></sup></span>
<span className="v" id="v15" data-v="15" data-xref="提多书 3:10; 帖撒罗尼迦前书 5:14; 哥林多前书 5:5"> 但不要把他看作仇敌，要像劝兄弟姐妹一样劝他。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="Psalms 29:11; 约翰福音 16:33; 马太福音 1:23"> 愿赐平安的随时赐予你们平安。愿主与你们众人同在。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 16:21; 帖撒罗尼迦后书 1:5; 歌罗西书 4:18"> 这是我保罗亲手写下的信函，向你们问候。这是我所写信函的标志。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 16:20; 罗马书 16:23"> 愿我们主耶稣基督的恩典与你们众人同在。</span>
</div>

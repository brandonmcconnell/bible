<span className="v" id="v2" data-v="2" data-xref="约翰一书 4:1–2; 马可福音 13:7; 马太福音 24:4–6"> 如果有任何灵的显现或消息、或收到号称来自我们的信函，告诉你们主的日子已经来到，请不要沮丧或担心。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 24:4–6; 约翰一书 2:18; 以弗所书 5:6"> 不要让任何人用任何方法迷惑你们，因为在那之前，必先发生叛乱<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“背道”，即末日，对上帝的最终否定。">a</a></sup>，无法之徒会露出原型，他的末日就是被摧毁。</span>
<span className="v" id="v4" data-v="4" data-xref="Ezekiel 28:2; Daniel 7:25; 启示录 13:6–7"> 这样的人以上帝为敌，将自己抬高自己，高于被称为上帝和受人敬拜的一切。他甚至坐在上帝的宫殿中，自称为上帝。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得后书 1:15; 加拉太书 5:21; 马太福音 16:9"> 还记得我和你们一起时，曾告诉过你们这一切？</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦后书 2:3; 帖撒罗尼迦后书 2:8"> 现在你们也知道，是什么让他一直没有行动，因为要等到他的恰当时刻才会显示出来。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="对这一整个部分（2:6-12）的含义有很多争论。">b</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="约翰一书 4:3; 启示录 17:7; 提摩太后书 2:17–18"> 因为那无法<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“无法之谜”，指的是反对上帝的力量“显现秘密。”这不仅是破坏法律，还是彻底的无法，完全不尊重律法。">c</a></sup>的秘密已经在产生影响，只是他还在控制着，他也会一直这么做，直到那控制被解除。</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦后书 2:3; 启示录 19:20–21; Isaiah 11:4"> 那时候，这无法之徒就会显现。主耶稣将把他除掉，把他吹跑<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原意为“通过他口中的气息。”">d</a></sup>，用其临时的光辉消灭他。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 24:24; 启示录 19:20; 以弗所书 2:2"> 他（无法之徒）的到来是为了行撒旦之事，拥有各种能力，显示奇迹，进行看似令人惊讶、其实是骗术的行为。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 1:18; Proverbs 1:7; 哥林多后书 4:2–3"> 在那些正在走向毁灭之路的人身上，行各种不义的欺诈之举，因为他们拒绝去爱真理并因此而得救。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 1:28; 约翰福音 12:39–43; 提摩太前书 4:1"> 因此，上帝就送给他们一个令人相信的错觉，让他们相信谎言。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="谎言：在这个段落中的意思，很确定是指敌人（《以赛亚书》14，《以西结书》28）关于上帝本质和特性的谎言，他们甚至自称是上帝（2:4）。关于上帝“送来”这种错觉，请注意，在圣经中，上帝经常会说到他无法防止发生的事情。">e</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 1:32; 罗马书 8:7–8; 马可福音 16:16"> 这样的结果是，所有不信真理、喜欢邪恶之人都会被定罪。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="提摩太后书 1:9; 以弗所书 1:4–5; 帖撒罗尼迦前书 1:4"> 但主所爱的兄弟姐妹们，我们应该一直感谢上帝，因为上帝从最初就选择了你们，通过其灵拯救你们，让你们变得正直良善，相信正道。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:12; 彼得前书 5:10; 帖撒罗尼迦前书 1:5"> 上帝就是通过我们向你们传的福音，召唤你们，让你们可以获得我们主耶稣基督的荣耀。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 11:2; 帖撒罗尼迦后书 3:6; 帖撒罗尼迦后书 2:2"> 所以兄弟姐妹们，要站稳。关于你们学到的，无论是我们口传或写于我们的信函，都要持守。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 5:2–5; 约翰福音 3:16; 彼得前书 1:3–8"> 愿我们的主耶稣基督以及父上帝(他通过其恩典给予我们永恒的心心和值得信赖的希望），</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦后书 3:3; 帖撒罗尼迦前书 3:13; 帖撒罗尼迦前书 3:2"> 可以鼓励你们，让你们变得强大，做出良善言行。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提多书 1:7; 使徒行传 20:28; 彼得前书 5:2"> 下面这句话值得我们相信：“如果有人希望成为长者，这也是可以做的善行。”</span>
<span className="v" id="v2" data-v="2" data-xref="提多书 1:6–9; 提摩太后书 2:24; 罗马书 12:13"> 一个长者必须无可指摘，只娶一名妻子，有节制，保持平衡、庄重、款待他人、善于教导。</span>
<span className="v" id="v3" data-v="3" data-xref="提多书 1:7; 以弗所书 5:18; 提多书 3:2"> 他应该不好酒、不暴力，而是要温和，与人无争或者不贪财，</span>
<span className="v" id="v4" data-v="4" data-xref="提多书 1:6; Genesis 18:19; 提摩太前书 3:12"> 他必须能管好自己的家，他让儿女做的事情，儿女必须敬重顺服。</span>
<span className="v" id="v5" data-v="5" data-xref="1 Samuel 3:13; 以弗所书 5:24; 使徒行传 20:28"> （因为一个男人如果不知如何管好自己的家，怎能管理上帝的教会？）</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前书 6:4; 希伯来书 5:12–13; 彼得前书 2:2"> 他不应该是一个新加入的信徒，否则他可能会骄傲<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或“他以无知为荣。”">a</a></sup>，这就落入与魔鬼相同的惩罚之中。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 8:21; 提摩太后书 2:26; 歌罗西书 4:5"> 他在教会以外也应有个好名声，这样他就不会被人毁谤，从而落在魔鬼的陷阱。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="腓立比书 1:1; 提摩太前书 5:23; 使徒行传 6:3–6"> 同样，执事<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“执事”一词直接源自希腊​词“diakonos”，意思是仆人。">b</a></sup>也必须庄重、不伪善、不酗酒、不骗取不义之财。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前书 1:19; 约翰二书 1:9–10; 提摩太前书 1:5"> 他们必须用纯粹的良心信上帝，坚持显示关于上帝真想。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 5:22; 提摩太前书 3:13; 提多书 1:6–7"> 他们首先应去尝试一段时间，如果没有错误，然后才让他们担任执事。</span>
<span className="v" id="v11" data-v="11" data-xref="提多书 2:3; 提多书 3:2; 提摩太前书 3:2"> 他们的妻子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“他们的妻子”：或简称为“女人。”">c</a></sup>也要庄重，不应用闲话中伤他人，应该有节制，所做的一切都应该值得信任。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太前书 3:2; 提摩太前书 3:4–5; 腓立比书 1:1"> 执事只应娶一个妻子，善于管理儿女和自己的家。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 25:21; 希伯来书 6:10; 使徒行传 21:35"> 那些表现优秀的执事，为自己赢得好名声，也因相信基督耶稣而获得更多自信。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 11:34; 腓利门书 1:22; 哥林多后书 1:15–17"> 尽管希望尽快见到你，我仍把这些写给你，</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 2:5; 以弗所书 2:21–22; 帖撒罗尼迦前书 1:9"> 万一我拖延了，你也可以知道人们在上帝的家中应该做出怎样的行为。这是永生上帝的教会、真理的柱石和根基。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 1:14; 希伯来书 1:3; 马可福音 16:19"> 关于上帝所显现的真相真惊人，这一点毫无疑问。他以人的形态让我们知道他，灵是他的证明，天使看到他，向各国宣布，世界相信他，他为此获得荣耀。</span>
</div>
</div>

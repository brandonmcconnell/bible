<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提多书 2:5; 彼得前书 2:17–20; 提多书 2:8–10"> 作为奴仆，应当知道其主人值得尊重，避免玷污上帝之名和基督徒的信仰。</span>
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 4:1; 提摩太前书 4:11; Genesis 16:4–5"> 如果奴仆的主人是基督徒，不可因为他们是兄弟而不尊重主人；相反，要更加倍用心地服侍主人，因为被他们服侍而受益之人，是他们应该爱的信徒。传授这些教导，鼓励人们追随他们。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前书 1:3; 罗马书 16:17; 提摩太前书 1:10"> 有的人会传授不同的信仰，不听从善意建议，尤其是我们主耶稣基督纯之道，以及上帝的真正教诲。</span>
<span className="v" id="v4" data-v="4" data-xref="提摩太后书 2:23; 提摩太后书 3:4; 提摩太前书 3:6"> 他们傲慢无礼，一无所知, 最喜欢猜测和进行理论争辩，由此产生妒忌、纷争、毁谤、恶毒的流言蜚语和邪恶的猜想。</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太后书 3:5; 提多书 1:11; 彼得后书 2:3"> 那些心思败坏、丧失真理的人不断争吵，他们将虔诚视为来财之道......</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 13:5; 提摩太前书 6:8; Proverbs 16:8"> 但知晓并追随上帝是如此令人满足。</span>
<span className="v" id="v7" data-v="7" data-xref="Job 1:21; Psalms 49:17; 路加福音 12:20–21"> 因为我们没有将任何东西带到这世上，也不能带任何东西离开。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 13:5–6; 马太福音 6:11; 马太福音 6:25–33"> 只要我们有衣有食，就应当知足。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 2:15–17; Proverbs 15:27; 提摩太前书 3:7"> 但那些渴望发财之人，就会落入试探的陷阱；追随很多无知而有害的冲动。</span>
<span className="v" id="v10" data-v="10" data-xref="Proverbs 1:19; 提摩太前书 6:9; Psalms 32:10"> 因为贪财是很多恶行的缘由。很多渴望钱财之人会偏离真理，伤害自己，经历许多的痛苦。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太后书 2:22; 提摩太后书 3:17; 提摩太前书 4:12"> 但你是上帝之人，应该远离这些事，要追求做善良正直的事情，真正做到虔诚，相信上帝。要去爱，要忍耐和温柔。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 5:10; 提摩太前书 1:18; 哥林多前书 9:25–26"> 因你相信上帝，所以要为良善而战，坚定地相信永生，你就是因此而受到召唤，这也是你在许多见证人面前做出的承诺。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 18:36–37; 马太福音 27:11; 提摩太前书 5:21"> 在为万物赐予生命的上帝面前，在曾向本丢·彼拉多证实福音的耶稣基督面前，我嘱咐你，</span>
<span className="v" id="v14" data-v="14" data-xref="彼得后书 3:14; 彼得前书 1:7; 帖撒罗尼迦前书 5:23"> 要虔诚地遵循所教导你的一切<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“遵守诫命。”">a</a></sup>，这样你就不会受到指责，直到我们的主耶稣基督显现。</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 19:16; 启示录 17:14; 提摩太前书 1:17"> 在适当的时候，那受到祝福的、唯一的全能者、万王之王、万主之主的耶稣，必将显现。</span>
<span className="v" id="v16" data-v="16" data-xref="提摩太前书 1:17; 约翰福音 1:18; 约翰一书 1:5"> 只有他能够永生，住在不能靠近的光之中。没有人见过他，也无法看见他。愿荣耀和永恒的力量都归给他！阿门。</span>
<span className="v" id="v17" data-v="17" data-xref="Proverbs 11:28; 使徒行传 14:17; Proverbs 27:24"> 警告那些现世的富有之人，不要骄傲。告诉他们不要去信那并不可靠的财富，要信那赐予我们万物、供我们享用的上帝。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 13:16; 约翰一书 3:17; Psalms 37:3"> 嘱咐他们要行善，在善事上做到富有，准备好分享自己所拥有的，要慷慨好施。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 6:19–21; 提摩太前书 6:12; 提摩太后书 2:19"> 通过这种方式，他们就是在积累财富，为未来打下一个坚固的基础，让他们可以拥有真正的生命。</span>
<span className="v" id="v20" data-v="20" data-xref="歌罗西书 2:8; 提摩太后书 2:16; 提摩太后书 1:12–14"> 提摩太，要保护好交给你的一切，不要关注那些冒充“知识”毫无意义空谈和争辩。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 2:18; 提摩太前书 1:6; 提摩太后书 4:22"> 那些宣传这些想法的人，已经偏离了对上帝的信。愿恩典与你同在。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Leviticus 19:32; 彼得前书 5:5–6; 提多书 2:2"> 不要严厉责备比你年长之人，而是要像自己的父亲一样鼓励他；要像对待自己的兄弟一样，对待年轻人；</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前书 4:12; 马太福音 12:50; 腓立比书 4:8"> 将比你年长的妇人视为母亲，将年轻女人视为姐妹，遵守最高的礼仪标准。</span>
<span className="v" id="v3" data-v="3" data-xref="Deuteronomy 27:19; 使徒行传 6:1; Deuteronomy 10:18"> 帮助失去家庭的寡妇。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 6:1–3; 约翰福音 19:26–27; 马太福音 15:4–6"> 如果寡妇有儿孙，应当让儿孙先在自己家里学习孝道，报答父母将其养大的恩情，因为这是基督徒的责任。这会让上帝感到喜悦。</span>
<span className="v" id="v5" data-v="5" data-xref="提摩太前书 5:3; 路加福音 2:37; 哥林多前书 7:32"> 至于真正的寡妇，没有家庭，没有人帮助，孤身一人，她们寄希望于上帝，日夜不停地祷告。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 5:5; 启示录 18:7; 路加福音 15:24"> 但寡妇若只想享乐，那么她即使身体活着，也已经死了。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太前书 4:11; 提多书 2:15; 提摩太后书 4:1"> 要向人们进行这样的指导，让其无可指摘。</span>
<span className="v" id="v8" data-v="8" data-xref="加拉太书 6:10; 哥林多后书 12:14; 路加福音 11:11–13"> 但人若不照顾自己的亲属，尤其是自己的家人，就等于背弃信仰，比不信之人更糟糕。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前书 3:2; 提摩太前书 5:11; 路加福音 2:36–37"> 只有年过六十、忠于自己丈夫的寡妇，才能被列入名单。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="可获得教会帮助的寡妇名单。">a</a></sup></span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 6:18; 提多书 3:8; 使徒行传 9:36"> 这样的寡妇应有做善事的声誉：她是否好好地养育儿女？是否会招待客人？是否曾为圣徒洗脚，是否曾救济困苦之人？是否曾尽力行善？</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 5:14; Hosea 13:6; 雅各书 5:5"> 不能将年轻的寡妇列入这个名单，因为当身体的渴望让她们想要再嫁时，他们就会放弃对基督的献身。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 1:6; 雅各书 3:1; 哥林多前书 11:34"> 因此她们因丢弃最初的承诺而有罪。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这里的意思是：寡妇已经承诺在教会中侍奉基督，她们也因此得到教会的帮助。但再婚会破坏这个承诺。">b</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="Proverbs 20:19; 帖撒罗尼迦后书 3:6–11; 使徒行传 20:30"> 而且她们懒惰惯了，走家串户。不但懒惰，而且好说闲话，好管闲事，说不该说的话。</span>
<span className="v" id="v14" data-v="14" data-xref="提多书 2:5; 提摩太前书 6:1; 提多书 2:8"> 因此，我非常建议年轻寡妇结婚，生儿育女，照顾家庭，不给敌人以批评的机会；</span>
<span className="v" id="v15" data-v="15" data-xref="彼得后书 2:2; 犹大书 1:4–5; 彼得后书 2:20–22"> 但有些人已经追随了撒旦。</span>
<span className="v" id="v16" data-v="16" data-xref="提摩太前书 5:3–5; 提摩太前书 5:8"> 任何女基督徒的家中如果有寡妇，就应该救济她们，不要让教会因这责任而受累。这样，教会就可以救济那些真正有需要的寡妇了。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 13:17; 帖撒罗尼迦前书 5:12–13; 加拉太书 6:6"> 那些引导教会的长老，他们的价值应该加倍<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或者“应获得足够的报酬。”">c</a></sup>，尤其是那些进行讲道和传授工作的长老</span>
<span className="v" id="v18" data-v="18" data-xref="Deuteronomy 25:4; 哥林多前书 9:14; 哥林多前书 9:7–10"> 正如经文所说：“牛在踩谷子的时候，不要笼住它的嘴。”还说：“做工就应该获得工钱。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《申命记》25:4；又见《路加福音》10:7。">d</a></sup></span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 18:16; Deuteronomy 19:15; 哥林多后书 13:1"> 如果有人控诉长老，除非有两三个证人，否则不要相信。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太后书 4:2; 提多书 1:13; 提摩太前书 1:20"> 要当众责备那些罪人，对其他人也是一个警示。</span>
<span className="v" id="v21" data-v="21" data-xref="彼得后书 2:4; 提摩太后书 4:1; 提摩太前书 6:13"> 在上帝和基督耶稣以及圣天使的面前，我指引你们要没有偏心地遵循这些指引，做任何事都不要采取偏袒的态度。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 5:11; 提摩太前书 3:10; 提摩太前书 3:6"> 不要匆忙地为别人按手，也不要陷入他人的罪之中，要保护自己的纯洁。</span>
<span className="v" id="v23" data-v="23" data-xref="Psalms 104:15; Proverbs 31:4–7; 提摩太前书 4:4"> 如果你的胃不好，而且经常生病，不要只是喝水，可以稍微喝点酒。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太后书 4:10; 使徒行传 8:18; 加拉太书 5:19–21"> 有些人的罪非常明显，他们的罪行很确凿；有些人的罪是则是后来才显露出来。</span>
<span className="v" id="v25" data-v="25" data-xref="Proverbs 10:9; 路加福音 11:33; Psalms 37:5–6"> 同样，有些善行也很明显，即使有的善行隐藏起来，不久后也会显露出来。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 2:11; 加拉太书 5:17; 罗马书 7:23"> 你们之间的争斗和吵闹从何而来？难道不是来自你们身体中彼此对抗的情感欲望吗？</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 16:24; 马太福音 7:7–8; 雅各书 1:5"> 你们在欲望中燃烧，但却得不到想要的。为了追逐欲望，你们会杀人，但却无法得到自己所追求的。你们吵闹争斗，但什么都得不到，因为你们并没有为之祈祷；</span>
<span className="v" id="v3" data-v="3" data-xref="约翰一书 5:14; 约翰一书 3:22; 雅各书 1:6–7"> 你们祈祷了，但却什么也没得到。那是因为你们的动机错误，你们想要的，就是把所得的一切用于满足自己的私欲。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰一书 2:15–16; 罗马书 8:7; 约翰福音 15:19"> 淫乱的人哪！你们难道没意识到，与世俗为友就是与上帝为敌吗？与世俗为友之人，就成了上帝的敌人。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 6:16; 哥林多前书 6:19; Numbers 11:29"> 难道你不记得经文中说：“上帝放在我们身体中的灵，非常善妒”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或者“上帝给我们的灵中，充满了强烈的欲望。”">a</a></sup>？</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 23:12; Proverbs 3:34; 彼得前书 5:5"> 但上帝给我们的恩典更大；所以经文说：“上帝抵挡骄傲之人，赐予谦卑之人恩典。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引自《箴言》3:34。">b</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="彼得前书 5:8–9; 以弗所书 4:27; 以弗所书 6:11–12"> 所以请遵循上帝的指引，抵抗魔鬼，魔鬼就会从你们这里逃离。</span>
<span className="v" id="v8" data-v="8" data-xref="Psalms 145:18; 希伯来书 10:22; Malachi 3:7"> 亲近上帝，上帝就亲近你们。罪人们啊，洗净你们的手；三心两意之人啊，净化你们的思想。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 7:10–11; 马太福音 5:4; 路加福音 6:25"> 表达你们的愁苦、悲哀和哭泣，把欢笑变为悲痛，把快乐变为忧愁。</span>
<span className="v" id="v10" data-v="10" data-xref="Psalms 147:6; 马太福音 23:12; 彼得前书 5:6"> 你们在主面前务必要谦卑，他就会让你们高升。</span>
<span className="v" id="v11" data-v="11" data-xref="彼得前书 2:1; 罗马书 2:1; 雅各书 5:9"> 朋友们，不要互相毁谤；一个人如果批判其他信徒，谴责<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或“法官。”">c</a></sup>他们，就等于批判和谴责律法。如果你批判律法，就不会遵守律法，因为你扮演了审判律法的角色。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 14:4; 罗马书 2:1; 马太福音 10:28"> 只有一个立法者和审判者——那就是可以拯救、也可以毁灭你的上帝。那么你审判邻居，你认为自己是谁？</span>
<span className="v" id="v13" data-v="13" data-xref="Proverbs 27:1; 路加福音 12:17–20; Genesis 11:3–4"> 你们会说：“今天或明天，我们要到某个城市去，在那里住一年，做生意赚钱。”</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 1:24; Psalms 39:5; 约翰一书 2:17"> 其实你们并不知道明天会怎样。你们的生命像什么？它只是一团雾，出现一小会儿，然后就不见了。</span>
<span className="v" id="v15" data-v="15" data-xref="Proverbs 19:21; 希伯来书 6:3; Lamentations 3:37"> 你们倒不如说：“如果主愿意，我们就可以这样活着，计划做什么事。”</span>
<span className="v" id="v16" data-v="16" data-xref="Proverbs 27:1; 哥林多前书 5:6; Psalms 52:7"> 但现在你们竟然张狂自夸；这种自夸是邪恶。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 9:41; 约翰福音 13:17; 约翰福音 15:22"> 因为如果你明知道该行善，却没有这么做，就是你的罪。</span>

<span className="v" id="v1" data-v="1" data-xref="Proverbs 24:23; 雅各书 2:9; Leviticus 19:15"> 我的朋友们，作为一名信徒，相信我们荣耀的主耶稣基督，就不应该以貌取人。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 15:22; Esther 3:10; Esther 8:2"> 如果某人手戴金戒指、身穿华服走进你们的会堂；然后一个衣衫褴褛的穷人也走进去了。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 8:9; 雅各书 2:6; 路加福音 7:44–46"> 如果你特别关注华服之人，说：“请坐上座。”然后对穷人说：“你站在那里。”或说：“坐在我的脚下方的地上。”</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 7:24; Job 34:19; 马太福音 7:1–5"> 你不是再用恶意歧视和判断别人吗？</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 5:3; 路加福音 6:20; 启示录 2:9"> 我亲爱的朋友们，听我说：上帝不是选择了那些在世上被视为贫穷的人吗继承上帝承诺赐给爱他之人的天国？</span>
<span className="v" id="v6" data-v="6" data-xref="Proverbs 17:5; 哥林多前书 11:22; Proverbs 14:31"> 但你们却侮辱穷人。那些欺压你们、拉你们上法庭的难道不是富人吗？</span>
<span className="v" id="v7" data-v="7" data-xref="腓立比书 2:9–11; 启示录 13:5–6; 提摩太前书 1:13"> 难道不是他们亵渎那个人的荣耀名字<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="通常被认为为耶稣的名字。">a</a></sup>吗？是那个人向你们发出召唤，你们也属于他。</span>
<span className="v" id="v8" data-v="8" data-xref="Leviticus 19:18; 加拉太书 5:14; 马太福音 22:39"> 如果你们遵守经书的尊贵法律：“要爱邻如己”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引自《利未记》19:18。">b</a></sup>，你们就做对了。</span>
<span className="v" id="v9" data-v="9" data-xref="Leviticus 19:15; 雅各书 2:1–4; 约翰一书 3:4"> 如果你们显示出偏向之心，那就是犯罪，律法就会裁定你们犯法。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 3:10; 马太福音 5:18–19; Deuteronomy 27:26"> 如果一个人遵守了律法的所有要求，但却违背了其中一条，就等于违反所有律法。</span>
<span className="v" id="v11" data-v="11" data-xref="Exodus 20:13–14; 马太福音 5:21–28; Deuteronomy 5:17–18"> 上帝告诉你们不可奸淫，也告诉你们不可杀人；如果你不奸淫但却杀人，那就还是犯法。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《出埃及记》20:13-14或《申命记》5:17-18。">c</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="雅各书 1:25; 雅各书 2:8; 彼得后书 1:4–8"> 你们的语言和行为，应该像那些受自由律法审判之人。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 5:7; 马太福音 6:15; Proverbs 21:13"> 任何人如果没有怜悯之心，审判他的时候也就不会有怜悯；但怜悯胜过审判。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="目前对这节经文的确切含义有争议，但其核心基本是强调上帝的慈悲性格。">d</a></sup></span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 7:26–27; 马太福音 7:21–23; 雅各书 1:22–25"> 我的朋友们，如果一个人说他有信心，却没有行动，有什么益处呢？这“信心”能救他吗？</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 3:11; 马太福音 25:35–40; Isaiah 58:7"> 如果你的兄弟姐妹缺衣少食，</span>
<span className="v" id="v16" data-v="16" data-xref="Proverbs 3:27–28; 约翰一书 3:16–18; 马太福音 25:42–45"> 你对他们说：“祝福你们！愿你们吃得饱穿得暖！”，但却不给他们活下去所需要的，那有什么用处呢？</span>
<span className="v" id="v17" data-v="17" data-xref="雅各书 2:26; 彼得后书 1:5–9; 雅各书 2:19–20"> 如果你事实上没有做良善正确的事情，你对上帝信的本身也是死的，毫无价值的。</span>
<span className="v" id="v18" data-v="18" data-xref="雅各书 3:13; 雅各书 2:14; 加拉太书 5:6"> 有人会驳斥：“你有对上帝的信心，我做我的善行。”那么，请显示你对上帝有信心却没有善行，我会借着我的善行，将我的信心显示给你看。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 4:34; 马可福音 1:24; 马太福音 8:29"> 你相信只有一个上帝？非常好，但魔鬼也相信上帝，但他们却害怕上帝。</span>
<span className="v" id="v20" data-v="20" data-xref="雅各书 2:17; 雅各书 2:26; Proverbs 12:11"> 愚昧的人哪！你难道不知道，相信上帝却不做正义良善之事，并没有什么用处吗？</span>
<span className="v" id="v21" data-v="21" data-xref="Genesis 22:16–18; Genesis 22:9–12; 约翰福音 8:39"> 我们的祖先亚伯拉罕将其子以撒献在祭坛上，不是因其行为而被视为正确吗？<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="或者“被证明是正确的。”">e</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="帖撒罗尼迦前书 1:3; 希伯来书 11:17–19; 加拉太书 5:6"> 你看，他对上帝的信心与他的行为一致，他的信心因其行为而变得完整。</span>
<span className="v" id="v23" data-v="23" data-xref="Genesis 15:6; Isaiah 41:8; 2 Chronicles 20:7"> 正如经文所说：“亚伯拉罕相信上帝，这被视为他做出正义良善之事。”<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="引自《创世纪》15:6。">f</a></sup>他也被称为上帝的朋友。<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="见《以撒亚纪》41：8。">g</a></sup></span>
<span className="v" id="v24" data-v="24" data-xref="雅各书 2:21–22; 雅各书 2:15–18; Psalms 60:12"> 因此一个人被称为正直良善，是因其行为，而非单纯因为对上帝的信。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 11:31; Joshua 6:22–25; Joshua 2:19–21"> 同样，妓女喇合照顾信使，从另一条路把他们送走，她难道不会因这一行为而被称为正义良善吗？</span>
<span className="v" id="v26" data-v="26" data-xref="雅各书 2:20; 雅各书 2:17; 雅各书 2:14"> 身体没有灵即死；同样，信心没有行为也为死。</span>

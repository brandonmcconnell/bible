<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Ezekiel 12:15; 彼得前书 1:1; 约翰福音 7:35"> 这封信来自上帝和主耶稣基督的仆人雅各，写给散落在各国的十二支派。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="即以色列的十二个部落。">a</a></sup>在此向你们问候！</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="彼得前书 1:6–8; 雅各书 1:12; 哥林多后书 12:9–10"> 我的朋友们，当你们遭遇各种困难时，请选择保持欢喜；</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 5:3–4; 希伯来书 10:36; 歌罗西书 1:11"> 因为你们知道，这些都是挑战你对上帝的信心，这个过程会产生忍耐。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 21:19; 彼得前书 5:10; 马太福音 5:48"> 希望你们的忍耐尽可能强大，让你们可以彻底成熟，没有任何匮乏。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="Proverbs 2:3–6; 约翰福音 15:7; Proverbs 3:5–7"> 你们如有人需要智慧，就询问上帝，他慷慨厚赐众人，从无保留。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 21:21–22; 希伯来书 11:6; 马可福音 11:22–24"> 但要凭着对他的信念祈求他，不要有疑惑。疑惑之人，正如被风吹拂翻腾的碎浪。</span>
<span className="v" id="v7" data-v="7" data-xref="雅各书 4:3; Isaiah 58:3–4; Proverbs 21:27"> 那样的人别想从主那里获得什么——</span>
<span className="v" id="v8" data-v="8" data-xref="1 Kings 18:21; 马太福音 6:24; 雅各书 4:8"> 因为这样三心两意之人，在所有道路上都会摇摆不定。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="Jeremiah 9:23–24; 雅各书 2:5–6; Proverbs 19:1"> 出身贫穷的信徒，应当以赐予他们的高位为荣；</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前书 1:24; 约翰一书 2:17; Job 14:2"> 富足之人也不应该以谦卑之位为辱；<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="主要指上帝看待每个群体的方式（1:9-10）；不一定是他们在社会中的地位……">b</a></sup>因为他们会向田野中的花，必会枯萎。</span>
<span className="v" id="v11" data-v="11" data-xref="Isaiah 40:7–8; Psalms 37:35–36; Psalms 49:6–14"> 太阳出来，热风一吹，草就会枯干，花必凋谢，它的美也会消散；富足之人也会以同样方式失去所获得的一切。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彼得前书 5:10; 彼得前书 1:6–8; 启示录 2:10"> 能忍受磨炼之人是有福的；因为在证明其值得信赖后，他们必会获得生命的王冠，这是主向爱他之人做出的承诺。</span>
<span className="v" id="v13" data-v="13" data-xref="Habakkuk 2:12–13; 雅各书 1:12; 罗马书 9:19–20"> 一个人在被试探时不可说“上帝在试探我”；因为上帝无法被恶试探，他也不会试探任何人。</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 7:21–22; 以弗所书 4:22; 马太福音 15:18"> 这试探来自我们自己的邪恶欲望，它让我们迷失，给我们设下陷阱。</span>
<span className="v" id="v15" data-v="15" data-xref="Psalms 7:14; Job 15:35; 罗马书 5:12–21"> 这样的欲望会生出罪；罪成长后就成为死亡。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="加拉太书 6:7; 雅各书 1:19; 腓立比书 2:12"> 我亲爱的朋友们，不要被欺骗。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 3:27; 马太福音 7:11; 希伯来书 13:8"> 所有的美好、所有完美的礼物，都是来自上面，并从创造太阳、月亮和星星的父那里下，与他们不同的是，他不会改变，他不会动摇或产生阴影。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="雅各所指似乎是天体和日食（阴影）的运动变化。">c</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 8:29–31; 彼得前书 1:23; 约翰福音 3:3–5"> 他选择通过真理之道给我们新生命，通过这种方式，在他所创造的万物中，我们对他才会如此特别。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="通常被认为，这是指上帝对我们灵性重生的召唤和供养。">d</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="Proverbs 17:27; Proverbs 21:23; Proverbs 14:29"> 我亲爱的朋友们，请记住，人人都应该快速聆听，但要慢慢地说，慢一点动怒；</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太后书 2:24–25; 以弗所书 4:26; 雅各书 3:17–18"> 因为人的愤怒无法体现上帝的良善特征。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原意为“成就上帝的正直良善。”">e</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="以弗所书 4:22; 以弗所书 1:13; 彼得前书 2:11"> 所以要摆脱一切污秽和邪恶，谦卑地接受植入你们心中的道，因为这道能拯救你们。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 2:13; 路加福音 6:46–48; 约翰福音 13:17"> 你们的行为应该遵守道的指示，不要只是听，不要自己欺骗自己；</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 7:26–27; Ezekiel 33:31–32; 雅各书 2:14–26"> 如果你只去听道而不践行，就像盯着镜子中自己的脸。</span>
<span className="v" id="v24" data-v="24" data-xref="彼得后书 3:11; 路加福音 1:66; 路加福音 7:39"> 你看到了自己，但走开后，马上就忘记自己的样子。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 11:28; 约翰福音 13:17; 哥林多后书 3:17–18"> 但如果你仔细研究那让人自由的完美律法，遵守它，不像有些人那样只是听听，然后就忘记了，而是要在行动中遵守它，这样你就会因自己的行为而受到祝福。</span>
<span className="v" id="v26" data-v="26" data-xref="以弗所书 4:29; Psalms 141:3; 彼得前书 3:10"> 如果你认为自己很虔诚，却不约束自己的语言，就是自己欺骗自己，你的虔诚毫无用处。</span>
<span className="v" id="v27" data-v="27" data-xref="Isaiah 1:16–17; 约翰一书 3:17–19; 加拉太书 6:9–10"> 在我们的天父上帝眼中，纯洁而真诚的虔诚，就像去造访患难中的孤儿寡妇，要保护自己不被世俗所污染。</span>
</div>
</div>

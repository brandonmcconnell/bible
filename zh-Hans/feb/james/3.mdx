<span className="v" id="v1" data-v="1" data-xref="路加福音 12:47–48; 提摩太前书 1:7; 彼得前书 5:3"> 我的朋友们，你们中不应有太多人去传授，因为你们知道，我们是谁做教师的人在审判的时候会承担更沉重的责任。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各书 1:26; Proverbs 13:3; 彼得前书 3:10"> 我们在许多的事上都有过错，如有人在言语上没有过错，他就是真正的好人，也能够控制其整个身体。</span>
<span className="v" id="v3" data-v="3" data-xref="Psalms 32:9; Psalms 39:1; 雅各书 1:26"> 我们把嚼环放入马嘴，让它们驯服，借此驾驭它们的整个身体。</span>
<span className="v" id="v4" data-v="4" data-xref="Psalms 107:25–27; 马太福音 8:24; 使徒行传 27:14–38"> 再看看船，船只虽然很大，又会受到狂风摧残，但舵手只用小小的舵，就可以随意操纵船身。</span>
<span className="v" id="v5" data-v="5" data-xref="Proverbs 18:21; Jeremiah 9:3–8; Proverbs 12:18"> 同理，舌头虽然只是身体的一个小器官，却会说出夸大之语。想想一个小小的火种，就可以烧毁整个森林；</span>
<span className="v" id="v6" data-v="6" data-xref="Psalms 120:2–3; Proverbs 16:27; 马可福音 7:15"> 舌头就是火！在身体的各个器官中，舌头就是那邪恶世界，它会让你整个人蒙羞，烧毁你整个生命，因为那是被哥和拿之火所点燃。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="哥和拿：耶路撒冷外面的垃圾场，这里会用火焚烧垃圾。这个词被象征性指做恶人的终点。见《马太福音》5:22 脚注。">a</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 5:4"> 人类可以驯服所有飞禽走兽、爬行动物和水生物，</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 3:13; Psalms 140:3; Psalms 55:21"> 但没有人能够驯服舌头；它是难以控制的恶物，充满了致命毒素。</span>
<span className="v" id="v9" data-v="9" data-xref="Psalms 10:7; Genesis 1:26–27; Psalms 62:4"> 我们用它赞美我们的主和天父，也用它来咒诅按上帝形象造出的人。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 12:14; 彼得前书 3:9; 哥林多前书 3:3"> 同一张嘴，又称颂主，又咒诅人，我的朋友们，这不应该！</span>
<span className="v" id="v11" data-v="11"> 一个泉眼中能同时涌出甜水和苦水吗？</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 6:43–44; 马太福音 12:33; 马太福音 7:16–20"> 我的朋友们，无花果树能结橄榄吗？葡萄树能长无花果吗？咸水也不能生出甜水！</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太书 5:23; 雅各书 3:17; 马太福音 5:5"> 你们中间如有人有智慧、有见识，让他们用美好的生活展示自己的行为，用智慧的善良和周全的考量，做正义良善之事。</span>
<span className="v" id="v14" data-v="14" data-xref="雅各书 3:16; 哥林多前书 13:4; 腓立比书 2:3"> 如果你们心中有刻薄的嫉妒，还有自私的野心，就不能对其夸口，不可用说谎反对真理。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各书 3:17; 雅各书 1:17; 哥林多前书 3:19"> 这种“智慧”并非来自天上，而是人间的、非灵性的、恶魔的“智慧。”</span>
<span className="v" id="v16" data-v="16" data-xref="雅各书 3:14; 哥林多前书 3:3; 哥林多前书 14:33"> 凡有嫉妒和自私的地方，就必有纷扰和各种恶行。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 5:22–23; Proverbs 2:6; 哥林多前书 13:4–7"> 但来自天上的智慧，首先是纯洁的，可带来和平。它善良，接受合理的想法，里面满是恩慈和善果，真实而没有虚伪。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 5:9; Hosea 10:12; 腓立比书 1:11"> 那些种下和平之人，其真正的正直良善，也将让他收获和平果实。</span>

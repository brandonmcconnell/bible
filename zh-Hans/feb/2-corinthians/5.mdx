<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Job 19:25–26; 约翰一书 3:2; 彼得后书 1:13–14"> 我们知道，当我们所居住的人间“帐篷”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这里的象征意义是将人间的身躯视为帐篷，天堂的身体则是一所房子，这两栋房子都像身上的“衣服”一样。">a</a></sup>被拆毁，我们就会获得上帝为我们准备的居所，并非人类建造，而是天上永存的居所。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 8:23; 哥林多前书 15:53–54; 哥林多后书 5:3–4"> 我们叹息着、如此迫切地渴望能够拥有那天上的住处，就像换上新衣服。</span>
<span className="v" id="v3" data-v="3" data-xref="Genesis 3:7–11; 启示录 16:15; 启示录 3:18"> 当我们穿上这新衣服，就不会再赤身裸体。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 15:53–54; 哥林多后书 5:2; Isaiah 25:8"> 我们身处这“帐篷”中哀叹，被今生的苦压垮。与其说我们希望脱去今生之衣，倒不如说我们更期待将要穿上的新衣，这样就可以在这必死之躯中注入生命。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 1:22; 以弗所书 1:13–14; 罗马书 8:23"> 上帝为我们准备了这一切，带来灵保证我们达成这目标。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 5:1; 腓立比书 3:20–21; 希伯来书 11:13"> 我们始终保持信心，但知晓一点：当我们安然生活在这肉体之躯中，就远离了主。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 11:1–27; 哥林多后书 4:18; 罗马书 8:24–25"> (因为我们是靠信靠上帝而活，而不是靠看见他而活）。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比书 1:20–24; 哥林多后书 5:6; 约翰福音 14:3"> 正如我所说，我们充满信心地期盼着远离这身躯，与主同在。</span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 1:10; 彼得后书 3:14; 罗马书 14:18"> 因此我们立定志向，无论是否住在自己的身体中，都要让主欢喜。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 16:27; 启示录 22:12; 以弗所书 6:8"> 因为最终我们所有人都要现身基督的审判之座面前，然后根据每个人此生所做的一切，或善或恶，接受应得的结果。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="犹大书 1:23; 希伯来书 10:31; 提摩太后书 2:24–26"> 我们知道我们尊重主，以此劝勉众人。上帝非常了解我们是谁，我盼望你们的内心也能清楚地知晓自己。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 3:1; 哥林多后书 1:14; 加拉太书 6:12–14"> 我们并不是再次向你们夸赞自己，只是给予你们让我们骄傲的机会，让你们可以应对那些只看外在、不关注内心之人。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“内心深处。”">b</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 11:16–17; 哥林多后书 11:1; 哥林多后书 12:6"> 如果我们“疯狂”，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="这可能是科林斯人对保罗及其同伴的批评。">c</a></sup>那也是为了上帝。如果我们清醒，那是为了你们。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 2:20; 罗马书 14:7–9; 马太福音 10:37–38"> 基督的爱督促我们前进，因为我们确定他为众人而死，所以众人现在已经死去。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 14:7–9; 彼得前书 4:2–4; 彼得前书 1:14–15"> 基督为众人而死，就是为了让他们不再为自己而生，而是要为已经死去、并且死而复活的主而生。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 3:11; 腓立比书 3:7–8; 约翰福音 6:63"> 从今以后，我们不再从人的角度看待人。虽然我们曾经以人的角度看待基督，但现在已经不再如此。</span>
<span className="v" id="v17" data-v="17" data-xref="Ezekiel 36:26; 以弗所书 4:22–24; Isaiah 43:18–19"> 所以任何人如果与基督同在，就是一个全新的生命，旧人已去，新人已来！</span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 1:20–21; 哥林多后书 5:19–20; 罗马书 5:10–11"> 上帝通过基督改变了我们，让我们不再与他为敌，而是成为朋友。上帝给了我们同样的使命，将他的敌人转变成他的朋友。</span>
<span className="v" id="v19" data-v="19" data-xref="Isaiah 43:25; Isaiah 44:22; 约翰一书 2:1–2"> 通过基督，上帝让这个世界不再与他为敌，而是成为朋友，不再追究他们的罪过，并且告诉了我们化敌为友的道理。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 6:20; 路加福音 14:23; Malachi 2:7"> 因此，我们就是基督的使者，上帝通过我们劝告世人：“请求你们，难道不希望回归、与上帝为友吗？”</span>
<span className="v" id="v21" data-v="21" data-xref="彼得前书 2:22–24; 彼得前书 3:18; 罗马书 5:19"> 耶稣从未犯下任何罪过，上帝让无罪的他经历罪的后果，让我们可以获得善良正义的性格，因为上帝就是善良正义。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或“我们可以拥有正义，因为上帝即正义”，这是指道德上的正确，而不是“对错”中的正确。">d</a></sup></span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 16:9; 哥林多后书 9:2; 哥林多后书 9:4"> 兄弟姐妹们，现在我想让你们知道上帝赐予马其顿教会的恩典，</span>
<span className="v" id="v2" data-v="2" data-xref="雅各书 2:5; Proverbs 11:25; 哥林多后书 6:10"> 尽管他们遭受了可怕的痛苦，他们心中仍然满溢着欢喜。尽管他们如此贫困，内心仍然充满了慷慨。</span>
<span className="v" id="v3" data-v="3" data-xref="Exodus 35:29; Exodus 35:5; Exodus 35:21–22"> 我可以作证，他们已力所能及地给予，甚至超出了他们的能力！</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 24:17; 加拉太书 6:10; 哥林多后书 9:1"> 他们再三恳求我们，能够有此殊荣承担上帝之子的侍奉责任，这是他们自己的选择。</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 12:1; 罗马书 14:7–9; 2 Chronicles 30:12"> 他们不仅达成了我们对他们的希望，还按照上帝的旨意将自己献给主，然后献给我们。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 12:18; 哥林多后书 8:19; 哥林多后书 8:4"> 由于提多率先开始与你们一起工作，所以我们鼓励他回到你们那里，完成你们这光荣的侍奉职责。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 9:8; 彼得后书 1:5–8; 帖撒罗尼迦后书 1:3"> 你们的一切都很丰饶，包括对上帝的信、口才、灵性知识、彻底的奉献要尊重他们的引领，尊重在这份工作中以这种奉献精神提供帮助的所有人。和对我们的爱。那么，在履行这光荣的侍奉职责时，也要展示你们的丰饶。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 7:6; 约翰一书 3:17–19; 雅各书 2:14–16"> 我并不是在命令你们这样做，而是通过与其他人进行比较，证明你们的爱有多么诚挚。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="大概意味着其他教会，例如马其顿的教会。">a</a></sup></span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 8:32; 腓立比书 2:6–8; 马太福音 20:28"> 你们知道主耶稣基督的恩典。尽管他非常富足，却为你们选择贫穷，然后通过他的贫穷，让你们变得富足。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 6:18–19; 希伯来书 13:16; 哥林多后书 9:2"> 我向你们提供一个建议：完成你们已经开始的工作，将对你们有益。在去年，你们不仅率先慷慨给予，也是率先产生这种想法。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 9:2"> 现在就去完成你们计划做的事情，像你们计划的那样热情地完成，在力所能及的范围内给予。</span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 12:42–44; 哥林多后书 9:7; 路加福音 21:1–4"> 只要有意愿，只需要力所能及地给予即可，而不是给出自己没有的东西。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 4:34; 罗马书 15:26–27"> 这样做不是为了让其他人更轻松，让你们更受累，而是要大家都均等。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 9:12; 使徒行传 4:34"> 现在你们很富裕，完全可以满足他们的需要。反过来，当他们变得富裕，就可以满足你们的需要，这样就可以公平对待所有人。</span>
<span className="v" id="v15" data-v="15" data-xref="Exodus 16:18; 路加福音 22:35"> 正如经文所记：“拥有太多之人没有剩余，拥有太少之人并不缺乏。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这里指的是《出埃及记》16:8 中收集吗哪。">b</a></sup></span>
<span className="v" id="v16" data-v="16" data-xref="启示录 17:17; Jeremiah 32:40; 哥林多后书 2:13–14"> 感谢上帝，他给了提多与我一样的对你的奉献。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 8:6; 希伯来书 13:22; 哥林多后书 8:10"> 尽管提多愿意按照我们说的做，他去见你们却是他自己的想法，他已经决定这样做。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 12:18; 哥林多后书 8:19; 哥林多前书 7:17"> 我们还派了一位兄弟和他同去，此人在传播福音方面的工作，获得了众教会的称赞。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 16:3–4; 哥林多后书 4:15; 哥林多后书 9:8"> 不但如此，众教会更指派他作我们的旅伴，将我们所拥有的慷慨馈赠出去。这样做是为了主的荣耀，也是为了展示我们渴望帮助其他人的热切心愿。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="参见《哥林多前书》16:3-4。">c</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="帖撒罗尼迦前书 5:22; 罗马书 14:16; 以弗所书 5:15"> 有人批评我们使用这赠礼的方式，对此我想进行辩护。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 12:17; 彼得前书 2:12; 腓立比书 4:8"> 我们关注的是以正义方式正确行事，不仅在主的面前，还是要在所有人的面前。</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比书 2:20–22"> 我们还派了另一位兄弟与他们同去，他经受住了我们的多次考验，值得信赖，也非常希望提供帮助。现在他对你们更有信心，因此也更热切地希望提供帮助。</span>
<span className="v" id="v23" data-v="23" data-xref="腓立比书 2:25; 腓利门书 1:17; 哥林多后书 8:6"> 如果有人说起提多，我会说他是我的同伴。他为了你们而与我合作。其他的两位兄弟则是教会的代表，是基督的荣耀。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 7:14; 哥林多后书 7:4; 哥林多后书 9:2–4"> 所以，请在众教会面前欢迎他们，向他们证明你们的爱，证明你们的确值得我们骄傲。</span>

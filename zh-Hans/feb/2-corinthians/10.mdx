<span className="v" id="v1" data-v="1" data-xref="哥林多后书 10:10; 马太福音 11:29; 加拉太书 5:2"> 我是保罗，当我与你们在一起时，我是“羞涩”的，但离开你们后，我又是“大胆”的。在此，我亲自以基督的善良和温柔恳请你们。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="保罗似乎正在处理一些针对他的控诉。">a</a></sup></span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 13:10; 哥林多后书 13:2; 加拉太书 5:16–25"> 恳请你们，让我下一次与你们相处之时，无需再强迫自己变得强硬，当有人认为我们以凡俗方式行事时，我也无需再壮着胆子予以回应。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 10:4; 加拉太书 2:20; 彼得前书 4:1–2"> 我们虽然生活在这个世界，但并未按照俗世的方式战斗。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 6:7; 以弗所书 6:13–18; Jeremiah 1:10"> 我们作战所用的兵器不是属于这个世界，而是上帝的强大力量，足以摧毁人类思想的堡垒，消灭误导人类的谬误。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 4:12; Isaiah 55:7; 彼得前书 1:14–15"> 为了阻挡上帝的知识，人类用傲慢铸就巍峨高墙，但上帝的力量仍然会将其推倒。他会制止所有背叛想法，将其转化为对基督的服从认同。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 2:9; Numbers 16:26–30; 哥林多后书 7:15"> 我们已经准备好，当你们完全顺服，就会去惩罚所有不顺从之人。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 5:12; 约翰福音 7:24; 哥林多前书 14:37"> 看看是什么在盯着你的脸！如果有人认为自己属于基督，就要再想一想：他属于基督，同样我们也属于基督。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 13:10; 哥林多后书 12:6; 加拉太书 1:1"> 尽管我可能略微夸大了我们的权力，但也不会感到难堪。主赐给我们这样的权力，就是为了成就你们，而非破坏你们。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 10:10; 哥林多前书 4:19–21; 哥林多前书 4:5"> 我写信的目的并不是为了惊吓你们。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 1:17; Exodus 4:10; 加拉太书 4:13–14"> 有人说：“他的信严厉又强硬，但他本人却其貌不扬，不善言辞。”</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 12:20; 哥林多后书 13:2–3; 哥林多后书 13:10"> 说这话的人应该知道，我们未与你们在一起时，会通过文字表达。我们与你们在一起时，就会采取行动。</span>
<span className="v" id="v12" data-v="12" data-xref="Proverbs 27:2; Proverbs 26:12; 路加福音 18:11"> 有的人只考虑自己，我们不会与之妄加比较。他们用自己衡量自己，用自己比较自己，这真的很愚蠢。</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 12:6; 罗马书 15:20; 彼得前书 4:10"> 但我们不会用无法衡量的夸张方式自我吹嘘，而是使用上帝赐给我们的量度，衡量我们的所作所为。这量度也适用于你们。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 4:15; 提摩太前书 1:11; 罗马书 1:16"> 我们这样说，并不是将自己的权力过度延伸到你们那里，好像我们从未到过你们那里去。事实上，我们早已将基督的福音传到你们那里。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="保罗说，他来到哥林多时，一直都在其责任范围内传播福音。可能有人会说，科林斯并非属于保罗的责任范围内。">b</a></sup></span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 15:20; 帖撒罗尼迦后书 1:3; 哥林多后书 10:13"> 我们并未以无法衡量的夸张方式自吹自擂，将别人的功劳冠在自己的头上。相反，我们希望随着你们对上帝信仰的不断增加，为你们所做的工作也能大幅扩展。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 15:24–28; 使徒行传 19:21"> 这样我们就能在你们以外的地点传递福音。对于其他人所完成的工作，我们不会拿来夸耀。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="保罗不想分析论功领赏的问题，宁愿继续传播福音。">c</a></sup></span>
<span className="v" id="v17" data-v="17" data-xref="Jeremiah 9:23–24; 哥林多前书 1:31; 雅各书 1:9–10"> “如果你想夸耀，就夸耀主。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《耶利米书》9:24。">d</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 16:15; Proverbs 21:2; 哥林多前书 4:5"> 因为受尊敬的并非自我赞美之人，而是主所赞美的人。</span>

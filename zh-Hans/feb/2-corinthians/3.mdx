<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 12:11; 哥林多后书 10:12; 哥林多后书 5:12"> 我们这时开始自吹自擂了吗？或者我们像有些人那样，需要为你们提供推荐信，或者希望你们为我们写推荐信？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 9:1–2; 帖撒罗尼迦前书 1:8; 罗马书 1:8"> 你们就是我们的推荐信，以你们的经历写就，供所有人诵读和知晓。</span>
<span className="v" id="v3" data-v="3" data-xref="Ezekiel 11:19; Jeremiah 31:33; 希伯来书 8:10"> 你们也彰显了自己就是来自基督的信函，通过我们传递给众人。这封信函并非用墨写就，而是用永续上帝之灵写成。它并非写在石板上，而是写在人类生命的经历之中。</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比书 1:6; 以弗所书 3:12; 哥林多后书 2:14"> 通过基督，我们在上帝面前才有这样的信心。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 12:9; 腓立比书 4:13; 哥林多前书 15:10"> 我们并不认为凭借自己的力量这样做，是上帝给了我们这样的能力！</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 6:63; 罗马书 7:6; Jeremiah 31:31"> 他赋予我们为新约侍奉的责任，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或“盟约。”">a</a></sup>这新约并非来自律法文字，而是来自灵。律法的文字会杀戮，但灵赋予生命。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 3:9–11; 罗马书 10:4; Exodus 31:18"> 以往人们会在石头上刻字，表达与上帝之间的关系。这种方式尽管表达了上帝的荣耀，但人仍不免一死，这荣耀也在慢慢暗淡。因此，以色列人甚至无法去正视摩西面庞散发的闪亮的光芒。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 3:16; 以弗所书 2:18; 加拉太书 3:14"> 那么，以经文的方式表达上帝的新方法，是否会有更大的荣耀？</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 3:21–22; 希伯来书 12:18–21; 哥林多后书 5:21"> 如果那定罪的古老方式仍然散发荣光，上帝成就我们良善正直的新方法就更有荣光！</span>
<span className="v" id="v10" data-v="10" data-xref="彼得后书 1:17; Haggai 2:7–9; 使徒行传 26:13"> 相比新方法无以伦比的荣光，曾经荣耀的旧方法就显得彻底黯淡无光。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 5:20–21; 希伯来书 8:13; 希伯来书 7:21–25"> 如果正在暗淡的旧方法尚有荣光，作为其后续的新方法就拥有更多的荣光。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 7:4; 使徒行传 4:13; 腓立比书 1:20"> 既然我们心怀自信的希望，我们就真正拥有了胆量。</span>
<span className="v" id="v13" data-v="13" data-xref="Exodus 34:33–35; 希伯来书 10:1–9; 以弗所书 2:14–15"> 我们不必像摩西那样，在脸上蒙上面纱，避免色列人因他脸上的荣光而目眩。事实上，这荣光已经开始暗淡。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 4:3–4; 使徒行传 26:18; 罗马书 11:25"> 尽管如此，他们的态度一直顽固不明、铁石心肠。因为即使是现在，当他们诵读旧约的时候，这“面纱”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="换言之，他们看不清。">b</a></sup>仍然存在，只有通过基督可以将其揭开。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 13:27–29"> 即使是现在，他们在诵读摩西之书的时候，心中仍然蒙着这样的面纱。</span>
<span className="v" id="v16" data-v="16" data-xref="Exodus 34:34; Isaiah 29:18; Isaiah 25:7"> 但当他们转向并接受主，这层面纱就会去掉了。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 8:2; 加拉太书 5:13; 约翰福音 8:32"> 主就是灵，主的灵在哪里，哪里就有自由。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 4:6; 以弗所书 4:22–24; 罗马书 12:2"> 我们所有人脸上的面纱都已经揭下，仿佛一面镜子体现了主的荣光。我们已经转化成与灵相同的镜像，他的荣光越来越闪亮，这都要感谢主之灵。</span>

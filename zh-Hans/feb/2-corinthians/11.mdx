<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 11:4; 哥林多前书 1:21; 哥林多后书 11:19"> 希望你们容忍我这一点点的蠢笨，其实你们一直都很容忍我。</span>
<span className="v" id="v2" data-v="2" data-xref="Hosea 2:19–20; 以弗所书 5:26–27; Isaiah 54:5"> 我把你们献给基督，就像把贞洁童女许配给一个丈夫。所以我对你们感到忧心忡忡，但这是一种神圣的嫉妒之情。</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 2:8; 加拉太书 1:6; 以弗所书 4:14"> 我担心你们的思想受到引诱，不再真诚纯粹地承诺于主，就像蛇用诡计欺骗了夏娃。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 1:6–8; 哥林多前书 3:11; 提摩太前书 2:5"> 我担心如果有人来告诉你，除了我所讲述的耶稣以外，还有另一位耶稣，你们轻而易举地相信他们，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="换句话说，他们对以不同方式解释福音的人太宽容。">a</a></sup>接受另一个不同的灵，而非你们已经接受的那一个，或者听取另一个福音，并非你们相信的那一个。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 12:11–12; 哥林多前书 15:10; 加拉太书 2:6–9"> 我认为自己并不比那些“超级使徒”低等。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所书 3:4; 哥林多前书 1:17; 哥林多后书 4:2"> 虽然我不善于辞令，但却了解自己在说什么，我们已经通过各种方式向你们清楚显明这一点。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 12:13; 帖撒罗尼迦前书 2:9; 哥林多后书 10:1"> 我保持谦卑，让你们提升，把上帝福音免费传给你们，这样做有罪吗？</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比书 4:18; 哥林多后书 11:9; 腓立比书 4:14–16"> 为了帮助你们，我接受了其他教会的酬劳，也可以说是剥削了其他教会。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦后书 3:8–9; 帖撒罗尼迦前书 2:9; 帖撒罗尼迦前书 2:6"> 我在你们那里时，也曾遇到需要帮助的时候，但我没有连累任何人，因为从马其顿前来的信徒们，已经满足了我的需求。我坚决不成为你们的负担，我从未如此。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 9:1; 罗马书 1:9; 使徒行传 18:12"> 我确认这一点，就像确认我心灵中的基督真理：在亚该亚一带没有人能阻止我这样夸赞！</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 12:15; 哥林多后书 6:11–12; 哥林多后书 7:3"> 为什么？是我不爱你们吗？上帝知道是这样的。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 9:12; 哥林多前书 5:6; 哥林多后书 5:12"> 我曾做过的事情，未来还要继续做，防止有人借此机会吹嘘，声称他们的工作和我们一样。</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太书 1:7; 启示录 2:2; 约翰一书 4:1"> 这样的人就是假使徒，是不诚实的工人，伪装<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“将他们转为。”又见第 14 句。">b</a></sup>成基督的使徒。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 1:8; 哥林多后书 2:11; 哥林多后书 11:3"> 但不必对之感到惊讶，因为撒旦也伪装成光明天使，</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比书 3:19; 启示录 9:11; Isaiah 9:14–15"> 所以，如果撒旦的仆役装成良善的仆役，不必惊讶，但他们最终的解决办法还是会由其行为所决定。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 11:1; 哥林多后书 12:6; 哥林多后书 12:11"> 让我重复一下：请不要以为我很愚蠢，但如果你这么想，也要接纳我这愚蠢之人，让我可以稍微夸夸口。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="保罗认为，它也可以像自夸的假信徒那样夸耀自己。">c</a></sup></span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 7:12; 腓立比书 3:3–6; 哥林多后书 9:4"> 我所说的一切并非主会说的，不过是一些愚蠢的吹嘘。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 4:10; 哥林多后书 11:21–23; 哥林多后书 10:12–18"> 有许多人按着世俗的标准夸口，让我也来夸夸口。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 4:10; 哥林多前书 10:15; 哥林多前书 8:1"> （你们如此聪慧，竟然乐意容忍愚蠢之人。）<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="显然这是一种讽刺的说法，尤其是之后的讲述......">d</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="加拉太书 2:4; 加拉太书 4:3; 加拉太书 5:1"> 有人奴役你们，拿走你们的一切、榨干你们、在你们面前趾高气扬、打你的脸，你也愚蠢地容忍他们！</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 10:10; 哥林多后书 11:17; 哥林多后书 10:1–2"> 很遗憾我们太软弱了，无法像他们一样对待你们。但其他人夸口的所有事情，我们也敢开口。(在这里我又像个傻瓜一样说话了。)</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比书 3:5; 罗马书 11:1; 罗马书 9:4"> 他们是希伯来人？我也是。他们是以色列人？我也是。他们是亚伯拉罕的后裔？我也是。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 6:4–5; 哥林多后书 1:9–10; 哥林多后书 6:9"> 他们是基督的仆人？说句狂话，我更是。我受更多的劳苦，坐过更多的牢狱，受了过量的鞭打，常常有生命的危险。</span>
<span className="v" id="v24" data-v="24" data-xref="马可福音 13:9; Deuteronomy 25:2–3; 马太福音 10:17"> 我被犹太人打过五次，每次四十下减去一下，</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 14:19; 使徒行传 16:37; 希伯来书 11:37"> 被棍打过三次，被石头打过一次，三次遇着船坏掉，在深海里漂了一昼一夜，</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 14:5; 使徒行传 17:5; 使徒行传 13:50"> 多次行远路，遇着江河的危险、强盗的危险、同族的危险、外族的危险、<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原意为“异教徒。”">e</a></sup>城中的危险、荒野的危险、海上的危险、假兄弟的危险，</span>
<span className="v" id="v27" data-v="27" data-xref="腓立比书 4:12; 哥林多后书 6:5; 帖撒罗尼迦前书 2:9"> 劳碌辛苦，多次不得睡觉，又饥又渴，多次缺粮，赤身挨冷。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 7:17; 罗马书 15:16; 使徒行传 20:18–35"> 除了这些外面的事，还有为各教会挂心的事，天天压在我的身上。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 8:13; 哥林多前书 9:22; 加拉太书 4:8–20"> 有人软弱，我难道不软弱？有人陷在罪里，我难道不焦急？</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多后书 12:5–11; Proverbs 25:27; 哥林多前书 2:3"> 如果必须夸口，我就夸自己的弱点。</span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 9:5; 以弗所书 1:3; 约翰福音 10:30"> 主耶稣的父上帝是应当永远受称颂的，他知道我没有说谎。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 9:24–25; 哥林多后书 11:26"> 在大马士革，亚里达王手下的总督把守着大马士革城，要拘捕我，</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 9:25; 1 Samuel 19:12; Joshua 2:18"> 我就被人放在一个大篮子里，从城墙的窗户缒下来，逃脱了他的控制。</span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 4:7; 彼得前书 2:11; Proverbs 8:13"> 亲爱的朋友们，由于我们做出了这样的承诺，就应该洁净自己，除去身体和心灵上的一切污秽，通过敬畏上帝达成圣洁。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 20:33; 哥林多后书 6:12–13; 哥林多后书 11:9"> 请接纳我们作为你们的朋友！我们未做过任何措施，没有让任何人堕落，也没有利用过谁。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 6:11–12; 帖撒罗尼迦前书 2:8; 哥林多后书 11:11"> 我这样说不是为了定你们的罪，正如我之前所说，你们对我们如此重要，我们与你们可以同生共死。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 1:4; 哥林多后书 3:12; 雅各书 1:2"> 我愿为你们振臂高呼，因为你们让我感到如此光荣。你们就是对我最大的激励，尽管我们经历各种患难，你们让我格外欢喜。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 2:13; Deuteronomy 32:25; 使徒行传 20:1"> 我们抵达马其顿的时候，没有感到片刻的安宁。相反，我们受到了来自各方的攻击，外有争战，内有恐惧。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 1:3–4; 帖撒罗尼迦后书 2:16–17; 哥林多后书 7:13"> 尽管如此，上帝总能给沮丧之人带来鼓励。提多的到来就是我们最大的安慰。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 5:2; 犹大书 1:3; 哥林多后书 8:16"> 我们的安慰不仅因为他的到来，还因为你们给予他的鼓励。他告诉我们，你们渴望见到我，还因为我而感到难过和忧愁，这让我更加欢喜。</span>
<span className="v" id="v8" data-v="8" data-xref="启示录 3:19; Jeremiah 20:7–9; 马太福音 26:21–22"> 尽管我写的那封信让你们忧伤，但我并不后悔——其实我曾经感到后悔，因为那封信伤害了你们，但只是很短的一段时间。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 15:7; Jeremiah 31:18–20; 哥林多后书 7:10–11"> 现在我很快乐，不是因为伤害你们，而是因为这种痛苦让你们改变了心意。你们按照上帝的旨意感到难过，所以不会因为我们而受到任何伤害。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 3:19; 使徒行传 11:18; 提摩太后书 2:25–26"> 上帝希望我们感受到的忧伤，让我们可以改变心意，获得救赎。这种忧伤不会留下遗憾，但世俗的忧伤却会招致死亡。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 14:18; 提摩太前书 5:21–22; 提摩太后书 2:15"> 当你们依照上帝的旨意感受到了这种忧伤，看看你们都发生了什么。还记得你们变得多么热情，渴望为自己辩护，对已经发生的事情感到愤怒，认真对待这一切，渴望做正确的事情，关注自己是谁，渴望实现正义。你们通过所有这些改变，表明你们多么诚心地渴望恢复良善正直。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="保罗似乎是指之前提到需要注意的问题，例如第 2 章。">a</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 2:9; 提摩太前书 3:5; 哥林多后书 2:17"> 因此，以往我写信给你们，并未讨论谁做错事或被错误对待，而是表达了你们如何在上帝的面前为我们做出奉献。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 7:6; 哥林多前书 12:26; 哥林多前书 16:13"> 这让我们备受鼓舞。我们除了感受到鼓舞之外，还很高兴看到提多的欢喜，因为你们让他心安。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 7:4; 帖撒罗尼迦后书 1:4; 哥林多后书 1:18–20"> 我向他夸赞<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="保罗在这封信的这里和其他地方都说到了他夸口的事情。这应该理解为他对自己的骄傲，而不是对其他人的赞美。">b</a></sup>你们，你们没有让我失望。我对你们所说的都是真话，同样，我向提多夸赞你们也是出自真心。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比书 2:12; 哥林多后书 2:9; 约翰一书 3:17"> 提多还记起你们如何按照他所说的行事，如何以尊重的方式迎接他。这让他更加关爱你们。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 2:3; 腓利门书 1:8; 腓利门书 1:21"> 很高兴我可以对你们怀有充分的信心。</span>

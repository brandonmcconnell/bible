<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦后书 3:13; 加拉太书 6:9; 以弗所书 3:13"> 那么，上帝凭借其悲悯给予我们新方法，与他建立联系，我们就不能放弃。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 2:17; 帖撒罗尼迦前书 2:3–5; 哥林多后书 5:11"> 但我们已经放弃了秘密的、可耻的行为。我们绝不欺骗，绝不曲解上帝之道。我们在上帝面前彰显真理，让每个人都可以凭借自己的良心做决定。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 3:14; 哥林多前书 1:18; 帖撒罗尼迦后书 2:9–11"> 尽管我们传播的福音蒙着面纱，但这只是在将死之人的眼中才是如此。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 12:40; 哥林多后书 3:14; 使徒行传 26:18"> 那些不信上帝的人，是因为俗世的神明蒙蔽了他们的心灵。基督就是上帝的形象，但他们无法看到基督荣耀的福音。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 1:24; 哥林多前书 1:23; 帖撒罗尼迦前书 2:5–6"> 我们并不是宣扬<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“传教。”">a</a></sup>自己，而是在传播耶稣基督就是主，事实上，我们因耶稣的缘故成了你们的仆人。</span>
<span className="v" id="v6" data-v="6" data-xref="Isaiah 60:2; Genesis 1:3; 彼得前书 2:9"> 因为上帝说“要有光从黑暗里照出来”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引自《创世纪》1:3。">b</a></sup>，这光已经照在我们的心里，点亮耶稣基督脸庞的荣光，那是上帝知识的荣光。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 3:5–6; 哥林多后书 5:1; 以弗所书 2:8–9"> 我们将这珍宝放在瓦罐中，显明这超强力量源自上帝而非我们。</span>
<span className="v" id="v8" data-v="8" data-xref="雅各书 1:2–4; 罗马书 8:35–37; 彼得前书 4:12–14"> 我们虽然遭受各方面的攻击，却没有破碎。我们也会对前路感到迷茫，却从不绝望。</span>
<span className="v" id="v9" data-v="9" data-xref="Isaiah 43:2; Micah 7:8; Psalms 37:24–25"> 我们受到迫害，却上帝并未丢弃我们。我们被打倒了，却没有死亡。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 6:5; 提摩太后书 2:11; 彼得前书 4:13"> 我们以肉体之躯体现耶稣之死，所以也能让这肉体之躯体现耶稣之生。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 15:49; 罗马书 8:36; Psalms 44:22"> 当我们存活于世，因为耶稣的缘故常常遭受死亡的威胁，只有这样，我们必死之躯才能体现耶稣的生。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 13:9; 哥林多前书 4:10; 使徒行传 20:24"> 通过这种方式，我们面临死亡，才能让你们拥有生命。</span>
<span className="v" id="v13" data-v="13" data-xref="Psalms 116:10; 希伯来书 11:1–40; 哥林多后书 3:12"> 我们拥有相同的信仰之灵，正如经文中所记：“<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《诗篇》116:10。">c</a></sup>我相信上帝，所以我说出来。”我们也信仰上帝，所以为他说出来。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 4:14; 罗马书 8:11; 犹大书 1:24"> 因为知道上帝让主耶稣死而复生，也必定让我们与耶稣一同复活，将我们和你们一起呈献在他的面前。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 8:28; 以弗所书 3:20–21; 哥林多后书 9:11–12"> 这一切都是为了你们，让上帝的恩典惠及更多人，让对上帝的感恩更加强大，让荣耀归给上帝。</span>
<span className="v" id="v16" data-v="16" data-xref="Isaiah 40:31; 歌罗西书 3:10; Isaiah 40:29"> 所以，我们不会放弃。尽管我们的肉体身躯逐渐朽坏，内在的自我却每日展露新颜。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 8:18; 彼得前书 5:10; 罗马书 5:3–5"> 我们经历的苦难微不足道，只会短暂持续，只是为了让我们成就不断增强的荣耀。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 5:7; 罗马书 8:24–25; 希伯来书 11:1"> 对于可见的一切，我们并不担心自身。因为我们期待的是不可见的一切。我们看到的都是短暂的，看不见的才是永远。</span>
</div>

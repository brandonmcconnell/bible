<span className="v" id="v1" data-v="1" data-xref="哥林多后书 1:23; 哥林多后书 12:20–21; 哥林多后书 13:10"> 正因为如此，我决定还是不要造访你们，再一次为你们带来忧愁。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 7:8; 哥林多后书 1:14; 哥林多前书 12:26"> 如果我让你们忧愁，谁还能让我快乐呢？, 不会是那些我让他们忧愁之人。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 5:10; 哥林多后书 8:22; 腓利门书 1:21"> 所以我撰写了这封信，免得那些本会让我快乐之人，带给我忧愁。我深信，你们所有人都会分享我的欢乐。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 7:12; Proverbs 27:5–6; Leviticus 19:17–18"> 在撰写这封信的时候，我曾多次留下泪水，内心充满苦痛和沉重。这并不是为了让你们悲伤，而是让你们知道我对你们的爱有多深。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 5:12–13; 加拉太书 4:12; Proverbs 17:25"> 我并不想言过其实，但那个人带给你们所有人的痛苦，远远超过我。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 5:4–5; 提摩太前书 5:20; 哥林多后书 7:11"> 因你们中的绝大多数人，那个人遭受了足够的惩罚，</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 4:32; 加拉太书 6:1–2; 歌罗西书 3:13"> 所以现在你们应该饶恕他，友善对待他，免得他陷入绝望。</span>
<span className="v" id="v8" data-v="8" data-xref="犹大书 1:22–23; 加拉太书 6:1–2; 加拉太书 6:10"> 所以，希望你们要公开地向他表明你们的爱。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 10:6; 腓利门书 1:21; 腓立比书 2:22"> 我正是出于这个原因才写了那封信，就是为了解你们的真实性格，是否会凡事顺从。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 20:23; 马太福音 18:18; 哥林多后书 5:20"> 你们宽恕谁，我就宽恕谁。无论我宽恕了什么，都已在基督面前为了你们而宽恕。</span>
<span className="v" id="v11" data-v="11" data-xref="彼得前书 5:8; 以弗所书 6:11–12; 哥林多后书 11:3"> 这样做才能避免让撒旦有机可乘，我们太了解他的诡计了。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 16:8; 使徒行传 14:27; 歌罗西书 4:3"> 当年我为传播基督福音到了特罗亚，主便为我开启一扇机会之门。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 7:5–6; 哥林多后书 12:18; 提多书 1:4"> 但那时候的我因为找不到兄弟提多，心里无法感到安宁。于是我辞别众人去往马其顿<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="从特洛阿德到马其顿的旅程需要跨越海洋。">a</a></sup>。</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所书 5:2; 罗马书 8:37; 哥林多后书 2:15–16"> 但赞美上帝，他总是在基督里带领我们进行胜利的游行。无论我们身在何处，都能通过我们传播上帝知识的芬芳气息。</span>
<span className="v" id="v15" data-v="15" data-xref="以弗所书 5:2; 哥林多前书 1:18; Ezekiel 20:41"> 我们就像基督先给上帝的气息，从获得拯救以及正在消亡的人群中散发出来。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 3:5–6; 约翰福音 9:39; 彼得前书 2:7–8"> 对于死亡之人而言，这气息就是腐烂的气息，对于获得拯救的人而言，这气息就是生命的芬芳！</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 4:2; 哥林多后书 1:12; 彼得后书 2:1–3"> 我们不像大多数人那样，用上帝之道谋取利益。相反，我们真心诚意分享上帝之道，知晓上帝正在观察我们。</span>

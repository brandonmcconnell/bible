<span className="v" id="v1" data-v="1" data-xref="加拉太书 1:12; 哥林多后书 12:7; 约翰一书 5:20"> 夸口固然无益，却也是必要的。现在我要说说主的异象和启示。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 22:17; Ezekiel 8:1–3; 帖撒罗尼迦前书 4:17"> 我认识一个在基督里的人，他十四年前被提升到第三重天上去。（是带着身体被提的呢？我不知道，是离开了身体呢？我也不知道，只有上帝知道。）</span>
<span className="v" id="v3" data-v="3"> 我认识这个人，（是带着身体被提升，还是脱离身体提升，我都不知道，只有上帝知道。）</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 23:43; 启示录 2:7; Ezekiel 31:9"> 他被提升到乐园里去，听见了难以言喻的话，那是人不可以说的。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 11:30; 哥林多前书 2:3; 哥林多后书 12:9–10"> 为了这个人，我要夸口，但为了我自己，除了我的软弱以外，我没有可夸的。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 11:16; 哥林多后书 11:31; 哥林多后书 12:11"> 即使我想夸口，也不算愚妄，因为我要说的是真话。但我闭口不提，免得有人把我看得太高，超过他在我身上的所见所闻。</span>
<span className="v" id="v7" data-v="7" data-xref="Numbers 33:55; Judges 2:3; 2 Chronicles 32:25–26"> 又因为我所得的启示太大，恐怕会高抬自己，所以就有一根刺加在我的身上，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="保罗的身体可能有一些问题。">a</a></sup>让撒旦的差役来攻击我，免得我高抬自己。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 5:7; 马太福音 26:39–44; 1 Samuel 15:11"> 为了这事，我曾经三次求主，让这根刺离开我。</span>
<span className="v" id="v9" data-v="9" data-xref="腓立比书 4:13; 哥林多后书 12:10; Isaiah 40:29–31"> 他却对我说：“我的恩典够你用，因为我的能力在人的软弱面前会显得完整。”所以，我更喜欢夸自己的软弱，好让基督的能力临到我的身上。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 12:9; 以弗所书 6:10; 罗马书 5:3"> 因此，我因为基督的缘故，就以软弱、凌辱、艰难、迫害、困苦为欢喜，因为我什么时候软弱，就在什么时候刚强。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 11:5; 哥林多后书 11:1; 哥林多前书 15:8–10"> 我成了愚妄的人，是你们逼的。其实你们应该称赞我，因为我虽然算不得什么，却没有一点比不上那些“超级使徒”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="参见 11:5。">b</a></sup>。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 15:18–19; 哥林多后书 11:4; 哥林多后书 4:2"> 我在你们中间，以各种忍耐，用神迹、奇事和大能，作为使徒的凭据。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 9:12; 哥林多前书 9:6; 哥林多后书 11:7–9"> 除了我自己没有成为你们的重担以外，你们还有什么比不上别的教会呢？这一点委屈，请原谅我吧！<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="再次声明应被视为具有讽刺意味，又见16段。">c</a></sup></span>
<span className="v" id="v14" data-v="14" data-xref="Proverbs 19:14; Genesis 24:35–36; 哥林多前书 10:33"> 好了，我打算第三次到你们那里去，这一次也不会成为你们的重担，因为我所要的不是你们的东西，而是你们自己。儿女不需要为父母积财，父母却应该为儿女积财。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 2:8; 哥林多后书 1:6; 腓立比书 2:17"> 至于我，我甘心乐意为你们的灵魂付上一切，鞠躬尽瘁。难道我越爱你们，就越得不到你们的爱吗？</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦前书 2:5; 哥林多后书 10:2–3; 哥林多后书 12:13"> 好吧，即便如此，我也不是你的负担！也许我是个狡猾的人，会用诡计来陷害你！</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 9:5; 哥林多前书 4:17; 2 Kings 5:20–27"> 我派到你们那里去的人，我借着谁占过你们的便宜？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 8:6; 罗马书 4:12; 使徒行传 20:33–35"> 我劝提多到你们那里去，又派了那位兄弟一同去。提多占过你们的便宜吗？我们行事，不是同一个心灵吗？不是同样的步伐吗？</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 9:1; 哥林多前书 14:26; 哥林多后书 10:8"> 你们一直以为我们是在向你们申辩吗？我们与基督同在，在上帝面前说话。亲爱的你们，一切事都是为了成就你们。</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太书 5:19–21; 彼得前书 2:1; 罗马书 1:29"> 我怕我来的时候，看到你们不如我的预期，你们见我也不如你们的预期。我怕有纷争、嫉妒、恼怒、自私、毁谤、谗言、狂傲、混乱的事。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 13:2; 彼得前书 4:2–3; 歌罗西书 3:5"> 怕我再来的时候，我的上帝让我在你们面前感到羞愧。并且我要为许多从前犯罪的人哀痛，因为他们行了污秽、奸淫、邪荡的事，却不肯悔改。</span>

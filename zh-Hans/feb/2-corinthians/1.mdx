<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太后书 1:1; 腓立比书 1:1; 以弗所书 1:1"> 本函来自奉上帝旨意成为基督耶稣信徒的保罗，以及我们的教友提摩太兄弟。它将送给哥林多的上帝教会，以及和亚该亚地区的所有上帝子民。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 1:7; 以弗所书 6:23; 腓立比书 1:2"> 愿你们获得来自天父和主耶稣基督的恩典与平安。</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所书 1:3; 彼得前书 1:3; 罗马书 15:5–6"> 赞颂上帝、主耶稣基督的天父。他是充满怜悯的天父，是赐予所有抚慰的上帝。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 5:11; Isaiah 51:12; 帖撒罗尼迦后书 2:16–17"> 上帝在我们经历的所有苦难中抚慰我们，让我们可以用他所赐的抚慰，抚慰其他置身苦难之人。</span>
<span className="v" id="v5" data-v="5" data-xref="歌罗西书 1:24; 腓立比书 3:10; 哥林多后书 4:10–11"> 我们越多承受基督所受的痛苦，就会获得更多基督的抚慰。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太后书 2:10; 哥林多后书 1:4; 哥林多后书 4:15–18"> 如果我们身处不幸，那是为了能获得抚慰和拯救。如果我们获得抚慰，你也会获得抚慰，让你能够耐心地熬过我们所受的痛苦。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:17–18; 帖撒罗尼迦后书 1:4–7; 雅各书 1:12"> 我们对你们充满信心，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“我们对你的希望很坚定。”">a</a></sup>因为我们知道，你们承担了我们受的痛苦，但也必会获得我们的抚慰。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 4:7–12; 哥林多前书 15:32; 哥林多前书 4:8"> 兄弟姐妹们，我们要向你们讲述我们在亚西亚遭受的苦难。那苦难如此强烈，我们甚至担心没有足够的力量继续下去，甚至不知道能否活着结束这一切。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 3:5; 希伯来书 11:19; 哥林多后书 4:7"> 事实上，那就像我们内在已被判处了死刑。但也正因为如此，我们不再仅倚靠自己的力量，而是去相信可以让人死而复生的上帝。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 4:10; Psalms 34:19; 彼得后书 2:9"> 他将我们从可怕的死亡中拯救出来，他还会再次这样做。我们完全相信上帝会继续拯救我们。</span>
<span className="v" id="v11" data-v="11" data-xref="腓立比书 1:19; 哥林多后书 4:15; 使徒行传 12:5"> 请为我们祈祷，这也是对我们的支持。通过这种方式让众人为我们感谢上帝，上帝将会根据众人的祈祷，赐予我们恩典。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 2:17; 哥林多前书 2:13; 雅各书 3:13–18"> 我们始终以恰当的方式对待其他人，尤其是你们。我们的良心也证明了这一点，对此我们深感自豪。我们以圣洁和真诚遵循上帝的原则，不是依靠世俗的聪明，而是凭借上帝的恩典。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 4:2; 腓利门书 1:6; 哥林多后书 13:6"> 我们不会以复杂的语言撰写任何文字，因为我们希望你们能够读懂和理解。我希望你们最终能够理解，</span>
<span className="v" id="v14" data-v="14" data-xref="腓立比书 2:16; 哥林多前书 1:8; 帖撒罗尼迦前书 2:19–20"> 即使你们现在并未全部理解，当主降临的时候，你们也会以我们为荣，就像我们也会以你们为荣。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 4:19; 罗马书 1:11; 罗马书 15:29"> 我非常确信你们对我的信念，所以计划首先造访你们，让你们可以再次获得恩惠。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 16:5–7; 使徒行传 21:5; 使徒行传 19:21–22"> 随后我将去马其顿，再从马其顿返回你们那里，你们将送我去犹太。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 5:37; 雅各书 5:12; 哥林多后书 10:2–3"> 我为什么要改变最初的计划？你们是否认为我总是轻易做决定？是否认为我如凡俗之人一般，在计划一切时总是似是而非？</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 1:9; 启示录 3:7; 约翰福音 7:28"> 上帝是值得信赖的，我们向你们所传之道绝不是似是而非，</span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 13:8; 启示录 1:17; 约翰二书 1:9"> 因为我、西拉和提摩太向你们宣扬耶稣基督、上帝之子的真理，不可能似是而非。以基督为名，所有的一切都是绝对的“是。”</span>
<span className="v" id="v20" data-v="20" data-xref="约翰一书 2:24–25; 加拉太书 3:22; 启示录 7:12"> 对于上帝的所有承诺，基督的回答始终都为“是。”通过耶稣，我们也向上帝的荣耀说“是。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“阿门”，意为“是”或“我同意。”">b</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 2:27; 彼得前书 5:10; 约翰一书 2:20"> 上帝赐予你我所有人内在的力量，坚定地与基督同在。他已经指认了我们，</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 4:30; 哥林多后书 5:5; 以弗所书 1:13–14"> 在我们身上盖下批准的印章，这也是圣灵可以说服我们的保证。</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 1:20; 哥林多前书 4:21; 罗马书 1:9"> 我呼求上帝给我作证，我之所以没有到哥林多，就是为了避免为你们带来苦痛。</span>
<span className="v" id="v24" data-v="24" data-xref="彼得前书 5:3; 哥林多前书 15:1; 腓立比书 1:25–26"> 我们不希望命令你们与上帝的信仰，而是希望帮助你们获得欢喜的体验，因为你们对上帝的信仰让你们更坚定。</span>

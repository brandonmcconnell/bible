<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 2:25–29; Genesis 25:32; Ecclesiastes 6:11"> 那么犹太人有什么优势吗？割礼又有什么益处？</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 9:4; 使徒行传 7:38; 哥林多前书 9:17"> 是的，有很多益处！首先，这代表他们已接受了上帝之道的委托。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太后书 2:13; 希伯来书 4:2; 罗马书 9:6"> 即使有人不信上帝，又会怎样？难道他们不信，就可以证明上帝不可信吗？</span>
<span className="v" id="v4" data-v="4" data-xref="Psalms 51:4; Psalms 116:11; 加拉太书 2:17"> 当然不是！即使所有人都被证明是在说谎，上帝始终在讲述真相，正如经文所记：“你所说的将被证明为公义，在你接受审判<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《诗篇》51:4。">a</a></sup>时将会获胜。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或“你将被证明是正确的。”">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="罗马书 6:19; 加拉太书 3:15; 罗马书 9:18–20"> 但如果我们的过错可以彰显上帝的良善正直，我们又会得出怎样的结论呢？难道上帝对我们宣告审判是错的吗？（我是从人类的角度看待这个问题。）</span>
<span className="v" id="v6" data-v="6" data-xref="Genesis 18:25; 使徒行传 17:31; Job 8:3"> 当然不是！上帝又会用哪些其他的方法审判这个世界呢？</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 3:4; 罗马书 9:19–20; 使徒行传 13:27–29"> 有人可能会说：“如果因我的谎言证明了上帝的真相，难道不更加彰显他的荣耀吗？为什么我还要像罪人一样受审判？”</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 6:1; 罗马书 6:15; 罗马书 5:20"> 难道你是在说：“让我们的恶带来善？”当有人毁谤我们，有人会这么说。这种人就应该接受正义的审判！</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="加拉太书 3:22; 罗马书 6:15; Isaiah 65:5"> 那么我们犹太人真的比其他人更优秀吗？当然不是！请记住，我们已经讨论过，犹太人或是外族人都在罪恶的控制之下。</span>
<span className="v" id="v10" data-v="10" data-xref="Psalms 53:1–3; Psalms 14:1–3; 罗马书 3:23"> 正如经文所说：“没有正确行事之人，一个都没有。</span>
<span className="v" id="v11" data-v="11" data-xref="Psalms 14:2–4; Psalms 53:2; 提多书 3:3"> 没有人理解，没有人寻求上帝。</span>
<span className="v" id="v12" data-v="12" data-xref="Psalms 14:3; Ecclesiastes 7:20; Isaiah 64:6"> 人人都背离了上帝，人人都在彻头彻尾地犯错。没有行善之人，一个都没有。</span>
<span className="v" id="v13" data-v="13" data-xref="Psalms 5:9; Psalms 140:3; 马太福音 23:27–28"> 他们的喉咙如敞开的坟墓，他们的口中满是诡诈，他们嘴唇流出的都是蛇的毒液，</span>
<span className="v" id="v14" data-v="14" data-xref="Psalms 10:7; Psalms 109:17–18; Psalms 59:12"> 他们满口恶毒和诅咒，</span>
<span className="v" id="v15" data-v="15" data-xref="Isaiah 59:7–8; Proverbs 1:16; Proverbs 6:18"> 制造苦痛和死亡却速度飞快。</span>
<span className="v" id="v16" data-v="16"> 他们的路通往灾难和不幸。</span>
<span className="v" id="v17" data-v="17" data-xref="Isaiah 59:8; 罗马书 5:1; 路加福音 1:79"> 他们不知道如何和平生活。</span>
<span className="v" id="v18" data-v="18" data-xref="Psalms 36:1; Proverbs 23:17; Proverbs 16:6"> 他们完全不尊重上帝。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="来自第 12 至 18 句的文字参考了《雅歌》14:1-3，《雅歌》5:9，《雅歌》140:3，《雅歌》10:7，《以赛亚书》59:7-8，《箴言》1:16，《雅歌》36:1。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="加拉太书 3:10; 加拉太书 3:22–23; 罗马书 2:12–18"> 很显然，律法所述一切管辖律法之下生活的所有人，确保任何人都不会为自己寻求借口，确保全世界的所有人只回答上帝。</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太书 2:16; 使徒行传 13:39; 罗马书 3:28"> 因为没有人能通过践行律法的要求，在上帝面前成就良善正直。律法只是帮助我们意识到什么才是罪。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 10:43; Jeremiah 33:16; 腓立比书 3:9"> 但现在，上帝已经显明了他的良善正直的形象<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="见1:17。又见3:22。">d</a></sup>。尽管有律法和先知的话可以证明，但上帝的良善正直并非因为遵守律法。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 10:12; 加拉太书 3:28; 罗马书 8:1"> 上帝良善正直的形象，源自那些相信耶稣基督之人，来自那些对他有信心之人。</span>
<span className="v" id="v23" data-v="23" data-xref="Ecclesiastes 7:20; 约翰一书 1:8–10; 罗马书 3:9"> 我们都是罪人，我们远远达不到上帝荣耀的完美。</span>
<span className="v" id="v24" data-v="24" data-xref="彼得前书 1:18–19; 提多书 3:5–7; 歌罗西书 1:14"> 但上帝通过其馈赠的恩典，通过基督耶稣让我们获得自由，进而让我们达到良善正直。</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 3:23–24; 彼得前书 1:18–20; 约翰一书 4:10"> 上帝公开将耶稣作为馈赠，为信他之人、为他为之洒下鲜血之人带来和平<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="“耶稣作为带来和平的馈赠”：上帝宽恕、治愈和恢复和谐的方式。">e</a></sup>。上帝这样做，是为了证明他才是真正的良善正直，因为之前他对罪行报以容忍并宽恕，</span>
<span className="v" id="v26" data-v="26" data-xref="Deuteronomy 32:4; 罗马书 4:5; 罗马书 3:30"> 但现在，就在此时此刻，上帝证明了他的良善正直，做出良善正直之事，让信任耶稣之人成为良善正直之人。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="罗马书 4:2; 罗马书 2:23; 哥林多前书 1:29–31"> 那么我们还有什么可夸耀的？绝对没有，没有任何解释的余地。那么为什么呢？难道是因为我们遵循了律法的要求？不是，是因为我们遵循了相信上帝的律法。</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太书 2:16; 加拉太书 3:8; 提多书 3:7"> 我们可以确定的是，人通过相信上帝而变成良善正直之人，不是通过遵循律法。</span>
<span className="v" id="v29" data-v="29" data-xref="歌罗西书 3:11; 以弗所书 3:6; Zechariah 2:11"> 难道上帝只是犹太人的上帝？他不也是外族人的上帝吗？当然是！</span>
<span className="v" id="v30" data-v="30" data-xref="加拉太书 3:8; 加拉太书 3:20; 腓立比书 3:3"> 只有唯一的上帝，他通过我们对他的信而在道德上成为良善正直之人，无论你是谁，是犹太人或外族人。</span>
<span className="v" id="v31" data-v="31" data-xref="加拉太书 2:21; 马太福音 5:17; 罗马书 13:8–10"> 是否这就意味着，信上帝就可以摒弃律法？当然不是！事实上，我们信上帝确定了律法的重要性。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得前书 2:16; 加拉太书 5:13; 罗马书 6:15"> 那么我们应该做出怎样的反应？难道是通过继续犯罪获得更多的恩典？</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 3:9; 歌罗西书 3:3; 罗马书 7:4"> 当然不是<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“但愿不要这样！”这个有力的回答曾有多种翻译方式：当然不是！绝不！上帝禁止！又见6:15等句。">a</a></sup>！既然我们已经因罪而死，又怎能继续活在罪中？</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 3:27; 加拉太书 2:20–21; 罗马书 6:8"> 难道你们不知道吗？所有通过受洗而追随基督耶稣之人，都是受洗与他共同赴死？</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 5:17; 歌罗西书 3:10; 以弗所书 4:22–24"> 通过受洗，我们与他一同埋葬在死亡中，就像基督通过天父的荣耀死而复活，我们也可以获得新生命。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 3:10–11; 哥林多后书 4:10; 歌罗西书 2:12"> 如果我们像他一样死去，从而与他成为一体，我们也会像他一样死而复生。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="加拉太书 2:20; 以弗所书 4:22; 加拉太书 5:24"> 我们知道，死亡之前的“旧我”已经与耶稣一起钉上十字架，通过抛弃罪恶的死亡之躯，我们便不再被罪所奴役。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得前书 4:1; 歌罗西书 3:1–3; 罗马书 7:4"> 因为死去之人已经从罪中获得自由。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太后书 2:11–12; 歌罗西书 3:3–4; 哥林多后书 4:10–14"> 既然我们与基督共同赴死，我们就有信心必将与他同住，</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 6:14; 启示录 1:18; 使徒行传 2:24–28"> 因为我们知道，由于基督已经死而复生，即不会再受死亡掌控，因此获得永生。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 5:21; 彼得前书 4:6; 彼得前书 3:18"> 通过死亡，他带走了所有的罪，现在他复活，便为上帝而活！</span>
<span className="v" id="v11" data-v="11" data-xref="歌罗西书 3:3–5; 哥林多前书 6:20; 罗马书 6:2"> 同样，你应该认为自己已因罪而死亡，通过基督耶稣因上帝而复活。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 5:16; 罗马书 6:16; 罗马书 8:13"> 不要让罪掌控你凡人之躯，不要屈服于它的诱惑，</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 12:1; 罗马书 6:16; 歌罗西书 3:5"> 不要将身体的某一部分成为罪的邪恶工具。而是要像那些因死而复生回归的一样，将自己奉献给上帝，将身体的全部作为工具，为上帝行善。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 5:18; 罗马书 8:2; 罗马书 7:4–11"> 罪无法掌控你，因你并非身处律法之下，而是置身恩典之中。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="提多书 2:11–14; 以弗所书 2:8–10; 罗马书 6:1–2"> 那么，我们不在律法之下、而在恩典之中，是否就意味着我们应该做出有罪之事？当然不是！</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 8:34; 马太福音 6:24; Joshua 24:15"> 你难道没有意识到吗？如果你成为某人的奴隶，服从他们的命令，你就是向你发号施令之人的奴隶。如果你是罪的奴隶，结果就是死亡，如果你服从上帝，结果就是与他和解。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前书 2:9; 提摩太后书 1:13; 罗马书 1:8"> 感谢上帝，因为尽管你曾是罪的奴隶，但你全心全意选择遵循所学到的上帝真理。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 6:22; 罗马书 8:2; 加拉太书 5:1"> 当你解脱了罪恶，就会成为只按道德正确行事的奴隶。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="罗马书 6:13; 彼得前书 4:2–4; 歌罗西书 3:5–7"> 我使用这个日常例子，是因为人类的思维具有局限性。正如你们曾为不道德的努力，罪行累累。现在你们必须成为纯洁和正义的奴隶。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 6:16–17; 约翰福音 8:34"> 当你是罪的奴隶时，就不需要正确行事。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 1:32; 罗马书 7:5; 罗马书 6:23"> 但这样做的结果是什么？你难道不会为自己的所作所为感到羞耻吗？这样的行为会带你走向死亡！</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:16; 罗马书 6:18; 罗马书 8:2"> 但当你已从罪中解脱，就成为上帝的奴隶，这会让你获得纯洁的生命——最终得到永生。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 3:36; 罗马书 5:12; 雅各书 1:15"> 死亡是罪的代价，但通过我们的主基督耶稣，上帝向我们馈赠了永生。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 3:18–19; 哥林多后书 5:17; 加拉太书 3:13"> 现在那些与基督耶稣一体之人不会被定罪。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 6:14; 哥林多后书 3:17; 罗马书 6:18"> 生命之灵的律法，通过基督耶稣让我脱离罪恶和死亡。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 13:39; 加拉太书 4:4–5; 希伯来书 7:18–19"> 因我们的罪恶天性，律法也无能为力的，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“罪恶天性”，原意为“肉体”，即人性罪恶堕落的身体特征。这个词与人类的灵性相反，经常用于以下内容。">a</a></sup>但上帝却能做到！他派来自己的儿子，以人类之形解决了所有的罪恶问题，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或“为了罪而牺牲自己。”">b</a></sup>摧毁我们罪恶人性中罪的力量。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 5:16; 加拉太书 5:22–25; 歌罗西书 1:22"> 通过这种方式，我们可以追随圣灵而非罪恶人性，以此履行律法对善良的要求。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 2:14; 加拉太书 5:19–25; 约翰福音 3:6"> 那些追随罪恶人性之人，只专注于罪恶之事，那些追随圣灵之人，只专注于圣灵之事。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 6:8; 罗马书 8:7; 罗马书 8:13"> 罪恶的人心会走向死亡，但被圣灵引导之心会拥有生命与平安。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 2:14; 约翰一书 2:15–16; 雅各书 4:4"> 罪恶人心与上帝为敌，因为它拒绝遵守上帝的律法。事实上，它永远无法遵守。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 3:5–6; 希伯来书 11:5–6; 罗马书 8:9"> 追随其罪恶本性之人永远无法让上帝欢喜。</span>
<span className="v" id="v9" data-v="9" data-xref="加拉太书 4:6; 哥林多前书 3:16; 提摩太后书 1:14"> 不是追随你的罪恶天性，而是要追随圣灵——如果你心中有上帝之灵。但如果你心中没有基督之灵，你也就不是基督之人。</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 3:17; 加拉太书 2:20; 哥林多后书 5:21"> 但如果基督常驻你的心中，即使你的身体因罪恶而死去，这灵也会赐予你生命，因为上帝视你为正义。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 4:14; 罗马书 6:4–5; 哥林多后书 4:11"> 如果你心中有那让耶稣死而复生的灵，让耶稣死而复生的上帝就会通过这灵，为你的死亡之躯赋予生命。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 6:2–15; 哥林多前书 6:19–20; 彼得前书 4:2–3"> 所以兄弟姐妹们，我们不必去追随那按照人类欲望操控我们的罪恶天性<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或“没有义务。”">c</a></sup>。</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太书 6:8; 彼得前书 2:11; 哥林多前书 9:27"> 如果你的生命被你的罪恶天性所控制，你就会死亡。但如果你追随圣灵之路，将你所做罪行处死，你就会活着。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 5:18; 约翰福音 1:12; 加拉太书 3:26"> 所有被上帝之灵引导的人都是上帝之子。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 4:5–7; 提摩太后书 1:7; 哥林多前书 2:12"> 赋予你的灵不会再次奴役你，恐吓你。不会。你所得到的灵，将让你成为上帝家园中的孩子。现在我们可以大声高呼：“上帝就是我们的父亲！”</span>
<span className="v" id="v16" data-v="16" data-xref="约翰一书 4:13; 哥林多后书 1:22; 哥林多后书 5:5"> 圣灵也同意我们<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原意为“我们的灵。”">d</a></sup>就是上帝之子。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 4:7; 加拉太书 3:29; 以弗所书 3:6"> 如果我们是他的孩子，便是他的继承人。我们是上帝的子孙，与基督一样的子孙。但如果你想分享基督的荣耀，就必须也分享他的痛苦。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 4:17–18; 彼得前书 4:13; 彼得前书 1:5–7"> 但我深信，相比未来将显示给我们的荣耀，我们现在所受之苦根本不值一提。</span>
<span className="v" id="v19" data-v="19" data-xref="Malachi 3:17–18; 罗马书 8:23; 约翰一书 3:2"> 由上帝创造的世间万物都在耐心等待，渴望上帝向他的孩子昭示。</span>
<span className="v" id="v20" data-v="20" data-xref="Genesis 3:17–19; Genesis 5:29; 罗马书 8:22"> 上帝允许造物的初衷被违背。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 22:3–5; 使徒行传 3:21; 彼得后书 3:13"> 万物满怀希望地期待那一刻，从腐朽奴役中解脱，分享身为上帝儿女的荣耀。</span>
<span className="v" id="v22" data-v="22" data-xref="Jeremiah 12:4; Jeremiah 12:11; 约翰福音 16:21"> 我们深知，到目前为止，所有上帝的造物都在期待中痛苦呻吟，一如女人分娩遭受疼痛。</span>
<span className="v" id="v23" data-v="23" data-xref="腓立比书 3:20–21; 哥林多后书 5:2–5; 希伯来书 9:28"> 不只是上帝造物，我们又何尝不是如此。虽然提前获得圣灵的恩赐，但在等待上帝“收养”我们、救赎我们身躯之时，我们的内心也在痛苦呻吟。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 5:7; 希伯来书 11:1; 哥林多后书 4:18"> 我们因希望而获得拯救。但目前你们看到的根本不是希望。谁会希望拥有已经看到的东西？</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 12:12; 希伯来书 10:36; Psalms 27:14"> 我们自然会期盼尚未看到之事，所以我们耐心地等待它。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 10:20; 以弗所书 6:18; 加拉太书 4:6"> 同样，圣灵会在我们软弱之时帮助我们。我们不知道如何向上帝表达，但通过我们无法用言语表达的悲叹，圣灵代替我们向上帝表达。</span>
<span className="v" id="v27" data-v="27" data-xref="Jeremiah 17:10; 约翰一书 5:14–15; 以弗所书 2:18"> 那洞察所有人心的上帝深知圣灵的意图，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="或“圣灵的思想。”">e</a></sup>知晓圣灵代表信徒向上帝祈求。</span>
<span className="v" id="v28" data-v="28" data-xref="彼得前书 5:10; 雅各书 1:12; Genesis 50:20"> 我们知道，神在所有事情上都为爱他的人，那些被他召唤成为他计划一部分的人的利益而工作。</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所书 1:4–5; Jeremiah 1:5; 以弗所书 1:11"> 上帝早已选择了这些人，如对待他儿子一般厚待他们，所以他的儿子乃众多兄弟姐妹中的第一人。</span>
<span className="v" id="v30" data-v="30" data-xref="启示录 17:14; 罗马书 8:28; 以弗所书 1:11"> 上帝召唤他所选择的众人，对于他所召唤之人，上帝让其良善正义，上帝让其良善正义之人，自会获得荣耀。</span>
<span className="v" id="v31" data-v="31" data-xref="Psalms 118:6; Jeremiah 1:19; Psalms 56:11"> 那么我们对此应该怎么做？如果上帝垂青我们，又是谁反对我们？</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 3:16; 罗马书 8:28; Psalms 84:11"> 但上帝并未护住自己的儿子，而是为我们众人舍弃了他，难道他不会慷慨馈赠我们一切吗？</span>
<span className="v" id="v33" data-v="33" data-xref="启示录 12:10–11; Isaiah 50:8–9; Isaiah 54:17"> 上帝的特别子民不会因任何事而遭受控诉。是上帝让我们良善正义，</span>
<span className="v" id="v34" data-v="34" data-xref="希伯来书 7:25; 罗马书 8:27; 希伯来书 9:24"> 谁又能定我们的罪？受死之人乃基督耶稣，更重要的是，他死而复生，然后站在上帝的右边，替我们祈求。</span>
<span className="v" id="v35" data-v="35" data-xref="约翰福音 10:28; Psalms 103:17; 约翰福音 16:33"> 没有人能阻断我们获得基督之爱。压迫能吗？痛苦能吗？迫害能吗？饥饿、贫困、危险或暴力能吗？</span>
<span className="v" id="v36" data-v="36" data-xref="Psalms 44:22; Isaiah 53:7; 哥林多前书 15:30"> 正如经文所言，“因为你的缘故，我们始终面临被杀害的危险之中。他们对待我们的方式如待宰绵羊。”<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="引自《诗篇》44:22。">f</a></sup></span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前书 15:57; 约翰一书 4:4; 哥林多后书 2:14"> 不会的。对于发生在我们身上的一切，爱我们的耶稣让我们可以战胜一切。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 10:28; 罗马书 14:8; 提摩太后书 1:12"> 我完全相信，无论生死、无论天使或魔鬼、无论现在或未来、无论任何力量，</span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 10:28–30; 罗马书 8:35; 罗马书 5:8"> 无论高低，事实上，任何上帝造物都不能阻碍我们获得基督耶稣所获得的上帝之爱。</span>

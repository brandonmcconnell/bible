<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="feb" data-translation-id="cmn_feb" data-translation-label="易读圣经" data-book="ROM" data-book-slug="romans" data-book-name="罗马书" data-chapter="11" data-verses="36">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 11:22; 1 Samuel 12:22; 腓立比书 3:5"> 但我要问：“上帝是否拒绝了他的子民？”当然不是！我就是以色列人，来自便雅悯支派。</span>
<span className="v" id="v2" data-v="2" data-xref="Psalms 94:14; 罗马书 8:29–30; Exodus 32:1"> 上帝不会弃绝他所选择的子民。还记得经文中如何描述以利亚吗？他向上帝抱怨以色列，说：</span>
<span className="v" id="v3" data-v="3" data-xref="1 Kings 19:10–18; 1 Kings 18:13; Nehemiah 9:26"> “主啊，他们杀了你的先知，毁坏了你的祭坛。现在只剩我一人，他们也想杀了我！”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="1 Kings 19:18; Numbers 25:3; Zephaniah 1:4"> 上帝如何回答他？“我还留有七千人没有向巴力膜拜。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《列王记》19:10-18。">a</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 9:27; 以弗所书 1:5–6; 罗马书 9:11"> 如今也是同样的情况：仍然有虔诚之人留下来，那是上帝恩典所选之人。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 2:21; 罗马书 4:4–5; 提摩太后书 1:9"> 由于是通过恩典所选，很显然这选择并非基于人们的所作作为，否则恩典便不会称为恩典！</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="罗马书 9:18; 罗马书 11:5; 哥林多后书 4:4"> 那么我们可以得出什么结论呢？以色列人并未达成他们为之奋斗的目标，只有被选中之人达成，其他人则变成铁石心肠。</span>
<span className="v" id="v8" data-v="8" data-xref="Deuteronomy 29:4; Isaiah 29:10; Ezekiel 12:2"> 正如经文所说：“上帝让他们的思想麻木，所以直到今日，他们眼不能见，耳不能听。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="参见《申命记》29:4；《以赛亚书》6:9-10；《以赛亚书》29:10。">b</a></sup></span>
<span className="v" id="v9" data-v="9" data-xref="Psalms 69:22–23; 路加福音 12:20; Psalms 28:4"> 大卫补充道：“让他们的盛宴成为他们的陷阱，成为捕捉他们的网，那是带来惩罚的诱惑。</span>
<span className="v" id="v10" data-v="10" data-xref="Psalms 69:23; Deuteronomy 28:64–68; 彼得后书 2:4"> 让他们双眼失明无法看到，让他们始终因沮丧而弯腰驼背。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《诗篇》69:22-23。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 13:46–48; 罗马书 11:31; 罗马书 10:19"> 但我并不是在说，他们会因跌倒而彻底倒下。绝非如此！但因为他们的错，救赎降临到其他国家，“让他们嫉妒。”</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 11:25; 歌罗西书 1:27; 罗马书 11:15"> 如果他们倒下会让世界受益，那他们所失去的会让外族人受益，如果他们完全达成了自己注定的成就，将会带来更多益处。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="隐喻之意。">d</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 9:15; 提摩太后书 1:11–12; 以弗所书 3:8"> 现在我想和你们外族人说几句。我是向外族人传道的传教士，我宣讲自己所行之事，</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 7:16; 提摩太前书 4:16; 罗马书 9:3"> 这会让我的子民嫉妒，他们中的某些人也会因此获得救赎。</span>
<span className="v" id="v15" data-v="15" data-xref="以弗所书 1:10; 罗马书 5:10–11; 歌罗西书 1:20–21"> 如果上帝拒绝他们会让世人成为上帝的朋友，那么上帝就会接纳他们，就像让死人复活！</span>
<span className="v" id="v16" data-v="16" data-xref="Ezekiel 44:30; 雅各书 1:18; Proverbs 3:9"> 如果首先献祭的那部分面包圣洁，其他的面包也同样圣洁，如果树根圣洁，树枝也是如此。</span>
<span className="v" id="v17" data-v="17" data-xref="以弗所书 2:11–13; 以弗所书 3:6; 马太福音 21:43"> 如果有些枝条被折断，就会将你这根野橄榄枝接在树上，与其他树枝分享橄榄树根部的养分，</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 10:12; 罗马书 11:20; 以弗所书 2:19–20"> 所以你不能看低其他树枝。如果你忍不住想要吹嘘，请记住并非你在滋养树根，而是树根在滋养你。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 11:17; 罗马书 11:11–12; 罗马书 11:23–24"> 你可以说：“树枝折断了，所以可以将我嫁接在上面了。”</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 12:16; 哥林多后书 1:24; 哥林多前书 10:12"> 但他们折断是因为不信上帝，但你因为相信上帝，才能留在树上。所以不要自视甚高，而是要心存尊重，</span>
<span className="v" id="v21" data-v="21" data-xref="彼得后书 2:4–9; Jeremiah 25:29; Jeremiah 49:12"> 因为如果上帝无法饶恕树上原来生长的枝杈，也不会饶恕你。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 3:14; 希伯来书 3:6; 哥林多前书 15:2"> 你要知道上帝既良善又强硬。他对堕落之人非常严厉，但只要你相信他的良善，他就会良善对你，否则也会将你折断。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 3:16; Zechariah 12:10; 马太福音 23:39"> 如果他们不再抗拒相信上帝，就会重新被嫁接到树上，上帝有能力这样做。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 11:17–18; 罗马书 11:30"> 如果可以将你从一棵野橄榄树上砍下，然后嫁接到一棵人工栽培的橄榄树上，那么重新嫁接到他们原始生长的树，岂不是更容易？</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="路加福音 21:24; 哥林多后书 3:14–16; 罗马书 16:25"> 我的兄弟姐妹们，希望你们不要忽略这曾被隐藏的真理，否则你们就会变得自负。以色列人的心已经开始变得坚硬，直到接纳外族人的过程彻底完成。</span>
<span className="v" id="v26" data-v="26" data-xref="Isaiah 59:20; Jeremiah 31:31–37; Psalms 14:7"> 所有以色列人必须通过这种方式获得拯救。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="这段话并不是在宣讲普世救赎，而是拯救整个以色列（包括外族人和犹太人，他们通过上帝的恩典接受救赎）。">e</a></sup>正如经文所说：“救世主将来自锡安，他会改变雅各，让他不再与上帝对立。</span>
<span className="v" id="v27" data-v="27" data-xref="Jeremiah 31:31–34; Isaiah 59:21; Ezekiel 36:25–29"> 我承诺他们，我会带走他们的罪。”<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="《以赛亚书》59:20-21 和《以赛亚书》27:9 的内容相结合。">f</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="Deuteronomy 10:15; Deuteronomy 7:7–8; 马太福音 21:43"> 尽管他们是福音之敌，但这对你们有益。他们仍是天选子民，因其祖先而获得上帝的爱。</span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 7:21; Numbers 23:19; Malachi 3:6"> 上帝不会收回他的恩赐和召唤。</span>
<span className="v" id="v30" data-v="30" data-xref="歌罗西书 3:7; 以弗所书 2:1–2; 哥林多前书 7:25"> 你曾经不服从上帝，但现在上帝因他们的不服从，而对你予以怜悯。</span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 11:15; 罗马书 10:16; 罗马书 11:25"> 他们现在就像你曾经那样不服从，最终他们也会像你一样获得怜悯。</span>
<span className="v" id="v32" data-v="32" data-xref="加拉太书 3:22; 罗马书 3:9; 提摩太前书 2:4–6"> 对于所有不服从之人，上帝都会将其视为囚徒，以此怜悯所有人。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="Job 5:9; Job 11:7–9; Psalms 92:5"> 上帝的富饶、智慧和知识如此深奥！他的决定令人难以置信，他的方法让人难以想象！</span>
<span className="v" id="v34" data-v="34" data-xref="Isaiah 40:13; 哥林多前书 2:16; Job 15:8"> 谁能知晓上帝的想法？谁能给他建议？<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="引自《以赛亚书》40:13。">g</a></sup></span>
<span className="v" id="v35" data-v="35" data-xref="Job 41:11; Job 35:7; 哥林多前书 4:7"> 你给予上帝的，上帝难道必须偿还？<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="引自《约伯记》41:11。">h</a></sup></span>
<span className="v" id="v36" data-v="36" data-xref="歌罗西书 1:15–17; 哥林多前书 8:6; 希伯来书 2:10"> 世间一切都源于他，世间一切都因他而存在，世间一切都为他而存在。愿荣耀永远归给他，阿门！</span>
</div>
</div>

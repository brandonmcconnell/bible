<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Isaiah 51:2; 罗马书 4:16; 哥林多后书 11:22"> 让我们以亚伯拉罕为例。从人类的角度来看，他是我们国家的祖先。那么问题是：他经历了什么？</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 1:31; 哥林多后书 11:30; 腓立比书 3:9"> 如果亚伯拉罕因其行为而被称为正义，他可能会因此而夸口，但决不能在上帝面前。</span>
<span className="v" id="v3" data-v="3" data-xref="Genesis 15:6; 雅各书 2:23; 加拉太书 3:6–8"> 经文是怎么说的？“亚伯拉罕相信上帝，所以就被视为正确行事的善良之人。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《创世纪》15:6。">a</a></sup></span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 11:6; 罗马书 9:32; 罗马书 11:35"> 做工的人会获得酬劳，但不算是恩赐，而是他们应得的。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 3:9; 罗马书 3:22; 提多书 3:3–7"> 上帝让罪人转为正义，将他们视为正义之人，因为他们相信上帝，为上帝而工作。所以</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太后书 1:9; 腓立比书 3:9; 哥林多前书 1:30"> 大卫说过，上帝视为正义之人有福，并非是他们做工的一种交换！</span>
<span className="v" id="v7" data-v="7" data-xref="Psalms 32:1–2; Psalms 130:3–4; 路加福音 7:47–50"> “那些过错获得赦免、罪恶得到宽恕之人，如此有福，</span>
<span className="v" id="v8" data-v="8" data-xref="Psalms 32:2; 彼得前书 2:24; 哥林多后书 5:19–20"> 主没有将其视为有罪，如此有福。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引自《诗篇》32:1-2。">b</a></sup></span>
<span className="v" id="v9" data-v="9" data-xref="加拉太书 3:14; 歌罗西书 3:11; 加拉太书 3:26–28"> 那么这福气只属于犹太人吗？或者也属于其他人？我们刚刚说过，亚伯拉罕被视为善良正义，是因为他相信上帝。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 6:15; 加拉太书 5:6; Genesis 17:10"> 那么，这又在何时发生呢？在亚伯拉是犹太人的时候，还是更早？</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 3:22; 路加福音 19:9; 哥林多后书 1:22"> 其实是在他领受割礼之前，割礼确认了他对上帝的信任，这让他成为正义之人。这发生在他受割礼之前，所以他是所有相信上帝、被上帝视为正义之人的祖先，即使这些人没有受割礼成为犹太人也是如此。</span>
<span className="v" id="v12" data-v="12" data-xref="Song of Solomon 1:8; 约翰福音 8:39–40; Proverbs 2:20"> 他也是受割礼之人的父，不仅因为他们受割礼，还因为他们遵循我们祖先亚伯拉罕的例子，他在受割礼之前就信上帝。</span>
<span className="v" id="v13" data-v="13" data-xref="加拉太书 3:29; Genesis 22:17–18; Genesis 28:14"> 上帝承诺亚伯拉罕和他的后裔：这个世界将属于他。但这个承诺并非因他遵循律法，而是因为他相信上帝而变成良善正直之人。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 3:18–24; 腓立比书 3:9; 罗马书 4:16"> 如果这承诺的传承是根据律法而来，那么就无所谓相信上帝与否，承诺也就没有了意义。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 5:13; 加拉太书 3:10; 罗马书 3:19–20"> 因为律法会带来惩罚<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="违反律法的惩罚，当然包括所有人。">c</a></sup>。但如果没有律法，就谈不上违背律法。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 3:24–26; 以弗所书 2:8; 加拉太书 3:22"> 所以这承诺是基于对上帝的相信。上帝将其作为恩赐馈赠，是向所有亚伯拉罕的子孙做出的承诺，不只是那些遵循律法之人，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="保罗在这里并不是说遵守摩西律法的人就是与上帝对立，他已经讨论了这个问题。他只是在说，上帝并未把不遵守摩西律法的人排除在外。">d</a></sup>还包括相信众人之父亚伯拉罕的所有人。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 1:28; Genesis 17:4–5; 约翰福音 5:21"> 如经文所记：“我已立你为万国之父。”<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="引自《创世纪》17:5。">e</a></sup>在上帝面前，亚伯拉罕相信上帝，那让人起死回生、造物于世的上帝。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 8:24; Genesis 15:5–6; 使徒行传 27:25"> 在没有希望的时候，亚伯拉罕仍心怀希望地相信上帝，这让他成为众人之父，正如上帝所承诺：“所以你将有众多的后裔！”<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="即《出埃及记》15:5。">f</a></sup></span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 11:11–19; 罗马书 4:20–21; Genesis 17:17"> 他近一百岁时，感到自己的身躯已行将朽木，撒拉也无法生育，但他对上帝的信丝毫未曾减弱，</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 1:45; 哥林多前书 16:13; Daniel 10:19"> 他坚信上帝的承诺，从未有丝毫怀疑。相反，他更坚定地相信上帝，将荣耀给予上帝。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:37; Jeremiah 32:27; Genesis 18:14"> 他完全确信上帝承诺之事，上帝必能成就。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 4:6; 罗马书 4:3"> 这就是为什么上帝将亚伯拉罕视为正义之人。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 10:11; 罗马书 15:4; 哥林多前书 10:6"> “亚伯拉罕被视为正义之人”<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="引自《创世纪》15:6。">g</a></sup>这句话，不只是为他而写，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 2:24; 彼得前书 1:21; 使徒行传 13:30"> 也为我们而写，我们中会有人被上帝视为正义之人，因为我们相信上帝让主耶稣死而复活。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰一书 4:9–10; Isaiah 53:5–6; 哥林多后书 5:21"> 耶稣因我们的罪而受到背叛并送死，<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="见《以赛亚书》53:4-5。">h</a></sup>又通过复活让我们成为良善正直之人。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 5:14; 罗马书 14:1; 加拉太书 6:1–2"> 我们这样虔诚之人应该支持心灵软弱之人。而不只是取悦自己。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 14:19; 哥林多前书 10:24; 腓立比书 2:4–5"> 我们应该鼓励他人去做道德正确之事，帮助他们变得强大。</span>
<span className="v" id="v3" data-v="3" data-xref="Psalms 69:9; 腓立比书 2:8; 约翰福音 4:34"> 基督活着并非为了取悦自己，而是如经文所说，“虐待你之人应承受的侮辱，都由我承担。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《诗篇》69:9。">a</a></sup></span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 10:11; 提摩太后书 3:16–17; 罗马书 4:23–24"> 这段古老经文是为了帮助我们理解并鼓励我们，以便我们可以在希望中耐心等待。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 2:4–5; 彼得前书 3:8; 罗马书 12:16"> 在追随基督耶稣的过程中，愿那赐予我们忍耐和鼓励的上帝帮助你们团结一心，</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 10:29–30; 启示录 1:6; 以弗所书 1:3"> 让你们同心同声赞颂主耶稣基督之父上帝的荣耀！</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 10:40; 约翰福音 13:34; 罗马书 5:2"> 所以要像基督接纳你们一样彼此接纳，把荣耀归给上帝。</span>
<span className="v" id="v8" data-v="8" data-xref="加拉太书 4:4–5; 马太福音 15:24; 约翰福音 1:11"> 我坚信基督作为犹太人的仆人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“割礼。”">b</a></sup>来到世间，就是为了表明上帝所言均为真理，信守了他对他们祖先的承诺。</span>
<span className="v" id="v9" data-v="9" data-xref="2 Samuel 22:50; Psalms 18:49; 罗马书 3:29"> 他来此也是为了让外族人赞美神的慈悲，正经文所说：“所以我要在外族人中赞美你，歌颂你的名。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《诗篇》18:49。">c</a></sup></span>
<span className="v" id="v10" data-v="10" data-xref="Psalms 67:3–4; Deuteronomy 32:43; Isaiah 42:10–12"> 还有那句：“外族人啊，与他的子民共同庆祝！”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《申命记》32:43。">d</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="Psalms 117:1"> “所有的外族人啊，赞美主，愿万民赞美他。”<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="引自《诗篇》117:1。">e</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="Isaiah 11:10; Isaiah 11:1; 马太福音 12:21"> 以赛亚还说过：“耶西的后裔要统治世界，外族人要对他寄予厚望。”<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="引自《耶利米书》11:10。“杰西的后裔。”这是指大卫王的父亲杰西，他是王室家族的始祖。">f</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="帖撒罗尼迦后书 2:16–17; 罗马书 12:12; 哥林多后书 9:8"> 愿希望之神因你对他的信，将所有喜悦与平安充满你的心，让你因圣灵的力量而充满希望！</span>
<span className="v" id="v14" data-v="14" data-xref="歌罗西书 3:16; 彼得后书 1:12; 约翰一书 2:21"> 我的兄弟姐妹们，我深信你们满心善良，拥有渊博知识，所以能够彼此教导。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 12:3; 哥林多前书 15:10; 罗马书 1:5"> 这封信函中，我直言不讳地阐述了自己的某些观点，只是为了提醒你们。因为上帝赐予我恩典，</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 11:13; 罗马书 1:1; 使徒行传 9:15"> 承担基督耶稣向外族人传道的使命，就像神父分享上帝的福音，让他们成为上帝接纳的敬献，通过圣灵实现圣洁。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 2:14–16; 哥林多后书 12:11–21; 希伯来书 5:1"> 因此，侍奉上帝是一件引以为荣之事，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 15:12; 罗马书 1:5; 使徒行传 21:19"> （因为这是基督通过我所行之事，否则我断然不敢妄言），我已通过教导和展示，</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多后书 12:12; 希伯来书 2:4; 使徒行传 19:11–12"> 借着神迹和奇迹的力量以及圣灵的能力，引领外族人顺服上帝。从耶路撒冷一直到伊利里亚姆，我在所到之处传遍基督的福音。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 10:13–16; 哥林多前书 3:9–15; 以弗所书 2:20–22"> 事实上，我盼望和在未听说基督之名的地方传播福音，这样我才不会在其他人所为的基础上传道。</span>
<span className="v" id="v21" data-v="21" data-xref="Isaiah 52:15; Isaiah 65:1"> 正如圣经所说：“未曾听闻福音之人将会知晓，未曾了解之人将会明白。”<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="引自《以赛亚书》52:15。">g</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 1:13; 帖撒罗尼迦前书 2:17–18"> 这就是为什么我多次想要来探望你们，却始终受阻无法成行的原因。</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 15:32; 罗马书 1:10–12; 罗马书 15:29"> 但是现在，由于我已在这里传遍了福音，加之多年来一直期待拜访你们，</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 15:28; 罗马书 1:12; 使徒行传 15:3"> 所以希望在我去西班牙时能够与你们相见。当我们相见之时，也许你们可以为我的旅程提供一些帮助。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 24:17; 使徒行传 19:21; 使徒行传 20:22"> 此刻我正在去耶路撒冷的路上，那里的信徒需要帮助。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多后书 8:1–9; 使徒行传 11:27–30; 哥林多后书 9:2"> 因为马其顿和亚该亚的信徒认为，应该向耶路撒冷的贫困信徒送去捐赠。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 9:11; 加拉太书 6:6; 腓利门书 1:19"> 他们很愿意这么做，认为这是他们应尽的本分。<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="意思是外族人感谢犹太人分享上帝的福音。这种情况尤其适用于耶路撒冷的信徒，因此外族人很愿意赠礼帮助他们。">h</a></sup>因为外族人感受到了灵性的收获，所以也认为应该在物质上为犹太信徒<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="隐喻之意。">i</a></sup>提供帮助，表达感谢。</span>
<span className="v" id="v28" data-v="28" data-xref="罗马书 15:24; 腓立比书 4:17; 歌罗西书 1:6"> 当我完成这项工作，安全地将这笔捐款交给他们，就会在去西班牙的途中拜访你。</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所书 4:13; 罗马书 1:10–12; Psalms 16:11"> 我知道当我与你们见面时，基督一定会赐予我们满满的祝福。</span>
<span className="v" id="v30" data-v="30" data-xref="歌罗西书 4:12; 哥林多后书 1:11; 哥林多后书 4:11"> 我的兄弟姐妹们，我鼓励你们通过主耶稣基督和圣灵的爱，共同为我祈祷。</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒罗尼迦后书 3:2; 哥林多后书 8:4; 哥林多后书 9:1"> 祈祷我不会被犹太地不信上帝的众人所伤害，祈祷耶路撒冷的信徒会欢迎我的工作。</span>
<span className="v" id="v32" data-v="32" data-xref="哥林多前书 16:18; 腓利门书 1:20; 腓利门书 1:7"> 祈祷我如上帝所愿，将喜悦带到你们身边，让我们能够因彼此的陪伴而欢喜。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多后书 13:11; 腓立比书 4:9; 帖撒罗尼迦前书 5:23"> 愿赐平安的上帝与你们众人同在。阿门。</span>
</div>

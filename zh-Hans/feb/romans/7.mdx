<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 6:14; 罗马书 7:6; 罗马书 6:3"> 兄弟姐妹们，（在此我想向知晓律法之人说几句），<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="保罗用这个词来说律法，可以有多种含义，但通常是指整个犹太信仰体系。其中大部分与遵守规则有关。">a</a></sup>难道你们没有看到，律法只对活人有约束力吗？</span>
<span className="v" id="v2" data-v="2" data-xref="Genesis 2:23–24; 哥林多前书 7:39; 哥林多前书 7:4"> 例如，已婚妇女在丈夫活着时受法律约束，但如果他死了，她就免除了对他的法律义务。</span>
<span className="v" id="v3" data-v="3" data-xref="Exodus 20:14; 马太福音 5:32; 马可福音 10:6–12"> 因此，如果她在丈夫在世时与另一个男人住在一起，她就是犯下通奸之罪。但如果她的丈夫过世，她改嫁另一个男人，就不是通奸罪。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前书 2:24; 加拉太书 5:22–23; Isaiah 54:5"> 同样，我的朋友们，通过基督之躯，我们对律法而言已经死去。所以现在你属于另一个人——基督，他死而复生，这样我们才能为上帝而过上有意义的生活<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“为上帝结出果实。”">b</a></sup>。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 2:3; 加拉太书 5:16–17; 加拉太书 5:24"> 当我们被过往的旧天性所掌控，我们体内就充满了罪恶的欲望（如律法所揭示），导致死亡。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 3:23–25; 哥林多后书 3:6; 罗马书 7:4"> 但现在我们已经脱离了律法，对于束缚我们的枷锁而言，我们已经死去，所以我们可用全新的灵服侍上帝，而非在律法的旧文中行事。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 3:20; 罗马书 4:15; 哥林多前书 15:56"> 那么我们可以得出什么结论呢？律法是罪吗？当然不是！除非法律定义罪，否则我不会知道何为罪。如果律法没有说“不要渴望拥有属于别人的东西”，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《出埃及记》20:17或《申命记》5:21。">c</a></sup>我就无法意识到想拥有他人之物为错。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 7:11; 哥林多前书 15:56; 罗马书 4:15"> 但是通过这条诫命，罪恶设法挑起我心中各种自私欲——没有律法，罪也死亡。</span>
<span className="v" id="v9" data-v="9" data-xref="加拉太书 3:10; 罗马书 8:7; 雅各书 2:10–11"> 我过去并未意识到律法到底意味着什么，但当我明白这条诫命的含义，罪复活，我死去。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 3:7; 罗马书 10:5; Leviticus 18:5"> 我发现，那条意为带来生命的诫命，反而带来了死亡，</span>
<span className="v" id="v11" data-v="11" data-xref="Genesis 3:13; 罗马书 7:8; 希伯来书 3:13"> 因为罪通过诫命找到了欺骗我的方法，用诫命杀死了我！</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太前书 1:8; Psalms 119:137; Psalms 19:7–12"> 但律法本身是神圣的，诫命是神圣、正义和善良的。</span>
<span className="v" id="v13" data-v="13" data-xref="雅各书 1:13–15; 加拉太书 3:21; 罗马书 8:3"> 善良之事会杀了我吗？当然不是！但是我因良善而死去，这种行为让罪显示出来。因此，通过诫命的含义，它揭示了罪到底有多邪恶。</span>
<span className="v" id="v14" data-v="14" data-xref="1 Kings 21:25; 2 Kings 17:17; 罗马书 7:18"> 我们意识到律法是有灵性的，但我太像人了，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原意为“身体。”">d</a></sup>是罪的奴隶。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 5:17; 罗马书 7:19–20; Ecclesiastes 7:20"> 我不明白自己在做什么，做着自己不想做和厌恶的事情，这就是我所做的！</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 7:12; 罗马书 7:14; 提摩太前书 1:8"> 但如果我说自己违心做事，就表明我承认法律为善良正义。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 7:20; 腓立比书 3:8–9; 罗马书 7:18"> 所以做事的并不是我，而是我内在的罪。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 3:6; Psalms 51:5; 加拉太书 5:17"> 因为我知自己的罪恶人性，所以我本不善良。即使我想做善事，也做不到。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 7:15"> 我想做善事，却无法做到，我不想做邪恶之事，最终却这么做了！</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 7:17"> 但如果我所做并非出于本意，那这行为便源于我身体中的罪。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 6:14; 罗马书 7:23; Psalms 119:133"> 这就是我发现的原则：如果我想做善事，邪恶也伴左右。</span>
<span className="v" id="v22" data-v="22" data-xref="Psalms 1:2; Psalms 40:8; Psalms 119:35"> 我内心尊崇上帝的律法，</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 5:17; 雅各书 4:1; 罗马书 8:2"> 但我发现另一种律法在我心中作祟，它与我思想所遵循的律法相违背，我内在的罪恶律法将我困成它的囚徒。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 6:6; 提摩太后书 4:18; 提多书 2:14"> 我如此痛苦！这身体带我走向死亡，谁能拯救我？<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原意为“死亡之身。”">e</a></sup>感谢上帝，他通过我们的主耶稣基督达成我的愿望！</span>
<span className="v" id="v25" data-v="25" data-xref="加拉太书 5:17–24; 歌罗西书 3:17; 哥林多后书 12:9–10"> 现在的情况是：虽然我自己选择服从上帝的律法，但我的人性却服从了罪恶的律法。</span>
</div>

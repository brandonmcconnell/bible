<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 6:37; 罗马书 2:3; 约翰福音 8:7–9"> 无论你是谁，如果你评判他人，你就无法给自己找到借口。无论你以何种方式谴责他人，其实就是在评判自己，因为你也不过如此。</span>
<span className="v" id="v2" data-v="2" data-xref="Psalms 9:7–8; Zephaniah 3:5; Psalms 145:17"> 我们知道，上帝根据真理审判做出此类行径之人。</span>
<span className="v" id="v3" data-v="3" data-xref="Proverbs 16:5; 路加福音 12:14; 罗马书 1:32–1"> 当你评判他人，你真的以为自己可以躲过上帝的审判吗？</span>
<span className="v" id="v4" data-v="4" data-xref="彼得后书 3:9; Isaiah 30:18; Exodus 34:6"> 还是说，你们藐视上帝伟大的仁慈、宽容和忍耐，不知道上帝的仁慈是为了带领你悔改？</span>
<span className="v" id="v5" data-v="5" data-xref="Ecclesiastes 12:14; 罗马书 1:18; 罗马书 2:2–3"> 因为你们的铁石心肠和不肯悔改，当上帝的审判彰显绝对良善正直的那一天，你们会让自己陷入更大的痛苦之中。</span>
<span className="v" id="v6" data-v="6" data-xref="Psalms 62:12; Jeremiah 32:19; 马太福音 16:27"> 上帝会根据每个人的所作所为，给予其应有的对待：<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《诗篇》62:12。">a</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="提摩太后书 4:7–8; 路加福音 8:15; 提摩太后书 1:10"> 始终努力追求行善正义之人，将获得荣耀和尊贵，永生和不朽。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 3:18–21; 帖撒罗尼迦后书 1:8; 提摩太前书 6:3–4"> 但自私自利、拒绝真理、主动选择邪恶的人，将承受上帝之反对的惩罚。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 4:17; Ezekiel 18:4; 罗马书 1:16"> 作恶之人将陷入痛苦和折磨，先是犹太人，然后是外族人。</span>
<span className="v" id="v10" data-v="10" data-xref="Isaiah 32:17; Isaiah 26:12; Numbers 6:26"> 但行善之人则会被赐予荣耀、尊贵与平安，先是犹太人，后是外族人。</span>
<span className="v" id="v11" data-v="11" data-xref="Deuteronomy 10:17; 使徒行传 10:34; 2 Chronicles 19:7"> 因为上帝从不偏袒。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 9:21; 加拉太书 3:10; 加拉太书 2:16–19"> 犯下罪行之人，即使其罪行没有被写入摩西之律法<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="即摩西写下的律法。没有制定书面律法的人被称为“外族人”，已经制定书面律法的人即犹太人。">b</a></sup>，仍会迷失。如犯下律法所载之罪，将按律法接受审判。</span>
<span className="v" id="v13" data-v="13" data-xref="雅各书 1:22–25; 约翰一书 3:7; 雅各书 2:21–25"> 在上帝面前，只是聆听律法不代表你就是良善正直。只有在行为中践行律法，才是真正的正义。</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 2:12; 罗马书 1:19–20; 罗马书 2:27"> 外族人没有成文的律法，但他们按照本能行事，即使没有书面文字，也能够遵守律法。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多后书 5:11; 哥林多后书 1:12; 罗马书 1:18–19"> 他们以这种方式表明，律法早已刻在他们心中。他们会思考自己的所作所为，如果做错，他们会受到良知的审判，或以良知保护他们做出良善正义的行为。</span>
<span className="v" id="v16" data-v="16" data-xref="Ecclesiastes 12:14; 哥林多前书 4:5; 使徒行传 17:31"> 我将要宣讲的福音就是：上帝通过基督审判每个人的隐秘思想，这一天正在到来。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 2:23; Micah 3:11; Isaiah 48:1–2"> 你们自称犹太人又如何呢？你们依赖书面律法，夸口与上帝有着特别的关系。</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 5:21; Deuteronomy 4:8; 雅各书 4:17"> 你们知晓他想要什么，通过律法的教诲做正确的事。</span>
<span className="v" id="v19" data-v="19" data-xref="启示录 3:17–18; 马太福音 15:14; Isaiah 49:6"> 你们如此确信可以成为盲人的向导，成为黑暗中的光。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太后书 3:5; 提多书 1:16; 提摩太后书 1:13"> 你们认为从律法中获得了所有真理，就可以开悟愚昧，成为“幼儿”的教师。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 9:27; 马太福音 23:3–28; 路加福音 12:47"> 既然你们忙于教导别人，为什么不教导自己？你告诉人们不可偷窃，为什么自己却偷窃？</span>
<span className="v" id="v22" data-v="22" data-xref="Malachi 3:8; 马太福音 12:39; 马可福音 11:17"> 你们告诉人们不可奸淫，为什么自己却奸淫？你们告诉人们不要膜拜神像，为什么自己却亵渎圣殿？<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或“抢夺庙宇。”">c</a></sup></span>
<span className="v" id="v23" data-v="23" data-xref="雅各书 4:16–17; 罗马书 2:17; 罗马书 3:2"> 你们自诩拥有律法，为什么自己却因违背律法，扭曲上帝旨意？</span>
<span className="v" id="v24" data-v="24" data-xref="Ezekiel 36:20–23; Isaiah 52:5; 彼得后书 2:2"> 正如经文所说：“上帝的形象因你们<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《以赛亚书》52:5。原意为“上帝之名”，所指主要是其性格。">d</a></sup>而被外族人所诬蔑。”</span>
<span className="v" id="v25" data-v="25" data-xref="Jeremiah 4:4; 加拉太书 5:3–6; 使徒行传 7:51"> 你们只有遵行律法，割礼<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="在旧约圣经中，上帝让以色列人进行割礼，表明他们是上帝的天选子民。">e</a></sup>才会有益处。但如果你们违背律法，割礼就毫无意义，与没有割礼又有何区别。</span>
<span className="v" id="v26" data-v="26" data-xref="歌罗西书 2:11; 哥林多前书 7:18–19; 罗马书 8:4"> 未受割礼之人<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="没有割礼，意味着不是犹太人或是“外族人。”">f</a></sup>如果谨遵律法，仍然可以被视为已经接受了割礼。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 12:41–42; 罗马书 2:29; 哥林多后书 3:6"> 即使你们有成文律法并进行了割礼，如果违背律法规定，也可以由未接受割礼却遵守律法的人进行审判。</span>
<span className="v" id="v28" data-v="28" data-xref="加拉太书 6:15; 马太福音 3:9; 罗马书 9:6–8"> 让你成为犹太人并非由外在条件决定，也不是割礼在身体上的标记所证明。</span>
<span className="v" id="v29" data-v="29" data-xref="Deuteronomy 30:6; 腓立比书 3:3; Deuteronomy 10:16"> 只有内在实行了“心之割礼”，追寻圣灵而非律法的文字，才是真正的犹太人。这样的人寻求的是来自上帝而非人类的赞美，。</span>
</div>

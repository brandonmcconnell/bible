<span className="v" id="v2" data-v="2" data-xref="腓立比书 2:29; 腓立比书 1:27; 马太福音 10:40–42"> 请以主之名，用合乎信徒身份的方式接待她。无论她需要什么，请帮助她，因为她曾帮助过许多人，也曾帮助我。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 16:19; 提摩太后书 4:19; 使徒行传 18:26"> 请转达我对百基拉<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="曾出现在《门徒行传》18:2 中，名字拼写略有差异。又见《哥林多前书》16:19。">a</a></sup>和亚居拉的问候，他们曾与我一起为耶稣基督工作，</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比书 2:30; 约翰一书 3:16; 哥林多前书 16:1"> 曾为我冒着生命风险。不只是我很感谢他们，所有外族人的教会也都感激他们。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="即非犹太人的教堂。">b</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="歌罗西书 4:15; 腓利门书 1:2; 哥林多前书 16:19"> 我想要问候在他们家中的教会。问候亲爱的朋友以拜尼妥，他是亚西亚省第一位追随基督之人。</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 16:12; 马太福音 27:55; 提摩太前书 5:10"> 问候马利亚，她一直在为你们辛勤付出。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 16:11; 罗马书 16:21; 腓利门书 1:23"> 问候我的同乡安多尼古和犹尼亚，他们曾与我一起囚禁于监牢。他们在门徒中时很有威望，早在我之前就已追随基督。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比书 4:1; 约翰一书 3:14; 罗马书 16:5"> 问候我亲爱的朋友暗伯利，他与主同在。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 16:2–3; 罗马书 16:21"> 问候与我共同侍奉基督的珥巴努以及亲爱的朋友士达古。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 14:18; 彼得前书 1:7; Deuteronomy 8:2"> 问候追随基督、值得信赖的亚比利。问候亚里斯多博的家人。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 16:21; 罗马书 16:7"> 问候我的同乡希罗天，以及拿其舒家中属于主的所有人。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦前书 5:12–13; 希伯来书 6:10–11; 哥林多前书 15:58"> 问候为主辛劳工作的土非拿和土富撒，以及亲爱的彼息，她为主奉献了太多。</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 15:21; 提摩太前书 5:2; 约翰二书 1:1"> 问候主的优秀仆人鲁孚<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或“上帝的特殊子民之一。”">c</a></sup>和他的母亲，我也将她视为我的母亲。</span>
<span className="v" id="v14" data-v="14" data-xref="歌罗西书 1:2; 罗马书 8:29; 希伯来书 3:1"> 问候亚逊其都、弗勒干、赫米、百罗巴、赫马和与他们同在的兄弟们。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 16:2; 罗马书 1:7; 罗马书 16:14"> 问候非罗罗哥和犹利亚、尼利亚与他的姐妹阿林巴以及同他们在一起的众信徒。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦前书 5:26; 哥林多前书 16:20; 哥林多后书 13:12"> 热切地问候彼此，基督的众教会向你们致以问候。</span>
<span className="v" id="v17" data-v="17" data-xref="犹大书 1:19; 帖撒罗尼迦后书 3:6; 提摩太前书 6:3–5"> 我亲爱的信徒朋友们，对于你们所学的教义，如果有人在你们中间制造纷争和困扰，奉劝你们要小心他们，一定要远离！</span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 2:4; 马太福音 7:15; 提摩太前书 6:5"> 这种人并不服侍我们的主基督，只服侍自己的欲望，只会用花言巧语欺蒙骗毫无戒心的人。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 10:16; 哥林多前书 14:20; 腓立比书 2:15"> 人人都知道你们有多么忠诚，这让我满心欢喜。但我希望你们能知晓善良和纯洁，也能慧眼识别罪恶。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:19; 约翰一书 3:8; Genesis 3:15"> 和平的上帝很快就会战胜撒旦，让他臣服于你们。愿主耶稣的恩典与你们同在。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 20:4; 使徒行传 17:5; 使徒行传 13:1"> 我的同工提摩太和我的亲族路求、耶逊和所西巴德都问候你们。</span>
<span className="v" id="v22" data-v="22" data-xref="加拉太书 6:11; 哥林多前书 16:21; 罗马书 16:8"> （我——代笔写这封信的德图——也与主问候你们。）</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 1:14; 使徒行传 19:22; 提摩太后书 4:20"> 那接待我也接待全教会的该犹，问候你们。本城的司库以拉都和夸图的信徒问候你们。</span>
<span className="v" id="v24" data-v="24"> <sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="早期手抄本中没有第 24 句。">d</a></sup></span>
<span className="v" id="v25" data-v="25" data-xref="哥林多前书 2:7; 罗马书 2:16; 歌罗西书 1:26–27"> 让我们向上帝致敬 通过我所传福音和耶稣基督之道，上帝让你们更强大。 如今这奥秘<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="“奥秘”，即秘密的真相或只有信徒知道的秘密计划。又见第 26 句。">e</a></sup>已经显现， 这真理的奥秘曾不被世人所知，</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 1:5; 加拉太书 3:8; 罗马书 15:18"> 但现在通过众先知之笔昭然于世， 遵循永恒上帝的谕旨， 展示在全世界所有人的面前， 让他们相信并顺服于上帝。</span>
<span className="v" id="v27" data-v="27" data-xref="提摩太前书 1:17; 罗马书 11:36; 启示录 7:10–12"> 让我们借由耶稣基督， 向唯一睿智的上帝致敬， 祝他荣耀永存。阿门。<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="最后这段经文似乎是一首诗或一首歌，因此以诗歌的方式写成。">f</a></sup></span>

<span className="v" id="v1" data-v="1" data-xref="彼得前书 2:5; 罗马书 6:13; 希伯来书 13:15–16"> 我的兄弟姐妹们，因为上帝同情<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或“怜悯。”">a</a></sup>你们，所以我鼓励你们把自己的肉体之躯献给上帝，作为圣洁和喜悦的活祭。这是顺理成章的敬拜方式。</span>
<span className="v" id="v2" data-v="2" data-xref="彼得前书 1:14; 以弗所书 4:22–24; 哥林多后书 5:17"> 不要在这世上随波逐流，要通过思想的灵性新生而蜕变，这样就可以彰显上帝真正的旨意：善良、欢喜和完美。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 6:3; 腓立比书 2:3–8; Proverbs 26:12"> 通过上帝赐予我的恩典，我要向你们所有人解释一点：每个人都有自己应该成为的样子，你不应自视甚高。你应该根据上帝给你的信的程度，理智地看待自己。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 12:27; 哥林多前书 12:12–14; 以弗所书 4:15–16"> 正如人体有很多组成部分，但每个部分的作用不尽相同，</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 12:20; 哥林多前书 10:17; 哥林多前书 12:27–28"> 尽管我们人数众多，但我们的身体与基督相同，我们属于彼此。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前书 4:10–11; 哥林多前书 7:7; 哥林多前书 12:28–31"> 每个人都拥有不同的恩赐，因上帝赋予我们的恩典而异。如果这是在说上帝，就要根据你信的程度行事。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 4:11; 提摩太后书 4:2; 使徒行传 13:1"> 如果应该服侍上帝，就去服侍；如果你应该进行教导，就去教导；</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 9:7; 提摩太前书 5:17; 哥林多前书 12:28"> 如果应该鼓励他人，就去鼓励；如果应该给予，就慷慨给予；如果应该引领，就应承诺予以引领；如果应该慈悲，那应该高兴地这样做。</span>
<span className="v" id="v9" data-v="9" data-xref="Psalms 34:14; 彼得前书 4:8; 提摩太前书 1:5"> 爱必须真诚。憎恨一切邪恶，紧紧抓住善良。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比书 2:3; 约翰福音 13:34–35; 希伯来书 13:1"> 像爱你的家人一样对彼此奉献，重视他人胜过自己。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 6:10–11; 使徒行传 18:25; 启示录 3:15–16"> 不要因付出辛劳而不情愿，要以满腔热忱侍奉主。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 15:13; 希伯来书 10:36; Psalms 62:8"> 因你的希望而保持欢乐，接受那即将到来的困难，继续祈祷。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 13:16; 哥林多后书 9:12; 约翰一书 3:17"> 通过给予满足上帝子民的需求，热情款待陌生人。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 3:9; 马太福音 5:44; 帖撒罗尼迦前书 5:15"> 祝福迫害你的人——祝福他们，而不是诅咒。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 12:26; 希伯来书 13:3; Psalms 35:13–14"> 与快乐之人一起快乐，与哭泣之人一起哭泣。</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前书 3:8; Proverbs 3:7; 雅各书 3:13–17"> 为彼此着想。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或“彼此和谐相处。”">b</a></sup>不要认为自己比别人更重要，要谦逊，不要自负。</span>
<span className="v" id="v17" data-v="17" data-xref="Proverbs 20:22; 帖撒罗尼迦前书 5:15; 马太福音 5:39"> 不要以恶报恶。向所有人展示你正在行善，</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 12:14; 马太福音 5:9; 罗马书 14:19"> 在你力所能及的范围内，与所有人和平相处。</span>
<span className="v" id="v19" data-v="19" data-xref="Deuteronomy 32:35; 希伯来书 10:30; Proverbs 24:29"> 亲爱的朋友们，不要想着报复，上帝自会审判<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“为愤怒留出空间。”">c</a></sup>。正如经文所说，“主说：‘我必伸张正义，我必报应。’”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《申命记》32:35。">d</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="Proverbs 25:21–22; 马太福音 5:44; 路加福音 6:27"> 如果你的仇敌饿了，给他们食物，如果他们渴了，给他们水，这样做就如同把火炭堆在他们头顶。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="即让他们产生极大的尴尬和耻辱感。源自《箴言》25:21-22。">e</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="彼得前书 3:9; 路加福音 6:27–30; Proverbs 16:32"> 不可被恶战胜，要以善胜恶。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="使徒行传 9:15; 罗马书 15:16; 哥林多前书 1:1"> 此函来自基督耶稣的仆人保罗。我蒙受上帝的感召成为其使徒，上帝指派我传播福音，</span>
<span className="v" id="v2" data-v="2" data-xref="提多书 1:2; 路加福音 1:70; 罗马书 3:21"> 上帝的众先知此前也曾在圣经中他的预言承诺这福音。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 1:1; 加拉太书 4:4; Jeremiah 23:5–6"> 这福音讲述的是上帝之子，其人类祖先为大卫。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 9:14; 希伯来书 5:5–6; 以弗所书 1:19–23"> 但他通过圣灵的力量死而复生，彰显他就是上帝之子。他就是耶稣基督，我们的主。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 9:15; 罗马书 16:26; 使徒行传 6:7"> 我通过他获得了成为使徒的特权，呼吁万国顺服并相信他，</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前书 2:9; 启示录 17:14; 彼得后书 1:10"> 在受到召唤跟随耶稣基督的人中，也有你们。</span>
<span className="v" id="v7" data-v="7" data-xref="歌罗西书 1:2; 犹大书 1:1–2; 以弗所书 1:2"> 这封信写给所有住在罗马、为上帝所爱并受到召唤成为其特殊之人，愿你们获得来自天父上帝和主耶稣基督的恩典和平安。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 16:19; 哥林多前书 1:4; 帖撒罗尼迦前书 1:8–9"> 首先要说的是，我要透过耶稣基督为你们所有人感谢上帝，因为全世界都在讲述你们对上帝的信。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 6:18; 提摩太后书 1:3; 以弗所书 1:16–19"> 我始终在为你们祈祷，上帝可鉴。我全心全意侍奉上帝，传播关于上帝之子的福音。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 15:30–32; 使徒行传 18:21; 腓利门书 1:22"> 我在祷告中总是在恳求，上帝能够让我最终与你们相见。</span>
<span className="v" id="v11" data-v="11" data-xref="彼得后书 1:12; 罗马书 16:25; 罗马书 15:29"> 我真心想要造访你们，与你们分享圣灵的祝福，为你们赋予力量。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦前书 3:7–10; 约翰三书 1:3–4; 哥林多后书 7:13"> 通过这种方式，我们可以鼓励彼此对上帝的信，包括你们的信和我的信。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 19:21; 腓立比书 4:17; 提摩太后书 4:17"> 我的兄弟姐妹们，我一直在计划去拜访你们，但总是受到阻拦无法成行，现在终于如愿以偿。我想去见证圣灵在你们当中结出的善果，就像在其他国家中一样。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“外族人。”">a</a></sup></span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 9:16–23; 使徒行传 9:15; 歌罗西书 3:11"> 无论是开化或未开化之人，无论是受教养或无教养之人，我都有服务你们的义务。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 15:20; Isaiah 6:8; 哥林多前书 9:17"> 所以，我非常想要去罗马，与你们分享福音。</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 8:38; 提摩太后书 1:8; 彼得前书 4:16"> 我当然不会以福音为耻，这福音彰显了上帝拯救信他之人的力量——先是犹太人，然后是其他所有人。</span>
<span className="v" id="v17" data-v="17" data-xref="Habakkuk 2:4; 加拉太书 3:11; 希伯来书 10:38"> 上帝通过这福音显示他的善良和正义，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“上帝的正义。”">b</a></sup>从始至终都值得信赖。正如经文所记：“那些与上帝保持一致之人因信上帝而活。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原文中的字面意思为：“信者必将活下去。”引自《哈巴谷书》2:4。">c</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 5:6; 提摩太前书 4:1–2; 罗马书 1:32"> 如果你不信上帝、道德不义、<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“正义”：保罗在整个罗马世界中宣讲的是道德上的正义，而非简单的正确与否。">d</a></sup>被魔鬼所控压制真理，上帝对这一行为的反对<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原意为“愤怒。”人类的问题就是将其负面情绪归咎于上帝。">e</a></sup>必会从天堂显现。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 14:16–17; Psalms 19:1–6; 罗马书 1:20"> 关于上帝，我们可知的已经显而易见，因为他已经向众人显明。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 1:19; Isaiah 40:26; Psalms 19:1–6"> 自从创世以来，上帝隐形的一面，比如他的永恒能力和神性，都已通过他的造物显现。这样的人无法找到任何借口，</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所书 4:17–18; 2 Kings 17:15; Jeremiah 2:5"> 他们知道上帝，却不赞美或感谢上帝。相反，他们对上帝的看法显示出彻头彻尾的愚蠢，黑暗填满了他们的空虚之心。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 1:19–21; 罗马书 11:25; Proverbs 26:12"> 他们自诩聪明，却已变得蠢笨。</span>
<span className="v" id="v23" data-v="23" data-xref="Psalms 106:20; Jeremiah 2:11; 使徒行传 17:29"> 他们以凡俗之人、飞鸟走兽和昆虫做神像，取代上帝的永恒荣耀。</span>
<span className="v" id="v24" data-v="24" data-xref="Psalms 81:11–12; 使徒行传 7:42; 使徒行传 14:16"> 所以上帝已放弃他们，任由其堕落思想沉迷于邪恶的欲望，用可耻而低级的行径对待彼此。</span>
<span className="v" id="v25" data-v="25" data-xref="Habakkuk 2:18; Jeremiah 13:25; 约翰一书 2:15–16"> 他们用谎言取代上帝的真理，膜拜和侍奉造物而非应该永远称颂的造物之主。阿门。</span>
<span className="v" id="v26" data-v="26" data-xref="犹大书 1:7; 提摩太前书 1:10; 罗马书 1:24"> 因此，上帝抛弃了他们去追求邪恶的欲望。有的女人用正常之性进行堕落的交易。</span>
<span className="v" id="v27" data-v="27" data-xref="Leviticus 20:13; Leviticus 18:22; 罗马书 1:23–24"> 同样，男人也放弃了与女人之间的性爱，转而对彼此燃起欲火，男人与男人做出可耻行径。他们堕落的后果必会令其遭受苦痛折磨。</span>
<span className="v" id="v28" data-v="28" data-xref="帖撒罗尼迦后书 2:10–12; 罗马书 1:21; 提多书 1:16"> 既然他们认为不值得去认识上帝，上帝就放弃他们，任凭他们以无法被信任、毫无价值的方式思考，做出本不应该允许的行径。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多后书 12:20; Proverbs 16:28; Psalms 41:7"> 他们的内心已经彻底走入歧途，满是邪恶、贪婪、仇恨、嫉妒、谋杀、争吵、欺诈、怨恨和谗言。</span>
<span className="v" id="v30" data-v="30" data-xref="提摩太后书 3:2; 犹大书 1:16; 彼得后书 2:18"> 他们毁谤他人，憎恨上帝。他们自大傲慢，自吹自擂。他们会犯下新的罪恶。他们会忤逆父母。</span>
<span className="v" id="v31" data-v="31" data-xref="提摩太后书 3:3; Proverbs 18:2; 罗马书 3:11"> 他们不愿意去理解真相，从不守信用，他们冷酷无情，没有恻隐之心。</span>
<span className="v" id="v32" data-v="32" data-xref="罗马书 2:1–5; 罗马书 1:21; 罗马书 6:21"> 尽管他们对上帝的要求心知肚明，但行为却让他们走向死路。他们不仅自己这么做，也会唆使其他人这么做。</span>
</div>

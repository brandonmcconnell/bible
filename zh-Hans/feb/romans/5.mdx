<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Isaiah 32:17; 罗马书 15:13; 约翰福音 16:33"> 我们既然信任上帝而成为良善正直之人，就通过我们的主耶稣基督与上帝和平相处。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 2:18; 以弗所书 3:12; 罗马书 12:12"> 通过耶稣、通过对他的信任，我们才能在所站之处获得恩典，期盼分享上帝荣耀所带来的福报和信心。</span>
<span className="v" id="v3" data-v="3" data-xref="雅各书 1:2–3; 雅各书 1:12; 彼得前书 3:14"> 不仅如此，我们还在困难来袭时保持自信，因为我们知道患难会带来精神上的上的持久力量<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或“忍耐。”">a</a></sup>，</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前书 5:10; 雅各书 1:12; 哥林多后书 4:8–12"> 精神上的上的持久力量会让我们拥有成熟的性格，成熟的性格会带来自信的希望。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 4:6; 以弗所书 3:16–19; 腓立比书 1:20"> 这希望让我们永远不会失望，因为上帝通过他赐予我们的圣灵，将他的爱灌注在我们的心中。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所书 2:1–5; 罗马书 5:8; 歌罗西书 2:13"> 当我们感到彻头彻尾的无助，耶稣便在恰好的时间，因不信上帝之人而赴死。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 15:13; 约翰一书 3:16; 罗马书 16:4"> 谁能为其他人而死，为不正确行事之人而死？（有人可能愿意为他人舍生，但只是为真正善良之人而死）</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 15:13; 约翰福音 3:16; 罗马书 5:6"> 基督为仍然是罪人的我们而放弃自己的生命，这就是上帝彰显他对我们的爱。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦前书 1:10; 罗马书 8:1; 以弗所书 2:13"> 既然他的死<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“血。”">b</a></sup>让我们成为良善正直之人，就可以确定，我们将在即将到来的审判中，因他而获得拯救。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 5:18–19; 哥林多后书 4:10–11; 罗马书 8:32"> 我们以他为敌的时候，上帝通过上帝之子的死让我们成为他的朋友，可以确定的是，上帝将通过上帝之子的生命拯救我们。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 5:18–19; 罗马书 5:10; Isaiah 61:10"> 不仅如此，上帝通过主耶稣所行之事与我们和解，让我们成为他的朋友，我们现在就可以为之而庆贺。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 15:21–22; 罗马书 5:19; 罗马书 6:23"> 罪通过人进入这个世界，罪带来死亡。所以，所有人都会死，因为所有人都有罪。</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 4:15; 哥林多前书 15:56; 约翰一书 3:4"> 在律法被赋予人类以前，罪便已存于这世界，但因为当时没有律法，罪也不算罪。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 15:45; 罗马书 5:17; 希伯来书 9:27"> 但从亚当到摩西的这段时间，死亡仍然无法躲避，即使那些没有以亚当犯罪的方式犯罪的人，他们仍然会死。<br />亚当预示了那即将到来之人。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="换言之，亚当是即将到来的耶稣的象征或他的形象。">c</a></sup></span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 6:23; 以弗所书 2:8; 罗马书 5:12"> 但耶稣的恩赐与亚当的罪截然不同。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="通过“耶稣”和“亚当”来阐明恩赐和罪恶的含义。">d</a></sup>尽管很多人因一个人的罪而死，上帝会赐予更多恩典，通过耶稣基督让众多之人可以分享。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 13:38–39; Isaiah 1:18; Isaiah 44:22"> 这恩赐的结果与罪行结果完全不同，亚当之罪带来了审判和定罪，恩赐却会让我们因上帝而变得良善正直，无论我们有多少罪。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 15:21–22; 哥林多前书 15:49; 罗马书 5:12"> 因一个人的罪，死亡就会因此人而掌控这世界。但上帝的恩典如此伟大，他恩赐之礼让我们变得良善正确，因为每一位接受他之人，都会通过耶稣基督获得生命。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 15:22; 罗马书 5:12; 罗马书 5:15"> 一个罪让所有人都遭受审判，所有人都被定罪。同样，一个良善行为也会让所有人获得生而良善正义的机会。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 5:18; 哥林多后书 5:21; 腓立比书 2:8"> 亚当的不顺从让众人变成了罪人。同样，耶稣的顺从会让众人与上帝和解。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 6:1; 提多书 3:3–7; 罗马书 6:14"> 当律法被带到这个世界，罪就变得显而易见。但是，当罪变得更加显而易见，恩典同样也会变得显而易见！</span>
<span className="v" id="v21" data-v="21" data-xref="提多书 2:11; 罗马书 5:14; 罗马书 8:10"> 正如罪统治人间并带给我们死亡，如今恩典统治人间会让我们与上帝和解，通过我们的主耶稣基督带给我们永生。</span>
</div>

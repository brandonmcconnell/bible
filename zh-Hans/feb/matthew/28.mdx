<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 16:1–8; 约翰福音 20:1–10; 马太福音 27:56"> 过了安息日，在下一周第一天<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这一天对应了我们的星期天。这段文字明确指出，这一天就是“第一天”，是安息日之后的“第七天。”">a</a></sup>天亮的时候，抹大拉的玛利亚和另一位玛利亚来看望坟墓。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 16:26; 约翰福音 20:12–13; 马可福音 16:3–5"> 忽然地面剧烈震动起来，主的使者从天而降，把石头滚到一边，坐在上面。</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 9:3; 使徒行传 1:10; 马可福音 16:5"> 他的脸散发着亮光，衣服洁白如雪。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 1:17; Daniel 10:7; 马太福音 27:65–66"> 看守之人因为害怕而浑身战抖，仿佛死了一样。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="启示录 1:17–18; 希伯来书 1:14; Isaiah 41:10"> 使者对妇女们说：“你们不要怕，我知道你们在找被钉十字架的耶稣。</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 16:6; 马太福音 12:40; 路加福音 24:6–8"> 他不在这里，已经照他所说复活了。你们来看安放他的地方吧。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 26:32; 路加福音 24:22–24; 马太福音 28:10"> 快去告诉他的门徒：他已经从死人中复活了。他会比你们先到加利利去，你们在那里必看见他。我保证。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="Psalms 2:11; 马可福音 16:8; 路加福音 24:36–41"> 她们立刻离开坟墓，又害怕，又欢喜，跑去告诉耶稣的门徒。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 28:17; 约翰福音 20:14–17; 马太福音 14:33"> 忽然，耶稣向她们迎面而来，说：“你们好。”她们跑上前，抱住他的脚拜他。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 8:29; 约翰福音 20:17; 马太福音 28:7"> 耶稣对她们说：“不要怕，去告诉我的兄弟，叫他们到加利利去，他们在那里必会看见我。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马太福音 27:65–66; 马太福音 28:4"> 她们去的时候，有些卫兵进了城，把发生的一切报告了祭司长。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 26:3–4; 使徒行传 4:5–22; 马太福音 27:1–2"> 祭司长于是和长老聚集在一起商量出个计划，然后拿许多钱用于贿赂士兵，</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马太福音 26:64"> 说：“你们要这样说：‘他的门徒晚上过来，趁我们睡着的时候，把他偷走了。’</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 27:2; 使徒行传 12:19"> 如果总督知道了这件事，我们会说服他，你们不用担心。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="提摩太前书 6:10; 马太福音 27:8; 马太福音 26:15"> 士兵收了钱，按照祭司长和长老的指使去做，犹太人至今都流传着这段故事。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马太福音 26:32; 马太福音 28:10; 马太福音 28:7"> 十一个门徒往加利利去，到了耶稣指定的山上。</span>
<span className="v" id="v17" data-v="17" data-xref="Psalms 45:11; Psalms 2:12; 约翰福音 5:23"> 他们看见耶稣就膜拜他，但仍然有些人怀疑。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 3:35; 彼得前书 3:22; 马太福音 11:27"> 耶稣上前来，对他们说：“天上地上的一切权力都赐给我了。</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 16:15–16; 使徒行传 2:38–39; 使徒行传 1:8"> 你们要去让万国之民都做我的门徒，奉父子圣灵的名，给他们施洗。</span>
<span className="v" id="v20" data-v="20" data-xref="Isaiah 41:10; Joshua 1:5; 使徒行传 18:9–10"> 我向你们教导的一切，都要教导他们遵守。记住，我始终与你们同在，直到这世界的终结。”</span>
</div>
</div>

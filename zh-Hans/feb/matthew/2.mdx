<span className="v" id="v1" data-v="1" data-xref="Micah 5:2; 约翰福音 7:42; 路加福音 2:4–7"> 耶稣诞生在犹太的伯利恒，当时正是希律王执政时期。耶稣诞生后，几位智者<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或“博士。”他们的身份应该为宗教祭司长，可能来自于波斯，擅长星相学。">a</a></sup>从东方来到耶路撒冷。</span>
<span className="v" id="v2" data-v="2" data-xref="Numbers 24:17; Jeremiah 23:5; 启示录 22:16"> 他们说：“犹太之王已经诞生，他在哪里？我们看到他的明星显现于东方的夜空，特来拜访。”</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 17:6–7; 约翰福音 11:47–48; 马太福音 23:37"> 希律王听闻此言颇感紧张，整个耶路撒冷城的民众也内心惴惴。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 21:23; 马太福音 7:29; 使徒行传 6:12"> 希律召集所有的祭司长和民间的宗教老师，询问他们弥赛亚可能会诞生在何处。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 7:42; Ruth 1:1; 1 Samuel 16:1"> 众人回答：“在犹太的伯利恒。因为先知曾写道：</span>
<span className="v" id="v6" data-v="6" data-xref="Ezekiel 34:23–25; Micah 5:2; Isaiah 9:6–7"> 犹大的伯利恒啊，你在犹大诸城<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“城市”为隐喻。">b</a></sup>中并非渺小，因为未来你们中将诞生一位领袖，他将带领以色列人。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="见《弥迦书》5:2和《撒母耳记》5:2。">c</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="Exodus 1:10; 1 Samuel 18:21; Psalms 55:21"> 听闻此言，希律私下叫来几位智者，仔细询问那颗星具体出现的时间。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 3:19–20; Jeremiah 41:5–7; 路加福音 20:20–21"> 然后他派他们去伯利恒，还说：“你们到了那里后，仔细寻找那个孩子，找到后就来向我报告，我也会去拜见他。”</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 2:2; Proverbs 8:17; Psalms 25:12"> 智者于是听从国王的旨意出发，他们之前看到的那颗星位于东方，一路指引着他们，最终停在孩子所在之处的上空。</span>
<span className="v" id="v10" data-v="10" data-xref="Psalms 105:3; 路加福音 2:20; 路加福音 2:10"> 看到这颗星<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="很显然，这意味着当他们看到那颗星停了下来，因为他们已经看到了星星，然后从他们在东方的家一路跟着星星而行。">d</a></sup>，智者们分外欢喜！</span>
<span className="v" id="v11" data-v="11" data-xref="Isaiah 60:6; Psalms 72:10; 路加福音 2:16"> 他们随即走进房屋，看见孩子与其母亲玛利亚。于是他们伏拜在孩子面前，打开宝袋，将里面的黄金、乳香、没药作为礼物送给他。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 2:22; 马太福音 2:19; 马太福音 2:13"> 由于主曾托梦警告他们，不要将眼前所见禀报希律王，于是他们便从另外一条道路回到了自己的国家。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 10:7; 使徒行传 5:19; 马太福音 1:20"> 智者离开后，主的天使出现在约瑟的梦中，告诉他：“快起来！带着孩子和他的母亲逃到埃及并住下，等候我的指示。因为希律一定会想方设法找到这孩子并将他除掉。”</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 2:20–21; 使徒行传 26:21; 马太福音 1:24"> 约瑟醒来后，立刻连夜带着孩子和妻子向埃及逃去。</span>
<span className="v" id="v15" data-v="15" data-xref="Hosea 11:1; Exodus 4:22; Numbers 24:8"> 此后便一直住在那里，直到希律王驾崩。这件事应验了主借先知所传达的预言：“我从埃及唤出我儿。”<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="引自《何西阿书》11:1。">e</a></sup></span>
<span className="v" id="v16" data-v="16" data-xref="Isaiah 59:7; Proverbs 28:15; Judges 16:10"> 希律发现智者欺骗了他，非常生气。根据从智者处打听的信息，他推测这个男孩应该不到两岁，于是立刻下令杀掉伯利恒城内及周边地区所有两岁以下男孩。<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="换言之，在智者发现这颗星之前，它已经在天空显现了两年。">f</a></sup></span>
<span className="v" id="v17" data-v="17"> 这正应了先知耶利米的预言：</span>
<span className="v" id="v18" data-v="18" data-xref="Jeremiah 31:15; Jeremiah 9:17–21; Jeremiah 4:31"> 在拉玛传来可怕的痛哭与哀嚎，拉结为其子女哭泣，白发人送黑发人，这是任何安慰都无法抚平的悲伤。<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="引自《耶利米书》31:15。">g</a></sup></span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 1:20; Daniel 8:25; 马太福音 2:12–13"> 希律王驾崩之后，主派天使向住在埃及的约瑟托梦，告诉他：</span>
<span className="v" id="v20" data-v="20" data-xref="Exodus 4:19; 1 Kings 12:1–3; 马太福音 2:13"> “出发吧！带着孩子和孩子的母亲去以色列，因为想要取这孩子性命的人已死去。”</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 11:8; Genesis 6:22"> 约瑟醒来后，便带着孩子和孩子的母亲动身前往以色列。</span>
<span className="v" id="v22" data-v="22" data-xref="Isaiah 48:17–18; 路加福音 2:39; 约翰福音 7:52"> 但当他听说希律之子亚基劳斯继位做了犹太王，便害怕回到以色列。由于在梦中获得警告，于是他便去了加利利，</span>
<span className="v" id="v23" data-v="23" data-xref="Judges 13:5; 约翰福音 1:45–46; 马可福音 1:24"> 在一座名为拿撒勒的城市中安顿下来。这应验了先知的那句话：人们将称他为拿撒勒人。<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="即耶稣。马修在这里并没有引用某一句具体的预言。">h</a></sup></span>
</div>

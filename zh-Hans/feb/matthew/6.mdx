<span className="v" id="v1" data-v="1" data-xref="马太福音 23:5; 约翰福音 12:43; 希伯来书 6:10"> “不要将善事做在人的面前，叫别人看见，否则就得不到天父的赏赐。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 6:5; 马太福音 6:16; 哥林多后书 9:6–15"> 所以若你施舍穷人，不要像那些伪君子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="来自希腊的词语，原意“假装。”">a</a></sup>一样，在会堂和街头到处张扬，博取众人的称赞。实话告诉你们，他们已经得到了他们的赏赐。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 7:4; 马太福音 9:30; 马可福音 1:44"> 你施舍的时候，不要叫你的左手知道右手所做的。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 6:18; 马太福音 6:6; Jeremiah 17:10"> 你的施舍应隐秘进行。因圣父在隐秘中观察，必将赏赐于你。</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 18:10–11; 马太福音 6:2; 路加福音 18:13"> 当你们祈祷，不可如伪君子一般：他们只喜欢站在会堂和路口祈祷，只为让人看见。说实话，他们已经得到了他们的赏赐。</span>
<span className="v" id="v6" data-v="6" data-xref="2 Kings 4:33; 马太福音 14:23; Isaiah 65:24"> 至于你们，你们的祈祷应在密室中进行，关上门，向隐密中的圣父祈祷。因圣父在隐密中观察，必将赏赐于你。</span>
<span className="v" id="v7" data-v="7" data-xref="Ecclesiastes 5:2–3; Ecclesiastes 5:7; 1 Kings 18:26–29"> 当你祈祷，不可如异教徒般反复念叨毫无意义的词语。他们误以为只要重复，上帝就可以听到。</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 6:32; 路加福音 12:30; 腓立比书 4:6"> 不可像他们那样，因为早在你们开口祈祷之前，圣父便已洞悉你们需要什么。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 11:1–4; 启示录 4:11; 罗马书 8:15"> 所以要这样祈祷： 我们的天父，赞颂你的圣名。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 10:36; 马太福音 26:42; 马太福音 12:50"> 愿你的国度降临！愿你的意志在世间成真，一如在天国一般。</span>
<span className="v" id="v11" data-v="11" data-xref="Proverbs 30:8; 路加福音 11:3; 马太福音 4:4"> 今天请赐予我们需要的食物；</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 4:32; 马可福音 11:25; 以弗所书 1:7"> 赦免我们的罪恶，一如我们饶恕了那些曾对我们犯下罪行之人；</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 10:13; 启示录 7:14–17; 马太福音 26:41"> 请阻止我们深陷诱惑，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或“请勿让我们陷入诱惑。”原文此处采用被动语态，不是主动语态。换言之，祈祷者的愿望是：上帝不要允许诱惑征服我们。这代表诱惑并非来自上帝。">b</a></sup>拯救我们脱离邪恶。</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所书 4:32; 马可福音 11:25; 歌罗西书 3:13"> 如果你们饶恕他人对你犯下的罪，天父自会饶恕你们的罪。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 18:35"> 如果你们不饶恕他人对你犯下的罪，天父也不会饶恕你们。</span>
<span className="v" id="v16" data-v="16" data-xref="Isaiah 58:3–5; 马太福音 9:14–15; Daniel 9:3"> 当你们禁食，不可如伪君子般愁眉苦脸，他们只是装作难受的模样，向别人显示其正在禁食。实话告诉你们，他们已经得到了他们的赏赐。</span>
<span className="v" id="v17" data-v="17" data-xref="Ruth 3:3; Ecclesiastes 9:8; 2 Samuel 12:20"> 当你禁食，要梳洗得当，</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 6:6; 马太福音 6:4; 哥林多后书 10:18"> 不要叫外人看到你在禁食，因圣父在隐秘中正在观察你，必将与你予以赏赐。</span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 13:5; 约翰一书 2:15–16; 路加福音 12:21"> 不可在这世界上堆积财富，因地上有虫蛀，有锈蚀，还有贼闯入偷窃。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 12:33; 马太福音 19:21; 雅各书 2:5"> 你应在天堂积聚财富，那里没有虫蛀锈蚀，没有盗贼偷窃。</span>
<span className="v" id="v21" data-v="21" data-xref="歌罗西书 3:1–3; 路加福音 12:34; 哥林多后书 4:18"> 因为你最看重什么，就表明你是谁。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 11:34–36; 哥林多后书 11:3; 歌罗西书 3:22"> 你的眼，就是点亮身体的灯。若眼睛健康，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或“好的，纯洁的。”">c</a></sup>整个身体就会亮起来。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰一书 2:11; 马太福音 6:22; Isaiah 5:20–21"> 若眼睛邪恶，你的身体就会身处黑暗。如果你心中的‘光’成为黑暗，那才是真正的黑暗！</span>
<span className="v" id="v24" data-v="24" data-xref="约翰一书 2:15–16; 路加福音 16:13; 雅各书 4:4"> 一个人不能侍奉两主；你必会爱其中一人，恨另一人，或忠于其中一人，鄙视另一人；你无法同时服务于上帝和金钱。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原意来自于阿拉伯语，意为叙利亚的金钱和财富之上帝。">d</a></sup></span>
<span className="v" id="v25" data-v="25" data-xref="腓立比书 4:6; 彼得前书 5:7; 罗马书 8:32"> 所以我要说的是，不必担心生命，忧虑衣食住行。难道生命不比食物重要？身体不比衣服更重要？</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 10:29–31; Psalms 147:9; 路加福音 12:24–32"> 看天空中的鸟<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原意为“空气之鸟”是指野鸟而非驯养之鸟。">e</a></sup>：它们不播种、不收割、不存粮食，但天父仍喂养它们。难道你们不比它们更宝贵吗？</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 12:25–26; Ecclesiastes 3:14; Psalms 39:5–6"> 你们谁又能通过忧虑，让寿命延长一分钟？</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 6:25; 腓立比书 4:6; 路加福音 12:27"> 何必为衣着忧虑？看看田野中那些美丽的鲜花，看看它们成长的方式：不必辛苦劳作，不必忙于纺织。</span>
<span className="v" id="v29" data-v="29" data-xref="2 Chronicles 9:20–22; 2 Chronicles 9:4–6; 彼得前书 3:2–5"> 但我想说的是，即使是所罗门最荣耀时刻的穿着，也比不上任何一朵野花。</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 14:31; 路加福音 12:28; 彼得前书 1:24"> 田野的草今天还在，明天就会被扔进炉火中，如果上帝这样装扮田野，你们这些缺乏信任的人，上帝又怎会为你们做更多？</span>
<span className="v" id="v31" data-v="31" data-xref="彼得前书 5:7; 路加福音 12:29; 马太福音 4:4"> 所以不要忧虑，不要想着：‘我们该吃什么？喝什么？穿什么？’</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 6:8; 路加福音 12:30; 以弗所书 4:17"> 这些只是异教徒的追求，你们的天父知道你们需要的一切。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 12:31; 马太福音 5:6; 约翰福音 6:27"> 先求他的国度，求他正确的生活方式，一切都会赐给你。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 6:25; 约翰福音 14:27; 希伯来书 13:5–6"> 所以不要为明天忧虑，因为明天自有明天的担忧。每天邪恶的事情已经够多了。”</span>

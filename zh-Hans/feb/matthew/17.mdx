<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 9:28–36; 马太福音 26:37; 马可福音 5:37"> 六天后，耶稣带着彼得、雅各和雅各的弟弟约翰，登上一处高山，只有他们几个。</span>
<span className="v" id="v2" data-v="2" data-xref="Psalms 104:2; 马太福音 28:3; 路加福音 9:29"> 耶稣在他们面前变身，面孔如太阳一样照耀，衣服洁白如光。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 24:44; 马可福音 9:4; Malachi 4:5"> 忽然，摩西和以利亚出现在他们面前，与耶稣说话。</span>
<span className="v" id="v4" data-v="4" data-xref="马可福音 9:5–6; 路加福音 9:33; 约翰福音 14:8–9"> 彼得对耶稣说：“主啊，在这里真好。如果你愿意，我就在这里搭三座棚，一间为你，一间为摩西，一间为以利亚。”</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 3:17; 马太福音 12:18; Deuteronomy 18:15"> 彼得说话的时候，一朵明亮的云彩笼罩他们，云中有声音说：“这是我所爱之子，他让我高兴，你们要听他的。”</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 26:14; 彼得后书 1:18; Daniel 8:17"> 门徒听见，便俯伏在地上，惊恐万分。</span>
<span className="v" id="v7" data-v="7" data-xref="Daniel 10:18; 马太福音 14:27; Daniel 8:18"> 耶稣前来，摸着他们说：“起来，不用怕。”</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 9:36; 马可福音 9:8; 使徒行传 12:10–11"> 他们抬起头来，却只见耶稣自己，别无他人。</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 8:30; 马可福音 9:9–13; 马太福音 17:23"> 下山的途中，耶稣吩咐他们：“人子从死亡中复活以前，不要把所见异象告诉其他人。”</span>
<span className="v" id="v10" data-v="10" data-xref="Malachi 4:5–6; 马太福音 11:14; 约翰福音 1:21"> 门徒就问他：“那为什么宗教老师会说，以利亚先来？”</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 3:21; 路加福音 1:16–17; Malachi 4:6"> 耶稣回答：“以利亚定会出现，准备好一切。</span>
<span className="v" id="v12" data-v="12" data-xref="Isaiah 53:3–12; 马太福音 16:21; 使徒行传 13:24–28"> 但我要说的是，以利亚已经降临，只是人们不认识他，随意待他。人子必会因他们遭受苦难。”</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 11:14"> 门徒方然领悟，耶稣所指为施洗约翰。</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 9:14–29; 马可福音 1:40; 使徒行传 10:25–26"> 耶稣和门徒来到民众处，一个人前来，跪在耶稣面前说：</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 4:24; Job 1:10–19; 马可福音 9:20–22"> “主啊，可怜我的儿子吧，他患了失心疯<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“傻瓜。”意思与拉丁语“lunaticus”的英语“lunatic”相近。">a</a></sup>，非常痛苦，经常会跌入水火之中。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 17:19–20; 路加福音 9:40; 使徒行传 19:15–16"> 我带他去见你的门徒，但他们无法医好他。”</span>
<span className="v" id="v17" data-v="17" data-xref="Numbers 14:11; 马太福音 6:30; 马可福音 16:14"> 耶稣说：“你们<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“世界。”">b</a></sup>不肯相信我，如此堕落！我要在这里与你们待到何时？我要忍受你们到何时？把孩子带到我这里。”</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 9:22; 马可福音 1:34; 马可福音 5:8"> 耶稣与恶鬼对峙，让那鬼离开了孩子，孩子马上就好了。</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 9:28; 马可福音 4:10"> 稍后，门徒悄悄来问耶稣：“为什么我们无法驱鬼？”</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 17:6; 马可福音 11:23; 路加福音 1:37"> 他说：“因为你们的信心不够。告诉你们吧。只要你们有信心，哪怕只像一粒芥菜种那么小，也能对这山说：‘从这里移到那里’，它也会移开，没有什么不可以。”</span>
<span className="v" id="v21" data-v="21"> <sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="最早的抄本中并无第 21句。">c</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 16:21; 路加福音 18:31–34; 马太福音 17:23"> 耶稣与门徒走过加利利的路上，耶稣对门徒说：“人子将被背叛，人将凌驾于<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原意为“被人类出卖。”">d</a></sup>他之上。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 16:21; Isaiah 53:10–12; 马可福音 8:31"> 他们将杀害他，但第三天他会复活。”这话让门徒们心生悲伤。</span>
<span className="v" id="v24" data-v="24" data-xref="Exodus 38:26; Exodus 30:13; 马可福音 9:33"> 他们来到迦百农，负责收殿税的税吏前来对彼得说：“你们的老师不纳丁税吗？”</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 22:21; 罗马书 13:6–7; 马太福音 22:17"> 彼得说：“当然纳税。” 当他走进屋子里，耶稣已经预料到这段对话，于是说：“人间的君王向谁征收关税和殿税，向自己的孩子还是外人？你怎么看，西门？”</span>
<span className="v" id="v26" data-v="26"> 彼得回答：“外人。”耶稣对他说：“这样，他的孩子就可以免税了。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多后书 6:3; 哥林多前书 8:9; 哥林多前书 9:19–22"> 但我不想冒犯任何人。所以你要到海边去钓鱼，把钓上来的第一条鱼拿起来，掰开鱼嘴，就会找到一个大银币<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="价值为古希伯来货币一谢克尔。当时的圣殿税为每人半谢克尔。">e</a></sup>，可以拿去交给他们，做你我的殿税。”</span>

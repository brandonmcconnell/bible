<span className="v" id="v1" data-v="1" data-xref="马可福音 3:22; 马太福音 23:2; 路加福音 5:21"> 有法利赛人和宗教老师从耶路撒冷前来，问耶稣：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 11:38; 马可福音 7:2; 歌罗西书 2:20–23"> “你的门徒为什么违背祖先的传统，在饭前不洗手？”</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 2:23; 提多书 1:14; 歌罗西书 2:8"> 耶稣回答：“你们为什么因依据传统而违背上帝的诫命呢？</span>
<span className="v" id="v4" data-v="4" data-xref="Exodus 20:12; Leviticus 20:9; Exodus 21:17"> 上帝说：‘当孝敬父母，’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《出埃及记》20:12或《申命记》5:16。">a</a></sup>又说：‘咒骂父母必被处死。’<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引自《出埃及记》21:17或《利未记》20:0。">b</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 7:10–13; 使徒行传 5:29; 马太福音 23:16–18"> 你们却认为如果一个人对父母说：‘我把给你们的东西都献给了上帝，’</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前书 5:8; Jeremiah 8:8; 马可福音 7:13"> 所以这个人就可以不孝敬父母了。你们遵循了传统，却背弃了上帝。</span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 7:6; 马太福音 23:23–29; 使徒行传 28:25–27"> 这是伪君子的行为！以赛亚用来说你们的预言太对了：</span>
<span className="v" id="v8" data-v="8" data-xref="Isaiah 29:13; Ezekiel 33:31; 使徒行传 8:21"> ‘这些人只把尊敬说在嘴上，思想却在远离我，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或“这些人用语言尊重我，但心距我还有很长的路。”">c</a></sup></span>
<span className="v" id="v9" data-v="9" data-xref="Isaiah 29:13; 马可福音 7:7; 提摩太前书 1:4"> 他们对我的敬拜并无意义，他们所授仅为人类的要求而已。’”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《以赛亚书》29:13。">d</a></sup></span>
<span className="v" id="v10" data-v="10" data-xref="马可福音 7:14–15; 路加福音 20:45–47; 路加福音 24:45"> 耶稣叫来民众，对他们说：“你们要听，也要明白：</span>
<span className="v" id="v11" data-v="11" data-xref="马可福音 7:15; 马太福音 15:18–20; 雅各书 3:5–8"> 污秽之物并非口中所入，而是口中所出。”</span>
<span className="v" id="v12" data-v="12" data-xref="1 Kings 22:13–14; 哥林多前书 10:32–33; 加拉太书 2:5"> 门徒前来告诉他：“你知道吗，法利赛人对你所说的话很生气。”</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 15:2; Isaiah 60:21; 约翰福音 15:6"> 耶稣说：“不是我天父栽种的植物，都要连根拔起。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 6:39; Isaiah 56:10; 马太福音 23:16–24"> 不用理会他们！他们只是瞎眼的向导。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="即法利赛人。">e</a></sup>瞎子带瞎子走路，二人都会跌进坑中。”</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 13:36; 马可福音 4:34; 约翰福音 16:29"> 然后彼得说：“请给我们解释这个比喻吧。”</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 16:9; 马可福音 7:18; 马可福音 9:32"> 耶稣说：“你们还是不明白吗？</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 6:45; 哥林多前书 6:13; 马太福音 7:19–20"> 你没发现吗？入口之物会进入肠胃，然后作为废物排泄出去。<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="原意为“冲入下水道。”">f</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="Proverbs 15:28; 马太福音 12:34; 雅各书 3:6–10"> 但从口里所出均发自内心，这才会让人污秽。</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 7:21–23; 加拉太书 5:19–21; Jeremiah 17:9"> 因为由心而生的有恶念、凶杀、奸淫、淫乱、偷盗、伪证或诽谤，</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 7:3–4; 以弗所书 5:3–6; 哥林多前书 6:18–20"> 这些才会使人污秽，不洗手吃饭却不会如此这样。”</span>
<span className="v" id="v21" data-v="21" data-xref="马可福音 7:24–30; 马太福音 11:21–23; Judges 1:31"> 耶稣离开那里，向推罗和西顿走去。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 9:27; 马可福音 7:25–26; 马太福音 17:15"> 一个迦南妇人从那地方出来，喊着说：“主啊，大卫的子孙，可怜我吧！我的女儿被鬼附得很苦。”</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 14:15; 马可福音 10:47–48; Lamentations 3:8"> 耶稣并未回答。门徒上前求他说：“别让她再跟随我们了，她的喊叫很恼人。”</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 10:5–6; 罗马书 15:8; Jeremiah 50:6–7"> 耶稣对女人说：“我只是被派到以色列家迷失的羊那里。”</span>
<span className="v" id="v25" data-v="25" data-xref="Genesis 32:26; 马太福音 20:31; 马太福音 14:33"> 她便跪在耶稣面前说：“主啊，求你帮助我！”</span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 7:27–28; 马太福音 7:6; 腓立比书 3:2"> 耶稣回答：“把孩子的食物丢给狗<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="这个词用于狗时，表示宠物狗或小狗。">g</a></sup>吃可不好。”</span>
<span className="v" id="v27" data-v="27" data-xref="以弗所书 3:8; 路加福音 16:21; Job 40:4–5"> 她说：“主啊，是的，不过小狗也会吃主人桌子掉下的碎渣。”</span>
<span className="v" id="v28" data-v="28" data-xref="马可福音 9:23–24; 马太福音 8:13; Psalms 145:19"> 于是耶稣对她说：“你对我的信心极大，那就让你如愿吧！”从那一刻起，她的女儿就好了。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 4:18; 约翰福音 6:1; 马太福音 5:1"> 耶稣在返途中经过加利利之海，便走到附近的山上，坐下。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 6:17–19; 使徒行传 5:15–16; 马太福音 14:35–36"> 人潮不断涌向他这里，带来瘸腿、盲人、残废、哑巴和其他病患，放在他脚前，耶稣便医好他们。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 9:8; 路加福音 18:43; 路加福音 17:15–18"> 民众看见哑巴能说话，残废能复原，瘸腿能行走，盲人能看见，十分惊奇，开始颂赞以色列的上帝。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 27:33; 路加福音 12:29–30; 马太福音 9:36"> 耶稣唤来门徒，说：“我对这一群人感到很难过，他们与我在一起已有三天，没有进食；我不想叫他们饿着肚子回去，恐怕他们会在路上晕倒。”</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 6:37; 马太福音 14:15; 马可福音 8:4–5"> 门徒对他说：“这荒郊野外的，哪里有足够的食物给这么多人吃饱呢？”</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 16:9–10; 路加福音 24:41–42; 约翰福音 21:9–10"> 耶稣问他们：“你们有多少饼？”他们说：“七块饼和几条小鱼。”</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 9:14–16; 马可福音 6:39–40; 约翰福音 6:10"> 耶稣于是吩咐民众坐在地上，</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 22:19; 罗马书 14:6; 约翰福音 6:11"> 然后拿起那七块饼和鱼，祝福这食物，然后掰开递给门徒，门徒又分给众人。</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 8:19–21; 马太福音 16:9–10; 马太福音 15:33"> 所有人都有食物吃，并且吃得很饱。然后他们把剩下的食物收集起来，足足装满了七个大篮子。</span>
<span className="v" id="v38" data-v="38"> 吃的人，除了妇女和孩子，共四千人。</span>
<span className="v" id="v39" data-v="39" data-xref="马可福音 8:10; 马太福音 14:22"> 耶稣解散了民众后就登上船，来到马加丹地区。</span>

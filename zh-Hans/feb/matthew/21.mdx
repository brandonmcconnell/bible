<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Zechariah 14:4; 马可福音 11:1–10; 路加福音 21:37"> 耶稣和门徒去了耶路撒冷，来到橄榄山的伯法其小村。耶稣派两个门徒出门，</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 19:30–32; 马可福音 11:2–3; 约翰福音 2:5–8"> 对他们说：“到那个村子里去，在那里，你会看见一头驴被绳子拴在那里，它身边还有一头小驴。把它们解开，牵来给我。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 8:1–2; 使徒行传 17:25; 哥林多后书 8:9"> 如果有人问你们，就要说：‘主需要它们。’他会立刻让你们牵走。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="Zechariah 9:9; 约翰福音 12:15; 马太福音 1:22"> 这应验了先知所说：</span>
<span className="v" id="v5" data-v="5" data-xref="Zechariah 9:9–10; Isaiah 62:11; Isaiah 12:6"> “告诉锡安子民，说：‘看哪，你的王来了，他生性谦卑，骑着一头驴，还带着那头驴的幼崽。’”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="见《以赛亚书》62:11和《撒迦利亚书》9:9。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="Exodus 39:43; 约翰福音 15:14; Exodus 40:16"> 这两位门徒照着耶稣的吩咐而行，</span>
<span className="v" id="v7" data-v="7" data-xref="2 Kings 9:13; 马可福音 11:4–8; 路加福音 19:32–35"> 牵了母驴和小驴来，把衣服搭在驴身上，耶稣骑了上去。</span>
<span className="v" id="v8" data-v="8" data-xref="2 Kings 9:13; 约翰福音 12:13; Leviticus 23:40"> 人群中有很多人把自己的衣服铺在路上，也有人从树上把树枝砍下，铺在路上。</span>
<span className="v" id="v9" data-v="9" data-xref="Psalms 118:24–26; 路加福音 2:14; 约翰福音 12:13–15"> 前呼后拥的民众喊叫着：“颂赞归于救世主<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这个词的原意为“请拯救我们”，为颂扬之语。">b</a></sup>，大卫的子孙，他奉主之名前来，有福了。高高在上和散那！。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 9:5; Ruth 1:19; 约翰福音 12:16–19"> 耶稣进了耶路撒冷，全城轰动，城中人问：“此人是谁？”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约翰福音 6:14; 路加福音 7:16; 约翰福音 7:40"> 人群回答：“这就是先知耶稣，来自加利利的拿撒勒。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约翰福音 2:14–17; 路加福音 19:45–47; 马可福音 11:15–18"> 耶稣进了圣殿，把殿里所有买卖人都赶走，推倒换钱的桌子和卖鸽子小贩的凳子。</span>
<span className="v" id="v13" data-v="13" data-xref="Jeremiah 7:11; Isaiah 56:7; 路加福音 19:46"> 他对他们说：“经书上写着：‘我的殿应为祷告的殿。’<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《以赛亚书》56:7。">c</a></sup>你们竟把它弄成贼窝了。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="使徒行传 3:1–9; 使徒行传 10:38; 马太福音 11:4–5"> 殿里的盲人和瘸腿之人都走过来，耶稣医好了他们。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 21:9; 路加福音 19:39–40; Isaiah 26:11"> 祭司长和宗教老师眼见耶稣所行奇事，又看见小孩子在殿中喊叫“救世主，大卫的子孙”，就很忿怒，对耶稣说：“你听见孩子们说什么吗？”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="Psalms 8:2; 马太福音 11:25; 路加福音 19:39–40"> 耶稣说：“我听见了。你没念过这段经文？‘你从小孩和婴儿的口中，听到赞美。’”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《诗篇》8:2。">d</a></sup></span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 11:18; 马可福音 11:11; 路加福音 24:50"> 耶稣于是离开他们出了城，来到伯大尼，在那里过了一夜。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 4:2; 希伯来书 4:15; 马太福音 12:1"> 耶稣第二天清早回城的时候，觉得饿了。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 15:6; 马可福音 11:14; 提多书 1:16"> 他看见路旁有一棵无花果树，就走过去，但树上除了叶子什么也没有，于是它对树说：“你永远不会结果了。”那棵树就立刻枯萎。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="Isaiah 40:6–8; 马可福音 11:20–21; 雅各书 1:10–11"> 门徒看见了，十分惊奇，说：“这棵无花果树为什么立刻枯萎了？”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="雅各书 1:6; 马太福音 17:20; 马可福音 11:22–23"> 耶稣回答他们：“告诉你们实话，如果你们相信上帝，不怀疑，不但可以像我对无花果树所做的那样，还可以对这座山说‘移走吧，落入海中’。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 7:7; 约翰一书 5:14–15; 马可福音 11:24"> 你们祷告，无论求什么，只要相信，必会心想事成。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 4:7; 马可福音 11:27–33; 1 Chronicles 24:1–19"> 耶稣走进圣殿，他在教导众人的时候，祭司长和民间长老前来问他：“你凭什么权力做这些事？谁给你这权力？”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 6:9; 歌罗西书 4:6; 马太福音 10:16"> 耶稣回答他们：“我也要问你们一句，如果你们回答我，我就告诉你们我凭什么权力行这些事。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰一书 3:20; 马可福音 1:1–11; 约翰福音 3:18"> 约翰的洗礼从何而来？从天上来，还是从人中来？”他们开始商讨：“如果我们说‘从天上来’，他会问我们‘那你们为什么不信他呢？’</span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 6:20; 马太福音 14:5; 约翰福音 5:35"> 如果我们说‘从人中来’，民众又会对付我们<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原意为“我们害怕民众。”">e</a></sup>，因为他们会认为约翰就是先知。”</span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 1:18–22; 帖撒罗尼迦后书 2:9–10; 路加福音 20:7–8"> 于是他们回答耶稣：“我们不知道。” 耶稣也对他们说：“那我也不会告诉你们，我凭什么权力行这些事。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 15:58; 马太福音 20:1; 哥林多前书 10:15"> 我来给你们一个比喻。一个人有两个儿子。他对大儿子说：‘孩子，你今天到葡萄园去工作吧。’</span>
<span className="v" id="v29" data-v="29" data-xref="Ezekiel 18:28–32; 马太福音 3:2–8; Isaiah 55:6–7"> 儿子回答：‘我不想去。’但后来他改变了主意，去了葡萄园。</span>
<span className="v" id="v30" data-v="30" data-xref="提多书 1:16; Ezekiel 33:31; 马太福音 23:3"> 父亲同样吩咐小儿子。小儿子说：‘父亲，我会去的。’但却没有去。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 7:29; 路加福音 7:37–50; 马太福音 7:21"> 你们说，这两个儿子，哪一个更听父亲的话？”<br />他们回答：“大儿子。”<br />耶稣对他们说：“我告诉你们实话，税吏和娼妓都会比你们先进入上帝之国。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="路加福音 7:37–50; Zechariah 7:11–12; 路加福音 7:29–30"> 约翰前来指示你们上帝的正道之路，你们不信他，但税吏和娼妓却信他。你们看见后，仍未改变心意去信他。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="Isaiah 5:1–4; 马可福音 12:1–12; 路加福音 20:9–19"> 这里还有一个比喻：有一位家主种了一个葡萄园，四面围上篱笆，在园子里挖了一个踩葡萄酿酒的池子，盖了一座瞭望台，然后把园子租给佃户，就远行去了。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 20:10–19; Isaiah 5:4; Zechariah 1:3–6"> 到了收获之时，园主派了仆人到佃户那里，去收属于他的葡萄。</span>
<span className="v" id="v35" data-v="35" data-xref="2 Chronicles 36:15–16; 马太福音 5:12; 希伯来书 11:36–37"> 佃户却攻击仆人，打伤一人，杀了一人，又用石头砸死一人。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 22:4"> 于是园主再派其他的仆人去，人数比前一次更多，但佃户用同样的方式对付他们。</span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 3:16; 约翰福音 3:35–36; Zephaniah 3:7"> 最后他派了自己的儿子去，说：‘他们必尊敬我的儿子。’</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 20:14; Genesis 37:18–20; 马可福音 12:7–8"> 佃户看见他的儿子，就开始商量：‘这是继承产业之人，杀了他，我们就能占有他的产业！’</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 2:23; 雅各书 5:6; 路加福音 22:52–54"> 于是他们抓住园主之子，把他推到葡萄园外杀了。</span>
<span className="v" id="v40" data-v="40" data-xref="希伯来书 10:29; 马可福音 12:9; 路加福音 20:15–16"> 那么，如果葡萄园主前来，会怎样对待那些佃户？”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="使徒行传 18:6; 马太福音 21:43; 使徒行传 28:28"> 众人回答：“他会毫不留情地除掉那些恶人，把葡萄园租给按时缴纳葡萄的佃户。”</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="Psalms 118:22–23; Isaiah 28:16; 使徒行传 4:11"> 耶稣对他们说：“你可曾记得经上所说：‘建筑工人所弃的石头，成了房屋的奠基石，这是主所为，我们视为奇迹。’<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="引自《诗篇》118:22-23。">f</a></sup></span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 21:41; 马太福音 8:11–12; 彼得前书 2:9"> 所以我要告诉你们，上帝之国将从你们这里取走，赐给那结正道之果的异教徒。</span>
<span className="v" id="v44" data-v="44" data-xref="Isaiah 8:14–15; 彼得前书 2:8; Daniel 2:34–35"> 摔在这石头上的人，必会粉身碎骨，这石头掉在谁的身上，也必将其压得粉碎。”</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="路加福音 20:19; 路加福音 11:45; 马太福音 12:12"> 祭司长和法利赛人听了耶稣这番比喻，知道这是暗指他们。</span>
<span className="v" id="v46" data-v="46" data-xref="马太福音 21:11; 马太福音 21:26; 路加福音 7:16"> 他们想要逮捕耶稣，但又害怕民众，因为他们都认为耶稣是先知。</span>
</div>
</div>

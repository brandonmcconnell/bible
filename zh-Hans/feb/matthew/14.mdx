<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 3:1; 马可福音 8:15; 路加福音 9:7–9"> 这时，君王希律<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“君王”，一个大郡中四分之一的土地。在本处指加利利地区。">a</a></sup>听见耶稣所做的一切，</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 16:14; 约翰福音 10:41; 马可福音 8:28"> 就对臣仆说：“这人是从死人中复活的施洗约翰，所以有这样的能力。”</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 6:17; 路加福音 3:19–20; 马太福音 4:12"> 希律曾因弟弟腓力的妻子希罗底的缘故，拘捕了约翰，把他捆绑后关在监里，</span>
<span className="v" id="v4" data-v="4" data-xref="Leviticus 20:21; Leviticus 18:16; 马可福音 6:18"> 因为约翰多次对他说：“你和她结婚乃非法之举。”</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 21:26; 马太福音 11:9; 马可福音 6:19–20"> 他想杀掉约翰，但又害怕民众，因为他们都认为约翰是先知。</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 6:21–23; Genesis 40:20; Hosea 1:5–6"> 到了希律生日的那天，希罗底的女儿<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="通常被认为是所罗门。">b</a></sup>在众人面前跳舞，希律非常高兴，</span>
<span className="v" id="v7" data-v="7" data-xref="Esther 5:3; Esther 5:6; Esther 7:2"> 于是就向她承诺，无论她要求什么都能给她。</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 6:24; Proverbs 29:10; Proverbs 1:16"> 她在母亲的怂恿下说：“请把施洗约翰的头放在盘子上送给我。”</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 19:12–16; 1 Samuel 14:28; 马可福音 6:26"> 希律对自己刚才的承诺感到后悔了，但碍于在座宾客的面子，就下令满足她的愿望。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 17:12; 马太福音 21:35–36; 路加福音 9:9"> 他派人到监牢中砍下约翰的头，</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 16:6; Genesis 49:7; Ezekiel 16:3–4"> 把头放在盘子上送给那个女孩，女孩又带给母亲。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 8:2; 马太福音 27:58–61"> 约翰的门徒前来认领了尸体，把它埋葬，然后去告诉耶稣。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:10–17; 马太福音 14:1–2; 马可福音 6:30–44"> 耶稣听见后便独自坐船离开，想去一个清净之地独处。民众听说后，便从各个城镇徒步赶来追随他。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 4:15; 马太福音 9:36; 希伯来书 2:17"> 耶稣下了船便看见一大群人，心生怜悯，便医好了人群中的病患。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 15:23; 马可福音 8:3; 马可福音 6:35–36"> 黄昏时分，门徒前来对他说：“这是荒郊野岭，天色已晚，请让民众散开，让他们回自己的村子里买些吃食吧。”</span>
<span className="v" id="v16" data-v="16" data-xref="2 Kings 4:42–44; 哥林多后书 8:2–3; Ecclesiastes 11:2"> 耶稣回答：“他们无需离开，由你们给他们吃的就好！”</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 15:33–34; 马可福音 6:37–38; 路加福音 9:13"> 门徒说：“我们这里除了五块饼和两条鱼，什么也没有。”</span>
<span className="v" id="v18" data-v="18"> 耶稣说：“把它们拿过来给我。”</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 8:6–7; 路加福音 24:30; 1 Samuel 9:13"> 他让众人坐在草地上，拿起那五块饼两条鱼，然后望着天，开始为众人祝福，随后把饼掰开，递给门徒，门徒又分给众人。</span>
<span className="v" id="v20" data-v="20" data-xref="Exodus 16:12; 马可福音 6:42–44; 马太福音 16:8–10"> 大家最终都吃饱了，剩下的吃食被收集起来，装满了十二个篮子。</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比书 4:19; 哥林多后书 9:8–11; 使徒行传 4:4"> 最终有五千名男子吃下了这些食物，还不包括妇女和孩子。</span>
<span className="v" id="v22" data-v="22" data-xref="马可福音 6:45–51; 约翰福音 6:15–21; 马太福音 15:39"> 耶稣立刻催促门徒上船，叫他们先到对岸去，他留下来指示民众散开。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 6:12; 马可福音 6:46; 马太福音 26:36"> 解散了民众后，他独自上山去祷告。晚上降临，他一个人在那里。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 6:18; 马可福音 6:48; 马太福音 8:24"> 此时门徒的船已离岸数公里，因为逆风而受波浪侵袭。</span>
<span className="v" id="v25" data-v="25" data-xref="Job 9:8; 约翰福音 6:19; 马可福音 6:48"> 大约凌晨 3 点左右，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“四更。”">c</a></sup>耶稣在海面上走过来，赶上了他们。</span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 6:49–50; 启示录 1:17; 路加福音 1:11–12"> 门徒见他在海面上行走，惊恐地大叫：“有鬼啊！”</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 23:11; 启示录 1:17–18; 约翰福音 16:33"> 耶稣立刻对他们说：“放心吧！是我！不要怕。”</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 6:68; 罗马书 12:3; 马太福音 26:33–35"> 彼得对他说：“主啊，如果是你，让我也在水面上走到你那里去。”</span>
<span className="v" id="v29" data-v="29" data-xref="腓立比书 4:13; 马可福音 9:23; 使徒行传 3:16"> 耶稣说：“来吧！”彼得就下了船，行于水面之上，向耶稣走去。</span>
<span className="v" id="v30" data-v="30" data-xref="Lamentations 3:54–57; 提摩太后书 4:16–17; 马可福音 14:38"> 但他见到风浪就心生害怕，快要沉下去之时立刻呼叫：“主啊！救我！”</span>
<span className="v" id="v31" data-v="31" data-xref="雅各书 1:6–8; Psalms 138:7; Genesis 22:14"> 耶稣马上伸手拉住他，对他说：“你对我的信太少了，为什么疑惑？”</span>
<span className="v" id="v32" data-v="32" data-xref="Psalms 107:29–30; 马可福音 4:41; 约翰福音 6:21"> 他们上了船，风停了。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 11:27; Psalms 2:7; 罗马书 1:4"> 船上的人都开始膜拜耶稣，说：“你真是上帝的儿子。”</span>
<span className="v" id="v34" data-v="34" data-xref="马可福音 6:53–56; 路加福音 5:1; 约翰福音 6:24–25"> 他们来到对岸的革尼撒勒地区。</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 4:24–25; 马可福音 6:55; 马可福音 1:28–34"> 当地人认出是耶稣，就把消息传遍整个地区。众人把一切病患都带了过来，</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 6:19; 马可福音 3:10; Exodus 28:33–43"> 他们求耶稣，让患者摸一摸他的衣服，摸着的人都痊愈了。</span>

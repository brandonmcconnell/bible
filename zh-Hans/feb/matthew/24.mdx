<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="feb" data-translation-id="cmn_feb" data-translation-label="易读圣经" data-book="MAT" data-book-slug="matthew" data-book-name="马太福音" data-chapter="24" data-verses="51">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 13:1–37; 路加福音 21:5–36; Ezekiel 8:6"> 耶稣出了圣殿，门徒走上前骄傲地把圣殿建筑指给他看。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 19:44; Jeremiah 26:18; Micah 3:12"> 他对门徒说：“你们看这些建筑？告诉你们实话，未来这里将没有一块石头留下，所有的石头都将崩塌。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马可福音 13:3–4; 使徒行传 1:7; 帖撒罗尼迦前书 5:1–11"> 耶稣坐在橄榄山上，门徒暗中前来询问：“请告诉我们，何时会出现此事？你的降临和这个世界的终结，会有什么预兆？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰一书 4:1; Jeremiah 29:8; 帖撒罗尼迦后书 2:3"> 耶稣回答他们：“你们要小心，不要被人迷惑。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 24:11; 马太福音 24:24; Jeremiah 14:14"> 因为许多人会假冒我之名而来，说他就是基督，借此迷惑众人。</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 13:7–8; 路加福音 21:9; 彼得前书 3:14–15"> 你们将听见战争，还有关于战争的传言。要小心，但不要惊慌，因为这避免不了，但不是最终结局。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 21:11; 启示录 6:8; Isaiah 19:2"> 一个民族要攻打另一个民族，一个国家要攻打另一个国家，处处都是饥荒和地震，</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦前书 5:3; 彼得前书 4:17–18; Deuteronomy 28:59"> 这一切不过是诞生之痛的开始。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约翰福音 16:2; 约翰福音 15:19–20; 路加福音 21:16–17"> 然后人们会抓住你们，折磨你们，杀害你们，你们要因我的名而被万民痛恨。</span>
<span className="v" id="v10" data-v="10" data-xref="Micah 7:5–6; 路加福音 21:16; 马太福音 11:6"> 届时会有许多人会失去信仰，彼此出卖，互相恨恶。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 24:24; 马太福音 7:15; 马太福音 24:5"> 也有许多假先知出现，迷惑众人。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 2:4–5; 雅各书 4:1–4; 启示录 3:15"> 越来越多的邪恶出现，将人们的爱冷却，</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 10:22; 马可福音 13:13; 启示录 2:10"> 唯有忍耐到底者方可得救。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 14:6; 罗马书 10:18; 罗马书 16:25–26"> 这王国的福音要传遍天下，向万民听到，然后最终结局才会来到。</span>
<span className="v" id="v15" data-v="15" data-xref="Daniel 9:27; Daniel 12:11; 马可福音 13:14"> 当你们看见那‘污秽的偶像崇拜’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意“荒凉的亵渎”，见《但以理书》9:27，《但以理书》11:31，《但以理书》12:11。">a</a></sup>站在但以理先知所说圣地（读至此处应认真思考），</span>
<span className="v" id="v16" data-v="16" data-xref="Genesis 19:15–17; 路加福音 21:21–22; 希伯来书 11:7"> 那时，住在犹太的应当逃到山上，</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 17:31–33; 马可福音 13:15–16; 马太福音 10:27"> 站在房顶之人，不要下来拿家里的东西，</span>
<span className="v" id="v18" data-v="18"> 在田里的也不要回去取衣服。</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 23:29–30; Deuteronomy 28:53–56; 路加福音 21:23"> 在那样的日子，对于怀孕的和哺乳孩子的母亲极为可怕！</span>
<span className="v" id="v20" data-v="20" data-xref="Exodus 16:29; 使徒行传 1:12"> 你们应当祈求，不要在冬季或安息日的时候逃难，</span>
<span className="v" id="v21" data-v="21" data-xref="Daniel 12:1; Joel 2:2; Malachi 4:1"> 因为那时必有大灾难，这是从世界的开始到现在未曾有过的，以后也必不会再有。</span>
<span className="v" id="v22" data-v="22" data-xref="马可福音 13:20; 提摩太后书 2:10; 马太福音 24:31"> 除非那样的日子变短，否则无人可以存活，但是为了天选之人，那些日子必会变短。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 21:8; 路加福音 17:23–24; Deuteronomy 13:1–3"> 届时，如果有人对你们说：‘看，基督在这里！’或说：‘他在那里！’你们不要信，</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦后书 2:9–11; 马可福音 13:22; 启示录 13:13–14"> 因为必有假弥赛亚和假先知出现，做出看似了不起的上帝神迹和奇事。如果可以，他们连天选之民也要迷惑。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 16:1; 路加福音 21:13; Isaiah 48:5–6"> 你们看！我已经提前告诉你们了。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 3:2–3; Isaiah 40:3; 马太福音 3:1"> 如果他们对你们说：‘看！基督在荒野里。’你们不要出去；或说：‘看！他已悄悄降临。’也不要相信。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 17:24–37; Zechariah 9:14; Job 37:3"> 似电光从东方闪出来，一直照到西方，人子降临之时也是如此。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 17:37; Job 39:27–30; Deuteronomy 28:49"> ‘有尸身之处，必有秃鹫也聚于此’。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="Amos 8:9; Joel 3:15; Isaiah 13:10"> 当灾难刚刚过去，太阳黯然，月亮也不发光，众星从天坠落，天上万象震动。</span>
<span className="v" id="v30" data-v="30" data-xref="启示录 1:7; Daniel 7:13; 路加福音 21:27"> 届时，人子的征兆就显在天上，地上的万族都要哀号，看见人子展示能力，载满荣耀，驾天上之云降临。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="见《但以理书》7:13-14。">b</a></sup></span>
<span className="v" id="v31" data-v="31" data-xref="帖撒罗尼迦前书 4:16; 马可福音 13:27; Isaiah 27:13"> 当号角发出响声，他要差派天使，把他的选民从四方、从天和地的各处招聚而来。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“从四方之风，从天尽头到另一端。”">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马可福音 13:28–29; 路加福音 21:29–30"> 这里有一个无花果树的比喻：树枝长出嫩芽生出叶子之时，你们便知道夏天将近。</span>
<span className="v" id="v33" data-v="33" data-xref="雅各书 5:9; 希伯来书 10:37; Ezekiel 7:2–14"> 同样，当你们看见这一切，就知道人子将要降临你们中间。</span>
<span className="v" id="v34" data-v="34" data-xref="马可福音 13:30–31; 路加福音 21:32–33; 马太福音 16:28"> 实话告诉你们，这一切必要发生，然后这世界才会过去。</span>
<span className="v" id="v35" data-v="35" data-xref="Isaiah 40:8; 彼得前书 1:25; Numbers 23:19"> 天地都要过去，但我的言语决不会消失。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="马可福音 13:32; 使徒行传 1:7; 马太福音 24:44"> 至于具体的日期和时间，无人知晓，连天上的使者和人子也不知情，只有天父知道。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 17:26–27; Genesis 6:1–7; 彼得后书 2:5"> 诺亚时代的样子，即是人子降临时刻的样子。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 17:26–28; 罗马书 13:13–14; 路加福音 14:18–20"> 洪水之前的时代，人们吃喝嫁娶，直到诺亚进入方舟的那一天。</span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 3:20; 马太福音 24:37; 使徒行传 13:41"> 他们不知道会发生什么事，直到洪水来了，把他们全都冲走了。人子降临之时也将是这样。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="路加福音 17:34–37; 彼得后书 2:7–9; 彼得后书 2:5"> 届时，有两人在田里工作，一个被带走，一个被留下。</span>
<span className="v" id="v41" data-v="41" data-xref="Exodus 11:5; Isaiah 47:2; 路加福音 17:35"> 两个女人在磨坊推磨，一人被带走，一人被留下。</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 21:36; 帖撒罗尼迦前书 5:6; 马太福音 25:13"> 因此你们要警惕，因为不知道你们的主何时会来。</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 12:39; 马太福音 24:44; 帖撒罗尼迦前书 5:2–6"> 但想想：家主若晓得窃贼晚上何时会来，自会提高警觉，不让窃贼闯入偷盗。</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 25:10; 马太福音 24:42; 马太福音 25:13"> 所以你们也要准备妥当，因为人子会在想不到日子到来。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="马太福音 25:21; 马太福音 25:23; 哥林多前书 4:1–2"> 谁是忠心和考量周全的仆人？那就是被主人指派管理全家、按时分派粮食的仆人。</span>
<span className="v" id="v46" data-v="46" data-xref="启示录 16:15; 路加福音 12:43; 路加福音 12:37"> 主人来到时如果看到他照做，那仆人就有福了。</span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 25:23; 马太福音 25:21; 路加福音 12:37"> 告诉你们实话，主人将指派他管理自己的一切财产。</span>
<span className="v" id="v48" data-v="48" data-xref="马太福音 18:32; Isaiah 32:6; 路加福音 12:45"> 如果他是个恶意仆人，心中暗想：‘我的主人不会那么快回来’，</span>
<span className="v" id="v49" data-v="49" data-xref="启示录 17:6; 启示录 16:6; Micah 3:5"> 于是就会动手打其他仆人，与醉汉们大吃大喝。</span>
<span className="v" id="v50" data-v="50" data-xref="帖撒罗尼迦前书 5:2–3; 启示录 3:3; 马太福音 24:42–44"> 但在他没有想到的日期和时辰，仆人的主人回来了，</span>
<span className="v" id="v51" data-v="51" data-xref="马太福音 8:12; 马太福音 22:13; 路加福音 12:46"> 他被严厉处罚，一如对待其他虚伪之人<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="那些声称跟随主却并未做到之人。">d</a></sup>那样被送到一个地方，那里必有哀哭切齿。</span>
</div>
</div>

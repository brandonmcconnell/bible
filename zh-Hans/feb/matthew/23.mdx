<span className="v" id="v1" data-v="1" data-xref="路加福音 12:1; 路加福音 20:45–46; 马太福音 15:10–20"> 然后，耶稣对民众和门徒说：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 20:46; 马可福音 12:38; Malachi 2:7"> “宗教老师和法利赛人负责解读摩西的律法，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“坐在摩西的座位上。”">a</a></sup></span>
<span className="v" id="v3" data-v="3" data-xref="提摩太后书 3:5; 提多书 1:16; 罗马书 2:19–24"> 凡他们吩咐你们所做之事，你们都要遵行和谨守，但不可效法他们的行为，因为他们不会实践所宣扬的事情。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 11:46; 使徒行传 15:10; 加拉太书 6:13"> 他们把重担捆起来，压在人的肩头，但自己却一个指头也不肯动。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 6:1–16; 约翰福音 12:43; 腓立比书 2:3"> 他们所做的一切都只是做给人看，把经文的匣子做大<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或装经文的盒子。这种用皮革做的盒子可以绑在额头和手臂上，里面放着书写的经文：《出埃及记》13:1-6和《申命记》6:4-9；《申命记》11:13-21。">b</a></sup>，把他们衣服的流苏做长，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="这些流苏是为了体现他们对上帝的虔诚。见《民数记》15:37-41。">c</a></sup></span>
<span className="v" id="v6" data-v="6" data-xref="约翰三书 1:9; 路加福音 11:43–54; 马可福音 12:38–39"> 他们喜欢筵席上的首位、会堂里的高位，</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 1:38; 约翰福音 1:49; 约翰福音 3:26"> 他们喜欢民众在市场向他们问安，称呼他们为‘拉比’<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="这是希伯来语单词，意为“伟大的人”，被用做尊重宗教老师。">d</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="雅各书 3:1; 哥林多前书 1:12–13; 彼得前书 5:3"> 然而不要让人们称你为‘拉比’，因为只有一人是你们的老师，其他人都是兄弟。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 3:1; 希伯来书 12:9; Malachi 1:6"> 不要称呼世上之人为父，因为只有一位为你们之父，就是天父。</span>
<span className="v" id="v10" data-v="10"> 也不要让人们称你为老师，因为只有一位是你们之师，那就是弥赛亚。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 9:19; 加拉太书 5:13; 约翰福音 13:14–15"> 你们中间最伟大之人，必做你们的仆人。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 5:5; 雅各书 4:6; Proverbs 29:23"> 凡自称伟大的人，必被看轻，凡自己谦卑者，必被称为伟大。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 11:52; 马太福音 23:29; 马太福音 23:23"> 虚伪的宗教老师和法利赛人呐，你们即将面临灾祸！你们在人面前关了天国之门，自己不进去，还拦着想要进去之人。</span>
<span className="v" id="v14" data-v="14"> <sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="在最权威的早期手抄本中并无第 14 句。">e</a></sup></span>
<span className="v" id="v15" data-v="15" data-xref="以弗所书 2:3; 使徒行传 13:10; 使徒行传 13:43"> 虚伪的宗教老师和法利赛人呐，你们即将面临灾祸！你们走遍海洋陆地，只为让人入教。但当其他人入了教，你们却使他沦为哥和拿之子，比你们有过之而不及。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 15:14; 马太福音 5:33–35; 雅各书 5:12"> 你们说：‘凡指着圣殿起誓，皆无用处，凡指着圣殿的金子起誓，必须遵守。’这样说多么愚蠢，你们就是盲人啊！</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 23:19; Numbers 16:38–39; Psalms 94:8"> 你们这些盲目的愚昧人，到底是金子伟大，还是赋予黄金神圣地位的圣殿伟大？</span>
<span className="v" id="v18" data-v="18"> 你们又说：‘凡指着祭坛起誓，皆无用处，但指着坛上的祭物起誓，必须遵守。’</span>
<span className="v" id="v19" data-v="19" data-xref="Exodus 29:37; Exodus 30:29"> 盲目之人呐！到底是祭物伟大，还是赋予祭物上帝圣的祭坛伟大？</span>
<span className="v" id="v20" data-v="20"> 所以，凡指着祭坛起誓，他就是指着祭坛和其上的一切起誓；</span>
<span className="v" id="v21" data-v="21" data-xref="Psalms 26:8; 1 Kings 8:13; 2 Chronicles 6:2"> 指着圣殿起誓，就是指着圣殿和住在里面的上帝起誓；</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 5:34; Psalms 11:4; Isaiah 66:1"> 指天起誓，就是指着上帝宝座和宝座上的上帝起誓。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 11:42; Micah 6:8; Hosea 6:6"> 虚伪的宗教老师和法利赛人呐，你们即将面临灾祸！你们把十分之一的薄荷、茴香和孜然献祭，却忽略律法上更重要的内容：正义、怜悯和信任。固然献出十分之一的财富很重要，但你们忘记了其他事情。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 19:24; 马太福音 27:6–8; 马太福音 15:2–6"> 你们这些盲目的向导，你们滤掉了水中的蚊虫，却把骆驼吞下去。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 11:39–40; 马太福音 15:19–20; 马可福音 7:4–13"> 虚伪的宗教老师和法利赛人呐，你们即将面临灾祸！你们清洗了杯子和盘子的外在，内在却满是贪婪和自我放纵。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多后书 7:1; 雅各书 4:8; 希伯来书 10:22"> 瞎眼的法利赛人呐，先把杯和盘的里面洗净，才能让外面也干净。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 11:44; 使徒行传 23:3; Numbers 19:16"> 虚伪的宗教老师和法利赛人呐，你们即将面临灾祸！你们就是这样，<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="原意为“不清洁。”">f</a></sup></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 16:15; Psalms 51:6; 马太福音 23:5"> 外表看来像正人君子，内在却充满虚伪和邪恶。</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 11:47–48; 使徒行传 2:29"> 虚伪的宗教老师和法利赛人呐，你们即将面临灾祸！你建造坟墓纪念先知，装饰漂亮的坟墓。</span>
<span className="v" id="v30" data-v="30" data-xref="Jeremiah 2:30; 马太福音 23:34–35; 马太福音 21:35–36"> 你们说：‘我们若活在祖先的时代，决不会和先知一样流血。’</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 7:51–52; 帖撒罗尼迦前书 2:15–16; Joshua 24:22"> 但这样说，你们就是指证自己就是杀害先知之人的子孙。</span>
<span className="v" id="v32" data-v="32" data-xref="Genesis 15:16; Numbers 32:14; 帖撒罗尼迦前书 2:16"> 那么，用你们祖先的方法完成这一切吧！</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 3:7; 马太福音 12:34; 马太福音 5:22"> 你们就是蛇，就是毒蛇所生，你们怎能逃脱定罪的审判呢？<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="“哥和拿” (见5:22)。即末世审判。">g</a></sup></span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 10:16–17; 马太福音 13:52; 歌罗西书 1:28"> 我派先知、智慧人和宗教老师到你们那里，但有的你们要杀害，钉在十字架上，有的你们要在会堂里鞭打，从这城追到那城。</span>
<span className="v" id="v35" data-v="35" data-xref="2 Chronicles 24:20–22; Zechariah 1:1; 希伯来书 11:4"> 所有义人流在地上的血， 从义人亚伯到你们在圣殿和祭坛之间所杀的巴拉加的儿子赛迦利亚，都归到你们身上。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 10:23; 马太福音 24:34; 马可福音 13:30–31"> 告诉你们吧，这一切的后果必落在这代人的身上。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 13:34–35; Ruth 2:12; Psalms 91:4"> 耶路撒冷啊，耶路撒冷，你们杀害先知，又用石头把派过去的人杀害。我屡次想招聚你的民众，如母鸡将小鸡招到翅膀下，只是你们不愿意。</span>
<span className="v" id="v38" data-v="38" data-xref="Jeremiah 22:5; 路加福音 13:35; 路加福音 21:24"> 你看，你们的家<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="原文意为“房屋”，可能是指圣殿。">h</a></sup>必成为一片荒芜，彻底空荡荡。</span>
<span className="v" id="v39" data-v="39" data-xref="Psalms 118:26; 马太福音 21:9; 罗马书 11:25"> 我告诉你们，从今后你们一定见不到我，直到那一天你们说：‘愿上帝保佑那位以主的名义来的。’”<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="引自《诗篇》118:26。">i</a></sup></span>
</div>

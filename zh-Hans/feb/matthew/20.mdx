<span className="v" id="v1" data-v="1" data-xref="马太福音 13:47; 马太福音 13:24; Song of Solomon 8:11–12"> 天国如一位家主，清早出去雇请工人到他的葡萄园工作。</span>
<span className="v" id="v2" data-v="2" data-xref="1 Samuel 2:26; Ecclesiastes 12:1; 马太福音 22:19"> 他和工人说定一天的工钱是一个银币，然后派他们去葡萄园。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前书 5:13; 使徒行传 2:15; 马太福音 20:6–7"> 大约九点钟，他又出门看见还有人闲站在街市上。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 6:11; 彼得前书 4:2–3; 路加福音 19:7–10"> 于是就对他们说：‘你们也到葡萄园来吧，我会给你们合理的工钱。’</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 11:24–26; 使徒行传 10:3; 马可福音 15:33–34"> 于是他们便去工作了。大概在正午和下午三点钟，他又出门做同样的事。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 6:12; 约翰福音 9:4; 使徒行传 17:21"> 下午五点钟左右，他再出去，看见还有人站着，就问他们：‘你们为什么整天站在这里不去工作？’</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 2:11–12; 希伯来书 6:10; 约翰福音 9:4"> 他们回答：‘没有人用我们。’他说：‘你们也到葡萄园来吧。’</span>
<span className="v" id="v8" data-v="8" data-xref="Deuteronomy 24:15; 彼得前书 4:10; 罗马书 2:6–10"> 到了黄昏，葡萄园主对工头说：‘把工人都叫来，给他们工钱，从最后来的开始，最先来的排在最后。’</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 20:6–7; 路加福音 23:40–43; 马太福音 20:2"> 那些下午五点钟才开始做工的人来了，每个人都领到一个银币。</span>
<span className="v" id="v10" data-v="10"> 最先做工的人也来了，以为会多得一点，但每个人都领到一个银币。</span>
<span className="v" id="v11" data-v="11" data-xref="帖撒罗尼迦前书 2:16; 路加福音 19:7; 使徒行传 22:21–22"> 于是他们就埋怨家主，说：</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 11:5–6; 哥林多后书 11:23–28; 路加福音 12:55"> ‘我们一整天都在烈日之下劳作，这些后来人只工作了一个小时，却得到跟我们一样的工钱。’</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 26:50; 马太福音 22:12; 罗马书 9:14–15"> 家主回答他们说：‘朋友，我并没有亏待你。你我不是讲定了一个银币吗？</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 17:2; 路加福音 15:31; 马太福音 6:6"> 拿你的工钱走吧！我给后来人的报酬和你们一样，我想这样做。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 9:15–24; Deuteronomy 15:9; Jonah 4:1–4"> 难道我不可以照自己的想法使用我的财物吗？还是因为我想做善事，你就不高兴呢？’</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 19:30; 马可福音 10:31; 马太福音 22:14"> 因此，先来者将在后，在后者将在前。”</span>
<span className="v" id="v17" data-v="17" data-xref="马可福音 10:32–34; 路加福音 18:31–34; 马太福音 16:13"> 耶稣去耶路撒冷的途中，把十二门徒带到一边，一边走一边说：</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 16:21; 使徒行传 2:23; 马太福音 27:1"> “我们现在要去耶路撒冷，人子要被交给祭司长和宗教老师，他们会定他死罪，</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 16:21; 马可福音 15:16–20; 马太福音 27:27–31"> 把他交给异教徒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这里指罗马人。">a</a></sup>凌辱鞭打，钉在十字架上。但他第三天就会复活。”</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 4:21; 马可福音 10:35–45; 马太福音 8:2"> 这时，西庇太之子的母亲带着她的两个儿子前来见耶稣，跪在耶稣面前求他。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 19:28; 马可福音 10:36–37; Esther 5:3"> 耶稣问她：“你想要什么？”她说：“求你下令，让我这两个儿子进入你的王国，一个坐在你的右边，一个坐在你的左边。”</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 26:42; 路加福音 22:42; 马太福音 26:39"> 耶稣回答：“你们知道自己在求什么吗？我将要喝的东西<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这里指痛苦。">b</a></sup>，你们能喝吗？”他们回答：“能，我们能喝。”</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 1:9; 马太福音 25:34; 使徒行传 12:2"> 他对他们说：“你们当然会喝我所喝之物，但坐在我左右的权利并非我所能赐予，我父决定赐给谁，就赐给谁。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或“那位置只留给我父准备之人。”">c</a></sup>”</span>
<span className="v" id="v24" data-v="24" data-xref="彼得前书 5:5; 腓立比书 2:3; 马可福音 10:41"> 其他十个门徒听见了，对这兄弟二人很恼怒。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 22:25–27; 马太福音 20:25–28; 约翰福音 13:12–17"> 耶稣把他们叫过来，说：“你们知道各国都有统治者管制，有强大领袖管辖。</span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 10:43; 马可福音 9:35; 马可福音 10:45"> 但你们不会如此。谁想在你们中间成为统治者，就会成为你们的奴仆。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 22:26; 马可福音 9:33–35; 马太福音 18:4"> 谁想在你们中间为首，就会变成奴隶。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 22:27; 希伯来书 9:28; 提多书 2:14"> 正如人子来，并非为了被他人服侍，而是为了服侍他人，以自己的生命，来赎众人之命。”</span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 10:46–52; 路加福音 18:35–43; 马太福音 9:27–31"> 他们离开耶利哥的时候，许多人跟着耶稣。</span>
<span className="v" id="v30" data-v="30" data-xref="马可福音 10:46; Isaiah 42:16; 马太福音 21:9"> 有两个盲人坐在路旁，听说耶稣经过就喊叫：“主啊，大卫的子孙，可怜一下我们吧！”</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 19:13; 歌罗西书 4:2; 马太福音 7:7–8"> 民众告诉他们不要出声，他们却愈加放声喊叫：“主啊，大卫的子孙，可怜我们吧！”</span>
<span className="v" id="v32" data-v="32" data-xref="Ezekiel 36:37; 腓立比书 4:6; 马太福音 20:21"> 耶稣站住，叫他们过来，说：“要我为你们做什么呢？”</span>
<span className="v" id="v33" data-v="33" data-xref="Psalms 119:18; 以弗所书 1:17–19"> 他们说：“主啊，求你让我们看见。”</span>
<span className="v" id="v34" data-v="34" data-xref="希伯来书 4:15–16; 马太福音 9:29; 使徒行传 26:18"> 耶稣怜悯他们，触摸他们的眼睛后，他们立刻看到，于是开始跟随耶稣。</span>

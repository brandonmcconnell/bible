<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 6:37; 罗马书 2:1–2; 雅各书 4:11–12"> “不可判断其他人，否则你也会被判断。</span>
<span className="v" id="v2" data-v="2" data-xref="雅各书 2:13; 马可福音 4:24; 路加福音 6:38"> 你们论断其他人的标准，其他人就会用这标准论断你，你们用什么标准衡量他人，他人也必同样衡量你。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 8:7–9; 加拉太书 6:1; 路加福音 6:41–42"> 为什么你只看到兄弟眼中的木屑，却不理会自己眼中的梁木？</span>
<span className="v" id="v4" data-v="4"> 若你自己眼中有梁木，怎能对兄弟说：‘让我除掉你眼中的木屑’呢？</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 6:42; Psalms 51:9–13; 马太福音 23:13–28"> 这就是伪君子的行为！要先拿走你眼中的梁木，才能看清楚，才有资格除掉兄弟眼中的木屑。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="Proverbs 9:7–8; Proverbs 23:9; 马太福音 10:14–15"> 不要把圣物丢给狗，也不要把你们的珍珠丢给猪，这样猪就不会将其践踏，狗就不会转过来攻击你们。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 21:22; 约翰一书 3:22; 约翰福音 15:7"> 如果你求，自会给你； 如果你寻找，就会找到； 如果你敲门，门就会为你打开。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原为“急需解决”的意思，可作为“继续提问”理解。">a</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="Psalms 81:10; Psalms 81:16; 路加福音 23:42–43"> 因为凡祈求必得到，寻找必寻见，敲门必开门。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 11:11–13"> 如果你的儿子向你要饼，你会给他石头吗？</span>
<span className="v" id="v10" data-v="10"> 如果他要鱼，你会给他蛇吗？</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 11:11–13; 雅各书 1:17; 罗马书 8:32"> 即使你们中的邪恶之人，尚且知道把好东西送给儿女，何况你们的天父，自然更会把好东西赐给祈求之人。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="路加福音 6:31; 罗马书 13:8–10; 加拉太书 5:13–14"> 所以，在对待其他人时，要用你希望他们对待你的方式，这就是律法和先知们的律法。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 13:24–25; Proverbs 16:25; 约翰福音 14:6"> 进入必经窄门，只有通往灭亡之门才会大敞大开，道路宽阔，那是很多人都会走的路。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 13:23–30; 马太福音 22:14; 马太福音 16:24–25"> 但通往生命之门狭窄，道路难行，那是寥寥几人会走的路。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰一书 4:1; 彼得后书 2:1–3; 马太福音 24:11"> 小心假先知！他们披着羊皮出现，内心却是残暴的狼。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 6:43–45; 马太福音 12:33; 雅各书 3:12"> 通过果实<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="换言之，可以通过其行为之“果”判断一个人。">b</a></sup>就可以辨认它们：荆棘中如何摘到葡萄？蒺藜中如何看到无花果？</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 12:33–35; 加拉太书 5:22–24; 以弗所书 5:9"> 所以，好树结好果，坏树结坏果；</span>
<span className="v" id="v18" data-v="18" data-xref="加拉太书 5:17; 约翰一书 3:9–10"> 好树不能结坏果，坏树也不能结好果。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 3:10; 希伯来书 6:8; 约翰福音 15:2–6"> 不结好果之树，必会被砍下丢在火中。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 7:16; 使徒行传 5:38"> 因此你们凭其果子就可以认出他们来。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="罗马书 2:13; 路加福音 6:46; 雅各书 1:22"> 不是每个人喊我‘主啊，主啊！’，就都能进入天国，唯有遵行天父圣意，才能进入。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 13:25–27; 哥林多前书 13:1–2; Malachi 3:17–18"> 到审判日那天，必有许多人对我说：‘主啊，主啊，难道我们没有以你的名预言，以你的名驱赶魔鬼，以你的名行神迹？’</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 25:41; Psalms 6:8; 路加福音 13:25"> 但我会告诉他们：我从来不认识你们，你们这些作恶之人，走开吧！<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="见《诗篇》6:8。">c</a></sup></span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 6:47–49; 约翰福音 13:17; 哥林多前书 3:10–11"> 所以，凡听见我的话并遵行之人，才是聪明之人，他们会在结实的岩石上修建房屋。</span>
<span className="v" id="v25" data-v="25" data-xref="雅各书 1:12; Psalms 125:1–2; 彼得前书 1:7"> 无论是倾盆大雨、大水泛滥、狂风呼啸，这房屋都不会倒塌，因为它稳稳修在结实的岩石之上。</span>
<span className="v" id="v26" data-v="26" data-xref="Jeremiah 8:9; 路加福音 6:49; 雅各书 2:20"> 凡听我这番言语却不遵行，就如将房屋盖在沙土上的愚人。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 13:19–22; 彼得后书 2:20–22; 哥林多前书 3:13"> 雨淋、水冲和风吹会摇撼他们的房屋，房子会倒塌，而且很彻底。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 4:32; 马可福音 1:22; 约翰福音 7:46"> 耶稣讲完这番话，民众都惊奇他的训诫。</span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 4:12–13; 路加福音 20:8; Deuteronomy 18:18–19"> 因为耶稣教导他们的样子更像权威之人，而非他们熟悉的宗教老师。</span>
</div>

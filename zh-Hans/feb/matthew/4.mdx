<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 2:18; 路加福音 4:1–13; 马可福音 1:12–15"> 随后，圣灵引领耶稣来到荒野，接受魔鬼的试探。</span>
<span className="v" id="v2" data-v="2" data-xref="Deuteronomy 9:18; Exodus 34:28; 1 Kings 19:8"> 耶稣禁食四十昼夜，感到了饥饿。</span>
<span className="v" id="v3" data-v="3" data-xref="Genesis 3:1–5; 帖撒罗尼迦前书 3:5; Numbers 11:4–6"> 魔鬼便出现在他面前，诱惑他：“如果你真的是上帝之子，那就把这些石头变成食物吧。”</span>
<span className="v" id="v4" data-v="4" data-xref="Deuteronomy 8:3; 路加福音 4:4; 约翰福音 6:63"> 耶稣答道：“经书中写道：‘人活着并不只靠食物，更要依靠上帝所说的字字句句。’”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《申命记》8:3。">a</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 4:9; 马太福音 27:53; 启示录 11:2"> 随后，魔鬼带着耶稣走进圣城<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="即耶路撒冷。">b</a></sup>，让他站在圣殿的最高处。</span>
<span className="v" id="v6" data-v="6" data-xref="Psalms 91:11–12; 希伯来书 1:14; Psalms 34:7"> 魔鬼对耶稣说：“你若是上帝之子，就从这里跳下去证明！因为经书中写道：上帝会命令天使拯救你，不受伤害。他们会托住你，免得你被石头绊倒。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《诗篇》91:11-12。">c</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="Deuteronomy 6:16; 哥林多前书 10:9; Psalms 78:18"> 耶稣回答：“那经书也写着：不可试探吾主上帝。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《申命记》6:16。">d</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="约翰一书 2:15–16; 启示录 11:15; Psalms 49:16–17"> 然后，魔鬼带耶稣站上一座高山，向他展示世上所有王国的荣华。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 4:4; Daniel 5:18–19; 约翰福音 16:11"> 魔鬼说：“只要俯首拜我，我就把这一切送给你。”</span>
<span className="v" id="v10" data-v="10" data-xref="Deuteronomy 6:13–14; Deuteronomy 10:20; Joshua 24:14"> “走开吧，撒旦！”耶稣道：“经书说：你只应拜吾主上帝，只侍奉他。”<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="引自《申命记》6:13。">e</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 26:53; 希伯来书 1:14; 路加福音 22:43"> 魔鬼于是离开了，天使出现，看护耶稣。</span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 1:14; 路加福音 3:20; 马太福音 14:3"> 当耶稣听闻约翰被捕，便返回加利利。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 4:46; 马可福音 1:21; 马太福音 11:23"> 他离开拿撒勒，来自海边的迦百农并住下。这里位于西布伦和拿弗他利境内。</span>
<span className="v" id="v14" data-v="14" data-xref="Isaiah 9:1–2; 马太福音 2:23; 路加福音 24:44"> 这应验了以赛亚先知所述：</span>
<span className="v" id="v15" data-v="15" data-xref="Isaiah 9:1; 2 Kings 15:29; Joshua 21:32"> “在西布伦地和拿弗他利之地，沿着海滨之路穿越约旦河，那就是异教徒所居的加利利！</span>
<span className="v" id="v16" data-v="16" data-xref="Isaiah 9:2; Isaiah 42:6–7; Isaiah 60:1–3"> 那里身处黑暗中的人民，看见了一道伟大之光；那黎明之光，照耀于被困在死亡幽暗之地的人民。”<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="引自《以赛亚书》9:1-2。">f</a></sup></span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 3:2; 使徒行传 2:38; 马可福音 1:14–15"> 从那时起，耶稣开始传递上帝的讯息。他说：“悔改吧，因为天国已降临。”</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 1:40–42; 马太福音 10:2; 路加福音 6:14"> 当耶稣走在加利利海边时，看见兄弟二人：西门（即彼得）和他的弟弟安得烈。他们是渔夫，正在向海中撒网。</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 1:17–18; 约翰福音 12:26; 马太福音 16:24"> 耶稣对他们说：“来跟随我吧，让我教你们如何捕捞人类。”</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 10:28–31; 马太福音 19:27; 路加福音 18:28–30"> 他们立刻撇下网，跟从耶稣而去。</span>
<span className="v" id="v21" data-v="21" data-xref="马可福音 1:19–20; 马太福音 10:2; 马可福音 3:17"> 耶稣继续向前，看见另一对兄弟：雅各和他的兄弟约翰。他们正和父亲西庇太一起，在船上整理鱼网。于是耶稣便召唤他们。<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="隐喻为“成为他的门徒。”">g</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 10:37; 路加福音 9:59–60; Deuteronomy 33:9–10"> 兄弟二人立刻告别父亲，离开船跟随耶稣。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 9:35; 马可福音 1:39; 使徒行传 10:38"> 耶稣走遍加利利，在各地的会堂中教导民众，宣讲天国的福音，治愈人们患有的所有疾病。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 8:6; 马太福音 17:15; 路加福音 5:15"> 他的名声传遍叙利亚省各地，<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="加利利北方地区。">h</a></sup>于是人们将所有患者都带到他身边。无论是癫痫、魔鬼附体、精神疾病或者瘫痪，耶稣都能让他们痊愈。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 6:17; 马可福音 5:20; 马可福音 3:7–8"> 于是有大批民众从加利利、低加波利、耶路撒冷、犹太和约旦河东赶来，跟随耶稣。</span>
</div>

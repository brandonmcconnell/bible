<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Isaiah 61:1–3; 使徒行传 10:38; 路加福音 8:1"> 耶稣吩咐完十二门徒后就离开了，到附近各城教导传道。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 6:17; 马太福音 14:3; 马太福音 9:14"> 约翰被关在监牢中时，听到基督所做之事，便派他的门徒</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 11:27; Malachi 3:1; Deuteronomy 18:15–18"> 以他的名义去询问耶稣：“你是我们期盼到来之人吗？还是我们必须继续寻找其他人？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 耶稣回答：“你们回去吧，把听见和看见的都告诉约翰，</span>
<span className="v" id="v5" data-v="5" data-xref="Isaiah 35:4–6; Isaiah 61:1–3; 路加福音 4:18"> 盲者可见，瘸者可行，麻风患者治愈，聋者可以听见，亡者复活，贫苦者听到福音。</span>
<span className="v" id="v6" data-v="6" data-xref="Isaiah 8:14–15; 哥林多前书 2:14; 马太福音 26:31"> 不拒绝我者，必被祝福。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="雅各书 1:6; 约翰福音 5:35; 马可福音 1:3–5"> 他们继续前行，耶稣对众人讲起约翰。他说：“在荒野中时，你会期待什么？被风吹动的芦苇吗？</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 3:4; 2 Kings 1:8; Zechariah 13:4"> 你们到底想要看什么？身穿华服之人吗？衣着就像王宫中居住的人一样吗？</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 1:76; 马太福音 14:5; 马太福音 21:24–26"> 那么，你们到那里想要看什么？先知吗？是的，但我要告诉你，他不只是一名先知。</span>
<span className="v" id="v10" data-v="10" data-xref="Malachi 3:1; Isaiah 40:3; Malachi 4:5"> 他便是经文中所写那人：‘我差遣使者到你前面，为你备好你的道路。’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《玛拉基书》3:1。">a</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 7:28; 以弗所书 3:8; 马太福音 3:11"> 告诉你们实话，在人类<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“那些由女性诞下之人。”">b</a></sup>世界中，任何人都不如施洗者约翰伟大，但在天国中，他却是最微不足道的那一个。</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 16:16; 路加福音 13:24; 以弗所书 6:11–13"> 从施洗约翰之时到现在，天国不断遭受猛烈攻击，暴徒企图以武力将其占为己有。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 5:17–18; 罗马书 3:21; 使徒行传 13:27"> 因为在约翰到来之前，所有的先知和律法<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="即《旧约》所述讯息。">c</a></sup>都在讲述上帝之道。</span>
<span className="v" id="v14" data-v="14" data-xref="Malachi 4:5; 马太福音 17:10–13; 马可福音 9:11–13"> 如果你们准备好相信，那么约翰就是你们应该期待的以利亚。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="见《玛拉基书》4:5。">d</a></sup></span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 8:8; 马太福音 13:9; 马可福音 4:23"> 如果你有耳朵，就要去听。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 7:31–35; 马太福音 12:34; 马太福音 23:36"> 我该把这代人比作什么？它就像小孩子坐在市场中，喊着彼此的名字说：</span>
<span className="v" id="v17" data-v="17" data-xref="Isaiah 28:9–13; Isaiah 30:29; Jeremiah 9:17–20"> ‘我们给你们吹笛子，你们却不跳舞，我们唱哀歌，你们也不哭泣。’</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 1:15; 马太福音 3:4; 约翰福音 10:20"> 约翰前来，禁食禁水，人们说‘他是鬼附体！’</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 9:10–11; 路加福音 15:1–2; 路加福音 19:7"> 另一方面，人子确实来了，并且吃了喝了，人们却说：‘你看，这人贪食好酒，与税吏和罪人为友。’但通过他的行为，显示出智慧即为正道。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:13–15; Jeremiah 8:6; 提摩太后书 2:25–26"> 随后，耶稣开始批判他曾行过大多数上帝神迹的城，因为那里的人不肯悔改。</span>
<span className="v" id="v21" data-v="21" data-xref="Ezekiel 3:6–7; 使徒行传 12:20; 路加福音 9:10"> “哥拉逊啊，你应感到羞愧！伯赛大啊，你应感到羞愧！在你们那里所行上帝神迹，如果出现在推罗和西顿，城中之人早已披麻蒙灰，想要悔改。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 11:24; 马太福音 10:15; 希伯来书 10:26–31"> 但告诉你吧，在审判日那天，推罗和西顿的情况会比你们更好。</span>
<span className="v" id="v23" data-v="23" data-xref="Isaiah 14:13–15; 约翰福音 4:46–54; Genesis 13:13"> 至于迦百农，你们会升入天堂吗？不，你们必会跌入冥府。在你们那里行过的上帝神迹，如果行在 索多玛，那座城还会存留到今天。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 10:15; 马太福音 11:22; 马可福音 6:11"> 但我告诉你们，在审判日那天，索多那城所受的惩罚可比你们轻。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马太福音 21:16; Psalms 8:2; 马太福音 16:17"> 然后耶稣祈祷：“天父啊，天地之主，我赞美你，因你向智慧和聪明之人隐藏了这一切，却向普罗大众显明。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原意为“婴儿。”">e</a></sup></span>
<span className="v" id="v26" data-v="26" data-xref="提摩太后书 1:9; 以弗所书 1:11; Job 33:13"> 天父啊，是的，这样做让你欢喜。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 14:6–9; 马太福音 28:18; 路加福音 10:22"> 天父已将这一切交给我，只有天父理解其子，只有天父之子及其选择进行启示之人，才理解天父。</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 11:29; 约翰福音 7:37; 约翰福音 6:37"> 所有挣扎负重之人，到我这里来。我必让你们休息。</span>
<span className="v" id="v29" data-v="29" data-xref="Jeremiah 6:16; 约翰一书 2:6; 腓立比书 2:7–8"> 接受我的轭，向我学习，我内心善良谦卑，从我这里你将获得需要的休息。</span>
<span className="v" id="v30" data-v="30" data-xref="约翰一书 5:3; 约翰福音 16:33; 腓立比书 4:13"> 我的轭很轻柔，我的负重很轻。”</span>
</div>
</div>

</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 9:33–37; 路加福音 9:46–48; 马太福音 20:20–28"> 这时门徒前来问耶稣：“天国里谁最伟大？”</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 19:13–14; 马可福音 9:36–37; 1 Kings 3:7"> 耶稣叫来一个小孩子站在他们当中，说：</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 10:14–15; 彼得前书 2:2; 马太福音 19:14"> “实话告诉你们，如果你们不改变思维方式，变成像小孩子一样，一定不能进天国。</span>
<span className="v" id="v4" data-v="4" data-xref="雅各书 4:10; 路加福音 14:11; 马可福音 10:43"> 所以，凡谦卑如这小孩子，在天国里便最伟大。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 25:40; 马可福音 9:37; 约翰福音 13:20"> 凡因我之名接受这样的小孩子，便是接受我。</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 9:42; 路加福音 17:1–2; 马太福音 18:10"> 但任何人如让这信我的小孩犯罪，最好在他们的脖子上系一块大磨石<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“驴磨石”指的是驴转动大磨石，而不是用手转动的小磨石。">a</a></sup>，把他沉在深海。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 17:1; 哥林多前书 11:19; 马太福音 26:24"> 灾祸正在降临这个世界，因为这里有太多让人犯罪的诱惑。诱惑必然降临，但对于带来诱惑之人，这必是一场灾难！</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 5:29–30; 腓立比书 3:8–9; 罗马书 13:12"> 如果你的手或脚让你犯罪，就把它砍下丢掉。即使缺手缺脚，但你却可以获得永生，总好过手脚齐全坠入永不熄灭之火。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 14:22; 马太福音 18:8; 马太福音 5:29"> 如果你的一只眼睛让你犯罪，把它挖出来丢掉。一只眼睛进入永生，总比两眼齐全坠入哥和拿好。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="哥和拿。见5:22注释。">b</a></sup></span>
<span className="v" id="v10" data-v="10" data-xref="Psalms 91:11; Psalms 34:7; 希伯来书 1:14"> 你们要小心，不要轻视任何小孩。我告诉你们，他们的天使在天上，常常见到<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“看到面容。”">c</a></sup>天父的面。</span>
<span className="v" id="v11" data-v="11"> <sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="最早的抄本中并无第 11 句。">d</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="Ezekiel 34:12; 路加福音 15:4–7; Ezekiel 34:16"> 一个人有一百只羊，如果丢了一只，他会不把九十九只留在山上，去寻找迷失的那只？你们认为呢？</span>
<span className="v" id="v13" data-v="13" data-xref="Zephaniah 3:17; 路加福音 15:5–10; 雅各书 2:13"> 告诉你吧，他若找到了丢失的羊，就只是为这一只羊欢喜，胜过那未迷路的九十九只。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 17:12; 约翰福音 6:39–40; 彼得后书 3:9"> 同理，你们的天父也不愿意丢失任何一个小孩子。</span>
<span className="v" id="v15" data-v="15" data-xref="Leviticus 19:17; 路加福音 17:3–4; 加拉太书 6:1"> 如果你的兄弟<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="或“其他新人者。”">e</a></sup>对你做出罪行，在与他单独相处时，要指出他的过失。如果他肯听，便还是你的兄弟。</span>
<span className="v" id="v16" data-v="16" data-xref="Deuteronomy 19:15; 哥林多后书 13:1; 约翰福音 8:17"> 如果他不肯听，就再带一两个人，凭两三个证人之口，就会更加确认真相。<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="见《申命记》19:15。">f</a></sup></span>
<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦后书 3:6; 哥林多前书 5:9–7; 帖撒罗尼迦后书 3:14–15"> 如果他还是不听，就告诉教会，如果他连教会也不听，就把他看作异教徒<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="原意为“异教徒。”">g</a></sup>和税吏吧。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 16:19; 哥林多后书 2:10; 约翰福音 20:23"> 告诉你们实话吧，你们在地上禁止的，在天上也被禁止，你们在地上允许的，在天上也被允许。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 7:7; 约翰一书 5:14–16; 马可福音 11:24"> 我还要告诉你们，人间若有两人同心祈求一件事，我的天父必为他们成全。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 5:4; 启示录 21:3; 马太福音 28:20"> 因为无论在哪里，有两三个人以我之名相聚，我就与他们同在。”</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 17:3–4; 马太福音 18:15"> 这时彼得前来问耶稣：“主啊，如果我的兄弟得罪我，我可饶恕他多少次？七次吗？”</span>
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 3:13; 马可福音 11:25; 马太福音 6:14–15"> 耶稣对他说：“不是七次，而是七次的七十倍。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 13:24; 罗马书 14:12; 马太福音 3:2"> 所以天国如一个国王，要和欠其钱财的仆人算账。</span>
<span className="v" id="v24" data-v="24" data-xref="Psalms 38:4; Psalms 130:3–4; 路加福音 16:5"> 当他开始清算时，一个仆人被带到他面前，此人欠下一万银币。<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="一个天文数字。">h</a></sup></span>
<span className="v" id="v25" data-v="25" data-xref="2 Kings 4:1; Nehemiah 5:5; 路加福音 7:42"> 他没有钱偿还，主人就下令叫人把他和妻小以及一切统统卖掉，用来偿还。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 18:29; 路加福音 7:43; 马太福音 8:2"> 那仆人就跪下拜他，说：‘请宽容我，我会把一切偿还于你。’</span>
<span className="v" id="v27" data-v="27" data-xref="Psalms 145:8; Nehemiah 9:17; Psalms 86:15"> 主人动了慈悲心，便把那仆人放了，免了他的债。</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 20:2; Ezekiel 45:9; Deuteronomy 15:2"> 但之后，这仆人遇到欠他一百个银币<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="小银币，是当时的货币。事实上，第二位仆人欠他的数额，远比他欠主人的数额小太多。">i</a></sup>之人，就抓住对方并扼其喉咙，说：‘把你欠我的钱还给我。’</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 18:26; 马太福音 6:12; 腓利门书 1:18–19"> 那人与他都是仆人，跪下求他说：‘请宽容我，我会还给你。’</span>
<span className="v" id="v30" data-v="30" data-xref="1 Kings 22:27; 1 Kings 21:27–29"> 他却不肯，反而把另一人押走并关进监牢，等他把所欠的钱财还清。</span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 12:15; 希伯来书 13:3; 马可福音 3:5"> 其他的仆人见到此景非常沮丧，就去向主人报告这一切。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 19:22; 马太福音 25:26; 罗马书 3:19"> 于是主人叫他来，对他说：‘你这个恶仆，你求我，我就免了你欠我的一切。</span>
<span className="v" id="v33" data-v="33" data-xref="歌罗西书 3:13; 马太福音 6:12; 以弗所书 4:32–2"> 难道你不应像我怜悯你一样，怜悯你的同伴吗？’</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 5:25–26; 雅各书 2:13; 路加福音 12:58–59"> 主人大怒，把他送去服刑，等他把所欠的一切还清。</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 6:14–15; 雅各书 2:13; 路加福音 6:37–38"> 如果你们不从心里<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="原意为“跟从你的心。”">j</a></sup>饶恕你的兄弟，我的天父也必这样待你们。”</span>

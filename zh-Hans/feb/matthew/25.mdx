<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 12:35–36; 腓立比书 2:15–16; 马太福音 24:42–51"> 天国如十名少女，提着灯出去迎接新郎。</span>
<span className="v" id="v2" data-v="2" data-xref="Jeremiah 24:2; 哥林多前书 10:1–5; 马太福音 13:19–23"> 她们中间有五人蠢笨，五人聪明。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 3:15–16; 提摩太后书 3:5; Isaiah 48:1–2"> 愚蠢之人拿着灯，却没有带油，</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 8:9; 约翰一书 2:27; 约翰一书 2:20"> 聪明之人拿着灯，也把油装在罐里带来。</span>
<span className="v" id="v5" data-v="5" data-xref="Habakkuk 2:3; 帖撒罗尼迦前书 5:6–8; 彼得后书 3:4–9"> 新郎很晚都没有到，她们打起了瞌睡，睡着了。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得后书 3:10; 马太福音 24:31; 马太福音 24:44"> 半夜时有人喊叫：‘新郎来了，快出来迎接。’</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 12:35; 启示录 3:19–20; 彼得后书 3:14"> 少女纷纷醒过来，整理她们的灯。</span>
<span className="v" id="v8" data-v="8" data-xref="Proverbs 13:9; 路加福音 12:35; 希伯来书 4:1"> 愚蠢之人对聪明之人说：‘请把你们的油分一点给我们，我们的灯快要熄灭了。’聪明之人回答：</span>
<span className="v" id="v9" data-v="9" data-xref="Psalms 49:7–9; 启示录 3:17–18; Isaiah 55:6–7"> ‘这些恐怕不够我们大家使用，不如你们自己到卖油之地去买吧！’</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 13:25; 马太福音 24:44; 路加福音 12:36–37"> 她们去买油的时候，新郎来了，准备好了的少女便和他们进去参加婚筵，门关上了。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 7:21–23; 希伯来书 12:16–17"> 随后其余的少女也来到，说：‘主啊，主啊，给我们开门吧！’</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 8:3; 提摩太后书 2:19; 约翰福音 10:27"> 主却回答：‘告诉你们实话，我不认识你们。’</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 24:42–44; 启示录 16:15; 帖撒罗尼迦前书 5:6"> 所以要警惕，因为你不知道具体的日期和时间。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马可福音 13:34; 路加福音 19:12–27; 彼得前书 4:9–11"> 天国又像一个人要外出远行，唤自己的仆人来，把自己的家业交给他们。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 18:24; 路加福音 19:13–14; 路加福音 12:48"> 他按照各人的能力分发钱币：一人给了五袋银币，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="当时的货币，是一笔不菲数额。">a</a></sup>一人给两袋银币，一人给了一袋银币。然后主人便远行去了。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰三书 1:5–8; 提摩太前书 6:17–18; 提摩太后书 2:6"> 领了五袋银币之人马上去做生意，又赚了五袋银币。</span>
<span className="v" id="v17" data-v="17" data-xref="Proverbs 3:9–10; 以弗所书 5:16; 彼得前书 4:10"> 领了两袋银币之人也是如此，赚了两袋银币。</span>
<span className="v" id="v18" data-v="18" data-xref="彼得后书 1:8; Haggai 1:2–4; Malachi 1:10"> 但那领了一袋银币之人却在地上挖了个洞，把主人的钱币藏起来。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 3:12–15; 哥林多后书 5:10; 罗马书 14:7–12"> 过了很久主人回来了，要和他们算算账目。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 20:24; 路加福音 19:16–17; 歌罗西书 1:29"> 领了五个袋银币的仆人带着赚来的五袋钱币前来，说：‘主人，你给了五袋银币，你看，我又赚了五袋。’</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 25:23; 路加福音 16:10; 约翰福音 12:26"> 主人对他说：‘良善又忠心的仆人，你做得好！你在小事上证明了自己的忠心，我要派你管理更多事。欢喜吧，因为我真的对你很满意！’</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多后书 8:12; 哥林多后书 8:7–8; 哥林多后书 8:1–3"> 领了两袋银币也前来，说：‘主人，你给了两袋银币，你看，我又赚了两袋。’</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 25:21; 马可福音 14:8–9; 马可福音 12:41–44"> 主人对他说：‘良善又忠心的仆人，你做得好！你在小事上证明了自己的忠心，我要派你管理更多事。欢喜吧，因为我真的对你很满意！’</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 19:20–22; 路加福音 15:29; Malachi 3:14–15"> 领了一袋银币的也前来，说：‘主人，我知道你是个严厉之人，即使没有撒种的地方也要收割，即使没有播种的地方也要收获。</span>
<span className="v" id="v25" data-v="25" data-xref="提摩太后书 1:6–7; 罗马书 8:15; 启示录 21:8"> 因为我害怕你，于是把你的钱藏在地里。你看，你的钱还在这里。’</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 18:32; Job 15:5–6"> 可是主人对他说：‘你这可恶又懒惰的仆人，你既然知道我会在没有撒种的地方也要收割，在没有播种的地方也要收获，</span>
<span className="v" id="v27" data-v="27" data-xref="Deuteronomy 23:19–20; 罗马书 3:19; 犹大书 1:15"> 那你就应该把我的钱存入银行，待我回来的时候，可以连本带利收回。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 19:24; 路加福音 10:42"> 你们把他银币拿去，交给那拥有十袋银币之人。</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 8:18; 马可福音 4:25; 马太福音 13:12"> 因为凡是拥有者，他就会得到更多；凡是一无所有，就算有也会被夺走。</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 8:12; 启示录 3:15–16; 马太福音 13:50"> 他将没有用的仆人丢在外面的黑暗里，在那里哀哭切齿。’</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="启示录 1:7; 帖撒罗尼迦后书 1:7–8; 马太福音 19:28"> 当人子携荣耀而来，带着所有的天使降临人间，他会坐在荣耀的宝座上。</span>
<span className="v" id="v32" data-v="32" data-xref="Malachi 3:18; 马太福音 13:49; 哥林多后书 5:10"> 所有人都聚集在他面前，他要把他们彼此分开，好像牧羊人把绵羊和山羊分开一样：</span>
<span className="v" id="v33" data-v="33" data-xref="Psalms 100:3; 约翰福音 10:26–28; 约翰福音 21:15–17"> 把绵羊放在右边，山羊放在左边。</span>
<span className="v" id="v34" data-v="34" data-xref="彼得前书 1:19–20; 雅各书 2:5; 启示录 21:7"> 然后，王对右边的人说：‘蒙我父赐福的人，来承受创世以来为你们预备好的王国吧。</span>
<span className="v" id="v35" data-v="35" data-xref="约翰一书 3:16–19; 雅各书 2:15–16; Deuteronomy 15:7–11"> 因为我饿了，你们给我食物；我渴了，你们给我解渴；我是陌生人，你们接待我；</span>
<span className="v" id="v36" data-v="36" data-xref="雅各书 1:27; 提摩太后书 1:16–18; 雅各书 5:14–15"> 我赤身露体，你们给我衣服穿；我病了，你们照顾我；我被投入监牢，你们来看我。’</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 6:3; 1 Chronicles 29:14; 彼得前书 5:5–6"> 那些正确行事之人回答：‘主啊，我们什么时候见你饿了给你吃食，见你渴了给你解渴？</span>
<span className="v" id="v38" data-v="38"> 什么时候见你陌生就接待你，赤身露体就给你衣服穿呢？</span>
<span className="v" id="v39" data-v="39"> 什么时候见你病了，或到监牢里看你呢？’</span>
<span className="v" id="v40" data-v="40" data-xref="Proverbs 19:17; Proverbs 14:31; 马太福音 10:42"> 王回答他们说：‘我告诉你们实话，你们这样对待我最微不足道的兄弟，也就是这样对待我。’</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="彼得后书 2:4; 犹大书 1:6–7; 帖撒罗尼迦后书 1:9"> 王对左边之人说：‘你们是被诅咒的，离开吧，到魔鬼和其使者准备的永恒<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="在结果上是永恒的，而不是在时间上是永恒的。">b</a></sup>之火中去吧！</span>
<span className="v" id="v42" data-v="42" data-xref="雅各书 2:15–24; 约翰福音 5:23; 马太福音 12:30"> 因为我饿了，你们没有给我吃；我渴了，你们没有给我解渴；</span>
<span className="v" id="v43" data-v="43"> 我陌生，你们没有接待我；我赤身露体，你们没有给我衣服穿；我病了或者身处监牢，你们没有来看我。’</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 7:22; 路加福音 10:29; 马太福音 25:24–27"> 他们回答：‘主啊，我们什么时候见你饿了、渴了、陌生、赤身露体、病了或身处监牢，却没有服侍你呢？’</span>
<span className="v" id="v45" data-v="45" data-xref="Proverbs 21:13; Proverbs 17:5; Proverbs 14:31"> 王回答他们：‘我告诉你们实话，你们这样对待我最微不足道的兄弟，也就是这样对待我’</span>
<span className="v" id="v46" data-v="46" data-xref="Daniel 12:2; 约翰福音 3:36; 约翰福音 5:29"> 你们要进入永恒的谴责，良善之人却要进入永生。”</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 15:1; 约翰福音 18:28; Micah 2:1"> 清晨时分，所有的祭司长和民间长老都聚集在一起，商议怎样治死耶稣。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 20:19; 使徒行传 3:13; 提摩太前书 6:13"> 他们把他绑起来，押去交给总督彼拉多。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 7:10; 路加福音 22:47–48; Job 20:15–29"> 此刻，出卖耶稣的犹大见耶被稣定了罪，就后悔了，把那三十块银子还给祭司长和长老，说：</span>
<span className="v" id="v4" data-v="4" data-xref="1 Samuel 15:30; 提多书 1:16; 使徒行传 18:15–17"> “我有罪了！我出卖了无辜之人的血！”他们说：“这是你的问题，跟我们有什么关系？”</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 1:18–19; 2 Samuel 17:23; 1 Kings 16:18"> 犹大把银子丢进圣殿，然后跑到一个地方吊死了。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 6:7–9; Deuteronomy 23:18; Isaiah 61:8"> 祭司长把银子拾起来，说：“这是带血的钱币，不可放在殿库里。”</span>
<span className="v" id="v7" data-v="7"> 他们商议之后，就用那些钱买了陶匠的田地，用作异教徒的坟地。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 1:19; 马太福音 28:15; Joshua 4:9"> 那块田地被称为“血田。”</span>
<span className="v" id="v9" data-v="9" data-xref="Zechariah 11:12–13; 马太福音 1:22; Leviticus 27:2–7"> 这应验了耶利米先知所说：“他们拿了三十个银币，这就以色列人给他估算的价钱，</span>
<span className="v" id="v10" data-v="10" data-xref="Zechariah 11:13"> 他们用这三十个银币买下陶匠的田，正如主所传来的指示。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="见《撒迦利亚书》11:12-13，参考《耶利米书》32:6-15。">a</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 23:2–3; 马可福音 15:2–5; 马太福音 26:25"> 耶稣站在总督面前，总督问他：“你是犹太人的王吗？”耶稣回答：“这是你说的。”</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 26:63; Isaiah 53:7; 马太福音 27:14"> 祭司长和长老控告他的时候，他却不回答。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 26:62; 约翰福音 18:35; 使徒行传 22:24"> 彼拉多又问他：“他们作证指控你那么多事，你没有听见吗？”</span>
<span className="v" id="v14" data-v="14" data-xref="Isaiah 8:18; Psalms 71:7; 哥林多前书 4:9"> 耶稣一句话也不回答他，令总督非常诧异。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 18:38–40; 路加福音 23:16; 约翰福音 19:16"> 每逢这时候，总督都会一个惯例，让民众根据自己的意愿，决定释放一名囚犯。</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 15:7; 使徒行传 3:14; 路加福音 23:25"> 这时监狱中有个声名狼藉的囚犯，名叫巴拉巴。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 19:15; 1 Kings 18:21; 马可福音 15:9–12"> 民众聚集的时候，彼拉多问他们：“你们要我释放谁？巴拉巴或是称为基督的耶稣呢？”</span>
<span className="v" id="v18" data-v="18" data-xref="Proverbs 27:4; 使徒行传 5:17; 马可福音 15:10"> （他知道他们是因为嫉妒才把耶稣交上来。）</span>
<span className="v" id="v19" data-v="19" data-xref="Zechariah 9:9; Proverbs 29:1; 马太福音 27:24"> 彼拉多坐在审判台上的时候，他的妻子派人来说：“你们不要对这无辜之人做任何事，因为今天我因为梦到他而受了很多的苦。”</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 3:14–15; 约翰福音 19:15–16; 约翰福音 18:40"> 祭司长和长老怂恿民众，叫他们去要求释放巴拉巴，将耶稣处死。</span>
<span className="v" id="v21" data-v="21"> 总督问他们：“这两个人，你们要我释放哪一个？”他们说：“巴拉巴！”</span>
<span className="v" id="v22" data-v="22" data-xref="Isaiah 53:2–3; Isaiah 49:7; 使徒行传 13:38"> 彼拉多对他们说：“那么，我怎样处置那被称为弥赛亚的耶稣呢？”他们齐声说：“把他钉上十字架！”</span>
<span className="v" id="v23" data-v="23" data-xref="Genesis 37:18–19; 使徒行传 7:57; 使徒行传 23:12–15"> 彼拉多说：“为什么呢？他做了什么恶事呢？”众人更加大声喊叫：“把他钉上十字架！”</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 27:4; Psalms 26:6; 哥林多后书 5:21"> 彼拉多见局势已定，民众正在酝酿骚动，就拿起水在民众面前洗手，说：“让此人流血与我无关，这是你们的决定。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“你们自己所见。”">b</a></sup></span>
<span className="v" id="v25" data-v="25" data-xref="Joshua 2:19; 使徒行传 5:28; 使徒行传 7:52"> 民众回答：“让他流血的责任，归在我们和我们子孙的身上吧。”</span>
<span className="v" id="v26" data-v="26" data-xref="Isaiah 53:5; 约翰福音 19:1; 马可福音 15:15"> 于是彼拉多释放了巴拉巴，鞭打了耶稣鞭，再把他送去钉上十字架。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 18:28; 约翰福音 18:33; 使徒行传 10:1"> 总督的士兵把耶稣带到军营<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="军事总部。">c</a></sup>，召集全队士兵来到他面前。</span>
<span className="v" id="v28" data-v="28" data-xref="马可福音 15:17; 约翰福音 19:2–5; 路加福音 23:11"> 他们脱去他的衣服，给他披上朱红色的外袍，</span>
<span className="v" id="v29" data-v="29" data-xref="Isaiah 53:3; 马太福音 20:19; Psalms 69:19–20"> 又用荆棘编成冠冕，戴在他的头上，把一根芦苇放在他的右手，跪在他面前戏弄他说：“犹太人之王万岁！”</span>
<span className="v" id="v30" data-v="30" data-xref="Isaiah 50:6; 马太福音 26:67; Isaiah 53:7"> 随后士兵向他吐唾沫，又拿起芦苇抽他的头。</span>
<span className="v" id="v31" data-v="31" data-xref="Isaiah 53:7; 1 Kings 21:13; 1 Kings 21:10"> 戏弄完耶稣后，他们脱下他的外袍，给他穿回自己的衣服，带去钉十字架。</span>
<span className="v" id="v32" data-v="32" data-xref="马可福音 15:21; 马太福音 16:24; 路加福音 23:26"> 他们出来的时候，遇见一个名叫西门的古利奈人，于是强迫他背上耶稣的十字架。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 19:17–19; 马可福音 15:22–32; 马可福音 15:34"> 一行人来到一个名叫各各他的地方，意为“髑髅地”，</span>
<span className="v" id="v34" data-v="34" data-xref="Psalms 69:21; 马可福音 15:23; 马太福音 27:48"> 把苦胆调和的酒给他喝，他尝了一口但没有喝。</span>
<span className="v" id="v35" data-v="35" data-xref="Psalms 22:18; 马可福音 15:24–32; 路加福音 23:34"> 士兵把他钉上十字架，然后掷骰子分他的衣物。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="见《诗篇》22:18。">d</a></sup></span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 27:54; 马可福音 15:44; 马可福音 15:39"> 随后坐在那里看守他。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 23:38; 约翰福音 19:19–22; 马可福音 15:26"> 他们在耶稣头的上方钉了一块牌子，写着他的罪状：“这是犹太人的王——耶稣。”</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 19:18; 路加福音 23:39–43; Isaiah 53:12"> 同时钉上十字架的还有两个强盗，一个在右，一个在左。</span>
<span className="v" id="v39" data-v="39" data-xref="Psalms 109:25; Lamentations 1:12; Psalms 69:7–12"> 路过的人嘲笑他，摇着头说：</span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 26:61; 马太福音 4:6; 马太福音 4:3"> “你不是承诺拆毁圣殿，然后在三日之内将其再建吗？救救自己吧！如果你是上帝的儿子，那就从十字架下来吧！”</span>
<span className="v" id="v41" data-v="41" data-xref="Psalms 35:26; Isaiah 28:22; Psalms 22:12–13"> 祭司长、宗教老师和长老也同样讥笑他，说：</span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 1:49; 马太福音 27:37; 使徒行传 4:14"> “他救了别人，却不能救自己。如果他是以色列的王，现在从十字架走下来，我们就信他。</span>
<span className="v" id="v43" data-v="43" data-xref="Psalms 22:8; 约翰福音 10:36; Isaiah 37:10"> 他如此笃定地信上帝。如果上帝想要他活着，就让上帝现在救他吧，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="更糟的是，他们对他引用了这段经文中的话：《诗篇》22:8。">e</a></sup>因为他说自己是上帝的儿子。”</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 27:38; 马可福音 15:32; 路加福音 23:39–43"> 和他一同钉十字架的强盗也都这样侮辱他。</span>
<span className="v" id="v45" data-v="45" data-xref="Amos 8:9; 马可福音 15:33–34; 路加福音 23:44–45"> 从正午到下午三点钟，黑暗开始笼罩世界。</span>
<span className="v" id="v46" data-v="46" data-xref="Psalms 22:1; 希伯来书 5:7; Isaiah 53:10"> 大约三点钟，耶稣大声呼叫：“以利，以利，拉马，撒巴各大尼？”（意思是“我的上帝，我的上帝，你为什么离弃我？”）<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="引自《诗篇》22:1。">f</a></sup></span>
<span className="v" id="v47" data-v="47" data-xref="Malachi 4:5; 马可福音 15:35–36; 马太福音 11:14"> 站在那里的几个人听见了就说：“这个人在呼叫以利亚呢。”</span>
<span className="v" id="v48" data-v="48" data-xref="Psalms 69:21; 马太福音 27:34; 路加福音 23:36"> 有一个人马上跑去拿海绵蘸满了酸酒，用芦苇递给他喝。<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="见《诗篇》69:21。">g</a></sup></span>
<span className="v" id="v49" data-v="49"> 但其他的人说：“别管他，我们看看以利亚来不来救他。”</span>
<span className="v" id="v50" data-v="50" data-xref="约翰福音 19:30; Isaiah 53:9–12; Psalms 22:14–15"> 耶稣再次大声呼叫，然后就吐出了最后一口气。<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="希伯来语，意味着他已经死去。">h</a></sup></span>
<span className="v" id="v51" data-v="51" data-xref="希伯来书 10:19–22; 马可福音 15:38; 希伯来书 6:19"> 忽然，圣殿里的幔子从上到下裂成两半，地动山摇，石头崩裂，</span>
<span className="v" id="v52" data-v="52" data-xref="Isaiah 26:19; 帖撒罗尼迦前书 4:14; 哥林多前书 15:20"> 坟墓裂开，许多生前做善事的死人也复活了。</span>
<span className="v" id="v53" data-v="53" data-xref="启示录 11:2; Isaiah 48:2; 启示录 21:2"> 待到耶稣复活之后，他们从坟墓中走出，进入圣城<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="即耶路撒冷。">i</a></sup>，在众人面前显现。</span>
<span className="v" id="v54" data-v="54" data-xref="马太福音 27:36; 马可福音 15:39; 马太福音 27:43"> 百夫长和一起看守耶稣的士兵们，看见地震和所发生的事情，十分惧怕，说：“这个人真是上帝之子。”</span>
<span className="v" id="v55" data-v="55" data-xref="路加福音 8:2–3; 路加福音 23:48–49; 约翰福音 19:25–27"> 有许多妇女在远远观看，她们从加利利开始就跟随耶稣并侍奉他。</span>
<span className="v" id="v56" data-v="56" data-xref="约翰福音 19:25; 马可福音 15:47–1; 马太福音 28:1"> 她们中间有抹大拉的玛利亚、雅各和约西的母亲玛利亚、以及西庇太儿子的母亲。</span>
<span className="v" id="v57" data-v="57" data-xref="约翰福音 19:38–42; 马可福音 15:42–47; 路加福音 23:50–56"> 到了晚上，有一个来自亚利马太的富人前来，他名叫约瑟，是耶稣的门徒。</span>
<span className="v" id="v58" data-v="58" data-xref="路加福音 23:52–53; 马可福音 15:44–46"> 这个人去见彼拉多，请求认领耶稣的身体，彼拉多同意了。</span>
<span className="v" id="v59" data-v="59"> 约瑟领了耶稣的身体，用干净的细麻布裹好，</span>
<span className="v" id="v60" data-v="60" data-xref="Isaiah 53:9; 马太福音 28:2; 马太福音 27:66"> 放在他从岩石上为自己新凿出来的坟墓里，然后滚来一块大石头挡住墓门，随后才离开。</span>
<span className="v" id="v61" data-v="61" data-xref="马太福音 28:1; 马太福音 27:56"> 抹大拉的玛利亚和另一位叫做玛利亚的女人都在那里，对着坟墓坐着。</span>
<span className="v" id="v62" data-v="62" data-xref="马可福音 15:42; 约翰福音 19:14; 约翰福音 19:42"> 第二天<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="即安息日。">j</a></sup>，即过了“预备日”的那一天，祭司长和法利赛人去见彼拉多，说：</span>
<span className="v" id="v63" data-v="63" data-xref="路加福音 9:22; 马太福音 16:21; 约翰福音 2:19"> “大人，我们想起那个骗子，生前说过：‘三天之后，我要复活。’</span>
<span className="v" id="v64" data-v="64" data-xref="马太福音 28:13; 马太福音 12:45"> 请你下令把坟墓严密看守，直到第三天，免得他的门徒把他偷去，然后骗民众说：‘他从死人中复活了。’这会导致日后出现比之前更大的骗局。”</span>
<span className="v" id="v65" data-v="65" data-xref="马太福音 27:66; 马太福音 28:11–15; Proverbs 21:30"> 彼拉多对他们说：“你们带着卫兵，尽可能严密看守吧。”</span>
<span className="v" id="v66" data-v="66" data-xref="Daniel 6:17; 马太福音 27:60; 提摩太后书 2:19"> 祭司长和法利赛人于是到墓前的石头封好，又派卫兵把守，严密守住坟墓。</span>

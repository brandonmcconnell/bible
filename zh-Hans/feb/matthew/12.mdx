<span className="v" id="v1" data-v="1" data-xref="Deuteronomy 23:25; 马可福音 2:23–28; 路加福音 6:1–5"> 安息日那天，耶稣走过麦田，门徒们饿了，就摘了些麦穗来吃。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 12:10; 约翰福音 7:21–24; 路加福音 14:3"> 法利赛人看到便对耶稣说：“你看，你的门徒做了安息日不可做的事。”</span>
<span className="v" id="v3" data-v="3" data-xref="1 Samuel 21:3–6; 路加福音 6:3; 马可福音 2:25–26"> 但耶稣对他们说：“大卫和他的人在饥饿时做什么，你们没有念过吗？</span>
<span className="v" id="v4" data-v="4" data-xref="Leviticus 24:5–9; Exodus 25:30; Leviticus 8:31"> 他走进上帝的上帝殿，吃下了只有祭司才能吃的圣饼，而他们其实并不允许这样做。</span>
<span className="v" id="v5" data-v="5" data-xref="Numbers 28:9–10; 约翰福音 7:22–23; Nehemiah 13:17"> 律法书中写道：‘在安息日，在殿里供职的祭司即使触犯了安息日规定，也不算有罪。’你们也没有读过吗？</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 12:41–42; 2 Chronicles 6:18; 彼得前书 2:4–5"> 让我告诉你们，这里有一位比圣殿更伟大之人。</span>
<span className="v" id="v7" data-v="7" data-xref="Hosea 6:6; 马太福音 9:13; Micah 6:6–8"> 经文中说：‘我要的是怜悯，不是献祭。’如果你明白这句话的意思，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《何西阿书》6:6。">a</a></sup>就不会认为无罪之人有罪。</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 2:28; 路加福音 6:5; 约翰福音 5:17–23"> 因为人子是安息日的主。”</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 3:1–6; 路加福音 6:6–11"> 然后耶稣离开，来到他们的会堂。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 13:14; 约翰福音 9:16; 约翰福音 8:6"> 会堂里有个人的一只手已经残疾。有人问耶稣：“在安息日治病可以吗？”但他这样问，只是想找理由控诉耶稣。</span>
<span className="v" id="v11" data-v="11" data-xref="Deuteronomy 22:4; 路加福音 14:5; 路加福音 13:15–17"> 耶稣回答：“假设你有一只羊，在安息日掉进坑里，你难道不把它抓住拉上来吗？</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 6:26; 路加福音 6:9; 马可福音 3:4"> 难道你不觉得人比羊更贵重吗？所以，在安息日行善是允许的。”</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 13:13; 使徒行传 3:7–8"> 然后他对那残疾之人说：“伸出手来！”手残之人一伸手就复原了，和另一只手别无二致。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 11:53; 约翰福音 10:39; 马可福音 3:6"> 但法利赛人却走出去，开始密谋如何杀掉耶稣。</span>
<span className="v" id="v15" data-v="15" data-xref="马可福音 3:7–12; 马太福音 10:23; 马太福音 19:2"> 耶稣知道了，就离开那里，大批民众都跟随他。他医好所有人，</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 8:4; 马太福音 9:30; 马太福音 17:9"> 但嘱咐他们不可张扬他所做的一切。</span>
<span className="v" id="v17" data-v="17" data-xref="Isaiah 42:1–4; Isaiah 42:9; 马太福音 13:35"> 这就应验了以赛亚先知所说：</span>
<span className="v" id="v18" data-v="18" data-xref="Isaiah 42:1; 路加福音 4:18; 使徒行传 10:38"> “这便是上帝所选的仆人， 是我所爱之人，让我心生喜悦之人。 我会把我的灵赐给他， 他必向异教徒宣扬正道。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 11:29; 约翰福音 18:36–38; 提摩太后书 2:24–25"> 他不争论，不喧嚷，街上无人能听见他的声音。</span>
<span className="v" id="v20" data-v="20" data-xref="Isaiah 42:3–4; Ezekiel 34:16; Isaiah 61:1–3"> 他不会折断残破的芦苇， 不会吹灭将残的灯芯， 但他终会证明使他的审判为正道。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或“为公正带来胜利。”">b</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="Isaiah 11:10; 罗马书 15:12–13; Isaiah 42:4"> 异教徒都要对他寄以厚望。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“以他之名期盼。”这首诗源自《以赛亚书》42:1-4。">c</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 11:14–15; 马可福音 7:35–37; Isaiah 29:18"> 有人带来一个被鬼附体、又瞎又哑之人来到耶稣这里。耶稣医好他，让他能够说话，能够看到。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 9:27; 约翰福音 4:29; 马太福音 22:42–43"> 众人都很惊奇地说：“难道他真的就是大卫的子孙？”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="意为将会到来的弥赛亚。">d</a></sup></span>
<span className="v" id="v24" data-v="24" data-xref="马可福音 3:22; 马太福音 9:34; 路加福音 11:15"> 但法利赛人听说这一切，便说：“他不过是利用魔鬼之王的力量驱赶魔鬼而已。”</span>
<span className="v" id="v25" data-v="25" data-xref="加拉太书 5:15; Jeremiah 17:10; 马太福音 9:4"> 耶稣知道他们的心思，就对他们说：“如果一个国家四分五裂，必定毁灭，任何城镇或家庭若四分五裂，必会毁灭。</span>
<span className="v" id="v26" data-v="26" data-xref="歌罗西书 1:13; 启示录 20:2–3; 约翰一书 5:19"> 如果让撒旦驱除撒旦，他就是在驱逐自己。他的王国又怎能存在？</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 19:13–16; 马可福音 9:38–39; 路加福音 9:49–50"> 我若靠魔鬼之王的力量驱鬼，你们又以谁之名驱鬼呢？这样，你们就是自证错误。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 11:20; Daniel 7:14; 马太福音 6:33"> 我若以上帝之灵驱鬼，这就代表天国已降临你们的身边！</span>
<span className="v" id="v29" data-v="29" data-xref="Isaiah 49:24; 马可福音 3:27; 路加福音 11:21–22"> 如果你闯进猛士家中，想要夺其财物，难道不是要先将其捆绑起来？只有这样做，你才能拿走他家中的一切。</span>
<span className="v" id="v30" data-v="30" data-xref="马可福音 9:40; 路加福音 11:23; Joshua 24:15"> 未与我站在一起之人，即反对我，不与我聚在一起，即被散落孤立。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 12:10; 马可福音 3:28–30; 希伯来书 10:29"> 所以让我告诉你们，人所犯的一切罪过和亵渎行为都可以赦免，但亵渎圣灵将无法被宽恕。</span>
<span className="v" id="v32" data-v="32" data-xref="马可福音 3:29; 希伯来书 10:26–29; 希伯来书 6:4–6"> 你在说话间得罪人子可以赦免，但得罪圣灵，今生来世均无法得到赦免。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 6:43–44; 马太福音 7:16–20; 雅各书 4:8"> 种下好树便结好果子，种坏树便结坏果子，凭结果就能认出树的好坏。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 6:45; 马太福音 15:18; 以弗所书 4:29"> 你是毒蛇的后代，你这邪恶之人又怎能口中良善？因为你心中所思，必会脱口而出。</span>
<span className="v" id="v35" data-v="35" data-xref="Proverbs 15:4; 歌罗西书 4:6; Proverbs 15:28"> 良善之人行善事就会带来良善，人行恶事就会带来邪恶。</span>
<span className="v" id="v36" data-v="36" data-xref="Ecclesiastes 12:14; 罗马书 2:16; 启示录 20:12"> 我告诉你们，在审判之日，人们必会对所说的无心之语负起责任。</span>
<span className="v" id="v37" data-v="37" data-xref="Proverbs 13:3; 雅各书 2:21–25"> 因为你所说之语将被证明为正义或有罪。”</span>
<span className="v" id="v38" data-v="38" data-xref="哥林多前书 1:22; 马可福音 8:11–12; 路加福音 11:16"> 这时，一些宗教老师和法利赛人对耶稣说：“老师，想请你显现一个上帝神迹给我们看看。”</span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 16:4; 路加福音 11:29–32; 马可福音 8:38"> 但耶稣说：“只有不相信上帝的邪恶之人，才会想要寻找上帝的神迹，但他们只能看到约拿先知的上帝神迹。</span>
<span className="v" id="v40" data-v="40" data-xref="Jonah 1:17; 马太福音 27:63–64; 马太福音 16:21"> 就像约拿曾在大鱼腹中待上三日三夜，人子也要在土中待上三日三夜。</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 12:42; 希伯来书 11:7; 马太福音 12:6"> 待到审判日那天，尼尼微人将会崛起，与这代人一起判定这代人的罪，因为他们在听了约拿的传道后便悔改了。你看，这里有一位是比约拿更伟大之人。</span>
<span className="v" id="v42" data-v="42" data-xref="1 Kings 10:1–13; 2 Chronicles 9:1–12; 希伯来书 1:2–4"> 在审判日那天，南方女王要崛起，与这代人一起判定这个世界的罪，因为她来自大地的尽头，来此便是为聆听所罗门的智慧。你看，这里有一位是比所罗门更伟大之人。</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 11:24–26; 路加福音 8:28–32; 马太福音 8:29"> 待一个邪灵离开人体，它会在荒芜之地游荡，寻找栖身之所，却遍寻不得。</span>
<span className="v" id="v44" data-v="44" data-xref="约翰一书 4:4; 启示录 13:8–9; 犹大书 1:4–5"> 然后他说：‘我将回到之前离开的地方。’当它回来时，发现这个地方是空的，一切都很干净整洁。</span>
<span className="v" id="v45" data-v="45" data-xref="路加福音 11:26; 马可福音 5:9; 希伯来书 6:4–8"> 他于是带了另外七个比他更邪恶的恶灵来，全部住了进去。那人后来的情况比以前更糟糕。邪恶的世界必将如此。”</span>
<span className="v" id="v46" data-v="46" data-xref="马太福音 13:55; 约翰福音 2:12; 约翰福音 7:3"> 耶稣在对民众讲话的时候，他的母亲和弟弟站在外面，要和他对话。</span>
<span className="v" id="v47" data-v="47"> 有人告诉耶稣：“你的母亲和弟弟站在外面，有话要跟你说。”</span>
<span className="v" id="v48" data-v="48" data-xref="马可福音 3:32–33; 马太福音 10:37; 路加福音 2:52"> 他回答那人：“谁是我的母亲？谁是我的兄弟？”</span>
<span className="v" id="v49" data-v="49" data-xref="马可福音 3:34; 约翰福音 17:8–9; 约翰福音 20:17–20"> 他伸手指着门徒说：“看啊，他们就是我的母亲，我的兄弟！</span>
<span className="v" id="v50" data-v="50" data-xref="路加福音 8:21; 马可福音 3:35; 约翰福音 15:14"> 凡是遵行天父旨意者，就是我的兄弟姐妹和母亲！”</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 10:40; 马太福音 19:1–9; 马太福音 7:28"> 耶稣讲完这番话后就离开加利利，来到约旦河东的犹太境内。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 12:15; 马可福音 6:55–56; 马太福音 15:30–31"> 有许多人跟着他，他在那里医好了他们。</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 10:2; 希伯来书 3:9; 马太福音 16:1"> 法利赛人前来试探耶稣，说：“男人可以无论任何缘故休妻吗？”</span>
<span className="v" id="v4" data-v="4" data-xref="Genesis 2:23; Genesis 1:27; Genesis 5:2"> 耶稣回答：“难道你没读过，上帝起初造人，是造男造女的。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="见《创世记》1:27和《创世纪》5:2。">a</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="Genesis 2:21–24; 哥林多前书 7:4; 哥林多前书 7:2"> 他又说：‘所以男人要离开父母，与妻结合，二人成为一体’。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“一个躯体。”引自《创世纪》2:24。">b</a></sup></span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 13:4; 马可福音 10:9; 哥林多前书 7:10–14"> 这样他们便不再是两个人，而是一体。由上帝连接的关系，没有人可以将其分开。”</span>
<span className="v" id="v7" data-v="7" data-xref="Deuteronomy 24:1–4; 马太福音 5:31; 马可福音 10:4"> 他们就问：“那为什么摩西却说男人若给了休书，就可以休妻, 让她离开？”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="见《申命记》24:1。">c</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="Malachi 2:13–14; Genesis 2:24; 马可福音 10:5"> 耶稣回答：“摩西这样说，是因为你们铁了心的态度，才准许你们休妻，但起初并非这样。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 5:32; 路加福音 16:18; 哥林多前书 7:39"> 我告诉你们，凡休妻另娶，如果不是因为妻子不贞，便是犯下奸淫罪。”</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 7:32–35; Proverbs 19:13–14; Proverbs 21:19"> 门徒对他说：“夫妻关系既然如此，倒不如不结婚。”</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 7:17; 哥林多前书 7:35; 哥林多前书 7:7–9"> 耶稣对他们说：“不是每个人都能接受这个教诲，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原意为“文字。”">d</a></sup>只有向其赐予，才能领受。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 7:32–38; 哥林多前书 9:5; Isaiah 56:3–4"> 有些人是生来就不能结婚，有些人不能结婚是因为被人阉割，也有人是为了天国的原因。能接受者自会接受。”</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 10:13–16; 路加福音 18:15–17; 马太福音 18:2–5"> 这时，有人带了小孩子来到耶稣面前，求他为其祝福和祈祷，但门徒们不让他们这样做。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 18:3; 路加福音 18:16–17; 哥林多前书 14:20"> 但耶稣说：“让小孩子到我这里来，不要禁止他们，因为天国就是属于这样的人。”</span>
<span className="v" id="v15" data-v="15" data-xref="马可福音 10:16; 提摩太后书 3:15; 哥林多前书 7:14"> 于是他将手放在孩子身上, 为其祝福，然后就离开了。</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 10:17–30; 约翰福音 3:15; 犹大书 1:21"> 有一个人前来见耶稣说：“老师，我做什么善事才可以获得永生？”</span>
<span className="v" id="v17" data-v="17" data-xref="Leviticus 18:5; 路加福音 10:26–28; 加拉太书 3:11–13"> 耶稣说：“为什么问我关于善的事呢？善者只有一人。如果你想永生，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原意为“整个生命。”">e</a></sup>就应当遵守诫命。”</span>
<span className="v" id="v18" data-v="18" data-xref="Deuteronomy 5:16–21; Exodus 20:12–17; 马可福音 10:19"> 那人问：“什么诫命？”耶稣回答：“不可杀人，不可奸淫，不可偷盗，不可做假证供，</span>
<span className="v" id="v19" data-v="19" data-xref="Leviticus 19:18; Exodus 20:12; 马太福音 22:39"> 当孝敬父母，当爱邻居如己。”<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="引自《出埃及记》20:12-16；《利未记》19:18；《申命记》5:16-20。">f</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="加拉太书 3:24; 马可福音 10:20–21; 腓立比书 3:6"> 那青年对他说：“这一切我都遵守了，还缺少什么呢？”</span>
<span className="v" id="v21" data-v="21" data-xref="马可福音 10:21; 路加福音 18:22; 路加福音 12:33"> 耶稣对他说：“如果你想要圆满，<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="这里的圆满，是指想法满足或达成。">g</a></sup>就变卖你的所有分给穷人，你在天国便必有财宝，而且你要跟从我。”</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 6:24; Ezekiel 33:31; 马太福音 13:22"> 那青年听见这话，就满脸忧愁地离开了，原来他很富有。</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太前书 6:9–10; 马太福音 13:22; 马可福音 10:23"> 耶稣对门徒说：“告诉你们真相，有钱人很难进入天国。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 5:44; 路加福音 18:25; 马可福音 10:24–25"> 我还要告诉你们，骆驼穿过针眼，比有钱的人进上帝之国还容易！”</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 10:13; 马太福音 24:22; 罗马书 11:5–7"> 门徒听此甚为惊奇，于是询问：“如果这样，谁会被拯救呢？”</span>
<span className="v" id="v26" data-v="26" data-xref="Jeremiah 32:27; 路加福音 1:37; Job 42:2"> 耶稣看着他们说：“从人的角度是不可能，但对上帝而言一切皆可实现。”</span>
<span className="v" id="v27" data-v="27" data-xref="腓立比书 3:8; 路加福音 18:28; 路加福音 5:11"> 彼得回答：“你看，我们已舍弃一切跟随你，我们会得到什么回报？”</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 22:28–30; 哥林多前书 6:2–3; 马太福音 25:31"> 耶稣对他们说：“告诉你们真相，待万物重建，人子坐于其荣耀宝座，跟从我之人也会坐在十二个宝座上，审判以色列的十二个 支派。</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 18:29–30; 马可福音 10:29–30; 腓立比书 3:8"> 凡因为我而放弃房屋、兄弟、姊妹、父母、儿女或田地，到时候必得百倍，获得永生。</span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 20:16; 路加福音 13:30; 马可福音 10:31"> 有许多先来者将在后，很多后来者将在前。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 20:1–16; 马太福音 12:43–45; 路加福音 14:16"> 耶稣又讲述了一个比喻：</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 19:7–9; 马太福音 13:24; 以弗所书 5:24–32"> “天国好比一个王，为儿子摆设婚筵。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 22:17; 约翰福音 5:40; 路加福音 14:15–17"> 他派仆人去请受邀之人来参加婚筵。但他们不肯来。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 13:46; 马太福音 21:36; 约翰福音 6:50–57"> 他再派另一些仆人去，对他们说：‘告诉那些受邀之人，我已经预备好了筵席，宰杀了公牛和肥畜，一切都预备妥当。来参加婚筵吧！’</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 2:3; 路加福音 14:18–20; 约翰一书 2:15–16"> 但那些人却不理会这番邀请，掉头走开，有的去耕田，有的去做买卖，</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 15:19–20; 约翰福音 16:2–3; 使徒行传 7:51–57"> 还有些人抓住王的仆人，凌辱他们，把他们杀了。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 19:27; 彼得前书 4:17–18; 路加福音 21:24"> 王怒火中烧，派兵消灭那些凶手，焚毁他们的城。</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦后书 1:5; 使徒行传 13:46; 启示录 3:4"> 然后对仆人说：‘婚筵已经预备好了，只是受邀之人不配来此。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 14:21–24; Proverbs 1:20–23; 马可福音 16:15–16"> 你们去大路口站着，邀请所有遇见之人来参加婚筵。’</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 6:9–11; 启示录 19:6–9; 哥林多后书 12:21"> 那些仆人走到街上，把所有遇见之人，无论好坏，都招聚而来，很快婚筵就满座了。</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 3:4–5; 启示录 19:8; 希伯来书 4:12–13"> 王进来与赴筵之人见面，发现一人没有穿着婚筵的礼服，</span>
<span className="v" id="v12" data-v="12" data-xref="1 Samuel 2:9; Job 5:16; 马太福音 20:13"> 于是王就对他说：‘朋友，你没有婚筵礼服，怎能进入这里？’那人无话可说。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 8:12; 马太福音 25:30; 马太福音 24:51"> 于是王对侍从说：‘把他的手脚都绑起来，丢到黑暗中，在那里必有哀哭切齿。’</span>
<span className="v" id="v14" data-v="14" data-xref="彼得后书 1:10; 路加福音 13:23–24; 马太福音 7:13–14"> 因为受邀人很多，但很少是他选择之人。”</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 20:20–26; 马可福音 12:13–17; Psalms 2:2"> 法利赛人离开了，聚在一起商量，怎样通过耶稣所说的话来陷害他。</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 3:6; 马可福音 8:15; 马可福音 12:14"> 他们派了自己的门徒和希律党的门徒一同去问耶稣：“老师，我们知道你为人诚实，你所传授上帝之道皆为真理。你不允许任何人影响你，不在乎头衔或地位。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 2:1; 罗马书 13:6–7; 马太福音 17:25"> 那么请说说你的看法：纳税给凯撒，可不可以？”</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 8:6; 路加福音 5:22; 约翰福音 2:25"> 耶稣看出他们的恶意，就说：“虚伪的人，为什么试探我？</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 20:2; 启示录 6:6; 马太福音 18:28"> 把纳税的钱币给我看看。”他们拿了一个银币<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="罗马银币，用于支付罗马人规定的税负。">a</a></sup>递给耶稣。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 20:24"> 耶稣问他们：“这上面是谁的头像，谁的名号？”</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 13:7; Proverbs 24:21; 使徒行传 4:19"> 他们回答：“这是凯撒。” 他就对他们说：“凯撒的就应当归于凯撒，上帝的就应当归于上帝。”</span>
<span className="v" id="v22" data-v="22" data-xref="马可福音 12:12; 马太福音 22:46; 路加福音 20:25–26"> 这话让他们分外震惊，于是就离开他走了。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 4:1; 马可福音 12:18–27; 使徒行传 23:6–8"> 撒都该人从来不相信复活。那天晚些时候，他们前来问耶稣：</span>
<span className="v" id="v24" data-v="24" data-xref="Deuteronomy 25:5–10; 路加福音 20:28; Ruth 1:11"> “老师，摩西说如果一个已婚<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="隐喻之意。">b</a></sup>男人死了，没有儿女，他的弟弟就应该娶他的妻子，为哥哥留后。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="见《申命记》25:5-6。">c</a></sup></span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 20:29–33; 马可福音 12:19–23; 希伯来书 9:27"> 以前我们这里有兄弟七人，老大结了婚，没有孩子就死了，留下妻子给他的弟弟。嫁给老二后，老二死了，嫁给老三，老三死了，</span>
<span className="v" id="v26" data-v="26"> 直到最后同样的事情又发生在老七身上。</span>
<span className="v" id="v27" data-v="27"> 最后那女人也死了。</span>
<span className="v" id="v28" data-v="28"> 那么复活的时候，她会是这七兄弟中哪人的妻子呢？因为他们都娶过她。”</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 20:9; 罗马书 15:4; 路加福音 1:37"> 耶稣回答：“你们错在不明白圣经，也不知道上帝的能力。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 20:34–36; 马可福音 12:24–25; 马太福音 24:38"> 复活之后，人们不娶也不嫁，就像天堂的天使一样。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 12:3; 马太福音 21:16; 马太福音 21:42"> 关于逝者复活之事，难道你们没读过上帝所说：</span>
<span className="v" id="v32" data-v="32" data-xref="Exodus 3:6; 马可福音 12:26–27; 路加福音 20:37–38"> ‘我是亚伯拉罕的上帝，以撒的上帝，雅各的上帝’，上帝并非死人之上帝，而是活人之上帝。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《出埃及记》3:6。">d</a></sup></span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 12:17; 马可福音 6:2; 约翰福音 7:46"> 民众听了他所说的，对其教义感到很惊异。</span>
<span className="v" id="v34" data-v="34" data-xref="马可福音 12:28–31; 马太福音 25:3–5; 马太福音 12:14"> 听说耶稣让撒都该人无言以对，一群法利赛人便跑来提出更多问题。</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 7:30; 路加福音 10:25–37; 路加福音 11:52"> 其中有一个研究法律的专家，试探耶稣说：</span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 12:28–33; 马太福音 5:19–20; 路加福音 11:42"> “老师，律法中哪一条诫命最重要？”</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 12:29–30; 路加福音 10:27; Deuteronomy 6:5"> 耶稣回答：“‘你要全心、全性、全意爱你的主，你的上帝。’<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="引自《申命记》6:5。">e</a></sup></span>
<span className="v" id="v38" data-v="38"> 这是最重要的受要诫命。</span>
<span className="v" id="v39" data-v="39" data-xref="马可福音 12:31; 路加福音 10:27–37; Leviticus 19:18"> 第二条与它相似，那就是：‘要爱人如己。’<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="引自《利未记》19:18。">f</a></sup></span>
<span className="v" id="v40" data-v="40" data-xref="罗马书 13:9; 马太福音 7:12; 约翰一书 4:19–21"> 全部律法和先知之书，均以这两条诫命为根据。”</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 20:41–44; 马可福音 12:35–37; 马太福音 22:34"> 法利赛人聚在一起之时，耶稣问他们：</span>
<span className="v" id="v42" data-v="42" data-xref="Jeremiah 23:5–6; 约翰福音 6:68–69; 马太福音 16:13–17"> “你们对基督的看法如何？他是谁的子孙？”他们回答：“大卫的子孙。”</span>
<span className="v" id="v43" data-v="43" data-xref="2 Samuel 23:2; 启示录 4:2; 马可福音 12:36"> 耶稣又问：“但受到感召后的大卫为何称他为主？他说</span>
<span className="v" id="v44" data-v="44" data-xref="Psalms 110:1; 希伯来书 1:13; 使徒行传 2:34–35"> ‘主对我主说：你坐在我的右边，待我击败你所有敌人。’<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="原意为“将你所有的敌人放在你脚下。”引自《诗篇》110:1。">g</a></sup></span>
<span className="v" id="v45" data-v="45" data-xref="罗马书 1:3–4; 启示录 22:16; 约翰福音 8:58"> 大卫既然称他为主，他怎么又是大卫的子孙呢？”</span>
<span className="v" id="v46" data-v="46" data-xref="马可福音 12:34; 路加福音 20:40; 路加福音 14:6"> 无人能够回答。此后再也没有人敢向他提问。</span>

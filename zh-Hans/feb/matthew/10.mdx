<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="feb" data-translation-id="cmn_feb" data-translation-label="易读圣经" data-book="MAT" data-book-slug="matthew" data-book-name="马太福音" data-chapter="10" data-verses="42">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 9:1–6; 马可福音 3:13–15; 马可福音 6:7–13"> 耶稣叫了十二门徒来，赐给他们力量，可以赶出污灵和医治各种疾病、各种病症。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="马太福音 4:21; 使徒行传 1:13; 路加福音 5:10"> 十二门徒的名字如下：首先是西门（又名彼得）、西门的弟弟安得烈、西庇太的儿子雅各，雅各的弟弟约翰、</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 3:18; 使徒行传 1:13; 马可福音 2:14"> 腓力、巴多罗迈、多马、税吏马太、亚勒腓的儿子雅各、达太、</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 26:14; 马太福音 26:47; 约翰福音 13:2"> 激进派的西门和之后出卖耶稣的加略人犹大。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 4:9; 使徒行传 22:21–23; 2 Kings 17:24–41"> 耶稣让这十二个人出门，嘱咐他们：“不要去异教徒那里，撒玛利亚人的城市也要避开。</span>
<span className="v" id="v6" data-v="6" data-xref="Jeremiah 50:6; Ezekiel 34:6; Isaiah 53:6"> 你们要造访的，是以色列那些迷途之羊。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 28:31; 马太福音 3:2; 路加福音 9:60"> 你们要一边走一边宣扬：天国将近。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 3:6; 路加福音 10:9; 使徒行传 4:30"> 要医治患者，让死人复活，治愈麻风病人，赶走魔鬼。你们免费获得这样的能力，也要免费送给别人。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 22:35; 路加福音 9:3–5; 路加福音 10:4–12"> 你们的口袋中不要携带金、银、铜钱。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 10:7–12; 提摩太前书 5:17–18; 哥林多前书 9:4–14"> 一路不要带着行囊或两件披风，不要穿鞋或带手杖，因为劳作之人值得获得支持。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或“喂养。”">a</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 10:7–8; Job 31:32; Judges 19:16–21"> 无论走进哪座城市或乡村，都要问那里有谁遵循良善之道，然后住一段时间再离开。</span>
<span className="v" id="v12" data-v="12" data-xref="1 Samuel 25:6; 路加福音 10:5–6; 使徒行传 10:36"> 你走进这些人的房屋后，要向他们祝福。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 10:6; Psalms 35:13; 哥林多后书 2:16"> 如果这屋配得上，你们的平安<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“平安”即“祝福”之意。">b</a></sup>就必将落入屋中；如果这屋配不上，你们的平安仍随你而行。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 10:10–11; 使徒行传 18:6; Nehemiah 5:13"> 如果有人不欢迎你们，不听你们的话，那就离开那个房子或那个城，一边走一边抖掉脚上的灰尘。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得后书 2:6; 约翰一书 4:17; 约翰福音 15:22–24"> 实话告诉你，在审判日那天，索多玛和蛾摩拉也不会遭受这么多的痛苦。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 10:3; 腓立比书 2:15; 哥林多前书 14:20"> 现在，我派你们出去，就好比羊走进狼群。所以你们要像蛇一样聪明，像鸽子一样无害。</span>
<span className="v" id="v17" data-v="17" data-xref="马可福音 13:9; 马太福音 23:34; 使徒行传 26:11"> 要小心，因为有人要把你们送到公议会<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“古犹太的最高法院。”">c</a></sup>，会在会堂中鞭打你们。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 5:25–27; 马太福音 8:4; Psalms 2:1–6"> 因为我的缘故，你们还会被带到统治者和君主面前，向他们和异教徒作证。</span>
<span className="v" id="v19" data-v="19" data-xref="Exodus 4:12; 马可福音 13:11–13; 提摩太后书 4:17"> 你们被捕之时，用不着担心说什么和怎么说，因为那时你们必会在恰当之时说出恰当之语。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 21:15; 使徒行传 6:10; 路加福音 12:12"> 因为那时说话之人并非你们，而是你们的天父之灵，他通过你们在说话。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 21:16–17; Micah 7:5–6; 马可福音 13:12–13"> 兄弟会彼此背叛相残，父亲会出卖儿女，儿女要悖逆父母，害死他们。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 24:13; 雅各书 1:12; 启示录 2:10"> 你们坚持到最后，所以会被众人恨恶，然而忍耐到最后必会得救。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 16:28; 使徒行传 8:1; 马可福音 13:26"> 如果有人在城中迫害你们，就逃到其他城去。实话告诉你们，你们还没有走遍以色列各城之前，人子便已到来。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 15:20; 路加福音 6:40; 约翰福音 13:16"> 信徒不能比老师更伟大，奴仆也不能胜过主人。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 11:15; 马太福音 12:24; 马太福音 9:34"> 学生若像老师，奴仆若像主人，就应该感到满足。如果一家之主被称为魔王别西卜，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="即撒旦，死上帝。">d</a></sup>那么他的家人甚至可能会被称作更可怕的名字。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 8:17; 马可福音 4:22; Jeremiah 1:8"> 所以不要怕他们。遮掩之事必会揭露，隐藏之事终将揭晓。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 5:20; 约翰福音 16:13; 约翰福音 16:1"> 我在暗处告诉你们这一切，你们要在光明之处宣讲。你们听见的是耳语，但要在房顶上大声宣扬。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 12:4–5; Isaiah 8:12–13; 启示录 2:10"> 不要害怕那些在身体上杀死你、但不能在精神上的上杀死你的人。相反，要害怕那可以在哥和拿中摧毁你身体和精神上的的人。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="见5:22下的注释。">e</a></sup></span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 12:6–7; Psalms 104:27–30"> 两只麻雀能卖一个铜钱，如果天父不知道，就不会有一只麻雀落在地上。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 12:7; 1 Samuel 14:45; 使徒行传 27:34"> 天父甚至知道你们有多少根头发。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 12:24; Psalms 8:5; 马太福音 6:26"> 所以不要怕，你们比一堆麻雀贵重得多。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="启示录 3:5; 罗马书 10:9–10; 路加福音 12:8–9"> 凡在人前宣布承认<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="原意为“忏悔。”">f</a></sup>我之人，我也会在天父面前承认他，</span>
<span className="v" id="v33" data-v="33" data-xref="提摩太后书 2:12; 路加福音 9:26; 路加福音 12:9"> 凡是在人前不认我的，我在天父面前也不会认他。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 12:49–53; 使徒行传 14:4; 使徒行传 13:45–50"> 你们不要以为我的到来，是为大地带来和平，我并非带来和平，而是刀剑。</span>
<span className="v" id="v35" data-v="35" data-xref="Micah 7:5–6; 马太福音 10:21; 路加福音 21:16"> 我的到来会让父与子对立，女儿与母亲的对立，媳妇与婆婆作对。</span>
<span className="v" id="v36" data-v="36" data-xref="Micah 7:6; Jeremiah 12:6; Psalms 41:9"> 你的敌人将是你的家人。<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="见《弥迦书》7:6。">g</a></sup></span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 14:26; 马太福音 22:37; 腓立比书 3:7–9"> 若你爱父母胜于爱我，便不配属于我；若你爱儿女胜于爱我，便不配属于我；</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 14:27; 马可福音 8:34; 马太福音 16:24"> 如你不背起自己的十字架跟从我，便不配属于我。</span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 12:25; 马可福音 8:35–36; 路加福音 17:33"> 顾惜自己生命，必要失去生命；<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="换言之，只靠你凡人的努力活下去，不算成功。">h</a></sup>但为我牺牲生命，必得生命。</span>
<span className="v" id="v40" data-v="40" data-xref="约翰福音 13:20; 路加福音 9:48; 路加福音 10:16"> 人们欢迎你们，便是欢迎我，接待我之人，便是接待派我前来的天父。</span>
<span className="v" id="v41" data-v="41" data-xref="约翰三书 1:5–8; 希伯来书 6:10; 2 Kings 4:16–17"> 人们如果因为先知的身份而欢迎他们，将获得与先知相同的奖励。人们如果欢迎正道之人，将获得与正道之人相同的奖励。</span>
<span className="v" id="v42" data-v="42" data-xref="希伯来书 6:10; 马太福音 25:40; 马可福音 9:41–42"> 告诉你们实话，一个人如果给我的门徒一杯冰凉的水，即使是我最微不足道的那个门徒，也绝对获得他的赏赐。”</span>
</div>
</div>

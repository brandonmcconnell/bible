<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 3:18; 以弗所书 5:33; 以弗所书 5:22–24"> 妻子们，你们要以同样的方式接受丈夫的权威，只有这样，如果有些丈夫拒绝接受这个词，你仍然可以用无言的行为说服他们，</span>
<span className="v" id="v2" data-v="2" data-xref="彼得前书 2:12; 彼得前书 1:15; 腓立比书 1:27"> 让他们承认你的纯洁和虔诚行为。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前书 2:9–10; 罗马书 12:2; Isaiah 3:18–24"> 不要专注于外在的吸引力，比如发型、黄金首饰或时髦的衣服。</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 3:12; 1 Samuel 16:7; 罗马书 2:29"> 要让你的吸引力来自内心，内在的温柔和平精神，具有持久吸引力。这也是上帝所看重的。</span>
<span className="v" id="v5" data-v="5" data-xref="提多书 2:3–4; 提摩太前书 5:5; 路加福音 2:37"> 过去信上帝的圣洁女性，就是通过这种方式让自己变得美丽，顺服丈夫</span>
<span className="v" id="v6" data-v="6" data-xref="Genesis 18:12; 罗马书 9:7–9; Isaiah 57:11"> 就像撒拉顺从亚伯拉罕，称他为“主。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或“主人。”如今这种关系在婚姻中已很少见到。">a</a></sup>如果你做正确的事而没有被吓倒，你就是她的女儿。</span>
<span className="v" id="v7" data-v="7" data-xref="歌罗西书 3:19; Genesis 2:23–24; 马太福音 19:3–9"> 丈夫们，同样当你和妻子生活在一起，要去体谅她们。虽然她可能没有你那么强有力，但应该尊重她，因为她将与你平等地继承上帝赐予的生命。一定要这样做，这样你在祈祷的时候就不会受到妨碍。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 12:10; 以弗所书 4:31–2; 彼得前书 1:22"> 最后，你们应该有同样的态度。要有同理心，彼此相爱。要有同情心，要谦虚。</span>
<span className="v" id="v9" data-v="9" data-xref="Proverbs 20:22; 罗马书 12:17; 罗马书 12:14"> 不要以恶报恶，也不要在被虐待时反击，而是应该祝福——因为这就是你蒙受召唤要做的，所以你可以自己得到祝福。</span>
<span className="v" id="v10" data-v="10" data-xref="Psalms 34:12–16; 雅各书 1:26; 彼得前书 2:1"> 记住：“那些希望热爱生命之人，想要看见好日子的人，就必须禁止说出恶语，不能说谎；</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 5:9; Psalms 34:14; 希伯来书 12:14"> 要远离邪恶，要做善事，寻找并追求和平。</span>
<span className="v" id="v12" data-v="12" data-xref="Psalms 34:15–16; 约翰福音 9:31; Proverbs 15:29"> 因为主只会看到那些正确做事的人，他的耳朵会听到他们的祈祷；但主会反对那些作恶之人。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引自《诗篇》34:12-16。">b</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="Proverbs 16:7; 罗马书 8:28; 帖撒罗尼迦前书 5:15"> 如果你们热心行善，谁能伤害你们呢？</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 10:28; 彼得前书 2:19–20; 马太福音 5:10–12"> 就算你们因做了正确之事而受苦，也是有福的。不要害怕别人的威胁，不要畏惧。</span>
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 4:6; 提摩太后书 2:25–26; 路加福音 21:14–15"> 你们的思想要专注于基督主。随时准备好，如果有人向你询问你所拥有的的希望，要向他们解释，以温和尊重的方式解释。</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前书 2:12; 希伯来书 13:18; 彼得前书 2:15"> 你的良心务必要是清白的，这样如果有人指控你，就会感到尴尬，因为他们诽谤你在基督那里过着的好生活。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前书 3:14; 彼得前书 4:19; 马太福音 26:39"> 因行善而受苦（如果这是上帝想要的）肯定比因做错而受苦更好！</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 9:28; 希伯来书 9:26; 哥林多后书 5:21"> 耶稣一次性地为罪而死，那完全真实的、良善的和正确的人，为那些坏人而死<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“为不正确的人做正确的事。”在这节经文中，耶稣的死，清除证明了罪不可避免的后果。他以最强烈、最确凿的方式经历了罪的后果，也证明了夺走生命的不是上帝，而是罪本身带来了不可避免的致命后果（见《罗马书》6:23）。">c</a></sup>，这样他就可以把你带到上帝面前。他的身体被杀害了，但他却以灵死而复生。</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前书 4:6; Isaiah 61:1; Isaiah 42:7"> 他去和那些 “被囚禁” 的人谈话<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或 “被囚禁的灵魂。”对这句话有很多争论。用来表示 “灵魂”的词应该注意，第20节中的八个人用的是同一个词。有些人把那些 “被囚禁” 的人理解为洪水时那些被罪性 “囚禁” 的人（见创世记6:5）。">d</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="希伯来书 11:7; 彼得后书 2:5; Genesis 6:3"> 当上帝在诺亚时代耐心地等待着建造方舟的时候，那些拒绝相信的人。只有少数人--事实上是八个人-“通过水” 得救。</span>
<span className="v" id="v21" data-v="21" data-xref="马可福音 16:16; Ezekiel 36:25–26; 使徒行传 2:38"> 现在正拯救你的洗礼，就是这水的象征。并非通过洗掉你身上的污垢，而是来自无愧的良心，是对上帝的积极回应。耶稣基督的复活，让你的救赎成为可能。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 9:24; 希伯来书 12:2; 希伯来书 10:12"> 基督升到天上后，站在上帝的右手边，天使、有权势之人和有能力之人，都服从他。</span>

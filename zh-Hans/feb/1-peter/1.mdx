<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="雅各书 1:1; 使徒行传 2:5–11; 希伯来书 11:13"> 这封信来自耶稣基督的使徒彼得，写给已被上帝选择之人：那些散落流放在本都、加拉太、加帕多家、亚西亚和庇推尼的人。</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦后书 2:13; 以弗所书 1:4–5; 希伯来书 12:24"> 你们被父上帝以其智慧而选中，是灵让你们圣洁，这样你们就可以听从耶稣基督，被他的血撒过。愿你们拥有更多的恩典与平安！</span>
<span className="v" id="v3" data-v="3" data-xref="彼得前书 1:23; 约翰一书 5:4; 罗马书 15:13"> 赞美上帝，我们主耶稣基督之父！通过他伟大的怜悯，我们得以重生；借着耶稣基督死而复生我们被赋予永生的希望。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或者“给我们带来生命的希望。”">a</a></sup></span>
<span className="v" id="v4" data-v="4" data-xref="启示录 21:27; 希伯来书 9:15; 彼得前书 5:4"> 这传承是永恒的，永远不会朽坏或消失，会为你们在天堂中安全地保留着。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 1:6; 以弗所书 2:8; 帖撒罗尼迦后书 2:13–14"> 通过你们对上帝的信任，上帝会用他的能力保护你们，直到救赎到来——那是已经准备好在末日显现的救赎。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 1:2; 彼得前书 5:10; 罗马书 12:12"> 因此，你们要为之欢喜。但你们现今经历各种考验的时候，或许暂时会感到难过。</span>
<span className="v" id="v7" data-v="7" data-xref="Job 23:10; Isaiah 48:10; 彼得前书 4:12"> 这些都证明了你们对上帝的信任是真实的，就像用火来证明是否真金，但即使是金子也可以被摧毁，你们的信比金子更有价值！通过这种方式，你们对上帝的信任就会获得认可，当耶稣基督出现时，你们会得到赞美、光荣和尊崇。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 20:29; 哥林多后书 5:7; 罗马书 15:13"> 你们虽然没有见过他，却爱他；现在虽然不能看见他，却信他。所以，你们充满了无法形容、美妙的幸福。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 6:22; 雅各书 1:21; 希伯来书 11:13"> 你们信他的奖励，就是将会得到拯救。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 13:17; 路加福音 10:24; 路加福音 24:25–27"> 先知们说道为你们准备的恩典时，他们寻找和研究的也正是这样的救赎。</span>
<span className="v" id="v11" data-v="11" data-xref="Isaiah 52:13–14; 彼得后书 1:21; 路加福音 24:25–27"> 他们试图找出救赎将在何时以何种方式发生，因为他们中基督的灵，清楚讲述了基督将要遭受的苦难和获得的荣耀。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 15:26; 哥林多前书 2:10; 以弗所书 3:10"> 他们听到的解释是：他们这样做并非为了自己，而是为了你们。因为他们所讲的，你现在已经从那些通过上天派来的圣灵与你分享好消息的人那里学到了。就连天使也急于知道这一切！</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前书 5:8; 路加福音 12:35; 彼得前书 4:7"> 你们的思想务必要准备好。保持头脑清醒。把希望完全寄托于你们在耶稣显现时将会获得的恩典。</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 12:2; 提多书 3:3–5; 彼得前书 4:2–3"> 像那些按照他们吩咐去做的孩子一样生活。当你不知道何为更好，不要让那时候的罪恶欲望左右你们。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 5:48; 哥林多后书 7:1; 希伯来书 12:14"> 现在你们做的每一件事都要是圣洁的，就像那召唤你的人就是圣洁的。</span>
<span className="v" id="v16" data-v="16" data-xref="Leviticus 11:44; Leviticus 19:2; Leviticus 20:7"> 因为经书说：“你们要圣洁，因为我是圣洁的。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引自《利未记》11:44-45或《利未记》19:2">b</a></sup></span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 10:34–35; 2 Chronicles 19:7; 马太福音 6:9"> 既然你们称他为父，意识到他会根据每个人的所作所为公正评判每个人，请认真对待你们在地球上的时间，尊重他。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 6:20; 提多书 2:14; Psalms 49:7–8"> 你们已经知道，你们并没有摆脱从祖先那里继承的无意义生活方式，这些都是是没有持久价值的东西，比如金银。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 1:7; 彼得前书 2:22–24; 约翰福音 1:29"> 你们因基督宝贵的血而获得自由，他就像一只没有瑕疵或缺陷的羔羊。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 1:4; 提摩太后书 1:9–10; 希伯来书 9:26"> 基督是在创世之前被上帝所挑选，却会在这末世<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或者“在时间的尽头。”">c</a></sup>为你们的好而显现。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 2:24; 希伯来书 2:9; 约翰福音 12:44"> 通过他，你们信那让基督死而复生并让他荣耀的上帝，这样你们就可以对上帝有信心，有希望。</span>
<span className="v" id="v22" data-v="22" data-xref="提摩太前书 1:5; 希伯来书 13:1; 罗马书 12:9–10"> 既然你们已经按照真理奉献了自己，那就像真正的家人一样真诚地相爱。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或“以兄弟之爱。”">d</a></sup></span>
<span className="v" id="v23" data-v="23" data-xref="彼得前书 1:3; 希伯来书 4:12; 约翰福音 1:13"> 你已经重生了，不是必死的 “种子”<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="这里想要表现的是：不同“种子”产生不同种类的“生命。”">e</a></sup>的产物，而是不死的种子，通过神的活的、永恒的话语</span>
<span className="v" id="v24" data-v="24" data-xref="Isaiah 40:6–8; Psalms 103:15; 雅各书 4:14"> 因为：“所有人皆如草，他们的荣光如野花；草必枯干，花必凋谢，</span>
<span className="v" id="v25" data-v="25" data-xref="Isaiah 40:8; 马太福音 5:18; Psalms 119:89"> 但只有主的道，永远长存。”<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="引自《以赛亚书》40:6-8。">f</a></sup>这就是向你们解释的福音。</span>
</div>

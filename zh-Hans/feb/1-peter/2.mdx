<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以弗所书 4:31; 雅各书 1:21; 雅各书 4:11"> 所以要放弃你们做的所有邪恶之事：所有的不诚实、虚伪和嫉妒，所有你们诽谤别人的方式。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 5:12–13; 以弗所书 4:15; 彼得后书 3:18"> 你们应该变得像那只需要纯净灵奶的新生婴儿，这样才能在救赎中成长，</span>
<span className="v" id="v3" data-v="3" data-xref="Psalms 34:8; 希伯来书 6:5–6; Psalms 63:5"> 现在你们已经品尝到了主是多么的良善。</span>
<span className="v" id="v4" data-v="4" data-xref="Psalms 118:22–23; 使徒行传 4:11–12; 彼得前书 2:7"> 因为你们来到他面前——他是曾被人们拒绝、视为无用的活石，但被上帝所选和珍视。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 2:20–22; 彼得前书 2:9; 哥林多前书 3:9"> 你们也要变得像活石一样，被建造成一座灵的家。你们是神圣的祭司，通过耶稣基督向上帝献上他喜欢的灵之献祭。</span>
<span className="v" id="v6" data-v="6" data-xref="Isaiah 28:16; 罗马书 9:32–33; 彼得前书 2:4"> 因为经书<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《以赛亚书》28:16。">a</a></sup>上说：“看哪！我在锡安放了一块特别选择、价值非凡的主基石。信他的人必不会失望。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或“羞愧。”">b</a></sup></span>
<span className="v" id="v7" data-v="7" data-xref="Psalms 118:22–23; 马可福音 12:10–11; 使徒行传 4:11–12"> 他对真信的你很有价值。但对于那些不信的人来说，“建造者拒绝的石头成为主要的基石”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《诗篇》118:22。">c</a></sup>，</span>
<span className="v" id="v8" data-v="8" data-xref="Isaiah 8:14; 哥林多前书 1:23; 罗马书 9:32–33"> 还说这是“绊倒你的石头和让你跌倒的石头。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《耶利米书》8:14。">d</a></sup>人们因为拒绝接受这条信息而走得跌跌撞撞——这对他们来说，是完全可以预见的。</span>
<span className="v" id="v9" data-v="9" data-xref="Exodus 19:5–6; Deuteronomy 7:6; 启示录 1:6"> 恰恰相反，你们是一个特别选中的家庭，拥有皇家祭司的身份，是一个圣洁的国家，是属于上帝的子民。因此，你们可以显现上帝做过的神奇之事，将你们从黑暗中召唤到他神奇的光之中。</span>
<span className="v" id="v10" data-v="10" data-xref="Hosea 2:23; 希伯来书 4:16; Hosea 1:9–10"> 过去你们是无名之辈，但现在你们是上帝的子民。过去你们未曾获得怜悯，但现在你们获得了怜悯。</span>
<span className="v" id="v11" data-v="11" data-xref="约翰一书 2:15–17; 加拉太书 5:24; 彼得前书 4:2"> 我的朋友们，作为这个世界上的外族人和陌生人，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="“外族人和陌生人”——不把这个世界视为家。">e</a></sup>我恳求你们不要屈服于那与灵冲突的物质欲望。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 3:16; 马太福音 5:16; 提多书 2:7–8"> 当你们与非基督徒在一起时，一定行动恰当。只有这样，即使他们指责你做错了，他们也会看到你所做的好事，在上帝来临时荣耀上帝。<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="原意为“探访日。”">f</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="提多书 3:1; 罗马书 13:1–7; 提摩太前书 2:1–2"> 你们为了主而顺从人的权威，无论是最高权威的君王，</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 13:3–4"> 还是上帝任命去惩罚罪恶之人，表扬善良的官员。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 3:17; 提多书 2:8; 马太福音 7:26"> 通过做良善正确之事，上帝希望你们让那做出无知指控的愚昧之人闭嘴。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太书 5:13; 罗马书 6:22; 罗马书 6:18"> 是的，你们是自由的人，但不要用自由掩饰邪恶，要像上帝的仆人一样生活。</span>
<span className="v" id="v17" data-v="17" data-xref="Proverbs 24:21; 罗马书 12:10; 罗马书 13:7"> 要尊重众人，向信徒社区表达你的爱，要尊重上帝，尊敬君王。</span>
<span className="v" id="v18" data-v="18" data-xref="提多书 2:9–10; 以弗所书 6:5–7; 歌罗西书 3:22–25"> 如果你是仆人，就要听从你的主人——不仅听从那良善的好主人，也要听从那些严厉的主人。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 5:10–12; 彼得前书 3:14–17; 彼得前书 2:20"> 因为这就是恩典：忍受生活的痛苦以及不公平带来的苦难，只关注上帝。</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前书 2:19; 彼得前书 3:17; 马太福音 5:10–12"> 但是，如果你是因为做错事而受到惩罚，就没有任何功劳。如果你是做善事和正确的事而受苦，你忍受了它，那么上帝的恩典就与你同在。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 2:6; 马太福音 16:24; 约翰福音 13:15"> 事实上，这是你被召唤要做的，因为基督为你们受苦，给你们竖立榜样，所以你们应该追随他的脚步。</span>
<span className="v" id="v22" data-v="22" data-xref="Isaiah 53:9; 哥林多后书 5:21; 希伯来书 4:15"> 他从不犯罪，从不撒谎；<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="引自《以赛亚书》53:9。">g</a></sup></span>
<span className="v" id="v23" data-v="23" data-xref="Isaiah 53:7; 彼得前书 4:19; 希伯来书 12:3"> 当他受到虐待时，没有反击。当他受苦时，并没有威胁要报复。他只是将自己放在那总能正确判断之人的手中。</span>
<span className="v" id="v24" data-v="24" data-xref="Isaiah 53:4–6; 马太福音 8:17; 罗马书 6:11"> 他在十字架上，以自己的身体承担了我们罪的后果，以便让我们对于罪而言已经死了，可以良善公正地活着。<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="“我们罪的后果”：这是罪的结果，因耶稣的死而得到证明。罪本身无法转变——它们是由罪人犯下，不能传递给任何人或其他任何东西，因为罪是某个罪人的具体行为。">h</a></sup>“因着他的伤，你们得到治愈。”<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="引自《以赛亚书》53:5，解释了救赎就是医治那些让我们死、罪所带来的痛苦，而不是上帝对律法进行重新调整，或向其支付金钱。">i</a></sup></span>
<span className="v" id="v25" data-v="25" data-xref="Isaiah 53:6; Ezekiel 34:6; 路加福音 15:4–6"> 你们过去就像迷路的羊，<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="见《以赛亚书》53:6。">j</a></sup>但现在已经回到看官你们的牧人那里了。</span>
</div>

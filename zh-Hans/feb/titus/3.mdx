<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 13:1–7; 彼得前书 2:13–17; Ecclesiastes 10:4"> 你要提醒他们，遵从掌权人让他们做的，服从权力。他们应该随时准备做任何善事。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 4:31; 提摩太后书 2:24–25; 以弗所书 4:2"> 他们不应该毁谤其他人，不要与他人争论，要向所有人显示温柔和礼貌。</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所书 2:1–3; 罗马书 6:17; 歌罗西书 1:21"> 曾几何时，我们也很无知、不顺服。我们受到蛊惑，成为各种私欲和享乐的奴隶，我们过着邪恶的生活，到处都是嫉妒和愤愤、彼此憎恨的人，</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以弗所书 2:4–10; 提多书 2:10–11; 提摩太前书 4:10"> 但当我们的救世主上帝显示其良善和慈爱，他拯救我们</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 2:8–9; 提摩太后书 1:9; 哥林多前书 6:11"> 不是因为我们做了什么善事，而是出于他的怜悯。他通过重生的洁净和全新的圣灵实现这一点，</span>
<span className="v" id="v6" data-v="6" data-xref="Joel 2:28; 罗马书 5:5; 使徒行传 10:45"> 通过我们的救世主耶稣基督，将圣灵大量倾注于我们身上。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:17; 提多书 2:11; 哥林多前书 6:11"> 既然我们因他的恩典而变得良善正直，就可以凭着对永生的希望成为他的后代。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="提多书 3:14; 提多书 1:9; Psalms 16:2–3"> 你应该相信我说的这番话，希望你能强调这些指导，让那些相信上帝的人可以认真思考自己，认真做善事；这些都很重要，对所有人都有益。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太后书 2:14; 提摩太后书 2:23; 提摩太前书 4:7"> 避免进行毫无意义的讨论，不要迷恋家谱, 不要争论，不要对犹太律法争吵，这都是毫无用处的，完全没有帮助。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 16:17; 约翰二书 1:10; 马太福音 18:15–17"> 警告哪些曾造成不和的人，就像之前说的那样，之后就不要在关注他们了。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 10:26; 路加福音 19:22; 马太福音 25:26–28"> 要意识到，他们已经背道，是罪人，他们定了自己的罪。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="提摩太后书 4:9; 提摩太后书 4:12; 哥林多前书 16:8–9"> 我派亚提马或推基古到你那里去时，你要赶快到尼哥波立来见我，因为我已决定在那里过冬。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 18:24; 马太福音 22:35; 约翰三书 1:6–8"> 你要尽可能帮助西纳律师和亚波罗的旅程，让他们备好所有必须的物品。</span>
<span className="v" id="v14" data-v="14" data-xref="歌罗西书 1:10; 提多书 3:8; 马太福音 7:19"> 希望我们自己人可以学习做善事的习惯，满足他人的日常需要，他们需要做出贡献！</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太前书 1:5; 以弗所书 6:23–24; 约翰二书 1:1–2"> 和我在一起的所有人都向你问候。请把我最美好的祝福送给那些我们的人，那些相信上帝的人。愿恩典与你们所有人同在。</span>
</div>
</div>

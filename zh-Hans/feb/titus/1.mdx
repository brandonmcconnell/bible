<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 1:1; 提摩太前书 6:3; 提摩太后书 2:25"> 这封信来自上帝的仆人、耶稣基督的使徒保罗。我发送这封信，是为了建立上帝所选子民的信心，并分享可以让我们为上帝而活的真理知识。</span>
<span className="v" id="v2" data-v="2" data-xref="Numbers 23:19; 约翰一书 2:25; 提摩太后书 1:9"> 这给了他们永生的希望，这永生是从不说谎的上帝很久以前承诺的。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前书 1:11; 提多书 3:4–6; 提摩太前书 1:1"> 在适当的时候，上帝就按照福音的宣讲，显现他的道。这宣讲也是我遵循主上帝的命令，在他的委托下讲述给你们。</span>
<span className="v" id="v4" data-v="4" data-xref="提摩太后书 1:2; 犹大书 1:3; 彼得后书 1:1"> 这封信是寄给提多的，他是我真正的儿子，通过我们共同对上帝的信任。愿你们拥有来自父上帝和救世主基督耶稣的恩惠和平安。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 14:23; 提摩太前书 1:3; Ecclesiastes 12:9"> 我过去之所以把你留在克里特岛，是要你办好需要完成的事，照我所说的在各城任命长老。</span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前书 3:2–7; 提摩太前书 3:12; 提多书 1:6–8"> 长老的人选必须拥有良好声誉，有一名妻子，儿女都信主，没有人控告其放荡或不服从。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 5:18; 彼得后书 2:10; 彼得前书 4:10"> 作为上帝的领导者，大长老必须拥有良好的声誉，不能傲慢自大、不能随便动怒、不好酒、不打人、不贪不义之财。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太前书 3:2; 提多书 2:7; 1 Kings 5:7"> 他要热情好客, 喜爱好的事情，做良善正直的事情。他应为上帝而活，应该自我控制，</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦后书 2:15; 提摩太后书 1:13; 提摩太前书 6:3"> 必须将自己奉献给那所传授的、值得信赖的道。这样他能以正确的教导鼓励他人，说服那些不同意的人。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 1:6; 约翰一书 4:1; 加拉太书 2:4"> 因为周围有很多背叛者，他们说了很多没有意义的欺骗之语，尤其是来自奉行割礼的那群人。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="即那些认为割礼是救赎不可缺少环节的犹太信徒。">a</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="提摩太后书 3:6; 提摩太前书 6:5; 罗马书 3:19"> 他们的言论必须停止。这些人让整个家庭陷入混乱，为了赚钱而进行错误的传授。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 16:18; 提摩太前书 4:2; 使徒行传 17:28"> 他们自己人中就有一个先知说过<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="不一定是指信奉割礼派的群体或其他不同政见者团体，而是来克里特岛的某个人。">b</a></sup>：“克里特人总爱说谎，他们就是懒惰而贪婪的恶兽。”</span>
<span className="v" id="v13" data-v="13" data-xref="提多书 2:2; 提摩太前书 5:20; 提多书 2:15"> 这说的是真的。因此，你要严厉地责备他们，让他们用健全的方式相信上帝，</span>
<span className="v" id="v14" data-v="14" data-xref="提摩太后书 4:4; 歌罗西书 2:22; 加拉太书 4:9"> 不再理会犹太人的无稽之谈和偏离正道之人的说法。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 14:14; 罗马书 14:20; 哥林多前书 10:23"> 对于心灵洁净之人，一切都是洁净；但对于污秽和不信上帝的人，一切都不洁净，连他们的思想和良心都是污秽的。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰一书 2:4; Isaiah 29:13; 以弗所书 5:6"> 他们声称知道上帝，行为却显示并非如此。他们是可憎的、悖逆的，做任何善事都毫无用处。</span>

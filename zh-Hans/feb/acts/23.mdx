<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="feb" data-translation-id="cmn_feb" data-translation-label="易读圣经" data-book="ACT" data-book-slug="acts" data-book-name="使徒行传" data-chapter="23" data-verses="35">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 24:16; 提摩太后书 1:3; 哥林多后书 1:12"> 保罗毫不躲避地看着公议会成员，说：“各位兄弟，此前我一直都凭着良心在上帝面前行事。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="约翰福音 18:22; 使徒行传 24:1; Micah 5:1"> 大祭司亚拿尼亚命令保罗身边的侍从，对他进行掌掴。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="Deuteronomy 25:1–2; 约翰福音 7:51; 马太福音 23:27–28"> 保罗对他说：“你们这粉饰的墙啊，上帝会惩罚你们！你坐在那里按律法审判我，现在竟然违背律法命人打我吗？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 站在保罗身边的侍从说：“你胆敢辱骂上帝的大祭司吗？”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="Exodus 22:28; Ecclesiastes 10:20; 犹大书 1:8–9"> 保罗说：“兄弟们，我不知道他是大祭司。因为经文中说：‘不可咒诅民众的统治者。’”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《出埃及记》22:28。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 24:15; 使徒行传 24:21; 使徒行传 26:5–8"> 保罗发现公议会中有撒都该人，还有法利赛人。于是就大声说：“兄弟们，我是法利赛人，也是法利赛人的子孙，我现在受审是因为我盼望死人能够复活！”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="Psalms 55:9; 约翰福音 7:40–43; 马太福音 10:34"> 他说完这番话，法利赛人和撒都该人之间产生了分歧，公议会的意见分成了两派。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 20:27; 马太福音 22:23; 马可福音 12:18"> （法利赛人相信死而复生、天使和灵，但撒都该人却完全不相信。）</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 22:7; 使徒行传 22:17–18; 约翰福音 12:29"> 现场出现了一阵骚乱，几名法利赛派的宗教老师站起来，激烈地辩论道：“我们看不出这人有罪，可能灵或天使真的和他说过话。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="雅各书 1:19; 雅各书 3:14–2; 使徒行传 22:24"> 争论越来越激烈，千夫长担心反对者可能会伤害保罗，于是就吩咐士兵去把他从人群中救出来，带到了军营中。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 18:9; 使徒行传 19:21; 提摩太后书 4:17"> 当天晚上，主站在保罗身边，对他说：“保持这样的勇气！你在罗马为我作证的方式，要和你在耶路撒冷所做的一样。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 23:30; Isaiah 8:9–10; 使徒行传 23:21"> 第二天，一些犹太人一起策划杀死保罗的计划。他们还发誓，不杀保罗，不吃不喝。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 16:2; 2 Samuel 15:31; 2 Samuel 15:12"> 共有四十多人参与了这项阴谋。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="使徒行传 23:12; Jeremiah 8:12; Isaiah 3:9"> 他们来见祭司长和长老，说：“我们已经郑重发誓，不杀保罗，不吃不喝。</span>
<span className="v" id="v15" data-v="15" data-xref="Isaiah 59:7; Psalms 37:32–33; Proverbs 1:16"> 你们和公议会应该给千夫长捎个口信，把保罗带到你们这里来。你们装作想要更详细地审问他，我们在路上会随时准备杀了他。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行传 23:10; 哥林多前书 3:19; 使徒行传 23:32"> 但保罗的外甥（他姐妹的孩子）却听到了这次伏击的诡计，于是就跑到军营去告诉保罗。</span>
<span className="v" id="v17" data-v="17" data-xref="Proverbs 22:3; 马太福音 8:8–9; 马太福音 10:16"> 保罗让人叫来一位百夫长，对他说：“请你带这位青年人去见千夫长，他有事禀报。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以弗所书 3:1; 以弗所书 4:1; 使徒行传 28:17"> 百夫长带着保罗的外甥去见千夫长，说：“犯人保罗求我带这位青年人来见你，他有事禀报。”</span>
<span className="v" id="v19" data-v="19" data-xref="Jeremiah 31:32; Esther 9:12; Esther 7:2"> 千夫长拉着青年人的手走到一边，私下问他：“有什么事要报告？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="使徒行传 23:14–15; 使徒行传 23:1; Psalms 12:2"> 保罗外甥说：“犹太人已经密谋好了，明天会让你把保罗带到公议会，装作想要更详细地审问他。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 23:12–14; 使徒行传 14:5–6; 哥林多后书 11:26"> 别听他们的，因为有四十多人正准备偷袭保罗。他们已经发了誓，不杀保罗，不吃不喝。他们现在已经准备好了，就等你同意他们的要求了。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马可福音 1:44; Joshua 2:14"> 千夫长嘱咐那青年人：“不要对别人说，你把这事告诉了我。”然后就让他走了。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 14:25; 使徒行传 23:33; 路加福音 12:38"> 千夫长叫来两名百夫长，说：“准备好两百名步兵、七十名骑兵和两百个长枪手，晚上九点钟去该撒利亚。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 25:14; 使徒行传 23:26; 使徒行传 24:10"> 还要为保罗准备可以骑的马匹，护送他安全到达腓力斯总督那里。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 千夫长写了一封信，大意如下：</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 15:23; 使徒行传 26:25; 路加福音 1:3"> “尊敬的费利克斯总督，请接受克劳迪乌斯·莱修斯的问候！</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 22:25–29; 使徒行传 21:31–33; 使徒行传 24:6"> 犹太人把这人捉住并打算杀害他，我听说他是罗马公民，就带领士兵把他救了出来。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 22:30"> 为了知晓犹太人控告他的原因，我就把他带到了公议会。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 26:31; 使徒行传 25:25; 使徒行传 18:15"> 我发现他被控告，是关于他们律法上的问题，但并没有应该判处死刑或入狱的罪名。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 23:35; 使徒行传 25:16; 使徒行传 25:5–6"> 后来我发现了有人想要密谋杀害他，就立刻把他送到你那里去，命令那些原告在你面前进行指控。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="提摩太后书 2:3–4; 路加福音 7:8; 使徒行传 23:23–24"> 于是士兵们听命把保罗带了出来，连夜带到安提帕底。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 23:23; 使徒行传 23:10"> 第二天早晨，他们便派骑兵队把保罗送走，士兵就回了军营。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="使徒行传 23:26; 使徒行传 23:23–24; 使徒行传 28:16"> 骑兵队抵达该撒利亚后，把信和保罗都交给了总督。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 21:39; 使徒行传 25:1; Daniel 2:49"> 总督读罢信后问保罗来自哪个省。在得知他是基利家人后，</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 23:30; 使徒行传 25:16; 马太福音 27:27"> 就说：“等到原告到了之后，我就会审问你。”然后命令人把他拘禁在希律的王府中。</span>
</div>
</div>

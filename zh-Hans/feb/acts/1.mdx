<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 1:3; 路加福音 24:19; 马太福音 4:23–24"> 尊敬的提阿非罗先生<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="意为“爱上帝的人”，可以是一个具体的人，也可能是更广泛的含义。这里所说的“上一本书”是路加福音。">a</a></sup>：在上一本书中，我从最初开始讲述了耶稣所行之事和所授之道，</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 1:9; 约翰福音 20:21; Isaiah 59:20–21"> 一直写到他通过圣灵向所选择的使徒发出指示，然后被带入天堂。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 15:5–7; 使徒行传 13:31; 约翰福音 20:26"> 在他受难以后的四十天中，他又向使徒们显现，以令人信服的证据证明他仍然活着，还向使徒们讲述了上帝之国的一切。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 24:49; 约翰福音 14:16; 约翰福音 15:26"> 当他与使徒们<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或“当他与他们共同用餐时。”">b</a></sup>同在人间时，曾吩咐他们：“不要离开耶路撒冷，要等候天父承诺给予你们的，正如你们从我这里听到的。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 3:11; 使徒行传 11:15–16; 路加福音 3:16"> 约翰用水施洗，但在几天后，你们就会接受圣灵的施洗。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="路加福音 19:11; 路加福音 17:20; Daniel 7:27"> 所以当使徒们与复活后的耶稣相见时，便询问耶稣：“主啊，你打算现在就恢复以色列王国吗？”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 24:36; 帖撒罗尼迦前书 5:1–2; 马可福音 13:32"> 耶稣回答：“只有天父有权决定这个日期和时间，你们不必知道。</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 28:19; 马可福音 16:15; 罗马书 15:19"> 但当圣灵降临在你们身上，你们就会获得力量，要在耶路撒冷、犹太全地、撒玛利亚乃至大地的极点，作我的见证人。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="Daniel 7:13; 路加福音 24:50–51; 马可福音 16:19"> 说罢，他就在使徒们的目视下腾空而起，随后被一朵云遮住了踪迹，再也无法看到。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 24:4; 约翰福音 20:12; 启示录 7:14"> 正当使徒们专心地望着耶稣升天之时，忽然出现两名白衣之人，站在他们旁边，</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 1:7; 帖撒罗尼迦前书 4:16; 马可福音 13:26"> 他们问：“加利利人，你们为什么站在这里望天？这位离开你们去天堂的耶稣，将会以你们所目睹他进入天堂的方式，回到你们身边。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="路加福音 24:52; 马太福音 21:1; 路加福音 24:50"> 后来，使徒们从橄榄山回到耶路撒冷，两者之间的距离大约是安息日步行那么远。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="换言之，距离相对比较短。">c</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 20:8; 路加福音 22:12; 马可福音 14:15"> 来到目的地后，他们来到了下榻之所，需要通过楼梯来走到楼上。他们是：彼得、约翰、雅各、安得烈、腓力、多马、巴多罗迈、马太、亚勒腓的儿子雅各、激进派的西门、雅各的儿子犹大。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 6:4; 以弗所书 6:18; 歌罗西书 4:2"> 使徒们开始进行祷告，与他们一起的还有几名女性以及耶稣的母亲玛利亚和他的兄弟们。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 15:6; 使徒行传 21:20; 启示录 3:4"> 这时候大约有 120 名信徒聚在一起，彼得站起来向众人发言：</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="Psalms 41:9; 约翰福音 13:18; Psalms 55:12–15"> “兄弟姐妹们，圣灵在经文上借大卫之口，讲述了犹大带人捉拿耶稣的事，一定会应验。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 1:25; 马可福音 3:19; 约翰福音 17:12"> 他本是我们中间的一员，共同承担这份侍奉之责。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 27:3–10; 马太福音 26:14–15; Psalms 55:23"> （犹大用这笔不义之财买了一块田，后来在田间一头倒了下去，身体裂开，内脏全部流了出来。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 2:22; 马太福音 28:15; 使徒行传 21:40"> 住在耶路撒冷的人都知道这件事，所以那块地也被称作“亚革大马”，当地语言的意思就是“血田”）。</span>
<span className="v" id="v20" data-v="20" data-xref="Psalms 69:25; Psalms 109:8–15; 使徒行传 1:25"> 《诗篇》中曾写到：“让他的住处变为荒芜，无人居住。”还写到：“让别人取代他的侍奉之责。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《诗篇》69:25和《诗篇》109:8。">d</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约翰福音 15:27; 路加福音 10:1–2; Numbers 27:17"> “所以，我们必须再选择一名使徒，他全程一直与我们在一起，</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 1:2; 使徒行传 4:33; 使徒行传 1:8–9"> 从约翰施洗开始，直到耶稣离开我们升入天堂。我们必须选择这样一个人与我们一起，做为耶稣复活的见证人。”</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 15:22; 使徒行传 1:26"> 于是他们选择了两个人：约瑟（又名巴撒巴）和马提亚，</span>
<span className="v" id="v24" data-v="24" data-xref="1 Samuel 16:7; 使徒行传 15:8; 希伯来书 4:13"> 然后众人开始共同祷告：“主啊！你知道每个人的想法,<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="“你知道每个人的想法”，原意为“知心之人。”">e</a></sup>请指示你希望从这两人中选择谁，</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多前书 9:2; 约翰福音 6:70–71; 约翰福音 17:12"> 来承担这使徒的侍奉之责。犹大已放弃这责任，去了他该去的地方。”</span>
<span className="v" id="v26" data-v="26" data-xref="Leviticus 16:8; Joshua 18:10; 1 Samuel 14:41–42"> 他们开始抽签，结果抽中了马提亚，于是他加入了另外 11 名使徒之列。</span>
</div>
</div>

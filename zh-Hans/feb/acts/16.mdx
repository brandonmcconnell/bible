<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太后书 1:5; 提摩太后书 1:2; 哥林多前书 4:17"> 保罗先去了特庇，然后又到了路司得。在那里有一位名叫提摩太的信徒，其母亲是犹太基督徒，父亲则是一名希腊人。</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前书 5:10; 提摩太后书 3:15; 使徒行传 14:21"> 提摩太在路司得和以哥念的兄弟中名声很好，</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 2:3; 哥林多前书 9:20; 加拉太书 5:6"> 保罗希望带上他一同旅行，但由于当地的犹太人都知道他父亲是希腊人，所以他给他行了割礼。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 15:28–29; 使徒行传 15:2; 使徒行传 11:30"> 他们随后便一起去往其他城市，向其他信徒们讲述耶路撒冷使徒和长老所定下的规矩。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 9:31; 使徒行传 2:47; 使徒行传 6:7"> 众教会更坚定地相信主，信徒的数量与日俱增。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 18:23; 使徒行传 16:7; 使徒行传 13:2–4"> 由于圣灵阻止他们在亚西亚传道，于是他们就走遍了弗吕家和加拉太地区。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:9; 腓立比书 1:19; 加拉太书 4:6"> 来到每西亚边境时，他们打算去庇推尼，但耶稣的圣灵不允许他们进入这座城市。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 2:12; 提摩太后书 4:13; 使徒行传 16:11"> 于是他们经由每西亚来到特罗亚。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 9:10–12; 使徒行传 19:21; 使徒行传 18:5"> 保罗在夜里看到了一番异象，一名马其顿人站着恳求他说：“请到马其顿来帮帮我们！”</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 2:12–13; 使徒行传 14:7; 使徒行传 16:10–17"> 保罗见此异象后，我们<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这里改称“我们”，代表书的作者路加也加入他们的行列。">a</a></sup>认为上帝在召唤我们去那里传播福音，于是立刻安排了去往马其顿的行程。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 21:1; 使徒行传 16:8"> 我们从特罗亚乘船直接去了撒摩特拉，第二天又赶往尼亚波利，</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦前书 2:2; 腓立比书 1:1; 使徒行传 20:6"> 从那里去了腓立比，这也是马其顿最重要的城市，同时也是罗马的殖民地，然后在城里住了几天。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 13:14; 歌罗西书 1:23; 使徒行传 17:2"> 安息日那天，由于考虑到人们会到河边祈祷，所以我们出了城去往河边，然后坐下，与聚集在那里的妇女交流。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以弗所书 1:17–18; 路加福音 24:45; Isaiah 50:5"> 其中一位妇女名叫吕底亚，在推雅推拉城众售卖紫色布料，敬仰主的她专心聆听我们的话语。主开启她的心灵，让她留心保罗的言语，接受了他对她的教诲。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 11:14; 希伯来书 13:2; 使徒行传 16:33"> 她和家人受洗之后，就恳请我们：“你们如果认为我是对主一心一意，就请到我家来住吧。”她坚持邀请我们，直到我们答应了这个请求。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="Leviticus 19:31; Deuteronomy 18:9–11; Isaiah 8:19"> 有一天，我们正在去往祈祷的场所，路上遇到一名被恶灵附体的婢女。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为，“蟒蛇灵”，也是占卜灵。">b</a></sup>她因为擅长占卜，为她的主人们赚取丰厚收入。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 14:6; 彼得前书 2:16; 马可福音 5:7"> 这婢女跟在我们身边，大声喊：“这些人是至高上帝的仆人，向你们宣讲如何获得救赎。”</span>
<span className="v" id="v18" data-v="18" data-xref="马可福音 16:17; 路加福音 10:17–19; 使徒行传 3:6"> 她一连几天都这样做，保罗感到不胜其烦，于是转身对那恶鬼说：“以耶稣基督之名，命令你从她身上出来！”那恶鬼就离开了她的身体。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 17:6; 使徒行传 21:30; 使徒行传 8:3"> 但她的主人们看见自己的财路断了，就拉着保罗和西拉去见集市上的长官，</span>
<span className="v" id="v20" data-v="20" data-xref="雅各书 4:4; 约翰福音 15:18–20; 使徒行传 28:22"> 他们将两人带到裁判官面前，说：“这些犹太人人正在扰乱我们的城市。</span>
<span className="v" id="v21" data-v="21" data-xref="Esther 3:8; 使徒行传 26:3; Jeremiah 10:3"> 对于我们罗马人而言，接受或践行他们所鼓吹的事情，是不合法的。”</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒罗尼迦前书 2:2; 哥林多后书 6:5; 哥林多后书 11:23–25"> 民众纷纷攻击他们，裁判官剥去他们的衣服，下令对他们施以棍刑。</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 2:10; 提摩太后书 2:9; 1 Samuel 23:22–23"> 用棍子打了他们以后，就把他们投入监牢，吩咐狱卒看住他们。</span>
<span className="v" id="v24" data-v="24" data-xref="Job 13:27; Job 33:11; Jeremiah 29:26"> 狱卒遵命把他们押入内部的牢房，将他们的两脚拴在木柱上。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="帖撒罗尼迦前书 5:16–18; Psalms 119:62; 雅各书 1:2"> 大约午夜时分，保罗和西拉向上帝祈祷并唱起颂歌，引来其他囚犯们侧耳听着。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 4:31; 使徒行传 5:19; 使徒行传 12:10"> 忽然发生了大地震，震撼了监牢的地基，所有的牢房门立刻打开，囚犯身上的锁链也脱落了。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行传 12:19; 马太福音 27:5; Judges 9:54"> 狱卒醒来后发现牢门全开，以为囚犯都已逃脱了，便拔出刀来想要自刎。</span>
<span className="v" id="v28" data-v="28" data-xref="帖撒罗尼迦前书 5:15; 路加福音 23:34; 路加福音 6:27–28"> 保罗大喊：“别伤害自己，我们都在这里！”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="启示录 3:9; 使徒行传 24:25; Isaiah 60:14"> 狱卒叫人拿来灯，然后冲了进去。看到保罗和西拉，便全身颤抖着俯伏在他们面前。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 2:37; 约翰福音 6:27–29; Isaiah 58:9"> 随后他便护送二人出了监牢，问到：“先生们，我该怎样做才能得救？”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 1:12; 使徒行传 2:38–39; 约翰福音 3:36"> 他们说：“相信主耶稣，你和全家人就会获得救赎。”</span>
<span className="v" id="v32" data-v="32" data-xref="罗马书 1:16; 歌罗西书 1:27–28; 提摩太前书 1:13–16"> 然后，他们就开始向他和全家人宣讲主之道。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 1:16; 使徒行传 16:15; 使徒行传 16:25"> 尽管当时已是深夜，狱卒还是为使徒清洗伤口，然后和家人一起受了洗。</span>
<span className="v" id="v34" data-v="34" data-xref="罗马书 15:13; 使徒行传 2:46; 罗马书 5:11"> 他将使徒们带回家中，为其准备饭菜，他和全家因相信上帝而获得极大的喜悦。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="Jeremiah 5:22; Psalms 76:10; 使徒行传 5:40"> 第二天清晨，裁判官派法警来找狱卒，说：“放了那些人。”</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 15:33; 约翰福音 14:27; 1 Samuel 1:17"> 狱卒对保罗说：“裁判官派人来释放你们，现在你们可以平安地离开了。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒行传 22:25–29; Psalms 58:1–2; 马太福音 10:16"> 但保罗对他们说：“我们是罗马人，但他们在没有审判的情况下就公开殴打我们，将我们投入监牢，现在又想让我们悄悄地走？不行！他们应当亲自来释放我们！”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="使徒行传 22:29; 马太福音 21:46; 马太福音 14:5"> 法警回去报告，裁判官听说保罗和西拉是罗马人，感到很害怕，</span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 8:34; 马可福音 5:17; Daniel 6:23"> 于是跑来向他们道歉，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="未经审判惩罚罗马公民是违法行为。">c</a></sup>亲自护送他们出了监牢，恳请他们离开这座城。</span>
<span className="v" id="v40" data-v="40" data-xref="帖撒罗尼迦前书 3:2–3; 使徒行传 16:14; 使徒行传 14:22"> 两人离开监牢后去了吕底亚的家，在那里见到了其他信徒，鼓舞他们一番后便离开了。</span>
</div>
</div>

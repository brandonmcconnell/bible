<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="feb" data-translation-id="cmn_feb" data-translation-label="易读圣经" data-book="ACT" data-book-slug="acts" data-book-name="使徒行传" data-chapter="10" data-verses="48">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 27:1; 马太福音 8:5–13; 马太福音 27:27"> 在该撒利亚有一人名叫哥尼流，是意大利营的罗马百夫长。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 7:7–8; 使徒行传 10:4; 使徒行传 10:22"> 他为人虔诚，与全家人一起敬拜上帝，对穷人非常慷慨，经常向上帝祷告。</span>
<span className="v" id="v3" data-v="3" data-xref="Daniel 9:20–21; 使徒行传 3:1; 使徒行传 5:19"> 一天大约下午三点钟时候，他在异象中清楚看到上帝的一位天使来到他身边，呼唤他：“哥尼流！”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="腓立比书 4:6; 希伯来书 6:10; 使徒行传 10:31"> 他很害怕地盯着天使看，然后问到：“主啊，你想要干嘛？”天使说：“上帝注意到你的祷告和善行，看到了你对穷人的慷慨。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 16:9; 使徒行传 9:38; 使徒行传 15:7"> 现在派人到约帕去，把一个叫做彼得的人带过来，他还有个名字叫西门。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 9:43; 使徒行传 11:13–14; 罗马书 10:14–17"> 他在海边制皮匠西门的家里做客。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="腓利门书 1:16; 1 Samuel 14:6–7; 马太福音 8:9–10"> 待与他说话的天使走后，他就叫来两个家仆和他的一名私人护卫，也是一名虔诚的信徒。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 9:36; Psalms 119:59–60; 使徒行传 10:33"> 他把一切解释给他们听，然后派他们到约帕去。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="Zephaniah 1:5; Psalms 55:17; 1 Samuel 9:25"> 第二天，他们即将接近那座城的时候，彼得爬上屋顶<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="当时房屋都是平顶，可用作露天的房间。">a</a></sup>去祷告。中午时分，</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 22:17; 启示录 4:2–3; 哥林多后书 12:2–4"> 彼得觉得饿了，想要吃点东西。就在准备午餐的时候，他忽然感到一阵恍惚，</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 3:6; 约翰福音 1:51; 罗马书 16:25–26"> 然后便看见天空开启，有什么东西降落在下面，仿佛是一大块四角绑住的布，</span>
<span className="v" id="v12" data-v="12" data-xref="Genesis 7:8–9; 约翰福音 7:37; 哥林多前书 6:9–11"> 里面可以看到各种各样的动物、昆虫和飞鸟。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 4:31–34; Jeremiah 35:2–5; 使徒行传 10:10"> 一个声音对他说：“彼得，起来吧，把它们宰杀后食用！”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="Leviticus 20:25; Ezekiel 4:14; Daniel 1:8"> 彼得说：“主啊，万万不可！我从不吃不纯不洁的食物。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 10:25; 马太福音 15:11; 提多书 1:15"> 那声音又对他说：“上帝已让它洁净，不可称其不洁！”</span>
<span className="v" id="v16" data-v="16" data-xref="Genesis 41:32; 约翰福音 21:17; 哥林多后书 13:1"> 这样的异象重复了三次，然后那块布立刻被收回天空。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 13:12; 使徒行传 10:7–19; 使徒行传 5:24"> 彼得感到很困惑，不知这异象到底意味着什么。此时哥尼流派来的人找到西门所在的房子，站在门口，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 10:5–6; 使徒行传 11:11"> 他们高喊，询问这里是否有一个名叫彼得或西门的人。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 8:29; 使徒行传 11:12; 使徒行传 21:4"> 彼得还在想着那异象，圣灵对他说：“看，有三个人来找你。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 15:7–9; Zechariah 2:9–11; Isaiah 48:16"> 起来，到楼下和他们走吧。完全不要担心，因为他们是我派来的。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约翰福音 1:38–39; 马可福音 10:51; 使徒行传 10:29"> 于是彼得下楼与他们相见，说：“我就是你们所要找的人。为什么你们会来这里？”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 11:14; 使徒行传 10:2; 使徒行传 22:12"> 他们说：“百夫长哥尼流派我们前来。他是一位敬畏上帝的善良之人，犹太人民都很敬重他。一位圣天使给他指示，请你到他家中，让他聆听你的宣讲。”</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 10:45; 使徒行传 11:12; 彼得前书 4:9"> 彼得邀请他们进屋住下。<br />第二天，彼得和来自约帕的几名兄弟与他们一起离开。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 8:40; Zechariah 8:20–23; Zechariah 3:10"> 一行人在第二天来到该撒利亚，此时哥尼流已经找来亲朋好友迎接他们。</span>
<span className="v" id="v25" data-v="25" data-xref="启示录 19:10; 启示录 22:8–9; Daniel 2:46"> 彼得走进房屋后，哥尼流迎上来，俯伏在他脚前叩拜。</span>
<span className="v" id="v26" data-v="26" data-xref="启示录 19:10; 启示录 22:8–9; 使徒行传 14:14–15"> 彼得把他扶起，说：“起来，我不过是凡人而已！”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="哥林多后书 2:12; 约翰福音 4:35; 使徒行传 10:24"> 彼得和他说了几句话就走了进去，看见许多人聚集在那里。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 4:9; 以弗所书 3:6–7; 加拉太书 2:12–14"> 他对众人说：“你们当然知道，犹太人本来不准与异教徒有联系或彼此探访，但上帝已经指示我，不可把任何人视为不纯或不洁。</span>
<span className="v" id="v29" data-v="29" data-xref="Psalms 119:60; 彼得前书 3:15; 使徒行传 10:19–20"> 所以我受邀后就立刻毫不推辞地来了。那么现在我想知道，你要我来所为何事？”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行传 10:3; Daniel 9:20–21; Nehemiah 9:1–3"> 哥尼流说：“四天前下午三点钟，我在家里祷告时，忽然有一人站在我面前，身上的衣服发着明亮的光。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 10:4; Daniel 9:23; 路加福音 1:13"> 那人对我说：‘哥尼流，上帝已听到你的祷告，他已看到你对穷人的慷慨。</span>
<span className="v" id="v32" data-v="32"> 派人到约帕去找一位叫做彼得的人过来，他现在住在制皮匠西门位于海边的家中。’</span>
<span className="v" id="v33" data-v="33" data-xref="雅各书 1:19; 加拉太书 4:14; 2 Chronicles 30:12"> 所以我就立刻派人去请你过来，所以此刻我们都能在这里，在上帝面前相聚，准备聆听主吩咐你的一切。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="罗马书 2:11; 2 Chronicles 19:7; Deuteronomy 10:17"> 彼得回答：“我非常确信上帝从不偏袒。</span>
<span className="v" id="v35" data-v="35" data-xref="约翰一书 2:29; 使徒行传 10:2; 罗马书 10:12–13"> 无论哪个民族，只要尊重上帝，行事善良正义，就会被上帝所接纳。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 28:18; 使徒行传 2:36; 启示录 17:14"> 你们知道，上帝借耶稣基督，也就是万物之主，传播和平的福音，将这道传递给以色列人。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 4:14; 使徒行传 2:22; 使徒行传 28:22"> 你们知道，约翰呼吁大家受洗之后，这道就从加利利传遍了犹太。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 4:18; 使徒行传 2:22; Isaiah 61:1–3"> 这是关于拿撒勒人耶稣的道，讲述了上帝如何用圣灵和力量选定他，进行膏立。讲述了他如何四处行善，治愈所有被魔鬼控制之人，因为上帝与他同在。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 24:48; 使徒行传 1:8; 使徒行传 10:41"> 对于他在犹太人之地和耶路撒冷所行一切，我们就是见证人。他们把他钉上十字架，谋害了他。</span>
<span className="v" id="v40" data-v="40" data-xref="彼得前书 1:21; 使徒行传 13:30–31; 哥林多前书 15:3–4"> 但上帝让他在第三天复活并显现，</span>
<span className="v" id="v41" data-v="41" data-xref="约翰福音 14:22; 使徒行传 10:39; 约翰福音 21:13"> 不过并非显现给所有的人，而是显现给上帝所选的见证人，包括我们这些在他死而复生后，与他一起吃喝之人。</span>
<span className="v" id="v42" data-v="42" data-xref="哥林多后书 5:10; 提摩太后书 4:1; 彼得前书 4:5"> 他让我们承担向民众传道的使命，证明他就是上帝选来审判活人和死人的主。</span>
<span className="v" id="v43" data-v="43" data-xref="Zechariah 13:1; 使徒行传 2:38; Isaiah 53:11"> 他就是所有先知所言之人：信他之人的罪就会以他之名得到赦免。”</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="使徒行传 11:15; 使徒行传 19:6; 使徒行传 15:8"> 彼得说话的时候，圣灵降临到所有听道民众的身上，</span>
<span className="v" id="v45" data-v="45" data-xref="使徒行传 10:23; 使徒行传 2:38; 加拉太书 3:13–14"> 与彼得一同前来的犹太人信徒<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“那些相信割礼之人。”">b</a></sup>非常震惊，因为异教徒也能获得圣灵之礼。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒行传 19:6; 使徒行传 2:4; 马可福音 16:17"> 他们能听懂用方言说的话，一起赞美上帝。</span>
<span className="v" id="v47" data-v="47" data-xref="使徒行传 8:36; 罗马书 10:12; 使徒行传 11:15–17"> 彼得问：“既然这些人已经和我们一样接受圣灵，谁又能阻止他们接受水的洗礼呢？”</span>
<span className="v" id="v48" data-v="48" data-xref="使徒行传 2:38; 使徒行传 8:16; 加拉太书 3:27"> 然后，他就吩咐以耶稣基督之名为他们施洗。随后，众人请彼得在此再多住几天。</span>
</div>
</div>

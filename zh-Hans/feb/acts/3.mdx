<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Psalms 55:17; 使徒行传 10:3; 使徒行传 4:13"> 下午三点的祷告瞬间，彼得和约翰向圣殿走去。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 14:8; 约翰福音 9:8; 路加福音 16:20"> 有人将一个生来瘸腿之人抬来，每天放他在殿门口（这扇门名为“美”），向进殿之人乞讨。</span>
<span className="v" id="v3" data-v="3"> 他看见彼得和约翰将要进殿，就向他们讨钱。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 14:9–10; 约翰福音 11:40; 路加福音 4:20"> 彼得和约翰定睛看着他，彼得说：“看我们！”</span>
<span className="v" id="v5" data-v="5"> 那人就专注地看着他们，希望从他们那里得些什么。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 3:16; 使徒行传 10:38; 使徒行传 4:10"> 彼得却说：“我没有金银，只是把我有的给你。以拿撒勒人耶稣基督之名，让你行走！”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马可福音 1:31; 马可福音 9:27; 使徒行传 9:41"> 于是彼得拉着他的右手，扶他起来，他的脚和踝骨立刻变得有力，</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 14:10; Isaiah 35:6; Psalms 107:20–22"> 他跳起来后开始行走，连走带跳，赞美上帝，同他们进入殿中。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 4:21; 使徒行传 4:16; 路加福音 13:17"> 众人看见他一边走一边赞美上帝，</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 3:2; 约翰福音 5:20; 约翰福音 9:3"> 大家认出他就是平时坐在圣殿美门口的讨饭乞丐，对于他身上发生的事情惊讶不已。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 5:12; 约翰福音 10:23; 路加福音 8:38"> 那人紧紧跟随着彼得和约翰，倍感惊奇的众人也跟着他们跑到了所罗门廊<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="圣殿的一部分，又见5:12。">a</a></sup>处。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 3:5; 约翰福音 3:27–28; Daniel 2:28–30"> 彼得借此机会对大家说：“以色列人，为什么要为这事惊讶呢？为什么盯着我们看，好像这人能够行走，都是我们凭借自己的能力和信仰达成？</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 22:32; 使徒行传 7:32; 马太福音 27:17–25"> 亚伯拉罕、以撒、雅各的上帝，也是我们祖先的上帝，他已经让其仆人耶稣获得了荣耀。就是那位你们把他送到官府的耶稣。彼拉多本来决定要释放他，你们却当着彼拉多的面拒绝了这个决定。</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 1:24; 使徒行传 7:52; 彼得前书 3:18"> 你们拒绝接受一位善良的圣者，反倒要求释放一名杀人犯。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 2:24; 启示录 21:6; 使徒行传 2:32"> 你们杀死了这位生命的创造者，上帝却让他死而复生。我们亲眼见证了这一切。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 21:21–22; 使徒行传 4:10; 使徒行传 14:9"> 这位男人因为相信耶稣之名，所以被耶稣所治愈。现在你们看到这个男人，你们都认识他。因为相信耶稣，他当着你们众人的面被治愈了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 23:34; 使徒行传 13:27; 约翰福音 16:3"> 兄弟姐妹们，现在我知道你们这样做是出于无知，你们的领导者也是如此。</span>
<span className="v" id="v18" data-v="18" data-xref="Isaiah 53:1–12; 使徒行传 26:22–23; 使徒行传 2:23"> 但上帝却实现了他通过众先知之口所传递的信息：这位基督将会受害。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 2:38; Isaiah 44:22; Isaiah 43:25"> 所以你们应该忏悔，改邪归正，这样才能让你们的罪一笔勾销，主才能为你们送来治愈和恢复的机会，</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 24:30–36; 启示录 19:11–16; 帖撒罗尼迦后书 2:2"> 才会将指定给你们的耶稣基督派来。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 8:21; Isaiah 1:26; 使徒行传 1:11"> 在世界万物修复之前，他一定会留在天堂，也就是上帝在很久以前通过圣先知之口宣布的讯息。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="Deuteronomy 18:15–19; 使徒行传 7:37; 加拉太书 4:4"> 摩西曾说：‘主上帝将从你们自己人中选择像我这样的先知，派遣给你们。无论他对你们说什么，你们都应当聆听。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引自《申命记》18:15。">b</a></sup></span>
<span className="v" id="v23" data-v="23" data-xref="Deuteronomy 18:19; 约翰福音 12:48; 希伯来书 10:28–30"> 不聆听这位先知之人，必会在人类中彻底灭绝。’<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="见《申命记》18:19。">c</a></sup></span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 3:21; 路加福音 24:27; 1 Samuel 3:20"> 从撒母耳起的所有先知，都曾经预言过这样的日子。</span>
<span className="v" id="v25" data-v="25" data-xref="Genesis 22:18; 加拉太书 3:8; 使徒行传 2:39"> 你们是先知的子孙，也是上帝与你们祖先所立之约<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或“盟约。”">d</a></sup>的后人。上帝曾对亚伯拉罕说：‘作为你后代的人间万众都会获得祝福。’<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="引自《创世纪》22:18。">e</a></sup></span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 1:21; 使徒行传 3:22; 犹大书 1:24"> 上帝为你们准备好了他的仆人，首先把他派来，通过纠正你们的邪恶之道为你们祝福。”</span>
</div>
</div>

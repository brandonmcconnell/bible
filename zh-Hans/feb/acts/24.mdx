<span className="v" id="v1" data-v="1" data-xref="使徒行传 24:11; 使徒行传 23:2; 使徒行传 25:2"> 五天后，大祭司亚拿尼亚、几名长老和一位名叫帖土罗的律师来到总督府，控告保罗。</span>
<span className="v" id="v2" data-v="2" data-xref="Proverbs 29:5; Proverbs 26:28; 使徒行传 24:26–27"> 当保罗被传唤过来，帖土罗开始控诉他：“腓力斯大人，因为你的缘故，民众长久以来一直享受着太平。由于您的明智判断，为了国家的利益而进行了改革。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 23:26; 使徒行传 26:25; 路加福音 1:3"> 全国人民都对你深表感激。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 11:32"> 但为了不烦扰你，我们只需要占用你一点时间。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 28:22; 使徒行传 24:14; 使徒行传 26:5"> 我们发现这个人就像瘟疫一样<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“瘟疫。”">a</a></sup>，他煽动普天下的犹太人叛乱，还是拿撒勒派的头目。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 24:12; 使徒行传 21:27–32; 约翰福音 18:31"> 因为他想要污损圣殿，所以我们将他逮捕。</span>
<span className="v" id="v7" data-v="7"> <sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="第 24:6b-8a 句的真实性存有疑问，在标准希腊文本中被删除。">b</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 23:35; 使徒行传 25:15–16; 使徒行传 25:5"> 你只需亲自审问，就会清楚我们控告他的一切事实。”</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦前书 2:16; Micah 7:2–3; Psalms 4:2"> 犹太人也应声附和，证实事实的确如此。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前书 3:15; 1 Samuel 2:25; 路加福音 18:2"> 总督示意保罗回应。保罗开始申辩：“我知道你多年来一直担任本国的法官，我很乐意为自己辩护。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 24:1; 使徒行传 21:18; 使徒行传 23:11"> 有一点很容易证明，我是十二天前才抵达耶路撒冷进行礼拜，</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 25:8; 使徒行传 28:17; 使徒行传 24:18"> 无论在圣殿、会堂或城里，没有人看到我跟人辩论或是煽动群众作乱，</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 25:7; 彼得前书 3:16"> 他们现在控告我的事，也没有人能向你证明。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 9:2; 罗马书 3:21; 使徒行传 3:13"> 但我要向你明确一件事：我谨遵正道信仰伺奉我们祖先的上帝，但他们称之为邪教。无论是律法还是先知所记载的一切，我都相信。</span>
<span className="v" id="v15" data-v="15" data-xref="Daniel 12:2; 约翰福音 5:28–29; 帖撒罗尼迦前书 4:14–16"> 我和他们一样对上帝心存希望，相信无论是正义或不正义之人都会复活。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 23:1; 提摩太前书 1:5; 哥林多后书 4:2"> 因此，我在上帝和世人面前，努力保持无愧于心。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 2:10; 罗马书 15:25–28; 哥林多前书 16:1–4"> 我曾离开这里几年，在返回时带来了捐款支援穷苦人，也为上帝带来了祭物。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 26:21; 使徒行传 21:26–30; 使徒行传 24:12"> 他们在圣殿中找到我时，我正在完成洁净礼，没有和大群民众在一起，更没有骚乱，</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 23:30; 使徒行传 25:16"> 当时只有几名来自亚西亚的犹太人而已。他们针对于我，今天就应该站在你面前控告我。</span>
<span className="v" id="v20" data-v="20"> 这些人如果发现我有什么罪行，当我站在公议会面前受审时，就会说出来了。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 23:6; 使徒行传 4:2; 使徒行传 26:6–8"> 如果有什么特别的，那可能就是我向他们喊的那句话：‘我今天在你们面前受审，就是因为我相信死人复活。’”</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 24:6; 使徒行传 24:24; 使徒行传 25:26"> 腓力斯本人非常熟悉道，于是就故意拖延审讯。他说：“等千夫长吕西亚过来的时候，我再来决定你的案子。”</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 28:16; 使徒行传 27:3; Proverbs 16:7"> 他吩咐百夫长看守保罗，但要给他一些自由，不要阻止保罗的亲友前来照料。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 20:21; 加拉太书 2:16; 马可福音 6:20"> 几天后，腓力斯把他的犹太妻子土西拉带来。他们召见保罗，听他讲述对耶稣基督的信仰。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 16:8; 彼得前书 3:15; 使徒行传 10:42"> 保罗简述了关于在生活中遵循正道、自我控制和即将到来的审判，这让腓力斯感到警觉，于是说：“你现在可以走了，有机会再叫你过来。”</span>
<span className="v" id="v26" data-v="26" data-xref="提摩太前书 6:9–10; Proverbs 17:23; Isaiah 56:11"> 此外，他也想让保罗向他行贿，所以后来又多次传见他，与他交流。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 25:9; 使徒行传 25:14; 使徒行传 12:3"> 两年过去了，非斯都接替了腓力斯的职务，腓力斯为了讨好犹太人，就将保罗继续关在监牢中。</span>

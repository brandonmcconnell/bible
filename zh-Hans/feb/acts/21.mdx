<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 2:17; 路加福音 5:4; 1 Samuel 20:41–42"> 在与他告别之后，我们也乘船直接去了哥士，第二天抵达罗底，然后从那里去往帕大拉。</span>
<span className="v" id="v2" data-v="2" data-xref="Jonah 1:3; 使徒行传 11:19; 使徒行传 15:3"> 在帕大拉，我们看到一艘开往腓尼基的船，于是就上船继续前行。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 21:16; 使徒行传 4:36; 马太福音 4:24"> 在旅途中，我们远远地在左手方向看见了塞浦路斯。继续航行到叙利亚后，我们在推罗上岸，因为船要在那里卸货。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 20:22–23; 使徒行传 21:10–12; 使徒行传 20:6–7"> 我们找到了一些信徒，在那里停留了七天。这些信徒曾通过圣灵告诉保罗，不要去耶路撒冷。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 20:36; 使徒行传 9:40; Psalms 95:6"> 在那艘船准备再次起航时，我们回到船上继续旅程。在我们离开城市的时候，所有信徒都携妻带子给我们送行。大家一起跪在海滩上祷告，互相告别。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 19:27; 约翰福音 1:11; 哥林多后书 2:13"> 随后我们就上了船返回家中。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 13:24; 1 Samuel 10:4; 使徒行传 28:12"> 我们从推罗开始的那段旅程，终点是多利买。我们问候那里的信徒，然后住了一天。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 6:5; 使徒行传 8:26–40; 以弗所书 4:11"> 第二天我们便离开并去往该撒利亚，住在福音传播者腓利的家中，他也是七执事之一。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="被选出来帮助分配食物的七人之一(6:5)。">a</a></sup></span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 2:17; 启示录 2:20; Joel 2:28"> 他有四名尚未嫁人的女儿，都具有预言的能力。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 11:28; 使徒行传 21:4; 使徒行传 20:16"> 我们在那里住了几天之后，一位名叫亚迦布的先知从犹太赶来。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 21:33; Jeremiah 13:1–11; 1 Samuel 15:27–28"> 他找到我们，拿出保罗的腰带绑住他自己的手脚，然后说：“圣灵说，犹太人在耶路撒冷就是这样捆绑这腰带的主人，然后把他交给异教徒。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 16:21–23; 使徒行传 20:22; 使徒行传 21:4"> 听闻此话，我们就和那里的信徒央求保罗不要去耶路撒冷。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 20:24; 腓立比书 2:17; 腓立比书 1:20–21"> 保罗却回答：“你们为什么要哭？这让我的心都碎了。以主耶稣之名，我们不仅准备好在耶路撒冷被捆绑，也准备好死在那里。”</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 22:42; 马太福音 26:42; 马太福音 26:39"> 由于他不听劝阻，我们只能对他说“愿主的意愿能够达成”，然后就放弃了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行传 25:1; 使徒行传 25:6; 使徒行传 25:9"> 几天后，我们收拾行装去耶路撒冷。</span>
<span className="v" id="v16" data-v="16" data-xref="Proverbs 16:31; 使徒行传 21:8; Psalms 92:14"> 该撒利亚的几名信徒与我们同行，带着我们住进塞浦路斯人拿孙的家里，他很早就成为了上帝的信徒。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行传 15:4; 罗马书 15:7; 希伯来书 13:1–2"> 到了耶路撒冷后，那里的信徒们热情地接待我们。</span>
<span className="v" id="v18" data-v="18" data-xref="加拉太书 1:19; 加拉太书 2:9; 使徒行传 15:13"> 第二天，保罗和我们一同去见雅各，教会的长老们也都在那里。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 14:27; 使徒行传 1:17; 罗马书 15:18–19"> 保罗向他们问候，然后就详细讲述了上帝如何通过他所履行的侍奉，在异教徒中所做的一切。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="罗马书 10:2; 加拉太书 1:14; 使徒行传 22:3"> 众人听罢纷纷赞美上帝，对保罗说：“兄弟，你看，犹太人信主的人有好几万，他们仍然小心地遵循着律法。</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太书 6:12–15; 哥林多前书 9:19–21; 加拉太书 5:1–6"> 但他们听说，你教导所有与异教徒生活在一起的犹太人不遵循摩西的律法，让他们不要给孩子行割礼，不要遵守我们的风俗。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 15:12; 使徒行传 15:22; 使徒行传 19:32"> 他们肯定听说你已经来了，那我们应该怎么办呢？</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 18:18; Numbers 6:2–7"> 我们希望你能这么做：我们中有四人已经起誓发愿，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 21:26; 使徒行传 24:18; 使徒行传 18:18"> 你和他们一起去行洁净礼，付钱让他们剃去头发，这样大家就知道，以往听说关于你的说法都不真实，你也是一名遵守律法、循规蹈矩之人。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 15:29; 使徒行传 15:19–20"> 至于信主的异教徒，我们已经写信吩咐他们，不要吃献祭神像的食物，要避开血和勒死的牲畜，不要淫乱。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 24:18; 使徒行传 21:24; Numbers 6:13–20"> 于是保罗带走了那四个人，第二天和他们一起行洁净礼，然后去了圣殿，告知他们何时洁净期满以及每个人应该献祭的时间。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行传 26:21; 使徒行传 24:18; 使徒行传 13:50"> 在快到第七天的时候，亚西亚来的犹太人在圣殿中看见保罗，于是就煽动众人反对保罗并捉拿他。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 24:5–6; 使徒行传 21:21; 使徒行传 26:20–21"> 他们高喊：“以色列人啊，快来帮忙！这个人到处唆使众人反对我们以色列人，反对律法和圣殿。他甚至还把希腊人带入圣殿，污染了这片圣地。”</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 20:4; 提摩太后书 4:20; 使徒行传 18:19"> （他们之所以这么说，是因为之前曾在城里看到他和弗所人特罗非摩在一起，所以就以为保罗带他进入了圣殿。）</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 26:21; 哥林多后书 11:26; 使徒行传 16:19–22"> 全城都骚动起来，民众纷纷涌来抓住保罗，将他拖出殿外，殿门立刻关闭。</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多后书 11:23–33; 使徒行传 17:5; 使徒行传 26:9–10"> 他们正准备杀了保罗时，有人向罗马军营的千夫长报告，整个耶路撒冷都陷入了混乱。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行传 23:27; Isaiah 3:15; 使徒行传 5:40"> 千夫长立刻带着百夫长和士兵，向暴乱地点赶来。暴徒们看到千夫长和士兵，便停止殴打保罗。</span>
<span className="v" id="v33" data-v="33" data-xref="以弗所书 6:20; 使徒行传 21:11; 使徒行传 20:23"> 长官上前抓住保罗，命令用两条铁链把他捆住，然后询问他是谁，做过什么事。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 19:32; 使徒行传 23:10; 使徒行传 22:24"> 暴徒中有些人开始各执一词地胡乱叫喊，长千夫长也没办法找到真相，只好下令把保罗带到营地去。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="Habakkuk 1:2–3; Psalms 55:9; Psalms 58:2"> 保罗来到台阶处，由于周围的民众变得很暴力，士兵们不得不把保罗抬起来。</span>
<span className="v" id="v36" data-v="36" data-xref="约翰福音 19:15; 使徒行传 22:22; 路加福音 23:18"> 人群中有一些跟上来的人高声喊叫：“干掉他！”</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 21:34; 路加福音 21:15; 使徒行传 19:30"> 保罗快被带到军营的时候，保罗问千夫长说：“可以跟你说句话吗？”<br />千夫长说：“你懂希腊语？</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 24:26; 使徒行传 5:36–37; 马太福音 5:11"> 之前煽动骚乱、带领四千名杀手跑到荒野去的那个埃及人，不就是你吗？”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒行传 22:3; 使徒行传 9:11; 使徒行传 23:27"> 保罗说：“我是犹太人，来自基利家的重镇之一大数。请准我与民众说几句。”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="使徒行传 12:17; 使徒行传 22:2; 约翰福音 5:2"> 千夫长批准了他的请求。于是保罗就站在台阶上，向民众做了一个安静的手势。待大家都平静下来后，他开始用阿拉姆语演讲。</span>
</div>
</div>

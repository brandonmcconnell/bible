<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 25:25; 使徒行传 25:12; 使徒行传 10:1"> 到了将我们押送到意大利的时候，帝国团中一位名叫犹流的百夫长负责看管保罗和其他囚犯。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 19:29; 腓利门书 1:24; 歌罗西书 4:10"> 我们坐上一艘来自亚大米田的船，它将要开往亚西亚沿岸的海港。我们上船后就出发了，还有一人与我们同行：马其顿的帖撒罗尼迦人亚里达古。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 24:23; 使徒行传 28:16; 使徒行传 27:43"> 第二天我们在西顿短暂停留，犹流对保罗非常友好，允许他到岸上看朋友，接受他们的招待。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 4:36; 使徒行传 15:39; 使徒行传 13:4"> 随后我们又从那里继续出发，因为是逆风，船便向塞浦路斯的背风地点驶去。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 6:9; 使徒行传 13:13; 使徒行传 15:41"> 船只直接穿过基利家和旁非利亚一带的水域，抵达了吕家的每拉港。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 28:11; 使徒行传 27:1; 使徒行传 6:9"> 在那里，百夫长找到一艘来自亚历山太，开往意大利的船只，于是安排我们上了这艘船。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 27:21; 提多书 1:5; 提多书 1:12"> 但这艘船在随后的几天行驶得都很缓慢，好不容抵达革尼土对面的海域。因为逆风的缘故，船只无法继续前行，只能在撒摩尼附近背风穿过克里特的海域。</span>
<span className="v" id="v8" data-v="8"> 沿着海岸行驶的这段航程很困难，最终抵达了拉西亚城附近一个名叫美港的地方。</span>
<span className="v" id="v9" data-v="9" data-xref="Numbers 29:7; Leviticus 23:27–29; Leviticus 16:29–31"> 这段旅程已经浪费了不少时间，未来的航程也很危险，此时都已过了禁食节<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“禁食节”：即赎罪日，大概是在十月，这个季节并不适合航行。">a</a></sup>。保罗警告他们说：</span>
<span className="v" id="v10" data-v="10" data-xref="Daniel 2:30; 使徒行传 27:20–26; 使徒行传 27:41–44"> “各位，我估计这次旅程会非常困难，而且会有损失，不只是货物和船只，连我们的性命也危在旦夕。”</span>
<span className="v" id="v11" data-v="11" data-xref="Ezekiel 33:4; 希伯来书 11:7; Ezekiel 3:17–18"> 但百夫长更相信船长和船主的建议，把保罗的警告当耳旁风。</span>
<span className="v" id="v12" data-v="12" data-xref="Psalms 107:30; 使徒行传 27:8"> 由于这个港口很小，无法在此过冬，所以大多数人主张继续航行，可以到非尼基去过冬——那是位于克里特的一个朝向西北和西南的港口。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:55; Song of Solomon 4:16; Job 37:17"> 这时海上开始刮起和缓的南风，他们认为可以按计划进行，于是就起锚沿着克里特海滩接近海岸的路线航行。</span>
<span className="v" id="v14" data-v="14" data-xref="马可福音 4:37; Psalms 107:25–27; Exodus 14:21–27"> 但很快，从陆地向海上刮起了一阵名为“东北风”的飓风。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各书 3:4; 使徒行传 27:27"> 船只被困在海中，无法迎风前行，只好随风飘流。</span>
<span className="v" id="v16" data-v="16"> 最终我们来到一个名为高达的小岛，这里可以背风行驶。我们还花了很大力气将救生艇<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“船上之船”，这是类似橡皮艇或救生艇的小船，有时候会被拖到船后，有时需要绑在甲板上。又见第 30 句。">b</a></sup>拉住。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 27:29; 使徒行传 27:26; 使徒行传 27:41"> 水手把小艇吊起来，用缆索绕在船身将其捆好。他们担心船会在赛耳底的浅滩搁浅，于是放下船帆，任其飘流。</span>
<span className="v" id="v18" data-v="18" data-xref="Jonah 1:5; 使徒行传 27:38; 马太福音 16:26"> 船只在风浪中剧烈颠簸。第二天，船员们开始将货物拋在海里，</span>
<span className="v" id="v19" data-v="19" data-xref="Job 2:4; 路加福音 9:24–25; 马可福音 8:35–37"> 第三天，他们又将船上的设备扔掉。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 24:29; 马太福音 8:24–25; Jeremiah 2:25"> 接连数天都看不见太阳或星辰，肆虐的暴风雨铺天盖地，看起来我们似乎没有一点生还的希望。</span>
<span className="v" id="v21" data-v="21" data-xref="Genesis 42:22; Psalms 107:5–6; 使徒行传 27:7"> 船上的人已经很久没有进食了。保罗站在他们面前，说：“各位，你们本该听我的，不要离开克里特，那样就可以避开这样的灾难和损失了。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 27:25; 使徒行传 27:36; 哥林多后书 4:8–9"> 但现在我想说的是，鼓起勇气，因为除了这艘船被毁，你们所有人都不会丢掉性命。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 23:11; 罗马书 1:9; 提摩太后书 4:17"> 因为昨晚，我所侍奉的上帝<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“我所属于的上帝。”">c</a></sup>派来天使站在我身边，对我说：</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 23:11; 提摩太后书 4:16–17; 马太福音 10:28"> ‘保罗，不要怕。你一定会站在凯撒面前接受审判。看，上帝慷慨地赐予你这些人，他们与你同船而行。’</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 4:20–21; 路加福音 1:45; Numbers 23:19"> 所以各位，拿出勇气来。我相信上帝，我确信事情一定会像我说的那样。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 28:1; 使徒行传 27:17; 使徒行传 27:29"> 但是我们会在一个岛上失事。”</span>
<span className="v" id="v27" data-v="27" data-xref="Jonah 1:6; 使徒行传 27:30; 启示录 18:17"> 到了第十四天的午夜，我们还在亚得里亚海面被风吹着。水手感觉这里应该距离陆地不远了。</span>
<span className="v" id="v28" data-v="28"> 于是他们探测了一下水深， 40 米，继续往前再探测， 30 米。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 27:17; 希伯来书 6:19; Deuteronomy 28:67"> 他们怕船只可能会在乱石上搁浅，于是就从船尾拋下四个锚，祈祷天亮。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 27:16; 使徒行传 27:32"> 水手们想要弃船逃生，于是假装要从船头拋锚，其实是想把救生艇放在海面上。</span>
<span className="v" id="v31" data-v="31" data-xref="帖撒罗尼迦后书 2:13–14; Psalms 91:11–12; Jeremiah 29:11–13"> 保罗对百夫长和士兵说：“水手如果不留在船上，你们必死无疑！”</span>
<span className="v" id="v32" data-v="32" data-xref="腓立比书 3:7–9; 路加福音 16:8"> 于是士兵砍断拴着救生艇的绳子，任它消失在海中。</span>
<span className="v" id="v33" data-v="33"> 天快亮的时候，保罗劝大家吃点东西。他说：“你们忧心忡忡地想着这件事，已经连续 14 天没有吃东西了！</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 10:30; 1 Kings 1:52; 路加福音 21:18"> 听我劝，吃点东西吧，这可以让你们有力气！因为你们所有人连一根头发都不会失去。”</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 15:36; 哥林多前书 10:30–31; 提摩太前书 4:3–4"> 保罗说完就拿起饼，在众人面前感谢上帝，然后把饼掰开吃。</span>
<span className="v" id="v36" data-v="36" data-xref="哥林多后书 1:4–6; 使徒行传 27:22; Psalms 27:14"> 众人受到鼓舞，也开始进食。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 2:41; 罗马书 13:1; 彼得前书 3:20"> 我们这艘船上的共有 276 人，</span>
<span className="v" id="v38" data-v="38" data-xref="Jonah 1:5; 马太福音 6:25; 使徒行传 27:18–19"> 大家吃饱后，为了减轻船只的负荷，水手把船上的麦子拋在海里。</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 28:1"> 黎明时分，他们来到一个不知名的海岸线，只看见一个海湾和一片海滩。他们计划在那里尝试将船搁浅。</span>
<span className="v" id="v40" data-v="40" data-xref="Isaiah 33:23; 使徒行传 27:29–30"> 他们砍断拴着锚的绳子，将锚丢在海里，同时又松开舵绳，拉起前帆，顺着风向那片海滩驶去。</span>
<span className="v" id="v41" data-v="41" data-xref="哥林多后书 11:25–26; Ezekiel 27:26; 使徒行传 27:26–29"> 但船还是卡在了沙洲处，船搁浅了，船头卡在沙滩上，一动不动。船尾则被大浪冲击，撞得粉碎。</span>
<span className="v" id="v42" data-v="42" data-xref="马可福音 15:15–20; Ecclesiastes 9:3; Psalms 74:20"> 士兵想要杀了所有囚犯，防止有人游泳逃脱。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行传 27:3; Proverbs 16:7; 使徒行传 27:11"> 但百夫长想要救保罗，就制止了他们的这个念头，吩咐会游泳的跳下水，先到岸上去，</span>
<span className="v" id="v44" data-v="44" data-xref="使徒行传 27:22; Psalms 107:28–30; 约翰福音 6:39–40"> 其余的人可以借助木板或船上的设备上岸。最终，所有人都安全登陆。</span>

<span className="v" id="v1" data-v="1" data-xref="马太福音 24:9; 约翰福音 15:20; 马太福音 10:17–18"> 当时君王希律开始迫害教会成员。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:37; 马太福音 20:23; 马太福音 4:21–22"> 他用剑处决了约翰的哥哥雅各，</span>
<span className="v" id="v3" data-v="3" data-xref="Exodus 23:15; 约翰福音 12:43; 使徒行传 24:27"> 由于此举受到了犹太人的支持，于是他又在除酵节期间捉拿彼得。</span>
<span className="v" id="v4" data-v="4" data-xref="Proverbs 19:21; 路加福音 22:33; 路加福音 21:12"> 他们逮捕了彼得后将其投入监牢，由四班士兵看守，每班四个人。君王希律打算逾越节过后，就对他进行公审。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 12:26; 帖撒罗尼迦前书 5:17; 雅各书 5:16"> 彼得在监牢期间，教会开始为他虔诚地祈求上帝。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 21:33; 希伯来书 13:6; 腓立比书 4:6–7"> 就在希律打算将他公审的前一夜，彼得被安排睡在两名士兵中间，手腕上的两条锁链分别与两人栓在一起，还有卫兵守在门前。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 5:19; 使徒行传 16:26; Psalms 146:7"> 忽然，一名天使出现，光芒照亮了牢房。天使将彼得唤醒，说：“快点！起来吧！”于是彼得手上的锁链就脱落了。</span>
<span className="v" id="v8" data-v="8"> 天使对他说：“穿上衣服和鞋！”彼得照做了。天使又对他说：“披上外衣，跟我走！”</span>
<span className="v" id="v9" data-v="9" data-xref="Psalms 126:1; 希伯来书 11:8; Genesis 45:26"> 于是彼得就跟着天使走出去，但他只是以为看到了异象，没有意识到天使所做的一切都在真实发生。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 5:19; 使徒行传 16:26; Isaiah 45:1–2"> 他们经过第一队和第二队守卫，来到通往城内的铁门，门便自动给他们打开。他们出来后沿着街道行走，天使忽然就离开了。</span>
<span className="v" id="v11" data-v="11" data-xref="Daniel 6:22; Daniel 3:28; 彼得后书 2:9"> 彼得这时候才明白，说：“现在我知道怎么回事了！主派天使将我从希律的权势中拯救出来，让我躲过犹太人的阴谋。”</span>
<span className="v" id="v12" data-v="12" data-xref="约翰一书 5:14–15; 使徒行传 12:5; 马太福音 18:19–20"> 明白这一切，他就到约翰（又名马可）的母亲玛利亚家中，很多信徒聚在那里祷告。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 12:16; 路加福音 13:25; 约翰福音 18:16–17"> 彼得敲了敲大门，一位名叫罗大的侍女出来准备开门。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 24:41; 马太福音 28:8"> 但认出是彼得的声音后，她兴奋的顾不上开门就跑进屋，大声喊：“彼得就在门外！。”</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 18:10; 路加福音 24:11; 马可福音 16:14"> 大家说：“你疯了！”她却坚持地说这是真的。他们说：“那一定是他的天使！”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“他的天使。”当时有人认为，无论一个人活着还是死去，都有一个灵魂上的存在。但在现在，人们可能会说：“这是他的鬼魂！”">a</a></sup></span>
<span className="v" id="v16" data-v="16"> 彼得继续敲门，他们最终打开了门，一见是他，非常惊讶。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 21:40; 使徒行传 13:16; 使徒行传 19:33"> 彼得向他们举起手示意安静，然后对他们解释主如何带他走出监牢。他又说：“把这事告诉雅各和众兄弟。”然后就离开去往别处了。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 5:22–25; 使徒行传 16:27; 使徒行传 19:23"> 天亮的时候，士兵们惊慌不已，不知彼得去了哪里。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 16:27; Psalms 37:32–33; 约翰福音 12:10–11"> 希律开始四处搜索他，但始终没有找到。于是就审问卫兵，然后下令把他们处死。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="希腊人实际上说：“他们被带走了。”但大多数圣经解读者都认为这个词的意思为“把他们带走处死”，因为让囚犯逃脱会导致死刑。">b</a></sup>随后希律便离开犹太去往该撒利亚，在那里住下。</span>
<span className="v" id="v20" data-v="20" data-xref="Ezra 3:7; 马太福音 11:21–22; Ezekiel 27:17"> 此刻的希律对推罗和西顿人充满了愤怒。这两个地方的人派了一个联合代表团来见他，设法拉拢了国王的个人助理伯拉斯。这个代表团希望向希律求和，因为这两地在粮食供应商都依赖希律的国家。</span>
<span className="v" id="v21" data-v="21"> 到了约定见面的日期，希律穿上国王的长袍，坐在王座上，向众人讲话。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 14:10–13; 启示录 13:4; 犹大书 1:16"> 人群中有人大声说：“这是上帝的声音，不是人的声音！”</span>
<span className="v" id="v23" data-v="23" data-xref="Psalms 115:1; 使徒行传 10:25–26; 帖撒罗尼迦后书 2:4"> 但由于他没有将荣耀归于上帝，主的使者将他击倒。 他被虫吃掉了，死了。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 6:7; 使徒行传 19:20; 帖撒罗尼迦后书 3:1"> 但上帝之道却开始传播，信徒的数量越来越多。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 12:12; 彼得前书 5:13; 使徒行传 15:37"> 巴拿巴和扫罗完成了送捐款的任务，就带着约翰马可 从耶路撒冷返回。</span>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="feb" data-translation-id="cmn_feb" data-translation-label="易读圣经" data-book="ACT" data-book-slug="acts" data-book-name="使徒行传" data-chapter="5" data-verses="42">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="Leviticus 10:1–3; 提摩太后书 2:20; 马太福音 13:47–48"> 有一个人名叫亚拿尼亚，和妻子撒非拉一起把田地都卖了。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 4:37; 彼得后书 2:14–15; 马太福音 23:5"> 但他悄悄留下了一部分收入，妻子也知晓这件事。他把其余的钱拿来放在使徒面前。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="Jeremiah 23:24; Isaiah 29:15; 约翰福音 13:2"> 彼得说：“亚拿尼亚，为什么你让撒旦充满你的心，说服你欺骗圣灵，私底下把卖地的钱留了一部分？</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 5:3; Joshua 7:25–26; 2 Kings 5:25–27"> 田地还没有卖时，不就是你自己的吗？既然卖了，所得的收入不是由你做主吗？为什么决定这样做呢？你这不是欺骗人，而是欺骗上帝！”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 5:10–11; 使徒行传 2:43; 使徒行传 5:13"> 亚拿尼亚听罢，立刻倒地断了气。所有听闻之人都十分害怕。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 19:40; 2 Samuel 18:17; Deuteronomy 21:23"> 有几个青年人过来用裹尸布把他包好，抬出去埋葬了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 大约三小时后，亚拿尼亚的妻子来到这里，还不知道发生了什么事。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 5:2"> 彼得问她：“告诉我，你们卖田地的钱就这么多吗？”<br />她说：“是的，就是这么多。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 10:9; 使徒行传 5:3–4; Psalms 95:8–11"> 彼得说：“你们为什么串通一气<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“诱惑。”">a</a></sup>试探主的灵？你看，埋葬你丈夫的人刚刚回来，他们也会把你抬出去！”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 5:5"> 她立刻倒在彼得脚边，断了气。那些青年人返回后发现她死了，便把她也抬出去，埋在她丈夫旁边。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 5:5; 哥林多前书 10:11–12; 使徒行传 19:17"> 所有信徒和听闻此事之人，都感到万分恐惧。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 19:11; 哥林多后书 12:12; 希伯来书 2:4"> 主通过使徒显现许多神迹和奇迹。所有信徒过去一直都聚集在所罗门廊下。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="见3:11脚注。">b</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 2:47; 使徒行传 4:21; 约翰福音 12:42"> 其他人虽然很尊重他们，但都没有加入其中的胆量。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 2:47; 使徒行传 4:4; Isaiah 55:11–13"> 但相信主的信男信女却越来越多，</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 14:36; 使徒行传 19:11–12; 约翰福音 14:12"> 甚至有人把病人放在床和垫子中，抬到街上，希望彼得在经过时，至少他的影子可以落在他们身上。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="他们认为，即使彼得的影子也可以治愈病患。">c</a></sup></span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 16:17–18; 马可福音 2:3–4; 马太福音 15:30–31"> 耶路撒冷周围城市的人，也带着病人和恶灵附体之人蜂拥而来，所有病患全部被治愈。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行传 13:45; 使徒行传 7:9; 使徒行传 17:5"> 但这让大祭司和同伙的撒都该人非常嫉妒，决定插手迫害他们。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 4:3; 路加福音 21:12; 哥林多后书 11:23"> 他们捉拿了使徒，把他们押在公共拘留所里。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 16:26; Psalms 34:7; 使徒行传 12:7–11"> 但到了晚上，有一位主的天使打开监牢门，把他们放了出去，对他们说：</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 6:63; 约翰福音 6:68; 约翰一书 5:11–12"> “去圣殿那里，把新生命之道的一切告诉众人。”</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 8:2; 使徒行传 22:15; 使徒行传 12:18–19"> 使徒听从吩咐，在黎明时分走进圣殿教导众人。<br />与此同时，大祭司及其同党和以色列人众长老召开了公议会，派人到监牢把使徒带过来。</span>
<span className="v" id="v22" data-v="22"> 但差役在监牢里找不到使徒，于是回来报告说：</span>
<span className="v" id="v23" data-v="23" data-xref="Psalms 2:4; Psalms 33:10; Daniel 6:22–24"> “我们发现监牢门紧闭，狱卒也守在门外，但打开门后，里面一个人都找不到。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行传 4:1; 使徒行传 5:26; 约翰福音 12:19"> 圣殿的守卫和祭司长听到这个消息，觉得很困惑，不知道发生了什么。</span>
<span className="v" id="v25" data-v="25"> 这时有人来报告说：“看啊，你们押在监牢里的那些人，正在圣殿里教导民众呢！”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 5:13; 使徒行传 4:21; 马太福音 26:5"> 于是守卫长和差役一起过去把使徒带过来，但没有用暴力，怕众民用石头打他们。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 5:22; 使徒行传 4:7; 路加福音 22:66"> 使徒们被带过来后，站在公议会前。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马太福音 27:25; 使徒行传 7:52; 使徒行传 4:10–11"> 大祭司问他们：“我们难道没有吩咐过你们，不准再以此名教导民众吗？现在看看，你们让整个耶路撒冷都知道了你们的教导，你们还想把那人的死怪在我们头上！”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行传 4:19; 1 Samuel 15:24; 马可福音 7:7–9"> 彼得和众使徒回答：“我们服从上帝必须高于服从人。</span>
<span className="v" id="v30" data-v="30" data-xref="加拉太书 3:13; 彼得前书 2:24; 使徒行传 10:39"> 你们将其放上十字架杀害的耶稣，我们祖先的上帝已使他复活。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 24:47; 使徒行传 2:33; 希伯来书 2:10"> 上帝把他高举在自己的右边，获得首领和救世主的荣耀，以此让以色列人悔改，让他们的罪得以赦免。</span>
<span className="v" id="v32" data-v="32" data-xref="约翰福音 15:26–27; 希伯来书 2:3–4; 使徒行传 1:8"> 我们为所发生的这一切作证，上帝向顺从他之人赐予的圣灵也为这一切作证。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="使徒行传 7:54; 使徒行传 2:37; 路加福音 4:28–29"> 公议会的人听闻此言非常恼怒，想要杀了他们。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 22:3; 路加福音 2:46; 路加福音 5:17"> 但公议会中有一个名叫迦玛列的法利赛人，是民众所尊敬的律法教师。他站起来吩咐差役把使徒暂时带出去。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="使徒行传 22:26; Jeremiah 26:19; 马太福音 27:19"> 然后他对大家说：“以色列人的首领们，你们在谋划处理这些人时应该小心。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 8:9; 彼得后书 2:2; 加拉太书 6:3"> 从前有个叫丢大的人想要扬名立万，大约有四百人跟随他。但他被杀后，跟随他的人便作鸟兽散，什么都没有剩下。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 2:1–2; Psalms 7:14–15; 马太福音 26:52"> 在他之后，一个加利利人叫犹大，在人口普查的过程中也召集了众人跟从他。他死去后，那些听命于他的人也就消失了。</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 15:13; Lamentations 3:37; Isaiah 8:9–10"> 所以对于眼前的事情，劝你们不要管这些人，随他们吧！如果他们的计划或行动出于人意，必将失败。</span>
<span className="v" id="v39" data-v="39" data-xref="Proverbs 21:30; Isaiah 46:10; 马太福音 16:18"> 如果出于上帝，你们就不能打败他们，那样你们就是在对抗上帝了！”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="马太福音 10:17; 使徒行传 5:28; 使徒行传 4:17–21"> 他们接受了他的劝告，于是把使徒传进来，鞭打一顿并禁止他们以耶稣之名教导，然后就把他们释放了。</span>
<span className="v" id="v41" data-v="41" data-xref="雅各书 1:2; 彼得前书 4:13–16; 路加福音 6:22"> 使徒高兴地从公议会出来，他们觉得为主之名受辱是一件值得的事情。</span>
<span className="v" id="v42" data-v="42" data-xref="使徒行传 2:46; 使徒行传 20:20; 路加福音 21:37"> 他们继续每天在圣殿中或走家串户地教导众人，昭告耶稣即基督。</span>
</div>
</div>

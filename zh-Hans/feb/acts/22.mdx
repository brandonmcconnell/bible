<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 7:2; 使徒行传 28:17; 使徒行传 13:26"> 他说：“各位父老兄弟，请听我在你们面前的申辩。”</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 21:40"> 众人听到保罗用阿拉姆语说话，立刻变得非常安静。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="使徒行传 26:5; 腓立比书 3:5–6; 使徒行传 9:11"> 他开始讲述：“我是犹太人，生在基利家的大数。但其实我是在这座城里长大，在迦玛列门下接受教育。老师教育我要严格遵守祖先的律法，我满腔热情地对待上帝，就像今天这里的所有人一样。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 22:19–20; 提摩太前书 1:13–15; 使徒行传 26:9–11"> 我也曾经迫害信奉此道之人，将他们处死，把男女信徒投入监狱。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 9:1–2; 路加福音 22:66; 使徒行传 5:21"> 大祭司和公议会的长老都可以为我作证。我曾收到他们的授意信，要求处理在大马士革的犹太人信徒。于是我去了那里捉拿那些人，把他们带到耶路撒冷接受惩罚。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 9:3–8; 使徒行传 26:12–18; 启示录 1:16"> 那天大约中午时分，我正在去往大马士革的路上，即将抵达目的地时，忽然一束耀眼的光芒从天而降，环绕着我。</span>
<span className="v" id="v7" data-v="7" data-xref="Jeremiah 2:9; 马太福音 25:45; Genesis 22:11"> 我仆倒在地，只听见一个声音对我说：‘扫罗啊，扫罗，你为什么迫害我？’</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 26:9; 1 Samuel 8:7; Exodus 16:7–8"> 我答道：‘主啊，你是谁？’<br />他说：‘我就是你迫害的拿撒勒人耶稣。’</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 9:7; Daniel 10:7; 使徒行传 26:13"> 与我同行之人只看见那束光，却听不到与我说话的声音。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 16:30; 使徒行传 22:12–16; 使徒行传 2:37"> 我说：‘主啊，我该怎么做？’<br />主告诉我：‘站起来，进到大马士革城里，那里会有人告知安排你做的事情。’</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 9:8–9; 使徒行传 13:11; Isaiah 42:16"> 那束光如此强烈，我的双眼便看不到了，我的同伴们牵着我的手走进了大马士革。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 10:22; 使徒行传 6:3; 约翰三书 1:12"> 有一个人名叫亚拿尼亚，是一名遵守律法的虔诚之人，当地所有犹太人都很敬重他。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 9:17–18; 腓利门书 1:16"> 他站在我旁边对我说：‘扫罗兄弟，你现在可以看见了。’就在那一刻，我又能看到了。我看到了他。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="加拉太书 1:12; 哥林多前书 15:8; 哥林多前书 9:1"> 他对我说：‘我们祖先的上帝指认你来理解他的旨意，去见真正良善的正义之人，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="即耶稣。">a</a></sup>去听见他要对你所说的一切。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 23:11; 使徒行传 4:20; 约翰福音 15:27"> 对于你的所见所闻，你将向所有人作证。所以你还在等什么呢？</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 2:38; 使徒行传 2:21; 提多书 3:5"> 起来受洗去吧，呼唤他的名，洗净你的罪吧。’</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 12:1–4; 使徒行传 10:9–10; 使徒行传 9:26–28"> 我回到耶路撒冷后，有一次在殿里祷告时，忽然在恍惚间看到了异象。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 9:29; 路加福音 21:21; Ezekiel 3:6–7"> 主在异象中对我说：‘快！你必须尽快离开耶路撒冷，因为他们无法接受你所讲述关于我的一切。’</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 22:4; 马太福音 10:17; 使徒行传 8:3"> 我回答：‘主啊，他们肯定知道，我曾在很多会堂中拷打信你之人，将它们送进监牢，</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 7:58; 使徒行传 8:1; 罗马书 1:32"> 司提芬因为为你作证而被杀害的时候，我就站在那里，而且完全支持那些杀死他的人，还为他们拿着衣服。’</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 9:15; 提摩太前书 2:7; 以弗所书 3:6–8"> 主对我说：‘现在就离开吧，我要派你到远方异教徒那里去。’”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 25:24; 使徒行传 21:36; 约翰福音 19:15"> 众人一直都在听他说的话，但听到这里，他们就高喊：“应该把这种人从世间除掉，他不配活着！”</span>
<span className="v" id="v23" data-v="23" data-xref="2 Samuel 16:13; 使徒行传 26:11; Ecclesiastes 10:3"> 他们喊叫着，扯开外衣，向空中扔撒尘土。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 21:31–32; 使徒行传 21:34; 约翰福音 19:1"> 就在这时，千夫长下令把保罗带到军营，命人用鞭刑拷问他，想要找出高声喊叫的民众反对他的原因。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 16:37; 使徒行传 25:16; 使徒行传 27:43"> 士兵将他四肢伸开，用皮带将其捆住，准备施以鞭刑。这时保罗对站在旁边的百夫长说：“你们鞭打一个还没有定罪的罗马公民，这合法吗？”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 23:27; 使徒行传 22:29"> 百夫长听言就去报告千夫长，说：“这个人是罗马公民，该怎么办？”</span>
<span className="v" id="v27" data-v="27"> 千夫长就过来问保罗：“告诉我，你真是罗马公民吗？”他说：“是的。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 千夫长说：“为了获得罗马公民的身份，我可是花了一大笔钱。”保罗说：“我生下来就是罗马公民。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行传 21:33; 使徒行传 22:24–26; 使徒行传 16:38–39"> 于是那些想要拷问他的人立刻走开了。得知他是罗马公民，又曾被捆绑起来，千夫长感到很害怕。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="囚禁未定罪的罗马公民为违法行为。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行传 23:28; 使徒行传 21:33; 使徒行传 21:11"> 第二天，千夫长想要了解为什么犹太人要控告保罗，于是就解开他身上的锁链，随后召集祭司长和公议会全体成员，将保罗带到众人面前。</span>
</div>
</div>

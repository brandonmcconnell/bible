<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="feb" data-translation-id="cmn_feb" data-translation-label="易读圣经" data-book="ACT" data-book-slug="acts" data-book-name="使徒行传" data-chapter="8" data-verses="40">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 22:20; Daniel 3:16–18; 使徒行传 5:40"> 扫罗也认可了对司提芬的杀戮。从那天起，耶路撒冷的教会受到严重迫害。除了使徒以外，其他信徒都散落到犹太和撒玛利亚各地。</span>
<span className="v" id="v2" data-v="2" data-xref="Genesis 50:10–11; Genesis 23:2; Jeremiah 22:18"> （有些虔诚之人怀着巨大的悲痛安葬了司提芬）。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前书 1:13; 加拉太书 1:13; 哥林多前书 15:9"> 扫罗却开始残害教会，挨家挨户地将男男女女拖出去坐监。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="马太福音 10:23; 使徒行传 11:19; 使徒行传 8:1"> 那些散落各地的信徒，会在所到之处传扬上帝之道。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 6:5; 使徒行传 21:8; 使徒行传 8:35–36"> 腓利来到了撒玛利亚城，向民众宣讲基督。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 4:41–42; 2 Chronicles 30:12; 马太福音 20:15–16"> 群众听到腓利所讲，看见他所行神迹，于是便全心聆听他的一字一句。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 10:1; 使徒行传 14:8–10; 马可福音 16:17–18"> 许多魔鬼附体之人得救了，他们身上的恶灵嚎叫着被驱赶出来，还有许多瘫痪和残疾之人都得到痊愈。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 13:52; 使徒行传 13:48; 使徒行传 8:39"> 城里的民众们欢天喜地。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 13:6; 使徒行传 5:36; 约翰福音 7:18"> 城里有一人名叫西门，善用邪术。他自称是一位重要的大人物，让撒玛利亚人为之而惊叹。</span>
<span className="v" id="v10" data-v="10" data-xref="Jeremiah 31:34; 彼得后书 2:2; 启示录 13:3"> 城中之人无论高高在上还是卑微在下，都听从于他，说：“这就是那‘大能上帝’之人。”</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 8:9; 加拉太书 3:1; Isaiah 44:25"> 因为他长久以来用邪术蒙蔽众人，让他们对之感到信服。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 2:38; 使徒行传 1:3; 马太福音 28:19"> 腓利来此向他们传递上帝之国的福音，宣讲耶稣基督之名，于是众人相信了腓利，男女女女均受了洗。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 8:6–7; 约翰福音 5:20; 使徒行传 19:11"> 连西门自己也相信并受洗，然后跟随腓利，为所目睹的神迹和奇迹而惊叹不已。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:13; 帖撒罗尼迦前书 3:2; 加拉太书 2:9"> 听说撒玛利亚的居民接受了上帝之道，耶路撒冷的使徒就派彼得和约翰到那里去。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 2:38; 约翰福音 16:23–24; 约翰福音 14:13–14"> 二人赶到后就为改变信仰的信徒祷告，让他们接受圣灵。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 2:38; 使徒行传 19:2; 马太福音 28:19"> 但圣灵尚未降在他们任何一个身上，他们只是以耶稣之名受了洗。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 19:6; 使徒行传 6:6; 提摩太后书 1:6"> 使徒为他们行按手礼，他们便接受了圣灵。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="提摩太前书 6:5; 马太福音 10:8; 2 Kings 8:9"> 西门看见使徒按手后就有圣灵降临，就拿出钱给使徒，</span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 14:7–11; 约翰三书 1:9; 约翰福音 5:44"> 他请求道：“把这力量也给我吧，让我为谁按手，谁就可以接受圣灵。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="Daniel 5:17; 马太福音 10:8; 使徒行传 2:38"> 彼得对他说：“让你的钱跟你一同灭亡吧！你居然以为上帝的恩赐可以用钱购买！</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 4:13; Psalms 36:1; 马太福音 6:22–24"> 你不属于这里，这里的一切也不属于你，因为在上帝眼中，你的态度大错特错。</span>
<span className="v" id="v22" data-v="22" data-xref="提摩太后书 2:25–26; Daniel 4:27; 希伯来书 4:12"> 为自己的罪恶行径忏悔吧！祈求主，请求他原谅你这样的想法。</span>
<span className="v" id="v23" data-v="23" data-xref="Isaiah 58:6; Proverbs 5:22; 约翰福音 8:34"> 我可以看出你心中满是强烈的嫉妒，被你的恶所捆绑。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="Exodus 8:8; Numbers 21:7; Job 42:8"> 西门回答：“请为我求主，别让你们说的事情发生在我身上！”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行传 20:21; 使徒行传 26:22–23; 使徒行传 1:8"> 使徒作了见证并宣讲了主的道，然后就返回耶路撒冷，沿途在撒玛利亚人的许多村庄里传扬福音。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 5:19; 希伯来书 1:14; 2 Kings 1:3"> 主的天使对腓利说：“准备好向南走，你要去耶路撒冷到迦萨的那条荒漠道路。”</span>
<span className="v" id="v27" data-v="27" data-xref="Zephaniah 3:10; Psalms 68:31; Isaiah 56:3–8"> 于是腓利动身出发，路上遇到一名衣索匹亚人，是衣索匹亚女王干大基<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="干大基不是女王的名字，而是她的头衔，类似于“法老。”">a</a></sup>手下一名位高权重的官员，掌管女王全部国库。他去耶路撒冷去礼拜。</span>
<span className="v" id="v28" data-v="28" data-xref="歌罗西书 3:16; Isaiah 1:1; 使徒行传 28:25"> 在回来的路上，坐在马车上翻看以赛亚先知的书。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行传 10:19; 使徒行传 11:12; 使徒行传 20:22–23"> 圣灵对腓利说：“走过去，走近那车子。”</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 24:44–45; 约翰福音 5:39; 以弗所书 5:17"> 于是腓利跑过去，听见那官员在读以赛亚先知的书，就询问：“你明白自己看到的内容吗？”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="罗马书 10:14; Psalms 73:16–17; Isaiah 29:18–19"> 那官员说：“没有人指导，我怎能明白呢？”于是就请腓利上车，坐在他身边。</span>
<span className="v" id="v32" data-v="32" data-xref="Isaiah 53:7–8; 彼得前书 2:21–24; Jeremiah 51:40"> 他当时在读的那段经文是：“他像绵羊一样被牵走宰杀，又像羔羊一样在剪羊毛之人面前沉默无声，他一句话也不说。</span>
<span className="v" id="v33" data-v="33" data-xref="Isaiah 53:12; Isaiah 53:8; Zechariah 13:7"> 他受尽屈辱，得不到公平的审判。没有人知道他的后裔会是谁，因为他的生命走向终点。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“他的生命被从人间夺走。”引自《以赛亚书》53:7-8。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马太福音 15:15; 马太福音 13:36; 马太福音 2:2–4"> 那官员对腓利说：“请问先知这番话是在说谁？他自己？还是指别人？”</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 24:27; 使徒行传 18:28; 使徒行传 28:23"> 腓利开始解释，从这段经文开始，向他传讲耶稣。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 10:47; 约翰福音 3:5; 提多书 3:5–6"> 他们一路走下去，来到一处溪流，官员说：“你看，这里有水，为什么我不受洗呢？”</span>
<span className="v" id="v37" data-v="37"> <sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="在最早期的手稿中没有这节经文。">c</a></sup></span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 4:1; 约翰福音 3:22–23"> 于是官员吩咐停车，腓利和他两人走到水中，腓利给他施洗。</span>
<span className="v" id="v39" data-v="39" data-xref="1 Kings 18:12; 2 Kings 2:16; Ezekiel 8:3"> 他们从水里出来时，主的圣灵就把腓利带走了，送到了亚锁都。官员再也没有见到他，但仍满心喜悦地继续旅程。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行传 21:8; 使徒行传 23:23; 使徒行传 23:33"> 腓利在亚锁都走遍各城，传讲福音，最终来到该撒利亚。</span>
</div>
</div>

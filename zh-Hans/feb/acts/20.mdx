<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 7:5; 使徒行传 19:21; 提摩太前书 1:3"> 骚乱平息以后，保罗把信徒们召集在一起，鼓励他们一番后便辞行前往马其顿。</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦前书 2:3; 帖撒罗尼迦前书 4:1; 歌罗西书 1:28"> 他走遍该地区的各个角落，激励鼓舞那里的信徒，然后来到了希腊。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 20:19; 哥林多后书 11:26; 使徒行传 9:23–24"> 他在那里住了三个月后，准备乘船去叙利亚。就在这时，他发现有些犹太人想要密谋对付他，于是他决定通过马其顿返回。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 19:29; 以弗所书 6:21; 提摩太后书 4:20"> 与他同行的人有：比里亚人所巴特（毕罗斯之子）、帖撒罗尼迦人亚里达古和西公都，特庇人该犹和提摩太，亚西亚人推基古和特罗非摩。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 16:8; 使徒行传 16:10–11; 提摩太后书 4:13"> 这些人先行，在特罗亚等候我们。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 12:3; 使徒行传 16:12; Exodus 23:15"> 我们则在除酵节后乘船从腓立比出发，五天后在特罗亚与他们会合，在那里停留了一个星期。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 16:2; 使徒行传 2:42; 约翰福音 20:19"> 星期日那天，我们聚在一起用餐。保罗计划第二天清晨离开，在当天一直讲道到午夜时分。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 1:13; 路加福音 22:12"> （我们聚餐地点的楼上，点亮了许多灯火。）</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马可福音 13:36; 马太福音 26:40–41; Jonah 1:5–6"> 有一个名叫犹推古的少年坐在窗台上，因为保罗讲道的时间很长，他越发困倦，于是便睡了过去，从三楼坠下去，待众人把他扶起来时，发现他已经死去。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马可福音 5:39; 马太福音 9:23–24; 1 Kings 17:21–22"> 保罗走下楼，趴在他身上把其抱住，说：“别担心，他还活着。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 20:7; 使徒行传 20:9"> 随即他回到楼上，掰开饼与众人继续讲道，直到天明才离开。</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦后书 2:16; 帖撒罗尼迦前书 5:14; 哥林多后书 1:4"> 他们把已经活过来的少年带回家，对此事深表感激。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马可福音 6:46; 马可福音 1:35; 马可福音 6:31–33"> 我们上船后向亚朔出发，按计划我们需要在那里与保罗会和，因为他走的是陆路。</span>
<span className="v" id="v14" data-v="14"> 我们在亚朔与他会合后，接他上船一同去往米推利尼。</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太后书 4:20; 使徒行传 20:17"> 随后又乘船去了基阿，第二天在撒摩短暂停留，接下来到了米利都。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 16:8; 使徒行传 2:1; 使徒行传 19:21"> 保罗希望能在五旬节赶到耶路撒冷，所以决定不在以弗所停留，以免在亚西亚耽搁时间。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="提多书 1:5; 使徒行传 11:30; 提摩太前书 5:17"> 在米利都，他派人给以弗所教会的长老捎去口信。</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 1:5–6; 使徒行传 18:19; 使徒行传 19:1"> 他们抵达目的地后，保罗说：“你们知道从我们一起抵达亚西亚的第一天起，我的表现一直都很好。</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 3:24; 哥林多后书 2:4; 罗马书 12:11"> 我以谦卑之心服侍主，经常泪流满面，还要忍受犹太人密谋带来的麻烦和压力。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 20:27; 提摩太后书 4:2; 使徒行传 5:42"> 但我一直向你们讲述会对你们有益的事，毫无保留。在走街串巷的过程中，我公开向你们讲道。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 2:38; 使徒行传 11:18; 约翰一书 5:11–13"> 我向犹太人和希腊人都作过见证，想要他们悔改并归于上帝，相信我们的主耶稣，这一点很重要。</span>
<span className="v" id="v22" data-v="22" data-xref="雅各书 4:14; 哥林多后书 5:14; 彼得后书 1:14"> 现在，灵坚持让我去耶路撒冷，我不知道自己在那里会遭遇什么事，</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 9:16; 帖撒罗尼迦前书 3:3; 使徒行传 21:4"> 只知道在我所造访的所有城中，圣灵都在警告我，将有监牢和苦难在等着我。</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太后书 4:6–8; 哥林多后书 4:1; 哥林多后书 12:10"> 但我并不吝惜自己的性命，只想完成自己的使命，达成主耶稣分派给我的职责，为上帝恩典的福音作见证。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行传 28:31; 使徒行传 20:38; 马太福音 4:23"> 我与你们讲述了上帝之国。现在我确信，你们无法再见到我了。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 18:6; Ezekiel 3:18–21; Ezekiel 33:2–9"> 所以我今天要向你们宣布，如果有人迷失，那不是我的责任。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“我没有导致任何人流血。”可能参考《以西结书》33:8-9。">a</a></sup></span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 20:20; 帖撒罗尼迦前书 2:4; 加拉太书 1:7–10"> 上帝想要你们知道的，我已经毫无保留地告诉了你们。</span>
<span className="v" id="v28" data-v="28" data-xref="彼得前书 5:2–3; 提摩太前书 4:16; Isaiah 40:11"> 请照顾好自己，也照顾好圣灵派你们看管的羊群。主用自己的鲜血建立的教会，你们要为之做出贡献。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 7:15; 彼得后书 2:1; 约翰福音 10:12"> 我知道在我离开之后，必有凶狠豺狼闯到你们中间，不肯放过你们所看守的羊群。</span>
<span className="v" id="v30" data-v="30" data-xref="提摩太前书 1:19–20; 提摩太后书 4:3–4; Proverbs 23:33"> 你们中也会有人开始颠倒黑白，引诱信徒跟从他们。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 19:8; 使徒行传 20:19; 使徒行传 19:10"> 所以要小心，别忘记三年来，我日夜不停地教导你们，经常为你们泪流满面。</span>
<span className="v" id="v32" data-v="32" data-xref="歌罗西书 1:12; 以弗所书 1:14; 歌罗西书 3:24"> 现在我就要把你们交给上帝的关爱，交给他恩典之道，这道可以让你们成长，并为你提供属于所有遵守正道的人的遗产。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多后书 11:9; 哥林多前书 9:12; 哥林多前书 9:18"> 我从未贪念任何人的金银或衣服。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 18:3; 哥林多前书 4:12; 帖撒罗尼迦后书 3:8–9"> 你们知道我凭借自己的双手行事，满足我自己和同伴们的需要。</span>
<span className="v" id="v35" data-v="35" data-xref="希伯来书 13:16; Proverbs 19:17; 哥林多后书 9:6–12"> 我凡事都以身作则，努力帮助那些软弱之人，牢记主耶稣的教会：‘给予远比获得更有福。’”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="使徒行传 21:5; 路加福音 22:41; 腓立比书 4:6"> 说罢这番话，他跪下来同大家一起祷告。</span>
<span className="v" id="v37" data-v="37" data-xref="提摩太后书 1:4; 哥林多前书 16:20; 帖撒罗尼迦前书 5:26"> 众人痛哭着抱住保罗，亲吻他。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 15:3; 哥林多前书 16:11; 使徒行传 20:25"> 保罗说他们不会再见他，这句话让他们伤心不已。随后，他们和他一起走到船上。</span>
</div>
</div>

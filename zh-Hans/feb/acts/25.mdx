<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 23:34; 使徒行传 25:5; 使徒行传 8:40"> 非斯都抵达这个省<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="罗马的犹太省。">a</a></sup>三天后，就从该撒利亚去了耶路撒冷。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 25:15; Proverbs 4:16; 使徒行传 24:1"> 祭司长和犹太人首领在他面前控告保罗，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 9:24; 使徒行传 23:12–15; 1 Samuel 23:19–21"> 请求他把保罗押到耶路撒冷，这样他们就能埋伏在路上杀死他。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 24:23"> 但非斯都的回答是，保罗现在关押在该撒利亚，他马上要回到那里去。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 25:25; 约翰福音 18:29–30; 使徒行传 25:18–19"> 他对众人说：“你们首领可以和我一起，如果这个人做错了什么, 可以控告他。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 25:17; 使徒行传 25:10; 马太福音 27:19"> 非斯都在那里停留了十天八天后，就回到该撒利亚，然后在第二天开庭，吩咐把保罗带上来。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 24:13; 路加福音 23:10; 使徒行传 25:24"> 保罗刚走进来，从耶路撒冷来的犹太人就站在他周围，提出许多重罪指控，但却无法给出证据。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 24:12; 使徒行传 28:17; 哥林多后书 1:12"> 保罗为自己辩护：“无论是从犹太人律法、圣殿或凯撒的角度来讲，我都没有犯下任何罪行。”</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 24:27; 使徒行传 12:3; 使徒行传 25:20"> 但非斯都为了满足犹太人的想法，就问保罗：“那你愿意去耶路撒冷，让我在那里审问这个案子吗？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 27:18; 哥林多后书 4:2; 使徒行传 28:18"> 保罗回答：“此刻我站在凯撒的法庭面前，这里就是我应当受审的地点。你很清楚，我对犹太人并未做过错事。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 28:19; 使徒行传 26:32; 使徒行传 25:25"> 如果我犯下罪行，做过应该被判死罪的事情，我不会请求宽恕。但如果这些人对我的控告不属实，谁也别想把我送给他们。我要向凯撒上诉。”</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 19:21; 腓立比书 1:12–14; 腓立比书 1:20"> 非斯都与议会商量了一番后答复：“既然你想要向凯撒上诉，你应该这样做！”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 8:40; 使徒行传 26:1; 使徒行传 26:27–28"> 几天后，亚基帕王和百尼基来到该撒利亚，然后到非斯都这里拜访。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 24:27"> 他们停留了一些时日，非斯都向国王讲述了保罗的案子。他说：“有个囚犯，是腓力斯在位时留下来的案子。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 25:1–3; Esther 3:9; 路加福音 18:3–5"> 我在耶路撒冷的时候，祭司长和犹太人长老控告他，要求对他定罪。</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 7:51; Deuteronomy 19:17–18; 使徒行传 23:30"> 我的答复是，被告还没有和原告当面对证，没有获得机会指控进行自我辩护，就不能把他送过去，这不符合罗马法律。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 25:6; 使徒行传 25:10"> 所以当控告方抵达这里后，我马上就在第二天开庭，吩咐把那人提出来。</span>
<span className="v" id="v18" data-v="18"> 但当原告发言的时候，他们的指控并非我所想的罪行。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 23:29; 使徒行传 18:15; 哥林多前书 15:3–4"> 事实上，他们所进行的辩论都是宗教问题，还谈到了一位名叫耶稣的死人，但保罗却说他还活着。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 25:9"> 我不知道如何调查处理这样的事情，就问他是否愿意去耶路撒冷接受审问。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 4:16; 路加福音 2:1; 使徒行传 25:10–11"> 但保罗要求他的案子应该由皇帝裁判，我就下令把他关起来，找机会把他送给凯撒。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 9:15; 马太福音 10:18; Isaiah 52:15"> 亚基帕对非斯都说：“我也想听听这人说些什么。”非斯都说：“那我安排你明天过来听。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 26:30; 使徒行传 25:13; 约翰一书 2:16"> 第二天，亚基帕和百尼基一起在盛大的仪式中抵达，与千夫长和城中的名人一起进了法庭。非斯都吩咐把保罗提出来。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行传 22:22; 使徒行传 25:7; 使徒行传 25:2–3"> 非斯都说：“亚基帕王和在座的各位，你们面前的这个人，耶路撒冷和本地的犹太人都向我情愿，表示应该对他处以死刑。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 23:29; 使徒行传 25:11–12; 路加福音 23:4"> 但我发现他并没有犯下应处死之罪。他自己想要向皇帝上诉，我就决定把他押解过去。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 26:2–3"> 但对于这个人，我实在没有什么明确的事情可以呈奏皇帝。所以我把他带到诸位面前，特别是亚基帕王面前，希望能够找到一些可以向皇帝陈述的内容。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 7:51; Proverbs 18:13"> 对我来说，在没有解释对他的指控的情况下就送囚犯似乎是不公平的。”</span>
</div>
</div>

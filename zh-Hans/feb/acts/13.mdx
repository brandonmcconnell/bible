<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 4:36; 使徒行传 15:35; 使徒行传 11:22–27"> 在安提阿教会中有几名先知和教师：巴拿巴、西门（尼结）、古利奈人路求、马念（君王希律儿时的伙伴）和扫罗。</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太书 1:15; 使徒行传 9:15; 哥林多前书 12:11"> 他们在膜拜主并进行禁食的时候，圣灵说：“让巴拿巴和扫罗<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或“专门去做。”">a</a></sup>为我做事。”</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 6:6; 提摩太后书 2:2; 使徒行传 13:2"> 教会成员禁食、祈祷并把手放在他们身上祝福之后，他们就送他们上路了。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 4:36; 使徒行传 13:2; 使徒行传 11:19"> 巴拿巴和扫罗在圣灵的指引下去了西流基，从那里乘船去往塞浦路斯。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 13:14; 使徒行传 13:46; 使徒行传 14:1"> 来到撒拉米后，他们就在犹太人的会堂中宣讲上帝之道，约翰<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这位约翰是约翰马可 (12:25)。">b</a></sup>担任他们的助手。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 7:15; 约翰一书 4:1; 哥林多后书 11:13"> 他们走遍整个岛屿，最终来到了帕弗，遇见一位自称巴·耶稣的犹太人术士，是个假先知。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 19:38; 使徒行传 13:12; 使徒行传 18:12"> 他与省长士求·保罗走的很近。这位省长非常睿智，特别邀请巴拿巴和扫罗来为他讲上帝之道。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太后书 3:8; 使徒行传 13:6–7; 提摩太后书 4:14–15"> 但这位术士（希腊名字叫做以吕马）不接受他们，试图让省长不要相信上帝。</span>
<span className="v" id="v9" data-v="9" data-xref="Micah 3:8; 使徒行传 4:8; 使徒行传 2:4"> 但被注满圣灵的扫罗（又名保罗）定睛看着他，</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 8:44; 哥林多后书 11:3; 马太福音 13:38"> 说：“你这满心欺诈、万恶满盈之人，魔鬼之子，正义的敌人！你总是在阻碍主的真理之路，为什么你不肯放弃呢？</span>
<span className="v" id="v11" data-v="11" data-xref="Exodus 9:3; Psalms 32:4; 希伯来书 10:31"> 看，主的惩罚已经到来，你将成为盲人，暂时看不见阳光。”黑暗和迷雾立刻笼罩着这位术士，他不得不找人牵他的手，给他领路。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 10:4–5; 使徒行传 13:7; 路加福音 4:22"> 省长看见眼前的一切，便信了上帝，主的教导让他惊讶不已。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 15:38; 使徒行传 2:10; 使徒行传 14:24–25"> 然后保罗和同伴从帕弗乘船来到旁非利亚的别加，约翰则离开他们返回耶路撒冷去了。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 16:13; 使徒行传 14:19; 使徒行传 13:5"> 他们一路前行，经过别加后抵达彼西底的安提阿，在安息日这天进入会堂，然后坐下来。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 13:22; 使徒行传 15:21; 马可福音 5:22"> 他们朗读了律法和先知的书籍，会堂首领派人传来口信，说：“兄弟们，如果你们有什么鼓励之语，就说说吧！”</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 12:17; 使徒行传 13:26; 使徒行传 10:2"> 保罗站起来，伸手示意大家看过来，然后开始说：“以色列人和所有敬畏上帝之人，听我说。</span>
<span className="v" id="v17" data-v="17" data-xref="Deuteronomy 7:6–8; Isaiah 63:9–14; Psalms 105:23–24"> 我们的祖先寄居在埃及的土地时，以色列人民的上帝选中了他们，凭其伟大力量带领他们走出埃及，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 7:36; Psalms 95:8–11; Psalms 106:13–29"> 然后他在旷野耐心地照顾他们四十年。</span>
<span className="v" id="v19" data-v="19" data-xref="Deuteronomy 7:1; Psalms 78:55; 使徒行传 7:45"> 上帝在消灭了迦南七国后，就把那片土地分给以色列人的祖先，让他们代代继承，这样又过了 450 年。</span>
<span className="v" id="v20" data-v="20" data-xref="Judges 2:16; 1 Samuel 3:20; 2 Kings 23:22"> 后来上帝又为他们派来首领，一直持续到撒母耳先知的时刻。</span>
<span className="v" id="v21" data-v="21" data-xref="1 Samuel 10:1; 1 Samuel 15:1; 1 Samuel 12:12–19"> 人们请求上帝为他们送来国王，上帝就把便雅悯部落中一个人派来为王，他是基士的儿子扫罗，统治了四十年。</span>
<span className="v" id="v22" data-v="22" data-xref="1 Samuel 13:13–14; 1 Kings 15:5; Psalms 78:70–72"> 之后上帝又废去扫罗，选择大卫为王。在为大卫作证时，上帝说：‘我找到耶西的儿子大卫，他符合我的心意，将遵行我的一切旨意。’<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="见《撒母耳记》13:14。">c</a></sup></span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 1:1; Psalms 132:11; 启示录 22:16"> 耶稣是大卫的后裔，是上帝之前承诺带给以色列的救世主。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 1:22; 约翰福音 1:6–8; 路加福音 3:2–20"> 耶稣来临之前，约翰便昭告所有以色列人应该进行忏悔洗礼。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 3:11; 马可福音 1:7; 约翰福音 1:26–27"> 约翰即将完成他的使命时说：‘你们以为我是谁？我不是你们所寻找的那个人。但在我之后来的那个人，我就是给他解鞋带都不配。’<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《路加福音》3:16。">d</a></sup></span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 1:77; 罗马书 1:16; 路加福音 1:69"> 兄弟们、亚伯拉罕的子孙以及敬畏上帝的众人，这救赎之道已传授给我们。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 3:17; 路加福音 24:24–27; 路加福音 24:20"> 住在耶路撒冷的众人和他们的长官，他们不认识基督，也不理解安息日所读的先知之语。事实上，他们为耶稣定罪恰好应验了先知的预言。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 23:21–25; 路加福音 23:14–16; 约翰福音 19:4"> 尽管他们无法找到宣判他死刑的罪状，但还是要求彼拉多杀害他。</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 23:53; 约翰福音 19:28; 约翰福音 19:30"> 预言中关于他们会对耶稣所做的一切，都应验了。然后他们把耶稣从十字架上取下并埋葬在坟墓中。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 2:24; 使徒行传 17:31; 马太福音 28:6"> 但上帝却使他死而复活。</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 24:48; 使徒行传 1:3; 使徒行传 1:11"> 多日后，他显现在那些从加利利到耶路撒冷一路跟随他的人面前，那些人现在就成了他在民众面前的见证者。</span>
<span className="v" id="v32" data-v="32" data-xref="罗马书 4:13; 使徒行传 26:6; Ezekiel 34:23"> 我们来此是向你们传递福音，通过耶稣的复活，上帝向我们祖先的承诺</span>
<span className="v" id="v33" data-v="33" data-xref="Psalms 2:7; 希伯来书 5:5; 希伯来书 1:5–6"> 都已向我们这些子孙应验了。就如《诗篇》第二篇所记：‘你是我子，今日我成为你父。’<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="引自《诗篇》2:7。">e</a></sup></span>
<span className="v" id="v34" data-v="34" data-xref="Isaiah 55:3; Psalms 89:2–4; 罗马书 6:9"> 上帝使他死而复生，不会再死去。他曾这样说：‘正如我向大卫所做的承诺，我所赐予你们的，神圣而值得相信。’<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="即《以赛亚书》55:3。">f</a></sup></span>
<span className="v" id="v35" data-v="35" data-xref="Psalms 16:10; 使徒行传 2:27–31; Psalms 49:9"> 《诗篇》 还说：‘你不会允许圣者见到腐朽。’<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="引自《诗篇》16:10。">g</a></sup></span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 2:29; 2 Samuel 7:12; 1 Kings 2:10"> 但大卫在自己的世界中完成了上帝派给他的使命后，就死去了，与他的祖先葬在一起，躯体也腐朽了。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 13:30; 使徒行传 2:24"> 唯独上帝令其复活这一人，没有看到腐朽。</span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 24:47; 约翰一书 2:12; 哥林多后书 5:18–21"> 兄弟们，我希望你们理解我们正在讲述的一切，通过这个人，罪已经得到了宽恕。</span>
<span className="v" id="v39" data-v="39" data-xref="罗马书 10:4; 加拉太书 2:16; 罗马书 8:3"> 通过这个人，所有信他之人都会远离错误，实现道德正义，<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="也有“道德正确”的意思，但在这里的含义远非“正确”，因此在这里添加了“道德”一词。">h</a></sup>但凭着摩西的律法，你永远都无法达到这种正义。</span>
<span className="v" id="v40" data-v="40" data-xref="Malachi 4:1; 希伯来书 3:12; Malachi 3:2"> 务必不能让先知在书上所说降临在你们身上：</span>
<span className="v" id="v41" data-v="41" data-xref="Habakkuk 1:5; 彼得前书 4:17; 罗马书 11:7–14"> ‘傲慢的人呐！你们会惊奇地看到，然后死去！因为我在你们生命中所做的事情，即使有人向你讲述，你也永远都无法相信！’”<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="引自《哈巴谷书》1:5。">i</a></sup></span>
<span className="v" id="v42" data-v="42" data-xref="使徒行传 28:28; 使徒行传 10:33; 马太福音 19:30"> 保罗和巴拿巴打算离开，众人请他们在下一个安息日再来讲述更多。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行传 11:23; 使徒行传 14:22; 以弗所书 2:8"> 这次会堂的聚会结束后，许多犹太人和归信犹太教的虔诚教徒，都跟随了保罗和巴拿巴。两人和他们交流，鼓励他们始终紧随上帝的恩典。</span>
<span className="v" id="v44" data-v="44" data-xref="Psalms 110:3; Genesis 49:10; Isaiah 11:10"> 到了下一个安息日，几乎全城的人都赶来，希望聆听上帝之道。</span>
<span className="v" id="v45" data-v="45" data-xref="犹大书 1:10; 使徒行传 18:6; 使徒行传 5:17"> 犹太人看见这攒动人群，感到异常嫉妒，于是开始驳斥保罗所讲之道，诅咒他。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒行传 28:28; 马太福音 21:43; 使徒行传 18:5–6"> 保罗和巴拿巴却强有力地回应：“我们必须先向你们讲述上帝之道。既然你们拒绝这道，就代表你们觉得自己不配获得永生，所以我们现在要去异教徒那里去了。</span>
<span className="v" id="v47" data-v="47" data-xref="Isaiah 49:6; Isaiah 42:6; 路加福音 2:32"> 主吩咐过我们说：‘我让你们成为异教徒的光，你们将把拯救带到世界的尽头。’”<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="引自《以赛亚书》49:6。">j</a></sup></span>
<span className="v" id="v48" data-v="48" data-xref="罗马书 8:29–30; 以弗所书 1:4; 罗马书 11:7"> 异教徒听见这个消息分外欢喜，赞美主之道，所有被选为永生之人都相信了上帝。</span>
<span className="v" id="v49" data-v="49" data-xref="使徒行传 12:24; 使徒行传 19:10; 使徒行传 19:26"> 上帝之道就这样传遍那个地区。</span>
<span className="v" id="v50" data-v="50" data-xref="使徒行传 14:19; 使徒行传 13:45; 使徒行传 14:2"> 但犹太人教唆虔诚的尊贵女性和城中的首领，煽动大家迫害保罗和巴拿巴，把他们驱逐出境。</span>
<span className="v" id="v51" data-v="51" data-xref="马太福音 10:14; 使徒行传 18:6; 路加福音 9:5"> 于是两人当众跺掉脚上的尘土以示抗议，向以哥念走去。</span>
<span className="v" id="v52" data-v="52" data-xref="罗马书 15:13; 帖撒罗尼迦前书 1:6; 使徒行传 4:31"> 而信徒们继续满心欢喜并被圣灵充满。</span>

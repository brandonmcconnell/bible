<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 5:6; 使徒行传 15:5; Leviticus 12:3"> 有几个来自犹太的人开始教授信徒。他们对信徒们说：“你们若不按照摩西定下的规矩行受割礼，就无法获得救赎。”</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 15:22–23; 使徒行传 15:6–7; 加拉太书 2:1–2"> 保罗和巴拿巴与他们进行了激烈的辩论，于是众人指派他们和其他几个人去耶路撒冷，向信徒和长老们讲述这个问题。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 14:27; 使徒行传 21:5; 哥林多前书 16:11"> 教会为他们送行后，他们便上路了。途径腓尼基和撒玛利亚，讲述异教徒如何改变信仰，这让所有信徒都很高兴。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 14:27; 使徒行传 15:12; 使徒行传 15:3"> 来到耶路撒冷后，教会、信徒和长老们接待了他们，他们也报告了上帝通过他们所行的一切。</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 5:1–3; 腓立比书 3:5–8; 使徒行传 15:1"> 但有几名法利赛派的信徒却提出了反对意见，他们说：“这些归信上帝的异教徒必须行割礼，教导他们遵守摩西的律法。”</span>
<span className="v" id="v6" data-v="6" data-xref="Proverbs 15:22; 希伯来书 13:7; 希伯来书 13:17"> 使徒和长老聚集在一起商讨此事。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 10:17–18; 加拉太书 2:7–9; 1 Chronicles 28:4–5"> 在进行了大量辩论后，彼得站起来对他们说：“兄弟们，你们知道过去上帝在你们中间选择了我，就是为了让异教徒可以听到福音之道，相信耶稣。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 1:24; 使徒行传 10:47; 使徒行传 14:3"> 那洞察我们思想<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或“知道我们思考的方式。”">a</a></sup>的上帝也表明接受他们，就像对待我们一样向他们赐以圣灵。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 3:6; 加拉太书 5:6; 使徒行传 10:28"> 上帝绝不会将我们和他们区别对待。因为他们相信上帝，所以上帝洁净了他们的思想。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 5:1; 马太福音 23:4; 加拉太书 4:9"> 现在你们为什么要反对上帝，把我们祖先和我们都无法承受的重负，放在这些信徒的身上？</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 3:24; 提多书 3:4–7; 提多书 2:11"> 我们确信承蒙主耶稣的恩典获得救赎，与他们有着同样的方式。”</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 14:27; 使徒行传 15:4; 使徒行传 21:19"> 巴拿巴和保罗述说了上帝通过他们在异教徒中所行的神迹奇事，所有人都专心聆听。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 12:17; 加拉太书 2:12; 雅各书 1:1"> 他们讲述完后，雅各说：“兄弟们，请听我说！</span>
<span className="v" id="v14" data-v="14" data-xref="彼得后书 1:1; 使徒行传 15:7–9; 路加福音 2:31–32"> 刚才西门<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这里的西门即彼得。">b</a></sup>讲述了上帝如何显示他对异教徒的关心，从他们中间挑选一名鉴定信仰上帝之人。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 15:8–12; 使徒行传 13:47"> 这符合了众先知所写下的问题，正如经上所记：</span>
<span className="v" id="v16" data-v="16" data-xref="Amos 9:11–12; Psalms 89:35–49; 路加福音 1:31–33"> ‘未来我要回归，重建大卫崩塌的宅邸，在废墟上将其重建，让它重新站立起来，</span>
<span className="v" id="v17" data-v="17" data-xref="Zechariah 2:11; Zechariah 8:20–23; Isaiah 65:1"> 我这样做，是为了让剩下的人可以追随主，包括所有呼唤我名的异教徒。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 1:4; 以弗所书 3:9; Isaiah 46:9–10"> 这就是主的真言，他很久以前就昭示了这一切。’<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《阿摩司书》9:11-12。">c</a></sup></span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 15:28; 加拉太书 1:7–10; 使徒行传 15:24"> 所以我认为，不应该为难那些归信上帝的异教徒。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 15:29; 启示录 2:20; Leviticus 3:17"> 我们应该给他们写信，告诉他们不吃祭祀偶像的食物<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="意为“污染神像。”">d</a></sup>、不要淫乱、要避开勒死的牲畜和血。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 13:15; 使徒行传 13:27; 哥林多后书 3:14–15"> 因为很久很久以来，各地都在教导摩西所写律法，每逢安息日，都会有人在会堂中诵读。”</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 15:27; 使徒行传 15:40; 帖撒罗尼迦前书 1:1"> 使徒、长老和教会所有人都认可这个方法，于是他们决定选出几名代表，派他们和保罗、巴拿巴一同到安提阿去。最终选择的人是犹大（巴撒巴）和西拉，他们是信徒中的领袖。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 23:26; 雅各书 1:1; 加拉太书 1:21"> 他们被派出去送信。信上说： “安提阿、叙利亚和基利家的非犹太异族<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="原意为“外邦人。”">e</a></sup>兄弟们，这里是来自使徒、长老和信徒们的问候。</span>
<span className="v" id="v24" data-v="24" data-xref="加拉太书 5:12; 加拉太书 5:10; 使徒行传 15:1"> 听说我们中有些人在向你们讲道时，让你们感到困扰和不安，其实我们并没有吩咐他们这样做。</span>
<span className="v" id="v25" data-v="25" data-xref="彼得后书 3:15; 使徒行传 1:14; 使徒行传 15:2"> 因此，我们一致同意选出几名代表，与我们挚爱的巴拿巴和保罗一起派去见你们，</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 14:19; 使徒行传 9:23–25; 腓立比书 2:29–30"> 这两个人曾为了主耶稣基督之名，置个人生死于不顾。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 15:22; 使徒行传 15:32; 约翰三书 1:13"> 我们派犹大和西拉同行，他们会亲口确认我们所说的一切。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 16:13; 启示录 2:24; 马太福音 11:30"> 圣灵和我们都认为，除了以下重要的要求，最好不要让你们承担更多重负。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 15:20; 使徒行传 21:25; 启示录 2:14"> 你们应该避免的是：不吃祭祀偶像的食物，要避开勒死的牲畜和血，不要淫乱。只要遵守这些要求就好了。上帝保佑你们！”</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 16:4; 使徒行传 6:2; 使徒行传 23:33"> 还有人被派到安提阿，在那里召集众人，交上这封书信。</span>
<span className="v" id="v31" data-v="31" data-xref="加拉太书 2:4–5; 腓立比书 3:3; 加拉太书 5:1"> 众人读罢，因信上的劝勉之语而感到欣慰。</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 11:23; 使徒行传 14:22; 使徒行传 13:1"> 犹大和西拉也是先知，他们说了许多鼓励兄弟们的话，让他们获得了更大的力量。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 16:11; 使徒行传 16:36; 希伯来书 11:31"> 住了一段时间后，他们打道回府，带走了众人向耶路撒冷信徒送去的祝福。</span>
<span className="v" id="v34" data-v="34"> <sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="有人认为第 34 句不是原文的一部分。">f</a></sup></span>
<span className="v" id="v35" data-v="35" data-xref="提摩太后书 4:2; 歌罗西书 1:28; 使徒行传 13:1"> 但保罗和巴拿巴却住在安提阿，与众人一起进行教导，传播主之道。</span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 14:6; 使徒行传 13:4; 使徒行传 13:51"> 过了一段时间，保罗对巴拿巴说：“我们回到曾经传道的那些城邦去吧，看看那里的信徒们现在如何了。”</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 12:12; 腓利门书 1:24; 使徒行传 13:5"> 巴拿巴打算带上约翰马可一同去，</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 13:13; Proverbs 25:19; 路加福音 14:27–34"> 但保罗认为带上他不合适，因为他当年在旁非利亚时曾经离开过他们，没有继续与他们一起完成自己的使命。</span>
<span className="v" id="v39" data-v="39" data-xref="歌罗西书 4:10; Ecclesiastes 7:20; 使徒行传 4:36"> 两人为此大吵一架，于是分道扬镳。巴拿巴带上马可，乘船去塞浦路斯。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行传 15:22; 使徒行传 14:26; 使徒行传 11:23"> 保罗则选了西拉，当他们离开时，信徒们将他们交托给主的恩典。</span>
<span className="v" id="v41" data-v="41" data-xref="使徒行传 15:23; 加拉太书 1:21; 使徒行传 15:32"> 保罗走遍了叙利亚和基利家，鼓舞那里的教会。</span>

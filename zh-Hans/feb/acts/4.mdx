<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="feb" data-translation-id="cmn_feb" data-translation-label="易读圣经" data-book="ACT" data-book-slug="acts" data-book-name="使徒行传" data-chapter="4" data-verses="37">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 22:4; 使徒行传 6:12; 使徒行传 23:6–9"> 使徒们向群众宣讲的时候，祭司、圣殿的守卫长和撒都该人都来到了他们这里。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 17:18; 帖撒罗尼迦前书 4:13–14; 使徒行传 24:14–15"> 看到使徒教导民众，讲述通过耶稣死而复生之事，他们非常愤怒。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 5:18; 马太福音 10:16–17; 使徒行传 16:19–24"> 于是他们逮捕了使徒，由于天色已晚，就决定把使徒拘留到第二天。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 2:41; 哥林多后书 2:14–17; 提摩太后书 2:9–10"> 但很多人都相信了这番宣讲，信徒的总人数已经增加到大约五千人。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 4:8; 马太福音 27:1–2; 路加福音 20:1"> 第二天，犹太人的长官、长老和宗教老师都聚集在耶路撒冷。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 3:2; 约翰福音 18:24; 马太福音 26:3"> 加入其中的还有大祭司亚那和该亚法、约翰、亚历山大，以及大祭司的家人。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 21:23; 马可福音 11:28; 使徒行传 5:40"> 他们让彼得和约翰站在他们面前，问到：“你们凭什么能力或以谁的名义做这件事？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 12:11–12; 马太福音 10:19–20; 使徒行传 2:4"> 身体充满圣灵的彼得对他们说：“民众的首领、长老，</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 3:15–17; 使徒行传 3:7; 约翰福音 10:32"> 我们今天受审，难道是因为我们对一名无法帮助他自己的人做出了善行？因为我们将他治愈？</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 5:29–32; 使徒行传 3:6; 使徒行传 2:36"> 如果是，你们各位和以色列全民都应当知道，站在你们面前这人之所以彻底痊愈，是以拿撒勒人耶稣基督之名，就是你们把他钉死在十字架上，上帝却使他死而复生的耶稣基督。</span>
<span className="v" id="v11" data-v="11" data-xref="Psalms 118:22–23; Isaiah 28:16; 马可福音 12:10–12"> ‘他是你们这些建筑工人丢弃的石头，但他其实是建筑的主要基石。’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《诗篇》118:22。">a</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 14:6; 哥林多前书 3:11; 约翰福音 3:36"> 任何其他人都无法拯救，在这天底下，无法以任何其他人类之名拯救我们。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 1:27; 约翰福音 7:15; 马太福音 11:25"> 他们看到彼得和约翰的自信，也知道这两人只是没有受过教育的普通民众，便感到很惊讶，同时也认出他们是耶稣的同伴。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 19:36; 使徒行传 3:8–12; 使徒行传 4:21"> 那被治愈之人和他们站在一起，看到眼前的情景，他们也无话反驳。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行传 26:30–32; 使徒行传 5:34–42; 马太福音 5:22"> 于是他们就让受审之人到公议会外面去，他们开始进行商议。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 21:15; 使徒行传 6:10; 约翰福音 12:18"> 他们说：“应该拿这几个人怎么办？他们的确显现了强大的神迹，而且所有住在耶路撒冷的人都知道了，我们无法否认。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 5:28; 罗马书 15:18–22; 使徒行传 5:24"> 但为了避免这件事在民众中越传越广，我们应该警告他们，不许再奉此名<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="显然是耶稣的名字，但他们甚至不想说出具体的名字……">b</a></sup>向任何人传道。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行传 5:40; 路加福音 24:46–48; 使徒行传 5:20"> 于是把彼得他们叫来，命令他们不得再以耶稣之名教导民众。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 5:29; Exodus 1:17; 哥林多前书 10:15"> 但彼得和约翰回答：“无论这在上帝眼中是对是错，听从你们还是听从上帝，你们决定吧。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 22:15; Jeremiah 20:9; 哥林多前书 9:16–17"> 我们无法对看到和听到的保持沉默！”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 5:26; 马太福音 21:46; 路加福音 22:2"> 由于民众在看到这个神迹后都开始颂赞上帝，公议会无法找到惩罚他们的方法，于是在恐吓一番后就把他们放了。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 5:5; 使徒行传 9:33; 路加福音 13:11"> 那位因神迹而被治愈的男人已经四十多岁了。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 6:14–17; 使徒行传 12:11–12; Psalms 119:63"> 使徒们被释放之后，来到其他信徒那里，讲述了祭司长和长老所说的一切。</span>
<span className="v" id="v24" data-v="24" data-xref="Exodus 20:11; Jeremiah 32:17; Nehemiah 9:6"> 众人听罢，一起向上帝祈祷：“主啊，你创造了天地、海洋和世间万物。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="Psalms 2:1–6; 使徒行传 1:16; 使徒行传 2:30"> 你凭借圣灵通过我们的祖先和你的仆人大卫之口说：‘万国民众为什么如此愤怒？他们为什么以空谋妄想针对我？</span>
<span className="v" id="v26" data-v="26" data-xref="Psalms 2:2; 启示录 17:12–14; Daniel 9:24"> 人间的君王准备开战<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="隐喻为“战争。”">c</a></sup>，首领们聚在一起反对主，反对他们的天选之人。’<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="意为“涂抹圣膏。”引自《诗篇》2:1-2。">d</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马太福音 27:2; 使徒行传 4:30; 路加福音 9:22"> 现在这一切就真实地发生在这座城市中！希律和本丢·彼拉多与异教徒和以色列民众，就在这城里聚集，反对你所膏立的圣仆耶稣。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 2:23; Isaiah 46:10; Genesis 50:20"> 他们做出了你早已决定之事，因为你有这样做的权利和意愿。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="使徒行传 4:13; 使徒行传 14:3; 腓立比书 1:14"> 主啊，看看他们对我们的恐吓！帮帮你的仆人吧，让他们能够有胆量传讲你的道。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 4:27; 使徒行传 3:6; 使徒行传 5:12"> 在你行使治愈力量之时，愿你能通过你的圣仆耶稣之名，实现神迹和奇迹。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马太福音 21:22; 使徒行传 2:2; 使徒行传 2:4"> 祷告完毕，他们聚会的建筑震动起来，圣灵充满所有人的身体，他们开始大胆传讲上帝之道。</span>
<span className="v" id="v32" data-v="32" data-xref="哥林多前书 1:10; 以弗所书 4:2–6; 彼得前书 3:8"> 所有信徒同心同思，任何人都不会认为某些财物属于自己，他们彼此分享一切。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 1:16; 使徒行传 1:22; 使徒行传 1:8"> 使徒凭借强大的力量传递主耶稣复活的讯息，他们也获得了上帝的慷慨祝福。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 2:45; 路加福音 12:33; 路加福音 16:9"> 没有哪个信徒感到匮乏，他们卖掉了所有的田地或财产，</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 5:2; 使徒行传 2:45; 哥林多后书 8:20–21"> 把收入放在使徒面前，照着各人的需要进行分配。</span>
<span className="v" id="v36" data-v="36" data-xref="加拉太书 2:9; 加拉太书 2:13; 加拉太书 2:1"> 有一个叫做约瑟的利未人，生在塞浦路斯，使徒称他为巴拿巴（意为鼓励之子）。</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 5:1–2; 使徒行传 4:34–35; 马太福音 19:29"> 他也卖掉了自己的田地，把钱拿来放在使徒面前。</span>
</div>
</div>

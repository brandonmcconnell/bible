<span className="v" id="v1" data-v="1" data-xref="Psalms 22:27; Malachi 1:11; Isaiah 32:15"> 其他门徒和住在犹太的兄弟们，也听说了异教徒接受上帝之道的事情。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 10:45; 使徒行传 10:9; 使徒行传 15:1"> 彼得返回耶路撒冷后，那些信守割礼<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“那些受割礼之人”，可能代表“犹太人。”但从上下文来看，这些应该是担心与“异教徒”关系的犹太基督徒。">a</a></sup>的人就此与他争论。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 10:28; 加拉太书 2:12; 路加福音 15:2"> 他们说：“你竟然进入未受割礼之人的房屋，跟他们一起吃饭！”</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 1:3; 使徒行传 14:27; Joshua 22:21–31"> 彼得就把所发生的一切讲给他们听：</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 10:9–32; 使徒行传 9:10; 使徒行传 22:17"> “我在约帕城祷告的时候，恍惚间见到异象，天上降下一个东西，好像一块绑着四角的大布，落在我的面前。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 4:20; 使徒行传 3:4"> 我看到布里面有动物、野兽、昆虫和飞鸟。</span>
<span className="v" id="v7" data-v="7"> 我听见一个声音对我说：‘彼得，起来吧，把它们宰杀后食用！’</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 14:14; Hosea 9:3; 哥林多前书 7:14"> 我说：‘主啊，万万不可！我从不吃不纯不洁的食物。’</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 15:9; 希伯来书 9:13–14; 使徒行传 10:34–35"> 那天上的声音回答：‘上帝已让它洁净，不可称其不洁！’</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 21:17; Numbers 24:10; 哥林多后书 12:8"> 这异象重复了三次，然后所有一切就被收回天上。</span>
<span className="v" id="v11" data-v="11" data-xref="Exodus 4:27; 使徒行传 9:10–12; Exodus 4:14"> 就在那时，该撒利亚派来找我的三个人，站在我住的房子门前。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 8:29; 罗马书 3:22; 帖撒罗尼迦后书 2:2"> 圣灵告诉我与他们同去，不要担心他们是谁。这六位兄弟也与我随行，我们到了哥尼流的家。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 10:30–32; 使徒行传 10:3–6; 使徒行传 9:43"> 他向我们解释如何看见天使站在他家里，对他说：‘派人到约帕去，请彼得前来，</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 16:15; 使徒行传 10:22; 使徒行传 16:31–34"> 他有话要告诉你，可以让你和全家获得救赎。’</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 19:6; 使徒行传 10:34–46; 使徒行传 2:2–12"> 当我开始讲话，圣灵便落在他们身上，与当初降在我们身上一样。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 1:5; 马可福音 1:8; Proverbs 1:23"> 于是我想起主所说的：‘约翰用水施洗，但你们要接受圣灵的施洗。’</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 10:47; 罗马书 9:20–26; Daniel 4:35"> 我们相信主耶稣基督，所以上帝就像对我们一样恩赐他们，我又有何力量阻止上帝？”</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 10:12–13; 哥林多后书 7:10; Ezekiel 36:26"> 众人听闻这番解释，无语辩驳，开始赞美上帝，说：“看来上帝也赐予异教徒悔改和永生的机会。”</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 4:36; 使徒行传 21:2; 使徒行传 15:3"> 司提芬被迫害而被处死后，受到影响的信徒逃亡到了腓尼基、塞浦路斯和安提阿，然后只向犹太人传道。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 27:32; 使徒行传 13:1; 哥林多前书 1:23–24"> 有些塞浦路斯人和古利奈人信徒逃到安提阿后，也开始对希腊人传讲主耶稣。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:66; 使徒行传 2:47; 使徒行传 5:14"> 主的力量与他们同在，所以信主和信他的人数量众多。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 9:27; 使徒行传 8:14; 使徒行传 13:1–3"> 这事传到耶路撒冷的教会，他们就派巴拿巴去安提阿。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 15:58; 使徒行传 14:22; 使徒行传 13:43"> 但当巴拿巴到了之后，看见上帝恩典的成果，倍感喜悦，于是鼓励众人用真心真意奉献主。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 11:21; 使徒行传 5:14; 使徒行传 9:31"> 巴拿巴是一位善良之人，充满圣灵和信心，于是许多人归信了主。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 9:11; 使徒行传 9:27; 使徒行传 9:30"> 后来他到大数去找扫罗，</span>
<span className="v" id="v26" data-v="26" data-xref="彼得前书 4:16; 使徒行传 26:28; 彼得前书 4:14"> 在找到后就把他带到安提阿。在随后的一年中，他们一同在教会聚集众人，对他们进行教导。从安提阿开始，信徒们开始被成为“基督徒。”</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 13:1; 哥林多前书 12:28; 以弗所书 4:11"> 就在这段时间，有几位先知从耶路撒冷来到安提阿。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 21:10; 使徒行传 18:2; 路加福音 3:1"> 其中一位叫做亚迦布的先知站起来，借助圣灵给出警示预言：整个世界将出现一次严重的大饥荒，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“有人居住的世界”，通常指罗马帝国。">b</a></sup>（这个预言在革老丢时期果然成真了。）</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多后书 8:12–14; 加拉太书 2:10; 哥林多后书 8:2–4"> 于是信徒们决定根据各人的力量捐款，帮助住在犹太的兄弟。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 14:23; 使徒行传 12:25; 使徒行传 15:4"> 他们在捐款后，让巴拿巴和扫罗把钱送到长老那里。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 27:26; 使徒行传 27:44; 使徒行传 27:39"> 我们终于安全上岸后，才知道这个岛叫做马尔他。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 1:14; 希伯来书 13:2; 歌罗西书 3:11"> 当地的人对我们很友好。由于下过一场雨，天气很冷，他们还生起火让我们取暖。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 23:33; 马太福音 12:34; 使徒行传 28:4"> 保罗捡了一捆木柴，扔进火里。但木材里藏着一条毒蛇，但是因为高温, 他爬出来咬了保罗的手。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 13:2; 路加福音 13:4; 约翰福音 7:24"> 当地人看见那条蛇悬在他手上，就对彼此说：“这人一定是个凶手，虽然从海里脱险，但正义也要取他的命！”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="路加福音 10:19; 马可福音 16:18; Psalms 91:13"> 但保罗却把那条蛇抖在火里，自己毫发无损。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 12:22; 使徒行传 14:11–13; 马太福音 21:9"> 当地人等着看他伤口肿胀或者倒地死去。但很久后他仍然平安无事，于是他们就改变了想法，认为他是一个神。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 10:40–41; 路加福音 19:6–9; 使徒行传 28:2"> 附近的土地为岛上首领部百流所有。他很欢迎我们的到来，好心地招待了我们三天。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 9:40; 马可福音 6:5; 雅各书 5:14–16"> 当时部百流的父亲患了重病，躺在床上高烧不起，同时伴有痢疾。保罗走进去看望他，为他祈祷按手，将他医好。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 5:12; 马可福音 6:54–56; 使徒行传 5:15"> 这之后，岛上其他病患都被送了过来，也被他治愈了。</span>
<span className="v" id="v10" data-v="10" data-xref="帖撒罗尼迦前书 2:6; 腓立比书 4:11–12; 马太福音 6:31–34"> 他们送给我们很多礼物。到了开船之时，又为我们准备了航程需要的所有补给。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 27:6; 哥林多前书 8:4; Isaiah 45:20"> 我们在岛上停留了三个月，然后上了一艘从亚历山太开来的船。它也在这个岛上过冬，船头装饰着宙斯双子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="以双胞胎卡斯特和普洛斯的名字命名。">a</a></sup>的雕像。</span>
<span className="v" id="v12" data-v="12"> 我们随船停在叙拉古，在那里逗留了三天。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 27:13"> 之后继续航行到利基翁，抵达之后的第二天刮起南风，所以我们用了一天的时间就到了达部丢利。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 21:4; 使徒行传 20:6; 使徒行传 19:1"> 在那里我们遇到一些信徒，邀请我们在那里住了七天。<br />最终，我们抵达了罗马。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 13:3; 罗马书 15:24; Exodus 4:14"> 罗马的信徒听说我们到来，于是赶来在亚比乌和三馆迎接我们。看到他们，保罗便感谢上帝，心中感觉更受鼓舞。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 27:3; 使徒行传 24:23; 使徒行传 28:30–31"> 抵达罗马后，保罗被允许与一名士兵一起被软禁起来看管他。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行传 25:8; 使徒行传 6:14; 使徒行传 25:10"> 三天后，保罗请犹太人首领前来见面。所有人都到了之后，保罗说：“兄弟们，我没有做过任何违背人民或者祖先习俗的错事，却像囚犯一样被逮捕，被他们从耶路撒冷送到罗马人的手里。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 26:31–32; 使徒行传 23:29; 使徒行传 22:24–25"> 他们在审讯我之后，由于没有找到判处死刑的罪过，就想释放我。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 26:32; 使徒行传 25:21; 使徒行传 25:10–12"> 但犹太人首领却反对这么做，所以我迫不得已才要求向凯撒上诉，并非我想要对抗我的同胞。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 6:20; 提摩太后书 2:9; 使徒行传 26:6–7"> 因此我请求与你们见面谈谈这件事情，因为我之所以像这样被捆绑起来，就是为了以色列的希望。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="Isaiah 54:17; Isaiah 41:11; Isaiah 50:8"> 众人对他说：“我们没有收到任何关于你的犹太来信，今天赶过来的这些人，也没有人想要指控你或说你的坏话。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 2:12; 使徒行传 24:14; 彼得前书 3:16"> 但我们想听听你相信什么，尤其是关于这教派的态度，要知道它在所有地方都受到了抵制。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 17:2–3; 使徒行传 19:8; 使徒行传 18:28"> 于是他们和保罗约了个见面的日子。在那天有很多人来到他的住所与他见面。他从早到晚不停地向众人讲解，告诉他们上帝之国的一切，通过引用摩西的律法和先知的预言，规劝他们信奉耶稣。</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 14:4; 使徒行传 17:4–5; 使徒行传 19:8–9"> 对于他所说的一切，有人信服，也有人不愿相信。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 15:7; 彼得后书 1:21; 马可福音 7:6"> 众人无法达成一致的意见，于是就纷纷离开了。在他们走之前，保罗这样说：“圣灵通过赛亚先知告诉你们祖先的话一点不错：</span>
<span className="v" id="v26" data-v="26" data-xref="Isaiah 6:9–10; Ezekiel 12:2; Isaiah 42:19–20"> ‘去民众那里告诉他们，尽管你们听到了，却从未理解，纵使看见了，却从未领悟。</span>
<span className="v" id="v27" data-v="27" data-xref="Isaiah 6:10"> 因为这些人的心灵顽固不化，有耳朵却无法听到，双眼紧闭，不想用双眼看见，用耳朵听到，用心理解。如果他们回到我身边，我会治愈他们。’<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引述《以赛亚书》6:9-10。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 2:30–32; 使徒行传 26:17–18; 罗马书 3:29–30"> 所以你们应当知道，来自上帝的救赎已经赐予异教徒，他们将会仔细聆听。”</span>
<span className="v" id="v29" data-v="29"> <sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="有的经文中没有这一段，有些评论家认为，这可能是后来加入的内容。">c</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 保罗在自己租的房子里住了整整两年，接待所有上门拜访之人。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 4:29; 以弗所书 6:19–20; 马太福音 4:23"> 他放胆传讲神的国，教导有关主耶稣基督的事。 没有人阻止他。</span>
</div>
</div>

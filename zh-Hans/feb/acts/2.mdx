<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 15:6; 腓立比书 2:2; 使徒行传 1:13–15"> 五旬节那天，使徒们聚集在一起。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 4:31; 1 Kings 19:11; Psalms 18:10"> 忽然天上发出响动，仿佛强风填满了他们所在的整个房屋。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 3:11; 约翰福音 1:32–33; Jeremiah 23:29"> 他们又看到看似舌头一般的火焰，落在每个人的身上。</span>
<span className="v" id="v4" data-v="4" data-xref="马可福音 16:17; 使徒行传 13:52; 使徒行传 4:31"> 圣灵充满每个人的身体，他们开始通晓不同国家的语言，这也是圣灵赋予他们的能力。</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 2:25; 使徒行传 8:2; 歌罗西书 1:23"> 当时，耶路撒冷住着很多来自不同国家的虔诚犹太人。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 2:3; 哥林多前书 16:9; 使徒行传 2:2"> 听到响动，众人便聚了过来。听见使徒能够讲述他们各自的母语，他们倍感困惑。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 2:12; 使徒行传 1:11; 约翰福音 7:52"> 他们万分惊讶地说：“看这些说话的人，他们都是加利利人，是不是？</span>
<span className="v" id="v8" data-v="8"> 但我们怎么听见他们在讲我们的母语呢？</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 1:1; 使徒行传 18:2; 启示录 1:4"> 我们来自帕提亚、玛代人、以拦、美索不达米亚、犹太、加帕多家、本都、亚西亚、</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 16:6; Zechariah 8:23; Zechariah 8:20"> 弗吕家、旁非利亚、埃及以及靠近古利奈的利比亚的各地，还有来自罗马的犹太人和归信犹太教之人，</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 12:10; Exodus 15:11; Psalms 78:4"> 以及克里特人和阿拉伯之人——但现在，我们听到他们用我们本地的语言，讲述上帝的伟大事迹。”</span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 15:26; 使徒行传 17:20; 路加福音 18:36"> 众人感到惊讶困扰，彼此询问：“这意味着什么？”</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 14:23; 使徒行传 2:15; 1 Samuel 1:14"> 但也有人讥嘲笑道：“他们就是酒喝太多，醉了。”</span>
<span className="v" id="v14" data-v="14" data-xref="Isaiah 51:7; Isaiah 51:1; Deuteronomy 27:9"> 彼得和另外 11 名使徒站起来，他高声对众人说：“犹太人和所有住在耶路撒冷的朋友啊，仔细听好了，我要向你们解释这一切。</span>
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 5:5–8; 1 Samuel 1:15; 马太福音 20:3"> 这些人并非如你们所想喝醉了，现在只是上午九点钟而已。</span>
<span className="v" id="v16" data-v="16" data-xref="Joel 2:28–32"> 所发生的一切正如约珥先知所言：</span>
<span className="v" id="v17" data-v="17" data-xref="Joel 2:28–32; Isaiah 44:3; 提多书 3:4–6"> 上帝说：‘在末日到来的日子，我要将我的圣灵施与所有人，你们的儿女将会说出预言，你们的青年人将看到异象，你们的老年人将会梦到梦境。</span>
<span className="v" id="v18" data-v="18" data-xref="加拉太书 3:28; 歌罗西书 3:11; 哥林多前书 7:21–22"> 我将把我的圣灵施于我的仆人，无论男女，他们都将说出预言。</span>
<span className="v" id="v19" data-v="19" data-xref="Joel 2:30–31; Zephaniah 1:14–18; Malachi 4:1–6"> 我要在天堂和大地向你们显现神迹，有血、有火、有旋转的烟雾！</span>
<span className="v" id="v20" data-v="20" data-xref="彼得后书 3:10; Amos 8:9; 马太福音 24:29"> 在主的伟大荣耀之日降临之前，太阳将变得黑暗，月亮将变为血红。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 10:12–13; Joel 2:32; Psalms 86:5"> 但只要呼唤主的名字，必会得救。’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《约珥书》2:28-32。">a</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 3:2; 约翰福音 14:10–11; 马太福音 12:28"> 以色列人，听好了：正如你们所知，上帝通过拿撒勒人耶稣在你们之中显现惊人的奇迹和神迹，证明他就是上帝所确定之人。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 22:22; 使徒行传 4:28; 使徒行传 3:18"> 上帝早已预知将会发生什么，他按照自己的计划，决定将耶稣交给你们。但你们却借由恶人之手，把他钉上了十字架。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 6:14; 彼得前书 1:21; 使徒行传 2:32"> 但上帝让他起死回生，无需遭受死亡的痛苦，因为死亡没有困住他的力量。</span>
<span className="v" id="v25" data-v="25" data-xref="Psalms 16:8–11; Isaiah 41:13; Psalms 62:6"> 大卫这样说耶稣：‘我总是会看见主在我面前。因为他就在我身边，我必不会动摇。</span>
<span className="v" id="v26" data-v="26" data-xref="Psalms 16:9; Psalms 63:5; Psalms 71:23"> 所以我才会如此快乐，所以我的言语中充满喜悦，所以我的身体充满希望。</span>
<span className="v" id="v27" data-v="27" data-xref="Psalms 16:10; 使徒行传 2:31; 启示录 1:18"> 因你不会弃我于坟墓，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="意为“冥王”，死者所去之地。又见第 31 句。">b</a></sup>也不会让圣者腐朽。</span>
<span className="v" id="v28" data-v="28" data-xref="Psalms 16:11; Psalms 25:4; Psalms 21:6"> 你向我指引了生命之路，让我因你在身旁而充满欢喜。’<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="引自《诗篇》16:8-11。">c</a></sup></span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 13:36; 1 Kings 2:10; 使徒行传 7:8–9"> 兄弟姐妹们，让我坦白地告诉你们，我们的祖先大卫已经死去并被埋葬，至今他的坟墓仍在人间。</span>
<span className="v" id="v30" data-v="30" data-xref="Psalms 132:11–18; Psalms 89:3–4; Jeremiah 33:14–15"> 但他是先知，知晓上帝向他做出的誓言，要从他的后裔中选择一人接替他的王位。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 2:27; Psalms 16:10; 使徒行传 13:35"> 大卫已看见了即将发生的事，曾这样讲述基督的复活：‘基督不会被弃于坟墓，他的肉身也不腐朽。’</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 3:15; 使徒行传 1:8; 使徒行传 1:22"> 上帝让这位耶稣复活，我们都是这件事的见证人。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 1:4; 使徒行传 5:31; 使徒行传 2:17"> 现在他已被高举到上帝的右边，获得天父承诺给予他的圣灵，在被施与圣灵后，你们所见所闻就会倾吐而出。</span>
<span className="v" id="v34" data-v="34" data-xref="Psalms 110:1; 马太福音 22:42–45; 希伯来书 1:13"> 大卫并没有升入天堂，但他却说：‘主对我主说：坐在我右边，</span>
<span className="v" id="v35" data-v="35" data-xref="启示录 19:19–3; 罗马书 16:20; Isaiah 60:14"> 让我把你的仇敌成为你的脚凳。’<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《诗篇》110:1。胜利的象征。">d</a></sup></span>
<span className="v" id="v36" data-v="36" data-xref="使徒行传 5:30–31; 罗马书 14:8–12; 哥林多后书 5:10"> 现在要让以色列所有人都确信：被你们钉上十字架上的这位耶稣，上帝已经让他成为主和基督！”<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="弥赛亚（希伯来文）即基督（希腊文）。">e</a></sup></span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 3:10; 使徒行传 22:10; 希伯来书 4:12–13"> 众人听到这一切，心中倍感痛苦。<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="原意为“切入心脏。”">f</a></sup>他们询问彼得和其他使徒说：“兄弟们，我们应该怎么办？”</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 22:16; 马可福音 16:16; 使徒行传 8:12"> 彼得说：“悔改！所有人都要以耶稣基督之名受洗，以便你们的罪获得救赎，这样就能获得圣灵馈赠。</span>
<span className="v" id="v39" data-v="39" data-xref="Isaiah 44:3; Genesis 17:7–8; 罗马书 8:30"> 这承诺给予你们、你们的儿女、以及所有远方之人，我们主上帝召来的所有人。”</span>
<span className="v" id="v40" data-v="40" data-xref="腓立比书 2:15; Deuteronomy 32:5; 马太福音 17:17"> 彼得继续讲述，给出更多证明。他警告众人，说：“从这个扭曲的世界拯救自己吧！”</span>
<span className="v" id="v41" data-v="41" data-xref="使徒行传 4:4; 使徒行传 2:47; 使徒行传 16:31–34"> 那些接受他这番话的人都受了洗，这一天内的门徒数量就增加了约三千人。</span>
<span className="v" id="v42" data-v="42" data-xref="希伯来书 10:25; 使徒行传 1:14; 约翰一书 1:3"> 他们立下承诺要遵守门徒的教诲，对其他信徒也立下承诺，共同“分享饼”<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="这可能代表圣餐，不仅是普通的饭菜，但也包括在内。">g</a></sup>和共同祈祷。</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 7:16; 约翰福音 14:12; 路加福音 8:37"> 众人敬畏地看到使徒们做出的奇迹和神迹。</span>
<span className="v" id="v44" data-v="44" data-xref="使徒行传 4:32; 约翰一书 3:16–18; 哥林多后书 8:14–15"> 所有信徒都聚在一起，分享自己的所有。</span>
<span className="v" id="v45" data-v="45" data-xref="约翰一书 3:17; 提摩太前书 6:18–19; 雅各书 2:14–16"> 他们变卖房屋和财物，按照个人所需分享变卖所得。</span>
<span className="v" id="v46" data-v="46" data-xref="使徒行传 5:42; 使徒行传 20:7; 使徒行传 2:42"> 他们日夜持续地在圣殿中聚会，在家中共同进餐，以谦卑幸福的心情享用食物。他们赞美上帝，所有人都赞赏他们。</span>
<span className="v" id="v47" data-v="47" data-xref="使徒行传 16:5; 使徒行传 5:13–14; 使徒行传 2:41"> 他们的数量不断增加，因为主将所拯救之人带到这里。</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 18:23–28; 哥林多前书 16:12; 哥林多前书 1:12"> 亚波罗在哥林多期间，保罗从内陆抵达以弗所，在那里找到了若干信徒。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 7:39; 使徒行传 11:15–17; 加拉太书 3:5"> 他问他们说：“当你们信了上帝的时候，是否领取了圣灵？”他们说：“没有，我们甚至都没听说过圣灵这件事情。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="使徒行传 18:25; 哥林多前书 12:13; 使徒行传 8:16"> 保罗问：“那么你们接受的是何种施洗？”<br />他们说：“是约翰的施洗。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰福音 1:29–34; 使徒行传 11:16; 使徒行传 1:5"> 保罗说：“约翰提供的是悔改施洗，他告诉众人应该相信在他之后到来的那个人，也就是他们应该相信耶稣。”</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 8:12; 使徒行传 8:16; 罗马书 6:3–4"> 众人听罢，便以主耶稣之名进行受洗。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 6:6; 使徒行传 2:4; 马可福音 16:17"> 保罗为他们按手，圣灵就便降临在他们身上，他们开始用不同的语言说话，还可以进行预言。</span>
<span className="v" id="v7" data-v="7"> 这些人总计大约十二人。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 28:23; 使徒行传 1:3; 使徒行传 9:20–22"> 在三个月的时间内，保罗一直都在会堂里向那里的人大胆宣讲，与他们进行讨论，努力说服他们相信上帝之国。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 19:23; 使徒行传 9:2; 使徒行传 18:6–8"> 但有些人始终顽固不化，拒绝接受他的宣讲，还在众人面前毁谤道<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“道”：早期代表基督教的词语。">a</a></sup>。所以保罗放弃了他们，离开了会堂，将信徒们也一并带走。之后，他每天都在推喇奴讲堂与大家进行讨论。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 20:31; 提摩太后书 1:15; 使徒行传 16:6"> 就这样过了两年，所有亚西亚省的居民，无论犹太人或希腊人，都听到了主的道。</span>
<span className="v" id="v11" data-v="11" data-xref="马可福音 16:17–20; 使徒行传 5:12; 罗马书 15:18–19"> 上帝通过保罗显现很多不同寻常的神迹。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 5:15; 2 Kings 13:20–21; 马可福音 16:17"> 甚至有人会拿走保罗曾经触碰的手帕或围巾，去医治病患和赶走邪灵。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马太福音 12:27; 马可福音 9:38; 路加福音 11:19"> 几个犹太人打着耶稣的名号四处驱鬼，向身上附着之人说：“我以保罗所言耶稣之名，命令你们出来。”</span>
<span className="v" id="v14" data-v="14"> 一位名叫士基瓦的犹太人司长，他的七个儿子都在做这件事，一个是犹太人，一个是大祭司。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行传 16:17–18; 路加福音 4:33–35; 马可福音 1:34"> 但有一天当他们驱魔时，邪灵却回答到：“我认识耶稣，也认识保罗，但你们是谁？”</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 8:29; 马可福音 5:3–4; 马可福音 5:15"> 邪灵附体那人扑到他们身上将其制服，一番痛殴后，他们赤裸着身体从那房子逃了出来，满身是伤。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦后书 1:12; 使徒行传 5:5; 腓立比书 2:9–11"> 所有住在以弗所的犹太人和希腊人都知道此事，纷纷表示敬畏，主耶稣之名获得了广泛尊重。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 10:10; Psalms 32:5; 马太福音 3:6"> 也有许多信主之人前来忏悔他们的罪，公开坦诚他们曾经做过的恶行。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 13:8; Exodus 32:20; Genesis 35:4"> 其中有许多曾经施行巫术之人，把他们关于巫术的书堆在一起当众烧掉。他们估算了一下书价，总计五万银币。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 12:24; 使徒行传 6:7; Isaiah 55:11"> 通过这种方式，主的道日益强大，广为传播。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 20:22; 使徒行传 20:16; 使徒行传 23:11"> 在这之后，保罗决定穿过马其顿和亚该亚去往耶路撒冷。他说：“我到了那边以后，必须去罗马看看。”</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 16:23; 提摩太后书 4:20; 使徒行传 16:3"> 他派了两名帮手提摩太和以拉都两人去马其顿，自己则暂时留在亚西亚省。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 19:9; 使徒行传 24:22; 哥林多后书 1:8–10"> 就在这期间，发生了很多关于道的骚乱，</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太前书 6:9–10; 使徒行传 16:16; 使徒行传 16:19"> 有一位名叫低米丢的银匠，以制造亚底米女神的小银龛为生，这门手艺给他这样的工匠带来了不少生意。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 16:19; Hosea 12:7–8; 启示录 18:11–19"> 他把同行和相似行业的工人们聚起来，说：“工友们，你们知道，我们就是靠这门生意赚钱。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 17:29; 哥林多前书 8:4; Isaiah 44:10–20"> 毫无疑问，通过你们看见和听见的事情，你们也应该意识到这个叫保罗的人，不仅在以弗所、还几乎在整个亚西亚游说和误导众人，说人类所制造的都不是上帝的创造。</span>
<span className="v" id="v27" data-v="27" data-xref="Zephaniah 2:11; 提摩太前书 6:5; 马太福音 23:13"> 这不仅导致我们这一行可能会受人鄙视，就连伟大女神亚底米的庙也会遭人摒弃，亚西亚和普天下所敬拜的女神将失去其威严。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="启示录 13:4; 启示录 17:13; 使徒行传 16:19–24"> 这话掀起了众人的怒火，他们高喊到：“以弗所人的亚底米，伟大的神！”</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 20:4; 歌罗西书 4:10; 使徒行传 27:2"> 全城陷入大骚动，他们捉住了与保罗同行的马其顿人该犹和亚里达古，一起冲进了剧场。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 21:39; 2 Samuel 18:2–3; 使徒行传 17:22–31"> 保罗想去直面暴徒，但其他信徒不让他这么做。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 19:10; 使徒行传 21:12; 使徒行传 16:6"> 保罗有几名省长官<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“宗主。”">b</a></sup>的朋友，也捎来口信，叮嘱他不要去剧场那里。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行传 21:34; 使徒行传 19:40; 马太福音 11:7–9"> 但暴徒们并不知道聚集的原因，如一群无头苍蝇一般，口中胡乱喊叫着。</span>
<span className="v" id="v33" data-v="33" data-xref="使徒行传 12:17; 提摩太后书 4:14; 提摩太前书 1:20"> 人群中的犹太人把亚历山大推到前面，他做了个让大家安静的手势，想要解释给众人听。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 19:28; 马太福音 6:7; 启示录 13:4"> 众人认出他是犹太人，便异口同声高喊：“以弗所人的亚底米，伟大的神！”足足喊了两个小时。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="帖撒罗尼迦后书 2:10–11; 提摩太前书 4:2; 以弗所书 2:12"> 后来书记官设法安抚了民众。他说：“以弗所人呐！你们的城是看守伟大亚底米的圣殿，也看守来自天堂的神像。这一点谁不知道呢？</span>
<span className="v" id="v36" data-v="36" data-xref="Proverbs 14:29; 使徒行传 5:35–39; Proverbs 25:8"> 这些都是不可辩驳的事实，你们应当保持平静，不可冲动行事。</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多后书 6:3; 罗马书 2:22; 使徒行传 25:8"> 你们抓到这里的两个人，既没有打劫庙宇，也没有亵渎我们的女神。</span>
<span className="v" id="v38" data-v="38" data-xref="使徒行传 13:7; 哥林多前书 6:1; 使徒行传 18:14"> 如果低米丢和其他工匠想要控告谁，完全可以去找总督<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“总领事。”">c</a></sup>或提交法庭，可以在那里提交诉状。</span>
<span className="v" id="v39" data-v="39"> 如果还有其他问题，就应该进行合法的集会予以解决。</span>
<span className="v" id="v40" data-v="40" data-xref="使徒行传 17:5–8; 马太福音 26:5; 使徒行传 20:1"> 今天的骚乱毫无来由，我们实在无法评判，事实上，我们甚至可能需要为这件事情负责。”</span>
<span className="v" id="v41" data-v="41" data-xref="Ecclesiastes 9:17; Psalms 65:7; 哥林多后书 1:8–10"> 说罢这番话，他就让暴徒们散去了。</span>
</div>
</div>

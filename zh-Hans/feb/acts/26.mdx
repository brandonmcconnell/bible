<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="feb" data-translation-id="cmn_feb" data-translation-label="易读圣经" data-book="ACT" data-book-slug="acts" data-book-name="使徒行传" data-chapter="26" data-verses="32">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 9:15; Proverbs 1:24; 使徒行传 26:2"> 亚基帕对保罗说：“准许你为自己辩护。”于是保罗用手臂示意开始了自己的辩护：</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2"> “亚基帕王，很荣幸今天能就犹太人控告我一事，在你面前进行自我辩护。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 6:14; 使徒行传 26:26; 使徒行传 26:7"> 尤其是你熟悉犹太人的所有规则和习俗，所以恳请你耐心听取我说的话。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="加拉太书 1:13; 提摩太后书 3:10; 腓立比书 3:5"> 从我在祖国幼年时期的经历再到耶路撒冷的一切，所有犹太人都知道我的人生道路。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 23:6; 使徒行传 22:3; 使徒行传 24:5"> 他们一直以来都很了解我，如果他们肯作证，你就会知道，我一直严格遵循最严格的教派，忠于我的信仰。我按照法利赛人的方式生活。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="提多书 2:13; 使徒行传 24:15; 使徒行传 28:20"> 现在我之所以站在这里受审，就是因为上帝向祖先们承诺的希望。</span>
<span className="v" id="v7" data-v="7" data-xref="雅各书 1:1; 腓立比书 3:11; 提摩太前书 5:5"> 我们的十二族群始终虔诚地服侍上帝，都是盼望这希望可以实现。是的，国王陛下，犹太人控告我也是因为这希望。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 15:12–20; 使徒行传 4:2; 使徒行传 17:31–32"> 为什么你们认为，上帝让死人复活是不可思议的事情呢？</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="提摩太前书 1:13; 使徒行传 22:8; 腓立比书 3:6"> 我以前也真的相信，自己应该想方设法反对拿撒勒人耶稣之名。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 8:3; 使徒行传 9:13–14; 使徒行传 9:21"> 我在耶路撒冷就是这么做的。我在祭司长的授权下，把很多信徒扔进监牢，在他们被杀的时候，我也完全同意。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 22:19; 马太福音 10:17; 使徒行传 13:45"> 我让他们在所有的犹太教堂受到惩罚，试图让他们放弃。 我非常反对他们，我到国外的城市去迫害他们。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 26:10; 使徒行传 22:5–11; 使徒行传 9:1–8"> 但有一天，我得到祭司长的授权和指令去往大马士革。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 17:2; 启示录 21:23; 启示录 1:16"> 国王陛下，就在那天中午，我在路上看见来自天上的一道光，比太阳更明亮，照耀着我和其他同伴。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 21:40; 使徒行传 22:2; 使徒行传 9:7"> 我们都伏倒在地，然后我听见有声音用希伯来语对我说：‘扫罗啊，扫罗！你为什么迫害我？你是很难对抗我的！’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“踢山羊”，一种驱赶牲畜的的刺鞭。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 15:20–21; 马太福音 25:45; Exodus 16:8"> 我问到：‘主啊，你是谁？’<br />主说：‘我就是你所迫害的耶稣。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 22:14–15; Ezekiel 2:1; Daniel 10:11"> 但现在起来吧。我之所以要向你显现，是为了指认你为我的仆人，为我见证，告诉其他人你如何看到我，以及我向你显现的一切。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 9:15; 提摩太前书 2:7; Jeremiah 1:19"> 我要把你从同胞和异教徒那里拯救出来，现在我就派你到他们那里去，</span>
<span className="v" id="v18" data-v="18" data-xref="彼得前书 2:9; 以弗所书 1:18; 以弗所书 5:8"> 开启他们的双眼，让他们从黑暗转向光明，从撒旦的控制转向上帝，这样他们的罪恶才会得到赦免，那些因信我而正确行事之人，才会被包含其中。’</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="Isaiah 50:5; 加拉太书 1:16; Ezekiel 2:7–8"> 亚基帕王啊，很显然，我没有违背这来自天堂的异象。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 3:8; 使徒行传 3:19; 使徒行传 2:38"> 我先在大马士革、耶路撒冷、犹太全地向众人宣讲这忏悔之道，然后又向异教徒宣讲：关于如何转信上帝，通过行动彰显他们的悔改。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 21:30–31; 使徒行传 21:27; 使徒行传 25:3"> 犹太人就是因此在圣殿中捉拿我，想要杀我。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 24:14; 约翰福音 5:46; 罗马书 3:21"> 但我获得了上帝的眷顾，所以今天还能站在众人面前，包括普通百姓和尊贵之人。我所言只是重复了摩西和先知所讲必然发生之事，</span>
<span className="v" id="v23" data-v="23" data-xref="Isaiah 53:1–12; 路加福音 24:26; 歌罗西书 1:18"> 那就是基督必须受难，然后率先死而复生，向犹太人和异教徒宣告上帝的拯救之光。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="隐喻之意。最初版本仅提到了“光。”">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 2:13–14; 哥林多前书 1:23; 哥林多前书 4:10"> 保罗的自我辩护说到这里，非斯都大声说：“保罗！你疯了！你的学问让你疯了！”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行传 23:26; 提多书 1:9; 提多书 2:7–8"> 保罗回答：“非斯都大人，我没有疯，我说的都是真实，都是言之有理。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 26:2–3; 使徒行传 2:1–12; Isaiah 30:20"> 国王意识到了这一点，我只是很坦白地解释而已。我相信他知道到底发生了什么，因为这种事情无法躲躲藏藏。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="使徒行传 26:22–23"> 亚基帕王啊，你相信先知所言吗？我知道你信！”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="使徒行传 11:26; 马太福音 10:18; 使徒行传 26:29"> 亚基帕问保罗说：“你认为自己能这么快就说服我变成基督徒吗？”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以弗所书 6:20; 歌罗西书 1:28; 罗马书 10:1"> 保罗回答：“无论时间长短，都没有关系。我不止为你向上帝祈祷，更包括今天希望像我一样的所有听众，只是不应该有这锁链。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行传 18:15; 使徒行传 28:22; 使徒行传 25:23"> 亚基帕王、总督、百尼基以及在座的所有人都站起来，然后离开了法庭，</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 23:29; 使徒行传 23:9; 使徒行传 28:18"> 召开了一次会议。他们的结论是：“这个人并没有犯下任何应处死或监禁的罪行。”</span>
<span className="v" id="v32" data-v="32" data-xref="使徒行传 28:18; 使徒行传 25:11–12; 使徒行传 25:25"> 亚基帕对非斯都说：“如果他没有请求向凯撒上诉，就可以释放了。”</span>
</div>
</div>

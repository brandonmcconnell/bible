<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 1:2; 提摩太后书 4:20; 哥林多后书 1:1"> 随后保罗离开雅典，来到哥林多，</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 16:3–4; 哥林多前书 16:19; 提摩太后书 4:19"> 在这里遇到一位老家在本都的犹太人亚居拉。由于革老丢<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="罗马皇帝。">a</a></sup>命令所有犹太人离开罗马，所以他最近和妻子百基拉从意大利来到这里，于是保罗去见他们。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 4:12; 帖撒罗尼迦前书 2:9; 哥林多后书 11:9"> 由于他们和保罗一样都是以做帐棚为生，于是保罗在他们家住了下来。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 5:11; 使徒行传 17:17; 使徒行传 28:23"> 每逢安息日，保罗都会到会堂进行辩论，劝导犹太人和希腊人。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 5:14; 使徒行传 18:28; 使徒行传 20:21"> 西拉和提摩太从马其顿赶到这里与保罗会和，保罗就可以专心传扬主的道，向犹太人证明耶稣就是基督。</span>
<span className="v" id="v6" data-v="6" data-xref="Ezekiel 33:4; 2 Samuel 1:16; Ezekiel 33:8–9"> 当犹太人反对他、诅咒他时，他就会抖动衣服<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="表示无罪的象征性行为。">b</a></sup>，对他们说：“你们的罪由你们自己承担，与我无关。从现在起，我要到异教徒那里去了。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="使徒行传 16:14; 歌罗西书 4:11; 使徒行传 10:2"> 于是他离开那里，住到了敬拜上帝的提多·犹士都的家中，就在会堂的隔壁。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 1:13–17; 罗马书 10:14–17; 马可福音 16:15–16"> 会堂主管基利司布和全家人信了主，很多哥林多人也在听了道之后信了主，接受了施洗。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 23:11; 以弗所书 6:19–20; 使徒行传 27:23–25"> 夜里，主通过异象对保罗说：“不要怕，大胆宣讲，不要保持沉默！</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 12:9; Exodus 4:12; Isaiah 41:10"> 因为我与你同在，没有人会攻击你，因为在这座城里有许多人都追随我。”</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 14:3; 使徒行传 19:10; 使徒行传 20:31"> 保罗在那里住了一年零六个月，想向众人传授上帝之道。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="使徒行传 13:50; 使徒行传 18:27; 使徒行传 13:7"> 但在迦流<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="迦流是罗马斯多葛哲学家塞内卡的兄弟。">c</a></sup>担任亚该亚省长期间，犹太人一致起来攻击保罗，将他带到了法院，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原意为“审判座椅”或“审判长椅。”又见18:16-17。">d</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 25:8; 使徒行传 24:5–6; 使徒行传 6:13"> 说：“此人劝大家以违反律法的方式敬拜上帝。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="彼得前书 3:14–15; 使徒行传 25:11; 马可福音 9:19"> 保罗刚要开口为自己辩护，迦流就对犹太人说：“如果你们犹太人想要指控犯法或严重违法行为，我一定会听你们的讲述。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 23:29; 使徒行传 25:19; 提摩太前书 6:4"> 但你们争论的只是文字、名字和你们的律法，那你们应当自己处理。我不会审判此类案子。”</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 12:16; Psalms 76:10; 罗马书 13:3–4"> 说罢，迦流就把他们从法院赶了出去。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 1:1; Amos 6:6; 使徒行传 17:32"> 随后众人转向攻击会堂主管苏提尼，在法院门外殴打他，但迦流对此完全不予理会。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行传 21:24; Numbers 6:18; Numbers 6:5–9"> 保罗在这里住了一段时间后，便辞别了信徒，乘船去叙利亚，百基拉和亚居拉与他同行。因为他之前许下承诺，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="誓言：可能是拿撒勒人的誓言（见《民数记》6）。">e</a></sup>他就在坚革里剃光了头发。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以弗所书 1:1; 提摩太前书 1:3; 提摩太后书 1:18"> 一行人抵达以弗所后，保罗离开众人自己去了会堂，在那里跟犹太人辩论。</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 1:37–38; 哥林多前书 16:12; 使徒行传 20:16"> 众人请他多住一段时间，但被他拒绝了。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 4:19; 雅各书 4:15; 罗马书 15:32"> 他辞别众人，在以弗所乘船离开。临行前他告诉众人：“如果上帝允许，我还会回来。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 8:40; 使徒行传 15:4; 使徒行传 23:23"> 他在该撒利亚下船，与教会成员见了一面，<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="可能是耶路撒冷的教会成员。">f</a></sup>然后启程去往安提阿。</span>
<span className="v" id="v23" data-v="23" data-xref="使徒行传 14:22; 使徒行传 16:6; 使徒行传 15:41"> 他在那里住了一段时间后，继续走遍加拉太地区和弗吕加的各个城镇，为众信徒带去鼓舞激励。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哥林多前书 4:6; 提多书 3:13; 哥林多前书 3:5–6"> 与此同时，一位名叫亚波罗的犹太人来到以弗所。他老家在亚历山太，颇有口才，非常了解圣经。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 19:3; 罗马书 12:11; Hosea 14:9"> 他曾接受主之道的教诲，内心充满热情，无论讲话还是授道，都能准确讲述耶稣，但他只知晓约翰施洗之事。</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 18:25; 使徒行传 14:3; 哥林多前书 12:21"> 他开始在会堂里公开讲道。百基拉和亚居拉听说了他，就邀请他加入，更全面地解读上帝之道。</span>
<span className="v" id="v27" data-v="27" data-xref="帖撒罗尼迦后书 2:13–14; 雅各书 1:16–18; 彼得前书 1:2–3"> 后来他决定去亚该亚，信徒们就鼓励他，还给那里的使徒写信，请他们接待他。抵达亚该亚后，在当地人蒙受恩典相信上帝的过程中，他起了很大的作用，</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 18:5; 哥林多前书 15:3–4; 使徒行传 9:22"> 因为他能在公开辩论种有力驳斥犹太人，通过圣经证明耶稣既是基督。</span>
</div>
</div>

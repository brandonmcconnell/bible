<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 18:4; 使徒行传 13:51; 使徒行传 13:46"> 在以哥念发生了相同的事情。保罗和巴拿巴来到犹太人的会堂讲道。他们的言语如此令人信服，很多犹太人和说希腊语的朝拜者都相信了耶稣。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 13:50; 使徒行传 21:27–30; 使徒行传 14:19"> 但那些拒绝相信耶稣的犹太人，却去煽动异教徒的情绪，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="换言之，即非犹太人民众。">a</a></sup>毒害他们的心，让他们反对信徒。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 2:4; 以弗所书 6:18–20; 使徒行传 20:32"> 但保罗和巴拿巴在那里停留了很久，以主为名勇敢传道，主也通过他们实现了神迹奇事，以此证实他的恩典之道。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 28:24; 使徒行传 14:14; 路加福音 11:21–23"> 于是城里民众分成了两派，一派服从犹太人，一派支持使徒。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 14:19; 提摩太后书 3:11; 使徒行传 17:5"> 但随后异教徒、犹太人以及他们的首领，决定攻击保罗和巴拿巴，用石头打他们。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 14:20–21; 马太福音 10:23; 提摩太后书 3:11"> 但两人发现了这个阴谋，于是逃到吕高尼地区，来到路司得和特庇这两座城，</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 14:21; 使徒行传 16:10; 帖撒罗尼迦前书 2:2"> 在那里传递福音。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 3:2; 约翰福音 9:1–2; 约翰福音 5:3–5"> 路司得城有一个残疾人，双脚都动不了。他生下来就瘸腿，从未走过路。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 3:4; 马太福音 15:28; 马太福音 9:28–29"> 他坐在那里听保罗讲道。当保罗看向他，发现相信上帝可以将他治愈，</span>
<span className="v" id="v10" data-v="10" data-xref="Isaiah 35:6; 约翰福音 5:8–9; 约翰福音 14:12"> 于是保罗大声说：“用你的双脚站起来吧！”那人就跳起来，开始行走。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 28:6; 使徒行传 8:10; 使徒行传 12:22"> 目睹保罗所为，众人用吕高尼语大声说：“上帝以人的样子降临到我们中间！”</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 19:35"> 于是他们称巴拿巴为希腊神宙斯，称保罗为赫米，因为大部分时候都是保罗在讲话。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="Daniel 2:46; 使徒行传 10:25"> 城门外一座宙斯庙的祭司，牵来几头公牛、手拿花环<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="花环—在杀死动物前放在动物的身体上。">b</a></sup>来到城门处，打算在众人面前进行献祭。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 26:65; 哥林多前书 9:5–6; 2 Kings 5:7"> 但巴拿巴和保罗两个使徒听说这个消息，便撕开衣服<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="在古老的文化中，这是苦难的迹象。">c</a></sup>，跳进民众中大喊：</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 10:26; 哥林多前书 8:4; 雅各书 5:17"> “各位，怎么能这么做呢？我们也是人，天性与你们一样，我们来此向你们传递福音，就是为了让你们远离这些毫无意义的事，归从永生的上帝，就是那位创造天地大海和世间万物的上帝。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 17:30; Psalms 81:12; 罗马书 1:28"> 在过往的世界里，他允许各国各行其道，</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 1:19–20; Joel 2:23; Job 5:10"> 尽管如此，他仍然通过行善事留下证明，向你们送来天堂之雨和四季的作物，为你们提供所需的食物，为你们心中带来快乐。”</span>
<span className="v" id="v18" data-v="18" data-xref="Jeremiah 44:16–17; Genesis 19:9; Genesis 11:6"> 这番话勉强说服了众人，不再向他们献祭。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="哥林多后书 11:25; 提摩太后书 3:11; 使徒行传 13:50–51"> 但有些来自安提阿和以哥念的犹太人，成功挑唆民众用石头打保罗，然后以为他死了，就把他拖到城外。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 1:9–10; 哥林多后书 6:9; 使徒行传 14:6"> 但就在信徒们围着他时，他竟然站起来，走回了城里。第二天，他跟巴拿巴一同到特庇去。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 14:19; 使徒行传 14:1; 使徒行传 13:51"> 他们在那里向众人传递福音，让许多人都成为信徒，然后他们又回到路司得、以哥念和安提阿。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 5:10; 提摩太后书 3:12; 约翰福音 16:33"> 他们鼓励信徒坚定信念，守住心中对耶稣的信，他们说：“只有经历诸多苦难，我们才能进入上帝之国。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="提多书 1:5; 使徒行传 11:30; 雅各书 5:14"> 两人为每个教会指派了长老，然后与众人一起祈祷和禁食，之后就将他们交给所信的主，受到主的关怀，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 13:13–14; 使徒行传 15:38"> 然后经过彼西底来到旁非利亚。</span>
<span className="v" id="v25" data-v="25"> 在别加讲道以后，他们又继续去往亚大利，</span>
<span className="v" id="v26" data-v="26" data-xref="使徒行传 15:40; 使徒行传 11:19; 哥林多后书 1:12"> 从那里坐船返回安提阿<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="叙利亚的安提阿是他们传道之旅的起点（参见13:1）。">d</a></sup>，那里是他们旅程的起点，也是在那里受到上帝的恩典，致力于完成自己的使命，如今使命已经达成。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 16:9; 使徒行传 15:12; 歌罗西书 4:3"> 他们抵达目的地后就召集教会的众人，讲述了上帝通过他们所做的一切，以及他如何向信他的异教徒敞开大门。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 11:26; 使徒行传 15:35"> 随后两人与信徒们一起生活了很久。</span>
</div>
</div>

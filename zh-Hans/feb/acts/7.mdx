<span className="v" id="v1" data-v="1" data-xref="约翰福音 18:19–21; 马太福音 26:61–62; 使徒行传 6:13–14"> 大祭司问到：“这些指控是真的吗？”</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 22:1; Genesis 11:31; Psalms 29:3"> 司提芬说：“各位父老兄弟，听我说！我们的祖先亚伯拉罕当年还没有搬到哈兰时，曾住在美索不达米亚，荣耀的上帝就是在那个时候向他显现，</span>
<span className="v" id="v3" data-v="3" data-xref="Genesis 12:1; 希伯来书 11:8; Joshua 24:3"> 对他说：‘你要离开你的国家和民众，到我指示你的地方去。’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="引自《创世纪》12:1。">a</a></sup></span>
<span className="v" id="v4" data-v="4" data-xref="Genesis 12:4–5; Genesis 11:31–32; Isaiah 41:9"> 于是他离开迦勒底人的国家，搬到哈兰。他父亲去世后，上帝又叫他从那里迁到你们现在所住的地方。</span>
<span className="v" id="v5" data-v="5" data-xref="Genesis 17:8; Genesis 12:7; Genesis 13:15"> 但上帝并没有在这里赐他产业，他甚至没有立足之地。但上帝承诺将赐予他和子孙田产，尽管那时他尚无子嗣。</span>
<span className="v" id="v6" data-v="6" data-xref="Genesis 15:13; Exodus 12:40–41; 加拉太书 3:17"> 上帝还告诉他，他的后代将在异教徒国家居住，他们将会在那里被奴役、被虐待长达四百年。</span>
<span className="v" id="v7" data-v="7" data-xref="Exodus 3:12; Psalms 105:27–36; Nehemiah 9:9–11"> 上帝说：‘我会惩罚那个奴役他们的国家，最终，他们会离开那里，来到这敬拜我。’<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="引自《创世纪》15:13-14；《出埃及记》3:12。">b</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="Genesis 35:23–26; Genesis 17:9–14; Genesis 21:1–4"> 上帝还赐予他割礼之约。于是亚伯拉罕的儿子以撒在出生后第八天就行了割礼。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或“割礼约定。”">c</a></sup>随后，以撒诞下雅各，雅各是十二位族长的父亲。</span>
<span className="v" id="v9" data-v="9" data-xref="Genesis 39:2; Psalms 105:17; Isaiah 43:2"> 先人们因为妒忌约瑟，就把他卖到埃及为奴，但上帝与他同在，</span>
<span className="v" id="v10" data-v="10" data-xref="Proverbs 3:4; 提摩太后书 4:18; Proverbs 2:6"> 救他于所有苦难之中，赋予他智慧，让他获得埃及王法老的偏爱。法老立他为主管，管理埃及和法老皇族的事务。</span>
<span className="v" id="v11" data-v="11" data-xref="Genesis 41:54–57; Genesis 45:11; Genesis 42:5"> 后来埃及和迦南全境遭遇了一场大饥荒，先人没有办法获得食物。</span>
<span className="v" id="v12" data-v="12" data-xref="Genesis 42:1–24; Genesis 43:2"> 雅各听说埃及有粮食，于是派我们的祖先去，这也是他们的第一次造访。</span>
<span className="v" id="v13" data-v="13" data-xref="Genesis 45:1–18; Genesis 46:31–10"> 在第二次造访期间，约瑟向兄弟们表明了自己的身世，法老才了解了约瑟的家世。</span>
<span className="v" id="v14" data-v="14" data-xref="Genesis 46:26–27; Deuteronomy 10:22; Exodus 1:5"> 约瑟派人把自己的父亲雅各和所有亲戚接了过来，总计七十五人。</span>
<span className="v" id="v15" data-v="15" data-xref="Genesis 49:33; Exodus 1:6; Genesis 46:3–7"> 雅各来到埃及，然后和其他祖先一样，都在埃及去世。</span>
<span className="v" id="v16" data-v="16" data-xref="Joshua 24:32; Genesis 23:16; Exodus 13:19"> 他们的遗体被运回示剑，埋葬在亚伯拉罕用银子从哈抹之子那里买来的墓地中。</span>
<span className="v" id="v17" data-v="17" data-xref="Exodus 1:7–12; 使徒行传 7:6; 使徒行传 13:17"> 此刻已接近上帝对亚伯拉罕承诺的兑现时间，以色列人在埃及的人口越来越多。</span>
<span className="v" id="v18" data-v="18" data-xref="Exodus 1:8"> 这时又一位新郡王开始统治埃及，他并不认识约瑟。</span>
<span className="v" id="v19" data-v="19" data-xref="Psalms 105:25; Exodus 1:9–22; 启示录 12:4–5"> 他阴谋利用我们的同胞，虐待我们的祖先，逼他们拋弃自己的孩子，任由孩子死去。</span>
<span className="v" id="v20" data-v="20" data-xref="希伯来书 11:23; Exodus 2:2–10; 1 Samuel 16:12"> 就在那时候，摩西降生了。他生来俊美，在父亲家中被照顾了三个月。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 11:24; Exodus 2:2–10; Deuteronomy 32:26"> 他被拋弃后，法老女儿把他捡了回去，当作儿子抚养。</span>
<span className="v" id="v22" data-v="22" data-xref="Isaiah 19:11; Daniel 1:17–20; 2 Chronicles 9:22"> 摩西接受了埃及人所有知识领域的教育，是一位强有力的演讲者和领袖。</span>
<span className="v" id="v23" data-v="23" data-xref="Exodus 2:11–12; Proverbs 21:1; 希伯来书 11:24–26"> 但到了四十岁那年，他决定去造访自己的同胞以色列人。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 18:10–11; 使徒行传 7:28; 约翰福音 18:25–27"> 他看到一位同胞受到虐待，就跑过去为同胞伸张正义，打死了那个欺负人的埃及人。</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 15:7; 马可福音 9:32; 2 Kings 5:1"> 摩西以为，他的以色列同胞们知道上帝将通过他拯救他们，但此时他们对此一无所知。</span>
<span className="v" id="v26" data-v="26" data-xref="Exodus 2:13–15; Proverbs 18:19; 约翰一书 3:11–15"> 第二天他来到这里时，看到两个以色列人在打架，便试图调和两人的争斗：‘嘿，你们是兄弟，为什么要攻击彼此呢？’</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 7:35; 路加福音 12:14; 使徒行传 7:54"> 但那挑起事端的男人把他推开，质问到：‘谁让你管我们的？怎么你成了我们的法官了？</span>
<span className="v" id="v28" data-v="28"> 难道你想像昨天杀那个埃及人一样，杀了我吗？’<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="引自《出埃及记》2:13-14.">d</a></sup></span>
<span className="v" id="v29" data-v="29" data-xref="Exodus 18:2–4; Exodus 2:14–22; Exodus 4:19–20"> 听到这番话，摩西离开了此地，以流亡者的身份来到米甸地，在那里有两个儿子。</span>
<span className="v" id="v30" data-v="30" data-xref="Exodus 3:1–2; 使徒行传 7:35; Isaiah 43:2"> 四十年后在西奈山的荒野中，一位天使在燃烧的荆棘丛中向摩西显现。</span>
<span className="v" id="v31" data-v="31" data-xref="Exodus 3:3–4"> 摩西见此非常惊讶，跑上前去想要仔细端详，这时就有主的声音说：</span>
<span className="v" id="v32" data-v="32" data-xref="Exodus 3:6; 马太福音 22:32; Job 4:14"> ‘我是你祖先的上帝，就是亚伯拉罕、以撒、雅各的上帝。’<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="引自《出埃及记》3:6。">e</a></sup>摩西吓得战战兢兢，不敢抬头。</span>
<span className="v" id="v33" data-v="33" data-xref="Exodus 3:5; Joshua 5:15; Ecclesiastes 5:1"> 主对他说：‘脱掉你的鞋，因为你站在圣地。</span>
<span className="v" id="v34" data-v="34" data-xref="Exodus 3:7–10; Exodus 4:31; Psalms 106:44"> 我亲眼看到我的子民在埃及所受的痛苦，听到他们的悲鸣，现在我要到人间拯救他们。现在过来，我要派你到埃及去。’<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="引自《出埃及记》3:5-10。">f</a></sup></span>
<span className="v" id="v35" data-v="35" data-xref="Psalms 118:22–23; 路加福音 19:14; Psalms 113:7–8"> 就是这位摩西，当他们说：‘谁让你成为审判我们的领袖？’并因此而排斥他，<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="引自《出埃及记》2:14。">g</a></sup>上帝派天使在荆棘中向他显现，指定他成为领袖和救赎者。</span>
<span className="v" id="v36" data-v="36" data-xref="Exodus 12:41; Exodus 14:21; Exodus 33:1"> 摩西在埃及和红海显现神迹后，便带领以色列人离开埃及，在随后的四十年中，又在荒野中继续显现神迹。</span>
<span className="v" id="v37" data-v="37" data-xref="Deuteronomy 18:15–19; 使徒行传 3:22–23; 约翰福音 18:37"> 就是这位摩西，对以色列人承诺‘上帝要从你们中间选择一名像我这样的先知。’<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="引自《申命记》18:15。">h</a></sup></span>
<span className="v" id="v38" data-v="38" data-xref="罗马书 3:2; 希伯来书 5:12; 彼得前书 4:11"> 当摩西和上帝召集的民众来到荒野中后，天使在西奈山上与他对话。就是在那里，他和祖先们一起亲自接受了上帝传递给我们的鲜活之语。</span>
<span className="v" id="v39" data-v="39" data-xref="Numbers 14:3–4; Numbers 11:5; Nehemiah 9:16–17"> 就是这位摩西，我们的祖先不先信他，而是拒绝他，打算返回埃及。</span>
<span className="v" id="v40" data-v="40" data-xref="Exodus 32:1; Exodus 32:23"> 于是他们对亚伦说：‘为我们制作上帝的神像，因为我们不知道把我们从埃及领出来的摩西，到底发生了什么。’<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="引自《出埃及记》32:1。">i</a></sup></span>
<span className="v" id="v41" data-v="41" data-xref="Psalms 106:19–21; Nehemiah 9:18; 启示录 9:20"> 然后他们制作了一个牛犊样子的神像，向其献祭，还因为自己做出来的东西而大肆庆祝！</span>
<span className="v" id="v42" data-v="42" data-xref="Amos 5:25–26; Ezekiel 20:39; Jeremiah 19:13"> 于是上帝放弃了他们，任凭他们膜拜星辰，正如先知所写：‘以色列人啊，你们在荒野四十年中，可曾将祭牲和祭物献给我？</span>
<span className="v" id="v43" data-v="43" data-xref="Amos 5:26–27; Exodus 20:4–5; Deuteronomy 5:8–9"> 没有，你们抬着摩洛的帐篷，还有理番之神的星星图像，你们把它们做出来然后膜拜它们。所以我要把你们放逐到巴比伦的另一边。’<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="引自《阿摩司书》5:25-27。">j</a></sup></span>
<span className="v" id="v44" data-v="44" data-xref="Exodus 25:40; Exodus 38:21; 希伯来书 8:5"> 我们的祖先在沙漠中有见证的帐幕<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="意为它传达了上帝的信息，提供他存在的证据。">k</a></sup>。上帝谈话向摩西指示，如何按照上帝的计划行事。</span>
<span className="v" id="v45" data-v="45" data-xref="Psalms 44:2; Joshua 18:1; Joshua 23:9"> 后来，我们的祖先与约书亚一起占领了这片土地，把帐幕也带到这里。在他们之前，上帝已将这片土地中的异教徒赶走。他们在这里一直居住到大卫的时代。</span>
<span className="v" id="v46" data-v="46" data-xref="Psalms 132:1–5; 使徒行传 13:22; 2 Samuel 7:1–5"> 大卫蒙受上帝的恩宠，请求为雅各的上帝找个居所。</span>
<span className="v" id="v47" data-v="47" data-xref="1 Kings 8:20; 1 Kings 6:37–38; 2 Samuel 7:13"> 但为他修建圣殿<sup className="fn"><a href="#fn-l" id="fnref-l" data-fn="原意为“房子。”">l</a></sup>的却是所罗门。</span>
<span className="v" id="v48" data-v="48" data-xref="使徒行传 17:24–25; Isaiah 66:1–2; 1 Kings 8:27"> 但事实上，至高之神并没有住在我们为其建造的圣殿中，正如先知说：</span>
<span className="v" id="v49" data-v="49" data-xref="Isaiah 66:1; Psalms 11:4; 约翰福音 4:21"> ‘主说：天是我的宝座，地是我的脚凳，你们又能为我建造怎样的居所呢？你为我造出的床，怎能让我安寝？</span>
<span className="v" id="v50" data-v="50" data-xref="Jeremiah 32:17; Psalms 33:6–9; 使徒行传 14:15"> 这一切不都是出自我手吗？’<sup className="fn"><a href="#fn-m" id="fnref-m" data-fn="引自《以赛亚书》66:1-2。">m</a></sup></span>
<span className="v" id="v51" data-v="51" data-xref="Deuteronomy 10:16; 以弗所书 4:30; Isaiah 63:10"> 你们这些心肠冰冷的傲慢之人呐！你们从不聆听！<sup className="fn"><a href="#fn-n" id="fnref-n" data-fn="原意为“在心脏和耳朵上进行割礼。”">n</a></sup>你们总是抗拒圣灵！你们的行为就和你们的祖先一模一样！</span>
<span className="v" id="v52" data-v="52" data-xref="马太福音 5:12; 2 Chronicles 36:16; 1 Kings 19:10"> 哪位先知没有遭受你们祖先的迫害？先知预先告知那真正善良正义之人即将到来，于是就被杀害。现在，那善良正义之人又被你们背叛和谋杀。</span>
<span className="v" id="v53" data-v="53" data-xref="希伯来书 2:2; 加拉太书 3:19; 使徒行传 7:38"> 你们接受了由天使传达的律法，却不遵守。”</span>
<span className="v" id="v54" data-v="54" data-xref="使徒行传 5:33; Psalms 35:16; 马太福音 25:30"> 公议会的成员听闻此言，恼怒异常，咬牙切齿地向司提芬咆哮。</span>
<span className="v" id="v55" data-v="55" data-xref="马可福音 16:19; 希伯来书 1:3; 哥林多后书 4:6"> 但司提芬身体中充满圣灵，他目不转睛地望着天，看见上帝的荣耀，看见耶稣站在上帝的右边。</span>
<span className="v" id="v56" data-v="56" data-xref="马太福音 26:64–65; 使徒行传 10:11; 启示录 11:19"> 他说：“看呐！我看见天已开启，人子站在上帝的右边。”</span>
<span className="v" id="v57" data-v="57" data-xref="Zechariah 7:11; Psalms 58:4; 使徒行传 23:27"> 但众人却捂住了耳朵，大声喊叫着向他冲过去，</span>
<span className="v" id="v58" data-v="58" data-xref="使徒行传 22:20; 使徒行传 8:1; 使徒行传 6:13"> 把他推出城外，用石头打他。那些谴责他的人把自己的衣服放在一个名叫扫罗的青年人脚前。</span>
<span className="v" id="v59" data-v="59" data-xref="路加福音 23:46; Psalms 31:5; 使徒行传 22:16"> 司提芬在被他们用石头攻击时祈祷：“主耶稣啊，求你接收我的灵魂！”</span>
<span className="v" id="v60" data-v="60" data-xref="马太福音 5:44; 路加福音 23:34; 哥林多前书 15:20"> 然后跪下来大喊：“主啊，不要因这罪而惩罚他们！”说罢，他就死去了。<sup className="fn"><a href="#fn-o" id="fnref-o" data-fn="原意为“睡着了。”在《新约》中常用“睡着”来指代死亡。">o</a></sup></span>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="feb" data-translation-id="cmn_feb" data-translation-label="易读圣经" data-book="ACT" data-book-slug="acts" data-book-name="使徒行传" data-chapter="17" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 1:1; 腓立比书 4:16; 使徒行传 20:4"> 保罗和西拉沿途经过了暗非波里和亚波罗尼亚，来到帖撒罗尼迦，那里有犹太人的会堂。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 9:20; 使徒行传 17:17; 使徒行传 18:4"> 保罗按惯例走进会堂，一连三个安息日，都在这里根据圣经与他们进行辩论。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 18:28; 使徒行传 9:22; 路加福音 24:32"> 他解释了经文的含义，证明基督必须先死去后，然后再死而复生。他对众人说：“我向你们讲述的这位耶稣，就是基督。”</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 17:12; 使徒行传 13:43; 使徒行传 14:4"> 有的人被保罗和西拉说服了，加入了他们的行列，此外还有很多说希腊语的朝拜者<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="说希腊语的朝拜者：这个词通常用于表明其“异教徒”的身份。他们接受了犹太教唯一上帝的信仰，但并未通过割礼成为犹太人。">a</a></sup>，以及城里位高权重的女性。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="加拉太书 5:26; 使徒行传 17:13; 罗马书 16:21"> 但犹太人却因此而倍感嫉妒，于是从集市中找来一群流氓，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“市场中的恶人。”">b</a></sup>凑成团伙在城里面闹事。他们冲进耶孙的家中，到处寻找保罗和西拉，要把他们交给民众。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 24:5; 使徒行传 16:19–21; 使徒行传 28:22"> 但由于找不到这两名使徒，他们就把耶孙和几名信徒带到地方长官那里，叫嚣着说：“这些人素有滋事的恶名，把这世界闹得天翻地覆。现在他们来到这里，</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 23:2; 使徒行传 16:21; 约翰福音 19:12"> 耶孙却在自己的家宅中招待这些人。他们都违背凯撒的法令，说另外还有一个王叫做耶稣，这就是叛国罪。”</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 2:3; 约翰福音 11:48"> 民众和地方长官听到这番话，深感不安，</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 17:5"> 让耶孙和其余人交了保释金后，就放了他们。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 17:2; 帖撒罗尼迦前书 2:2; 使徒行传 17:13–14"> 信徒们当晚就将保罗和西拉送走。二人去了比里亚，到达后便走进犹太人的会堂。</span>
<span className="v" id="v11" data-v="11" data-xref="Isaiah 34:16; Proverbs 2:1–5; 约翰福音 5:39"> 这里的民众比帖撒罗尼迦人开明，他们很快就接受了主的道，每天研读圣经，确认他们所听到的是否正确。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 5:14; 使徒行传 14:1; 使徒行传 13:50"> 很多人因此成为信徒，包括地位高贵的希腊男性和女性。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="帖撒罗尼迦前书 2:14–16; Proverbs 28:25; 使徒行传 6:12"> 但帖撒罗尼迦的犹太人听说保罗又在比里亚宣讲上帝之道，便跑到那里煽动挑拨民众。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 17:10; 马太福音 10:23; 使徒行传 9:25"> 信徒们立刻把保罗送到海边，西拉和提摩太仍然留在比里亚。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 18:5; 帖撒罗尼迦前书 3:1; 使徒行传 18:1"> 护送保罗的人将他远远地带到雅典，保罗在他们返回的时候，给西拉和提摩太带去口信，让他们尽快赶去与他会和。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="Psalms 119:158; 彼得后书 2:7; Psalms 119:136"> 保罗在雅典等他们的时候，看见满城都是宗教神像，心中感到非常不安。</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 13:16; 使徒行传 14:1–4; 使徒行传 17:2–4"> 于是在会堂中与犹太人和其他崇拜上帝之人进行了辩论<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="大概是17:4中所提到的同一类“信徒”，即接受以色列上帝、但未成为犹太人的异教徒。">c</a></sup>，此外还每天到集市中去，与所遇到的陌生人进行辩论。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 1:20–21; 歌罗西书 2:8; 路加福音 11:53"> 有些伊壁鸠鲁派和斯多亚派的哲学家也同他争论。他们想知道：“这个人到底想要干什么？”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="原意为“这个啄种鸟想说什么？”“啄种鸟”是一种在集市上啄食种子的鸟，叫个不停，因此这个词也可以做“胡言乱语”之意。">d</a></sup>由于保罗谈论了耶稣和复活，所以还有人认为：“他似乎是在宣讲外族的神。”</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 1:27; 使徒行传 17:22; 使徒行传 24:24"> 于是他们把保罗带到亚略巴古<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="这是类似哲学家论坛的地方。">e</a></sup>，询问他：“请和我们讲讲你所宣扬的那个新教义？</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 1:23; Hosea 8:12; 哥林多前书 2:14"> 我们听说了你讲的那些事情，听起来太奇怪了，所以我们想知道那到底是什么意思。”</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 2:16–17; 歌罗西书 4:5; 以弗所书 5:16"> （所有雅典人和住在那里的异教徒，都非常喜欢谈论和打听新奇之事，以此打发时间）。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="使徒行传 25:19; 使徒行传 19:35; 使徒行传 17:16"> 保罗站上亚略巴古的中间，说：“各位雅典人，我发现你们对任何事情都抱有虔诚之心。</span>
<span className="v" id="v23" data-v="23" data-xref="约翰福音 4:22; 加拉太书 4:8–9; 约翰福音 17:3"> 我走路的时候曾留意你们的圣坛，曾有一个圣坛上写着‘献给未知的神’。我要向你们讲述的上帝，就是你们所膜拜的这个未知之神。</span>
<span className="v" id="v24" data-v="24" data-xref="1 Kings 8:27; Deuteronomy 10:14; 使徒行传 7:48"> 上帝创造世界和世间万物，他是天地的主，并未生活在人类建造的庙宇之中，</span>
<span className="v" id="v25" data-v="25" data-xref="Psalms 50:8–13; Genesis 2:7; Isaiah 42:5"> 他什么都不需要，也不需要我们的服务，因为他本身就是所有生灵的生命之源。</span>
<span className="v" id="v26" data-v="26" data-xref="Deuteronomy 32:7–8; Genesis 3:20; 罗马书 5:12–19"> 他从一个最初的人创造了世界上的所有人，在之前就决定了他们应该生活在哪里，应该活多久。</span>
<span className="v" id="v27" data-v="27" data-xref="Jeremiah 23:23–24; Deuteronomy 4:7; 使徒行传 14:17"> 上帝想要的是他们能够追寻上帝，能够去寻找并找到他。但其实他离我们每个人都不遥远。</span>
<span className="v" id="v28" data-v="28" data-xref="Job 12:10; 歌罗西书 1:17; 希伯来书 1:3"> 我们在他的护翼下生存、活动和存在。正如你们的诗人写到：‘我们就是他的家人。’</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="Isaiah 40:25; Exodus 20:4; Psalms 115:4–8"> 正因为我们是他的家人，所以不应该将上帝想象成金银石头，然后由人类用手艺和思想将其塑造形象。</span>
<span className="v" id="v30" data-v="30" data-xref="使徒行传 14:16; 提多书 2:11–12; 路加福音 24:47"> 上帝原谅了人类过往的无知，但现在，他吩咐各处的所有人都要悔改，</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 25:31–46; 彼得后书 3:7; 罗马书 2:16"> 因为他已经定好时间，届时将由他指认的那个人，对世间进行正义审判。为了向众人证明他就是那个人，上帝会让那人死而复生。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行传 17:18; 使徒行传 26:8; 使徒行传 25:19"> 众人听到死人复活这句，便开始嘲笑他。但也有人说：“以后请回来，给我们多讲讲这件事。”</span>
<span className="v" id="v33" data-v="33"> 于是保罗就离开他们了。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 17:19; 罗马书 11:5–6; 使徒行传 13:48"> 有几个人跟随了他并且相信了上帝，包括亚略巴古的成员丢尼修、一位名叫戴马里的女子和很多其他人。</span>
</div>
</div>

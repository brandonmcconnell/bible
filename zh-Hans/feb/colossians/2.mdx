<span className="v" id="v1" data-v="1" data-xref="歌罗西书 1:29; 腓立比书 1:30; 启示录 3:14–22"> 我想让你们知道我是多么的努力工作，为了你们、为了老底嘉的人们，事实上还为那些不曾见过面的人们。</span>
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 1:27; 歌罗西书 4:8; 以弗所书 6:22"> 我的努力是为了让你们能够受到鼓舞，让你们在爱中彼此联系，可以凭借领悟而感到完全的确信，以此获得巨大的益处，因为这才是上帝带来的真正知识。希望你们知道，上帝显现的奥秘，那就是耶稣！</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 1:24; 哥林多前书 1:30; 罗马书 11:33"> 通过耶稣，你们可以发现一切智慧和知识。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰一书 4:1; 以弗所书 4:14; 罗马书 16:18–19"> 我说这些话，免得有人用花言巧语欺骗你们。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“虚假的论点。”">a</a></sup></span>
<span className="v" id="v5" data-v="5" data-xref="哥林多前书 5:3–4; 帖撒罗尼迦前书 2:17; 哥林多前书 16:13"> 我的身体虽然没有和你们在一起，灵却与你们同在。很高兴看见团结在一起，坚定地信基督。</span>
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 1:10; 约翰一书 2:6; 帖撒罗尼迦前书 4:1"> 一如你们如何接受基督耶稣为主，就按照这种方式追随他，</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 3:17; Jeremiah 17:8; 以弗所书 2:20–22"> 以他为根基，以他进行修建。希望你们对他的信能继续变得更强壮，遵循一直向你们教导的，对上帝充满感激。</span>
<span className="v" id="v8" data-v="8" data-xref="提摩太前书 6:20; 以弗所书 5:6; 马太福音 7:15"> 要小心，不要哪些不遵循基督、而是按照人的传统和世俗言论，皆有其哲学和骗人的空谈，奴役你们。</span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 1:19; 约翰福音 10:30; 约翰福音 1:14"> 因为上帝神圣本性，以基督身体的形式完整存在，</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 3:19; 歌罗西书 1:16–18; 以弗所书 1:20–23"> 你们也因他而完整<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或“完整”、“整体。”">b</a></sup>。他远远高于所有执政掌权者。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 2:29; 腓立比书 3:3; 罗马书 6:6"> 通过他，你们接受了“割礼”，但并非由人手进行，而是通过基督提供的割礼，从人类罪的天性中获得自由。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="很明显，这不是在谈论身体上的割礼，而是它在精神上的上的意义。">c</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 6:3–5; 彼得前书 3:21; 加拉太书 3:27"> 你们在洗礼中已与他埋葬在一起，也因信上帝将基督从死人中复活的行为，与耶稣一同复活了。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 2:5–6; 罗马书 8:11; 以弗所书 2:1"> 尽管你们因罪和肉体未受割礼而死亡，但上帝让你们与基督一起复活，上帝赦免了我们的一切罪。</span>
<span className="v" id="v14" data-v="14" data-xref="Isaiah 44:22; 以弗所书 2:14–16; Isaiah 43:25"> 他根据那用于反对我们的律法，抹去了我们的债；他把这障碍<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="请注意，这个障碍对我们而言，不是对上帝。">d</a></sup>钉在十字架上，以此将其移除。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 2:14; 以弗所书 4:8; 马太福音 12:29"> 他废除了 很明显，这不是在谈论身体上的割礼，而是它在精神上的上的意义。统治者和掌权者的权利，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="很明确指的是邪恶的宗教机构。">e</a></sup>将他们的真正的样子公开显示，用胜利彻底征服他们。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 14:5–6; 罗马书 14:10; 加拉太书 4:10"> 所以不要让任何人因你们所选择遵循的饮食、宗教节日、新月或特殊安息日，而批评你们 你选择跟随。<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="在此处，保罗所指的是犹太人礼仪中每年的各种节日。">f</a></sup></span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 10:1; 希伯来书 8:5; 约翰福音 1:17"> 这些不过是即将到来之事的影子，因为那真正的现实就是基督。</span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 2:8; 约翰一书 4:1–2; 歌罗西书 2:23"> 不要让人通过欺骗夺去你们<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="自我折磨；这句话也可以翻译成“虚假的谦卑。”">g</a></sup>的奖赏，他们坚持让你们故作谦卑或敬拜天使。他们说自己曾看到过异像，所以就认为自己好于任何人，他们的有罪思想也变得如此自负，令人可笑。</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所书 4:15–16; 约翰福音 15:4–6; 彼得后书 3:18"> 这样的人并没有与自己的头连接，没有用头指导身体，没有通过身体的关节和筋络获得滋养，连接在一起。因为身体是连接在一起的，按照上帝希望它成长的方式成长。</span>
<span className="v" id="v20" data-v="20" data-xref="歌罗西书 2:8; 歌罗西书 2:16; 加拉太书 4:3"> 你们若与基督一同死去，摆脱世俗强加给你们的宗教要求，<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="可能是指犹太宗教规定，也可能是异教仪式和禁忌。">h</a></sup>为什么好像仍然是这个世界的一部分，仍然要受这些要求的摆布，</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太前书 4:3; Genesis 3:3; Isaiah 52:11"> 比如“不可拿、不可尝、不可触”的要求？</span>
<span className="v" id="v22" data-v="22" data-xref="Isaiah 29:13; 提多书 1:14; 哥林多前书 6:13"> 这些要求所指，是一经使用就会坏掉的东西。<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="这通常是指关于食物和饮料的规则，这些食物和饮料肯定会被消费，然后“用完。”">i</a></sup>这些规条是照着人的要求和教训而定。</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太前书 4:8; 歌罗西书 2:18; 歌罗西书 2:8"> 对于那些以自我为中心敬拜之人、故作谦卑之人和“苦修身体”之人，这些规则似乎合情合理。但事实上，它们在应对所有罪恶欲望方面，没有任何帮助。</span>
</div>

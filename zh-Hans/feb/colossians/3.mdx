<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="罗马书 8:6; 马太福音 6:33; 哥林多后书 4:18"> 所以，你们既然与基督共同复活，就应当寻求天上之事，在那里，基督坐在上帝的右边。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 2:15–17; 1 Chronicles 22:19; 歌罗西书 3:1"> 要改变你们的想法，关注天上而非地上的事。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 2:20; 罗马书 6:2; 歌罗西书 2:20"> 你们已经死去，你们的生命与基督一起，与上帝同在，保持安全。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 11:25; 约翰一书 3:2; 加拉太书 2:20"> 基督就是你们的生命，当他显现，你们也会分享他所显现的荣耀。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="罗马书 8:13; 加拉太书 5:19–21; 加拉太书 5:24"> 所以要清除你们在这世间的天性，比如性罪恶、不道德、淫念、恶欲和贪欲。这些都是在拜神像。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所书 5:6; 罗马书 1:18; 彼得前书 1:14"> 因为这些事，忤逆之人会体验上帝的审判。</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 2:2; 彼得前书 4:3–4; 罗马书 6:19–20"> 你们曾经这样生活，遵循这样的行文，</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 4:29; 以弗所书 4:22; 雅各书 1:20–21"> 但现在，你们应该摆脱忿怒、恼怒、恶毒、毁谤以及粗言秽语这样的事。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 4:22; 以弗所书 4:25; Leviticus 19:11"> 不要彼此说谎，因为你们已经摆脱旧我和旧行，</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 4:23–24; 罗马书 12:2; 以弗所书 2:10"> 换上新我，这新我更像是造物主，能够更好地认识主。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太书 3:28–29; 哥林多前书 12:13; 罗马书 10:12"> 在这种新情况下，不分希腊人和犹太人、受割礼的和未受割礼、外族人、野蛮人、<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“塞西亚人”，被认为是源自现在俄罗斯南部、乌克兰和中亚地区的“野蛮人”">a</a></sup>奴隶或自由人，因为基督就是一切，也存在与我们所有人之中。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以弗所书 4:32; 以弗所书 4:2; 约翰一书 4:19"> 因为你们是上帝的特殊子民，是圣洁、蒙爱之人，就要拥有怜悯的性情，恩慈、谦卑、温柔和忍耐。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 4:32; 马可福音 11:25; 雅各书 2:13"> 如果你对其他人有抱怨，要彼此宽容，互相饶恕；主怎样饶恕你们，你们也要怎样饶恕别人。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 4:8; 以弗所书 5:2; 哥林多前书 13:1–13"> 最重要的是，要爱彼此，这是将你们团结在一起的最佳纽带。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比书 4:6–7; 约翰福音 14:27; Isaiah 26:3"> 愿基督的平安指引你们的思考，因为你们受上帝蒙召成为一体，也要为此要感谢上帝。</span>
<span className="v" id="v16" data-v="16" data-xref="Psalms 119:11; 以弗所书 5:19; 约翰福音 15:7"> 让基督之道充分住在你们心里，遵循所有智慧之道，用诗章、圣诗、灵歌彼此教导，互相劝戒，怀着感恩和虔诚歌颂上帝。</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 10:31; 歌罗西书 3:23; Proverbs 3:6"> 你们所作的一切，无论是言语或行为，都要以主耶稣之名，借着他感谢父上帝。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 5:22–9; 提多书 2:4–5; 哥林多前书 11:3"> 你们做妻子的要尊重丈夫，这对主而言是正确的行为。</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前书 3:7; Genesis 2:23–24; 歌罗西书 3:21"> 你们作丈夫的要爱妻子，不可错误地对待她们。</span>
<span className="v" id="v20" data-v="20" data-xref="Exodus 20:12; 以弗所书 6:1–3; Proverbs 6:20"> 你们作儿女的凡事要听从父母，这会让主感到喜悦。</span>
<span className="v" id="v21" data-v="21" data-xref="Proverbs 4:1–4; 以弗所书 6:4; Psalms 103:13"> 你们作父亲的不要激怒儿女，免得他们丧失信心。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 6:5–7; 提摩太前书 6:1–2; 加拉太书 1:10"> 你们作仆人的要凡事听从人类主人，做事不要只是为了让主人看，而是要真诚地尊重主。</span>
<span className="v" id="v23" data-v="23" data-xref="歌罗西书 3:17; 以弗所书 6:6–7; 罗马书 14:8"> 无论你们作什么，都要认真做，就像你在为主做这一切，而非为人。</span>
<span className="v" id="v24" data-v="24" data-xref="以弗所书 6:8; 加拉太书 1:10; 使徒行传 20:32"> 因为你们知道，主会给你们回报，让你们继承！你们服务于主耶稣！</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 10:34; 罗马书 2:11; 哥林多后书 5:10"> 但那些不义的人，就会因其行为而遭受报应。主从不偏袒。</span>
</div>

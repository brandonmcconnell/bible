<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以弗所书 6:8–20; 雅各书 2:13; Deuteronomy 24:14–15"> 你们作主人的要公平对待仆人，要知道你们也有一位天上的主人。</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦前书 5:17–18; 腓立比书 4:6; 以弗所书 6:18"> 记得始终要祷告，心存警醒和感恩的心祷告！</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所书 6:19–20; 使徒行传 14:27; 帖撒罗尼迦后书 3:1–2"> 也要为我们祷告，求上帝为我们打开传道之门，讲述基督所显现的奥秘，我也是因为这个原因，此刻被投入监牢。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 4:1–4; 以弗所书 6:20; 歌罗西书 4:6"> 祈祷我能像我说的那样，把事情说明白。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 5:15–17; 帖撒罗尼迦前书 4:12; 雅各书 3:13"> 你们要把握时机，聪明地与外人来往。</span>
<span className="v" id="v6" data-v="6" data-xref="以弗所书 4:29; 彼得前书 3:15; Ecclesiastes 10:12"> 说话时始终要保持礼貌，要大方得体，要思考如何以最佳方式回答所有人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以弗所书 6:21–23; 使徒行传 20:4; 提摩太后书 4:12"> 关于我所发生的一切，推基古会告诉你们。他是我心爱的兄弟，是值得新来的神职者，是与主同在的工友。</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 6:22; 歌罗西书 2:2; 腓立比书 2:28"> 我派他到你们那里去，就是为了一个理由：让你们知道我们的情况，让你们振作起来。</span>
<span className="v" id="v9" data-v="9" data-xref="腓利门书 1:10–19; 歌罗西书 4:7"> 与他同去的是欧尼西慕，这是一位值得信赖的亲爱兄弟，是你们的一份子。他们会把这里的一切告诉你们。</span>
<span className="v" id="v10" data-v="10" data-xref="腓利门书 1:24; 提摩太后书 4:11; 使徒行传 19:29"> 与我一起被投入监牢的还有亚里达古, 以及巴拿巴的表弟马可，他们也向你们问候。（正如之前告诉你们的，如果马克拜访你们，请接待他。）</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 11:2; 哥林多后书 6:1; 使徒行传 10:45"> 此外还有别号为优士都的耶稣，他们都是犹太的基督徒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“属于受割礼的人。”">a</a></sup>，在这里与我一起为上帝王国工作，对我的帮助很大。</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 15:30; 歌罗西书 1:9; 歌罗西书 1:7"> 以巴弗也问候你们，他是你们那里的人，是基督耶稣的仆人。他祷告的时候，总是充满热情地为你们祈祷，希望你们作为成长的基督徒，可以稳稳站立，要对上帝希望我们所做的一切充满信念。</span>
<span className="v" id="v13" data-v="13" data-xref="歌罗西书 2:1; 罗马书 10:2; 启示录 1:11"> 我可以作证，为了你们以及在老底嘉和希拉波立的人，他做了很多事情。</span>
<span className="v" id="v14" data-v="14" data-xref="腓利门书 1:24; 提摩太后书 4:10–11"> 亲爱的路加医生和底马也问候你们。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 16:5; 腓利门书 1:2; 哥林多前书 16:9"> 请问候在老底嘉的信徒和宁法，以及在她家家中聚会的教会。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦前书 5:27; 帖撒罗尼迦后书 3:14"> 你们读完这封信以后，也要交给老底嘉的教会阅读；你们也要读老底嘉的那封信。</span>
<span className="v" id="v17" data-v="17" data-xref="腓利门书 1:2; 使徒行传 1:17; Ezekiel 44:23–24"> 告诉亚基布：“要留心你在主那里领受的职务，好好把它完成。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="希伯来书 13:3; 提摩太后书 4:22; 提摩太前书 6:21"> 我是保罗，亲笔写下这封信向你们问候。记得我正在监牢之中。愿恩惠与你们同在。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 1:1; 哥林多前书 1:1; 腓利门书 1:1"> 这封信函来自奉上帝旨意成为基督耶稣使徒的保罗以及提摩太兄弟，</span>
<span className="v" id="v2" data-v="2" data-xref="彼得后书 1:2; 以弗所书 1:1; 罗马书 1:7"> 写给歌罗西的信徒以及相信基督的所有人。愿你们获得来自上帝我父的恩典与平安。</span>
<span className="v" id="v3" data-v="3" data-xref="帖撒罗尼迦前书 1:2; 歌罗西书 1:9; 提摩太后书 1:3"> 我们始终为你们感谢上帝，我主耶稣基督之父，为你祈祷。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 1:15; 帖撒罗尼迦后书 1:3; 帖撒罗尼迦前书 1:3"> 我们已听说你们对基督耶稣的信仰，以及你们对所有信徒的爱，</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前书 1:3–4; 以弗所书 1:13; 提摩太后书 4:8"> 因为在天堂有希望在等着你们。你们已经在福音中听到这个信息，</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 15:16; 腓立比书 1:11; 歌罗西书 1:23"> 这真理的信息传遍全世界，在广泛的传播中产生了效果。现在，它也传向了你们。自从你们听到它并意识到上帝恩典的本质后，它也对你们产生了同样的效果。</span>
<span className="v" id="v7" data-v="7" data-xref="歌罗西书 4:12; 腓利门书 1:23; 歌罗西书 4:7"> 我们亲爱的朋友和工友的以巴弗，他代表你们成为基督值得信赖的仆人，教授你们这一切。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 15:30; 提摩太后书 1:7; 加拉太书 5:22"> 他也将你们对灵的爱，明确告诉了我们。</span>
<span className="v" id="v9" data-v="9" data-xref="雅各书 3:17; 腓立比书 1:9–11; 雅各书 1:5"> 因此，我们从听到这些消息的那天起，就不停为你们祷告，祈求上帝让你们理解他对你们的要求，赋予你们一切属灵的智慧和悟性。</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 4:1; 希伯来书 13:21; 彼得后书 1:2–3"> 通过这种方式，你们可以正直良善的方式代表主，让主喜悦；结下所有善果，更深刻地了解上帝；</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 3:16; 腓立比书 4:13; 以弗所书 4:2"> 希望你们借由他的非凡力量，可以更加强大，凡事宽容忍耐；</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 20:32; 以弗所书 1:11; 以弗所书 1:18"> 希望你们幸福地向父祈祷，他让我们可以获得生活于光明之中上帝子民的传承。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 5:8; 使徒行传 26:18; 彼得前书 2:9"> 他拯救我们脱离黑暗的统治，让我们迁入其爱子的王国。</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所书 1:7; 罗马书 3:24–25; 彼得前书 1:19–20"> 通过他的爱子，我们获得自由，罪得赦免。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 1:3; 约翰福音 14:9; 约翰福音 1:1"> 这位爱子是那不可见上帝的可见之形。他早在万物之前即已存在<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“最先出生”，显示的是位置而非出生时间。">a</a></sup>，</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 11:36; 约翰福音 1:3; 哥林多前书 8:6"> 那天上地上的一切——可见和不可见、国王、统治者和掌权者，无不通过他而创造，为他而创造。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 1:3; 哥林多前书 8:6; 使徒行传 17:28"> 他存在于万物之先，将万物凝聚在一起。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 1:22–23; 启示录 1:5; 以弗所书 4:15–16"> 他是身体的头，这身体就是教会。他是源起，在死而复生之人中位居首位<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“最先出生”，见第 15 节。这表明尽管耶稣并非最先复活之​的人，但在任何情况下都占据最高的位置。">b</a></sup>，因此超越一切。</span>
<span className="v" id="v19" data-v="19" data-xref="歌罗西书 2:9; 约翰福音 1:16; 以弗所书 1:23"> 上帝很高兴其爱子拥有他的所有特征，</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 5:18–21; 以弗所书 1:10; 约翰一书 4:9–10"> 借由其子，将宇宙万物归于他身上，因为他通过在其十字架上所流的血成就了和平；他使地上和天上的每一个人都和好。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="这个“他”在这里可能会有些难以理解。获取用一个明确的名词可能会帮助理解，但翻译会有些困难：“上帝很高兴基督拥有上帝的完整特征，通过基督，将宇宙中的一切都带回他自己（上帝），因为基督通过在十字架流的血创造了和平，通过基督让天上和地下的所有人和好。”">c</a></sup>。</span>
<span className="v" id="v21" data-v="21" data-xref="以弗所书 2:12; 提多书 3:3–7; 以弗所书 2:1–3"> 你们从前也与上帝是陌路人，你们的行为就是与他为敌。</span>
<span className="v" id="v22" data-v="22" data-xref="以弗所书 5:27; 犹大书 1:24; 以弗所书 1:4"> 但现在，上帝通过他死亡的人类身体与你们和解，把你们带到他身边，在那里能够拥有圣洁、纯粹和 无瑕。</span>
<span className="v" id="v23" data-v="23" data-xref="希伯来书 3:14; 希伯来书 3:6; 马太福音 24:13–14"> 但你们对他的信念，必须如磐石般持久，不动摇。不受动摇对福音希望。这福音你们已经听过，已传遍世界，这也是我保罗所做的工作。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 5:3; 提摩太后书 1:8; 哥林多后书 1:5–8"> 现在能为你们受苦，我感觉欢喜。因为通过我身体所发生的一切，成为基督受难的一部分。基督是为其身体——也就是教会而持续受难。</span>
<span className="v" id="v25" data-v="25" data-xref="以弗所书 3:2; 歌罗西书 1:23; 加拉太书 2:7–8"> 上帝给了我关于你们的指示，我按照这个指示服务于教会，将上帝之语完整呈现给你们。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 8:10; 罗马书 16:25–26; 以弗所书 3:3–10"> 这是很多岁月、很多世代隐藏的奥秘，但现在已经向上帝子民显现。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 14:20; 罗马书 8:10; 以弗所书 3:16–17"> 上帝希望他们知道这个光荣奥秘财富对万国的意义：<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或“异族人。”">d</a></sup>基督住在你里面是荣耀的盼望！</span>
<span className="v" id="v28" data-v="28" data-xref="以弗所书 5:27; Jeremiah 3:15; 以弗所书 4:11–13"> 我们向所有人讲述他，用我们知道的最佳方法指导和教导他们，让上帝面前的每个人都因基督而彻底圆满。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 15:10; 以弗所书 1:19; 哥林多前书 9:25–27"> 这也是我竭尽全力工作的目的。通过上帝的力量，这力量也对我产生了强大的影响，我依赖这力量。</span>
</div>

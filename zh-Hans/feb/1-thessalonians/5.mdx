<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 1:7; 帖撒罗尼迦前书 4:9; 马太福音 24:36"> 兄弟姐妹们，关于预言的时间和日期，我们无需用文字累述。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 16:15; 彼得后书 3:10; 马太福音 24:42–44"> 因为你们很清楚，主的那一天必会到来，但会在一个意外的时间到来，就像夜晚出现盗贼一样让人意外。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 21:34–35; 马太福音 24:37–39; 路加福音 17:26–30"> 那时候，人们还在谈论和平和安全，忽然就会彻底毁灭，就像婴儿忽然出生，他们不会逃脱。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰一书 2:8; 彼得后书 3:10; Deuteronomy 19:6"> 但是你们，各位兄弟姐妹们，你们对之并非毫不知情，所以当审判日<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原意为“白天。”">a</a></sup>如贼一样忽然来临时，你们不会感到惊诧。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 5:8; 使徒行传 26:18; 约翰福音 12:36"> 因为你们都是光明之子，白昼之子；我们不是属于黑夜或黑暗。</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前书 1:13; 马太福音 24:42; 路加福音 22:46"> 所以，我们不能像其他人一样沉睡，我们应该保持清醒，头脑清晰。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 13:13; 哥林多前书 15:34; 彼得后书 2:13"> 因为人会在夜晚睡觉，在夜晚喝醉；</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 13:12–13; 以弗所书 6:11; 彼得前书 1:13"> 但我们属于白昼，所以应该保持头脑清醒。我们要披上信与爱的胸甲，戴上救赎希望的头盔。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦前书 1:10; 彼得前书 2:10; 提摩太后书 2:10"> 因为上帝并未决定要惩罚我们，而是通过我们的主耶稣基督，通过救赎拯救我们。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 14:8–9; 彼得前书 3:18; 罗马书 8:34"> 基督为<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“为了”在这里的意思没有“代替”的意思。">b</a></sup>我们而死，让我们无论或者还是死去，都能与他一起活着。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 4:29; 希伯来书 10:25; 罗马书 15:2"> 所以要彼此鼓励，赋予力量，正如你们一直在做的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="希伯来书 13:17; 希伯来书 13:7; 提摩太前书 5:17–18"> 兄弟姐妹们，请你们尊重那些与你们一起工作的人，他们引领你们走向主并教导你们。</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 9:50; 希伯来书 12:14; 加拉太书 6:6"> 因为他们所做的事情，你们要用爱格外尊重他们。应当彼此和睦地生活在一起。</span>
<span className="v" id="v14" data-v="14" data-xref="提摩太后书 4:2; 罗马书 14:1; 使徒行传 20:35"> 兄弟姐妹们，奉劝你们要警戒懒惰之人，要去勉励焦虑之人，帮助软弱之人，耐心对待每个人。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 3:9; 加拉太书 6:10; Leviticus 19:18"> 任何人都不能以恶报恶，而是要始终对彼此、对所有其他人做善事。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 12:12; 腓立比书 4:4; 马太福音 5:12"> 始终要保持欢喜，</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 12:12; 歌罗西书 4:2; 以弗所书 6:18"> 不要停止祷告，</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 5:20; 腓立比书 4:6; 歌罗西书 3:17"> 凡事都要心存感激，因为这是上帝通过基督耶稣给你们的旨意。</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所书 4:30; 使徒行传 7:51; 提摩太后书 1:6"> 不要遏制灵，</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 14:3–6; 哥林多前书 14:1; Numbers 11:25–29"> 不要藐视先知之语。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 4:1; 罗马书 12:2; 以弗所书 5:10"> 凡事都要仔细查验，坚守好事，</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多后书 6:3; 腓立比书 4:8; 哥林多前书 10:31–33"> 远离所有恶行。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="犹大书 1:24; 希伯来书 4:12; 哥林多前书 1:8–9"> 愿赐予平安的上帝让你们真正圣洁，愿主耶稣基督再次来临时，你们整个人——包括身体、精神和灵都无可指责。</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦后书 3:3; Numbers 23:19; 哥林多前书 1:9"> 那召唤你们的是值得信任的，他必会这样做。</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 13:18–19; 腓立比书 1:19; 腓利门书 1:22"> 兄弟姐妹们，请为我们祷告。</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 16:16; 哥林多前书 16:20"> 热情地问候那边的所有信徒。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“用圣洁的吻。”">c</a></sup></span>
<span className="v" id="v27" data-v="27" data-xref="歌罗西书 4:16; 使徒行传 19:13; 提摩太前书 1:3"> 我以主为名，请你们向所有信徒阅读这封信。</span>
<span className="v" id="v28" data-v="28" data-xref="罗马书 16:20; 帖撒罗尼迦后书 3:18; 罗马书 16:23"> 愿我们主耶稣基督的恩典与你们同在。</span>
</div>

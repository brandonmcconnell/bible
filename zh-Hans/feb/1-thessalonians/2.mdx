<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦后书 3:1; 哥林多前书 15:2; 哥林多前书 15:58"> 兄弟姐妹们，你们都知道，我们的造访对你们意味着什么，那并不是浪费时间。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 16:22–24; 使徒行传 4:13; 使徒行传 17:2–9"> 你们应该记得，虽然我们在腓立比受了那么多苦和凌辱，面对强烈的反对，我们仍然通过上帝的帮助，与你们分享上帝的福音。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 2:17; 哥林多后书 4:2; 帖撒罗尼迦前书 4:7"> 因为我们所说的并非欺骗，不是污秽或诡诈。</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 1:10; 罗马书 8:27; 加拉太书 2:7"> 相反，我们所说的一切都获得了上帝的批准，他把福音委托给我们。我们的目的不是取悦人，而是取悦上帝，他在评判我们的动机。</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 1:9; 哥林多后书 12:17; 使徒行传 20:33"> 你们知道，我们从来不说奉承之语，也从不会故起贪婪自私之心，上帝可以作证。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 1:10; 帖撒罗尼迦前书 2:9; 约翰福音 5:41"> 我们并非想要赢得其他人的赞美，不是你们，也不是任何人。作为基督的使者，我们本来会成为你们的“负担。”</span>
<span className="v" id="v7" data-v="7" data-xref="Isaiah 66:13; 帖撒罗尼迦前书 2:11; 提摩太后书 2:24–25"> 但我们在你们中，我们却像母亲照顾自己的孩子一样善良行事。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰一书 3:16; 哥林多后书 12:15; 腓立比书 2:17"> 我们如此爱你们，不但原意把上帝的福音传给你们，甚至连我们自己也乐意给你们，因为我们爱你们。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦后书 3:7–9; 哥林多后书 11:9; 使徒行传 18:3"> 兄弟姐妹们，别忘记我们所有的辛劳，日夜不停地工作，就是为了在与你们分享上帝的福音时，不会成为你们的负担。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前书 5:3; 帖撒罗尼迦前书 1:5; 哥林多后书 1:12"> 我们以公正、无可指责的圣洁态度对待你们，我们的行为你们可以佐证，上帝也可以作证。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 4:14–15; 希伯来书 13:22; 提摩太前书 5:21"> 你们知道我们如何关爱你们所有人，就像父亲对待儿女一样。我们鼓励你们、安慰你们、分享我们的经历，</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 4:1; 约翰一书 2:6; 约翰一书 1:6–7"> 让你们可以像上帝希望的那样生活，这上帝召唤你们走进他的王国和荣耀。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 4:12; 罗马书 10:17; 彼得前书 1:23"> 此外：我们一直在感谢上帝，当你们听到并接受上帝之道，你们没有把它们当做人类之道，而是真正的上帝之道。相信上帝，就会产生这样的效果。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 3:4; 希伯来书 10:33–34; 希伯来书 5:7–8"> 兄弟姐妹们，你们的经历就像位于犹太地的上帝教会一样，这些教会属于耶稣基督。就像你们的犹太基督徒教友一样，他们遭受犹太领袖的迫害，</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 5:12; 路加福音 11:48–53; 使徒行传 7:52"> 那些领袖杀了耶稣和众先知，又把我们赶出来。他们得不到上帝的喜悦，与所有的人作对，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 17:13; 使徒行传 14:19; 马可福音 16:16"> 试图阻挠我们向其他国家<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“异族人。”">a</a></sup>传道，不让他们得救。他们始终充满最大的恶，但所有的审判必将降临到他们身上。</span>
<span className="v" id="v17" data-v="17" data-xref="歌罗西书 2:5; 哥林多前书 5:3; 帖撒罗尼迦前书 3:6"> 兄弟姐妹们，因为有一段时间没有见到你们，我们感觉好像经历了一次与家人的离别，但这离别只是身体离开，而不是精神。我们非常渴望再次亲自见到你们，这就是我们想要做的。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 15:22; 罗马书 1:13; 启示录 2:10"> 我们非常想造访你们，我保罗试过很多次，只是撒旦阻挡了我们。</span>
<span className="v" id="v19" data-v="19" data-xref="腓立比书 4:1; 帖撒罗尼迦前书 3:13; 腓立比书 2:16"> 但正是你们给了我们希望，让我们感到幸福，当主耶稣再次降临，当我们站在他面前，我们会因你们而感到骄傲！</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 1:14; 哥林多前书 11:7; Proverbs 17:6"> 你们就是我们的荣耀和欢喜！</span>

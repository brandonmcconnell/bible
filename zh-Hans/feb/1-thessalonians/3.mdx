<span className="v" id="v2" data-v="2" data-xref="使徒行传 14:22–23; 以弗所书 6:21–22; 腓立比书 2:19–25"> 派我们的兄弟提摩太去，这对我们最好了。在传递耶稣福音时，他是我们的兄弟，与上帝一起工作。我们把他派过去，是为了让你们更坚定地相信上帝，给你们勇气，</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 14:22; 罗马书 5:3; 使徒行传 9:16"> 让你们任何人都不会因困难而沮丧。你们应该知道，这困难是预料之中的。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 2:14; 哥林多后书 8:1–2; 帖撒罗尼迦前书 2:2"> 即使与你们在一起的时候，我们就一直在警告，我们将会遭受困难。你们也知道，事实的确如此。</span>
<span className="v" id="v5" data-v="5" data-xref="雅各书 1:13–14; 马太福音 4:3; 哥林多后书 2:11"> 这就是为什么当我无法在忍受时，就派人去看看你们是否仍然信上帝。我担心魔鬼<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“魔鬼”，原意为“诱惑者。”">a</a></sup>成功地诱惑了你们，导致我们的努力都白费了！<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“成功地诱惑”——原文的本意只是“试探”，但在英语中，这并不意味保罗的恐惧，即诱惑已经成功。这里的问题不是被诱惑，而是因为诱惑而犯下罪行。">b</a></sup></span>

<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 11:2; Isaiah 52:7; Proverbs 25:25"> 造访你们的提摩太刚刚返回，带给你们对上帝的信和你们的爱告诉我们，这是一个好消息。他还告诉我们，你们仍然会想起我们，希望见到我们，就像我们想见你们一样。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 1:4; 约翰二书 1:4; 帖撒罗尼迦前书 3:8–9"> 兄弟姐妹们，当我们在经历苦痛时，得知你们仍然坚持对上帝的信，这消息真正地鼓励了我们。</span>
<span className="v" id="v8" data-v="8" data-xref="歌罗西书 1:23; 哥林多前书 16:13; 启示录 3:11"> 因为你们坚定地与主站在一起，对我们而言就值得继续活下去。</span>
<span className="v" id="v9" data-v="9" data-xref="Psalms 71:14–15; Psalms 96:12–13; 哥林多后书 9:15"> 你们给我们带来了快乐，当我们来到上帝面前，我们怎么能不为此感谢上帝呢？</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 13:9; 帖撒罗尼迦前书 3:11; 腓立比书 1:25"> 我们热切地日夜祈求，希望能再次与你们见面，帮助你们继续培养对上帝的信。</span>
<span className="v" id="v11" data-v="11" data-xref="Proverbs 3:5–6; 马太福音 6:32; 帖撒罗尼迦后书 2:16"> 愿我们的父上帝和我们的主耶稣，能让我们可以尽快到你们那里去。</span>
<span className="v" id="v12" data-v="12" data-xref="腓立比书 1:9; 约翰一书 4:7–16; 马太福音 22:39"> 愿主增加你们的爱，让这爱可以溢出并彼此流淌，流淌到每个人那里，就像我们爱你们一样。</span>
<span className="v" id="v13" data-v="13" data-xref="歌罗西书 1:22; 帖撒罗尼迦前书 5:23; 以弗所书 5:27"> 通过这种方式，愿耶稣让你们坚定。在我们主耶稣和众圣徒到来的时候，你们能站在我们的父上帝面前，完全圣洁，无可指责。</span>

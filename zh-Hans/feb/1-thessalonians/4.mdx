<span className="v" id="v1" data-v="1" data-xref="歌罗西书 1:10; 帖撒罗尼迦后书 1:3; 彼得后书 3:18"> 还有几件事：兄弟姐妹们，我们以主耶稣之名请求你们，就像我们所告诉你们的那样，以让上帝喜悦的方式行事。当然了你们已经这样做，只是要做得更多！</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 28:20; Ezekiel 3:17; 帖撒罗尼迦后书 3:10"> 我们以主耶稣之名传递的指示，你们要记住。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得前书 4:2; 罗马书 12:2; 帖撒罗尼迦前书 5:23"> 上帝的旨意是要你们以圣洁方式生活；远离不道德的淫欲，</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 7:9; 罗马书 12:1; 希伯来书 13:4"> 每个人都能以圣洁尊重的方式控制自己<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这也可以翻译成“知道如何娶妻。”">a</a></sup>；</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 4:8; 使徒行传 17:30–31; 以弗所书 4:17–19"> 不要像那些不认识上帝的异族人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“异族人”、“其他国家。”">b</a></sup>一样放纵欲望；</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 13:4; Exodus 20:17; 罗马书 12:19"> 在这些事情上，不要欺骗或利用其他基督徒。因为主在这样的事情上必会施以正义，我们已经清晰地向你们解释并警告过你们。</span>
<span className="v" id="v7" data-v="7" data-xref="Leviticus 11:44; 以弗所书 1:4; 彼得前书 2:9–12"> 上帝召唤我们，并非是让我们的生命玷污，而是要我们圣洁。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰一书 3:24; 路加福音 10:16; 约翰福音 12:48"> 所以拒绝这命令的人，并不是拒绝其他人嘞所说的，而是在拒绝将其圣灵赐给你们的上帝。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰一书 3:11; 罗马书 12:10; 约翰一书 3:23"> 关于爱其他的信徒，我们无需再写什么，因为上帝已经教你们如何彼此相爱。</span>
<span className="v" id="v10" data-v="10" data-xref="腓立比书 1:9; 帖撒罗尼迦前书 3:12; 帖撒罗尼迦后书 1:3"> 事实上，你们已经向全马其顿所有的信徒展示了这种爱。尽管如此，我们仍要鼓励各位兄弟姐妹们，要更加彼此相爱；</span>
<span className="v" id="v11" data-v="11" data-xref="Ecclesiastes 4:6; 以弗所书 4:28; 彼得前书 3:4"> 要试图过着安静的生活，关注自己的事情，亲手做自己的工作，正如我们之前解释过的。</span>
<span className="v" id="v12" data-v="12" data-xref="歌罗西书 4:5; 彼得前书 2:12; 罗马书 12:17"> 只有这样，你们的生活方式才可能受到非基督徒的尊重，你们不用以来其他人来提供你们所需。</span>
<span className="v" id="v13" data-v="13" data-xref="Daniel 12:2; 帖撒罗尼迦前书 4:15; 帖撒罗尼迦前书 5:10"> 兄弟姐妹们，关于人们死去后发生什么，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="原意为“睡着”">c</a></sup>我们不想让你们感到困扰，所以你们不用向其他没有希望的人那样感到悲伤。</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 8:11; 腓立比书 3:20–21; Isaiah 26:19"> 因为我们确信，耶稣死后又复活，我们也确信上帝会通过耶稣，带来<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="从后面两段话来看，“带来那些...” 很显然是从地球上复活之人。">d</a></sup>那些已死的信他之人。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 15:51–53; 哥林多后书 4:14; 帖撒罗尼迦前书 2:19"> 我们现在所讲的一切都来自主：我们这些还活着、仍然留在这里等待主来临的人，肯定不会站在已死之人的前面。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 15:51–52; 启示录 1:7; 马太福音 24:30–31"> 因为主必亲自从天堂降临，发出号令，伴随天使长的呼叫，还有上帝号角的声音，那些因相信基督而死之人必先复活；</span>
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 15:52; 启示录 11:12; 约翰福音 14:3"> 我们这些还活着、还留在这里的人，将与他们一起被提升到云中，在空中与主相会。这样，我们就能永远与主同在。</span>
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 5:11; 路加福音 21:28; 帖撒罗尼迦前书 5:14"> 所以，就用这些话互相鼓励吧。</span>
</div>

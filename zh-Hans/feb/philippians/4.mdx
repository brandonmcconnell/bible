<span className="v" id="v1" data-v="1" data-xref="腓立比书 1:27; 哥林多前书 16:13; Psalms 27:14"> 我亲爱的朋友们，你们对我很重要，让我如此快乐，所以我们坚定不移地与主同在！对我来说，你们就是我最高的成就！我真的很爱你们，很想见到你们！</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 12:14; 哥林多前书 1:10; 马可福音 9:50"> 尤迪亚和顺都基——建议你们解决彼此之间的分歧，在主面前达成一致。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 3:5; 启示录 13:8; 路加福音 10:20"> 事实上，我忠实的同事们，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一位不知名的基督徒，可能生活在腓立比。">a</a></sup>请你们帮助这些妇女，因为她们都在与我一起传播福音——还有克莱门特和我的其他同事，她们的名字就记录在生活之中。</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 5:16–18; 罗马书 12:12; 雅各书 1:2–4"> 永远因与主同在而感到快乐——再说一遍，要感到快乐！</span>
<span className="v" id="v5" data-v="5" data-xref="雅各书 5:8–9; 马太福音 6:25; 提多书 3:2"> 每个人都应该知道你们的好意。主很快就会降临。</span>
<span className="v" id="v6" data-v="6" data-xref="Proverbs 3:5–6; 彼得前书 5:7; 马太福音 6:25–33"> 不要担心任何事情，要在祈祷中将一切交给上帝，向他解释你的需求，感谢他所做的一切。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 14:27; Isaiah 26:3; 帖撒罗尼迦后书 3:16"> 那时候，就会获得超过你想象、上帝带给你的平安，保护你以正确的思想和态度与基督耶稣同在。</span>
<span className="v" id="v8" data-v="8" data-xref="雅各书 3:17; 提多书 2:7; 罗马书 12:9–21"> 最后，要去想那些真实的、尊贵的、正确的、纯洁的、美丽的、值得称道的事情，真正好的、值得表扬的事情。</span>
<span className="v" id="v9" data-v="9" data-xref="雅各书 1:22; 腓立比书 3:17; 帖撒罗尼迦前书 4:1–8"> 践行从我这里学到的一切，践行从我这里得到的一切，践行你看到我做的一切，践行听到我说的一切。届时，赐予平安的上帝会与你同在。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 11:9; 加拉太书 6:6; 哥林多后书 7:6–7"> 感谢主，真高兴你们终于想起我了——我知道你们以前曾经很关心我，但对此却无法提供帮助。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 6:6–9; 希伯来书 13:5–6; 马太福音 6:31–34"> 我并非在谈论我自己的需求，因为我已经学会了在任何情况下都要让自己感到满足。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 11:29; 哥林多后书 12:7–10; 哥林多后书 11:27"> 我习惯了一无所有，也曾拥有很多。在每一种可能的情况下，我都学会了如何面对富足和饥饿。对于富有和贫困的生活，我有一个秘诀：</span>
<span className="v" id="v13" data-v="13" data-xref="Isaiah 41:10; 哥林多后书 12:9–10; 歌罗西书 1:11"> 凭借那让我坚强之人，我无所不能！</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 13:16; 腓立比书 1:7; 希伯来书 10:34"> 即便如此，在我遇到麻烦的时候，很高兴你们能与我分享事。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比书 1:5; 哥林多后书 11:8–12; 使徒行传 16:40–5"> 腓立比人请记住，在我开始分享福音时，当我离开马其顿时，你们是唯一为我提供经济帮助的教会。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦前书 2:9; 使徒行传 17:1; 帖撒罗尼迦前书 2:18"> 我在帖撒罗尼迦的时候，你们也曾帮助过我两次。</span>
<span className="v" id="v17" data-v="17" data-xref="提多书 3:14; 希伯来书 6:10; 哥林多后书 9:9–13"> 我并非在寻找捐赠，而是为你们的“账户”增加“利润。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="保罗使用了一个商业术语，可能象征性地指其灵的“账户。”">b</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 13:16; 腓立比书 4:12; 哥林多后书 9:12"> 因为我所拥有的远超过自己需要的。很感激以巴弗提寄来的东西。它们就像是取悦上帝并获得其认可、散发扑鼻香气的祭品。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多后书 9:8–11; Psalms 84:11; 彼得前书 5:10"> 上帝的荣耀财富就在耶稣基督之中，用你们需要的一切来满足你们！</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 11:36; Psalms 115:1; 启示录 14:7"> 荣耀归于我父上帝，直至永远。阿门。</span>
<span className="v" id="v21" data-v="21" data-xref="加拉太书 1:2; 腓利门书 1:23–24; 歌罗西书 4:10–14"> 问候每一位与基督耶稣同在的信徒。与我同在的耶稣基督的兄弟姐妹向你们问好。</span>
<span className="v" id="v22" data-v="22" data-xref="腓立比书 1:13; 哥林多后书 13:13; 罗马书 16:16"> 所有的信徒都向你们问好，尤其是凯撒宫里的人们。</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 13:14; 罗马书 16:20; 罗马书 16:23"> 愿主耶稣基督的恩典与你们的灵同在。</span>

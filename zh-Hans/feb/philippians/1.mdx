<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 1:1; 使徒行传 16:12–15; 罗马书 1:1"> 这封信来自基督耶稣的仆人保罗和提摩太，写给住在腓立比、所有与基督耶稣在一起的上帝子民，同时也写给所有的教会领袖和助手。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 1:7; 哥林多后书 1:2; 彼得前书 1:2"> 愿我们的父上帝和主耶稣基督赐予你们恩典和平安。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 1:4; 帖撒罗尼迦前书 1:2–3; 腓利门书 1:4–5"> 当我想起你们，就会感谢我的上帝，</span>
<span className="v" id="v4" data-v="4" data-xref="帖撒罗尼迦前书 1:2; 罗马书 1:9; 约翰二书 1:4"> 总是很高兴地在祈祷中记住你们所有人，</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 4:14–15; 腓立比书 1:7; 希伯来书 3:14"> 因为自始至终，你们都在我一起传播福音。</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦前书 5:23–24; 腓立比书 2:13; 以弗所书 4:12"> 我非常相信，你们会继续努力工作，实现成功的结果，直到耶稣基督再次到来。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 7:3; 腓立比书 1:5; 歌罗西书 4:18"> 我以这种方式思考你们所有人恰如其分，因为你们对我来说意义重大。无论在监狱里还是在外面宣讲福音，你们都与我一起分享上帝的恩典。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比书 4:1; 罗马书 1:9; 提摩太后书 1:4"> 上帝是我的见证，见证我领受基督耶稣的关怀并对你们每一个人保持的深情。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦前书 3:12; 歌罗西书 1:9; 彼得后书 1:5–6"> 我祈祷你们会越来越热爱知识，更加深刻地理解，</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 12:2; 帖撒罗尼迦前书 3:13; 帖撒罗尼迦前书 5:23"> 这样就能弄清楚什么才是真正重要的。当基督再来时，你们就可以做到真诚无瑕，</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 12:11; 约翰福音 15:8; 约翰福音 15:4–5"> 通过耶稣基督让生命之果充满正直良善，将荣耀和赞美归于上帝。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="提摩太后书 2:9; 罗马书 8:28; 使徒行传 11:19–21"> 我的兄弟姐妹们，我想让你们知道，我所经历的一切，都是在推动福音向前发展！</span>
<span className="v" id="v13" data-v="13" data-xref="提摩太后书 2:9; 以弗所书 3:1; 腓立比书 1:7"> 所有人——包括所有禁卫军<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="罗马皇帝的护卫。">a</a></sup>——现在都知道我为了基督而被锁链束缚；</span>
<span className="v" id="v14" data-v="14" data-xref="以弗所书 6:19–20; 帖撒罗尼迦前书 2:2; 路加福音 1:74"> 因为我被锁链束缚，这里的大多数基督徒都获得鼓励, 勇敢无畏地说出上帝的话语！</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 16:17–18; 腓立比书 2:3; 哥林多后书 11:13"> 是的，有些人说话是出于嫉妒和竞争。但有些人说话却秉承良好的动机。</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 2:17; 哥林多后书 4:1–2; Psalms 69:26"> 他们的行为是出于爱，因为他们知道，我来此是为了给福音辩护。</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太后书 1:11–12; 腓立比书 2:3; 腓立比书 1:7"> 那些人因为自私的野心而使用欺骗性的方式介绍基督，试图为处于监禁中的我制造麻烦。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 9:50; 马可福音 9:38–40; 哥林多前书 15:11"> 那又怎样？我关心的就是基督以何种方式出现，无论来自假装还是真实的信念。这就是让我快乐的原因——我会继续快乐！</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 8:28; 使徒行传 16:7; 哥林多后书 1:11"> 为什么？因为我深信，通过你们为我祈祷，通过耶稣基督之灵的帮助，这将成为我的救赎。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="保罗所指可能是从他现有的情况中获得救赎或最终的救赎，也可能指代两者。">b</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="彼得前书 4:16; 哥林多前书 6:20; Isaiah 54:4"> 因为我最大的希望和期待，就是不要做任何让我会感到羞耻的事情。相反，我会一如既往地大胆盼望，即使是现在也是如此，无论我是生是死，基督都会通过我实现极大荣耀。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="加拉太书 2:20; 哥林多后书 5:8; 哥林多后书 5:1"> 对我而言，活着是为基督而死，死了才会有收获。</span>
<span className="v" id="v22" data-v="22" data-xref="彼得前书 4:2; 加拉太书 2:20; 腓立比书 1:24"> 但如果我继续住在这里，这将是一项富有成效的工作，那么我真的不知道什么才是最好的选择！</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 5:8; Psalms 17:15; 启示录 14:13"> 因为我处于两难境地——我真的想离开并与基督在一起，这会好得多，</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 16:7; 腓立比书 1:22; 腓立比书 1:25–26"> 就你而言，仍然留在这里更重要。</span>
<span className="v" id="v25" data-v="25" data-xref="腓立比书 2:24; 哥林多后书 1:24; 以弗所书 4:11–13"> 既然我已经很确认，知道自己会留在这里，随着你们越来越相信上帝并感到喜乐，我会留在你们身边帮助你们，</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多后书 1:14; 哥林多后书 5:12; 腓立比书 3:3"> 以便当我再次见到你们时，你们会更因为我的原因，赞美基督耶稣。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以弗所书 4:1; 哥林多前书 16:13–14; 哥林多前书 1:10"> 只要确保你的生活方式符合基督的福音，无论我是否去看你们，都能听到你们在做什么——我知道你们彼此完全一致，因相信福音而共同努力，精神上就实现了团结一致。</span>
<span className="v" id="v28" data-v="28" data-xref="提摩太后书 1:7–8; 帖撒罗尼迦后书 1:5–6; 马太福音 10:28"> 不要让敌人吓到你们。要勇敢地向他们证明，他们将会迷失，但上帝会亲自来拯救你们。</span>
<span className="v" id="v29" data-v="29" data-xref="雅各书 1:2; 彼得前书 4:13; 使徒行传 5:41"> 因为你们不仅拥有信耶稣的特权，也会为他受苦。</span>
<span className="v" id="v30" data-v="30" data-xref="帖撒罗尼迦前书 2:2; 使徒行传 16:19–40; 提摩太后书 4:7"> 你们正在经历的挣扎，就像你们所见我所经历的挣扎——你们现在也知道，我仍然在挣扎。</span>
</div>
</div>

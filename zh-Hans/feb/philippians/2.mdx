<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 3:12; 约翰一书 4:12; 约翰一书 4:7–8"> 那么，如果你们因基督而受到鼓励，如果你们因他的爱而获得安慰，如果你们分享灵，如果你们有同情心和怜悯心，</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 12:16; 彼得前书 3:8–9; 哥林多前书 1:10"> 那么就可以用同样的方式思考，以同样的方式相爱，精神上达成团结，追求一个共同的目标，让我的快乐变得完整。</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 12:10; 加拉太书 5:26; 以弗所书 5:21"> 不要出于自私或骄傲的原因去做事，要谦虚地为他人着想，而不是为自己着想。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 10:24; 罗马书 15:1; 雅各书 2:8"> 你们不应该只顾着自己的事情，还要为他人的利益着想。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰一书 2:6; 马太福音 11:29; 彼得前书 2:21"> 你们应该拥有和基督耶稣一样的态度。</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 5:18; 哥林多后书 4:4; 希伯来书 1:3"> 尽管他本来始终都是上帝，但他并不关注自己与上帝是否平等。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 8:9; 马太福音 20:28; 约翰福音 1:14"> 他清空<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这里说明耶稣选择“放空”自己，放下他的神圣力量。">a</a></sup>自己，保持仆人的本性，成为人。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 10:18; 希伯来书 12:2; 罗马书 5:19"> 他以人形来到，谦卑自己，将自己交给死亡——甚至死在十字架上。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 19:16; 马太福音 28:18; 彼得前书 3:22"> 这就是为什么上帝将他放在最尊贵、最有权力的地位，给他最尊贵的名字——</span>
<span className="v" id="v10" data-v="10" data-xref="Isaiah 45:23–25; 马太福音 28:18; 启示录 5:13–14"> 以便每个人都为耶稣之名而鞠躬，无论是在天上、地上或地底，</span>
<span className="v" id="v11" data-v="11" data-xref="约翰一书 4:15; 罗马书 14:11; 约翰福音 13:13"> 所有人都会宣告耶稣基督是主，以此荣耀父上帝。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得后书 1:5–10; 路加福音 13:23–24; 哥林多前书 15:58"> 所以我的好朋友们，继续以完全敬畏和尊重上帝的方式，朝着救赎的目标努力，按照告诉你的方式去做——不仅当我和你们在一起的时候如此，现在我离开你们更要如此。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 13:21; 哥林多后书 3:5; 提摩太后书 1:9"> 因为在你们心中是上帝在起作用，他带来意志和能力，让你们去做他想让你们做的事。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 4:9; 哥林多前书 10:10; 腓立比书 2:3"> 做每件事都不要抱怨或争论</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 5:14–16; 彼得前书 2:12; 马太福音 5:45"> 这样你们才会真诚，不会有任何错误。在过着不诚实和腐败生活的民众<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="见 申命记 32:5。">b</a></sup>中，成为上帝无可指责的孩子；在他们中间，像照亮世界的光一样闪耀，</span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 9:26; 加拉太书 2:2; 约翰一书 1:1"> 向他们传授生命之道。只有这样，当基督再次来到，我会就会有一些值得骄傲的事情，证明我没有白白四处奔波和操劳！</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太后书 4:6; 罗马书 15:16; 希伯来书 13:15–16"> 所以，即使我把自己的生命当作祭品和供品，只要能让你们信任上帝，我就会为此感到高兴。我和你们在一起很高兴，</span>
<span className="v" id="v18" data-v="18" data-xref="雅各书 1:2–4; 腓立比书 4:4; 腓立比书 3:1"> 就像你们有这样的欢喜，因为和我在一起而感到高兴。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 4:17; 帖撒罗尼迦前书 3:6–8; 帖撒罗尼迦前书 3:2"> 我希望，如果这是主耶稣的旨意，请尽快将提摩太派去见你们。只要我知道你们在做什么，我就会感到高兴。</span>
<span className="v" id="v20" data-v="20" data-xref="腓立比书 2:2; 哥林多前书 16:10; 腓立比书 2:22"> 我不知道有谁像他那样真正关心你们。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 10:24; 马太福音 16:24; 腓立比书 2:4"> 其他人只关心自己的利益，不关心耶稣基督的利益。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 4:17; 哥林多后书 2:9; 提摩太后书 1:2"> 但是你们已经知道他是谁了——就像一个孩子在帮助他的父亲，他和我一起工作来传播福音。</span>
<span className="v" id="v23" data-v="23" data-xref="1 Samuel 22:3; 腓立比书 2:19"> 我希望在了解自己的进展情况后，就立刻派他去。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰三书 1:14; 腓利门书 1:22; 腓立比书 1:25–26"> 我相信主，很快我也能去。</span>
<span className="v" id="v25" data-v="25" data-xref="腓立比书 4:18; 腓利门书 1:1–2; 腓立比书 4:3"> 但我认为把以巴弗提送到你们那边很重要。他是我的兄弟、同事和战友。他是你们派来照顾我的人，</span>
<span className="v" id="v26" data-v="26" data-xref="罗马书 12:15; Proverbs 12:25; 以弗所书 3:13"> 一直渴望见到你们。他担心你们，因为你们也听说了，他生病了。</span>
<span className="v" id="v27" data-v="27" data-xref="Psalms 34:19; 腓立比书 2:30; Psalms 103:3–4"> 他确实生病了——差点死去——但上帝怜悯他。不仅怜悯他，也怜悯我，这样我就不会不断发生各种悲剧。</span>
<span className="v" id="v28" data-v="28" data-xref="约翰福音 16:22; 提摩太后书 1:4; 腓立比书 2:26–27"> 正因如此，我才那么想派他去见你们。你们因为见到他而开心，我就不用那么心焦。</span>
<span className="v" id="v29" data-v="29" data-xref="帖撒罗尼迦前书 5:12; 哥林多前书 16:18; 提摩太前书 5:17"> 所以，请心怀主并以极大的幸福欢迎他——让他这样的人感到荣耀，</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前书 16:17; 使徒行传 20:24; 腓立比书 4:10"> 因为他在为基督工作时几乎失去声明，冒着生命危险来弥补你们无法给我提供的帮助。</span>

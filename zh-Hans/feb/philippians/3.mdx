<span className="v" id="v1" data-v="1" data-xref="罗马书 5:11; 腓立比书 4:4; 雅各书 1:2"> 总而言之：我亲爱的朋友们，以主为喜乐！向你重复这些话，对我来说不是负担，这是为了保护你的安全！</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 11:13; 提多书 1:16; 启示录 22:15"> 小心那些狗！警惕那些做坏事的人！小心那些切割身体之人！<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="保罗用这个贬义词指那些坚持身体割礼之人。他将之余灵性割礼进行对比，明确表示上帝的子民不再需要身体上的割礼。">a</a></sup></span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 2:11; Deuteronomy 30:6; 罗马书 7:6"> 因为我们真正行了割礼，我们借着神的灵敬拜, 将我们的信心寄托于耶稣基督。我们对人的能力没有信心<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原意为“肉体”，又见第 4 节。">b</a></sup>——</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多后书 11:18–22"> 如果有一种方法可以去依靠人性，我自己就可以获得这样的信心！如果有人认为，他们有信心可以拥有这样的人性，那么我就可以超越他们：</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 11:22; 罗马书 11:1; 使徒行传 23:6"> 我在第八天受了割礼，是便雅悯支派的以色列人，一个真正的希伯来人。在遵守律法方面，我是法利赛人；</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 1:13–14; 使徒行传 8:3; 使徒行传 26:9–10"> 说到宗教奉献，我曾是教会的破坏者；在依法行事上，我无可指责！</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 14:33; 马太福音 16:26; 马太福音 13:44–46"> 但无论我以何种方式获得任何好处，我都认为这是基督的损失。</span>
<span className="v" id="v8" data-v="8" data-xref="Jeremiah 9:23–24; 罗马书 8:18; 腓立比书 3:7"> 确实，我把一切都视为损失，它让我通过认识我主基督耶稣获得令人难以置信的益处。我会为了他而丢掉这一切，把它们视为垃圾，我通过这种方式才拥有基督。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 5:21; 哥林多前书 1:30; 加拉太书 2:16"> 我希望与他同在，并非因为我做了什么或律法所说的正确，而是通过相信基督而实现正直善良，通过对他的信任而被上帝视为正直善良。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 2:20; 罗马书 8:17; 彼得前书 4:1–2"> 我想真正了解他，以及他死而复生的能力——体验他的苦难，在他的死亡中变得像他一样，</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 20:35–36; 启示录 20:5; 使徒行传 23:6"> 好让我经历最终的复活！</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太前书 6:11–12; 彼得后书 1:5–8; Psalms 138:8"> 并不是说​我已经拥有一切，或者我已经很完美——但我奔跑的目的，是为赢得基督耶稣为我获得的一切。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:62; 希伯来书 12:1–2; 腓立比书 3:12"> 我的朋友们，我不认为我已经赢得，但这是我的一个目标：不顾身后发生什么，努力向前看。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 9:24; 彼得前书 5:10; 启示录 3:21"> 我奔向终点线，是为了赢得上帝通过基督耶稣邀请我进入天堂的奖品。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 7:17; 雅各书 1:4–5; Proverbs 2:3–6"> 灵性成熟的人应该这样想，如果你有什么不同的想法，上帝会向你展示这一点，</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 2:6; 启示录 3:3; 启示录 2:4–5"> 我们只需确保遵循所了解的一切即可。</span>
<span className="v" id="v17" data-v="17" data-xref="腓立比书 4:9; 哥林多前书 4:16; 彼得前书 5:3"> 我的朋友们，像其他人一样，按照我的榜样行事，注意我们的行为方式，因为你们需要以我们为榜样。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 4:17; Isaiah 8:11; 加拉太书 6:12"> 有些人因其生活方式而与基督的十字架为敌——正如我以前经常告诉你们的那样，在此我再重复一遍，尽管这让我非常痛苦，让我想要放声痛哭。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 16:18; 罗马书 8:5–7; 彼得后书 2:3"> 他们最终会完全迷失，这些人的“上帝”只是其肉体欲望，本事应该让他们感到羞耻的事情，他们却引以为豪。他们只考虑今世的事情。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 2:19; 歌罗西书 3:1–3; 哥林多后书 4:18–1"> 但我们的祖国是天堂，我们也在等待救世主——主耶稣基督，从那里降临。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 3:2; 歌罗西书 3:4; 哥林多前书 15:42–56"> 他会重新创造我们有缺陷的身体，让我们的身体像他那荣耀的身体一样，可以运用他那样掌控一切的力量。</span>

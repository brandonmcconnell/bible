<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 7:12; 约书亚记 7:10; 列王纪下 8:3–4"> 雅各见埃及有粮食，就对儿子们说：“你们为什么彼此相看呢？”</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 43:8; 创世记 45:9; 创世记 43:2"> 他说：“看哪，我听说埃及有粮食。你们下到那里去，从那里为我们买些来，使我们可以存活，不至于死亡。”</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 42:5; 创世记 42:13"> 于是约瑟的十个哥哥下去，要从埃及买粮。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 42:38; 创世记 43:29; 创世记 11:4"> 但雅各没有让约瑟的弟弟便雅悯和他的哥哥们同去；因为他说：“恐怕他遭遇灾祸。”</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 41:57; 使徒行传 7:11; 创世记 12:10"> 以色列的儿子们也在来买粮的人中前来，因为迦南地有饥荒。</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 3:9; 创世记 37:7–10; 创世记 41:40–41"> 当时约瑟治理那地；卖粮给那地众民的就是他。约瑟的哥哥们来了，脸伏于地，向他下拜。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 42:30; 创世记 42:14–17; 马太福音 15:23–26"> 约瑟看见他的哥哥们，就认出他们来，却装作陌生人，严厉地对他们说话。他对他们说：“你们从哪里来？”<br />他们说：“从迦南地来，要买食物。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="创世记 37:2; 约翰福音 20:14; 路加福音 24:16"> 约瑟认出他的哥哥们，他们却没有认出他。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 37:5–9; 出埃及记 32:35; 约书亚记 2:1"> 约瑟想起从前所做关于他们的那些梦，就对他们说：“你们是探子！你们来是要窥探这地的虚实。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 37:8; 撒母耳记上 26:17; 创世记 27:37"> 他们对他说：“不是的，我主；你的仆人们是来买食物的。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 42:19; 哥林多后书 6:4; 约翰福音 7:18"> 我们都是一个人的儿子；我们是诚实人。你的仆人们不是探子。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 他对他们说：“不，你们来就是要窥探这地的虚实！”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 37:30; 创世记 42:32; 创世记 44:20"> 他们说：“你的仆人们本是十二个兄弟，是迦南地同一个人的儿子；看哪，最小的如今和我们的父亲在一起，还有一个已经不在了。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 15:21–28; 约伯记 13:24; 创世记 42:9–11"> 约瑟对他们说：“事情正如我对你们说的：‘你们是探子！’</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 17:55; 耶利米书 5:7; 创世记 42:16"> 你们要这样受试验：我指着法老的性命起誓，除非你们最小的弟弟到这里来，否则你们不得从这里出去。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 42:11"> 你们中间派一个人去，把你们的弟弟带来；你们其余的人要被捆绑，好试验你们的话，看你们里面有没有真实；若不然，我指着法老的性命起誓，你们确实是探子。”</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 40:4; 希伯来书 12:10; 创世记 40:7"> 于是他把他们全都拘禁了三天。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="利未记 25:43; 尼希米记 5:15; 路加福音 18:2"> 到了第三天，约瑟对他们说：“你们这样做，就可以存活，因为我敬畏上帝。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 45:23; 以赛亚书 42:7; 创世记 40:3"> 如果你们是诚实人，就让你们的一个兄弟拘禁在你们被囚的地方；你们可以走，带着粮食去救你们家里的饥荒。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 44:23; 创世记 43:5; 创世记 42:34"> 你们要把最小的弟弟带到我这里来；这样，你们的话就可以得到证实，你们也不至于死。”<br />他们就这样做了。</span>
<span className="v" id="v21" data-v="21" data-xref="何西阿 5:15; 马可福音 9:43–45; 创世记 37:23–28"> 他们彼此说：“我们在弟弟的事上确实有罪；当他哀求我们的时候，我们看见他内心的痛苦，却不肯听。因此这苦难临到我们身上。”</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 24:22; 诗篇 9:12; 列王纪上 2:32"> 流便回答他们说：“我不是对你们说过：‘不可伤害那孩子而犯罪’吗？你们却不肯听。看哪，现在他的血也被追讨了。”</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多后书 5:20; 约翰福音 16:13–14"> 他们不知道约瑟听得懂他们的话；因为他们中间有传译的人。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 43:30; 犹大书 1:22–23; 希伯来书 4:15"> 约瑟转身离开他们，哭了。随后又回到他们那里，和他们说话；他从他们中间取出西缅，在他们眼前把他捆绑起来。</span>
<span className="v" id="v25" data-v="25" data-xref="彼得前书 3:9; 罗马书 12:17–21; 创世记 45:21"> 约瑟吩咐人把粮食装满他们的袋子，又把各人的银钱放回各人的口袋里，并给他们路上用的食物。事情就这样为他们办了。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 他们把粮食驮在驴上，就离开那里去了。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 4:24; 路加福音 2:7; 路加福音 10:34"> 到了住宿的地方，他们中有一个人打开口袋，要拿饲料喂驴，就看见自己的银钱；看哪，银钱在他的袋口。</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 45:7; 耶利米哀歌 3:37; 创世记 42:36"> 他对兄弟们说：“我的银钱退回来了！看哪，就在我的口袋里！”他们都心惊胆战，战战兢兢地彼此说：“上帝向我们做的这是什么事呢？”</span>
<span className="v" id="v29" data-v="29"> 他们来到迦南地，到了他们父亲雅各那里，把所遭遇的一切都告诉他，说：</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 42:7"> “那人，就是那地的主，严厉地对我们说话，把我们当作窥探那地的探子。</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 42:11"> 我们对他说：‘我们是诚实人，不是探子。</span>
<span className="v" id="v32" data-v="32"> 我们本是十二个兄弟，是我们父亲的儿子；有一个已经不在了，最小的如今和我们的父亲在迦南地。’</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 42:19–20; 创世记 42:15"> 那人，就是那地的主，对我们说：‘我要这样知道你们是诚实人：把你们的一个兄弟留在我这里，带着粮食去救你们家里的饥荒，你们就去吧。</span>
<span className="v" id="v34" data-v="34" data-xref="创世记 34:10; 创世记 34:21; 列王纪上 10:15"> 把你们最小的弟弟带到我这里来。这样我就知道你们不是探子，而是诚实人。于是我会把你们的兄弟交还给你们，你们也可以在这地做买卖。’”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="创世记 43:21; 创世记 43:12; 创世记 43:15"> 后来他们倒空口袋；看哪，各人的银钱包都在自己的口袋里。他们和父亲看见各人的银钱包，就害怕。</span>
<span className="v" id="v36" data-v="36" data-xref="创世记 43:14; 罗马书 8:31; 以赛亚书 27:9"> 他们的父亲雅各对他们说：“你们使我失去儿子！约瑟不在了，西缅不在了，你们又要把便雅悯带走。这一切都与我作对。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="创世记 46:9; 弥迦书 6:7; 创世记 43:9"> 流便对他父亲说：“如果我不把他带回到你这里，你可以杀我的两个儿子。你把他交在我手里，我必把他带回到你这里。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="创世记 37:35; 创世记 42:4; 创世记 37:33"> 他说：“我的儿子不可和你们下去；因为他的哥哥已经死了，只剩下他一个。如果他在你们所走的路上遭遇灾祸，你们就使我白发苍苍、悲悲惨惨地下到阴间。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="阴间是死人的所在。">a</a></sup></span>
</div>
</div>

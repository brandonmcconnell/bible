<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 22:17; 历代志上 1:35; 申命记 23:7"> 这是以扫（就是以东）后代的记载。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 36:25; 创世记 28:9; 创世记 9:25"> 以扫从迦南的女子中娶妻：就是赫人以伦的女儿亚大，希未人祭便的孙女、亚拿的女儿阿何利巴玛，</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 28:9; 创世记 25:13"> 又娶了以实玛利的女儿、尼拜约的妹妹巴实抹。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 1:35; 出埃及记 2:18; 约伯记 2:11"> 亚大给以扫生了以利法；巴实抹生了流珥；</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 35:29"> 阿何利巴玛生了耶乌施、雅兰和可拉。这些是以扫的儿子，是在迦南地给他生的。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 32:3; 创世记 12:5; 创世记 17:8"> 以扫带着他的妻子、儿子、女儿和家中所有的人口，以及他的牲畜、所有的动物和一切财产，就是他在迦南地所积聚的，往别地去，离开了他的兄弟雅各。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 13:6; 创世记 17:8; 创世记 28:4"> 因为他们的财物太多，不能住在一起；他们寄居的地容不下他们，因为他们的牲畜太多。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 32:3; 玛拉基书 1:3; 以西结 35:2–7"> 以扫住在西珥山地。以扫就是以东。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 19:37"> 这是以东人的祖先以扫在西珥山地后代的记载：</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 36:3–4; 历代志上 1:35–54"> 以下是以扫儿子的名字：以扫妻子亚大的儿子以利法，和以扫妻子巴实抹的儿子流珥。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 36:15–16; 历代志上 1:35–36"> 以利法的儿子是提幔、阿抹、洗玻、迦坦和基纳斯。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 17:8–16; 申命记 25:17–19; 撒母耳记上 15:2–9"> 亭纳是以扫儿子以利法的妾；她给以利法生了亚玛力。这些是以扫妻子亚大的后裔。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 1:37; 创世记 36:17"> 以下是流珥的儿子：拿哈、谢拉、沙玛和米撒。这些是以扫妻子巴实抹的后裔。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 36:2; 创世记 36:18; 历代志上 1:35"> 以下是以扫妻子阿何利巴玛的儿子；阿何利巴玛是祭便的孙女、亚拿的女儿。她给以扫生了耶乌施、雅兰和可拉。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="俄巴底亚 1:9; 约伯记 2:11; 创世记 36:11–12"> 以下是以扫子孙中的族长：以扫长子以利法的子孙中，有提幔族长、阿抹族长、洗玻族长、基纳斯族长、</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 15:15"> 可拉族长、迦坦族长、亚玛力族长。这些是在以东地从以利法出来的族长；他们都是亚大的子孙。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 36:13; 历代志上 1:37; 创世记 36:4"> 以下是以扫儿子流珥的子孙：拿哈族长、谢拉族长、沙玛族长、米撒族长。这些是在以东地从流珥出来的族长；他们都是以扫妻子巴实抹的子孙。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 36:14; 历代志上 1:35; 创世记 36:5"> 以下是以扫妻子阿何利巴玛的子孙：耶乌施族长、雅兰族长、可拉族长。这些是从以扫妻子、亚拿的女儿阿何利巴玛出来的族长。</span>
<span className="v" id="v19" data-v="19"> 这些是以扫（就是以东）的子孙，这些是他们的族长。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命记 2:12; 申命记 2:22; 创世记 14:6"> 以下是那地居民何利人西珥的子孙：罗坍、朔巴、祭便、亚拿、</span>
<span className="v" id="v21" data-v="21"> 底顺、以察和底珊。这些是在以东地从西珥子孙何利人出来的族长。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 1:39"> 罗坍的儿女是何利和希幔；罗坍的妹妹是亭纳。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 1:40"> 以下是朔巴的儿女：亚勒文、玛拿辖、以巴录、示玻和阿南。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 2:10; 撒母耳记下 18:9; 列王纪上 4:28"> 以下是祭便的儿女：亚雅和亚拿。这亚拿在旷野放他父亲祭便的驴时，发现了温泉。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 36:2; 创世记 36:18; 历代志上 1:41"> 以下是亚拿的儿女：底顺和亚拿的女儿阿何利巴玛。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志上 1:41"> 以下是底顺的儿女：欣但、伊是班、益兰和基兰。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志上 1:42; 创世记 36:21; 历代志上 1:38"> 以下是以察的儿女：辟罕、撒番和亚干。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米哀歌 4:21; 约伯记 1:1; 耶利米书 25:20"> 以下是底珊的儿女：乌斯和亚兰。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 36:20; 创世记 36:28; 历代志上 1:41–42"> 以下是从何利人出来的族长：罗坍族长、朔巴族长、祭便族长、亚拿族长、</span>
<span className="v" id="v30" data-v="30" data-xref="但以理 7:23; 以赛亚书 23:15; 列王纪下 11:19"> 底顺族长、以察族长和底珊族长。这些是在西珥地按他们族长所列，从何利人出来的族长。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="创世记 17:6; 历代志上 1:43–50; 创世记 17:16"> 以色列人还没有君王治理以前，在以东地作王的是以下这些人。</span>
<span className="v" id="v32" data-v="32"> 比珥的儿子比拉在以东作王；他的城名叫亭哈巴。</span>
<span className="v" id="v33" data-v="33" data-xref="耶利米书 49:13; 耶利米书 49:22; 阿摩司 1:12"> 比拉死了，波斯拉人谢拉的儿子约巴接替他作王。</span>
<span className="v" id="v34" data-v="34" data-xref="创世记 36:11; 约伯记 2:11; 创世记 36:15"> 约巴死了，提幔人之地的户珊接替他作王。</span>
<span className="v" id="v35" data-v="35"> 户珊死了，比达的儿子哈达接替他作王；这哈达曾在摩押田野击败米甸。他的城名叫亚未得。</span>
<span className="v" id="v36" data-v="36" data-xref="历代志上 1:47"> 哈达死了，玛士利加人桑拉接替他作王。</span>
<span className="v" id="v37" data-v="37" data-xref="历代志上 1:48; 创世记 10:11"> 桑拉死了，大河边的利河伯人扫罗接替他作王。</span>
<span className="v" id="v38" data-v="38"> 扫罗死了，亚革波的儿子巴勒·哈南接替他作王。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及记 15:15; 历代志上 1:50"> 亚革波的儿子巴勒·哈南死了，哈达接替他作王。他的城名叫巴乌；他的妻子名叫米希她别，是玛特列的女儿，米萨合的孙女。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="历代志上 1:51–54; 出埃及记 15:15; 创世记 36:31"> 以下是从以扫出来的族长的名字，按他们的家族、地方和名字排列：亭纳族长、亚勒瓦族长、耶帖族长、</span>
<span className="v" id="v41" data-v="41"> 阿何利巴玛族长、以拉族长、比嫩族长、</span>
<span className="v" id="v42" data-v="42"> 基纳斯族长、提幔族长、米比萨族长、</span>
<span className="v" id="v43" data-v="43" data-xref="创世记 45:8; 历代志上 4:14; 创世记 25:30"> 玛基叠族长和以兰族长。这些是以东的族长，按他们在所得之地的住处排列。这就是以东人的祖先以扫。</span>
</div>

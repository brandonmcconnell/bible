<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 112:1–3; 加拉太书 3:9; 马太福音 6:33"> 亚伯拉罕年纪老迈，岁数很大。耶和华在一切事上都赐福给亚伯拉罕。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 47:29; 创世记 39:4–6; 创世记 15:2"> 亚伯拉罕对他家中最年长、管理他一切所有的仆人说：“请你把手放在我的大腿下。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 6:14–17; 创世记 26:34–35; 创世记 28:8"> 我要叫你指着耶和华，就是天上的上帝、地上的上帝起誓：你不可从我所住之地的迦南人女子中，为我的儿子娶妻。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 28:2; 创世记 22:20–23; 创世记 12:7"> 你要往我的本地、我的亲族那里去，为我的儿子以撒娶妻。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="耶利米书 4:2; 出埃及记 9:2; 出埃及记 20:7"> 仆人对他说：“如果那女子不愿意跟我到这地来，我是否必须把你的儿子带回你出来的那地去呢？”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="加拉太书 5:1; 彼得后书 2:20–22; 希伯来书 10:39"> 亚伯拉罕对他说：“你要谨慎，不可把我的儿子带回那里去。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 33:2; 创世记 13:15; 希伯来书 1:14"> 耶和华，天上的上帝——祂曾带我离开我父亲的家和我出生的土地，祂曾对我说话，向我起誓说：‘我要把这地赐给你的后裔’——祂必差遣祂的使者在你前面，你就要从那里为我的儿子娶妻。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 2:17–20; 民数记 30:5; 民数记 30:8"> 如果那女子不愿意跟你来，你就可以脱离向我所起的这个誓；只是不可把我的儿子带回那里去。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 24:2"> 仆人就把手放在他主人亚伯拉罕的大腿下，为这事向他起誓。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 11:31; 申命记 23:4; 创世记 27:43"> 仆人带了他主人十匹骆驼，手里带着主人各样的好东西，就起身往美索不达米亚去，到了拿鹤的城。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 9:11; 出埃及记 2:16; 约翰福音 4:7"> 傍晚时分，女子出来打水的时候，他叫骆驼跪在城外的水井旁。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 24:27; 出埃及记 3:6; 创世记 26:24"> 他说：“耶和华，我主人亚伯拉罕的上帝，求你使我今天顺利，以慈爱待我主人亚伯拉罕。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 24:43; 诗篇 37:5; 出埃及记 2:16"> 看哪，我站在这水泉旁，城里人的女儿们正出来打水。</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 6:37; 士师记 6:17; 创世记 15:8"> 我对哪一个少女说：‘请你放下水罐，让我喝水’，她若说：‘请喝，我也要给你的骆驼喝’，愿她就是你为你仆人以撒所指定的。这样，我就知道你以慈爱待了我的主人。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="创世记 11:29; 创世记 24:45; 以赛亚书 65:24"> 他话还没有说完，看哪，利百加肩上扛着水罐出来了；她是彼土利的女儿，彼土利是亚伯拉罕的兄弟拿鹤的妻子密迦所生的儿子。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 26:7; 民数记 31:17–18; 创世记 39:6"> 那少女容貌非常美丽，是个童女，没有男人亲近过她。她下到水泉那里，装满了水罐，又上来。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 4:7; 以赛亚书 21:14; 创世记 26:1–35"> 仆人跑上前去迎着她，说：“请让我喝一点你罐里的水。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="箴言 31:26; 彼得前书 3:8; 创世记 24:14"> 她说：“我主，请喝。”她急忙把水罐放在手上，给他喝。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 24:14; 彼得前书 4:9; 创世记 24:45–46"> 她给他喝完了，就说：“我也要为你的骆驼打水，直到它们喝足。”</span>
<span className="v" id="v20" data-v="20"> 她急忙把水罐里的水倒在水槽里，又跑到井旁打水，为他所有的骆驼打水。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="诗篇 107:43; 创世记 24:12; 撒母耳记下 7:18–20"> 那人定睛看她，默默不语，要知道耶和华是否使他的行程顺利。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结 16:11–12; 出埃及记 32:2–3; 创世记 23:15–16"> 骆驼喝足以后，那人拿出一个重半舍客勒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一舍客勒约为10克，或约0.35盎司。">a</a></sup>的金环，又拿出两只戴在她手上的金镯，重十舍客勒，</span>
<span className="v" id="v23" data-v="23"> 说：“你是谁的女儿？请告诉我。你父亲家里有没有地方让我们住宿？”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="创世记 24:15; 创世记 22:23; 创世记 22:20"> 她对他说：“我是彼土利的女儿；彼土利是密迦给拿鹤所生的儿子。”</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 32:8; 彼得前书 4:9; 士师记 19:19–21"> 她又对他说：“我们有足够的草料和饲料，也有住宿的地方。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="创世记 24:48; 出埃及记 4:31; 创世记 24:52"> 那人就低头敬拜耶和华。</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 24:48; 创世记 24:12; 诗篇 98:3"> 他说：“耶和华，我主人亚伯拉罕的上帝，是应当称颂的；祂没有停止以慈爱和信实待我的主人。至于我，耶和华一路引导我到了我主人亲族的家。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="创世记 24:67; 创世记 24:55; 创世记 31:33"> 那少女跑去，把这些话告诉她母亲家里的人。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 29:5; 创世记 29:13; 创世记 24:55"> 利百加有一个哥哥，名叫拉班。拉班跑到外面水泉那里，到那人那里去。</span>
<span className="v" id="v30" data-v="30"> 他看见环子和他妹妹手上的镯子，又听见他妹妹利百加的话，说“那人对我这样说”，就来到那人那里。看哪，那人正站在水泉旁的骆驼那里。</span>
<span className="v" id="v31" data-v="31" data-xref="路得记 3:10; 创世记 26:29; 诗篇 115:15"> 他说：“蒙耶和华赐福的人，请进来！你为什么站在外面？我已经预备好了房子，也为骆驼预备了地方。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="士师记 19:21; 创世记 43:24; 创世记 18:4"> 那人进了屋，卸了骆驼。他给骆驼草料和饲料，又拿水给他和跟随他的人洗脚。</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 132:3–5; 提摩太前书 6:2; 以弗所书 6:5–8"> 饭食摆在他面前给他吃，但他说：“我不说完我的事情，就不吃。”<br />拉班说：“请说。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> 他说：“我是亚伯拉罕的仆人。</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 24:1; 创世记 13:2; 箴言 10:22"> 耶和华大大赐福给我的主人，使他昌大。耶和华赐给他羊群、牛群、银子、金子、仆人、婢女、骆驼和驴。</span>
<span className="v" id="v36" data-v="36" data-xref="创世记 25:5; 创世记 21:10; 创世记 21:1–7"> 我主人的妻子撒拉年老的时候，给我的主人生了一个儿子。我主人把他一切所有的都给了这个儿子。</span>
<span className="v" id="v37" data-v="37" data-xref="创世记 27:46; 以斯拉记 9:1–3; 创世记 24:2–9"> 我主人叫我起誓，说：‘你不可从我所住之地的迦南人女子中，为我的儿子娶妻。</span>
<span className="v" id="v38" data-v="38" data-xref="创世记 24:4; 创世记 31:19; 创世记 12:1"> 你要往我父亲的家、我的亲族那里去，为我的儿子娶妻。’</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 24:5"> 我问我的主人：‘如果那女子不跟我来呢？’</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及记 23:20; 诗篇 16:8; 创世记 5:24"> 他对我说：‘我在祂面前行事为人的耶和华，必差遣祂的使者与你同去，使你的道路亨通。你要从我的亲族和我父亲的家中，为我的儿子娶妻。</span>
<span className="v" id="v41" data-v="41" data-xref="创世记 24:8; 申命记 29:12"> 你到我亲族那里去的时候，就可以脱离我所起的誓。如果他们不把她交给你，你也可以脱离我所起的誓。’</span>
<span className="v" id="v42" data-v="42" data-xref="尼希米记 1:11; 创世记 24:12–14; 以斯拉记 8:21"> 我今天到了水泉那里，就说：‘耶和华，我主人亚伯拉罕的上帝，如果你现在使我所行的道路亨通——</span>
<span className="v" id="v43" data-v="43" data-xref="创世记 24:13–14"> 看哪，我站在这水泉旁。愿那出来打水的少女，我对她说：“请给我一点你罐里的水喝”，</span>
<span className="v" id="v44" data-v="44" data-xref="创世记 24:14; 彼得前书 3:8; 创世记 2:22"> 她若对我说：“请喝，我也要为你的骆驼打水”——愿她就是耶和华为我主人的儿子所指定的女子。’</span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 7:7; 使徒行传 12:12–17; 创世记 24:15–20"> 我心里还没有说完，看哪，利百加肩上扛着水罐出来了。她下到水泉那里打水。我对她说：‘请让我喝水。’</span>
<span className="v" id="v46" data-v="46" data-xref="创世记 24:18–19"> 她急忙从肩上放下水罐，说：‘请喝，我也要给你的骆驼喝。’我就喝了；她也给骆驼喝。</span>
<span className="v" id="v47" data-v="47" data-xref="诗篇 45:13–14; 创世记 24:22–24; 以赛亚书 62:3–5"> 我问她说：‘你是谁的女儿？’她说：‘我是彼土利的女儿；彼土利是密迦给拿鹤所生的儿子。’我就把环子戴在她鼻子上，把镯子戴在她手上。</span>
<span className="v" id="v48" data-v="48" data-xref="箴言 3:5–6; 创世记 24:26–27; 诗篇 48:14"> 我低头敬拜耶和华，称颂耶和华，我主人亚伯拉罕的上帝，因为祂引导我走正确的道路，为我主人的儿子娶我主人兄弟家的女儿。</span>
<span className="v" id="v49" data-v="49" data-xref="创世记 47:29; 约书亚记 2:14; 箴言 3:3"> 现在，你们若愿意以慈爱和信实待我的主人，就告诉我；若不愿意，也告诉我，好让我或向右，或向左。”</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="诗篇 118:23; 创世记 31:24; 创世记 31:29"> 拉班和彼土利回答说：“这事出于耶和华，我们不能对你说好说歹。</span>
<span className="v" id="v51" data-v="51" data-xref="创世记 20:15; 创世记 24:15; 撒母耳记下 16:10"> 看哪，利百加就在你面前。把她带去吧，让她作你主人儿子的妻子，正如耶和华所说的。”</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="创世记 24:26; 创世记 24:48; 诗篇 116:1–2"> 亚伯拉罕的仆人听见他们的话，就俯伏在地敬拜耶和华。</span>
<span className="v" id="v53" data-v="53" data-xref="创世记 24:22; 创世记 24:10; 出埃及记 12:35"> 仆人拿出银饰、金饰和衣服，给了利百加；他也把贵重的礼物给了她哥哥和她母亲。</span>
<span className="v" id="v54" data-v="54" data-xref="创世记 24:56; 创世记 24:59; 创世记 28:5–6"> 他和跟随他的人吃喝，并住宿了一夜。早晨他们起来，他说：“请让我回到我主人那里去。”</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="创世记 4:3; 利未记 25:29; 士师记 14:8"> 利百加的哥哥和母亲说：“让这少女同我们住几天，至少十天；以后她再去。”</span>
</div>
<div className="bp">
<span className="v" id="v56" data-v="56" data-xref="箴言 25:25; 约书亚记 1:8; 以赛亚书 48:15"> 他对他们说：“耶和华既然使我的道路亨通，就不要耽延我。请让我走，好回到我主人那里去。”</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57"> 他们说：“我们把少女叫来，问问她。”</span>
<span className="v" id="v58" data-v="58" data-xref="路加福音 1:38; 诗篇 45:10–11"> 他们叫了利百加来，对她说：“你愿意跟这个人去吗？”<br />她说：“我愿意去。”</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="创世记 35:8; 民数记 11:12; 创世记 24:50"> 于是他们打发他们的姊妹利百加和她的乳母、亚伯拉罕的仆人，以及跟随他的人离去。</span>
<span className="v" id="v60" data-v="60" data-xref="创世记 22:17; 创世记 17:16; 路得记 4:11–12"> 他们给利百加祝福，对她说：“我们的姊妹啊，愿你成为千万人的母亲；愿你的后裔占有那些恨他们之人的城门。”</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61" data-xref="诗篇 45:10; 创世记 2:24; 以斯帖记 8:14"> 利百加和她的使女们起身，骑上骆驼，跟着那人。仆人带着利百加，就上路去了。</span>
<span className="v" id="v62" data-v="62" data-xref="创世记 25:11; 创世记 16:14; 创世记 12:9"> 以撒从庇耳拉海莱的路上来，因为他住在南地。</span>
<span className="v" id="v63" data-v="63" data-xref="诗篇 119:15; 诗篇 1:2; 诗篇 104:34"> 傍晚，以撒出去在田间默想。他举目观看，看哪，有骆驼来了。</span>
<span className="v" id="v64" data-v="64" data-xref="士师记 1:14; 约书亚记 15:18"> 利百加举目，看见以撒，就下了骆驼。</span>
<span className="v" id="v65" data-v="65" data-xref="提摩太前书 2:9; 哥林多前书 11:5–6; 哥林多前书 11:10"> 她对仆人说：“那在田间走来迎接我们的人是谁？”<br />仆人说：“是我的主人。”<br />她就拿面纱蒙上自己。</span>
<span className="v" id="v66" data-v="66" data-xref="马可福音 6:30"> 仆人把自己所做的一切事都告诉了以撒。</span>
<span className="v" id="v67" data-v="67" data-xref="雅歌 8:2; 以弗所书 5:22–33; 创世记 23:1–2"> 以撒把她领进他母亲撒拉的帐棚，娶了利百加，她就成了他的妻子。他爱她。以撒在母亲死后得了安慰。</span>
</div>

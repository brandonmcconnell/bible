<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 18:15; 使徒行传 10:41; 创世记 43:30–31"> 约瑟在所有站在他面前的人面前再也控制不住自己，就喊道：“叫所有人都从我面前出去！”约瑟向兄弟们表明自己身份的时候，没有别人和他站在一起。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 46:29; 使徒行传 20:37; 民数记 14:1"> 他放声大哭。埃及人听见了，法老的家也听见了。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 7:13; 使徒行传 9:5; 撒迦利亚书 12:10"> 约瑟对他的兄弟们说：“我是约瑟！我的父亲还在吗？”<br />他的兄弟们不能回答他，因为他们在他面前惊惶。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 37:28; 马太福音 14:27; 创世记 50:18"> 约瑟对他的兄弟们说：“请你们靠近我。”<br />他们就靠近了。他说：“我是约瑟，你们的兄弟，就是你们卖到埃及的那一个。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 50:20; 使徒行传 7:9–15; 创世记 45:7–8"> 现在，不要忧伤，也不要因你们把我卖到这里而恼恨自己，因为上帝差我在你们以先来，为要保存生命。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 47:23; 创世记 41:54; 创世记 41:56"> 这地的饥荒已经有这两年了，还要有五年，期间不会有耕种，也不会有收成。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 44:4; 使徒行传 7:35; 诗篇 18:50"> 上帝差我在你们以先来，是要使你们在地上有余民存留，并借着大大的拯救保全你们的性命。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 15:16; 罗马书 9:16; 约翰福音 19:11"> 这样看来，差我到这里来的不是你们，而是上帝；祂使我作法老的父，作他全家的主，并治理埃及全地。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 45:19–20; 创世记 45:13"> 你们要赶快上到我父亲那里，对他说：‘你的儿子约瑟这样说：“上帝已经使我作全埃及的主。请下到我这里来，不要耽延。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 9:26; 出埃及记 8:22; 创世记 46:34–6"> 你要住在歌珊地，离我很近，你和你的儿女、你儿女的儿女、你的羊群、牛群，以及你一切所有的，都要住在那里。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 47:12; 创世记 47:6; 马太福音 15:5–6"> 我要在那里供养你；因为还有五年饥荒，免得你和你的家眷，并你一切所有的，都陷入贫穷。”’</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 42:23; 路加福音 24:39; 约翰福音 20:27"> 看哪，你们的眼睛和我弟弟便雅悯的眼睛都看见，是我的口在对你们说话。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 7:14; 启示录 21:23; 彼得前书 1:10–12"> 你们要把我在埃及一切的荣耀，以及你们所看见的一切，都告诉我父亲。你们要赶快把我父亲带到这里来。”</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 33:4; 创世记 29:11; 创世记 46:29"> 他伏在他弟弟便雅悯的颈项上哭，便雅悯也伏在他的颈项上哭。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 15:20; 撒母耳记上 10:1; 诗篇 77:4"> 他亲吻所有的兄弟，抱着他们哭。之后，他的兄弟们就和他说话。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="创世记 41:33; 以斯帖记 1:21; 创世记 20:15"> 这消息传到法老的家里，说：“约瑟的兄弟们来了。”法老和他的臣仆都喜悦这事。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 42:25–26; 创世记 44:1–2"> 法老对约瑟说：“你告诉你的兄弟们：‘你们要这样做：把货物驮在牲畜上，起程往迦南地去。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 27:28; 民数记 18:12; 创世记 47:6"> 带着你们的父亲和你们的家眷，到我这里来，我要把埃及地的美物赐给你们，你们也要吃这地肥美的出产。’</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 46:5; 创世记 45:27; 创世记 31:17–18"> 现在你奉命要这样做：从埃及地带车辆去，接你们的孩子和妻子，又把你们的父亲带来。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 1:19; 路加福音 17:31; 申命记 7:16"> 也不要顾惜你们的物品，因为埃及全地的美物都是你们的。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 45:19; 以西结 23:24; 耶利米哀歌 1:18"> 以色列的儿子们就这样做了。约瑟照法老的命令给他们车辆，又给他们路上用的食物。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 43:34; 列王纪下 5:5; 士师记 14:12"> 他给他们每人一套替换的衣服；但给便雅悯三百块银子和五套替换的衣服。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 24:10; 出埃及记 16:3; 创世记 43:11"> 他送给他父亲的是这些：十匹公驴，驮着埃及的美物；又有十匹母驴，驮着粮食、饼和他父亲路上用的食物。</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦前书 5:13; 诗篇 133:1–3; 创世记 42:21–22"> 于是约瑟送他的兄弟们走，他们就离去了。他对他们说：“你们路上不要争吵。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 他们从埃及上去，来到迦南地，到他们的父亲雅各那里。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 44:28; 创世记 37:35; 路加福音 24:34"> 他们告诉他说：“约瑟还活着，并且他治理埃及全地。”雅各的心麻木了，因为他不信他们。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 85:6; 以赛亚书 57:15; 创世记 45:19"> 他们就把约瑟对他们说的一切话都告诉他。他看见约瑟派来接他的车辆，他们的父亲雅各的灵就苏醒了。</span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 2:28–30; 约翰福音 16:21–22; 创世记 46:30"> 以色列说：“够了。我的儿子约瑟还活着。我要在死以前去见他。”</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 24:37–39; 彼得后书 2:5–9; 创世记 6:9"> 耶和华对挪亚说：“你和你全家都进入方舟，因为在这世代中，我看见你在我面前是义的。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 8:20; 利未记 10:10; 利未记 11:1–47"> 凡洁净的动物，你要带七对，公的和母的；不洁净的动物，你要带一对，公的和母的；</span>
<span className="v" id="v3" data-v="3"> 天空的飞鸟也要七对，公的和母的，好在全地面上保留种类。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 6:13; 创世记 7:12; 创世记 7:17"> 因为再过七天，我要使雨降在地上四十昼夜；我所造的一切活物，我都要从地面上消灭。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 6:22; 路加福音 8:21; 出埃及记 39:32"> 挪亚就照耶和华所吩咐他的一切去做。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 5:32; 创世记 8:13"> 洪水临到地上的时候，挪亚六百岁。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 17:27; 创世记 6:18; 马太福音 24:38"> 挪亚同他的儿子、妻子和儿媳，因为洪水，进入方舟。</span>
<span className="v" id="v8" data-v="8"> 洁净的动物、不洁净的动物、飞鸟和地上一切爬行的，</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 7:16; 创世记 2:19; 耶利米书 8:7"> 都成对到挪亚那里，进入方舟，公的和母的，正如上帝所吩咐挪亚的。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 6:17; 创世记 7:4; 路加福音 17:27"> 过了那七天，洪水临到地上。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 8:2; 玛拉基书 3:10; 箴言 8:28–29"> 在挪亚一生的第六百年，二月十七日，就在那一天，大渊的泉源都裂开，天空的窗户也打开了。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 7:4; 马太福音 4:2; 创世记 7:17"> 雨降在地上四十昼夜。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 6:18; 创世记 7:1; 创世记 6:10"> 就在那一天，挪亚和挪亚的儿子闪、含、雅弗，以及挪亚的妻子和他三个儿子的妻子，都进入方舟——</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 7:8–9; 创世记 7:2–3"> 他们，和各类的走兽、各类的牲畜、各类在地上爬行的爬行动物，以及各类的飞鸟，各种鸟类，</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 6:19–20; 以赛亚书 11:6"> 凡有生命气息的血肉之物，都成对到挪亚那里，进入方舟。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 25:10; 路加福音 13:25; 诗篇 91:1–10"> 进去的，是一切血肉之物中的公的和母的，正如上帝所吩咐他的；然后耶和华把他关在里面。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 7:4; 创世记 7:12"> 洪水在地上泛滥四十天。水势上涨，把方舟托起；方舟就从地上升高。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 14:28; 诗篇 69:15; 约伯记 22:16"> 水势浩大，在地上大大上涨；方舟漂浮在水面上。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 104:6–9; 诗篇 46:2–3; 彼得后书 3:6"> 水势在地上极其浩大，普天下所有的高山都被淹没。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 3:23; 诗篇 104:6"> 水又高过山十五肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘是人手臂从中指尖到肘部的长度，约18英寸或46厘米。">a</a></sup>，山都被淹没了。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 6:13; 创世记 7:4; 创世记 6:17"> 凡在地上活动的血肉之物都死了，包括飞鸟、牲畜、走兽、地上爬行的一切爬行动物，以及所有的人。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 2:7; 创世记 6:17"> 凡在旱地上、鼻孔里有生命之灵气息的，都死了。</span>
<span className="v" id="v23" data-v="23" data-xref="彼得后书 2:5; 彼得前书 3:20; 希伯来书 11:7"> 地面上的一切活物都被消灭了，包括人、牲畜、爬行动物和天空的飞鸟；它们都从地上被消灭。只剩下挪亚和那些与他同在方舟里的人。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 8:3–4"> 水淹没大地一百五十天。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 2:6; 西番雅书 3:9; 以赛亚书 19:18"> 全地只有一种语言，一样的言语。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 10:10; 但以理 1:2; 创世记 14:1"> 他们往东迁移的时候，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="七十士译本作“从东方”。">a</a></sup>在示拿地找到一片平原，就住在那里。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 14:10; 出埃及记 1:14; 出埃及记 2:3"> 他们彼此说：“来吧，我们来造砖，把砖烧透。”他们用砖当石头，用柏油当灰泥。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 1:28; 约翰福音 5:44; 路加福音 1:51"> 他们说：“来吧，我们来为自己建一座城和一座塔，塔顶通天；我们要为自己扬名，免得我们分散在全地面上。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 18:21; 诗篇 33:13–14; 约翰福音 3:13"> 耶和华降临，要察看人类的子孙所建的城和塔。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 2:1–4; 创世记 3:22; 创世记 11:1"> 耶和华说：“看哪，他们是同一个民族，都有同一种语言；这只是他们开始做的事。如今他们所图谋要做的，就没有什么能拦阻他们了。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 33:10; 诗篇 55:9; 约伯记 5:12–13"> 来吧，我们下去，在那里混乱他们的语言，使他们听不懂彼此的言语。”</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 1:51; 申命记 32:8; 创世记 10:25"> 于是耶和华从那里把他们分散在全地面上；他们就停止建造那城。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 10:10; 创世记 10:5; 创世记 10:20"> 因此那城名叫巴别，因为耶和华在那里混乱了全地的语言；耶和华从那里把他们分散在全地面上。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志上 1:17–27; 创世记 10:21–22; 路加福音 3:34–36"> 这是闪后代的记载：洪水以后两年，闪一百岁，生了亚法撒。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 9:7; 诗篇 144:12; 创世记 1:28"> 闪生亚法撒以后，又活了五百年，并且生了其他儿女。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="路加福音 3:36"> 亚法撒活到三十五岁，生了沙拉。</span>
<span className="v" id="v13" data-v="13"> 亚法撒生沙拉以后，又活了四百零三年，并且生了其他儿女。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 沙拉活到三十岁，生了希伯。</span>
<span className="v" id="v15" data-v="15"> 沙拉生希伯以后，又活了四百零三年，并且生了其他儿女。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="创世记 10:21; 历代志上 1:19; 民数记 24:24"> 希伯活到三十四岁，生了法勒。</span>
<span className="v" id="v17" data-v="17"> 希伯生法勒以后，又活了四百三十年，并且生了其他儿女。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 3:35"> 法勒活到三十岁，生了拉吴。</span>
<span className="v" id="v19" data-v="19"> 法勒生拉吴以后，又活了二百零九年，并且生了其他儿女。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 3:35"> 拉吴活到三十二岁，生了西鹿。</span>
<span className="v" id="v21" data-v="21"> 拉吴生西鹿以后，又活了二百零七年，并且生了其他儿女。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约书亚记 24:2"> 西鹿活到三十岁，生了拿鹤。</span>
<span className="v" id="v23" data-v="23"> 西鹿生拿鹤以后，又活了二百年，并且生了其他儿女。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 3:34; 约书亚记 24:2"> 拿鹤活到二十九岁，生了他拉。</span>
<span className="v" id="v25" data-v="25"> 拿鹤生他拉以后，又活了一百一十九年，并且生了其他儿女。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="约书亚记 24:2; 历代志上 1:26–27; 创世记 22:20–24"> 他拉活到七十岁，生了亚伯兰、拿鹤和哈兰。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="创世记 12:4; 创世记 14:12; 创世记 11:31"> 这是他拉后代的记载。他拉生了亚伯兰、拿鹤和哈兰；哈兰生了罗得。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 15:7; 尼希米记 9:7; 使徒行传 7:2–4"> 哈兰在他的出生地，就是迦勒底的吾珥，死在他父亲他拉之前。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 17:15; 创世记 22:20; 创世记 24:15"> 亚伯兰和拿鹤都娶了妻。亚伯兰的妻子名叫撒莱；拿鹤的妻子名叫密迦，是哈兰的女儿；哈兰也是亦迦的父亲。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 29:31; 创世记 21:1–2; 路加福音 1:7"> 撒莱不能生育，没有孩子。</span>
<span className="v" id="v31" data-v="31" data-xref="尼希米记 9:7; 使徒行传 7:2–4; 创世记 24:10"> 他拉带着他的儿子亚伯兰、哈兰的儿子罗得，就是他的孙子，以及他的儿媳撒莱，就是他儿子亚伯兰的妻子，一同出了迦勒底的吾珥，要往迦南地去；他们来到哈兰，就住在那里。</span>
<span className="v" id="v32" data-v="32"> 他拉的日子共有二百零五年。他拉死在哈兰。</span>
</div>
</div>

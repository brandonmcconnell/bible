<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约伯记 5:2; 创世记 29:31; 创世记 37:11"> 拉结见自己不给雅各生孩子，就嫉妒她姐姐。她对雅各说：“给我孩子，不然我就死了。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="创世记 16:2; 诗篇 127:3; 列王纪下 5:7"> 雅各向拉结发怒，说：“我岂能代替上帝呢？是祂使你不能生育。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 50:23; 约伯记 3:12; 路得记 4:11"> 她说：“看哪，我的婢女辟拉在这里。你与她同房，使她可以在我的膝上生孩子，我也可以借着她得孩子。”</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 35:22; 创世记 21:10; 撒母耳记下 12:11"> 于是拉结把她的婢女辟拉给雅各为妻，雅各就与她同房。</span>
<span className="v" id="v5" data-v="5"> 辟拉怀孕，给雅各生了一个儿子。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米哀歌 3:59; 诗篇 35:24; 诗篇 43:1"> 拉结说：“上帝为我伸冤，也听了我的声音，赐给我一个儿子。”因此她给他起名叫但。</span>
<span className="v" id="v7" data-v="7"> 拉结的婢女辟拉又怀孕，给雅各生了第二个儿子。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 32:24–25; 创世记 23:6; 创世记 49:21"> 拉结说：“我与姐姐进行了激烈的较力，并且得胜了。”她给他起名叫拿弗他利。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 30:4; 创世记 30:17; 创世记 29:35"> 利亚见自己停止生育，就把她的婢女悉帕给雅各为妻。</span>
<span className="v" id="v10" data-v="10"> 利亚的婢女悉帕给雅各生了一个儿子。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 49:19; 以赛亚书 65:11; 创世记 35:26"> 利亚说：“何等幸运！”她给他起名叫迦得。</span>
<span className="v" id="v12" data-v="12"> 利亚的婢女悉帕又给雅各生了第二个儿子。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 1:48; 箴言 31:28; 雅歌 6:9"> 利亚说：“我有福啊，因为众女子必称我有福。”她给他起名叫亚设。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="雅歌 7:13; 创世记 25:30"> 收割麦子的日子，流便出去，在田里找到了风茄，就拿来给他的母亲利亚。拉结对利亚说：“请给我一些你儿子的风茄。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数记 16:13; 哥林多前书 4:3; 民数记 16:9–10"> 利亚对她说：“你夺了我的丈夫，难道是小事吗？你还要夺我儿子的风茄吗？”<br />拉结说：“既然这样，为了你儿子的风茄，今晚他可以与你同寝。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 到了晚上，雅各从田里回来，利亚出去迎接他，说：“你必须到我这里来；因为我确实用我儿子的风茄把你雇来了。”<br />那一夜，雅各与她同寝。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 30:6; 创世记 30:22; 出埃及记 3:7"> 上帝听了利亚，她就怀孕，给雅各生了第五个儿子。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 49:14–15; 申命记 33:18; 创世记 46:13"> 利亚说：“上帝给了我报酬，因为我把婢女给了我丈夫。”她给他起名叫以萨迦。</span>
<span className="v" id="v19" data-v="19"> 利亚又怀孕，给雅各生了第六个儿子。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 35:23; 马太福音 4:13; 创世记 49:13"> 利亚说：“上帝赐给我丰厚的嫁妆。现在我丈夫会与我同住，因为我给他生了六个儿子。”她给他起名叫西布伦。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 34:1–3; 创世记 34:26; 创世记 46:15"> 后来，她生了一个女儿，给她起名叫底拿。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="创世记 29:31; 诗篇 113:9; 诗篇 127:3"> 上帝记念拉结；上帝听了她，开了她的子宫。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 1:25; 创世记 29:31; 路加福音 1:27"> 她怀孕，生了一个儿子，说：“上帝除去了我的羞辱。”</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 49:22–26; 创世记 35:24; 创世记 37:2"> 她给他起名叫约瑟，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="约瑟的意思是“愿他增添”。">a</a></sup>说：“愿耶和华再给我增添一个儿子。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 24:54; 创世记 24:56; 创世记 28:15"> 拉结生了约瑟以后，雅各对拉班说：“请打发我走，让我回到自己的地方，回到我的本乡。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 29:30; 何西阿 12:12; 创世记 31:26"> 请把我为你服侍而得的妻子和孩子给我，让我走；因为你知道我怎样服侍了你。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路得记 2:13; 使徒行传 7:10; 以赛亚书 61:9"> 拉班对他说：“我若在你眼前蒙恩，请留下；因为我占卜得知，耶和华为你的缘故赐福给我。”</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 29:15; 创世记 29:19"> 他又说：“请你定下你的工价，我就给你。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="创世记 31:6; 创世记 31:38–40; 彼得前书 2:18"> 雅各对他说：“你知道我怎样服侍你，也知道你的牲畜在我手下怎样。</span>
<span className="v" id="v30" data-v="30" data-xref="提摩太前书 5:8; 哥林多后书 12:14; 申命记 11:10"> 我来以前，你所有的很少，如今却增多成群；我所到之处，耶和华都赐福给你。现在，我什么时候才可以为自己的家也预备呢？”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 21:4–6; 希伯来书 13:5; 诗篇 118:8"> 拉班说：“我该给你什么？”<br />雅各说：“你什么也不用给我。你若为我做这件事，我就再牧养看守你的羊群。</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 31:8; 创世记 31:10; 创世记 30:35"> 今天我要走遍你所有的羊群，把其中凡有斑有点的、绵羊中凡黑色的，以及山羊中有点有斑的都挑出来。这些就作为我的工价。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 13:14; 撒母耳记下 22:21; 撒母耳记上 26:23"> 以后你来查看摆在你面前我的工价时，我的清白必为我作证。凡在我这里的，若不是山羊中有斑有点的，或绵羊中黑色的，就算是偷来的。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="哥林多前书 7:7; 民数记 22:29; 哥林多前书 14:5"> 拉班说：“看哪，就照你的话吧。”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="创世记 31:9"> 那一天，拉班把有纹有点的公山羊，所有有斑有点的母山羊，凡身上有白色的，以及绵羊中所有黑色的，都挑出来，交在他儿子们手里。</span>
<span className="v" id="v36" data-v="36"> 他使自己和雅各之间相隔三天的路程；雅各就牧养拉班其余的羊群。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="创世记 31:9–13; 以西结 31:8"> 雅各拿了杨树、杏树和悬铃木的新鲜枝条，剥出白纹，使枝条里面的白色露出来。</span>
<span className="v" id="v38" data-v="38"> 他把剥了皮的枝条放在羊群来喝水的水槽里，正对着羊群；羊群来喝水的时候就受孕。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及记 12:35–36; 创世记 31:9–12; 创世记 31:40"> 羊群在枝条前受孕，就生下有纹、有斑、有点的羊。</span>
<span className="v" id="v40" data-v="40"> 雅各把羊羔分出来，使羊群面向拉班羊群中有纹的和所有黑色的羊。他把自己的羊群另放一处，不放在拉班的羊群里。</span>
<span className="v" id="v41" data-v="41"> 每当羊群中强壮的受孕时，雅各就把枝条放在水槽里羊群眼前，使它们在枝条旁受孕；</span>
<span className="v" id="v42" data-v="42"> 但羊群瘦弱的时候，他就不放。这样，瘦弱的归拉班，强壮的归雅各。</span>
<span className="v" id="v43" data-v="43" data-xref="创世记 24:35; 创世记 30:30; 创世记 26:13–14"> 这人极其兴旺，拥有许多羊群、婢女、仆人、骆驼和驴。</span>
</div>
</div>

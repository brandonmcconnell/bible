<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 12:6; 创世记 18:10; 创世记 18:14"> 耶和华照祂所说的眷顾撒拉；耶和华照祂所应许的为撒拉成就了。</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太书 4:22; 希伯来书 11:11; 创世记 18:10"> 撒拉怀了孕，在上帝对亚伯拉罕说定的时候，给年老的亚伯拉罕生了一个儿子。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 17:19; 罗马书 9:7; 创世记 21:6"> 亚伯拉罕给撒拉为他所生的儿子起名叫以撒。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“以撒”的意思是“他笑”。">a</a></sup></span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 7:8; 申命记 12:32; 约翰福音 7:22–23"> 以撒出生后第八天，亚伯拉罕照上帝所吩咐他的，给他的儿子以撒行了割礼。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 17:17; 罗马书 4:19; 创世记 17:1"> 他的儿子以撒出生的时候，亚伯拉罕一百岁。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 126:2; 以赛亚书 54:1; 创世记 17:17"> 撒拉说：“上帝使我欢笑；凡听见的人都要与我一同欢笑。”</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 18:11–12; 以赛亚书 66:8; 帖撒罗尼迦后书 1:10"> 她又说：“谁会对亚伯拉罕说，撒拉要哺养孩子呢？因为我在他年老的时候给他生了一个儿子。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 1:22; 何西阿 1:8; 创世记 40:20"> 那孩子渐渐长大，断了奶。以撒断奶的那一天，亚伯拉罕摆设了盛大的筵席。</span>
<span className="v" id="v9" data-v="9" data-xref="加拉太书 4:29; 创世记 16:15; 加拉太书 4:22"> 撒拉看见埃及人夏甲给亚伯拉罕所生的儿子在嘲笑。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 8:35; 约翰一书 2:19; 加拉太书 4:22–31"> 因此她对亚伯拉罕说：“把这个使女和她的儿子赶出去！因为这个使女的儿子不可和我的儿子以撒一同承受产业。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="希伯来书 12:11; 创世记 17:18; 马太福音 10:37"> 亚伯拉罕因他的儿子，这事在他眼中非常难过。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 11:18; 罗马书 9:7–8; 创世记 17:19"> 上帝对亚伯拉罕说：“不要因这孩子和你的使女而难过。凡撒拉对你说的，你都要听从她的话；因为从以撒生的，才要称为你的后裔。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 16:10; 创世记 17:20; 创世记 21:18"> 至于这使女的儿子，我也要使他成为一国，因为他是你的孩子。”</span>
<span className="v" id="v14" data-v="14" data-xref="传道书 9:10; 诗篇 119:60; 创世记 16:7"> 亚伯拉罕清早起来，拿饼和一袋水给夏甲，把这些放在她肩上，又把孩子交给她，就打发她离开。她走了，在别是巴的旷野游荡。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 3:9; 诗篇 63:1; 耶利米书 14:3"> 袋里的水用尽了，她就把孩子放在一棵灌木底下。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 49:15; 创世记 29:11; 撒母耳记上 24:16"> 她走开，在对面坐下，相隔有一段距离，大约一箭之远；因为她说：“不要让我看见孩子死。”她坐在对面，放声大哭。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 16:11; 诗篇 50:15; 出埃及记 3:7"> 上帝听见那孩子的声音。<br />上帝的使者从天上呼叫夏甲，对她说：“夏甲，你怎么了？不要惧怕，因为上帝已经听见孩子在那里发出的声音。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 21:13; 创世记 16:10; 创世记 17:20"> 起来，把孩子扶起来，用你的手扶住他；因为我要使他成为大国。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="民数记 22:31; 列王纪下 6:17–20; 以赛亚书 35:5–6"> 上帝开了她的眼睛，她就看见一口水井。她去把水袋装满水，给孩子喝。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 28:15; 创世记 39:21; 创世记 16:12"> 上帝与那孩子同在，他渐渐长大。他住在旷野；他长大后成了弓箭手。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 26:34–35; 创世记 24:3–4; 民数记 12:16"> 他住在巴兰的旷野；他母亲从埃及地给他娶了一个妻子。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约书亚记 3:7; 创世记 26:26; 创世记 26:28"> 那时候，亚比米勒和他的军队统领非各对亚伯拉罕说：“你所做的一切事都有上帝与你同在。</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 2:12; 创世记 20:14; 希伯来书 6:16"> 现在，请你在这里指着上帝向我起誓，不以虚假待我、我的儿子和我的孙子。我怎样恩待了你，你也要照样恩待我，以及你寄居的这地。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="希伯来书 6:16; 创世记 14:13; 罗马书 12:18"> 亚伯拉罕说：“我愿意起誓。”</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 26:15–22; 创世记 29:8; 箴言 25:9"> 亚伯拉罕因一口水井的事责备亚比米勒；那口井是亚比米勒的仆人强夺去的。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 13:7; 列王纪下 5:20–24"> 亚比米勒说：“我不知道是谁做了这事。你也没有告诉我，我直到今天才听见。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="创世记 14:22–23; 以赛亚书 32:8; 罗马书 1:31"> 亚伯拉罕拿羊和牛给亚比米勒，二人就立了约。</span>
<span className="v" id="v28" data-v="28"> 亚伯拉罕把羊群中的七只母羊羔分开放在一边。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记上 15:14; 创世记 33:8; 出埃及记 12:26"> 亚比米勒问亚伯拉罕：“你把这七只母羊羔分开放在一边，是什么意思？”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="创世记 31:52; 约书亚记 24:27; 约书亚记 22:27–28"> 他说：“你要从我手里收下这七只母羊羔，作为我的证据，证明这口井是我挖的。”</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 26:33; 创世记 21:14; 列王纪上 4:25"> 所以他称那地方为别是巴，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“别是巴”可意为“起誓之井”或“七之井”。">b</a></sup>因为他们二人在那里起了誓。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 13:17; 创世记 21:27; 士师记 13:1"> 他们就在别是巴立了约。亚比米勒和他的军队统领非各起身，回到非利士人的地去了。</span>
<span className="v" id="v33" data-v="33" data-xref="提摩太前书 1:17; 以赛亚书 40:28; 诗篇 90:2"> 亚伯拉罕在别是巴栽了一棵柽柳，在那里求告耶和华—<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="英文中全大写的 LORD 或 GOD，除非另有说明来自短形式 יה Yah，均译自希伯来文 יהוה Yahweh。">c</a></sup>永恒上帝—的名。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志上 29:15; 彼得前书 2:11; 希伯来书 11:9"> 亚伯拉罕在非利士人的地寄居了许多日子。</span>
</div>
</div>

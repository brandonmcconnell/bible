<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 31:17; 出埃及记 20:11; 诗篇 33:6"> 天、地和其中的万象都完成了。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 4:4; 出埃及记 31:17; 申命记 5:14"> 到第七日，上帝完成了祂所做的工；第七日，祂歇了祂所做的一切工。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结 20:12; 马可福音 2:27; 利未记 23:3"> 上帝赐福给第七日，使它成为圣日，因为在这日，祂歇了祂所做的一切创造之工。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="创世记 5:1; 启示录 1:8; 创世记 1:4"> 这是天和地被创造时的来历，就是耶和华<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="当“LORD”或“GOD”以全部大写字母显示时，是上帝专有名（希伯来文“יהוה”，通常读作“雅威”）的译法。">a</a></sup>上帝造地和天的时候。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 3:23; 希伯来书 6:7; 约伯记 5:10"> 田野的植物还没有在地上出现，田野的菜蔬也还没有长出来；因为耶和华上帝还没有降雨在地上，也没有人耕种土地，</span>
<span className="v" id="v6" data-v="6"> 但有雾气从地上升起，滋润土地的整个表面。</span>
<span className="v" id="v7" data-v="7" data-xref="传道书 12:7; 约伯记 33:4; 哥林多前书 15:45"> 耶和华上帝用地上的尘土塑造了人，将生命的气息吹进他的鼻孔里；人就成了有生命的人。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结 28:13; 创世记 3:24; 创世记 13:10"> 耶和华上帝在东方，在伊甸栽了一个园子，把祂所塑造的人安置在那里。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 3:22; 启示录 2:7; 启示录 22:14"> 耶和华上帝使各样树木从地里长出来，悦人眼目，又好作食物；园子当中还有生命树和分别善恶的树。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 22:1; 诗篇 46:4"> 有一条河从伊甸流出来滋润那园子；从那里分开，成为四条河的源头。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 25:18; 创世记 10:29; 撒母耳记上 15:7"> 第一条名叫比逊；它流经哈腓拉全地，那里有金子；</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 28:20; 民数记 11:7; 以西结 28:13"> 那地的金子是好的。比多拉<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：芳香树脂">b</a></sup>和红玛瑙也在那里。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 10:6; 以赛亚书 11:11"> 第二条河名叫基训；它就是流经古实全地的那条河。</span>
<span className="v" id="v14" data-v="14" data-xref="但以理 10:4; 创世记 15:18; 申命记 1:7"> 第三条河名叫希底结；它流在亚述前面。第四条河就是幼发拉底河。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 128:2; 创世记 2:8; 以弗所书 4:28"> 耶和华上帝把那人带来，安置在伊甸园里，要他耕种并看守那园子。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 15:22; 提摩太前书 4:4; 提摩太前书 6:17"> 耶和华上帝吩咐那人说：“园中各样树上的果子，你都可以随意吃；</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 6:23; 雅各书 1:15; 创世记 3:19"> 只是分别善恶树上的果子，你不可吃；因为你吃它的日子，必定死。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="传道书 4:9–12; 哥林多前书 11:7–12; 箴言 18:22"> 耶和华上帝说：“那人独居不好。我要为他造一个与他相配的帮助者。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作：适合他的，或与他相宜的。">c</a></sup>”</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 8:4–8; 创世记 1:28; 创世记 9:2"> 耶和华上帝用地上的尘土塑造了田野的各样动物和天空的各样飞鸟，把它们带到那人面前，看他要怎样称呼它们。那人怎样称呼各样有生命的活物，那就是它的名字。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 2:18"> 那人给一切牲畜、天空的飞鸟和田野的各样动物都起了名；只是给那人没有找到与他相配的帮助者。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 15:12; 约伯记 4:13; 撒母耳记上 26:12"> 耶和华上帝使那人沉睡。他睡着的时候，祂取下他的一根肋骨，又把那处的肉合起来。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 11:8–9; 提摩太前书 2:13; 希伯来书 13:4"> 耶和华上帝用从那人身上取下的肋骨造了一个女人，把她带到那人面前。</span>
<span className="v" id="v23" data-v="23" data-xref="以弗所书 5:28–30; 哥林多前书 11:8–9; 撒母耳记下 5:1"> 那人说：“这一次，她是我骨中的骨、肉中的肉。她要称为‘女人’，因为她是从男人身上取出来的。”</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 19:3–9; 以弗所书 5:28–31; 马可福音 10:6–12"> 因此，男人要离开他的父亲和母亲，与他的妻子联合，二人成为一体。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 3:7; 创世记 3:10–11; 罗马书 10:11"> 那人和他的妻子二人都赤身露体，却并不羞愧。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 28:3–4; 创世记 24:3; 创世记 27:46"> 以撒叫了雅各来，给他祝福，并吩咐他说：“你不可娶迦南女子为妻。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 25:20; 何西阿 12:12; 创世记 24:50"> 起来，往巴旦亚兰去，到你母亲的父亲彼土利家里；在那里从你母亲的兄弟拉班的女儿中娶一个为妻。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 48:3; 创世记 35:11; 创世记 1:28"> 愿全能的上帝赐福给你，使你生养众多，人数增多，成为许多民族的群体；</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 3:14; 创世记 12:7; 以弗所书 1:3"> 又愿祂把亚伯拉罕的祝福赐给你和与你同在的后裔，使你承受你所寄居的土地，就是上帝赐给亚伯拉罕的地。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 以撒送雅各离开。雅各就往巴旦亚兰去，到亚兰人彼土利的儿子拉班那里；拉班是利百加的兄弟，利百加是雅各和以扫的母亲。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 27:33; 创世记 28:1"> 以扫看见以撒已经给雅各祝福，并送他往巴旦亚兰去，要他从那里娶妻；又看见以撒给他祝福的时候吩咐他说：“你不可娶迦南女子为妻”；</span>
<span className="v" id="v7" data-v="7" data-xref="以弗所书 6:1; 以弗所书 6:3; 歌罗西书 3:20"> 并且雅各听从了父母，去了巴旦亚兰。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 24:3; 创世记 26:34–35; 撒母耳记上 8:6"> 以扫看见迦南女子不蒙他父亲以撒喜悦，</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 36:3; 创世记 36:18; 创世记 36:13"> 就到以实玛利那里，在他已有的妻子之外，又娶了亚伯拉罕儿子以实玛利的女儿、尼拜约的妹妹玛哈拉为妻。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 7:2; 创世记 11:31; 创世记 32:10"> 雅各离开别示巴，往哈兰去。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 8:20; 创世记 28:18; 创世记 31:46"> 他来到一个地方，因为太阳已经落了，就在那里过夜。他拿了那地方的一块石头，放在头下，就在那地方躺下睡了。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 1:51; 民数记 12:6; 创世记 32:1–2"> 他梦见有一个阶梯立在地上，顶端达到天上。看哪，上帝的使者在阶梯上上去下来。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 13:15; 创世记 48:3; 创世记 35:12"> 看哪，耶和华站在阶梯上方，说：“我是耶和华，是你祖亚伯拉罕的上帝，也是以撒的上帝。你现在躺卧的这地，我要赐给你和你的后裔。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 12:3; 使徒行传 3:25; 创世记 18:18"> 你的后裔必像地上的尘土；你必向西、向东、向北、向南扩展。地上的万族都必因你和你的后裔得福。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 1:5; 以赛亚书 41:10; 耶利米书 1:19"> 看哪，我与你同在；无论你往哪里去，我都必保守你，并且必带你回到这地。因为我总不离开你，直到我成就了我对你所说的话。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约书亚记 5:15; 出埃及记 3:5; 出埃及记 15:11"> 雅各从睡梦中醒来，说：“耶和华确实在这地方，我竟不知道。”</span>
<span className="v" id="v17" data-v="17" data-xref="提摩太前书 3:15; 创世记 35:1–13; 传道书 5:1"> 他就惧怕，说：“这地方何等可畏！这不是别的，正是上帝的殿，也是天的门。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="创世记 35:14; 创世记 31:45; 创世记 31:13"> 雅各清早起来，拿起他放在头下的那块石头，立作柱子，又在柱顶上浇油。</span>
<span className="v" id="v19" data-v="19" data-xref="何西阿 12:4–5; 创世记 35:1; 创世记 48:3"> 他给那地方起名叫伯特利；但那城起初名叫路斯。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太前书 6:8; 撒母耳记下 15:8; 创世记 31:13"> 雅各许愿说：“如果上帝与我同在，在我所走的这路上保守我，又给我食物吃、衣服穿，</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 11:31; 申命记 26:17; 撒母耳记下 19:24"> 使我平平安安回到我父亲的家，并且耶和华作我的上帝，</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 35:7; 创世记 14:20; 申命记 14:22–23"> 那么我所立作柱子的这块石头，必成为上帝的殿；凡你所赐给我的，我必定把十分之一献给你。”</span>
</div>
</div>

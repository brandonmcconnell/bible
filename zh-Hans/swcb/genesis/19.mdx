<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="GEN" data-book-slug="genesis" data-book-name="创世记" data-chapter="19" data-verses="38">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 18:22; 创世记 18:1–5; 希伯来书 13:2"> 傍晚，那两个天使来到所多玛。罗得正坐在所多玛城门口。罗得看见他们，就起来迎接，脸伏于地下拜，</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 18:4; 路加福音 24:28–29; 希伯来书 13:2"> 说：“我主啊，请看，请到仆人家里来过夜，洗洗脚，然后清早起来再走你们的路。”<br />他们说：“不，我们要在街上过夜。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 18:6–8; 士师记 6:19; 撒母耳记上 28:24"> 罗得极力催促他们，他们就转向他那里，进了他的家。他为他们预备筵席，烤了无酵饼，他们就吃了。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 13:13; 箴言 4:16; 出埃及记 23:2"> 他们还没有躺下，城里的人，就是所多玛的人，连老带少，来自各处的全体百姓，都围住那房子。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 19:22; 以赛亚书 3:9; 犹大书 1:7"> 他们呼叫罗得，对他说：“今晚到你这里来的人在哪里？把他们带出来给我们，让我们与他们交合。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="士师记 19:23"> 罗得出来，到门口他们那里去，随手把门关上，</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 6:9–11; 士师记 19:23; 利未记 20:13"> 说：“我的弟兄们，请不要行这样的恶。</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 19:24; 创世记 19:31–38; 士师记 9:15"> 请看，我有两个女儿，还是处女。请让我把她们带出来给你们，你们看怎样好，就怎样待她们。只是这些人既然来到我屋檐的荫下，不可对他们做什么。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 2:14; 彼得后书 2:7–8; 创世记 13:12"> 他们说：“退开！”又说：“这个人来寄居，竟要自立为审判官。现在我们要待你比待他们更坏！”他们用力挤逼罗得那人，靠近要破门。</span>
<span className="v" id="v10" data-v="10"> 但那两个人伸出手来，把罗得拉进屋里，到他们那里，然后关上门。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 6:18; 使徒行传 13:11; 申命记 28:28–29"> 他们击打在屋门口的人，使他们眼目昏迷，无论大小都是这样，以致他们找门找得疲乏。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 7:1; 彼得后书 2:7; 启示录 18:4"> 那两个人对罗得说：“你这里还有什么人吗？女婿、儿子、女儿，以及你在城里所有的人，都要从这地方带出去；</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 18:20; 马太福音 13:49–50; 犹大书 1:7"> 因为我们要毁灭这地方，因为控告他们的呼声在耶和华面前已经非常大，所以耶和华差我们来毁灭这地方。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 16:21; 耶利米书 51:6; 民数记 16:45"> 罗得就出去，对那些已经许配给他女儿的女婿说：“起来！离开这地方，因为耶和华要毁灭这城！”<br />但他的女婿们却以为他在开玩笑。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 16:24–27; 启示录 18:4; 创世记 19:22"> 天亮的时候，天使催促罗得说：“起来！带着你妻子和你这里的两个女儿，免得你因这城的罪孽被毁灭。”</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 9:15–16; 提多书 3:5; 约翰福音 6:44"> 但他迟延不走；那两个人就抓住他的手、他妻子的手和他两个女儿的手，因为耶和华怜悯他；他们把他带出来，安置在城外。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 24:16–18; 路加福音 9:62; 腓立比书 3:13–14"> 他们把他们带出来以后，其中一位说：“逃命吧！不要回头看，也不要在平原任何地方停留。要逃到山上去，免得你被毁灭！”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰福音 13:6–8; 使徒行传 10:14; 创世记 32:26"> 罗得对他们说：“我主啊，不要这样。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 27:1; 诗篇 103:1–22; 提摩太前书 1:14–16"> 请看，你仆人在你眼前蒙恩，你向我施行慈爱，救了我的性命，显为广大。但我不能逃到山上去，恐怕灾祸追上我，我就死了。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 119:175; 箴言 3:5–7; 创世记 19:30"> 请看，这座城又近，可以逃到那里去，而且是小城。请让我逃到那里去——它不是小城吗？——我的性命就可以存活。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="诗篇 145:19; 诗篇 34:15; 诗篇 102:17"> 他对罗得说：“看哪，这件事我也应允你；你所说的这座城，我不会倾覆。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 13:10; 创世记 14:2; 创世记 32:25–28"> 赶快逃到那里去，因为你到那里以前，我什么都不能做。”因此那城名叫琐珥。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="琐珥意思是“小”。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 罗得到了琐珥的时候，太阳已经升在地上。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 29:23; 以赛亚书 13:19; 阿摩司 4:11"> 于是耶和华从天上、从耶和华那里，向所多玛和蛾摩拉降下硫磺与火。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 107:34; 创世记 14:3; 创世记 13:10"> 祂倾覆了那些城、整个平原、城里所有的居民，以及地上生长的一切。</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 17:31–32; 创世记 19:17; 箴言 14:14"> 但罗得的妻子在他后面回头看，她就变成一根盐柱。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="哈巴谷 2:1; 诗篇 5:3; 希伯来书 2:1"> 亚伯拉罕清早起来，到他曾站在耶和华面前的地方。</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 18:9; 启示录 9:2; 启示录 21:8"> 他向所多玛和蛾摩拉，以及平原全地观看，只见那地的烟气上腾，好像火炉的烟气。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="创世记 8:1; 申命记 9:5; 创世记 18:23–33"> 上帝毁灭平原各城的时候，上帝记念亚伯拉罕；祂倾覆罗得所住的那些城时，把罗得从倾覆之中送了出来。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="创世记 19:19; 以赛亚书 15:5; 雅各书 1:8"> 罗得离开琐珥上去，住在山里；他的两个女儿也和他同住，因为他害怕住在琐珥。他和两个女儿住在一个洞里。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 25:5; 以赛亚书 4:1; 创世记 16:2"> 大女儿对小女儿说：“我们的父亲老了，地上又没有男人按全地的常例来与我们亲近。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 18:6–7; 创世记 11:3; 创世记 9:21"> 来，我们让父亲喝酒，然后我们与他同寝，好从我们的父亲延续后裔。”</span>
<span className="v" id="v33" data-v="33" data-xref="哈巴谷 2:15–16; 箴言 23:29–35; 箴言 20:1"> 那夜，她们让父亲喝酒；大女儿进去与她父亲同寝。她躺下的时候，父亲不知道；她起来的时候，父亲也不知道。</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米书 8:12; 耶利米书 6:15; 以赛亚书 3:9"> 第二天，大女儿对小女儿说：“看哪，我昨夜与父亲同寝了。今晚我们再让他喝酒，你进去与他同寝，好从我们的父亲延续后裔。”</span>
<span className="v" id="v35" data-v="35" data-xref="箴言 24:16; 诗篇 8:4; 彼得前书 4:7"> 那夜，她们也让父亲喝酒；小女儿起来与他同寝。她躺下的时候，父亲不知道；她起来的时候，父亲也不知道。</span>
<span className="v" id="v36" data-v="36" data-xref="哈巴谷 2:15; 士师记 1:7; 马太福音 7:2"> 这样，罗得的两个女儿都从她们的父亲怀了孕。</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 2:9; 列王纪下 3:1–27; 民数记 21:29"> 大女儿生了一个儿子，给他起名叫摩押。他是今日摩押人的祖先。</span>
<span className="v" id="v38" data-v="38" data-xref="申命记 2:19; 士师记 10:6–40; 诗篇 83:4–8"> 小女儿也生了一个儿子，给他起名叫便亚米。他是今日亚扪人的祖先。</span>
</div>
</div>

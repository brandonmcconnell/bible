<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 45:10; 创世记 46:31; 创世记 46:28"> 约瑟进去告诉法老，说：“我的父亲和我的弟兄，带着他们的羊群、牛群和一切所有的，已经从迦南地来了；看哪，他们在歌珊地。”</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 7:13; 歌罗西书 1:28; 犹大书 1:24"> 约瑟从他弟兄中选了五个人，带到法老面前。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 46:33–34; 帖撒罗尼迦后书 3:10; 创世记 4:2"> 法老对他的弟兄说：“你们以什么为业？”<br />他们对法老说：“你的仆人是牧羊的，我们和我们的祖先都是如此。”</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 46:34; 创世记 15:13; 申命记 26:5"> 他们又对法老说：“我们来这地寄居，因为迦南地的饥荒严重，仆人的羊群没有草场。现在，求你准许你的仆人住在歌珊地。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 法老对约瑟说：“你的父亲和你的弟兄到你这里来了。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 18:21; 箴言 22:29; 创世记 47:11"> 埃及地都在你面前。你要让你的父亲和你的弟兄住在这地最好的地方，让他们住在歌珊地。你若知道他们中间有能干的人，就派他们管理我的牲畜。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="创世记 47:10; 撒母耳记下 8:10; 撒母耳记上 2:20"> 约瑟带他父亲雅各进来，站在法老面前；雅各就给法老祝福。</span>
<span className="v" id="v8" data-v="8"> 法老对雅各说：“你年纪多大了？”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="诗篇 39:12; 诗篇 39:5; 约伯记 14:1"> 雅各对法老说：“我寄居的年日是一百三十年。我一生的年日又少又苦，不及我祖先在寄居岁月中一生的年日。”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 47:7; 诗篇 129:8; 希伯来书 7:7"> 雅各给法老祝福，就从法老面前出去了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="创世记 47:6; 出埃及记 1:11; 出埃及记 12:37"> 约瑟安置他的父亲和弟兄，照法老所吩咐的，把埃及地最好的地方，就是兰塞斯地，给他们作产业。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 45:11; 提摩太前书 5:8; 创世记 47:1"> 约瑟按着他们各家人口的多少，供给他的父亲、弟兄和他父亲全家粮食。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 7:11; 列王纪上 18:5; 耶利米哀歌 4:9"> 全地都没有粮食，因为饥荒非常严重，埃及地和迦南地都因饥荒而衰弱。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 41:56; 路加福音 16:10–12; 路加福音 16:1–2"> 约瑟收聚埃及地和迦南地所有的钱，就是他们买粮的钱；约瑟把这些钱带进法老的宫中。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 8:8; 诗篇 37:3; 马太福音 6:11"> 埃及地和迦南地的钱都用尽了，所有埃及人都来见约瑟，说：“给我们粮食吧！为什么让我们死在你面前呢？因为我们的钱用尽了。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 4:5; 但以理 6:5–7; 哥林多前书 10:32"> 约瑟说：“如果你们的钱用完了，就把你们的牲畜给我，我就给你们食物来换你们的牲畜。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约伯记 2:4; 出埃及记 9:3; 以赛亚书 31:1"> 他们把牲畜带到约瑟那里，约瑟就给他们粮食，换取马、羊群、牛群和驴；那一年，他用粮食换了他们所有的牲畜，供养他们。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 6:26; 耶利米书 38:9"> 那一年过去了，第二年他们又来见他，对他说：“我们不向我主隐瞒：我们的钱都用尽了，牲畜群也归了我主。在我主眼前，除了我们的身体和我们的土地，什么都没有剩下。</span>
<span className="v" id="v19" data-v="19" data-xref="尼希米记 5:2–3; 约伯记 2:4; 耶利米哀歌 1:11"> 为什么要让我们和我们的土地都死在你眼前呢？请你用粮食买我们和我们的土地，我们和我们的土地就作法老的仆人。请给我们种子，使我们可以存活，不至死亡，土地也不至荒废。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 于是约瑟为法老买下埃及所有的土地，因为饥荒沉重地压在埃及人身上，各人都卖了自己的田地，土地就归了法老。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 41:48"> 至于百姓，约瑟使他们迁到各城，从埃及边界的一端直到另一端。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯拉记 7:24; 尼希米记 13:10; 帖撒罗尼迦后书 3:10"> 只有祭司的土地，他没有买，因为祭司从法老那里有定额的供给，吃法老给他们的定额供给；所以他们没有卖自己的土地。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 112:5; 诗篇 41:1; 传道书 11:6"> 约瑟对百姓说：“看哪，今天我为法老买下了你们和你们的土地。看哪，这里有种子给你们，你们要耕种土地。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 41:34; 诗篇 41:1; 诗篇 112:5"> 到收成的时候，你们要把五分之一给法老，其余四份归你们自己，用作田间的种子，也作你们和你们家里的人，以及你们幼小孩子的食物。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 33:15; 箴言 11:26–27; 创世记 18:3"> 他们说：“你救了我们的性命！愿我们在我主眼前蒙恩，我们愿作法老的仆人。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="创世记 47:22; 以西结 7:24"> 约瑟为埃及地定下这条例，直到今日：五分之一归法老。只有祭司的土地没有归法老。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="创世记 46:3; 出埃及记 1:7; 使徒行传 7:17"> 以色列住在埃及地，就是歌珊地；他们在那里置产业，生养众多，人数大大增多。</span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 90:10; 创世记 47:8–9; 创世记 37:2"> 雅各在埃及地住了十七年。这样，雅各一生的年日是一百四十七年。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 31:14; 创世记 24:49; 创世记 24:2"> 以色列死期临近，就叫了他的儿子约瑟来，对他说：“我若在你眼前蒙恩，请你把手放在我的大腿下，用慈爱和信实待我。请不要把我葬在埃及，</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 49:29–32; 创世记 23:19; 创世记 25:9"> 等我与我的祖先同睡时，你要把我从埃及抬出去，葬在他们的墓地里。”<br />约瑟说：“我必照你所说的去做。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪上 1:47; 希伯来书 11:21; 创世记 24:3"> 以色列说：“你要向我起誓。”约瑟就向他起誓。于是以色列在床头俯伏敬拜。</span>
</div>
</div>

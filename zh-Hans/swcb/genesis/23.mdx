<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 17:17"> 撒拉活了一百二十七岁；这就是撒拉一生的年数。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 23:19; 创世记 13:18; 历代志上 6:57"> 撒拉死在迦南地的基列·亚巴（又叫希伯仑）。亚伯拉罕来为撒拉哀恸，为她哭泣。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 10:15; 创世记 23:7; 撒母耳记上 26:6"> 亚伯拉罕从他的死者面前起来，对赫的子孙说：</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 29:15; 希伯来书 11:9; 创世记 17:8"> “我在你们中间是寄居的外人。请在你们中间给我一块坟地作为产业，好让我把我的死者从我眼前安葬。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 赫的子孙回答亚伯拉罕，对他说：</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 24:35; 创世记 14:14; 出埃及记 32:22"> “我主啊，请听我们。你在我们中间是上帝的王侯。请把你的死者葬在我们最好的坟墓里；我们没有一个人会不让你用他的坟墓来安葬你的死者。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="希伯来书 12:14; 创世记 19:1; 箴言 18:24"> 亚伯拉罕起来，向那地的百姓，就是赫的子孙，下拜。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 25:9; 约翰一书 2:1–2; 列王纪上 2:17"> 他同他们说：“如果你们愿意让我把我的死者从我眼前安葬，请听我，并代我请求琐辖的儿子以弗仑，</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 13:8; 罗马书 12:17"> 让他把他所有、在他田地尽头的麦比拉洞卖给我。请让他在你们中间按足价卖给我，作为坟地的产业。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 34:20; 创世记 34:24; 创世记 23:18"> 当时以弗仑正坐在赫的子孙中间。赫人以弗仑就在赫的子孙和凡进他城门的人听见的地方回答亚伯拉罕说：</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 19:24; 以赛亚书 32:8; 申命记 19:15"> “不，我主啊，请听我。我把那块田给你，也把田里的洞给你；我在我族人的子孙面前把它给你。请安葬你的死者吧。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 23:7; 创世记 18:2; 创世记 19:1"> 亚伯拉罕在那地的百姓面前下拜。</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 13:8; 撒母耳记下 24:24; 创世记 14:22–23"> 他在那地百姓听见的地方对以弗仑说：“如果你愿意，请听我。我要把田价给你；请你从我这里收下，我就在那里安葬我的死者。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 以弗仑回答亚伯拉罕，对他说：</span>
<span className="v" id="v15" data-v="15" data-xref="以西结 45:12; 出埃及记 30:13; 出埃及记 30:15"> “我主啊，请听我。一块值四百舍客勒银子<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一舍客勒约为10克，所以400舍客勒约为4公斤，或8.8磅。">a</a></sup>的地，在你我之间算什么呢？所以，请安葬你的死者吧。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒迦利亚书 11:12; 耶利米书 32:9; 出埃及记 30:13"> 亚伯拉罕听从以弗仑。亚伯拉罕把以弗仑在赫的子孙听见的地方所说的银子称给他，就是四百舍客勒银子，是按商人通用的标准。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 25:9; 创世记 50:13; 创世记 23:20"> 于是，以弗仑在麦比拉、幔利前面的那块田，那田和田里的洞，以及田中所有、在四围边界内的树木，都立契</span>
<span className="v" id="v18" data-v="18" data-xref="路得记 4:1; 耶利米书 32:12; 创世记 34:20"> 归给亚伯拉罕为产业；这是在赫的子孙面前，在凡进他城门的人面前办理的。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 50:13; 传道书 12:7; 传道书 12:5"> 此后，亚伯拉罕把他的妻子撒拉安葬在迦南地幔利前面（就是希伯仑）的麦比拉田间的洞里。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 32:10–14; 路得记 4:7–10; 创世记 49:31–32"> 那块田和田里的洞，就由赫的子孙立契归给亚伯拉罕，作为坟地的产业。</span>
</div>
</div>

</div>

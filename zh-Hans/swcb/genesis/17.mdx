<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="GEN" data-book-slug="genesis" data-book-name="创世记" data-chapter="17" data-verses="27">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="腓立比书 4:13; 以弗所书 3:20; 路加福音 1:6"> 亚伯兰九十九岁的时候，耶和华向亚伯兰显现，对他说：“我是全能的上帝。你要在我面前行事，并且要无可指摘。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 17:4–6; 创世记 12:2; 诗篇 105:8–11"> 我要在我与你之间立我的约，并要使你极其增多。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="士师记 13:20; 创世记 17:17; 民数记 16:45"> 亚伯兰就脸伏于地。上帝与他说话，说：</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 35:11; 加拉太书 3:28–29; 创世记 12:2"> “至于我，看哪，我的约与你同在。你必成为许多民族的父。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 1:21–23; 尼希米记 9:7; 创世记 17:15"> 你的名不再叫亚伯兰，你的名要叫亚伯拉罕；因为我已经立你作许多民族的父。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 17:4; 马太福音 1:6–17; 创世记 35:11"> 我要使你极其多结果子，也要使多国从你而出；君王必从你而出。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 9:7–9; 使徒行传 2:39; 创世记 26:24"> 我要在我与你之间，并你以后世世代代的后裔之间，坚立我的约，作永远的约；我要作你和你以后后裔的上帝。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 26:12; 诗篇 105:11; 出埃及记 6:7"> 我要把你寄居的地，就是迦南全地，赐给你和你以后的后裔，作永远的产业；我也要作他们的上帝。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 56:4–5; 诗篇 25:10; 诗篇 103:18"> 上帝对亚伯拉罕说：“至于你，你和你以后世世代代的后裔都要遵守我的约。</span>
<span className="v" id="v10" data-v="10" data-xref="歌罗西书 2:11–12; 罗马书 4:9–11; 使徒行传 7:8"> 这就是我与你们之间，并你以后后裔之间，你们所要遵守的我的约：你们中间所有的男子都要受割礼。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 4:11; 使徒行传 7:8; 申命记 10:16"> 你们要在包皮的肉上受割礼；这要作我与你们之间立约的记号。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 12:3; 路加福音 2:21; 出埃及记 12:48–49"> 你们世世代代中，凡男子，生下来第八天都要受割礼；无论是家里生的，或是用银钱从任何外人那里买来的，就是不属你后裔的人，都要如此。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 12:44; 创世记 37:36; 尼希米记 5:8"> 你家里生的，和你用银钱买来的，都必须受割礼。我的约要在你们的肉上，作永远的约。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 4:24–26; 民数记 15:30–31; 出埃及记 12:19"> 不受割礼的男子，就是没有在包皮的肉上受割礼的，那人必从他的民中被剪除；他背弃了我的约。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 12:25; 创世记 32:28; 创世记 17:5"> 上帝对亚伯拉罕说：“至于你的妻子撒莱，你不可再叫她名为撒莱，她的名要叫撒拉。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 35:11; 创世记 17:6; 以赛亚书 49:23"> 我要赐福给她，而且也要从她赐给你一个儿子。是的，我要赐福给她，她必作多国之母；多民的君王必从她而出。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="启示录 11:16; 创世记 21:6; 创世记 18:12"> 亚伯拉罕就脸伏于地，笑了，心里说：“一百岁的人还能生孩子吗？撒拉已经九十岁了，还能生产吗？”</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 2:39; 诗篇 41:12; 诗篇 4:6"> 亚伯拉罕对上帝说：“但愿以实玛利活在你面前！”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 1:13–20; 创世记 21:2–3; 列王纪下 4:16–17"> 上帝说：“不然，你的妻子撒拉必给你生一个儿子。你要给他起名叫以撒。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“以撒”的意思是“他笑”。">a</a></sup>我要与他坚立我的约，作他以后后裔永远的约。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 21:18; 创世记 21:13; 创世记 25:12–18"> 至于以实玛利，我已经听了你的话。看哪，我已经赐福给他，必使他多结果子，使他极其增多。他必成为十二个首领的父；我也要使他成为大国。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 21:2–3; 创世记 26:2–5; 加拉太书 3:29"> 但我的约，我要与以撒坚立，就是明年这指定的时候，撒拉要给你生的那个儿子。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="创世记 18:33; 创世记 35:9–15; 士师记 6:21"> 上帝与亚伯拉罕说完话，就离开他上升去了。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 119:60; 创世记 18:19; 创世记 17:10–14"> 正在那一天，亚伯拉罕照着上帝对他所说的，带了他的儿子以实玛利，以及凡在他家里生的、凡用他的银钱买来的，就是亚伯拉罕家中所有男子，在他们包皮的肉上施行割礼。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 4:11; 创世记 17:17; 罗马书 4:19–20"> 亚伯拉罕在包皮的肉上受割礼的时候，年九十九岁。</span>
<span className="v" id="v25" data-v="25"> 他的儿子以实玛利在包皮的肉上受割礼的时候，年十三岁。</span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 119:60; 创世记 22:3–4; 创世记 12:4"> 正在那一天，亚伯拉罕和他的儿子以实玛利都受了割礼。</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 18:19"> 他家里所有的男子，无论是家里生的，还是用银钱从外人那里买来的，也都和他一同受了割礼。</span>
</div>
</div>

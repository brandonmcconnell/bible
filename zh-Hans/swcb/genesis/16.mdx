<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 4:24; 创世记 12:16; 创世记 15:2–3"> 亚伯兰的妻子撒莱没有给他生孩子。她有一个埃及婢女，名叫夏甲。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 21:4; 创世记 18:10; 创世记 3:17"> 撒莱对亚伯兰说：“看哪，耶和华使我不能生育。请你与我的婢女同房，也许我可以借着她得孩子。”亚伯兰听从了撒莱的话。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 16:5; 创世记 12:4–5; 撒母耳记下 5:13"> 亚伯兰在迦南地住了十年以后，亚伯兰的妻子撒莱把她的埃及婢女夏甲给了她丈夫亚伯兰，作他的妻子。</span>
<span className="v" id="v4" data-v="4" data-xref="箴言 30:23; 撒母耳记下 6:16; 哥林多前书 13:4–5"> 亚伯兰与夏甲同房，她就怀了孕。她见自己怀了孕，就看不起她的主母。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 31:53; 出埃及记 5:21; 诗篇 7:8"> 撒莱对亚伯兰说：“我受的委屈归到你身上！我把我的婢女交在你怀中，她见自己怀了孕，就看不起我。愿耶和华在你我之间施行判断。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="耶利米书 38:5; 箴言 14:29; 彼得前书 3:7"> 亚伯兰对撒莱说：“看哪，你的婢女在你手中；你看怎样好，就怎样待她吧。”撒莱苦待夏甲，夏甲就从她面前逃走了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="创世记 25:18; 出埃及记 15:22; 创世记 21:17"> 耶和华的使者在旷野的水泉旁，就是在通往书珥路上的那泉旁，找到了她。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 3:9; 创世记 4:10; 传道书 10:4"> 他说：“撒莱的婢女夏甲，你从哪里来？要往哪里去？”<br />她说：“我从我的主母撒莱面前逃出来。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="彼得前书 5:5–6; 传道书 10:4; 提多书 2:9"> 耶和华的使者对她说：“回到你的主母那里，服在她手下。”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 17:20; 诗篇 83:6–7; 创世记 25:12–18"> 耶和华的使者又对她说：“我必使你的后裔大大增多，多到不可胜数。”</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 2:23–24; 出埃及记 3:7; 以赛亚书 7:14"> 耶和华的使者又对她说：“看哪，你已经怀孕，将要生一个儿子。你要给他起名叫以实玛利，因为耶和华听见了你的苦情。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 25:18; 创世记 21:20; 约伯记 39:5–8"> 他为人必像野驴。他的手要攻击所有人，所有人的手也要攻击他。他必与他所有的弟兄相敌而居。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="诗篇 139:1–12; 创世记 32:30; 箴言 5:21"> 夏甲称那对她说话的耶和华为：“你是看见我的上帝。”因为她说：“我见了祂以后，竟还活着吗？”</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 24:62; 创世记 25:11; 创世记 21:31"> 因此，那井被称为庇耳·拉海·莱。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="庇耳·拉海·莱的意思是“那位活着又看见我的者之井”。">a</a></sup>看哪，它在加低斯和巴列之间。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="创世记 25:12; 创世记 21:9–21; 创世记 17:25–26"> 夏甲给亚伯兰生了一个儿子。亚伯兰给夏甲所生的儿子起名叫以实玛利。</span>
<span className="v" id="v16" data-v="16"> 夏甲给亚伯兰生以实玛利的时候，亚伯兰八十六岁。</span>
</div>
</div>

</div>

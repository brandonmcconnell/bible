<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 9:7; 创世记 1:28; 创世记 8:17"> 上帝赐福给挪亚和他的儿子们，对他们说：“要繁衍增多，遍满全地。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 8:4–8; 创世记 1:28; 雅各书 3:7"> 地上的各样走兽、天空的各样飞鸟，都会惧怕你们、畏惧你们；凡在地上爬行的，以及海里一切的鱼，都交在你们手中。</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 14:14; 歌罗西书 2:21–22; 哥林多前书 10:31"> 凡活着的动物，都可以作你们的食物；我怎样把绿色植物赐给你们，也照样把这一切都赐给你们。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 12:23; 申命记 15:23; 申命记 12:16"> 只是带着生命的肉，就是带着血的肉，你们不可吃。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 21:28–29; 出埃及记 21:12; 创世记 4:9–10"> 至于你们生命的血，我必追讨；向各样走兽，我必追讨；向人，向各人的兄弟，我也必追讨人的生命。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 24:17; 马太福音 26:52; 启示录 13:10"> 凡流人血的，他的血也必被人所流，因为上帝是照着祂自己的形像造人。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 1:28; 创世记 9:1; 创世记 9:19"> 你们要繁衍增多，在地上大量增殖，并且在其中增多。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 上帝对挪亚和同他在一起的儿子们说：</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 6:18; 以赛亚书 54:9–10; 罗马书 1:3"> “至于我，看哪，我要与你们，以及你们以后的后裔，坚立我的约；</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 8:1; 创世记 9:15–16; 诗篇 36:5–6"> 也与同你们在一起的一切活物，就是飞鸟、牲畜和同你们在一起的地上一切走兽，凡从方舟里出来的，地上一切走兽，坚立我的约。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 54:9; 创世记 8:21–22; 创世记 7:21–23"> 我要与你们坚立我的约：凡有血肉的，不再被洪水剪除；也不再有洪水毁灭全地。”</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 17:11; 马太福音 26:26–28; 出埃及记 12:13"> 上帝说：“这是我在我与你们，以及同你们在一起的一切活物之间所立之约的记号，直到世世代代：</span>
<span className="v" id="v13" data-v="13" data-xref="以西结 1:28; 启示录 4:3; 启示录 10:1"> 我把我的彩虹设在云中，它要作我与地之间立约的记号。</span>
<span className="v" id="v14" data-v="14"> 我使云彩遮盖大地的时候，彩虹会显现在云中，</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 7:9; 以西结 16:60; 以赛亚书 54:8–10"> 我就要记念我与你们，以及一切有血肉的活物之间所立的约；水就不再成为洪水，毁灭凡有血肉的。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 54:8–10; 耶利米书 32:40; 撒母耳记下 23:5"> 彩虹必在云中；我必观看它，好记念上帝与地上一切有血肉的活物之间所立的永远之约。”</span>
<span className="v" id="v17" data-v="17"> 上帝对挪亚说：“这就是我在我与地上一切有血肉的之间所坚立之约的记号。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="创世记 10:1; 创世记 10:6; 创世记 9:25–27"> 从方舟出来的挪亚的儿子，是闪、含和雅弗。含是迦南的父亲。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 1:4–28; 创世记 8:17; 创世记 5:32"> 这三个人是挪亚的儿子；全地的人都是从他们而来。</span>
</div>
<div className="bp poetry">
<span className="v" id="v20" data-v="20" data-xref="申命记 20:6; 箴言 10:11; 以赛亚书 28:24–26"> 挪亚开始作农夫，栽了一个葡萄园。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 20:1; 哈巴谷 2:15–16; 箴言 23:31–32"> 他喝了葡萄酒，就醉了，在自己的帐棚里赤身露体。</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 30:17; 加拉太书 6:1; 马太福音 18:15"> 迦南的父亲含看见他父亲赤身，就告诉外面的两个兄弟。</span>
<span className="v" id="v23" data-v="23" data-xref="加拉太书 6:1; 出埃及记 20:12; 提摩太前书 5:17"> 闪和雅弗拿了一件衣服，搭在两人的肩上，倒退着进去，遮盖他们父亲赤身；他们的脸背着，没有看见父亲赤身。</span>
<span className="v" id="v24" data-v="24"> 挪亚酒醒以后，知道他的小儿子向他所做的事，</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 9:23; 申命记 27:16; 士师记 1:28–30"> 就说：<br /><span className="pl pl-1">“迦南受咒诅；</span><br /><span className="pl pl-2">他必作他兄弟们奴仆中的奴仆。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v26" data-v="26" data-xref="诗篇 144:15; 创世记 12:1–3; 路加福音 3:23–36"> 他又说：<br /><span className="pl pl-1">“耶和华，闪的上帝，是应当称颂的；</span><br /><span className="pl pl-2">愿迦南作闪的奴仆。</span></span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 11:12; 罗马书 15:12; 希伯来书 11:9–10"> <span className="pl pl-1">愿上帝扩张雅弗；</span><br /><span className="pl pl-2">愿他住在闪的帐棚里；</span><br /><span className="pl pl-2">愿迦南作他的奴仆。”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 洪水以后，挪亚又活了三百五十年。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 5:27; 诗篇 90:10; 创世记 5:32"> 挪亚一生的日子共九百五十年，然后他死了。</span>
</div>
</div>

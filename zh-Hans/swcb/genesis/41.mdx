<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="GEN" data-book-slug="genesis" data-book-name="创世记" data-chapter="41" data-verses="57">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 20:3; 创世记 29:14; 出埃及记 4:9"> 过了整整两年，法老做了梦；看哪，他站在河边。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 19:6"> 看哪，有七头母牛从河里上来，又美好又肥壮，在芦苇草中吃草。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 41:20–21; 创世记 41:4"> 看哪，另有七头母牛随后从河里上来，又丑陋又瘦弱，站在河岸边那些母牛旁边。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 3:15"> 这些又丑陋又瘦弱的母牛吞吃了那七头又美好又肥壮的母牛。于是法老醒了。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 32:14"> 他又睡着，第二次做梦；看哪，一根麦秆上长出七个穗子，又饱满又美好。</span>
<span className="v" id="v6" data-v="6" data-xref="以西结 17:10; 何西阿 13:15; 以西结 19:12"> 看哪，随后又长出七个穗子，又细弱，又被东风吹焦。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 37:5; 创世记 20:3"> 这些细弱的穗子吞吃了那七个饱满充实的穗子。法老醒了，看哪，原来是个梦。</span>
<span className="v" id="v8" data-v="8" data-xref="但以理 4:7; 出埃及记 7:22; 马太福音 2:1"> 到了早晨，他心里不安，就派人召来埃及所有的术士和智慧人。法老把他的梦告诉他们，却没有人能给法老解释。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 40:14; 创世记 40:23; 创世记 40:1–3"> 那时，酒政长对法老说：“我今天想起我的过失。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 39:20; 创世记 40:2–3; 创世记 37:36"> 从前法老向臣仆发怒，把我和膳长囚在护卫长的府中。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 40:5–8"> 我和他同一夜都做了梦，各人所做的梦都有各自的解释。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 40:12–19; 创世记 37:36; 创世记 39:1"> 在那里同我们在一起的，有一个年轻的希伯来人，是护卫长的仆人；我们把梦告诉他，他就给我们解释了我们的梦。他按着各人的梦给各人解释。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结 43:3; 创世记 40:20–22; 创世记 40:12"> 后来事情果然照他给我们解释的那样成就：我官复原职，膳长却被挂起来了。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="但以理 2:25; 诗篇 113:7–8; 诗篇 105:19–22"> 于是法老派人召约瑟，他们就急忙把他从牢坑里带出来。他剃了头，换了衣服，进到法老面前。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理 5:16; 但以理 5:12; 诗篇 25:14"> 法老对约瑟说：“我做了一个梦，却没有人能解释。我听人说，你听了梦就能解释。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 3:5; 创世记 40:8; 但以理 2:47"> 约瑟回答法老说：“这不在于我；上帝必给法老平安的答复。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 法老对约瑟说：“在我的梦中，看哪，我站在河岸边；</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 24:8; 耶利米书 24:1–3; 耶利米书 24:5"> 看哪，有七头肥壮美好的母牛从河里上来，在芦苇草中吃草；</span>
<span className="v" id="v19" data-v="19"> 看哪，随后又有七头母牛上来，瘦弱、非常丑陋、干瘦；在埃及全地，我从未见过这样丑陋的。</span>
<span className="v" id="v20" data-v="20"> 这些干瘦丑陋的母牛吞吃了先前那七头肥壮的母牛；</span>
<span className="v" id="v21" data-v="21" data-xref="以西结 3:3; 诗篇 37:19; 启示录 10:9–10"> 它们吞吃以后，却看不出它们曾吞吃过，仍像起初一样丑陋。于是我醒了。</span>
<span className="v" id="v22" data-v="22"> 我又在梦中看见，看哪，一根麦秆上长出七个穗子，又充实又美好；</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 129:6–7; 何西阿 13:15; 列王纪下 19:26"> 看哪，随后又长出七个穗子，枯萎、细弱，被东风吹焦。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理 4:7; 创世记 41:8; 出埃及记 8:19"> 这些细弱的穗子吞吃了那七个美好的穗子。我把这梦告诉术士，却没有人能给我说明。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="但以理 2:45; 启示录 4:1; 以弗所书 1:17"> 约瑟对法老说：“法老的梦是一个。上帝把祂将要做的事告诉了法老。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 41:47; 创世记 41:2; 创世记 41:53"> 那七头美好的母牛就是七年；那七个美好的穗子也是七年。这梦是一个。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 8:1; 撒母耳记下 24:19"> 随后上来的那七头干瘦丑陋的母牛就是七年；那七个空瘪、被东风吹焦的穗子也是如此；它们将是七个饥荒之年。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 41:25; 创世记 41:16"> 这就是我对法老所说的事。上帝已经把祂将要做的事指示法老。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 41:26; 创世记 41:46–47; 创世记 41:49"> 看哪，埃及全地将有七个大丰收之年。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 47:13; 创世记 41:54; 雅各书 5:17"> 随后将兴起七个饥荒之年，埃及地一切的丰收都要被遗忘；饥荒必耗尽这地，</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 24:20; 撒母耳记上 5:6"> 因那随后的饥荒极其严重，这地就不再记得曾有丰收。</span>
<span className="v" id="v32" data-v="32" data-xref="民数记 23:19; 以赛亚书 46:10–11; 以赛亚书 14:24–27"> 这梦向法老重复两次，是因为这事已由上帝定准，上帝快要使它成就。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="创世记 41:39; 使徒行传 6:3; 申命记 1:13"> “现在，愿法老寻得一个有见识、有智慧的人，派他治理埃及地。</span>
<span className="v" id="v34" data-v="34" data-xref="箴言 22:3; 路加福音 16:5; 箴言 6:6–8"> 愿法老这样行：任命官员管理这地，在七个丰收之年，征收埃及地出产的五分之一。</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 45:6–7; 创世记 41:56; 出埃及记 4:13"> 让他们聚集将要来到的这些丰年中的一切粮食，在法老的权下把谷物储存在各城，作为粮食，并加以看守。</span>
<span className="v" id="v36" data-v="36" data-xref="创世记 47:13–25"> 这些粮食要作为这地的储备，以应付埃及地将有的七个饥荒之年，使这地不至因饥荒而灭亡。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="使徒行传 7:10; 列王纪上 21:2; 撒母耳记下 3:36"> 这事在法老眼中，并在他所有臣仆眼中，都看为好。</span>
<span className="v" id="v38" data-v="38" data-xref="约伯记 32:8; 但以理 5:14; 民数记 27:18"> 法老对他的臣仆说：“像这样的人，有上帝的灵在他里面，我们还能找得着吗？”</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 41:33; 创世记 41:28; 创世记 41:25"> 法老对约瑟说：“既然上帝把这一切都指示了你，就没有人像你这样有见识、有智慧。</span>
<span className="v" id="v40" data-v="40" data-xref="箴言 22:29; 使徒行传 7:10; 诗篇 105:21–22"> 你要管理我的家；我的百姓都要照你的话受治理。只有在宝座上，我比你大。”</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 28:18; 腓立比书 2:9–11; 创世记 42:6"> 法老对约瑟说：“看哪，我已经派你治理埃及全地。”</span>
<span className="v" id="v42" data-v="42" data-xref="但以理 5:29; 但以理 5:7; 以斯帖记 3:10"> 法老从自己手上取下印戒，戴在约瑟手上，又给他穿上细麻衣，把金链戴在他的颈项上。</span>
<span className="v" id="v43" data-v="43" data-xref="使徒行传 7:10; 创世记 45:8; 创世记 45:26"> 他使约瑟坐在自己的副车上；有人在他前面呼喊：“屈膝！”法老就派他治理埃及全地。</span>
<span className="v" id="v44" data-v="44" data-xref="诗篇 105:22; 出埃及记 11:7"> 法老对约瑟说：“我是法老。在埃及全地，没有你的许可，任何人不得抬手动脚。”</span>
<span className="v" id="v45" data-v="45" data-xref="创世记 46:20; 以西结 30:17; 出埃及记 2:16"> 法老给约瑟起名叫撒发那忒·巴内亚，又把安城祭司波提非拉的女儿亚西纳给他为妻。约瑟就出去巡视埃及地。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="但以理 1:19; 列王纪上 12:6; 撒母耳记上 16:21"> 约瑟站在埃及王法老面前的时候，年三十岁。约瑟从法老面前出去，走遍埃及全地。</span>
<span className="v" id="v47" data-v="47" data-xref="创世记 26:12; 诗篇 72:16"> 在七个丰收之年，土地出产丰盛。</span>
<span className="v" id="v48" data-v="48" data-xref="创世记 41:34–36; 创世记 47:21"> 约瑟聚集埃及地那七年中的一切粮食，把粮食存放在各城。他把各城周围田地里的粮食，都储存在本城里。</span>
<span className="v" id="v49" data-v="49" data-xref="诗篇 78:27; 士师记 6:5; 创世记 22:17"> 约瑟积存谷物，多如海沙，极其众多，直到无法再数，因为多得不可胜数。</span>
<span className="v" id="v50" data-v="50" data-xref="创世记 46:20; 创世记 48:5; 撒母耳记下 8:18"> 饥荒之年还没有来到以前，约瑟生了两个儿子，是安城祭司波提非拉的女儿亚西纳给他生的。</span>
<span className="v" id="v51" data-v="51" data-xref="诗篇 30:5; 箴言 31:7; 申命记 33:17"> 约瑟给长子起名叫玛拿西，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“玛拿西”的发音近似希伯来语“忘记”。">a</a></sup>他说：“因为上帝使我忘记了我一切的劳苦，以及我父亲的全家。”</span>
<span className="v" id="v52" data-v="52" data-xref="创世记 49:22; 创世记 50:23; 创世记 17:6"> 他给次子起名叫以法莲，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“以法莲”的发音近似希伯来语“加倍结果子”。">b</a></sup>说：“因为上帝使我在受苦之地昌盛。”</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="创世记 41:29–31; 诗篇 73:20; 路加福音 16:25"> 埃及地的七个丰年结束了。</span>
<span className="v" id="v54" data-v="54" data-xref="创世记 45:11; 使徒行传 7:11; 诗篇 105:16"> 七个饥荒之年开始来到，正如约瑟所说的。各地都有饥荒，惟有埃及全地有粮食。</span>
<span className="v" id="v55" data-v="55" data-xref="马太福音 17:5; 马太福音 3:17; 耶利米书 14:1–6"> 埃及全地都饥饿的时候，百姓向法老呼求粮食；法老对所有埃及人说：“你们到约瑟那里去；他对你们说什么，你们就做什么。”</span>
<span className="v" id="v56" data-v="56" data-xref="创世记 42:6; 撒迦利亚书 5:3; 路加福音 21:35"> 饥荒遍及全地。约瑟打开所有仓库，卖粮给埃及人。埃及地的饥荒十分严重。</span>
<span className="v" id="v57" data-v="57" data-xref="创世记 41:54; 创世记 42:5; 创世记 41:56"> 各国的人都来到埃及，到约瑟那里买谷物，因为全地的饥荒都十分严重。</span>
</div>
</div>

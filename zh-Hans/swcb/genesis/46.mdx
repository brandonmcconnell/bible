<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 28:13; 创世记 26:22–25; 创世记 28:10"> 以色列带着他所有的一切起行，来到别是巴，向他父亲以撒的上帝献祭。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 15:1; 约伯记 33:14–15; 约伯记 4:13"> 上帝在夜间的异象中对以色列说：“雅各，雅各！”<br />他说：“我在这里。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 12:2; 申命记 26:5; 以赛亚书 43:1–2"> 祂说：“我是上帝，是你父亲的上帝。不要害怕下埃及去，因为我必在那里使你成为大国。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 3:8; 创世记 28:15; 创世记 48:21"> 我要和你一同下埃及去，也必定把你再带上来。约瑟必亲手合上你的眼睛。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 45:21; 创世记 45:19; 创世记 45:27"> 雅各从别是巴起行；以色列的儿子们把他们的父亲雅各，以及他们的孩子和妻子，都带上法老派来接他的车。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 24:4; 以赛亚书 52:4; 使徒行传 7:15"> 他们带着牲畜和在迦南地所得的财物来到埃及——雅各和他所有的后裔都与他同来，</span>
<span className="v" id="v7" data-v="7"> 他的儿子和孙子、女儿和孙女；他把所有的后裔都带着一同来到埃及。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 1:1–5; 申命记 33:6; 历代志上 2:1–55"> 这些是来到埃及的以色列子孙的名字，就是雅各和他的儿子们：雅各的长子流便。</span>
<span className="v" id="v9" data-v="9"> 流便的儿子：哈诺、法路、希斯仑、迦米。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 6:15; 创世记 29:33; 创世记 28:1"> 西缅的儿子：耶母利、雅悯、阿辖、雅斤、琐辖，还有迦南女子所生的儿子扫罗。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 29:34; 历代志上 6:16; 民数记 8:1–26"> 利未的儿子：革顺、哥辖、米拉利。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 4:21; 创世记 38:10; 创世记 29:35"> 犹大的儿子：珥、俄南、示拉、法勒斯、谢拉；但珥和俄南死在迦南地。法勒斯的儿子是希斯仑和哈母勒。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 12:32; 创世记 35:23; 创世记 30:14–18"> 以萨迦的儿子：陀拉、普瓦、约伯、伸仑。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 33:18–19; 民数记 26:26–27; 民数记 1:30–31"> 西布伦的儿子：西烈、以伦、雅利。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 29:32–35; 创世记 30:17–21; 创世记 34:1–31"> 这些是利亚在巴旦·亚兰给雅各所生的儿子，另有他的女儿底拿。他儿女的全部人数是三十三人。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 26:15–17; 创世记 30:11; 民数记 1:24–25"> 迦得的儿子：洗非芸、哈基、书尼、以斯本、以利、亚罗底、亚列利。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 49:20; 创世记 30:13; 民数记 1:13"> 亚设的儿子：音拿、亦施瓦、亦施韦、比利亚，还有他们的妹妹西拉。比利亚的儿子：希别和玛结。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 29:24; 创世记 35:26; 创世记 30:9–13"> 这些是拉班给他女儿利亚的婢女悉帕的儿子；她给雅各所生的共有十六人。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 44:27; 创世记 29:18; 创世记 35:24"> 雅各妻子拉结的儿子：约瑟和便雅悯。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 41:50–52; 创世记 41:45; 申命记 33:13–17"> 约瑟在埃及地生了玛拿西和以法莲，是安城祭司波提非拉的女儿亚西纳给他生的。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 7:6–12; 历代志上 8:1–7; 民数记 26:38–40"> 便雅悯的儿子：比拉、比结、亚实别、基拉、乃缦、以希、罗实、母平、户平、亚勒。</span>
<span className="v" id="v22" data-v="22"> 这些是拉结给雅各所生的儿子；总共十四人。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 1:38–39; 创世记 49:16–17; 民数记 1:12"> 但的儿子：户伸。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 7:13; 民数记 1:42–43; 创世记 35:25"> 拿弗他利的儿子：雅薛、沽尼、耶色、示冷。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 29:29; 创世记 35:25; 创世记 30:3–8"> 这些是拉班给他女儿拉结的婢女辟拉的儿子；她给雅各所生的总共七人。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 1:5; 创世记 35:11; 士师记 8:30"> 同雅各来到埃及的人，就是从他本身所出的，除了雅各儿子们的妻子以外，总共六十六人。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 10:22; 使徒行传 7:14; 出埃及记 1:5"> 约瑟在埃及所生的儿子有两人。雅各全家来到埃及的总共七十人。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="创世记 45:10; 创世记 44:16–34; 创世记 49:8"> 雅各派犹大先到约瑟那里，在他前面指引去歌珊的路；他们就来到歌珊地。</span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 15:20; 创世记 45:14–15; 创世记 33:4"> 约瑟套好他的车，上歌珊去迎接他的父亲以色列。他来到父亲面前，伏在他的颈项上，在他的颈项上哭了许久。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 2:29–30; 创世记 45:28"> 以色列对约瑟说：“既然我见了你的面，知道你还活着，现在我可以死了。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="创世记 47:1–3; 希伯来书 2:11; 使徒行传 18:3"> 约瑟对他的兄弟们和他父亲的家说：“我要上去告诉法老，对他说：‘我的兄弟们和我父亲的家，原在迦南地的，都到我这里来了。</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 47:3; 列王纪上 9:27; 列王纪上 18:5–6"> 这些人是牧羊人，因为他们一直养牲畜；他们把羊群、牛群，以及所有的一切都带来了。’</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 46:32; 创世记 47:2–4; 约拿 1:8"> 到时候，法老召你们来，问：‘你们是做什么的？’</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 8:26; 创世记 43:32; 创世记 46:32"> 你们就要说：‘你的仆人们从幼年直到现在都是养牲畜的，我们和我们的祖先都是如此。’这样，你们就可以住在歌珊地；因为凡牧羊的，都为埃及人所厌恶。”</span>
</div>
</div>

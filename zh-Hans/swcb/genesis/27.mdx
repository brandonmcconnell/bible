<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 3:2; 创世记 48:10; 创世记 25:23–25"> 以撒年老了，眼睛昏花，不能看见，就叫了他的大儿子以扫来，对他说：“我儿？”<br />他对他说：“我在这里。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="雅各书 4:14; 传道书 9:10; 箴言 27:1"> 以撒说：“看哪，我已经老了，不知道我死的日子。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 25:27–28; 创世记 10:9; 哥林多前书 6:12"> 现在，请你拿你的武器，就是箭袋和弓，出去到田野，为我打些野味来。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 11:20; 创世记 48:9; 创世记 49:28"> 照我所爱的，为我做成美味，拿来给我吃，使我的灵魂在我死以前可以给你祝福。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 以撒对他儿子以扫说话的时候，利百加听见了。以扫往田野去打野味，要带回来。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 25:28"> 利百加对她儿子雅各说：“看哪，我听见你父亲对你哥哥以扫说：</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 6:26; 撒母耳记上 24:19; 申命记 33:1"> ‘你给我拿些野味来，做成美味，让我吃，好在我死以前，在耶和华面前给你祝福。’</span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 6:1; 创世记 27:13; 使徒行传 5:29"> 现在，我儿，要照我所吩咐你的，听从我的话。</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 13:15; 撒母耳记上 16:20"> 你现在到羊群那里去，从那里给我取两只肥好的山羊羔来；我就照你父亲所爱的，为他做成美味。</span>
<span className="v" id="v10" data-v="10"> 你要拿给你父亲吃，使他在死以前给你祝福。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="创世记 25:25"> 雅各对他母亲利百加说：“看哪，我哥哥以扫是有毛的人，我却是光滑的人。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 27:18; 创世记 25:27; 玛拉基书 1:14"> 万一我父亲摸我，我在他看来就会像个欺哄人的；我就要给自己招来咒诅，不是祝福。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马太福音 27:25; 撒母耳记上 25:24; 撒母耳记下 14:9"> 他母亲对他说：“我儿，你所受的咒诅归到我身上；你只管听从我的话，去给我取来。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="创世记 27:9; 箴言 23:2–3; 创世记 25:28"> 他就去取了，拿给他母亲；他母亲做成美味，正是他父亲所爱的。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 27:27; 路加福音 20:46; 路加福音 15:22"> 利百加把她大儿子以扫上好的衣服，就是在家里她那里放着的，拿来给她小儿子雅各穿上。</span>
<span className="v" id="v16" data-v="16"> 她又把山羊羔的皮包在他的手上和他颈项光滑的地方。</span>
<span className="v" id="v17" data-v="17"> 她把所做的美味和饼交在她儿子雅各手里。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 他来到父亲那里，说：“我父亲？”<br />他说：“我在这里。我儿，你是谁？”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 28:15; 马太福音 26:70–74; 撒迦利亚书 13:3–4"> 雅各对他父亲说：“我是以扫，你的长子。我已经照你吩咐我的做了。请起来坐着，吃我的野味，使你的灵魂可以给我祝福。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 20:7; 约伯记 13:7; 创世记 24:12"> 以撒对他儿子说：“我儿，你怎么这么快就找到了？”<br />他说：“因为耶和华你的上帝使我顺利得着。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="雅各书 4:8; 以赛亚书 57:19; 创世记 27:12"> 以撒对雅各说：“我儿，请你近前来，让我摸摸你，看你究竟是不是我的儿子以扫。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 雅各就近前来到他父亲以撒那里。以撒摸着他，说：“声音是雅各的声音，手却是以扫的手。”</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 27:16; 希伯来书 11:20; 罗马书 9:11–12"> 他没有认出他来，因为他的手有毛，像他哥哥以扫的手一样；于是他给他祝福。</span>
<span className="v" id="v24" data-v="24" data-xref="歌罗西书 3:9; 以弗所书 4:25; 箴言 12:22"> 他说：“你真是我的儿子以扫吗？”<br />他说：“我是。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v25" data-v="25" data-xref="创世记 27:4"> 他说：“拿近前来，我要吃我儿子的野味，使我的灵魂可以给你祝福。”<br />他就拿近前来，以撒吃了；又拿酒给他，他也喝了。</span>
<span className="v" id="v26" data-v="26"> 他父亲以撒对他说：“我儿，现在近前来，亲亲我。”</span>
<span className="v" id="v27" data-v="27" data-xref="希伯来书 6:7; 诗篇 65:10; 希伯来书 11:20"> 他就近前来亲了他。以撒闻到他衣服上的气味，就给他祝福，说：<br /><span className="pl pl-1">“看哪，我儿子的气味，</span><br /><span className="pl pl-2">如同耶和华所赐福的田地的气味。</span></span>
<span className="v" id="v28" data-v="28" data-xref="申命记 33:28; 申命记 33:13; 诗篇 133:3"> <span className="pl pl-1">愿上帝赐给你天上的甘露，</span><br /><span className="pl pl-2">地上的肥沃，</span><br /><span className="pl pl-2">并丰盛的五谷和新酒。</span></span>
<span className="v" id="v29" data-v="29" data-xref="创世记 12:3; 民数记 24:9; 以赛亚书 49:23"> <span className="pl pl-1">愿众民事奉你，</span><br /><span className="pl pl-2">愿万国向你下拜。</span><br /><span className="pl pl-1">愿你作你弟兄们的主。</span><br /><span className="pl pl-2">愿你母亲的儿子们向你下拜。</span><br /><span className="pl pl-1">凡咒诅你的，愿他受咒诅。</span><br /><span className="pl pl-2">凡祝福你的，愿他蒙祝福。”</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 以撒刚给雅各祝福完，雅各才从他父亲以撒面前出去，他哥哥以扫就打猎回来了。</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 27:4"> 他也做成美味，拿来给他父亲。他对父亲说：“请我父亲起来，吃你儿子的野味，使你的灵魂可以给我祝福。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="创世记 27:18"> 他父亲以撒对他说：“你是谁？”<br />他说：“我是你的儿子，你的长子以扫。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="创世记 28:3–4; 罗马书 11:29; 以弗所书 1:3"> 以撒就极其剧烈地颤抖，说：“那么，那打了野味拿来给我的人是谁呢？在你来以前，我已经吃了他拿来的一切，也给他祝福了。是的，他必蒙祝福。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="希伯来书 12:17; 箴言 1:31; 撒母耳记上 30:4"> 以扫听见他父亲的话，就放声痛哭，极其悲苦，对他父亲说：“我父亲啊，也给我祝福，连我也给我祝福吧！”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="帖撒罗尼迦前书 4:6; 约伯记 13:7; 玛拉基书 2:10"> 他说：“你弟弟用诡诈来了，已经把你的祝福夺去了。”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="创世记 25:26; 约翰福音 1:47; 创世记 32:28"> 以扫说：“他名叫雅各，岂不是正合适吗？他已经两次抓住我的脚跟，取代我了。他夺去了我的长子名分；看哪，现在又夺去了我的祝福。”他又说：“你没有为我留下一个祝福吗？”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="撒母耳记下 8:14; 创世记 27:28–29; 创世记 25:23"> 以撒回答以扫说：“看哪，我已经立他作你的主，也把他所有的弟兄都给他作仆人；我又用五谷和新酒供养他。我儿，现在我还能为你做什么呢？”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="希伯来书 12:17; 创世记 27:34; 以赛亚书 65:14"> 以扫对他父亲说：“我父亲啊，你只有一个祝福吗？我父亲啊，也给我祝福，连我也给我祝福吧！”以扫就放声而哭。</span>
</div>
<div className="bp poetry">
<span className="v" id="v39" data-v="39" data-xref="创世记 27:28; 希伯来书 11:20; 约书亚记 24:4"> 他父亲以撒回答他说：<br /><span className="pl pl-1">“看哪，你的住处必有地上的肥沃，</span><br /><span className="pl pl-1">也有从上而来天上的甘露。</span><br /></span>
<span className="v" id="v40" data-v="40" data-xref="列王纪下 8:20–22; 创世记 25:23; 历代志下 25:11–12"> <span className="pl pl-1">你必倚靠刀剑生活，也必事奉你的弟弟。</span><br /><span className="pl pl-1">到你挣脱的时候，</span><br /><span className="pl pl-1">你必从颈项上挣开他的轭。”</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="约翰一书 3:12–15; 创世记 37:4; 创世记 50:3–4"> 以扫因他父亲给雅各祝的福，就怨恨雅各。以扫心里说：“为我父亲居丧的日子近了；到那时，我要杀我的弟弟雅各。”</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="创世记 37:18–20; 撒母耳记上 30:5; 创世记 42:21–22"> 有人把她大儿子以扫的话告诉了利百加。她就差人叫来她小儿子雅各，对他说：“看哪，你哥哥以扫正打算杀你，借此安慰自己。</span>
<span className="v" id="v43" data-v="43" data-xref="创世记 27:8; 创世记 11:31; 创世记 27:13"> 现在，我儿，要听从我的话。起来，逃到哈兰我哥哥拉班那里去。</span>
<span className="v" id="v44" data-v="44" data-xref="创世记 31:38; 创世记 31:41"> 你要同他住些日子，直到你哥哥的怒气转消——</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 19:21; 创世记 4:8–16; 创世记 9:5–6"> 直到你哥哥向你发的怒气转消，他忘了你对他所做的事。那时我就差人去，把你从那里接回来。我为什么要在一天之内丧失你们两个人呢？”</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="创世记 24:3; 创世记 26:34–35; 创世记 28:8"> 利百加对以撒说：“我因赫人的女子厌烦我的生命。如果雅各也娶这样的赫人女子，就是这地的女子为妻，我活着还有什么益处呢？”</span>
</div>

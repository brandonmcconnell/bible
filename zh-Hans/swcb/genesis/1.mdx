<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="GEN" data-book-slug="genesis" data-book-name="创世记" data-chapter="1" data-verses="31">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 1:1–3; 希伯来书 11:3; 以赛亚书 45:18"> 起初，上帝<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="译作“上帝”的希伯来词是“אֱלֹהִ֑ים”（Elohim）。">a</a></sup>创造了天和地。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 4:23; 诗篇 104:30; 以赛亚书 45:18"> 地是混沌空虚的。黑暗在深渊的表面，上帝的灵盘旋在水面上。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 4:6; 约翰福音 1:5; 以赛亚书 45:7"> 上帝说：“要有光。”就有了光。</span>
<span className="v" id="v4" data-v="4" data-xref="传道书 2:13; 创世记 1:18; 传道书 11:7"> 上帝看光，看见光是好的。上帝把光和黑暗分开。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 74:16; 以赛亚书 45:7; 帖撒罗尼迦前书 5:5"> 上帝称光为“昼”，称黑暗为“夜”。有晚上，有早晨，这是第一日。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="耶利米书 51:15; 诗篇 33:6; 约伯记 37:18"> 上帝说：“众水之间要有穹苍，把水和水分开。”</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 8:28–29; 诗篇 148:4; 马太福音 8:27"> 上帝造了穹苍，把穹苍以下的水和穹苍以上的水分开；事情就这样成了。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 1:5; 创世记 1:19; 创世记 1:10"> 上帝称穹苍为“天空”。有晚上，有早晨，这是第二日。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="彼得后书 3:5; 约拿 1:9; 耶利米书 5:22"> 上帝说：“天空以下的水要聚集到一处，使干地显露出来。”事情就这样成了。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 32:4; 诗篇 104:31; 创世记 1:4"> 上帝称干地为“地”，称水聚集的地方为“海”。上帝看见这是好的。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 104:14–17; 希伯来书 6:7; 诗篇 147:8"> 上帝说：“地要长出青草、结种子的菜蔬，以及按着各自种类结果子的果树，果子里有种子，在地上。”事情就这样成了。</span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 4:28; 以赛亚书 55:10–11; 马太福音 13:24–26"> 地长出了青草，和按着各自种类结种子的菜蔬，以及按着各自种类结果子的树，果子里有种子；上帝看见这是好的。</span>
<span className="v" id="v13" data-v="13"> 有晚上，有早晨，这是第三日。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="诗篇 104:19–20; 申命记 4:19; 耶利米书 31:35"> 上帝说：“天空的穹苍中要有光体，把昼和夜分开；它们要作为记号，标明节令、日子和年岁；</span>
<span className="v" id="v15" data-v="15"> 它们要在天空的穹苍中发光，照耀地上。”事情就这样成了。</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 136:7–9; 申命记 4:19; 诗篇 8:3"> 上帝造了两个大光体：较大的光体管理白昼，较小的光体管理黑夜。祂也造了众星。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 8:3; 诗篇 8:1; 约伯记 38:12"> 上帝把它们安置在天空的穹苍中，照耀地上，</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 31:35; 诗篇 19:6"> 管理白昼和黑夜，并把光和黑暗分开。上帝看见这是好的。</span>
<span className="v" id="v19" data-v="19"> 有晚上，有早晨，这是第四日。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 2:19; 诗篇 104:24–25; 列王纪上 4:33"> 上帝说：“水中要充满有生命的活物，鸟要在地以上、天空的穹苍中飞翔。”</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 104:24–26; 创世记 1:25; 创世记 8:19"> 上帝创造了大海兽，以及水中滋生的、各样能活动的活物，都是按着各自的种类；又创造了各样有翅膀的鸟，都是按着各自的种类。上帝看见这是好的。</span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 40:15; 创世记 8:17; 诗篇 107:38"> 上帝赐福给它们，说：“要繁殖增多，充满海中的水；鸟也要在地上增多。”</span>
<span className="v" id="v23" data-v="23"> 有晚上，有早晨，这是第五日。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="诗篇 50:9–10; 创世记 6:20; 创世记 8:19"> 上帝说：“地要生出有生命的活物，各从其类：牲畜、爬行动物，和地上的野兽，各从其类。”事情就这样成了。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 27:5; 约伯记 12:8–10; 创世记 2:19–20"> 上帝造了地上的野兽，各从其类；牲畜，各从其类；以及一切在地上爬行的动物，各从其类。上帝看见这是好的。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="歌罗西书 3:10; 以弗所书 4:24; 诗篇 8:4–8"> 上帝说：“我们要照着我们的形象，按着我们的样式造人。让他们管理海里的鱼、天空的鸟、牲畜、全地，以及地上一切爬行的动物。”</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 19:4; 以弗所书 2:10; 创世记 5:1–2"> 上帝就照着祂自己的形象创造了人。祂照着上帝的形象创造了他；祂创造了他们，有男有女。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 9:1; 创世记 9:7; 利未记 26:9"> 上帝赐福给他们。上帝对他们说：“要繁殖增多，充满这地，制伏它；也要管理海里的鱼、天空的鸟，和地上各样活动的活物。”</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 9:3; 诗篇 104:14–15; 诗篇 145:15–16"> 上帝说：“看哪，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“看哪”来自“הִנֵּה”，意思是看、留意、观察、看见或注视。它常用作感叹词。">b</a></sup>我已把全地表面上一切结种子的菜蔬，和一切结果子的树，就是果子里有种子的树，都赐给你们；它们要作你们的食物。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 104:14; 诗篇 145:15–16; 诗篇 147:9"> 至于地上的各样野兽、天空的各样鸟，以及地上一切爬行的、有生命的动物，我把各样绿色植物赐给它们作食物。”事情就这样成了。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="提摩太前书 4:4; 诗篇 104:24; 诗篇 19:1–2"> 上帝看祂所造的一切，看哪，都非常好。有晚上，有早晨，这是第六日。</span>
</div>
</div>

</div>

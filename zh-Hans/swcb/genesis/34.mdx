<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 30:21; 耶利米书 2:36; 创世记 30:13"> 利亚给雅各所生的女儿底拿出去，要看那地的女子们。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 5:28; 约伯记 31:1; 约伯记 31:9"> 那地的首领，希未人哈抹的儿子示剑看见她，就拉住她，与她同寝，玷辱了她。</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿 2:14; 以赛亚书 40:2; 历代志下 30:22"> 他的心依恋雅各的女儿底拿；他爱这少女，并温言安慰她。</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 14:2; 撒母耳记下 13:13; 创世记 21:21"> 示剑对他父亲哈抹说：“请给我娶这少女为妻。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 13:22; 利未记 10:3; 撒母耳记上 10:27"> 雅各听见示剑玷污了他的女儿底拿；那时他的儿子们正和牲畜在田野。雅各就默不作声，等他们回来。</span>
<span className="v" id="v6" data-v="6"> 示剑的父亲哈抹出来见雅各，要和他商谈。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 7:15; 士师记 20:6; 申命记 22:21"> 雅各的儿子们听见这事，就从田野回来。这些人忧伤，又十分愤怒，因为示剑与雅各的女儿同寝，在以色列中做了愚妄的事，这是不该做的。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 11:2; 诗篇 119:20; 诗篇 84:2"> 哈抹同他们商谈，说：“我儿子示剑的心恋慕你们的女儿。请把她给他为妻。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 7:3; 创世记 26:34–35; 创世记 19:14"> 你们与我们通婚吧。把你们的女儿给我们，也为自己娶我们的女儿。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 20:15; 创世记 47:27; 创世记 42:34"> 你们可以与我们同住；这地就在你们面前。你们可以住在这里，做买卖，并在这里置产业。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="创世记 33:15; 创世记 18:3"> 示剑对底拿的父亲和兄弟们说：“愿我在你们眼前蒙恩；你们向我要什么，我都给。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 22:16–17; 申命记 22:28–29; 撒母耳记上 18:25–27"> 你们尽管向我要重重的聘金，我必照你们所说的给；只要把这少女给我为妻。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 25:27–34; 以赛亚书 59:13; 约伯记 13:4"> 雅各的儿子们因为示剑玷污了他们的妹妹底拿，就用诡诈的话回答示剑和他父亲哈抹，</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 23:1–39; 撒母耳记下 15:7; 创世记 17:11"> 对他们说：“我们不能做这事，把我们的妹妹给一个未受割礼的人，因为那是我们的耻辱。</span>
<span className="v" id="v15" data-v="15" data-xref="加拉太书 4:12"> 只有在这条件下，我们才会同意你们：你们要像我们一样，使你们中间所有的男丁都受割礼。</span>
<span className="v" id="v16" data-v="16"> 这样，我们就把我们的女儿给你们，也为我们自己娶你们的女儿；我们要与你们同住，成为一个民族。</span>
<span className="v" id="v17" data-v="17"> 但如果你们不听从我们，不受割礼，我们就带走我们的妹妹，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="希伯来文直译为“女儿”">a</a></sup>离开。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 他们的话使哈抹和哈抹的儿子示剑满意。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 17:12; 使徒行传 13:50; 撒母耳记上 22:14"> 那少年人不迟延去做这事，因为他喜爱雅各的女儿；他在他父亲全家中是最受尊荣的。</span>
<span className="v" id="v20" data-v="20" data-xref="路得记 4:1; 箴言 31:23; 阿摩司 5:12"> 哈抹和他儿子示剑来到他们城门口，对本城的人说：</span>
<span className="v" id="v21" data-v="21"> “这些人与我们和睦，所以让他们住在这地，在这里做买卖吧。看哪，这地足够宽广，可以容纳他们。我们可以娶他们的女儿为妻，也把我们的女儿给他们。</span>
<span className="v" id="v22" data-v="22"> 只有在这条件下，这些人才会同意与我们同住，成为一个民族：就是我们中间所有的男丁都受割礼，像他们受割礼一样。</span>
<span className="v" id="v23" data-v="23" data-xref="箴言 1:12–13; 约翰福音 6:26–27; 约翰福音 2:16"> 他们的群畜、财物和一切牲口，岂不都要归我们吗？只要我们同意他们，他们就会与我们同住。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="创世记 23:10; 哥林多前书 7:19; 以赛亚书 1:10–16"> 凡从他城门出去的人都听从哈抹和他儿子示剑；凡从他城门出去的男丁都受了割礼。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 49:5–7; 创世记 29:33–34; 民数记 31:7"> 到第三天，他们正疼痛的时候，雅各的两个儿子，就是底拿的兄弟西缅和利未，各自拿着刀，趁城里的人毫无防备，来到城中，杀了所有男丁。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 2:26; 申命记 32:42; 以赛亚书 31:8"> 他们用刀刃杀了哈抹和他的儿子示剑，把底拿从示剑家里带出来，就走了。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 7:13; 约书亚记 7:21; 出埃及记 2:14"> 雅各的儿子们来到被杀的人那里，掠夺那城，因为他们玷污了他们的妹妹。</span>
<span className="v" id="v28" data-v="28" data-xref="约伯记 1:15–16; 申命记 8:17–18; 约伯记 20:5"> 他们夺了他们的羊群、牛群、驴，以及城里和田野里的一切；</span>
<span className="v" id="v29" data-v="29"> 又夺了他们所有的财富，掳走他们所有的孩子和妻子，并把屋里的一切都掠夺了。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 105:12; 约书亚记 7:25; 出埃及记 5:21"> 雅各对西缅和利未说：“你们连累了我，使我在这地的居民中，就是迦南人和比利洗人中，成了可憎恶的人。我的人数稀少，他们必聚集起来攻击我，击杀我；我和我的家都要灭亡。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="箴言 6:34; 创世记 34:13; 创世记 49:7"> 他们说：“他岂可待我们的妹妹如同妓女吗？”</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 30:22; 创世记 19:29; 诗篇 136:23"> 上帝记念挪亚和所有与他一同在方舟里的走兽、牲畜；上帝使风吹过大地，水就退落。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 7:11; 马太福音 8:26–27; 箴言 8:28"> 深渊的泉源和天上的窗户也都关闭了，天上的雨也止住了。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 7:24; 创世记 7:11"> 水不断从地上退去；过了一百五十天，水退落了。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 19:37; 耶利米书 51:27; 以赛亚书 37:38"> 七月十七日，方舟停在亚拉腊群山上。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 7:11"> 水继续退去，直到十月。十月初一，山顶都显露出来。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 6:16; 但以理 6:10"> 过了四十天，挪亚打开他所造方舟的窗户，</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 147:9; 列王纪上 17:6; 列王纪上 17:4"> 放出一只乌鸦；它飞来飞去，直到地上的水都干了。</span>
<span className="v" id="v8" data-v="8" data-xref="雅歌 2:14; 雅歌 1:15; 马太福音 10:16"> 他又亲自放出一只鸽子，要看看水是否已经从地面退去；</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 11:28; 诗篇 116:7; 申命记 28:65"> 但鸽子找不到落脚之处，就回到方舟里，到他那里，因为水仍在全地面上。他伸手把鸽子接住，带进方舟到自己那里。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 7:4; 创世记 7:10; 创世记 8:12"> 他又等了另外七天，再次把鸽子从方舟里放出去。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 8:15; 撒迦利亚书 4:12–14; 罗马书 10:15"> 到了傍晚，鸽子回到他那里；看哪，它嘴里叼着一片新摘下来的橄榄叶。挪亚就知道水已经从地上退去了。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 25:9; 以赛亚书 30:18; 创世记 8:10"> 他又等了另外七天，放出鸽子；鸽子就不再回到他那里了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 7:11"> 到第六百零一年，正月初一，地上的水都干了。挪亚揭开方舟的盖观看；他看见地面已经干了。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 7:13–14; 创世记 7:11"> 到二月二十七日，地就干了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 上帝对挪亚说：</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 7:13; 诗篇 121:8; 诗篇 91:11"> “你和你的妻子、你的儿子、你儿子的妻子，都要从方舟里出来。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 1:22; 创世记 9:1; 耶利米书 31:27–28"> 凡与你同在的一切有血肉的活物，包括飞鸟、牲畜，以及地上一切爬行的爬行动物，你都要带出来，使它们在地上大量滋生，在地上繁衍增多。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="诗篇 121:8"> 于是挪亚和他的儿子、妻子、儿媳都一同出来了。</span>
<span className="v" id="v19" data-v="19"> 所有走兽、所有爬行动物、所有飞鸟，以及地上一切活动的生物，都各按其类，从方舟里出来了。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="希伯来书 13:15–16; 罗马书 12:1; 创世记 22:9"> 挪亚为耶和华筑了一座祭坛，从各样洁净的走兽和各样洁净的飞鸟中取来，献在祭坛上作燔祭。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多后书 2:15; 以弗所书 5:2; 以赛亚书 54:9–10"> 耶和华闻了那怡人的香气。耶和华心里说：“我不再因人的缘故咒诅土地，因为人心里的意念从小就是恶的；我也不再照我所行的，击杀一切活物。</span>
<span className="v" id="v22" data-v="22" data-xref="雅各书 5:7; 诗篇 74:16–17; 耶利米书 5:24"> 大地还存在的时候，播种和收割、寒冷和炎热、夏天和冬天、白昼和黑夜，都不会止息。”</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 6:3; 士师记 6:33; 何西阿 12:12"> 雅各继续上路，来到东方人的地方。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 4:14; 以赛亚书 49:10; 约翰福音 4:6"> 他观看，看见田野里有一口井，又见有三群羊卧在井旁；因为人们都从那口井给羊群喝水。井口上的石头很大。</span>
<span className="v" id="v3" data-v="3"> 羊群都聚集在那里；人们就把石头从井口滚开，给羊喝水，然后把石头放回井口原处。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 28:10; 创世记 27:43; 使徒行传 7:2"> 雅各对他们说：“我的弟兄们，你们从哪里来？”<br />他们说：“我们从哈兰来。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 24:24; 创世记 24:29; 创世记 31:53"> 他对他们说：“你们认识拿鹤的儿子拉班吗？”<br />他们说：“我们认识。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 20:9; 创世记 37:14; 出埃及记 18:7"> 他对他们说：“他平安吗？”<br />他们说：“平安。看哪，他的女儿拉结正带着羊来。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以弗所书 5:16; 加拉太书 6:9–10"> 他说：“看哪，现在还是正午，还不到牲畜聚集的时候。你们给羊喝水，然后去放牧吧。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="马可福音 16:3; 路加福音 24:2; 创世记 34:14"> 他们说：“我们不能，必须等到所有羊群都聚集起来，人们把石头从井口滚开，然后我们才给羊喝水。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 2:21; 雅歌 1:7–8; 出埃及记 2:15–16"> 雅各还在同他们说话的时候，拉结带着她父亲的羊来了，因为这些羊是她牧放的。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 2:17"> 雅各看见他母亲的兄弟拉班的女儿拉结，又看见他母亲的兄弟拉班的羊，就走近前去，把石头从井口滚开，给他母亲的兄弟拉班的羊群喝水。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 33:4; 创世记 45:14–15; 创世记 45:2"> 雅各亲吻拉结，放声而哭。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 24:28; 创世记 13:8; 创世记 14:14–16"> 雅各告诉拉结，自己是她父亲的亲族，是利百加的儿子。她就跑去告诉她父亲。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 24:29; 使徒行传 20:37; 罗马书 16:16"> 拉班听见他姐姐的儿子雅各的消息，就跑去迎接他，抱着他，亲吻他，带他到自己家里。雅各把这一切事都告诉了拉班。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 19:12–13; 创世记 2:23; 士师记 9:2"> 拉班对他说：“你实在是我的骨，我的肉。”雅各就和他同住了一个月。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 30:28; 创世记 31:7"> 拉班对雅各说：“你虽然是我的亲族，难道就该白白服侍我吗？告诉我，你要什么工价？”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路得记 4:11; 创世记 49:31; 创世记 31:4"> 拉班有两个女儿，长女名叫利亚，次女名叫拉结。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 12:11; 创世记 46:19–22; 创世记 24:16"> 利亚的眼睛柔弱，拉结却体态美丽，容貌秀丽。</span>
<span className="v" id="v18" data-v="18" data-xref="何西阿 12:12; 出埃及记 22:16–17; 创世记 34:12"> 雅各爱拉结，就说：“我愿为你服侍七年，为要娶你的次女拉结。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 6:11; 以赛亚书 6:5; 诗篇 12:2"> 拉班说：“我把她给你，胜过把她给别人。你与我同住吧。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 13:7; 以弗所书 5:2; 何西阿 12:12"> 雅各为了拉结服侍了七年；因为他爱她，这七年在他看来不过像几天。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="士师记 15:1; 创世记 29:20; 创世记 4:1"> 雅各对拉班说：“我的日期已经满了，请把我的妻子给我，好让我与她同房。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="启示录 19:9; 路得记 4:10–13; 士师记 14:10–18"> 拉班就聚集当地所有的人，摆设筵席。</span>
<span className="v" id="v23" data-v="23" data-xref="弥迦书 7:5; 创世记 38:14–15; 创世记 24:65"> 到了晚上，拉班把女儿利亚带来给雅各，雅各就与她同房。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 16:1; 创世记 30:9–12; 创世记 46:18"> 拉班又把自己的婢女悉帕给女儿利亚作婢女。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 7:2; 箴言 11:31; 哥林多前书 3:13"> 到了早晨，看哪，竟是利亚！雅各对拉班说：“你向我做的这是什么事？我服侍你，不是为了拉结吗？你为什么欺骗我？”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 拉班说：“在我们这里，没有把小女儿先给人，而把长女留后的规矩。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 18:18; 士师记 14:12; 创世记 2:2–3"> 你为这一个满了七日婚期，我们就把那一个也给你；为此你要再服侍我七年。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 雅各就这样做，满了利亚的七日婚期。拉班把女儿拉结也给他作妻子。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 35:22; 创世记 29:24; 创世记 30:3–8"> 拉班又把自己的婢女辟拉给女儿拉结作婢女。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 31:41; 创世记 29:20; 创世记 31:15"> 雅各也与拉结同房，并且爱拉结胜过爱利亚，又服侍拉班七年。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒母耳记上 2:21; 马太福音 10:37; 申命记 21:15"> 耶和华看见利亚被厌弃，就使她能生育；拉结却不能生育。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 26:7; 出埃及记 4:31; 出埃及记 3:7"> 利亚怀孕，生了一个儿子，给他起名叫流便；因为她说：“耶和华看见了我的苦情；如今我的丈夫必爱我。”</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 34:25; 创世记 49:5–6; 创世记 34:30"> 她又怀孕，生了一个儿子，说：“耶和华听见我被厌弃，所以又赐给我这个儿子。”于是她给他起名叫西缅。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 32:26–29; 创世记 49:5–7; 创世记 46:11"> 她又怀孕，生了一个儿子。她说：“这一次，我的丈夫必与我联合，因为我给他生了三个儿子。”因此他的名字叫利未。</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 1:2; 历代志上 5:2; 创世记 49:8–12"> 她又怀孕，生了一个儿子。她说：“这一次，我要赞美耶和华。”因此她给他起名叫犹大。此后她停止生育。</span>
</div>
</div>

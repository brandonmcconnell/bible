<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 32:6–7; 创世记 27:41–42; 创世记 32:16"> 雅各举目观看，看哪，以扫来了，和他同来的有四百人。雅各就把孩子们分给利亚、拉结和两个婢女。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 29:30; 创世记 30:22–24; 创世记 37:3"> 他把婢女和她们的孩子放在前面，利亚和她的孩子在后面，拉结和约瑟在最后。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 42:6; 路加福音 14:11; 创世记 18:2"> 他自己走在他们前头，七次俯伏在地，直到走近他哥哥。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="创世记 45:14–15; 诗篇 34:4; 路加福音 15:20"> 以扫跑来迎接他，抱住他，伏在他的颈项上亲吻他，他们就哭了。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 127:3; 以赛亚书 8:18; 创世记 48:9"> 以扫举目看见妇人和孩子，就说：“这些和你在一起的人是谁？”<br />雅各说：“这些孩子是上帝施恩赐给你仆人的。”</span>
<span className="v" id="v6" data-v="6"> 于是婢女们和她们的孩子走近前来，俯伏下拜。</span>
<span className="v" id="v7" data-v="7"> 利亚和她的孩子也走近前来，俯伏下拜。随后，约瑟和拉结走近前来，也俯伏下拜。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="创世记 32:5; 创世记 39:5; 创世记 32:13–20"> 以扫说：“我所遇见的这一大群是什么意思？”<br />雅各说：“是为要在我主眼前蒙恩。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 27:39; 腓利门书 1:7; 创世记 27:41"> 以扫说：“我的兄弟，我已经够了；你的仍归你吧。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约伯记 33:26; 启示录 22:4; 创世记 32:30"> 雅各说：“不，请不要这样；我若如今在你眼前蒙恩，就请从我手里收下我的礼物，因为我见了你的面，如同见了上帝的面，而且你悦纳了我。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 25:27; 腓立比书 4:18; 创世记 30:43"> 请收下我带给你的礼物，因为上帝恩待了我，并且我已经够了。”雅各再三劝他，他就收下了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 以扫说：“我们起行走吧；我在你前头走。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 40:11; 以西结 34:15–16; 以西结 34:23–25"> 雅各对他说：“我主知道孩子们年幼娇弱，跟着我的羊群牛群也正在哺乳；如果催赶它们一天，所有的羊群都会死。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 32:3; 以赛亚书 40:11; 罗马书 15:1"> 请我主在仆人前头先走；我要按着我前面牲畜的步伐和孩子们的步伐，慢慢前行，直到我到西珥我主那里。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路得记 2:13; 创世记 47:25; 创世记 34:11"> 以扫说：“请让我把跟随我的人留几个在你这里。”<br />雅各说：“何必呢？愿我在我主眼前蒙恩。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 于是，以扫当天就起程回西珥去了。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 60:6; 约书亚记 13:27; 士师记 8:5"> 雅各却往疏割去，为自己建造房屋，又为牲畜搭棚。因此那地方名叫疏割。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="疏割的意思是“棚子”或“棚屋”。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="士师记 9:1; 使徒行传 7:16; 约书亚记 24:1"> 雅各从巴旦·亚兰回来，平安地到了迦南地的示剑城，在城前安营。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 7:16; 约翰福音 4:5; 约书亚记 24:32"> 他向示剑的父亲哈抹的子孙，用一百块银钱买了他支搭帐棚的那块地。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 35:7; 创世记 21:33; 创世记 32:28"> 他在那里筑了一座祭坛，称它为伊勒·伊罗伊·以色列。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="伊勒·伊罗伊·以色列的意思是“上帝，以色列的上帝”，或“以色列的上帝是大能的”。">b</a></sup></span>
</div>
</div>

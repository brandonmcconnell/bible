<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 14:13; 创世记 48:3; 创世记 13:18"> 耶和华在幔利的橡树那里向他显现；那时，正是一天最热的时候，他坐在帐棚门口。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 13:2; 创世记 18:22; 创世记 19:1"> 他举目观看，看见有三个人站在他附近。他一看见，就从帐棚门口跑去迎接他们，俯伏在地，</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 32:5"> 说：“我主啊，我若在你眼前蒙恩，请不要从你仆人这里过去。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 24:32; 创世记 19:2; 创世记 43:24"> 请让人取一点水来，你们洗洗脚，在树下歇息。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 104:15; 士师记 13:15; 士师记 6:18"> 我去拿一点饼来，好让你们恢复精神，然后你们再上路；既然你们来到你仆人这里，就这样吧。”<br />他们说：“好，就照你说的做吧。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="马太福音 13:33; 希伯来书 13:2; 使徒行传 16:15"> 亚伯拉罕急忙进帐棚去见撒拉，说：“快拿三细亚<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="1细亚约为7升、1.9加仑或0.8配克。">a</a></sup>细面调和，做饼。”</span>
<span className="v" id="v7" data-v="7" data-xref="玛拉基书 1:14; 路加福音 15:27; 路加福音 15:30"> 亚伯拉罕又跑到牛群里，牵了一头又嫩又好的牛犊，交给仆人；仆人就赶快把它预备好。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 19:3; 士师记 13:15; 启示录 3:20"> 亚伯拉罕取了凝乳、奶和预备好的牛犊，摆在他们面前；他在树下侍立在他们旁边，他们就吃了。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="提多书 2:5; 创世记 24:67; 创世记 4:9"> 他们问他说：“你的妻子撒拉在哪里？”<br />他说：“在那边，帐棚里。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 21:2; 创世记 17:21; 罗马书 9:8–9"> 祂说：“到明年这时候，我必回到你这里；看哪，你的妻子撒拉会有一个儿子。”<br />撒拉在帐棚门口听见了；帐棚门就在祂身后。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 17:17; 希伯来书 11:11–12; 路加福音 1:36"> 亚伯拉罕和撒拉年纪都老迈了，撒拉已经过了生育的年龄。</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 3:6; 创世记 17:17; 路加福音 1:18–20"> 撒拉心里笑了，说：“我既已衰老，我主也老了，还会有这乐事吗？”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约翰福音 2:25"> 耶和华对亚伯拉罕说：“撒拉为什么笑，说：‘我既然老了，真的还能生孩子吗？’</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 1:37; 马太福音 19:26; 马可福音 10:27"> 耶和华岂有难成的事吗？到了所定的时候，明年这时节，我必回到你这里，撒拉会有一个儿子。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰一书 1:8; 箴言 28:13; 以弗所书 4:23"> 撒拉因为害怕，就否认说：“我没有笑。”<br />祂说：“不，你确实笑了。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行传 15:3; 使徒行传 21:5; 使徒行传 20:38"> 那几个人从那里起身，向所多玛眺望；亚伯拉罕也与他们同行，要送他们一程。</span>
<span className="v" id="v17" data-v="17" data-xref="阿摩司 3:7; 诗篇 25:14; 约翰福音 15:15"> 耶和华说：“我所要做的事，岂可向亚伯拉罕隐瞒呢？</span>
<span className="v" id="v18" data-v="18" data-xref="加拉太书 3:8; 创世记 26:4; 加拉太书 3:14"> 亚伯拉罕必定成为又大又强的国，地上的万国都必因他蒙福。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 6:6–7; 申命记 4:9–10; 提摩太前书 3:4–5"> 因为我已认定他，为要使他吩咐自己的儿女和他以后的家人，谨守耶和华的道，行公义和公正；好使耶和华把祂论到亚伯拉罕所说的话成就在他身上。”</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 19:13; 以西结 16:49–50; 以赛亚书 3:9"> 耶和华说：“所多玛和蛾摩拉的呼声甚大，他们的罪恶极其严重，</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 3:8; 创世记 11:5; 西番雅书 1:12"> 我现在要下去，看看他们的所作所为，是否像传到我这里的呼声那样恶劣；若不是，我也要知道。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="创世记 19:1; 使徒行传 7:55; 以西结 22:30"> 那几个人转身离开那里，往所多玛去；亚伯拉罕却仍站在耶和华面前。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 16:22; 撒母耳记下 24:17; 创世记 20:4"> 亚伯拉罕近前来，说：“你真的要把义人与恶人一同灭绝吗？</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 5:1; 以赛亚书 1:9; 马太福音 7:13–14"> 假若城里有五十个义人呢？你还要灭绝那地方，不为城里的五十个义人饶恕它吗？</span>
<span className="v" id="v25" data-v="25" data-xref="约伯记 8:3; 以赛亚书 3:10–11; 约伯记 8:20"> 愿你绝不做这样的事，把义人与恶人一同杀死，使义人与恶人一样。愿你绝不如此！审判全地的那一位，岂不行公正吗？”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="耶利米书 5:1; 马太福音 24:22; 以赛亚书 65:8"> 耶和华说：“我若在所多玛城里找到五十个义人，我就为他们的缘故饶恕整个地方。”</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 3:19; 以赛亚书 6:5; 哥林多前书 15:47–48"> 亚伯拉罕回答说：“看哪，我虽然不过是尘土和灰烬，还冒昧对主说话。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 18:29; 列王纪上 20:32–33; 创世记 18:26"> 假若五十个义人少了五个呢？你会因少了五个就毁灭全城吗？”<br />祂说：“我若在那里找到四十五个，就不毁灭它。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以弗所书 6:18; 希伯来书 4:16"> 亚伯拉罕又对祂说：“假若在那里找到四十个呢？”<br />祂说：“为了这四十个的缘故，我也不这样做。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="诗篇 89:7; 诗篇 9:12; 以斯帖记 4:11–16"> 亚伯拉罕说：“愿主不要发怒，我还要说。假若在那里找到三十个呢？”<br />祂说：“我若在那里找到三十个，就不这样做。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 11:8; 创世记 18:27; 路加福音 18:1"> 亚伯拉罕说：“看哪，我还冒昧对主说话。假若在那里找到二十个呢？”<br />祂说：“为了这二十个的缘故，我也不毁灭它。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="雅各书 5:15–17; 士师记 6:39; 马太福音 7:7"> 亚伯拉罕说：“愿主不要发怒，我只再说这一次。假若在那里找到十个呢？”<br />祂说：“为了这十个的缘故，我也不毁灭它。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="创世记 18:22; 创世记 32:26; 创世记 31:55"> 耶和华与亚伯拉罕说完话，就离去了；亚伯拉罕也回到自己的地方。</span>
</div>
</div>

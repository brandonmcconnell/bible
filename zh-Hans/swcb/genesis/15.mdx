<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 41:10; 诗篇 119:114; 诗篇 84:11"> 这些事以后，耶和华的话在异象中临到亚伯兰，说：“亚伯兰，不要惧怕。我是你的盾牌，是你极大的赏赐。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="创世记 25:21; 使徒行传 7:5; 创世记 12:1–3"> 亚伯兰说：“主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="译为“主”的词是“Adonai”。">a</a></sup>耶和华啊，你要赐给我什么呢？我既然没有孩子，承受我产业的却是大马士革人以利以谢。”</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 14:14; 箴言 29:21; 传道书 2:7"> 亚伯兰又说：“看哪，你没有赐给我后裔；看哪，生在我家中的人要作我的继承人。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="创世记 17:16; 加拉太书 4:28; 撒母耳记下 7:12"> 看哪，耶和华的话临到他，说：“这人必不作你的继承人；从你亲身所出的，才要作你的继承人。”</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 11:12; 罗马书 4:18; 申命记 1:10"> 耶和华带他到外面，说：“你现在向天观看，数算众星，若是你能数得过来。”又对亚伯兰说：“你的后裔也将这样。”</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 2:23; 加拉太书 3:6–14; 罗马书 4:9"> 亚伯兰信耶和华，耶和华就把这算为他的义。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 12:1; 使徒行传 7:2–4; 罗马书 4:13"> 祂对亚伯兰说：“我是耶和华，曾领你出了迦勒底的吾珥，为要把这地赐给你承受。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 1:18; 路加福音 1:34; 以赛亚书 7:11"> 他说：“主耶和华啊，我怎能知道我必承受这地呢？”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 2:24; 利未记 14:30; 利未记 14:22"> 祂对他说：“你为我取一头三岁的母牛，一只三岁的母山羊，一只三岁的公绵羊，一只斑鸠和一只雏鸽来。”</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 34:18–19; 利未记 1:17; 创世记 15:17"> 亚伯兰就把这些都取来，劈成两半，把每半块彼此相对摆放；只是鸟没有劈开。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 13:4; 诗篇 119:13; 以西结 17:3"> 有猛禽落在那些尸体上，亚伯兰就把它们赶走。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 2:21; 约伯记 33:15; 但以理 10:8–9"> 太阳将落的时候，亚伯兰沉沉睡去；看哪，恐惧和极大的黑暗临到他。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 7:6–7; 出埃及记 1:11; 出埃及记 12:40–41"> 祂对亚伯兰说：“你要确实知道，你的后裔必寄居在不属于他们的土地上，并要服侍那里的人；他们必苦待你的后裔四百年。</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 9:9–11; 出埃及记 6:5–6; 出埃及记 12:32–38"> 他们所服侍的那国，我也要审判。后来他们必带着许多财物出来；</span>
<span className="v" id="v15" data-v="15" data-xref="约伯记 5:26; 创世记 25:7–9; 历代志下 34:28"> 至于你，你要平平安安地归到你列祖那里，到了美好的老年才被埋葬。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 21:26; 但以理 8:23; 出埃及记 12:40"> 到了第四代，他们必再回到这里，因为亚摩利人的罪孽还没有满盈。”</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 34:18–19; 士师记 6:21; 耶利米书 11:4"> 太阳落下，天黑了；看哪，有冒烟的炉和燃烧的火把从这些肉块中间经过。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 1:3–4; 创世记 12:7; 创世记 24:7"> 那日，耶和华与亚伯兰立约，说：“我已将这地赐给你的后裔，从埃及河直到那大河，就是幼发拉底河：</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 24:21–22"> 就是基尼人、基尼洗人、甲摩尼人、</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 17:5; 创世记 14:5"> 赫人、比利洗人、利乏音人、</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 10:15–19; 出埃及记 23:23–28; 申命记 7:1"> 亚摩利人、迦南人、革迦撒人和耶布斯人的地。”</span>
</div>

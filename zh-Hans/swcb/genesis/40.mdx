<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 40:13; 创世记 39:20–23; 以斯帖记 6:1"> 这些事以后，埃及王的酒政和膳长得罪了他们的主——埃及王。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 16:14; 箴言 19:12; 诗篇 76:10"> 法老向他的两个官员，就是酒政长和膳长发怒。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 39:20; 创世记 39:23"> 他把他们拘禁在护卫长的府中，关进监牢，就是约瑟被囚的地方。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 39:1; 诗篇 37:5; 创世记 37:36"> 护卫长把他们交给约瑟，约瑟就服侍他们。他们在监里过了许多日子。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 41:11; 创世记 40:8; 创世记 37:5–10"> 他们二人，就是被囚在监里的埃及王的酒政和膳长，同一夜各做了一个梦，各人的梦各有讲解。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 41:8; 但以理 2:1–3; 创世记 40:8"> 早晨，约瑟进到他们那里，看见他们，见他们面带愁容。</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米记 2:2; 撒母耳记上 1:8; 路加福音 24:17"> 他就问法老的官员，就是和他一同被拘禁在他主人府中的人，说：“你们今天为什么脸色这样忧愁？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="但以理 2:47; 创世记 41:15–16; 但以理 2:28"> 他们对他说：“我们做了一个梦，却没有人能解。”<br />约瑟对他们说：“解梦不是属于上帝吗？请把梦告诉我。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="士师记 7:13–15; 创世记 37:5–10; 但以理 4:8"> 酒政长把他的梦告诉约瑟，对他说：“我梦见，看哪，有一棵葡萄树在我面前，</span>
<span className="v" id="v10" data-v="10"> 树上有三根枝子。它好像发了芽，开了花，枝上的葡萄都成熟了。</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 1:11–1; 列王纪上 10:5; 历代志下 9:4"> 法老的杯在我手中；我摘下葡萄，挤在法老的杯里，把杯递在法老手中。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 41:12; 士师记 7:14; 创世记 41:25–26"> 约瑟对他说：“这梦的讲解是这样：三根枝子就是三天。</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 3:3; 耶利米书 52:31; 列王纪下 25:27"> 再过三天，法老必抬举你的头，使你官复原职。你要把法老的杯递在他手中，像从前作他酒政时一样。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 2:12; 路加福音 23:42; 撒母耳记上 20:14–15"> 但你顺利的时候，请记得我，求你以仁慈待我，在法老面前提到我，把我从这府中带出去。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 3:17–18; 创世记 39:20; 提摩太前书 1:10"> 因为我实在是从希伯来人的地被掳来的；我在这里也没有做什么该被关进地牢的事。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="创世记 40:1–2"> 膳长见讲解是好的，就对约瑟说：“我也做了一个梦，看哪，我头上顶着三筐白饼。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 49:20; 历代志上 12:20"> 最上面的筐里有各样为法老烤制的食物，鸟儿从我头上的筐里吃这些食物。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="创世记 40:12; 创世记 41:26; 哥林多前书 11:24"> 约瑟回答说：“这梦的讲解是这样：三个筐就是三天。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 40:22; 使徒行传 20:27; 撒母耳记下 21:6"> 再过三天，法老必把你的头从你身上抬起来，把你挂在树上；鸟儿要吃你身上的肉。”</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 40:19; 创世记 40:13; 马太福音 14:6"> 到了第三天，是法老的生日，他为众臣仆设摆宴席，在臣仆中抬举了酒政长的头和膳长的头。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 40:13; 尼希米记 2:1"> 他使酒政长复任原职，酒政长就把杯递在法老手中；</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 40:19; 创世记 41:16; 但以理 2:30"> 但他把膳长挂起来，正如约瑟给他们讲解的。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 31:12; 约伯记 19:14; 诗篇 105:19"> 然而酒政长没有记念约瑟，反而忘了他。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 1:32–33; 创世记 23:1–2; 创世记 28:1"> 亚伯拉罕又娶了一个妻子，名叫基土拉。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 1:32–33; 民数记 25:17–18; 约伯记 2:11"> 她给他生了心兰、约珊、米但、米甸、伊施巴和书亚。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结 25:13; 耶利米书 49:8; 以西结 27:20"> 约珊生了示巴和底但。底但的儿子是亚书利族、利都是族和利乌米族。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 60:6"> 米甸的儿子是以法、以弗、哈诺、亚比大和以勒大。这些都是基土拉的子孙。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 24:36; 希伯来书 1:2; 加拉太书 3:29"> 亚伯拉罕把自己所有的一切都给了以撒，</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 21:14; 士师记 6:3; 使徒行传 14:17"> 但亚伯拉罕也把礼物给了他妾所生的众子。他还在世的时候，就打发他们离开他的儿子以撒，往东方去，到东方之地。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 12:4"> 这些是亚伯拉罕一生所活的岁数：一百七十五岁。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 35:28–29; 创世记 15:15; 历代志上 29:28"> 亚伯拉罕气绝而死，享高寿，年老，岁数满足，就归到他本族那里。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 50:13; 创世记 35:29; 创世记 49:29–30"> 他的儿子以撒和以实玛利把他埋葬在麦比拉洞里，就是幔利附近、赫人琐辖的儿子以弗仑的田中；</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 23:16; 创世记 49:31"> 那块田是亚伯拉罕从赫的子孙那里买来的。亚伯拉罕和他的妻子撒拉都葬在那里。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 22:17; 创世记 16:14; 创世记 24:62"> 亚伯拉罕死后，上帝赐福给他的儿子以撒。以撒住在庇耳·拉海·莱附近。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="诗篇 83:6; 创世记 17:20; 创世记 21:13"> 这是亚伯拉罕的儿子以实玛利的后代记载；以实玛利是撒拉的婢女埃及人夏甲给亚伯拉罕所生的。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 1:29–31; 以赛亚书 60:7; 雅歌 1:5"> 以下是以实玛利众子的名字，按着他们出生的次序列出：以实玛利的长子尼拜约，其次是基达、亚德别、米比衫、</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 21:11; 以赛亚书 21:16"> 米施玛、度玛、玛撒、</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 5:19; 约伯记 2:11"> 哈达、提玛、伊突、拿非施和基底玛。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 17:20; 创世记 17:23"> 这些是以实玛利的儿子，这些是他们的名字，按着他们的村庄和营地；他们按着自己的民族，作了十二个首领。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 15:15; 创世记 25:7–8"> 这些是以实玛利一生的岁数：一百三十七岁。他气绝而死，就归到他本族那里。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 16:12; 创世记 20:1; 列王纪下 23:29"> 他们住的地方从哈腓拉直到埃及前面的书珥，就是往亚述去的路上。他住在他所有亲族的对面。</span>
</div>
<div className="bp poetry">
<span className="v" id="v19" data-v="19" data-xref="马太福音 1:2; 路加福音 3:34; 使徒行传 7:8"> 这是亚伯拉罕的儿子以撒的后代记载。亚伯拉罕生了以撒。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 24:29; 创世记 24:67; 创世记 22:23"> 以撒四十岁的时候，娶了利百加为妻；利百加是巴旦·亚兰的亚兰人彼土利的女儿，亚兰人拉班的妹妹。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 1:13; 以赛亚书 58:9; 以斯拉记 8:23"> 以撒为他的妻子恳求耶和华，因为她不能生育。耶和华应允了他的恳求，他的妻子利百加就怀了孕。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 9:9; 撒母耳记上 28:6; 撒母耳记上 30:8"> 孩子们在她腹中彼此相争。她说：“若是这样，我为什么还活着呢？”她就去求问耶和华。</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 9:10–13; 创世记 27:40; 创世记 27:29"> 耶和华对她说：<br /><span className="pl pl-1">“两国在你腹中，</span><br /><span className="pl pl-1">两族要从你身体里分开。</span><br /><span className="pl pl-1">一族要强过另一族，</span><br /><span className="pl pl-1">年长的要服侍年幼的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 她生产的日子到了，看哪，她腹中有双胞胎。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 27:11; 创世记 27:16; 创世记 27:23"> 先出来的全身发红，像毛衣一样；他们给他起名叫以扫。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 27:36; 何西阿 12:3; 创世记 38:28–30"> 随后，他弟弟也出来了，手抓住以扫的脚跟；他被起名叫雅各。利百加生他们的时候，以撒六十岁。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="希伯来书 11:9; 创世记 21:20; 创世记 10:9"> 两个孩子渐渐长大。以扫善于打猎，是个田野的人；雅各为人安静，住在帐棚里。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 27:19; 创世记 27:31; 创世记 27:4"> 以撒爱以扫，因为他吃以扫打来的野味；利百加却爱雅各。</span>
<span className="v" id="v29" data-v="29" data-xref="箴言 13:25; 以赛亚书 40:30–31; 撒母耳记上 14:28"> 有一次，雅各熬汤。以扫从田野回来，饿得发昏。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 36:1; 出埃及记 15:15; 创世记 36:9"> 以扫对雅各说：“请把那红汤给我喝一点，因为我饿得发昏。”因此他的名字叫以东。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“以东”的意思是“红”。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31"> 雅各说：“你先把长子的名分卖给我。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="玛拉基书 3:14; 约伯记 21:15; 约伯记 22:17"> 以扫说：“看哪，我快要死了，这长子的名分对我有什么用呢？”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="希伯来书 12:16; 创世记 27:36; 希伯来书 6:16"> 雅各说：“你先向我起誓。”<br />他就向雅各起了誓，把长子的名分卖给了雅各。</span>
<span className="v" id="v34" data-v="34" data-xref="腓立比书 3:18–19; 希伯来书 12:16–17; 哥林多前书 15:32"> 雅各把饼和红豆汤给以扫；以扫吃了，喝了，就起来走了。以扫就这样轻看了他的长子名分。</span>
</div>

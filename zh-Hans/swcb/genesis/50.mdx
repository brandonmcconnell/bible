<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 46:4; 申命记 6:7–8; 使徒行传 8:2"> 约瑟伏在他父亲脸上，为他哀哭，亲吻他。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 50:26; 历代志下 16:14; 约翰福音 19:39–40"> 约瑟吩咐他的仆人，就是医生，给他父亲薰尸；医生就给以色列薰尸。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 20:29; 申命记 34:8; 创世记 50:10"> 为他用了四十天，因为薰尸所需的日子就是这样多。埃及人为以色列哀哭了七十天。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="创世记 18:3; 以斯帖记 4:2"> 为他哀哭的日子过去以后，约瑟对法老的臣仆说：“如果我现在在你们眼前蒙恩，请你们替我奏告法老说：</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 16:14; 以赛亚书 22:16; 马太福音 27:60"> ‘我父亲叫我起誓，说：“看哪，我快要死了。你要把我葬在我在迦南地为自己挖好的坟墓里。”现在求你让我上去埋葬我的父亲，然后我必回来。’”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 48:21"> 法老说：“你上去埋葬你的父亲吧，照着他叫你起的誓去做。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="创世记 14:16"> 约瑟就上去埋葬他的父亲；与他一同上去的，有法老所有的臣仆、法老家中的长老，以及埃及地所有的长老，</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 32:24–27; 出埃及记 10:26; 出埃及记 10:8–9"> 还有约瑟全家、他的兄弟们和他父亲的家人；只有他们的孩子、羊群和牛群留在歌珊地。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 14:28; 列王纪下 18:24; 雅歌 1:9"> 车辆和骑兵也与他一同上去；那是一支非常庞大的队伍。</span>
<span className="v" id="v10" data-v="10" data-xref="约伯记 2:13; 使徒行传 8:2; 撒母耳记下 1:17"> 他们来到约旦河那边亚达的禾场，在那里大大哀号，极其悲痛。约瑟为他父亲哀悼了七天。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 10:15–19; 创世记 24:6; 申命记 11:30"> 那地的居民迦南人看见亚达禾场上的哀悼，就说：“这是埃及人一场沉重的哀悼。”因此那地方名叫亚伯・米斯拉音，在约旦河那边。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 7:16; 创世记 49:29–32; 以弗所书 6:1"> 雅各的儿子们就照他所吩咐他们的去做，</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 49:29–31; 创世记 23:16–18; 使徒行传 7:16"> 因为他的儿子们把他抬到迦南地，葬在麦比拉田间的洞里；这洞和那块田，是亚伯拉罕从赫人以弗仑买来作坟地的产业，在幔利附近。</span>
<span className="v" id="v14" data-v="14"> 约瑟埋葬了父亲以后，就和他的兄弟们，以及所有同他上去埋葬他父亲的人，返回埃及。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="箴言 28:1; 创世记 42:21–22; 诗篇 53:5"> 约瑟的兄弟们见他们的父亲死了，就说：“或许约瑟会恨我们，并要为我们对他所做的一切恶，向我们彻底报复。”</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 29:25"> 他们就派人去见约瑟，说：“你父亲临死以前吩咐说：</span>
<span className="v" id="v17" data-v="17" data-xref="以弗所书 4:32; 马太福音 6:14–15; 创世记 45:8"> ‘你们要对约瑟这样说：“现在求你饶恕你兄弟们的过犯和他们的罪，因为他们恶待了你。”’现在求你饶恕你父亲的上帝的仆人们的过犯。”他们对约瑟说这些话的时候，约瑟哭了。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 37:7–11; 创世记 42:6; 创世记 45:3"> 他的兄弟们也来，俯伏在他面前，说：“看哪，我们是你的仆人。”</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 12:19; 创世记 45:5; 创世记 30:2"> 约瑟对他们说：“不要害怕，难道我能代替上帝吗？</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 8:28; 诗篇 119:71; 创世记 45:5–8"> 至于你们，你们的意思是要害我，但上帝的意思是要成就美善，为要保全许多人的性命，正如今日所成就的。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 47:12; 彼得前书 3:9; 创世记 45:10–11"> 现在你们不要害怕。我必供养你们和你们的孩子。”于是约瑟安慰他们，对他们说了亲切的话。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 约瑟和他父亲的家人住在埃及。约瑟活了一百一十岁。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 32:39; 创世记 30:3; 约伯记 42:16"> 约瑟看见以法莲的子孙直到第三代；玛拿西的儿子玛吉的孩子们也生在约瑟的膝上。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 3:16–17; 创世记 35:12; 创世记 26:3"> 约瑟对他的兄弟们说：“我快要死了，但上帝必定眷顾你们，领你们从这地上去，到祂向亚伯拉罕、以撒、雅各起誓所应许的那地。”</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 13:19; 约书亚记 24:32; 创世记 47:29–31"> 约瑟叫以色列的儿女起誓，说：“上帝必定眷顾你们；你们要把我的骸骨从这里带上去。”</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 50:2–3; 创世记 47:9; 约书亚记 24:29"> 约瑟死了，享年一百一十岁。人给他薰尸，把他安放在棺材里，留在埃及。</span>
</div>
</div>

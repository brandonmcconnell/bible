<span className="v" id="v2" data-v="2" data-xref="马太福音 19:4; 马可福音 10:6; 创世记 2:23"> 祂创造他们，有男有女，并且赐福给他们。在他们被造的日子，祂给他们起名叫亚当。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“亚当”和“人”在希伯来文中拼写所用的辅音完全相同，所以这里可以正确地译作任一意思。">a</a></sup></span>
<span className="v" id="v3" data-v="3" data-xref="创世记 4:25; 约伯记 25:4; 诗篇 51:5"> 亚当活到一百三十岁，生了一个儿子，样式和形像都像自己，就给他起名叫塞特。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 1:1–3; 路加福音 3:36–38; 创世记 5:26"> 亚当生塞特以后，又活了八百年，并且生了其他儿女。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 5:8; 创世记 5:11; 创世记 3:19"> 亚当共活了九百三十岁，然后死了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 4:26"> 塞特活到一百零五岁，生了以挪士。</span>
<span className="v" id="v7" data-v="7"> 塞特生以挪士以后，又活了八百零七年，并且生了其他儿女。</span>
<span className="v" id="v8" data-v="8"> 塞特共活了九百一十二岁，然后死了。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 3:37; 历代志上 1:2"> 以挪士活到九十岁，生了该南。</span>
<span className="v" id="v10" data-v="10"> 以挪士生该南以后，又活了八百一十五年，并且生了其他儿女。</span>
<span className="v" id="v11" data-v="11"> 以挪士共活了九百零五岁，然后死了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="路加福音 3:37"> 该南活到七十岁，生了玛勒列。</span>
<span className="v" id="v13" data-v="13"> 该南生玛勒列以后，又活了八百四十年，并且生了其他儿女；</span>
<span className="v" id="v14" data-v="14"> 该南共活了九百一十岁，然后死了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="历代志上 1:2"> 玛勒列活到六十五岁，生了雅列。</span>
<span className="v" id="v16" data-v="16"> 玛勒列生雅列以后，又活了八百三十年，并且生了其他儿女。</span>
<span className="v" id="v17" data-v="17"> 玛勒列共活了八百九十五岁，然后死了。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="创世记 4:17; 历代志上 1:3; 犹大书 1:14–15"> 雅列活到一百六十二岁，生了以诺。</span>
<span className="v" id="v19" data-v="19"> 雅列生以诺以后，又活了八百年，并且生了其他儿女。</span>
<span className="v" id="v20" data-v="20"> 雅列共活了九百六十二岁，然后死了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 3:37"> 以诺活到六十五岁，生了玛土撒拉。</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒罗尼迦前书 2:12; 创世记 17:1; 创世记 6:9"> 玛土撒拉出生以后，以诺与上帝同行三百年，并且又生了儿女。</span>
<span className="v" id="v23" data-v="23"> 以诺共活了三百六十五岁。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 11:5–6; 约翰一书 1:7; 创世记 5:22"> 以诺与上帝同行，后来就找不到了，因为上帝把他取去了。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 4:18"> 玛土撒拉活到一百八十七岁，生了拉麦。</span>
<span className="v" id="v26" data-v="26"> 玛土撒拉生拉麦以后，又活了七百八十二年，并且生了其他儿女。</span>
<span className="v" id="v27" data-v="27"> 玛土撒拉共活了九百六十九岁，然后死了。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 拉麦活到一百八十二岁，生了一个儿子。</span>
<span className="v" id="v29" data-v="29" data-xref="彼得后书 2:5; 希伯来书 11:7; 马太福音 24:37"> 他给他起名叫挪亚，说：“这个必在我们的工作，以及我们双手的劳苦上安慰我们；这劳苦是因耶和华所咒诅的地而来的。”</span>
<span className="v" id="v30" data-v="30"> 拉麦生挪亚以后，又活了五百九十五年，并且生了其他儿女。</span>
<span className="v" id="v31" data-v="31"> 拉麦共活了七百七十七岁，然后死了。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="创世记 6:10; 创世记 10:21; 创世记 9:18–19"> 挪亚五百岁以后，生了闪、含和雅弗。</span>

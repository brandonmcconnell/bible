<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 31:13; 何西阿 12:4; 诗篇 91:15"> 上帝对雅各说：“起来，上伯特利去，住在那里。要在那里为上帝筑一座坛，就是你逃避你哥哥以扫的时候向你显现的那位上帝。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="出埃及记 19:14; 出埃及记 19:10; 以西结 18:31"> 于是雅各对他的家人和所有与他同在的人说：“除掉你们中间的外邦神明，洁净自己，更换衣服。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 43:2; 创世记 32:7; 创世记 31:3"> 我们起来，上伯特利去。我要在那里为上帝筑一座坛；祂在我遭难的日子应允了我，在我所走的路上与我同在。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士师记 9:6; 申命记 7:25; 出埃及记 32:20"> 他们就把手中所有的外邦神明和耳朵上的环子都交给雅各；雅各把它们藏在示剑旁边的橡树下。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 23:27; 历代志下 17:10; 约书亚记 5:1"> 他们起行，上帝使周围各城的人都惊恐，所以他们没有追赶雅各的儿子们。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 28:19; 创世记 28:22; 创世记 12:8"> 雅各和所有与他同在的人，来到迦南地的路斯，就是伯特利。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 35:3; 创世记 35:1; 创世记 28:13"> 他在那里筑了一座坛，称那地方为伊勒伯特利，因为他逃避哥哥的时候，上帝在那里向他显现。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 24:59; 撒母耳记上 31:13; 士师记 2:5"> 利百加的奶妈底波拉死了，葬在伯特利下边的橡树下；那树名叫亚伦巴古。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 35:1; 创世记 18:1; 创世记 26:2"> 雅各从巴旦亚兰回来以后，上帝又向他显现，并赐福给他。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 17:5; 创世记 32:27–28; 创世记 17:15"> 上帝对他说：“你的名是雅各。你不要再名叫雅各，你的名要叫以色列。”于是祂给他起名叫以色列。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 17:1; 创世记 9:1; 创世记 22:17"> 上帝对他说：“我是全能的上帝。你要生养众多；将有一国和一群国家从你而出，君王也要从你身而出。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 12:7; 创世记 28:13; 创世记 26:3–4"> 我赐给亚伯拉罕和以撒的地，我也要赐给你；我还要把这地赐给你以后的后裔。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 17:22; 创世记 18:33; 士师记 6:21"> 上帝在与雅各说话的地方，从他那里上升离去了。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 28:18–19; 撒母耳记上 7:12; 出埃及记 17:15"> 雅各在上帝与他说话的地方立了一根柱子，是一根石柱；他在柱子上浇了奠祭，又在上面浇了油。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 28:19"> 雅各给上帝与他说话的那地方起名叫“伯特利”。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="弥迦书 5:2; 创世记 48:7; 列王纪下 5:19"> 他们从伯特利起行。离以法他还有一段路，拉结临产，而且产痛剧烈。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 30:24; 撒母耳记上 4:19–21"> 她产痛剧烈的时候，接生婆对她说：“不要怕，因为你现在又得了一个儿子。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 12:20; 使徒行传 7:59; 路加福音 23:46"> 她的生命将要离去，因为她快死了，就给孩子起名叫便俄尼，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“便俄尼”的意思是“我忧患之子”。">a</a></sup>但他父亲给他起名叫便雅悯。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“便雅悯”的意思是“我右手之子”。">b</a></sup></span>
<span className="v" id="v19" data-v="19" data-xref="弥迦书 5:2; 创世记 48:7; 路得记 4:11"> 拉结死了，葬在通往以法他的路上；以法他又叫伯利恒。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 10:2; 创世记 35:14; 撒母耳记下 18:17–18"> 雅各在她的坟上立了一根柱子；这就是拉结坟上的柱子，直到今日还在。</span>
<span className="v" id="v21" data-v="21" data-xref="弥迦书 4:8; 路加福音 2:8"> 以色列起行，在以得塔那边支搭了帐棚。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 5:1; 利未记 18:8; 撒母耳记下 20:3"> 以色列住在那地的时候，流便去与他父亲的妾辟拉同寝，以色列也听见了这事。<br />雅各的儿子共有十二个。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 30:18–20; 创世记 46:8–15; 创世记 29:32–35"> 利亚的儿子：吕便，雅各的长子，还有西缅、利未、犹大、以萨迦和西布伦。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 30:22–24; 创世记 46:19–22; 创世记 35:16–18"> 拉结的儿子：约瑟和便雅悯。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 46:23–25; 创世记 37:2; 创世记 30:4–8"> 辟拉的儿子，辟拉是拉结的使女：但和拿弗他利。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 30:9–13; 创世记 46:16–18; 创世记 25:20"> 悉帕的儿子，悉帕是利亚的使女：迦得和亚设。这些都是雅各的儿子，是他在巴旦亚兰所生的。</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 13:18; 创世记 23:19; 创世记 18:1"> 雅各来到他父亲以撒那里，到了幔利，就是基列亚巴，也就是希伯仑；亚伯拉罕和以撒曾在那里寄居。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="创世记 25:7; 创世记 50:26; 创世记 47:28"> 以撒的年日是一百八十年。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 15:15; 创世记 49:33; 创世记 49:31"> 以撒气绝而死，归到他祖先那里，年老日子满足。他的儿子以扫和雅各把他埋葬了。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 17:8; 创世记 23:4; 创世记 36:7"> 雅各住在他父亲寄居的地方，就是迦南地。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 35:25–26; 创世记 35:22; 撒母耳记上 2:22–24"> 这是雅各后代的记事。约瑟十七岁时，和他的哥哥们一起牧放羊群。他还是个少年，常和他父亲的妻子辟拉和悉帕的儿子们在一起。约瑟把他们的恶行报告给父亲。</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 3:35; 创世记 37:32; 撒母耳记下 13:18"> 以色列爱约瑟过于爱他所有的儿子，因为约瑟是他年老时所生的；他为约瑟做了一件彩衣。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 27:41; 约翰一书 3:12; 约翰一书 4:20"> 约瑟的哥哥们见父亲爱他过于爱所有的哥哥，就恨他，不能和他说和睦的话。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 28:12; 创世记 42:9; 约翰福音 17:14"> 约瑟做了一个梦，告诉他的哥哥们，他们就更加恨他。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 44:18; 士师记 9:7"> 他对他们说：“请听我所做的这个梦：</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 44:14; 创世记 42:6; 创世记 43:26"> 看哪，我们在田里捆禾捆；看哪，我的禾捆起来，并且站直；看哪，你们的禾捆围过来，向我的禾捆下拜。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 10:27; 使徒行传 7:35; 希伯来书 10:29"> 他的哥哥们问他说：“难道你真的要作王统治我们吗？难道你真的要管辖我们吗？”他们因他的梦和他的话，就更加恨他。</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 7:9–14; 创世记 37:7; 但以理 8:10"> 他又做了另一个梦，告诉他的哥哥们，说：“看哪，我又做了一个梦：看哪，太阳、月亮和十一个星都向我下拜。”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 27:29; 腓立比书 2:10–11; 以赛亚书 60:14"> 他把这梦告诉父亲和哥哥们。他父亲责备他说：“你做的这是什么梦？难道我和你母亲，以及你的哥哥们，真的要来俯伏在地，向你下拜吗？”</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 7:9; 路加福音 2:19; 路加福音 2:51"> 他的哥哥们嫉妒他，但他父亲把这话存在心里。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 37:1; 创世记 33:18; 创世记 34:25–31"> 约瑟的哥哥们去示剑，牧放他们父亲的羊群。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 6:1–3; 撒母耳记上 3:8; 撒母耳记上 3:16"> 以色列对约瑟说：“你的哥哥们不是在示剑牧羊吗？来，我要派你到他们那里去。”约瑟对他说：“我在这里。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="创世记 35:27; 路加福音 19:42; 诗篇 125:5"> 他对约瑟说：“你去看看你哥哥们是否平安，羊群是否平安，再回来告诉我。”于是他从希伯仑谷派约瑟出去，约瑟就来到示剑。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 4:27; 士师记 4:22; 创世记 21:14"> 有一个人遇见他；看哪，他正在田野里徘徊。那人问他说：“你在找什么？”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:10; 雅歌 1:7"> 他说：“我在找我的哥哥们。请告诉我，他们在哪里牧羊。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王纪下 6:13"> 那人说：“他们已经离开这里了，因为我听见他们说：‘我们去多坍吧。’”<br />约瑟就去追赶他的哥哥们，在多坍找到了他们。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 23:12; 诗篇 37:12; 诗篇 37:32"> 他们远远地看见他，趁他还没有走近，就同谋要杀他。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 28:12; 创世记 37:11; 创世记 37:5"> 他们彼此说：“看哪，那个做梦的人来了。</span>
<span className="v" id="v20" data-v="20" data-xref="提多书 3:3; 箴言 27:4; 马太福音 2:2–16"> 现在来吧，我们把他杀了，丢进一个坑里，就说：‘有恶兽把他吞吃了。’我们倒要看看他的梦会怎么样。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 42:22; 创世记 35:22; 约书亚记 10:28"> 吕便听见了，就救约瑟脱离他们的手，说：“我们不可害他的性命。”</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 22:12; 申命记 13:9; 创世记 42:22"> 吕便又对他们说：“不可流血。把他丢进这旷野里的坑中，但不可下手害他”——这是要救约瑟脱离他们的手，把他送回他父亲那里。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 37:3; 马太福音 27:28; 创世记 42:21"> 约瑟来到哥哥们那里，他们就剥去约瑟身上的衣服，就是他身上那件彩衣；</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 38:6; 诗篇 130:1–2; 撒迦利亚书 9:11"> 他们抓住他，把他丢进坑里。那坑是空的，里面没有水。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 37:28; 创世记 43:11; 耶利米书 8:22"> 他们坐下吃饭，举目观看，看哪，有一队以实玛利人从基列来；他们的骆驼驮着香料、乳香和没药，要带下埃及去。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 37:20; 创世记 4:10; 创世记 25:32"> 犹大对他的哥哥们说：“我们杀了自己的兄弟，遮掩他的血，有什么益处呢？</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 16:26; 创世记 42:21; 撒母耳记上 18:17"> 来吧，我们把他卖给以实玛利人，不可下手害他；因为他是我们的兄弟，是我们的骨肉。”他的哥哥们听从了他。</span>
<span className="v" id="v28" data-v="28" data-xref="使徒行传 7:9; 诗篇 105:17; 创世记 45:4–5"> 有米甸的商人经过，他们把约瑟从坑里拉上来，提了出来，用二十块银子把约瑟卖给以实玛利人。商人们把约瑟带到埃及。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约伯记 1:20; 创世记 37:34; 创世记 44:13"> 吕便回到坑边，看见约瑟不在坑里，就撕裂自己的衣服。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 42:13; 耶利米书 31:15; 创世记 42:32"> 他回到兄弟们那里，说：“那孩子没有了！我，我该往哪里去呢？”</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 37:23; 箴言 28:13; 创世记 37:3"> 他们拿了约瑟的衣服，宰了一只公山羊，把衣服蘸在血里。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 15:30; 创世记 37:3; 创世记 44:20–23"> 他们把那件彩衣带到父亲那里，说：“我们找到了这件衣服。请你辨认一下，看是不是你儿子的衣服。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="创世记 37:20; 创世记 44:28; 约翰福音 13:7"> 他认出来，就说：“这是我儿子的衣服。有恶兽把他吞吃了。约瑟必定被撕碎了。”</span>
<span className="v" id="v34" data-v="34" data-xref="创世记 37:29; 撒母耳记下 3:31; 诗篇 69:11"> 雅各撕裂自己的衣服，腰间围上麻布，为他的儿子哀悼了许多日子。</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 42:38; 约伯记 2:11; 撒母耳记下 12:17"> 他的儿子们和女儿们都起来安慰他，他却不肯受安慰。他说：“我必悲哀着下到阴间<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="阴间是死人所在之处。">a</a></sup>，到我儿子那里去。”他的父亲为他哭泣。</span>
<span className="v" id="v36" data-v="36" data-xref="创世记 40:4; 创世记 37:28; 列王纪下 25:8"> 米甸人在埃及把约瑟卖给法老的官员、护卫长波提乏。</span>
</div>
</div>

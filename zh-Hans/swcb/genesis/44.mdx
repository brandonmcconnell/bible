<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 42:25; 创世记 43:16; 创世记 24:2"> 约瑟吩咐他家的管家说：“把粮食装满这些人的袋子，尽他们所能带的装满，又把各人的银钱放在各人的袋口里。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 8:8; 创世记 42:20; 申命记 8:16"> 把我的杯，就是那只银杯，和他买粮的银钱，一同放在最小的那个的袋口里。”管家就照约瑟所说的话做了。</span>
<span className="v" id="v3" data-v="3"> 早晨天一亮，这些人和他们的驴就被送走了。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 10:32; 诗篇 35:12; 箴言 17:13"> 他们出了城，还没有走远，约瑟就对他的管家说：“起来，追赶那些人。追上他们的时候，要问他们：‘你们为什么以恶报善呢？</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 30:27; 利未记 19:26; 列王纪下 21:6"> 这不是我主人用来喝酒、也确实用来占卜的杯吗？你们这样做是作恶了。’”</span>
<span className="v" id="v6" data-v="6"> 管家追上他们，就把这些话对他们说了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="创世记 38:16–18; 创世记 37:18–32; 列王纪下 8:13"> 他们对他说：“我主为什么说这样的话呢？你的仆人绝不会做这样的事！</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 43:12; 创世记 42:35; 罗马书 13:9"> 看哪，我们在袋口里发现的银钱，尚且从迦南地带回来还给你；我们又怎会从你主人的家里偷银子或金子呢？</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 31:32; 诗篇 7:3–5; 约伯记 31:38–40"> 在你仆人中间，无论在谁那里找到，就让他死；我们也都作我主的奴仆。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及记 22:3; 创世记 44:17; 创世记 44:33"> 他说：“现在就照你们的话这样办吧。在谁那里找到，谁就作我的奴仆；至于你们，可以无罪。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 于是他们急忙各人把自己的袋子卸在地上，各人打开自己的袋子。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 44:26–32; 创世记 42:36–38; 创世记 43:14"> 管家搜查，从年长的开始，到年幼的为止；那杯竟在便雅悯的袋子里找到了。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 1:11; 创世记 37:29–34; 撒母耳记下 1:2"> 他们就撕裂衣服，各人把东西驮在驴上，回城去了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="创世记 50:18; 创世记 43:25; 创世记 43:16"> 犹大和他的兄弟们来到约瑟的家，约瑟还在那里；他们就在他面前俯伏在地。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 4:10; 创世记 21:26; 创世记 3:13"> 约瑟对他们说：“你们做的这是什么事？难道你们不知道，像我这样的人确实会占卜吗？”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="创世记 44:9; 但以理 9:7; 民数记 32:23"> 犹大说：“我们对我主还能说什么呢？还能讲什么呢？我们怎能表明自己清白呢？上帝已经查出了你仆人们的罪孽。看哪，我们和那手中找到杯的人，都是我主的奴仆。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="箴言 17:15; 撒母耳记下 23:3; 创世记 18:25"> 约瑟说：“我绝不会这样做。在谁手中找到杯，谁就作我的奴仆；至于你们，可以平平安安地上去，到你们父亲那里。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 32:22; 创世记 41:40; 创世记 18:30"> 犹大就挨近他说：“哦，我主，求你让仆人向我主说一句话，不要向仆人发怒，因为你如同法老一样。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 43:7; 创世记 43:29; 创世记 42:7–10"> 我主曾问仆人们说：‘你们有父亲或兄弟吗？’</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 37:3; 创世记 42:38; 路加福音 7:12"> 我们对我主说：‘我们有父亲，已经年老；还有他年老时所生的孩子，是个小的。他的哥哥已经死了，他母亲只剩下他一个；他父亲爱他。’</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 42:15; 创世记 42:20; 阿摩司 9:4"> 你对仆人们说：‘把他带下来到我这里，让我亲眼看看他。’</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 44:30; 创世记 42:38"> 我们对我主说：‘这孩子不能离开他父亲，因为他若离开父亲，父亲就会死。’</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 43:5; 创世记 43:3; 创世记 42:15–20"> 你对仆人们说：‘你们最小的弟弟若不与你们一同下来，你们就不得再见我的面。’</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 42:29–34"> 我们上去到你仆人我父亲那里，就把我主的话告诉了他。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 43:2; 创世记 43:5"> 我们的父亲说：‘你们再去给我们买一点食物。’</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 11:7; 创世记 43:4–5"> 我们说：‘我们不能下去。如果我们最小的弟弟与我们同去，我们才可以下去；因为我们最小的弟弟若不与我们同去，我们就不能见那人的面。’</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 46:19; 创世记 35:16–18; 创世记 30:22–25"> 你仆人我父亲对我们说：‘你们知道，我的妻子给我生了两个儿子。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 37:33; 创世记 37:13–14; 创世记 42:36"> 一个离开我出去了，我说：“他一定是被撕碎了”；直到如今我再没有见过他。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 42:38; 创世记 43:14; 申命记 31:17"> 如果你们把这一个也从我这里带走，而他遭遇灾祸，你们就会使我白发苍苍、带着悲伤下到阴间。’<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="阴间是死人所在之处。">a</a></sup></span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 18:1; 撒母耳记下 18:33; 创世记 44:31"> 现在，如果我回到你仆人我父亲那里，孩子却没有和我们同在；既然我父亲的生命与这孩子的生命紧紧相连，</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 44:29; 创世记 37:35; 哥林多后书 7:10"> 他看见孩子不在了，就必死。这样，仆人们就会使你仆人、我们的父亲白发苍苍、带着悲伤下到阴间。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="阴间是死人所在之处。">b</a></sup></span>
<span className="v" id="v32" data-v="32" data-xref="创世记 43:8–9; 创世记 43:16"> 因为仆人曾为这孩子向我父亲作保，说：‘我若不把他带回你那里，我就在我父亲面前永远担当罪责。’</span>
<span className="v" id="v33" data-v="33" data-xref="约翰一书 3:16; 出埃及记 32:32; 希伯来书 7:22"> 现在，求你让仆人替这孩子留下，作我主的奴仆；让这孩子和他的兄弟们一同上去。</span>
<span className="v" id="v34" data-v="34" data-xref="以斯帖记 8:6; 诗篇 116:3; 诗篇 119:143"> 因为若这孩子不与我同去，我怎能上去到我父亲那里呢？恐怕我会看见灾祸临到我父亲。”</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰一书 3:12; 创世记 3:15; 创世记 4:25"> 那人和他的妻子夏娃同房<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：睡在一起；或：发生关系">a</a></sup>。她怀了孕<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：成孕">b</a></sup>，生了该隐，说：“我靠耶和华的帮助得了一个男子。”</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 3:15; 约翰一书 3:12; 路加福音 11:51"> 她又生了该隐的弟弟亚伯。亚伯是牧羊的，该隐是耕地的。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 18:12; 利未记 2:1–11; 列王纪上 17:7"> 过了一些时候，该隐从地里的出产拿供物献给耶和华。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 11:4; 箴言 3:9; 出埃及记 13:12"> 亚伯也从他羊群中头生的和羊的脂油拿来献上。耶和华看中了亚伯和他的供物，</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 11:4; 约伯记 5:2; 路加福音 15:28–30"> 却没有看中该隐和他的供物。该隐就非常恼怒，脸色沉了下来。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 1:18; 约伯记 5:2; 路加福音 15:31–32"> 耶和华对该隐说：“你为什么恼怒？你的脸色为什么沉了下来？</span>
<span className="v" id="v7" data-v="7" data-xref="雅各书 1:15; 罗马书 2:6–10; 以赛亚书 3:10–11"> 你若行得好，脸色岂不会扬起来吗？你若行得不好，罪就伏在门口。它渴望辖制你，但你必须管辖它。”</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 23:35; 约翰一书 3:12–15; 犹大书 1:11"> 该隐对他的弟弟亚伯说：“我们到田野去吧。”他们在田野的时候，该隐起来攻击他的弟弟亚伯，把他杀了。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="箴言 28:13; 约翰福音 8:44; 诗篇 9:12"> 耶和华对该隐说：“你的弟弟亚伯在哪里？”<br />他说：“我不知道。我岂是看守我弟弟的吗？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="希伯来书 12:24; 诗篇 72:14; 希伯来书 11:4"> 耶和华说：“你做了什么？你弟弟血的声音从地里向我哀告。</span>
<span className="v" id="v11" data-v="11" data-xref="加拉太书 3:10; 约伯记 16:18; 创世记 3:14"> 现在你因这地受咒诅；这地开了口，从你手里接受了你弟弟的血。</span>
<span className="v" id="v12" data-v="12" data-xref="何西阿 9:17; 利未记 26:36; 利未记 26:20"> 从今以后，你耕种土地，土地不再给你效力。你必在地上流离漂泊。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约伯记 15:22; 启示录 16:9; 启示录 16:11"> 该隐对耶和华说：“我的刑罚太重，过于我所能承受。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 35:19; 诗篇 143:7; 约伯记 15:20–24"> 看哪，你今日把我从这地面上赶出去；我必躲避你的面，在地上流离漂泊。凡遇见我的，必杀我。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西结 9:4; 诗篇 79:12; 创世记 4:24"> 耶和华对他说：“因此，凡杀该隐的，必遭报七倍。”耶和华给该隐立了一个记号，免得遇见他的人击杀他。</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="耶利米书 23:39; 约伯记 2:7; 创世记 4:14"> 该隐离开耶和华面前，住在伊甸东边的挪得地。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 49:11; 传道书 2:4–11; 但以理 4:30"> 该隐和他的妻子同房。她怀了孕，生了以诺。该隐建造了一座城，并按他儿子的名字给那城起名叫以诺。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 36:2; 创世记 5:21"> 以诺生以拿。以拿生米户雅利。米户雅利生玛土撒利。玛土撒利生拉麦。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 2:24; 马太福音 19:8; 创世记 2:18"> 拉麦娶了两个妻子：一个名叫亚大，另一个名叫洗拉。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 4:2; 耶利米书 35:9–10; 约翰福音 8:44"> 亚大生雅八；他是住帐棚、拥有牲畜之人的祖先。</span>
<span className="v" id="v21" data-v="21" data-xref="约伯记 21:12; 以赛亚书 5:12; 创世记 31:27"> 他的兄弟名叫犹八；他是一切弹琴吹箫之人的祖先。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 33:25; 申命记 8:9; 历代志下 2:7"> 洗拉也生了土八该隐；他是打造各种铜铁利器的工匠。土八该隐的妹妹是拿玛。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 23:18; 出埃及记 20:13; 利未记 19:18"> 拉麦对他的妻子们说：<br /><span className="pl pl-1">“亚大、洗拉，听我的声音；</span><br /><span className="pl pl-2">拉麦的妻子们，侧耳听我的话。</span><br /><span className="pl pl-1">因为我为我的伤杀了一个人，</span><br /><span className="pl pl-2">为我的瘀伤杀了一个年轻人。</span></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 18:22; 创世记 4:15"> <span className="pl pl-1">如果该隐遭报七倍，</span><br /><span className="pl pl-2">拉麦必遭报七十七倍。”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 4:8; 创世记 4:10–11; 历代志上 1:1"> 亚当又和他的妻子同房。她生了一个儿子，给他起名叫塞特，说：“因为上帝赐给我另一个孩子代替亚伯；该隐杀了他。”</span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 116:17; 列王纪上 18:24; 约珥 2:32"> 塞特也生了一个儿子，给他起名叫以挪士。那时候，人开始求告耶和华的名。</span>
</div>

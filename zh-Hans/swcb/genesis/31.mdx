<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="GEN" data-book-slug="genesis" data-book-name="创世记" data-chapter="31" data-verses="55">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="传道书 4:4; 诗篇 49:16–17; 约伯记 31:31"> 雅各听见拉班的儿子们说：“雅各把我们父亲所有的都夺去了；他从我们父亲的财物中得了这一切财富。”</span>
<span className="v" id="v2" data-v="2" data-xref="但以理 3:19; 撒母耳记上 18:9–11; 创世记 4:5"> 雅各看见拉班脸上的表情，看哪，对他已经不像从前了。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 28:15; 创世记 32:9; 希伯来书 13:5"> 耶和华对雅各说：“你要回到你祖先之地，到你的亲族那里去；我必与你同在。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 雅各就派人把拉结和利亚叫到田野里，到他的羊群那里，</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 31:2–3; 创世记 31:53; 创世记 48:15"> 对她们说：“我看见你们父亲脸上的表情，对我已经不像从前了；但是我父亲的上帝一直与我同在。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 30:29; 以弗所书 6:5–8; 提多书 2:9–10"> 你们知道，我用尽全力服侍了你们的父亲。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 37:28; 创世记 31:29; 民数记 14:22"> 你们的父亲欺骗我，十次改了我的工价；但是上帝不容许他害我。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 30:32"> 如果他说：‘有斑点的归你作工价’，全群就生下有斑点的；如果他说：‘有条纹的归你作工价’，全群就生下有条纹的。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 31:1; 创世记 31:16; 箴言 13:22"> 这样，上帝把你们父亲的牲畜取来，赐给了我。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 13:1; 创世记 30:39; 创世记 20:6"> 到羊群交配的时候，我在梦中举目观看，看哪，跳上母羊群的公山羊都是有条纹的、有斑点的、有花斑的。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 58:9; 创世记 31:13; 撒母耳记上 3:6"> 上帝的使者在梦中对我说：‘雅各。’我说：‘我在这里。’</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 3:7; 申命记 24:15; 创世记 31:42"> 他说：‘现在你举目观看，看哪，凡跳上母羊群的公山羊都是有条纹的、有斑点的、有花斑的，因为拉班向你所做的一切，我都看见了。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 31:3; 创世记 32:9; 创世记 28:12–22"> 我是伯特利的上帝；你曾在那里膏立柱子，也曾在那里向我许愿。现在起来，离开这地，回到你出生之地去。’”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路得记 4:11; 创世记 2:24; 创世记 29:24"> 拉结和利亚回答他说：“在我们父亲的家里，难道还有我们的份额或产业吗？</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 29:15–20; 创世记 31:41; 创世记 29:27–30"> 我们岂不是被他看作外人吗？因为他卖了我们，又把我们的银钱用尽了。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 30:35–1; 创世记 31:9; 诗篇 45:10"> 上帝从我们父亲那里取来的一切财富，都是我们和我们儿女的。现在，上帝对你所说的一切，你都去做吧。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 30:17; 创世记 24:61; 创世记 24:10"> 于是雅各起来，让他的儿子和妻子骑上骆驼，</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 27:1–2; 创世记 27:41; 创世记 35:27–29"> 又带走他所有的牲畜和他所积聚的一切财物，就是他在巴旦·亚兰所得的牲畜，要往迦南地，到他父亲以撒那里去。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 19:13; 创世记 31:30; 何西阿 3:4"> 那时拉班去剪羊毛；拉结偷了她父亲的特拉芬<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="特拉芬是家中的神像，可能与继承家庭产业的权利有关。">a</a></sup>。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 雅各瞒过了亚兰人拉班，没有告诉他自己要逃走。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 12:17; 创世记 37:25; 创世记 46:28"> 于是他带着所有的一切逃走。他起来，渡过大河，向基列山地进发。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约伯记 5:12–13; 创世记 30:36; 出埃及记 14:5–31"> 到第三天，有人告诉拉班，雅各已经逃走了。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 13:8; 创世记 24:27; 出埃及记 2:11"> 拉班带着他的亲族去追赶雅各，追了七天的路程，在基列山地追上了他。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 24:50; 创世记 31:29; 创世记 20:3"> 夜间，上帝在梦中来到亚兰人拉班那里，对他说：“你要小心，无论好坏都不可对雅各说什么。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 12:8; 创世记 33:18; 希伯来书 11:9"> 拉班追上了雅各。那时雅各在山地支搭了帐棚；拉班和他的亲族也在基列山地安营。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记上 30:2; 创世记 12:18; 创世记 20:9–10"> 拉班对雅各说：“你做的是什么事？你竟瞒过我，把我的女儿们带走，像被刀剑掳去的俘虏一样？</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 15:20; 箴言 26:23–26; 创世记 31:3–5"> 你为什么暗暗逃走，瞒过我，不告诉我？我本可以欢欢喜喜地，唱着歌，打着手鼓，弹着琴，送你离去；</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 31:55; 路得记 1:14; 使徒行传 20:37"> 你又不让我亲吻我的外孙和女儿们。现在你做的是愚蠢的事。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 31:53; 创世记 31:42; 创世记 31:24"> 我手中本有能力害你们，但是你父亲的上帝昨夜对我说：‘你要小心，无论好坏都不可对雅各说什么。’</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 10:11; 创世记 31:19; 士师记 18:24"> 现在，你要离去，是因为你切切想念你父亲的家；可是你为什么偷了我的神像？”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="箴言 29:25; 创世记 31:26–27; 创世记 20:11"> 雅各回答拉班说：“因为我害怕；我想：‘恐怕你强行把你的女儿们从我这里夺走。’</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 12:3–5; 创世记 31:30; 创世记 31:19"> 你在谁那里找到你的神像，谁就不得存活。在我们的亲族面前，你查出在我这里有什么是你的，就拿去。”原来雅各不知道拉结偷了那些神像。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="创世记 24:67; 创世记 24:28"> 拉班进了雅各的帐棚，又进了利亚的帐棚，也进了两个女仆的帐棚；但他没有找到。他从利亚的帐棚出来，进了拉结的帐棚。</span>
<span className="v" id="v34" data-v="34" data-xref="创世记 31:19; 创世记 31:17"> 拉结已经把特拉芬拿来，放在骆驼的鞍子里，自己坐在上面。拉班摸遍了整个帐棚，却没有找到。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 19:32; 出埃及记 20:12; 彼得前书 2:18"> 她对父亲说：“我主不要生气，我不能在你面前起来，因为我正有妇人的月事。”他搜寻，却没有找到特拉芬。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以弗所书 4:26; 创世记 49:7; 民数记 16:15"> 雅各就发怒，与拉班争辩。雅各回答拉班说：“我有什么过犯？我有什么罪，你竟这样紧追我？</span>
<span className="v" id="v37" data-v="37" data-xref="彼得前书 2:12; 哥林多前书 6:4–5; 撒母耳记上 12:3–4"> 现在你摸遍了我所有的物件，从你家中的一切物件里找到了什么？请摆在我的亲族和你的亲族面前，让他们在我们二人之间裁判。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="创世记 30:27; 申命记 28:4; 以西结 34:2–4"> “这二十年我一直与你同在。你的母绵羊和母山羊没有流产；你羊群中的公羊，我也没有吃过。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及记 22:31; 出埃及记 22:10–13; 利未记 22:8"> 被野兽撕裂的，我没有带来给你；我自己承担损失。无论白天被偷，还是夜间被偷，你都向我追讨。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 2:8; 出埃及记 2:19–22; 彼得前书 5:2–4"> 我的情形是这样：白天干热耗尽我，夜间寒霜侵袭我；我的睡眠从我眼中逃走。</span>
<span className="v" id="v41" data-v="41" data-xref="创世记 31:7; 哥林多前书 15:10; 哥林多后书 11:26"> 这二十年我在你家里。我为你的两个女儿服侍你十四年，为你的羊群服侍你六年；你却十次改了我的工价。</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 31:7; 创世记 31:53; 以赛亚书 8:13"> 如果不是我父亲的上帝，亚伯拉罕的上帝，以撒所敬畏的那一位与我同在，你现在必定打发我空手而去。上帝看见了我的苦情和我手中的劳苦，昨夜责备了你。”</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43"> 拉班回答雅各说：“女儿是我的女儿，孩子是我的孩子，羊群是我的羊群；你所看见的一切都是我的！但今天我能对这些我的女儿，或对她们所生的孩子做什么呢？</span>
<span className="v" id="v44" data-v="44" data-xref="创世记 31:52; 约书亚记 24:25–27; 约书亚记 22:27"> 现在来吧，让我们立约，你我之间立约；让这约作我和你之间的见证。”</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="创世记 28:18–22"> 雅各拿了一块石头，立作柱子。</span>
<span className="v" id="v46" data-v="46" data-xref="传道书 3:5; 创世记 31:23; 创世记 31:54"> 雅各对他的亲族说：“你们聚集石头。”他们就拿石头堆成一堆，在那石堆旁吃饭。</span>
<span className="v" id="v47" data-v="47" data-xref="希伯来书 12:1"> 拉班称它为伊迦尔·撒哈杜他<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“伊迦尔·撒哈杜他”在亚兰语中意思是“见证之堆”。">b</a></sup>，雅各却称它为迦累得<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“迦累得”在希伯来语中意思是“见证之堆”。">c</a></sup>。</span>
<span className="v" id="v48" data-v="48" data-xref="约书亚记 24:27; 约书亚记 13:8–9; 创世记 31:23"> 拉班说：“今天这石堆在我和你之间作见证。”因此它名叫迦累得，</span>
<span className="v" id="v49" data-v="49" data-xref="士师记 11:29; 士师记 10:17; 撒母耳记上 7:5–6"> 又叫米斯巴，因为他说：“我们彼此离别的时候，愿耶和华在我和你之间鉴察。</span>
<span className="v" id="v50" data-v="50" data-xref="耶利米书 42:5; 耶利米书 29:23; 弥迦书 1:2"> 如果你苦待我的女儿们，或是在我的女儿们以外另娶妻子，虽然没有人与我们同在，看哪，上帝在我和你之间作见证。”</span>
<span className="v" id="v51" data-v="51"> 拉班又对雅各说：“看这石堆，又看这柱子，是我在我和你之间所立的。</span>
<span className="v" id="v52" data-v="52" data-xref="创世记 31:48; 创世记 31:44–45"> 愿这石堆作见证，愿这柱子作见证：我不会越过这石堆到你那里去加害，你也不会越过这石堆和这柱子到我这里来加害。</span>
<span className="v" id="v53" data-v="53" data-xref="创世记 31:42; 创世记 16:5; 约书亚记 24:2"> 愿亚伯拉罕的上帝、拿鹤的上帝，就是他们父亲的上帝，在我们之间判断。”雅各就指着他父亲以撒所敬畏的那一位起誓。</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及记 18:12; 创世记 37:25; 创世记 26:30"> 雅各在山上献祭，又叫他的亲族来吃饭。他们吃了饭，就在山上过夜。</span>
<span className="v" id="v55" data-v="55" data-xref="创世记 31:28; 申命记 23:5; 创世记 18:33"> 清早，拉班起来，亲吻他的外孙和女儿们，并为他们祝福。拉班离开，回到自己的地方去了。</span>
</div>
</div>

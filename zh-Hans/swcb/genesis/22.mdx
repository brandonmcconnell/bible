<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 11:17; 雅各书 2:21; 申命记 8:2"> 这些事以后，上帝试验亚伯拉罕，对他说：“亚伯拉罕！”<br />他说：“我在这里。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="约翰福音 3:16; 罗马书 8:32; 希伯来书 11:17"> 上帝说：“现在带上你的儿子，就是你所爱的独生子以撒，往摩利亚地去，在我将要告诉你的一座山上，把他献为燔祭。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="诗篇 119:60; 马太福音 10:37; 路加福音 14:26"> 亚伯拉罕清早起来，备上驴，带着两个仆人和他的儿子以撒。他劈好了燔祭用的柴，就起身往上帝告诉他的地方去了。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 13:32; 马太福音 17:23; 何西阿 6:2"> 第三天，亚伯拉罕举目，远远看见那地方。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 11:19; 希伯来书 12:1"> 亚伯拉罕对他的仆人说：“你们和驴留在这里；我和这孩子要到那边去。我们敬拜以后，就回到你们这里来。”</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 19:17; 彼得前书 2:24; 以赛亚书 53:6"> 亚伯拉罕把燔祭用的柴放在他儿子以撒身上，自己手里拿着火和刀。于是二人一同走去。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:15; 马太福音 26:39; 创世记 8:20"> 以撒对他父亲亚伯拉罕说：“我父亲？”<br />他说：“我儿，我在这里。”<br />以撒说：“看哪，火和柴都有了，可是燔祭用的羊羔在哪里呢？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约翰福音 1:36; 约翰福音 1:29; 启示录 5:12"> 亚伯拉罕说：“我儿，上帝必为自己预备燔祭用的羊羔。”于是二人一同走去。</span>
<span className="v" id="v9" data-v="9" data-xref="雅各书 2:21; 希伯来书 11:17–19; 腓立比书 2:7–8"> 他们到了上帝告诉亚伯拉罕的地方。亚伯拉罕在那里筑坛，把柴摆好，捆绑他的儿子以撒，把他放在坛上的柴上。</span>
<span className="v" id="v10" data-v="10" data-xref="雅各书 2:21–23; 希伯来书 11:17–19; 以赛亚书 53:6–12"> 亚伯拉罕伸手拿刀，要杀他的儿子。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="创世记 21:17; 出埃及记 3:4; 创世记 16:9–10"> 耶和华的使者从天上呼唤他说：“亚伯拉罕！亚伯拉罕！”<br />他说：“我在这里。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="雅各书 2:21–22; 雅各书 2:18; 撒母耳记上 15:22"> 使者说：“不要把手伸向这孩子，也不要对他做任何事。因为现在我知道你敬畏上帝；你没有把你的儿子，就是你的独生子，留下不给我。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 10:13; 诗篇 40:6–8; 哥林多后书 1:9–10"> 亚伯拉罕举目观看，见他后面有一只公羊，两角缠在灌木丛中。亚伯拉罕就去取了那只公羊，把它献为燔祭，代替他的儿子。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 22:13; 出埃及记 17:15; 创世记 22:8"> 亚伯拉罕给那地方起名叫“耶和华必预备”。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或“耶和华以勒”，或“耶和华看见”">a</a></sup>所以直到今日人还说：“在耶和华的山上，必有预备。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 耶和华的使者第二次从天上呼唤亚伯拉罕，</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 6:13–14; 路加福音 1:73; 诗篇 105:9"> 说：“耶和华说：‘我指着自己起誓，因为你做了这事，没有把你的儿子，就是你的独生子，留下不给我，</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 15:5; 创世记 24:60; 耶利米书 33:22"> 我必大大赐福给你，也必使你的后裔大大增多，如天上的星，又如海边的沙。你的后裔必得着他仇敌的城门。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 3:25; 创世记 12:3; 加拉太书 3:16"> 因你的后裔，地上万国都必蒙福，因为你听从了我的声音。’”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="创世记 21:31; 士师记 20:1; 约书亚记 15:28"> 于是亚伯拉罕回到他的仆人那里，他们就起身，一同往别是巴去。亚伯拉罕住在别是巴。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 11:29; 创世记 24:24; 箴言 25:25"> 这些事以后，有人告诉亚伯拉罕说：“看哪，密迦也给你的兄弟拿鹤生了儿子：</span>
<span className="v" id="v21" data-v="21" data-xref="约伯记 1:1; 约伯记 32:2; 诗篇 60:1–12"> 长子乌斯、他的兄弟布斯、亚兰的父亲基母利、</span>
<span className="v" id="v22" data-v="22"> 基薛、哈琐、必达、益拉和彼土利。”</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 24:15; 创世记 28:5; 创世记 24:51"> 彼土利生了利百加。这八个人是密迦给亚伯拉罕的兄弟拿鹤生的。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 16:3; 创世记 25:6; 箴言 15:25"> 拿鹤的妾名叫流玛，也生了提八、迦含、他辖和玛迦。</span>
</div>
</div>

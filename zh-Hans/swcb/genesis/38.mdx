<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 22:1; 列王纪下 4:8; 箴言 13:20"> 那时，犹大离开他的弟兄们下去，去到一个亚杜兰人那里，那人名叫希拉。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 2:3; 创世记 24:3; 创世记 6:2"> 犹大在那里看见一个迦南人书亚的女儿，就娶了她，与她同房。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 46:12; 民数记 26:19"> 她怀孕，生了一个儿子；犹大给他起名叫珥。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 46:12; 民数记 26:19"> 她又怀孕，生了一个儿子；她给他起名叫俄南。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 26:20; 创世记 38:26; 创世记 46:12"> 她再生了一个儿子，给他起名叫示拉。她生示拉的时候，犹大正在基悉。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 24:3; 创世记 21:21; 马太福音 1:3"> 犹大为他的长子珥娶了一个妻子，她名叫他玛。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 2:3; 创世记 46:12; 民数记 26:19"> 犹大的长子珥在耶和华眼中为恶，所以耶和华使他死了。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 25:5–10; 马太福音 22:23–27; 路得记 4:5–11"> 犹大对俄南说：“你要与哥哥的妻子同房，对她尽丈夫兄弟的本分，为你哥哥立后。”</span>
<span className="v" id="v9" data-v="9" data-xref="提多书 3:3; 申命记 25:6; 雅各书 3:16"> 俄南知道后裔不会归自己；所以他与哥哥的妻子同房时，就把精液遗在地上，免得给哥哥留下后裔。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 46:12; 民数记 11:1; 历代志上 21:7"> 他所做的事在耶和华眼中为恶，耶和华也使他死了。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 22:13; 路得记 1:11–13"> 于是犹大对他的儿媳他玛说：“你守寡住在你父亲家里，等我儿子示拉长大。”因为他说：“恐怕他也像他的哥哥们一样死了。”他玛就去，住在她父亲家里。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约书亚记 15:10; 撒母耳记下 13:39; 士师记 14:1"> 过了许多日子，书亚的女儿，就是犹大的妻子，死了。犹大得了安慰以后，就和他的朋友亚杜兰人希拉上亭拿，到他剪羊毛的人那里去。</span>
<span className="v" id="v13" data-v="13"> 有人告诉他玛说：“看哪，你的公公正上亭拿去剪羊毛。”</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 38:26; 创世记 38:11–13; 耶利米书 3:2"> 他玛就脱下寡妇的衣服，用帕子蒙着自己，又把自己裹住，坐在通往亭拿路上的伊拿印城门口；因为她看见示拉已经长大，却没有被给他作妻子。</span>
<span className="v" id="v15" data-v="15"> 犹大看见她，以为她是妓女，因为她蒙着脸。</span>
<span className="v" id="v16" data-v="16" data-xref="提摩太前书 6:10; 马太福音 26:15; 撒母耳记下 13:11"> 犹大转到路边她那里，说：“来吧，请让我与你同房。”原来他不知道她是自己的儿媳。<br />她说：“你要给我什么，才可以与我同房呢？”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以西结 16:33; 创世记 38:20; 箴言 20:16"> 他说：“我会从羊群里送一只山羊羔给你。”<br />她说：“在你送来以前，你愿意给我一个抵押物吗？”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="创世记 38:25–26; 何西阿 4:11; 耶利米书 22:24"> 他说：“我给你什么作抵押物呢？”<br />她说：“你的印章、你的印绳和你手里的杖。”<br />他就把这些给了她，并与她同房，她就从他怀了孕。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 38:14; 撒母耳记下 14:5; 撒母耳记下 14:2"> 她起来走了，摘下帕子，穿上寡妇的衣服。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 20:9; 利未记 19:17; 撒母耳记下 13:3"> 犹大托他的朋友亚杜兰人送那只山羊羔去，要从那女人手里取回抵押物，却找不到她。</span>
<span className="v" id="v21" data-v="21"> 他就问那地方的人说：“在路旁伊拿印的那个妓女在哪里？”<br />他们说：“这里没有过妓女。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 他回到犹大那里，说：“我没有找到她；而且那地方的人也说：‘这里没有过妓女。’”</span>
<span className="v" id="v23" data-v="23" data-xref="以弗所书 5:12; 箴言 6:33; 启示录 16:15"> 犹大说：“让她拿去吧，免得我们蒙羞。看哪，我送了这只山羊羔去，你却没有找到她。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="利未记 21:9; 以西结 23:19; 士师记 19:2"> 大约三个月以后，有人告诉犹大说：“你的儿媳他玛作了妓女；而且看哪，她因作妓女怀了孕。”<br />犹大说：“把她带出来，烧死她。”</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 37:32; 创世记 38:18; 哥林多前书 4:5"> 她被带出来的时候，就打发人去见她公公，说：“我从这些东西的主人怀了孕。”她又说：“请认一认，这印章、印绳和杖是谁的。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="撒母耳记上 24:17; 约翰福音 8:9; 提多书 2:11–12"> 犹大认出了这些，就说：“她比我更义，因为我没有把她给我的儿子示拉。”<br />犹大不再与她同房了。</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 25:24"> 到了她生产的时候，看哪，她腹中是一对双胞胎。</span>
<span className="v" id="v28" data-v="28"> 她生产时，一个孩子伸出一只手；接生婆就拿朱红线系在他的手上，说：“这是先出来的。”</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 2:4; 马太福音 1:3; 创世记 46:12"> 他把手缩回去的时候，看哪，他的兄弟出来了；接生婆说：“你为什么为自己冲出了一个破口呢？”因此，他的名叫法勒斯。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="法勒斯意为“冲破”。">a</a></sup></span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 9:6; 历代志上 2:4; 马太福音 1:3"> 后来，他那手上有朱红线的兄弟也出来了，他的名叫谢拉。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="谢拉意为“朱红色”或“光亮”。">b</a></sup></span>
</div>
</div>

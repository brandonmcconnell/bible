<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 11:3; 哥林多后书 11:14; 启示录 12:9"> 在耶和华上帝所造的田野一切动物中，蛇比任何一种都更狡猾。它对女人说：“上帝真的说过，‘你们不可吃园中任何树上的果子’吗？”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="诗篇 58:4"> 女人对蛇说：“园中树上的果子，我们可以吃；</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 2:16–17; 哥林多后书 6:17; 出埃及记 19:12–13"> 只是园子中间那棵树上的果子，上帝说过：‘你们不可吃，也不可摸，免得你们死。’”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰福音 8:44; 哥林多后书 11:3; 提摩太前书 2:14"> 蛇对女人说：“你们绝不会死，</span>
<span className="v" id="v5" data-v="5" data-xref="以西结 28:2; 帖撒罗尼迦后书 2:4; 哥林多后书 11:13–15"> 因为上帝知道，你们吃的那一天，你们的眼睛就会打开，你们会像上帝一样，知道善恶。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约翰一书 2:16; 雅各书 1:14–15; 提摩太前书 2:14"> 于是女人见那棵树的果子好作食物，又悦人眼目，而且那棵树令人喜爱，能使人有智慧，就摘下果子来吃了。她又给了和她在一起的丈夫，他也吃了。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 59:6; 创世记 2:25; 创世记 3:5"> 他们二人的眼睛就打开了，知道自己是赤身露体的。他们便把无花果树的叶子缝在一起，为自己做遮身的东西。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 23:24; 箴言 15:3; 希伯来书 4:13"> 天凉的时候，他们听见耶和华上帝在园中行走的声音，那人和他的妻子就藏在园中的树木中，躲避耶和华上帝的面。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 4:9; 创世记 16:8; 创世记 18:20–21"> 耶和华上帝呼唤那人，对他说：“你在哪里？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 2:25; 诗篇 119:120; 以赛亚书 47:3"> 那人说：“我在园中听见你的声音，因为我赤身露体，就害怕；所以我藏了起来。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="罗马书 3:20; 创世记 4:10; 诗篇 50:21"> 上帝说：“谁告诉你赤身露体呢？我吩咐你不可吃的那棵树上的果子，你吃了吗？”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="箴言 28:13; 雅各书 1:13–15; 约伯记 31:33"> 那人说：“你赐给我、与我在一起的女人，她把那棵树上的果子给我，我就吃了。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 11:3; 提摩太前书 2:14; 创世记 4:10–12"> 耶和华上帝对女人说：“你做了什么事？”<br />女人说：“蛇欺骗了我，我就吃了。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="弥迦书 7:17; 以赛亚书 65:25; 诗篇 72:9"> 耶和华上帝对蛇说：<br /><span className="pl pl-1">“因为你做了这事，</span><br /><span className="pl pl-2">你在一切牲畜和田野一切动物中受咒诅。</span><br /><span className="pl pl-1">你必用肚子行走，</span><br /><span className="pl pl-2">你一生的日子都要吃尘土。</span></span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 16:20; 约翰一书 3:8; 启示录 12:17"> <span className="pl pl-1">我要使你和女人彼此为敌，</span><br /><span className="pl pl-2">你的后裔和她的后裔也彼此为敌。</span><br /><span className="pl pl-1">他要击伤你的头，</span><br /><span className="pl pl-2">你要击伤他的脚跟。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="提多书 2:5; 歌罗西书 3:18; 哥林多前书 11:3"> 对女人，祂说：<br /><span className="pl pl-1">“我必大大增加你生育的痛苦。</span><br /><span className="pl pl-2">你必在痛苦中生儿女。</span><br /><span className="pl pl-1">你必恋慕你的丈夫，</span><br /><span className="pl pl-2">他必管辖你。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="罗马书 8:20–22; 创世记 5:29; 以赛亚书 24:5–6"> 对亚当，祂说：<br /><span className="pl pl-1">“因为你听从了妻子的话，</span><br /><span className="pl pl-2">又吃了那棵树上的果子，</span><br /><span className="pl pl-2">就是我吩咐你说‘你不可吃’的那棵树，</span><br /><span className="pl pl-2">地就因你的缘故受咒诅。</span><br /><span className="pl pl-1">你一生的日子必劳苦，才能从地里得食物。</span></span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 13:7; 约伯记 5:5; 以赛亚书 7:23"> <span className="pl pl-2">地必给你长出荆棘和蒺藜；</span><br /><span className="pl pl-2">你也要吃田间的菜蔬。</span></span>
<span className="v" id="v19" data-v="19" data-xref="传道书 12:7; 约伯记 34:15; 诗篇 104:29"> <span className="pl pl-1">你必汗流满面才得吃饼，直到你归于地，</span><br /><span className="pl pl-2">因为你是从地里取出来的。</span><br /><span className="pl pl-1">你本是尘土，</span><br /><span className="pl pl-2">也必归于尘土。”</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 2:23; 马太福音 1:23; 创世记 5:29"> 那人给他的妻子起名叫夏娃，因为她要成为一切活人的母亲。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 61:10; 哥林多后书 5:21; 哥林多后书 5:2–3"> 耶和华上帝为亚当和他的妻子用动物皮做衣服，给他们穿上。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="启示录 2:7; 启示录 22:14; 箴言 3:18"> 耶和华上帝说：“看哪，那人已经像我们中间的一个，知道善恶。现在，恐怕他伸出手来，又摘生命树的果子吃，就永远活着——”</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 4:2; 创世记 3:19; 创世记 4:12"> 因此，耶和华上帝把他从伊甸园送出去，去耕种他所出自的土地。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 1:7; 诗篇 104:4; 出埃及记 25:18–22"> 于是祂赶出那人；又在伊甸园的东边安设基路伯<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="基路伯是有能力的天使般受造物，是带翅膀的上帝使者。见以西结书10章。">a</a></sup>，以及四面转动、发火焰的剑，守卫通往生命树的道路。</span>
</div>

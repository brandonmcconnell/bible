<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="GEN" data-book-slug="genesis" data-book-name="创世记" data-chapter="26" data-verses="35">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 12:10; 创世记 25:11; 创世记 21:22–32"> 那地有饥荒，是亚伯拉罕的日子曾有的第一次饥荒以外的另一次。以撒往基拉耳去，到非利士人的王亚比米勒那里。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 12:7; 诗篇 37:3; 创世记 17:1"> 耶和华向他显现，说：“不要下埃及去；要住在我指示你的地。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 28:15; 诗篇 105:9; 创世记 17:8"> 你要寄居在这地，我必与你同在，赐福给你；因为我要把这一切地方赐给你和你的后裔，并要坚立我向你父亲亚伯拉罕所起的誓。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 3:25; 创世记 15:5; 创世记 22:17–18"> 我要使你的后裔增多，如天上的星那样多，并要把这一切地方赐给你的后裔。地上的万国都必因你的后裔蒙福，</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 7:24; 创世记 22:18; 创世记 22:16"> 因为亚伯拉罕听从我的声音，遵守我的吩咐、我的命令、我的律例和我的律法。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 20:1"> 以撒就住在基拉耳。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 29:25; 创世记 12:13; 创世记 20:2"> 那地方的人问起他的妻子，他说：“她是我的妹妹。”因为他害怕说：“她是我的妻子。”他心想：“恐怕这地方的人会为了利百加杀我，因为她容貌美丽。”</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 62:5; 箴言 5:18–19; 箴言 7:6"> 他在那里住了很久。有一天，非利士人的王亚比米勒从窗户往外观看，看哪，见以撒正与他的妻子利百加亲昵。</span>
<span className="v" id="v9" data-v="9"> 亚比米勒召了以撒来，说：“看哪，她明明是你的妻子！你为什么说：‘她是我的妹妹’？”<br />以撒对他说：“因为我说：‘恐怕我因她而死。’”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 20:9–10; 创世记 12:18–19"> 亚比米勒说：“你向我们做的这是什么事？百姓中有人很容易就会与你的妻子同寝，你就把罪责带到我们身上了！”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="诗篇 105:15; 创世记 20:6; 箴言 6:29"> 亚比米勒吩咐众民说：“凡碰这人或他妻子的，必要被处死。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马可福音 4:8; 创世记 24:1; 创世记 26:3"> 以撒在那地撒种，那一年收获了所种的一百倍。耶和华赐福给他。</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 112:3; 箴言 10:22; 创世记 24:35"> 这人日渐昌大，越来越兴盛，直到极其昌大。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 37:11; 创世记 13:2; 箴言 27:4"> 他拥有羊群、牛群和许多家仆。非利士人就嫉妒他。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 21:30; 创世记 21:25"> 当他父亲亚伯拉罕在世的日子，他父亲的仆人所挖的一切井，非利士人都塞住了，用土填满。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 1:9"> 亚比米勒对以撒说：“你离开我们吧，因为你比我们强盛得多。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 以撒就离开那里，在基拉耳谷安营，住在那里。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒迦利亚书 13:2; 何西阿 2:17; 民数记 32:38"> 他父亲亚伯拉罕在世的日子所挖的水井，亚伯拉罕死后非利士人塞住了，以撒又重新挖出来，并按他父亲给它们所起的名字，仍叫那些名字。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 4:10–11; 约翰福音 7:38; 雅歌 4:15"> 以撒的仆人在谷中挖井，在那里挖到一口流动<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：活的；或：新鲜的。">a</a></sup>的水井。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 21:25"> 基拉耳的牧人与以撒的牧人争论，说：“这水是我们的。”因此以撒给那井起名叫埃色，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“埃色”的意思是“争竞”。">b</a></sup>因为他们与他相争。</span>
<span className="v" id="v21" data-v="21" data-xref="以斯拉记 4:6"> 他们又挖了另一口井，也为那井争论。因此以撒给那井起名叫西提拿。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“西提拿”的意思是“敌对”。">c</a></sup></span>
<span className="v" id="v22" data-v="22" data-xref="创世记 17:6; 出埃及记 1:7; 诗篇 118:5"> 他离开那里，又挖了另一口井，他们不再为这井争论。因此他给那井起名叫利河伯。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“利河伯”的意思是“宽阔之处”。">d</a></sup>他说：“因为现在耶和华给我们宽阔之地，我们必在这地繁盛。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="士师记 20:1; 创世记 21:31; 创世记 46:1"> 以撒从那里上别是巴去。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 15:1; 出埃及记 3:6; 以赛亚书 43:1–2"> 当夜，耶和华向他显现，说：“我是你父亲亚伯拉罕的上帝。不要惧怕，因为我与你同在；为了我仆人亚伯拉罕的缘故，我必赐福给你，使你的后裔增多。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 13:18; 诗篇 116:17; 创世记 12:7–8"> 以撒在那里筑了一座祭坛，求告耶和华的名，并在那里支搭帐篷。以撒的仆人也在那里挖了一口井。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="创世记 21:22–32; 创世记 20:3"> 后来，亚比米勒从基拉耳到以撒那里去，同来的有他的朋友亚户撒和他的军长非各。</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 26:16; 士师记 11:7; 使徒行传 7:14"> 以撒对他们说：“你们既然恨我，把我从你们那里打发走，为什么还到我这里来呢？”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="创世记 21:22–23; 以赛亚书 45:14; 以赛亚书 61:9"> 他们说：“我们清楚看见耶和华与你同在，就说：‘现在让我们之间，就是我们和你之间有誓约；让我们与你立约，</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 24:31; 创世记 21:22; 创世记 22:17"> 使你不加害于我们，正如我们没有碰你，除了善待你以外，什么也没有向你做，并且平平安安地把你送走。’你现在是蒙耶和华赐福的人。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="创世记 19:3; 罗马书 12:18; 希伯来书 12:14"> 以撒就为他们设摆筵席，他们便吃喝。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记上 20:16–17; 希伯来书 6:16; 创世记 25:33"> 他们清早起来，彼此起誓。以撒送他们走，他们就平平安安地离开他去了。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 10:4; 箴言 13:4; 箴言 2:4–5"> 就在那一天，以撒的仆人来，把他们所挖的井告诉他，对他说：“我们找到水了。”</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 21:31; 创世记 26:28"> 他给那井起名叫“示巴”。<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="“示巴”的意思是“誓言”或“七”。">e</a></sup>因此那城名叫“别是巴”<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="“别是巴”的意思是“誓言之井”或“七之井”。">f</a></sup>，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="创世记 36:2; 创世记 36:13; 出埃及记 34:16"> 以扫四十岁的时候，娶了赫人比利的女儿犹滴，又娶了赫人以伦的女儿巴实抹为妻。</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 27:46–2; 创世记 28:8; 创世记 6:2"> 她们使以撒和利百加心里愁烦。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 37:28; 诗篇 105:17; 创世记 37:36"> 约瑟被带下埃及。法老的官员、护卫长波提乏，是一个埃及人；他从把约瑟带到那里的以实玛利人手中买了约瑟。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 18:14; 诗篇 91:15; 耶利米书 15:20"> 耶和华与约瑟同在，他就凡事顺利。他住在他埃及主人家里。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 1:3; 创世记 30:27; 马太福音 5:16"> 他的主人看见耶和华与他同在，又看见耶和华使他手中所做的一切都顺利。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 39:21–22; 箴言 27:18; 创世记 19:19"> 约瑟在他眼前蒙恩，服侍他；波提乏就派他管理自己的家，把自己所有的一切都交在他手中。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 30:27; 撒母耳记下 6:11–12; 使徒行传 27:24"> 自从波提乏派约瑟管理他的家和他所有的一切以后，耶和华因约瑟的缘故赐福给那埃及人的家。耶和华的赐福临到他所有的一切，无论是在家里还是在田间。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 16:12; 路加福音 19:17; 箴言 31:11"> 波提乏把自己所有的一切都留在约瑟手中；除了自己所吃的食物以外，别的事他一概不管。<br />约瑟体格健美，容貌俊美。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 13:11; 以西结 16:34; 彼得后书 2:14"> 这些事以后，他主人的妻子看上了约瑟，对他说：“你与我同寝吧。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="箴言 23:26–28; 箴言 22:14; 箴言 9:13–18"> 约瑟却拒绝，对他主人的妻子说：“看哪，我主人有我在家里，什么事都不管，并且把他所有的一切都交在我手中。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 12:13; 创世记 20:6; 创世记 42:18"> 在这家里没有人比我大；除了你以外，他没有一样不交给我，因为你是他的妻子。我怎能做这样大的恶事，得罪上帝呢？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="彼得前书 2:11; 创世记 39:8; 帖撒罗尼迦前书 5:22"> 她天天对约瑟这样说，他却不听从她，不与她同寝，也不和她在一起。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 5:12; 以弗所书 5:3; 玛拉基书 3:5"> 有一天，约瑟进屋去做他的工作，家里的人没有一个在屋里。</span>
<span className="v" id="v12" data-v="12" data-xref="提摩太后书 2:22; 箴言 7:13–27; 传道书 7:26"> 她抓住他的衣服，说：“你与我同寝吧！”<br />约瑟把衣服留在她手中，跑到外面去了。</span>
<span className="v" id="v13" data-v="13"> 她看见约瑟把衣服留在她手中，跑到外面去了，</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 10:21; 彼得前书 2:20; 诗篇 35:11"> 就叫了家里的人来，对他们说：“看哪，他把一个希伯来人带到我们这里来戏弄我们。那人进来要与我同寝，我就大声呼喊。</span>
<span className="v" id="v15" data-v="15"> 他听见我提高声音呼喊，就把衣服留在我身边，跑到外面去了。”</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 37:32; 耶利米书 4:22; 耶利米书 9:3–5"> 她把约瑟的衣服放在自己身边，直到他的主人回家。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 23:1; 列王纪上 18:17; 诗篇 37:14"> 她照这些话对他说：“你带到我们这里来的那个希伯来仆人，进来要戏弄我；</span>
<span className="v" id="v18" data-v="18"> 我提高声音呼喊，他就把衣服留在我身边，跑到外面去了。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="创世记 4:5–6; 箴言 18:17; 箴言 6:34–35"> 约瑟的主人听见妻子对他说的话，说“你的仆人就是这样对待我的”，他的怒气就发作。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 40:15; 提摩太后书 2:9; 诗篇 105:18–19"> 约瑟的主人把约瑟带走，关进监狱，就是王的囚犯被囚禁的地方；约瑟就在那里被关押。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 3:21; 以赛亚书 41:10; 彼得前书 3:17"> 但耶和华与约瑟同在，以慈爱待他，使他在司狱眼前蒙恩。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 40:3–4; 创世记 39:4; 撒母耳记上 2:30"> 司狱把监狱里所有的囚犯都交在约瑟手中；他们在那里所做的一切，都由约瑟负责。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 43:2; 创世记 39:2–3; 诗篇 1:3"> 凡交在约瑟手下的事，司狱一概不管，因为耶和华与约瑟同在；约瑟所做的，耶和华都使它顺利。</span>
</div>
</div>

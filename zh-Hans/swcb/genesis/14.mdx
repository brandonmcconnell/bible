<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 10:10; 创世记 10:22; 以赛亚书 37:12"> 当示拿王暗拉非、以拉撒王亚略、以拦王基大老玛和戈印王提达在位的日子，</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 13:10; 申命记 29:23; 创世记 10:19"> 他们与所多玛王比拉、蛾摩拉王比沙、押玛王示纳、洗扁王善以别，以及比拉王（比拉又名琐珥）交战。</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 3:16; 申命记 3:17; 民数记 34:12"> 这些王都在西订谷（又名盐海）会合。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 9:25–26; 以西结 17:15"> 他们服事基大老玛十二年，第十三年就背叛了。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 3:11; 创世记 15:20; 申命记 1:4"> 第十四年，基大老玛和与他同盟的众王来到，在亚特律加宁击败利乏音人，在哈麦击败苏西人，在沙微基列亭击败以米人，</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 2:22; 申命记 2:12; 创世记 21:21"> 又在何利人的西珥山击败何利人，一直打到靠近旷野的伊勒巴兰。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 20:2; 创世记 16:14; 创世记 20:1"> 他们转回，来到安密巴（又名加低斯），击败亚玛力人的全境，也击败住在哈洗逊他玛的亚摩利人。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 19:22; 创世记 13:10; 创世记 19:20"> 所多玛王、蛾摩拉王、押玛王、洗扁王和比拉王（比拉又名琐珥）都出战，在西订谷摆阵迎敌，</span>
<span className="v" id="v9" data-v="9"> 对抗以拦王基大老玛、戈印王提达、示拿王暗拉非和以拉撒王亚略；四王对抗五王。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 19:17; 创世记 19:30; 以赛亚书 24:18"> 西订谷满是柏油坑；所多玛王和蛾摩拉王逃跑，有些人就在那里掉进坑里，剩下的人逃到山地去了。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 14:21; 创世记 14:16; 申命记 28:31"> 四王夺取了所多玛和蛾摩拉一切的财物，以及他们所有的粮食，就离去了。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 12:5; 创世记 11:27; 启示录 3:19"> 他们也把住在所多玛的亚伯兰兄弟的儿子罗得和他的财物掳去，离开了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 13:18; 创世记 14:24; 创世记 40:15"> 有一个逃出来的人来告诉希伯来人亚伯兰。那时，亚伯兰住在亚摩利人幔利的橡树旁；幔利是以实各的兄弟，又是亚乃的兄弟，他们都是亚伯兰的盟友。</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 18:29; 创世记 15:3; 创世记 17:27"> 亚伯兰听见他的亲属被掳，就率领他家里出生、受过训练的三百一十八人，一直追到但。</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 9:2; 诗篇 112:5; 列王纪上 15:18"> 夜间，他和他的仆人分兵攻击他们，击败了他们，又追赶他们直到大马士革北边的何把。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 30:18–19; 撒母耳记上 30:8; 创世记 12:2"> 他把一切财物夺回来，也把他的亲属罗得和他的财物，以及妇女和其他人都带了回来。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 18:18; 箴言 19:4; 希伯来书 7:1"> 亚伯兰击败基大老玛和与他同盟的众王回来以后，所多玛王出来，在沙微谷（就是王谷）迎接他。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 6:20–3; 诗篇 110:4; 希伯来书 5:6"> 撒冷王麦基洗德带着饼和酒出来；他是至高上帝的祭司。</span>
<span className="v" id="v19" data-v="19" data-xref="希伯来书 7:6–7; 创世记 14:22; 诗篇 24:1"> 他祝福亚伯兰，说：“愿亚伯兰蒙至高上帝赐福，祂是天地的拥有者。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 28:22; 希伯来书 7:4–9; 玛拉基书 3:10"> 至高上帝是应当称颂的，祂把你的仇敌交在你手里。”<br />亚伯兰就把所得的一切拿出十分之一给他。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 所多玛王对亚伯兰说：“你把人给我，财物你自己拿去吧。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="但以理 12:7; 但以理 4:34; 申命记 32:40"> 亚伯兰对所多玛王说：“我已经向耶和华——至高上帝、天地的拥有者——举手起誓，</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 5:16; 哥林多后书 11:9–12; 以斯帖记 9:15–16"> 凡是属于你的，即使一根线、一根鞋带，或任何东西，我都不拿，免得你说：‘我使亚伯兰富足。’</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 14:13; 箴言 3:27; 马太福音 7:12"> 除了年轻人已经吃用的，以及与我同行的人所得的份，就是亚乃、以实各和幔利所得的份，我什么都不要。让他们拿自己的份吧。”</span>
</div>

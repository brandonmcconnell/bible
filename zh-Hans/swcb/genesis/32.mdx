<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 91:11; 诗篇 34:7; 希伯来书 1:4"> 雅各继续上路，上帝的使者遇见了他。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 2:8; 约书亚记 5:14; 约书亚记 21:38"> 雅各看见他们，就说：“这是上帝的军营。”他给那地方起名叫玛哈念。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“玛哈念”的意思是“两个营”。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 25:30; 约书亚记 24:4; 申命记 2:5"> 雅各派使者在他前面，往西珥地、以东境内，到他哥哥以扫那里去。</span>
<span className="v" id="v4" data-v="4" data-xref="彼得前书 3:6; 路加福音 14:11; 创世记 33:8"> 他吩咐他们说：“你们要这样告诉我主以扫：‘你的仆人雅各这样说：我曾在拉班那里寄居，一直到现在。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 33:8; 创世记 33:15; 创世记 33:11"> 我有牛、驴、羊群、男仆和女仆。现在我派人来告诉我主，为要在你眼前蒙恩。’”</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 33:1; 创世记 32:8; 创世记 32:11"> 使者回到雅各那里，说：“我们到了你哥哥以扫那里。他正来迎接你，并且有四百人和他在一起。”</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 35:3; 哥林多后书 1:8–10; 出埃及记 14:10"> 雅各就非常害怕，心里愁烦。他把和他在一起的人，以及羊群、牛群和骆驼，分成两队。</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 10:16; 创世记 33:1–3"> 他说：“如果以扫来到这一队，击杀他们，剩下的那一队还可以逃脱。”</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 31:42; 诗篇 34:4–6; 创世记 31:3"> 雅各说：“我父亲亚伯拉罕的上帝，我父亲以撒的上帝，耶和华啊，你曾对我说：‘回到你的本地、你的亲族那里去，我必善待你。’</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 18:35; 创世记 24:27; 撒母耳记下 7:18"> 你向仆人所施的一切慈爱和一切信实，最小的我也不配得；因为我只拿着我的杖过了这约旦河，如今却成了两队。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 59:1–2; 箴言 18:19; 马太福音 6:13"> 求你救我脱离我哥哥的手，脱离以扫的手；因为我怕他，恐怕他来击杀我，连母亲带儿女一同击杀。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 28:13–15; 希伯来书 6:17; 提多书 1:2"> 你曾说：‘我必定善待你，使你的后裔像海边的沙，多得数不清。’”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 18:16; 创世记 43:11; 箴言 19:6"> 那一夜，雅各住在那里，从他所有的财物中取出礼物，要送给他哥哥以扫：</span>
<span className="v" id="v14" data-v="14" data-xref="约伯记 1:3; 申命记 8:18; 约伯记 42:12"> 母山羊二百只，公山羊二十只，母绵羊二百只，公绵羊二十只，</span>
<span className="v" id="v15" data-v="15"> 有奶的骆驼三十匹，带着它们的驹；母牛四十头，公牛十头，母驴二十匹，驴驹十匹。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 33:8–9; 创世记 32:20; 箴言 2:11"> 他把这些分别交在仆人手里，每群各自分开，又对仆人说：“你们在我前面过去，使群与群之间隔开一段距离。”</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 33:3"> 他吩咐走在最前面的说：“我哥哥以扫遇见你的时候，若问你说：‘你是谁的人？你往哪里去？你前面这些是谁的？’</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 32:4–5"> 你就说：‘这些是你仆人雅各的，是送给我主以扫的礼物。看哪，他自己也在我们后面。’”</span>
<span className="v" id="v19" data-v="19"> 他又吩咐第二队、第三队和所有跟在各群后面的人，说：“你们遇见以扫的时候，也要这样对他说。</span>
<span className="v" id="v20" data-v="20" data-xref="约伯记 42:8–9; 箴言 21:14; 创世记 43:11"> 你们还要说：‘不但如此，看哪，你的仆人雅各也在我们后面。’”因为他说：“我要用走在我前面的礼物平息他的怒气，然后再见他的面。也许他会接纳我。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 于是礼物在他前面过去；那一夜，他自己留在营中。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命记 3:16; 申命记 2:37; 提摩太前书 5:8"> 那一夜，雅各起来，带着他的两个妻子、两个女仆和十一个儿子，过了雅博渡口。</span>
<span className="v" id="v23" data-v="23"> 他带他们过了溪，又把他所有的都送过去。</span>
<span className="v" id="v24" data-v="24" data-xref="何西阿 12:3–5; 以弗所书 6:12; 路加福音 13:24"> 雅各独自留下，有一个人与他摔跤，直到天快亮。</span>
<span className="v" id="v25" data-v="25" data-xref="哥林多后书 12:7–9; 何西阿 12:3–4; 马太福音 26:41"> 那人见自己不能胜过他，就摸了他的大腿窝；雅各的大腿窝在摔跤的时候就扭伤了。</span>
<span className="v" id="v26" data-v="26" data-xref="何西阿 12:4; 诗篇 115:12–13; 哥林多后书 12:8–9"> 那人说：“让我走吧，因为天快亮了。”<br />雅各说：“你不给我祝福，我就不让你走。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 那人对他说：“你叫什么名字？”<br />他说：“雅各。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="启示录 2:17; 创世记 35:10; 以赛亚书 62:2–4"> 那人说：“你的名字不要再叫雅各，要叫以色列；因为你与上帝和人较力，并且得胜了。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 9:6; 士师记 13:16–18; 约伯记 11:7"> 雅各问他说：“请告诉我你的名字。”<br />那人说：“你为什么问我的名字？”于是他在那里给雅各祝福。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及记 24:10–11; 民数记 12:8; 以赛亚书 6:5"> 雅各给那地方起名叫毗努伊勒；<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="毗努伊勒的意思是“上帝的面”。">b</a></sup>因为他说：“我面对面见了上帝，我的生命仍蒙保全。”</span>
<span className="v" id="v31" data-v="31" data-xref="哥林多后书 12:7; 创世记 19:15; 士师记 8:8"> 他经过毗努伊勒的时候，太阳升起来照在他身上；他因大腿的缘故一瘸一拐。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 5:5"> 因此，以色列人直到今日都不吃大腿窝上髋部的筋，因为那人摸了雅各大腿窝上髋部的筋。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 41:50–52; 创世记 46:20; 诗篇 128:6"> 这些事以后，有人对约瑟说：“看哪，你父亲病了。”约瑟就带着他的两个儿子玛拿西和以法莲同去。</span>
<span className="v" id="v2" data-v="2" data-xref="以弗所书 6:10; 撒母耳记上 23:16; 申命记 3:28"> 有人告诉雅各说：“看哪，你儿子约瑟到你这里来了。”以色列就勉强支撑自己，在床上坐起来。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 35:9–12; 出埃及记 6:3; 创世记 28:3"> 雅各对约瑟说：“全能的上帝曾在迦南地的路斯向我显现，赐福给我，</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 17:8; 创世记 35:11; 创世记 26:4"> 对我说：‘看哪，我要使你生养众多，使你增多，使你成为多族的群体；我要把这地赐给你以后的后裔，作永远的产业。’</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 41:50–52; 约书亚记 14:4; 创世记 46:20"> 现在，我来到埃及你这里以前，你在埃及地所生的两个儿子是我的；以法莲和玛拿西要像流便和西缅一样归我。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 14:4"> 你在他们以后所生的后裔，才归你；他们在自己的产业中，要归在他们兄弟的名下。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 35:16–19; 马太福音 2:18; 创世记 35:9"> 至于我，我从巴旦来的时候，拉结在迦南地的路上、离以法他还有一段路的地方，在我身旁死了；我就把她葬在那里，在通往以法他的路上（以法他又叫伯利恒）。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 以色列看见约瑟的儿子们，就说：“这些是谁？”</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="创世记 27:4; 创世记 33:5; 希伯来书 11:21"> 约瑟对他父亲说：“他们是上帝在这里赐给我的儿子。”<br />他说：“请把他们带到我这里来，我要给他们祝福。”</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 27:1; 创世记 27:27; 撒母耳记上 3:2"> 以色列因年老眼睛昏花，不能看清楚。约瑟把他们带近他；他就亲吻他们，拥抱他们。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 3:20; 创世记 45:26; 创世记 42:36"> 以色列对约瑟说：“我本以为见不到你的面，看哪，上帝竟也让我看见你的后裔。”</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 42:6; 利未记 19:32; 创世记 19:1"> 约瑟把他们从以色列两膝之间领出来，自己脸伏于地敬拜。</span>
<span className="v" id="v13" data-v="13"> 约瑟拉着他们两人，用右手拉以法莲，对着以色列的左手；用左手拉玛拿西，对着以色列的右手，把他们带近他。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 41:51; 诗篇 118:16; 马太福音 19:15"> 以色列伸出右手，按在年幼的以法莲头上，又把左手按在玛拿西头上；他有意这样交叉双手，因为玛拿西是长子。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 17:1; 歌罗西书 2:6; 以赛亚书 33:16"> 他给约瑟祝福，说：<br /><span className="pl pl-1">“愿我祖亚伯拉罕和以撒所行在祂面前的上帝，</span><br /><span className="pl pl-1">就是从我一生直到今日牧养我的上帝，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 34:22; 创世记 49:22; 创世记 48:5"> <span className="pl pl-1">那救赎我脱离一切祸患的使者，赐福给这两个孩子；</span><br /><span className="pl pl-1">愿我的名归在他们身上，</span><br /><span className="pl pl-1">我祖亚伯拉罕和以撒的名也归在他们身上；</span><br /><span className="pl pl-1">愿他们在地上繁衍众多。”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 48:14; 罗马书 9:7–8; 历代志上 21:7"> 约瑟见他父亲把右手按在以法莲的头上，就不高兴，便托起他父亲的手，要把它从以法莲的头上移到玛拿西的头上。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 19:18; 创世记 29:26; 创世记 43:33"> 约瑟对他父亲说：“我父，不是这样；这个才是长子。请把你的右手按在他的头上。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命记 33:17; 民数记 1:33–35; 创世记 25:28"> 他父亲却不肯，说：“我知道，我儿，我知道。他也必成为一族，他也必兴盛；不过他的弟弟必比他更大，他的后裔必成为多国。”</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 24:60; 路得记 4:11–12; 创世记 28:3"> 当日，他给他们祝福说：“以色列人要用你们的名祝福，说：‘愿上帝使你像以法莲、像玛拿西一样。’”他把以法莲立在玛拿西前面。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 50:24; 创世记 46:4; 创世记 28:15"> 以色列对约瑟说：“看哪，我快要死了，但上帝必与你们同在，带你们回到你们祖先之地。</span>
<span className="v" id="v22" data-v="22" data-xref="约翰福音 4:5; 约书亚记 24:32; 历代志上 5:2"> 此外，我比给你弟兄的多给你一份，就是我用刀用弓从亚摩利人手中夺来的。”</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 1:28"> 当人在地面上开始增多，又有女儿生给他们的时候，</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 82:6–7; 约翰一书 2:16; 彼得后书 2:14"> 上帝的儿子们看见人的女儿美丽，就随意挑选，娶来为妻。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 9:30; 以赛亚书 63:10; 耶利米书 11:11"> 耶和华说：“我的灵必不永远与人相争，因为他也是血肉之躯；所以他的日子要有一百二十年。”</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 13:33; 撒母耳记下 21:15–22; 撒母耳记上 17:4"> 那些日子，尼非利人<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：巨人">a</a></sup>在地上；后来也是这样。上帝的儿子们与人的女儿同房，她们给他们生了儿女。那些人就是古时的勇士，有名的人。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马太福音 15:19; 罗马书 1:28–31; 马可福音 7:21–23"> 耶和华看见人在地上的邪恶很大，人心里所思想的一切意念，终日尽都是恶。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 63:10; 撒母耳记上 15:11; 以弗所书 4:30"> 耶和华后悔祂在地上造了人，心中忧伤。</span>
<span className="v" id="v7" data-v="7" data-xref="西番雅书 1:3; 诗篇 37:20; 耶利米书 12:3–4"> 耶和华说：“我要把我所创造的人从地面上除灭——人，连同走兽、爬行动物和天空的飞鸟；因为我后悔造了他们。”</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 19:19; 希伯来书 4:16; 路加福音 1:30"> 但挪亚在耶和华眼前蒙恩。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 1:6; 希伯来书 11:7; 彼得后书 2:5"> 挪亚的世代记在下面：挪亚是个义人，在他那个世代的人中无可指摘。挪亚与上帝同行。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 5:32"> 挪亚生了三个儿子：闪、含和雅弗。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结 8:17; 何西阿 4:1–2; 哈巴谷 2:8"> 地在上帝面前败坏了，地上充满了暴力。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 53:2–3; 箴言 15:3; 诗篇 14:1–3"> 上帝观看这地，看哪，地已经败坏了；因为凡有血肉的都在地上败坏了自己的道路。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="何西阿 4:1–2; 彼得前书 4:7; 以西结 7:2–6"> 上帝对挪亚说：“凡有血肉的尽头已经来到我面前，因为地因他们充满了暴力。看哪，我要把他们和地一同毁灭。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 3:20; 路加福音 17:27; 马太福音 24:38"> 你要用歌斐木造一只方舟。方舟里要造隔间，里外都要涂上柏油。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 3:11; 创世记 7:20"> 你要这样造：方舟的长三百肘，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一肘是人手臂从中指指尖到肘部的长度，约十八英寸或四十六厘米。">b</a></sup>宽五十肘，高三十肘。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 8:6; 创世记 7:16; 以西结 41:16"> 你要给方舟造一个顶，使它向上收成一肘。你要把方舟的门开在旁边。方舟要分下层、中层和上层。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 7:4; 彼得后书 2:5; 创世记 7:21–23"> 看哪，我要使洪水泛滥在这地上，毁灭天下凡有生命气息的血肉之物。地上的一切都要死。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 11:7; 创世记 7:7; 创世记 17:7"> 但我要与你立我的约。你要进入方舟，你和你的儿子、你的妻子，以及你儿子的妻子，都要与你一同进去。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 7:15–16; 创世记 7:8–9; 创世记 8:17"> 凡有血肉的一切活物，每一类你都要带两个进方舟，使它们与你一同存活；它们要有公有母。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 10:11–12; 创世记 2:19; 创世记 7:8–16"> 飞鸟各从其类，牲畜各从其类，地上各样爬行动物各从其类，每一类都要有两个到你那里来，使它们存活。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 1:29–30; 诗篇 145:16; 诗篇 136:25"> 你要把各种可吃的食物带在身边，积聚起来；这要作你和它们的食物。”</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 40:16; 约翰福音 15:14; 马太福音 7:24–27"> 挪亚就这样做了。凡上帝吩咐他的，他都照样做了。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 12:10; 使徒行传 7:11–13; 耶利米哀歌 5:10"> 那地的饥荒很严重。</span>
<span className="v" id="v2" data-v="2" data-xref="提摩太前书 6:6–8; 箴言 16:18; 箴言 15:16"> 他们从埃及带来的粮食吃完以后，他们的父亲对他们说：“你们再去给我们买一点食物来。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 44:23; 创世记 43:5; 撒母耳记下 3:13"> 犹大对他说：“那人严严地警告我们说：‘除非你们的兄弟和你们同来，否则你们不得见我的面。’</span>
<span className="v" id="v4" data-v="4"> 如果你让我们的兄弟和我们同去，我们就下去给你买食物；</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 20:12; 创世记 44:26; 创世记 42:38"> 如果你不让他去，我们就不下去，因为那人对我们说：‘除非你们的兄弟和你们同来，否则你们不得见我的面。’”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 以色列说：“你们为什么这样害我，告诉那人你们还有一个兄弟呢？”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="创世记 43:3; 创世记 42:13; 创世记 43:27"> 他们说：“那人仔细询问我们和我们的亲属，说：‘你们的父亲还活着吗？你们还有兄弟吗？’我们只是照着他问的回答他。我们怎么会知道他会说：‘把你们的兄弟带下来’呢？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="创世记 42:2; 申命记 33:6; 创世记 45:19"> 犹大对他父亲以色列说：“请让这孩子和我同去，我们就起身去，好叫我们、你，以及我们的孩子们都可以存活，不至于死。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 42:37; 腓利门书 1:18–19; 希伯来书 7:22"> 我愿为他作担保；你可以向我追讨他。我若不把他带回来交在你面前，就让我永远担当罪责；</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 19:16"> 因为如果我们没有耽搁，现在必定已经第二次回来了。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="创世记 37:25; 耶利米书 8:22; 以西结 27:17"> 他们的父亲以色列对他们说：“既然必须这样，你们就这样做：把这地上最好的出产装在器皿里，带下去送给那人作礼物，就是一点乳香、一点蜂蜜、香料、没药、坚果和杏仁；</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 42:25; 创世记 42:35; 帖撒罗尼迦前书 4:6"> 手里要带双倍的银钱，并且把归还在你们袋口里的银钱也带回去；也许那是疏忽。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 42:38"> 也带着你们的兄弟，起身回到那人那里去。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖记 4:16; 创世记 17:1; 使徒行传 21:14"> 愿全能的上帝使你们在那人面前蒙怜悯，好叫他释放你们另一个兄弟和便雅悯回来给你们。至于我，我若丧失儿女，就丧失吧。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 这些人就拿了那礼物，手里又带双倍的银钱，并带着便雅悯；他们起身下到埃及，站在约瑟面前。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 44:1; 创世记 43:19; 创世记 24:2–10"> 约瑟看见便雅悯和他们同来，就对他的管家说：“把这些人带进屋里，宰一只牲畜，预备好；因为这些人中午要和我一起吃饭。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 那人就照约瑟所吩咐的去做，把这些人带到约瑟的家里。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 42:35; 罗马书 7:8; 创世记 42:21"> 这些人因为被带到约瑟的家里，就害怕，说：“我们被带进来，是因为头一次归还在我们袋子里的银钱；他要找机会对付我们，袭击我们，把我们和我们的驴都抓去作奴隶。”</span>
<span className="v" id="v19" data-v="19"> 他们走近约瑟的管家，在屋门口对他说话，</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 42:3; 创世记 42:10; 创世记 42:27"> 说：“我主啊，我们头一次确实是下来买食物的。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 43:12; 创世记 42:27–35; 罗马书 13:8"> 后来我们到了住宿的地方，打开袋子，看哪，各人的银钱都在自己的袋口里，我们的银钱足数足量。现在我们已经把它带回在手里。</span>
<span className="v" id="v22" data-v="22"> 我们手里另外带了银钱下来买食物。我们不知道是谁把我们的银钱放在我们袋子里的。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约翰福音 20:26; 创世记 42:24; 约翰福音 14:27"> 他说：“愿你们平安，不要害怕。你们的上帝，就是你们父亲的上帝，已经把财宝赐给你们，放在你们的袋子里。你们的银钱我已经收了。”他就把西缅带出来交给他们。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 18:4; 创世记 24:32; 路加福音 7:44"> 那人把这些人带进约瑟的家，给他们水，他们就洗脚；他又给他们的驴草料。</span>
<span className="v" id="v25" data-v="25" data-xref="创世记 43:11; 创世记 43:16"> 他们预备好礼物，等候约瑟中午来，因为他们听说要在那里吃饭。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="腓立比书 2:10–11; 创世记 27:29; 创世记 42:6"> 约瑟回到家里，他们就把手中的礼物拿进屋里给他，并且俯伏在地向他下拜。</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 42:13; 撒母耳记上 25:5; 撒母耳记上 17:22"> 约瑟问他们好，说：“你们所说的那位老人，你们的父亲，他平安吗？他还活着吗？”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="创世记 37:7; 创世记 43:26; 撒母耳记下 14:4"> 他们说：“你的仆人，我们的父亲平安；他还活着。”他们就低头下拜。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 42:13; 民数记 6:25; 创世记 30:22–24"> 约瑟举目看见便雅悯，就是他同母的兄弟，就说：“这就是你们对我说过的那最小的兄弟吗？”又说：“我儿，愿上帝恩待你。”</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 42:24; 耶利米书 31:20; 列王纪上 3:26"> 约瑟急忙离开，因为他对弟弟心里激动，就找地方哭。他进了自己的房间，在那里哭了。</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 45:1; 彼得前书 3:10; 以赛亚书 42:14"> 他洗了脸，出来，克制自己，说：“摆饭吧。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="创世记 46:34; 出埃及记 8:26; 创世记 43:16"> 他们就给约瑟单独摆一席，给那些人单独摆一席，也给和他一起吃饭的埃及人单独摆一席；因为埃及人不和希伯来人一起吃饭，那对埃及人来说是可憎的事。</span>
<span className="v" id="v33" data-v="33"> 他们在约瑟面前坐下，长子按着他的长子名分，幼子按着他的年幼次序；这些人彼此惊奇。</span>
<span className="v" id="v34" data-v="34" data-xref="创世记 45:22; 撒母耳记下 11:8; 撒母耳记上 1:5"> 约瑟从自己面前分食物给他们；但便雅悯所得的一份比他们任何一人的多五倍。他们就喝酒，和约瑟一同欢宴。</span>
</div>
</div>

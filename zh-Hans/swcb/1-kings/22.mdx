<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 20:34"> 亚兰和以色列之间连续三年没有战争。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 15:24; 列王纪上 22:1; 列王纪上 22:41"> 第三年，犹大王约沙法下去见以色列王。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 4:43; 列王纪上 4:13; 约书亚记 21:38"> 以色列王对他的臣仆说：“你们知道基列的拉末是属于我们的，可是我们却无所作为，不从亚兰王手中夺回来吗？”</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 3:7; 以弗所书 5:11; 约翰二书 1:11"> 他对约沙法说：“你愿意和我一起去攻打基列的拉末吗？”<br />约沙法对以色列王说：“你我不分彼此，我的民如同你的民，我的马如同你的马。”</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 3:5–6; 历代志下 18:4–5; 耶利米书 42:2–6"> 约沙法又对以色列王说：“请你先求问耶和华的话。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王纪上 18:19; 耶利米书 23:14–17; 以西结 13:7–16"> 于是以色列王召集先知，约有四百人，对他们说：“我可以去攻打基列的拉末吗？还是应当作罢？”<br />他们说：“上去吧，因为主必将那城交在王手中。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王纪下 3:11–13; 历代志下 18:6–7"> 但约沙法说：“这里没有耶和华的先知，我们可以求问他吗？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="阿摩司 5:10; 约翰福音 3:19–21; 约翰福音 7:7"> 以色列王对约沙法说：“还有一个人，我们可以藉着他求问耶和华，就是音拉的儿子米该雅；只是我恨他，因为他指着我所说的预言，不说吉语，只说凶言。”<br />约沙法说：“王不要这样说。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王纪下 9:32; 以赛亚书 39:7; 列王纪上 22:26–27"> 于是以色列王叫来一个官员，说：“快去把音拉的儿子米该雅带来。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以斯帖记 5:1; 以斯帖记 6:8–9; 列王纪上 18:29"> 当时，以色列王和犹大王约沙法各穿朝服，坐在自己的宝座上，在撒玛利亚城门入口处的空场上；众先知都在他们面前说预言。</span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亚书 1:18–21; 申命记 33:17; 以西结 22:27–28"> 基拿拿的儿子西底家为自己造了铁角，说：“耶和华这样说：‘你要用这些角抵撞亚兰人，直到他们灭尽。’”</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 35:22; 列王纪上 22:6–15; 列王纪上 22:32–36"> 众先知也都这样说预言，说：“上基列的拉末去吧，必定顺利；因为耶和华必将那城交在王手中。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="弥迦书 2:6–7; 诗篇 11:1; 以赛亚书 30:10–11"> 去召米该雅的使者对他说：“看哪，众先知异口同声向王说吉语。请你也像他们中的一个人所说的话一样，说吉语。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 24:13; 民数记 22:18; 历代志下 18:12–13"> 米该雅说：“我指着永活的耶和华起誓，耶和华对我说什么，我就说什么。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王纪上 18:27; 士师记 10:14; 马太福音 26:45"> 他来到王那里，王问他说：“米该雅啊，我们可以去攻打基列的拉末吗？还是应当忍住不去？”<br />他回答他说：“上去吧，必定顺利；耶和华必将那城交在王手中。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="使徒行传 19:13; 马太福音 26:63; 约书亚记 6:26"> 王对他说：“我要你多少次奉耶和华的名起誓，才肯只对我说真话呢？”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民数记 27:17; 马太福音 9:36; 列王纪上 22:34–36"> 他说：“我看见全以色列散在山上，如同没有牧人的羊群。耶和华说：‘这些人没有主人；让他们各自平平安安地回家去吧。’”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王纪上 22:8; 箴言 10:24; 路加福音 11:45"> 以色列王对约沙法说：“我不是告诉过你，他指着我所说的预言，不说吉语，只说凶言吗？”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约伯记 2:1; 约伯记 1:6; 但以理 7:9–10"> 米该雅说：“因此，你要听耶和华的话。我看见耶和华坐在祂的宝座上，天上的全军侍立在祂左右。</span>
<span className="v" id="v20" data-v="20" data-xref="以西结 14:9; 约伯记 12:16; 耶利米书 4:10"> 耶和华说：‘谁去引诱亚哈，使他上去，倒在基列的拉末呢？’这个这样说，那个那样说。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="约伯记 2:1; 列王纪上 22:23; 约伯记 1:6–7"> 有一个灵出来，站在耶和华面前，说：‘我去引诱他。’</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="士师记 9:23; 撒母耳记上 19:9; 撒母耳记上 16:14"> 耶和华问他说：‘用什么方法？’<br />他说：‘我要出去，在他所有先知的口中作说谎的灵。’<br />耶和华说：‘你必能引诱他，也必成功；你去这样做吧。’</span>
<span className="v" id="v23" data-v="23" data-xref="以西结 14:9; 马太福音 24:24–25; 以赛亚书 44:20"> 现在，看哪，耶和华已经把说谎的灵放在你这些先知的口中；耶和华已经宣告灾祸要临到你。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="使徒行传 23:2; 耶利米哀歌 3:30; 弥迦书 5:1"> 基拿拿的儿子西底家走近来，打米该雅的脸颊，说：“耶和华的灵从哪条路离开我去对你说话呢？”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王纪上 20:30; 彼得后书 2:1; 启示录 19:20"> 米该雅说：“看哪，到那日你进内室躲藏的时候，就会看见了。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 以色列王说：“把米该雅带走，送回去交给城长亚们和王的儿子约阿施。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 16:10; 历代志下 18:25–27; 启示录 2:10"> 你们要说：‘王这样说：“把这个人关在监里，用困苦的饼和困苦的水养他，等到我平安回来。”’”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="民数记 16:29; 弥迦书 1:2; 使徒行传 13:10–11"> 米该雅说：“如果你真的能平安回来，耶和华就没有藉我说话。”他又说：“众民哪，你们都要听！”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="历代志下 18:28; 列王纪上 22:2–9"> 于是以色列王和犹大王约沙法上基列的拉末去了。</span>
<span className="v" id="v30" data-v="30" data-xref="历代志下 35:22; 耶利米书 23:24; 撒母耳记上 28:8"> 以色列王对约沙法说：“我要改装上阵；你仍穿你的朝服。”以色列王就改装上阵。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪上 20:24; 历代志下 18:30; 耶利米书 16:6"> 亚兰王已经吩咐他的三十二个战车长说：“无论大小，你们都不要与他们交战，只要专攻以色列王。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="箴言 13:20; 约拿 2:1–2; 诗篇 130:1–4"> 战车长看见约沙法，就说：“这一定是以色列王！”于是转过去攻击他。约沙法就呼喊起来。</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 76:10; 列王纪上 22:31"> 战车长见他不是以色列王，就转身不再追赶他。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志下 35:23; 弥迦书 6:13; 撒母耳记上 17:49"> 有一个人随意开弓，射中了以色列王铠甲的接缝处。王就对驾车的人说：“转车，把我带出战场，因为我受了重伤。”</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 22:28; 列王纪上 20:42"> 那一天战事越来越激烈。王被扶着站在战车上，面对亚兰人；到了傍晚就死了。血从伤处流到战车底部。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪下 14:12; 列王纪上 22:31; 士师记 21:24"> 日落的时候，有呼声传遍军中，说：“各归各城，各归各地吧！”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37"> 王死后，人把他带到撒玛利亚；他们就把王葬在撒玛利亚。</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪上 21:19; 马太福音 24:35; 耶利米书 44:21–23"> 他们在撒玛利亚池旁洗那战车；狗来舔他的血，妓女在那里洗身，这正应验了耶和华所说的话。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="阿摩司 3:15; 以西结 27:6; 诗篇 45:8"> 亚哈其余的事迹，他所做的一切，他所建造的象牙宫，以及他所建造的一切城，不都写在《以色列诸王记》上吗？</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳记下 7:12; 列王纪下 1:17; 列王纪下 1:2"> 亚哈与他列祖同睡；他的儿子亚哈谢接续他作王。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="历代志下 20:31; 列王纪上 22:2; 历代志下 17:1"> 以色列王亚哈第四年，亚撒的儿子约沙法登基作犹大王。</span>
<span className="v" id="v42" data-v="42" data-xref="列王纪下 1:17; 列王纪上 15:2; 列王纪上 15:10"> 约沙法登基的时候三十五岁，在耶路撒冷作王二十五年。他母亲名叫阿苏巴，是示利希的女儿。</span>
<span className="v" id="v43" data-v="43" data-xref="列王纪上 15:14; 列王纪下 12:3; 箴言 4:27"> 他行他父亲亚撒所行的一切道路，没有偏离，行耶和华眼中看为正的事。然而，丘坛还没有废去；百姓仍在丘坛上献祭、烧香。</span>
<span className="v" id="v44" data-v="44" data-xref="列王纪上 22:2; 历代志下 19:2; 列王纪下 8:18"> 约沙法与以色列王修好。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="列王纪上 14:29; 列王纪上 11:41; 历代志下 20:34"> 约沙法其余的事迹，他所显出的勇力，以及他怎样争战，不都写在《犹大诸王记》上吗？</span>
<span className="v" id="v46" data-v="46" data-xref="列王纪上 15:12; 列王纪上 14:24; 申命记 23:17"> 他把他父亲亚撒在世时剩下的男庙妓，从境内除去了。</span>
<span className="v" id="v47" data-v="47" data-xref="撒母耳记下 8:14; 列王纪下 3:9; 列王纪下 8:20"> 那时以东没有王，由总督治理。</span>
<span className="v" id="v48" data-v="48" data-xref="列王纪上 9:26; 列王纪上 10:22; 列王纪上 9:28"> 约沙法造了他施船，要往俄斐去运金子；只是没有去成，因为船在以旬迦别破毁了。</span>
<span className="v" id="v49" data-v="49"> 那时亚哈的儿子亚哈谢对约沙法说：“让我的仆人和你的仆人一同坐船去吧。”但约沙法不肯。</span>
<span className="v" id="v50" data-v="50" data-xref="历代志下 21:1; 列王纪上 22:40; 列王纪上 15:24"> 约沙法与他列祖同睡，葬在他祖大卫的城里，与他的列祖在一起。他的儿子约兰接续他作王。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="列王纪下 1:17; 列王纪上 22:40; 列王纪上 15:25"> 犹大王约沙法第十七年，亚哈的儿子亚哈谢在撒玛利亚登基作以色列王；他作以色列王共两年。</span>
<span className="v" id="v52" data-v="52" data-xref="列王纪上 15:26; 列王纪上 21:25; 启示录 3:20"> 他行耶和华眼中看为恶的事，行他父亲所行的道路，又行他母亲所行的道路，也行尼八的儿子耶罗波安使以色列陷在罪里的道路。</span>
<span className="v" id="v53" data-v="53" data-xref="列王纪上 16:30–32; 以赛亚书 65:3; 列王纪下 3:2"> 他事奉巴力，敬拜巴力，照他父亲所行的一切，惹耶和华以色列的上帝发怒。</span>
</div>
</div>

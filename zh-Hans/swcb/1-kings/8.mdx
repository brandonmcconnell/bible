<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 5:2–10; 历代志上 15:25; 撒母耳记下 6:12–17"> 那时，所罗门召集以色列的长老和各支派的首领，就是以色列人各父系家族的族长，到耶路撒冷所罗门王那里，要把耶和华的约柜从大卫城，就是锡安，运上来。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 23:34; 历代志下 7:8–10; 撒迦利亚书 14:16–19"> 以他念月，就是第七个月，在节期中，以色列众人都聚集到所罗门王那里。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 31:9; 约书亚记 3:6; 民数记 4:15"> 以色列所有的长老都来了，祭司就抬起约柜。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 3:4; 历代志下 1:3; 出埃及记 40:2–33"> 他们把耶和华的柜、会幕，以及会幕里所有的圣器具都运上来；祭司和利未人把这些都运上来。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 6:13; 历代志上 16:1; 列王纪上 8:62–63"> 所罗门王和聚集到他那里的以色列全会众，都在约柜前与他同在，献上绵羊和牛，多得无法计算，无法数点。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 6:19; 撒母耳记下 6:17; 列王纪上 6:27"> 祭司把耶和华的约柜抬进它的地方，就是殿的内殿，至圣所里，放在基路伯的翅膀底下。</span>
<span className="v" id="v7" data-v="7"> 因为基路伯张开翅膀在约柜所在的地方之上，基路伯从上面遮盖约柜和抬柜的杠。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 25:13–15; 出埃及记 37:4–5; 约书亚记 4:9"> 那些杠很长，从内殿前的圣所可以看见杠头，但在外面看不见。那些杠直到今日还在那里。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 25:21; 希伯来书 9:4; 出埃及记 40:20"> 约柜里除了两块石版以外，什么也没有；这是以色列人从埃及地出来以后，耶和华与他们立约的时候，摩西在何烈放在柜里的。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 40:34–35; 历代志下 7:1–2"> 祭司从圣所出来的时候，云充满了耶和华的殿，</span>
<span className="v" id="v11" data-v="11" data-xref="以西结 43:4–5; 以西结 44:4; 哥林多后书 3:18"> 以致祭司因那云不能站立供职；因为耶和华的荣耀充满了耶和华的殿。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="诗篇 97:2; 历代志下 6:1–11; 利未记 16:2"> 那时所罗门说：“耶和华曾说，祂要住在幽暗之中。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 7:13; 诗篇 132:13–14; 希伯来书 9:24"> 我确实为你建造了居所，作你永远居住的地方。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 6:18; 列王纪上 8:55–56; 历代志下 30:18–20"> 王转过脸来，为以色列全会众祝福；以色列全会众都站着。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 1:68; 历代志上 29:20; 历代志上 29:10"> 他说：“耶和华以色列的上帝是当称颂的！祂亲口对我父大卫说话，又亲手成就，说：</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 16:1; 列王纪上 8:29; 撒母耳记下 7:4–8"> 『自从我把我的民以色列从埃及领出来的日子以来，我没有从以色列任何支派中拣选一座城建造殿宇，使我的名在那里；但我拣选大卫来治理我的民以色列。』</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 7:2–3; 历代志上 22:7; 历代志上 28:2"> “我父大卫心里有意，要为耶和华以色列上帝的名建造殿宇。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 6:7–9; 哥林多后书 8:12"> 但耶和华对我父大卫说：『你心里有意要为我的名建造殿宇，你心里有这意念是好的。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 7:5; 历代志上 22:8–10; 历代志上 28:6"> 不过，你不可建造这殿；而是你所生的儿子，他要为我的名建造这殿。』</span>
<span className="v" id="v20" data-v="20" data-xref="历代志上 28:5–6; 腓立比书 1:6; 列王纪上 8:15"> 现在耶和华成就了祂所说的话；我已经接替我父大卫起来，照耶和华所应许的，坐在以色列的王位上，并且为耶和华以色列上帝的名建造了这殿。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 8:9; 申命记 31:26; 列王纪上 8:5–6"> 我在那里为约柜设立了地方，柜里有耶和华的约，就是祂把我们的祖先从埃及地领出来时与他们所立的约。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以斯拉记 9:5; 列王纪上 8:54; 出埃及记 9:33"> 所罗门当着以色列全会众，站在耶和华的坛前，向天伸开双手，</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 7:22; 申命记 7:9; 但以理 9:4"> 说：“耶和华以色列的上帝啊，在上天下地，没有上帝像你；你向那些全心行在你面前的仆人守约，施慈爱；</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 7:16; 列王纪上 8:15; 撒母耳记下 7:12"> 你向你的仆人我父大卫守住所应许他的。你亲口说了，也亲手成就了，正如今日一样。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 2:4; 列王纪上 9:4–6; 耶利米书 33:17–26"> 耶和华以色列的上帝啊，现在求你向你的仆人我父大卫守住所应许他的，说：『只要你的子孙谨慎自己的道路，像你在我面前所行的一样行在我面前，你在我面前就必不断有人坐在以色列的王位上。』</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 7:25–29; 以赛亚书 41:17; 撒母耳记上 1:17"> “以色列的上帝啊，现在求你使你对你的仆人我父大卫所说的话得以证实。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 2:6; 以赛亚书 66:1; 耶利米书 23:24"> 可是，上帝果真要住在地上吗？看哪，天和天上的天尚且容不下你，何况我所建造的这殿呢！</span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 88:1–2; 诗篇 5:1; 路加福音 18:1"> 然而，耶和华我的上帝啊，求你垂顾你仆人的祷告和恳求，垂听你仆人今日在你面前所发的呼求和祷告；</span>
<span className="v" id="v29" data-v="29" data-xref="历代志下 6:20; 列王纪上 8:16; 历代志下 7:15–16"> 愿你的眼目昼夜睁开，注视这殿，就是注视你曾说『我的名必在那里』的地方；求你垂听你仆人朝这地方所献的祷告。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 8:39; 列王纪上 8:34; 列王纪上 8:36"> 你的仆人和你的民以色列朝这地方祷告时，求你垂听他们的恳求。求你在天上，你的居所垂听；你垂听的时候，求你赦免。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及记 22:8–11; 历代志下 6:22–23; 利未记 5:1"> “若有人得罪邻舍，有誓言加在他身上，要使他起誓，他来到这殿中你的坛前起誓，</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 25:1; 以赛亚书 3:10–11; 罗马书 2:6–10"> 求你就在天上垂听、施行判断，审判你的仆人：定恶人为有罪，使他的行为归到自己头上；称义人为义，照他的义报应他。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="利未记 26:17; 申命记 28:25; 约拿 3:10"> “你的民以色列若因得罪你而在仇敌面前被击败，如果他们转回归向你，承认你的名，在这殿里向你祷告恳求，</span>
<span className="v" id="v34" data-v="34" data-xref="耶利米书 31:4–9; 但以理 9:12; 创世记 13:15"> 求你就在天上垂听，赦免你民以色列的罪，使他们回到你赐给他们祖先的地。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="利未记 26:19; 申命记 11:17; 列王纪上 8:33"> “若因他们得罪你，天闭塞不下雨；如果他们朝这地方祷告，承认你的名，并且在你使他们受苦的时候离开他们的罪，</span>
<span className="v" id="v36" data-v="36" data-xref="诗篇 27:11; 撒母耳记上 12:23; 耶利米书 6:16"> 求你就在天上垂听，赦免你的仆人和你的民以色列的罪；又指教他们当行的善道，并降雨在你的地上，就是你赐给你民作为产业的地上。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="申命记 28:21–22; 利未记 26:16; 历代志下 20:9"> “若这地有饥荒，若有瘟疫，若有枯萎病、霉烂、蝗虫或毛虫；若他们的仇敌在他们城邑之地围困他们；无论有什么灾祸，什么疾病，</span>
<span className="v" id="v38" data-v="38" data-xref="诗篇 73:21–22; 列王纪上 8:22; 腓立比书 4:6"> 你的民以色列中，或任何一人，或全体众人，各人若知道自己心中的灾祸，向这殿伸开双手，无论献上什么祷告和恳求，</span>
<span className="v" id="v39" data-v="39" data-xref="历代志上 28:9; 耶利米书 17:10; 使徒行传 1:24"> 求你就在天上，你的居所垂听，赦免，并且施行；你知道各人的心，求你照各人一切所行的报应他，因为惟有你知道所有世人的心；</span>
<span className="v" id="v40" data-v="40" data-xref="诗篇 130:4; 启示录 19:5; 申命记 6:2"> 使他们在你赐给我们祖先的地上生活的日子，都敬畏你。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="列王纪上 10:1–2; 使徒行传 8:27–40; 出埃及记 18:8–12"> “此外，论到不属你民以色列的外族人，若他为你的名从远方而来</span>
<span className="v" id="v42" data-v="42" data-xref="申命记 3:24; 列王纪下 17:36; 出埃及记 3:13–16"> （因为他们必听见你的大名、你大能的手和你伸出来的膀臂），当他来朝这殿祷告时，</span>
<span className="v" id="v43" data-v="43" data-xref="诗篇 102:15; 撒母耳记上 17:46; 诗篇 22:27"> 求你就在天上，你的居所垂听，照那外族人向你呼求的一切去行；使地上万民都认识你的名，敬畏你，像你的民以色列一样，并且知道我所建造的这殿是归在你名下的。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="历代志下 6:34; 诗篇 78:67–69; 列王纪上 8:16"> “你的民若照你差遣他们所走的任何道路，出去与他们的仇敌争战，并且向耶和华祷告，朝向你所拣选的城，以及我为你的名所建造的殿，</span>
<span className="v" id="v45" data-v="45" data-xref="创世记 18:25; 诗篇 9:4; 耶利米书 5:28"> 求你就在天上垂听他们的祷告和恳求，为他们主持公道。</span>
<span className="v" id="v46" data-v="46" data-xref="传道书 7:20; 箴言 20:9; 约翰一书 1:8–10"> 他们若得罪你——因为没有不犯罪的人——你向他们发怒，把他们交给仇敌，使仇敌把他们掳到仇敌之地，或远或近；</span>
<span className="v" id="v47" data-v="47" data-xref="诗篇 106:6; 尼希米记 1:6–11; 尼希米记 9:26–30"> 如果他们在被掳去的地方悔改，转回，在掳掠他们之人的地向你恳求，说：『我们犯了罪，行事悖逆，作了恶』；</span>
<span className="v" id="v48" data-v="48" data-xref="但以理 6:10; 耶利米书 29:12–14; 申命记 4:29"> 如果他们在掳掠他们的仇敌之地，尽心尽性归向你，朝向你赐给他们祖先的地、你所拣选的城和我为你的名所建造的殿，向你祷告，</span>
<span className="v" id="v49" data-v="49" data-xref="列王纪下 19:19; 列王纪上 8:45; 撒迦利亚书 1:15–16"> 求你就在天上，你的居所垂听他们的祷告和恳求，为他们主持公道；</span>
<span className="v" id="v50" data-v="50" data-xref="诗篇 106:46; 历代志下 30:9; 使徒行传 7:10"> 赦免你的民得罪你的罪，赦免他们干犯你的一切过犯；又使他们在掳掠他们的人面前蒙怜悯，叫那些人怜悯他们</span>
<span className="v" id="v51" data-v="51" data-xref="尼希米记 1:10; 耶利米书 11:4; 申命记 4:20"> （因为他们是你的民，是你的产业，是你从埃及、从铁炉中领出来的）；</span>
<span className="v" id="v52" data-v="52" data-xref="诗篇 145:18; 列王纪上 8:29; 诗篇 86:5"> 愿你的眼目睁开，垂顾你仆人的恳求和你民以色列的恳求，无论他们何时向你呼求，都垂听他们。</span>
<span className="v" id="v53" data-v="53" data-xref="出埃及记 19:5–6; 申命记 14:2; 申命记 32:9"> 主耶和华啊，因为你把他们从地上万民中分别出来，作你的产业，正如你把我们的祖先从埃及领出来的时候，借你的仆人摩西所说的。”</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="历代志下 7:1; 历代志下 6:12–13; 路加福音 22:45"> 所罗门向耶和华祷告并献上这一切恳求完了，就从耶和华的坛前起来；他原是双膝跪下，向天伸开双手。</span>
<span className="v" id="v55" data-v="55" data-xref="列王纪上 8:14; 撒母耳记下 6:18; 民数记 6:23–26"> 他站着，大声为以色列全会众祝福，说：</span>
<span className="v" id="v56" data-v="56" data-xref="约书亚记 23:14–15; 约书亚记 21:44–45; 路加福音 21:33"> “耶和华是当称颂的！祂照自己一切所应许的，赐安息给祂的民以色列。祂借祂仆人摩西所应许的一切美好应许，没有一句落空。</span>
<span className="v" id="v57" data-v="57" data-xref="约书亚记 1:5; 申命记 31:6; 申命记 31:8"> 愿耶和华我们的上帝与我们同在，像与我们的祖先同在一样。愿祂不撇下我们，也不丢弃我们，</span>
<span className="v" id="v58" data-v="58" data-xref="诗篇 119:36; 以西结 36:26–27; 耶利米书 31:33"> 使我们的心归向祂，行祂一切的道路，谨守祂吩咐我们祖先的诫命、律例和典章。</span>
<span className="v" id="v59" data-v="59" data-xref="诗篇 141:2; 约翰福音 17:9; 约翰福音 17:20–24"> 愿我在耶和华面前恳求的这些话，昼夜常在耶和华我们的上帝面前，使祂按每日所需，为祂的仆人和祂民以色列主持公道；</span>
<span className="v" id="v60" data-v="60" data-xref="申命记 4:35; 耶利米书 10:10–12; 列王纪上 18:39"> 使地上万民都知道，惟有耶和华是上帝，除祂以外没有别的。</span>
</div>
<div className="bp">
<span className="v" id="v61" data-v="61" data-xref="列王纪上 11:4; 列王纪下 20:3; 哥林多后书 7:1"> “所以你们的心当向耶和华我们的上帝完全，行祂的律例，谨守祂的诫命，像今日一样。”</span>
</div>
<div className="bp">
<span className="v" id="v62" data-v="62" data-xref="撒母耳记下 6:17–19; 以斯拉记 6:16–17; 历代志下 7:4–10"> 王和所有与他同在的以色列人，在耶和华面前献祭。</span>
<span className="v" id="v63" data-v="63" data-xref="以斯拉记 6:16–17; 历代志下 15:11; 尼希米记 12:27"> 所罗门向耶和华献平安祭的祭牲：牛二万二千头，羊十二万只。这样，王和以色列众人就为耶和华的殿行奉献礼。</span>
<span className="v" id="v64" data-v="64" data-xref="历代志下 4:1; 历代志下 7:7"> 当日，王把耶和华殿前院子的中间分别为圣；因为他在那里献燔祭、素祭和平安祭牲的脂肪，因为耶和华面前的铜坛太小，容纳不下燔祭、素祭和平安祭牲的脂肪。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 6:33; 历代志下 28:22; 约书亚记 19:18"> 这些事以后，耶斯列人拿伯有一个葡萄园，在耶斯列，靠近撒马利亚王亚哈的宫殿。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 8:14; 雅各书 1:14–15; 提摩太前书 6:9"> 亚哈对拿伯说：“把你的葡萄园给我，好让我作菜园，因为它靠近我的家；我会给你一个比它更好的葡萄园来交换。或者，如果你看为好，我就按它的价值给你银钱。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="民数记 36:7; 利未记 25:23; 以西结 46:18"> 拿伯对亚哈说：“耶和华绝不许可我把我祖先的产业给你！”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪上 20:43; 雅各书 1:14; 约拿 4:9"> 亚哈因耶斯列人拿伯对他说的话，就闷闷不乐，怒气冲冲地回到自己的宫里；因为拿伯说：“我不把我祖先的产业给你。”他躺在床上，转过脸去，不肯吃饭。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 16:31; 创世记 3:6; 列王纪上 19:2"> 他的妻子耶洗别来到他那里，对他说：“你的心为什么这样忧闷，连饭也不吃呢？”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以斯帖记 5:9–14; 雅各书 4:2–7; 提摩太前书 6:9–10"> 他对她说：“因为我对耶斯列人拿伯说：‘把你的葡萄园卖给我；或者，如果你愿意，我就给你另一个葡萄园来交换。’他却回答说：‘我不把我的葡萄园给你。’”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 8:14; 弥迦书 7:3; 撒母耳记下 13:4"> 他的妻子耶洗别对他说：“现在统治以色列国的不是你吗？起来，吃饭，让你的心欢喜。我会把耶斯列人拿伯的葡萄园给你。”</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米记 6:5; 列王纪下 10:11; 以斯拉记 4:7–8"> 于是她奉亚哈的名写信，用他的印封上，把信送给拿伯城里的长老和贵族，就是与拿伯同城居住的人。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 58:4; 马太福音 23:13; 路加福音 20:47"> 她在信中写道：“要宣告禁食，让拿伯在民中坐在高位。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 22:28; 使徒行传 6:11; 利未记 24:15–16"> 又要安排两个无赖坐在他面前，让他们作证告他说：‘你咒骂了上帝和王！’然后把他带出去，用石头打死。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 4:19; 利未记 19:15; 列王纪下 10:6–7"> 拿伯城里的人，就是住在他城里的长老和贵族，就照耶洗别写信送给他们所吩咐的去做。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 58:4; 列王纪上 21:8–10"> 他们宣告禁食，让拿伯在民中坐在高位。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 9:26; 申命记 22:24; 传道书 10:20"> 那两个无赖进来，坐在拿伯面前；这两个无赖当着众民的面作证告他，就是告拿伯说：“拿伯咒骂了上帝和王！”于是他们把他带到城外，用石头打死了。</span>
<span className="v" id="v14" data-v="14" data-xref="传道书 8:14; 撒母耳记下 11:14–24; 传道书 5:8"> 然后他们派人去见耶洗别，说：“拿伯已经被石头打死了。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="箴言 1:10–16; 箴言 4:17; 列王纪上 21:7"> 耶洗别听见拿伯已经被石头打死，就对亚哈说：“起来，去占有耶斯列人拿伯的葡萄园，就是他拒绝卖给你的；因为拿伯不活着了，已经死了。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="俄巴底亚 1:12–14; 罗马书 1:32; 撒母耳记下 11:25–27"> 亚哈听见拿伯死了，就起来，下到耶斯列人拿伯的葡萄园，要占有它。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="诗篇 9:12; 以赛亚书 26:21; 列王纪下 5:26"> 耶和华的话临到提斯比人以利亚，说：</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 13:32; 历代志下 22:9"> “起来，下去迎见住在撒马利亚的以色列王亚哈。看哪，他正在拿伯的葡萄园里，他下去那里要占有它。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 22:38; 撒母耳记下 12:9; 哈巴谷 2:9"> 你要对他说：‘耶和华这样说：“你杀了人，又占有产业吗？”’你还要对他说：‘耶和华这样说：“狗在什么地方舔了拿伯的血，也要在那里舔你的血，就是你的血。”’”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王纪下 17:17; 罗马书 7:14; 列王纪上 21:25"> 亚哈对以利亚说：“我的仇敌啊，你找到我了吗？”<br />他回答说：“我找到了你，因为你出卖了自己，行耶和华眼中看为恶的事。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 14:10; 撒母耳记上 25:34; 列王纪下 10:1–7"> 看哪，我必使灾祸临到你，必把你彻底扫除；凡属亚哈靠墙小便的，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：男丁">a</a></sup>以及以色列中被关的和在外自由的，我都必剪除。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 16:3; 列王纪上 14:16; 列王纪上 16:11"> 我必使你的家像尼八的儿子耶罗波安的家，又像亚希雅的儿子巴沙的家，因为你惹我发怒，又使以色列犯罪。”</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 9:10; 列王纪下 9:30–37; 列王纪上 21:25"> 耶和华也论到耶洗别说：“狗必在耶斯列的城垒旁吃耶洗别。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 16:4; 列王纪上 14:11; 耶利米书 15:3"> 凡属亚哈的人，死在城里的，狗必吃他；死在田野的，天空的飞鸟必吃他。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="箴言 22:14; 列王纪上 21:20; 列王纪上 16:30–33"> 从来没有人像亚哈这样，出卖自己，行耶和华眼中看为恶的事，是他的妻子耶洗别煽动他的。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 21:11; 创世记 15:16; 利未记 18:25–30"> 他随从偶像，行了极可憎的事，正如耶和华在以色列人面前赶出的亚摩利人所行的一切。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="列王纪下 6:30; 创世记 37:34; 撒母耳记下 3:31"> 亚哈听见这些话，就撕裂衣服，把麻布披在身上，禁食，睡卧也穿着麻布，并且垂头丧气地行走。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 耶和华的话临到提斯比人以利亚，说：</span>
<span className="v" id="v29" data-v="29" data-xref="彼得后书 3:9; 弥迦书 7:18; 诗篇 86:15"> “你看见亚哈在我面前怎样自卑了吗？因为他在我面前自卑，我就不在他的日子降下这灾祸；我要在他儿子的日子，使这灾祸临到他的家。”</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 20:5; 列王纪上 13:33–34; 撒母耳记上 31:2"> 那时，耶罗波安的儿子亚比雅病了。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 28:8; 列王纪上 11:29–38; 撒母耳记下 14:2"> 耶罗波安对他的妻子说：“请你起来，乔装改扮，使人认不出你是耶罗波安的妻子；往示罗去。看哪，先知亚希雅在那里，他曾说我必作这民的王。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 9:7–8; 列王纪上 13:7; 列王纪下 4:42"> 你要带着十个饼、几个薄饼和一瓶蜜去见他；他会告诉你这孩子将要怎样。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪上 11:29; 撒母耳记上 3:2; 撒母耳记上 4:15"> 耶罗波安的妻子就这样行，起身往示罗去，来到亚希雅的家。亚希雅不能看见，因为他年纪老迈，眼睛已经昏花。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 6:8–12; 箴言 21:30; 列王纪下 4:27"> 耶和华对亚希雅说：“看哪，耶罗波安的妻子要来，为她儿子的事求问你，因为他病了。你要对她如此如此说；她进来的时候，必装作别的妇人。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="但以理 5:17–28; 使徒行传 5:9–10; 路加福音 20:20–23"> 她进门的时候，亚希雅听见她的脚步声，就说：“耶罗波安的妻子，进来吧！你为什么装作别人呢？我奉差遣向你传沉重的信息。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 16:2; 撒母耳记下 12:7–8; 撒母耳记上 15:16"> 你去告诉耶罗波安：‘耶和华以色列的上帝如此说：“我从民中高举你，立你作我民以色列的君主，</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 15:5; 列王纪上 11:33–38; 历代志下 28:1"> 将国从大卫家夺过来赐给你；然而你不像我的仆人大卫，他遵守我的诫命，一心跟随我，专行我眼中看为正的事。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 23:35; 尼希米记 9:26; 诗篇 50:17"> 你却行恶，比你以前的众人更甚；你去为自己造别的神和铸像，惹我发怒，又把我丢在你的背后。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 32:36; 列王纪上 21:21; 列王纪下 14:26"> 因此，看哪，我必降灾给耶罗波安的家，从耶罗波安家中剪除凡向墙小便的，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：男性">a</a></sup>以及在以色列中被关的和自由的；我必彻底扫除耶罗波安的家，如人扫尽粪土，直到全然除尽。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 16:4; 耶利米书 15:3; 列王纪上 21:23–24"> 属耶罗波安的人，死在城中的，狗必吃他；死在田野的，空中的鸟必吃他；因为耶和华已经说了。”’</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 14:3; 列王纪上 14:16–17; 列王纪下 1:6"> 所以你起来，回你家去吧。你的脚一进城，孩子就必死。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 19:3; 历代志下 12:12; 约伯记 19:28"> 以色列众人都要为他哀哭，埋葬他；因为在耶罗波安家中，只有他得入坟墓，因为在他里面发现有向着耶和华以色列的上帝的一点善。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 15:27–29; 以西结 7:2–7; 以西结 12:22–28"> 而且耶和华要为自己在以色列兴起一位王，他必剪除耶罗波安的家。就是今日！什么？就是现在。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 23:15–16; 诗篇 52:5; 列王纪下 15:29"> 耶和华必击打以色列，使他们像芦苇在水中摇动；祂必将以色列从赐给他们列祖的这美地上连根拔起，把他们分散到大河<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="指幼发拉底河。">b</a></sup>那边，因为他们造了亚舍拉木柱，惹耶和华发怒。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 15:34; 列王纪上 16:2; 列王纪上 13:34"> 祂必舍弃以色列，因为耶罗波安所犯的罪，就是他犯罪并使以色列陷在其中的罪。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王纪上 15:33; 列王纪上 16:15; 列王纪上 16:23"> 耶罗波安的妻子起身离去，来到得撒。她一到家门槛，孩子就死了。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 14:13"> 以色列众人埋葬了他，并为他哀哭，正如耶和华借祂仆人先知亚希雅所说的话。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="历代志下 13:2–20; 历代志上 27:24; 列王纪上 16:20"> 耶罗波安其余的事，他怎样争战，怎样作王，看哪，都写在以色列诸王年代志书上。</span>
<span className="v" id="v20" data-v="20" data-xref="约伯记 14:12; 诗篇 3:5; 列王纪上 11:43"> 耶罗波安作王的日子共二十二年；然后他与列祖同睡，他儿子拿答接续他作王。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="历代志下 12:13; 列王纪上 11:36; 列王纪上 14:31"> 所罗门的儿子罗波安在犹大作王。罗波安登基的时候四十一岁，在耶路撒冷作王十七年；耶路撒冷是耶和华从以色列各支派中所选择、要将祂的名安置在那里的城。罗波安的母亲名叫拿玛，是亚扪女子。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 12:1; 哥林多前书 10:22; 诗篇 78:58"> 犹大行耶和华眼中看为恶的事；他们所犯的罪惹动祂的忌邪，超过他们列祖所行的一切。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 12:2; 以赛亚书 57:5; 列王纪下 17:9–10"> 因为他们也在各高冈上、各青翠树下，为自己筑丘坛，立圣柱和亚舍拉木柱。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 23:17; 哥林多前书 6:9; 列王纪上 15:12"> 境内也有男庙妓。他们照着耶和华在以色列子孙面前赶出的列国一切可憎的事而行。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王纪上 11:40; 历代志下 12:2–4; 历代志下 12:9"> 罗波安王第五年，埃及王示撒上来攻打耶路撒冷；</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 15:18; 历代志下 9:15–16; 列王纪上 7:51"> 他拿走了耶和华殿里的宝物和王宫里的宝物，全都拿走了；又拿走了所罗门制造的所有金盾牌。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 8:11; 撒母耳记上 22:17; 列王纪上 18:46"> 罗波安王制造铜盾牌来代替那些金盾牌，交在守王宫门的护卫长手中。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 12:11"> 王每逢进耶和华的殿，护卫就拿着这些盾牌，随后带回护卫室。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王纪上 22:45; 列王纪上 15:23; 列王纪上 14:19"> 罗波安其余的事，和他所行的一切，岂不都写在犹大诸王年代志书上吗？</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 12:24; 列王纪上 12:21; 列王纪上 15:6–7"> 罗波安与耶罗波安之间常有战争。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志下 12:16; 马太福音 1:7; 列王纪上 15:3"> 罗波安与列祖同睡，和他的列祖一同葬在大卫城。他的母亲名叫拿玛，是亚扪女子。他儿子亚比央接续他作王。</span>
</div>
</div>

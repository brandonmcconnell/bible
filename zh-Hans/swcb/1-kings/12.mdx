<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 9:6; 历代志下 10:1–19; 士师记 9:1"> 罗波安往示剑去，因为全以色列都来到示剑，要立他作王。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 11:40; 历代志下 10:2–3; 列王纪上 11:26–31"> 尼八的儿子耶罗波安听见这事时，他还在埃及；他曾躲避所罗门王，逃到埃及，并且住在那里。</span>
<span className="v" id="v3" data-v="3"> 他们派人去召他来。耶罗波安和以色列全会众就来，对罗波安说：</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 8:11–18; 列王纪上 4:7; 马太福音 11:29–30"> “你父亲使我们的轭沉重。现在求你使你父亲加在我们身上的苦役和重轭轻省些，我们就事奉你。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪上 12:12"> 他对他们说：“你们离开三天，然后再回到我这里来。”<br />于是百姓就离开了。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约伯记 12:12; 约伯记 32:7; 撒母耳记下 16:20"> 罗波安王向他父亲所罗门在世时侍立在他面前的老年人请教，说：“你们给我什么建议，好回答这百姓呢？”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="箴言 15:1; 历代志下 10:6–7; 列王纪上 12:13"> 他们回答说：“如果你今天作这百姓的仆人，服事他们，用好话回答他们，他们就永远作你的仆人。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="箴言 19:20; 传道书 10:2–3; 历代志下 10:8"> 但罗波安却弃绝老年人给他的建议，转去向那些与他一同长大、侍立在他面前的年轻人请教。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 22:6–8; 撒母耳记下 17:5–6; 历代志下 10:9"> 他对他们说：“这百姓对我说：‘你父亲加在我们身上的轭，求你使它轻省些。’你们给什么建议，使我们可以回答他们呢？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志下 10:10–11; 箴言 10:14; 以赛亚书 47:6"> 那些与他一同长大的年轻人对他说：“这百姓对你说：‘你父亲使我们的轭沉重，求你使它轻省些。’你要这样告诉他们：‘我的小指头比我父亲的腰还粗。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 27:11; 以西结 2:6; 耶利米书 28:13–14"> 我父亲使你们负重轭，我却要加重你们的轭；我父亲用鞭子责打你们，我却要用蝎子责打你们。’”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王纪上 12:5; 历代志下 10:12–14"> 第三天，耶罗波安和众百姓都来到罗波安那里，正如王所吩咐的，说：“第三天再到我这里来。”</span>
<span className="v" id="v13" data-v="13" data-xref="雅各书 3:17; 箴言 13:20; 传道书 10:12"> 王粗暴地回答百姓，弃绝老年人给他的建议，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 5:16–18; 列王纪上 12:10–11; 出埃及记 5:5–9"> 照着年轻人的建议对他们说：“我父亲使你们的轭沉重，我却要加重你们的轭；我父亲用鞭子责打你们，我却要用蝎子责打你们。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王纪上 12:24; 申命记 2:30; 士师记 14:4"> 王不肯听从百姓，因为这事出于耶和华，为要成就耶和华借示罗人亚希雅对尼八的儿子耶罗波安所说的话。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 20:1; 耶利米书 23:5–6; 历代志下 10:16"> 全以色列见王不听从他们，百姓就回答王说：“我们在大卫那里有什么份呢？我们在耶西的儿子那里没有产业。以色列啊，回你的帐棚去吧！大卫啊，现在顾你自己的家吧。”于是以色列人都回自己的帐棚去了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王纪上 11:36; 列王纪上 11:13; 历代志下 11:13–17"> 至于住在犹大各城的以色列人，罗波安仍作他们的王。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 4:6; 撒母耳记下 20:24; 列王纪上 5:14"> 罗波安王派掌管服苦役之人的亚多兰去；全以色列人就用石头打他，把他打死。罗波安王急忙登上自己的战车，逃往耶路撒冷。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 17:21; 历代志下 10:19; 约书亚记 4:9"> 这样，以色列背叛大卫家，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王纪上 11:13; 列王纪上 11:32; 何西阿 8:4"> 全以色列听见耶罗波安已经回来，就派人召他到会众那里，立他作全以色列的王。除了犹大支派以外，没有人跟随大卫家。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="历代志下 11:1–3; 历代志上 21:5; 历代志下 14:8"> 罗波安来到耶路撒冷，召集犹大全家和便雅悯支派，共十八万精选的战士，要与以色列家争战，使国归回所罗门的儿子罗波安。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 11:2; 历代志下 12:5–7; 列王纪上 13:1"> 但上帝的话临到上帝的人示玛雅，说：</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 12:17"> “你要告诉所罗门的儿子犹大王罗波安，和犹大、便雅悯全家，以及其余的百姓，说：</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 12:15; 历代志下 25:7–8; 何西阿 8:4"> ‘耶和华这样说：“你们不可上去与你们的弟兄以色列人争战。各人都要回自己的家去，因为这事出于我。”’”于是他们听从耶和华的话，照着耶和华的话回去，走自己的路了。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="士师记 8:17; 士师记 8:8; 士师记 9:45–49"> 耶罗波安在以法莲山地修筑示剑，就住在那里；他又从那里出去，修筑毗努伊勒。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 38:18–21; 以赛亚书 7:9; 马可福音 2:6–8"> 耶罗波安心里说：“现在这国必归回大卫家。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 12:5–7; 箴言 29:25; 申命记 12:14"> 如果这百姓上耶路撒冷，在耶和华的殿里献祭，这百姓的心就必转回他们的主，就是犹大王罗波安；他们会杀了我，归回犹大王罗波安。”</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪下 10:29; 出埃及记 32:8; 列王纪下 17:16"> 于是王商议之后，造了两只金牛犊；他对百姓说：“你们上耶路撒冷去太为难了。以色列啊，看哪，这些就是领你们从埃及地上来的神明！”</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 28:19; 士师记 18:27–31; 何西阿 4:15"> 他把一只安置在伯特利，另一只安置在但。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 17:21; 列王纪上 13:34; 列王纪下 10:31"> 这事就成了罪，因为百姓甚至远到但，在那一只牛犊前敬拜。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志下 13:9; 列王纪下 17:32; 列王纪上 13:32–33"> 耶罗波安建造邱坛的殿，又从百姓中立祭司；这些人并不是利未的子孙。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 8:5; 列王纪上 8:2; 阿摩司 7:10–13"> 耶罗波安在八月十五日设立节期，像犹大的节期一样，并且上到祭坛。他在伯特利这样行，向他所造的牛犊献祭，又在伯特利安置他所设立的邱坛祭司。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪上 13:1; 民数记 15:39; 马太福音 15:6"> 八月十五日，就是他凭自己心意所定的月份，他上到他在伯特利所造的祭坛；他为以色列人设立节期，并且上到祭坛烧香。</span>
</div>
</div>

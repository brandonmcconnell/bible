<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 12:32–33; 列王纪下 23:17; 帖撒罗尼迦前书 4:15"> 看哪，有一个神人凭耶和华的话从犹大来到伯特利；耶罗波安正站在坛旁要烧香。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结 36:1; 列王纪下 23:15–18; 列王纪下 22:1–2"> 他凭耶和华的话向坛呼喊，说：“坛哪！坛哪！耶和华这样说：‘看哪，必有一个儿子生在大卫家，名叫约西亚。他必在你上面献祭那些在你上面烧香的邱坛祭司，人的骨头也必烧在你上面。’”</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 1:22; 出埃及记 4:3–5; 士师记 6:17"> 当日，他给了一个预兆，说：“这就是耶和华所说的预兆：看哪，这坛必裂开，坛上的灰必倾倒出来。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="启示录 11:5; 历代志下 18:25–27; 路加福音 6:10"> 王听见神人向伯特利的坛所呼喊的话，耶罗波安就从坛旁伸出手，说：“抓住他！”他向神人伸出的手就枯干了，以致不能收回。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 13:3; 耶利米书 28:16–17; 申命记 18:22"> 坛也裂开了，灰从坛上倾倒出来，正如神人凭耶和华的话所给的预兆。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 9:28; 使徒行传 8:24; 出埃及记 10:17"> 王对神人说：“现在请你恳求耶和华你的上帝施恩，为我祷告，使我的手可以复原。”<br />神人恳求耶和华，王的手就复原了，像先前一样。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王纪下 5:15; 撒母耳记上 9:7–8; 士师记 13:15"> 王对神人说：“请你跟我回家，恢复一下体力，我也要给你赏赐。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="民数记 24:13; 民数记 22:18; 马可福音 6:23"> 神人对王说：“你就是把你家的一半给我，我也不跟你进去；我也不在这地方吃饭喝水；</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 13:17; 申命记 13:13–18; 罗马书 16:17"> 因为耶和华的话这样吩咐我说：‘你不可吃饭，不可喝水，也不可从你来的路回去。’”</span>
<span className="v" id="v10" data-v="10"> 于是他走另一条路，没有从他来伯特利的路回去。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪下 23:18; 列王纪上 13:20–21; 民数记 24:2"> 有一个老先知住在伯特利。他的一个儿子来，把那日神人在伯特利所行的一切事都告诉了他；神人对王所说的话，他们也告诉了父亲。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 他们的父亲问他们：“他走的是哪条路？”他的儿子们已经看见那从犹大来的神人所走的路。</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 10:4; 撒母耳记下 19:26; 士师记 5:10"> 他对儿子们说：“给我备驴。”他们就给他备了驴，他便骑上。</span>
<span className="v" id="v14" data-v="14" data-xref="腓立比书 4:12–13; 哥林多后书 11:27; 哥林多前书 4:11–12"> 他追赶神人，发现他坐在橡树底下，就问他：“你是从犹大来的神人吗？”<br />他说：“我是。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 老先知对他说：“请你跟我回家吃饭。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪上 13:8–9; 马太福音 16:23; 民数记 22:19"> 他说：“我不可跟你回去，也不可跟你进去；我不可在这地方跟你吃饭喝水。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 20:35; 帖撒罗尼迦前书 4:15; 列王纪上 13:1"> 因为有耶和华的话对我说：‘你不可在那里吃饭喝水，也不可转回，从你来的路回去。’”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰一书 4:1; 马太福音 7:15; 民数记 22:35"> 老先知对他说：“我也是先知，和你一样；有一位天使凭耶和华的话对我说：‘把他带回你的家，让他吃饭喝水。’”其实他是在欺骗他。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命记 13:1; 创世记 3:6; 使徒行传 4:19"> 于是神人跟他回去，在他家里吃饭喝水。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 7:22; 民数记 24:4; 民数记 24:16–24"> 他们坐席的时候，耶和华的话临到那带神人回来的先知；</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 13:17; 撒母耳记上 13:13–14; 撒母耳记上 4:18"> 他就向那从犹大来的神人呼喊，说：“耶和华这样说：‘因为你违背了耶和华的话，没有遵守耶和华你的上帝所吩咐你的命令，</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 14:18–20; 列王纪上 14:13; 耶利米书 22:18–19"> 反而回来，在祂对你说“不可吃饭，不可喝水”的地方吃了饭、喝了水，所以你的尸体不得入你列祖的坟墓。’”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 神人吃完饭、喝完水之后，老先知为他所带回来的那位先知备上驴。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 20:36; 列王纪下 2:24; 箴言 26:13"> 他走了以后，有一只狮子在路上遇见他，把他咬死。他的尸体倒在路上，驴站在尸体旁边，狮子也站在尸体旁边。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 13:11"> 看哪，有人经过，看见尸体倒在路上，狮子站在尸体旁边；他们就来到老先知所住的城里，把这事告诉人。</span>
<span className="v" id="v26" data-v="26" data-xref="以西结 9:6; 箴言 11:31; 诗篇 119:120"> 那从路上把神人带回来的先知听见这事，就说：“这是那违背耶和华话语的神人。因此耶和华把他交给狮子；狮子撕裂他，把他咬死，正如耶和华对他说的话。”</span>
<span className="v" id="v27" data-v="27"> 他对儿子们说：“给我备驴。”他们就备了驴。</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪上 17:6; 诗篇 148:7–8; 但以理 6:22–24"> 他去了，发现神人的尸体倒在路上，驴和狮子站在尸体旁边。狮子没有吃尸体，也没有撕裂驴。</span>
<span className="v" id="v29" data-v="29"> 老先知把神人的尸体抱起来，放在驴上，带了回来。他来到老先知的城里，为他哀哭，要埋葬他。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 22:18; 使徒行传 8:2; 列王纪上 14:13"> 他把尸体安放在自己的坟墓里；众人为他哀哭，说：“哀哉，我的兄弟！”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪下 23:17–18; 民数记 23:10; 路加福音 16:22–23"> 老先知埋葬他以后，对儿子们说：“我死了以后，你们要把我葬在神人所葬的坟墓里，把我的骸骨安放在他的骸骨旁边。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 16:24; 列王纪上 13:2; 列王纪上 12:31"> 因为他凭耶和华的话，向伯特利的坛和撒马利亚各城中所有邱坛的殿所呼喊的话，必定应验。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="历代志下 11:15; 历代志下 13:9; 民数记 17:12–13"> 这事以后，耶罗波安仍不离开他的恶道，反而又从众民中立人为邱坛的祭司；凡愿意的，他都任命为圣，使他们作邱坛的祭司。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 14:10; 列王纪上 15:29–30; 列王纪上 12:30"> 这事成了耶罗波安家的罪，甚至使他的家从地面上被剪除、被毁灭。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="传道书 1:12; 历代志下 9:30; 列王纪上 12:19–20"> 所罗门王作全以色列的王。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 18:21; 哥林多前书 12:28; 撒母耳记下 8:15–18"> 他所任用的官长如下：撒督的儿子亚撒利雅作祭司；</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 8:16; 以赛亚书 62:6; 历代志上 18:15"> 示沙的儿子以利何烈和亚希亚作书记；亚希律的儿子约沙法作史官；</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 2:35; 列王纪上 2:26–27"> 耶何耶大的儿子比拿雅统管军队；撒督和亚比亚他作祭司；</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 27:33; 撒母耳记下 15:37; 撒母耳记下 16:16"> 拿单的儿子亚撒利雅统管众官员；拿单的儿子撒布得作首席大臣，是王的朋友；</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 9:15; 撒母耳记下 20:24; 列王纪上 12:18"> 亚希煞管理王宫；押大的儿子亚多尼兰管理服劳役的人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志上 27:1–15"> 所罗门在全以色列有十二个官员，负责为王和王家供应食物；每人一年中供应一个月。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 24:33; 士师记 19:1; 士师记 17:1"> 他们的名字如下：便户珥，在以法莲山区；</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 21:16; 撒母耳记上 6:20; 撒母耳记上 6:12"> 便底甲，在玛迦斯、沙宾、伯示麦和以伦伯哈南；</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 15:35; 约书亚记 12:17; 约书亚记 17:2"> 便希悉，在亚鲁泊（梭哥和希弗全地都属他）；</span>
<span className="v" id="v11" data-v="11" data-xref="约书亚记 11:2; 约书亚记 12:23; 约书亚记 17:11"> 便亚比拿达，在多珥全高地（他娶了所罗门的女儿她法为妻）；</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 17:11; 士师记 5:19; 约书亚记 3:16"> 亚希律的儿子巴拿，在他纳和米吉多，以及靠近撒拉他拿、在耶斯列下方的伯善全地，从伯善直到亚伯米何拉，远至约缅那边；</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 3:4; 民数记 32:41; 列王纪上 22:3"> 便基别，在基列的拉末（在基列的玛拿西的儿子睚珥的城镇都属他；在巴珊的亚珥歌伯地区也属他，那里有六十座大城，都有城墙和铜闩）；</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 13:26; 撒母耳记下 17:24; 撒母耳记下 2:8"> 易多的儿子亚希拿达，在玛哈念；</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 19:32–39; 撒母耳记下 15:27; 撒母耳记上 18:18"> 亚希玛斯，在拿弗他利（他也娶了所罗门的女儿巴实抹为妻）；</span>
<span className="v" id="v16" data-v="16" data-xref="约书亚记 19:24–31; 撒母耳记下 15:32"> 户筛的儿子巴拿，在亚设和比亚录；</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 19:17–23"> 巴路亚的儿子约沙法，在以萨迦；</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 1:8; 约书亚记 18:20–28; 撒迦利亚书 12:13"> 以拉的儿子示每，在便雅悯；</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 2:26–17; 约书亚记 13:9–12; 民数记 21:21–35"> 乌利的儿子基别，在基列地，就是亚摩利人的王西宏和巴珊王噩的国土；他是在那地唯一的官员。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 22:17; 列王纪上 3:8; 创世记 32:12"> 犹大和以色列人口众多，多如海边的沙；他们吃喝欢乐。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 15:18; 约书亚记 1:4; 诗篇 68:29"> 所罗门统治从那大河直到非利士人的地，又直到埃及边界的所有国度。这些国度在所罗门一生的日子都进贡，并服侍他。</span>
<span className="v" id="v22" data-v="22"> 所罗门每天所需的食物是：细面三十歌珥<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一歌珥等于一贺梅珥，约为55.9美制加仑（液量），或211升，或6蒲式耳">a</a></sup>，粗面六十歌珥，</span>
<span className="v" id="v23" data-v="23" data-xref="尼希米记 5:17–18"> 肥牛十头，草场的牛二十头，羊一百只，另外还有鹿、羚羊、狍子和肥禽。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 22:9; 诗篇 72:11; 诗篇 72:3"> 因为他统管大河这边的一切，从提弗萨直到迦萨，治理大河这边的众王；他四境周围都有平安。</span>
<span className="v" id="v25" data-v="25" data-xref="弥迦书 4:4; 撒迦利亚书 3:10; 士师记 20:1"> 所罗门在世的日子，从但直到别是巴，犹大和以色列都安然居住，各人在自己的葡萄树下和无花果树下。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志下 1:14; 历代志下 9:25; 撒母耳记下 8:4"> 所罗门有四万个马棚，供拉战车的马使用，又有一万二千名骑兵。</span>
<span className="v" id="v27" data-v="27"> 那些官员各按自己的月份，为所罗门王和所有来到所罗门王席上的人供应食物；他们使一切都不缺乏。</span>
<span className="v" id="v28" data-v="28" data-xref="以斯帖记 8:10; 以斯帖记 8:14; 弥迦书 1:13"> 他们也各按职责，把大麦和干草送到官员所在的地方，供马和快马使用。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪上 3:12; 雅各书 3:17; 列王纪上 4:20"> 上帝赐给所罗门极多的智慧、悟性和宽广的心智，如同海边的沙。</span>
<span className="v" id="v30" data-v="30" data-xref="但以理 5:11–12; 创世记 25:6; 但以理 1:20"> 所罗门的智慧胜过所有东方人的智慧，也胜过埃及所有的智慧。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 2:6; 历代志上 15:19; 列王纪上 3:12"> 因为他比所有人更有智慧——比以斯拉人以探，以及玛曷的儿子希幔、甲各、达大更有智慧；他的名声传遍周围各国。</span>
<span className="v" id="v32" data-v="32" data-xref="雅歌 1:1–17; 马太福音 13:35; 箴言 1:1–31"> 他讲了三千句箴言，他的诗歌共有一千零五首。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪下 19:23; 诗篇 51:7; 诗篇 92:12"> 他讲论树木，从黎巴嫩的香柏树直到墙上长出的牛膝草；他也讲论走兽、飞鸟、爬行动物和鱼。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志下 9:23; 列王纪上 10:1; 历代志下 9:1"> 万民中都有人来听所罗门的智慧，是地上听见他智慧的众王所差来的。</span>
</div>

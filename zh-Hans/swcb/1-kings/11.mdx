<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 17:17; 箴言 6:24; 尼希米记 13:23–27"> 所罗门王爱许多外邦女子，包括法老的女儿，以及摩押人、亚扪人、以东人、西顿人和赫人中的女子。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 34:16; 申命记 7:3–4; 约书亚记 23:12–13"> 关于这些民族，耶和华曾对以色列人说：“你们不可进入他们中间，他们也不可进入你们中间，因为他们必定使你们的心转去随从他们的神明。”所罗门却爱恋这些女子。</span>
<span className="v" id="v3" data-v="3" data-xref="传道书 7:28; 撒母耳记下 5:13–16; 历代志下 11:21"> 他有七百个作公主的妻子，三百个妃嫔；他的妻子们使他的心偏离了。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 9:4; 列王纪上 8:61; 列王纪上 11:6"> 所罗门年老的时候，他的妻子们使他的心转去随从别的神明；他的心不像他父亲大卫的心那样，对耶和华他的上帝完全。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 2:13; 列王纪上 11:7; 列王纪下 23:13"> 因为所罗门随从西顿人的女神亚斯她录，又随从亚扪人可憎之神米勒公。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 14:24; 约书亚记 14:8; 约书亚记 14:14"> 所罗门行耶和华眼中看为恶的事，不像他父亲大卫那样专心跟从耶和华。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 21:29; 士师记 11:24; 使徒行传 7:43"> 那时，所罗门在耶路撒冷对面的山上，为摩押可憎之神基抹和亚扪人可憎之神摩洛建造邱坛。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 10:11–12; 列王纪上 11:1; 以西结 16:22–29"> 他为所有外邦妻子也是这样做；她们向自己的神明烧香献祭。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 9:2; 列王纪上 3:5; 申命记 7:4"> 耶和华向所罗门发怒，因为他的心偏离了耶和华以色列的上帝；这位上帝曾两次向他显现，</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 6:12–13; 历代志下 7:17–22; 列王纪上 9:4–7"> 并且为这事吩咐过他，不可随从别的神明；可是他没有遵守耶和华所吩咐的。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 12:15–16; 列王纪上 11:31; 列王纪下 17:21"> 因此，耶和华对所罗门说：“因为你做了这事，没有遵守我吩咐你的约和律例，我必将国从你手中撕去，赐给你的臣仆。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 20:19; 撒母耳记上 9:4–5; 列王纪下 22:19–20"> 然而，为你父亲大卫的缘故，我不在你活着的日子这样做；我要从你儿子手中把国撕去。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 12:20; 申命记 12:11; 列王纪上 11:32"> 只是我不撕去整个国；为了我仆人大卫的缘故，也为了我所选择的耶路撒冷的缘故，我要把一个支派赐给你的儿子。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志上 5:26; 诗篇 89:30–34; 以赛亚书 13:17"> 耶和华兴起一个敌人攻击所罗门，就是以东人哈达；他是以东王族的后裔。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 8:14; 历代志上 18:12–13; 申命记 20:13"> 从前大卫在以东的时候，军队的统帅约押上去埋葬被杀的人，并击杀以东所有的男丁</span>
<span className="v" id="v16" data-v="16"> （约押和以色列众人在那里住了六个月，直到他把以东所有的男丁都剪除），</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 2:13–14; 出埃及记 2:1–10; 列王纪下 11:2"> 那时哈达还只是个小孩，就和他父亲臣仆中的几个以东人一起逃往埃及。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 10:12; 申命记 33:2; 申命记 1:1"> 他们从米甸动身，来到巴兰；又从巴兰带了一些人同行，来到埃及王法老那里。法老给他房屋，指定供给他食物，又给他土地。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 39:4; 耶利米书 43:7–9; 创世记 39:21"> 哈达在法老眼前大蒙恩 favor，以致法老把自己妻子的妹妹，就是王后答比匿的妹妹，赐给他为妻。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 21:7; 撒母耳记上 1:24"> 答比匿的妹妹为他生了儿子基努拔。答比匿在法老宫中给基努拔断奶；基努拔就在法老宫中，在法老的众子中间。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 2:10; 出埃及记 4:19; 马太福音 2:20"> 哈达在埃及听见大卫与他列祖同睡，军队的统帅约押也死了，就对法老说：“请让我离开，好回到我本国去。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 18:22–23; 路加福音 22:35; 马可福音 14:31"> 法老对他说：“你在我这里缺少什么？看哪，你竟要回到本国去？”<br />他回答说：“没有什么；不过请让我离开。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪上 11:14; 撒母耳记下 8:3; 撒母耳记下 10:15–18"> 上帝又兴起一个敌人攻击所罗门，就是以利亚大的儿子利逊；他曾从他的主人、琐巴王哈大底谢那里逃出来。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 10:8; 撒母耳记下 10:18; 列王纪上 20:34"> 大卫击杀琐巴人之后，利逊招聚人跟随自己，成了一支队伍的首领。他们往大马士革去，住在那里，并在大马士革作王。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 15:2; 诗篇 106:40; 列王纪上 5:4"> 所罗门在世的日子，除了哈达所造成的祸患以外，利逊也一直作以色列的敌人。他憎恶以色列，并作了亚兰的王。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="历代志下 13:6; 列王纪上 12:2; 列王纪上 11:28"> 尼八的儿子耶罗波安也举手攻击王。他是以法莲人，来自洗利达，是所罗门的臣仆；他母亲名叫洗鲁阿，是个寡妇。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 9:24; 列王纪上 9:15; 箴言 30:32"> 他举手攻击王的原因是这样：所罗门建造米罗，修补他父亲大卫城的破口。</span>
<span className="v" id="v28" data-v="28" data-xref="箴言 22:29; 撒母耳记下 19:20; 士师记 1:22–23"> 耶罗波安这个人很有才能；所罗门见这个青年勤劳，就派他督管约瑟家一切服劳役的人。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪上 12:15; 列王纪上 14:2; 历代志下 9:29"> 那时，耶罗波安从耶路撒冷出去，示罗人先知亚希雅在路上遇见他。亚希雅穿着一件新衣；他们二人单独在田野。</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 15:27–28; 撒母耳记上 24:4–5"> 亚希雅拿起自己身上的新衣，撕成十二片。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪上 11:11–12"> 他对耶罗波安说：“你拿十片；因为耶和华以色列的上帝这样说：『看哪，我要将国从所罗门手中撕去，把十个支派赐给你</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 11:13; 列王纪上 12:20–21; 列王纪上 14:21"> （但因我仆人大卫的缘故，也因耶路撒冷的缘故，就是我从以色列众支派中所选择的城，他必有一个支派），</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪上 11:9; 列王纪上 11:5–7; 列王纪上 9:5–7"> 因为他们离弃了我，敬拜西顿人的女神亚斯她录、摩押的神基抹和亚扪人的神米勒公。他们没有行我的道，没有行我眼中看为正的事，也没有遵守我的律例和典章，像他父亲大卫所行的那样。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="列王纪上 11:12–13; 列王纪上 11:31; 约伯记 11:6"> 『然而，我不从他手中夺取整个国；为了我所选择的仆人大卫的缘故，就是那遵守我诫命和律例的大卫，我要使他一生作首领。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 12:20; 列王纪上 11:12; 出埃及记 20:5–6"> 但我要从他儿子手中夺取国，将十个支派赐给你。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪下 8:19; 列王纪上 11:13; 列王纪上 15:4"> 我要把一个支派赐给他的儿子，使我仆人大卫在我面前，在耶路撒冷，就是我为自己选择、要将我的名立在那里的城里，常有灯光。</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 14:26; 列王纪上 11:26; 撒母耳记下 3:21"> 我要选取你，你要照你心里一切所愿的掌权，作以色列的王。</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳记下 7:11; 约书亚记 1:5; 申命记 31:8"> 如果你听从我所吩咐你的一切，行我的道，行我眼中看为正的事，遵守我的律例和诫命，像我仆人大卫所行的那样，我就与你同在，为你建立稳固的家，像我为大卫所建立的一样，并将以色列赐给你。</span>
<span className="v" id="v39" data-v="39" data-xref="路加福音 1:32–33; 路加福音 2:11; 以赛亚书 11:1–10"> 我必为这事使大卫的后裔受苦，但不是永远。』”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="历代志下 12:2–9; 以赛亚书 14:24–27; 耶利米哀歌 3:37"> 因此，所罗门想要杀耶罗波安；耶罗波安却起身逃往埃及，投奔埃及王示撒，并留在埃及，直到所罗门死了。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="历代志下 9:29–31"> 所罗门其余的事，凡他所行的和他的智慧，岂不都写在《所罗门行传》上吗？</span>
<span className="v" id="v42" data-v="42" data-xref="列王纪上 2:11"> 所罗门在耶路撒冷作全以色列的王，共四十年。</span>
<span className="v" id="v43" data-v="43" data-xref="列王纪下 21:18; 列王纪上 2:10; 马太福音 1:7"> 所罗门与他列祖同睡，葬在他父亲大卫的城里；他儿子罗波安接续他作王。</span>
</div>
</div>

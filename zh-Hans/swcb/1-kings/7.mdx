<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 9:10; 历代志下 8:1; 传道书 2:4–5"> 所罗门建造自己的宫室用了十三年，完成了他整座宫室。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 10:17; 历代志下 9:16; 列王纪上 10:21"> 他又建造黎巴嫩林宫，长一百肘，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘是人手臂从中指尖到肘部的长度，约为18英寸或46厘米。">a</a></sup>宽五十肘，高三十肘，有四排香柏木柱子，柱上有香柏木梁。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 6:5"> 柱上的四十五根梁，每排十五根，上面都覆以香柏木。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结 40:22; 以西结 40:16; 列王纪上 6:4"> 有三排横梁，窗户三层相对。</span>
<span className="v" id="v5" data-v="5"> 所有的门和门框都与横梁成方形；窗户三层相对。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 7:12; 以西结 41:25–26"> 他又造柱廊，长五十肘，宽三十肘；柱廊前有廊子，廊前有柱子和门槛。</span>
<span className="v" id="v7" data-v="7" data-xref="箴言 20:8; 诗篇 122:5; 以赛亚书 9:7"> 他又造宝座廊，就是他施行审判的审判廊；从地面到顶棚都覆以香柏木。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 8:11; 列王纪上 3:1; 列王纪上 9:24"> 他居住的宫室，在廊后另一个院内，作法与这廊相同。他又为所娶的法老女儿建造一座宫室，像这廊一样。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 7:10–11; 列王纪上 5:17"> 这一切都是用贵重的石头造成的，就是按尺寸凿成、里外用锯锯齐的石头；从根基直到檐石，外面直到大院，都是这样。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 21:19–20; 哥林多前书 3:10–11; 以赛亚书 54:11"> 根基是贵重的大石头，有十肘的石头，也有八肘的石头。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 2:20–22; 彼得前书 2:5"> 上面也有贵重的石头，就是按尺寸凿成的石头，还有香柏木。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 6:36; 列王纪上 7:6; 约翰福音 10:23"> 大院四周有三层凿成的石头和一层香柏木梁，正如耶和华殿的内院和殿廊一样。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志下 4:11; 历代志下 2:13–14; 列王纪上 7:40"> 所罗门王派人从推罗把希兰请来。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 2:14; 历代志下 4:16; 出埃及记 31:2–6"> 他是拿弗他利支派一个寡妇的儿子，父亲是推罗人，是青铜匠；他满有智慧、悟性和技能，能做各样青铜的工。他来到所罗门王那里，完成了王交给他的全部工作。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 52:21; 历代志下 3:15–17; 列王纪上 7:21"> 他铸造了两根青铜柱，每根高十八肘；一条十二肘的线可以围住任一根柱子。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 38:19; 历代志下 4:12–13; 出埃及记 38:17"> 他又铸造两个青铜柱顶，安在柱子的顶端；一个柱顶高五肘，另一个柱顶也高五肘。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 28:14; 出埃及记 28:24–25; 出埃及记 28:22"> 柱子顶端的柱顶有棋格状的网子和链状的花环；一个柱顶有七个，另一个柱顶也有七个。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 28:14; 出埃及记 39:15–18; 出埃及记 28:22"> 他这样造了柱子；在一个网子周围有两排石榴，用来遮盖柱子顶端的柱顶；另一个柱顶也照样做。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 7:22; 列王纪上 6:32–35; 列王纪上 6:18"> 廊内柱子顶端的柱顶作成百合花样，高四肘。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 3:16; 历代志下 4:13; 耶利米书 52:22–23"> 两根柱子上，在靠近网子的鼓腹旁，上面也有柱顶；另一个柱顶周围成排有二百个石榴。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志下 3:17; 列王纪上 6:3; 列王纪上 7:12"> 他把柱子立在圣殿的廊前；立右边的柱子，给它起名叫雅斤；立左边的柱子，给它起名叫波阿斯。</span>
<span className="v" id="v22" data-v="22"> 柱子顶端有百合花样。这样，柱子的工程就完成了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="历代志下 4:2; 列王纪下 25:13; 耶利米书 52:17"> 他又铸造一个海，从这边缘到那边缘有十肘，形状是圆的，高五肘；一条三十肘的线可以围住它。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 6:18; 历代志下 4:3; 出埃及记 37:17–22"> 在海的边缘下面，四周有花蕾环绕，每肘十个，围绕着海；花蕾有两排，是铸海的时候一同铸成的。</span>
<span className="v" id="v25" data-v="25" data-xref="耶利米书 52:20; 历代志下 4:4–5; 马太福音 28:19"> 海立在十二只铜牛上：三只向北，三只向西，三只向南，三只向东；海安在牛的上面，牛的后部都朝内。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志下 4:5; 列王纪上 7:38; 列王纪上 6:18"> 海的厚度有一掌宽；边缘的作法像杯边，又像百合花。它可容二千罢特。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="历代志下 4:14; 列王纪下 25:13; 耶利米书 52:17"> 他又造十个青铜盆座。每个盆座长四肘，宽四肘，高三肘。</span>
<span className="v" id="v28" data-v="28"> 盆座的作法是这样：它们有镶板，镶板在边框之间；</span>
<span className="v" id="v29" data-v="29" data-xref="何西阿 5:14; 以西结 10:14; 出埃及记 37:7"> 在边框之间的镶板上有狮子、牛和基路伯；边框上方有座架；狮子和牛下面有垂挂的花环。</span>
<span className="v" id="v30" data-v="30" data-xref="以西结 10:10–13; 以西结 3:13; 以西结 1:15–21"> 每个盆座有四个青铜轮和青铜轴；四角有支架。支架是在盆下面铸成的，每边都有花环。</span>
<span className="v" id="v31" data-v="31"> 其口在顶冠内，向上有一肘；口是圆的，像座架的作法，直径一肘半；口上也有雕刻，镶板是方的，不是圆的。</span>
<span className="v" id="v32" data-v="32"> 四个轮子在镶板下面；轮轴安在盆座上。每个轮子高一肘半。</span>
<span className="v" id="v33" data-v="33" data-xref="以西结 1:18; 以西结 1:16"> 轮子的作法像战车的轮子；轴、轮辋、辐条和轮毂全都是铸成的。</span>
<span className="v" id="v34" data-v="34"> 每个盆座四角各有一个支架；支架与盆座连成一体。</span>
<span className="v" id="v35" data-v="35"> 盆座上端有一个圆环，高半肘；盆座上端的支架和镶板与盆座连成一体。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 7:29; 列王纪上 6:29; 以西结 41:18–20"> 他在支架的板上和镶板上雕刻基路伯、狮子和棕树，各按其空处雕刻，周围有花环。</span>
<span className="v" id="v37" data-v="37"> 他照这样造了十个盆座：全都是同一种铸法、同一种尺寸、同一种样式。</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及记 40:11–12; 撒迦利亚书 13:1; 约翰一书 1:7"> 他又造十个青铜盆。每个盆可容四十罢特。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="1罢特是1歌珥的十分之一，约为5.6美制加仑或21升，因此40罢特约为224加仑或840升。">b</a></sup>每个盆量为四肘；十个盆座上每座有一个盆。</span>
<span className="v" id="v39" data-v="39" data-xref="历代志下 4:10; 历代志下 4:6"> 他把盆座安放在殿的右边五个、左边五个；又把海安放在殿的右边，朝东，偏南。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="历代志下 4:11–16; 出埃及记 24:6; 出埃及记 39:32–43"> 希兰又造了锅、铲子和盆。这样，希兰完成了他为所罗门王在耶和华殿中所做的一切工作：</span>
<span className="v" id="v41" data-v="41" data-xref="列王纪上 7:15–22; 历代志下 4:12"> 两根柱子；柱子顶端柱顶的两个碗状部分；两个网子，用来遮盖柱子顶端柱顶的两个碗状部分；</span>
<span className="v" id="v42" data-v="42" data-xref="列王纪上 7:20"> 两个网子上的四百个石榴；每个网子有两排石榴，用来遮盖柱子上柱顶的两个碗状部分；</span>
<span className="v" id="v43" data-v="43"> 十个盆座；盆座上的十个盆；</span>
<span className="v" id="v44" data-v="44" data-xref="列王纪上 7:23; 列王纪上 7:25"> 一个海；海下面的十二只牛；</span>
<span className="v" id="v45" data-v="45" data-xref="出埃及记 27:3; 出埃及记 38:3; 历代志下 4:16"> 锅、铲子和盆。希兰为所罗门王给耶和华殿所造的这一切器具，都是磨亮的青铜。</span>
<span className="v" id="v46" data-v="46" data-xref="约书亚记 3:16; 历代志下 4:17; 创世记 33:17"> 王在约旦平原，在疏割和撒拉但之间的胶泥地铸造这些器具。</span>
<span className="v" id="v47" data-v="47" data-xref="历代志上 22:14; 历代志上 22:3; 历代志下 4:18"> 所罗门没有称量这一切器具，因为器具太多，青铜的重量无法查明。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="出埃及记 37:10–16; 历代志下 4:8; 出埃及记 39:36"> 所罗门又造耶和华殿里的一切器具：金坛和放陈设饼的桌子，是金的；</span>
<span className="v" id="v49" data-v="49" data-xref="历代志下 4:7; 历代志下 4:20; 撒迦利亚书 4:11–14"> 内殿前的灯台，右边五个、左边五个，是纯金的；花、灯盏和灯剪，是金的；</span>
<span className="v" id="v50" data-v="50" data-xref="出埃及记 25:29; 历代志下 4:21–22; 出埃及记 27:3"> 杯、剪灯花的剪刀、盆、匙和火鼎，是纯金的；内殿，就是至圣所的门，以及圣殿的门，其铰链都是金的。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="历代志下 5:1; 撒母耳记下 8:7–11; 历代志上 28:11–18"> 这样，所罗门王为耶和华殿所做的一切工程都完成了。所罗门把他父亲大卫分别为圣的东西，就是银子、金子和器具，都带进来，放在耶和华殿的府库里。</span>
</div>
</div>

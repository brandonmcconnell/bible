<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 12:42; 路加福音 11:31; 历代志下 9:1–12"> 示巴女王听见所罗门因耶和华的名而得的声誉，就来用难题考问他。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 25:23; 诗篇 4:4; 约伯记 4:2"> 她带着极大的随从来到耶路撒冷，有骆驼驮着香料、极多的金子和宝石；她来到所罗门那里，就把心里所有的事都对他说了。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 1:5–6; 马太福音 13:11; 列王纪上 10:1"> 所罗门回答了她所有的问题；没有什么事对王是隐藏的，是他不能告诉她的。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 12:42; 列王纪上 3:28; 历代志下 9:3–4"> 示巴女王看见所罗门一切的智慧、他所建造的宫殿、</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 26:16; 列王纪上 4:22–23; 列王纪下 16:18"> 他席上的食物、他臣仆的座次、他官员的侍立、他们的衣服、他的酒政，以及他上耶和华殿的台阶，她就惊得魂不守舍。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 9:5–6"> 她对王说：“我在本国听见关于你的事迹和你的智慧，果然是真实的报告。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 2:9; 约翰福音 20:25–29; 约翰一书 3:2"> 可是，我没有相信那些话，直到我来了，亲眼看见。看哪，人告诉我的还不到一半！你的智慧和兴盛超过了我所听见的名声。</span>
<span className="v" id="v8" data-v="8" data-xref="箴言 8:34; 箴言 10:21; 路加福音 11:31"> 你的人有福了！你这些仆人有福了！他们常常站在你面前，听你的智慧。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 72:2; 列王纪上 5:7; 撒母耳记下 8:15"> 耶和华你的上帝是当称颂的！祂喜悦你，使你坐在以色列的宝座上。因为耶和华永远爱以色列，所以祂立你作王，为要施行公平和公义。”</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 10:2; 马太福音 2:11; 列王纪上 9:14"> 她送给王一百二十他连得金子、极大量的香料和宝石。后来再没有这样丰盛的香料，像示巴女王送给所罗门王的这些。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪上 9:27–28; 历代志下 8:18; 诗篇 45:9"> 希兰的船队从俄斐运来金子，也从俄斐运来大量檀香木<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="可能是一种印度檀香木，纹理美观，气味芬芳，适合木工使用。">a</a></sup>和宝石。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 25:1–31; 诗篇 150:3–5; 启示录 14:2–3"> 王用檀香木为耶和华的殿和王宫制作柱子，又为歌唱的人制作琴瑟；这样的檀香木直到今日再没有运来，也没有人见过。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="诗篇 37:4; 马太福音 15:28; 诗篇 20:4"> 所罗门王除了按自己的王室厚礼送给示巴女王的以外，她所想要、所求的一切，他都给了她。于是她和她的仆人转回自己的本国去了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志下 9:13–28; 列王纪上 9:28"> 所罗门每年所得金子的重量是六百六十六他连得<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一他连得约为30公斤或66磅，或965金衡盎司；所以666他连得约为20公吨。">b</a></sup>金子，</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 72:10; 历代志上 9:24; 以赛亚书 21:13"> 此外还有商旅所带来的，以及商人的贸易、杂族诸王和本地省长所进贡的。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 14:26–28; 历代志下 12:9–10; 历代志下 9:15–16"> 所罗门王用锤打的金子制造了二百面大盾牌；每面大盾牌用金子六百舍客勒<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一舍客勒约为10克或0.32金衡盎司；所以600舍客勒约为6公斤或13.2磅，或192金衡盎司。">c</a></sup>。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 7:2; 列王纪上 14:26"> 他又用锤打的金子制造了三百面盾牌；每面盾牌用金子三弥那<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一弥那约为600克或1.3美制磅。">d</a></sup>；王把它们放在黎巴嫩林宫里。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 45:8; 列王纪上 10:22; 启示录 20:11"> 王又制造了一个象牙大宝座，用最精美的金子包裹。</span>
<span className="v" id="v19" data-v="19"> 宝座有六级台阶，宝座后面的顶部是圆形的；座位两旁有扶手，扶手旁边站着两只狮子。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 24:9; 创世记 49:9; 民数记 23:24"> 六级台阶两边各站着狮子，共十二只；在任何国度都没有制造过这样的。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 10:17; 列王纪上 7:2; 历代志下 9:20–22"> 所罗门王所有的饮器都是金的，黎巴嫩林宫里所有的器皿都是纯金的；没有一件是银的，因为在所罗门的日子，银子算不了什么。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 22:48; 创世记 10:4; 历代志下 20:36–37"> 因为王在海上有一支他施船队，与希兰的船队在一起。他施船队每三年回来一次，带来金子、银子、象牙、猿猴和孔雀。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪上 3:12–13; 歌罗西书 2:2–3; 列王纪上 4:29–34"> 这样，所罗门王在财富和智慧上超过了地上所有的王。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 3:12; 雅各书 1:5; 列王纪上 3:28"> 全地的人都求见所罗门，要听上帝放在他心里的智慧。</span>
<span className="v" id="v25" data-v="25" data-xref="约伯记 42:11; 诗篇 72:10; 诗篇 72:15"> 年复一年，各人都带来自己的贡物：银器、金器、衣服、铠甲、香料、马和骡子。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="历代志下 9:25; 列王纪上 4:26; 申命记 17:16"> 所罗门聚集战车和骑兵。他有一千四百辆战车，十二千名骑兵；他把他们安置在战车城，也安置在耶路撒冷王那里。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志下 1:15–17; 申命记 17:17; 历代志下 9:27"> 王使银子在耶路撒冷像石头一样普遍，使香柏木像低地的桑树一样多。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 17:16; 历代志下 9:28; 以赛亚书 31:1–3"> 所罗门所有的马是从埃及运来的；王的商人按定价一群一群地接收。</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 1:4; 列王纪下 7:6–7; 玛拉基书 1:1"> 从埃及进口一辆战车要六百舍客勒<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一舍客勒约为10克或0.35盎司。">e</a></sup>银子，一匹马要一百五十舍客勒；他们也照样把车马输出给赫人的诸王和叙利亚的诸王。</span>
</div>
</div>

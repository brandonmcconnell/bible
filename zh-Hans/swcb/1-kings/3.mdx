<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 9:24; 列王纪上 11:1; 列王纪上 6:1–15"> 所罗门与埃及王法老结亲，娶了法老的女儿，带她进大卫城，直到他建完自己的宫、耶和华的殿，以及耶路撒冷四围的城墙。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 22:43; 历代志下 33:17; 申命记 12:2–5"> 只是百姓仍在邱坛献祭，因为那时还没有为耶和华的名建殿。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 8:3; 诗篇 31:23; 申命记 30:16"> 所罗门爱耶和华，遵行他父亲大卫的律例；只是他仍在邱坛献祭烧香。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 16:39; 历代志下 1:3; 历代志下 7:5"> 王往基遍去，要在那里献祭，因为那是最大的邱坛；所罗门在那坛上献了一千只燔祭。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 9:2; 雅各书 1:5–6; 民数记 12:6"> 在基遍，夜间梦中，耶和华向所罗门显现；上帝说：“你愿我赐给你什么，你可以求。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王纪上 9:4; 列王纪上 1:48; 哥林多后书 9:11"> 所罗门说：“你向你仆人、我父亲大卫施行了极大的慈爱，因为他在你面前以诚实、公义和正直的心与你同行。你为他存留了这极大的慈爱，赐给他一个儿子坐在他的王位上，正如今日一样。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 29:1; 民数记 27:17; 耶利米书 1:6"> 现在，耶和华我的上帝啊，你使你的仆人接续我父亲大卫作王；但我只是个小孩子，不知道怎样出入。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 15:5; 创世记 13:16; 历代志上 21:2"> 你的仆人在你所拣选的子民中；这民众多，因人数太多，无法数算。</span>
<span className="v" id="v9" data-v="9" data-xref="雅各书 1:5; 箴言 16:16; 希伯来书 5:14"> 所以求你赐给你的仆人一颗明辨的心，可以审判你的子民，能分辨善恶；因为谁能审判你这众多的子民呢？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="箴言 15:8"> 所罗门求这事，使主喜悦。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 8:26; 雅各书 4:2–3; 箴言 16:31"> 上帝对他说：“因为你求这事，没有为自己求长寿，也没有为自己求财富，也没有求你仇敌的性命，却为自己求明辨，好能辨明公正，</span>
<span className="v" id="v12" data-v="12" data-xref="约翰一书 5:14–15; 传道书 1:16; 马太福音 12:42"> 看哪，我已经照你的话而行。看哪，我赐给你一颗智慧而明辨的心，以致在你以前没有人像你，在你以后也没有人兴起像你。</span>
<span className="v" id="v13" data-v="13" data-xref="以弗所书 3:20; 马太福音 6:33; 箴言 3:16"> 你没有求的，我也赐给你，就是财富和尊荣，使你在世的日子，列王中没有一个能像你。</span>
<span className="v" id="v14" data-v="14" data-xref="箴言 3:2; 诗篇 91:16; 列王纪上 15:5"> 你若行我的道路，谨守我的律例和诫命，像你父亲大卫所行的一样，我就使你的日子长久。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="创世记 41:7; 列王纪上 8:65; 以斯帖记 1:3"> 所罗门醒来；看哪，原来是一个梦。于是他来到耶路撒冷，站在耶和华约柜前，献上燔祭，又献平安祭，并为他所有的臣仆摆设筵席。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及记 18:16; 士师记 11:1; 民数记 27:2"> 那时，有两个作妓女的妇人来到王那里，站在他面前。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 13:7; 创世记 43:20"> 一个妇人说：“我主啊，我和这妇人同住一屋；我在屋里与她同住的时候，生了一个孩子。</span>
<span className="v" id="v18" data-v="18"> 我生产后的第三天，这妇人也生了孩子。我们在一起，屋里没有外人与我们同在，只有我们两个人在屋里。</span>
<span className="v" id="v19" data-v="19"> 夜里，这妇人的孩子死了，因为她压在孩子身上。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 3:20; 马太福音 13:25; 诗篇 139:11"> 她半夜起来，趁你婢女睡着的时候，从我身旁把我的儿子抱走，放在她怀里，又把她死了的孩子放在我怀里。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 21:7; 撒母耳记上 1:23; 耶利米哀歌 4:3–4"> 早晨我起来要给我的孩子吃奶，看哪，他已经死了；可是早晨我仔细看他，看哪，他并不是我所生的儿子。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="列王纪上 3:23–24"> 另一个妇人说：“不是！活着的是我的儿子，死了的是你的儿子。”<br />第一个妇人说：“不是！死了的是你的儿子，活着的是我的儿子。”她们就在王面前这样争辩。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 王说：“一个说：‘这活着的是我的儿子，死了的是你的儿子；’另一个说：‘不是！死了的是你的儿子，活着的是我的儿子。’”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 王说：“给我拿一把刀来。”他们就把刀拿到王面前。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="箴言 25:8"> 王说：“把这活孩子劈成两半，一半给这个，一半给那个。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 49:15; 耶利米书 31:20; 约翰一书 3:17"> 那活孩子的母亲因心里恋慕自己的儿子，就对王说：“我主啊，把活孩子给她吧，千万不可杀他！”<br />另一个妇人却说：“他既不归我，也不归你；把他劈开吧。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 王回答说：“把活孩子给第一个妇人，绝不可杀他。她是孩子的母亲。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="但以理 2:47; 列王纪上 3:9–12; 歌罗西书 2:3"> 全以色列听见王所作的判决，就敬畏王，因为他们看出上帝的智慧在他里面，使他能施行公正。</span>
</div>
</div>

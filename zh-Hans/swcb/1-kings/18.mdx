<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 4:25; 雅各书 5:17; 申命记 28:12"> 过了许多日子，到第三年，耶和华的话临到以利亚，说：“你去，使亚哈看见你；我要降雨在地上。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="列王纪下 6:25; 箴言 28:1; 利未记 26:26"> 以利亚就去，要使亚哈看见他。撒玛利亚的饥荒非常严重。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 7:2; 列王纪上 16:9; 马太福音 10:28"> 亚哈召了掌管王宫的俄巴底来。（俄巴底非常敬畏耶和华；</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 18:13; 马太福音 10:40–42; 启示录 17:4–6"> 因为耶洗别剪除耶和华的先知时，俄巴底带了一百个先知，把他们每五十人藏在一个洞里，并用饼和水供养他们。）</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 14:5–6; 约珥 1:18; 约珥 2:22"> 亚哈对俄巴底说：“你走遍这地，到一切水泉和一切溪旁去。也许我们能找到草，使马和骡存活，免得所有牲畜都灭绝。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="耶利米书 14:3"> 于是他们分地巡行；亚哈独自走一路，俄巴底独自走另一路。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 1:6–8; 创世记 44:20; 以赛亚书 60:14"> 俄巴底在路上时，看哪，以利亚来迎着他。他认出以利亚，就俯伏在地，说：“是你吗？我主以利亚。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="罗马书 13:7; 列王纪上 18:3; 彼得前书 2:17–18"> 他回答说：“是我。你去告诉你的主：‘看哪，以利亚在这里！’”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 5:21; 列王纪上 18:12; 列王纪上 17:18"> 他说：“我犯了什么罪，你竟要把你仆人交在亚哈手里，使他杀我呢？</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 17:1; 列王纪上 1:29; 列王纪上 18:15"> 我指着永生的耶和华你的上帝起誓，没有一邦一国是我主没有差人去找你的。若有人说：‘他不在这里’，我主就使那国那邦起誓，说他们找不到你。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪上 18:8; 列王纪上 18:14"> 现在你说：‘去告诉你的主：“看哪，以利亚在这里。”’</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 2:16; 使徒行传 8:39; 以西结 8:3"> 恐怕我一离开你，耶和华的灵就把你带到我不知道的地方；我去告诉亚哈，他若找不到你，就会杀我。可是我，你的仆人，从年幼时就敬畏耶和华。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 18:4; 马太福音 25:35; 诗篇 18:21–24"> 耶洗别杀害耶和华的先知时，我怎样把耶和华先知中的一百人，每五十人藏在一个洞里，并用饼和水供养他们，难道没有人告诉我主吗？</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 10:28"> 现在你说：‘去告诉你的主：“看哪，以利亚在这里。”’他会杀我的。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王纪上 17:1; 列王纪上 18:10; 路加福音 2:13–14"> 以利亚说：“我指着我所侍立在祂面前的永生万军之耶和华起誓，我今日必使亚哈看见我。”</span>
<span className="v" id="v16" data-v="16"> 于是俄巴底去迎见亚哈，告诉他；亚哈就去迎见以利亚。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约书亚记 7:25; 列王纪上 21:20; 使徒行传 16:20"> 亚哈看见以利亚时，就对他说：“使以色列遭祸的，是你吗？”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="历代志下 15:2; 列王纪上 9:9; 耶利米书 2:19"> 他回答说：“使以色列遭祸的不是我，而是你和你父家，因为你们离弃耶和华的诫命，随从众巴力。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 19:26; 列王纪上 16:33; 彼得后书 2:1"> 现在你要差人召集以色列众人到迦密山，到我这里来，并召巴力的四百五十个先知和亚舍拉的四百个先知，就是在耶洗别席上吃饭的那些人。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王纪上 22:9"> 于是亚哈差人到以色列所有儿女那里，召集众先知到迦密山。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 6:24; 约书亚记 24:15; 哥林多前书 10:21–22"> 以利亚走近众民，说：“你们在两边之间摇摆不定要到几时呢？如果耶和华是上帝，就跟随祂；如果巴力是，就跟随他。”<br />众民一句话也不回答。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="列王纪上 19:10; 列王纪上 19:14; 提摩太后书 4:3–4"> 以利亚对众民说：“作耶和华先知的只剩下我，只有我一个；巴力的先知却有四百五十人。</span>
<span className="v" id="v23" data-v="23"> 现在让他们给我们两头公牛；让他们为自己选择一头公牛，切成块子，放在柴上，不要点火；我也要预备另一头公牛，放在柴上，也不要点火。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 18:38; 历代志上 21:26; 历代志下 7:1"> 你们求告你们神的名，我也求告耶和华的名。那用火回应的上帝，就让祂作上帝。”<br />众民回答说：“你所说的好。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 以利亚对巴力的先知说：“你们为自己选择一头公牛，先预备好，因为你们人多；求告你们神的名，却不要点火。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="耶利米书 10:5; 哥林多前书 8:4; 马太福音 6:7"> 他们取了给他们的公牛，预备好了，从早晨直到中午求告巴力的名，说：“巴力啊，应允我们吧！”可是没有声音，也没有人回应。他们在所筑的坛周围跳跃。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="诗篇 78:65–66; 以赛亚书 41:23; 传道书 11:9"> 到了中午，以利亚讥笑他们，说：“大声呼喊吧，因为他是神。他或许正在沉思，或许走到别处，或许正在旅途中；也许他睡着了，必须把他叫醒。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="利未记 19:28; 申命记 14:1; 马可福音 5:5"> 他们就大声呼喊，按他们的规矩用刀和枪割划自己，直到血从身上涌出来。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪上 18:26; 撒母耳记上 18:10; 出埃及记 29:39"> 过了中午，他们说预言，直到献晚祭的时候；可是没有声音，没有回应，也没有人理会。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="历代志下 33:16; 列王纪上 19:14; 列王纪上 19:10"> 以利亚对众民说：“到我这里来！”众民就都到他那里。他修复了已经被拆毁的耶和华的坛。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 17:34; 创世记 35:10; 创世记 32:28"> 以利亚照雅各子孙支派的数目，取了十二块石头；耶和华的话曾临到雅各，说：“你的名要叫以色列。”</span>
<span className="v" id="v32" data-v="32" data-xref="歌罗西书 3:17; 出埃及记 20:24–25; 士师记 21:4"> 他用这些石头奉耶和华的名筑了一座坛，又在坛的四围挖了一条沟，足以容纳二细亚<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一细亚约为7升、1.9加仑或0.8配克。">a</a></sup>的种子。</span>
<span className="v" id="v33" data-v="33" data-xref="创世记 22:9; 士师记 6:20; 利未记 1:6–8"> 他把柴摆好，把公牛切成块子，放在柴上。他说：“把四个罐装满水，倒在燔祭和柴上。”</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多后书 8:21; 哥林多后书 4:2"> 他又说：“做第二次。”他们就做第二次。他说：“做第三次。”他们就做第三次。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 18:32; 列王纪上 18:38"> 水流在坛的四围；他又使沟里也满了水。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="列王纪上 18:29; 列王纪下 19:19; 出埃及记 3:6"> 到了献晚祭的时候，先知以利亚走近，说：“耶和华，亚伯拉罕、以撒、以色列的上帝啊，求你今日使人知道你是以色列中的上帝，也知道我是你的仆人，并且我做这一切事都是照你的话。</span>
<span className="v" id="v37" data-v="37" data-xref="但以理 9:17–19; 路加福音 1:16–17; 以西结 36:25–27"> 耶和华啊，求你应允我，应允我，使这民知道你耶和华是上帝，又知道你已经使他们的心回转过来。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="历代志上 21:26; 利未记 9:24; 历代志下 7:1"> 于是耶和华的火降下，烧尽了燔祭、柴、石头和尘土，又舐尽沟里的水。</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪上 18:24; 历代志下 7:3; 列王纪上 18:21"> 众民看见了，就俯伏在地，说：“耶和华，祂是上帝！耶和华，祂是上帝！”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="申命记 18:20; 士师记 4:7; 申命记 13:5"> 以利亚对他们说：“捉拿巴力的先知！不要让他们逃脱一个！”<br />他们就捉拿了他们；以利亚把他们带下到基顺溪，在那里杀了他们。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="列王纪上 18:1; 传道书 9:7; 列王纪上 17:1"> 以利亚对亚哈说：“起来，吃喝吧；因为有大雨的响声了。”</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="路加福音 6:12; 但以理 9:7; 约书亚记 7:6"> 亚哈就上去吃喝。以利亚上到迦密山顶；他屈身伏在地上，把脸伏在两膝之间。</span>
<span className="v" id="v43" data-v="43" data-xref="哈巴谷 2:3; 路加福音 18:7; 路加福音 18:1"> 他对仆人说：“你现在上去，向海那边观看。”<br />他上去观看，然后说：“什么也没有。”<br />他说：“再去。”如此七次。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="路加福音 12:54; 约伯记 8:7; 撒迦利亚书 4:10"> 到第七次，仆人说：“看哪，有一小片云，像人的手掌，从海里升起。”<br />他说：“你上去告诉亚哈：‘准备好，下去，免得雨阻挡你。’”</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="列王纪上 18:39–40; 约书亚记 17:16; 列王纪上 21:1"> 转眼之间，天空因云和风变黑，就下起大雨。亚哈乘车往耶斯列去。</span>
<span className="v" id="v46" data-v="46" data-xref="以西结 3:14; 以西结 1:3; 列王纪下 9:1"> 耶和华的手临到以利亚；他把外衣束在腰间，跑在亚哈前面，直到耶斯列的入口。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 3:1–2; 使徒行传 7:47; 历代志上 29:19"> 以色列子孙从埃及地出来以后第四百八十年，所罗门作以色列王在位第四年西弗月，就是第二月，他开始建造耶和华的殿。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结 40:1–41; 以西结 41:1–15; 启示录 21:16–17"> 所罗门王为耶和华建的殿，长六十肘，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘是人手臂从中指尖到肘部的长度，约18英寸或46厘米。">a</a></sup>宽二十肘，高三十肘。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 28:11; 历代志下 3:3–4; 以西结 41:15"> 殿堂前的廊子长二十肘，与殿的宽度相同；廊子在殿前宽十肘。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结 40:16; 以西结 41:26; 以西结 41:16"> 他为殿做了固定格棂的窗户。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 6:16; 列王纪上 6:19–21; 列王纪上 6:31"> 他靠着殿墙四围建造楼层，环绕殿堂和内殿的墙；又在四围做了旁屋。</span>
<span className="v" id="v6" data-v="6"> 下层宽五肘，中层宽六肘，第三层宽七肘；因为他在殿墙外侧四围做了壁阶，使梁不插入殿墙里。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 27:5–6; 彼得前书 2:5; 出埃及记 20:25"> 建殿的时候，所用的石头是在采石场预备好的；建殿的时候，在殿里听不见锤子、斧子或任何铁器的声音。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结 41:6–7"> 中层旁屋的门在殿的右侧。人从螺旋梯上到中层，又从中层上到第三层。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 6:14; 列王纪上 6:38"> 这样，他建造殿并完成了；又用香柏木梁和木板遮盖殿。</span>
<span className="v" id="v10" data-v="10"> 他沿着整座殿建造楼层，每层高五肘；这些楼层用香柏木材支承在殿上。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和华的话临到所罗门，说：</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 22:10; 歌罗西书 1:23; 列王纪上 3:14"> “论到你正在建造的这殿，你若遵行我的律例，施行我的典章，谨守我的一切诫命，按着它们而行，我就向你坚立我对你父亲大卫所说的话。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 31:6; 出埃及记 25:8; 利未记 26:11"> 我要住在以色列子孙中间，不离弃我的子民以色列。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王纪上 6:9; 列王纪上 6:38; 使徒行传 7:47–48"> 这样，所罗门建造殿，并完成了。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 7:7"> 他用香柏木板建造殿内的墙；从殿的地面直到顶棚，他在里面都用木板覆盖。他又用柏木板铺殿的地面。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 3:8; 列王纪上 8:6; 希伯来书 9:3"> 他在殿的后部，用香柏木板从地面到顶棚建造了二十肘的隔间；他在殿里面把这隔间建成内殿，就是至圣所。</span>
<span className="v" id="v17" data-v="17"> 内殿前面的殿堂长四十肘。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 7:24"> 殿里面都是香柏木，刻有花蕾和盛开的花；全是香柏木，看不见石头。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 8:6–10; 诗篇 28:2; 列王纪上 6:5"> 他在殿内预备了内殿，要把耶和华的约柜安放在那里。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 6:2–3; 列王纪上 6:22; 列王纪上 7:48"> 内殿里面长二十肘，宽二十肘，高二十肘；他用纯金包裹内殿，又用香柏木包裹祭坛。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志下 3:7–9; 历代志下 3:14–16; 列王纪上 6:5"> 所罗门用纯金包裹殿内；又在内殿前横拉金链，并用金包裹内殿。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 30:1; 出埃及记 30:3; 历代志下 3:7–14"> 他用金包裹整座殿，直到全殿完工；他也用金包裹属于内殿的整座祭坛。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出埃及记 37:7–9; 创世记 3:24; 彼得前书 1:12"> 他在内殿里用橄榄木做了两个基路伯，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“基路伯”是“基路伯”的复数，指一种天使性活物。">b</a></sup>各高十肘。</span>
<span className="v" id="v24" data-v="24"> 基路伯的一个翅膀长五肘，基路伯的另一个翅膀也长五肘；从一个翅膀尖到另一个翅膀尖，共十肘。</span>
<span className="v" id="v25" data-v="25"> 另一个基路伯也是十肘。两个基路伯尺寸一样，形状相同。</span>
<span className="v" id="v26" data-v="26"> 一个基路伯高十肘，另一个基路伯也是这样。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 37:9; 出埃及记 25:20; 历代志下 5:8"> 他把基路伯安放在内殿里。基路伯的翅膀伸展开来，一个基路伯的翅膀触到这边墙，另一个基路伯的翅膀触到那边墙；它们的翅膀在殿的中央彼此相接。</span>
<span className="v" id="v28" data-v="28"> 他用金包裹基路伯。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王纪上 6:32; 诗篇 92:12–15; 历代志下 4:2–5"> 他在殿四围所有墙上雕刻基路伯、棕树和盛开的花的图案，里外都是如此。</span>
<span className="v" id="v30" data-v="30" data-xref="启示录 21:18–21; 以赛亚书 60:17; 以赛亚书 54:11–12"> 他用金包裹殿的地面，里外都是如此。</span>
<span className="v" id="v31" data-v="31" data-xref="希伯来书 10:19–20; 以弗所书 3:18; 约翰福音 14:6"> 他为内殿的入口做了橄榄木门；门楣和门柱占墙的五分之一。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 6:18; 列王纪上 6:29"> 他这样做了两扇橄榄木门；在门上雕刻基路伯、棕树和盛开的花，并用金包裹。他把金铺在基路伯和棕树上。</span>
<span className="v" id="v33" data-v="33"> 他又为殿堂的入口做了橄榄木门柱，占墙的四分之一，</span>
<span className="v" id="v34" data-v="34" data-xref="以西结 41:23–25; 列王纪上 5:8"> 和两扇柏木门；这一扇门的两片门叶是折叠的，那一扇门的两片门叶也是折叠的。</span>
<span className="v" id="v35" data-v="35"> 他雕刻基路伯、棕树和盛开的花，并用金包裹，使金贴合在雕刻上。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 7:12; 历代志下 7:7; 出埃及记 27:9–19"> 他用三层凿成的石头和一层香柏木梁建造内院。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="列王纪上 6:1; 历代志下 3:2"> 第四年西弗月，耶和华殿的根基立定。</span>
<span className="v" id="v38" data-v="38" data-xref="以斯拉记 6:14–15; 列王纪上 7:1; 撒迦利亚书 4:9"> 第十一年布勒月，就是第八月，殿按着它所有部分和一切规格都完成了。这样，他建殿用了七年。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 7:11–6; 列王纪上 9:19; 列王纪上 7:51"> 所罗门建造完耶和华的殿、王的宫殿，以及所罗门所喜悦要做的一切心愿之后，</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 3:5; 历代志下 7:12; 列王纪上 11:9"> 耶和华第二次向所罗门显现，正如祂曾在基遍向他显现一样。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 10:17; 约翰一书 5:14; 列王纪下 20:5"> 耶和华对他说：“你在我面前所作的祷告和恳求，我已经听见了。你所建的这殿，我已经分别为圣，使我的名永远在那里；我的眼和我的心也必常在那里。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 15:5; 列王纪上 3:14; 列王纪上 11:6"> 至于你，如果你像你父亲大卫所行的一样，存纯全的心和正直，在我面前行事，照我所吩咐你的一切去做，谨守我的律例和典章，</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 2:4; 列王纪上 6:12; 撒母耳记下 7:16"> 我就必坚立你治理以色列的国位，直到永远，正如我应许你父亲大卫说：‘你必不缺人坐以色列的王位。’</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 7:14–16; 历代志上 28:9; 历代志下 15:2"> 但如果你们和你们的子孙转离，不跟从我，不谨守我摆在你们面前的诫命和律例，反而去事奉别的神明，敬拜它们，</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 44:14; 耶利米书 24:9; 申命记 4:26"> 我就必把以色列从我赐给他们的地上剪除；这殿，就是我为我的名分别为圣的殿，我也必从我面前丢弃；以色列必在万民中成为俗语和笑谈。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 29:24–26; 耶利米书 22:8–9; 历代志下 7:21"> 这殿虽然如此高大，凡经过的人都必惊骇，发出嘘声；他们要说：‘耶和华为什么这样待这地和这殿呢？’</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 2:19; 耶利米书 5:19; 申命记 29:25–28"> 人必回答：‘因为他们离弃了耶和华他们的上帝，就是领他们祖先出埃及地的那一位，转而依附别的神明，敬拜它们，事奉它们。因此，耶和华使这一切灾祸临到他们。’”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="列王纪上 6:37–1; 历代志下 8:1–18; 列王纪上 9:1"> 二十年期满的时候，所罗门已经建造完两座殿，就是耶和华的殿和王的宫殿。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 8:2; 历代志下 2:16; 历代志下 2:8–10"> （推罗王希兰曾照所罗门一切的愿望，供给他香柏木、松木和金子。）所罗门王就把加利利地的二十座城给了希兰。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 22:34; 士师记 14:3"> 希兰从推罗出来，要看看所罗门给他的那些城；这些城却不合他的心意。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 19:27; 阿摩司 1:9; 列王纪上 5:1–2"> 他说：“我兄弟啊，你给我的这些是什么城呢？”他称那些城为迦步勒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“迦步勒”的发音近似希伯来语“毫无用处”。">a</a></sup>之地，直到今日。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 9:11; 列王纪上 10:10; 列王纪上 9:28"> 希兰送给王一百二十他连得<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一他连得约为30公斤或66磅，或965金衡盎司；因此120他连得约为3.6公吨。">b</a></sup>金子。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约书亚记 17:11; 列王纪上 9:24; 撒母耳记下 5:9"> 所罗门王征召强制劳役，是为了建造耶和华的殿、自己的宫殿、米罗、耶路撒冷的城墙、夏琐、米吉多和基色。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 3:1; 列王纪上 9:24; 列王纪上 7:8"> 埃及王法老曾上来攻取基色，用火焚烧，杀了住在城里的迦南人，又把这城作为陪嫁礼物给了自己的女儿，就是所罗门的妻子。</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 16:3; 约书亚记 21:22; 历代志下 8:4–18"> 所罗门在那地建造了基色、下伯·和仑、</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 19:44; 历代志下 8:4"> 巴拉、旷野中的他玛，</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 9:1; 传道书 6:9; 出埃及记 1:11"> 以及所罗门所有的储货城、战车城、骑兵城，又在耶路撒冷、黎巴嫩和他所统治的全地，建造他所喜悦要建的一切。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 23:23; 创世记 15:19–21; 申命记 7:1–3"> 至于亚摩利人、赫人、比利洗人、希未人和耶布斯人中所有剩下的人，就是那些不属于以色列人的人——</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 17:12; 士师记 1:21; 约书亚记 15:63"> 他们的子孙在他们之后仍留在这地，就是以色列人不能完全灭尽的那些人——所罗门从他们中征召人作服劳役的奴仆，直到今日。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 25:39; 列王纪上 4:1–27; 撒母耳记上 8:11–12"> 但所罗门没有使以色列人作奴仆；他们是战士、他的臣仆、他的官长、他的军官，以及管理他的战车和骑兵的长官。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 5:16; 历代志下 8:10; 历代志下 2:18"> 这些人是监管所罗门工程的长官，共五百五十名，管理做工的百姓。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王纪上 7:8; 撒母耳记下 5:9; 历代志下 32:5"> 但法老的女儿从大卫城上到所罗门为她建造的宫殿。那时，所罗门建造了米罗。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="历代志下 8:12–13; 历代志下 8:16; 出埃及记 23:14–17"> 所罗门每年三次在他为耶和华建造的坛上献燔祭和平安祭，也在耶和华面前的坛上与这些祭一同烧香。这样，他完成了这殿。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="列王纪上 22:48; 民数记 33:35; 申命记 2:8"> 所罗门王在以东地、红海岸边、以禄旁边的以旬·迦别建造了一支船队。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 10:11; 列王纪上 5:6; 列王纪上 5:9"> 希兰派他的仆人，就是熟悉海事的水手，与所罗门的仆人一同上船。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 8:18; 历代志上 29:4; 列王纪上 10:11"> 他们到了俄斐，从那里取得四百二十他连得<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一他连得约为30公斤或66磅，或965金衡盎司；因此420他连得约为12.6公吨。">c</a></sup>金子，带给所罗门王。</span>
</div>
</div>

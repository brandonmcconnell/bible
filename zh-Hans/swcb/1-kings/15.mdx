<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 14:31; 历代志下 13:1–22"> 尼八的儿子耶罗波安王第十八年，亚比央登基作犹大王。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 13:2; 历代志下 11:20–22; 列王纪上 15:13"> 他在耶路撒冷统治三年。他母亲名叫玛迦，是亚比沙龙的女儿。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 11:4; 诗篇 119:80; 列王纪上 3:14"> 亚比央行了他父亲在他以前所行的一切罪；他的心不像他祖先大卫的心那样，完全归向耶和华他的上帝。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 11:36; 历代志下 21:7; 以赛亚书 37:35"> 然而，为了大卫的缘故，耶和华他的上帝在耶路撒冷给他一盏灯，立他的儿子接续他，并坚立耶路撒冷；</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 14:8; 撒母耳记下 11:15–17; 列王纪上 15:3"> 因为大卫行耶和华眼中看为正的事，一生没有偏离耶和华所吩咐他的一切事，只有赫人乌利亚那件事例外。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 14:30"> 罗波安和耶罗波安之间，他一生都有战争。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 13:2–22; 列王纪上 14:29"> 亚比央其余的事迹和他所行的一切，不都写在《犹大诸王记》上吗？亚比央和耶罗波安之间有战争。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 14:1; 列王纪上 14:31; 马太福音 1:7–8"> 亚比央与他祖先同睡，众人把他葬在大卫城；他的儿子亚撒接续他作王。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 以色列王耶罗波安第二十年，亚撒登基作犹大王。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 15:2; 列王纪上 15:13; 历代志下 13:2"> 他在耶路撒冷统治四十一年。他母亲名叫玛迦，是亚比沙龙的女儿。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 14:2; 历代志下 15:17; 列王纪上 15:3"> 亚撒行耶和华眼中看为正的事，像他祖先大卫所行的一样。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 22:46; 列王纪上 14:23–24; 历代志下 14:2–5"> 他把男庙妓从境内除去，又除掉他祖先所造的一切偶像。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 32:20; 申命记 7:5; 撒迦利亚书 13:3"> 他还废除了他母亲玛迦太后的位分，因为她为亚舍拉造了可憎的像。亚撒砍下她的像，在汲沦溪旁烧了。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 22:43; 列王纪上 8:61; 列王纪上 15:3"> 只是邱坛还没有废去。然而亚撒的心一生都完全归向耶和华。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 7:51; 历代志下 14:13; 历代志下 15:18"> 他把他父亲所分别为圣的物和自己所分别为圣的物，就是银子、金子和器具，都带进耶和华的殿。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪上 15:32; 列王纪上 14:30; 历代志下 16:1–6"> 亚撒和以色列王巴沙之间，他们一生都有战争。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 12:27; 历代志下 16:1–6; 约书亚记 18:25"> 以色列王巴沙上来攻击犹大，修筑拉玛，要不许人出入犹大王亚撒那里。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 14:26; 列王纪下 12:18; 列王纪上 11:23–24"> 于是亚撒把耶和华殿的府库和王宫府库中所剩下的一切银子和金子，都交在他臣仆手中。亚撒王差遣他们去见住在大马士革的亚兰王便哈达，就是希旬的孙子、他伯利们的儿子，说：</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 1:31; 历代志下 16:7; 罗马书 3:8"> “我与你之间要立约，像我父亲与你父亲之间所立的约一样。看哪，我送给你银子和金子作为礼物。请你去废除你与以色列王巴沙所立的约，使他离开我。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王纪下 15:29; 士师记 18:29; 约书亚记 11:2"> 便哈达听从亚撒王，派他军队的将领去攻击以色列的城邑，击败了以云、但、亚伯·伯·玛迦、全基尼烈，以及拿弗他利全地。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 14:17; 列王纪上 16:15–18; 历代志下 16:5"> 巴沙听见了，就停工不修筑拉玛，住在得撒。</span>
<span className="v" id="v22" data-v="22" data-xref="约书亚记 21:17; 约书亚记 18:24; 约书亚记 18:26"> 于是亚撒王向犹大众人宣告，没有人得免除。他们搬走巴沙用来修筑拉玛的石头和木料；亚撒王用这些去修筑便雅悯的迦巴和米斯巴。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志下 16:11–14; 列王纪上 14:29–31; 列王纪上 15:7–8"> 亚撒其余的一切事迹、他所有的勇力、他所行的一切，以及他所建造的城邑，不都写在《犹大诸王记》上吗？只是他年老的时候，脚患了病。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 1:8; 列王纪上 22:41–43; 历代志下 17:1–9"> 亚撒与他祖先同睡，与他祖先同葬在他祖先大卫的城里；他的儿子约沙法接续他作王。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="列王纪上 14:20; 列王纪上 14:12"> 犹大王亚撒第二年，耶罗波安的儿子拿答登基作以色列王；他作以色列王两年。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 14:16; 列王纪上 15:34; 列王纪上 15:30"> 他行耶和华眼中看为恶的事，走他父亲的路，犯他父亲使以色列陷在其中的罪。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 19:44; 约书亚记 21:23; 列王纪上 14:14"> 以萨迦家的亚希雅的儿子巴沙背叛拿答；巴沙在属于非利士人的基比顿击杀了他，因为拿答和以色列众人正在围攻基比顿。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 32:35"> 就在犹大王亚撒第三年，巴沙杀了他，接续他作王。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪上 14:9–16; 列王纪下 19:25; 列王纪下 10:10–11"> 巴沙一作王，就击杀耶罗波安全家。凡有气息的，他一个也没有给耶罗波安留下，直到把耶罗波安家灭尽，正应验了耶和华借祂仆人示罗人亚希雅所说的话；</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 15:26; 列王纪上 14:22; 列王纪上 14:9–16"> 这是因耶罗波安所犯的罪，也因他使以色列陷在其中的罪，并因他惹耶和华以色列的上帝发怒的激怒。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪上 14:19; 列王纪上 16:20; 列王纪上 16:14"> 拿答其余的事迹和他所行的一切，不都写在《以色列诸王记》上吗？</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 15:16"> 亚撒和以色列王巴沙之间，他们一生都有战争。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="列王纪上 16:8"> 犹大王亚撒第三年，亚希雅的儿子巴沙在得撒登基，作全以色列的王二十四年。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 15:26; 列王纪上 14:16; 列王纪上 12:28–29"> 他行耶和华眼中看为恶的事，走耶罗波安的路，犯耶罗波安使以色列陷在其中的罪。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 47:29; 申命记 31:14; 提摩太前书 1:18"> 大卫临终的日子近了，他吩咐他的儿子所罗门说：</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 1:6–7; 约书亚记 23:14; 以弗所书 6:10"> “我要走世人都要走的路。所以你要刚强，作大丈夫；</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 29:9; 申命记 17:18–20; 箴言 3:1–4"> 要谨守耶和华你上帝的训诲，行祂的道路，遵守祂的律例、诫命、典章和法度，照摩西律法上所写的，好使你凡所做的、无论转向哪里都亨通。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 20:3; 撒母耳记下 7:25; 列王纪上 8:25"> 这样，耶和华就可以坚立祂论到我所说的话，说：‘你的子孙若谨慎自己的道路，全心全意按真理行在我面前，’祂说，‘你就必不断有人坐以色列的宝座。’</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 3:27; 撒母耳记下 20:10; 撒母耳记下 18:5"> “此外，你也知道洗鲁雅的儿子约押怎样待我，就是他怎样待以色列两位军队元帅：尼珥的儿子押尼珥和益帖的儿子亚玛撒；他杀了他们，在太平时流了战时的血，把战时的血沾在他腰间的带子和脚上的鞋上。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 2:9; 以赛亚书 57:21; 诗篇 37:37"> 所以你要照你的智慧行，不要让他的白发安然下到阴间<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="阴间是死人所在之处。">a</a></sup>。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 17:27–29; 撒母耳记下 9:7; 撒母耳记下 19:31–40"> 但你要恩待基列人巴西莱的众子，使他们列在与你同席吃饭的人中；因为我逃避你哥哥押沙龙的时候，他们就是这样来接待我的。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 16:5–8; 列王纪上 2:36–46; 撒母耳记下 19:16–23"> “看哪，在你那里有巴户琳的便雅悯人，基拉的儿子示每；我去玛哈念的那一天，他用严厉的咒骂咒诅我；后来他下到约旦河迎接我，我就指着耶和华向他起誓说：‘我必不用刀杀你。’</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 2:6; 创世记 42:38; 创世记 44:31"> 现在你不要以他为无罪，因为你是聪明人，知道该怎样待他；你要使他的白发带着血下到阴间<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="阴间是死人所在之处。">b</a></sup>。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 2:29; 使徒行传 13:36; 列王纪上 1:21"> 大卫与他的列祖同睡，葬在大卫城。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 5:4–5; 历代志上 29:26–27"> 大卫作以色列王的日子是四十年；他在希伯仑作王七年，在耶路撒冷作王三十三年。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 1:1; 历代志上 29:23–25; 诗篇 132:12"> 所罗门坐在他父亲大卫的王位上；他的国位非常稳固。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 16:4–5; 列王纪上 1:5–10; 路加福音 10:5–6"> 哈及的儿子亚多尼雅来见所罗门的母亲拔示巴。她说：“你来是平安的吗？”<br />他说：“是平安的。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 14:12; 路加福音 7:40"> 他又说，我有话要告诉你。”<br />她说：“你说吧。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="历代志上 22:9–10; 历代志上 28:5–7; 列王纪上 1:25"> 他说：“你知道这国原是我的，全以色列都定意拥戴我作王。然而，国位转归我兄弟了；因为这是从耶和华而来的。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 30:7; 诗篇 132:10"> 现在我求你一件事，请不要拒绝我。”<br />她对他说：“你说吧。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 12:8; 列王纪上 1:2–4; 撒母耳记下 3:7"> 他说：“请你对所罗门王说，因为他不会拒绝你，求他把书念女子亚比煞赐给我作妻子。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="箴言 14:15"> 拔示巴说：“好，我必为你向王说。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="诗篇 45:9; 列王纪上 15:13; 利未记 19:32"> 于是拔示巴去见所罗门王，要为亚多尼雅向他说话。王起来迎接她，向她下拜，然后坐在自己的王位上，又吩咐人为王母设一个座位；她就坐在王的右边。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 7:7–11; 马太福音 11:24; 约翰福音 2:3–4"> 她说：“我有一件小事求你，请不要拒绝我。”<br />王对她说：“母亲，请说吧，因为我不会拒绝你。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王纪上 1:3; 撒母耳记下 16:21–22"> 她说：“请将书念女子亚比煞赐给你哥哥亚多尼雅作妻子。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="历代志上 3:2; 历代志上 3:5; 马太福音 20:22"> 所罗门王回答他母亲说：“为什么为亚多尼雅求书念女子亚比煞呢？也为他求国吧，因为他是我的哥哥；不但为他，也为祭司亚比亚他和洗鲁雅的儿子约押求吧。”</span>
<span className="v" id="v23" data-v="23" data-xref="路得记 1:17; 诗篇 140:9; 诗篇 64:8"> 于是所罗门王指着耶和华起誓说：“亚多尼雅若不是说了这话自取性命，愿上帝重重地降罚于我。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 22:10; 历代志上 17:10; 历代志上 17:17"> 现在，永活的耶和华既然坚立我，使我坐在我父亲大卫的王位上，又照祂所应许的为我建立家，亚多尼雅今日必被处死。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 8:18; 列王纪上 2:46; 士师记 8:20–21"> 所罗门王派耶何耶大的儿子比拿雅去；他击杀亚多尼雅，亚多尼雅就死了。</span>
<span className="v" id="v26" data-v="26" data-xref="约书亚记 21:18; 撒母耳记上 22:20–23; 耶利米书 1:1"> 王对祭司亚比亚他说：“你回亚拿突，到你自己的田地去吧，因为你本是该死的。但这一次我不处死你，因为你在我父亲大卫面前抬过主<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="译为“主”的词是“Adonai”。">c</a></sup>耶和华的约柜，也因为我父亲所受的一切苦难，你也一同受过。”</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 2:27–36; 撒母耳记上 3:12–14; 耶利米书 7:12–14"> 于是所罗门革除亚比亚他，不许他作耶和华的祭司，为要应验耶和华在示罗论以利家所说的话。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王纪上 1:50; 列王纪上 1:7; 撒母耳记下 18:2"> 这消息传到约押那里；约押曾随从亚多尼雅，虽然他没有随从押沙龙。约押逃到耶和华的帐幕，抓住祭坛的角。</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪上 2:25; 出埃及记 21:14; 列王纪上 2:46"> 有人告诉所罗门王说：“约押逃到耶和华的帐幕；看哪，他在祭坛旁。”所罗门就派耶何耶大的儿子比拿雅，说：“你去击杀他。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 比拿雅来到耶和华的帐幕，对约押说：“王这样说：‘出来！’”<br />他说：“不，我要死在这里。”<br />比拿雅回去向王报告说：“约押这样说，他这样回答我。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="申命记 21:8–9; 民数记 35:33; 出埃及记 21:14"> 王对他说：“就照他说的去做，击杀他，把他埋葬，好使约押无故所流的血离开我和我父亲的家。</span>
<span className="v" id="v32" data-v="32" data-xref="士师记 9:24; 士师记 9:57; 诗篇 7:16"> 耶和华必使他的血归到他自己的头上，因为他下手攻击了两个比他更公义、更好的人，用刀杀了他们，而我父亲大卫并不知道；他们就是以色列军队的元帅、尼珥的儿子押尼珥，和犹大军队的元帅、益帖的儿子亚玛撒。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 27:25; 列王纪上 2:32; 路加福音 2:14"> 所以他们的血必永远归到约押的头上和他后裔<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或作：种子">d</a></sup>的头上。但大卫、他的后裔、他的家和他的王位，必永远从耶和华得平安。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马太福音 3:1; 约书亚记 15:61; 列王纪上 2:25"> 于是耶何耶大的儿子比拿雅上去击杀约押，把他杀死；约押葬在旷野他自己的家中。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 2:27; 历代志上 24:3; 历代志上 29:22"> 王派耶何耶大的儿子比拿雅接替约押统领军队；王又派祭司撒督接替亚比亚他。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="撒母耳记下 16:5–9; 列王纪上 2:8–9; 箴言 20:26"> 王派人召示每来，对他说：“你要在耶路撒冷为自己建造房屋，住在那里，不可往别处去。</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳记下 1:16; 撒母耳记下 15:23; 约书亚记 2:19"> 因为你出去、过汲沦溪的那一天，你要确知你必定死；你的血必归到你自己的头上。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="列王纪上 20:4; 列王纪下 20:19"> 示每对王说：“你所说的很好。我主我王怎样说，你的仆人就怎样做。”于是示每在耶路撒冷住了许多日子。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="撒母耳记上 21:10; 撒母耳记上 27:2–3"> 过了三年，示每的两个奴仆逃到迦特王、玛迦的儿子亚吉那里。有人告诉示每说：“看哪，你的奴仆在迦特。”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="路加福音 12:15; 箴言 15:27; 提摩太前书 6:10"> 示每就起来，备上驴，往迦特去见亚吉，要寻找他的奴仆；示每去了，把他的奴仆从迦特带回来。</span>
<span className="v" id="v41" data-v="41"> 有人告诉所罗门，示每从耶路撒冷去了迦特，又回来了。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="诗篇 15:4; 列王纪上 2:36–38; 路加福音 15:22"> 王就派人召示每来，对他说：“我岂不是叫你指着耶和华起誓，并且警告你说：‘你要确知，你出去往别处去的那一天，你必定死’吗？你对我说：‘我所听见的话很好。’</span>
<span className="v" id="v43" data-v="43" data-xref="罗马书 13:5; 历代志下 30:12; 传道书 8:2"> 那么，你为什么没有遵守耶和华的誓言和我吩咐你的命令呢？”</span>
<span className="v" id="v44" data-v="44" data-xref="撒母耳记下 16:5–13; 诗篇 7:16; 以西结 17:19"> 王又对示每说：“你心里知道你向我父亲大卫所行的一切恶。所以耶和华必使你的恶归到你自己的头上。</span>
<span className="v" id="v45" data-v="45" data-xref="箴言 25:5; 列王纪上 2:24; 以赛亚书 9:6–7"> 但所罗门王必蒙福，大卫的王位必在耶和华面前永远坚立。”</span>
<span className="v" id="v46" data-v="46" data-xref="历代志下 1:1; 列王纪上 2:12; 列王纪上 2:45"> 于是王吩咐耶何耶大的儿子比拿雅；他出去击杀示每，示每就死了。国位在所罗门手中坚立了。</span>
</div>
</div>

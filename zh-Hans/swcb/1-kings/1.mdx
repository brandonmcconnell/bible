<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 23:1–2; 历代志上 29:27–28; 历代志上 23:1"> 大卫王年纪老迈，年岁已高；人给他盖上衣被，他却不能暖和。</span>
<span className="v" id="v2" data-v="2" data-xref="传道书 4:11; 创世记 16:5; 弥迦书 7:5"> 于是他的臣仆对他说：“请为我主我王寻找一个年轻的童女，让她侍立在王面前，照料王；让她睡在你怀中，使我主我王得以暖和。”</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 19:18; 以斯帖记 2:4; 以斯帖记 2:2"> 他们就在以色列全境寻找美貌的年轻女子，找到了书念女子亚比煞，就把她带到王那里。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 1:25"> 这年轻女子极其美貌；她照料王，服侍王，但王没有与她同房。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 15:1; 撒母耳记下 3:4; 申命记 17:15–16"> 那时，哈及的儿子亚多尼雅自高，说：“我要作王。”于是他为自己预备车辆、马兵，又派五十人在他前面奔跑。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 3:3–4; 撒母耳记上 3:13; 希伯来书 12:5–6"> 他父亲从来没有使他不悦，问他说：“你为什么这样做？”他也非常俊美，是押沙龙以后生的。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 20:25; 列王纪上 2:22; 撒母耳记上 22:20–23"> 他与洗鲁雅的儿子约押和祭司亚比亚他商议；他们就跟从亚多尼雅，帮助他。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 4:18; 撒母耳记下 23:8–39; 撒母耳记下 20:25"> 但是祭司撒督、耶何耶大的儿子比拿雅、先知拿单、示每、利以，以及属于大卫的勇士，都没有与亚多尼雅在一起。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 17:17; 撒母耳记下 13:23–27; 撒母耳记下 15:11–12"> 亚多尼雅在隐·罗结旁边的琐希列磐石那里宰了羊、牛和肥畜，邀请了他所有的兄弟，就是王的众子，以及所有作王臣仆的犹大人；</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 12:24; 列王纪上 1:19; 撒母耳记下 12:1–15"> 但他没有邀请先知拿单、比拿雅、勇士们，以及他的兄弟所罗门。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 3:4; 撒母耳记下 7:12–17; 撒母耳记下 12:24–25"> 拿单对所罗门的母亲拔示巴说：“哈及的儿子亚多尼雅已经作王了，我们的主大卫却不知道，你没有听说吗？</span>
<span className="v" id="v12" data-v="12" data-xref="箴言 11:14; 使徒行传 27:31; 创世记 19:17"> 现在请来，让我给你出个主意，好救你自己的性命和你儿子所罗门的性命。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 1:30; 列王纪上 1:17; 诗篇 132:11–12"> 你进去见大卫王，对他说：‘我主我王啊，你不是曾向你的婢女起誓说：“你儿子所罗门必接续我作王，坐在我的王位上”吗？那么，亚多尼雅为什么作王了呢？’</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 13:1; 列王纪上 1:17–27"> 看哪，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“看哪”源自“הִנֵּה”，意思是看、留意、观察、看见或注视。它常用作感叹词。">a</a></sup>你还在那里与王说话的时候，我也会随后进去，证实你的话。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王纪上 1:1"> 拔示巴进内室见王。王非常老迈；书念女子亚比煞正在服侍王。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 25:23; 撒母耳记上 24:8; 撒母耳记上 20:41"> 拔示巴向王屈身下拜，表示敬意。王说：“你要什么？”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王纪上 1:13; 列王纪上 1:30; 彼得前书 3:6"> 她对王说：“我主啊，你曾指着耶和华<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="当英文以全大写形式译作“LORD”或“GOD”时，是在翻译上帝的专有名（希伯来文“יהוה”，通常读作雅威）。">b</a></sup>你的上帝<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="译作“上帝”的希伯来词是“אֱלֹהִ֑ים”（Elohim）。">c</a></sup>向你的婢女起誓说：‘你儿子所罗门必接续我作王，坐在我的王位上。’</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 1:24; 列王纪上 1:11; 使徒行传 3:17"> 现在，看哪，亚多尼雅作王了；而你，我主我王，却不知道。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 1:25; 列王纪上 1:7–10"> 他宰了许多牛、肥畜和羊，邀请了王的众子、祭司亚比亚他和军队的统帅约押；但他没有邀请你的仆人所罗门。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志上 29:1; 诗篇 123:2; 历代志上 22:8–10"> 至于你，我主我王，全以色列的眼目都仰望你，等你告诉他们，谁要在我主我王之后坐在他的王位上。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 2:10; 申命记 31:16; 创世记 15:15"> 否则，等我主我王与他列祖同睡的时候，我和我儿子所罗门就会被视为罪犯。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约伯记 1:16–18; 创世记 24:15; 但以理 9:20"> 看哪，她还在与王说话的时候，先知拿单进来了。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 1:16; 彼得前书 2:17; 罗马书 13:7"> 有人告诉王说：“看哪，先知拿单来了！”<br />他来到王面前，就俯伏在地，向王下拜。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 1:17–18; 列王纪上 1:5; 列王纪上 1:13–14"> 拿单说：“我主我王啊，你曾说过：‘亚多尼雅必接续我作王，坐在我的王位上’吗？</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 10:24; 列王纪上 1:19; 列王纪上 1:9"> 因为他今天下去，宰了许多牛、肥畜和羊，邀请了王的众子、军队的众统帅和祭司亚比亚他。看哪，他们正在他面前吃喝，说：‘愿亚多尼雅王万岁！’</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 1:8; 列王纪上 1:10; 撒母耳记下 7:2"> 但他没有邀请我，就是你的仆人，也没有邀请祭司撒督、耶何耶大的儿子比拿雅，以及你的仆人所罗门。</span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 15:15; 列王纪上 1:24; 列王纪下 4:27"> 这事是出于我主我王吗？你却没有告诉你的仆人，谁应当在我主我王之后坐在他的王位上。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 大卫王回答说：“叫拔示巴到我这里来。”她就来到王面前，站在王面前。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 4:9; 诗篇 136:24; 撒母耳记上 14:45"> 王起誓说：“我指着那救赎我的性命脱离一切患难、永活的耶和华起誓，</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 1:13; 列王纪上 1:17"> 我既然指着耶和华——以色列的上帝——向你起誓说：‘你儿子所罗门必接续我作王，代替我坐在我的王位上’，我今天必定照这话而行。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="但以理 2:4; 但以理 5:10; 但以理 3:9"> 于是拔示巴面伏于地，向王下拜，表示敬意，说：“愿我主大卫王万岁！”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="列王纪上 1:8; 列王纪上 1:38; 列王纪上 1:26"> 大卫王说：“把祭司撒督、先知拿单和耶何耶大的儿子比拿雅叫到我这里来。”他们就来到王面前。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志下 32:30; 列王纪上 1:38; 历代志下 33:14"> 王对他们说：“带着你们主人的臣仆，使我儿子所罗门骑上我自己的骡子，带他下到基训。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 1:25; 撒母耳记下 15:10; 撒母耳记上 10:1"> 祭司撒督和先知拿单要在那里膏他作以色列的王。你们要吹号，说：‘愿所罗门王万岁！’</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 1:17; 诗篇 72:1–2; 列王纪上 1:13"> 然后你们要跟随他上来，他要来坐在我的王位上；因为他要代替我作王。我已经立他作以色列和犹大的君王。”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="耶利米书 28:6; 哥林多前书 14:16; 诗篇 72:19"> 耶何耶大的儿子比拿雅回答王说：“阿们。愿耶和华，我主我王的上帝，也这样说。</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳记上 20:13; 列王纪上 1:47; 约书亚记 1:17"> 耶和华怎样与我主我王同在，愿祂也照样与所罗门同在，使他的王位比我主大卫王的王位更大。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="撒母耳记下 8:18; 列王纪上 1:8; 列王纪上 1:33"> 于是祭司撒督、先知拿单、耶何耶大的儿子比拿雅，以及基利提人和比利提人，都下去，使所罗门骑上大卫王的骡子，把他带到基训。</span>
<span className="v" id="v39" data-v="39" data-xref="诗篇 89:20; 列王纪上 1:34; 历代志上 29:22"> 祭司撒督从帐幕中取了盛油的角，膏了所罗门。他们吹号，众民都说：“愿所罗门王万岁！”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="列王纪下 11:14; 撒迦利亚书 9:9; 列王纪下 11:20"> 众民都跟随他上来，百姓吹笛，极其欢喜，以致地都因他们的声音震动。</span>
<span className="v" id="v41" data-v="41" data-xref="约伯记 15:21–22; 路加福音 17:26–29; 使徒行传 21:31"> 亚多尼雅和所有与他同在的宾客刚吃完，就听见了。约押听见号声，就说：“城里为什么有这样喧闹的声音？”</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="撒母耳记下 15:36; 撒母耳记下 17:17; 撒母耳记下 18:27"> 他还在说话的时候，看哪，祭司亚比亚他的儿子约拿单来了；亚多尼雅说：“进来吧；因为你是个贤良的人，必带来好消息。”</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43"> 约拿单回答亚多尼雅说：“确实，我们的主大卫王已经立所罗门作王了。</span>
<span className="v" id="v44" data-v="44"> 王派祭司撒督、先知拿单、耶何耶大的儿子比拿雅，以及基利提人和比利提人与他同去；他们使他骑上王的骡子。</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪上 1:40; 但以理 5:26–28; 撒母耳记上 4:5"> 祭司撒督和先知拿单已经在基训膏他作王。他们从那里欢欢喜喜地上来，以致全城都回响。这就是你们所听见的声音。</span>
<span className="v" id="v46" data-v="46" data-xref="历代志上 29:23; 诗篇 132:11; 列王纪上 1:13"> 并且，所罗门已经坐在国位上。</span>
<span className="v" id="v47" data-v="47" data-xref="创世记 47:31; 列王纪上 1:37; 以斯拉记 6:10"> 而且王的臣仆来祝福我们的主大卫王，说：‘愿你的上帝使所罗门的名比你的名更美，使他的王位比你的王位更大。’王就在床上屈身下拜。</span>
<span className="v" id="v48" data-v="48" data-xref="列王纪上 3:6; 诗篇 132:11–12; 诗篇 145:2"> 王还这样说：‘耶和华，以色列的上帝，是应当称颂的；祂今日赐下一人坐在我的王位上，甚至使我的眼睛亲眼看见了。’”</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="以赛亚书 21:4–5; 箴言 28:1; 但以理 5:4–6"> 亚多尼雅所有的宾客都惧怕，就起来，各人走自己的路去了。</span>
<span className="v" id="v50" data-v="50" data-xref="列王纪上 2:28; 出埃及记 21:14; 出埃及记 27:2"> 亚多尼雅因所罗门而惧怕，就起来，去抓住祭坛的角。</span>
<span className="v" id="v51" data-v="51"> 有人告诉所罗门说：“看哪，亚多尼雅惧怕所罗门王；看哪，他正抓住祭坛的角，说：‘愿所罗门王先向我起誓，不用刀杀他的仆人。’”</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="撒母耳记上 14:45; 撒母耳记下 14:11; 箴言 13:6"> 所罗门说：“他若显明自己是贤良的人，连他的一根头发也不会落在地上；但他若被发现有恶，就必死。”</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="列王纪上 1:16; 撒母耳记下 14:24; 撒母耳记下 1:2"> 于是所罗门王派人把他从祭坛那里带下来。他来向所罗门王下拜；所罗门对他说：“回你家去吧。”</span>
</div>
</div>

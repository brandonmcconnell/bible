<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 14:1; 历代志下 2:3; 列王纪上 5:10"> 推罗王希兰派他的臣仆到所罗门那里，因为他听说众人已经膏所罗门接替他父亲作王；希兰一向爱大卫。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 2:3"> 所罗门差人去见希兰，说：</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 28:3; 历代志上 22:8; 诗篇 110:1"> “你知道，我父亲大卫因为四围的战争，不能为耶和华他上帝的名建殿，直到耶和华把他的仇敌放在他脚掌之下。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 22:9; 列王纪上 4:24; 使徒行传 9:31"> 但现在，耶和华我的上帝使我四境安宁；没有仇敌，也没有灾祸。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 17:12; 历代志上 22:10; 撒母耳记下 7:12–13"> 看哪，我有意为耶和华我上帝的名建殿，正如耶和华对我父亲大卫所说：‘我必立你的儿子接替你坐在你的王位上；他要为我的名建造这殿。’</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 2:8; 列王纪上 6:9–10; 罗马书 12:17"> 现在，请你吩咐人为我从黎巴嫩砍伐香柏木。我的臣仆会与你的臣仆同在；你臣仆的工价，我必照你所说的一切给你。因为你知道，我们中间没有人像西顿人那样善于砍伐木材。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="箴言 23:24; 以赛亚书 9:6; 历代志下 2:11–12"> 希兰听见所罗门的话，就大大欢喜，说：“今日耶和华是当受称颂的，因为祂赐给大卫一个有智慧的儿子，来治理这伟大的百姓。”</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 6:34; 历代志下 3:5; 撒母耳记下 6:5"> 希兰差人去见所罗门，说：“你差人给我的话，我已经听见了。凡你所愿关于香柏木材和柏木材的事，我都必照办。</span>
<span className="v" id="v9" data-v="9" data-xref="以斯拉记 3:7; 以西结 27:17; 使徒行传 12:20"> 我的臣仆会把木材从黎巴嫩运下到海边；我会把它们扎成木排，经海路运到你指定给我的地方，并在那里解开，你就可以收取。你也要成全我的愿望，把食物供应给我的家。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 于是希兰照所罗门一切所愿，给他香柏木材和柏木材。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 2:10; 列王纪上 4:22"> 所罗门给希兰二万歌珥<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="二万歌珥约为十二万蒲式耳，或约四百二十万升小麦，重量约为三千二百七十公吨。">a</a></sup>小麦，作他家中的食物，又给二十歌珥<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="二十歌珥约为一千一百加仑，或约四千二百二十升。">b</a></sup>纯净的油。所罗门年年这样给希兰。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 3:12; 阿摩司 1:9; 雅各书 1:5"> 耶和华照着祂所应许所罗门的，赐给他智慧。希兰与所罗门之间有和平，他们二人彼此立了约。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王纪上 9:15; 列王纪上 4:6"> 所罗门王从全以色列征召服劳役的人；被征召的有三万人。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 4:6–19; 历代志上 27:1–15"> 他派他们轮班去黎巴嫩，每月一万人：他们一个月在黎巴嫩，两个月在家；亚多尼兰管理这些服劳役的人。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 9:20–22; 历代志下 2:17–18; 历代志下 8:7–9"> 所罗门有七万人扛抬重物，八万人在山中凿石，</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 9:23; 历代志下 2:2"> 此外，还有所罗门监管工程的首领官员三千三百人，管理做工的百姓。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 6:7; 历代志上 22:2; 以赛亚书 28:16"> 王下令，他们就开采大石头、贵重的石头，用琢好的石头奠定殿的根基。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 13:5; 以西结 27:9; 诗篇 83:7"> 所罗门的工匠、希兰的工匠和迦巴勒人都凿好石头，并预备木料和石头，要建造这殿。</span>
</div>
</div>

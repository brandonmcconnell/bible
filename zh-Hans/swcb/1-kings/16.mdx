<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 20:34; 历代志下 19:2; 列王纪上 16:7"> 耶和华的话临到哈拿尼的儿子耶户，责备巴沙说：</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪上 15:34; 列王纪上 14:7; 撒母耳记上 2:8"> “我既从尘土中高举你，立你作我子民以色列的君王，你却行耶罗波安所行的路，使我的子民以色列犯罪，以他们的罪惹我发怒；</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 14:10; 列王纪上 15:29–30; 以赛亚书 66:24"> 看哪，我必把巴沙和他的家彻底扫除；我必使你的家像尼八的儿子耶罗波安的家一样。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 14:11; 列王纪上 21:24"> 属巴沙的人，凡死在城里的，必被狗吃；凡死在田野的，必被天空的飞鸟吃。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪上 14:19; 列王纪上 15:31; 历代志下 16:1–6"> 巴沙其余的事，他所做的和他的勇力，不是都写在《以色列诸王记》上吗？</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 14:17; 列王纪上 15:21; 列王纪上 16:13–14"> 巴沙与他祖先同睡，葬在得撒；他的儿子以拉接续他作王。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王纪上 14:14; 何西阿 1:4; 诗篇 115:4"> 耶和华的话也借哈拿尼的儿子先知耶户临到，责备巴沙和他的家；这是因为他行了耶和华眼中看为恶的一切事，以他手所做的惹耶和华发怒，像耶罗波安的家一样，又因为他击杀了他。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 犹大王亚撒第二十六年，巴沙的儿子以拉在得撒登基作以色列王，作王两年。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 18:3; 创世记 39:4; 但以理 5:1–4"> 他的臣仆心利，就是统管他一半战车的将领，背叛他。当时以拉在得撒，在管理得撒王宫的亚杂家里喝醉了；</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 9:31"> 心利进去击杀他，把他杀死；那是在犹大王亚撒第二十七年。心利接续他作王。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 25:22; 列王纪上 16:3; 列王纪上 15:29"> 心利一登基，刚坐上王位，就攻击巴沙的全家；巴沙的亲属和朋友中，凡靠墙小便的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：男丁">a</a></sup>，他一个也没有留下。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 16:1; 列王纪上 16:7; 历代志下 10:15"> 这样，心利照着耶和华借先知耶户责备巴沙所说的话，灭绝了巴沙的全家。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 32:21; 列王纪上 15:30; 以赛亚书 41:29"> 这是因为巴沙的一切罪，和他儿子以拉的罪；他们自己犯罪，又使以色列犯罪，以他们虚无的偶像惹耶和华——以色列的上帝发怒。</span>
<span className="v" id="v14" data-v="14"> 以拉其余的事，和他所做的一切，不是都写在《以色列诸王记》上吗？</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王纪上 15:27; 约书亚记 19:44; 约伯记 20:5"> 犹大王亚撒第二十七年，心利在得撒作王七天。当时百姓正安营围攻属非利士人的基比顿。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 22:2; 列王纪下 8:26; 弥迦书 6:16"> 安营的百姓听说心利背叛，并且杀了王。因此，以色列众人当天就在营中立军队统帅暗利作以色列王。</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 9:50; 路加福音 19:43–44; 列王纪下 18:9–12"> 暗利从基比顿上去，全以色列也与他同去；他们围困得撒。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 17:23; 撒母耳记上 31:4–5; 约伯记 2:9–10"> 心利见城被攻取，就进了王宫的堡垒，放火焚烧王宫，使自己葬身火中而死。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 15:26; 列王纪上 14:16; 列王纪上 12:28"> 这是因为他所犯的罪：他行耶和华眼中看为恶的事，走耶罗波安所行的路，犯耶罗波安所犯、使以色列犯罪的罪。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 16:14; 列王纪上 16:5; 列王纪上 16:27"> 心利其余的事，和他所行的背叛，不是都写在《以色列诸王记》上吗？</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马太福音 12:25; 以弗所书 4:3–5; 箴言 28:2"> 那时，以色列民分成两派：一半百姓跟随基纳的儿子提比尼，要立他作王；一半跟随暗利。</span>
<span className="v" id="v22" data-v="22"> 但跟随暗利的百姓胜过跟随基纳的儿子提比尼的百姓；于是提比尼死了，暗利就作了王。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 16:8; 列王纪上 16:29; 历代志下 22:2"> 犹大王亚撒第三十一年，暗利登基作以色列王，共作王十二年；他在得撒作王六年。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 13:32; 列王纪上 16:32; 使徒行传 8:5–8"> 他用两他连得<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一他连得约为三十公斤或六十六磅。">b</a></sup>银子向示麦买了撒马利亚山；他在山上建城，照着山的主人示麦的名字，给所建的城起名叫撒马利亚。</span>
<span className="v" id="v25" data-v="25" data-xref="弥迦书 6:16; 列王纪上 16:30–31; 列王纪上 14:9"> 暗利行耶和华眼中看为恶的事，所行的恶超过了在他以前的所有人。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 16:19; 列王纪上 16:13; 列王纪上 12:26–33"> 因为他走尼八的儿子耶罗波安所行的一切道路，犯耶罗波安使以色列犯罪的那些罪，以他们虚无的偶像惹耶和华——以色列的上帝发怒。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 16:20; 列王纪上 16:14; 列王纪上 16:5"> 暗利其余所做的事，和他所显出的勇力，不是都写在《以色列诸王记》上吗？</span>
<span className="v" id="v28" data-v="28"> 暗利与他祖先同睡，葬在撒马利亚；他的儿子亚哈接续他作王。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29"> 犹大王亚撒第三十八年，暗利的儿子亚哈登基作以色列王。暗利的儿子亚哈在撒马利亚作以色列王二十二年。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 16:25; 列王纪上 21:25; 列王纪上 14:9"> 暗利的儿子亚哈行耶和华眼中看为恶的事，超过了在他以前的所有人。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪下 17:16; 列王纪下 10:18; 士师记 18:7"> 他走尼八的儿子耶罗波安所犯的罪路，好像还算为小事；他又娶西顿人王谒巴力的女儿耶洗别为妻，去事奉巴力，敬拜他。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪下 10:21; 列王纪下 10:26–27"> 他在撒马利亚所建的巴力庙里，为巴力筑了一座坛。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪下 13:6; 列王纪上 21:25; 列王纪下 21:3"> 亚哈又造了亚舍拉神像；亚哈所做的，惹耶和华——以色列的上帝发怒，比在他以前的以色列诸王更甚。</span>
<span className="v" id="v34" data-v="34" data-xref="约书亚记 6:26; 约书亚记 23:14–15; 马太福音 24:35"> 在亚哈的日子，伯特利人希伊勒重建耶利哥。他立根基的时候，丧失了长子亚比兰；安置城门的时候，丧失了幼子西割；这正应验了耶和华借嫩的儿子约书亚所说的话。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 52:4–11; 历代志上 6:15; 耶利米书 34:1–6"> 他作王第九年十月初十日，巴比伦王尼布甲尼撒率领他的全军来攻打耶路撒冷，对着城安营，并在四围筑垒攻城。</span>
<span className="v" id="v2" data-v="2"> 于是城被围困，直到西底家王第十一年。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 52:6; 以西结 5:12; 耶利米书 38:2"> 四月初九日，城里饥荒严重，以致那地的百姓没有粮食。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结 33:21; 列王纪下 25:5; 耶利米书 39:2–7"> 城被攻破，所有战士就在夜间从靠近王园、两道城墙之间的门路逃跑；那时迦勒底人正四围围城；王就往亚拉巴的路去了。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 30:16; 耶利米书 39:5; 阿摩司 2:14–16"> 迦勒底的军队追赶王，在耶利哥的平原追上了他；他的全军都离散了。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 23:33; 耶利米书 34:21–22; 耶利米书 21:7"> 他们捉住王，把他带到利比拉巴比伦王那里；他们就对他宣判。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 32:4–5; 士师记 16:21; 耶利米书 39:6–7"> 他们在西底家眼前杀了他的众子，然后剜出西底家的眼睛，用铜链锁住他，把他带到巴比伦去。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="耶利米书 52:12–16; 耶利米书 40:1–4; 耶利米哀歌 4:12"> 巴比伦王尼布甲尼撒作王第十九年五月初七日，巴比伦王的臣仆、护卫长尼布撒拉旦来到耶路撒冷。</span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司 2:5; 诗篇 74:3–7; 列王纪上 9:8"> 他焚烧了耶和华的殿、王宫和耶路撒冷的一切房屋；所有显贵的房屋，他都用火焚烧。</span>
<span className="v" id="v10" data-v="10" data-xref="尼希米记 1:3; 耶利米书 39:8; 耶利米书 52:14–23"> 跟随护卫长的迦勒底全军拆毁了耶路撒冷四围的城墙。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结 5:2; 耶利米书 15:1–2; 耶利米书 39:9"> 城里剩下的百姓、投降巴比伦王的人，以及其余的民众，护卫长尼布撒拉旦都掳走了。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 40:7; 列王纪下 24:14; 以西结 33:24"> 但护卫长留下那地最贫穷的一些人，叫他们修理葡萄园、耕种田地。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志下 36:18; 耶利米哀歌 1:10; 列王纪下 20:17"> 迦勒底人打碎耶和华殿里的铜柱、盆座和耶和华殿里的铜海，把铜运到巴比伦去。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 27:3; 列王纪上 7:47–50; 出埃及记 38:3"> 他们又拿走锅、铲子、灯剪、调羹，以及他们用来供职的一切铜器。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理 5:2–3; 民数记 7:13–14; 列王纪上 7:48–51"> 护卫长拿走火盘和碗；凡属金的按金，凡属银的按银，都拿走了。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 7:47"> 所罗门为耶和华殿所造的两根柱子、一个铜海和盆座，这一切器物的铜都没有称重量。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 7:15–22; 耶利米书 52:21–23"> 一根柱子高十八肘，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘是人手臂从中指尖到肘部的长度，约18英寸或46厘米。">a</a></sup>上面有铜柱顶；柱顶高三肘，柱顶四围有网子和石榴，全都是铜的；第二根柱子和它的网子也是这样。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米书 29:25; 以斯拉记 7:1; 耶利米书 21:1"> 护卫长拿住大祭司西莱雅、副祭司西番雅和三个守门的；</span>
<span className="v" id="v19" data-v="19" data-xref="以斯帖记 1:14"> 又从城里拿住一个管理战士的官员，以及在城中找到的、常见王面的五个人；又拿住书记官，就是招募那地百姓的军长，以及在城中找到的那地百姓六十个人。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米哀歌 4:16; 耶利米书 52:26–27; 列王纪下 23:33"> 护卫长尼布撒拉旦拿住他们，带到利比拉巴比伦王那里。</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 28:64; 列王纪下 23:27; 申命记 4:26"> 巴比伦王在哈马地的利比拉击杀他们，把他们处死。这样，犹大被掳离开了本地。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="耶利米书 39:14; 列王纪下 22:12; 耶利米书 41:2"> 至于留在犹大地、巴比伦王尼布甲尼撒所留下的百姓，他立沙番的孙子、亚希甘的儿子基大利作省长管理他们。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 40:7–9; 耶利米书 40:11–12; 约书亚记 18:26"> 众军长和他们的人听见巴比伦王立了基大利作省长，就来到米斯巴见基大利；他们是尼探雅的儿子以实玛利、加利亚的儿子约哈难、尼陀法人他户篾的儿子西莱雅、玛迦人的儿子雅撒尼亚，以及他们的人。</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 40:9–10; 耶利米书 43:6; 撒母耳记下 19:23"> 基大利向他们和他们的人起誓，对他们说：“不要因迦勒底人的臣仆而害怕。住在这地，服事巴比伦王，你们就必平安。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒迦利亚书 7:5; 撒迦利亚书 8:19; 耶利米书 40:15"> 但到了七月，王室后裔以利沙玛的孙子、尼探雅的儿子以实玛利，带着十个人前来，击杀基大利，使他死了，也杀了在米斯巴与他在一起的犹大人和迦勒底人。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 43:4–7; 耶利米书 41:16–18; 耶利米书 42:14–22"> 于是众百姓，无论大小，和众军长都起身来到埃及，因为他们惧怕迦勒底人。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 52:31–34; 创世记 40:20; 创世记 40:13"> 犹大王约雅斤被掳第三十七年十二月二十七日，巴比伦王以未米罗达登基那一年，把犹大王约雅斤从监狱中释放出来，</span>
<span className="v" id="v28" data-v="28" data-xref="但以理 2:37; 耶利米书 27:6–11; 但以理 5:18–19"> 亲切地对他说话，并使他的座位高过在巴比伦与他同在众王的座位；</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 9:7; 以赛亚书 61:3; 创世记 41:42"> 约雅斤脱去囚衣。他一生的日子，常在王面前吃饭；</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 11:3; 马太福音 6:11; 尼希米记 11:23"> 至于他的供给，王不断赐给他固定的供给，每日一份，直到他一生的日子。</span>
</div>

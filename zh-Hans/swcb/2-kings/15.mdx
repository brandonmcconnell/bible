<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 26:3–4; 列王纪下 14:21; 历代志下 26:1"> 以色列王耶罗波安第二十七年，犹大王亚玛谢的儿子亚撒利雅登基。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 26:3–4"> 他登基的时候十六岁，在耶路撒冷作王五十二年。他母亲名叫耶可利雅，是耶路撒冷人。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 14:3–4; 列王纪下 12:2–3; 历代志下 26:4"> 亚撒利雅行耶和华眼中看为正的事，照他父亲亚玛谢所行的一切。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 15:35; 列王纪下 14:4; 列王纪下 12:3"> 然而，丘坛还没有废去，百姓仍在丘坛献祭、烧香。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 13:46; 民数记 12:14; 列王纪下 7:3"> 耶和华击打王，使他患麻风病，直到死日；他住在隔离的房子里。王的儿子约坦管理王宫，治理那地的百姓。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 26:5–15; 列王纪下 14:18"> 亚撒利雅其余的事，以及他所行的一切，不都写在《犹大列王记》上吗？</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 26:23; 以赛亚书 6:1"> 亚撒利雅与他列祖同睡，人把他和他列祖一同葬在大卫城；他的儿子约坦接续他作王。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪下 14:16–17; 列王纪下 14:29–1; 列王纪下 14:21"> 犹大王亚撒利雅第三十八年，耶罗波安的儿子撒迦利雅在撒玛利亚作以色列王六个月。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 14:24; 列王纪下 13:2; 列王纪下 13:11"> 他行耶和华眼中看为恶的事，像他列祖所行的一样；他没有离开尼八的儿子耶罗波安使以色列陷入的那些罪。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 15:28; 列王纪下 15:14; 列王纪下 9:24"> 雅比的儿子沙龙背叛他，在百姓面前击杀他，杀死了他，并接续他作王。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 14:28"> 撒迦利雅其余的事，看哪，都写在《以色列列王记》上。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 10:30; 马可福音 13:31; 列王纪下 13:13"> 这就是耶和华对耶户所说的话，说：“你的子孙必坐在以色列的王位上，直到第四代。”这事果然应验了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王纪下 15:1; 马太福音 1:8–9; 列王纪下 15:8"> 犹大王乌西雅第三十九年，雅比的儿子沙龙登基，在撒玛利亚作王一个月。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 14:17; 列王纪上 16:17; 列王纪上 16:15"> 迦底的儿子米拿现从得撒上来，到了撒玛利亚，在撒玛利亚击杀雅比的儿子沙龙，杀死了他，并接续他作王。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 14:19; 列王纪上 14:29; 列王纪下 15:11"> 沙龙其余的事，以及他所发动的叛乱，看哪，都写在《以色列列王记》上。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪下 8:12; 列王纪上 4:24; 何西阿 13:16"> 那时，米拿现从得撒出发，攻打提斐萨和其中所有的人，以及它的四境；因为他们没有给他开城门，他就攻打那城，并剖开其中所有怀孕的妇女。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 犹大王亚撒利雅第三十九年，迦底的儿子米拿现登基，在撒玛利亚作以色列王十年。</span>
<span className="v" id="v18" data-v="18"> 他行耶和华眼中看为恶的事；他一生没有离开尼八的儿子耶罗波安使以色列陷入的那些罪。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 14:5; 历代志上 5:25–26; 列王纪下 18:16"> 亚述王普勒来攻打那地，米拿现就给普勒一千他连得<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一他连得约为三十公斤或六十六磅，所以一千他连得约为三十公吨。">a</a></sup>银子，为要使普勒的手支持他，巩固他手中的国位。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 18:14–17; 列王纪下 23:35; 列王纪下 17:3–4"> 米拿现向以色列人征收这笔银子，就是向所有有财富的勇士征收，每人五十舍客勒<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一舍客勒约为十克或约0.35盎司，所以五十舍客勒约为0.5公斤或1.1磅。">b</a></sup>银子，好给亚述王。于是亚述王转回去，没有停留在那地。</span>
<span className="v" id="v21" data-v="21"> 米拿现其余的事，以及他所行的一切，不都写在《以色列列王记》上吗？</span>
<span className="v" id="v22" data-v="22"> 米拿现与他列祖同睡，他的儿子比加辖接续他作王。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪上 15:25; 列王纪上 22:51; 约伯记 20:5"> 犹大王亚撒利雅第五十年，米拿现的儿子比加辖登基，在撒玛利亚作以色列王两年。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪下 15:9; 列王纪下 15:18"> 他行耶和华眼中看为恶的事；他没有离开尼八的儿子耶罗波安使以色列陷入的那些罪。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 28:6; 列王纪下 9:14; 列王纪上 16:9"> 他的将领、利玛利的儿子比加背叛他，在撒玛利亚王宫的堡垒里，与亚珥歌伯和亚利耶一同攻击他；比加身边有五十个基列人。他杀了比加辖，并接续他作王。</span>
<span className="v" id="v26" data-v="26"> 比加辖其余的事，以及他所行的一切，看哪，都写在《以色列列王记》上。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 7:4; 以赛亚书 7:1; 列王纪下 15:23"> 犹大王亚撒利雅第五十二年，利玛利的儿子比加登基，在撒玛利亚作以色列王二十年。</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪下 15:18; 列王纪下 13:6; 列王纪下 15:9"> 他行耶和华眼中看为恶的事；他没有离开尼八的儿子耶罗波安使以色列陷入的那些罪。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 5:26; 列王纪下 17:6; 列王纪下 16:7"> 以色列王比加在位的日子，亚述王提革拉·毗列色来攻取以云、亚伯·伯·玛迦、雅挪亚、基低斯、夏琐、基列、加利利，以及拿弗他利全地；他把这些地方的人掳到亚述去。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 17:1; 历代志下 28:4–6; 列王纪下 16:1"> 乌西雅的儿子约坦第二十年，以拉的儿子何细亚背叛利玛利的儿子比加，攻击他，杀死了他，并接续他作王。</span>
<span className="v" id="v31" data-v="31"> 比加其余的事，以及他所行的一切，看哪，都写在《以色列列王记》上。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="历代志上 3:12; 列王纪下 15:7; 历代志下 27:1–9"> 以色列王利玛利的儿子比加第二年，犹大王乌西雅的儿子约坦登基。</span>
<span className="v" id="v33" data-v="33" data-xref="历代志下 27:1"> 他登基的时候二十五岁，在耶路撒冷作王十六年。他母亲名叫耶路莎，是撒督的女儿。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志下 26:4–5; 列王纪下 15:3–4; 历代志下 27:2"> 约坦行耶和华眼中看为正的事；他照他父亲乌西雅所行的一切而行。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪下 12:3; 历代志下 23:20; 历代志下 27:3–9"> 然而，丘坛还没有废去，百姓仍在丘坛献祭、烧香。他建造了耶和华殿的上门。</span>
<span className="v" id="v36" data-v="36" data-xref="历代志下 27:4–9; 列王纪下 15:6–7"> 约坦其余的事，以及他所行的一切，不都写在《犹大列王记》上吗？</span>
<span className="v" id="v37" data-v="37" data-xref="列王纪下 16:5; 以赛亚书 7:1; 路加福音 21:28"> 在那些日子，耶和华开始差遣亚兰王利汛和利玛利的儿子比加来攻击犹大。</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪上 14:20; 列王纪上 14:31; 列王纪下 16:1"> 约坦与他列祖同睡，和他列祖一同葬在他祖大卫的城里；他的儿子亚哈斯接续他作王。</span>
</div>
</div>

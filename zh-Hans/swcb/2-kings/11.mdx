<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 41:1; 列王纪下 25:25; 历代志下 22:10–12"> 亚哈谢的母亲亚他利雅见她儿子死了，就起来除灭王室所有的后裔。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 33:26; 耶利米书 35:2; 以赛亚书 7:6–7"> 但约兰王的女儿、亚哈谢的妹妹约示巴，把亚哈谢的儿子约阿施从那些被杀的王子中偷偷带走，连他和他的乳母一起安置在卧房里；她们把他藏起来，避开亚他利雅，使他没有被杀。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 12:8; 历代志下 22:12; 玛拉基书 3:15"> 他同她一起藏在耶和华殿里六年；亚他利雅统治那地。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 11:19; 列王纪下 11:9; 列王纪下 11:17"> 第七年，耶何耶大派人召来迦利人和护卫兵的百夫长，把他们带到耶和华殿里，到他那里；他与他们立约，并在耶和华殿里与他们立约，又把王的儿子指给他们看。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 9:25; 以西结 44:2–3; 历代志上 23:32"> 他吩咐他们说：“你们要这样做：凡在安息日进班的，你们三分之一要守卫王宫；</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 23:4–5; 历代志上 26:13–19"> 三分之一要在苏珥门；三分之一要在护卫兵后面的门。这样，你们要守卫这殿，作为屏障。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 23:6; 列王纪下 11:5"> 你们另外两队，就是所有在安息日出班的人，要在王周围守卫耶和华殿。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 27:17; 历代志下 23:7; 列王纪上 2:28–31"> 你们要围绕在王四周，各人手持兵器；凡闯入队列以内的，必被杀死。王出入的时候，你们都要与王同在。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="历代志下 23:8; 列王纪下 11:4; 历代志上 26:26"> 百夫长们照祭司耶何耶大所吩咐的一切去做；他们各自带着自己的人，就是安息日进班的和安息日出班的，来到祭司耶何耶大那里。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 8:7; 历代志上 18:7; 历代志下 5:1"> 祭司把耶和华殿里大卫王的枪和盾牌交给百夫长们。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 11:8; 以西结 8:16; 列王纪下 11:10"> 护卫兵各人手持兵器站立，从殿的右侧直到殿的左侧，沿着祭坛和殿，在王的四周。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 25:16; 撒母耳记上 10:24; 列王纪上 1:39"> 然后他领出王的儿子，把王冠戴在他头上，又把约交给他；他们立他作王，膏了他；他们拍掌说：“愿王万岁！”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志下 23:12–15"> 亚他利雅听见护卫兵和百姓的声音，就来到耶和华殿，到百姓那里；</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 34:31; 列王纪下 23:3; 列王纪下 9:23"> 她观看，看哪，王照惯例站在柱旁，百夫长和吹号的人在王旁边；那地所有百姓都欢喜，并且吹号。亚他利雅就撕裂自己的衣服，喊叫说：“谋反！谋反！”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西结 9:7; 历代志下 23:14; 历代志下 23:9"> 祭司耶何耶大吩咐那些统率军队的百夫长，对他们说：“把她从队伍中间带出去。凡跟随她的人，都要用刀杀死。”因为祭司说：“不可让她在耶和华殿里被杀。”</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 9:6; 历代志下 23:15; 马太福音 7:2"> 他们就抓住她；她经由马匹进入王宫的通道去，就在那里被杀。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 5:3; 历代志下 15:12–14; 历代志下 34:31"> 耶何耶大在耶和华与王和百姓之间立约，使他们作耶和华的子民；又在王与百姓之间立约。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 12:3; 列王纪下 10:26; 列王纪上 18:40"> 那地所有百姓都到巴力的殿，把它拆毁；他们把巴力的祭坛和偶像彻底打碎，又在祭坛前杀了巴力的祭司玛坦。祭司派官员管理耶和华殿。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 17:25; 耶利米书 22:4; 历代志下 23:19"> 他带着百夫长、迦利人、护卫兵和那地所有百姓；他们领王从耶和华殿下来，经由护卫兵门来到王宫。王坐在众王的宝座上。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 11:10; 箴言 29:2; 列王纪下 11:14"> 于是那地所有百姓都欢喜，城也平静了。亚他利雅已在王宫被刀杀死。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="历代志下 24:1–14; 列王纪下 22:1; 列王纪下 11:4"> 约阿施登基的时候年七岁。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 15:39; 历代志下 34:1–33; 耶利米书 1:2"> 约西亚登基的时候年八岁，在耶路撒冷作王三十一年。他母亲名叫耶底大，是波斯加人亚大雅的女儿。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 5:32; 约书亚记 1:7; 列王纪下 18:3"> 他行耶和华眼中看为正的事，行他祖大卫一切的道路，不偏左右。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="历代志下 34:3–33"> 约西亚王十八年，王差遣米书兰的孙子、亚萨利雅的儿子书记沙番到耶和华的殿去，说：</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 12:4; 马可福音 12:41–42; 历代志下 34:9–18"> “你上去见大祭司希勒家，叫他清点送入耶和华殿的银子，就是守门的人从百姓收来的。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 12:11–14; 列王纪下 12:5; 历代志下 24:12–13"> 让他们把银子交在督管耶和华殿工程的人手里；叫这些人把银子给耶和华殿里做工的人，用来修理殿的破损，</span>
<span className="v" id="v6" data-v="6"> 就是给木匠、建筑工和石匠，并购买木料和凿成的石头来修理殿。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 12:15; 哥林多前书 4:2; 尼希米记 7:2"> 不过，交在他们手里的银子不必向他们查账，因为他们办事忠诚。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="申命记 31:24–26; 历代志下 34:14–28"> 大祭司希勒家对书记沙番说：“我在耶和华的殿里发现了律法书。”希勒家把书交给沙番，沙番就读了。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 8:11; 列王纪下 25:22; 列王纪下 18:18"> 书记沙番来到王那里，向王回报说：“你的仆人已经把殿里找到的银子倒出来，交在督管耶和华殿工程的人手里了。”</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 36:21; 耶利米书 13:18; 申命记 17:18–20"> 书记沙番又告诉王说：“希勒家祭司交给我一本书。”于是沙番在王面前读那书。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="历代志下 34:19; 约珥 2:13; 列王纪下 22:19"> 王听见律法书上的话，就撕裂衣服。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 26:24; 列王纪下 25:22; 列王纪下 19:2–3"> 王吩咐希勒家祭司、沙番的儿子亚希甘、米该亚的儿子亚革波、书记沙番和王的臣仆亚撒雅，说：</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 29:23–28; 申命记 31:17–18; 耶利米书 37:17"> “你们去为我、为百姓、为全犹大，就这本所发现的书上的话求问耶和华；因为耶和华向我们所发的烈怒极大，是因我们的祖先没有听从这书上的话，没有照着一切指着我们所写的去行。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="士师记 4:4; 历代志下 34:22; 弥迦书 6:4"> 于是希勒家祭司、亚希甘、亚革波、沙番和亚撒雅去见女先知户勒大；她是掌管衣库的沙龙的妻子，沙龙是提克瓦的儿子，提克瓦是哈哈斯的儿子。（那时户勒大住在耶路撒冷第二区。）他们与她谈话。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 1:6; 列王纪下 1:16; 耶利米书 23:28"> 她对他们说：“耶和华以色列的上帝这样说：‘你们要告诉那差遣你们来见我的人：</span>
<span className="v" id="v16" data-v="16" data-xref="但以理 9:11–14; 约书亚记 23:15; 申命记 29:27"> “耶和华这样说：‘看哪，我必使灾祸临到这地方和这里的居民，就是犹大王所读那书上的一切话。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 21:22; 耶利米书 7:20; 申命记 29:24–28"> 因为他们离弃我，向别的神烧香，用他们手所做的一切惹我发怒；所以我的烈怒必向这地方发作，不能熄灭。’”</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 34:26–28; 玛拉基书 3:16–17; 以赛亚书 3:10"> 至于那差遣你们来求问耶和华的犹大王，你们要这样告诉他：“耶和华以色列的上帝这样说：‘论到你所听见的话，</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 51:17; 列王纪上 21:29; 以赛亚书 57:15"> 因为你听见我指着这地方和这里居民所说的话，就是他们必成为荒凉和咒诅的时候，你心里柔软，在耶和华面前自卑，又撕裂衣服，在我面前哭泣，所以我也听见了你。’这是耶和华说的。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 37:37; 以赛亚书 57:1–2; 历代志上 17:11"> ‘因此，看哪，我必使你归到你祖先那里；你必平平安安地归入你的坟墓。我要降在这地方的一切灾祸，你的眼睛必不看见。’”’”于是他们把这话带回去给王。</span>
</div>

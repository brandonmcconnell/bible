<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 13:10; 历代志下 25:1–4; 列王纪下 14:15"> 以色列王约哈斯的儿子约阿施第二年，犹大王约阿施的儿子亚玛谢开始作王。</span>
<span className="v" id="v2" data-v="2"> 他开始作王的时候二十五岁，在耶路撒冷作王二十九年。他母亲名叫约耶但，是耶路撒冷人。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 25:2–3; 撒迦利亚书 1:4–6; 列王纪上 11:4"> 他行耶和华眼中看为正的事，只是不像他祖大卫；他照他父亲约阿施一切所行的去行。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 12:3; 列王纪下 16:4; 列王纪下 15:35"> 然而，邱坛还没有废去；百姓仍在邱坛献祭、焚香。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 25:3–4; 列王纪下 12:20–21; 民数记 35:33"> 国位一在他手中稳固，他就杀了那些弑杀他父王的臣仆；</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 24:16; 以西结 18:20; 以西结 18:4"> 但那些凶手的儿女，他没有处死；这是照摩西律法书上所写的，正如耶和华所命令说：“父亲不可因儿女被处死，儿女也不可因父亲被处死；各人要因自己的罪而死。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 8:13; 历代志上 18:12; 约书亚记 15:38"> 亚玛谢在盐谷杀了一万以东人，又在战争中攻取西拉，给它起名叫约帖，直到今日。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 25:17–24; 撒母耳记下 2:14–17; 列王纪下 14:11"> 那时，亚玛谢派使者到以色列王、耶户的孙子、约哈斯的儿子约阿施那里，说：“来吧，让我们彼此当面相见。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="士师记 9:8–15; 列王纪上 4:33; 历代志下 33:11"> 以色列王约阿施派人到犹大王亚玛谢那里，说：“黎巴嫩的一棵蒺藜派人去对黎巴嫩的一棵香柏树说：‘把你的女儿给我的儿子为妻。’后来，黎巴嫩的一只野兽经过，把那棵蒺藜踩倒了。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 26:16; 申命记 8:14; 历代志下 32:25"> 你的确击败了以东，你的心就高傲起来。你以此为荣耀，安居在家吧；你为什么要招惹祸患，使自己倾覆，连你和犹大也一同倾覆呢？”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约书亚记 19:38; 历代志下 25:16; 约书亚记 15:10"> 但亚玛谢不肯听。于是以色列王约阿施上来，他和犹大王亚玛谢在属犹大的伯示麦彼此当面相见。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记下 18:17; 撒母耳记上 4:10; 列王纪上 22:36"> 犹大败在以色列面前，各人都逃回自己的帐棚。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 8:16; 尼希米记 12:39; 撒迦利亚书 14:10"> 以色列王约阿施在伯示麦擒住犹大王亚玛谢，就是亚哈谢的孙子、约阿施的儿子；他来到耶路撒冷，拆毁耶路撒冷的城墙，从以法莲门直到角门，共四百肘。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘是人手臂从中指尖到肘部的长度，约为18英寸或46厘米。">a</a></sup></span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 14:26; 列王纪上 7:51; 列王纪上 15:18"> 他拿走耶和华殿里和王宫府库里所找到的一切金银和一切器皿，又带走人质，然后回撒马利亚去了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王纪下 13:12–13; 列王纪上 14:19–20; 列王纪下 10:34–35"> 约阿施其余所行的事和他的勇力，以及他怎样与犹大王亚玛谢交战，岂不都写在《以色列诸王记》上吗？</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 13:9; 列王纪下 13:13; 列王纪上 1:21"> 约阿施与他列祖同睡，葬在撒马利亚，与以色列诸王同葬；他的儿子耶罗波安接续他作王。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="历代志下 25:25–28; 列王纪下 13:10; 列王纪下 14:23"> 以色列王约哈斯的儿子约阿施死后，犹大王约阿施的儿子亚玛谢又活了十五年。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 11:41; 列王纪上 14:29; 列王纪下 13:8"> 亚玛谢其余所行的事，岂不都写在《犹大诸王记》上吗？</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 10:31; 列王纪下 15:25; 列王纪下 12:20–21"> 有人在耶路撒冷背叛他，密谋害他，他就逃到拉吉；但他们派人追到拉吉，在那里杀了他。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 9:28; 列王纪下 12:21; 历代志下 33:20"> 他们用马把他运回，他就葬在耶路撒冷，与他列祖同葬在大卫城。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王纪下 21:24; 马太福音 1:8–9; 列王纪下 15:13"> 犹大众民立亚撒利雅接续他父亲亚玛谢作王；那时他十六岁。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 16:6; 列王纪上 9:26; 申命记 2:8"> 他修建以拉他，使它归回犹大。此后，王与他列祖同睡。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="何西阿 1:1; 阿摩司 7:9–11; 阿摩司 1:1"> 犹大王约阿施的儿子亚玛谢第十五年，以色列王约阿施的儿子耶罗波安开始在撒马利亚作王，作王四十一年。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪下 13:6; 列王纪下 13:11; 创世记 38:7"> 他行耶和华眼中看为恶的事；他没有离开尼八的儿子耶罗波安使以色列陷入的一切罪。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 3:17; 马太福音 12:39–40; 约书亚记 19:13"> 他恢复了以色列的边界，从哈马口直到亚拉巴海，正如耶和华——以色列的上帝——借祂仆人、迦特希弗人亚米太的儿子、先知约拿所说的话。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 32:36; 出埃及记 3:7; 列王纪下 13:4"> 因为耶和华看见以色列所受的苦难，无论为奴的还是自由的，都极其痛苦；而且没有人帮助以色列。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 13:23; 列王纪下 13:5; 罗马书 11:2–12"> 耶和华并没有说要从天下涂抹以色列的名；祂却借约阿施的儿子耶罗波安的手拯救他们。</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪上 11:24; 历代志上 18:5–6; 撒母耳记下 8:6"> 耶罗波安其余所行的事，他一切所行的，以及他的勇力，他怎样争战，又怎样为以色列收复大马士革和曾属于犹大的哈马，岂不都写在《以色列诸王记》上吗？</span>
<span className="v" id="v29" data-v="29" data-xref="列王纪下 15:8"> 耶罗波安与他列祖，就是与以色列诸王同睡；他的儿子撒迦利雅接续他作王。</span>
</div>

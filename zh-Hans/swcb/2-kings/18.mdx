<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 28:27–1; 马太福音 1:9–10; 历代志上 3:13"> 以色列王以拉的儿子何细亚第三年，犹大王亚哈斯的儿子希西家开始作王。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 29:1–2"> 他开始作王的时候二十五岁，在耶路撒冷作王二十九年。他母亲名叫亚比，是撒迦利雅的女儿。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 20:3; 列王纪上 11:4; 历代志下 31:20–21"> 希西家行耶和华眼中看为正的事，照他祖先大卫所行的一切。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 31:1; 民数记 21:8–9; 列王纪下 18:22"> 他除去丘坛，打碎柱像，砍下亚舍拉木柱；又把摩西所造的铜蛇打成碎片，因为到那些日子，以色列人还向它烧香；他称它为尼忽士但。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 23:25; 列王纪下 19:10; 马太福音 27:43"> 希西家倚靠耶和华——以色列的上帝；在他以后，犹大诸王中没有一个像他的，在他以前的诸王中也没有。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 23:8; 申命记 10:20; 约翰福音 14:15"> 因为他紧紧跟随耶和华，不离开祂，并且遵守耶和华吩咐摩西的诫命。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:31; 创世记 39:2–3; 列王纪下 16:7"> 耶和华与他同在；他无论往哪里去，都亨通。他背叛亚述王，不再服事他。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 14:29; 列王纪下 17:9; 历代志下 28:18"> 希西家击败非利士人，直到迦萨和它的边界，从守望楼直到坚固城。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="何西阿 10:14; 列王纪下 17:3–23; 列王纪下 18:1"> 希西家王第四年，就是以色列王以拉的儿子何细亚第七年，亚述王撒缦以色上来攻打撒玛利亚，围困了它。</span>
<span className="v" id="v10" data-v="10" data-xref="阿摩司 6:7; 阿摩司 9:1–4; 弥迦书 1:6–9"> 过了三年，他们攻取了城。希西家第六年，就是以色列王何细亚第九年，撒玛利亚被攻取。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 5:26; 列王纪下 17:6; 以赛亚书 37:12"> 亚述王把以色列人掳到亚述，安置在哈腊、歌散河边的哈博，以及玛代人的城邑里，</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 4:17; 彼得前书 2:8; 弥迦书 3:4"> 因为他们不听从耶和华他们上帝的声音，反而违背祂的约，就是耶和华的仆人摩西所吩咐的一切；他们不肯听，也不肯行。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 36:1–22; 历代志下 32:1–23; 以赛亚书 7:17–25"> 希西家王第十四年，亚述王西拿基立上来攻打犹大所有的坚固城，并且攻取了。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 18:7; 路加福音 14:32; 列王纪上 20:4"> 犹大王希西家差人到拉吉去见亚述王，说：“我得罪了你。请你离开我；你加在我身上的，我都愿承担。”亚述王向犹大王希西家索要三百他连得银子和三十他连得<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一他连得约为30公斤，或66磅，或965金衡盎司。">a</a></sup>金子。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 16:8; 列王纪上 15:18–19; 列王纪下 12:18"> 希西家把耶和华殿里和王宫宝库里所有的银子都给了他。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 29:3; 列王纪上 6:31–35"> 那时，犹大王希西家把耶和华殿门上的金子和他自己包在柱子上的金子都刮下来，给了亚述王。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 20:1; 列王纪下 20:20; 以赛亚书 7:3"> 亚述王从拉吉差遣他珥探、拉伯撒利和拉伯沙基，率领大军到耶路撒冷，去见希西家王。他们上去，来到耶路撒冷；他们上来以后，就站在上池的水道旁，就是通往漂布地的大路上。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 19:2; 以赛亚书 36:3; 撒母耳记下 8:16–17"> 他们呼叫王的时候，管理王宫的希勒家的儿子以利亚敬、书记舍伯那和亚萨的儿子史官约亚出来见他们。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 36:4; 列王纪下 19:10; 以赛亚书 10:8–14"> 拉伯沙基对他们说：“现在你们要对希西家说：‘大王，亚述王这样说：“你所倚靠的这信心是什么呢？</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 21:30–31"> 你说（不过是空话）：‘我有作战的谋略和力量。’现在你倚靠谁，竟背叛我呢？</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 30:7; 以西结 29:6–7; 以赛亚书 30:2–3"> 看哪，你所倚靠的，是埃及这根压伤的芦苇杖；人若靠在上面，它就会刺进他的手，把手扎透。埃及王法老对一切倚靠他的人就是这样。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 31:1; 列王纪下 18:4–5; 马太福音 27:43"> 但如果你们对我说：‘我们倚靠耶和华我们的上帝。’希西家不是已经除去祂的丘坛和祭坛，并且对犹大和耶路撒冷说：‘你们要在耶路撒冷这座祭坛前敬拜’吗？</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 17:42; 列王纪上 20:10; 尼希米记 4:2–5"> 现在，请你和我主亚述王打赌吧；如果你那边能派出骑兵骑马，我就给你两千匹马。</span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 10:8; 申命记 17:16; 以赛亚书 36:6"> 既然这样，你怎能击退我主臣仆中最小的一个军长呢？你竟倚靠埃及，要战车和骑兵吗？</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 19:6; 以赛亚书 10:5–6; 列王纪下 19:22–37"> 现在，我上来攻打毁灭这地方，难道没有耶和华的意思吗？耶和华对我说：‘上去攻打这地，毁灭它。’”’”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以斯拉记 4:7; 但以理 2:4; 以赛亚书 36:11–12"> 希勒家的儿子以利亚敬、舍伯那和约亚对拉伯沙基说：“请你用亚兰语对你的仆人说话，因为我们听得懂；不要在城墙上百姓听得见的地方，用犹大语同我们说话。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="诗篇 73:8; 耶利米哀歌 4:5; 以西结 4:15"> 但拉伯沙基对他们说：“我主差我来，难道只是对你的主和你说这些话吗？不也是对这些坐在城墙上的人说吗？他们要和你们一起吃自己的粪，喝自己的尿。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 36:13–18; 以赛亚书 10:8–13; 以西结 29:3"> 于是拉伯沙基站着，用犹大语大声呼喊，说：“你们要听大王，亚述王的话！</span>
<span className="v" id="v29" data-v="29" data-xref="历代志下 32:15; 帖撒罗尼迦后书 2:8; 历代志下 32:11"> 王这样说：‘不要让希西家欺骗你们，因为他不能救你们脱离他的手。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 125:1–2; 路加福音 23:35; 列王纪下 19:32–34"> 也不要让希西家使你们倚靠耶和华，说：“耶和华必定拯救我们，这城必不交在亚述王手中。”</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪上 4:25; 列王纪上 4:20; 撒迦利亚书 3:10"> 不要听希西家的话。’因为亚述王这样说：‘你们要与我讲和，出来归顺我；这样，你们各人就可以吃自己葡萄树上的果子，各人吃自己无花果树上的果子，各人喝自己水池里的水；</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 8:7–9; 出埃及记 3:8; 申命记 11:12"> 直到我来，把你们带到一个像你们本地一样的地方，那里有五谷和新酒，有粮食和葡萄园，有橄榄树和蜂蜜，使你们可以存活，不至死亡。不要听希西家的话，因为他劝诱你们说：“耶和华必拯救我们。”</span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 10:10–11; 列王纪下 19:12–13; 历代志下 32:19"> 列国的神明有哪一个曾救自己的地脱离亚述王的手呢？</span>
<span className="v" id="v34" data-v="34" data-xref="以赛亚书 10:9; 列王纪下 17:23–33; 耶利米书 49:23"> 哈马和亚珥拔的神明在哪里？西法瓦音、希拿、以瓦的神明在哪里？他们救了撒玛利亚脱离我的手吗？</span>
<span className="v" id="v35" data-v="35" data-xref="但以理 3:15; 以赛亚书 10:15; 出埃及记 5:2"> 这些列国的所有神明中，有谁救自己的国家脱离我的手，使耶和华能救耶路撒冷脱离我的手呢？’”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="阿摩司 5:13; 箴言 9:7; 马太福音 7:6"> 百姓却静默不言，一句话也不回答他；因为王的命令是：“不要回答他。”</span>
<span className="v" id="v37" data-v="37" data-xref="列王纪下 22:11; 创世记 37:29; 列王纪下 5:7"> 于是管理王宫的希勒家的儿子以利亚敬、书记舍伯那和亚萨的儿子史官约亚都撕裂衣服，来到希西家那里，把拉伯沙基的话告诉了他。</span>
</div>
</div>

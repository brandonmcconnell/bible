<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 10:1; 列王纪下 4:29; 列王纪上 1:39"> 先知以利沙叫了一个先知门徒来，对他说：“你要束上腰，手里拿着这瓶油，往基列的拉末去。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 9:5; 列王纪上 19:16–17; 列王纪下 9:11"> 你到了那里，要寻找宁示的孙子、约沙法的儿子耶户；进去，使他从他的弟兄中起来，带他进内室。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 19:16; 出埃及记 29:7; 撒母耳记上 16:2"> 然后拿这瓶油，倒在他头上，说：‘耶和华这样说：“我膏你作以色列的王。”’然后开门逃走，不要停留。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 于是那青年，就是那年轻的先知，往基列的拉末去了。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 3:19"> 他到了那里，看哪，军队的将领们正坐着。他说：“将军，我有话对你说。”<br />耶户说：“是对我们哪一个说？”<br />他说：“将军，是对你。”</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 22:7; 列王纪上 19:16; 列王纪下 9:3"> 耶户就起来，进了屋子。那年轻先知把油倒在他头上，对他说：“耶和华以色列的上帝这样说：‘我膏你作耶和华子民的王，就是作以色列的王。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 21:15; 列王纪上 18:4; 申命记 32:43"> 你要击打你主人亚哈的家，好使我在耶洗别身上，为我的仆人众先知的血，和耶和华一切仆人的血报仇。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 25:22; 申命记 32:36; 列王纪下 14:26"> 亚哈全家都必灭亡。凡属亚哈、靠墙小便的，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：男丁">a</a></sup>无论在以色列中被关的或自由的，我都要剪除。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 15:29; 列王纪上 21:22; 列王纪上 14:10–11"> 我要使亚哈的家像尼八的儿子耶罗波安的家，又像亚希雅的儿子巴沙的家。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 21:23; 列王纪下 9:35–36; 列王纪下 9:3"> 狗必在耶斯列的田地上吃耶洗别，没有人埋葬她。’”说完，他就开门逃走了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="耶利米书 29:26; 使徒行传 26:24; 何西阿 9:7"> 耶户出来，到他主人的臣仆那里；有一人对他说：“平安吗？这疯子为什么来找你？”<br />他对他们说：“你们知道那人，也知道他说话的样子。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 他们说：“那是谎话。现在告诉我们吧。”<br />他说：“他这样对我说：‘耶和华这样说：我膏你作以色列的王。’”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马可福音 11:7–8; 列王纪上 1:39; 列王纪上 1:34"> 他们就急忙各拿自己的外衣，铺在他身下的台阶顶上；又吹号，说：“耶户作王了！”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王纪下 8:28; 列王纪上 22:3; 列王纪上 16:16"> 这样，宁示的孙子、约沙法的儿子耶户背叛了约兰。（那时约兰和以色列众人正在防守基列的拉末，抵挡亚兰王哈薛；</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 8:29; 撒母耳记上 27:9–11; 历代志下 22:6"> 但约兰王已经回到耶斯列，医治他与亚兰王哈薛作战时亚兰人所伤的伤。）耶户说：“如果这是你们的心意，就不要让任何人逃出城，去耶斯列报信。”</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 22:6–7; 列王纪下 8:28–29"> 于是耶户坐车往耶斯列去，因为约兰躺卧在那里。犹大王亚哈谢也下去看望约兰。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 16:4; 以西结 33:2–9; 列王纪下 7:14"> 守望的人站在耶斯列的楼上，看见耶户的一队人前来，就说：“我看见一队人。”<br />约兰说：“派一个骑马的人去迎见他们，让他说：‘平安吗？’”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王纪下 9:19; 列王纪下 9:22; 耶利米书 16:5"> 于是有一个骑马的人去迎见耶户，说：“王问：‘平安吗？’”<br />耶户说：“平安与你有什么相干？转到我后面去！”<br />守望的人说：“使者到了他们那里，却没有回来。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 王又派第二个骑马的人出去；他到了他们那里，说：“王问：‘平安吗？’”<br />耶户回答说：“平安与你有什么相干？转到我后面去！”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳记下 18:27; 列王纪上 19:17; 传道书 9:10"> 守望的人说：“他到了他们那里，也没有回来。赶车的样子像宁示的儿子耶户赶车，因为他赶得很猛。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王纪上 21:1–7; 历代志下 22:7; 弥迦书 1:13"> 约兰说：“套车！”<br />他们就给他套车。以色列王约兰和犹大王亚哈谢各坐自己的车出去；他们出去迎见耶户，在耶斯列人拿伯的田地那里遇见了他。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 21:13; 那鸿书 3:4; 列王纪上 16:30–33"> 约兰看见耶户，就说：“耶户啊，平安吗？”<br />他回答说：“你母亲耶洗别的淫乱和邪术这样多，哪里来的平安？”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪下 11:14; 历代志下 23:13"> 约兰掉转车头逃跑，对亚哈谢说：“亚哈谢啊，这是叛乱！”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王纪上 22:34; 箴言 21:30; 帖撒罗尼迦前书 5:3"> 耶户用尽全力拉弓，射中约兰两臂之间；箭穿透他的心，他就倒在车上。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 21:19; 列王纪上 21:24–29; 以赛亚书 13:1"> 耶户对他的将领毕甲说：“把他抬起来，丢在耶斯列人拿伯的田地里；因为你要记得，你和我一同跟随他父亲亚哈骑马的时候，耶和华曾对他发出这审判的话：</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 21:19; 申命记 5:9; 历代志下 25:4"> ‘耶和华说：我昨日确实看见拿伯的血和他众子的血；耶和华说：我必在这块地上报应你。’现在你要照耶和华的话，把他抬起来，丢在这块地上。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="士师记 1:27; 约书亚记 17:11; 列王纪下 8:29"> 犹大王亚哈谢看见这事，就从园亭的路逃跑。耶户追赶他，说：“在车上也击打他！”他们就在靠近以伯莲的古珥坡上击中了他。他逃到米吉多，死在那里。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 35:24; 列王纪下 23:30; 列王纪下 12:21"> 他的臣仆用车把他送到耶路撒冷，将他葬在大卫城他自己的坟墓里，与他的列祖同葬。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志下 21:18–19; 历代志下 22:1–2; 列王纪下 8:24–25"> 亚哈的儿子约兰第十一年，亚哈谢开始作犹大的王。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="耶利米书 4:30; 以西结 23:40; 以西结 24:17"> 耶户到了耶斯列，耶洗别听见了，就描画眼睛，装饰头发，从窗户往外观看。</span>
<span className="v" id="v31" data-v="31" data-xref="列王纪上 16:9–20"> 耶户进城门的时候，她说：“杀自己主人的心利啊，你来是平安吗？”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以斯帖记 2:15; 出埃及记 32:26; 历代志下 11:12"> 耶户抬脸向窗户观看，说：“谁站在我这边？谁？”<br />有两三个太监从窗户向他探出头来。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="弥迦书 7:10; 耶利米哀歌 1:15; 以赛亚书 25:10"> 他说：“把她扔下来！”<br />他们就把她扔下来；她的血有些溅在墙上和马上。随后耶户践踏了她。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 16:31; 列王纪上 21:25; 以赛亚书 65:15"> 耶户进去，吃喝完了，就说：“现在去料理这个被咒诅的女人，把她埋葬；因为她是王的女儿。”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="使徒行传 12:23; 以赛亚书 14:18–20; 约伯记 31:3"> 他们去埋葬她，却只找到她的头骨、脚和手掌。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 21:23; 利未记 8:36; 列王纪下 14:25"> 他们就回来告诉耶户。<br />他说：“这正是耶和华的话，是祂藉祂仆人提斯比人以利亚所说的：‘狗必在耶斯列的田地上吃耶洗别的肉；</span>
<span className="v" id="v37" data-v="37" data-xref="耶利米书 8:2; 诗篇 83:10; 耶利米书 16:4"> 耶洗别的尸体必在耶斯列的地上，如同田间的粪土，以至于人不能说：“这是耶洗别。”’”</span>
</div>
</div>

</div>

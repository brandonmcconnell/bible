<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 1:17; 列王纪上 22:51; 列王纪下 8:16"> 犹大王约沙法第十八年，亚哈的儿子约兰在撒马利亚登基作以色列王，作王十二年。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 10:18; 列王纪下 10:26–28; 列王纪上 21:25"> 他行耶和华眼中看为恶的事，但不像他的父亲和母亲那样，因为他除掉了他父亲所造的巴力柱像。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 14:16; 列王纪上 15:34; 列王纪下 15:18"> 然而，他仍执意不离开尼八的儿子耶罗波安使以色列所犯的那些罪；他没有离开这些罪。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 8:2; 创世记 26:13–14; 约伯记 1:3"> 摩押王米沙是牧羊业主；他曾把十万只羔羊和十万只公绵羊的羊毛供给以色列王。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 1:1; 列王纪下 8:20; 历代志下 21:8–10"> 亚哈死后，摩押王就背叛以色列王。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 24:1–25; 撒母耳记上 11:8; 撒母耳记上 15:4"> 那时，约兰王从撒马利亚出去，召集以色列全军。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 22:4; 历代志下 22:10–12; 历代志下 18:3"> 他派人去见犹大王约沙法，说：“摩押王背叛了我。你愿意和我一同去攻打摩押吗？”<br />约沙法说：“我愿意上去；我与你一样，我的民与你的民一样，我的马与你的马一样。”</span>
<span className="v" id="v8" data-v="8" data-xref="玛拉基书 1:2–3; 民数记 21:4"> 他又说：“我们从哪条路上去？”<br />约兰回答：“从以东旷野的路上去。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王纪上 22:47; 民数记 20:2; 出埃及记 17:1"> 于是以色列王与犹大王和以东王一同出发，绕道行了七天。军队和随行的牲口都没有水喝。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 78:34–36; 以赛亚书 51:20; 以赛亚书 8:21"> 以色列王说：“唉！耶和华召集这三王，是要把他们交在摩押手中。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="列王纪上 22:7; 列王纪上 19:21; 列王纪下 3:3"> 约沙法说：“这里没有耶和华的先知，让我们可以借着他求问耶和华吗？”<br />以色列王的一个臣仆回答说：“这里有沙法的儿子以利沙，就是曾倒水在以利亚手上的。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王纪下 5:15; 列王纪下 2:21; 以赛亚书 60:14"> 约沙法说：“耶和华的话与他同在。”于是以色列王、约沙法和以东王下到他那里。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="列王纪上 22:6; 列王纪上 18:19; 列王纪上 22:10–11"> 以利沙对以色列王说：“我与你有什么相干？去你父亲的先知和你母亲的先知那里吧。”<br />以色列王对他说：“不要这样；因为耶和华召集这三王，是要把他们交在摩押手中。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王纪下 5:16; 列王纪上 17:1; 历代志下 19:3–4"> 以利沙说：“我指着我所侍立在祂面前、永活的万军之耶和华起誓：若不是我顾念犹大王约沙法的情面，我必不看你一眼，也不接见你。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 16:23; 以弗所书 5:18–19; 以西结 1:3"> 现在，给我带一个乐师来。”乐师弹奏的时候，耶和华的手临到以利沙。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 2:16–18; 列王纪下 4:3"> 他说：“耶和华这样说：‘要在这谷中挖满沟渠。’</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 107:35; 以赛亚书 41:17–18; 以赛亚书 48:21"> 因为耶和华这样说：‘你们看不见风，也看不见雨，但这谷必充满水；你们和你们的牲畜，以及其他牲口，都要喝水。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 32:27; 路加福音 1:37; 耶利米书 32:17"> 在耶和华眼中，这还是小事；祂也要把摩押人交在你们手中。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 13:17; 申命记 20:19–20; 士师记 6:16"> 你们要攻破每一座坚固城和每一座佳美城，砍倒每一棵好树，塞住所有水泉，并用石头毁坏每一块良田。’”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 29:39–40; 但以理 9:21; 列王纪上 18:36"> 到了早晨，约在献祭的时候，看哪，水从以东的方向流来，那地就充满了水。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以弗所书 6:14; 列王纪上 20:11"> 摩押众人听见诸王上来攻打他们，就聚集起来，凡能披戴盔甲的，无论老少，都站在边界上。</span>
<span className="v" id="v22" data-v="22"> 他们清早起来，太阳照在水上；摩押人看见对面的水红如血。</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 5:30; 出埃及记 15:9; 以赛亚书 10:14"> 他们说：“这是血！诸王必定败亡，彼此击杀了。现在，摩押人哪，去抢掠吧！”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦前书 5:3–4; 约书亚记 8:20–22; 士师记 20:40–46"> 摩押人来到以色列营前，以色列人就起来攻击摩押人，使他们在以色列人面前逃跑；以色列人向前进入那地，继续攻击摩押人。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 16:7; 耶利米书 48:36; 耶利米书 48:31"> 他们摧毁城邑；在每一块良田上，各人投石，把地填满。他们又塞住所有水泉，砍倒一切好树，直到基珥哈列设只剩下那里的石头；然而甩石兵围绕它，攻击它。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 3:9; 阿摩司 2:1"> 摩押王见战势对他过于猛烈，就带着七百名拔刀的人，要突围到以东王那里，却不能成功。</span>
<span className="v" id="v27" data-v="27" data-xref="弥迦书 6:7; 申命记 12:31; 士师记 11:31"> 于是他把那本应接续他作王的长子，在城墙上献为燔祭。有大怒临到以色列；他们就离开他，返回自己的地去了。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 1:1; 以赛亚书 7:1; 列王纪下 15:38"> 利玛利的儿子比加第十七年，犹大王约坦的儿子亚哈斯开始作王。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 28:1–4; 列王纪下 15:34; 列王纪上 11:4–8"> 亚哈斯开始作王的时候二十岁，在耶路撒冷作王十六年。他没有像他祖先大卫那样，行耶和华他上帝眼中看为正的事。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 12:31; 利未记 18:21; 列王纪下 21:2"> 他却行以色列诸王的道路，甚至使自己的儿子经火，照着耶和华从以色列人面前赶出的那些列国所行可憎的事。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 12:2; 列王纪上 14:23; 耶利米书 17:2"> 他在丘坛上、山冈上、各青翠树下献祭烧香。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪下 15:37; 以赛亚书 9:6–7; 以赛亚书 8:9–10"> 那时，亚兰王利汛和利玛利的儿子以色列王比加上来攻打耶路撒冷。他们围困亚哈斯，却不能胜过他。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 14:22; 申命记 2:8; 列王纪上 9:26"> 那时，亚兰王利汛为亚兰收回以拉他，把犹大人从以拉他赶出去；亚兰人来到以拉他，住在那里，直到今日。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 15:29; 耶利米哀歌 4:17; 何西阿 14:3"> 亚哈斯差遣使者去见亚述王提革拉毗列色，说：“我是你的仆人，你的儿子。现在亚兰王和以色列王起来攻击我，求你上来救我脱离他们的手。”</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪下 12:17–18; 历代志下 28:20–21; 历代志下 16:2"> 亚哈斯拿耶和华殿里和王宫宝库里所有的金银，送给亚述王作礼物。</span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司 9:7; 以赛亚书 22:6; 阿摩司 1:3–5"> 亚述王听从了他；亚述王上去攻打大马士革，夺取了城，把城中的居民掳到吉珥，又杀了利汛。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="罗马书 12:2; 以西结 23:16–17; 以赛亚书 8:2"> 亚哈斯王去大马士革迎接亚述王提革拉毗列色，看见大马士革的祭坛；亚哈斯王就把祭坛的图样和建造的规格送给祭司乌利亚。</span>
<span className="v" id="v11" data-v="11" data-xref="何西阿 4:6; 历代志下 26:17–18; 何西阿 5:11"> 祭司乌利亚建了一座祭坛；祭司乌利亚照着亚哈斯王从大马士革所送来的一切去做，等候亚哈斯王从大马士革回来。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 26:16–19; 历代志下 28:25; 列王纪上 13:1"> 王从大马士革回来，看见那祭坛；王就走近祭坛，在坛上献祭。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 1:1–3"> 他烧了自己的燔祭和素祭，浇上奠祭，又把自己平安祭牲的血洒在坛上。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 4:1; 出埃及记 40:6; 出埃及记 40:29"> 他又把耶和华面前的铜坛，从殿前、就是从他自己的祭坛和耶和华殿之间搬出来，放在他祭坛的北边。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 29:39–41; 列王纪上 8:64; 历代志下 29:21–24"> 亚哈斯王吩咐祭司乌利亚说：“早晨的燔祭、晚上的素祭、王的燔祭和素祭，以及全国人民的燔祭、素祭和奠祭，都要烧在大坛上；燔祭的一切血和祭牲的一切血，也都要洒在这坛上；至于铜坛，要留给我求问之用。”</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 4:19; 使徒行传 5:29; 犹大书 1:11"> 祭司乌利亚就照亚哈斯王所吩咐的一切去做。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="历代志下 4:14–15; 耶利米书 52:20; 历代志下 28:24"> 亚哈斯王切掉盆座的镶板，把盆从座上挪下来，又把铜海从它下面的铜牛上取下，放在石铺的地上。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 11:5; 列王纪上 10:5; 以西结 46:2"> 他又因亚述王的缘故，把殿中为安息日所建的遮盖通道，以及王从外面进入耶和华殿的入口都拆除了。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 15:36; 历代志下 28:26; 列王纪下 20:20–21"> 亚哈斯所行其余的事，不是都写在《犹大列王记》上吗？</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 1:9; 以赛亚书 1:1; 历代志上 3:13"> 亚哈斯与他的祖先同睡，与他的祖先一同葬在大卫城；他的儿子希西家接续他作王。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="但以理 1:1; 耶利米书 25:1; 耶利米书 25:9"> 约雅敬在位的日子，巴比伦王尼布甲尼撒上来，约雅敬臣服他三年；后来他转而背叛尼布甲尼撒。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 35:11; 列王纪下 23:27; 列王纪下 21:12–14"> 耶和华差遣迦勒底人的队伍、亚兰人的队伍、摩押人的队伍和亚扪人的队伍来攻击约雅敬，又差遣他们来攻击犹大，要毁灭它，正如耶和华借祂仆人众先知所说的话。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 18:25; 列王纪下 21:2–11; 列王纪下 23:26–27"> 这事临到犹大，确是出于耶和华的命令，要因玛拿西的罪，照他所行的一切，将他们从祂面前除去；</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪下 21:16; 诗篇 106:38; 民数记 35:33"> 又因他所流无辜人的血；因为他使无辜人的血充满了耶路撒冷，耶和华不肯赦免。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 36:8; 耶利米书 26:1–24; 耶利米书 22:13–17"> 约雅敬其余的事和他所行的一切，不是都写在《犹大列王记》上吗？</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 22:18–19; 历代志下 36:6; 耶利米书 36:30"> 约雅敬与他祖先同睡，他儿子约雅斤接续他作王。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="耶利米书 37:5–7; 耶利米书 46:2; 创世记 15:18"> 埃及王不再从他的国中出来；因为巴比伦王已经夺取了从埃及小河直到幼发拉底河，凡属埃及王的一切土地。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="历代志下 36:9; 历代志上 3:16; 耶利米书 37:1"> 约雅斤登基的时候十八岁，在耶路撒冷作王三个月。他母亲名叫尼护施她，是耶路撒冷人以利拿单的女儿。</span>
<span className="v" id="v9" data-v="9"> 约雅斤行耶和华眼中看为恶的事，照他父亲所行的一切。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 25:2; 但以理 1:1–2"> 那时，巴比伦王尼布甲尼撒的臣仆上到耶路撒冷，城就被围困。</span>
<span className="v" id="v11" data-v="11"> 巴比伦王尼布甲尼撒来到城前，那时他的臣仆正在围困城。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 24:1; 耶利米书 52:28; 列王纪下 25:27"> 犹大王约雅斤出去投降巴比伦王，他和他的母亲、臣仆、首领、官员都出去；巴比伦王在他作王第八年擒获了约雅斤。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 39:6; 列王纪下 20:17; 耶利米书 20:5"> 巴比伦王从那里搬出了耶和华殿里的一切宝物和王宫里的宝物，又把以色列王所罗门在耶和华殿中所造的一切金器都砍碎，正如耶和华所说的。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 52:28; 列王纪下 25:12; 列王纪下 24:16"> 他掳去了全耶路撒冷的人，包括所有首领、所有勇士，共一万俘虏，以及所有工匠和铁匠；除了当地最贫穷的百姓以外，没有人留下。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 36:10; 耶利米书 22:24–28; 以斯帖记 2:6"> 他把约雅斤掳到巴比伦，又把王的母亲、王的妻妾、他的官员，以及当地的显要人物，都从耶路撒冷掳到巴比伦。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 52:28; 列王纪下 24:14; 耶利米书 29:2"> 所有有力量的人，共七千名，工匠和铁匠一千名，都是强壮能作战的人；巴比伦王把他们都掳到巴比伦。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 37:1; 历代志下 36:4; 列王纪下 23:34"> 巴比伦王立约雅斤父亲的兄弟玛探雅接续他作王，并给他改名叫西底家。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王纪下 23:31; 耶利米书 52:1–11; 耶利米书 37:1"> 西底家登基的时候二十一岁，在耶路撒冷作王十一年。他母亲名叫哈慕他勒，是立拿人耶利米的女儿。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 23:37; 耶利米书 24:8; 以西结 21:25"> 西底家行耶和华眼中看为恶的事，照约雅敬所行的一切。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 36:13; 帖撒罗尼迦后书 2:9–11; 耶利米书 38:17–21"> 因耶和华的怒气，这事临到耶路撒冷和犹大，直到祂把他们从自己面前赶出去。<br />后来西底家背叛了巴比伦王。</span>
</div>

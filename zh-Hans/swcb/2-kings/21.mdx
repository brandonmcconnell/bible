<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 62:4; 历代志下 32:33–9; 马太福音 1:10"> 玛拿西登基的时候十二岁，在耶路撒冷作王五十五年。他母亲名叫协西巴。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 12:31; 历代志下 36:14; 历代志下 33:2–4"> 他行耶和华眼中看为恶的事，效法耶和华在以色列人面前赶出的列国那些可憎的事。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 18:4; 列王纪下 17:16; 申命记 17:3"> 他重新建筑他父亲希西家所毁坏的丘坛，又为巴力筑祭坛，造了亚舍拉像，照以色列王亚哈所行的，敬拜天上的万象，事奉它们。</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 8:29; 撒母耳记下 7:13; 耶利米书 32:34"> 他在耶和华的殿中筑祭坛；耶和华曾论这殿说：“我必将我的名安置在耶路撒冷。”</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 7:12; 列王纪下 23:4; 列王纪下 23:12"> 他在耶和华殿的两个院子里，为天上的万象筑祭坛。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 17:17; 利未记 19:31; 利未记 18:21"> 他使自己的儿子经火，又行法术，用邪术，并交鬼、行巫术。他行了许多耶和华眼中看为恶的事，惹祂发怒。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 7:16; 列王纪上 9:3; 撒母耳记下 7:13"> 他把自己所造、雕刻的亚舍拉像安置在殿中；论到这殿，耶和华曾对大卫和他儿子所罗门说：“在这殿中，并在我从以色列众支派中所拣选的耶路撒冷，我必永远安置我的名；</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 7:10; 申命记 5:28–29; 诗篇 81:11–16"> 只要他们谨守遵行我所吩咐他们的一切，并照我仆人摩西吩咐他们的一切律法而行，我就不再使以色列的脚离开我赐给他们列祖之地而漂流。”</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 29:12; 尼希米记 9:26; 列王纪上 14:16"> 但他们不听从，玛拿西引诱他们行恶，比耶和华在以色列人面前所灭的列国更甚。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 23:34–37; 历代志下 33:10; 历代志下 36:15"> 耶和华借祂仆人众先知说：</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 24:3–4; 列王纪上 21:26; 列王纪下 21:9"> “因犹大王玛拿西行了这些可憎的事，所行的恶超过了在他以前的亚摩利人，又用他的偶像使犹大犯罪；</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 19:3; 撒母耳记上 3:11; 但以理 9:12"> 所以耶和华以色列的上帝这样说：‘看哪，我必降灾祸在耶路撒冷和犹大，使凡听见的人两耳都要发响。</span>
<span className="v" id="v13" data-v="13" data-xref="阿摩司 7:7–8; 耶利米哀歌 2:8; 以赛亚书 34:11"> 我必把量撒玛利亚的准绳和量亚哈家的线坠拉在耶路撒冷之上；我必擦净耶路撒冷，如人擦盘子一样，擦净了就把它翻过来。</span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 23:33; 列王纪下 19:4; 诗篇 89:38–45"> 我必丢弃我产业中所余剩的人，把他们交在仇敌手中。他们必成为所有仇敌的掠物和战利品，</span>
<span className="v" id="v15" data-v="15" data-xref="以西结 20:30; 申命记 31:27; 以西结 20:21"> 因为自从他们的列祖出埃及那日直到今日，他们行我眼中看为恶的事，惹我发怒。’”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数记 35:33; 历代志下 33:9; 列王纪下 21:11"> 此外，玛拿西流了许多无辜人的血，直到使耶路撒冷从这头到那头都充满了；这还不算他使犹大犯罪，行耶和华眼中看为恶之事的罪。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="列王纪下 20:20–21; 历代志下 33:1–20"> 玛拿西其余的事迹，他所行的一切，以及他所犯的罪，不都写在《犹大列王记》上吗？</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 33:20; 列王纪下 21:26; 历代志下 32:33"> 玛拿西与他祖先同睡，葬在自己宫院的园子里，就是乌撒园；他儿子亚们接续他作王。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="历代志下 33:21–23; 列王纪上 22:51; 历代志上 3:14"> 亚们登基的时候二十二岁，在耶路撒冷作王二年。他母亲名叫米舒利密，是约提巴人哈鲁斯的女儿。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 23:32; 列王纪下 21:11; 使徒行传 7:51"> 亚们行耶和华眼中看为恶的事，像他父亲玛拿西所行的。</span>
<span className="v" id="v21" data-v="21"> 他行他父亲所行的一切道路，事奉他父亲所事奉的偶像，并敬拜它们；</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪下 22:17; 列王纪上 11:33; 历代志上 28:9"> 他离弃耶和华他列祖的上帝，不行耶和华的道路。</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 12:20; 列王纪下 14:19; 历代志下 33:24–25"> 亚们的臣仆背叛他，在他自己的宫里杀了王。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪下 14:5; 列王纪下 11:17; 列王纪下 14:21"> 但当地的百姓杀了所有背叛亚们王的人；当地的百姓立他儿子约西亚接续他作王。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 20:20; 列王纪下 21:17"> 亚们所行其余的事，不都写在《犹大列王记》上吗？</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 21:18; 马太福音 1:10; 列王纪上 13:5"> 亚们葬在乌撒园中自己的坟墓里；他儿子约西亚接续他作王。</span>
</div>

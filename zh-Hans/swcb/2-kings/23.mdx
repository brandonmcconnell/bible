<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="2KI" data-book-slug="2-kings" data-book-name="列王纪下" data-chapter="23" data-verses="37">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 34:29–33; 历代志下 30:2; 申命记 31:28"> 王差遣人，他们就把犹大和耶路撒冷的所有长老都聚集到他那里。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 22:8; 申命记 31:10–13; 启示录 20:12"> 王上到耶和华的殿，所有犹大人和耶路撒冷所有居民都与他同去，还有祭司、先知和全体百姓，无论大小；王就把在耶和华殿里找到的那约书上的一切话，读给他们听。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 11:14; 列王纪下 11:17; 申命记 13:4"> 王站在柱旁，在耶和华面前立约，要跟随耶和华，尽心尽性遵守祂的诫命、法度和律例，实行写在这书上的约言；众民都应允这约。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 21:3; 列王纪下 21:7; 历代志下 33:3"> 王吩咐大祭司希勒家、副祭司和守门的人，把耶和华殿里一切为巴力、为亚舍拉和为天上万象所造的器皿都搬出来；他在耶路撒冷外汲沦的田间焚烧了这些器皿，又把它们的灰带到伯特利。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 44:17–19; 列王纪下 21:3–4; 何西阿 10:5"> 他废除了犹大诸王所立、在犹大各城的邱坛和耶路撒冷周围各处烧香的拜偶像祭司，也废除了那些向巴力、太阳、月亮、行星和天上万象烧香的人。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 34:4; 列王纪下 23:15; 列王纪上 14:23"> 他把亚舍拉像从耶和华殿里搬出耶路撒冷，带到汲沦溪边，在汲沦溪边焚烧，把它打碎成灰尘，又把它的灰尘撒在平民的坟上。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 15:12; 以西结 16:16; 列王纪上 14:24"> 他拆毁耶和华殿里男庙妓的屋子，就是妇女为亚舍拉织帷帐的地方。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 15:22; 约书亚记 21:17; 列王纪上 19:3"> 他把所有祭司从犹大各城带出来，又玷污祭司曾经烧香的邱坛，从迦巴直到别是巴；他也拆毁城门口的邱坛，就是在市长约书亚门的入口处、人在进城门时左边的那些邱坛。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 44:10–14; 撒母耳记上 2:36; 玛拉基书 2:8–9"> 然而邱坛的祭司不上耶路撒冷耶和华的坛，只是在他们弟兄中间吃无酵饼。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 30:33; 耶利米书 19:6; 利未记 18:21"> 他玷污欣嫩子谷里的陀斐特，使人不能让自己的儿子或女儿经火献给摩洛。</span>
<span className="v" id="v11" data-v="11" data-xref="以西结 8:16; 申命记 4:19; 历代志下 14:5"> 他除去犹大诸王献给太阳的马，就是在耶和华殿入口处，靠近院内官员拿单米勒的房间旁边的马；又用火焚烧献给太阳的战车。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 21:5; 西番雅书 1:5; 耶利米书 19:13"> 犹大诸王在亚哈斯楼顶上所造的坛，以及玛拿西在耶和华殿两院中所造的坛，王都拆毁，从那里打碎，又把它们的灰尘倒进汲沦溪。</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 11:7; 列王纪上 11:5; 民数记 21:29"> 王玷污耶路撒冷前面、毁坏山右边的邱坛，就是以色列王所罗门为西顿人可憎的亚斯她录、为摩押可憎的基抹、为亚扪人可憎的米勒公所建造的。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 7:5; 出埃及记 23:24; 列王纪下 23:16"> 他打碎柱像，砍下亚舍拉木柱，又用人的骸骨填满它们原来的地方。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="列王纪下 23:6; 列王纪上 14:16; 列王纪上 21:22"> 此外，伯特利的坛和使以色列陷在罪里的尼八的儿子耶罗波安所造的邱坛，就是那坛和邱坛，他也拆毁；他焚烧那邱坛，把它打成灰尘，又焚烧亚舍拉像。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 13:1–2; 列王纪上 13:32; 约翰福音 10:35"> 约西亚转身，看见山上那里的坟墓，就差人从坟墓里取出骸骨，烧在坛上，玷污了坛，正如耶和华的话，就是那宣告这些事的上帝仆人所宣告的。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 13:1; 列王纪上 13:30–31"> 于是他说：“我所看见的那座碑是什么？”<br />那城里的人告诉他说：“这是从犹大来的上帝仆人的坟墓；他曾宣告你向伯特利的坛所做的这些事。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王纪上 13:31; 列王纪上 13:1–22"> 他说：“由他吧！不要让任何人挪动他的骸骨。”所以他们没有动他的骸骨，也没有动那从撒玛利亚来的先知的骸骨。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志下 34:6–7; 列王纪下 17:9; 以西结 8:17–18"> 撒玛利亚各城里一切邱坛的屋子，就是以色列诸王所造、惹耶和华发怒的，约西亚也都除去，并且照他在伯特利所做的一切事对待它们。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 11:18; 历代志下 34:5; 出埃及记 22:20"> 他把那里所有邱坛的祭司都杀在坛上，又在坛上焚烧人的骸骨；然后他回到耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命记 16:1–8; 民数记 9:2–5; 历代志下 35:1–19"> 王吩咐全体百姓说：“你们要照这约书上所写的，向耶和华你们的上帝守逾越节。”</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 30:1–3; 历代志下 30:13–20; 历代志下 35:3–19"> 的确，自从治理以色列的士师的日子以来，以及在以色列诸王和犹大诸王的一切日子里，都没有守过这样的逾越节；</span>
<span className="v" id="v23" data-v="23"> 只是在约西亚王第十八年，这逾越节才在耶路撒冷向耶和华守了。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="利未记 19:31; 列王纪下 21:6; 创世记 31:19"> 此外，约西亚除掉交鬼的、行巫术的、特拉芬<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="特拉芬是家中的神像。">a</a></sup>、偶像，以及在犹大地和耶路撒冷所见的一切可憎之物，为要实行希勒家祭司在耶和华殿里所找到的书上所写的律法的话。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 18:5; 耶利米书 29:13; 申命记 6:5"> 在约西亚以前，没有王像他那样照摩西的一切律法，尽心、尽性、尽力归向耶和华；在他以后，也没有兴起一个像他的王。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 21:11–13; 列王纪下 24:4; 耶利米书 3:7–10"> 然而，耶和华并没有转离祂猛烈的大怒，就是祂向犹大发出的烈怒，因为玛拿西用一切惹祂发怒的事惹动了祂。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 18:11; 列王纪下 21:13; 列王纪下 21:4"> 耶和华说：“我也要把犹大从我眼前除掉，像我除掉以色列一样；我必弃绝我所拣选的这城，就是耶路撒冷，也弃绝我曾说『我的名必在那里』的殿。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王纪下 20:20"> 约西亚其余的事迹，以及他所做的一切，岂不都写在《犹大列王记》上吗？</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 46:2; 历代志下 35:20–24; 士师记 5:19"> 在他的日子，埃及王法老尼哥上到幼发拉底河，攻击亚述王；约西亚王出去迎击他，法老尼哥在米吉多一看见他，就杀了他。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 9:28; 历代志下 36:1–4; 列王纪下 21:24"> 他的臣仆用车把他的尸体从米吉多运走，带到耶路撒冷，葬在他自己的坟墓里。这地的百姓立约西亚的儿子约哈斯，膏他，使他接续他父亲作王。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="历代志上 3:15; 列王纪下 24:18; 耶利米书 22:11"> 约哈斯登基的时候二十三岁，在耶路撒冷作王三个月。他母亲名叫哈慕他，是立拿人耶利米的女儿。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪下 21:2–7; 列王纪下 21:21–22"> 约哈斯行耶和华眼中看为恶的事，照他列祖所行的一切。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪上 8:65; 列王纪下 25:6; 耶利米书 39:5–6"> 法老尼哥在哈马地的利比拉拘禁他，使他不能在耶路撒冷作王；又罚这地缴纳一百他连得银子和一他连得<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一他连得约为30千克或66磅，或965金衡盎司。">b</a></sup>金子。</span>
<span className="v" id="v34" data-v="34" data-xref="以西结 19:3–4; 列王纪下 24:17; 历代志上 3:15"> 法老尼哥立约西亚的儿子以利亚敬接续他父亲约西亚作王，并改他的名为约雅敬；却把约哈斯带走，他来到埃及，就死在那里。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪下 23:33; 列王纪下 15:19–20"> 约雅敬把银子和金子交给法老；但他按法老的命令向这地征税，好交出那笔银子。他向这地的百姓，每个人按他所估定的数额，索取银子和金子，交给法老尼哥。</span>
<span className="v" id="v36" data-v="36" data-xref="历代志下 36:5; 耶利米书 26:1; 历代志上 3:15"> 约雅敬登基的时候二十五岁，在耶路撒冷作王十一年。他母亲名叫西布大，是鲁玛人毗大雅的女儿。</span>
<span className="v" id="v37" data-v="37" data-xref="历代志下 33:22–23; 以西结 19:5–9; 耶利米书 36:31"> 约雅敬行耶和华眼中看为恶的事，照他列祖所行的一切。</span>
</div>
</div>

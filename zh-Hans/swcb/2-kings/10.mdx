<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 8:30; 列王纪上 13:32; 列王纪上 21:8–14"> 亚哈在撒马利亚有七十个儿子。耶户写信，送到撒马利亚，给耶斯列的首领，就是长老们，以及抚养亚哈儿子的人，说：</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 5:6"> “现在，这信一到你们那里，你们主人的儿子既然与你们同在，你们又有战车和马，也有坚固城和兵器，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 2:8–9; 列王纪上 12:20–21; 撒母耳记下 2:12–17"> 就要从你们主人的儿子中选出最好、最合适的一个，立他坐他父亲的王位，为你们主人的家争战。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 9:24; 列王纪下 9:27; 以赛亚书 27:4"> 但他们极其惧怕，说：“看哪，两个王都不能在他面前站立，我们又怎能站得住呢？”</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 20:32; 列王纪上 20:4; 约书亚记 9:11"> 管理王宫的、管理城市的、长老们，以及抚养孩子的人，都派人去见耶户，说：“我们是你的仆人；凡你吩咐我们的，我们都必去做。我们不会立任何人作王。你看怎样好，就怎样做吧。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="启示录 2:20–23; 申命记 5:9; 民数记 25:4"> 耶户第二次写信给他们，说：“如果你们站在我这边，又愿意听从我的话，就把你们主人那些儿子的人头带来，明天这个时候到耶斯列来见我。”<br />当时王的儿子七十人，都在城中的显贵那里，由他们抚养。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 21:21; 列王纪下 11:1; 列王纪下 10:9"> 信一到他们那里，他们就把王的儿子七十人都杀了，把他们的人头装在筐里，送到耶斯列给耶户。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 21:23; 撒母耳记下 11:18–21; 马可福音 6:28"> 有使者来告诉耶户说：“他们把王儿子们的人头带来了。”<br />耶户说：“把它们堆成两堆，放在城门口，直到早晨。”</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 9:14–24; 以赛亚书 5:3; 何西阿 1:4"> 到了早晨，耶户出去站着，对众民说：“你们是无辜的。看哪，我背叛我的主人，并且杀了他；可是这些人是谁杀的呢？</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 21:29; 列王纪上 21:19; 列王纪下 9:7–10"> 现在你们要知道，耶和华论亚哈家所说的话，一句也不会落空；因为耶和华藉着祂仆人以利亚所说的，祂已经成就了。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约伯记 18:19; 列王纪上 18:19; 列王纪上 22:6"> 于是耶户击杀亚哈家在耶斯列剩下的一切人，以及他所有的显贵、亲信和祭司，直到没有给他留下一个余剩的人。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 耶户起身离开，往撒马利亚去。他在路上到了牧人剪羊毛的房屋那里，</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 8:29; 列王纪下 8:24; 历代志下 21:17"> 遇见犹大王亚哈谢的兄弟们，就说：“你们是谁？”<br />他们回答说：“我们是亚哈谢的兄弟。我们下去，是要向王的儿女和王后的儿女问安。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志下 22:10; 列王纪下 10:6; 列王纪下 10:10–11"> 耶户说：“活捉他们！”<br />他们就活捉了这些人，在剪羊毛房的坑旁把他们杀了，共四十二人；耶户没有留下他们中的任何一个。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米书 35:14–19; 以斯拉记 10:19; 以西结 17:18"> 耶户从那里离开以后，遇见利甲的儿子约拿达出来迎接他。耶户向他问安，对他说：“你的心对我是否正直，像我的心对你的心一样？”<br />约拿达回答说：“是。”<br />耶户说：“若是，就把你的手给我。”他就把手给耶户；耶户拉他上车，到自己这里。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 19:10; 马太福音 6:5; 列王纪下 10:31"> 耶户说：“你跟我来，看我为耶和华大发热心。”于是他们让约拿达坐在耶户的战车上。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 9:8; 历代志下 22:8; 玛拉基书 4:1"> 耶户到了撒马利亚，就击杀亚哈在撒马利亚剩下的一切人，直到把他们灭尽，正如耶和华对以利亚所说的话。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="列王纪上 16:31–32; 列王纪下 3:2; 罗马书 3:8"> 耶户召集众民，对他们说：“亚哈事奉巴力还少，耶户却要更多地事奉他。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪上 22:6; 列王纪上 18:19; 哥林多后书 11:3"> 现在，你们要把巴力所有的先知、所有敬拜他的人和所有祭司都召到我这里来，不可缺少一人；因为我要向巴力献大祭。凡缺席的，必不得活。”但耶户这样做是出于诡计，意在消灭敬拜巴力的人。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约珥 1:14; 出埃及记 32:5; 列王纪上 18:19–20"> 耶户说：“要为巴力分别为圣，召开严肃会！”<br />他们就宣告了。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 16:32; 列王纪下 11:18; 约珥 3:2"> 耶户差人走遍全以色列；所有敬拜巴力的人都来了，没有一个人不来。他们进入巴力庙；巴力庙从这头到那头都满了。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 28:2; 马太福音 22:11–12"> 耶户对看管衣库的人说：“为所有敬拜巴力的人拿出礼服来！”<br />他就为他们拿出礼服。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 13:30; 马太福音 25:32–33; 马太福音 13:41"> 耶户和利甲的儿子约拿达进了巴力庙。然后他对敬拜巴力的人说：“你们要仔细查看，确保这里与你们在一起的没有耶和华的仆人，只有敬拜巴力的人。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王纪上 20:30–42"> 他们进去献祭和燔祭。耶户已经在外面为自己安排了八十个人，对他们说：“我交在你们手中的人若有一个逃脱，放走他的，必以自己的性命抵那人的性命。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="启示录 16:6–7; 以西结 22:21–22; 列王纪上 18:40"> 耶户献完燔祭，就对护卫兵和军官说：“进去杀他们！不要让一个人逃脱。”于是他们用刀刃击杀他们。护卫兵和军官把尸体抛出去，又进入巴力庙的内殿。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪上 14:23; 列王纪下 3:2; 列王纪下 19:18"> 他们把巴力庙里的柱像搬出来焚烧。</span>
<span className="v" id="v27" data-v="27" data-xref="但以理 3:29; 以斯拉记 6:11; 但以理 2:5"> 他们拆毁了巴力的柱像，又拆毁了巴力庙，把它变成厕所，直到今日。</span>
<span className="v" id="v28" data-v="28"> 这样，耶户从以色列中毁灭了巴力。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王纪上 12:28–30; 列王纪上 14:16; 列王纪上 13:33–34"> 然而，耶户没有离开尼八的儿子耶罗波安使以色列犯的那些罪，就是在伯特利和但的金牛犊。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 10:35; 列王纪下 13:1; 列王纪下 13:10"> 耶和华对耶户说：“因为你实行我眼中看为正的事，做得好，并且照我心中一切的意思对待亚哈家，你的子孙必坐以色列的王位，直到第四代。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪下 10:29; 箴言 4:23; 希伯来书 2:1"> 但耶户没有全心留意遵行耶和华以色列上帝的律法。他没有离开耶罗波安使以色列犯的那些罪。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="列王纪下 8:12; 列王纪上 19:17; 列王纪下 13:22"> 在那些日子，耶和华开始削减以色列的疆土；哈薛在以色列全境攻击他们，</span>
<span className="v" id="v33" data-v="33" data-xref="阿摩司 1:3–4; 申命记 2:36; 约书亚记 13:9–12"> 从约旦河以东，基列全地，就是迦得人、流便人和玛拿西人的地，从亚嫩谷旁的亚罗珥起，直到基列和巴珊。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 11:41; 列王纪上 14:29; 列王纪上 14:19"> 耶户其余的事迹，他所行的一切和他所有的勇力，岂不都写在《以色列诸王记》上吗？</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 14:20; 列王纪上 14:31; 列王纪上 1:21"> 耶户与他祖先同睡；他们把他葬在撒马利亚。他儿子约哈斯接续他作王。</span>
<span className="v" id="v36" data-v="36"> 耶户在撒马利亚统治以色列的时间是二十八年。</span>
</div>
</div>

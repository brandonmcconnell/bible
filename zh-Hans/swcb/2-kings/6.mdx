<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 2:3; 列王纪下 4:1; 约书亚记 17:14"> 先知的门徒们对以利沙说：“看哪，我们与你同住并聚会的地方，对我们来说太小了。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 21:3; 使徒行传 18:3; 帖撒罗尼迦前书 2:9"> 请让我们到约旦河去，各人从那里取一根木料，在那里为自己造一个可住的地方。”<br />他回答说：“你们去吧！”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="约伯记 6:28; 士师记 19:6; 列王纪下 5:23"> 有一个人说：“请你也愿意与仆人们同去。”<br />他回答说：“我去。”</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 19:5; 申命记 29:11"> 于是他与他们同去。他们来到约旦河，就砍伐树木。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 37:21; 传道书 10:10; 列王纪下 6:15"> 有一个人砍树的时候，斧头掉进水里。他就呼喊说：“哀哉，我主啊！这是借来的。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王纪下 2:21; 马可福音 8:23–25; 列王纪下 4:41"> 神人问：“掉在哪里？”他把那地方指给他看。以利沙砍下一根木棍，扔在那里，就使铁斧头浮上来。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 4:36; 出埃及记 4:4; 列王纪下 4:7"> 他说：“拿起来。”那人就伸手拿了。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪下 6:24; 箴言 21:30; 箴言 20:18"> 亚兰王与以色列交战；他和臣仆商议说：“我的营要设在某某地方。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="阿摩司 3:7; 启示录 1:1; 列王纪下 6:12"> 神人派人去见以色列王，说：“你要小心，不可经过这地方，因为亚兰人正下到那里。”</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 13:14; 列王纪下 5:14; 使徒行传 27:24"> 以色列王就派人到神人告诉他并警戒他的地方去；他在那里自我防备，不止一两次。</span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 18:7–11; 以赛亚书 57:20–21; 马太福音 2:3–12"> 亚兰王的心因这事非常烦乱。他召来臣仆，对他们说：“你们不告诉我，我们中间有谁是帮以色列王的吗？”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="但以理 2:28–30; 阿摩司 3:7; 列王纪下 6:9–10"> 他的一个臣仆说：“我主我王，不是这样；而是在以色列的先知以利沙，把你在卧室里所说的话告诉以色列王。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 37:17; 约翰福音 11:47–53; 撒母耳记上 23:22–23"> 王说：“你们去看看他在哪里，我好派人去抓他。”<br />有人告诉他说：“看哪，他在多坍。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王纪下 18:17; 撒母耳记上 24:2; 撒母耳记上 23:26"> 于是王派马匹、战车和大军往那里去。他们夜间来到，包围了那城。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 8:26; 历代志下 20:12; 诗篇 53:5"> 神人的仆人清早起来出去，看哪，有军队带着马匹和战车围了城。他的仆人对他说：“哀哉，我主啊！我们该怎么办？”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 41:10–14; 罗马书 8:31; 约翰一书 4:4"> 他回答说：“不要惧怕，因为与我们同在的，比与他们同在的更多。”</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 68:17; 诗篇 34:7; 撒迦利亚书 6:1–7"> 以利沙祷告说：“耶和华啊，求你开他的眼睛，使他能看见。”耶和华开了那年轻人的眼睛，他就看见；看哪，满山都是火马和火战车，围绕以利沙。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 13:11; 约翰福音 12:40; 创世记 19:11"> 敌人下到他那里时，以利沙向耶和华祷告说：“求你击打这群人，使他们失明。”<br />耶和华就照以利沙的话，使他们失明。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 24:16; 撒母耳记下 16:18–19; 路加福音 9:23"> 以利沙对他们说：“这不是那条路，也不是那座城。跟我来，我要带你们到你们所寻找的那人那里。”于是他带他们到了撒玛利亚。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 6:17; 路加福音 24:31; 路加福音 16:23"> 他们进了撒玛利亚以后，以利沙说：“耶和华啊，开这些人的眼睛，使他们能看见。”<br />耶和华开了他们的眼睛，他们就看见；看哪，他们正在撒玛利亚城中。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王纪下 5:13; 列王纪下 8:9; 列王纪下 2:12"> 以色列王看见他们，就对以利沙说：“我父啊，我可以击杀他们吗？我可以击杀他们吗？”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="罗马书 12:20–21; 创世记 48:22; 何西阿 2:18"> 他回答说：“不可击杀他们。你岂会击杀那些你用刀用弓俘虏的人吗？当把饼和水摆在他们面前，让他们吃喝，然后回到他们的主人那里。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪下 5:2; 列王纪下 24:2; 路加福音 6:35"> 王就为他们预备盛大的筵席。他们吃喝之后，王送他们离去，他们就回到他们的主人那里。从此，亚兰的队伍不再侵扰以色列地。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="列王纪上 20:1; 列王纪上 22:31; 传道书 9:14"> 此后，亚兰王便哈达聚集他的全军，上来围困撒玛利亚。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 6:28–29; 耶利米书 14:18; 耶利米书 14:13–15"> 撒玛利亚发生了大饥荒。看哪，他们围困那城，以致一个驴头卖八十块银子，四分之一卡伯<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一卡伯约为2升，所以四分之一卡伯约为500毫升，或约一品脱。">a</a></sup>鸽子粪卖五块银子。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 14:4; 以赛亚书 10:3; 路加福音 18:3"> 以色列王在城墙上经过时，有一个妇人向他呼喊说：“我主我王啊，求你帮助！”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="诗篇 118:8–9; 诗篇 124:1–3; 诗篇 60:11"> 他说：“耶和华若不帮助你，我从哪里帮助你呢？从禾场，还是从酒榨呢？”</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 14:5; 士师记 18:23; 耶利米哀歌 4:10"> 王又问她：“你有什么事？”<br />她回答说：“这个女人对我说：『把你的儿子交出来，我们今天可以吃他，明天我们再吃我的儿子。』</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 26:29; 申命记 28:53; 申命记 28:57"> 于是我们把我的儿子煮了吃。第二天，我对她说：『把你的儿子交出来，我们可以吃他。』她却把她的儿子藏起来了。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="列王纪上 21:27; 列王纪下 5:7; 列王纪下 19:1"> 王听见妇人的话，就撕裂衣服。当时他正在城墙上经过，百姓观看，看哪，他贴身穿着麻衣。</span>
<span className="v" id="v31" data-v="31" data-xref="路得记 1:17; 列王纪上 19:2; 约翰福音 11:50"> 于是他说：“如果今天沙法的儿子以利沙的头仍留在他身上，愿上帝重重地降罚于我！”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以西结 20:1; 列王纪上 18:4; 以西结 8:1"> 那时，以利沙正坐在自己的屋里，长老们也和他同坐。王从自己面前派了一个人去；但在使者来到以利沙那里以前，以利沙对长老们说：“你们看见了吗？这个杀人凶手的儿子派人来取我的头。看哪，使者来的时候，你们要关上门，把门抵住，不让他进来。他主人的脚步声不是在他后面吗？”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约伯记 2:9; 以赛亚书 8:21; 创世记 4:13"> 他还在和他们说话的时候，看哪，使者下到他那里。于是他说：“看哪，这灾祸是从耶和华来的。我何必再等候耶和华呢？”</span>
</div>
</div>

</div>

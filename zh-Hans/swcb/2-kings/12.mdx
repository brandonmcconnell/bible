<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 3:11; 列王纪下 11:21; 列王纪下 11:1–4"> 耶户第七年，约阿施登基，在耶路撒冷作王四十年。他母亲名叫洗比雅，是别是巴人。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 24:17–22; 历代志下 26:4; 历代志下 25:2"> 约阿施在祭司耶何耶大教导他的日子里，一生行耶和华眼中看为正的事。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 14:4; 列王纪上 22:43; 列王纪上 15:14"> 然而，丘坛还没有废去；百姓仍在丘坛献祭、烧香。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 22:4; 出埃及记 35:5; 历代志上 29:3–9"> 约阿施对祭司们说：“凡带进耶和华殿、分别为圣之物的银子，就是通用的钱，各人按估价所交的钱，以及任何人心里愿意带进耶和华殿的一切银子，</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 58:12; 列王纪上 11:27; 列王纪下 22:5–6"> 祭司们各自要从自己的捐献者收取；殿哪里发现破损，就要修补哪里。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="历代志下 29:34; 彼得前书 5:2; 以赛亚书 56:10–12"> 可是到了约阿施王第二十三年，祭司们还没有修补殿的破损。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 24:16; 历代志下 24:5–14; 列王纪下 11:4"> 于是约阿施王召了祭司耶何耶大和其他祭司来，对他们说：“你们为什么不修补殿的破损呢？现在你们不要再从你们的司库收取银子，要把银子交出来，用来修补殿的破损。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 祭司们同意不再从百姓收取银子，也不再负责修补殿的破损。</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 12:41; 诗篇 84:10; 耶利米书 35:4"> 祭司耶何耶大取了一个箱子，在箱盖上钻了一个孔，放在祭坛旁边，就是人进入耶和华殿时右边的地方；守门的祭司把所有带进耶和华殿的银子都放进箱子里。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 8:17; 列王纪下 22:12; 列王纪下 19:2"> 他们见箱子里的银子很多，王的书记和大祭司就上来，把耶和华殿里所得的银子装袋数点。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 22:5–6; 历代志下 24:11–12; 历代志下 34:9–11"> 他们把称过的银子交在办事的人手中，就是监督耶和华殿工程的人；这些人把银子支付给在耶和华殿做工的木匠和建造的人，</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 22:5–6; 列王纪上 5:17–18; 以斯拉记 3:7"> 以及泥瓦匠和凿石匠，又用来购买木料和凿成的石头，以修补耶和华殿的破损，并支付一切为修理殿所需的费用。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 24:14; 列王纪上 7:48–50; 以斯拉记 1:9–11"> 但是带进耶和华殿的银子，没有用来为耶和华殿制造银杯、灯剪、碗、号筒，或任何金器银器；</span>
<span className="v" id="v14" data-v="14"> 因为他们把银子交给办事的人，用来修理耶和华殿。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 22:7; 约翰三书 1:5; 哥林多前书 4:2–3"> 他们把银子交给那些人，由他们付给做工的人，并不要求他们交账，因为他们办事忠诚。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 7:7; 利未记 5:15–18; 利未记 4:24"> 赎愆祭的银子和赎罪祭的银子没有带进耶和华殿；那是归祭司的。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="历代志下 24:23–24; 路加福音 9:53; 耶利米书 42:15"> 那时，亚兰王哈薛上去攻打迦特，攻取了它；哈薛又决意上去攻打耶路撒冷。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 15:18; 列王纪下 18:15–16; 列王纪下 12:4"> 犹大王约阿施把他祖先犹大诸王约沙法、约兰、亚哈谢分别为圣的一切圣物，和自己分别为圣的物，以及耶和华殿和王宫府库中所有的金子，都送给亚兰王哈薛；哈薛就离开耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="列王纪上 14:29; 列王纪上 14:19; 列王纪上 11:41"> 约阿施其余的事迹，和他所行的一切，不是都写在《犹大列王记》上吗？</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 24:24–27; 列王纪下 14:5; 撒母耳记下 5:9"> 他的臣仆起来结党，在下到悉拉路上的米罗宫击杀约阿施。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪下 14:1; 历代志下 24:26–27"> 因为杀他的，是他的臣仆示米押的儿子约撒甲和朔默的儿子约萨拔；他死了，人把他葬在大卫城，与他的祖先同葬；他的儿子亚玛谢接续他作王。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 21:27; 列王纪下 18:37; 历代志下 32:20–22"> 希西家王听见这事，就撕裂衣服，披上麻衣，进了耶和华的殿。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 1:1; 以赛亚书 2:1; 马太福音 4:14"> 他差派家宰以利亚敬、书记舍伯那和祭司中的长老，都披着麻衣，去见亚摩斯的儿子以赛亚先知。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 30:5–7; 以赛亚书 66:9; 何西阿 13:13"> 他们对他说：“希西家这样说：『今天是患难、责罚和被弃绝的日子；因为孩子到了产门，却没有力量生产。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 16:12; 罗马书 9:27; 约书亚记 14:12"> 或许耶和华你的上帝会听见拉伯沙基的一切话；他的主人亚述王差他来辱骂永生的上帝，耶和华你的上帝也许会责备祂所听见的那些话。因此，请你为所剩下的余民献上祷告。』”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 希西家王的臣仆就来到以赛亚那里。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 18:35; 列王纪下 18:17; 以赛亚书 37:6–38"> 以赛亚对他们说：“你们要这样告诉你们的主人：『耶和华说：“你所听见的话，就是亚述王的仆人亵渎我的那些话，不要因这些话惧怕。</span>
<span className="v" id="v7" data-v="7" data-xref="俄巴底亚 1:1; 列王纪下 7:6; 诗篇 18:14–15"> 看哪，我必把一个灵放在他里面，他必听见消息，就返回自己的地；我必使他在自己的地被刀杀死。”』”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪下 18:14; 约书亚记 10:29; 约书亚记 12:11"> 拉伯沙基回去，发现亚述王正在攻打立拿；因为他听说亚述王已经离开拉吉。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 23:27; 以赛亚书 37:9; 列王纪下 18:17"> 亚述王听见有人论埃塞俄比亚王特哈加说：“看哪，他已经出来要与你争战”，就又差使者去见希西家，说：</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 18:5; 列王纪下 18:29–30; 历代志下 32:15–19"> “你们要这样告诉犹大王希西家：『你所倚靠的上帝说：耶路撒冷必不交在亚述王手中。不要让祂这样欺骗你。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 10:8–11; 历代志下 32:13–14; 列王纪下 19:17–18"> 看哪，你已经听见亚述诸王怎样对待各地，把它们彻底毁灭。难道你能得拯救吗？</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪下 17:6; 创世记 11:31; 以西结 27:23"> 我列祖所毁灭的列国，就是歌散、哈兰、利色，以及住在提拉撒的伊甸子民，他们的神明救了他们吗？</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 18:34; 列王纪下 17:24; 以赛亚书 11:11"> 哈马王、亚珥拔王、西法瓦音城的王、希拿和以瓦的王在哪里呢？』”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 37:14; 诗篇 91:1–2; 诗篇 123:1–4"> 希西家从使者手中接过书信，读了；然后希西家上耶和华的殿，在耶和华面前展开那信。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 44:6; 列王纪下 5:15; 但以理 4:34–35"> 希西家在耶和华面前祷告，说：“耶和华，以色列的上帝，坐在基路伯之上的那一位啊，你，惟有你，是地上万国的上帝。你造了天和地。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 6:40; 诗篇 31:2; 列王纪下 19:4"> 耶和华啊，求你侧耳垂听；耶和华啊，求你睁眼观看。求你听西拿基立差人来辱骂永生上帝的话。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 5:26; 约伯记 9:2; 哥林多前书 14:25"> 耶和华啊，亚述诸王确实使列国和他们的土地荒废，</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 17:29; 以赛亚书 44:9–20; 耶利米书 10:3–9"> 又把他们的神明扔在火里；因为那些并不是神明，不过是人手所造的，是木头和石头。所以他们把它们毁灭了。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 83:18; 列王纪上 8:43; 诗篇 67:1–2"> 现在，耶和华我们的上帝啊，求你从他的手中拯救我们，好叫地上万国都知道，惟独你耶和华是上帝。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="列王纪下 20:5; 历代志下 32:20–21; 耶利米书 33:3"> 于是亚摩斯的儿子以赛亚差人去见希西家，说：“耶和华，以色列的上帝，如此说：『你向我祷告攻击亚述王西拿基立，我已经听见了。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米哀歌 2:13; 约伯记 16:4; 耶利米书 14:17"> 耶和华论他说的话是这样：『锡安的处女藐视你，嗤笑你；耶路撒冷的女子向你摇头。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 5:24; 诗篇 71:22; 以赛亚书 30:11–12"> 你辱骂、亵渎的是谁？你向谁扬声，又高高举目？你攻击的是以色列的圣者！</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪下 18:17; 诗篇 20:7; 以赛亚书 10:18"> 你借着使者辱骂主，并且说：“我凭我众多的战车，登上高山之巅，到黎巴嫩最深之处；我要砍下它高大的香柏树和精选的柏树；我要进入它最远的住处，就是它肥美田园的树林。</span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 19:6; 出埃及记 15:9; 撒母耳记下 17:13"> 我挖井喝了异地的水；我要用我的脚掌使埃及的一切河流干涸。”</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 45:7; 以赛亚书 10:5–6; 以赛亚书 37:26–27"> 难道你没有听见吗？我早已做成这事，从古时就形成了它；如今我使它成就，使你得以把坚固城毁坏成荒凉的废堆。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 51:30; 诗篇 102:11; 耶利米书 51:32"> 所以其中的居民力量微弱，惊惶羞愧；他们像田间的草，又像青菜，像房顶上的草，又像未长成就被枯风吹焦的禾稼。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 37:28–29; 耶利米书 23:23–24; 诗篇 139:1–11"> 但你坐下，你出去，你进来，以及你向我发的狂怒，我都知道。</span>
<span className="v" id="v28" data-v="28" data-xref="以西结 29:4; 以西结 38:4; 列王纪下 19:33"> 因为你向我发狂怒，又因为你的傲慢上达到我耳中，所以我必把我的钩子放在你的鼻子里，把我的嚼环放在你的嘴唇中；我必使你从你来的路转回去。』</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="利未记 25:20–22; 列王纪下 20:8–9; 出埃及记 3:12"> “这要作给你的兆头：今年你们要吃自生的，第二年吃从那自生的；第三年你们要撒种收割，栽种葡萄园，吃其中的果子。</span>
<span className="v" id="v30" data-v="30" data-xref="列王纪下 19:4; 以赛亚书 27:6; 历代志下 32:22–23"> 犹大家逃脱剩下的人必再次向下扎根，向上结果。</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 9:7; 罗马书 11:5; 罗马书 9:27"> 因为必有余民从耶路撒冷出去，必有逃脱的人从锡安山出来。耶和华的热心必成就这事。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 8:7–10; 撒母耳记下 20:15; 以赛亚书 37:33–35"> “所以耶和华论亚述王这样说：『他必不来到这城，也不在那里射箭；他必不拿盾牌来到城前，也不筑垒攻城。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪下 19:28; 列王纪下 19:36"> 他从哪条路来，必从哪条路回去，必不来到这城。』这是耶和华说的。</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪上 11:12–13; 列王纪下 20:6; 列王纪上 15:4"> 『因我自己的缘故，也因我仆人大卫的缘故，我必保护这城，拯救这城。』”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="历代志下 32:21–22; 撒母耳记下 24:16; 出埃及记 12:29–30"> 那一夜，耶和华的使者出去，在亚述人的营中击杀了十八万五千人。人们清早起来，看哪，尽都是死尸。</span>
<span className="v" id="v36" data-v="36" data-xref="约拿 1:2; 列王纪下 19:7; 列王纪下 19:33"> 亚述王西拿基立就拔营离去，回去住在尼尼微。</span>
<span className="v" id="v37" data-v="37" data-xref="以斯拉记 4:2; 创世记 8:4; 列王纪下 19:7"> 他在他的神尼斯洛庙里敬拜的时候，亚得米勒和沙利色用刀杀了他；他们逃到亚拉腊地。他的儿子以撒哈顿接续他作王。</span>
</div>
</div>

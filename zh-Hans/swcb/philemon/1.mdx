<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 1:1; 以弗所书 3:1; 腓利门书 1:9"> 基督<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“基督”意思是“受膏者”。">a</a></sup>耶稣的囚徒保罗，和我们的弟兄提摩太，写给我们亲爱的同工腓利门，</span>
<span className="v" id="v2" data-v="2" data-xref="腓立比书 2:25; 歌罗西书 4:17; 罗马书 16:5"> 并写给亲爱的亚腓亚、我们的战友亚基布，以及你家里的教会：</span>
<span className="v" id="v3" data-v="3" data-xref="罗马书 1:7; 以弗所书 1:2; 哥林多后书 13:14"> 愿恩典与平安从我们的父上帝和主耶稣基督临到你们。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="罗马书 1:8; 以弗所书 1:16; 帖撒罗尼迦后书 1:3"> 我在祷告中提到你时，常常感谢我的上帝，</span>
<span className="v" id="v5" data-v="5" data-xref="歌罗西书 1:4; 以弗所书 1:15; 哥林多前书 16:1"> 因为听见你对主耶稣和众圣徒所存的爱心与信心；</span>
<span className="v" id="v6" data-v="6" data-xref="腓立比书 1:9–11; 彼得后书 1:8; 歌罗西书 1:9"> 愿你信心的相交，因认识我们在基督耶稣里所有的一切善事而发挥功效。</span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 7:13; 帖撒罗尼迦前书 3:9; 哥林多后书 7:4"> 弟兄啊，因为众圣徒的心借着你得了舒畅，所以我们因你的爱有许多喜乐和安慰。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦前书 2:6; 哥林多后书 10:8; 哥林多后书 3:12"> 因此，我虽然在基督里大有胆量，可以吩咐你做合宜的事，</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 5:20; 以弗所书 4:1; 罗马书 12:1"> 但为着爱的缘故，我宁愿恳求你；我就是这样的保罗，年老的，如今又是为耶稣基督被囚的。</span>
<span className="v" id="v10" data-v="10" data-xref="歌罗西书 4:9; 哥林多前书 4:15; 提摩太前书 1:2"> 我为我在锁链中所生的孩子阿尼西谋恳求你，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“阿尼西谋”意思是“有用的”。">b</a></sup></span>
<span className="v" id="v11" data-v="11" data-xref="提摩太后书 4:11; 约伯记 30:1–2; 彼得前书 2:10"> 他从前对你没有用处，如今对你和我都有用处。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 6:14–15; 耶利米书 31:20; 马可福音 11:25"> 我现在把他送回去。所以你要接纳他；他就是我自己的心。</span>
<span className="v" id="v13" data-v="13" data-xref="腓立比书 1:7; 以弗所书 3:1; 哥林多前书 16:17"> 我本想把他留在我身边，使他在我为福音所受的锁链中替你服侍我。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 9:7; 历代志上 29:17; 彼得前书 5:2–3"> 但没有你的同意，我什么也不愿意做，好使你的善行不是出于勉强，而是出于自愿。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 50:20; 创世记 45:5–8; 以赛亚书 20:6"> 他暂时与你分离，或许正是为此，好使你永远得着他，</span>
<span className="v" id="v16" data-v="16" data-xref="歌罗西书 3:22; 马太福音 23:8; 哥林多前书 7:22"> 不再是奴隶，而是超过奴隶，是亲爱的弟兄；对我尤其如此，何况对你呢，无论按肉身，还是在主里都是如此。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多后书 8:23; 马太福音 10:40; 腓利门书 1:12"> 所以，如果你把我看作同伴，就接纳他，如同接纳我一样。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 53:4–7"> 他若亏负了你，或欠你什么，都记在我的账上。</span>
<span className="v" id="v19" data-v="19" data-xref="加拉太书 6:11; 加拉太书 5:2; 哥林多前书 4:15"> 我保罗亲笔写下：我必偿还（更不用说，连你自己也是欠我的）。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰三书 1:4; 腓利门书 1:7; 腓利门书 1:12"> 是的，弟兄，愿我在主里从你得喜乐。愿你在主里使我的心得舒畅。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="帖撒罗尼迦后书 3:4; 哥林多后书 2:3; 哥林多后书 7:16"> 我深信你会顺服，所以写信给你，知道你所做的甚至会超过我所说的。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="哥林多后书 1:11; 腓立比书 2:24; 约翰二书 1:12"> 此外，也请为我预备一间客房，因为我盼望因着你们的祷告，我会重新回到你们那里。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="歌罗西书 1:7; 罗马书 16:7; 歌罗西书 4:12"> 在基督耶稣里与我一同被囚的以巴弗问候你，</span>
<span className="v" id="v24" data-v="24" data-xref="提摩太后书 4:10–11; 歌罗西书 4:14; 歌罗西书 4:10"> 我的同工马可、亚里达古、底马和路加也问候你。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="提摩太后书 4:22; 罗马书 16:23; 罗马书 16:20"> 愿我们主耶稣基督的恩典与你的灵同在。阿们。</span>
</div>
</div>

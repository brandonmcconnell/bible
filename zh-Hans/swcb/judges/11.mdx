<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 11:32; 士师记 6:12; 列王纪下 5:1"> 基列人耶弗他是英勇善战的人。他是一个妓女的儿子；基列生了耶弗他。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 12:10; 箴言 2:16; 申命记 23:2"> 基列的妻子也给他生了儿子。妻子的儿子们长大后，就把耶弗他赶出去，对他说：“你不可在我们父亲的家里承受产业，因为你是别的女人的儿子。”</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 9:4; 撒母耳记上 22:2; 撒母耳记下 10:8"> 于是耶弗他逃离他的兄弟，住在陀伯地。有些匪徒聚集到耶弗他那里，跟随他出入。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士师记 10:9"> 过了一些时候，亚扪人攻打以色列。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 118:22–23; 使徒行传 7:35–39; 哥林多前书 1:27–29"> 亚扪人攻打以色列的时候，基列的长老去陀伯地请耶弗他回来。</span>
<span className="v" id="v6" data-v="6"> 他们对耶弗他说：“请你来作我们的统帅，好让我们与亚扪人争战。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="启示录 3:9; 创世记 45:4–5; 以赛亚书 60:14"> 耶弗他对基列的长老说：“你们不是恨我，把我从我父亲的家里赶出去吗？现在你们遭难，为什么来找我呢？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="士师记 10:18; 列王纪上 13:6; 出埃及记 10:17"> 基列的长老对耶弗他说：“因此，我们现在回头来找你，好让你和我们同去，与亚扪人争战。你要作我们基列所有居民的领袖。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数记 32:20–29"> 耶弗他对基列的长老说：“如果你们带我回去与亚扪人争战，耶和华又把他们交在我面前，我就作你们的领袖吗？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 42:5; 创世记 31:50; 耶利米书 29:23"> 基列的长老对耶弗他说：“耶和华要在我们之间作见证；我们必照你的话去做。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="士师记 10:17; 撒母耳记上 10:17; 士师记 20:1"> 于是耶弗他同基列的长老去了，百姓立他作自己的领袖和统帅。耶弗他在米斯巴，把自己所有的话都陈明在耶和华面前。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命记 2:26; 马太福音 18:15–16; 箴言 25:8–9"> 耶弗他派使者去见亚扪人的王，说：“你与我有什么相干，竟到我这里来攻打我的地呢？”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 32:22; 民数记 21:24–26; 申命记 2:37"> 亚扪人的王回答耶弗他的使者说：“因为以色列从埃及上来的时候，夺去了我的地，从亚嫩河直到雅博河，又到约旦河。现在请和平地归还这些地区。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="彼得前书 3:11; 罗马书 12:18; 希伯来书 12:14"> 耶弗他又派使者去见亚扪人的王；</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 2:19; 申命记 2:9; 民数记 21:27–30"> 他对他说：“耶弗他说：以色列并没有夺取摩押地，也没有夺取亚扪人的地；</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 14:25; 申命记 1:40; 民数记 20:1"> 以色列从埃及上来以后，经过旷野到红海，又来到加低斯。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 20:14–21; 申命记 2:4–9; 民数记 20:1"> 那时，以色列派使者去见以东王，说：‘请让我们经过你的地。’可是以东王不听。同样，以色列又派人去见摩押王，他也不肯；于是以色列就留在加低斯。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 2:1–8; 民数记 22:36; 民数记 21:4–13"> 后来他们经过旷野，绕过以东地和摩押地，来到摩押地的东边，在亚嫩河的另一边安营；他们没有进入摩押的境内，因为亚嫩河是摩押的边界。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 21:21–35; 申命记 2:26–36; 申命记 3:1–17"> 以色列派使者去见亚摩利人的王、西宏，就是希实本王；以色列对他说：‘请让我们经过你的地，到我的地方去。’</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 13:15–32; 民数记 21:23–25; 诗篇 136:17–21"> 但是西宏不放心让以色列经过他的境界；西宏反而召集他的众民，在雅杂安营，与以色列争战。</span>
<span className="v" id="v21" data-v="21"> 耶和华以色列的上帝，把西宏和他的众民都交在以色列手中，以色列就击败了他们。于是以色列占有了那地居民亚摩利人的全地。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 2:36"> 他们占有了亚摩利人的全境，从亚嫩河直到雅博河，从旷野直到约旦河。</span>
<span className="v" id="v23" data-v="23"> 现在，耶和华以色列的上帝已经把亚摩利人从祂子民以色列面前赶出，你还要占有他们的地吗？</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 21:29; 诗篇 78:55; 弥迦书 4:5"> 你的神基抹赐给你去占有的，你岂不占有吗？照样，凡耶和华我们的上帝从我们面前赶出的，我们也要占有他们的地。</span>
<span className="v" id="v25" data-v="25" data-xref="弥迦书 6:5; 约书亚记 24:9–10; 申命记 23:3–4"> 现在，难道你比摩押王、西拨的儿子巴勒还强吗？他岂曾与以色列争执，或岂曾与他们争战呢？</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 2:36; 约书亚记 12:5; 士师记 10:8"> 以色列住在希实本和所属的乡镇，亚罗珥和所属的乡镇，以及亚嫩河沿岸的一切城邑，已经三百年了！在那段期间，你们为什么没有收回这些地方呢？</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 24:15; 创世记 16:5; 撒母耳记上 24:12"> 所以我没有得罪你，倒是你攻打我，亏待我。愿审判者耶和华今日在以色列人与亚扪人之间施行审判。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王纪下 14:11; 箴言 16:18"> 然而，亚扪人的王不听耶弗他传给他的话。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 11:25; 士师记 3:10; 士师记 13:25"> 耶和华的灵降在耶弗他身上，他就经过基列和玛拿西，又经过基列的米斯巴；他从基列的米斯巴前往亚扪人那里。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="创世记 28:20; 撒母耳记上 1:11; 传道书 5:1–2"> 耶弗他向耶和华许愿，说：“你若果真把亚扪人交在我手中，</span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 66:13–14; 利未记 27:28–29; 撒母耳记上 1:28"> 那么，当我从亚扪人那里平安回来时，从我家门出来迎接我的，无论是谁，都必归耶和华；我也必把他献上为燔祭。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="士师记 1:4; 士师记 2:18; 士师记 3:10"> 于是耶弗他前往亚扪人那里，与他们争战；耶和华把他们交在他手中。</span>
<span className="v" id="v33" data-v="33" data-xref="以西结 27:17; 申命记 2:36"> 他大大击杀他们，从亚罗珥直到米匿，共二十座城，又直到亚伯基拉明。这样，亚扪人在以色列人面前被制伏了。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="耶利米书 31:4; 出埃及记 15:20; 士师记 10:17"> 耶弗他回到米斯巴，到了自己的家；看哪，他的女儿出来迎接他，拿着铃鼓跳舞。她是他的独生女；除此以外，他没有儿子，也没有女儿。</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 14:7–9; 创世记 37:29–30; 创世记 42:36–38"> 他一看见她，就撕裂衣服，说：“哀哉，我的女儿啊！你使我极其痛苦，也成了使我烦恼的人；因为我已经向耶和华开了口，不能收回。”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="撒母耳记下 18:19; 腓立比书 2:30; 罗马书 16:4"> 她对他说：“我的父亲啊，你既然已经向耶和华开了口，就照你口中所说的待我吧，因为耶和华已经为你向你的仇敌，就是亚扪人报了仇。”</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 1:25; 撒母耳记上 1:6"> 她又对父亲说：“求你准我这件事：给我两个月，让我离开，到山中去，为我的童贞哀哭，我和我的同伴一起去。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> 他说：“你去吧。”他就让她离开两个月；她和她的同伴去了，在山中为自己的童贞哀哭。</span>
<span className="v" id="v39" data-v="39" data-xref="以赛亚书 66:3; 士师记 11:31; 利未记 27:28–29"> 两个月结束后，她回到父亲那里；父亲就照他所许的愿待她。她没有亲近过男子。这在以色列中成了一个习俗：</span>
<span className="v" id="v40" data-v="40" data-xref="列王纪上 9:25; 士师记 5:11"> 以色列的女子每年去纪念基列人耶弗他的女儿，每年四天。</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 9:26–29; 士师记 2:19–20; 士师记 2:13–14"> 以色列人行耶和华眼中看为恶的事，所以耶和华把他们交在米甸手中七年。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:38; 撒母耳记上 13:6; 申命记 28:47–48"> 米甸的手胜过以色列；因为米甸的缘故，以色列人为自己在山中造了洞穴、山洞和堡垒。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 6:33; 士师记 3:13; 士师记 7:12"> 每当以色列人撒种之后，米甸人、亚玛力人和东方人就上来攻击他们。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 26:16; 申命记 28:51; 弥迦书 6:15"> 他们对着以色列人安营，毁坏地上的出产，直到迦萨；他们没有给以色列留下任何维生之物，羊、牛、驴也没有留下。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 7:12; 士师记 8:10; 耶利米书 46:23"> 因为他们带着牲畜和帐棚上来；他们人数众多，像蝗虫一样。他们和他们的骆驼都数不胜数；他们进入那地，要毁坏它。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 3:9; 耶利米书 5:17; 诗篇 50:15"> 以色列因米甸的缘故极其衰微；以色列人就向耶和华呼求。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 以色列人因米甸的缘故向耶和华呼求的时候，</span>
<span className="v" id="v8" data-v="8" data-xref="以西结 20:5–32; 以赛亚书 63:9–14; 诗篇 136:10–16"> 耶和华差遣一位先知到以色列人那里；他对他们说：“耶和华——以色列的上帝——如此说：‘我曾带你们从埃及上来，把你们从为奴之家带出来。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 44:2–3"> 我救你们脱离埃及人的手，也脱离一切欺压你们之人的手；我把他们从你们面前赶出去，把他们的地赐给你们。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 10:2; 列王纪下 17:35–39; 耶利米书 9:13"> 我对你们说：“我是耶和华你们的上帝。你们居住在亚摩利人的地，不可敬畏他们的神明。”可是你们没有听从我的声音。’”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约书亚记 17:2; 希伯来书 11:32; 士师记 13:3"> 耶和华的使者来到俄弗拉，在亚比以谢人约阿施所有的橡树下坐着。约阿施的儿子基甸正在榨酒池里打麦子，为要躲避米甸人。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 1:5; 路加福音 1:28; 士师记 2:18"> 耶和华的使者向他显现，对他说：“大能的勇士啊，耶和华与你同在！”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="诗篇 77:7–9; 历代志下 15:2; 以赛亚书 59:1–2"> 基甸对他说：“唉，我主啊，如果耶和华与我们同在，为什么这一切事临到我们呢？我们的祖先告诉我们说：‘耶和华岂不是带我们从埃及上来吗？’祂一切奇妙的作为在哪里呢？可是现在耶和华丢弃了我们，把我们交在米甸手中。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="约书亚记 1:5–9; 希伯来书 11:34; 撒母耳记上 12:11"> 耶和华看着他说：“你靠着你这能力去，从米甸手中拯救以色列。我岂不是差遣你了吗？”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 9:21; 出埃及记 3:11; 出埃及记 4:10"> 他对祂说：“主啊，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="译作“主”的词是“Adonai”。">a</a></sup>我怎能拯救以色列呢？看哪，我的家族在玛拿西中最贫弱，我在我父家也是最小的。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约书亚记 1:5; 出埃及记 3:12; 使徒行传 11:21"> 耶和华对他说：“我必与你同在，你必击打米甸人，如击打一人一样。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="诗篇 86:17; 出埃及记 33:13; 以赛亚书 7:11"> 他对祂说：“我若在你眼前蒙恩，就请给我一个记号，证明是你在与我说话。</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 13:15; 创世记 18:3; 创世记 18:5"> 请你不要离开这里，等我到你这里来，把我的礼物带出来，摆在你面前。”<br />祂说：“我会等到你回来。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="创世记 18:6–8; 士师记 13:15–19; 利未记 2:4"> 基甸进去，预备了一只山羊羔，又用一伊法<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="1伊法约为22升，或约为2/3蒲式耳">b</a></sup>细面做了无酵饼。他把肉放在篮子里，把汤放在锅里，带到橡树下给祂，献在祂面前。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="士师记 13:19; 列王纪上 18:33–34"> 上帝的使者对他说：“把肉和无酵饼拿来，放在这块磐石上，把汤倒出来。”<br />他就这样做了。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 9:24; 列王纪上 18:38; 历代志下 7:1"> 于是耶和华的使者伸出手中杖的顶端，碰了肉和无酵饼；火就从磐石中上来，烧尽了肉和无酵饼。耶和华的使者就从他眼前离去了。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="创世记 32:30; 出埃及记 33:20; 申命记 5:26"> 基甸看出祂是耶和华的使者；基甸说：“哀哉，主耶和华啊！因为我面对面看见了耶和华的使者！”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="但以理 10:19; 约翰福音 20:26; 创世记 43:23"> 耶和华对他说：“愿你平安！不要害怕。你不会死。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="创世记 22:14; 出埃及记 17:15; 士师记 8:32"> 于是基甸在那里为耶和华筑了一座祭坛，称它为“耶和华是平安”。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作“沙龙”">c</a></sup>直到今日，它还在亚比以谢人的俄弗拉。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及记 34:13; 士师记 3:7; 使徒行传 5:29"> 当夜，耶和华对他说：“取你父亲的公牛，就是那第二头七岁的公牛，拆毁你父亲所有的巴力祭坛，砍倒旁边的亚舍拉神柱。</span>
<span className="v" id="v26" data-v="26" data-xref="哥林多前书 14:40; 撒母耳记下 24:18; 哥林多前书 14:33"> 然后在这堡垒顶上，按规矩为耶和华你的上帝筑一座祭坛；取那第二头公牛，用你所砍倒的亚舍拉神柱作柴，献为燔祭。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="帖撒罗尼迦前书 2:4; 约翰福音 2:5; 申命记 4:1"> 于是基甸从他的仆人中带了十个人，照耶和华对他说的去做。他因惧怕父家和城里的人，不敢在白天做这事，就在夜间做了。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 城里的人清早起来，看哪，巴力的祭坛被拆毁了，旁边的亚舍拉神柱被砍倒了，那第二头公牛献在新筑的祭坛上。</span>
<span className="v" id="v29" data-v="29"> 他们彼此说：“谁做了这事？”<br />他们查问搜寻以后，就说：“这是约阿施的儿子基甸做的。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="使徒行传 26:9; 腓立比书 3:6; 耶利米书 50:38"> 城里的人对约阿施说：“把你的儿子带出来，他必须死，因为他拆毁了巴力的祭坛，又砍倒了旁边的亚舍拉神柱。”</span>
<span className="v" id="v31" data-v="31" data-xref="耶利米书 10:11; 哥林多前书 8:4; 以弗所书 5:11"> 约阿施对所有站着反对他的人说：“你们要为巴力争辩吗？你们要救他吗？凡为他争辩的，愿他到早晨以前被处死！他若是神，有人拆毁了他的祭坛，就让他为自己争辩吧！”</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 12:11; 士师记 7:1; 撒母耳记下 11:21"> 因此那一天，约阿施给他起名叫耶路巴力，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“耶路巴力”的意思是“让巴力争辩”。">d</a></sup>说：“让巴力与他争辩吧，因为他拆毁了巴力的祭坛。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约书亚记 17:16; 士师记 6:3; 罗马书 8:35–39"> 那时，所有米甸人、亚玛力人和东方人都聚集起来；他们渡过来，在耶斯列谷安营。</span>
<span className="v" id="v34" data-v="34" data-xref="士师记 3:27; 历代志下 24:20; 士师记 3:10"> 但耶和华的灵临到基甸，他就吹响号角；亚比以谢人就聚集起来跟随他。</span>
<span className="v" id="v35" data-v="35" data-xref="历代志下 30:6–12; 士师记 4:6"> 他派使者走遍玛拿西全地，他们也聚集起来跟随他。他又派使者到亚设、西布伦和拿弗他利；他们就上来与他们会合。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="士师记 6:14; 马太福音 16:1; 士师记 6:17–20"> 基甸对上帝说：“你若照你所说的，要藉我的手拯救以色列，</span>
<span className="v" id="v37" data-v="37" data-xref="何西阿 14:5; 马太福音 10:5–6; 马太福音 15:24"> 看哪，我要把一团羊毛放在禾场上。如果只有羊毛上有露水，而整个地面都是干的，我就知道你要照你所说的，藉我的手拯救以色列。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="以赛亚书 35:7"> 事情果然如此；第二天他清早起来，挤压那团羊毛，从羊毛中拧出露水，满了一碗水。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="创世记 18:32; 以赛亚书 50:2; 诗篇 107:33–35"> 基甸对上帝说：“求你不要向我发怒，容我只再说这一次。请让我只用这团羊毛再试一次。现在只让羊毛是干的，而整个地面都有露水。”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40"> 那夜，上帝就这样做了；只有羊毛是干的，而整个地面都有露水。</span>
</div>
</div>

</div>

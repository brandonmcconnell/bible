<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 17:6; 士师记 19:1; 士师记 1:34"> 那些日子，以色列中没有王。那些日子，但人的支派寻求可居住的产业；因为直到那日，他们在以色列各支派中还没有完全得着自己的产业。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 13:25; 约书亚记 2:1; 士师记 18:11"> 但的子孙从他们全族中，从琐拉和以实陶，派出五个勇士去窥探那地，查察那地。他们对他们说：“去，查察那地！”<br />他们来到以法莲山地，到了米迦的家，就在那里住宿。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 12:6; 创世记 27:22; 马太福音 26:73"> 他们在米迦家附近时，认出那个年轻利未人的声音；于是他们转到那里，对他说：“谁带你到这里来？你在这地方做什么？你在这里有什么？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士师记 17:10; 以西结 13:19; 箴言 28:21"> 他对他们说：“米迦如此如此待我，又雇了我，我就作了他的祭司。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="使徒行传 8:10; 以赛亚书 30:1; 列王纪上 22:5"> 他们对他说：“请你求问上帝，使我们知道我们所走的路是否顺利。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王纪上 22:6; 列王纪上 22:15; 诗篇 33:18"> 祭司对他们说：“平平安安地去吧。你们所走的路是在耶和华面前。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约书亚记 19:47; 士师记 18:27–28; 撒母耳记上 3:13"> 于是那五个人离开，来到拉亿，看见住在那里的人安然居住，像西顿人一样，安静稳妥；那地没有掌权的人能在任何事上使他们蒙羞，他们又离西顿人很远，与别人没有来往。</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 18:11; 士师记 18:2; 士师记 13:2"> 他们回到琐拉和以实陶，来到他们的弟兄那里；他们的弟兄问他们：“你们怎么说？”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约书亚记 2:23–24; 民数记 13:30; 约书亚记 18:3"> 他们说：“起来，我们上去攻打他们吧！因为我们已经看见那地，看哪，那地非常好。你们还静坐不动吗？不要懒惰，要去进入那地，占有它。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 18:27; 士师记 18:7; 申命记 2:29"> 你们去的时候，会来到一群毫无防备的百姓那里；那地宽阔，因为上帝已经把它交在你们手中，是一个地上所需一无所缺的地方。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="士师记 18:16"> 于是但人的家族从琐拉和以实陶出发，有六百人佩带兵器。</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 13:25; 约书亚记 15:60; 历代志下 1:4"> 他们上去，在犹大的基列·耶琳安营。因此那地方直到今日还称为玛哈尼·但。看哪，它在基列·耶琳的后面。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 24:30; 士师记 19:1; 士师记 18:2–3"> 他们从那里往以法莲山地去，来到米迦的家。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="士师记 17:5; 士师记 18:3–4; 撒母耳记上 14:28"> 那时，曾去窥探拉亿之地的五个人回应他们的弟兄说：“你们知道这些屋子里有以弗得、特拉芬<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="特拉芬是家中的偶像，可能与家庭财产的继承权有关。">a</a></sup>、雕刻的像和铸成的像吗？现在你们要想想该做什么。”</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 43:27; 撒母耳记上 17:22; 约翰福音 14:27"> 他们转到那里，来到那个年轻利未人的家，就是米迦的家，向他问安。</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 18:11"> 那六百个佩带兵器、属于但子孙的人，站在门口。</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 18:14; 士师记 17:4–5; 士师记 18:2"> 那五个去窥探那地的人上去，进入那里，拿走雕刻的像、以弗得、特拉芬和铸成的像；祭司则同那六百个佩带兵器的人站在门口。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 这些人进了米迦的家，拿走雕刻的像、以弗得、特拉芬和铸成的像时，祭司对他们说：“你们在做什么？”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约伯记 29:9; 约伯记 21:5; 士师记 17:10"> 他们对他说：“安静，把手放在口上，跟我们走，作我们的父亲和祭司。你作一个人家的祭司好呢，还是作以色列一个支派、一个家族的祭司好呢？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 56:11; 以西结 13:19; 箴言 30:15"> 祭司心里欢喜，就拿起以弗得、特拉芬和雕刻的像，进入众人中间。</span>
<span className="v" id="v21" data-v="21"> 于是他们转身离开，把孩童、牲畜和财物放在前面。</span>
<span className="v" id="v22" data-v="22"> 他们离米迦的家已有相当一段距离时，住在米迦家附近屋子里的人都聚集起来，追上了但的子孙。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 114:5; 撒母耳记下 14:5; 撒母耳记上 11:5"> 他们向但的子孙呼喊；但人转过脸来，对米迦说：“你有什么事，竟带着这么一群人来呢？”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="哈巴谷 2:18–19; 以赛亚书 44:18–20; 诗篇 115:8"> 他说：“你们把我所造的神像和祭司都带走了！我还剩下什么呢？你们怎么还问我：‘你有什么事？’”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约伯记 27:2; 约伯记 3:5; 撒母耳记上 30:6"> 但的子孙对他说：“不要让我们听见你的声音，免得性情暴躁的人攻击你，使你和你全家的人丧命。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 但的子孙继续走他们的路；米迦见他们比自己强，就转身回自己的家去了。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 19:47; 士师记 18:7; 士师记 18:10"> 他们带着米迦所造的东西和他所有的祭司，来到拉亿，到一群安静、毫无防备的百姓那里，用刀剑击杀他们，又放火烧了那城。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 10:6; 士师记 18:7; 民数记 13:21"> 没有人拯救，因为那城离西顿很远，他们又与别人没有来往；那城在伯·利合旁边的谷中。他们重建那城，并住在其中。</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 19:47; 创世记 14:14; 列王纪上 15:20"> 他们照着他们祖先但的名字，给那城起名叫但；但生于以色列。然而那城从前名叫拉亿。</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 4:10–11; 士师记 13:1; 士师记 17:5"> 但的子孙为自己立起那雕刻的像；摩西的孙子、革舜的儿子约拿单，以及他的儿子们，作但人支派的祭司，直到那地被掳的日子。</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 18:1; 撒母耳记上 1:3; 士师记 19:18"> 这样，他们为自己立起米迦所造的雕刻的像；上帝的殿在示罗的整个时期，那像一直在那里。</span>
</div>
</div>

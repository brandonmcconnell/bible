<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 11:11; 撒母耳记上 3:20; 撒母耳记上 10:17"> 于是以色列众人都出来，会众如同一人聚集，从但直到别示巴，连同基列地，都到米斯巴耶和华那里。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 8:10; 士师记 20:17; 士师记 20:15"> 全体百姓的首领，就是以色列各支派的首领，都站在上帝子民的会中；拔刀的步兵共有四十万人。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 19:22–27; 路加福音 14:31–32; 路加福音 12:58–59"> （便雅悯人听见以色列人上了米斯巴。）以色列人说：“请告诉我们，这恶事是怎样发生的？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士师记 19:15–28"> 那被杀妇人的丈夫利未人回答说：“我和我的妾来到属便雅悯的基比亚，要在那里过夜。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 19:22; 士师记 19:25–26; 创世记 19:4–8"> 基比亚人起来攻击我，夜里围住房子。他们想要杀我，又强暴了我的妾，她就死了。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 19:29; 约书亚记 7:15; 士师记 19:23"> 我把我的妾切成块，送遍以色列产业的全境，因为他们在以色列中行了淫乱和愚妄的事。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 19:30; 哥林多前书 5:6; 哥林多前书 5:10–12"> 看哪，你们都是以色列人，请在这里提出你们的意见和计策。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="传道书 9:10; 士师记 20:1; 箴言 21:3"> 众人都如同一人起来，说：“我们没有一个人要回自己的帐棚，也没有一个人要转回自己的家。</span>
<span className="v" id="v9" data-v="9" data-xref="约拿 1:7; 尼希米记 11:1; 约书亚记 14:2"> 现在我们要这样对付基比亚：我们要抽签上去攻打它；</span>
<span className="v" id="v10" data-v="10"> 我们要在以色列各支派中，每一百人取十人，每一千人取一百人，每一万人取一千人，为百姓取粮；使他们到了便雅悯的基比亚，可以照基比亚人在以色列中所行的一切愚妄事对付他们。”</span>
<span className="v" id="v11" data-v="11"> 于是以色列众人聚集，攻击那城，联合如同一人。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命记 13:14; 申命记 20:10; 罗马书 12:18"> 以色列各支派派人走遍便雅悯全支派，说：“你们中间发生的这恶事是什么呢？</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 17:12; 申命记 13:13; 士师记 19:22"> 现在，把在基比亚的那些人，就是那些恶徒，交出来，我们好处死他们，从以色列中除掉恶。”<br />可是便雅悯人不肯听从他们弟兄以色列人的话。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 20:20; 约伯记 15:25–26; 民数记 21:23"> 便雅悯人从各城聚集到基比亚，要出去与以色列人争战。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 26:41; 士师记 20:25; 民数记 1:37"> 那日，从各城来的便雅悯人被数点，拔刀的共有二万六千人，此外还有基比亚的居民，被数点有七百名精选的人。</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 3:15; 历代志上 12:2; 撒母耳记上 17:49–50"> 在这些士兵中，有七百名精选的人惯用左手；他们每一个人都能用机弦甩石打中一根头发，也不偏差。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 1:46; 历代志下 17:14–18; 民数记 26:51"> 除了便雅悯以外，以色列人被数点，拔刀的共有四十万人；这些都是战士。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="士师记 20:23; 士师记 20:26–27; 民数记 27:21"> 以色列人起来，上伯特利去求问上帝。他们问：“我们中间谁当先上去，与便雅悯人争战？”<br />耶和华说：“犹大先去。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约书亚记 7:16; 约书亚记 3:1; 约书亚记 6:12"> 以色列人清早起来，对着基比亚安营。</span>
<span className="v" id="v20" data-v="20"> 以色列人出去，要与便雅悯争战；以色列人在基比亚摆阵，攻击他们。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 20:25; 诗篇 73:18–19; 历代志下 28:10"> 便雅悯人从基比亚出来，那日把以色列人二万二千人杀倒在地。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 64:5; 士师记 20:17; 撒母耳记上 30:6"> 百姓，就是以色列人，鼓起勇气，又在第一天摆阵的地方再次摆阵。</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 20:26–27; 诗篇 78:34–36; 约书亚记 7:6"> 以色列人上去，在耶和华面前哭泣直到晚上；他们求问耶和华说：“我们还要再上前去，与我的弟兄便雅悯人争战吗？”<br />耶和华说：“上去攻打他。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 第二天，以色列人上前去攻击便雅悯人。</span>
<span className="v" id="v25" data-v="25" data-xref="士师记 20:21; 创世记 18:25; 罗马书 2:5"> 第二天，便雅悯从基比亚出来迎击他们，又把以色列人一万八千人杀倒在地；这些人都是拔刀的。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="士师记 20:23; 约珥 2:12–18; 士师记 20:18"> 于是以色列众人和全体百姓都上伯特利去，在那里哭泣，坐在耶和华面前，那日禁食直到晚上；然后他们在耶和华面前献上燔祭和平安祭。</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 18:1; 士师记 20:18; 撒母耳记上 4:3–4"> 以色列人求问耶和华（因为上帝的约柜那些日子在那里，</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 7:9; 约书亚记 24:33; 申命记 18:5"> 亚伦的孙子、以利亚撒的儿子非尼哈，那些日子侍立在约柜前），说：“我们还要再出去，与我的弟兄便雅悯人争战呢，还是停止呢？”<br />耶和华说：“上去；因为明天我必把他交在你手中。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约书亚记 8:4; 撒母耳记下 5:23; 士师记 20:34"> 以色列人在基比亚四围设下伏兵。</span>
<span className="v" id="v30" data-v="30"> 第三天，以色列人上去攻击便雅悯人，照前几次一样，对着基比亚摆阵。</span>
<span className="v" id="v31" data-v="31" data-xref="士师记 19:13–14; 约书亚记 7:5; 以赛亚书 10:29"> 便雅悯人出来迎击百姓，被引离那城；他们照前几次一样，在田野间的大路上开始击杀百姓，其中一条路上伯特利，另一条路通基比亚，杀了约三十名以色列人。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="约书亚记 8:15–16"> 便雅悯人说：“他们像起初一样在我们面前被击倒了。”但以色列人说：“我们逃跑，把他们从城里引到大路上。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约书亚记 8:18–22"> 以色列众人都从自己的地方起来，在巴力·他玛摆阵。以色列的伏兵也从自己的地方，就是从玛利·迦巴，冲出来。</span>
<span className="v" id="v34" data-v="34" data-xref="约书亚记 8:14; 以赛亚书 47:11; 约伯记 21:13"> 从全以色列中有一万名精选的人来到基比亚对面，战斗十分激烈；但便雅悯人不知道灾祸已经临近他们。</span>
<span className="v" id="v35" data-v="35" data-xref="约伯记 20:5; 士师记 20:15; 士师记 20:44–46"> 耶和华在以色列面前击败便雅悯；那日以色列人杀灭便雅悯人二万五千一百名；这些人都是拔刀的。</span>
<span className="v" id="v36" data-v="36" data-xref="约书亚记 8:15–29"> 于是便雅悯人看出自己被击败了，因为以色列人在便雅悯人面前退让，是因他们倚靠所设下、攻击基比亚的伏兵。</span>
<span className="v" id="v37" data-v="37" data-xref="约书亚记 8:19; 约书亚记 6:5; 出埃及记 19:13"> 伏兵急忙冲向基比亚；伏兵展开攻势，用刀刃击杀全城。</span>
<span className="v" id="v38" data-v="38" data-xref="约书亚记 8:20; 创世记 17:21; 列王纪下 4:16"> 以色列人与伏兵约定的信号，是要使一大团烟云从城中升起。</span>
<span className="v" id="v39" data-v="39" data-xref="士师记 20:32"> 以色列人在战场上转身，便雅悯开始击杀以色列人，约有三十人；因为他们说：“他们在我们面前必定被击倒，像第一次战斗一样。”</span>
<span className="v" id="v40" data-v="40" data-xref="约书亚记 8:20; 启示录 19:3; 创世记 19:28"> 但当烟云开始从城中升起，成为烟柱的时候，便雅悯人回头观看；看哪，全城的烟冲天而上。</span>
<span className="v" id="v41" data-v="41" data-xref="彼得后书 2:12; 路加福音 21:26; 启示录 6:15–17"> 以色列人转身，便雅悯人就惊惶，因为他们看见灾祸已经临到自己。</span>
<span className="v" id="v42" data-v="42" data-xref="约书亚记 8:15; 何西阿 9:9; 耶利米哀歌 1:3"> 因此他们在以色列人面前转身，往旷野的路逃跑；但战斗紧紧追赶他们，从各城出来的人也在其中消灭他们。</span>
<span className="v" id="v43" data-v="43" data-xref="约书亚记 8:20–22"> 他们围住便雅悯人，追赶他们，在他们歇脚之处践踏他们，直到基比亚附近、朝日出的方向。</span>
<span className="v" id="v44" data-v="44"> 便雅悯人倒下了一万八千人；这些都是勇士。</span>
<span className="v" id="v45" data-v="45" data-xref="约书亚记 15:32; 士师记 21:13; 撒迦利亚书 14:10"> 他们转身，往旷野逃到临门磐石。以色列人在大路上扫荡了他们五千人，又紧紧追赶他们直到基顿，击杀了他们二千人。</span>
<span className="v" id="v46" data-v="46" data-xref="士师记 20:35; 士师记 20:15"> 这样，那日便雅悯人倒下的，共有二万五千名拔刀的人；这些都是勇士。</span>
<span className="v" id="v47" data-v="47" data-xref="以赛亚书 1:9; 诗篇 103:9–10; 哈巴谷 3:2"> 但有六百人转身，往旷野逃到临门磐石，在临门磐石住了四个月。</span>
<span className="v" id="v48" data-v="48" data-xref="申命记 13:15–17; 历代志下 25:13; 历代志下 28:6–9"> 以色列人又转向便雅悯人，用刀刃击杀他们——包括整座城、牲畜，以及他们所遇见的一切。此外，他们还放火烧了所遇见的一切城。</span>
</div>
</div>

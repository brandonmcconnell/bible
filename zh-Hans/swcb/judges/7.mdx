<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 6:32; 传道书 9:10; 创世记 12:6"> 耶路巴力，就是基甸，和所有跟随他的人清早起来，在哈律泉旁安营。米甸人的营在他们北边，靠近谷中的摩利山。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 8:17; 哥林多前书 1:27–29; 哥林多后书 4:7"> 耶和华对基甸说：“跟随你的人太多，我不能将米甸人交在他们手中，免得以色列向我夸口说：‘是我自己的手救了我。’</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 20:8; 启示录 17:14; 启示录 21:8"> 现在你要宣告给百姓听，说：‘凡惧怕战兢的，可以从基列山回去离开。’”于是百姓中有二万二千人回去，只剩下一万人。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="诗篇 33:16; 撒母耳记上 16:7; 撒母耳记上 14:6"> 耶和华对基甸说：“人还是太多。你带他们下到水边，我要在那里为你试验他们。我对你说‘这人可以跟你去’的，他就可以跟你去；我对你说‘这人不可跟你去’的，他就不可去。”</span>
<span className="v" id="v5" data-v="5"> 于是基甸带百姓下到水边；耶和华对基甸说：“凡用舌头舔水、像狗舔水一样的，你要把他单独分在一边；凡跪下喝水的，也要如此。”</span>
<span className="v" id="v6" data-v="6"> 用手捧到口边舔水的，共有三百人；其余的百姓都跪下喝水。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 14:6; 以赛亚书 41:14–16; 士师记 7:18–22"> 耶和华对基甸说：“我要用这三百个舔水的人拯救你们，把米甸人交在你手中。其余的百姓都可以各归各处。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约书亚记 6:20; 民数记 10:9; 约书亚记 6:4"> 于是百姓手里拿着食物和号角；基甸打发其余的以色列人各回自己的帐棚，只留下那三百人。米甸营在他下方的谷中。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 46:2–3; 士师记 3:28; 使徒行传 18:9–10"> 当夜，耶和华对他说：“起来，下到营里去，因为我已经把那营交在你手中。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 4:10–14; 士师记 4:8–9"> 如果你害怕下去，就带你的仆人普拉一同下到营里。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 6:10; 士师记 7:13–15; 以赛亚书 35:3–4"> 你会听见他们所说的话；以后你的手就必刚强，可以下到营里去。”于是基甸带着他的仆人普拉，下到营中武装人员的最外围。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="士师记 8:10; 士师记 6:5; 约书亚记 11:4"> 米甸人、亚玛力人和所有东方人都横卧在谷中，多如蝗虫；他们的骆驼无数，多如海边的沙。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 1:27; 以赛亚书 41:14–15; 士师记 4:9"> 基甸到了，看哪，有一个人正在把梦讲给同伴听。他说：“看哪，我做了一个梦；看哪，有一个大麦饼滚进米甸营中，来到帐棚前，撞击帐棚，使帐棚倒塌，翻转倾覆，帐棚就平伏在地。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王纪下 7:6–7; 约书亚记 2:9; 约书亚记 2:24"> 他的同伴回答说：“这不是别的，正是以色列人约阿施的儿子基甸的刀。上帝已经把米甸和全军都交在他手中。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="哥林多后书 10:4–6; 创世记 40:8; 历代志下 20:18–19"> 基甸听见那梦的叙述和解释，就敬拜。随后他回到以色列营中，说：“起来吧，因为耶和华已经把米甸的军队交在你们手中！”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="哥林多后书 4:7"> 他把三百人分成三队，把号角和空瓶交在他们每个人手中，瓶里藏着火把。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 11:1; 马太福音 16:24; 希伯来书 13:7"> 他对他们说：“你们看着我，照我所做的去做。看哪，我到了营的最外围时，我怎样做，你们也要怎样做。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 20:15–17; 撒母耳记上 17:47"> 我和所有跟随我的人吹号角的时候，你们也要在全营四围吹号角，并且呼喊：‘为耶和华！为基甸！’”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="诗篇 2:9; 出埃及记 14:24; 马太福音 25:6"> 基甸和跟随他的一百人，在中更开始、敌人刚换更的时候，来到营的最外围。他们就吹号角，打碎手中的瓶。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 27:13; 哥林多后书 4:7; 哥林多前书 15:52"> 三队的人都吹号角，打碎瓶，左手拿着火把，右手拿着号角吹奏；他们呼喊说：“耶和华和基甸的刀！”</span>
<span className="v" id="v21" data-v="21" data-xref="历代志下 20:17; 箴言 28:1; 列王纪下 7:6–7"> 他们各自站在营的四围；敌军全营都奔跑起来；他们呐喊，使敌人逃散。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 4:12; 约书亚记 6:20; 约书亚记 6:4"> 三百人吹响号角，耶和华使全军中各人的刀彼此相击，攻击全军；军队就逃跑，直到通往洗利拉的伯示他，直到靠近他巴的亚伯米何拉边界。</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 6:35; 撒母耳记上 14:21–22"> 以色列人从拿弗他利、亚设和全玛拿西聚集起来，追赶米甸。</span>
<span className="v" id="v24" data-v="24" data-xref="士师记 3:27–28; 腓立比书 1:27; 罗马书 15:30"> 基甸差遣使者走遍以法莲全山地，说：“你们下来攻击米甸人，在他们前面夺取水源，直到伯巴拉，直到约旦河！”于是所有以法莲人都聚集起来，夺取水源，直到伯巴拉，直到约旦河。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 10:26; 士师记 8:3–4; 诗篇 83:11–12"> 他们擒获了米甸的两个首领俄立和西伊伯。他们在俄立磐石杀了俄立，在西伊伯酒榨杀了西伊伯；他们追赶米甸，并把俄立和西伊伯的首级带过约旦河，送到基甸那里。</span>
</div>
</div>

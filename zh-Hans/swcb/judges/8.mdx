<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 19:41; 士师记 12:1–6; 约伯记 5:2"> 以法莲人对他说：“你去与米甸争战的时候没有召我们，你为什么这样待我们呢？”他们就严厉地责备他。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 13:4–7; 腓立比书 2:2–3; 雅各书 3:13–18"> 他对他们说：“我如今所做的，与你们相比算什么呢？以法莲所拾剩的葡萄，不是胜过亚比以谢所收的葡萄吗？</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 15:1; 士师记 7:24–25; 约翰福音 4:37"> 上帝已把米甸的首领俄立和西伊伯交在你们手中！我所能做的，与你们相比算什么呢？”他说了这话，他们对他的怒气就消了。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="加拉太书 6:9; 哥林多后书 4:16; 撒母耳记上 14:28–29"> 基甸来到约旦河，就过了河；他和跟随他的三百人虽然疲乏，却仍追赶。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 33:17; 诗篇 60:6; 撒母耳记上 25:18"> 他对疏割人说：“请给跟随我的人一些饼，因为他们疲乏了；我正在追赶米甸的两个王西巴和撒慕拿。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="列王纪上 20:11; 腓立比书 2:21; 箴言 18:23"> 疏割的首领说：“西巴和撒慕拿的手现在已经在你手里了吗？我们为什么要给你的军队饼呢？”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="士师记 7:15"> 基甸说：“既然这样，等耶和华把西巴和撒慕拿交在我手中以后，我就要用旷野的荆棘和蒺藜撕裂你们的肉。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="创世记 32:30–31; 列王纪上 12:25"> 他从那里上到毗努伊勒，也照样对他们说；毗努伊勒人回答他，像疏割人回答的一样。</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 8:17; 列王纪上 22:27–28"> 他也对毗努伊勒人说：“我平安回来的时候，必拆毁这座楼。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="士师记 7:12; 士师记 20:25; 士师记 20:2"> 那时西巴和撒慕拿在加各，他们的军队也和他们在一起，约有一万五千人，就是东方人全军所剩下的人；因为拿刀的已经倒毙了十二万人。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 32:35; 民数记 32:42; 士师记 18:27"> 基甸从挪巴和约比哈东边，沿着住帐棚之人的路上去，击打那军队；因为那军队以为安全无事。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 83:11; 阿摩司 2:14; 约伯记 12:16–21"> 西巴和撒慕拿逃跑，基甸追赶他们，捉住米甸的两个王西巴和撒慕拿，并使全军惊乱。</span>
<span className="v" id="v13" data-v="13"> 约阿施的儿子基甸从希列斯坡从战场回来。</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 1:24–25; 撒母耳记上 30:11–15"> 他捉住疏割人中的一个少年，盘问他；那少年就把疏割的首领和长老七十七个人写给他。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 8:6–7"> 基甸来到疏割人那里，说：“看哪，西巴和撒慕拿在这里；你们曾为了他们讥诮我说：‘西巴和撒慕拿的手现在已经在你手里了吗？我们为什么要给你疲乏的人饼呢？’”</span>
<span className="v" id="v16" data-v="16" data-xref="士师记 8:7; 以斯拉记 2:6; 箴言 10:13"> 于是他拿住城里的长老，又取旷野的荆棘和蒺藜，用这些教训了疏割人。</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 8:9; 列王纪上 12:25"> 他又拆毁毗努伊勒的楼，杀了城里的人。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="士师记 4:6; 犹大书 1:16; 诗篇 89:12"> 然后他对西巴和撒慕拿说：“你们在他泊杀的那些人是什么样的人？”<br />他们回答：“他们像你一样，个个都有王子的样貌。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 他说：“他们是我的兄弟，是我母亲的儿子。我指着永活的耶和华起誓，你们若留他们存活，我就不杀你们。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="诗篇 149:9; 撒母耳记上 15:33; 约书亚记 10:24"> 他对自己的长子益帖说：“起来，杀他们！”可是那少年不敢拔刀；因为他害怕，毕竟还是个少年。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="诗篇 83:11; 士师记 8:26; 以赛亚书 3:18"> 西巴和撒慕拿说：“你自己起来扑向我们吧；因为人如何，力量也如何。”基甸就起来，杀了西巴和撒慕拿，并取下他们骆驼脖子上的月牙饰物。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约翰福音 6:15; 士师记 9:8–15; 撒母耳记上 12:12"> 以色列人对基甸说：“请你治理我们，你的儿子和你儿子的儿子也治理我们；因为你救我们脱离了米甸的手。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 33:22; 撒母耳记上 12:12; 撒母耳记上 10:19"> 基甸对他们说：“我不治理你们，我的儿子也不治理你们；耶和华要治理你们。”</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 25:13; 创世记 37:25; 创世记 37:28"> 基甸又对他们说：“我有一个请求：请你们各人把所掳之物中的耳环给我。”（原来他们有金耳环，因为他们是以实玛利人。）</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 他们回答：“我们甘愿给你。”他们就铺开一件衣服，各人把所掳之物中的耳环扔在其上。</span>
<span className="v" id="v26" data-v="26" data-xref="启示录 18:16; 约翰福音 19:2; 启示录 18:12"> 他所请求的金耳环，重量有一千七百舍客勒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一舍客勒约为10克，或约0.32金衡盎司；所以1700舍客勒约为17公斤，或37.4磅。">a</a></sup>金子；此外还有月牙饰物、耳坠、米甸王所穿的紫色衣服，以及他们骆驼脖子上的项链。</span>
<span className="v" id="v27" data-v="27" data-xref="士师记 17:5; 士师记 18:14; 诗篇 106:39"> 基甸用这些做了一个以弗得，放在自己的城俄弗拉。后来全以色列在那里随从它行淫；这就成了基甸和他家的网罗。</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 5:31; 士师记 3:11; 士师记 3:30"> 这样，米甸在以色列人面前被制伏，不再抬头。基甸在世的日子，那地太平四十年。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="士师记 6:32; 士师记 7:1; 撒母耳记上 12:11"> 约阿施的儿子耶路巴力回去，住在自己家里。</span>
<span className="v" id="v30" data-v="30" data-xref="士师记 9:5; 士师记 9:2; 列王纪上 11:3"> 基甸有七十个亲生的儿子，因为他有许多妻子。</span>
<span className="v" id="v31" data-v="31" data-xref="士师记 9:18; 创世记 22:24; 创世记 16:15"> 他在示剑的妾也给他生了一个儿子，基甸给他起名叫亚比米勒。</span>
<span className="v" id="v32" data-v="32" data-xref="创世记 25:8; 士师记 6:24; 约伯记 5:26"> 约阿施的儿子基甸寿数满足而死，葬在他父亲约阿施的坟墓里，在亚比以谢人的俄弗拉。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="士师记 9:46; 士师记 2:19; 士师记 9:4"> 基甸一死，以色列人又转去随从众巴力行淫，并立巴力比利土为他们的神。</span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 78:42; 诗篇 106:21; 诗篇 78:11"> 以色列人不记念耶和华他们的上帝，就是那位救他们脱离四围一切仇敌之手的；</span>
<span className="v" id="v35" data-v="35" data-xref="传道书 9:14–15; 士师记 9:5; 士师记 9:16–19"> 也没有照耶路巴力，就是基甸，向以色列所施的一切恩惠，善待他的家。</span>
</div>
</div>

</div>

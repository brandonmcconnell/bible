<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 20:18; 民数记 27:21; 士师记 20:28"> 约书亚死后，以色列子孙求问耶和华，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="在英文中，当“LORD”或“GOD”以全大写字母呈现时，是上帝专有名（希伯来文“יהוה”，通常发音为 Yahweh）的翻译。">a</a></sup>说：“谁要先为我们上去攻击迦南人，与他们争战？”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="启示录 5:5; 希伯来书 7:14; 民数记 2:3"> 耶和华说：“犹大要上去。看哪，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“Behold”源自“הִנֵּה”，意思是看、留意、观察、看见或凝视。它常用作感叹词。">b</a></sup>我已经把那地交在他手中。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 10:11; 约书亚记 19:1; 士师记 1:17"> 犹大对他的弟兄西缅说：“请你同我上到我拈阄所得之地，好让我们攻击迦南人；我也照样同你到你拈阄所得之地。”于是西缅与他同去。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 11:8; 出埃及记 23:28–29; 约书亚记 11:6–8"> 犹大上去，耶和华把迦南人和比利洗人交在他们手中。他们在比色击杀了一万人。</span>
<span className="v" id="v5" data-v="5"> 他们在比色遇见亚多尼·比色，就与他争战，击杀了迦南人和比利洗人。</span>
<span className="v" id="v6" data-v="6"> 亚多尼·比色逃跑；他们追赶他，捉住他，砍掉他双手的大拇指和双脚的大脚趾。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 15:33; 启示录 13:10; 路加福音 6:37–38"> 亚多尼·比色说：“曾有七十个王，双手的大拇指和双脚的大脚趾都被砍掉，在我的桌子底下捡食。我怎样待人，上帝<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="译为“上帝”的希伯来词是“אֱלֹהִ֑ים”（Elohim）。">c</a></sup>也怎样待我。”他们把他带到耶路撒冷，他就死在那里。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 15:63; 士师记 1:21"> 犹大子孙攻打耶路撒冷，攻取了城，用刀刃击杀城中的人，并放火烧城。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约书亚记 15:13–20; 约书亚记 11:21; 约书亚记 10:36"> 后来，犹大子孙下去，与住在山地、南地和低地的迦南人争战。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 13:22; 约书亚记 14:15; 耶利米书 9:23"> 犹大去攻击住在希伯仑的迦南人。（希伯仑从前名叫基列·亚巴。）他们击杀了示筛、亚希幔和挞买。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约书亚记 15:15; 约书亚记 10:38–39"> 他从那里去攻击底璧的居民。（底璧从前名叫基列·西弗。）</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 15:16–17; 撒母耳记上 17:25; 撒母耳记上 18:23"> 迦勒说：“谁击败基列·西弗并攻取那城，我就把我女儿押撒给他为妻。”</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 3:9"> 迦勒的弟弟基纳斯的儿子俄陀聂攻取了那城，迦勒就把女儿押撒给他为妻。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="约书亚记 15:18–19"> 押撒来的时候，劝丈夫向她父亲求一块田。她从驴上下来；迦勒对她说：“你要什么？”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 25:18; 哥林多后书 9:5; 彼得前书 3:9"> 她对他说：“求你给我一份福分；既然你把我安置在南地，也求你给我水泉。”于是迦勒把上泉和下泉都给了她。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 10:29–32; 士师记 4:11; 撒母耳记上 15:6"> 摩西的岳父、基尼人的子孙，和犹大子孙一同从棕树城上到犹大旷野，就是亚拉得以南的地方；他们去与那民同住。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 21:3; 士师记 1:3; 约书亚记 19:4"> 犹大和他的弟兄西缅同去，击杀住在洗法的迦南人，把那城完全毁灭。那城的名就叫何珥玛。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 11:22; 士师记 3:3; 约书亚记 15:45–47"> 犹大也攻取了迦萨和它的境界，亚实基伦和它的境界，以革伦和它的境界。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 41:10; 士师记 1:2; 诗篇 60:12"> 耶和华与犹大同在，犹大就赶出了山地的居民；可是谷地的居民有铁车，所以犹大不能赶出他们。</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 1:10; 约书亚记 15:13–14; 民数记 14:24"> 他们照摩西所说的，把希伯仑给了迦勒；迦勒就从那里赶出了亚衲的三个儿子。</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 15:63; 士师记 19:10–12; 士师记 1:8"> 便雅悯子孙没有赶出住在耶路撒冷的耶布斯人；耶布斯人就与便雅悯子孙同住在耶路撒冷，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="士师记 1:19; 列王纪下 18:7; 民数记 1:32"> 约瑟家也上去攻击伯特利，耶和华与他们同在。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 28:19; 创世记 35:6; 创世记 48:3"> 约瑟家派人去窥探伯特利。（那城从前名叫路斯。）</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 2:12–14; 撒母耳记上 30:15"> 侦察的人看见一个人从城里出来，就对他说：“请你把进城的入口指给我们，我们必以恩慈待你。”</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 6:22–25"> 那人把进城的入口指给他们，他们就用刀刃击杀城中的人；但让那人和他全家离去。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 7:6; 历代志下 1:17"> 那人到了赫人之地，建造了一座城，称那城为路斯；直到今日，那城还叫这个名字。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约书亚记 17:11–13; 耶利米书 48:10; 诗篇 106:34–35"> 玛拿西没有赶出伯·善和所属城镇的居民，也没有赶出他纳和所属城镇、多珥和所属城镇、以伯莲和所属城镇、米吉多和所属城镇的居民；迦南人执意住在那地。</span>
<span className="v" id="v28" data-v="28"> 以色列强盛以后，就使迦南人服苦役，却没有把他们完全赶出。</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 16:10; 列王纪上 9:16"> 以法莲没有赶出住在基色的迦南人；迦南人就住在基色，在他们中间。</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 19:15"> 西布伦没有赶出基特伦的居民，也没有赶出拿哈拉的居民；迦南人就住在他们中间，并且服苦役。</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 19:24–30"> 亚设没有赶出亚柯的居民，西顿的居民，以及亚黑拉、亚革悉、黑巴、亚弗革、利合的居民；</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 106:34–35"> 亚设人就住在那地的居民迦南人中间，因为他们没有赶出他们。</span>
<span className="v" id="v33" data-v="33" data-xref="约书亚记 19:32–38; 士师记 1:30; 诗篇 18:24"> 拿弗他利没有赶出伯·示麦的居民，也没有赶出伯·亚纳的居民；他就住在那地的居民迦南人中间。然而，伯·示麦和伯·亚纳的居民都服苦役。</span>
<span className="v" id="v34" data-v="34" data-xref="约书亚记 19:47; 士师记 18:1"> 亚摩利人把但子孙逼到山地，因为他们不准但子孙下到谷地；</span>
<span className="v" id="v35" data-v="35" data-xref="约书亚记 19:42; 士师记 12:12; 约书亚记 10:12"> 亚摩利人执意住在希烈山、亚雅仑和沙宾。然而约瑟家的手强盛起来，亚摩利人就服苦役。</span>
<span className="v" id="v36" data-v="36" data-xref="民数记 34:4; 约书亚记 15:2–3"> 亚摩利人的边界是从亚克拉滨坡，从岩石起往上。</span>
</div>
</div>

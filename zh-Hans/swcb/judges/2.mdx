<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 20:2; 创世记 17:7–8; 利未记 26:42"> 耶和华的使者从吉甲上到波金。他说：“我把你们从埃及领出来，带你们进入我起誓要赐给你们列祖的地。我说：‘我永不废弃我与你们所立的约。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 7:2–4; 耶利米书 2:36; 以斯拉记 9:1–3"> 你们不可与这地的居民立约；你们要拆毁他们的祭坛。’可是你们没有听从我的声音。你们为什么这样做呢？</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 23:13; 民数记 33:55; 申命记 7:16"> 因此我也说：‘我必不把他们从你们面前赶出去；他们必成为你们肋旁的刺，他们的神也必成为你们的网罗。’”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="耶利米书 31:9; 箴言 17:10; 撒迦利亚书 12:10"> 耶和华的使者向以色列众子说这些话的时候，百姓就放声大哭。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 7:9; 创世记 35:8; 约书亚记 7:26"> 他们给那地方起名叫波金，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“波金”的意思是“哭泣的人”。">a</a></sup>并在那里向耶和华献祭。</span>
<span className="v" id="v6" data-v="6" data-xref="约书亚记 24:28–31; 约书亚记 22:6"> 约书亚遣散百姓以后，以色列众子各自到自己的产业那里去，占有那地。</span>
<span className="v" id="v7" data-v="7" data-xref="腓立比书 2:12; 约书亚记 24:31; 历代志下 24:2"> 约书亚在世的日子，以及约书亚死后仍然在世的长老们在世的日子，百姓都事奉耶和华；这些长老曾看见耶和华为以色列所行的一切大事。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 24:29–30"> 耶和华的仆人、嫩的儿子约书亚死了，享年一百一十岁。</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 19:50; 约书亚记 24:30"> 他们把他葬在他产业的境内，就是以法莲山地的亭拿·希烈，在迦实山的北边。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 2:12; 提多书 1:16; 出埃及记 5:2"> 那一整代人都归到他们列祖那里以后，另有一代人在他们以后兴起；他们不认识耶和华，也不知道祂为以色列所做的事。</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 4:1; 士师记 6:1; 士师记 3:7"> 以色列众子行耶和华眼中看为恶的事，事奉众巴力。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 20:5; 申命记 13:5; 申命记 6:14–15"> 他们离弃耶和华，就是领他们出埃及地的他们列祖的上帝，去随从周围各族的神，向它们下拜；他们惹耶和华发怒。</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 10:6; 诗篇 106:36; 士师记 3:7"> 他们离弃耶和华，事奉巴力和亚斯她录。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 17:20; 诗篇 106:40–42; 申命记 32:30"> 耶和华的怒气向以色列发作，祂把他们交在抢掠者手中，任凭他们抢掠；又把他们卖在四围仇敌的手中，以致他们不能再在仇敌面前站立。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 28:15–68; 约书亚记 23:15–16; 利未记 26:14–46"> 他们无论往哪里出去，耶和华的手都攻击他们，降祸给他们，正如耶和华所说的，也正如耶和华向他们所起誓的；他们就陷入极大的困苦。</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 13:20; 诗篇 106:43–45; 撒母耳记上 12:11"> 耶和华兴起士师，把他们从抢掠他们的人手中拯救出来。</span>
<span className="v" id="v17" data-v="17" data-xref="加拉太书 1:6; 申命记 9:12; 士师记 2:7"> 然而他们不听从他们的士师；他们随从别神行淫，向它们下拜。他们很快偏离他们列祖所行、听从耶和华诫命的道路；他们并没有这样行。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 32:36; 约书亚记 1:5; 出埃及记 2:24"> 耶和华为他们兴起士师的时候，耶和华就与那士师同在；那士师在世的日子，耶和华把他们从仇敌手中拯救出来，因为他们因受压迫、受扰害而呻吟，耶和华就为他们忧伤。</span>
<span className="v" id="v19" data-v="19" data-xref="士师记 8:33; 士师记 4:1; 马太福音 23:32"> 可是士师一死，他们就转回，比他们的列祖更加败坏，去随从别神，事奉它们，向它们下拜。他们不停止自己的行为，也不放弃顽梗的道路。</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 2:14; 约书亚记 23:16; 出埃及记 32:10–11"> 耶和华的怒气向以色列发作；祂说：“因为这民族违背我吩咐他们列祖所守的约，没有听从我的声音，</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 23:13; 士师记 2:3; 士师记 3:3"> 所以约书亚死时所留下的列国，我也必不再从他们面前赶出任何一国；</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 8:2; 申命记 8:16; 申命记 13:3"> 好借着这些国考验以色列，看他们是否谨守耶和华的道路，行在其中，像他们列祖谨守一样。”</span>
<span className="v" id="v23" data-v="23"> 因此，耶和华留下那些国，没有急速赶出它们，也没有把它们交在约书亚手中。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 15:47; 以斯拉记 9:1–2; 创世记 38:16–18"> 参孙到了迦萨，在那里看见一个妓女，就进去与她同寝。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 118:10–12; 撒母耳记上 23:26; 使徒行传 9:24"> 有人告诉迦萨人说：“参孙在这里！”他们就围住他，在城门口整夜埋伏等候他；他们整夜安静不动，说：“等到天亮，我们就杀他。”</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 2:24; 诗篇 107:16; 以赛亚书 63:1–5"> 参孙睡到半夜，半夜起来，抓住城门的门扇和两根门柱，连门闩一起拔起来，扛在肩上，带到希伯仑前面那座山的山顶。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 10:6; 箴言 22:14; 尼希米记 13:26"> 这事以后，参孙爱上了梭烈谷的一个女人，名叫大利拉。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 13:3; 士师记 14:15; 提摩太前书 6:9–10"> 非利士人的首领上来见她，对她说：“你要引诱他，看他的大力气从哪里来，我们用什么方法能胜过他，好捆绑他、苦待他；我们每个人都给你一千一百块银子。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="箴言 7:21; 箴言 6:26; 箴言 22:14"> 大利拉对参孙说：“请你告诉我，你的大力气从哪里来，要用什么捆绑你才可以苦待你。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 21:2–3; 罗马书 3:8; 撒母耳记上 27:10"> 参孙对她说：“如果他们用七根从未晒干的新绳弦捆绑我，我就会软弱，像普通人一样。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="传道书 7:26"> 于是非利士人的首领给她带来七根未晒干的新绳弦，她就用这些捆绑参孙。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 58:9"> 那时有人埋伏在内室里。她对参孙说：“参孙哪，非利士人来抓你了！”他就挣断那些绳弦，如同麻线一碰到火就断了一样。这样，他力气的来源仍然没有被人知道。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="士师记 16:13; 路加福音 22:48; 士师记 16:7"> 大利拉对参孙说：“看哪，你戏弄我，对我说谎。现在请你告诉我，要怎样捆绑你。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="箴言 13:5; 以弗所书 4:25; 箴言 13:3"> 他对她说：“如果他们只用从未使用过的新绳捆绑我，我就会软弱，像普通人一样。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 于是大利拉拿新绳捆绑他，然后对他说：“参孙哪，非利士人来抓你了！”那时有人埋伏在内室里。他却把臂上的绳挣断，如同挣断一根线一样。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 大利拉对参孙说：“直到现在，你一直戏弄我，对我说谎。告诉我，要用什么捆绑你。”<br />他对她说：“如果你把我头上的七绺头发同织机上的织物织在一起。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="诗篇 106:43; 以斯拉记 9:13–14"> 她就用织机的橛子钉住，对他说：“参孙哪，非利士人来抓你了！”他从睡中醒来，把织机的橛子和织物都拔了出来。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士师记 14:16; 约翰一书 2:15–16; 约翰福音 14:21–24"> 她对他说：“你的心既然不在我这里，怎么能说‘我爱你’呢？你这三次戏弄我，没有告诉我你的大力气从哪里来。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="箴言 7:21–23; 路加福音 18:5; 马可福音 14:24"> 她天天用话催逼他，催促他，他心里烦恼得要死。</span>
<span className="v" id="v17" data-v="17" data-xref="弥迦书 7:5; 士师记 13:5; 箴言 12:23"> 他就把心里的一切都告诉她，对她说：“从来没有剃刀剃过我的头，因为我从母腹里就是归上帝的拿细耳人。如果我被剃了头，我的力气就会离开我，我就会软弱，像所有普通人一样。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 26:15; 士师记 16:5; 提摩太前书 6:10"> 大利拉见他已经把心里的一切都告诉了她，就派人去叫非利士人的首领，说：“这一次你们上来吧，因为他已经把心里的一切都告诉我了。”于是非利士人的首领上到她那里，手里带着银子。</span>
<span className="v" id="v19" data-v="19" data-xref="箴言 7:26–27; 箴言 7:21–23; 传道书 7:26"> 她使参孙睡在她膝上，然后叫了一个人来，剃掉他头上的七绺头发；她就开始制伏他，他的力气也离开了他。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 14:42–43; 撒母耳记上 16:14; 约书亚记 7:12"> 她说：“参孙哪，非利士人来抓你了！”<br />他从睡中醒来，说：“我要像前几次一样出去，挣脱出来。”但他不知道耶和华已经离开了他。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 2:19; 箴言 14:14; 以赛亚书 47:2"> 非利士人抓住他，剜出他的眼睛；他们把他带下到迦萨，用铜链锁住他；他就在监狱里推磨。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 107:13–14; 诗篇 106:44–45; 利未记 26:44"> 然而，他被剃以后，头发又开始长起来。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 5:2–5; 箴言 24:17; 诗篇 35:15–16"> 非利士人的首领聚集在一起，要向他们的神大衮献大祭，并且欢庆；因为他们说：“我们的神已经把我们的仇敌参孙交在我们手里了。”</span>
<span className="v" id="v24" data-v="24" data-xref="但以理 5:4; 但以理 5:23; 士师记 15:16"> 百姓看见他，就赞美他们的神；因为他们说：“我们的神已经把我们的仇敌，就是毁坏我们国土、杀了我们许多人的那一位，交在我们手里了。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 13:28; 士师记 19:6; 士师记 9:27"> 他们心里快乐的时候，就说：“叫参孙来，让他给我们取乐。”他们就把参孙从监狱里叫出来；他在他们面前表演。他们使他站在柱子中间；</span>
<span className="v" id="v26" data-v="26"> 参孙对牵着他手的童子说：“让我摸到支撑这房子的柱子，好让我靠在上面。”</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 22:8; 撒母耳记下 11:2; 约书亚记 2:8"> 那房子里满了男人和女人；非利士人的众首领都在那里；房顶上约有三千男女，观看参孙表演。</span>
<span className="v" id="v28" data-v="28" data-xref="耶利米书 15:15; 耶利米哀歌 3:31–32; 诗篇 143:12"> 参孙呼求耶和华说：“主耶和华啊，求你记念我；上帝啊，求你只这一次赐我力量，让我因我的两只眼睛，一次向非利士人报仇。”</span>
<span className="v" id="v29" data-v="29"> 参孙抱住支撑那房子的两根中间柱子，靠在柱子上，右手抱一根，左手抱一根。</span>
<span className="v" id="v30" data-v="30" data-xref="腓立比书 2:8; 马太福音 16:25; 马太福音 24:38–39"> 参孙说：“让我和非利士人一同死吧！”他用尽全力屈身，房子就倒塌，压在首领和里面所有百姓身上。这样，他死时所杀的人，比他生前所杀的人还多。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="士师记 15:20; 士师记 13:25; 士师记 13:2"> 后来，他的兄弟和他父亲全家都下来，把他抬上去，葬在琐拉和以实陶之间，他父亲玛挪亚的坟墓里。他作以色列的士师二十年。</span>
</div>
</div>

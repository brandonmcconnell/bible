<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 8:31; 诗篇 83:2–4; 撒母耳记下 15:6"> 耶路巴力的儿子亚比米勒往示剑去，到了他母亲的兄弟那里，对他们和他外祖父全家的人说：</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 29:14; 士师记 8:30; 希伯来书 2:14"> “请你们对示剑所有人说：‘是耶路巴力所有的儿子，就是七十个人，都管理你们好呢，还是一个人管理你们好呢？’也请你们记得，我是你们的骨肉。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 29:15; 诗篇 10:3; 箴言 1:11–14"> 他母亲的兄弟就把这一切话替他说给示剑所有人听。他们的心倾向亚比米勒，因为他们说：“他是我们的弟兄。”</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 8:33; 使徒行传 17:5; 历代志下 13:7"> 他们从巴力·比利土庙里给了他七十块银子；亚比米勒用这些银子雇了一些无用、鲁莽的人，他们就跟随他。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 11:1–2; 历代志下 21:4; 士师记 6:24"> 他到俄弗拉他父亲的家，把他的弟兄们，就是耶路巴力的儿子七十个人，杀在一块石头上；但耶路巴力的小儿子约坦还活着，因为他躲藏起来了。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 5:9; 列王纪上 12:20; 列王纪下 12:20"> 示剑所有人和米罗全家都聚集，去到示剑柱旁的橡树那里，立亚比米勒为王。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 11:29; 约翰福音 4:20; 申命记 27:12"> 有人把这事告诉约坦，他就去，站在基利心山顶上，高声呼喊，对他们说：“示剑人哪，你们要听我，好使上帝也听你们。</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 8:22–23; 但以理 4:10–18; 列王纪下 14:9"> 众树出去，要膏立一位王来统治它们。它们对橄榄树说：‘请你作我们的王。’</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="利未记 2:1; 出埃及记 29:7; 使徒行传 4:27"> “但橄榄树对它们说：‘我岂可停止出产我的油，就是人藉着我用来尊荣上帝和人的，去在众树之上摇来摇去呢？’</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> “众树对无花果树说：‘请你来作我们的王。’</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="路加福音 13:6–7"> “但无花果树对它们说：‘我岂可舍弃我的甘甜和我的美果，去在众树之上摇来摇去呢？’</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> “众树对葡萄树说：‘请你来作我们的王。’</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="诗篇 104:15; 传道书 10:19; 民数记 15:5"> “葡萄树对它们说：‘我岂可舍弃使上帝和人欢喜的新酒，去在众树之上摇来摇去呢？’</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王纪下 14:9"> “于是众树都对荆棘说：‘请你来作我们的王。’</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 30:2; 士师记 9:20; 何西阿 14:7"> “荆棘对众树说：‘如果你们真诚地膏我作你们的王，就来投靠在我的荫下；否则，愿火从荆棘中出来，吞灭黎巴嫩的香柏树。’</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="士师记 8:35"> “现在，倘若你们立亚比米勒为王，是以诚实和公义行事；倘若你们善待了耶路巴力和他的家，并且照他手所当得的报答了他</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 16:4; 罗马书 5:8; 启示录 12:11"> （因为我父亲曾为你们争战，冒着性命危险，把你们从米甸人手中救出来；</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 9:5–6; 士师记 8:30–31; 士师记 9:14"> 而你们今日起来攻击我父亲的家，把他的儿子七十个人杀在一块石头上，又立他婢女的儿子亚比米勒作示剑人的王，因为他是你们的弟兄）；</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 8:6; 雅各书 4:16; 腓立比书 3:3"> 如果你们今日果然以诚实和公义待耶路巴力和他的家，就可以因亚比米勒欢喜，也让他因你们欢喜；</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 9:15; 士师记 9:56–57; 历代志下 20:22–23"> 否则，愿火从亚比米勒那里出来，吞灭示剑人和米罗家；又愿火从示剑人和米罗家那里出来，吞灭亚比米勒。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数记 21:16; 撒母耳记下 20:14; 约书亚记 19:8"> 约坦逃跑，逃到比珥<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“比珥”在希伯来语中是“井”的意思，即一个因其水井而得名的村庄。">a</a></sup>，住在那里，因为惧怕他的弟兄亚比米勒。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 亚比米勒作以色列的首领三年。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 33:1; 以赛亚书 19:14; 以赛亚书 19:2"> 后来，上帝使一个恶灵在亚比米勒和示剑人之间制造纷争；示剑人就以诡诈待亚比米勒，</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 2:32; 诗篇 7:16; 以斯帖记 9:25"> 为要使耶路巴力七十个儿子所受的强暴归到亚比米勒身上，使他们的血归到杀害他们的弟兄亚比米勒身上，也归到那些支持他杀害自己弟兄的示剑人身上。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 8:12–13; 箴言 1:11–12; 约书亚记 8:4"> 示剑人在山顶上设伏兵等候亚比米勒；凡从他们那里经过的人，他们都抢劫。有人把这事告诉了亚比米勒。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="创世记 13:8; 创世记 19:7"> 以别的儿子迦勒和他的弟兄们来到示剑；示剑人就信靠他。</span>
<span className="v" id="v27" data-v="27" data-xref="士师记 9:4; 士师记 9:46; 诗篇 109:17"> 他们到田间去，收取葡萄园的果子，踹葡萄，举行庆宴，又进他们神的庙中吃喝，咒诅亚比米勒。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 34:2; 创世记 34:6; 撒母耳记上 25:10"> 以别的儿子迦勒说：“亚比米勒是谁？示剑又是谁，我们竟要服侍他？他不是耶路巴力的儿子吗？西布勒不是他的官员吗？你们去服侍示剑的父亲哈抹的人吧；我们为什么要服侍他呢？</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 15:4; 撒母耳记下 2:14–17; 以赛亚书 36:8–9"> 但愿这民归在我手下！那样我就要除掉亚比米勒。”他对亚比米勒说：“增添你的军队，出来吧！”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 城的统治者西布勒听见以别的儿子迦勒的话，就怒火中烧。</span>
<span className="v" id="v31" data-v="31"> 他暗中派使者到亚比米勒那里，说：“看哪，以别的儿子迦勒和他的弟兄们已经来到示剑；看哪，他们正煽动全城反对你。</span>
<span className="v" id="v32" data-v="32" data-xref="罗马书 3:15; 诗篇 36:4; 箴言 1:11–16"> 现在，你和跟随你的民要夜间上来，在田野埋伏。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记上 10:7; 传道书 9:10; 利未记 25:26"> 到早晨太阳一出来，你就及早起来，冲向这城。看哪，他和跟随他的民出来攻击你的时候，你就照机会所许的对付他们。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> 亚比米勒和所有跟随他的民夜间起来，分作四队埋伏，攻击示剑。</span>
<span className="v" id="v35" data-v="35"> 以别的儿子迦勒出来，站在城门口。亚比米勒和跟随他的民就从埋伏的地方起来。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="马可福音 8:24; 以西结 7:7"> 迦勒看见那些人，就对西布勒说：“看哪，有人从山顶下来。”<br />西布勒对他说：“你把山的影子看作人了。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="申命记 18:14"> 迦勒又说：“看哪，有人从那地的中央下来，又有一队人从米恶尼尼橡树的路上来。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="士师记 9:28–29; 列王纪下 14:8–14; 撒母耳记下 2:26–27"> 西布勒就对他说：“你先前说‘亚比米勒是谁，我们竟要服侍他？’你的口现在在哪里呢？这不是你所轻视的民吗？现在请你出去，与他们交战吧。”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39"> 迦勒就率领示剑人出去，与亚比米勒交战。</span>
<span className="v" id="v40" data-v="40" data-xref="列王纪上 20:18–21; 列王纪上 20:30"> 亚比米勒追赶他，他就在他面前逃跑；许多人受伤倒下，直到城门口。</span>
<span className="v" id="v41" data-v="41" data-xref="士师记 9:28; 士师记 9:30"> 亚比米勒住在亚鲁玛；西布勒把迦勒和他的弟兄们赶出去，不许他们住在示剑。</span>
<span className="v" id="v42" data-v="42"> 次日，民出到田间；有人把这事告诉亚比米勒。</span>
<span className="v" id="v43" data-v="43"> 他带着民，把他们分作三队，在田野埋伏；他观看，看哪，民从城里出来。于是他起来攻击他们，击杀他们。</span>
<span className="v" id="v44" data-v="44" data-xref="加拉太书 5:15; 士师记 9:15; 士师记 9:20"> 亚比米勒和跟随他的队伍向前冲去，站在城门口；另外两队冲向所有在田野的人，击杀他们。</span>
<span className="v" id="v45" data-v="45" data-xref="列王纪下 3:25; 申命记 29:23; 雅各书 2:13"> 亚比米勒整天攻打那城；他夺取了那城，杀了城中的人。他拆毁那城，又撒上盐。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="士师记 8:33; 士师记 9:4; 列王纪上 8:26"> 示剑楼的所有人听见了，就进了伊勒·比利土殿的堡垒。</span>
<span className="v" id="v47" data-v="47"> 有人告诉亚比米勒，示剑楼的所有人都聚集在一起。</span>
<span className="v" id="v48" data-v="48" data-xref="诗篇 68:14; 箴言 1:11–12; 士师记 7:17–18"> 亚比米勒和所有跟随他的民上撒们山；亚比米勒手里拿着斧子，砍下树上的一根枝子，拿起来扛在肩上。然后他对跟随他的民说：“你们看见我所做的，就赶快照我所做的去做！”</span>
<span className="v" id="v49" data-v="49" data-xref="加拉太书 5:15; 雅各书 3:16; 士师记 9:20"> 众人也各自砍下枝子，跟随亚比米勒，把枝子放在堡垒的底部，放火烧堡垒，使火烧在他们身上；这样，示剑楼的所有人也都死了，约有一千男女。</span>
<span className="v" id="v50" data-v="50"> 随后亚比米勒往提备斯去，安营攻打提备斯，并夺取了那城。</span>
<span className="v" id="v51" data-v="51"> 但城中有一座坚固的楼；城中所有男女都逃到那里，把自己关在里面，又上到楼顶。</span>
<span className="v" id="v52" data-v="52" data-xref="士师记 9:48–49; 列王纪下 14:10; 列王纪下 15:16"> 亚比米勒来到楼前攻打它，走近楼门，要用火焚烧。</span>
<span className="v" id="v53" data-v="53" data-xref="撒母耳记下 11:21; 约伯记 31:3; 耶利米书 49:20"> 有一个妇人把一块上磨石扔在亚比米勒的头上，打破了他的头骨。</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="撒母耳记上 31:4–5"> 他就急忙叫那给他拿兵器的少年人来，对他说：“拔出你的刀，杀了我，免得人议论我说：‘一个妇人杀了他。’”他的少年人就刺透他，他便死了。</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="撒母耳记下 18:16; 撒母耳记下 20:21–22; 列王纪上 22:35–36"> 以色列人看见亚比米勒死了，就各自回到自己的地方。</span>
<span className="v" id="v56" data-v="56" data-xref="诗篇 94:23; 士师记 9:24; 箴言 5:22"> 这样，上帝报应了亚比米勒所行的恶，就是他杀害自己七十个弟兄、得罪他父亲的恶；</span>
<span className="v" id="v57" data-v="57" data-xref="士师记 9:20; 约书亚记 6:26; 列王纪上 16:34"> 上帝也把示剑人的一切恶报应在他们头上；耶路巴力的儿子约坦的咒诅就临到他们。</span>
</div>
</div>

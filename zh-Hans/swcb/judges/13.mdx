<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 12:9; 士师记 6:1; 罗马书 2:6"> 以色列人又行耶和华眼中看为恶的事；耶和华就把他们交在非利士人手中四十年。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="约书亚记 19:41; 路加福音 1:7; 约书亚记 15:33"> 有一个人是琐拉人，属但族，名叫玛挪亚；他的妻子不生育，没有孩子。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:13; 路加福音 1:11; 士师记 6:11–12"> 耶和华的使者向那妇人显现，对她说：“看哪，你不生育，没有孩子；但你必怀孕，生一个儿子。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 1:15; 士师记 13:14; 民数记 6:2–3"> 现在你要谨慎，不可喝葡萄酒或烈酒，也不可吃任何不洁净之物；</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 6:5; 撒母耳记上 1:11; 历代志上 18:1"> 因为，看哪，你必怀孕，生一个儿子。不可用剃刀剃他的头，因为这孩子从母腹起就要归上帝作拿细耳人。他必开始从非利士人手中拯救以色列。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="士师记 13:17–18; 撒母耳记上 9:6; 马太福音 28:3–4"> 于是那妇人来告诉丈夫说：“有一位上帝的人到我这里来，他的面貌像上帝使者的面貌，非常令人敬畏。我没有问他从哪里来，他也没有告诉我他的名字；</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 13:4"> 但他对我说：‘看哪，你必怀孕，生一个儿子；现在不可喝葡萄酒或烈酒，也不可吃任何不洁净之物，因为这孩子从母腹起直到死的日子，都要归上帝作拿细耳人。’”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 9:6; 约伯记 34:32; 箴言 3:5–6"> 玛挪亚就恳求耶和华说：“主啊，求你让你所差来的那位上帝的人再到我们这里来，教导我们应当怎样待那将要出生的孩子。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="诗篇 65:2; 马太福音 7:7–11"> 上帝听了玛挪亚的声音；上帝的使者在那妇人坐在田间的时候，又到她那里来；但她的丈夫玛挪亚没有和她在一起。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 4:28–29; 约翰福音 1:41–42"> 那妇人急忙跑去告诉丈夫，对他说：“看哪，那天到我这里来的那个人又向我显现了。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 玛挪亚起来跟随妻子，来到那人那里，对他说：“你就是那对我妻子说话的人吗？”<br />他说：“我是。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="箴言 22:6; 以弗所书 6:4; 创世记 18:19"> 玛挪亚说：“愿你的话成就。我们该怎样养育这孩子？他将来要做什么呢？”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 耶和华的使者对玛挪亚说：“凡我对那妇人说的，她都要谨慎遵守。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 2:5; 士师记 13:4; 帖撒罗尼迦后书 3:4"> 葡萄树所出的任何东西，她都不可吃；葡萄酒或烈酒，她都不可喝；任何不洁净之物，她都不可吃。凡我吩咐她的，她都要遵守。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士师记 6:18–19; 创世记 18:3–5; 士师记 13:3"> 玛挪亚对耶和华的使者说：“请你留在我们这里，好让我们为你预备一只山羊羔。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="士师记 13:23; 士师记 6:20; 士师记 6:26"> 耶和华的使者对玛挪亚说：“你即使留我，我也不吃你的食物。你若预备燔祭，就必须献给耶和华。”原来玛挪亚不知道他是耶和华的使者。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 32:29"> 玛挪亚对耶和华的使者说：“你的名字是什么？等你的话成就时，我们好尊敬你。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="创世记 32:29; 以赛亚书 9:6; 士师记 13:6"> 耶和华的使者对他说：“你为什么问我的名字呢？它是不可测度的<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“奇妙的”">a</a></sup>。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="士师记 6:19–21; 列王纪上 18:30–38"> 于是玛挪亚拿了那只山羊羔和素祭，在磐石上献给耶和华。当玛挪亚和他的妻子观看的时候，那使者行了一件奇妙的事。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 9:24; 历代志上 21:16; 列王纪下 2:11"> 火焰从祭坛上升向天空的时候，耶和华的使者就在祭坛的火焰中升上去了。玛挪亚和他的妻子观看，就脸伏于地。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 6:22; 何西阿 12:4–5; 士师记 13:16"> 耶和华的使者不再向玛挪亚和他的妻子显现。玛挪亚这才知道他是耶和华的使者。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 32:30; 申命记 5:26; 约翰福音 1:18"> 玛挪亚对妻子说：“我们一定要死，因为我们看见了上帝。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="诗篇 25:14; 哥林多前书 12:21; 约翰福音 15:15"> 但他的妻子对他说：“耶和华若喜悦杀我们，就不会从我们手中收纳燔祭和素祭，也不会把这一切事指示我们，更不会在这时候告诉我们这样的事。”</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 1:80; 撒母耳记上 3:19; 希伯来书 11:32"> 那妇人生了一个儿子，给他起名叫参孙。孩子长大，耶和华赐福给他。</span>
<span className="v" id="v25" data-v="25" data-xref="士师记 3:10; 约书亚记 15:33; 约翰福音 3:34"> 耶和华的灵开始在玛哈尼但，就是在琐拉和以实陶之间，感动他。</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 2:21–22; 申命记 7:22; 箴言 17:3"> 这些就是耶和华所留下的民族，为要借着他们考验以色列，就是那些没有经历过迦南诸战事的人；</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 3:5; 创世记 3:7; 哥林多前书 9:26–27"> 这只是为了使以色列子孙的后代知道战争，好教导他们作战，至少教导那些从前完全不知道战争的人：</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 13:3; 约书亚记 13:5; 士师记 10:7"> 非利士人的五个首领、所有迦南人、西顿人，以及住在黎巴嫩山上的希未人，从巴力·黑门山直到哈马口。</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 3:1; 士师记 2:22; 出埃及记 15:25"> 这些民族被留下，为要借着他们考验以色列，好知道他们是否听从耶和华的诫命，就是祂借摩西吩咐他们列祖的。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 106:34–38; 创世记 10:15–18; 出埃及记 3:8"> 以色列子孙住在迦南人、赫人、亚摩利人、比利洗人、希未人和耶布斯人中间。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 7:3–4; 出埃及记 34:16; 列王纪上 11:1–5"> 他们娶这些人的女儿为妻，又把自己的女儿嫁给这些人的儿子，并事奉他们的神明。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 34:13; 列王纪下 23:6; 列王纪上 18:19"> 以色列子孙行耶和华眼中看为恶的事，忘记耶和华他们的上帝，事奉诸巴力和亚舍拉。</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 2:14; 哈巴谷 3:7; 士师记 4:9"> 因此耶和华的怒气向以色列发作，祂把他们卖在美索不达米亚王古珊·利萨田手中；以色列子孙服事古珊·利萨田八年。</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 3:15; 士师记 1:13; 诗篇 22:5"> 以色列子孙向耶和华呼求的时候，耶和华就为以色列子孙兴起一位拯救者来拯救他们，就是迦勒的弟弟基纳斯的儿子俄陀聂。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 13:25; 撒母耳记上 11:6; 士师记 14:19"> 耶和华的灵降在他身上，他就作以色列的士师；他出去争战，耶和华把美索不达米亚王古珊·利萨田交在他手中。他的手胜过古珊·利萨田。</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 5:31; 士师记 8:28; 约书亚记 11:23"> 于是那地太平四十年；后来基纳斯的儿子俄陀聂死了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 12:9; 士师记 2:19; 士师记 2:14"> 以色列子孙又行耶和华眼中看为恶的事；耶和华就使摩押王伊矶伦强盛，攻击以色列，因为他们行了耶和华眼中看为恶的事。</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 1:16; 申命记 34:3; 士师记 5:14"> 伊矶伦招聚亚扪人和亚玛力人到他那里；他去攻打以色列，他们就占领了棕树城。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 28:47–48; 申命记 28:40; 利未记 26:23–25"> 以色列子孙服事摩押王伊矶伦十八年。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 3:9; 诗篇 78:34; 以赛亚书 36:16"> 但以色列子孙向耶和华呼求的时候，耶和华就为他们兴起一位拯救者：便雅悯人基拉的儿子以笏，是一个惯用左手的人。以色列子孙托他把贡物送给摩押王伊矶伦。</span>
<span className="v" id="v16" data-v="16" data-xref="雅歌 3:8; 启示录 2:12; 诗篇 149:6"> 以笏为自己做了一把两刃的剑，长一肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘是人手臂从中指尖到肘部的长度，约十八英寸或四十六厘米。">a</a></sup>；他把剑佩在衣服里面，靠右大腿。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结 34:20; 约伯记 15:27; 耶利米书 50:11"> 他把贡物献给摩押王伊矶伦。伊矶伦是一个非常肥胖的人。</span>
<span className="v" id="v18" data-v="18"> 以笏献完贡物，就打发抬贡物的人离开。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 4:20; 士师记 3:20; 使徒行传 23:18–19"> 但他自己从吉甲附近的石像那里转回来，说：“王啊，我有一件秘密的事要告诉你。”<br />王说：“安静！”所有侍立在王身边的人都离开他出去了。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="耶利米书 10:7; 阿摩司 3:15; 诗篇 29:1"> 以笏来到王那里；王正独自一人坐在凉爽的楼房里。以笏说：“我有上帝的话要传给你。”王就从座位上站起来。</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亚书 13:3; 约伯记 20:25; 撒母耳记上 15:33"> 以笏伸出左手，从右大腿取出剑来，刺进王的肚腹。</span>
<span className="v" id="v22" data-v="22"> 连剑柄也随着剑刃进去了；脂肪合在剑刃上，因为他没有把剑从王的肚腹拔出来；剑尖从后面穿出。</span>
<span className="v" id="v23" data-v="23"> 以笏就出去到廊子，把楼房的门关上，锁住。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒母耳记上 24:3"> 他出去以后，王的仆人来了，看见楼房的门锁着，就说：“他一定是在楼房里遮盖他的脚<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：“解手”。">b</a></sup>。”</span>
<span className="v" id="v25" data-v="25"> 他们等到觉得羞愧；看哪，王还没有打开楼房的门。于是他们拿钥匙开了门，看哪，他们的主人已经倒在地上死了。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 以笏趁他们耽搁的时候逃走，经过石像那里，逃到西伊拉。</span>
<span className="v" id="v27" data-v="27" data-xref="士师记 6:34; 撒母耳记上 13:3; 士师记 5:14"> 他到了以后，就在以法莲山地吹号；以色列子孙就跟着他从山地下去，他在他们前面带领。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="士师记 12:5; 士师记 7:9; 士师记 7:15"> 他对他们说：“跟随我，因为耶和华已经把你们的仇敌摩押人交在你们手中。”他们就跟随他，占据约旦河的渡口，防备摩押人，不准任何人过去。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 32:15; 士师记 3:17; 诗篇 17:10"> 那时他们击杀了约一万名摩押人，个个都是强壮的人和勇士；没有一人逃脱。</span>
<span className="v" id="v30" data-v="30" data-xref="士师记 3:11; 士师记 5:31"> 这样，那一天摩押就在以色列手下被制伏。于是那地太平八十年。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="士师记 5:6; 哥林多前书 1:17; 撒母耳记上 17:50"> 在以笏之后，有亚拿的儿子珊迦，他用赶牛棍击杀了六百名非利士人。他也拯救了以色列。</span>
</div>
</div>

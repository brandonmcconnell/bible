<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 20:1; 马可福音 6:23; 使徒行传 23:12"> 以色列人在米斯巴曾起誓说：“我们中谁也不可把自己的女儿嫁给便雅悯人为妻。”</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 20:26; 士师记 20:18; 撒母耳记上 30:4"> 百姓来到伯特利，在上帝面前坐在那里直到晚上，放声痛哭。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 74:1; 约书亚记 7:7–9; 以赛亚书 63:17"> 他们说：“耶和华——以色列的上帝啊，为什么以色列中会发生这样的事，以致今日以色列缺了一个支派呢？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 24:25; 列王纪上 8:64; 诗篇 78:34–35"> 第二天，百姓清早起来，在那里筑了一座祭坛，献上燔祭和平安祭。</span>
<span className="v" id="v5" data-v="5" data-xref="士师记 5:23; 士师记 21:18; 士师记 21:1"> 以色列人说：“以色列众支派中，有谁没有上到会众那里到耶和华面前来呢？”因为他们曾针对不上米斯巴到耶和华面前来的人起了严厉的誓，说：“他必定要被处死。”</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 21:15; 士师记 20:23; 路加福音 19:41–42"> 以色列人为他们的弟兄便雅悯悲伤，说：“今日以色列中有一个支派被剪除了。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 21:1; 士师记 21:18; 撒母耳记上 14:28–29"> 我们既然指着耶和华起誓，不把我们的女儿嫁给他们为妻，那么我们怎样为那些剩下的人预备妻子呢？”</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 31:11–13; 撒母耳记上 11:1–3; 撒母耳记下 2:5–6"> 他们说：“以色列各支派中，有哪一个没有上米斯巴到耶和华面前来呢？”看哪，从基列雅比没有一个人到营中来参加会众。</span>
<span className="v" id="v9" data-v="9"> 因为百姓被数点的时候，看哪，基列雅比的居民中没有一个在那里。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 5:23; 士师记 21:5; 撒母耳记上 11:7"> 会众就派一万二千名最勇猛的人到那里去，吩咐他们说：“你们去，用刀刃击杀基列雅比的居民，连妇女和小孩子也一并击杀。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 31:17–18; 申命记 2:34"> 你们要这样做：所有男子，以及所有与男人同寝过的妇女，你们都要尽行毁灭。”</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 18:1; 耶利米书 7:12; 诗篇 78:60"> 他们在基列雅比的居民中，找到四百个年轻处女，是未曾与男人同寝、没有亲近过男人的；他们就把她们带到迦南地的示罗营中。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="士师记 20:47; 申命记 20:10; 以弗所书 2:17"> 全会众就派人去对在利门磐石的便雅悯人说话，向他们宣告和平。</span>
<span className="v" id="v14" data-v="14" data-xref="士师记 21:12; 哥林多前书 7:2; 士师记 20:47"> 那时便雅悯人回来了；众人就把他们从基列雅比的妇女中所存留性命的女子给了他们。可是还是不够。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 21:6; 历代志上 15:13; 以赛亚书 58:12"> 百姓为便雅悯悲伤，因为耶和华使以色列各支派中有了一个缺口。</span>
<span className="v" id="v16" data-v="16"> 会众的长老说：“既然便雅悯的女子都被毁灭了，我们怎样为那些剩下的人预备妻子呢？”</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 26:55; 民数记 36:7"> 他们说：“便雅悯逃脱的人必须有产业，免得以色列中有一个支派被涂抹。</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 21:1; 士师记 11:35"> 然而，我们不可把我们的女儿嫁给他们为妻，因为以色列人曾起誓说：‘把妻子给便雅悯的人必受咒诅。’”</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 16:10; 申命记 16:1; 申命记 16:13"> 他们说：“看哪，每年在示罗有耶和华的节期；示罗在伯特利以北，在从伯特利上示剑的大路东边，又在利波拿以南。”</span>
<span className="v" id="v20" data-v="20"> 他们吩咐便雅悯人说：“你们去，埋伏在葡萄园里，</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 11:34; 出埃及记 15:20; 传道书 3:4"> 观看；看哪，如果示罗的女子出来跳舞，你们就从葡萄园里出来，各人从示罗的女子中抢一个为妻，然后往便雅悯地去。</span>
<span className="v" id="v22" data-v="22" data-xref="士师记 21:1; 士师记 21:18; 士师记 21:14"> 如果她们的父亲或兄弟来向我们申诉，我们就对他们说：‘请看在我们的情面上，把她们让给他们；因为我们在战争中没有为每个人夺取妻子，而你们也不是亲自把女儿给他们，所以你们并没有违背誓言。’”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="士师记 20:48"> 便雅悯人就这样做，按他们的人数，从跳舞的女子中掳去女子作自己的妻子。他们就起行，回到自己的产业，重建城邑，住在其中。</span>
<span className="v" id="v24" data-v="24"> 那时以色列人从那里离开，各归自己的支派和宗族；他们各自从那里出去，回到自己的产业。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 12:8; 士师记 17:6; 箴言 3:5"> 那些日子，以色列中没有王；人人都行自己眼中看为正的事。</span>
</div>

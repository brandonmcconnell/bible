<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 5:3; 士师记 3:12; 士师记 3:7"> 以笏死后，以色列人又行耶和华眼中看为恶的事。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 11:1; 士师记 4:16; 士师记 4:13"> 耶和华把他们卖在迦南王耶宾手中；耶宾在夏琐作王，他军队的统帅是西西拉，住在外邦人的哈罗设。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 1:19; 诗篇 106:42; 士师记 3:9"> 以色列人向耶和华呼求，因为耶宾有九百辆铁战车，并且大大欺压以色列人二十年。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 15:20; 路加福音 2:36; 列王纪下 22:14"> 那时，有一位女先知底波拉，是拉比多的妻子，治理以色列。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 18:19; 耶利米书 31:15; 出埃及记 18:26"> 她住在以法莲山地，在拉玛和伯特利之间底波拉的棕树下；以色列人都上到她那里求审判。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 13:47; 士师记 8:18; 希伯来书 11:32"> 她派人从拿弗他利的基低斯召来亚比挪庵的儿子巴拉，对他说：“耶和华——以色列的上帝岂不是已经吩咐说：‘你去，领路到他泊山，带着拿弗他利人和西布伦人一万人与你同行吗？</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 18:40; 以西结 38:10–16; 诗篇 83:9–10"> 我要把耶宾军队的统帅西西拉，连同他的战车和群众，引到你那里，到基顺河；我要把他交在你手中。’”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 4:10–14; 马太福音 14:30–31"> 巴拉对她说：“如果你同我去，我就去；如果你不同我去，我就不去。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="士师记 2:14; 撒母耳记上 2:30; 士师记 4:17–22"> 她说：“我一定同你去。不过，你所走的这路程不会成为你的荣耀，因为耶和华要把西西拉卖在一个女人手中。”于是底波拉起来，和巴拉一同往基低斯去。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="士师记 5:18; 士师记 5:15; 士师记 4:14"> 巴拉召集西布伦人和拿弗他利人到基低斯。有一万人跟随他；底波拉也同他上去。</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 1:16; 约书亚记 19:33; 民数记 10:29"> 基尼人希百已经离开基尼人，就是摩西的妻兄何巴的子孙，在靠近基低斯的撒拿音橡树旁支搭帐棚。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 89:12; 耶利米书 46:18; 约书亚记 19:12"> 有人告诉西西拉，亚比挪庵的儿子巴拉已经上了他泊山。</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 4:2–3; 士师记 4:7"> 西西拉就从外邦人的哈罗设召集他所有的战车，就是九百辆铁战车，以及所有跟随他的人，到基顺河。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命记 9:3; 撒母耳记下 5:24; 以赛亚书 52:12"> 底波拉对巴拉说：“起来！因为今天就是耶和华把西西拉交在你手中的日子。耶和华岂不是已经在你前面出去了吗？”于是巴拉从他泊山下去，有一万人跟随他。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 10:10; 诗篇 83:9–10; 士师记 5:20–21"> 耶和华在巴拉面前用刀剑使西西拉、他所有的战车和全军都溃乱。西西拉下了战车，徒步逃跑。</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 2:12; 利未记 26:7–8; 雅各书 2:13"> 巴拉追赶战车和军队，直到外邦人的哈罗设；西西拉的全军都倒在刀下，一个也没有留下。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="诗篇 69:22; 以赛亚书 57:21; 阿摩司 5:19–20"> 然而西西拉徒步逃到基尼人希百的妻子雅亿的帐棚那里，因为夏琐王耶宾和基尼人希百家之间有和平。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 6:19"> 雅亿出来迎接西西拉，对他说：“请进来，我主，请到我这里来；不要怕。”他就进了她的帐棚，她用毯子盖住他。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="士师记 5:25–26; 创世记 24:43; 以赛亚书 41:17"> 他对她说：“请给我一点水喝，因为我渴了。”<br />她打开一个盛奶的容器，给他喝了，又盖住他。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约书亚记 2:3–5; 撒母耳记下 17:20"> 他对她说：“你站在帐棚门口，如果有人来问你说：‘这里有人吗？’你就说：‘没有。’”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="士师记 5:26–27; 哥林多前书 1:27; 士师记 3:21"> 那时，希百的妻子雅亿拿了一根帐棚橛子，又手里拿着锤子，悄悄走到他那里，把橛子钉进他的太阳穴，直钉入地里；因为他睡得很熟。于是他昏迷而死。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 17:10–15; 撒母耳记下 17:3"> 看哪，巴拉追赶西西拉的时候，雅亿出来迎接他，对他说：“来，我把你所寻找的人指给你看。”他进到她那里；看哪，西西拉已经死了，帐棚橛子还在他的太阳穴里。</span>
<span className="v" id="v23" data-v="23" data-xref="尼希米记 9:24; 诗篇 18:47; 诗篇 18:39"> 这样，那一天上帝在以色列人面前制服了迦南王耶宾。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记上 3:12"> 以色列人的手越来越强，胜过迦南王耶宾，直到他们消灭了迦南王耶宾。</span>
</div>
</div>

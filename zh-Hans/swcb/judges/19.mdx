<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 18:1; 士师记 17:8; 玛拉基书 2:15"> 那些日子，以色列中没有王。有一个利未人寄居在以法莲山地偏远的一带，他从犹大的伯利恒为自己娶了一个妾。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结 16:28; 申命记 22:21; 利未记 21:9"> 他的妾行淫背叛他，离开他，回到犹大伯利恒她父亲的家，在那里住了四个月。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 34:3; 创世记 50:21; 利未记 19:17"> 她丈夫起身去追她，要用好话劝她，把她带回来；他带着仆人和两头驴。女子把他带进她父亲的家；那年轻女子的父亲看见他，就欢欢喜喜地迎接他。</span>
<span className="v" id="v4" data-v="4"> 他的岳父，就是那年轻女子的父亲，留他在那里；他就与他同住了三天。于是他们吃喝，并在那里住宿。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="士师记 19:8; 创世记 18:5; 诗篇 104:15"> 到了第四天，他们清早起来，他也起身要走。年轻女子的父亲对女婿说：“请吃一点饼，振作你的心，然后你再上路。”</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 19:9; 士师记 16:25; 路得记 3:7"> 于是二人一同坐下吃喝。年轻女子的父亲又对那人说：“请你愿意留下过夜，使你的心快乐。”</span>
<span className="v" id="v7" data-v="7"> 那人起身要走；但他的岳父挽留他，他又在那里住了一夜。</span>
<span className="v" id="v8" data-v="8"> 到了第五天，他清早起来要走；年轻女子的父亲说：“请吃点东西，振作你的心，等到日头偏西再走。”于是二人一同吃了。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="箴言 27:1; 路加福音 24:29; 雅各书 4:13–14"> 那人和他的妾、他的仆人起身要走的时候，他的岳父，就是那年轻女子的父亲，对他说：“看哪，现在日头快到晚上了，请你留下过夜。看哪，天快完了。请在这里住宿，使你的心快乐；明天清早上路，回你的家去。”</span>
<span className="v" id="v10" data-v="10" data-xref="约书亚记 15:63; 约书亚记 15:8; 士师记 1:8"> 但那人不愿那夜住宿，就起身离开，来到耶布斯附近，就是耶路撒冷。他带着两头备好鞍的驴，他的妾也与他同在。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 5:6; 士师记 1:21; 士师记 19:10"> 他们到了耶布斯附近，天色已经很晚；仆人对主人说：“请来吧，我们进这耶布斯人的城，在里面住宿。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 主人对他说：“我们不可进不是以色列人之子的外族人的城；我们要往基比亚去。”</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 10:26; 何西阿 5:8; 以赛亚书 10:29"> 他又对仆人说：“来吧，我们靠近这些地方中的一个，或在基比亚，或在拉玛住宿。”</span>
<span className="v" id="v14" data-v="14"> 于是他们继续前行；太阳在他们将近属于便雅悯的基比亚时落下了。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 19:18; 马太福音 25:35; 马太福音 25:43"> 他们就转到那里，要进基比亚住宿。他进去，坐在城里的街上；因为没有人接他们到家里住宿。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="士师记 19:1; 诗篇 104:23; 创世记 3:19"> 看哪，傍晚有一个老人从田间工作回来。这人原是以法莲山地的人，寄居在基比亚；但那地方的人是便雅悯人。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 32:17; 创世记 16:8"> 他举目，看见城里街上那赶路的人；老人就说：“你往哪里去？从哪里来？”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="士师记 18:31; 约翰福音 15:6; 撒母耳记上 1:7"> 他对他说：“我们从犹大伯利恒往以法莲山地偏远的一带去。我是那里的人，我去了犹大伯利恒。现在我要去耶和华的殿；却没有人接我进他的家。</span>
<span className="v" id="v19" data-v="19"> 其实我们有草和饲料给驴，也有饼和酒给我、给你的婢女，以及给与你仆人们同在的少年人；什么都不缺。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="士师记 6:23; 雅各书 2:15–16; 希伯来书 13:2"> 老人说：“愿你平安！你一切所需只管让我供应，只是不可在街上过夜。”</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 43:24; 创世记 18:4; 路加福音 7:44"> 于是他把那人带进自己的家，给驴喂了饲料。他们洗了脚，就吃喝。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 19:4–5; 哥林多前书 6:9; 士师记 20:5"> 他们正使心快乐的时候，看哪，城里的人，一些邪恶之徒，围住房子，敲打门；他们对房子的主人，就是那老人，说：“把进你家的那个人带出来，好让我们与他交合！”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="创世记 34:7; 撒母耳记下 13:12; 士师记 20:6"> 那人，就是房子的主人，出去见他们，对他们说：“不，我的弟兄们，请不要这样作恶；既然这人进了我的家，就不要行这样的丑事。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 19:8; 申命记 21:14; 创世记 34:2"> 看哪，这里有我的处女女儿和他的妾；我现在把她们带出来。你们可以凌辱她们，按你们看为好的待她们；只是对这人，不可行这样的丑事。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="何西阿 10:9; 何西阿 9:9; 何西阿 7:4–7"> 但那些人不肯听他；那人就抓住自己的妾，把她带出去交给他们；他们与她交合，整夜凌辱她，直到早晨。天开始发亮的时候，他们才放她走。</span>
<span className="v" id="v26" data-v="26" data-xref="士师记 19:3; 创世记 18:12; 彼得前书 3:6"> 天快亮的时候，那女人来到她主人所在的那人家门口，倒在那里，直到天亮。</span>
<span className="v" id="v27" data-v="27"> 她的主人早晨起来，打开房门，出去要上路；看哪，那女人，就是他的妾，倒在房门口，两手搭在门槛上。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="士师记 20:5; 列王纪上 18:29"> 他对她说：“起来，我们走吧！”可是没有人回答。于是他把她驮在驴上；那人起身，回自己的地方去了。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="士师记 20:6–7; 撒母耳记上 11:7; 罗马书 10:2"> 他进了自己的家，就拿刀把他的妾切开，按着肢体分成十二块，送到以色列全境。</span>
<span className="v" id="v30" data-v="30" data-xref="士师记 20:7; 箴言 13:10; 何西阿 9:9"> 凡看见的人都说：“从以色列人出埃及地的日子直到今日，从未行过、也未见过这样的事！你们要思想，要商议，要说出来。”</span>
</div>
</div>

<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 5:1–4; 马可福音 13:34; 雅歌 8:11–12"> 耶稣开始用比喻对他们说：<span className="woj">“有一个人栽种了一个葡萄园，四面围上篱笆，挖了一个榨酒池，建了一座守望塔，然后租给园户，就去外国了。</span></span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 15:1–8; 希伯来书 1:1; 耶利米书 44:4"> <span className="woj">到了收获的季节，他打发一个仆人到园户那里，要从他们那里收纳自己应得的葡萄园果子。</span></span>
<span className="v" id="v3" data-v="3" data-xref="帖撒罗尼迦前书 2:15; 尼希米记 9:26; 耶利米书 29:26"> <span className="woj">园户却抓住他，打了他一顿，叫他空手回去。</span></span>
<span className="v" id="v4" data-v="4"> <span className="woj">主人又打发另一个仆人到他们那里；他们用石头打伤了他的头，并且狠狠地侮辱他。</span></span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 22:6; 马太福音 23:37; 尼希米记 9:30"> <span className="woj">主人又打发一个去，他们就把他杀了。后来又打发了许多仆人去，有的被他们打了，有的被他们杀了。</span></span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 1:1–2; 马太福音 3:17; 约翰福音 1:34"> <span className="woj">园主只剩下一个人，就是他的爱子。最后他把儿子打发去，说：‘他们会尊重我的儿子的。’</span></span>
<span className="v" id="v7" data-v="7" data-xref="创世记 37:20; 马太福音 2:16; 使徒行传 2:23"> <span className="woj">那些园户却彼此说：‘这是继承人。来吧，我们杀了他，产业就归我们了。’</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 21:39; 路加福音 20:15; 马太福音 21:33"> <span className="woj">他们就抓住他，杀了他，把他扔出葡萄园外。</span></span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 10:20–12; 马太福音 21:43; 路加福音 19:27"> <span className="woj">那么，葡萄园的主人会怎么做呢？他必来除灭那些园户，把葡萄园租给别人。</span></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 118:22–23; 彼得前书 2:7–8; 以赛亚书 28:16"> <span className="woj">你们连这节经文也没有念过吗：</span><br /><span className="pl pl-1 woj">‘工匠弃绝的石头，</span><br /><span className="pl pl-2 woj">成了房角的头块石头。</span></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 118:23; 使徒行传 3:12–16; 哈巴谷 1:5"> <span className="pl pl-1 woj">这是主所做的，</span><br /><span className="pl pl-2 woj">在我们眼中看为奇妙’？”</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马可福音 11:18; 马太福音 22:22; 约翰福音 7:44"> 他们看出这比喻是指着他们说的，就想逮捕祂，但又害怕群众，只好离开祂走了。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 20:20–26; 路加福音 11:54; 马可福音 3:6"> 后来，他们打发几个法利赛人和希律党人到耶稣那里，要在祂的话语上找把柄。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:4; 路加福音 20:22; 约翰福音 7:18"> 他们来了，就问祂：“老师，我们知道祢是诚实的，不偏徇任何人；因为祢不看人的情面，而是按真理教导上帝的道。纳税给凯撒合法不合法？</span>
<span className="v" id="v15" data-v="15" data-xref="以西结 17:2; 启示录 2:23; 马可福音 10:2"> 我们该纳不该纳？”<br />耶稣看穿了他们的虚伪，就对他们说：<span className="woj">“你们为什么试探我？拿一个银币来给我看。”</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 20:24–26; 启示录 3:12; 马太福音 22:19–22"> 他们拿了来。<br />耶稣问他们：<span className="woj">“这像和名号是谁的？”</span><br />他们对祂说：“凯撒的。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 13:7; 彼得前书 2:17; 哥林多后书 5:14–15"> 耶稣回答他们说：<span className="woj">“凯撒的归给凯撒，上帝的归给上帝。”</span><br />他们对祂非常惊奇。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 22:23–33; 使徒行传 4:1–2; 使徒行传 23:6–9"> 撒都该人向来认为没有复活，他们来到耶稣那里，问祂说：</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 25:5–10; 路得记 4:5; 路得记 1:11–13"> “老师，摩西为我们写下规条：‘人的哥哥若死了，留下妻子，没有留下孩子，他的弟弟就当娶他的妻子，为哥哥生养后代。’</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 22:25–28; 路加福音 20:29–33"> 从前有兄弟七人。第一个娶了妻子，死了没有留下后代。</span>
<span className="v" id="v21" data-v="21"> 第二个娶了她，也死了，没有留下孩子。第三个也是这样。</span>
<span className="v" id="v22" data-v="22"> 七个人娶了她，都没有留下孩子。最后，那女人也死了。</span>
<span className="v" id="v23" data-v="23"> 在复活的时候，当他们复活，她将是谁的妻子呢？因为七个人都娶过她。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约翰福音 20:9; 提摩太后书 3:15–17; 马太福音 22:29"> 耶稣回答他们说：<span className="woj">“你们错了，岂不是因为你们不明白圣经，也不晓得上帝的大能吗？</span></span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 20:35–36; 马太福音 22:30; 约翰一书 3:2"> <span className="woj">当人们从死里复活的时候，既不娶也不嫁，而是像天上的天使一样。</span></span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 3:2–6; 路加福音 20:37; 创世记 17:7–8"> <span className="woj">至于死人复活的事，你们没有读过摩西书上《荆棘篇》里，上帝是怎么对他说的吗？上帝说：‘我是亚伯拉罕的上帝，以撒的上帝，雅各的上帝。’</span></span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 14:9; 罗马书 4:17; 马可福音 12:24"> <span className="woj">祂不是死人的上帝，而是活人的上帝。你们是大错特错了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马太福音 22:34–40; 路加福音 10:25–28; 路加福音 20:39"> 有一个文士听见他们辩论，知道耶稣回答得好，就走上前去问祂：“所有的诫命中，哪一条是最大的呢？”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="申命记 6:4; 路加福音 10:27; 加拉太书 3:20"> 耶稣回答：<span className="woj">“最大的是：‘以色列啊，你要听，耶和华我们的上帝，耶和华是独一的。</span></span>
<span className="v" id="v30" data-v="30" data-xref="申命记 6:5"> <span className="woj">你要尽心、尽性、尽意、尽力爱耶和华你的上帝。’</span><span className="woj">这是第一条诫命。</span></span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 13:8–9; 马太福音 22:39; 利未记 19:18"> <span className="woj">第二条也是如此：‘要爱邻如己。’</span><span className="woj">再没有别的诫命比这两条更大的了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="申命记 4:39; 申命记 4:35; 以赛亚书 46:9"> 那文士对耶稣说：“老师，说得真对，祢说祂是独一的，除了祂以外，再没有别的；</span>
<span className="v" id="v33" data-v="33" data-xref="何西阿 6:6; 弥迦书 6:6–8; 撒母耳记上 15:22"> 并且尽心、尽智、尽性、尽力爱祂，又爱邻如己，这比一切的燔祭和各样祭物重要得多。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v34" data-v="34" data-xref="歌罗西书 4:6; 路加福音 20:40; 马太福音 22:46"> 耶稣见他回答得有智慧，就对他说：<span className="woj">“你离上帝的国不远了。”</span><br />从此以后，没有人敢再问祂任何问题。</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 20:41–44; 马太福音 22:41–45; 马太福音 26:55"> 耶稣在圣殿里教导人的时候，回应说：<span className="woj">“文士怎么说基督是大卫的子孙呢？</span></span>
<span className="v" id="v36" data-v="36" data-xref="诗篇 110:1; 希伯来书 1:13; 马太福音 22:43–45"> <span className="woj">大卫自己被圣灵感动说：</span><br /><span className="pl pl-1 woj">‘耶和华对我主说，</span><br /><span className="pl pl-2 woj">“坐在我的右边，</span><br /><span className="pl pl-2 woj">等我使祢的仇敌作祢的脚凳。”’</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="罗马书 1:3–4; 马太福音 11:25; 马太福音 1:23"> <span className="woj">大卫自己都称祂为主，祂又怎么会是大卫的子孙呢？”</span><br />大群的百姓都欢喜听祂。</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 23:1–7; 路加福音 20:45–47; 路加福音 11:43"> 耶稣在教导中对他们说：<span className="woj">“要提防文士。他们喜欢穿长袍走来走去，喜欢人们在街市上向他们问安，</span></span>
<span className="v" id="v39" data-v="39" data-xref="雅各书 2:2–3"> <span className="woj">又喜欢会堂里的高位，和宴席上的首座。</span></span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 23:13; 路加福音 20:47; 马太福音 23:33"> <span className="woj">他们吞没了寡妇的房产，假意作长长的祷告。这些人必受更重的惩罚。”</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 21:1–4; 列王纪下 12:9; 约翰福音 8:20"> 耶稣对着圣殿的奉献箱坐下，观看群众怎样把钱投入箱中。有许多富人投进了许多钱。</span>
<span className="v" id="v42" data-v="42"> 有一个穷寡妇来，投了两个小铜钱，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="原文为“雷普塔”（lepta）。雷普塔是非常小的铜钱，每个价值半个“克特兰”（quadrans），也就是四分之一的阿萨利昂（assarion）铜币。雷普塔的价值不到农业工人一天工资的百分之一。">a</a></sup>就是一个大文钱。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“克特兰”是一种硬币，价值约等于一个银币的六十四分之一。一个银币约等于农业工人一天的工资。">b</a></sup></span>
<span className="v" id="v43" data-v="43" data-xref="哥林多后书 9:6–8; 哥林多后书 8:2; 使徒行传 11:29"> 耶稣把门徒叫来，对他们说：<span className="woj">“我确实地告诉你们，这穷寡妇投入奉献箱的，比所有人投的都多。</span></span>
<span className="v" id="v44" data-v="44" data-xref="哥林多后书 8:2–3; 约翰一书 3:17; 以斯拉记 2:68–69"> <span className="woj">因为他们都是从自己的富余中拿出捐项，但这寡妇是从自己的匮乏中，把她所有的一切，就是她赖以为生的全部，都投进去了。”</span></span>
</div>
</div>

## 脚注

<ol className="fnl">
<li id="fn-a"><a href="#fnref-a" className="fnb">a</a> <span className="fnr">12:42</span> 原文为“雷普塔”（lepta）。雷普塔是非常小的铜钱，每个价值半个“克特兰”（quadrans），也就是四分之一的阿萨利昂（assarion）铜币。雷普塔的价值不到农业工人一天工资的百分之一。</li>
<li id="fn-b"><a href="#fnref-b" className="fnb">b</a> <span className="fnr">12:42</span> “克特兰”是一种硬币，价值约等于一个银币的六十四分之一。一个银币约等于农业工人一天的工资。</li>
</ol>

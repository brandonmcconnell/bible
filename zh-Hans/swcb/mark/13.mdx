</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="路加福音 21:6; 马太福音 24:2; 列王纪上 9:7–8"> 耶稣对他说：<span className="woj">“你看见这些伟大的建筑了吗？将来在这里绝没有一块石头留在另一块石头上而不被拆毁的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马太福音 21:1; 马可福音 4:34; 马可福音 14:33"> 耶稣在橄榄山上对着圣殿坐着，彼得、雅各、约翰和安得烈私下问祂：</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 1:6–7; 马太福音 24:3; 但以理 12:6"> “请告诉我们，什么时候会有这些事呢？这一切事将要成就的时候，会有什么预兆呢？”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="歌罗西书 2:8; 以弗所书 5:6; 耶利米书 29:8"> 耶稣回答，开始对他们说：<span className="woj">“你们要谨慎，免得有人迷惑你们。</span></span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 13:22; 耶利米书 23:21–25; 约翰福音 8:24"> <span className="woj">因为将有许多人冒我的名来，说：‘我就是那一位！’</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“我就是”。">a</a></sup><span className="woj">并且要迷惑许多人。</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="路加福音 21:9–11; 约翰福音 14:27; 马太福音 24:6–7"> <span className="woj">“当你们听见打仗和打仗的风声，不要惊慌。这些事必须发生，但末日还没有到。</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 24:8; 以赛亚书 37:3; 诗篇 48:6"> <span className="woj">民要攻打民，国要攻打国。多处将有地震，也会有饥荒。这些都是生产之痛的开始。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马太福音 10:17–18; 约翰福音 16:2; 腓立比书 1:29"> <span className="woj">“但你们自己要谨慎，因为他们要把你们交给议会。你们将在会堂里受鞭打。你们还要为我的缘故站在统治者和君王面前，对他们作见证。</span></span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 24:14; 歌罗西书 1:23; 罗马书 10:18"> <span className="woj">然而，福音必须先传给万民。</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 21:14–15; 路加福音 12:11–12; 马太福音 10:19–21"> <span className="woj">当他们把你们押去交给人时，不要事先忧虑要说什么，也不要预谋；在那一刻赐给你们什么话，你们就说什么。因为说话的不是你们，而是圣灵。</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 10:21; 路加福音 12:52–53; 路加福音 21:16"> <span className="woj">“兄弟将要把兄弟交去处死，父亲对孩子也会这样。儿女将起来与父母为敌，害死他们。</span></span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 15:18–19; 马太福音 10:22; 马太福音 24:13"> <span className="woj">你们将为我的名被众人恨恶，但忍耐到底的，必然得救。</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="但以理 9:27; 但以理 12:11; 但以理 11:31"> <span className="woj">“当你们看见先知但以理所说的‘那带来荒凉的可憎之物’</span><span className="woj">站在不当站的地方”</span>（读者须留意），<span className="woj">“那时，在犹太的，应当逃到山上；</span></span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 17:31–33; 希伯来书 11:7; 腓立比书 3:7–8"> <span className="woj">在屋顶上的，不要下来，也不要进去从家里拿任何东西；</span></span>
<span className="v" id="v16" data-v="16"> <span className="woj">在田里的，也不要回去取外衣。</span></span>
<span className="v" id="v17" data-v="17" data-xref="耶利米哀歌 4:10; 路加福音 23:29; 何西阿 9:14"> <span className="woj">在那些日子，孕妇和哺乳的母亲有祸了！</span></span>
<span className="v" id="v18" data-v="18"> <span className="woj">你们要祷告，免得你们的逃亡发生在冬天。</span></span>
<span className="v" id="v19" data-v="19" data-xref="但以理 12:1; 约珥 2:2; 马太福音 24:21"> <span className="woj">因为在那些日子必有苦难，自从上帝创造万物直到如今，从来没有过这样的苦难，将来也绝不会再有。</span></span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 24:22; 撒迦利亚书 13:8–9; 以赛亚书 65:8–9"> <span className="woj">若不是主减少了那日子，没有任何肉体可以得救；但为了祂所拣选的选民，祂将那日子减少了。</span></span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 21:8; 马太福音 24:23–25; 马太福音 24:5"> <span className="woj">那时，若有人对你们说：‘看哪，基督在这里！’或说：‘看哪，在那里！’你们不要信。</span></span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 24:24; 帖撒罗尼迦后书 2:8–14; 马可福音 13:6"> <span className="woj">因为假基督和假先知将要起来，显神迹奇事，如果可能的话，甚至连选民也要迷惑。</span></span>
<span className="v" id="v23" data-v="23" data-xref="彼得后书 3:17; 马可福音 13:5; 约翰福音 14:29"> <span className="woj">你们要谨慎。</span><br /><span className="woj">“看哪，我已经把一切都预先告诉你们了。</span></span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 13:10; 使徒行传 2:19–20; 启示录 6:12–14"> <span className="woj">“但在那些日子，那苦难之后，太阳将要变黑，月亮也不发光，</span></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 34:4; 启示录 6:13"> <span className="woj">众星将从天上坠落，天上的万象都将震动。</span></span>
<span className="v" id="v26" data-v="26" data-xref="启示录 1:7; 马太福音 16:27; 马太福音 24:30"> <span className="woj">那时，人们将看见人子带着大能力和大荣耀驾云降临。</span></span>
<span className="v" id="v27" data-v="27" data-xref="撒迦利亚书 2:6; 马太福音 24:31; 申命记 30:4"> <span className="woj">那时，祂要差遣天使，从四方，从地极到天边，把祂的选民聚集起来。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 21:29–31; 马太福音 24:32–33"> <span className="woj">“你们要从无花果树学个比喻：当树枝发嫩长叶的时候，你们就知道夏天近了；</span></span>
<span className="v" id="v29" data-v="29" data-xref="彼得前书 4:17–18; 雅各书 5:9; 以西结 12:25–28"> <span className="woj">照样，当你们看见这些事发生，就知道时候近了，就在门口了。</span></span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 24:34; 路加福音 21:32; 马太福音 16:28"> <span className="woj">我确实地告诉你们，这世代</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="此处译作“世代”的词（genea）也可译作“种族”、“家族”或“人民”。">b</a></sup><span className="woj">还没有过去，这一切事都要发生。</span></span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 40:8; 以赛亚书 51:6; 马太福音 24:35"> <span className="woj">天地都要废去，我的话却绝不废去。</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行传 1:7; 马太福音 24:36–42; 马太福音 25:13"> <span className="woj">“但关于那日子或那时辰，没有人知道，连天上的天使也不知道，子也不知道，唯独父知道。</span></span>
<span className="v" id="v33" data-v="33" data-xref="以弗所书 6:18; 路加福音 12:40; 罗马书 13:11–12"> <span className="woj">你们要谨慎，时刻警醒祷告；因为你们不知道那时期什么时候来到。</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马太福音 25:14–30; 约翰福音 10:3; 路加福音 12:36–40"> <span className="woj">“这就像一个人出国远行，离开自己的家，把权柄交给他的仆人们，分派各人当做的工作，又吩咐看门的人要警醒。</span></span>
<span className="v" id="v35" data-v="35" data-xref="马可福音 13:33; 马太福音 24:42; 马太福音 24:44"> <span className="woj">所以你们要警醒，因为你们不知道这家的主人什么时候来——或许在黄昏，或许在半夜，或许在鸡叫时，或许在清晨；</span></span>
<span className="v" id="v36" data-v="36" data-xref="帖撒罗尼迦前书 5:6–7; 罗马书 13:11–14; 马太福音 24:48–51"> <span className="woj">免得他忽然来到，发现你们在睡觉。</span></span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 13:33; 路加福音 12:41–46; 马可福音 13:35"> <span className="woj">我对你们说的话，也是对众人说的：要警醒！”</span></span>
</div>

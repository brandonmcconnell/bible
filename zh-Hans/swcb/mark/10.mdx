<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 10:40; 马可福音 4:2; 约翰福音 11:7"> 耶稣从那里起身，来到犹太的境界和约旦河对岸。群众又聚集到祂那里。祂照常又教导他们。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 7:10–11; 路加福音 11:53–54; 约翰福音 8:6"> 有法利赛人来试探耶稣，问祂说：“丈夫休妻合法吗？”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 8:20; 加拉太书 4:21; 路加福音 10:25"> 耶稣回答说：<span className="woj">“摩西吩咐你们的是什么？”</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="申命记 24:1–4; 马太福音 5:31–32; 以赛亚书 50:1"> 他们说：“摩西准许人写了休书就可以休妻。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马太福音 19:8; 尼希米记 9:26; 使徒行传 7:51"> 但耶稣对他们说：<span className="woj">“正是因为你们心硬，他才写这条诫命给你们。</span></span>
<span className="v" id="v6" data-v="6" data-xref="创世记 1:27; 创世记 5:2; 创世记 1:1"> <span className="woj">但从创世之初，上帝造人是造男造女。</span></span>
<span className="v" id="v7" data-v="7" data-xref="创世记 2:24; 马太福音 19:5–6; 以弗所书 5:31"> <span className="woj">因此，人要离开父母，与妻子联合，</span></span>
<span className="v" id="v8" data-v="8" data-xref="以弗所书 5:28; 创世记 2:24; 哥林多前书 6:16"> <span className="woj">两人成为一体。</span><span className="woj">这样，他们不再是两个人，而是一体了。</span></span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 7:1–3; 历代志上 7:10–13"> <span className="woj">所以，上帝所配合的，人不可分开。”</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马可福音 9:33; 马可福音 9:28; 马可福音 4:10"> 到了屋里，门徒又问祂同样的事。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 5:31–32; 马太福音 19:9; 哥林多前书 7:10–11"> 祂对他们说：<span className="woj">“凡休妻另娶的，就是犯了淫乱得罪她。</span></span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 7:11; 哥林多前书 7:13"> <span className="woj">妻子若离弃丈夫另嫁，也是犯了淫乱。”</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马太福音 19:13–15; 路加福音 18:15–17; 出埃及记 10:9–11"> 有人带着小孩子来见耶稣，要祂摸他们，门徒却责备那些带孩子来的人。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 19:14; 马太福音 18:10; 马太福音 18:4"> 耶稣看见就很生气，对他们说：<span className="woj">“让小孩子到我这里来！不要阻止他们，因为上帝的国正属于这样的人。</span></span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 18:3; 路加福音 18:17; 约翰福音 3:3–6"> <span className="woj">我确实地告诉你们，凡不像小孩子一样接受上帝国的，绝不能进去。”</span></span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 9:36; 以赛亚书 40:11; 约翰福音 21:15–17"> 于是祂把他们抱在怀里，按手在他们头上，为他们祝福。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 19:16–30; 路加福音 18:18–30; 罗马书 2:7"> 耶稣出来行路的时候，有一个人跑来，跪在祂面前，问祂说：“良善的老师，我该做什么才能承受永生？”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 18:19; 马太福音 19:17; 罗马书 3:12"> 耶稣对他说：<span className="woj">“你为什么称我良善呢？除了上帝一位之外，再没有良善的。</span></span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 20:12–17; 罗马书 13:9; 雅各书 2:11"> <span className="woj">你知道这些诫命：‘不可谋杀’，‘不可奸淫’，‘不可偷窃’，‘不可作假见证’，‘不可欺诈’，‘当孝敬父母’。”</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以西结 33:31–32; 提摩太后书 3:5; 腓立比书 3:6"> 他对耶稣说：“老师，这一切我从小都遵守了。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马太福音 6:19–21; 启示录 2:4; 路加福音 18:22"> 耶稣看着他，就爱他，对他说：<span className="woj">“你还缺少一样。去变卖你所有的，分给穷人，你就必有财宝在天上；然后来，背起十字架跟从我。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约翰一书 2:15–16; 提摩太前书 6:9–10; 路加福音 12:15"> 他听见这话，脸色就沉了下来，忧愁地走了，因为他有许多财产。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 1:26; 路加福音 18:24; 马可福音 3:5"> 耶稣周围一看，对门徒说：<span className="woj">“有钱财的人进上帝的国，是何等困难啊！”</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="雅各书 5:1–3; 箴言 11:28; 诗篇 52:7"> 门徒对祂的话感到惊奇。但耶稣又对他们说：<span className="woj">“孩子们，倚靠钱财的人进上帝的国，是何等困难啊！</span></span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 19:24–25; 路加福音 18:25; 马太福音 23:24"> <span className="woj">骆驼穿过针眼，比财主进上帝的国还容易呢。”</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 16:31; 哥林多后书 11:23; 罗马书 10:9–13"> 门徒就极其惊讶，对祂说：“这样谁能得救呢？”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马太福音 19:26; 耶利米书 32:27; 约伯记 42:2"> 耶稣看着他们说：<span className="woj">“在人是不能的，在上帝却不然，因为在上帝凡事都能。”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马太福音 19:27–30; 路加福音 18:28–30; 路加福音 14:33"> 彼得就对祂说：“看哪，我们已经撇下一切跟从祢了。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 9:23; 马太福音 5:10–11; 马可福音 8:35"> 耶稣说：<span className="woj">“我确实地告诉你们，无论谁为了我和福音的缘故，撇下房屋、兄弟、姐妹、父亲、母亲、妻子、儿女或田地，</span></span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 18:30; 腓立比书 3:8; 哥林多后书 6:10"> <span className="woj">没有不在今世得百倍的：就是房屋、兄弟、姐妹、母亲、儿女和田地，并且要受逼迫；在来世必得永生。</span></span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 19:30; 路加福音 13:30; 马太福音 20:16"> <span className="woj">然而，许多在前的将要在后，在后的将要在前。”</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马太福音 20:17–19; 路加福音 18:31–34; 路加福音 9:51"> 他们行在路上，要上耶路撒冷去；耶稣走在他们前面。门徒很惊奇，跟从的人也害怕。耶稣又把十二使徒带到一边，开始把将要发生在祂身上的事告诉他们：</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 27:2; 马太福音 20:17–19; 马可福音 8:31"> <span className="woj">“看哪，我们正在上耶路撒冷去。人子将被交给祭司长和文士。他们将定祂死罪，并把祂交给外邦人。</span></span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 26:67; 马太福音 16:21; 马可福音 14:65"> <span className="woj">他们要戏弄祂，向祂吐唾沫，鞭打祂，杀害祂。第三天祂要复活。”</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 20:20–28; 撒母耳记下 14:4–11; 列王纪上 2:20"> 西庇太的儿子雅各和约翰进前来，对耶稣说：“老师，我们求祢，无论我们向祢求什么，都愿祢为我们成就。”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="约翰福音 15:7; 列王纪上 3:5–15; 马可福音 10:51"> 耶稣问他们：<span className="woj">“你们要我为你们做什么？”</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="马太福音 19:28; 马可福音 16:19; 路加福音 24:26"> 他们对祂说：“在祢得荣耀的时候，赐我们一个坐在祢右边，一个坐在祢左边。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="路加福音 12:50; 马太福音 20:21–22; 诗篇 75:8"> 但耶稣对他们说：<span className="woj">“你们不知道自己求的是什么。我喝的杯，你们能喝吗？我受的洗，你们能受吗？”</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="使徒行传 12:2; 启示录 1:9; 约翰福音 17:14"> 他们对祂说：“我们能。”<br />耶稣对他们说：<span className="woj">“我喝的杯，你们固然要喝；我受的洗，你们固然要受；</span></span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 20:23; 马太福音 25:34; 约翰福音 17:24"> <span className="woj">只是坐在我的右边和左边，不是我可以赐的，而是为谁预备的，就赐给谁。”</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="马太福音 20:24; 箴言 13:10; 罗马书 12:10"> 那十个门徒听见了，就开始对雅各和约翰感到恼怒。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="彼得前书 5:3; 路加福音 22:25; 马太福音 20:25"> 耶稣把他们叫来，对他们说：<span className="woj">“你们知道，外邦人有被尊为首领的在他们身上作威作福，也有大人物对他们滥用权柄。</span></span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 23:8–12; 路加福音 14:11; 马可福音 9:35"> <span className="woj">但在你们中间不可这样；相反，谁想在你们中间成为大的，就要做你们的仆人；</span></span>
<span className="v" id="v44" data-v="44"> <span className="woj">你们中间谁想居首位，就要做众人的奴仆。</span></span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 20:28; 腓立比书 2:5–8; 哥林多后书 8:9"> <span className="woj">因为人子来，也不是要受人的服事，而是要服事人，并且要舍命，作多人的赎价。”</span></span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="路加福音 18:35–1; 马太福音 20:29–34; 约翰福音 9:8"> 他们来到耶利哥。当耶稣同门徒和一大群人出耶利哥的时候，有一个瞎眼的乞丐，就是底买的儿子巴底买，正坐在路边。</span>
<span className="v" id="v47" data-v="47" data-xref="马可福音 1:24; 马太福音 9:27; 启示录 22:16"> 他听见是拿撒勒人耶稣，就开始喊叫说：“大卫的子孙耶稣啊，怜悯我吧！”</span>
<span className="v" id="v48" data-v="48" data-xref="耶利米书 29:13; 马可福音 7:26–29; 希伯来书 5:7"> 许多人责备他，叫他安静，他却越发大声喊叫：“大卫的子孙啊，怜悯我吧！”</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49" data-xref="路加福音 18:40; 马太福音 20:32–34; 约翰福音 11:28"> 耶稣停住脚步，说：<span className="woj">“叫他过来。”</span><br />他们就叫那瞎子，对他说：“放心！起来，祂叫你呢！”</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="腓立比书 3:7–9; 希伯来书 12:1"> 瞎子丢下他的外衣，跳起来，走到耶稣面前。</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="路加福音 18:41–43; 马可福音 10:36; 马太福音 7:7"> 耶稣问他：<span className="woj">“你要我为你做什么？”</span><br />瞎子对祂说：“拉波尼，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“拉波尼”是希伯来语的音译，意为“伟大的老师”。">a</a></sup>我要能看见。”</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="马太福音 9:22; 使徒行传 26:18; 马可福音 8:25"> 耶稣对他说：<span className="woj">“你去吧。你的信心救了你。”</span>瞎子立刻就看见了，便在路上跟从了耶稣。</span>
</div>
</div>

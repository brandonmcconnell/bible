<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 8:26–39; 马太福音 8:28–34; 马可福音 4:35"> 他们来到海的对岸，进入格拉森人的地区。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 1:23; 以赛亚书 65:4; 马可福音 5:8"> 耶稣刚下船，立刻就有一个被污鬼附着的人从坟茔里出来迎着祂。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 65:4; 路加福音 8:29; 但以理 4:32–33"> 那人住在坟茔里。再也没有人能绑住他，就是用铁链也不行；</span>
<span className="v" id="v4" data-v="4" data-xref="雅各书 3:7–8"> 因为人屡次用脚镣和铁链捆绑他，铁链却被他挣断，脚镣也被他弄碎了。没有人能制伏他。</span>
<span className="v" id="v5" data-v="5" data-xref="约伯记 2:7–8; 列王纪上 18:28; 约翰福音 8:44"> 他日夜常在坟茔和山野间大声喊叫，又用石头割自己。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 2:19; 诗篇 66:3; 路加福音 4:41"> 他从远处看见耶稣，就跑过去拜祂，</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 8:29; 使徒行传 16:17; 马太福音 26:63"> 大声呼叫说：“至高上帝的儿子耶稣，我与祢有什么相干？我指着上帝恳求祢，不要折磨我！”</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 1:25; 马可福音 9:25–26; 使徒行传 16:18"> 这是因为耶稣曾对他说：“污鬼，从这人里面出来！”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 8:30; 马可福音 5:15; 马太福音 26:53"> 耶稣问他：“你叫什么名字？”</span>
<span className="v" id="v10" data-v="10" data-xref="马可福音 3:22; 马可福音 5:13"> 他回答说：“我的名字叫‘群’，因为我们数目众多。”他再三恳求耶稣，不要把他们赶出那个地区。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 11:7–8; 以赛亚书 65:4; 以赛亚书 66:3"> 当时，在山坡上有一大群猪正在吃食。</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 2:11; 约伯记 1:10–12; 路加福音 22:31–32"> 所有的鬼都恳求耶稣说：“打发我们进入猪群，好让我们附在它们身上吧。”</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪上 22:22; 彼得前书 3:22; 约伯记 2:6"> 耶稣立刻准许了它们。污鬼就出来，进入猪群。那群猪大约有两千头，便冲下悬崖，投入海里淹死了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 8:34; 马太福音 8:33"> 放猪的人逃跑了，去到城里和乡下传开这事。人们就来看发生了什么事。</span>
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 1:13; 提摩太后书 1:7; 撒母耳记上 6:20–21"> 他们来到耶稣那里，看见那曾被鬼附着、体内有“群”鬼的人，正坐着，穿戴整齐，神智清醒；他们就害怕起来。</span>
<span className="v" id="v16" data-v="16"> 看见这事的人，把那被鬼附的人所经历的，以及猪群的事，都告诉了大家。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 8:34; 马可福音 1:24; 路加福音 8:37"> 众人就开始恳求耶稣离开他们的地区。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 8:38–39; 腓立比书 1:23–24; 马可福音 5:17"> 耶稣上船的时候，那曾被鬼附的人恳求要和祂在一起。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 66:16; 约翰福音 4:29; 以赛亚书 38:9–20"> 耶稣不许，却对他说：“你回家去，到你的亲友那里，把主为你做了何等伟大的事，以及祂怎样怜悯你，都告诉他们。”</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 7:31; 马太福音 4:25"> 那人就走了，开始在低加波利宣扬耶稣为他做了何等伟大的事，众人听了都十分惊奇。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马太福音 9:1; 马可福音 4:1; 路加福音 8:40"> 耶稣乘船又渡回对岸，有一大群人聚集到祂那里；祂就在海边。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 13:14; 使徒行传 18:8; 马可福音 5:35–36"> 看哪，有一个名叫崖鲁的会堂主管来了；他一看见耶稣，就俯伏在祂脚前，</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 13:13; 路加福音 4:40; 马可福音 16:18"> 再三恳求祂说：“我的小女儿快要死了。求祢去按手在她身上，使她痊愈，可以活下去。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="马可福音 5:31; 马可福音 3:20; 路加福音 7:6"> 耶稣就同他去。一大群人跟随祂，四面拥挤着祂。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 15:25–27; 路加福音 8:43–44; 马太福音 9:20–22"> 有一个女人，患了十二年的血漏病，</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 30:12–13; 耶利米书 8:22; 诗篇 108:12"> 在许多医生手里受了许多苦，花尽了她所有的一切，病情不但没有好转，反而更重了。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 19:12; 马太福音 14:36; 使徒行传 5:15"> 她听见有关耶稣的事，就夹在群众中走到耶稣背后，摸祂的衣服。</span>
<span className="v" id="v28" data-v="28"> 因为她说：“我只要摸到祂的衣服，就会痊愈的。”</span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 5:34; 诗篇 30:2; 马可福音 3:10"> 她的血漏立刻止住了，她感觉到自己身上的病已经痊愈。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 6:19; 路加福音 8:46; 路加福音 5:17"> 耶稣心里立刻知道有能力从自己身上出去，就在群众中转过身来，问：“谁摸了我的衣服？”</span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 8:45; 路加福音 9:12"> 门徒对祂说：“祢看这群众拥挤着祢，祢还问‘谁摸了我’吗？”</span>
<span className="v" id="v32" data-v="32"> 耶稣周围观看，要看做这事的女人。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 8:47; 路加福音 1:29; 路加福音 1:12"> 那女人知道发生在自己身上的事，就恐惧战兢地走过来，俯伏在耶稣面前，把实情全告诉了祂。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 8:48; 马太福音 9:22; 路加福音 7:50"> 耶稣对她说：“女儿，你的信心救了你。平平安安地去吧，你的疾病痊愈了。”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="路加福音 8:49; 约翰福音 11:39; 马可福音 5:22"> 耶稣还在说话的时候，有人从会堂主管的家里来，说：“你的女儿死了。何必再麻烦老师呢？”</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 8:50; 马太福音 9:28–29; 约翰福音 11:40"> 耶稣听见他们所说的话，就对会堂主管说：“不要怕，只要信。”</span>
<span className="v" id="v37" data-v="37" data-xref="使徒行传 9:40; 马可福音 14:33; 哥林多后书 13:1"> 祂除了彼得、雅各和雅各的兄弟约翰以外，不许任何人跟随祂。</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 9:23–24; 路加福音 8:52–53; 马可福音 5:22"> 他们来到会堂主管的家里，耶稣看见一片喧闹，有人在哭泣、大声哀号。</span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 20:10; 帖撒罗尼迦前书 5:10; 帖撒罗尼迦前书 4:13–14"> 祂走进去，对他们说：“你们为什么喧闹哭泣呢？这孩子不是死了，而是睡着了。”</span>
<span className="v" id="v40" data-v="40" data-xref="尼希米记 2:19; 列王纪下 4:33; 马太福音 9:24–25"> 他们就嘲笑祂。耶稣把他们都赶出去，带着孩子的父母和跟随的人，进了孩子躺卧的房间。</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 1:31; 路加福音 7:14–15; 路加福音 8:54–55"> 祂拉着孩子的手，对她说：“大利大，古米！”翻译出来就是：“小女孩，我吩咐你起来！”</span>
<span className="v" id="v42" data-v="42" data-xref="马可福音 4:41; 使徒行传 3:10–13; 马可福音 7:37"> 那女孩立刻起来行走，那时她十二岁。众人惊奇得目瞪口呆。</span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 8:4; 马太福音 9:30; 马可福音 1:43"> 耶稣严厉地嘱咐他们，不要让任何人知道这事，又吩咐给女孩拿些东西吃。</span>
</div>
</div>

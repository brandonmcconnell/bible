<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 12:9–14; 路加福音 6:6–11; 马可福音 1:21"> 耶稣又进了会堂，那里有一个人枯干了一只手。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 37:32; 路加福音 14:1; 路加福音 6:7"> 众人暗中监视耶稣，看祂会不会在安息日医治那人，以便控告祂。</span>
<span className="v" id="v3" data-v="3" data-xref="腓立比书 1:28–30; 以赛亚书 42:4; 路加福音 6:8"> 耶稣对那枯干了一只手的人说：<span className="woj">“站起来！”</span></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 6:9; 马太福音 12:10–12; 何西阿 6:6"> 耶稣问他们：<span className="woj">“在安息日行善合法，还是作恶合法？救命合法，还是害命合法？”</span>他们却默不作声。</span>
<span className="v" id="v5" data-v="5" data-xref="路加福音 6:10; 以弗所书 4:18; 罗马书 11:25"> 耶稣怒目环视他们，为他们心硬感到悲伤，就对那人说：<span className="woj">“伸出你的手来。”</span>那人一伸，他的手就复原了，像另一只手一样健康。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 22:16; 马可福音 12:13; 马太福音 12:14"> 法利赛人出去，立刻与希律党人商议怎样除掉耶稣。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 4:25; 路加福音 6:17; 马太福音 12:15"> 耶稣同门徒退到海边去；有大群的人从加利利跟随祂。还有从犹太、</span>
<span className="v" id="v8" data-v="8" data-xref="以西结 35:15; 以赛亚书 34:5; 马太福音 11:21"> 耶路撒冷、以土买、约旦河对岸，以及推罗和西顿附近来的人。这大群的人听见祂所行的伟大事迹，就都来到祂那里。</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 5:30; 约翰福音 6:15"> 因为人多，祂就吩咐门徒为祂预备一只小船，免得群众拥挤祂。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 14:36; 马可福音 6:56; 马太福音 4:23"> 因为祂治好了许多人，以致凡有病的都挤着要摸祂。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 4:41; 马可福音 1:23–24; 路加福音 8:28"> 污鬼无论何时看见祂，就俯伏在祂面前，喊叫说：“祢是上帝的儿子！”</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 12:16; 马可福音 1:25; 马可福音 1:34"> 耶稣严厉地警告它们，不要把祂的身份宣扬出去。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:1; 路加福音 6:12–16; 马太福音 10:1–4"> 耶稣上了山，把自己想要的人呼召过来，他们就来到祂那里。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 1:8; 路加福音 9:1–6; 约翰福音 15:16"> 祂设立了十二个人，要他们常与自己同在，又要差遣他们出去传道，</span>
<span className="v" id="v15" data-v="15"> 并且赐给他们医治疾病和赶鬼的权柄：</span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 1:42; 使徒行传 1:13; 马太福音 16:16–18"> 西门（耶稣给他起名叫彼得）；</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 4:12; 马可福音 14:33; 耶利米书 23:29"> 西庇太的儿子雅各和雅各的兄弟约翰（耶稣给他们起名叫半尼其，意思是“雷电之子”）；</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 1:13; 马可福音 2:14; 马太福音 9:9"> 安得烈、腓力、巴多罗买、马太、多马、亚勒腓的儿子雅各、达太、奋锐党的西门；</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 6:71; 约翰福音 13:2; 使徒行传 1:16–25"> 以及出卖祂的加略人犹大。<br />后来，耶稣进了一所房子。</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 6:31; 约翰福音 4:31–34; 马可福音 9:28"> 群众又聚集起来，以致他们连吃饭的时间都没有。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 26:24; 约翰福音 10:20; 马可福音 3:31"> 祂的亲属听见这事，就出来要拉住祂，因为他们说：“祂疯了。”</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 15:1; 马太福音 10:25; 马太福音 9:34"> 从耶路撒冷下来的文士说：“祂被别西卜附着了！”又说：“祂是靠着鬼王赶鬼的。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 11:17–23; 马太福音 12:25–30; 马太福音 13:34"> 耶稣把他们叫来，用比喻对他们说：<span className="woj">“撒但怎能赶出撒但呢？</span></span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亚书 11:14; 以赛亚书 19:2–3; 撒母耳记下 20:6"> <span className="woj">若是一个国家自相纷争，那个国家就站立不住。</span></span>
<span className="v" id="v25" data-v="25" data-xref="雅各书 3:16; 诗篇 133:1; 加拉太书 5:15"> <span className="woj">若是一个家庭自相纷争，那个家庭也站立不住。</span></span>
<span className="v" id="v26" data-v="26"> <span className="woj">撒但若是自相攻打、纷争，他就站立不住，而是要灭亡了。</span></span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 49:24–26; 马太福音 12:29; 路加福音 11:21–23"> <span className="woj">绝没有人能进壮汉的家里抢夺他的财物，除非先将那壮汉捆绑起来，然后才能洗劫他的家。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 12:10; 马太福音 12:31–32; 约翰一书 5:16"> <span className="woj">“我确实地告诉你们，世人一切的罪和一切亵渎的话都可以得到赦免；</span></span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 12:31–32; 路加福音 12:10; 帖撒罗尼迦后书 1:9"> <span className="woj">但无论谁亵渎圣灵，将永远得不着赦免，并且要担当永远的罪责。”</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NU（联合圣经公会版）作“犯了永远的罪”。">a</a></sup></span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 10:20; 马可福音 3:22"> 耶稣说这话，是因为他们说：“祂是被污鬼附着的。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路加福音 8:19–21; 马太福音 12:46–50"> 当时，耶稣的母亲和兄弟们来了。他们站在外面，派人进去叫祂。</span>
<span className="v" id="v32" data-v="32"> 群众正围着祂坐着，就有人告诉祂：“看哪，祢的母亲和兄弟姐妹<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TR（公认文本）省略了“姐妹”。">b</a></sup>在外面找祢。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马可福音 3:21; 申命记 33:9; 马可福音 6:3"> 耶稣回答他们说：<span className="woj">“谁是我的母亲？谁是我的兄弟？”</span></span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 12:49–50; 路加福音 11:27–28; 罗马书 8:29"> 于是祂环视坐在周围的人，说：<span className="woj">“看哪，这就是我的母亲，我的兄弟！</span></span>
<span className="v" id="v35" data-v="35" data-xref="约翰一书 2:17; 马太福音 7:21; 约翰一书 3:22–23"> <span className="woj">凡遵行上帝旨意的人，就是我的兄弟、姐妹和母亲了。”</span></span>
</div>
</div>

</div>

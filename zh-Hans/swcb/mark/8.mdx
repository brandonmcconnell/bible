<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 15:32–39; 马可福音 6:34–44"> 那些日子，又有一大群人聚集，他们没有什么吃的。耶稣把门徒叫来，对他们说：</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 9:36; 弥迦书 7:19; 诗篇 103:13"> <span className="woj">“我怜悯这群人，因为他们跟我在一起已经三天，没有什么吃的了。</span></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 40:31; 士师记 8:4–6; 撒母耳记上 30:10–12"> <span className="woj">我若叫他们饿着肚子回家，他们会在半路上支持不住，因为他们中有些人是从很远的地方来的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 4:42–44; 列王纪下 7:2; 马可福音 6:52"> 门徒回答祂：“在这荒野地，哪里能找来饼让这些人吃饱呢？”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马太福音 14:15–17; 马太福音 15:34; 路加福音 9:13"> 耶稣问他们：<span className="woj">“你们有多少个饼？”</span><br />他们说：“七个。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 3:17; 马太福音 15:35–36; 约翰福音 6:10–11"> 祂吩咐众人坐在地上，拿起那七个饼，祝谢后擘开，递给门徒叫他们摆开，门徒就摆在众人面前。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 14:19; 约翰福音 21:5; 路加福音 24:41–42"> 他们还有几条小鱼。耶稣祝福了，也吩咐把这些摆开。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪下 4:42–44; 诗篇 145:16; 马太福音 16:10"> 众人都吃饱了。他们把剩下的零碎收拾起来，装满了七个筐子。</span>
<span className="v" id="v9" data-v="9"> 当时吃的人约有四千。随后，耶稣打发他们走了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 15:39"> 祂立刻同门徒上船，来到大玛努他地区。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 10:9; 马太福音 12:38; 申命记 6:16"> 法利赛人出来，开始盘问耶稣，求祂显一个从天上来的神迹，借此试探祂。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 12:39–40; 马可福音 7:34; 马太福音 16:4"> 耶稣灵里深深叹息，说：<span className="woj">“这世代</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="此处译作“世代”的词 (genea) 也可译作“人民”、“种族”或“家族”。">a</a></sup><span className="woj">为什么求神迹呢？我确实地告诉你们，绝没有神迹给这世代看。”</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约翰福音 12:36; 使徒行传 13:45–46; 诗篇 81:12"> 祂就离开他们，又上船往对岸去了。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 16:5"> 门徒忘了带饼；在船上除了一个饼，他们身边没有别的了。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 5:6–8; 马太福音 16:6; 马太福音 16:11–12"> 耶稣警告他们说：<span className="woj">“你们要小心：提防法利赛人的酵和希律的酵。”</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 9:46; 路加福音 20:5; 马太福音 16:7–8"> 他们彼此议论说：“这是因为我们没有带饼。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马可福音 6:52; 以赛亚书 63:17; 马可福音 2:8"> 耶稣看透了，就对他们说：<span className="woj">“为什么因为没有饼就议论呢？你们还不明白、还不领悟吗？你们的心还是刚硬吗？</span></span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 28:26–27; 马太福音 13:14–15; 耶利米书 5:21"> <span className="woj">你们有眼睛看不见吗？有耳朵听不到吗？你们不记得了吗？</span></span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 9:12–17; 马太福音 14:17–21; 约翰福音 6:5–13"> <span className="woj">我为五千人擘开那五个饼的时候，你们收起来的零碎装满了几个篮子呢？”</span><br />他们告诉祂：“十二个。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马太福音 15:34–38; 马可福音 8:1–9"> <span className="woj">“为四千人擘开那七个饼的时候，你们收起来的零碎装满了几个筐子呢？”</span><br />他们告诉祂：“七个。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马可福音 6:52; 马太福音 16:11–12; 马可福音 8:12"> 祂问他们：<span className="woj">“你们还是不明白吗？”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马太福音 11:21; 马可福音 6:45; 路加福音 10:13"> 他们来到伯赛大。有人带着一个瞎子来，求耶稣摸他。</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 7:33; 约翰福音 9:6–7; 马可福音 5:23"> 耶稣拉着瞎子的手，领他到村外去。把唾沫吐在他的眼睛上，按手在他身上，问他：“你看见什么没有？”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 32:3; 以赛亚书 29:18; 哥林多前书 13:9–12"> 他抬头一看，说：“我看见人了，但我看他们好像树在走动。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="彼得前书 2:9; 彼得后书 3:18; 箴言 4:18"> 于是耶稣又按手在他的眼睛上。他定睛一看，就复原了，看每一个人都清楚了。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 8:4; 马可福音 8:23; 马可福音 5:43"> 耶稣打发他回家，说：<span className="woj">“连这村子你也不要进去，也不要告诉村里的任何人。”</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马太福音 16:13–20; 路加福音 9:18–20"> 耶稣和门徒出去，往该撒利亚·腓立比的村庄去。在路上祂问门徒：<span className="woj">“人们说我是谁？”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约翰福音 1:21; 马太福音 14:2; 玛拉基书 4:5"> 他们告诉祂说：“有人说是施洗约翰；也有人说是以利亚；还有人说是先知里的一位。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约翰一书 4:15; 马太福音 16:15–16; 约翰一书 5:1"> 祂问他们：<span className="woj">“那你们说我是谁？”</span><br />彼得回答说：“祢是基督。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 9:21; 马太福音 16:20; 马可福音 9:9"> 耶稣就严厉地嘱咐他们，不要把祂的事告诉任何人。</span>
<span className="v" id="v31" data-v="31" data-xref="马可福音 10:33–34; 约翰福音 2:19; 路加福音 24:26"> 祂开始教导他们，人子必须受许多苦，被长老、祭司长和文士弃绝，并且被杀，过三天后复活。</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 16:22; 约翰福音 16:25; 约翰福音 16:29"> 祂公开地把这话告诉他们。彼得就把祂拉到一边，开始劝阻祂。</span>
<span className="v" id="v33" data-v="33" data-xref="马太福音 4:10; 腓立比书 3:19; 约翰一书 2:15"> 耶稣转过身来，看着门徒，斥责彼得说：<span className="woj">“撒但，退到我后面去！因为你不体贴上帝的心意，只体贴人的意思。”</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马太福音 10:38; 路加福音 14:26–27; 约翰福音 10:27"> 祂把众人和门徒叫来，对他们说：<span className="woj">“若有人要跟从我，就当舍己，背起他的十字架来跟从我。</span></span>
<span className="v" id="v35" data-v="35" data-xref="提摩太后书 2:11–13; 哥林多前书 9:23; 路加福音 17:33"> <span className="woj">因为凡要救自己生命的，必丧掉生命；凡为我和福音丧掉生命的，必救了生命。</span></span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 16:26; 路加福音 9:25; 诗篇 49:17"> <span className="woj">人就是赚得全世界，却赔上自己的生命，有什么益处呢？</span></span>
<span className="v" id="v37" data-v="37" data-xref="诗篇 49:7–8; 彼得前书 1:18–19"> <span className="woj">人还能拿什么换回自己的生命呢？</span></span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 12:8–9; 罗马书 1:16; 约翰一书 2:23"> <span className="woj">在这淫乱罪恶的世代，凡把我和我的道当作可耻的，当人子在祂天父的荣耀里，同着众圣天使降临的时候，也要把那人当作可耻的。”</span></span>
</div>
</div>

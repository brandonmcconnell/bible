<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="MRK" data-book-slug="mark" data-book-name="马可福音" data-chapter="9" data-verses="50">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 9:27; 希伯来书 2:9; 路加福音 22:30"> 耶稣对他们说：<span className="woj">“我确实地告诉你们，站在这里的，有人在品尝死味之前，必定看见上帝的国带着能力降临。”</span></span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="路加福音 9:28–36; 以赛亚书 33:17; 马太福音 17:1–8"> 过了六天，耶稣带着彼得、雅各和约翰，暗暗地领他们上了一座高山，就在他们面前变了形象。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 28:3; 但以理 7:9; 启示录 7:14"> 祂的衣服闪烁发光，极其洁白，如雪一般，世上绝没有漂布的能漂得那样白。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 9:30–31; 马太福音 17:3–4; 使徒行传 3:21–24"> 以利亚和摩西向他们显现，并且与耶稣说话。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="腓立比书 1:23; 约翰福音 14:8–9; 启示录 22:3–4"> 彼得对耶稣说：“拉比，我们在这里真好。让我们搭三座帐篷吧：一座为祢，一座为摩西，一座为以利亚。”</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 1:17; 但以理 10:15–19; 马可福音 16:5–8"> 彼得其实不知道该说什么才好，因为他们都非常害怕。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="彼得后书 1:17; 马太福音 3:17; 马可福音 1:11"> 有一朵云彩来遮盖他们，又有声音从云彩里出来说：“这是我的爱子，你们要听祂。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 10:16; 使徒行传 8:39–40; 路加福音 24:31"> 门徒忽然周围一看，不再看见任何人，只见耶稣单独和他们在一起。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马太福音 12:40; 马太福音 17:9–13; 马可福音 5:43"> 下山的时候，耶稣嘱咐他们，在人子从死里复活之前，不要将他们所看见的告诉任何人。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 17:18; 路加福音 24:7–8; 路加福音 18:33–34"> 他们就把这话记在心里，彼此讨论“从死里复活”到底是什么意思。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="玛拉基书 4:5; 玛拉基书 3:1; 马太福音 11:14"> 他们就问耶稣：“为什么文士说以利亚必须先来？”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 53:1–12; 以赛亚书 50:6; 以赛亚书 52:14"> 耶稣对他们说：<span className="woj">“以利亚固然要先来复兴万事。但经上指着人子是怎么写的呢？说祂必须受许多苦，被人藐视。</span></span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 14:3–11; 马太福音 17:12–13; 马太福音 11:14"> <span className="woj">但我告诉你们，以利亚已经来了，他们却任意待他，正如经上指着他所写的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 9:37–42; 马太福音 17:14–20; 路加福音 11:53–54"> 他们回到门徒那里，看见一大群人围着他们，又有文士在和他们辩论。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 34:30; 马可福音 9:2–3"> 众人一看见耶稣，都极其惊讶，就跑上去迎接祂。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 5:30–32; 马可福音 8:11"> 耶稣问文士们：<span className="woj">“你们在和他们辩论什么？”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马可福音 9:25; 路加福音 11:14; 约翰福音 4:47"> 人群中有个人回答说：“老师，我把我的儿子带到祢这里来了，他被哑巴鬼附着；</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 17:19–20; 马可福音 11:23; 马太福音 17:16"> 无论在哪里，鬼一抓住他，就把他摔倒；他就口吐白沫，咬牙切齿，身体僵硬。我请祢的门徒把鬼赶出去，他们却办不到。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="民数记 14:11; 约翰福音 20:27; 民数记 14:27"> 耶稣对他们说：<span className="woj">“唉，这不信的世代啊！我还要跟你们在一起多久呢？我还要忍耐你们多久呢？把他带到我这里来。”</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马可福音 1:26; 路加福音 4:35; 约翰福音 8:44"> 他们就把孩子带到祂面前。鬼一看见耶稣，立刻使孩子猛烈抽搐，倒在地上打滚，口吐白沫。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 9:33; 使徒行传 4:22; 马可福音 5:25"> 耶稣问他父亲：<span className="woj">“他这样有多久了？”</span><br />父亲说：“从小就是这样。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 15:22–28; 马可福音 5:19; 马太福音 20:34"> 鬼屡次把他扔进火里和水里，要毁灭他。祢若能做什么，求祢怜悯我们，帮助我们吧！”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约翰福音 11:40; 希伯来书 11:6; 马可福音 11:23"> 耶稣对他说：<span className="woj">“你若能信，对信的人，凡事都能。”</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 17:5; 希伯来书 12:2; 以弗所书 2:8"> 孩子的父亲立刻喊着说：“我信！但我信心不足，求祢帮助！”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="使徒行传 16:18; 路加福音 9:42; 马可福音 9:15"> 耶稣看见群众跑拢过来，就斥责那污鬼，对它说：<span className="woj">“你这聋哑的鬼，我吩咐你从他里面出来，再也不要进去了！”</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马可福音 9:20; 马可福音 1:26; 马可福音 9:18"> 那鬼大叫了一声，使孩子猛烈地抽搐了一阵，就出来了。孩子变得好像死了一样，以致大多数人都说：“他死了。”</span>
<span className="v" id="v27" data-v="27" data-xref="马可福音 1:31; 使徒行传 3:7; 马可福音 1:41"> 但耶稣拉着他的手扶他起来，他就站起来了。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马太福音 17:19–20; 马可福音 7:17; 马太福音 15:15"> 耶稣进了房子，门徒暗暗地问祂：“为什么我们不能把它赶出去呢？”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="雅各书 5:15; 但以理 9:3; 马太福音 17:20"> 耶稣对他们说：<span className="woj">“除了祷告和禁食，绝不能把这一类的鬼赶出来。”</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="马太福音 17:22–23; 路加福音 9:43–45; 马可福音 6:31–32"> 他们离开那里，经过加利利。耶稣不想让人知道，</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 16:21; 马可福音 9:12; 路加福音 24:44–46"> 因为祂正在教导门徒，并对他们说：<span className="woj">“人子将被交在人的手里，他们会杀害祂；被杀之后，第三天祂要复活。”</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="路加福音 2:50; 路加福音 9:45; 路加福音 18:34"> 门徒却不明白这话，又不敢问祂。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 18:1–5; 希伯来书 4:13; 路加福音 9:46–48"> 他们来到迦百农。耶稣在屋里时问门徒：<span className="woj">“你们在路上彼此争论什么呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马可福音 9:50; 马太福音 20:21–24; 马太福音 18:1–5"> 门徒默不作声，因为他们在路上彼此争论谁是最大的。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 20:25–28; 马可福音 10:42–45; 路加福音 22:26"> 耶稣坐下，把十二使徒叫来，对他们说：<span className="woj">“若有人想做第一，他必须做众人中末后的，并做众人的仆人。”</span></span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 10:16; 马太福音 19:14–15; 马太福音 18:2"> 于是祂领过一个小孩子来，让他站在他们中间，又把他抱在怀里，对他们说：</span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 18:3–5; 路加福音 10:16; 马太福音 10:40–42"> <span className="woj">“凡为我的名接待一个这样的小孩子的，就是接待我；凡接待我的，不是接待我，而是接待那差我来的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="路加福音 9:49–50; 民数记 11:26–29; 路加福音 11:19"> 约翰对耶稣说：“老师，我们看见一个人奉祢的名赶鬼，我们就阻止他，因为他不跟从我们。”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="哥林多前书 12:3; 哥林多前书 13:1–2; 马太福音 13:28–29"> 但耶稣说：<span className="woj">“不要阻止他，因为没有人奉我的名行神迹，反倒能轻易毁谤我。</span></span>
<span className="v" id="v40" data-v="40" data-xref="马太福音 12:30; 路加福音 11:23"> <span className="woj">因为不反对我们的，就是支持我们的。</span></span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 10:42; 马太福音 25:40; 哥林多前书 15:23"> <span className="woj">凡因你们属于基督，而奉我的名给你们一杯水喝的，我确实地告诉你们，他绝不会失去他的赏赐。</span></span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="马太福音 18:6; 路加福音 17:1–2; 马太福音 18:10"> <span className="woj">“无论谁使这些信我的小弟兄中任何一个跌倒，倒不如把一块大磨石拴在他的脖子上，扔进海里。</span></span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 5:29–30; 马太福音 18:8–9; 马太福音 25:41"> <span className="woj">你的手若使你跌倒，就把它砍下来。你残缺进入永生，总比有两只手下到欣嫩子谷</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“地狱”。">a</a></sup><span className="woj">，进入那不灭的火里更好，</span></span>
<span className="v" id="v44" data-v="44"> <span className="woj">‘在那里的虫是不死的，火是不灭的。’</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NU（联合圣经公会版）省略第44节。">b</a></sup></span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 18:8; 马太福音 5:22; 马可福音 9:43"> <span className="woj">你的脚若使你跌倒，就把它砍下来。你瘸腿进入永生，总比有两只脚被扔进欣嫩子谷</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作“地狱”。">c</a></sup><span className="woj">，进入那永远不灭的火里更好——</span></span>
<span className="v" id="v46" data-v="46"> <span className="woj">‘在那里的虫是不死的，火是不灭的。’</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="NU（联合圣经公会版）省略第46节。">d</a></sup></span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 18:9; 马可福音 9:43; 马太福音 5:22"> <span className="woj">你的眼若使你跌倒，就把它挖出来。你只有一只眼进入上帝的国，总比有两只眼被扔进火的欣嫩子谷</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="或作“地狱”。">e</a></sup><span className="woj">更好，</span></span>
<span className="v" id="v48" data-v="48" data-xref="以赛亚书 66:24; 马可福音 9:43–45; 马太福音 25:41"> <span className="woj">‘在那里的虫是不死的，火是不灭的。’</span></span>
<span className="v" id="v49" data-v="49" data-xref="利未记 2:13; 以西结 43:24"> <span className="woj">因为必用火当盐腌各人，各样的祭物也必用盐腌。</span></span>
<span className="v" id="v50" data-v="50" data-xref="歌罗西书 4:6; 罗马书 12:18; 马太福音 5:13"> <span className="woj">盐本是好的，但盐若失了咸味，你们用什么使它再咸呢？你们里面要有盐，彼此和睦。”</span></span>
</div>
</div>

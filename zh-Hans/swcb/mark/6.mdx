<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 4:16–30; 马太福音 13:54–58; 马太福音 2:23"> 耶稣离开那里，来到自己的家乡，祂的门徒也跟随着祂。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 7:15; 约翰福音 6:42; 使徒行传 4:13–14"> 到了安息日，祂开始在会堂里教导人。许多听见的人都十分惊奇，说：“这个人从哪里得来这些事呢？”又说：“赐给这个人的是什么智慧，竟能借着祂的手行出这样的神迹？</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 12:46; 马太福音 13:55–57; 约翰福音 6:42"> 这不是那木匠吗？不是马利亚的儿子，雅各、约西、犹大和西门的兄弟吗？祂的妹妹们不也和我们在一起吗？”他们就对祂反感。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰福音 4:44; 路加福音 4:24; 马太福音 13:57"> 耶稣对他们说：“先知除了在自己的家乡、亲属和本家之外，没有不受人尊敬的。”</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 13:58; 马可福音 9:23; 马可福音 5:23"> 祂在那里不能行什么神迹，只给几个病人按手，医治了他们。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 9:35; 马太福音 8:10; 路加福音 13:22"> 祂因他们的不信而感到诧异。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="传道书 4:9–10; 路加福音 10:17–20; 马太福音 10:1–5"> 祂把十二个门徒叫来，开始差遣他们两个两个地出去，并赐给他们制伏污鬼的权柄。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 9:3; 马太福音 10:9–10; 路加福音 10:4"> 祂嘱咐他们，行路的时候，除了一根拐杖之外，什么都不要带：不要带食物，不要带口袋，腰袋里也不要带钱，</span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 12:8; 以弗所书 6:15"> 只要穿鞋，也不要穿两件内衣。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 10:7–8; 路加福音 9:4; 马太福音 10:11–13"> 祂对他们说：“你们无论在哪里进了一家，就住在那里，直到离开那个地方。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 10:14–15; 使徒行传 18:6; 路加福音 10:10–15"> 无论何处不接待你们，不听从你们，你们离开那里的时候，就把脚底的尘土跺掉，作为对他们的见证。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="有些抄本增加：“我确实地告诉你们，在审判的日子，所多玛和蛾摩拉所受的，比那城所受的还容易承受。”">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 4:17; 路加福音 13:3; 使徒行传 20:21"> 门徒就出去传道，劝人悔改。</span>
<span className="v" id="v13" data-v="13" data-xref="雅各书 5:14–15; 马可福音 6:7; 路加福音 10:17"> 他们赶出许多鬼，用油抹了许多病人，治好他们。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 9:7–9; 马可福音 6:14–29; 路加福音 23:7–12"> 希律王听见了耶稣的事，因为祂的名声已经传扬开来。他说：“施洗约翰从死人中复活了，所以这些能力才在他里面运行。”</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 16:14; 玛拉基书 4:5; 马太福音 21:11"> 但别人说：“他是以利亚。”还有人说：“他是个先知，像古时的一位先知。”</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 11:10–13; 马太福音 27:4; 路加福音 9:9"> 希律听见却说：“这是我斩首的那个约翰，他从死人中复活了。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 3:19–20; 马太福音 11:2; 路加福音 3:1"> 原来希律为了他兄弟腓力的妻子希罗底的缘故，曾派人去逮捕约翰，把他绑在监里，因为希律已经娶了那妇人。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 20:21; 利未记 18:16; 列王纪上 22:14"> 约翰曾对希律说：“你占有你兄弟的妻子是不合法的。”</span>
<span className="v" id="v19" data-v="19" data-xref="传道书 7:9; 以弗所书 4:26–27; 创世记 39:17–20"> 希罗底就怀恨在心，想要杀他，却不能；</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 21:26; 马太福音 14:5; 历代志下 24:15–22"> 因为希律敬畏约翰，知道他是个公义圣洁的人，就保护他。希律听约翰讲论，十分困惑，却仍然乐意听他。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以斯帖记 2:18; 创世记 40:20; 彼得前书 4:3"> 后来，合适的机会来了。希律在生日那天，设宴招待他的大臣、千夫长和加利利的显贵。</span>
<span className="v" id="v22" data-v="22" data-xref="以斯帖记 1:10–12; 马太福音 14:6; 但以理 5:2"> 希罗底的女儿进来跳舞，使希律和同席的人都很高兴。王对那少女说：“你想要什么，只管向我求，我必赐给你。”</span>
<span className="v" id="v23" data-v="23" data-xref="以斯帖记 7:2; 以斯帖记 5:3; 以斯帖记 5:6"> 王又对她起誓说：“无论你向我求什么，就是我国家的一半，我也必赐给你。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约伯记 31:31; 以西结 19:2–3; 创世记 27:8–11"> 她出去对母亲说：“我该求什么呢？”<br />母亲说：“施洗约翰的头。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="罗马书 3:15; 民数记 7:19–89; 民数记 7:13"> 少女立刻急忙进去见王，要求说：“我愿王立刻把施洗约翰的头放在盘子里赐给我。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 27:24–25; 马太福音 14:9; 马太福音 27:3–5"> 王极其忧愁，但因为所起的誓，又因为同席的客人，不愿拒绝她。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 14:10–11"> 王立刻派了一个卫兵，吩咐把约翰的头拿来。卫兵就去监里斩了约翰的头，</span>
<span className="v" id="v28" data-v="28"> 把头放在盘子里端来，交给了少女，少女就交给了她母亲。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马太福音 14:12; 历代志下 24:16; 马太福音 27:57–60"> 约翰的门徒听见了，就来把他的尸体领去，安放在坟墓里。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路加福音 9:10; 路加福音 10:17; 马太福音 10:2"> 使徒们聚集到耶稣那里，把他们所做和所教导的一切都告诉了祂。</span>
<span className="v" id="v31" data-v="31" data-xref="马可福音 3:20; 约翰福音 6:1; 马可福音 1:45"> 祂对他们说：“你们自己来，同我暗暗地到旷野的地方去歇息一会儿。”因为来往的人多，他们连吃饭的时间都没有。</span>
<span className="v" id="v32" data-v="32" data-xref="马可福音 8:2–9; 马可福音 6:45; 马可福音 4:36"> 于是他们乘船，暗暗地往旷野的地方去了。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约翰福音 6:2; 马太福音 15:29–31; 马可福音 6:54–55"> 众人看见他们离去，有许多人认出祂，就从各城步行，争先恐后地跑到那里，比他们先到了。</span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 9:36; 路加福音 9:11; 民数记 27:17"> 耶稣下了船，看见一大群人，就对他们动了怜悯的心，因为他们如同没有牧人的羊群一样；于是祂开始教导他们许多事。</span>
<span className="v" id="v35" data-v="35" data-xref="约翰福音 6:5–15; 路加福音 9:12–17; 马太福音 14:15–21"> 天色已经晚了，门徒来到祂跟前，说：“这地方荒凉，而且天色已经晚了。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 15:23; 马可福音 3:21; 马可福音 5:31"> 请打发他们散去，好让他们到周围的乡下和村庄，去为自己买些食物。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="列王纪下 4:42–44; 马太福音 15:32–33; 马可福音 8:2–3"> 耶稣却回答他们说：“你们给他们吃吧。”<br />门徒问祂：“我们要去买两百银币的饼给他们吃吗？”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="马太福音 15:34; 马可福音 8:5; 约翰福音 6:9"> 耶稣对他们说：“你们有多少个饼？去看看。”<br />他们查看之后，说：“五个，还有两条鱼。”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="哥林多前书 14:40; 哥林多前书 14:33; 马太福音 15:35"> 耶稣吩咐他们，叫众人都一排一排地坐在青草地上。</span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 9:14–15"> 众人就一排一排地坐下，有一百人的，有五十人的。</span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 14:19; 马可福音 7:34; 路加福音 9:16"> 耶稣拿起那五个饼和两条鱼，望着天祝谢，掰开饼，递给门徒，让他们摆在众人面前；又把那两条鱼分给众人。</span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 9:17; 马可福音 8:8–9; 马太福音 15:37–38"> 大家都吃，并且吃饱了。</span>
<span className="v" id="v43" data-v="43" data-xref="马可福音 8:19–20"> 门徒把碎饼和碎鱼收拾起来，装满了十二个篮子。</span>
<span className="v" id="v44" data-v="44"> 吃饼的男人有五千个。</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="马太福音 14:22–33; 约翰福音 6:15–21; 马可福音 6:32"> 耶稣随即催门徒上船，先渡到对岸的伯赛大去，等祂自己遣散群众。</span>
<span className="v" id="v46" data-v="46" data-xref="马可福音 1:35; 马太福音 6:6; 路加福音 6:12"> 祂辞别了他们之后，就上山去祷告。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="马太福音 14:23; 约翰福音 6:16–17"> 到了晚上，船在海中，耶稣独自在岸上。</span>
<span className="v" id="v48" data-v="48" data-xref="路加福音 24:28; 路加福音 12:38; 约伯记 9:8"> 祂看见门徒因为逆风，摇橹十分艰难。大约在夜里四更天，祂在海面上行走，向他们走去，本想走过他们那里去。</span>
<span className="v" id="v49" data-v="49" data-xref="马太福音 14:25–26; 路加福音 24:37; 约伯记 9:8"> 门徒看见祂在海面上行走，以为是个幽灵，就惊叫起来；</span>
<span className="v" id="v50" data-v="50" data-xref="马太福音 14:27; 约翰福音 6:19–20; 以赛亚书 43:2"> 因为他们都看见了祂，就十分惊慌。耶稣立刻对他们说：“放心！是我！”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作“我是！”">b</a></sup>“不要怕。”</span>
<span className="v" id="v51" data-v="51" data-xref="诗篇 93:3–4; 马可福音 4:39; 约翰福音 6:21"> 于是祂上船与他们在一起，风就停了；他们心里极其惊奇，</span>
<span className="v" id="v52" data-v="52" data-xref="马可福音 8:17–21; 路加福音 24:25; 以赛亚书 63:17"> 因为他们没有明白分饼的事，他们的心还是愚顽的。</span>
</div>
<div className="bp">
<span className="v" id="v53" data-v="53" data-xref="马太福音 14:34–36; 约翰福音 6:24–25; 路加福音 5:1"> 他们渡过去，到了革尼撒勒靠岸，把船拴好。</span>
<span className="v" id="v54" data-v="54" data-xref="诗篇 9:10; 腓立比书 3:10"> 他们一下船，众人立刻认出了祂，</span>
<span className="v" id="v55" data-v="55" data-xref="马太福音 4:24; 马可福音 2:1–3; 马可福音 3:7–11"> 就跑遍那整个地区，听见祂在哪里，就把有病的人用垫子抬到哪里。</span>
<span className="v" id="v56" data-v="56" data-xref="马太福音 9:20; 路加福音 6:19; 民数记 15:38–39"> 祂无论进到哪里，是村庄、城市还是乡下，人们都把病人放在市场上，恳求祂哪怕只让他们摸一下祂衣服的穗子；凡摸着祂的人，就都痊愈了。</span>
</div>
</div>

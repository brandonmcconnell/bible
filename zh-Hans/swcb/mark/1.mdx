<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="MRK" data-book-slug="mark" data-book-name="马可福音" data-chapter="1" data-verses="45">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰一书 5:11–12; 马太福音 4:3; 马太福音 3:17"> 上帝的儿子，耶稣基督福音的起头。</span>
</div>
<div className="bp poetry">
<span className="v" id="v2" data-v="2" data-xref="玛拉基书 3:1; 马太福音 11:10; 路加福音 1:76"> 正如先知书上所记：<br /><span className="pl pl-1">“看哪，</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“看哪”源于希腊文“ἰδοὺ”，意为注视、注意、观察或凝视，常作感叹词用。">a</a></sup><br /><span className="pl pl-1">我差遣我的使者在祢前面，</span><br /><span className="pl pl-2">他要在祢前面预备道路：</span></span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 40:3–5; 马太福音 3:3; 路加福音 3:4–6"> <span className="pl pl-1">在旷野有呼喊者的声音，</span><br /><span className="pl pl-2">‘预备主的道！</span><br /><span className="pl pl-2">修直祂的路！’”</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="使徒行传 19:3–4; 马太福音 3:6; 使徒行传 13:24–25"> 约翰在旷野出现，施洗<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作“浸”。">b</a></sup>并传讲悔改的洗礼，使罪得赦。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 26:40–42; 使徒行传 19:18; 马太福音 3:5–6"> 犹太全地和耶路撒冷的众人都出去到他那里，承认他们的罪，在约旦河里受他的洗。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 1:8; 利未记 11:22; 马太福音 3:4"> 约翰穿着骆驼毛的衣服，腰束皮带，吃的是蝗虫和野蜜。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 13:25; 路加福音 3:16; 约翰福音 1:27"> 他传讲说：“有一位在我以后来的，能力比我更大，我就是弯腰给祂解鞋带也不配。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 1:5; 哥林多前书 12:13; 使徒行传 19:4–6"> 我用水<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="希腊文 (en) 在某些语境中也可译作“用”。">c</a></sup>给你们施洗，祂却要用圣灵给你们施洗。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马太福音 3:13–17; 马太福音 2:23; 路加福音 3:21–22"> 那些日子，耶稣从加利利的拿撒勒来，在约旦河里受了约翰的洗。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 1:31–34; 路加福音 3:22; 以赛亚书 42:1"> 祂刚从水里上来，就看见天裂开了，圣灵仿佛鸽子降在祂身上。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 42:1; 马可福音 9:7; 马太福音 3:17"> 又有声音从天上来说：“祢是我的爱子，我喜悦祢。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 4:1–11; 路加福音 4:1–13"> 圣灵随即把祂催促到旷野去。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 2:17–18; 希伯来书 4:15; 出埃及记 34:28"> 祂在旷野四十天，受撒但的试探，与野兽同在一起；并且有天使来服事祂。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 4:23; 马太福音 4:12; 路加福音 8:1"> 约翰被捕以后，耶稣来到加利利，传讲上帝国的福音，</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 3:2; 使徒行传 2:36–38; 马太福音 4:17"> 说：<span className="woj">“日期满了，上帝的国近了！你们当悔改，信福音。”</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马太福音 4:18–22; 约翰福音 1:40–42; 约翰福音 6:8"> 耶稣沿着加利利海边行走，看见西门和西门的兄弟安得烈在海里撒网，他们本来是渔夫。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 5:10; 马太福音 4:19–20; 使徒行传 2:38–41"> 耶稣对他们说：<span className="woj">“来跟从我，我要使你们成为得人的渔夫。”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 18:28–30; 路加福音 5:11; 马可福音 10:28–31"> 他们立刻丢下网，跟从了祂。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马可福音 5:37; 使徒行传 1:13; 马可福音 10:35"> 耶稣稍往前走，看见西庇太的儿子雅各和他的兄弟约翰，他们正在船上补网。</span>
<span className="v" id="v20" data-v="20" data-xref="马太福音 10:37; 路加福音 14:26; 马可福音 10:29"> 耶稣随即呼召他们。他们就把父亲西庇太和雇工留在船上，跟从了耶稣。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马可福音 6:2; 马可福音 1:39; 马太福音 4:23"> 他们进了迦百农。一到安息日，耶稣就进入会堂教导人。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 7:28–29; 马太福音 13:54; 路加福音 4:32"> 众人对祂的教导感到惊奇，因为祂教导他们正像有权柄的人，不像那些文士。</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 9:25; 马可福音 7:25; 马可福音 1:34"> 就在那时，会堂里刚好有一个被污鬼附着的人，他喊叫起来，</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 8:29; 雅各书 2:19; 使徒行传 3:14"> 说：“哈！拿撒勒人耶稣，我们与祢有什么相干？祢来是要灭绝我们吗？我知道祢是谁，祢是上帝的圣者！”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马可福音 1:34; 路加福音 4:41; 使徒行传 16:17"> 耶稣斥责它说：<span className="woj">“住口，从他里面出来！”</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马可福音 9:26; 马可福音 9:20; 路加福音 11:22"> 污鬼使那人猛烈抽搐，大声喊叫着，就从他里面出来了。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 15:31; 马可福音 7:37; 路加福音 9:1"> 众人都十分惊讶，以致彼此议论说：“这是什么事？是个新教导吗？祂竟有权柄吩咐污鬼，连污鬼也听从了祂！”</span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 9:31; 路加福音 4:37; 马可福音 1:45"> 耶稣的名声立刻传遍了加利利的整个地区和周围地带。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 4:38–39; 马太福音 8:14–15; 马可福音 1:21"> 他们一出会堂，就同着雅各和约翰进了西门和安得烈的家。</span>
<span className="v" id="v30" data-v="30" data-xref="哥林多前书 9:5; 马可福音 5:23; 约翰福音 11:3"> 西门的岳母正发烧躺着，他们立刻把她的病情告诉了耶稣。</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 9:41; 诗篇 116:12; 马可福音 5:41"> 耶稣走过去，拉着她的手扶她起来。烧立刻<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="NU（联合圣经公会版）省略了“立刻”。">d</a></sup>退了，她就开始服事他们。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马太福音 8:16; 马可福音 3:2; 路加福音 4:40"> 到了晚上，日落的时候，有人把一切害病的和被鬼附的，都带到耶稣面前。</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 1:5; 使徒行传 13:44"> 全城的人都聚集在门前。</span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 4:41; 马可福音 3:12; 马太福音 4:23"> 耶稣治好了许多患各样疾病的人，又赶出许多鬼。祂不许鬼说话，因为鬼认识祂。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="路加福音 6:12; 路加福音 5:16; 路加福音 22:39–46"> 清晨，天还没亮，耶稣就起来走出去，来到荒野的地方，在那里祷告。</span>
<span className="v" id="v36" data-v="36"> 西门和同伴们去寻找祂。</span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 12:19; 马可福音 1:5; 撒迦利亚书 11:11"> 找到了，就对祂说：“大家都在找祢。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="路加福音 4:43; 约翰福音 17:8; 以赛亚书 61:1–3"> 耶稣对他们说：<span className="woj">“我们去别处吧，到附近的村镇去，我也好在那里传道，因为我正是为此而来的。”</span></span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 4:23; 马可福音 1:21; 路加福音 4:43–44"> 于是祂走遍全加利利，在他们的会堂里传道，并且赶鬼。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="路加福音 5:12–14; 马太福音 8:2–4; 利未记 13:1–14"> 有一个麻风病人来到耶稣面前，跪下恳求祂说：“祢若愿意，必能叫我洁净。”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="马太福音 9:36; 希伯来书 2:17; 希伯来书 4:15"> 耶稣动了怜悯的心，就伸手摸他，对他说：<span className="woj">“我愿意。你洁净了吧。”</span></span>
<span className="v" id="v42" data-v="42" data-xref="约翰福音 15:3; 马可福音 5:29; 约翰福音 4:50–53"> 祂刚说完，麻风病立刻离开了他，他就洁净了。</span>
<span className="v" id="v43" data-v="43" data-xref="马太福音 9:30; 马可福音 7:36; 路加福音 8:56"> 耶稣严厉地嘱咐他，立刻打发他走，</span>
<span className="v" id="v44" data-v="44" data-xref="利未记 14:1–32; 路加福音 17:14; 马太福音 8:4"> 并对他说：<span className="woj">“你要小心，什么也不要告诉人，只要去把身体给祭司察看，又为你得洁净献上摩西所吩咐的祭物，作为对他们的印证。”</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="马可福音 2:13; 马太福音 9:31; 约翰福音 6:2"> 那人出去，却开始四处宣扬，把这事传开了，以致耶稣不能再公开进城，只好留在外面的旷野地方。人们从各处来到祂那里。</span>
</div>
</div>

</div>

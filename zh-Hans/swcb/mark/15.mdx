<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="MRK" data-book-slug="mark" data-book-name="马可福音" data-chapter="15" data-verses="47">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 27:1–2; 路加福音 23:1–5; 路加福音 22:66"> 一到早晨，祭司长同长老、文士和全议会的人立刻进行商议。他们把耶稣绑起来，押走交给了彼拉多。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 2:2; 马太福音 27:11–14; 提摩太前书 6:13"> 彼拉多问祂：“祢是犹太人的王吗？”<br />耶稣回答说：<span className="woj">“你说的是。”</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 53:7; 马可福音 15:5; 约翰福音 18:29–31"> 祭司长控告了祂许多事。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 19:10; 马太福音 27:13; 马太福音 26:62"> 彼拉多又问祂：“祢什么都不回答吗？看哪，他们作见证控告祢的事有多少！”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 53:7; 撒迦利亚书 3:8; 诗篇 71:7"> 但耶稣还是什么也不回答，以致彼拉多感到非常惊讶。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约翰福音 18:39–40; 使徒行传 25:9; 使徒行传 24:27"> 每逢节期，彼拉多常按着众人的要求，给他们释放一个囚犯。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 23:18–19; 马太福音 27:16; 路加福音 23:25"> 当时有一个人名叫巴拉巴，和同伙的叛乱分子关在一起；他们在暴动时犯了谋杀罪。</span>
<span className="v" id="v8" data-v="8"> 群众大声呼喊，开始要求彼拉多照常例为他们办。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 19:14–16; 约翰福音 19:4–5; 约翰福音 18:39"> 彼拉多回答他们说：“你们要我给你们释放犹太人的王吗？”</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 27:4; 提多书 3:3; 创世记 4:4–6"> 因为他察觉到，祭司长是出于嫉妒才把耶稣交出来的。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 3:14; 约翰福音 18:40; 何西阿 5:1"> 但祭司长煽动群众，要他宁可给他们释放巴拉巴。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 23:5–6; 以赛亚书 9:6–7; 撒迦利亚书 9:9"> 彼拉多又问他们：“那么，你们称作犹太人之王的这个人，我该拿祂怎么办呢？”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 他们又喊着说：“把祂钉十字架！”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 23:41; 路加福音 23:23–24; 以赛亚书 53:3"> 彼拉多对他们说：“为什么？祂做了什么恶事呢？”<br />但他们越发大声喊叫：“把祂钉十字架！”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 19:1; 马太福音 27:26; 以赛亚书 50:6"> 彼拉多想要讨好群众，就给他们释放了巴拉巴，并且把耶稣鞭打之后，交给人去钉十字架。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰福音 19:9; 马太福音 27:27–31; 约翰福音 18:28"> 士兵把耶稣押进院子里，就是总督府；他们把全营的士兵都叫了来。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 27:28–30; 约翰福音 19:2–5; 路加福音 23:11"> 他们给祂穿上紫袍，又用荆棘编了一顶冠冕给祂戴上，</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 27:42–43; 马可福音 15:2; 创世记 37:10"> 就开始向祂致敬说：“万岁，犹太人的王！”</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 14:65; 以赛亚书 53:3–5; 路加福音 23:11"> 他们用一根芦苇秆打祂的头，向祂吐唾沫，又屈膝向祂下拜。</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 19:16; 马太福音 27:31"> 戏弄完了，他们剥下祂的紫袍，给祂穿上祂自己的衣服。然后带祂出去，要把祂钉十字架。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马太福音 27:32; 路加福音 23:26; 罗马书 16:13"> 有一个从乡下来的人从那里经过，就是亚历山大和鲁孚的父亲古利奈人西门。他们强迫他同去，要他背耶稣的十字架。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 27:33–44; 约翰福音 19:17–27; 路加福音 23:27–38"> 他们把耶稣带到一个地方，名叫各各他，翻译出来就是“髑髅地”。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 27:34; 约翰福音 19:28–30; 路加福音 23:36"> 他们拿调了没药的酒给祂喝，祂却没有接。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 23:34; 约翰福音 19:23–24; 马太福音 27:35–36"> 他们把祂钉在十字架上，又为祂的衣服抽签，看谁能分到什么。</span>
<span className="v" id="v25" data-v="25" data-xref="约翰福音 19:14; 马可福音 15:33; 马太福音 27:45"> 他们钉祂十字架的时候，是第三个时辰<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="即上午九点。">a</a></sup>。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 27:37; 马太福音 2:2; 约翰福音 19:18–22"> 在祂上面写着控告祂的牌子：“犹太人的王”。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 23:32–33; 马太福音 27:38; 约翰福音 19:18"> 他们又把两个强盗和祂同钉十字架，一个在祂右边，一个在祂左边。</span>
<span className="v" id="v28" data-v="28"> 这就应验了经上所说的话：“祂被列在罪犯之中。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NU（联合圣经公会版）省略第28节。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马可福音 14:58; 诗篇 109:25; 耶利米哀歌 1:12"> 路过的人辱骂祂，摇着头说：“哈！祢这要拆毁圣殿、三天内建造起来的，</span>
<span className="v" id="v30" data-v="30"> 救救祢自己，从十字架上下来吧！”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约翰福音 12:23–24; 马太福音 27:41–43; 路加福音 23:35–37"> 祭司长和文士也同样在他们中间戏弄祂，说：“祂救了别人，却不能救自己。</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 27:44; 路加福音 23:39–43; 撒迦利亚书 9:9"> 让这位基督，以色列的王，现在从十字架上下来吧，好让我们看见就信祂。”<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="TR（公认文本）省略“祂”。">c</a></sup>那些和祂同钉十字架的人也侮辱祂。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 27:45; 路加福音 23:44–45; 阿摩司 8:9–10"> 到了第六个时辰<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或作“正午”。">d</a></sup>，黑暗笼罩了整个大地，直到第九个时辰<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="即下午三点。">e</a></sup>。</span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 22:1; 马太福音 27:46; 希伯来书 5:7"> 在第九个时辰，耶稣大声呼喊说：<span className="woj">“以罗伊！以罗伊！拉马撒巴各大尼？”</span>翻译出来就是：<span className="woj">“我的上帝！我的上帝！祢为什么离弃我？”</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 27:47–49; 马可福音 9:11–13; 马太福音 17:11–13"> 旁边站着的人中，有几个听见了就说：“看哪，祂在呼叫以利亚。”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="诗篇 69:21; 马可福音 15:23; 约翰福音 19:28–30"> 有一个人跑去，拿海绵蘸满了醋，绑在芦苇秆上，送给祂喝，说：“随祂去吧。让我们看看以利亚会不会来把祂取下来。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="约翰福音 19:30; 路加福音 23:46; 马太福音 27:50"> 耶稣大喊了一声，就断了气。</span>
<span className="v" id="v38" data-v="38" data-xref="希伯来书 10:19–23; 路加福音 23:45; 希伯来书 9:3–12"> 圣殿的幔子从上到下裂成了两半。</span>
<span className="v" id="v39" data-v="39" data-xref="马太福音 27:54; 路加福音 23:47–48; 马太福音 27:43"> 对面站着的百夫长，看见祂这样断气，就说：“这人真是上帝的儿子！”</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="路加福音 23:49; 路加福音 8:2–3; 马太福音 27:55–56"> 还有些妇女在远处观看，其中有抹大拉的马利亚，小雅各和约西的母亲马利亚，以及撒罗米。</span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 8:2–3; 马太福音 27:55–56"> 当耶稣在加利利的时候，她们就跟随祂，服事祂；还有许多同祂一起上耶路撒冷的妇女也在那里。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="路加福音 23:50–56; 约翰福音 19:38–42; 约翰福音 19:31"> 到了傍晚，因为那天是预备日，也就是安息日的前一天，</span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 2:38; 路加福音 2:25; 路加福音 23:51"> 亚利马太的约瑟来了，他是一位受人尊敬的议员，自己也在盼望上帝的国。他放胆进去见彼拉多，求取耶稣的遗体。</span>
<span className="v" id="v44" data-v="44" data-xref="约翰福音 19:31–37"> 彼拉多很惊讶祂已经死了。他把百夫长叫来，问他耶稣死去了多久。</span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 27:58; 约翰福音 19:38; 马可福音 15:39"> 他从百夫长那里查明之后，就把遗体赐给了约瑟。</span>
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 53:9; 马太福音 27:59–60; 以赛亚书 22:16"> 约瑟买了一块细麻布，把耶稣取下来，用细麻布裹好，安放在一个从岩石中凿出来的坟墓里，又滚过一块石头挡住墓门。</span>
<span className="v" id="v47" data-v="47" data-xref="马可福音 15:40; 马可福音 16:1; 路加福音 23:55–2"> 抹大拉的马利亚和约西的母亲马利亚，都看见了安放祂的地方。</span>
</div>
</div>

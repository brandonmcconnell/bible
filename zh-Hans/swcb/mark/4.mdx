<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 5:1–3; 马可福音 2:13; 路加福音 8:4–10"> 耶稣又在海边开始教导人。有一大群人聚集到祂那里，所以祂上了一只停在海里的船坐下。众人都留在海边的陆地上。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 13:34–35; 马可福音 3:23; 马可福音 4:11"> 祂用比喻教导他们许多事，在教导中对他们说：</span>
<span className="v" id="v3" data-v="3" data-xref="雅各书 2:5; 马太福音 13:26; 马可福音 4:26–29"> “你们听着！看哪，有一个农夫出去撒种。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 13:19; 马可福音 4:15; 马太福音 13:4"> 撒的时候，有种子落在路旁，鸟儿飞来把它吃掉了。</span>
<span className="v" id="v5" data-v="5" data-xref="以西结 36:26; 路加福音 8:6; 路加福音 8:13"> 有的落在土浅的石头地上，因为土不深，很快就长出苗来。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 1:11; 耶利米书 17:5–8; 约拿 4:8"> 太阳一出来，就被晒焦了；又因为没有根，就枯干了。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 4:3; 路加福音 8:14; 创世记 3:17–18"> 有的落在荆棘丛中，荆棘长起来，把它挤住了，就结不出果实来。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 15:5; 歌罗西书 1:6; 马可福音 4:20"> 还有的落在好土里，就发芽生长，结出果实，有的结三十倍，有的六十倍，有的一百倍。”</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 11:15; 马可福音 4:23–24; 启示录 3:22"> 耶稣又说：“凡有耳可听的，就应当听。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 13:10–17; 马可福音 4:34; 箴言 13:20"> 当耶稣独自一人的时候，跟随祂的人和十二个门徒问祂这些比喻的意思。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 11:25; 路加福音 8:10; 约翰一书 5:20"> 祂对他们说：“上帝国的奥秘只赐给你们，但对于外面的人，凡事都用比喻，</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 6:9–10; 以赛亚书 44:18; 马太福音 13:14–15"> 叫他们‘看是看见，却不晓得；听是听见，却不明白；免得他们回转而得赦免。’”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="启示录 3:19; 马太福音 13:51–52; 马可福音 7:17–18"> 耶稣又对他们说：“你们不明白这个比喻吗？那怎么能明白所有的比喻呢？</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 8:4; 马太福音 13:19; 马太福音 13:37"> 农夫所撒的，就是道。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 5:8; 马太福音 13:19; 哥林多后书 2:11"> 那些撒在路旁的，就是人听了道，撒但立刻来，把撒在他们心里的道夺走。</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 6:20; 路加福音 8:13; 马太福音 13:20–21"> 同样，那些撒在石头地上的，就是人听了道，立刻欢喜领受，</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 11:6; 帖撒罗尼迦前书 3:3–5; 马太福音 12:31"> 但他们心里没有根，不过是暂时的。一旦为道遭受患难或迫害，立刻就跌倒了。</span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 8:14; 耶利米书 4:3; 马太福音 13:22"> 还有那撒在荆棘丛中的，是指人听了道，</span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 2:15–17; 提摩太前书 6:9–10; 提摩太前书 6:17"> 后来有今生的忧虑、财富的迷惑，以及对其他事物的欲望进来，挤住了道，就结不出果实来。</span>
<span className="v" id="v20" data-v="20" data-xref="歌罗西书 1:10; 路加福音 8:15; 约翰福音 15:4–5"> 那些撒在好土里的，就是人听了道，领受了，并且结出果实，有的三十倍，有的六十倍，有的一百倍。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马太福音 5:15; 路加福音 11:33; 路加福音 8:16"> 耶稣又对他们说：“人拿灯来，难道是要放在量器底下或床底下吗？不是要放在灯台上吗？</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 8:17; 传道书 12:14; 马太福音 10:26–27"> 因为隐藏的事没有不显露出来的，隐瞒的事也没有不暴露出来的。</span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 4:9; 马太福音 11:15; 启示录 2:29"> 凡有耳可听的，就应当听。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="希伯来书 2:1; 路加福音 8:18; 马太福音 7:2"> 祂又对他们说：“要留心你们所听的。你们用什么量器量给人，也会用什么量器量给你们，并且还要加给你们。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 13:12; 路加福音 8:18; 马太福音 25:28–29"> 因为凡有的，还要加给他；凡没有的，连他所有的也要夺走。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马太福音 13:24; 哥林多前书 3:6–9; 路加福音 8:11"> 耶稣又说：“上帝的国如同人把种子撒在地上，</span>
<span className="v" id="v27" data-v="27" data-xref="传道书 11:5; 帖撒罗尼迦后书 1:3; 哥林多前书 15:37–38"> 黑夜睡觉，白日起来，种子发芽生长，他却不知道怎么会这样。</span>
<span className="v" id="v28" data-v="28" data-xref="马可福音 4:31–32; 何西阿 6:3; 腓立比书 1:9–11"> 地自然地出产果实：先长苗，后吐穗，最后穗上结满子粒。</span>
<span className="v" id="v29" data-v="29" data-xref="约珥 3:13; 马太福音 13:30; 马太福音 13:40–43"> 果实一成熟，他立刻就拿镰刀去割，因为收割的时候到了。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="马太福音 13:31–32; 路加福音 13:18–21; 耶利米哀歌 2:13"> 祂又说：“我们可以把上帝的国比作什么呢？或者用什么比喻来说明呢？</span>
<span className="v" id="v31" data-v="31" data-xref="使徒行传 19:20; 路加福音 13:18–19; 但以理 2:44–45"> 它就像一粒芥菜种，种在地里的时候，比地上所有的种子都小；</span>
<span className="v" id="v32" data-v="32" data-xref="但以理 4:20–22; 但以理 4:10–14; 以西结 31:3–10"> 但种下以后，它就长起来，比各样的蔬菜都大，又长出大枝，以致空中的飞鸟可以在它的荫下栖息。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马太福音 13:34–35; 约翰福音 16:12; 希伯来书 5:11–14"> 耶稣用许多这样的比喻，照着他们所能听懂的，向他们讲道。</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 16:25; 马可福音 4:10; 马太福音 15:15–20"> 若不用比喻，就不对他们讲；但私下里，祂向自己的门徒解释一切。</span>
</div>
</div>

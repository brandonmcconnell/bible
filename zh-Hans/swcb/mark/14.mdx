<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 22:1–2; 出埃及记 12:6–20; 约翰福音 13:1"> 距离逾越节和除酵节还有两天。祭司长和文士正在设法怎样用诡计逮捕耶稣，并把祂杀了。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 7:40; 箴言 21:30; 约翰福音 12:19"> 因为他们说：“不可在节期里动手，免得百姓生乱。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="路加福音 7:37–39; 约翰福音 12:1–8; 约翰福音 11:2"> 耶稣在伯大尼长大麻风的西门家里坐席的时候，有一个女人拿来一个雪花石膏瓶，里面盛着非常昂贵的纯真哪哒香膏。她打破瓶子，把香膏浇在耶稣的头上。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰福音 12:4–5; 马太福音 26:8–9; 玛拉基书 1:12–13"> 有几个人心里很恼怒，说：“为什么这样浪费香膏呢？</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 13:29; 以弗所书 4:28; 哥林多前书 10:10"> 这香膏本可以卖三百多个银币<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="300个银币大约是农业工人一年的工资。">a</a></sup>来分给穷人。”于是他们就责备她。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="提多书 3:14; 希伯来书 10:24; 希伯来书 13:21"> 耶稣却说：<span className="woj">“由她吧。为什么为难她呢？她在我身上做了一件美事。</span></span>
<span className="v" id="v7" data-v="7" data-xref="申命记 15:11; 马太福音 26:11; 雅各书 2:14–16"> <span className="woj">因为常有穷人与你们同在，只要你们愿意，随时都能行善帮助他们；但你们不常有我。</span></span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 8:12; 约翰福音 12:7; 马可福音 15:42–1"> <span className="woj">她已经尽了自己所能的。她为我的安葬，预先用香膏抹了我的身体。</span></span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 26:12–13; 马可福音 16:15; 马太福音 24:14"> <span className="woj">我确实地告诉你们，这福音无论传到全世界的什么地方，这女人所做的都要被述说，作为对她的记念。”</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="路加福音 22:3–6; 马太福音 26:14–16; 约翰福音 13:2"> 十二使徒之一的加略人犹大，去见祭司长，要把耶稣交给他们。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 6:10; 何西阿 7:3; 犹大书 1:11"> 他们听见了都很高兴，并答应给他钱。犹大就开始寻找机会，要把耶稣交出去。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及记 12:6; 出埃及记 12:18; 马太福音 26:17–19"> 除酵节的第一天，就是宰杀逾越节羔羊的那一天，门徒问耶稣：“祢要我们去哪里为祢预备逾越节的晚餐呢？”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 22:10–13; 马太福音 26:18–19; 路加福音 19:30–33"> 耶稣就差遣两个门徒，对他们说：<span className="woj">“你们进城去，必有一个拿着水罐的人迎面而来。你们要跟着他，</span></span>
<span className="v" id="v14" data-v="14" data-xref="启示录 3:20; 马可福音 11:3; 约翰福音 13:13"> <span className="woj">无论他进哪一家，你们就对那家的主人说：‘老师问，“我的客房在哪里？我好和我的门徒在那里吃逾越节的晚餐。”’</span></span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 1:13; 诗篇 110:3; 箴言 21:1–2"> <span className="woj">他必亲自指给你们一间摆设整齐、准备妥当的宽敞楼厅。你们就在那里为我们预备吧。”</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰福音 16:4; 路加福音 22:13; 路加福音 22:35"> 门徒出去，进了城，发现一切果然正如耶稣对他们所说的一样，他们就预备了逾越节的晚餐。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 22:14; 约翰福音 13:21–26; 马太福音 26:20–24"> 到了晚上，耶稣和十二使徒来了。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 41:9; 约翰福音 6:47; 约翰福音 6:70"> 他们坐着吃饭的时候，耶稣说：<span className="woj">“我确实地告诉你们，你们中间有一个与我同吃的人将要出卖我了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 22:21–23; 马太福音 26:22; 约翰福音 13:22"> 他们就开始忧愁起来，一个接一个地问祂：“总不是我吧？”另一个也说：“总不是我吧？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约翰福音 13:26; 马太福音 26:23; 约翰福音 6:71"> 耶稣回答他们说：<span className="woj">“是十二使徒中的一个，就是与我一同蘸手在盘子里的那个人。</span></span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 26:24–25; 以赛亚书 53:1–12; 约翰福音 19:28"> <span className="woj">人子固然要离世，正如经上指着祂所写的，但出卖人子的那人有祸了！那人若是没有出生倒好。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马太福音 26:26–29; 马可福音 14:24; 哥林多前书 10:16–17"> 他们吃饭的时候，耶稣拿起饼来，祝福了，就擘开递给他们，说：<span className="woj">“你们拿去吃吧，这是我的身体。”</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马可福音 14:22; 马太福音 26:27; 哥林多前书 10:16"> 祂又拿起杯来，祝谢了，递给他们。他们都喝了。</span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亚书 9:11; 出埃及记 24:8; 启示录 7:9–17"> 耶稣对他们说：<span className="woj">“这是我立约的血，是为许多人流出来的。</span></span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 26:29; 诗篇 104:15; 路加福音 22:16–18"> <span className="woj">我确实地告诉你们，我绝不再喝这葡萄汁，直到我在上帝的国里喝新的那一天。”</span></span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 26:30; 路加福音 22:39; 使徒行传 16:25"> 他们唱了诗歌，就出来往橄榄山去。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="撒迦利亚书 13:7; 约翰福音 16:32; 马太福音 26:31"> 耶稣对他们说：<span className="woj">“今夜你们全都要因为我而跌倒，因为经上记着：‘我要击打牧人，羊群就会分散。’</span></span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 28:16; 马可福音 16:7; 马太福音 28:7"> <span className="woj">然而，我复活以后，要在你们之前先去加利利。”</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马太福音 26:33–35; 路加福音 22:33–34; 约翰福音 13:36–38"> 但彼得对祂说：“即使所有人都跌倒，我也绝不会。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约翰福音 13:38; 马可福音 14:66–72; 创世记 1:5"> 耶稣对他说：<span className="woj">“我确实地告诉你，就在今天，就在今夜，鸡叫两遍以先，你要三次不认我。”</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及记 19:8; 约翰福音 13:37; 箴言 16:18"> 彼得却更加极力地说：“我就是必须与祢同死，也绝不会不认祢！”众人也都这样说。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马可福音 14:36; 马可福音 14:39; 诗篇 18:5–6"> 他们来到一个名叫客西马尼的地方。耶稣对门徒说：<span className="woj">“你们坐在这里，等我祷告。”</span></span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 22:44; 希伯来书 5:7; 马可福音 5:37"> 祂带着彼得、雅各和约翰同去，就开始极其惊恐和难过。</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 12:27; 马可福音 13:35–37; 彼得前书 5:8"> 对他们说：<span className="woj">“我的灵魂极其忧伤，几乎要死。你们留在这里，并要警醒。”</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马可福音 14:41; 申命记 9:18; 希伯来书 5:7"> 祂稍往前走，俯伏在地上祷告，说，如果可能，求这时刻离开祂。</span>
<span className="v" id="v36" data-v="36" data-xref="加拉太书 4:6; 罗马书 8:15–16; 约翰福音 5:30"> 祂说：<span className="woj">“阿爸，</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“阿爸”是亚兰文单词的希腊文拼写，意思是“父亲”或“爸爸”，带有一种亲密、尊敬和慈爱的意味。">b</a></sup><span className="woj">父啊，在祢凡事都能。求祢将这杯撤去。然而，不要照我的意愿，只要照祢的意愿。”</span></span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="马太福音 26:40; 马可福音 14:29–31; 希伯来书 12:3"> 耶稣回来，发现他们睡着了，就对彼得说：<span className="woj">“西门，你睡着了吗？你不能警醒片刻吗？</span></span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 26:41; 马太福音 24:42; 路加福音 21:36"> <span className="woj">总要警醒祷告，免得你们陷入试探。心灵固然愿意，肉体却软弱了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="马太福音 26:42–44; 哥林多后书 12:8; 马太福音 6:7"> 祂又去祷告，说的还是同样的话。</span>
<span className="v" id="v40" data-v="40" data-xref="马可福音 9:33–34; 罗马书 3:19; 创世记 44:16"> 祂再次回来，发现他们又睡着了，因为他们的眼睛非常困倦；他们也不知道该怎么回答祂。</span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 14:35; 马可福音 9:31; 约翰福音 17:1"> 祂第三次回来，对他们说：<span className="woj">“你们现在还在睡觉安歇吗？够了。时刻已经到了。看哪，人子被交在罪人手里了。</span></span>
<span className="v" id="v42" data-v="42" data-xref="马太福音 26:46; 约翰福音 18:1–2"> <span className="woj">起来！我们走吧。看哪，出卖我的人近了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="约翰福音 18:3–11; 路加福音 22:47–53; 马太福音 26:47–56"> 耶稣还在说话的时候，十二使徒之一的犹大立刻来了。还有一群人带着刀剑棍棒，从祭司长、文士和长老那里，与他同来。</span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 26:48–50; 箴言 27:6; 诗篇 55:20–21"> 出卖耶稣的人曾给他们一个暗号，说：“我亲吻谁，谁就是那个人。你们要把祂抓住，严密地押走。”</span>
<span className="v" id="v45" data-v="45" data-xref="马太福音 23:7–10; 玛拉基书 1:6; 马可福音 12:14"> 犹大一到，就立刻走到耶稣跟前，说：“拉比！拉比！”便亲吻了祂。</span>
<span className="v" id="v46" data-v="46" data-xref="约翰福音 18:12; 耶利米哀歌 4:20; 使徒行传 2:23"> 他们就向祂下手，把祂抓住了。</span>
<span className="v" id="v47" data-v="47" data-xref="约翰福音 18:10–11; 马太福音 26:51–54; 路加福音 22:49–51"> 旁边站着的人中，有一个拔出刀来，砍了打祭司长仆人一刀，削掉了他的耳朵。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="路加福音 22:52–53; 撒母耳记上 26:18; 撒母耳记上 24:14–15"> 耶稣对他们说：<span className="woj">“你们带着刀剑棍棒出来抓我，如同对付强盗一样吗？</span></span>
<span className="v" id="v49" data-v="49" data-xref="约翰福音 18:20; 约翰福音 8:2; 路加福音 22:37"> <span className="woj">我天天和你们在一起，在圣殿里教导人，你们并没有逮捕我。但这是为了使经上的话得应验。”</span></span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="马可福音 14:27; 约翰福音 16:32; 诗篇 88:18"> 门徒全都离开祂逃跑了。</span>
<span className="v" id="v51" data-v="51"> 有一个年轻人，赤身披着一块麻布，跟随耶稣。那些年轻人就去抓他，</span>
<span className="v" id="v52" data-v="52" data-xref="马可福音 13:14–16; 创世记 39:12; 约伯记 2:4"> 他却丢下麻布，赤身逃跑了。</span>
<span className="v" id="v53" data-v="53" data-xref="马太福音 26:57–68; 约翰福音 18:12–14; 路加福音 22:54–62"> 他们把耶稣押到大祭司那里。所有的祭司长、长老和文士都聚集在一起。</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="约翰福音 18:18; 马太福音 26:3; 约翰福音 18:25"> 彼得远远地跟着耶稣，一直进了大祭司的院子。他同差役们坐在一起，在火光中烤火取暖。</span>
<span className="v" id="v55" data-v="55" data-xref="彼得前书 3:16–18; 马太福音 26:59–60; 马太福音 5:22"> 祭司长和全议会寻找证据控告耶稣，要治死祂，却找不到。</span>
<span className="v" id="v56" data-v="56"> 因为有许多人作假见证控告祂，但他们的证词并不一致。</span>
<span className="v" id="v57" data-v="57" data-xref="使徒行传 6:13–14; 马太福音 26:60–61; 约翰福音 2:18–21"> 有几个人站起来作假见证控告祂，说：</span>
<span className="v" id="v58" data-v="58" data-xref="约翰福音 2:19; 希伯来书 9:11; 哥林多后书 5:1"> “我们听祂说过：‘我要拆毁这座人手建造的圣殿，三天内我要另建一座不是人手建造的。’”</span>
<span className="v" id="v59" data-v="59"> 即使这样，他们的证词还是不一致。</span>
</div>
<div className="bp">
<span className="v" id="v60" data-v="60" data-xref="约翰福音 19:9–10; 马太福音 26:62–63; 马可福音 15:3–5"> 大祭司站起来，走到中间问耶稣：“祢什么都不回答吗？这些人作见证控告祢的是什么呢？”</span>
<span className="v" id="v61" data-v="61" data-xref="马太福音 26:63–64; 马可福音 15:2; 以赛亚书 53:7"> 耶稣却默不作声，什么也不回答。大祭司又问祂：“祢是那当称颂者的儿子基督吗？”</span>
</div>
<div className="bp">
<span className="v" id="v62" data-v="62" data-xref="但以理 7:13–14; 诗篇 110:1; 希伯来书 1:3"> 耶稣说：<span className="woj">“我是。你们将要看见人子坐在权能者的右边，驾着天上的云降临。”</span></span>
</div>
<div className="bp">
<span className="v" id="v63" data-v="63" data-xref="马太福音 26:65; 以赛亚书 36:22–1; 民数记 14:6"> 大祭司撕裂了自己的衣服，说：“我们还需要什么证人呢？</span>
<span className="v" id="v64" data-v="64" data-xref="利未记 24:16; 约翰福音 10:31–33; 约翰福音 19:7"> 你们已经听见这僭妄的话了！你们认为如何？”他们全都定祂犯了死罪。</span>
<span className="v" id="v65" data-v="65" data-xref="马太福音 26:67–68; 使徒行传 23:2; 以赛亚书 50:6"> 就有人开始向祂吐唾沫，蒙住祂的脸，用拳头打祂，并对祂说：“说预言吧！”差役们也用手掌打祂。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 23:56–12; 约翰福音 20:1–10; 马太福音 28:1–10"> 安息日一过，抹大拉的马利亚、雅各的母亲马利亚和撒罗米就买了香料，要去膏抹耶稣。</span>
<span className="v" id="v2" data-v="2" data-xref="约翰福音 20:1; 路加福音 24:1; 马太福音 28:1"> 一周的第一天清晨，太阳刚出来，她们就来到坟墓那里。</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 15:46–47; 马太福音 27:60–66"> 她们彼此说：“谁能帮我们把石头从墓门辊开呢？”</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 28:2–4; 路加福音 24:2; 约翰福音 20:1"> 原来那石头非常大。她们抬头一看，却看见那石头已经辊开了。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 20:11–12; 路加福音 24:3–5; 约翰福音 20:8"> 她们进了坟墓，看见一个年轻人坐在右边，穿着白袍，就非常惊恐。</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 1:17–18; 哥林多前书 15:3–7; 路加福音 24:46"> 他对她们说：“不要惊恐。你们寻找那钉十字架的拿撒勒人耶稣，祂已经复活了！祂不在这里。请看安放祂的地方！</span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 14:28; 马太福音 26:32; 马太福音 28:10"> 你们去，告诉祂的门徒和彼得说：‘祂要在你们之前先去加利利。在那里你们将要看见祂，正如祂从前对你们所说的那样。’”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路加福音 24:22–24; 路加福音 24:9–11; 马可福音 16:5–6"> 她们出来<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR（公认文本）增加了“急忙”。">a</a></sup>，从坟墓那里逃跑了，因为她们浑身发抖，惊骇不已。她们什么也没对人说，因为她们害怕。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="有一份孤立的手稿省略了第9-20节，但在第8节末尾加上了这个“马可福音的简短结语”：她们把吩咐的一切事，简明地告诉了彼得周围的人。此后，耶稣亲自差遣他们，从东到西，传扬那神圣不朽的、关乎永远救恩的宣告。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约翰福音 20:14–19; 路加福音 8:2; 约翰福音 20:12"> <sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="NU（联合圣经公会版）包含第9-20节的文本，但在脚注中提到少数手稿省略了这部分。世界英语圣经的译者认为，基于压倒性的文本证据，包括权威的希腊文多数文本新约，以及TR（公认文本）和NU文本中引用的许多手稿，马可福音16:9-20是可靠的。">c</a></sup>在一周的第一天清晨，耶稣复活后，首先向抹大拉的马利亚显现；祂曾从她身上赶出七个鬼。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 20:18; 路加福音 24:17; 约翰福音 16:6"> 她去告诉那些向来跟随祂的人，那时他们正在哀恸哭泣。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 24:11; 马可福音 16:13–14; 马可福音 9:19"> 他们听见耶稣还活着，并且被她看见了，却不相信。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="路加福音 24:13–32; 约翰福音 21:14; 约翰福音 21:1"> 这些事之后，门徒中有两个人走在往乡下去的路上，耶稣以另一种形象向他们显现。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 20:25; 路加福音 24:33–35; 约翰福音 20:8"> 他们回去告诉其余的人，大家还是不相信。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 15:5; 路加福音 24:36–43; 希伯来书 3:7–8"> 后来，十一个门徒坐席的时候，耶稣向他们显现；并且斥责他们的不信和心硬，因为他们不信那些在祂复活后看见祂的人。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 28:19; 马可福音 13:10; 使徒行传 1:8"> 祂对他们说：<span className="woj">“你们往普天下去，向万物传扬福音。</span></span>
<span className="v" id="v16" data-v="16" data-xref="约翰福音 11:25–26; 约翰福音 3:36; 罗马书 10:9–14"> <span className="woj">信而受洗的必然得救；但不信的必被定罪。</span></span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 5:16; 哥林多前书 12:28; 使徒行传 8:7"> <span className="woj">信的人必有这些神迹伴随他们：奉我的名赶鬼；说新方言；</span></span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 10:19; 雅各书 5:14–15; 使徒行传 28:3–6"> <span className="woj">手能拿蛇；若喝了什么致命的毒物，也绝不受害；手按病人，病人就必康复。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="彼得前书 3:22; 希伯来书 1:3; 希伯来书 12:2"> 主<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="NU增加了“耶稣”。">d</a></sup>和他们说完了话，就被接升天，坐在上帝的右边。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 2:4–5; 使徒行传 14:3; 罗马书 15:19"> 门徒出去，到处传道，主与他们同工，借着伴随的神迹证实所传的道。阿们。</span>
</div>

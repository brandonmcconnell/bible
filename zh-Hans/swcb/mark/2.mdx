<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 4:47; 路加福音 5:18; 路加福音 18:35–38"> 过了几天，耶稣又进了迦百农。人们听说祂在家里，</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 2:13; 马可福音 1:45; 诗篇 40:9"> 立刻有许多人聚集，甚至连门前都没有空地了；祂就对他们讲道。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 5:18–26; 马太福音 9:1–8; 马太福音 4:24"> 有四个人抬着一个瘫子来到祂那里。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 5:19; 申命记 22:8"> 因为人多，无法走到祂跟前，他们就把祂上方的屋顶拆了。拆开之后，把瘫子连他躺卧的垫子一起缒了下去。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 9:2; 雅各书 5:15; 马可福音 2:9–10"> 耶稣看见他们的信心，就对瘫子说：<span className="woj">“孩子，你的罪得赦免了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="路加福音 5:21–22; 马可福音 8:17; 哥林多后书 10:5"> 但有几个文士坐在那里，心里议论说：</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 43:25; 路加福音 5:21; 弥迦书 7:18"> “这个人为什么这样说僭妄的话呢？除了上帝以外，谁能赦罪呢？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="诗篇 139:2; 使徒行传 8:22; 路加福音 5:22"> 耶稣灵里立刻知道他们心里这样议论，就对他们说：<span className="woj">“你们心里为什么议论这些事呢？</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 5:22–25; 马太福音 9:5"> <span className="woj">对瘫子说‘你的罪得赦免了’，或说‘起来，拿起你的垫子行走’，哪一样更容易呢？</span></span>
<span className="v" id="v10" data-v="10" data-xref="但以理 7:13–14; 马太福音 9:6–8; 约翰福音 5:20–27"> <span className="woj">但要叫你们知道，人子在地上有赦罪的权柄”</span>——祂就对瘫子说——</span>
<span className="v" id="v11" data-v="11" data-xref="马可福音 1:41; 约翰福音 5:8–10; 约翰福音 6:63"> <span className="woj">“我吩咐你，起来，拿起你的垫子，回家去吧。”</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 9:33; 马太福音 9:8; 路加福音 7:16"> 那人就起来，立刻拿起垫子，当着众人的面出去了。以致众人都十分惊奇，将荣耀归给上帝，说：“我们从来没有见过这样的事！”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马可福音 4:1; 箴言 1:20–22; 路加福音 19:48"> 耶稣又出到海边去，众人都来到祂那里，祂便教导他们。</span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 5:27–32; 路加福音 6:15; 马太福音 9:9–13"> 祂往前走的时候，看见亚勒腓的儿子利未坐在税关上，就对他说：<span className="woj">“跟从我。”</span>利未就起来跟从了祂。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 15:1; 路加福音 5:29–30; 马太福音 9:10–11"> 耶稣在利未家里坐席的时候，有许多税吏和罪人与耶稣和祂的门徒一同坐席，因为有许多这样的人跟从祂。</span>
<span className="v" id="v16" data-v="16" data-xref="路加福音 19:10; 路加福音 19:7; 路加福音 18:11"> 法利赛人中的文士看见耶稣和罪人及税吏一同吃饭，就对祂的门徒说：“祂怎么和税吏及罪人一同吃喝呢？”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 9:12–13; 路加福音 15:7; 路加福音 5:31–32"> 耶稣听见，就对他们说：<span className="woj">“健康的人不需要医生，有病的人才需要。我来本不是要呼召义人，而是要呼召罪人悔改。”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 18:12; 马太福音 6:18; 马太福音 9:14–17"> 当时，约翰的门徒和法利赛人正在禁食。有人来问耶稣：“为什么约翰的门徒和法利赛人的门徒禁食，祢的门徒却不禁食呢？”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马太福音 25:1–10; 创世记 29:22; 士师记 14:10–11"> 耶稣对他们说：<span className="woj">“新郎还跟伴郎在一起的时候，伴郎岂能禁食呢？只要新郎还跟他们在一起，他们就不能禁食。</span></span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 17:22; 启示录 21:9; 以赛亚书 54:5"> <span className="woj">但日子将到，新郎要从他们身边被带走，那一天他们就要禁食了。</span></span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 9:16; 哥林多前书 10:13; 以赛亚书 57:16"> <span className="woj">没有人会把一块没缩过水的新布缝在旧衣服上，否则新补丁会把旧衣服扯破，破洞就更大了。</span></span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 9:17; 诗篇 119:83; 路加福音 5:37–38"> <span className="woj">也没有人会把新酒装进旧皮袋里；否则新酒会胀破皮袋，酒漏出来，皮袋也毁了；新酒必须装在新皮袋里。”</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 12:1–8; 申命记 23:24–25; 路加福音 6:1–5"> 有一个安息日，耶稣经过麦田。祂的门徒在行路时，开始掐起麦穗来。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 20:10; 希伯来书 12:3; 马太福音 12:2"> 法利赛人对耶稣说：“看哪，他们为什么在安息日做不合法的事呢？”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 21:3–6; 路加福音 10:26; 马太福音 22:31"> 耶稣对他们说：<span className="woj">“大卫和跟从他的人缺乏饥饿时所做的事，你们没有念过吗？</span></span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 8:17; 利未记 24:5–9; 撒母耳记上 21:1"> <span className="woj">他在亚比亚他作大祭司的时候，怎样进了上帝的殿，吃了陈设饼（这饼除了祭司以外，任何人吃都是不合法的），又给跟从他的人吃？”</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="歌罗西书 2:16; 路加福音 6:9; 申命记 5:14"> 祂又对他们说：<span className="woj">“安息日是为人设立的，人不是为安息日设立的。</span></span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 12:8; 启示录 1:10; 约翰福音 5:17"> <span className="woj">所以，人子也是安息日的主。”</span></span>
</div>
</div>

</div>

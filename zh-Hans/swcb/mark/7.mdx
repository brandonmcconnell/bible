<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 15:1–20; 马可福音 3:22; 路加福音 5:17"> 那时，法利赛人和几个从耶路撒冷来的文士，聚集在耶稣那里。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 10:28; 马太福音 7:3–5; 罗马书 14:14"> 他们看见祂的几个门徒用不洁净的手，也就是没有洗过的手吃饭，就加以指责。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 1:14; 马可福音 7:13; 歌罗西书 2:8"> （原来，法利赛人和所有的犹太人都拘守古人的传统，若不仔细洗手就不吃饭；</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 9:10; 马太福音 23:25; 路加福音 11:38–39"> 他们从市场回来，若不洗净也不吃饭；他们还拘守许多别的传统，比如洗杯子、罐子、铜器和床铺。</span>
<span className="v" id="v5" data-v="5" data-xref="帖撒罗尼迦后书 3:6; 使徒行传 21:21; 马太福音 15:2"> 法利赛人和文士问祂：“祢的门徒为什么不遵守古人的传统，竟用不洁净的手吃饭呢？”</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 29:13; 提多书 1:16; 马太福音 15:7–9"> 耶稣回答他们说：<span className="woj">“以赛亚指着你们这些伪君子所作的预言是对的，正如经上所记：</span><br /><span className="pl pl-1 woj">‘这百姓用嘴唇尊敬我，</span><br /><span className="pl pl-2 woj">心却远离我。</span></span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 29:13; 马太福音 15:9; 雅各书 1:26"> <span className="pl pl-1 woj">他们敬拜我也是徒然的，</span><br /><span className="pl pl-2 woj">因为他们把人的规条当作教义教导人。’</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="马可福音 7:3–4; 以赛亚书 1:12"> <span className="woj">“你们撇弃了上帝的诫命，却拘守人的传统——就如洗罐子、洗杯子，还做了许多类似的事。”</span></span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 44:16–17; 加拉太书 2:21; 以赛亚书 29:13"> 祂又对他们说：<span className="woj">“你们为了坚守自己的传统，竟巧妙地废弃了上帝的诫命！</span></span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 21:17; 出埃及记 20:12; 申命记 5:16"> <span className="woj">摩西曾说：‘当孝敬父母’；</span><span className="woj">又说：‘咒骂父母的，必被处死。’</span></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 23:18; 提摩太前书 5:4–8; 马太福音 15:5"> <span className="woj">但你们却说：‘人若对父母说：“我本该给你们的供养，已经作了各耳板”’</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“各耳板”是希伯来语，意为献给上帝的供物。">a</a></sup>（各耳板就是献给上帝的供物），</span>
<span className="v" id="v12" data-v="12"> <span className="woj">“你们就不再容许他为父母做任何事。</span></span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 7:9; 提多书 1:14; 马太福音 5:17–20"> <span className="woj">这就是你们借着代代相传的传统，废弃了上帝的道。你们还做了许多类似的事。”</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 15:10; 以赛亚书 6:9; 箴言 8:5"> 耶稣又把众人叫来，对他们说：<span className="woj">“你们所有人都要听我的，也要明白。</span></span>
<span className="v" id="v15" data-v="15" data-xref="箴言 4:23; 利未记 11:42–47; 提多书 1:15"> <span className="woj">从外面进去的，不能使人污秽；唯有从人里面出来的，才能使人污秽。</span></span>
<span className="v" id="v16" data-v="16"> <span className="woj">有耳可听的，就应当听！”</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NU（联合圣经公会版）省略第16节。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 15:15; 马太福音 13:36; 马可福音 9:28"> 耶稣离开众人进了一所房子，门徒就向祂请教这个比喻。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 15:16–17; 希伯来书 5:11; 以赛亚书 28:9–10"> 祂对他们说：<span className="woj">“你们也这样不明白吗？难道你们不知道，凡从外面进入人里面的，不能使人污秽，</span></span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 15:17; 哥林多前书 6:13; 歌罗西书 2:21–22"> <span className="woj">因为它不是进入人的心，而是进入人的胃，然后排入厕所，这样就洁净了各样食物吗？”</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="NU在“厕所”后结束了耶稣的直接引语和提问，以“这样祂就宣告各样食物都是洁净的了”结束本节。">c</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="雅各书 3:6; 雅各书 1:14–15; 雅各书 4:1"> 祂又说：<span className="woj">“从人里面出来的，那才使人污秽。</span></span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 17:9; 罗马书 8:7–8; 雅各书 4:1–3"> <span className="woj">因为从里面，就是从人心里发出来的，有恶念、苟合、淫乱、谋杀、偷窃、</span></span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 20:15; 马太福音 6:23; 彼得前书 2:15"> <span className="woj">贪婪、邪恶、诡诈、放荡、嫉妒、毁谤、骄傲和愚妄。</span></span>
<span className="v" id="v23" data-v="23" data-xref="马可福音 7:15; 提多书 1:15; 哥林多前书 3:17"> <span className="woj">这一切的恶都是从里面发出来的，并且能使人污秽。”</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="马太福音 15:21–28; 马太福音 11:21; 以西结 28:2"> 耶稣从那里起身，往推罗和西顿的境内去。祂进了一所房子，本来不想让人知道，却隐藏不住。</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 15:22; 马可福音 9:17–23; 使徒行传 10:25–26"> 有一个妇人，她的小女儿被污鬼附着，听见耶稣的事，就来俯伏在祂脚前。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 15:22; 以赛亚书 49:12; 加拉太书 3:28"> 这妇人是希腊人，属于叙利非尼基族。她求耶稣把鬼从她女儿身上赶出去。</span>
<span className="v" id="v27" data-v="27" data-xref="马太福音 15:23–28; 马太福音 7:6; 使徒行传 22:21"> 耶稣对她说：<span className="woj">“让孩子们先吃饱吧，拿孩子们的饼扔给狗吃是不合适的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="罗马书 10:12; 罗马书 3:29; 使徒行传 11:17–18"> 妇人回答说：“主啊，是的，但桌子底下的狗也吃孩子们掉下来的碎渣。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 66:2; 马太福音 5:3; 约翰一书 3:8"> 耶稣对她说：<span className="woj">“就凭这句话，你回去吧。鬼已经从你女儿身上出去了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约翰一书 3:8; 约翰福音 4:50–52"> 她回到家里，发现孩子躺在床上，鬼已经出去了。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马可福音 5:20; 马太福音 15:29–31; 马太福音 4:25"> 耶稣又离开推罗的境界，经过西顿和底加波利地区，来到加利利海。</span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 11:14; 马可福音 5:23; 马太福音 9:32–33"> 有人带着一个耳聋口吃的人来见耶稣，求祂按手在他身上。</span>
<span className="v" id="v33" data-v="33" data-xref="马可福音 8:23; 约翰福音 9:6–7; 马可福音 5:40"> 耶稣把他领到一边，离开众人，用手指探进他的耳朵，又吐唾沫抹他的舌头；</span>
<span className="v" id="v34" data-v="34" data-xref="约翰福音 11:41; 马可福音 5:41; 马可福音 6:41"> 然后望天叹息，对他说：<span className="woj">“以法大！”</span>意思是，<span className="woj">“开了吧！”</span></span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 35:5–6; 诗篇 33:9; 马可福音 2:12"> 他的耳朵立刻开了，舌结也解了，说话也清楚了。</span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 8:4; 马可福音 8:26; 马可福音 3:12"> 耶稣嘱咐他们不要告诉任何人，但祂越是嘱咐，他们越是热烈地宣扬。</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 6:51; 马可福音 5:42; 出埃及记 4:10–11"> 众人惊奇到了极点，说：“祂所做的一切都好，甚至让聋子听见，让哑巴说话！”</span>
</div>
</div>

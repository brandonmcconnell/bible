<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 5:12–14; 哥林多后书 7:1; 希伯来书 9:14"> 所以，我们应当离开基督初步道理的教导，竭力进到完全成熟，不再重新立根基，就是悔改离开死的行为、对上帝有信心，</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 15:13–57; 使徒行传 17:31–32; 罗马书 6:3–5"> 以及关于各种洗礼、按手、死人复活和永远审判的教导。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 18:21; 哥林多前书 16:7; 哥林多前书 4:19"> 如果上帝许可，我们就要这样做。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 10:26–29; 彼得后书 2:20–22; 马太福音 5:13"> 因为那些曾经蒙了光照，尝过天上的恩赐，又有份于圣灵，</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前书 2:3; 路加福音 8:13; 马太福音 13:20–21"> 并且尝过上帝美善的话语和来世的能力，</span>
<span className="v" id="v6" data-v="6" data-xref="彼得后书 2:21; 希伯来书 10:29; 希伯来书 6:4"> 后来却离弃的人，要使他们重新悔改是不可能的；因为他们为自己把上帝的儿子重钉十字架，公然羞辱祂。</span>
<span className="v" id="v7" data-v="7" data-xref="何西阿 10:12; 以赛亚书 44:3; 诗篇 65:9–13"> 那吸收屡次降在其上的雨水，并为耕种它的人生出合用作物的土地，就从上帝领受祝福；</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 3:17–18; 约翰福音 15:6; 路加福音 13:7–9"> 但如果它长出荆棘和蒺藜，就被弃绝，近于受咒诅，结局就是被焚烧。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="希伯来书 10:39; 哥林多后书 7:10; 希伯来书 6:4–6"> 亲爱的，虽然我们这样说，却深信你们有更好的事，就是与救恩相伴的事。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 10:42; 希伯来书 13:16; 加拉太书 6:10"> 因为上帝并非不公义，以至于忘记你们的工作，以及你们为祂的名所显出的爱心劳苦，就是你们曾服侍圣徒，并且仍在服侍。</span>
<span className="v" id="v11" data-v="11" data-xref="彼得后书 1:5–8; 希伯来书 3:6; 罗马书 5:2–5"> 我们渴望你们每一个人都显出同样的殷勤，使盼望充足，一直到底，</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 13:7; 希伯来书 10:36; 约翰一书 2:25"> 好叫你们不至于懈怠，反而效法那些凭着信心和忍耐承受应许的人。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 22:15–18; 路加福音 1:73; 耶利米书 22:5"> 上帝向亚伯拉罕许应许的时候，既不能指着比自己更大的起誓，就指着自己起誓，</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 22:17; 申命记 1:10; 尼希米记 9:23"> 说：“我必定赐福给你，必定使你增多。”</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 12:2–3; 罗马书 4:17–25; 出埃及记 1:7"> 这样，他耐心等候以后，就得着了所应许的。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 22:11; 希伯来书 6:13; 创世记 31:53"> 人确实是指着比自己大的起誓；在他们一切争议中，起誓作为确认，就了结了争端。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 6:18; 箴言 19:21; 以赛亚书 55:11"> 照样，上帝既定意要向承受应许的人更充分地显明祂旨意的不改变，就用誓言加以保证，</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 23:19; 提多书 1:2; 撒母耳记上 15:29"> 好叫我们这些逃去避难、要抓住摆在前面盼望的人，借着这两件不改变的事——在这些事上上帝绝不可能说谎——可以得到强有力的鼓励。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 43:5; 罗马书 5:5–10; 希伯来书 9:7"> 这盼望是我们灵魂的锚，既稳妥又牢靠，并且进入幔子内的地方；</span>
<span className="v" id="v20" data-v="20" data-xref="希伯来书 4:14; 希伯来书 3:1; 希伯来书 5:6"> 作先锋的耶稣已经为我们进入那里，照着麦基洗德的等次成了永远的大祭司。</span>
</div>

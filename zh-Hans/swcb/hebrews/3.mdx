<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="提摩太后书 1:9; 腓立比书 3:14; 希伯来书 4:14–15"> 所以，圣洁的弟兄们，你们这些有份于属天呼召的人，应当思想我们所承认的使徒和大祭司：耶稣。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 12:7; 提摩太前书 3:15; 以弗所书 2:22"> 祂对那位委任祂的忠心，正如摩西在祂的全家中也忠心一样。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多前书 3:9; 彼得前书 2:5–7; 撒迦利亚书 6:12–13"> 祂被算为配得比摩西更大的荣耀，因为建造房屋的人比房屋更尊贵。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 3:3; 希伯来书 1:2; 以斯帖记 2:10"> 因为每一座房屋都是由人建造的，但建造万物的是上帝。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 12:7; 希伯来书 3:2; 出埃及记 14:31"> 摩西确实作为仆人，在祂的全家中忠心，为以后要说的事作见证；</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 6:16; 哥林多前书 3:16; 希伯来书 10:35"> 但基督<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“基督”的意思是“受膏者”。">a</a></sup>作为儿子，治理祂的家忠心。我们若把我们的确信和因盼望而有的夸耀坚守到底，我们就是祂的家。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 95:7–11; 希伯来书 3:15; 以赛亚书 55:3"> 所以，正如圣灵所说：<br /><span className="pl pl-1">“今天，如果你们听见祂的声音，</span></span>
<span className="v" id="v8" data-v="8" data-xref="箴言 28:14; 出埃及记 17:7; 撒迦利亚书 7:11–12"> <span className="pl pl-2">就不可硬着你们的心，像在悖逆的时候，</span><br /><span className="pl pl-2">在旷野受试炼的日子；</span><br /></span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 7:36; 申命记 4:9; 出埃及记 19:4"> <span className="pl pl-2">在那里，你们的祖先试验我，考验我，</span><br /><span className="pl pl-2">并且看见我的作为四十年。</span></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 95:10; 帖撒罗尼迦后书 2:10–12; 诗篇 67:2"> <span className="pl pl-1">因此我厌烦那世代，</span><br /><span className="pl pl-2">说：‘他们心里常常迷误，</span><br /><span className="pl pl-2">他们不认识我的道路。’</span></span>
<span className="v" id="v11" data-v="11" data-xref="申命记 1:34–35; 希伯来书 4:3; 民数记 32:10–13"> <span className="pl pl-1">我就在怒中起誓：</span><br /><span className="pl pl-2">‘他们绝不可进入我的安息。’”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="耶利米书 17:5; 耶利米书 7:24; 耶利米书 17:9"> 弟兄们，你们要谨慎，免得你们中间有人存着不信的邪恶之心，以致离弃永活的上帝；</span>
<span className="v" id="v13" data-v="13" data-xref="帖撒罗尼迦前书 5:11; 希伯来书 10:24–25; 提摩太后书 4:2"> 总要趁着还有称为“今天”的时候，天天彼此劝勉，免得你们中间有人因罪的欺骗而刚硬。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 3:6; 希伯来书 6:11; 希伯来书 12:10"> 因为我们若将起初的确信坚定地坚持到底，就已经与基督有份了；</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 3:7–8; 诗篇 95:7; 希伯来书 10:38"> 正如有话说：<br /><span className="pl pl-1">“今天，如果你们听见祂的声音，</span><br /><span className="pl pl-2">就不可硬着你们的心，像在悖逆的时候。”</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数记 14:2; 民数记 14:30; 民数记 26:65"> 那些听见了却悖逆的是谁呢？难道不是所有由摩西带领出埃及的人吗？</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 14:29; 民数记 26:64–65; 民数记 14:32–33"> 祂厌烦了四十年的是谁呢？难道不是那些犯罪、尸首倒在旷野的人吗？</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 14:30; 希伯来书 4:6; 申命记 1:34–35"> 祂向谁起誓，说他们不能进入祂的安息呢？不就是那些不顺从的人吗？</span>
<span className="v" id="v19" data-v="19" data-xref="犹大书 1:5; 约翰福音 3:36; 马可福音 16:16"> 这样看来，他们不能进入，是因为不信。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="希伯来书 1:3; 歌罗西书 3:1; 启示录 3:21"> 我们所说的事，重点就是：我们有这样一位大祭司，祂已经坐在天上威严者宝座的右边，</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 33:7; 哥林多后书 5:1; 希伯来书 9:23–24"> 是圣所和真帐幕的执事；这帐幕是主所支搭的，不是人所支搭的。</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所书 5:2; 希伯来书 5:1; 希伯来书 9:14"> 凡大祭司都是为献上礼物和祭物而设立的。因此，这位大祭司也必须有所献上。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 7:11–15; 希伯来书 5:1; 民数记 17:12–13"> 祂若在地上，就根本不会是祭司，因为已经有照律法献礼物的祭司；</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 25:40; 歌罗西书 2:17; 希伯来书 10:1"> 他们事奉的不过是天上事物的副本和影子，正如摩西将要建造帐幕的时候，上帝警戒他说：“你要谨慎，照着在山上指示你的样式，制造一切。”</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 7:22; 加拉太书 3:16–21; 希伯来书 12:24"> 但如今，祂所得的职事更优越，正如祂也是更美之约的中保；这约是凭更美的应许立定的。</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="希伯来书 7:11; 加拉太书 3:21; 希伯来书 7:18"> 那第一个约若没有缺欠，就不会寻求第二个约的位置了。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 31:31–34; 希伯来书 10:16–17; 希伯来书 12:24"> 因为祂指责他们说：<br /><span className="pl pl-1">“看哪，</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“看哪”来自“ἰδοὺ”，意思是看、留意、观察、看见或注视。它常用作感叹词。">a</a></sup><br /><span className="pl pl-1">日子将到，”主说，</span><br /><span className="pl pl-2">“我要与以色列家和犹大家立新约；</span></span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 31:32; 加拉太书 4:24; 马可福音 8:23"> <span className="pl pl-1">不像我拉着他们祖宗的手，</span><br /><span className="pl pl-2">领他们出埃及地的那日与他们所立的约；</span><br /><span className="pl pl-1">因为他们没有持守我的约，</span><br /><span className="pl pl-2">我也不理他们，”主说。</span></span>
<span className="v" id="v10" data-v="10" data-xref="以西结 36:26–28; 耶利米书 31:33; 以西结 11:19–20"> <span className="pl pl-1">“主说：那些日子以后，</span><br /><span className="pl pl-2">我与以色列家所立的约乃是这样：</span><br /><span className="pl pl-1">我要把我的律法放在他们的心思里；</span><br /><span className="pl pl-2">也要写在他们的心上。</span><br /><span className="pl pl-1">我要作他们的上帝，</span><br /><span className="pl pl-2">他们要作我的子民。</span></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 31:34; 以赛亚书 54:13; 约翰福音 6:45"> <span className="pl pl-1">他们各人不必教导自己的同胞</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TR作“邻舍”，而不是“同胞”。">b</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-2">各人也不必教导自己的弟兄，说：‘你要认识主’，</span><br /><span className="pl pl-2">因为他们都要认识我，</span><br /><span className="pl pl-2">从他们中最小的到最大的。</span></span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 10:16–17; 以赛亚书 43:25; 罗马书 11:27"> <span className="pl pl-1">因为我要怜悯他们的不义，</span><br /><span className="pl pl-2">不再记念他们的罪和不法行为。”</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="哥林多后书 5:17; 希伯来书 7:18–19; 希伯来书 7:11–12"> 祂既说“新约”，就使第一个约成为旧的了。但那正在变旧、渐渐衰老的，就快要消逝了。</span>
</div>

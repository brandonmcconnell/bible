<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="HEB" data-book-slug="hebrews" data-book-name="希伯来书" data-chapter="11" data-verses="40">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 5:7; 哥林多后书 4:18; 罗马书 8:24–25"> 信心是所盼望之事的把握，是未见之事的确据。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:39; 希伯来书 11:4"> 古人因这信心得了称许。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 33:6; 彼得后书 3:5; 约翰福音 1:3"> 因着信，我们明白宇宙是借着上帝的话造成的，以致所看见的并不是从可见之物造出来的。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="希伯来书 12:24; 创世记 4:3–5; 约翰一书 3:11–12"> 因着信，亚伯献给上帝比该隐更美的祭；借着这祭，他得了自己为义人的见证，就是上帝为他的礼物作见证；又借着这信，他虽然死了，却仍旧说话。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 5:21–24; 犹大书 1:14; 希伯来书 11:6"> 因着信，以诺被接去，使他不至于见死；人也找不到他，因为上帝已经把他接去了。原来他被接去以前，已经得了蒙上帝喜悦的见证。</span>
<span className="v" id="v6" data-v="6" data-xref="箴言 8:17; 耶利米书 29:13–14; 马太福音 6:33"> 没有信，就不可能蒙祂喜悦；因为到上帝面前来的人必须信祂存在，并且信祂赏赐寻求祂的人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="创世记 6:13–1; 彼得前书 3:20; 以西结 14:14"> 因着信，挪亚既蒙警示，知道还没有看见的事，就怀着敬虔的惧怕<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“敬畏”">a</a></sup>预备了一只方舟，使他全家得救；借着这信，他定了世界的罪，并且承受了那照着信而来的义。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="创世记 12:1–4; 使徒行传 7:2–4; 马太福音 7:24–25"> 因着信，亚伯拉罕蒙召的时候，就顺从出去，往他将要领受为产业的地方去。他出去的时候，还不知道要往哪里去。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 12:8; 创世记 13:18; 创世记 13:3"> 因着信，他在应许之地寄居，好像在异乡，与同承一个应许的以撒、雅各同住帐棚。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 13:14; 腓立比书 3:20; 希伯来书 12:22"> 因为他等候那座有根基的城；这城的设计者和建造者就是上帝。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="罗马书 4:20–21; 希伯来书 10:23; 创世记 18:11–14"> 因着信，连撒拉自己虽然过了生育的年龄，仍得了怀孕生子的能力，因为她认定那应许她的是信实的。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 22:17; 创世记 32:12; 创世记 15:5"> 所以，从一个人，就是一个如同已死的人，生出如天上的星那样众多、如海边的沙那样无数的人来。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="创世记 23:4; 诗篇 39:12; 希伯来书 11:27"> 这些人都是存着信而死的，并没有得着所应许的，只是从远处看见<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="公认经文加上“并且确信”">b</a></sup>了，又欢迎它们，并且承认自己在地上是客旅，是寄居的。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 4:18–7; 希伯来书 11:16; 希伯来书 13:14"> 说这样话的人，显明他们正在寻找自己的家乡。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 24:6–8; 创世记 12:10; 创世记 32:9–11"> 如果他们想念的是自己出来的那个地方，他们本来还有机会回去。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 13:14; 希伯来书 11:10; 腓立比书 3:20"> 但如今他们羡慕一个更美的家乡，就是天上的。因此，上帝不以被称为他们的上帝为耻，因为祂已经为他们预备了一座城。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 22:16; 创世记 22:1–12; 雅各书 2:21–24"> 因着信，亚伯拉罕受试验的时候，把以撒献上；是的，那欢然领受各样应许的人，正把他独一的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“独一的”一词来自希腊文“μονογενη”，有时译作“独生的”或“唯一的”。">c</a></sup>儿子献上。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 21:12; 罗马书 9:7; 创世记 17:19"> 论到这儿子，曾有话说：“你的后裔要从以撒而称为。”</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 4:17–21; 马太福音 9:28; 以弗所书 3:20"> 他断定，上帝甚至能叫人从死人中复活。按比喻说，他也确实从死人中把他领回来了。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 27:27–40; 创世记 28:2–3"> 因着信，以撒为将来的事祝福雅各和以扫。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 47:31–1; 创世记 48:5–22"> 因着信，雅各临死的时候，祝福约瑟的两个儿子各人，并且扶着杖头敬拜。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及记 13:19; 创世记 50:24–25; 约书亚记 24:32"> 因着信，约瑟临终的时候，提到以色列子孙出埃及的事，并且为自己的骸骨留下吩咐。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出埃及记 1:22; 出埃及记 1:16; 希伯来书 13:6"> 因着信，摩西出生以后，被父母藏了三个月，因为他们看见这孩子俊美；他们也不怕王的命令。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出埃及记 2:10–11; 使徒行传 7:21–24"> 因着信，摩西长大以后，拒绝被称为法老女儿的儿子，</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 84:10; 提摩太后书 2:3–10; 约伯记 36:21"> 宁愿和上帝的子民同受虐待，也不愿暂时享受罪中之乐；</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 10:35; 希伯来书 11:6; 彼得前书 4:14"> 他看为基督所受的羞辱比埃及的财宝更宝贵，因为他注目于那赏赐。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多后书 4:18; 希伯来书 11:13; 希伯来书 11:1"> 因着信，他离开埃及，不怕王的怒气；因为他坚忍，像是看见那不能看见的上帝。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 12:21–30; 希伯来书 9:19; 希伯来书 12:24"> 因着信，他守逾越节并洒血，使那灭长子的不能碰他们。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="出埃及记 14:13–21; 诗篇 106:9–11; 诗篇 78:13"> 因着信，他们过红海如行干地；埃及人试着这样做，就被吞灭了。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约书亚记 6:3–20; 哥林多后书 10:4–5"> 因着信，耶利哥的城墙被围绕七天以后就倒塌了。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="雅各书 2:25; 约书亚记 6:22–25; 马太福音 1:5"> 因着信，妓女喇合和平地接待了探子，就没有和那些不顺从的人一同灭亡。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 16:1; 撒母耳记上 1:20; 撒母耳记上 16:13"> 我还要再说什么呢？如果要述说基甸、巴拉、参孙、耶弗他、大卫、撒母耳和众先知，时间就不够了——</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 144:1–2; 希伯来书 6:12–15; 希伯来书 10:36"> 他们借着信制服了列国，施行了公义，得了应许，堵住了狮子的口，</span>
<span className="v" id="v34" data-v="34" data-xref="列王纪下 6:16–18; 哥林多后书 12:9–10; 撒母耳记上 17:51–52"> 灭了烈火的威力，逃脱了刀剑的锋刃，从软弱中变为刚强，在战争中成为勇猛，使外国的军队逃跑。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪下 4:27–37; 列王纪上 17:22–24; 腓立比书 3:11"> 有妇人得回自己的死人，就是借着复活得回的。另有人受酷刑，不肯接受释放，为要得着更美的复活。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 20:2; 创世记 39:20; 耶利米书 37:15–21"> 又有人受戏弄和鞭打的试炼，甚至受捆锁和监禁。</span>
<span className="v" id="v37" data-v="37" data-xref="历代志下 24:21; 耶利米书 26:23; 列王纪上 19:10"> 他们被石头打死。他们被锯锯死。他们受试探。他们被刀杀死。他们披着绵羊皮和山羊皮到处流浪；穷乏、受患难、受虐待——</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪上 18:4; 撒母耳记上 22:1; 列王纪上 19:9"> 这世界不配有他们——他们漂流在旷野、山岭、洞穴和地洞中。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="路加福音 10:23–24; 希伯来书 11:13; 希伯来书 11:2"> 这些人都因信得了称许，却没有得着所应许的；</span>
<span className="v" id="v40" data-v="40" data-xref="启示录 6:11; 希伯来书 8:6; 希伯来书 10:11–14"> 因为上帝为我们预备了更美的事，使他们若没有我们，就不能得以完全。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰一书 4:20–1; 彼得前书 3:8; 彼得前书 1:22"> 你们要常存弟兄相爱的心。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 25:35; 创世记 18:1–3; 彼得前书 4:9"> 不要忘记接待客旅，因为有人这样做，不知不觉就接待了天使。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 25:36; 希伯来书 10:34; 罗马书 12:15"> 要记念那些被捆锁的人，如同与他们同被捆锁；也要记念受虐待的人，因为你们自己也在身体之内。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 2:24; 箴言 5:15–23; 加拉太书 5:19"> 婚姻人人都应当尊重，婚床也不可玷污；因为淫乱的人和奸淫的人，上帝必审判。</span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="申命记 31:8; 约书亚记 1:5; 申命记 31:6"> 你们要不贪爱钱财，以现有的为满足，因为祂曾说：“我绝不撇下你，也绝不离弃你。”</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 118:6–9; 以赛亚书 41:10; 罗马书 8:31"> 所以我们可以放胆说：<br /><span className="pl pl-1">“主是帮助我的，我必不惧怕。</span><br /><span className="pl pl-2">人能对我做什么呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="帖撒罗尼迦前书 5:12–13; 希伯来书 13:17; 腓立比书 3:17"> 你们要记念那些带领你们的人，就是曾把上帝的话讲给你们的人；要思想他们行事为人的结局，效法他们的信心。</span>
<span className="v" id="v8" data-v="8" data-xref="玛拉基书 3:6; 雅各书 1:17; 启示录 1:8"> 耶稣基督昨日、今日、直到永远，都是一样的。</span>
<span className="v" id="v9" data-v="9" data-xref="以弗所书 4:14; 提摩太前书 6:3–5; 以弗所书 5:6"> 不要被各样陌生怪异的教导带偏；因为心靠恩典得坚固是好的，不是靠食物；那些拘泥于食物的人并没有因此得益。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 5:7–8; 哥林多前书 10:20; 哥林多前书 9:13"> 我们有一座祭坛，那些事奉圣幕的人没有权利从这坛上吃。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 16:27; 出埃及记 29:14; 利未记 9:11"> 因为那些牲畜的血由大祭司带进圣所作为赎罪祭，牲畜的尸体却在营外焚烧。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 9:12–14; 约翰福音 19:17–18; 使徒行传 7:58"> 因此，耶稣也为要用自己的血使百姓成圣，就在城门外受苦。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 11:26; 彼得前书 4:14–16; 使徒行传 5:41"> 所以，我们要出到营外，到祂那里去，担当祂所受的凌辱。</span>
<span className="v" id="v14" data-v="14" data-xref="腓立比书 3:20; 歌罗西书 3:1–3; 希伯来书 11:12–16"> 因为我们在这里没有长存的城，却寻求那将要来的城。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 107:21–22; 诗篇 50:14; 罗马书 12:1"> 那么，我们要藉着祂，常常把赞美的祭献给上帝，这就是嘴唇宣告效忠祂名所结的果子。</span>
<span className="v" id="v16" data-v="16" data-xref="帖撒罗尼迦后书 3:13; 加拉太书 6:10; 罗马书 12:13"> 只是不可忘记行善和分享，因为这样的祭是上帝所喜悦的。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦前书 5:12–13; 提摩太前书 5:17; 希伯来书 13:7"> 你们要顺服那些带领你们的人，并且服从他们；因为他们为你们的灵魂警醒，好像将来要交账的人。要使他们欢欢喜喜地做这事，不至于叹息；否则，那对你们没有益处。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="帖撒罗尼迦前书 5:25; 帖撒罗尼迦后书 3:1; 歌罗西书 4:3"> 请为我们祷告；因为我们深信自己有无亏的良心，愿意在凡事上行得端正。</span>
<span className="v" id="v19" data-v="19" data-xref="腓利门书 1:22; 罗马书 1:10–12; 罗马书 15:31–32"> 我更恳切地劝你们这样做，好使我早日回到你们那里。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约翰福音 10:11; 希伯来书 10:22; 诗篇 23:1"> 愿赐平安的上帝，就是凭永约之血使群羊的大牧人——我们的主耶稣——从死人中复活的上帝，</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比书 2:13; 帖撒罗尼迦后书 2:17; 腓立比书 4:13"> 在各样善工上装备你们，使你们遵行祂的旨意；又藉着耶稣基督，在你们里面成就祂眼中所喜悦的事。愿荣耀归给祂，直到永永远远。阿们。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="希伯来书 3:1; 彼得前书 5:12; 哥林多后书 6:1"> 弟兄们，我劝你们容纳这劝勉的话，因为我只用简短的话写给你们。</span>
<span className="v" id="v23" data-v="23" data-xref="腓利门书 1:1; 帖撒罗尼迦前书 3:2; 提摩太后书 1:8"> 你们要知道，我们的弟兄提摩太已经获释；如果他很快就来，我会同他一起去见你们。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="希伯来书 13:7; 希伯来书 13:17; 使徒行传 18:2"> 请问候所有带领你们的人和众圣徒。从意大利来的人问候你们。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="歌罗西书 4:18; 提摩太后书 4:22; 提多书 3:15"> 愿恩典与你们众人同在。阿们。</span>
</div>

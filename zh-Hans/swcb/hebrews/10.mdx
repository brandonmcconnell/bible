<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="HEB" data-book-slug="hebrews" data-book-name="希伯来书" data-chapter="10" data-verses="39">

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 8:5; 希伯来书 9:11; 歌罗西书 2:17"> 律法既有将来美事的影子，不是那些事物本体的真像，就绝不能用每年不断献上的同样祭物，使那些近前来的人完全。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 43:25; 弥迦书 7:19; 诗篇 103:12"> 否则，这些祭物岂不早已停止献上了吗？因为敬拜的人一次得洁净以后，就不再有罪的意识了。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 9:7; 出埃及记 30:10; 利未记 23:27–28"> 但在那些祭物中，每年都有罪的提醒。</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 10:11; 以赛亚书 1:11–15; 弥迦书 6:6–8"> 因为公牛和山羊的血不可能除去罪。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 40:6–8; 以赛亚书 1:11; 以赛亚书 7:14"> 所以，祂到世上来的时候，说：<br /><span className="pl pl-1">“祭物和供物不是你所愿要的，</span><br /><span className="pl pl-2">但你为我预备了身体。</span></span>
<span className="v" id="v6" data-v="6" data-xref="玛拉基书 1:10; 马太福音 3:17; 诗篇 147:11"> <span className="pl pl-1">全烧祭和赎罪祭不是你所喜悦的。</span></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 40:7–8; 约翰福音 4:34; 约翰福音 6:38"> <span className="pl pl-2">那时我说：‘看哪，我来了；经卷上已经记载关于我的事；</span><br /><span className="pl pl-2">上帝啊，我来为要遵行你的旨意。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="希伯来书 10:5; 马可福音 12:33"> 祂前面说：“祭物、供物、全烧祭和赎罪祭不是你所愿要的，也不是你所喜悦的”（这些都是按律法献上的），</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 7:18–19; 希伯来书 12:27–28; 希伯来书 10:7"> 然后祂又说：“看哪，我来了，为要遵行你的旨意。”祂废去前者，为要设立后者。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 10:14; 希伯来书 10:12; 哥林多前书 6:11"> 凭这旨意，借着耶稣基督的身体一次而永远地献上，我们已经成圣了。</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="希伯来书 5:1; 民数记 28:3; 希伯来书 10:4"> 每一个祭司确实天天站着事奉，屡次献上同样的祭物；这些祭物绝不能除去罪。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 1:3; 歌罗西书 3:1; 罗马书 8:34"> 但祂为罪献上一次永远有效的祭物以后，就坐在上帝的右边，</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 1:13; 诗篇 110:1; 路加福音 20:43"> 从此等候祂的仇敌被放在祂的脚下作脚凳。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 7:25; 希伯来书 10:1; 希伯来书 9:14"> 因为祂借着一次献祭，就使那些正在成圣的人永远完全。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 3:7; 启示录 2:11; 启示录 3:6"> 圣灵也向我们作见证，因为祂先说：</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 31:33–34; 希伯来书 8:8–12; 罗马书 11:27"> <span className="pl pl-1">“主说：那些日子以后，</span><br /><span className="pl pl-2">这就是我要与他们所立的约：</span><br /><span className="pl pl-1">我要把我的律法放在他们心上，</span><br /><span className="pl pl-2">也要写在他们意念上；”</span><br />然后祂又说：</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 31:34; 希伯来书 8:12"> <span className="pl pl-1">“我绝不再记念他们的罪和他们的罪孽。”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="希伯来书 10:2; 希伯来书 10:14"> 既然这些都得了赦免，就不再有为罪献的祭物了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以弗所书 2:18; 希伯来书 9:12; 希伯来书 4:16"> 所以，弟兄们，我们既然靠着耶稣的血，有胆量进入圣所，</span>
<span className="v" id="v20" data-v="20" data-xref="约翰福音 14:6; 约翰福音 10:9; 希伯来书 9:3"> 借着祂为我们开辟的一条又新又活的路，穿过幔子，也就是说，穿过祂的肉身，</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 2:17; 希伯来书 4:14–16; 希伯来书 8:1"> 又有一位伟大的祭司治理上帝的家，</span>
<span className="v" id="v22" data-v="22" data-xref="以西结 36:25; 约翰福音 3:5; 以弗所书 5:26"> 就让我们以真诚的心、充足的信心近前来；我们的心已经被洒净，脱离了邪恶的良心，身体也用清水洗净了。</span>
<span className="v" id="v23" data-v="23" data-xref="帖撒罗尼迦前书 5:24; 哥林多前书 1:9; 帖撒罗尼迦后书 3:3"> 我们要坚守所宣认的盼望，毫不动摇；因为那应许我们的祂是信实的。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦前书 5:11; 约翰一书 3:18; 希伯来书 13:1"> 我们要思考怎样彼此激励，以致有爱心和善行；</span>
<span className="v" id="v25" data-v="25" data-xref="使徒行传 2:42; 帖撒罗尼迦前书 5:11; 马太福音 18:20"> 不可放弃我们自己的聚会，像有些人习惯那样；倒要彼此劝勉。既然你们看见那日临近，就更要如此。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="彼得后书 2:20–22; 希伯来书 6:4–6; 约翰福音 9:41"> 因为我们领受了真理的知识以后，若故意犯罪，就不再有赎罪的祭物了；</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 26:11; 希伯来书 2:3; 西番雅书 1:18"> 只剩下可怕地等候审判，以及那将吞灭对敌者的烈火。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 2:2; 申命记 19:15; 申命记 17:2–13"> 藐视摩西律法的人，凭两三个见证人的证言，不蒙怜悯而死。</span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 6:6; 以弗所书 4:30; 以赛亚书 63:10"> 何况那践踏上帝的儿子，把使他成圣之约的血看作不圣洁，又侮辱恩典的圣灵的人，你们想，他将被判为配受多么更重的刑罚呢？</span>
<span className="v" id="v30" data-v="30" data-xref="申命记 32:35–36; 罗马书 12:19; 那鸿书 1:2"> 因为我们知道那位说：“伸冤在我，我必报应，”主说。又说：“主将审判祂的子民。”</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 10:28; 路加福音 12:5; 希伯来书 12:29"> 落在永活上帝的手里，真是可怕的事。</span>
</div>
<div className="bp poetry">
<span className="v" id="v32" data-v="32" data-xref="希伯来书 6:4; 希伯来书 12:4; 提摩太后书 2:3–13"> 但你们要记念从前的日子，那时你们蒙了光照以后，忍受了苦难中的大争战：</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多前书 4:9; 腓立比书 4:14; 希伯来书 11:36"> 一方面，你们被公开示众，遭受辱骂和患难；另一方面，你们又成为那些遭遇这样之人的同伴。</span>
<span className="v" id="v34" data-v="34" data-xref="彼得前书 1:4; 提摩太后书 1:16; 马太福音 5:11–12"> 因为我受锁链捆绑时，你们同情我；你们也欣然接受自己的财物被抢夺，因为知道你们为自己在天上有更美、更长存的产业。</span>
<span className="v" id="v35" data-v="35" data-xref="哥林多前书 15:58; 加拉太书 6:8–10; 希伯来书 3:6"> 所以，不要丢弃你们的胆量，它有极大的赏赐。</span>
<span className="v" id="v36" data-v="36" data-xref="希伯来书 12:1; 诗篇 37:7; 雅各书 5:7–11"> 因为你们需要忍耐，为的是在遵行上帝的旨意以后，可以得着所应许的。</span>
<span className="v" id="v37" data-v="37" data-xref="雅各书 5:7–9; 哈巴谷 2:3–4; 路加福音 18:8"> <span className="pl pl-1">“再过非常短的一点时候，</span><br /><span className="pl pl-2">那要来的就要来，并不迟延。</span></span>
<span className="v" id="v38" data-v="38" data-xref="加拉太书 3:11; 哈巴谷 2:4; 罗马书 1:17"> <span className="pl pl-1">但义人必因信而活。</span><br /><span className="pl pl-2">他若退缩，我的心就不喜悦他。”</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="约翰一书 5:5; 彼得前书 1:5; 马可福音 16:16"> 但我们不是那些退缩以致沉沦的人，而是那些有信心以致灵魂得救的人。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 25:8; 希伯来书 9:10–11; 希伯来书 8:2"> 其实，连第一<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR 加上“会幕”">a</a></sup>个约也有事奉上帝的条例和地上的圣所。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 40:4; 利未记 24:5–8; 出埃及记 26:35"> 因为有一座会幕预备好了。头一层里面有灯台、桌子和陈设饼，这一层称为圣所。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 26:31–33; 出埃及记 40:3; 马太福音 27:51"> 第二层幔子后面，是称为至圣所的会幕，</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 17:10; 历代志下 5:10; 出埃及记 40:3"> 里面有金香坛和四面包金的约柜；柜里有盛吗哪的金罐、亚伦发过芽的杖和约版；</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 16:2; 民数记 7:89; 出埃及记 25:17–22"> 柜上面有荣耀的基路伯遮盖施恩座。关于这些事，我们现在不能逐一细说。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数记 28:3; 出埃及记 27:21; 路加福音 1:8–11"> 这些物件既这样预备好了，祭司就常常进入头一层会幕，履行事奉的职责；</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 16:34; 利未记 5:18; 希伯来书 10:19–20"> 至于第二层，只有大祭司一年一次独自进去，而且不是不带着血；这血是他为自己和百姓的过失献上的。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 14:6; 希伯来书 3:7; 希伯来书 10:19–22"> 圣灵借此表明：头一层会幕仍然存立的时候，进入圣所的道路还没有显明。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得前书 3:21; 希伯来书 5:1; 罗马书 5:14"> 这象征现今的时代；在其中所献的礼物和祭物，就良心而言，不能使敬拜者完全，</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 2:15; 歌罗西书 2:16; 利未记 11:2–47"> 不过是连同食物、饮料和各样洗濯礼在内的属肉体条例，是施加在人身上直到更新的时候。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="希伯来书 9:23–24; 哥林多后书 5:1; 希伯来书 8:1–2"> 但是，基督已经来到，作了将来美好事物的大祭司；祂借着那更大、更完全的会幕——不是人手所造的，也就是说，不属于这受造界的——</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 10:4; 彼得前书 1:18–19; 希伯来书 9:15"> 也不是借着山羊和牛犊的血，而是借着祂自己的血，一次而永远地进入圣所，获得了永远的救赎。</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 19:2–21; 利未记 16:14–16; 使徒行传 15:9"> 如果山羊和公牛的血，以及母牛的灰洒在被玷污的人身上，尚且使人成圣，达到肉体的洁净，</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 10:22; 彼得前书 1:19; 约翰一书 1:7"> 何况基督的血呢？祂借着永恒的圣灵，把无瑕无疵的自己献给上帝；祂的血岂不更能洁净你们的良心，使你们脱离死的行为，好事奉永活的上帝吗？</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 3:24–26; 罗马书 8:30; 罗马书 8:28"> 因此，祂是新约的中保；既然已经有死亡发生，为要救赎人在第一约之下所犯的过犯，好使那些蒙召的人可以领受永恒产业的应许。</span>
<span className="v" id="v16" data-v="16" data-xref="雅各书 2:10; 哥林多前书 15:22; 罗马书 5:12"> 凡有遗嘱，就必须有立遗嘱者的死；</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 48:21; 约翰福音 14:27; 加拉太书 3:15"> 因为遗嘱是在人死后才有效；立遗嘱的人还活着时，遗嘱绝不会生效。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 24:3–8; 希伯来书 9:14; 希伯来书 9:22"> 所以，就连第一约也不是不用血设立的。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 24:5–11; 民数记 19:6; 希伯来书 10:4"> 因为摩西照着律法把每一条诫命都向众百姓讲完以后，就拿牛犊和山羊的血，连同水、朱红色羊毛和牛膝草，把那书本身和众百姓都洒了，</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 24:8; 马太福音 26:28; 希伯来书 13:20"> 说：“这是上帝吩咐给你们的约之血。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="利未记 8:15; 利未记 8:19; 出埃及记 29:36"> 他又照样用血洒了会幕和事奉用的一切器皿。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 17:11; 利未记 6:7; 利未记 4:35"> 按照律法，几乎一切都是用血洁净的；若不流血，就没有赦免。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="彼得前书 1:19–21; 希伯来书 10:4; 希伯来书 9:14"> 所以，天上事物的摹本必须用这些来洁净；但天上的事物本身，必须用比这些更好的祭物来洁净。</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 12:2; 希伯来书 9:11–12; 希伯来书 9:23"> 因为基督并没有进入人手所造、作为真圣所仿本的圣所，而是进入了天上本身，如今为我们显在上帝面前；</span>
<span className="v" id="v25" data-v="25" data-xref="希伯来书 9:12; 希伯来书 9:7; 希伯来书 9:14"> 祂也不是要多次献上自己，像大祭司年年带着不是自己的血进入圣所那样；</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 9:12; 彼得前书 1:20; 希伯来书 1:2"> 否则，从创世以来，祂就必须多次受苦了。但如今在世代的末了，祂只显现了一次，借着献上自己为祭来除去罪。</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多后书 5:10; 传道书 12:7; 传道书 12:14"> 按着定命，人都要死一次，死后有审判；</span>
<span className="v" id="v28" data-v="28" data-xref="提多书 2:13; 彼得前书 2:24; 罗马书 6:10"> 照样，基督也一次被献上，担当了许多人的罪；祂还要第二次显现，不是为了处理罪，而是为了拯救那些热切等候祂的人。</span>
</div>

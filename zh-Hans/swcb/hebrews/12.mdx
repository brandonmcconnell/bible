<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太后书 4:7; 哥林多前书 9:24–27; 腓立比书 2:16"> 所以，我们既有这样众多如云的见证人围绕着，就该卸下一切重担和那容易缠累我们的罪，以坚忍奔跑那摆在我们前面的赛程，</span>
<span className="v" id="v2" data-v="2" data-xref="弥迦书 7:7; 彼得前书 3:18; 彼得前书 2:23–24"> 仰望耶稣，就是信心的创始者和成全者。祂因那摆在祂前面的喜乐，就忍受了十字架，轻看羞辱，如今已经坐在上帝宝座的右边。</span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="加拉太书 6:9; 哥林多后书 4:16; 启示录 2:3"> 你们要思想这位忍受罪人这样顶撞祂的主，免得你们疲倦，灵魂灰心。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 10:13; 启示录 2:13; 希伯来书 10:32–34"> 你们与罪争战，还没有抵抗到流血的地步。</span>
<span className="v" id="v5" data-v="5" data-xref="箴言 3:11–12; 约伯记 5:17–18; 启示录 3:19"> 你们又忘了那把你们当儿女劝勉的话：<br /><span className="pl pl-1">“我儿，不可轻看主的管教，</span><br /><span className="pl pl-2">被祂责备的时候也不可灰心；</span><br /></span>
<span className="v" id="v6" data-v="6" data-xref="启示录 3:19; 箴言 3:12; 诗篇 119:75"> <span className="pl pl-2">因为主所爱的，祂必管教，</span><br /><span className="pl pl-2">又鞭打凡祂所接纳的儿子。”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="箴言 19:18; 申命记 8:5; 箴言 13:24"> 你们忍受，是为了受管教。上帝待你们如同待儿女；哪有儿子不受父亲管教呢？</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 12:6; 彼得前书 5:9–10; 诗篇 73:1"> 但如果你们没有受管教，而众人都已经有份于管教，那么你们就是私生子，不是儿女了。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 16:22; 民数记 27:16; 以赛亚书 42:5"> 再者，我们曾有肉身的父亲管教我们，我们尚且尊敬他们；何况万灵的父，我们岂不更当顺服祂而得生命吗？</span>
<span className="v" id="v10" data-v="10" data-xref="彼得后书 1:4; 利未记 11:44–45; 提多书 2:14"> 他们确实是照自己以为好的，在短暂的日子里管教我们；但祂管教我们，是为我们的益处，使我们可以有份于祂的圣洁。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 5:3–5; 哥林多后书 4:17; 希伯来书 12:5–6"> 凡管教，当时似乎不觉得喜乐，反觉得忧愁；可是后来，对于那些经过管教训练的人，它结出平安的义果。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 35:3; 希伯来书 12:3; 帖撒罗尼迦前书 5:14"> 所以，你们要把下垂的手、发软的膝挺起来，</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 4:26–27; 以赛亚书 35:3; 加拉太书 6:1"> 也要为你们的脚修直道路，使瘸腿的不要脱臼，反而得医治。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="哥林多后书 7:1; 彼得前书 1:15–16; 帖撒罗尼迦前书 4:7"> 你们要追求与众人和睦，并追求圣洁；没有圣洁，没有人能看见主。</span>
<span className="v" id="v15" data-v="15" data-xref="希伯来书 3:12; 申命记 29:18; 加拉太书 5:4"> 你们要谨慎，免得有人亏缺上帝的恩典；免得有苦毒的根长出来扰乱你们，许多人因此被玷污；</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 25:31–34; 哥林多前书 6:15–20; 启示录 22:15"> 免得有人淫乱，或像以扫那样亵渎世俗；他为了一顿饭卖了自己长子的名分。</span>
<span className="v" id="v17" data-v="17" data-xref="箴言 1:24–31; 马太福音 25:11–12; 马太福音 7:23"> 你们知道，后来他想要承受祝福，竟被拒绝；虽然他流泪恳切寻求，却找不到改变心意的机会。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命记 4:11; 出埃及记 24:17; 出埃及记 20:18"> 你们原不是来到那可触摸、燃着火的山，以及幽暗、黑暗、暴风，</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 18:16; 哥林多前书 15:52; 申命记 4:12"> 号角的响声和说话的声音面前；那些听见这声音的人恳求不要再向他们多说一句话，</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 19:12–13; 出埃及记 19:16; 加拉太书 3:10"> 因为他们承受不了所吩咐的话：“即使是牲畜触碰这山，也要被石头打死。”<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="公认文本加上：“或用箭射死”">a</a></sup></span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 19:16; 申命记 9:19; 以赛亚书 6:3–5"> 那景象如此可怕，以至于摩西说：“我惊恐战栗。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="加拉太书 4:26; 腓立比书 3:20; 启示录 14:1"> 但你们已经来到锡安山，来到永活上帝的城，就是天上的耶路撒冷，来到无数众多的天使那里，</span>
<span className="v" id="v23" data-v="23" data-xref="雅各书 1:18; 希伯来书 11:40; 路加福音 10:20"> 来到欢庆的聚会，和登记在天上的众长子的教会，来到审判众人的上帝那里，来到已经成全的义人之灵那里，</span>
<span className="v" id="v24" data-v="24" data-xref="希伯来书 9:15; 希伯来书 11:28; 希伯来书 11:4"> 来到新约的中保耶稣那里，并来到所洒的血那里；这血所说的，比亚伯的血所说的更美。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="希伯来书 8:5; 申命记 30:17; 希伯来书 2:1–3"> 你们要谨慎，不可拒绝那位说话的。因为那些拒绝在地上警告他们的，尚且不能逃罪；何况我们这些转离那位从天上警告我们的，岂不更不能逃罪吗？</span>
<span className="v" id="v26" data-v="26" data-xref="哈该书 2:6–7; 以赛亚书 13:13; 出埃及记 19:18"> 当时祂的声音震动了地；但如今祂已经应许说：“再一次，我不但要震动地，还要震动天。”</span>
<span className="v" id="v27" data-v="27" data-xref="哥林多前书 7:31; 马太福音 24:35; 彼得后书 3:10–11"> “再一次”这句话表明，那些被震动之物，就是受造之物，都要被除去，好使那些不被震动的存留下来。</span>
<span className="v" id="v28" data-v="28" data-xref="罗马书 12:1–2; 希伯来书 13:15; 但以理 2:44"> 所以，我们既领受了不能被震动的国，就当持守恩典，借着这恩典，以虔诚和敬畏，照上帝所悦纳的事奉祂，</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 4:24; 申命记 9:3; 希伯来书 10:27"> 因为我们的上帝乃是吞灭的火。</span>
</div>
</div>

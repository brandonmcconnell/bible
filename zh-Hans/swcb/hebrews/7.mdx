<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="HEB" data-book-slug="hebrews" data-book-name="希伯来书" data-chapter="7" data-verses="28">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 14:18–20; 诗篇 57:2; 希伯来书 6:20"> 这位麦基洗德，是撒冷王，也是至高上帝的祭司；他迎接击败众王归来的亚伯拉罕，并为他祝福。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 18:21; 诗篇 85:10–11; 撒母耳记上 8:17"> 亚伯拉罕也把一切所得的十分之一分给他。他的名首先解释为“公义之王”，然后他又是“撒冷王”，意思就是“平安之王”。</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 7:17; 希伯来书 7:23–28; 出埃及记 6:20–27"> 他无父，无母，无家谱，既无日子的开始，也无生命的终结，却被显为与上帝的儿子相似，长久作祭司。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="创世记 14:20; 使徒行传 2:29; 使徒行传 7:8–9"> 你们想一想，这人是何等伟大，连族长亚伯拉罕也把上好的战利品取十分之一给了他。</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 27:30–33; 历代志下 31:4–6; 民数记 18:21–32"> 利未子孙中领受祭司职分的人，照着律法有命令，可以向百姓收取十一奉献，就是向自己的弟兄收取，虽然这些人也是出自亚伯拉罕的身体。</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 4:13; 希伯来书 7:3–4; 创世记 13:14–17"> 但那家谱不列在他们中间的人，却从亚伯拉罕收取十一奉献，并且为那领受应许的人祝福。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 30:27; 创世记 48:15–20; 提摩太前书 3:16"> 毫无争议，位分小的是蒙位分大的祝福。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 6:20; 希伯来书 5:6; 启示录 1:18"> 在这里，收取十一奉献的是会死的人；在那里，收取十一奉献的却是那被见证为活着的人。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 5:12; 创世记 14:20; 希伯来书 7:4"> 可以说，连收取十一奉献的利未，也借着亚伯拉罕纳了十一奉献，</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 35:11; 希伯来书 7:5; 创世记 46:26"> 因为麦基洗德迎接亚伯拉罕的时候，利未还在他祖先的身体里。</span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="希伯来书 8:7; 加拉太书 2:21; 加拉太书 4:9"> 如果完全是借着利未的祭司职分而有的——因为百姓是在这职分之下领受了律法——那么，为什么还需要另有一位祭司照麦基洗德的等次兴起，而不称为照亚伦的等次呢？</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 31:31–34; 以赛亚书 66:21; 以西结 16:61"> 祭司职分既然改变，律法也必然随之改变。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 7:11; 希伯来书 7:14; 民数记 17:5"> 因为这些话所指的那一位，属于另一个支派；从那支派中从来没有人在祭坛前供职。</span>
<span className="v" id="v14" data-v="14" data-xref="弥迦书 5:2; 以赛亚书 11:1; 路加福音 3:33"> 我们的主显然是出自犹大；论到这个支派，摩西没有说过有关祭司职分的事。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 110:4; 希伯来书 7:17–21; 希伯来书 7:3"> 如果照麦基洗德的样式另有一位祭司兴起，这事就更加显明了。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 1:18; 歌罗西书 2:20; 希伯来书 7:28"> 祂成为祭司，不是照属肉体命令的律法，而是照不能毁坏之生命的大能；</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 110:4; 希伯来书 5:6; 希伯来书 7:21"> 因为有见证说：<br /><span className="pl pl-1">“你是永远的祭司，</span><br /><span className="pl pl-2">照麦基洗德的等次。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v18" data-v="18" data-xref="罗马书 8:3; 使徒行传 13:39; 加拉太书 4:9"> 先前的命令因软弱无益而被废除，</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 13:39; 希伯来书 4:16; 希伯来书 9:9"> 因为律法没有使什么成为完全；同时又引进了更美的盼望，借着这盼望，我们亲近上帝。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 18:7; 希伯来书 5:6; 诗篇 110:4"> 再者，祂成为祭司既不是没有起誓；</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 110:4; 希伯来书 7:17; 希伯来书 6:16–18"> 那些人固然是没有起誓而成为祭司的，惟有祂是借着那论到祂说话者的誓言成为祭司：<br /><span className="pl pl-1">“主起了誓，必不改变心意：</span><br /><span className="pl pl-2">‘你是永远的祭司，</span><br /><span className="pl pl-2">照麦基洗德的等次。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="哥林多前书 11:25; 创世记 44:32; 希伯来书 8:6–12"> 正因如此，耶稣就成了更美之约的保证。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="尼希米记 12:10–11; 历代志上 6:3–14; 希伯来书 7:8"> 那些人成为祭司的确有许多，因为死亡阻止他们继续任职。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 12:34; 希伯来书 7:28; 以赛亚书 9:6–7"> 但祂因为永远长存，就拥有永不更换的祭司职分。</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 8:34; 约翰一书 2:1–2; 提摩太前书 2:5"> 所以，凡借着祂亲近上帝的人，祂都能拯救到底，因为祂永远活着，为他们代求。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="哥林多后书 5:21; 希伯来书 4:14–15; 彼得前书 2:22"> 这样的大祭司正适合我们：圣洁、无邪恶、没有玷污、与罪人分别，并且被高举超过诸天。</span>
<span className="v" id="v27" data-v="27" data-xref="希伯来书 9:28; 希伯来书 9:12; 希伯来书 9:14"> 祂不像那些大祭司，必须天天献上祭物，先为自己的罪，后为百姓的罪；因为祂献上自己时，就一次而永远地成就了这事。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 2:10; 希伯来书 7:21; 希伯来书 1:2"> 律法所立为大祭司的是有软弱的人；但在律法以后所起誓的话，却立了那位已经得以完全、直到永远的儿子。</span>
</div>
</div>

<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 8:3; 希伯来书 10:11; 希伯来书 7:27"> 凡大祭司都是从人间选取，受任命替人办理与上帝有关的事，为要献上礼物和赎罪祭。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 4:15; 希伯来书 2:18; 哥林多后书 12:9–10"> 他能温和地对待那些无知和迷失的人，因为他自己也被软弱所包围。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 9:7; 希伯来书 9:7; 利未记 16:6"> 因此，他必须为百姓的罪献祭，也必须为自己的罪献祭。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 28:1; 民数记 16:40; 民数记 16:5"> 没有人自己取得这尊荣，惟有像亚伦一样蒙上帝呼召的人才可以。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 2:7; 约翰福音 8:54; 使徒行传 13:33"> 照样，基督也没有荣耀自己，使自己成为大祭司；而是那对祂说话的荣耀了祂：<br /><span className="pl pl-1">“你是我的儿子；</span><br /><span className="pl pl-2">我今日生了你。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="诗篇 110:4; 希伯来书 7:17; 希伯来书 7:21"> 祂又在另一处说：<br /><span className="pl pl-1">“你是永远的祭司，</span><br /><span className="pl pl-2">照着麦基洗德的等次。”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马可福音 14:32–39; 路加福音 22:41–44; 约翰福音 17:1"> 基督在祂肉身的日子，曾大声哀哭，流泪祷告恳求那能救祂脱离死亡的主；祂因敬虔的敬畏，蒙了垂听。</span>
<span className="v" id="v8" data-v="8" data-xref="腓立比书 2:8; 希伯来书 10:5–9; 约翰福音 4:34"> 祂虽然是儿子，还是因所受的苦难学会了顺从。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 2:10; 希伯来书 9:12; 希伯来书 9:15"> 祂既已得以完全，就为所有顺从祂的人，成了永恒救恩的根源，</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 5:5–6; 希伯来书 6:20"> 蒙上帝称为照着麦基洗德等次的大祭司。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马太福音 13:15; 使徒行传 28:27; 彼得后书 3:16"> 关于祂，我们有许多话要说，而且难以解释，因为你们已经变得听觉迟钝。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 6:1; 哥林多前书 3:1–3; 彼得前书 2:2"> 到这个时候，你们本该作教师了；可是你们还需要有人重新教导你们上帝启示之言初步原则的基础。你们成了需要奶，而不是干粮的人。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 14:20; 彼得前书 2:2; 提摩太后书 3:16"> 凡吃奶的人，对公义的话都没有经验，因为他是婴孩。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 2:14–15; 帖撒罗尼迦前书 5:21; 以弗所书 1:18"> 但干粮是给长大成人的人；他们的感官因操练而熟练，能够分辨善恶。</span>
</div>

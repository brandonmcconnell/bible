<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="GAL" data-book-slug="galatians" data-book-name="加拉太书" data-chapter="5" data-verses="26">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 3:17; 加拉太书 5:13; 彼得前书 2:16"> 所以，基督已经使我们得了自由；你们要在这自由中站立得稳，不要再被奴役的轭束缚。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="加拉太书 5:6; 使徒行传 15:1; 罗马书 9:31–32"> 看哪，我保罗告诉你们：你们若接受割礼，基督就对你们毫无益处。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 3:10; 罗马书 2:25; 雅各书 2:10–11"> 我也再向每一个接受割礼的人作证：他有义务遵行全部律法。</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 9:31–32; 彼得后书 2:20–22; 罗马书 11:6"> 你们这些想靠律法称义的人，已经与基督隔绝，从恩典中坠落了。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 130:5; 帖撒罗尼迦前书 1:10; 诗篇 62:5"> 因为我们借着圣灵，凭着信心，等候义的盼望。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 6:15; 哥林多前书 7:19; 雅各书 2:14–26"> 因为在基督耶稣里，受割礼或不受割礼都算不得什么，唯有借着爱发挥功效的信心才算数。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="哥林多前书 9:24; 加拉太书 3:1; 希伯来书 12:1"> 你们本来跑得很好！是谁拦阻了你们，使你们不顺从真理呢？</span>
<span className="v" id="v8" data-v="8" data-xref="加拉太书 1:6; 罗马书 8:28"> 这样的劝诱不是出于那位呼召你们的。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 15:33; 哥林多前书 5:6–7; 马可福音 8:15"> 一点酵会发遍整团面。</span>
<span className="v" id="v10" data-v="10" data-xref="加拉太书 5:12; 哥林多后书 2:3; 加拉太书 1:7"> 我在主里对你们有信心，相信你们不会有别的想法；但那扰乱你们的人，无论是谁，都必承担他应受的审判。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 1:23; 加拉太书 6:12; 加拉太书 4:29"> 然而，弟兄们，至于我，我若仍然传割礼，为什么还受迫害呢？那么，十字架令人绊跌之处就被除去了。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 5:10; 哥林多前书 5:13; 提多书 3:10"> 我真希望那些搅扰你们的人索性阉割自己。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="彼得前书 2:16; 哥林多前书 9:19; 哥林多前书 8:9"> 弟兄们，你们蒙召是要得自由；只是不可把自由当作放纵肉体的机会，倒要借着爱彼此作仆人。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 7:12; 利未记 19:18; 加拉太书 6:2"> 因为全律法都在这一句话中得以成全，就是：“要爱你的邻舍如同自己。”</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 3:3; 雅各书 3:14–3; 加拉太书 5:26"> 但你们若彼此相咬相吞，就要小心，免得彼此吞灭了。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="加拉太书 5:24–25; 罗马书 8:12–14; 加拉太书 6:8"> 我却说，你们要顺着圣灵而行，就绝不会满足肉体的私欲。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 8:13; 约翰福音 3:6; 罗马书 8:5–8"> 因为肉体所贪恋的与圣灵相敌，圣灵所愿的也与肉体相敌；这两者彼此敌对，使你们不能做自己所愿意做的事。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 8:14; 罗马书 6:14–15; 加拉太书 5:25"> 但你们若被圣灵引导，就不在律法之下。</span>
<span className="v" id="v19" data-v="19" data-xref="哥林多前书 6:9–10; 歌罗西书 3:5–8; 马太福音 15:18–19"> 肉体的行为是显而易见的，就是：通奸、淫乱、污秽、放荡、</span>
<span className="v" id="v20" data-v="20" data-xref="提多书 3:10; 哥林多前书 11:19; 启示录 21:8"> 偶像崇拜、巫术、仇恨、纷争、猜忌、暴怒、争竞、分裂、派系纷争、</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 6:9–10; 罗马书 8:13; 罗马书 13:13"> 嫉妒、凶杀、醉酒、狂欢宴乐，以及诸如此类的事；我预先警告你们，正如我从前也警告过你们：行这样事的人必不能承受上帝的国。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 3:12–17; 哥林多前书 13:4–7; 约翰福音 15:5"> 圣灵的果子却是爱、喜乐、平安、忍耐、恩慈、良善、信心<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：信实">a</a></sup>、</span>
<span className="v" id="v23" data-v="23" data-xref="提摩太前书 1:9; 使徒行传 24:25; 提多书 2:2"> 温柔和节制。这样的事，没有律法禁止。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 6:6; 罗马书 13:14; 罗马书 8:13"> 凡属基督的人，已经把肉体及其情欲和私欲钉在十字架上了。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="加拉太书 5:16; 罗马书 8:4–5; 罗马书 8:2"> 我们若靠圣灵而活，也要靠圣灵行事。</span>
<span className="v" id="v26" data-v="26" data-xref="雅各书 3:14–16; 腓立比书 2:1–3; 雅各书 4:16"> 我们不要变得自负，彼此挑衅，彼此嫉妒。</span>
</div>
</div>

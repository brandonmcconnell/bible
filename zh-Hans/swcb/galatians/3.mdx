<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 5:7–8; 哥林多后书 11:3; 加拉太书 1:6"> 愚昧的加拉太人哪，谁蛊惑了你们，使你们不顺从真理呢？耶稣基督被钉十字架，已经在你们中间公开地描绘在你们眼前了。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 10:16–17; 加拉太书 3:14; 使徒行传 15:8"> 我只想从你们得知这一件事：你们领受圣灵，是因行律法，还是因听见而信呢？</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 5:4–8; 加拉太书 4:7–10; 希伯来书 7:16–19"> 你们竟这样愚昧吗？既靠圣灵开始，如今还要靠肉体成全吗？</span>
<span className="v" id="v4" data-v="4" data-xref="约翰二书 1:8; 哥林多前书 15:2; 希伯来书 10:32–39"> 你们受了这么多苦，都是徒然的吗？但愿这不是徒然的！</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 3:2; 使徒行传 14:9–10; 使徒行传 19:11–12"> 那么，那位供应圣灵给你们、又在你们中间行异能的，是因你们行律法而这样做，还是因你们听见而信呢？</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 15:6; 罗马书 4:21–22; 雅各书 2:23"> 正如亚伯拉罕“信上帝，这就算为他的义。”</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 9:7–8; 加拉太书 3:9; 加拉太书 3:26–29"> 所以你们要知道：本于信的人，才是亚伯拉罕的儿女。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 12:3; 创世记 22:18; 创世记 28:14"> 圣经预先看见上帝要使外邦人因信称义，就预先向亚伯拉罕传福音，说：“万国都要因你得福。”</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 4:16; 加拉太书 3:29; 罗马书 4:24"> 这样看来，本于信的人就和有信心的亚伯拉罕一同蒙福。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命记 27:26; 罗马书 8:7; 罗马书 3:19–20"> 凡是本于行律法的人，都在咒诅之下；因为经上记着：“凡不持续遵行律法书上所写的一切事的人，都是受咒诅的。”</span>
<span className="v" id="v11" data-v="11" data-xref="哈巴谷 2:4; 罗马书 1:17; 希伯来书 10:38"> 没有人靠律法在上帝面前称义，这是明显的，因为：“义人必因信而活。”</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 18:5; 罗马书 10:5–6; 尼希米记 9:29"> 律法并不是本于信，而是：“行这些事的人必因这些事而活。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="彼得前书 2:24; 申命记 21:23; 希伯来书 9:12"> 基督为我们成了咒诅，从律法的咒诅中救赎了我们；因为经上记着：“凡挂在木头上的，都是受咒诅的”，</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 3:28–29; 哥林多前书 12:13; 以西结 36:26–27"> 为要使亚伯拉罕的福分借着基督耶稣临到外邦人，使我们可以借着信领受所应许的圣灵。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="希伯来书 9:17; 罗马书 6:19; 罗马书 3:5"> 弟兄们，我按人的常例来说：即使只是人的约，一经确认，也没有人废除或增添。</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 17:7–8; 罗马书 4:13; 路加福音 1:55"> 这些应许是向亚伯拉罕和他的后裔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：种子">a</a></sup>说的。祂并不是说“给众后裔<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：种子（复数）">b</a></sup>”，好像是指许多人；而是指着一位说：“给你的后裔”，这后裔就是基督。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 11:39–40; 创世记 15:13; 罗马书 4:13–14"> 我的意思是：那由上帝在基督里预先确认的约，四百三十年以后才来的律法不能把它废除，以致使应许失效。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 6:12–15; 加拉太书 2:21; 罗马书 4:13–16"> 因为产业若是本于律法，就不再本于应许；但上帝是借着应许把产业赐给了亚伯拉罕。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 7:53; 罗马书 7:7–13; 希伯来书 2:2"> 那么，律法为什么存在呢？它是因过犯而添上的，直到那承受应许的后裔来到；又是借着天使，经由一位中保的手设立的。</span>
<span className="v" id="v20" data-v="20" data-xref="提摩太前书 2:5; 申命记 6:4; 约伯记 9:33"> 中保并不是只涉及一方；但上帝是一位。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="加拉太书 2:21; 罗马书 9:31; 罗马书 3:20–22"> 这样，律法是与上帝的应许相对立吗？绝不是！因为如果曾赐下能够使人得生命的律法，义就确实是本于律法了。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 11:32; 希伯来书 9:15; 加拉太书 3:23"> 但圣经把万有都圈禁在罪之下，为要使那应许可以因信耶稣基督赐给信的人。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="加拉太书 5:18; 加拉太书 3:24–25; 加拉太书 3:19"> 但在信来到以前，我们被看守在律法之下，被圈禁起来，等候那后来要启示出来的信。</span>
<span className="v" id="v24" data-v="24" data-xref="罗马书 10:4; 使徒行传 13:38–39; 罗马书 7:24–25"> 这样，律法成了我们的导师，引我们到基督那里，使我们可以因信称义。</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 6:14; 罗马书 7:4; 希伯来书 10:15–18"> 但既然信已经来到，我们就不再在导师之下了。</span>
<span className="v" id="v26" data-v="26" data-xref="以弗所书 1:5; 哥林多后书 6:18; 约翰福音 1:12–13"> 因为你们借着在基督耶稣里的信心，都是上帝的儿女。</span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 13:14; 哥林多前书 12:13; 罗马书 6:3–4"> 凡受洗归入基督的，都已经披戴基督了。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 12:12–13; 歌罗西书 3:11; 罗马书 3:29–30"> 不再分犹太人或希腊人，不再分奴隶或自由人，不再分男或女；因为你们在基督耶稣里全都成为一了。</span>
<span className="v" id="v29" data-v="29" data-xref="以弗所书 3:6; 罗马书 9:7–8; 加拉太书 3:7"> 如果你们属于基督，就也是亚伯拉罕的后裔，是按着应许作承受产业的人。</span>
</div>

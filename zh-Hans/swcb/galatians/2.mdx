<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 2:3; 使徒行传 14:12; 哥林多后书 8:23"> 后来，过了十四年，我又同巴拿巴上耶路撒冷去，也带着提多同行。</span>
<span className="v" id="v2" data-v="2" data-xref="加拉太书 2:6; 腓立比书 2:16; 帖撒罗尼迦前书 3:5"> 我上去是出于启示；我把我在外邦人中所传的福音向他们陈明，不过是私下向那些有名望的人陈明，恐怕我正在奔跑，或已经奔跑，都是徒然的。</span>
<span className="v" id="v3" data-v="3" data-xref="加拉太书 5:2–6; 使徒行传 16:3; 哥林多前书 9:20–21"> 可是，连与我同去的提多，虽是希腊人，也没有被迫受割礼。</span>
<span className="v" id="v4" data-v="4" data-xref="犹大书 1:4; 加拉太书 5:1; 加拉太书 4:3"> 这是因那些被偷偷带进来的假弟兄而起的；他们潜入，要窥探我们在基督耶稣里所有的自由，好使我们受奴役；</span>
<span className="v" id="v5" data-v="5" data-xref="加拉太书 2:14; 加拉太书 4:16; 歌罗西书 1:5"> 对于这些人，我们连一小时也没有向他们屈服让步，好使福音的真理得以继续留在你们中间。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 2:2; 使徒行传 10:34; 哥林多后书 12:11"> 至于那些被认为重要的人——无论他们是什么身份，对我都没有分别；上帝不偏待人——我说，那些有名望的人并没有给我增添什么；</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 9:15; 提摩太前书 2:7; 加拉太书 1:16"> 正相反，当他们看见我受托把福音传给未受割礼的人，正如彼得受托把福音传给受割礼的人——</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 9:15; 使徒行传 22:21; 使徒行传 2:14–41"> 因为那一位借着彼得在受割礼的人中尽使徒职分而运行，也借着我在外邦人中尽使徒职分而运行——</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 12:3; 启示录 3:12; 加拉太书 2:2"> 又看出那赐给我的恩典时，雅各、矶法和约翰，那些被认为是柱石的人，就向巴拿巴和我伸出右手，表示相交，让我们到外邦人那里去，他们到受割礼的人那里去。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 24:17; 约翰一书 3:17; 希伯来书 13:16"> 只是他们要我们记念穷人；这也正是我热心去做的。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 5:20; 哥林多后书 5:16; 使徒行传 15:1"> 可是，彼得来到安提阿的时候，我当面抵挡他，因为他是该受责备的。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 10:28; 路加福音 15:2; 使徒行传 11:2–3"> 因为在有些人从雅各那里来以前，他常和外邦人一同吃饭；可是他们一来，他就退缩，跟外邦人隔开，因为他怕那些属割礼的人。</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 15:33; 以弗所书 4:14; 希伯来书 13:9"> 其余的犹太人也跟他一同装假，以致连巴拿巴也被他们的装假带偏了。</span>
<span className="v" id="v14" data-v="14" data-xref="加拉太书 2:5; 使徒行传 10:28; 使徒行传 15:10–11"> 可是，我看见他们没有照着福音的真理正直行事，就在众人面前对彼得说：“你既是犹太人，却按外邦人的方式生活，而不按犹太人的方式生活，为什么要强迫外邦人按犹太人的方式生活呢？</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="提多书 3:3; 以弗所书 2:3; 以弗所书 2:11–12"> “我们生来是犹太人，不是外邦的罪人，</span>
<span className="v" id="v16" data-v="16" data-xref="腓立比书 3:9; 诗篇 143:2; 罗马书 9:30"> 但我们知道，人不是因律法的行为称义，而是借着对耶稣基督的信心称义；连我们也信了基督耶稣，为要因对基督的信心称义，而不是因律法的行为称义，因为凡有血肉的人，没有一个会因律法的行为称义。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 6:1–2; 约翰一书 3:8–10; 约翰一书 3:5"> 可是，如果我们寻求在基督里称义的时候，我们自己也被发现是罪人，难道基督是罪的仆役吗？绝对不是！</span>
<span className="v" id="v18" data-v="18" data-xref="加拉太书 4:9–12; 加拉太书 2:4–5; 加拉太书 2:12–16"> 因为我若重新建起我已经拆毁的，就显明自己是违犯律法的人。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 7:4; 罗马书 6:2; 帖撒罗尼迦前书 5:10"> 因为我借着律法向律法死了，为要向上帝活着。</span>
<span className="v" id="v20" data-v="20" data-xref="加拉太书 5:24; 哥林多后书 5:15; 罗马书 6:4–6"> 我已经与基督同钉十字架；现在活着的不再是我，而是基督在我里面活着。如今我在肉身中活着，是凭着信上帝的儿子而活；祂爱我，并且为我舍了自己。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 11:6; 加拉太书 3:21; 希伯来书 7:11"> 我不废弃上帝的恩典；因为如果义是借着律法而来，那么基督就是徒然死了！”</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 4:23; 加拉太书 4:29; 创世记 24:2–3"> 我说，继承人只要还是孩童，虽然是所有产业的主人，却与奴仆没有分别，</span>
<span className="v" id="v2" data-v="2"> 而是在监护人和管家的手下，直到父亲所指定的日期。</span>
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 2:20; 歌罗西书 2:8; 加拉太书 4:9"> 我们也是这样：当我们还是孩童的时候，也在世上的初级原则之下作奴仆。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 7:14; 约翰福音 1:14; 罗马书 1:3"> 但时候满足时，上帝差遣祂的儿子，由女子所生，且生在律法之下，</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 9:15; 以弗所书 1:5; 彼得前书 1:18–20"> 为要救赎那些在律法之下的人，使我们得着被收纳为儿女的名分。</span>
<span className="v" id="v6" data-v="6" data-xref="罗马书 8:15–17; 罗马书 5:5; 罗马书 8:9"> 因为你们是儿女，上帝就差遣祂儿子的灵进入你们心里，呼喊说：“阿爸，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“阿爸”是亚兰语中表示“父亲”或“爸爸”的词的希腊文拼写，用于亲近、尊敬且充满爱的称呼。">a</a></sup>父啊！”</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 8:16–17; 加拉太书 3:29–2; 加拉太书 3:26"> 这样，你不再是奴仆，而是儿子；既是儿子，就借着基督成为上帝的继承人。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 8:4; 以弗所书 2:11–12; 帖撒罗尼迦后书 1:8"> 然而，那时你们不认识上帝，给那些本质上并不是神明的作奴仆。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 8:3; 加拉太书 3:3; 罗马书 8:3"> 但如今你们既然认识了上帝，更确切地说，是被上帝所认识，为什么又转回到那些软弱贫乏的初级原则去，愿意重新给它们作奴仆呢？</span>
<span className="v" id="v10" data-v="10" data-xref="歌罗西书 2:16–17; 罗马书 14:5; 利未记 23:1–44"> 你们谨守日子、月份、节期和年份。</span>
<span className="v" id="v11" data-v="11" data-xref="帖撒罗尼迦前书 3:5; 腓立比书 2:16; 加拉太书 2:2"> 我为你们担心，恐怕我在你们身上的劳苦是徒然的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="哥林多后书 2:5; 列王纪上 22:4; 创世记 34:15"> 弟兄们，我恳求你们：要像我一样，因为我也像你们一样。你们没有亏待我，</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 2:3; 哥林多后书 12:7–10; 哥林多后书 11:30"> 但你们知道，我初次向你们传福音，是因身体软弱。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 10:40; 帖撒罗尼迦前书 2:13; 希伯来书 13:2"> 我身体上那使你们受试炼的事，你们没有轻看，也没有厌弃；反而接待我，如同接待上帝的天使，甚至如同接待基督耶稣。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="罗马书 5:2; 约翰一书 3:16–18; 歌罗西书 4:13"> 那么，你们当时所享的福在哪里呢？我可以为你们作证：如果可能，你们那时甚至会把自己的眼睛挖出来给我。</span>
<span className="v" id="v16" data-v="16" data-xref="阿摩司 5:10; 箴言 9:8; 约翰福音 8:45"> 那么，我把真理告诉你们，就成了你们的仇敌吗？</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 16:18; 哥林多后书 11:13–15; 彼得后书 2:3"> 那些人对你们热心，并不是出于好意；不，他们是想把你们隔绝出去，好叫你们反过来对他们热心。</span>
<span className="v" id="v18" data-v="18" data-xref="腓立比书 2:12; 启示录 3:19; 腓立比书 1:27"> 但在美善的事上热心，总是好的，并不只是在我与你们同在的时候才好。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="以弗所书 4:13; 罗马书 8:29; 罗马书 13:14"> 我的孩子们，我为你们再受生产之痛，直到基督在你们里面成形——</span>
<span className="v" id="v20" data-v="20" data-xref="帖撒罗尼迦前书 2:17–18; 哥林多前书 4:19–21; 帖撒罗尼迦前书 3:9"> 我倒希望现在就在你们那里，改变我的语气，因为我为你们感到困惑。</span>
</div>
<div className="bp poetry">
<span className="v" id="v21" data-v="21" data-xref="加拉太书 3:10; 加拉太书 3:23–24; 罗马书 7:5–6"> 你们这些愿意在律法之下的人，告诉我：你们不听律法吗？</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 16:15; 创世记 21:10; 创世记 21:1–2"> 因为经上记着：亚伯拉罕有两个儿子，一个是女奴所生，一个是自由妇人所生。</span>
<span className="v" id="v23" data-v="23" data-xref="希伯来书 11:11; 罗马书 9:7–8; 加拉太书 4:28–29"> 然而，从女奴所生的，是按着肉体生的；从自由妇人所生的，是借着应许生的。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 21:9–13; 希伯来书 10:15–18; 创世记 16:8"> 这些事含有寓意，因为这两个妇人就是两个约。一个约是出于西奈山，生下儿女使他们为奴，这就是夏甲。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 19:44; 使徒行传 1:11; 加拉太书 1:17"> 因为这夏甲就是阿拉伯境内的西奈山，与现今的耶路撒冷相对应；因为她和她的儿女一同为奴。</span>
<span className="v" id="v26" data-v="26" data-xref="希伯来书 12:22; 腓立比书 3:20; 弥迦书 4:1–2"> 但在上的耶路撒冷是自由的；她是我们众人的母亲。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 54:1–5; 诗篇 113:9; 路得记 4:14–16"> 因为经上记着：<br /><span className="pl pl-1">“不能生育、没有生产的啊，要欢喜！</span><br /><span className="pl pl-2">没有经历产痛的啊，要放声欢呼！</span><br /><span className="pl pl-2">因为荒凉的妇人，比有丈夫的妇人儿女更多。”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="加拉太书 4:23; 罗马书 9:8–9; 罗马书 4:13–18"> 弟兄们，如今我们像以撒一样，是应许的儿女。</span>
<span className="v" id="v29" data-v="29" data-xref="创世记 21:9; 罗马书 8:13; 加拉太书 5:11"> 可是，正如当时那按着肉体生的逼迫那按着圣灵生的，现在也是这样。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 21:10–12; 约翰福音 8:35; 罗马书 8:15–17"> 然而，经上怎么说？“把女奴和她的儿子赶出去，因为女奴的儿子绝不会与自由妇人的儿子一同承受产业。”</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 8:36; 约翰福音 1:12–13; 加拉太书 5:1"> 所以，弟兄们，我们不是女奴的儿女，而是自由妇人的儿女。</span>
</div>
</div>

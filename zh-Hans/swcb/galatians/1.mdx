<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="加拉太书 1:11–12; 哥林多前书 1:1; 罗马书 1:1"> 保罗，一个使徒——不是出于人，也不是借着人，而是借着耶稣基督<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“基督”的意思是“受膏者”。">a</a></sup>和使祂从死人中复活的父上帝——</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 16:1; 腓立比书 4:21; 使徒行传 16:5–6"> 以及所有和我在一起的弟兄<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这里译为“弟兄”的词，在此处以及上下文允许的地方，也可正确译为“弟兄姊妹”或“兄弟姐妹”。">b</a></sup>，写信给加拉太的各教会：</span>
<span className="v" id="v3" data-v="3" data-xref="约翰二书 1:3; 哥林多后书 13:14; 罗马书 1:7–15"> 愿恩典和平安从父上帝和我们的主耶稣基督临到你们。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 20:28; 罗马书 4:25; 加拉太书 2:20"> 祂为我们的罪舍了自己，为要救我们脱离现今这邪恶的世代，照着我们的上帝和父的旨意——</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 11:36; 犹大书 1:25; 诗篇 72:19"> 愿荣耀归于祂，直到永永远远。阿们。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 11:4; 加拉太书 5:7–8; 以赛亚书 29:13"> 我惊讶你们这么快就离弃那位在基督的恩典中呼召你们的，转向另一个“福音”，</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 15:24; 罗马书 16:17–18; 加拉太书 5:10"> 其实并没有另一个“福音”。不过有些人搅扰你们，想要歪曲基督的福音。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 11:13–14; 加拉太书 1:9; 启示录 22:18–19"> 但即使是我们，或是从天上来的天使，若把任何不同于我们传给你们的“福音”传给你们，愿他受咒诅。</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 16:17; 箴言 30:6; 申命记 4:2"> 正如我们以前说过，我现在再说：若有人把任何不同于你们所领受的“福音”传给你们，愿他受咒诅。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="帖撒罗尼迦前书 2:4; 使徒行传 5:29; 以弗所书 6:6"> 我现在是在求人的赞许，还是求上帝的赞许呢？我是在竭力讨人的喜悦吗？如果我仍然讨人的喜悦，就不是基督的仆人了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="加拉太书 1:1; 哥林多前书 2:9–10; 哥林多前书 11:23"> 弟兄们，关于我所传的福音，我要你们知道：它不是出于人。</span>
<span className="v" id="v12" data-v="12" data-xref="加拉太书 1:16; 哥林多前书 2:10; 加拉太书 1:1"> 因为我不是从人领受的，也不是受人教导的，而是借着耶稣基督的启示得来的。</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 8:3; 哥林多前书 15:9; 使徒行传 22:3–5"> 你们听说过我从前在犹太教中的行事为人：我怎样极力迫害上帝的教会，并摧残它。</span>
<span className="v" id="v14" data-v="14" data-xref="歌罗西书 2:8; 使徒行传 26:5; 腓立比书 3:4–6"> 我在犹太教中超越了我本族许多同龄人，对我祖宗的传统格外热心。</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 1:5; 以赛亚书 49:5; 以赛亚书 49:1"> 然而，当那位从我母腹中把我分别出来、又借着祂的恩典呼召我的上帝乐意</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 16:17; 以弗所书 3:5–10; 以弗所书 6:12"> 将祂的儿子启示在我里面，好让我在外邦人中传扬祂的时候，我没有立刻同血肉之人商议，</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 9:20–25; 哥林多后书 11:32–33; 加拉太书 1:18"> 也没有上耶路撒冷去见那些在我以前作使徒的人，而是去了阿拉伯，随后又回到大马士革。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行传 9:22–23; 使徒行传 9:26–29; 使徒行传 22:17–18"> 三年后，我上耶路撒冷去拜访彼得，和他住了十五天。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 13:55; 马可福音 6:3; 马太福音 12:46"> 至于其他使徒，除了主的兄弟雅各，我没有见过别人。</span>
<span className="v" id="v20" data-v="20" data-xref="罗马书 9:1; 哥林多后书 11:31; 哥林多后书 11:10–11"> 至于我写给你们的这些事，看哪，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“看哪”来自“ἰδοὺ”，意思是看、留意、观察、看见或凝视。它常用作感叹语。">c</a></sup>我在上帝面前说，我没有说谎。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 15:41; 使徒行传 9:30; 使徒行传 6:9"> 后来我到了叙利亚和基利家的地区。</span>
<span className="v" id="v22" data-v="22" data-xref="帖撒罗尼迦前书 2:14; 罗马书 16:7; 帖撒罗尼迦后书 1:1"> 那时，犹太地区在基督里的各教会还没有见过我的面，</span>
<span className="v" id="v23" data-v="23" data-xref="哥林多前书 15:8–10; 使徒行传 9:13; 提摩太前书 1:13–16"> 只是听说：“从前迫害我们的那个人，现在传扬他从前试图摧毁的信仰。”</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 9:8; 使徒行传 11:18; 路加福音 15:10"> 他们就因我而荣耀上帝。</span>
</div>
</div>

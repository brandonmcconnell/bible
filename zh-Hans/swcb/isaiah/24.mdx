<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="那鸿书 2:10; 以赛亚书 2:19; 以赛亚书 42:15"> 看哪，耶和华使大地空虚，使它荒废，将它翻转，并驱散其中的居民。</span>
<span className="v" id="v2" data-v="2" data-xref="何西阿 4:9; 耶利米哀歌 5:12–14; 以西结 7:12–13"> 那时，百姓怎样，祭司也怎样；仆人怎样，主人也怎样；婢女怎样，主母也怎样；买主怎样，卖主也怎样；债主怎样，欠债的也怎样；收利息的怎样，付利息的也怎样。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 24:1; 以赛亚书 6:11; 申命记 29:23"> 大地必全然空虚，全然荒废；因为耶和华已经说了这话。</span>
<span className="v" id="v4" data-v="4" data-xref="何西阿 4:3; 以赛亚书 33:9; 以赛亚书 3:26"> 大地悲哀衰残，世界衰弱枯萎，地上尊贵的人也衰弱。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 13:20; 罗马书 8:20–21; 但以理 7:25"> 大地也在其居民之下被玷污，因为他们违背了律法，违反了条例，破坏了永约。</span>
<span className="v" id="v6" data-v="6" data-xref="玛拉基书 4:1; 马太福音 7:14; 撒迦利亚书 5:3–4"> 因此，咒诅吞噬了大地，住在其中的人被定为有罪。因此，地上的居民被焚烧，剩下的人稀少。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 16:10; 约珥 1:10–12; 以赛亚书 16:8"> 新酒悲哀，葡萄树衰弱，所有心中欢乐的人都叹息。</span>
<span className="v" id="v8" data-v="8" data-xref="何西阿 2:11; 启示录 18:22; 以西结 26:13"> 击鼓的欢笑止息，欢乐之人的喧声停止，弹琴的喜乐止息。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 5:22; 传道书 9:7; 以赛亚书 5:20"> 他们不再唱歌饮酒；烈酒在饮用的人口中必发苦。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 18:2; 启示录 17:5–6; 以赛亚书 24:12"> 混乱的城被拆毁；家家关门，无人能进去。</span>
<span className="v" id="v11" data-v="11" data-xref="何西阿 7:14; 以赛亚书 24:7–9; 耶利米书 48:33"> 街上因酒而有哀号；一切喜乐都变为昏暗，地上的欢笑消逝了。</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 9:11; 弥迦书 1:12; 耶利米哀歌 5:18"> 城中只剩荒凉，城门被毁坏击碎。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 1:9; 以西结 6:8–11; 以西结 11:16–20"> 在大地之中，在万民之间，情形必像打过的橄榄树，又像摘完葡萄后所剩的零星果子。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 40:9; 耶利米书 31:12; 以赛亚书 54:1"> 这些人必扬声欢呼，因耶和华的威严而高声呼喊；他们从海那边高声呼喊。</span>
<span className="v" id="v15" data-v="15" data-xref="玛拉基书 1:11; 以赛亚书 42:4; 以赛亚书 60:9"> 因此，你们要在东方荣耀耶和华，在海岛上荣耀耶和华——以色列上帝的名！</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 21:2; 耶利米书 5:11; 以赛亚书 33:1"> 我们从地极听见歌声：“荣耀归于义者！”<br />但我说：“我消瘦了！我消瘦了！我有祸了！”诡诈的人行事诡诈；是的，诡诈的人大行诡诈。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 48:43–44; 列王纪上 19:17; 利未记 26:21–22"> 住在地上的人哪，恐惧、陷坑和网罗都临到你。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 7:11; 诗篇 18:7; 约书亚记 10:10–11"> 那逃避恐惧之声的，必掉进陷坑；从陷坑中爬上来的，必被网罗捉住；因为高处的窗户都打开了，大地的根基也震动。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 34:4–10; 申命记 11:6; 启示录 20:11"> 大地全然破裂，大地崩裂分开，大地剧烈震动。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 19:14; 何西阿 4:1–5; 但以理 11:19"> 大地必像醉汉摇摇晃晃，又像吊床来回摇摆；它的悖逆重重压在它身上，它必倒下，不再起来。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="诗篇 76:12; 以赛亚书 34:2–17; 撒迦利亚书 14:12–19"> 到那日，耶和华必在高处惩罚高处的众军，在地上惩罚地上的君王。</span>
<span className="v" id="v22" data-v="22" data-xref="撒迦利亚书 9:11; 以赛亚书 42:22; 耶利米书 38:6–13"> 他们必被聚集，像囚犯被聚在坑中，又被关在监牢里；过了许多日子，他们必受惩治。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 60:19; 启示录 21:23; 以赛亚书 13:10"> 那时，月亮必蒙羞，太阳必惭愧；因为万军之耶和华必在锡安山和耶路撒冷作王；荣耀必在祂的长老面前。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="以赛亚书 38:1–8; 历代志下 32:24; 列王纪下 20:1–11"> 那些日子，希西家病得要死。亚摩斯的儿子以赛亚先知来见他，对他说：“耶和华<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="英文中全大写的 LORD 或 GOD，除非另有说明为短形式 יה Yah，均来自希伯来文 יהוה Yahweh。">a</a></sup>如此说：‘你要安排好你的家，因为你必死，不能存活。’”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="马太福音 6:6; 诗篇 91:15; 列王纪上 8:30"> 于是希西家转脸朝墙，向耶和华祷告，</span>
<span className="v" id="v3" data-v="3" data-xref="希伯来书 5:7; 诗篇 18:20–27; 希伯来书 6:10"> 说：“耶和华啊，求你记念我怎样以诚实和完全的心行在你面前，又做了你眼中看为善的事。”于是希西家痛哭。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 耶和华的话临到以赛亚，说：</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 34:5–6; 约翰一书 5:14–15; 启示录 7:17"> “你去告诉希西家：‘耶和华——你祖大卫的上帝——如此说：“我听见了你的祷告，看见了你的眼泪。看哪，我要在你的寿数上加添十五年。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 37:35; 以赛亚书 31:4–5; 以赛亚书 12:6"> 我要救你和这城脱离亚述王的手，并且我要保护这城。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 6:37–39; 以赛亚书 37:30; 以赛亚书 7:11–14"> 这要作耶和华给你的兆头，表明耶和华必成就祂所说的这事。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪下 20:9–11; 约书亚记 10:12–14; 马太福音 16:1"> 看哪，亚哈斯日晷上随着太阳下移的影子，我要使它往后退十级。”’”于是，太阳在日晷上所下移的影子退了十级。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="诗篇 18:1; 出埃及记 15:1–21; 约伯记 5:18"> 犹大王希西家患病又从病中康复以后所写的文字：</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 102:24; 哥林多后书 1:9; 诗篇 107:18"> <span className="pl pl-1">我说：“我在生命的中途要进入阴间</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="阴间是死人的所在。">b</a></sup><br /><span className="pl pl-1">的门；</span><br /><span className="pl pl-2">我剩余的年岁被夺去了。”</span></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 27:13; 诗篇 116:8–9; 诗篇 31:22"> <span className="pl pl-1">我说：“我必不得见耶和华，</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="希伯来文：יה Yah">c</a></sup><br /><span className="pl pl-2">在活人之地见不到耶和华；</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="希伯来文：יה Yah">d</a></sup><br /><span className="pl pl-2">我在世上的居民中再也见不到人。</span></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 73:14; 哥林多后书 5:1; 希伯来书 1:12"> <span className="pl pl-1">我的住处被拆除，</span><br /><span className="pl pl-2">像牧人的帐棚一样从我这里被卷走。</span><br /><span className="pl pl-1">我像织布工卷起我的生命；</span><br /><span className="pl pl-2">祂要把我从织机上剪断。</span><br /><span className="pl pl-2">从白昼到黑夜，你要使我完结。</span></span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 51:8; 但以理 6:24; 诗篇 50:22"> <span className="pl pl-1">我耐心等候直到早晨；</span><br /><span className="pl pl-2">祂像狮子折断我所有的骨头。</span><br /><span className="pl pl-2">从白昼到黑夜，你要使我完结。</span></span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 59:11; 诗篇 69:3; 诗篇 123:1–4"> <span className="pl pl-1">我像燕子或鹤啾啾鸣叫，</span><br /><span className="pl pl-2">又像鸽子哀鸣。</span><br /><span className="pl pl-2">我的眼睛仰望到衰弱。</span><br /><span className="pl pl-2">主啊，我受欺压；</span><br /><span className="pl pl-2">求你为我作保。”</span></span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 21:27; 约伯记 7:11; 约伯记 10:1"> <span className="pl pl-1">我还能说什么呢？</span><br /><span className="pl pl-2">祂既对我说了，也亲自成就了。</span><br /><span className="pl pl-2">因我灵魂的痛苦，我一生都要谨慎而行。</span></span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 12:10–11; 哥林多前书 11:32; 诗篇 119:25"> <span className="pl pl-1">主啊，人靠这些事而活；</span><br /><span className="pl pl-2">我的灵也在这一切事上得生命。</span><br /><span className="pl pl-2">你使我复原，使我存活。</span></span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 43:25; 弥迦书 7:18–19; 约拿 2:6"> <span className="pl pl-1">看哪，为了平安，我竟遭遇极大的痛苦；</span><br /><span className="pl pl-2">但你因爱我的灵魂，救它脱离败坏的坑；</span><br /><span className="pl pl-2">因为你把我一切的罪都抛在你的背后。</span></span>
<span className="v" id="v18" data-v="18" data-xref="传道书 9:10; 诗篇 30:9; 诗篇 6:5"> <span className="pl pl-1">因为阴间</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="阴间是死人的所在。">e</a></sup><br /><span className="pl pl-1">不能赞美你；</span><br /><span className="pl pl-2">死亡不能颂扬你。</span><br /><span className="pl pl-1">下到坑中的人不能盼望你的信实。</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="申命记 6:7; 诗篇 119:175; 诗篇 78:3–6"> <span className="pl pl-1">活着的人，活着的人，他必赞美你，像我今日一样。</span><br /><span className="pl pl-2">父亲必使儿女知道你的信实。</span></span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 116:2; 诗篇 150:4; 诗篇 145:2"> <span className="pl pl-1">耶和华必拯救我。</span><br /><span className="pl pl-2">因此，我们一生的日子都要在耶和华的殿中，用弦乐器唱我的诗歌。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="列王纪下 20:7–8; 马可福音 7:33; 约翰福音 9:6"> 以赛亚曾说：“让他们取一块无花果饼来，贴在疮上作药膏，他就会痊愈。”</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 118:18–19; 列王纪下 20:8; 约翰福音 5:14"> 希西家也曾说：“我能上耶和华的殿，有什么兆头呢？”</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 32:1; 列王纪下 18:13; 列王纪下 18:17"> 希西家王十四年，亚述王西拿基立上来攻击犹大所有坚固城，并且攻取了。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志下 32:9–23; 以赛亚书 7:3; 列王纪下 18:17–37"> 亚述王从拉吉派拉伯沙基率领大军到耶路撒冷，去见希西家王。他站在漂布者田间大路旁、上池的水沟那里。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 8:16–17; 以赛亚书 22:15–21; 撒母耳记下 20:24–25"> 于是管理王宫的希勒家的儿子以利亚敬、书记舍伯那和亚萨的儿子史官约亚，出来见他。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 18:19–37; 犹大书 1:16; 箴言 16:18"> 拉伯沙基对他们说：“现在你们要告诉希西家：‘大王，亚述王这样说：“你所倚靠的这信心是什么？</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 18:7; 耶利米书 52:3; 箴言 21:30–31"> 我说，你作战的谋略和力量不过是空话。现在你倚靠谁，竟背叛我呢？</span>
<span className="v" id="v6" data-v="6" data-xref="以西结 29:6–7; 耶利米书 37:5–8; 列王纪下 18:21"> 看哪，你倚靠埃及，就是倚靠这根压伤的芦苇杖；人若靠在它上面，它就会刺进他的手，把手扎穿。埃及王法老对于一切倚靠他的人也是这样。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 18:4–5; 诗篇 42:10–11; 诗篇 42:5"> 但如果你对我说：‘我们倚靠耶和华我们的上帝’，那不正是希西家除去祂的丘坛和祭坛，并且对犹大和耶路撒冷说：‘你们要在这坛前敬拜’的那一位吗？”</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 17:40–43; 列王纪上 20:10; 尼希米记 4:2–5"> 现在，请你与我主亚述王打个赌吧；如果你这边能给它们配上骑兵，我就给你两千匹马。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 10:8; 以赛亚书 30:16–17; 以赛亚书 36:6"> 这样，你怎能击退我主最小仆人中的一个军长呢？你竟倚靠埃及，要战车和骑兵吗？</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪下 18:25; 以赛亚书 10:5–7; 列王纪上 13:18"> 现在我上来攻击这地，要毁灭它，难道没有耶和华的意思吗？耶和华对我说：‘上去攻击这地，毁灭它。’”’”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以斯拉记 4:7; 但以理 2:4; 列王纪下 18:26–27"> 以利亚敬、舍伯那和约亚对拉伯沙基说：“请你用亚兰语对你的仆人说话，因为我们听得懂。不要用犹大人的语言对我们说话，免得城墙上的百姓听见。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王纪下 18:27; 利未记 26:29; 耶利米哀歌 4:9–10"> 但拉伯沙基说：“我主派我来，难道只是对你的主和你说这些话，不也是对那些坐在城墙上、将要与你们一同吃自己粪、喝自己尿的人说吗？”</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 32:18; 诗篇 73:8–9; 列王纪下 18:28–32"> 于是拉伯沙基站着，用犹大人的语言大声呼喊说：“你们要听大王，亚述王的话！</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦后书 2:4; 启示录 13:5–6; 但以理 6:20"> 王这样说：‘不要让希西家欺骗你们，因为他不能救你们。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 37:23–24; 马太福音 27:43; 诗篇 71:9–11"> 不要让希西家使你们倚靠耶和华，说：“耶和华必定拯救我们；这城必不交在亚述王手中。”’</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 4:25; 撒迦利亚书 3:10; 弥迦书 4:4"> 不要听希西家的话，因为亚述王这样说：‘你们要与我讲和，出来归我；你们各人可以吃自己葡萄树上的果子，各人吃自己无花果树上的果子，各人喝自己蓄水池里的水；</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 18:32; 申命记 8:7–9; 约伯记 20:17"> 等我来，把你们带到一个像你们本地一样的地方，就是有谷物和新酒之地，有粮食和葡萄园之地。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 37:17–18; 以赛亚书 36:15; 以赛亚书 37:10"> 你们要谨防希西家劝诱你们说：“耶和华必拯救我们。”列国的神有哪一个曾救自己的土地脱离亚述王的手呢？</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 10:9–11; 耶利米书 49:23; 撒母耳记下 8:9"> 哈马和亚珥拔的神在哪里？西法瓦音的神在哪里？他们曾救撒玛利亚脱离我的手吗？</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 50:21; 历代志下 32:19; 以赛亚书 37:23–29"> 这些国家所有的神中，有谁曾救自己的国家脱离我的手，以致耶和华能救耶路撒冷脱离我的手呢？’”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="箴言 26:4; 诗篇 38:13–15; 马太福音 7:6"> 但他们沉默不语，一句话也没有回答，因为王的命令是：“不要回答他。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 36:3; 以赛亚书 33:7; 马太福音 26:65"> 于是管理王宫的希勒家的儿子以利亚敬、书记舍伯那和亚萨的儿子史官约亚，都撕裂衣服，来到希西家那里，把拉伯沙基的话告诉了他。</span>
</div>
</div>

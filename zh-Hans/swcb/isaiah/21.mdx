<span className="v" id="v2" data-v="2" data-xref="以赛亚书 33:1; 耶利米书 49:34; 诗篇 60:3"> 有严厉的异象向我宣告：诡诈的人行诡诈，毁灭者施行毁灭。以拦哪，上去吧！围攻吧！玛代一切的叹息，我已经使它止息。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 13:8; 诗篇 48:6; 以赛亚书 26:17"> 因此，我的腰间充满痛苦；疼痛抓住了我，像产妇的疼痛一样。我痛得不能听，惊惶得不能看。</span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 21:34–36; 撒母耳记上 25:36–38; 但以理 5:1"> 我的心发颤；恐怖使我惊惧。我所渴望的黄昏，竟变成了我的战栗。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 51:11; 耶利米书 51:57; 耶利米书 51:39"> 他们摆设筵席，设立守望；他们吃，他们喝。首领们哪，起来，用油抹盾牌！</span>
<span className="v" id="v6" data-v="6" data-xref="以西结 33:2–7; 以西结 3:17; 哈巴谷 2:1–2"> 因为主对我这样说：“去，设立守望者，让他报告所看见的。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 21:9; 以赛亚书 37:24; 希伯来书 2:1"> 他若看见车队，两两并行的骑兵，一队驴，一队骆驼，就要侧耳细听，极其留心。”</span>
<span className="v" id="v8" data-v="8" data-xref="哈巴谷 2:1–2; 以赛亚书 56:10; 彼得前书 5:8"> 他像狮子一样喊叫：“主啊，我白日不断站在守望楼上，整夜也守在我的岗位上。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 18:2; 启示录 14:8; 耶利米书 51:8"> 看哪，这里来了一队人，两两并行的骑兵。”他回答说：“巴比伦倾倒了！倾倒了！她诸神一切雕刻的偶像都被打碎在地。</span>
</div>
<div className="bp">

</div>

<span className="v" id="v12" data-v="12" data-xref="使徒行传 17:30–32; 使徒行传 2:37–38; 以西结 18:30–32"> 守望者说：“早晨将到，黑夜也来。你们若要询问，就询问吧；再回来吧。”</span>

<span className="v" id="v13" data-v="13" data-xref="耶利米书 25:23–24; 历代志上 1:32; 以西结 27:15"> 关于阿拉伯的默示。<br />底但的商队啊，你们必在阿拉伯的树丛中住宿。</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 25:15; 约伯记 6:19; 罗马书 12:20"> 提玛地的居民拿水给口渴的人，带着饼迎接逃亡的人。</span>
<span className="v" id="v15" data-v="15" data-xref="约伯记 6:19–20; 以赛亚书 13:14"> 因为他们逃避刀剑，逃避拔出的刀、张开的弓，以及激烈的战事。</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 120:5; 以赛亚书 60:7; 以赛亚书 16:14"> 因为主对我这样说：“一年之内，照雇工按契约计算的年数，基达一切的荣耀都必衰败；</span>
<span className="v" id="v17" data-v="17" data-xref="撒迦利亚书 1:6; 民数记 23:19; 马太福音 24:35"> 基达子孙中弓箭手的余数，就是勇士，必所剩无几；因为耶和华——以色列的上帝已经说了。”</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 11:52; 弥迦书 3:1–4; 马太福音 23:23"> 那些制定不义法令的人有祸了！那些书写压迫性法令的文士有祸了！</span>
<span className="v" id="v2" data-v="2" data-xref="玛拉基书 3:5; 以赛亚书 3:14; 以赛亚书 29:21"> 他们剥夺穷乏人的公正，抢去我百姓中贫寒人的权利，使寡妇成为他们的掠物，使孤儿成为他们的猎物！</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿 9:7; 路加福音 19:44; 约伯记 31:14"> 到审判的日子，从远方临到的荒凉来到时，你们要怎么办呢？你们要逃往谁那里求助呢？你们要把自己的财富留在哪里呢？</span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 5:25; 以赛亚书 9:12; 耶利米书 37:10"> 他们只得在俘虏之下屈身，<br /><span className="pl pl-2">倒在被杀的人之下。</span><br /><span className="pl pl-1">尽管如此，祂的怒气仍未转消，</span><br /><span className="pl pl-2">祂的手仍然伸出。</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="耶利米书 51:20–24; 以赛亚书 14:25; 以赛亚书 30:30"> 亚述啊，有祸了！他是我怒气的棍；他手中的杖，是我的愤怒！</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 9:17; 耶利米书 25:9; 撒迦利亚书 10:5"> 我要差他攻击亵渎的国家，又要吩咐他攻击惹我发怒的百姓，夺取掠物，抢取猎物，把他们践踏如街上的泥土。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 50:20; 弥迦书 4:11–12; 使徒行传 2:23"> 然而，他的意思并不是这样，他心里也不这样想；他心里只想毁灭，剪除不少国家。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪下 18:24; 列王纪下 19:10; 以西结 26:7"> 因为他说：“我的众首领不都是王吗？</span>
<span className="v" id="v9" data-v="9" data-xref="历代志下 35:20; 列王纪下 16:9; 创世记 10:10"> 迦勒挪岂不像迦基米施吗？哈马岂不像亚珥拔吗？撒马利亚岂不像大马士革吗？”</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 10:14; 列王纪下 19:17–19; 列王纪下 18:33–35"> 我的手怎样取得偶像之国，那些国家的雕刻偶像胜过耶路撒冷和撒马利亚的偶像，</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 37:10–13; 以赛亚书 2:8; 以赛亚书 36:19–20"> 我岂不照我对撒马利亚和她的偶像所做的，也照样对耶路撒冷和她的偶像做吗？</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王纪下 19:31; 以赛亚书 65:7; 耶利米书 50:18"> 因此，主在锡安山和耶路撒冷完成祂一切工作的时候，我必惩罚亚述王傲慢之心所结的果子，和他高傲眼神中的狂妄。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 8:17; 但以理 4:30; 以西结 26:2"> 因为他说：“我靠自己手的力量成就了这事，也靠我的智慧，因为我有聪明。我挪移了各民族的疆界，抢夺了他们的财宝。我像勇士一样使他们的统治者降卑。</span>
<span className="v" id="v14" data-v="14" data-xref="约伯记 31:25; 箴言 21:6–7; 那鸿书 2:9–1"> 我的手取得各民族的财富，如同取得鸟窝；我收集全地，如同人收集被遗弃的蛋。没有谁拍动翅膀，张开嘴，或鸣叫。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="罗马书 9:20–21; 以赛亚书 45:9; 以赛亚书 10:5"> 斧头岂可向用斧砍伐的人夸耀呢？锯子岂可向用锯的人自高呢？这就像棍竟要举起那举棍的人，又像杖竟要举起那不是木头的人。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 32:21; 使徒行传 12:23; 诗篇 106:15"> 因此，主——万军之耶和华<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="英文以全大写字母呈现时，“LORD”或“GOD”是上帝专有名的译法（希伯来文“יהוה”，通常读作“雅威”）。">a</a></sup>，必在他的肥壮者中降下消瘦；在他的荣耀之下，必有焚烧被点燃，如火焚烧一样。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 27:4; 民数记 11:1–3; 以赛亚书 37:23"> 以色列的光必成为火，祂的圣者必成为火焰；一日之间就焚烧吞灭他的荆棘和蒺藜。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 19:23; 以赛亚书 10:33–34; 以赛亚书 9:18"> 祂必耗尽他树林和肥田的荣耀，连灵魂带身体都耗尽；这必像旗手昏倒一样。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 21:17; 以赛亚书 37:36"> 他树林中剩下的树必稀少，连孩子都能写下它们的数目。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 37:31–32; 以赛亚书 50:10; 以赛亚书 1:9"> 到那日，以色列的余民，就是雅各家逃脱的人，必不再倚靠那击打他们的，却要真实地倚靠耶和华<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="英文以全大写字母呈现时，“LORD”或“GOD”是上帝专有名的译法（希伯来文“יהוה”，通常读作“雅威”）。">b</a></sup>——以色列的圣者。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 9:6; 哥林多后书 3:14–16; 何西阿 7:10"> 余民必归回，就是雅各的余民，归向大能的上帝。</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 9:27–28; 以赛亚书 6:13; 启示录 20:8"> 以色列啊，你的百姓虽多如海沙，其中只有余民归回。毁灭已经定下，公义满溢其中。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 28:22; 以赛亚书 24:1–23; 罗马书 9:28"> 因为主——万军之耶和华<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="英文以全大写字母呈现时，“LORD”或“GOD”是上帝专有名的译法（希伯来文“יהוה”，通常读作“雅威”）。">c</a></sup>，必在全地施行所定的彻底毁灭。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="希伯来书 12:22–24; 以赛亚书 37:6; 以赛亚书 61:3"> 所以，主——万军之耶和华如此说：“住在锡安的我的百姓啊，不要害怕亚述人；他虽用棍击打你，又照埃及所做的举杖攻击你，</span>
<span className="v" id="v25" data-v="25" data-xref="但以理 11:36; 列王纪下 19:35; 希伯来书 10:37"> 但再过极短的时候，对你的愤怒就要止息，我的怒气要转向他的毁灭。”</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 9:4; 士师记 7:25; 列王纪下 19:35"> 万军之耶和华必兴起鞭子攻击他，像在俄立磐石击杀米甸人一样。祂的杖必伸在海上，祂必像对付埃及那样举起杖。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 9:4; 路加福音 4:18; 以赛亚书 14:25"> 到那日，他的重担必从你的肩头卸下，他的轭必从你的颈项除去；那轭必因膏油的缘故被毁坏。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 14:2; 撒母耳记上 13:2; 撒母耳记上 13:5"> 他来到亚叶，经过米矶仑，在密抹存放他的辎重。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记上 13:23; 撒母耳记上 7:17; 约书亚记 21:17"> 他们越过隘口，在迦巴住宿。拉玛战栗；扫罗的基比亚逃跑了。</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 25:44; 耶利米书 1:1; 约书亚记 21:18"> 迦琳的女子啊，要高声呼喊！莱煞啊，要留心听！可怜的亚拿突啊！</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 15:31"> 玛得米那逃跑了；基柄的居民逃往安全之处。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 21:1; 以赛亚书 37:22; 以赛亚书 19:16"> 就在今日，他要在挪伯停留；他向锡安女子的山，就是耶路撒冷的冈陵，挥动他的手。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="阿摩司 2:9; 但以理 4:37; 以赛亚书 37:38"> 看哪，主——万军之耶和华，必以可畏的力量砍下枝条；高大的必被砍倒，高耸的必被降卑。</span>
<span className="v" id="v34" data-v="34" data-xref="以赛亚书 37:24; 但以理 4:23; 耶利米书 48:2"> 祂必用铁器砍下森林的密丛；黎巴嫩必被大能者砍倒。</span>
</div>
</div>

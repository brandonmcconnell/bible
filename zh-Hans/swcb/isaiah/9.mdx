<div className="bp poetry">

<span className="v" id="v3" data-v="3" data-xref="以赛亚书 35:10; 诗篇 119:162; 以赛亚书 26:15"> <span className="pl pl-1">你使这国人数增多。</span><br /><span className="pl pl-2">你加增了他们的喜乐。</span><br />他们在你面前欢喜，像收割时的欢喜，又像人分掠物时的快乐。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 30:8; 以赛亚书 14:25; 以赛亚书 10:26–27"> 因为他们所负重担的轭、肩头上的杖、欺压者的棍，你都折断了，像在米甸的日子一样。</span>
<span className="v" id="v5" data-v="5" data-xref="帖撒罗尼迦后书 1:8; 诗篇 46:9; 以赛亚书 30:33"> 因为战士在喧嚣战斗中的一切盔甲，以及卷在血中的衣服，都必被焚烧，作火的燃料。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 2:11; 马太福音 28:18; 耶利米书 23:5–6"> 因为有一个孩子为我们而生，有一个儿子赐给我们；政权必担在他的肩上。他的名必称为奇妙策士、大能的上帝、永在的父、和平之君。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 1:32–33; 但以理 2:44; 但以理 7:14"> 他的政权扩展与和平必无穷无尽。他必在大卫的宝座上治理他的国，从今直到永远，以公平和公义建立它，坚固它。万军之耶和华的热心必成就这事。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 8:4–8; 撒迦利亚书 1:6; 撒迦利亚书 5:1–4"> 主向雅各发出一句话，<br /><span className="pl pl-2">它临到以色列。</span></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 46:12; 彼得前书 5:5; 以西结 7:27"> <span className="pl pl-1">所有百姓都将知道，</span><br /><span className="pl pl-2">就是以法莲和撒玛利亚的居民；他们凭骄傲和心中的狂妄说：</span></span>

<span className="v" id="v11" data-v="11" data-xref="以赛亚书 8:4–7; 以赛亚书 17:1–5; 以赛亚书 7:8"> <span className="pl pl-1">因此，耶和华必高举利汛的敌人来攻击他，</span><br /><span className="pl pl-2">并且激动他的仇敌；</span><br /></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 5:25; 历代志下 28:18; 诗篇 79:7"> <span className="pl pl-2">前面有亚兰人，</span><br /><span className="pl pl-2">后面有非利士人；</span><br /><span className="pl pl-2">他们张口吞吃以色列。</span><br /><span className="pl pl-1">虽然如此，祂的怒气还未转消，</span><br /><span className="pl pl-2">祂的手仍然伸出。</span></span>
</div>
<div className="bp poetry">

<span className="v" id="v14" data-v="14" data-xref="以赛亚书 19:15; 启示录 18:8; 何西阿 1:6"> <span className="pl pl-1">因此，耶和华要在一日之间从以色列中剪除头与尾、</span><br /><span className="pl pl-2">棕枝与芦苇。</span></span>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="阿摩司 4:4–5; 撒母耳记下 5:9; 弥迦书 6:6–7"> 亚利伊勒有祸了！亚利伊勒，大卫安营的城！年复一年吧；让节期循环吧；</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 5:25–30; 以赛亚书 3:26; 以赛亚书 10:32"> 那时我必使亚利伊勒困苦，那里必有悲伤和哀号；她对我必像祭坛的炉膛。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“亚利伊勒”。">a</a></sup></span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 19:43–44; 以西结 21:22; 列王纪下 25:1–4"> 我必四面安营攻击你，必用驻扎的军兵围困你，又筑起攻城工事攻击你。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 8:19; 诗篇 44:25; 以赛亚书 3:8"> 你必被降低，从地中说话；你的言语必从尘土中咕哝出来。你的声音必像交鬼者的声音，从地中发出；你的言语必从尘土中低语。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="帖撒罗尼迦前书 5:3; 以赛亚书 17:13–14; 以赛亚书 37:36"> 但你众多的仇敌必像细尘，众多的强暴人必像被吹散的糠秕。是的，这事必在一瞬间，突然临到。</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 13:8; 撒母耳记上 2:10; 马太福音 24:7"> 万军之耶和华必用雷轰、地震、大声响、旋风、暴风和吞灭之火焰来眷顾她。</span>
<span className="v" id="v7" data-v="7" data-xref="约伯记 20:8; 弥迦书 4:11–12; 撒迦利亚书 12:9"> 列国中一切攻击亚利伊勒的群众，就是一切攻击她和她堡垒、使她困苦的人，必像梦，像夜间的异象。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 44:12; 诗篇 73:20; 以赛亚书 10:7–16"> 这必像饥饿的人做梦，看哪，他在吃；但他醒来，饥饿仍未满足；又像口渴的人做梦，看哪，他在喝；但他醒来，看哪，他仍然疲乏，还是口渴。列国中一切攻击锡安山的群众也必这样。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 51:21–22; 以赛亚书 19:14; 启示录 17:6"> 你们停顿惊奇吧！你们使自己眼瞎，就眼瞎吧！他们醉了，却不是因酒；他们摇晃，却不是因烈酒。</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 11:8; 以赛亚书 44:18; 帖撒罗尼迦后书 2:9–12"> 因为耶和华把沉睡的灵浇灌在你们身上，闭上了你们的眼，就是先知；祂蒙住了你们的头，就是先见。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 13:11; 但以理 12:4; 以赛亚书 8:16"> 一切异象对你们都成了封住之书的话；人把书交给识字的人，说：“请读这个。”他说：“我不能，因为它封住了。”</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 7:15–16; 以赛亚书 29:18; 耶利米书 5:4"> 又把书交给不识字的人，说：“请读这个。”他说：“我不识字。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="耶利米书 12:2; 以西结 33:31–33; 马可福音 7:2–13"> 主说：“因为这百姓用口亲近我，用嘴唇尊敬我，心却远离我；他们对我的敬畏，不过是人所教导的诫命；</span>
<span className="v" id="v14" data-v="14" data-xref="哈巴谷 1:5; 哥林多前书 1:19–24; 以赛亚书 28:21"> 所以，看哪，我要在这百姓中继续行奇妙的事，就是奇妙又奇异的事；他们智慧人的智慧必消灭，他们审慎人的聪明必隐藏。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以西结 8:12; 以赛亚书 47:10; 以赛亚书 30:1"> 那些向耶和华深深隐藏谋略的人有祸了！他们的作为在黑暗中，他们说：“谁看见我们？”又说：“谁知道我们？”</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 9:19–21; 以赛亚书 64:8; 以赛亚书 45:9–11"> 你们把事情颠倒了！窑匠岂可被看作与泥土一样吗？受造之物岂可对造它的说：“他没有造我”？被塑成之物岂可论塑造它的说：“他没有聪明”？</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 32:15; 马太福音 19:30; 希伯来书 10:37"> 不是还有极短的时候，黎巴嫩就要变成肥沃的田地，而肥沃的田地要被看作森林吗？</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 35:5; 马太福音 11:5; 马可福音 7:37"> 到那日，聋子必听见书上的话；瞎子的眼睛必从幽暗和黑暗中看见。</span>
<span className="v" id="v19" data-v="19" data-xref="雅各书 2:5; 以赛亚书 61:1; 马太福音 11:29"> 谦卑人也必因耶和华增添喜乐；人间的贫穷人必因以色列的圣者欢欣。</span>
<span className="v" id="v20" data-v="20" data-xref="弥迦书 2:1; 以赛亚书 28:14–22; 路加福音 16:14"> 因为强暴人归于无有，讥诮人止息，所有伺机作恶的人都被剪除——</span>
<span className="v" id="v21" data-v="21" data-xref="阿摩司 5:10–12; 雅各书 5:6; 使徒行传 3:14"> 他们因一句话就使人被控告，在城门口给责备人的设下网罗，并用虚假的见证剥夺无辜者的公正。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 45:17; 以赛亚书 51:2; 耶利米书 30:10"> 所以，救赎亚伯拉罕的耶和华论雅各家如此说：“雅各必不再羞愧，他的脸也不再发白。</span>
<span className="v" id="v23" data-v="23" data-xref="以弗所书 2:10; 以赛亚书 19:25; 以赛亚书 45:11"> 但他看见他的儿女，就是我手的工作，在他中间的时候，他们必尊我的名为圣。是的，他们必尊雅各的圣者为圣，也必敬畏以色列的上帝。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 15:17–19; 希伯来书 5:2; 以赛亚书 28:7"> 心灵迷误的人也必得明白，发怨言的人必领受教训。”</span>
</div>
</div>

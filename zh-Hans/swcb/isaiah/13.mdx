<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 47:1–15; 耶利米书 50:1–64; 以赛亚书 1:1"> 亚摩斯的儿子以赛亚所看见、论巴比伦的默示。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="耶利米书 51:58; 以赛亚书 5:26; 耶利米书 50:2"> 你们要在光秃的山上竖立旗帜！要向他们扬声呼喊！要挥手，使他们进入尊贵人的门。</span>
<span className="v" id="v3" data-v="3" data-xref="约珥 3:11; 耶利米书 51:20–24; 启示录 17:12–18"> 我已经命令我分别为圣的人；是的，我已经召集我勇猛的人来执行我的怒气，就是那些因我威严而欢跃的人。</span>
<span className="v" id="v4" data-v="4" data-xref="约珥 3:14; 启示录 19:11–21; 约珥 2:25"> 山间有群众喧嚷的声音，好像大国的声音；有列国众邦聚集骚动的声音！万军之耶和华正在召集军队预备争战。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 51:20–46; 马太福音 24:31; 耶利米书 50:9"> 他们从远方之地而来，从天的尽头而来；就是耶和华和祂盛怒的兵器，要毁灭全地。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约珥 1:15; 以赛亚书 13:9; 阿摩司 5:18"> 你们要哀号，因为耶和华的日子近了！这日必如毁灭从全能者而来。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结 21:7; 那鸿书 2:10; 那鸿书 1:6"> 因此，所有的手都要发软，人人的心都要消化。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 26:17; 帖撒罗尼迦前书 5:3; 那鸿书 2:10"> 他们必惊惶；痛苦和忧伤要抓住他们。他们必疼痛，像临产的妇人一样。他们彼此惊愕相看；他们的脸面如火焰。</span>
<span className="v" id="v9" data-v="9" data-xref="那鸿书 1:6; 玛拉基书 4:1; 以赛亚书 13:15–18"> 看哪，耶和华的日子来到，残酷，带着烈怒和猛烈的忿怒；要使这地荒凉，除灭其中的罪人。</span>
<span className="v" id="v10" data-v="10" data-xref="约珥 2:31; 马太福音 24:29; 马可福音 13:24"> 天上的众星和星座都不发光；太阳一出来就变黑暗，月亮也不使它的光照耀。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 2:11; 以赛亚书 5:15; 但以理 5:22–23"> 我必因世界的恶惩罚世界，因恶人的罪孽惩罚恶人。我必使骄傲人的狂妄止息，使强暴人的傲慢降卑。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 4:1; 以赛亚书 24:6; 约伯记 28:16"> 我必使人比精金还稀少，使人比俄斐的纯金更稀少。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 12:26–27; 约珥 3:16; 马太福音 24:29"> 因此，在万军之耶和华的震怒中，在祂猛烈忿怒的日子，我必使诸天震动，地也必被摇撼，离开本位。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 22:17; 耶利米书 50:16; 列王纪上 22:36"> 到那时，他们必像被追赶的羚羊，又像无人聚集的羊，各自转回本族，各自逃回本地。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 14:19–22; 耶利米书 50:27; 以赛亚书 47:9–14"> 凡被找到的，都必被刺透；凡被抓住的，都必倒在刀下。</span>
<span className="v" id="v16" data-v="16" data-xref="那鸿书 3:10; 何西阿 10:14; 诗篇 137:8–9"> 他们的婴孩也必在他们眼前被摔碎；他们的房屋必被洗劫，他们的妻子必被强暴。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="但以理 5:28–31; 耶利米书 51:11; 以赛亚书 41:25"> 看哪，我必激动玛代人来攻击他们；玛代人不看重银子，至于金子，他们也不喜爱。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 8:12; 历代志下 36:17; 以赛亚书 13:16"> 他们的弓必击碎少年人；他们必不怜悯腹中的果子。他们的眼也不顾惜孩童。</span>
<span className="v" id="v19" data-v="19" data-xref="但以理 4:30; 西番雅书 2:9; 耶利米书 51:41"> 巴比伦，列国的荣耀，迦勒底人骄傲的华美，必像上帝倾覆所多玛和蛾摩拉一样。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米书 51:43; 以赛亚书 14:23; 耶利米书 50:3"> 它必永无人居住，世世代代无人住在其中。阿拉伯人不在那里支搭帐棚，牧人也不使羊群躺卧在那里。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 18:2; 以赛亚书 34:11–15"> 旷野的野兽却要躺卧在那里；他们的房屋必满了豺狼。鸵鸟必住在那里，野山羊必在那里跳跃。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 51:33; 以赛亚书 25:2; 以赛亚书 35:7"> 鬣狗必在他们的城堡中哀叫，豺狼必在华美的宫殿里呼号。她的时候近了，她的日子必不延长。</span>
</div>

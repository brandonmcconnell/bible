<span className="v" id="v1" data-v="1" data-xref="约珥 3:4–8; 阿摩司 1:9–10; 创世记 10:4"> 关于推罗的默示。<br />他施的船只啊，哀号吧！因为推罗已经荒废，没有房屋，也无人进入；这消息是从基提地向他们显明的。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 47:5; 以赛亚书 41:1; 以西结 28:2"> 海岛的居民啊，要静默；海上往来的西顿商人曾使你富足。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 2:18; 历代志上 13:5; 以西结 27:33"> 在大水之上，西曷的粮种、尼罗河的收成，是她的进项；她曾是万国的市场。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 18:23; 创世记 10:15; 耶利米书 47:3–4"> 西顿哪，要羞愧；因为海，就是海的堡垒，发声说：“我没有经历产痛，也没有生产；我没有养育少年人，也没有抚养童女。”</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 2:9–11; 出埃及记 15:14–16; 启示录 18:17–19"> 这消息传到埃及的时候，他们必因推罗的消息而痛苦。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 23:12; 以赛亚书 21:15; 以赛亚书 23:10"> 你们要渡到他施去！海岛的居民啊，哀哭吧！</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 22:2; 以赛亚书 32:13; 约书亚记 19:29"> 这是你们欢乐的城吗？她的根源在古老的日子；她的脚曾带她到远方去旅居。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 10:8; 耶利米书 50:44–45; 申命记 29:24–28"> 推罗是赐人冠冕的城，她的商人是王子，她的贸易者是地上尊贵的人；是谁策划这事攻击她呢？</span>
<span className="v" id="v9" data-v="9" data-xref="雅各书 4:6; 以赛亚书 13:11; 约伯记 40:11–12"> 是万军之耶和华策划了这事，为要玷污一切荣耀的骄傲，使地上一切尊贵的人被藐视。</span>
<span className="v" id="v10" data-v="10" data-xref="约伯记 12:21; 以赛亚书 23:14; 诗篇 18:32"> 他施的女子啊，要像尼罗河一样漫过你的地；再没有束缚了。</span>
<span className="v" id="v11" data-v="11" data-xref="撒迦利亚书 9:3–4; 出埃及记 14:21; 耶利米书 47:7"> 祂向海伸出手，震动列国；耶和华已经下令，要毁灭迦南的堡垒。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 18:22; 以西结 26:13–14; 以赛亚书 23:1–2"> 祂说：“受欺压的西顿处女啊，你必不再欢乐。起来，渡到基提去；即使在那里，你也得不到安息。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="哈巴谷 1:6; 以赛亚书 10:5; 列王纪下 17:24"> 看哪，迦勒底人的地。这民族原本不存在；亚述人为住旷野的人建立了它。他们设立自己的攻城塔，拆毁它的宫殿，使它成为废墟。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 23:1; 以赛亚书 23:6; 以西结 27:25–30"> 他施的船只啊，哀号吧！因为你们的堡垒已经荒废！</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 25:22; 耶利米书 25:9–11; 但以理 7:14"> 到那日，推罗必被遗忘七十年，照着一位王的年日。七十年结束以后，推罗的情形就像妓女之歌所唱的。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 30:14; 箴言 7:10–12"> 被遗忘的妓女啊，拿琴在城中巡行吧；弹出悦耳的曲调，多唱歌曲，好使人再记起你。</span>
<span className="v" id="v17" data-v="17" data-xref="那鸿书 3:4; 以西结 27:6–36; 启示录 19:2"> 七十年结束以后，耶和华必眷顾推罗。她要回到自己的工价，又要与地面上世上的万国行淫。</span>
<span className="v" id="v18" data-v="18" data-xref="诗篇 72:10; 申命记 26:12–14; 腓立比书 4:17–18"> 她的货财和她的工价必归耶和华为圣；必不被积攒，也不被储藏，因为她的货财必归给住在耶和华面前的人，使他们吃得充足，并有耐穿的衣服。</span>

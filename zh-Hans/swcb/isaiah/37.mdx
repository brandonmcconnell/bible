<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 19:1–37; 以斯拉记 9:5; 以赛亚书 36:22–38"> 希西家王听见这话，就撕裂衣服，披上麻布，进了耶和华的殿。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 1:1; 列王纪下 18:18; 以赛亚书 36:3"> 他差遣家宰以利亚敬、书记舍伯那，以及祭司中的长老，都披着麻布，去见亚摩斯的儿子以赛亚先知。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 66:9; 何西阿 13:13; 以赛亚书 26:17–18"> 他们对他说：“希西家这样说：‘今日是患难、责罚、被弃绝的日子；因为孩子到了产门，却没有力量生产。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 1:9; 以赛亚书 36:20; 以赛亚书 10:22"> 或许耶和华你的上帝会听见拉伯沙基的话，就是他的主人亚述王差他来辱骂永生上帝的话，并且会责备耶和华你的上帝所听见的话。所以，请你为所剩下的余民献上祷告。’”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 希西家王的臣仆就来到以赛亚那里。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 7:4; 以赛亚书 35:4; 马可福音 5:36"> 以赛亚对他们说：“你们要这样告诉你们的主人：‘耶和华说：“你所听见的话，就是亚述王的臣仆亵渎我的话，不要害怕。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 31:8–9; 历代志下 32:21; 以赛亚书 33:10–12"> 看哪，我要把一个灵放在他里面；他会听见消息，就返回自己的本地。我必使他在自己的本地倒在刀下。”’”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约书亚记 10:29; 民数记 33:20–21; 列王纪下 19:8–9"> 拉伯沙基回去，发现亚述王正在攻打立拿，因为他听说王已经离开拉吉。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 18:1; 以赛亚书 20:5; 以赛亚书 37:7"> 他听见有关古实王特哈加的消息，说：“他已经出来要与你交战。”他听见这事，就差遣使者去见希西家，说：</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 36:15; 列王纪下 18:5; 马太福音 27:43"> “你们要这样对犹大王希西家说：‘不要让你所倚靠的上帝欺骗你，说：“耶路撒冷必不交在亚述王手中。”</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 36:18–20; 列王纪下 18:33–35; 以赛亚书 14:17"> 看哪，你已经听见亚述诸王怎样对待各地，把它们完全毁灭。难道你还能得救吗？</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 11:31; 列王纪下 17:6; 列王纪下 18:11"> 我列祖所毁灭的列国，就是歌散、哈兰、利色，以及在提拉撒的伊甸人，他们的神明拯救了他们吗？</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 19:13; 列王纪下 17:24; 以赛亚书 36:19"> 哈马王、亚珥拔王、西法瓦音城的王，以及希拿和以瓦的王在哪里呢？’”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王纪下 19:14; 诗篇 123:1–4; 约珥 2:17–20"> 希西家从使者手中接过书信，读了以后，就上耶和华的殿，把书信展开在耶和华面前。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 7:8–9; 但以理 9:3–4; 雅各书 5:13"> 希西家向耶和华祷告，说：</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 25:22; 诗篇 99:1; 诗篇 86:10"> “万军之耶和华，以色列的上帝，坐在基路伯之上的那一位，惟有你是地上万国的上帝。你造了天和地。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 6:40; 诗篇 17:6; 以赛亚书 37:4"> 耶和华啊，求你侧耳垂听；耶和华啊，求你睁眼观看。求你听西拿基立所说的一切话，他差人来辱骂永生上帝。</span>
<span className="v" id="v18" data-v="18" data-xref="那鸿书 2:11–12; 列王纪下 15:29; 列王纪下 17:6"> 耶和华啊，亚述诸王确实毁灭了列国和他们的土地，</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 44:9–10; 耶利米书 10:11; 何西阿 8:6"> 又把他们的神明扔在火里；因为那些并不是神，不过是人手所造的木头和石头，所以他们把它们毁灭了。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 46:10; 列王纪上 18:36–37; 诗篇 83:17–18"> 耶和华我们的上帝啊，现在求你救我们脱离他的手，使地上万国都知道惟有你是耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 58:9; 以赛亚书 38:3–6; 使徒行传 4:31"> 亚摩斯的儿子以赛亚就派人去见希西家，说：“耶和华以色列的上帝这样说：‘因你为亚述王西拿基立的事向我祷告，</span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 16:4; 耶利米哀歌 2:13; 以赛亚书 1:8"> 这就是耶和华论到他所说的话：锡安的处女女儿藐视你，讥笑你；耶路撒冷的女儿向你摇头。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结 39:7; 但以理 5:20–23; 以赛亚书 17:7"> 你辱骂、亵渎的是谁？你向谁扬声，高高举目呢？是向以色列的圣者。</span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 14:8; 以赛亚书 10:18; 出埃及记 15:9"> 你藉你的臣仆辱骂主，并且说：“我凭我众多的战车，登上山岭的高处，进入黎巴嫩的深处。我要砍下其中高大的香柏树和上好的柏树；我要进入它最远的高处，进入它肥美田野的森林。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪上 20:10; 以赛亚书 36:12; 列王纪下 19:23–24"> 我挖井喝水，并且要用我的脚掌踏干埃及所有的河流。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="使徒行传 4:27–28; 使徒行传 2:23; 彼得前书 2:8"> “‘你岂没有听见，我早已做成这事，在古时就安排了它吗？现在我使它成就，使你可以摧毁坚固城，把它们变成荒废的废墟。</span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 129:6; 诗篇 37:2; 彼得前书 1:24"> 因此其中的居民力量微弱，惊惶羞愧；他们像田野的草，又像青菜，像房顶上的草，又像庄稼还未长成之前的田地。</span>
<span className="v" id="v28" data-v="28" data-xref="启示录 2:13; 诗篇 139:1–11; 耶利米书 23:23–24"> 但你坐下，你出去，你进来，以及你向我发怒，我都知道。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结 38:4; 以赛亚书 30:28; 以赛亚书 37:34"> 因为你向我发怒，又因为你的狂傲上达我的耳中，所以我要把我的钩子放在你的鼻子上，把我的嚼环放在你的嘴唇里；我要使你从你来的路转回去。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="列王纪下 19:29; 利未记 25:4–5; 列王纪上 13:3–5"> “‘这要作为给你的兆头：你们今年要吃自生的，第二年吃从自生的长出来的；第三年要耕种收割，栽种葡萄园，吃其中的果子。</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 27:6; 列王纪下 19:30–31; 诗篇 80:9"> 犹大家逃脱剩下的余民，必再次向下扎根，向上结果。</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 9:7; 列王纪下 19:31; 以赛亚书 59:17"> 因为必有余民从耶路撒冷出来，逃脱的人必从锡安山出来。万军之耶和华的热心必成就这事。’</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 17:12; 以赛亚书 10:32–34; 以赛亚书 17:14"> “所以耶和华论到亚述王这样说：‘他必不来到这城，也不在那里射箭；他必不拿盾牌来到城前，也不筑垒攻城。</span>
<span className="v" id="v34" data-v="34" data-xref="以赛亚书 37:29; 箴言 21:30"> 他从哪条路来，必从哪条路回去，必不来到这城，’耶和华说。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪下 20:6; 以赛亚书 38:6; 以赛亚书 31:5"> ‘因为我为自己的缘故，又为我仆人大卫的缘故，必保护这城，拯救这城。’”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="以赛亚书 10:12; 列王纪下 19:35; 以赛亚书 10:33–34"> 耶和华的使者出去，在亚述营中击杀了十八万五千人。众人清早起来，看哪，他们全都成了死尸。</span>
<span className="v" id="v37" data-v="37" data-xref="约拿 1:2; 约拿 3:3; 创世记 10:11–12"> 于是亚述王西拿基立拔营，离去，返回尼尼微，住在那里。</span>
<span className="v" id="v38" data-v="38" data-xref="创世记 8:4; 耶利米书 51:27; 以斯拉记 4:2"> 他在他的神尼斯洛庙里敬拜的时候，他的儿子亚得米勒和沙利色用刀杀了他；他们逃到亚拉腊地。他的儿子以撒哈顿接续他作王。</span>
</div>
</div>

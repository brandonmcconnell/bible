<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="诗篇 102:13; 撒迦利亚书 1:17; 撒迦利亚书 8:22–23"> 因为耶和华必怜悯雅各，必再拣选以色列，把他们安置在自己的土地上。寄居的外人必与他们联合，归附雅各家。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 61:5; 以赛亚书 60:14; 耶利米书 30:16"> 万民必接他们，把他们带回本处；以色列家必在耶和华的土地上得他们为仆婢。他们要掳掠那些曾掳掠他们的人，并要辖制曾欺压他们的人。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米书 30:10; 以赛亚书 32:18; 以斯拉记 9:8–9"> 到那日，耶和华必使你脱离忧伤、困苦，以及你被迫服的苦役，得享安息。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 49:26; 哈巴谷 1:2–10; 耶利米书 51:34–35"> 那时你必提起这首讽刺诗攻击巴比伦王，说：“欺压人的何竟止息！黄金城何竟止息！”</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 125:3; 以赛亚书 9:4; 耶利米书 48:15–17"> 耶和华折断了恶人的杖，折断了统治者的权杖；</span>
<span className="v" id="v6" data-v="6" data-xref="但以理 7:19–21; 雅各书 2:13; 启示录 17:16–17"> 他们在愤怒中不断击打万民，在怒气中辖制列国，施行无人制止的逼迫。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 126:1–3; 诗篇 98:7–9; 诗篇 96:11–13"> 全地得安息，享平静；众人都发声歌唱。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结 31:16; 以赛亚书 55:12–13; 撒迦利亚书 11:2"> 松树和黎巴嫩的香柏树也因你欢喜，说：“自从你被降卑，再没有伐木的人上来攻击我们。”</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 32:21–32; 耶利米书 50:8; 箴言 15:24"> 阴间<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="阴间是死人所在之处。">a</a></sup>从下面因你震动，要迎接你来到；它为你惊动亡灵，就是地上所有的首领；它使列国的君王都从宝座上站起来。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 49:6–14; 传道书 2:16; 诗篇 82:6–7"> 他们都要回答你，对你说：“你也变得像我们一样软弱了吗？你也变得像我们一样了吗？”</span>
<span className="v" id="v11" data-v="11" data-xref="但以理 5:25–30; 约伯记 21:11–15; 以赛亚书 66:24"> 你的威荣和你琴瑟的声音都被带下阴间；<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="阴间是死人所在之处。">b</a></sup>蛆虫铺在你身下，虫子覆盖你。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西结 28:13–17; 启示录 12:7–10; 路加福音 10:18"> 明亮之星，黎明之子啊，你何竟从天坠落！你这使列国俯伏的，何竟被砍倒在地上！</span>
<span className="v" id="v13" data-v="13" data-xref="但以理 8:10–12; 以西结 28:2; 以西结 28:12–16"> 你心里曾说：“我要升到天上！我要把我的宝座高举在上帝的众星之上！我要坐在聚会的山上，在极北之处！</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 47:8; 创世记 3:5; 帖撒罗尼迦后书 2:4"> 我要升到云层的高处之上！我要使自己像至高者一样！”</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 11:23; 以西结 32:23; 使徒行传 12:22–23"> 然而你必被带下阴间，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="阴间是死人所在之处。">c</a></sup>到坑中的深处。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 50:23; 诗篇 58:10–11; 耶利米书 51:20–23"> 看见你的人必凝视你，细看你，说：“这就是那使大地震动、使列国摇撼的人吗？</span>
<span className="v" id="v17" data-v="17" data-xref="约珥 2:3; 以赛亚书 13:19–22; 以赛亚书 45:13"> 这就是那使世界像旷野，倾覆其城邑，不释放被囚的人归家的人吗？”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="历代志下 24:25; 以赛亚书 22:16; 以西结 32:18–32"> 列国的君王都在荣耀中安睡，各在自己的坟墓里。</span>
<span className="v" id="v19" data-v="19" data-xref="耶利米书 41:9; 耶利米书 41:7; 列王纪上 21:24"> 但你却被抛出自己的坟墓，好像可憎的枝子；你被那些被刀刺透、被杀之人的尸体遮盖，他们下到坑中的石头那里；你又像被脚践踏的尸首。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 21:10; 约伯记 18:19; 诗篇 37:28"> 你不得与他们同葬，因为你毁坏了自己的土地，杀害了自己的百姓。作恶者的后裔必永不被提名。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马太福音 23:35; 出埃及记 20:5; 哈巴谷 2:8–12"> 要因他们祖先的罪孽，预备屠杀他的儿女，免得他们起来占有大地，使世界的表面布满城邑。</span>
<span className="v" id="v22" data-v="22" data-xref="耶利米书 50:29–35; 箴言 10:7; 列王纪上 14:10"> 万军之耶和华说：“我必起来攻击他们，从巴比伦剪除名号、余民、子孙和后代。”这是耶和华说的。</span>
<span className="v" id="v23" data-v="23" data-xref="西番雅书 2:14; 以赛亚书 13:21–22; 列王纪上 14:10"> 万军之耶和华说：“我也必使它成为豪猪的产业和水池；我要用毁灭的扫帚扫净它。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="箴言 19:21; 约伯记 23:13; 以赛亚书 46:10–11"> 万军之耶和华起誓说：“我怎样思想，事情必照样成就；我怎样定意，事情必照样立定：</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 9:4; 那鸿书 1:13; 以赛亚书 37:36–38"> 我必在我的地上击碎亚述人，在我的山上把他践踏在脚下。这样，他的轭必离开他们，他的重担必离开他们的肩头。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 23:9; 西番雅书 3:6–8; 出埃及记 15:12"> 这是为全地所定的计划；这是向列国伸出的手。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 43:13; 约伯记 23:13; 历代志下 20:6"> 因为万军之耶和华已经定了计划，谁能阻止呢？祂的手已经伸出，谁能使它转回呢？”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="列王纪下 16:20; 以赛亚书 13:1; 历代志下 28:27"> 亚哈斯王去世的那一年，有以下默示。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 30:6; 以赛亚书 11:8; 历代志下 26:6"> 非利士全地啊，不要因击打你的杖折断了就欢喜；因为从蛇的根必生出毒蛇，它所结的果子必是会飞的火蛇。</span>
<span className="v" id="v30" data-v="30" data-xref="以赛亚书 7:21–22; 西番雅书 2:4–7; 以赛亚书 5:17"> 贫寒人的长子必得食物，穷乏人必安然躺卧；但我必以饥荒杀死你的根，你的余民也必被杀。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="耶利米书 1:14; 以赛亚书 20:1; 以赛亚书 14:29"> 城门哪，哀号吧！城啊，呼喊吧！非利士全地啊，你都消化了；因为烟从北方而来，他的行列中没有掉队的人。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="诗篇 102:16; 诗篇 87:5; 雅各书 2:5"> 人将怎样回答那国的使者呢？就是：耶和华已经建立锡安，祂百姓中受苦的人必在其中避难。</span>
</div>
</div>

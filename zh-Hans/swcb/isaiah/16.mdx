<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 3:4; 以赛亚书 10:32; 列王纪下 14:7"> 你们当将羔羊送给那地的统治者，从西拉经过旷野，送到锡安女子的山。</span>
<span className="v" id="v2" data-v="2" data-xref="箴言 27:8; 士师记 11:18; 耶利米书 48:20"> 摩押的女子在亚嫩的渡口，必像漂泊的鸟，像被冲散的巢。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 32:2; 列王纪上 18:4; 以赛亚书 25:4"> 你们要献计！要施行公正！在正午使你的荫影像黑夜一样！要隐藏被赶散的人！不要出卖逃亡者！</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 14:4; 以赛亚书 51:13; 以赛亚书 9:4"> 让我的被赶散者寄居在你那里！至于摩押，你要作他的藏身之处，使他躲避毁灭者的面。因为勒索者归于无有，毁灭止息，欺压人的从地上消灭。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理 7:14; 弥迦书 4:7; 以赛亚书 9:6–7"> 必有宝座因慈爱而坚立；必有一位凭诚实坐在其上，在大卫的帐幕中施行审判，寻求公正，并迅速行公义。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="阿摩司 2:1; 俄巴底亚 1:3–4; 耶利米书 48:29–30"> 我们听见摩押的骄傲，他极其骄傲；也听见他的狂妄、骄傲和愤怒。他的夸耀算不得什么。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 3:25; 历代志上 16:3; 耶利米书 48:20"> 因此，摩押必为摩押哀号；人人都必哀号。你们必为基珥哈列设的葡萄饼哀伤，彻底受创。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 15:4; 民数记 32:38; 耶利米书 48:32"> 因为希实本的田地和西比玛的葡萄树都衰残了。列国的君主折断了它上好的枝条；那些枝条延伸到雅谢，蔓延到旷野。它的嫩枝向外伸展，越过了海。</span>
<span className="v" id="v9" data-v="9" data-xref="耶利米书 40:12; 以赛亚书 15:4–5; 耶利米书 40:10"> 因此，我要用雅谢的哭泣，为西比玛的葡萄树哀哭。希实本和以利亚利啊，我要用我的眼泪浇灌你；因为战斗的呐喊已经临到你的夏果和你的收成。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 48:33; 士师记 9:27; 阿摩司 5:17"> 欢喜从肥田中被夺去，快乐也被夺去；葡萄园里必没有歌唱，也没有欢呼。没有人在榨酒池中踹酒。我已使欢呼声止息。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 15:5; 耶利米书 48:36; 何西阿 11:8"> 因此，我的心为摩押如竖琴鸣响，我的肺腑为基珥赫列斯鸣响。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 15:2; 列王纪上 18:29; 耶利米书 48:35"> 到那时，摩押现身，在邱坛上使自己疲乏，又来到他的圣所祷告，却不能得胜。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 44:8"> 这是耶和华从前论到摩押所说的话。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 21:16; 耶利米书 48:46–47; 以赛亚书 23:9"> 但现在耶和华说：“三年之内，照受雇工人计算年期的方式，摩押的荣耀连同他众多的群众都必被轻视；所剩余的人必极少，又软弱。”</span>
</div>

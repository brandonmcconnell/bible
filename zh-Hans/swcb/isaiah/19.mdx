<span className="v" id="v1" data-v="1" data-xref="出埃及记 12:12; 启示录 1:7; 约书亚记 2:11"> 关于埃及的默示。<br />“看哪，耶和华驾着疾行的云，来到埃及。埃及的偶像必在祂面前战兢；埃及人的心必在里面消融。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 7:22; 撒母耳记上 14:20; 马太福音 10:36"> 我要激动埃及人攻击埃及人；他们各人必攻击自己的弟兄，各人攻击自己的邻舍；城攻击城，国攻击国。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 8:19; 但以理 2:2; 历代志上 10:13"> 埃及人的灵必在他们里面衰竭。我要破坏他们的谋略。他们必求问偶像、念咒的、交鬼的和巫师。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 20:4; 耶利米书 46:26; 以西结 29:19"> 我要把埃及人交在残酷的主手中；凶猛的王必统治他们。”主万军之耶和华<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="当“LORD”或“GOD”以全大写字母呈现时，是上帝专有之名（希伯来文“יהוה”，通常发音为雅威）的译法。">a</a></sup>说。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="耶利米书 51:36; 以西结 30:12; 撒迦利亚书 14:18"> 海中的水必枯竭，河也必荒废干涸。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 37:25; 出埃及记 7:18; 列王纪下 19:24"> 河流必发臭；埃及的河渠必减少并干涸；芦苇和蒲草必枯萎。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 32:20; 约珥 1:17–18; 以赛亚书 23:3"> 尼罗河旁、尼罗河边的草场，以及尼罗河沿岸一切播种的田地，都必干枯，被吹散，归于无有。</span>
<span className="v" id="v8" data-v="8" data-xref="以西结 47:10; 哈巴谷 1:15; 民数记 11:5"> 渔夫必哀叹，所有在尼罗河垂钓的人都必悲哀，在水面撒网的人也必衰弱。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 27:7; 箴言 7:16; 列王纪上 10:28"> 此外，梳理麻的人和织白布的人都必羞愧。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 11:10; 出埃及记 7:19; 出埃及记 8:5"> 支柱必被打碎；所有受雇工作的人都必心中忧伤。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民数记 13:22; 使徒行传 7:22; 列王纪上 4:30"> 琐安的首领极其愚昧；法老最有智慧谋士的计谋也变为愚蠢。你们怎能对法老说：“我是智慧人的子孙，是古王的后裔”？</span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 1:20; 以赛亚书 14:24; 士师记 9:38"> 那么，你的智慧人在哪里呢？现在让他们告诉你，让他们知道万军之耶和华对埃及所定的旨意。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结 30:13; 耶利米书 2:16; 耶利米书 46:14"> 琐安的首领成了愚昧人；孟斐斯的首领受了迷惑。那些作她各支派房角石的人，使埃及走迷了路。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦后书 2:11; 列王纪上 22:20–23; 以西结 14:7–9"> 耶和华在她中间调和了乖谬的灵；他们使埃及在她一切所做的事上走迷了路，好像醉汉在自己的呕吐物中踉跄。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 9:14–15; 帖撒罗尼迦前书 4:11–12; 箴言 14:23"> 无论头或尾、棕枝或芦苇，都不能为埃及做成任何事。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 51:30; 那鸿书 3:13; 以赛亚书 11:15"> 到那日，埃及人必像女人一样；他们必因万军之耶和华向他们挥动的手而战兢惧怕。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 14:24; 但以理 4:35; 以西结 29:6–7"> 犹大地必使埃及惊恐。凡有人向他提起这地的，都必害怕，因为万军之耶和华向埃及所定的计划。</span>
<span className="v" id="v18" data-v="18" data-xref="西番雅书 3:9; 撒迦利亚书 2:11; 以赛亚书 19:21"> 到那日，埃及地必有五座城说迦南的语言，并指着万军之耶和华起誓；其中一座要称为“毁灭之城”。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="创世记 28:18; 约书亚记 22:10; 约书亚记 22:26"> 到那日，在埃及地中央必有一座祭坛归给耶和华，在边界上必有一根柱归给耶和华。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 50:15; 提多书 2:13; 以赛亚书 45:21–22"> 这要在埃及地作记号，作见证，归给万军之耶和华；因为他们因受欺压者的缘故向耶和华呼求，祂就差遣一位拯救者和保护者给他们，解救他们。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 11:9; 玛拉基书 1:11; 约翰福音 17:3"> 耶和华必被埃及认识；到那日，埃及人必认识耶和华。是的，他们必用祭物和供物敬拜，并向耶和华许愿，也必还愿。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 32:39; 希伯来书 12:11; 何西阿 14:1"> 耶和华必击打埃及，既击打又医治。他们必归向耶和华，祂就应允他们的恳求，并医治他们。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 11:16; 以弗所书 2:18–22; 以赛亚书 35:8–10"> 到那日，必有一条大道从埃及通往亚述；亚述人要进入埃及，埃及人也要进入亚述；埃及人要和亚述人一同敬拜。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 65:8; 创世记 12:2; 加拉太书 3:14"> 到那日，以色列必与埃及和亚述三者并列，成为地上的祝福；</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 29:23; 何西阿 2:23; 罗马书 9:24–25"> 因为万军之耶和华已经赐福给他们，说：“我的百姓埃及有福了，我手所做的亚述有福了，我的产业以色列有福了。”</span>
</div>

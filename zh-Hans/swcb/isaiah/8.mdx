<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 30:8; 约伯记 19:23–24; 哈巴谷 2:2–3"> 耶和华对我说：“你取一块大牌，用人的笔在上面写：‘归玛黑珥・沙拉勒・哈施・巴斯’；<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“玛黑珥・沙拉勒・哈施・巴斯”的意思是“急速掳掠，迅速抢夺”。">a</a></sup></span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 16:10–11; 列王纪下 18:2; 哥林多后书 13:1"> 我要为自己召来忠信的见证人作证：祭司乌利亚和耶比利家的儿子撒迦利亚。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="何西阿 1:3–9; 士师记 4:4; 以赛亚书 7:13–14"> 我亲近那女先知，她就怀孕，生了一个儿子。耶和华对我说：“给他起名叫‘玛黑珥・沙拉勒・哈施・巴斯’。</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 9:11; 列王纪下 16:9; 申命记 1:39"> 因为在这孩子还不知道怎样叫‘我父’、‘我母’以前，大马士革的财宝和撒马利亚的掳物必被亚述王带走。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 7:10"> 耶和华又对我说：</span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 9:7; 尼希米记 3:15; 以赛亚书 7:6"> “因为这百姓拒绝了缓缓流淌的西罗亚水，却因利汛和利玛利的儿子而欢喜；</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 17:12–13; 创世记 6:17; 以赛亚书 7:17"> 所以现在，看哪，主必使大河汹涌浩大的洪水临到他们，就是亚述王和他一切的荣耀。它必涨过一切河道，漫过一切河岸。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 7:14; 以赛亚书 30:28; 马太福音 1:23"> 它必冲入犹大，泛滥横流，直涨到颈项。它展开的翅膀必遍满你的地，哦，以马内利。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 14:5–6; 箴言 11:21; 诗篇 37:14–15"> 万民哪，喧嚷吧，你们必被打得粉碎！远方各国的人哪，要侧耳听：装备作战吧，你们必被击碎！装备作战吧，你们必被击碎！</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米哀歌 3:37; 罗马书 8:31; 约伯记 5:12"> 你们一同筹谋，终必归于无有；你们发言，终不能成立，因为上帝与我们同在。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以西结 3:14; 箴言 1:15; 耶利米书 15:19"> 耶和华用大能的手这样对我说，并指教我不可行这百姓所行的道路，说：</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 3:14–15; 路加福音 21:9; 诗篇 53:5"> “这百姓所称为阴谋的，你们不可都称为阴谋；不要怕他们的威吓，也不要惊惶。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 12:5; 以赛亚书 26:3–4; 启示录 15:4"> 你们必须尊万军之耶和华为圣。祂是你们所当惧怕的；祂是你们所当畏惧的。</span>
<span className="v" id="v14" data-v="14" data-xref="彼得前书 2:8; 罗马书 9:32–33; 以赛亚书 28:16"> 祂必成为圣所；但对以色列两家，祂必成为绊脚的石头、使人跌倒的磐石；对耶路撒冷的居民，祂必成为圈套和网罗。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 21:44; 路加福音 20:17–18; 以赛亚书 28:13"> 许多人必在它上面绊跌、跌倒、破碎，被网罗缠住，被捉拿。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="但以理 12:4; 希伯来书 3:5; 马可福音 4:10–11"> 要把这约包扎起来；在我的门徒中封住这律法。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 10:36–39; 哈巴谷 2:3; 耶利米哀歌 3:25–26"> 我要等候那向雅各家掩面的耶和华；我要仰望祂。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 2:13–14; 路加福音 2:34; 撒迦利亚书 8:3"> 看哪，我和耶和华赐给我的儿女，在以色列中作兆头和奇事，都是出于住在锡安山的万军之耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="历代志上 10:13; 利未记 20:6; 历代志下 33:6"> 有人对你们说：“要去求问那些交鬼的和行巫术的，就是那些啁啾低语的人。”百姓不应当求问自己的上帝吗？难道要为活人求问死人吗？</span>
<span className="v" id="v20" data-v="20" data-xref="彼得后书 1:19; 提摩太后书 3:15–17; 以赛亚书 30:8–11"> 当转向律法和约！如果他们所说的不照这话，必定没有晨光临到他们。</span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 9:20; 箴言 19:3; 耶利米哀歌 4:4–5"> 他们必经过这地，极其困苦饥饿。饥饿的时候，他们必焦躁不安，咒骂自己的王和自己的上帝。他们必仰面向上，</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 5:30; 马太福音 22:13; 耶利米书 13:16"> 又观看大地，只见困苦、黑暗和痛苦的幽暗；他们必被赶入浓黑之中。</span>
</div>

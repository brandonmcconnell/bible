<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 25:2; 撒迦利亚书 9:1; 阿摩司 1:3–5"> 关于大马士革的默示。<br />“看哪，大马士革不再为城，必成为荒废的土堆。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结 25:5; 耶利米书 7:33; 民数记 32:34"> 亚罗珥的城邑被撇弃，必成为羊群之地；羊群必躺卧，没有人使它们惊吓。</span>
<span className="v" id="v3" data-v="3" data-xref="何西阿 9:11; 以赛亚书 8:4; 以赛亚书 7:16"> 以法莲的堡垒必消失，大马士革的国权也必止息，亚兰剩余的人也必如此；他们必像以色列儿女的荣耀一样。”这是万军之耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 10:16; 申命记 32:15–27; 以赛亚书 24:13"> “到那日，雅各的荣耀必衰微，他肥胖的身体必消瘦。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 13:30; 约珥 3:13; 耶利米书 51:33"> 这就像收割的人收聚禾稼，用手臂割下麦穗；又像人在利乏音谷拾取遗落的麦穗。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 24:13; 申命记 4:27; 罗马书 9:27"> 然而其中仍有拾剩的果子留下，像打橄榄树之后，在最高的枝梢上剩两三个橄榄，在多结果子的树最外面的枝条上剩四五个。”这是耶和华——以色列的上帝说的。</span>
<span className="v" id="v7" data-v="7" data-xref="弥迦书 7:7; 何西阿 6:1; 何西阿 3:5"> 到那日，人必仰望造他的主，他们的眼目必尊重以色列的圣者。</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 30:22; 以赛亚书 27:9; 以赛亚书 2:8"> 他们不再仰望祭坛，就是自己手所做的；也不再尊重自己指头所造的，无论是亚舍拉木柱，还是香坛。</span>
<span className="v" id="v9" data-v="9" data-xref="阿摩司 3:11–15; 以赛亚书 27:10; 以赛亚书 24:1–12"> 到那日，他们坚固的城必像林中和山顶被撇弃的地方，就是从以色列儿女面前被撇弃的地方；那里必成为荒凉。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 106:21; 申命记 32:18; 以赛亚书 26:4"> 因为你忘记了拯救你的上帝，不记念你力量的磐石。所以你栽种悦人的植物，插上外来的苗。</span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 4:8; 何西阿 8:7; 加拉太书 6:7–8"> 你栽种的日子，就给它围上篱笆；早晨，你使你所种的开花；但在悲伤和绝望痛苦的日子，收成却飞去了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米书 6:23; 路加福音 21:25; 诗篇 18:4"> 唉，许多民族的喧嚷！他们喧嚷，好像众海的澎湃；列国的奔腾！他们奔腾，好像大水的汹涌。</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 9:5; 诗篇 1:4; 以赛亚书 41:15–16"> 列国必奔腾，好像许多水的汹涌；但祂必斥责他们，他们就远远逃跑；他们必被追赶，像山上的糠秕在风前，又像旋转的尘土在暴风前。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 19:35; 箴言 22:23; 耶利米书 13:25"> 到了晚上，看哪，惊恐！未到早晨，他们就不在了。这就是掳掠我们之人所得的份，是抢夺我们之人的命运。</span>
</div>

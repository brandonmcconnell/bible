<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 15:37; 列王纪下 16:1; 以赛亚书 1:1"> 在犹大王乌西雅的孙子、约坦的儿子亚哈斯的日子，亚兰王利汛和以色列王利玛利的儿子比加上来攻打耶路撒冷，却不能胜过它。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 8:12; 以赛亚书 7:13; 以赛亚书 9:9"> 有人告诉大卫家说：“亚兰已经与以法莲结盟。”他的心和他百姓的心就都颤抖，好像林中的树被风吹动而颤抖。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="列王纪下 18:17; 以赛亚书 36:2; 罗马书 9:27"> 耶和华对以赛亚说：“你和你的儿子施亚雅述，现在出去迎见亚哈斯，在上池水沟的尽头，在漂布地的大路上。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 35:4; 耶利米哀歌 3:26; 申命记 20:3"> 你要告诉他说：‘你要谨慎，保持平静；不要惧怕，也不要因这两个冒烟火把的残头，就是利汛、亚兰和利玛利的儿子所发的烈怒而心里胆怯。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 83:3–4; 撒迦利亚书 1:15; 诗篇 2:2"> 因为亚兰、以法莲和利玛利的儿子密谋害你，说：</span>
<span className="v" id="v6" data-v="6"> “我们上去攻打犹大，把它撕裂；我们彼此瓜分它，并在其中立他比勒的儿子为王。”</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 8:10; 耶利米哀歌 3:37; 以赛亚书 46:10–11"> 主耶和华如此说：“这事必站立不住，也必不会成就。”</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 17:1–3; 创世记 14:15; 撒母耳记下 8:6"> 因为亚兰的首都是大马士革，大马士革的首领是利汛。六十五年之内，以法莲必被击碎，不再成为一族。</span>
<span className="v" id="v9" data-v="9" data-xref="希伯来书 11:6; 罗马书 11:20; 历代志下 20:20"> 以法莲的首都是撒玛利亚，撒玛利亚的首领是利玛利的儿子。你们若不信，就必不能坚立。’”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 8:5; 以赛亚书 1:5; 以赛亚书 10:20"> 耶和华又对亚哈斯说：</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 37:30; 以赛亚书 38:7–8; 以赛亚书 38:22"> “你要向耶和华你的上帝求一个兆头；无论是在深处，还是在上面的高处，都可以求。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西结 33:31; 历代志下 28:22; 玛拉基书 3:15"> 但亚哈斯说：“我不求；我不试探耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 43:24; 以赛亚书 63:10; 以西结 34:18"> 以赛亚说：“大卫家啊，现在请听！你们使人疲乏还算小事吗？还要使我的上帝也疲乏吗？</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 1:23; 以赛亚书 9:6; 路加福音 1:31"> 因此，主自己要给你们一个兆头。看哪，那童女将要怀孕生一个儿子，并要给他起名叫以马内利。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“以马内利”的意思是“上帝与我们同在”。">a</a></sup></span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 7:22; 阿摩司 5:15; 马太福音 3:4"> 到他知道弃恶择善的时候，他必吃奶油和蜂蜜。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 8:4; 申命记 1:39; 以赛亚书 9:11"> 因为在这孩子知道弃恶择善以前，你所憎恶的那两个王所辖之地必被撇弃。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 8:7–8; 以赛亚书 10:5–6; 历代志下 28:19–21"> 耶和华必使日子临到你、你的百姓和你父家，就是亚述王来临的日子；这样的日子，自以法莲离开犹大以来从未有过。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 5:26; 约书亚记 24:12; 申命记 1:44"> 到那日，耶和华必吹哨，召来埃及江河极远处的苍蝇，又召来亚述地的蜜蜂。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 2:19; 耶利米书 16:16; 以赛亚书 2:21"> 它们都要来，停落在荒凉的谷地、岩石的裂缝、所有荆棘篱笆和一切草场上。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 8:7; 以西结 29:18; 以赛亚书 10:15"> 到那日，主必用从大河彼岸雇来的剃刀，就是亚述王，剃去头和脚上的毛；胡须也要剃掉。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 5:17; 耶利米书 39:10; 以赛亚书 37:30"> 到那日，人只养活一头小母牛和两只羊。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 7:15; 马太福音 3:4; 撒母耳记下 17:29"> 因为它们产奶丰多，他就吃奶油；凡留在境内的人都要吃奶油和蜂蜜。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 5:6; 雅歌 8:11–12; 马太福音 21:33"> 到那日，每一处曾有一千棵葡萄树、价值一千舍客勒银子的地方，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一舍客勒约为10克或约0.35盎司，所以1000舍客勒约为10千克或22磅。">b</a></sup>都必长满蒺藜和荆棘。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 27:3"> 人要带着箭和弓到那里去，因为全地都将长满蒺藜和荆棘。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 7:21–22; 以赛亚书 13:20–22; 以赛亚书 5:17"> 凡曾用锄头耕种的山地，你因怕蒺藜和荆棘，不会到那里去；那里必成为放牛之处，也成为羊践踏之地。”</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 65:2; 以赛亚书 1:2; 何西阿 7:13"> 耶和华说：“反叛的儿女有祸了！他们筹划计谋，却不是出于我；结成联盟，却不靠我的灵，好使罪上加罪；</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 36:6; 民数记 27:21; 申命记 28:68"> 他们起身下到埃及，却没有求问我的意见；要靠法老的力量坚固自己，投靠埃及的荫庇！</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 20:5; 罗马书 10:11; 耶利米书 17:5–6"> 因此，法老的力量必成为你们的羞耻，投靠埃及的荫庇必成为你们的羞辱。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 19:11; 以赛亚书 57:9; 耶利米书 43:7"> 因为他们的首领已在琐安，他们的使臣到了哈内斯。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 2:36; 以赛亚书 30:7; 以赛亚书 30:16"> 他们都必因那不能使他们受益的民族而羞愧；那民族不能帮助，也不能使人受益，反成羞辱和凌辱。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="申命记 8:15; 以赛亚书 46:1–2; 耶利米书 11:4"> 论南方牲畜的重负。<br />他们经过艰难困苦之地，那里有母狮和公狮、毒蛇和飞翔的火蛇；他们把财富驮在小驴的肩上，把财宝放在骆驼的峰上，带到一个不能使他们受益的民族那里。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 2:22; 以赛亚书 7:4; 诗篇 118:8–9"> 因为埃及的帮助是徒然无用的；所以我称她为“坐着不动的拉哈伯”。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 31:22; 哈巴谷 2:2; 以赛亚书 8:1"> 现在你去，当着他们写在版上，记录在书卷中，使它为将来的日子存到永永远远。</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 30:1; 使徒行传 7:51; 撒迦利亚书 1:4–6"> 因为这是反叛的百姓，是说谎的儿女，是不肯听耶和华律法的儿女；</span>
<span className="v" id="v10" data-v="10" data-xref="以西结 13:7–10; 罗马书 16:18; 阿摩司 2:12"> 他们对先见说：“不要看见！”对先知说：“不要向我们预言正直的话。要对我们说悦耳的话，预言虚假的事。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 8:7; 罗马书 1:30; 约翰福音 15:23–24"> 离开正道吧，偏离路径吧；让以色列的圣者从我们面前消失吧。”</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 31:1–3; 以赛亚书 5:24; 帖撒罗尼迦前书 4:8"> 因此，以色列的圣者这样说：“因为你们藐视这话，倚靠欺压和乖僻，并依赖它，</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 29:5; 以西结 13:10–15; 列王纪上 20:30"> 所以这罪孽对你们来说，必像高墙上凸出、即将倒塌的裂口，顷刻之间突然崩塌。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 2:9; 耶利米书 19:10–11; 彼得后书 2:4–5"> 祂要打碎它，像打碎窑匠的瓦器，毫不顾惜地碎成片，以致在碎片中找不到一片可用来从炉中取火，或从池中舀水。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 26:3–4; 以赛亚书 32:17; 耶利米书 3:22–23"> 主耶和华以色列的圣者曾这样说：“你们得救在于归回和安息；你们的力量在于安静和信靠。”你们却不肯，</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 31:1; 以赛亚书 31:3; 申命记 28:25"> 反而说：“不，我们要骑马逃跑！”所以你们必逃跑；又说：“我们要骑快马！”所以追赶你们的也必迅疾。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 28:25; 约书亚记 23:10; 申命记 32:30"> 一人叱喝，千人逃跑；五人叱喝，你们都要逃跑，直到你们剩下，像山顶上的信号杆，又像冈上的旗帜。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="耶利米哀歌 3:25–26; 彼得后书 3:9; 箴言 16:20"> 因此，耶和华必等候，要施恩给你们；因此，祂必被高举，好怜悯你们，因为耶和华是公义的上帝。凡等候祂的都是有福的。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 60:20; 诗篇 50:15; 以赛亚书 65:24"> 因为百姓必在锡安、在耶路撒冷居住。你必不再哭泣。祂听见你呼求的声音，必定施恩给你；祂一听见，就必应允你。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪上 22:27; 诗篇 80:5; 阿摩司 8:11–12"> 主虽然把患难的饼和困苦的水给你们，然而你的教师不再隐藏，你必亲眼看见你的教师；</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 32:8; 箴言 3:5–6; 以赛亚书 58:11"> 你或向右转，或向左转，你的耳朵必听见背后有声音说：“这是正路，要行在其中。”</span>
<span className="v" id="v22" data-v="22" data-xref="士师记 17:3–4; 以赛亚书 31:7; 撒迦利亚书 13:2"> 你们必玷污你们银雕像上的包银和金铸像上的镀金；你们必把它们当作污秽之物丢弃。你要对它说：“走开！”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒迦利亚书 8:11–12; 以赛亚书 32:20; 诗篇 65:9–13"> 祂必为你撒在地里的种子降雨；地所出产的粮食必肥美丰盛。到那日，你的牲畜必在宽阔的草场上吃草。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 45:6; 申命记 25:4; 撒母耳记上 8:12"> 耕地的牛和小驴也必吃用铲和叉扬净的可口饲料。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 43:19–20; 以赛亚书 35:6–7; 以赛亚书 2:14–15"> 在大行杀戮、塔楼倒塌的日子，各高山各高冈上必有溪流和水道。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 60:19–20; 申命记 32:39; 启示录 22:5"> 耶和华包扎祂百姓的裂伤，医治他们被击打的创伤那日，月光必像日光，日光必强七倍，像七日的光。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="帖撒罗尼迦后书 2:8; 那鸿书 1:5–6; 诗篇 18:7–9"> 看哪，耶和华的名从远方而来，祂的怒气燃烧，浓烟升腾。祂的嘴唇充满愤怒，祂的舌头像吞灭的火。</span>
<span className="v" id="v28" data-v="28" data-xref="以赛亚书 37:29; 以赛亚书 11:4; 帖撒罗尼迦后书 2:8"> 祂的气如涨溢的河水，直涨到颈项，要用毁灭的筛筛列国；祂要把引人走向灭亡的嚼环放在万民的腮颊中。</span>
<span className="v" id="v29" data-v="29" data-xref="诗篇 42:4; 诗篇 95:1–2; 出埃及记 15:1–21"> 你们必有歌，如守圣节的夜间；你们心中欢喜，好像人吹着笛子前往耶和华的山，到以色列的磐石那里。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 18:13–14; 约书亚记 10:11; 以赛亚书 29:6"> 耶和华必使祂威严的声音被听见，显明祂膀臂的降下，带着祂怒气的愤恨和吞灭之火的火焰，带着狂风、暴雨和冰雹。</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 11:4; 以赛亚书 9:4; 弥迦书 5:5–6"> 亚述人必因耶和华的声音惊惶；祂必用杖击打他。</span>
<span className="v" id="v32" data-v="32" data-xref="以赛亚书 11:15; 以赛亚书 19:16; 以赛亚书 2:19"> 耶和华所加在他身上的刑杖，每一击都必伴随着铃鼓和琴瑟的声音；祂必在挥舞兵器的战斗中与他们争战。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪下 23:10; 创世记 19:24; 耶利米书 19:6"> 因为他的焚烧之处早已预备好了；确实，是为王预备的。祂使火堆又深又宽，有火和许多木柴。耶和华的气如硫磺河点燃它。</span>
</div>

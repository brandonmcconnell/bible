<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="何西阿 7:5; 以赛亚书 28:7; 列王纪下 14:25–27"> 以法莲醉酒之人骄傲的冠冕有祸了！他荣耀华美那渐渐凋谢的花有祸了！它在被酒制伏之人的肥美谷顶上。</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 30:30; 那鸿书 1:8; 以西结 13:11"> 看哪，主有一位大能刚强者。他像冰雹的暴风、毁灭的风暴，又像汹涌泛滥的大水，必用手将他们摔在地上。</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 26:6; 希伯来书 10:29; 启示录 11:2"> 以法莲醉酒之人骄傲的冠冕必被踏在脚下。</span>
<span className="v" id="v4" data-v="4" data-xref="那鸿书 3:12; 弥迦书 7:1; 以赛亚书 28:1"> 他荣耀华美那渐渐凋谢的花，就是在肥美谷顶上的，必像夏天以前初熟的无花果；人一看见，就摘下吞吃。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前书 5:4; 以赛亚书 62:3; 以赛亚书 60:19"> 到那日，万军之耶和华必成为祂余民荣耀的冠冕、美丽的冕旒，</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 18:32–34; 约翰福音 5:30; 约书亚记 1:9"> 又成为坐堂审判者公平的灵，并成为在城门口击退战事之人的力量。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 56:10–12; 路加福音 21:34; 以赛亚书 19:14"> 他们也因酒摇摇晃晃，因烈酒东倒西歪。祭司和先知因烈酒摇晃，被酒吞没；他们因烈酒东倒西歪，在异象上出错，在判案中绊跌。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 48:26; 箴言 26:11; 哈巴谷 2:15–16"> 因为所有桌子都满了污秽的呕吐物和污物，没有一处干净。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="诗篇 131:2; 耶利米书 6:10; 约翰福音 12:38"> 他要将知识教导谁呢？要向谁解释信息呢？是那些刚断奶、刚离开母怀的孩子吗？</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 28:13; 提摩太后书 3:7; 耶利米书 11:7"> 因为这是命令加命令，命令加命令；准绳加准绳，准绳加准绳；这里一点，那里一点。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 14:21; 申命记 28:49; 以赛亚书 33:19"> 但祂要用口齿不清的嘴唇和另一种语言对这百姓说话；</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 11:28–29; 以赛亚书 30:15; 耶利米书 6:16"> 祂曾对他们说：“这是安息之所；要使疲乏的人得安息。”又说：“这是舒畅之处。”可是他们不肯听。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 13:14; 以赛亚书 6:9–10; 彼得后书 3:16"> 所以，耶和华的话临到他们，就成了命令加命令，命令加命令；准绳加准绳，准绳加准绳；这里一点，那里一点；以致他们走去，向后跌倒，破碎，落入网罗，被捉住。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 28:22; 以赛亚书 29:20; 以赛亚书 1:10"> 所以，你们这些讥诮的人，就是在耶路撒冷治理这百姓的，要听耶和华的话：</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 8:7–8; 以西结 13:22; 阿摩司 2:4"> “因为你们说：‘我们与死亡立约，与阴间<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="阴间是死人所在之处。">a</a></sup>达成协议。泛滥的鞭灾经过时，不会临到我们；因为我们以谎言为避难所，在虚假之下藏身。’”</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 118:22; 使徒行传 4:11–12; 彼得前书 2:6–8"> 因此，主耶和华说：“看哪，我在锡安放一块石头作根基，是一块经过试验的石头，是宝贵的房角石，是稳固的根基。信的人必不仓促行事。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 21:13; 阿摩司 7:7–9; 启示录 16:21"> 我必以公平为准绳，以公义为铅垂线。冰雹必扫除谎言的避难所，大水必漫过藏身之处。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 7:7; 以赛亚书 8:10; 以赛亚书 28:15"> 你们与死亡所立的约必被废除；你们与阴间<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="阴间是死人所在之处。">b</a></sup>所达成的协议必站立不住。泛滥的鞭灾经过时，你们就必被它践踏。</span>
<span className="v" id="v19" data-v="19" data-xref="哈巴谷 3:16; 以赛亚书 36:22; 列王纪下 24:2"> 每逢它经过，就必抓住你们；因为它必清晨又清晨地经过，昼夜不停；明白这信息只会带来惊恐。”</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 64:6; 哥林多前书 1:18–31; 罗马书 9:30–32"> 因为床太短，不能伸展；被子太窄，不能裹身。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 14:11; 约书亚记 10:12; 撒母耳记下 5:20"> 因为耶和华必兴起，像在毗拉心山一样；祂必发怒，像在基遍谷一样；为要做祂的工，就是祂奇异的工，并成就祂的事，就是祂非常的事。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 10:22–23; 以赛亚书 24:1–23; 马太福音 27:44"> 现在，你们不要讥诮，免得你们的捆绑更牢；因为我从主万军之耶和华<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="英文中以全大写呈现的“LORD”或“GOD”，是上帝专有名（希伯来文“יהוה”，通常发音为雅威）的译法。">c</a></sup>那里听见，毁灭全地的定旨已经定了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 1:2; 耶利米书 22:29; 启示录 2:11"> 你们要侧耳，听我的声音！要留心，听我的话语！</span>
<span className="v" id="v24" data-v="24" data-xref="耶利米书 4:3; 何西阿 10:11–12"> 那为撒种而耕地的人，岂会不停地耕吗？他岂会一直翻土、打碎土块吗？</span>
<span className="v" id="v25" data-v="25" data-xref="以西结 4:9; 马太福音 23:23; 出埃及记 9:31–32"> 他把地面整平以后，岂不是撒上莳萝，播下孜然，按行种小麦，在指定之处种大麦，在它的地方种粗麦吗？</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 31:3–6; 出埃及记 36:2; 约伯记 39:17"> 因为他的上帝教导他正确的判断，指教他。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 41:15; 以赛亚书 27:7–8; 耶利米书 46:28"> 莳萝不是用尖利的器具打出来的，孜然也不是用车轮碾过的；莳萝是用杖打出来，孜然是用棍打出来。</span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 9:9–10; 马太福音 3:12; 约翰福音 12:24"> 做饼用的粮食必须磨碎；所以他不会一直打它。虽然他让打谷车的轮子碾过它，他的马却不会把它磨碎。</span>
<span className="v" id="v29" data-v="29" data-xref="罗马书 11:33; 耶利米书 32:19; 约伯记 5:9"> 这也是出于万军之耶和华；祂的谋略奇妙，智慧卓越。</span>
</div>

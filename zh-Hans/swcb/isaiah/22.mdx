<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="耶利米书 21:13; 诗篇 125:2; 约珥 3:12"> 关于异象谷的默示。<br />你现在怎么了，竟全都上了房顶呢？</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 32:13; 以赛亚书 23:7; 耶利米哀歌 2:20"> 你这充满喧嚷、喧闹的城、欢乐的镇啊，你被杀的人不是被刀杀的，也不是死在战场上。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪下 25:4–7; 以赛亚书 3:1–8; 耶利米书 39:4–7"> 你所有的官长一同逃跑，却被弓箭手捆绑；凡在你那里被找到的，都一同被捆绑；他们逃到远方。</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 9:1; 马太福音 2:18; 诗篇 77:2"> 所以我说：“不要看我；我要痛哭。不要竭力安慰我，因为我百姓的女子遭毁灭。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="弥迦书 7:4; 以赛亚书 37:3; 路加福音 23:30"> 因为这是主万军之耶和华<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="在英文中以全大写呈现的“LORD”或“GOD”，是上帝专有名的译法（希伯来文“יהוה”，通常读作雅威）。">a</a></sup>所定的日子，在异象谷中有混乱、践踏和困惑，有城墙被攻破，有向群山呼喊的声音。”</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 16:9; 以赛亚书 21:2; 阿摩司 1:5"> 以拦带着箭袋，率领战车上的人和骑兵；吉珥揭开盾牌。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 8:7–8; 以赛亚书 10:28–32; 耶利米书 39:1–3"> 你最肥美的山谷满了战车，骑兵在城门前列阵。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 7:2; 列王纪上 10:17; 以赛亚书 36:1–3"> 祂揭去了犹大的遮盖；那日，你仰望森林宫里的兵器。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪下 20:20; 尼希米记 3:16; 历代志下 32:1–6"> 你们看见大卫城的破口很多，就聚集下池的水。</span>
<span className="v" id="v10" data-v="10"> 你们数点耶路撒冷的房屋，拆毁房屋来加固城墙。</span>
<span className="v" id="v11" data-v="11" data-xref="弥迦书 7:7; 耶利米书 33:2–3; 以赛亚书 31:1"> 你们又在两道城墙之间造了水库，用来储存旧池的水；却没有仰望成就这事的那一位，也没有尊重从古时筹划这事的那一位。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约珥 2:17; 弥迦书 1:16; 约珥 1:13"> 那日，主万军之耶和华<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="在英文中以全大写呈现的“LORD”或“GOD”，是上帝专有名的译法（希伯来文“יהוה”，通常读作雅威）。">b</a></sup>呼召人哭泣、哀号、剃头、披麻；</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 56:12; 哥林多前书 15:32; 路加福音 17:26–29"> 看哪，竟是欢喜快乐，宰牛杀羊，吃肉喝酒，说：“我们吃喝吧，因为明天我们就要死了。”</span>
<span className="v" id="v14" data-v="14" data-xref="以西结 24:13; 撒母耳记上 3:14; 以赛亚书 5:9"> 万军之耶和华<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="在英文中以全大写呈现的“LORD”或“GOD”，是上帝专有名的译法（希伯来文“יהוה”，通常读作雅威）。">c</a></sup>在我耳中启示说：“这罪孽直到你们死也必不得赦免。”这是主万军之耶和华说的。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 36:3; 列王纪下 18:18; 列王纪下 19:2"> 主万军之耶和华说：“去，到这位管库的舍伯那那里，就是管理王宫的，对他说：</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 27:60; 历代志下 16:14; 撒母耳记下 18:18"> 『你在这里做什么？你在这里有谁，竟在这里为自己凿坟墓呢？』他竟在高处为自己凿坟墓，在磐石中为自己雕出住处！</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 14:3; 约伯记 9:24; 以斯帖记 7:8"> 看哪，耶和华必胜过你，猛烈地把你掷出去；是的，祂必牢牢抓住你。</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 17:13; 阿摩司 7:17"> 祂必将你卷了又卷，像球一样抛到宽阔之地。你必死在那里；你荣耀的战车也必在那里。你这使你主人家蒙羞的人啊！</span>
<span className="v" id="v19" data-v="19" data-xref="以西结 17:24; 诗篇 75:6–7; 约伯记 40:11–12"> 我必把你从你的职位上赶出去；你必从你的岗位上被拉下来。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 36:3; 列王纪下 18:18; 以赛亚书 37:2"> 到那日，我必召我的仆人希勒家的儿子以利亚敬，</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 45:8; 以赛亚书 9:6–7; 创世记 41:42–43"> 把你的袍子穿在他身上，用你的腰带束紧他；我必将你的权柄交在他手中。他必作耶路撒冷居民和犹大家的父。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 16:18–19; 启示录 3:7; 约伯记 12:14"> 我必将大卫家的钥匙放在他肩头上。他开了，无人能关；他关了，无人能开。</span>
<span className="v" id="v23" data-v="23" data-xref="以斯拉记 9:8; 约伯记 36:7; 撒迦利亚书 10:4"> 我必将他像钉子钉在稳固之处；他必成为他父家的荣耀宝座。</span>
<span className="v" id="v24" data-v="24" data-xref="但以理 6:1–3; 约翰福音 20:21–23; 马太福音 28:18"> 他们必把他父家一切荣耀都挂在他身上，就是后代和子孙，以及一切小器皿，从杯子直到各样罐子。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 46:11; 以斯帖记 9:24–25; 诗篇 146:3"> 万军之耶和华说：“到那日，那钉在稳固之处的钉子必松脱，必被砍下而坠落；挂在其上的重担必被剪除，因为耶和华已经说了。”</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 16:13; 诗篇 78:71; 撒母耳记上 9:16"> 撒母耳拿起一瓶油，倒在扫罗的头上，又亲吻他，说：“耶和华不是膏立你作祂产业的领袖吗？</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 9:3–5; 创世记 35:19–20; 约书亚记 18:28"> 你今天离开我以后，会在便雅悯境内的泄撒，靠近拉结的坟墓那里，遇见两个人。他们会告诉你：‘你去寻找的那些驴已经找到了；看哪，你父亲已经不再挂念那些驴，却为你担忧，说：“我为我的儿子该怎么办呢？”’”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 35:3; 创世记 35:1; 创世记 28:22"> “你从那里再往前走，会来到他泊的橡树那里；在那里会有三个人遇见你，他们正上伯特利去到上帝那里：一个带着三只小山羊，一个带着三个饼，另一个带着一袋酒。</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 18:15"> 他们会向你问安，给你两个饼，你要从他们手中接过来。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪下 3:15; 撒母耳记上 13:3; 撒母耳记上 19:20"> “此后你会来到上帝的山，那里有非利士人的驻防营。你到了那城的时候，会遇见一队先知从邱坛下来；他们前面有人拿着瑟、手鼓、笛子和琴，他们自己正在说预言。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 10:10; 撒母耳记上 19:23–24; 民数记 11:25"> 耶和华的灵必大大临到你，你就会和他们一同说预言，并且变成另一个人。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 6:12; 约书亚记 1:5; 以赛亚书 7:14"> 这些兆头临到你以后，你就要照当时合宜的去做，因为上帝与你同在。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 11:14–15; 撒母耳记上 13:4; 撒母耳记上 13:8–15"> “你要在我以先下到吉甲去；看哪，我要下到你那里献燔祭，又献平安祭。你要等候七天，直到我来到你那里，指示你应当做什么。”</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 38:7–8; 撒母耳记上 10:2–6; 士师记 7:11"> 事情果然如此：扫罗转身离开撒母耳的时候，上帝就赐给他另一颗心；那一天，所有这些兆头都应验了。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 10:5–6; 撒母耳记上 19:20–24"> 他们来到那山的时候，看哪，一队先知迎面遇见他；上帝的灵大大临到他，他就在他们中间说预言。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 19:24; 约翰福音 7:15; 马太福音 13:54–55"> 从前认识他的人看见了，看哪，他竟和先知一同说预言，众人就彼此说：“基士的儿子怎么了？扫罗也列在先知中吗？”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 54:13; 约翰福音 6:45; 雅各书 1:17"> 那地方有一个人回答说：“他们的父亲是谁呢？”因此这话成了俗语：“扫罗也列在先知中吗？”</span>
<span className="v" id="v13" data-v="13"> 扫罗说完预言，就来到邱坛。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 14:50; 列王纪下 5:25; 撒母耳记上 9:3–10"> 扫罗的叔叔问他和他的仆人：“你们到哪里去了？”<br />他说：“去找驴。我们见找不到，就去见撒母耳。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 扫罗的叔叔说：“请告诉我，撒母耳对你说了什么。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="箴言 29:11; 士师记 14:6; 撒母耳记上 9:20"> 扫罗对他的叔叔说：“他清楚告诉我们，驴已经找到了。”至于撒母耳所说有关王国的事，扫罗却没有告诉他。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="士师记 20:1; 撒母耳记上 7:5–6"> 撒母耳把百姓召集到米斯巴，到耶和华面前；</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 6:8–9; 尼希米记 9:27–28; 士师记 2:1"> 他对以色列子孙说：“耶和华——以色列的上帝这样说：‘我把以色列从埃及领上来，救你们脱离埃及人的手，又脱离一切欺压你们之国的手。’</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 12:12; 撒母耳记上 8:19; 约书亚记 24:1"> 但你们今天却弃绝了你们的上帝；祂亲自救你们脱离你们一切的灾难和困苦。你们对祂说：‘不！请立一个王治理我们！’现在，你们要按着支派、按着千人队，站在耶和华面前。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约书亚记 7:16–18; 使徒行传 1:24–26; 撒母耳记上 14:41"> 于是撒母耳使以色列众支派近前来，便雅悯支派被选中。</span>
<span className="v" id="v21" data-v="21"> 他使便雅悯支派按着宗族近前来，玛特利宗族被选中。然后基士的儿子扫罗被选中；可是众人寻找他，却找不着。</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 27:21; 士师记 20:18; 撒母耳记上 23:2–4"> 因此他们又求问耶和华：“还有人要到这里来吗？”<br />耶和华回答说：“看哪，他藏在行李中。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 9:2; 撒母耳记上 16:7; 撒母耳记上 17:4"> 他们就跑去，从那里把他带来。他站在百姓中间，从肩膀以上，比所有百姓都高。</span>
<span className="v" id="v24" data-v="24" data-xref="列王纪上 1:25; 列王纪上 1:39; 撒母耳记下 21:6"> 撒母耳对全体百姓说：“你们看见耶和华所拣选的人了吗？在众百姓中没有一个像他的。”<br />全体百姓就欢呼说：“愿王万岁！”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 8:11–18; 申命记 17:14–20; 罗马书 13:1–7"> 撒母耳把王国的规章告诉百姓，又写在书上，放在耶和华面前。然后撒母耳遣散众百姓，各人回自己的家去。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记上 11:4; 约书亚记 18:28; 撒母耳记上 15:34"> 扫罗也回到他在基比亚的家；有一支军队与他同去，他们的心是上帝所感动的。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 13:13; 历代志下 17:5; 列王纪上 10:25"> 但有些无赖之徒说：“这个人怎能拯救我们呢？”他们藐视他，没有给他带礼物；但扫罗默不作声。</span>
</div>

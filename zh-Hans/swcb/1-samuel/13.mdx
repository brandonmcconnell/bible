<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 12:5; 弥迦书 6:6"> 扫罗登基的时候三十岁；他作以色列王四十二年。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="传统希伯来文本省略了“三十”和“四十”。这里根据少数七十士译本抄本补上空缺。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 10:26; 撒母耳记上 13:5; 撒母耳记上 14:31"> 扫罗从以色列人中为自己挑选了三千人：其中两千人与扫罗在密抹和伯特利山地，一千人与约拿单在便雅悯的基比亚。其余的百姓，扫罗都打发他们各自回帐棚去了。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 10:5; 士师记 3:27; 士师记 6:34"> 约拿单攻击在迦巴的非利士人驻军，非利士人听见了。扫罗就在全地吹角，说：“让希伯来人听见！”</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 34:30; 出埃及记 5:21; 撒迦利亚书 11:8"> 以色列众人听见扫罗攻击了非利士人的驻军，也听见以色列人在非利士人眼中成了可憎恶的。百姓就聚集到吉甲，跟随扫罗。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 14:23; 约书亚记 11:4; 约书亚记 18:12"> 非利士人聚集起来，要与以色列争战；他们有战车三万辆，骑兵六千，百姓多得像海边的沙。他们上来，在伯亚文以东的密抹安营。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 6:2; 希伯来书 11:38; 士师记 10:9"> 以色列人看见自己处境危急，因为百姓受了困迫，就藏在洞穴、丛林、岩石、坟墓和坑里。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 20:8; 利未记 26:17; 民数记 32:1–5"> 有些希伯来人已经过了约旦河，到了迦得和基列地；至于扫罗，他仍在吉甲，所有跟随他的百姓都战战兢兢。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 10:8"> 扫罗等了七天，照撒母耳所定的日期；可是撒母耳没有到吉甲，百姓就离开扫罗四散了。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 3:4; 箴言 21:27; 箴言 15:8"> 扫罗说：“把燔祭和平安祭带到我这里来。”他就献上燔祭。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 15:13; 路得记 2:4; 诗篇 129:8"> 他刚献完燔祭，看哪，撒母耳就来了；扫罗出去迎接他，要向他问安。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 13:23; 撒母耳记上 13:5; 撒母耳记上 13:16"> 撒母耳说：“你做了什么？”<br />扫罗说：“因为我看见百姓离开我四散，你又没有在所定的日子内来到，而且非利士人聚集在密抹，</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 66:3; 阿摩司 8:5; 哥林多后书 9:7"> 所以我说：‘现在非利士人必下到吉甲来攻击我，而我还没有求耶和华施恩。’因此我勉强自己，献上了燔祭。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 15:22; 历代志下 16:9; 撒母耳记上 15:28"> 撒母耳对扫罗说：“你做了愚昧的事。你没有遵守耶和华你上帝所吩咐你的命令；因为如今耶和华本要使你的国在以色列中永远坚立。</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 13:22; 撒母耳记上 15:28; 诗篇 89:19–37"> 但现在你的国必不能继续。耶和华已经为自己寻得一个合祂心意的人，耶和华已经指定他作祂百姓的领袖，因为你没有遵守耶和华所吩咐你的。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 14:2; 撒母耳记上 13:2; 撒母耳记上 13:6–7"> 撒母耳起身，从吉甲往便雅悯的基比亚去。扫罗数点跟他在一起的百姓，约有六百人。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 13:3"> 扫罗和他儿子约拿单，以及跟他们在一起的百姓，都住在便雅悯的迦巴；非利士人却在密抹安营。</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 18:23; 撒母耳记上 14:15; 约书亚记 19:3"> 有掠兵从非利士人的营中出来，分成三队：一队转向通往俄弗拉、到书亚地的路；</span>
<span className="v" id="v18" data-v="18" data-xref="尼希米记 11:34; 约书亚记 18:13–14; 约书亚记 16:3"> 一队转向伯和仑的路；另一队转向边界的路，那边界俯瞰朝向旷野的洗波音谷。</span>
<span className="v" id="v19" data-v="19" data-xref="列王纪下 24:14; 士师记 5:8; 耶利米书 24:1"> 那时，以色列全地找不到一个铁匠，因为非利士人说：“免得希伯来人为自己制造刀或枪。”</span>
<span className="v" id="v20" data-v="20"> 所有以色列人都下到非利士人那里，各人去磨自己的犁头、镢头、斧头和镰刀。</span>
<span className="v" id="v21" data-v="21"> 磨镢头、犁头、叉、斧头和赶牛锥，每件的价钱是一派印<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一派印（或“皮姆”）是三分之二舍客勒银子，即0.26盎司，或7.6克。">b</a></sup>。</span>
<span className="v" id="v22" data-v="22" data-xref="士师记 5:8; 撒迦利亚书 4:6; 撒母耳记上 17:50"> 所以到了争战的日子，跟随扫罗和约拿单的百姓手中，没有一个人有刀有枪；惟有扫罗和他儿子约拿单有。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 10:28; 撒母耳记上 14:1; 撒母耳记上 14:4–5"> 非利士人的驻军出到密抹的隘口。</span>
</div>

<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 8:5; 撒母耳记上 8:1; 撒母耳记上 8:20"> 现在，看哪，王在你们前面行走。我已经年老发白了。看哪，我的儿子们也和你们在一起。我从幼年直到今日，都在你们前面行走。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 20:33; 民数记 16:15; 彼得前书 5:2"> 我在这里。你们要在耶和华和祂的受膏者面前作证指控我：我夺过谁的牛？夺过谁的驴？欺骗过谁？压迫过谁？我从谁手里收过贿赂，以致蒙蔽自己的眼睛呢？我必还给你们。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="但以理 6:4; 诗篇 37:5–6; 约翰三书 1:12"> 他们说：“你没有欺骗我们，也没有压迫我们，也没有从任何人手里拿过什么。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及记 22:4; 使徒行传 24:20; 使徒行传 23:9"> 他对他们说：“今日耶和华对你们作证，祂的受膏者也作证：你们在我手里没有查出什么。”<br />他们说：“祂作证。”</span>
<span className="v" id="v6" data-v="6" data-xref="弥迦书 6:4; 出埃及记 6:26; 诗篇 99:6"> 撒母耳对百姓说：“耶和华立了摩西和亚伦，又把你们的祖先从埃及地领上来。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 1:18; 弥迦书 6:1–5; 使徒行传 17:3"> 现在你们要站住，我要在耶和华面前，与你们辩明耶和华向你们和你们祖先所行的一切公义作为。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 4:14–16; 出埃及记 2:23–24; 诗篇 78:54–55"> “雅各进了埃及以后，你们的祖先呼求耶和华，耶和华就差遣摩西和亚伦；他们把你们的祖先从埃及领出来，使他们住在这地方。</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 13:1; 士师记 10:7; 士师记 3:12"> 但他们忘记了耶和华他们的上帝；祂就把他们交在夏琐军队的统帅西西拉手里，交在非利士人手里，又交在摩押王手里；这些人就攻击他们。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 10:10; 士师记 2:13; 士师记 3:7"> 他们呼求耶和华，说：‘我们有罪了，因为我们离弃耶和华，事奉诸巴力和亚斯她录；但现在求你救我们脱离仇敌的手，我们就事奉你。’</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 6:32; 士师记 4:6; 士师记 8:35"> 耶和华就差遣耶路巴力、比但、耶弗他和撒母耳，救你们脱离四围仇敌的手；你们就安然居住。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="士师记 8:23; 撒母耳记上 8:5–7; 创世记 17:7"> “你们看见亚扪人的王拿辖来攻击你们，就对我说：‘不，我们要有一位王治理我们，’其实耶和华你们的上帝原是你们的王。</span>
<span className="v" id="v13" data-v="13" data-xref="何西阿 13:11; 撒母耳记上 10:24; 撒母耳记上 8:5"> 现在，看哪，这就是你们所选择、所求的王。看哪，耶和华已经立了一位王治理你们。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 24:14; 申命记 28:1–14; 诗篇 81:12–15"> 如果你们敬畏耶和华，事奉祂，听从祂的声音，不背叛耶和华的命令，那么你们和治理你们的王就都要跟随耶和华你们的上帝。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 24:20; 以赛亚书 1:20; 以赛亚书 3:11"> 但如果你们不听从耶和华的声音，反而背叛耶和华的命令，那么耶和华的手就必攻击你们，像从前攻击你们的祖先一样。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及记 14:13; 出埃及记 14:31; 撒母耳记上 12:7"> “现在你们要站住，看耶和华在你们眼前所要行的这件大事。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 8:7; 箴言 26:1; 撒母耳记上 7:9–10"> 今天不是割麦子的时候吗？我要呼求耶和华，愿祂打雷降雨；你们就会知道并看见，你们求立一位王这事，在耶和华眼中所行的是大恶。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 14:31; 以斯拉记 10:9; 诗篇 106:12–13"> 于是撒母耳呼求耶和华，耶和华就在那一天打雷降雨。众百姓就极其惧怕耶和华和撒母耳。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及记 9:28; 约翰一书 5:16; 撒母耳记上 12:23"> 众百姓对撒母耳说：“求你为你的仆人们向耶和华你的上帝祷告，免得我们死亡；因为我们求立一位王，是在我们一切罪上又加了这恶。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命记 11:16; 约书亚记 23:6; 彼得前书 3:16"> 撒母耳对百姓说：“不要惧怕。你们确实行了这一切恶；然而不要转离，不跟随耶和华，只要全心事奉耶和华。</span>
<span className="v" id="v21" data-v="21" data-xref="哈巴谷 2:18; 耶利米书 10:15; 耶利米书 16:19"> 不要转离去随从那些不能使人得益、也不能拯救人的虚无之物，因为它们本是虚无。</span>
<span className="v" id="v22" data-v="22" data-xref="申命记 7:7–8; 申命记 14:2; 诗篇 106:8"> 耶和华为祂大名的缘故，必不撇弃祂的百姓，因为耶和华乐意使你们成为属祂自己的百姓。</span>
<span className="v" id="v23" data-v="23" data-xref="歌罗西书 1:9; 罗马书 1:9; 提摩太后书 1:3"> 至于我，若停止为你们祷告，愿这事远离我，免得我得罪耶和华；我却要将善而正的道路指教你们。</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 10:21; 箴言 1:7; 以赛亚书 5:12"> 只要敬畏耶和华，诚诚实实、全心事奉祂；因为你们要思想祂为你们行了何等大的事。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 24:20; 何西阿 10:3; 撒母耳记上 31:1–5"> 但如果你们仍然作恶，你们和你们的王都必灭亡。”</span>
</div>

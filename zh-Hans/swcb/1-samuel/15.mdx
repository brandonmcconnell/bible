<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="1SA" data-book-slug="1-samuel" data-book-name="撒母耳记上" data-chapter="15" data-verses="35">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 9:16; 撒母耳记上 12:14; 诗篇 2:10–11"> 撒母耳对扫罗说：“耶和华差遣我膏立你作祂百姓以色列的王。所以现在，你要听耶和华话语的声音。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 25:17–19; 出埃及记 17:8–16; 民数记 24:20"> 万军之耶和华如此说：‘亚玛力怎样在以色列从埃及上来的路上抵挡他，我都记得。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 20:16–18; 民数记 24:20; 民数记 31:17"> 现在你要去攻击亚玛力，将他们所有的一切尽行毁灭，不可怜惜他们；要把男人、女人、婴孩和吃奶的孩子、牛和羊、骆驼和驴都杀死。’”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约书亚记 15:24; 撒母耳记上 11:8; 撒母耳记上 13:15"> 扫罗召集百姓，在提拉因数点他们，共有步兵二十万，犹大人一万。</span>
<span className="v" id="v5" data-v="5"> 扫罗来到亚玛力的城，在谷中设下埋伏。</span>
<span className="v" id="v6" data-v="6" data-xref="士师记 1:16; 民数记 10:29–32; 出埃及记 18:19"> 扫罗对基尼人说：“你们离开吧，从亚玛力人中间下去，免得我把你们和他们一同毁灭；因为以色列众子民从埃及上来的时候，你们曾以恩慈待他们。”于是基尼人从亚玛力人中间离开了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="创世记 16:7; 创世记 25:18; 撒母耳记上 14:48"> 扫罗击杀亚玛力人，从哈腓拉直到通往书珥的路，书珥在埃及对面。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 30:1; 以斯帖记 3:1; 民数记 24:7"> 他活捉了亚玛力人的王亚甲，又用刀锋将所有百姓尽行毁灭。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 15:15; 撒母耳记上 15:19; 撒母耳记上 15:3"> 但是扫罗和百姓却怜惜亚甲，以及羊群、牛群、肥畜、羊羔中最好的，和一切美好的，不肯将它们尽行毁灭；凡卑劣无用的，他们都尽行毁灭了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 耶和华的话临到撒母耳，说：</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 13:13; 创世记 6:6; 撒母耳记下 24:16"> “我为立扫罗作王而忧伤，因为他转离不跟随我，没有履行我的命令。”撒母耳愤怒，就整夜向耶和华呼求。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约书亚记 15:55; 撒母耳记下 18:18; 撒母耳记上 25:2"> 撒母耳清早起来，要去迎见扫罗；有人告诉撒母耳说：“扫罗到了迦密，看哪，他为自己立了纪念碑，然后转身经过那里，下到吉甲去了。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="士师记 17:2; 路得记 3:10; 箴言 31:31"> 撒母耳来到扫罗那里；扫罗对他说：“愿你蒙耶和华赐福！我已经履行了耶和华的命令。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 3:13–15; 耶利米书 2:18–19; 耶利米书 2:34–37"> 撒母耳说：“那么，我耳中听见的这羊叫和牛鸣是什么意思呢？”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 15:21; 撒母耳记上 15:9; 出埃及记 32:22–23"> 扫罗说：“这些是他们从亚玛力人那里带来的；因为百姓怜惜羊群和牛群中最好的，要献给耶和华你的上帝。其余的，我们已经尽行毁灭了。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 9:27; 列王纪上 22:16; 撒母耳记上 12:7"> 撒母耳对扫罗说：“且住，我要把耶和华昨夜对我说的话告诉你。”<br />他说：“请说。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 10:22; 撒母耳记上 9:21; 撒母耳记上 15:1–3"> 撒母耳说：“你在自己眼中虽是微小，岂不是被立为以色列各支派的元首吗？耶和华膏立你作以色列的王；</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 10:29; 创世记 13:13; 创世记 15:16"> 耶和华差遣你上路，说：‘你去，将那些罪人亚玛力人尽行毁灭，与他们争战，直到他们灭绝。’</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 14:32; 历代志下 33:6; 历代志下 36:12"> 你为什么没有听从耶和华的声音，反而夺取掠物，行耶和华眼中看为恶的事呢？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 15:13; 马太福音 19:20; 罗马书 10:3"> 扫罗对撒母耳说：“我确实听从了耶和华的声音，走了耶和华差遣我走的路，带回了亚玛力王亚甲，也将亚玛力人尽行毁灭了。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 15:15; 出埃及记 32:22–23; 创世记 3:13"> 只是百姓从掠物中取了羊和牛，就是当灭之物中最好的，要在吉甲献给耶和华你的上帝。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="何西阿 6:6; 诗篇 51:16–17; 箴言 21:3"> 撒母耳说：“耶和华喜悦燔祭和祭物，岂如喜悦人听从耶和华的声音呢？看哪，听从胜于献祭；侧耳听命胜于公绵羊的脂油。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 28:16; 撒母耳记上 13:14; 利未记 20:6"> 因为悖逆与行巫术的罪相同，顽梗与偶像崇拜和特拉芬一样。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="特拉芬是家庭神像，可能与家庭财产的继承权有关。">a</a></sup>因为你厌弃了耶和华的话，祂也厌弃你作王。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒母耳记下 12:13; 以赛亚书 51:12–13; 民数记 22:34"> 扫罗对撒母耳说：“我犯了罪；因为我惧怕百姓，听从了他们的声音，就违背了耶和华的命令和你的话。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 10:17"> 现在，求你赦免我的罪，同我回去，好让我敬拜耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="何西阿 4:6; 撒母耳记上 13:14; 撒母耳记上 16:1"> 撒母耳对扫罗说：“我不同你回去；因为你厌弃了耶和华的话，耶和华也厌弃你，不让你作以色列的王。”</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 11:30–31"> 撒母耳转身要走，扫罗抓住他外袍的衣襟，衣襟就撕裂了。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 28:17–18; 使徒行传 13:22; 但以理 4:32"> 撒母耳对他说：“今日耶和华已经从你身上撕下以色列的国，把它赐给你的一位邻舍，他比你更好。</span>
<span className="v" id="v29" data-v="29" data-xref="以西结 24:14; 民数记 23:19; 提多书 1:2"> 并且，以色列的大能者不说谎，也不反悔；因为祂不是人，不致反悔。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="约翰福音 5:44; 约翰福音 12:43; 以赛亚书 29:13"> 他说：“我犯了罪；然而现在求你在我百姓的长老和以色列面前尊重我，同我回去，好让我敬拜耶和华你的上帝。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31"> 于是撒母耳跟随扫罗回去；扫罗就敬拜耶和华。</span>
<span className="v" id="v32" data-v="32" data-xref="启示录 18:7; 帖撒罗尼迦前书 5:3; 耶利米书 48:44"> 撒母耳说：“把亚玛力人的王亚甲带到我这里来！”<br />亚甲欢欢喜喜地来到他面前。亚甲说：“死亡的苦楚确实已经过去了。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="士师记 1:7; 创世记 9:6; 马太福音 7:2"> 撒母耳说：“你的刀怎样使妇人丧子，你的母亲在妇人中也必照样丧子！”于是撒母耳在吉甲，在耶和华面前把亚甲砍成碎块。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="撒母耳记上 11:4; 撒母耳记上 7:17"> 撒母耳往拉玛去了；扫罗也上自己的家，到扫罗的基比亚去了。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记上 15:11; 撒母耳记上 19:24; 撒母耳记上 16:1"> 直到撒母耳死的日子，撒母耳不再去见扫罗；但撒母耳为扫罗悲伤。耶和华也为立扫罗作以色列的王而忧伤。</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 16:18–19; 提摩太前书 5:21; 尼希米记 7:2"> 撒母耳年老的时候，立他的儿子作以色列的士师。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 6:38; 创世记 22:19; 历代志上 6:28"> 他的长子名叫约珥，次子名叫亚比亚；他们在别示巴作士师。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 16:19; 诗篇 15:5; 提摩太前书 6:10"> 他的儿子不行他的道路，反而偏向不义之财，收受贿赂，歪曲公正。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 7:17; 撒母耳记下 5:3; 出埃及记 3:16"> 于是，以色列的众长老聚集起来，到拉玛来见撒母耳。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 17:14–15; 何西阿 13:10–11; 撒母耳记上 8:6–8"> 他们对他说：“看哪，你已经年老，你的儿子不行你的道路。现在请为我们立一个王来治理我们，像列国一样。”</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 15:11; 雅各书 1:5; 撒母耳记上 12:17"> 他们说“请给我们一个王来治理我们”这话，使撒母耳不喜悦。<br />撒母耳就向耶和华祷告。</span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 10:16; 撒母耳记上 10:19; 出埃及记 16:8"> 耶和华对撒母耳说：“百姓对你所说的一切话，你只管听从；因为他们不是厌弃你，而是厌弃我，不要我作他们的王。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 106:34–40; 出埃及记 32:1; 士师记 13:1"> 自从我把他们从埃及领上来的那日直到今日，他们所行的一切事，都是离弃我，事奉别神；他们现在待你也是这样。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 10:25; 撒母耳记上 8:11–18; 以西结 46:18"> 现在你只管听从他们的话；然而你要严肃地警告他们，把将来治理他们的王的作法指示他们。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 撒母耳就把耶和华的一切话告诉那些向他求王的百姓。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 14:52; 申命记 17:14–20; 撒母耳记上 10:25"> 他说：“将来治理你们的王，他的作法必是这样：他会带走你们的儿子，派他们为他驾车，作他的马兵，在他的战车前奔跑；</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 22:7; 列王纪上 4:7; 历代志上 27:1–22"> 又会为自己任命千夫长、五十夫长；派人耕种他的田地，收割他的庄稼，制造他的兵器和战车的器具。</span>
<span className="v" id="v13" data-v="13"> 他会带走你们的女儿，使她们作调香的、烹调的、烤饼的。</span>
<span className="v" id="v14" data-v="14" data-xref="以西结 46:18; 列王纪上 21:7; 列王纪上 21:19"> 他会夺取你们的田地、葡萄园和橄榄园中最好的，赐给他的臣仆。</span>
<span className="v" id="v15" data-v="15" data-xref="但以理 1:3; 以赛亚书 39:7; 创世记 37:36"> 他会取你们的种子和葡萄园的十分之一，赐给他的官员和臣仆。</span>
<span className="v" id="v16" data-v="16"> 他会带走你们的男仆、女仆、最好的青年和驴，派他们作他自己的工。</span>
<span className="v" id="v17" data-v="17"> 他会取你们羊群的十分之一；你们也必作他的仆人。</span>
<span className="v" id="v18" data-v="18" data-xref="弥迦书 3:4; 以赛亚书 1:15; 箴言 1:25–28"> 到那日，你们必因自己所选择的王哀求；但耶和华到那日必不应允你们。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="耶利米书 44:16; 耶利米书 7:13; 以赛亚书 66:4"> 可是百姓不肯听撒母耳的话；他们说：“不！我们一定要有一个王治理我们，</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 8:5; 诗篇 106:35; 申命记 7:6"> 好使我们也像列国一样；让我们的王治理我们，走在我们前面，为我们争战。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="士师记 11:11"> 撒母耳听见百姓的一切话，就把这些话陈明在耶和华耳中。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 8:7; 何西阿 13:11"> 耶和华对撒母耳说：“你只管听从他们的话，为他们立一个王。”<br />撒母耳对以色列人说：“你们各自回自己的城去吧。”</span>
</div>
</div>

</div>

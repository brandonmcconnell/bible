<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪下 9:1; 撒母耳记上 15:23; 诗篇 78:68–71"> 耶和华对撒母耳说：“我既然已经弃绝扫罗作以色列的王，你还要为他哀伤多久呢？把你的角装满油，去吧。我要差你到伯利恒人耶西那里，因为我已在他的儿子中为自己预备了一个王。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 9:12; 撒母耳记上 20:29; 马太福音 10:16"> 撒母耳说：“我怎么能去呢？扫罗若听见了，就会杀我。”<br />耶和华说：“你带一头母牛犊去，说：‘我来是要向耶和华献祭。’</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 9:16; 撒母耳记上 16:12–13; 撒母耳记下 15:11"> 你要请耶西来赴祭，我会指示你当做的事。我要指名给你的人，你要为我膏他。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪上 2:13; 历代志上 12:17–18; 撒母耳记上 21:1"> 撒母耳就照耶和华所说的去做，来到伯利恒。城里的长老战战兢兢地出来迎接他，说：“你是为平安而来吗？”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约书亚记 3:5; 利未记 20:7–8; 出埃及记 19:10"> 他说：“是为平安而来；我是来向耶和华献祭的。你们要自洁，跟我来赴祭。”他使耶西和他的儿子们自洁，请他们来赴祭。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 17:13; 历代志上 2:13; 撒母耳记上 17:22"> 他们来的时候，撒母耳看见以利押，就说：“在耶和华面前的，必定是祂的受膏者。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约翰福音 7:24; 耶利米书 17:10; 路加福音 16:15"> 但耶和华对撒母耳说：“不要看他的外貌，也不要看他身材高大，因为我已经弃绝他；我不像人那样看。人看外貌，耶和华却看内心。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 17:13; 历代志上 2:13"> 于是耶西叫亚比拿达来，使他从撒母耳面前经过。撒母耳说：“耶和华也没有拣选这一个。”</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 17:13; 历代志上 2:13; 撒母耳记下 13:3"> 耶西又使沙玛经过。撒母耳说：“耶和华也没有拣选这一个。”</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 2:13–15"> 耶西使他的七个儿子都从撒母耳面前经过。撒母耳对耶西说：“耶和华没有拣选这些人。”</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 78:70–71; 撒母耳记下 7:8; 撒母耳记下 13:3"> 撒母耳对耶西说：“你的孩子都在这里了吗？”<br />他说：“还剩下最小的。看哪，他正在牧羊。”<br />撒母耳对耶西说：“派人去把他带来；他不到这里来，我们就不坐下。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="耶利米哀歌 4:7; 诗篇 89:19–20; 雅歌 5:10"> 耶西就派人去把他带进来。他面色红润，脸庞俊美，容貌美好。耶和华说：“起来！膏他，因为就是这个人。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 10:6; 希伯来书 1:9; 约翰福音 3:34"> 于是撒母耳拿起盛油的角，在他的兄弟们中间膏了他。从那日起，耶和华的灵大大降在大卫身上。随后撒母耳起身去了拉玛。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 51:11; 撒母耳记上 18:12; 士师记 9:23"> 耶和华的灵离开了扫罗，有一个从耶和华那里来的邪灵搅扰他。</span>
<span className="v" id="v15" data-v="15"> 扫罗的臣仆对他说：“看哪，有一个从上帝那里来的邪灵搅扰你。</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪下 3:15; 列王纪上 10:8; 撒母耳记上 19:9"> 请我主吩咐侍立在你面前的臣仆，去寻找一个善于弹琴的人。这样，当从上帝那里来的邪灵临到你身上时，他就用手弹琴，你就会好起来。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 扫罗对他的臣仆说：“你们给我找一个弹得好的人，带到我这里来。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 3:19; 创世记 39:23; 创世记 39:2"> 其中一个少年人回答说：“看哪，我见过伯利恒人耶西的一个儿子，他善于弹奏，是大有勇力的人，是战士，说话谨慎，容貌俊美；耶和华也与他同在。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 16:11; 撒母耳记上 17:15; 诗篇 78:70–72"> 因此，扫罗派使者去见耶西，说：“把你那与羊群在一起的儿子大卫送到我这里来。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 10:27; 箴言 18:16; 撒母耳记上 17:18"> 耶西拿了一头驴，驮着饼、一皮袋酒和一只山羊羔，由他儿子大卫送给扫罗。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 41:46; 箴言 22:29; 诗篇 146:3"> 大卫来到扫罗那里，侍立在他面前。扫罗非常爱他，他就作了扫罗拿兵器的人。</span>
<span className="v" id="v22" data-v="22"> 扫罗派人去见耶西，说：“请让大卫侍立在我面前，因为他在我眼前蒙了恩。”</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 16:14–16; 撒母耳记上 18:10–11; 路加福音 11:24–26"> 每当从上帝那里来的灵临到扫罗身上，大卫就拿琴，用手弹奏；扫罗便舒畅好转，那邪灵也离开了他。</span>
</div>
</div>

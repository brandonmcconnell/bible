<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="路加福音 1:46–56; 诗篇 13:5; 以赛亚书 12:2–3"> 哈拿祷告说：<br /><span className="pl pl-1">“我的心因耶和华而欢欣！</span><br /><span className="pl pl-2">我的角因耶和华而高举。</span><br /><span className="pl pl-1">我的口向我的仇敌张开，</span><br /><span className="pl pl-2">因为我因你的救恩而喜乐。</span></span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 22:32; 以赛亚书 44:6; 诗篇 86:8"> <span className="pl pl-1">没有人像耶和华那样圣洁，</span><br /><span className="pl pl-2">因为除你以外没有别的；</span><br /><span className="pl pl-2">也没有磐石像我们的上帝。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="箴言 8:13; 列王纪上 8:39; 箴言 24:12"> <span className="pl pl-1">“不要再说极其骄傲的话。</span><br /><span className="pl pl-2">不要让傲慢从你们口中出来，</span><br /><span className="pl pl-2">因为耶和华是有知识的上帝；</span><br /><span className="pl pl-2">行为都由祂衡量。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="诗篇 76:3; 诗篇 37:15; 诗篇 46:9"> <span className="pl pl-1">“勇士的弓都折断了；</span><br /><span className="pl pl-2">绊跌的人却以力量为腰带。</span></span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 15:9; 路加福音 1:53; 诗篇 113:9"> <span className="pl pl-1">饱足的人为饼把自己雇出去；</span><br /><span className="pl pl-2">饥饿的人却不再饥饿。</span><br /><span className="pl pl-1">是的，不生育的生了七个；</span><br /><span className="pl pl-2">多有儿女的却衰弱。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="申命记 32:39; 以赛亚书 26:19; 启示录 1:18"> <span className="pl pl-1">“耶和华使人死，也使人活；</span><br /><span className="pl pl-2">祂使人下到阴间</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="阴间是死人所在之处。">a</a></sup><br /><span className="pl pl-2">，也使人上来。</span></span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 75:7; 约伯记 5:11; 申命记 8:17–18"> <span className="pl pl-1">耶和华使人贫穷，也使人富足；</span><br /><span className="pl pl-2">祂使人降卑，也使人升高。</span></span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 113:7–8; 但以理 2:48; 雅各书 2:5"> <span className="pl pl-1">祂从尘土中抬举贫寒人，</span><br /><span className="pl pl-2">从粪堆中提拔穷乏人，</span><br /><span className="pl pl-2">使他们与王子同坐，</span><br /><span className="pl pl-2">承受荣耀的宝座。</span><br /><span className="pl pl-1">因为地的柱子属于耶和华；</span><br /><span className="pl pl-2">祂把世界立在其上。</span></span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 121:3; 诗篇 91:11–12; 诗篇 33:16–17"> <span className="pl pl-1">祂必保守祂圣民的脚步，</span><br /><span className="pl pl-2">但恶人必在黑暗中沉默；</span><br /><span className="pl pl-2">因为人不能靠力量得胜。</span></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 2:9; 诗篇 89:24; 诗篇 18:13–14"> <span className="pl pl-1">与耶和华相争的人必被打碎；</span><br /><span className="pl pl-2">祂必从天上向他们打雷。</span><br /><span className="pl pl-1">“耶和华必审判地极；</span><br /><span className="pl pl-2">祂必赐力量给祂的王，</span><br /><span className="pl pl-2">高举祂受膏者的角。”</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 3:1; 撒母耳记上 2:18; 撒母耳记上 1:28"> 以利加拿回拉玛，到自己的家去了。那孩子在以利祭司面前事奉耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="罗马书 1:28–30; 耶利米书 2:8; 士师记 2:10"> 以利的儿子是恶人；他们不认识耶和华。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 7:29–34"> 祭司对待百姓的规矩是这样：每逢有人献祭，肉还在煮的时候，祭司的仆人就来，手里拿着三齿叉；</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 29:27–28; 以赛亚书 56:11; 撒母耳记上 2:29"> 他把叉子插进盆、锅、釜或鼎里。叉子带上来的，祭司都取为己有。凡来到示罗的以色列人，他们都这样对待。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 3:16; 利未记 3:3–5; 罗马书 16:18"> 是的，在脂肪还没有焚烧以前，祭司的仆人就来，对献祭的人说：“把肉给祭司去烤吧；因为他不要从你那里收煮过的肉，只要生的。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="利未记 7:23–25; 利未记 3:16; 彼得前书 5:2–3"> 如果那人对他说：“应该先焚烧脂肪，然后你可以照你心里想要的拿。”他就说：“不，你现在就要给我；不然，我就要强抢。”</span>
<span className="v" id="v17" data-v="17" data-xref="玛拉基书 2:7–9; 创世记 13:13; 玛拉基书 2:13"> 这些年轻人在耶和华面前的罪非常大；因为他们藐视耶和华的供物。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 3:1; 出埃及记 28:4; 撒母耳记上 2:11"> 但撒母耳还是个孩子，穿着细麻布以弗得，在耶和华面前事奉。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 1:3; 撒母耳记上 1:21; 出埃及记 23:14"> 此外，他母亲每年为他做一件小袍子，和丈夫上来献年祭的时候带给他。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 1:27–28; 路加福音 2:34; 路得记 4:11"> 以利为以利加拿和他的妻子祝福，说：“愿耶和华从这妇人给你后代<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或译：种子">b</a></sup>，补偿她向耶和华所求的。”随后他们回到自己的家。</span>
<span className="v" id="v21" data-v="21" data-xref="路加福音 2:40; 撒母耳记上 3:19; 创世记 21:1"> 耶和华眷顾哈拿，她就怀孕，生了三个儿子、两个女儿。孩子撒母耳在耶和华面前长大。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及记 38:8; 撒母耳记上 2:13–17; 耶利米书 7:9–10"> 以利年纪非常老了；他听见他儿子们怎样待全以色列人，又听见他们与在会幕门口服事的妇人同寝。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 8:12; 腓立比书 3:19; 使徒行传 9:4"> 他对他们说：“你们为什么做这样的事呢？因为我从这众百姓那里听见你们的恶行。</span>
<span className="v" id="v24" data-v="24" data-xref="玛拉基书 2:8; 提摩太前书 3:7; 使徒行传 6:3"> 我儿啊，不可这样；我听见的传闻不好！你们使耶和华的百姓悖逆。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 3:14; 约书亚记 11:20; 希伯来书 10:26"> 人若得罪人，上帝会审判他；人若得罪耶和华，谁能为他代求呢？”然而他们不听父亲的话，因为耶和华定意要杀他们。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 2:52; 路加福音 2:40; 使徒行传 2:47"> 孩子撒母耳渐渐长大，越发蒙耶和华和人喜爱。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="申命记 33:1; 出埃及记 4:27; 出埃及记 4:14–16"> 有一个上帝的人来到以利那里，对他说：“耶和华这样说：‘你父家在埃及受法老家奴役的时候，我不是向他们显现了吗？</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 28:1; 利未记 8:7–8; 民数记 18:19"> 我不是从以色列众支派中拣选他作我的祭司，使他上我的祭坛，烧香，在我面前穿以弗得吗？我不是把以色列子孙一切火祭的供物都赐给你父家了吗？</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 10:37; 申命记 32:15; 撒母耳记上 2:13–17"> 我在我居所中所吩咐的祭物和供物，你们为什么践踏呢？你为什么尊重你的儿子过于尊重我，用我百姓以色列一切供物中最好的使自己肥胖呢？’</span>
<span className="v" id="v30" data-v="30" data-xref="约翰福音 12:26; 耶利米书 18:9–10; 箴言 3:9–10"> “因此，耶和华以色列的上帝说：‘我确曾说，你的家和你父的家必永远行在我面前。’但现在耶和华说：‘我绝不这样；因为尊重我的，我必尊重他；藐视我的，必被咒诅。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记上 22:17–20; 列王纪上 2:26–27; 诗篇 37:17"> 看哪，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“看哪”源自“הִנֵּה”，意思是看、留意、观察、观看或凝视，常用作感叹语。">c</a></sup>日子将到，我要砍断你的膀臂和你父家的膀臂，使你家中没有老年人。</span>
<span className="v" id="v32" data-v="32" data-xref="撒迦利亚书 8:4; 撒母耳记上 4:11; 诗篇 78:59–64"> 在我赐给以色列的一切丰富中，你必看见我居所遭患难。你家中永远不会有老年人。</span>
<span className="v" id="v33" data-v="33" data-xref="列王纪上 2:26–27; 列王纪上 1:7; 撒母耳记上 22:21–23"> 你家中我没有从我祭坛前剪除的那人，必使你的眼睛消耗<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或译：使你的眼睛因泪而昏花">d</a></sup>，使你的心忧伤。你家中所增添的人都必死在壮年。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记上 4:11; 列王纪上 13:3; 撒母耳记上 4:17"> 临到你两个儿子何弗尼和非尼哈的事，必成为给你的预兆：他们二人必在同一天死去。</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 7:27; 撒母耳记下 7:11; 列王纪上 11:38"> 我要为自己兴起一位忠信的祭司；他必照我心中和意念中所想的去行。我要为他建立稳固的家；他必永远行在我的受膏者面前。</span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 2:27; 玛拉基书 1:13; 以西结 44:10–12"> 你家中剩下的人都必来向他下拜，为得一块银子和一个饼，说：“求你把我安置在祭司的一个职分里，好让我吃一口饼。”’”</span>
</div>
</div>

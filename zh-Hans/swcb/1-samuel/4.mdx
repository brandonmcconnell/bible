<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 29:1; 撒母耳记上 7:12; 撒母耳记上 5:1"> 撒母耳的话传到全以色列。<br />以色列出去与非利士人交战，安营在以便以谢旁边；非利士人安营在亚弗。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米哀歌 3:40; 撒母耳记上 17:8; 约书亚记 7:5–8"> 非利士人摆阵攻击以色列。双方交战的时候，以色列被非利士人击败；非利士人在战场上杀了约四千名以色列军兵。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太后书 3:5; 民数记 10:35; 哥林多前书 10:1–5"> 百姓回到营中，以色列的长老说：“耶和华今天为什么使我们败在非利士人面前呢？让我们从示罗把耶和华的约柜取来，带到我们这里，使它来到我们中间，救我们脱离仇敌的手。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 6:2; 民数记 7:89; 诗篇 80:1"> 于是百姓派人到示罗，从那里把万军之耶和华的约柜带来；耶和华坐在基路伯之上。以利的两个儿子何弗尼和非尼哈也在那里，与上帝的约柜同在。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 6:5; 约伯记 20:5; 阿摩司 6:3"> 耶和华的约柜进营的时候，全以色列大声欢呼，地也震动。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 32:17–18"> 非利士人听见欢呼的声音，就说：“希伯来人营中这大声欢呼是什么意思？”他们知道耶和华的柜进了营。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 32:30; 出埃及记 14:25; 出埃及记 15:14–16"> 非利士人就害怕，因为他们说：“上帝来到营中了。”他们又说：“我们有祸了！因为从前没有发生过这样的事。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 9:14; 出埃及记 7:5; 诗篇 78:43–51"> 我们有祸了！谁能救我们脱离这些大能神明的手呢？这些就是在旷野用各样灾祸击打埃及人的神明。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 16:13; 士师记 13:1; 撒母耳记下 10:12"> 非利士人哪，你们要刚强，要像男子汉，免得作希伯来人的奴仆，像他们作过你们的奴仆一样。你们要像男子汉一样刚强，要争战！”</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 26:17; 列王纪下 14:12; 申命记 28:25"> 非利士人争战，以色列就被击败，各人逃回自己的帐棚。那次杀戮极其惨重，以色列的步兵倒下了三万人。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 2:34; 诗篇 78:64; 撒母耳记上 2:32"> 上帝的柜被夺去；以利的两个儿子何弗尼和非尼哈也被杀了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约书亚记 7:6; 尼希米记 9:1; 撒母耳记下 15:32"> 有一个便雅悯人从军中跑出来，当天来到示罗，衣服撕裂，头上蒙灰。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 1:9; 撒母耳记上 4:18; 约书亚记 7:9"> 他来的时候，看哪，以利正坐在路旁自己的座位上观望，因为他的心为上帝的柜战抖。那人进城报信，全城就呼喊起来。</span>
<span className="v" id="v14" data-v="14"> 以利听见呼喊的声音，就说：“这喧嚷的声音是什么意思？”<br />那人急忙前来告诉以利。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 3:2; 诗篇 90:10; 列王纪上 14:4"> 那时以利九十八岁了。他眼目昏花，不能看见。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 1:4; 撒母耳记上 3:6; 约书亚记 7:19"> 那人对以利说：“我是从军中来的；我今天从军中逃出来。”<br />以利说：“我儿，事情怎样了？”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 3:11; 撒母耳记上 4:10–11"> 报信的人回答说：“以色列在非利士人面前逃跑，百姓中也遭了大屠杀。你的两个儿子何弗尼和非尼哈也都死了，上帝的柜也被夺去了。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 4:21–22; 彼得前书 4:17–18; 诗篇 69:9"> 他一提到上帝的柜，以利就从座位上往后跌倒，在门旁折断颈项而死；因为他年老，身体沉重。他作以色列的士师四十年。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19"> 他的儿媳、非尼哈的妻子怀孕，快要生产。她听见上帝的柜被夺去，以及她公公和丈夫都死了的消息，就屈身生产，因为产痛临到她。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 35:17–18; 诗篇 77:2; 约翰福音 16:21"> 她临死的时候，站在她旁边的妇人们对她说：“不要怕，因为你生了一个儿子。”她却不回答，也不放在心上。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 26:8; 耶利米书 2:11; 诗篇 78:61"> 她给孩子起名叫以迦博，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“以迦博”的意思是“无荣耀”。">a</a></sup>说：“荣耀离开以色列了！”这是因为上帝的柜被夺去，也因为她公公和丈夫的缘故。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 137:5–6; 约翰福音 2:17"> 她说：“荣耀离开以色列了，因为上帝的柜被夺去了。”</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 15:35; 历代志下 28:18; 历代志上 11:13"> 非利士人召集他们的军队，要来争战；他们聚集在属犹大的梭哥，安营在梭哥和亚西加之间的以弗·大悯。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 21:9; 撒母耳记上 17:19"> 扫罗和以色列人也聚集，安营在以拉谷，摆列阵势迎战非利士人。</span>
<span className="v" id="v3" data-v="3"> 非利士人站在这边山上，以色列人站在那边山上，中间有谷相隔。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 11:22; 撒母耳记下 21:16–22; 历代志上 20:4–8"> 有一个从非利士营中出来的勇士，名叫歌利亚，是迦特人；他身高六肘零一虎口<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘是人手臂从中指尖到肘部的长度，约18英寸或46厘米。一虎口是人手张开时从拇指尖到小指尖的长度（约半肘，即9英寸，或22.8厘米）。因此，歌利亚身高约9英尺9英寸，或2.97米。">a</a></sup>。</span>
<span className="v" id="v5" data-v="5"> 他头戴铜盔，身穿鳞甲；那甲重五千舍客勒<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一舍客勒约10克，或约0.35盎司，所以5000舍客勒约50公斤，或110磅。">b</a></sup>铜。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 17:45; 历代志下 9:15; 列王纪上 10:16"> 他腿上有铜护胫，两肩之间背着铜标枪。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 21:19; 撒母耳记上 17:41; 历代志上 11:23"> 他枪的杆粗如织布机的轴；枪头重六百舍客勒铁。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一舍客勒约10克，或约0.35盎司，所以600舍客勒约6公斤，或约13磅。">c</a></sup>拿盾牌的人走在他前面。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 8:17; 历代志上 21:3; 撒母耳记上 17:26"> 他站住，向以色列的军队呼喊，对他们说：“你们为什么出来摆列阵势呢？我不是非利士人吗？你们不是扫罗的仆人吗？你们为自己选一个人，让他下到我这里来。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 11:1"> 如果他能与我交战，把我杀死，我们就作你们的仆人；但如果我胜过他，把他杀死，你们就作我们的仆人，服侍我们。”</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 17:25–26; 撒母耳记上 17:45; 撒母耳记上 17:36"> 那非利士人又说：“我今天向以色列的军队挑战！给我一个人，好让我们彼此交战！”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约书亚记 1:9; 申命记 31:8; 箴言 28:1"> 扫罗和全以色列听见这非利士人的这些话，就惊惶，非常惧怕。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 16:10–11; 创世记 35:19; 撒母耳记上 16:18"> 大卫是犹大伯利恒的那个以法他人耶西的儿子；耶西有八个儿子。在扫罗的日子，那人已经年纪老迈。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 2:13; 撒母耳记下 21:21; 撒母耳记上 17:28"> 耶西三个最大的儿子已经跟随扫罗去打仗；他去打仗的三个儿子，名字是：长子以利押，其次亚比拿达，第三是沙玛。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 16:11; 创世记 25:23"> 大卫是最小的；三个最大的儿子跟随扫罗。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 16:11; 撒母耳记上 16:19–23"> 大卫却在扫罗那里和伯利恒之间往返，为父亲放羊。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马太福音 4:2; 路加福音 4:2"> 那非利士人早晚都上前来，站出来，共四十天。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 25:18; 撒母耳记下 17:28; 路得记 2:14"> 耶西对他儿子大卫说：“现在你拿一伊法<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="1伊法约22升，或约2/3蒲式耳。">d</a></sup>这些烘过的谷物和这十个饼，赶快送到营里给你的哥哥们；</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 37:14; 撒母耳记上 16:20; 撒母耳记下 17:29"> 再把这十块奶酪带给他们千夫长；看看你哥哥们好不好，并带回消息。”</span>
<span className="v" id="v19" data-v="19"> 那时扫罗和他们，以及以色列众人都在以拉谷，与非利士人交战。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 26:5; 路加福音 19:43; 以弗所书 6:1–2"> 大卫清早起来，把羊交给看守的人，照耶西吩咐他的，带着食物去了。他来到辎重营的时候，军兵正出阵迎战，呐喊着要交战。</span>
<span className="v" id="v21" data-v="21"> 以色列人和非利士人摆列阵势，军队对着军队。</span>
<span className="v" id="v22" data-v="22" data-xref="路加福音 10:5–6; 士师记 18:15; 以赛亚书 10:28"> 大卫把行李交在看守行李的人手中，跑到军阵那里，来问他哥哥们安。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 17:8–10"> 他正与他们说话的时候，看哪，那勇士，就是名叫歌利亚的迦特非利士人，从非利士人的队伍中上来，说了同样的话；大卫都听见了。</span>
<span className="v" id="v24" data-v="24" data-xref="撒母耳记上 13:6–7; 利未记 26:36; 以赛亚书 7:2"> 以色列众人看见那人，就从他面前逃跑，非常害怕。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 15:16; 启示录 2:7; 启示录 3:12"> 以色列人说：“你们看见这个上来的人了吗？他上来确实是要向以色列挑战。若有人杀了他，王必赐给那人极大的财富，把自己的女儿给他，并使他父家在以色列免税。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="申命记 5:26; 撒母耳记上 11:2; 撒母耳记上 14:6"> 大卫对站在他旁边的人说：“有人杀了这非利士人，除去以色列的耻辱，将得什么呢？这未受割礼的非利士人是谁，竟敢向永生上帝的军队挑战？”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 17:25"> 百姓照先前的话回答他说：“杀了他的人必得这样的待遇。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马太福音 10:36; 创世记 37:11; 箴言 18:19"> 大卫的长兄以利押听见他与那些人说话，以利押就向大卫发怒，说：“你为什么下来？你把旷野里那几只羊交给谁了？我知道你的骄傲和你心里的恶意；你下来不过是要看战斗。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="彼得前书 3:9; 哥林多前书 2:15; 箴言 15:1"> 大卫说：“我现在做了什么呢？难道没有缘故吗？”</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 17:26–27"> 他离开以利押，转向另一个人，又照这样问；百姓仍照先前的话回答他。</span>
<span className="v" id="v31" data-v="31" data-xref="箴言 22:29"> 有人听见大卫所说的话，就在扫罗面前述说；扫罗便派人召他来。</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 16:18; 申命记 20:1–3; 诗篇 3:6"> 大卫对扫罗说：“不要因他使人的心丧胆。你的仆人要去与这非利士人交战。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="民数记 13:31; 申命记 9:2; 启示录 13:4"> 扫罗对大卫说：“你不能去对抗这非利士人与他交战；因为你不过是个少年，而他从少年时就是战士。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> 大卫对扫罗说：“你的仆人为父亲放羊；有时狮子或熊来，从羊群中叼走一只羊羔，</span>
<span className="v" id="v35" data-v="35" data-xref="阿摩司 3:12; 提摩太后书 4:17–18; 但以理 6:22"> 我就追出去，击打它，把羊羔从它口中救出来。它起来攻击我，我就抓住它的胡须，击打它，把它杀死。</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳记上 17:10; 使徒行传 5:38–39; 罗马书 2:28–29"> 你的仆人曾击杀狮子和熊。这未受割礼的非利士人也必像它们一样，因为他向永生上帝的军队挑战。”</span>
<span className="v" id="v37" data-v="37" data-xref="提摩太后书 4:17–18; 诗篇 138:7–8; 哥林多后书 1:9–10"> 大卫又说：“耶和华曾救我脱离狮子的爪和熊的爪，祂也必救我脱离这非利士人的手。”<br />扫罗对大卫说：“去吧！耶和华必与你同在。”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> 扫罗给大卫穿上自己的衣服，把铜盔戴在他头上，又给他穿上铠甲。</span>
<span className="v" id="v39" data-v="39" data-xref="撒迦利亚书 4:6; 哥林多后书 10:4–5; 何西阿 1:7"> 大卫把扫罗的刀系在衣服外面，试着走动，因为他没有试过。大卫对扫罗说：“我不能穿戴这些去，因为我没有试过。”于是大卫把这些都脱下。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="哥林多前书 1:27–29; 马太福音 10:10; 士师记 15:15–16"> 他手中拿着杖，从溪中为自己选了五块光滑的石子，放在他牧羊袋里的囊中；手里拿着甩石带，就走近那非利士人。</span>
<span className="v" id="v41" data-v="41"> 那非利士人走着，渐渐接近大卫；拿盾牌的人走在他前面。</span>
<span className="v" id="v42" data-v="42" data-xref="撒母耳记上 16:12; 撒母耳记上 17:33; 诗篇 123:3–4"> 那非利士人环视，看见大卫，就轻视他；因为他不过是个少年，面色红润，容貌俊美。</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳记下 9:8; 撒母耳记下 3:8; 撒母耳记上 24:14"> 那非利士人对大卫说：“你拿杖到我这里来，我是狗吗？”那非利士人就指着自己的神明咒诅大卫。</span>
<span className="v" id="v44" data-v="44" data-xref="以西结 28:9–10; 箴言 18:12; 列王纪上 20:10–11"> 那非利士人又对大卫说：“到我这里来吧！我要把你的肉给空中的飞鸟和田野的走兽。”</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="哥林多后书 10:4; 历代志下 32:8; 哥林多后书 3:5"> 大卫对那非利士人说：“你带着刀、枪和标枪到我这里来；我却奉万军之耶和华的名到你这里来，祂是以色列军队的上帝，就是你所挑战的。</span>
<span className="v" id="v46" data-v="46" data-xref="以赛亚书 52:10; 约书亚记 4:24; 列王纪下 19:19"> 今天，耶和华必把你交在我手中。我必击打你，割下你的头。今天我必把非利士军队的尸体给空中的飞鸟和地上的野兽，使全地都知道以色列中有上帝，</span>
<span className="v" id="v47" data-v="47" data-xref="诗篇 44:6–7; 撒迦利亚书 4:6; 何西阿 1:7"> 也使这全会众知道：耶和华拯救人，不是靠刀枪；因为争战属于耶和华，祂必把你们交在我们手中。”</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="箴言 28:1; 诗篇 27:1"> 那非利士人起身，走近来迎着大卫的时候，大卫急忙向军阵跑去，迎着那非利士人。</span>
<span className="v" id="v49" data-v="49" data-xref="哥林多前书 1:27–28; 列王纪下 9:24; 列王纪上 22:34"> 大卫把手伸进袋里，取出一块石子，用甩石带甩出去，击中那非利士人的额头。石子陷入他的额头，他就脸伏于地倒下。</span>
<span className="v" id="v50" data-v="50" data-xref="士师记 15:15; 撒母耳记上 17:39; 撒母耳记上 23:21"> 这样，大卫用甩石带和石子胜过那非利士人，击打那非利士人，把他杀死；但大卫手中没有刀。</span>
<span className="v" id="v51" data-v="51" data-xref="希伯来书 11:34; 撒母耳记上 21:9; 撒母耳记下 23:21"> 大卫跑去，站在那非利士人身旁，拿起他的刀，从鞘中拔出来，杀死他，并用刀割下他的头。<br />非利士人看见他们的勇士死了，就逃跑。</span>
<span className="v" id="v52" data-v="52" data-xref="约书亚记 15:11; 约书亚记 15:33–36; 约书亚记 15:45–46"> 以色列人和犹大人起来呐喊，追赶非利士人，直到该，又到以革伦的城门。非利士人受伤的倒在往沙拉音的路上，直到迦特，又到以革伦。</span>
<span className="v" id="v53" data-v="53" data-xref="耶利米书 4:20; 列王纪下 7:7–16; 耶利米书 30:16"> 以色列人追赶非利士人回来，就掠夺他们的营。</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及记 16:33; 约书亚记 4:7–8; 撒母耳记上 21:9"> 大卫拿着那非利士人的头，带到耶路撒冷；却把他的军装放在自己的帐棚里。</span>
<span className="v" id="v55" data-v="55" data-xref="撒母耳记上 16:21–22; 撒母耳记上 17:58"> 扫罗看见大卫出去迎战那非利士人，就对军队的元帅押尼珥说：“押尼珥，这少年是谁的儿子？”<br />押尼珥说：“王啊，我敢以你的性命起誓，我不知道。”</span>
</div>
<div className="bp">
<span className="v" id="v56" data-v="56"> 王说：“你去查问这年轻人是谁的儿子！”</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="撒母耳记上 17:54"> 大卫击杀那非利士人回来时，押尼珥带他到扫罗面前；他手中拿着那非利士人的头。</span>
<span className="v" id="v58" data-v="58" data-xref="撒母耳记上 17:12; 撒母耳记上 16:18–19"> 扫罗对他说：“少年人哪，你是谁的儿子？”<br />大卫回答说：“我是你仆人伯利恒人耶西的儿子。”</span>
</div>
</div>

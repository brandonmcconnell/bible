<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 15:7; 撒母耳记上 29:11; 撒母耳记上 27:8–10"> 到第三天，大卫和跟随他的人来到洗革拉。亚玛力人已经侵袭了南地和洗革拉，攻破洗革拉，用火焚烧，</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 27:11; 约伯记 38:11; 诗篇 76:10"> 又把城中的妇女和所有的人，无论大小，都掳去了。他们没有杀一个人，只是把他们带走，就上路离开了。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 34:19; 彼得前书 1:6–7; 启示录 3:9"> 大卫和跟随他的人来到那城，看哪，城已经被火焚烧；他们的妻子、儿子和女儿都被掳去了。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 11:4; 民数记 14:1; 士师记 21:2"> 于是大卫和跟随他的人放声大哭，直到再也没有力气哭。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 25:42–43; 撒母耳记下 2:2; 撒母耳记上 1:2"> 大卫的两个妻子也被掳去了，就是耶斯列女子亚希暖，和迦密人拿八的妻子亚比该。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 56:3–4; 诗篇 56:11; 诗篇 62:5"> 大卫非常困苦，因为众人都为自己的儿女心里悲痛，谈论要用石头打死他；但大卫靠耶和华他的上帝坚固自己。</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪上 2:26; 撒母耳记上 22:20–21; 撒母耳记上 23:2–9"> 大卫对亚希米勒的儿子、祭司亚比亚他说：“请把以弗得拿到我这里来。”<br />亚比亚他就把以弗得拿到大卫那里。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 30:18; 箴言 3:5–6; 撒母耳记上 23:2"> 大卫求问耶和华，说：“我若追赶这队人，能追上他们吗？”<br />祂回答他说：“追赶吧，因为你必定能追上，并且一定能夺回一切。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 27:2"> 于是大卫和跟随他的六百人出发，来到比梭溪；那些留在后面的人就停在那里。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 30:9; 撒母耳记上 30:21; 撒母耳记上 14:31"> 但大卫和四百人继续追赶；有二百人因疲乏到不能过比梭溪，就留在后面。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 12:20–21; 申命记 23:7; 马太福音 25:35"> 他们在田野遇见一个埃及人，把他带到大卫那里，给他饼吃；他吃了，又给他水喝。</span>
<span className="v" id="v12" data-v="12" data-xref="士师记 15:19; 撒母耳记上 14:27; 撒母耳记上 30:13"> 他们又给他一块无花果饼和两串葡萄干。他吃了以后，精神就恢复了；因为他已经三天三夜没有吃饼，也没有喝水。</span>
<span className="v" id="v13" data-v="13" data-xref="雅各书 2:13; 箴言 12:10; 约伯记 31:13–15"> 大卫问他说：“你属于谁？你从哪里来？”<br />他说：“我是埃及的少年人，是一个亚玛力人的仆人；三天前我病了，我主人就把我丢下。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 1:38; 撒母耳记下 8:18; 列王纪上 1:44"> 我们侵袭了基利提人的南地、属于犹大的地方，以及迦勒的南地；又用火焚烧了洗革拉。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约书亚记 2:12; 约书亚记 9:19–20; 以西结 17:16"> 大卫对他说：“你愿意带我下去到这队人那里吗？”<br />他说：“你要指着上帝向我起誓，不杀我，也不把我交在我主人手里，我就带你下去到这队人那里。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="启示录 11:10–13; 撒母耳记下 13:28; 士师记 16:23–30"> 他带大卫下去；看哪，他们散布在全地上，吃喝跳舞，因为他们从非利士地和犹大地夺得了许多财物。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 11:11; 诗篇 18:42; 撒母耳记上 15:3"> 大卫击杀他们，从黄昏直到次日晚上。他们中间没有一个人从那里逃脱，只有四百个骑骆驼的少年人逃走了。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 14:16"> 大卫夺回亚玛力人所掳去的一切，也救回了他的两个妻子。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 91:9–10; 撒母耳记上 30:8; 约伯记 1:10"> 凡他们所掳去的，无论大小，无论儿女，或是掠物，或是任何东西，都没有缺少一样。大卫把这一切都带回来了。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 30:26; 民数记 31:9–12; 历代志下 20:25"> 大卫夺取了一切羊群和牛群；他们把这些赶在其余牲畜前面，说：“这是大卫的掠物。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="希伯来书 13:1; 撒母耳记上 30:10; 士师记 8:15"> 大卫来到那二百人那里；他们因疲乏不能跟随大卫，也曾被留在比梭溪。他们出来迎接大卫和跟随他的人。大卫走近他们，就问候他们。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 7:12; 申命记 13:13; 列王纪上 21:10"> 跟随大卫去的人中，所有恶人和无赖之徒回应说：“因为他们没有跟我们同去，我们所夺回的掠物，除了每个人的妻子儿女可以给他带走之外，什么都不给他们；让他们离开吧。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="申命记 8:18; 诗篇 44:2–7; 使徒行传 7:2"> 大卫却说：“我的弟兄们，不可这样处理耶和华赐给我们的东西；祂保守了我们，又把那来攻击我们的队伍交在我们手里。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 22:8; 民数记 31:27; 诗篇 68:12"> 这事谁会听你们的呢？下去作战的得多少，看守辎重的也得多少；他们要同样分取。”</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 16:13"> 从那日起，大卫就把这定为以色列的律例和典章，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="撒母耳记上 25:27; 创世记 33:11; 以赛亚书 32:8"> 大卫来到洗革拉，就把一些掠物送给犹大的长老，就是他的朋友们，说：“看哪，这是从耶和华仇敌的掠物中取来，送给你们的礼物。”</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 15:48; 约书亚记 19:8; 士师记 1:22–23"> 他送给在伯特利的人，在南地拉末的人，在雅提珥的人，</span>
<span className="v" id="v28" data-v="28" data-xref="约书亚记 13:16; 约书亚记 15:50; 约书亚记 21:14"> 在亚罗珥的人，在西弗末的人，在以实提莫的人，</span>
<span className="v" id="v29" data-v="29" data-xref="士师记 1:16; 撒母耳记上 27:10; 撒母耳记上 15:6"> 在拉哈勒的人，在耶拉篾人各城的人，在基尼人各城的人，</span>
<span className="v" id="v30" data-v="30" data-xref="士师记 1:17; 约书亚记 19:4; 约书亚记 15:42"> 在何珥玛的人，在博拉珊的人，在亚挞的人，</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 2:1; 撒母耳记下 15:10; 撒母耳记下 4:1"> 在希伯仑的人，以及大卫和跟随他的人从前常停留的各处。</span>
</div>
</div>

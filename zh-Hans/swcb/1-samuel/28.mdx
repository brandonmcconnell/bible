<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 17:1; 撒母耳记上 29:1–3; 撒母耳记上 7:7"> 那些日子，非利士人聚集他们的军队，要与以色列争战。亚吉对大卫说：“你要确知，你和你的人都要随我出征，加入军队。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="罗马书 12:9; 撒母耳记下 16:16–19; 撒母耳记上 27:10"> 大卫对亚吉说：“这样，你就会知道你仆人能做什么。”<br />亚吉对大卫说：“这样，我要立你永远作我的护卫。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="利未记 19:31; 撒母耳记上 25:1; 利未记 20:27"> 那时撒母耳已经死了，全以色列都为他哀悼，把他葬在拉玛，就是他自己的城里。扫罗曾把交鬼的人和巫师从境内赶出去。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 31:1; 约书亚记 19:18; 列王纪下 4:8"> 非利士人聚集起来，来到书念安营；扫罗也聚集全以色列，他们在基利波安营。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 57:20–21; 但以理 5:6; 以赛亚书 21:3–4"> 扫罗看见非利士人的军队，就惧怕，心中大大战兢。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 12:6; 撒母耳记上 14:37; 耶利米哀歌 2:9"> 扫罗求问耶和华，耶和华却不藉着梦、乌陵或先知回答他。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 16:16; 约书亚记 17:11; 历代志上 10:13"> 于是扫罗对臣仆说：“给我找一个交鬼的妇人，我好到她那里去求问她。”<br />他的臣仆对他说：“看哪，在隐多珥有一个交鬼的妇人。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 8:19; 历代志上 10:13; 列王纪上 22:30"> 扫罗乔装改扮，穿上别的衣服，带着两个人同去，夜里来到那妇人那里。他说：“请你用交鬼之术为我求问，把我向你指名的人给我招上来。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 28:3; 列王纪下 5:7; 撒母耳记下 18:13"> 那妇人对他说：“看哪，你知道扫罗所做的事，他怎样把交鬼的人和巫师从这地剪除。你为什么给我的性命设网罗，使我死呢？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 14:11; 撒母耳记上 19:6; 申命记 18:10–12"> 扫罗指着耶和华向她起誓说：“我指着永活的耶和华起誓，你必不因这事受罚。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 那妇人说：“我该把谁给你招上来？”<br />他说：“把撒母耳给我招上来。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 28:3; 列王纪上 14:5"> 那妇人看见撒母耳，就大声呼喊；那妇人对扫罗说：“你为什么欺骗我？你就是扫罗！”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="诗篇 82:6–7; 约翰福音 10:34–35; 出埃及记 22:28"> 王对她说：“不要害怕！你看见了什么？”<br />那妇人对扫罗说：“我看见一个神灵从地里上来。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 15:27; 列王纪下 2:8; 撒母耳记上 24:8"> 他对她说：“他的样子怎样？”<br />她说：“有一个老人上来，身上披着外袍。”扫罗认出那是撒母耳，就脸伏于地，向他致敬下拜。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 16:23–26; 撒母耳记上 28:6; 撒母耳记上 18:12"> 撒母耳对扫罗说：“你为什么惊扰我，把我招上来？”<br />扫罗回答说：“我非常困苦；因为非利士人与我争战，上帝已经离开我，不再藉着先知或梦回答我。因此我呼求你，好使你告诉我该怎样做。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪下 6:27; 耶利米哀歌 2:5; 诗篇 68:1–3"> 撒母耳说：“既然耶和华已经离开你，成了你的敌人，你为什么还问我呢？</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 15:27–29; 撒母耳记上 16:13; 撒母耳记上 13:13–14"> 耶和华已经照祂借着我所说的话向你行了。耶和华已经把国从你手中撕走，赐给你的邻舍，就是大卫。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 15:9; 列王纪上 20:42; 诗篇 50:21–22"> 因为你没有听从耶和华的声音，没有在亚玛力身上施行祂猛烈的怒气，所以耶和华今日向你行了这事。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 5:5; 耶利米书 28:16–17; 列王纪上 22:20"> 而且，耶和华也必把以色列连同你交在非利士人手中；明天你和你的儿子们必与我在一起。耶和华也必把以色列的军队交在非利士人手中。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 28:5; 约伯记 26:2; 约伯记 15:20–24"> 扫罗立刻全身倒在地上，因撒母耳的话非常惧怕。他毫无力气，因为他整昼整夜都没有吃饭。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="士师记 12:3; 约伯记 13:14; 撒母耳记上 19:5"> 那妇人来到扫罗面前，看见他非常惊惶，就对他说：“看哪，婢女已经听从你的话，把自己的性命放在手中，听从了你对我所说的话。</span>
<span className="v" id="v22" data-v="22"> 现在，也请你听从婢女的话，让我在你面前摆上一点饼。你吃了，好在上路时有力气。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪上 21:4; 路加福音 24:29; 路加福音 14:23"> 但他拒绝，说：“我不吃。”可是他的臣仆和那妇人一同催促他；他就听从他们的话，从地上起来，坐在榻上。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 15:23; 创世记 18:7–8"> 那妇人家里有一头肥牛犊。她急忙把它宰了；又拿面揉好，烤成无酵饼。</span>
<span className="v" id="v25" data-v="25"> 她把这些摆在扫罗和他的臣仆面前，他们就吃了。然后他们起身，当夜离去了。</span>
</div>
</div>

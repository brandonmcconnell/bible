<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="阿摩司 8:11–12; 诗篇 74:9; 撒母耳记上 3:21"> 童子撒母耳在以利面前侍奉耶和华。那些日子，耶和华的话稀少，异象也不常有。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 4:15; 诗篇 90:10; 创世记 27:1"> 那时，以利躺卧在自己的地方；他的眼睛已经开始昏花，不能看见。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 27:4; 利未记 24:2–4; 出埃及记 27:20–21"> 上帝的灯还没有熄灭，撒母耳也躺卧在耶和华的殿里，就是上帝的约柜所在之处。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 6:8; 哥林多前书 12:6–11; 出埃及记 3:4"> 耶和华呼唤撒母耳。撒母耳说：“我在这里。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 他就跑到以利那里，说：“我在这里；因为你呼唤我。”<br />以利说：“我没有呼唤你，再去躺下吧。”<br />他就去躺下了。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 9:2; 撒母耳记上 4:16; 撒母耳记下 18:22"> 耶和华又呼唤说：“撒母耳！”<br />撒母耳起来，到以利那里，说：“我在这里；因为你呼唤我。”<br />以利回答说：“我儿，我没有呼唤你，再去躺下吧。”</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 19:2; 耶利米书 9:24"> 那时撒母耳还不认识耶和华，耶和华的话也还没有向他显明。</span>
<span className="v" id="v8" data-v="8" data-xref="约伯记 33:14–15; 哥林多前书 13:11–12"> 耶和华第三次呼唤撒母耳。他起来，到以利那里，说：“我在这里；因为你呼唤我。”<br />以利就明白是耶和华呼唤这孩子。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 20:19; 以赛亚书 6:8; 诗篇 85:8"> 因此，以利对撒母耳说：“你去躺下吧。如果祂呼唤你，你就说：‘耶和华啊，请说，仆人敬听。’”于是撒母耳去，在自己的地方躺下。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 3:8; 撒母耳记上 3:4–6"> 耶和华来了，站在那里，像前几次一样呼唤：“撒母耳！撒母耳！”<br />撒母耳说：“请说，仆人敬听。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哈巴谷 1:5; 耶利米书 19:3; 列王纪下 21:12"> 耶和华对撒母耳说：“看哪，我要在以色列中行一件事，凡听见的人，两耳都必震响。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 2:27–36; 撒迦利亚书 1:6; 约书亚记 23:15"> 到那日，我要向以利成就我论到他家所说的一切，从开始直到末了。</span>
<span className="v" id="v13" data-v="13" data-xref="箴言 19:18; 马太福音 10:37; 撒母耳记上 2:12"> 因为我已经告诉他，我必因他所知道的罪孽，永远审判他的家；因为他的儿子们自招咒诅，他却没有约束他们。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 22:14; 撒母耳记上 2:25; 耶利米书 15:1"> 因此，我向以利家起誓：以利家的罪孽永远不能靠祭物或供物除去。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="耶利米书 1:6–8; 玛拉基书 1:10; 撒母耳记上 1:9"> 撒母耳躺到早晨，然后打开耶和华殿的门。撒母耳害怕把这异象告诉以利。</span>
<span className="v" id="v16" data-v="16"> 以利呼唤撒母耳，说：“撒母耳，我儿！”<br />他说：“我在这里。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 3:35; 路得记 1:17; 诗篇 141:5"> 以利说：“祂对你说了什么事？请不要向我隐瞒。祂对你所说的一切，你若向我隐瞒什么，愿上帝重重地惩罚你。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约伯记 2:10; 以赛亚书 39:8; 士师记 10:15"> 撒母耳就把一切都告诉他，没有向他隐瞒什么。<br />以利说：“这是耶和华。愿祂照自己看为好的去行。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="创世记 39:2; 撒母耳记上 9:6; 列王纪上 8:56"> 撒母耳渐渐长大，耶和华与他同在，使他的话一句也不落空。</span>
<span className="v" id="v20" data-v="20" data-xref="士师记 20:1; 撒母耳记下 3:10; 提摩太前书 1:12"> 从但直到别是巴，全以色列都知道撒母耳被确立为耶和华的先知。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 3:1; 创世记 12:7; 撒母耳记上 3:4"> 耶和华又在示罗显现；因为耶和华在示罗借着耶和华的话向撒母耳显明自己。</span>
</div>
</div>

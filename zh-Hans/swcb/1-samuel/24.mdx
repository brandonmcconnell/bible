<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 23:28–29; 以西结 22:9; 撒母耳记上 23:19"> 扫罗追赶非利士人回来以后，有人告诉他说：“看哪，大卫在隐基底的旷野。”</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 26:2; 诗篇 104:18; 诗篇 37:32"> 扫罗就从全以色列中选取三千精兵，去野山羊的岩石那里寻找大卫和跟随他的人。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 3:24; 诗篇 57:1–11; 诗篇 142:1–7"> 他来到路旁的羊圈，那里有一个洞；扫罗进去解手。大卫和跟随他的人正藏在洞的最深处。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 26:8–11; 撒母耳记上 24:10; 撒母耳记上 26:23"> 大卫的人对他说：“看哪，耶和华曾对你说的日子到了：‘看哪，我要把你的仇敌交在你手里，你可以照你看为好的待他。’”于是大卫起来，悄悄割下扫罗衣袍的边。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 24:10; 列王纪下 22:19; 约翰一书 3:20–21"> 后来，大卫因割下扫罗衣袍的边，心里自责。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 1:14; 约伯记 31:29–30; 撒母耳记上 26:9–11"> 他对跟随他的人说：“耶和华禁止我向我的主，就是耶和华的受膏者，做这样的事；我不可伸手攻击他，因为他是耶和华的受膏者。”</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 5:44; 诗篇 7:4; 罗马书 12:17–21"> 大卫用这些话制止了跟随他的人，不容他们起来攻击扫罗。扫罗从洞里起来，继续上路。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 25:23–24; 罗马书 13:7; 出埃及记 20:12"> 随后大卫也起来，走出洞，在扫罗身后呼喊说：“我主我王！”<br />扫罗回头看时，大卫就脸伏于地，向他下拜。</span>
<span className="v" id="v9" data-v="9" data-xref="传道书 7:21–22; 箴言 29:12; 箴言 16:28"> 大卫对扫罗说：“你为什么听信人的话，说：‘看哪，大卫想要害你’呢？</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 105:15; 撒母耳记上 24:4; 撒母耳记上 26:8–9"> 看哪，今天你亲眼看见，今天耶和华在洞中怎样把你交在我手里。有人劝我杀你，但我饶了你。我说：‘我不可伸手攻击我的主，因为他是耶和华的受膏者。’</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 26:20; 撒母耳记上 23:14; 撒母耳记上 23:23"> 我父啊，看哪，请看你衣袍的边在我手里；我割下你衣袍的边，却没有杀你，由此你可以知道并看见，我手中没有恶意，也没有悖逆。我没有得罪你，你却追猎我的性命，要夺取它。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 43:1; 士师记 11:27; 诗篇 35:1"> 愿耶和华在你我之间判断；愿耶和华为我向你报仇，但我的手必不加在你身上。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 7:20; 马太福音 7:16–18; 马太福音 12:33–34"> 古人的箴言说：‘恶事出于恶人。’但我的手必不加在你身上。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 26:20; 撒母耳记上 17:43; 撒母耳记下 9:8"> 以色列王出来攻击谁呢？你追赶谁呢？一条死狗吗？一只跳蚤吗？</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 43:1; 诗篇 35:1; 诗篇 119:154"> 因此，愿耶和华作审判者，在你我之间断定是非；愿祂察看，为我申辩，救我脱离你的手。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 26:17; 创世记 33:4; 路加福音 21:15"> 大卫向扫罗说完这些话以后，扫罗说：“这是你的声音吗，我儿大卫？”扫罗就放声哭了。</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 5:44; 撒母耳记上 26:21; 创世记 38:26"> 他对大卫说：“你比我更公义；因为你以善待我，我却以恶待你。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 26:23; 诗篇 31:8; 撒母耳记上 23:12"> 你今天显明了你怎样善待我；因为耶和华把我交在你手里时，你没有杀我。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 18:20; 撒母耳记上 23:21; 箴言 25:21–22"> 人若遇见自己的仇敌，岂会平安地放他走吗？所以，愿耶和华因你今天向我所做的，以善报答你。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 23:17; 马太福音 2:3–6; 撒母耳记下 3:17–18"> 现在，看哪，我知道你必定作王，以色列的国必在你手中坚立。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 21:23; 撒母耳记下 21:6–8; 撒母耳记上 20:14–17"> 所以现在，请你指着耶和华向我起誓：你不会在我以后剪除我的后裔，也不会从我父家除灭我的名。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 23:29; 约翰福音 2:24; 马太福音 10:16–17"> 大卫就向扫罗起誓。扫罗回家去了；大卫和跟随他的人却上到山寨去。</span>
</div>

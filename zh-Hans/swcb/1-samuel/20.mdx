<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="彼得后书 2:9; 哥林多后书 1:12; 约翰一书 3:21"> 大卫从拉玛的拿约逃走，来到约拿单那里，对他说：“我做了什么？我有什么罪孽？我在你父亲面前犯了什么罪，以致他寻索我的性命？”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 9:15; 约翰福音 17:8; 约翰福音 15:15"> 约拿单对他说：“绝不会！你必不至于死。看哪，我父亲无论大事小事，没有不向我透露的。我父亲为什么会把这事向我隐瞒呢？没有这回事。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 25:26; 申命记 6:13; 列王纪下 2:6"> 大卫又起誓说：“你父亲明明知道我在你眼中蒙恩；他心里说：‘不要让约拿单知道这事，免得他忧伤。’但我指着永活的耶和华，又指着你的性命起誓，我与死亡之间不过一步之遥。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 约拿单对大卫说：“你心里想要什么，我都会为你做。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民数记 10:10; 撒母耳记上 19:2; 民数记 28:11"> 大卫对约拿单说：“看哪，明天是月朔，我本不该缺席，要与王同席吃饭；但请容我去，让我藏在田野，直到第三天晚上。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 17:58; 撒母耳记上 9:12; 申命记 12:5"> 如果你父亲确实发现我不在，你就说：‘大卫恳切地向我请假，要赶回他的本城伯利恒，因为全家在那里有每年的祭礼。’</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 25:17; 以斯帖记 7:7; 申命记 1:23"> 如果他说：‘好，’你的仆人就平安无事；但如果他发怒，你就知道他已定意要降祸。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 14:32; 撒母耳记上 18:3; 撒母耳记上 23:18"> 所以，请以慈爱待你的仆人，因为你使你的仆人与你一同进入耶和华的约；如果我有罪孽，你就亲手杀我，何必把我带到你父亲那里呢？”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 20:42; 撒母耳记上 19:2; 撒母耳记上 20:38"> 约拿单说：“绝不会临到你！如果我确知我父亲定意要使祸患临到你，我岂不告诉你吗？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 25:14; 撒母耳记上 25:17; 创世记 42:30"> 大卫对约拿单说：“如果你父亲严厉地回答你，谁来告诉我呢？”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 约拿单对大卫说：“来！我们到田野去。”于是二人都出到田野。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 22:22; 约伯记 31:4; 箴言 25:2–3"> 约拿单对大卫说：“我指着耶和华——以色列的上帝——起誓：明天约这个时候，或第三天，我探明我父亲的意思，看哪，如果他对大卫有好意，我岂不差人到你那里告诉你吗？</span>
<span className="v" id="v13" data-v="13" data-xref="路得记 1:17; 历代志上 22:11; 约书亚记 1:5"> 倘若我父亲有意加害于你，而我不告诉你、不送你离开，使你平安地走，愿耶和华重重地降罚于约拿单。愿耶和华与你同在，像祂从前与我父亲同在一样。</span>
<span className="v" id="v14" data-v="14" data-xref="撒母耳记下 9:3; 以弗所书 5:1–2"> 你不仅要在我还活着的时候，以耶和华的慈爱待我，使我不至于死；</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 21:7; 撒母耳记上 24:21; 撒母耳记下 9:1–7"> 就是耶和华从地面上剪除大卫每一个仇敌的时候，你也不可永远断绝你对我家的慈爱。”</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 25:22; 撒母耳记上 18:3; 撒母耳记下 21:8"> 于是约拿单与大卫家立约，说：“愿耶和华向大卫的仇敌追讨。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="箴言 18:24; 撒母耳记上 18:1; 撒母耳记上 18:3"> 约拿单因爱大卫，就使大卫再次起誓；因为他爱大卫，如同爱自己的生命。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 20:25; 撒母耳记上 20:5"> 约拿单对他说：“明天是月朔，人必发现你不在，因为你的座位会空着。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 19:2; 撒母耳记上 20:5"> 你等了三天以后，要赶快下去，到这事开始时你藏身的地方，留在以色石旁。</span>
<span className="v" id="v20" data-v="20"> 我会朝它旁边射三支箭，好像射靶一样。</span>
<span className="v" id="v21" data-v="21" data-xref="耶利米书 5:2; 阿摩司 8:14; 耶利米书 12:16"> 看哪，我会派童子去，说：‘去，把箭找来！’如果我对童子说：‘看哪，箭在你这边，把它们拿来，’那你就出来，因为我指着永活的耶和华起誓，你平安无事，没有危险。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 20:37"> 但如果我这样对童子说：‘看哪，箭在你前面，’那你就走吧，因为耶和华已经差你离开。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 20:14–15; 撒母耳记上 20:42; 创世记 31:50"> 至于你我所谈的事，看哪，耶和华永远在你我之间。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="箴言 4:17; 以赛亚书 1:11–15; 箴言 21:3"> 于是大卫藏在田野。月朔到了，王坐下吃饭。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 20:18; 士师记 16:20"> 王照常坐在自己的座位上，就是靠墙的座位；约拿单站起来，押尼珥坐在扫罗旁边，但大卫的位置空着。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 15:5; 利未记 11:24; 利未记 11:27"> 然而那一天扫罗什么也没说，因为他想：“他遇到了什么事。他不洁净，必定不洁净。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="彼得前书 2:4; 撒母耳记上 19:15; 撒母耳记上 18:11"> 月朔的次日，就是第二天，大卫的位置还是空着。扫罗对他的儿子约拿单说：“耶西的儿子为什么昨天、今天都没有来吃饭？”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 20:6"> 约拿单回答扫罗说：“大卫恳切地向我求准去伯利恒。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记上 17:28"> 他说：‘请让我去，因为我们家在城里有祭礼，我哥哥吩咐我必须在那里。现在，如果我在你眼中蒙恩，请让我离开，去见我的弟兄们。’所以他没有来到王的席上。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="箴言 21:24; 雅各书 1:19–20; 箴言 25:28"> 扫罗就向约拿单怒气大发，对他说：“你这悖逆、顽梗妇人的儿子！我岂不知道你选择了耶西的儿子，自取羞辱，也使你母亲的下体蒙羞吗？</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记上 19:6; 撒母耳记上 20:8; 撒母耳记上 19:11–15"> 只要耶西的儿子还在地上活着，你和你的国都不能坚立。所以现在要派人把他带到我这里来，因为他是该死的！”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马太福音 27:23; 撒母耳记上 19:5; 路加福音 23:22"> 约拿单回答他父亲扫罗，对他说：“他为什么该被处死？他做了什么？”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="撒母耳记上 20:7; 撒母耳记上 18:11; 撒母耳记上 19:10"> 扫罗向他掷枪，要刺他。由此约拿单知道，他父亲已定意要处死大卫。</span>
<span className="v" id="v34" data-v="34" data-xref="以弗所书 4:26; 马可福音 3:5; 传道书 7:20"> 于是约拿单怒气冲冲地从席上起来，在那月的第二天没有吃饭；他为大卫忧伤，因为他父亲使大卫蒙羞。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 20:5; 撒母耳记上 20:19"> 到了早晨，约拿单按与大卫约定的时候出到田野，有一个小童跟着他。</span>
<span className="v" id="v36" data-v="36" data-xref="撒母耳记上 20:20–22"> 他对小童说：“快跑，去找我所射的箭。”小童跑的时候，他把一支箭射到他前面。</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳记上 20:22"> 小童到了约拿单所射之箭的地方，约拿单在小童后面喊说：“箭不是在你前面吗？”</span>
<span className="v" id="v38" data-v="38" data-xref="诗篇 55:6–9; 箴言 6:4–5; 马可福音 13:14–16"> 约拿单又在小童后面喊：“快去！赶紧！不要停留！”约拿单的小童拾起箭，回到他主人那里。</span>
<span className="v" id="v39" data-v="39"> 但那小童什么也不知道，只有约拿单和大卫知道这事。</span>
<span className="v" id="v40" data-v="40"> 约拿单把自己的兵器交给小童，对他说：“去，把它们带到城里。”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="创世记 29:11; 撒母耳记上 18:3; 撒母耳记下 9:6"> 小童一走，大卫就从南边出来，脸伏于地，拜了三次。他们彼此亲吻，彼此哭泣，大卫哭得更厉害。</span>
<span className="v" id="v42" data-v="42" data-xref="撒母耳记上 1:17; 撒母耳记上 23:18; 撒母耳记上 20:22–23"> 约拿单对大卫说：“平安地去吧，因为我们二人曾奉耶和华的名起誓说：‘耶和华永远在我与你之间，也在我的后裔与你的后裔之间。’”大卫就起身离去；约拿单也进了城。</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 10:1–12; 撒母耳记上 28:4; 撒母耳记下 1:21"> 非利士人与以色列交战；以色列人在非利士人面前逃跑，在基利波山上倒毙。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 8:33; 撒母耳记上 14:49; 撒母耳记上 23:17"> 非利士人紧追扫罗和他的儿子们；非利士人杀了扫罗的儿子约拿单、亚比拿达和麦基舒亚。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 1:6; 创世记 49:23; 列王纪上 22:34"> 战势对扫罗十分危急，弓箭手追上了他；他因弓箭手而极其窘迫。</span>
<span className="v" id="v4" data-v="4" data-xref="士师记 9:54; 撒母耳记下 1:6; 撒母耳记下 1:9–10"> 扫罗对拿他兵器的人说：“拔出你的刀来，用它把我刺透，免得这些未受割礼的人来把我刺透，凌辱我！”但拿他兵器的人不肯，因为他十分惧怕。于是扫罗拿起自己的刀，伏在刀上。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 10:5"> 拿他兵器的人见扫罗已经死了，也照样伏在自己的刀上，与他一同死了。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 12:17; 何西阿 13:10–11; 历代志上 10:6"> 这样，扫罗和他的三个儿子、拿他兵器的人，以及跟随他的所有人，都在那一天一同死了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命记 28:33; 利未记 26:32; 利未记 26:36"> 在山谷那边的以色列人，以及约旦河那边的人，看见以色列人逃跑，扫罗和他的儿子们也死了，就弃城逃跑；非利士人便来住在其中。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志下 20:25; 历代志上 10:8"> 第二天，非利士人来剥取阵亡者的财物，发现扫罗和他的三个儿子倒在基利波山上。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 1:20; 士师记 16:23–24; 撒母耳记上 17:54"> 他们砍下他的头，剥下他的军装，派人走遍非利士人的地，把消息传到他们偶像的庙里和民众那里。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 2:13; 约书亚记 17:11; 撒母耳记上 21:9"> 他们把他的军装放在亚斯她录的庙里，又把他的尸体钉在伯珊的城墙上。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 11:1–11; 撒母耳记下 2:4"> 基列雅比的居民听见非利士人对扫罗所做的事，</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 16:14; 耶利米书 34:5; 撒母耳记下 2:4–7"> 所有勇士就起来，连夜赶去，从伯珊的城墙上取下扫罗的尸体和他儿子们的尸体；他们回到雅比，在那里焚烧了尸体。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 21:12–14; 创世记 50:10; 撒母耳记上 22:6"> 他们取了他们的骸骨，埋葬在雅比的柽柳<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：盐杉">a</a></sup>树下，并禁食七天。</span>
</div>

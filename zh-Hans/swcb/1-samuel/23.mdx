<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约书亚记 15:44; 弥迦书 6:15; 尼希米记 3:17–18"> 有人告诉大卫：“看哪，非利士人正在攻打基伊拉，抢掠禾场。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 23:4; 撒母耳记下 5:19; 撒母耳记下 5:23"> 于是大卫求问耶和华，说：“我可以去攻打这些非利士人吗？”<br />耶和华对大卫说：“去攻打非利士人，拯救基伊拉。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="耶利米书 12:5; 诗篇 11:1; 撒母耳记上 23:15"> 大卫的人对他说：“看哪，我们在犹大这里尚且惧怕，何况我们若去基伊拉，攻击非利士人的军队呢？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士师记 7:7; 约书亚记 8:7; 列王纪下 3:18"> 大卫又再次求问耶和华。耶和华回答他说：“起来，下基伊拉去；因为我必把非利士人交在你手中。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 大卫和跟随他的人到了基伊拉，与非利士人争战，夺走他们的牲畜，大大击杀他们。这样，大卫拯救了基伊拉的居民。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="撒母耳记上 22:20; 撒母耳记上 14:3; 撒母耳记上 14:18"> 亚希米勒的儿子亚比亚他逃到基伊拉投奔大卫的时候，手里带着以弗得下来。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 24:4–6; 约伯记 20:5; 撒母耳记上 26:8–9"> 有人告诉扫罗，大卫到了基伊拉。扫罗说：“上帝已经把他交在我手中了，因为他进了有城门和门闩的城，把自己关在里面了。”</span>
<span className="v" id="v8" data-v="8"> 扫罗召集众民出战，要下到基伊拉去围困大卫和跟随他的人。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 30:7; 撒母耳记上 23:6; 民数记 27:21"> 大卫知道扫罗正设计谋害他，就对亚比亚他祭司说：“把以弗得拿来。”</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 3:15–16; 撒母耳记上 23:8; 创世记 18:24"> 大卫说：“耶和华——以色列的上帝啊，你仆人的确听说扫罗要到基伊拉来，为我的缘故毁灭这城。</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 33:3; 诗篇 50:15; 马太福音 7:7–8"> 基伊拉人会把我交在他手中吗？扫罗会照你仆人所听见的下来吗？耶和华——以色列的上帝啊，求你告诉你仆人。”<br />耶和华说：“他会下来。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 23:20; 诗篇 31:8; 诗篇 62:1"> 大卫又说：“基伊拉人会把我和跟随我的人交在扫罗手中吗？”<br />耶和华说：“他们会把你们交出来。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 22:2; 撒母耳记上 25:13; 撒母耳记上 30:9–10"> 于是大卫和跟随他的人，约有六百，起来离开基伊拉，往他们能去的地方去了。有人告诉扫罗，大卫已经从基伊拉逃脱；扫罗就不去了。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 54:3–4; 诗篇 32:7; 约书亚记 15:24"> 大卫住在旷野的山寨里，停留在西弗旷野的山地。扫罗天天寻找他，但上帝没有把他交在扫罗手中。</span>
<span className="v" id="v15" data-v="15"> 大卫知道扫罗已经出来寻索他的性命。那时大卫在西弗旷野的树林里。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 35:3–4; 希伯来书 12:12–13; 约伯记 4:3–4"> 扫罗的儿子约拿单起来，到树林里去见大卫，使他靠着上帝得以坚固。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 20:31; 撒母耳记上 24:20; 使徒行传 28:16"> 他对大卫说：“不要惧怕，因为我父亲扫罗的手找不到你；你必作以色列的王，我也必在你以下；这事我父亲扫罗也知道。”</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 21:7; 撒母耳记上 20:42; 撒母耳记上 18:3"> 他们二人在耶和华面前立约。然后大卫仍住在树林里，约拿单回自己的家去了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 26:1; 撒母耳记上 26:3; 诗篇 54:1–7"> 西弗人上到基比亚见扫罗，说：“大卫不是藏在我们那里吗？他在树林里的山寨中，在荒原以南的哈基拉山上。</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 23:12; 箴言 29:26; 箴言 11:23"> 现在，王啊，请你下来，照你心里一切所愿的下来；我们的责任就是把他交在王手中。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 22:8; 以赛亚书 66:5; 弥迦书 3:11"> 扫罗说：“愿你们蒙耶和华赐福，因为你们怜悯了我。</span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 5:13"> 请你们去，再查得更确实，知道并看明他出没的地方在哪里，又是谁在那里看见了他；因为有人告诉我，他非常狡猾。</span>
<span className="v" id="v23" data-v="23" data-xref="罗马书 3:15–16; 马可福音 14:1; 民数记 10:36"> 所以你们要察看，确认他藏身的一切隐蔽处；然后带着确实的消息回来见我，我就与你们同去。若他在这地境内，我必在犹大的千万人中搜出他来。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="撒母耳记上 25:2; 约书亚记 15:55"> 他们就起来，在扫罗以先往西弗去；但大卫和跟随他的人在玛云旷野，在荒原以南的亚拉巴。</span>
<span className="v" id="v25" data-v="25" data-xref="士师记 15:8; 撒母耳记上 23:28"> 扫罗和跟随他的人去寻找大卫。有人告诉大卫，他就下到磐石那里，住在玛云旷野。扫罗听见了，就在玛云旷野追赶大卫。</span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 17:9; 哥林多后书 1:8; 诗篇 140:1–9"> 扫罗在山的这一边走，大卫和跟随他的人在山的那一边走；大卫急忙逃避扫罗，因为扫罗和跟随他的人围住大卫和跟随他的人，要捉拿他们。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 19:9; 诗篇 116:3; 申命记 32:36"> 但有一个使者来见扫罗，说：“快快来吧，因为非利士人已经侵袭这地！”</span>
<span className="v" id="v28" data-v="28"> 于是扫罗转回，不再追赶大卫，去迎战非利士人。因此，人给那地方起名叫西拉·哈玛希罗结。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“西拉·哈玛希罗结”的意思是“分离之岩”。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="历代志下 20:2; 约书亚记 15:62; 以西结 47:10"> 大卫从那里上去，住在隐·基底的山寨里。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 6:27; 弥迦书 7:5; 撒母耳记下 1:25–26"> 有一天，扫罗的儿子约拿单对给他拿兵器的年轻人说：“来！我们过到那边非利士人的防营去。”但他没有告诉父亲。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 13:15–16; 以赛亚书 10:28–29"> 扫罗停留在基比亚的尽边，在米矶仑的石榴树下；与他同在的百姓约有六百人，</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 22:20; 撒母耳记上 2:28; 撒母耳记上 4:21"> 还有亚希亚，就是亚希突的儿子、以迦博的兄弟、非尼哈的儿子、以利的孙子；以利从前在示罗作耶和华的祭司。亚希亚穿着以弗得。百姓不知道约拿单已经离开了。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 13:23"> 在约拿单想要经过、到非利士人防营去的隘口之间，这边有一座岩石峭壁，那边也有一座岩石峭壁；一座名叫播薛，另一座名叫西尼。</span>
<span className="v" id="v5" data-v="5"> 一座峭壁在北边，面对密抹，另一座在南边，面对迦巴。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 19:26; 罗马书 8:31; 撒迦利亚书 4:6"> 约拿单对给他拿兵器的年轻人说：“来！我们过到这些未受割礼之人的防营去。也许耶和华会为我们行事，因为耶和华施行拯救，不受人数多少限制。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 7:3; 撒迦利亚书 8:23; 撒母耳记上 10:7"> 给他拿兵器的人对他说：“你心里所想的，尽管去做。去吧，看哪，我照你的心意与你同在。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="士师记 7:9–14"> 约拿单说：“看哪，我们要过到那些人那里，让他们看见我们。</span>
<span className="v" id="v9" data-v="9" data-xref="士师记 6:36–40; 创世记 24:13–14"> 如果他们这样对我们说：‘等到我们到你们那里去！’我们就站在原处，不上他们那里去。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 24:14; 撒母耳记上 10:7; 士师记 7:11"> 但如果他们这样说：‘上到我们这里来！’我们就上去，因为耶和华已经把他们交在我们手里了。这就是给我们的记号。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 13:6; 撒母耳记上 14:22; 士师记 6:2"> 他们二人就让非利士人的防营看见自己；非利士人说：“看哪，希伯来人从他们藏身的洞里出来了！”</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 17:43–44; 撒母耳记下 5:24; 士师记 7:15"> 防营的人回应约拿单和给他拿兵器的人，说：“上到我们这里来，我们要给你们看点东西！”<br />约拿单对给他拿兵器的人说：“跟着我上来，因为耶和华已经把他们交在以色列手里了。”</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 8:31; 约书亚记 23:10; 利未记 26:7–8"> 约拿单就手脚并用地爬上去，给他拿兵器的人跟在他后面。敌人在约拿单面前倒下，给他拿兵器的人跟在他后面杀他们。</span>
<span className="v" id="v14" data-v="14"> 约拿单和给他拿兵器的人这第一次击杀的，约有二十人，在一英亩地里约半条犁沟的距离内。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 13:17; 创世记 35:5; 撒母耳记下 5:24"> 营中、田野和所有百姓中都起了震恐；防营的人和掠兵也都震恐；地也震动，于是有极大的震恐。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志下 20:22–25; 以赛亚书 19:2; 士师记 7:22"> 在便雅悯的基比亚，扫罗的守望者观看；看哪，群众溃散，四处奔逃。</span>
<span className="v" id="v17" data-v="17"> 扫罗就对与他同在的百姓说：“现在清点一下，看看我们这里少了谁。”他们清点之后，看哪，约拿单和给他拿兵器的人不在那里。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 30:7–8; 撒母耳记上 5:2; 士师记 20:23"> 扫罗对亚希亚说：“把上帝的约柜带到这里来。”因为那时上帝的约柜与以色列人同在。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 14:24; 民数记 27:21; 约书亚记 9:14"> 扫罗正和祭司说话的时候，非利士人营中的骚乱越来越大；扫罗就对祭司说：“收回你的手！”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="士师记 7:22; 历代志下 20:23; 撒母耳记上 14:16"> 扫罗和与他同在的众百姓集合起来，来到战场；看哪，非利士人在极大的混乱中，各人用刀互相击杀。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 29:4; 士师记 7:23"> 先前与非利士人在一起、从四围随他们上到营中的希伯来人，也转而与跟随扫罗和约拿单的以色列人在一起。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 13:6; 撒母耳记上 31:7"> 同样，所有藏在以法莲山地的以色列人，听见非利士人逃跑，也在战斗中紧追他们。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 14:30; 撒母耳记上 13:5; 诗篇 44:6–8"> 那一天，耶和华拯救了以色列；战事越过伯亚文。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约书亚记 6:26; 罗马书 10:2; 士师记 1:28"> 那一天，以色列人很困乏，因为扫罗曾叫百姓起誓，说：“凡在晚上以前，在我向仇敌报仇以前吃任何食物的人，必受咒诅。”所以百姓没有一个人尝食物。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及记 3:8; 民数记 13:27; 申命记 9:28"> 众百姓都进了树林；地上有蜜。</span>
<span className="v" id="v26" data-v="26" data-xref="传道书 9:2"> 百姓进了树林，看哪，有蜜滴下来，可是没有人伸手入口，因为百姓惧怕那誓言。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 14:29; 撒母耳记上 14:43; 撒母耳记上 30:12"> 但约拿单没有听见他父亲用誓言命令百姓。因此他伸出手中杖的末端，蘸在蜂房里，又把手送入口中；他的眼睛就明亮起来。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 14:43; 撒母耳记上 14:24"> 百姓中有一个人回答说：“你父亲曾严严地叫百姓起誓，说：‘今天吃食物的人，必受咒诅。’”所以百姓疲乏。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="列王纪上 18:18; 约书亚记 7:25"> 约拿单说：“我父亲连累了这地。请看，我只尝了一点这蜜，眼睛就明亮起来。</span>
<span className="v" id="v30" data-v="30" data-xref="传道书 9:18"> 何况今天百姓若能自由吃他们从仇敌所得的掠物呢？现在击杀非利士人的岂不是会更多吗？”</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 10:12; 约书亚记 19:42"> 那一天，他们从密抹到亚雅仑击杀非利士人。百姓非常疲乏；</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记上 15:19; 利未记 3:17; 利未记 17:10–14"> 百姓就扑向掠物，取了羊、牛和牛犊，在地上宰杀；百姓吃的时候连血一起吃了。</span>
<span className="v" id="v33" data-v="33" data-xref="罗马书 2:1; 马太福音 7:5"> 有人告诉扫罗说：“看哪，百姓吃带血的肉，得罪耶和华了。”<br />他说：“你们行事背信。今天把一块大石头滚到我这里来！”</span>
<span className="v" id="v34" data-v="34"> 扫罗说：“你们散到百姓中，对他们说：‘各人把自己的牛，各人把自己的羊，带到我这里来，在这里宰杀了吃；不要吃带血的肉，得罪耶和华。’”那一夜，众百姓各人把自己的牛带来，在那里宰杀。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="撒母耳记上 7:17; 撒母耳记上 7:12; 提摩太后书 3:5"> 扫罗为耶和华筑了一座坛。这是他为耶和华所筑的第一座坛。</span>
<span className="v" id="v36" data-v="36" data-xref="以赛亚书 48:1–2; 诗篇 73:28; 玛拉基书 2:7"> 扫罗说：“我们夜里下去追赶非利士人，掳掠他们直到晨光，不留下他们一人。”<br />他们说：“你看怎样好，就怎样做吧。”<br />祭司说：“我们在这里亲近上帝吧。”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="撒母耳记上 28:6; 撒母耳记上 30:7–8; 撒母耳记上 23:9–12"> 扫罗求问上帝：“我可以下去追赶非利士人吗？你要把他们交在以色列手里吗？”但那一天上帝没有回答他。</span>
<span className="v" id="v38" data-v="38" data-xref="士师记 20:2; 约书亚记 7:14–26; 民数记 24:17"> 扫罗说：“你们百姓所有的首领都到这里来，要查明，看今日这罪在谁身上。</span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳记上 14:44; 撒母耳记下 12:5; 撒母耳记上 14:24"> 我指着拯救以色列的永活耶和华起誓，即使罪在我儿子约拿单身上，他也必定要死。”但众百姓中没有一个人回答他。</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳记下 15:15; 撒母耳记上 14:7; 撒母耳记上 14:36"> 于是他对全以色列说：“你们站在一边，我和我儿子约拿单站在另一边。”<br />百姓对扫罗说：“你看怎样好，就怎样做吧。”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="使徒行传 1:24; 约书亚记 7:16–18; 撒母耳记上 10:20–21"> 因此扫罗对耶和华以色列的上帝说：“求你显明正确的一方。”<br />约拿单和扫罗被抽中，百姓却脱出。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> 扫罗说：“在我和我儿子约拿单之间抽签。”<br />约拿单被抽中了。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="约书亚记 7:19; 撒母耳记上 14:27; 约拿 1:7–10"> 扫罗就对约拿单说：“告诉我，你做了什么！”<br />约拿单告诉他，说：“我的确用手中杖的末端尝了一点蜜；看哪，我必须死。”</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="撒母耳记上 14:39; 路得记 1:17; 撒母耳记上 25:22"> 扫罗说：“愿上帝这样，并且加倍地降罚；约拿单，你必定要死。”</span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="路加福音 21:18; 使徒行传 27:34; 撒母耳记下 14:11"> 百姓对扫罗说：“约拿单在以色列中成就了这样大的拯救，难道他该死吗？绝不可！我指着永活的耶和华起誓，他头上的一根头发也不可落到地上，因为他今日是与上帝一同做成这事！”于是百姓救了约拿单，他就没有死。</span>
<span className="v" id="v46" data-v="46"> 扫罗就停止追赶非利士人，上去了；非利士人也回到自己的地方。</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="撒母耳记下 10:6; 撒母耳记上 14:52; 撒母耳记下 8:3"> 扫罗取得以色列的王权以后，就攻打他四围所有的仇敌：摩押、亚扪人、以东、琐巴诸王，以及非利士人。他无论转向哪里，都打败他们。</span>
<span className="v" id="v48" data-v="48" data-xref="出埃及记 17:14; 撒母耳记上 15:3–7; 申命记 25:19"> 他奋勇行事，击打亚玛力人，救以色列脱离抢掠他们之人的手。</span>
<span className="v" id="v49" data-v="49" data-xref="历代志上 8:33; 撒母耳记上 31:2; 撒母耳记下 6:20–23"> 扫罗的儿子是约拿单、亦施韦和麦基舒亚；他的两个女儿名字如下：长女名叫米拉，次女名叫米甲。</span>
<span className="v" id="v50" data-v="50" data-xref="撒母耳记下 2:8; 撒母耳记上 17:55; 撒母耳记下 3:27"> 扫罗的妻子名叫亚希暖，是亚希玛斯的女儿。他军队的元帅名叫押尼珥，是尼珥的儿子；尼珥是扫罗的叔叔。</span>
<span className="v" id="v51" data-v="51" data-xref="撒母耳记上 9:1; 撒母耳记上 9:21"> 基士是扫罗的父亲；押尼珥的父亲尼珥是亚别的儿子。</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="撒母耳记上 8:11; 撒母耳记上 8:1"> 扫罗在世的日子，与非利士人有激烈的战争；扫罗看见任何勇士或任何英勇的人，就把他收归自己使用。</span>
</div>
</div>

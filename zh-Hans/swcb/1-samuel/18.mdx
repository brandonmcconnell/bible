<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 20:17; 箴言 18:24; 撒母耳记上 18:3"> 大卫对扫罗说完话以后，约拿单的心就与大卫的心紧密相连；约拿单爱他，如同爱自己的性命。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记上 17:15; 撒母耳记上 16:21–23"> 那一天，扫罗留下大卫，不再让他回父亲的家。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 20:8–17; 撒母耳记上 20:42; 撒母耳记下 21:7"> 约拿单与大卫立约，因为约拿单爱他，如同爱自己的性命。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 41:42; 路加福音 15:22; 以斯帖记 6:8–9"> 约拿单脱下自己身上的外袍，连同衣服，以及刀、弓、腰带，都给了大卫。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 18:30; 撒母耳记上 18:14–15; 歌罗西书 4:5"> 扫罗无论差遣大卫到哪里，他都行事明智；扫罗就立他统领战士。这在众百姓眼中看为好，在扫罗臣仆眼中也看为好。</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 15:20; 士师记 11:34; 诗篇 68:25"> 众人回来，大卫击杀那非利士人归来的时候，妇女们从以色列各城出来，唱歌跳舞，拿着铃鼓，欢欢喜喜，带着乐器，迎接扫罗王。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 21:11; 撒母耳记上 29:5; 出埃及记 15:21"> 妇女们一边奏乐，一边彼此唱和说：<br /><span className="pl pl-1">“扫罗杀死千千，</span><br /><span className="pl pl-2">大卫杀死万万。”</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 15:28; 箴言 13:10; 雅各书 4:5"> 扫罗非常恼怒，这话使他不悦。他说：“她们把万万归给大卫，只把千千归给我。他还缺少什么呢？只剩下王国了！”</span>
<span className="v" id="v9" data-v="9" data-xref="马可福音 7:22; 创世记 31:2; 马太福音 20:15"> 从那一天起，扫罗就嫉视大卫。</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记上 19:9; 帖撒罗尼迦后书 2:11; 列王纪上 18:29"> 第二天，从上帝那里来的邪灵猛烈临到扫罗，他就在屋中说预言。大卫照平常一样用手弹琴。扫罗手里拿着枪；</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 20:33; 以赛亚书 54:17; 路加福音 4:30"> 扫罗把枪掷出去，因为他说：“我要把大卫钉在墙上！”大卫两次从他面前躲开。</span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 18:15; 撒母耳记上 18:29; 撒母耳记上 16:13–14"> 扫罗惧怕大卫，因为耶和华与大卫同在，却离开了扫罗。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 5:2; 诗篇 121:8; 撒母耳记上 18:16–17"> 因此扫罗使大卫离开自己面前，立他作千夫长；大卫就在百姓面前出入。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="创世记 39:23; 马太福音 28:20; 撒母耳记上 16:18"> 大卫在一切事上行事明智；耶和华与他同在。</span>
<span className="v" id="v15" data-v="15" data-xref="雅各书 3:17; 歌罗西书 4:5; 雅各书 1:5"> 扫罗见大卫行事非常明智，就畏惧他。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 18:5; 民数记 27:17; 列王纪上 3:7"> 但全以色列和犹大都爱大卫，因为他在他们面前出入。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 17:25; 撒母耳记上 25:28; 撒母耳记上 18:25"> 扫罗对大卫说：“看哪，我的大女儿米拉，我要把她给你作妻子。你只要为我作勇士，争战耶和华的战役。”因为扫罗说：“不要让我的手加在他身上，要让非利士人的手加在他身上。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 7:18; 撒母耳记上 9:21; 撒母耳记上 18:23"> 大卫对扫罗说：“我是谁？我的性命算什么？我父亲的家在以色列中又算什么？我怎能作王的女婿呢？”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="士师记 7:22; 撒母耳记下 21:8; 士师记 14:20"> 到了扫罗的女儿米拉本该给大卫的时候，她却给了米何拉人亚得列作妻子。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 18:28"> 扫罗的女儿米甲爱大卫；有人告诉扫罗，扫罗看这事为好。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 18:17; 出埃及记 10:7; 耶利米书 9:8"> 扫罗说：“我要把她给大卫，使她成为他的网罗，好让非利士人的手攻击他。”因此扫罗第二次对大卫说：“你今日可以作我的女婿。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="诗篇 36:1–3; 诗篇 55:21; 撒母耳记下 13:28–29"> 扫罗吩咐臣仆说：“你们私下对大卫说：‘看哪，王喜悦你，他所有的臣仆也都爱你；现在你就作王的女婿吧。’”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="诗篇 119:141; 箴言 14:20; 传道书 9:15–16"> 扫罗的臣仆把这些话说给大卫听。大卫说：“你们以为作王的女婿是小事吗？我不过是贫穷卑微的人。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 扫罗的臣仆告诉他说：“大卫是这样说的。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 34:12; 撒母耳记上 18:17; 撒母耳记上 14:24"> 扫罗说：“你们要告诉大卫：‘王不要什么聘礼，只要一百个非利士人的阳皮，好向王的仇敌报仇。’”扫罗心想，要使大卫落在非利士人的手里。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记上 18:21"> 扫罗的臣仆把这些话告诉大卫，大卫就喜欢作王的女婿。期限还没有到，</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记下 3:14; 士师记 14:19; 撒母耳记上 18:13"> 大卫和跟随他的人就起身前去，杀了二百个非利士人。大卫把他们的阳皮带来，足数交给王，为要作王的女婿。于是扫罗把自己的女儿米甲给大卫作妻子。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 24:20; 撒母耳记上 26:25; 创世记 37:8–11"> 扫罗看见并知道耶和华与大卫同在；扫罗的女儿米甲也爱大卫。</span>
<span className="v" id="v29" data-v="29" data-xref="传道书 4:4; 约翰福音 11:53; 雅各书 2:19"> 扫罗就更加惧怕大卫；扫罗一直作大卫的仇敌。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 18:5; 撒母耳记下 11:1; 彼得前书 2:4"> 后来，非利士人的首领们出战；每逢他们出战，大卫行事都比扫罗所有的臣仆更明智，因此他的名大受尊重。</span>
</div>

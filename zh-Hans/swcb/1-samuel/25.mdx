<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 28:3; 民数记 20:29; 申命记 34:8"> 撒母耳死了；以色列众人聚集，为他哀哭，把他葬在拉玛他自己的家那里。<br />后来大卫起身，下到巴兰的旷野。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 38:13; 撒母耳记上 23:24; 约书亚记 15:55"> 在玛云有一个人，他的产业在迦密；这人极其富有。他有三千只绵羊、一千只山羊；那时他正在迦密剪羊毛。</span>
<span className="v" id="v3" data-v="3" data-xref="箴言 14:1; 箴言 31:10; 以赛亚书 32:5–7"> 那人名叫拿八；他的妻子名叫亚比该。这女子聪明，容貌美丽；但那人为人刚愎，行事邪恶。他是迦勒家族的人。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 38:13; 撒母耳记下 13:23"> 大卫在旷野听见拿八正在剪羊毛。</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 43:23; 撒母耳记上 17:22"> 大卫就派十个年轻人去；大卫对这些年轻人说：“你们上迦密去，到拿八那里，奉我的名问候他。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 10:5; 历代志上 12:18; 诗篇 122:7"> 要对他说：‘愿你长寿！愿你平安！愿你家平安！愿你一切所有的都平安！</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 25:21; 撒母耳记上 25:15–16; 撒母耳记上 22:2"> 现在我听说你有剪羊毛的人。你的牧人如今曾和我们在一起，我们没有伤害他们；他们在迦密的整个期间，什么也没有失落。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯帖记 9:19; 尼希米记 8:10–12; 路加福音 14:12–14"> 你可以问你的年轻人，他们会告诉你。所以愿这些年轻人在你眼前蒙恩，因为我们是在好日子来的。请把你手边所有的，给你的仆人和你的儿子大卫。’”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="列王纪下 2:15; 历代志下 14:7; 创世记 8:4"> 大卫的年轻人到了，就奉大卫的名把这一切话告诉拿八，然后等候。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="士师记 9:28; 以赛亚书 32:7; 撒母耳记上 22:7–8"> 拿八回答大卫的仆人说：“大卫是谁？耶西的儿子是谁？如今背离主人逃跑的仆人很多。</span>
<span className="v" id="v11" data-v="11" data-xref="士师记 8:6; 加拉太书 6:10; 哥林多后书 6:9"> 难道我要把我的饼、我的水，和我为剪羊毛的人宰好的肉，拿来给那些我不知道从哪里来的人吗？”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 36:21–22; 撒母耳记下 24:13; 希伯来书 13:17"> 于是大卫的年轻人转身照原路回去，到了大卫那里，把这一切话告诉他。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 23:13; 箴言 25:8; 撒母耳记上 24:5–6"> 大卫对他的人说：“各人都佩上刀！”<br />于是各人都佩上刀。大卫也佩上刀。约有四百人跟随大卫，二百人留守辎重。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="撒母耳记上 13:10; 马可福音 15:29"> 有一个年轻人告诉拿八的妻子亚比该说：“看哪，大卫从旷野派使者来问候我们的主人，他却辱骂他们。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 25:7; 撒母耳记上 25:21; 腓立比书 2:15"> 但是那些人待我们很好；我们在田野与他们同行的时候，没有受伤害，也没有失落什么。</span>
<span className="v" id="v16" data-v="16" data-xref="约伯记 1:10; 出埃及记 14:22; 撒迦利亚书 2:5"> 我们和他们一起牧羊的整个期间，他们昼夜都作我们的墙。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 20:7; 申命记 13:13; 撒母耳记上 20:9"> 所以现在你要知道并考虑该做什么；因为灾祸已经定了，要临到我们的主人和他全家。他是这样一个无赖，没人能和他说话。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 16:1; 马太福音 5:25; 箴言 6:4–5"> 亚比该就急忙拿了二百个饼、两皮袋酒、五只已经收拾好的羊、五细亚<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一细亚约为7公升，或1.9加仑，或0.8配克。">a</a></sup>烘过的谷物、一百串葡萄干、二百个无花果饼，都驮在驴上。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 32:20; 创世记 32:16; 箴言 31:11–12"> 她对自己的年轻人说：“你们走在我前面。看哪，我随后就来。”但她没有告诉丈夫拿八。</span>
<span className="v" id="v20" data-v="20" data-xref="列王纪下 4:24"> 她骑着驴，沿着山间隐蔽处下去；看哪，大卫和他的人也正向她那里下来，她就遇见了他们。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="箴言 17:13; 以弗所书 4:31; 罗马书 12:21"> 大卫曾说：“我在旷野保护这人所有的一切，使他所有的没有一样失落，实在是徒然了；他竟以恶报善。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 14:10; 撒母耳记上 20:13; 撒母耳记上 3:17"> 凡属他的，到明日天亮，若我还留下一个向墙小便的，愿上帝这样惩罚大卫的仇敌，并且加倍惩罚。”<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：男丁。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 20:41; 士师记 1:14; 约书亚记 15:18"> 亚比该看见大卫，就急忙从驴上下来，在大卫面前脸伏于地，俯伏下拜。</span>
<span className="v" id="v24" data-v="24" data-xref="以斯帖记 8:3; 撒母耳记上 25:28; 撒母耳记下 14:9"> 她俯伏在他的脚前，说：“我主啊，罪责归我，归我！请让你的婢女向你进言，也请听婢女的话。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 25:17; 玛拉基书 2:2; 撒母耳记下 13:33"> 请我主不要把这个无赖拿八放在心上，因为他人如其名：他名叫拿八，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“拿八”的意思是“愚昧”。">c</a></sup>愚昧也与他同在；至于我，你的婢女，并没有看见我主所派来的年轻人。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 18:32; 罗马书 12:19–20; 创世记 20:6"> 现在，我主啊，我指着永生的耶和华和你的性命起誓，既然耶和华阻止了你，使你不至于流人血担罪，也不亲手为自己报仇，那么现在，愿你的仇敌和那些谋害我主的人都像拿八一样。</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 33:11; 撒母耳记上 30:26; 列王纪下 5:15"> 现在，婢女带给我主的这份礼物，愿交给跟随我主的年轻人。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 18:17; 撒母耳记下 7:11; 撒母耳记上 24:11"> 请赦免你婢女的过犯。因为我主为耶和华争战，耶和华必定为我主建立稳固的家；你一生都不会被查出有恶。</span>
<span className="v" id="v29" data-v="29" data-xref="约翰福音 17:21; 马太福音 10:29–30; 玛拉基书 3:17"> 虽然有人起来追赶你，索取你的性命，我主的性命却必与耶和华你的上帝同在，包在生命的包裹中；至于你仇敌的性命，祂必把他们甩出去，如同从机弦的兜里甩出一样。</span>
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 13:14; 诗篇 89:20; 撒母耳记上 23:17"> 将来耶和华照着祂论到你所说的一切好话成就，并立你作以色列的领袖时，</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 40:14; 罗马书 12:19; 路加福音 23:42"> 这事就不会成为你的忧伤，也不会使我主心里绊跌，就是无故流血，或我主亲自报仇。耶和华恩待我主的时候，求你记念你的婢女。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="路加福音 1:68; 出埃及记 18:10; 诗篇 72:18"> 大卫对亚比该说：“耶和华以色列的上帝是当受称颂的，因为祂今日派你来迎接我！</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记上 25:26; 箴言 28:23; 箴言 9:9"> 你的明辨是当称赞的；你也是有福的，因为你今日阻止了我，使我不至于流人血担罪，也不亲手为自己报仇。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记上 11:11; 撒母耳记上 25:26; 约书亚记 10:6"> 我指着永生的耶和华以色列的上帝起誓，祂阻止我加害于你；你若没有急忙来迎接我，到明日天亮，拿八那里必定连一个向墙小便的也不剩下。”<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或作：一个男丁。">d</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="创世记 19:21; 撒母耳记上 20:42; 列王纪下 5:19"> 于是大卫从她手中收下她带来的东西，又对她说：“平平安安上你家去吧。看哪，我听从了你的话，准了你的请求。”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="撒母耳记上 25:19; 撒母耳记下 13:23; 撒母耳记下 13:28"> 亚比该回到拿八那里；看哪，他在家里摆设宴席，好像王的宴席。拿八心中快乐，因为他醉得很厉害。所以她直到天亮都没有告诉他什么。</span>
<span className="v" id="v37" data-v="37" data-xref="申命记 28:28; 撒母耳记上 25:34; 撒母耳记上 25:22"> 到了早晨，拿八酒醒以后，他的妻子把这些事告诉他；他的心就在他里面死了，变得像石头一样。</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳记上 26:10; 列王纪下 15:5; 撒母耳记上 6:9"> 约过了十天，耶和华击打拿八，他就死了。</span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳记上 25:26; 撒母耳记上 25:34; 箴言 22:23"> 大卫听见拿八死了，就说：“耶和华是当受称颂的，祂为我辩明了拿八加给我的羞辱，又拦阻祂的仆人不行恶。耶和华使拿八的恶行归到他自己头上。”<br />大卫就派人去向亚比该提亲，要娶她为妻。</span>
<span className="v" id="v40" data-v="40" data-xref="创世记 24:51; 创世记 24:37–38"> 大卫的仆人到了迦密亚比该那里，对她说：“大卫派我们到你这里来，要娶你去作他的妻子。”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="提摩太前书 5:10; 约翰福音 13:3–5; 路得记 2:10"> 她就起来，脸伏于地，俯伏下拜，说：“看哪，婢女愿作仆人，洗我主仆人的脚。”</span>
<span className="v" id="v42" data-v="42" data-xref="创世记 24:61–67; 诗篇 45:10–11"> 亚比该急忙起身，骑上驴，带着五个跟随她的婢女；她跟随大卫的使者去了，作了他的妻子。</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳记上 30:5; 约书亚记 15:56; 撒母耳记上 27:3"> 大卫也娶了耶斯列人亚希暖；她们二人都作了他的妻子。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="撒母耳记下 3:14; 撒母耳记上 18:27; 撒母耳记上 18:20"> 扫罗已经把他的女儿、大卫的妻子米甲，给了迦琳人拉亿的儿子帕提。</span>
</div>
</div>

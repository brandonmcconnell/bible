<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 3:11; 创世记 8:21; 民数记 9:2–3"> “你要吩咐以色列人，对他们说：‘你们要谨慎，在指定的时候把我的供物，就是献给我的食物、作为馨香之气献给我的火祭，献上。’</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 6:9; 但以理 11:31; 约翰福音 1:29"> 你要对他们说：‘这是你们要献给耶和华的火祭：一岁的公羊羔，没有残疾，每天两只，作为常献的燔祭。</span>
<span className="v" id="v4" data-v="4" data-xref="但以理 9:21; 列王纪上 18:36; 出埃及记 12:6"> 早晨要献一只羊羔，傍晚要献另一只羊羔；</span>
<span className="v" id="v5" data-v="5" data-xref="利未记 2:1; 出埃及记 16:36; 出埃及记 29:38–42"> 并献十分之一伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="1伊法约为22升，或约为一蒲式耳的三分之二。">a</a></sup>细面作素祭，调上四分之一欣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="1欣约为6.5升，或1.7加仑。">b</a></sup>捣成的油。</span>
<span className="v" id="v6" data-v="6" data-xref="阿摩司 5:25; 利未记 6:9; 诗篇 50:8"> 这是在西奈山所规定常献的燔祭，作为馨香之气，是献给耶和华的火祭。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 29:42; 民数记 28:14; 以赛亚书 57:6"> 每只羊羔的奠祭要用四分之一欣<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="1欣约为6.5升，所以四分之一欣约为1.6升，或1.7夸脱。">c</a></sup>。你要在圣所中把浓酒作为奠祭浇奠给耶和华。</span>
<span className="v" id="v8" data-v="8"> 傍晚要献另一只羊羔；要像早晨的素祭和奠祭一样献上，作为火祭，献给耶和华作馨香之气。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 58:13; 诗篇 92:1–4; 启示录 1:10"> “‘在安息日，要献两只一岁的公羊羔，没有残疾，并献十分之二伊法<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="1伊法约为22升，或约为一蒲式耳的三分之二。">d</a></sup>细面作素祭，调上油，又献同献的奠祭；</span>
<span className="v" id="v10" data-v="10" data-xref="以西结 46:4–5; 民数记 29:22; 民数记 29:31"> 这是每个安息日的燔祭，是在常献的燔祭和同献的奠祭以外献的。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民数记 10:10; 以西结 46:6; 以斯拉记 3:5"> “‘在你们每月初一，要向耶和华献燔祭：两头公牛犊、一只公绵羊、七只一岁的公羊羔，都没有残疾；</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 15:4–12; 以西结 46:5–7; 民数记 29:10"> 每头公牛要献十分之三伊法<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="1伊法约为22升，或约为一蒲式耳的三分之二。">e</a></sup>细面作素祭，调上油；那一只公绵羊要献十分之二细面作素祭，调上油；</span>
<span className="v" id="v13" data-v="13"> 每只羊羔要献十分之一细面，调上油作素祭，作为馨香的燔祭，是献给耶和华的火祭。</span>
<span className="v" id="v14" data-v="14"> 同献的奠祭，每头公牛要用半欣酒，公绵羊要用三分之一欣，羊羔要用四分之一欣。这是一年中每个月当献的燔祭。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 28:3; 民数记 28:22; 民数记 15:24"> 又要把一只公山羊作为赎罪祭献给耶和华，是在常献的燔祭和同献的奠祭以外献的。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命记 16:1–8; 出埃及记 12:18; 利未记 23:5–8"> “‘正月十四日是耶和华的逾越节。</span>
<span className="v" id="v17" data-v="17" data-xref="利未记 23:6; 出埃及记 23:15; 出埃及记 13:6"> 这个月十五日要守节；要吃无酵饼七天。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 12:16; 利未记 23:7–8"> 第一天要有圣会；你们不可做日常劳作，</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 15:21; 以西结 45:21–25; 民数记 29:8"> 却要献火祭，就是献给耶和华的燔祭：两头公牛犊、一只公绵羊、七只一岁的公羊羔；它们都要没有残疾。</span>
<span className="v" id="v20" data-v="20"> 同献的素祭要用调油的细面：每头公牛献十分之三伊法，公绵羊献十分之二伊法；</span>
<span className="v" id="v21" data-v="21"> 七只羊羔中，每只羊羔献十分之一伊法；</span>
<span className="v" id="v22" data-v="22" data-xref="罗马书 8:3"> 又献一只公山羊作赎罪祭，为你们赎罪。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 28:3; 民数记 28:10"> 这些要在早晨的燔祭，就是常献的燔祭以外献上。</span>
<span className="v" id="v24" data-v="24"> 七天之中，每天都要这样献上火祭的食物，作为献给耶和华的馨香之气；这是在常献的燔祭和同献的奠祭以外献的。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 23:8; 民数记 28:18; 出埃及记 13:6"> 第七天你们要有圣会；不可做日常劳作。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 23:16; 出埃及记 34:22; 利未记 23:10"> “‘在初熟果子的日子，就是你们在七七节向耶和华献新素祭的时候，要有圣会；你们不可做日常劳作；</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 23:18–19; 民数记 28:11; 民数记 28:19"> 却要献燔祭给耶和华作馨香之气：两头公牛犊、一只公绵羊、七只一岁的公羊羔；</span>
<span className="v" id="v28" data-v="28"> 同献的素祭要用调油的细面：每头公牛献十分之三伊法，那一只公绵羊献十分之二伊法；</span>
<span className="v" id="v29" data-v="29"> 七只羊羔中，每只羊羔献十分之一伊法；</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 28:15; 民数记 28:22; 彼得前书 2:24"> 又献一只公山羊，为你们赎罪。</span>
<span className="v" id="v31" data-v="31" data-xref="民数记 28:19; 民数记 28:3; 玛拉基书 1:13–14"> 除了常献的燔祭和同献的素祭以外，你们还要献上这些和同献的奠祭。你们要确保它们没有残疾。</span>
</div>
</div>

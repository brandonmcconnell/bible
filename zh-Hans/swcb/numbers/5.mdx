<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 21:1; 利未记 13:46; 民数记 12:14"> “你要吩咐以色列人，把每一个麻风病人、每一个患漏症的人，以及凡因尸体而不洁净的人，都送出营外。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 23:14; 利未记 26:11–12; 诗篇 68:18"> 无论男女，你们都要把他们送到营外，免得他们玷污自己的营；我就住在他们中间。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 以色列人就这样做，把他们送到营外；耶和华怎样吩咐摩西，以色列人就怎样做了。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 耶和华对摩西说：</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 5:1–4; 利未记 5:14–7"> “你要告诉以色列人：‘无论男人女人，若犯了人所犯的任何罪，以致干犯耶和华，那人就有罪了，</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 5:5; 利未记 26:40; 约书亚记 7:19"> 他就要承认自己所犯的罪；他要为自己的罪全数赔偿，另加五分之一，交给他所亏负的那人。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 6:6–7; 利未记 7:7; 利未记 25:25–26"> 但那人若没有亲属可以接受这罪的赔偿，那么为罪所作、归给耶和华的赔偿就要归祭司；此外，还要献上为他赎罪的公绵羊，借此为他赎罪。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 18:3–4; 利未记 7:6–14; 利未记 6:17–18"> 以色列人一切圣物中的每一份举祭，就是他们献给祭司的，都要归祭司。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 10:13"> 各人的圣物要归自己；任何人给祭司的，都要归祭司。’”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和华对摩西说：</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 5:19–20; 箴言 2:16–17"> “你要告诉以色列人，对他们说：‘若有人的妻子偏离正道，对他不忠，</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 18:20; 利未记 20:10; 箴言 7:18–19"> 有男人与她同寝交合，这事瞒过她丈夫的眼睛，被隐藏起来；她被玷污了，却没有证人指证她，也没有当场被抓住；</span>
<span className="v" id="v14" data-v="14" data-xref="雅歌 8:6; 箴言 6:34; 西番雅书 3:8"> 丈夫若有疑忌的心临到他，他就疑忌自己的妻子，而她确实被玷污了；或者他有疑忌的心临到他，他就疑忌自己的妻子，而她并没有被玷污；</span>
<span className="v" id="v15" data-v="15" data-xref="以西结 29:16; 列王纪上 17:18; 利未记 5:11"> 这人就要带妻子到祭司那里，也要为她带上供物：一伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="1伊法约等于22升，或约三分之二蒲式耳。">a</a></sup>的十分之一大麦面。他不可在上面浇油，也不可加乳香，因为这是疑忌的素祭，是记念的素祭，使罪孽被记起。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 2:22–23; 耶利米书 17:10; 希伯来书 13:4"> 祭司要使那女人近前来，让她站在耶和华面前。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 30:18; 约翰福音 8:6; 民数记 19:2–9"> 祭司要用瓦器取圣水，又要取一些帐幕地上的尘土，放进水里。</span>
<span className="v" id="v18" data-v="18" data-xref="箴言 5:4; 民数记 5:22; 启示录 10:9–10"> 祭司要让那女人站在耶和华面前，解开那女人头上的头发，把记念的素祭放在她手中，这就是疑忌的素祭。祭司手里要拿着招致咒诅的苦水。</span>
<span className="v" id="v19" data-v="19" data-xref="罗马书 7:2; 民数记 5:12; 马太福音 26:63"> 祭司要叫她起誓，并对那女人说：“若没有男人与你同寝，你在丈夫权下也没有偏离而陷入不洁，就愿你不受这招致咒诅的苦水之害。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 5:12"> 但你若在丈夫权下偏离正道，若你被玷污了，并且有男人在你丈夫以外与你同寝——”</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 6:26; 尼希米记 10:29; 撒母耳记上 14:24"> 祭司就要叫那女人发咒诅的誓；祭司要对那女人说：“愿耶和华使你在你的民中成为咒诅和誓言，当耶和华使你的大腿萎缩、你的身体肿胀时；</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 109:18; 诗篇 89:52; 约伯记 31:39–40"> 这招致咒诅的水要进入你的腹中，使你的身体肿胀、大腿萎缩。”那女人要说：“阿们，阿们。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 3:19; 诗篇 51:1; 诗篇 51:9"> “‘祭司要把这些咒诅写在书卷上，又把它们洗入苦水中。</span>
<span className="v" id="v24" data-v="24" data-xref="撒迦利亚书 5:3–4; 玛拉基书 3:5"> 他要使那女人喝下招致咒诅的苦水；那招致咒诅的水要进入她里面，变为苦。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 8:27; 民数记 5:18; 民数记 5:15"> 祭司要从那女人手中接过疑忌的素祭，在耶和华面前摇一摇这素祭，然后把它带到祭坛前。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 2:2; 利未记 2:9; 利未记 5:12"> 祭司要从素祭中取一把作为记念的部分，烧在祭坛上；然后要使那女人喝那水。</span>
<span className="v" id="v27" data-v="27" data-xref="耶利米书 42:18; 撒迦利亚书 8:13; 耶利米书 29:18"> 他使她喝了那水以后，事情就要这样发生：如果她被玷污，干犯了自己的丈夫，那招致咒诅的水就要进入她里面，变为苦；她的身体要肿胀，大腿要萎缩；那女人就要在她的民中成为咒诅。</span>
<span className="v" id="v28" data-v="28" data-xref="弥迦书 7:7–10; 哥林多后书 4:17; 诗篇 113:9"> 但那女人若没有被玷污，而是洁净的，她就要免受惩罚，并且能怀孕生育后代。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：种子">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数记 5:19; 民数记 5:12; 民数记 5:15"> “‘这就是疑忌的律法：妻子在丈夫权下偏离正道，被玷污，</span>
<span className="v" id="v30" data-v="30"> 或是有疑忌的心临到一个男人，他就疑忌自己的妻子；他就要使那女人站在耶和华面前，祭司要在她身上执行这一切律法。</span>
<span className="v" id="v31" data-v="31" data-xref="利未记 20:10; 罗马书 2:8–9; 以西结 18:4"> 那男人要免除罪孽，那女人却要担当自己的罪孽。’”</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 1:1; 出埃及记 40:2"> 以色列人出埃及地以后第二年正月，耶和华在西奈的旷野对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 16:1–2; 哥林多前书 5:7–8; 历代志下 35:1"> “要让以色列人按所定的时候守逾越节。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 12:6–11; 利未记 23:5; 历代志下 30:2"> 本月十四日黄昏，你们要按所定的时候守这节；要照逾越节一切的条例和一切的典章来守。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 摩西告诉以色列人要守逾越节。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 5:10; 马太福音 28:20; 出埃及记 12:1–13"> 他们就在正月十四日黄昏，在西奈的旷野守逾越节。耶和华怎样吩咐摩西，以色列人就照样行了。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 27:2; 出埃及记 18:15; 民数记 5:2"> 有几个人因人的尸体而不洁净，以致那一天不能守逾越节；那一天，他们来到摩西和亚伦面前。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 16:2; 哥林多前书 5:7–8; 出埃及记 12:27"> 那些人对他说：“我们因人的尸体而不洁净。为什么我们被拦住，不能在所定的时候，在以色列人中间献耶和华的供物呢？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="诗篇 85:8; 民数记 27:5; 哥林多前书 4:4"> 摩西回答他们：“你们等候，我要听耶和华就你们的事有什么吩咐。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 耶和华对摩西说：</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 2:1–2; 以弗所书 2:12–13; 哥林多前书 11:28"> “你要对以色列人说：‘你们中间或你们世世代代中，若有人因尸体而不洁净，或在远方旅途中，他仍要向耶和华守逾越节。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 30:2–15; 出埃及记 12:43–49; 约翰福音 19:36"> 他们要在二月十四日黄昏守这节；要与无酵饼和苦菜一起吃逾越节的羊羔。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 19:36; 出埃及记 12:46; 出埃及记 12:10"> 一点也不可留到早晨，也不可折断它的骨头。他们要照逾越节的一切条例来守。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 17:14; 出埃及记 12:15; 民数记 9:7"> 但那洁净又不在旅途中的人，若不守逾越节，那人要从他的民中被剪除；因为他没有在所定的时候献耶和华的供物，那人要担当自己的罪。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及记 12:48–49; 利未记 24:22; 以赛亚书 56:3–7"> “‘若有外人寄居在你们中间，想要向耶和华守逾越节，他就要照逾越节的条例和典章去行。无论是外人，还是本地出生的人，你们都要有同一条例。’”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及记 13:21; 出埃及记 40:34; 尼希米记 9:19"> 立起帐幕的那一天，云彩遮盖帐幕，就是见证的帐幕。到了晚上，云彩在帐幕上，形状像火，直到早晨。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米记 9:12; 出埃及记 40:38; 哥林多前书 10:1"> 常是这样：云彩遮盖帐幕，夜间有火的形状。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 40:36–38; 诗篇 32:8; 约翰福音 10:9"> 每当云彩从帐幕上升起，以色列人随后就起行；云彩停在哪里，以色列人就在那里安营。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 10:1; 约翰二书 1:6; 出埃及记 17:1"> 以色列人照耶和华的命令起行，也照耶和华的命令安营。云彩在帐幕上停留多久，他们就安营多久。</span>
<span className="v" id="v19" data-v="19" data-xref="撒迦利亚书 3:7; 民数记 1:52–53; 民数记 3:8"> 云彩在帐幕上停留许多日子的时候，以色列人就遵守耶和华的命令，不起行。</span>
<span className="v" id="v20" data-v="20"> 有时云彩在帐幕上停留几天；他们就照耶和华的命令安营，又照耶和华的命令起行。</span>
<span className="v" id="v21" data-v="21" data-xref="尼希米记 9:19; 尼希米记 9:12"> 有时云彩从晚上停到早晨；早晨云彩升起，他们就起行。无论白天或夜间，云彩一升起，他们就起行。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 32:8; 出埃及记 40:36–37; 出埃及记 40:16"> 云彩停留在帐幕上，无论是两天、一个月，或是一年，只要云彩停在其上，以色列人就安营，不起行；但云彩一升起，他们就起行。</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 22:3; 民数记 9:19; 创世记 26:5"> 他们照耶和华的命令安营，也照耶和华的命令起行。他们遵守耶和华的命令，是照耶和华藉摩西所吩咐的。</span>
</div>

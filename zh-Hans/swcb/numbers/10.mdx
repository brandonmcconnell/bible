<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="以赛亚书 1:13; 约珥 1:14; 诗篇 81:3"> “你要用银子做两支号，要用锤打成的工艺来做；你要用它们召集会众，也用于各营起行。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 4:5; 约珥 2:15–16"> 吹这两支号的时候，全会众都要聚集到你那里，到会幕门口。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 7:2; 出埃及记 18:21; 民数记 1:4–16"> 如果只吹一支，以色列千夫队的首领，就是众族长，要聚集到你那里。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 2:3–9; 民数记 10:14; 以赛亚书 58:1"> 你们吹出警号的时候，安营在东边的各营就要起行。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 10:18; 民数记 2:10–16"> 第二次吹出警号的时候，安营在南边的各营就要起行。他们起行时要吹出警号。</span>
<span className="v" id="v7" data-v="7" data-xref="约珥 2:1; 民数记 10:3–4"> 但召集会众的时候，你们要吹号，却不可吹出警号。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约书亚记 6:4–16; 民数记 31:6; 历代志上 15:24"> “亚伦的儿子们，就是祭司，要吹这些号；这要作你们世世代代永远的条例。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 10:18; 士师记 2:18; 创世记 8:1"> 你们在自己的地上与欺压你们的敌人争战时，要用这些号吹出警号；这样，你们就会在耶和华你们的上帝面前被记念，也必从你们的仇敌手中得拯救。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="诗篇 81:3; 帖撒罗尼迦前书 4:16; 哥林多前书 11:24–26"> “在你们欢乐的日子、规定的节期和月朔，你们要在燔祭和平安祭的祭物上吹号；这些号要使你们在你们的上帝面前蒙记念。我是耶和华你们的上帝。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出埃及记 40:17; 民数记 1:1; 民数记 9:11"> 第二年二月二十日，云彩从约的帐幕上升起。</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 21:21; 民数记 12:16; 民数记 9:5"> 以色列人按着他们的行程，从西奈旷野起行；云彩停在巴兰旷野。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 1:6; 民数记 9:23"> 他们初次起行，是照耶和华藉着摩西所吩咐的。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 2:3–9; 民数记 1:7; 民数记 7:12"> 首先，犹大子孙营的旗号按着他们的军队起行；亚米拿达的儿子拿顺统领他的军队。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 7:18; 民数记 1:8"> 苏押的儿子拿坦业统领以萨迦子孙支派的军队。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 7:24; 民数记 1:9"> 希伦的儿子以利押统领西布伦子孙支派的军队。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 7:6–8; 民数记 1:51; 希伯来书 12:28"> 帐幕拆卸下来；革顺的子孙和米拉利的子孙抬着帐幕起行。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 2:10–16; 民数记 1:5; 民数记 26:5–18"> 流便营的旗号按着他们的军队起行；示丢珥的儿子以利蓿统领他的军队。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 1:6; 民数记 7:36"> 苏利沙代的儿子示路蔑统领西缅子孙支派的军队。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 1:14; 民数记 2:14; 民数记 7:42"> 丢珥的儿子以利雅萨统领迦得子孙支派的军队。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数记 10:17; 民数记 7:9; 民数记 4:4–16"> 哥辖人抬着圣所起行。其他人在他们到达以前已经把帐幕支搭起来。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数记 2:18–24; 民数记 1:10; 民数记 26:23–41"> 以法莲子孙营的旗号按着他们的军队起行；亚米忽的儿子以利沙玛统领他的军队。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 1:10; 民数记 7:54"> 比大蓿的儿子迦玛列统领玛拿西子孙支派的军队。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 1:11; 民数记 7:60"> 基多尼的儿子亚比但统领便雅悯子孙支派的军队。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约书亚记 6:9; 民数记 1:12; 创世记 49:16–17"> 但子孙营的旗号按着他们的军队起行，作各营的后卫；亚米沙代的儿子亚希以谢统领他的军队。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 1:13; 民数记 7:72"> 俄兰的儿子帕结统领亚设子孙支派的军队。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 1:15; 民数记 7:78"> 以南的儿子亚希拉统领拿弗他利子孙支派的军队。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 2:34; 民数记 24:4–5; 哥林多前书 14:33"> 以色列人按着他们的军队就是这样行进的；他们就起行了。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="创世记 12:7; 士师记 4:11; 出埃及记 3:1"> 摩西对何巴说，他是摩西的岳父、米甸人流珥的儿子：“我们正要前往耶和华所说‘我要把它赐给你们’的地方。请你和我们同去，我们必善待你；因为耶和华已经论到以色列，说要赐福。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="路得记 1:15–17; 诗篇 45:10; 马太福音 21:29"> 何巴对他说：“我不去；我要回我自己的地方，到我的亲族那里去。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约伯记 29:15; 加拉太书 6:2; 哥林多前书 12:14–21"> 摩西说：“请你不要离开我们；因为你知道我们在旷野应当怎样安营，你可以作我们的眼目。</span>
<span className="v" id="v32" data-v="32" data-xref="士师记 1:16; 申命记 10:18; 约翰一书 1:3"> 如果你和我们同去，必定如此：耶和华怎样善待我们，我们也要照样善待你。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="申命记 1:33; 出埃及记 3:1; 诗篇 95:11"> 他们从耶和华的山起行，走了三天的路程。耶和华的约柜在他们前面行了三天的路程，为他们寻找安歇的地方。</span>
<span className="v" id="v34" data-v="34" data-xref="尼希米记 9:12; 尼希米记 9:19; 诗篇 105:39"> 他们从营中起行的时候，白天耶和华的云彩在他们上方。</span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 68:1–2; 以赛亚书 17:12–14; 诗篇 132:8"> 约柜起行的时候，摩西就说：“耶和华啊，求你兴起，愿你的仇敌四散！愿恨你的人从你面前逃跑！”</span>
<span className="v" id="v36" data-v="36" data-xref="申命记 1:10; 诗篇 90:13–17; 以赛亚书 63:17"> 约柜停住的时候，他就说：“耶和华啊，求你回到以色列的千千万万中。”</span>
</div>
</div>

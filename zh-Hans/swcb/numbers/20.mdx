<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 13:21; 出埃及记 15:20; 民数记 33:36"> 以色列人，就是全会众，在正月来到寻的旷野。百姓住在加低斯。米利暗死在那里，也葬在那里。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 16:19; 民数记 16:42; 出埃及记 15:23–24"> 会众没有水，就聚集起来攻击摩西和亚伦。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 17:2; 民数记 14:1–2; 民数记 16:31–35"> 百姓与摩西争闹，说：“巴不得我们在我们的弟兄死在耶和华面前的时候也死了！</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 17:3; 诗篇 106:21; 民数记 16:13–14"> 你们为什么把耶和华的会众带到这旷野，使我们和我们的牲畜都死在这里呢？</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 16:14; 耶利米书 2:2; 耶利米书 2:6"> 你们为什么使我们从埃及上来，把我们带到这恶劣的地方呢？这里不是可撒种的地方，也没有无花果树、葡萄树、石榴树，甚至没有水喝。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数记 14:5; 民数记 16:4; 民数记 16:19"> 摩西和亚伦离开会众面前，来到会幕门口，俯伏在地。耶和华的荣耀向他们显现。</span>
<span className="v" id="v7" data-v="7"> 耶和华对摩西说：</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 4:17; 使徒行传 2:1–4; 启示录 22:17"> “你拿着杖，和你的哥哥亚伦召集会众，在他们眼前吩咐磐石，叫它流出水来。你要从磐石中为他们取出水来，使会众和他们的牲畜有水喝。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数记 17:10"> 摩西照耶和华吩咐他的，从耶和华面前拿了杖。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 106:32–33; 使徒行传 14:9–15; 路加福音 9:54–55"> 摩西和亚伦把会众聚集到磐石前，他对他们说：“你们这些悖逆的人，现在听吧！我们要为你们从这磐石中取出水来吗？”</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 10:4; 出埃及记 17:6; 申命记 8:15"> 摩西举手，用杖击打磐石两下，就有许多水流出来，会众和他们的牲畜都喝了。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命记 1:37; 民数记 27:14; 以西结 36:23"> 耶和华对摩西和亚伦说：“因为你们不信我，没有在以色列人眼前尊我为圣，所以你们必不得把这会众带进我赐给他们的地。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="出埃及记 17:7; 诗篇 95:8; 申命记 33:8"> 这些水就是米利巴水；<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“米利巴”的意思是“争闹”。">a</a></sup>因为以色列人与耶和华争闹，耶和华就在他们中间显为圣。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="士师记 11:16–17; 申命记 23:7; 俄巴底亚 1:10–12"> 摩西从加低斯派使者去见以东王，说：<br />“你的弟兄以色列这样说：我们所遭遇的一切艰难，你都知道；</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 12:40; 申命记 26:6; 创世记 46:6"> 我们的祖先下到埃及，我们在埃及住了许久。埃及人恶待我们和我们的祖先。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 14:19; 出埃及记 23:20; 出埃及记 33:2"> 我们向耶和华呼求的时候，祂听了我们的声音，差遣一位使者，把我们从埃及领出来。看哪，我们现在在加低斯，就是你边界边上的一座城。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="申命记 2:27; 申命记 2:29; 民数记 21:22–24"> “请让我们经过你的地。我们不经过田地，也不经过葡萄园，也不喝井里的水；我们要走王道，不偏向右，也不偏向左，直到经过你的边界。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 以东对他说：“你不可从我这里经过，免得我带刀出去攻击你。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="申命记 2:28; 申命记 2:6; 出埃及记 12:38"> 以色列人对他说：“我们要沿大道上去；如果我和我的牲畜喝了你的水，我就付水价。只求让我步行经过，并不做别的事。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="士师记 11:17; 阿摩司 1:11; 创世记 32:6"> 他说：“你不可经过。”以东率领许多民众，用强大的兵力出来攻击他。</span>
<span className="v" id="v21" data-v="21" data-xref="士师记 11:18; 申命记 2:29; 申命记 2:4–8"> 这样，以东拒绝让以色列经过他的边界；于是以色列转离了他。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数记 20:1; 民数记 20:14; 民数记 21:4"> 他们从加低斯起行；以色列人，就是全会众，来到何珥山。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 33:37"> 耶和华在以东地边界旁的何珥山对摩西和亚伦说：</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 25:8; 申命记 32:50; 民数记 31:2"> “亚伦要归到他的本族那里；因为你们在米利巴水边违背了我的话，所以他不得进入我赐给以色列人的地。</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 33:38–39"> 你带亚伦和他的儿子以利亚撒上何珥山；</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 20:24; 以赛亚书 22:21–22; 希伯来书 7:11"> 把亚伦的圣衣脱下来，给他的儿子以利亚撒穿上。亚伦要归到他的本族那里，并要死在那里。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27"> 摩西照耶和华所吩咐的行。他们在全会众眼前上了何珥山。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 10:6; 出埃及记 29:29–30; 申命记 34:9"> 摩西把亚伦的圣衣脱下来，给他的儿子以利亚撒穿上。亚伦死在山顶那里，摩西和以利亚撒就下了山。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 34:8; 历代志下 35:24–25; 创世记 1:10"> 全会众见亚伦已经死了，以色列全家就为亚伦哀哭三十天。</span>
</div>
</div>

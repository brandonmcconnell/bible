<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 34:1; 申命记 3:8; 民数记 21:20"> 以色列人起行，在约旦河东、耶利哥对面的摩押平原安营。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 11:25; 民数记 21:20–35; 民数记 21:3"> 西拨的儿子巴勒看见以色列向亚摩利人所做的一切。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 15:15; 以赛亚书 23:5; 约书亚记 9:24"> 摩押因那民众多，就非常惧怕；摩押因以色列人而忧虑。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 25:15–18; 民数记 31:8; 民数记 24:17"> 摩押对米甸的长老说：“现在这群人要把我们四围所有的一切都舔尽，像牛舔尽田间的草一样。”<br />那时，西拨的儿子巴勒作摩押王。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 23:4; 约书亚记 24:9; 弥迦书 6:5"> 他差遣使者到毗夺去，到大河旁、他本族之人的地，召比珥的儿子巴兰，说：“看哪，有一民从埃及出来。看哪，他们遮满地面，并且住在我对面。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 24:9; 民数记 23:7–8; 使徒行传 16:16"> 现在请你来，为我咒诅这民，因为他们比我强盛。也许我能得胜，我们就可以击败他们，我也可以把他们赶出这地；因为我知道，你祝福谁，谁就蒙福；你咒诅谁，谁就受咒诅。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 9:7–8; 弥迦书 3:11; 罗马书 16:18"> 摩押的长老和米甸的长老手里带着占卜的酬金出发。他们来到巴兰那里，把巴勒的话告诉了他。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="民数记 23:12; 民数记 22:19–20; 耶利米书 12:2"> 巴兰对他们说：“你们今夜在这里住宿，我必照耶和华对我说的话回复你们。”摩押的首领就留在巴兰那里。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="创世记 20:3; 民数记 22:20; 创世记 16:8"> 上帝来到巴兰那里，说：“与你在一起的这些人是谁？”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 巴兰对上帝说：“摩押王西拨的儿子巴勒对我说：</span>
<span className="v" id="v11" data-v="11"> ‘看哪，从埃及出来的那民遮满地面。现在请你来，为我咒诅他们。也许我能与他们争战，并把他们赶出去。’”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="申命记 23:5; 以弗所书 1:3; 创世记 12:2"> 上帝对巴兰说：“你不可与他们同去。你不可咒诅那民，因为他们是蒙福的。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="申命记 23:5; 民数记 22:14"> 巴兰早晨起来，对巴勒的首领说：“你们回本地去吧，因为耶和华不准我与你们同去。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 22:37; 民数记 22:13"> 摩押的首领起来，回到巴勒那里，说：“巴兰不肯与我们同来。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="使徒行传 10:7–8; 民数记 22:7–8"> 巴勒又差遣首领，比先前更多，也更尊贵。</span>
<span className="v" id="v16" data-v="16"> 他们来到巴兰那里，对他说：“西拨的儿子巴勒这样说：‘请不要让任何事阻碍你到我这里来，</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 24:11; 以斯帖记 5:11; 马太福音 4:8–9"> 因为我必大大尊荣你；凡你对我说的，我都必照做。所以请你来，为我咒诅这民。’”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民数记 24:13; 列王纪上 22:14; 历代志下 18:13"> 巴兰回答巴勒的臣仆说：“即使巴勒把他满屋的金银给我，我也不能越过耶和华我上帝的话，或少或多地去做什么。</span>
<span className="v" id="v19" data-v="19" data-xref="犹大书 1:11; 彼得后书 2:3; 提摩太前书 6:9–10"> 现在请你们今晚也留在这里，好让我知道耶和华还要对我说什么。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数记 23:12; 民数记 24:13; 民数记 23:26"> 上帝夜里来到巴兰那里，对他说：“如果这些人来召你，你就起来，与他们同去；但我对你说什么话，你只可照着去做。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="箴言 1:15–16"> 巴兰早晨起来，给他的驴备上鞍，和摩押的首领同去。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 4:24; 耶利米哀歌 2:4; 民数记 22:32"> 上帝因他去了就发怒；耶和华的使者站在路上，作为敌对者拦阻他。那时他骑着他的驴，有两个仆人跟着他。</span>
<span className="v" id="v23" data-v="23" data-xref="犹大书 1:11; 彼得后书 2:16; 哥林多前书 1:27–29"> 驴看见耶和华的使者站在路上，手里拔出刀来，就离开道路，走进田里。巴兰打驴，要把它赶回路上。</span>
<span className="v" id="v24" data-v="24"> 耶和华的使者又站在葡萄园之间的窄路上，这边有墙，那边也有墙。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 47:12; 约伯记 5:13–15"> 驴看见耶和华的使者，就挨着墙，把巴兰的脚挤在墙上。巴兰又打它。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="何西阿 2:6; 以赛亚书 26:11"> 耶和华的使者又往前去，站在狭窄的地方，左右都没有转身的路。</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 14:16; 雅各书 1:19; 箴言 27:3–4"> 驴看见耶和华的使者，就在巴兰身下卧倒。巴兰怒气发作，用杖打驴。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="彼得后书 2:16; 路加福音 1:37; 出埃及记 4:11"> 耶和华开了驴的口，驴对巴兰说：“我向你做了什么，你竟这三次打我？”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="箴言 12:10; 马太福音 15:19; 箴言 12:16"> 巴兰对驴说：“因为你戏弄我；但愿我手中有刀，我现在就把你杀了。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="彼得后书 2:16; 哥林多前书 1:27–28"> 驴对巴兰说：“我不是你的驴吗？你一生直到今日都骑着我。我平常曾这样对待你吗？”<br />他说：“没有。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="创世记 21:19; 路加福音 24:31; 使徒行传 26:18"> 于是耶和华开了巴兰的眼睛，他就看见耶和华的使者站在路上，手里拔出刀来；他就低头，俯伏在地。</span>
<span className="v" id="v32" data-v="32" data-xref="箴言 28:18; 使徒行传 13:10; 民数记 22:22"> 耶和华的使者对他说：“你为什么这三次打你的驴？看哪，我出来作敌对者，因为你的道路在我面前是邪僻的。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 16:33–35; 民数记 14:37; 列王纪上 13:24–28"> 驴看见我，这三次在我面前转开。它若没有从我面前转开，我现在必定已经杀了你，却让它活着。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="约伯记 34:31–32; 撒母耳记下 12:13; 撒母耳记上 15:24"> 巴兰对耶和华的使者说：“我犯了罪，因为我不知道你站在路上拦阻我。现在，如果你看这事为恶，我就回去。”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="帖撒罗尼迦后书 2:9–12; 以赛亚书 37:26–29; 民数记 22:20–21"> 耶和华的使者对巴兰说：“你和这些人同去吧；但你只可说我将要对你说的话。”<br />于是巴兰和巴勒的首领同去。</span>
<span className="v" id="v36" data-v="36" data-xref="以赛亚书 16:2; 使徒行传 28:15; 耶利米书 48:20"> 巴勒听见巴兰来了，就出去到摩押城迎接他；那城在亚嫩边界上，在边界的尽头。</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 24:11; 约翰福音 5:44; 马太福音 4:8–9"> 巴勒对巴兰说：“我不是恳切差人去召你吗？你为什么不到我这里来？难道我真的不能尊荣你吗？”</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="民数记 22:18; 箴言 19:21; 民数记 23:16"> 巴兰对巴勒说：“看哪，我已经到你这里来了。现在我岂能随意说什么呢？上帝把什么话放在我口中，我就说什么。”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39"> 巴兰与巴勒同行，来到基列胡琐。</span>
<span className="v" id="v40" data-v="40" data-xref="民数记 23:14; 箴言 1:16; 民数记 23:2"> 巴勒献上牛羊为祭，又送给巴兰和与他同在的首领。</span>
<span className="v" id="v41" data-v="41" data-xref="民数记 23:13; 民数记 25:2–3; 历代志下 11:15"> 到了早晨，巴勒带着巴兰上到巴力的高处；他从那里看见那民的一部分。</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 13:5; 阿摩司 2:11–12; 罗马书 1:1"> “你要对以色列人说：‘无论男女，若许特别的愿，就是拿细耳人的愿，要把自己分别出来归耶和华，</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 1:15; 提摩太前书 5:23; 阿摩司 2:12"> 他就要远离葡萄酒和烈酒；不可喝酒醋，也不可喝烈酒醋；不可喝任何葡萄汁，也不可吃鲜葡萄或干葡萄。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 6:5; 民数记 6:21; 民数记 6:8–9"> 在他分别出来的一切日子，凡葡萄树所出的，从籽到皮，他都不可吃。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="撒母耳记上 1:11; 士师记 16:17; 士师记 13:5"> “‘在他分别出来许愿的一切日子，不可用剃刀剃他的头，直到他分别归耶和华的日子满了。他要成为圣洁；要让头上的发绺长长。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="利未记 21:11; 利未记 19:28; 利未记 21:1–3"> “‘在他分别归耶和华的一切日子，他不可挨近死尸。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 9:6; 利未记 21:1–2; 利未记 21:10–12"> 他的父亲、母亲、兄弟或姐妹死了，他不可因他们使自己不洁净，因为他分别归上帝<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="译作“上帝”的希伯来词是“אֱלֹהִ֑ים”（Elohim）。">a</a></sup>的凭据在他头上。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 6:17–18"> 在他分别出来的一切日子，他是归耶和华为圣的。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数记 6:18; 使徒行传 18:18; 利未记 14:9"> “‘若有人在他旁边突然死亡，玷污了他分别归圣的头，他就要在得洁净的日子剃头；第七日他要剃头。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 15:29; 利未记 1:14; 利未记 15:14"> 第八日，他要把两只斑鸠或两只雏鸽带到会幕门口，交给祭司。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 14:30–31; 利未记 5:8–10"> 祭司要献一只作赎罪祭，另一只作燔祭，为他赎罪，因为他因死人而沾染了不洁；当天要重新使他的头分别为圣。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 5:6; 马太福音 24:13; 利未记 14:24"> 他要把自己分别出来的日子重新归给耶和华，并要带一只一岁的公羊羔作赎愆祭；但先前的日子要作废，因为他分别归圣被玷污了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 21:26"> “‘这是拿细耳人的条例：当他分别出来的日子满了，就要把他带到会幕门口。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 3:6; 利未记 4:32; 利未记 4:2–3"> 他要把自己的供物献给耶和华：一只一岁、无残疾的公羊羔作燔祭，一只一岁、无残疾的母羊羔作赎罪祭，一只无残疾的公绵羊作平安祭，</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 2:4; 出埃及记 29:2; 民数记 15:10"> 一篮无酵饼，就是调油的细面饼和抹油的无酵薄饼，以及同献的素祭和奠祭。</span>
<span className="v" id="v16" data-v="16"> 祭司要把这些呈献在耶和华面前，并献上他的赎罪祭和燔祭。</span>
<span className="v" id="v17" data-v="17"> 他要把那只公绵羊连同那篮无酵饼献给耶和华，作平安祭的祭牲；祭司也要献上相应的素祭和奠祭。</span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 21:24; 民数记 6:9; 使徒行传 18:18"> 拿细耳人要在会幕门口剃去他分别归圣期间所留的头发，取这头发放在平安祭牲下面的火上。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 2:15; 利未记 7:30; 出埃及记 29:23–28"> 拿细耳人剃去分别归圣期间所留的头发以后，祭司要取那只公绵羊煮熟的肩、一块篮中的无酵饼和一块无酵薄饼，放在拿细耳人的手上；</span>
<span className="v" id="v20" data-v="20" data-xref="传道书 9:7; 出埃及记 29:27–28; 民数记 5:25"> 祭司要把这些作为摇祭，在耶和华面前摇一摇。它们与所摇的胸、所献的腿一起，都是归祭司为圣的。然后，拿细耳人才可以喝葡萄酒。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="希伯来书 13:16; 以斯拉记 2:69; 民数记 5:29"> “‘这是许愿的拿细耳人的条例，也是他为自己分别归圣献给耶和华的供物；此外，还要按他力所能及的献上。照他所许的愿，他必须按他分别归圣的条例而行。’”</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22"> 耶和华对摩西说：</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 21:5; 历代志上 23:13; 创世记 48:20"> “你要对亚伦和他的儿子们说：‘你们要这样为以色列人祝福。’你们要对他们说：</span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦前书 5:23; 诗篇 121:4–7; 腓立比书 4:7"> <span className="pl pl-1">‘愿耶和华赐福给你，保护你。</span></span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 80:19; 诗篇 119:135; 诗篇 31:16"> <span className="pl pl-2">愿耶和华使祂的脸光照你，</span><br /><span className="pl pl-2">赐恩给你。</span></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 4:6; 诗篇 29:11; 帖撒罗尼迦后书 3:16"> <span className="pl pl-1">愿耶和华向你仰脸，</span><br /><span className="pl pl-2">赐你平安。’</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="历代志下 7:14; 但以理 9:18–19; 申命记 28:10"> “他们要这样把我的名放在以色列人身上；我也要赐福给他们。”</span>
</div>

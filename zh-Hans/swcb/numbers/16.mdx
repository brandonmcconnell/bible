<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="犹大书 1:11; 申命记 11:6; 出埃及记 6:21"> 利未的曾孙、哥辖的孙子、以斯哈的儿子可拉，和流便子孙中以利押的儿子大坍、亚比兰，以及比勒的儿子安，带着一些人起来；</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 26:9; 以西结 23:10; 创世记 6:4"> 他们起来反抗摩西；同他们一起的还有以色列子孙中的二百五十个会众首领，都是被召参加会的人，有名望的人。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 106:16; 民数记 14:14; 出埃及记 19:6"> 他们聚集起来反对摩西和亚伦，对他们说：“你们太过分了！全会众人人都是圣洁的，耶和华也在他们中间！你们为什么把自己高举在耶和华的会众之上呢？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="民数记 14:5; 民数记 20:6; 约书亚记 7:6"> 摩西听见了，就俯伏在地。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 65:4; 民数记 17:5; 提摩太后书 2:19"> 他对可拉和他所有同党说：“到了早晨，耶和华必显明谁是属祂的，谁是圣洁的，并使那人亲近祂；祂所拣选的人，祂必使那人亲近祂。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 10:1; 民数记 16:46–48; 列王纪上 18:21–23"> 你们要这样做：可拉和他所有同党，你们要拿香炉，</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 16:3; 以弗所书 1:4; 列王纪上 18:17–18"> 明天在耶和华面前把火放在香炉里，又把香放在火上。耶和华拣选的人，那人才是圣洁的。你们利未子孙太过分了！”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 摩西又对可拉说：“利未子孙哪，现在请听！</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 7:13; 申命记 10:8; 以西结 44:10–11"> 以色列的上帝把你们从以色列会众中分别出来，使你们亲近祂，办理耶和华帐幕的事奉，又站在会众面前服事他们，这在你们看来是小事吗？</span>
<span className="v" id="v10" data-v="10" data-xref="箴言 13:10; 约翰三书 1:9; 民数记 18:7"> 祂已经使你和你所有弟兄利未子孙一同亲近祂，你们还要求祭司职分吗？</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 16:7–8; 出埃及记 17:2; 民数记 16:3"> 所以，你和你所有同党是聚集起来反对耶和华！亚伦算什么，你们竟向他发怨言呢？”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="彼得前书 2:13–14; 犹大书 1:8; 箴言 29:9"> 摩西派人去召以利押的儿子大坍和亚比兰；他们说：“我们不上去！</span>
<span className="v" id="v13" data-v="13" data-xref="使徒行传 7:35; 出埃及记 2:14; 民数记 11:5"> 你把我们从流奶与蜜之地领上来，要在旷野杀死我们，这还是小事吗？你还要自立为首领来统治我们吗？</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 20:24; 民数记 36:8–10; 民数记 20:5"> 而且，你并没有把我们带进流奶与蜜之地，也没有把田地和葡萄园给我们为产业。难道你要挖掉这些人的眼睛吗？我们不上去。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="创世记 4:4–5; 哥林多后书 7:2; 帖撒罗尼迦前书 2:10"> 摩西非常愤怒，对耶和华说：“不要垂顾他们的供物。我没有从他们那里拿过一头驴，也没有伤害过他们一个人。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 12:3; 撒母耳记上 12:7; 提摩太后书 2:14"> 摩西对可拉说：“明天，你和你所有同党，你们和亚伦，都要来到耶和华面前。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 12:7"> 各人要拿自己的香炉，把香放在上面；各人把自己的香炉带到耶和华面前，共二百五十个香炉；你和亚伦也各拿自己的香炉。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 于是他们各人拿自己的香炉，把火放在里面，又把香放在上面，同摩西和亚伦站在会幕门口。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 14:10; 民数记 16:42; 出埃及记 16:7"> 可拉把全会众聚集到会幕门口，对着他们。<br />耶和华的荣耀向全会众显现。</span>
<span className="v" id="v20" data-v="20"> 耶和华对摩西和亚伦说：</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 16:45; 出埃及记 32:10; 诗篇 73:19"> “你们要从这会众中间分别出来，好让我在片刻之间灭绝他们！”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数记 27:16; 撒迦利亚书 12:1; 约伯记 12:10"> 他们就俯伏在地，说：“上帝，万有血肉之灵的上帝啊，一个人犯罪，你就要向全会众发怒吗？”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和华对摩西说：</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 16:21"> “你要告诉会众说：‘你们要离开可拉、大坍、亚比兰的帐篷四围！’”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="民数记 11:16–17; 民数记 11:25; 民数记 11:30"> 摩西起来，往大坍和亚比兰那里去；以色列的长老也跟随他。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 52:11; 哥林多后书 6:17; 启示录 18:4"> 他对会众说：“请你们离开这些恶人的帐篷，他们的任何东西都不可触碰，免得你们因他们一切的罪被灭绝！”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约伯记 9:4; 以赛亚书 28:14; 约伯记 40:10–11"> 于是众人从可拉、大坍、亚比兰的帐篷四围离开。大坍和亚比兰出来，同他们的妻子、儿子和小孩子，站在自己帐篷门口。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约翰福音 6:38; 出埃及记 3:12; 约翰福音 14:11"> 摩西说：“你们凭这事就知道，耶和华差遣我行这一切事；因为这不是出于我自己的心意。</span>
<span className="v" id="v29" data-v="29" data-xref="耶利米哀歌 4:22; 列王纪上 22:28; 出埃及记 32:34"> 如果这些人像众人通常那样死去，或遭遇众人通常的遭遇，那么耶和华就没有差遣我。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 55:15; 民数记 16:33; 约伯记 31:3"> 但如果耶和华行一件新事，使地开口，把他们和一切属于他们的都吞下去，使他们活活地坠入阴间，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="阴间是死人所在之处。">a</a></sup>你们就会明白，这些人藐视了耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="诗篇 106:17–18; 民数记 27:3; 申命记 11:6"> 摩西刚说完这一切话，他们脚下的地就裂开。</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 106:17; 民数记 26:11; 启示录 12:16"> 地开了口，把他们和他们的家眷，以及所有属可拉的人和他们一切的财物都吞下去。</span>
<span className="v" id="v33" data-v="33" data-xref="以西结 32:18; 以赛亚书 14:9; 诗篇 9:15"> 这样，他们和一切属于他们的都活活地坠入阴间。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="阴间是死人所在之处。">b</a></sup>地在他们上面合拢，他们就从会中灭亡了。</span>
<span className="v" id="v34" data-v="34" data-xref="撒迦利亚书 14:5; 以赛亚书 33:3; 启示录 6:15–17"> 在他们四围的以色列众人听见他们的呼喊就逃跑；因为他们说：“恐怕地也把我们吞下去！”</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 26:10; 利未记 10:2; 诗篇 106:18"> 有火从耶和华那里出来，吞灭了那献香的二百五十个人。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36"> 耶和华对摩西说：</span>
<span className="v" id="v37" data-v="37" data-xref="利未记 27:28; 民数记 16:18; 民数记 16:7"> “你要告诉亚伦祭司的儿子以利亚撒，从火中把那些香炉拿出来，并把火撒到营外；因为那些香炉是圣洁的，</span>
<span className="v" id="v38" data-v="38" data-xref="民数记 26:10; 以西结 14:8; 彼得后书 2:6"> 就是那些犯罪、自害己命之人的香炉。要把它们锤成片子，用来包坛；因为他们曾把这些香炉献在耶和华面前，所以是圣洁的。它们要成为给以色列子孙的记号。”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39"> 于是以利亚撒祭司拿了那些被火烧死的人所献的铜香炉；人就把它们锤成片子，用来包坛，</span>
<span className="v" id="v40" data-v="40" data-xref="民数记 3:10; 民数记 18:4–7; 历代志下 26:16–21"> 给以色列子孙作纪念，使不属亚伦后裔的外人不可近前来，在耶和华面前烧香，免得他像可拉和他的同党一样；这正如耶和华借着摩西对以利亚撒所说的。</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="民数记 16:1–7; 诗篇 106:23; 民数记 14:2"> 第二天，以色列子孙全会众向摩西和亚伦发怨言，说：“你们杀了耶和华的百姓！”</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="民数记 16:19; 利未记 9:23; 民数记 20:6"> 会众聚集起来反对摩西和亚伦的时候，他们望向会幕。看哪，云彩遮盖了会幕，耶和华的荣耀显现了。</span>
<span className="v" id="v43" data-v="43"> 摩西和亚伦来到会幕前面。</span>
<span className="v" id="v44" data-v="44"> 耶和华对摩西说：</span>
<span className="v" id="v45" data-v="45" data-xref="民数记 16:21–22; 民数记 16:24; 民数记 20:6"> “你们要离开这会众中间，好让我在片刻之间灭绝他们！”他们就俯伏在地。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="民数记 8:19; 历代志上 27:24; 利未记 10:6"> 摩西对亚伦说：“拿你的香炉，把坛上的火放在里面，把香放在火上，赶快拿到会众那里，为他们赎罪；因为烈怒已经从耶和华那里发出！瘟疫已经开始了。”</span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="马太福音 5:44; 申命记 33:10–11; 诗篇 106:29"> 亚伦照摩西所说的去做，跑到会中。看哪，瘟疫已经在百姓中开始了。他把香放上，为百姓赎罪。</span>
<span className="v" id="v48" data-v="48" data-xref="撒母耳记下 24:25; 希伯来书 7:24–25; 民数记 16:18"> 他站在死人和活人之间；瘟疫就止住了。</span>
<span className="v" id="v49" data-v="49" data-xref="民数记 25:9; 民数记 16:32–35; 希伯来书 2:1–3"> 除了因可拉事件而死的人以外，因瘟疫而死的共有一万四千七百人。</span>
<span className="v" id="v50" data-v="50" data-xref="历代志上 21:26–30; 民数记 16:43"> 亚伦回到会幕门口摩西那里，瘟疫就止住了。</span>
</div>
</div>

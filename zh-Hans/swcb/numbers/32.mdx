<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 21:32; 民数记 32:3; 创世记 13:10–11"> 流便子孙和迦得子孙有极多的牲畜。他们看见雅谢地和基列地；看哪，那地方适合牧养牲畜。</span>
<span className="v" id="v2" data-v="2"> 于是迦得子孙和流便子孙前来，对摩西、以利亚撒祭司和会众的首领说：</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 48:34; 以赛亚书 16:8–9; 民数记 32:34–38"> “亚他录、底本、雅谢、宁拉、希实本、以利亚利、西比玛、尼波、比稳，</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 21:34; 申命记 2:24–35; 民数记 21:24"> 就是耶和华在以色列会众面前击败的那地，是适合牧养牲畜的地；而你的仆人也有牲畜。”</span>
<span className="v" id="v5" data-v="5" data-xref="路得记 2:10; 约书亚记 7:7; 耶利米书 31:2"> 他们说：“我们若在你眼前蒙恩，求你把这地给你的仆人作产业，不要领我们过约旦河。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 13:5; 撒母耳记下 11:11; 腓立比书 2:4"> 摩西对迦得子孙和流便子孙说：“难道你们的弟兄去打仗，你们却坐在这里吗？</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 13:27–4; 民数记 32:9; 申命记 1:28"> 你们为什么使以色列子孙灰心，不肯过去进入耶和华赐给他们的地呢？</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 1:19–25; 民数记 14:2; 民数记 13:2–26"> 我从加低斯·巴尼亚差派你们的父辈去察看那地时，他们也是这样做的。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 13:23–10; 申命记 1:24–28"> 他们上到以实各谷，看见那地以后，就使以色列子孙灰心，不愿进入耶和华赐给他们的地。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 14:11; 诗篇 95:11; 以西结 20:15"> 那日，耶和华的怒气发作，祂起誓说：</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 14:28–30; 民数记 14:24; 民数记 26:2"> ‘凡从埃及上来、二十岁以上的人，必定没有一个能看见我向亚伯拉罕、以撒和雅各起誓所应许的那地，因为他们没有专心跟从我；</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 1:36; 民数记 14:30; 民数记 14:24"> 惟有基尼洗族耶孚尼的儿子迦勒，和嫩的儿子约书亚可以看见，因为他们专心跟从耶和华。’</span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 10:5; 民数记 14:33–35; 希伯来书 3:16–19"> 耶和华的怒气向以色列发作，使他们在旷野来回漂流四十年，直到那在耶和华眼中行恶的整个世代都消灭了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 11:48; 诗篇 78:57; 马太福音 23:31–33"> “看哪，你们这一群罪人的后代，竟起来接替你们父辈的位置，使耶和华向以色列所发的烈怒更加增添。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 8:11–12; 历代志下 15:2; 历代志下 7:19–22"> 你们若转离不跟从祂，祂还要再把他们撇在旷野；这样，你们就会毁灭这全体百姓。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="创世记 33:17; 民数记 34:22"> 他们走近摩西，说：“我们要在这里为牲畜筑羊圈，为孩子们建城；</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 4:12–13; 民数记 32:29–32; 申命记 3:18–20"> 但我们自己要全副武装，走在以色列子孙前面，直到把他们带到他们的地方。我们的孩子要住在坚固城里，以防这地的居民。</span>
<span className="v" id="v18" data-v="18" data-xref="约书亚记 22:1–5"> 我们不回自己的家，直到以色列子孙各自承受了自己的产业。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 13:8; 约书亚记 12:1–6; 民数记 34:15"> 我们不和他们在约旦河那边及更远之地一同承受产业，因为我们的产业已经归给我们，在约旦河这边，就是东边。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="约书亚记 4:12–13; 申命记 3:18–20; 约书亚记 1:13–15"> 摩西对他们说：“如果你们要这样做，如果你们要武装起来，在耶和华面前出去打仗，</span>
<span className="v" id="v21" data-v="21"> 你们所有拿起兵器的人都要在耶和华面前过约旦河，直到祂从自己面前赶出祂的仇敌，</span>
<span className="v" id="v22" data-v="22" data-xref="约书亚记 22:9; 约书亚记 22:4; 申命记 3:20"> 那地在耶和华面前被征服；之后你们就可以回来，在耶和华和以色列面前无亏欠。这地也必在耶和华面前成为你们的产业。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 59:12; 箴言 13:21; 创世记 44:16"> “但你们若不这样做，看哪，你们就是得罪耶和华；要确知，你们的罪必追上你们。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 32:16; 民数记 30:2; 民数记 32:34–42"> 你们可以为孩子们建城，为羊群筑圈；但你们口中所说的，必须实行。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约书亚记 1:13–14"> 迦得子孙和流便子孙对摩西说：“你的仆人必照我主所吩咐的去做。</span>
<span className="v" id="v26" data-v="26" data-xref="约书亚记 1:14"> 我们的孩子、妻子、羊群和一切牲畜，都要留在基列的城里；</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 4:12; 民数记 32:17; 民数记 12:11"> 但你的仆人，凡武装好能作战的人，都要照我主所说的，在耶和华面前过去争战。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约书亚记 1:13"> 于是摩西为他们的事吩咐以利亚撒祭司、嫩的儿子约书亚，以及以色列子孙各支派的宗族首领。</span>
<span className="v" id="v29" data-v="29"> 摩西对他们说：“如果迦得子孙和流便子孙，凡武装好能在耶和华面前作战的人，都与你们一同过约旦河，并且那地在你们面前被征服，那么你们就要把基列地给他们作产业；</span>
<span className="v" id="v30" data-v="30" data-xref="约书亚记 22:19"> 但他们若不带着兵器与你们一同过去，就要在迦南地你们中间得产业。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31"> 迦得子孙和流便子孙回答说：“耶和华怎样对你的仆人说，我们就怎样做。</span>
<span className="v" id="v32" data-v="32"> 我们要带着兵器，在耶和华面前过去，进入迦南地；但我们承受为业的产业仍要留在约旦河东边。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="约书亚记 12:6; 申命记 29:8; 申命记 3:12–17"> 摩西把亚摩利王西宏的国和巴珊王噩的国，就是那地，连同其中的城邑和边界，以及周围之地的城邑，都给了他们，就是给了迦得子孙、流便子孙和约瑟的儿子玛拿西半个支派。</span>
<span className="v" id="v34" data-v="34" data-xref="申命记 2:36; 民数记 32:3; 以赛亚书 17:2"> 迦得子孙重建了底本、亚他录、亚罗珥、</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 32:1; 民数记 32:3"> 亚他录·朔反、雅谢、约比哈、</span>
<span className="v" id="v36" data-v="36" data-xref="民数记 32:3"> 伯·宁拉和伯·哈兰，都是坚固城，并筑了羊圈。</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 21:27; 民数记 32:3; 以赛亚书 15:4"> 流便子孙重建了希实本、以利亚利、基列亭、</span>
<span className="v" id="v38" data-v="38" data-xref="以赛亚书 46:1; 民数记 32:3; 约书亚记 23:7"> 尼波、巴力·免——这些名字都改了——以及西比玛。他们给所重建的城另起了名字。</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 50:23; 约书亚记 17:1; 民数记 26:29"> 玛拿西的儿子玛吉的子孙往基列去，占领了那地，赶出了那里的亚摩利人。</span>
<span className="v" id="v40" data-v="40" data-xref="约书亚记 17:1; 约书亚记 13:29–31; 申命记 3:13–15"> 摩西把基列赐给玛拿西的儿子玛吉，他就住在那里。</span>
<span className="v" id="v41" data-v="41" data-xref="申命记 3:14; 士师记 10:4; 约书亚记 13:30"> 玛拿西的子孙睚珥去占领了其中的村庄，称它们为哈倭特·睚珥。</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 49:11; 撒母耳记下 18:18"> 挪巴去占领了基纳和所属的村庄，并照自己的名字称它为挪巴。</span>
</div>
</div>

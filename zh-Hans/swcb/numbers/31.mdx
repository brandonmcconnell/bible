<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="NUM" data-book-slug="numbers" data-book-name="民数记" data-chapter="31" data-verses="54">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 27:13; 民数记 25:14–18; 启示录 6:10"> “你要为以色列人向米甸人报仇。之后，你必归到你本族那里。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="利未记 26:25; 民数记 25:11; 列王纪下 10:30"> 摩西对百姓说：“你们要从中装备人出战，使他们攻击米甸，向米甸施行耶和华的报仇。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 26:8; 撒母耳记上 14:6; 士师记 7:2"> 你们要从以色列各支派中，每支派派一千人去作战。”</span>
<span className="v" id="v5" data-v="5"> 于是，从以色列的各千人队中，每支派交出一千人，共一万二千人，装备好去作战。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 14:44; 民数记 10:8–9; 历代志下 13:12–15"> 摩西派他们去作战，每支派一千人；又派祭司以利亚撒的儿子非尼哈一同去作战，手里拿着圣所的器具和吹警报的号角。</span>
<span className="v" id="v7" data-v="7" data-xref="士师记 21:11; 列王纪上 11:15–16; 撒母耳记上 27:9"> 他们照耶和华吩咐摩西的，与米甸作战，杀了所有的男丁。</span>
<span className="v" id="v8" data-v="8" data-xref="约书亚记 13:21–22; 民数记 25:15; 启示录 2:14"> 他们在所杀的人以外，又杀了米甸的众王：以未、利金、苏珥、户珥、利巴，就是米甸的五个王。他们也用刀杀了比珥的儿子巴兰。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 20:14; 历代志下 28:8–10; 历代志下 28:5"> 以色列人俘虏了米甸的妇女和她们的孩子；又把他们所有的牲畜、所有的羊群和所有的财物都掠为战利品。</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 1:7; 撒母耳记上 30:1; 约书亚记 6:24"> 他们用火焚烧了米甸人所居住之处的一切城邑和一切营寨。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 20:14; 约书亚记 8:2"> 他们夺取了一切俘虏和一切掠物，无论人畜。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 22:1"> 他们把俘虏、掠物和战利品带到摩西、祭司以利亚撒，以及以色列人会众那里，就是约旦河边、耶利哥对面的摩押平原营中。</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 5:2; 撒母耳记上 30:21; 民数记 31:12"> 摩西、祭司以利亚撒，以及会众所有的首领，都出到营外迎接他们。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 13:19; 撒母耳记上 15:13–14; 民数记 31:48"> 摩西向那些从战场服役回来的军官，就是千夫长和百夫长发怒。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 15:3; 耶利米书 48:10; 申命记 2:34"> 摩西对他们说：“你们竟让所有妇女都活着吗？</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 25:1–9; 彼得后书 2:15; 启示录 2:14"> 看哪，正是这些妇女因巴兰的计谋，使以色列人在毗珥的事上干犯耶和华，以致瘟疫临到耶和华的会众中。</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 21:11–12; 申命记 20:16–18; 申命记 7:2"> 现在，你们要杀掉孩童中所有的男孩，也要杀掉凡与男人同寝、认识过男人的妇女。</span>
<span className="v" id="v18" data-v="18" data-xref="申命记 21:10–14; 历代志下 28:8–10; 申命记 20:14"> 但所有没有与男人同寝、没有认识过男人的女孩，你们要为自己存留她们的性命。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="民数记 19:11–22; 民数记 5:2; 历代志上 22:8"> “你们要在营外安营七天。凡杀过人的，凡摸过被杀之人的，你们和你们的俘虏，都要在第三天和第七天洁净自己。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 19:22; 创世记 35:2; 出埃及记 19:10"> 你们要洁净一切衣服、一切皮制之物、一切山羊毛制品，以及一切木制之物。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数记 30:16"> 祭司以利亚撒对去打仗的战士说：“这是耶和华吩咐摩西的律法条例。</span>
<span className="v" id="v22" data-v="22"> 至于金、银、铜、铁、锡、铅，</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 19:9; 民数记 19:17; 哥林多前书 3:13"> 凡能经火的，都要使它经火，它就洁净；不过仍要用除污秽的水洁净。凡不能经火的，你们要使它经水。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 11:25; 利未记 15:13; 利未记 14:9"> 第七天你们要洗衣服，就洁净了。之后，你们可以进营。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 耶和华对摩西说：</span>
<span className="v" id="v26" data-v="26"> “你和祭司以利亚撒，以及会众各父家的首领，要计算所夺取的掠物，无论人畜；</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 22:8; 诗篇 68:12; 撒母耳记上 30:24–25"> 又要把掠物分成两份：一份给出去打仗、精于作战的人，一份给全会众。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 18:26; 民数记 31:30; 民数记 31:47"> 你要从出去打仗的战士所得中，向耶和华征收贡物：每五百取一个；无论是人、牛、驴、羊群。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 29:27; 申命记 12:19; 申命记 12:12"> 要从他们的一半中取出来，交给祭司以利亚撒，作为耶和华的摇祭。</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 3:31; 民数记 3:7–8; 民数记 3:25"> 从以色列人的一半中，无论是人、牛、驴、羊群和各样牲畜，你要每五十抽取一个，交给办理耶和华帐幕事务的利未人。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31"> 摩西和祭司以利亚撒就照耶和华吩咐摩西的做了。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32"> 战士所夺的战利品以外，所剩的掠物共有羊六十七万五千只，</span>
<span className="v" id="v33" data-v="33"> 牛七万二千头，</span>
<span className="v" id="v34" data-v="34"> 驴六万一千匹，</span>
<span className="v" id="v35" data-v="35"> 人三万二千名，都是没有与男人同寝、没有认识过男人的女子。</span>
<span className="v" id="v36" data-v="36"> 出去打仗之人的份，就是那一半，数目是羊三十三万七千五百只；</span>
<span className="v" id="v37" data-v="37"> 从羊中给耶和华的贡物是六百七十五只。</span>
<span className="v" id="v38" data-v="38"> 牛三万六千头，其中给耶和华的贡物是七十二头。</span>
<span className="v" id="v39" data-v="39"> 驴三万零五百匹，其中给耶和华的贡物是六十一匹。</span>
<span className="v" id="v40" data-v="40"> 人一万六千名，其中给耶和华的贡物是三十二人。</span>
<span className="v" id="v41" data-v="41" data-xref="民数记 18:8; 民数记 18:19; 希伯来书 7:9–12"> 摩西把那贡物，就是耶和华的摇祭，交给祭司以利亚撒，照耶和华吩咐摩西的做了。</span>
<span className="v" id="v42" data-v="42"> 至于以色列人的一半，就是摩西从打仗的人那里分出来的，</span>
<span className="v" id="v43" data-v="43"> （会众的那一半是羊三十三万七千五百只，</span>
<span className="v" id="v44" data-v="44"> 牛三万六千头，</span>
<span className="v" id="v45" data-v="45"> 驴三万零五百匹，</span>
<span className="v" id="v46" data-v="46"> 人一万六千名，）</span>
<span className="v" id="v47" data-v="47" data-xref="民数记 31:30; 路加福音 10:1–8; 以赛亚书 56:10–11"> 就是从以色列人的这一半中，摩西无论人畜，每五十抽取一个，交给办理耶和华帐幕事务的利未人，照耶和华吩咐摩西的做了。</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48"> 统领军中千人的军官，就是千夫长和百夫长，来到摩西面前。</span>
<span className="v" id="v49" data-v="49" data-xref="约翰福音 18:9; 撒母耳记上 30:18–19; 诗篇 72:14"> 他们对摩西说：“你的仆人们已经清点了我们所统领的战士，我们中间没有少一人。</span>
<span className="v" id="v50" data-v="50" data-xref="出埃及记 30:12; 出埃及记 30:15–16; 诗篇 116:12"> 如今我们把各人所得的金器，就是臂环、手镯、印戒、耳环、项链，带来献给耶和华作供物，好在耶和华面前为我们的生命赎罪。”</span>
</div>
<div className="bp">
<span className="v" id="v51" data-v="51" data-xref="民数记 7:2–6"> 摩西和祭司以利亚撒收下了他们的金子，就是各样加工的首饰。</span>
<span className="v" id="v52" data-v="52"> 千夫长和百夫长献给耶和华作摇祭的所有金子，共有一万六千七百五十舍客勒。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一舍客勒约为10克，或约0.35盎司，所以16,750舍客勒约为167.5千克，或约368.5磅。">a</a></sup></span>
<span className="v" id="v53" data-v="53" data-xref="申命记 20:14; 民数记 31:32"> 战士们各自夺取了战利品。</span>
<span className="v" id="v54" data-v="54" data-xref="出埃及记 30:16; 撒迦利亚书 6:14; 使徒行传 10:4"> 摩西和祭司以利亚撒收下千夫长和百夫长的金子，带进会幕，在耶和华面前为以色列人作纪念。</span>
</div>
</div>

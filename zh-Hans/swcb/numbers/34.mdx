<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 17:8; 诗篇 105:11; 申命记 1:7–8"> “你要吩咐以色列人，对他们说：‘你们进入迦南地的时候，这就是要归给你们作产业的地，就是按边界划定的迦南地，</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 14:3; 以西结 47:13; 约书亚记 3:16"> 你们南边的地区要从寻的旷野，沿着以东旁边；你们南边的边界要从盐海的东端开始。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 32:8; 约书亚记 15:3–4; 民数记 13:26"> 你们的边界要转到亚克拉滨坡的南边，经过寻；又从加低斯巴尼亚的南边经过；再从那里到哈萨亚达，经过押们。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 15:4; 创世记 15:18; 列王纪上 8:65"> 边界要从押们转到埃及溪，直到海为止。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约书亚记 1:4; 以西结 47:20; 以西结 47:15"> “‘至于西边的边界，你们要以大海和它的沿岸为界。这要作你们西边的边界。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="民数记 33:37; 民数记 34:6; 民数记 34:3"> “‘这要作你们北边的边界：从大海起，你们要划到何珥山。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 13:21; 列王纪下 14:25; 约书亚记 13:5–6"> 从何珥山，你们要划到哈马口；边界要经过西达达。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 47:17"> 然后边界要到西斐仑，直到哈萨以难为止。这要作你们北边的边界。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> “‘你们要划定东边的边界，从哈萨以难到示番。</span>
<span className="v" id="v11" data-v="11" data-xref="列王纪下 23:33; 申命记 3:17; 约书亚记 11:2"> 边界要从示番下到利比拉，在亚因的东边。边界要继续下去，直到基尼烈海东边的岸。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 34:3; 创世记 13:10; 创世记 19:24–26"> 边界要下到约旦河，直到盐海为止。这要作你们的地，按四围的边界划定。’”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 34:1; 约书亚记 14:1–5"> 摩西吩咐以色列人说：“这就是你们要拈阄承受为产业的地，是耶和华吩咐要给九个支派和半个支派的；</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 32:33; 民数记 32:23; 约书亚记 14:2–3"> 因为流便子孙的支派按着他们父家，迦得子孙的支派按着他们父家，以及玛拿西半个支派，已经领受了他们的产业。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 32:32"> 这两个支派和半个支派已经在约旦河东、耶利哥对面，向日出的方向，领受了他们的产业。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 耶和华对摩西说：</span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 14:1; 约书亚记 19:51; 民数记 13:8"> “这些是要为你们分地作产业的人名：祭司以利亚撒和嫩的儿子约书亚。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 1:4–16"> 你们要从每个支派选取一位首领，来分地作产业。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 26:65; 民数记 13:30; 民数记 14:24"> 这些人的名字如下：犹大支派中，有耶孚尼的儿子迦勒。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 49:5"> 西缅子孙支派中，有亚米忽的儿子示母利。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 49:27; 诗篇 68:27"> 便雅悯支派中，有基斯伦的儿子以利达。</span>
<span className="v" id="v22" data-v="22"> 但子孙支派中，有一位首领，约利的儿子布基。</span>
<span className="v" id="v23" data-v="23"> 约瑟子孙中，玛拿西子孙支派中，有一位首领，以弗得的儿子汉聂。</span>
<span className="v" id="v24" data-v="24"> 以法莲子孙支派中，有一位首领，示弗但的儿子基母利。</span>
<span className="v" id="v25" data-v="25"> 西布伦子孙支派中，有一位首领，帕纳的儿子以利撒番。</span>
<span className="v" id="v26" data-v="26"> 以萨迦子孙支派中，有一位首领，阿散的儿子帕铁。</span>
<span className="v" id="v27" data-v="27"> 亚设子孙支派中，有一位首领，示罗米的儿子亚希忽。</span>
<span className="v" id="v28" data-v="28"> 拿弗他利子孙支派中，有一位首领，亚米忽的儿子比大黑。”</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 19:51; 民数记 34:18"> 这些人就是耶和华所吩咐，要在迦南地把产业分给以色列人的人。</span>
</div>

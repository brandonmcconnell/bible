<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 1:45; 民数记 11:1–4"> 全会众都放声呼喊；那一夜，百姓哭了。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 15:24; 出埃及记 17:3; 民数记 16:41"> 以色列众子孙都向摩西和亚伦发怨言。全会众对他们说：“但愿我们死在埃及地，或死在这旷野！</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 14:31–32; 耶利米书 9:3; 诗篇 78:40"> 耶和华为什么把我们带到这地，使我们倒在刀下呢？我们的妻子和孩子必被掳掠或杀害！我们回埃及去不是更好吗？”</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 7:39; 尼希米记 9:16–17; 申命记 17:16"> 他们彼此说：“我们要立一个首领，回埃及去。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民数记 16:4; 民数记 16:22; 民数记 16:45"> 摩西和亚伦就在以色列众子孙全会众面前俯伏在地。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数记 14:30; 民数记 13:30; 民数记 14:38"> 窥探那地的人当中，嫩的儿子约书亚和耶孚尼的儿子迦勒撕裂衣服。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 13:27; 申命记 1:25; 申命记 8:7–9"> 他们对以色列众子孙全会众说：“我们经过并窥探的那地，是极美好的地。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 22:20; 以赛亚书 62:4; 民数记 13:27"> 如果耶和华喜悦我们，祂就必把我们带进那地，把它赐给我们；那是流奶与蜜之地。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 7:18; 罗马书 8:31; 申命记 31:6"> 只是不可背叛耶和华，也不要怕那地的百姓；因为他们是我们的食物。保护他们的已经离开他们，耶和华却与我们同在。不要怕他们。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及记 17:4; 撒母耳记上 30:6; 利未记 9:23"> 但全会众威胁要用石头打死他们。<br />耶和华的荣耀在会幕中向以色列众子孙显现。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 78:32; 诗篇 106:24; 诗篇 78:22"> 耶和华对摩西说：“这百姓藐视我要到几时呢？我在他们中间行了这一切神迹，他们还不信我要到几时呢？</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 32:10; 民数记 25:9; 撒母耳记下 24:12–15"> 我要用瘟疫击打他们，废除他们的产业，却要使你成为比他们更大、更强的国。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="诗篇 106:23; 以西结 20:9; 申命记 32:27"> 摩西对耶和华说：“这样，埃及人必听见这事；因为你曾用你的大能把这百姓从他们中间领上来。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 15:14; 出埃及记 33:11; 申命记 5:4"> 他们也必把这事告诉这地的居民。他们已经听见你耶和华是在这百姓中间；因为你耶和华是面对面被人看见的，你的云彩停在他们上方，你白天在云柱中、夜间在火柱中走在他们前面。</span>
<span className="v" id="v15" data-v="15" data-xref="士师记 6:16"> 如今你若把这百姓如同杀一人一样杀了，那些听见你名声的列国就会说：</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 9:28; 约书亚记 7:9; 约书亚记 7:7"> ‘因为耶和华不能把这百姓带进祂向他们起誓应许的地，所以祂在旷野把他们杀了。’</span>
<span className="v" id="v17" data-v="17" data-xref="马太福音 9:6; 马太福音 9:8; 弥迦书 3:8"> 现在，求主<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="译作“主”的词是“阿多奈”。">a</a></sup>的大能照你所说的显为大，说：</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 34:6–7; 诗篇 145:8; 出埃及记 20:5"> ‘耶和华不轻易发怒，并且有丰盛的慈爱，赦免罪孽和悖逆；祂绝不以有罪的为无罪，必追讨父亲的罪孽在儿女身上，直到三四代。’</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 34:9; 诗篇 78:38; 诗篇 106:45"> 求你照你丰盛的慈爱赦免这百姓的罪孽，正如你从埃及直到如今一直赦免这百姓一样。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="弥迦书 7:18–20; 雅各书 5:16; 诗篇 106:23"> 耶和华说：“我已经照你的话赦免了；</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 72:19; 哈巴谷 2:14; 以赛亚书 6:3"> 然而，我指着我的永生起誓，并指着全地必充满耶和华的荣耀起誓：</span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 19:3; 创世记 31:7; 出埃及记 32:1"> 凡看见我的荣耀和我在埃及与旷野所行神迹的人，却仍这十次试探我，又不听从我的声音，</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 32:11; 民数记 26:64; 以西结 20:15"> 他们必不得看见我向他们祖先起誓应许的地；凡藐视我的，也没有一个人能看见那地。</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 14:6–9; 约书亚记 14:6–14; 以弗所书 6:6"> 但我的仆人迦勒，因他里面另有一种灵，并且专心跟随我，我必把他带进他所去过的那地；他的后裔必得那地为业。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 1:40; 民数记 13:29; 诗篇 81:11–13"> 既然亚玛力人和迦南人住在谷中，明天你们要转回，沿着通往红海的路进旷野去。”</span>
<span className="v" id="v26" data-v="26"> 耶和华对摩西和亚伦说：</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 16:12; 哥林多前书 10:10; 出埃及记 16:28"> “这邪恶的会众向我发怨言，我要忍受他们到几时呢？以色列子孙向我所发的怨言，我都听见了。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 14:21; 希伯来书 3:17; 民数记 14:2"> 你要告诉他们：‘耶和华说：我指着我的永生起誓，你们在我耳中怎样说，我必照样待你们。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 1:45; 哥林多前书 10:5; 希伯来书 3:17"> 你们的尸体必倒在这旷野；你们中间凡被数点的，照你们的总数，从二十岁以上，向我发怨言的，</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 26:65; 民数记 14:38; 申命记 1:36–38"> 必不得进入我起誓要使你们居住的那地；惟有耶孚尼的儿子迦勒和嫩的儿子约书亚可以进去。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 1:39; 诗篇 106:24; 民数记 26:64"> 但你们所说必被掳掠或杀害的孩子，我必把他们带进去；他们必认识你们所弃绝的那地。</span>
<span className="v" id="v32" data-v="32" data-xref="哥林多前书 10:5; 民数记 14:29; 希伯来书 3:17"> 至于你们，你们的尸体必倒在这旷野。</span>
<span className="v" id="v33" data-v="33" data-xref="以西结 23:35; 民数记 32:13; 申命记 2:14"> 你们的儿女必在旷野漂流四十年，担当你们的淫行，直到你们的尸体在旷野灭尽。</span>
<span className="v" id="v34" data-v="34" data-xref="以西结 4:6; 民数记 13:25; 耶利米书 18:9–10"> 按你们窥探那地的日数，就是四十天，一天算一年，你们要担当自己的罪孽四十年，也必知道我与你们疏离。’</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 23:19; 哥林多前书 10:5; 希伯来书 3:19"> 我耶和华已经说了。我必定这样对待这聚集起来敌挡我的全体邪恶会众；他们必在这旷野灭尽，死在那里。”</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="民数记 13:31–33; 民数记 13:4–16"> 摩西差去窥探那地的人回来以后，报那地的恶信，使全会众向他发怨言；</span>
<span className="v" id="v37" data-v="37" data-xref="哥林多前书 10:10; 民数记 16:49; 希伯来书 3:17"> 那些报那地恶信的人，都在耶和华面前遭瘟疫而死。</span>
<span className="v" id="v38" data-v="38" data-xref="约书亚记 14:6–10; 民数记 26:65"> 但那些去窥探那地的人中，嫩的儿子约书亚和耶孚尼的儿子迦勒仍然活着。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="出埃及记 33:4; 马太福音 8:12; 希伯来书 12:17"> 摩西把这些话告诉以色列众子孙，百姓就极其悲哀。</span>
<span className="v" id="v40" data-v="40" data-xref="申命记 1:41; 马太福音 7:21–23; 路加福音 13:25"> 他们清早起来，上到山顶，说：“看哪，我们在这里，要上耶和华所应许的地方去；因为我们犯了罪。”</span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="历代志下 24:20; 约伯记 4:9; 耶利米书 2:37"> 摩西说：“你们为什么现在违背耶和华的命令呢？这事必不能成功。</span>
<span className="v" id="v42" data-v="42" data-xref="申命记 1:42; 约书亚记 7:8; 约书亚记 7:12"> 不要上去，因为耶和华不在你们中间；免得你们在仇敌面前被击败。</span>
<span className="v" id="v43" data-v="43" data-xref="民数记 13:29; 民数记 14:25; 历代志下 15:2"> 因为亚玛力人和迦南人在那里，在你们面前；你们必倒在刀下，因为你们转离，不跟随耶和华，所以耶和华必不与你们同在。”</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="申命记 1:43; 撒母耳记上 4:3–11; 民数记 31:6"> 但他们擅自上到山顶。然而，耶和华的约柜和摩西都没有离开营地。</span>
<span className="v" id="v45" data-v="45" data-xref="民数记 21:3; 士师记 1:17; 申命记 1:44"> 于是亚玛力人和住在那山上的迦南人都下来，击打他们，把他们追杀直到何珥玛。</span>
</div>
</div>

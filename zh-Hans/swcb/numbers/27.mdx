<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 26:33; 加拉太书 3:28; 历代志上 7:15"> 约瑟的儿子玛拿西宗族中，玛拿西的儿子玛吉的儿子基列的儿子希弗的儿子西罗非哈，他的女儿们前来。她们的名字是：玛拉、挪阿、曷拉、密迦和得撒。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 15:33–34; 申命记 17:8–10; 出埃及记 18:19–26"> 她们站在会幕门口，在摩西、以利亚撒祭司、众首领和全会众面前，说：</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 26:64–65; 以西结 18:4; 民数记 14:35"> “我们的父亲死在旷野。他没有在可拉一党中，加入那些聚集起来攻击耶和华的人；他是因自己的罪而死的，并且他没有儿子。</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 17:4; 诗篇 109:13; 出埃及记 32:11"> 为什么因我们的父亲没有儿子，就让他的名从他宗族中被除去呢？求你们在我们父亲的兄弟中，给我们产业为业。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="利未记 24:12–13; 约伯记 23:4; 箴言 3:5–6"> 摩西把她们的案件呈到耶和华面前。</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 3:28; 诗篇 68:5–6"> 耶和华对摩西说：</span>
<span className="v" id="v7" data-v="7" data-xref="加拉太书 3:28; 耶利米书 49:11; 约书亚记 17:4"> “西罗非哈的女儿们说得对。你一定要在她们父亲的兄弟中，把产业给她们为业；你要使她们父亲的产业归给她们。</span>
<span className="v" id="v8" data-v="8"> 你要告诉以色列人说：‘如果一个人死了，没有儿子，你们就要使他的产业归给他的女儿。</span>
<span className="v" id="v9" data-v="9"> 如果他没有女儿，你们就要把他的产业给他的兄弟。</span>
<span className="v" id="v10" data-v="10"> 如果他没有兄弟，你们就要把他的产业给他父亲的兄弟。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 35:29; 路得记 4:3–6; 耶利米书 32:8"> 如果他父亲没有兄弟，你们就要把他的产业给他宗族中最近的亲属，他就要承受这产业。这要成为以色列人的律例和典章，照耶和华吩咐摩西的。’”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数记 33:47–48; 申命记 34:1–4; 申命记 3:23–27"> 耶和华对摩西说：“你上这亚巴琳山，观看我赐给以色列人的地。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 10:6; 民数记 31:2; 民数记 20:24–28"> 你看过以后，也要归到你本民那里，像你哥哥亚伦归去一样；</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 1:37; 民数记 20:8–13; 出埃及记 17:7"> 因为在会众争闹的时候，你们在寻的旷野违背了我的话，没有在他们眼前在水那里尊我为圣。”（这水就是寻的旷野中加低斯的米利巴水。）</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 摩西对耶和华说：</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 16:22; 耶利米书 3:15; 希伯来书 12:9"> “愿耶和华，一切血肉之灵的上帝，任命一个人治理会众，</span>
<span className="v" id="v17" data-v="17" data-xref="以西结 34:5; 马可福音 6:34; 列王纪上 22:17"> 可以在他们面前出去，在他们面前进来，领他们出去，带他们进来，使耶和华的会众不至像没有牧人的羊群。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命记 34:9; 民数记 27:23; 创世记 41:38"> 耶和华对摩西说：“你要选嫩的儿子约书亚，就是有圣灵在他里面的人，把你的手按在他身上。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 3:28; 申命记 31:7–8; 申命记 31:23"> 你要使他站在以利亚撒祭司和全会众面前，在他们眼前委任他。</span>
<span className="v" id="v20" data-v="20" data-xref="约书亚记 1:16–18; 撒母耳记上 10:9; 列王纪下 2:9–10"> 你要把权柄赐给他，使以色列人的全会众都听从他。</span>
<span className="v" id="v21" data-v="21" data-xref="约书亚记 9:14; 撒母耳记上 28:6; 出埃及记 28:30"> 他要站在以利亚撒祭司面前；以利亚撒要在耶和华面前为他求问乌陵的判断。他们要照他的话出去，照他的话进来；他和全体以色列人，就是全会众，都要如此。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 摩西照耶和华吩咐他的做了。他选了约书亚，使他站在以利亚撒祭司和全会众面前。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 3:28; 民数记 27:19; 申命记 31:7–8"> 他把手按在约书亚身上，委任他，正如耶和华借摩西所说的。</span>
</div>
</div>

</div>

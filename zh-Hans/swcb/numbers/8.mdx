<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 25:37; 出埃及记 40:25; 利未记 24:1–2"> “你要告诉亚伦，对他说：‘你点灯的时候，七盏灯要照亮灯台前方。’”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3"> 亚伦就这样做了。他点亮灯盏，使灯台前方明亮，正如耶和华吩咐摩西的。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 25:31–40; 出埃及记 25:9; 出埃及记 25:18"> 这灯台的做工是用金子锤出来的，从底座到花朵都是锤出来的。人照着耶和华指示摩西的样式造了灯台。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 耶和华对摩西说：</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 7:1; 雅各书 4:8; 出埃及记 19:15"> “你要从以色列子孙中取利未人，并洁净他们。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 19:13; 民数记 19:7–10; 利未记 8:6"> 你要这样洁净他们：把洁净水洒在他们身上，让他们用剃刀刮全身，洗净衣服，洁净自己。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 2:1; 出埃及记 29:1; 利未记 16:3"> 然后让他们取一头公牛犊和同献的素祭，就是调了油的细面；你还要另取一头公牛犊作赎罪祭。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 40:12; 利未记 8:3; 出埃及记 29:4–37"> 你要把利未人带到会幕前，也要召集以色列子孙全会众。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 1:4; 使徒行传 6:6; 提摩太前书 4:14"> 你要把利未人献在耶和华面前，以色列子孙要按手在利未人身上；</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 7:30; 利未记 8:29; 民数记 1:49–53"> 亚伦要代表以色列子孙，把利未人作为摇祭献在耶和华面前，好让他们办理耶和华的事奉。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="希伯来书 10:4–10; 出埃及记 29:10; 利未记 1:4"> “利未人要按手在那两头公牛的头上；你要把一头献给耶和华作赎罪祭，另一头作燔祭，为利未人赎罪。</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 8:21; 民数记 8:11; 罗马书 15:16"> 你要使利未人站在亚伦和他儿子们面前，把他们作为摇祭献给耶和华。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 3:45; 玛拉基书 3:17; 民数记 18:6"> 这样，你要把利未人从以色列子孙中分别出来，利未人就要归我。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数记 8:11; 民数记 8:13; 民数记 3:23–37"> “之后，利未人要进去办理会幕的事奉。你要洁净他们，把他们作为摇祭献上。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 3:12; 民数记 3:45; 民数记 3:9"> 因为他们是从以色列子孙中完全献给我的；我取他们归我，是代替以色列子孙中一切头生的，就是凡头胎所生的。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 13:2; 路加福音 2:23; 出埃及记 13:12–15"> 因为以色列子孙中一切头生的，无论是人是牲畜，都是我的。我击杀埃及地一切头生的那一天，就把他们分别为圣归我。</span>
<span className="v" id="v18" data-v="18"> 我取了利未人，代替以色列子孙中一切头生的。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 1:53; 民数记 16:46; 历代志下 26:16–20"> 我从以色列子孙中把利未人赐给亚伦和他的儿子们，作为礼物，好在会幕中办理以色列子孙的事奉，并为以色列子孙赎罪，免得以色列子孙靠近圣所时，他们中间有灾祸。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 摩西、亚伦和以色列子孙全会众就这样待利未人。凡耶和华论到利未人所吩咐摩西的，以色列子孙都照样待他们。</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 8:7; 民数记 19:19; 民数记 8:15"> 利未人洁净自己脱离罪，并洗净衣服；亚伦把他们作为摇祭献在耶和华面前，又为他们赎罪，使他们洁净。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 31:2; 历代志下 35:8–15; 民数记 8:15"> 之后，利未人进去，在亚伦和他儿子们面前，在会幕中办理他们的事奉。耶和华论到利未人怎样吩咐摩西，他们就怎样待他们。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23"> 耶和华对摩西说：</span>
<span className="v" id="v24" data-v="24" data-xref="民数记 4:3; 历代志上 23:3; 民数记 4:23"> “关于利未人所指定的是这样：从二十五岁以上，他们要进去参与会幕事奉的工作；</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 4:23; 提摩太后书 4:7"> 到了五十岁，他们要从工作的职务中退休，不再事奉，</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 1:53; 民数记 3:32; 提摩太前书 4:15"> 只可在会幕中协助他们的弟兄尽职守，却不可再办理事奉。你要这样安排利未人的职责。”</span>
</div>
</div>

</div>

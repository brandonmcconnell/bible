<span className="v" id="v1" data-v="1" data-xref="诗篇 77:20; 弥迦书 6:4; 出埃及记 12:51"> 这些是以色列子孙的行程；他们在摩西和亚伦手下，按着队伍从埃及地出来。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 9:17–23; 申命记 10:11; 民数记 10:6"> 摩西照着耶和华的命令，记下他们各段行程的出发地点。这些就是他们按着出发地点所行的路程。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 14:8; 出埃及记 12:37; 出埃及记 13:4"> 正月十五日，他们从兰塞起行；逾越节的次日，以色列子孙在所有埃及人眼前昂然出去，</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 12:12; 以赛亚书 19:1; 出埃及记 18:11"> 那时埃及人正在埋葬他们所有的长子，就是耶和华在他们中间所击杀的。耶和华也向他们的神明施行了审判。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 12:37"> 以色列子孙从兰塞起行，在疏割安营。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 13:20"> 他们从疏割起行，在旷野边上的以倘安营。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 14:2; 出埃及记 14:9; 民数记 33:8"> 他们从以倘起行，转回到巴力洗分对面的比哈希录，在密夺前面安营。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 15:22–26; 出埃及记 14:21–31"> 他们从哈希录前面起行，穿过海中进入旷野。他们在以倘旷野走了三天的路程，在玛拉安营。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 15:27"> 他们从玛拉起行，来到以琳。在以琳有十二股水泉和七十棵棕树，他们就在那里安营。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 16:1; 出埃及记 17:1"> 他们从以琳起行，在红海边安营。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 16:1"> 他们从红海起行，在汛的旷野安营。</span>
<span className="v" id="v12" data-v="12"> 他们从汛的旷野起行，在脱加安营。</span>
<span className="v" id="v13" data-v="13"> 他们从脱加起行，在亚录安营。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 17:1–8; 出埃及记 19:2"> 他们从亚录起行，在利非订安营；在那里，百姓没有水喝。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 19:1–2; 出埃及记 16:1"> 他们从利非订起行，在西奈旷野安营。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 11:34; 民数记 10:11–13; 民数记 10:33"> 他们从西奈旷野起行，在基博罗哈他瓦安营。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 11:35"> 他们从基博罗哈他瓦起行，在哈洗录安营。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 12:16"> 他们从哈洗录起行，在利提玛安营。</span>
<span className="v" id="v19" data-v="19"> 他们从利提玛起行，在临门帕烈安营。</span>
<span className="v" id="v20" data-v="20"> 他们从临门帕烈起行，在立拿安营。</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 1:1"> 他们从立拿起行，在勒撒安营。</span>
<span className="v" id="v22" data-v="22"> 他们从勒撒起行，在基希拉他安营。</span>
<span className="v" id="v23" data-v="23"> 他们从基希拉他起行，在沙斐山安营。</span>
<span className="v" id="v24" data-v="24"> 他们从沙斐山起行，在哈拉大安营。</span>
<span className="v" id="v25" data-v="25"> 他们从哈拉大起行，在玛吉希录安营。</span>
<span className="v" id="v26" data-v="26"> 他们从玛吉希录起行，在他哈安营。</span>
<span className="v" id="v27" data-v="27"> 他们从他哈起行，在他拉安营。</span>
<span className="v" id="v28" data-v="28"> 他们从他拉起行，在密加安营。</span>
<span className="v" id="v29" data-v="29"> 他们从密加起行，在哈摩拿安营。</span>
<span className="v" id="v30" data-v="30" data-xref="申命记 10:5–6"> 他们从哈摩拿起行，在摩西录安营。</span>
<span className="v" id="v31" data-v="31" data-xref="申命记 10:6; 创世记 36:27; 历代志上 1:43"> 他们从摩西录起行，在比尼亚干安营。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 10:7"> 他们从比尼亚干起行，在曷哈及甲安营。</span>
<span className="v" id="v33" data-v="33" data-xref="申命记 10:7"> 他们从曷哈及甲起行，在约巴他安营。</span>
<span className="v" id="v34" data-v="34"> 他们从约巴他起行，在阿博拿安营。</span>
<span className="v" id="v35" data-v="35" data-xref="申命记 2:8; 列王纪上 9:26; 列王纪上 22:48"> 他们从阿博拿起行，在以旬迦别安营。</span>
<span className="v" id="v36" data-v="36" data-xref="民数记 20:1; 民数记 27:14; 申命记 32:51"> 他们从以旬迦别起行，在寻的旷野，就是加低斯，安营。</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 21:4; 民数记 20:22–23; 民数记 20:16"> 他们从加低斯起行，在以东地边界的何珥山安营。</span>
<span className="v" id="v38" data-v="38" data-xref="申命记 10:6; 申命记 32:50; 民数记 20:24–28"> 祭司亚伦照着耶和华的命令上了何珥山，死在那里；那是在以色列子孙从埃及地出来后的第四十年五月初一日。</span>
<span className="v" id="v39" data-v="39"> 亚伦死在何珥山的时候，年一百二十三岁。</span>
<span className="v" id="v40" data-v="40" data-xref="民数记 21:1–9"> 住在迦南地南地的迦南人亚拉得王，听见以色列子孙来了。</span>
<span className="v" id="v41" data-v="41" data-xref="民数记 21:4"> 他们从何珥山起行，在撒摩拿安营。</span>
<span className="v" id="v42" data-v="42"> 他们从撒摩拿起行，在普嫩安营。</span>
<span className="v" id="v43" data-v="43" data-xref="民数记 21:10"> 他们从普嫩起行，在阿伯安营。</span>
<span className="v" id="v44" data-v="44" data-xref="民数记 21:11"> 他们从阿伯起行，在摩押边界的以耶亚巴琳安营。</span>
<span className="v" id="v45" data-v="45"> 他们从以耶起行，在底本迦得安营。</span>
<span className="v" id="v46" data-v="46" data-xref="耶利米书 48:18; 以西结 6:14; 以赛亚书 15:2"> 他们从底本迦得起行，在亚门低比拉太音安营。</span>
<span className="v" id="v47" data-v="47" data-xref="申命记 32:49; 申命记 34:1; 民数记 27:12"> 他们从亚门低比拉太音起行，在尼波对面的亚巴琳山地安营。</span>
<span className="v" id="v48" data-v="48" data-xref="民数记 22:1"> 他们从亚巴琳山地起行，在摩押平原，约旦河边、耶利哥对面安营。</span>
<span className="v" id="v49" data-v="49" data-xref="约书亚记 2:1; 约书亚记 13:20; 民数记 25:1–9"> 他们在约旦河边安营，从伯耶施末直到摩押平原的亚伯什亭。</span>
<span className="v" id="v50" data-v="50" data-xref="民数记 33:48–49"> 耶和华在摩押平原，约旦河边、耶利哥对面，对摩西说：</span>
<span className="v" id="v51" data-v="51" data-xref="约书亚记 3:17; 申命记 9:1; 申命记 7:1"> “你要告诉以色列子孙，对他们说：‘你们过约旦河进入迦南地的时候，</span>
<span className="v" id="v52" data-v="52" data-xref="出埃及记 23:24; 利未记 26:1; 申命记 20:16–18"> 就要从你们面前赶出那地所有的居民，毁灭他们所有的石像，毁灭他们所有铸成的偶像，拆毁他们所有的丘坛。</span>
<span className="v" id="v53" data-v="53" data-xref="申命记 11:31; 诗篇 115:16; 申命记 32:8"> 你们要占领那地，住在其中；因为我已经把那地赐给你们，要让你们拥有它。</span>
<span className="v" id="v54" data-v="54" data-xref="民数记 26:53–56; 约书亚记 18:11–48; 约书亚记 15:1–12"> 你们要按着家族拈阄承受那地；人多的，要给他们较大的产业；人少的，要给他们较小的产业。阄落到谁那里，那里就归谁。你们要按着父系支派承受产业。</span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="士师记 2:3; 诗篇 106:34–36; 申命记 7:16"> “‘但如果你们不从你们面前赶出那地的居民，那么你们所留下的人，就必像你们眼中的刺、肋旁的荆棘；他们必在你们所居住的地上扰害你们。</span>
<span className="v" id="v56" data-v="56" data-xref="路加福音 21:23–24; 申命记 28:63; 利未记 20:23"> 我原打算怎样待他们，也必照样待你们。’”</span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 23:10; 民数记 15:18; 利未记 25:2"> “你要对以色列人说，告诉他们：‘你们进了我所赐给你们居住的地，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 29:18; 创世记 8:21; 腓立比书 4:18"> 若要从牛群或羊群中取牲畜献火祭给耶和华，作燔祭或祭物，为要还愿，或作甘心祭，或在你们指定的节期献上，使馨香之气达到耶和华面前，</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 29:40; 利未记 23:13; 利未记 6:14"> 那么献供物的人，要把细面一伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="1伊法约为22升，或约为2/3蒲式耳。">a</a></sup>的十分之一，调和油一欣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="1欣约为6.5升，或1.7加仑。">b</a></sup>的四分之一，作为素祭献给耶和华。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 28:7; 民数记 28:14; 士师记 9:13"> 你要为奠祭预备酒一欣的四分之一，与燔祭或祭物一同献上；每只羊羔都要这样。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数记 28:12–14; 民数记 15:4"> “‘若是献公绵羊，你要预备细面一伊法<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="1伊法约为22升，或约为2/3蒲式耳。">c</a></sup>的十分之二，调和油一欣的三分之一，作为素祭；</span>
<span className="v" id="v7" data-v="7"> 又要为奠祭献酒一欣的三分之一，成为馨香之气，达到耶和华面前。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 3:1; 利未记 7:11–18; 利未记 1:3"> 你预备公牛作燔祭或祭物，为要还愿，或作平安祭献给耶和华时，</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 28:14; 民数记 28:12; 利未记 6:14"> 就要把细面一伊法<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="1伊法约为22升，或约为2/3蒲式耳。">d</a></sup>的十分之三，调和油半欣，作为素祭，和公牛一同献上；</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 15:5; 民数记 6:15"> 又要为奠祭献酒半欣，作为火祭，成为馨香之气，达到耶和华面前。</span>
<span className="v" id="v11" data-v="11"> 每一头公牛、每一只公绵羊、每一只公羊羔或小山羊，都要这样办理。</span>
<span className="v" id="v12" data-v="12"> 你们按所预备的数目，每一只都要照数这样办理。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> “‘凡本地出生的人献火祭，成为馨香之气达到耶和华面前，都要这样办理。</span>
<span className="v" id="v14" data-v="14"> 若有外人寄居在你们中间，或在你们世世代代中有人住在你们中间，要献火祭，成为馨香之气达到耶和华面前；你们怎样办理，他也要怎样办理。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 9:14; 民数记 15:29; 出埃及记 12:49"> 至于会众，你们和寄居的外人都要有同一个定例；这要作你们世世代代永远的定例。在耶和华面前，你们怎样，外人也要怎样。</span>
<span className="v" id="v16" data-v="16"> 你们和寄居在你们中间的外人，都要有同一条律法、同一项条例。’”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和华对摩西说：</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 15:2; 申命记 26:1–15"> “你要对以色列人说，告诉他们：‘你们进了我带你们去的那地，</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 5:11–12"> 你们吃那地出产的饼时，要向耶和华献上摇祭。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 2:14; 出埃及记 34:26; 申命记 26:2–10"> 你们要从初熟的面团中取一个饼献为摇祭；要像禾场上的摇祭一样，把它奉上。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 29:28; 民数记 18:26"> 你们世世代代都要从初熟的面团中取一份，作为摇祭献给耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="利未记 4:2; 利未记 4:27; 利未记 5:15–17"> “‘你们若犯了错误，没有遵行耶和华对摩西所说的这一切诫命，</span>
<span className="v" id="v23" data-v="23"> 就是耶和华借着摩西吩咐你们的一切，从耶和华赐下命令的那日起，直到你们世世代代，</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 4:23; 利未记 4:13–21; 利未记 5:15"> 如果这是会众在不知情中无意做的，那么全会众要献一头公牛犊作燔祭，成为馨香之气达到耶和华面前，并照条例献上同献的素祭和奠祭，又献一只公山羊作赎罪祭。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 4:20; 罗马书 3:25; 希伯来书 2:17"> 祭司要为以色列全会众赎罪，他们就必蒙赦免；因为这是错误，他们也已经为自己的错误，把供物，就是献给耶和华的火祭，以及他们的赎罪祭，带到耶和华面前。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 15:24"> 以色列全会众和寄居在他们中间的外人都必蒙赦免；因为就全体百姓而言，这事是无意中做的。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="利未记 4:27–28; 使徒行传 17:30; 使徒行传 3:17"> “‘若有一个人无意中犯罪，他就要献一只一岁的母山羊作赎罪祭。</span>
<span className="v" id="v28" data-v="28" data-xref="利未记 4:35"> 那人在耶和华面前无意中犯罪、犯了错误，祭司要为这犯罪的人赎罪；祭司为他赎罪，他就必蒙赦免。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 15:15; 利未记 16:29; 利未记 17:15"> 在以色列人中本地出生的人和寄居在他们中间的外人，若有人无意中做了什么事，你们都要有同一条律法。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="希伯来书 10:26; 诗篇 19:13; 申命记 1:43"> “‘但无论是本地出生的人，还是外人，若有人擅敢行事，就是亵渎耶和华；那人必须从他的民中被剪除。</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 12:9; 箴言 13:13; 以西结 18:20"> 因为他轻视耶和华的话，违背了祂的命令，那人必须被彻底剪除；他的罪孽要归到他身上。’”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="出埃及记 35:2–3; 出埃及记 31:14–15; 出埃及记 20:8–10"> 以色列人在旷野的时候，发现有一个人在安息日捡柴。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 8:3–20"> 那些发现他捡柴的人，就把他带到摩西、亚伦和全会众那里。</span>
<span className="v" id="v34" data-v="34" data-xref="利未记 24:12; 民数记 9:8"> 他们把他拘禁起来，因为还没有说明该怎样处置他。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="使徒行传 7:58; 出埃及记 31:14–15; 列王纪上 21:13"> 耶和华对摩西说：“那人必须被处死；全会众要在营外用石头打死他。”</span>
<span className="v" id="v36" data-v="36" data-xref="约书亚记 7:25"> 于是全会众把他带到营外，用石头打死了他，正如耶和华吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37"> 耶和华对摩西说：</span>
<span className="v" id="v38" data-v="38" data-xref="马太福音 23:5; 申命记 22:12; 马太福音 9:20"> “你要对以色列人说，告诉他们：他们世世代代要在衣服的边上给自己做穗子<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="或作“流苏”（希伯来文 צִיצִ֛ת）。">e</a></sup>，并在每边的穗子<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="或作“流苏”。">f</a></sup>上加一根蓝色的线。</span>
<span className="v" id="v39" data-v="39" data-xref="诗篇 106:39; 箴言 28:26; 诗篇 73:27"> 这要作为你们的穗子，<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="或作“流苏”。">g</a></sup>使你们看见它，就记得耶和华的一切诫命，并去遵行；也不随从自己的心和自己的眼目去行淫，像你们从前所做的那样；</span>
<span className="v" id="v40" data-v="40" data-xref="罗马书 12:1; 帖撒罗尼迦前书 4:7; 利未记 11:44–45"> 好使你们记得并遵行我的一切诫命，归你们的上帝为圣。</span>
<span className="v" id="v41" data-v="41" data-xref="彼得前书 2:9–10; 以西结 36:25–27; 希伯来书 11:16"> 我是耶和华你们的上帝，曾把你们从埃及地领出来，要作你们的上帝：我是耶和华你们的上帝。”</span>
</div>
</div>

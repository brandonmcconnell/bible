<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="NUM" data-book-slug="numbers" data-book-name="民数记" data-chapter="13" data-verses="33">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 1:22–25; 民数记 32:8; 民数记 34:18"> “你要派人去窥探迦南地，就是我赐给以色列子孙的地。要从他们父系的每一个支派中派一个人，每个人都要是他们当中的首领。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="民数记 12:16; 民数记 32:8; 申命记 1:19"> 摩西就照耶和华的命令，从巴兰旷野派他们出去。他们全都是以色列子孙中的首领。</span>
<span className="v" id="v4" data-v="4"> 以下是他们的名字：<br />属流便支派的，有撒刻的儿子沙母亚。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 属西缅支派的，有何利的儿子沙法。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数记 34:19; 民数记 14:6; 民数记 13:30"> 属犹大支派的，有耶孚尼的儿子迦勒。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 属以萨迦支派的，有约瑟的儿子以迦。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 24:13; 民数记 11:28; 民数记 13:16"> 属以法莲支派的，有嫩的儿子何希阿。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9"> 属便雅悯支派的，有拉孚的儿子帕提。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 属西布伦支派的，有梭底的儿子迦叠。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 属约瑟支派中玛拿西支派的，有苏西的儿子迦底。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 属但支派的，有基玛利的儿子亚米利。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13"> 属亚设支派的，有米迦勒的儿子西帖。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 属拿弗他利支派的，有缚西的儿子拿比。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 属迦得支派的，有玛基的儿子基乌利。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数记 13:8; 出埃及记 17:9; 民数记 14:6"> 这些就是摩西派去窥探那地之人的名字。摩西称嫩的儿子何希阿为约书亚。</span>
<span className="v" id="v17" data-v="17" data-xref="士师记 1:9; 创世记 12:9; 士师记 1:19"> 摩西派他们去窥探迦南地，对他们说：“你们从这里上南地去，再上山地去。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结 34:14; 出埃及记 3:8"> 要察看那地怎样；住在那里的人是强是弱，是少是多；</span>
<span className="v" id="v19" data-v="19"> 他们所住的地是好是坏；他们所住的城是营寨还是坚城；</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 31:23; 申命记 31:6–8; 以西结 34:14"> 那地怎样，是肥沃还是贫瘠，其中有没有树木。你们要勇敢，带些那地的果子回来。”那时正是葡萄初熟的时候。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数记 20:1; 民数记 33:36; 民数记 27:14"> 于是他们上去，从寻旷野直到利合，靠近哈马口一带，窥探那地。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 78:12; 诗篇 78:43; 以赛亚书 19:11"> 他们由南地上去，来到希伯仑；在那里有亚衲的子孙亚希幔、示筛、挞买。（希伯仑比埃及的琐安早建七年。）</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 13:24; 民数记 32:9; 申命记 1:24–25"> 他们来到以实各谷，从那里砍下一根枝子，上面有一挂葡萄，两个人用杠抬着，又带了一些石榴和无花果。</span>
<span className="v" id="v24" data-v="24"> 那地方叫作以实各谷，是因为以色列子孙从那里砍下的那挂葡萄。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 34:28; 出埃及记 24:18; 民数记 14:33–34"> 过了四十天，他们窥探那地回来。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 32:8; 民数记 20:1; 申命记 1:19"> 他们走到巴兰旷野的加低斯，来到摩西、亚伦和以色列子孙全会众那里，向他们和全会众回报，又把那地的果子给他们看。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 3:8; 出埃及记 3:17; 出埃及记 13:5"> 他们告诉他说：“我们到了你派我们去的那地；那地果然流奶与蜜，这就是那地的果子。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 9:1–2; 申命记 1:28; 民数记 13:33"> 然而，住在那地的人民强壮，城也坚固宽大；并且我们在那里看见了亚衲的子孙。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 14:43; 士师记 6:3; 创世记 15:19–21"> 亚玛力人住在南地；赫人、耶布斯人和亚摩利人住在山地；迦南人住在海边，并沿着约旦河一带。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="民数记 14:24; 罗马书 8:31; 腓立比书 4:13"> 迦勒在摩西面前使百姓安静，说：“我们立刻上去占领那地吧；因为我们一定能够胜过它！”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="申命记 1:28; 约书亚记 14:8; 希伯来书 3:19"> 但那些和他一同上去的人说：“我们不能上去攻打那民，因为他们比我们强壮。”</span>
<span className="v" id="v32" data-v="32" data-xref="阿摩司 2:9; 民数记 14:36–37; 以西结 36:13–14"> 他们向以色列子孙报那所窥探之地的恶信，说：“我们经过并窥探的那地，是吞吃居民的地；我们在那里所看见的所有人民，都是身材高大的人。</span>
<span className="v" id="v33" data-v="33" data-xref="申命记 1:28; 以赛亚书 40:22; 创世记 6:4"> 我们在那里看见了尼非利人，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：巨人">a</a></sup>就是出自尼非利人的<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：巨人">b</a></sup>亚衲子孙。我们看自己像蚱蜢，他们看我们也是这样。”</span>
</div>
</div>

</div>

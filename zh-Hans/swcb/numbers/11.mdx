<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 21:5; 民数记 16:35; 列王纪下 1:12"> 百姓在耶和华耳中发怨言。耶和华听见了，祂的怒气就燃烧起来；耶和华的火在他们中间焚烧，烧毁了营地边缘的一些地方。</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 21:7; 雅各书 5:16; 民数记 16:45–48"> 百姓向摩西呼求；摩西向耶和华祷告，火就止住了。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 9:22"> 那地方名叫他备拉，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“他备拉”的意思是“焚烧”。">a</a></sup>因为耶和华的火曾在他们中间焚烧。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 10:6; 出埃及记 12:38; 诗篇 106:14"> 他们中间混杂的民起了强烈的贪欲；以色列人也又哭着说：“谁能给我们肉吃呢？</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 16:3; 诗篇 17:14; 腓立比书 3:19"> 我们记得在埃及白白吃的鱼，还有黄瓜、西瓜、韭菜、葱和蒜；</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 21:5; 撒母耳记下 13:4"> 可是现在我们的胃口都没了。除了眼前这吗哪以外，什么都没有。”</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 16:31; 创世记 2:12; 出埃及记 16:14–15"> 吗哪像芫荽子，外观像香胶树脂。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="香胶树脂是从某些非洲树木中提取的树脂。">b</a></sup></span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 16:31; 出埃及记 16:16–18; 出埃及记 16:23"> 百姓到处走动，把吗哪收集起来，用磨磨碎，或用臼捣碎，放在锅里煮，做成饼。它的味道像新榨的油。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 16:13–14; 诗篇 78:23–25; 申命记 32:2"> 夜间露水降在营地上的时候，吗哪也随之降下。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="诗篇 78:21; 民数记 16:27; 民数记 14:1–2"> 摩西听见百姓各按家族哭泣，各人都在自己的帐篷门口；耶和华的怒气大大燃烧，摩西也不喜悦。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 1:12; 出埃及记 5:22; 耶利米书 15:10"> 摩西对耶和华说：“你为什么这样苦待你的仆人？我为什么没有在你眼前蒙恩，以致你把这全体百姓的重担放在我身上？</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 49:23; 以赛亚书 40:11; 帖撒罗尼迦前书 2:7"> 难道这全体百姓是我怀胎生的吗？难道是我把他们生出来的，以致你要对我说：‘你要把他们抱在怀里，像乳母抱吃奶的婴儿一样，把他们带到你向他们列祖起誓应许的土地去’？</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 15:33; 马可福音 8:4; 约翰福音 6:5–9"> 我从哪里得肉给这全体百姓吃呢？因为他们在我面前哭着说：‘给我们肉吃吧！’</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 18:18; 申命记 1:9–12; 哥林多后书 2:16"> 我独自不能担当这全体百姓，因为这担子对我太重了。</span>
<span className="v" id="v15" data-v="15" data-xref="腓立比书 1:20–24; 列王纪上 19:4; 约拿 4:3"> 你若这样待我，我若在你眼前蒙恩，求你立刻杀了我吧；不要让我看见自己的苦境。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及记 24:1; 出埃及记 24:9; 申命记 16:18"> 耶和华对摩西说：“你要从以色列的长老中，为我招聚七十个人，就是你所知道作百姓长老和官长的人；把他们带到会幕那里，使他们和你一同站在那里。</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 11:25; 撒母耳记上 10:6; 哥林多前书 12:4–11"> 我要在那里降临，与你说话。我要把在你身上的圣灵分给他们，使圣灵降在他们身上；他们就要和你一同担当百姓的重担，免得你独自担当。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 19:10; 使徒行传 7:39; 出埃及记 16:3–7"> “你要对百姓说：‘你们要为明天分别为圣，你们就会有肉吃；因为你们在耶和华耳中哭着说：“谁能给我们肉吃呢？我们在埃及过得好。”所以耶和华必给你们肉吃，你们也要吃。</span>
<span className="v" id="v19" data-v="19"> 你们不只是吃一天、两天、五天、十天或二十天，</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 106:15; 民数记 21:5; 诗篇 78:27–30"> 而是要吃整整一个月，直到肉从你们鼻孔里出来，使你们厌恶；因为你们厌弃了在你们中间的耶和华，又在祂面前哭着说：“我们为什么要从埃及出来呢？”’”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及记 12:37; 民数记 1:46; 创世记 12:2"> 摩西说：“我所在的这百姓，步行的男人有六十万；你却说：‘我要给他们肉，使他们吃整整一个月。’</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 15:33; 列王纪下 7:2; 约翰福音 6:9"> 难道要为他们宰杀羊群牛群，才够他们吃吗？难道要为他们聚集海中所有的鱼，才够他们吃吗？”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 59:1; 以赛亚书 50:2; 创世记 18:14"> 耶和华对摩西说：“耶和华的手岂是缩短了吗？现在你要看我的话是否会在你这里成就。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数记 11:16; 民数记 11:26"> 摩西出去，把耶和华的话告诉百姓；他又招聚百姓中的七十位长老，使他们站在会幕四围。</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 11:17; 约珥 2:28–29; 撒母耳记上 10:10"> 耶和华在云中降临，对摩西说话；祂把在摩西身上的圣灵分给那七十位长老，使圣灵降在他们身上。圣灵停在他们身上的时候，他们就说预言，但以后没有再这样做。</span>
<span className="v" id="v26" data-v="26" data-xref="耶利米书 36:5; 撒母耳记上 20:26; 撒母耳记上 10:22"> 但有两个人仍留在营里，一个名叫伊利达，另一个名叫米达；圣灵也停在他们身上。他们是在被记录的人之中，却没有出去到会幕那里；他们就在营里说预言。</span>
<span className="v" id="v27" data-v="27"> 有一个年轻人跑去告诉摩西，说：“伊利达和米达正在营里说预言！”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马可福音 9:38–40; 路加福音 9:49–50; 约翰福音 3:26"> 嫩的儿子约书亚，就是摩西的仆人、摩西所拣选的人之一，回答说：“我主摩西，制止他们！”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 14:5; 马太福音 9:37–38; 路加福音 10:2"> 摩西对他说：“你是为我的缘故嫉妒吗？但愿耶和华的百姓都作先知，但愿耶和华把祂的圣灵降在他们身上！”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30"> 摩西和以色列的长老都回到营里。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 16:13; 诗篇 105:40; 诗篇 78:26–29"> 有风从耶和华那里吹出，从海上带来鹌鹑，使它们落在营旁，在营的这边约有一天的路程，那边也约有一天的路程，环绕营地，离地面约二肘<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一肘是人手臂从中指尖到肘部的长度，约为18英寸或46厘米。">c</a></sup>高。</span>
<span className="v" id="v32" data-v="32" data-xref="以西结 45:11; 出埃及记 16:36"> 百姓起来，整天整夜，又整整次日，收集鹌鹑；收得最少的也收了十贺梅珥。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="1贺梅珥约为220升或6蒲式耳。">d</a></sup>他们把鹌鹑为自己摊在营地四围。</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 78:30–31; 诗篇 106:14–15; 民数记 25:9"> 肉还在他们牙齿之间，尚未嚼烂，耶和华的怒气就向百姓燃烧；耶和华用极大的灾疫击打百姓。</span>
<span className="v" id="v34" data-v="34" data-xref="申命记 9:22; 哥林多前书 10:6; 民数记 33:16"> 那地方名叫基博罗·哈他瓦，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="“基博罗·哈他瓦”的意思是“贪欲之坟”。">e</a></sup>因为他们在那里埋葬了那些起贪欲的人。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="民数记 33:17; 民数记 12:16; 申命记 1:1"> 百姓从基博罗·哈他瓦起行，到哈洗录；他们就住在哈洗录。</span>
</div>
</div>

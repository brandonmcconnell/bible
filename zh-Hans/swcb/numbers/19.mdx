<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西和亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 22:20–25; 申命记 21:3; 撒母耳记上 6:7"> “这是耶和华所吩咐的律法条例。你要告诉以色列人，把一头没有斑点、没有残疾、从未负过轭的红母牛牵到你们这里来。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 4:12; 利未记 4:21; 利未记 16:27"> 你们要把它交给祭司以利亚撒；他要把它牵到营外，有人要在他面前宰杀它。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 4:17; 利未记 4:6; 利未记 16:14"> 祭司以利亚撒要用指头取它的一些血，向会幕前面弹血七次。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 29:14; 利未记 4:11–12; 诗篇 22:14"> 有人要在他眼前焚烧这母牛；它的皮、肉、血，连同粪，都要焚烧。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 14:4; 利未记 14:49; 诗篇 51:7"> 祭司要取香柏木、牛膝草和朱红色线，丢在焚烧母牛的火中。</span>
<span className="v" id="v7" data-v="7" data-xref="利未记 11:25; 利未记 11:40; 民数记 19:8"> 然后祭司要洗自己的衣服，用水洗身，之后才可以进营；祭司要不洁净直到晚上。</span>
<span className="v" id="v8" data-v="8"> 焚烧母牛的人也要用水洗自己的衣服，用水洗身，并且要不洁净直到晚上。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="希伯来书 9:13; 民数记 19:13; 民数记 19:20–21"> “一个洁净的人要收起母牛的灰，放在营外洁净的地方；这灰要为以色列会众保存，用来调制除污秽的水。这是赎罪祭。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 12:49; 民数记 19:7–8; 歌罗西书 3:11"> 收取母牛灰的人要洗自己的衣服，并且要不洁净直到晚上。这要作为以色列人和寄居在他们中间的外族人的永远条例。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民数记 5:2; 民数记 31:19; 利未记 21:1"> “凡触摸任何人尸体的，要不洁净七天。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 31:19; 启示录 7:14; 利未记 7:17"> 第三天，他要用那水洁净自己，第七天他就洁净了；但如果他第三天不洁净自己，到第七天他也不会洁净。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 15:31; 利未记 22:3; 利未记 7:20"> 凡触摸死人，就是已死之人的身体，却不洁净自己的，就玷污了耶和华的帐幕；那人必从以色列中被剪除。因为除污秽的水没有洒在他身上，他就不洁净；他的不洁净仍在他身上。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> “人死在帐棚里的律法是这样：凡进那帐棚的，以及凡在那帐棚里的，都要不洁净七天。</span>
<span className="v" id="v15" data-v="15" data-xref="利未记 14:36; 利未记 11:32; 民数记 31:20"> 凡没有扎紧盖子的敞口器皿，都是不洁净的。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数记 31:19; 马太福音 23:27; 路加福音 11:44"> “凡在田野里触摸被刀杀的人、尸体、人的骨头或坟墓的，都要不洁净七天。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 7:38; 创世记 26:19; 启示录 7:17"> “要为不洁净的人取一些焚烧赎罪祭后的灰，放在器皿里，再把流水倒在灰上。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结 36:25–27; 希伯来书 9:14; 民数记 19:9"> 一个洁净的人要拿牛膝草，蘸在水中，洒在帐棚上、所有器皿上、在那里的人身上，以及触摸过骨头、被杀的人、死人或坟墓的人身上。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 1:7; 希伯来书 10:22; 以西结 36:25"> 那洁净的人要在第三天和第七天洒在不洁净的人身上。第七天，他要洁净那人。那人要洗自己的衣服，用水洗身，到了晚上就洁净了。</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 16:16; 创世记 17:14; 民数记 19:13"> 但那不洁净而不洁净自己的人，必从会众中被剪除，因为他玷污了耶和华的圣所。除污秽的水没有洒在他身上，他是不洁净的。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 9:13–14; 希伯来书 10:4; 希伯来书 9:10"> 这要作为他们永久的条例。洒除污秽之水的人要洗自己的衣服；触摸除污秽之水的人要不洁净直到晚上。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="哈该书 2:13; 利未记 7:19; 马太福音 15:19–20"> “不洁净的人所触摸的任何物都要不洁净；触摸那物的人也要不洁净直到晚上。”</span>
</div>

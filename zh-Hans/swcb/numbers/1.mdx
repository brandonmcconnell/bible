<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 25:22; 出埃及记 19:1; 民数记 10:11–12"> 耶和华<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="在英文中，当译为全大写字母时，“LORD”或“GOD”是上帝专有名（希伯来文“יהוה”，通常读作雅威）的翻译。">a</a></sup>在西奈的旷野，在会幕里，在他们出埃及地以后第二年二月初一，对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 38:26; 出埃及记 30:12; 民数记 1:18"> “你要按以色列子孙全会众的家族、父家，照名字的数目，一个一个地，统计所有男丁的人数；</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 30:14; 民数记 14:29; 民数记 33:1"> 从二十岁以上，在以色列中凡能出去打仗的，你和亚伦要按他们的队伍数点他们。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 1:16; 出埃及记 18:25; 民数记 13:2–15"> 每一个支派要有一个人与你们同在，各人都是他父家的首领。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 7:30; 创世记 30:5–20; 创世记 49:1–33"> 以下是要与你们一同站立的人的名字：<br />属流便的：示丢珥的儿子以利蓿。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数记 7:36; 民数记 2:12"> 属西缅的：苏利沙代的儿子示路蔑。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="路加福音 3:32; 民数记 10:14; 马太福音 1:2–5"> 属犹大的：亚米拿达的儿子拿顺。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="民数记 7:18; 民数记 10:15; 民数记 2:5"> 属以萨迦的：苏押的儿子拿坦业。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数记 7:24; 民数记 10:16; 民数记 2:7"> 属西布伦的：希伦的儿子以利押。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民数记 7:54; 民数记 7:48; 历代志上 7:26–27"> 属约瑟子孙的：属以法莲的，是亚米忽的儿子以利沙玛；属玛拿西的，是比大蓿的儿子迦玛列。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="民数记 7:60; 民数记 10:24; 民数记 2:22"> 属便雅悯的：基多尼的儿子亚比但。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数记 7:66; 民数记 2:25; 民数记 10:25"> 属但的：亚米沙代的儿子亚希以谢。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 7:72; 民数记 10:26; 民数记 2:27"> 属亚设的：俄兰的儿子帕结。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 2:14; 民数记 7:42; 民数记 10:20"> 属迦得的：丢珥的儿子以利雅萨。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数记 7:78; 民数记 10:27; 民数记 2:29"> 属拿弗他利的：以南的儿子亚希拉。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数记 7:2; 出埃及记 18:21; 出埃及记 18:25"> 这些是从会众中被召的人，是他们父系支派的首领<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作“族长”，或作“领袖”">b</a></sup>；他们是以色列千人队的首领。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 10:3; 启示录 7:4–17; 民数记 1:5–15"> 摩西和亚伦就带着这些按名指定的人。</span>
<span className="v" id="v18" data-v="18" data-xref="以斯拉记 2:59; 尼希米记 7:61; 希伯来书 7:3"> 二月初一，他们召集全会众；众人就按家族、父家，照名字的数目，从二十岁以上，一个一个地申报自己的族谱。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 1:2; 民数记 26:1–2; 撒母耳记下 24:1–10"> 耶和华怎样吩咐摩西，摩西就在西奈的旷野照样数点他们。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数记 26:5–7; 民数记 2:10–11; 创世记 46:9"> 以色列长子流便的子孙，按他们的世代、家族、父家，照名字的数目，一个一个地，从二十岁以上的所有男丁，凡能出去打仗的：</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 26:7; 民数记 2:10–11"> 他们中被数的，属流便支派的，共有四万六千五百人。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数记 26:12–14; 创世记 34:25–30; 民数记 2:12–13"> 西缅的子孙，按他们的世代、家族、父家，其中被数的，照名字的数目，一个一个地，从二十岁以上的所有男丁，凡能出去打仗的：</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 26:14; 民数记 2:13; 民数记 25:8–9"> 他们中被数的，属西缅支派的，共有五万九千三百人。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数记 26:15–18; 创世记 46:16; 民数记 2:14–15"> 迦得的子孙，按他们的世代、家族、父家，照名字的数目，从二十岁以上，凡能出去打仗的：</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 26:18; 民数记 2:15"> 他们中被数的，属迦得支派的，共有四万五千六百五十人。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="创世记 29:35; 民数记 26:19–22; 撒母耳记下 24:9"> 犹大的子孙，按他们的世代、家族、父家，照名字的数目，从二十岁以上，凡能出去打仗的：</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记下 24:9; 民数记 26:22; 历代志下 17:14–16"> 他们中被数的，属犹大支派的，共有七万四千六百人。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="创世记 46:13; 创世记 49:14–15; 创世记 30:18"> 以萨迦的子孙，按他们的世代、家族、父家，照名字的数目，从二十岁以上，凡能出去打仗的：</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 26:25; 民数记 2:6"> 他们中被数的，属以萨迦支派的，共有五万四千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="民数记 26:26–27; 创世记 49:13; 创世记 30:20"> 西布伦的子孙，按他们的世代、家族、父家，照名字的数目，从二十岁以上，凡能出去打仗的：</span>
<span className="v" id="v31" data-v="31" data-xref="民数记 26:27; 民数记 2:8"> 他们中被数的，属西布伦支派的，共有五万七千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="民数记 26:35–37; 申命记 33:17; 创世记 46:20"> 约瑟的子孙：以法莲的子孙，按他们的世代、家族、父家，照名字的数目，从二十岁以上，凡能出去打仗的：</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 26:37; 申命记 33:17; 民数记 2:19"> 他们中被数的，属以法莲支派的，共有四万零五百人。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="民数记 26:28–34"> 玛拿西的子孙，按他们的世代、家族、父家，照名字的数目，从二十岁以上，凡能出去打仗的：</span>
<span className="v" id="v35" data-v="35" data-xref="民数记 26:34; 创世记 48:19–20; 民数记 2:21"> 他们中被数的，属玛拿西支派的，共有三万二千二百人。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="创世记 49:27; 创世记 44:20; 启示录 7:8"> 便雅悯的子孙，按他们的世代、家族、父家，照名字的数目，从二十岁以上，凡能出去打仗的：</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 26:41; 士师记 20:44–46; 历代志下 17:17"> 他们中被数的，属便雅悯支派的，共有三万五千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="创世记 46:23; 创世记 30:5–6; 创世记 49:16–17"> 但的子孙，按他们的世代、家族、父家，照名字的数目，从二十岁以上，凡能出去打仗的：</span>
<span className="v" id="v39" data-v="39" data-xref="民数记 26:43; 民数记 2:26"> 他们中被数的，属但支派的，共有六万二千七百人。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="创世记 30:12–13; 创世记 46:27; 创世记 49:20"> 亚设的子孙，按他们的世代、家族、父家，照名字的数目，从二十岁以上，凡能出去打仗的：</span>
<span className="v" id="v41" data-v="41" data-xref="民数记 26:47; 民数记 2:28"> 他们中被数的，属亚设支派的，共有四万一千五百人。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="创世记 49:21; 民数记 26:48–50; 创世记 46:24"> 拿弗他利的子孙，按他们的世代、家族、父家，照名字的数目，从二十岁以上，凡能出去打仗的：</span>
<span className="v" id="v43" data-v="43" data-xref="民数记 26:50; 民数记 2:30"> 他们中被数的，属拿弗他利支派的，共有五万三千四百人。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44" data-xref="民数记 26:64; 民数记 1:2–16"> 这些就是被数的人，是摩西、亚伦和以色列的十二位首领所数点的；每一位首领代表自己的父家。</span>
<span className="v" id="v45" data-v="45"> 这样，以色列子孙中，按他们的父家，从二十岁以上，在以色列中凡能出去打仗的，所有被数的人——</span>
<span className="v" id="v46" data-v="46" data-xref="出埃及记 12:37; 民数记 26:51; 出埃及记 38:26"> 所有被数的，共有六十万三千五百五十人。</span>
<span className="v" id="v47" data-v="47" data-xref="民数记 2:33; 民数记 3:1–49; 民数记 26:57–62"> 但利未人按他们父系的支派没有被数在其中。</span>
<span className="v" id="v48" data-v="48"> 因为耶和华对摩西说：</span>
<span className="v" id="v49" data-v="49" data-xref="民数记 26:62; 民数记 2:33"> “只有利未支派，你不可数点，也不可在以色列子孙中统计他们的人数；</span>
<span className="v" id="v50" data-v="50" data-xref="出埃及记 38:21; 出埃及记 31:18; 民数记 4:15"> 你却要派利未人管理见证的帐幕、帐幕的一切器具，以及一切属于帐幕的物件。他们要抬帐幕和帐幕的一切器具；他们要照管帐幕，并且在帐幕周围安营。</span>
<span className="v" id="v51" data-v="51" data-xref="民数记 3:38; 民数记 3:10; 撒母耳记上 6:19"> 帐幕要起行的时候，利未人要拆卸；帐幕要支搭的时候，利未人要支搭。外人若接近，必被处死。</span>
<span className="v" id="v52" data-v="52" data-xref="民数记 2:2; 民数记 2:34; 民数记 10:1–36"> 以色列子孙要支搭自己的帐棚，各归自己的营，各归自己的旗号，按他们的队伍安营。</span>
<span className="v" id="v53" data-v="53" data-xref="民数记 16:46; 历代志上 23:32; 利未记 10:6"> 但利未人要在见证的帐幕周围安营，免得愤怒临到以色列子孙的会众。利未人要负责守护见证的帐幕。”</span>
</div>
<div className="bp">
<span className="v" id="v54" data-v="54" data-xref="申命记 12:32; 出埃及记 40:16; 出埃及记 39:32"> 以色列子孙就这样做了。耶和华怎样吩咐摩西，他们就照样做了。</span>
</div>

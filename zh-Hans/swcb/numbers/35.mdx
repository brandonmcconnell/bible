<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 22:1; 民数记 31:12; 民数记 33:50"> 耶和华在摩押平原，约旦河边，耶利哥对面，对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 14:3–4; 以西结 48:8; 约书亚记 21:2–42"> “你要吩咐以色列人，从他们所得为业之地，把一些城给利未人居住；也要把城四围的郊地给利未人。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志下 11:14; 约书亚记 21:11; 以西结 45:2"> 这些城要给他们居住；城的郊地要给他们的牲畜、财物和各样的动物使用。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> “你们给利未人的城邑郊地，要从城墙起向外延伸一千肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘是人手臂从中指尖到肘部的长度，约18英寸或46厘米。">a</a></sup>，四围都是。</span>
<span className="v" id="v5" data-v="5"> 你们要在城外量：东边二千肘，南边二千肘，西边二千肘，北边二千肘，城在中间。这要作他们诸城的郊地。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约书亚记 21:13; 约书亚记 21:3; 诗篇 9:9"> “你们给利未人的城，其中六座要作逃城，给杀人者逃往那里。此外，你们还要给他们四十二座城。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 21:3–42; 历代志上 6:54–81"> 你们给利未人的城，总共要有四十八座，连同城的郊地。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 26:54; 民数记 33:54; 约书亚记 21:1–42"> 你们从以色列人的产业中所给出的城，产业多的要多取，产业少的要少取；各人要按自己所承受的产业，把自己的城给些给利未人。”</span>
<span className="v" id="v9" data-v="9"> 耶和华对摩西说：</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 12:9; 申命记 19:1–2; 利未记 14:34"> “你要对以色列人说：『你们过约旦河进入迦南地的时候，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 21:13; 约书亚记 20:2; 民数记 35:6"> 要为自己指定几座城作你们的逃城，使无意中杀人的可以逃到那里。</span>
<span className="v" id="v12" data-v="12" data-xref="约书亚记 20:3–6; 申命记 19:6; 约书亚记 20:9"> 这些城要作你们躲避报血仇者的避难处，使杀人者在站在会众面前受审以前不致死亡。</span>
<span className="v" id="v13" data-v="13"> 你们所给出的城，要有六座作你们的逃城。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 19:8–10; 申命记 4:41–43; 约书亚记 20:7–9"> 你们要在约旦河东给出三座城，在迦南地给出三座城；这些都要作逃城。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 15:16; 加拉太书 3:28; 罗马书 3:29"> 这六座城要给以色列人、寄居者和住在他们中间的外人作避难处，使所有无意中杀人的都可以逃到那里。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="利未记 24:17; 创世记 9:5–6; 申命记 19:11–13"> 『可是，若有人用铁器击打人，以致那人死了，他就是凶手；凶手必须被处死。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 21:18"> 若他用手中足以致死的石头击打人，以致那人死了，他就是凶手；凶手必须被处死。</span>
<span className="v" id="v18" data-v="18"> 或者，若他用手中足以致死的木器击打人，以致那人死了，他就是凶手；凶手必须被处死。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 20:3; 申命记 19:6; 申命记 19:12"> 报血仇的人要亲自处死那凶手；遇见他时，就要处死他。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 21:14; 申命记 19:11; 撒母耳记下 3:27"> 若有人因仇恨推人，或埋伏着向人投掷东西，以致那人死了，</span>
<span className="v" id="v21" data-v="21"> 或者因敌意用手击打人，以致那人死了，那个击打的人必须被处死。他是凶手；报血仇的人遇见凶手时，就要处死他。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数记 35:11; 出埃及记 21:13; 约书亚记 20:3"> 『可是，若有人突然推人，却没有敌意；或不是埋伏着向人投掷任何东西；</span>
<span className="v" id="v23" data-v="23"> 或是没有看见对方，却把任何足以致死的石头丢在他身上，以致他死了，而他原不是对方的仇敌，也无意害对方，</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 20:6; 民数记 35:12"> 会众就要照这些典章，在打人者和报血仇的人之间作判断。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 29:7; 利未记 4:3; 罗马书 3:24–26"> 会众要把杀人者从报血仇的人手中救出来，并且把他送回他逃入的逃城；他要住在那里，直到那受圣油膏立的大祭司死了。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 『但杀人者若在任何时候出了他所逃入之逃城的边界，</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 22:2; 申命记 19:10; 申命记 19:6"> 报血仇的人在他的逃城边界以外找到他，报血仇的人若杀了那杀人者，就不算有流血的罪；</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 3:14; 希伯来书 10:26–30; 希伯来书 6:4–8"> 因为杀人者本该留在他的逃城里，直到大祭司死了。大祭司死后，杀人者可以回到自己产业之地。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数记 27:11; 民数记 27:1"> 『这些事要在你们世世代代，在你们一切住处，作你们的律例和典章。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="希伯来书 10:28; 申命记 19:15; 马太福音 18:16"> 『凡杀了人的，要凭几个见证人的证言处死凶手；但不可只凭一个见证人指证任何人，使他被处死。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="申命记 19:11–13; 创世记 9:5–6; 诗篇 51:14"> 『再者，对于该死的凶手，你们不可收取赎金来代替他的性命；他必须被处死。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行传 4:12; 加拉太书 3:10–13; 加拉太书 2:21"> 『对于逃到逃城的人，你们不可收取赎金，使他在祭司死以前回来住在本地。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 11:50–51; 诗篇 106:38; 何西阿 4:2–3"> 『这样，你们就不可玷污你们所居住的地；因为血会玷污地。若有人在地上流了血，除了流那流人血者的血以外，不能为那地赎罪。</span>
<span className="v" id="v34" data-v="34" data-xref="民数记 5:3; 诗篇 135:21; 启示录 21:27"> 你们不可污秽你们所居住、我所住的地；因为我耶和华住在以色列人中间。』”</span>
</div>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 2:21; 创世记 26:34–35; 创世记 24:37"> 米利暗和亚伦因摩西所娶的古实女子，就毁谤摩西；因为他娶了一个古实女子。</span>
<span className="v" id="v2" data-v="2" data-xref="以西结 35:12–13; 民数记 16:3; 弥迦书 6:4"> 他们说：“难道耶和华只与摩西说话吗？祂不也与我们说话吗？”耶和华听见了。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马太福音 11:29; 雅各书 3:13; 哥林多后书 11:5"> 摩西这个人极其谦和，胜过地面上的所有人。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 76:9; 民数记 16:16–21"> 耶和华忽然对摩西、亚伦和米利暗说：“你们三个人出来，到会幕这里来！”<br />他们三个人就出来了。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 11:25; 出埃及记 34:5; 诗篇 99:7"> 耶和华在云柱中降临，站在会幕门口，呼唤亚伦和米利暗；他们二人就上前来。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 3:5; 创世记 31:10–11; 创世记 46:2"> 祂说：“现在你们要听我的话。你们中间若有先知，我耶和华必在异象中向他显明自己，在梦中与他说话。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 3:2–6; 约书亚记 1:1; 诗篇 105:26"> 我的仆人摩西不是这样；他在我全家尽忠。</span>
<span className="v" id="v8" data-v="8" data-xref="申命记 34:10; 哥林多前书 13:12; 出埃及记 33:11"> 我要与他口对口说话，明明地说，不用谜语；他也要看见耶和华的形像。你们为什么不惧怕毁谤我的仆人，毁谤摩西呢？”</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 17:22; 何西阿 5:15; 民数记 11:1"> 耶和华的怒气向他们发作；祂就离开了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命记 24:9; 列王纪下 5:27; 出埃及记 4:6"> 云彩从会幕上离开；看哪，米利暗长了麻风，像雪一样白。亚伦看着米利暗，看哪，她长了麻风。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 19:19; 撒母耳记下 24:10; 箴言 30:32"> 亚伦对摩西说：“我主啊，求你不要把这罪归在我们身上；我们在这事上行了愚妄，也犯了罪。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 88:4–5; 哥林多前书 15:8; 提摩太前书 5:6"> 求你不要让她像死胎一样，一出母腹，肉就烂了一半。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="罗马书 12:21; 路加福音 6:28; 雅各书 5:15"> 摩西向耶和华呼求说：“上帝啊，求你医治她！”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命记 25:9; 约伯记 30:10; 以赛亚书 50:6"> 耶和华对摩西说：“她父亲若只是吐唾沫在她脸上，她岂不也要蒙羞七天吗？要把她关在营外七天，之后她才可以被带回来。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命记 24:8–9; 弥迦书 7:8–9; 弥迦书 6:4"> 于是米利暗被关在营外七天；百姓没有启行，直到米利暗被带回来。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 11:35; 民数记 33:18; 民数记 10:12"> 后来，百姓从哈洗录启行，在巴兰旷野安营。</span>
</div>

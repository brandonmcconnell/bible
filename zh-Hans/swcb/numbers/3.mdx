<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 6:20; 创世记 10:1; 出埃及记 6:16"> 这是耶和华在西奈山与摩西说话的日子，亚伦和摩西后代的记述。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 6:23; 民数记 26:60; 出埃及记 28:1"> 亚伦儿子的名字如下：长子拿答，还有亚比户、以利亚撒和以他玛。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="出埃及记 28:41; 利未记 8:30; 利未记 8:12"> 这些是亚伦儿子的名字；他们是受膏的祭司，是摩西分别为圣、承接圣职、供祭司职分的。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 10:1–2; 民数记 26:61"> 拿答和亚比户在西奈的旷野，在耶和华面前献凡火的时候，就死在耶和华面前；他们没有儿女。以利亚撒和以他玛在他们的父亲亚伦面前供祭司职分。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5"> 耶和华对摩西说：</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 10:8; 民数记 2:33; 民数记 1:49–53"> “你要使利未支派近前来，站在祭司亚伦面前，服事他。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 1:50; 民数记 8:15; 民数记 8:11"> 他们要在会幕前守他所交托的职守，也守全会众所交托的职守，办理帐幕的事务。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 4:33; 民数记 10:17; 以赛亚书 52:11"> 他们要看守会幕的一切器具，也要替以色列人守所交托的职责，办理帐幕的事务。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 8:19; 民数记 18:6–7; 以弗所书 4:8"> 你要把利未人交给亚伦和他的儿子；他们是从以色列人中全然给他的。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 1:51; 民数记 3:38; 罗马书 12:7"> 你要指派亚伦和他的儿子，他们要守他们的祭司职分；外人若近前，必被处死。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和华对摩西说：</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 3:41; 民数记 8:16; 民数记 18:6"> “看哪，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“看哪”，来自“הִנֵּה”，意思是看、留意、观察、看见或凝视。它常用作感叹词。">a</a></sup>我已经从以色列人中取了利未人，代替以色列人中一切开母胎的长子；利未人要归我，</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 2:23; 出埃及记 13:12; 出埃及记 13:2"> 因为一切头生的都是我的。我击杀埃及地一切头生的那日，就把以色列中一切头生的，无论是人是牲畜，都分别为圣归我。他们要归我。我是耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 耶和华在西奈的旷野对摩西说：</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 26:62; 马可福音 10:14; 提摩太后书 3:15"> “你要按父家、按宗族数点利未的子孙；凡一个月以上的男子，你都要数点。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数记 3:39; 民数记 4:37; 民数记 4:49"> 摩西照耶和华的话，按他所吩咐的数点他们。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 46:11; 出埃及记 6:16–19; 民数记 15:5–23"> 利未儿子的名字如下：革顺、哥辖、米拉利。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="历代志上 6:17; 历代志上 26:1–32; 出埃及记 6:17–19"> 革顺儿子的名字按他们的宗族如下：立尼和示每。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及记 6:18; 历代志上 6:18; 历代志上 15:17–21"> 哥辖的儿子按他们的宗族如下：暗兰、以斯哈、希伯伦、乌薛。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 6:19; 历代志上 6:19; 民数记 3:33"> 米拉利的儿子按他们的宗族如下：抹利和母示。<br />这些是利未人按他们父家的宗族。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 属革顺的有立尼宗族和示每宗族；这些是革顺人的宗族。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数记 4:38–40"> 他们中被数点的，按所有一个月以上男子的数目，凡被数点的，共有七千五百名。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="民数记 1:53; 民数记 2:17"> 革顺人的宗族要在帐幕后面，就是西边安营。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24"> 革顺人父家的首领是拉伊勒的儿子以利雅萨。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 25:9; 历代志上 23:32; 历代志上 9:14–33"> 革顺子孙在会幕中的职责是看管帐幕、帐棚、帐棚的盖、会幕门口的帘子、</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 35:18; 出埃及记 38:9–16; 出埃及记 27:9–16"> 院子的帷幔、院子门口的帘子——这院子围着帐幕和祭坛——以及帐幕和院子的一切绳子，办理这一切事务。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="历代志上 26:23; 民数记 3:19; 历代志上 23:12"> 属哥辖的有暗兰宗族、以斯哈宗族、希伯伦宗族和乌薛宗族；这些是哥辖人的宗族。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 3:31; 民数记 4:35–36; 民数记 3:7"> 按所有一个月以上男子的数目，共有八千六百名，负责守圣所的职守。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数记 1:53; 民数记 3:23; 民数记 2:10"> 哥辖子孙的宗族要在帐幕南边安营。</span>
<span className="v" id="v30" data-v="30"> 哥辖人宗族父家的首领是乌薛的儿子以利撒反。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 36:35–36; 出埃及记 27:1–8; 出埃及记 26:31–33"> 他们的职责是看管约柜、桌子、灯台、祭坛、圣所中供职用的器具、帘子，以及办理这一切事务。</span>
<span className="v" id="v32" data-v="32" data-xref="民数记 4:27; 民数记 4:16; 民数记 20:25–28"> 祭司亚伦的儿子以利亚撒要作利未人众首领的首领，监督那些守圣所职守的人。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="民数记 3:20; 历代志上 6:19; 历代志上 23:21"> 属米拉利的有抹利宗族和母示宗族；这些是米拉利的宗族。</span>
<span className="v" id="v34" data-v="34" data-xref="民数记 2:9; 民数记 2:11; 民数记 1:21"> 他们中被数点的，按所有一个月以上男子的数目，共有六千二百名。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="＋22,000是四舍五入到2位有效数字的总数。上文所列革顺人、哥辖人和米拉利人的总和是22,300，但传统希伯来文本的数字是四舍五入到2位有效数字，而不是3位有效数字。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="民数记 1:53; 民数记 2:25; 民数记 3:28–29"> 米拉利人宗族父家的首领是亚比亥的儿子苏列。他们要在帐幕北边安营。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 26:32; 出埃及记 26:37; 出埃及记 26:15–29"> 米拉利子孙指定的职责是看管帐幕的板、闩、柱子、座、所有器具，以及办理这一切事务，</span>
<span className="v" id="v37" data-v="37"> 还有院子四围的柱子、座、橛子和绳子。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="民数记 3:10; 民数记 1:53; 民数记 2:3"> 在帐幕前面东边，就是会幕前面向日出之地安营的，是摩西以及亚伦和他的儿子；他们要替以色列人守圣所的职守。外人若近前，必被处死。</span>
<span className="v" id="v39" data-v="39" data-xref="民数记 26:62; 马太福音 7:14; 民数记 4:47–48"> 凡被数点的利未人，就是摩西和亚伦照耶和华的命令、按宗族所数点的，所有一个月以上的男子，共有二万二千名。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="民数记 3:15; 路加福音 10:20; 诗篇 87:6"> 耶和华对摩西说：“你要数点以色列人中所有一个月以上头生的男子，登记他们名字的数目。</span>
<span className="v" id="v41" data-v="41" data-xref="民数记 3:12; 民数记 3:45; 民数记 8:16"> 你要为我取利未人——我是耶和华——代替以色列人中一切头生的；又要取利未人的牲畜，代替以色列人牲畜中一切头生的。”</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> 摩西就照耶和华所吩咐他的，数点以色列人中一切头生的。</span>
<span className="v" id="v43" data-v="43" data-xref="民数记 3:39"> 所有一个月以上头生的男子，按名字数目，被数点的共有二万二千二百七十三名。</span>
</div>
<div className="bp">
<span className="v" id="v44" data-v="44"> 耶和华对摩西说：</span>
<span className="v" id="v45" data-v="45" data-xref="民数记 3:12; 民数记 3:40–41"> “你要取利未人代替以色列人中一切头生的，又取利未人的牲畜代替他们的牲畜；利未人要归我。我是耶和华。</span>
<span className="v" id="v46" data-v="46" data-xref="出埃及记 13:13; 民数记 18:15–16"> 以色列人头生的，比利未人的数目多出二百七十三人；为了赎回他们，</span>
<span className="v" id="v47" data-v="47" data-xref="出埃及记 30:13; 利未记 27:6; 民数记 18:16"> 你要为每人取五舍客勒；要按圣所的舍客勒<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一舍客勒约为10克，或约0.35盎司。">c</a></sup>收取（一个舍客勒是二十季拉<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一季拉约为0.5克，或约7.7格令。">d</a></sup>）；</span>
<span className="v" id="v48" data-v="48"> 你要把赎回多余之人的赎银交给亚伦和他的儿子。”</span>
</div>
<div className="bp">
<span className="v" id="v49" data-v="49"> 于是摩西从那些超过利未人所赎数目的人那里收取赎银；</span>
<span className="v" id="v50" data-v="50" data-xref="民数记 3:46–47; 彼得前书 3:18; 马太福音 20:28"> 他从以色列人头生的收取银子，按圣所的舍客勒，共一千三百六十五舍客勒；<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一舍客勒约为10克，或约0.35盎司；所以1365舍客勒约为13.65千克，或约30磅。">e</a></sup></span>
<span className="v" id="v51" data-v="51" data-xref="民数记 3:48; 民数记 16:15; 撒母耳记上 12:3–4"> 摩西照耶和华的话，把赎银交给亚伦和他的儿子，正如耶和华吩咐摩西的。</span>
</div>
</div>

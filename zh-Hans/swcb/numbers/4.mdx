<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西和亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 3:27; 民数记 3:19"> “你要按哥辖子孙的宗族、父家，从利未子孙中数点他们，</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 4:23; 历代志上 23:3–5; 列王纪下 11:4–12"> 从三十岁以上直到五十岁，凡进入事奉、在会幕里做工的，都要数点。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="民数记 4:19; 马可福音 13:34; 民数记 4:30"> “哥辖子孙在会幕里的事奉，是关于至圣之物的。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 27:51; 希伯来书 9:3; 出埃及记 40:3"> 营起行的时候，亚伦和他的儿子们要进去，取下遮掩的幔子，用它遮盖见证柜，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 25:13–15; 出埃及记 35:19; 民数记 4:7–8"> 又把海狗皮盖在上面，再铺上纯蓝色的布，然后穿上柜杠。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="利未记 24:5–8; 出埃及记 37:10–16; 出埃及记 25:23–30"> “在陈设饼的桌子上，他们要铺一块纯蓝色的布，把盘子、调羹、碗和用来奠酒的杯摆在上面；常设的饼也要在上面。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 4:6–7; 民数记 4:11–13; 民数记 4:9"> 他们要在这些物件上铺一块朱红色的布，再用海狗皮盖在上面，然后穿上桌杠。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 25:31–39; 出埃及记 37:17–24; 启示录 1:20–1"> “他们要拿一块纯蓝色的布，遮盖发光的灯台、灯盏、灯剪、灯花盘，以及一切用来供灯台使用的油器。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 4:12; 民数记 4:6"> 他们要把灯台和它的一切器具放在海狗皮套里，再放在抬架上。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出埃及记 40:5; 出埃及记 30:1–19; 出埃及记 40:26–27"> “在金坛上，他们要铺一块纯蓝色的布，用海狗皮盖在上面，然后穿上坛杠。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="历代志上 9:29; 出埃及记 25:9; 历代志下 4:22"> “他们要把圣所里供职用的一切器具，放在纯蓝色的布里，用海狗皮盖上，再放在抬架上。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="利未记 6:12–13; 出埃及记 39:1; 出埃及记 39:41"> “他们要把坛上的灰除去，在坛上铺一块紫色的布。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志下 4:19; 出埃及记 38:1–7"> 又要把供坛使用的一切器具，就是火盘、叉子、铲子、盆，以及坛的一切器具，都放在坛上；他们要在坛上铺海狗皮，然后穿上坛杠。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 6:6–7; 民数记 7:9; 申命记 31:9"> “营起行的时候，亚伦和他的儿子们把圣所和圣所的一切器具遮盖完毕以后，哥辖子孙才可以来抬；只是他们不可触摸圣物，免得死亡。这些会幕中的物件是哥辖子孙所当抬的。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="出埃及记 25:6; 利未记 24:2; 出埃及记 30:23–38"> “祭司亚伦的儿子以利亚撒的职责，是看管点灯的油、馨香的香、常献的素祭和膏油，也要负责整个帐幕和其中的一切，就是圣所和圣所的器具。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和华对摩西和亚伦说：</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 6:6–7; 民数记 17:10; 民数记 18:5"> “不可让哥辖宗族这一支派从利未人中被剪除；</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 4:15"> 他们靠近至圣之物的时候，你们要这样待他们，使他们可以存活，不至死亡：亚伦和他的儿子们要进去，给每个人指定他所当办的事和他所当抬的物；</span>
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 6:19; 出埃及记 19:21; 民数记 4:15"> 只是他们连片刻也不可进去观看圣所，免得死亡。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21"> 耶和华对摩西说：</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 3:18; 民数记 3:21; 民数记 3:24"> “你也要按革顺子孙的父家、宗族数点他们；</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 4:3; 提摩太前书 1:18; 哥林多前书 9:7"> 从三十岁以上直到五十岁，凡进入供职、在会幕里做工的，你都要数点。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数记 4:19; 民数记 4:31–32; 民数记 4:47"> “革顺人各宗族的事奉，就是服事和搬运：</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 3:25–26; 出埃及记 26:14; 民数记 7:5–7"> 他们要抬帐幕的幔子、会幕和它的盖，以及盖在上面的海狗皮盖，会幕门口的帘子，</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 35:18; 出埃及记 27:9"> 院子的帷幔，帐幕和祭坛四围院子门口的帘子，绳子，以及服事用的一切器具；凡与这些有关该做的事，他们都要办理。</span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 1:70; 哥林多前书 11:2"> 革顺子孙一切的服事和一切所抬的物，都要照亚伦和他儿子们的命令；你们要把他们所负责抬的一切派给他们，作为职责。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 4:33; 哥林多前书 12:5–6"> 这是革顺子孙各宗族在会幕里的事奉；他们的职责要在祭司亚伦的儿子以他玛手下。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数记 3:33–35"> “至于米拉利子孙，你要按他们的宗族、父家数点他们；</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 4:3; 民数记 4:23; 提摩太后书 2:4"> 从三十岁以上直到五十岁，凡进入事奉、做会幕之工的，你都要数点。</span>
<span className="v" id="v31" data-v="31" data-xref="民数记 3:36–37; 出埃及记 26:15; 民数记 7:8–9"> 这是他们按会幕中一切事奉所负责搬运的：帐幕的板、闩、柱子、卯座，</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 38:21; 历代志上 9:29; 民数记 3:8"> 院子四围的柱子、卯座、橛子、绳子，连同一切器具，以及与这些有关的一切事奉。你们要按名指定他们所负责搬运的器具。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 4:28; 约书亚记 3:6; 以赛亚书 3:6"> 这是米拉利子孙各宗族按会幕中一切事奉所做的工，要在祭司亚伦的儿子以他玛手下。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34"> 摩西、亚伦和会众的首领按哥辖子孙的宗族、父家数点他们，</span>
<span className="v" id="v35" data-v="35" data-xref="历代志上 23:24; 民数记 4:23; 历代志上 23:3"> 从三十岁以上直到五十岁，凡进入事奉、在会幕里做工的，</span>
<span className="v" id="v36" data-v="36"> 按宗族被数点的，共有二千七百五十人。</span>
<span className="v" id="v37" data-v="37"> 这些就是哥辖各宗族中被数点的，都是在会幕里事奉的人；摩西和亚伦照耶和华藉摩西所吩咐的数点了他们。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38"> 革顺子孙中，按他们的宗族、父家被数点的，</span>
<span className="v" id="v39" data-v="39"> 从三十岁以上直到五十岁，凡进入事奉、在会幕里做工的，</span>
<span className="v" id="v40" data-v="40" data-xref="民数记 3:32"> 按他们的宗族、父家被数点的，共有二千六百三十人。</span>
<span className="v" id="v41" data-v="41"> 这些就是革顺子孙各宗族中被数点的，都是在会幕里事奉的人；摩西和亚伦照耶和华所吩咐的数点了他们。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42"> 米拉利子孙各宗族中，按他们的宗族、父家被数点的，</span>
<span className="v" id="v43" data-v="43"> 从三十岁以上直到五十岁，凡进入事奉、在会幕里做工的，</span>
<span className="v" id="v44" data-v="44" data-xref="哥林多前书 10:13; 哥林多后书 12:9–10; 哥林多前书 12:8–12"> 按他们的宗族被数点的，共有三千二百人。</span>
<span className="v" id="v45" data-v="45" data-xref="民数记 4:29"> 这些就是米拉利子孙各宗族中被数点的；摩西和亚伦照耶和华藉摩西所吩咐的数点了他们。</span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46"> 所有被数点的利未人，就是摩西、亚伦和以色列的首领按他们的宗族、父家所数点的，</span>
<span className="v" id="v47" data-v="47" data-xref="哥林多前书 12:4–31; 罗马书 12:6–8; 民数记 4:3"> 从三十岁以上直到五十岁，凡进入会幕做服事的工和搬运的工的，</span>
<span className="v" id="v48" data-v="48" data-xref="民数记 3:39; 马太福音 20:16; 马太福音 22:15"> 被数点的共有八千五百八十人。</span>
<span className="v" id="v49" data-v="49" data-xref="民数记 1:54; 民数记 4:31; 民数记 4:15"> 摩西照耶和华的吩咐数点他们，各按他的事奉和他所抬的物。摩西照耶和华所吩咐他的，这样数点了他们。</span>
</div>
</div>

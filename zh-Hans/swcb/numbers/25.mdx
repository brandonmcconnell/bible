<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多前书 10:8; 民数记 33:49; 约书亚记 2:1"> 以色列人住在什亭；百姓开始与摩押的女子行淫。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 10:20; 出埃及记 20:5; 出埃及记 34:15–16"> 这些女子邀请百姓去献祭给她们的神；百姓就吃祭物，并向她们的神下拜。</span>
<span className="v" id="v3" data-v="3" data-xref="约书亚记 22:17; 诗篇 106:28–29; 何西阿 9:10"> 以色列与巴力·毗珥联合，耶和华的怒气就向以色列发作。</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 13:17; 申命记 4:3; 申命记 21:23"> 耶和华对摩西说：“把百姓中所有的首领带来，在日头前把他们悬挂在耶和华面前，好使耶和华的烈怒从以色列转消。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及记 18:21; 列王纪上 18:40; 申命记 13:9"> 摩西对以色列的审判官说：“你们各人要把属自己的人中与巴力·毗珥联合的都杀了。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="约珥 2:17; 民数记 22:4; 耶利米书 36:23"> 看哪，以色列人中有一个人，当摩西和以色列全会众眼前，在会幕门口哭泣的时候，带着一个米甸女子来到他的弟兄们那里。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 6:25; 诗篇 106:30; 约书亚记 22:30–31"> 祭司亚伦的孙子、以利亚撒的儿子非尼哈看见了，就从会众中起来，手里拿着枪。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 16:46–48; 诗篇 106:29–31; 历代志上 21:22"> 他跟随那以色列人进了帐棚，一枪刺穿他们二人，刺穿那以色列男子，也刺穿那女人的身体。这样，瘟疫就在以色列人中止住了。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 10:8; 申命记 4:3–4; 民数记 25:4–5"> 因瘟疫而死的有二万四千人。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 耶和华对摩西说：</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 32:21; 诗篇 78:58; 申命记 32:16"> “祭司亚伦的孙子、以利亚撒的儿子非尼哈，在以色列人中以我的忌邪为忌邪，使我的愤怒从以色列人身上转消，所以我没有在我的忌邪中灭绝以色列人。</span>
<span className="v" id="v12" data-v="12" data-xref="玛拉基书 2:4–5; 玛拉基书 3:1; 以赛亚书 54:10"> 因此你要说：‘看哪，我将我的平安之约赐给他。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 2:17; 罗马书 10:2–4; 耶利米书 33:22"> 这约要归给他，也归给他以后的后裔，作为永远祭司职分的约；因为他为他的上帝忌邪，并为以色列人赎罪。’”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 1:23; 民数记 26:14; 历代志下 19:7"> 那被杀的以色列男子，就是与米甸女子一同被杀的，名叫心利，是撒路的儿子，是西缅人中一个父家的首领。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 31:8; 约书亚记 13:21; 民数记 25:18"> 那被杀的米甸女子名叫哥斯比，是苏珥的女儿；苏珥是米甸一个父家的族长。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 耶和华对摩西说：</span>
<span className="v" id="v17" data-v="17" data-xref="民数记 31:1–3; 启示录 18:6"> “你要扰害米甸人，击杀他们；</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 2:14; 出埃及记 32:35; 哥林多后书 11:3"> 因为他们用诡计扰害你们，在毗珥的事上，并在他们的姊妹、米甸首领的女儿哥斯比的事上欺骗了你们；这哥斯比是在因毗珥的事而发生瘟疫的日子被杀的。”</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="NUM" data-book-slug="numbers" data-book-name="民数记" data-chapter="21" data-verses="35">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="士师记 1:16; 民数记 33:40; 约书亚记 12:14"> 住在南地的迦南人亚拉得王，听见以色列从亚他林路而来，就攻打以色列，掳走了他们一些人。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 11:30; 创世记 28:20; 撒母耳记上 1:11"> 以色列向耶和华许愿说：“你若真的把这人民交在我手中，我就必彻底毁灭他们的城。”</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 14:45; 申命记 1:44; 诗篇 10:17"> 耶和华听了以色列的声音，把迦南人交给他们；他们就彻底毁灭了迦南人和他们的城。那地方的名叫何珥玛。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“何珥玛”的意思是“毁灭”。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及记 6:9; 士师记 11:18; 民数记 32:7"> 他们从何珥山起行，沿着通往红海的路走，要绕过以东地。人民因这路途心里非常沮丧。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 78:19; 民数记 16:13–14; 出埃及记 17:2–3"> 人民就攻击上帝和摩西，说：“你们为什么把我们从埃及领上来，使我们死在旷野呢？这里没有饼，没有水，我们心里厌恶这令人厌恶的食物！”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 10:9; 耶利米书 8:17; 申命记 8:15"> 耶和华差遣毒蛇进入人民中间，蛇就咬他们，以色列中死了许多人。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 8:24; 民数记 11:2; 诗篇 78:34"> 人民来到摩西那里，说：“我们犯了罪，因为我们攻击了耶和华和你。求你向耶和华祷告，叫祂使这些蛇离开我们。”摩西就为人民祷告。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约翰福音 3:14; 诗篇 106:43–45; 诗篇 145:8"> 耶和华对摩西说：“你造一条毒蛇，挂在杆子上。凡被咬的人，一看见它，就必活着。”</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 3:14–15; 希伯来书 12:2; 约翰福音 6:40"> 摩西就造了一条铜蛇，挂在杆子上。若有蛇咬了什么人，那人一望这铜蛇，就活了。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民数记 33:43–45"> 以色列人起行，在阿伯安营。</span>
<span className="v" id="v11" data-v="11"> 他们从阿伯起行，在以耶亚巴琳安营；这地方在摩押对面的旷野，向着日出之地。</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 2:13–14"> 他们从那里起行，在撒烈谷安营。</span>
<span className="v" id="v13" data-v="13" data-xref="士师记 11:18; 民数记 22:36; 以赛亚书 16:2"> 他们从那里起行，在亚嫩河的另一边安营；亚嫩河在旷野中，从亚摩利人的边境流出；因为亚嫩河是摩押的边界，在摩押和亚摩利人之间。</span>
<span className="v" id="v14" data-v="14" data-xref="约书亚记 10:13; 撒母耳记下 1:18"> 所以 《耶和华的战记》 上说：“苏法的瓦希伯，亚嫩的谷，</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 21:28; 申命记 2:18; 申命记 2:9"> 众谷的斜坡，转向亚珥的居所，靠近摩押的边界。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数记 20:8; 以赛亚书 12:3; 以赛亚书 41:17–18"> 他们从那里起行到比珥；这就是耶和华对摩西说：“把人民聚集起来，我要给他们水”的那口井。</span>
</div>
<div className="bp poetry">
<span className="v" id="v17" data-v="17" data-xref="雅各书 5:13; 出埃及记 15:1–2; 诗篇 106:12"> 那时，以色列唱了这首歌：<br /><span className="pl pl-1">“井啊，涌上来！你们要向它歌唱，</span></span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 33:22; 提摩太前书 6:17–18; 雅各书 4:12"> <span className="pl pl-2">这井是众首领所挖的，</span><br /><span className="pl pl-2">是人民的贵族所挖的，</span><br /><span className="pl pl-2">用权杖和他们的杖挖成。”</span><br />他们从旷野起行到玛他拿；</span>
<span className="v" id="v19" data-v="19"> 又从玛他拿到拿哈列；从拿哈列到巴末；</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 23:28; 民数记 23:14; 申命记 1:5"> 又从巴末到摩押田野中的谷，到了毗斯迦的山顶，从那里可以俯瞰荒漠。</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 2:26–28; 民数记 20:14–19; 士师记 11:19–21"> 以色列派使者去见亚摩利人的王西宏，说：</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 20:17"> “请让我们从你的地经过。我们不转入田间或葡萄园，也不喝井里的水；我们要走王道，直到经过你的边境。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="士师记 11:20; 申命记 29:7–8; 以赛亚书 15:4"> 西宏却不准以色列经过他的边境；西宏召集他的全体人民，出去到旷野迎击以色列，来到雅杂，与以色列争战。</span>
<span className="v" id="v24" data-v="24" data-xref="阿摩司 2:9; 约书亚记 24:8; 创世记 32:22"> 以色列用刀刃击杀他，占领他的地，从亚嫩河直到雅博河，直到亚扪人的边界；因为亚扪人的边界设有防御。</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 32:33–42; 以赛亚书 16:8–9; 耶利米书 48:2"> 以色列夺取了这一切城。以色列住在亚摩利人的一切城里，就是希实本和属希实本的一切乡村。</span>
<span className="v" id="v26" data-v="26"> 因为希实本是亚摩利人的王西宏的城；西宏曾与摩押先前的王争战，从他手中夺取了他的全地，直到亚嫩河。</span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 14:4; 民数记 21:14; 哈巴谷 2:6"> 所以说箴言的人说：<br /><span className="pl pl-1">“你们到希实本来吧。</span><br /><span className="pl pl-2">愿西宏的城被建造，被坚立；</span></span>
<span className="v" id="v28" data-v="28" data-xref="民数记 21:15; 耶利米书 48:45–46; 以赛亚书 15:1–2"> <span className="pl pl-1">因为有火从希实本发出，</span><br /><span className="pl pl-2">有火焰从西宏的城发出。</span><br /><span className="pl pl-1">它吞灭了摩押的亚珥，</span><br /><span className="pl pl-2">亚嫩高处的诸主。</span></span>
<span className="v" id="v29" data-v="29" data-xref="士师记 11:24; 列王纪下 23:13; 耶利米书 48:46"> <span className="pl pl-1">摩押啊，你有祸了！</span><br /><span className="pl pl-2">基抹的人民啊，你灭亡了！</span><br /><span className="pl pl-1">他使自己的儿子逃亡，</span><br /><span className="pl pl-2">使自己的女儿被掳，</span><br /><span className="pl pl-2">交给亚摩利人的王西宏。</span></span>
<span className="v" id="v30" data-v="30" data-xref="耶利米书 48:18; 以赛亚书 15:2; 耶利米书 48:22"> <span className="pl pl-1">我们射击了他们。</span><br /><span className="pl pl-2">希实本直到底本都灭亡了。</span><br /><span className="pl pl-1">我们使这地荒废直到挪法，</span><br /><span className="pl pl-2">直延到米底巴。”</span></span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="约书亚记 13:8–12; 民数记 32:33–42; 申命记 3:16–17"> 这样，以色列就住在亚摩利人的地。</span>
<span className="v" id="v32" data-v="32" data-xref="耶利米书 48:32; 民数记 32:1; 民数记 32:35"> 摩西派人去窥探雅谢。他们夺取了雅谢的乡村，赶出那里的亚摩利人。</span>
<span className="v" id="v33" data-v="33" data-xref="约书亚记 13:12; 申命记 1:4; 申命记 29:7"> 他们转身，沿着通往巴珊的路上去。巴珊王噩和他的全体人民出来，在以得来与他们交战。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="诗篇 135:10–11; 约书亚记 8:7; 申命记 3:2–3"> 耶和华对摩西说：“不要怕他，因为我已经把他和他的全体人民，以及他的地，都交在你手中。你要待他，像你待住在希实本的亚摩利人王西宏一样。”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="申命记 29:7–8; 约书亚记 13:12; 申命记 3:3–17"> 于是他们击杀了他和他的众子，以及他的全体人民，直到没有一个幸存者；他们就占领了他的地。</span>
</div>
</div>

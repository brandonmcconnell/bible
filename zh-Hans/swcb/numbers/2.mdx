<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西和亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 14:40; 民数记 10:22; 民数记 1:50"> “以色列人要各按自己的旗号，随着他们父家的旗帜安营；他们要在会幕四围安营，离会幕有一段距离。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="历代志上 2:10; 路得记 4:20; 路加福音 3:32–33"> “在东边，向日出之地安营的，要属犹大营的旗号，按着他们的队伍。犹大人的首领是亚米拿达的儿子拿顺。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 26:22; 民数记 1:27"> 他的队伍，以及其中被数点的人，共有七万四千六百名。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民数记 1:8; 民数记 7:18; 民数记 7:23"> “在他旁边安营的，是以萨迦支派。以萨迦人的首领是苏押的儿子拿坦业。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 26:25; 民数记 1:29"> 他的队伍，以及其中被数点的人，共有五万四千四百名。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="民数记 1:9; 民数记 7:24; 民数记 10:16"> “西布伦支派：西布伦人的首领是希伦的儿子以利押。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 26:26–27; 民数记 1:31"> 他的队伍，以及其中被数点的人，共有五万七千四百名。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="民数记 10:14"> “凡属犹大营被数点的，按着他们的队伍，共有十八万六千四百名。他们要首先起行。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="民数记 1:5; 创世记 49:3–4; 民数记 7:35"> “在南边，要有流便营的旗号，按着他们的队伍。流便人的首领是示丢珥的儿子以利蓿。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 26:7; 民数记 1:21"> 他的队伍，以及其中被数点的人，共有四万六千五百名。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="民数记 1:6; 民数记 10:19; 民数记 7:41"> “在他旁边安营的，是西缅支派。西缅人的首领是苏利沙代的儿子示路蔑。</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 26:14; 民数记 1:23"> 他的队伍，以及其中被数点的人，共有五万九千三百名。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 1:14; 民数记 7:42; 民数记 7:47"> “迦得支派：迦得人的首领是流珥的儿子以利雅萨。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 26:18; 民数记 1:25"> 他的队伍，以及其中被数点的人，共有四万五千六百五十名。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="民数记 10:18; 民数记 2:9; 民数记 2:24"> “凡属流便营被数点的，按着他们的军队，共有十五万一千四百五十名。他们要第二队起行。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民数记 10:21; 民数记 10:17; 民数记 3:38"> “随后，会幕要起行，利未人的营在各营中间。他们怎样安营，也要怎样起行，各人在自己的位置，按着他们的旗号。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民数记 1:10; 民数记 10:22; 创世记 48:14–20"> “在西边，要有以法莲营的旗号，按着他们的队伍。以法莲人的首领是亚米忽的儿子以利沙玛。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 1:33; 民数记 26:37"> 他的队伍，以及其中被数点的人，共有四万零五百名。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数记 1:10; 民数记 7:54; 民数记 10:23"> “在他旁边的，是玛拿西支派。玛拿西人的首领是比大蓿的儿子迦玛列。</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 26:34; 民数记 1:35"> 他的队伍，以及其中被数点的人，共有三万二千二百名。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="民数记 1:11; 民数记 7:60; 民数记 10:24"> “便雅悯支派：便雅悯人的首领是基多尼的儿子亚比但。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 1:37; 民数记 26:41"> 他的军队，以及其中被数点的人，共有三万五千四百名。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数记 10:22; 民数记 2:31; 诗篇 80:2"> “凡属以法莲营被数点的，按着他们的队伍，共有十万八千一百名。他们要第三队起行。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="民数记 1:12; 民数记 7:66; 民数记 10:25"> “在北边，要有但营的旗号，按着他们的队伍。但人的首领是亚米沙代的儿子亚希以谢。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 26:43; 民数记 1:39"> 他的队伍，以及其中被数点的人，共有六万二千七百名。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="民数记 1:13; 民数记 7:77; 民数记 7:72"> “在他旁边安营的，是亚设支派。亚设人的首领是俄兰的儿子帕结。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 1:41; 民数记 26:47"> 他的队伍，以及其中被数点的人，共有四万一千五百名。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数记 1:15; 民数记 10:27; 民数记 26:48–50"> “拿弗他利支派：拿弗他利人的首领是以南的儿子亚希拉。</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 1:42–43; 民数记 26:50"> 他的队伍，以及其中被数点的人，共有五万三千四百名。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="民数记 10:25; 民数记 2:16; 民数记 2:9"> “凡属但营被数点的，共有十五万七千六百名。他们要按着自己的旗号最后起行。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="民数记 1:46; 出埃及记 38:26; 民数记 2:9"> 这些就是以色列人按着他们父家被数点的人。各营按着他们的军队，凡被数点的，共有六十万三千五百五十名。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 26:57–62; 民数记 1:47–49"> 只是利未人没有数点在以色列人中，正如耶和华吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="诗篇 119:6; 民数记 24:2; 民数记 24:5–6"> 以色列人就这样行。凡耶和华所吩咐摩西的，他们都照着行：按着自己的旗号安营，也照样起行；各人按着自己的宗族，照着自己的父家。</span>
</div>
</div>

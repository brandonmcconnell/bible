<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 25:9"> 瘟疫之后，耶和华对摩西和祭司亚伦的儿子以利亚撒说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 38:25–26; 民数记 1:2–3; 出埃及记 30:11–16"> “你们要按父家数点以色列子孙全会众，从二十岁以上，在以色列中凡能出去打仗的。”</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 22:1; 民数记 33:48; 民数记 35:1"> 摩西和以利亚撒祭司在摩押平原、约旦河边、耶利哥对面，对他们说：</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 1:1; 历代志上 21:1"> “要数点从二十岁以上的人，照耶和华吩咐摩西和以色列子孙的。”<br />这些是从埃及地出来的人。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 5:3; 创世记 46:8–9; 出埃及记 6:14"> 以色列的长子是吕便；流便的子孙：属哈诺的，有哈诺族；属法路的，有法路族；</span>
<span className="v" id="v6" data-v="6"> 属希斯伦的，有希斯伦族；属迦米的，有迦米族。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 46:9; 民数记 26:21; 民数记 2:11"> 这些是流便人的各族；他们中被数点的，共有四万三千七百三十人。</span>
<span className="v" id="v8" data-v="8"> 法路的儿子是以利押。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 1:16; 民数记 16:1–35; 诗篇 106:17"> 以利押的儿子是尼母利、大坍、亚比兰。这大坍和亚比兰，就是会众中被召的人；当可拉一伙人背叛耶和华的时候，他们也在那一伙人中背叛摩西和亚伦。</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 16:38; 彼得后书 2:6; 民数记 16:31–35"> 地开了口，把他们和可拉一同吞下去；那一伙人死亡的时候，火吞灭了二百五十个人，他们就成了警戒的记号。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 6:24; 诗篇 42:1; 民数记 16:33"> 然而，可拉的儿子们没有死。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 4:24; 创世记 46:10; 出埃及记 6:15"> 西缅的子孙按着他们的宗族：属尼母利的，有尼母利族；属雅悯的，有雅悯族；属雅斤的，有雅斤族；</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 46:10"> 属谢拉的，有谢拉族；属扫罗的，有扫罗族。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 1:22–23; 民数记 2:12–13"> 这些是西缅人的各族，共有二万二千二百人。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 46:16; 民数记 2:14"> 迦得的子孙按着他们的宗族：属洗分的，有洗分族；属哈基的，有哈基族；属书尼的，有书尼族；</span>
<span className="v" id="v16" data-v="16" data-xref="创世记 46:16"> 属阿斯尼的，有阿斯尼族；属以利的，有以利族；</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 46:16"> 属亚律的，有亚律族；属亚列利的，有亚列利族。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 1:24–25; 民数记 2:14–15"> 这些是迦得子孙的各族，按他们中被数点的，共有四万零五百人。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 46:12; 创世记 38:1–10; 历代志上 2:3–8"> 犹大的儿子是珥和俄南。珥和俄南死在迦南地。</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米记 11:24; 创世记 46:12; 路加福音 3:33"> 犹大的子孙按着他们的宗族是：属示拉的，有示拉族；属法勒斯的，有法勒斯族；属谢拉的，有谢拉族。</span>
<span className="v" id="v21" data-v="21"> 法勒斯的子孙是：属希斯伦的，有希斯伦族；属哈母勒的，有哈母勒族。</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 1:26–27; 民数记 2:3–4; 创世记 49:8"> 这些是犹大的各族，按他们中被数点的，共有七万六千五百人。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 46:13; 历代志上 7:1; 创世记 30:17–18"> 以萨迦的子孙按着他们的宗族：属陀拉的，有陀拉族；属普瓦的，有普瓦族；</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 46:13"> 属雅述的，有雅述族；属伸仑的，有伸仑族。</span>
<span className="v" id="v25" data-v="25" data-xref="民数记 2:5–6; 民数记 1:28–29"> 这些是以萨迦的各族，按他们中被数点的，共有六万四千三百人。</span>
<span className="v" id="v26" data-v="26" data-xref="创世记 46:14; 创世记 30:19–20"> 西布伦的子孙按着他们的宗族：属西烈的，有西烈族；属以伦的，有以伦族；属雅利的，有雅利族。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 1:30–31; 民数记 2:7–8"> 这些是西布伦人的各族，按他们中被数点的，共有六万零五百人。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 46:20; 创世记 48:5; 创世记 41:51–52"> 约瑟的子孙按着他们的宗族：玛拿西和以法莲。</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 17:1; 民数记 36:1; 历代志上 7:14–19"> 玛拿西的子孙：属玛吉的，有玛吉族；玛吉生了基列；属基列的，有基列族。</span>
<span className="v" id="v30" data-v="30" data-xref="士师记 6:11; 士师记 6:34; 士师记 6:24"> 这些是基列的子孙：属伊以谢的，有伊以谢族；属希勒的，有希勒族；</span>
<span className="v" id="v31" data-v="31"> 属亚斯烈的，有亚斯烈族；属示剑的，有示剑族；</span>
<span className="v" id="v32" data-v="32"> 属示米大的，有示米大族；属希弗的，有希弗族。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 27:1; 民数记 36:10–12"> 希弗的儿子西罗非哈没有儿子，只有女儿；西罗非哈女儿的名字是玛拉、挪阿、曷拉、密迦、得撒。</span>
<span className="v" id="v34" data-v="34" data-xref="民数记 1:34–35; 民数记 2:20–21"> 这些是玛拿西的各族；他们中被数点的，共有五万二千七百人。</span>
<span className="v" id="v35" data-v="35" data-xref="历代志上 7:20–21"> 这些是以法莲的子孙，按着他们的宗族：属书提拉的，有书提拉族；属比结的，有比结族；属他罕的，有他罕族。</span>
<span className="v" id="v36" data-v="36"> 这些是书提拉的子孙：属以兰的，有以兰族。</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 1:32–33; 民数记 2:18–19"> 这些是以法莲子孙的各族，按他们中被数点的，共有三万二千五百人。这些是约瑟的子孙，按着他们的宗族。</span>
<span className="v" id="v38" data-v="38" data-xref="历代志上 8:1; 历代志上 7:6–12; 创世记 46:2"> 便雅悯的子孙按着他们的宗族：属比拉的，有比拉族；属亚实别的，有亚实别族；属亚希兰的，有亚希兰族；</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 46:21"> 属书反的，有书反族；属户反的，有户反族。</span>
<span className="v" id="v40" data-v="40" data-xref="历代志上 8:3"> 比拉的儿子是亚勒和乃缦：属亚勒的，有亚勒族；属乃缦的，有乃缦族。</span>
<span className="v" id="v41" data-v="41" data-xref="民数记 2:22–23; 创世记 46:21; 民数记 1:36–37"> 这些是便雅悯的子孙，按着他们的宗族；他们中被数点的，共有四万五千六百人。</span>
<span className="v" id="v42" data-v="42" data-xref="创世记 46:23"> 这些是但的子孙，按着他们的宗族：属书含的，有书含族。这些是但的各族，按着他们的宗族。</span>
<span className="v" id="v43" data-v="43" data-xref="民数记 1:38–39; 民数记 2:25–26"> 书含各族，按他们中被数点的，共有六万四千四百人。</span>
<span className="v" id="v44" data-v="44" data-xref="创世记 46:17; 历代志上 7:30"> 亚设的子孙按着他们的宗族：属音拿的，有音拿族；属亦施韦的，有亦施韦族；属比利亚的，有比利亚族。</span>
<span className="v" id="v45" data-v="45"> 比利亚的子孙中：属希别的，有希别族；属玛结的，有玛结族。</span>
<span className="v" id="v46" data-v="46" data-xref="创世记 46:17"> 亚设的女儿名叫西拉。</span>
<span className="v" id="v47" data-v="47" data-xref="民数记 2:27–28; 民数记 1:40–41"> 这些是亚设子孙的各族，按他们中被数点的，共有五万三千四百人。</span>
<span className="v" id="v48" data-v="48" data-xref="创世记 46:24; 历代志上 7:13"> 拿弗他利的子孙按着他们的宗族：属雅薛的，有雅薛族；属沽尼的，有沽尼族；</span>
<span className="v" id="v49" data-v="49" data-xref="历代志上 7:13"> 属耶色的，有耶色族；属示冷的，有示冷族。</span>
<span className="v" id="v50" data-v="50" data-xref="民数记 1:42–43; 民数记 2:29–30"> 这些是拿弗他利的各族，按着他们的宗族；他们中被数点的，共有四万五千四百人。</span>
<span className="v" id="v51" data-v="51" data-xref="民数记 1:46; 民数记 2:32; 出埃及记 12:37"> 这些是以色列子孙中被数点的，共有六十万一千七百三十人。</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52"> 耶和华对摩西说：</span>
<span className="v" id="v53" data-v="53" data-xref="约书亚记 11:23; 约书亚记 14:1; 诗篇 105:44"> “要按名单的人数，把地分给这些人为产业。</span>
<span className="v" id="v54" data-v="54" data-xref="民数记 33:54; 民数记 32:3; 民数记 32:5"> 人数多的，你要多给产业；人数少的，你要少给产业。各族要按其中被数点的人数分得产业。</span>
<span className="v" id="v55" data-v="55" data-xref="民数记 34:13; 民数记 33:54; 约书亚记 14:2"> 然而，地要凭抽签分配。他们要按父祖各支派的名字承受产业。</span>
<span className="v" id="v56" data-v="56" data-xref="哥林多前书 12:4; 罗马书 11:7"> 要按所抽的签，在人数多的和人数少的之间分配他们的产业。”</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="创世记 46:11; 历代志上 6:1; 出埃及记 6:16–19"> 利未人按着他们的宗族被数点的是这些：属革顺的，有革顺族；属哥辖的，有哥辖族；属米拉利的，有米拉利族。</span>
<span className="v" id="v58" data-v="58" data-xref="民数记 16:1; 民数记 3:17–21; 出埃及记 6:20"> 这些是利未的各族：立尼族、希伯伦族、玛利族、母示族、可拉族。哥辖生了暗兰。</span>
<span className="v" id="v59" data-v="59" data-xref="出埃及记 6:20; 出埃及记 2:1–2; 利未记 18:12"> 暗兰的妻子名叫约基别，是利未的女儿，是在埃及给利未所生的。她给暗兰生了亚伦、摩西和他们的姊妹米利暗。</span>
<span className="v" id="v60" data-v="60" data-xref="民数记 3:2; 民数记 3:8"> 亚伦生了拿答、亚比户、以利亚撒、以他玛。</span>
<span className="v" id="v61" data-v="61" data-xref="民数记 3:4; 利未记 10:1–2; 历代志上 24:1–2"> 拿答和亚比户在耶和华面前献凡火的时候死了。</span>
<span className="v" id="v62" data-v="62" data-xref="申命记 10:9; 民数记 35:2–8; 民数记 3:39"> 他们中被数点的，共有二万三千人，都是一个月以上的男丁；他们没有被数在以色列子孙中，因为在以色列子孙中没有给他们产业。</span>
<span className="v" id="v63" data-v="63" data-xref="民数记 26:3"> 这些是摩西和以利亚撒祭司所数点的人；他们在摩押平原、约旦河边、耶利哥对面，数点了以色列子孙。</span>
<span className="v" id="v64" data-v="64" data-xref="申命记 2:14–15; 申命记 4:3–4; 哥林多前书 10:5"> 但这些人中，没有一个是从前摩西和亚伦祭司在西奈旷野数点以色列子孙时所数点过的人。</span>
<span className="v" id="v65" data-v="65" data-xref="哥林多前书 10:5–6; 民数记 14:38; 罗马书 11:22"> 因为耶和华论到他们曾说：“他们必定死在旷野。”他们中没有一个人存留，除了耶孚尼的儿子迦勒和嫩的儿子约书亚。</span>

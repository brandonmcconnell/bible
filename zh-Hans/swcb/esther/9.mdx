<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="EST" data-book-slug="esther" data-book-name="以斯帖记" data-chapter="9" data-verses="32">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以斯帖记 3:13; 以斯帖记 8:12; 诗篇 30:11"> 十二月，就是亚达月十三日，王的命令和诏令将要执行。那一天，犹太人的仇敌原本希望制伏他们，结果却正好相反，犹太人制伏了恨他们的人。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯帖记 8:17; 以斯帖记 8:11; 诗篇 71:13"> 犹太人在亚哈随鲁王各省的各城聚集起来，下手攻击那些想要害他们的人。无人能抵挡他们，因为对他们的惧怕落在所有人民身上。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 8:36; 以斯帖记 8:5; 但以理 6:1–2"> 各省所有首领、总督、省长和办理王事的人都帮助犹太人，因为对末底改的惧怕落在他们身上。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 3:1; 历代志上 11:9; 撒母耳记上 2:30"> 末底改在王宫中位高权重，他的名声传遍各省；末底改这人越来越有权势。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 18:34–40; 诗篇 20:7–8; 诗篇 149:6–9"> 犹太人用刀击杀所有仇敌，大肆杀戮毁灭，照自己所愿待那些恨他们的人。</span>
<span className="v" id="v6" data-v="6" data-xref="以斯帖记 3:15"> 在书珊城堡，犹太人杀死并毁灭了五百人。</span>
<span className="v" id="v7" data-v="7"> 他们又杀了巴珊大他、达分、亚斯帕他、</span>
<span className="v" id="v8" data-v="8"> 坡拉他、亚大利雅、亚利大他、</span>
<span className="v" id="v9" data-v="9"> 帕玛斯他、亚利赛、亚利代和瓦耶撒他，</span>
<span className="v" id="v10" data-v="10" data-xref="以斯帖记 5:11; 以斯帖记 8:11; 创世记 14:23"> 这十人都是哈米大他的儿子哈曼的儿子，哈曼是犹太人的仇敌；但犹太人没有下手掠夺财物。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 那一天，在书珊城堡被杀的人数呈到王面前。</span>
<span className="v" id="v12" data-v="12" data-xref="以斯帖记 7:2; 以斯帖记 5:6"> 王对王后以斯帖说：“犹太人在书珊城堡杀死并毁灭了五百人，还有哈曼的十个儿子；在王其余各省，他们又做了什么呢？现在你还求什么？必赐给你。你还有什么请求？必为你成就。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以斯帖记 8:11; 申命记 21:23; 以斯帖记 9:15"> 以斯帖说：“如果王认为好，请准许书珊的犹太人明日也照今日的诏令行事，并把哈曼的十个儿子挂在木架上。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14"> 王命令这样行。诏令在书珊颁布，人就把哈曼的十个儿子挂起来。</span>
<span className="v" id="v15" data-v="15" data-xref="以斯帖记 8:11; 以斯帖记 9:10; 以斯帖记 9:16"> 在书珊的犹太人又在亚达月十四日聚集，杀了书珊三百人；但他们没有下手掠夺财物。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以斯帖记 8:11; 以斯帖记 9:2; 利未记 26:7–8"> 在王各省其余的犹太人也聚集起来，为自己的性命自卫，脱离仇敌得享安宁，并杀了恨他们的人七万五千；但他们没有下手掠夺财物。</span>
<span className="v" id="v17" data-v="17" data-xref="以斯帖记 9:21; 以斯帖记 9:1; 以斯帖记 8:9"> 这事发生在亚达月十三日；十四日他们安息，把那日定为设宴欢乐的日子。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="以斯帖记 9:21; 以斯帖记 9:1; 以斯帖记 9:15"> 但在书珊的犹太人，在十三日和十四日聚集，十五日才安息，把那日定为设宴欢乐的日子。</span>
<span className="v" id="v19" data-v="19" data-xref="以斯帖记 8:17; 启示录 11:10; 尼希米记 8:10–12"> 因此，住在无城墙村镇的乡村犹太人，把亚达月十四日定为欢乐设宴的节日，也作为彼此馈送食物的日子。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命记 31:19–22; 哥林多后书 1:10–11; 诗篇 145:4–12"> 末底改记录这些事，并写信给亚哈随鲁王各省远近所有犹太人，</span>
<span className="v" id="v21" data-v="21"> 嘱咐他们每年守亚达月十四日和十五日，</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 30:11; 以赛亚书 14:3; 以斯帖记 9:19"> 因为这两天是犹太人脱离仇敌得享安宁的日子，是他们从忧愁转为喜乐、从哀悼转为节庆的月份；他们要把这两日定为设宴欢乐、彼此馈送食物、周济穷人的日子。</span>
<span className="v" id="v23" data-v="23"> 犹太人就接受他们已经开始守的规矩，照末底改写给他们的去行。</span>
<span className="v" id="v24" data-v="24" data-xref="以斯帖记 3:5–13; 以斯帖记 9:10"> 因为亚甲族人哈米大他的儿子哈曼，就是所有犹太人的仇敌，曾设计毁灭犹太人，又掣“普珥”，就是掣签，要吞灭并毁灭他们。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 7:16; 诗篇 140:9; 诗篇 141:10"> 但这事传到王面前时，王下令写信，使哈曼针对犹太人所策划的恶计回到他自己头上，又使他和他的众子都被挂在木架上。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以斯帖记 9:20; 民数记 16:40; 以西结 39:11"> 因此，人因“普珥”这词称这些日子为“普珥日”。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“普珥日”是希伯来文“普珥”的复数形式，意思是“签”。">a</a></sup>因这信上的一切话，以及他们亲眼所见、所经历的事，</span>
<span className="v" id="v27" data-v="27" data-xref="撒迦利亚书 2:11; 以赛亚书 56:6; 以斯帖记 8:17"> 犹太人为自己、为自己的后裔、也为所有归附他们的人，确立并承担守这两日的责任，使这事不可废止，每年都照所写的、按指定日期遵守。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 13:8–9; 约书亚记 4:7; 诗篇 103:2"> 这些日子要世世代代、家家户户、各省各城被记念和遵守；这些普珥日不可从犹太人中废去，记念也不可从他们的后裔<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：种子。">b</a></sup>中消失。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="以斯帖记 9:20; 以斯帖记 2:15; 以斯帖记 8:10"> 亚比孩的女儿王后以斯帖和犹太人末底改，以全权写信，确认这第二封关于普珥日的信。</span>
<span className="v" id="v30" data-v="30" data-xref="以斯帖记 1:1; 以斯帖记 8:9; 撒迦利亚书 8:19"> 末底改向亚哈随鲁国一百二十七省所有犹太人发信，信中有平安和真实的话，</span>
<span className="v" id="v31" data-v="31" data-xref="以斯帖记 4:3; 以斯帖记 4:16; 约拿 3:2–9"> 要确认这些普珥日按指定日期遵守，正如犹太人末底改和王后以斯帖所规定的，也正如他们为自己和后裔在禁食和哀悼的事上所承担的。</span>
<span className="v" id="v32" data-v="32" data-xref="以斯帖记 9:26"> 以斯帖的命令确认了这些普珥日的事；这事也写在书上。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 24:7; 以斯帖记 5:11; 但以理 6:2"> 这些事以后，亚哈随鲁王抬举亚甲族人哈米大他的儿子哈曼，使他升高，把他的座位设在与他同在的众首领之上。</span>
<span className="v" id="v2" data-v="2" data-xref="以斯帖记 3:5; 诗篇 15:4; 以斯帖记 5:9"> 在王门那里所有王的臣仆都跪拜哈曼，向他致敬，因为王曾这样吩咐关于他的事。唯独末底改不跪拜，也不向他致敬。</span>
<span className="v" id="v3" data-v="3" data-xref="以斯帖记 3:2; 出埃及记 1:17; 以斯帖记 2:19"> 于是王门那里王的臣仆对末底改说：“你为什么违背王的命令？”</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 39:10; 约拿 1:9; 但以理 6:20–28"> 他们天天这样劝他说话，他却不听；于是他们告诉哈曼，要看看末底改的理由是否站得住，因为他已经告诉他们自己是犹太人。</span>
<span className="v" id="v5" data-v="5" data-xref="但以理 3:19; 以斯帖记 5:9; 箴言 21:24"> 哈曼见末底改不跪拜，也不向他致敬，就满心愤怒。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 83:4; 启示录 12:12"> 但他不屑只下手害末底改一人；因为人已经把末底改的民族告诉了他。因此哈曼想要毁灭亚哈随鲁全境内所有犹太人，就是末底改的民族。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 6:15; 以西结 21:21–22; 以斯帖记 9:24–26"> 亚哈随鲁王十二年正月，就是尼散月，有人在哈曼面前掣普珥，就是掣签，从一日到一日，从一月到一月，结果选中了十二月，就是亚达月。</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 4:12–15; 使徒行传 16:20–21; 申命记 4:27"> 哈曼对亚哈随鲁王说：“有一个民族散居、分散在你国各省的众民之中；他们的律法与众民不同，也不遵守王的律法。容留他们，对王没有益处。</span>
<span className="v" id="v9" data-v="9" data-xref="创世记 23:16; 马太福音 18:24"> 如果王认为好，就请下令毁灭他们；我愿把一万他连得<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一他连得约为30公斤、66磅，或965金衡盎司。">a</a></sup>银子交给办理王事的人，收入王的府库。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 41:42; 以斯帖记 8:2; 以斯帖记 7:6"> 王从自己手上取下戒指，给了哈米大他的儿子亚甲族人哈曼，就是犹太人的仇敌。</span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 23:25; 耶利米书 40:4; 耶利米书 26:14"> 王对哈曼说：“银子赐给你，那民族也交给你；你看怎样好，就怎样待他们吧。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王纪上 21:8; 以斯帖记 1:22; 但以理 6:12"> 正月十三日，王的书记被召来；他们就照哈曼所吩咐的一切，写信给王的总督、各省省长和各民族的首领，按各省的文字、各民族的语言书写。信是奉亚哈随鲁王的名写成，并用王的戒指盖印。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志下 30:6; 以斯帖记 9:10; 以斯帖记 8:10–14"> 信由驿使送往王的各省，要在一天之内，就是十二月亚达月十三日，把所有犹太人，无论老少、孩童、妇女，都毁灭、杀戮、灭绝，并掠夺他们的财物。</span>
<span className="v" id="v14" data-v="14" data-xref="以斯帖记 8:13–14"> 这信的副本作为诏令颁布在各省，传给所有民族，使他们预备等候那一天。</span>
<span className="v" id="v15" data-v="15" data-xref="以斯帖记 8:15; 约翰福音 16:20; 箴言 29:2"> 驿使奉王命急忙出发；诏令也在书珊城堡颁布。王和哈曼坐下饮酒，书珊城却一片困惑。</span>
</div>
</div>

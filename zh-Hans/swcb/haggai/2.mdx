<span className="v" id="v1" data-v="1" data-xref="哈该书 1:1; 哈该书 2:20; 哈该书 2:10"> 七月二十一日，耶和华的话借先知哈该临到，说：</span>
<span className="v" id="v2" data-v="2" data-xref="哈该书 1:1; 尼希米记 8:9; 以斯拉记 2:63"> “现在你要对撒拉铁的儿子、犹大省长所罗巴伯，和约萨答的儿子、大祭司约书亚，以及百姓的余民说：</span>
<span className="v" id="v3" data-v="3" data-xref="以斯拉记 3:12; 哈该书 2:9; 以西结 7:20"> ‘你们中间还有谁见过这殿从前的荣耀？现在你们看它怎样？在你们眼中岂不是如同无有吗？</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 28:20; 约书亚记 1:9; 撒迦利亚书 8:9"> 然而现在，所罗巴伯啊，要刚强，’耶和华说。‘约萨答的儿子、大祭司约书亚啊，要刚强。这地所有的百姓啊，要刚强，’耶和华说，‘并且做工，因为我与你们同在，’万军之耶和华说。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 34:10; 出埃及记 29:45–46; 以赛亚书 41:13"> 这是你们出埃及时我与你们立约的话；我的灵住在你们中间。‘不要惧怕。’</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 12:26–28; 以赛亚书 10:25; 马可福音 13:24–26"> 因为万军之耶和华如此说：‘再过不多时候，我必震动天、地、海和旱地；</span>
<span className="v" id="v7" data-v="7" data-xref="玛拉基书 3:1; 列王纪上 8:11; 约翰福音 7:37–39"> 我必震动万国。万国的珍宝必来到，我要使这殿充满荣耀，万军之耶和华说。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 50:10–12; 诗篇 24:1; 以赛亚书 60:17"> 银子是我的，金子也是我的，’万军之耶和华说。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 85:8–9; 哥林多后书 3:9–10; 歌罗西书 1:19–21"> ‘这殿后来的荣耀必大过先前的荣耀，’万军之耶和华说；‘在这地方，我必赐下平安，’万军之耶和华说。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="哈该书 2:20; 哈该书 1:1; 哈该书 1:15–1"> 大流士第二年九月二十四日，耶和华的话借先知哈该临到，说：</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 10:10–11; 玛拉基书 2:7; 申命记 33:10"> “万军之耶和华如此说：现在要向祭司询问有关律法的事，说：</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 6:27; 马太福音 23:19; 利未记 7:6"> ‘如果有人用衣襟兜着圣肉，这衣襟碰到饼、炖菜、酒、油，或任何食物，那食物会成为圣洁吗？’”<br />祭司回答说：“不会。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 5:2–3; 民数记 19:11–22; 利未记 22:4–6"> 哈该又说：“如果一个因尸体而不洁的人碰到这些东西中的任何一样，那东西会不洁吗？”<br />祭司回答说：“会不洁。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="箴言 28:9; 提多书 1:15; 以赛亚书 1:11–15"> 哈该就回答说：“耶和华说：‘这百姓在我面前也是如此，这国也是如此；他们手所做的一切也是如此。他们在那里所献的也是不洁的。</span>
<span className="v" id="v15" data-v="15" data-xref="哈该书 1:5; 以斯拉记 3:10; 以斯拉记 4:24"> 现在，请你们从今日往前追想，在耶和华殿里石头还没有叠在石头上以前，</span>
<span className="v" id="v16" data-v="16" data-xref="哈该书 1:6; 玛拉基书 2:2; 箴言 3:9–10"> 那一切时候，有人来到一堆二十量的谷堆那里，却只有十量；有人来到酒池要舀五十量，却只有二十量。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 28:22; 哈该书 1:11; 哈该书 1:9"> 我用枯萎病、霉病和冰雹击打你们手所做的一切；可是你们仍没有转向我，’耶和华说。</span>
<span className="v" id="v18" data-v="18" data-xref="撒迦利亚书 8:9; 哈该书 2:15; 以斯拉记 5:1–2"> ‘请你们从今日往前追想，从九月二十四日，就是耶和华殿立根基的日子起，你们要追想。</span>
<span className="v" id="v19" data-v="19" data-xref="玛拉基书 3:10; 哈巴谷 3:17–18; 箴言 3:9–10"> 种子还在仓里吗？是的，葡萄树、无花果树、石榴树和橄榄树都还没有结果。从今日起，我必赐福给你们。’”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 这月二十四日，耶和华的话第二次临到哈该，说：</span>
<span className="v" id="v21" data-v="21" data-xref="撒迦利亚书 4:6–10; 哈该书 2:6–7; 哈该书 1:1"> “你要对犹大省长所罗巴伯说：‘我必震动天和地。</span>
<span className="v" id="v22" data-v="22" data-xref="弥迦书 5:10; 士师记 7:22; 西番雅书 3:8"> 我必倾覆列国的宝座；我必毁灭万国列邦的势力。我必倾覆战车和坐在车上的人。马和骑马的人都必倒下，各人倒在自己弟兄的刀下。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 43:10; 以赛亚书 42:1; 雅歌 8:6"> 到那日，万军之耶和华说，我必提取你，我仆人撒拉铁的儿子所罗巴伯，’耶和华说，‘使你像印戒，因为我拣选了你，’万军之耶和华说。”</span>
</div>

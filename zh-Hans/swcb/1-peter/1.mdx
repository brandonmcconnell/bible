<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="雅各书 1:1; 使徒行传 2:5–11; 希伯来书 11:13"> 耶稣基督的使徒彼得，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“基督”的意思是“受膏者”。">a</a></sup>写给那在本都、加拉太、加帕多家、亚细亚和庇推尼散居、作寄居者的蒙拣选的人，</span>
<span className="v" id="v2" data-v="2" data-xref="帖撒罗尼迦后书 2:13; 以弗所书 1:4–5; 希伯来书 12:24"> 就是照着父上帝的预知，借着圣灵的成圣，为要你们顺服耶稣基督，并蒙祂的血洒净的人：愿恩典与平安多多加给你们。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="彼得前书 1:23; 约翰一书 5:4; 罗马书 15:13"> 愿颂赞归于我们主耶稣基督的上帝和父！祂照着自己的大怜悯，借着耶稣基督从死人中复活，使我们重生，得着活的盼望，</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 21:27; 希伯来书 9:15; 彼得前书 5:4"> 得着不能朽坏、不能玷污、不能衰残的产业，就是为你们存留在天上的产业。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 1:6; 以弗所书 2:8; 帖撒罗尼迦后书 2:13–14"> 你们这因信心而蒙上帝能力保守的人，必得着那预备在末后的时候显明的救恩。</span>
<span className="v" id="v6" data-v="6" data-xref="雅各书 1:2; 彼得前书 5:10; 罗马书 12:12"> 因此，你们大大喜乐；不过如今若是必须，你们暂时在各种试炼中忧愁，</span>
<span className="v" id="v7" data-v="7" data-xref="约伯记 23:10; 以赛亚书 48:10; 彼得前书 4:12"> 好叫你们经过验证的信心，比那会朽坏、虽经过火炼的金子更宝贵，在耶稣基督显现的时候，可以显为可得称赞、荣耀和尊贵——</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 20:29; 哥林多后书 5:7; 罗马书 15:13"> 你们虽未曾认识祂，却爱祂；虽然如今看不见祂，却仍然信祂，并且以无法言喻、满有荣耀的喜乐大大欢喜，</span>
<span className="v" id="v9" data-v="9" data-xref="罗马书 6:22; 雅各书 1:21; 希伯来书 11:13"> 得着你们信心的结果，就是你们灵魂的救恩。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 13:17; 路加福音 10:24; 路加福音 24:25–27"> 关于这救恩，众先知寻求并仔细查考；他们预言了将临到你们的恩典，</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 52:13–14; 彼得后书 1:21; 路加福音 24:25–27"> 查考他们里面基督的灵预先证明基督要受的苦难，以及随后而来的荣耀时，所指的是谁，或是什么样的时候。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰福音 15:26; 哥林多前书 2:10; 以弗所书 3:10"> 他们蒙启示，知道他们在这些事上服事的不是自己，而是你们；这些事如今已经由那些靠着从天上差来的圣灵向你们传福音的人传给你们；这些事，天使也渴望详细察看。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="彼得前书 5:8; 路加福音 12:35; 彼得前书 4:7"> 所以，要使你们的心思准备行动。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="直译：“束上你们心思的腰”或“系上你们心思腰间的带子”。">b</a></sup>要谨醒，把你们的盼望完全寄托在耶稣基督显现时要带给你们的恩典上——</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 12:2; 提多书 3:3–5; 彼得前书 4:2–3"> 要像顺服的儿女，不要照你们从前无知时的私欲来塑造自己，</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 5:48; 哥林多后书 7:1; 希伯来书 12:14"> 却要照那召你们的圣者，在一切行为上也成为圣洁，</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 11:44; 利未记 19:2; 利未记 20:7"> 因为经上记着说：“你们要圣洁，因为我是圣洁的。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="使徒行传 10:34–35; 历代志下 19:7; 马太福音 6:9"> 你们若称那不偏待人、按各人的行为审判的为父，就当存敬畏的心，度你们在这里寄居的日子，</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多前书 6:20; 提多书 2:14; 诗篇 49:7–8"> 知道你们得以从祖宗传下来的虚妄生活方式中被赎出来，不是用银子、金子这类会朽坏之物，</span>
<span className="v" id="v19" data-v="19" data-xref="约翰一书 1:7; 彼得前书 2:22–24; 约翰福音 1:29"> 而是用基督宝贵的血，如同无瑕疵、无污点羔羊的血。</span>
<span className="v" id="v20" data-v="20" data-xref="以弗所书 1:4; 提摩太后书 1:9–10; 希伯来书 9:26"> 祂在创世以前诚然是预先被知道的，却在这末后的世代为了你们显明出来。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 2:24; 希伯来书 2:9; 约翰福音 12:44"> 你们借着祂信上帝，就是那使祂从死人中复活、又赐给祂荣耀的上帝，使你们的信心和盼望都在于上帝。</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="提摩太前书 1:5; 希伯来书 13:1; 罗马书 12:9–10"> 你们既借着圣灵，因顺服真理洁净了自己的灵魂，以致有真诚的弟兄情谊，就要从心里热切地彼此相爱。</span>
<span className="v" id="v23" data-v="23" data-xref="彼得前书 1:3; 希伯来书 4:12; 约翰福音 1:13"> 你们已经重生，不是从会朽坏的种子，而是从不会朽坏的种子，是借着上帝那活着且永远长存的道。</span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 40:6–8; 诗篇 103:15; 雅各书 4:14"> 因为：<br /><span className="pl pl-1">“凡有血肉的都像草，</span><br /><span className="pl pl-2">人的一切荣耀都像草上的花。</span><br /><span className="pl pl-1">草必枯干，花也凋落；</span></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 40:8; 马太福音 5:18; 诗篇 119:89"> <span className="pl pl-2">惟有主的道永远长存。”</span><br />这道就是传给你们的福音。</span>
</div>
</div>

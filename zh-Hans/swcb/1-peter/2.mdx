<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以弗所书 4:31; 雅各书 1:21; 雅各书 4:11"> 所以，你们要除去一切邪恶、一切诡诈、假冒为善、嫉妒和一切毁谤，</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 5:12–13; 以弗所书 4:15; 彼得后书 3:18"> 像初生的婴孩一样，渴慕那纯净的属灵奶，好使你们借着它成长，</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 34:8; 希伯来书 6:5–6; 诗篇 63:5"> 如果你们确实尝过主是恩慈的。</span>
<span className="v" id="v4" data-v="4" data-xref="诗篇 118:22–23; 使徒行传 4:11–12; 彼得前书 2:7"> 你们来到祂面前，祂是活石，固然被人弃绝，却被上帝拣选、看为宝贵。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 2:20–22; 彼得前书 2:9; 哥林多前书 3:9"> 你们也像活石，被建造成属灵的家，成为圣洁的祭司群体，借着耶稣基督献上上帝所悦纳的属灵祭物。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 28:16; 罗马书 9:32–33; 彼得前书 2:4"> 因为经上记着说：<br /><span className="pl pl-1">“看哪，</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“看哪”，源自“הִנֵּה”或“ἰδοὺ”，意思是看、留意、观察、看见或凝视。它常用作感叹词。">a</a></sup><br /><span className="pl pl-1">我在锡安安放一块房角首石，是蒙拣选、宝贵的。</span><br /><span className="pl pl-2">信靠祂的人绝不至失望。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="诗篇 118:22–23; 马可福音 12:10–11; 使徒行传 4:11–12"> 所以，这尊荣是给你们这些信的人；但对那些不顺从的人，<br /><span className="pl pl-1">“匠人所弃的石头，</span><br /><span className="pl pl-2">已成了房角的首石，”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 8:14; 哥林多前书 1:23; 罗马书 9:32–33"> 又说：<br /><span className="pl pl-1">“作绊脚的石头，作令人跌倒的磐石。”</span><br />他们因不顺从这道而绊跌；他们也正是为此被指定的。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 19:5–6; 申命记 7:6; 启示录 1:6"> 但你们是蒙拣选的族类、君尊的祭司群体、圣洁的国度、归上帝所有的子民，为要宣扬那召你们出黑暗、进入祂奇妙光明者的美善卓越。</span>
<span className="v" id="v10" data-v="10" data-xref="何西阿 2:23; 希伯来书 4:16; 何西阿 1:9–10"> 从前你们不是子民，如今却是上帝的子民；从前未蒙怜悯，如今却蒙了怜悯。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约翰一书 2:15–17; 加拉太书 5:24; 彼得前书 4:2"> 亲爱的，我劝你们，既然是寄居者和旅客，就要禁戒那与灵魂争战的肉体私欲，</span>
<span className="v" id="v12" data-v="12" data-xref="彼得前书 3:16; 马太福音 5:16; 提多书 2:7–8"> 在外邦人中品行端正，使他们虽然在某些事上毁谤你们为作恶的人，却因看见你们的好行为，就在眷顾的日子荣耀上帝。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="提多书 3:1; 罗马书 13:1–7; 提摩太前书 2:1–2"> 所以，你们为主的缘故，要顺服人的一切制度：或是君王，因他居于至高地位；</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 13:3–4"> 或是官长，因他们是由他差派，为要惩罚作恶的人，称赞行善的人。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 3:17; 提多书 2:8; 马太福音 7:26"> 因为上帝的旨意是要你们借着行善，使愚昧人的无知哑口无言。</span>
<span className="v" id="v16" data-v="16" data-xref="加拉太书 5:13; 罗马书 6:22; 罗马书 6:18"> 你们要像自由人一样生活，却不可用自由作遮盖邪恶的外衣，而要作上帝的奴仆。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="箴言 24:21; 罗马书 12:10; 罗马书 13:7"> 要尊重众人。要爱弟兄姊妹。要敬畏上帝。要尊重君王。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="提多书 2:9–10; 以弗所书 6:5–7; 歌罗西书 3:22–25"> 仆人们，你们要以完全的尊敬顺服主人；不但顺服良善温和的，也要顺服乖僻的。</span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 5:10–12; 彼得前书 3:14–17; 彼得前书 2:20"> 因为若有人因着对上帝的良心，忍受痛苦，受冤屈之苦，这是可称许的。</span>
<span className="v" id="v20" data-v="20" data-xref="彼得前书 2:19; 彼得前书 3:17; 马太福音 5:10–12"> 你们若犯罪而受责打，能忍耐，有什么可夸的呢？但你们若行善而受苦，能忍耐，这在上帝面前是可称许的。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 2:6; 马太福音 16:24; 约翰福音 13:15"> 你们蒙召原是为此，因为基督也为我们受了苦，给你们<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="公认经文读作“我们”，而不是“你们”">b</a></sup>留下榜样，使你们可以跟随祂的脚踪，</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 53:9; 哥林多后书 5:21; 希伯来书 4:15"> 祂没有犯罪，“祂口里也没有发现诡诈。”</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 53:7; 彼得前书 4:19; 希伯来书 12:3"> 祂被辱骂的时候，不还口辱骂；受苦的时候，也不威吓，倒把自己交托给那位按公义审判的。</span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 53:4–6; 马太福音 8:17; 罗马书 6:11"> 祂亲自在木头上，在自己的身体里担当了我们的罪，使我们既然向罪死了，就可以向义活着。因祂的伤痕，你们得了医治。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或译：鞭痕">c</a></sup></span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 53:6; 以西结 34:6; 路加福音 15:4–6"> 因为你们从前像羊一样走迷；但如今已经归回你们灵魂的牧人和监督。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“监督”源自希腊文 ἐπίσκοπον，可指监督、管理者、守护者或督导者。">d</a></sup></span>
</div>

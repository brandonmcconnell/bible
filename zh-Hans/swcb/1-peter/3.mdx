<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="歌罗西书 3:18; 以弗所书 5:33; 以弗所书 5:22–24"> 照样，作妻子的，要顺服自己的丈夫；这样，即使有不顺从这道的人，也可以不用言语，因妻子的品行而被赢得，</span>
<span className="v" id="v2" data-v="2" data-xref="彼得前书 2:12; 彼得前书 1:15; 腓立比书 1:27"> 因为他们看见你们在敬畏中纯洁的品行。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太前书 2:9–10; 罗马书 12:2; 以赛亚书 3:18–24"> 你们的美丽不要来自外在的装饰，就是编头发、戴金饰或穿华美衣服，</span>
<span className="v" id="v4" data-v="4" data-xref="歌罗西书 3:12; 撒母耳记上 16:7; 罗马书 2:29"> 而要来自心里隐藏的人，以温柔安静的灵为不朽坏的装饰；这在上帝眼中极为宝贵。</span>
<span className="v" id="v5" data-v="5" data-xref="提多书 2:3–4; 提摩太前书 5:5; 路加福音 2:37"> 因为古时仰望上帝的圣洁妇女，也是这样装饰自己，顺服自己的丈夫。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 18:12; 罗马书 9:7–9; 以赛亚书 57:11"> 撒拉就是这样听从亚伯拉罕，称他为主。你们若行善，又不因任何恐吓而惧怕，就成了她的儿女。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="歌罗西书 3:19; 创世记 2:23–24; 马太福音 19:3–9"> 作丈夫的，你们也要照样，按着所当有的认识与妻子共同生活；要尊重女人，如同尊重较软弱的器皿，因为她们也与你们一同承受生命的恩典；这样，你们的祷告就不至受阻。</span>
</div>
<div className="bp poetry">
<span className="v" id="v8" data-v="8" data-xref="罗马书 12:10; 以弗所书 4:31–2; 彼得前书 1:22"> 最后，你们都要同心，彼此体恤，相爱如弟兄，心存怜悯，谦恭有礼；</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 20:22; 罗马书 12:17; 罗马书 12:14"> 不要以恶报恶，以辱骂还辱骂；反要祝福，因为你们蒙召正是为此，好叫你们承受祝福。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 34:12–16; 雅各书 1:26; 彼得前书 2:1"> 因为，<br /><span className="pl pl-1">“凡愿意爱生命、</span><br /><span className="pl pl-2">看见好日子的人，</span><br /><span className="pl pl-1">要禁止舌头不出恶言，</span><br /><span className="pl pl-2">嘴唇不说诡诈。</span></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 5:9; 诗篇 34:14; 希伯来书 12:14"> <span className="pl pl-1">他要离恶行善，</span><br /><span className="pl pl-2">寻求和平，一心追求。</span></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 34:15–16; 约翰福音 9:31; 箴言 15:29"> <span className="pl pl-1">因为主的眼看顾义人，</span><br /><span className="pl pl-2">祂的耳垂听他们的祷告；</span><br /><span className="pl pl-2">但主的面敌对行恶的人。”</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 16:7; 罗马书 8:28; 帖撒罗尼迦前书 5:15"> 如果你们效法良善，谁会伤害你们呢？</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 10:28; 彼得前书 2:19–20; 马太福音 5:10–12"> 但即使你们为义受苦，也是有福的。“不要怕他们所怕的，也不要惊慌。”</span>
<span className="v" id="v15" data-v="15" data-xref="歌罗西书 4:6; 提摩太后书 2:25–26; 路加福音 21:14–15"> 只要心里尊主上帝为圣。若有人问你们心中盼望的缘由，要常常预备好，以谦卑和敬畏回答各人；</span>
<span className="v" id="v16" data-v="16" data-xref="彼得前书 2:12; 希伯来书 13:18; 彼得前书 2:15"> 要存无亏的良心。这样，当你们被人当作作恶的人毁谤时，那些辱骂你们在基督里美好品行的人就会羞愧。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前书 3:14; 彼得前书 4:19; 马太福音 26:39"> 因为，如果这是上帝的旨意，为行善受苦总比为作恶受苦更好。</span>
<span className="v" id="v18" data-v="18" data-xref="希伯来书 9:28; 希伯来书 9:26; 哥林多后书 5:21"> 因为基督也曾为罪一次受苦，义者代替不义的人，为要带你们到上帝面前；祂在肉体中被处死，却在圣灵中得以活过来，</span>
<span className="v" id="v19" data-v="19" data-xref="彼得前书 4:6; 以赛亚书 61:1; 以赛亚书 42:7"> 祂也曾在这圣灵里去向监狱里的灵宣讲，</span>
<span className="v" id="v20" data-v="20" data-xref="希伯来书 11:7; 彼得后书 2:5; 创世记 6:3"> 就是从前在挪亚的日子、方舟建造的时候，当上帝耐心等待时，那些不顺从的灵。在方舟里，少数人，就是八个人，借着水得救。</span>
<span className="v" id="v21" data-v="21" data-xref="马可福音 16:16; 以西结 36:25–26; 使徒行传 2:38"> 这水是洗礼的象征；洗礼现在也拯救你们——不是除掉肉体的污秽，而是无亏的良心向上帝的回应——这是借着耶稣基督的复活，</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 9:24; 希伯来书 12:2; 希伯来书 10:12"> 祂已经进了天，在上帝的右边；众天使、各样权柄和能力都服在祂之下。</span>

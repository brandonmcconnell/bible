<span className="v" id="v2" data-v="2" data-xref="撒迦利亚书 13:9; 以赛亚书 4:4; 哥林多前书 3:13–15"> “可是，祂来的日子，谁能承受呢？祂显现的时候，谁能站立得住呢？因为祂如炼净之人的火，又如洗衣人的碱；</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 1:25; 箴言 17:3; 撒迦利亚书 13:9"> 祂必坐下，像炼银匠洁净银子；祂必洁净利未的子孙，像炼金银一样炼净他们；他们就要凭公义向耶和华献供物。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 7:1–3; 以赛亚书 56:7; 撒迦利亚书 8:3"> 那时，犹大和耶路撒冷所献的供物，必蒙耶和华悦纳，像古时的日子，又像远古的年岁。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="雅各书 5:8–9; 希伯来书 13:4; 申命记 5:11"> 我必临近你们，施行审判。我必迅速作见证，指控行邪术的、奸淫的、起假誓的、在工价上欺压雇工的、欺压寡妇和孤儿的、使寄居者得不到公正的，以及不敬畏我的人。”万军之耶和华说。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="民数记 23:19; 希伯来书 13:8; 雅各书 1:17"> “因为我耶和华不改变；所以你们雅各的子孙没有灭亡。</span>
<span className="v" id="v7" data-v="7" data-xref="撒迦利亚书 1:3; 罗马书 10:21; 罗马书 10:3"> 从你们列祖的日子以来，你们就偏离我的典章，没有遵守。你们要归向我，我就归向你们。”万军之耶和华说。“可是你们说：‘我们该怎样归向呢？’</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="箴言 3:9–10; 马太福音 22:21; 马可福音 12:17"> 人岂可抢夺上帝呢？你们竟抢夺我！可是你们说：‘我们怎样抢夺了你呢？’就是在十分之一和供物上。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 28:15–19; 哈该书 1:6–11; 哈该书 2:14–17"> 你们受了咒诅；因为你们抢夺我，连这整个民族都是如此。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多后书 9:6–8; 马太福音 6:33; 箴言 3:9–10"> 你们要把全部十分之一送入仓库，使我殿中有粮。现在就以此试验我，”万军之耶和华说，“看我是否不为你们打开天上的窗户，把福分倾倒给你们，多到无处可容。</span>
<span className="v" id="v11" data-v="11" data-xref="申命记 11:14; 约珥 2:22; 撒迦利亚书 8:12"> 我必为你们斥责那吞噬者，它必不毁坏你们地里的果实；你们田间的葡萄树也不会在未熟之先落果。”万军之耶和华说。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 61:9; 以赛亚书 62:4; 撒迦利亚书 8:23"> “万国必称你们为有福，因为你们必成为令人喜悦之地。”万军之耶和华说。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="玛拉基书 2:17; 以赛亚书 37:23; 罗马书 9:20"> “你们用强硬的话顶撞我，”耶和华说。“可是你们说：‘我们说了什么话顶撞你呢？’</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 58:3; 西番雅书 1:12; 诗篇 73:8–13"> 你们说：‘事奉上帝是徒然的，’又说：‘我们遵守祂的吩咐，在万军之耶和华面前悲哀而行，有什么益处呢？</span>
<span className="v" id="v15" data-v="15" data-xref="玛拉基书 4:1; 耶利米书 12:1–2; 玛拉基书 2:17"> 如今我们称狂傲的人为有福；行邪恶的人反被建立起来；他们试探上帝，却得以逃脱。’”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="启示录 20:12; 诗篇 56:8; 玛拉基书 4:2"> 那时，敬畏耶和华的人彼此交谈；耶和华留心听见了。有一本纪念册在祂面前写成，记下那些敬畏耶和华、尊崇祂名的人。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 19:5; 申命记 7:6; 哥林多后书 6:18"> “在我行事的日子，他们必属我，作我自己的产业。”万军之耶和华说。“我必顾惜他们，如同人顾惜服事自己的儿子。</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 25:46; 诗篇 58:10–11; 创世记 18:25"> 那时你们必再辨明义人与恶人，事奉上帝的和不事奉祂的。”</span>
</div>

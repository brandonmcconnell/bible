<span className="v" id="v1" data-v="1" data-xref="何西阿 5:1; 玛拉基书 1:6; 耶利米书 13:13"> “现在，众祭司啊，这命令是给你们的。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 17:18; 启示录 14:7; 诗篇 69:22"> 如果你们不听，也不放在心上，把荣耀归给我的名，”万军之耶和华说，“我就使咒诅临到你们，咒诅你们的祝福。事实上，我已经咒诅了这些祝福，因为你们没有放在心上。</span>
<span className="v" id="v3" data-v="3" data-xref="那鸿书 3:6; 玛拉基书 2:9; 约伯记 20:7"> 看哪，我必斥责你们的后裔，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：种子">a</a></sup>并把粪抹在你们脸上，就是你们节期祭物的粪；你们必和它一同被带走。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 3:12; 以西结 38:23; 马太福音 3:12"> 你们就知道，我把这命令传给你们，是要使我的约可以与利未同在。”万军之耶和华说。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 25:12–13; 以西结 34:25; 以西结 37:26"> “我与他所立的是生命与平安的约；我把这些赐给他，使他敬畏我；他也敬畏我，在我的名面前存畏惧。</span>
<span className="v" id="v6" data-v="6" data-xref="但以理 12:3; 提摩太后书 2:15–16; 启示录 14:5"> 真理的律法在他口中，他嘴唇里找不到不义。他以平安和正直与我同行，使许多人离开罪孽。</span>
<span className="v" id="v7" data-v="7" data-xref="提摩太后书 2:24–25; 利未记 10:11; 申命记 21:5"> 因为祭司的嘴唇应当保守知识，人也应当从他口中寻求律法；因为他是万军之耶和华的使者。</span>
<span className="v" id="v8" data-v="8" data-xref="尼希米记 13:29; 耶利米书 18:15; 以赛亚书 30:11"> 但你们偏离了道路；你们使许多人在律法上绊跌；你们败坏了利未的约。”万军之耶和华说。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 2:30; 申命记 1:17; 马太福音 19:17–18"> “所以，我也使你们在众民面前成为可鄙而邪恶的，因为你们没有遵守我的道路，却在律法上徇私。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 100:3; 玛拉基书 2:11; 哥林多前书 8:6"> 我们岂不是都有一位父吗？岂不是一位上帝创造了我们吗？我们为什么各人以诡诈待自己的弟兄，亵渎我们列祖的约呢？</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多后书 6:14–18; 以斯拉记 9:1–2; 尼希米记 13:23–29"> 犹大行了诡诈，在以色列和耶路撒冷中行了可憎的事；因为犹大亵渎了耶和华所爱的圣洁，并娶了外邦神的女儿为妻。</span>
<span className="v" id="v12" data-v="12" data-xref="利未记 18:29; 利未记 20:3; 以西结 24:21"> 行这事的人，无论是醒着的、应答的，还是向万军之耶和华献供物的，耶和华必把他从雅各的帐棚中剪除。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 1:11–15; 耶利米书 14:12; 诗篇 78:34–37"> “你们又行这事：用眼泪、哭泣和叹息遮盖耶和华的祭坛，因为祂不再看顾供物，也不乐意从你们手中收纳。</span>
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 2:15; 传道书 9:9; 以赛亚书 54:6"> 你们还说：‘为什么呢？’因为耶和华曾在你和你幼年所娶的妻子之间作见证；你却以诡诈待她，虽然她是你的伴侣，是与你立约的妻子。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 19:4–6; 玛拉基书 2:14; 马可福音 10:6–8"> 祂岂不是使你们成为一体吗，虽然祂还有圣灵的余裕？为什么成为一体呢？祂寻求敬虔的后裔。所以你们要谨守自己的灵，不可有人以诡诈待自己幼年所娶的妻子。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 19:3–9; 马太福音 5:31–32; 马可福音 10:2–12"> 恨恶妻子并休妻的人，”以色列的上帝耶和华说，“是以强暴遮盖自己的衣裳！”万军之耶和华说。“所以你们要留意自己的灵，不可不忠。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 43:24; 彼得后书 3:3–4; 传道书 8:11"> 你们用自己的话使耶和华厌烦。你们还说：“我们怎样使祂厌烦了呢？”就是你们说：“凡行恶的，在耶和华眼中都为善，祂也喜悦他们；”或说：“公义的上帝在哪里呢？”</span>
</div>

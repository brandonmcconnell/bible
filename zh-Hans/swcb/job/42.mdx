<div className="bp poetry">
<span className="v" id="v1" data-v="1"> 于是约伯回答耶和华说：</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 19:26; 马可福音 10:27; 创世记 18:14"> <span className="pl pl-1">“我知道你万事都能做，</span><br /><span className="pl pl-2">你的旨意没有能被拦阻的。</span></span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 131:1; 诗篇 139:6; 约伯记 38:2"> <span className="pl pl-1">你问：‘这无知地遮蔽谋略的是谁？’</span><br /><span className="pl pl-2">因此我所说的，是我不明白的事，</span><br /><span className="pl pl-2">是对我太奇妙、我所不知道的事。</span></span>
<span className="v" id="v4" data-v="4" data-xref="约伯记 40:7; 约伯记 38:3; 创世记 18:30–32"> <span className="pl pl-1">你说：‘现在你听，我要说话；</span><br /><span className="pl pl-2">我要问你，你要回答我。’</span></span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 1:17–18; 罗马书 10:17; 约翰福音 12:45"> <span className="pl pl-1">我从前风闻有你，</span><br /><span className="pl pl-2">如今我的眼睛看见你。</span></span>
<span className="v" id="v6" data-v="6" data-xref="以斯拉记 9:6; 提摩太前书 1:13–16; 雅各书 4:7–10"> <span className="pl pl-1">因此我厌恶自己，</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：“因此我撤回所说的”；本节希伯来文含义较难确定。">a</a></sup><br /><span className="pl pl-2">在尘土和炉灰中悔改。”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="约伯记 11:5–6; 约伯记 32:2–3; 约伯记 32:5"> 耶和华对约伯说完这些话以后，耶和华对提幔人以利法说：“我的怒气向你和你的两个朋友发作，因为你们论到我所说的，不像我的仆人约伯说得正确。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 23:1; 雅各书 5:16; 诗篇 103:10"> 现在你们要取七头公牛、七只公绵羊，到我的仆人约伯那里去，为自己献上燔祭；我的仆人约伯要为你们祷告，我必悦纳他，不照你们的愚妄待你们。因为你们论到我所说的，不像我的仆人约伯说得正确。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="希伯来书 11:8; 使徒行传 9:6; 使徒行传 10:33"> 于是提幔人以利法、书亚人比勒达、拿玛人琐法照着耶和华吩咐他们的去行；耶和华就悦纳了约伯。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命记 30:3; 约伯记 8:6–7; 箴言 22:4"> 约伯为他的朋友祷告以后，耶和华恢复了约伯的昌盛。耶和华赐给约伯的，比他从前所有的加倍。</span>
<span className="v" id="v11" data-v="11" data-xref="约伯记 2:11; 约伯记 19:13–14; 箴言 16:7"> 于是约伯所有的弟兄、姐妹和从前认识他的人，都来到他那里，在他家里与他一同吃饭。他们为耶和华使他遭遇的一切灾祸安慰他、抚慰他。每人也给他一块银钱<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="原文为 kesitah，是一种钱币单位，可能为银子。">b</a></sup>，每人一只金环。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约伯记 8:7; 传道书 7:8; 箴言 10:22"> 这样，耶和华赐福给约伯后来的日子，胜过起初。他有一万四千只羊、六千匹骆驼、一千对牛和一千头母驴。</span>
<span className="v" id="v13" data-v="13" data-xref="约伯记 1:2; 诗篇 107:41; 诗篇 127:3"> 他也有七个儿子，三个女儿。</span>
<span className="v" id="v14" data-v="14"> 他给长女起名叫耶米玛，次女叫基洗亚，三女叫基连·哈朴。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 27:7; 诗篇 144:12; 使徒行传 7:20"> 在全地找不到像约伯的女儿那样美丽的女子。她们的父亲使她们在弟兄中得产业。</span>
<span className="v" id="v16" data-v="16" data-xref="箴言 17:6; 诗篇 128:6; 创世记 50:23"> 此后，约伯又活了一百四十年，得见他的儿子和孙子，直到四代。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 25:8; 创世记 15:15; 约伯记 5:26"> 约伯年纪老迈，日子满足而死。</span>
</div>

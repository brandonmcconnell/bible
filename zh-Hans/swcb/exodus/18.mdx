<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="EXO" data-book-slug="exodus" data-book-name="出埃及记" data-chapter="18" data-verses="27">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 2:16; 诗篇 77:14–15; 出埃及记 3:1"> 米甸的祭司、摩西的岳父叶忒罗，听见上帝为摩西和祂的子民以色列所做的一切，就是耶和华怎样把以色列从埃及领出来。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 2:21; 出埃及记 4:25–26"> 摩西的岳父叶忒罗接了摩西的妻子西坡拉，就是摩西曾送回去的；</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 2:22; 使徒行传 7:29; 诗篇 39:12"> 又接了她的两个儿子。一个儿子名叫革舜，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“革舜”的发音近似希伯来语“在那里作寄居者”。">a</a></sup>因为摩西说：“我在异地作了寄居者。”</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 13:6; 提摩太后书 4:17; 哥林多后书 1:8–10"> 另一个名叫以利以谢，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="以利以谢的意思是“上帝是我的帮助”。">b</a></sup>因为他说：“我父亲的上帝是我的帮助，救我脱离法老的刀。”</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 3:1; 出埃及记 3:12; 出埃及记 24:16–17"> 摩西的岳父叶忒罗，带着摩西的儿子和妻子，来到旷野中摩西那里，就是他在上帝的山安营的地方。</span>
<span className="v" id="v6" data-v="6"> 他对摩西说：“我，你的岳父叶忒罗，带着你的妻子和她的两个儿子，到你这里来了。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="创世记 29:13; 创世记 14:17; 撒母耳记下 11:7"> 摩西出去迎接他的岳父，向他下拜，并亲吻他。他们彼此问安，然后进了帐棚。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 145:4–12; 尼希米记 9:9–15; 诗篇 107:2"> 摩西把耶和华为以色列的缘故向法老和埃及人所做的一切，以及他们在路上遭遇的一切艰难，还有耶和华怎样拯救他们，都告诉了他的岳父。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多前书 12:26; 罗马书 12:15; 以赛亚书 66:10"> 叶忒罗因耶和华向以色列所施的一切恩惠，就是祂把他们从埃及人手中救出来，而欢喜。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 14:20; 撒母耳记下 18:28; 路加福音 1:68"> 叶忒罗说：“耶和华是应当称颂的！祂把你们从埃及人手中和法老手中救出来；祂把这百姓从埃及人手下救出来。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 95:3; 出埃及记 15:11; 历代志下 2:5"> 如今我知道，耶和华比万神都大，因为从埃及人狂傲对待这百姓的事上，就可以看出。”</span>
<span className="v" id="v12" data-v="12" data-xref="创世记 31:54; 申命记 12:7; 出埃及记 24:11"> 摩西的岳父叶忒罗拿来燔祭和祭物献给上帝。亚伦和以色列所有长老都来了，在上帝面前与摩西的岳父一同吃饭。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 16:5; 约伯记 29:7; 士师记 5:10"> 第二天，摩西坐着审断百姓，百姓从早到晚都站在摩西周围。</span>
<span className="v" id="v14" data-v="14"> 摩西的岳父看见他为百姓所做的一切，就说：“你为百姓做的这是什么事呢？你为什么独自坐着，众百姓从早到晚都站在你周围？”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="民数记 15:34; 民数记 27:5; 民数记 9:8"> 摩西对他的岳父说：“因为百姓到我这里来求问上帝。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 24:14; 哥林多前书 6:1; 撒母耳记下 15:3"> 他们有案件的时候，就到我这里来；我便在人与邻舍之间审断，并使他们知道上帝的律例和祂的律法。”</span>
<span className="v" id="v17" data-v="17"> 摩西的岳父对他说：“你这样做不好。</span>
<span className="v" id="v18" data-v="18" data-xref="民数记 11:14–17; 使徒行传 6:1–4; 哥林多后书 12:15"> 你和与你同在的这百姓必定都会疲惫不堪，因为这事对你太重，你一个人独自办理不了。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 27:5; 申命记 5:5; 出埃及记 20:19"> 现在你要听我的话。我给你出个主意，愿上帝与你同在。你要在上帝面前代表百姓，把案件带到上帝面前。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 5:1; 诗篇 143:8; 申命记 1:18"> 你要教导他们律例和律法，指示他们当行的路、当做的事。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 6:3; 申命记 1:13–17; 历代志下 19:5–10"> 此外，你要从众百姓中选出有才能、敬畏上帝、诚实、恨恶不义之财的人，派他们管理百姓，作千夫长、百夫长、五十夫长、十夫长。</span>
<span className="v" id="v22" data-v="22" data-xref="民数记 11:17; 民数记 27:2; 民数记 15:33"> 让他们随时审断百姓。凡重大的案件，他们都要带到你这里；凡小案件，他们自己审断。这样，你就轻省些，他们也可以与你同担这担子。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 8:6–7; 出埃及记 18:18; 撒母耳记上 8:22"> 如果你这样做，而且上帝也这样吩咐你，那么你就能承受得住，这全体百姓也都能平安地回到自己的地方。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="以斯拉记 10:2; 出埃及记 18:19; 出埃及记 18:2–5"> 于是摩西听从他岳父的话，照他所说的一切去做。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 1:15; 出埃及记 18:21; 使徒行传 6:5"> 摩西从全以色列中选出有才能的人，立他们作百姓的首领，作千夫长、百夫长、五十夫长、十夫长。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 18:22; 出埃及记 18:14–15; 申命记 17:8"> 他们随时审断百姓；难办的案件就带到摩西那里，凡小案件他们自己审断。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 10:29–30; 士师记 19:9; 创世记 31:55"> 摩西让他的岳父离去，他就回自己的地方去了。</span>
</div>
</div>

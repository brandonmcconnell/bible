<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 28:3; 出埃及记 35:30–35; 出埃及记 31:1–6"> “比撒列、亚何利亚伯，以及凡心里有智慧的人，就是耶和华把智慧和聪明放在他们里面、使他们知道怎样做圣所事奉一切工作的人，都要照耶和华所吩咐的一切去做。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="歌罗西书 4:17; 希伯来书 5:4; 出埃及记 31:6"> 摩西召了比撒列、亚何利亚伯，以及凡心里有智慧的人，就是耶和华把智慧放在他心里，又凡心里受感动前来做这工的人。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 35:29; 出埃及记 35:27; 出埃及记 35:5–21"> 他们从摩西那里领受以色列人带来、为圣所事奉的工作而用来制作的一切奉献。百姓每天早晨仍然把甘心奉献的礼物带来给他。</span>
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 3:10; 路加福音 12:42; 马太福音 24:45"> 凡做圣所一切工作的智慧人，各自从自己所做的工作那里来，</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 31:6–10; 哥林多后书 8:2–3; 历代志下 24:14"> 对摩西说：“百姓带来的，比耶和华吩咐要做的工作所需的还多，已经绰绰有余。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6"> 摩西下令，他们就在全营中宣告说：“无论男女，都不可再为圣所的奉献制作什么。”于是百姓就被制止，不再带来。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 31:10"> 因为他们已有的材料足够做一切工作，而且有余。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="列王纪上 6:23; 出埃及记 26:1–37; 以西结 1:5–28"> 做工的人中，凡心里有智慧的，都用十幅幔子做帐幕；这些幔子是用捻的细麻，蓝色、紫色、朱红色线做的。他们用巧匠的工艺，在上面绣上基路伯。</span>
<span className="v" id="v9" data-v="9"> 每幅幔子长二十八肘，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘是人手臂从中指尖到肘部的长度，约十八英寸或四十六厘米。">a</a></sup>宽四肘；所有幔子都是同一尺寸。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 12:27; 出埃及记 26:3; 诗篇 122:3"> 他把五幅幔子彼此相连，又把另外五幅幔子彼此相连。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 26:4"> 他在一组相连处最边上一幅幔子的边缘做蓝色的钮环；在第二组相连处最外边那幅幔子的边缘也照样做。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 26:5; 出埃及记 26:10"> 他在一幅幔子上做五十个钮环，又在第二组相连处那幅幔子的边缘做五十个钮环；这些钮环彼此相对。</span>
<span className="v" id="v13" data-v="13" data-xref="彼得前书 2:4–5; 以弗所书 2:20–22; 哥林多前书 12:20"> 他又做五十个金钩，用钩子把幔子彼此相连；这样，帐幕就成为一个整体。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及记 26:7–13"> 他用山羊毛做幔子，作为帐幕以上的罩棚；他做了十一幅。</span>
<span className="v" id="v15" data-v="15"> 每幅幔子长三十肘，每幅幔子宽四肘；十一幅幔子都是同一尺寸。</span>
<span className="v" id="v16" data-v="16"> 他把五幅幔子连成一组，又把六幅幔子连成一组。</span>
<span className="v" id="v17" data-v="17"> 他在一组相连处最外边那幅幔子的边缘做五十个钮环，又在第二组相连处最外边那幅幔子的边缘做五十个钮环。</span>
<span className="v" id="v18" data-v="18"> 他又做五十个铜钩，把帐棚连在一起，使它成为一个整体。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 26:14"> 他又为帐棚做一个盖，是染红的公羊皮，又在上面做一个海牛皮的盖。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 25:5; 民数记 25:1; 出埃及记 40:18–19"> 他用皂荚木为帐幕做竖立的板。</span>
<span className="v" id="v21" data-v="21"> 每块板长十肘，每块板宽一肘半。</span>
<span className="v" id="v22" data-v="22"> 每块板有两个榫头，彼此相接；他为帐幕所有的板都是这样做。</span>
<span className="v" id="v23" data-v="23"> 他为帐幕做板：南面向南的一侧二十块板。</span>
<span className="v" id="v24" data-v="24"> 他在这二十块板底下做四十个银座：这一块板底下有两个座，安放它的两个榫头；另一块板底下也有两个座，安放它的两个榫头。</span>
<span className="v" id="v25" data-v="25"> 帐幕的第二面，就是北面，他做二十块板，</span>
<span className="v" id="v26" data-v="26"> 和四十个银座：这一块板底下两个座，另一块板底下两个座。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 26:22; 出埃及记 26:27"> 帐幕的后面，就是西面，他做六块板。</span>
<span className="v" id="v28" data-v="28"> 他又为帐幕后面的两个角做两块板。</span>
<span className="v" id="v29" data-v="29" data-xref="使徒行传 4:32; 以弗所书 3:18–19; 哥林多前书 1:10"> 这些板下端是双的，并且直到顶端都一样，接到第一个环；在两个角上的两块板，他都是这样做。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 26:25"> 共有八块板和它们的银座，十六个座——每块板底下两个座。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及记 26:26–29; 出埃及记 25:28; 出埃及记 30:5"> 他用皂荚木做横闩：为帐幕这一面的板做五根，</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 26:26"> 为帐幕另一面的板做五根，又为帐幕西面后边的板做五根横闩。</span>
<span className="v" id="v33" data-v="33"> 他使中间的横闩从板的中央穿过，从这一端到那一端。</span>
<span className="v" id="v34" data-v="34"> 他把板包上金子，又做金环作为横闩穿过的地方，并把横闩包上金子。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 27:51; 希伯来书 10:20; 出埃及记 40:21"> 他用蓝色、紫色、朱红色线和捻的细麻做幔子，上面有基路伯；他用巧匠的工艺做成。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 1:18"> 他为幔子做四根皂荚木柱子，包上金子；柱子的钩子是金的。他又为柱子铸了四个银座。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及记 26:36–37; 出埃及记 40:28"> 他为帐棚的门做帘子，是用蓝色、紫色、朱红色线和捻的细麻做的，是绣花匠的工艺；</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及记 27:10"> 又做帘子的五根柱子和柱子的钩子。他把柱顶和柱箍包上金子；五个座是铜的。</span>
</div>
</div>

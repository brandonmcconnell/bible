<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 4:21; 出埃及记 7:13–14; 出埃及记 3:20"> 耶和华对摩西说：“你进去见法老，因为我使他的心和他臣仆的心刚硬，好让我在他们中间显出我这些神迹；</span>
<span className="v" id="v2" data-v="2" data-xref="约珥 1:3; 申命记 4:9; 申命记 6:20–22"> 也好让你在你儿子和你孙子耳中述说，我怎样对待埃及人，以及我在他们中间所行的神迹；使你们知道我是耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="彼得前书 5:6; 列王纪上 21:29; 雅各书 4:10"> 摩西和亚伦进去见法老，对他说：“耶和华——希伯来人的上帝这样说：‘你拒绝在我面前谦卑自己，要到几时呢？让我的子民走，好事奉我。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 9:3; 约珥 2:25; 出埃及记 11:4–5"> 不然，你若拒绝让我的子民走，看哪，明天我必使蝗虫进入你的国境，</span>
<span className="v" id="v5" data-v="5" data-xref="约珥 1:4; 出埃及记 9:32; 约珥 2:25"> 它们要遮满地面，甚至人不能看见地。它们要吃尽冰雹之后给你们剩下、逃过灾害的余物，也要吃尽田间为你们生长的一切树木。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 8:21; 出埃及记 8:3; 出埃及记 11:6"> 你的宫殿、你所有臣仆的房屋，以及所有埃及人的房屋，都要被蝗虫充满；这是自从你祖先和你祖先的祖先在地上以来，直到今日，从未见过的。’”摩西转身，离开法老出去了。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 18:21; 出埃及记 23:33; 约书亚记 23:13"> 法老的臣仆对他说：“这人作我们的网罗要到几时呢？让这些人去事奉耶和华——他们的上帝吧。你还不知道埃及已经毁了吗？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 10:24; 出埃及记 12:31; 出埃及记 8:8"> 摩西和亚伦又被带到法老那里；法老对他们说：“去事奉耶和华你们的上帝吧；但要去的是哪些人？”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 5:1; 哥林多前书 5:7–8; 申命记 31:12–13"> 摩西说：“我们要带着年轻的和年老的同去；我们要带着儿子和女儿，带着羊群和牛群同去，因为我们必须向耶和华守节。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及记 13:21; 历代志下 32:15; 出埃及记 12:30–31"> 法老对他们说：“如果我让你们和你们的小孩同去，愿耶和华与你们同在吧！看哪，灾祸明明在你们面前。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 10:28; 诗篇 119:69; 出埃及记 5:4"> 不行！你们壮年男子去事奉耶和华吧，因为这才是你们所求的！”于是他们被赶出法老面前。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及记 7:19; 出埃及记 10:4–5"> 耶和华对摩西说：“你向埃及地伸出你的手，使蝗虫上到埃及地来，吃尽地上的一切菜蔬，就是冰雹所留下的一切。”</span>
<span className="v" id="v13" data-v="13" data-xref="约拿 1:4; 诗篇 78:26; 诗篇 148:8"> 摩西就向埃及地伸出他的杖；耶和华使东风刮在那地上一整天、一整夜；到了早晨，东风把蝗虫带来了。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 78:46; 约珥 1:2–4; 诗篇 105:34–35"> 蝗虫上到埃及全地，停在埃及四境；灾情极其严重。在它们以前没有这样的蝗虫，在它们以后也不会再有。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 10:5; 诗篇 78:46; 约珥 1:6–7"> 因为它们遮满了全地的表面，以致那地变黑了；它们吃尽地上一切菜蔬和冰雹所留下的树上一切果子。埃及全地，无论是树木还是田间的菜蔬，一点绿色也没有剩下。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 9:27; 撒母耳记下 19:20; 撒母耳记上 15:30"> 于是法老急忙召摩西和亚伦来，说：“我得罪了耶和华你们的上帝，也得罪了你们。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 8:8; 出埃及记 9:28; 列王纪上 13:6"> 现在请你再一次赦免我的罪，并祈求耶和华你们的上帝，也从我这里挪去这死亡之灾。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 6:28; 出埃及记 8:28–30; 出埃及记 8:9"> 摩西离开法老出去，祈求耶和华。</span>
<span className="v" id="v19" data-v="19" data-xref="约珥 2:20; 出埃及记 13:18; 出埃及记 15:4"> 耶和华使极强的西风刮起，把蝗虫卷走，吹入红海。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“红海”是希伯来语“Yam Suf”的译法；更直译可译为“芦苇海”或“香蒲海”。它指现在称为红海的水域，或可能指与红海相连或邻近的某个水域。">a</a></sup>在埃及四境连一只蝗虫也没有剩下。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 4:21; 出埃及记 11:10; 申命记 2:30"> 但耶和华使法老的心刚硬，他就不让以色列子孙走。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="启示录 16:10–11; 犹大书 1:6; 路加福音 23:44"> 耶和华对摩西说：“你向天空伸出你的手，使埃及地上有黑暗，是可以摸得着的黑暗。”</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 105:28; 启示录 16:10; 出埃及记 20:21"> 摩西向天空伸出他的手，埃及全地就有浓密的黑暗三天。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 8:22; 以赛亚书 42:16; 彼得前书 2:9"> 三天之久，他们彼此看不见，也没有人从自己的地方起来；但所有以色列子孙的住处都有光。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出埃及记 10:8–10; 出埃及记 8:28; 创世记 34:23"> 法老召摩西来，说：“去事奉耶和华吧。只是你们的羊群和牛群要留下；你们的小孩也可以和你们同去。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="利未记 9:22; 利未记 16:9; 出埃及记 29:1–46"> 摩西说：“你也必须把祭牲和燔祭牲交在我们手里，好让我们献给耶和华我们的上帝。</span>
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 23:18; 使徒行传 2:44–45; 箴言 3:9"> 我们的牲畜也要和我们同去；连一个蹄子也不可留下，因为我们必须从其中取一些来事奉耶和华我们的上帝；而且我们还不知道要用什么事奉耶和华，直到我们到了那里才知道。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="出埃及记 10:20; 出埃及记 4:21; 出埃及记 14:8"> 但耶和华使法老的心刚硬，他不愿让他们走。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 25:16; 历代志下 16:10; 阿摩司 7:13"> 法老对他说：“离开我！你要小心，不可再见我的面；因为你见我面的那一天，你必死！”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="希伯来书 11:27; 出埃及记 12:30–31; 出埃及记 11:4–8"> 摩西说：“你说得好。我必不再见你的面。”</span>
</div>
</div>

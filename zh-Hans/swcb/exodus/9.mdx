<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 8:1; 出埃及记 10:3; 出埃及记 8:20"> 耶和华对摩西说：“你进去见法老，对他说：『耶和华——希伯来人的上帝——这样说：“让我的百姓走，好让他们事奉我。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 8:2; 出埃及记 4:23; 利未记 26:27–28"> 因为如果你拒绝让他们走，仍然扣留他们，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 7:4; 使徒行传 13:11; 撒母耳记上 6:9"> 看哪，耶和华的手要临到你田间的牲畜，就是临到马、驴、骆驼、牛群和羊群，降下极重的瘟疫。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 8:22; 出埃及记 10:23; 玛拉基书 3:18"> 耶和华要把以色列的牲畜和埃及的牲畜分别出来；以色列子孙所有的，一样也不会死。”』”</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 8:23; 出埃及记 10:4; 耶利米书 28:16–17"> 耶和华定了一个期限，说：“明天耶和华必在这地行这事。”</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 78:48; 出埃及记 9:25; 诗篇 78:50"> 第二天，耶和华行了这事；埃及所有的牲畜都死了，但以色列子孙的牲畜，一头也没有死。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 7:14; 出埃及记 8:32; 以赛亚书 48:4"> 法老派人去看，看哪，以色列人的牲畜连一头也没有死。可是法老的心顽梗，不让百姓走。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 8:16"> 耶和华对摩西和亚伦说：“你们取满手的炉灰，让摩西当着法老的眼前向天扬起来。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 16:2; 申命记 28:27; 约伯记 2:7"> 它要在埃及全地变成细尘，在埃及全地的人和牲畜身上成为发作的疮和水泡。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命记 28:27"> 他们取了炉灰，站在法老面前；摩西向天扬起来，就在人和牲畜身上成为发作的疮和水泡。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 7:11–12; 出埃及记 8:18–19; 启示录 16:2"> 术士因这些疮不能站在摩西面前，因为疮在术士和所有埃及人身上。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 4:21; 出埃及记 7:13–14; 诗篇 81:11–12"> 耶和华使法老的心刚硬，他就不听他们，正如耶和华对摩西所说的。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="出埃及记 8:20; 出埃及记 7:15; 出埃及记 9:1"> 耶和华对摩西说：“你清早起来，站在法老面前，对他说：『耶和华——希伯来人的上帝——这样说：“让我的百姓走，好让他们事奉我。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 8:10; 利未记 26:28; 历代志上 17:20"> 因为这一次，我要把我所有的灾祸都降在你本人、你的臣仆和你的百姓身上，使你知道普天下没有谁像我。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 3:20; 出埃及记 9:3; 出埃及记 9:16"> 因为现在我若伸出我的手，用瘟疫击打你和你的百姓，你们就会从地上被剪除；</span>
<span className="v" id="v16" data-v="16" data-xref="罗马书 9:17; 箴言 16:4; 诗篇 83:17–18"> 然而，正是为这个缘故，我使你存立：为要向你显明我的能力，使我的名传遍全地。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 37:29; 以赛亚书 10:15; 以赛亚书 37:23–24"> 你仍然高抬自己，敌对我的百姓，不肯让他们走。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪上 20:6; 诗篇 83:15; 出埃及记 9:22–25"> 看哪，明天大约这时候，我要降下极重的冰雹；自埃及立国之日直到如今，从来没有这样的冰雹。</span>
<span className="v" id="v19" data-v="19" data-xref="哈巴谷 3:2"> 现在，你要吩咐人把你的牲畜和你田间所有的一切都收进遮蔽处。凡在田间被发现、没有带回家的，无论是人是牲畜，冰雹都要落在他们身上，他们必死。”』”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="箴言 13:13; 箴言 22:3; 希伯来书 11:7"> 法老的臣仆中惧怕耶和华话语的人，就使他们的仆人和牲畜逃进屋里。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结 40:4; 约伯记 34:14; 历代志上 22:19"> 但不把耶和华的话放在心上的，就把他的仆人和牲畜留在田间。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="启示录 16:21; 出埃及记 7:19; 出埃及记 8:5"> 耶和华对摩西说：“你向天伸手，使埃及全地有冰雹，落在人、牲畜和田间各样的植物上，遍及埃及地。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="诗篇 18:13; 约书亚记 10:11; 以赛亚书 30:30"> 摩西向天伸出他的杖，耶和华就降下雷声和冰雹；闪电直闪到地上。耶和华使冰雹降在埃及地。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 9:23; 马太福音 24:21; 出埃及记 10:6"> 于是有极其严重的冰雹，冰雹中夹杂着闪电；自埃及成为一国以来，埃及全地从来没有这样的冰雹。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 78:47; 诗篇 105:32–33"> 在埃及全地，冰雹击打了田间所有的一切，无论是人是牲畜；冰雹击打了田间各样的植物，又打断了田间各样的树木。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 11:7; 出埃及记 9:4; 出埃及记 10:23"> 只有在以色列子孙所在的歌珊地没有冰雹。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="耶利米哀歌 1:18; 诗篇 129:4; 出埃及记 10:16"> 法老派人召摩西和亚伦来，对他们说：“这一次我犯了罪。耶和华是公义的，我和我的百姓是邪恶的。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 8:8; 出埃及记 10:17; 出埃及记 8:28"> 请你们祈求耶和华，因为这大雷声和冰雹已经够了。我会让你们走，你们不必再留下了。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="哥林多前书 10:26; 列王纪上 8:38; 以赛亚书 1:15"> 摩西对他说：“我一出城，就要向耶和华伸开双手。雷声必停止，也不再有冰雹，使你知道大地是耶和华的。</span>
<span className="v" id="v30" data-v="30" data-xref="以赛亚书 26:10; 箴言 16:6; 以赛亚书 63:17"> 至于你和你的臣仆，我知道你们还不惧怕耶和华上帝。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="路得记 1:22; 路得记 2:23; 哈巴谷 3:17"> 亚麻和大麦被击坏了，因为大麦已经成熟，亚麻正在开花。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 10:22"> 但是小麦和粗麦没有被击坏，因为它们还没有长成。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 9:29; 出埃及记 8:12; 雅各书 5:17–18"> 摩西离开法老出城，向耶和华伸开双手；雷声和冰雹就停止了，雨也不再倾倒在地上。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 7:14; 历代志下 36:13; 出埃及记 4:21"> 法老见雨、冰雹和雷声都停止了，就越发犯罪；他和他的臣仆都硬着心。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及记 4:21"> 法老的心刚硬，不让以色列子孙走，正如耶和华借着摩西所说的。</span>
</div>
</div>

</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="箴言 1:10–11; 箴言 1:15; 路加福音 23:23–24"> “不可随从众人作恶；不可在诉讼中作见证，随从多数来歪曲公正。</span>
<span className="v" id="v3" data-v="3" data-xref="雅各书 3:17; 利未记 19:15; 诗篇 82:2–3"> 在穷人的诉讼中，也不可偏袒他。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="申命记 22:1–4; 帖撒罗尼迦前书 5:15; 马太福音 5:44"> “如果你遇见仇敌的牛或驴迷了路，总要把它牵回来还给他。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 22:4"> 如果你看见恨你的人的驴伏在重担之下，不可撇下他不管；总要帮助他卸下重担。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="玛拉基书 3:5; 耶利米书 5:28; 利未记 19:15"> “不可在穷人的诉讼中屈枉他们的公正。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以弗所书 4:25; 出埃及记 34:7; 出埃及记 23:1"> “要远离虚假的控告；不可杀害无辜和义人，因为我必不称恶人为义。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="申命记 16:19; 箴言 17:23; 以赛亚书 5:23"> “不可收受贿赂，因为贿赂能使明眼人眼瞎，又歪曲义人的话。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="申命记 27:19; 出埃及记 22:21; 申命记 24:14–18"> “不可欺压寄居者，因为你们知道寄居者的心情，因为你们在埃及地也作过寄居者。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未记 25:3–4"> “六年你要耕种你的地，收取地的出产；</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 26:34–35; 利未记 25:2–7; 利未记 25:11–12"> 但第七年要让地休耕闲置，使你民中的穷人可以吃；他们所剩下的，野地的走兽可以吃。你的葡萄园和橄榄园也要照样办理。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="路加福音 13:14; 出埃及记 34:21; 出埃及记 35:3"> “六天你要做你的工，第七天要安息，好使你的牛和驴可以休息，你婢女的儿子和寄居者也可以恢复精神。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约书亚记 23:7; 撒迦利亚书 13:2; 提摩太前书 4:16"> “我对你们所说的一切事，你们都要谨慎遵行；不可呼求别神的名，也不可让它们的名从你口中被人听见。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="申命记 16:16; 出埃及记 34:22–24; 利未记 23:34"> “你一年要三次向我守节。</span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 22:7; 出埃及记 34:20; 民数记 28:16–25"> 你要守无酵节。照我所吩咐你的，在亚笔月所定的时候，要吃无酵饼七天，因为你是在这月从埃及出来的；谁也不可空手朝见我。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 34:22; 出埃及记 22:29; 利未记 23:9–21"> 又要守收割节，就是你在田间所撒种、劳作所得的初熟果子；并在年底从田间收聚你劳作所得的时候，守收藏节。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 16:16; 出埃及记 34:23; 出埃及记 23:14"> 一年三次，你所有的男丁都要朝见主耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 34:25; 利未记 2:11; 申命记 16:4"> “不可把我祭物的血同有酵饼一起献上。我节期祭物的脂肪不可留到早晨。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及记 34:26; 申命记 14:21; 申命记 26:10"> 你要把你土地上初熟之物中最初熟的带到耶和华你上帝的殿中。<br />“不可用母山羊的奶煮小山羊。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 33:14; 诗篇 91:11; 出埃及记 32:34"> “看哪，我差遣一位使者在你前面，在路上保护你，领你到我所预备的地方。</span>
<span className="v" id="v21" data-v="21" data-xref="诗篇 78:56; 诗篇 78:40; 希伯来书 12:25"> 你要留心听从他，听他的声音。不可惹他发怒，因为他不会赦免你们的悖逆，因为我的名在他里面。</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 12:3; 申命记 30:7; 撒迦利亚书 2:8"> 但你若确实听他的声音，遵行我所说的一切，我就要作你仇敌的仇敌，作你敌人的敌人。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 23:20; 以赛亚书 5:13; 创世记 15:19–21"> 因为我的使者要走在你前面，领你到亚摩利人、赫人、比利洗人、迦南人、希未人、耶布斯人那里；我必剪除他们。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 20:5; 申命记 12:30–31; 民数记 33:52"> 不可向他们的神下拜，也不可事奉它们，也不可照他们的做法去行；却要彻底推翻它们，打碎他们的柱像。</span>
<span className="v" id="v25" data-v="25" data-xref="申命记 7:15; 出埃及记 15:26; 约书亚记 22:5"> 你们要事奉耶和华你们的上帝，祂必赐福给你的粮和你的水；我也必从你们中间除去疾病。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 7:14; 约伯记 5:26; 申命记 28:4"> 在你的地上，必没有流产的，也没有不能生育的。我要使你日子的数目满足。</span>
<span className="v" id="v27" data-v="27" data-xref="申命记 2:25; 创世记 35:5; 申命记 11:25"> 我必使我的惊恐行在你前面，使你所到之处的万民都陷入混乱；我必使你所有的仇敌在你面前转背逃跑。</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 7:20; 约书亚记 24:11–12"> 我要差遣黄蜂在你前面，把希未人、迦南人和赫人从你面前赶出去。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 7:22; 约书亚记 17:12–13; 士师记 3:1–4"> 我不会在一年之内把他们从你面前赶出去，免得这地荒凉，野地的走兽增多来害你。</span>
<span className="v" id="v30" data-v="30"> 我要渐渐地把他们从你面前赶出去，直到你人数增多，承受这地为产业。</span>
<span className="v" id="v31" data-v="31" data-xref="创世记 15:18; 申命记 11:24; 约书亚记 21:44"> 我要设定你的边界，从红海直到非利士人的海，又从旷野直到大河；因为我要把这地的居民交在你手中，你要把他们从你面前赶出去。</span>
<span className="v" id="v32" data-v="32" data-xref="申命记 7:2; 出埃及记 34:12; 出埃及记 34:15"> 不可与他们立约，也不可与他们的神立约。</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 106:36; 申命记 7:16; 出埃及记 34:12"> 他们不可住在你的地上，免得他们使你得罪我；因为你若事奉他们的神，这必成为你的网罗。”</span>
</div>

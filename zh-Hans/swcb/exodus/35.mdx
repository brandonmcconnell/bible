<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 34:32; 出埃及记 31:1–11; 罗马书 2:13"> 摩西召集以色列子孙全会众，对他们说：“这些是耶和华吩咐你们要遵行的话。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 23:3; 路加福音 13:14–15; 出埃及记 20:9–10"> 『六日要做工，但第七日要成为你们的圣日，是向耶和华守的安息日，作为庄严安息的日子；凡在这日做任何工的，必须被处死。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 16:23; 民数记 15:32–36; 出埃及记 12:16"> 在安息日，你们一切住处都不可生火。』”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及记 25:1–2"> 摩西对以色列子孙全会众说：“这是耶和华所吩咐的话，说：</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 9:7; 诗篇 110:3; 出埃及记 25:2–7"> 『你们要从自己中间拿礼物献给耶和华；凡心里甘愿的，都可以把它带来，作为献给耶和华的礼物：金、银、铜，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 26:7–14; 出埃及记 26:31; 出埃及记 28:15"> 蓝色、紫色、朱红色线，细麻，山羊毛，</span>
<span className="v" id="v7" data-v="7"> 染红的公羊皮，海牛皮，皂荚木，</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 27:20; 出埃及记 25:1–40; 出埃及记 30:23"> 点灯的油，做膏油和芬芳香料用的香料，</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 39:6–14; 出埃及记 28:9; 出埃及记 25:5"> 红玛瑙，以及镶嵌在以弗得和胸牌上的宝石。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及记 31:1–6; 出埃及记 36:1–4"> 『你们中间凡心里有智慧的人，都要来做耶和华所吩咐的一切：</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 26:1–37; 出埃及记 36:8–34; 出埃及记 31:7–9"> 帐幕、它的外罩、顶盖、钩子、板、闩、柱子和座；</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 25:10–22; 出埃及记 26:31–33; 出埃及记 37:1–9"> 约柜和它的杠、施恩座、遮掩的帘子；</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 25:23–30; 利未记 24:5–6; 出埃及记 37:10–16"> 桌子和它的杠，以及它的一切器具和陈设饼；</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 25:31–39; 马太福音 5:14–15; 出埃及记 37:17–24"> 点灯用的灯台和它的器具、灯盏，以及点灯的油；</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 30:1–10; 出埃及记 30:22–38; 出埃及记 37:25–28"> 香坛和它的杠，膏油，芬芳的香，门帘，就是帐幕门口的帘子；</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 27:1–8; 出埃及记 30:18–21; 出埃及记 38:1–8"> 燔祭坛和它的铜网、杠，以及它的一切器具，洗濯盆和盆座；</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 7:2; 出埃及记 38:9–20; 出埃及记 27:9–19"> 院子的帷幔、柱子和柱座，以及院门的门帘；</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 27:19"> 帐幕的橛子、院子的橛子和它们的绳子；</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 31:10; 民数记 4:5–15; 出埃及记 28:1–43"> 供在圣所事奉用的精工衣服，就是祭司亚伦的圣衣，以及他儿子们作祭司事奉用的衣服。』”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20"> 以色列子孙全会众从摩西面前离开。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 25:2; 出埃及记 35:26; 历代志上 29:14"> 凡心受感动、灵里甘愿的人都来，为会幕的工程、其中一切事奉，以及圣衣，把礼物献给耶和华。</span>
<span className="v" id="v22" data-v="22" data-xref="尼希米记 7:70–72; 马太福音 2:11; 以斯拉记 2:68–69"> 凡心里甘愿的，男男女女都来，带来了胸针、耳环、印戒、手镯，各样金饰；凡把金子作为礼物献给耶和华的人也是如此。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 29:8; 出埃及记 25:2–7; 出埃及记 35:6–10"> 凡有蓝色、紫色、朱红色线，细麻，山羊毛，染红的公羊皮，海牛皮的人，都带了来。</span>
<span className="v" id="v24" data-v="24" data-xref="哥林多后书 8:12"> 凡献银和铜作礼物的，都把礼物带来献给耶和华；凡有皂荚木可供任何事奉工程使用的，也都带了来。</span>
<span className="v" id="v25" data-v="25" data-xref="罗马书 16:12; 路加福音 8:2–3; 箴言 14:1"> 凡心里有智慧的妇女都亲手纺线，把所纺的带来，就是蓝色、紫色、朱红色线和细麻。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 35:21; 出埃及记 36:8; 出埃及记 35:29"> 凡心受感动、有智慧的妇女都纺山羊毛。</span>
<span className="v" id="v27" data-v="27" data-xref="以斯拉记 2:68; 历代志上 29:6; 出埃及记 35:9"> 众首领把红玛瑙和要镶嵌在以弗得与胸牌上的宝石带来；</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 30:23–38; 出埃及记 35:8"> 又带来香料和油，供点灯、做膏油和芬芳的香使用。</span>
<span className="v" id="v29" data-v="29" data-xref="哥林多后书 9:7; 出埃及记 35:21–22; 出埃及记 35:4"> 以色列子孙，无论男女，凡心里甘愿为耶和华借摩西吩咐要做的一切工带来礼物的，都把甘心供物献给耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及记 31:1–6; 雅各书 1:17; 哥林多前书 12:11"> 摩西对以色列子孙说：“看哪，耶和华已经按名召了犹大支派中户珥的孙子、乌利的儿子比撒列。</span>
<span className="v" id="v31" data-v="31" data-xref="雅各书 1:17; 以赛亚书 11:2–5; 以赛亚书 61:1–3"> 祂以圣灵充满他，使他有智慧、悟性、知识，能做各样工艺，</span>
<span className="v" id="v32" data-v="32"> 能设计巧工，用金、银、铜制作，</span>
<span className="v" id="v33" data-v="33"> 能雕刻宝石以便镶嵌，也能雕刻木头，做各样精巧的工艺。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 31:6; 历代志下 2:14; 以斯拉记 7:27"> 祂又把教导人的能力放在他心里，也放在但支派中亚希撒抹的儿子亚何利亚伯心里。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及记 35:31; 列王纪上 7:14; 以赛亚书 28:26"> 祂使他们心里充满智慧，能做各样工艺，就是雕刻匠、巧匠、用蓝色、紫色、朱红色线和细麻刺绣者，以及织布者的工；他们能做各样工艺，也能设计巧工。</span>
</div>

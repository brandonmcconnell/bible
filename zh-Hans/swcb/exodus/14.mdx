<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 12:1; 出埃及记 13:1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 33:7–8; 耶利米书 44:1; 出埃及记 13:17–18"> “你要吩咐以色列人转回，在比哈希录前，密夺和海之间，巴力洗分前安营；你们要在它对面，靠海安营。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 4:28; 撒母耳记上 23:23; 诗篇 71:11"> 法老必论到以色列人说：‘他们在这地绕迷了；旷野把他们困住了。’</span>
<span className="v" id="v4" data-v="4" data-xref="罗马书 9:22–23; 出埃及记 7:5; 罗马书 9:17"> 我要使法老的心刚硬，他就会追赶他们；我要在法老和他的全军身上得荣耀；埃及人就知道我是耶和华。”他们就这样做了。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="诗篇 105:25; 出埃及记 12:33; 路加福音 11:24–26"> 有人告诉埃及王，百姓逃走了；法老和他臣仆的心就转而敌对这百姓，他们说：“我们这是做了什么，竟让以色列人离开，不再服侍我们？”</span>
<span className="v" id="v6" data-v="6"> 法老预备他的战车，带着他的军队同去；</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 15:4; 士师记 4:3; 诗篇 68:17"> 他带了六百辆特选的战车，以及埃及所有的战车，每辆都有军官统领。</span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 13:17; 民数记 33:3; 申命记 26:8"> 耶和华使埃及王法老的心刚硬，他就追赶以色列人；以色列人却昂然无惧地出去。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：公然反抗地。">a</a></sup></span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 15:9; 约书亚记 24:6; 出埃及记 14:2"> 埃及人追赶他们。法老所有的马匹、战车、骑兵和军队，追上了在海边安营的以色列人；他们在比哈希录旁边，巴力洗分前。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约书亚记 24:7; 诗篇 34:17; 尼希米记 9:9"> 法老临近的时候，以色列人举目一看，看哪，埃及人正追在他们后面；他们就非常惧怕。以色列人向耶和华呼求。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 106:7–8; 民数记 14:1–4; 出埃及记 15:23–24"> 他们对摩西说：“难道埃及没有坟墓，你把我们带出来，是要我们死在旷野吗？你为什么这样待我们，把我们从埃及领出来呢？</span>
<span className="v" id="v12" data-v="12" data-xref="约拿 4:3; 出埃及记 6:9; 约拿 4:8"> 我们在埃及不是对你说过这话吗？我们说：‘不要管我们，让我们服侍埃及人。’因为服侍埃及人，比死在旷野还好。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="历代志下 20:17; 历代志下 20:15; 出埃及记 14:30"> 摩西对百姓说：“不要惧怕。站稳，看耶和华今天要为你们施行的拯救；因为你们今天所看见的埃及人，必永远不再看见了。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 3:22; 申命记 20:4; 历代志下 20:17"> 耶和华必为你们争战，你们只管安静。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约书亚记 7:10; 以斯拉记 10:4–5; 尼希米记 9:9"> 耶和华对摩西说：“你为什么向我呼求？你要吩咐以色列人往前走。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 7:19; 出埃及记 4:20; 出埃及记 4:2"> 你举起你的杖，向海伸手，把海分开。以色列人就要从海中间走干地过去。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 14:8; 出埃及记 14:4; 以西结 34:11"> 看哪，我自己要使埃及人的心刚硬，他们就会跟着进去。我要在法老和他的全军、他的战车、他的骑兵身上为自己得荣耀。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 7:5; 出埃及记 14:4; 出埃及记 7:17"> 我在法老、他的战车和他的骑兵身上为自己得荣耀的时候，埃及人就知道我是耶和华。”</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 63:9; 出埃及记 32:34; 出埃及记 23:20–21"> 在以色列营前行走的上帝的使者，转到他们后面去；云柱也从他们前面转移，站在他们后面。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 8:14; 哥林多后书 2:15–16; 箴言 4:18–19"> 它来到埃及营和以色列营之间；有云和黑暗，却又在夜间发光。整夜双方彼此不能相近。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 63:12; 出埃及记 15:8; 诗篇 66:6"> 摩西向海伸手，耶和华就用强劲的东风，使海水一整夜退去，把海变成干地，水就分开了。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 11:29; 诗篇 66:6; 出埃及记 15:19"> 以色列人从海中间走干地过去；水在他们的右边和左边成了墙。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 15:19; 出埃及记 14:17; 出埃及记 15:9"> 埃及人追赶他们，法老所有的马匹、战车和骑兵，都跟着他们进入海中间。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 13:21; 诗篇 77:16–19; 出埃及记 14:25"> 到了晨更的时候，耶和华从火柱和云柱中向埃及军兵观看，使埃及军兵混乱。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 14:14; 申命记 3:22; 约伯记 20:24"> 祂使他们的战车轮脱落，他们就难以行驶；于是埃及人说：“我们逃离以色列人吧，因为耶和华为他们争战，攻击埃及人！”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 14:16; 出埃及记 8:5; 雅各书 2:13"> 耶和华对摩西说：“你向海伸手，使水回流到埃及人、他们的战车和骑兵身上。”</span>
<span className="v" id="v27" data-v="27" data-xref="约书亚记 4:18; 诗篇 78:53; 希伯来书 11:29"> 摩西向海伸手，天一亮，海就恢复原状；埃及人迎着海水逃跑。耶和华把埃及人推翻在海中间。</span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 78:53; 诗篇 106:9–11; 哈巴谷 3:13"> 水回流，淹没了战车和骑兵，就是法老的全军，那些跟着以色列人进到海里的，连一个也没有剩下。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 14:22; 诗篇 77:19–20; 以赛亚书 43:2"> 但以色列人却在海中间走干地；水在他们的右边和左边成了墙。</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 106:8; 诗篇 106:10; 诗篇 92:9–11"> 那一天，耶和华这样把以色列从埃及人手中拯救出来；以色列看见埃及人死在海边。</span>
<span className="v" id="v31" data-v="31" data-xref="约翰福音 2:11; 约翰福音 11:45; 约翰福音 2:23–25"> 以色列看见耶和华向埃及人所行的大事，百姓就敬畏耶和华；他们信耶和华，也信祂的仆人摩西。</span>
</div>

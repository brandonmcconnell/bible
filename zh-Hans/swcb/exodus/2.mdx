<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 26:59; 历代志上 23:12–14; 出埃及记 6:16–20"> 有一个利未家的人，去娶了一个利未女子为妻。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:23; 使徒行传 7:20; 诗篇 112:5"> 那女人怀孕，生了一个儿子。她见他是个俊美的孩子，就把他藏了三个月。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 1:22; 使徒行传 7:19; 创世记 6:14"> 后来她不能再藏他了，就为他取了一个蒲草箱，涂上焦油和沥青。她把孩子放在里面，搁在河边的芦苇中。</span>
<span className="v" id="v4" data-v="4" data-xref="民数记 26:59; 出埃及记 15:20; 弥迦书 6:4"> 孩子的姐姐远远站着，要看他究竟会怎样。</span>
<span className="v" id="v5" data-v="5" data-xref="使徒行传 7:21; 诗篇 12:5; 诗篇 9:9"> 法老的女儿下到河边洗澡。她的侍女们在河岸边行走。她看见芦苇中的箱子，就派她的女仆去取来。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 8:50; 彼得前书 3:8; 使徒行传 7:21"> 她打开箱子，看见那孩子；看哪，那男婴哭了。她怜悯他，说：“这是希伯来人的孩子。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 2:4; 民数记 26:59; 民数记 12:1"> 那时，孩子的姐姐对法老的女儿说：“要我去从希伯来妇女中给你叫一个乳母来，好为你奶养这孩子吗？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 46:3–4; 诗篇 27:10; 出埃及记 6:20"> 法老的女儿对她说：“去吧。”<br />那少女就去叫了孩子的母亲来。</span>
<span className="v" id="v9" data-v="9"> 法老的女儿对她说：“把这孩子带去，为我奶养他，我会给你工钱。”<br />那女人就把孩子带去，奶养他。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 11:24; 创世记 16:11; 撒母耳记上 1:20"> 孩子长大了，她把他带到法老的女儿那里，他就成了她的儿子。她给他起名叫摩西，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“摩西”的发音近似希伯来语“拉出来”。">a</a></sup>说：“因为我把他从水里拉出来。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="希伯来书 11:24–26; 使徒行传 7:22–24; 出埃及记 1:11"> 那些日子，摩西长大以后，出去到他的弟兄们那里，看他们所负的重担。他看见一个埃及人殴打一个希伯来人，就是他的一个弟兄。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 7:24–26"> 他左右观看，见没有人在那里，就杀了那个埃及人，把他藏在沙土里。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 7:26–28; 哥林多前书 6:7–8"> 第二天他出去，看哪，有两个希伯来人彼此争斗。他对那做错事的人说：“你为什么打你的同伴？”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 12:14; 马太福音 21:23; 创世记 19:9"> 那人说：“谁立你作我们的首领和审判官？难道你打算杀我，像杀那埃及人一样吗？”<br />摩西就害怕，说：“这事必定已经被人知道了。”</span>
<span className="v" id="v15" data-v="15" data-xref="使徒行传 7:29; 希伯来书 11:27; 创世记 24:11"> 法老听见这事，就想要杀摩西。但摩西逃离法老面前，住在米甸地；他坐在一口井旁。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="创世记 24:11; 出埃及记 3:1; 撒母耳记上 9:11"> 米甸的祭司有七个女儿。她们来打水，把水槽盛满，要给她们父亲的羊群喝。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 29:10; 创世记 21:25; 创世记 26:15–22"> 牧羊人来了，把她们赶走；摩西却站起来帮助她们，又给她们的羊群喝水。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 3:1; 民数记 10:29; 出埃及记 4:18"> 她们来到父亲流珥那里；他说：“你们今天怎么这么快就回来了？”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="创世记 50:11; 创世记 29:10"> 她们说：“有一个埃及人救我们脱离牧羊人的手，而且还为我们打水，给羊群喝。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="创世记 31:54; 创世记 43:25; 希伯来书 13:2"> 他对女儿们说：“他在哪里？你们为什么把那人撇下了？叫他来吃饭。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 31:38–40; 希伯来书 13:5; 希伯来书 11:25"> 摩西愿意和那人同住。那人把自己的女儿西坡拉给了摩西。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 11:13–14; 使徒行传 7:29; 出埃及记 22:21"> 她生了一个儿子，摩西给他起名叫革舜，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“革舜”的发音近似希伯来语“在那里作寄居者”。">b</a></sup>因为他说：“我在异乡作了寄居者。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="创世记 18:20–21; 雅各书 5:4; 出埃及记 3:7–9"> 过了许多日子，埃及王死了。以色列子孙因奴役而叹息，就哀求；他们因奴役发出的呼求上达到上帝那里。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 26:3; 诗篇 105:42; 出埃及记 6:5"> 上帝听见他们的呻吟，就记念祂与亚伯拉罕、以撒、雅各所立的约。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 4:31; 诗篇 55:22; 出埃及记 3:7–8"> 上帝看见以色列子孙；上帝也明白。</span>
</div>
</div>

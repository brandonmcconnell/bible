<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 25:10–20; 出埃及记 26:33; 民数记 10:33–36"> 比撒列用皂荚木造了约柜。柜长二肘半，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘是人手臂从中指尖到肘部的长度，约十八英寸或四十六厘米。">a</a></sup>宽一肘半，高一肘半。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 30:3"> 他用纯金把柜内外包上，又在柜的四围做了金边。</span>
<span className="v" id="v3" data-v="3"> 他为柜铸了四个金环，安在柜的四脚上：这一边两个环，那一边两个环。</span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 9:15; 彼得前书 1:7; 民数记 4:14–15"> 他用皂荚木做了杠，用金包上。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 4:15; 撒母耳记下 6:3–7; 民数记 1:50"> 他把杠穿进柜两侧的环里，用来抬柜。</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 9:5; 提多书 2:14; 罗马书 3:25"> 他用纯金造了施恩座，长二肘半，宽一肘半。</span>
<span className="v" id="v7" data-v="7" data-xref="以西结 10:2; 诗篇 104:4; 诗篇 80:1"> 他用金造了两个基路伯，是锤出来的，安在施恩座的两端：</span>
<span className="v" id="v8" data-v="8"> 这端一个基路伯，那端一个基路伯。他在施恩座的两端造基路伯，与施恩座连成一体。</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 1:51; 希伯来书 1:14; 创世记 28:12"> 基路伯在上方展开翅膀，用翅膀遮盖施恩座，彼此相向。基路伯的脸朝向施恩座。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="约翰福音 1:14; 以西结 40:39–42; 玛拉基书 1:12"> 他用皂荚木做了桌子，长二肘，宽一肘，高一肘半。</span>
<span className="v" id="v11" data-v="11"> 他用纯金把桌子包上，又在四围做了金边。</span>
<span className="v" id="v12" data-v="12"> 他在桌子的四围做了一掌宽的边框，又在边框四围做了金边。</span>
<span className="v" id="v13" data-v="13"> 他为桌子铸了四个金环，把环安在桌子四脚上的四角。</span>
<span className="v" id="v14" data-v="14"> 环靠近边框，是穿杠抬桌子的地方。</span>
<span className="v" id="v15" data-v="15"> 他用皂荚木做了杠，用金包上，用来抬桌子。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 25:29; 列王纪上 7:50; 列王纪下 12:13"> 他用纯金做了桌子上的器具：盘子、调羹、碗，以及用来浇奠的壶。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及记 25:31–39; 希伯来书 9:2; 历代志下 13:11"> 他用纯金造了灯台。灯台是锤出来的；它的座、干、杯、花萼和花，都与灯台连成一体。</span>
<span className="v" id="v18" data-v="18"> 灯台两侧伸出六根枝子：这边伸出三根枝子，那边伸出三根枝子。</span>
<span className="v" id="v19" data-v="19"> 一根枝子上有三个杯，形状像杏花，有花萼和花；另一根枝子上也有三个杯，形状像杏花，有花萼和花。从灯台伸出的六根枝子都是这样。</span>
<span className="v" id="v20" data-v="20" data-xref="传道书 12:5; 耶利米书 1:11; 出埃及记 25:33"> 灯台本身有四个杯，形状像杏花，有花萼和花；</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 25:35"> 灯台每两根枝子下面有一个花萼，与灯台连成一体；又每两根枝子下面有一个花萼，与灯台连成一体；再每两根枝子下面有一个花萼，与灯台连成一体；从灯台伸出的六根枝子都是这样。</span>
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 3:5; 出埃及记 25:31; 诗篇 51:17"> 它们的花萼和枝子都与灯台连成一体；整个灯台是一整块纯金锤出来的。</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 1:12; 出埃及记 25:37; 启示录 1:20–1"> 他用纯金做了灯台的七盏灯、灯剪和灯花盘。</span>
<span className="v" id="v24" data-v="24"> 他用一他连得<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一他连得约为三十公斤，或六十六磅，或九百六十五金衡盎司。">b</a></sup>纯金造了灯台和一切器具。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及记 30:1–5; 希伯来书 7:25; 启示录 8:3–4"> 他用皂荚木造了香坛。坛是方的，长一肘，宽一肘，高二肘；坛的角与坛连成一体。</span>
<span className="v" id="v26" data-v="26"> 他用纯金把坛包上：坛顶、坛的四面和坛的角；又在坛的四围做了金边。</span>
<span className="v" id="v27" data-v="27"> 他在坛冠状边饰下面的两条边上，就是两侧，做了两个金环，作为穿杠抬坛的地方。</span>
<span className="v" id="v28" data-v="28"> 他用皂荚木做了杠，用金包上。</span>
<span className="v" id="v29" data-v="29" data-xref="诗篇 141:2; 希伯来书 7:25; 约翰一书 2:20"> 他又按调香师的工艺，做了圣膏油和纯净的馨香之香。</span>
</div>

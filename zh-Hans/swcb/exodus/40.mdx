<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 26:30; 出埃及记 13:4; 民数记 7:1"> “正月初一日，你要立起会幕的帐幕。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 35:12; 民数记 4:5; 启示录 11:19"> 你要把约柜放在里面，用幔子遮掩柜。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 24:8; 出埃及记 40:22–25; 出埃及记 37:10–24"> 你要把桌子搬进去，摆好上面的物件。你要把灯台搬进去，点亮灯盏。</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 10:19–22; 希伯来书 9:24; 约翰一书 2:1–2"> 你要把烧香的金坛安放在约柜前，又要挂上帐幕门口的帘子。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 40:29; 约翰一书 4:9–10; 希伯来书 13:10"> “你要把燔祭坛安放在会幕的帐幕门前。</span>
<span className="v" id="v7" data-v="7" data-xref="撒迦利亚书 13:1; 约翰一书 1:7; 诗篇 26:6"> 你要把洗濯盆安放在会幕和坛之间，盆里要盛水。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 40:33; 以弗所书 4:11–12; 马太福音 16:18"> 你要在四围立起院子，挂上院门的帘子。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="利未记 8:10; 民数记 7:1; 马太福音 3:16"> “你要拿膏油，膏抹帐幕和其中所有的一切，使帐幕和其中一切器具分别为圣，帐幕就成为圣。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 29:36–37; 路加福音 1:35; 以赛亚书 61:1"> 你要膏抹燔祭坛和坛的一切器具，使坛分别为圣，坛就成为至圣。</span>
<span className="v" id="v11" data-v="11"> 你要膏抹洗濯盆和盆座，使它分别为圣。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="利未记 8:1–13; 利未记 9:1–24; 出埃及记 29:1–35"> “你要把亚伦和他的儿子们带到会幕门口，用水洗他们。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 28:41; 约翰一书 2:20; 约翰一书 2:27"> 你要给亚伦穿上圣衣；你要膏抹他，使他分别为圣，好让他事奉我，作祭司。</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 61:10; 罗马书 8:30; 哥林多前书 1:30"> 你要带他的儿子们来，给他们穿上内袍。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 25:13; 希伯来书 5:1–14; 希伯来书 8:1–10"> 你要膏抹他们，像膏抹他们的父亲一样，好让他们事奉我，作祭司。他们受膏，就使他们世世代代拥有永远的祭司职分。”</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 4:1; 出埃及记 40:17–32; 申命记 12:32"> 摩西就这样做了；凡耶和华吩咐他的，他都照样做了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民数记 7:1; 出埃及记 40:1–2; 民数记 9:1"> 第二年正月初一日，帐幕立起来了。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结 37:27–28; 彼得前书 1:5; 利未记 26:11"> 摩西立起帐幕，安放卯座，竖立木板，穿上横闩，立起柱子。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 26:1–14; 出埃及记 36:8–19"> 他把罩棚铺在帐幕以上，又把帐幕的顶盖放在其上，照耶和华所吩咐摩西的。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 16:34; 申命记 10:5; 希伯来书 10:19–21"> 他拿了约放进柜里，把杠穿在柜上，又把施恩座放在柜的上面。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 26:33; 出埃及记 40:3; 出埃及记 35:12"> 他把柜抬进帐幕，挂上遮掩的幔子，遮掩约柜，照耶和华所吩咐摩西的。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 26:35; 约翰福音 6:53–57; 以弗所书 3:8"> 他把桌子放在会幕里，在帐幕北边，幔子外面。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 25:30; 出埃及记 40:4; 希伯来书 9:2"> 他在耶和华面前把饼摆列在桌上，照耶和华所吩咐摩西的。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 26:35; 启示录 2:5; 约翰福音 1:1"> 他把灯台放在会幕里，在帐幕南边，与桌子相对。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 40:4; 出埃及记 25:37; 启示录 4:5"> 他在耶和华面前点亮灯盏，照耶和华所吩咐摩西的。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 40:5; 希伯来书 7:25; 约翰福音 11:42"> 他把金坛放在会幕里，幔子前面；</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 30:7"> 又在坛上烧馨香的香，照耶和华所吩咐摩西的。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 40:5; 希伯来书 10:19–20; 以弗所书 2:18"> 他挂上帐幕门口的帘子。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 40:6; 希伯来书 13:5–6; 希伯来书 13:10"> 他把燔祭坛安放在会幕的帐幕门口，在坛上献燔祭和素祭，照耶和华所吩咐摩西的。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 40:7; 出埃及记 38:8; 以西结 36:25"> 他把洗濯盆安放在会幕和坛之间，盆里盛水，用来洗濯。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 30:19–20; 诗篇 26:6; 约翰福音 13:10"> 摩西、亚伦和他的儿子们在那里洗手洗脚。</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 73:19; 出埃及记 30:19–20; 出埃及记 40:19"> 他们进会幕的时候，靠近坛的时候，都洗濯，照耶和华所吩咐摩西的。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 40:8; 出埃及记 27:9–16; 约翰福音 17:4"> 他在帐幕和坛的四围立起院子，挂上院门的帘子。这样，摩西完成了工程。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="启示录 15:8; 民数记 9:15–23; 历代志下 7:2"> 那时，云彩遮盖会幕，耶和华的荣耀充满帐幕。</span>
<span className="v" id="v35" data-v="35" data-xref="列王纪上 8:11; 利未记 16:2; 历代志下 7:2"> 摩西不能进入会幕，因为云彩停在其上，耶和华的荣耀充满帐幕。</span>
<span className="v" id="v36" data-v="36" data-xref="尼希米记 9:19; 民数记 9:17; 出埃及记 13:21–22"> 在以色列人一切的行程中，每当云彩从帐幕上升起，他们就起行；</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 9:19–22; 诗篇 31:15"> 如果云彩没有升起，他们就不起行，直到云彩升起的日子。</span>
<span className="v" id="v38" data-v="38" data-xref="诗篇 78:14; 民数记 9:15; 出埃及记 13:21"> 在他们一切的行程中，白天有耶和华的云彩在帐幕上，夜间云中有火，在以色列全家眼前。</span>
</div>
</div>

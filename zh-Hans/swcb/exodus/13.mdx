<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 2:23; 民数记 3:13; 申命记 15:19"> “以色列人中凡头生的，无论是人是牲畜，凡开母胎的，都要分别为圣归我；这是属我的。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命记 24:18; 申命记 5:15; 出埃及记 20:2"> 摩西对百姓说：“你们要记念这一天，就是你们从埃及、从为奴之家出来的日子；因为耶和华用大能的手把你们从这地方领出来。不可吃有酵的饼。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 34:18; 出埃及记 23:15; 出埃及记 12:2"> 今天，你们在亚笔月出来。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 3:8; 约书亚记 24:11; 出埃及记 12:25–26"> 将来耶和华把你领进迦南人、赫人、亚摩利人、希未人、耶布斯人的地，就是祂向你祖先起誓要赐给你的、流奶与蜜之地，那时你要在这月守这礼仪。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 12:15–20; 出埃及记 34:18; 利未记 23:8"> 七天之内，你要吃无酵饼；第七天要向耶和华守节。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 12:19; 马太福音 16:6"> 这七天之内要吃无酵饼；在你那里不可看见有酵的饼，在你境内也不可看见酵。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 13:14; 出埃及记 12:26–27; 诗篇 44:1"> 到那日，你要告诉你的儿子说：‘这是因为我从埃及出来时，耶和华为我所做的事。’</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 6:8; 申命记 11:18–19; 民数记 15:39"> 这要在你手上作记号，在你两眼之间作纪念，使耶和华的律法在你口中；因为耶和华用大能的手把你从埃及领出来。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 12:14; 出埃及记 12:24–25; 出埃及记 23:15"> 所以，你每年到了定期都要守这条例。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="出埃及记 13:5"> “将来耶和华照着祂向你和你祖先所起的誓，把你领进迦南人的地，并把那地赐给你，</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 18:15; 利未记 27:26; 出埃及记 34:19"> 那时，你要把一切开母胎的，以及你所有牲畜中头生的，都分别出来归耶和华；公的都要归耶和华。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 34:20; 民数记 18:15–17; 启示录 14:4"> 凡头生的驴，你要用羊羔赎回；如果不赎，就要折断它的颈项；你儿子中凡头生的，都要赎回。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 13:3; 约书亚记 4:6; 诗篇 145:4"> 将来你的儿子问你说：‘这是什么意思？’你就要告诉他说：‘耶和华用大能的手把我们从埃及、从为奴之家领出来。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 12:29"> 法老顽固，不肯让我们走的时候，耶和华就击杀埃及地所有头生的，从人头生的到牲畜头生的都杀了。因此，凡开母胎的公牲畜，我都献祭给耶和华；但我儿子中凡头生的，我都赎回。’</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 13:9; 申命记 11:18; 申命记 6:7–9"> 这要在你手上作记号，在你两眼之间作标记；因为耶和华用大能的手把我们从埃及领出来。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及记 14:11–12; 尼希米记 9:17; 民数记 14:1–4"> 法老放百姓走以后，上帝没有领他们走非利士人之地的路，虽然那条路较近；因为上帝说：“恐怕百姓看见战争就后悔，返回埃及。”</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 14:2; 申命记 32:10; 民数记 33:6–8"> 于是上帝领百姓绕道，走红海旷野的路；以色列人带着兵器从埃及地上去。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 50:24–25; 约书亚记 24:32; 使徒行传 7:16"> 摩西把约瑟的骸骨一同带去，因为约瑟曾使以色列人严严起誓说：“上帝必定眷顾你们；那时你们要把我的骸骨从这里一同带上去。”</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 33:5–6; 出埃及记 12:37"> 他们从疏割起行，在旷野边缘的以倘安营。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 10:1–2; 尼希米记 9:12; 申命记 1:33"> 耶和华白天在云柱中走在他们前面，引领他们的路；夜间在火柱中给他们光照，使他们可以日夜行走；</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 121:5–8; 启示录 10:1"> 白天的云柱、夜间的火柱，总不离开百姓面前。</span>
</div>

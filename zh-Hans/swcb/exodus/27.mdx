<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 38:1–7; 出埃及记 20:24–26; 出埃及记 40:10"> “你要用皂荚木做祭坛，长五肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘是人手臂从中指尖到肘部的长度，约十八英寸或四十六厘米。">a</a></sup>，宽五肘。祭坛要是正方形，高三肘。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="祭坛约为二点三米×二点三米×一点四米，或约七英尺半×七英尺半×四英尺半。">b</a></sup></span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 118:27; 出埃及记 29:12; 利未记 4:7"> 你要在坛的四角做角；坛角要与坛连成一体。你要用铜包裹祭坛。</span>
<span className="v" id="v3" data-v="3" data-xref="列王纪上 7:45; 民数记 4:14; 历代志上 28:17"> 你要做坛上的盆，用来收去坛灰；还要做铲子、盘子、肉叉和火盆。坛的一切器具都要用铜做。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 35:16; 出埃及记 25:12; 出埃及记 38:4–5"> 你要为坛做一个铜网的格栅，在网的四角上做四个铜环。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 38:4"> 你要把网安在坛下方四围的边缘下面，使网达到坛的半腰。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 35:13–15; 民数记 4:44; 出埃及记 30:4"> 你要为祭坛做杠，用皂荚木做杠，并用铜包裹。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 25:28; 出埃及记 30:4; 民数记 4:13–14"> 杠要穿在环内；抬祭坛的时候，杠要在祭坛的两边。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 25:40; 出埃及记 25:9; 希伯来书 8:5"> 你要用板把坛做成中空的。他们要照着在山上指示你的样式做。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 38:9–20; 以西结 40:32; 以西结 42:3"> “你要做帐幕的院子：朝南的一边，要有捻的细麻帷幔，作院子这一边，长一百肘。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 26:19–21; 耶利米书 52:21; 出埃及记 36:38"> 帷幔的柱子要有二十根，铜座二十个；柱子的钩和箍要用银做。</span>
<span className="v" id="v11" data-v="11"> 北边的长度也照样，要有长一百肘的帷幔，柱子二十根，铜座二十个；柱子的钩和箍要用银做。</span>
<span className="v" id="v12" data-v="12"> 院子的西边，宽度要有五十肘的帷幔；柱子十根，座十个。</span>
<span className="v" id="v13" data-v="13"> 院子东边朝东的宽度要有五十肘。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 27:9; 出埃及记 26:36"> 门这一侧的帷幔要十五肘；柱子三根，座三个。</span>
<span className="v" id="v15" data-v="15"> 另一侧也要有十五肘的帷幔；柱子三根，座三个。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 26:36; 士师记 5:30; 出埃及记 28:39"> 院子的门要有二十肘的门帘，用蓝色、紫色、朱红色线和捻的细麻，由绣花匠做成；柱子四根，座四个。</span>
<span className="v" id="v17" data-v="17"> 院子四围所有的柱子都要用银箍箍着；柱子的钩要用银做，座要用铜做。</span>
<span className="v" id="v18" data-v="18"> 院子要长一百肘，各处宽五十肘，高五肘，用捻的细麻做，座要用铜做。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 35:18; 以赛亚书 22:23–25; 民数记 4:32"> 帐幕中各样事奉所用的一切器具，以及帐幕所有的橛子和院子所有的橛子，都要用铜做。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="利未记 24:1–4; 撒迦利亚书 4:11–14; 诗篇 23:5"> “你要吩咐以色列子孙，把捣成的纯橄榄油拿来给你，用来点灯，使灯常常燃着。</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 19:21; 民数记 18:23; 撒母耳记上 3:3"> 在会幕里，在约前面那幔子的外面，亚伦和他的儿子们要从晚上到早晨，在耶和华面前整理这灯；这要为以色列子孙世世代代作永远的定例。</span>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="EXO" data-book-slug="exodus" data-book-name="出埃及记" data-chapter="30" data-verses="38">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 8:3; 出埃及记 37:25–28; 出埃及记 40:5"> “你要造一座烧香的坛，要用金合欢木造。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 27:2"> 坛长一肘，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘是人手臂从中指尖到肘部的长度，约十八英寸或四十六厘米。">a</a></sup>宽一肘，坛要是方的，高二肘；坛的角要与坛连成一体。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 25:11; 出埃及记 25:24"> 要用纯金包裹坛的上面、四围的侧面和坛的角；又要在坛的四围做金边。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 25:27; 出埃及记 26:29; 出埃及记 27:7"> 要在金边以下为坛做两个金环；要做在坛两侧的边上，作为穿杠的地方，用来抬坛。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 25:13; 出埃及记 25:27"> 要用金合欢木做杠，并用金包裹。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 25:21–22; 出埃及记 30:36; 利未记 16:13"> 要把坛放在约柜旁的幔子前，就是在约上面的施恩座前；在那里我要与你相会。</span>
<span className="v" id="v7" data-v="7" data-xref="撒母耳记上 2:28; 历代志上 23:13; 出埃及记 27:20–21"> 亚伦要每天早晨在坛上烧馨香的香；他整理灯的时候，要烧这香。</span>
<span className="v" id="v8" data-v="8" data-xref="希伯来书 9:24; 帖撒罗尼迦前书 5:17; 希伯来书 7:25"> 黄昏亚伦点灯的时候，也要烧这香；这要在耶和华面前，作为你们世世代代常烧的香。</span>
<span className="v" id="v9" data-v="9" data-xref="利未记 10:1"> 你们不可在坛上献别的香，也不可献燔祭、素祭；也不可在坛上浇奠祭。</span>
<span className="v" id="v10" data-v="10" data-xref="利未记 16:18; 希伯来书 9:22–23; 利未记 16:29–30"> 亚伦每年一次要在坛的角上行赎罪之礼；他要用赎罪祭牲的血，每年一次为坛赎罪；这要作为你们世世代代的条例。这坛归耶和华为至圣。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 耶和华对摩西说：</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 31:50; 历代志上 27:24; 出埃及记 38:25–26"> “你数点以色列人的时候，按被数点的人数，每个人都要在被数点时，为自己的生命把赎价交给耶和华，免得你数点他们的时候，他们中间有灾祸。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 27:25; 民数记 3:47; 以西结 45:12"> 凡列入被数点的人，都要按圣所的舍客勒<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一舍客勒约十克，或约零点三五盎司。">b</a></sup>交半舍客勒；一舍客勒是二十季拉<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一季拉约零点五克，或约七点七格令。">c</a></sup>；这半舍客勒是给耶和华的供物。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 1:20; 民数记 1:18; 民数记 1:3"> 凡列入被数点的人，从二十岁以上，都要把供物给耶和华。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 31:50; 利未记 17:11; 出埃及记 30:12"> 他们给耶和华的供物，为自己的生命赎罪的时候，富有的不可多给，贫穷的也不可少给，都要给半舍客勒。<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一舍客勒约十克，或约零点三五盎司。">d</a></sup></span>
<span className="v" id="v16" data-v="16" data-xref="尼希米记 10:32–33; 民数记 16:40; 出埃及记 38:25–31"> 你要从以色列人收取赎罪银，指定用在会幕的事务上；这要在耶和华面前作以色列人的纪念，为你们的生命赎罪。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17"> 耶和华对摩西说：</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 40:7; 出埃及记 38:8; 列王纪上 7:23"> “你还要造一个铜盆和铜座，用来洗濯；要把盆放在会幕和坛之间，在盆里盛水。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 52:11; 出埃及记 40:31–32; 诗篇 26:6"> 亚伦和他的儿子们要在盆里洗手洗脚。</span>
<span className="v" id="v20" data-v="20" data-xref="利未记 10:1–3; 希伯来书 12:28–29; 历代志上 13:10"> 他们进会幕的时候，要用水洗，免得死亡；或者他们近前到坛那里供职，向耶和华焚烧火祭的时候，也要洗。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 28:43; 出埃及记 27:21"> 他们要洗手洗脚，免得死亡。这要作他们永远的条例，就是亚伦和他的后裔世世代代的条例。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22"> 耶和华又对摩西说：</span>
<span className="v" id="v23" data-v="23" data-xref="以西结 27:19; 雅歌 4:14; 以西结 27:22"> “你还要取上等香料：流质没药五百舍客勒；<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一舍客勒约十克，或约零点三五盎司，所以五百舍客勒约五千克，或约十一磅。">e</a></sup>香肉桂取一半，就是二百五十舍客勒；香菖蒲二百五十舍客勒；</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 45:8; 出埃及记 29:40; 民数记 3:47"> 桂皮五百舍客勒，都按圣所的舍客勒；又取橄榄油一欣。<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一欣约六点五升，或一点七加仑。">f</a></sup></span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 37:29; 历代志上 9:30; 出埃及记 40:9"> 你要把这些做成圣膏油，就是按调香之法调制的香膏；它要作圣膏油。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 7:1; 约翰一书 2:20; 以赛亚书 61:1"> 你要用这油膏会幕、约柜、</span>
<span className="v" id="v27" data-v="27"> 桌子和桌子的一切器具、灯台和灯台的器具、香坛、</span>
<span className="v" id="v28" data-v="28"> 燔祭坛和坛的一切器具，以及盆和盆座。</span>
<span className="v" id="v29" data-v="29" data-xref="马太福音 23:19; 出埃及记 29:37; 利未记 6:18"> 你要使它们分别为圣，使它们成为至圣；凡触着它们的，都要成为圣。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 8:12; 出埃及记 28:3; 利未记 8:30"> 你要膏亚伦和他的儿子们，使他们分别为圣，可以作祭司事奉我。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 37:29; 利未记 21:10; 诗篇 89:20"> 你要对以色列人说：‘这要世世代代归我作圣膏油。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 30:25; 出埃及记 30:37–38; 利未记 21:10"> 不可倒在人的身上，也不可照它的配方调制类似的膏油。它是圣的，你们也要以它为圣。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 30:38; 创世记 17:14; 出埃及记 12:15"> 凡调制类似的膏油，或把这油抹在外人身上的，那人要从他的民中被剪除。’”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="出埃及记 37:29; 出埃及记 25:6; 出埃及记 30:23"> 耶和华对摩西说：“你要为自己取馨香的香料，就是苏合香、螺甲香、白松香；这些馨香的香料要与纯乳香相配，各样分量要相等。</span>
<span className="v" id="v35" data-v="35" data-xref="利未记 2:13; 出埃及记 30:25; 约翰福音 12:3"> 你要用这些做成香，就是按调香之法调制的香品，加盐调和，纯净而圣洁。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 25:22; 出埃及记 30:6; 出埃及记 16:34"> 要把其中一些捣得极细，放一些在会幕里约的前面，就是我要与你相会的地方。这香对你们要为至圣。</span>
<span className="v" id="v37" data-v="37" data-xref="利未记 2:3; 出埃及记 29:37; 出埃及记 30:32–33"> 这种香，你们不可照它的配方为自己调制；它对你们要归耶和华为圣。</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及记 30:33"> 凡调制类似的香来闻的，那人要从他的民中被剪除。”</span>
</div>
</div>

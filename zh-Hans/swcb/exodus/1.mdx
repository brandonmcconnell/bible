<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 2:1–2; 创世记 46:8–26; 创世记 35:23–26"> 以下是以色列众子的名字，他们随雅各来到埃及，各人和各人的家眷都来了：</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 35:22"> 流便、西缅、利未和犹大，</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 28:20; 创世记 35:23"> 以萨迦、西布伦和便雅悯，</span>
<span className="v" id="v4" data-v="4"> 但和拿弗他利，迦得和亚设。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 10:22; 创世记 46:26–27; 士师记 8:30"> 凡从雅各身体所出的，共有七十人；约瑟已经在埃及。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 50:26; 创世记 50:24; 使徒行传 7:14–16"> 约瑟死了，他的众兄弟和那一代的人也都死了。</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 46:3; 创世记 1:28; 申命记 26:5"> 以色列的子孙生养众多，大大增多，繁衍起来，变得极其强盛；那地就满了他们。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 7:18; 传道书 2:18–19; 传道书 9:15"> 后来，有一位不认识约瑟的新王兴起，治理埃及。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 105:24–25; 传道书 4:4; 雅各书 3:14–16"> 他对自己的百姓说：“看哪，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“看哪”源自“הִנֵּה”，意思是看、注意、观察、看见或凝视。它常用作感叹词。">a</a></sup>以色列子孙这族人比我们更多、更强盛。</span>
<span className="v" id="v10" data-v="10" data-xref="使徒行传 7:19; 诗篇 83:3–4; 箴言 1:11"> 来吧，我们要用计策对付他们，免得他们增多；若有战争爆发，他们也加入我们的仇敌，与我们作战，并且离开这地。”</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 15:13; 创世记 47:11; 出埃及记 3:7"> 于是埃及人派督工辖制他们，用重担苦待他们。他们为法老建造储藏城：比东和兰塞。</span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 105:24; 出埃及记 1:9; 罗马书 8:28"> 可是埃及人越苦待他们，他们就越增多，越扩展。埃及人开始惧怕以色列的子孙。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 4:20"> 埃及人严酷地使以色列的子孙服劳役，</span>
<span className="v" id="v14" data-v="14" data-xref="使徒行传 7:19; 民数记 20:15; 出埃及记 2:23"> 使他们的生活因艰苦的劳役而愁苦，就是和泥、做砖，以及田间各样的劳役；他们在一切劳役上都严酷地使他们服役。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15"> 埃及王对希伯来的收生婆说话；一个名叫施弗拉，另一个名叫普阿。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 1:22; 马太福音 21:38; 启示录 12:4"> 他说：“你们给希伯来妇人接生，看她们在产凳上时，若是儿子，就要杀他；若是女儿，就让她活着。”</span>
<span className="v" id="v17" data-v="17" data-xref="使徒行传 5:29; 出埃及记 1:21; 马太福音 10:28"> 但是收生婆敬畏上帝，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="译为“上帝”的希伯来词是“אֱלֹהִ֑ים”（Elohim）。">b</a></sup>没有照埃及王吩咐她们的去做，反而使男婴存活。</span>
<span className="v" id="v18" data-v="18" data-xref="传道书 8:4; 撒母耳记下 13:28"> 埃及王召了收生婆来，对她们说：“你们为什么做这事，使男孩存活呢？”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约书亚记 2:4–24; 撒母耳记下 17:19–20; 撒母耳记上 21:2"> 收生婆对法老说：“因为希伯来妇人不像埃及妇人；她们健壮，收生婆还没到，她们就已经生产了。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 3:10; 传道书 8:12; 箴言 11:18"> 上帝厚待收生婆，百姓也增多，变得非常强盛。</span>
<span className="v" id="v21" data-v="21" data-xref="列王纪上 11:38; 撒母耳记上 2:35; 诗篇 37:3"> 因为收生婆敬畏上帝，祂就赐给她们家室。</span>
<span className="v" id="v22" data-v="22" data-xref="使徒行传 7:19; 箴言 1:16; 出埃及记 1:16"> 法老吩咐他的全体百姓说：“凡出生的男孩，你们都要丢进河里；凡女孩，你们都要让她活着。”</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 18:7; 希伯来书 5:1–5; 民数记 17:2–9"> “你要从以色列人中，使你的哥哥亚伦和他的儿子们，就是亚伦和亚伦的儿子拿答、亚比户、以利亚撒、以他玛，一同亲近你，好叫他作祭司事奉我。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 8:30; 出埃及记 31:10; 启示录 19:8"> 你要为你的哥哥亚伦制作圣衣，使他得荣耀和华美。</span>
<span className="v" id="v3" data-v="3" data-xref="以弗所书 1:17; 哥林多前书 12:7–11; 以赛亚书 11:2"> 你要吩咐一切心中有智慧的人，就是我用智慧的灵充满的人，叫他们制作亚伦的衣服，使他分别为圣，好作祭司事奉我。</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 6:14; 启示录 9:17; 以赛亚书 59:17"> 他们要制作的衣服是这些：胸牌、以弗得、外袍、合身内袍、礼冠和腰带。他们要为你的哥哥亚伦和他的儿子们制作圣衣，好叫他作祭司事奉我。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 25:3–4; 出埃及记 39:2–3"> 他们要用金线、蓝色线、紫色线、朱红色线和细麻。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 39:2–7; 出埃及记 26:1"> “他们要用金线、蓝色线、紫色线、朱红色线和捻成的细麻，以巧匠的手工制作以弗得。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 39:4"> 以弗得要有两条肩带，接在两端，使它连在一起。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 28:27–28; 利未记 8:7; 出埃及记 29:5"> 以弗得上巧织的带子，要和以弗得一样的做法，并与它连成一体；要用金线、蓝色线、紫色线、朱红色线和捻成的细麻制作。</span>
<span className="v" id="v9" data-v="9" data-xref="以西结 28:13; 历代志下 2:7; 以赛亚书 49:16"> 你要取两块红玛瑙，在上面刻以色列众子的名字。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 1:1–4; 创世记 43:33"> 六个名字刻在一块宝石上，其余六个名字刻在另一块宝石上，按他们出生的次序。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太后书 2:19; 启示录 7:2; 耶利米书 22:24"> 你要用刻宝石的手工，像刻印章一样，按以色列众子的名字刻这两块宝石；要把它们镶在金槽中。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 28:29; 约书亚记 4:7; 出埃及记 39:6–7"> 你要把这两块宝石安在以弗得的肩带上，作为以色列众子的纪念石。亚伦要在他的两肩上，在耶和华面前担负他们的名字，作为纪念。</span>
<span className="v" id="v13" data-v="13"> 你要制作金槽，</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 39:15; 出埃及记 39:17–18; 列王纪上 7:17"> 又要制作两条纯金链子；要把它们做成绳子一样的编工。你要把编成的链子接在金槽上。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及记 28:30; 出埃及记 26:1; 出埃及记 28:4"> “你要制作决断的胸牌，用巧匠的手工；要照以弗得的做法制作，用金线、蓝色线、紫色线、朱红色线和捻成的细麻来制作。</span>
<span className="v" id="v16" data-v="16"> 胸牌要是正方形，双层的；长一虎口<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一虎口是人伸开手时，从拇指尖到小指尖的长度（约半肘，或9英寸，或22.8厘米）。">a</a></sup>，宽一虎口。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结 28:13; 出埃及记 39:10–21; 箴言 8:11"> 你要在上面镶嵌宝石，排成四行：第一行是红宝石、黄玉和绿宝石；</span>
<span className="v" id="v18" data-v="18" data-xref="以西结 27:16; 约伯记 28:6; 雅歌 5:14"> 第二行是绿松石、蓝宝石<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：青金石。">b</a></sup>和翡翠；</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 54:12; 出埃及记 39:12"> 第三行是风信子石、玛瑙和紫晶；</span>
<span className="v" id="v20" data-v="20" data-xref="以西结 1:16; 启示录 4:3; 但以理 10:6"> 第四行是贵橄榄石、红玛瑙和碧玉。这些宝石都要镶在金槽中。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 21:12; 启示录 7:4–8; 列王纪上 18:31"> 这些宝石要按以色列众子的名字，共十二块，按他们的名字；要像刻印章一样，每块按一个名字，代表十二支派。</span>
<span className="v" id="v22" data-v="22"> 你要在胸牌上制作链子，像绳子一样，是纯金的编工。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 25:11–15"> 你要在胸牌上制作两个金环，把两个环安在胸牌的两端。</span>
<span className="v" id="v24" data-v="24"> 你要把两条金编链穿在胸牌两端的两个环里。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 39:15; 出埃及记 39:4; 出埃及记 28:14"> 两条编链的另外两端，要接在两个金槽上，并安在以弗得前面的肩带上。</span>
<span className="v" id="v26" data-v="26"> 你要制作两个金环，安在胸牌的两端，就是胸牌里面朝向以弗得一侧的边上。</span>
<span className="v" id="v27" data-v="27"> 你要制作两个金环，安在以弗得前面的两条肩带下方，靠近接缝，在以弗得巧织带子的上面。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 15:38; 出埃及记 28:31; 出埃及记 39:30–31"> 要用蓝色细绳，把胸牌的环系在以弗得的环上，使胸牌贴在以弗得巧织的带子上，胸牌就不致从以弗得上松脱。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 28:12; 出埃及记 28:30; 耶利米书 30:21"> 亚伦进圣所的时候，要把以色列众子的名字带在他胸前决断的胸牌上，在耶和华面前常作纪念。</span>
<span className="v" id="v30" data-v="30" data-xref="尼希米记 7:65; 以斯拉记 2:63; 民数记 27:21"> 你要把乌陵和土明放在决断的胸牌里；亚伦进到耶和华面前的时候，它们要在亚伦的心上。亚伦要在耶和华面前，常把以色列人的决断担在心上。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="利未记 8:7; 出埃及记 28:4; 出埃及记 39:22–26"> “你要制作以弗得的外袍，全部用蓝色。</span>
<span className="v" id="v32" data-v="32" data-xref="尼希米记 4:16; 约翰福音 19:23–24; 出埃及记 39:28"> 袍子中间要有一个领口，领口周围要有织成的边，好像铠甲的领口，免得撕裂。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 39:24–26; 撒迦利亚书 14:20; 列王纪上 7:18"> 你要在袍子底边四周，用蓝色线、紫色线、朱红色线制作石榴；在石榴之间，四周要有金铃铛：</span>
<span className="v" id="v34" data-v="34" data-xref="雅歌 8:2; 约翰福音 15:4–8; 歌罗西书 1:10"> 一个金铃铛一个石榴，一个金铃铛一个石榴，围绕在外袍的底边上。</span>
<span className="v" id="v35" data-v="35" data-xref="希伯来书 9:12; 利未记 16:2"> 亚伦供职的时候要穿上；他进圣所到耶和华面前，以及出来的时候，铃铛的声音都要被听见，免得他死亡。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="撒迦利亚书 14:20; 利未记 8:9; 出埃及记 39:30"> “你要制作一面纯金牌，像刻印章一样，在上面刻着：‘归耶和华为圣。’</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及记 29:6; 出埃及记 28:4; 撒迦利亚书 3:5"> 你要用蓝色细绳把它系在礼冠上；它要在礼冠的前面。</span>
<span className="v" id="v38" data-v="38" data-xref="彼得前书 2:24; 民数记 18:1; 利未记 10:17"> 它要在亚伦的额上；亚伦要担当圣物的罪孽，就是以色列人在一切分别为圣的礼物中所献为圣的；它要常在他的额上，使他们在耶和华面前蒙悦纳。</span>
<span className="v" id="v39" data-v="39" data-xref="诗篇 45:14"> 你要用细麻织内袍。你要用细麻制作礼冠。你要制作腰带，是刺绣工的手工。</span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="出埃及记 39:41; 出埃及记 28:4; 出埃及记 28:2"> “你要为亚伦的儿子们制作内袍；要为他们制作腰带；也要为他们制作头巾，使他们得荣耀和华美。</span>
<span className="v" id="v41" data-v="41" data-xref="出埃及记 29:7; 利未记 8:1–36; 出埃及记 40:15"> 你要把这些穿戴在你的哥哥亚伦和与他同在的儿子们身上，并膏他们，授予他们职分，使他们分别为圣，好叫他们作祭司事奉我。</span>
<span className="v" id="v42" data-v="42" data-xref="以西结 44:18; 利未记 6:10; 利未记 16:4"> 你要为他们制作细麻裤子，遮盖他们赤裸的肉体；裤子要从腰部直到大腿。</span>
<span className="v" id="v43" data-v="43" data-xref="出埃及记 27:21; 出埃及记 20:26; 利未记 5:17"> 亚伦和他的儿子们进会幕，或就近祭坛在圣所供职的时候，都要穿上，免得他们担当罪孽而死亡。这要作他和他以后的后裔永远的条例。”</span>
</div>
</div>

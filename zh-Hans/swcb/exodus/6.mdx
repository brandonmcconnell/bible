<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 12:33; 出埃及记 12:31; 出埃及记 3:19–20"> 耶和华对摩西说：“现在你要看见我将怎样对待法老；因为因着大能的手，他必让他们离去；因着大能的手，他必把他们赶出他的地。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="耶利米书 9:24; 玛拉基书 3:6; 使徒行传 17:24–25"> 上帝对摩西说：“我是耶和华。</span>
<span className="v" id="v3" data-v="3" data-xref="诗篇 83:18; 诗篇 68:4; 创世记 17:1"> 我曾以全能的上帝向亚伯拉罕、以撒、雅各显现；但至于我的名耶和华<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="LORD 或 GOD 全部大写时，均出自希伯来文 יהוה Yahweh（耶和华），除非另有说明是出自其短式 יה Yah。">a</a></sup>，我未曾使他们这样认识我。</span>
<span className="v" id="v4" data-v="4" data-xref="创世记 28:4; 创世记 15:18; 创世记 17:7–8"> 我也与他们立了我的约，要把迦南地，就是他们寄居、作客旅之地，赐给他们。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 2:24; 诗篇 106:44–45; 以赛亚书 63:9"> 此外，我听见了以色列子孙的呻吟，就是埃及人使他们服苦役所发的呻吟；我也记念我的约。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 26:8; 历代志上 17:21; 出埃及记 7:4"> 所以你要告诉以色列子孙：‘我是耶和华；我要把你们从埃及人的重担下领出来，使你们脱离他们的苦役；我要用伸出来的膀臂和重大的审判救赎你们。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 7:6; 申命记 29:13; 申命记 4:20"> 我要以你们为我的子民；我要作你们的上帝；你们就知道我是耶和华你们的上帝，是把你们从埃及人的重担下领出来的。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 26:3; 创世记 15:18; 以西结 20:42"> 我要把你们带进我起誓要赐给亚伯拉罕、以撒、雅各的那地；我要把那地赐给你们为产业：我是耶和华。’”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 5:21; 约伯记 21:4; 出埃及记 14:12"> 摩西这样告诉以色列子孙，可是他们因心灵痛苦，又因苦役残酷，就不听摩西。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10"> 耶和华对摩西说：</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 6:29; 出埃及记 5:23; 出埃及记 3:10"> “你进去对埃及王法老说，要他让以色列子孙离开他的地。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及记 4:10; 耶利米书 1:6; 出埃及记 6:30"> 摩西在耶和华面前说：“看哪，以色列子孙尚且不听我，法老怎会听我呢？何况我是嘴唇未受割礼的人。”</span>
<span className="v" id="v13" data-v="13" data-xref="民数记 27:23; 提摩太前书 6:13; 诗篇 91:11"> 耶和华对摩西和亚伦说话，吩咐他们到以色列子孙那里，也到埃及王法老那里，要把以色列子孙从埃及地领出来。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="创世记 46:9; 历代志上 5:3; 民数记 26:5–7"> 以下是他们父家的族长。以色列长子流便的儿子：哈诺、法路、希斯伦、迦米；这些是流便的各家族。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 4:24; 创世记 46:10; 民数记 26:12–13"> 西缅的儿子：耶母利、雅悯、阿辖、雅斤、琐辖，以及迦南女子所生的儿子扫罗；这些是西缅的各家族。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 3:17; 创世记 46:11; 历代志上 6:1"> 以下是利未的儿子按他们世代的名字：革顺、哥辖、米拉利；利未一生的年日是一百三十七年。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 6:17; 民数记 3:18; 历代志上 23:7"> 革顺的儿子：立尼、示每，按着他们的家族。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 6:18; 历代志上 6:2; 民数记 3:19"> 哥辖的儿子：暗兰、以斯哈、希伯伦、乌薛；哥辖一生的年日是一百三十三年。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 3:20; 历代志上 23:21; 历代志上 6:19"> 米拉利的儿子：抹利、母示。这些是利未人的各家族，按着他们的世代。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 26:59; 出埃及记 2:1–2; 出埃及记 6:18"> 暗兰娶了他父亲的妹妹约基别为妻；她给他生了亚伦和摩西。暗兰一生的年日是一百三十七年。</span>
<span className="v" id="v21" data-v="21" data-xref="民数记 16:1; 历代志上 6:37–38; 民数记 16:32"> 以斯哈的儿子：可拉、尼斐、细基利。</span>
<span className="v" id="v22" data-v="22" data-xref="利未记 10:4; 民数记 3:30; 尼希米记 3:20"> 乌薛的儿子：米沙利、以利撒反、西提利。</span>
<span className="v" id="v23" data-v="23" data-xref="路得记 4:19–20; 民数记 2:3; 民数记 1:7"> 亚伦娶了亚米拿达的女儿、拿顺的妹妹以利沙巴为妻；她给他生了拿答、亚比户、以利亚撒、以他玛。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 6:22–23; 民数记 16:1; 撒母耳记上 1:1"> 可拉的儿子：亚惜、以利加拿、亚比亚撒；这些是可拉人的各家族。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 24:33; 民数记 25:7–13; 约书亚记 22:31–32"> 亚伦的儿子以利亚撒娶了普铁的一个女儿为妻；她给他生了非尼哈。这些是利未人父家的族长，按着他们的家族。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 12:51; 出埃及记 12:17; 出埃及记 7:4"> 耶和华曾对这亚伦和摩西说：“要按着以色列子孙的军队，把他们从埃及地领出来。”</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 6:26; 出埃及记 7:10; 诗篇 77:20"> 向埃及王法老说话、要把以色列子孙从埃及领出来的，就是这摩西和亚伦。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 当耶和华在埃及地对摩西说话的那日，</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 6:11; 出埃及记 7:2; 出埃及记 6:2"> 耶和华对摩西说：“我是耶和华。凡我告诉你的，你都要告诉埃及王法老。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及记 6:12; 出埃及记 4:10; 哥林多前书 9:16–17"> 摩西在耶和华面前说：“看哪，我是嘴唇未受割礼的人，法老怎会听我呢？”</span>
</div>

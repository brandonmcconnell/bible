<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华在埃及地对摩西和亚伦说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 13:4; 申命记 16:1; 出埃及记 34:18"> “你们要以本月为众月之首；对你们来说，这要作为一年的第一个月。</span>
<span className="v" id="v3" data-v="3" data-xref="利未记 1:2; 哥林多前书 5:7; 约翰福音 1:29"> 你们要告诉以色列全会众说：『本月初十日，各人要按父家取一只羊羔，一家一只羊羔；</span>
<span className="v" id="v4" data-v="4"> 如果一家的人太少，吃不了一只羊羔，他就要和隔壁的邻舍按人数合取一只；你们要按每个人的食量来计算所需的羊羔。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得前书 1:18–19; 希伯来书 9:13–14; 玛拉基书 1:14"> 你们的羊羔要没有残疾，是一岁的公羊；你们可以从绵羊或山羊中取。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 23:5; 历代志下 30:15–18; 民数记 28:16"> 你们要把它留到本月十四日；以色列全会众要在黄昏时宰杀它。</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 11:28; 出埃及记 12:22–23; 希伯来书 9:22"> 他们要取一些血，抹在吃羊羔的房屋两边的门柱和门楣上。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 34:25; 申命记 16:7; 出埃及记 13:3"> 当夜他们要吃羊羔的肉，用火烤了，和无酵饼一起吃；也要和苦菜一起吃。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 12:8; 申命记 16:7; 耶利米哀歌 1:13"> 不可吃生的，也不可用水煮，一定要用火烤；连头、腿和内脏一起烤。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 23:18; 出埃及记 34:25; 出埃及记 29:34"> 不可让一点留到早晨；若有留到早晨的，要用火烧掉。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 12:27; 以弗所书 6:15; 哥林多前书 5:7"> 你们要这样吃：腰间束带，脚上穿鞋，手中拿杖；你们要急忙地吃。这是耶和华的逾越节。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 33:4; 出埃及记 12:23; 诗篇 82:6"> 因为那夜我要走遍埃及地，击杀埃及地所有头生的，无论是人是牲畜；我也要向埃及一切神明施行审判。我是耶和华。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 11:28; 出埃及记 12:23; 约翰一书 1:7"> 这血要在你们所在的房屋上作你们的记号；我看见这血，就越过你们。我击打埃及地的时候，灾殃必不临到你们毁灭你们。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪下 23:21; 出埃及记 12:24; 出埃及记 13:9–10"> 这日要作你们的纪念日；你们要守这日为耶和华的节。你们要按永远的条例，世世代代守这节。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="创世记 17:14; 申命记 16:3; 出埃及记 23:15"> 七天之内，你们要吃无酵饼；第一天就要把酵从你们家中除去。因为从第一天到第七天，凡吃有酵之饼的人，那人必从以色列中剪除。</span>
<span className="v" id="v16" data-v="16" data-xref="利未记 23:7–8; 民数记 28:18; 出埃及记 16:23"> 第一日你们要有圣会，第七日也要有圣会；这两日，任何工作都不可做，惟有每个人必须吃的食物，可以由你们预备。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 7:5; 出埃及记 13:3; 出埃及记 12:41"> 你们要守无酵节，因为正是在这一天，我把你们的队伍从埃及地领了出来。因此，你们要按永远的条例，世世代代守这日。</span>
<span className="v" id="v18" data-v="18" data-xref="利未记 23:5–8; 出埃及记 12:15; 出埃及记 12:1–2"> 正月十四日傍晚，你们要吃无酵饼，直到本月二十一日傍晚。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 12:15; 出埃及记 23:15; 申命记 16:3"> 七天之内，在你们家中不可发现有酵；因为凡吃发了酵之物的人，无论是寄居者，还是本地出生的人，那人必从以色列会众中剪除。</span>
<span className="v" id="v20" data-v="20"> 凡有酵的东西，你们都不可吃；在你们一切住处，你们都要吃无酵饼。』”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及记 12:3; 路加福音 22:7–13; 历代志下 35:5–6"> 于是摩西召来以色列所有的长老，对他们说：“你们要按各家牵出并取羊羔，宰逾越节的羊羔。</span>
<span className="v" id="v22" data-v="22" data-xref="希伯来书 11:28; 民数记 19:18; 诗篇 51:7"> 你们要拿一束牛膝草，蘸盆里的血，把盆里的血抹在门楣和两边的门柱上。你们谁也不可出自己的房门，直到早晨。</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 7:3; 启示录 9:4; 希伯来书 11:28"> 因为耶和华要经过，击打埃及人；祂看见门楣和两边门柱上的血，就会越过那门，不容灭命者进你们的房屋击杀你们。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 12:14; 创世记 17:8–10"> 你们要守这事，作为你和你子孙永远的条例。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 3:17; 出埃及记 3:8; 申命记 12:8–9"> 将来你们进了耶和华照祂应许要赐给你们的地，就要守这项礼仪。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 13:14–15; 申命记 32:7; 诗篇 145:4"> 当你们的儿女问你们：『你们行这项礼仪是什么意思？』</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 4:31; 出埃及记 12:11; 哥林多前书 5:7"> 你们就要说：『这是献给耶和华的逾越节祭；祂在埃及击杀埃及人的时候，越过以色列人的房屋，救了我们的家。』”<br />百姓低头敬拜。</span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 11:28"> 以色列人就去照样做；耶和华怎样吩咐摩西和亚伦，他们就怎样做。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="诗篇 78:51; 出埃及记 4:23; 诗篇 105:36"> 到了半夜，耶和华击杀埃及地所有头生的，从坐在宝座上的法老的长子，直到地牢中被囚之人的长子，以及所有头生的牲畜。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 11:6; 阿摩司 5:17; 箴言 21:13"> 法老和他所有臣仆，以及所有埃及人，夜里都起来了；埃及中有大哀号，因为没有一家不死人的。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 6:1; 出埃及记 10:9; 出埃及记 3:19–20"> 夜里，法老召摩西和亚伦来，说：“起来！你们和以色列人都从我民中出去吧！照你们所说的，去事奉耶和华！</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 10:26; 创世记 27:34; 创世记 27:38"> 也照你们所说的，带着你们的羊群牛群走吧！也为我祝福！”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="诗篇 105:38; 出埃及记 11:1; 创世记 20:3"> 埃及人催促百姓，要他们赶快离开那地，因为他们说：“我们都要死了。”</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 8:3"> 百姓把还没有发酵的面团，连同和面盆包在衣服里，扛在肩上。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及记 3:21–22; 出埃及记 11:2–3; 创世记 15:14"> 以色列人照摩西的话做，向埃及人索要银器、金器和衣服。</span>
<span className="v" id="v36" data-v="36" data-xref="创世记 15:14; 使徒行传 7:10; 出埃及记 3:21–22"> 耶和华使百姓在埃及人眼前蒙恩，以致埃及人把他们所要的给了他们。他们就掠夺了埃及人。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="民数记 1:46; 出埃及记 38:26; 民数记 33:3"> 以色列人从兰塞起行，到了疏割；除了孩子以外，步行的男子约有六十万。</span>
<span className="v" id="v38" data-v="38" data-xref="民数记 11:4; 撒迦利亚书 8:23"> 还有许多杂族人也和他们一同上去，并有羊群、牛群，牲畜非常多。</span>
<span className="v" id="v39" data-v="39" data-xref="出埃及记 11:1; 出埃及记 6:1; 出埃及记 12:31–33"> 他们把从埃及带出来的面团烤成无酵饼，因为面团还没有发酵；他们被催逼离开埃及，不能耽延，也没有为自己预备食物。</span>
<span className="v" id="v40" data-v="40" data-xref="创世记 15:13; 使徒行传 7:6; 使徒行传 13:17"> 以色列人住在埃及的时间，共有四百三十年。</span>
<span className="v" id="v41" data-v="41" data-xref="哈巴谷 2:3; 约翰福音 7:8; 使徒行传 1:7"> 四百三十年结束的那一天，耶和华的众队伍都从埃及地出来了。</span>
<span className="v" id="v42" data-v="42" data-xref="申命记 16:1–6; 出埃及记 12:14; 出埃及记 13:10"> 这是应当为耶和华郑重守望的一夜，因为祂把他们从埃及地领了出来；这就是耶和华的那一夜，以色列众人世世代代都应当郑重守望。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="出埃及记 12:48; 民数记 9:14; 出埃及记 12:11"> 耶和华对摩西和亚伦说：“逾越节的条例是这样：任何外邦人都不可吃这祭牲；</span>
<span className="v" id="v44" data-v="44" data-xref="创世记 17:12–13; 创世记 17:23"> 但各人用银钱买来的仆人，你给他行了割礼以后，他就可以吃。</span>
<span className="v" id="v45" data-v="45" data-xref="利未记 22:10; 以弗所书 2:12"> 寄居者和雇工不可吃。</span>
<span className="v" id="v46" data-v="46" data-xref="民数记 9:12; 约翰福音 19:36; 约翰福音 19:33"> 要在一所房子里吃；不可把一点肉带到房子外面，也不可折断它一根骨头。</span>
<span className="v" id="v47" data-v="47" data-xref="出埃及记 12:6; 民数记 9:13; 出埃及记 12:3"> 以色列全会众都要守这节。</span>
<span className="v" id="v48" data-v="48" data-xref="民数记 9:14; 歌罗西书 3:11; 加拉太书 3:28"> 若有寄居者在你们中间寄居，愿意向耶和华守逾越节，他所有的男子都要受割礼，然后他才可以近前来守这节。他要像本地出生的人一样；但没有受割礼的人都不可吃这祭牲。</span>
<span className="v" id="v49" data-v="49" data-xref="民数记 15:15–16; 民数记 15:29; 利未记 24:22"> 本地出生的人和在你们中间寄居的寄居者，都要同归一条律法。”</span>
<span className="v" id="v50" data-v="50" data-xref="马太福音 7:24–25; 出埃及记 6:26; 出埃及记 7:4"> 以色列众人都照样做；耶和华怎样吩咐摩西和亚伦，他们就怎样做。</span>
<span className="v" id="v51" data-v="51" data-xref="出埃及记 12:41; 出埃及记 6:26"> 就在那一天，耶和华按着以色列人的队伍，把他们从埃及地领了出来。</span>
</div>
</div>

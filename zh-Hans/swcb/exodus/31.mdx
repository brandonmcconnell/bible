<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 36:1; 出埃及记 35:30; 约翰福音 3:27"> “看哪，我已经按名召了犹大支派中户珥的孙子、乌利的儿子比撒列。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 35:31; 以赛亚书 28:26; 列王纪上 7:14"> 我以上帝的灵充满他，使他有智慧、聪明、知识，能做各样的工艺，</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 26:1; 出埃及记 25:32–35; 历代志下 2:13–14"> 能设计巧工，用金、银、铜制作，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 28:9–21"> 又能切割宝石来镶嵌，雕刻木头，做各样的工艺。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 35:10; 出埃及记 35:34–1; 出埃及记 28:3"> 看哪，我亲自任命但支派中亚希撒抹的儿子亚何利亚伯与他同工；凡心中有智慧的人，我已把智慧放在他们心里，使他们能做我所吩咐你的一切：</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 36:8–9; 出埃及记 25:10–22; 出埃及记 26:1–37"> 会幕、约柜、柜上的施恩座、会幕的一切器具，</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 37:10–28; 出埃及记 30:1–10; 出埃及记 25:23–40"> 桌子和桌子的器具、纯金灯台和灯台的一切器具、香坛，</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 38:1–8; 出埃及记 27:1–8; 出埃及记 40:11"> 燔祭坛和坛的一切器具、洗濯盆和盆座，</span>
<span className="v" id="v10" data-v="10" data-xref="民数记 4:5–14; 出埃及记 28:1–43; 出埃及记 39:1–43"> 精工制作的衣服——祭司亚伦的圣衣，以及他儿子们供祭司职分用的衣服——</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 37:29; 出埃及记 30:23–38"> 膏油和圣所用的馨香之香；他们都要照我所吩咐你的一切去做。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12"> 耶和华对摩西说：</span>
<span className="v" id="v13" data-v="13" data-xref="以西结 20:12; 以西结 20:20; 利未记 19:30"> “你也要对以色列人说：‘你们务要守我的安息日；因为这是我与你们之间世世代代的记号，使你们知道我是使你们分别为圣的耶和华。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 35:2–3; 民数记 15:32–36; 以西结 20:21"> 所以你们要守安息日，因为这日对你们是圣的。凡亵渎这日的，必被处死；凡在这日做任何工的，那人必从他民中被剪除。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 2:2; 出埃及记 16:23; 利未记 23:3"> 六日可以做工，但第七日是完全安息的安息日，归耶和华为圣。凡在安息日做任何工的，必被处死。</span>
<span className="v" id="v16" data-v="16" data-xref="耶利米书 50:5; 创世记 9:13; 创世记 17:11"> 因此，以色列人要守安息日，世世代代遵守安息日，作为永远的约。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 1:31; 出埃及记 31:13; 创世记 2:2–3"> 这是我与以色列人之间永远的记号；因为六日之内，耶和华造了天和地，第七日祂安息了，并且得了舒畅。’”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命记 4:13; 出埃及记 32:15–16; 申命记 5:22"> 耶和华在西奈山与摩西说完话，就把两块约版，就是石版，交给摩西；那是用上帝的指头写的。</span>
</div>

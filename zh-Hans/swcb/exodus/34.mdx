<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 32:19; 出埃及记 31:18; 诗篇 119:89"> 耶和华对摩西说：“你要凿出两块石版，像先前的一样。我要把先前那些版上的话，就是你摔碎的那些版上的话，写在这两块版上。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 19:20; 申命记 9:25; 出埃及记 19:11"> 到了早晨，你要准备好，早晨上西奈山，在山顶那里到我面前来。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 19:12–13; 出埃及记 19:21; 提摩太前书 2:5"> 不可有人和你一同上来，也不可让人在山上任何地方被看见；也不可让羊群或牛群在那山前吃草。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 摩西就凿出两块石版，像先前的一样；清早起来，照耶和华所吩咐他的，上西奈山去，手里拿着两块石版。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 33:19; 民数记 11:25; 路加福音 9:34–35"> 耶和华在云中降临，和他一同站在那里，宣告耶和华<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="全大写的 LORD 或 GOD 来自希伯来文 יהוה Yahweh，除非另有说明是来自短式 יה Yah。">a</a></sup>的名。</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 86:15; 约珥 2:13; 诗篇 103:8–13"> 耶和华从他面前经过，宣告说：“耶和华！耶和华，有怜悯、有恩典的上帝，不轻易发怒，并且有丰盛的慈爱和信实，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 20:5–6; 诗篇 103:3; 申命记 5:9–10"> 为千代存留慈爱，赦免罪孽、悖逆和罪；却绝不以有罪的为无罪，必追讨父亲的罪孽，临到儿女和儿女的儿女，直到三四代。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 4:31; 历代志下 20:18; 创世记 17:3"> 摩西急忙俯伏在地，敬拜。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 33:12; 申命记 32:9; 诗篇 94:14"> 他说：“主啊，我若在你眼前蒙恩，求主在我们中间同行，虽然这是硬着颈项的百姓；求你赦免我们的罪孽和我们的罪，并以我们为你的产业。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命记 10:21; 诗篇 77:14; 以赛亚书 64:3"> 祂说：“看哪，我要立约：我要在你全体百姓面前行奇事，是在全地、在万国中未曾行过的；你所在的全体百姓都要看见耶和华的作为，因为我与你所行的是可畏的事。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 33:2; 出埃及记 3:17; 出埃及记 3:8"> 你要谨守我今日吩咐你的。看哪，我要从你面前赶出亚摩利人、迦南人、赫人、比利洗人、希未人和耶布斯人。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 23:32–33; 约书亚记 23:12–13; 申命记 7:2"> 你要谨慎，免得与你所去那地的居民立约，免得这约成为你们中间的网罗；</span>
<span className="v" id="v13" data-v="13" data-xref="列王纪下 18:4; 出埃及记 23:24; 申命记 7:25–26"> 你们却要拆毁他们的祭坛，打碎他们的柱像，砍下他们的亚舍拉木柱；</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 4:24; 申命记 32:21; 哥林多前书 10:22"> 因为你不可敬拜别的神；因为耶和华的名为『忌邪』，祂是忌邪的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="士师记 2:17; 诗篇 106:28; 民数记 25:2"> “不可与那地的居民立约，免得他们随从自己的神行淫，向自己的神献祭，有人邀请你，你就吃他的祭物；</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 7:3–4; 列王纪上 11:2–4; 以斯拉记 9:2"> 又免得你为你的儿子娶他们的女儿，而她们的女儿随从自己的神行淫，并使你的儿子随从她们的神行淫。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="利未记 19:4; 出埃及记 32:8; 以赛亚书 46:6–7"> “你们不可为自己铸造偶像。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 13:4; 利未记 23:6; 出埃及记 13:6–7"> “你要守除酵节。照我所吩咐你的，在亚笔月所定的时候，你要吃无酵饼七天；因为你是在亚笔月出了埃及。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及记 13:2; 出埃及记 22:29; 出埃及记 13:12"> “凡头生开母胎的都是我的；你牲畜中一切公的，就是牛羊头生的，也是我的。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 13:13; 出埃及记 23:15; 申命记 16:16"> 驴头生的，你要用羊羔赎回；若不赎回，就要折断它的颈项。你所有头生的儿子都要赎回。谁也不可空手朝见我。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及记 23:12; 申命记 21:4; 路加福音 13:14"> “六日你要做工，第七日要安息；耕种的时候和收割的时候也要安息。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及记 23:16; 申命记 16:10–15; 约翰福音 7:2"> “你要在收小麦初熟果子的时候守七七节，并在年底守收获节。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 23:14; 申命记 16:16; 出埃及记 23:17"> 一年三次，你所有的男丁都要朝见主耶和华，以色列的上帝。</span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 78:55; 出埃及记 33:2; 箴言 16:7"> 因为我要从你面前赶出列国，扩张你的疆界；你一年三次上去朝见耶和华你的上帝的时候，也没有人会觊觎你的土地。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="出埃及记 23:18; 出埃及记 12:10; 哥林多前书 5:7–8"> “你不可把我祭物的血和有酵的饼一同献上。逾越节的祭物不可留到早晨。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 23:19; 申命记 14:21; 申命记 26:2"> “你要把你地里最初熟的土产带到耶和华你上帝的殿。<br />“不可用母山羊的奶煮小山羊。”</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="出埃及记 24:4; 申命记 31:9; 申命记 4:13"> 耶和华对摩西说：“你要写下这些话；因为我是照这些话与你和以色列立约。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="出埃及记 34:1; 出埃及记 24:18; 申命记 9:18"> 摩西在那里与耶和华同在四十昼夜；他既不吃饼，也不喝水。他把约的话，就是十条诫命，写在版上。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马太福音 17:2; 路加福音 9:29; 出埃及记 32:15"> 摩西从西奈山下来，手里拿着两块约版；他下山的时候，摩西不知道自己的脸皮因他与耶和华说话而发光。</span>
<span className="v" id="v30" data-v="30" data-xref="马可福音 9:3; 路加福音 5:8; 民数记 12:8"> 亚伦和以色列众人看见摩西，看哪，他脸上的皮肤发光；他们就害怕，不敢近前来。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 3:15; 出埃及记 24:1–3; 创世记 45:3"> 摩西呼唤他们，于是亚伦和会众所有的首领都回到他那里；摩西就和他们说话。</span>
<span className="v" id="v32" data-v="32" data-xref="列王纪上 22:14; 出埃及记 24:3; 马太福音 28:20"> 以后，以色列众人也近前来，他就把耶和华在西奈山与他所说的一切命令都吩咐他们。</span>
<span className="v" id="v33" data-v="33" data-xref="哥林多后书 4:4–6; 哥林多后书 3:13–18; 罗马书 10:4"> 摩西和他们说完话，就把帕子蒙在脸上。</span>
<span className="v" id="v34" data-v="34" data-xref="哥林多后书 3:16; 希伯来书 10:19–22; 希伯来书 4:16"> 但摩西进去到耶和华面前与祂说话的时候，就揭去帕子，直到出来；他出来后，就把所领受的命令告诉以色列人。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及记 34:29–30; 约翰福音 5:35; 但以理 12:3"> 以色列人看见摩西的脸，见摩西脸上的皮肤发光；摩西就再把帕子蒙在脸上，直到他进去与耶和华说话。</span>
</div>

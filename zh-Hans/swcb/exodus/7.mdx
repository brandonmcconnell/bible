<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 4:15–16; 诗篇 82:6; 约翰福音 10:35–36"> 耶和华对摩西说：“看哪，我使你在法老面前如同上帝；你的哥哥亚伦要作你的先知。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 4:15; 出埃及记 6:29; 申命记 4:2"> 凡我命令你的，你都要说；你的哥哥亚伦要对法老说，好让他准以色列子孙离开他的地。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 4:21; 出埃及记 11:9; 诗篇 105:27–36"> 我要使法老的心刚硬，并在埃及地增多我的神迹和奇事。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 11:9; 出埃及记 6:6; 出埃及记 12:51"> 但法老不会听从你们，所以我要把我的手加在埃及，用重大的审判把我的军队，就是我的子民以色列子孙，从埃及地领出来。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 14:18; 出埃及记 7:17; 出埃及记 8:22"> 当我向埃及伸手，把以色列子孙从他们中间领出来的时候，埃及人就知道我是耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 7:2; 创世记 6:22; 出埃及记 7:10"> 摩西和亚伦就这样做了；耶和华怎样命令他们，他们就怎样做。</span>
<span className="v" id="v7" data-v="7" data-xref="申命记 34:7; 使徒行传 7:30; 申命记 31:2"> 摩西和亚伦对法老说话的时候，摩西八十岁，亚伦八十三岁。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8"> 耶和华对摩西和亚伦说：</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 4:2; 约翰福音 2:18; 以赛亚书 7:11"> “法老对你们说：‘行一个奇迹吧！’那时你要告诉亚伦：‘拿你的杖，扔在法老面前，它就会变成蛇。’”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="出埃及记 4:3; 路加福音 10:19; 阿摩司 9:3"> 摩西和亚伦进去见法老，照耶和华所命令的做了。亚伦把他的杖扔在法老和他臣仆面前，杖就变成了蛇。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 7:22; 提摩太后书 3:8; 出埃及记 8:18"> 于是法老也召来智者和术士；埃及的术士们也用他们的法术做了同样的事。</span>
<span className="v" id="v12" data-v="12" data-xref="约翰一书 4:4; 出埃及记 9:11; 出埃及记 8:18–19"> 他们各人都扔下自己的杖，杖就变成了蛇；但亚伦的杖吞了他们的杖。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 4:21; 出埃及记 8:15; 撒迦利亚书 7:11–12"> 法老的心刚硬，不听从他们，正如耶和华所说的。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及记 10:20; 出埃及记 8:15; 出埃及记 10:1"> 耶和华对摩西说：“法老的心顽固，他拒绝让百姓离开。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 8:20; 出埃及记 2:5; 出埃及记 7:10"> 明早你要去见法老。看哪，他要出去到水边。你要站在河岸上迎见他，手里要拿着那根曾变成蛇的杖。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 3:18; 出埃及记 9:1; 出埃及记 9:13"> 你要对他说：‘耶和华，希伯来人的上帝，差我到你这里来，说：“放我的子民走，好让他们在旷野事奉我。看哪，直到现在你还没有听从。”</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 4:9; 出埃及记 5:2; 出埃及记 7:5"> 耶和华这样说：“凭这事，你就知道我是耶和华。看哪，我要用我手中的杖击打河里的水，水就会变成血。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 7:24; 出埃及记 7:21; 民数记 11:20"> 河里的鱼会死，河也会发臭；埃及人必厌恶喝这河里的水。”’”</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 14:21; 出埃及记 10:12; 出埃及记 8:5–6"> 耶和华对摩西说：“告诉亚伦：‘拿你的杖，向埃及的水伸出你的手，向他们的河流、水道、池塘和一切水池伸手，使这些水都变成血。在埃及全地，无论木器里、石器里，都必有血。’”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="诗篇 78:44; 诗篇 105:29; 出埃及记 7:17–18"> 摩西和亚伦照耶和华所命令的做了；他在法老和他臣仆眼前举起杖，击打河里的水，河里所有的水都变成了血。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 7:18; 启示录 8:9"> 河里的鱼死了，河也发臭，埃及人不能喝河里的水；血遍满埃及全地。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 7:11; 提摩太后书 3:8; 耶利米书 27:18"> 埃及的术士们也用他们的法术做了同样的事。于是法老的心刚硬，不听从他们，正如耶和华所说的。</span>
<span className="v" id="v23" data-v="23" data-xref="耶利米书 36:24; 以西结 40:4; 玛拉基书 2:2"> 法老转身回到自己的宫里，连这事也不放在心上。</span>
<span className="v" id="v24" data-v="24"> 所有埃及人在河的周围挖地找水喝，因为他们不能喝河里的水。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 10:23; 出埃及记 8:9–10; 撒母耳记下 24:13"> 耶和华击打河以后，满了七天。</span>
</div>

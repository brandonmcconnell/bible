<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 7:40; 申命记 9:9; 出埃及记 24:18"> 百姓见摩西迟迟没有从山上下来，就聚集到亚伦那里，对他说：“来，为我们造神明，好在我们前面引路；至于这个摩西，就是把我们从埃及地领上来的人，我们不知道他遭遇了什么事。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="士师记 8:24–27; 出埃及记 12:35–36; 以西结 16:17"> 亚伦对他们说：“你们妻子、儿子、女儿耳上的金环，都摘下来，拿给我。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 46:6; 以赛亚书 40:19–20; 耶利米书 10:9"> 众百姓就把他们耳上的金环摘下来，拿给亚伦。</span>
<span className="v" id="v4" data-v="4" data-xref="尼希米记 9:18; 申命记 9:16; 列王纪上 12:28"> 亚伦从他们手中接过来，用雕刻工具塑成形状，做成一只铸造的牛犊。他们就说：“以色列啊，这些就是你的神明，是它们把你从埃及地领上来的。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="列王纪下 10:20; 利未记 23:2; 利未记 23:37"> 亚伦看见了，就在牛犊前筑了一座坛；亚伦宣告说：“明天要向耶和华守节。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 10:7; 民数记 25:2; 使徒行传 7:41–42"> 第二天，他们清早起来，献上燔祭，又献上平安祭；百姓坐下吃喝，起来玩乐。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 32:11; 何西阿 9:9; 士师记 2:19"> 耶和华对摩西说：“去，下去吧；因为你的百姓，就是你从埃及地领上来的，已经败坏了自己！</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 12:28; 出埃及记 20:23; 出埃及记 20:3–4"> 他们很快就偏离了我所吩咐他们的道路。他们为自己造了一只铸造的牛犊，敬拜它，向它献祭，并且说：‘以色列啊，这些就是你的神明，是它们把你从埃及地领上来的。’”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 7:51; 申命记 9:13; 以赛亚书 48:4"> 耶和华对摩西说：“我看见这百姓了。看哪，他们是硬着颈项的百姓。</span>
<span className="v" id="v10" data-v="10" data-xref="申命记 9:14; 民数记 14:12; 申命记 9:19"> 现在，你不要拦阻我，让我的怒气向他们发作，好灭绝他们；我要使你成为大国。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="申命记 9:18–20; 申命记 9:26–29; 诗篇 106:23"> 摩西恳求耶和华他的上帝，说：“耶和华啊，祢为什么向祢的百姓发烈怒呢？这百姓是祢用大能和大力的手从埃及地领出来的。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 14:13–16; 申命记 9:28; 约书亚记 7:9"> 为什么让埃及人议论说：‘祂把他们领出来，是要加害他们，在山中杀他们，把他们从地面上灭绝’？求祢转离祢的烈怒，回心转意，不把这灾祸降给祢的百姓。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 6:13; 创世记 12:7; 创世记 22:16"> 求祢记念祢的仆人亚伯拉罕、以撒和以色列，祢曾指着自己向他们起誓，对他们说：‘我要使你们的后裔<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：“种子”">a</a></sup>多如天上的星；我所说的这一切土地，我都要赐给你们的后裔，他们要永远承受为业。’”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="约拿 3:10; 诗篇 106:45; 耶利米书 26:13"> 于是耶和华转意，不把祂说要降给祂百姓的灾祸降下。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命记 9:15; 出埃及记 40:20; 申命记 5:22"> 摩西转身下山，手里拿着两块约版；版的两面都写着字，这面那面都有字。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 31:18; 希伯来书 8:10; 申命记 10:1"> 版是上帝的工作，字是上帝的字，刻在版上。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="出埃及记 24:13; 出埃及记 17:9; 约书亚记 6:20"> 约书亚听见百姓呼喊的声音，就对摩西说：“营里有战争的声音。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 15:1–18; 但以理 5:4; 但以理 5:23"> 他说：“这不是得胜者呼喊的声音，也不是战败者哀号的声音；我所听见的乃是歌唱的声音。”</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 9:16–17; 耶利米书 31:32; 耶利米哀歌 5:15"> 摩西一走近营，就看见牛犊和跳舞，怒气便发作，把两块版从手中扔出去，在山下摔碎了。</span>
<span className="v" id="v20" data-v="20" data-xref="申命记 9:21; 列王纪下 23:6; 列王纪下 23:15"> 他拿起他们所造的牛犊，用火焚烧，磨成粉末，撒在水面上，叫以色列人喝。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="创世记 20:9; 约书亚记 7:19–26; 列王纪上 21:22"> 摩西对亚伦说：“这百姓对你做了什么，以致你使他们犯了大罪？”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命记 9:24; 出埃及记 15:24; 出埃及记 16:20"> 亚伦说：“请我主不要发烈怒。你知道这百姓，他们是倾向邪恶的。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 32:1–4; 出埃及记 32:8"> 他们对我说：‘为我们造神明，好在我们前面引路。至于这个摩西，就是把我们从埃及地领上来的人，我们不知道他遭遇了什么事。’</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 32:4; 路加福音 10:29; 罗马书 3:10"> 我就对他们说：‘凡有金子的，都摘下来。’他们就把金子给了我；我把它扔进火里，这只牛犊就出来了。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 47:3; 弥迦书 1:11; 启示录 16:15"> 摩西见百姓失控了，（因为亚伦放任他们失控，使他们在仇敌中被讥笑，）</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 9:32; 马太福音 12:30; 撒母耳记下 20:11"> 摩西就站在营门口，说：“凡属耶和华的，都到我这里来！”<br />利未的众子都聚集到他那里。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 25:5; 路加福音 14:26; 申命记 33:8–9"> 他对他们说：“耶和华以色列的上帝这样说：‘各人把刀佩在腰间，在营中从这门到那门来回走遍，各人要杀自己的弟兄，各人要杀自己的同伴，各人要杀自己的邻舍。’”</span>
<span className="v" id="v28" data-v="28" data-xref="申命记 33:9; 玛拉基书 2:4–6; 哥林多前书 10:8"> 利未的子孙照摩西的话做了。那一天，百姓中约有三千人倒下。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 25:11–13; 马太福音 10:37; 撒迦利亚书 13:3"> 摩西说：“今天你们要把自己分别为圣归给耶和华，因为各人都对付了自己的儿子和弟兄，好叫祂今日赐福给你们。”</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="撒母耳记上 12:20; 民数记 25:13; 列王纪下 17:21"> 第二天，摩西对百姓说：“你们犯了大罪。现在我要上到耶和华那里去，也许我可以为你们的罪赎罪。”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="出埃及记 20:23; 但以理 9:11; 但以理 9:8"> 摩西回到耶和华那里，说：“唉，这百姓犯了大罪，为自己造了金神。</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 69:28; 罗马书 9:3; 启示录 21:27"> 现在，倘若祢肯赦免他们的罪——若不然，求祢把我从祢所写的册上涂抹掉。”</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="申命记 29:20; 以西结 18:4; 启示录 20:12"> 耶和华对摩西说：“谁得罪了我，我就要把谁从我的册上涂抹掉。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 23:20; 申命记 32:35; 马太福音 23:35"> 现在你去，领这百姓到我对你说过的地方。看哪，我的使者必在你前面引路。不过，到我惩罚的日子，我必因他们的罪惩罚他们。”</span>
<span className="v" id="v35" data-v="35" data-xref="使徒行传 7:41; 出埃及记 32:25; 撒母耳记下 12:9–10"> 耶和华击打百姓，是因为他们对亚伦所造的牛犊所做的事。</span>
</div>
</div>

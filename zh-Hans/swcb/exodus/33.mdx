<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 12:7; 出埃及记 32:13; 出埃及记 32:7"> 耶和华对摩西说：“你和你从埃及地领上来的百姓，要离开这里，上去，到我向亚伯拉罕、以撒、雅各起誓所应许的地去；我曾说：‘我要把这地赐给你的后裔。’</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 32:34; 约书亚记 24:11; 出埃及记 23:27–31"> 我要差遣一位使者在你前面；我要赶出迦南人、亚摩利人、赫人、比利洗人、希未人和耶布斯人。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 32:9–10; 出埃及记 3:8; 使徒行传 7:51"> 你们要上到流奶与蜜之地去；但我不在你们中间上去，因为你们是硬着颈项的百姓，免得我在路上灭绝你们。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="民数记 14:39; 民数记 14:1; 以西结 26:16"> 百姓听见这坏消息，就悲哀；没有人佩戴自己的首饰。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="民数记 16:21; 民数记 16:45–46; 出埃及记 33:3–4"> 耶和华曾对摩西说：“你要告诉以色列子孙：‘你们是硬着颈项的百姓。如果我一刻在你们中间上去，就会灭绝你们。所以现在要把你们身上的首饰摘下来，好让我知道该怎样待你们。’”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 33:4; 出埃及记 32:3; 耶利米书 2:19"> 以色列子孙从何烈山起，就摘下自己的首饰。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 55:6–7; 出埃及记 29:42–43; 箴言 15:29"> 摩西惯常把帐棚支搭在营外，离营很远，并称它为“会幕”。凡寻求耶和华的，都出到营外的会幕那里。</span>
<span className="v" id="v8" data-v="8" data-xref="民数记 16:27"> 每当摩西出到会幕那里，众百姓就都起来，各人站在自己的帐棚门口，望着摩西，直到他进了会幕。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 99:7; 出埃及记 31:18; 出埃及记 13:21–22"> 摩西进会幕的时候，云柱就降下来，停在会幕门口，耶和华就与摩西说话。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 8:22; 列王纪上 8:14; 出埃及记 4:31"> 众百姓看见云柱停在会幕门口，就都起来，各人在自己的帐棚门口敬拜。</span>
<span className="v" id="v11" data-v="11" data-xref="民数记 12:8; 申命记 34:10; 出埃及记 24:13"> 耶和华与摩西面对面说话，好像人对朋友说话一样。摩西又回到营里；但他的助手，嫩的儿子约书亚，一个年轻人，没有离开会幕。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及记 33:17; 耶利米书 1:5; 约翰福音 10:14–15"> 摩西对耶和华说：“看哪，你对我说：‘把这百姓领上去。’却没有让我知道你要差遣谁与我同去。你还说过：‘我按名认识你，你也在我眼前蒙了恩。’</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 119:33; 诗篇 25:4; 诗篇 27:11"> 现在，如果我在你眼前蒙了恩，求你将你的道路指示我，使我可以认识你，好在你眼前蒙恩；也求你想一想，这国民是你的百姓。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="约书亚记 21:44; 马太福音 11:28; 约书亚记 1:5"> 祂说：“我的同在必与你同行，我必使你得安息。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及记 34:9; 诗篇 4:6; 出埃及记 33:3"> 摩西对祂说：“如果你的同在不与我同去，就不要把我们从这里领上去。</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 4:7; 民数记 14:14; 列王纪上 8:53"> 人怎样才知道我和你的百姓在你眼前蒙了恩呢？岂不是因你与我们同去，使我和你的百姓与地面上的万民分别出来吗？”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 65:24; 约翰一书 5:14–15; 出埃及记 33:12"> 耶和华对摩西说：“你所说的这事，我也要做；因为你在我眼前蒙了恩，并且我按名认识你。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="启示录 21:23; 出埃及记 33:20; 提多书 2:13"> 摩西说：“求你将你的荣耀显给我看。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="罗马书 9:15–18; 以弗所书 1:6–8; 耶利米书 31:14"> 祂说：“我要使我一切的良善从你面前经过，并要在你面前宣告耶和华的名。我要恩待谁，就恩待谁；要怜悯谁，就怜悯谁。”</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 32:30; 约翰福音 1:18; 提摩太前书 6:16"> 祂又说：“你不能看见我的面，因为人不能看见我而仍然活着。”</span>
<span className="v" id="v21" data-v="21" data-xref="申命记 5:31; 撒迦利亚书 3:7; 约书亚记 20:4"> 耶和华又说：“看哪，在我这里有一个地方，你要站在磐石上。</span>
<span className="v" id="v22" data-v="22" data-xref="诗篇 91:1; 以赛亚书 2:21; 诗篇 91:4"> 我的荣耀经过的时候，我要把你放在磐石穴中，用我的手遮掩你，直到我经过；</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 33:20; 约翰福音 1:18; 提摩太前书 6:16"> 然后我要收回我的手，你就会看见我的背；只是我的面不可被看见。”</span>
</div>
</div>

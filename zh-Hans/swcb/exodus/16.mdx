<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="EXO" data-book-slug="exodus" data-book-name="出埃及记" data-chapter="16" data-verses="36">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="民数记 33:10–12; 出埃及记 15:27; 出埃及记 17:1"> 他们从以琳起行；在出埃及地以后第二个月十五日，以色列子孙全会众来到汛的旷野，就是在以琳和西奈之间。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 10:10; 出埃及记 15:24; 诗篇 106:25"> 以色列子孙全会众在旷野向摩西和亚伦发怨言；</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 11:4–5; 民数记 20:3–5; 出埃及记 17:3"> 以色列子孙对他们说：“但愿我们在埃及地，坐在肉锅旁、吃饼得饱的时候，死在耶和华手中！因为你们把我们领出来，到这旷野，是要用饥饿杀死这全会众。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="哥林多前书 10:3; 诗篇 78:24–25; 申命记 8:2"> 耶和华对摩西说：“看哪，我要从天上给你们降下饼如雨；百姓要天天出去，收取当天的分量，好让我试验他们，看他们是否遵行我的律法。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 16:22–23; 出埃及记 35:2–3; 利未记 25:21–22"> 到第六天，他们要预备带回来的；那一天所收的要比平日所收的多一倍。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 6:7; 民数记 16:28; 出埃及记 16:12–13"> 摩西和亚伦对以色列全体子孙说：“到了晚上，你们就会知道是耶和华把你们从埃及地领出来。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 40:5; 民数记 16:11; 约翰福音 11:40"> 到了早晨，你们要看见耶和华的荣耀，因为祂听见了你们向耶和华所发的怨言。我们算什么，你们竟向我们发怨言？”</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 13:2; 撒母耳记上 8:7; 帖撒罗尼迦前书 4:8"> 摩西说：“耶和华晚上要给你们肉吃，早晨要给你们饼，使你们饱足，因为耶和华听见了你们向祂所发的怨言。我们算什么？你们发怨言不是向我们，而是向耶和华。”</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 16:16; 出埃及记 16:2; 出埃及记 16:8"> 摩西对亚伦说：“你要告诉以色列子孙全会众：‘你们近前来到耶和华面前，因为祂已经听见你们的怨言。’”</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 16:7; 民数记 16:19; 民数记 16:42"> 亚伦对以色列子孙全会众说话的时候，他们向旷野观看，看哪，耶和华的荣耀在云中显现。</span>
<span className="v" id="v11" data-v="11"> 耶和华对摩西说：</span>
<span className="v" id="v12" data-v="12" data-xref="约珥 3:17; 以西结 39:22; 出埃及记 6:7"> “我已经听见以色列子孙的怨言。你要告诉他们说：‘到了晚上，你们要吃肉；到了早晨，你们要吃饼得饱。这样，你们就知道我是耶和华你们的上帝。’”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 11:9; 诗篇 105:40; 诗篇 78:27–28"> 到了晚上，有鹌鹑飞来，遮满了营地；到了早晨，营地周围有露水降下。</span>
<span className="v" id="v14" data-v="14" data-xref="民数记 11:7–9; 诗篇 105:40; 诗篇 78:24"> 那降下的露水消失以后，看哪，旷野的地面上有一种细小圆粒，细小如地上的霜。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 16:4; 约翰福音 6:58; 出埃及记 16:31"> 以色列子孙看见了，就彼此说：“这是什么？”因为他们不知道那是什么。摩西对他们说：“这是耶和华赐给你们吃的饼。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 16:36; 出埃及记 16:18; 出埃及记 16:32–33"> 耶和华所吩咐的是这样：‘你们要按各人的食量收取；按你们的人数，每人一俄梅珥<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一俄梅珥约为2.2升，或约2.3夸脱。">a</a></sup>，各人为自己帐棚里的人收取。’”</span>
<span className="v" id="v17" data-v="17"> 以色列子孙就这样做了；有的收得多，有的收得少。</span>
<span className="v" id="v18" data-v="18" data-xref="哥林多后书 8:14–15"> 他们用俄梅珥量的时候，收得多的没有余，收得少的也没有缺；各人都按自己的食量收取。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 12:10; 出埃及记 23:18; 马太福音 6:34"> 摩西对他们说：“谁也不可把这些留到早晨。”</span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 10:14; 民数记 16:15; 以弗所书 4:26"> 然而他们不听摩西的话；有人把一些留到早晨，就生虫变臭了；摩西向他们发怒。</span>
<span className="v" id="v21" data-v="21" data-xref="箴言 6:6–11; 传道书 12:1; 哥林多后书 6:2"> 他们每天早晨按各人的食量收取；太阳一热，就融化了。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 16:5; 利未记 25:22; 出埃及记 16:16"> 到第六天，他们收取双倍的饼，每人两俄梅珥；会众所有的首领都来告诉摩西。</span>
<span className="v" id="v23" data-v="23" data-xref="利未记 23:3; 出埃及记 31:15; 出埃及记 20:8–11"> 摩西对他们说：“这就是耶和华所说的：‘明天是庄严的安息，是归耶和华为圣的安息日。你们要烤的就烤，要煮的就煮；剩下的一切，要为自己存放起来，留到早晨。’”</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 16:20; 出埃及记 16:33"> 他们照摩西所吩咐的存放到早晨；它没有变臭，里面也没有虫子。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 16:23; 出埃及记 16:29; 尼希米记 9:14"> 摩西说：“今天吃这些吧，因为今天是归耶和华的安息日；今天你们在田野里找不到它。</span>
<span className="v" id="v26" data-v="26" data-xref="申命记 5:13; 出埃及记 20:9–11; 以西结 46:1"> 六天你们可以收取，第七天却是安息日；那一天必没有。”</span>
<span className="v" id="v27" data-v="27" data-xref="箴言 20:4"> 第七天，百姓中有人出去收取，却什么也找不到。</span>
<span className="v" id="v28" data-v="28" data-xref="诗篇 78:10; 诗篇 106:13; 民数记 14:11"> 耶和华对摩西说：“你们拒绝遵守我的诫命和我的律法，要到几时呢？</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 31:13; 以赛亚书 58:13–14; 以西结 20:12"> 看哪，耶和华既然把安息日赐给你们，所以祂在第六天赐给你们两天的饼。各人要留在自己的地方；第七天谁也不可离开自己的地方。”</span>
<span className="v" id="v30" data-v="30" data-xref="申命记 5:12–14; 利未记 23:3; 希伯来书 4:9"> 于是百姓在第七天安息了。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="雅歌 2:3; 民数记 11:6–9; 出埃及记 16:15"> 以色列家给它起名叫“吗哪”，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“吗哪”的意思是“这是什么？”">b</a></sup>它像芫荽子，是白色的；味道像加了蜜的薄饼。</span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 105:5; 路加福音 22:19; 诗篇 111:4–5"> 摩西说：“耶和华所吩咐的是这样：‘要把满一俄梅珥的吗哪保存起来，留给你们世世代代，使他们看见我在旷野用来喂养你们的饼，就是我把你们从埃及地领出来的时候所赐的。’”</span>
<span className="v" id="v33" data-v="33" data-xref="希伯来书 9:4"> 摩西对亚伦说：“拿一个罐子，把满一俄梅珥的吗哪放在里面，存放在耶和华面前，留给你们世世代代。”</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 27:21; 出埃及记 25:21; 出埃及记 25:16"> 亚伦就照耶和华吩咐摩西的，把它存放在见证前，留作保存。</span>
<span className="v" id="v35" data-v="35" data-xref="尼希米记 9:20–21; 约书亚记 5:12; 申命记 8:2–3"> 以色列子孙吃吗哪四十年，直到他们来到有人居住的地方；他们吃吗哪，直到来到迦南地的边界。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 16:16; 出埃及记 16:32–33"> 俄梅珥是伊法的十分之一。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="1伊法约为22升，或约为一蒲式耳的三分之二。">c</a></sup></span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="EXO" data-book-slug="exodus" data-book-name="出埃及记" data-chapter="39" data-verses="43">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 31:10; 出埃及记 35:23; 出埃及记 35:19"> 他们用蓝色、紫色、朱红色线，做了精工制作的衣服，用以在圣所供职；又为亚伦做了圣衣，正如耶和华吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="出埃及记 28:6–12; 利未记 8:7; 出埃及记 25:7"> 他用金线、蓝色、紫色、朱红色线和捻的细麻做了以弗得。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 36:8; 出埃及记 26:1"> 他们把金子锤成薄片，剪成细线，与蓝色、紫色、朱红色线和细麻交织在一起，是巧匠的工艺。</span>
<span className="v" id="v4" data-v="4"> 他们为以弗得做了相连的肩带，在两端连接起来。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 1:13; 马太福音 28:20; 以赛亚书 11:5"> 以弗得上用来束紧的巧织带子，与以弗得连成一体，工艺相同，是用金线、蓝色、紫色、朱红色线和捻的细麻做的，正如耶和华吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 28:9; 以西结 28:13; 约伯记 28:16"> 他们琢磨缟玛瑙，镶在金槽里，按以色列子孙的名字雕刻，如同刻印章一样。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 4:7; 出埃及记 28:12; 出埃及记 28:29"> 他把这两块宝石安在以弗得的肩带上，作以色列子孙的纪念石，正如耶和华吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="出埃及记 28:4; 利未记 8:8–9; 以赛亚书 59:17"> 他做了胸牌，是巧匠的工艺，像以弗得的工艺一样，用金线、蓝色、紫色、朱红色线和捻的细麻做成。</span>
<span className="v" id="v9" data-v="9"> 胸牌是正方形的。他们把胸牌做成双层，长一拃，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一拃是人伸开手时，从拇指尖到小指尖的长度（约半肘，或9英寸，或22.8厘米）。">a</a></sup>宽一拃，是双层的。</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 28:21; 出埃及记 28:16–17; 启示录 21:19–21"> 他们在胸牌上镶嵌四行宝石：第一行是红宝石、黄玉和绿柱石；</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 28:18; 以西结 28:13"> 第二行是绿松石、蓝宝石<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：青金石。">b</a></sup>和祖母绿；</span>
<span className="v" id="v12" data-v="12"> 第三行是风信子石、玛瑙和紫水晶；</span>
<span className="v" id="v13" data-v="13"> 第四行是贵橄榄石、缟玛瑙和碧玉。这些都镶在金槽里。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 21:12"> 这些宝石按以色列子孙的名字，共十二块，按他们的名字；每一块按自己的名字，为十二支派雕刻，如同刻印章一样。</span>
<span className="v" id="v15" data-v="15" data-xref="约翰福音 10:28; 约翰福音 17:12; 彼得前书 1:5"> 他们在胸牌上做了像绳子的链子，是用纯金编成的。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 25:12"> 他们做了两个金槽和两个金环，把两个环安在胸牌的两端。</span>
<span className="v" id="v17" data-v="17"> 他们把两条金编链穿在胸牌两端的两个环里。</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 28:14; 雅歌 1:10"> 又把两条编链的另外两端接在两个金槽上，安在以弗得前面的肩带上。</span>
<span className="v" id="v19" data-v="19"> 他们做了两个金环，安在胸牌的两端，安在胸牌向着以弗得里面一侧的边上。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 26:3"> 他们又做了两个金环，安在以弗得前面两条肩带的下方，靠近连接处，在以弗得巧织带子的上方。</span>
<span className="v" id="v21" data-v="21" data-xref="马太福音 16:24; 哥林多前书 1:25; 哥林多前书 1:27"> 他们用蓝色细带，把胸牌的环系在以弗得的环上，使胸牌贴在以弗得的巧织带子上，不致从以弗得上松脱，正如耶和华吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="出埃及记 28:31–35"> 他做了以弗得的外袍，是织成的工，完全用蓝色线做成。</span>
<span className="v" id="v23" data-v="23"> 外袍中间的领口像铠甲的领口，领口周围有镶边，使它不致撕裂。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 28:33; 加拉太书 5:22"> 他们在外袍的下摆上，用蓝色、紫色、朱红色线和捻的细麻做了石榴。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 28:33–34; 雅歌 4:13; 诗篇 89:15"> 他们做了纯金的铃铛，把铃铛安在外袍下摆周围的石榴之间，在石榴之间；</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 28:34; 雅歌 4:13; 雅歌 6:7"> 一个铃铛一个石榴，一个铃铛一个石榴，围在外袍的下摆周围，用以供职，正如耶和华吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以西结 44:18; 彼得前书 1:13; 以赛亚书 61:10"> 他们为亚伦和他的儿子们，用细麻织成内袍，</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 28:4; 以西结 44:18; 出埃及记 28:39"> 用细麻做礼冠，用细麻做头巾，用捻的细麻做细麻裤子，</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 28:39"> 又用捻的细麻和蓝色、紫色、朱红色线做腰带，是绣花匠的工艺，正如耶和华吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="启示录 5:10; 希伯来书 7:26; 希伯来书 1:3"> 他们用纯金做圣冠的牌，在上面刻字，如同刻印章一样，写着：“归耶和华为圣”。</span>
<span className="v" id="v31" data-v="31"> 他们把蓝色细带系在牌上，把它固定在礼冠上方，正如耶和华吩咐摩西的。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="出埃及记 39:42–43; 马太福音 28:20; 出埃及记 25:40"> 这样，会幕，就是会见之幕的一切工程都完成了。以色列子孙照耶和华吩咐摩西的一切去做；他们就这样做了。</span>
<span className="v" id="v33" data-v="33" data-xref="出埃及记 35:11–19; 出埃及记 31:7–11; 出埃及记 36:1–38"> 他们把帐幕带到摩西那里：帐幕和它的一切器具、钩子、板、横木、柱子、座，</span>
<span className="v" id="v34" data-v="34"> 染红的公羊皮盖、海牛皮盖、遮掩的幔子，</span>
<span className="v" id="v35" data-v="35" data-xref="希伯来书 9:5; 出埃及记 25:17; 希伯来书 9:8"> 约柜和它的杠、施恩座，</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 25:30; 列王纪上 7:48"> 桌子和它的一切器皿、陈设饼，</span>
<span className="v" id="v37" data-v="37" data-xref="腓立比书 2:15; 出埃及记 27:21; 马太福音 5:14–16"> 纯金灯台和它的灯盏，就是要摆列的灯盏，以及它的一切器皿和点灯的油，</span>
<span className="v" id="v38" data-v="38" data-xref="出埃及记 30:7; 出埃及记 37:29; 出埃及记 30:3"> 金坛、膏油、馨香的香、帐幕门口的帘子，</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪上 8:64; 出埃及记 38:30"> 铜坛和它的铜网、杠，以及它的一切器皿，盆和盆座，</span>
<span className="v" id="v40" data-v="40" data-xref="出埃及记 27:9–16"> 院子的帷幔、柱子、座、院门的帘子、绳子、橛子，以及帐幕，就是会见之幕中供职用的一切器具，</span>
<span className="v" id="v41" data-v="41" data-xref="出埃及记 28:2; 出埃及记 31:10; 出埃及记 39:1"> 在圣所供职用的精工衣服，祭司亚伦的圣衣，以及他儿子们供祭司职分用的衣服。</span>
<span className="v" id="v42" data-v="42" data-xref="出埃及记 35:10; 出埃及记 23:21–22; 提摩太后书 2:15"> 耶和华怎样吩咐摩西，以色列子孙就怎样做了这一切工程。</span>
<span className="v" id="v43" data-v="43" data-xref="民数记 6:23–27; 利未记 9:22–23; 撒母耳记下 6:18"> 摩西查看一切工程，看哪，他们都做成了，正如耶和华所吩咐的。他们就是这样做的；摩西就为他们祝福。</span>
</div>

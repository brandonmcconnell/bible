<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 4:14; 申命记 6:20; 出埃及记 24:3–4"> “你要摆在他们面前的典章如下：</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="申命记 15:12–15; 出埃及记 12:44; 申命记 15:18"> “如果你买了希伯来奴仆，他要服侍六年；到了第七年，他可以自由离去，不用付任何代价。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 15:12–14"> 他若是独身来的，就要独身离去；他若已经有妻子，他的妻子也要和他一同离去。</span>
<span className="v" id="v4" data-v="4"> 如果他的主人给他妻子，而她给他生了儿子或女儿，妻子和儿女都要归主人，他自己要独身离去。</span>
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 5:14–15; 申命记 15:16–17; 以赛亚书 26:13"> 但如果那奴仆明明地说：‘我爱我的主人、我的妻子和我的儿女；我不愿自由离去；’</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 15:17; 利未记 25:40; 申命记 19:17–18"> 他的主人就要把他带到上帝面前，又要把他带到门前或门柱旁；他的主人要用锥子穿透他的耳朵，他就要永远服侍主人。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="尼希米记 5:5; 出埃及记 21:2–3"> “如果有人卖女儿作婢女，她不可像男奴那样离去。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 28:8; 申命记 20:7; 玛拉基书 2:11–15"> 如果她不讨主人的喜悦，而主人已经把她许配给自己，他就要准许她被赎回。他既然以诡诈待了她，就无权把她卖给外族人。</span>
<span className="v" id="v9" data-v="9"> 如果他把她许配给自己的儿子，就要按女儿的待遇待她。</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 7:1–6"> 如果他另娶妻子，就不可减少她的饮食、衣服和夫妻的权利。</span>
<span className="v" id="v11" data-v="11"> 如果他不为她做这三件事，她就可以不用付钱，自由离去。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="创世记 9:6; 马太福音 26:52; 利未记 24:17"> “击打人以致死亡的，必须被处死。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 20:2–9; 撒母耳记上 24:18; 申命记 4:41–43"> 但如果不是出于故意，而是上帝容许这事发生，我就要为你指定一个他可以逃往的地方。</span>
<span className="v" id="v14" data-v="14" data-xref="列王纪上 2:28–34; 希伯来书 10:26; 民数记 15:30–31"> 如果有人设计谋害他的邻舍，蓄意杀他，你要把他从我的祭坛那里带走，使他处死。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="申命记 21:18–21; 箴言 30:17; 提摩太前书 1:9"> “攻击自己父亲或母亲的，必须被处死。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="申命记 24:7; 提摩太前书 1:10; 出埃及记 22:4"> “绑架人并把他卖了的，或那人还在他手中被发现的，必须被处死。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="箴言 20:20; 马可福音 7:10–11; 申命记 27:16"> “咒骂自己父亲或母亲的，必须被处死。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 21:20; 申命记 25:11; 撒母耳记下 14:6"> “如果人争斗，一个人用石头或拳头击打另一个人，那人没有死，却卧床不起；</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 3:29; 撒迦利亚书 8:4"> 后来若能起来，扶着杖在外行走，击打他的人就可以免受刑罚；只是他必须赔偿那人误工的损失，并负责医治他，直到他完全康复。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="箴言 29:19; 申命记 19:21; 民数记 35:19"> “如果有人用棍子打他的奴仆或婢女，使他死在自己手下，那人必须受惩罚。</span>
<span className="v" id="v21" data-v="21" data-xref="利未记 25:44–46"> 不过，如果奴仆过了一两天还能起来，他就不受惩罚，因为那奴仆是他的财产。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="申命记 22:18–19; 出埃及记 21:30; 申命记 16:18"> “如果人打架，伤害了怀孕的妇人，以致她早产，却没有造成其他伤害，他必须照妇人的丈夫所要求、审判官所准许的，缴纳罚款。</span>
<span className="v" id="v23" data-v="23" data-xref="申命记 19:21; 民数记 35:31; 利未记 24:19"> 但如果造成伤害，你就要以命偿命，</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 19:21; 马太福音 5:38–40; 马太福音 7:2"> 以眼还眼，以牙还牙，以手还手，以脚还脚，</span>
<span className="v" id="v25" data-v="25"> 以灼伤还灼伤，以伤口还伤口，以瘀伤还瘀伤。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="出埃及记 21:20; 约伯记 31:13–15; 诗篇 72:12–14"> “如果有人击打他的奴仆或婢女的眼睛，把眼睛打坏，他就要因那只眼睛释放那人，使他自由。</span>
<span className="v" id="v27" data-v="27"> 如果他打掉男奴的一颗牙，或婢女的一颗牙，他就要因那颗牙释放那奴仆，使他自由。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="出埃及记 21:32; 利未记 20:15–16; 创世记 9:5–6"> “如果牛抵死男人或女人，那牛必须用石头打死，牛肉不可吃；但牛主不承担责任。</span>
<span className="v" id="v29" data-v="29" data-xref="申命记 21:1–9"> 但如果那牛素来有抵人的习惯，牛主也受过警告，却没有把它看管起来，以致它杀死男人或女人，那牛要用石头打死，牛主也要被处死。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 21:22; 出埃及记 30:12; 民数记 35:31–33"> 如果有赎价加在他身上，他就要按所加给他的一切，交出赎自己性命的价银。</span>
<span className="v" id="v31" data-v="31"> 无论牛抵死的是儿子还是女儿，都要按这判例办理。</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 26:15; 撒迦利亚书 11:12–13; 马太福音 27:3–9"> 如果牛抵死男奴或婢女，就要把三十舍客勒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一舍客勒约为10克，或约0.35盎司；所以三十舍客勒约为300克，或约10.6盎司。">a</a></sup>银子交给奴仆的主人，牛也要用石头打死。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="箴言 28:10; 耶利米书 18:20; 传道书 10:8"> “如果有人打开一个坑，或有人挖坑而不遮盖，有牛或驴掉在里面，</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 22:6; 出埃及记 21:29–30; 出埃及记 22:14"> 坑的主人就要赔偿。他要把钱给牲畜的主人，死了的牲畜要归他。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35"> “如果一个人的牛伤了另一个人的牛，以致它死了，他们就要卖掉活牛，平分价银；死牛也要平分。</span>
<span className="v" id="v36" data-v="36"> 或者，如果人知道那牛素来有抵人的习惯，牛主却没有把它看管起来，他就必须以牛赔牛，死牛要归他自己。</span>
</div>
</div>

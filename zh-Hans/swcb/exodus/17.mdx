<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 16:1; 出埃及记 19:2; 出埃及记 17:8"> 以色列子孙全会众从汛的旷野起行，按着耶和华的命令一站一站往前走，在利非订安营；可是那里没有水给百姓喝。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 78:18; 申命记 6:16; 哥林多前书 10:9"> 因此百姓与摩西争闹，说：“给我们水喝。”<br />摩西对他们说：“你们为什么与我争闹？为什么试探耶和华？”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="出埃及记 16:2–3; 出埃及记 15:24"> 百姓在那里口渴要水喝；于是百姓向摩西发怨言，说：“你为什么把我们从埃及领上来，使我们和我们的儿女、牲畜都渴死呢？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 30:6; 民数记 14:10; 约翰福音 8:59"> 摩西向耶和华呼求说：“我该怎样对待这百姓呢？他们几乎要用石头打死我了。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及记 7:19–20; 民数记 20:8–11; 使徒行传 20:23–24"> 耶和华对摩西说：“你要走在百姓前面，带着以色列的长老，也要手里拿着你击打尼罗河的杖，去吧。</span>
<span className="v" id="v6" data-v="6" data-xref="哥林多前书 10:4; 民数记 20:9–11; 尼希米记 9:15"> 看哪，我要在那里，在何烈的磐石上，站在你面前。你要击打磐石，水就会从磐石里出来，让百姓可以喝。”摩西就在以色列长老眼前这样行了。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 81:7; 诗篇 95:8; 民数记 20:13"> 他给那地方起名叫玛撒，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="玛撒意为“试探”。">a</a></sup>又叫米利巴，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="米利巴意为“争闹”。">b</a></sup>因为以色列子孙在那里争闹，又因为他们试探耶和华，说：“耶和华是在我们中间，还是不在？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="创世记 36:12; 申命记 25:17–19; 民数记 24:20"> 后来亚玛力来了，在利非订与以色列争战。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 24:13; 申命记 32:44; 出埃及记 4:20"> 摩西对约书亚说：“你为我们选出人来，出去与亚玛力争战。明天我要站在山顶上，手里拿着上帝的杖。”</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 24:14; 出埃及记 31:2; 出埃及记 17:12"> 于是约书亚照着摩西对他说的去做，与亚玛力争战；摩西、亚伦和户珥都上了山顶。</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 2:8; 雅各书 5:16; 诗篇 56:9"> 摩西举起手的时候，以色列就得胜；他放下手的时候，亚玛力就得胜。</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 35:3; 腓立比书 1:19; 希伯来书 12:12"> 但是摩西的手发沉；他们就拿一块石头放在他下面，他便坐在上面。亚伦和户珥扶着他的手，一个在这边，一个在那边。他的手就稳住，直到日落。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 10:42; 约书亚记 10:37; 约书亚记 10:32"> 约书亚用刀刃击败了亚玛力和他的百姓。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 34:27; 民数记 24:20; 撒母耳记上 30:1"> 耶和华对摩西说：“你要把这事写在书上作为纪念，又要念给约书亚听：我必从天下彻底涂抹亚玛力的记忆。”</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 22:14; 士师记 6:24; 诗篇 60:4"> 摩西筑了一座祭坛，给它起名叫“耶和华是我们的旌旗”。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作：“耶和华尼西”。全大写的 LORD 或 GOD，除非另有说明来自短形式 יה Yah，都是来自希伯来文 יהוה Yahweh。">c</a></sup></span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 21:8–11; 以赛亚书 66:1; 使徒行传 7:49"> 他说：“耶和华<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="希伯来文：יה Yah">d</a></sup>已经起誓：‘耶和华<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="全大写的 LORD 或 GOD，除非另有说明来自短形式 יה Yah，都是来自希伯来文 יהוה Yahweh。">e</a></sup>必世世代代与亚玛力争战。’”</span>
</div>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="EXO" data-book-slug="exodus" data-book-name="出埃及记" data-chapter="29" data-verses="46">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="利未记 4:3; 玛拉基书 1:13–14; 出埃及记 12:5"> “你要这样行，使他们分别为圣，好在祭司的职分上事奉我：取一头公牛犊和两只没有残缺的公绵羊，</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 6:15; 利未记 2:15; 利未记 7:12"> 无酵饼、调油的无酵饼、抹油的无酵薄饼，都要用细麦面做成。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 6:17; 利未记 8:26; 利未记 8:2"> 你要把这些放在一个篮子里，连篮子带来，又把公牛和两只公绵羊带来。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 40:12; 希伯来书 10:22; 出埃及记 26:36"> 你要把亚伦和他的儿子带到会幕门口，用水洗他们。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 28:2–8; 利未记 8:7–8"> 你要拿礼服给亚伦穿上内袍、以弗得的外袍、以弗得和胸牌，又给他系上以弗得巧工织成的带子。</span>
<span className="v" id="v6" data-v="6" data-xref="利未记 8:9; 出埃及记 28:36–39"> 你要把礼冠戴在他头上，把圣冠加在礼冠上。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 35:25; 利未记 21:10; 约翰福音 3:34"> 然后你要取膏油倒在他头上，膏他。</span>
<span className="v" id="v8" data-v="8" data-xref="利未记 8:13; 出埃及记 28:40"> 你要把他的儿子带来，给他们穿上内袍。</span>
<span className="v" id="v9" data-v="9" data-xref="民数记 18:7; 利未记 8:22–28; 申命记 18:5"> 你要给他们，就是亚伦和他的儿子，束上腰带，给他们绑上头巾。祭司职分要归他们，作为永远的条例。你要使亚伦和他的儿子承接圣职。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="利未记 1:4; 利未记 8:14; 出埃及记 29:15"> “你要把公牛带到会幕前；亚伦和他的儿子要按手在公牛的头上。</span>
<span className="v" id="v11" data-v="11" data-xref="利未记 9:8; 利未记 9:12; 出埃及记 29:4"> 你要在耶和华面前，在会幕门口宰这公牛。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 27:2; 利未记 9:9; 利未记 8:15"> 你要取一些公牛的血，用指头抹在祭坛的角上；其余所有的血要倒在祭坛脚那里。</span>
<span className="v" id="v13" data-v="13" data-xref="利未记 3:3–4; 撒母耳记上 2:16; 利未记 9:10"> 你要取所有盖在内脏上的脂肪、肝上的盖、两个肾和肾上的脂肪，烧在祭坛上。</span>
<span className="v" id="v14" data-v="14" data-xref="利未记 4:11–12; 利未记 4:21; 出埃及记 30:10"> 只是公牛的肉、皮和粪，你要在营外用火焚烧；这是赎罪祭。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及记 29:19; 出埃及记 29:3; 利未记 8:18–21"> “你也要取一只公绵羊，亚伦和他的儿子要按手在公绵羊的头上。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 29:11–12"> 你要宰这公绵羊，取它的血，洒在祭坛四周。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 4:14; 利未记 1:13; 利未记 1:9"> 你要把公绵羊切成块，洗净它的内脏和腿，放在它的肉块和头那里。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 8:21; 腓立比书 4:18; 创世记 22:7"> 你要把整只公绵羊烧在祭坛上；这是献给耶和华的燔祭，是馨香之气，是献给耶和华的火祭。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="出埃及记 29:3; 利未记 8:22–29"> “你要取另一只公绵羊，亚伦和他的儿子要按手在公绵羊的头上。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 50:5; 希伯来书 10:22; 利未记 14:16"> 然后你要宰这公绵羊，取一些它的血，抹在亚伦的右耳垂上和他儿子的右耳垂上，又抹在他们右手的大拇指上和右脚的大脚趾上；并把血洒在祭坛四周。</span>
<span className="v" id="v21" data-v="21" data-xref="希伯来书 9:22; 出埃及记 29:7; 出埃及记 29:1"> 你要取祭坛上的血和膏油，洒在亚伦和他的衣服上，以及他的儿子和他儿子的衣服上；他和他的衣服，他的儿子和他儿子的衣服，都要一同分别为圣。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 29:13; 利未记 9:21; 利未记 9:19"> 你也要取这公绵羊的一些脂肪、肥尾巴、盖在内脏上的脂肪、肝上的盖、两个肾和肾上的脂肪，以及右腿（因为这是承接圣职所用的公绵羊），</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 29:2–3; 利未记 8:26"> 又从耶和华面前那一篮无酵饼中取一个饼、一个调油的饼和一个薄饼。</span>
<span className="v" id="v24" data-v="24" data-xref="利未记 7:30; 利未记 8:27; 利未记 9:21"> 你要把这一切放在亚伦手中和他儿子手中，在耶和华面前摇一摇，作为摇祭。</span>
<span className="v" id="v25" data-v="25" data-xref="利未记 8:28; 出埃及记 29:41; 利未记 3:16"> 你要从他们手中接过来，烧在祭坛上的燔祭上，在耶和华面前成为馨香之气；这是献给耶和华的火祭。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="利未记 8:29; 利未记 7:31; 利未记 7:34"> “你要取亚伦承接圣职所用的那只公绵羊的胸，在耶和华面前摇一摇，作为摇祭；这要作你的份。</span>
<span className="v" id="v27" data-v="27" data-xref="利未记 10:15; 民数记 18:11; 申命记 18:3"> 你要把承接圣职所用公绵羊中，那作为亚伦的和作为他儿子的，就是所摇的摇祭之胸和所举起的摇祭之腿，分别为圣。</span>
<span className="v" id="v28" data-v="28" data-xref="民数记 15:19–20; 利未记 7:11–38; 利未记 10:14–15"> 这要从以色列人归给亚伦和他的儿子，作为他们永远的份；因为这是摇祭。这要从以色列人的平安祭中，作为以色列人献给耶和华的摇祭。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="民数记 18:8; 出埃及记 28:3–4; 出埃及记 30:30"> “亚伦的圣衣要留给他以后的儿子，他们要穿着这些受膏，穿着这些承接圣职。</span>
<span className="v" id="v30" data-v="30" data-xref="民数记 20:28; 利未记 13:5; 使徒行传 20:6–7"> 接替他作祭司的儿子，进入会幕在圣所事奉的时候，要穿这些衣服七天。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="利未记 8:31; 撒母耳记上 2:13; 以西结 46:20–24"> “你要取承接圣职所用的公绵羊，在圣处煮它的肉。</span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 12:4; 出埃及记 29:23; 出埃及记 29:2–3"> 亚伦和他的儿子要在会幕门口吃这公绵羊的肉和篮子里的饼。</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 18:4; 利未记 10:13–18; 诗篇 22:26"> 他们要吃那些用来赎罪、使他们承接圣职并分别为圣的东西；但外人不可吃，因为这些是圣的。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 12:10; 利未记 8:32; 出埃及记 29:22"> 如果承接圣职所用的肉或饼有剩到早晨的，你就要用火焚烧剩下的；不可吃，因为这是圣的。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="出埃及记 29:30; 利未记 14:8–11; 利未记 8:4–36"> “你要照我所吩咐你的一切，向亚伦和他的儿子这样行。你要用七天使他们承接圣职。</span>
<span className="v" id="v36" data-v="36" data-xref="希伯来书 10:11; 希伯来书 9:22–23; 出埃及记 30:28–29"> 每天你要献一头公牛作赎罪祭，为赎罪用。你为祭坛赎罪的时候，要洁净祭坛；又要膏祭坛，使它分别为圣。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及记 40:10; 马太福音 23:19; 出埃及记 30:28–29"> 你要为祭坛赎罪七天，使它分别为圣；祭坛就成为至圣。凡触碰祭坛的都要成为圣。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="历代志下 2:4; 历代志上 16:40; 民数记 28:3–8"> “你要献在祭坛上的，就是这样：每天不断地献两只一岁的羊羔。</span>
<span className="v" id="v39" data-v="39" data-xref="以西结 46:13–15; 列王纪下 16:15; 诗篇 5:3"> 早晨要献一只羊羔；傍晚要献另一只羊羔；</span>
<span className="v" id="v40" data-v="40" data-xref="腓立比书 2:17; 以西结 46:14; 约珥 2:14"> 和这一只羊羔同献的，要有十分之一伊法<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="1伊法约为22升，或约为一蒲式耳的三分之二。">a</a></sup>细面，调上四分之一欣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="1欣约为6.5升，或1.7加仑，所以四分之一欣约为1.6升。">b</a></sup>捣成的油，又有四分之一欣酒作奠祭。</span>
<span className="v" id="v41" data-v="41" data-xref="以西结 46:13–15; 列王纪上 18:29; 诗篇 141:2"> 另一只羊羔要在傍晚献上；要照早晨的素祭和同献的奠祭办理，作为馨香之气，是献给耶和华的火祭。</span>
<span className="v" id="v42" data-v="42" data-xref="出埃及记 25:22"> 这要在耶和华面前、会幕门口，作你们世世代代不断献的燔祭；我要在那里与你们相会，在那里对你说话。</span>
<span className="v" id="v43" data-v="43" data-xref="列王纪上 8:11; 历代志下 7:1–3; 玛拉基书 3:1"> 我要在那里与以色列人相会；那地方要因我的荣耀分别为圣。</span>
<span className="v" id="v44" data-v="44" data-xref="利未记 21:15; 利未记 22:9; 利未记 22:16"> 我要使会幕和祭坛分别为圣，也要使亚伦和他的儿子分别为圣，好在祭司的职分上事奉我。</span>
<span className="v" id="v45" data-v="45" data-xref="利未记 26:12; 哥林多后书 6:16; 出埃及记 25:8"> 我要住在以色列人中间，作他们的上帝。</span>
<span className="v" id="v46" data-v="46" data-xref="出埃及记 20:2; 耶利米书 31:33; 以西结 20:5"> 他们必知道我是耶和华他们的上帝，是我把他们从埃及地领出来，好住在他们中间；我是耶和华他们的上帝。</span>
</div>
</div>

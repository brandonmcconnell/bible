<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 3:18; 出埃及记 2:14; 耶利米书 1:6"> 摩西回答说：“可是，看哪，他们不会信我，也不会听我的声音；因为他们会说：‘耶和华并没有向你显现。’”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="出埃及记 4:17; 出埃及记 4:20; 以赛亚书 11:4"> 耶和华对他说：“你手里是什么？”<br />他说：“一根杖。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="出埃及记 7:10–15; 阿摩司 5:19; 出埃及记 4:17"> 祂说：“把它扔在地上。”<br />他把它扔在地上，它就变成了一条蛇；摩西就从它面前逃开。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="使徒行传 28:3–6; 创世记 22:1–2; 诗篇 91:13"> 耶和华对摩西说：“伸出你的手，抓住它的尾巴。”<br />他伸出手，抓住了它，它就在他手中变成了杖。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="出埃及记 19:9; 创世记 48:3; 出埃及记 3:15"> “这是要使他们相信：耶和华，他们列祖的上帝，亚伯拉罕的上帝、以撒的上帝、雅各的上帝，已经向你显现。”</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪下 5:27; 民数记 12:10"> 耶和华又对他说：“现在把你的手放进衣襟里。”<br />他把手放进衣襟里；等他拿出来时，看哪，他的手患了麻风，像雪一样白。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王纪下 5:14; 申命记 32:39; 马太福音 8:3"> 祂说：“再把你的手放进衣襟里。”<br />他又把手放进衣襟里；等他从衣襟里拿出来时，看哪，手已经复原，像他身上别处的肉一样。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 28:10; 申命记 32:39; 出埃及记 4:30–31"> “如果他们不信你，也不听第一个神迹的声音，那么他们必信后一个神迹的声音。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 7:19–25; 出埃及记 1:22; 马太福音 7:2"> 如果他们连这两个神迹也不信，也不听你的声音，你就要从河里取些水，倒在干地上。你从河里取出的水，到了干地上就会变成血。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="耶利米书 1:6; 出埃及记 6:12; 使徒行传 7:22"> 摩西对耶和华说：“主啊，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="译作“主”的词是“阿多奈”。">a</a></sup>我素来不是能言善辩的人；从前不是，自从你对仆人说话以来也不是；因为我说话迟钝，舌头笨拙。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="阿摩司 3:6; 诗篇 146:8; 以西结 3:26–27"> 耶和华对他说：“谁造了人的口？谁使人哑、聋、能看见或瞎眼？岂不是我耶和华吗？</span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 1:9; 路加福音 12:11–12; 马太福音 10:19–20"> 现在去吧，我必与你的口同在，教导你该说什么。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约拿 1:3; 出埃及记 4:1; 马太福音 13:41"> 摩西说：“主啊，求你差派别人去吧。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马可福音 14:13–15; 出埃及记 4:27; 历代志上 21:7"> 耶和华向摩西发怒，说：“你的兄弟利未人亚伦怎么样？我知道他很会说话。并且，看哪，他正出来迎接你；他看见你，心里必欢喜。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 51:16; 申命记 18:18; 路加福音 21:15"> 你要对他说，把这些话放在他口中；我必与你的口和他的口同在，并且教导你们该做什么。</span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 7:1–2; 诗篇 82:6; 约翰福音 10:34–35"> 他要替你向百姓说话。他要作你的口；你要对他如同上帝一样。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 4:2; 哥林多前书 1:27; 出埃及记 7:9–20"> 你要把这根杖拿在手里，用它来行这些神迹。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="出埃及记 3:1; 撒母耳记上 1:17; 提摩太前书 6:1"> 摩西就去，回到他的岳父叶忒罗那里，对他说：“请让我回到在埃及的弟兄们那里，看看他们是否还活着。”<br />叶忒罗对摩西说：“平平安安地去吧。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马太福音 2:20; 出埃及记 2:23; 出埃及记 2:15"> 耶和华在米甸对摩西说：“去吧，回埃及去；因为那些寻索你性命的人都死了。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="出埃及记 17:9; 民数记 20:8–9; 出埃及记 18:3–4"> 摩西带着妻子和儿子们，让他们骑上一头驴，就回埃及地去。摩西手里拿着上帝的杖。</span>
<span className="v" id="v21" data-v="21" data-xref="罗马书 9:18; 以赛亚书 63:17; 出埃及记 14:8"> 耶和华对摩西说：“你回埃及的时候，要留意在法老面前行我交在你手中的一切奇事；但我要使他的心刚硬，他必不让百姓离去。</span>
<span className="v" id="v22" data-v="22" data-xref="何西阿 11:1; 罗马书 9:4; 耶利米书 31:9"> 你要对法老说：‘耶和华这样说：以色列是我的儿子，我的长子；</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 11:5; 出埃及记 12:29; 诗篇 135:8"> 我已经对你说：“让我的儿子离去，好事奉我；”但你拒绝让他离去。看哪，我要杀你的长子。’”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="创世记 17:14; 民数记 22:22–23; 何西阿 13:8"> 在路上的住宿处，耶和华遇见摩西，想要杀他。</span>
<span className="v" id="v25" data-v="25" data-xref="约书亚记 5:2–3; 创世记 17:14; 撒母耳记下 16:7"> 西坡拉就拿一块火石，割下她儿子的包皮，丢在他的脚前；她说：“你真是我血的新郎。”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 于是耶和华放过了他。那时她说：“你是血的新郎，”这是因割礼的缘故。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="出埃及记 3:1; 出埃及记 4:14–16; 列王纪上 19:8"> 耶和华对亚伦说：“到旷野去迎接摩西。”<br />他就去，在上帝的山遇见摩西，并亲吻他。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 4:8–9; 出埃及记 4:15–16; 马太福音 21:29"> 摩西把耶和华差遣他时所说的一切话，以及吩咐他行的一切神迹，都告诉了亚伦。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 3:16; 出埃及记 24:11; 出埃及记 24:1"> 摩西和亚伦就去，召集了以色列子孙的所有长老。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 4:16"> 亚伦把耶和华对摩西所说的一切话都说了，又在百姓眼前行了那些神迹。</span>
<span className="v" id="v31" data-v="31" data-xref="出埃及记 3:18; 出埃及记 2:25; 诗篇 106:12–13"> 百姓就信了；他们听见耶和华眷顾以色列子孙，并且看见他们所受的苦难，就低头敬拜。</span>
</div>

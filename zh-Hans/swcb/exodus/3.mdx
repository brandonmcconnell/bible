<span className="v" id="v1" data-v="1" data-xref="列王纪上 19:8; 出埃及记 17:6; 诗篇 78:70–72"> 那时，摩西牧放他岳父、米甸祭司叶忒罗的羊群；他把羊群赶到旷野的深处，来到上帝的山，就是何烈山。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 7:30–35; 以赛亚书 43:2; 马可福音 12:26"> 耶和华<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="当英文以全大写形式写作“LORD”或“GOD”时，是对上帝专有名（希伯来文“יהוה”，通常读作“雅威”）的翻译。">a</a></sup>的使者在荆棘丛中、从火焰里向他显现。他观看，看哪，荆棘丛被火烧着，却没有烧毁。</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 7:31; 诗篇 107:8; 约伯记 37:14"> 摩西说：“我要转过去，看看这大异象，为什么荆棘丛没有烧掉。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="申命记 33:16; 撒母耳记上 3:6; 使徒行传 9:4"> 耶和华看见他转过去要看，上帝就从荆棘丛中呼唤他说：“摩西！摩西！”<br />他说：“我在这里。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约书亚记 5:15; 使徒行传 7:33; 出埃及记 19:12"> 祂说：“不要靠近这里。把你脚上的鞋脱下来，因为你所站的地方是圣地。”</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 20:37; 马太福音 22:32; 出埃及记 4:5"> 祂又说：“我是你父亲的上帝，是亚伯拉罕的上帝，以撒的上帝，雅各的上帝。”<br />摩西遮住脸，因为他害怕看上帝。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="诗篇 145:19; 诗篇 106:44; 出埃及记 2:23–25"> 耶和华说：“我确实看见了我的百姓在埃及所受的苦，也听见了他们因督工而发出的呼喊；我知道他们的痛苦。</span>
<span className="v" id="v8" data-v="8" data-xref="创世记 50:24; 创世记 15:18–21; 出埃及记 3:17"> 我下来，要从埃及人手中救他们，领他们离开那地，上到美好宽阔之地，到流奶与蜜之地；就是迦南人、赫人、亚摩利人、比利洗人、希未人、耶布斯人的地方。</span>
<span className="v" id="v9" data-v="9" data-xref="箴言 22:22–23; 出埃及记 2:23; 出埃及记 1:13–14"> 现在，看哪，以色列子孙的呼喊已经达到我这里；我也看见埃及人怎样欺压他们。</span>
<span className="v" id="v10" data-v="10" data-xref="弥迦书 6:4; 撒母耳记上 12:6; 诗篇 105:26"> 现在你来，我要差你到法老那里，使你把我的百姓以色列子孙从埃及领出来。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 18:18; 哥林多后书 3:5; 出埃及记 6:12"> 摩西对上帝说：“我是谁，竟能到法老那里，又竟能把以色列子孙从埃及领出来呢？”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约书亚记 1:5; 罗马书 8:31; 以赛亚书 41:10"> 祂说：“我必定与你同在。这将是我差遣你的记号：你把百姓从埃及领出来以后，你们必在这山上事奉上帝。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="箴言 30:4; 以赛亚书 9:6; 耶利米书 23:6"> 摩西对上帝说：“看哪，我到以色列子孙那里，对他们说：‘你们祖宗的上帝差我到你们这里来。’他们若问我：‘祂叫什么名字？’我该对他们说什么呢？”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="约翰福音 8:58; 希伯来书 13:8; 启示录 1:8"> 上帝对摩西说：“我是自有永有者。”又说：“你要这样告诉以色列人：‘自有永有者差我到你们这里来。’”</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 17:7–8; 希伯来书 13:8; 玛拉基书 3:6"> 上帝又对摩西说：“你要这样告诉以色列子孙：‘耶和华<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“LORD”或“GOD”若为全大写，除非另有说明是来自短形式 יה Yah，都是来自希伯来文 יהוה Yahweh。">b</a></sup>，你们祖宗的上帝，亚伯拉罕的上帝，以撒的上帝，雅各的上帝，差我到你们这里来。’这是我的名，直到永远；这也是我世世代代被记念的名。</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 8:4; 出埃及记 4:31; 出埃及记 4:29"> 你去召集以色列的长老，对他们说：‘耶和华，你们祖宗的上帝，亚伯拉罕的上帝，以撒的上帝，雅各的上帝，向我显现，说：“我确实眷顾了你们，也看见了你们在埃及所遭遇的事。</span>
<span className="v" id="v17" data-v="17" data-xref="创世记 15:13–21; 创世记 50:24; 创世记 46:4"> 我已经说，我要把你们从埃及的苦难中领上来，到迦南人、赫人、亚摩利人、比利洗人、希未人、耶布斯人的地，到流奶与蜜之地。”’</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 9:1; 出埃及记 7:16; 出埃及记 10:24–26"> 他们会听你的话。你和以色列的长老要去见埃及王，对他说：‘耶和华，希伯来人的上帝，已经与我们相会。现在求你让我们走三天的路程到旷野去，好向耶和华我们的上帝献祭。’</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 5:2; 出埃及记 6:1; 出埃及记 7:1–14"> 我知道，若不是被大能的手迫使，埃及王不会准你们去。</span>
<span className="v" id="v20" data-v="20" data-xref="使徒行传 7:36; 尼希米记 9:10; 出埃及记 9:15"> 我必伸出我的手，在埃及中施行我一切奇事，击打埃及；此后他就会让你们走。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 12:36; 诗篇 105:37; 出埃及记 11:3"> 我必使这百姓在埃及人眼前蒙恩；你们离开的时候，必不空手而去。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结 39:10; 出埃及记 11:2; 出埃及记 12:35–36"> 但每个妇人都要向她的邻舍和到她家来的女人要银饰、金饰和衣服。你们要把这些穿戴在你们的儿子和女儿身上。你们要掠夺埃及人。”</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1"> 耶和华对摩西说：</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 9:7; 尼希米记 11:2; 以斯拉记 2:68"> “你要吩咐以色列人，让他们为我收取奉献物；凡心里甘愿的人，你们都要从他收取我的奉献物。</span>
<span className="v" id="v3" data-v="3" data-xref="申命记 8:9; 约伯记 28:2"> 你们要从他们收取的奉献物是：金、银、铜，</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 19:8; 创世记 41:42; 以西结 16:10"> 蓝色线、紫色线、朱红色线、细麻、山羊毛，</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 26:37–1; 出埃及记 26:14–15; 出埃及记 36:20"> 染红的公羊皮、海牛皮，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：精制皮革">a</a></sup>皂荚木，</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 27:20; 出埃及记 25:37; 出埃及记 40:24–25"> 点灯的油，作膏油和馨香香料用的香料，</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 28:4; 出埃及记 28:6–30"> 红玛瑙，以及镶嵌在以弗得和胸牌上的宝石。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 6:16; 列王纪上 6:13; 启示录 21:3"> 他们要为我造一座圣所，使我可以住在他们中间。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 25:40; 希伯来书 8:5; 使徒行传 7:44"> 你们要照我所指示你的一切，就是帐幕的样式和其中一切器具的样式，照样去做。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="希伯来书 9:4; 出埃及记 37:1–3; 申命记 10:1–3"> “他们要用皂荚木造一只柜。柜长二肘半，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一肘是人手臂从中指尖到肘部的长度，约十八英寸或四十六厘米。">b</a></sup>宽一肘半，高一肘半。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 25:24; 出埃及记 30:3; 历代志下 3:4"> 你要用纯金包裹它；里外都要包裹，并要在四围镶上金边。</span>
<span className="v" id="v12" data-v="12" data-xref="出埃及记 27:7; 出埃及记 25:26; 出埃及记 25:15"> 你要为它铸四个金环，安在它的四只脚上；这边两个环，那边两个环。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 15:15; 民数记 4:11; 出埃及记 27:6"> 你要用皂荚木做杠，并用金包裹。</span>
<span className="v" id="v14" data-v="14"> 要把杠穿在柜旁的环内，用来抬柜。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪上 8:8; 历代志下 5:9"> 杠要留在柜的环内，不可从柜上抽出来。</span>
<span className="v" id="v16" data-v="16" data-xref="申命记 31:26; 列王纪上 8:9; 希伯来书 9:4"> 我将要赐给你的约，你要放在柜里。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 9:5; 出埃及记 37:6; 希伯来书 4:16"> 你要用纯金造一块施恩座，长二肘半，宽一肘半。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结 10:20; 希伯来书 9:5; 列王纪上 8:6–7"> 你要用锤出的金子造两个基路伯，安在施恩座的两端。</span>
<span className="v" id="v19" data-v="19"> 这端造一个基路伯，那端造一个基路伯；施恩座两端的基路伯要和施恩座连成一体。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志上 28:18; 列王纪上 8:7; 希伯来书 9:5"> 基路伯要向上展开翅膀，用翅膀遮盖施恩座；他们要彼此相对。基路伯的脸要朝向施恩座。</span>
<span className="v" id="v21" data-v="21" data-xref="出埃及记 26:34; 罗马书 10:4; 出埃及记 25:16–17"> 你要把施恩座安在柜的上面，又要把我将要赐给你的约放在柜里。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 29:42–43; 民数记 7:89; 以赛亚书 37:16"> 我要在那里与你相会；我要从施恩座以上，从约柜上两个基路伯中间，把我所要吩咐你传给以色列人的一切告诉你。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="希伯来书 9:2; 出埃及记 37:10–16; 列王纪上 7:48"> “你要用皂荚木造一张桌子，长二肘，宽一肘，高一肘半。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 25:11; 列王纪上 6:20–22"> 你要用纯金包裹它，并在四围镶上金边。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 37:2; 出埃及记 30:3"> 你要在桌子的四围做一掌宽的框，又要在框的四围镶上金边。</span>
<span className="v" id="v26" data-v="26"> 你要为桌子做四个金环，把环安在四只脚上的四角。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 25:14; 出埃及记 25:28"> 环要靠近框，作为穿杠的地方，用来抬桌子。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 25:14; 使徒行传 9:15; 民数记 10:17"> 你要用皂荚木做杠，并用金包裹，好用杠抬桌子。</span>
<span className="v" id="v29" data-v="29" data-xref="民数记 4:7; 出埃及记 37:16; 启示录 3:20"> 你要做桌上的盘子、调羹、壶和碗，用来浇奠祭；这些都要用纯金做。</span>
<span className="v" id="v30" data-v="30" data-xref="利未记 24:5–9; 马太福音 12:4; 出埃及记 39:36"> 你要常常把陈设饼摆在桌上，在我面前。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="列王纪上 7:49; 撒迦利亚书 4:2; 出埃及记 37:17–24"> “你要用纯金造一座灯台。灯台要用锤出的工艺制成；它的座、干、杯、球和花，都要与它连成一体。</span>
<span className="v" id="v32" data-v="32"> 灯台两旁要伸出六个枝子：这边伸出三个枝子，那边伸出三个枝子；</span>
<span className="v" id="v33" data-v="33" data-xref="民数记 17:4–8; 耶利米书 1:11–12; 撒迦利亚书 4:3"> 这一个枝子上有三个杯，形状像杏花，有球有花；那一个枝子上也有三个杯，形状像杏花，有球有花；从灯台伸出的六个枝子都是这样。</span>
<span className="v" id="v34" data-v="34"> 灯台本身要有四个杯，形状像杏花，有球有花；</span>
<span className="v" id="v35" data-v="35"> 灯台伸出的六个枝子中，每两个枝子下有一个球，与灯台连成一体，每两个枝子下有一个球，与灯台连成一体，每两个枝子下有一个球，与灯台连成一体。</span>
<span className="v" id="v36" data-v="36" data-xref="出埃及记 25:18; 列王纪上 10:16–17; 历代志下 9:15"> 这些球和枝子都要与灯台连成一体，全部是一件用纯金锤出的作品。</span>
<span className="v" id="v37" data-v="37" data-xref="民数记 8:2; 启示录 1:20–1; 利未记 24:2–4"> 你要做七盏灯；人要点亮这些灯，使灯光照在灯台前方。</span>
<span className="v" id="v38" data-v="38" data-xref="列王纪下 12:13; 耶利米书 52:18; 列王纪下 25:14"> 灯剪和灯花盘都要用纯金做。</span>
<span className="v" id="v39" data-v="39"> 灯台和这一切器具，要用一他连得<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一他连得约为三十公斤，或六十六磅，或九百六十五金衡盎司。">c</a></sup>纯金制成。</span>
<span className="v" id="v40" data-v="40" data-xref="希伯来书 8:5; 出埃及记 26:30; 使徒行传 7:44"> 你要谨慎，照着在山上指示给你的样式去做。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 27:1–8; 以西结 43:13–17; 出埃及记 40:6"> 他用皂荚木造燔祭坛。坛是四方的，长五肘，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘是人手臂从中指尖到肘部的长度，约十八英寸或四十六厘米。">a</a></sup>宽五肘，高三肘。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 27:2; 约伯记 6:12"> 他在坛的四角上作了角；这些角与坛连成一体，又用铜包裹坛。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 27:3; 撒母耳记上 2:13"> 他作了坛的一切器具：盆、铲、盘、叉和火鼎；坛的一切器具都是用铜作的。</span>
<span className="v" id="v4" data-v="4"> 他为坛作了一个铜网格，安在坛四围的凸缘以下，达到坛的半腰。</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 27:4"> 他为铜网格的四角铸了四个环，作为穿杠的地方。</span>
<span className="v" id="v6" data-v="6" data-xref="申命记 10:3; 出埃及记 25:6"> 他用皂荚木作杠，用铜包裹。</span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 9:15; 哥林多前书 2:2; 哥林多前书 1:24"> 他把杠穿进坛两侧的环里，用来抬坛。他用木板把坛作成中空的。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 2:22; 路加福音 2:37; 出埃及记 40:7"> 他用在会幕门口服事的妇女的镜子，作了铜盆和铜盆座。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="出埃及记 27:9–19; 诗篇 89:7; 列王纪上 6:36"> 他作了院子：朝南的一面，院子的帷幔是细捻麻作的，长一百肘；</span>
<span className="v" id="v10" data-v="10"> 柱子二十根，铜座二十个；柱子的钩和横杆是银的。</span>
<span className="v" id="v11" data-v="11"> 朝北的一面也长一百肘，柱子二十根，铜座二十个；柱子的钩和横杆是银的。</span>
<span className="v" id="v12" data-v="12"> 朝西的一面，帷幔长五十肘，柱子十根，座十个；柱子的钩和横杆是银的。</span>
<span className="v" id="v13" data-v="13"> 朝东的一面长五十肘；</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 27:14"> 门这一边的帷幔长十五肘，柱子三根，座三个；</span>
<span className="v" id="v15" data-v="15"> 另一边也是这样：院门左右两边的帷幔各长十五肘，柱子各三根，座各三个。</span>
<span className="v" id="v16" data-v="16"> 院子四围所有的帷幔都是细捻麻作的。</span>
<span className="v" id="v17" data-v="17"> 柱子的座是铜的；柱子的钩和横杆是银的；柱顶包银。院子所有的柱子都有银横杆。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志下 3:14"> 院门的门帘是绣工织成的，用蓝色、紫色、朱红色线和细捻麻作成，长二十肘；按宽度量，高五肘，与院子的帷幔一样。</span>
<span className="v" id="v19" data-v="19"> 门帘的柱子四根，铜座四个；钩是银的，柱顶的包裹和横杆也是银的。</span>
<span className="v" id="v20" data-v="20" data-xref="历代志下 3:9; 出埃及记 27:19; 以弗所书 2:21–22"> 帐幕一切的橛子，以及院子四围的橛子，都是铜的。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="使徒行传 7:44; 民数记 9:15; 历代志下 24:6"> 这些是帐幕，就是见证的帐幕，所用材料的清单；这是照摩西的命令，为利未人的服事而数点的，由祭司亚伦的儿子以他玛经手。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 35:30–3; 出埃及记 31:1–5; 诗篇 119:6"> 凡耶和华吩咐摩西的，犹大支派中户珥的孙子、乌利的儿子比撒列都作了。</span>
<span className="v" id="v23" data-v="23" data-xref="出埃及记 35:34; 出埃及记 31:6"> 与他同工的有但支派中亚希撒抹的儿子亚何利亚伯；他是雕刻匠、巧匠，又是用蓝色、紫色、朱红色线和细麻作刺绣的。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数记 18:16; 民数记 3:47; 利未记 27:25"> 为圣所各项工程所用的一切金子，就是奉献的金子，共有二十九他连得<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一他连得约为三十公斤，或六十六磅，或九百六十五金衡盎司。">b</a></sup>七百三十舍客勒，是按圣所的舍客勒<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一舍客勒约为十克，或约零点三二金衡盎司。">c</a></sup>计算的。</span>
<span className="v" id="v25" data-v="25" data-xref="出埃及记 30:12"> 会众中被数点之人的银子，共有一百他连得<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一他连得约为三十公斤，或六十六磅。">d</a></sup>一千七百七十五舍客勒，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="一舍客勒约为十克，或约零点三五盎司。">e</a></sup>是按圣所的舍客勒计算的：</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 1:46; 出埃及记 30:13; 出埃及记 12:37"> 凡经过数点的，就是二十岁以上的，每人一比加<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="一比加约为五克，或约零点一七五盎司。">f</a></sup>，就是半舍客勒，是按圣所的舍客勒<sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="一舍客勒约为十克，或约零点三五盎司。">g</a></sup>计算的；共有六十万三千五百五十人。</span>
<span className="v" id="v27" data-v="27" data-xref="出埃及记 26:19; 出埃及记 26:25; 出埃及记 26:21"> 那一百他连得<sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="一他连得约为三十公斤，或六十六磅。">h</a></sup>银子用来铸造圣所的座和幔子的座：一百个座用一百他连得，每个座一他连得。</span>
<span className="v" id="v28" data-v="28" data-xref="出埃及记 27:17"> 他用那一千七百七十五舍客勒<sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="一舍客勒约为十克，或约零点三五盎司；所以一千七百七十五舍客勒约为十七点七五公斤，或约三十九磅。">i</a></sup>银子作柱子的钩，包裹柱顶，并为柱子作横杆。</span>
<span className="v" id="v29" data-v="29"> 奉献的铜共有七十他连得<sup className="fn"><a href="#fn-j" id="fnref-j" data-fn="一他连得约为三十公斤，或六十六磅。">j</a></sup>二千四百舍客勒。<sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="七十他连得加二千四百舍客勒约为二千一百二十四公斤，或二点一二四公吨。">k</a></sup></span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 26:37; 出埃及记 27:17; 出埃及记 27:10"> 他用这些铜作会幕门口的座、铜坛和坛上的铜网格、坛的一切器具，</span>
<span className="v" id="v31" data-v="31"> 院子四围的座、院门的座、帐幕一切的橛子，以及院子四围一切的橛子。</span>
</div>
</div>

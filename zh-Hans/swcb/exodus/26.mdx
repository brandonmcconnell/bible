<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 36:8–19; 出埃及记 26:36; 出埃及记 26:31"> “此外，你要用捻成的细麻和蓝色、紫色、朱红色线做会幕的十幅幔子；要用巧匠的手艺做成，带有基路伯的图案。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 7:2; 民数记 4:25; 历代志上 17:1"> 每幅幔子要长二十八肘，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘是人手臂从中指尖到肘部的长度，约为十八英寸或四十六厘米。">a</a></sup>宽四肘；所有幔子都要同一尺寸。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 36:10; 歌罗西书 2:2; 以弗所书 2:21–22"> 五幅幔子要彼此相连，另外五幅幔子也要彼此相连。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 36:11–12; 出埃及记 36:17; 出埃及记 26:10–11"> 你要在第一组相连的幔子中、最边上一幅幔子的边缘做蓝色钮环；在第二组相连的幔子中、最外边一幅幔子的边缘，也要照样做。</span>
<span className="v" id="v5" data-v="5"> 你要在这一幅幔子上做五十个钮环，也要在第二组相连的那幅幔子边缘做五十个钮环；钮环要彼此相对。</span>
<span className="v" id="v6" data-v="6" data-xref="出埃及记 36:13; 出埃及记 26:11; 出埃及记 26:33"> 你要做五十个金扣，用这些扣把幔子彼此相连，使会幕成为一体。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 26:14; 诗篇 45:13; 出埃及记 26:9"> “你要用山羊毛做幔子，作为会幕以上的遮盖；要做十一幅幔子。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 26:13; 出埃及记 26:2"> 每幅幔子要长三十肘，宽四肘；十一幅幔子都要同一尺寸。</span>
<span className="v" id="v9" data-v="9"> 你要把五幅幔子单独相连，又把六幅幔子单独相连，并要把第六幅幔子在帐幕前面折叠起来。</span>
<span className="v" id="v10" data-v="10"> 你要在第一组相连幔子最外边一幅的边缘做五十个钮环，又在第二组相连幔子最外边一幅的边缘做五十个钮环。</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 26:3; 出埃及记 26:6"> 你要做五十个铜扣，把扣穿进钮环，使帐幕相连，成为一体。</span>
<span className="v" id="v12" data-v="12"> 帐幕幔子余下垂出的部分，就是余下的半幅幔子，要垂在会幕的后面。</span>
<span className="v" id="v13" data-v="13" data-xref="出埃及记 26:2; 出埃及记 26:8"> 帐幕幔子长度余下的部分，这边一肘，那边一肘，要垂在会幕的两侧，在这边和那边遮盖会幕。</span>
<span className="v" id="v14" data-v="14" data-xref="出埃及记 36:19; 出埃及记 25:5; 出埃及记 35:23"> 你要为帐幕做一个染红公羊皮的罩盖，上面再加一个海牛皮的罩盖。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="出埃及记 36:20–33; 民数记 4:31–32; 出埃及记 40:17–18"> “你要用皂荚木做会幕的木板，竖立起来。</span>
<span className="v" id="v16" data-v="16"> 每块板要长十肘，每块板宽一肘半。</span>
<span className="v" id="v17" data-v="17" data-xref="出埃及记 36:22; 出埃及记 26:19; 出埃及记 36:24"> 每块板要有两个榫头，彼此相连；会幕所有的木板都要这样做。</span>
<span className="v" id="v18" data-v="18"> 你要为会幕做二十块木板，用在朝南的一侧。</span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 38:27; 出埃及记 38:30–31; 出埃及记 26:37"> 在这二十块木板下面，你要做四十个银座；一块板下面有两个座，承接它的两个榫头，另一块板下面也有两个座，承接它的两个榫头。</span>
<span className="v" id="v20" data-v="20"> 会幕的第二面，就是北侧，也要做二十块木板，</span>
<span className="v" id="v21" data-v="21"> 和四十个银座；一块板下面有两个座，另一块板下面也有两个座。</span>
<span className="v" id="v22" data-v="22"> 会幕后面，就是西面，你要做六块木板。</span>
<span className="v" id="v23" data-v="23"> 会幕后面的两个角，要做两块木板。</span>
<span className="v" id="v24" data-v="24" data-xref="出埃及记 36:29–30; 诗篇 133:1–3; 哥林多前书 1:10"> 它们下端要双合，上端也要同样连接成一体，直到第一个环；两块都要这样，作为两个角。</span>
<span className="v" id="v25" data-v="25"> 这样共有八块木板，和它们的银座，共十六个座；一块板下面有两个座，另一块板下面也有两个座。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="罗马书 15:1; 民数记 4:31; 加拉太书 6:1–2"> “你要用皂荚木做横木：会幕这一侧的木板要五根，</span>
<span className="v" id="v27" data-v="27"> 会幕另一侧的木板要五根横木，会幕后面，就是西面那一侧的木板，也要五根横木。</span>
<span className="v" id="v28" data-v="28"> 中间的横木要在木板中间，从这一头贯穿到那一头。</span>
<span className="v" id="v29" data-v="29" data-xref="出埃及记 25:11–12"> 你要把木板包上金，又要为木板做金环，用来穿横木；横木也要包上金。</span>
<span className="v" id="v30" data-v="30" data-xref="出埃及记 25:40; 希伯来书 8:5; 出埃及记 25:9"> 你要照着在山上指示你的样式立起会幕。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="马太福音 27:51; 历代志下 3:14; 出埃及记 36:35"> “你要用蓝色、紫色、朱红色线和捻成的细麻做一幅幔子，带有基路伯的图案；这要用巧匠的手艺做成。</span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 26:37; 出埃及记 36:38; 以斯帖记 1:6"> 你要把幔子挂在四根包金的皂荚木柱子上；柱子的钩子要用金做，并安在四个银座上。</span>
<span className="v" id="v33" data-v="33" data-xref="希伯来书 9:2–3; 利未记 16:2; 出埃及记 40:21"> 你要把幔子挂在扣下，把约柜带进去，放在幔子里面；这幔子要为你们把圣所和至圣所隔开。</span>
<span className="v" id="v34" data-v="34" data-xref="出埃及记 40:20; 出埃及记 25:21; 希伯来书 9:5"> 你要把施恩座安在至圣所里的约柜上。</span>
<span className="v" id="v35" data-v="35" data-xref="出埃及记 40:24; 出埃及记 40:22; 希伯来书 9:2"> 你要把桌子摆在幔子外面，把灯台摆在桌子对面，在会幕朝南的一侧；桌子要放在北侧。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="出埃及记 36:37; 民数记 9:15; 出埃及记 26:31"> “你要为帐幕的门做一幅门帘，用蓝色、紫色、朱红色线和捻成的细麻，以刺绣工的手艺做成。</span>
<span className="v" id="v37" data-v="37" data-xref="出埃及记 36:38"> 你要为门帘做五根皂荚木柱子，包上金；柱子的钩子要用金做。你要为柱子铸造五个铜座。</span>
</div>
</div>

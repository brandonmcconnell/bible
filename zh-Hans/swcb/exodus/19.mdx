<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="出埃及记 16:1; 出埃及记 12:6; 利未记 23:16–18"> 以色列子孙出埃及地以后，第三个月，就在那一天，他们来到西奈的旷野。</span>
<span className="v" id="v2" data-v="2" data-xref="出埃及记 3:1; 出埃及记 17:1; 出埃及记 3:12"> 他们从利非订起行，来到西奈的旷野，就在旷野安营；以色列在那里，在山前安营。</span>
<span className="v" id="v3" data-v="3" data-xref="出埃及记 3:4; 使徒行传 7:38; 出埃及记 20:21"> 摩西上到上帝那里，耶和华从山上呼唤他说：“你要这样对雅各家说，告诉以色列子孙：</span>
<span className="v" id="v4" data-v="4" data-xref="申命记 32:11–12; 以赛亚书 63:9; 以赛亚书 40:31"> ‘我向埃及人所做的事，以及我怎样如鹰把你们背在翅膀上，带你们归向我，你们都看见了。</span>
<span className="v" id="v5" data-v="5" data-xref="申命记 14:2; 申命记 7:6; 申命记 26:18"> 现在，如果你们确实听从我的声音，遵守我的约，你们就要在万民中作属我的产业；因为全地都是我的；</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 5:10; 彼得前书 2:9; 彼得前书 2:5"> 你们要归我作祭司的国度，作圣洁的国民。’这些话你要告诉以色列子孙。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 4:29–30; 出埃及记 3:16; 哥林多前书 15:1"> 摩西来召了民中的长老，把耶和华吩咐他的这一切话摆在他们面前。</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 24:7; 出埃及记 24:3; 约书亚记 24:24"> 众百姓一同回答说：“耶和华所说的一切，我们都要遵行。”<br />摩西就把百姓的话回报耶和华。</span>
<span className="v" id="v9" data-v="9" data-xref="申命记 4:36; 出埃及记 19:16; 出埃及记 24:15–16"> 耶和华对摩西说：“看哪，我要在密云中临到你那里，使百姓在我与你说话的时候可以听见，也可以永远信任你。”摩西把百姓的话告诉耶和华。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 10:22; 创世记 35:2; 利未记 11:44–45"> 耶和华对摩西说：“你到百姓那里去，今天和明天使他们分别为圣，并让他们洗净衣服，</span>
<span className="v" id="v11" data-v="11" data-xref="出埃及记 19:16; 出埃及记 34:5; 申命记 33:2"> 到第三天预备好了；因为第三天，耶和华要在众百姓眼前降临在西奈山上。</span>
<span className="v" id="v12" data-v="12" data-xref="希伯来书 12:20–21; 约书亚记 3:4; 出埃及记 19:21"> 你要在四围给百姓划定界限，说：‘你们要谨慎，不可上山，也不可触碰山的边界。凡触碰这山的，必要被处死。</span>
<span className="v" id="v13" data-v="13" data-xref="帖撒罗尼迦前书 4:16; 希伯来书 12:20; 出埃及记 19:16"> 不可有手触碰他；他必要被石头打死，或被箭射穿；无论是牲畜还是人，都不可存活。’号角拉长声的时候，他们才可以上到山那里。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及记 19:10"> 摩西从山上下到百姓那里，使百姓分别为圣；他们就洗净自己的衣服。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 7:5; 撒母耳记上 21:4–5; 出埃及记 19:11"> 他对百姓说：“到第三天要预备好。不可与女人同房。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="希伯来书 12:18–19; 诗篇 18:11–14; 希伯来书 12:21"> 到了第三天早晨，山上有雷轰、闪电和密云，并且有极响亮的号角声；营中的众百姓都战抖。</span>
<span className="v" id="v17" data-v="17" data-xref="申命记 4:10; 申命记 5:5"> 摩西领百姓出营去迎见上帝；他们站在山脚下。</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 5:5; 出埃及记 3:2; 诗篇 144:5"> 整座西奈山都冒烟，因为耶和华在火中降临在山上；山的烟上腾，如烧窑的烟一样，整座山大大震动。</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 81:7; 出埃及记 19:16; 尼希米记 9:13"> 号角的声音越来越响，摩西说话，上帝就用声音回答他。</span>
<span className="v" id="v20" data-v="20" data-xref="尼希米记 9:13; 出埃及记 34:2; 出埃及记 19:11"> 耶和华降临在西奈山上，在山顶上。耶和华召摩西上山顶，摩西就上去了。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 6:19; 出埃及记 3:5; 希伯来书 12:28–29"> 耶和华对摩西说：“你下去警告百姓，免得他们闯过来要观看耶和华，以致许多人灭亡。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 24:5; 使徒行传 5:10; 历代志上 13:9–11"> 又要让那些亲近耶和华的祭司使自己分别为圣，免得耶和华冲击他们。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="出埃及记 19:12; 约书亚记 3:4–5"> 摩西对耶和华说：“百姓不能上西奈山，因为你已经警告我们说：‘要在山的四围划定界限，使山分别为圣。’”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="希伯来书 4:16; 希伯来书 12:18–25; 希伯来书 12:29"> 耶和华对他说：“下去吧！你要带亚伦和你一同上来；只是不可让祭司和百姓闯过来上到耶和华这里，免得祂冲击他们。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 于是摩西下到百姓那里，告诉他们。</span>
</div>
</div>

</div>

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="撒迦利亚书 14:5; 历代志下 26:1–23; 列王纪上 19:19"> 这是阿摩司的话；他是提哥亚牧人中的一员，在犹大王乌西雅的日子，以色列王约阿施的儿子耶罗波安的日子，在地震前两年，他论以色列所见的。</span>
<span className="v" id="v2" data-v="2" data-xref="约珥 3:16; 耶利米书 25:30; 阿摩司 9:3"> 他说：<br /><span className="pl pl-1">“耶和华</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="当英文以全大写字母写作“LORD”或“GOD”时，是上帝专有名（希伯来文“יהוה”，通常读作 Yahweh）的译法。">a</a></sup><br /><span className="pl pl-1">必从锡安吼叫，</span><br /><span className="pl pl-2">从耶路撒冷发声；</span><br /><span className="pl pl-1">牧人的草场必悲哀，</span><br /><span className="pl pl-2">迦密的山顶必枯干。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="列王纪下 8:12; 阿摩司 1:9; 以赛亚书 8:4"> 耶和华如此说：<br /><span className="pl pl-1">“因大马士革三番四次地犯罪，</span><br /><span className="pl pl-2">我必不撤回对它的惩罚，</span><br /><span className="pl pl-2">因为他们用铁打谷器碾压基列；</span></span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 49:27; 列王纪下 6:24; 列王纪下 13:25"> <span className="pl pl-1">所以我必降火在哈薛家中，</span><br /><span className="pl pl-2">吞灭便哈达的宫殿。</span></span>
<span className="v" id="v5" data-v="5" data-xref="列王纪下 16:9; 阿摩司 9:7; 耶利米书 51:30"> <span className="pl pl-1">我必折断大马士革的门闩，</span><br /><span className="pl pl-2">从亚文谷剪除居民，</span><br /><span className="pl pl-2">从伊甸家剪除执掌权杖的人；</span><br /><span className="pl pl-2">亚兰的百姓必被掳到吉珥，”</span><br />这是耶和华说的。</span>
</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="阿摩司 1:11; 历代志下 28:18; 俄巴底亚 1:11"> 耶和华如此说：<br /><span className="pl pl-1">“因迦萨三番四次地犯罪，</span><br /><span className="pl pl-2">我必不撤回对它的惩罚，</span><br /><span className="pl pl-2">因为他们掳走了整个群体，</span><br /><span className="pl pl-2">把他们交给以东；</span></span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 18:8; 耶利米书 47:1; 西番雅书 2:4"> <span className="pl pl-1">所以我必降火在迦萨的城墙上，</span><br /><span className="pl pl-2">吞灭它的宫殿。</span></span>
<span className="v" id="v8" data-v="8" data-xref="以西结 25:16; 以赛亚书 14:29–31; 耶利米书 47:4–5"> <span className="pl pl-1">我必从亚实突剪除居民，</span><br /><span className="pl pl-2">从亚实基伦剪除执掌权杖的人；</span><br /><span className="pl pl-1">我必转手攻击以革伦；</span><br /><span className="pl pl-2">非利士人的余民必灭亡，”</span><br />这是主<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="译作“主”的词是“Adonai”。">b</a></sup>耶和华说的。</span>
</div>
<div className="bp poetry">
<span className="v" id="v9" data-v="9" data-xref="列王纪上 9:11–14; 以赛亚书 23:1–18; 约珥 3:4–8"> 耶和华如此说：<br /><span className="pl pl-1">“因推罗三番四次地犯罪，</span><br /><span className="pl pl-2">我必不撤回对它的惩罚；</span><br /><span className="pl pl-2">因为他们把整个群体交给以东，</span><br /><span className="pl pl-2">又不记念弟兄之约；</span></span>
<span className="v" id="v10" data-v="10" data-xref="撒迦利亚书 9:4; 阿摩司 1:7; 阿摩司 1:4"> <span className="pl pl-1">所以我必降火在推罗的城墙上，</span><br /><span className="pl pl-2">吞灭它的宫殿。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v11" data-v="11" data-xref="以西结 25:12–14; 历代志下 28:17; 玛拉基书 1:4"> 耶和华如此说：<br /><span className="pl pl-1">“因以东三番四次地犯罪，</span><br /><span className="pl pl-2">我必不撤回对他的惩罚，</span><br /><span className="pl pl-2">因为他用刀追赶自己的弟兄，</span><br /><span className="pl pl-2">抛弃一切怜悯，</span><br /><span className="pl pl-2">他的怒气不断发作，</span><br /><span className="pl pl-2">永远怀着烈怒；</span></span>
<span className="v" id="v12" data-v="12" data-xref="耶利米书 49:7; 俄巴底亚 1:9–10; 耶利米书 49:20"> <span className="pl pl-1">所以我必降火在提幔，</span><br /><span className="pl pl-2">吞灭波斯拉的宫殿。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v13" data-v="13" data-xref="何西阿 13:16; 以西结 25:2–7; 耶利米书 49:1–6"> 耶和华如此说：<br /><span className="pl pl-1">“因亚扪人三番四次地犯罪，</span><br /><span className="pl pl-2">我必不撤回对他们的惩罚，</span><br /><span className="pl pl-2">因为他们剖开基列的孕妇，</span><br /><span className="pl pl-2">为要扩张自己的疆界。</span></span>
<span className="v" id="v14" data-v="14" data-xref="耶利米书 49:2; 阿摩司 2:2; 申命记 3:11"> <span className="pl pl-1">所以我必在拉巴的城墙内点火，</span><br /><span className="pl pl-2">吞灭它的宫殿，</span><br /><span className="pl pl-2">在争战的日子伴随着呐喊，</span><br /><span className="pl pl-2">在旋风的日子伴随着暴风；</span></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 49:3"> <span className="pl pl-1">他们的王必被掳去，</span><br /><span className="pl pl-2">他和他的首领都一同被掳，”</span><br />这是耶和华说的。</span>
</div>

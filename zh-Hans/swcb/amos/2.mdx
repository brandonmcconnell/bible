</div>
<div className="bp poetry">
<span className="v" id="v6" data-v="6" data-xref="约珥 3:3; 弥迦书 3:2–3; 阿摩司 5:11–12"> 耶和华如此说：<br /><span className="pl pl-1">“以色列三番四次地犯罪，</span><br /><span className="pl pl-2">我必不撤回对它的惩罚，</span><br /><span className="pl pl-2">因为他们为银子出卖义人，</span><br /><span className="pl pl-2">为一双鞋出卖穷乏人；</span><br /></span>
<span className="v" id="v7" data-v="7" data-xref="阿摩司 5:12; 以赛亚书 10:2; 以西结 22:11"> <span className="pl pl-2">他们把贫穷人的头践踏在地上的尘土中，</span><br /><span className="pl pl-2">又使受欺压的人得不到公正。</span><br /><span className="pl pl-1">父子二人与同一个少女同寝，以亵渎我的圣名。</span></span>
<span className="v" id="v8" data-v="8" data-xref="申命记 24:12–17; 出埃及记 22:26–27; 阿摩司 6:6"> <span className="pl pl-2">他们在各祭坛旁躺卧在拿来作抵押的衣服上。</span><br /><span className="pl pl-2">在他们上帝</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="译作“上帝”的希伯来词是“אֱלֹהִ֑ים”（Elohim）。">a</a></sup><br /><span className="pl pl-2">的殿里，他们喝受罚之人的酒。</span></span>
<span className="v" id="v9" data-v="9" data-xref="约伯记 18:16; 玛拉基书 4:1; 申命记 3:11"> <span className="pl pl-1">然而，我曾在他们面前毁灭亚摩利人，</span><br /><span className="pl pl-2">他的身量如香柏树那样高，</span><br /><span className="pl pl-2">他像橡树那样强壮；</span><br /><span className="pl pl-2">然而，我毁灭了他上面的果子，</span><br /><span className="pl pl-2">也毁灭了他下面的根。</span></span>
<span className="v" id="v10" data-v="10" data-xref="申命记 2:7; 出埃及记 12:51; 阿摩司 3:1"> <span className="pl pl-1">我也曾把你们从埃及地领上来，</span><br /><span className="pl pl-2">在旷野引导你们四十年，</span><br /><span className="pl pl-2">使你们得亚摩利人的土地为业。</span></span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 7:25; 民数记 6:2–3; 列王纪上 20:41"> <span className="pl pl-1">我从你们的儿子中兴起一些人作先知，</span><br /><span className="pl pl-2">又从你们的青年中兴起一些人作拿细耳人。</span><br /><span className="pl pl-1">以色列人哪，这不是事实吗？”</span><br /><span className="pl pl-2">耶和华说。</span></span>
<span className="v" id="v12" data-v="12" data-xref="阿摩司 7:13; 以赛亚书 30:10; 耶利米书 11:21"> <span className="pl pl-1">“可是你们给拿细耳人酒喝，</span><br /><span className="pl pl-2">又吩咐先知说：‘不可说预言！’</span></span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 1:14; 以赛亚书 43:24; 以西结 16:43"> <span className="pl pl-1">看哪，</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“看哪”来自“הִנֵּה”，意思是看、留意、观察、观看或凝视，常用作感叹词。">b</a></sup><br /><span className="pl pl-1">我要在你们所在之处压垮你们，</span><br /><span className="pl pl-2">如同满载禾捆的车压过一样。</span></span>

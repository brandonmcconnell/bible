<span className="v" id="v1" data-v="1" data-xref="诗篇 68:21; 启示录 1:17; 以赛亚书 6:1"> 我看见主站在祭坛旁边；祂说：“击打柱头，使门槛震动。把它们打碎，砸在众人的头上。剩下的人，我必用刀杀死；他们中没有一个能逃走，没有一个能逃脱。</span>
<span className="v" id="v2" data-v="2" data-xref="耶利米书 51:53; 诗篇 139:7–10; 俄巴底亚 1:4"> 他们即使挖入阴间，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="阴间是死人所在的地方。">a</a></sup>我的手也必从那里抓住他们；他们即使爬上天，我也必从那里把他们拉下来。</span>
<span className="v" id="v3" data-v="3" data-xref="耶利米书 16:16; 耶利米书 23:23–24; 以赛亚书 27:1"> 他们即使藏在迦密山顶，我也必搜寻，把他们从那里捉出来；他们即使从我眼前藏在海底，我也必在那里命令蛇，蛇必咬他们。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 26:33; 耶利米书 21:10; 耶利米书 44:11"> 他们即使被掳到仇敌面前，我也必在那里命令刀剑，刀剑必杀他们。我要定睛在他们身上，降祸不降福。</span>
<span className="v" id="v5" data-v="5" data-xref="阿摩司 8:8; 诗篇 46:6; 以赛亚书 64:1"> 因为主万军之耶和华<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="当译作全大写的“LORD”或“GOD”时，它是上帝专有名（希伯来文“יהוה”，通常发音为雅威）的翻译。">b</a></sup>一触摸地，地就消融；凡住在地上的都必哀哭。全地必像大河涨起，又像埃及的河退落。</span>
<span className="v" id="v6" data-v="6" data-xref="阿摩司 5:8; 阿摩司 4:13; 诗篇 104:3"> 祂在天上建造祂的楼阁，在地上奠定祂的穹隆；祂召唤海水，把水倾倒在地面上——耶和华是祂的名。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 47:4; 申命记 2:23; 列王纪下 16:9"> 耶和华说：“以色列人哪，你们在我看来，岂不像古实人的儿女吗？我岂不是曾把以色列从埃及地领上来，也把非利士人从迦斐托、亚兰人从吉珥领上来吗？</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 30:11; 阿摩司 9:4; 耶利米书 44:27"> 看哪，主耶和华的眼目察看这犯罪的国；我必将它从地面上毁灭，只是我必不把雅各家全然毁灭。”耶和华说。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 22:31; 申命记 28:64; 以赛亚书 30:28"> “因为看哪，我要发命令，把以色列家筛在列国中，好像用筛子筛谷物一样；然而连最小的一粒也不会落在地上。</span>
<span className="v" id="v10" data-v="10" data-xref="阿摩司 6:3; 以赛亚书 33:14; 阿摩司 6:1"> 我民中凡说‘灾祸必追不上我们，也不会遇见我们’的罪人，都必死在刀下。</span>
<span className="v" id="v11" data-v="11" data-xref="使徒行传 15:15–17; 耶利米书 33:14–16; 以赛亚书 16:5"> 到那日，我必使已经倒塌的大卫帐幕重新立起，堵住它的破口；我必使它的废墟重新立起，建造它如古时一样，</span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 43:7; 以赛亚书 65:1; 使徒行传 15:17"> 使他们可以拥有以东所剩余的，以及所有称为我名下的列国。”行这事的耶和华说。</span>
<span className="v" id="v13" data-v="13" data-xref="约珥 3:18; 约翰福音 4:35; 利未记 26:5"> <span className="pl pl-1">耶和华说：“看哪，日子将到，</span><br /><span className="pl pl-2">耕地的必追上收割的，</span><br /><span className="pl pl-2">踹葡萄的必追上撒种的；</span><br /><span className="pl pl-2">众山要滴下甜酒，</span><br /><span className="pl pl-2">众岭都要流淌。</span></span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 61:4; 耶利米书 30:3; 耶利米书 30:18"> <span className="pl pl-1">我要使我民以色列从被掳中归回；</span><br /><span className="pl pl-2">他们要重建荒废的城邑，并住在其中；</span><br /><span className="pl pl-2">他们要栽种葡萄园，喝其中所出的酒。</span><br /><span className="pl pl-1">他们也要建造园子，</span><br /><span className="pl pl-2">吃其中的果子。</span></span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 24:6; 以西结 37:25; 以赛亚书 60:21"> <span className="pl pl-1">我要把他们栽植在他们的地上；</span><br /><span className="pl pl-2">他们不再从我所赐给他们的地上被拔出来。”</span><br /><span className="pl pl-2">耶和华你的上帝说。</span></span>

<span className="v" id="v1" data-v="1" data-xref="历代志下 6:7–9; 历代志上 15:1; 历代志上 17:5"> 大卫住在自己的宫中时，就对先知拿单说：“看哪，我住在香柏木的宫中，耶和华的约柜却在帐幕里。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="历代志上 28:2; 哥林多前书 13:9; 撒迦利亚书 8:23"> 拿单对大卫说：“你心里所想的一切，都去做吧；因为上帝与你同在。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="阿摩司 3:7; 民数记 12:6; 以赛亚书 30:21"> 当夜，上帝的话临到拿单，说：</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 28:2–3; 以赛亚书 55:8–9; 历代志下 6:8–9"> “你去告诉我的仆人大卫：‘耶和华这样说：“你不可为我建造居住的殿；</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 7:6; 出埃及记 40:2–3; 列王纪上 8:16"> 因为自从我带以色列上来那日直到今日，我未曾住在殿里，而是从帐幕到帐幕，从一个居所到另一个居所。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 7:7; 民数记 10:33–36; 哥林多后书 6:16"> 凡我与全以色列同行的地方，我何曾对我所吩咐牧养我子民的以色列士师中任何一位说过一句话：‘你们为什么没有为我建造香柏木的殿呢？’”’</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 6:21; 出埃及记 3:1–10; 撒母耳记上 17:15"> “现在，你要告诉我的仆人大卫：‘万军之耶和华这样说：“我从羊圈中，从跟随羊群之处取了你，立你作我民以色列的君王。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记上 18:14; 历代志上 17:2; 诗篇 113:7–8"> 你无论往哪里去，我都与你同在，并且从你面前剪除你所有的仇敌。我要使你的名像地上伟人的名一样。</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 2:23; 以西结 28:4; 以弗所书 5:6"> 我要为我的子民以色列指定一个地方，栽植他们，使他们住在自己的地方，不再被扰动；恶人的子孙也不再像起初那样毁坏他们，</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 7:11; 士师记 2:14–18; 出埃及记 1:21"> 也不再像我命士师治理我民以色列以来那样。我要制伏你所有的仇敌。而且我告诉你，耶和华必为你建立家室。</span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 132:11; 列王纪上 1:21; 历代志上 28:5"> 到你的日子满足、你必须去与你列祖同在的时候，我必在你以后兴起你的后裔，就是你众子中的一位；我必坚定他的国。</span>
<span className="v" id="v12" data-v="12" data-xref="列王纪上 5:5; 但以理 2:44; 以赛亚书 9:7"> 他必为我建造殿，我必坚定他的王位直到永远。</span>
<span className="v" id="v13" data-v="13" data-xref="希伯来书 1:5; 以赛亚书 55:3; 历代志上 17:12"> 我要作他的父，他要作我的子。我必不从他身上收回我的慈爱，像从你以前那人身上收回一样；</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 89:36; 路加福音 1:32–33; 诗篇 72:17"> 我却要使他永远立在我的殿和我的国中。他的王位必坚立直到永远。”’”</span>
<span className="v" id="v15" data-v="15" data-xref="耶利米书 23:28; 使徒行传 20:27; 撒母耳记下 7:17"> 拿单就照这一切话，照这整个异象，对大卫说了。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 7:18; 创世记 32:10; 以弗所书 3:8"> 于是大卫王进去，坐在耶和华面前，说：“耶和华上帝啊，我是谁？我的家算什么？你竟带领我到这地步。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 17:11–15; 腓立比书 2:8–11; 以赛亚书 49:6"> 上帝啊，这在你眼中还算为小事；你又论到你仆人的家，直到久远的将来，并且耶和华上帝啊，你按高贵之人的规格看待我。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 21:17; 撒母耳记上 2:30; 撒母耳记下 7:20–24"> 你赐尊荣给你的仆人，大卫还能向你再说什么呢？因为你认识你的仆人。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 37:35; 撒母耳记下 7:21; 但以理 9:17"> 耶和华啊，你为你仆人的缘故，并照你自己的心意，行了这一切伟大的事，使人知道这一切伟大的事。</span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 44:6; 耶利米书 10:6–7; 以弗所书 3:20"> 耶和华啊，照我们亲耳所听见的一切，没有谁像你；除你以外，也没有上帝。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结 20:9–10; 以赛亚书 63:9; 以赛亚书 48:9"> 地上哪一个国家像你的子民以色列呢？上帝曾去为自己救赎他们作子民，又借着大而可畏的事为你建立名声，从你所救赎、出埃及的子民面前赶出列国。</span>
<span className="v" id="v22" data-v="22" data-xref="出埃及记 19:5–6; 彼得前书 2:9; 罗马书 11:1–12"> 因为你使你的子民以色列永远作你自己的子民；耶和华啊，你也成了他们的上帝。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 119:49; 耶利米书 11:5; 路加福音 1:38"> 现在，耶和华啊，愿你论到你仆人和他家的话永远坚立；求你照你所说的去行。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 6:13; 耶利米书 31:1; 启示录 21:3"> 愿你的名永远坚立，并被尊为大，有人说：‘万军之耶和华是以色列的上帝，确是以色列的上帝；你仆人大卫的家在你面前坚立。’</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记上 9:15; 以西结 36:37; 诗篇 10:17"> 我的上帝啊，因为你已经向你的仆人启示，你要为他建立家室，所以你的仆人才有勇气在你面前祷告。</span>
<span className="v" id="v26" data-v="26" data-xref="出埃及记 34:6–7; 希伯来书 6:18; 提多书 1:2"> 现在，耶和华啊，你是上帝，你已经应许把这美好的事赐给你的仆人。</span>
<span className="v" id="v27" data-v="27" data-xref="以弗所书 1:3; 罗马书 11:29; 诗篇 72:17"> 现在，你乐意赐福给你仆人的家，使它永远在你面前存续；因为耶和华啊，你已经赐福，它就永远蒙福。”</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 46:13; 民数记 26:23–24"> 以萨迦的儿子有陀拉、普瓦、雅述、伸仑，共四人。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 24:1–9; 历代志上 27:23–24; 历代志上 27:1"> 陀拉的儿子有乌西、利法雅、耶利、雅买、易伯散、示母利；他们都是陀拉父家的首领，在他们的世代中是勇士。大卫在位的日子，他们的人数是二万二千六百。</span>
<span className="v" id="v3" data-v="3"> 乌西的儿子是伊斯拉希。伊斯拉希的儿子有米迦勒、俄巴底亚、约珥、伊示雅，共五人；他们全都是首领。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 12:32"> 随同他们的，按他们的世代、照他们的父家，有作战军队的班队三万六千人；因为他们有许多妻子和儿子。</span>
<span className="v" id="v5" data-v="5"> 他们的弟兄，在以萨迦所有宗族中，都是勇士；全都按家谱登记，共八万七千人。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="创世记 46:21; 历代志上 8:1–40; 历代志上 7:10–11"> 便雅悯的儿子有比拉、比结、耶叠，共三人。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 17:17–18; 历代志上 21:1–5"> 比拉的儿子有以斯本、乌西、乌薛、耶利摩、以利，共五人；他们是父家的首领，是勇士；他们按家谱登记的有二万二千零三十四人。</span>
<span className="v" id="v8" data-v="8"> 比结的儿子有西米拉、约阿施、以利以谢、以利约乃、暗利、耶利摩、亚比雅、亚拿突、亚拉篾。这些全都是比结的儿子。</span>
<span className="v" id="v9" data-v="9"> 他们按世代、照他们父家的首领登记在家谱中的，是勇士，共二万零二百人。</span>
<span className="v" id="v10" data-v="10" data-xref="士师记 3:15–30"> 耶叠的儿子是比勒罕。比勒罕的儿子有耶乌施、便雅悯、以笏、基拿拿、细坦、他施、亚希沙哈。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志下 17:13–19"> 这些全都是耶叠的子孙，按他们父家的首领，都是勇士；能出去随军作战的有一万七千二百人。</span>
<span className="v" id="v12" data-v="12" data-xref="民数记 26:38–39; 创世记 46:21; 历代志上 7:15"> 书品、户品是以珥的儿子；户伸是亚黑的儿子。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="民数记 26:48–49; 创世记 30:3–8; 创世记 35:22"> 拿弗他利的儿子有雅薛、沽尼、耶色、沙龙，都是辟拉的子孙。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 32:30–42; 士师记 5:14; 申命记 3:13–15"> 玛拿西的儿子有亚斯列，是他的亚兰妾所生的。她生了基列的父亲玛吉。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 26:33; 民数记 36:1–12; 民数记 27:1–11"> 玛吉娶了户品和书品的姐妹为妻，她的名字叫玛迦。第二个名叫西罗非哈；西罗非哈有女儿。</span>
<span className="v" id="v16" data-v="16"> 玛吉的妻子玛迦生了一个儿子，给他起名叫毗利施。他兄弟的名字叫示利施；示利施的儿子是乌兰和利金。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记上 12:11"> 乌兰的儿子是比但。这些是玛拿西的儿子玛吉之子基列的子孙。</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 6:24; 士师记 6:11; 士师记 8:2"> 他的姐妹哈摩利吉生了伊施荷、亚比以谢、玛拉。</span>
<span className="v" id="v19" data-v="19"> 示米大的儿子是亚现、示剑、利克希、阿尼安。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="民数记 26:35–36"> 以法莲的儿子是书提拉；书提拉的儿子是比列；比列的儿子是他哈；他哈的儿子是以拉大；以拉大的儿子是他哈；</span>
<span className="v" id="v21" data-v="21"> 他哈的儿子是撒拔；撒拔的儿子是书提拉；还有以谢和以列。那地土生的迦特人杀了他们，因为他们下去夺取他们的牲畜。</span>
<span className="v" id="v22" data-v="22" data-xref="约伯记 2:11; 创世记 37:34"> 他们的父亲以法莲为他们哀哭了许多日子，他的弟兄们来安慰他。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 23:5"> 以法莲与妻子同房，她就怀孕，生了一个儿子；以法莲给他起名叫比利亚，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“比利亚”与希伯来语“灾祸”一词相近。">a</a></sup>因为他的家遭了灾祸。</span>
<span className="v" id="v24" data-v="24" data-xref="约书亚记 16:3; 约书亚记 16:5; 历代志下 8:5"> 他的女儿是舍伊拉；她建造了下伯和仑、上伯和仑，以及乌羡舍伊拉。</span>
<span className="v" id="v25" data-v="25"> 他的儿子是利法；利法的儿子是利悉；利悉的儿子是提拉；提拉的儿子是他罕；</span>
<span className="v" id="v26" data-v="26"> 他罕的儿子是拉但；拉但的儿子是亚米忽；亚米忽的儿子是以利沙玛；</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 13:8; 民数记 13:16; 出埃及记 17:9–14"> 以利沙玛的儿子是嫩；嫩的儿子是约书亚。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 28:19; 约书亚记 16:2–3; 历代志上 6:66–67"> 他们的产业和住处是伯特利及其所属的乡镇，向东有拿兰，向西有基色及其所属的乡镇；还有示剑及其所属的乡镇，直到迦萨及其所属的乡镇；</span>
<span className="v" id="v29" data-v="29" data-xref="士师记 1:22–29; 撒迦利亚书 12:11; 列王纪下 9:27"> 又在玛拿西子孙的边界旁，有伯善及其所属的乡镇、他纳及其所属的乡镇、米吉多及其所属的乡镇、多珥及其所属的乡镇。以色列的儿子约瑟的子孙住在这些地方。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="创世记 46:17; 民数记 26:44–46"> 亚设的儿子有音拿、亦施瓦、亦施韦、比利亚。他们的姐妹是西拉。</span>
<span className="v" id="v31" data-v="31"> 比利亚的儿子有希别和玛结；玛结是比撒威的父亲。</span>
<span className="v" id="v32" data-v="32"> 希别生雅弗勒、朔默、何坦和他们的姐妹书雅。</span>
<span className="v" id="v33" data-v="33"> 雅弗勒的儿子有巴萨、宾哈、亚施法。这些是雅弗勒的子孙。</span>
<span className="v" id="v34" data-v="34"> 朔默的儿子有亚希、罗迦、耶户巴、亚兰。</span>
<span className="v" id="v35" data-v="35"> 他兄弟希连的儿子有琐法、音那、示利斯、亚抹。</span>
<span className="v" id="v36" data-v="36"> 琐法的儿子有书亚、哈尼弗、书阿勒、比利、音拉、</span>
<span className="v" id="v37" data-v="37"> 比悉、何得、沙玛、施沙、益兰、比拉。</span>
<span className="v" id="v38" data-v="38"> 益帖的儿子有耶孚尼、毗斯巴、亚拉。</span>
<span className="v" id="v39" data-v="39"> 乌拉的儿子有亚拉、汉尼业、利写。</span>
<span className="v" id="v40" data-v="40" data-xref="历代志上 21:1–5; 撒母耳记下 24:1–9"> 这些全都是亚设的子孙，是父家的首领，精选的勇士，众领袖中的首要者。他们按家谱登记、能服役作战的人数是二万六千人。</span>
</div>

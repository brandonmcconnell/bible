<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 16:1; 历代志上 17:1–5; 诗篇 132:5"> 大卫在大卫城为自己建造房屋，又为上帝的约柜预备地方，支搭帐幕。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 10:8; 申命记 31:9; 民数记 18:1–8"> 那时大卫说：“除了利未人以外，没有人该抬上帝的约柜；因为耶和华拣选他们抬上帝的约柜，并永远事奉祂。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="列王纪上 8:1; 历代志上 13:5; 历代志上 15:1"> 大卫召集以色列众人到耶路撒冷，要将耶和华的约柜抬到他为它预备的地方。</span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 6:16–22; 历代志上 12:26–28; 历代志上 6:16–30"> 大卫聚集亚伦的子孙和利未人：</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 6:22–24"> 哥辖的子孙中，有首领乌列和他的弟兄一百二十人；</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 6:29–30"> 米拉利的子孙中，有首领亚撒雅和他的弟兄二百二十人；</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 15:11; 历代志上 23:8"> 革顺的子孙中，有首领约珥和他的弟兄一百三十人；</span>
<span className="v" id="v8" data-v="8" data-xref="出埃及记 6:22"> 以利撒反的子孙中，有首领示玛雅和他的弟兄二百人；</span>
<span className="v" id="v9" data-v="9" data-xref="出埃及记 6:18; 历代志上 23:19; 历代志上 26:30–31"> 希伯伦的子孙中，有首领以利业和他的弟兄八十人；</span>
<span className="v" id="v10" data-v="10" data-xref="出埃及记 6:18; 历代志上 6:18; 历代志上 23:12"> 乌薛的子孙中，有首领亚米拿达和他的弟兄一百一十二人。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="历代志上 12:28; 列王纪上 2:35; 撒母耳记上 22:20–23"> 大卫召来祭司撒督和亚比亚他，以及利未人乌列、亚撒雅、约珥、示玛雅、以利业和亚米拿达，</span>
<span className="v" id="v12" data-v="12" data-xref="历代志下 35:6; 出埃及记 19:14–15; 历代志上 15:14"> 对他们说：“你们是利未人各父家的首领。你们和你们的弟兄都要使自己分别为圣，好把耶和华——以色列上帝的约柜抬到我为它预备的地方。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 6:3; 哥林多前书 14:40; 约翰一书 1:8–10"> 因为起初你们没有抬它，耶和华我们的上帝就向我们发作，因为我们没有按定例寻求祂。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="历代志下 29:15; 约珥 2:16–17; 历代志下 29:34"> 于是祭司和利未人使自己分别为圣，要把耶和华——以色列上帝的约柜抬上来。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 4:15; 民数记 7:9; 历代志下 5:9"> 利未人的子孙用杠把上帝的约柜抬在肩上，正如摩西照耶和华的话所吩咐的。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="历代志上 13:8; 历代志下 5:13; 历代志上 16:42"> 大卫吩咐利未人的首领，要派他们的弟兄作歌唱者，用乐器，就是瑟、琴和钹，大声奏响，欢喜扬声。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 6:39; 历代志上 6:44; 历代志上 6:33"> 于是利未人派约珥的儿子希幔；在他的弟兄中，派比利家的儿子亚萨；在他们弟兄米拉利的子孙中，派古沙雅的儿子以探；</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 26:4; 历代志上 26:8; 历代志上 13:14"> 又派与他们同列、居次等的弟兄：撒迦利雅、便、雅薛、示米拉末、耶歇、乌尼、以利押、比拿雅、玛西雅、玛他提雅、以利斐利户、弥克尼雅，以及守门的俄别以东和耶利。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 25:6; 历代志上 16:5; 历代志上 13:8"> 这样，歌唱者希幔、亚萨和以探用铜钹大声奏响；</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 46:1–11"> 撒迦利雅、亚薛、示米拉末、耶歇、乌尼、以利押、玛西雅和比拿雅用瑟，调为阿拉莫；</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 10:5; 历代志上 25:6–7; 诗篇 81:1–2"> 玛他提雅、以利斐利户、弥克尼雅、俄别以东、耶利和亚撒西雅用琴，按八弦琴调，来领奏。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 15:27; 历代志上 15:16; 历代志上 25:7–8"> 利未人的首领基拿尼雅负责歌唱；他因精通此事，就教导歌唱者。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 84:10; 列王纪下 22:4; 历代志上 9:21–23"> 比利家和以利加拿为约柜守门。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 16:6; 民数记 10:8; 历代志上 15:28"> 祭司示巴尼雅、约沙法、拿坦业、亚玛赛、撒迦利雅、比拿雅和以利以谢在上帝的约柜前吹号；俄别以东和耶希雅为约柜守门。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 6:12–23; 弥迦书 5:2; 腓立比书 3:3"> 于是大卫、以色列的长老和千夫长欢欢喜喜地去，从俄别以东的家把耶和华的约柜抬上来。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 23:29; 历代志上 29:14; 诗篇 66:13–15"> 上帝帮助抬耶和华约柜的利未人时，他们就献上七头公牛和七只公绵羊为祭。</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记上 2:18; 撒母耳记下 6:14"> 大卫穿着细麻布袍，所有抬约柜的利未人、歌唱者，以及歌唱者的领班基拿尼雅也都这样穿着；大卫还穿着细麻布以弗得。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志上 13:8; 历代志上 15:16; 历代志下 5:12–13"> 这样，以色列众人欢呼，吹号角、吹号、敲钹，又用瑟和琴大声奏响，把耶和华的约柜抬上来。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 6:20–23; 撒母耳记下 6:16; 申命记 31:26"> 耶和华的约柜进大卫城的时候，扫罗的女儿米甲从窗户往外观看，看见大卫王跳舞欢庆，心里就轻视他。</span>
</div>
</div>

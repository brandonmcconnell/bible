<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="1CH" data-book-slug="1-chronicles" data-book-name="历代志上" data-chapter="29" data-verses="30">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 22:5; 列王纪上 3:7; 历代志下 13:7"> 大卫王对全会众说：“我的儿子所罗门，是上帝惟独拣选的，还年轻稚嫩，而这工程浩大；因为这宫殿不是为人，乃是为耶和华上帝。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 22:3–5; 哥林多后书 8:3; 以赛亚书 54:11–12"> 我已经尽我的全力，为我上帝的殿预备了金器所需的金、银器所需的银、铜器所需的铜、铁器所需的铁、木器所需的木，又预备了缟玛瑙、可镶嵌的宝石、各色嵌工用的石头、各样宝石，以及大量大理石。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 21:24; 诗篇 27:4; 诗篇 26:8"> 此外，因为我心爱我上帝的殿，我既有自己积存的金银，就把它献给我上帝的殿，超过我为圣殿所预备的一切：</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 9:28; 历代志上 22:14; 约伯记 28:16"> 就是俄斐金三千他连得，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一他连得约为30公斤或66磅或965金衡盎司，所以3000他连得约为90公吨。">a</a></sup>精炼的银七千他连得，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="约210公吨。">b</a></sup>用来包覆各殿宇的墙壁；</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 7:2–3; 出埃及记 35:5–9; 以斯拉记 7:15–16"> 金子用于金器，银子用于银器，并用于工匠手所做的各样工。今日有谁甘心将自己奉献给耶和华呢？”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="哥林多后书 9:7; 历代志上 27:25–1; 以赛亚书 60:3–10"> 于是，宗族的首领、以色列各支派的首领、千夫长和百夫长，以及管理王工程的官员，都甘心献上；</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米记 7:70–71; 以斯拉记 2:69"> 他们为上帝殿的事奉献上金子五千他连得<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一他连得约为30公斤或66磅或965金衡盎司，所以5000他连得约为150公吨。">c</a></sup>和一万达利克，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="达利克是波斯王发行的金币，每枚重约8.4克，或约0.27金衡盎司。">d</a></sup>银子一万他连得，铜一万八千他连得，铁十万他连得。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志上 23:8; 历代志上 26:21–22"> 凡有宝石的人，就把宝石交给革顺人耶歇管理，归入耶和华殿的宝库。</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 9:7–8; 哥林多后书 8:3; 列王纪上 8:61"> 百姓欢喜，因为他们甘心献上；他们以完全的心甘心献给耶和华。大卫王也大大欢喜。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="以弗所书 1:3; 彼得前书 1:3; 罗马书 1:7"> 因此，大卫在全会众面前称颂耶和华；大卫说：“耶和华，我们祖先以色列的上帝啊，你是当受称颂的，直到永永远远。</span>
<span className="v" id="v11" data-v="11" data-xref="希伯来书 1:3; 但以理 4:34–35; 提摩太前书 1:17"> 耶和华啊，伟大、能力、荣耀、胜利和威严都是你的！因为天上和地上的一切都是你的。耶和华啊，国度是你的；你被高举为万有之首。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 3:16; 历代志下 20:6; 申命记 8:18"> 财富和尊荣都从你而来，你统管万有！能力和大能都在你手中！使人尊大、赐力量给众人，都在你手中！</span>
<span className="v" id="v13" data-v="13" data-xref="诗篇 106:1; 哥林多后书 9:15; 哥林多后书 8:16"> 现在，我们的上帝啊，我们感谢你，赞美你荣耀的名。</span>
<span className="v" id="v14" data-v="14" data-xref="雅各书 1:17; 哥林多后书 3:5; 罗马书 11:36"> 我是谁？我的百姓又是谁？竟能如此甘心献上呢？因为万物都从你而来，我们把从你而来的献给了你。</span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 144:4; 利未记 25:23; 诗篇 102:11"> 我们在你面前是寄居的，是客旅，正如我们列祖一样。我们在地上的日子如影子，不能长存。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 29:14; 诗篇 24:1; 历代志下 31:10"> 耶和华我们的上帝啊，我们为你的圣名建造殿宇所预备的这一切丰盛之物，都是从你手而来，也全都是你的。</span>
<span className="v" id="v17" data-v="17" data-xref="耶利米书 17:10; 箴言 11:20; 历代志上 28:9"> 我的上帝啊，我也知道你察验人心，并喜悦正直。至于我，我以正直的心甘心献上这一切。现在我也欢喜看见在这里的你的百姓甘心献给你。</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 32:39; 耶利米书 10:23; 希伯来书 13:21"> 耶和华，我们祖先亚伯拉罕、以撒和以色列的上帝啊，求你使你百姓心中所思想的这意愿永远保持，并预备他们的心归向你；</span>
<span className="v" id="v19" data-v="19" data-xref="诗篇 72:1; 历代志上 28:9; 雅各书 1:17"> 又求你赐我儿子所罗门完全的心，使他遵守你的诫命、你的法度和你的律例，实行这一切，并建造我已经预备材料的这宫殿。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="诗篇 95:6; 出埃及记 4:31; 诗篇 135:19–21"> 于是大卫对全会众说：“现在你们要称颂耶和华你们的上帝！”<br />全会众就称颂耶和华他们列祖的上帝，低头，在耶和华和王面前俯伏。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志下 7:4–9; 民数记 15:7; 以斯拉记 6:17"> 次日，他们向耶和华献祭，又向耶和华献燔祭，就是公牛一千只、公绵羊一千只、羔羊一千只，并同献奠祭；又为以色列众人献上丰盛的祭物。</span>
<span className="v" id="v22" data-v="22" data-xref="列王纪上 2:35; 历代志上 23:1; 出埃及记 24:11"> 那日，他们在耶和华面前吃喝，大大欢喜。他们第二次立大卫的儿子所罗门为王，并在耶和华面前膏他作领袖，又膏撒督作祭司。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="列王纪上 2:12; 历代志上 28:5; 罗马书 13:1"> 于是所罗门坐在耶和华的宝座上，接续他父亲大卫作王，并且亨通；以色列众人都听从他。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 2:3–9; 以西结 17:18; 创世记 24:2"> 所有首领、勇士，以及大卫王的众子，都顺服所罗门王。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志下 1:12; 历代志下 1:1; 传道书 2:9"> 耶和华使所罗门在以色列众人眼前极其尊大，又赐给他君王的威严，是在他以前以色列任何王都未曾有过的。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="历代志上 18:14; 诗篇 78:71–72"> 耶西的儿子大卫作全以色列的王。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪上 2:11; 撒母耳记下 5:4–5; 历代志上 3:4"> 他作以色列王的年日是四十年；在希伯仑作王七年，在耶路撒冷作王三十三年。</span>
<span className="v" id="v28" data-v="28" data-xref="创世记 15:15; 使徒行传 13:36; 历代志上 23:1"> 他寿数满足而死，享高寿、财富和尊荣；他的儿子所罗门接续他作王。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记上 9:9; 撒母耳记下 12:1–7; 历代志上 21:9–11"> 大卫王的事迹，始末都写在撒母耳先见的史书、拿单先知的史书，以及迦得先见的史书上；</span>
<span className="v" id="v30" data-v="30" data-xref="但以理 4:25; 但以理 4:23; 但以理 2:21"> 其中记载他的一切统治和他的英勇事迹，以及发生在他、以色列和列国身上的事。</span>
</div>
</div>

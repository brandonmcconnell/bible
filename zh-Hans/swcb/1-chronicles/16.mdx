<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 15:1; 以斯拉记 6:16–18; 历代志下 5:6–7"> 他们把上帝的约柜抬进来，安放在大卫为它所支搭的帐幕中央；他们在上帝面前献上燔祭和平安祭。</span>
<span className="v" id="v2" data-v="2" data-xref="创世记 47:10; 创世记 14:19; 利未记 1:3"> 大卫献完燔祭和平安祭，就奉耶和华的名祝福百姓。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 8:10; 以西结 45:17; 历代志下 35:7–8"> 他分给以色列众人，无论男女，每人一个饼、一份肉和一块葡萄干饼。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="历代志上 23:27–32; 诗篇 72:18; 诗篇 103:2"> 他派一些利未人在耶和华的约柜前供职，记念、称谢、赞美耶和华以色列的上帝：</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 6:39; 历代志下 29:25; 历代志上 15:16–24"> 为首的是亚萨，其次是撒迦利亚，然后是耶利、示米拉末、耶希伊勒、玛他提雅、以利押、比拿雅、俄别以东和耶利，他们弹奏弦乐器和竖琴；亚萨敲钹，发出响声；</span>
<span className="v" id="v6" data-v="6" data-xref="历代志下 13:12; 历代志下 29:26–28; 历代志下 5:12–13"> 祭司比拿雅和雅哈悉常常在上帝的约柜前吹号。</span>
</div>
<div className="bp poetry">
<span className="v" id="v7" data-v="7" data-xref="撒母耳记下 22:1; 诗篇 18:1; 撒母耳记下 23:1–2"> 那一天，大卫首次借亚萨和他的弟兄，设立向耶和华称谢的事。</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 105:1–15; 以赛亚书 12:4; 列王纪下 19:19"> <span className="pl pl-1">要称谢耶和华，</span><br /><span className="pl pl-2">求告祂的名，</span><br /><span className="pl pl-2">在万民中传扬祂的作为。</span></span>
<span className="v" id="v9" data-v="9" data-xref="歌罗西书 3:16; 诗篇 96:1–3; 诗篇 98:1–4"> <span className="pl pl-1">要向祂歌唱，</span><br /><span className="pl pl-2">向祂歌颂；</span><br /><span className="pl pl-2">述说祂一切奇妙的作为。</span></span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 7:7–8; 耶利米书 29:13; 诗篇 34:2"> <span className="pl pl-1">要以祂的圣名为荣耀；</span><br /><span className="pl pl-2">愿寻求耶和华的人心中欢喜。</span></span>
<span className="v" id="v11" data-v="11" data-xref="诗篇 27:8–9; 西番雅书 2:2–3; 诗篇 68:35"> <span className="pl pl-1">要寻求耶和华和祂的能力，</span><br /><span className="pl pl-2">永远寻求祂的面。</span></span>
<span className="v" id="v12" data-v="12" data-xref="诗篇 111:4; 诗篇 119:20; 诗篇 103:2"> <span className="pl pl-1">要记念祂所行奇妙的作为、</span><br /><span className="pl pl-2">祂的奇事和祂口中的判决，</span></span>
<span className="v" id="v13" data-v="13" data-xref="彼得前书 2:9; 出埃及记 19:5–6; 诗篇 135:4"> <span className="pl pl-1">你们祂仆人以色列的后裔</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：种子">a</a></sup><br /><span className="pl pl-1">，</span><br /><span className="pl pl-2">祂所拣选的雅各子孙啊。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v14" data-v="14" data-xref="诗篇 48:10–11; 以赛亚书 26:9; 出埃及记 15:2"> <span className="pl pl-1">祂是耶和华我们的上帝；</span><br /><span className="pl pl-2">祂的判决遍及全地。</span></span>
<span className="v" id="v15" data-v="15" data-xref="诗篇 105:8; 玛拉基书 4:4; 申命记 7:9"> <span className="pl pl-1">要永远记念祂的约，</span><br /><span className="pl pl-2">就是祂吩咐直到千代的话，</span><br /></span>
<span className="v" id="v16" data-v="16" data-xref="创世记 26:3; 创世记 17:2; 创世记 35:11"> <span className="pl pl-2">祂与亚伯拉罕所立的约，</span><br /><span className="pl pl-2">向以撒所起的誓。</span></span>
<span className="v" id="v17" data-v="17" data-xref="创世记 17:7–8; 创世记 35:11–12; 约书亚记 24:11–13"> <span className="pl pl-1">祂将这约向雅各确立为律例，</span><br /><span className="pl pl-2">向以色列确立为永远的约，</span></span>
<span className="v" id="v18" data-v="18" data-xref="创世记 13:15; 弥迦书 2:5; 创世记 17:8"> <span className="pl pl-1">说：“我必把迦南地赐给你们，</span><br /><span className="pl pl-2">作你们产业的分。”</span><br /></span>
<span className="v" id="v19" data-v="19" data-xref="创世记 34:30; 申命记 7:7; 使徒行传 7:5"> <span className="pl pl-2">那时你们人数稀少，</span><br /><span className="pl pl-2">是的，极其稀少，并且在那地作寄居的外人。</span></span>
<span className="v" id="v20" data-v="20" data-xref="创世记 46:6; 创世记 20:1; 创世记 46:3"> <span className="pl pl-1">他们从这国游到那国，</span><br /><span className="pl pl-2">从这王国到另一族民。</span></span>
<span className="v" id="v21" data-v="21" data-xref="创世记 12:17; 创世记 20:3; 出埃及记 7:15–18"> <span className="pl pl-1">祂不容任何人欺压他们，</span><br /><span className="pl pl-2">并且为了他们责备君王，</span></span>
<span className="v" id="v22" data-v="22" data-xref="创世记 20:7; 诗篇 105:15; 创世记 49:8–10"> <span className="pl pl-1">说：“不可触碰我的受膏者！</span><br /><span className="pl pl-2">不可伤害我的先知！”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v23" data-v="23" data-xref="诗篇 96:1–13; 诗篇 71:15; 以赛亚书 51:6–8"> <span className="pl pl-1">全地都要向耶和华歌唱！</span><br /><span className="pl pl-2">天天宣扬祂的救恩。</span></span>
<span className="v" id="v24" data-v="24" data-xref="以赛亚书 12:2–6; 但以理 4:1–3; 诗篇 22:27"> <span className="pl pl-1">要在列国中宣告祂的荣耀，</span><br /><span className="pl pl-2">在万民中宣告祂奇妙的作为。</span></span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 89:7; 诗篇 76:7; 诗篇 66:3–5"> <span className="pl pl-1">因为耶和华为大，极当受赞美；</span><br /><span className="pl pl-2">祂也当受敬畏，超过万神。</span></span>
<span className="v" id="v26" data-v="26" data-xref="诗篇 102:25; 利未记 19:4; 以赛亚书 42:5"> <span className="pl pl-1">因为万民的神明都是偶像，</span><br /><span className="pl pl-2">惟有耶和华创造了诸天。</span></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 16:11; 诗篇 96:6; 诗篇 28:7–8"> <span className="pl pl-1">尊荣和威严在祂面前；</span><br /><span className="pl pl-2">能力和喜乐在祂所在之处。</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 15:10; 腓立比书 4:13; 诗篇 100:1–2"> <span className="pl pl-1">万民的各家啊，要将荣耀能力归给耶和华，</span><br /><span className="pl pl-2">归给耶和华！</span></span>
<span className="v" id="v29" data-v="29" data-xref="诗篇 100:4; 诗篇 96:9; 以赛亚书 6:3"> <span className="pl pl-1">要将祂名所当得的荣耀归给耶和华。</span><br /><span className="pl pl-2">要带着供物来到祂面前；</span><br /><span className="pl pl-2">要以圣洁的装束敬拜耶和华。</span></span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 33:9; 诗篇 148:5–6; 希伯来书 1:3"> <span className="pl pl-1">全地都要在祂面前战抖；</span><br /><span className="pl pl-2">世界也坚立，不能动摇。</span></span>
<span className="v" id="v31" data-v="31" data-xref="诗篇 96:10; 启示录 19:6; 诗篇 97:1"> <span className="pl pl-1">愿诸天欢喜，</span><br /><span className="pl pl-2">愿大地快乐！</span><br /><span className="pl pl-2">愿人在列国中说：“耶和华作王了！”</span></span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 148:9–10; 以赛亚书 44:23; 诗篇 98:7–8"> <span className="pl pl-1">愿海和其中所充满的澎湃！</span><br /><span className="pl pl-2">愿田野和其中所有的都欢腾！</span></span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 98:9; 诗篇 96:12–13; 启示录 11:17–18"> <span className="pl pl-1">那时，林中的树木都要在耶和华面前欢呼歌唱，</span><br /><span className="pl pl-2">因为祂来要审判大地。</span></span>
<span className="v" id="v34" data-v="34" data-xref="诗篇 106:1; 历代志下 7:3; 诗篇 107:1"> <span className="pl pl-1">要称谢耶和华，因为祂本为善，</span><br /><span className="pl pl-2">因为祂的慈爱永远长存。</span></span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 106:47–48; 彼得前书 2:9; 诗篇 14:7"> <span className="pl pl-1">要说：“我们救恩的上帝啊，求你拯救我们！</span><br /><span className="pl pl-2">求你聚集我们，救我们脱离列国，</span><br /><span className="pl pl-2">好称谢你的圣名，</span><br /><span className="pl pl-2">在对你的赞美中欢然夸胜。”</span></span>
<span className="v" id="v36" data-v="36" data-xref="列王纪上 8:15; 诗篇 72:18–19; 列王纪上 8:56"> <span className="pl pl-1">耶和华以色列的上帝是当称颂的，</span><br /><span className="pl pl-2">从亘古直到永远。</span><br />众民都说：“阿们。”并且赞美耶和华。</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="历代志下 8:14; 以斯拉记 3:4; 历代志上 16:4–6"> 于是大卫把亚萨和他的弟兄留在那里，在耶和华的约柜前，照每日的职分所需，常常在约柜前供职；</span>
<span className="v" id="v38" data-v="38" data-xref="历代志上 26:10; 历代志上 13:14; 历代志上 25:3"> 又留下俄别以东和他们的六十八位亲属；又派耶杜顿的儿子俄别以东和何萨作守门的；</span>
<span className="v" id="v39" data-v="39" data-xref="列王纪上 3:4; 历代志上 15:11; 历代志下 1:3–4"> 又派祭司撒督和他作祭司的弟兄，在基遍丘坛耶和华的帐幕前，</span>
<span className="v" id="v40" data-v="40" data-xref="民数记 28:3–8; 出埃及记 29:38–42; 历代志下 31:3"> 早晚不断在燔祭坛上向耶和华献燔祭，完全照耶和华吩咐以色列的律法上所写的一切；</span>
<span className="v" id="v41" data-v="41" data-xref="历代志下 5:13; 历代志上 25:1–6; 历代志下 20:21"> 与他们同在的还有希幔、耶杜顿，以及其余被拣选、按名指定的人，要称谢耶和华，因为祂的慈爱永远长存；</span>
<span className="v" id="v42" data-v="42" data-xref="诗篇 150:3–6; 历代志上 25:6–7; 历代志下 29:25–28"> 与他们同在的希幔和耶杜顿，带着号和钹，供那些要大声奏响的人使用，又带着上帝之歌所用的乐器；耶杜顿的子孙则看守门。</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳记下 6:19–20; 创世记 18:19; 诗篇 101:2"> 众民各归各家；大卫也回去为他的家祝福。</span>
</div>

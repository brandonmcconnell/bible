<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 3:1; 历代志上 21:18–28; 创世记 28:17"> 大卫说：“这是耶和华上帝的殿，这是以色列献燔祭的坛。”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="历代志下 2:17; 列王纪上 9:20–21; 列王纪上 5:17–18"> 大卫下令聚集在以色列地的外族人；又派石匠凿出建造上帝殿所用的石头。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 22:14; 历代志上 29:2; 列王纪上 7:47"> 大卫预备了大量的铁，用来做门扇的钉子和连接件，又预备了多得无法称量的铜，</span>
<span className="v" id="v4" data-v="4" data-xref="列王纪上 5:6–10; 以斯拉记 3:7; 历代志下 2:3"> 以及无数的香柏木，因为西顿人和推罗人把大量香柏木运给大卫。</span>
<span className="v" id="v5" data-v="5" data-xref="列王纪上 3:7; 历代志上 29:1; 约翰福音 3:30"> 大卫说：“我儿子所罗门还年轻稚嫩，而要为耶和华建造的殿必须极其宏伟，在万国中有名声和荣耀。因此，我要为这殿预备材料。”于是大卫在去世以前大量预备。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 27:23; 使徒行传 20:25–31; 使徒行传 1:2"> 然后他召来他的儿子所罗门，吩咐他为耶和华——以色列的上帝——建造殿。</span>
<span className="v" id="v7" data-v="7" data-xref="诗篇 132:5; 列王纪上 8:16–20; 历代志下 6:7–9"> 大卫对他的儿子所罗门说：“至于我，我心里本想为耶和华我上帝的名建造殿。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪上 5:3; 历代志上 28:3; 历代志上 17:4–10"> 但是耶和华的话临到我，说：‘你流了许多血，发动了大规模的战争。你不可为我的名建造殿，因为你在我眼前使许多血流在地上。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 4:25; 列王纪上 5:4; 列王纪上 4:20"> 看哪，你将有一个儿子出生，他必作和平的人。我必使他得安宁，脱离四围所有的仇敌；因为他的名必叫所罗门。在他的日子，我必将平安和安静赐给以色列。</span>
<span className="v" id="v10" data-v="10" data-xref="希伯来书 1:5; 撒母耳记下 7:13–14; 历代志上 17:12–14"> 他必为我的名建造殿；他要作我的儿子，我要作他的父；我必坚定他治理以色列的国位，直到永远。’</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 22:16; 历代志上 28:20; 提摩太后书 4:22"> 现在，我儿啊，愿耶和华与你同在，使你亨通，照祂论到你所说的，建造耶和华你上帝的殿。</span>
<span className="v" id="v12" data-v="12" data-xref="雅各书 1:5; 箴言 14:8; 列王纪上 3:9–12"> 愿耶和华赐给你明辨和悟性，使你治理以色列，好使你遵守耶和华你上帝的律法。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 1:6–9; 历代志上 28:20; 历代志上 28:7"> 你若谨守遵行耶和华借摩西吩咐以色列的律例和典章，就必亨通。你要刚强壮胆；不要惧怕，也不要惊惶。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志上 22:3; 列王纪下 25:16; 历代志上 29:4–7"> 现在，看哪，我在艰难中为耶和华的殿预备了十万他连得<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一他连得约为30公斤、66磅或965金衡盎司，所以十万他连得约为3公吨">a</a></sup>金子，一百万他连得<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="约30,000公吨">b</a></sup>银子，还有多得无法称量的铜和铁，因为数量很多。我也预备了木料和石头；你还可以再添上。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 28:6; 出埃及记 35:32; 列王纪上 7:14"> 你这里也有许多工匠——凿石的、做石工和木工的，以及各种善于各样工作的人；</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 22:11; 腓立比书 4:13; 以弗所书 5:14"> 至于金、银、铜、铁，多得无法计算。起来行动吧，愿耶和华与你同在。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="历代志上 28:1–6; 约翰三书 1:8; 历代志上 29:6"> 大卫又吩咐以色列所有的首领帮助他的儿子所罗门，说：</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 22:9; 历代志上 23:25; 撒母耳记下 7:1"> “耶和华你们的上帝不是与你们同在吗？祂不是使你们四围都得安宁吗？因为祂已将这地的居民交在我手中；这地在耶和华和祂百姓面前已经被制服。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 28:9; 申命记 4:29; 历代志上 16:11"> 现在，你们要立定你们的心和灵魂来跟随耶和华你们的上帝。所以要起来，建造耶和华上帝的圣所，好把耶和华的约柜和上帝的圣器带进那为耶和华的名所建造的殿中。”</span>
</div>

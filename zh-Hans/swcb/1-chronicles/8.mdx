<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 46:21; 历代志上 7:6–12; 民数记 26:38"> 便雅悯生了长子比拉、次子亚实别、三子亚哈拉、</span>
<span className="v" id="v2" data-v="2"> 四子挪哈、五子拉法。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 46:21; 民数记 26:40"> 比拉有儿子：亚达、基拉、亚比忽、</span>
<span className="v" id="v4" data-v="4"> 亚比书、乃缦、亚何亚、</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 7:12; 民数记 26:39; 士师记 3:15"> 基拉、示孚汛和户兰。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 2:54; 士师记 3:20–30; 历代志上 7:10"> 这些是以忽的儿子。他们是迦巴居民父家的首领；迦巴人曾被掳到玛拿辖：</span>
<span className="v" id="v7" data-v="7"> 乃缦、亚希雅和基拉；基拉掳了他们，又生了乌撒和亚希忽。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="路得记 1:1; 创世记 25:6"> 沙哈连在摩押地生了儿女；那是在他把她们送走以后。户伸和巴拉是他的妻子。</span>
<span className="v" id="v9" data-v="9"> 他从妻子贺得生了约巴、洗比雅、米沙、玛勒堪、</span>
<span className="v" id="v10" data-v="10"> 耶乌斯、沙迦和米玛。这些是他的儿子，都是父家的首领。</span>
<span className="v" id="v11" data-v="11"> 他从户伸生了亚比突和以利巴力。</span>
<span className="v" id="v12" data-v="12" data-xref="以斯拉记 2:33; 尼希米记 7:37; 尼希米记 6:2"> 以利巴力的儿子：希伯、米珊和沙麦；沙麦建造了阿挪、罗德及其所属的城镇；</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 2:52; 约书亚记 19:42; 历代志上 4:4"> 还有比利亚和示玛；他们是亚雅仑居民父家的首领，曾使迦特居民逃跑；</span>
<span className="v" id="v14" data-v="14"> 还有亚希约、沙煞、耶利末、</span>
<span className="v" id="v15" data-v="15"> 西巴第雅、亚拉得、以得、</span>
<span className="v" id="v16" data-v="16"> 米迦勒、伊施巴、约哈，这些是比利亚的儿子；</span>
<span className="v" id="v17" data-v="17"> 西巴第雅、米书兰、希西基、希伯、</span>
<span className="v" id="v18" data-v="18"> 伊施米莱、伊斯利亚、约巴，这些是以利巴力的儿子；</span>
<span className="v" id="v19" data-v="19"> 雅金、细基利、撒底、</span>
<span className="v" id="v20" data-v="20"> 以利乃、洗勒太、以利业、</span>
<span className="v" id="v21" data-v="21"> 亚大雅、比莱雅、申拉，这些是示每的儿子；</span>
<span className="v" id="v22" data-v="22"> 伊施班、希伯、以利业、</span>
<span className="v" id="v23" data-v="23"> 押顿、细基利、哈南、</span>
<span className="v" id="v24" data-v="24"> 哈拿尼雅、以拦、安陀提雅、</span>
<span className="v" id="v25" data-v="25"> 伊弗底雅、毗努伊勒，这些是沙煞的儿子；</span>
<span className="v" id="v26" data-v="26"> 珊示莱、示哈利雅、亚他利雅、</span>
<span className="v" id="v27" data-v="27"> 雅利西雅、以利亚、细基利，这些是耶罗罕的儿子。</span>
<span className="v" id="v28" data-v="28" data-xref="士师记 1:21; 约书亚记 15:63; 尼希米记 11:1"> 这些人按着他们的世代，都是父家的首领，是族中的首要人物；他们住在耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="历代志上 9:35–38"> 基遍的父亲住在基遍；他的妻子名叫玛迦。</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 9:36–37"> 他的长子是押顿，还有夙、基士、巴力、拿答、</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 9:37"> 基多、亚希约、撒迦、</span>
<span className="v" id="v32" data-v="32" data-xref="历代志上 9:38"> 米基罗；米基罗生了示米亚。他们也同自己的家族住在耶路撒冷，靠近他们的亲族。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记上 9:1; 撒母耳记下 2:8; 撒母耳记上 31:2"> 尼珥生了基士；基士生了扫罗；扫罗生了约拿单、麦基舒亚、亚比拿达和伊施巴力。</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记下 4:4; 撒母耳记下 9:12; 撒母耳记下 9:10"> 约拿单的儿子是米力巴力；米力巴力生了米迦。</span>
<span className="v" id="v35" data-v="35" data-xref="历代志上 9:41"> 米迦的儿子：比顿、米勒、他利亚和亚哈斯。</span>
<span className="v" id="v36" data-v="36" data-xref="历代志上 9:42"> 亚哈斯生了耶何阿达；耶何阿达生了亚拉篾、亚斯玛弗和心利；心利生了摩撒。</span>
<span className="v" id="v37" data-v="37" data-xref="历代志上 9:43"> 摩撒生了比尼亚；拉法是他的儿子，以利亚撒是他的儿子，亚悉是他的儿子。</span>
<span className="v" id="v38" data-v="38"> 亚悉有六个儿子，他们的名字是：亚斯利干、波基路、以实玛利、示亚利雅、俄巴底雅和哈南。这些全都是亚悉的儿子。</span>
<span className="v" id="v39" data-v="39"> 他兄弟以设的儿子：长子乌兰、次子耶乌施、三子以利法列。</span>
<span className="v" id="v40" data-v="40" data-xref="诗篇 128:3–6; 历代志下 14:8; 历代志上 12:2"> 乌兰的儿子都是大能勇士，是弓箭手，有许多儿子和孙子，共一百五十人。这些全都是便雅悯的子孙。</span>

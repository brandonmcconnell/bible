<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 23:2; 历代志上 11:10–47; 历代志上 27:1–34"> 大卫召集以色列所有的首领到耶路撒冷：各支派的首领、按班次服事王的军队统领、千夫长、百夫长、管理王和王众子一切财物产业的主管，以及官员、勇士，就是所有大能的勇士。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 99:5; 以赛亚书 66:1; 历代志上 17:1–2"> 大卫王起身站立，说：“我的弟兄，我的子民啊，请听我说！至于我，我心里本想为耶和华的约柜，也为我们上帝的脚凳，建造一座安息的殿；我也已经为建造作了预备。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 22:8; 历代志上 17:4; 历代志下 6:8–9"> 但是上帝对我说：‘你不可为我的名建殿，因为你是战士，流过人的血。’</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记上 16:1; 历代志上 5:2; 撒母耳记上 16:6–13"> 然而耶和华——以色列的上帝——从我父的全家中拣选我，永远作以色列的王；因为祂拣选犹大作领袖，又在犹大家中拣选我父的家，在我父的众子中喜悦我，立我作全以色列的王。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 3:1–9; 历代志上 23:1; 历代志上 22:9–10"> 在我所有的儿子中——因为耶和华赐给我许多儿子——祂拣选了我儿子所罗门，坐在耶和华治理以色列之国的宝座上。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 7:13–14; 历代志上 22:9–10; 希伯来书 3:6"> 祂对我说：‘你的儿子所罗门要建造我的殿和我的院宇；因为我拣选他作我的儿子，我也要作他的父。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 22:13; 列王纪上 8:61; 列王纪上 6:12–13"> 如果他像今日一样，坚持遵行我的诫命和典章，我就必坚立他的国，直到永远。’</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="申命记 4:1; 申命记 5:32–3; 箴言 2:1–5"> 现在，在耶和华的会众——全以色列——眼前，并在我们上帝垂听之下，你们要谨守并寻求耶和华你们上帝的一切诫命，好使你们得着这美地，并留给你们身后的子孙永远为产业。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="耶利米书 29:13; 雅各书 4:8–11; 马太福音 7:7–8"> “我儿所罗门啊，你要认识你父亲的上帝，用纯全的心和乐意的意念事奉祂；因为耶和华鉴察万人的心，明白一切思想的意念。你若寻求祂，祂必让你寻见；你若离弃祂，祂必永远弃绝你。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 28:6; 提摩太前书 4:16; 历代志上 22:16–19"> 现在你要留心，因为耶和华拣选你为圣所建造殿。你要刚强，去做吧！”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="历代志上 28:19; 列王纪上 6:3; 出埃及记 25:40"> 大卫把殿廊、殿的房屋、府库、楼房、内室和施恩座所在之处的图样，交给他儿子所罗门；</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 26:20; 列王纪上 14:26; 出埃及记 25:40"> 又把他藉着圣灵所得的一切图样，就是耶和华殿的院宇、周围所有房间、上帝殿的府库，以及分别为圣之物的府库，都交给他；</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 9:29; 历代志上 25:1–31; 列王纪上 7:1–51"> 还有祭司和利未人的班次，耶和华殿中一切事奉的工作，以及耶和华殿中事奉所用的一切器具——</span>
<span className="v" id="v14" data-v="14"> 各类事奉所用的一切金器，都按重量给金子；各类事奉所用的一切银器，也都按重量给银子；</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 25:31–39; 撒迦利亚书 4:11–14; 启示录 1:12–13"> 金灯台和灯盏所需的金子，按重量给每个灯台和灯盏；银灯台也按每个灯台和灯盏的用途，按重量给银子；</span>
<span className="v" id="v16" data-v="16" data-xref="列王纪上 7:48; 历代志下 4:8; 出埃及记 25:23–30"> 陈设饼的桌子，每张桌子所需的金子，都按重量给；银桌子所需的银子也照样给；</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪上 10:21; 历代志下 4:20–22; 民数记 7:13–14"> 叉子、盆和杯都用纯金；金碗按每个碗的重量给金子；银碗也按每个碗的重量给银子；</span>
<span className="v" id="v18" data-v="18" data-xref="出埃及记 25:18–22; 出埃及记 30:1–10; 诗篇 80:1"> 香坛按重量给精金；又给车的图样，就是展开翅膀遮掩耶和华约柜的基路伯，所需的金子。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 28:11–12; 出埃及记 25:40; 以西结 3:14"> 大卫说：“这一切，就是这图样的一切工程，都是出于耶和华的手，以文字使我明白的。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="历代志上 22:13; 约书亚记 1:5–9; 以赛亚书 41:10"> 大卫对他儿子所罗门说：“你要刚强壮胆，去做吧！不要惧怕，也不要惊惶，因为耶和华上帝，就是我的上帝，与你同在。祂必不撇下你，也不离弃你，直到耶和华殿中服事的一切工作都完成。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 24:1–26; 历代志上 22:17–18; 出埃及记 31:3"> 看哪，祭司和利未人的班次已经为上帝殿中的一切事奉预备好了；凡甘心乐意且有技能、能作各样事奉的人，必在各样工作上与你同在。首领和众民也必完全听从你的吩咐。”</span>
</div>
</div>

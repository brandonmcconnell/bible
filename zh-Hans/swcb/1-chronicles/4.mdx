<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="1CH" data-book-slug="1-chronicles" data-book-name="历代志上" data-chapter="4" data-verses="43">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 46:12; 创世记 38:29; 民数记 26:20–21"> 犹大的儿子：法勒斯、希斯仑、迦米、户珥和朔巴。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 13:25; 历代志上 2:52–54; 约书亚记 15:33"> 朔巴的儿子利亚雅生雅哈；雅哈生亚户买和拉哈。这些是琐拉人的各家族。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 15:11; 历代志下 11:6"> 这些是以坦之父的儿子：耶斯列、伊施玛和伊得巴；他们的妹妹名叫哈悉勒玻尼。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 4:18; 历代志上 2:50; 历代志上 4:39"> 毗努伊勒是基多之父，以谢是户沙之父。这些是以法他的长子、伯利恒之父户珥的儿子。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 2:24"> 提哥亚之父亚施户有两个妻子：希拉和拿拉。</span>
<span className="v" id="v6" data-v="6"> 拿拉给他生亚户撒、希弗、提米尼和哈辖斯他利。这些是拿拉的儿子。</span>
<span className="v" id="v7" data-v="7"> 希拉的儿子是洗列、以斯哈和伊提南。</span>
<span className="v" id="v8" data-v="8"> 哈哥斯生亚诺、琐比巴，以及哈仑的儿子亚哈黑的各家族。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 4:21; 历代志上 7:23; 创世记 35:18"> 雅比斯比他的兄弟更尊贵。他母亲给他起名叫雅比斯，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“雅比斯”听起来与希伯来语中表示“痛苦”的词相似。">a</a></sup>说：“因为我是在痛苦中生了他。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 7:7–11; 诗篇 116:1–4; 箴言 10:22"> 雅比斯呼求以色列的上帝<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="译作“上帝”的希伯来词是“אֱלֹהִ֑ים”（Elohim）。">b</a></sup>说：“愿你确实赐福给我，扩张我的境界！愿你的手与我同在，愿你保守我远离邪恶，使我不致造成痛苦！”<br />上帝就赐给他所求的。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11"> 书哈的兄弟基绿生米黑；米黑是伊施屯之父。</span>
<span className="v" id="v12" data-v="12"> 伊施屯生伯拉法、巴西亚和拿辖城之父提欣拿。这些是利迦人。</span>
<span className="v" id="v13" data-v="13" data-xref="约书亚记 15:17; 士师记 1:13; 士师记 3:9–11"> 基纳斯的儿子：俄陀聂和西莱雅。俄陀聂的儿子：哈塔。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="希腊文和武加大译本加上“和米乌诺泰”。">c</a></sup></span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 11:35; 列王纪下 24:14"> 米乌诺泰生俄弗拉；西莱雅生约押，约押是基·哈拉欣之父，因为他们是工匠。</span>
<span className="v" id="v15" data-v="15" data-xref="民数记 13:6; 民数记 14:6–10; 约书亚记 15:13–20"> 耶孚尼的儿子迦勒的儿子：以路、以拉和拿安。以拉的儿子：基纳斯。</span>
<span className="v" id="v16" data-v="16"> 耶哈利勒的儿子：西弗、西法、提利亚和亚萨列。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 4:19; 历代志上 6:57; 约书亚记 15:50"> 以斯拉的儿子：益帖、米列、以弗和雅伦；米列的妻子生米利暗、沙买和以实提摩之父益巴。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 2:42; 历代志上 4:39; 约书亚记 15:58"> 他那犹大妻子生基多之父耶列、梭哥之父希伯和撒挪亚之父耶古铁。这些是米列所娶法老的女儿比提雅的儿子。</span>
<span className="v" id="v19" data-v="19" data-xref="约书亚记 15:44; 撒母耳记上 23:1–13"> 荷第雅的妻子、拿含的姊妹的儿子，是迦米人基伊拉的父和玛迦人以实提摩的父。</span>
<span className="v" id="v20" data-v="20"> 示门的儿子：暗嫩、林拿、便哈南和提伦。以示的儿子：琐黑和便琐黑。</span>
<span className="v" id="v21" data-v="21" data-xref="创世记 38:5; 历代志上 2:3; 民数记 26:20"> 犹大的儿子示拉的儿子：利迦之父珥、玛利沙之父拉大，以及亚实比家中做细麻布之人的各家族；</span>
<span className="v" id="v22" data-v="22"> 还有约敬、哥西巴人、约阿施、撒拉；他们曾在摩押掌权；又有雅书比利恒。这些记载是古老的。</span>
<span className="v" id="v23" data-v="23" data-xref="诗篇 81:6; 历代志上 4:14"> 这些人是窑匠，又是尼他应和基低拉的居民；他们住在那里，为王做工。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="创世记 46:10; 出埃及记 6:15; 民数记 26:12–14"> 西缅的儿子：尼母利、雅悯、雅立、谢拉、扫罗；</span>
<span className="v" id="v25" data-v="25"> 他的儿子沙龙，他的儿子米比衫，他的儿子米施玛。</span>
<span className="v" id="v26" data-v="26"> 米施玛的儿子：他的儿子哈母利，他的儿子撒刻，他的儿子示每。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 26:14; 民数记 26:22; 民数记 2:13"> 示每有十六个儿子和六个女儿；但他的兄弟没有很多儿女，他们全家族也没有像犹大子孙那样增多。</span>
<span className="v" id="v28" data-v="28" data-xref="约书亚记 19:2–3; 约书亚记 15:28–29; 约书亚记 19:9"> 他们住在别是巴、摩拉大、哈萨书亚，</span>
<span className="v" id="v29" data-v="29" data-xref="约书亚记 19:3–4"> 在辟拉、以森、陀腊，</span>
<span className="v" id="v30" data-v="30" data-xref="尼希米记 11:28; 约书亚记 19:4–5; 撒母耳记上 30:1"> 在彼土利、何珥玛、洗革拉，</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 19:5–6"> 在伯玛嘉博、哈萨苏撒、伯比利和沙拉音。这些是他们的城，直到大卫作王的时候。</span>
<span className="v" id="v32" data-v="32" data-xref="约书亚记 19:7"> 他们的村庄是以坦、亚因、临门、陀健和亚珊，共五座城；</span>
<span className="v" id="v33" data-v="33" data-xref="约书亚记 19:8"> 还有环绕这些城的一切村庄，直到巴力。这些是他们的住处；他们保存自己的家谱。</span>
<span className="v" id="v34" data-v="34"> 米所巴、雅米勒、亚玛谢的儿子约沙、</span>
<span className="v" id="v35" data-v="35"> 约珥、约示比雅的儿子耶户；约示比雅是西莱雅的儿子，西莱雅是亚薛的儿子；</span>
<span className="v" id="v36" data-v="36"> 以利约乃、雅哥巴、约朔海、亚帅雅、亚底业、耶西篾、比拿雅，</span>
<span className="v" id="v37" data-v="37"> 还有示非的儿子细撒；示非是亚龙的儿子，亚龙是耶大雅的儿子，耶大雅是申利的儿子，申利是示玛雅的儿子——</span>
<span className="v" id="v38" data-v="38" data-xref="历代志上 5:24; 创世记 6:4"> 这些按名提到的人，是他们各家族中的首领。他们父家的族人大大增多。</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="历代志上 4:4; 历代志上 4:18; 约书亚记 15:58"> 他们去到基多入口，直到谷的东边，为他们的羊群寻找牧场。</span>
<span className="v" id="v40" data-v="40" data-xref="士师记 18:7–10; 诗篇 105:23; 诗篇 78:51"> 他们找到了肥美的好牧场，那地宽阔、安静、太平；因为从前住在那里的人是含的后裔。</span>
<span className="v" id="v41" data-v="41" data-xref="以赛亚书 14:28–32; 列王纪下 18:8–12; 历代志上 4:34–38"> 这些按名写下的人，在犹大王希西家的日子来到，攻击他们的帐棚和在那里找到的米乌尼人；他们把这些人灭尽，直到今日，并住在他们的地方，因为那里有牧场可供他们的羊群。</span>
<span className="v" id="v42" data-v="42" data-xref="创世记 36:8–9; 申命记 1:2"> 他们当中有些人，就是西缅子孙中的五百人，往西珥山去；以示的儿子毗拉提、尼利雅、利法雅、乌薛作他们的首领。</span>
<span className="v" id="v43" data-v="43" data-xref="撒母耳记上 30:17; 撒母耳记上 15:7–8; 撒母耳记下 8:12"> 他们击杀了逃脱的亚玛力人余民，就住在那里，直到今日。</span>
</div>
</div>

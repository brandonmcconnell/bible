<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 29:28; 历代志上 28:5; 列王纪上 1:33–39"> 大卫年纪老迈，寿数满足；他就立他儿子所罗门作以色列的王。</span>
<span className="v" id="v2" data-v="2" data-xref="约书亚记 24:1; 历代志下 34:29–30; 历代志上 13:1"> 他召集以色列所有的首领，以及祭司和利未人。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 23:24; 民数记 4:2–49"> 利未人从三十岁以上的都被数点；按人头逐一计算，他们的数目共有三万八千。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志下 19:8; 申命记 16:18; 历代志上 26:29–31"> 大卫说：“这些人中，有二万四千人负责督理耶和华殿的工作，六千人作官长和审判官，</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 29:25–26; 历代志下 8:14; 诗篇 87:7"> 四千人作守门的，四千人用我所造来赞美的乐器赞美耶和华。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="历代志下 8:14; 历代志上 6:1; 历代志上 6:16"> 大卫按利未的儿子革顺、哥辖、米拉利，把他们分成班次。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="历代志上 26:21; 出埃及记 6:17; 历代志上 6:17–20"> 属革顺人的有拉但和示每。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志上 6:33–34; 历代志上 15:20–21; 历代志上 15:7"> 拉但的儿子：族长耶希伊利、西坦、约珥，共三人。</span>
<span className="v" id="v9" data-v="9"> 示每的儿子：示罗密、哈薛、哈兰，共三人。这些是拉但父家的首领。</span>
<span className="v" id="v10" data-v="10"> 示每的儿子：雅哈、西拿、耶乌施、比利亚。这四人是示每的儿子。</span>
<span className="v" id="v11" data-v="11"> 雅哈是族长，西撒次之；但耶乌施和比利亚的儿子不多，所以他们在计算时合为一个父家。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="出埃及记 6:18; 民数记 3:27; 民数记 26:58"> 哥辖的儿子：暗兰、以斯哈、希伯伦、乌薛，共四人。</span>
<span className="v" id="v13" data-v="13" data-xref="申命记 21:5; 出埃及记 6:20; 撒母耳记上 2:28"> 暗兰的儿子：亚伦和摩西；亚伦被分别出来，要把至圣之物分别为圣；他和他的子孙永远如此，又要在耶和华面前烧香，事奉祂，并永远奉祂的名祝福。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 33:1; 诗篇 90:1; 历代志上 26:23–25"> 至于上帝的人摩西，他的儿子们归在利未支派中。</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 18:3–4; 出埃及记 2:22; 出埃及记 4:20"> 摩西的儿子：革舜和以利以谢。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 26:24; 历代志上 25:20; 历代志上 24:20"> 革舜的儿子：族长细布业。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 26:25"> 以利以谢的儿子是族长利哈比雅；以利以谢没有别的儿子，但利哈比雅的儿子极多。</span>
<span className="v" id="v18" data-v="18" data-xref="历代志上 26:26; 历代志上 24:22"> 以斯哈的儿子：族长示罗密。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 24:23; 历代志上 15:9; 历代志上 23:12"> 希伯伦的儿子：族长耶利雅、次子亚玛利雅、三子雅哈悉、四子耶加面。</span>
<span className="v" id="v20" data-v="20"> 乌薛的儿子：族长米迦，次子伊示雅。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="出埃及记 6:19; 历代志上 6:20; 历代志上 24:26–30"> 米拉利的儿子：抹利和母示。抹利的儿子：以利亚撒和基士。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 24:28; 民数记 36:6–8"> 以利亚撒死了，没有儿子，只有女儿；她们的亲族，基士的儿子娶了她们为妻。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 24:30"> 母示的儿子：抹利、以得、耶利摩，共三人。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="民数记 10:17; 民数记 10:21; 历代志上 23:3"> 这些是利未的子孙，按他们的父家，就是那些按名字的数目、逐一按人头登记的父家首领；他们从二十岁以上，办理耶和华殿事奉的工作。</span>
<span className="v" id="v25" data-v="25" data-xref="诗篇 132:13–14; 历代志上 22:18; 撒母耳记下 7:11"> 因为大卫说：“耶和华以色列的上帝已经使祂的子民得安息；祂永远住在耶路撒冷。</span>
<span className="v" id="v26" data-v="26" data-xref="民数记 4:5; 民数记 7:9; 民数记 4:15"> 利未人也不再需要抬帐幕和帐幕中供事奉用的一切器具。”</span>
<span className="v" id="v27" data-v="27" data-xref="历代志上 23:24; 诗篇 72:20; 撒母耳记下 23:1"> 照着大卫最后的话，利未的子孙从二十岁以上的都被数点。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志下 35:3–6; 历代志下 31:11; 历代志下 35:11–14"> 他们的职责是辅佐亚伦的子孙，办理耶和华殿的事奉：在院子里、在房间中、在洁净一切圣物上，以及上帝殿事奉的工作上；</span>
<span className="v" id="v29" data-v="29" data-xref="利未记 19:35–36; 出埃及记 25:30; 利未记 6:20–23"> 也负责陈设饼、素祭的细面，或无酵薄饼，或在锅里烤的，或调和的，又负责一切容量和尺寸的度量；</span>
<span className="v" id="v30" data-v="30" data-xref="诗篇 92:1–3; 以斯拉记 3:10–11; 历代志上 9:33"> 每天早晨站立，称谢赞美耶和华，晚上也照样；</span>
<span className="v" id="v31" data-v="31" data-xref="以赛亚书 1:13–14; 民数记 28:1–29; 民数记 10:10"> 又在安息日、月朔和指定的节期，按有关条例所定的数目，常常在耶和华面前向耶和华献上一切燔祭；</span>
<span className="v" id="v32" data-v="32" data-xref="民数记 1:53; 民数记 3:38; 民数记 3:6–9"> 并且他们要看守会幕的职责、圣所的职责，以及他们弟兄亚伦子孙的职责，办理耶和华殿的事奉。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 32:28; 创世记 35:22–26; 启示录 7:5–8"> 以色列的儿子是：流便、西缅、利未、犹大、以萨迦、西布伦、</span>
<span className="v" id="v2" data-v="2"> 但、约瑟、便雅悯、拿弗他利、迦得和亚设。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="创世记 38:2–10; 创世记 46:12; 民数记 26:19"> 犹大的儿子是：珥、俄南、示拉；这三人是迦南女子书亚的女儿给他生的。犹大的长子珥在耶和华<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="当英文以全大写字母显示“LORD”或“GOD”时，它是上帝专有名（希伯来文“יהוה”，通常读作雅威）的译法。">a</a></sup>眼中为恶，耶和华就杀了他。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 1:3; 创世记 38:13–30; 尼希米记 11:4"> 犹大的儿媳他玛给他生了法勒斯和谢拉。犹大的儿子共有五人。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 46:12; 路得记 4:18; 民数记 26:21"> 法勒斯的儿子是：希斯仑和哈母勒。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 4:31; 约书亚记 7:17–18; 约书亚记 7:1"> 谢拉的儿子是：心利、以探、希幔、甲各和达拉，共五人。</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 6:18; 申命记 7:26; 约书亚记 7:25"> 迦米的儿子是：亚割；他就是使以色列遭祸的人，在当灭之物上犯了罪。</span>
<span className="v" id="v8" data-v="8"> 以探的儿子是：亚撒利雅。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="历代志上 2:42; 马太福音 1:3; 路得记 4:19"> 希斯仑所生的儿子还有：耶拉篾、兰和基路拜。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 1:4; 民数记 1:7; 民数记 2:3"> 兰生亚米拿达；亚米拿达生拿顺，拿顺是犹大子孙的首领；</span>
<span className="v" id="v11" data-v="11" data-xref="路得记 4:21; 马太福音 1:4–5; 路加福音 3:32"> 拿顺生撒门，撒门生波阿斯，</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 15:12; 历代志上 10:14; 以赛亚书 11:10"> 波阿斯生俄备得，俄备得生耶西；</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记上 17:13; 撒母耳记上 17:28; 历代志上 20:7"> 耶西生长子以利押，次子亚比拿达，三子示米亚，</span>
<span className="v" id="v14" data-v="14"> 四子拿坦业，五子拉代，</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记上 16:10–11; 撒母耳记上 17:12–14"> 六子阿鲜，七子大卫；</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 26:6; 撒母耳记下 3:39; 撒母耳记下 2:18–23"> 他们的姐妹是洗鲁雅和亚比该。洗鲁雅的儿子是：亚比筛、约押和亚撒黑，共三人。</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 17:25; 列王纪上 2:32; 撒母耳记下 20:4–12"> 亚比该生亚玛撒；亚玛撒的父亲是以实玛利人益帖。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 希斯仑的儿子迦勒与妻子阿苏巴以及耶略生了儿女；她的儿子是：耶设、朔罢和押墩。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 2:50; 历代志上 2:24; 历代志上 4:4"> 阿苏巴死后，迦勒娶了以法他；以法他给他生了户珥。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 31:2; 出埃及记 36:1–2; 出埃及记 37:1"> 户珥生乌利，乌利生比撒列。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="民数记 27:1; 申命记 3:15; 民数记 26:29"> 后来希斯仑与基列之父玛吉的女儿同房；他六十岁时娶了她为妻，她给他生了西割。</span>
<span className="v" id="v22" data-v="22" data-xref="约书亚记 13:30; 申命记 3:14; 民数记 32:41"> 西割生睚珥；睚珥在基列地有二十三座城。</span>
<span className="v" id="v23" data-v="23" data-xref="约书亚记 13:30; 申命记 3:14; 民数记 32:41–42"> 基述人和亚兰人从他们手中夺取了睚珥的城镇，以及基纳和所属的乡镇，共六十座城。这些都是基列之父玛吉的子孙。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 4:5; 历代志上 2:9; 撒母耳记上 30:14"> 希斯仑在迦勒·以法他死了以后，希斯仑的妻子亚比雅给他生了提哥亚之父亚施户。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25"> 希斯仑的长子耶拉篾的儿子是：长子兰、布拿、阿连、阿鲜和亚希雅。</span>
<span className="v" id="v26" data-v="26"> 耶拉篾另有一个妻子，名叫亚他拉；她是阿南的母亲。</span>
<span className="v" id="v27" data-v="27"> 耶拉篾长子兰的儿子是：玛斯、雅悯和以结。</span>
<span className="v" id="v28" data-v="28"> 阿南的儿子是：沙买和雅大。沙买的儿子是：拿答和亚比述。</span>
<span className="v" id="v29" data-v="29"> 亚比述的妻子名叫亚比孩；她给他生了亚办和摩利。</span>
<span className="v" id="v30" data-v="30"> 拿答的儿子是：西列和亚遍；西列死了，没有儿女。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 2:34–35"> 亚遍的儿子是：以示。以示的儿子是：示珊。示珊的儿子是：亚来。</span>
<span className="v" id="v32" data-v="32"> 沙买的兄弟雅大的儿子是：益帖和约拿单；益帖死了，没有儿女。</span>
<span className="v" id="v33" data-v="33"> 约拿单的儿子是：比勒和撒萨。这些是耶拉篾的子孙。</span>
<span className="v" id="v34" data-v="34"> 示珊没有儿子，只有女儿。示珊有一个仆人，是埃及人，名叫耶哈。</span>
<span className="v" id="v35" data-v="35"> 示珊把自己的女儿嫁给他的仆人耶哈为妻；她给他生了亚太。</span>
<span className="v" id="v36" data-v="36" data-xref="历代志上 11:41"> 亚太生拿单，拿单生撒拔，</span>
<span className="v" id="v37" data-v="37"> 撒拔生以弗拉，以弗拉生俄备得，</span>
<span className="v" id="v38" data-v="38"> 俄备得生耶户，耶户生亚撒利雅，</span>
<span className="v" id="v39" data-v="39"> 亚撒利雅生希勒斯，希勒斯生以利亚萨，</span>
<span className="v" id="v40" data-v="40"> 以利亚萨生西斯买，西斯买生沙龙，</span>
<span className="v" id="v41" data-v="41"> 沙龙生耶加米雅，耶加米雅生以利沙玛。</span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="历代志上 2:23–24; 希伯来书 12:23; 罗马书 8:29"> 耶拉篾的兄弟迦勒的儿子是：长子米沙，他是西弗之父；还有希伯仑之父玛利沙的儿子。</span>
<span className="v" id="v43" data-v="43"> 希伯仑的儿子是：可拉、他普亚、利肯和示玛。</span>
<span className="v" id="v44" data-v="44"> 示玛生拉含；拉含是约干之父。利肯生沙买。</span>
<span className="v" id="v45" data-v="45" data-xref="约书亚记 15:58"> 沙买的儿子是玛云；玛云是伯夙之父。</span>
<span className="v" id="v46" data-v="46" data-xref="历代志上 2:18–19; 历代志上 2:48"> 迦勒的妾以法生哈兰、摩撒和迦谢；哈兰生迦谢。</span>
<span className="v" id="v47" data-v="47"> 雅代的儿子是：利健、约坦、基珊、比列、以法和沙亚弗。</span>
<span className="v" id="v48" data-v="48" data-xref="创世记 25:5–6; 历代志上 2:46"> 迦勒的妾玛迦生示别和特哈拿。</span>
<span className="v" id="v49" data-v="49" data-xref="约书亚记 15:31; 历代志上 2:42; 以赛亚书 10:31"> 她又生了抹玛拿之父沙亚弗，抹比拿之父和基比亚之父示法；迦勒的女儿是押撒。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="撒母耳记上 7:1; 约书亚记 15:60; 历代志上 2:53"> 这些是迦勒的儿子，迦勒是以法他的长子户珥的儿子：基列·耶琳之父朔巴、</span>
<span className="v" id="v51" data-v="51" data-xref="历代志上 4:4; 约翰福音 7:42; 马太福音 2:6"> 伯利恒之父撒门、伯迦得之父哈勒。</span>
<span className="v" id="v52" data-v="52" data-xref="历代志上 4:2"> 基列·耶琳之父朔巴有儿子：哈罗以，玛拿哈人的一半。</span>
<span className="v" id="v53" data-v="53" data-xref="撒母耳记下 23:38; 士师记 13:25; 士师记 13:2"> 基列·耶琳的宗族有：以帖人、布特人、书玛人和密来人；琐拉人和以实陶人都是从他们出来的。</span>
<span className="v" id="v54" data-v="54" data-xref="尼希米记 7:26; 以斯拉记 2:22; 尼希米记 12:28"> 撒门的子孙是：伯利恒、尼陀法人、亚他绿·伯·约押、玛拿哈人的一半，以及琐利人。</span>
<span className="v" id="v55" data-v="55" data-xref="列王纪下 10:15; 士师记 1:16; 耶利米书 35:19"> 住在雅比斯的文士宗族有：特拉人、示米押人和苏甲人。这些是从利甲家的祖先哈末而来的基尼人。</span>
</div>

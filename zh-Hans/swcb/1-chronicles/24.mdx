<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志上 23:6; 出埃及记 6:23; 民数记 26:60"> 亚伦子孙的班次如下。亚伦的儿子是拿答、亚比户、以利亚撒和以他玛。</span>
<span className="v" id="v2" data-v="2" data-xref="利未记 10:2; 民数记 3:4; 民数记 26:61"> 拿答和亚比户死在他们父亲以前，而且没有儿女；所以以利亚撒和以他玛供祭司的职分。</span>
<span className="v" id="v3" data-v="3" data-xref="撒母耳记下 8:17; 历代志上 24:31; 撒母耳记上 21:1"> 大卫和以利亚撒子孙中的撒督，以及以他玛子孙中的亚希米勒，按他们服事的职务次序给他们分班。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 23:24; 民数记 25:11–13; 历代志上 15:6–12"> 以利亚撒子孙中作首领的人，比以他玛子孙中作首领的人更多；他们这样分班：以利亚撒子孙中有十六个父家的首领；以他玛子孙中，按他们的父家，有八个。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 24:31; 约书亚记 18:10; 使徒行传 4:1"> 他们这样用抽签公平地分班；因为以利亚撒子孙和以他玛子孙中，都有圣所的首领和上帝的首领。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 18:16; 马太福音 8:19; 尼希米记 8:1"> 利未人中拿坦业的儿子书记示玛雅，在王、众首领、撒督祭司、亚比亚他的儿子亚希米勒，以及祭司和利未人各父家的首领面前，把他们记录下来；为以利亚撒取一个父家，也为以他玛取一个父家。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="以斯拉记 2:36; 尼希米记 11:10; 尼希米记 12:19"> 第一签抽出来归耶何雅立，第二签归耶大雅，</span>
<span className="v" id="v8" data-v="8" data-xref="以斯拉记 2:39; 尼希米记 7:35; 尼希米记 12:15"> 第三签归哈琳，第四签归梭琳，</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米记 12:17"> 第五签归玛基雅，第六签归米雅民，</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 1:5; 尼希米记 12:4; 尼希米记 12:17"> 第七签归哈歌斯，第八签归亚比雅，</span>
<span className="v" id="v11" data-v="11" data-xref="以斯拉记 2:36; 尼希米记 12:10; 尼希米记 7:39"> 第九签归耶书亚，第十签归示迦尼，</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米记 12:10"> 第十一签归以利亚实，第十二签归雅金，</span>
<span className="v" id="v13" data-v="13"> 第十三签归胡巴，第十四签归耶是比押，</span>
<span className="v" id="v14" data-v="14" data-xref="尼希米记 7:40; 以斯拉记 2:37; 以斯拉记 10:20"> 第十五签归比勒迦，第十六签归音麦，</span>
<span className="v" id="v15" data-v="15"> 第十七签归希悉，第十八签归哈辟悉，</span>
<span className="v" id="v16" data-v="16"> 第十九签归毗他希雅，第二十签归以西结，</span>
<span className="v" id="v17" data-v="17"> 第二十一签归雅斤，第二十二签归迦末，</span>
<span className="v" id="v18" data-v="18"> 第二十三签归第莱雅，第二十四签归玛西亚。</span>
<span className="v" id="v19" data-v="19" data-xref="历代志上 9:25; 哥林多前书 14:40; 希伯来书 7:11"> 这就是他们服事的职务次序，照着他们祖宗亚伦所给他们的条例，进入耶和华的殿，正如耶和华——以色列的上帝所吩咐亚伦的。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="历代志上 26:24; 历代志上 23:16; 历代志上 6:18"> 利未其余的子孙如下：暗兰的子孙中有书巴业；书巴业的子孙中有耶希底亚。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 23:17; 历代志上 26:25"> 利哈比雅：利哈比雅的子孙中，首领是伊示雅。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 23:18; 民数记 3:27; 民数记 3:19"> 以斯哈人中有示罗摩；示罗摩的子孙中有雅哈。</span>
<span className="v" id="v23" data-v="23" data-xref="历代志上 23:19; 历代志上 26:31"> 希伯伦的儿子是耶利雅，次子亚玛利雅，三子雅哈悉，四子耶加面。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 23:20"> 乌薛的儿子是米迦；米迦的子孙中有沙密。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志上 15:20; 历代志上 15:18; 历代志上 23:20"> 米迦的兄弟是伊示雅；伊示雅的子孙中有撒迦利亚。</span>
<span className="v" id="v26" data-v="26" data-xref="历代志上 23:21"> 米拉利的儿子是抹利和母示。雅西雅的儿子是比挪。</span>
<span className="v" id="v27" data-v="27" data-xref="民数记 3:20; 历代志上 23:21; 历代志上 6:19"> 米拉利从雅西雅所生的儿子是比挪、朔含、撒刻和伊比利。</span>
<span className="v" id="v28" data-v="28" data-xref="历代志上 23:22"> 抹利的子孙中有以利亚撒；以利亚撒没有儿子。</span>
<span className="v" id="v29" data-v="29"> 基士：基士的儿子是耶拉篾。</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 23:23; 历代志上 6:47"> 母示的儿子是抹利、以得和耶利摩。这些都是利未人的子孙，按他们的父家排列。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 24:5–6; 历代志上 26:13; 历代志上 25:8"> 他们也在大卫王、撒督、亚希米勒，以及祭司和利未人各父家的首领面前抽签，正如他们的兄弟亚伦的子孙一样；首要的父家和他年幼兄弟的父家一样。</span>

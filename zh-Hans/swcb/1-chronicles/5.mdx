<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 35:22; 创世记 29:32; 创世记 48:15–22"> 以色列长子流便的子孙（流便原是长子；但因为他玷污了父亲的床榻，他长子的名分就给了以色列儿子约瑟的子孙；家谱也不按长子的名分来记录。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 2:6; 弥迦书 5:2; 希伯来书 7:14"> 因为犹大胜过他的弟兄，君王也从他而出；但长子的名分是约瑟的）——</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 46:9; 出埃及记 6:14; 民数记 26:5–9"> 以色列长子流便的儿子是：哈诺、法路、希斯伦、迦米。</span>
<span className="v" id="v4" data-v="4"> 约珥的子孙：他的儿子示玛雅，示玛雅的儿子歌革，歌革的儿子示每，</span>
<span className="v" id="v5" data-v="5"> 示每的儿子米迦，米迦的儿子利亚雅，利亚雅的儿子巴力，</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 5:26; 列王纪下 15:29; 历代志下 28:20"> 巴力的儿子比拉；亚述王提革拉毗列尼色把他掳去。他是流便人的首领。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 5:17"> 他的弟兄按宗族，在他们世代的家谱登记时，有作首领的耶利、撒迦利雅，</span>
<span className="v" id="v8" data-v="8" data-xref="历代志上 5:4; 民数记 32:34; 民数记 32:38"> 还有比拉；比拉是亚撒的儿子，亚撒是示玛的儿子，示玛是约珥的儿子。比拉住在亚罗珥，直到尼波和巴力免；</span>
<span className="v" id="v9" data-v="9" data-xref="约书亚记 22:8–9"> 又向东居住，直到幼发拉底河这边旷野的入口，因为他们的牲畜在基列地增多。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="创世记 21:9; 历代志上 5:18–21; 诗篇 83:6"> 扫罗的日子，他们与夏甲人作战；夏甲人倒在他们手下，他们就住在夏甲人的帐棚里，遍布基列东边全地。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约书亚记 13:11; 约书亚记 13:24–28; 申命记 3:10–17"> 迦得的子孙住在他们旁边，在巴珊地，直到撒迦：</span>
<span className="v" id="v12" data-v="12"> 有首领约珥，次位沙番，还有雅乃和在巴珊的沙法。</span>
<span className="v" id="v13" data-v="13"> 他们同父家的弟兄有米迦勒、米书兰、示巴、约赖、雅干、细亚、希伯，共七人。</span>
<span className="v" id="v14" data-v="14"> 这些都是亚比孩的子孙；亚比孩是户利的儿子，户利是雅罗亚的儿子，雅罗亚是基列的儿子，基列是米迦勒的儿子，米迦勒是耶示筛的儿子，耶示筛是雅多的儿子，雅多是布斯的儿子。</span>
<span className="v" id="v15" data-v="15"> 还有古尼的孙子、押比叠的儿子亚希，是他们父家的首领。</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 27:29; 雅歌 2:1; 以赛亚书 35:2"> 他们住在基列、巴珊和巴珊的乡镇，并沙仑所有的牧场，直到它们的边界。</span>
<span className="v" id="v17" data-v="17" data-xref="列王纪下 14:16; 列王纪下 14:28; 列王纪下 15:32"> 这些人在犹大王约坦的日子和以色列王耶罗波安的日子，都按家谱登记。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="民数记 1:3; 约书亚记 4:12–13"> 流便的子孙、迦得人和玛拿西半支派中，有勇士，能拿盾牌和刀剑，能拉弓射箭，善于作战，能出去打仗的共有四万四千七百六十人。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 25:15; 历代志上 1:31; 历代志上 5:10"> 他们与夏甲人、伊突人、拿非施人和挪答人作战。</span>
<span className="v" id="v20" data-v="20" data-xref="诗篇 22:4–5; 诗篇 9:10; 历代志下 18:31"> 他们得了帮助，攻击这些人，夏甲人和所有与他们同在的人都被交在他们手中；因为他们在战斗中呼求上帝，祂就应允他们，因为他们倚靠祂。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 18:13; 民数记 31:35"> 他们夺取了这些人的牲畜：骆驼五万只，羊二十五万只，驴二千头，人口十万。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志下 32:8; 罗马书 8:31; 约书亚记 23:10"> 被杀倒下的人很多，因为这场战争是出于上帝。他们住在这些人的地方，直到被掳的时候。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="申命记 3:8–9; 雅歌 4:8; 诗篇 133:3"> 玛拿西半支派的子孙住在那地。他们人数增多，从巴珊直到巴力黑门、示尼珥和黑门山。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 4:38"> 这些是他们父家的首领：以弗、以示、以列、亚斯列、耶利米、何达威雅、雅叠；他们都是大能的勇士，有名望的人，是他们父家的首领。</span>
<span className="v" id="v25" data-v="25" data-xref="启示录 17:5; 诗篇 106:34–39; 出埃及记 34:15"> 他们背叛了他们列祖的上帝，随从那地各族的神明行淫；这些族是上帝在他们面前所毁灭的。</span>
<span className="v" id="v26" data-v="26" data-xref="列王纪下 15:19; 列王纪下 17:6; 列王纪下 15:29"> 因此，以色列的上帝激动亚述王普勒的心，也激动亚述王提革拉毗列尼色的心；他就把流便人、迦得人和玛拿西半支派掳走，带到哈腊、哈博、哈拉和歌散河边，直到今日。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 11:1–2; 撒母耳记下 10:1–19; 撒母耳记上 12:12"> 这事以后，亚扪人的王拿辖死了，他儿子接续他作王。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 23:3–6; 撒母耳记上 30:26; 创世记 19:37–38"> 大卫说：“我要以恩慈待拿辖的儿子哈嫩，因为他父亲曾以恩慈待我。”<br />于是大卫派使者去，为哈嫩的父亲安慰他。大卫的臣仆来到亚扪人的地，到哈嫩那里安慰他。</span>
<span className="v" id="v3" data-v="3" data-xref="士师记 1:23–24; 哥林多前书 13:5–7; 列王纪上 12:8–11"> 但亚扪人的首领对哈嫩说：“大卫派安慰者到你这里来，你以为他是在尊敬你的父亲吗？他的臣仆到你这里来，难道不是要查探、倾覆、窥探这地吗？”</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 10:4–5; 以赛亚书 15:2; 马可福音 12:4"> 于是哈嫩抓住大卫的臣仆，剃掉他们的胡须，又把他们的衣服从中间割断，直到臀部，然后把他们打发走。</span>
<span className="v" id="v5" data-v="5" data-xref="约书亚记 6:24–26; 马太福音 18:31; 列王纪上 16:34"> 有人去把这些人所受的待遇告诉大卫。王就派人去迎接他们，因为这些人极其羞辱。王说：“你们留在耶利哥，等胡须长起来，然后再回来。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="历代志上 18:5; 创世记 34:30; 历代志上 18:9"> 亚扪人见自己使大卫厌恶，哈嫩和亚扪人就送出一千他连得<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一他连得约为30公斤或66磅，所以一千他连得约为30公吨。">a</a></sup>银子，从美索不达米亚、亚兰・玛迦和琐巴雇用战车和骑兵。</span>
<span className="v" id="v7" data-v="7" data-xref="民数记 21:30; 约书亚记 13:9; 约书亚记 13:16"> 于是他们为自己雇了三万二千辆战车，以及玛迦王和他的军兵；他们来到米底巴附近安营。亚扪人也从他们各城聚集起来，出来作战。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志上 11:6; 历代志上 11:10–47; 撒母耳记下 23:8–39"> 大卫听见了，就派约押率领勇士的全军出战。</span>
<span className="v" id="v9" data-v="9" data-xref="列王纪上 20:1; 列王纪上 20:24; 以赛亚书 28:6"> 亚扪人出来，在城门口摆阵；那些前来的王另在田野摆阵。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 10:9–14; 士师记 20:42–43; 约书亚记 8:22"> 约押看见前后都有战阵攻击他，就从以色列所有精兵中挑选一些人，使他们摆阵迎战亚兰人。</span>
<span className="v" id="v11" data-v="11" data-xref="历代志上 18:12; 历代志上 11:20; 历代志上 19:9"> 其余的兵交在他兄弟亚比筛手中；他们摆阵迎战亚扪人。</span>
<span className="v" id="v12" data-v="12" data-xref="腓立比书 1:27–28; 尼希米记 4:20; 传道书 4:9–12"> 约押说：“如果亚兰人强过我，你就来帮助我；如果亚扪人强过你，我就去帮助你。</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 4:14; 诗篇 27:14; 撒母耳记下 10:12"> 要刚强，让我们为我们的百姓和我们上帝的城邑奋勇。愿耶和华照祂看为好的去行。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="列王纪上 20:19–21; 历代志下 13:5–16; 耶利米书 46:15–16"> 于是约押和跟随他的人向亚兰人阵前接近，要与他们交战；亚兰人在他面前逃跑。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 8:31; 利未记 26:7"> 亚扪人见亚兰人逃跑，他们也在约押兄弟亚比筛面前逃跑，进了城。于是约押回到耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 10:16; 撒迦利亚书 14:1–3; 弥迦书 4:11–12"> 亚兰人见自己被以色列击败，就派使者去，召来大河<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作：幼发拉底河。">b</a></sup>那边的亚兰人，由哈大底谢的军长朔法率领。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 22:6–7; 历代志上 19:9"> 有人把这事告诉大卫，他就聚集以色列全军，过了约旦河，来到他们那里，摆阵迎战他们。大卫既摆阵迎战亚兰人，他们就与他交战。</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记下 10:18; 诗篇 33:16; 诗篇 18:32"> 亚兰人在以色列面前逃跑；大卫杀了亚兰人七千名战车兵和四万名步兵，又杀了军长朔法。</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 10:19; 约书亚记 9:9–11; 列王纪上 20:1"> 哈大底谢的臣仆见自己被以色列击败，就与大卫讲和，臣服于他。从此亚兰人不再愿意帮助亚扪人。</span>
</div>
</div>

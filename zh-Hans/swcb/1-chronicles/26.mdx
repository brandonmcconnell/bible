<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="历代志下 23:19; 民数记 26:9–11; 诗篇 44:1"> 守门者的班次如下：可拉族中，亚萨子孙里可利的儿子米施利米雅。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 9:21"> 米施利米雅有几个儿子：长子撒迦利亚，次子耶叠，三子西巴第雅，四子雅提聂，</span>
<span className="v" id="v3" data-v="3"> 五子以拦，六子约哈难，七子以利约乃。</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 16:38; 历代志上 15:24; 历代志上 15:18"> 俄别以东有几个儿子：长子示玛雅，次子约萨拔，三子约亚，四子沙甲，五子拿坦业，</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 128:1"> 六子亚米利，七子以萨迦，八子毗乌利太；因为上帝赐福给他。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 12:28; 提摩太前书 6:12; 士师记 6:12"> 他的儿子示玛雅也生了几个儿子，他们管理自己父亲的家，因为他们是大能的勇士。</span>
<span className="v" id="v7" data-v="7"> 示玛雅的儿子是俄得尼、利法益、俄备得、以利萨巴；他们的亲族以利户和西玛迦也是勇士。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多后书 3:6; 彼得前书 4:11; 哥林多前书 12:4–11"> 这些都是俄别以东的子孙；他们和他们的儿子、弟兄，都是有能力、有力量办事的人。俄别以东家共六十二人。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 26:14; 历代志上 26:1"> 米施利米雅有儿子和弟兄，都是勇士，共十八人。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 16:38; 历代志上 5:1–2"> 米拉利子孙中，何萨也有几个儿子：首领申利（他本不是长子，但他父亲立他作首领），</span>
<span className="v" id="v11" data-v="11"> 次子希勒家，三子提巴利雅，四子撒迦利亚。何萨的儿子和弟兄共十三人。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="历代志上 25:8"> 这些人是守门者的班次，是首领们的班次；他们有职务，与他们的弟兄一样，在耶和华殿里事奉。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 25:8; 历代志上 24:31; 历代志上 24:5"> 他们按着父家，为各门抽签，无论大小都一样。</span>
<span className="v" id="v14" data-v="14"> 向东的签落在示利米雅名下。然后他们为他的儿子撒迦利亚抽签；他是有智慧的谋士，他的签落在北边。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志下 25:24; 历代志上 26:17"> 俄别以东抽到南边；他的儿子们抽到库房。</span>
<span className="v" id="v16" data-v="16" data-xref="尼希米记 12:24; 历代志上 26:10–12; 列王纪上 10:5"> 书聘和何萨抽到西边，在沙利基门旁、上行的大道那里，守卫与守卫相对。</span>
<span className="v" id="v17" data-v="17" data-xref="历代志下 8:14; 历代志上 9:24"> 东边每日有六个利未人，北边每日四人，南边每日四人，库房两人、两人。</span>
<span className="v" id="v18" data-v="18" data-xref="列王纪下 23:11"> 西边的帕巴，在大道上有四人，在帕巴有二人。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 16:11"> 这些是守门者的班次，属于可拉子孙和米拉利子孙。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="历代志上 26:22; 历代志上 28:12–19; 历代志上 22:14–16"> 利未人中，亚希雅管理上帝殿的府库和分别为圣之物的府库。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 23:7; 历代志上 6:17; 历代志上 29:8"> 拉但的子孙，就是属拉但的革顺人子孙，属革顺人拉但的父家首领，是耶希伊利。</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 23:8; 尼希米记 10:38; 历代志上 26:20"> 耶希伊利的儿子西坦和他的兄弟约珥，管理耶和华殿的府库。</span>
<span className="v" id="v23" data-v="23" data-xref="民数记 3:27; 历代志上 23:12; 民数记 3:19"> 暗兰族、以斯哈族、希伯伦族、乌薛族中：</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 24:20; 历代志上 23:15–16"> 摩西的儿子革舜的儿子细布业，掌管各府库。</span>
<span className="v" id="v25" data-v="25" data-xref="历代志上 23:17–18; 历代志上 23:15; 出埃及记 18:4"> 他的弟兄中，属以利以谢的，有以利以谢的儿子利哈比雅，利哈比雅的儿子耶筛亚，耶筛亚的儿子约兰，约兰的儿子细基利，细基利的儿子示罗密。</span>
<span className="v" id="v26" data-v="26" data-xref="撒母耳记下 8:11; 历代志上 29:2–9; 历代志上 22:14"> 这示罗密和他的弟兄管理一切分别为圣之物的府库，就是大卫王、父家首领、千夫长、百夫长和军队的将领所分别为圣的物。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 12:14; 约书亚记 6:19; 尼希米记 10:32–34"> 他们把战争中夺得的一些掠物分别为圣，用来修缮耶和华的殿。</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记上 9:9; 撒母耳记上 17:55; 撒母耳记下 10:9–14"> 凡先见撒母耳、基士的儿子扫罗、尼珥的儿子押尼珥、洗鲁雅的儿子约押所分别为圣的，以及任何人分别为圣的物，都归示罗密和他弟兄管理。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="历代志上 23:4; 尼希米记 11:16; 历代志下 34:13"> 以斯哈族中，基拿尼雅和他的儿子被派办理以色列的外务，作官员和审判官。</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 27:17; 历代志上 23:19; 历代志上 23:12"> 希伯伦族中，哈沙比雅和他的弟兄一千七百名勇士，负责管理约旦河西的以色列，办理耶和华的一切事务和王的事务。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 23:19; 约书亚记 21:39; 历代志上 29:27"> 希伯伦族中，耶利雅是希伯伦族的首领，是按他们世代的父家所立的。大卫作王第四十年，人们查访他们，在基列的雅谢，在他们中间找到了大能的勇士。</span>
<span className="v" id="v32" data-v="32" data-xref="历代志下 19:11; 历代志上 12:37; 历代志上 23:24"> 他的亲族有二千七百名勇士，都是父家首领；大卫王派他们管理吕便人、迦得人和玛拿西半支派，办理关于上帝的一切事务和王的事务。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记上 27:2–6; 历代志上 11:24–25; 历代志上 8:33"> 以下这些人是在大卫因基士的儿子扫罗而逃亡的时候，来到洗革拉投奔他的；他们都是勇士，帮助他作战。</span>
<span className="v" id="v2" data-v="2" data-xref="士师记 3:15; 士师记 20:16; 撒母耳记上 17:49"> 他们装备弓箭，能左右开弓，用机弦甩石，又能拉弓射箭；他们是便雅悯支派中扫罗的亲族。</span>
<span className="v" id="v3" data-v="3" data-xref="历代志上 11:28; 撒母耳记下 21:6; 历代志上 11:33"> 为首的是亚希以谢，其次是约阿施，他们是基比亚人示玛的儿子；还有押斯玛弗的儿子耶薛和毗勒；比拉迦；亚拿突人耶户；</span>
<span className="v" id="v4" data-v="4" data-xref="约书亚记 9:3; 约书亚记 15:36; 历代志上 11:15"> 基遍人以实玛雅，是三十勇士中的勇士，也是三十勇士的首领；耶利米；雅哈悉；约哈难；基低拉人约撒拔；</span>
<span className="v" id="v5" data-v="5"> 伊利乌赛；耶利摩；比亚利雅；示玛利雅；哈律弗人示法提雅；</span>
<span className="v" id="v6" data-v="6"> 以利加拿、耶西亚、亚撒列、约以谢、雅朔班，都是可拉人；</span>
<span className="v" id="v7" data-v="7" data-xref="约书亚记 15:58; 历代志上 4:18; 历代志上 4:39"> 还有基多人耶罗罕的儿子约拉和西巴第雅。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 2:18; 撒母耳记下 17:10; 撒母耳记下 23:20"> 有些迦得人到旷野的山寨投奔大卫，都是英勇的战士，受过战斗训练，能使用盾牌和枪；他们的面貌好像狮子的面貌，行动敏捷如山上的羚羊：</span>
<span className="v" id="v9" data-v="9"> 为首的是以谢，第二是俄巴底雅，第三是以利押，</span>
<span className="v" id="v10" data-v="10"> 第四是弥施玛拿，第五是耶利米，</span>
<span className="v" id="v11" data-v="11"> 第六是亚太，第七是以利业，</span>
<span className="v" id="v12" data-v="12"> 第八是约哈难，第九是以利萨巴，</span>
<span className="v" id="v13" data-v="13"> 第十是耶利米，第十一是末巴奈。</span>
<span className="v" id="v14" data-v="14" data-xref="申命记 32:30; 利未记 26:8"> 这些迦得子孙都是军队的首领；最小的能抵一百人，最大的能抵一千人。</span>
<span className="v" id="v15" data-v="15" data-xref="约书亚记 3:15; 约书亚记 4:18; 耶利米书 49:19"> 正月里，约旦河水涨过两岸的时候，他们渡过约旦河，使住在山谷中的人，无论东边西边，都逃散了。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 有些便雅悯人和犹大人也来到山寨投奔大卫。</span>
<span className="v" id="v17" data-v="17" data-xref="彼得前书 2:23; 犹大书 1:9; 哥林多后书 13:11"> 大卫出去迎接他们，对他们说：“你们若是和平地来帮助我，我的心就必与你们联合；但你们若是来把我出卖给我的敌人，虽然我手中没有过错，愿我们列祖的上帝察看并责备。”</span>
<span className="v" id="v18" data-v="18" data-xref="士师记 6:34; 士师记 3:10; 撒母耳记下 17:25"> 那时圣灵临到三十勇士的首领亚玛赛，他说：“大卫啊，我们是属你的；耶西的儿子啊，我们站在你这边。愿平安，愿平安归于你；也愿平安归于帮助你的人，因为你的上帝帮助你。”于是大卫接纳他们，立他们作队伍的首领。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="撒母耳记上 29:2–9"> 大卫从前与非利士人同去攻打扫罗的时候，也有些玛拿西人投奔他；但他们没有帮助非利士人，因为非利士人的首领商议之后把他送走，说：“他会临阵倒戈，归向他的主人扫罗，使我们的首级陷入危险。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="申命记 33:17; 申命记 1:15; 撒母耳记上 29:11"> 大卫往洗革拉去的时候，有玛拿西人投奔他：押拿、约撒拔、耶叠、米迦勒、约撒拔、以利户、洗勒太，都是玛拿西的千夫长。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 30:1–17; 历代志上 12:20; 历代志上 5:24"> 他们帮助大卫攻击劫掠的队伍，因为他们都是英勇的战士，又在军中作首领。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 3:1; 约伯记 17:9; 创世记 32:2"> 天天都有人来帮助大卫，直到成了一支大军，如同上帝的军队。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 2:3–4; 历代志上 11:10; 撒母耳记上 16:1"> 以下是装备作战、来到希伯仑见大卫的人数，为要照耶和华的话把扫罗的国转给他。</span>
<span className="v" id="v24" data-v="24"> 犹大子孙中拿盾牌和枪、装备作战的，有六千八百人。</span>
<span className="v" id="v25" data-v="25"> 西缅子孙中为战争预备的英勇战士，有七千一百人。</span>
<span className="v" id="v26" data-v="26"> 利未子孙中，有四千六百人。</span>
<span className="v" id="v27" data-v="27" data-xref="列王纪下 11:9; 列王纪下 25:18; 历代志上 6:49–57"> 耶何耶大是亚伦家的领袖，跟随他的有三千七百人；</span>
<span className="v" id="v28" data-v="28" data-xref="撒母耳记下 8:17; 历代志上 6:8; 历代志上 6:53"> 还有年轻英勇的撒督，以及他父家的二十二个首领。</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 2:8–9; 历代志上 12:2; 创世记 31:23"> 便雅悯子孙，就是扫罗的亲族，有三千人，因为直到那时，他们大多数仍效忠扫罗家。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 6:4"> 以法莲子孙中，有二万零八百人，都是英勇的战士，在他们父家中有名望。</span>
<span className="v" id="v31" data-v="31" data-xref="约书亚记 17:1–18"> 玛拿西半支派中，有一万八千人，是按名指定来立大卫为王的。</span>
<span className="v" id="v32" data-v="32" data-xref="以弗所书 5:17; 路加福音 12:56–57; 以斯帖记 1:13"> 以萨迦子孙中，有通达时势、知道以色列应当怎样行的人；他们的首领有二百人，所有弟兄都听从他们的命令。</span>
<span className="v" id="v33" data-v="33" data-xref="诗篇 12:2; 约翰福音 1:47"> 西布伦人中，能出征、能用各样兵器摆阵作战、能指挥并且不怀二心的，有五万人。</span>
<span className="v" id="v34" data-v="34"> 拿弗他利人中，有一千个首领，跟随他们拿盾牌和枪的有三万七千人。</span>
<span className="v" id="v35" data-v="35"> 但人中，能摆阵作战的，有二万八千六百人。</span>
<span className="v" id="v36" data-v="36" data-xref="历代志上 12:33; 约珥 2:7"> 亚设人中，能出征、能摆阵作战的，有四万人。</span>
<span className="v" id="v37" data-v="37" data-xref="约书亚记 14:3; 申命记 3:12–16; 约书亚记 13:7–32"> 约旦河那边，吕便人、迦得人和玛拿西半支派中，带着各样作战兵器的，有十二万人。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="创世记 49:8–10; 列王纪上 8:61; 诗篇 101:2"> 这些全都是能排列战阵的战士，他们以完全的心来到希伯仑，要立大卫作全以色列的王；其余的以色列人也都同心要立大卫为王。</span>
<span className="v" id="v39" data-v="39" data-xref="创世记 31:54; 撒母耳记下 19:42; 创世记 26:30"> 他们在那里与大卫同住三天，吃喝，因为他们的弟兄已经为他们预备了供应。</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳记上 25:18; 撒母耳记下 16:1; 耶利米书 23:5–6"> 此外，近处的人，甚至远到以萨迦、西布伦、拿弗他利的人，都用驴、骆驼、骡子和牛驮来饼，以及面粉、无花果饼、串串葡萄干、酒、油、牛和羊，供应丰富；因为以色列中有喜乐。</span>
</div>
</div>

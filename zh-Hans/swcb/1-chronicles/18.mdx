<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 8:1–18; 撒母耳记上 5:8; 撒母耳记下 1:20"> 此后，大卫击败非利士人，制伏了他们，又从非利士人手中夺取了迦特和它属下的城镇。</span>
<span className="v" id="v2" data-v="2" data-xref="列王纪下 3:4–5; 列王纪上 10:25; 以赛亚书 16:1"> 他击败摩押；摩押人就臣服于大卫，向他进贡。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="诗篇 60:1; 撒母耳记下 8:3; 创世记 15:18"> 琐巴王哈大底谢往哈马去，要在幼发拉底河一带建立自己的统治时，大卫击败了他。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 8:4; 列王纪上 10:26; 列王纪上 4:2"> 大卫从他那里夺取了一千辆战车、七千名骑兵、两万名步兵；大卫砍断了所有战车马的腿筋，只留下足够拉一百辆战车的马。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 19:6; 撒母耳记下 8:5–6; 撒母耳记上 14:47"> 大马士革的亚兰人来帮助琐巴王哈大底谢，大卫就击杀了亚兰人二万二千人。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 17:8; 诗篇 121:8; 箴言 21:31"> 于是大卫在大马士革的亚兰设立驻军；亚兰人就臣服于大卫，向他进贡。大卫无论往哪里去，耶和华都使他得胜。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 9:15–16; 列王纪上 10:16–17; 历代志下 12:9–10"> 大卫夺取哈大底谢臣仆所拿的金盾牌，把它们带到耶路撒冷。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 8:8; 历代志下 4:12–18; 列王纪上 7:15–47"> 大卫又从哈大底谢的城提巴和均夺取了非常多的铜；所罗门用这些铜制造了铜海、柱子和铜器。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 8:9"> 哈马王陀乌听见大卫击败了琐巴王哈大底谢的全军，</span>
<span className="v" id="v10" data-v="10" data-xref="撒母耳记下 8:10; 以赛亚书 39:1; 历代志下 9:1"> 就派他的儿子哈多兰去见大卫王，向他问安，并祝贺他，因为他攻打哈大底谢并击败了他——原来哈大底谢常与陀乌交战。哈多兰带来了各样金器、银器和铜器。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记上 30:13; 历代志上 26:26–27; 列王纪上 7:51"> 大卫王也把这些分别为圣献给耶和华，连同他从各国夺来的金银，就是从以东、摩押、亚扪人、非利士人和亚玛力夺来的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="历代志上 19:11; 撒母耳记下 10:10; 撒母耳记下 8:13–14"> 此外，洗鲁雅的儿子亚比筛在盐谷击杀了以东人一万八千。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 18:6; 创世记 27:37; 诗篇 144:10"> 他在以东设立驻军；所有以东人都臣服于大卫。大卫无论往哪里去，耶和华都使他得胜。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="耶利米书 33:15; 诗篇 89:14; 诗篇 78:71–72"> 大卫作全以色列的王；他为全体百姓施行公平和公义。</span>
<span className="v" id="v15" data-v="15" data-xref="历代志上 11:6; 列王纪上 4:3; 撒母耳记下 8:16"> 洗鲁雅的儿子约押统领军队；亚希律的儿子约沙法作史官；</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记下 8:17; 撒母耳记下 20:25; 列王纪上 4:3"> 亚希突的儿子撒督和亚比亚他的儿子亚比米勒作祭司；沙威沙作书记；</span>
<span className="v" id="v17" data-v="17" data-xref="撒母耳记下 8:18; 撒母耳记下 15:18; 列王纪上 2:34–35"> 耶何耶大的儿子比拿雅统领基利提人和比利提人；大卫的众子都在王身边作首领。</span>
</div>

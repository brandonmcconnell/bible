<span className="v" id="v4" data-v="4" data-xref="创世记 5:32; 创世记 9:18; 路加福音 17:26"> 挪亚、闪、含和雅弗。</span>

<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="创世记 10:1–5; 以西结 38:6; 以西结 27:13"> 雅弗的儿子：歌篾、玛各、玛代、雅完、土巴、米设和提拉。</span>
<span className="v" id="v6" data-v="6" data-xref="创世记 10:3"> 歌篾的儿子：亚实基拿、代法和陀迦玛。</span>
<span className="v" id="v7" data-v="7" data-xref="耶利米书 2:10; 民数记 24:24; 以赛亚书 66:19"> 雅完的儿子：以利沙、他施、基提和罗单。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="创世记 10:6–7"> 含的儿子：古实、麦西、弗和迦南。</span>
<span className="v" id="v9" data-v="9"> 古实的儿子：西巴、哈腓拉、撒弗他、拉玛、撒弗提迦。拉玛的儿子：示巴和底但。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 10:8–12; 弥迦书 5:6"> 古实生了宁录；他开始在地上成为勇士。</span>
<span className="v" id="v11" data-v="11" data-xref="创世记 10:13–18"> 麦西生了路低人、亚拿米人、利哈比人、拿弗土希人、</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 2:23; 耶利米书 47:4; 阿摩司 9:7"> 帕斯鲁细人、迦斯路希人（非利士人由此而出）和迦斐托人。</span>
<span className="v" id="v13" data-v="13" data-xref="创世记 9:22; 创世记 23:20; 创世记 10:15–19"> 迦南生了他的长子西顿，又生了赫，</span>
<span className="v" id="v14" data-v="14" data-xref="创世记 15:21; 约书亚记 3:10; 出埃及记 33:2"> 以及耶布斯人、亚摩利人、革迦撒人、</span>
<span className="v" id="v15" data-v="15" data-xref="出埃及记 3:8; 列王纪上 9:20; 出埃及记 13:5"> 希未人、亚基人、西尼人、</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 34:8; 列王纪上 8:65"> 亚瓦底人、洗玛利人和哈马人。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="创世记 10:22–32; 以斯拉记 4:2; 以西结 32:24"> 闪的儿子：以拦、亚述、亚法撒、路德、亚兰、乌斯、户勒、基帖和米设。</span>
<span className="v" id="v18" data-v="18" data-xref="创世记 11:12–15; 创世记 10:24"> 亚法撒生了沙拉，沙拉生了希伯。</span>
<span className="v" id="v19" data-v="19" data-xref="创世记 10:21; 创世记 11:16–17; 创世记 10:25"> 希伯生了两个儿子：一个名叫法勒，因为在他的日子，地被分开；他的兄弟名叫约坍。</span>
<span className="v" id="v20" data-v="20" data-xref="创世记 10:26–27"> 约坍生了亚摩答、沙列、哈萨玛非、耶拉、</span>
<span className="v" id="v21" data-v="21"> 哈多兰、乌萨、德拉、</span>
<span className="v" id="v22" data-v="22" data-xref="创世记 10:28"> 以巴、亚比玛利、示巴、</span>
<span className="v" id="v23" data-v="23" data-xref="列王纪上 10:11; 创世记 25:18; 撒母耳记上 15:7"> 俄斐、哈腓拉和约巴。这些都是约坍的儿子。</span>
<span className="v" id="v24" data-v="24" data-xref="创世记 11:10–26; 路加福音 3:34–36"> 闪、亚法撒、沙拉、</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 3:35"> 希伯、法勒、拉吴、</span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 3:34–35"> 西鹿、拿鹤、他拉、</span>
<span className="v" id="v27" data-v="27" data-xref="创世记 11:27–32; 尼希米记 9:7; 约书亚记 24:2"> 亚伯兰（也称为亚伯拉罕）。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="创世记 17:19–21; 创世记 21:2–5; 创世记 21:9–10"> 亚伯拉罕的儿子：以撒和以实玛利。</span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 60:7; 创世记 25:12–16; 雅歌 1:5"> 这些是他们的后代：以实玛利的长子尼拜约，其次是基达、亚德别、米比衫、</span>
<span className="v" id="v30" data-v="30" data-xref="以赛亚书 21:11; 创世记 25:15"> 米施玛、度玛、玛撒、哈达、提玛、</span>
<span className="v" id="v31" data-v="31"> 伊突、拿非施和基底玛。这些是以实玛利的儿子。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="创世记 25:1–4; 耶利米书 25:23; 士师记 6:1–6"> 亚伯拉罕的妾基土拉的儿子：她生了心兰、约珊、米但、米甸、伊施巴和书亚。约珊的儿子：示巴和底但。</span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 60:6"> 米甸的儿子：以法、以弗、哈诺、亚比大和以勒大。这些都是基土拉的儿子。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="创世记 32:28; 使徒行传 7:8; 马太福音 1:2"> 亚伯拉罕生了以撒。以撒的儿子：以扫和以色列。</span>
<span className="v" id="v35" data-v="35" data-xref="创世记 36:9–10; 创世记 36:4–5"> 以扫的儿子：以利法、流珥、耶乌施、雅兰和可拉。</span>
<span className="v" id="v36" data-v="36" data-xref="耶利米书 49:20; 阿摩司 1:12; 俄巴底亚 1:9"> 以利法的儿子：提幔、阿抹、洗非、迦坦、基纳斯、亭纳和亚玛力。</span>
<span className="v" id="v37" data-v="37"> 流珥的儿子：拿哈、谢拉、沙玛和米撒。</span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="创世记 36:20–30"> 西珥的儿子：罗坍、朔巴、祭便、亚拿、底顺、以察和底珊。</span>
<span className="v" id="v39" data-v="39" data-xref="申命记 2:12; 创世记 36:22; 申命记 2:22"> 罗坍的儿子：何利和荷幔；亭纳是罗坍的妹妹。</span>
<span className="v" id="v40" data-v="40" data-xref="创世记 36:23–24"> 朔巴的儿子：亚勒文、玛拿辖、以巴、示非和阿南。祭便的儿子：亚雅和亚拿。</span>
<span className="v" id="v41" data-v="41" data-xref="创世记 36:25–26"> 亚拿的儿子：底顺。底顺的儿子：哈姆兰、伊是班、益兰和基兰。</span>
<span className="v" id="v42" data-v="42" data-xref="耶利米哀歌 4:21; 创世记 36:27–28"> 以察的儿子：辟罕、撒番和雅干。底珊的儿子：乌斯和亚兰。</span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="创世记 36:31–43; 民数记 24:17–19; 创世记 49:10"> 这些是在以色列人有君王统治以前，在以东地作王的王：比珥的儿子比拉；他的城名叫亭哈巴。</span>
<span className="v" id="v44" data-v="44" data-xref="以赛亚书 34:6; 以赛亚书 63:1; 阿摩司 1:12"> 比拉死了，波斯拉人谢拉的儿子约巴接续他作王。</span>
<span className="v" id="v45" data-v="45" data-xref="创世记 36:11; 约伯记 2:11"> 约巴死了，提幔人之地的户珊接续他作王。</span>
<span className="v" id="v46" data-v="46"> 户珊死了，比达的儿子哈达接续他作王；这哈达曾在摩押田野击败米甸。他的城名叫亚未得。</span>
<span className="v" id="v47" data-v="47" data-xref="创世记 36:36"> 哈达死了，玛士利加人桑拉接续他作王。</span>
<span className="v" id="v48" data-v="48" data-xref="创世记 36:37"> 桑拉死了，大河旁的利河伯人扫罗接续他作王。</span>
<span className="v" id="v49" data-v="49"> 扫罗死了，亚革波的儿子巴勒·哈南接续他作王。</span>
<span className="v" id="v50" data-v="50" data-xref="创世记 36:39"> 巴勒·哈南死了，哈达接续他作王；他的城名叫巴伊。他妻子的名字是米希他别，是玛特列的女儿、米萨合的孙女。</span>
<span className="v" id="v51" data-v="51" data-xref="创世记 36:40"> 后来哈达死了。以东的族长有：亭纳族长、亚利亚族长、耶帖族长、</span>
<span className="v" id="v52" data-v="52"> 阿何利巴玛族长、以拉族长、比嫩族长、</span>
<span className="v" id="v53" data-v="53"> 基纳斯族长、提幔族长、米比萨族长、</span>
<span className="v" id="v54" data-v="54" data-xref="创世记 36:41–43"> 玛基叠族长和以兰族长。这些是以东的族长。</span>

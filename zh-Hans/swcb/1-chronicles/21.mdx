<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 24:1–25; 撒迦利亚书 3:1; 约伯记 2:4–6"> 撒但起来攻击以色列，激动大卫去数点以色列。</span>
<span className="v" id="v2" data-v="2" data-xref="历代志上 27:23–24; 撒母耳记下 3:10; 撒母耳记下 24:15"> 大卫对约押和百姓的首领说：“你们去，从别是巴直到但，数点以色列；把结果报给我，好让我知道他们的数目。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="申命记 1:11; 以赛亚书 26:15; 历代志上 19:13"> 约押说：“愿耶和华使祂的子民比现在多一百倍。但是，我主我王啊，他们不都是我主的仆人吗？我主为什么要求做这事呢？为什么要使以色列陷入罪责呢？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="使徒行传 5:29; 出埃及记 1:17; 但以理 3:18"> 然而王的话胜过了约押。于是约押出去，走遍全以色列，然后回到耶路撒冷。</span>
<span className="v" id="v5" data-v="5" data-xref="撒母耳记下 24:9; 历代志上 27:23"> 约押把所数点的百姓总数交给大卫。全以色列能拔刀的有一百一十万人；犹大能拔刀的有四十七万人。</span>
<span className="v" id="v6" data-v="6" data-xref="历代志上 27:24; 民数记 1:47–49; 撒母耳记下 20:9–10"> 但约押没有把利未和便雅悯数在其中，因为他厌恶王的命令。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="列王纪上 15:5; 约书亚记 7:5; 撒母耳记下 21:14"> 上帝不喜悦这事，因此祂击打以色列。</span>
<span className="v" id="v8" data-v="8" data-xref="撒母耳记下 12:13; 约翰一书 1:9; 创世记 34:7"> 大卫对上帝说：“我做了这事，犯了大罪。现在求你除去你仆人的罪孽，因为我行了极愚昧的事。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="撒母耳记上 9:9; 撒母耳记下 24:11; 历代志上 29:29"> 耶和华对大卫的先见迦得说：</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 13:21–22; 启示录 3:19; 箴言 1:29–31"> “你去告诉大卫说：‘耶和华如此说：“我给你三样选择。你要选择其中一样，好让我向你施行。”’”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="箴言 19:20"> 于是迦得来到大卫那里，对他说：“耶和华如此说：‘你自己选择：</span>
<span className="v" id="v12" data-v="12" data-xref="申命记 28:27; 使徒行传 12:23; 以西结 14:19–21"> 或者三年的饥荒；或者在你敌人面前被消灭三个月，让你仇敌的刀追上你；或者三天耶和华的刀，就是地上的瘟疫，并且耶和华的使者在以色列全境施行毁灭。现在你要考虑，我该怎样回复那差我来的。’”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="诗篇 130:7; 以赛亚书 55:7; 腓立比书 1:23"> 大卫对迦得说：“我甚为困苦。求让我落在耶和华手中，因为祂的怜悯极大；不要让我落在人手中。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="出埃及记 12:30; 历代志上 27:24; 列王纪下 19:35"> 于是耶和华降瘟疫在以色列，以色列中倒下了七万人。</span>
<span className="v" id="v15" data-v="15" data-xref="创世记 6:6; 出埃及记 32:14; 耶利米书 26:18"> 上帝差遣一位使者到耶路撒冷，要毁灭它。正要毁灭的时候，耶和华看见，就为这灾祸转意，对那施行毁灭的使者说：“够了！现在收回你的手。”那时，耶和华的使者站在耶布斯人阿珥楠的禾场旁。</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 14:5; 列王纪上 21:27; 列王纪下 6:17"> 大卫举目，看见耶和华的使者站在地与天空之间，手里有拔出的刀，伸向耶路撒冷。<br />那时大卫和长老都身穿麻衣，俯伏在地。</span>
<span className="v" id="v17" data-v="17" data-xref="以西结 16:63; 撒母耳记下 24:17; 约翰福音 10:11–12"> 大卫对上帝说：“吩咐数点百姓的不是我吗？犯罪、行了大恶的正是我；但这些羊做了什么呢？耶和华我的上帝啊，求你的手攻击我和我的父家；不要攻击你的子民，使他们遭受灾害。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="历代志下 3:1; 撒母耳记下 24:18; 历代志上 21:11"> 那时，耶和华的使者吩咐迦得去告诉大卫，要大卫上去，在耶布斯人阿珥楠的禾场上为耶和华筑一座坛。</span>
<span className="v" id="v19" data-v="19" data-xref="使徒行传 9:6; 约翰福音 2:5; 列王纪下 5:10–14"> 大卫就照迦得奉耶和华之名所说的话上去了。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="士师记 6:11"> 阿珥楠回头，看见那使者；与他同在的四个儿子都藏起来了。那时阿珥楠正在打麦子。</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记上 25:23; 撒母耳记下 24:18–20"> 大卫来到阿珥楠那里，阿珥楠观看，看见大卫，就从禾场出去，面伏于地，向大卫下拜。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 24:21; 列王纪上 21:2; 民数记 25:8"> 大卫对阿珥楠说：“请把这禾场的地方卖给我，好让我在这里为耶和华筑一座坛。你要按足价卖给我，使瘟疫可以从百姓中止住。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="撒母耳记下 24:22–23; 撒母耳记上 6:14; 创世记 23:4–6"> 阿珥楠对大卫说：“你拿去吧，愿我主我王照他眼中看为好的去做。看哪，我把牛给你作燔祭，把打麦器具给你作柴，把小麦给你作素祭；这一切我都给你。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="申命记 16:16–17; 创世记 14:23; 创世记 23:13"> 大卫王对阿珥楠说：“不，我一定要按足价买。我不可把你的东西拿来献给耶和华，也不可献不用我花代价的燔祭。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 24:24–25"> 于是大卫为那地方给了阿珥楠六百舍客勒<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一舍客勒约为10克，或约0.32金衡盎司，因此600舍客勒约为6千克，或约192金衡盎司。">a</a></sup>重的金子。</span>
<span className="v" id="v26" data-v="26" data-xref="利未记 9:24; 士师记 6:21; 箴言 15:8"> 大卫在那里为耶和华筑了一座坛，献上燔祭和平安祭，并求告耶和华；耶和华就从天上以火在燔祭坛上回应他。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="约翰福音 18:11; 诗篇 103:20; 历代志上 21:15–16"> 耶和华吩咐那使者，他就把刀收回鞘里。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28"> 那时，大卫见耶和华在耶布斯人阿珥楠的禾场上回应了他，就在那里献祭。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 16:39; 历代志下 1:3; 历代志下 1:13"> 因为摩西在旷野所造耶和华的帐幕和燔祭坛，那时都在基遍的丘坛。</span>
<span className="v" id="v30" data-v="30" data-xref="启示录 1:17; 希伯来书 12:28–29; 启示录 15:4"> 但大卫不能到那坛前求问上帝，因为他因耶和华使者的刀而惧怕。</span>
</div>
</div>

</div>

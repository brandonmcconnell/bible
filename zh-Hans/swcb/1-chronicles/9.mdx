<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="尼希米记 7:64; 历代志上 5:25–26; 耶利米书 52:14–15"> 这样，以色列众人都按家谱登记；看哪，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“看哪”源自“הִנֵּה”，意思是看、留意、观察、看见或凝视。它常用作感叹词。">a</a></sup>他们都记在《以色列诸王记》上。犹大因他们的不忠被掳到巴比伦。</span>
<span className="v" id="v2" data-v="2" data-xref="尼希米记 7:73; 以斯拉记 2:58; 以斯拉记 2:70"> 最先回到自己城邑中产业居住的，是以色列人、祭司、利未人和殿役。</span>
<span className="v" id="v3" data-v="3" data-xref="尼希米记 11:1; 历代志下 11:16; 尼希米记 11:4–9"> 在耶路撒冷，住着犹大子孙、便雅悯子孙，以及以法莲和玛拿西子孙中的一些人：</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 2:5; 创世记 46:12; 民数记 26:20"> 乌太；乌太是亚米忽的儿子，亚米忽是暗利的儿子，暗利是音利的儿子，音利是巴尼的儿子；他属于犹大的儿子法勒斯的子孙。</span>
<span className="v" id="v5" data-v="5" data-xref="民数记 26:20; 尼希米记 11:5"> 示罗人中有长子亚赛雅和他的众子。</span>
<span className="v" id="v6" data-v="6" data-xref="民数记 26:20; 历代志上 2:6; 创世记 38:30"> 谢拉的子孙中有耶乌利和他们的弟兄，共六百九十人。</span>
<span className="v" id="v7" data-v="7" data-xref="尼希米记 10:20; 尼希米记 11:7; 尼希米记 8:4"> 便雅悯的子孙中有撒路；撒路是米书兰的儿子，米书兰是何大雅的儿子，何大雅是哈西努亚的儿子；</span>
<span className="v" id="v8" data-v="8"> 还有耶罗罕的儿子伊比尼雅，米基利的孙子、乌西的儿子以拉，以及伊比尼雅的曾孙、利乌珥的孙子、示法提雅的儿子米书兰；</span>
<span className="v" id="v9" data-v="9" data-xref="尼希米记 11:8"> 还有他们的弟兄，按他们的世代，共九百五十六人。这些人按他们的父家都是父系家族的族长。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="尼希米记 12:19; 尼希米记 11:10–24"> 祭司中有耶大雅、耶何雅立、雅斤，</span>
<span className="v" id="v11" data-v="11" data-xref="尼希米记 11:11; 列王纪下 25:18; 民数记 4:33"> 还有管理上帝殿的亚撒利雅；亚撒利雅是希勒家的儿子，希勒家是米书兰的儿子，米书兰是撒督的儿子，撒督是米拉约的儿子，米拉约是亚希突的儿子；</span>
<span className="v" id="v12" data-v="12" data-xref="尼希米记 7:40; 以斯拉记 2:37; 尼希米记 11:12–13"> 还有亚大雅；亚大雅是耶罗罕的儿子，耶罗罕是巴施户珥的儿子，巴施户珥是玛基雅的儿子；还有玛赛；玛赛是亚第业的儿子，亚第业是雅西拉的儿子，雅西拉是米书兰的儿子，米书兰是米示利密的儿子，米示利密是音麦的儿子；</span>
<span className="v" id="v13" data-v="13" data-xref="尼希米记 11:14; 历代志上 26:30; 历代志上 26:32"> 还有他们的弟兄，都是他们父家的族长，共一千七百六十人；他们都是很能干的人，适合做上帝殿中服事的工作。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="民数记 26:57; 尼希米记 10:11; 历代志上 6:29"> 利未人中有示玛雅；示玛雅是哈述的儿子，哈述是亚斯利甘的儿子，亚斯利甘是哈沙比雅的儿子，属于米拉利的子孙；</span>
<span className="v" id="v15" data-v="15" data-xref="尼希米记 11:22; 尼希米记 11:17; 历代志上 11:17"> 还有巴巴甲、希勒施、迦拉，以及玛他尼；玛他尼是米迦的儿子，米迦是细基利的儿子，细基利是亚萨的儿子；</span>
<span className="v" id="v16" data-v="16" data-xref="历代志上 25:1; 历代志下 35:15; 历代志上 12:25"> 还有俄巴底亚；俄巴底亚是示玛雅的儿子，示玛雅是迦拉的儿子，迦拉是耶杜顿的儿子；还有比利家；比利家是亚撒的儿子，亚撒是以利加拿的儿子，他住在尼陀法人的村庄里。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="历代志上 26:1–32; 历代志上 23:5; 尼希米记 11:19"> 守门人有沙龙、亚谷、达们、亚希幔和他们的弟兄；沙龙是首领。</span>
<span className="v" id="v18" data-v="18" data-xref="以西结 46:1–2; 以西结 44:2–3; 列王纪上 10:5"> 他们先前在朝东的王门供职。他们是利未子孙营地的守门人。</span>
<span className="v" id="v19" data-v="19" data-xref="民数记 26:9–11; 诗篇 44:1; 列王纪下 11:15"> 沙龙是可利的儿子，可利是以比雅撒的儿子，以比雅撒是可拉的儿子。沙龙和他父家的弟兄可拉族人，负责服事的工作，看守会幕的门槛。他们的祖先曾管理耶和华的营，守护入口。</span>
<span className="v" id="v20" data-v="20" data-xref="民数记 31:6; 民数记 3:32; 民数记 4:33"> 从前，以利亚撒的儿子非尼哈管理他们，耶和华与他同在。</span>
<span className="v" id="v21" data-v="21" data-xref="历代志上 26:14; 历代志上 26:2"> 米施利米雅的儿子撒迦利雅，是会幕门口的守门人。</span>
<span className="v" id="v22" data-v="22" data-xref="撒母耳记上 9:9; 历代志上 28:13; 历代志上 23:1–32"> 凡被选作门槛守门人的，共二百一十二人。他们按家谱登记在自己的村庄中，是大卫和先见撒母耳指定担任这受托职分的。</span>
<span className="v" id="v23" data-v="23" data-xref="以西结 44:14; 历代志下 23:19; 以西结 44:10–11"> 于是他们和他们的子孙负责看守耶和华殿的门，就是会幕之殿的门，作守卫。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 26:14–18"> 守门人在四方，就是东、西、南、北四面。</span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 11:5; 历代志下 23:8; 列王纪下 11:7"> 他们住在各村庄的弟兄，每七天要定期前来与他们同职，</span>
<span className="v" id="v26" data-v="26" data-xref="尼希米记 13:5; 尼希米记 10:38–39; 历代志上 26:20–27"> 因为四个守门长是利未人，担任受托的职分，管理上帝殿的房间和库房。</span>
<span className="v" id="v27" data-v="27" data-xref="历代志上 23:30–32; 玛拉基书 1:10; 撒母耳记上 3:15"> 他们住在上帝殿的四周，因为这是他们的职责；每天早晨开门也是他们的职责。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="尼希米记 13:4–5; 尼希米记 12:44; 历代志上 26:22–26"> 他们中有人负责服事用的器皿；这些器皿按数拿进，也按数拿出。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 23:29; 出埃及记 30:23–38; 出埃及记 27:20"> 他们中也有人被指派管理器具、圣所的一切器皿、细面、酒、油、乳香和香料。</span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="出埃及记 30:23–25; 出埃及记 37:29; 出埃及记 30:35–38"> 祭司的子孙中有人调制香料的混合物。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 9:19; 历代志上 9:22; 利未记 6:21"> 利未人中有一人名叫玛他提雅，是可拉族沙龙的长子，受托管理在平锅上烤的物。</span>
<span className="v" id="v32" data-v="32" data-xref="利未记 24:5–8; 历代志上 6:33–48; 出埃及记 25:30"> 他们的弟兄中，哥辖子孙有人负责陈设饼，每逢安息日预备。</span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="历代志上 6:31–33; 诗篇 134:1–2; 历代志上 16:4–6"> 这些是歌唱者，是利未人父系家族的族长，住在房间中，免去其他事务，因为他们昼夜从事自己的工作。</span>
<span className="v" id="v34" data-v="34" data-xref="尼希米记 11:1–15; 历代志上 9:13"> 这些人按他们的世代，是利未人父系家族的族长，是首领。他们住在耶路撒冷。</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="历代志上 2:23–24; 历代志上 2:50–52; 历代志上 8:29–40"> 基遍的父亲耶利住在基遍；他的妻子名叫玛迦。</span>
<span className="v" id="v36" data-v="36" data-xref="历代志上 9:39; 历代志上 8:33"> 他的长子是押顿，其次是族珥、基士、巴力、尼珥、拿答、</span>
<span className="v" id="v37" data-v="37" data-xref="历代志上 8:31"> 基多、亚希约、撒迦利雅和米基罗。</span>
<span className="v" id="v38" data-v="38" data-xref="历代志上 8:32"> 米基罗生示米暗。他们也和自己的亲族一起住在耶路撒冷，靠近自己的亲族。</span>
<span className="v" id="v39" data-v="39" data-xref="撒母耳记上 13:22; 历代志上 8:33–38; 历代志上 10:2"> 尼珥生基士。基士生扫罗。扫罗生约拿单、玛基舒亚、亚比拿达和伊施巴力。</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳记下 4:4; 历代志上 8:34–36"> 约拿单的儿子是米力巴力。米力巴力生米迦。</span>
<span className="v" id="v41" data-v="41" data-xref="历代志上 8:35"> 米迦的儿子是毗顿、米勒、他利亚和亚哈斯。</span>
<span className="v" id="v42" data-v="42" data-xref="历代志上 8:36"> 亚哈斯生雅拉。雅拉生亚拉篾、亚斯玛威和心利。心利生摩撒。</span>
<span className="v" id="v43" data-v="43" data-xref="历代志上 8:37"> 摩撒生比尼亚；他的儿子是利法雅，利法雅的儿子是以利亚萨，以利亚萨的儿子是亚悉。</span>
<span className="v" id="v44" data-v="44"> 亚悉有六个儿子，他们的名字是亚斯利甘、波基路、以实玛利、示亚利雅、俄巴底亚和哈难。这些都是亚悉的儿子。</span>
</div>

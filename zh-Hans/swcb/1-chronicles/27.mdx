<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="列王纪上 4:27; 历代志下 26:11–13; 申命记 1:15"> 以色列人按他们的人数，就是父家首领、千夫长、百夫长，以及在各班次的一切事务上服事王的官员；这些班次全年逐月轮流出入，每班有二万四千人。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="历代志上 11:11; 撒母耳记下 23:8"> 第一个月第一班的统领是撒巴第业的儿子雅朔班；他的班有二万四千人。</span>
<span className="v" id="v3" data-v="3" data-xref="民数记 26:20; 民数记 10:14; 创世记 49:8–10"> 他是法勒斯的子孙，是第一个月所有军队统领的首领。</span>
<span className="v" id="v4" data-v="4" data-xref="撒母耳记下 23:9; 历代志上 11:12"> 第二个月的班次由亚合人朵代和他的班次管理，密基罗作官长；他的班有二万四千人。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志上 18:17; 列王纪上 4:4–5"> 第三个月第三位军队统领是祭司长耶何耶大的儿子比拿雅；他的班有二万四千人。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 23:20–23; 历代志上 11:22–25; 撒母耳记下 22:20–23"> 这比拿雅是三十勇士中的勇士，并统领三十人；他的班次中有他儿子亚米萨拔。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 11:26; 撒母耳记下 23:24; 撒母耳记下 2:18–23"> 第四个月第四位统领是约押的兄弟亚撒黑；他以后是他的儿子西巴第雅；他的班有二万四千人。</span>
<span className="v" id="v8" data-v="8" data-xref="历代志上 11:27; 撒母耳记下 23:25; 历代志上 26:29"> 第五个月第五位统领是以斯拉人沙姆户；他的班有二万四千人。</span>
<span className="v" id="v9" data-v="9" data-xref="历代志上 11:28; 撒母耳记下 23:26"> 第六个月第六位统领是提哥亚人益吉的儿子以拉；他的班有二万四千人。</span>
<span className="v" id="v10" data-v="10" data-xref="历代志上 11:27; 撒母耳记下 23:26"> 第七个月第七位统领是以法莲子孙中比伦人希利斯；他的班有二万四千人。</span>
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 21:18; 历代志上 11:29; 民数记 26:20"> 第八个月第八位统领是谢拉族中户沙人西比该；他的班有二万四千人。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 11:28; 撒母耳记下 23:27"> 第九个月第九位统领是便雅悯人中亚拿突人亚比以谢；他的班有二万四千人。</span>
<span className="v" id="v13" data-v="13" data-xref="历代志上 11:30; 撒母耳记下 23:28"> 第十个月第十位统领是谢拉族中尼陀法人玛哈莱；他的班有二万四千人。</span>
<span className="v" id="v14" data-v="14" data-xref="历代志上 11:31; 撒母耳记下 23:30"> 第十一个月第十一位统领是以法莲子孙中比拉顿人比拿雅；他的班有二万四千人。</span>
<span className="v" id="v15" data-v="15" data-xref="撒母耳记下 23:29; 历代志上 4:13; 士师记 3:9"> 第十二个月第十二位统领是俄陀聂族中尼陀法人希勒代；他的班有二万四千人。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16"> 此外，管理以色列各支派的是：管理流便人的，是细基利的儿子以利以谢；管理西缅人的，是玛迦的儿子示法提雅；</span>
<span className="v" id="v17" data-v="17" data-xref="历代志上 26:30; 历代志上 24:31; 历代志上 12:27–28"> 管理利未的，是基母利的儿子哈沙比雅；管理亚伦的，是撒督；</span>
<span className="v" id="v18" data-v="18" data-xref="撒母耳记上 16:6; 撒母耳记上 17:29; 撒母耳记上 17:13"> 管理犹大的，是大卫的一个兄弟以利户；管理以萨迦的，是米迦勒的儿子暗利；</span>
<span className="v" id="v19" data-v="19"> 管理西布伦的，是俄巴底雅的儿子以实玛雅；管理拿弗他利的，是亚斯列的儿子耶利摩；</span>
<span className="v" id="v20" data-v="20"> 管理以法莲子孙的，是亚撒细雅的儿子何细亚；管理玛拿西半支派的，是毗大雅的儿子约珥；</span>
<span className="v" id="v21" data-v="21" data-xref="撒母耳记下 3:27; 撒母耳记上 14:50–51; 撒母耳记下 3:37"> 管理基列地玛拿西半支派的，是撒迦利雅的儿子易多；管理便雅悯的，是押尼珥的儿子雅西业；</span>
<span className="v" id="v22" data-v="22" data-xref="历代志上 28:1"> 管理但的，是耶罗罕的儿子亚萨列。这些是以色列各支派的统领。</span>
<span className="v" id="v23" data-v="23" data-xref="创世记 15:5; 历代志上 21:2–5; 希伯来书 11:12"> 但大卫没有数点二十岁和二十岁以下的人，因为耶和华曾说祂要使以色列增多，如天上的星。</span>
<span className="v" id="v24" data-v="24" data-xref="历代志上 21:1–17; 撒母耳记下 24:1–15"> 洗鲁雅的儿子约押开始数点，却没有完成；因此烈怒临到以色列。这数目也没有列入大卫王记的账册中。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="历代志下 16:2; 出埃及记 1:11; 历代志下 26:10"> 掌管王的府库的是亚叠的儿子亚斯玛威。掌管田野、城镇、村庄和塔楼中府库的是乌西雅的儿子约拿单；</span>
<span className="v" id="v26" data-v="26"> 管理耕种田地之人的，是基绿的儿子以斯利。</span>
<span className="v" id="v27" data-v="27"> 管理葡萄园的是拉玛人示每。管理葡萄园出产、用于酒窖的是示弗米人撒巴第。</span>
<span className="v" id="v28" data-v="28" data-xref="列王纪上 10:27; 历代志下 1:15; 列王纪上 4:7"> 管理低地橄榄树和桑无花果树的是基第利人巴勒哈南。管理油库的是约阿施。</span>
<span className="v" id="v29" data-v="29" data-xref="历代志上 5:16; 以赛亚书 65:10"> 管理在沙仑放牧的牛群的是沙仑人示提赉。管理山谷中牛群的是押莱的儿子沙法。</span>
<span className="v" id="v30" data-v="30" data-xref="创世记 47:6; 约伯记 1:3"> 管理骆驼的是以实玛利人阿比勒。管理驴群的是米仑人耶希底亚。管理羊群的是哈基人雅悉。</span>
<span className="v" id="v31" data-v="31" data-xref="历代志上 5:10"> 这些都是管理大卫王产业的官员。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="撒母耳记下 21:21; 撒母耳记下 13:3; 历代志上 11:11"> 大卫的叔叔约拿单作谋士；他是通达人，又是书记。哈摩尼的儿子耶歇陪伴王的众子。</span>
<span className="v" id="v33" data-v="33" data-xref="撒母耳记下 15:12; 撒母耳记下 15:37; 撒母耳记下 15:32"> 亚希多弗作王的谋士。亚基人户筛作王的朋友。</span>
<span className="v" id="v34" data-v="34" data-xref="历代志上 11:6; 列王纪上 1:7; 历代志上 27:5"> 亚希多弗之后，有比拿雅的儿子耶何耶大和亚比亚他。约押作王军队的统帅。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒母耳记下 5:1–16; 历代志上 12:23–40; 士师记 9:2"> 于是全以色列聚集到希伯仑，来到大卫那里，说：“看哪，我们是你的骨肉。</span>
<span className="v" id="v2" data-v="2" data-xref="撒母耳记下 5:2; 约翰福音 10:4; 诗篇 78:71"> 从前，甚至扫罗作王的时候，率领以色列出入的是你。耶和华你的上帝曾对你说：‘你要牧养我的子民以色列，你要作我子民以色列的君王。’”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 16:12–13; 撒母耳记上 16:1; 撒母耳记下 5:3"> 于是，以色列所有的长老都到希伯仑来见王；大卫就在希伯仑，在耶和华面前与他们立约。他们照耶和华藉撒母耳所说的话，膏立大卫作以色列的王。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="士师记 1:21; 创世记 15:21; 约书亚记 15:8"> 大卫和全以色列往耶路撒冷去，耶路撒冷又名耶布斯；那里的居民耶布斯人住在那里。</span>
<span className="v" id="v5" data-v="5" data-xref="历代志下 5:2; 列王纪上 8:1; 诗篇 87:2"> 耶布斯的居民对大卫说：“你进不到这里来！”然而大卫攻取了锡安的坚固城；这就是大卫城。</span>
<span className="v" id="v6" data-v="6" data-xref="撒母耳记下 8:16; 撒母耳记下 20:23; 撒母耳记下 3:27"> 大卫曾说：“谁先攻打耶布斯人，谁就作首领和统帅。”洗鲁雅的儿子约押先上去，就被立为首领。</span>
<span className="v" id="v7" data-v="7" data-xref="历代志上 11:5; 撒母耳记下 5:7; 诗篇 2:6"> 大卫住在那坚固城里，所以人称它为大卫城。</span>
<span className="v" id="v8" data-v="8" data-xref="士师记 9:6; 列王纪上 11:27; 列王纪下 12:20"> 他从米罗起，直到四围，建筑这城；约押修复城中其余的部分。</span>
<span className="v" id="v9" data-v="9" data-xref="撒母耳记下 3:1; 以赛亚书 41:10; 历代志上 9:20"> 大卫越来越强大，因为万军之耶和华与他同在。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="历代志上 11:3; 撒母耳记上 16:1; 历代志上 12:38"> 以下是大卫勇士中的首领；他们在他的国中与他一同奋勇，并同全以色列照耶和华关于以色列所说的话，立他作王。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="撒母耳记下 23:8; 历代志上 27:2; 历代志上 12:18"> 这是大卫勇士的数目：哈革摩尼人的儿子雅朔班，是三十人的首领；他举起枪攻击三百人，一次把他们杀死。</span>
<span className="v" id="v12" data-v="12" data-xref="历代志上 27:4; 撒母耳记下 23:17–19; 撒母耳记下 23:23"> 其次是亚合人朵多的儿子以利亚撒；他是三个勇士之一。</span>
<span className="v" id="v13" data-v="13" data-xref="撒母耳记下 23:11–12; 撒母耳记上 17:1"> 他曾与大卫在巴斯达闵；非利士人聚集在那里要打仗。那里有一块田长满大麦，百姓在非利士人面前逃跑。</span>
<span className="v" id="v14" data-v="14" data-xref="诗篇 144:10; 列王纪下 5:1; 撒母耳记上 14:23"> 他们却站在那块田中间，守住那田，击杀非利士人；耶和华施行了大拯救。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="历代志上 14:9; 撒母耳记下 5:18; 以赛亚书 17:5"> 三十个首领中的三个人下到磐石那里，到亚杜兰洞见大卫；非利士人的军队在利乏音谷安营。</span>
<span className="v" id="v16" data-v="16" data-xref="撒母耳记上 10:5; 撒母耳记上 13:4; 撒母耳记上 13:23"> 那时大卫在坚固城里，非利士人的驻军在伯利恒。</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 4:14; 以赛亚书 12:3; 撒母耳记下 23:15–16"> 大卫渴想，说：“但愿有人把伯利恒城门旁井里的水打来给我喝！”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="使徒行传 21:13; 撒母耳记上 19:5; 使徒行传 20:24"> 这三个人就闯过非利士人的军营，从伯利恒城门旁的井里打水，取了带到大卫那里；大卫却不肯喝，反而把水倾倒给耶和华，</span>
<span className="v" id="v19" data-v="19" data-xref="撒母耳记下 23:17; 诗篇 72:14; 士师记 9:17"> 说：“我的上帝绝不容我这样做！我岂可喝这些冒生命危险之人的血吗？”因为他们冒着生命危险把水带来。因此他不肯喝。这是那三个勇士所做的事。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="撒母耳记上 26:6; 历代志上 2:16; 撒母耳记下 20:6"> 约押的兄弟亚比筛是这三人的首领；他举起枪攻击三百人，把他们杀死，就在这三人中有名。</span>
<span className="v" id="v21" data-v="21" data-xref="哥林多前书 15:41; 马太福音 13:8"> 在这三人中，他比那两个更尊贵，因此作了他们的统领；然而他没有列入那三人之中。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="撒母耳记下 23:20–23; 撒母耳记下 8:18; 约书亚记 15:21"> 耶何耶大的儿子比拿雅，是甲薛一个勇士的儿子，行过大能的事；他杀了摩押的亚利伊勒两个儿子。他又在下雪的日子下到坑里，杀了一头狮子。</span>
<span className="v" id="v23" data-v="23" data-xref="撒母耳记上 17:7; 撒母耳记上 17:4; 申命记 3:11"> 他杀了一个埃及人；那人身材高大，有五肘<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="一肘是男人手臂从中指尖到肘部的长度，约18英寸或46厘米。因此这个埃及人身高约7英尺6英寸，即2.28米。">a</a></sup>高。那埃及人手里拿着一支枪，像织布机的轴；比拿雅只拿着棍子下去迎战他，从埃及人手里夺过枪来，用他自己的枪杀了他。</span>
<span className="v" id="v24" data-v="24"> 耶何耶大的儿子比拿雅做了这些事，就在三个勇士中有名。</span>
<span className="v" id="v25" data-v="25" data-xref="撒母耳记下 20:23"> 看哪，他比那三十人更尊贵，却没有达到那三人的地位；大卫立他统领自己的护卫队。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="历代志上 27:7; 撒母耳记下 21:19; 撒母耳记下 2:18–23"> 众军中的勇士还有：约押的兄弟亚撒黑，伯利恒人朵多的儿子伊勒哈难，</span>
<span className="v" id="v27" data-v="27" data-xref="撒母耳记下 23:25–26"> 哈罗人沙摩，比伦人希利斯，</span>
<span className="v" id="v28" data-v="28" data-xref="历代志上 27:12; 历代志上 27:9; 撒母耳记下 23:27"> 提哥亚人益吉的儿子以拉，亚拿突人亚比以谢，</span>
<span className="v" id="v29" data-v="29" data-xref="撒母耳记下 23:27–28; 历代志上 27:11"> 户沙人西比该，亚合人以莱，</span>
<span className="v" id="v30" data-v="30" data-xref="历代志上 27:13; 历代志上 27:15; 撒母耳记下 23:29"> 尼陀法人玛哈莱，尼陀法人巴拿的儿子希立，</span>
<span className="v" id="v31" data-v="31" data-xref="撒母耳记下 23:29"> 便雅悯子孙中基比亚人利拜的儿子以太，比拉顿人比拿雅，</span>
<span className="v" id="v32" data-v="32" data-xref="撒母耳记下 23:30–31"> 迦实溪人户莱，亚拉巴人亚比伊勒，</span>
<span className="v" id="v33" data-v="33"> 巴哈鲁人亚斯玛威，沙本人以利雅哈巴，</span>
<span className="v" id="v34" data-v="34" data-xref="撒母耳记下 23:32–33"> 基孙人哈深的儿子们，哈拉人沙基的儿子约拿单，</span>
<span className="v" id="v35" data-v="35" data-xref="撒母耳记下 23:33–34"> 哈拉人沙甲的儿子亚希暗，乌珥的儿子以利法，</span>
<span className="v" id="v36" data-v="36"> 米基拉人希弗，比伦人亚希雅，</span>
<span className="v" id="v37" data-v="37" data-xref="撒母耳记下 23:35"> 迦密人希斯罗，以斯拜的儿子拿莱，</span>
<span className="v" id="v38" data-v="38" data-xref="撒母耳记下 23:36"> 拿单的兄弟约珥，哈基利的儿子米巴，</span>
<span className="v" id="v39" data-v="39"> 亚扪人洗勒，比录人拿哈莱，就是洗鲁雅的儿子约押拿兵器的人，</span>
<span className="v" id="v40" data-v="40" data-xref="撒母耳记下 20:26"> 以帖人以拉，以帖人迦立，</span>
<span className="v" id="v41" data-v="41" data-xref="历代志上 2:36; 撒母耳记下 23:39; 撒母耳记下 11:6–27"> 赫人乌利亚，亚来的儿子撒拔，</span>
<span className="v" id="v42" data-v="42"> 吕便人示撒的儿子亚第拿，是吕便人的一个首领，另有三十人跟随他，</span>
<span className="v" id="v43" data-v="43"> 玛迦的儿子哈难，密特尼人约沙法，</span>
<span className="v" id="v44" data-v="44"> 亚斯她拉人乌西亚，亚罗珥人何坦的儿子沙玛和耶利，</span>
<span className="v" id="v45" data-v="45"> 示弥利的儿子耶叠和他的兄弟约哈，提洗人，</span>
<span className="v" id="v46" data-v="46"> 玛哈未人以利业，伊勒拿安的儿子耶利拜和约沙未雅，摩押人以特玛，</span>
<span className="v" id="v47" data-v="47"> 以利业，俄备得，米琐巴人雅西业。</span>
</div>

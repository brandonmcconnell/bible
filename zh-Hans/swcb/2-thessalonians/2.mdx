<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 4:14–17; 马可福音 13:27; 马太福音 24:31"> 弟兄们，关于我们主耶稣基督的来临，以及我们聚集到祂那里，我们请求你们，</span>
<span className="v" id="v2" data-v="2" data-xref="约翰一书 4:1–2; 马可福音 13:7; 马太福音 24:4–6"> 不要因灵、因话语，或因冒称出于我们的书信，说基督的日子已经来到，就很快心思动摇或惊慌。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 24:4–6; 约翰一书 2:18; 以弗所书 5:6"> 任何人都不要用任何方式欺骗你们。因为除非那背叛<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：离弃；或译：叛离">a</a></sup>先来到，并且那罪恶之人，就是灭亡之子，被显露出来，那日子就不会来到。</span>
<span className="v" id="v4" data-v="4" data-xref="以西结 28:2; 但以理 7:25; 启示录 13:6–7"> 他抵挡一切被称为神的，或受人敬拜的，并且高抬自己超过这一切，以至于他像上帝一样坐在上帝的殿里，自称为上帝。</span>
<span className="v" id="v5" data-v="5" data-xref="彼得后书 1:15; 加拉太书 5:21; 马太福音 16:9"> 我还与你们在一起的时候，曾告诉你们这些事，你们不记得吗？</span>
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦后书 2:3; 帖撒罗尼迦后书 2:8"> 现在你们知道那拦阻他的是什么，为要使他在自己的时候被显露出来。</span>
<span className="v" id="v7" data-v="7" data-xref="约翰一书 4:3; 启示录 17:7; 提摩太后书 2:17–18"> 因为不法的奥秘已经在运行；只是现在有一位拦阻的，直到他被挪开。</span>
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦后书 2:3; 启示录 19:20–21; 以赛亚书 11:4"> 那时，那不法者必被显露出来；主必用祂口中的气杀灭他，并以祂来临时的显现消灭他。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 24:24; 启示录 19:20; 以弗所书 2:2"> 这不法者的来临，是照着撒但的运行，带着各样能力、神迹和虚假的奇事，</span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 1:18; 箴言 1:7; 哥林多后书 4:2–3"> 并且在那些正在灭亡的人中，带着各样邪恶的欺骗；因为他们没有接受对真理的爱，使他们可以得救。</span>
<span className="v" id="v11" data-v="11" data-xref="罗马书 1:28; 约翰福音 12:39–43; 提摩太前书 4:1"> 因此，上帝给他们送去强烈的迷惑，使他们信从谎言，</span>
<span className="v" id="v12" data-v="12" data-xref="罗马书 1:32; 罗马书 8:7–8; 马可福音 16:16"> 好使所有不信真理、倒喜爱不义的人都被定罪。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="提摩太后书 1:9; 以弗所书 1:4–5; 帖撒罗尼迦前书 1:4"> 主所爱的弟兄们，我们却总该为你们感谢上帝，因为上帝从起初拣选了你们，使你们借着圣灵的成圣和对真理的信而得救。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 2:12; 彼得前书 5:10; 帖撒罗尼迦前书 1:5"> 为此，祂借着我们所传的福音呼召你们，好让你们得着我们主耶稣基督的荣耀。</span>
<span className="v" id="v15" data-v="15" data-xref="哥林多前书 11:2; 帖撒罗尼迦后书 3:6; 帖撒罗尼迦后书 2:2"> 所以，弟兄们，要站立得稳，持守我们所教导你们的传统，无论是口传的，还是书信传的。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="罗马书 5:2–5; 约翰福音 3:16; 彼得前书 1:3–8"> 愿我们的主耶稣基督自己，和爱我们、借着恩典赐给我们永远安慰和美好盼望的上帝我们的父，</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦后书 3:3; 帖撒罗尼迦前书 3:13; 帖撒罗尼迦前书 3:2"> 安慰你们的心，并在一切善行善言上坚固你们。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="哥林多后书 1:19; 使徒行传 16:1; 帖撒罗尼迦前书 1:1–10"> 保罗、西拉和提摩太，写信给在我们的父上帝和主耶稣基督里的帖撒罗尼迦人的教会：</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 1:7; 哥林多前书 1:3; 哥林多前书 1:8"> 愿恩典与平安从我们的父上帝和主耶稣基督归给你们。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="彼得后书 3:18; 彼得后书 1:5–10; 箴言 4:18"> 弟兄们，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这里译为“弟兄们”的词，以及上下文允许的地方，也可以正确地译为“弟兄姊妹们”或“手足们”。">a</a></sup>我们应当常常为你们感谢上帝，这本是合宜的，因为你们的信心格外增长，你们每一个人彼此相爱的心也都充足满溢，</span>
<span className="v" id="v4" data-v="4" data-xref="希伯来书 10:36; 雅各书 5:7–8; 希伯来书 12:1–3"> 以致我们自己在上帝的众教会中，因你们在所遭受的一切逼迫和患难中仍有坚忍和信心，就为你们夸耀。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 1:28; 使徒行传 14:22; 路加福音 20:35"> 这正是上帝公义审判的明显记号，为要使你们配得上帝的国；你们也正是为这国受苦。</span>
<span className="v" id="v6" data-v="6" data-xref="撒迦利亚书 2:8; 歌罗西书 3:25; 诗篇 94:20–23"> 因为在上帝看来，将患难报应给那些使你们受患难的人，是公义的；</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 14:13; 马太福音 16:27; 犹大书 1:14–15"> 也使你们这些受患难的人与我们同得安息，就是在主耶稣同祂大能的天使，在火焰中从天上显现的时候。</span>
<span className="v" id="v8" data-v="8" data-xref="彼得前书 4:17; 彼得后书 3:7; 希伯来书 10:27"> 祂要惩罚那些不认识上帝的人，以及那些不顺从我们主耶稣福音的人；</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 25:41; 启示录 14:10–11; 马太福音 25:46"> 他们要受刑罚，就是离开主的面和祂大能的荣耀，遭受永远的毁灭。</span>
<span className="v" id="v10" data-v="10" data-xref="以弗所书 1:18; 哥林多前书 3:13; 约翰福音 17:10"> 在那日，祂来要在祂的圣徒身上得荣耀，并在一切信的人中受赞叹；因为我们向你们所作的见证，你们已经信了。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="腓立比书 2:13; 歌罗西书 1:9–13; 帖撒罗尼迦前书 1:3"> 为此，我们也常常为你们祷告，愿我们的上帝算你们配得祂的呼召，并用能力成就你们一切良善的愿望和信心的工作，</span>
<span className="v" id="v12" data-v="12" data-xref="帖撒罗尼迦后书 1:10; 彼得前书 4:14; 约翰福音 17:10"> 好使我们主耶稣<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="公认经文加上“基督”。">b</a></sup>的名照着我们的上帝和主耶稣基督的恩典，在你们身上得荣耀，你们也在祂里面得荣耀。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦前书 5:25; 歌罗西书 4:3; 哥林多前书 16:9"> 最后，弟兄们，请为我们祷告，使主的道迅速传开，并得着荣耀，正如在你们中间一样；</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多后书 4:3–4; 罗马书 15:31; 申命记 32:20"> 也使我们得以脱离无理又邪恶的人，因为不是人人都有信心。</span>
<span className="v" id="v3" data-v="3" data-xref="提摩太后书 4:18; 帖撒罗尼迦前书 5:24; 哥林多前书 10:13"> 但主是信实的，祂必坚固你们，保护你们脱离那恶者。</span>
<span className="v" id="v4" data-v="4" data-xref="腓立比书 1:6; 腓利门书 1:21; 帖撒罗尼迦前书 4:10"> 关于你们，我们在主里有信心，知道我们所吩咐的事，你们现在正在行，将来也必行。</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 119:36; 历代志上 29:18; 申命记 30:6"> 愿主引导你们的心进入上帝的爱和基督的忍耐。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="帖撒罗尼迦后书 3:10–11; 帖撒罗尼迦后书 3:7; 罗马书 16:17"> 弟兄们，我们奉我们主耶稣基督的名吩咐你们：凡有弟兄不守规矩地行事，不照他们从我们所领受的传统而行，你们都要远离他。</span>
<span className="v" id="v7" data-v="7" data-xref="帖撒罗尼迦后书 3:6; 帖撒罗尼迦后书 3:9; 哥林多前书 4:16"> 你们自己知道应当怎样效法我们，因为我们在你们中间没有不守规矩地行事，</span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 6:11; 帖撒罗尼迦前书 2:9; 以弗所书 4:28"> 也没有白吃任何人的饭，而是辛劳困苦，昼夜工作，免得加重你们任何人的负担。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦后书 3:7; 帖撒罗尼迦前书 2:6; 哥林多前书 9:4–14"> 这并不是因为我们没有权利，而是要把自己作为榜样给你们，使你们效法我们。</span>
<span className="v" id="v10" data-v="10" data-xref="创世记 3:19; 箴言 13:4; 箴言 20:4"> 我们在你们那里的时候，也曾这样吩咐你们：“若有人不愿意工作，就不可让他吃饭。”</span>
<span className="v" id="v11" data-v="11" data-xref="提摩太前书 5:13; 帖撒罗尼迦后书 3:6; 帖撒罗尼迦前书 4:11"> 因为我们听说，在你们中间有些人不守规矩地行事，什么工都不做，反倒专管闲事。</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 4:28; 帖撒罗尼迦前书 4:11; 帖撒罗尼迦后书 3:8"> 这样的人，我们在主耶稣基督里吩咐并劝勉他们，要安静地工作，吃自己的饭。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="加拉太书 6:9–10; 希伯来书 12:3; 哥林多后书 4:1"> 但你们，弟兄们，行善不要厌倦。</span>
<span className="v" id="v14" data-v="14" data-xref="提多书 3:10; 帖撒罗尼迦后书 3:6; 哥林多前书 5:11"> 如果有人不听从我们在这封信里的话，要记下那人，不要与他交往，好使他惭愧。</span>
<span className="v" id="v15" data-v="15" data-xref="提多书 3:10; 帖撒罗尼迦前书 5:14; 哥林多前书 5:5"> 不要把他当作仇敌，却要劝戒他如同弟兄。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="诗篇 29:11; 约翰福音 16:33; 马太福音 1:23"> 愿赐平安的主亲自随时随事赐你们平安。愿主与你们众人同在。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="哥林多前书 16:21; 帖撒罗尼迦后书 1:5; 歌罗西书 4:18"> 我保罗亲笔问安；这是每封信中的记号。我就是这样写的。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 16:20; 罗马书 16:23"> 愿我们主耶稣基督的恩典与你们众人同在。阿们。</span>
</div>

<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="1TH" data-book-slug="1-thessalonians" data-book-name="帖撒罗尼迦前书" data-chapter="2" data-verses="20">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="帖撒罗尼迦后书 3:1; 哥林多前书 15:2; 哥林多前书 15:58"> 弟兄们，你们自己知道，我们到你们那里去并不是徒然的；</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 16:22–24; 使徒行传 4:13; 使徒行传 17:2–9"> 你们也知道，我们从前在腓立比受了苦，又遭受羞辱，却仍靠着我们的上帝放胆，在许多争战中把上帝的福音传给你们。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 2:17; 哥林多后书 4:2; 帖撒罗尼迦前书 4:7"> 因为我们的劝勉不是出于错谬，不是出于污秽，也不是用诡诈；</span>
<span className="v" id="v4" data-v="4" data-xref="加拉太书 1:10; 罗马书 8:27; 加拉太书 2:7"> 而是既然蒙上帝验中，把福音托付给我们，我们就这样讲，不是要讨人喜欢，而是要讨那察验我们心的上帝喜欢。</span>
<span className="v" id="v5" data-v="5" data-xref="罗马书 1:9; 哥林多后书 12:17; 使徒行传 20:33"> 因为我们从来没有用谄媚的话，这是你们知道的；也没有以贪婪为幌子，上帝可以作见证；</span>
<span className="v" id="v6" data-v="6" data-xref="加拉太书 1:10; 帖撒罗尼迦前书 2:9; 约翰福音 5:41"> 也没有向人寻求荣耀，不是向你们，也不是向别人。我们作为基督的使徒，本可以要求权柄，</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 66:13; 帖撒罗尼迦前书 2:11; 提摩太后书 2:24–25"> 但我们在你们中间温柔，好像哺乳的母亲爱护自己的孩子。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约翰一书 3:16; 哥林多后书 12:15; 腓立比书 2:17"> 我们这样深切爱慕你们，不但乐意把上帝的福音分给你们，也愿意把自己的生命给你们，因为你们已经成了我们非常亲爱的人。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦后书 3:7–9; 哥林多后书 11:9; 使徒行传 18:3"> 弟兄们，你们记得我们的辛劳和劳苦；我们昼夜做工，为的是不加重你们任何人的负担，就向你们传讲上帝的福音。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得前书 5:3; 帖撒罗尼迦前书 1:5; 哥林多后书 1:12"> 你们和上帝都可以作见证，我们对你们这些信的人为人是何等圣洁、公义、无可指责。</span>
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 4:14–15; 希伯来书 13:22; 提摩太前书 5:21"> 你们也知道，我们怎样待你们每一个人，好像父亲待自己的儿女一样，劝勉你们，安慰你们，恳求你们，</span>
<span className="v" id="v12" data-v="12" data-xref="以弗所书 4:1; 约翰一书 2:6; 约翰一书 1:6–7"> 使你们行事为人配得过那召你们进入祂自己国度和荣耀的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="希伯来书 4:12; 罗马书 10:17; 彼得前书 1:23"> 为这缘故，我们也不住地感谢上帝，因为你们从我们领受上帝信息的话时，并不把它当作人的话来接纳，而是照它实在所是的，当作上帝的话来接纳；这话也在你们这些信的人里面运行。</span>
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 3:4; 希伯来书 10:33–34; 希伯来书 5:7–8"> 弟兄们，你们成了在基督耶稣里、在犹太的上帝众教会的效法者；因为你们也从自己的同胞受了同样的苦，正如他们从犹太人所受的一样。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 5:12; 路加福音 11:48–53; 使徒行传 7:52"> 这些犹太人既杀害了主耶稣和他们自己的先知，又把我们赶出去；他们不讨上帝喜悦，并且敌对众人，</span>
<span className="v" id="v16" data-v="16" data-xref="使徒行传 17:13; 使徒行传 14:19; 马可福音 16:16"> 拦阻我们向外邦人说话，使外邦人可以得救，好常常填满他们自己的罪。但忿怒已经临到他们，到了极处。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="歌罗西书 2:5; 哥林多前书 5:3; 帖撒罗尼迦前书 3:6"> 弟兄们，我们暂时与你们分离，是在身体上，不是在心里；就越发迫切，极其渴望见你们的面。</span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 15:22; 罗马书 1:13; 启示录 2:10"> 因此我们想要到你们那里去；我保罗确实一次又一次想去，可是撒但阻挡了我们。</span>
<span className="v" id="v19" data-v="19" data-xref="腓立比书 4:1; 帖撒罗尼迦前书 3:13; 腓立比书 2:16"> 我们的盼望、喜乐，或欢喜的冠冕是什么呢？在我们的主耶稣<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR 加有“基督”">a</a></sup>降临的时候，在祂面前，不正是你们吗？</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多后书 1:14; 哥林多前书 11:7; 箴言 17:6"> 因为你们就是我们的荣耀，我们的喜乐。</span>
</div>
</div>

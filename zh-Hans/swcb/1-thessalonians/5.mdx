<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="使徒行传 1:7; 帖撒罗尼迦前书 4:9; 马太福音 24:36"> 弟兄们，关于时候和日期，不需要写什么给你们。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 16:15; 彼得后书 3:10; 马太福音 24:42–44"> 因为你们自己清楚知道，主的日子来到，就像夜间的贼一样。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 21:34–35; 马太福音 24:37–39; 路加福音 17:26–30"> 人正说“平安稳妥”的时候，突然的毁灭就临到他们，好像产痛临到怀孕的妇人一样；他们绝不能逃脱。</span>
<span className="v" id="v4" data-v="4" data-xref="约翰一书 2:8; 彼得后书 3:10; 申命记 19:6"> 但弟兄们，你们不在黑暗里，以致那日子像贼一样临到你们。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 5:8; 使徒行传 26:18; 约翰福音 12:36"> 你们都是光明之子，都是白昼之子。我们不属于黑夜，也不属于黑暗；</span>
<span className="v" id="v6" data-v="6" data-xref="彼得前书 1:13; 马太福音 24:42; 路加福音 22:46"> 所以，我们不要像其余的人那样睡觉，却要警醒谨守。</span>
<span className="v" id="v7" data-v="7" data-xref="罗马书 13:13; 哥林多前书 15:34; 彼得后书 2:13"> 因为睡觉的人是在夜里睡，醉酒的人是在夜里醉。</span>
<span className="v" id="v8" data-v="8" data-xref="罗马书 13:12–13; 以弗所书 6:11; 彼得前书 1:13"> 但既然我们属于白昼，就要谨守，穿上信心和爱心的胸甲，又把救恩的盼望当作头盔戴上。</span>
<span className="v" id="v9" data-v="9" data-xref="帖撒罗尼迦前书 1:10; 彼得前书 2:10; 提摩太后书 2:10"> 因为上帝不是定意要我们遭受忿怒，而是要我们借着我们的主耶稣基督得着救恩；</span>
<span className="v" id="v10" data-v="10" data-xref="罗马书 14:8–9; 彼得前书 3:18; 罗马书 8:34"> 祂为我们死，使我们无论醒着或睡着，都可以与祂同活。</span>
<span className="v" id="v11" data-v="11" data-xref="以弗所书 4:29; 希伯来书 10:25; 罗马书 15:2"> 所以，你们要彼此劝勉，互相建立，正如你们一直在做的。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="希伯来书 13:17; 希伯来书 13:7; 提摩太前书 5:17–18"> 弟兄们，我们请求你们，要看重那些在你们中间劳苦、在主里治理你们并劝戒你们的人；</span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 9:50; 希伯来书 12:14; 加拉太书 6:6"> 又因他们所做的工，用爱心格外尊重他们。<br />你们彼此要和睦。</span>
<span className="v" id="v14" data-v="14" data-xref="提摩太后书 4:2; 罗马书 14:1; 使徒行传 20:35"> 弟兄们，我们劝你们：要劝戒不守规矩的人，勉励灰心的人，扶助软弱的人，对众人要忍耐。</span>
<span className="v" id="v15" data-v="15" data-xref="彼得前书 3:9; 加拉太书 6:10; 利未记 19:18"> 你们要谨慎，不可有人以恶报恶待任何人；倒要常常追求对彼此和对众人都有益的事。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="罗马书 12:12; 腓立比书 4:4; 马太福音 5:12"> 要常常喜乐。</span>
<span className="v" id="v17" data-v="17" data-xref="罗马书 12:12; 歌罗西书 4:2; 以弗所书 6:18"> 要不住地祷告。</span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 5:20; 腓立比书 4:6; 歌罗西书 3:17"> 凡事谢恩，因为这是上帝在基督耶稣里对你们的旨意。</span>
<span className="v" id="v19" data-v="19" data-xref="以弗所书 4:30; 使徒行传 7:51; 提摩太后书 1:6"> 不要熄灭圣灵。</span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 14:3–6; 哥林多前书 14:1; 民数记 11:25–29"> 不要藐视先知性的讲论。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰一书 4:1; 罗马书 12:2; 以弗所书 5:10"> 凡事都要察验；那美善的，要牢牢持守。</span>
<span className="v" id="v22" data-v="22" data-xref="哥林多后书 6:3; 腓立比书 4:8; 哥林多前书 10:31–33"> 要远离各样形式的恶。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="犹大书 1:24; 希伯来书 4:12; 哥林多前书 1:8–9"> 愿赐平安的上帝亲自使你们完全成圣。愿你们的灵、魂和身体全然蒙保守，在我们的主耶稣基督来临时无可指摘。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦后书 3:3; 民数记 23:19; 哥林多前书 1:9"> 那召你们的是信实的，祂也必成就这事。</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="希伯来书 13:18–19; 腓立比书 1:19; 腓利门书 1:22"> 弟兄们，请为我们祷告。</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="罗马书 16:16; 哥林多前书 16:20"> 你们要以圣洁的亲吻问候所有弟兄。</span>
<span className="v" id="v27" data-v="27" data-xref="歌罗西书 4:16; 使徒行传 19:13; 提摩太前书 1:3"> 我凭主郑重吩咐你们，务要把这封信读给所有圣徒弟兄听。</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="罗马书 16:20; 帖撒罗尼迦后书 3:18; 罗马书 16:23"> 愿我们的主耶稣基督的恩典与你们同在。阿们。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="西番雅书 3:8; 耶利米书 10:25; 启示录 15:1"> 我听见有大声音从圣殿里出来，对七位天使说：“你们去，把上帝烈怒的七碗倒在地上！”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="启示录 8:7; 启示录 16:11; 启示录 13:15–18"> 第一位天使去了，把他的碗倒在地上，那些有兽的印记、敬拜兽像的人身上就生出又恶又痛的疮。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="出埃及记 7:17–21; 启示录 8:8–9; 启示录 11:6"> 第二位天使把他的碗倒在海里，海就变成了血，好像死人的血，海中一切有生命的都死了。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="出埃及记 7:17–20; 启示录 8:10–11; 何西阿 13:15"> 第三位天使把他的碗倒在江河和水泉里，水就变成了血。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 1:8; 启示录 11:17; 启示录 1:4"> 我听见掌管众水的天使说：“昔在今在的圣者啊，你是公义的，因为你施行了这些审判。</span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 49:26; 启示录 11:18; 启示录 6:10–11"> 他们曾流圣徒和先知的血，你也给他们血喝；这是他们应得的。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="启示录 19:2; 启示录 6:9; 启示录 15:3–4"> 我听见祭坛说：“是的，主上帝，全能者啊，你的审判真实而公义。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="使徒行传 2:20; 启示录 14:18; 约拿 4:8"> 第四位天使把他的碗倒在太阳上，太阳就得到权柄，用火烤灼人。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 2:21; 启示录 16:21; 启示录 11:13"> 人被大热烤灼，就亵渎那掌管这些灾的上帝之名。他们却不悔改，不把荣耀归给祂。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="启示录 9:2; 马太福音 8:12; 以赛亚书 8:21–22"> 第五位天使把他的碗倒在兽的宝座上，兽的国就变黑暗了。人因疼痛咬自己的舌头，</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 16:9; 启示录 16:2; 启示录 16:21"> 又因他们的疼痛和疮，亵渎天上的上帝。他们仍不悔改自己的行为。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="启示录 9:14; 耶利米书 51:36; 以赛亚书 44:27"> 第六位天使把他的碗倒在大河幼发拉底河上，河水就干了，好为从日出之地来的众王预备道路。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作：东方">a</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="启示录 19:20; 帖撒罗尼迦后书 2:9–11; 启示录 20:10"> 我看见有三个污灵，像青蛙一样，从龙口、兽口和假先知的口中出来；</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 17:14; 提摩太前书 4:1; 启示录 20:8"> 它们本是鬼魔的灵，施行神迹，出去到全世界的众王那里，要把他们聚集起来，为上帝全能者那大日的战争作准备。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="帖撒罗尼迦前书 5:2–3; 马太福音 24:42–43; 彼得后书 3:10"> <span className="woj">“看哪，我来像贼一样。那警醒并保守自己衣服的人有福了，免得他赤身行走，让人看见他的羞耻。”</span></span>
<span className="v" id="v16" data-v="16" data-xref="撒迦利亚书 12:11; 士师记 5:19; 约珥 3:9–14"> 祂把他们聚集到一个地方，希伯来话叫“哈米吉多顿”。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 19:30; 启示录 21:6; 以弗所书 6:12"> 第七位天使把他的碗倒在空中。就有大声音从天上的圣殿里，从宝座那里出来，说：“成了！”</span>
<span className="v" id="v18" data-v="18" data-xref="但以理 12:1; 启示录 4:5; 启示录 11:19"> 随后有闪电、声音和雷声；又有大地震，自从地上有人以来，从没有发生过这样的地震，如此巨大，如此猛烈。</span>
<span className="v" id="v19" data-v="19" data-xref="启示录 18:5; 启示录 17:18; 启示录 18:21"> 那大城裂为三段，列国的城也都倒塌了。大巴比伦在上帝面前被记起，祂要把祂烈怒之酒的杯给她。</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 6:14; 启示录 20:11; 耶利米书 4:23–25"> 各海岛都逃走了，众山也不见了。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 11:19; 约书亚记 10:11; 启示录 16:9"> 又有大冰雹，每块约重一他连得，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="一他连得约为30公斤或66磅。">b</a></sup>从天上落在人身上。人因冰雹的灾亵渎上帝，因为这灾极其严重。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 22:16; 启示录 22:6; 加拉太书 1:12"> 这是耶稣基督的启示，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“基督”的意思是“受膏者”。">a</a></sup>就是上帝赐给祂，要祂将必须很快发生的事指示祂的众仆人；祂差遣祂的天使<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作“使者”（这里以及凡提到天使之处）。">b</a></sup>向祂的仆人约翰显明。</span>
<span className="v" id="v2" data-v="2" data-xref="哥林多前书 1:6; 约翰福音 19:35; 约翰一书 1:1"> 约翰见证了上帝的道和耶稣基督的见证，就是他所看见的一切。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="路加福音 11:28; 启示录 22:10; 罗马书 13:11"> 朗读这预言话语的人，和那些听见又遵守其中所记之事的人，都是有福的，因为时候近了。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 11:2; 约翰福音 1:1; 希伯来书 13:8"> 约翰写信给亚细亚的七个教会：愿恩典和平安从那今在、昔在、以后要来的上帝，从祂宝座前的七灵，临到你们；</span>
<span className="v" id="v5" data-v="5" data-xref="诗篇 89:27; 希伯来书 9:14; 约翰一书 1:7"> 也从耶稣基督，就是那忠信的见证者、从死人中首先复生的、地上众王的元首，临到你们。祂爱我们，用自己的血洗净我们脱离罪；</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 5:10; 启示录 20:6; 出埃及记 19:6"> 祂又使我们成为国度，作祂上帝和父的祭司。愿荣耀和权能归给祂，直到永永远远。阿们。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 24:30; 撒迦利亚书 12:10; 但以理 7:13"> 看哪，<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“看哪”出自“ἰδοὺ”，意思是看、留意、观察、观看或注视，常用作感叹词。">c</a></sup>祂正驾云而来，众目都要看见祂，连刺透祂的人也要看见祂。地上的万族都要因祂哀哭。是的，阿们。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 44:6; 启示录 22:13; 以赛亚书 43:10"> <span className="woj">“我是阿拉法和俄梅戛，</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="公认经文加上“始和终”。">d</a></sup><span className="woj">”</span>主上帝说，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="公认经文省略“上帝”。">e</a></sup><span className="woj">“是今在、昔在、以后要来的全能者。”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="使徒行传 14:22; 启示录 3:10; 约翰福音 16:33"> 我约翰，是你们的弟兄，又与你们一同在基督耶稣里的患难、国度和忍耐上有份；我因上帝的道和耶稣基督的见证，曾在那名叫拔摩的岛上。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 21:10; 哥林多后书 12:2–4; 启示录 4:1–2"> 在主日，我在圣灵里，听见在我后面有大声音，像号角一样，</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 3:1; 耶利米书 30:2; 哈巴谷 2:2"> 说：<sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="公认经文加上“我是阿拉法和俄梅戛，首先的和末后的。”">f</a></sup><span className="woj">“你所看见的，要写在书卷上，寄给七个教会：</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="公认经文加上“在亚细亚”。">g</a></sup><span className="woj">就是寄给以弗所、士每拿、别迦摩、推雅推喇、撒狄、非拉铁非和老底嘉。”</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="撒迦利亚书 4:2; 出埃及记 25:37; 启示录 1:20–1"> 我转过身，要看那与我说话的声音。转过身来，就看见七个金灯台。</span>
<span className="v" id="v13" data-v="13" data-xref="但以理 7:13; 但以理 10:5–6; 但以理 10:16"> 在灯台中间，有一位好像人子，身穿长袍，直垂到脚，又在胸间束着金带。</span>
<span className="v" id="v14" data-v="14" data-xref="但以理 10:6; 但以理 7:9; 启示录 19:12"> 祂的头和头发都洁白，如白羊毛，像雪一样；祂的眼睛像火焰；</span>
<span className="v" id="v15" data-v="15" data-xref="以西结 43:2; 但以理 10:6; 启示录 14:2"> 祂的脚像在炉中炼过的光亮的铜；祂的声音像众水的声音。</span>
<span className="v" id="v16" data-v="16" data-xref="希伯来书 4:12; 启示录 19:15; 启示录 2:12"> 祂右手拿着七颗星；从祂口中出来一把锋利的双刃剑；祂的脸像太阳在最强烈时发光。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 44:6; 启示录 22:13; 但以理 10:8–10"> 我一看见祂，就仆倒在祂脚前，像死了一样。<br />祂把右手按在我身上，说：<span className="woj">“不要怕。我是首先的，也是末后的，</span></span>
<span className="v" id="v18" data-v="18" data-xref="罗马书 6:9; 希伯来书 7:25; 罗马书 14:8–9"> <span className="woj">又是那活着的。我曾死过，看哪，我现在活着，直到永永远远。阿们。我拿着死亡和阴间的钥匙。</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="或作“地狱”。">h</a></sup></span>
<span className="v" id="v19" data-v="19" data-xref="启示录 4:1–11; 启示录 1:11–3"> <span className="woj">所以，你要把你所看见的事、现在的事和此后将要发生的事写下来。</span></span>
<span className="v" id="v20" data-v="20" data-xref="启示录 2:1; 启示录 3:1; 启示录 1:16"> <span className="woj">至于你所看见、在我右手中的七颗星，以及七个金灯台，其奥秘是这样：七颗星就是七个教会的天使；</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="或作“使者”（这里以及凡提到天使之处）。">i</a></sup><span className="woj">七个灯台就是七个教会。</span></span>
</div>
</div>

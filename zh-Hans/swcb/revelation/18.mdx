<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以西结 43:2; 路加福音 17:24; 帖撒罗尼迦后书 2:8"> 这些事以后，我看见另一位天使从天上下来，有大权柄；地就因他的荣耀发光。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 14:8; 耶利米书 51:8; 耶利米书 51:37"> 他用大声音喊着说：“倒塌了！倒塌了！大巴比伦倒塌了！她已经成了鬼魔的住处，各样污灵的监牢，各样污秽可憎之鸟的牢笼！</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 14:8; 启示录 17:2; 启示录 18:9"> 因为万国都喝了她淫乱之烈怒的酒；地上的君王与她行了淫乱；地上的商人因她奢华的丰盛而致富。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 52:11; 哥林多后书 6:17; 耶利米书 51:6"> 我又听见另一个声音从天上说：“我的子民哪，你们要从她那里出来，免得有份于她的罪，免得受她的灾殃；</span>
<span className="v" id="v5" data-v="5" data-xref="创世记 18:20–21; 以斯拉记 9:6; 启示录 16:19"> 因为她的罪已经堆到天上，上帝已经记起她的罪孽。</span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 50:29; 诗篇 137:8; 耶利米书 51:24"> 她怎样回报人，你们也要怎样回报她，并照她的行为加倍报应她。她调和的杯，要为她调双倍。</span>
<span className="v" id="v7" data-v="7" data-xref="以赛亚书 47:7–9; 西番雅书 2:15; 耶利米哀歌 1:1"> 她怎样荣耀自己、放纵奢华，你们也要照样使她受痛苦和悲哀。因为她心里说：‘我坐着作女王，并不是寡妇，绝不会见到悲哀。’</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 50:34; 耶利米书 50:31; 启示录 17:16"> 因此，她的灾殃要在一天之内来到，就是死亡、悲哀和饥荒；她也要被火烧尽，因为审判她的主上帝是大有能力的。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="启示录 19:3; 启示录 18:3; 启示录 17:2"> 地上的君王，就是那些与她行淫乱、同她放纵奢华的，看见她被焚烧的烟，就要为她哭泣哀号。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 18:19; 启示录 18:8; 启示录 18:15–17"> 他们因怕她所受的痛苦，就远远地站着，说：‘哀哉！哀哉！巴比伦大城，坚固的城啊！因为你的审判在一小时之内就临到了。’</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 18:3; 启示录 18:23; 以西结 27:27–36"> 地上的商人也为她哭泣悲哀，因为再没有人买他们的货物了：</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 17:4; 以西结 27:5–25; 箴言 8:10–11"> 就是金、银、宝石、珍珠、细麻布、紫色布、丝绸、朱红色布、各样贵重木材、各样象牙器皿、各样极贵重木材和铜、铁、大理石所造的器皿；</span>
<span className="v" id="v13" data-v="13" data-xref="以西结 27:13; 阿摩司 2:6; 彼得后书 2:3"> 还有肉桂、香料、香膏、乳香、酒、橄榄油、细面、麦子、牛、羊、马、车，以及人的身体和灵魂。</span>
<span className="v" id="v14" data-v="14" data-xref="哥林多前书 10:6; 诗篇 106:14; 路加福音 16:25"> 你灵魂所贪恋的果子已经离你而去；一切精美奢华的东西都从你那里消失了，你再也找不到它们。</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 18:3; 使徒行传 19:24–27; 以西结 27:31"> 贩卖这些货物、因她致富的商人，因怕她所受的痛苦，就远远地站着，哭泣悲哀，</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 17:4; 路加福音 16:19–31; 启示录 18:10–11"> 说：‘哀哉！哀哉！这大城啊！她曾披戴细麻布、紫色布和朱红色布，又用金子、宝石和珍珠装饰！</span>
<span className="v" id="v17" data-v="17" data-xref="以西结 27:27–36; 启示录 17:16; 以赛亚书 23:14"> 因为这样巨大的财富在一小时之内就荒废了。’各船主、所有航行各处的人、水手，以及凡靠海谋生的人，都远远地站着，</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 13:4; 以西结 27:30–32; 启示录 18:9–10"> 看见她被焚烧的烟，就喊着说：‘有什么能比这大城呢？’</span>
<span className="v" id="v19" data-v="19" data-xref="启示录 18:10; 约书亚记 7:6; 以西结 27:30"> 他们把尘土撒在头上，哭泣悲哀地喊着说：‘哀哉！哀哉！这大城啊！凡在海中有船的，都因她的巨大财富而致富！因为她在一小时之内就荒废了。’</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="启示录 6:10; 启示录 19:1–3; 路加福音 18:7–8"> “天哪，众圣徒、使徒和先知啊，你们要因她欢喜，因为上帝已经在她身上为你们施行了审判。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="耶利米书 51:63–64; 以西结 26:21; 启示录 5:2"> 有一位大力的天使举起一块石头，好像一块大磨石，扔进海里，说：“巴比伦这大城也要这样猛烈地被摔下去，再也找不到了。</span>
<span className="v" id="v22" data-v="22" data-xref="以西结 26:13; 耶利米书 25:10; 耶利米书 7:34"> 弹琴者、歌者、吹笛者和吹号者的声音，在你里面再也听不到了；任何手艺的工匠，在你里面再也找不到了；磨坊的声音，在你里面再也听不到了。</span>
<span className="v" id="v23" data-v="23" data-xref="启示录 18:3; 以赛亚书 23:8; 那鸿书 3:4"> 灯的光在你里面再也不发亮了；新郎和新娘的声音，在你里面再也听不到了。因为你的商人曾是地上的权贵；万国都被你的邪术迷惑了。</span>
<span className="v" id="v24" data-v="24" data-xref="启示录 17:6; 启示录 16:6; 耶利米书 51:49"> 在她里面发现了先知和圣徒的血，以及地上一切被杀之人的血。”</span>
</div>

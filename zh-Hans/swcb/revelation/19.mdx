<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 7:10–12; 历代志上 29:11; 启示录 11:15"> 这些事以后，我听见天上好像有一大群人的响亮声音，说：“哈利路亚！救恩、能力、荣耀都属于我们的上帝；</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 32:43; 启示录 6:10; 启示录 18:20"> 因为祂的审判是真实而公义的。祂已经审判了那用自己的淫乱败坏全地的大淫妇，并且为祂仆人的血向她伸冤。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 34:10; 启示录 18:18; 启示录 14:11"> 第二次又有声音说：“哈利路亚！她的烟往上升，直到永永远远。”</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 5:14; 尼希米记 8:6; 诗篇 106:48"> 那二十四位长老和四个活物都俯伏，敬拜坐在宝座上的上帝，说：“阿们！哈利路亚！”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="诗篇 134:1; 诗篇 148:11–13; 诗篇 150:6"> 有声音从宝座发出，说：“上帝所有的仆人哪，所有敬畏祂的人哪，无论大小，都要赞美我们的上帝！”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="诗篇 97:1; 启示录 14:2; 诗篇 93:1"> 我听见好像一大群人的声音，又像众水的声音，又像强烈雷鸣的声音，说：“哈利路亚！因为主我们的上帝，全能者，作王了！</span>
<span className="v" id="v7" data-v="7" data-xref="启示录 21:9; 启示录 21:2; 启示录 19:9"> 我们要欢喜快乐，把荣耀归给祂；因为羔羊的婚礼到了，祂的新妇也已经预备好了。”</span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 61:10; 启示录 7:13–14; 诗篇 132:9"> 她蒙准穿上明亮洁净的细麻衣；这细麻衣就是圣徒的义行。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="启示录 22:6; 马太福音 22:2–4; 路加福音 14:15–16"> 他对我说：“你要写：‘被邀请赴羔羊婚宴的人有福了。’”他又对我说：“这些是上帝真实的话。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="启示录 22:8–9; 使徒行传 10:25–26; 约翰福音 5:39"> 我就俯伏在他脚前要敬拜他。他对我说：“注意！不可这样！我和你，以及你那些持守耶稣见证的弟兄，同是奴仆。你要敬拜上帝，因为耶稣的见证就是预言之灵。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="诗篇 96:13; 以赛亚书 11:3–5; 诗篇 98:9"> 我看见天开了；看哪，有一匹白马，骑在马上的那位称为“信实真实”。祂按公义审判并争战。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 19:16; 路加福音 10:22; 启示录 2:17–18"> 祂的眼睛如火焰，头上戴着许多冠冕。祂有写下的众名，又有一个写下的名字，除了祂自己，没有人知道。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 1:1; 以赛亚书 63:1–6; 约翰福音 1:14"> 祂穿着一件溅了血的衣袍。祂的名被称为“上帝之道”。</span>
<span className="v" id="v14" data-v="14" data-xref="犹大书 1:14; 启示录 7:9; 启示录 19:8"> 天上的众军都穿着洁白的细麻衣，骑着白马跟随祂。</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 63:2–6; 启示录 1:16; 启示录 2:27"> 有一把锋利的两刃剑从祂口中出来，祂要用这剑击打列国。祂要用铁杖统治他们。祂踹全能上帝烈怒的酒榨。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 17:14; 提摩太前书 6:15; 但以理 2:47"> 在祂的衣袍和大腿上有名写着：“万王之王，万主之主。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="启示录 19:21; 启示录 8:13; 以西结 39:17–20"> 我看见一位天使站在日头中。他大声呼喊，对所有飞在天空中的鸟说：“来！聚集起来赴上帝的大筵席，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="公认经文读作“伟大上帝的筵席”，而不是“上帝的大筵席”。">a</a></sup></span>
<span className="v" id="v18" data-v="18" data-xref="以西结 39:18–20; 启示录 6:15; 撒母耳记上 17:44"> 好吃君王的肉、将领的肉、勇士的肉、马和骑马者的肉，以及所有人的肉，无论自主的、为奴的，大小都包括在内。”</span>
<span className="v" id="v19" data-v="19" data-xref="启示录 16:16; 启示录 16:14; 启示录 17:12–14"> 我看见那兽、地上的君王和他们的军队都聚集起来，要与骑在马上的那位并祂的军队争战。</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 20:10; 启示录 21:8; 帖撒罗尼迦后书 2:8–11"> 那兽被擒拿；那在兽面前行神迹、用这些神迹迷惑了那些受兽印记和敬拜兽像之人的假先知，也一同被擒拿。他们两个被活活扔进烧着硫磺的火湖里。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 19:11–15; 启示录 1:16; 启示录 19:17–19"> 其余的人都被骑在马上的那位口中出来的剑杀了，所有的鸟都吃饱了他们的肉。</span>
</div>

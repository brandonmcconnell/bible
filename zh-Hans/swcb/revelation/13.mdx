<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 12:3; 启示录 17:3; 但以理 7:23–25"> 随后我站在<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NU作它站在">a</a></sup>海边的沙上。我看见一个兽从海里上来，有十只角和七个头；角上戴着十个王冠，头上有亵渎的名号。</span>
<span className="v" id="v2" data-v="2" data-xref="但以理 7:4–7; 彼得前书 5:8; 启示录 17:12"> 我所看见的兽像豹，脚像熊的脚，口像狮子的口。龙把自己的能力、宝座和大权柄都给了它。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 17:8; 启示录 13:14; 启示录 17:17"> 它的一个头似乎受了致命伤；那致命的伤口却被医好了。全地的人都对那兽惊奇不已。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 13:2; 启示录 18:18; 启示录 13:15"> 他们拜那龙，因为它把权柄给了那兽；他们也拜那兽，说：“谁能与这兽相比？谁能与它交战？”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="但以理 7:8; 但以理 7:25; 但以理 11:36"> 有一张说夸大话和亵渎话的口赐给了它；又赐给它权柄，使它可以争战四十二个月。</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 12:34; 希伯来书 9:24; 启示录 12:12"> 它开口向上帝说亵渎的话，亵渎祂的名、祂的居所，以及那些住在天上的。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理 7:21; 启示录 11:7; 但以理 7:25"> 它获准与圣徒争战，并且胜过他们；又有权柄赐给它，制伏各支派、各民族、各语言和各邦国。</span>
<span className="v" id="v8" data-v="8" data-xref="彼得前书 1:19–20; 以弗所书 1:4; 马太福音 25:34"> 凡名字从世界的根基以来没有记在被杀羔羊生命册上的，所有住在地上的人都要拜它。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 2:7; 启示录 2:17; 启示录 2:11"> 有耳的，就应当听。</span>
<span className="v" id="v10" data-v="10" data-xref="耶利米书 15:2; 以赛亚书 33:1; 启示录 14:12"> 若有人注定被掳，他就要被掳；若有人注定被刀杀，他就必须被杀。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TR作：“若有人使人被掳，他就要被掳；若有人要用刀杀人，他就必须被刀杀。”而不是“若有人注定被掳，他就要被掳；若有人注定被刀杀，他就必须被杀。”">b</a></sup>圣徒的忍耐和信心就在这里。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="但以理 7:8; 哥林多后书 11:13–15; 马太福音 7:15"> 我又看见另一个兽从地里上来。它有两只角，像羊羔的角，说话却像龙。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 17:10–11; 启示录 14:11; 启示录 14:9"> 它在头一个兽面前，行使头一个兽的一切权柄；它使地和住在其中的人拜那头一个兽，就是那致命伤口被医好的兽。</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 24:24; 启示录 19:20; 帖撒罗尼迦后书 2:9–10"> 它行大奇事，甚至在人面前使火从天降到地上。</span>
<span className="v" id="v14" data-v="14" data-xref="启示录 12:9; 启示录 19:20; 启示录 13:8"> 它因获准在那兽面前所行的奇事，就迷惑我自己的<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="NU省略“我自己的”">c</a></sup>那些住在地上的人，吩咐住在地上的人要为那受过刀伤而又活了的兽造一个像。</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 20:4; 启示录 19:20; 但以理 3:3–6"> 它获准把气息赐给那兽的像，使兽像既能说话，又能叫所有不拜兽像的人都被杀。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 20:4; 启示录 19:20; 以西结 9:4"> 它又使所有人，无论大小、贫富、自主的、为奴的，都在右手上或额上受印记；</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 15:2; 启示录 13:16; 启示录 14:11"> 除非有那印记，就是兽的名或它名的数目，否则谁也不能买卖。</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 15:2; 启示录 17:9; 启示录 21:17"> 智慧就在这里。有悟性的人，应当计算那兽的数目，因为这是一个人的数目；它的数目是六百六十六。</span>
</div>

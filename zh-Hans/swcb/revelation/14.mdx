<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约珥 2:32; 启示录 3:12; 启示录 7:3–17"> 我又观看，看哪，羔羊站在锡安山上，同祂在一起的有十四万四千人，他们的额上写着祂的名和祂父的名。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 5:8; 以西结 43:2; 启示录 1:15"> 我听见有声音从天上传来，好像众水的声音，又好像大雷的声音。我所听见的声音，好像弹琴的人在弹他们的琴。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 5:9; 启示录 14:1; 启示录 15:3"> 他们在宝座前，并在四活物和众长老面前唱一首新歌；除了那十四万四千人，就是从地上被救赎出来的人以外，没有人能学会那歌。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 3:4; 哥林多后书 11:2; 雅各书 1:18"> 这些人没有因女人而玷污自己，因为他们是童身。这些人羔羊无论往哪里去，他们都跟随祂。这些人是从人间被耶稣救赎出来的，作为初熟的果子献给上帝和羔羊。</span>
<span className="v" id="v5" data-v="5" data-xref="以弗所书 5:27; 诗篇 32:2; 西番雅书 3:13"> 他们口中查不出谎言，因为他们是无可指摘的。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="公认经文加上“在上帝的宝座前”">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="马可福音 16:15; 启示录 8:13; 以弗所书 3:9–11"> 我又看见一位天使飞在中天，有永恒的福音要传给住在地上的人，就是给各邦国、各支派、各语言、各民族。</span>
<span className="v" id="v7" data-v="7" data-xref="出埃及记 20:11; 启示录 15:4; 尼希米记 9:6"> 他大声说：“要敬畏主，把荣耀归给祂，因为祂审判的时候已经到了。要敬拜那创造天、地、海和众水泉源的主！”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 21:9; 耶利米书 51:7–8; 启示录 18:2–3"> 又有另一位，就是第二位天使，接着说：“大巴比伦倾倒了！她使万国喝了她淫乱烈怒的酒。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="启示录 14:11; 启示录 14:6–8; 启示录 13:3–6"> 又有另一位，就是第三位天使，跟着他们，大声说：“若有人敬拜那兽和兽像，并在自己的额上或手上受了印记，</span>
<span className="v" id="v10" data-v="10" data-xref="以赛亚书 51:17; 启示录 16:19; 耶利米书 25:15–17"> 他也必喝上帝烈怒的酒，就是斟在祂愤怒的杯中、没有掺杂的酒。他必在圣天使面前和羔羊面前，在火与硫磺中受折磨。</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 19:3; 以赛亚书 34:10; 马太福音 25:41"> 他们受折磨的烟往上升，直到永永远远。那些敬拜兽和兽像的人，以及凡受它名之印记的人，昼夜不得安息。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="启示录 13:10; 启示录 12:17; 启示录 3:10"> 圣徒的忍耐就在这里；他们是遵守上帝诫命和对耶稣的信心的人。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="启示录 20:6; 提摩太后书 4:7–8; 帖撒罗尼迦前书 5:10"> 我听见有声音从天上说：“你要写下：‘从今以后，在主里死去的人有福了。’”<br />圣灵说：“是的，他们要从自己的劳苦中得安息，因为他们的行为随着他们。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="但以理 7:13; 以赛亚书 19:1; 马太福音 17:5"> 我又观看，看见一朵白云，云上坐着一位好像人子的，头上戴着金冠冕，手里拿着锋利的镰刀。</span>
<span className="v" id="v15" data-v="15" data-xref="约珥 3:13; 马太福音 13:39; 马可福音 4:29"> 又有一位天使从殿中出来，向那坐在云上的大声呼喊说：“伸出你的镰刀来收割吧，因为收割的时候已经到了；地上的庄稼已经熟透了！”</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 16:27; 启示录 14:19; 启示录 14:14"> 那坐在云上的就把他的镰刀挥向地上，地上的庄稼就被收割了。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="启示录 14:18; 启示录 14:14–15; 启示录 15:5–6"> 又有一位天使从天上的殿中出来，他也拿着锋利的镰刀。</span>
<span className="v" id="v18" data-v="18" data-xref="约珥 3:13; 启示录 16:8; 启示录 14:15–16"> 又有一位天使从祭坛那里出来，就是那有权柄管火的。他向那拿着锋利镰刀的天使大声呼喊说：“伸出你锋利的镰刀，收取地上葡萄树的果串吧，因为地上的葡萄已经完全熟了！”</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 32:32–33; 启示录 19:15–21"> 那天使就把他的镰刀挥向地上，收取了地上的葡萄，丢进上帝烈怒的大酒榨中。</span>
<span className="v" id="v20" data-v="20" data-xref="耶利米哀歌 1:15; 启示录 19:14–21; 以赛亚书 63:1–3"> 那酒榨在城外被践踏，血从酒榨中流出来，高到马的嚼环，远达一千六百斯塔迪亚。<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="1600斯塔迪亚＝296公里或184英里">b</a></sup></span>
</div>

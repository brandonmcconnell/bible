<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 65:17–19; 彼得后书 3:13; 以赛亚书 66:22"> 我又看见一个新天新地，因为先前的天和先前的地已经过去，海也不再有了。</span>
<span className="v" id="v2" data-v="2" data-xref="希伯来书 11:10; 启示录 3:12; 启示录 21:10"> 我看见圣城新耶路撒冷从天上由上帝那里降下，预备好了，就像新娘为丈夫妆饰整齐。</span>
<span className="v" id="v3" data-v="3" data-xref="以西结 37:27; 哥林多后书 6:16; 约翰福音 14:23"> 我听见有大声音从天上出来，说：“看哪，上帝的居所与人在一起；祂要与他们同住，他们要作祂的子民，上帝亲自要与他们同在，作他们的上帝。</span>
<span className="v" id="v4" data-v="4" data-xref="以赛亚书 25:8; 启示录 7:17; 哥林多前书 15:26"> 祂要擦去他们眼中的每一滴眼泪。死亡不再有了；哀恸、哭号、痛苦也不再有了。先前的事已经过去了。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="哥林多后书 5:17; 以赛亚书 42:9; 以赛亚书 43:19"> 坐在宝座上的那位说：<span className="woj">“看哪，我将一切都更新。”</span>他又说：<span className="woj">“你要写下来，因为这些上帝的话是可信且真实的。”</span></span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 7:37–38; 约翰福音 4:10; 启示录 7:17"> 祂又对我说：<span className="woj">“我是阿拉法和俄梅戛，是开始和终结。我要把生命水泉中的水白白赐给口渴的人。</span></span>
<span className="v" id="v7" data-v="7" data-xref="哥林多后书 6:18; 希伯来书 8:10; 启示录 2:11"> <span className="woj">得胜的，我要把这些赐给他。我要作他的上帝，他要作我的儿子。</span></span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 6:9–10; 启示录 2:11; 以弗所书 5:5–6"> <span className="woj">但至于胆怯的、不信的、罪人，</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR和NU省略“罪人”">a</a></sup><span className="woj">可憎的、杀人的、淫乱的、行邪术的，</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这里译为“行邪术的”的词也包括使用药剂和毒品的人。">b</a></sup><span className="woj">拜偶像的和所有说谎的人，他们的份就在烧着火与硫磺的湖里；这是第二次的死。”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="启示录 21:2; 启示录 19:7; 启示录 16:1–17"> 那拿着盛满最后七灾之七碗的七位天使中，有一位来对我说：“你到这里来，我要把新娘，就是羔羊的妻子，指给你看。”</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 21:2; 以西结 11:24; 以西结 40:1–49"> 他在圣灵里把我带到一座又大又高的山上，将那从天上由上帝那里降下的圣城耶路撒冷指给我看，</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 4:6; 启示录 22:5; 启示录 22:1"> 它有上帝的荣耀。它的光辉如同极贵重的宝石，好像碧玉，明如水晶；</span>
<span className="v" id="v12" data-v="12" data-xref="以西结 48:31–34; 启示录 7:4–8; 启示录 21:17–21"> 它有又大又高的城墙，有十二道门，门那里有十二位天使，门上写着名字，就是以色列子孙十二支派的名字。</span>
<span className="v" id="v13" data-v="13" data-xref="以西结 48:31–34"> 东边有三道门，北边有三道门，南边有三道门，西边有三道门。</span>
<span className="v" id="v14" data-v="14" data-xref="希伯来书 11:10; 以弗所书 2:20; 以赛亚书 54:11"> 城墙有十二根基，根基上有羔羊十二使徒的十二个名字。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 2:1; 启示录 11:1–2; 以西结 41:1–5"> 那与我说话的，拿着一根金芦苇作量尺，要量那城、城门和城墙。</span>
<span className="v" id="v16" data-v="16" data-xref="以西结 48:35; 以西结 48:8–20"> 那城是四方的，长宽一样。他用芦苇量那城，是一万二千零十二司他迪亚。<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="12,012司他迪亚 = 2,221公里或1,380英里。TR作12,000司他迪亚，而不是12,012司他迪亚。">c</a></sup>它的长、宽、高都相等。</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 7:4; 申命记 3:11; 启示录 13:18"> 他又量了城墙，是一百四十四肘，<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="144肘约为65.8米或216英尺。">d</a></sup>按人的量法，也就是天使的量法。</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 21:11; 启示录 21:21; 启示录 21:19"> 城墙的构造是碧玉；那城是纯金，如同纯净的玻璃。</span>
<span className="v" id="v19" data-v="19" data-xref="以赛亚书 54:11–12; 出埃及记 28:17–21; 约伯记 28:16–19"> 城墙的根基用各样宝石装饰：第一根基是碧玉，第二是蓝宝石，<sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="或作：青金石。">e</a></sup>第三是玉髓，第四是绿宝石，</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 4:3"> 第五是缠丝玛瑙，第六是红玉髓，第七是贵橄榄石，第八是绿柱石，第九是黄玉，第十是绿玉髓，第十一是风信子石，第十二是紫水晶。</span>
<span className="v" id="v21" data-v="21" data-xref="启示录 21:18; 启示录 17:4; 启示录 22:2"> 十二道门是十二颗珍珠；每一道门都是由一颗珍珠造成的。城中的街道是纯金，如同透明的玻璃。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约翰福音 4:23; 列王纪上 8:27; 历代志下 2:6"> 我没有看见城里有殿，因为主上帝全能者和羔羊就是它的殿。</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 60:19–20; 启示录 22:5; 启示录 21:11"> 那城不需要太阳或月亮照耀，因为上帝的荣耀亲自照亮它，它的灯就是羔羊。</span>
<span className="v" id="v24" data-v="24" data-xref="启示录 21:26; 启示录 22:2; 撒迦利亚书 8:22–23"> 列国要在它的光中行走。地上的君王要把列国的荣耀和尊贵带进那城。</span>
<span className="v" id="v25" data-v="25" data-xref="以赛亚书 60:11; 撒迦利亚书 14:7; 启示录 22:5"> 它的城门白昼绝不关闭（因为那里不会有黑夜），</span>
<span className="v" id="v26" data-v="26" data-xref="启示录 21:24"> 他们要把列国的荣耀和尊贵带进那城，好让他们可以进入。</span>
<span className="v" id="v27" data-v="27" data-xref="启示录 22:14–15; 以赛亚书 52:1; 启示录 20:15"> 凡污秽之物，或造成可憎之事或谎言的人，都绝不能进入那城；惟有写在羔羊生命册上的人才能进入。</span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 21:15; 以西结 42:15–20; 撒迦利亚书 2:1–2"> 有一根像杖的芦苇赐给我。有人说：“起来，量一量上帝的殿、祭坛，以及在殿中敬拜的人。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 12:6; 但以理 7:25; 路加福音 21:24"> 只是殿外的院子要留下，不要量，因为它已经给了列国。他们要践踏圣城四十二个月。</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 12:6; 启示录 11:2; 申命记 19:15"> 我要赐能力给我的两个见证人，他们要身穿麻衣，说预言一千二百六十天。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 4:11–14; 撒迦利亚书 4:2–3; 耶利米书 11:16"> 这二人就是那两棵橄榄树和两个灯台，站在全地之主面前。</span>
<span className="v" id="v5" data-v="5" data-xref="耶利米书 5:14; 列王纪下 1:10–12; 何西阿 6:5"> 如果有人想要伤害他们，就有火从他们口中出来，吞灭他们的仇敌。如果有人想要伤害他们，他必须这样被杀。</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 17:1; 路加福音 4:25; 诗篇 105:26–36"> 他们有权柄关闭天空，使天在他们说预言的日子不下雨；他们也有权柄掌管众水，把水变成血，并且随意用各样灾害击打大地。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="启示录 13:7; 但以理 8:23–24; 但以理 7:25"> 他们作完见证的时候，那从无底坑上来的兽要与他们争战，胜过他们，并且杀了他们。</span>
<span className="v" id="v8" data-v="8" data-xref="耶利米书 23:14; 启示录 18:10; 启示录 18:21"> 他们的尸体要倒在那大城的街上；这城按属灵意义叫所多玛和埃及，他们的主也在那里被钉十字架。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 79:2–3; 启示录 17:15; 启示录 10:11"> 从各民族、支派、语言、国家中，有人要观看他们的尸体三天半，并且不许把他们的尸体安放在坟墓里。</span>
<span className="v" id="v10" data-v="10" data-xref="列王纪上 18:17; 启示录 3:10; 使徒行传 5:33"> 住在地上的人要因他们而欢喜快乐，彼此赠送礼物，因为这两个先知曾使住在地上的人受折磨。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="创世记 2:7; 罗马书 8:11; 罗马书 8:2"> 三天半以后，从上帝那里来的生命之气进入他们里面，他们就站了起来；看见他们的人都大大惧怕。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 4:1; 列王纪下 2:11; 使徒行传 1:9"> 我听见有大声音从天上对他们说：“上到这里来！”他们就在云中升到天上，他们的仇敌也看见了。</span>
<span className="v" id="v13" data-v="13" data-xref="启示录 14:7; 启示录 6:12; 约书亚记 7:19"> 就在那时，发生了大地震，城的十分之一倒塌；因地震而死的有七千人，其余的人都恐惧，把荣耀归给天上的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="启示录 8:13; 启示录 9:12; 启示录 15:1"> 第二样灾祸过去了。看哪，第三样灾祸快要来了。</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理 7:14; 启示录 12:10; 但以理 7:27"> 第七位天使吹号，天上就有大声音说：“世界的国度成了我们主和祂基督的国度；祂要作王，直到永永远远！”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="启示录 4:4; 启示录 4:10; 启示录 7:11"> 在上帝宝座前坐在自己宝座上的二十四位长老，就俯伏在地，敬拜上帝，</span>
<span className="v" id="v17" data-v="17" data-xref="启示录 1:8; 启示录 16:5; 启示录 4:8–9"> 说：“主上帝，全能者啊，那今在、昔在的一位，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR 加上“以及将要来的”">a</a></sup>我们感谢你，因为你已经执掌你的大能，作王了。</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 19:5; 启示录 20:12; 启示录 6:10–11"> 列国发怒，你的愤怒也临到了；审判死人的时候到了，也到了赐奖赏给你的奴仆众先知、众圣徒，以及敬畏你名的人，无论大小的时候；又到了毁灭那些毁灭大地之人的时候。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="启示录 16:21; 启示录 15:5–8; 以西结 38:22"> 上帝在天上的殿开了，在祂殿中可以看见主的约柜。随后有闪电、声音、雷轰、地震和大冰雹。</span>
</div>
</div>

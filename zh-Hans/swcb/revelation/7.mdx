<span className="v" id="v2" data-v="2" data-xref="以弗所书 4:30; 哥林多后书 1:22; 启示录 7:3–8"> 我又看见另一位天使从日出之地上来，拿着永活上帝的印。他向那四位得到权柄要伤害地和海的天使大声呼喊，</span>
<span className="v" id="v3" data-v="3" data-xref="以西结 9:4; 启示录 22:4; 启示录 9:4"> 说：“不要伤害地、海和树，等我们在我们上帝的奴仆额上盖了印！”</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 14:1; 启示录 14:3; 马太福音 19:28"> 我听见受印者的数目：十四万四千，是从以色列子孙各支派中受印的：</span>
<span className="v" id="v5" data-v="5" data-xref="出埃及记 1:2–4; 民数记 10:14–27; 民数记 13:4–16"> <span className="pl pl-1">犹大支派中受印的一万二千，</span><br /><span className="pl pl-1">流便支派中一万二千，</span><br /><span className="pl pl-1">迦得支派中一万二千，</span><br /></span>

<span className="v" id="v7" data-v="7" data-xref="创世记 35:23; 民数记 26:14; 民数记 25:14"> <span className="pl pl-1">西缅支派中一万二千，</span><br /><span className="pl pl-1">利未支派中一万二千，</span><br /><span className="pl pl-1">以萨迦支派中一万二千，</span><br /></span>

<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="启示录 5:9; 约翰福音 12:13; 诗篇 117:1–2"> 这些事以后，我观看，看哪，有一大群人，没有人能数得过来，是从各国、各支派、各民族、各种语言来的，站在宝座和羔羊面前，身穿白袍，手拿棕树枝。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 19:1; 诗篇 3:8; 以赛亚书 45:21"> 他们大声呼喊说：“救恩归于坐在宝座上的我们的上帝，也归于羔羊！”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="启示录 5:11–13; 启示录 19:4–6; 启示录 4:10"> 众天使都站在宝座、众长老和四个活物的周围；他们就在宝座前面伏于地，敬拜上帝，</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 5:12–14; 犹大书 1:25; 诗篇 100:4"> 说：“阿们！愿颂赞、荣耀、智慧、感谢、尊贵、能力和力量，都归于我们的上帝，直到永永远远！阿们。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="启示录 7:9; 启示录 4:10; 启示录 5:5"> 长老中有一位回应，对我说：“这些身穿白袍的人是谁？他们是从哪里来的？”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="约翰一书 1:7; 启示录 22:14; 希伯来书 13:12"> 我对他说：“我主，你知道。”<br />他对我说：“这些人是从大苦难中出来的。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或译：压迫">a</a></sup>他们曾在羔羊的血里洗净自己的袍子，使袍子洁白。</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 21:3–4; 启示录 22:3; 哥林多后书 6:16"> 因此，他们在上帝的宝座前，昼夜在祂的殿中事奉祂。那坐在宝座上的，要在他们上面支搭祂的帐幕。</span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 49:10; 诗篇 121:6; 马太福音 5:6"> 他们不再饥饿，也不再干渴；太阳不再灼晒他们，任何炎热也不再伤害他们；</span>
<span className="v" id="v17" data-v="17" data-xref="约翰福音 7:37–38; 诗篇 36:8–9; 约翰福音 4:14"> 因为在宝座中间的羔羊要牧养他们，领他们到生命水的泉源。上帝也要擦去他们眼中的每一滴眼泪。”</span>
</div>

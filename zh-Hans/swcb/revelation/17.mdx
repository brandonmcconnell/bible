<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="启示录 19:2; 启示录 17:1–17; 耶利米书 51:13"> 拿着七碗的七位天使中，有一位来对我说：“你到这里来，我要把坐在众水之上的大淫妇所受的审判指给你看。</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 14:8; 耶利米书 51:7; 启示录 18:3"> 地上的君王曾与她行淫；住在地上的人也因她淫乱的酒而醉了。”</span>
<span className="v" id="v3" data-v="3" data-xref="启示录 12:3; 启示录 13:1–6; 启示录 12:6"> 天使在圣灵里把我带到旷野去。我看见一个女人骑在一只朱红色的兽上；那兽满了亵渎的名号，有七个头和十只角。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 18:16; 耶利米书 51:7; 启示录 19:2"> 那女人穿着紫色和朱红色的衣服，用金子、宝石和珍珠装饰，手里拿着一个金杯，杯中盛满了地上淫乱的可憎之物和污秽。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 14:8; 启示录 18:2; 启示录 17:7"> 她额上写着一个名号：“奥秘，大巴比伦，众淫妇和地上可憎之物的母。”</span>
<span className="v" id="v6" data-v="6" data-xref="启示录 16:6; 启示录 13:15; 启示录 2:13"> 我看见那女人喝醉了圣徒的血和耶稣殉道者的血。我看见她，就大大惊奇。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="启示录 17:1–6; 启示录 17:8"> 天使对我说：“你为什么惊奇？我要把这女人的奥秘，以及那驮着她、有七个头和十只角的兽的奥秘告诉你。</span>
<span className="v" id="v8" data-v="8" data-xref="启示录 17:11; 启示录 11:7; 启示录 3:10"> 你所看见的兽，曾经在，现在不在；将要从无底坑上来，又要归于毁灭。住在地上的人，就是名字从创世以来没有写在生命册上的人，看见那兽曾经在、现在不在、将要出现，必感到惊奇。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR作“仍在”，而不是“将要出现”。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="启示录 13:18; 启示录 17:7; 马太福音 13:11"> 这里需要有智慧的心思。七个头就是女人所坐的七座山。</span>
<span className="v" id="v10" data-v="10"> 它们也是七位王。五位已经倒下了，一位还在，另一位还没有来到；他来的时候，必须存留片刻。</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 17:8"> 那曾经在、现在不在的兽，自己也是第八位，并且属于那七位；他要走向毁灭。</span>
<span className="v" id="v12" data-v="12" data-xref="启示录 12:3; 启示录 13:1; 但以理 7:24"> 你所看见的十只角，就是十位王；他们还没有得国，但他们要与兽一同领受权柄作王一个小时。</span>
<span className="v" id="v13" data-v="13" data-xref="启示录 17:17; 以西结 38:10; 以赛亚书 10:5–7"> 这些王同心合意，把自己的能力和权柄交给那兽。</span>
<span className="v" id="v14" data-v="14" data-xref="罗马书 8:30; 提摩太前书 6:15; 马太福音 22:14"> 他们要与羔羊争战，羔羊必胜过他们，因为祂是万主之主、万王之王；与祂同在的人是蒙召、被拣选、忠信的。”</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 17:1; 耶利米书 51:13; 耶利米书 51:55"> 天使又对我说：“你所看见的众水，就是淫妇所坐之处，是各民族、群众、列国和各语言的人。</span>
<span className="v" id="v16" data-v="16" data-xref="启示录 18:8; 以西结 16:37–44; 利未记 21:9"> 你所看见的十只角和那兽，必恨这淫妇，使她荒凉，把她剥光，吃她的肉，并用火把她完全烧尽。</span>
<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦后书 2:10–12; 箴言 21:1; 启示录 10:7"> 因为上帝把祂心中所定的放在他们心里，使他们同心合意，把自己的国交给那兽，直到上帝的话都成就。</span>
<span className="v" id="v18" data-v="18" data-xref="启示录 16:19; 启示录 18:2; 但以理 7:23"> 你所看见的女人，就是那统治地上众王的大城。”</span>
</div>

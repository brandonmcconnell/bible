<span className="v" id="v2" data-v="2" data-xref="启示录 22:1; 彼得前书 2:24; 启示录 2:7"> 在城的街道中央。河这边和那边有生命树，结十二种果子，每月都结果子。树上的叶子是为医治列国。</span>
<span className="v" id="v3" data-v="3" data-xref="马太福音 25:21; 启示录 21:3–4; 约翰福音 12:26"> 再也没有咒诅。上帝和羔羊的宝座必在城里，祂的仆人要侍奉祂。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 5:8; 启示录 14:1; 启示录 3:12"> 他们要见祂的面，祂的名必在他们的额上。</span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 60:19–20; 但以理 7:18; 启示录 20:4"> 不再有黑夜；他们也不需要灯光或日光，因为主上帝要照亮他们。他们要作王，直到永永远远。</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="启示录 1:1; 启示录 21:5; 启示录 19:9"> 他对我说：“这些话是可信的，是真实的。主，就是众先知之灵的上帝，差遣祂的天使，把必须快要发生的事指示祂的奴仆。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="启示录 1:3; 启示录 3:11; 启示录 22:20"> <span className="woj">“看哪，我快要来了！遵守这书上预言之话的人有福了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="启示录 19:10; 启示录 1:1; 启示录 19:19"> 我约翰就是听见、看见这些事的人。我听见、看见以后，就俯伏在那把这些事指给我看的天使脚前，要敬拜他。</span>
<span className="v" id="v9" data-v="9" data-xref="启示录 19:10; 歌罗西书 2:18–19; 启示录 14:7"> 他对我说：“千万不可！我与你和你的弟兄众先知，以及那些遵守这书上话语的人，都是同作奴仆的。你要敬拜上帝。”</span>
<span className="v" id="v10" data-v="10" data-xref="但以理 8:26; 启示录 1:3; 彼得前书 4:7"> 他又对我说：“不可封住这书上预言的话，因为时候近了。</span>
<span className="v" id="v11" data-v="11" data-xref="但以理 12:10; 箴言 4:18; 以西结 3:27"> 行不义的，让他仍旧行不义；污秽的，让他仍旧污秽；为义的，让他仍旧行义；圣洁的，让他仍旧圣洁。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 16:27; 以赛亚书 62:11; 以赛亚书 40:10"> <span className="woj">“看哪，我快要来了！我的赏赐在我这里，要照各人的行为报应各人。</span></span>
<span className="v" id="v13" data-v="13" data-xref="启示录 1:8; 启示录 21:6; 以赛亚书 44:6"> <span className="woj">我是阿拉法，我是俄梅戛；我是首先的，我是末后的；我是开始，我是终结。</span></span>
<span className="v" id="v14" data-v="14" data-xref="启示录 21:27; 约翰一书 5:3; 启示录 22:7"> <span className="woj">遵行祂命令的人有福了，</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NU 作“洗净自己衣袍的人”，而不是“遵行祂命令的人”。">b</a></sup><span className="woj">好使他们有权到生命树那里，也可以从城门进城。</span></span>
<span className="v" id="v15" data-v="15" data-xref="启示录 21:8; 加拉太书 5:19–21; 腓立比书 3:2"> <span className="woj">城外有犬类、行邪术的、淫乱的、杀人的、拜偶像的，以及一切喜爱并行虚谎的人。</span></span>
<span className="v" id="v16" data-v="16" data-xref="启示录 5:5; 彼得后书 1:19; 以赛亚书 11:1"> <span className="woj">我耶稣差遣我的天使，为众教会向你们见证这些事。我是大卫的根，又是他的后裔；我是明亮的晨星。”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 4:14; 启示录 21:6; 以赛亚书 55:1–3"> 圣灵和新妇都说：“来！”听见的人也该说：“来！”口渴的人可以来；愿意的人都可以白白取生命的水。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命记 12:32; 申命记 4:2; 箴言 30:6"> 我向一切听见这书上预言之话的人作见证：若有人在这些话上加添什么，上帝必把写在这书上的灾祸加在他身上。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 4:2; 路加福音 11:52; 启示录 22:2"> 若有人从这预言书的话中删去什么，上帝必从写在这书上的生命树<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="TR 作“生命册”，而不是“生命树”。">c</a></sup>和圣城中删去他的份。</span>
<span className="v" id="v20" data-v="20" data-xref="启示录 22:7; 希伯来书 9:28; 启示录 22:12"> 为这些事作见证的说：<span className="woj">“是的，我快要来了。”</span><br />阿们！是的，主耶稣啊，请来！</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="帖撒罗尼迦后书 3:18; 罗马书 16:20; 哥林多后书 13:14"> 愿主耶稣基督的恩典与众圣徒同在。阿们。</span>

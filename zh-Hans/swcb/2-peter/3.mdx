<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提摩太后书 1:6; 彼得后书 1:12–15; 彼得前书 1:22"> 亲爱的，如今这是我写给你们的第二封信；在这两封信里，我都是借着提醒来激发你们诚挚的心，</span>
<span className="v" id="v2" data-v="2" data-xref="犹大书 1:17; 彼得后书 2:21; 路加福音 1:70"> 使你们记得圣先知们从前所说的话，以及我们这些主和救主的使徒所传的命令。</span>
<span className="v" id="v3" data-v="3" data-xref="犹大书 1:18; 提摩太前书 4:1–2; 彼得后书 2:10"> 第一要知道，在末后的日子必有嘲讽的人来到，随从自己的私欲而行，</span>
<span className="v" id="v4" data-v="4" data-xref="耶利米书 17:15; 玛拉基书 2:17; 耶利米书 5:12–13"> 说：“祂来临的应许在哪里呢？因为从祖先睡了以来，万物仍照创造之初的样子继续存在。”</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 11:3; 创世记 1:9; 诗篇 24:2"> 他们故意忘记：从古以来，诸天就存在，地也借着上帝的话从水中出来，并在水之间形成；</span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 24:38–39; 彼得后书 2:5; 路加福音 17:27"> 借着这些，当时的世界被水淹没，就灭亡了。</span>
<span className="v" id="v7" data-v="7" data-xref="彼得后书 3:10; 以赛亚书 51:6; 彼得后书 3:12"> 但现在的诸天和地，凭着同一个话语被积存起来，留给火，保留到审判和不敬虔之人灭亡的日子。</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="诗篇 90:4; 罗马书 11:25; 哥林多前书 12:1"> 亲爱的，有一件事你们不可忘记：在主看来，一日如千年，千年如一日。</span>
<span className="v" id="v9" data-v="9" data-xref="提摩太前书 2:4; 罗马书 2:4; 哈巴谷 2:3"> 主对于祂的应许并不迟延，不像有些人认为的迟延；祂乃是对我们忍耐，不愿任何人灭亡，而愿人人都来悔改。</span>
<span className="v" id="v10" data-v="10" data-xref="启示录 21:1; 马太福音 24:35; 彼得后书 3:7"> 但主的日子要像夜间的贼一样来到。在那日，诸天要轰然消逝，众元素要被烈热熔化；地和其中的工程都要被烧尽。</span>
<span className="v" id="v11" data-v="11" data-xref="彼得前书 1:15; 腓立比书 1:27; 彼得前书 2:12"> 既然这一切都要这样被毁灭，你们该成为怎样的人，有圣洁的生活和敬虔，</span>
<span className="v" id="v12" data-v="12" data-xref="彼得后书 3:10; 以赛亚书 34:4; 弥迦书 1:4"> 等候并热切盼望上帝之日的来临！那日将使燃烧的诸天被销化，众元素也要因烈热熔化。</span>
<span className="v" id="v13" data-v="13" data-xref="以赛亚书 65:17; 启示录 21:1; 以赛亚书 66:22"> 但我们照着祂的应许，等候新天新地，有公义住在其中。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="帖撒罗尼迦前书 5:23; 帖撒罗尼迦前书 3:13; 腓立比书 1:10"> 所以，亲爱的，你们既然等候这些事，就要殷勤，使你们被祂发现时是在平安中，没有瑕疵，无可指摘。</span>
<span className="v" id="v15" data-v="15" data-xref="罗马书 2:4; 彼得后书 3:9; 提摩太前书 1:16"> 你们要把我们主的忍耐看作救恩；正如我们亲爱的弟兄保罗，也照着赐给他的智慧写信给你们，</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 15:6; 希伯来书 5:11; 雅各书 1:8"> 他在所有书信中也都是这样，谈到这些事。其中有些事难以明白，那些无知又不坚定的人加以曲解，正如他们曲解其他圣经一样，以致自取灭亡。</span>
<span className="v" id="v17" data-v="17" data-xref="希伯来书 3:14; 歌罗西书 2:8; 哥林多后书 11:13–15"> 所以，亲爱的，你们既然预先知道这些事，就要谨慎，免得被恶人的错谬带走，从自己坚定的立场上坠落。</span>
<span className="v" id="v18" data-v="18" data-xref="歌罗西书 1:10; 以弗所书 4:15; 彼得前书 2:2"> 你们却要在我们主和救主耶稣基督的恩典和知识上长进。愿荣耀归给祂，从现在直到永远。阿们。</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 7:15; 犹大书 1:4; 申命记 13:1–3"> 从前在百姓中也有假先知起来，照样，在你们中间也会有假教师。他们会暗中引进毁灭性的异端，甚至否认那买了他们的主宰，给自己招来迅速的毁灭。</span>
<span className="v" id="v2" data-v="2" data-xref="罗马书 2:24; 犹大书 1:10; 彼得前书 2:12"> 许多人会随从他们放荡<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="公认文本读作“毁灭性的”，而非“放荡”。">a</a></sup>的行径；结果，真理的道路就会被毁谤。</span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 2:17; 申命记 32:35; 罗马书 16:18"> 他们因贪婪，要用虚假的话利用你们。他们自古以来的判决并不迟延，他们的毁灭也不打盹。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="犹大书 1:6; 马太福音 25:41; 罗马书 8:32"> 因为上帝若没有宽容犯罪的天使，反而把他们投入塔耳塔罗斯，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="塔耳塔罗斯是地狱的另一个名称。">b</a></sup>交在幽暗的坑中，留到审判；</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 11:7; 彼得后书 3:6; 犹大书 1:14–15"> 又没有宽容古代的世界，却在祂使洪水临到不敬虔之人的世界时，保护了传扬公义的挪亚和另外七个人；</span>
<span className="v" id="v6" data-v="6" data-xref="犹大书 1:7; 路加福音 17:28–30; 申命记 29:23"> 又使所多玛和蛾摩拉二城化为灰烬，定了它们毁灭的刑罚，作为后来要过不敬虔生活之人的鉴戒；</span>
<span className="v" id="v7" data-v="7" data-xref="创世记 19:16; 创世记 19:29; 创世记 19:7–8"> 又搭救了义人罗得；他因恶人放荡的生活而极其痛苦</span>
<span className="v" id="v8" data-v="8" data-xref="诗篇 119:158; 以西结 9:4; 诗篇 119:136"> （因为那义人住在他们中间，天天因看见、听见他们不法的行为，使自己公义的灵魂受折磨）；</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 34:15–19; 哥林多前书 10:13; 启示录 3:10"> 那么，主知道怎样搭救敬虔的人脱离试探，也知道怎样把不义的人留在刑罚之下，等候审判的日子；</span>
<span className="v" id="v10" data-v="10" data-xref="犹大书 1:16; 犹大书 1:10; 犹大书 1:18"> 尤其是那些随从肉体、怀着污秽的私欲而行，并轻视权威的人。他们胆大任性，不怕毁谤尊荣者；</span>
<span className="v" id="v11" data-v="11" data-xref="犹大书 1:9; 帖撒罗尼迦后书 1:7; 诗篇 104:4"> 然而天使虽然在力量和能力上更大，尚且不在主面前用毁谤的判词控告他们。</span>
<span className="v" id="v12" data-v="12" data-xref="犹大书 1:10; 耶利米书 12:3; 加拉太书 6:8"> 但这些人像没有理性的牲畜，生来就是凭本性的动物，为被捕捉和毁灭；他们在自己所不明白的事上毁谤，必在自己的毁灭中被毁灭，</span>
<span className="v" id="v13" data-v="13" data-xref="罗马书 13:13; 罗马书 2:8–9; 希伯来书 2:2–3"> 领受不义的工价。他们以白昼宴乐为乐，是污点和瑕疵；他们与你们同席宴饮时，在自己的诡诈中寻欢作乐；</span>
<span className="v" id="v14" data-v="14" data-xref="彼得后书 2:3; 彼得后书 2:18; 以弗所书 2:3"> 眼中充满淫乱，不能停止犯罪；他们引诱不坚定的灵魂，有一颗在贪婪上训练有素的心，是被咒诅的儿女！</span>
<span className="v" id="v15" data-v="15" data-xref="启示录 2:14; 犹大书 1:11; 申命记 23:4–5"> 他们离弃正路，走入歧途，随从了比珥的儿子巴兰的道路；巴兰贪爱恶行的工价，</span>
<span className="v" id="v16" data-v="16" data-xref="民数记 22:21–33; 传道书 7:25; 路加福音 16:11"> 却因自己的悖逆受了责备。一头不能说话的驴用人的声音说话，阻止了那先知的疯狂。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="犹大书 1:12–13; 以弗所书 4:14; 耶利米书 14:3"> 这些人是无水的井，是被暴风驱赶的云；墨黑的幽暗已经为他们永远存留。</span>
<span className="v" id="v18" data-v="18" data-xref="彼得后书 2:20; 犹大书 1:15–16; 罗马书 13:13"> 他们说空洞夸大的话，用肉体的私欲和放荡，引诱那些确实正在脱离活在错谬中之人的人；</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 8:34; 罗马书 6:16–22; 加拉太书 5:13"> 应许给他们自由，自己却是败坏的奴仆；因为人被谁胜过，就被谁奴役。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="希伯来书 10:26–27; 希伯来书 6:4–8; 腓立比书 3:19"> 他们若借着认识主和救主耶稣基督，已经逃脱世上的污秽，却又被其中缠住、胜过，他们后来的景况就比先前更坏了。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结 18:24; 希伯来书 6:4–6; 雅各书 4:17"> 他们认识公义的道路以后，又背离那传给他们的圣洁命令，倒不如从来没有认识这道路还好。</span>
<span className="v" id="v22" data-v="22" data-xref="箴言 26:11"> 这句真实的箴言应验在他们身上：“狗又回到自己的呕吐物那里”；又说：“洗净了的母猪又回到泥里打滚。”</span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="提多书 2:13; 罗马书 3:21–26; 提多书 1:4"> 西门·彼得，耶稣基督的仆人和使徒，<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“基督”的意思是“受膏者”。">a</a></sup>写给那些因我们的上帝和救主耶稣基督的义，与我们同得一样宝贵信心的人：</span>
<span className="v" id="v2" data-v="2" data-xref="彼得后书 3:18; 约翰福音 17:3; 腓立比书 3:8"> 愿恩典和平安，因你们认识上帝和我们的主耶稣，而多多加给你们。</span>
<span className="v" id="v3" data-v="3" data-xref="彼得前书 5:10; 提摩太后书 1:9; 罗马书 8:28–30"> 祂神圣的能力，借着我们认识那位以自己的荣耀和美德呼召我们的主，已经把一切关乎生命和敬虔的事赐给了我们；</span>
<span className="v" id="v4" data-v="4" data-xref="以弗所书 4:23–24; 以西结 36:25–27; 哥林多后书 3:18"> 借着这些，祂已经把宝贵而极大的应许赐给了我们，使你们借着这些应许，在逃脱了世上因私欲而来的败坏之后，可以有份于神圣的性情。</span>
<span className="v" id="v5" data-v="5" data-xref="腓立比书 4:8; 箴言 4:23; 彼得后书 3:18"> 正因如此，你们也要分外殷勤：在你们的信心上加上美德；在美德上加上知识；</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 10:36; 罗马书 5:3–4; 路加福音 21:19"> 在知识上加上节制；在节制上加上坚忍；在坚忍上加上敬虔；</span>
<span className="v" id="v7" data-v="7" data-xref="希伯来书 13:1; 罗马书 12:10; 帖撒罗尼迦前书 3:12"> 在敬虔上加上弟兄之爱；在弟兄之爱上加上爱。</span>
<span className="v" id="v8" data-v="8" data-xref="提多书 3:14; 约翰福音 15:2; 希伯来书 6:12"> 因为这些若存在你们里面，并且不断增多，就会使你们在认识我们的主耶稣基督上，不至于闲懒，也不至于不结果子。</span>
<span className="v" id="v9" data-v="9" data-xref="彼得后书 2:18–20; 以弗所书 5:26; 提多书 2:14"> 但缺少这些的人是瞎眼的，只看见近处，已经忘了自己从旧日的罪中得了洁净。</span>
<span className="v" id="v10" data-v="10" data-xref="彼得后书 3:17; 路加福音 6:47–49; 希伯来书 6:11"> 所以，弟兄们，<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="这里译作“弟兄”的词，在上下文允许的地方，也可正确译为“弟兄姐妹”或“手足”。">b</a></sup>要更加殷勤，使你们所蒙的呼召和拣选确定无疑。因为你们若行这些事，就绝不会跌倒。</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 5:10; 马太福音 25:34; 启示录 3:21"> 这样，你们就必丰丰富富地得以进入我们主和救主耶稣基督永恒的国度。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约翰一书 2:21; 罗马书 15:14–15; 腓立比书 3:1"> 因此，虽然你们知道这些事，并且在现有的真理上已经坚固，我仍不会疏忽，必常常提醒你们。</span>
<span className="v" id="v13" data-v="13" data-xref="彼得后书 3:1; 彼得后书 1:14; 希伯来书 13:3"> 我认为，只要我还在这帐棚里，就应当借着提醒来激发你们；</span>
<span className="v" id="v14" data-v="14" data-xref="提摩太后书 4:6; 约翰福音 21:18–19; 申命记 31:14"> 因为我知道，我脱去这帐棚的时候快到了，正如我们的主耶稣基督向我显明的。</span>
<span className="v" id="v15" data-v="15" data-xref="申命记 31:19–29; 诗篇 71:18; 约书亚记 24:24–29"> 我也要竭力，使你们在我离世以后，仍能随时记念这些事。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="约翰一书 4:14; 约翰福音 1:14; 提摩太前书 1:4"> 我们把我们主耶稣基督的大能和来临告诉你们，并不是随从巧妙编造的神话，而是亲眼见过祂的威荣。</span>
<span className="v" id="v17" data-v="17" data-xref="马可福音 9:7; 马太福音 17:5; 马太福音 3:17"> 因为祂从父上帝领受尊贵和荣耀的时候，有声音从至大的荣耀中传给祂说：“这是我的爱子，是我所喜悦的。”</span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 17:6; 约书亚记 5:15; 出埃及记 3:5"> 我们同祂在圣山上的时候，亲耳听见这声音从天上发出。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="启示录 22:16; 以赛亚书 9:2; 诗篇 119:105"> 我们还有更确实的预言话语；你们留意这话是好的，好像留意照在暗处的灯，直到天破晓，晨星在你们心里升起。</span>
<span className="v" id="v20" data-v="20" data-xref="彼得后书 3:3; 罗马书 12:6; 罗马书 6:6"> 首先要知道：经上的预言没有一样是出于人自己的解释。</span>
<span className="v" id="v21" data-v="21" data-xref="提摩太后书 3:15–17; 彼得前书 1:11; 撒母耳记下 23:2"> 因为预言从来没有出于人的意志，而是上帝的圣洁之人在圣灵感动下说出来的。</span>
</div>
</div>

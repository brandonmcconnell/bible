<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 3:22; 马太福音 23:2; 路加福音 5:21"> 那时，有法利赛人和文士从耶路撒冷来到耶稣那里，说：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 11:38; 马可福音 7:2; 歌罗西书 2:20–23"> “你的门徒为什么违背古人的传统？因为他们吃饭的时候不洗手。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v3" data-v="3" data-xref="歌罗西书 2:23; 提多书 1:14; 歌罗西书 2:8"> 耶稣回答他们说：<span className="woj">“你们为什么也因你们的传统而违背上帝的诫命呢？</span></span>
<span className="v" id="v4" data-v="4" data-xref="出埃及记 20:12; 利未记 20:9; 出埃及记 21:17"> <span className="woj">因为上帝吩咐说：‘当孝敬父母，’</span><span className="woj">又说：‘咒骂父亲或母亲的，必须处死。’</span></span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 7:10–13; 使徒行传 5:29; 马太福音 23:16–18"> <span className="woj">你们却说：‘无论谁对父亲或母亲说：“你本来可以从我得着的供养，已经作了献给上帝的礼物，”</span></span>
<span className="v" id="v6" data-v="6" data-xref="提摩太前书 5:8; 耶利米书 8:8; 马可福音 7:13"> <span className="woj">他就可以不孝敬父母。’你们因自己的传统，使上帝的诫命失效了。</span></span>
<span className="v" id="v7" data-v="7" data-xref="马可福音 7:6; 马太福音 23:23–29; 使徒行传 28:25–27"> <span className="woj">假冒为善的人哪！以赛亚指着你们所说的预言真好，他说：</span></span>
<span className="v" id="v8" data-v="8" data-xref="以赛亚书 29:13; 以西结 33:31; 使徒行传 8:21"> <span className="pl pl-1 woj">‘这百姓用口亲近我，</span><br /><span className="pl pl-2 woj">用嘴唇尊敬我；</span><br /><span className="pl pl-2 woj">心却远离我。</span></span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 29:13; 马可福音 7:7; 提摩太前书 1:4"> <span className="pl pl-1 woj">他们敬拜我也是枉然，</span><br /><span className="pl pl-2 woj">因为他们把人的规条当作教义教导人。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马可福音 7:14–15; 路加福音 20:45–47; 路加福音 24:45"> 耶稣叫众人来，对他们说：<span className="woj">“你们要听，也要明白。</span></span>
<span className="v" id="v11" data-v="11" data-xref="马可福音 7:15; 马太福音 15:18–20; 雅各书 3:5–8"> <span className="woj">入口的不能污秽人；出口的，才污秽人。”</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="列王纪上 22:13–14; 哥林多前书 10:32–33; 加拉太书 2:5"> 门徒进前来对祂说：“你知道法利赛人听了这话就跌倒了吗？”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约翰福音 15:2; 以赛亚书 60:21; 约翰福音 15:6"> 耶稣回答说：<span className="woj">“凡不是我天父栽种的植物，都要连根拔起。</span></span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 6:39; 以赛亚书 56:10; 马太福音 23:16–24"> <span className="woj">任凭他们吧。他们是瞎眼人的瞎眼向导；若是瞎子领瞎子，两个人都要掉进坑里。”</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="马太福音 13:36; 马可福音 4:34; 约翰福音 16:29"> 彼得回答祂说：“请给我们解释这个比喻。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马太福音 16:9; 马可福音 7:18; 马可福音 9:32"> 耶稣说：<span className="woj">“你们到如今还不明白吗？</span></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 6:45; 哥林多前书 6:13; 马太福音 7:19–20"> <span className="woj">难道不明白，凡入口的进到肚腹，又排出体外吗？</span></span>
<span className="v" id="v18" data-v="18" data-xref="箴言 15:28; 马太福音 12:34; 雅各书 3:6–10"> <span className="woj">惟独出口的，是从心里发出来的，这才污秽人。</span></span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 7:21–23; 加拉太书 5:19–21; 耶利米书 17:9"> <span className="woj">因为从心里发出恶念、凶杀、奸淫、淫乱、偷盗、假见证和亵渎。</span></span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 7:3–4; 以弗所书 5:3–6; 哥林多前书 6:18–20"> <span className="woj">这些才是污秽人的；至于不洗手吃饭，并不污秽人。”</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马可福音 7:24–30; 马太福音 11:21–23; 士师记 1:31"> 耶稣离开那里，退到推罗、西顿一带地方。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 9:27; 马可福音 7:25–26; 马太福音 17:15"> 看哪，有一个迦南妇人从那境内出来，喊着说：“主啊，大卫的子孙，怜悯我吧！我的女儿被鬼附得很苦！”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 14:15; 马可福音 10:47–48; 耶利米哀歌 3:8"> 耶稣却一句话也不回答她。<br />门徒进前来求祂说：“请打发她走吧，因为她在我们后面一直喊叫。”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="马太福音 10:5–6; 罗马书 15:8; 耶利米书 50:6–7"> 耶稣回答说：<span className="woj">“我奉差遣，只是到以色列家迷失的羊那里去。”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="创世记 32:26; 马太福音 20:31; 马太福音 14:33"> 那妇人却来拜祂，说：“主啊，帮助我！”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="马可福音 7:27–28; 马太福音 7:6; 腓立比书 3:2"> 耶稣回答说：<span className="woj">“拿儿女的饼丢给狗，是不合宜的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="以弗所书 3:8; 路加福音 16:21; 约伯记 40:4–5"> 她说：“主啊，是的；可是狗也吃主人桌上掉下来的碎渣。”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马可福音 9:23–24; 马太福音 8:13; 诗篇 145:19"> 耶稣回答她说：<span className="woj">“妇人，你的信心很大！照你所愿的，给你成就了。”</span>从那时起，她的女儿就好了。</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马太福音 4:18; 约翰福音 6:1; 马太福音 5:1"> 耶稣离开那里，来到加利利海边，就上山坐在那里。</span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 6:17–19; 使徒行传 5:15–16; 马太福音 14:35–36"> 有大群人来到祂那里，带着瘸腿的、瞎眼的、哑巴、残疾的，以及许多别的病人，把他们放在祂脚前；祂就医好了他们。</span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 9:8; 路加福音 18:43; 路加福音 17:15–18"> 众人看见哑巴说话，残疾的痊愈，瘸腿的行走，瞎眼的看见，就惊奇不已，归荣耀给以色列的上帝。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="使徒行传 27:33; 路加福音 12:29–30; 马太福音 9:36"> 耶稣叫门徒来，说：<span className="woj">“我怜悯这群人，因为他们同我在这里已经三天，没有什么吃的。我不愿意叫他们饿着回去，恐怕他们在路上昏倒。”</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马可福音 6:37; 马太福音 14:15; 马可福音 8:4–5"> 门徒对祂说：“在这荒僻的地方，我们从哪里得这么多饼，使这么一大群人吃饱呢？”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马太福音 16:9–10; 路加福音 24:41–42; 约翰福音 21:9–10"> 耶稣对他们说：<span className="woj">“你们有多少饼？”</span><br />他们说：“七个，还有几条小鱼。”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="路加福音 9:14–16; 马可福音 6:39–40; 约翰福音 6:10"> 祂吩咐众人坐在地上；</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 22:19; 罗马书 14:6; 约翰福音 6:11"> 就拿着这七个饼和鱼，祝谢了，擘开，递给门徒；门徒又递给众人。</span>
<span className="v" id="v37" data-v="37" data-xref="马可福音 8:19–21; 马太福音 16:9–10; 马太福音 15:33"> 众人都吃，并且吃饱了；他们把剩下的碎块收拾起来，装满了七个篮子。</span>
<span className="v" id="v38" data-v="38"> 吃的人，除了妇女和孩子，有四千男人。</span>
<span className="v" id="v39" data-v="39" data-xref="马可福音 8:10; 马太福音 14:22"> 于是耶稣遣散众人，上了船，来到马加丹境内。</span>
</div>

<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 7:28; 马太福音 19:1"> 耶稣说完这一切话，就对门徒说：</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 22:1–2; 马可福音 14:1–2; 约翰福音 13:1–2"> <span className="woj">“你们知道，过两天就是逾越节，人子将要被交出去，钉在十字架上。”</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="约翰福音 11:47–53; 约翰福音 18:24; 马可福音 14:54"> 那时，祭司长、文士和百姓的长老聚集在大祭司该亚法的院子里。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 12:14; 诗篇 2:2; 使徒行传 13:10"> 他们一同商议，要用诡计拿住耶稣，把祂杀了。</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 27:24; 马太福音 21:26; 马太福音 14:5"> 只是他们说：“不可在节期动手，免得百姓中间发生骚乱。”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="马可福音 14:3–9; 路加福音 7:37–39; 约翰福音 12:1–8"> 耶稣在伯大尼长麻风的西门家里，</span>
<span className="v" id="v7" data-v="7" data-xref="约翰福音 12:2–3; 路加福音 7:46; 路加福音 7:37–38"> 有一个女人带着一玉瓶极贵重的香膏来到祂那里；耶稣坐席的时候，她把香膏浇在祂头上。</span>
<span className="v" id="v8" data-v="8" data-xref="约翰福音 12:4–6; 马可福音 14:4; 出埃及记 5:17"> 门徒看见了，就恼怒，说：“为什么这样浪费？</span>
<span className="v" id="v9" data-v="9" data-xref="约翰福音 12:5–6; 马可福音 14:5; 约书亚记 7:20–21"> 这香膏本可以卖许多钱，周济穷人。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="提多书 3:8; 希伯来书 13:21; 提摩太前书 5:10"> 耶稣知道了，就对他们说：<span className="woj">“为什么难为这女人呢？她在我身上做的是一件美事。</span></span>
<span className="v" id="v11" data-v="11" data-xref="申命记 15:11; 马可福音 14:7; 约翰福音 12:8"> <span className="woj">因为你们常有穷人和你们同在，只是你们不常有我。</span></span>
<span className="v" id="v12" data-v="12" data-xref="马可福音 14:8; 约翰福音 12:7; 马可福音 16:1"> <span className="woj">她把这香膏浇在我身上，是为我的安葬预先做的。</span></span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 14:9; 马太福音 24:14; 诗篇 112:6"> <span className="woj">我实在告诉你们，普天下无论在哪里传这福音，也要述说这女人所做的，作为对她的记念。”</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 22:3–6; 马太福音 10:4; 马可福音 14:10–11"> 那时，十二使徒中有一个，名叫加略人犹大，去见祭司长，</span>
<span className="v" id="v15" data-v="15" data-xref="撒迦利亚书 11:12–13; 创世记 37:26–28; 出埃及记 21:32"> 说：“我若把祂交给你们，你们愿意给我什么？”他们就给他称了三十块银钱。</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 14:11; 路加福音 22:6"> 从那时起，犹大就寻找机会要出卖耶稣。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="路加福音 22:7–13; 马可福音 14:12–16; 出埃及记 12:18–20"> 除酵节的第一天，门徒来到耶稣面前，对祂说：“你要我们在哪里为你预备逾越节的筵席？”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马可福音 14:13–16; 约翰福音 7:6; 约翰福音 17:1"> 祂说：<span className="woj">“你们进城，到某人那里去，对他说：‘老师说：我的时候近了；我要在你家里同我的门徒守逾越节。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="约翰福音 2:5; 约翰福音 15:14; 马太福音 21:6"> 门徒就照耶稣所吩咐的去做，预备了逾越节的筵席。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马可福音 14:17–21; 约翰福音 13:21; 路加福音 22:14–16"> 到了晚上，耶稣和十二个门徒一同坐席。</span>
<span className="v" id="v21" data-v="21" data-xref="约翰福音 13:21; 希伯来书 4:13; 约翰福音 6:70–71"> 他们正吃的时候，祂说：<span className="woj">“我实在告诉你们，你们中间有一个人要出卖我。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="约翰福音 13:22–25; 路加福音 22:23; 马可福音 14:19–20"> 他们就十分忧愁，一个一个问祂：“主啊，难道是我吗？”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="约翰福音 13:18; 诗篇 41:9; 约翰福音 13:26–28"> 祂回答说：<span className="woj">“同我蘸手在盘子里的，就是要出卖我的人。</span></span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 26:22–23; 路加福音 24:46; 马太福音 18:7"> <span className="woj">人子固然要照经上指着祂所写的去，但出卖人子的那人有祸了！那人若没有出生，倒还好。”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马太福音 26:64; 马太福音 27:11; 路加福音 22:70"> 出卖祂的犹大也问：“拉比，难道是我吗？”<br />耶稣对他说：<span className="woj">“你说的是。”</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="哥林多前书 11:23–29; 路加福音 22:18–20; 哥林多前书 10:16–17"> 他们正吃的时候，耶稣拿起饼来，祝谢了<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR 作“祝福了”，而非“祝谢了”。">a</a></sup>，擘开，递给门徒，说：<span className="woj">“你们拿着吃；这是我的身体。”</span></span>
<span className="v" id="v27" data-v="27" data-xref="以赛亚书 25:6; 哥林多前书 10:16; 诗篇 116:13"> 祂又拿起杯来，祝谢了，递给他们，说：<span className="woj">“你们都喝这个，</span></span>
<span className="v" id="v28" data-v="28" data-xref="希伯来书 10:4–14; 希伯来书 9:14–22; 利未记 17:11"> <span className="woj">因为这是我立新约的血，为许多人流出来，使罪得赦免。</span></span>
<span className="v" id="v29" data-v="29" data-xref="希伯来书 12:2; 启示录 7:17; 马可福音 14:25"> <span className="woj">但我告诉你们，从今以后，我绝不再喝这葡萄汁，直到我在我父的国里同你们喝新的那日。”</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="马太福音 21:1; 以弗所书 5:19–20; 路加福音 22:39"> 他们唱了诗，就出去往橄榄山去。</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="撒迦利亚书 13:7; 马可福音 14:27–28; 约翰福音 16:32"> 那时，耶稣对他们说：<span className="woj">“今夜，你们都要因我跌倒，因为经上记着：‘我要击打牧人，羊群的羊就分散了。’</span></span>
<span className="v" id="v32" data-v="32" data-xref="马太福音 28:10; 路加福音 18:33–34; 马太福音 28:16"> <span className="woj">但我复活以后，要在你们以前往加利利去。”</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 22:33; 约翰福音 13:36–38; 箴言 28:25–26"> 彼得回答祂说：“即使众人都因你跌倒，我也绝不跌倒。”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="约翰福音 13:38; 路加福音 22:34; 马太福音 26:75"> 耶稣对他说：<span className="woj">“我实在告诉你，今夜鸡叫以前，你要三次不认我。”</span></span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="罗马书 11:20; 约翰福音 13:37; 箴言 29:23"> 彼得对祂说：“我就是必须和你同死，也绝不不认你。”所有门徒也都这样说。</span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="马可福音 14:32–42; 马太福音 26:42; 路加福音 22:39–46"> 那时，耶稣同他们来到一个地方，名叫客西马尼，就对门徒说：<span className="woj">“你们坐在这里，等我到那边去祷告。”</span></span>
<span className="v" id="v37" data-v="37" data-xref="马太福音 4:21; 马太福音 17:1; 马可福音 5:37"> 祂带着彼得和西庇太的两个儿子同去，就忧愁起来，极其难过。</span>
<span className="v" id="v38" data-v="38" data-xref="约翰福音 12:27; 彼得前书 3:18; 彼得前书 2:24"> 于是耶稣对他们说：<span className="woj">“我的灵魂极其忧伤，几乎要死；你们留在这里，同我警醒。”</span></span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="约翰福音 6:38; 腓立比书 2:8; 路加福音 22:41–42"> 祂稍往前走，脸伏于地祷告，说：<span className="woj">“我父啊，若是可能，求你叫这杯离开我；然而，不要照我的意思，只要照你的意思。”</span></span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="马可福音 14:37; 路加福音 22:45; 马太福音 26:43"> 祂来到门徒那里，见他们睡着了，就对彼得说：<span className="woj">“怎么，你们不能同我警醒一小时吗？</span></span>
<span className="v" id="v41" data-v="41" data-xref="马可福音 14:38; 路加福音 22:46; 以弗所书 6:18"> <span className="woj">要警醒祷告，免得陷入试探。灵固然愿意，肉体却软弱。”</span></span>
</div>
<div className="bp">
<span className="v" id="v42" data-v="42" data-xref="马太福音 26:39; 马可福音 14:39–40; 希伯来书 4:15"> 祂第二次又离开去祷告，说：<span className="woj">“我父啊，这杯若不能离开我，除非我喝它，愿你的意思成就。”</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="路加福音 9:32; 罗马书 13:1; 箴言 23:34"> 祂又回来，见他们睡着了，因为他们眼睛沉重。</span>
<span className="v" id="v44" data-v="44" data-xref="哥林多后书 12:8; 路加福音 18:1; 马太福音 6:7"> 祂又离开他们，再去第三次祷告，说的还是同样的话。</span>
<span className="v" id="v45" data-v="45" data-xref="约翰福音 13:1; 约翰福音 12:27; 马可福音 14:41–42"> 然后祂来到门徒那里，对他们说：<span className="woj">“现在你们还在睡觉安歇吗？看哪，时候近了，人子要被交在罪人手里。</span></span>
<span className="v" id="v46" data-v="46" data-xref="路加福音 9:51; 约翰福音 14:31; 撒母耳记上 17:48"> <span className="woj">起来，我们走吧。看哪，出卖我的人近了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v47" data-v="47" data-xref="使徒行传 1:16; 马太福音 26:55; 马可福音 14:43–50"> 祂还在说话的时候，看哪，十二使徒中的一个犹大来了；有一大群人带着刀棒，跟他一同来，是从祭司长和百姓的长老那里来的。</span>
<span className="v" id="v48" data-v="48" data-xref="诗篇 55:20–21; 诗篇 28:3; 撒母耳记下 3:27"> 出卖耶稣的人已经给了他们一个暗号，说：“我亲吻谁，谁就是那人；你们拿住祂。”</span>
<span className="v" id="v49" data-v="49" data-xref="马太福音 26:25; 帖撒罗尼迦前书 5:26; 箴言 27:6"> 犹大立刻来到耶稣面前，说：“拉比，你好！”就亲吻祂。</span>
</div>
<div className="bp">
<span className="v" id="v50" data-v="50" data-xref="马太福音 20:13; 马太福音 22:12; 诗篇 41:9"> 耶稣对他说：<span className="woj">“朋友，你来这里是为了什么？”</span><br />于是那些人上前，下手拿住耶稣，逮捕了祂。</span>
<span className="v" id="v51" data-v="51" data-xref="约翰福音 18:36; 马可福音 14:47; 哥林多后书 10:4"> 看哪，同耶稣在一起的一个人伸手拔出刀来，砍了大祭司的仆人，削掉了他的耳朵。</span>
</div>
<div className="bp">
<span className="v" id="v52" data-v="52" data-xref="启示录 13:10; 创世记 9:6; 罗马书 12:19"> 耶稣对他说：<span className="woj">“把你的刀收回原处；凡动刀的，必死在刀下。</span></span>
<span className="v" id="v53" data-v="53" data-xref="列王纪下 6:17; 马太福音 4:11; 但以理 7:10"> <span className="woj">难道你以为我不能求我父，祂现在就会为我差遣十二营以上的天使吗？</span></span>
<span className="v" id="v54" data-v="54" data-xref="撒迦利亚书 13:7; 马太福音 26:24; 使徒行传 1:16"> <span className="woj">若是这样，经上所说事情必须如此成就，又怎能应验呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v55" data-v="55" data-xref="马可福音 12:35; 约翰福音 8:2; 路加福音 22:52–53"> 正在那时候，耶稣对众人说：<span className="woj">“你们带着刀棒出来拿我，如同拿强盗吗？我天天坐在圣殿里教导人，你们并没有拿我。</span></span>
<span className="v" id="v56" data-v="56" data-xref="撒迦利亚书 13:7; 约翰福音 16:32; 马可福音 14:50–52"> <span className="woj">但这一切事发生，是要应验先知书上的话。”</span><br />于是门徒都离开祂逃走了。</span>
</div>
<div className="bp">
<span className="v" id="v57" data-v="57" data-xref="马太福音 26:3; 马可福音 14:53–65; 诗篇 56:5–6"> 拿住耶稣的人，把祂带到大祭司该亚法那里；文士和长老已经聚集在那里。</span>
<span className="v" id="v58" data-v="58" data-xref="约翰福音 7:32; 约翰福音 18:15–16; 约翰福音 18:25"> 彼得远远地跟着祂，直到大祭司的院子，进去和差役坐在一起，要看事情的结局。</span>
</div>
<div className="bp">
<span className="v" id="v59" data-v="59" data-xref="使徒行传 6:11–13; 申命记 19:16–21; 马可福音 14:55–56"> 祭司长、长老和全议会寻找假见证控告耶稣，要把祂处死，</span>
<span className="v" id="v60" data-v="60" data-xref="申命记 19:15; 诗篇 35:11; 诗篇 27:12"> 却找不到。虽然有许多假见证人前来，还是找不到。最后有两个假见证人前来，</span>
<span className="v" id="v61" data-v="61" data-xref="约翰福音 2:19–21; 马太福音 27:40; 马可福音 15:29"> 说：“这个人曾说：‘我能拆毁上帝的圣殿，三天内又建造起来。’”</span>
</div>
<div className="bp">
<span className="v" id="v62" data-v="62" data-xref="约翰福音 19:9–11; 约翰福音 18:19–24; 马可福音 14:60"> 大祭司站起来，对祂说：“你什么都不回答吗？这些人作见证控告你的是什么呢？”</span>
<span className="v" id="v63" data-v="63" data-xref="利未记 5:1; 马太福音 16:16; 以赛亚书 53:7"> 耶稣却保持沉默。大祭司对祂说：“我指着永生上帝叫你起誓，要你告诉我们：你是不是基督，上帝的儿子？”</span>
</div>
<div className="bp">
<span className="v" id="v64" data-v="64" data-xref="但以理 7:13; 马可福音 14:62; 诗篇 110:1"> 耶稣对他说：<span className="woj">“你说的是。然而我告诉你们，从今以后，你们要看见人子坐在那位权能者的右边，驾着天上的云降临。”</span></span>
</div>
<div className="bp">

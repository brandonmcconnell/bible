</div>
<div className="bp">

</div>
<div className="bp">

<span className="v" id="v16" data-v="16" data-xref="彼得前书 2:12; 提多书 2:7; 约翰福音 15:8"> <span className="woj">你们的光也要这样照在人前，使他们看见你们的好行为，就荣耀你们在天上的父。</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="罗马书 10:4; 路加福音 16:17; 加拉太书 4:4–5"> <span className="woj">“不要以为我来是要废掉律法或先知；我来不是要废掉，而是要成全。</span></span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 16:17; 以赛亚书 40:8; 彼得前书 1:25"> <span className="woj">我实在告诉你们，直到天地废去，律法的一点</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="直译为 iota，即最小的希腊字母。">b</a></sup><span className="woj">一画</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作“字钩”。">c</a></sup><span className="woj">也绝不会废去，直到一切都成就。</span></span>

<span className="v" id="v20" data-v="20" data-xref="罗马书 10:2–3; 腓立比书 3:9; 罗马书 9:30–32"> <span className="woj">我告诉你们，你们的义若不胜过文士和法利赛人的义，绝不能进天国。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="申命记 5:17; 出埃及记 20:13; 民数记 35:30–34"> <span className="woj">“你们听见有话对古人说：‘不可杀人；’</span><span className="woj">又说：‘凡杀人的，难免受审判。’</span></span>
<span className="v" id="v22" data-v="22" data-xref="约翰一书 3:14–15; 约翰一书 4:20–21; 约翰一书 2:9"> <span className="woj">但我告诉你们，凡无缘无故向弟兄发怒的，</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="NU 省略“无缘无故”。">d</a></sup><span className="woj">难免受审判；凡对弟兄说‘拉加！’的，</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="“拉加”是亚兰语辱骂词，与“空”有关，含有“空脑袋”的意思。">e</a></sup><span className="woj">难免受议会审判；凡说‘愚蠢人！’的，难免被丢进地狱的火里。</span><sup className="fn"><a href="#fn-f" id="fnref-f" data-fn="或作“欣嫩谷”。">f</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马可福音 11:25; 利未记 6:2–6; 马太福音 5:24"> <span className="woj">“所以，你在祭坛前献礼物的时候，若在那里想起你的弟兄向你怀怨，</span></span>

<span className="v" id="v25" data-v="25" data-xref="路加福音 12:58–59; 箴言 25:8; 希伯来书 3:13"> <span className="woj">你同对头还在路上的时候，要赶快与他和解；免得对头把你交给审判官，审判官交给差役，你就被下在监里。</span></span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 18:34; 路加福音 12:59; 帖撒罗尼迦后书 1:9"> <span className="woj">我实在告诉你，你绝不能从那里出来，直到还清最后一文钱。</span><sup className="fn"><a href="#fn-g" id="fnref-g" data-fn="直译为 kodrantes，是小铜币，约值两个 lepta（寡妇的小钱），买不了多少东西。">g</a></sup></span>

<span className="v" id="v27" data-v="27" data-xref="申命记 5:18; 箴言 6:32; 出埃及记 20:14"> <span className="woj">“你们听见有话说：</span><sup className="fn"><a href="#fn-h" id="fnref-h" data-fn="TR 加有“对古人”。">h</a></sup><span className="woj">‘不可奸淫；’</span></span>

<span className="v" id="v29" data-v="29" data-xref="罗马书 8:13; 马可福音 9:43–48; 歌罗西书 3:5"> <span className="woj">若你的右眼使你跌倒，就把它剜出来丢掉；因为失去身体的一部分，强过全身被丢进地狱。</span><sup className="fn"><a href="#fn-i" id="fnref-i" data-fn="或作“欣嫩谷”。">i</a></sup></span>

</div>

<span className="v" id="v34" data-v="34" data-xref="雅各书 5:12; 以赛亚书 66:1; 申命记 23:21–23"> <span className="woj">但我告诉你们，什么誓都不可起：不可指着天起誓，因为天是上帝的宝座；</span></span>
<span className="v" id="v35" data-v="35" data-xref="诗篇 48:2; 玛拉基书 1:14; 历代志下 6:6"> <span className="woj">也不可指着地起誓，因为地是祂脚的踏凳；也不可指着耶路撒冷起誓，因为那是大君王的城。</span></span>

</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="利未记 24:19–20; 申命记 19:21; 出埃及记 21:22–27"> <span className="woj">“你们听见有话说：‘以眼还眼，以牙还牙。’</span></span>

<span className="v" id="v40" data-v="40" data-xref="路加福音 6:29; 哥林多前书 6:7"> <span className="woj">有人想告你，要拿你的里衣，就连外衣也让给他。</span></span>
<span className="v" id="v41" data-v="41" data-xref="路加福音 23:26; 马太福音 27:32; 马可福音 15:21"> <span className="woj">有人强逼你走一里路，你就同他走二里。</span></span>
<span className="v" id="v42" data-v="42" data-xref="箴言 19:17; 希伯来书 13:16; 路加福音 6:30–36"> <span className="woj">向你求的，就给他；想向你借贷的，不可转身拒绝。</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="利未记 19:18; 诗篇 139:21–22; 加拉太书 5:13–14"> <span className="woj">“你们听见有话说：‘要爱你的邻舍，</span><span className="woj">恨你的仇敌。’</span><sup className="fn"><a href="#fn-k" id="fnref-k" data-fn="这句话不在圣经中，但可参昆兰《会规》9:21-26。">k</a></sup></span>

<span className="v" id="v45" data-v="45" data-xref="诗篇 145:9; 路加福音 6:35; 使徒行传 14:17"> <span className="woj">好叫你们成为你们天父的儿女；因为祂叫太阳照恶人，也照好人；降雨给义人，也给不义的人。</span></span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="撒迦利亚书 14:4; 马可福音 11:1–10; 路加福音 21:37"> 他们将近耶路撒冷，来到橄榄山附近的伯法其<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR 和 NU 作“伯法其”，而非“伯法士基”。">a</a></sup>，耶稣就差遣两个门徒，</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 19:30–32; 马可福音 11:2–3; 约翰福音 2:5–8"> 对他们说：<span className="woj">“你们往对面的村子去，一进去，就会看见一匹驴拴在那里，还有一匹驴驹同在一处。把它们解开，牵到我这里来。</span></span>
<span className="v" id="v3" data-v="3" data-xref="哥林多后书 8:1–2; 使徒行传 17:25; 哥林多后书 8:9"> <span className="woj">若有人对你们说什么，你们就说：‘主需要它们。’那人立刻就会送来。”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v4" data-v="4" data-xref="撒迦利亚书 9:9; 约翰福音 12:15; 马太福音 1:22"> 这一切事发生，是要应验先知所说的话：</span>
<span className="v" id="v5" data-v="5" data-xref="撒迦利亚书 9:9–10; 以赛亚书 62:11; 以赛亚书 12:6"> <span className="pl pl-1">“要告诉锡安的女子：</span><br /><span className="pl pl-2">看哪，你的王来到你这里，</span><br /><span className="pl pl-2">祂谦和，骑着驴，</span><br /><span className="pl pl-2">骑着驴驹，就是驴的崽子。”</span></span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="出埃及记 39:43; 约翰福音 15:14; 出埃及记 40:16"> 门徒就去，照耶稣所吩咐的做了，</span>
<span className="v" id="v7" data-v="7" data-xref="列王纪下 9:13; 马可福音 11:4–8; 路加福音 19:32–35"> 牵来了驴和驴驹，把自己的衣服搭在它们身上；耶稣就骑坐在上面。</span>
<span className="v" id="v8" data-v="8" data-xref="列王纪下 9:13; 约翰福音 12:13; 利未记 23:40"> 有极多的人把自己的衣服铺在路上；也有人从树上砍下枝子，铺在路上。</span>
<span className="v" id="v9" data-v="9" data-xref="诗篇 118:24–26; 路加福音 2:14; 约翰福音 12:13–15"> 前行后随的众人不断呼喊说：“和散那<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="“和散那”的意思是“求你拯救”或“求你帮助”。">b</a></sup>归于大卫的子孙！奉主名来的，是有福的！至高之处的和散那！”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="使徒行传 9:5; 路得记 1:19; 约翰福音 12:16–19"> 耶稣进了耶路撒冷，全城都震动起来，说：“这是谁？”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="约翰福音 6:14; 路加福音 7:16; 约翰福音 7:40"> 众人说：“这是加利利拿撒勒来的先知耶稣。”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="约翰福音 2:14–17; 路加福音 19:45–47; 马可福音 11:15–18"> 耶稣进了上帝的圣殿，把圣殿里一切做买卖的人都赶出去，推翻兑换银钱之人的桌子和卖鸽子之人的凳子，</span>
<span className="v" id="v13" data-v="13" data-xref="耶利米书 7:11; 以赛亚书 56:7; 路加福音 19:46"> 对他们说：<span className="woj">“经上记着：‘我的殿必称为祷告的殿，’</span><span className="woj">你们倒使它成为强盗的巢穴！”</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="使徒行传 3:1–9; 使徒行传 10:38; 马太福音 11:4–5"> 瘸腿的和瞎眼的来到圣殿里祂那里，祂就医好了他们。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 21:9; 路加福音 19:39–40; 以赛亚书 26:11"> 祭司长和文士看见祂所行的奇事，又看见孩子们在圣殿里呼喊说：“和散那归于大卫的子孙！”就恼怒，</span>
<span className="v" id="v16" data-v="16" data-xref="诗篇 8:2; 马太福音 11:25; 路加福音 19:39–40"> 对祂说：“这些人所说的，你听见了吗？”<br />耶稣对他们说：<span className="woj">“是的。经上说：‘你从孩童和吃奶婴孩的口中，成全了赞美。’这话你们从来没有读过吗？”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 11:18; 马可福音 11:11; 路加福音 24:50"> 于是祂离开他们，出城到伯大尼去，在那里住宿。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="马太福音 4:2; 希伯来书 4:15; 马太福音 12:1"> 早晨，耶稣回城的时候饿了。</span>
<span className="v" id="v19" data-v="19" data-xref="约翰福音 15:6; 马可福音 11:14; 提多书 1:16"> 祂看见路旁有一棵无花果树，就走到树前，在树上找不到什么，只有叶子。祂对树说：<span className="woj">“从今以后，你永远不再结果子！”</span><br />那无花果树立刻枯干了。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 40:6–8; 马可福音 11:20–21; 雅各书 1:10–11"> 门徒看见了，就惊奇说：“无花果树怎么立刻枯干了呢？”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="雅各书 1:6; 马太福音 17:20; 马可福音 11:22–23"> 耶稣回答他们说：<span className="woj">“我实在告诉你们，你们若有信心，不疑惑，不但能行这无花果树所遭遇的事，就是对这座山说：‘挪开，投进海里！’也必成就。</span></span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 7:7; 约翰一书 5:14–15; 马可福音 11:24"> <span className="woj">你们祷告，无论求什么，只要相信，就必得着。”</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 4:7; 马可福音 11:27–33; 历代志上 24:1–19"> 耶稣进了圣殿，正在教导人的时候，祭司长和百姓的长老来到祂面前，说：“你凭什么权柄做这些事？谁给你这权柄？”</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="路加福音 6:9; 歌罗西书 4:6; 马太福音 10:16"> 耶稣回答他们说：<span className="woj">“我也要问你们一个问题；你们若告诉我，我也告诉你们，我凭什么权柄做这些事。</span></span>
<span className="v" id="v25" data-v="25" data-xref="约翰一书 3:20; 马可福音 1:1–11; 约翰福音 3:18"> <span className="woj">约翰的洗礼是从哪里来的？是从天上来的，还是从人来的？”</span><br />他们彼此商议说：“若说‘从天上来的’，祂必问我们：‘那你们为什么不信他？’</span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 6:20; 马太福音 14:5; 约翰福音 5:35"> 若说‘从人来的’，我们又怕众人，因为众人都认定约翰是先知。”</span>
<span className="v" id="v27" data-v="27" data-xref="罗马书 1:18–22; 帖撒罗尼迦后书 2:9–10; 路加福音 20:7–8"> 于是他们回答耶稣说：“我们不知道。”<br />祂也对他们说：<span className="woj">“我也不告诉你们，我凭什么权柄做这些事。</span></span>
<span className="v" id="v28" data-v="28" data-xref="哥林多前书 15:58; 马太福音 20:1; 哥林多前书 10:15"> <span className="woj">但你们怎么看？有一个人有两个儿子。他来到第一个儿子那里，说：‘孩子，今天到我的葡萄园去做工。’</span></span>
<span className="v" id="v29" data-v="29" data-xref="以西结 18:28–32; 马太福音 3:2–8; 以赛亚书 55:6–7"> <span className="woj">他回答说：‘我不去。’后来却懊悔，就去了。</span></span>
<span className="v" id="v30" data-v="30" data-xref="提多书 1:16; 以西结 33:31; 马太福音 23:3"> <span className="woj">父亲又来到第二个儿子那里，也是这样说。他回答说：‘主啊，我去。’却没有去。</span></span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 7:29; 路加福音 7:37–50; 马太福音 7:21"> <span className="woj">这两个儿子，哪一个遵行了父亲的意思呢？”</span><br />他们说：“第一个。”<br />耶稣对他们说：<span className="woj">“我实在告诉你们，税吏和娼妓倒比你们先进上帝的国。</span></span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 7:37–50; 撒迦利亚书 7:11–12; 路加福音 7:29–30"> <span className="woj">因为约翰按公义的道路来到你们这里，你们却不信他；税吏和娼妓倒信了他。你们看见了，后来还是不悔改去信他。</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 5:1–4; 马可福音 12:1–12; 路加福音 20:9–19"> <span className="woj">“你们再听一个比喻。有一个家主栽了一个葡萄园，周围圈上篱笆，在里面挖了压酒池，又盖了一座塔，把园子租给园户，就往外国去了。</span></span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 20:10–19; 以赛亚书 5:4; 撒迦利亚书 1:3–6"> <span className="woj">收果子的时候近了，他差仆人到园户那里去收他的果子。</span></span>
<span className="v" id="v35" data-v="35" data-xref="历代志下 36:15–16; 马太福音 5:12; 希伯来书 11:36–37"> <span className="woj">园户拿住他的仆人，打了一个，杀了一个，又用石头打死一个。</span></span>
<span className="v" id="v36" data-v="36" data-xref="马太福音 22:4"> <span className="woj">他又差别的仆人去，比先前更多；园户还是照样待他们。</span></span>
<span className="v" id="v37" data-v="37" data-xref="约翰福音 3:16; 约翰福音 3:35–36; 西番雅书 3:7"> <span className="woj">后来他差自己的儿子到他们那里去，说：‘他们必尊敬我的儿子。’</span></span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 20:14; 创世记 37:18–20; 马可福音 12:7–8"> <span className="woj">但园户看见那儿子，就彼此说：‘这是承受产业的。来吧，我们杀了他，占了他的产业。’</span></span>
<span className="v" id="v39" data-v="39" data-xref="使徒行传 2:23; 雅各书 5:6; 路加福音 22:52–54"> <span className="woj">于是他们拿住他，把他推出葡萄园外，杀了。</span></span>
<span className="v" id="v40" data-v="40" data-xref="希伯来书 10:29; 马可福音 12:9; 路加福音 20:15–16"> <span className="woj">那么，葡萄园的主人来的时候，要怎样处置这些园户呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="使徒行传 18:6; 马太福音 21:43; 使徒行传 28:28"> 他们对祂说：“他必狠狠地除灭那些恶人，把葡萄园另租给按时候交果子的园户。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v42" data-v="42" data-xref="诗篇 118:22–23; 以赛亚书 28:16; 使徒行传 4:11"> 耶稣对他们说：<span className="woj">“经上说：</span><br /><span className="pl pl-1 woj">‘匠人所弃的石头，</span><br /><span className="pl pl-2 woj">已成了房角的头块石头；</span><br /><span className="pl pl-1 woj">这是主所做的，</span><br /><span className="pl pl-2 woj">在我们眼中看为奇妙。’</span><br /><span className="woj">这话你们从来没有读过吗？</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="马太福音 21:41; 马太福音 8:11–12; 彼得前书 2:9"> <span className="woj">“所以我告诉你们，上帝的国必从你们夺去，赐给那能结出国度果子的民族。</span></span>
<span className="v" id="v44" data-v="44" data-xref="以赛亚书 8:14–15; 彼得前书 2:8; 但以理 2:34–35"> <span className="woj">跌在这石头上的，必被撞碎；这石头落在谁身上，就要把谁砸得粉碎。”</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="路加福音 20:19; 路加福音 11:45; 马太福音 12:12"> 祭司长和法利赛人听见祂这些比喻，就看出祂是指着他们说的。</span>
<span className="v" id="v46" data-v="46" data-xref="马太福音 21:11; 马太福音 21:26; 路加福音 7:16"> 他们想拿住祂，却惧怕众人，因为众人都认定祂是先知。</span>
</div>

<span className="v" id="v1" data-v="1" data-xref="路加福音 9:28–36; 马太福音 26:37; 马可福音 5:37"> 过了六天，耶稣带着彼得、雅各和雅各的兄弟约翰，暗暗地领他们上了一座高山。</span>
<span className="v" id="v2" data-v="2" data-xref="诗篇 104:2; 马太福音 28:3; 路加福音 9:29"> 祂在他们面前改变了形像<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“变了形像”。">a</a></sup>；祂的脸明亮如太阳，衣服洁白如光。</span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 24:44; 马可福音 9:4; 玛拉基书 4:5"> 看哪，摩西和以利亚向他们显现，正和耶稣说话。</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="马可福音 9:5–6; 路加福音 9:33; 约翰福音 14:8–9"> 彼得回应耶稣说：“主啊，我们在这里真好。你若愿意，我就在这里搭三座棚：一座为你，一座为摩西，一座为以利亚。”</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="马太福音 3:17; 马太福音 12:18; 申命记 18:15"> 他还在说话的时候，看哪，有一朵明亮的云彩遮盖他们；看哪，有声音从云彩里出来，说：“这是我的爱子，我喜悦祂。你们要听祂！”</span>
</div>
<div className="bp">
<span className="v" id="v6" data-v="6" data-xref="使徒行传 26:14; 彼得后书 1:18; 但以理 8:17"> 门徒听见了，就脸伏于地，非常害怕。</span>
<span className="v" id="v7" data-v="7" data-xref="但以理 10:18; 马太福音 14:27; 但以理 8:18"> 耶稣进前来摸他们，说：<span className="woj">“起来，不要怕。”</span></span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 9:36; 马可福音 9:8; 使徒行传 12:10–11"> 他们举目一看，不见一人，只见耶稣独自在那里。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马可福音 8:30; 马可福音 9:9–13; 马太福音 17:23"> 他们下山的时候，耶稣吩咐他们说：<span className="woj">“人子还没有从死人中复活以前，不可把所看见的告诉任何人。”</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="玛拉基书 4:5–6; 马太福音 11:14; 约翰福音 1:21"> 门徒问祂说：“那么，文士为什么说以利亚必须先来呢？”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="使徒行传 3:21; 路加福音 1:16–17; 玛拉基书 4:6"> 耶稣回答他们说：<span className="woj">“以利亚确实要先来，并要复兴万事；</span></span>
<span className="v" id="v12" data-v="12" data-xref="以赛亚书 53:3–12; 马太福音 16:21; 使徒行传 13:24–28"> <span className="woj">但我告诉你们，以利亚已经来了，人却不认识他，反而任意待他。人子也要照样受他们的苦。”</span></span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 11:14"> 门徒这才明白，祂是指着施洗者约翰对他们说的。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马可福音 9:14–29; 马可福音 1:40; 使徒行传 10:25–26"> 他们来到众人那里，有一个人来到耶稣面前，跪下说：</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 4:24; 约伯记 1:10–19; 马可福音 9:20–22"> “主啊，怜悯我的儿子！他患癫痫病，受苦很重，常常跌进火里，也常常跌进水里。</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 17:19–20; 路加福音 9:40; 使徒行传 19:15–16"> 我带他到你的门徒那里，他们却不能治好他。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="民数记 14:11; 马太福音 6:30; 马可福音 16:14"> 耶稣回答说：<span className="woj">“不信又悖谬的世代啊！我同你们在一起要到几时呢？我忍耐你们要到几时呢？把他带到我这里来。”</span></span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 9:22; 马可福音 1:34; 马可福音 5:8"> 耶稣斥责那鬼，鬼就从孩子里面出来；从那时起，孩子就好了。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马可福音 9:28; 马可福音 4:10"> 门徒私下到耶稣面前，说：“我们为什么不能把它赶出去呢？”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 17:6; 马可福音 11:23; 路加福音 1:37"> 祂对他们说：<span className="woj">“因为你们不信。我实在告诉你们，你们若有像一粒芥菜种那样的信心，就可以对这座山说：‘从这里移到那里去’，它也必移动；并且没有一件事是你们不能做的。</span></span>
<span className="v" id="v21" data-v="21"> <span className="woj">只是这一类，若不借着祷告和禁食，是不出来的。”</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NU 省略第 21 节。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马太福音 16:21; 路加福音 18:31–34; 马太福音 17:23"> 他们还住在加利利的时候，耶稣对他们说：<span className="woj">“人子将要被交在人手里，</span></span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 16:21; 以赛亚书 53:10–12; 马可福音 8:31"> <span className="woj">他们要杀害祂；第三天祂要复活。”</span><br />门徒就十分忧愁。</span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="出埃及记 38:26; 出埃及记 30:13; 马可福音 9:33"> 他们来到迦百农，收两德拉克马银税的人<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="两德拉克马是一枚希腊银币，约值两个德拉克马，约等于两个罗马第纳里，即两天工钱；常用来缴纳半舍客勒圣殿税。舍客勒约重十克，或约 0.35 盎司。">c</a></sup>来见彼得，说：“你们的老师不纳两德拉克马税吗？”</span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 22:21; 罗马书 13:6–7; 马太福音 22:17"> 彼得说：“纳。”<br />他进了屋子，耶稣先对他说：<span className="woj">“西门，你怎么看？世上的君王向谁收关税或丁税？向自己的儿子呢，还是向外人呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26"> 彼得对祂说：“向外人。”<br />耶稣对他说：<span className="woj">“这样，儿子就免税了。</span></span>
<span className="v" id="v27" data-v="27" data-xref="哥林多后书 6:3; 哥林多前书 8:9; 哥林多前书 9:19–22"> <span className="woj">但免得我们使他们跌倒，你去海边下钩，把先钓上来的鱼拿起来；打开它的口，就会找到一枚斯塔特银币。</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="斯塔特是银币，等于四个阿提卡德拉克马或两个亚历山大德拉克马，也等于一个犹太舍客勒，正好足够两个人缴纳半舍客勒圣殿税。舍客勒约重十克，或约 0.35 盎司，通常为银币。">d</a></sup><span className="woj">拿去给他们，替我和你缴纳。”</span></span>
</div>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 11:16; 马太福音 16:6; 使徒行传 4:1"> 法利赛人和撒都该人来试探耶稣，请祂显一个从天上来的神迹给他们看。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 12:54–56"> 耶稣回答他们说：<span className="woj">“到了傍晚，你们说：‘天必晴，因为天色发红。’</span></span>
<span className="v" id="v3" data-v="3" data-xref="路加福音 12:56; 历代志上 12:32; 马太福音 11:5"> <span className="woj">早晨又说：‘今天必有风雨，因为天色又红又暗。’假冒为善的人哪！你们知道分辨天色，却不能分辨时代的迹象！</span></span>
<span className="v" id="v4" data-v="4" data-xref="路加福音 11:29–30; 马太福音 12:39–40; 约拿 1:17"> <span className="woj">邪恶淫乱的世代寻求神迹；除了约拿先知的神迹以外，再没有神迹给它。”</span><br />祂就离开他们去了。</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 8:13–14; 马太福音 15:39"> 门徒渡到对岸，忘了带饼。</span>
<span className="v" id="v6" data-v="6" data-xref="路加福音 12:1; 加拉太书 5:9; 马太福音 16:12"> 耶稣对他们说：<span className="woj">“你们要谨慎，防备法利赛人和撒都该人的酵。”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马可福音 8:16–18; 马太福音 15:16–18; 使徒行传 10:14"> 他们彼此议论说：“这是因为我们没有带饼。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="马太福音 6:30; 马太福音 14:31; 马太福音 8:26"> 耶稣知道了，就说：<span className="woj">“小信的人哪，为什么因没有带饼而彼此议论呢？</span></span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 14:17–21; 约翰福音 6:9–13; 路加福音 9:13–17"> <span className="woj">你们还不明白吗？不记得那五个饼分给五千人，又收拾了多少篮子吗？</span></span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 15:34–38; 马可福音 8:17–21; 马可福音 8:5–9"> <span className="woj">也不记得那七个饼分给四千人，又收拾了多少篮子吗？</span></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 16:6; 路加福音 12:56; 马可福音 8:21"> <span className="woj">你们怎么不明白，我对你们说的不是饼呢？你们要防备法利赛人和撒都该人的酵。”</span></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="马太福音 5:20; 使徒行传 23:8; 马太福音 15:4–9"> 他们这才明白，耶稣不是叫他们防备饼的酵，而是防备法利赛人和撒都该人的教导。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:18–20; 马可福音 8:27–29; 但以理 7:13"> 耶稣来到凯撒利亚腓立比境内，就问门徒说：<span className="woj">“人们说我人子是谁？”</span></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马可福音 6:15; 马太福音 14:2; 玛拉基书 4:5"> 他们说：“有人说是施洗者约翰；有人说是以利亚；还有人说是耶利米，或是先知中的一位。”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 9:20; 马太福音 13:11; 马可福音 8:29"> 祂对他们说：<span className="woj">“你们说我是谁？”</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马太福音 14:33; 约翰福音 11:27; 约翰一书 4:15"> 西门彼得回答说：“你是基督，是永生上帝的儿子。”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="约翰福音 6:45; 以弗所书 1:17–18; 马太福音 11:25–27"> 耶稣回答他说：<span className="woj">“约拿的儿子西门，你有福了！因为这不是属血肉的启示你的，而是我在天上的父启示你的。</span></span>
<span className="v" id="v18" data-v="18" data-xref="以弗所书 2:19–22; 哥林多前书 3:9–11; 以赛亚书 28:16"> <span className="woj">我还告诉你：你是彼得，</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“彼得”希腊语为 Petros，指一块石头。">a</a></sup><span className="woj">我要把我的教会建造在这磐石</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="希腊语 petra，指岩体或基岩。">b</a></sup><span className="woj">上；阴间</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作“地狱”。">c</a></sup><span className="woj">的门不能胜过它。</span></span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 18:18; 以赛亚书 22:22; 启示录 1:18"> <span className="woj">我要把天国的钥匙给你；凡你在地上捆绑的，必是在天上已经捆绑的；凡你在地上释放的，必是在天上已经释放的。”</span></span>
<span className="v" id="v20" data-v="20" data-xref="马可福音 8:30; 路加福音 9:21; 约翰福音 1:41"> 于是祂吩咐门徒，不可告诉人祂就是耶稣基督。</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 24:6–7; 马太福音 20:17–19; 马太福音 17:22–23"> 从那时起，耶稣开始向门徒指明，祂必须往耶路撒冷去，受长老、祭司长和文士许多苦，被杀，第三天复活。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马可福音 8:32; 约翰福音 13:6–8; 马太福音 16:16–17"> 彼得就拉着祂，开始劝阻祂，说：“主啊，千万不可！这事绝不会临到你。”</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="罗马书 8:5–8; 歌罗西书 3:2; 腓立比书 3:19"> 耶稣却转过来，对彼得说：<span className="woj">“撒但，退到我后面去！你是绊跌我的，因为你不思念上帝的事，只思念人的事。”</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="马太福音 10:38; 路加福音 14:27; 彼得前书 4:1–2"> 于是耶稣对门徒说：<span className="woj">“若有人要跟从我，就当舍己，背起他的十字架，来跟从我。</span></span>
<span className="v" id="v25" data-v="25" data-xref="马太福音 10:39; 马可福音 8:35; 启示录 12:11"> <span className="woj">因为凡想救自己生命的，必丧失生命；凡为我丧失生命的，必得着生命。</span></span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 8:36–37; 约伯记 27:8; 路加福音 9:25"> <span className="woj">人若赚得全世界，却赔上自己的生命，有什么益处呢？人还能拿什么换回自己的生命呢？</span></span>
<span className="v" id="v27" data-v="27" data-xref="哥林多后书 5:10; 诗篇 62:12; 罗马书 2:6"> <span className="woj">因为人子将要在祂父的荣耀里，同祂的天使降临；那时，祂要照各人的行为报应各人。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 9:27; 马可福音 9:1; 约翰福音 8:52"> <span className="woj">我实在告诉你们，站在这里的人，有些在看见人子在祂的国里降临以前，绝不会尝死味。”</span></span>
</div>
</div>

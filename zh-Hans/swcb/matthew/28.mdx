<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 16:1–8; 约翰福音 20:1–10; 马太福音 27:56"> 安息日过后，七日第一日天快亮的时候，抹大拉的马利亚和另一个马利亚来看坟墓。</span>
<span className="v" id="v2" data-v="2" data-xref="使徒行传 16:26; 约翰福音 20:12–13; 马可福音 16:3–5"> 看哪，发生了大地震；因为主的一位天使从天上降下来，走到坟墓前，把石头滚开，坐在上面。</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 9:3; 使徒行传 1:10; 马可福音 16:5"> 他的相貌如闪电，衣服洁白如雪。</span>
<span className="v" id="v4" data-v="4" data-xref="启示录 1:17; 但以理 10:7; 马太福音 27:65–66"> 看守的人因他吓得浑身颤抖，像死人一样。</span>
<span className="v" id="v5" data-v="5" data-xref="启示录 1:17–18; 希伯来书 1:14; 以赛亚书 41:10"> 天使对妇女说：“不要怕，因为我知道你们在寻找那已经钉十字架的耶稣。</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 16:6; 马太福音 12:40; 路加福音 24:6–8"> 祂不在这里，因为祂已经复活了，正如祂所说的。来看看主曾躺卧的地方。</span>
<span className="v" id="v7" data-v="7" data-xref="马太福音 26:32; 路加福音 24:22–24; 马太福音 28:10"> 快去告诉祂的门徒：‘祂已经从死人中复活了；看哪，祂在你们以前往加利利去，在那里你们要看见祂。’看哪，我已经告诉你们了。”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="诗篇 2:11; 马可福音 16:8; 路加福音 24:36–41"> 她们就急忙离开坟墓，又害怕又大大欢喜，跑去把这消息告诉祂的门徒。</span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 28:17; 约翰福音 20:14–17; 马太福音 14:33"> 她们去告诉门徒的时候，看哪，耶稣迎见她们，说：<span className="woj">“愿你们喜乐！”</span><br />她们就上前抱住祂的脚，敬拜祂。</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="罗马书 8:29; 约翰福音 20:17; 马太福音 28:7"> 耶稣对她们说：<span className="woj">“不要怕。去告诉我的弟兄</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="这里“弟兄”一词也可正确译为“弟兄姐妹”或“手足”。">a</a></sup><span className="woj">，叫他们往加利利去，在那里他们要看见我。”</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马太福音 27:65–66; 马太福音 28:4"> 她们去的时候，看哪，看守的人中有几个进城，把所发生的一切事都告诉了祭司长。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 26:3–4; 使徒行传 4:5–22; 马太福音 27:1–2"> 祭司长和长老聚集商议以后，就拿许多银钱给士兵，</span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 26:64"> 说：“你们要说：‘他的门徒夜里来，趁我们睡着的时候把他偷走了。’</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 27:2; 使徒行传 12:19"> 如果这事传到总督耳中，我们会劝服他，使你们无忧无虑。”</span>
<span className="v" id="v15" data-v="15" data-xref="提摩太前书 6:10; 马太福音 27:8; 马太福音 26:15"> 士兵收了银钱，就照他们所吩咐的去做。这说法就在犹太人中间传开了，直到今日。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马太福音 26:32; 马太福音 28:10; 马太福音 28:7"> 十一个门徒往加利利去，到了耶稣所指定的山上。</span>
<span className="v" id="v17" data-v="17" data-xref="诗篇 45:11; 诗篇 2:12; 约翰福音 5:23"> 他们看见祂，就俯伏敬拜祂；但还有人疑惑。</span>
<span className="v" id="v18" data-v="18" data-xref="约翰福音 3:35; 彼得前书 3:22; 马太福音 11:27"> 耶稣进前来，对他们说：<span className="woj">“天上地下所有的权柄都赐给我了。</span></span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 16:15–16; 使徒行传 2:38–39; 使徒行传 1:8"> <span className="woj">所以，你们要去，使万民作我的门徒，奉父、子、圣灵的名给他们施洗，</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TR 和 NU 加有“所以”。">b</a></sup></span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 41:10; 约书亚记 1:5; 使徒行传 18:9–10"> <span className="woj">教导他们遵守我所吩咐你们的一切。看哪，我常与你们同在，直到这世代的终结。”</span>阿们。</span>
</div>

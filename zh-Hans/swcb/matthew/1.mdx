<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="创世记 22:18; 罗马书 1:3; 加拉太书 3:16"> 耶稣基督<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“弥赛亚”（希伯来语）和“基督”（希腊语）的意思都是“受膏者”。">a</a></sup>的家谱，祂是大卫的子孙，亚伯拉罕的子孙。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="使徒行传 7:8; 希伯来书 11:17–18; 创世记 46:8–27"> 亚伯拉罕生以撒，以撒生雅各，雅各生犹大和他的弟兄。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 46:12; 创世记 38:29–30; 历代志上 4:1"> 犹大从他玛生法勒斯和谢拉，法勒斯生希斯仑，希斯仑生亚兰，</span>
<span className="v" id="v4" data-v="4" data-xref="历代志上 2:10–12; 民数记 7:12; 民数记 2:3"> 亚兰生亚米拿达，亚米拿达生拿顺，拿顺生撒门，</span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 11:31; 路得记 1:16–17; 雅各书 2:25"> 撒门从喇合生波阿斯，波阿斯从路得生俄备得，俄备得生耶西，</span>
<span className="v" id="v6" data-v="6" data-xref="列王纪上 15:5; 撒母耳记上 17:12; 撒母耳记下 12:24–25"> 耶西生大卫王。大卫王<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NU 省略“王”。">b</a></sup>从曾作乌利亚妻子的妇人生所罗门，</span>
<span className="v" id="v7" data-v="7" data-xref="历代志下 14:1–15; 列王纪上 14:31; 列王纪上 11:43–24"> 所罗门生罗波安，罗波安生亚比雅，亚比雅生亚撒，</span>
<span className="v" id="v8" data-v="8" data-xref="历代志上 3:11; 历代志下 26:1–23; 列王纪下 8:16"> 亚撒生约沙法，约沙法生约兰，约兰生乌西雅，</span>
<span className="v" id="v9" data-v="9" data-xref="以赛亚书 7:1–13; 历代志下 26:21; 历代志下 27:1–32"> 乌西雅生约坦，约坦生亚哈斯，亚哈斯生希西家，</span>
<span className="v" id="v10" data-v="10" data-xref="历代志下 32:33–27; 列王纪上 13:2; 历代志上 3:13–15"> 希西家生玛拿西，玛拿西生亚们，亚们生约西亚，</span>
<span className="v" id="v11" data-v="11" data-xref="耶利米书 27:20; 耶利米书 52:28–30; 但以理 1:2"> 在被掳到巴比伦的时候，约西亚生耶哥尼雅和他的弟兄。</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="历代志上 3:17; 以斯拉记 3:2; 路加福音 3:27"> 被掳到巴比伦以后，耶哥尼雅生撒拉铁，撒拉铁生所罗巴伯，</span>
<span className="v" id="v13" data-v="13"> 所罗巴伯生亚比玉，亚比玉生以利亚敬，以利亚敬生亚所，</span>
<span className="v" id="v14" data-v="14"> 亚所生撒督，撒督生亚金，亚金生以律，</span>
<span className="v" id="v15" data-v="15"> 以律生以利亚撒，以利亚撒生马但，马但生雅各，</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 27:17; 约翰福音 4:25; 路加福音 3:23"> 雅各生约瑟，就是马利亚的丈夫；那称为基督的耶稣<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="“耶稣”的意思是“救恩”。">c</a></sup>，是从马利亚生的。</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 1:11–12; 列王纪下 24:14; 马太福音 11:2"> 这样，从亚伯拉罕到大卫共有十四代；从大卫到被掳到巴比伦共有十四代；从被掳到巴比伦到基督，也共有十四代。</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="加拉太书 4:4–5; 路加福音 1:27–38; 约伯记 14:4"> 耶稣基督的降生是这样的：祂母亲马利亚已经许配给约瑟，在他们同房以前，马利亚就从圣灵怀了孕。</span>
<span className="v" id="v19" data-v="19" data-xref="申命记 22:21–24; 申命记 24:1–4; 约翰福音 8:4–5"> 她丈夫约瑟是个义人，不愿公开羞辱她，就打算暗中解除婚约。</span>
<span className="v" id="v20" data-v="20" data-xref="箴言 3:5–6; 路加福音 1:19; 马太福音 1:18"> 他正思量这些事的时候，看哪，主的一位天使在梦中向他显现，说：“大卫的子孙约瑟，不要怕，只管娶过马利亚作你的妻子，因为她所怀的，是从圣灵来的。</span>
<span className="v" id="v21" data-v="21" data-xref="使徒行传 13:23; 使徒行传 4:12; 约翰福音 1:29"> 她将要生一个儿子，你要给祂起名叫耶稣<sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“耶稣”的意思是“救恩”。">d</a></sup>，因为祂要把自己的百姓从他们的罪中拯救出来。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v22" data-v="22" data-xref="路加福音 24:44; 马太福音 2:23; 列王纪上 8:15"> 这一切事发生，是要应验主借先知所说的话：</span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 7:14; 以赛亚书 9:6–7; 诗篇 46:11"> <span className="pl pl-1">“看哪，童女将要怀孕，</span><br /><span className="pl pl-2">生一个儿子；</span><br /><span className="pl pl-1">人要称祂的名为以马内利，”</span><br /><span className="pl pl-2">翻出来就是“上帝与我们同在”。</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约翰福音 15:14; 雅各书 2:21–26; 约翰福音 2:5–8"> 约瑟从睡梦中醒来，就照主的天使所吩咐的去做，娶了马利亚作妻子；</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 2:21; 出埃及记 13:2; 马太福音 1:21"> 只是没有和她同房，直到她生了头胎的儿子。约瑟就给祂起名叫耶稣。</span>
</div>

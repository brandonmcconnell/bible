<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 40:3–6; 约翰福音 1:6–8; 路加福音 1:76"> 那些日子，施洗者约翰出来，在犹太的旷野传道，说：</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 4:17; 马可福音 1:15; 但以理 2:44"> “你们要悔改，因为天国近了！”</span>
<span className="v" id="v3" data-v="3" data-xref="以赛亚书 40:3; 玛拉基书 3:1; 约翰福音 1:23"> 这人就是先知以赛亚所说的：<br /><span className="pl pl-1">“在旷野有人呼喊的声音：</span><br /><span className="pl pl-2">预备主的道路！</span><br /><span className="pl pl-2">修直祂的路径！”</span></span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="列王纪下 1:8; 撒迦利亚书 13:4; 马可福音 1:6"> 约翰身穿骆驼毛的衣服，腰束皮带，吃的是蝗虫和野蜜。</span>
<span className="v" id="v5" data-v="5" data-xref="马可福音 1:5; 路加福音 3:7; 约翰福音 3:23"> 那时，耶路撒冷、犹太全地，以及约旦河周围全境的人，都出去到他那里。</span>
<span className="v" id="v6" data-v="6" data-xref="使徒行传 19:18; 马太福音 3:13–16; 使徒行传 2:38–41"> 他们承认自己的罪，在约旦河里受他的洗。</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 12:34; 帖撒罗尼迦前书 1:10; 罗马书 5:9"> 约翰看见许多法利赛人和撒都该人来受他的洗，就对他们说：“毒蛇的后代啊！谁指示你们逃避将来的愤怒呢？</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 3:8; 使徒行传 26:20; 彼得后书 1:4–8"> 你们要结出与悔改相称的果子！</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 3:8; 罗马书 9:7–8; 加拉太书 3:27–29"> 不要自己心里想：‘我们有亚伯拉罕作我们的父。’我告诉你们，上帝能从这些石头中给亚伯拉罕兴起子孙来。</span>
<span className="v" id="v10" data-v="10" data-xref="约翰福音 15:6; 路加福音 3:9; 马太福音 7:19"> 现在斧子已经放在树根上了；凡不结好果子的树，都要砍下来，丢进火里。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 4:4; 路加福音 3:16; 使徒行传 1:5"> “我是用水给你们施洗，叫你们悔改；但那在我以后来的，能力比我更大，我连给祂提鞋也不配。祂要用圣灵给你们施洗。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR 和 NU 加有“并用火”。">a</a></sup></span>
<span className="v" id="v12" data-v="12" data-xref="玛拉基书 4:1; 马太福音 13:30; 路加福音 3:17"> 祂手里拿着簸箕，要彻底清理祂的禾场，把祂的麦子收进仓里，却要用不灭的火烧尽糠秕。”</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="约翰福音 1:32–34; 马太福音 2:22; 马可福音 1:9–11"> 那时，耶稣从加利利来到约旦河<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="即约旦河。">b</a></sup>约翰那里，要受他的洗。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 3:3–7; 使徒行传 1:5–8; 约翰福音 13:6–8"> 约翰却想拦住祂，说：“我需要受你的洗，你反倒到我这里来吗？”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="约翰福音 4:34; 约翰福音 15:10; 诗篇 40:7–8"> 耶稣回答他说：<span className="woj">“现在就准许吧，因为我们这样尽全一切义，是合宜的。”</span>于是约翰准许了祂。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 11:2; 马可福音 1:10; 路加福音 3:21–22"> 耶稣受了洗，随即从水里上来；看哪，诸天为祂开了。祂看见上帝的灵仿佛鸽子降下，落在祂身上。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 42:1; 诗篇 2:7; 马太福音 17:5"> 看哪，有声音从天上说：“这是我的爱子，我喜悦祂。”</span>
</div>
</div>

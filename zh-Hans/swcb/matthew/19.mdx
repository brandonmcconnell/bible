<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="约翰福音 10:40; 马太福音 19:1–9; 马太福音 7:28"> 耶稣说完这些话，就离开加利利，来到约旦河外犹太的境内。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 12:15; 马可福音 6:55–56; 马太福音 15:30–31"> 有大群人跟随祂，祂就在那里医治他们。</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马可福音 10:2; 希伯来书 3:9; 马太福音 16:1"> 有法利赛人来试探祂，说：“人无论因什么缘故都可以休妻吗？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="创世记 2:23; 创世记 1:27; 创世记 5:2"> 耶稣回答说：<span className="woj">“那起初造人的，造男造女，</span></span>
<span className="v" id="v5" data-v="5" data-xref="创世记 2:21–24; 哥林多前书 7:4; 哥林多前书 7:2"> <span className="woj">并且说：‘因此，人要离开父母，与妻子结合，二人成为一体，’</span>这经文你们没有读过吗？</span>
<span className="v" id="v6" data-v="6" data-xref="希伯来书 13:4; 马可福音 10:9; 哥林多前书 7:10–14"> <span className="woj">这样，他们不再是两个，而是一体了。所以，上帝所配合的，人不可分开。”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命记 24:1–4; 马太福音 5:31; 马可福音 10:4"> 他们问祂：“这样，摩西为什么吩咐给妻子休书，就可以休她呢？”</span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="玛拉基书 2:13–14; 创世记 2:24; 马可福音 10:5"> 耶稣对他们说：<span className="woj">“摩西因为你们心硬，才准许你们休妻；但从起初并不是这样。</span></span>
<span className="v" id="v9" data-v="9" data-xref="马太福音 5:32; 路加福音 16:18; 哥林多前书 7:39"> <span className="woj">我告诉你们，凡休妻另娶的，若不是因淫乱，就是犯奸淫；娶那被休之妇人的，也是犯奸淫。”</span></span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 7:32–35; 箴言 19:13–14; 箴言 21:19"> 门徒对祂说：“人和妻子的关系若是这样，倒不如不娶。”</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="哥林多前书 7:17; 哥林多前书 7:35; 哥林多前书 7:7–9"> 耶稣对他们说：<span className="woj">“这话不是人人都能领受，惟有赐给谁，谁才能领受。</span></span>
<span className="v" id="v12" data-v="12" data-xref="哥林多前书 7:32–38; 哥林多前书 9:5; 以赛亚书 56:3–4"> <span className="woj">因为有些阉人是从母腹生来就是这样；有些阉人是被人阉的；也有些阉人是为天国的缘故自己成为阉人的。能领受的，就领受吧。”</span></span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="马可福音 10:13–16; 路加福音 18:15–17; 马太福音 18:2–5"> 那时，有人带小孩子到耶稣那里，要祂给他们按手祷告；门徒就责备那些人。</span>
<span className="v" id="v14" data-v="14" data-xref="马太福音 18:3; 路加福音 18:16–17; 哥林多前书 14:20"> 但耶稣说：<span className="woj">“让小孩子到我这里来，不要禁止他们，因为天国正是属于这样的人。”</span></span>
<span className="v" id="v15" data-v="15" data-xref="马可福音 10:16; 提摩太后书 3:15; 哥林多前书 7:14"> 祂给他们按手，就离开那里。</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="马可福音 10:17–30; 约翰福音 3:15; 犹大书 1:21"> 看哪，有一个人来到耶稣面前，说：“良善的老师，我该做什么善事，才能得永生？”</span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="利未记 18:5; 路加福音 10:26–28; 加拉太书 3:11–13"> 耶稣对他说：<span className="woj">“你为什么称我是良善的？</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="MT 和 TR 如此；NU 作“你为什么问我关于善的事？”">a</a></sup><span className="woj">除了上帝一位以外，再没有良善的。你若要进入生命，就当遵守诫命。”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="申命记 5:16–21; 出埃及记 20:12–17; 马可福音 10:19"> 他问祂：“哪些诫命？”<br />耶稣说：<span className="woj">“‘不可杀人；不可奸淫；不可偷盗；不可作假见证；</span></span>
<span className="v" id="v19" data-v="19" data-xref="利未记 19:18; 出埃及记 20:12; 马太福音 22:39"> <span className="woj">当孝敬父母；’</span><span className="woj">又当‘爱邻舍如同自己。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="加拉太书 3:24; 马可福音 10:20–21; 腓立比书 3:6"> 那年轻人对祂说：“这一切我从小都遵守了，还缺少什么呢？”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="马可福音 10:21; 路加福音 18:22; 路加福音 12:33"> 耶稣对他说：<span className="woj">“你若要完全，就去变卖你所有的，分给穷人，你就必有财宝在天上；然后来跟从我。”</span></span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 6:24; 以西结 33:31; 马太福音 13:22"> 那年轻人听见这话，就忧忧愁愁地走了，因为他有许多产业。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="提摩太前书 6:9–10; 马太福音 13:22; 马可福音 10:23"> 耶稣对门徒说：<span className="woj">“我实在告诉你们，财主进天国是困难的。</span></span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 5:44; 路加福音 18:25; 马可福音 10:24–25"> <span className="woj">我又告诉你们，骆驼穿过针眼，比财主进上帝的国还容易。”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="罗马书 10:13; 马太福音 24:22; 罗马书 11:5–7"> 门徒听见了，就非常惊奇，说：“这样，谁能得救呢？”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="耶利米书 32:27; 路加福音 1:37; 约伯记 42:2"> 耶稣看着他们，说：<span className="woj">“在人这是不能的，但在上帝凡事都能。”</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="腓立比书 3:8; 路加福音 18:28; 路加福音 5:11"> 彼得回答祂说：“看哪，我们已经撇下一切跟从你了；那么我们将得到什么呢？”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 22:28–30; 哥林多前书 6:2–3; 马太福音 25:31"> 耶稣对他们说：<span className="woj">“我实在告诉你们，你们这些跟从我的人，到万物更新、人子坐在祂荣耀宝座上的时候，你们也要坐在十二个宝座上，审判以色列十二个支派。</span></span>
<span className="v" id="v29" data-v="29" data-xref="路加福音 18:29–30; 马可福音 10:29–30; 腓立比书 3:8"> <span className="woj">凡为我的名撇下房屋、弟兄、姐妹、父亲、母亲、妻子、儿女或田地的，必要得着百倍，并且承受永生。</span></span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 20:16; 路加福音 13:30; 马可福音 10:31"> <span className="woj">然而，许多在前的将要在后，在后的将要在前。</span></span>
</div>
</div>

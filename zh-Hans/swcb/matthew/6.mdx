<span className="v" id="v7" data-v="7" data-xref="传道书 5:2–3; 传道书 5:7; 列王纪上 18:26–29"> <span className="woj">你们祷告的时候，不可像外邦人那样空话连篇；他们以为话多了就必蒙垂听。</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 6:32; 路加福音 12:30; 腓立比书 4:6"> <span className="woj">所以不要像他们，因为你们求祂以前，你们的父已经知道你们需要什么。</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 11:1–4; 启示录 4:11; 罗马书 8:15"> <span className="woj">你们要这样祷告：</span><br /><span className="pl pl-1 woj">“‘我们在天上的父，愿你的名被尊为圣。</span><br /></span>

<span className="v" id="v12" data-v="12" data-xref="以弗所书 4:32; 马可福音 11:25; 以弗所书 1:7"> <span className="pl pl-1 woj">赦免我们的债，</span><br /><span className="pl pl-2 woj">如同我们也赦免欠我们债的人。</span></span>
<span className="v" id="v13" data-v="13" data-xref="哥林多前书 10:13; 启示录 7:14–17; 马太福音 26:41"> <span className="pl pl-1 woj">不叫我们陷入试探，</span><br /><span className="pl pl-2 woj">救我们脱离那恶者。</span><br /><span className="pl pl-1 woj">因为国度、权柄、荣耀，全是你的，直到永远。阿们。’</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NU 省略“因为国度、权柄、荣耀，全是你的，直到永远。阿们。”">b</a></sup></span>

<div className="bp">

<span className="v" id="v15" data-v="15" data-xref="马太福音 18:35"> <span className="woj">你们若不赦免人的过犯，你们的父也必不赦免你们的过犯。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 58:3–5; 马太福音 9:14–15; 但以理 9:3"> <span className="woj">“你们禁食的时候，不可像假冒为善的人，带着愁容；他们弄得满脸难看，为要叫人看出他们在禁食。我实在告诉你们，他们已经得了自己的赏赐。</span></span>
<span className="v" id="v17" data-v="17" data-xref="路得记 3:3; 传道书 9:8; 撒母耳记下 12:20"> <span className="woj">但你禁食的时候，要梳洗头发，洗净脸面，</span></span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 6:6; 马太福音 6:4; 哥林多后书 10:18"> <span className="woj">叫人看不出你在禁食，只叫你在隐密中的父看见；你父在隐密中察看，必赏赐你。</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="希伯来书 13:5; 约翰一书 2:15–16; 路加福音 12:21"> <span className="woj">“不要为自己在地上积攒财宝；地上有虫蛀、锈蚀，也有贼挖洞来偷。</span></span>

<div className="bp">

</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约翰一书 2:15–16; 路加福音 16:13; 雅各书 4:4"> <span className="woj">“没有人能事奉两个主人；不是恨这个爱那个，就是忠于这个轻看那个。你们不能又事奉上帝，又事奉玛门。</span></span>
<span className="v" id="v25" data-v="25" data-xref="腓立比书 4:6; 彼得前书 5:7; 罗马书 8:32"> <span className="woj">所以我告诉你们，不要为生命忧虑吃什么、喝什么；也不要为身体忧虑穿什么。生命不胜于食物吗？身体不胜于衣服吗？</span></span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 10:29–31; 诗篇 147:9; 路加福音 12:24–32"> <span className="woj">你们看天上的飞鸟：它们不种，也不收，也不收进仓里；你们的天父尚且养活它们。你们不比飞鸟贵重得多吗？</span></span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="路加福音 12:25–26; 传道书 3:14; 诗篇 39:5–6"> <span className="woj">“你们哪一个能靠忧虑使自己的寿命加上一刻</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="直译为“一肘”。">c</a></sup><span className="woj">呢？</span></span>
<span className="v" id="v28" data-v="28" data-xref="马太福音 6:25; 腓立比书 4:6; 路加福音 12:27"> <span className="woj">为什么为衣服忧虑呢？你们想想田野的百合花怎样生长；它们不劳苦，也不纺线，</span></span>
<span className="v" id="v29" data-v="29" data-xref="历代志下 9:20–22; 历代志下 9:4–6; 彼得前书 3:2–5"> <span className="woj">然而我告诉你们，就是所罗门极荣华的时候，他所穿戴的，还不如这花一朵。</span></span>

<span className="v" id="v31" data-v="31" data-xref="彼得前书 5:7; 路加福音 12:29; 马太福音 4:4"> <span className="woj">“所以不要忧虑，说：‘我们吃什么？’‘喝什么？’或‘穿什么？’</span></span>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 13:1–37; 路加福音 21:5–36; 以西结 8:6"> 耶稣出了圣殿，正往前走；门徒进前来，把圣殿的建筑指给祂看。</span>
<span className="v" id="v2" data-v="2" data-xref="路加福音 19:44; 耶利米书 26:18; 弥迦书 3:12"> 祂回答他们说：<span className="woj">“你们不是看见这一切了吗？我实在告诉你们，将来在这里，没有一块石头留在另一块石头上，不被拆毁。”</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马可福音 13:3–4; 使徒行传 1:7; 帖撒罗尼迦前书 5:1–11"> 耶稣在橄榄山上坐着，门徒私下来问祂说：“请告诉我们，什么时候会有这些事？你降临和这世代终结的时候，有什么预兆呢？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="约翰一书 4:1; 耶利米书 29:8; 帖撒罗尼迦后书 2:3"> 耶稣回答他们说：<span className="woj">“你们要谨慎，不要让人迷惑你们。</span></span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 24:11; 马太福音 24:24; 耶利米书 14:14"> <span className="woj">因为将有许多人冒我的名来，说：‘我是基督’，并且要迷惑许多人。</span></span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 13:7–8; 路加福音 21:9; 彼得前书 3:14–15"> <span className="woj">你们要听见打仗和打仗的风声；要谨慎，不要惊慌，因为这一切必须发生，只是末期还没有到。</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 21:11; 启示录 6:8; 以赛亚书 19:2"> <span className="woj">民要攻打民，国要攻打国；各处必有饥荒、瘟疫和地震。</span></span>
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦前书 5:3; 彼得前书 4:17–18; 申命记 28:59"> <span className="woj">这一切只是产难的开始。</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约翰福音 16:2; 约翰福音 15:19–20; 路加福音 21:16–17"> <span className="woj">“那时，人要把你们交给患难，也要杀害你们；你们要因我的名被万民恨恶。</span></span>
<span className="v" id="v10" data-v="10" data-xref="弥迦书 7:5–6; 路加福音 21:16; 马太福音 11:6"> <span className="woj">那时，许多人要跌倒，彼此出卖，彼此恨恶。</span></span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 24:24; 马太福音 7:15; 马太福音 24:5"> <span className="woj">又有许多假先知兴起，迷惑许多人。</span></span>
<span className="v" id="v12" data-v="12" data-xref="启示录 2:4–5; 雅各书 4:1–4; 启示录 3:15"> <span className="woj">因为不法的事增多，许多人的爱心就渐渐冷淡。</span></span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 10:22; 马可福音 13:13; 启示录 2:10"> <span className="woj">惟有忍耐到底的，必然得救。</span></span>
<span className="v" id="v14" data-v="14" data-xref="启示录 14:6; 罗马书 10:18; 罗马书 16:25–26"> <span className="woj">这天国的福音要传遍天下，对万民作见证，然后末期才来到。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="但以理 9:27; 但以理 12:11; 马可福音 13:14"> <span className="woj">“所以，你们看见先知但以理所说那造成荒凉的可憎之物，</span><span className="woj">站在圣地（读的人应当明白），</span></span>
<span className="v" id="v16" data-v="16" data-xref="创世记 19:15–17; 路加福音 21:21–22; 希伯来书 11:7"> <span className="woj">那时，在犹太的，应当逃到山上；</span></span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 17:31–33; 马可福音 13:15–16; 马太福音 10:27"> <span className="woj">在屋顶上的，不要下来拿屋里的东西；</span></span>
<span className="v" id="v18" data-v="18"> <span className="woj">在田里的，也不要回去取外衣。</span></span>
<span className="v" id="v19" data-v="19" data-xref="路加福音 23:29–30; 申命记 28:53–56; 路加福音 21:23"> <span className="woj">当那些日子，怀孕的和奶孩子的有祸了！</span></span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 16:29; 使徒行传 1:12"> <span className="woj">你们要祷告，使你们逃走的时候不在冬天，也不在安息日；</span></span>
<span className="v" id="v21" data-v="21" data-xref="但以理 12:1; 约珥 2:2; 玛拉基书 4:1"> <span className="woj">因为那时必有大灾难，</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“压迫”。">a</a></sup><span className="woj">从世界的起头直到如今，没有这样的灾难，以后也绝不会有。</span></span>
<span className="v" id="v22" data-v="22" data-xref="马可福音 13:20; 提摩太后书 2:10; 马太福音 24:31"> <span className="woj">若不缩短那些日子，凡有血肉的都不能存活；只是为选民的缘故，那些日子必被缩短。</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 21:8; 路加福音 17:23–24; 申命记 13:1–3"> <span className="woj">“那时，若有人对你们说：‘看哪，基督在这里！’或说：‘在那里！’你们不要信。</span></span>
<span className="v" id="v24" data-v="24" data-xref="帖撒罗尼迦后书 2:9–11; 马可福音 13:22; 启示录 13:13–14"> <span className="woj">因为假基督和假先知将要兴起，显大神迹、大奇事，倘若可能，连选民也要迷惑。</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="约翰福音 16:1; 路加福音 21:13; 以赛亚书 48:5–6"> <span className="woj">“看哪，我已经预先告诉你们了。</span></span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="路加福音 3:2–3; 以赛亚书 40:3; 马太福音 3:1"> <span className="woj">“所以，若有人对你们说：‘看哪，祂在旷野里’，你们不要出去；或说：‘看哪，祂在内室里’，你们不要信。</span></span>
<span className="v" id="v27" data-v="27" data-xref="路加福音 17:24–37; 撒迦利亚书 9:14; 约伯记 37:3"> <span className="woj">因为闪电怎样从东方发出，直照到西方，人子的降临也要这样。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 17:37; 约伯记 39:27–30; 申命记 28:49"> <span className="woj">尸首在哪里，秃鹰</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作“鹰”。">b</a></sup><span className="woj">也必聚集在那里。</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="阿摩司 8:9; 约珥 3:15; 以赛亚书 13:10"> <span className="woj">“那些日子的灾难</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作“压迫”。">c</a></sup><span className="woj">一过去，太阳就要昏暗，月亮也不放光，众星要从天上坠落，天上的万象都要震动；</span></span>
<span className="v" id="v30" data-v="30" data-xref="启示录 1:7; 但以理 7:13; 路加福音 21:27"> <span className="woj">那时，人子的预兆要显在天上；地上的万族都要哀哭，他们要看见人子带着能力和大荣耀，驾着天上的云降临。</span></span>
<span className="v" id="v31" data-v="31" data-xref="帖撒罗尼迦前书 4:16; 马可福音 13:27; 以赛亚书 27:13"> <span className="woj">祂要差遣祂的天使，用号筒的大声，把祂的选民从四方，从天这边到天那边，都聚集起来。</span></span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马可福音 13:28–29; 路加福音 21:29–30"> <span className="woj">“你们可以从无花果树学这个比喻：当树枝发嫩长叶的时候，你们就知道夏天近了。</span></span>
<span className="v" id="v33" data-v="33" data-xref="雅各书 5:9; 希伯来书 10:37; 以西结 7:2–14"> <span className="woj">同样，你们看见这一切事，也该知道祂近了，就在门口了。</span></span>
<span className="v" id="v34" data-v="34" data-xref="马可福音 13:30–31; 路加福音 21:32–33; 马太福音 16:28"> <span className="woj">我实在告诉你们，这世代</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="“世代”（genea）一词也可译为“族类”。">d</a></sup><span className="woj">还没有过去，这一切都要成就。</span></span>
<span className="v" id="v35" data-v="35" data-xref="以赛亚书 40:8; 彼得前书 1:25; 民数记 23:19"> <span className="woj">天地要废去，我的话却绝不会废去。</span></span>
</div>
<div className="bp">
<span className="v" id="v36" data-v="36" data-xref="马可福音 13:32; 使徒行传 1:7; 马太福音 24:44"> <span className="woj">“但那日子、那时辰，没有人知道，连天上的天使也不知道，</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="NU 加有“子也不知道”。">e</a></sup><span className="woj">只有我父知道。</span></span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 17:26–27; 创世记 6:1–7; 彼得后书 2:5"> <span className="woj">挪亚的日子怎样，人子降临也要怎样。</span></span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 17:26–28; 罗马书 13:13–14; 路加福音 14:18–20"> <span className="woj">洪水以前的那些日子，人照常吃喝、娶嫁，直到挪亚进方舟的那日，</span></span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 3:20; 马太福音 24:37; 使徒行传 13:41"> <span className="woj">他们并不知道，直到洪水来了，把他们全都冲走；人子降临也要这样。</span></span>
<span className="v" id="v40" data-v="40" data-xref="路加福音 17:34–37; 彼得后书 2:7–9; 彼得后书 2:5"> <span className="woj">那时，两个人在田里，一个被取去，一个被留下。</span></span>
<span className="v" id="v41" data-v="41" data-xref="出埃及记 11:5; 以赛亚书 47:2; 路加福音 17:35"> <span className="woj">两个女人推磨，一个被取去，一个被留下。</span></span>
<span className="v" id="v42" data-v="42" data-xref="路加福音 21:36; 帖撒罗尼迦前书 5:6; 马太福音 25:13"> <span className="woj">所以你们要警醒，因为你们不知道你们的主什么时候来到。</span></span>
<span className="v" id="v43" data-v="43" data-xref="路加福音 12:39; 马太福音 24:44; 帖撒罗尼迦前书 5:2–6"> <span className="woj">但你们要知道，家主若知道贼夜里哪一更来，就必警醒，不容自己的房屋被挖穿。</span></span>
<span className="v" id="v44" data-v="44" data-xref="马太福音 25:10; 马太福音 24:42; 马太福音 25:13"> <span className="woj">所以你们也要预备好，因为在你们想不到的时候，人子就来了。</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="马太福音 25:21; 马太福音 25:23; 哥林多前书 4:1–2"> <span className="woj">“谁是那忠心有智慧的仆人，被主人派来管理家里的人，按时分给他们食物呢？</span></span>
<span className="v" id="v46" data-v="46" data-xref="启示录 16:15; 路加福音 12:43; 路加福音 12:37"> <span className="woj">主人来到，看见那仆人这样做，那仆人就有福了。</span></span>
<span className="v" id="v47" data-v="47" data-xref="马太福音 25:23; 马太福音 25:21; 路加福音 12:37"> <span className="woj">我实在告诉你们，主人要派他管理自己一切所有的。</span></span>
<span className="v" id="v48" data-v="48" data-xref="马太福音 18:32; 以赛亚书 32:6; 路加福音 12:45"> <span className="woj">但那恶仆若心里说：‘我的主人来得迟’，</span></span>
<span className="v" id="v49" data-v="49" data-xref="启示录 17:6; 启示录 16:6; 弥迦书 3:5"> <span className="woj">就动手打他的同伴，又和醉酒的人一同吃喝，</span></span>
<span className="v" id="v50" data-v="50" data-xref="帖撒罗尼迦前书 5:2–3; 启示录 3:3; 马太福音 24:42–44"> <span className="woj">那仆人的主人要在他想不到的日子、不知道的时辰来到，</span></span>
<span className="v" id="v51" data-v="51" data-xref="马太福音 8:12; 马太福音 22:13; 路加福音 12:46"> <span className="woj">把他重重惩治，定他和假冒为善的人同受一份；在那里必要哀哭切齿。</span></span>
</div>

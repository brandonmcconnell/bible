<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="以赛亚书 61:1–3; 使徒行传 10:38; 路加福音 8:1"> 耶稣吩咐完十二个门徒以后，就离开那里，往他们的各城去教导人、传道。</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="马可福音 6:17; 马太福音 14:3; 马太福音 9:14"> 约翰在监里听见基督所做的事，就差两个门徒去，</span>
<span className="v" id="v3" data-v="3" data-xref="约翰福音 11:27; 玛拉基书 3:1; 申命记 18:15–18"> 问祂说：“你就是那要来的吗？还是我们该等候别人？”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4"> 耶稣回答他们说：<span className="woj">“你们去，把所听见、所看见的事告诉约翰：</span></span>
<span className="v" id="v5" data-v="5" data-xref="以赛亚书 35:4–6; 以赛亚书 61:1–3; 路加福音 4:18"> <span className="woj">瞎子看见，瘸子行走，麻风病人得洁净，聋子听见，</span><span className="woj">死人复活，贫穷的人有福音传给他们。</span></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 8:14–15; 哥林多前书 2:14; 马太福音 26:31"> <span className="woj">凡不因我跌倒的，就是有福的。”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="雅各书 1:6; 约翰福音 5:35; 马可福音 1:3–5"> 他们离开的时候，耶稣开始对众人讲论约翰，说：<span className="woj">“你们从前出去到旷野，是要看什么呢？看风吹动的芦苇吗？</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 3:4; 列王纪下 1:8; 撒迦利亚书 13:4"> <span className="woj">你们出去到底是要看什么呢？看穿细软衣服的人吗？看哪，那些穿细软衣服的人，是在王宫里。</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 1:76; 马太福音 14:5; 马太福音 21:24–26"> <span className="woj">你们出去到底为什么呢？要看先知吗？是的，我告诉你们，他比先知大多了。</span></span>
<span className="v" id="v10" data-v="10" data-xref="玛拉基书 3:1; 以赛亚书 40:3; 玛拉基书 4:5"> <span className="woj">经上所记的就是他：‘看哪，我要差遣我的使者在你面前，他要在你前面预备你的道路。’</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 7:28; 以弗所书 3:8; 马太福音 3:11"> <span className="woj">我实在告诉你们，凡妇人所生的，没有兴起过比施洗者约翰更大的；然而在天国里最小的，也比他大。</span></span>
<span className="v" id="v12" data-v="12" data-xref="路加福音 16:16; 路加福音 13:24; 以弗所书 6:11–13"> <span className="woj">从施洗者约翰的日子直到现在，天国遭受猛烈冲击，强悍的人强取它。</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“掠夺它”。">a</a></sup></span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 5:17–18; 罗马书 3:21; 使徒行传 13:27"> <span className="woj">因为众先知和律法都预言到约翰为止。</span></span>
<span className="v" id="v14" data-v="14" data-xref="玛拉基书 4:5; 马太福音 17:10–13; 马可福音 9:11–13"> <span className="woj">你们若愿意领受，他就是那要来的以利亚。</span></span>
<span className="v" id="v15" data-v="15" data-xref="路加福音 8:8; 马太福音 13:9; 马可福音 4:23"> <span className="woj">有耳可听的，就应当听。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 7:31–35; 马太福音 12:34; 马太福音 23:36"> <span className="woj">“我该用什么来比这世代呢？它像孩子坐在市场上，招呼同伴，</span></span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 28:9–13; 以赛亚书 30:29; 耶利米书 9:17–20"> <span className="woj">说：‘我们向你们吹笛，你们不跳舞；我们唱哀歌，你们不捶胸。’</span></span>
<span className="v" id="v18" data-v="18" data-xref="路加福音 1:15; 马太福音 3:4; 约翰福音 10:20"> <span className="woj">约翰来了，不吃也不喝，人就说：‘他有鬼。’</span></span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 9:10–11; 路加福音 15:1–2; 路加福音 19:7"> <span className="woj">人子来了，也吃也喝，人又说：‘看哪，一个贪食好酒的人，是税吏和罪人的朋友！’但智慧总由她的儿女证明为义。”</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NU 作“行为”，而非“儿女”。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 10:13–15; 耶利米书 8:6; 提摩太后书 2:25–26"> 耶稣开始责备那些祂行过最多异能的城，因为它们没有悔改。</span>
<span className="v" id="v21" data-v="21" data-xref="以西结 3:6–7; 使徒行传 12:20; 路加福音 9:10"> <span className="woj">“哥拉汛哪，你有祸了！伯赛大啊，你有祸了！因为在你们中间所行的异能，若行在推罗、西顿，他们早已披麻蒙灰悔改了。</span></span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 11:24; 马太福音 10:15; 希伯来书 10:26–31"> <span className="woj">但我告诉你们，在审判的日子，推罗和西顿所受的还比你们容易受。</span></span>
<span className="v" id="v23" data-v="23" data-xref="以赛亚书 14:13–15; 约翰福音 4:46–54; 创世记 13:13"> <span className="woj">迦百农啊，你已经被高举到天上吗？你必降到阴间。</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作“地狱”。">c</a></sup><span className="woj">因为在你那里所行的异能，若行在所多玛，它还可以存到今日。</span></span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 10:15; 马太福音 11:22; 马可福音 6:11"> <span className="woj">但我告诉你们，在审判的日子，所多玛地所受的还比你容易受。”</span></span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="马太福音 21:16; 诗篇 8:2; 马太福音 16:17"> 那时，耶稣回应说：<span className="woj">“父啊，天地的主，我感谢你！因为你把这些事向智慧聪明的人隐藏起来，却向婴孩显明出来。</span></span>
<span className="v" id="v26" data-v="26" data-xref="提摩太后书 1:9; 以弗所书 1:11; 约伯记 33:13"> <span className="woj">父啊，是的，因为这在你眼中本是美好的。</span></span>
<span className="v" id="v27" data-v="27" data-xref="约翰福音 14:6–9; 马太福音 28:18; 路加福音 10:22"> <span className="woj">一切都已经由我父交给我。除了父，没有人认识子；除了子和子愿意启示的人，也没有人认识父。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马太福音 11:29; 约翰福音 7:37; 约翰福音 6:37"> <span className="woj">“凡劳苦担重担的人，都到我这里来，我就使你们得安息。</span></span>
<span className="v" id="v29" data-v="29" data-xref="耶利米书 6:16; 约翰一书 2:6; 腓立比书 2:7–8"> <span className="woj">我心里柔和谦卑，你们当负我的轭，向我学习；这样，你们的灵魂就必得安息。</span></span>
<span className="v" id="v30" data-v="30" data-xref="约翰一书 5:3; 约翰福音 16:33; 腓立比书 4:13"> <span className="woj">因为我的轭是容易的，我的担子是轻省的。”</span></span>
</div>
</div>

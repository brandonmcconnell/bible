<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马可福音 9:33–37; 路加福音 9:46–48; 马太福音 20:20–28"> 那时候，门徒来到耶稣面前，说：“那么，在天国里谁是最大的？”</span>
</div>
<div className="bp">
<span className="v" id="v2" data-v="2" data-xref="马太福音 19:13–14; 马可福音 9:36–37; 列王纪上 3:7"> 耶稣叫一个小孩子来，使他站在他们中间，</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 10:14–15; 彼得前书 2:2; 马太福音 19:14"> 说：<span className="woj">“我实在告诉你们，你们若不回转，变得像小孩子一样，绝不能进天国。</span></span>
<span className="v" id="v4" data-v="4" data-xref="雅各书 4:10; 路加福音 14:11; 马可福音 10:43"> <span className="woj">所以，凡自己谦卑像这小孩子的，他在天国里就是最大的。</span></span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 25:40; 马可福音 9:37; 约翰福音 13:20"> <span className="woj">凡因我的名接待一个这样小孩子的，就是接待我；</span></span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 9:42; 路加福音 17:1–2; 马太福音 18:10"> <span className="woj">但凡使这些信我的小子中的一个跌倒的，倒不如把一块大磨石拴在他的颈项上，沉在深海里。</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="路加福音 17:1; 哥林多前书 11:19; 马太福音 26:24"> <span className="woj">“这世界有祸了，因为使人跌倒的事必来；使人跌倒的事固然免不了，但那使人跌倒的人有祸了！</span></span>
<span className="v" id="v8" data-v="8" data-xref="马太福音 5:29–30; 腓立比书 3:8–9; 罗马书 13:12"> <span className="woj">若你的手或脚使你跌倒，就砍下来丢掉；你残缺或瘸腿进入生命，强过有两只手、两只脚却被丢进永火里。</span></span>
<span className="v" id="v9" data-v="9" data-xref="使徒行传 14:22; 马太福音 18:8; 马太福音 5:29"> <span className="woj">若你的眼睛使你跌倒，就剜出来丢掉；你只有一只眼进入生命，强过有两只眼却被丢进火的地狱</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“欣嫩谷”。">a</a></sup><span className="woj">里。</span></span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 91:11; 诗篇 34:7; 希伯来书 1:14"> <span className="woj">你们要谨慎，不可轻看这些小子中的一个；我告诉你们，他们的天使在天上常常见我天父的面。</span></span>
<span className="v" id="v11" data-v="11"> <span className="woj">因为人子来，是要拯救失丧的人。</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NU 省略第 11 节。">b</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="以西结 34:12; 路加福音 15:4–7; 以西结 34:16"> <span className="woj">“你们怎么看？若一个人有一百只羊，其中一只走迷了路，他岂不把九十九只留在山上，去寻找那只迷路的吗？</span></span>
<span className="v" id="v13" data-v="13" data-xref="西番雅书 3:17; 路加福音 15:5–10; 雅各书 2:13"> <span className="woj">若是找着了，我实在告诉你们，他为这一只欢喜，胜过为那九十九只没有迷路的欢喜。</span></span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 17:12; 约翰福音 6:39–40; 彼得后书 3:9"> <span className="woj">照样，你们在天上的父也不愿这些小子中的一个灭亡。</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="利未记 19:17; 路加福音 17:3–4; 加拉太书 6:1"> <span className="woj">“若你的弟兄得罪你，你就去，趁只有你和他在一起的时候指出他的过错；他若听你，你就赢回了你的弟兄。</span></span>
<span className="v" id="v16" data-v="16" data-xref="申命记 19:15; 哥林多后书 13:1; 约翰福音 8:17"> <span className="woj">他若不听，你就另外带一两个人同去，好凭两三个见证人的口，句句都可定准。</span></span>
<span className="v" id="v17" data-v="17" data-xref="帖撒罗尼迦后书 3:6; 哥林多前书 5:9–7; 帖撒罗尼迦后书 3:14–15"> <span className="woj">他若不听他们，就告诉教会；他若连教会也不听，就把他看作外邦人和税吏。</span></span>
<span className="v" id="v18" data-v="18" data-xref="马太福音 16:19; 哥林多后书 2:10; 约翰福音 20:23"> <span className="woj">我实在告诉你们，凡你们在地上捆绑的，必是在天上已经捆绑的；凡你们在地上释放的，必是在天上已经释放的。</span></span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 7:7; 约翰一书 5:14–16; 马可福音 11:24"> <span className="woj">我又实在告诉你们，你们中间若有两个人在地上同心合意，无论求什么，我在天上的父必为他们成就。</span></span>
<span className="v" id="v20" data-v="20" data-xref="哥林多前书 5:4; 启示录 21:3; 马太福音 28:20"> <span className="woj">因为无论哪里有两三个人奉我的名聚集，我就在他们中间。”</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 17:3–4; 马太福音 18:15"> 那时，彼得进前来对祂说：“主啊，我的弟兄得罪我，我当赦免他多少次？到七次吗？”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 3:13; 马可福音 11:25; 马太福音 6:14–15"> 耶稣对他说：<span className="woj">“我不是对你说到七次，而是到七十个七次。</span></span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 13:24; 罗马书 14:12; 马太福音 3:2"> <span className="woj">因此，天国好像一个王，要和他的仆人算账。</span></span>
<span className="v" id="v24" data-v="24" data-xref="诗篇 38:4; 诗篇 130:3–4; 路加福音 16:5"> <span className="woj">刚开始算的时候，有人带了一个欠一万他连得的人来。</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="一万他连得约为三百公吨银子，是极大的数目，约等于六千万第纳里；一第纳里通常相当于农业工人一天工钱。">c</a></sup></span>
<span className="v" id="v25" data-v="25" data-xref="列王纪下 4:1; 尼希米记 5:5; 路加福音 7:42"> <span className="woj">因为他没有能力偿还，主人就吩咐把他和他的妻子儿女，以及一切所有的都卖了来偿还。</span></span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 18:29; 路加福音 7:43; 马太福音 8:2"> <span className="woj">那仆人就俯伏拜他，说：‘主啊，宽容我，我全都要还给你！’</span></span>
<span className="v" id="v27" data-v="27" data-xref="诗篇 145:8; 尼希米记 9:17; 诗篇 86:15"> <span className="woj">那仆人的主人动了怜悯的心，就释放他，免了他的债。</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="马太福音 20:2; 以西结 45:9; 申命记 15:2"> <span className="woj">“但那仆人出去，遇见一个同伴欠他一百第纳里，</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="一百第纳里约为六十分之一个他连得，约五百克（1.1 磅）银子。">d</a></sup><span className="woj">就抓住他，掐着他的喉咙，说：‘把你欠的还给我！’</span></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马太福音 18:26; 马太福音 6:12; 腓利门书 1:18–19"> <span className="woj">“他的同伴就俯伏在他脚前，求他说：‘宽容我，我一定还给你！’</span></span>
<span className="v" id="v30" data-v="30" data-xref="列王纪上 22:27; 列王纪上 21:27–29"> <span className="woj">他却不肯，反而去把他下在监里，直到还清所欠的债。</span></span>
<span className="v" id="v31" data-v="31" data-xref="罗马书 12:15; 希伯来书 13:3; 马可福音 3:5"> <span className="woj">其他同伴看见所发生的事，就非常忧愁，去把这一切事都告诉了主人。</span></span>
<span className="v" id="v32" data-v="32" data-xref="路加福音 19:22; 马太福音 25:26; 罗马书 3:19"> <span className="woj">于是主人叫他来，对他说：‘你这恶仆！你央求我，我就免了你那一切债。</span></span>
<span className="v" id="v33" data-v="33" data-xref="歌罗西书 3:13; 马太福音 6:12; 以弗所书 4:32–2"> <span className="woj">你不也应当怜悯你的同伴，像我怜悯你一样吗？’</span></span>
<span className="v" id="v34" data-v="34" data-xref="马太福音 5:25–26; 雅各书 2:13; 路加福音 12:58–59"> <span className="woj">主人就发怒，把他交给掌刑的人，直到他还清一切所欠的。</span></span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 6:14–15; 雅各书 2:13; 路加福音 6:37–38"> <span className="woj">你们各人若不从心里赦免弟兄的过犯，我天父也要这样待你们。”</span></span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 3:1; 马可福音 8:15; 路加福音 9:7–9"> 那时，分封的王希律听见关于耶稣的传闻，</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 16:14; 约翰福音 10:41; 马可福音 8:28"> 就对臣仆说：“这是施洗者约翰。他从死人中复活了，所以这些能力在他身上运行。”</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 6:17; 路加福音 3:19–20; 马太福音 4:12"> 原来希律为了他兄弟腓力的妻子希罗底，曾经拿住约翰，把他捆绑，下在监里。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 20:21; 利未记 18:16; 马可福音 6:18"> 因为约翰曾对他说：“你娶她是不合乎律法的。”</span>
<span className="v" id="v5" data-v="5" data-xref="马太福音 21:26; 马太福音 11:9; 马可福音 6:19–20"> 希律本想杀他，却怕众人，因为他们都把约翰看作先知。</span>
<span className="v" id="v6" data-v="6" data-xref="马可福音 6:21–23; 创世记 40:20; 何西阿 1:5–6"> 到了希律生日的时候，希罗底的女儿在众人面前跳舞，使希律欢喜。</span>
<span className="v" id="v7" data-v="7" data-xref="以斯帖记 5:3; 以斯帖记 5:6; 以斯帖记 7:2"> 因此希律起誓，应许她无论求什么都给她。</span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 6:24; 箴言 29:10; 箴言 1:16"> 她受了母亲指使，就说：“请把施洗者约翰的头放在盘子里，拿到这里给我。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="约翰福音 19:12–16; 撒母耳记上 14:28; 马可福音 6:26"> 王就忧愁，但为了所起的誓，又为了同席的人，就下令给她。</span>
<span className="v" id="v10" data-v="10" data-xref="马太福音 17:12; 马太福音 21:35–36; 路加福音 9:9"> 于是差人去，在监里斩了约翰。</span>
<span className="v" id="v11" data-v="11" data-xref="启示录 16:6; 创世记 49:7; 以西结 16:3–4"> 他的头被放在盘子里拿来，给了那少女；她就拿去给她母亲。</span>
<span className="v" id="v12" data-v="12" data-xref="使徒行传 8:2; 马太福音 27:58–61"> 约翰的门徒来，把尸体领去埋葬，然后去告诉耶稣。</span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 9:10–17; 马太福音 14:1–2; 马可福音 6:30–44"> 耶稣听见了，就上船，从那里独自退到荒僻的地方。众人听见，就从各城步行跟随祂。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="希伯来书 4:15; 马太福音 9:36; 希伯来书 2:17"> 耶稣出来，看见一大群人，就怜悯他们，医好了他们中间患病的人。</span>
<span className="v" id="v15" data-v="15" data-xref="马太福音 15:23; 马可福音 8:3; 马可福音 6:35–36"> 到了傍晚，门徒来到祂面前，说：“这是荒僻的地方，时候也已经晚了。请遣散众人，让他们往村子里去，自己买食物。”</span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="列王纪下 4:42–44; 哥林多后书 8:2–3; 传道书 11:2"> 耶稣却对他们说：<span className="woj">“他们不用离开；你们给他们吃吧。”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 15:33–34; 马可福音 6:37–38; 路加福音 9:13"> 他们对祂说：“我们这里只有五个饼、两条鱼。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18"> 祂说：<span className="woj">“拿到我这里来。”</span></span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 8:6–7; 路加福音 24:30; 撒母耳记上 9:13"> 祂吩咐众人坐在草地上，就拿起五个饼、两条鱼，望着天祝福，擘开饼，递给门徒；门徒又递给众人。</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 16:12; 马可福音 6:42–44; 马太福音 16:8–10"> 众人都吃，并且吃饱了。他们把剩下的碎块收拾起来，装满了十二个篮子。</span>
<span className="v" id="v21" data-v="21" data-xref="腓立比书 4:19; 哥林多后书 9:8–11; 使徒行传 4:4"> 吃的人，除了妇女和孩子，约有五千男人。</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马可福音 6:45–51; 约翰福音 6:15–21; 马太福音 15:39"> 耶稣随即催门徒上船，先渡到对岸去，自己留下来遣散众人。</span>
<span className="v" id="v23" data-v="23" data-xref="路加福音 6:12; 马可福音 6:46; 马太福音 26:36"> 祂遣散了众人以后，就独自上山去祷告。到了晚上，祂独自在那里。</span>
<span className="v" id="v24" data-v="24" data-xref="约翰福音 6:18; 马可福音 6:48; 马太福音 8:24"> 那时船已经在海中，因逆风被浪摇撼。</span>
<span className="v" id="v25" data-v="25" data-xref="约伯记 9:8; 约翰福音 6:19; 马可福音 6:48"> 夜里四更天<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="夜间分为四更，所以四更约为凌晨三点到日出。">a</a></sup>，耶稣在海面上行走，来到他们那里。</span>
<span className="v" id="v26" data-v="26" data-xref="马可福音 6:49–50; 启示录 1:17; 路加福音 1:11–12"> 门徒看见祂在海面上行走，就惊慌，说：“是鬼影！”他们害怕，就喊叫起来。</span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 23:11; 启示录 1:17–18; 约翰福音 16:33"> 耶稣立刻对他们说：<span className="woj">“放心！是我！</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作“我是！”">b</a></sup><span className="woj">不要怕。”</span></span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="约翰福音 6:68; 罗马书 12:3; 马太福音 26:33–35"> 彼得回答祂说：“主啊，如果是你，请吩咐我从水面上到你那里去。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="腓立比书 4:13; 马可福音 9:23; 使徒行传 3:16"> 祂说：<span className="woj">“来吧！”</span><br />彼得就从船上下去，在水面上走，要到耶稣那里去。</span>
<span className="v" id="v30" data-v="30" data-xref="耶利米哀歌 3:54–57; 提摩太后书 4:16–17; 马可福音 14:38"> 只因看见风很强，就害怕，将要沉下去，便喊着说：“主啊，救我！”</span>
</div>
<div className="bp">
<span className="v" id="v31" data-v="31" data-xref="雅各书 1:6–8; 诗篇 138:7; 创世记 22:14"> 耶稣立刻伸手拉住他，对他说：<span className="woj">“小信的人哪，为什么疑惑？”</span></span>
<span className="v" id="v32" data-v="32" data-xref="诗篇 107:29–30; 马可福音 4:41; 约翰福音 6:21"> 他们上了船，风就止住了。</span>
<span className="v" id="v33" data-v="33" data-xref="约翰福音 11:27; 诗篇 2:7; 罗马书 1:4"> 船上的人都来敬拜祂，说：“你真是上帝的儿子！”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马可福音 6:53–56; 路加福音 5:1; 约翰福音 6:24–25"> 他们渡过去，来到革尼撒勒地。</span>
<span className="v" id="v35" data-v="35" data-xref="马太福音 4:24–25; 马可福音 6:55; 马可福音 1:28–34"> 那地方的人认出耶稣，就差人往周围全境去，把一切患病的人都带到祂那里，</span>
<span className="v" id="v36" data-v="36" data-xref="路加福音 6:19; 马可福音 3:10; 出埃及记 28:33–43"> 只求摸祂衣服的穗子<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="或作“繸子”。">c</a></sup>；凡摸着的都痊愈了。</span>
</div>
</div>

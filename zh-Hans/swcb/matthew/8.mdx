<div className="bible-chapter" lang="zh-Hans" dir="ltr" data-lang="zh-Hans" data-translation="swcb" data-translation-id="cmn_swcb" data-translation-label="SWCB" data-book="MAT" data-book-slug="matthew" data-book-name="马太福音" data-chapter="8" data-verses="34">

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 8:18; 马太福音 4:25–1; 路加福音 5:15"> 耶稣从山上下来，有一大群人跟随祂。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 15:25; 路加福音 17:12–19; 马太福音 18:26"> 看哪，有一个麻风病人来到祂面前，俯伏敬拜祂，说：“主啊，你若愿意，就能使我洁净。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="路加福音 5:13; 诗篇 33:9; 列王纪下 5:14"> 耶稣伸手摸他，说：<span className="woj">“我愿意；你洁净了吧。”</span>他的麻风立刻洁净了。</span>
<span className="v" id="v4" data-v="4" data-xref="利未记 14:2–32; 路加福音 5:14; 路加福音 17:14"> 耶稣对他说：<span className="woj">“你要谨慎，不可告诉任何人；只要去，把身体给祭司察看，并献上摩西所吩咐的礼物，作为给他们的见证。”</span></span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="路加福音 7:1–10; 使徒行传 27:43; 使徒行传 10:1–33"> 耶稣进了迦百农，有一个百夫长来到祂面前，求祂帮助，</span>
<span className="v" id="v6" data-v="6" data-xref="歌罗西书 4:1; 马太福音 4:24; 使徒行传 9:33"> 说：“主啊，我的仆人瘫痪在家，受苦极重。”</span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="马太福音 9:18–19; 路加福音 7:6; 马可福音 5:23–24"> 耶稣对他说：<span className="woj">“我去医治他。”</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="诗篇 107:20; 路加福音 7:6–7; 诗篇 33:9"> 百夫长回答说：“主啊，我不配让你到我屋檐下；只要你说一句话，我的仆人就必痊愈。</span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 4:35–36; 提多书 2:9; 歌罗西书 3:22"> 因为我也是受权柄管辖的人，手下也有士兵。我对这个说：‘去’，他就去；对那个说：‘来’，他就来；对我的仆人说：‘做这事’，他就做。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="马太福音 15:28; 路加福音 7:9; 马可福音 6:6"> 耶稣听见了，就感到惊奇，对跟随的人说：<span className="woj">“我实在告诉你们，这样大的信心，就是在以色列中，我也没有见过。</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 13:28–29; 以弗所书 3:6; 加拉太书 3:28–29"> <span className="woj">我又告诉你们，必有许多人从东从西而来，在天国里与亚伯拉罕、以撒、雅各一同坐席；</span></span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 25:30; 路加福音 13:28; 马太福音 21:43"> <span className="woj">但本国的子民却要被丢在外面的黑暗里，在那里必要哀哭切齿。”</span></span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 9:29–30; 马可福音 9:23; 约翰福音 4:50"> 耶稣对百夫长说：<span className="woj">“你回去吧；照你所信的，给你成就了。”</span>他的仆人就在那时痊愈了。</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 4:38–41; 马可福音 1:29–34; 哥林多前书 9:5"> 耶稣来到彼得家里，看见彼得的岳母正发烧躺着。</span>
<span className="v" id="v15" data-v="15" data-xref="列王纪下 13:21; 路加福音 4:38–39; 路加福音 8:54"> 祂摸她的手，热就退了；她就起来服事祂。<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR 作“服事他们”，而非“服事祂”。">a</a></sup></span>
<span className="v" id="v16" data-v="16" data-xref="出埃及记 15:26; 马太福音 14:14; 马可福音 1:32–34"> 到了傍晚，有人把许多被鬼附的人带到祂面前；祂用一句话赶出那些灵，又医好了一切患病的人。</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 53:4; 彼得前书 2:24; 马太福音 1:22"> 这是要应验先知以赛亚所说的话：“祂担当了我们的软弱，背负了我们的疾病。”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 4:42–43; 路加福音 8:22; 马可福音 4:35"> 耶稣看见有一大群人围着祂，就吩咐渡到对岸去。</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="路加福音 22:33–34; 约翰福音 13:36–38; 路加福音 14:25–27"> 有一个文士来对祂说：“老师，无论你往哪里去，我都要跟从你。”</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="诗篇 84:3; 路加福音 2:7; 以赛亚书 53:2–3"> 耶稣对他说：<span className="woj">“狐狸有洞，天上的飞鸟有窝，只是人子没有枕头的地方。”</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 9:59–62; 利未记 21:11–12; 民数记 6:6–7"> 又有一个门徒对祂说：“主啊，准我先回去埋葬我的父亲。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="歌罗西书 2:13; 路加福音 15:32; 以弗所书 5:14"> 但耶稣对他说：<span className="woj">“跟从我，让死人去埋葬他们自己的死人吧。”</span></span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="路加福音 8:22–25; 马可福音 4:36–41; 马太福音 9:1"> 耶稣上了船，门徒跟随祂。</span>
<span className="v" id="v24" data-v="24" data-xref="路加福音 8:23; 诗篇 107:23–27; 马可福音 4:37–38"> 看哪，海上忽然起了猛烈的风暴，甚至船被浪遮盖；耶稣却睡着了。</span>
<span className="v" id="v25" data-v="25" data-xref="约拿 1:6; 历代志下 14:11; 马可福音 4:38–39"> 门徒来叫醒祂，说：“主啊，救我们！我们要丧命了！”</span>
</div>
<div className="bp">
<span className="v" id="v26" data-v="26" data-xref="以赛亚书 41:10–14; 诗篇 65:7; 诗篇 107:28–30"> 祂对他们说：<span className="woj">“你们为什么害怕？小信的人哪！”</span>于是祂起来，斥责风和海，海就大大平静了。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马可福音 7:37; 马可福音 6:51; 马太福音 14:33"> 众人都惊奇，说：“这是怎样的人？连风和海也听从祂！”</span>
</div>
<div className="bp">
<span className="v" id="v28" data-v="28" data-xref="路加福音 8:26–39; 马可福音 5:1–20; 使徒行传 10:38"> 耶稣来到对岸，到了格革撒人<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="NU 作“加大拉人”。">b</a></sup>的地方，有两个被鬼附的人从坟墓里出来迎着祂；他们极其凶猛，以致没有人能从那条路经过。</span>
<span className="v" id="v29" data-v="29" data-xref="马可福音 1:24; 路加福音 4:34; 雅各书 2:19"> 看哪，他们喊着说：“上帝的儿子耶稣，我们与你有什么相干？时候还没有到，你就来这里折磨我们吗？”</span>
<span className="v" id="v30" data-v="30" data-xref="申命记 14:8; 利未记 11:7; 马可福音 5:11"> 离他们很远，有一大群猪正在吃食。</span>
<span className="v" id="v31" data-v="31" data-xref="启示录 20:1–2; 路加福音 8:30–33; 马可福音 5:12"> 鬼央求祂说：“你若赶我们出去，就准我们进那群猪里吧。”</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马可福音 5:13; 使徒行传 2:23; 启示录 20:7"> 祂对它们说：<span className="woj">“去吧！”</span><br />鬼就出来，进入猪群；看哪，整群猪闯下山崖，投进海里，死在水中。</span>
<span className="v" id="v33" data-v="33" data-xref="路加福音 8:34–36; 马可福音 5:14–16; 使徒行传 19:15–17"> 放猪的人逃跑，进城去，把一切事和被鬼附的人所遭遇的事都告诉了众人。</span>
<span className="v" id="v34" data-v="34" data-xref="使徒行传 16:39; 路加福音 8:37–39; 路加福音 5:8"> 看哪，全城的人都出来迎见耶稣；他们看见祂，就央求祂离开他们的境界。</span>
</div>
</div>

</div>

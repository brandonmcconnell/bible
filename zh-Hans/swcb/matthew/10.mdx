<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="路加福音 9:1–6; 马可福音 3:13–15; 马可福音 6:7–13"> 耶稣叫了十二个门徒来，赐给他们权柄，可以赶出污灵，并医治各样的疾病和各样的病症。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 4:21; 使徒行传 1:13; 路加福音 5:10"> 十二使徒的名字是：头一个是西门，又称彼得；还有他的兄弟安得烈；西庇太的儿子雅各和雅各的兄弟约翰；</span>
<span className="v" id="v3" data-v="3" data-xref="马可福音 3:18; 使徒行传 1:13; 马可福音 2:14"> 腓力；巴多罗买；多马；税吏马太；亚勒腓的儿子雅各；利拜乌，又称为<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NU 省略“利拜乌，又称为”。">a</a></sup>达太；</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 26:14; 马太福音 26:47; 约翰福音 13:2"> 奋锐党的西门；还有加略人犹大，就是后来出卖耶稣的那一个。</span>
</div>
<div className="bp">
<span className="v" id="v5" data-v="5" data-xref="约翰福音 4:9; 使徒行传 22:21–23; 列王纪下 17:24–41"> 耶稣差遣这十二个人出去，吩咐他们说：<span className="woj">“外邦人的路，你们不要走；撒玛利亚人的城，你们不要进。</span></span>
<span className="v" id="v6" data-v="6" data-xref="耶利米书 50:6; 以西结 34:6; 以赛亚书 53:6"> <span className="woj">宁可往以色列家迷失的羊那里去。</span></span>
<span className="v" id="v7" data-v="7" data-xref="使徒行传 28:31; 马太福音 3:2; 路加福音 9:60"> <span className="woj">你们去的时候，要传讲说：‘天国近了！’</span></span>
<span className="v" id="v8" data-v="8" data-xref="使徒行传 3:6; 路加福音 10:9; 使徒行传 4:30"> <span className="woj">要医治病人，洁净麻风病人，</span><sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TR 加有“叫死人复活”。">b</a></sup><span className="woj">赶出鬼。你们白白得来，也要白白给出去。</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 22:35; 路加福音 9:3–5; 路加福音 10:4–12"> <span className="woj">腰袋里不要带金、银、铜钱；</span></span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 10:7–12; 提摩太前书 5:17–18; 哥林多前书 9:4–14"> <span className="woj">路上不要带行囊，不要带两件衣服，不要带鞋，也不要带手杖；因为工人得食物是应当的。</span></span>
<span className="v" id="v11" data-v="11" data-xref="路加福音 10:7–8; 约伯记 31:32; 士师记 19:16–21"> <span className="woj">无论进哪一城、哪一村，要打听那里谁是配得的人，就住在那里，直到离开。</span></span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 25:6; 路加福音 10:5–6; 使徒行传 10:36"> <span className="woj">进那家时，要向那家问安。</span></span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 10:6; 诗篇 35:13; 哥林多后书 2:16"> <span className="woj">那家若配得，你们所求的平安就临到它；若不配得，你们所求的平安就归回你们。</span></span>
<span className="v" id="v14" data-v="14" data-xref="路加福音 10:10–11; 使徒行传 18:6; 尼希米记 5:13"> <span className="woj">凡不接待你们，也不听你们话的人，你们离开那家或那城的时候，要把脚上的尘土跺下去。</span></span>
<span className="v" id="v15" data-v="15" data-xref="彼得后书 2:6; 约翰一书 4:17; 约翰福音 15:22–24"> <span className="woj">我实在告诉你们，在审判的日子，所多玛和蛾摩拉地所受的，还比那城容易受呢。</span></span>
</div>
<div className="bp">
<span className="v" id="v16" data-v="16" data-xref="路加福音 10:3; 腓立比书 2:15; 哥林多前书 14:20"> <span className="woj">“看哪，我差你们出去，如同羊进入狼群；所以你们要灵巧像蛇，纯良像鸽子。</span></span>
<span className="v" id="v17" data-v="17" data-xref="马可福音 13:9; 马太福音 23:34; 使徒行传 26:11"> <span className="woj">你们要防备人；因为他们要把你们交给议会，也要在他们的会堂里鞭打你们。</span></span>
<span className="v" id="v18" data-v="18" data-xref="使徒行传 5:25–27; 马太福音 8:4; 诗篇 2:1–6"> <span className="woj">你们又要为我的缘故被带到总督和君王面前，对他们和外邦人作见证。</span></span>
<span className="v" id="v19" data-v="19" data-xref="出埃及记 4:12; 马可福音 13:11–13; 提摩太后书 4:17"> <span className="woj">他们把你们交出去的时候，不要忧虑怎样说、说什么；因为到那时候，必赐给你们当说的话。</span></span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 21:15; 使徒行传 6:10; 路加福音 12:12"> <span className="woj">因为说话的不是你们，乃是你们父的灵在你们里面说话。</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="路加福音 21:16–17; 弥迦书 7:5–6; 马可福音 13:12–13"> <span className="woj">“弟兄要把弟兄交给死地，父亲要把儿女交给死地；儿女也要起来与父母为敌，害死他们。</span></span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 24:13; 雅各书 1:12; 启示录 2:10"> <span className="woj">你们要因我的名被众人恨恶；惟有忍耐到底的，必然得救。</span></span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 16:28; 使徒行传 8:1; 马可福音 13:26"> <span className="woj">有人在这城迫害你们，就逃到那城去。我实在告诉你们，以色列的城邑，你们还没有走遍，人子就来了。</span></span>
</div>
<div className="bp">
<span className="v" id="v24" data-v="24" data-xref="约翰福音 15:20; 路加福音 6:40; 约翰福音 13:16"> <span className="woj">“学生不能高过老师，仆人不能高过主人。</span></span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 11:15; 马太福音 12:24; 马太福音 9:34"> <span className="woj">学生能像老师，仆人能像主人，也就够了。人既称家主为别西卜，</span><sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="直译为“苍蝇之主”，也可指魔鬼。">c</a></sup><span className="woj">何况他的家人呢！</span></span>
<span className="v" id="v26" data-v="26" data-xref="路加福音 8:17; 马可福音 4:22; 耶利米书 1:8"> <span className="woj">所以不要怕他们；因为没有什么掩盖的事不被揭露，也没有什么隐藏的事不被人知道。</span></span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 5:20; 约翰福音 16:13; 约翰福音 16:1"> <span className="woj">我在暗中告诉你们的，你们要在光明中说出来；你们耳中听见的，要在屋顶上宣扬出来。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 12:4–5; 以赛亚书 8:12–13; 启示录 2:10"> <span className="woj">不要怕那些杀身体却不能杀灵魂的人；倒要怕那能把灵魂和身体都灭在地狱里的。</span><sup className="fn"><a href="#fn-d" id="fnref-d" data-fn="或作“欣嫩谷”。">d</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="路加福音 12:6–7; 诗篇 104:27–30"> <span className="woj">“两只麻雀不是卖一个小铜钱吗？</span><sup className="fn"><a href="#fn-e" id="fnref-e" data-fn="assarion 是小铜币，约值十分之一德拉克马，或十六分之一第纳里；约等于农业工人半小时的工钱。">e</a></sup><span className="woj">若不是你们父许可，其中一只也不会掉在地上。</span></span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 12:7; 撒母耳记上 14:45; 使徒行传 27:34"> <span className="woj">就是你们的头发，也都数过了。</span></span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 12:24; 诗篇 8:5; 马太福音 6:26"> <span className="woj">所以不要怕；你们比许多麻雀更贵重。</span></span>
<span className="v" id="v32" data-v="32" data-xref="启示录 3:5; 罗马书 10:9–10; 路加福音 12:8–9"> <span className="woj">凡在人面前承认我的，我在我天上的父面前也必承认他；</span></span>
<span className="v" id="v33" data-v="33" data-xref="提摩太后书 2:12; 路加福音 9:26; 路加福音 12:9"> <span className="woj">凡在人面前不认我的，我在我天上的父面前也必不认他。</span></span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="路加福音 12:49–53; 使徒行传 14:4; 使徒行传 13:45–50"> <span className="woj">“不要以为我来是要把平安带到地上；我来不是带来平安，而是带来刀剑。</span></span>
<span className="v" id="v35" data-v="35" data-xref="弥迦书 7:5–6; 马太福音 10:21; 路加福音 21:16"> <span className="woj">因为我来是要叫人与父亲相争，女儿与母亲相争，媳妇与婆婆相争；</span></span>
<span className="v" id="v36" data-v="36" data-xref="弥迦书 7:6; 耶利米书 12:6; 诗篇 41:9"> <span className="woj">人的仇敌就是自己家里的人。</span></span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 14:26; 马太福音 22:37; 腓立比书 3:7–9"> <span className="woj">爱父母过于爱我的，不配属我；爱儿女过于爱我的，也不配属我。</span></span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 14:27; 马可福音 8:34; 马太福音 16:24"> <span className="woj">不背起自己的十字架来跟从我的，也不配属我。</span></span>
<span className="v" id="v39" data-v="39" data-xref="约翰福音 12:25; 马可福音 8:35–36; 路加福音 17:33"> <span className="woj">得着自己生命的，必要丧失生命；为我丧失自己生命的，必要得着生命。</span></span>
</div>
<div className="bp">
<span className="v" id="v40" data-v="40" data-xref="约翰福音 13:20; 路加福音 9:48; 路加福音 10:16"> <span className="woj">“接待你们的，就是接待我；接待我的，就是接待那差我来的。</span></span>
<span className="v" id="v41" data-v="41" data-xref="约翰三书 1:5–8; 希伯来书 6:10; 列王纪下 4:16–17"> <span className="woj">因先知的名接待先知的，必得先知所得的赏赐；因义人的名接待义人的，必得义人所得的赏赐。</span></span>
<span className="v" id="v42" data-v="42" data-xref="希伯来书 6:10; 马太福音 25:40; 马可福音 9:41–42"> <span className="woj">无论谁，因门徒的名，只把一杯凉水给这些小子中的一个喝，我实在告诉你们，他绝不会失去自己的赏赐。”</span></span>
</div>

<div className="bt">
<div className="bp poetry">
<span className="v" id="v1" data-v="1" data-xref="弥迦书 5:2; 约翰福音 7:42; 路加福音 2:4–7"> 希律王的时候，耶稣生在犹太的伯利恒。看哪，有几位博士<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="“博士”（magoi）一词也可指教师、学者、医师、占星者、先见、解梦者或术士。">a</a></sup>从东方来到耶路撒冷，说：</span>
<span className="v" id="v2" data-v="2" data-xref="民数记 24:17; 耶利米书 23:5; 启示录 22:16"> “那生下来作犹太人之王的在哪里？我们在东方看见祂的星，特来敬拜祂。”</span>
<span className="v" id="v3" data-v="3" data-xref="使徒行传 17:6–7; 约翰福音 11:47–48; 马太福音 23:37"> 希律王听见了，就心里不安；全耶路撒冷也同他一样不安。</span>
<span className="v" id="v4" data-v="4" data-xref="马太福音 21:23; 马太福音 7:29; 使徒行传 6:12"> 他召集了百姓所有的祭司长和文士，问他们基督应当生在哪里。</span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 7:42; 路得记 1:1; 撒母耳记上 16:1"> 他们对他说：“在犹太的伯利恒，因为先知这样写着：</span>
<span className="v" id="v6" data-v="6" data-xref="以西结 34:23–25; 弥迦书 5:2; 以赛亚书 9:6–7"> <span className="pl pl-1">‘犹大地的伯利恒啊，</span><br /><span className="pl pl-2">你在犹大的诸首领中绝不是最小的；</span><br /><span className="pl pl-1">因为将有一位掌权者从你那里出来，</span><br /><span className="pl pl-2">祂要牧养我的百姓以色列。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="出埃及记 1:10; 撒母耳记上 18:21; 诗篇 55:21"> 于是希律暗中召了博士来，向他们仔细查问那星出现的时间。</span>
<span className="v" id="v8" data-v="8" data-xref="哥林多前书 3:19–20; 耶利米书 41:5–7; 路加福音 20:20–21"> 他差他们往伯利恒去，说：“你们去仔细寻找那小孩子；找到了，就回报我，好让我也去敬拜祂。”</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马太福音 2:2; 箴言 8:17; 诗篇 25:12"> 他们听了王的话，就去了。看哪，他们在东方所看见的那星在他们前头行，直到来到小孩子所在的地方，就停在上方。</span>
<span className="v" id="v10" data-v="10" data-xref="诗篇 105:3; 路加福音 2:20; 路加福音 2:10"> 他们看见那星，就大大欢喜，满心喜乐。</span>
<span className="v" id="v11" data-v="11" data-xref="以赛亚书 60:6; 诗篇 72:10; 路加福音 2:16"> 他们进了屋子，看见小孩子和祂母亲马利亚，就俯伏敬拜祂；又打开宝盒，把黄金、乳香和没药作为礼物献给祂。</span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 2:22; 马太福音 2:19; 马太福音 2:13"> 他们在梦中得了指示，不要回到希律那里去，就从别的路回自己的国家去了。</span>
</div>
<div className="bp">
<span className="v" id="v13" data-v="13" data-xref="使徒行传 10:7; 使徒行传 5:19; 马太福音 1:20"> 他们离开以后，看哪，主的一位天使在梦中向约瑟显现，说：“起来，带着小孩子和祂母亲逃往埃及，住在那里，直到我告诉你，因为希律要寻找这小孩子，要除灭祂。”</span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="马太福音 2:20–21; 使徒行传 26:21; 马太福音 1:24"> 约瑟就起来，连夜带着小孩子和祂母亲往埃及去，</span>
<span className="v" id="v15" data-v="15" data-xref="何西阿 11:1; 出埃及记 4:22; 民数记 24:8"> 住在那里，直到希律死了。这是要应验主借先知所说的话：“我从埃及召出我的儿子。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 59:7; 箴言 28:15; 士师记 16:10"> 希律见自己被博士愚弄了，就大大发怒，照着他从博士那里仔细查问出来的时间，差人把伯利恒和周围全境两岁以内的男孩全都杀了。</span>
<span className="v" id="v17" data-v="17"> 这就应验了先知耶利米所说的话：</span>
<span className="v" id="v18" data-v="18" data-xref="耶利米书 31:15; 耶利米书 9:17–21; 耶利米书 4:31"> <span className="pl pl-1">“在拉玛听见声音，</span><br /><span className="pl pl-2">是哀号、哭泣和大大悲恸的声音；</span><br /><span className="pl pl-1">拉结为她的儿女哭泣，</span><br /><span className="pl pl-2">不肯受安慰，</span><br /><span className="pl pl-2">因为他们都不在了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="马太福音 1:20; 但以理 8:25; 马太福音 2:12–13"> 希律死后，看哪，主的一位天使在埃及向约瑟梦中显现，说：</span>
<span className="v" id="v20" data-v="20" data-xref="出埃及记 4:19; 列王纪上 12:1–3; 马太福音 2:13"> “起来，带着小孩子和祂母亲往以色列地去，因为那些寻索小孩子性命的人已经死了。”</span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="希伯来书 11:8; 创世记 6:22"> 约瑟就起来，带着小孩子和祂母亲进入以色列地。</span>
<span className="v" id="v22" data-v="22" data-xref="以赛亚书 48:17–18; 路加福音 2:39; 约翰福音 7:52"> 但他听说亚基老接替他父亲希律作犹太王，就害怕往那里去；又在梦中得了指示，便退到加利利地区，</span>
<span className="v" id="v23" data-v="23" data-xref="士师记 13:5; 约翰福音 1:45–46; 马可福音 1:24"> 来到一座名叫拿撒勒的城，住在那里。这是要应验众先知所说的话：祂将被称为拿撒勒人。</span>
</div>
</div>

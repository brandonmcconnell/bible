<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 20:1–16; 马太福音 12:43–45; 路加福音 14:16"> 耶稣又用比喻对他们说：</span>
<span className="v" id="v2" data-v="2" data-xref="启示录 19:7–9; 马太福音 13:24; 以弗所书 5:24–32"> <span className="woj">“天国好像一个王，为自己的儿子摆设婚宴，</span></span>
<span className="v" id="v3" data-v="3" data-xref="启示录 22:17; 约翰福音 5:40; 路加福音 14:15–17"> <span className="woj">就差仆人去召那些被请的人来赴婚宴，他们却不肯来。</span></span>
<span className="v" id="v4" data-v="4" data-xref="使徒行传 13:46; 马太福音 21:36; 约翰福音 6:50–57"> <span className="woj">王又差别的仆人去，说：‘告诉那些被请的人：看哪，我已经预备好了筵席，牛和肥畜都已经宰了，样样齐备，请来赴婚宴吧！’</span></span>
<span className="v" id="v5" data-v="5" data-xref="希伯来书 2:3; 路加福音 14:18–20; 约翰一书 2:15–16"> <span className="woj">他们却不理会，各自走了；一个到自己的田里去，一个去做买卖；</span></span>
<span className="v" id="v6" data-v="6" data-xref="约翰福音 15:19–20; 约翰福音 16:2–3; 使徒行传 7:51–57"> <span className="woj">其余的人拿住他的仆人，凌辱他们，把他们杀了。</span></span>
<span className="v" id="v7" data-v="7" data-xref="路加福音 19:27; 彼得前书 4:17–18; 路加福音 21:24"> <span className="woj">王听见了，就发怒，派军队除灭那些杀人的人，烧毁他们的城。</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="帖撒罗尼迦后书 1:5; 使徒行传 13:46; 启示录 3:4"> <span className="woj">“于是他对仆人说：‘婚宴已经预备好了，只是所请的人不配。</span></span>
<span className="v" id="v9" data-v="9" data-xref="路加福音 14:21–24; 箴言 1:20–23; 马可福音 16:15–16"> <span className="woj">所以你们往大路岔口去，凡遇见的，都请来赴婚宴。’</span></span>
<span className="v" id="v10" data-v="10" data-xref="哥林多前书 6:9–11; 启示录 19:6–9; 哥林多后书 12:21"> <span className="woj">那些仆人就出去到大路上，凡遇见的，无论好坏都聚集来；婚宴上就坐满了客人。</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="启示录 3:4–5; 启示录 19:8; 希伯来书 4:12–13"> <span className="woj">“王进来看客人的时候，看见那里有一个没有穿婚宴礼服的人，</span></span>
<span className="v" id="v12" data-v="12" data-xref="撒母耳记上 2:9; 约伯记 5:16; 马太福音 20:13"> <span className="woj">就对他说：‘朋友，你没有穿婚宴礼服，怎么进到这里来呢？’那人无言可答。</span></span>
<span className="v" id="v13" data-v="13" data-xref="马太福音 8:12; 马太福音 25:30; 马太福音 24:51"> <span className="woj">于是王对仆人说：‘捆起他的手脚，把他带走，丢在外面的黑暗里；在那里必要哀哭切齿。’</span></span>
<span className="v" id="v14" data-v="14" data-xref="彼得后书 1:10; 路加福音 13:23–24; 马太福音 7:13–14"> <span className="woj">因为被召的人多，蒙选的人少。”</span></span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="路加福音 20:20–26; 马可福音 12:13–17; 诗篇 2:2"> 那时，法利赛人出去商议，怎样在耶稣的话语上设陷阱。</span>
<span className="v" id="v16" data-v="16" data-xref="马可福音 3:6; 马可福音 8:15; 马可福音 12:14"> 他们就打发自己的门徒同希律党人去见耶稣，说：“老师，我们知道你是诚实的，并且按真理教导上帝的道路，不顾忌任何人，因为你不看人的情面。</span>
<span className="v" id="v17" data-v="17" data-xref="路加福音 2:1; 罗马书 13:6–7; 马太福音 17:25"> 请告诉我们，你怎么看？纳税给凯撒，合乎律法不合乎？”</span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰福音 8:6; 路加福音 5:22; 约翰福音 2:25"> 耶稣看出他们的恶意，就说：<span className="woj">“假冒为善的人哪，为什么试探我？</span></span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 20:2; 启示录 6:6; 马太福音 18:28"> <span className="woj">拿纳税的钱给我看。”</span><br />他们就拿一个第纳里给祂。</span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="路加福音 20:24"> 祂问他们：<span className="woj">“这像和名号是谁的？”</span></span>
</div>
<div className="bp">
<span className="v" id="v21" data-v="21" data-xref="罗马书 13:7; 箴言 24:21; 使徒行传 4:19"> 他们说：“凯撒的。”<br />于是祂对他们说：<span className="woj">“这样，凯撒的归给凯撒，上帝的归给上帝。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="马可福音 12:12; 马太福音 22:46; 路加福音 20:25–26"> 他们听见了，就希奇，离开祂走了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="使徒行传 4:1; 马可福音 12:18–27; 使徒行传 23:6–8"> 那一天，撒都该人来到耶稣面前；他们说没有复活。他们问祂，</span>
<span className="v" id="v24" data-v="24" data-xref="申命记 25:5–10; 路加福音 20:28; 路得记 1:11"> 说：“老师，摩西说：‘若有人死了，没有孩子，他的兄弟就要娶他的妻，为兄弟立后<sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="或作“后裔”。">a</a></sup>。’</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 20:29–33; 马可福音 12:19–23; 希伯来书 9:27"> 从前我们这里有兄弟七人。第一个娶了妻，死了，没有留下后裔，就把妻子留给他的兄弟。</span>
<span className="v" id="v26" data-v="26"> 第二个、第三个，直到第七个，都是这样。</span>
<span className="v" id="v27" data-v="27"> 他们都死了以后，那女人也死了。</span>
<span className="v" id="v28" data-v="28"> 这样，复活的时候，她是七个人中哪一个的妻子呢？因为他们都娶过她。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="约翰福音 20:9; 罗马书 15:4; 路加福音 1:37"> 耶稣回答他们说：<span className="woj">“你们错了，因为不明白圣经，也不晓得上帝的大能。</span></span>
<span className="v" id="v30" data-v="30" data-xref="路加福音 20:34–36; 马可福音 12:24–25; 马太福音 24:38"> <span className="woj">复活的时候，人也不娶，也不嫁，而是像天上的上帝使者一样。</span></span>
<span className="v" id="v31" data-v="31" data-xref="马太福音 12:3; 马太福音 21:16; 马太福音 21:42"> <span className="woj">至于死人复活，上帝对你们所说的话，你们没有读过吗？祂说：</span></span>
<span className="v" id="v32" data-v="32" data-xref="出埃及记 3:6; 马可福音 12:26–27; 路加福音 20:37–38"> <span className="woj">‘我是亚伯拉罕的上帝，以撒的上帝，雅各的上帝。’</span><span className="woj">上帝不是死人的上帝，乃是活人的上帝。”</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="马可福音 12:17; 马可福音 6:2; 约翰福音 7:46"> 众人听见了，就对祂的教导感到惊奇。</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="马可福音 12:28–31; 马太福音 25:3–5; 马太福音 12:14"> 法利赛人听见耶稣使撒都该人无话可说，就聚集在一起。</span>
<span className="v" id="v35" data-v="35" data-xref="路加福音 7:30; 路加福音 10:25–37; 路加福音 11:52"> 他们中间有一个律法师试探耶稣，问祂说：</span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 12:28–33; 马太福音 5:19–20; 路加福音 11:42"> “老师，律法中哪一条诫命最大？”</span>
</div>
<div className="bp">
<span className="v" id="v37" data-v="37" data-xref="马可福音 12:29–30; 路加福音 10:27; 申命记 6:5"> 耶稣对他说：<span className="woj">“‘你要尽心、尽性、尽意爱主你的上帝。’</span></span>
<span className="v" id="v38" data-v="38"> <span className="woj">这是第一且最大的诫命。</span></span>
<span className="v" id="v39" data-v="39" data-xref="马可福音 12:31; 路加福音 10:27–37; 利未记 19:18"> <span className="woj">第二条也相似，就是：‘要爱邻舍如同自己。’</span></span>
<span className="v" id="v40" data-v="40" data-xref="罗马书 13:9; 马太福音 7:12; 约翰一书 4:19–21"> <span className="woj">全部律法和先知，都系于这两条诫命。”</span></span>
</div>
<div className="bp">
<span className="v" id="v41" data-v="41" data-xref="路加福音 20:41–44; 马可福音 12:35–37; 马太福音 22:34"> 法利赛人聚集的时候，耶稣问他们一个问题，</span>
<span className="v" id="v42" data-v="42" data-xref="耶利米书 23:5–6; 约翰福音 6:68–69; 马太福音 16:13–17"> 说：<span className="woj">“论到基督，你们怎么看？祂是谁的子孙？”</span><br />他们对祂说：“是大卫的子孙。”</span>
</div>
<div className="bp poetry">
<span className="v" id="v43" data-v="43" data-xref="撒母耳记下 23:2; 启示录 4:2; 马可福音 12:36"> 祂对他们说：<span className="woj">“那么，大卫在圣灵里怎么称祂为主，说：</span></span>
<span className="v" id="v44" data-v="44" data-xref="诗篇 110:1; 希伯来书 1:13; 使徒行传 2:34–35"> <span className="pl pl-1 woj">‘主对我主说：</span><br /><span className="pl pl-2 woj">你坐在我的右边，</span><br /><span className="pl pl-2 woj">等我使你的仇敌作你的脚凳’？</span></span>
</div>
<div className="bp">
<span className="v" id="v45" data-v="45" data-xref="罗马书 1:3–4; 启示录 22:16; 约翰福音 8:58"> <span className="woj">“既然大卫称祂为主，祂怎么又是大卫的子孙呢？”</span></span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="马可福音 12:34; 路加福音 20:40; 路加福音 14:6"> 没有人能回答祂一句话；从那一天起，也没有人敢再问祂什么。</span>
</div>
</div>

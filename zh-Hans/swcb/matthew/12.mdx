<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="申命记 23:25; 马可福音 2:23–28; 路加福音 6:1–5"> 那时，耶稣在安息日从麦田经过；祂的门徒饿了，就掐麦穗吃。</span>
<span className="v" id="v2" data-v="2" data-xref="马太福音 12:10; 约翰福音 7:21–24; 路加福音 14:3"> 法利赛人看见，就对祂说：“看哪，你的门徒做安息日不可做的事。”</span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="撒母耳记上 21:3–6; 路加福音 6:3; 马可福音 2:25–26"> 耶稣对他们说：<span className="woj">“大卫和跟随他的人饥饿的时候所做的，你们没有读过吗？</span></span>
<span className="v" id="v4" data-v="4" data-xref="利未记 24:5–9; 出埃及记 25:30; 利未记 8:31"> <span className="woj">他怎样进了上帝的殿，吃了陈设饼；这饼他和跟随他的人都不可吃，只有祭司才可以吃。</span></span>
<span className="v" id="v5" data-v="5" data-xref="民数记 28:9–10; 约翰福音 7:22–23; 尼希米记 13:17"> <span className="woj">或者，律法上说，安息日祭司在圣殿里犯了安息日，仍算无罪，这个你们没有读过吗？</span></span>
<span className="v" id="v6" data-v="6" data-xref="马太福音 12:41–42; 历代志下 6:18; 彼得前书 2:4–5"> <span className="woj">但我告诉你们，在这里有一位比圣殿更大的。</span></span>
<span className="v" id="v7" data-v="7" data-xref="何西阿 6:6; 马太福音 9:13; 弥迦书 6:6–8"> <span className="woj">你们若明白这话的意思：‘我喜爱怜悯，不喜爱祭祀，’</span><span className="woj">就不会定无罪之人的罪了。</span></span>
<span className="v" id="v8" data-v="8" data-xref="马可福音 2:28; 路加福音 6:5; 约翰福音 5:17–23"> <span className="woj">因为人子是安息日的主。”</span></span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="马可福音 3:1–6; 路加福音 6:6–11"> 耶稣离开那里，进了他们的会堂。</span>
<span className="v" id="v10" data-v="10" data-xref="路加福音 13:14; 约翰福音 9:16; 约翰福音 8:6"> 看哪，那里有一个人一只手枯干了。有人问耶稣说：“安息日治病合乎律法吗？”他们是要控告祂。</span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="申命记 22:4; 路加福音 14:5; 路加福音 13:15–17"> 耶稣对他们说：<span className="woj">“你们中间谁有一只羊，若在安息日掉进坑里，不把它抓住拉上来呢？</span></span>
<span className="v" id="v12" data-v="12" data-xref="马太福音 6:26; 路加福音 6:9; 马可福音 3:4"> <span className="woj">人比羊贵重得多！所以，安息日行善是合乎律法的。”</span></span>
<span className="v" id="v13" data-v="13" data-xref="路加福音 13:13; 使徒行传 3:7–8"> 于是祂对那人说：<span className="woj">“伸出你的手来。”</span>他一伸，手就复原，像另一只一样完好。</span>
<span className="v" id="v14" data-v="14" data-xref="约翰福音 11:53; 约翰福音 10:39; 马可福音 3:6"> 法利赛人却出去，商议怎样除灭耶稣。</span>
</div>
<div className="bp poetry">
<span className="v" id="v15" data-v="15" data-xref="马可福音 3:7–12; 马太福音 10:23; 马太福音 19:2"> 耶稣知道了，就离开那里。有大群人跟随祂，祂把他们都医好了，</span>
<span className="v" id="v16" data-v="16" data-xref="马太福音 8:4; 马太福音 9:30; 马太福音 17:9"> 又嘱咐他们不要使祂显扬出去，</span>
<span className="v" id="v17" data-v="17" data-xref="以赛亚书 42:1–4; 以赛亚书 42:9; 马太福音 13:35"> 这是要应验先知以赛亚所说的话：</span>
<span className="v" id="v18" data-v="18" data-xref="以赛亚书 42:1; 路加福音 4:18; 使徒行传 10:38"> <span className="pl pl-1">“看哪，我所拣选的仆人，</span><br /><span className="pl pl-2">我所爱的，我灵魂所喜悦的。</span><br /><span className="pl pl-1">我要把我的灵放在祂身上，</span><br /><span className="pl pl-2">祂要向万国宣告公理。</span></span>
<span className="v" id="v19" data-v="19" data-xref="马太福音 11:29; 约翰福音 18:36–38; 提摩太后书 2:24–25"> <span className="pl pl-1">祂不争竞，不喧嚷，</span><br /><span className="pl pl-2">街上也没有人听见祂的声音。</span></span>
<span className="v" id="v20" data-v="20" data-xref="以赛亚书 42:3–4; 以西结 34:16; 以赛亚书 61:1–3"> <span className="pl pl-1">压伤的芦苇，祂不折断；</span><br /><span className="pl pl-2">将残的灯火，祂不吹灭，</span><br /><span className="pl pl-1">直到祂使公理得胜。</span></span>
<span className="v" id="v21" data-v="21" data-xref="以赛亚书 11:10; 罗马书 15:12–13; 以赛亚书 42:4"> <span className="pl pl-2">万民都要仰望祂的名。”</span></span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 11:14–15; 马可福音 7:35–37; 以赛亚书 29:18"> 当时，有人把一个被鬼附、又瞎又哑的人带到耶稣面前；耶稣医好了他，使那哑巴又能说话，又能看见。</span>
<span className="v" id="v23" data-v="23" data-xref="马太福音 9:27; 约翰福音 4:29; 马太福音 22:42–43"> 众人都惊奇，说：“这难道是大卫的子孙吗？”</span>
<span className="v" id="v24" data-v="24" data-xref="马可福音 3:22; 马太福音 9:34; 路加福音 11:15"> 但法利赛人听见了，就说：“这个人赶鬼，无非是靠着鬼王别西卜。”</span>
</div>
<div className="bp">
<span className="v" id="v25" data-v="25" data-xref="加拉太书 5:15; 耶利米书 17:10; 马太福音 9:4"> 耶稣知道他们的意念，就对他们说：<span className="woj">“凡一国自相纷争，就必荒废；凡一城或一家自相纷争，就站立不住。</span></span>
<span className="v" id="v26" data-v="26" data-xref="歌罗西书 1:13; 启示录 20:2–3; 约翰一书 5:19"> <span className="woj">若撒但赶出撒但，就是自相纷争；他的国怎能站立得住呢？</span></span>
<span className="v" id="v27" data-v="27" data-xref="使徒行传 19:13–16; 马可福音 9:38–39; 路加福音 9:49–50"> <span className="woj">我若靠着别西卜赶鬼，你们的子弟又靠谁赶鬼呢？因此，他们就要作你们的审判者。</span></span>
<span className="v" id="v28" data-v="28" data-xref="路加福音 11:20; 但以理 7:14; 马太福音 6:33"> <span className="woj">我若靠着上帝的灵赶鬼，那么上帝的国已经临到你们了。</span></span>
<span className="v" id="v29" data-v="29" data-xref="以赛亚书 49:24; 马可福音 3:27; 路加福音 11:21–22"> <span className="woj">人怎能进壮士家里，抢夺他的家产呢？除非先捆住那壮士，然后才能抢夺他的家。</span></span>
</div>
<div className="bp">
<span className="v" id="v30" data-v="30" data-xref="马可福音 9:40; 路加福音 11:23; 约书亚记 24:15"> <span className="woj">“不与我同在的，就是敌挡我；不同我收聚的，就是分散。</span></span>
<span className="v" id="v31" data-v="31" data-xref="路加福音 12:10; 马可福音 3:28–30; 希伯来书 10:29"> <span className="woj">所以我告诉你们，人一切的罪和亵渎都可得赦免，惟独亵渎圣灵，总不得赦免。</span></span>
<span className="v" id="v32" data-v="32" data-xref="马可福音 3:29; 希伯来书 10:26–29; 希伯来书 6:4–6"> <span className="woj">凡说话干犯人子的，还可得赦免；惟独说话干犯圣灵的，无论在今世或来世，都不得赦免。</span></span>
</div>
<div className="bp">
<span className="v" id="v33" data-v="33" data-xref="路加福音 6:43–44; 马太福音 7:16–20; 雅各书 4:8"> <span className="woj">“你们或使树好，果子也好；或使树坏，果子也坏；因为树是凭果子认出来的。</span></span>
<span className="v" id="v34" data-v="34" data-xref="路加福音 6:45; 马太福音 15:18; 以弗所书 4:29"> <span className="woj">毒蛇的后代啊！你们既是恶人，怎能说出好话来呢？因为心里所充满的，口里就说出来。</span></span>
<span className="v" id="v35" data-v="35" data-xref="箴言 15:4; 歌罗西书 4:6; 箴言 15:28"> <span className="woj">善人从他所存的善</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR 加有“在心里”。">a</a></sup><span className="woj">发出善来；恶人从他所存的恶发出恶来。</span></span>
<span className="v" id="v36" data-v="36" data-xref="传道书 12:14; 罗马书 2:16; 启示录 20:12"> <span className="woj">我告诉你们，人所说的每一句闲话，在审判的日子都要供出来。</span></span>
<span className="v" id="v37" data-v="37" data-xref="箴言 13:3; 雅各书 2:21–25"> <span className="woj">因为要凭你的话称你为义，也要凭你的话定你的罪。”</span></span>
</div>
<div className="bp">
<span className="v" id="v38" data-v="38" data-xref="哥林多前书 1:22; 马可福音 8:11–12; 路加福音 11:16"> 当时，有几个文士和法利赛人回答祂说：“老师，我们愿意看你显个神迹。”</span>
</div>
<div className="bp">
<span className="v" id="v39" data-v="39" data-xref="马太福音 16:4; 路加福音 11:29–32; 马可福音 8:38"> 耶稣回答他们说：<span className="woj">“邪恶淫乱的世代寻求神迹；除了先知约拿的神迹以外，再没有神迹给它。</span></span>
<span className="v" id="v40" data-v="40" data-xref="约拿 1:17; 马太福音 27:63–64; 马太福音 16:21"> <span className="woj">约拿怎样三日三夜在大鱼腹中，人子也要照样三日三夜在地心里。</span></span>
<span className="v" id="v41" data-v="41" data-xref="马太福音 12:42; 希伯来书 11:7; 马太福音 12:6"> <span className="woj">尼尼微人在审判的时候，要同这世代一同站起来，定这世代的罪；因为他们听了约拿所传的就悔改了。看哪，在这里有一位比约拿更大的。</span></span>
<span className="v" id="v42" data-v="42" data-xref="列王纪上 10:1–13; 历代志下 9:1–12; 希伯来书 1:2–4"> <span className="woj">南方的女王在审判的时候，要同这世代一同起来，定这世代的罪；因为她从地极而来，要听所罗门的智慧。看哪，在这里有一位比所罗门更大的。</span></span>
</div>
<div className="bp">
<span className="v" id="v43" data-v="43" data-xref="路加福音 11:24–26; 路加福音 8:28–32; 马太福音 8:29"> <span className="woj">“污灵从人里面出来以后，经过干旱无水之地，寻找安歇之处，却找不着。</span></span>
<span className="v" id="v44" data-v="44" data-xref="约翰一书 4:4; 启示录 13:8–9; 犹大书 1:4–5"> <span className="woj">于是它说：‘我要回到我出来的那屋里去。’它回来以后，看见里面空着，已经打扫干净，整理好了。</span></span>
<span className="v" id="v45" data-v="45" data-xref="路加福音 11:26; 马可福音 5:9; 希伯来书 6:4–8"> <span className="woj">于是它去，另带了七个比自己更恶的灵来，都进去住在那里；那人末后的景况就比先前更坏了。这个邪恶的世代也要这样。”</span></span>
</div>
<div className="bp">
<span className="v" id="v46" data-v="46" data-xref="马太福音 13:55; 约翰福音 2:12; 约翰福音 7:3"> 耶稣还对众人说话的时候，看哪，祂母亲和祂的兄弟站在外面，要同祂说话。</span>
<span className="v" id="v47" data-v="47"> 有人对祂说：“看哪，你的母亲和你的兄弟站在外面，要同你说话。”</span>
</div>
<div className="bp">
<span className="v" id="v48" data-v="48" data-xref="马可福音 3:32–33; 马太福音 10:37; 路加福音 2:52"> 耶稣回答那对祂说话的人，说：<span className="woj">“谁是我的母亲？谁是我的兄弟？”</span></span>
<span className="v" id="v49" data-v="49" data-xref="马可福音 3:34; 约翰福音 17:8–9; 约翰福音 20:17–20"> 祂伸手指着门徒，说：<span className="woj">“看哪，我的母亲和我的兄弟！</span></span>
<span className="v" id="v50" data-v="50" data-xref="路加福音 8:21; 马可福音 3:35; 约翰福音 15:14"> <span className="woj">凡遵行我天父旨意的人，就是我的弟兄、姐妹和母亲。”</span></span>
</div>

<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="马太福音 4:13; 路加福音 8:37; 马太福音 8:18"> 耶稣上了船，渡过海，来到自己的城。</span>
<span className="v" id="v2" data-v="2" data-xref="马可福音 2:1–12; 路加福音 5:18–26; 耶利米书 31:33–34"> 看哪，有人把一个瘫痪的人用褥子抬到祂面前。耶稣看见他们的信心，就对那瘫痪的人说：<span className="woj">“孩子，放心吧！你的罪赦免了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v3" data-v="3" data-xref="马太福音 26:65; 路加福音 5:21; 利未记 24:16"> 看哪，有几个文士心里说：“这个人说亵渎的话。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="路加福音 6:8; 马太福音 12:25; 启示录 2:23"> 耶稣知道他们的意念，就说：<span className="woj">“你们为什么心里怀着恶念？</span></span>
<span className="v" id="v5" data-v="5" data-xref="约翰福音 5:8–14; 马可福音 2:9–12; 使徒行传 3:16"> <span className="woj">说‘你的罪赦免了’，或说‘起来行走’，哪一样容易呢？</span></span>
<span className="v" id="v6" data-v="6" data-xref="以赛亚书 43:25; 马太福音 9:5; 约翰福音 20:21–23"> <span className="woj">但要叫你们知道，人子在地上有赦罪的权柄——”</span>于是祂对瘫痪的人说：<span className="woj">“起来，拿起你的褥子，回家去吧。”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7"> 那人就起来，回家去了。</span>
<span className="v" id="v8" data-v="8" data-xref="路加福音 7:16; 马太福音 15:31; 使徒行传 4:21"> 众人看见，就感到惊奇，荣耀上帝，因为祂把这样的权柄赐给了人。</span>
</div>
<div className="bp">
<span className="v" id="v9" data-v="9" data-xref="路加福音 5:27–38; 马可福音 2:14–22; 路加福音 19:2–10"> 耶稣从那里往前走，看见一个名叫马太的人坐在税关那里，就对他说：<span className="woj">“跟从我。”</span>他就起来，跟从了祂。</span>
<span className="v" id="v10" data-v="10" data-xref="提摩太前书 1:13–16; 路加福音 5:29–32; 马可福音 2:15–17"> 耶稣在屋里坐席的时候，看哪，有许多税吏和罪人来，同耶稣和祂的门徒一同坐席。</span>
<span className="v" id="v11" data-v="11" data-xref="马太福音 11:19; 路加福音 5:30; 马可福音 2:16"> 法利赛人看见了，就对祂的门徒说：“你们的老师为什么和税吏并罪人一同吃饭？”</span>
</div>
<div className="bp">
<span className="v" id="v12" data-v="12" data-xref="路加福音 5:31; 启示录 3:17–18; 马可福音 2:17"> 耶稣听见，就对他们说：<span className="woj">“健康的人不需要医生，有病的人才需要。</span></span>
<span className="v" id="v13" data-v="13" data-xref="马可福音 2:17; 路加福音 19:10; 何西阿 6:6"> <span className="woj">你们去揣摩这话的意思：‘我喜爱怜悯，不喜爱祭祀。’</span><span className="woj">因为我来不是召义人，而是召罪人悔改。”</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="NU 省略“悔改”。">a</a></sup></span>
</div>
<div className="bp">
<span className="v" id="v14" data-v="14" data-xref="路加福音 5:33–39; 马可福音 2:18–22; 马太福音 6:16"> 那时，约翰的门徒来到耶稣面前，说：“为什么我们和法利赛人常常禁食，你的门徒倒不禁食呢？”</span>
</div>
<div className="bp">
<span className="v" id="v15" data-v="15" data-xref="启示录 19:9; 约翰福音 3:29; 启示录 21:2"> 耶稣对他们说：<span className="woj">“新郎和陪伴的人同在的时候，他们岂能悲哀呢？但日子将到，新郎要从他们中间被取走，那时他们就要禁食。</span></span>
<span className="v" id="v16" data-v="16" data-xref="哥林多前书 3:1–2; 约翰福音 16:12; 诗篇 125:3"> <span className="woj">没有人把未经缩水的新布补在旧衣服上；因为补丁会从衣服上扯裂下来，破口就更大了。</span></span>
<span className="v" id="v17" data-v="17" data-xref="约书亚记 9:4; 约伯记 32:19; 诗篇 119:83"> <span className="woj">也没有人把新酒装在旧皮袋里；若是这样，皮袋就裂开，酒漏出来，皮袋也坏了。总要把新酒装在新皮袋里，两样就都保全。”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="路加福音 8:41–56; 马可福音 5:22–43; 马太福音 8:2"> 耶稣正对他们说这些话的时候，看哪，有一个官来俯伏敬拜祂，说：“我的女儿刚刚死了；但请你来按手在她身上，她就必活了。”</span>
</div>
<div className="bp">
<span className="v" id="v19" data-v="19" data-xref="使徒行传 10:38; 加拉太书 6:9–10; 马太福音 8:7"> 耶稣就起来跟着他去，门徒也跟着去。</span>
<span className="v" id="v20" data-v="20" data-xref="路加福音 8:43–56; 马太福音 14:36; 马可福音 6:56"> 看哪，有一个患了十二年血漏的女人，从后面来，摸了耶稣衣服的穗子<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="或作“繸子”。">b</a></sup>；</span>
<span className="v" id="v21" data-v="21" data-xref="马可福音 5:26–33; 路加福音 8:45–47; 使徒行传 19:12"> 因为她心里说：“我只要摸到祂的衣服，就必痊愈。”</span>
</div>
<div className="bp">
<span className="v" id="v22" data-v="22" data-xref="路加福音 7:50; 马太福音 15:28; 马太福音 9:2"> 耶稣转过身来看见她，说：<span className="woj">“女儿，放心吧！你的信心使你痊愈了。”</span>从那时起，那女人就痊愈了。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="历代志下 35:25; 马可福音 5:35–40; 路加福音 8:49–51"> 耶稣到了那官的家里，看见吹笛的人和乱嚷的人群，</span>
<span className="v" id="v24" data-v="24" data-xref="使徒行传 20:10; 约翰福音 11:11–13; 马太福音 27:39–43"> 就说：<span className="woj">“让开吧，因为这女孩不是死了，是睡着了。”</span><br />他们就嗤笑祂。</span>
<span className="v" id="v25" data-v="25" data-xref="马可福音 9:27; 马可福音 5:41; 路加福音 8:54"> 人群被赶出去以后，耶稣进去，拉着女孩的手，女孩就起来了。</span>
<span className="v" id="v26" data-v="26" data-xref="马太福音 4:24; 马太福音 14:1–2; 马可福音 1:45"> 这消息传遍了那一带地方。</span>
</div>
<div className="bp">
<span className="v" id="v27" data-v="27" data-xref="马太福音 15:22; 马太福音 20:30–31; 马可福音 10:46–48"> 耶稣从那里往前走，有两个瞎子跟着祂，喊着说：“大卫的子孙啊，怜悯我们吧！”</span>
<span className="v" id="v28" data-v="28" data-xref="马可福音 9:23–24; 马太福音 13:58; 马太福音 8:2"> 耶稣进了屋子，瞎子来到祂面前。耶稣对他们说：<span className="woj">“你们信我能做这事吗？”</span><br />他们对祂说：“主啊，我们信。”</span>
</div>
<div className="bp">
<span className="v" id="v29" data-v="29" data-xref="马太福音 15:28; 马可福音 10:52; 马太福音 8:13"> 于是祂摸他们的眼睛，说：<span className="woj">“照着你们的信心，给你们成就吧。”</span></span>
<span className="v" id="v30" data-v="30" data-xref="马太福音 8:4; 路加福音 5:14; 马太福音 17:9"> 他们的眼睛就开了。耶稣严严地嘱咐他们说：<span className="woj">“要谨慎，不可让任何人知道。”</span></span>
<span className="v" id="v31" data-v="31" data-xref="马可福音 7:36; 马太福音 9:26; 马可福音 1:44–45"> 他们却出去，把祂的名声传遍了那一带地方。</span>
</div>
<div className="bp">
<span className="v" id="v32" data-v="32" data-xref="马太福音 4:24; 马太福音 12:22–24; 路加福音 11:14"> 他们出去的时候，看哪，有人把一个被鬼附的哑巴带到耶稣面前。</span>
<span className="v" id="v33" data-v="33" data-xref="以赛亚书 35:6; 马可福音 7:32–37; 出埃及记 4:11–12"> 鬼被赶出去以后，哑巴就说出话来。众人都惊奇，说：“在以色列中，从来没有见过这样的事！”</span>
</div>
<div className="bp">
<span className="v" id="v34" data-v="34" data-xref="路加福音 11:15; 马可福音 3:22; 马太福音 12:23–24"> 但法利赛人说：“祂是靠着鬼王赶鬼。”</span>
</div>
<div className="bp">
<span className="v" id="v35" data-v="35" data-xref="马太福音 4:23–24; 使徒行传 10:38; 马可福音 6:56"> 耶稣走遍各城各村，在他们的会堂里教导人，传讲天国的福音，医治各样的疾病和各样的病症。</span>
<span className="v" id="v36" data-v="36" data-xref="马可福音 6:34; 民数记 27:17; 耶利米书 50:6"> 祂看见众人，就怜悯他们，因为他们困苦<sup className="fn"><a href="#fn-c" id="fnref-c" data-fn="TR 作“疲乏”，而非“困苦”。">c</a></sup>流离，如同没有牧人的羊。</span>
<span className="v" id="v37" data-v="37" data-xref="路加福音 10:2; 马可福音 16:15; 哥林多前书 3:9"> 于是祂对门徒说：<span className="woj">“要收的庄稼多，工人却少。</span></span>
<span className="v" id="v38" data-v="38" data-xref="路加福音 10:1–2; 耶利米书 3:15; 帖撒罗尼迦后书 3:1"> <span className="woj">所以你们要求庄稼的主，打发工人出去收祂的庄稼。”</span></span>
</div>
</div>

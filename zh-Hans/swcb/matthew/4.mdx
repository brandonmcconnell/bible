<div className="bt">
<div className="bp">
<span className="v" id="v1" data-v="1" data-xref="希伯来书 2:18; 路加福音 4:1–13; 马可福音 1:12–15"> 随后，耶稣被圣灵引到旷野，受魔鬼试探。</span>
<span className="v" id="v2" data-v="2" data-xref="申命记 9:18; 出埃及记 34:28; 列王纪上 19:8"> 祂禁食四十昼夜，后来就饿了。</span>
<span className="v" id="v3" data-v="3" data-xref="创世记 3:1–5; 帖撒罗尼迦前书 3:5; 民数记 11:4–6"> 那试探者进前来，对祂说：“你若是上帝的儿子，就吩咐这些石头变成饼吧。”</span>
</div>
<div className="bp">
<span className="v" id="v4" data-v="4" data-xref="申命记 8:3; 路加福音 4:4; 约翰福音 6:63"> 耶稣回答说：<span className="woj">“经上记着：‘人活着，不是单靠食物，乃是靠上帝口里所出的一切话。’”</span></span>
</div>
<div className="bp poetry">
<span className="v" id="v5" data-v="5" data-xref="路加福音 4:9; 马太福音 27:53; 启示录 11:2"> 于是魔鬼带祂进了圣城，使祂站在圣殿顶端，</span>
<span className="v" id="v6" data-v="6" data-xref="诗篇 91:11–12; 希伯来书 1:14; 诗篇 34:7"> 对祂说：“你若是上帝的儿子，就跳下去吧，因为经上记着：<br /><span className="pl pl-1">‘祂要为你吩咐祂的天使’，又说：</span><br /><span className="pl pl-1">‘他们要用手托住你，</span><br /><span className="pl pl-2">免得你的脚碰在石头上。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v7" data-v="7" data-xref="申命记 6:16; 哥林多前书 10:9; 诗篇 78:18"> 耶稣对他说：<span className="woj">“经上又记着：‘不可试探主你的上帝。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v8" data-v="8" data-xref="约翰一书 2:15–16; 启示录 11:15; 诗篇 49:16–17"> 魔鬼又带祂上一座极高的山，把世上万国和万国的荣华都指给祂看，</span>
<span className="v" id="v9" data-v="9" data-xref="哥林多后书 4:4; 但以理 5:18–19; 约翰福音 16:11"> 对祂说：“你若俯伏敬拜我，我就把这一切都给你。”</span>
</div>
<div className="bp">
<span className="v" id="v10" data-v="10" data-xref="申命记 6:13–14; 申命记 10:20; 约书亚记 24:14"> 耶稣对他说：<span className="woj">“撒但，退到我后面去！</span><sup className="fn"><a href="#fn-a" id="fnref-a" data-fn="TR 和 NU 作“离开吧”，而非“退到我后面去”。">a</a></sup><span className="woj">因为经上记着：‘你要敬拜主你的上帝，单要事奉祂。’”</span></span>
</div>
<div className="bp">
<span className="v" id="v11" data-v="11" data-xref="马太福音 26:53; 希伯来书 1:14; 路加福音 22:43"> 于是魔鬼离开了祂；看哪，有天使来服事祂。</span>
</div>
<div className="bp poetry">
<span className="v" id="v12" data-v="12" data-xref="马可福音 1:14; 路加福音 3:20; 马太福音 14:3"> 耶稣听见约翰被交了出去，就退到加利利去。</span>
<span className="v" id="v13" data-v="13" data-xref="约翰福音 4:46; 马可福音 1:21; 马太福音 11:23"> 祂离开拿撒勒，来到迦百农居住；迦百农在海边，位于西布伦和拿弗他利境内，</span>
<span className="v" id="v14" data-v="14" data-xref="以赛亚书 9:1–2; 马太福音 2:23; 路加福音 24:44"> 这是要应验先知以赛亚所说的话：</span>
<span className="v" id="v15" data-v="15" data-xref="以赛亚书 9:1; 列王纪下 15:29; 约书亚记 21:32"> <span className="pl pl-1">“西布伦地，拿弗他利地，</span><br /><span className="pl pl-2">沿海的路，约旦河外，</span><br /><span className="pl pl-2">外邦人的加利利，</span></span>
<span className="v" id="v16" data-v="16" data-xref="以赛亚书 9:2; 以赛亚书 42:6–7; 以赛亚书 60:1–3"> <span className="pl pl-1">那坐在黑暗中的百姓看见了大光；</span><br /><span className="pl pl-2">那些坐在死亡之地和死荫中的人，</span><br /><span className="pl pl-2">有光照亮他们。”</span></span>
</div>
<div className="bp">
<span className="v" id="v17" data-v="17" data-xref="马太福音 3:2; 使徒行传 2:38; 马可福音 1:14–15"> 从那时起，耶稣开始传道，说：<span className="woj">“你们要悔改！因为天国近了。”</span></span>
</div>
<div className="bp">
<span className="v" id="v18" data-v="18" data-xref="约翰福音 1:40–42; 马太福音 10:2; 路加福音 6:14"> 耶稣在加利利海边行走，祂<sup className="fn"><a href="#fn-b" id="fnref-b" data-fn="TR 作“耶稣”，而非“祂”。">b</a></sup>看见两个弟兄，就是那称为彼得的西门和他兄弟安得烈，正在海里撒网；他们本是渔夫。</span>
<span className="v" id="v19" data-v="19" data-xref="马可福音 1:17–18; 约翰福音 12:26; 马太福音 16:24"> 祂对他们说：<span className="woj">“来跟从我，我要使你们成为得人的渔夫。”</span></span>
</div>
<div className="bp">
<span className="v" id="v20" data-v="20" data-xref="马可福音 10:28–31; 马太福音 19:27; 路加福音 18:28–30"> 他们立刻撇下网，跟从了祂。</span>
<span className="v" id="v21" data-v="21" data-xref="马可福音 1:19–20; 马太福音 10:2; 马可福音 3:17"> 祂从那里往前走，又看见另外两个弟兄，就是西庇太的儿子雅各和他兄弟约翰；他们同父亲西庇太在船上补网。耶稣就呼召他们。</span>
<span className="v" id="v22" data-v="22" data-xref="马太福音 10:37; 路加福音 9:59–60; 申命记 33:9–10"> 他们立刻离了船，别了父亲，跟从了祂。</span>
</div>
<div className="bp">
<span className="v" id="v23" data-v="23" data-xref="马太福音 9:35; 马可福音 1:39; 使徒行传 10:38"> 耶稣走遍加利利，在他们的会堂里教导人，传讲天国的福音，医治百姓各样的疾病和各样的病症。</span>
<span className="v" id="v24" data-v="24" data-xref="马太福音 8:6; 马太福音 17:15; 路加福音 5:15"> 祂的名声传遍了整个叙利亚。人们把所有患病的带到祂那里，就是受各种疾病和痛苦折磨的、被鬼附的、癫痫的、瘫痪的，祂都医好了。</span>
<span className="v" id="v25" data-v="25" data-xref="路加福音 6:17; 马可福音 5:20; 马可福音 3:7–8"> 于是有大群人从加利利、低加坡里、耶路撒冷、犹太和约旦河外来跟随祂。</span>
</div>
</div>
